**1.Abootimg**

Android 设备使用特殊的分区格式来启动设备上的任何操作系统。这些引导映像包含内核映像、ramdisk、可选的第二阶段引导加载程序和引导时传递给内核的命令行。Android 的原始 mkbootimg 只能创建这些图像，而 abootimg 也可以提取和修改它们。将其他操作系统引入 android 设备时，需要处理 android 启动映像。

  

**2.Aesfix**

该程序用于纠正 AES 密钥计划中的位错误。它应该与 aeskeyfind 程序的输出一起使用。

  

它仅限于 AES-128 密钥计划，并且只能纠正单向 1->0 位错误。在大多数情况下，它已针对可读性而不是性能进行了优化。

  

该软件包对多种活动很有用，例如取证调查。

  

**3.Aeskeyfind**

该程序说明了在捕获的内存映像中定位 128 位和 256 位 AES 密钥的自动技术。

  

该程序使用各种算法并执行简单的熵测试来过滤掉不是键的块。它计算重复字节的数量并跳过重复次数过多的块。

  

即使由于内存衰减导致密钥调度的几个位已损坏，此方法也能工作。

  

该软件包对多种活动很有用，例如取证调查。

  

**4.Afflib**

高级取证格式 (AFF) 是用于存储计算机取证信息的磁盘格式。AFF 的关键特性包括：

  

*   AFF 允许您将计算机取证数据和相关元数据存储在一个或多个文件中。
    
*   AFF 允许对文件进行数字签名，以提供监管链和长期文件完整性。
    
*   AFF 允许将取证磁盘映像存储在运行中加密和解密以进行处理。这允许将包含隐私敏感材料的磁盘映像存储在 Internet 上。
    

该软件包提供了 AFF 工具包，这是一组用于处理计算机取证信息的程序。使用这些工具，您可以：

  

*   在各种格式之间相互转换磁盘映像，包括：
    

①　原始或“dd”；

②　splitraw（其中单个图像在多个文件之间拆分）；

③　AFF 格式（其中整个磁盘映像存储在单个文件中）；

④　AFD 格式（其中一个磁盘映像存储在单个目录中存储的多个 AFF 文件中）；

⑤　AFM 格式（其中 AFF 文件用于注释原始文件）。

*   比较磁盘映像并报告不同的数据或元数据。
    
*   将磁盘映像从一个位置复制到另一个位置，对数据、元数据进行全面验证，并自动生成监管链段。
    
*   在 AFF 文件中查找错误并修复它们。
    
*   打印有关文件的信息。
    
*   打印有关文件的详细统计信息
    
*   生成磁盘映像元数据的 XML 表示（例如，获取时间或获取设备的序列号）。
    
*   生成一个 XML“磁盘指纹”，它允许快速对磁盘映像进行指纹识别，而无需计算机对整个磁盘的 SHA1。
    

AFF 工具包提供以下可执行文件：affcat、affcompare、affconvert、affcopy、affcrypto、affdiskprint、affinfo、affix、affrecover、affsegment、affsign、affstats、affuse、affverify 和 affxml。

  

**5.Aflplusplus**

American Fuzzy lop 是一种模糊器，它采用编译时检测和遗传算法来自动发现干净、有趣的测试用例，这些用例在目标二进制文件中触发新的内部状态。这大大提高了模糊代码的功能覆盖率。该工具生成的紧凑合成语料库也可用于为其他更多劳动力或资源密集型测试制度提供种子。

  

afl++-fuzz 旨在实用：它具有适度的性能开销，使用各种高效的模糊测试策略，基本上不需要配置，并无缝处理复杂的实际用例 - 例如，常见的图像解析或文件压缩库。

  

**6.Aircrack-Ng**

aircrack-ng 是一个 802.11a/b/g WEP/WPA 破解程序，一旦收集到足够多的加密数据包，它就可以恢复 40 位、104 位、256 位或 512 位 WEP 密钥。它还可以使用一些高级方法或简单地通过蛮力攻击 WPA1/2 网络。

  

它实现了标准的 FMS 攻击以及一些优化，因此与其他 WEP 破解工具相比，攻击速度要快得多。它还可以充分利用多处理器系统以加快破解过程。

  

**7.Airgeddon**

airgeddon 是一个菜单驱动的 3rd 方工具包装器，用于审核具有许多功能的无线网络。

  

**8.Altdns**

这是一个 DNS 侦察工具，允许发现符合模式的子域。Altdns 接收可能出现在域下的子域（例如 test、dev、staging）中的单词以及您知道的子域列表。

  

从作为输入提供给 altdns 的这两个列表中，该工具然后生成可能存在的“改变”或“变异”潜在子域的大量输出。它会保存此输出，以便您最喜欢的 DNS 暴力破解工具可以使用它。

  

**9.Amap**

AMAP 代表应用程序映射器。它是渗透测试人员的下一代扫描工具。即使应用程序在与正常端口不同的端口上运行，它也会尝试识别应用程序。

  

它还识别非基于 ASCII 的应用程序。这是通过发送触发数据包并在响应字符串列表中查找响应来实现的。

  

**10.Amass**

此工具可帮助信息安全专业人员的工具进行攻击面的网络映射和使用开源信息收集和主动探测技术，进行外部资产发现。

  

使用的信息收集技术：- DNS：基本枚举、暴力破解（根据请求）、反向 DNS 扫描、子域名更改/排列、区域传输（根据请求） - 抓取：Ask、Baidu、Bing、DNSDumpster、DNSTable、Dogpile、Exalead , Google, HackerOne, IPv4Info, Netcraft, PTRArchive, Riddler, SiteDossier, ViewDNS, Yahoo - 证书：Active pulls (on request), Censys, CertSpotter, Crtsh, Entrust, GoogleCT - APIs: AlienVault, BinaryEdge, BufferOver, CIRCL, CommonCrawl, DNSDB、HackerTarget、Mnemonic、NetworksDB、PassiveTotal、RADb、Robtex、SecurityTrails、ShadowServer、Shodan、Spyse（CertDB 和 FindSubdomains）、Sublist3rAPI、TeamCymru、ThreatCrowd、Twitter、Umbrella、URLScan、VirusTotal - 网络档案：ArchiveIt、ArchiveToday、Arquivo LoCArchive、OpenUKArchive、UKGovArchive、Wayback

  

**11.Apache-Users**

此 Perl 脚本将枚举使用 Apache 和 UserDir 模块的任何系统上的用户名。

  

**12.Apache2**

Apache HTTP 服务器项目的目标是构建一个安全、高效和可扩展的 HTTP 服务器，作为符合标准的开源软件。结果长期以来一直是 Internet 上排名第一的 Web 服务器。

  

安装此包会导致完整安装，包括配置文件、初始化脚本和支持脚本。

  

**13.Apktool**

这是一个用于逆向工程第 3 方、封闭、二进制 Android 应用程序的工具。可以将资源解码成接近原始的形式，并在进行一些修改后重建；它使逐步调试 smali 代码成为可能。此外，由于类似项目的文件结构和一些重复性任务（如构建 apk）的自动化，它使使用应用程序变得更容易。

  

**14.Arjun**

这是用于查找 URL 端点的查询参数的工具。

  

Web 应用程序使用参数（或查询）来接受用户输入，请考虑以下示例：

http://api.example.com/v1/userinfo?id=751634589 此 URL 似乎加载特定用户 ID 的用户信息，但是如果存在一个名为 admin 的参数，当设置为 True 时，端点会提供有关用户的更多信息怎么办？这就是 Arjun 所做的，它使用包含 25,980 个参数名称的庞大默认字典查找有效的 HTTP 参数。

  

**15.Armitage**

Armitage 是一个用于 Metasploit 的可编写脚本的红队协作工具，可将目标可视化、推荐漏洞利用并公开框架中的高级漏洞利用后功能。

  

**16.Arp-Scan**

arp-scan 是一个命令行工具，它使用 ARP 协议来发现和识别本地网络上的 IP 主机。它在 GPL 许可下可用于 Linux 和 BSD

  

**17.Arping**

arping 实用程序将 ARP 和/或 ICMP 请求发送到指定的主机并显示回复。主机可以通过其主机名、IP 地址或 MAC 地址来指定。

  

**18.Arpwatch**

Arpwatch维护网络上的以太网MAC地址及其相关IP对的数据库。如果发生任何更改，例如新站/活动、触发器、更改和重新使用的旧地址，则通过电子邮件通知系统管理员。

  

**19.Asleap**

证明专有 Cisco LEAP 网络存在严重缺陷。

  

可读入字典文件，提供输出文件名和输出索引文件名。

读取捕获文件，提供哈希文件文件名，哈希文件索引，并跳过身份验证检查。

使用单词表破解来自 freeradius的质询和响应

  

**20.Assetfinder**

该工具用于查找可能与给定域相关的域和子域。

  

**21.Atftp**

普通文件传输协议 (TFTP) 的交互式客户端。其用途主要用于测试和调试atftp 服务器。从 LAN 启动时，TFTP 客户端通常在 UEFI/BIOS 和引导程序（如 pxelinux）中实现。atftp 客户端还支持非交互式调用，以便于在脚本中使用。

  

**22.Autopsy**

Autopsy Forensic Browser 是 Sleuth Kit 中命令行数字取证分析工具的图形界面。Sleuth Kit 和 Autopsy 一起提供了许多与用于分析 Windows 和 UNIX 文件系统（NTFS、FAT、FFS、EXT2FS 和 EXT3FS）的商业数字取证工具相同的功能。

  

**23.Axel**

Axel 尝试通过为一个文件使用多个连接来加速下载过程，类似于 DownThemAll 和其他著名程序。它还可以使用多个镜像进行一次下载。

  

使用 Axel，您可以更快地从 Internet 获取文件。因此，Axel 可以将下载速度提高 60%（根据一些测试，大约是这样）。

  

Axel 支持 HTTP、HTTPS、FTP 和 FTPS 协议。

  

Axel 试图尽可能地轻巧，因此它可能在字节关键系统上用作 wget 克隆（和其他基于控制台的程序）。

  

**24.Android-Sdk**

Android SDK提供了为 Android 构建、测试和调试应用程序所需的 API 库和开发人员工具。
