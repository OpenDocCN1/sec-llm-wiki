**1.tlssled**

TLSSLed 是一个 Linux shell 脚本，其目的是评估目标 SSL/TLS (HTTPS) Web 服务器实现的安全性。它基于 sslscan，这是一个基于 openssl 库的 SSL/TLS 扫描器，以及“openssl s\_client”命令行工具。当前的测试包括检查目标是否支持 SSLv2 协议、NULL 密码、基于密钥长度（40 或 56 位）的弱密码、强密码（如 AES）的可用性、数字证书是否经过 MD5 签名，以及当前的 SSL/TLS 重新协商功能。

  

**2.tmux**

tmux 允许从单个终端（如屏幕）访问和控制多个终端（或窗口）。tmux 作为服务器-客户端系统运行。必要时会自动创建服务器并保存多个会话，每个会话可能有多个链接到它的窗口。任意数量的客户端都可以连接到一个会话，或者可以通过使用 tmux 发出命令来控制服务器。通信通过套接字进行，默认情况下位于 /tmp 中。此外，tmux 提供了一致且文档齐全的命令界面，无论是交互使用、作为键绑定还是从 shell 使用，都具有相同的语法。它提供了 vim 或 Emacs 键布局的选择。

  

**3.tnscmd10g**

在端口 1521/tcp 上刺激 oracle tnslsnr 进程的工具

  

**4.Traceroute**

traceroute 实用程序显示 IP 数据包在到达指定网络（或 Internet）主机的途中使用的路由。traceroute 显示数据包沿途的机器的 IP 号和主机名（如果可能）。Traceroute 用作网络调试工具。如果您遇到网络连接问题，traceroute 将向您显示问题出在路线上的位置。 如果您需要用于诊断网络连接问题的工具，请安装 traceroute

  

**5.truecrack**

TrueCrack 是 TrueCrypt（版权）卷的暴力密码破解程序。它使用 Nvidia Cuda 技术进行了优化。它与基于 RIPEMD160 密钥推导函数和用于基于 AES 的硬盘加密的 XTS 分组密码操作模式的 PBKDF2（在 PKCS5 v2.0 中定义）一起使用

  

**6.Tundeep**

除了 pcap 要求之外，该工具几乎完全位于受害者的用户空间中

  

**7.Twofi**

尝试破解密码时，自定义单词列表是标准词典的非常有用的补充。最初发布在“高效黑客的 7 个习惯”博客上的一个有趣想法是使用 Twitter 来帮助生成这些列表，该列表基于与被破解列表相关的关键字的搜索。我已经将这个想法扩展到 twofi 中，它将采用多个搜索词并返回一个按最常见的单词列表排序

  

**8.u-boot、u-boot-qemu、u-boot-tools**

u-boot-qemu，Das U-Boot 是嵌入式系统的跨平台引导加载程序，被多家主板供应商用作默认引导加载程序。它旨在易于移植和调试，并在许多受支持的架构上运行，包括 PPC、ARM、MIPS、x86、m68k、NIOS 和 Microblaze。这个包包括 qemu/kvm 的引导加载程序。包含平台：qemu-ppce500 qemu-riscv64 qemu-riscv64\_smode qemu-x86 qemu-x86\_64 qemu\_arm qemu\_arm64u-boot-tools，该软件包包括用于生成和列出各种格式的 U-Boot 映像的程序：1.图像，2.转储图像，3.mksunxiboot，4.mkenvimage。

  

**9.Ubertooth**

Project Ubertooth 是一个适合蓝牙实验的开源无线开发平台。该软件包包含使用硬件加密狗所需的一切。Ubertooth 能够嗅探 BLE（蓝牙智能）连接，它还能够嗅探来自基本速率 (BR) 蓝牙经典连接的一些数据。除了蓝牙特定功能外，还包含一个简单的 2.4 GHz 频段频谱分析仪 (ubertooth-specan-ui)，还可用于观察该频段中的其他内容。

  

**10.Udptunnel**

UDPTunnel 是一个小程序，它可以通过 TCP 连接双向隧道传输 UDP 数据包。它的主要目的（和最初的动机）是允许多媒体会议穿过只允许传出 TCP 连接的防火墙。UDPTunnel 还可用于网络中的安全测试。

  

**11.Uhd**

①libuhd-dev，Ettus Research 产品通用硬件驱动程序的主机库。

支持的设备提供模拟无线电接收器和发射器硬件以及数字接口，用于从主机上运行的软件定义无线电接收信号和从其接收信号。这个包包含使用 libuhd 开发的头文件。Doxygen 生成的文档在 uhd-host 包中

②libuhd3.15.0，Ettus Research 产品通用硬件驱动程序的主机库。

支持的设备提供模拟无线电接收器和发射器硬件以及数字接口，用于从主机上运行的软件定义无线电接收信号和从其接收信号。

这个包包含对 Python3 的 Python API 支持

③python3-uhd，Ettus Research 产品通用硬件驱动程序的主机库。

支持的设备提供模拟无线电接收器和发射器硬件以及数字接口，用于从主机上运行的软件定义无线电接收信号和从其接收信号。

④uhd-host，Ettus Research 产品通用硬件驱动程序的主机实用程序。

支持的设备提供模拟无线电接收器和发射器硬件以及数字接口，用于从主机上运行的软件定义无线电接收信号和从其接收信号。

  

该软件包包括用于定位和配置附加外围设备的 uhd\_find\_devices 应用程序、用于显示硬件配置信息的 uhd\_usrp\_probe 应用程序和 Doxygen 生成的文档  

  

**12.uhd-images：超高清图像**

  

**13.Undbx**

UnDBX 是一种从 MS Outlook Express .dbx 文件（或 MS Windows 中的类似电子邮件程序）中提取、恢复和取消删除电子邮件的工具。可以解析损坏的 .dbx 文件以尝试从中恢复消息。它还可以尝试取消删除邮件，不仅可以从已删除邮件中删除，还可以从未被覆盖的已删除邮件片段中删除。UnDBX 在取证调查中很有用。

  

**14.U****nhide**

Unhide 是一种取证工具，用于查找被 rootkit、Linux 内核模块或其他技术隐藏的进程和 TCP/UDP 端口。它包括两个实用程序：unhide 和 unhide-tcp。unhide 使用以下六种技术检测隐藏进程：

①比较 /proc 与 /bin/ps 输出

②将从 /bin/ps 收集的信息与通过 procfs 收集的信息进行比较。

③将从 /bin/ps 收集的信息与从系统调用（系统调用扫描）收集的信息进行比较。

④完整的PIDs空间占用（PIDs bruteforcing）

⑤反向搜索，验证ps看到的所有线程也被内核看到（/bin/ps输出vs /proc，procfs walk和syscall）

⑥快速比较 /proc、procfs walk 和 syscall vs /bin/ps 输出

unhide-tcp 通过暴力破解所有可用的 TCP/UDP 端口来识别正在侦听但未在/bin/netstat 中列出的 TCP/UDP 端口。rkhunter 可以在其日常扫描中使用该软件包。除了取证调查之外，这个包对于网络安全检查很有用

  

**15.unhide.rb**

Unhide.rb 是一种用于查找被 rootkit 隐藏的进程的取证工具。它以许多不同的方式寻找活动的进程。通过某种方式找到但其他方式未找到的进程被认为是“隐藏的”，并报告给用户。Unhide.rb 是原始 Unhide 用 Ruby 重写的试探性，它是用 C 编写的。虽然速度快得多，但它没有实现原始版本的所有诊断。它也不太安全，因为它不能静态编译。rkhunter 可以在其日常扫描中使用该软件包。

  

**16.Unicornscan**

Unicornscan 是一种新的信息收集和关联引擎，由安全研究和测试社区的成员构建。它旨在提供可扩展、准确、灵活和高效的引擎。它是根据 GPL 许可条款发布给社区使用的。优点：Unicornscan 是对用户域分布式 TCP/IP 堆栈的尝试。它旨在为研究人员提供一个高级接口，用于将刺激引入到启用 TCP/IP 的设备或网络中并测量来自其的响应。
