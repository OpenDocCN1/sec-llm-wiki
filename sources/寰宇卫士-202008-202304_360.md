**1.T50**

多协议数据包注入工具

\*nix 系统的多协议数据包注入工具，实际支持 15 种协议

特征：

1.泛洪攻击；

2.CIDR支持；

3.TCP，UDP，ICMP，IGMPv2，IGMPv3，EGP，DCCP，RSVP，RIPv1，RIPv2，GRE，ESP，AH，EIGRP和OSPF支持；

4.TCP选项；

5.高性能；

6.可以打每秒约1,000,000包

常见选项：

\--threshold NUM ：要发送的数据包的阈值NUM threshold（默认值1000）

\--flood：应用此选项将取代阈值

\--encapsulated：封装协议（GRE）（默认关闭）

\-B,--bogus-csum：伪校验和（默认关闭）

 -v,--version：版本打印版本并退出

\-h,--help：帮助显示此帮助并退出

示例：

运行一个默认的泛洪攻击（-flood）对目标IP（192.168.1.1）：

root@kali:~# t50 --flood 192.168.1.1

entering in flood mode...

hit CTRL+C to break.

T50 5.4.1-rc1 successfully launched on May 17th 2014 10:48:51

  

**2.tcpdump**

该程序允许你转储网络上的流量。tcpdump 能够检查 IPv4、ICMPv4、IPv6、ICMPv6、UDP、TCP、SNMP、AFS BGP、RIP、PIM、DVMRP、IGMP、SMB、OSPF、NFS 和许多其他数据包类型。

它可用于打印出网络接口上的数据包的头部，过滤匹配某个表达式的数据包。你可以使用此工具来追踪网络问题、检测攻击或监控网络活动。

示例：

Kali命令行输入：

Tcpdump -v -i eth0 -w cap123.pcap

  

**3.tcpflow**

它捕获作为 TCP 连接（流）的一部分传输的数据，并以方便协议分析或调试的方式存储数据。像“tcpdump”这样的程序会显示在线路上看到的数据包的摘要，但通常不存储实际传输的数据。相比之下，tcpflow 重建实际数据流并将每个流存储在单独的文件中以供以后分析。

tcpflow 理解序列号，无论重传或无序交付，都会正确重建数据流。但是，它目前无法理解 IP 分片；包含 IP 片段的流将不会被正确记录。

tcpflow 基于 LBL 数据包捕获库，因此支持与“tcpdump”等程序支持的相同的丰富过滤表达式。tcpflow 还可以从使用 'tcpdump -w' 捕获的数据重建流

  

**4.tcpick**

基于 libpcap 的文本模式嗅探器,可以实现跟踪、重组和重新排序 TCP 流将捕获的流保存在不同的文件中或在终端中显示它们使用不同的显示模式在终端上显示所有流，如 hexdump、hexdump + ascii、仅可打印字符、原始模式、彩色模式……处理多种网络接口类型，包括以太网卡和 PPP 接口

  

**5.tcpreplay**

旨在通过重放隐藏攻击的真实后台网络流量来测试 NIDS 的性能。Tcpreplay 允许您控制重放流量的速度，并且可以重放任意 tcpdump 跟踪。与以编程方式生成的人工流量不同，人工流量不执行 NIDS 执行的应用程序/协议检查，也不重现生产网络上出现的真实世界异常（不对称路由、流量突发/间歇、碎片、重传等)，tcpreplay 允许精确复制在真实网络上看到的真实流量。它包括以下可执行文件 tcpprep、tcprewrite、tcpreplay-edit、tcpbridge 和基于 pcap 的捕获是可能的。

①tcpinfo:用于调试损坏的 pcap 文件的 Pcap 文件解析器.

②tcpliveplay:使用新的 TCP 连接重播存储在实时网络上的 pcap 文件中的网络流量

③tcpprep:从 pcap 文件创建 tcpreplay 缓存缓存文件

④tcpreplay-edit：重放存储在 pcap 文件中的网络流量

⑤tcprewrite:在 pcap 文件中重写数据包

  

**6.teamSploit：**

基于组的渗透测试工具，提供实时协作和自动化。TeamSploit 是一套用于 Metasploit 框架的工具。TeamSploit 应该与任何 MSF 产品（包括 OpenSource、Express 或 Pro）一起使用

功能包括：

*   开发自动化
    
*   自动化后期开发
    
*   信息和数据收集
    
*   会话共享
    
*   特洛伊木马和 Trollware
    

TeamSploit 的主要目标是自动化常见的渗透测试任务，并为其他团队成员提供访问和信息

  

**7.termineter:**

这个包包含一个 Python 框架，它为智能仪表的安全测试提供了一个平台。它实现了 C1218 和 C1219 协议，用于通过光学接口进行通信。当前支持使用 C1219-2007 和 7 位字符集的仪表。这是北美最常见的配置。Termineter 通过使用带有串行接口的 ANSI 2 型光学探头的连接与智能仪表进行通信。

  

**8.testdisk：**

TestDisk 检查磁盘的分区和引导扇区。它在取证中非常有用，可以恢复丢失的分区。它适用于：

*   DOS/Windows FAT12、FAT16 和 FAT32
    
*   NTFS (Windows NT/2K/XP)
    
*   Linux Ext2 和 Ext3
    
*   BeFS (BeOS)
    
*   BSD 磁盘标签 ( FreeBSD/OpenBSD/NetBSD )
    
*   CramFS（压缩文件系统）
    
*   HFS 和 HFS+，分层文件系统
    
*   JFS，IBM 的日志文件系统
    
*   Linux 突袭
    
*   Linux Swap（版本 1 和 2）
    
*   LVM 和 LVM2，Linux 逻辑卷管理器
    
*   网络安全系统
    
*   ReiserFS 3.5 和 3.6
    
*   Sun Solaris i386 磁盘标签
    
*   UFS 和 UFS2 (Sun/BSD/...)
    
*   XFS，SGI 的日志文件系统
    

PhotoRec 是文件数据恢复软件，旨在从数码相机内存甚至硬盘中恢复丢失的图片。它已扩展为还搜索非音频/视频标头。它搜索以下文件并能够恢复它们：

*   Portable Network Graphics (.png)

*   zip archive (.zip)
    
      
    

**9.testssl.sh**

testssl.sh 是一个免费的命令行工具，它可以检查任何端口上的服务器服务是否支持 TLS/SSL 密码、协议以及最近的密码缺陷等。

主要特点：

①清晰的输出：您可以轻松判断任何事情的好坏

②易于安装：它适用于 Linux、Darwin、FreeBSD 和 MSYS2/Cygwin，开箱即用：无需安装或配置某些东西，无需 gems、CPAN、pip 等。

③灵活性：您可以测试任何启用 SSL/TLS 和 STARTTLS 服务，而不仅仅是端口 443 的网络服务器

④工具：几个命令行选项可帮助您运行您的测试并配置您的输出

⑤可靠：功能经过彻底测试

⑥冗长：如果由于客户端缺少功能而无法执行特定检查，您将收到警告

⑦隐私：只有您才能看到结果，而不是第三方

⑧自由：它是 100% 开源的。你可以看看代码，你可以改变它。甚至在GITHUB上面开源

  

**10.tftpd32**

tftpd32是一个免费的，开源的IPv6准备应用程序，它包括DHCP，TFTP，DNS，SNTP和日志服务器以及TFTP客户端。TFTP客户端和服务器与TFTP选项支持（TSIZE，块大小和超时），允许最高性能传输数据时完全兼容。一些扩展功能，如目录工具、安全调整、界面过滤；进度条和增强了客户端和服务器的 TFTP 协议的实用性和吞吐量。附带的 DHCP 服务器提供无限的自动或静态 IP 地址分配

  

**11.thc-ipv6**

用于测试 IPv6 和 ICMPv6 协议弱点的攻击工具包。

其中一些工具包括：

alive6：有效的活体扫描。

denial6：尝试针对目标进行一系列拒绝服务测试。

detect-new-ip6：检测加入网络的新 ip6 设备。

dnsdict6：并行化的 dns ipv6 字典 bruteforcer。

dos-new-ip6：检测新的 ip6 设备并告诉他们他们选择的 IP 在网络 (DOS) 上发生冲突。

exploit6：针对目标测试已知的 ipv6 漏洞。

fake\_mld6：在网络上您选择的多播组中宣布您自己。

fake\_router6：宣布自己是网络上的路由器。

flood\_advertise6：用随机邻居广告淹没目标。

flood\_router6：用随机路由器广告泛洪目标。

implementation6：对 ipv6 执行各种实现检查。

parasite6：icmp 邻居请求/广告欺骗者。

redir6：使用 icmp6 重定向欺骗器智能地将流量重定向给您（中间人）。

rsmurf6：远程 smurfer（目前已知仅适用于 Linux）。

thcping6：发送一个手工制作的 ping6 数据包。

toobig6：与redir6具有相同智能的mtu减少器。

  

**12.thc-pptp-bruter**

针对 pptp， vpn 端点（tcp 端口 1723）的蛮力程序。完全独立。支持最新的 MSChapV2 认证。针对 Windows 和 Cisco 网关进行了测试。利用 Microsoft 反蛮力实施中的弱点，这使得第二次尝试 300 个密码成为可能

  

**13.thc-ssl-dos**

thc-ssl-dos 是一个验证 SSL 性能的工具。建立安全的 SSL 连接需要服务器上的处理能力比客户端多 15 倍。thc-ssl-dos通过使服务器过载并将其从 Internet 上删除来利用这种不对称特性。这个问题影响了今天所有的 SSL 实现。供应商从 2003 年就意识到了这个问题，并且这个话题已经被广泛讨论。此攻击进一步利用 SSL 安全重新协商功能，通过单个 TCP 连接触发数千次重新协商

  

**14.Theharvester**

该软件包含一个用于从不同公共资源（搜索引擎、pgp 密钥服务器）收集子域名、电子邮件地址、虚拟主机、开放端口/横幅和员工姓名的工具

  

**15.tightvncserver**

VNC 代表虚拟网络计算。从本质上讲，它是一个远程显示系统，使您不仅可以在运行它的机器上查看计算“桌面”环境，还可以从 Internet 上的任何位置和各种机器架构查看计算“桌面”环境。这个包提供了一个服务器，X 客户端可以连接到它，服务器生成一个可以用 vncviewer 查看的显示。tinyvncserver 和普通 vncserver 之间的区别在于数据编码，针对低带宽连接进行了优化。如果客户端不支持 jpeg 或 zlib 编码，则可以使用默认编码。更高版本的 vncserver (> 3.3.3r2) 支持新的自动编码，该编码应该与 tinyvnc 编码一样好。

注意：此服务器不支持或不需要显示器。你需要一个 vncviewer 才能看到一些东西。但是，此查看器也可能位于运行本地网络中其他操作系统的计算机上。
