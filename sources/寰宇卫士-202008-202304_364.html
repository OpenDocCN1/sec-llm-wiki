六、启动 Pro 控制台

激活许可证密钥后，您可以从命令行运行 Metasploit。如果您拥有 Metasploit Pro 许可证，则可以运行 Pro Console。Pro Console 为您提供对 Metasploit Framework 的命令行访问，以及 Metasploit Pro 独有的功能，例如发现扫描、自动利用、暴力破解和报告，以此了解有关 Pro 控制台的更多信息。

 

要在 Linux 系统上启动 Pro Console，请打开命令行终端并在出现命令提示符时键入，您必须以 root.sudo msfpro 身份运行控制台。

$ cd /opt/metasploit

$ sudo msfpro

七、激活许可证密钥

现在您已经安装了 Metasploit，接下来您需要做的就是激活您的许可证密钥，每个许可证密钥都绑定到 Metasploit 的特定版本，并允许您访问您已注册的版本。

 

1、打开Metasploit Pro 的 Web 界面

如果您收到有关安全证书可信度的警告，请选择您了解风险并希望继续访问该网站。

2、当 Metasploit Pro 的 Web 界面出现时，将显示新用户设置页面，按照屏幕上的说明为 Metasploit Pro 创建用户帐户，保存用户帐户信息，以便您以 

后可以使用它来登录 Metasploit Pro。

 

 

3、创建用户帐户后，会出现激活 Metasploit 页面，在产品密钥字段中输入您从 Rapid7 收到的许可证密钥。

 

4、如果您需要使用 HTTP 代理访问 Internet，您可以选择 HTTP 代理选项并提供您要使用的 HTTP 代理服务器的信息。

5、 激活许可证密钥。

激活许可证密钥后，将出现“项目”页面，您现在可以创建一个项目并开始您的第一个 Pentest。
