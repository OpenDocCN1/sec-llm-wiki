三、在headless servers上安装 Metasploit


标准 Linux 安装程序将指导您在 Red Hat Enterprise 和 Ubuntu Linux 发行版上安装 Metasploit。安装程序将会引导您完成一系列提示，来确定您安装 Metasploit 的位置以及 Metasploit 服务使用的端口，还有安装开始时， 安装运行 Metasploit 所需的依赖项和服务。

 

1、打开 Linux 控制台。

2、下载安装程序并将其保存到您的系统中。

3、将安装程序的模式更改为可执行：

user@ubuntu:~4 chmod +x ./metasploit-latest-linux-x64-installer.run

4、运行安装程序：

sudo ./metasploit-latest-linux-x64-installer.run

5、当如下图欢迎消息出现时，按“ Enter ”开始安装过程。

 

6、阅读许可协议的每一部分并继续按“Enter”，直到您阅读完所有内容。

  

7、当您到达许可协议的末尾时，安装程序会显示以下屏幕,按“Enter” 继续。

 

8、输入 Y 以接受许可协议。

 

9、您可以直接按“Enter”在默认位置安装 Metasploit 或者输入安装 位置然后再按“Enter”。

 

10、添加一个调用Metasploit的初始化脚本，它使您能够启动、停止和重新启动 Metasploit 服务。

 

注：下一条消息提醒您禁用机器上启用的任何防火墙或防病毒应用程序。

11、 确认您没有运行任何防火墙或防病毒应用程序，然后按 Enter。12、输入您希望 Metasploit 服务运行的端口，然后按 Enter。

 

注：默认情况下，Metasploit 服务在端口 3790 上运行，如果要使用默认端口，请将端口字段留空并按 Enter。

 

13、输入要用于生成 SSL 证书的服务器名称。

 

如果要使用本地主机，请按 Enter。

 

14、输入您希望 SSL 证书有效的天数，然后按 Enter。

 

如果要使用默认值 3650 天，请按 Enter。

 

15、输入已信任证书。

 

16、安装过程现已准备就绪，输入并按"Enter"以安装Metasploit 及其所有组件。

下一条消息会通知您程序Metasploit正在安装，请等待安装完成。

17、 安装完成后，按 Enter 继续。

  

四、在headless servers上创建用户帐户

安装完成后，您需要先创建一个用户帐户，然后才能激活您的 Metasploit 许可证密钥，必须通过运行 script.createuser 创建初始用户帐户。

 

要创建用户帐户：

1、在 Linux 控制台中，输入以下命令以运行脚本：

user@ubuntu:~? sudo /opt/metasploit/createuser

2、该脚本会提示您输入用户名。输入要分配给帐户的用户名，然后按 “Enter”。

 

该脚本会创建用户帐户并自动为您生成密码，您需要复制密码，以便您可以登录 Metasploit Pro Web 界面，首次登录 Metasploit 后，您可以更改密码。


五、使用基于文本的浏览器激活您的许可证密钥

如果您无法访问 Web 浏览器，则可以从基于文本的浏览器（如 Lynx）激活您的许可证密钥。

 

1、启动浏览器

 

2、当出现 SSL 自签名证书消息时，输入以继续。

 

3、当cookie消息出现时，输入添加cookie并继续。

 

4、如果再次出现 SSL 自签名证书消息，请继续输入。

5、当登录页面出现时，输入您之前创建的用户名和密码，然后按 Enter。

 

6、如果 SSL 证书和 cookie 消息再次出现，请继续输入，一直到您看到 Metasploit menu为止。

 

7、当 Metasploit 菜单出现时，按两次空格键以查看许可证激活屏幕。

 

8、使用向下箭头导航到产品密钥字段并输入许可证密钥，许可证密钥应使用以下格式输入：xxxx-xxxx-xxxx-xxxx。

 

9、使用向下箭头导航到 ACTIVATE LICENSE 链接，然后按 Enter。

 

10、如果激活成功，将出现 Projects 屏幕并指示激活成功。

您现在已准备好运行 Metasploit。
