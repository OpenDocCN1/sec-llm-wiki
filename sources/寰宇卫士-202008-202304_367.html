本文采用图文并茂的方式详细分解Metasploit Pro的安装教程，并按照步骤分成上、中、下三篇，欢迎阅读参考。

安装Metasploit 是一个很简单的过程，安装向导会引导您通过一系列提示来确定要安装Metasploit 的位置以及您希望Metasploit 使用的端口。定义安装首选项后，安装程序会安装运行Metasploit 所需的依赖项和服务。

所有Metasploit 商业版都使用相同的安装程序。您用于激活产品的许可证密钥可解锁您购买的版本。

前期准备：

  • 获取许可证密钥—要激活 Metasploit，您需要拥有许可证密钥。如果您没有，请提交请求。

  • 验证您是否可以获得 root 权限或具有管理员权限—您必须在系统上具有 root 或管理员权限才能安装 Metasploit。

  • 禁用防病毒软件—防病毒软件将 Metasploit 检测为恶意软件，并可能导致 Metasploit 的安装和运行时出现问题。在安装 Metasploit 之前，请禁用系统使用的任何防病毒软件。

  • 禁用任何防火墙—本地防火墙，例如 Iptables 和 Windows 防火墙，会干扰漏洞利用和有效负载的运行。在安装 Metasploit 之前禁用所有本地防火墙。

  • 需要自行查看支持的操作系统和最低系统要求；

  • 安装 Metasploit 和 Nexpose

建议您在不同的系统上安装 Nexpose 和 Metasploit。如果您尝试在同一台机器上运行这两种产品，您可能会遇到性能问题。有关安装 Nexpose 的更多信息，请自行访问官方网站。


一、在 Windows 上安装 Metasploit

1、下载 Windows 安装程序。

2、下载安装程序后，找到安装程序文件并双击安装程序图标。

3、出现设置屏幕时，单击“Next”继续。

4、阅读许可协议，选择接受许可协议选项并单击“Next”继续。

5、为 Metasploit 选择一个安装目录，您选择的目录必须是空的，单击“Next”继续。

 

6、当禁用防病毒和防火墙屏幕出现时，如果您已禁用本地系统上的防病毒软件和防火墙，请单击“Next”，如果您在前期准备时未禁用它们，则此时必须禁用它们。

 

注：如果安装过程中检测到防病毒软件或防火墙已启用，您将看到警告，单击确定关闭警告，在禁用防火墙和防病毒软件之前，安装程序将不允许您继续安装。如果您不禁用它们，您将无法继续安装 Metasploit。

 

7、输入 Metasploit 服务应使用的 SSL 端口，然后单击“Next”。默认情况下，服务器将端口 3790 用于 HTTPS。如果该端口已经绑定到另一个进程，你可以使用netstat来确定一个进程是否已经在监听那个端口并结束该进程，或者可以输入另一个端口（例如8080或442）。

 

8、在下图中输入要用于生成 SSL 证书的 Web 服务器名称和证书的有效天数。

 

9、选择“ Yes, trust certificate ”将会把 Metasploit SSL 安装到操作系统的受信任证书中。如果您安装了该证书，使用操作系统证书的浏览器（例如 Internet Explorer）将不会提示您 SSL 证书不安全。

请注意，安装程序会创建一个临时证书颁发机构来生成证书并立即将其丢弃，以防止网络钓鱼攻击和证书的丢失。

 

10、安装程序已准备好安装 Metasploit 及其所有捆绑的依赖项。单击下一步继续。

11、安装完成后，单击“完成”按钮。

安装完成后，会出现一个窗口，提示您启动 Metasploit Web UI。此时，您应该启动 Metasploit Web UI 来创建用户帐户并激活您的许可证密钥，第一次启动 Metasploit 不需要重新启动系统。

 

二、在 Linux 上安装 Metasploit

1、打开命令行。

2、下载 Linux 安装程序。

3、将安装程序的模式更改为可执行：$ chmod +x desktop/metasploit-latest-linux-x64-installer.run

4、运行安装程序：

$ sudo desktop/metasploit-latest-linux-x64-installer.run

or

$ ./metasploit-latest-linux-x64-installer.run

5、当安装窗口出现时，单击“forward”开始安装过程。

 

6、阅读许可协议，选择我接受许可协议选项并单击“forward”继续。

 

7、为 Metasploit 选择一个安装目录，您选择的目录必须为空，单击“forward”以继续。

 

8、选择 Yes ，然后单击“forward”继续。

 

9、当禁用防病毒和防火墙屏幕出现时，如果您已禁用本地系统上的防病毒软件和防火墙，请单击“forward”。如果您尚未禁用它们，则此时必须禁用它们。

如果安装检测到防病毒软件或防火墙已启用，您将看到警告。单击确定关闭警告。在禁用防火墙和防病毒软件之前，安装程序将不允许您继续安装过程。如果您不能禁用它们，您将无法安装 Metasploit。
 

10、输入 Metasploit 服务应使用的 SSL 端口，然后单击“forward”。

注：默认情况下，服务器将端口 3790 用于 HTTPS。如果该端口已经绑定到另一个进程，可以使用来判断一个进程是否已经在该端口上监听并杀死该进程，也可以输入另一个端口，例如8080或442.netstat

 

11、在有效天数字段中输入要用于生成 SSL 证书的 Web 服务器名称和证书应有效的天数。

 

12、选择 Yes, trust certificate 将自签名 Metasploit SSL 证书安装到操作系统的受信任证书存储中。如果您安装了证书，使用操作系统证书的浏览器将不会提示您 SSL 证书不安全。

13、当“准备安装”屏幕出现时，单击“前进”开始安装过程。

14、安装完成后，单击完成按钮。

安装完成后，会出现一个窗口，提示您启动 Metasploit Web UI。此时，您应该启动 Metasploit Web UI 来创建用户帐户并激活您的许可证密钥。第一次启动 Metasploit 不需要重新启动系统。
