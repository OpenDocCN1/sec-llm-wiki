# Ubantu与Debian系统的Sudo溢出提权漏洞（CVE-2021-3156）

漏洞说明

sudo是linux系统管理指令，是允许系统管理员让普通用户执行一些或者全部的root命令的一个工具，如**halt、reboot、su**等等。这样不仅减少了root用户的登录 和管理时间，同样也提高了安全性。sudo不是对shell的一个代替，它是面向每个命令的。2021年01月26日，**sudo**被披露存在一个基于堆的缓冲区溢出漏洞（CVE-2021-3156，该漏洞被命名为“Baron Samedit”），可导致本地权限提升。当在类Unix的操作系统上执行命令时，非root用户可以使用sudo命令来以root用户身份执行命令。由于sudo错误地在参数中转义了反斜杠导致堆缓冲区溢出，从而允许任何本地用户（无论是否在sudoers文件中）获得root权限，无需进行身份验证，且攻击者不需要知道用户密码。

2

●

漏洞影响范围

  

sudo 1.8.2 - 1.8.31p2

sudo 1.9.0 - 1.9.5p1

漏洞利用

  

（1）登录一个非root用户，查看sudo版本。

 

![](../Images/591c9e20d15ceeb7bf1a481633be3849.png)

![](../Images/d8e8da22e8b7d6b970ad6175659e12e4.png)

  

 

（2）获取github上的exp进行漏洞利用

执行指令wget

压缩包下载完成后解压。

![](../Images/832e0c96878df3f15248c4394df66108.png)

   

进入解压目录并编译。

执行指令：

cd CVE-2021-3156-main/

make

![](../Images/caed4f0f3a1a0f18e1d678331bb34a67.png)

   

执行指令，执行红框选中的文件。

./sudo-hax-me-a-sandwich ubuntu

![](../Images/07735820ba5ff3e36ed43a275eb5452a.png)

   

可以看到用户被提权为root用户。

●

修复建议

目前官方已在sudo新版本1.9.5p2中修复了该漏洞，请受影响的用户尽快升级版本进行防护。
