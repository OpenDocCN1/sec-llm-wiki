  6. 执行nps脚本，根据环境的不同执行命令略有不同可以根据需求从下面命令中跳出自己可以执行的。

    不安装执行命令：
    nps
    ./nps
    nps start
    安装执行命令：
    ./nps install 如果使用./nps install安装的方法执行脚本的话，在配置文件所配置的信息无法进行二次更改，也就是当你安装过之后再去修改nps的配置文件那也不会生效，你使用的配置信息还是第一次配置的。安装过之后的执行方法为./nps start。
    ./nps start

    这里简单说明一下安装和不安装执行的好处和坏处：不安装执行nps服务器好处是可以随时更改配置信息，坏处是，执行过程的日志信息会打印到控制台。安装的好处是，执行nps服务器回在后台运行，日志信息也不会打印到控制台，坏处是，配置信息不能更改。

    如果是使用安装方法执行nps的，它的安装文件的位置在：
    /bin/nps
    /bin/nps-update
    /etc/nps

    安装后执行的日志信息保存在：
    /var/log/nps.log

nps的作用

简单说明一下nps的作用，作为一款代理工具，其作用肯定是代理流量，我们在渗透测试的过程中，拿到边缘网站权限之后想要进一步扩大战果就必须要进行内网渗透，而我们正常情况下访问不到目标内网只能通过打下的外网主机作为跳板去访问内网，而跳板机的环境并不适合我们进行渗透，这时我们使用nps将内网流量代理出来在我们的攻击机上就可以访问到内网这样我们就可以大展身手。

最后说几点注意事项：

  1. 配置服务器和客户端的过程中由于端口比较多所以尽量把每个端口的作用写下来这样配置客户端的时候就不会写错了

  2. 在执行客户端命令时日志信息会直接打印到控制窗口，建议使用后台运行方法 

    1.windows在命令前面加上start /b 命令在后台运行
    2.Linux  在命令后面加 &
    3.可以使用npc.exe -server= -vkey= -type=tcp >> 1.log将日志信息保存而不是输出到控制面板

  3. 最后一定要注意所使用的是哪个版本的别搞混了我就是在Linux上使用arm的客户端一直执行不了命令  应该使用amd版本的
