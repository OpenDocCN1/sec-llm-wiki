# frp搭建及使用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzMzEwNzIzNQ==&mid=2247494365&idx=2&sn=2552492388c1092b11424124fee25cad&chksm=c2532991f524a08710f3232b4c2649a690f827aed79d0b52a6f5fa56617eff7e6d7f974b9e61&scene=126&sessionid=1681449444#rd](http://mp.weixin.qq.com/s?__biz=MzkzMzEwNzIzNQ==&mid=2247494365&idx=2&sn=2552492388c1092b11424124fee25cad&chksm=c2532991f524a08710f3232b4c2649a690f827aed79d0b52a6f5fa56617eff7e6d7f974b9e61&scene=126&sessionid=1681449444#rd)

  

1.  下载
    
    ```
    https://github.com/fatedier/frp
    ```
    
2.  将frp上传到vps
    
    ![](../Images/59adf5c96abc72d363bdbcb404155bad.png)
    
3.  配置frp服务器配置文件frps.ini
    
    配置完成后保存退出
    
    ![](../Images/47e0aba167affb95c2f4dc9a3b23a978.png)
    
4.  开启服务，记得给frps添加执行权限
    
    ```
    ./frps -c frps.ini
    ```
    
5.  访问frp管理网页
    
    ```
    url:公网ip:7500(dashboard\_port)
    用户名/密码：dashboard\_user/dashboard\_pwd
    ```
    
    ![](../Images/92091f7f42dcc557cbd1e2cfc67833af.png)
    
    ![](../Images/a6570f3302b36c64086d08e236221672.png)
    
6.  客户端配置，客户端frpc.ini配置信息 ，所有的代理协议在frpc\_full.ini中都有例子说明，可以自行配置，如果要代理内网的某个网站的时候需要vps有域名（custom\_domains）所以本次实验没有配置后续的代理。
    
7.  客户端执行命令
    
    ```
    frpc -c frpc.ini
    ```
