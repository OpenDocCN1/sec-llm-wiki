安装教程

git clone https://gitee.com/windyjxx/ScanTools.gitpip3 install -r requirements.txtpython3 scan.pyinst # 安装脚本运行库文件

使用

第一次使用脚本请运行scan.py后执行inst自动安装插件运行库。

使用命令

命令

用法

help *

将*替换为命令可查看命令帮助

info

调用tig获取IP信息

inst

安装脚本运行库文件

clear

清屏命令

finger

调用finger脚本对资产进行探测指纹信息

apkscan

提取APK文件内的url地址

pocscan

当前支持致远、泛微综合漏洞扫描及批量扫描

dirscan

调用dirsearch脚本对资产进行敏感文件及文件目录扫描

portscan

对资产IP或域名进行常见端口列表扫描
