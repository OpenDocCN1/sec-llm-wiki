**安装**

    首先我的电脑里面安装了Java14，现在来添加一个Java8，下载Java8，是一个dmg文件，直接双击安装即可。

```
#javaexport JAVA_14_HOME=/Library/Java/JavaVirtualMachines/jdk-14.0.1.jdk/Contents/Homeexport JAVA_8_HOME=/Library/Java/JavaVirtualMachines/jdk1.8.0_241.jdk/Contents/Home
# 默认为JDK14JAVA_HOME=$JAVA_14_HOME
alias jdk14="export JAVA_HOME=$JAVA_14_HOME"alias jdk8="export JAVA_HOME=$JAVA_8_HOME"
```

**直接终端输入jdk8或者jdk14切换即可(关闭终端后恢复默认jdk14)**
