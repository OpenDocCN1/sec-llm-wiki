### **微信小助手**

在终端内使用以下命令即可安装成功！

```
1.  `sudo rm -r -f WeChatExtension-ForMac && git clone --depth=1 https://github.com/MustangYM/WeChatExtension-ForMac && cd WeChatExtension-ForMac/WeChatExtension/Rely && ./Install.sh && cd ~`
    
```

回车后输入Mac开机密码，然后会提示让你安装Git（你电脑如果没装的话根据提示安装即可），安装正常来说很快，但是不排除网络很差...比如我！![](../Images/952e124551ea72aa3c55e4a2a9ae3773.png)等待安装成功后启动微信即可在菜单看到“微信小助手”![](../Images/8733cbd073958ceb897ffc66c0378dda.png)

### 终端环境配置

### **终端美化**

该说不说自带的终端界面真的丑到爆了！![](../Images/b7d52dcb59be7c2683694398e4bc1146.png)在网上找了很多的美化教程但是感觉不如人意，所以把我自己研究的方法写出来。使用终端代理进行安装“zsh”：

```
1.  `sh -c "$(curl -fsSL https://raw.githubusercontent.com/robbyrussell/oh-my-zsh/master/tools/install.sh)"`
    
```

安装完成后点击菜单栏左上角 终端-偏好设置，然后根据下图设置：![](../Images/a1358e8abcc281bec8f09047f0298c24.png)设置完成后重新打开终端就是这个样子的：![](../Images/dd2df3af4a807b3111a37abbeb9a165f.png)然后安装powerlevel10k：

```
1.  `git clone https://github.com/romkatv/powerlevel10k.git $ZSH_CUSTOM/themes/powerlevel10k`
    
2.  
    
3.  `set ZSH_THEME=powerlevel10k/powerlevel10k in your ~/.zshrc.`
    
```

完成后重新打开终端发现乱码：![](../Images/1c39fb38c2aab2a11644b1b65182963a.png)这个时候我们去安装字体即可：https://www.nerdfonts.com/font-downloads 找到这个点击Download 下载即可![](../Images/3a1ee2b62dceca449892654e6df3c567.png)下载后解压出来，然后安装 “Hack Bold Nerd Font Complete Mono” 字体。安装字体完成后设置一下终端的字体即可。![](../Images/50d70a934d86ba8893a541239c8bc3d1.png)重新打开终端![](../Images/733e65a0254822287cf5dfabc7294c0d.png)我的插件列表，建议百度搜索名字查看使用方法！

```
1.  `plugins=(`
    
2.  `    git`
    
3.  `    zsh-autosuggestions`
    
4.  `    extract`
    
5.  `    hitokoto`
    
6.  `    zsh_reload`
    
7.  `    z`
    
8.  `    safe-paste`
    
9.  `    colored-man-pages`
    
10.  `    sudo`
     
11.  `    zsh-syntax-highlighting`
     
12.  `)`
     
```
