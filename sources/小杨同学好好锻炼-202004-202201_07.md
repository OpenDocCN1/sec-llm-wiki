拖入ida:

add函数分别可以申请size <= 0xF0 和 size <= 0x1E0大小的chunk.

  

edit函数含有off by null漏洞

![](../Images/d86debc79f93891a6a784ea75c00c656.png)

 

这题的思路是

首先将同样的大小的chunk放入 tcachebins中，然后再free一个进入unsigned bin即可，方便后面leak libc\_base

利用off by null 漏洞去构造 unsined chunk 前向合并，从而控制两个id执行同一个chunk.

然后利用fastbin攻击将\_\_free\_hook中的内容改为system,\_\_after\_morecore\_hook中写入"/bin/sh\\x00"

执行free函数即可getshell.

拖入ida:经典菜单题.

增 查 删 三个功能.

其中add函数中很容易可以看到存在堆溢出

  

![](../Images/c706304500d14a008251b0dae162c82d.png)

 

所以这题我们进行堆构造，使得后向合并，将合并的chunk放入unsigned bin中，这个时候再进行见到那的申请操作，便可以然后通过show函数得到libc\_base，从而控制两个id执行同一个chunk.

然后就和上题一样了，利用fastbin攻击将\_\_free\_hook中的内容改为system,\_\_after\_morecore\_hook中写入"/bin/sh\\x00"

执行free函数就可以getshell.
