# 大地导弹：印度第一款近程弹道导弹

本着知己知彼的原则，从本文开始，小火箭要对印度的多款导弹武器系统进行相关的介绍，并尽量对导弹进行全弹流场计算和弹道分析。本文是小火箭印度导弹系列文章的第一篇。  

  

![](../Images/92eb872ac7bd0fac25dba1a3e5e4675c.png)

在本文，小火箭要和大家共同探讨如下几个问题：  

  

1.  印度导弹武器系统相关的国防工业**体系**是何时建立的？
    
2.  印度首款弹道导弹是怎样**诞生**的？
    
3.  大地弹道导弹的**总体**设计情况是怎样的？
    
4.  大地弹道导弹有哪些**升级**改型？
    
5.  小火箭对大地弹道导弹的气动**计算**和弹道分析。
    

  

**体系**

  

印度国防工业科研机构体系建设的发轫可以追溯到上世纪50年代。1958年，印度成立了**国防研究与发展组织**。这是印度组建真正的航空航天与航海军事工业科研系统的开端。

  

在这之前，印度与大多数发展中国家类似，航空和航天的研究机构分属不同的集团，由遍布全国的数不清的零散研究所组成。  

  

![](../Images/5b5da26d600bebc2334c92930ed1fc30.png)

1958年，印度将当时国内所有能够算得上数的军工系统相关的科研单位和与之有较强关系的科学管理机构统统合并，成立了国防研究与发展组织，也就是我们如今能够经常在印度军事工业部门看到的**DRDO组织**。

  

![](../Images/458c827bdd29e432fff8905b3e4499b2.png)

上图为DRDO的标志。中间交叉的两根像是星球大战中的红色光剑的宝剑之上，是孔雀王朝著名君主阿育王在鹿野苑所立的阿育王柱的柱头装饰。这个柱头雕刻的是4只狮子站在基座上，各自面一个方向（变成二维的标志的时候，只能看到3只狮子）。

  

标志中，鸟的翅膀、齿轮、铁锚象征了科研机构为海陆空三军服务的宗旨。铁锚下方有一句梵语。小火箭查了一下，其含义是：

  

“**科学是力量之母**。”

  

DRDO（印度国防研究与发展组织）的总部位于新德里，主要负责印度国防工业装备的研发。

  

DRDO由印度科技研发生产委员会、印度科技发展机构、印度国防科学组织等多个大型科技与军事组织合并而成。合并后，原先零零散散的各路研究所、企业、政府机构等统一归口由印度国防部来管理。

  

  

![](../Images/277bfaa35e794cb9797604f80a7aa4d6.png)

经过几十年来的组建、发展与整合，如今的印度国防研究及发展组织管理着**52个**实验室。

  

这些实验室几乎涵盖了国防科技工业的所有领域：航海、地面装备、航天、航空、电子、生命科学、材料科学、指挥控制系统等。海陆空天电，看上去是一应俱全的。

  

DRDO组织目前有**2.5万**名工作人员，其中有**5000人**是科学家和工程师。

  

**诞生**

  

![](../Images/ae51c668ea3754fea7932d798b9b9f56.png)

首先掌握战略弹道导弹技术然后在此基础上发展运载火箭的思路对于工业技术基础较为薄弱而对卫星需求又极其迫切的印度来说并不合适。与**苏**、**美**、**中**这样的航天强国（或者是正在迈向航天强国的路上的国家）不同，印度航天事业的发展有着自己的特点：**他们没有先研发出运载火箭，而是首先造出了卫星**。

  

1963年，印度在顿巴建成了第一个火箭发射台，发射了印度的第一枚探空火箭（仅能亚轨道飞行，不能用来发射卫星）。**1975年4月19日，印度研制出了第一颗自己****的人造地球卫星，并借用苏联的火箭发射成功**。

  

![](../Images/629baa8d47c053ed83919af8811afde4.png)  

后来，印度有了自己的运载火箭。但是，长期以来，印度对于运载火箭的重视程度要远高于弹道导弹。这也就使得印度成了少有的运载火箭技术比弹道导弹技术更为先进的国家。上图为印度的PSLV运载火箭。这款火箭打过一箭104星还到过火星，详见小火箭的公号文章《[谁说三哥不行？印度火箭给中国公司发过卫星](http://mp.weixin.qq.com/s?__biz=MzI1NjAyMTg1NQ==&mid=2649492161&idx=1&sn=234cc32921df1c5ea2d6ae673faf9b35&scene=21#wechat_redirect)》。

  

1983年，印度突然觉得需要发展弹道导弹了。当年3月份，印度把导弹研究人才从空间研究机构中分离出来，专门组建了印度自己的导弹研究分部。

  

![](../Images/13a076e6d4411161df93870dff92cbdc.png)

同时，印度国防部给这个新成立的小部门提出了一系列要求。小火箭总结起来，就是研制和发展5款导弹：

  

第一，研制印度的首款**近程地地弹道导弹**。这就是普里特维计划。普里特维是音译，按意译来讲的话，就是“**大地**”；

  

第二，研制印度的首款**中远程地地弹道导弹**，也就是**烈火**计划；

  

第三，研制印度的首款**低空近程地对空导弹**，是为**特里舒尔**计划；

  

第四，研制印度的首款**中高空中远程地对空导弹**。这就是**阿卡什**计划；

第五，研制印度的首款**反坦克导弹**。此为**毒蛇**计划。

  

![](../Images/3a89b7ae6bdc3d87a2d986c10157ceed.png)  

1988年2月25日，大地近程弹道导弹研制成功。

  

印度为了能够发展出这样一款导弹，摆脱购买和仿制的发展模式，可谓是不遗余力。

  

![](../Images/86d43966e9a8973785dcff7964e2addd.png)

![](../Images/66a659a3d2bb21eef3e9baf78e9118af.png)

从人才的角度来说，在印度国防部和教育系统的共同努力下，从多所大学和研究所中认真遴选出来的具有导弹设计天赋的研究人员集中在印度第四大城市**海德拉巴**，享有印度能够提供的最好的科研待遇。

  

同时，7所高校、19个国防部旗下的研究所、21个军工企业也参与到了大地弹道导弹的攻关中。

  

涉及到该项目的科学家有**1000余人**。

  

从经费的角度来说，为了发展弹道导弹，印度不惜成本，大量投入。

  

在上世纪90年代之前，印度的导弹研制经费隐藏在空间技术发展的科学投入中，难以看出细节。但是，从1994年大地弹道导弹入役之后，我们还是能够看出印度为发展导弹技术而投入巨额资金的间接证据的。

  

![](../Images/3301ea7288005302b927277a5fca5108.png)

大地弹道导弹的入役和其他武器装备的发展使得印度在上世纪90年代的军费开支飙升。1995年2000年这5年时间，印度军费的年均增长率为**21.71%**。

  

在大地II型到大地III型导弹过渡的这段时间，仅2000年一年，印度的军费开支就高达**135亿**美元，较上一年增长了将近30%。这对于一个有将近一半的人口处于贫困或半贫困状态的国家来说，投入还是非常大的。

  

**设计**

  

![](../Images/92eb872ac7bd0fac25dba1a3e5e4675c.png)

大地I型近程弹道导弹，弹长**9.01米**，直径**1.10米**，全重**4.405吨**，能够将**1吨**重的弹头投掷到**150公里**的地方。大地I型近程弹道导弹的最小射程为**40公里**，最大射程为**150公里**，CEP为**10米到50米**之间。

  

![](../Images/d5ee3fc2f04d147651f995705c794cc5.png)

大地近程弹道导弹一开始研制的时候就考虑到了公路机动能力和一定的越野机动能力。早期的大地导弹使用一辆捷克8×8太脱拉卡车来作为运输-起竖-发射平台。

  

![](../Images/17b4938b6038ad97221b081f70e47703.png)

大地弹道导弹是少有的带有较大弹翼的弹道导弹。这方面有点儿像苏联上世纪60年代末研制的SS-21圣甲虫单级固体战术弹道导弹。

  

带有弹翼的弹道导弹可以飞出与传统弹道导弹不同的弹道。这个小火箭将在下文详述。

  

![](../Images/870d7e3193204dd2120a4e3e7b5482b5.png)  

大地I型弹道导弹是采用液体火箭发动机的单级导弹，使用两台喷管方向和推力大小可调的火箭发动机。

  

这导弹的尾焰颜色是不是也不太常见？

  

是的。从颜色来看，可以断定该导弹的燃料并没有采用四氧化二氮/偏二甲肼的配置。

  

不过，从发射现场的偏黄的红色烟雾来说，大地弹道导弹的氧化剂用的是发烟硝酸。如果考虑到作战使用的话，这种发烟硝酸会适量添加抑制剂。（很有可能是氢氟酸。）

  

但是，充当燃料的一定不是煤油，也不是肼类的物质。通过小火箭好友的帮助，小火箭找到了被印度军方称作G燃料的配方。

  

实际上，大地I型弹道导弹的燃料使用的是50%的二甲代苯胺与50%的三乙胺混合之后的产物。

  

![](../Images/5d9ed6abefe5ee49375dea85ce99dbc2.png)

长期关注小火箭的好友对二甲代苯胺应该有印象。而这个三乙胺其实也可以用作高能燃料的。（三乙胺还可以用作橡胶硫化促进剂、四氟乙烯的阻聚剂、表面活性剂、润湿剂、防腐剂及杀菌剂。）

  

从导弹4.4吨的发射质量和单级液体火箭发动机的燃料配置情况来看，小火箭认为大地I型弹道导弹是需要比较长的**准备时间**的。

  

估算了一下，我认为大地I型弹道导弹从接到作战指令和目标坐标到发射出去，这期间因调整制导控制系统、加注带有抑制剂的发烟硝酸、加注二甲代苯胺、三乙胺所需要花费的时间在**2个小时**以上。

  

**升级**

  

![](../Images/7c01e88bc38653017efabf39b9a500c4.png)

作为一款能够携带2万吨TNT当量核弹头的弹道导弹，大地I型的150公里射程显得有些尴尬。因此，在1995年大地I型弹道导弹入役后，增程型的大地II型弹道导弹也就在测试当中了。

  

![](../Images/1701d01b6689a42b747a367dbe7fa0fa.png)

![](../Images/818227a18f71ae069d9da17a825c9981.png)

大地II型导弹在总体设计上与大地I型导弹差别不大。不过，大地II型导弹的射程（250公里）要比大地I型（150公里）远得多。  

  

![](../Images/7478705bce1383f18902592d44680c7b.png)

大地II型弹道导弹的射程达到了250公里。这主要是因为大地II型导弹采用了较小的弹头（II型的弹头为500公斤的，I型的弹头是1000公斤的）。

  

另外，实际上，经过弹道计算，我们可以发现：如果**大地II型**采用比较好的制导控制算法，能够用好弹翼的滑翔作用的话，其射程能够轻松突破300公里，甚至可以达到**350公里**。

  

![](../Images/4640228544e4c588e808de2b89b4337e.png)

![](../Images/d9d3bfe04e2d43413c8965e0349698da.png)

大地II型弹道导弹1996年1月27日首次试射，2004年入役。

  

从导弹的尾焰和尾烟来看，大地II型弹道导弹依然采用了发烟硝酸+二甲代苯胺+三乙胺燃料。

  

**上舰**

  

![](../Images/c81c9c1df19216e57a0f5ad4395eed93.png)

印度科研人员有这么一个特殊本领：总是会用一种独特的创造力突然一下子就惊到大家。

  

比如，基于大地系列弹道导弹改进而来的导弹在水面舰艇上发射的试验，实在是令人印象深刻。

  

![](../Images/89be21ee7089f822eccc4e51f9ddb1eb.png)

这是印度海军的P51苏巴德拉号巡逻船。注意其后甲板上矗立的一枚弹道导弹。该导弹虽然长得像大地导弹，但是已经有了新的名字：丹努什。  

  

![](../Images/d9a0236f6a89fe21a9f9e176a054bed8.png)

这是世界上少有的在水面舰艇上发射的弹道导弹。

  

![](../Images/f6203226fac04bbd26e95c0b52f65fb4.png)

是不是只是为了拿一个水面舰艇发射的名头，测试一下子就结束了呢？  

  

并不是。据小火箭统计，印度海军至少进行了4次海上发射试验：分别在2012年10月5日、2013年11月23日、2015年4月9日和2015年11月24日。这不得不让我们认为，印度这么干是认真的。

  

**计算**

**![](../Images/c7fa66100debf01dee53a216e2f0d2d2.png)**

![](../Images/02dfd886208c4f210a66b450498c51c2.png)

小火箭启动小火箭计算中心，用了些时间，对大地弹道导弹进行了全弹流场计算。

  

![](../Images/4da350514cf4ec4237ea0406df106654.png)

大地近程弹道导弹标志性的4片削尖三角翼对全弹的空气动力特性有着显著的影响。对于一款弹道导弹而言，这样的影响足以使其飞出采用传统气动布局的弹道导弹不同的弹道了。

  

![](../Images/5c6a7e528fd32bb1ab54264d16d389c9.png)

![](../Images/e291c86ddf8df68f3f4d897a15d20adf.png)  

小火箭对大地II型弹道导弹的弹道进行了计算：

  

![](../Images/d5d47295abe77a21136a5a4994f54ff9.png)

与传统弹道导弹的“抛物线”（实际上是椭圆的一部分，只是长得像抛物线而已）不同。大地弹道导弹在再入稠密大气的时候，因为较大面积的弹翼的影响，导弹可以“拉起”一定的角度，从而形成略有滑翔感觉的一段末段弹道。  

  

另外，从提高打击效能的角度来分析，大地弹道导弹在末段比较优化的弹道倾角为80°。
