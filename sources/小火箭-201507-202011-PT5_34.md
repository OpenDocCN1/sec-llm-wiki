# 世界最大的飞机下线：重燃空中发射火箭热情

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NjAyMTg1NQ==&mid=2649496610&idx=1&sn=2793e2f2569dd72f7db34142192bc325&chksm=f235b812c54231040cd9e75a55b85cba5115139b6cc2d2029f1c47f2f4c89bef66c03fde2c58&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NjAyMTg1NQ==&mid=2649496610&idx=1&sn=2793e2f2569dd72f7db34142192bc325&chksm=f235b812c54231040cd9e75a55b85cba5115139b6cc2d2029f1c47f2f4c89bef66c03fde2c58&scene=27#wechat_redirect)

2017年5月31日，业内人士期盼很久的“同温层发射系统”的载机终于在美国莫哈维沙漠的航空航天基地下线了。作为空中发射运载火箭的载机，她必须能够具备强大的载重能力，这使得该机拥有了目前世界上最长的翼展（117米）。从这个角度来说，刚刚下线的这架飞机成为了世界上最大的飞机。  

  

![](../Images/a706e409dd72cb4dcd80eaae320a6180.png)

  

小火箭在本文要与大家一起讨论如下几个问题：

1.  同温层发射系统载机的**总体**设计情况；
    
2.  该载机在研制过程中有哪些**有趣**的地方；
    
3.  同温层发射系统的发射**过程**是怎样的；
    
4.  空中发射火箭相对于陆上发射有什么**优势**；
    
5.  空中发射火箭需要解决哪些关键**技术**；
    
6.  同温层发射系统载机下线**视频**与发射过程模拟。
    

  

**总体**

  

![](../Images/3aeedfe8e1029aaeba7307d2930c4939.png)

该机的厂内编号为Model 351，我们不妨在本文把她叫做**M351**号。该机翼展**117.349米**，机长**73.1米**。整机重量为**589.67吨**，可携带**230吨**重的发射载荷飞行**3704.1公里**。

  

![](../Images/845eff65f3c2371f83b14a886c375883.png)

该机的总设计师是**伯特·鲁坦**。他是美国加州理工大学航空工程学专业毕业的。现年74岁的鲁坦做出过不少有趣的设计。  

  

![](../Images/e9b43a8b8ab9662ad768fa3c9b3ca81e.png)

上图是美国国家航空航天博物馆的大厅内悬吊的3架飞行器。能够在这里展示的飞行器代表着她们背后都有着传奇的故事和炫目的荣耀。中间这架大白就是伯特·鲁坦设计的**太空船1号**。

  

这是人类首架由民营企业研制的能够载多人多次往返天地间的空天飞行器，荣获了安萨里X大奖。（有关该大奖，详见小火箭的公号文章《[重赏之下：盘点人类太空探索各项大奖](http://mp.weixin.qq.com/s?__biz=MzI1NjAyMTg1NQ==&mid=2649496233&idx=1&sn=e25eabcd079f45295d96d93f81264787&chksm=f235be99c542378f7bbc1b6726b9427683611815efe57e22617f1863388095518e22eadaf273&scene=21#wechat_redirect)》）另外，小火箭多说两句：上图左侧那架飞机是查尔斯·林白当年驾驶她完成人类首次横跨大西洋的不间断飞行的**“圣路易斯精神”号**，右侧则是完成人类首次超声速飞行的**贝尔X-1**飞行器。  

  

![](../Images/4245eb84751b8eb482cd89641c19ced9.png)

伯特·鲁坦设计的太空船1号

  

![](../Images/4133a4b0e1f60363ae2ac8185627a9f0.png)

![](../Images/d565c4c0cffadbe4d6c926096fc6ccef.png)

伯特·鲁坦设计的白色骑士2号  

  

![](../Images/9fcbd0aea1e0ff8c12b775c0748f0b94.png)

在追求大载重、远航程，另外还得漂亮的设计理念下，鲁坦的M351延续了他一贯的设计风格（尤其是与白色骑士2号有大量的相似之处）。

  

![](../Images/8b7db071172fb09b2fd17a11ad9e8730.png)

整机大量应用复合材料，而且大胆进行结构减重。  

  

**有趣**

  

作为一款空射火箭的载机，而且无论是设计师的履历还是下线后该机的样子，总是让人想到“高大上”这个单词。但是，实际上，这是一架攒（cuan）出来的飞机。

  

![](../Images/78f6b7c73313ed838b4c791e3bc4523b.png)

M351下线的场景：洁白的机体，巨大的厂房，宽广的大门。  

  

![](../Images/a33ff592c929f2c04c4c8696b5c67cf1.png)

M351共有28个机轮：前起落架2个，主起落架分为6组（左右两侧各3组），每组4个机轮。

在莫哈维航空航天基地的工程师们目睹M351下线。小火箭和大家一起认出了该机的起落架实际上来自于波音747之后，大家是不是看到该机的发动机也觉得眼熟了？

每架波音747拥有4台PW4056发动机，而每架M351需要6台。那么，在这个节日里，小火箭问，需要拆多少架波音747才能满足1架M351的需要呢？

  

答：取整数，为2架。

  

![](../Images/7d1d589636a2da2f51ceb7010e127df7.png)

**优势**

  

空中发射火箭的优势主要有2个：

  

一是火箭本身拥有了一定的速度和高度，能够以较少的燃料将载荷送入太空；

  

二是火箭在同温层发射，其发射时机基本上不再受天气情况的影响。而载机飞到公海上空时，其一级落区可以不影响陆上居民，火箭对射向的选择也比较自由。

  

**关键技术**

  

空中发射火箭的关键技术，本文先说三个主要的：

  

一是火箭（或洲际弹道导弹）的惯性导航系统在发射时已经随着载机这个动平台飞行了一段时间，需要有专门的陀螺对准算法来保证制导控制系统对位置和速度判断的准确性；

  

二是火箭（或洲际弹道导弹）与载机分离的时候，要避免与载机发生相撞事故；

  

三是要有载重量足够的大型载机，才能为运载火箭提供够用的空中平台。
