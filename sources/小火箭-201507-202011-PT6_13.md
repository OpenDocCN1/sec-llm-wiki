# 那天，一架轰炸机撞入了纽约帝国大厦

有关飞机撞击大楼的事件，大部分人的第一印象或许是911事件中，轰然倒塌的纽约世界贸易中心双子座大厦。实际上，在第二次世界大战期间，位于纽约市曼哈顿第五大道的地标建筑“帝国大厦”也遭受过飞机的撞击。那次撞击引发了一场令人印象极为深刻的大火。这一撞，让高层建筑的设计标准中增添了一项至今仍起着重要作用的规范，同时也诞生了一项影响较为深远的法案。

  

**1.大雾**  

  

![](../Images/78a635a58afd4a3ec6c26c15d24367f1.png)

1945年7月，二战末期，日本海军仅存的几艘大型战舰，基本上都集中在**吴海军基地**附近。由于燃料短缺，它们被用来作为高射炮平台使用。

**1945年7月28日**，第二次世界大战进入收尾阶段。美国海军与英国皇家海军的舰载机对日本海军残存的大型舰只进行轰炸，以便进一步提高士气并报复在1941年12月发生的偷袭珍珠港事件，同时阻止日本利用其舰队作为谈判筹码。

  

上图为7月28日当日，吴海军基地的日军战舰**榛名号**（金刚级战列舰的3号舰）正受到攻击的场景。

  

![](../Images/ef569ddbd1ecb9d52f132b2e0c4a22d1.png)

而在大西洋一侧的英国，1945年7月份的大选刚刚结束，温斯顿·丘吉尔意外落选。他引用了古希腊作家普鲁塔克的话说：“**对他们的伟大人物忘恩负义，是伟大民族的标志。**”然后，卸任了英国首相的职务。

  

![](../Images/18283fe131c4076bbd7e2069826414f7.png)

**1945年7月28日**当天，大西洋另一侧的**纽约**，则显得格外宁静。浓浓的大雾包裹着纽约市林立的高楼。

**没有战争硝烟，也没有大选的喧嚣，这个周六或许会和往常一样，在报纸的油墨香与或浓或淡的咖啡香气中，缓慢而美好地流逝**。  

  

![](../Images/bd9d56ade7e453aca745b2df23aaa828.png)

当日，飞行员小威廉·富兰克林·史密斯驾驶一架**B-25**米歇尔型双发轰炸机执行常规的人员转移任务。飞机从马萨诸塞州的汉斯科姆机场起飞，计划飞往拉瓜迪亚机场。

  

![](../Images/68f74ac58b651430b7e0b85133d6f5ac.png)

27岁的小威廉·富兰克林·史密斯在当时是一位小有名气的飞行员。他在1942年毕业于**西点军校**。在第二次世界大战期间，史密斯于欧洲战场服役，积累了上千小时的战斗飞行经验。

  

史密斯身体很棒，曾入选全美曲棍球队。在战场上，史密斯的高超驾驶技术经受住了考验，在1年多的战争生涯中，史密斯**从未损失过1架飞机**，总是能够安全地把飞机带回基地。

  

除了2名机组人员外，机上还有一位搭机回家探亲的名叫**阿尔伯特**的士兵。他准备去纽约探视他的母亲。他有一个弟弟，上周刚刚在太平洋战争中因伤势过重牺牲。阿尔伯特此次请假回家，就是为了安慰他的母亲。

  

担心出事情的母亲在前一天刚刚给阿尔伯特派发了电报，让他坐民航班机回家而不要乘坐军用飞机。但是因假期短暂，归心似箭的阿尔伯特最终还是选择了搭乘B-25轰炸机回家。

  

**2.撞击**

  

![](../Images/74bef1aa0d65323b8951dbd9c24fd3c5.png)

**1945年7月28日上午9点30分**，飞行员史密斯感觉不妙：纽约上空的大雾实在是太浓了，在空中根本无法辨认方向。他开始联系拉瓜迪亚机场塔台。

  

塔台给出的回复是：大雾太浓，局部地区能见度不足50米，不适合任何航空器起降，建议史密斯降落在离这里有一段距离、起降条件相对较好的纽瓦克机场。  

  

身经百战的史密斯降低了B-25的飞行高度，以便努力寻找到可以确认方位的地标。而没想到的是，拉瓜迪亚机场塔台的那句

  

“**史密斯，你可得小心点儿飞行！我们在这里连帝国大厦的楼顶都看不见！**”

  

竟然**一语成谶**。

  

![](../Images/3b3a65f1f973c06a6af769b5998f03c2.png)

史密斯驾驶B-25轰炸机在纽约的楼群上空飞行，他小心地避开了克莱斯勒大厦。

  

但是，当他右转飞行，准备穿过曼哈顿岛上空时，一个巨大的黑影猛然出现在他面前！那是帝国大厦！  

  

![](../Images/e7b359a0da4a9f1cb57cb020b14ab658.png)

飞行中的B-25轰炸机径直撞上了耸入云霄的帝国大厦！飞机撞上了帝国大厦北侧**78层和80层**之间，在大厦外墙撞出了一个**5.49米×6.11米**的大洞，机上的燃油瞬间引发了爆炸。

  

![](../Images/e5708f238b9872a4e94daffd07f2d2f0.png)

![](../Images/39b953994da493fe2285d8e5169dc717.png)

B-25的2台发动机，在撞击后，先后脱离机体，其中一台撞入帝国大厦的一架**电梯井**，沿着电梯井冒着火焰下坠。另外一台则**横扫**帝国大厦第79层的办公间，**连穿7层内墙**后，从另一侧外墙穿出，像一颗冒烟的陨石，落到帝国大厦脚下的建筑上。

  

![](../Images/807cc976c511351871d06b6d83f4f6e9.png)

这就是那台发动机砸穿的临近建筑的房顶。从这个洞向上可以看到帝国大厦的部分轮廓。

  

![](../Images/8077157c7a09794fb3ee11e0c28254ff.png)

小火箭画的B-25撞击帝国大厦示意图。  

  

**3.大火**

  

![](../Images/b7a396c859128fcbc7170a328c8cd546.png)

巨大的爆炸声和随之响起的震耳欲聋的消防警报立刻打破了周六上午的宁静。帝国大厦的78层、79层和80层冒出了浓烟。

  

![](../Images/6d110d800b7c98b1ad58ee6b1bd6d112.png)

随后，浓烟变为大火。而坠落到楼下的发动机也引发了大火。整栋大楼成了一支燃烧的火把。

  

**4.营救**

  

好在当时帝国大厦的商户不太多，而且在二战期间，时刻接受国防教育的民众没有看热闹的习惯，而是及时有序地疏散开了，没有造成更多伤害。更万幸的是，当时是周六上午，出来购物的人也不多。帝国大厦在工作日和周末下午，平均会有**5万人**，而此时，只有**1500人**在大厦中。

  

不过，不幸的是，当时79层有正在工作的人员。

  

据分析，在撞击瞬间，机上**3人**（机长**史密斯**、副驾驶**克里斯多夫**上士和搭乘飞机探亲的**阿尔伯特**）当场遇难。在帝国大厦79层工作的战争救济服务社和国家福利委员会办公室的人员出现了大量伤亡，其中**11人**当场遇难。

  

![](../Images/b7734aa36dbb0dec640f5b7a318253c6.png)

当时正在楼下享受假期的见习兵莫朗见状，立刻跑到附近的药店买了棉纱、绷带和镇痛药物，飞奔上楼。一路上，他救助了很多人。快跑到79层时，他发现了2名身受重伤的电梯女工。莫朗随即给她们进行了包扎。战争时期的密集训练让莫朗手法奇快。随后，他给她们注射了镇痛剂。

  

莫朗翻找女工随身的小包，找到了一支口红。他在她们的额头上用口红涂上了**大写字母“M”**。（这是美军医护人员的习惯做法，表示这名伤员已被注射过镇痛剂，以免后面赶到的医生进行重复注射。）  

  

![](../Images/b409157444ff5d65fb66c7ebc9f9e2fd.png)

在消防人员的努力奋斗下，大火在**40分钟内**被扑灭。帝国大厦的第79层，距离地面**300多米**。能够在这个高度控制如此规模的大火，这创造了人类历史上扑灭建筑火灾的高度纪录。

  

火势得到控制，一是得益于消防人员的专业和勇敢；二是得益于当时B-25轰炸机是飞行末段准备降落的阶段，机内燃油剩余量已经不多。

  

![](../Images/9b64d71fce94db52b43a0af1a8289c05.png)

街头的大火在人们的努力下也被扑灭了，只剩下B-25轰炸机的残骸留待处理。

  

![](../Images/cbd7f875b9e450edecd5e00f23a9163f.png)

小火箭觉得这里要特别提出的还有另外一位电梯女工。这位叫**奥利弗**的**20岁**的**电梯女工**前几天刚刚向经理提交了辞职信，下周她就可以不必在这里工作了。但是，在周六她却遭遇了这场变故。

  

撞击发生时，她正在第80层的电梯里。B-25轰炸机就在她脚下的电梯井穿过。在撞击中，奥利弗的**脊椎、骨盆等多处受伤**。困在电梯中的她随后被大火吞噬。好在，消防队员及时赶到，将她的脊椎固定后，送到了另外一部电梯中。

  

但是，又一场变故突现！奥利弗听到一个奇怪的声音（那是这部电梯的线缆崩断的声音）。电梯的线缆受轰炸机**冲撞**和随后大火的**炙烤**之后，强度下降，随即**断裂**。

  

电梯女工奥利弗随电梯**从75层的高度迅速下坠**，“彷佛周围的空气都凝固了”。但是，万幸的是，先于轿厢坠地的线缆起了缓冲垫的作用，而且急速下坠的电梯轿厢压缩了电梯井内的空气，使轿厢的下降速度有所减缓。

  

奥利弗奇迹般地幸存了下来，并就此创造了当时的电梯坠落幸存世界纪录。（吉尼斯世界纪录官方组织给奥利弗确认的下坠高度为**300米**。）（1999年，奥利弗老太太安祥地去世，享年74岁）。

  

**5.大厦**

  

![](../Images/8ed796f0af78d135759ea0c6db38402f.png)

帝国大厦，楼高**381米**，有**103层**，是保持世界最高建筑地位最久的摩天大楼（**1931年-1972年**）。后来，帝国大厦在1951年增添了高**62米**的天线，使其总高度升至**443米**。

  

![](../Images/4e8a71a519f4f025db00c31e1cc4752c.png)

帝国大厦，位于美国纽约州纽约市曼哈顿第五大道350号、西33街与西34街之间，其名称源于纽约州的昵称──帝国州。

  

![](../Images/47a5730c70c8ee569285e63649317fc4.png)

![](../Images/2d3a4d93a662a2b0aa093aa7b7da0d23.png)

![](../Images/4c0a0c8c52c25016218740dc4d3bc071.png)

![](../Images/5dc32a15a4ee336b65bc234ac80eea38.png)  

![](../Images/d7097319513cae74d3d5b86d1fd50e35.png)

大楼于**1930年**动工，在**1931年**落成，建造仅用时**410天**，这是当时罕见的建造速度纪录。同时，考虑到安全问题，大厦的在结构设计过程中取了相当高的安全系数。

  

**6.修复**

  

在撞击发生时，帝国大厦经受住了考验。不过，日后的修复工作还是给工程师们提出了挑战。

  

B-25的大部分机体“嵌入”到了大厦的第79层，整体运出是不太可能了。在商讨了多种方案后，大家决定，用最干脆的方法：**上斧子**！  

  

![](../Images/111d4c16ffd86c75afc3b8ad62c5fba0.png)

大家抡起消防斧，将B-25轰炸机相对还算是完整的机体劈成几大块。

  

![](../Images/7e03935a88d28f67bf801337a6fe0c57.png)

蒙皮和桁架结构被分拆，便于运到楼下。  

  

![](../Images/98b7e3ab86d4da45fbfeaf22776355e9.png)

大楼内部的管线要进行重新检查。

  

![](../Images/26b3e31f0e051776dfa1a59ecffaf91a.png)

外墙的大洞则由建筑工人搭上脚手架进行修补。

  

战时的修复工作总是进行得很快。实际上，撞击事件后的第一个周一，大厦的低层办公区就恢复了日常工作。几周后，大厦几乎就恢复了原样。  

  

**7.法案**

  

![](../Images/f00f8afbbe956f30db2a6866231d535a.png)

帝国大厦第78层和第80层之间的那个**5.49米×6.11米**的大洞早已被修补，难觅踪迹。只有清洗大楼外墙的**蜘蛛人**还能够在第79层的墙壁上发现一些修补后遗留的蛛丝马迹。

  

不过，这次撞击事故的确还是给后人留下了一些东西。在大厦的修复和赔偿过程中，美国军方成为了需要为损失付出代价的一方。之前，美国奉行“主权豁免原则”，受行政行为侵害的人只能依据一些个别有关侵权赔偿的规定，寻求很少的一些赔偿。而帝国大厦的坚持，让美国通过了《联邦侵权赔偿法》。从此，现代侵权赔偿制度确立。**在赔偿老百姓的损失的时候，军队也不能例外**。

  

![](../Images/3dac51012817436b3b4f20378f6a80e7.png)

另外，当时的纽约市长**拉瓜迪亚**，本身也是在陆军航空队干过的（纽约三大机场之一拉瓜迪亚机场以他的名字命名）。他深知那些二十多岁的无所畏惧的飞行老手们想要在纽约炫耀飞行技能的欲望。因此，拉瓜迪亚下达了严厉的禁令，杜绝了**战斗机、轰炸机穿越大桥桥洞**和**运输机在楼宇间超低空穿行**之类事情的发生。  

  

**8.灯泡**

  

![](../Images/b6f09d18794e9c392cd6879140320c9b.png)

另外一个影响更为广泛和深远的事情，就是高层建筑从此开始普及楼顶的**航空障碍灯**了。

  

![](../Images/bc66c71362177ede1e0fbf5b9de629f7.png)

![](../Images/23a39d7c03da940a217d2d6c21322960.png)

![](../Images/02bc9164c2eb35d3e56554af20df7d79.png)

如今，不仅仅是高层建筑，超过一定高度的铁塔、塔吊等也需要设置航空障碍灯，以防出现飞行器碰撞事故。

  

**低于45米**的障碍物使用低光强航空障碍灯，分为A、B、C共3型，有红色、蓝色和黄色等多种规格；  

  

高于地面**45米至105米**之间的障碍物使用中光强航空障碍灯，有**白色闪光灯**、**红色闪光灯**和**红色恒定发光灯**3种类型；

  

比地面**高150米以上**的障碍物必须使用高光强航空障碍灯，通常为**白色闪光灯**。这些灯要么同时闪光，要么按照**中层-顶层-底层**的顺序闪光。

  

![](../Images/1697e5b5d46cb16ccf75fd19b0a0086f.png)

其实帝国大厦顶端在1932年美国总统大选时安装了一架探照灯，夜晚亮起时，方圆80公里的民众都能看到一束光柱。帝国大厦以此来宣告罗斯福成功当选新一届美国总统。不过在1945年的时候，正值白天，探照灯没有工作。  

  

自**1945年7月28日**的那次事故后，高层建筑顶端的航空障碍灯就成了标准配置了。

  

![](../Images/5d83963b7eee00f3c6c39a743ff7ede9.png)

1984年，帝国大厦顶端安装了自动变色灯，灯光的表现力变得更为丰富多彩。

  

![](../Images/06c58887745ebbcc51d5a6eba99f7a83.png)

![](../Images/55163c605e0c388290d07f713d247598.png)

![](../Images/1af77a9d273eef70db42df2460d19f87.png)

帝国大厦在每年圣诞期间亮起的圣诞彩灯。

  

![](../Images/d511a13df765e898ce788c94508a2eab.png)

从2001年开始，帝国大厦还会在每年春节和每年中国的国庆节期间点亮红黄两色彩灯。
