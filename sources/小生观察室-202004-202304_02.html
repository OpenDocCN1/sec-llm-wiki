功能介绍

  • 系统状态监控

  • 支持多用户多协议，网页可视化操作

  • 支持的协议：vmess、vless、trojan、shadowsocks、dokodemo-door、socks、http

  • 支持配置更多传输配置

  • 流量统计，限制流量，限制到期时间

  • 可自定义 xray 配置模板

  • 支持 https 访问面板（自备域名 + ssl 证书）

  • 支持一键SSL证书申请且自动续签

准备工作

  1. VPS一台,测试环境：Ubuntu 20.04.1 LTS

  2. 解析好的域名一个

免费域名+DNS解析过程，可参考小生观察室往期文章

红队必备技能之隐蔽的技巧

环境配置

更新及安装组件

apt update -y
apt-get upgrade -y
apt install curl socat -y

安装Acme脚本

curl https://get.acme.sh | sh



证书申请

设置解析后的域名、邮箱地址任意输入

~/.acme.sh/acme.sh --register-account -m xxxx@xxxx.com
~/.acme.sh/acme.sh --issue -d www.小生观察室.com --standalone


安装证书到指定文件夹

~/.acme.sh/acme.sh --installcert -d www.小生观察室.com --key-file /root/private.key --fullchain-file c

安装X-ui面板

一键自动化安装&升级

bash <(curl -Ls https://raw.githubusercontent.com/vaxilu/x-ui/master/install.sh)



注：如果是云主机，需要在防火墙处放行对应的端口!!!

通过浏览器以IP:端口的方式访问面板


在入站列表处点击+号新建账户


支持多种协议，可根据自身需求进行设置，此处以vmess协议为例，设置完成后点击添加


添加完成后，可点击二维码并通过v2ray客户端扫描进行使用


如果添加证书和密钥目录后仍然无法登录https页面，需要重启v2-ui面板

x-ui restart
