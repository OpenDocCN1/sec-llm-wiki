## 功能介绍

*   系统状态监控
    
*   支持多用户多协议，网页可视化操作
    
*   支持的协议：vmess、vless、trojan、shadowsocks、dokodemo-door、socks、http
    
*   支持配置更多传输配置
    
*   流量统计，限制流量，限制到期时间
    
*   可自定义 xray 配置模板
    
*   支持 https 访问面板（自备域名 + ssl 证书）
    
*   支持一键SSL证书申请且自动续签
    

## 准备工作

1.  VPS一台,测试环境：Ubuntu 20.04.1 LTS
    
2.  解析好的域名一个
    

免费域名+DNS解析过程，可参考小生观察室往期文章

## 环境配置

### 更新及安装组件

```


apt update -y
```

### 安装Acme脚本

```

curl https://get.acme.sh | sh
```

  

![](../Images/27cfd74b3df9350bdd5e65eb1697a7c4.png)

  

### 证书申请

设置解析后的域名、邮箱地址任意输入

```


~/.acme.sh/acme.sh --register-account -m xxxx@xxxx.com
```

  

![](../Images/ef2a81a5d78d49ce04a085f68972b20c.png)

### 安装证书到指定文件夹

```

~/.acme.sh/acme.sh --installcert -d www.小生观察室.com --key-file /root/private.key --fullchain-file c
```

## 安装X-ui面板

一键自动化安装&升级

```

bash <(curl -Ls https://raw.githubusercontent.com/vaxilu/x-ui/master/install.sh)
```

  

![](../Images/16ec23bce70eacd127cf1dd6fa3f6027.png)

  

**注：如果是云主机，需要在防火墙处放行对应的端口!!!**

通过浏览器以`IP:端口`的方式访问面板

![](../Images/4e7576b6037eb2e3e86a21bf29bde7da.png)

  

在`入站列表`处点击`+号`新建账户

![](../Images/3a205183b7f775111378e632d124aa13.png)

  

支持多种协议，可根据自身需求进行设置，此处以`vmess`协议为例，设置完成后点击`添加`

![](../Images/fa5bc9a61418d9ec3e94826b8f30d606.png)

  

`添加`完成后，可点击二维码并通过`v2ray客户端`扫描进行使用

![](../Images/3b33972867c955bc24477de3d97f550e.png)

  

如果添加`证书`和`密钥`目录后仍然无法登录https页面，需要重启v2-ui面板

```

x-ui restart
```
