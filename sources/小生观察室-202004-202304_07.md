## 简要说明

使用Winrar及去除广告原由

*   7zip等其他压缩软件存在解压报错或其他异常
*   每次打开Winrar都会弹出广告影响用户体验

## Winrar简介

  

WinRAR是一款功能强大的文件压缩解压缩工具

WinRAR位支持目前绝大多数的压缩文件格式，包括. ZIP、.RAR、.TAR.GZ和.LZH

支持强力压缩、分卷、加密和自解压模块，简单易用

主要功能：

*   WinRAR压缩率更高
    
*   对多媒体文件有独特的高压缩率算法
    
*   能完善地支持ZIP格式并且可以解压多种格式的压缩包
    
*   设置项目非常完善，并且可以定制界面
    
*   对受损压缩文件的修复能力极强
    
*   能建立多种方式的全中文界面的全功能（带密码）
    
*   辅助功能设置细致
    
*   压缩包可以锁
    

  

## 测试过程

### 安装Winrar

官网下载地址：

```

https://www.rarlab.com/download.htm
```

选择 `Chinese Simplified (64 bit)`

![](../Images/884c583417ba939236aea1b53ace9823.png)

  

### 评估版本字样去除

下载并安装，安装完成后，打开任意压缩包文件在最上方会出现`评估版本`的字样

![](../Images/2bb2673a8e6a9159ed6f0c972baa3728.png)

  

这时新建文件，设置文件名为`rarreg.key`，将以下内容复制至文件中

```

RAR registration datafor

 Education
```

将该文件放置`winrar安装目录`下

![](../Images/4fd0f43c1697fcd1930adc398c455589.png)

  

再次打开winrar压缩包文件后`评估版本`字样已消失

![](../Images/6c154dee2cd7cd60518eeacb61da4e5d.png)

  

### 去除Winrar弹窗广告

下载反编译工具`Resource Hacker`，项目地址如下

```
http://www.angusj.com/resourcehacker/#download

```

  

![](../Images/b545cb49090e65a9e906eb530d44e0bf.png)

  

下载安装完成后，利用`Resource Hacker`工具将`WinRAR安装目录`下的`WinRAR.exe`打开

![](../Images/67d133b9646bcd648dff233a69ea3740.png)

  

在左侧栏中依次选择`String Table`-->`80 : 2052`，删除`1277`行`引号内的内容`或`删除整行`

![](../Images/891da07ef0524aa76581cac61349d7ba.png)

  

小生观察室选择的是`删除整行`

`双击`选中内容并选中上方的`剪刀`图标

![](../Images/45539a486e93fe8b6f3b3ca38bc3e703.png)

  

再点击`运行`，运行完成后点击`保存`

![](../Images/bbfbcb392b8883fc3f801929b7b00902.png)

  

  

最后关闭`esource Hacker`，再打开任意压缩包文件，就会发现广告已去除成功

## 总结说明

1.  禁止通过winrar中国代理网站或第三方渠道进行下载，会出现反编译后依然出现广告的现象，推荐直接去官网下载
2.  根据操作系统版本进行选择，Windows可选择64bit
