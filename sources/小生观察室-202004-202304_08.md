## HelloWorld简介

HelloWorld是一个以用户最佳主观体验为导向的插件，它支持多种主流协议和多种自定义视频分流服务，拥有精美的操作界面，并配上直观的节点信息

```


项目地址：
```

### 插件介绍

*   基于 Lean ssrp 全新MOD的 Hello World ,在原插件的基础上做了一些优化用户操作体验的修改
*   节点列表支持国旗显示并且页面打开自动检测节点的连接时间
*   支持各种分流组合，并且可以自己编辑所有分流的域名，相当于七组自定义分流
*   底部状态栏：左边显示国旗地区以及IP,右边为四个站点的可访问状态，彩色为可访问，灰色为不能访问
*   优化了国旗匹配方法
*   建议搭配Argon主题，以达到最佳的显示效果

## HelloWorld配置

### 自建节点

小生观察室自建节点，所以这里直接`添加`节点

```

服务-->HelloWorld-->节点列表-->添加
```

  

![](../Images/35c2895592ad22eead358a6169cbc270.png)

  

1.  复制`节点链接`并点击`导入配置信息`，粘贴配置链接点击`确认`会自动导入相关配置

![](../Images/23e10e998d83352feb81a0327ef99a46.png)

  

![](../Images/14f5c3e90b132aead8298d249f628942.png)

  

导入完成后点击最下方的`保存&应用`

2.  返回`基本设置`，将主服务器修改为刚设置的节点信息，并点击`保存&应用`

![](../Images/0bf03be13979e824a9e76f056dec8528.png)

  

3.  当右下角`4个Logo`全部不为灰色既表示连接正常

![](../Images/23b12d8417bcada3d11d7c70a467d6d9.png)

  

### 机场节点

如果是机场节点只需要选择`订阅设置`，将`订阅地址`添加至`订阅URL地址`并点击`保存并开始订阅`

  

![](../Images/4235be283d582b1789038b6342cff077.png)

  

如果`Passwall`使用不太稳定的情况下可以考虑使用`Hello World`
