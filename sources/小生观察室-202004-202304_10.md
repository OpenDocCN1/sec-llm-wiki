## R2Cplus简介

*   NanoPi R2C Plus是一款实现满速率双千兆的、完全开源的Iot应用神器
    
*   NanoPi R2C Plus使用RK3328 CPU，有两个千兆网络，1G DDR4内存和8GB闪存，支持Docker CE, 完全开源，用于企业物联网二次开发，个人定制NAS，家庭物联网网关等
    

### NanoPi R2C Plus资源特性

*   CPU: Rockchip RK3328, Quad-core Cortex-A53
    
*   DDR4 RAM: 1GB
    
*   Flash: 8GB eMMC 5.1 Flash
    
    Network：
    

*   10/100/1000M以太网口 x 1
*   USB3.0转10/100/1000M以太网口 x 1

*   USB2.0 Host: Type-A x1
    
*   MicroSD Slot x 1
    
*   MicroUSB: 供电和Slave功能
    
*   Debug Serial Port: 3.3V TTL电平，3Pin 2.54mm间距排针
    
*   LED: LED x 3
    
*   KEY: KEY x 1 用户自定义功能
    
*   PC Size: 57.5 x 54.3mm
    
*   Power Supply: DC 5V/2A
    
*   Temperature measuring range: 0℃ to 80℃
    
*   OS/Software: U-boot，Ubuntu-Core，OpenWrt

### 第三方固件

因互联网上固件种类很多，而且对于新人来说并不具备独立编译固件的能力，建议使用第三方固件方便快捷

本次以`骷颅头`第三方固件做演示

```

项目地址：https://github.com/DHDAXCW/NanoPi-R2C-Plus
```

## 写入过程

1.  首先把R2C Plus断电，拿出TF卡，放入读卡器插入电脑

**如果电脑提示格式化！千万不要点击格式化！直接选择写入即可！不提示则忽略**

**若卡已经有系统，在Windows下或者Mac下装有系统的TF卡是无法被读取的**

**对于电脑没有盘符或者看不到盘符的情况不要慌张，不是卡坏了**

2.  利用`rufus`写入固件

```

rufus官网：https://rufus.ie/zh/
```

3.  打开`rufus`并将下载好的`骷颅头`固件导入至设备，并点击`开始`

**默认会识别TF卡（最上面会显示卡容量） 然后镜像文件后面点选择 选择下载的`.img文件`或`.gz文件`**

![](../Images/7e481b4879fc949cd370a0689d425234.png)

  

4.  当出现以下提示时，选择`确定`

![](../Images/36859e0948e6532cc7a33de3141c8934.png)

  

## 设置网络

1.  写卡结束后，拿出TF卡插入R2C Plus的TF卡槽并接上电源，直到`SYS`灯变为`常亮`为止

![](../Images/850803f8cf00e24917ebc484fd3a75aa.png)

  

2.  将一根网线的一端插入电脑端，另外一端插入R2C Plus的`LAN`口
    
3.  将以太网设置为`自动获取`，获取到正常IP地址为止
    

![](../Images/0f722b47480b33029c4ca90076d16ee5.png)

  

4.  在浏览器输入获取到的`默认网关`地址【此处为:192.168.2.1】，输入账户密码并登录

```


 默认账户为:root
```

  

![](../Images/d90993b5949f968bb6ab9ecb1c76a365.png)

  

### 网络环境

大部分网络环境可以归类如下情况

![](../Images/5f0066476dd320172c6c080720d7d4a5.png)

  

1.  小生观察室是把R2C Plus作为`主路由`进行使用，所以路线为

```

光猫 --> R2C Plus --> 交换机或无限路由器 --> PC/手机等设备
```

所以会涉及到在R2C Plus设置拨号

1.  将`光猫`网线的另一头插入`R2C Plus`的`WAN`口
2.  在后台选择`网络`-`接口`-`WAN`-`修改`

![](../Images/24cfe96d9bc346f5d6ea6dbd55ed0b19.png)

  

4.将默认`DHCP客户端`修改为`PPPoE`

![](../Images/1c490ea213f70f745e1210146cb8512f.png)

  

并选择`切换协议`

![](../Images/fd99485f367533fc989602dd3342ed3a.png)

  

分别输入`宽带账户`、`宽带密码`并点击`保存&应用`

![](../Images/815f98ed3177d459df2dcb1a44d0b8b4.png)

  

稍等片刻，如果`WAN`口有正常显示数据包说明已经拨号成功且可以连接互联网

![](../Images/ef24f1b45f2cdaab1f7eb7e589058235.png)

  

### 测速效果

1.  国内测速推荐使用`https://www.speedtest.cn/`，基本可以跑满带宽

![](../Images/ea1efaf68e3f47beade51a4c805d1e22.png)

  

2.  科学上网后，推荐以Youtube视频访问速度为准，而非speedtest.net为准，speedtest.net会出现以节点访问网站进行测速

### 其他说明

1.  光猫拨号的情况下，可直接将另一端插入R2C Plus`WAN`口无需在R2C Plus设置拨号
2.  如果需要扩展到其他设备，只需将R2C Plus`LAN`口与无线路由器或交换机的`WAN`口进行连接，并将`无线路由器或交换机`中的网络从`拨号`设置为`自动获取（动态获取IP）`或设置成`AP模式`、`桥接模式`都可以
3.  TF卡写入次数超过5-8次后可以使用`SD Card Formatter`清理TF卡之后再重新写卡

```


SD Card Formatte官网
```

4.  新写入的固件并不能`科学上网`，需要设置插件才可以，后续新写一篇内容进行详细说明
5.  如果系统出现异常导致无法正常进行后台，推荐重新写卡即可
