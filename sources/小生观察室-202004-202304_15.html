前言

  • 平时会在Youtube上下载一些视频进行学习
  • 网上也有很多网页版的接口但都不太稳定，会出现无法正常解析1080P视频的情况
  • 在YouTube下载视频，其他工具有时候会出现下载的并非1080P的视频，或者下载的视频只有画面没有声音

工具介绍

工具1

第一个要介绍的工具是youtube-dl

youtube-dl简介

Youtube-dl 是一款采用 Python 编写的免费、开源、命令行程序，可一次下载单个视频、多个视频或整个播放列表，且同时支持 GNU/Linux、macOS 和 Microsoft Windows 这三大主流操作系统平台。

官网地址：

https://youtube-dl.org/

访问并点击Download instructions

网站会跳转至该页面

http://ytdl-org.github.io/youtube-dl/download.html

根据自身操作系统类型进行下载【本机为Windows】

另外需要额外下载ffmpeg

官网地址：

https://ffmpeg.org/download.html

根据自身操作系统类型进行下载【本机为Windows】


如果是Windows系统，这里推荐选第二个https://github.com/BtbN/FFmpeg-Builds/releases

并选择ffmpeg-master-latest-win64-gpl.zip进行下载


使用方法

  • 将youtube-dl和ffmpeg放在同一个文件夹


  • 将D:\youtube-dl和D:\youtube-dl\ffmpeg\ffmpeg-master-latest-win64-gpl\bin添加至环境变量

工具2

第二个要介绍的工具是IDM

官网地址

https://www.internetdownloadmanager.com/

默认该软件是收费的，这里提供由俄罗斯大佬破解的版本

下载地址为：

https://kobefans.lanzoub.com/iLkBs00whvbc

安装说明

下载完成之后运行,选择第一个并点击Next


同意协议继续Next


选择安装路径继续Next


勾选此项继续Next


按照以下选项进行设置并继续Next


等待安装完毕并打开，默认是英文状态，可自行修改为中文,设置好之后会自动重启IDM



确认无误后,访问官网找到浏览器插件链接地址

https://www.internetdownloadmanager.com/



会跳转至chrome 网上应用店点击添加至Chrome


点击添加扩展程序


完成后会弹出官网说明，点击关闭即可

使用说明

打开Youtube上的任意视频，以下面的视频为例

https://www.youtube.com/watch?v=LP9oi6Drqh0

打开视频后会默认出现IDM浮窗，然后选择自己需要的1080P视频，点击下载


点击后会出现下载窗口，点击开始下载即可
