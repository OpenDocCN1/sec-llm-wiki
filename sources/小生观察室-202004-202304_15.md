## 前言

*   平时会在Youtube上下载一些视频进行学习
*   网上也有很多网页版的接口但都不太稳定，会出现无法正常解析1080P视频的情况
*   在YouTube下载视频，其他工具有时候会出现下载的并非1080P的视频，或者下载的视频只有画面没有声音

## 工具介绍

### 工具1

第一个要介绍的工具是`youtube-dl`

### youtube-dl简介

Youtube-dl 是一款采用 Python 编写的免费、开源、命令行程序，可一次下载单个视频、多个视频或整个播放列表，且同时支持 GNU/Linux、macOS 和 Microsoft Windows 这三大主流操作系统平台。

官网地址：

```

https://youtube-dl.org/
```

访问并点击`Download instructions`

![](../Images/433b0759a4f6e0f3e13b3f0b92fe2e4c.png)

网站会跳转至该页面

```

http://ytdl-org.github.io/youtube-dl/download.html
```

根据自身操作系统类型进行下载【本机为Windows】

![](../Images/a880e24facc3bcc2faa77016ef726ef3.png)

另外需要额外下载`ffmpeg`

官网地址：

```

https://ffmpeg.org/download.html
```

根据自身操作系统类型进行下载【本机为Windows】

![](../Images/64f7d5a6a91264a782a571c12ce0b5bc.png)

  

如果是`Windows系统`，这里推荐选第二个`https://github.com/BtbN/FFmpeg-Builds/releases`

并选择`ffmpeg-master-latest-win64-gpl.zip`进行下载

![](../Images/ce39fd72324163cb21833b24db0a9493.png)

  

### 使用方法

*   将`youtube-dl`和`ffmpeg`放在同一个文件夹

![](../Images/a819a1822277d6b512f7a9a8259d3715.png)

  

*   将`D:\youtube-dl`和`D:\youtube-dl\ffmpeg\ffmpeg-master-latest-win64-gpl\bin`添加至`环境变量`

![](../Images/607e466ea32f141b703c6f51a09d7189.png)

  

执行如下命令获取视频信息

```


youtube-dl.exe -F https://www.youtube.com/watch?v=LP9oi6Drqh0for

 LP9oi6Drqh0:
```

  

![](../Images/bf3ecb5da8d6de586841d5195899a105.png)

下载所需视频（含音频）

```


youtube-dl.exe --ignore-config -f 137+140 https://www.youtube.com/watch?v=LP9oi6Drqh0in

 05:34in
 01:25"cors _ 漏洞赏金之CORS _ CORS _ 跨源资源共享 _ what is cors _ 同源策略 _ 跨域 _ cors解决 _ Cross-origin resource sharing-LP9oi6Drqh0.mp4"


```

`137`表示`137 mp4 1920x1080 1080p 465k , mp4_dash container, avc1.640028@ 465k, 30fps, video only, 19.51MiB`

`140`表示`140 m4a audio only tiny 129k , m4a_dash container, mp4a.40.2@129k (44100Hz), 5.42MiB`

表示将视频及音频进行合并

![](../Images/57669bf4ac03cfb11110bd62e9da42f2.png)

  

下载完成之后即可在当前文件夹下看到视频内容

### 工具2

第二个要介绍的工具是`IDM`

官网地址

```

https://www.internetdownloadmanager.com/
```

默认该软件是收费的，这里提供由俄罗斯大佬破解的版本

下载地址为：

```

https://kobefans.lanzoub.com/iLkBs00whvbc
```

### 安装说明

下载完成之后运行,选择第一个并点击`Next`

![](../Images/c159e101272f8412fed2a658e2706d37.png)

  

同意协议继续`Next`

![](../Images/cf64f56cc43b05074cccbfdaa155d9cf.png)

  

选择安装路径继续`Next`

![](../Images/7d5d88363d68e1c5e7cbb6ab69b6542d.png)

  

勾选此项继续`Next`

![](../Images/0e62cc799188b053730e870c2e8e1593.png)

  

按照以下选项进行设置并继续`Next`

![](../Images/dc2b64ca8705fbd112be56864a1d830d.png)

  

等待安装完毕并打开，默认是`英文`状态，可自行修改为`中文`,设置好之后会自动重启`IDM`

![](../Images/6d86ffb1e84bac83b281750faf89cdc2.png)

  

![](../Images/17d64cd5131e3eb177c903cbd559b573.png)

  

确认无误后,访问官网找到浏览器插件链接地址

```

https://www.internetdownloadmanager.com/
```

  

![](../Images/e4379f59f9d4e682c3916be3789d228d.png)

  

会跳转至`chrome 网上应用店`点击`添加至Chrome`

![](../Images/eec7546443341db22c78c1c7450c6ab0.png)

  

点击`添加扩展程序`

![](../Images/ce8ff4972cd2c71cc62332946d1e8fb9.png)

  

完成后会弹出官网说明，点击关闭即可

### 使用说明

打开Youtube上的任意视频，以下面的视频为例

```

https://www.youtube.com/watch?v=LP9oi6Drqh0
```

打开视频后会默认出现`IDM浮窗`，然后选择自己需要的1080P视频，点击下载

![](../Images/f6f72a1ae9dddacd00c59167dc34a1bc.png)

  

点击后会出现下载窗口，点击`开始下载`即可

![](../Images/aac89d9b73786b2d57eb72eb6018520b.png)
