## JetBrains简介

JetBrains是一家捷克的软件开发公司，该公司位于捷克的布拉格

在俄罗斯的圣彼得堡及美国马萨诸塞州波士顿都设有办公室

该公司最为人所熟知的产品是Java编程语言开发撰写时所用的集成开发环境：IntelliJ IDEA

JetBrains公司旗下有下列的几种开发工具:

*   Intellij IDEA：用于开发 Java 等
*   WebStorm：用于开发 JavaScript、HTML5、CSS3 等前端技术
*   PyCharm：用于开发 Python
*   PhpStorm：用于开发 PHP
*   RubyMine：用于开发 Ruby / Rails
*   AppCode：用于开发 Objective-C / Swift
*   CLion：用于开发 C / C++
*   DataGrip：用于开发数据库和SQL
*   Rider：用于开发.NET
*   GoLand：用于开发Go

## 前言

*   最新版与之前的版本有什么区别？
    
    JetBrains 2021.2.2及之前，可以通过无限重置试用期补丁来实现永久使用
    
    2021.2.3版本开始Jetbrains强制用户必须登录账号，试用期与账号绑定在一起导致本地重置试用期的方式失效

> 此处以JetBrains\_Pycharm\_Windows为例，其他JetBrains系列的工具都可以这样操作。

## 安装Pycharm

从官网下载对应系统安装包

```
https://www.jetbrains.com/pycharm/download/#section=windows

```

![](../Images/35df396f79c6db6ec426bb3c04b83e1a.png)

设置安装路径

![](../Images/739bf7774bb133d2172496c57b481f1f.png)

勾选需要的选项

![](../Images/846f254e43bd7890d789c373fc4d441e.png)

安装完成后选择`稍后重启`并点击`完成`

![](../Images/4afcc9b0a27281e1959e61a490878a5d.png)

## 注册JetBrains账户

打开Pycharm后点击`Start Trial`并点击`Log In to JetBrains account...`

浏览器跳出新窗口，选择注册新账户并输入邮箱地址

![](../Images/8e661be705906f08c90b3d8acf91882f.png)

邮箱会收到注册链接，点击并注册

![](../Images/c7bb72d83ac489ef7141b5cedd05208d.png)

输入`姓名`、`用户名`、`密码`，完成注册后会自动登录到Pycharm

点击`Start Trial`

![](../Images/a9328368f34fda4e4005e8a60141df21.png)

但这样激活后的时间时有短期限制的，我们先选择`Remove License`删除激活码并`退出`Pycharm

![](../Images/e4f0c544863590084b255dd558556e93.png)

## 正式激活

永久激活工具下载地址：

```

https://kobefans.lanzouw.com/iC19vyrizti
```

工具下载到本地解压后将`ja-netfilter`文件夹复制到任意目录

当前我设置的路径为`C盘`

![](../Images/58be62ba005f5fe840c734e2caae449e.png)

打开并修改`pycharm64.exe.vmoptions`文件

默认路径在`bin`里面下

![](../Images/a10d7bfe7f417b240b1eb90ca4674809.png)

在最后一行添加如下内容:

```
-javaagent:C:\ja-netfilter\ja-netfilter.jar
```

保存`pycharm64.exe.vmoptions`文件并重启Pycharm就可以激活成功了

![](../Images/63d7fb58b788ffb4d93279c5304fe8a1.png)
