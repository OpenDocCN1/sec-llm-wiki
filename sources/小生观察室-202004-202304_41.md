## HTTP 盲攻击 简介

HTTP 盲攻击，凡是不直接使用传统的 HTTP Request、HTTP Response 中的已有数据进行的漏洞挖掘与分析的攻击方式，都可以称为 HTTP 盲攻击。

该攻击适用于一切难以发现传统意义漏洞的系统，也可用于对目标没有任何了解却希望快速发现高危漏洞，同时不必关心直接目标到底存不存在漏洞的一种攻击方式。

在特定情况下可以配合利用 OOB 方法为基础突破口可进行检测和利用漏洞的攻击方式。
