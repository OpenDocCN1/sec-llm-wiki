二：服务端配置

默认安装完成后，启用配置文件为/usr/local/etc/v1ray/config.json，但这个默认配置为空，因此需要自定义服务端配置。


{
    "inbounds": [
        {
            "port": 12345, 
            "protocol": "vmess",
            "settings": {
                "clients": [
                    {
                        "id": "88888888-1234-1234-1234-888888888888" //客户端自定义生成
                    }
                ]
            }
        }
    ],
    "outbounds": [
        {
            "protocol": "freedom"
        }
    ]
}
