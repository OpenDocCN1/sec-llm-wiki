> >

> >   

默认情况下，VMware无法直接新建MacOS系统的虚拟机，需要依赖`Unlocker for VMware`工具来解锁，才能够在VMware上跑MacOS系统

**VMware15及以下版本可使用此解锁器**

下载地址：https://github.com/paolo-projects/unlocker/releases

下载完成后，解压`unlocker.zip`文件，并选择`以管理员身份运行`打开`win-install.cmd`文件

![](../Images/e8a1c6415629b0725467126dc4afc95a.png)

**如果安装的是最新版VMware16，推荐使用以下自动解锁器**

 https://github.com/paolo-projects/auto-unlocker/releases

下载完成后，解压`Unlocker.zip`文件，并选择`以管理员身份运行`打开`Unlocker`文件

![](../Images/418243a04f0a7a0d8dc92e2b74a3f575.png)

运行后自动关闭服务及进程，开始解锁任务并下载相关文件【下载速度有别于当前网络延迟情况】

![](../Images/f1cf3e932ffe9678c0d716a3fc8b2d93.png)

**通过分析代码发现一种更快速下载的方式**

*   使用浏览器打开网址：http://softwareupdate.vmware.com/cds/vmw-desktop/fusion/ 选择列表中最大的版本

![](../Images/784a25ccc0f265a8d9a4ddfbd2ebcd55.png)

![](../Images/c078453cdf21de9ad676676172543951.png)

![](../Images/4d81a7580925bc01e84b11ec06df334f.png)

![](../Images/708423c6a4079a9a55f82156533ff924.png)

将`com.vmware.fusion.zip.tar`文件下载到本地

*   用7zip打开这个解压文件，把`darwin.iso`和`darwinPre15.iso`解压缩到Unlocker的`tools`目录下

> 运行Unlocker后会自动生成`tools`文件夹

![](../Images/46f5535acd1651904e2c6498e0b6c4c4.png)

*   再将`darwin.iso`和`darwinPre15.iso`文件复制到WMware的安装目录中，然后用管理员权限运行一下 Unlocker
*   运行后出现以下提示，默认选中`Y`即可

![](../Images/77aa661ce6ce365829cb57fc085833b1.png)

  

二：安装MacOS系统

  

在新建虚拟机时选择`Apple Mac OS X`并选择对应版本

![](../Images/8271db89f4582a3eefbc058ee421a51e.png)

设置完成之后选择`编辑虚拟机设置`并添加MacOS镜像文件，启动虚拟机

![](../Images/1ba5a81944c0e5b96e9e2e19c30a819e.png)

设置完语言后选择`磁盘工具`

![](../Images/06b2497c4832acf855a6608193221c75.png)

选择对应盘符并选择`抹掉`盘符内容及设置名称

![](../Images/9ab952d1b98252dcf4d9aec1e820af0b.png)

完成之后选择`安装macOS`

![](../Images/b4708c6d9659a73e42b2d2ea84992c37.png)

点击`继续`并同意协议，选择对应盘符开始安装

![](../Images/119247987f88b9d756a13e4379e3a7f0.png)

安装完成后选择对应地区

![](../Images/43252dc10d7b7a6fa00944819e274c1b.png)

创建用户名

![](../Images/a560e0a061918db47970bc54d782c88c.png)

全部完成后就正式进入桌面  

![](../Images/fbd22991966ab6991a375472c1832172.png)

  

三：安装VMware Tool

默认情况下分辨率是较低的需要进行调试

修改IOS镜像文件，选择VMware目录下的`darwinPre15.iso`文件

![](../Images/5dbcfd9c468a731171457c779b1c76a5.png)

先选择退出光盘

![](../Images/854bf3595fb112437b947c1eef295ba7.png)

然后选择安装VMware Tools

![](../Images/f4f549c1a44348e2cfea994033d3da26.png)

选择安装VMware Tools

![](../Images/93c3bb5d6ba8f0f1db6bf2b9fc92b405.png)

一直选择继续安装，在安全性和隐私中选择解锁并点击`允许`并选择`重启虚拟机`  

![](../Images/b19eb739c65311070a3a3f69524ea8a9.png)

![](../Images/40dfdb69b9c24da9c8423458125e2ad6.png)
