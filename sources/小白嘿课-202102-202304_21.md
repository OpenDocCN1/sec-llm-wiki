****| ******0x5**** arp-ping**

**Arp-ping 基于 arp 协议，它可以 “ping” 受防火墙保护的主机**

**由于 arp-ping 只能一次 ping 一台主机，但在测试过程中肯定不能一台一台的 ping ，所以这里参考上面的 ping 脚本写了一个 arp-ping 循环 ping 主机的脚本。**

*   

```

```

```
C:\Users\RCSTEAM>for /l %i in (1,1,255) do @arp-ping.exe 192.168.10.%i -w 1 -n 1|find /i "Reply"Reply that 16:7D:DA:D7:8F:64 is 192.168.10.1 in 2.233msReply that 00:0C:29:A9:62:98 is 192.168.10.107 in 16.857msReply that 00:0C:29:DC:01:0D is 192.168.10.110 in 0.205msReply that 00:0C:29:DC:01:0D is 192.168.10.255 in 0.200ms
```
