Awvs

一款知名的商业版漏洞扫描器

Docker安装Awvs14方法

查找awvs14镜像

docker search awvs14


拉取awvs14镜像

docker pull secfa/docker-awvs


创建容器

docker run -d -p 3443:3443 --name awvs14 secfa/docker-awvs


访问：

https://ip:3443账户：admin@admin.com/Admin123
