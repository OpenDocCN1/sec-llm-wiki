前言

    今天为什么要分享这篇文章呢？因为我今天部署的时候遇到了坑点！作为一个看github从来不看lessus的人，最容易遭遇类似的情况，所以我今天来分享这篇文章。
     Github Monitor是VIPKID安全中心自研的一款企业用于监控github源码泄露的工具，该系统可以实现主动、及时发现企业泄露的源码。


问题过程
环境

kali2020python3

Github Monitor项目地址：

https://github.com/VKSRC/Github-Monitor/


安装Github-Monitor(docker部署)
1、下载

git clone https://github.com/VKSRC/Github-Monitor.git


2、进入目录

cd Github-Monitor


3、修改配置文件.env.docker

将.env.docker 改为.env

mv .env.docker .env


4、通过docker-comse安装

docker-compose up -d


5、报错了

   看提示，似乎升级pip就可以了，但是实际情况并不是这样的，因为这里提示的pip版本低是指docker中的pip，而我们直接升级的是docker外面的pip，这种情况怎么办呢？


6、解决问题

     其实在项目的lessus中有答案，但是我没看，不过在fb的群聊里有大佬帮我解决了这个问题，接下来就一起来解决这个问题。
上面说过了，是因为docker内容的pip版本低导致的，那直接解决docker内部的pip版本就能解决了，关键是怎么解决docker内部的pip版本呢？一起来找到dockerfile这个文件并进行编辑：

   vim Dockerfile


修改哪里呢？，其实在报错提示中已经很明显了，找到install requirement模块添加我圈住的内容即可。


install requirementCOPY server/requirements.pip /requirement.txtRUN pip3 install --upgrade "pip < 21.0"RUN pip3 install -r /requirement.txt -i http://pypi.doubanio.com/simple --trusted-host pypi.doubanio.com --trusted-host pypi.doubanio.com


再次docker-composer up -d就能够成功了
