📸一句话理解📸

python变量通俗来说，就是一个标签，贴哪指哪。例如你会认为碗里装的是饭，油桶里装的是油，在这里可以将碗和油桶类比为变量，它们容易使人知道装着的是什么。


🏹核心源码🏹(敲正确源码=成功一半)

首先活动下手指，敲入以下代码:

message = "Hello Python world!"                            
print(message)   

消息=″你好 python世界"
打印(消息)

接着运行，输出结果为:

Hello Python world!

🎵源码分析🎵(敲而不思则罔)

1.message = "Hello Python world!"

在这里，我们创建了变量messge，并利用"="(等号)将右边"Hello Python world!"赋给左边的变量messge，也可以理解为:给右边贴上了标签即变量messge。


2.print(message)

print()为打印函数，负责把括号中的内容打印出来，而此时括号中内容为变量message，在1中变量message作为一个标签又贴给了 "Hello Python world!" 。众里寻他千百度🛶，最后输出为 "Hello Python world!" 。
