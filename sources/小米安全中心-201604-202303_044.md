6月29日、30日小米举办了第五届小米IoT安全峰会，峰会一直坚持着开放，透明的理念，邀请多位行业顶尖安全专家为大家呈现优秀的IoT安全与隐私实践，带动整个生态一同进步，提升全行业安全隐私保护水平。本次峰会共有14个精彩议题：

**一、开场致辞**

![](../Images/36023dcf6582e18fc80da6acb92bfb27.png)

**小米集团副总裁崔宝秋**在致辞中提到，小米自2012年成立信息安全团队以来距今刚好10年，这10年间小米有过无数个第一次。第一次拿到安全隐私认证，第一次发布MIUI安全隐私白皮书，第一次对外发布基线，第一次创立了小米隐私品牌，第一次获得了百万美金技术大奖等等，这些都是小米安全隐私关键的里程碑。

小米IoT安全峰会，从2017年第一次举办到今天，已经是第五届了，峰会一直坚持着开放、透明的理念，邀请行业大咖为大家呈现优秀的IoT安全实践，带动整个生态一同进步，提升全行业安全隐私保护水平。本次峰会我们也继续将小米的安全隐私工作实践开放给大家，相互促进共同成长。

![](../Images/faa02ba77e73e693fcd01d67847cbeaf.png)

正如大家感受到的那样，每一次MIUI的版本迭代，也都为用户带来新的安全隐私体验，比如大家耳熟能详的照明弹，拦截网，隐匿面具等等功能。自2019年发布第一版MIUI安全隐私白皮书以来，一直将小米安全隐私保护理念、隐私功能和技术防护措施跟随着MIUI版本的迭代而更新。本次峰会MIUI13安全白皮书和MIUI13隐私白皮书也全新上线！小米一直力求在安全隐私上，对用户透明，让用户更放心使用我们的产品。

大家也都熟悉小米的 ：“手机 x AIoT”双引擎战略，所以我们在做好手机安全隐私工作的同时，AIoT产品的安全隐私工作也一直没有放松。

![](../Images/37edaa44dde0689d857598893ffa3473.png)

除了过往通过的TrustArc隐私认证，以及ISO系列的安全隐私认证外，在基础设施安全方面，小米获得了NIST CSF 认证，在产品方面， 2021年，2022年我们也分别获得BSI、UL、莱茵为我们颁发了IoT产品安全认证，认证依照国际物联网安全标准（欧盟国标EN303645，消费物联网安全，也是目前全球认可度比较高的物联网安全标准）。

![](../Images/c5f2486bf18dff6579d81e02ec998a3e.png)

如前文所述，小米在安全隐私上所做的努力，核心目标都是为了提升安全隐私的透明度。我们越透明，用户越信任。小米希望可以通过不断的将安全隐私工作“透明”给用户来建立信任，过去10年小米安全隐私稳扎稳打，为用户智能美好新生活保驾护航，让我们一起期待，小米安全隐私的下一个10年！

# **二、《数据安全治理框架及落地实践》**

![](../Images/94b591b1d0196f08511e5fe28656969b.png)面对数据安全威胁日益严峻的态势，着力解决数据安全领域的突出问题，有效提升数据安全治理能力迫在眉睫。**中国信通院云计算与大数据研究所副主任李雪妮**在本次议题中从数据安全治理体系建设的角度，总结了当前数据安全工作的现状和趋势。

# **三、《全球数据跨境流动治理态势与应对》**

![](../Images/ca18e030d2915a1221091a47992698df.png)近些年，跨境数据流动正受到越来越多国家的重视，然而全球跨境数据流动的治理规则却变得日益复杂。**中国互联网协会研究中心副主任****吴沈括**在本次议题中为我们阐述了国内外数据跨境流动现行法律法规与监管要求，还为企业提出有关数据跨境流动的合规风控策略。

# **四、《小米 IoT 隐私合规实践及思考》**

![](../Images/e3afd39b48b4955aac2e437a6a90b42d.png)近些年国家不仅对数据跨境传输问题非常重视，对用户的隐私合规问题也高度重视，小米也一直将用户的信息安全和隐私保护视为生存之本，**小米隐私合规法务的黄著馨律师**在本次议题中分享了小米IoT隐私合规实践及思考，小米始终坚持提供给用户更加透明、更能维护个人信息权益的产品和服务。

# **五、《基于位置服务的个人信息保护思考》**

![](../Images/95b2c6ed72261b6a2e753985d0316f64.png)随着信息化的智能化程度不断提升，对个人信息和行为数据需求越发强烈，特别是基于位置服务为大家生活提供了诸多便利，但不法分子也瞅准“商机”，引发了位置或行踪轨迹泄露，侵犯用户利益等诸多问题。来自**快手的隐私保护负责人邵华总**在本次议题中从位置信息敏感度区分，信息收集，内部使用和保护，外部共享等环节给出的工程实践参考。

# **六、《践行用户隐私安全保护，应用商店实践与思考》**

![](../Images/85625345a7b0f92c561bf300315f98ed.png)近年来，互联网行业迅猛发展，越来愈多的应用被分发和使用。在行业发展的同时，也为行业乱象的滋生带来土壤，违规应用带来的影响日益明显，不断侵害用户的隐私和信息安全。**小米开发者生态高级运营经理杜文博**在本次议题中为我们分享小米应用商店作为小米手机内最主流的分发平台，是如何来践行用户隐私安全保护的。

# **七、《再论静态分析，以臻图灵之境》**

![](../Images/c9c19bcde6494a391a0ff942f5d8e0f8.png)静态程序分析是Android系统安全研究中常见的理念，但在漏洞挖掘实战中不同的算法、建模和实现却会导致截然不同的结果，带来最直接的问题：为什么TA的工具可以发现漏洞，而你的却没有扫出来/有误报？一种答案是，静态分析框架并不开箱即用，而需对内部的理论和算法有深入的了解并进行优化，才能更有效地发现隐藏的漏洞。**獬豸安全实验室负责人，高级总监flanker**在本次议题中分享相关实践，并结合所挖掘出的CVE案例和漏洞链，讨论一些关键的改进点。

# **八、《小米安全开发实践》**

![](../Images/8969a8b756d9f61f645792a358d8bd20.png)安全开发（Secure Development Lifecycle）可以帮助企业尽量将安全“左移”，减少后期安全缺陷修复的成本投入，**MIUI系统安全部负责人王宝林**在峰会上介绍小米集团不同业务形态，如手机和移动应用，IoT，Web和服务端，在落地实践SDL遇到了哪些困难，又是如何通过教育培训，组织建设，流程制度和技术工具相结合，解决的实际落地难点的。

# **九、《百度AIoT安全体系建设实践》**

![](../Images/dbe9c213bf747819f5dff46468bef7b7.png)随着万物互联时代的到来，智能设备迎来了指数级增长，百度作为AI能力的服务提供者，打造了DuerOS智能语音交互系统，以软硬一体的形式服务上亿用户。然而在行业欣欣向荣的背后，仍然面临巨大的风险及挑战。不同于传统安全，AIoT安全面临的碎片化严重，成本控制严格，也往往是用户隐私数据的第一处理者。如何在业务及安全之间找到平衡点，并在风险可控的前提下助力业务成长是百度AIoT安全建设的首要难点。**百度AIoT安全研究团队负责人夏良钊**在本次议题中从实际出发，介绍百度AIoT安全的保障体系框架，展示如何在产品生命周期和数据生命周期中全方位保护设备安全及用户隐私，介绍在AIoT供应链安全场景的风险闭环思路，真正帮助产品实现“做用户贴心可靠的助手”。

# **十、《工业边缘控制器脆弱性分析》**

![](../Images/17cfb86e94afb41b35b53274593b52d2.png)**IRTeam工控安全红队团队创始人剑思庭**针在本次议题中对工业互联网大潮下的工业边缘控制器脆弱性，介绍工业边缘控制器功能和特点，同时浅析工业边缘控制器在开放协议侧的脆弱性分析，同时阐述工业边缘控制器遭受攻击后造成损失和严重基础设施后果，最后提出针对工业边缘控制器的纵深防护建设方案。

# **十一、《构建安全纯净移动互联网应用生态的最佳实践》**

![](../Images/6f9b7a5bd2911a410e56e1de08c25a5c.png)**安天移动安全智能终端产品部总监钟翔**在本次议题中以移动互联网应用的常见风险问题切入，从应用开发制作、分发下载、安装运行、更新或卸载的全生命周期视角深度剖析各环节面临的安全风险；结合安天&小米合作的实际案例，针对性介绍相关风险的治理策略及优秀实践方案，助力构建安全纯净的移动互联网应用生态，营造良好的开发者发展环境，激发创新体验。

# **十二、《智能网联汽车车机安全》**

![](../Images/98d2ac759665f2e3594f193b2c75c0b2.png)在智能化、电动化、网联化、共享化的发展趋势下，我国汽车产业进入了转型升级的新阶段，在政策+技术+产业链变革的驱动下，各大企业纷纷加入智能网联汽车的研发与制造。2021年3月，小米正式宣布进军智能电动汽车行业。伴随着社会对智能网联汽车的高度关注，信息安全将成为衡量汽车质量的重要标准。**小米高级安全工程师尹小元**在本次议题中介绍车机台架搭建、固件提取、隐藏调试分析以及常见漏洞等内容。

# **十三、《软件供应链安全威胁与解决方案》**

![](../Images/6ea838f0fa4cc8d6e59e0d9a09c4b5ad.png)随着软件及开源生态的发展，开源软件已经成为数字空间的基石。从Log4j漏洞到node-ipc组件投毒，近年来自软件供应链安全威胁涌现，企业违反GPL许可证的案例也屡见不鲜。在IoT及智能汽车领域，尤其是智能汽车产品作为复杂度高、安全性要求高的产品，可能通过云端、车身部件引入大量供应链软件，这将非常容易带来漏洞、合规及数据隐私风险。**墨菲安全联合创始人、墨菲安全实验室负责人欧阳强斌**在本次议题中从软件供应链的典型威胁场景、情报、威胁对抗及软件供应链安全评估及管理解决方案几个方面展开分享。

# **十四、《移动端加固防护技术在IoT终端的实践》**

![](../Images/bb6690cfd66ebc3d8d424518683ed030.png)目前IoT端产品在市场上高速发展,IoT端所面临的安全威胁不容小觑，**360-三六零天御团队高级安全开发工程师佟金龙**针对IoT端所面临的风险以及对抗IoT端破解分析。![](../Images/ab49c76e31509d53aa6335dcf0214163.png)随着全球消费级物联网市场持续高速增长，小米拥有全球领先的物联网平台，截至2021年11月，小米物联网平台联网设备数量超过4亿，有超过800万米粉拥有5件以上的IoT设备。小米作为物联网安全领域的践行者，始终秉承隐私保护（Privacy by Design）和安全保护（Security by Default）基本原则，愿意打造安全的物联网生态，与行业一起共同成长和进步。**最后，感谢一路支持小米IoT安全峰会的各位朋友，后续会在小米安全中心公众号中分享嘉宾的议题PPT，我们明年再见！**![](../Images/b6f79ca664c60ea2087ac9d66d3c087b.png)
