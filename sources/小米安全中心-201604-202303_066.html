致 谢 信






近期，小米安全中心（MiSRC）接收到来自京东信息安全实验室旗下的Dawn Security Lab关于小米某基础组件中存在高危漏洞的报告，Dawn Security Lab在报告中提供了详细的漏洞验证过程及结果。小米安全中心联合业务部门迅速做出响应，所有漏洞都得到了快速、有效地处理，及时保障了用户的安全。在此，小米安全中心对Dawn Security Lab表示衷心的感谢!

Dawn Security Lab专注于基础系统，应用及泛物联网方向的安全技术和产品建设，致力于为行业提供专业可靠的技术支持和安全服务，为企业在移动时代和AIoT时代的业务安全保驾护航。

在整个测试过程中，Dawn Security Lab展现出了优秀的安全技术能力和领先业界的工具自动化水平，为小米生态安全贡献了巨大的价值。最后，再次感谢Dawn Security Lab对小米安全的帮助与支持。

小米安全






小米安全中心(MiSRC)致力于保障海量终端用户的安全，欢迎更多热爱安全、关注小米产品、喜欢玩智能硬件的安全专家、团队向我们反馈小米产品及业务的安全漏洞，与我们一起保障国内外数亿用户的安全在线生活。
