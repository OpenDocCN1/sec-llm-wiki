岗位详情


1：办公网安全负责人 



岗位职责：
1.  负责集团办公安全体系规划、建设与运营工作；
2. 负责推动公司办公网基础安全（终端安全、网络准入、零信任体系等）架构设计和建设落地；
3. 负责公司办公安全入侵检测和响应能力建设，以及安全事件处理，并持续优化和改进办公安全风险指标及相关流程；
4. 负责团队工作规划和日常管理。


岗位要求：

1. 5 年以上大型互联网安全从业经验；
2. 熟悉掌握业界办公安全最佳实践和具体方案，负责过大型办公安全基础设施搭建或大型安全项目的实施；
3. 具备办公网安全策略制定、系统运维、入侵检测、应急响应和事件处理等能力；
4. 学习能力和责任心强，有团队合作精神和良好的沟通协调能力；
5. 具有 CISSP、CISA、CISP、ISO 27001、PMP 等相关认证或经验优先；
6. 具备编程能力（Golang/Python 等）者优先。



2：应用安全工程师



岗位职责：
1. 负责小米应用安全体系建设，包括不限于业务风险发现、业务防御能力建设、零信任体系建设等工作；
2. 负责安全自动化能力建设，包括但不限于黑白盒自动化扫描、WAF规则优化、攻击日志分析等；
3. 负责安全事件的跟进及复盘，推动内部通用能力建设优化；
4. 负责公司项目和产品的安全评估和测试，对接一条或多条业务线，推动业务安全解决方案的落地与实施。

岗位要求：

1. 熟悉常见漏洞的原理、检测、利用和修复，掌握主流应用框架的风险点和对应解决方案；
2. 熟悉 SDL 流程及DevSecOps框架，并有一定的推广和落地经验；
3. 拥有安全能力自动化、平台化建设经验，有一定的研发能力；
4. 有优秀的学习、沟通和问题解决能力。



3：安全运营工程师 



岗位职责：
1. 负责安全意识宣传，组织规划公司内部安全意识线上、线下宣贯活动；
2. 协助组织、实施信息安全培训并进行培训体系建设规划；
3. 负责内部漏洞管理、安全项目闭环、数据化能力建设等工作；
4. 负责内外部安全事件的响应、推动及复盘工作；
5. 参与对外漏洞响应平台的规划、发展及沟通工作。

岗位要求：

1. 有策划和落实线上活动的能力，有组织线上、线下活动的经验；
2. 熟悉owasp top 10安全漏洞原理；
3. 有一定的项目管理能力、沟通表达能力、文字功底以及良好的数据分析能力；
4. 熟悉信息安全业界的常见的媒体、平台、厂商等渠道及推广方法。



4：高级嵌入式设备安全工程师 



岗位职责：
1. 负责智能硬件设备的安全攻防技术研究，保障小米系列智能产品安全；
2. 参与 IoT 自动化检测体系的能力研究与实现；


岗位要求：

1. 了解 Linux 、Android、RTOS 等常见嵌入式系统运行原理；
2. 熟悉常见存储介质如：Nor Flash、NAND、EMMC 等数据提取；
3. 熟练使用逻辑分析仪等设备，可以分析电路、引脚通信数据；
4. 熟练查找并操作 UART、JTAG、SWD 等常见调试接口，获取权限，提取固件；
5. 熟练对固件内二进制程序、脚本逻辑进行分析，进行漏洞挖掘与利用；
6. 有智能产品安全漏洞分析经验者优先，小米产品更佳。



5:  高级二进制安全研究工程师 



岗位职责：
1. 负责智能产品二进制应用安全研究，挖掘与漏洞利用；
2. 对 Nday 漏洞研究，可以进行 POC 复现；


岗位要求：

1. 了解 ARM/MIPS/x86 架构下二进制的漏洞分析与利用；
2. 了解 gcc 安全编译选项 NX/ASLR/PIE/CANNARY 保护绕过思路；
3. 熟悉堆/栈溢出常规利用手段；
4. 熟练使用 IDA Pro、GDB、radare2 等调试工具（不限）；
5. 了解一些 fuzz 技术与原理，并做过实践；
6. 有 CTF 比赛经验更佳。



6:  高级Android安全工程师 



岗位职责：
1. 参与公司 Android 产品生态安全保障，如手机、IoT 等产品；
2. 辅助开发人员进行安全漏洞闭环，设计安全架构方案；
3. 移动安全领域技术对抗持续研究；


岗位要求：

1. 熟悉 Android 等移动系统平台及应用安全体系，有漏洞挖掘与利用研究经验
2. 熟悉移动平台应用层或 Native 层的代码分析或逆向工程能力；
3. 熟悉常用的逆向工具使用，如：IDA Pro、JEB、JADX 等（不限）；
4. 有内核安全、Framework、浏览器、Fuzz 漏洞研究等经验更佳。



7:  高级无线电安全工程师 



岗位职责：
1. 研究分析 IoT 产品常见无线通讯协议安全，对风险进行利用验证；
2. 不同产品品类、场景下的无线电安全攻防研究，防御方案制定；


岗位要求：

1. 熟练分析智能产品常用无线电通讯协议，如：BLE、Mesh、Wi-Fi、RF 等（有 UWB、NFC、Lora、蜂窝 经验更佳）；
2. 熟悉各类软件无线电开发版，如 USRP、HackRF、BladeRF 等，进行信号捕获、分析、窜改与重放；
3. 熟悉一些无线通信领域常用算法应用场景，如：AES、ECC、ECDH、HKDF、HMAC 等；
4. 有过各类无线电开发板开发经验者优先；
5. 有过无线电产品安全研究经验，如：手环、手表、滑板车等有小米产品研究经验者优先。



8：安全工程师（隐私合规方向）



岗位职责：
1. 组织制定网络安全及个人信息保护规章制度、操作规程并监督执行（ISMS&PIMS）；
2. 与监督、管理部门保持沟通，负责采取适当措施落实监管者的意见和建议（应审）；
3. 对集团业务变更/新产品（IoT智能设备与互联网产品App）进行数据安全影响评估和隐私合规设计（PIA）；
4. 规划与实施数据安全方案，监控数据泄露和合规使用行为（数据安全）。

岗位要求：
1. 本科及以上学历，信息安全、计算机科学与技术、法律及相关专业；
2. 3年以上信息安全或数据治理领域工作经验，具有大型互联网、金融、物联网类公司安全工作经验者优先。
3. 熟悉数据安全的国家级法律法规、国内外数据安全行业发展现状，了解企业级数据安全的最佳实践
4. 实践过数据安全生命周期、个人隐私保护者优先
5. 具备数据加解密、4A系统、DLP（数据防泄漏）、数据脱敏、数字水印等数据治理相关实际项目经验者优先
6. 熟悉前沿数据技术及隐私安全技术，如kafka、Hadoop、数据安全、差分隐私、同态加密、等，有具体生产实践者优先
7. 具有ISO27001 LA、CISA、CISSP、CISP、IAPP等专业领域资质认证从优。
