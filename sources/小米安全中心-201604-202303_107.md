# 用安全守护草原的梦｜企业联合公益活动—MiSRC

白帽师傅们看过来哇MiSRC新版上线后**现金奖励**活动来啦每提交一个**高危及以上**漏洞可额外获得**2000元**奖励并追加等值物资以您的名义捐赠给学校用白帽子的方式，帮助草原上的孩子完成梦想

  

![](../Images/f212ff0e085a5dee6d1dbbf00e620761.png)

满族屯满族乡，位于科右前旗西北部，是全国唯一以畜牧业为主的满族自治乡。这里最为出名的便是那充满神奇色彩和历史传说的科尔沁草原。但满族屯偏远的位置，致使曾经辉煌的草原未能赶上中国经济发展的时代班车。我们本次捐赠的满族屯学校是一所九年制边境乡村学校。建于1984年，目前有在校学生234名，教职工70 人。本次教育公益活动，由完美世界工会联合会与完美世界、爱奇艺、滴滴、小米、贝壳、VIPKID、微博、智联招聘 8 家企业的安全应急响应中心（SRC）联合发起。整个活动，在4月23日（世界读书日）开启直到5月31日结束，企业SRC与新老白帽们一起伸出圆梦之手！

**❤️  爱心白帽，公益挖洞**

国家越来越富强，社会越来越进步。我们熟练的在网络世界里驰骋，每天都享受着科技带给我们的便捷和快乐。但仍然有那么一群孩子，为了上学，他们要走最泥泞的路，翻过一个又一个山坡，每一个脚印都是为了完成“我的梦”。你愿意和我一起牵手，帮助那些在草原追梦的孩子吗？用白帽子的方式，来帮助他们完成梦想吧！  

**一个“低危”能让一个孩子吃上香喷喷的米饭，一个“中危”能让一个孩子背上崭新的书包，一个“高危”能解决一个孩子一学期的生活费，一个“严重”能资助一个孩子顺利完成学业。**在这个读书日，让我们帮助孩子有书可读，才是这个节日存在的重要意义。

**❤️  企业联合活动规则**

白帽子自愿参加企业联合教育公益活动。活动期间向参与企业联合教育公益活动（MiSRC、PWSRC、DSRC、71SRC、BKSRC、VKSRC、WSRC、ZPSRC）的任意一家提交漏洞报告即视为报名参与。  

  

活动期间，若白帽子向参与企业联合教育公益活动物资捐助的 SRC 提交有效中危漏洞报告达到**三家**，白帽子将会收到**所有提交中危有效漏洞 SRC 准备的精美礼品一份**，同时获得由完美世界工会联合会发放的**捐赠公益证书**。

在活动期间，写下对学生们的祝福和鼓励，分享到微信、微博等渠道邀请更多白帽朋友参与！截图发送至任意一家参与教育公益活动的企业 SRC 微信后台，活动结束将随机抽取白帽子获得礼品一份。  
![](../Images/9beaa8472404746357e53457def84b99.png)![](../Images/610db30dba57e4e935cff7fa0c181628.png)

  

MiSRC 活动时间  
4月23日-5月16日

  

**❤️  MiSRC 活动规则 **

  

4月23日-5月16日期间在 MiSRC 提交 **严重/高危** 漏洞的白帽子享受额外奖励**2000元**（边缘业务除外），同时MiSRC追加等值物资以白帽子的名义捐赠给学校，传递白帽爱心。

活动期间只要提交**有效漏洞**的白帽子，MiSRC将以MiSRC和白帽子的联合名义向学校学生捐赠学习物资，并官方致谢所有白帽捐赠者。

**注：提交漏洞时标题标注【公益活动】字样。**  

陶行知先生曾说：“教育乃立国之本，强国之基”。本次企业联合教育公益活动，8家企业联合为满足屯学校送去最紧缺的物资。包括：（文具套装、彩笔套装、书包、跳绳、图书、羽毛球拍、足球、篮球等）。在克服运输等重重困难之后，我们希望通过大家的努力，能够为满族屯学校的孩子们带去一缕春日的温暖希望。📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1835629833184215047](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1835629833184215047)
