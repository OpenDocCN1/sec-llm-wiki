# 小米安全课：差旅中如何保护信息安全

12月18日下午，小米安全研究员Mike在小米总参发布间分享了**《****差旅中如何保护信息安全》**的安全课程。课程中，Mike向听众介绍了差旅中常见的信息安全隐患，并给出了相关的应对建议。

  

![](../Images/1aaa25fa5f6ef71e2124b34a780df7ad.png)

**信息安全威胁往往在小的行为**  

 

在行程中，连接WiFi、租用充电宝甚至是租车时都有可能面对到安全威胁，银行卡装进口袋、拍张机票发朋友圈、拍一张夜景发条微博……任何不起眼的信息都有可能导致行程泄露。

 

面对海关检查，仅仅是给电子设备加密码是不够的，多国海关具有无条件搜查电子设备的权利，并且被搜查者需要配合提供电子设备密码，为了做好信息防护，**除了计算机加密、手机分身、重要文件云端加密存储等方法，还可以使用双层加密方法保护重要文件。**

 

活动现场，Mike向大家演示了防盗刷钱包、GPS、GSM信号屏蔽器等设备。

  

![](../Images/f68063e655948bab9d26c8406383952a.png)

**酒店房间也未必安全**  

 

到了酒店并不意味着可以放松警惕。在讲解完行程中注意事项后，Mike又曝光了酒店住宿的种种安全隐患。

 

猫眼可以看到访客的样貌，看似可以保护我们安全，但是通过反猫眼设备，门外可以清晰的看见室内的情况；不法分子还会通过猫眼开锁工具，数秒内打开酒店房门。由此看来，猫眼反而存在安全隐患。不仅仅是猫眼开锁，酒店清洁用房卡、NFC克隆卡进行开锁也应该提防。

 

Mike表示，刚刚看到的这些只是个“小把戏”，还有更令人害怕的威胁存在：通过专业设备隔墙窃听，在射灯、顶灯、烟雾报警器、装饰画、插座、小饰品等位置隐藏的针孔摄像头等。为此，**我们可以通过涉密谈话时开启电视声音、在黑暗状态中利用手机摄像头检查红外光、购买专门的屏蔽设备进行防护。**

  

![](../Images/373ac4c86cebe6ffdd6a3fd70df7f509.png)

 \*Mike现场演示摄像头检测方式

**最核心的是提高安全意识**

 

在参加会议时，更是要注意安全。别人赠送的数据线、充电宝，会场中见到的遗落的U盘，都有可能是不法分子设下的陷阱；陌生人递来的名片，身份真实性有待核实，名片上面的二维码，更不能轻易扫描。面对五花八门的风险，除了要做好准备，**最核心的就是提高安全意识。**

 

![](../Images/0455b8667a476d628b65931f023e430e.png)

  

笔记本防偷窥膜、阻门器、GPS&GSM干扰设备、防盗刷手机套&钱包、针孔摄像头探测仪等，有些看似“黑科技”的设备，市面上可以很轻易的买到。除了这些，计算机的清理文件、系统保护、加密文件；手机分身、查找手机、文件清理等功能，都是可以成为保护信息安全的“特效药”。  

 

Mike呼吁，差旅不仅仅是人身的安全，信息作为财产的一部分，一旦受到威胁，就可能造成难以估量的损失，希望更多的人学会保护信息安全，让每一次差旅都能平安。
