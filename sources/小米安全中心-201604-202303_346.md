# 共建互联网安全防护林，小米地球守卫者等你加入！

为了肯定安全极客对于互联网安全保护的作用，**小米安全中心**（MiSRC）计划从2018年起，加入由蚂蚁金服发起的、面向安全圈开放的合作项目“互联网安全防护林”计划。

  

![](../Images/5c5d9d6a2afe82c331e06b6135ff20d2.png)

项目以one bug = one tree 为口号，倡议安全圈中的有识之士一同参与。通过公益植树的形式，将无形的“网络安全保障”，等价于有形的“现实环境保护”。鼓励更多的安全极客参与到网络安全保障的阵营中，为用户建设“看得到”、“摸得到”的“绿色城墙”。

  

在网络安全的这条路上，任何人都可能成为受害者，网络安全带来的威胁就如同现实环境中的土地沙化一般，只有全民共进才能形成巨大的力量。项目的实施，为每一位“安全极客”的网络安全保卫行动，赋予了更大的社会价值及经济价值。

  

十九大以来，国家持续倡导“公益扶贫”和“环保扶贫”的发展主题，“互联网安全防护林”项目的推出，将通过植树造林等环境保护措施、改善地区恶劣的生产生活条件，推动当地经济发展，具有重要的民生价值和社会意义。

  

作为项目的重要参与方之一，**MiSRC**将通过以下形式，参与“互联网安全防护林”计划共建，践行企业、组织的社会责任感。

  

【 **活动规则 **】

  

① 自2018年3月12日起，凡在MiSRC提交**有效漏洞**，MiSRC都将以该白帽子的名义为互联网安全防护林捐赠一棵树。白帽子每提交1个有效漏洞即捐出1棵树，上不封顶；

  

② 每位提交有效漏洞的白帽子，都将获得一份专属的**电子版捐****赠证书**；

  

③ 截止2019年3月12日，在MiSRC累计捐树数量最多的**前3名**白帽子，都将获得由MiSRC提供的【**小米地球守卫者**】大礼一份！

  

一年之计在于春，为了守护更美好更安全的生存环境和互联网环境，趁现在加油挖洞吧~
