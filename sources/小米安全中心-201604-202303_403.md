# 小米安全中心2017年1月份排名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NzI2OTExNA==&mid=2247484194&idx=1&sn=a0b0115d98a01fc67ba95c2c46cb4744&chksm=ea8025b7ddf7aca1802d9a7753d4664aaa1c1c0ebb5e322bc721b7dc6b30521d4e5382298d58&scene=126&sessionid=1681381476#rd](http://mp.weixin.qq.com/s?__biz=MzI2NzI2OTExNA==&mid=2247484194&idx=1&sn=a0b0115d98a01fc67ba95c2c46cb4744&chksm=ea8025b7ddf7aca1802d9a7753d4664aaa1c1c0ebb5e322bc721b7dc6b30521d4e5382298d58&scene=126&sessionid=1681381476#rd)

在2017年1月，共有7位海内外安全专家通过小米安全中心（MiSRC）反馈了有效的安全漏洞和威胁情报。为小米数亿用户的安全做了保障，让我们对上月这7位安全专家表示感谢。

小米安全中心为安全专家们提供了小米手机5，小米电视，平衡车，小米手环2以及现金等礼物，可供选择。

欢迎更多的安全专家，关注小米产品，同时我们会推出更多活动，期待大家的热情参与。
