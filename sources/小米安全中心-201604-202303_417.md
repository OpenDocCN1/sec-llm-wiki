# 冒充成求购MIX手机F码的米粉，跟卖假F码的人聊了聊……

MIX作为小米公司推出的全面屏概念手机，自然超级火爆。例如，登上了时代周刊

![](../Images/99da84b0ba62f6e3a71f0264ee705850.png)  

  

锤子手机创始人罗永浩先生也在用

![](../Images/c1bfa7eb4916011a1c83aec86d8a1d22.png)  

  

因为MIX手机对制造工艺要求比较高，产能有限, 做不到开放购买。于是，一些骗子便趁机行骗，小编就看到有网友分享自己受骗经历

![](../Images/c937ae000585a4b907864e3089a5881c.png)

(复制案例地址到浏览器：http://bbs.xiaomi.cn/t-13241183-2-o0#comment\_top )

  

但该网友受骗的时间是11月10日，距离现在已经有一段时间了。该骗子还在行骗么？带着这样的疑问，小编决定找这位骗子聊聊。根据网友提供的骗子的QQ号，小编搜到了该骗子

![](../Images/863ffee0cbf467d84221360845f74d31.png)  

  

小编尝试加骗子好友，很快就通过了

![](../Images/003e9775f2fdffdf3d3776459e7c5260.png)  

  

然后骗子拿出截图试图证明自己真的有MIX手机F码

![](../Images/eec325e44c5d67869cc71c6e405fcb60.png)  

![](../Images/c04f838cef3a1ed0917ff6fe94b7a200.png)  

![](../Images/2ff74cb184a38c1b74be5a002f4b9bbd.png)

  

然后小编提出用有第三方担保的淘宝交易，对方拒绝了。但表示可以先付一半，剩下的一半等买到手机后再付。

![](../Images/9d64ad3ab2c48e514ee099fbc76c377c.png)  

![](../Images/3ec91b94e4183ab8014fe088e258eb3b.png)  

![](../Images/abc80f62b3574832c9c4c9a1a968b7a1.png)  

  

小编当然不是来买F码的，于是就把在网上看到的链接发给他了

![](../Images/60485d6824a25c5fcc3be933e9c3398b.png)  

  

然后小编就被删除好友并被拉黑了……

![](../Images/dfd1ae462abb6ce0d72a6d590ade40e6.png)  

  

但是作为一个拥有执着精神的人er，便又用另一个qq号添加了下，发现他还在尝试行骗……

  

在此小编再次提醒大家：

1.  **购买任何商品都请到官方指定渠道**
    
2.  **即便是小米员工也无法大批量获取F码，同时小米公司禁止小米员工买卖F 码，一旦发现将严肃处理**
    
3.  **官方微博微信社区等渠道会用F码奖励米粉，但会避免单个用户批量获得F码。如果有专营大批F码的卖家一定是骗子**
