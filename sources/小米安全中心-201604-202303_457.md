1\. 小米公司对自身产品和业务的安全问题非常重视，也一直致力于保障用户安全，我们希望通过小米安全响应中心加强与业界个人、组织及公司密切合作，来提升小米的整体安全水平。

2\. 小米公司对于保护用户利益，帮助小米安全提升的白帽子黑客，我们给予感谢和回馈。

3\. 小米公司反对和谴责一切以漏洞测试为借口，利用安全漏洞进行破坏、损害用户利益的黑客行为，包括但不限于利用漏洞盗取用户资料、入侵业务系统、修改、窃取相关系统资料、恶意传播漏洞或数据。对于发生上述行为的、小米公司将追究其法律责任。

**二、成长体系**

**1.如何成长**

提交漏洞会获得积分和金币，成长等级以积分为单位，积分累计达到每个等级要求时则升级

**2.成长等级有什么好处**

**福利（1）：**漏洞金币翻倍，让你赚钱翻倍

| 等级 || 积分 |
| --- | --- |
| LV0 || 0 |
| LV1 || 100 |
| LV2 || 300 |
| LV3 || 700 |
| LV4 || 1600 |
| LV5 || 3000 |
| LV6 || 7000 |
| LV7 || 15000 |
| LV8 || 25000 |
| LV9 || 50000 |
| LV10 || 100000 |

（LV0是每个用户的起点，LV10为封顶）

  

每两个等级对应的提交漏洞的金币翻倍数对应上升

LV0、LV1 所提交的漏洞金币翻0倍

LV2、LV3 所提交的漏洞金币翻1.1倍   

LV4、LV5 所提交的漏洞金币翻1.2倍

LV6、LV7 所提交的漏洞金币翻1.3倍

LV8、LV9 所提交的漏洞金币翻1.4倍

LV10 所提交的漏洞金币翻1.5倍

LV10为封顶等级

  

**福利（2）：**漏洞积分翻倍，助你快速成长

同金币翻倍

**福利（3）：**签到得积分，助你快速升级

LV3及以上的用户可以每天签到，起始签到得1个积分，

一周连续签到，则按照连续签到天数给予相应积分，

例如：连续签到3天，则第三天签到时给3个积分，连续签到7天给7个积分，7天为上限。

**福利（4）：**免费抽奖

每次升级有一次免费抽奖

**三、漏洞质量的计算方式**

漏洞评分（Rank）=a

奖励金币=b

系数X和漏洞等级的关系见下表：

![](../Images/6fbfca6ff451d8a33bab97a09e107a54.png)  
漏洞质量公式：质量=a\*X+b/100

例如：

小明同学提交了1个严重级别的漏洞，漏洞评分（Rank）=9，按照MiSRC之前的奖励机制

，小明获得了30000人民币的奖励，他的漏洞质量就是 9\*200+30000/100=2100

小强同学提交了10个低危级别的漏洞，每个漏洞的评分（Rank）都是1，按照MiSRC之前的奖励机制，小强每个漏洞获得了10元人民币奖励，每个漏洞的质量是 1\*10+10/100=10.1，10个低危漏洞总共的质量是101

设计该计算公式的初衷是：不以漏洞个数论英雄，让提交漏洞个数很少但质量却很高的白帽子在排行榜上能有一席之位。该算法可以拉开多次提交低危漏洞 和 少次提交高质量漏洞同学的分值距离。单纯的积分很难拉开距离。

**四、新增游戏模块**

**【夺宝奇兵】**

**![](../Images/47446902c86cfb9ddb10c55c0b2e9ebb.png)  
**类似于市面上的一元夺宝游戏，可以通过下注比商品原价值少很多的钱，抽取下注中的一人，获得该商品。

1.登录状态下，用户金币有且大于等于5个

2.根据商品不同，每注消费金币数不同；每人的注数上限为总注数的30%。

3.满注后即刻开奖，离开当前页面的用户，中奖结果会在个人消息中提示

4.中奖后，在弹框中确认收货地址。地址在提交后若要修改，需要找管理员。

5.奖品发放：次月月初。特殊情况联系发货管理员

**【幸运转盘】**

**![](../Images/4e09e5bb5df4d8e7808cece41bc5475d.png)  
**点击 “ready go!” 光标随机跳动，中奖概率很高哦~

1.登录状态下，用户金币有且大于等于5个

2.每次消费5个金币，每日没有次数上限。只要账上有金币，就可以无限制的玩

3.中奖后，在弹框中确认收货地址。地址在提交后若要修改，需要找管理员

4.奖品发放：次月月初。特殊情况联系发货管理员
