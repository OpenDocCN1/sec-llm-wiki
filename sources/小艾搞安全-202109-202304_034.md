## 使用方法 

### 1\. 安装并运行Serein

```


   pip3 install -r requirements.txt
```

### 2\. 工具配置

点击左上角的`软件配置`配置`fofa`的`email`和`key`（注意不是密码，而是`https://fofa.info/personalData`下方的`API KEY`），然后就可以愉快地使用`fofa搜索`啦。

**注意：必须是`fofa`普通/高级/企业账号，因为`fofa`注册会员调用`api`需要消耗`f`币，如果您是注册会员请确保您有`f`币，否则无法查询！**

### 3\. 此处以向日葵RCE漏洞为例

   1.我们想批量利用`向日葵RCE`漏洞，于是我们利用`base64加密`模块加密语句`body="Verification failure"`，得到：`Ym9keT0iVmVyaWZpY2F0aW9uIGZhaWx1cmUi`。

   2.我们选取获取前`2000`条（具体条数需要根据自己的会员情况来填写）：![](../Images/2d803c3e35d140fc882c91e170716950.png)![](../Images/d07fbfa61ecb3d0202edf8f22ed04b43.png)![](../Images/1ae7467dbbf5a9ef589c9cd7b72c7e05.png)

3.  直接点击`向日葵RCE一把梭`：![](../Images/304ba06d90de9c4e18914840bc581886.png)
    
4.  可以看到软件开始批量检测了（可能会出现短时间的空白，请耐心等待程序运行）：![](../Images/8798a2bdf26131dd6944b1204906aba0.png)
    
5.  **删除文件夹下`urls.txt`、`修正后的url.txt`、`host.txt`这三个文件，准备使用其他一键梭哈模块：**
