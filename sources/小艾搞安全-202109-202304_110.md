一、Shuffle  

#### 题目来源：攻防世界 (xctf.org.cn)

下载附件，没有任何后缀名，看一下16进制

![](../Images/59451a0f3007643d5a3cb11e463e8657.png)

  

elf文件，linux的可执行文件，用od打不开，再用查壳工具试试看

![](../Images/5c833d7e417bc6a9c01a56fc490cb79b.png)

  

没有显示出任务有效信息（这工具可能版本老了或者不行了，但是我懒得更新）

用ida打开

![](../Images/3f5334ae4b09d42412b6f28b61ae4edf.png)

  

可以直接看到定义了一串很像flag的字符串

我们再拖到虚拟机里运行看看

![](../Images/5b10c1362f035e15783bf79a9aa35070.png)

  

仔细观察可以发现，程序输出的就是ida下看到的那一串字符的随机排列

再结合题目提示：找到字符串在随机化之前

![](../Images/c255b2a4493933fa6611708878b28695.png)

  

基本确定flag就是那一串字符

SECCON{Welcome to the SECCON 2014 CTF!}

提交正确

### 三、dmd-50

#### 题目来源：攻防世界 (xctf.org.cn)

下载附件，查看信息，是个elf

![](../Images/3d7cf82599d0ab3e425eec182c5e59ab.png)

  

运行一下，是个验证

![](../Images/aae33f946f86e1fb27e8186843b3bf53.png)

  

老规矩，上ida，找enter the valid key，再反汇编一下

![](../Images/f622ba1808b95be958971540be64e432.png)

  

```













































int __cdecl main(int argc, const char **argv, const char **envp)
```

分析代码，看这，应该是个md5

![](../Images/4204f85b1aa6e3d82fc1a23399d393c5.png)

  

85行开始往后的那一大串，转化成字符之后，可以发现是程序常量，所以主要看55行开始的那一串就行了

![](../Images/bea040cea8742ff1e83693d3fe2df82d.png)

  

把55行if之后的数据全都拿出来，小端存储，所以我们倒着拿，然后就得到了

```

780438d5b6e29db0898bc4f0225935c0
```

再解密试一下，就得到grape

![](../Images/5d4c77ca8a1638d2c05f1bf315af519f.png)

  

到这里其实我有点懵了，看了下wp，这边解密工具给出的grape是经过两次md5运算的，而程序这里只经过了一次，所以再反向加密一次就能够得到flag

![](../Images/a24317ddcb9b11f48d074f8b7c6f1e00.png)

  

flag:b781cbb29054db12f88f08c6e161c199

攻防世界，这是一个比较适合新手去练习的一个ctf平台，这些的逆向题目也都不怎么难，尤其第一题都不需要有任何汇编和代码基础，会用ida就能做出来，挺推荐刚接触安全或者想打ctf的朋友去练练的。
