快速使用


  • 下载工具（下载链接在文末）

    下载成功后，安装依赖，命令如下：

    pip install -r requirements.txt

    PS.工具包里的Cobalt Strike内置了很多插件（包含了很多病毒程序，请自行甄别使用），如有需要可以自行加载；工具包较大，后续会持续补充。


  • 目录结构

├── GUI_Tools.py
├── GUI_Tools_wxpython_gui.py
├── JAR_Management.fbp
├── gui_other
├── gui_scan
├── gui_shouji
├── gui_webshell
├── Java_path
└── setting.py

  • 执行程序


    python3 GUI_Tools.py
