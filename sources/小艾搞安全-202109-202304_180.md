漏洞描述

2021年9月9日，**小艾安全监控到微软官方针对Microsoft MSHTML组件存在的远程代码执行漏洞发布了紧急通报。**

     Microsoft MSHTML.DLL是美国微软（Microsoft）公司的一个用于解析HTML语言的动态链接库，IE、Outlook、Outlook Express等应用程序都使用了该动态链接库。

MSHTML 存在代码注入漏洞，**远程攻击者可以创建带有恶意ActiveX控件的特制Office文档，诱使受害者打开文档并在系统上执行任意代码。   **

  

  

危害等级

高危

  

漏洞编号  

CVE-2021-40444

漏洞影响

此漏洞警报会影响Windows 10等软件或系统，Windows 7、Windows 8、Windows RT、Windows Server 2008 R0、Windows Server 2008 R2、Windows Server 2012、Windows Server 2016、Windows Server 2019、Windows Server 2022。
