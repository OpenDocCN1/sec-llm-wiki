小编想要最近为学院搭建一个安全快速方便的网盘，为学院的小伙伴们提供资源汇总和管理的乐土，经过检索再三进入选择的开源平台（实在没必要巨资购买商业版本）如下：


Seafile,kodexplorer,DzzOffice,Pyone,Kodexplorer,nextcloud,owncloud


搞安全的最怕什么？怕系统被黑被被攻击，基于种种原因选择了Python开发的Seafile平台，Seafile 协做平台，是一个功能强大的合作平台。

部署前提：


1、centos 7 2、安装docker 18.06.0-ce3、安装wget

下载安装脚本


https://raw.githubusercontent.com/helloxz/seafile/master/install_seafile.sh


chmod +x install_seafile.sh


赋予其可执行权限，其中默认安装的是6.2.3版本，您可以修改为最新版本7.0.5



修改如下



执行脚本


./install_seafile.sh


输入1 ，表示安装SeaFile，执行后会正在下载和安装需要对应的包



安装进入下一步，以来已经安装完成，下面进入配置阶段



输入【ENTER】键，输入主机名称，访问的IP地址，访问的端口等



输入【ENTER】键



输入【ENTER】键，输入管理员的邮箱，管理员登录的密码



说明：此处由于8000端口已经被其他服务使用修改端口



编辑/home/MyCloud/conf/ccnet.conf



编辑/home/MyCloud/conf/gunicorn.conf



进入找个目录重启服务，执行下面的脚本重启服务


./seafile.sh restart./seahub.sh restart


测试下登录http://192.168.60.204:8083/,此处是我的地址，默认8000端口



使用设置的管理员邮箱登录平台



稍微定制下风格，修改下logo和标题



修改安全性配置，设置密码强度，注册管理等




访问主平台登录



配置邮箱功能后注册可收到激活邮件


提示邮件内容



平台已经搭建起来了，你是否想着还要编辑和预览各类文档呢？

office的编辑与预览有两类方法：onlyoffice和office line。
下面进行office文档的编辑与预览功能的部署和配置，此处使用onlyoffice，相当于一个在线的office的编辑与预览服务器，由于该服务器仅用来做编辑预览，因此使用docker运行即可，执行下面命令检索docker镜像。


docker search onlyoffice


拉去docker的镜像


docker pull onlyoffice/documentserver


运行onlyoffice容器,注意8084为我环境的端口，其他端口已被占用


sudo docker run -i -t -d -p 8084:80  onlyoffice/documentserver


编辑文件/home/MyCloud/conf/seahub_settings.py，配置邮箱和office的调度接口



重启服务，配置基本完成



迫不及待的测试下查看word文档



预览和本地编辑的word文档一样，极为方便，ctrl+s即可保存
