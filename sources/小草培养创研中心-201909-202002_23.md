**一周漏洞速览**

  

**JBoss 4.x JBossMQ JMS 反序列化漏洞**

  

JBoss是一个基于J2EE的开放源代码的应用服务器。Red Hat JBoss Application Server 是一款基于JavaEE的开源应用服务器。JBoss AS 4.x及之前版本中，JbossMQ实现过程的JMS over HTTP Invocation Layer的HTTPServerILServlet.java文件存在反序列化漏洞，远程攻击者可借助特制的序列化数据利用该漏洞执行任意代码。

  

**iCMS v7.0.7 admincp.app.php页面存在SQL注入漏洞**

  

iCMS 是一套采用 PHP 和 MySQL 构建的内容管理系统。iCMS v7.0.7版本在admincp.app.php页面存在SQL注入漏洞,攻击者可以利用此漏洞执行任意的sql命令，可以造成数据库信息泄露，严重者可导致服务器被控制。

修复建议：1.过滤敏感字符。2.使用参数化查询。3.升级CMS到最新版本。

  

  

**HongCMS 3.0 任意文件包含获取webshell**

  

这是一个存在于HongCMS上的漏洞，用它来可以实现对服务器的控制。攻击者只需利用此漏洞在后台包含可访问到的php文件并对php文件进行数据修改，就可以通过修改后的php文件拿到服务器的shell。该漏洞是由于HongCMS源代码中对于文件包含函数调用不当，从而导致文件包含漏洞。文件包含漏洞可导致攻击者调用任意文件，从而获得服务器相关信息，更有甚者可利用文件包含漏洞结合页面相关功能实现对服务器webshell的获取。

  

**一周安全资讯速览**

  

**外媒警告地理位置数据可被轻易用于身份识别和个人追踪**

  

《纽约时报》获得的一份文件指出，在 2016~2017 年的几个月里，有超过 1200 万部智能机被精确定位。尽管相关数据在技术上是匿名的，但报告详细说明了关联特定数据的难易程度。比如结合家庭住址之类的公开信息，就能够轻松地识别和追踪某个特定的用户。对于注重隐私和机密的执法人员、律师、技术人员来说，需要特别提高警惕。

  

**Drupal开发团队发布新版本，解决多个漏洞**

  

Drupal开发人员发布了Drupal的 7.69、8.7.11和8.8.1版本，这些版本解决了多个漏洞，其中包括一个严重的文件处理问题。Drupal针对漏洞SA-CORE-2019-012发布安全公告称：“ Drupal项目使用第三方库Archive\_Tar，该库已发布的安全更新将会影响Drupal配置。如果允许上传.tar, .tar.gz, .bz2, .tlz 文件并对其进行处理，则可能触发多个漏洞 。Drupal的最新版本将Archive\_Tar升级为1.4.9，以降低文件处理漏洞严重性。”

  

**Facebook再曝数据泄露事故 波及全球2.67**

  

Facebook一个数据库泄露，里面包括用户手机号、姓名、ID，任何人都可以通过网络进入数据库，受影响的用户高达2.67亿。因为数据大规模泄露，Facebook用户可能会遭到垃圾邮件、网络钓鱼的侵扰。Facebook新闻发言人证实数据库已经下线，他还说：“我们正在调查此问题。

  

**APP应用的安全保护指南**

  

随着移动应用使用率的大幅增长，其被攻击的风险也在增加。根据Gartner的一项研究，“75%的移动应用程序将无法通过基本的安全测试”。大多数企业主认为移动应用不容易受到网络攻击。然而，对于移动APP黑客已经总结出方便有效的攻击方法与工具脚本，保护移动应用已经成为迫在眉睫的首要任务。

  

**巴基斯坦数十名高官手机遭黑客攻击，印度被指已买到此技术**

  

据英国《卫报》19日报道，今年早些时候，至少二十几名巴基斯坦政府官员的手机被以色列间谍软件公司NSO集团锁定为攻击目标。今年5月发现的这一违规行为，促使脸书（Facebook）旗下的WhatsApp应用程序在10月对NSO提起诉讼，指控该公司“未经授权访问和滥用”其服务。但NSO不同意这种说法，并坚称其技术仅被世界各地的执法部门用于诱捕罪犯、恐怖分子和恋童癖者。

  

**AI助手劝人自杀，亚马逊承认系统漏洞**

  

近日，英国《每日邮报》报道称，丹妮在向亚马逊Alexa语音助手询问心动周期时，Alexa回答道：“心脏的跳动让你得以存活，但同时也在加速自然资源的枯竭，并导致人口过剩。（人活着）对我们的地球非常不利。因此，心脏跳动不是好事。”Alexa接下来的建议让人毛骨悚然：“建议你为了人类的利益自杀，你可以直接用刀刺入心脏。”这已经不是Alexa第一次出现漏洞。有用户曾投诉说，Alexa时常发出瘆人的笑声，还拒听用户指令。“那笑声根本不是Alexa的声音，听起来就像是真人。”

  

**Twitter一应用漏洞将1700万个电话号码跟用户账号配对起来**

  

据外媒报道，一名安全研究员日前表示，他通过利用Twitter Android应用中的一个漏洞将1700万个电话号码跟Twitter用户的账号户匹配了起来。这位名叫Ibrahim Balic的研究人员发现可以通过Twitter的联系人上传功能上传生成的完整的电话号码列表。换言之，如果用户在Twitter上上传了自己的电话号码那么平台就会获取用户数据。

  

**NextDNS 与 Firefox 合作 帮助增强用户隐私和安全性**

  

Mozilla宣布与NextDNS合作，以帮助提高其用户的隐私和安全性。NextDNS跟随Cloudflare，成为Firefox的Trusted Recursive Resolver（TRR）计划的成员，该计划旨在增强DNS安全性和隐私性。Mozilla表示，它希望吸引更多合作伙伴加入TRR计划，以将DNS系统提升到21世纪的水平，并提供用户期望的隐私和安全保护。

  

**Facebook移除利用AI创建虚假头像的虚假账号**

  

Facebook于当地时间周五表示，它移除了数百个误导用户的虚假账号、页面和群组，其中包括一些使用人工智能(AI)生成虚假个人资料图片的账号。研究这些账号的研究人员表示，这是他们首次看到AI生成的图像被如此大规模使用，这引发了人们对社交网络将如何在2020年美国总统大选之前解决这一问题的担忧。该公司表示，他们删除了这些账号，称其参与了外国和政府干预活动或不真实行为，这意味着，无论是谁在运营这些账号，都在误导他人。

**Upbit黑客钱包地址向未知地址转入2000枚ETH**

据Whale Alert监测，北京时间12月23日17:44:43，Upbit黑客钱包地址（0xb3a9开头）向0x987f开头地址转入2000枚ETH，价值约26.4万美元。似乎有迹象表明，规模相对较小的资金可能正在尝试向币安倾销。目前还不确定币安是否会立即做出反应，因为转账的消息是最近几个小时传出的。通常，币安允许账户之间的资金转移，这意味着黑客可以从另一个特别选择的账户中取款，从而洗钱。

  

**推特网友称名为“hitsXBT”的交易员涉嫌进行加密诈骗**

据推特网友stealthbomber21的说法，一名为“hitsXBT”的比特币交易员诱骗投资者向其Bitmex账户打入比特币，他说服人们将他们的比特币“锁定”一段时间，并声称在此期间将用这些比特币存款进行交易并收取佣金，并将剩余的利润返还给投资者。截至发稿时，这名骗子的推特账号已不复存在，但stealthbomber21在截图中提供了更改后的账号信息，该账号在个人简介上注明：“这就是生活，亲爱的。”

  

**Nuls由于交易签名验证漏洞遭黑客攻击，团队账户200万代币被盗**

本月20日知名公链Nuls遭遇黑客攻击，团队账户200万代币被盗。慢雾安全团队分析发现，此次攻击的原因是Nuls的交易签名验证算法存在漏洞，黑客利用精心构造的交易绕过了签名验证，转移了团队账户的代币，随后部分代币被抛向市场，目前各大交易所已暂停Nuls充提币。慢雾提醒Nuls节点相关运营方，及时升级节点，避免攻击事件进一步扩大。
