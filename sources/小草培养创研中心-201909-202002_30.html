过完眼瘾了，赶紧动起手来吧！为了满足未安装和已安装老版本的伙计们的需求

  • 从镜像开始安装

镜像在https://www.kali.org/downloads/选择适合自己的版本

此处我使用的VM12（比较恋旧）

选择【稍后安装操作系统】

选择操作系统，Kali为Debian系列，VM12最新能识别到Debian 8.X

选择虚拟机存储位置

选择磁盘文件大小，一般默认20G，如果后期需要存储大量文件则选择调整

点击【完成】

点击【编辑虚拟机属性】，调整内存一般2G以上，选下载的ISO文件

点击【启动】开始安装

选择【图形界面】的安装模式，可以选择中文或英文（选择中文则需要安装增字体设置默认字体）

剩余的步骤就是下一步，下一步，傻瓜式的安装完成即可

安装完成重启进入，界面确实比之前帅的不是一点半点！！！

  • 从已有的Kali上更新升级

有人说已经安装过的是不是必须重装，不一定哟，听我慢慢道来~~~

apt update && apt upgrade && apt dist-upgradeapt -y full-upgrade[ -f /var/run/reboot-required ]&& reboot -f# 说明：此处会需要很长时间

更新完毕后检查是否更新成功

看到已经更新为新版本

安装xfce

apt -y install kali-desktop-xfce

切换默认桌面，选择3

update-alternatives --config x-session-manager

选择3  为xfce4为默认桌面，取代gnome

安装完毕，既然升级肯定存在一些残留的组件，统统卸载！

apt remove gnome-coreapt remove gnome-shellapt autoremove

基本上，安装升级就此完成，尽情的体验。Kali可以切换win10界面，小编的操作是：

#vim win10.sh

chmod +x win10.sh

以后只需要双击即可快速切换，方便极了！！！！


如果选择安装时使用的是中文版本，需要编辑更新源，然后设置字体

vim /etc/apt/sources.list# 写入如下下两行内容，默认安装完毕是不存在源地址的deb http://http.kali.org/kali kali-rolling main non-free contribdeb-src http://http.kali.org/kali kali-rolling main non-free contrib# 设置完毕后，执行下面的更新命令apt-get update && apt-get upgrade && apt-get cleandpkg-reconfigure locales

进入图形界面，选中en_US.UTF-8 UTF-8和zh_CN.UTF-8 UTF-8（空格是选择，tab是切换，*是选中）并将en_US.UTF-8选为默认。

安装中文字体

root@kali:~#apt-get install xfonts-intl-chineseroot@kali:~#apt-get install ttf-wqy-microhei

重启系统后即可看到变成中文字体了
