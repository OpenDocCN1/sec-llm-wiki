*   **从镜像开始安装**
    

镜像在https://www.kali.org/downloads/选择适合自己的版本

此处我使用的VM12（比较恋旧）

![](../Images/88205e4c3dc3858d8504831013b76163.png)

选择【稍后安装操作系统】  

![](../Images/6c3c51355f1c917026e3c9756b0415d6.png)

选择操作系统，Kali为Debian系列，VM12最新能识别到Debian 8.X  

![](../Images/071d8ff1eed2061d3eff90de98ef74ba.png)

选择虚拟机存储位置

![](../Images/52a12e93cf720307f7db314c21993b8c.png)

选择磁盘文件大小，一般默认20G，如果后期需要存储大量文件则选择调整  

![](../Images/24109b96bcbde4ef38c0bc91de50ee56.png)

点击【完成】  

![](../Images/d531f02007526ce76dcfc6f6714e7cc4.png)

点击【编辑虚拟机属性】，调整内存一般2G以上，选下载的ISO文件  

![](../Images/f090c84632d57997d36eb8694c7f8018.png)

点击【启动】开始安装  

![](../Images/c310ef1ebd9d5415abfa69b9b6a07bb2.png)

选择【图形界面】的安装模式，可以选择**中文**或**英文**（选择中文则需要安装增字体设置默认字体）

![](../Images/2081e7ec6934624d3443de36f97ae08e.png)

剩余的步骤就是下一步，下一步，傻瓜式的安装完成即可  

![](../Images/51567f40bf680e59b906eb8588ceb16b.png)

如果选择安装时使用的是中文版本，需要编辑更新源，然后设置字体

*   
*   
*   
*   
*   
*   
*   

```
vim /etc/apt/sources.list# 写入如下下两行内容，默认安装完毕是不存在源地址的deb http://http.kali.org/kali kali-rolling main non-free contribdeb-src http://http.kali.org/kali kali-rolling main non-free contrib# 设置完毕后，执行下面的更新命令apt-get update && apt-get upgrade && apt-get cleandpkg-reconfigure locales
```

进入图形界面，选中en\_US.UTF-8 UTF-8和zh\_CN.UTF-8 UTF-8（空格是选择，tab是切换，\*是选中）并将en\_US.UTF-8选为默认。

![](../Images/fb231ec047788006b0ed50239e1dbdd7.png)

安装中文字体  

*   
*   

```
root@kali:~#apt-get install xfonts-intl-chineseroot@kali:~#apt-get install ttf-wqy-microhei
```

重启系统后即可看到变成中文字体了
