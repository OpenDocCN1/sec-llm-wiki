什么是渗透测试

渗透测试 (Penetration Test, 简称 PenTest) 是通过模拟Hacker的攻击方法，来评估计算机网络系统安全的一种评估方法。这个过程是对系统的任何弱点、技术缺陷或漏洞进行的主动分析，这个分析是从一个攻击者角度来进行的，以非常规思路、非体制内视角、非专业内角度来窥视目标的最为薄弱之处。


从何处入手学习

了解渗透测试的体系框架是非常重要的一步，从全景上认识这门技术，避免从一开始就走错方向浪费时间。我们将系统地介绍渗透测试流程和各个环节的要点和痛点，从明确目标，然后以工具使用为切入点，使用工具门槛低、容易上手和产生成就感。通过工具和基础知识的加强，从练习渗透靶机开始，逐步掌握渗透测试的各方面技能。


什么是Hacker/骇客

Hacker，指技术高超的程序员或是精通网络入侵的人。

黑帽Hacker（又叫骇客）：试图破解某个程序、系统或网络，进而窃盗、毁损、牟利或使其瘫痪的人。

白帽Hacker（又叫白客,又称为白帽子），是那些用自己的Hacker技术来维护网络关系公平正义的Hacker。李纳斯·托沃兹 (Linus Torvalds), 是Linux之父 , 有名的白帽Hacker 之一。


我需要学会编程吗

需要。当进入中高级阶段，对于特定任务和没有现成脚本情况下，就需要自己写脚本，推荐学习脚本语言python, 首先它上手快和功能强，便于安装和调试，而且网上有大量的现成的库和例子可供使用。在自动化测试这门课里，学会Python已经成为标配。


预备知识

如果不想成为脚本小子这类，就好好的把基础学扎实。


  1. 计算机网络：了解网络的构架以及其中知识是必要的

  2. HTTP&HTTPS协议：Web页面采用的传输协议

  3. 操作系统 服务器所用的系统平台  没必要深入，但必须了解

  4. HTML&CSS&JavaScript&PHP，囊括前端后台，需要了解

  5. SQL语言：数据库操作

  6. Python：非常流行的语言


Web漏洞

SQL注入，文件上传，xss，csrf，一句话木马等相关概念先有一定的了解，然后再具体学习相关的安全技术(听说护网，80%都是从Web切入的，要学的很多，要多总结哟)。

  • Brute Force：暴力破解，对于弱口令使用

  • Command Injection：命令注入，针对某些使用命令行的功能

  • CSRF：跨站请求伪造，可获取用户的相关凭证

  • File Inclusion  文件包含，利用某些敏感文件

  • File Update：文件上传，上传木马的途径

  • SQL Injection：SQL注入，获取敏感信息

  • XSS：跨站脚本攻击，能取得一些敏感信息


其他漏洞

除了web漏洞外还需要了解各类应用、中间件、主机、操作系统、设备、智能终端等中的各类漏洞（除了Web渗透还有，主机渗透、内网渗透、社会工程学等等）。

  • 代码执行：遇到RCE（远程代码执行很嗨哟，MS17010）

  • 越权访问:轻轻松从普通用户即可跳到管理员（垂直越权，别忘了横向越权）

  • 敏感信息泄露：开发人员总是自认为“安全”，某个密码文件轻轻松松就能访问

  • 反序列化：最近很流行，Struts2已经成为其代名词

  • 缓冲区溢出：很多提权漏洞都是由于缓冲区超了！！

  • 人性弱点：贪婪、好奇、缺判断（社会工程学完好了可一往无前）
