# 小草空间丨校企交流研讨会 · 四叶草安全专场

**4月13日下午，由西安高新区人力资源行业协会主办、四叶草安全承办的2022年高校领导走访用人单位活动——校企交流研讨会·四叶草安全专场，在四叶草安全公司举办。**

  

![](../Images/d25fdddaeedd4f1828a0295edfd1b0b4.png)

  

会议围绕数字时代下的网络安全人才培养实践的主题，探讨校企之间“人才共育、资源共享、优势互补、协同发展”的深度合作模式。座谈会邀请了**西安科技大学高新学院、陕西科技大学镐京学院、延安大学西安创新学院、西安明德理工学院**等多家院校领导参加。

  

此前，教育部办公厅发布“关于开展全国高校书记校长访企拓岗促就业专项行动的通知”，号召发挥高校书记、校（院）长以及校领导班子成员带头做好毕业生就业工作的重要示范作用。

 

四叶草安全第一时间响应政策，将充分发挥生态资源优势，积极配合教育部开展的专项行动，搭建校企合作平台，促进教育链、人才链与产业链的有效衔接，探讨技术变革和产业优化升级方向，企业用人需求及人才培养模式创新等，与各大院校一同致力于提高人才培养质量，为广大毕业生提供更多就业机会。

  

  

座谈会上，四叶草安全创研中心的工作人员向高校领导介绍了四叶草安全的发展历程、安全产品及技术能力。同时，详尽阐述了**中心在人才培养体系、产品&平台、校企合作、实验室建设等方面的布局规划与实践成果。**

  

  

  

![](../Images/7909eba7279a7054ac538f65ea71136f.png)

  

![](../Images/24b1db474eec418c0d9ac5017d2e7f7a.png)

  

高校领导对中心在网安人才培养领域的专业度给予了高度认可，表示将以此次座谈会为契机，将与四叶草安全保持密切沟通，共同促进供需对接，学生就业等事宜，全面深化校企合作。
