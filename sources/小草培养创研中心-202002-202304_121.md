# 四叶草安全积极响应“教育部关于职业教育相关工作”，助力院校提质培优

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMDAwNzM3MQ==&mid=2247500355&idx=1&sn=cd385147b716142e4731d5bb9a79ecba&chksm=9769a667a01e2f7157b9870925048f0083a5e5b85598c02f95b5672b04c1a1825eb3a263a719&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxMDAwNzM3MQ==&mid=2247500355&idx=1&sn=cd385147b716142e4731d5bb9a79ecba&chksm=9769a667a01e2f7157b9870925048f0083a5e5b85598c02f95b5672b04c1a1825eb3a263a719&scene=27#wechat_redirect)

近日，教育部职成司印发了《职业教育与继续教育2022年工作要点》，文件指出：要深入贯彻落实习近平总书记关于职业教育工作的重要指示和全国职业教育大会精神。

  

按照《关于推动现代职业教育高质量发展的意见》《职业教育提质培优行动计划（2020-2023）》《国家职业教育改革实施方案》等文件精神，四叶草安全作为网络安全领域领先的实战创新企业，旗下网络安全人才培养与创新研究中心（以下简称创研中心）聚焦数字时代下的网络安全人才培养，将积极响应国家号召，助力职业院校开展2022年教育部部署的“关于职业教育与继续教育相关工作”。具体工作开展如下：

  

**1、数字赋能，助力职业院校开展网络安全相关专业的虚拟仿真实训基地建设，推动人才培养模式变革，提升教育质量。**

  

职业教育虚拟仿真实训基地建设是在数字中国，网络强国和现代教育理念指导下，通过虚拟化和数字化技术，深化教育教学改革创新，推进网络安全人才培养模式创新。创研中心提供关于网络技术相关专业的虚拟仿真实训基地建设综合解决方案，打造沉浸式体验学习环境，创新工学结合，学训一体的数字化教学方式，为师生提供智能化、个性化的新型教育教学环境，培养更多，更优秀，高质量的复合型人才。

  

虚拟仿真实训基地建设是基于专业要求，打造成集教学、实训、培训、科研、考核、科普等功能于一体的综合性实训平台，基于专业要求对行业场景和业务环境等进行虚拟化，让技术从实战得到训练，让行业需求与教学高度匹配，让岗位技能与专业高度结合，从而更有效且便捷的提升学生的学习积极性和技能实操能力，达到整体提升专业建设水平和人才培养质量的效果。

  

**2、资源赋能，协助高职学校书记、校长深入企业，开展“用人单位交流活动”**

  

深化产教融合对于全面提高职业教育质量、扩大就业创业、促进经济转型发展、培育经济发展新动能具有重要意义。为响应教育部和各省级教育行政部门关于“高职学校书记、校长拜访用人单位活动”的号召，创研中心将发挥生态资源优势，积极协助组织全国职业院校的书记、校长深入我司及生态伙伴企业的调研、参观、交流等系列活动，不断深化产教融合，校企合作。

  

四叶草安全拥有智库专家资源、行业协会资源，知名高校资源、生态伙伴资源及会议活动资源等， 可以提供一站式的参观交流活动服务，搭建校企合作平台，促进教育链、人才链与产业链的有效衔接，探讨技术变革和产业优化升级方向，企业用人需求及人才培养模式创新等，与各大院校一同致力于加快高素质职业技能人才培养。同时，四叶草安全还可提供免费的咨询服务团队，参与到学校相关专业的建设当中。
