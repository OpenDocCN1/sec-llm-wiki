**国产刷星软件上GitHub遭热议**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

2020年12月30日，国产开源软件“有偿刷星”再度被推上风口浪尖。近日，某开发者平台在其官网上线了“你点star，我送豪礼”的宣传推广活动，以鼓励用户使用其平台并达到促活的作用，据活动规则显示，用户在 GitHub 上为某知名开源项目点击 “Star”，会收到平台的红包奖励，而作为已经在GitHub上存在的有偿开源项目，“有偿刷星”明显违背了活动本意，使得本次活动公正性无法得到保障，不过没多久，这场营销活动就招来了一片骂声。有开发者表示，SKT 是在滥用 Star，其行为有损项目贡献者的努力，也会对开源生态环境造成危害。最后迫于舆论的压力，SKT 不得不提前终止了活动，并发表了道歉声明。

**越南遭遇攻击，损失或达数十亿**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

1月1日，越南官方机构网站遭遇了攻击，一群神秘的黑客通过在越南一个官方的政府软件数字签名工具包植入恶意代码，对越南私营企业和政府机构发起了一场复杂的供应链攻击。安全公司ESET发现了本次攻击，并在一份名为“Operation SignSight”的报告中详细描述称，攻击的目标是越南政府认证机构（VGCA），即该政府机构发布可用于电子签署官方文件的数字证书。直到目前，攻击的安全威胁在范围和严重性上都有所扩大。如果信息安全处理不当，可能会有损失数百万甚至数十亿美元的风险。

**光荣特库摩关闭美国与英国官网**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

1月4日，日本游戏发行商光荣特库摩在圣诞假期期间遭遇了黑客攻击，英文官网的六万五千名用户个人数据遭泄。公司目前决定暂时关闭美国与英国官网。光荣特库摩在12月25日的时候发布官方声明表示：“KTE运营的官方网站，‘Forum’页面和注册用户的信息（约65000条）或已全部泄露。用户数据中的账户名（可选填）和关联密码（已加密）和注册邮箱地址都存在泄露的可能。”本次遭遇到黑客入侵的是光荣特库摩的论坛页面，其中并不含任何信用卡信息。光荣特库摩补充表示，目前尚不清楚黑客身份，而且这次攻击勒索赎金的可能性较低。

![](../Images/ac52d46b424e6865dc6fca71151d9d7c.png)

  
  

  

**影响10万台设备的Zyxel账号**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

1月4日，据外网论坛爆料称，受国外企业青睐的网络设备制造商Zyxel旗下蟾皮内设备存在安全隐患，超过10万Zyxel防火墙、VPN网关和接入点控制器包含一个硬编码的管理级后门帐户，而这个账户的用户名、密码在一个系统的二进制文件中，是以明文形式存在的。攻击者可以通过SSH接口或web管理面板授予攻击者对设备的根访问权限。这个后门账户是由荷兰一组来自眼控的安全研究人员发现的，从漏洞的角度来看，它被认为是非常糟糕的。

![](../Images/777867ba365bb216c60f9488f8338794.png)

  
  

  

**特斯拉新车数据泄露**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

近日，近日有黑客无意从特斯拉数据库中的自动驾驶代码中，发现特斯拉将要量产的卡车图片。这一曝光让埃隆·马斯克大为恼火。黑客不仅截取到新车详细图片样板，还有新车的命名等相关数据信息，并且还公布了该车的摄像头位置等诸多细节。而次图片在网上得到了众多网友的肯定和回复，并声称看到过相关的伪装测试车辆，这两被命名为semi的测试车图片在公布后，其公司工程师默认了图片的真实性，而其中关于此车辆的其他信息也在公布信息之中。

![](../Images/831b0c47b4d4e5006622876a674481bb.png)

  
  

  

**东京奥组委计划培养220名“白色黑客”**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

据4日共同社发布消息称，约半年后将迎来东京奥运会和残奥会开幕式的奥组委已经培养了220名“白色黑客”（即白帽子、红客或称为正义黑客）作为应对网络攻击的工作人员。以发生大规模系统故障的平昌冬奥会为教训，东京奥组委设想全球瞩目的开幕式等遭到攻击的情况，打算以培养的人才为核心保障赛事运营。奥组委的白色黑客主要从NTT和NEC等民间企业借调。日本国立研究开发法人“情报通信研究机构”通过名为“Cyber Colosseo”的训练项目等进行培养。课程包括20个科目，演习采用分为敌我双方、在网络攻击中保卫系统等实战形式以掌握应对方法。

![](../Images/0079bf09cd13d389f60434a5720939de.png)

**ReCaptcha漏洞可以绕过音频验证码**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

1月4日，谷歌相关研究人员发现了一个可以让攻击者使用语音脚本绕过任何语音障碍的漏洞，在本次攻击中，攻击者通过获取音频reCAPTCHA的MP3文件，并将其提交给Google自己的语音文本API进行绕路攻破，被称为Uncaptcha。该漏洞使用了语音到文本机制，以覆盖ReCaptcha向其发出的任何音频挑战(针对视障人士)，从而使自动脚本能够绕过这些障碍。它被命名为Uncaptcha，Google不久后就对它进行了修补。

![](../Images/8f3680eb2c8b8b098109cd94bc8d5b02.png)

  
  

  

**美国国家安全局指责俄罗斯入侵SolarWinds**

![](../Images/496b1d9585f02725d2d4e0396f6d1311.png)

  
  

近日，SolarWinds供应链攻击逐渐演变为美俄之间的角力，根据最新消息称，美国联邦调查局，CISA，ODNI和国安局发布了联合声明把责任归咎于俄罗斯SolarWinds供应链攻击。这四个机构代表特朗普总统参加了网络统一协调小组(UCG)工作队的工作，该小组正在协调对SolarWinds黑客的调查和补救工作，对联邦政府网络产生了重大影响。UCG的调查仍在进行中，以确定事件的范围。根据UCG的声明，这次袭击是由一名高级持续威胁(APT)演员策划的，很可能是来自俄罗斯。
