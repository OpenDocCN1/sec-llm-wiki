![](../Images/db6f66baf64e5db7ec32230782f5b79b.png)  

  

  

  
0 1 撰写简历  
  

  

  
  
在准备简历之前，你要具备信息搜集能力，先研究投递简历的目标公司以及岗位的相关信息，包括公司的基本信息、所在行业、主要业务、岗位职责和工作范畴。正如一次网络攻击实操，你需要选好目标靶机！了解求职目标，就要做好信息搜集，你的简历准备才能足够精准，也更加贴近目标岗位的要求。这样的简历通过率至少是普通简历的两倍。假如你不想投近100份简历，面试50家企业，最后只有2个offer，那么就在前期对公司和职位进行信息搜集的时候，就把那些不符合自己目标预期的公司和岗位给排除掉，比如选择网络安全领域的渗透测试工程师岗位，专注做好针对某几家公司特定职位的简历。

![](../Images/ce2d369b62ce885f112f4815d337bdec.png)

  
  
  

  

  
0 2 打磨你的面试作品  
  

  

  
  
面试作品，你是不是第一次听到这个术语啊！在面试前，把自己的面试作品打印装订，同时把目标求职公司的相关信息梳理清晰，最后有目标的去准备相关的专业知识。有一类情况，面试ok，但是呈现一般，就会留下不好的印象，会让对方误以为面试作品是找枪手做的。我们需要平等地看待面试官和自己，这里推荐STAR法则（情境(situation)、任务(task)、行动(action)、结果(result)），有真实的成功面试案例哦。还有一个亮点，对面试公司的业务信息（适用于非技术岗位）不仅要了解，最好是熟悉，结合公司具体的业务和岗位来展开你和面试官的交流，这是侧面展示你的个人能力的加分项哦。

![](../Images/e49ed765fc1ce99662d1e30b2f5d99e0.png)

  
  
  

  

  
0 3 实习实践经历  
  

  

  
  
同样在两个人条件相当的情况下，有实习实践经历的优势更大。即使一个人成绩再好，如果面试竞争方有一段含金量不错的实习实践经历而对方没有，必然会处于劣势了。因为职场很多时候考验的并不是维度你的技术有多过硬，而是看中综合素养能力，比如沟通协调能力，团队协作能力，个人抗压、抗挫折能力。一个走出校门不太懂套路的学生，拿学校那一套法则做事多半是走不顺畅的，学生思维需要一个环境再熏陶一次之后，再解决在社会中面临的问题。企业都希望招募到有工作经验的人，所以在正式毕业前，大学生找一份实习或实践机会，亲身参与项目并从中获取业务实操经验是非常重要的。偏见和困境或许会影响你我的判断，只有懂得择时放下，才能轻装前行，从容面对一切。生命不是固定模式，生命有其他无限可能。希望心中的梦想越来越鲜活，为自己想成为的样子而前行，请保留初心和信心，做对选择，让时间证明今天的自己一定胜过昨天的自己！
