WPscan

WPScan是一个扫描WordPress漏洞的黑盒子扫描器。该扫描器可以实现获取Wordpress站点用户名，获取安装的所有插件、主题，以及存在漏洞的插件、主题，并提供漏洞信息。同时还可以实现对未加防护的Wordpress站点暴力破解用户名密码。

0x01 参数选项

--update 更新到最新版本
--url   | -u要扫描的`WordPress`站点.
--force | -f   不检查网站运行的是不是`WordPress`
--enumerate | -e [option(s)] 枚举

0x02 工具利用

1、扫描WordPress漏洞

wpscan --url http://www.xxx.com/

2、扫描WordPress用户

wpscan --url http://www.xxx.com/ --enumerate u

3、扫描主题

wpscan --url http://www.xxx.com/ --enumerate t

扫描主题中的漏洞

wpscan --url http://www.xxx.com/ --enumerate vt

4、扫描插件漏洞

wpscan --url http://www.xxx.com/ --enumerate p

扫描插件中的漏洞

wpscan --url http://www.xxx.com/ --enumerate vp

5、使用wpscan进行暴力破解

在进行暴力破解之前需要创建对应的字典文件

wpscan --url https://www.xxxxx.com/ -e u --wordlist /root/桌面/password.txt

Arp-scan

扫描内网中存活的主机

常用命令

1、扫描本地所有存活主机

arp-scan -l / arp-scan 192.168.129.0/24

2、指定interface扫描

arp-scan --interface tun0

Netdiscover

Netdiscover是一个主动/被动的ARP侦查工具。该工具在不使用DHCP的无线网络上非常有用。使用netdiscover工具可以在网络上扫描IP地址，ARP侦查工具netdiscover检查在线主机或搜索为它们发送的ARP请求。

1、主动

netdiscover -i eth0 -r 192.168.129.0/24

2、被动

netdiscover -p


Dirb

dirb是一个类似windows下御剑这些目录扫描工具

1、正常扫描

dirb 目标 字典路径

2、设置ua和cookie

dirb 目标 字典路径 -a "ua" -c "cookie"

3、使用代理和输出结果

dirb 目标 字典路径 -p ip:port -o result.txt


4、设置附加后缀

dirb 目标 字典路径 -X test(这样每个被测试的字典都附加test)

5、设置毫秒延迟

dirb 目标 字典路径 -z 1000(1秒)


Cewl

cewl是一个ruby应用，爬行指定url的指定深度。也可以跟一个外部链接，结果会返回一个单词列表，这个列表可以扔到John the ripper工具里进行密码破解。

1、默认方法

爬行给定的url，指定爬行深度，并且输出单词列表，这个列表可以用作破解密码的字典。

cewl http://xxx/

2、存储字典

cewl http://xxx/ -w dict.txt

3、生成指定长度的字典

爬行给定网站，然后输出最少是x个字符的单词列表

cewl http://xxx/ -m x

4、从网站获取email地址

使用-e参数来启用邮件参数，配合-n参数使用，-n参数是在爬行给定网站时隐藏生成的单词列表cewl http://xxx/ -n -e

5、计算网站中重复的次数

统计网站中重复出现好几次的单词的数量

cewl http://xxx/ -c

6、增加爬行深度

增加爬行等级，来遍历网站中更多的单词来生成更大的字典，默认是2

cewl http://xxx/ -d 3

7、Verbose模式

扩大网站的爬行结果来获取网站更加完整详细的信息，它不会生成字典，而是会dump网站上的信息。

cewl htt://xxx/ -v

8、生成字母数字字典

cewl http://xxx/ --with-numbers

9、绕过认证

如果存在一个认证页面来登录网站，那么上面的配置就行不通了，为了生成字典，可以使用下面的参数来绕过认证页面

cewl http://xxx/ --auth_type Digest --auth_user username --auth_path password -v

或者

ceal http://xxx/ --auth_type basic --auth_user username --auth_pass password -v

10、代理URL

如果网站使用了代理服务器，那么cewl的默认命令就无法生成字典了，使用—proxy参数来开启代理URL

cewl --proxy_host 192.168.1.103 --proxy_port 3128 -w dict.txt http://192.168.1.103/wordpress/


NMap 常用命令

NMap，也就是Network Mapper，是Linux下的网络扫描和嗅探工具包。nmap是在网络安全渗透测试中经常会用到的强大的扫描器。

1、获取远程主机的系统类型及开放端口

nmap -sS -P0 -sV -O -A -v

-sS         //TCP SYN 扫描（又称半开放或隐身扫描）
-P0         //允许你关闭 ICMP pings
-sV         //打开系统版本检测
-O         //尝试识别远程操作系统
-A         //同时打开操作系统指纹和版本检测
-v         //详细输出扫描情况

2、列出开放了指定端口的主机列表

nmap -sT -p 80 -oG - 192.168.129.* | grep open

3、在网络寻找所有在线主机

nmap -sP 192.168.129.0/24

4、Ping指定范围内的IP地址

nmap -sP 192.168.129.100-254

5、扫描一个.txt文件内的IP地址列表

nmap -iL target.txt

Droopescan

Droopescan是一款基于插件的扫描器，可帮助安全研究人员发现Drupal，SilverStripe，Wordpress，Joomla（枚举版本信息和可利用URL地址）和Moodle的问题。

1、指定特定的主机扫描

droopescan scan drupal -u http://xxx/ 其中drupal可省略并触发“CMS识别”

2、扫描多个url

droopescan scan drupal -U list_of_urls.txt

Hydra

Hydra是世界顶级的密码暴力破解工具，支持几乎所有协议的在线密码破解，功能强大，密码能否被破解的关键取决于破解字典是否足够强大。

1、破解ssh

hydra -L username.txt -P passwd.txt ip ssh

2、破解ftp

hydra ip ftp -L username.txt -o result.txt

3、破解telnet

hydra ip telnet -L username.txt -P passwd.txt

4、破解RDP（远程连接）

hydra ip rdp -L username.txt -P passwd.txt -V（-V 显示详细破解过程）

Enum4linux

Enum4linux是一个用于枚举来自Windows和Samba系统的信息的工具。

1、参数选项

-U       获取用户列表
-M       获取机器列表*
-S       获取共享列表
-P       获取密码策略信息
-G       获取组和成员列表
-d       详述适用于-U和-S
-u user   用户指定要使用的用户名（默认""）
-p pass   指定要使用的密码（默认为""）
-a       做所有简单枚举（-U -S -G -P -r -o -n -i），如果您没有提           供任何其他选项，则启用此选项
-h       显示此帮助消息并退出
-r       通过RID循环枚举用户
-R range RID范围要枚举（默认值：500-550,1000-1050，隐含-r）
-K n     继续搜索RID，直到n个连续的RID与用户名不对应，Impies RID范           围结束于999999.对DC有用
-l       通过LDAP 389 / TCP获取一些（有限的）信息（仅适用于DN）
-s       文件暴力猜测共享名称
-k user   远程系统上存在的用户（默认值：administrator，guest，               krbtgt，domain admins，root，bin，none）
        用于获取sid与“lookupsid known_username”
        使用逗号尝试几个用户：“-k admin，user1，user2”
-o       获取操作系统信息
-i       获取打印机信息
-w wrkg   手动指定工作组（通常自动找到）
-n       做一个nmblookup（类似于nbtstat）
-v       详细输出，显示正在运行的完整命令（net，rpcclient等）

2、常用命令

enum4linux -a -o 192.168.129.165
