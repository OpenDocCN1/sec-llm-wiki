## **靶机目标**

获取web端的8个flag

## **利用工具**

nmap、dirb、base64解码工具、ssh、steghide、burp、binwalk、volatility

## **操作过程**

直接访问可以看到首页  

![](../Images/0914f6cf1e85f8c27c530b282dcab522.png)

往下翻可以看到这8个flag的提示  

![](../Images/cab09639c49a503d59b8e53b5ed60f5a.png)

#### **flag1**

直接f12可以看到一个被注释掉的js链接

![](../Images/fb2c0a72cf7920175de2585b4ab1f135.png)

访问可以看到js源码

![](../Images/553558fd37b24d66788a7cb74a769252.png)

首行

```

666c61677b37633031333230373061306566373164353432363633653964633166356465657d
```

其中有数字，字母a-f。在联想flag1的提示与hex有关。将这串字符拿去十六进制解码，获得第一个flag      

```

 flag{7c0132070a0ef71d542663e9dc1f5dee}
```

![](../Images/51d6ef9429d55229511c0bf2d3e0e0f4.png)

将flag1的内容md5解密，获得nmap，下一个flag和nmap有关

#### **flag2**

nmap扫端口可以发现，22端口关闭，22222端口开着，尝试ssh连接它`ssh`

```
 192
```

然后获得第二个flag

![](../Images/0142c9b4e57a7d5a7dd23aa71d5ac098.png)

![](../Images/8f369f6090ad7197027e547a64f1e4eb.png)

  

将flag2值md5解密，获取到encrypt  ,flag3和加密有关

#### **flag3**

上面flag线索是加密，拦截，然后联想到开放了443端口，然后尝试访问`https://192.168.180.15`查看证书

  

![](../Images/98e083a8b198b55f54cf5aeaa8e5b58c.png)

在证书的颁发者里面获得到第三个flag

![](../Images/5c9a00ccb32a337c9daf4227e0463d9f.png)

将flag3的值去md5解密，获得personnel  

#### **flag4**

前面获取到的提示是代理，从flag3获取到的是personnel，不太搭猜测personnel是目录，访问它

![](../Images/6ab880ef283463f0865bd2907bd6c73f.png)提示拒绝访问，这里应该是需要挂代理伪造，结合第一个flag里面的IE4，应该是需要伪造ua头。

直接在burp里面伪造UA头  

![](../Images/7b58062b6071ae589dd4c2061b6afb28.png)

然后抓包，将里面的6.0修改为4.0成功访问personnel目录  

![](../Images/aca582921eee9591021be8c143f0b0aa.png)

终于在进入这个页面以后获得了第四个flag flag{14e10d570047667f904261e6d08f520f}  

![](../Images/d00f1f63d946d1d2766ade758ddd2f19.png)

  

这里提示线索是 new+flag

flag值md5解密以后是evidence

#### **flag5**

上个flag线索是newevidence，尝试访问一下这个目录，存在

![](../Images/eaebd5edc45da193cc1cfe58ce5720fb.png)

用户名可以想到上面访问personnel时，有个欢迎页面，hanratty在结合猫鼠游戏电影里面的探员，可以确定一个用户名carl.hanratty 密码直接爆破把

![](../Images/bc95762996200b780eb21babc9cef249.png)

爆破得到密码 Grace 然后修改UA头登陆，登陆后发现3个新证据

![](../Images/b5e6403809f52db944a0d8a3624136a4.png)

在第一个证据里面获得flag     flag{117c240d49f54096413dd64280399ea9}        

该flag值md5解密以后获得panam

#### **flag6**

然后继续看剩下的证据 第二个证据是个图片，第三个证据是一个pdf，pdf没什么特别的，图片的话涉及到图片隐写，然后将图片下载到kali，使用steghide命令分析，然后发现需要输入密码  

![](../Images/f0f826036aeea036e81d5272176cb075.png)

这时候想到刚才我们获得到的panam，尝试将它当成密码输入，然后输出了flag.txt

![](../Images/79ad2c6f26f5c262bc1952bd3b420f5b.png)

然后使用`steghide extract -sf image.jpg`输出并查看flag.txt

![](../Images/d71f4c1c84893d33092f9d8f9d26af24.png)

获得flag6   flag{d1e5146b171928731385eb7ea38c37b8}

#### **flag7**

猜测flag6里面的提示不是用户名密码就是目录，测试发现不是目录，应该是用户名密码

看一下第七条的提示弗兰克被摄像机拍到，大喊，我是活着的最快的人！

将喊得那句话英文原文拿去百度，这是闪电侠barry.allen说的一句话，这里用户名应该是barry和allen组合

密码应该是ILoveFrance或者iheartbrenda中的一个iheartbrenda

可以登陆的地方只有22222端口了吧  尝试登陆。以barryallen/iheartbrenda登陆成功，然后直接读取flag.txt获取到第7个flag

  

![](../Images/f978d9cfac34a17e89908866a75fe4c4.png)

#### **flag8**

目录底下还有一个data的文件 第8个flag应该是和这个有关，先将它下载到本地kali

然后使用binwalk分析一下该文件，发现这个是一个zip的文件，然后将后缀修改为zip，并顺手解压

![](../Images/94237bd97cac89480a26a3e2dc763dd3.png)

解压出来`security-system.data`联想到最开始提示第8个flag提示中提到了 Memory （内存）猜想应该是某一台机器的内存映像，

然后使用volatility进行分析

volatility imageinfo -f security-system.data imageinfo 获取一些基本信息

![](../Images/dacd721bd3e1ea5d0f57b009076a5610.png)

然后查看一下内存里留下的历史命令

volatility --profile=WinXPSP2x86 -f security-system.data cmdscan

![](../Images/e8702b1e7ca4723172d7463c4516f3b9.png)

这里获得了一些字符串，将它复制下来去掉空格，然后hex解码得到flag  

![](../Images/42c44e90eece5ea482b4681e452e3246.png)

flag{841dd3db29b0fbbd89c7b5be768cdc81}
