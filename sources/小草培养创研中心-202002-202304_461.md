## **靶场搭建：**

下载链接：https://download.vulnhub.com/lazysysadmin/Lazysysadmin.zip

下载完解压导入虚拟机，选择文件->打开->找到ovf文件  

![](../Images/4e982f70e71444bfcfeb08624e44a87c.png)

然后使用nat模式即可。

#### **00x0: 信息收集**

1.使用kali工具netdiscover 发现靶机IP 为192.168.42.133  

﻿![](../Images/7a6f85e8a1c02131810d7915dd7b517e.png)  

2.端口扫描：nmap -T4 -v 192.168.42.133  

﻿![](../Images/0bbb8ac4a8c98a25aed68a6539b5cc6b.png)  

开放了22，80，139，445，3306，6667端口。

3.目录扫描：dirb http://192.168.42.133

http://192.168.42.133/index.html

http://192.168.42.133/info.php

http://192.168.42.133/robots.txt      

http://192.168.42.133/wordpress/                                

http://192.168.42.133/wordpress/wp-login.php

http://192.168.42.133/phpmyadmin/                                                        

4.敏感信息：

My name is togie、目录遍历、smb未授权访问。

总结：对扫描出来的目录进行分析

扫描出来info.php文件，浏览器访问,下图可以看到目标存在信息泄露漏洞。  

﻿![](../Images/dde884afb6e007a800b9ff3410e7e5b2.png)  

扫描出来/phpmyadmin/目录，浏览器访问,可以看到是mysql的后台登录界面,尝试弱口令或者暴力破解。

﻿![](../Images/6880ab407f79d5b56686e5ab669d3010.png)

扫描发现wordpress ,浏览器访问，发现其中含有疑似用户名的信息。  

﻿![](../Images/087455c45f057cd772dd56523c94099a.png)  

尝试登录wordpress的默认后台管理页面wp-login.php

![](../Images/d6b2e3953675db6376ce7a5a621de494.png)  

尝试输入一些简单的弱口令,提示如下错误信息,发现用户名是admin,此处存在用户名名枚举漏洞,然后尝试暴力破解密码

使用wpscan扫描http://192.168.42.133/wordpress 看是否含有漏洞

 Vp 只枚举有漏洞的插件，vt只枚举存在漏洞的主题，tt列举缩略图相关的文件

#### **00x1:SMB 未授权访问**

在信息收集的过程中发现未授权访问。  

![](../Images/10bfa581e0181223a370f48aa1dd9f6e.png)  

使用 enum4linux 枚举发现帐号密码都是空  

﻿![](../Images/672c766c49c1b3eb4802d346964b4ea7.png)  

2.远程挂载，发现是网站的根目录

mount -t cifs -o username=' ',password=' ' //192.168.42.133/share$ /mnt

![](../Images/f205c553924c212ca07f580523a185ab.png)  

![](../Images/13f88bfd0c18e81bb5713f7027d0f467.png)

也可以使用smbclient 客户端或者window系统连接：

![](../Images/2c79f7ac2bdee1fbcf075ecd6b74edc9.png)﻿接下来找到了网站的账号密码及提示信息

![](../Images/814f4de623fe138c97021b5f012ea9e3.png)

提示的密码：

![](../Images/ba0a4e5b1eacfc3aa360ab6031ba4a8a.png)﻿证明存在SMB未授权访问。

#### **00x2:登陆 PHPMyadmin**

使用刚才得到的用户名和密码登录phpmyadmin，发现没什么用，不能getshell（大家可以自行尝试一下phpmyadmin一些getshell的方法）。

![](../Images/8a44fc549114bbbf42f2a708836ec95f.png)

**﻿00x3:Wordpress 后台Getshell**  

利用前期信息收集得到的后台http://192.168.42.133/wordpress/wp-login.php进行登录。

尝试手工弱口令爆破无果，发现存在此按钮。

![](../Images/0b64bfc537d00ecf956ffd93cd86de21.png)

﻿点击之后发现此页面有很多的My name is togie，所以才想这可能是登陆的一部分信息。  

![](../Images/087455c45f057cd772dd56523c94099a.png)

再次尝试登录还是未成功。这时使用之前得到的配置文件的Admin和Togie12345^^登陆成功。  

此版本的后台可以通过后台编辑Getshell，这里我编辑的是404页面。插入一句话并保存设置。

![](../Images/e0476002ab05cb0d0d06c9690b6e5647.png)

﻿可以看到一句话已经插进去了。（可以通过第一个未授权访问来查看具体的目录）  

![](../Images/d052210c3b5a7e6032dfea1b462c9106.png)

使用菜刀连接即可。  

![](../Images/b43956b387e9c04829172b3f8e3baa56.png)

﻿通过WordPress已经成功的Getshell了。

#### **00x4:爆破SSH端口**

根据之前得到的信息有123456，Admin和Togie12345^^，My name is togie。

使用hydra爆破ssh。（在实战中收集用户名、电话、邮箱等信息来制作特定字典进行爆破也是比较有效的。）

![](../Images/a95deb8848f33586e57fb62b37b18e3d.png)

成功获取到了用户名和密码并成功登录。

![](../Images/a868fb27b1d510e9d52c5fb5fcbb1336.png)

﻿提权，这里试了一下发现可以直接提权。
