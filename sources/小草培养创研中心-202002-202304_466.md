# CVE-2020-10560 OSSN任意文件读取漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMDAwNzM3MQ==&mid=2247484811&idx=1&sn=3ba27a1758ccf17eff1a405bfa60d221&chksm=976a61afa01de8b9147376df154396055b166c3c9705f685bc2420cfba38e1442bd83efaed3d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxMDAwNzM3MQ==&mid=2247484811&idx=1&sn=3ba27a1758ccf17eff1a405bfa60d221&chksm=976a61afa01de8b9147376df154396055b166c3c9705f685bc2420cfba38e1442bd83efaed3d&scene=27#wechat_redirect)

**【漏洞详情】**  

*   CVE-2020-10560 OSSN任意文件读取漏洞，问题出现在Open Source Social Network(OSSN)5.3及之前版本中。攻击者可通过对site\_key实施暴力破解攻击来为components/OssnComments/ossn\_com.php和libraries/ossn.lib.upgrade.php插入特制的URL，然后利用该漏洞读取任意文件。
    

**【环境搭建】**

*   1.首先通过git命令从github上下载OSSN环境，这里是通过docker搭建漏洞复现环境。git clone https://github.com/kevthehermit/CVE-2020-10560  
    
    ![](../Images/8c0ab56b686ee776f25cbc2665702d48.png)
    
*   2.然后使用docker-compose编译启动OSSN环境。注意：如果这里编译时，提示api版本不匹配，建议卸载安装旧版本docker。
    

![](../Images/8cef3a2e99f2ff9842ab80466d9ddc5d.png)  

*   3.编译启动完成，使用docker ps查看，表示环境启动成功。
    

![](../Images/9709c16cd0c86fb29b3defe0313f715f.png)  

*   4.使用通过浏览器访问OSSN环境，需要进行安装，点击下一步。
    

![](../Images/ba16a873b6838a87bd0bad3c6b442e65.png)

![](../Images/604abf699501175a6a48a9e639e6ce10.png)  

*   5.点击下一步。
    

![](../Images/7e8b4fed01e9eaa9e88292657f2619ba.png)

![](../Images/604abf699501175a6a48a9e639e6ce10.png)

*   6.进行网站设置，需要填写数据库信息和网站信息（网站名称和邮箱可以随便填写），点击下一步。
    
    ```
    		注意：这里的数据库信息填写如下：		DB: ossn		username: ossn		password: ossn		host: mysqlserver
    ```
    

![](../Images/11f8b076ee657e78bb21529382fbaf1d.png)  

*   7.创建管理账户，按要求填写即可。
    

![](../Images/6e88f489566bce82e8a5b4ac1aa95132.png)  

*   8.环境搭建完成。

**【验证详情】**

*   验证条件
    
*   首先需要获取site\_key的值，在实际环境中可以通过脚本爆破的方式来获取，site\_key爆破脚本参考链接：https://github.com/LucidUnicorn/CVE-2020-10560-Key-Recovery/releases
    
*   因为这里我们是在本地使用docker搭建的复现环境，我们直接取数据库查询site\_key值即可。
    
*   1.可以看到这里有一个mysql的主机，使用mysql用户名和密码连接数据库（ossn/ossn）。
    

![](../Images/af9f8f5243d5982b3cecbdf377767937.png)  

*   2.查询数据库中的表ossn\_ site\_settings，找到site \_key的值。
    

![](../Images/9754eb3b5b0a9a7fe9e1c08fbcf7f395.png)![](../Images/a215465365402ff251b3a5fe6ce4cd97.png)

*   验证过程
    
*   1.复制刚才我们从github上下载的poc进行漏洞利用。
    

![](../Images/776c2117e2fbc4a35aefa850d8051a3a.png)  

*   2.然后使用python3执行脚本，依次填写site\_key，读取的文件，目标网站地址，可以看到成功读取到了目标系统的passwd文件内容。  
    

![](../Images/25f3814dda6b8086f04fb86d703c69fe.png)
