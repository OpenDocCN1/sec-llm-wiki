### 0x01 反序列化  

回顾一下PHP的魔术方法：

`__construct()`(构造函数)：在对象创建时调用

`__destruct()`(析构函数)：在对象销毁时调用

`__toString()`：在对象被当做字符串时自动被调用

`__sleep()`：将对象序列化时调用

`__wakeup`：将字符串反序列化为对象时调用

`__call()`：当调用一个对象中的不能用的方法的时调用

#### CRLF  

成因查看官方文档：

```


public SoapClient::SoapClient ( mixed $wsdl \[, array $options \] )


```

![](../Images/aeffbeea02fdf630c2aaa0576e229d11.png)

其中可以看到有一个`User-Agent`，我们可以自定义`User-Agent`  

我们可以看到上边soap的数据包，在`User-Agent`下边的http header有`Content-Type为`和`Content-Length`如果我们想要进行CRLF注入，则要控制这两个字段

因此我们可以利用`SoapClient`利用CRLF发送如下post请求：

```


$payload \= new SoapClient(null,array('user\_agent'\=>"test\\r\\nCookie: PHPSESSID=08jl0ttu86a5jgda8cnhjtvq32\\r\\nContent-Type: application/x-www-form-urlencoded\\r\\nContent-Length:45\\r\\n\\r\\nusername=admin&password=nu1ladmin&code=470837\\r\\n\\r\\n\\r\\n",'location'\=>$location,

```
'uri'\=>$uri));
```


```

从而造成CRLF攻击

#### 组合拳

既然可以进行CRLF注入，假设我们可以调用soap，目标是内网主机，那么我们就可以在外网利用CRLF进行SQL注入、命令执行等手法攻击内网机器，造成了SSRF。
