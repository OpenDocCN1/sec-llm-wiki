在公众号后台回复Nessus即可获取下载链接！

新版Nessus目前没有破解，安装完成后请不要更新！

  
  
软件安装![](../Images/33d56c9bfa25f365e5d4e5c994f83692.png)  
  
  
  

1.先将Nessus安装包下载到本地

![](../Images/12645361e4a0ab499a1285cd3b71161e.png)

2.输入在微信公众号“小资青年Ai4”获取的解压密码进行解压。

![](../Images/628a6b8915c0a3dcc48c02296dda4322.png)

3.解压后得到如下两个文件：

![](../Images/7c68bcfe558af4d47478d2001b92e941.png)

4.将Nessus安装包移动到kali中：

![](../Images/bf5f3642ef71ea3e49a389fa60ce72bc.png)

5.运行“ sudo mv Nessus-8.10.1-debian6\_amd64.deb /opt/ ”命令，将安装包移动到“ /opt ”下：

![](../Images/3e80ac0a1d578cb169cd48995aab3000.png)

6.运行“ sudo dpkg -i Nessus-8.10.1-debian6\_amd64.deb ”命令开始安装Nessus。

![](../Images/fdecadb43d51455b01c77a2b3bba8715.png)

7.安装完成后运行“ sudo /etc/init.d/nessusd start ”命令运行Nessus：

![](../Images/c41a70bb2dc5a51f5e5d74d5c8ae35c0.png)

8.打开kali中的浏览器访问：https://127.0.0.1:8834 选择“高级”，“继续访问”：

![](../Images/7de1d00b1922a4942bd57bb79f0bc7db.png)

![](../Images/40a6d0998d85988f2d21f19b8a6cd3c6.png)

9.进入Nessus配置界面，这里选择最后一项：“Managed Scanner”：

![](../Images/dd88be0328a0152a12503b02d907923b.png)

10.这里我们选择“Tenable.sc”：

![](../Images/5d1af9dc779ddac5537a519ab93ef801.png)

11.设置一个用户名密码（自己一定要记住）！

![](../Images/c9ec19a4ca1246e894895ff82e7b47a8.png)

12.Nessus开始初始化配置。

![](../Images/3d9747a71f4aa01ff8da19b29d2ff955.png)

13.默认显示Nessus的系统信息界面，这时候就代表你安装完成了，这时候关掉你的浏览器进行下一步。

![](../Images/36d48b4592db02a074094f4f41b2ece1.png)

14.将压缩包中的另一个文件“ all-2.0.tar.gz ”移动到kali中：

![](../Images/266dc4b46771e0f4392632d32be78a6e.png)

15.运行“ sudo mv all-2.0.tar.gz /opt/nessus/ ”命令将“ all-2.0.tar.gz ”文件移动到“ /opt/nessus/ ”目录下。

![](../Images/7dc9b792f52779b5bd56606d4adb2147.png)

16.运行命令：“ sudo /opt/nessus/sbin/nessuscli update all-2.0.tar.gz ”将文件更新到系统中：

![](../Images/a58132cbc3e1d5539762585d8cd21454.png)

17.运行“ sudo tar -zxvf all-2.0.tar.gz plugin\_feed\_info.inc ”命令提取“ plugin\_feed\_info.inc ”文件：

![](../Images/8dede0b7880989925427045a54459767.png)

18.运行“ sudo mousepad plugin\_feed\_info.inc ”编辑配置文件，第一行保持不变，更改第二行，添加第三行。第二、三行内容如下：

PLUGIN\_FEED ="ProfessionalFeed (Direct)";

PLUGIN\_FEED\_TRANSPORT ="Tenable Network Security Lightning";

![](../Images/869b17dfd9e19f4f0d3c7c3958fa6edb.png)

![](../Images/25af47ae7377cfe615080bc4793fc822.png)

19.运行如下两条命令，将“ plugin\_feed\_info.inc ”文件拷贝到以下两个文件夹中。

sudo cp plugin\_feed\_info.inc /opt/nessus/var/nessus/

sudo cp plugin\_feed\_info.inc /opt/nessus/lib/nessus/plugins/

![](../Images/ee5f93d80e8357e2f938e23f4bce5df2.png)

20.运行“ sudo systemctl restart nessusd ”命令重启Nessus。

![](../Images/4d6bfb2a9eb0f82b739b63f2ac20441e.png)

21.打开浏览器再次访问https://127.0.0.1:8834系统会再次进行初始化，这个过程比较漫长，请耐心等待！

![](../Images/6a5e49f1a590f39116813fddd66606ba.png)

22.再次进入后所有安装工作就完成啦！

![](../Images/9c5ded0562a25e42ae29e90c9bf85aa8.png)

工具安装完成啦，撸起袖子干吧！

附：在日常使用中可以通过以下命令管理Nessus。

systemctl start nessusd       //启动nessus

systemctl status nessusd      //查看nessus的运行状态

systemctl stop nessusd        //停止nessus

systemctl kill nessusd        //杀死nessus的所有子进程

systemctl enable nessusd      //使nessus开机自启

systemctl disable nessusd     //关闭nessus开机自启

systemctl restart nessusd     //重启nessus
