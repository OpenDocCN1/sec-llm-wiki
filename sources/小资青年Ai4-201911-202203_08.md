1.前言  

最近很多朋友咨询我Vulhub环境搭建的问题，我最近也接触到漏洞复现的问题，于是就写下此篇文章，希望对各位朋友有所帮助！

Vulhub环境推荐使用Ubuntu操作系统搭建，操作比较简单，也比较稳定，不必要花更多的时间来搭建基础环境，下面我就用Ubuntu20.04来演示一下搭建Vulhub环境的全过程！文末还附有Cent OS 7安装Vulhub环境时基础环境的配置及安装时遇到问题的处理。详情见下文：

基础环境：Ubuntu2020.4、python3、pip3、curl

  

注：所有命令均以管理员身份运行，运行“ sudo -i ”命令可以切换root用户！

  
![](../Images/87edf103f8a03b6eaacd1892dbef59e3.png)       1.先验证Ubuntu20.04系统中的python、pip以及curl版本，如未安装则运行安装程序；

“ rename docker-compose-Linux-x86\_64 docker-compose docker-compose-Linux-x86\_64 ”

**附Cent OS 7配置基础环境配置**

  

Cent OS 7中很多基础环境都不满足Vulhub的环境的搭建，这也是为什么推荐Ubuntu搭建的原因，其中Cent OS 7默认安装的是python2，我们需要将python2换为python3，详见下文：

1. 安装python3前需要先运行“ yum install gcc patch libffi-devel python-devel  zlib-devel bzip2-devel openssl-devel ncurses-devel sqlite-devel readline-devel tk-devel gdbm-devel db4-devel libpcap-devel xz-devel -y ”命令安装环境依赖；

2. 运行“ wget https://www.python.org/ftp/python/3.8.4/Python-3.8.4rc1.tar.xz ”命令获取python3的安装包；

3. 运行“ tar -xvJf  Python-3.8.4rc1.tar.xz ”命令将下载后的压缩包解压；

4. 运行“ mkdir /usr/local/python3/ ”命令创建安装目录；

5. 运行“ cd Python-3.8.4rc1 ”命令进入到python3安装文件中运行“ ./configure --prefix=/usr/local/python3 ”命令开始安装python3；

6. 运行“ make && makeinstall ”命令开始编译并安装；

7. 如果报错：“ zipimport.ZipImportError: can't decompress data; zlib not available ”  
则运行“ yum install zlib\* ”后重新运行编译安装命令进行安装；

8. 运行“ ln -s /usr/local/python3/bin/python3 /usr/local/bin/python3 ”“ ln -s /usr/local/python3/bin/pip3 /usr/local/bin/pip3 ”命令来更换其为系统默认的python版本；

9. 安装完成后运行“ python3 -V ”和“ pip3 -V ”验证版本；

10. 在Cent OS 7中运行“ docker-compost up -d ”命令时可能会报一下错误：

ERROR: Couldn't connect to Docker daemon at http+docker://localunixsocket - is it running?

If it's at a non-standard location, specify the URL with the DOCKER\_HOST environment variable.

这说明我们没有将用户加入到docker组所以没有权限运行此命令，可以运行“ gpasswd -a ${USER} docker ”命令将用户加入到docker组中；随后运行“ service docker restart ”命令重启docker后生效，要运行“ newgrp - docker ”命令切换当前会话到新 group 或者重启 X 会话

注意:最后一步是必须的，否则因为 groups 命令获取到的是缓存的组信息，刚添加的组信息未能生效，所以 docker\-compost up \-d执行时同样有错。
