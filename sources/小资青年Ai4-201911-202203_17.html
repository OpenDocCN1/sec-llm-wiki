AWVS安装


软件安装包请在公众号后台回复“awvs”即可获取。


解压密码请在公众号后台回复“解压密码”即可获取。


由于文章格式问题，为避免不必要的错误，文章中用到的所有命令建议手动输入。

1.首先将AWVS13的压缩文件直接拖入虚拟机桌面。








2.将压缩包进行解压。








3.输入解压密码。








4.解压完成后桌面显示解压后的文件夹。








5.在桌面右键单击选择“在此打开终端”。









6.将解压后的文件移动到/opt下，输入“sudo mv Acunetix_13.X系列\ Linux破解版 /opt/”









7.添加权限，输入命令“sudo chmod 755 /opt/Acunetix_13.X系列\ Linux破解版/”









8.进入到AWVS安装包目录下，为所有文件加权限，输入命令“cd /opt/Acunetix_13.X系列\ Linux破解版/ ; sudo chmod +x *”









9.运行AWVS安装程序“sudo ./acunetix_13.0.200217097_x64_.sh”；



















































10.在kali软件列表中找到火狐浏览器并打开。









11.在地址栏输入https://127.0.0.1:3443；按下图示操作









12.浏览器弹出登录界面，代表安装成功！这时不要登录！ 









13. 关闭浏览器，开始破解AWVS13；

在终端中输入“sudo cp -rf wvsc /home/acunetix/.acunetix/v_200217097/scanner/”









14.在终端中输入“sudo cp -rf license_info.json /home/acunetix/.acunetix/data/license/”









15.重新启动AWVS13，输入命令“sudo systemctl restart a”。









16.重新打开浏览器输入https://127.0.0.1:3443进入登录界面，输入刚才设置的账密，点击登录即可！









17.进入到下图界面后表示破解成功！开始你的漏扫之旅吧！








18.附：AWVS基本操作命令

systemctl start acunetix             //启动awvs

systemctl status acunetix           //查看awvs的运行状态

systemctl stop acunetix             //停止awvs

systemctl kill acunetix                //杀死awvs的所有子进程

systemctl enable acunetix          //使awvs开机自启

systemctl disable acunetix         //关闭awvs开机自启

systemctl restart acunetix          //重启awvs
