# Kali安装AWVS13

![](../Images/b4425a8a0095e6ba5645f6611d57e47a.png "渐变颜色引导关注")![](../Images/b71f78129fc984d19d9e08c50ec431cc.png)AWVS安装  
  

软件安装包请在公众号后台回复“awvs”即可获取。

  

解压密码请在公众号后台回复“解压密码”即可获取。

  

由于文章格式问题，为避免不必要的错误，文章中用到的所有命令建议手动输入。

1.首先将AWVS13的压缩文件直接拖入虚拟机桌面。

  
  
  
  
  
  
  
![](../Images/d21a787b7c184db804823d23bdd5fb8c.png)

2.将压缩包进行解压。

  
  
  
  
  
  
  
![](../Images/849935c3d0825b3e3b92b9193f557e40.png)

3.输入解压密码。

  
  
  
  
  
  
  
![](../Images/8fdc553240477a45b9a126e797f4843e.png)

4.解压完成后桌面显示解压后的文件夹。

  
  
  
  
  
  
  
![](../Images/468f9c585be616ae177b1e2e1dcd6284.png)

5.在桌面右键单击选择“在此打开终端”。

  
  
  
  
  
  
  
![](../Images/8406f201eadc20adf7643d311432edf3.png)

  

6.将解压后的文件移动到/opt下，输入“sudo mv Acunetix\_13.X系列\\ Linux破解版 /opt/”

  
  
  
  
  
  
  
![](../Images/dd066a39ed1a040fc8e9363a81cddb80.png)

  

7.添加权限，输入命令“sudo chmod 755 /opt/Acunetix\_13.X系列\\ Linux破解版/”

  
  
  
  
  
  
  
![](../Images/203a7b5e8f68823a54b6ead1cf73cb04.png)

  

8.进入到AWVS安装包目录下，为所有文件加权限，输入命令“cd /opt/Acunetix\_13.X系列\\ Linux破解版/ ; sudo chmod +x \*”

  
  
  
  
  
  
  
![](../Images/135b841206f30a3554332edca9df1bb3.png)

  

9.运行AWVS安装程序“sudo ./acunetix\_13.0.200217097\_x64\_.sh”；

  
  
  
  
  
  
  
![](../Images/22de7685ea8f4599c5935cfa0c292779.png)  
  
  
  
  
  
  
![](../Images/3e1e3b04f1b7b8ab4183e01248093ccd.png)  
  
  
  
  
  
  
![](../Images/47fcd2b1d2ada390a89593348b502a8e.png)  
  
  
  
  
  
  
![](../Images/7769797b1a905687e9813b4c22c1a042.png)  
  
  
  
  
  
  
![](../Images/49e8e370fa7c98dca329cefab36ae389.png)  
  
  
  
  
  
  
![](../Images/5ce39bea0e697967395738ea4cf0d6e2.png)  
  
  
  
  
  
  
![](../Images/f671081ffab4dcf202bfbf4858e1da46.png)

  

10.在kali软件列表中找到火狐浏览器并打开。

  
  
  
  
  
  
  
![](../Images/c09816e3b4dd1cf3bedbf6a54885914c.png)

  

11.在地址栏输入https://127.0.0.1:3443；按下图示操作

  
  
  
  
  
  
  
![](../Images/54c73bd6d72dce29c97a0381b17c6427.png)

  

12.浏览器弹出登录界面，代表安装成功！这时不要登录！ 

  
  
  
  
  
  
  
![](../Images/58f9438d53eb81c1ffc67c8509410bbd.png)

  

13. 关闭浏览器，开始破解AWVS13；

在终端中输入“sudo cp -rf wvsc /home/acunetix/.acunetix/v\_200217097/scanner/”

  
  
  
  
  
  
  
![](../Images/fd15046bf19b6257eb461bad097242aa.png)

  

14.在终端中输入“sudo cp -rf license\_info.json /home/acunetix/.acunetix/data/license/”

  
  
  
  
  
  
  
![](../Images/4a78c4b89fa5bc14d6bd23e2adfab54d.png)

  

15.重新启动AWVS13，输入命令“sudo systemctl restart a”。

  
  
  
  
  
  
  
![](../Images/8d11ac61b7b33f76f411e81ec2d7461e.png)

  

16.重新打开浏览器输入https://127.0.0.1:3443进入登录界面，输入刚才设置的账密，点击登录即可！

  
  
  
  
  
  
  
![](../Images/f2905aefddd009fa308be1c0a56ca01b.png)

  

17.进入到下图界面后表示破解成功！开始你的漏扫之旅吧！

  
  
  
  
  
  
  
![](../Images/738a6e0e56cad04428d5cb1a19ef2beb.png)

18.附：AWVS基本操作命令

systemctl start acunetix             //启动awvs

systemctl status acunetix           //查看awvs的运行状态

systemctl stop acunetix             //停止awvs

systemctl kill acunetix                //杀死awvs的所有子进程

systemctl enable acunetix          //使awvs开机自启

systemctl disable acunetix         //关闭awvs开机自启

systemctl restart acunetix          //重启awvs
