01 Empire的安装

—


Empire作为一款红队内网渗透中的神器，自然广受各大安全研究员的喜爱，熟悉其功能及利用成为了

Empire的项目地址：https://github.com/EmpireProject/Empire

git clone https://github.com/EmpireProject/Empire

首先进入Empire/setup目录下执行安装程序./install.sh

我这里是使用的Kali环境，安装过程中出现安装M2Crypto错误

可以直接通过apt安装

apt install python-m2crypto

然后执行同目录下的./reset.sh

程序便安装成功了！


02 Empire基本构架

—


Empire的基本构架由Listeners、Stagers和Agents组成


Listeners

Listeners主要用来启动监听器，供程序反弹回shell。

键入listeners进入

可以通过uselistener命令设置一个监听器

dbx|onedrive：使用dropbox或者onedrive作为信息传递的中介，类似QQ空间上线或者weibo上线。http[s]：用http[s]进行交互。http_com：使用IE的COM组件进行交互。http_foreign：这个跟http看不出差别在哪。http_hop：接收到的请求转发到其他的listener，可以用于C2。http_mapi：通过邮件上线。meterpreter：就不多说了，大家都知道的。

创建一个http监听器

可通过info命令查看该监听器的详细配置信息，配置好后执行execute启动监听

list命令可供查看当前开启的监听器


Stagers

该功能用于生成恶意文件的payload

这里使用bat批处理的模块上线测试


agents

用于后渗透攻击模块

查看反弹回的shell

可通过rename更改agents默认名称，然后通过interact操控该机器

如果未在终端输出，则可进入empire目录的download文件夹下寻找日志文件

sc的截图也会保存至此

关于agents的更多模块，可以键入usemodule查看


03 Empire 横向移动

—


通过Empire的PTH(Pass The Hash)攻击进行横向移动渗透，获取机器权限后可以通过mimikaz读取明文，但有些时候不排除无法读取明文，或解密不出明文。这时便可以通过ntlm机制的验证缺陷来攻击其他域机器。

用mimikatz读取用户凭证后，可以用creds查看用户凭证。

creds plaintext将显示所有明文密码，而creds SERVER将搜索显示主机名或用户名中带有“ SERVER”的所有凭据

在Empire中有继承PTH攻击的模块

如上配置好相关信息后即可execute

将会获取一个PID

再利用steal_token窃取身份令牌

同时还继承了mimikatz的许多功能模块
