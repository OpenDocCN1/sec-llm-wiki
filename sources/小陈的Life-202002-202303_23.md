01 前言

—

  

之前写了几篇关于反序列化的文章，有很多小伙伴问我关于ysoserial工具的问题。于是乎想着写一篇关于该工具几个payload的分析。

  

ysoserial工具的GitHub地址：https://github.com/frohoff/ysoserial

![](../Images/d33ad1c48f7399e1ce1d3e35bbb798be.png)

截至目前为止，ysoserial已经收录很多payload  

了解过反序列化漏洞的同学估计对Apache Commons Collections关键词已经很熟悉了，

分析ysoserial不仅能学到反序列化各种gadget方法，同时还能深入了解Java的反射以及动态代理机制。是安全人员必懂技术之一。

  

本文将会从中取出部分payload拿出来讲解：

1.  Jdk7u21.java
    
2.  CommonsCollections4  
    

  

观看前需要了解Java反射、动态代理机制、javassist的相关知识。

```
public V put(K key, V value) {    if (key == null)        return putForNullKey(value);    int hash = hash(key);    int i = indexFor(hash, table.length);    for (Entry<K,V> e = table[i]; e != null; e = e.next) {        Object k;        if (e.hash == hash && ((k = e.key) == key || key.equals(k))) {            V oldValue = e.value;            e.value = value;            e.recordAccess(this);            return oldValue;        }    }
    modCount++;    addEntry(hash, key, value, i);    return null;}
```

经过分析可知，k为上一个存入的变量，key为本次存入的变量。

但是想要执行key.equals(k)仍然需要满足以下几点：

1.  key与k的hash计算值要相等，满足前面的表达式才会进入后面的逻辑与
    
2.  同时k与key的值不能相等，程序才能执行逻辑或后面的代码。
    
3.  其中key的对象为templates，k的对象为templatesImpl。
