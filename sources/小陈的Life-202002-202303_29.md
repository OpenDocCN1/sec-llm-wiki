动态代理基本上有两种方式，一种是通常的JDK加载动态代理的方式，可以在运行时指定需要增强的。故有程序在运行时创建的代理方式被称作为动态代理。另外一种动态代理方式就是CGlib。

  

01 JDK动态代理方式

—

  

按照之前的编程思想，想要实现个接口，需要在某个实现类的后面跟上“implements”关键词。

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
public class TestServer {    public static void main(String[] args) {        MyInterfaceImpl myInterface = new MyInterfaceImpl();        myInterface.fun1();        myInterface.fun2();    }}
interface MyInterface {    void fun1();    void fun2();}
class MyInterfaceImpl implements MyInterface {    public void fun1() {        System.out.println("fun1()");    }
    public void fun2() {        System.out.println("fun2()");    }}
```

用JDK动态代理技术，只需在程序加入newProxyInstance方法创建实例  

![](../Images/b2252157953eb6841b264d7b6eaf300d.png)

newProxyInstance方法有三个参数：  

*   
*   
*   
*   
*   
*   

```
public static Object newProxyInstance(    ClassLoader loader,    Class<?>[] interfaces,    InvocationHandler h)
```

*   ClassLoader loader：类加载器类型，MyInterface.class.getClassLoader()就可以获取到ClassLoader对象，一个Class对象就可以获取到一个ClassLoader对象；
    
*   Class\[\] interfaces：指定newProxyInstance()方法返回的对象要实现哪些接口，可以指定多个接口，例如上面例子只指定了一个接口：Class\[\] cs = {MyInterface.class};
    
*   InvocationHandler h：它是最重要的一个参数，是一个接口，名为调用处理器。无论你调用代理对象的什么方法，它都是在调用InvocationHandler的invoke()方法！  
    

  

其中第三个InvocationHandler参数是一个调用处理器，动态代理需要通过处理器的invoke方法处理，无论你调用接口的什么方法，都会传入invoke处理。

而invoke方法的参数也有三个：

*   Object proxy：代理对象，也就是Proxy.newProxyInstance()方法返回的对象，通常我们不用管。
    
*   Method method：表示当前被调用方法的反射对象，例如method.fun1()，那么method就是fun1()方法的反射对象。
    
*   Object\[\] args：表示当前被调用方法的参数，当然method.fun1()这个调用是没有参数的，所以args是一个零数组。
    

所以想要知道接口的什么方法被调用的时候只需从method.getName()获取
