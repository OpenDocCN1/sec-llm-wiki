**0X00 前言**

最近做的项目已经快到尾声了，目标使用的数据库是**PostgreSQL**。之前没有接触过这个数据库于是恶补了一下，这里分享一下我的收获。

  

**0x01 搭建PostgreSQL**

搞安全有一项基本能力要求，就是能复现各种奇奇怪怪的环境到本地来进行测试。而搭建环境这个工作，虽然有各种靶场或docker可以一键启动，但我还是喜欢手动的搭建一遍，这样对环境理解的会更深刻，并可能发现一些运维容易忽视的点。

  

PostgreSQL数据库搭建步骤如下：

  

**1、进入官网下载页面选择对应操作系统**

*https://www.postgresql.org/download/*

![](../Images/727369d8debb5ba896f0eb9518490d97.png)

  

2、**选好操作系统后下滑选择pgsql版本和系统架构**

我这里选择的是和目标一致的版本。选好后就会出现下图灰色的部分——官方给出的安装命令。

![](../Images/e751036a628ab1e415a6132029726bcc.png)

  

**3、一条一条照着输入就好了，下载安装启动一条龙。**

![](../Images/10e2fa9d6667ac33d73629d6564f746b.png)

  

**4、****ps aux****和****netstat -antp****命令查看进程和网络信息，发现pgsql相关进程。**

![](../Images/9148b2d5c88269bdd40135a5b5ecdbe5.png)

![](../Images/b70cf409a536efe01c0d8bfeed2dcd94.png)

  

**0x02连接PostgreSQL**

**1、pgsql安装后会创建一个postgresql系统用户，****cat  /etc/passwd****命令****可见，****su****命令切换到该用户。**

![](../Images/0bd7f6237c454b488e573fa1339bee25.png)

  

**2、直接输入****psql****命令，即可进入数据库命令行。****\\help****查看帮助。**

![](../Images/45a63a5d9624943544bd572ef4d4f19d.png)

  

**3、****\\q****退出数据库，****exit****返回到之前的用户。**

为降低学习成本，我跳过了学习命令行的使用方法，打算直接用navicat远程连接管理。

![](../Images/389f2e851ceb1f286dd66211469fe29e.png)

  

**4、不过之前****netstat -antp****看到，PostgreSQL安装好默认只允许本地ip连接，需要修改配置文件放开这个限制。**

![](../Images/201745dac47e00a8181e684b2d4902c7.png)

![](../Images/821fefb5cdc5af7b9605d2ecdce72814.png)

  

**5、之前用****ps aux****查看进程信息，获取到pgsql的data目录。**

![](../Images/bfea6491a75b6ebd104f216425cf0923.png)

  

**6、进入该目录，编辑****pg\_hba.conf****文件**

![](../Images/9f29ef4f18ae7d41a6c6d94503725f07.png)

  

**7、在最下面添加****host all all 0.0.0.0/0 trust****一行，可允许任意ip地址无需密码连接！**

![](../Images/3e6368be7cbd68e0f64fb0bb0ac9cb33.png)

  

**8、然后修改****postgresql.conf****文件，将****listen\_addresses****的值修改为****‘\*’****，并去掉前面的注释。**

![](../Images/6520b97c64495062c417c6bba1d3a484.png)

  

**9、****sudo systemctl restart postgresql-9.6**** 命令重启数据库使配置生效，再次查看网络信息发现已经允许所有ip访问了。**

![](../Images/b2d78534a4af67a36f69bf91e9c0d227.png)

  

**10、最后别忘记添加防火墙规则放行端口，如果是云主机还要配置相对应的安全组。**

**firewall-cmd --zone=public --add-port=5432/tcp --permanent**

**firewall-cmd --reload**

![](../Images/f547fb54ea1247088cce91d43c394d2e.png)

  

**11、使用Navicat新建PostgreSQL连接，直接输入ip地址并使用默认用户即可，无需输入密码。**

![](../Images/89a7ed72d3a59044072e8ae7abd51e01.png)

  

**12、连接成功**

![](../Images/0fd2cca5eb3a9d3b6e264e5b7c9952e8.png)

  

**0x03 基本使用方法**

**1、组织架构：库-模式-表**

PostgreSQL和mysql数据库的组织架构有一个区别，数据库和表之间多了一个东西叫做模式。如下图所示，test是数据库，下面的moshi是数据库的一个模式，模式下面才是表tabletest。表下的行列和mysql一样。

![](../Images/90baca584f37db71af381b3deb02dbd9.png)

  

**2、收集基本信息：**

select version();   *//查询数据库版本*

select current\_database();   *//查看当前数据库*

select user;   *//查看当前用户*

![](../Images/5eaaec7132b42f49ace8d0831a950062.png)

  

**3、收集用户信息**

select \* from pg\_user; *//查看所有用户*

select \* from information\_schema.table\_privileges;* //查看用户拥有的权限*

![](../Images/9e51cc3f4b5de6555cda3b9186a704e3.png)

![](../Images/aed00677493496dfecaed3c40b7abff3.png)

  

**4、收集表信息**

select \* from pg\_tables; *//查看所有表（含隐藏的系统表）*

select \* from information\_schema.columns where table\_schema='库名' and table\_name ='表名';**//查看某个表所有字段**

![](../Images/63415c85d65ff4db90fa0bc36781c360.png)

![](../Images/670130c0057bb8a449af569cf60e9e8d.png)

  

**0x04 设置密码**

pg\_hba.conf中设置认证方式为trust即可免输密码，但这样很不安全，所以这里记录一下pgsql设置密码的方式。

  

**1、安装PostgreSQL数据库后自动创建一个postgres用户作为数据库的管理员，同时创建同名linux系统用户，密码随机。要修改密码，首先以postgres系统用户登陆数据库：**

**sudo -u postgres psql**

![](../Images/a90cc9d9cd7741f3dee137b804c324e0.png)

  

**2、****ALTER USER postgres WITH PASSWORD ‘postgres’; **** //修改数据库用户密码**

**\\q ****//退出数据库客户端**

![](../Images/42a63acb96dcaf8020a80228dfdf5a72.png)

  

**3、****passwd postgres ****//修改系统用户密码**

![](../Images/ba24583ca57ab7546518754e49a9ba64.png)

**4、创建普通数据库用户**

**CREATE USER 用户名 WITH PASSWORD '密码' CREATEDB;**

**GRANT ALL PRIVILEGES ON DATABASE 数据库名 to 用户名;**

![](../Images/9a6bb73d01cbc786cf439ab2d063dacf.png)

  

**0x05 拖库**

**1、****pg\_dump****是类似于mysqldump一样的导出数据库的工具，一般来说安装PostgreSQL服务端后自带客户端含psql、pg\_dump等工具。无需特意去安装。**

![](../Images/266b63528f003d82daeeca2573a71fcc.png)

  

**2、特殊情况需单独安装pgsql客户端，下面给出了centos系统的安装命令。**

**\# ****yum install https://download.postgresql.org/pub/repos/yum/reporpms/EL-7-x86\_64/pgdg-redhat-repo-latest.noarch.rpm**

**#**** yum install postgresql96**

客户端和服务端的版本尽量对应，否则可能连接失败。有时候大版本号对应了，小版本号不对应也不行，这时候可以考虑换个大版本号试试：比如yum install postgresql10安装的客户端版本为10.5，但是服务端是10.8，这时候有概率连接失败，单独下载编译10.8版本客户端是一个解决方案，但是很麻烦，这时候就可以试试yum install postgresql11或yum install postgresql9，有几率连接成功（实际环境中遇到过）。

  

  

**3、一个坑：本机复现需要修改pg\_hba.conf，将这一行注释掉，然后重启服务**

![](../Images/0eea100be30d1853f51782b84072eef3.png)

**4、pg\_dump具体使用命令**

导出特定的表的数据：

**pg\_dump -h 主机 -U 用户名 -t "模式名.\\"表名\\"" 库名 -f 导出文件名**

![](../Images/7d263cf352d31be05ab0625705829776.png)

导出特定模式中所有数据：

**pg\_dump -h 主机 -U 用户名 -n 模式名 库名 -f 导出文件名**

![](../Images/489ac0903094f64b2f4d715a8877edf0.png)

导出特定库中所有的数据：

**pg\_dump -h 主机 -U 用户名 -d 库名 -f 导出文件名**

![](../Images/8a7dc9352cf7f148c4e872cfc19665d1.png)

  

**5、如何免密码使用pg\_dump**

使用场景：数据库过大，需要配合nohup启用后台进程去拖，这时候不方便输入密码。

（1）在当前用户家目录下新建**.pgpass**文件，权限设置为**600**

![](../Images/797673ba6f70e65fcfbe74389850771a.png)

（2）内容为：

**hostname:port:database:username:password**

![](../Images/f06c969d82c4112aef2fda7bc947927c.png)

（3）运行pg\_dump，当匹配到填写的hostname，port(不填默认为5432)，database和username四项正确时，即可不填写password，会自动从.pgpass文件中读取。

![](../Images/5109c2d774a599c27e82b81e7166c1b6.png)
