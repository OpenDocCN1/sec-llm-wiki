** 【引言】**

上一个教程教大家如何安装kali虚拟机并提供了相应的资源，不知道大家有没有自己尝试着安装成功了呢。这个系列的教程的第2篇也就是本篇将提供给大家安装kali时的**两个常见问题**的解决方案以及安装kali之后正式使用前需要进行的**基础配置**。

  

**【安装时常见问题】**  

**1. 虚拟机开机后黑屏**  

解决方案：点击左下角的开始菜单按钮，直接输入cmd，查找到cmd（命令提示符），右键单击它，选择“以管理员身份运行”。然后在打开的窗口中输入“netsh winsock reset ”（没有双引号），再**重启电脑**即可。  

注：有时安装某些软件后可能导致网络配置被更改，虚拟机再次黑屏，按上面的方法再弄一次就好啦。  

![](../Images/48f176698b02d1511c356a62d85a8683.png)

  

**2.虚拟机开机后提示：“……虚拟化技术禁用、没有开启VT-x……”（大概是这段话，关键词“虚拟化技术”）**

# 解决方案：进入bios（win10可以点击设置->更新和安全->恢复->立即重新启动 来进入BIOS），然后找到这个选项，开启即可。

![](../Images/d01c70b1ff04de2311fa2ef069008c98.png)

  

**【虚拟机快照】**  

虚拟机安装的常见问题解决之后，在正式使用前还要进行一些配置。不过因为大家可能还不熟悉linux系统，可能误操作导致系统崩溃。建议大家先了解一下VM的快照功能，它可以**快速的保存和恢复虚拟机的状态**，相当于备份的功能，这样系统崩溃之后就不用费力去重装系统了。

快照按钮在vm14中是上方菜单栏的几个小时钟的图标，使用非常简单，大家随便点点就会用了。

![](../Images/bd68c5e21fe6e13984e54c6215495781.png)

  

**【网络配置】**

刚装好的kali可能是不能联网的（正常情况下虚拟机可以复制主机的网络连接状态）。这时需要进行一些配置：  

1、打开kali的终端（Terminal）![](../Images/aea14bcb234df0778a5b5e06f15d33b5.png)，输入

gedit  /etc/network/interfaces

  

**（红色和蓝色之间有一个空格，以下皆是如此）**

2、在打开的窗口中末尾输入

 auto eth0

 iface eth0 inet dhcp

3、保存退出到终端输入

/etc/init.d/networking  restart

即可打开浏览器，打开百度测试是否能上网。

**【更换国内源】**  

kali linux系统可以使用apt命令快捷的安装软件，但是apt命令默认是从国外的源服务器下载软件，这与中国的网络国情冲突，可能导致软件下载失败的问题，所以要更换成国内的源：

1、输入 gedit  /etc/apt/sources.list 打开源配置文件

2、删除所有内容

3、复制下列内容

#阿里云  
deb http://mirrors.aliyun.com/kali kali\-rolling main non-free contrib  
deb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib  
#中科大  
deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib  
deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib  
#浙大  
deb http://mirrors.zju.edu.cn/kali kali-rolling main contrib non-free  
deb-src http://mirrors.zju.edu.cn/kali kali-rolling main contrib non-free  
#清华大学  
deb http://mirrors.tuna.tsinghua.edu.cn/kali kali-rolling main contrib non-free  
deb-src https://mirrors.tuna.tsinghua.edu.cn/kali kali-rolling main contrib non-free  
#官方源  
deb http://http.kali.org/kali kali-rolling main non-free contrib  
deb-src http://http.kali.org/kali kali-rolling main non-free contrib

4、保存退出到终端依次输入三条命令

1.  apt-get  update 
    
2.  apt-get upgrade 
    
3.  apt-get dist-upgrade
    

（期间会提示你输入y来进行下一步，要注意一下）
