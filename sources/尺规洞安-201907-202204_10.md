# Nessus最新版本突破16IP限制

**百度百科****:****Nessus** 是目前全世界最多人使用的系统漏洞扫描与分析软件。总共有超过75,000个机构使用Nessus 作为扫描该机构电脑系统的软件。

![](../Images/658efa55153d7e35ef0f5ecd33bb31d5.png)

  

  

  

大家好，我是AASCOM 。我们做渗透测试中离不开漏扫工具。Nessus用来扫描主机一直都是不错的选择，但是用普通的权限只用16个ip的扫描机会，16个用完就用不了，就会提示使用会员版。这一点确实有点小烦恼。所以我们来突破一下这个限制！！！

  

  

**一.首先我们看下Windows版本的破解**

    1.我们先去官网下载一个Windows10的最新版本；

官网最新下载地址：

https://www.tenable.com/downloads/nessus?loginAttempted=true

![](../Images/082dc6644ddd2afafba73542c8d682f3.png)

  

    2.然后点击安装，设置安装路径一路默认就好，然后打开nessus；https://localhost:8834/

    在浏览器中访问https://localhost:8834，初始化扫描器，选择Managed Scanner然后点击 Continue。

![](../Images/f165af0698b90f60ad778cea93fc573a.png)

  

        然后选择Tenable.sc ,然后点击 Continue

![](../Images/094fd5ac9768986e616c934b51cce3a7.png)

      

        设置一个账号和密码  

![](../Images/6b71f59b380a80677593a3908e4cbbd7.png)

  

      然后进去是没有扫描界面的，我们先看看没有破解是怎么样！

![](../Images/3eab92b7534a755782ab986b22ddbb8f.png)

  

  

    3.接下来就是破解了，打开cmd用管理员运行。

![](../Images/57ff9495c8b75d4a143519d7772f7a62.png)

  

    进入Nessus的安装目录，运行nessusccli.exe fetch --challenge

![](../Images/4fceb520597a36dd2b7f81a5118207b4.png)

  

    记住这串challenge code ，并打开下面的链接

![](../Images/f63d92fedcdcace6b1c17608ba7d00ea.png)

  

    打开链接，然后填入challenge code 和 激活码；

  

激活码在

https://zh-cn.tenable.com/products/nessus/nessus-essentials

随便输入姓名，然后你的输入邮箱，就会获得激活码

![](../Images/0d71f422272d03bb0ed4218a13da5079.png)

  

    然后填入challenge code 和 激活码 点击Submit

![](../Images/132dacb50d38544689887d780de4b53f.png)

  

    然后进入点击下载链接

![](../Images/59ffa7b3d3cbd30afb3399707c256ff4.png)

  

        下载后将插件包移到Nessus安装目录  

    在cmd输入nessuscli.exe update all-2.0.tar.gz

    记住 version   （后面要考）

![](../Images/726068f3a345d895b0343e43680c27f6.png)

  

    4.到现在为止，nessus安装完成，但只支持16个IP，接下来进行破解，修改两个文件，没有的话创建一下，再改成下面的内容；

    D:\\安装路径\\nessus\\plugin\_feed\_info.inc  

    D:\\安装路径\\nessus\\plugins\\plugin\_feed\_info.inc

  

PLUGIN\_SET = "202006091543";  
PLUGIN\_FEED = "ProfessionalFeed (Direct)";  
  
PLUGIN\_FEED\_TRANSPORT = "Tenable Network Security Lightning";

![](../Images/691b41a9422c4f40089a82d0269477f7.png)

  

    可以先用txt保存好，改好文件名：             plugin\_feed\_info.inc

分别放进指定目录

D:\\安装路径\\nessus\\plugin\_feed\_info.inc  

D:\\安装路径\\nessus\\plugins\\plugin\_feed\_info.inc

  

    5.然后重起下Tenable Nessus服务  

![](../Images/811b1c09b08ff02104263137307d6319.png)

    然后就是突破了16个ip限制。  

![](../Images/d00033a4ceee457f0b8ba3c33c86b6f3.png)

  

**二.接下看看kali Linux的Nessus的破解方法**

    1.在官网下载kali版本

![](../Images/e7604181b4dc97e52e112b43a365d86f.png)

    

        然后解压再sudo service nessusd start

![](../Images/8d516eead29d2326be1146a9fe18b1ac.png)

  

    2.然后就和前面一样了选择Managed Scanner ，选择Tenable.sc，然后点击 Continue。设置账号密码！！！

![](../Images/f165af0698b90f60ad778cea93fc573a.png)![](../Images/094fd5ac9768986e616c934b51cce3a7.png)

  

    3.kali会将nessus默认安装到/opt/目录下

    然后输入

sudo /opt/nessus/sbin/nessuscli fetch --challenge 

 记下challenge code

![](../Images/437ef5bcf600d6e15beb7aa915943b55.png)

  

    访问链接获取下载插件地址并下载  和上面一样  

![](../Images/3ccb86ebd31ca61b32c9fd0646af363f.png)![](../Images/59ffa7b3d3cbd30afb3399707c256ff4.png)

  

    4.将下载插件移到和nessuscli 同一目录

    /opt/nessus/sbin/

    输入

 sudo /opt/nessus/sbin/nessuscli update all-2.0.tar.gz

    记录下versior

![](../Images/1c00cde4c7db999df17a99fd74e2d729.png)

  

   5. 还是在这两个目录下添加plugin\_feed\_info.inc破解文件

sudo vim /opt/nessus/lib/nessus/plugins/plugin\_feed\_info.inc

sudo vim /opt/nessus/var/nessus/plugin\_feed\_info.inc

![](../Images/ff9c88bae2765ad84d5d807c06bb14a9.png)![](../Images/88b0dd16e0b4f5aa5adf993c628c67fb.png)

  

    vim输入 然后wq保存退出

PLUGIN\_SET = "202006091543";  
PLUGIN\_FEED = "ProfessionalFeed (Direct)";  
  
PLUGIN\_FEED\_TRANSPORT = "Tenable Network Security Lightning";

![](../Images/ba70898f601c3e89747252a29925016b.png)![](../Images/7df31ba7c6f78fb44a335bdaefc1e150.png)

  

6.然后重启下nessus服务

sudo service nessusd restart

  

然后访问https://localhost:8834/

突破IP限制成功

![](../Images/1c095c4e453c7f9f9583ce9e02ec3f34.png)

  

注：每次更新完后，上述两个文件都会变回家庭版的配置（因为我们是通过下载家庭版的插件包来进行离线更新的），所以原本是破解的，一更新就又变限制版了，需要重新改成上面的内容。

2.0.tar.gz
