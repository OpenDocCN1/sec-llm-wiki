1long Fact(long n）
2{
3    if (0 == n)
4        return 1;
5    else
6        return n * Fact (n-1);
7}


图上所示为主程序调用函数Fact(4)的执行过程。在函数过程体中，else语句以参数3,2,1,0执行了递归调用。在最后一次n = 0时，进入了if语句并执行if语句，并不再继续调用Fact函数，就递归终止了，开始逐步返回函数体。

将依次计算的1*1、2*1、3*2、4*6 将计算结果24返回给主程序中；


主要搞明白3个步骤：

1. 发送参数调用函数  

2. 带参数使用函数

3. 带值返回函数
