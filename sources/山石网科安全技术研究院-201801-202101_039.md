# 山石网科安研院获得首届中国I2S峰会暨工业互联网安全大赛优秀奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMDUxNTE1Mw==&mid=2247486653&idx=1&sn=1c151f95ba9a605d7261cb2a1ca92dac&chksm=fa51d903cd2650155768f3cbb21c846b7b35fe7b039b65a6a1656c2ebc992516198ba370d180&scene=126&sessionid=1681374573#rd](http://mp.weixin.qq.com/s?__biz=MzUzMDUxNTE1Mw==&mid=2247486653&idx=1&sn=1c151f95ba9a605d7261cb2a1ca92dac&chksm=fa51d903cd2650155768f3cbb21c846b7b35fe7b039b65a6a1656c2ebc992516198ba370d180&scene=126&sessionid=1681374573#rd)

2020年10月30-31日，由南通市人民政府、公安部第三研究所主办，南通市崇川区人民政府、中共南通市委网信办、南通市工业和信息化局、南通市公安局共同承办的“首届中国I²S峰会暨工业互联网安全大赛”在江苏南通成功召开。  

  

![](../Images/1c573b6379713887e9c5211414b7a447.png)

本次大赛紧密结合实际场景和工业互联网安全技术应用发展状况，采用线下5G环境半实物仿真环境决赛的方式，通过竞赛验证5G+工业互联网安全防御方案的效果，同时演练工控安全及工业互联网安全应急预案，提高工业互联网安全运维保障能力。参赛团队需通过逐步渗透，完成题目闯关，考察参赛选手在工业互联网网络、设备、控制、平台、应用、数据等方面的安全测试、评估、运维、保障能力以及完成指定任务的理论和技术水平。  

![](../Images/8ce5a5c0054a52b50b6db425b3a72d55.png)

大赛组委会从来自全国各地的众多报名队伍中优选了36支参赛队伍，参赛选手及专业裁判团队共200余人。经过一天半时间的激烈角逐，山石网科安研院NEURON团队脱颖而出获得本次大赛的优秀奖，在工控安全技术领域该团队还只是刚入门不久，能获得优秀奖已经是非常不错的成绩，这是值得鼓励和表扬的，期望他们再接再厉，在未来的赛事中有更好的发挥，继续不断获取卓越的成绩。

  

![](../Images/1bdabe39547211a8e6f63c2b96191999.png)

南通市委常委、崇川区委书记刘浩在峰会中提到，在南通举办中国工业互联网安全峰会及大赛，是“风口”产业与“风口”城市的相遇，必将促进行业企业与地方政府全方位对接，促进行业与地区融合发展。他表示欢迎大家关注南通，选择南通，在南通加速构建完整的网络安全产业生态圈。  
早在2019年11月，在南通市崇川区政府、南通市工信局、公安部等保中心的共同支持下，长三角网络安全产业园就已启动建设。经过一年的建设，园区快速发展、茁壮成长，“两院、两基地、五中心、两基金”的总体框架全面形成（“两院”：江苏智慧安全可信技术研究院，中国电子现代数字城市江苏研究院；“两基地”：研发基地和制造基地；“五中心”：技术研发中心、适配监测中心、标准验证中心、安全产品质量监督检验中心检分中心、信创网络安全等级保护验证设备中心分中心、人才培养中心；“两基金”：南通崇川网络安全产业发展基金，首期规模2亿元，南通崇川信创产业投资基金，首期规模5亿元），20多家企业相继落户，等保云防、等保云查系列产品完成研发并投入使用。
