## ******漏洞背景******  

近日山石网科安全研究院监测发现Apache Solr官方发布安全公告，披露在特定的Solr版本中ConfigSet API存在文件上传漏洞（CVE-2020-13957），攻击者利用漏洞可实现远程代码执行。山石网科安全研究院提醒使用Apache Solr的用户及时安排自检并做好安全加固。

  

## ******漏洞描述******  

Solr在通过结合 UPLOAD/CREATE 这两个 ACTION 在 ConfigSet API 上进行未授权操作时，攻击者可获取服务器权限。

  

## ******漏洞危害******

高危

  

## ******影响版本******

*   Apache Solr 6.6.0 to 6.6.5
    
*   Apache Solr 7.0.0 to 7.7.3
    
*   Apache Solr 8.0.0 to 8.6.2
    

  

## ******解决方案******

*   如果未使用ConfigSets API，则通过将系统属性设置为“ configset.upload.enabled”设置为“ false”来禁用UPLOAD命令。
    
*   使用身份验证/授权来确保未知的请求不会被允许访问。
    
*   升级到8.6.3及以上的安全版本。
    
*   如果不能进行升级，请考虑在SOLR-14663公告中的应用补丁。
    
*   将Solr API（包括Admin UI）仅对可信的IP或用户开放。
