漏洞背景

File Manager是一款用于文件管理的Wordpress插件。9月2日发布安全补丁，经过分析发现在6.9之前的版本中存在前台远程代码执行漏洞。


漏洞描述

核心原因是由于没有任何的访问限制，导致库文件lib/php/connector.minimal.php可以被直接访问。这个文件调用了并初始化了elFinder类，导致任意用户可以直接调用elFinder类中的文件等操作命令，包括文件上传等，可以造成任意代码执行。


  


在最新版本补丁中，官方删除了这个文件。

漏洞危害

严重


影响版本

< 6.9


解决方案

  • 升级到最新版本
