## ******漏洞背景******  

近日，Microsoft补丁日发布了123个漏洞的补丁更新，在这123个漏洞补丁中，严重漏洞有20个，高危漏洞有103个。

其中CVE-2020-1450 Windows DNS Server 远程代码执行漏洞尤为重要，该漏洞细节已公开，可引发蠕虫式传播，请尽快安装更新补丁。
