## ******漏洞背景******  

2020年7月14日,研究人员Pierre披露了V-SOL OLT中存在的多个严重漏洞，对产品的多个版本都有影响。

V-SOL OLT允许向大量客户端（使用ONT）提供FTTH连接。一些设备支持多个10 Gb上行链路，并提供多达1024个ONT（客户端）的Internet连接。  

## ******漏洞摘要******  

1.  使用telnet进行后门访问
    
2.  后门提权
    
3.  硬编码的RSA密钥
    
4.  潜在的命令注入  
    
5.  代码无验证
    
6.  用于创建帐户的后门
    
7.  V1600D型号专用的后门
    
8.  不安全的管理界面  
    

## ******漏洞详情******  

**1、使用telnet进行后门访问**

  

利用条件：远程登录服务器正在设备中运行，并且可以从WAN接口和FTTH LAN接口（从ONT）访问。

后门账号及密码：  

```
login: admin
!j@l#y$z%x6x7q8c9z)
```

凭证从固件映像中提取：  

![](../Images/bd4c3f375b547bb32c704b5467e13332.png)

带有硬编码凭据的身份验证过程  

```


$ telnet [ip]admin
!j@l#y$z%x6x7q8c9z)


```

  

## **2、后门提权**

可以使用密码`!j@l#y$z%x6x7q8c9z)`提升特权，并获得完整的管理员CLI访问权限：  

```

olt> enable!j@l#y$z%x6x7q8c9z)


```

有了此访问权限，攻击者就可以完全修改配置及固件。

硬编码的管理员启用密码  

![](../Images/be776356048f1eb722fc6eef8afb62f2.png)

  

**3、硬编码RSA密钥**

  

固件映像包含硬编码的RSA密钥，用于为Web服务器提供SSL加密。  
V1600D4L和V1600D-MINI：  

```
































$ cat self.key
```

V1600D，V1600G1和V1600G2：  

```
































$ cat usr/sbin/self.key
```

  

**4、潜在的命令注入  
**

  

正常情况下可以使用TFTP传输一些文件：  

```

upload tftp syslog <filename> <A.B.C.D>
```

但这容易受到命令注入的影响，从而允许以root用户身份运行命令。  
使用system启动的tftp进程将使用攻击者提供的参数，如下所示：  

![](../Images/b35c7eaf7217c5004b96a3461687704b.png)

  

**5、代码无验证  
**

  

在V1600D4L和V1600D-MINI的固件映像中，我们可以在init.sh脚本内找到以下内容：  

```







$ cat init.sh
```

在更新期间，该脚本似乎无需身份验证即可启动telnetd。  
  

**6、用于创建帐户的后门  
**

  

字符串 `4ef9cea10b2362f15ba4558b1d5c081f`与用于创建新用户的函数中的输入值进行比较。

该代码将检查用户是否为`admin`或是否提供了后门密码  `4ef9cea10b2362f15ba4558b1d5c081f`。

该功能是用来从非管理员用户创建管理员用户的。

![](../Images/80ef6c0574d28694a6bcb21052022003.png)

  

**7、V1600D型号专用的后门  
**

此后门出现在版本2.03.69中。  
将字符串`K0LTdi@gnos312$`与远程攻击者提供的密码进行比较。如果匹配，将提供访问权限。  

![](../Images/ad525534a2e5d809a341690f170b585e.png)

  

**8、不安全的管理界面**  

  

默认情况下，只能使用HTTP，HTTPS，telnet和SNMP远程管理设备。某些设备可能支持SSH。此外，SSL使用硬编码密钥。攻击者可以拦截以明文形式发送的密码，并可以通过中间人攻击（MITM）来劫持设备。

  

## ******影响版本******  

这些漏洞会影响以下可用的OLT模型：  

*   V1600D（V2.03.69和V2.03.57）
    
*   V1600D4L（V1.01.49）
    
*   V1600D-MINI（V1.01.48）
    
*   V1600G1（V2.0.7和V1.9.7）
    
*   V1600G2（V1.1.4）
    
*   V1600D2-L
    
*   V1600D2
    
*   V1600D4
    
*   V1600D4-DP
    
*   V1600D8
    
*   V1600D16
    
*   V1600G0
