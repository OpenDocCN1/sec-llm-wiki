漏洞通告 | 多个版本NVIDIA GPU驱动出现严重漏洞

漏洞背景

Nvidia 发布了一份安全通告，针对其驱动程序中的6个安全漏洞。

漏洞严重程度CVSS评分在5.5至7.8之间，严重影响了Windows和Linux计算机。

在驱动程序的Nvidia控制面板组件中发现第一个漏洞CVE‑2020‑5962，本地攻击者可以在其中损坏系统文件，从而导致拒绝服务或提权。

漏洞描述

CVE-ID

描述漏洞评分
CVE‑2020‑5962NVIDIA GPU显示驱动程序在NVIDIA控制面板组件中包含一个漏洞，在该漏洞中，具有本地系统访问权限的攻击者可能破坏系统文件，这可能导致拒绝服务或特权升级。7.8
CVE‑2020‑5963NVIDIA CUDA驱动程序在进程间通信API中包含一个漏洞，该漏洞中的不当访问控制可能会导致代码执行，拒绝服务或信息泄露。7.8
CVE‑2020‑5964NVIDIA GPU显示驱动程序的服务主机组件中包含一个漏洞，其中应用程序资源完整性检查可能会丢失。这种攻击可能导致代码执行，服务拒绝或信息泄露。6.5
CVE‑2020‑5965NVIDIA GPU显示驱动程序在DirectX 11用户模式驱动程序（nvwgf2um/x.dll）中包含一个漏洞，在该漏洞可能导致超出范围的访问，从而导致拒绝服务。5.5
CVE‑2020‑5966NVIDIA视窗GPU显示驱动程序包含在内核模式层（漏洞nvlddmkm.sys）处理程序DxgkDdiEscape，其中，一个NULL指针被解除引用，导致服务或特权潜在升级的拒绝。5.5
CVE‑2020‑5967NVIDIA Linux GPU显示驱动程序在UVM驱动程序中包含一个漏洞，竞争状况可能导致拒绝服务。5.5

以上为NVIDIA GPU 显示驱动漏洞。

除此之外还公布了多个vGPU软件漏洞，列表如下所示：


CVE描述漏洞评分
CVE‑2020‑5968NVIDIA Virtual GPU Manager在vGPU插件中的漏洞，该软件不会在使用索引或指针（例如内存或文件）访问的资源范围内限制或错误地限制操作，这可能会导致代码执行，拒绝服务，特权升级或信息泄露。7.8
CVE‑2020‑5969NVIDIA Virtual GPU Manager在vGPU插件中的漏洞。该漏洞将在使用共享资源之前对其进行验证，从而形成竞争状况，这可能导致拒绝服务或信息泄露。7.8
CVE‑2020‑5970NVIDIA Virtual GPU Manager在vGPU插件中的漏洞，其中未验证输入数据大小，这可能导致篡改或拒绝服务。7.8
CVE‑2020‑5971NVIDIA Virtual GPU Manager在vGPU插件中的漏洞，该软件通过使用缓冲区访问机制（例如引用目标缓冲区后的内存位置的索引或指针）从缓冲区读取软件，这可能导致代码执行，拒绝服务，特权升级或信息泄露。7.8
CVE‑2020‑5972NVIDIA Virtual GPU Manager在vGPU插件中的漏洞，这可能导致篡改或拒绝服务。5.5
CVE‑2020‑5973NVIDIA Virtual GPU Manager在vGPU插件中包含一个漏洞，其中有可能执行特权操作，这可能会导致拒绝服务。4.4
