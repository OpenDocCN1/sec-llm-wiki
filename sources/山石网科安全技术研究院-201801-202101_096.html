漏洞背景

近日，山石网科安全技术研究院监测到Apache Dubbo披露了Provider默认反序列化远程代码执行漏洞（CVE-2020-1948），攻击者可构造恶意请求执行任意代码。


漏洞描述

Apache Dubbo 是一种基于 Java 的高性能 RPC 框架。该项目 2011 年开源，并于 2018 年 2 月进入 Apache 孵化器，它提供了三大核心能力：面向接口的远程方法调用，智能容错和负载均衡，以及服务自动注册和发现。


该漏洞会影响所有使用2.7.6或更低版本的Dubbo用户，攻击者可以发送带有无法被识别的服务名或方法名的RPC请求，并携带一些恶意的参数负载。当恶意参数被反序列化时，将执行恶意代码。


漏洞危害

攻击者可向受影响服务器发送恶意请求执行任意代码，获得服务器权限。


影响版本

  • Apache Dubbo 2.7.0 ~ 2.7.6

  • Apache Dubbo 2.6.0 ~ 2.6.7

  • Apache Dubbo 2.5.x 所有版本 (官方不再提供支持)

解决方案

  • 更新Apache Dubbo至2.7.7或更高版本（https://github.com/apache/dubbo/releases/tag/dubbo-2.7.7）
