漏洞背景

2020年6月10日，山石网科安全技术研究院旗下的安全预警分析团队监测到国内安全厂商发布Apache Kylin漏洞的信息。


漏洞描述


Apache Kylin™是一个开源的、分布式的分析型数据仓库，提供Hadoop/Spark 之上的 SQL 查询接口及多维分析（OLAP）能力以支持超大规模数据，最初由 eBay 开发并贡献至开源社区。它能在亚秒内查询巨大的表。

官网共公布了两个漏洞，分别是：

  1. CVE-2020-1937 Apache Kylin SQL注入漏洞

    Kylin的restful api，可以让sql与用户输入字符串连接，用户很可能会运行恶意的数据库查询。

  2. CVE-2020-1956 Apache Kylin命令注入漏洞

    Kylin的restful api，它将用户输入字符串与os命令连接起来，用户可以在没有任何保护或验证的情况下执行任何系统命令。


漏洞危害

CVE-2020-1937 Apache Kylin SQL注入漏洞       高危

CVE-2020-1956 Apache Kylin命令注入漏洞        高危


影响版本

  • Kylin 2.3.0 to 2.3.2

  • Kylin 2.4.0 to 2.4.1

  • Kylin 2.5.0 to 2.5.2

  • Kylin 2.6.0 to 2.6.4

  • Kylin 3.0.0-alpha, Kylin 3.0.0-alpha2, Kylin 3.0.0-beta, Kylin 3.0.0


安全建议

  • 用户应该升级到3.0.2或2.6.6或设置kylin.tools.auto-migration-cube为false禁用命令执行。
