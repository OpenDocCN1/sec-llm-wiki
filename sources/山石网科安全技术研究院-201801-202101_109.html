漏洞通告 | WebSphere远程代码执行漏洞（CVE-2020-4450）

漏洞背景

2020年6月8日，山石网科安全技术研究院旗下的安全预警分析团队监测到IBM和国内安全厂商发布WebSphere远程代码执行漏洞的信息。


漏洞描述

漏洞由IIOP协议上的反序列化造成，远程攻击者可以使用特制的序列化对象序列通过IIOP协议攻击服务器，在目标服务端执行任意代码，IIOP协议默认是开启的。


漏洞危害

高危


影响版本

  • WebSphere Application Server 9.0.0.0 – 9.0.5.4

  • WebSphere Application Server 8.5.0.0 – 8.5.5.17

  • WebSphere Application Server 8.0.0.0 – 8.0.0.15 

  • WebSphere Application Server 7.0.0.0 – 7.0.0.45


安全建议

  • IBM已发布发布补丁

    9.0.0.0-9.0.5.4，安装补丁PH25074

    8.5.0.0-8.5.5.17，安装补丁PH25074

    7.0和8.0请更新至7.0.045或8.0.0.15，再安装补丁PH25074
