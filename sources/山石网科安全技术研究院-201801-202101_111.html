漏洞背景

2020年6月2日，外安全研究员公开了一份SMBGhost（绰号：永恒之黑）漏洞的RCE代码。该漏洞（CVE-2020-0796）在2020年3月12日，由微软官方发布了WindowsSMBv3 客户端/服务器远程代码执行漏洞的安全更新细节和补丁程序，发布之初就被官方标记为“被利用可能性高”。


由于该研究员在GitHub上公开了一份此漏洞的远程代码执行利用代码，漏洞的现实威胁进一步升级。由于漏洞无需用户验证的特性，可能导致类似WannaCry攻击那样蠕虫式的传播。鉴于漏洞危害很大，建议尽快安装补丁更新，山石产品最新规则已经可以全面防御该漏洞。



漏洞描述

漏洞发生在srv2.sys中,由于SMB没有正确处理压缩的数据包,在解压数据包的时候使用客户端传过来的长度进行解压时,并没有检查长度是否合法.最终导致整数溢出。

SMB v3中支持数据压缩,如果SMB Header中的ProtocolId为0x424D53FC也就是0xFC, 'S', 'M', 'B'.那么就说明数据是压缩的,这时smb会调用压缩解压处理的函数.

首先SMB会调用srv2!Srv2ReceiveHandler函数接收smb数据包，并根据ProtocoIId设置对应的处理函数。

漏洞检测


已经很多的验证脚本，整体的思路都是验证回包中的特定位置是否包含十六进制的\x11\x03或\x02\x00这两个关键字。

在存在漏洞的SMB版本的通信回包如下：

漏洞危害

高危


影响版本

  • 漏洞影响Windows10 1903之后的各个32位、64位版Windows，包括家用版、专业版、企业版、教育版。Windows 7不受影响。

  • Windows 10 Version 1903 for 32-bitSystems

  • Windows 10 Version 1903 for x64-basedSystems

  • Windows 10 Version 1903 forARM64-based Systems

  • Windows Server, Version 1903 (ServerCore installation)

  • Windows 10 Version 1909 for 32-bitSystems

  • Windows 10 Version 1909 for x64-basedSystems

  • Windows 10 Version 1909 forARM64-based Systems

  • Windows Server，Version 1909 (ServerCore installation


安全建议

  •  直接运行Windows 更新，完成补丁的安装。操作步骤：设置->更新和安全->Windows更新，点击“检查更新”。

  • 微软官方已发布针对此漏洞受影响版本的补丁程序，该安全更新通过更正SMBv3协议处理这些特制请求的方式来解决此漏洞。也可参考以下链接尽快安装补丁程序：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0796

    补丁链接：https://catalog.update.microsoft.com/v7/site/Search.aspx?q=KB4551762

  • 如果暂时无法安装补丁程序，可采取临时缓解措施：

    禁用SMBv3 compression

    用户可使用以下PowerShell命令禁用compression功能，以阻止未经身份验证的攻击者利用此漏洞来攻击SMBv3服务器：

Set-ItemProperty-Path "HKLM:\SYSTEM\CurrentControlSet\Services\LanmanServer\Parameters"DisableCompression -Type DWORD -Value 1 -Force
请注意（1）进行更改后，无需重新启动。（2）此解决方法不能防止针对SMB客户端的利用。使用以下PowerShell命令可解除禁用compression

  • 端口限制：在企业外围防火墙处阻止445端口的连接。TCP端口445用于启动与受影响组件的连接。在网络外围防火墙处阻止此端口将有助于保护位于防火墙后面的系统免受尝试利用此漏洞的攻击。这可以保护网络免受来自企业外围的攻击。在企业范围内阻止受影响的端口是避免基于Internet的攻击的最佳防御方法。但是，系统仍可能受到企业内网络的攻击。

    遵循Microsoft准则以防止SMB流量流出公司网络，详情请查阅以下链接：

    https://support.microsoft.com/en-us/help/3185535/preventing-smb-traffic-from-lateral-connections
