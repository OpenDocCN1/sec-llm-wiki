# 山石网科安全技术研究院介绍

山石网科安全技术研究院简称“山石安研院”，Hillstone Security Technology Research Institute，英文简称HSTRI，正式成立于2020年4月，是山石网科的信息安全智库部门，其前身是原安全服务部下的安全研究团队。山石安研院整体架构包括干将、莫邪两大安全实验室，以及安全预警分析、高端攻防培训两支独立的技术团队。安研院主要负责反APT跟踪和研究、出战全球攻防赛事及承办、高端攻防技术培训、全球中英文安全预警分析发布、各类软硬件漏洞挖掘和利用研究、承接国家网络安全相关课题、不定期发布年度或半年度的各类技术报告及公司整体攻防能力展现。技术方向包括移动安全、虚拟化安全、工控安全、物联安全、区块链安全、协议安全、源码安全、反APT及反窃密。在国家新基建及十四五规划即将到来的大背景下，我们将进一步全面为国家信息安全助力。

自2015年5月以来支撑公司向客户交付了几百次的安全测试服务，其中有web安全测试、渗透测试、代码审计和APP测试等各种类型，为中南空管局、深圳空管局、辽宁省朝阳市朝阳银行、苏宁环球、上海海事局、北京中国银行及山东省公安厅信通处等众多的客户提供了多场的高端攻防培训。

代表公司建立与国家互联网应急中心CNCERT的支撑合作关系，多年来给CNVD平台提交漏洞近千个，CNVD证书30多张。建立与国家漏洞库CNNVD的合作关系，提交漏洞近千个，获得证书20多个，获得CVE编号50多个，获得微软等知名企业多次的官网致谢，公布过多个全球影响力的严重漏洞。

曾协助客户申请世界技能大赛中国队网络安全代表队的训练基地，与国内各大甲方SRC平台建立合作关系，在多个甲方SRC都获得很好的名次。山石安研院多名研究员入选公安部网络安全千人计划候选人及广东省网络安全应急响应平台支撑单位专家库名单。参与OWASP Code Review Guide 2.0翻译并出版，合作出版书籍三本《应用软件安全代码审查指南》、《安全测试指南（第4版）》、《云计算安全防护技术》。

山石安研院与辽宁省、广东省、江苏省、江西省、山东省等五省公安厅都有支撑合作，得到了很好的表扬。代表公司参加了辽宁省、广东省多地公安厅的护网2018、2019、2020等网络攻防实战演习参演，两会期间支持广东省公安厅检查工作、协助济南办进行青岛上合峰会安全检查并获得表扬信、江苏省地市法院安全检查、改革开放40周年及港珠澳大桥的开通安保工作并获得表扬信、江苏省首届网络安全攻防演练活动、江西省公安厅公安内部比赛支撑。多年来代表公司参加了国家级、省级各类网络攻防大赛二十多场。

最后附上一条小招聘信息，******实习****安全研究员，苏州/北京，**WEB、二进制两个方向。

**职位描述：**

1、参与山石安研院研究工作，能提供安全问题的解决思路或针对性解决的模型；

2、跟踪重大安全事件，分析漏洞和攻击流程，撰写研究报告并发布预警；

3、负责原创漏洞挖掘，以及对出现的0day漏洞事件进行追踪分析和防御研究；

4、为公司安全产品提供代码级技术原型支持，需要足够的编码能力。  

  

**任职要求：**

1、 具有良好的洞察力、数据分析和归纳总结能力，能够从日志中发现异常事件；

2、 熟悉各类安全漏洞原理，对Web安全、服务端安全、客户端安全、移动安全、无线安全、物联网安全等某个方向有研究基础；

3、 有在国内外发布过重大影响漏洞的优先，至少在一个领域有过漏洞挖掘经验，提供CVE编号、CNVD证书、CNNVD证书等证明；

4、 熟练使用C\\C++、php、JS、java、python、Go等至少一种编程语言

5、 有CTF比赛经验者,独立发表过漏洞分析文章者或参与过IDS建设、恶意流量分析、海量日志分析者优先；

6、 具备良好的英文听说读写能力，能够无障碍阅读英文技术文档；

7、 具备良好的团队沟通、理解能力、协作能力、职业道德、责任心，能承受一定强度的工作压力。
