漏洞通告|Apache Tomcat Session 反序列化代码执行漏洞（CVE-2020-9484）

漏洞背景

近日，山石网科安全技术研究院旗下的安全预警分析团队监测到近日Apache Tomcat官方发布安全公告，披露了一个通过持久化Session可能导致远程代码执行的漏洞CVE-2020-9484。


漏洞描述

攻击者可以构造恶意请求，执行反序列化代码漏洞，但要成功利用该漏洞需要同时满足以下四个条件：

1. 攻击者能够控制服务器上文件的内容和名称；
2. 服务器PersistenceManager配置中使用了FileStore；
3. PersistenceManager配置sessionAttributeValueClassNameFilter的值为“NULL”，或者使用了其他较为宽松的过滤器，允许攻击者提供反序列化数据对象；
4. 攻击者知道使用的FileStore存储位置到可控文件的相对文件路径。

经过复现分析该漏洞整体利用条件较为苛刻，实际危害相对较低。

漏洞危害

中危


影响版本

Apache Tomcat 10.x < 10.0.0-M5

Apache Tomcat 9.x < 9.0.35

Apache Tomcat 8.x < 8.5.55

Apache Tomcat 7.x < 7.0.104


安全建议

1. 升级Apache Tomcat到安全版本

2. 禁止使用Session持久化功能

为彻底防止漏洞潜在风险，建议Apache Tomcat用户修复漏洞。
