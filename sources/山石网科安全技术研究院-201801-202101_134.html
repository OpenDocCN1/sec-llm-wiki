漏洞描述

Cacti是Cacti团队的一套开源的网络流量监测和分析工具。该工具通过snmpget来获取数据，使用RRDtool绘画图形进行分析，并提供数据和用户管理功能。Cacti 1.2.8版本中的graph_realtime.php文件存在安全漏洞，远程攻击者可借助cookie中的shell元字符利用该漏洞执行任意操作系统命令。



漏洞分析

该漏洞发生在尝试将恶意代码注入“ Cacti” cookie变量时，在与一些字符串连接后被传递给shell_exec函数，但是当尝试操作cookie值时会遇到身份验证问题，这将无法访问该页面，因此可以以“Guest”身份访问漏洞页面，不需要身份验证即可访问。


在170和171行可以看到，接收了几个参数并将它们连接在一起，还可以看到“ get_request_var”函数


graph_realtime.php

/* call poller */
$graph_rrd = read_config_option('realtime_cache_path') . '/user_' . session_id() . '_lgi_' . get_request_var('local_graph_id') . '.png';
170  $command   = read_config_option('path_php_binary');
171  $args      = sprintf('poller_realtime.php --graph=%s --interval=%d --poller_id=' . session_id(), get_request_var('local_graph_id'), $graph_data_array['ds_step']);
shell_exec("$command $args");

/* construct the image name  */
$graph_data_array['export_realtime'] = $graph_rrd;
$graph_data_array['output_flag']     = RRDTOOL_OUTPUT_GRAPH_DATA;
$null_param = array();


该函数将通过“ set_request_var”函数处理输入并设置参数值


html_utility.php

function get_request_var($name, $default = '') {
    global $_CACTI_REQUEST;

    $log_validation = read_config_option('log_validation');

    if (isset($_CACTI_REQUEST[$name])) {
        return $_CACTI_REQUEST[$name];
    } elseif (isset_request_var($name)) {
        if ($log_validation == 'on') {
            html_log_input_error($name);
        }

        set_request_var($name, $_REQUEST[$name]);

        return $_REQUEST[$name];
    } else {
        return $default;
    }
}


该函数将执行以下操作：


html_utility.php

function set_request_var($variable, $value) {
    global $_CACTI_REQUEST;

    $_CACTI_REQUEST[$variable] = $value;
    $_REQUEST[$variable]       = $value;
    $_POST[$variable]          = $value;
    $_GET[$variable]           = $value;
}


可以控制以下输入：

  • local_graph_id

  • $ graph_data_array ['ds_step']的值


得到另一个传递给shell_exec的变量，该变量是“ session_id（）”函数的值，函数将返回用户当前会话的值，可以使用它来注入命令。





漏洞危害

高危




影响版本

Cacti v1.2.8(最新版本为1.2.9)




安全建议

如果启用了“ Gest Realtime Graphs”特权，可以利用此漏洞，因此最好检查“ graph_realtime.php”文件是否具有此访问特权。


请将Cacti升级到最新1.2.9版本
