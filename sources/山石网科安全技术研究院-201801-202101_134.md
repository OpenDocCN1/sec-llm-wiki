## ******漏洞描述******  

Cacti是Cacti团队的一套开源的网络流量监测和分析工具。该工具通过snmpget来获取数据，使用RRDtool绘画图形进行分析，并提供数据和用户管理功能。Cacti 1.2.8版本中的graph\_realtime.php文件存在安全漏洞，远程攻击者可借助cookie中的shell元字符利用该漏洞执行任意操作系统命令。

  

  

## ******漏洞分析******  

该漏洞发生在尝试将恶意代码注入“ Cacti” cookie变量时，在与一些字符串连接后被传递给shell\_exec函数，但是当尝试操作cookie值时会遇到身份验证问题，这将无法访问该页面，因此可以以“Guest”身份访问漏洞页面，不需要身份验证即可访问。

  

在170和171行可以看到，接收了几个参数并将它们连接在一起，还可以看到“ get\_request\_var”函数

  

```


graph_realtime.php
```

  

该函数将通过“ set\_request\_var”函数处理输入并设置参数值

  

```


html_utility.php
```

  

该函数将执行以下操作：

  

```


html_utility.php
```

  

可以控制以下输入：

*   local\_graph\_id
    
*   $ graph\_data\_array \['ds\_step'\]的值
    

  

得到另一个传递给shell\_exec的变量，该变量是“ session\_id（）”函数的值，函数将返回用户当前会话的值，可以使用它来注入命令。  

  

![](../Images/97fcaecff422c81f3efaacd05c28954a.png)

  

  

  

## ******漏洞危害******  

**高危**

  

  

  

## ******影响版本******

Cacti v1.2.8(最新版本为1.2.9)

  

  

  

## ******安全建议******  

如果启用了“ Gest Realtime Graphs”特权，可以利用此漏洞，因此最好检查“ graph\_realtime.php”文件是否具有此访问特权。

  

请将Cacti升级到最新1.2.9版本
