漏洞背景

1月14日，微软发布了2020年第一个补丁日漏洞公告，其中包含Windows最新版本（包括Windows 10和Windows Server 2016/2019）中使用的加密库中一个严重漏洞补丁公告。此漏洞由美国国家安全局（NSA）发现并披露给了Microsoft ，漏洞编号为CVE-2020-0601。


目前，尚未发现在野漏洞利用和PoC代码，但是，根据美国国家安全局（NSA）的建议，远程利用工具可能会迅速广泛在公网出现，建议用户尽快安装2020年1月发布的补丁，以有效缓解Windows 10和Windows Server 2016/2019系统上的漏洞。



漏洞描述

NSA发现影响MicrosoftWindows加密函数的严重漏洞（CVE-2020-0601）。

此使攻击者可以破坏Windows验证密码的信任机制，并且可以进行远程代码执行。该漏洞会影响Windows 10和Windows Server 2016/2019以及依赖Windows获得信任的所有应用程序。利用此漏洞可以使攻击者突破可信任人的网络连接并进行远程代码执行。

漏洞位于crypt32.dll的Windows组件中，该Windows模块会处理 CryptoAPI中的证书和加密消息传递。 Microsoft CryptoAPI 提供的服务使开发人员能够保护Windows的安全，使用加密的的应用程序可以对数据进行加密和解密。



影响的信任验证包括：

o HTTPS连接

o签名的文件和电子邮件

o作为用户模式进程启动的签名可执行代码


该漏洞使Windows客户端和服务端面临各种利用威胁。NSA评估该漏洞为非常严重，远程利用工具可能会快速广泛地在公网散播。快速更新补丁程序是目前唯一的缓解措施。
