## ******漏洞背景******  

Citrix 近日公开修复了一个远程代码执行漏洞CVE-2019-19781, 未经身份验证的攻击者可以利用此漏洞执行任意代码。可以对NetScaler / ADC设备执行RCE攻击。此漏洞使攻击者可以绕过授权来创建具有用户控制内容的文件，然后可以通过服务器端脚本语言对其进行处理。可能还会有其他代码执行路径。

  

  

## ******漏洞描述******  

Citrix ADC（以前称为NetScaler）和Citrix Gateway的所有产品版本都会受到影响。攻击者可以通过访问Web界面访问ADC门户网站所使用的ADC / NS IP或虚拟IP来利用此功能，而无需考虑许可或配置功能。**成功的利用漏洞使攻击者可以完全控制受影响的系统。**一旦攻击者控制了系统，他们就可以访问专用网络资源，并且可以通过劫持经过身份验证的用户会话或窃取用户凭据来进一步横向渗透。

## ******漏洞危害******  

**高危**

  

  

## ******影响版本******  

Citrix ADC和Citrix Gateway 13.0 

Citrix ADC和NetScaler Gateway 12.1 

Citrix ADC和NetScaler Gateway 12.0 

Citrix ADC和NetScaler Gateway 11.1 

Citrix NetScaler ADC和NetScaler Gateway 10.5

  

  

## ******安全建议******  

利用此漏洞的URL中带有“ /../”和“ / vpns /”的HTTP请求。

  

应该拦截url中包含 /../ 的恶意请求。
