APT28（也通常称为FancyBear，STRONTIUM，Sednit，Sofacy等）是一个APT组织，根据美国司法部2018年7月的起诉书，这个组织被归为俄罗斯总参谋部情报总局的军方APT组织。该组织从2004年开始活跃，主要从事间谍活动。它的目标包括全球性公司的核心部门，军事和政府。  

  

## ******事件分析******

发现有一个“ gorodpavlodar.doc”文档。该文档是一封电子邮件的附件，这个电子邮件钓鱼发送给了很多人。这些收件人在一家大型矿业公司工作，这家公司是在哈萨克斯坦运营的。

  

这封电子邮件称是从“ Pavlodar市官方资源”发送的，但实际上是通过“ pavlodar.news@bk.ru”地址发送的。帕夫洛达尔（Pavlodar）是哈萨克斯坦东北部的一个城市，也是帕夫洛达尔地区的首府。原始电子邮件和翻译在下面列出，这会提示电子邮件的收件人查看附件的文档。

随附的文档还包含俄语文字，其译文大致为“给住宅供应热水的时间表”，并且据称来自“Akimat City Pavlodar的官方互联网资源”。该文件似乎是收件人用来填写其住址，停水日期和缺少热水的原因的表格。它还提示收件人启用“编辑/内容”以查看“受保护”的文档。

  

![](../Images/26ab70489698b61ab2828ea1612665a1.png)

  

通过Word中的“开发人员”选项卡打开Visual Basic控制台会显示一个受密码保护的项目，如果启用了内容，该项目将运行。为了绕过此密码限制，我在十六进制编辑器中打开了文档，并搜索了包含VBA密码的字符串“ DPB =”，并将其更改为“ DP x =”。此后打开项目将导致Word引发有关无效密钥（DPx）的多个错误，但允许我绕过密码限制。这使我可以查看项目的内容，如下所示，它看起来像是一个UserForm，其中除了一些标签之外，在两个输入框中还包含大量数据。

  

![](../Images/ccb523edd595064a6531df46721e3cd5.png)

Private Function drgvfdhre(tyruyt)  Dim fghfhggjj, asddf  Set fghfhggjj = CreateObject("Microsoft.XMLDOM")  Set asddf = fghfhggjj.createElement("tmp")  asddf.dataType = "bin.base64"  asddf.Text = tyruyt  drgvfdhre = asddf.nodeTypedValueEnd Function
Private Sub vbnbnm(tgbyh, edcrf)  Dim qsxx  Set qsxx = CreateObject("ADODB.Stream")  qsxx.Type = 1  qsxx.Open  qsxx.Write edcrf  qsxx.SaveToFile tgbyh, 2End Sub

执行宏后，将删除原始文档，并打开辅助文档“ graphic.doc”。该文档似乎是原始文档中包含的表单的“完整”版本，并且还包含执行上述可执行文件“ libssl.exe”的嵌入式宏。

  

![](../Images/7deee852150ac7810d61f675037497ac.png)

  

然后，它将通过HTTP POST请求www.gorodpavlodar.kz/modules/Contact/Includes/1c.php和www.gorodpavlodar.kz/modules/Contact/Includes/2c.php，以及硬编码的用户代理字符串“Mozilla/5.0（Windows NT 10.0；Win64；x64）”，启动两个硬编码URL的命令和控制通信。POST信息包括URL编码的主机信息-例如唯一ID，驱动器信息，主机名，操作系统，用户名，BIOS，日期，进程列表等。过去，这些POST请求会在服务器响应中接收二进制数据，但是现在可以用404 HTTP响应。

  

![](../Images/2636ea3c87b4edd0ced0852ae6cf9e93.png)

  

与二进制文件相关的活动容易让人联想到APT28的“ Zebrocy”后门程序。此外，二进制文件的静态分析表明，和其他有记录的“Zebrocy”程序有很多相似之处，特别是Vitali Kremez记录的程序。尽管这不是APT28负责该样本的确凿证据，但它与其他已确认的Zebrocy后门程序之间的相似性，以及哈萨克斯坦一直是APT28所针对的事实，还是值得怀疑的。
