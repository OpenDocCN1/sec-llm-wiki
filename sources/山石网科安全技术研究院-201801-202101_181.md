## ******漏洞描述******  

2019年09月11日，微软发布了9月份的安全更新公告。此次安全更新主要涵盖了Windows, IE, Edge浏览器, ChakraCore引擎, Office 服务等，其中较为突出的是：RDP Client 远程代码执行漏洞。

此系列漏洞不同于5月的BlueKeep漏洞（CVE-2019-0708）、8月的DejaBlue漏洞（CVE-2019-1181/1182）。此系列漏洞是出现在客户端的漏洞，需要受害者连接到恶意的服务器才会触发远程代码执行。

  

  

## ****漏洞详情****  

**Windows RDP 客户端远程代码执行漏洞**  

**CVE-2019-0787/CVE-2019-0788/CVE-2019-1290/CVE-2019-1291 **

  

这4个漏洞均是等级为 Critical (严重) 的漏洞，要利用此系列漏洞，攻击者需要控制服务器，然后使用户连接到该服务器。但因为攻击者无法强迫用户连接到恶意服务器，所以可能需要通过多种方式欺骗用户连接，如利用社会工程学、DNS中毒或使用中间人攻击（MITM）。目前公网上还未出现针对此漏洞的利用代码及在野攻击，但仍然需要用户引起高度重视。

  

  

## ****漏洞危害****  

**高危**

  

  

## **影响版本**

Microsoft Windows 10及其之后更新版本

Microsoft Windows 8.1 x32/x64Microsoft Windows 7 SP1 x32/x64Microsoft Windows RT 8.1
