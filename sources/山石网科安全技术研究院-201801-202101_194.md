## ******漏洞描述******  

2019年8月14日微软官方发布了安全补丁,其中包含2个严重的远程代码执行漏洞CVE-2019-1181和 CVE-2019-1182。这两个漏洞类似于此前修复的“BlueKeep”漏洞 (CVE-2019-0708)，也是“蠕虫级”漏洞，也就是说利用这些漏洞的任意恶意软件都能在无需用户交互的情况下从一台易受攻击的计算机传播到另外一台易受攻击的计算机中。

**此漏洞下的恶意病毒的传播方式之前席卷全球的WannaCry恶意软件的传播方式类似。**

**HSCERT研判，此漏洞级别为：严重，请用户尽快升级更新。**

  

  

  

## ****漏洞危害****  

公网开放RDP服务的主机数量巨大，影响面极大。

**严重**

  

  

## **影响版本**

该漏洞主要影响Windows主流操作系统 ，Windows XP、Windows Server 2003和Windows Server 2008不受影响，远程桌面协议(RDP)本身也不受影响

  

受影响版本：  

  

```
Windows 
```

  

  

  

## **安全建议**

1.微软已经发布了漏洞补丁，请用户尽快升级：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-1181

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-1182

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-1222

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-1226

  

2.临时缓解措施：

通过在系统上启用网络及身份认证（NLA）以暂时规避该漏洞影响

  

3.阻断企业外围防火墙上的TCP端口3389

  

4.如无必要，可禁用远程桌面服务
