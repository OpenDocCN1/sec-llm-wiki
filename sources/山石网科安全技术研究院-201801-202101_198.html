漏洞描述

近日，HSCERT监测发现，安全人员在Twitter上披露了一个关于KDE Framewors的命令执行漏洞。该漏洞是由于KDesktopfile类在处理.desktop、.directory文件时存在问题。攻击者可以创建恶意的此类型文件，用户在使用KDE file viewer浏览这些文件时就可触发漏洞，导致恶意文件代码执行，只需诱骗用户下载压缩文档、解压之后打开文件夹就能执行代码。

当前几乎所有的Linux 发行版本都受到此KDE漏洞的影响。



漏洞分析

此漏洞存在于 KDE 版本4和5中，可导致内嵌在.desktop 和 .directory 文件中的命令执行，只需打开一个文件夹或在某些情况下将压缩文档解压到桌面即可。

Freedesktop.org-compalint 桌面环境使用特殊的 .desktop 和 .directory 文件来配置应用和文件夹的显示方式。.desktop 文件用于在 KDE 目录中注册应用，而 .directory 文件用于说明 KDE 应该如何显示文件夹。
每份文件中都有各种字段，告知桌面环境如何显示目录或应用。其中的一个字段是Icon，在.desktop 文件中它指定了KDE 应该在目录中展示的图标路径，而对于 .directory 文件而言，它将指定在 Dolphin 查看文件夹时所使用的图标。
此漏洞存在于 KDE 允许使用shell 扩展通过某个环境变量或执行命令的方式动态地生成这些字段的值。
由于在Dolphin 或从Desktop 查看文件时可以被自动读取，因此可导致攻击者构造恶意 .desktop 和 .directory 文件夹，执行位于Icon字段中的命令。

攻击演示：
创建一份包含 .directory 文件的子文件夹的 ZIP 文件。这个目录文件的 Icon 字段中包含一个从服务器中下载 test.sh 脚本的命令并执行以启动 Kcalc。


用户下载test.zip 文件后解压并打开，KDE 就会读取 .directory 文件并执行分配给 Icon 字段的命令。



漏洞危害

高危



影响版本

KDE kconfig < 5.61.0



安全建议

KDE官方已经在最新版本中彻底移除了造成上述漏洞的相关功能，请用户尽快升级。
