## ******事件来源******  

近日，HSCERT监测发现有APT组织在使用LockerGoga勒索软件对某些厂商进行定向攻击。

LockerGoga是一种勒索软件，这款病毒有一些有趣的行为，通过我们研究，并与其他家族进行比较，它具有一些独特的功能和行为，与其他活跃的勒索软件家族相比，有一些非常少见的功能。

为了发现它的功能，我们分析了我们找到的所有样本，发现了它们之间的相似之处，以及开发生命周期如何添加或修改代码中的不同功能。

  

## ****样本分析****

LockerGoga和其他勒索软件家族的主要区别之一，是能够产生不同的进程，以在系统中加快文件加密的速度:  

  

![](../Images/387d8c6fe81a2d244690db6c91de9a06.png)

  

与其他类型的恶意软件一样，LockerGoga将使用系统中所有可用的CPU资源：

  

![](../Images/156b161a33f7ff14153ca22d90dc893f.png)

  

大多数LockerGoga样本的工作方式相同，我们观察了他们在开发生命周期中如何添加和删除某些类型的功能。

勒索软件需要从特权帐户执行。

LockerGoga在主/从配置中工作。恶意软件通过在％TEMP％文件夹上安装自身副本来开始感染终端。

![](../Images/e3315a5ec44cc7dfbd5fd1d6134419db.png)

复制后，它将使用-m参数启动一个新进程。

主进程使用-m参数运行，并负责创建要加密和生成从属的文件列表。

将使用一组不同的参数执行从属进程，如下所示。每个从属进程仅加密少量文件，以避免终端安全产品中可用的启发式检测。要加密的文件列表是通过IPC从主进程获取的，IPC是用于在Microsoft Windows中的应用程序之间共享数据的接口。通过IPC使用名为SM- <二进制名称>的映射部分完成通信。

以下是LockerGoga使用的IPC技术：

l 主进程（作为<LockerGogaBinary> -m运行）在系统上为IPC创建命名部分。

l 该部分名为“SM-tgytutrc”。

l 主勒索软件进程将要加密的文件的文件路径发送到“SM-tgytutrc”。

l 从属进程使用此部分来获取文件路径并加密目标文件。

 

沙箱复制主流程截图如下：

l 创建命名部分。

l 随后创建从属进程以加密PC上的目标文件。

  

![](../Images/2ca46a06e5e261f851afa230f2736bcf.png)

  

下面的从属进程（加密过程）的沙箱复制显示：

l 获取对主进程创建的部分的访问权限。

l 读取和加密基于命名部分中指定的文件路径找到的目标文件。

  

![](../Images/3d64f294fb1b944534055ac62a73052b.png)

  

勒索软件在终端上创建多个从属进程以加密文件。一些分析师认为这只是因为它加速了加密过程，但我们并不这样认为，因为通过勒索软件过程中的多线程方法而不是多进程方法可以实现相同的结果。

我们怀疑采用这种方法的原因如下：  

l 痕迹：  如果每个加密过程仅加密终端上的少量文件并终止，那么攻击对系统的整体占用空间就会减少，因为可能很难将多个加密过程与同一个威胁联合起来。

l 沙箱绕过：一些基于沙箱的检测系统监视写入系统的文件数量的阈值，并可能将其与写入的文件扩展名相关联。例如，如果一个进程在沙盒上读取200个文件，但只创建具有一个特定扩展名的文件（典型的勒索软件 - 在LockerGoga的情况下为Extn“.locked”）则可以将此视为异常行为。LockerGoga可能能够绕过这种检测技术。

基于文件I / O的检测旁路：基于多进程的方法可确保每个加密过程的I / O量（文件/磁盘I / O等）都在一定限度内，从而绕过监控的检测技术基于I / O的检测。

l 可靠性：即使最终用户手动终止一个加密过程，只要主勒索软件进程正在运行，文件将继续由新的从属进程加密。如果勒索软件进程不使用多进程方法，则终止勒索软件进程会停止终端上的加密。

样本数字签名：

在我们的分类阶段，我们发现一些LockerGoga样本已经过数字签名。我们正在从ATR观察到最新的勒索软件使用较低规模和更集中的数字签名：

l MIKL LIMITED

l ALISA LTD

对恶意软件进行数字签名可以帮助攻击者绕过系统中的一些安全保护措施。

作为感染过程的一部分，LockerGoga将在系统中创建静态互斥锁值，始终遵循相同的格式：MX- \[AZ\] \\ W +

传播方式：

已知恶意软件通过远程文件复制在本地网络中传播。为此，使用简单副本将一组.batch文件复制到远程计算机TEMP文件夹：

l复制xax.bat \\\\ 123.123.123.123 \\ c $ \\ windows \\ temp

恶意软件会将自身和工具PSEXEC.EXE复制到同一位置。复制完所有文件后，恶意软件将使用以下命令运行.BAT文件：

lStart psexec.exe \\\\ 123.123.123.123 -u domain \\ user -p“pass”-d -h -r mstdc -s accepteula -nobanner c：\\ windows \\ temp \\ xax.bat

这些.BAT文件中的每一个都包含在远程计算机上执行恶意软件的行。他们使用以下命令：

lstart wmic /node:"123.123.123.123“/ user：”domain \\ user“/ password：”pass“进程调用create”cmd /cc:\\windows\\temp\\kill.bat“

上面的批处理文件试图杀死多个AV产品并禁用安全工具。在脚本结束时，将执行远程计算机上的恶意软件副本

lC：\\ WINDOWS \\ TEMP \\ taskhost.exe。

由于这些批处理文件的存在以及恶意软件二进制文件没有直接引用它们，我们认为传播机制是由攻击者或未知二进制文件手动执行的。路径，用户名和密码在脚本中是硬编码的，表明攻击者之前已了解环境。

##  **病毒防护**

客户可以添加以下访问保护规则，以防止在受害主机上创建加密文件：

l File/Folder Access Protection Rule: Processes tInclude

l File or folder name tblock: \*.locked

l File actions tprevent: New files being create

  

客户还可以添加符合以下特征的访问保护规则：阻止创建\\执行：

l c:\\windows\\temp\\x??.bat

l c:\\windows\\temp\\kill.bat

l c:\\windows\\temp\\taskhost.exe

  

防止执行使用SN签名的二进制文件：

l C = GB，PostalCode = DT3 4DD，S = WEYMOUTH，L = WEYMOUTH，STREET = 16 Australia Road Chickerell

l O = MIKL LIMITED，CN = MIKL LIMITED
