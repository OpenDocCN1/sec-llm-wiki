漏洞预警 |微软补丁日发布多个高危漏洞安全更新

2019-04-11

   

事件来源

近日，HSCERT监测到微软发布了2019年3月份的月度安全漏洞公告，修复了其多款产品存在的270个安全漏洞。

利用上述漏洞，攻击者可以提升权限，绕过安全功能限制，获取敏感信息，执行远程代码或发起拒绝服务攻击等。

HSCERT判断此次更新针对的漏洞影响的范围广泛，建议广大用户及时通过 Windows 的安全更新服务及时进行系统升级，避免遭受到黑客攻击以及恶意软件的侵害。



漏洞描述

列出几个较为严重的漏洞描述：


CVE-2019-0786

Microsoft Windows SMB Server远程代码执行漏洞

攻击者首先必须登录系统。然后，攻击者可以运行之前专门设计的程序，该程序可以利用漏洞并控制受影响的系统。


CVE-2019-0859

Microsoft  Windows Win32k本地权限提升漏洞

当win32k组件未能正确处理内存中的对象时，Windows中存在权限提升漏洞，也称为“win32k权限提升漏洞”。攻击者可以运行专门设计的程序，该程序可以利用漏洞并控制受影响的系统。


CVE-2019-0822

Microsoft Windows Graphics Component远程代码执行漏洞

Microsoft图形组件处理内存对象的方式存在远程代码执行漏洞，也称为“Microsoft图形组件远程代码执行漏洞”。攻击者可以利用此漏洞在目标系统上执行任意代码，失败的攻击尝试也可能会导致拒绝服务攻击。


CVE-2019-0739

Microsoft Edge Chakra Scripting Engine远程内存破坏漏洞

攻击者可以制作一个精心设计的网站，该网站可以利用Edge中的漏洞，攻击者钓鱼说服用户查看该网站，攻击者可以添加可利用该漏洞的内容。


CVE-2019-0853 

Microsoft Windows  GDI+ 远程命令执行漏洞

在解析EMF文件记录时会出现该漏洞，特制的EMF文件记录可以触发对未初始化指针的访问，这允许攻击者执行任意代码。
此漏洞影响到多个微软组件和程序，尤其是操作系统和办公套件这些大规模利用 GDI+ 的组件。


CVE-2019-0793 

Microsoft Windows XML 远程命令执行漏洞

微软XML核心服务MSXML解析器处理用户输入时，存在远程代码执行漏洞。成功利用该漏洞的攻击者可以远程运行恶意代码来控制用户的系统。


CVE-2019-0831

Microsoft Office SharePoint跨站脚本漏洞

经过身份验证的攻击者可以通过向受影响的SharePoint服务器发送精心设计的请求来利用该漏洞。成功利用该漏洞的攻击者可以对受影响的系统执行跨站点脚本攻击，并在当前用户的安全上下文中运行脚本。


CVE-2019-0688 

Microsoft Windows TCP/IP 信息泄漏漏洞

SAS令牌和资源标识等数据可能会泄露给攻击者。IP分片攻击已经存在多年了，Ping of Death和Teardrop就是早期的例子。即使在现代的TCP/IP堆栈中，协议攻击仍然存在。


CVE-2019-0786

Microsoft Windows SMB 权限提升漏洞

当具有有效凭据的攻击者试图在一台计算机上通过 SMB 打开特制文件时，可能会触发微软服务器 SMB 中存在的权限提升漏洞。成功利用此漏洞的攻击者可以绕过操作系统中的某些安全检查机制，进而获得该计算机更高级的控制权限。

漏洞防护

鉴于本月修复的多个漏洞影响严重，部分漏洞技术细节已被公开，HSCERT建议广大用户尽快进行修补，以免遭受到黑客攻击以及恶意软件的侵害。

请及时进行 Microsoft Windows 版本更新并且保持 Windows 自动更新开启

windows server / windows 检测并开启 Windows 自动更新流程如下：

  • 点击开始菜单，在弹出的菜单中选择“控制面板”进行下一步！

  • 点击控制面板页面中的“系统和安全”，进入设置。

  • 在弹出的新的界面中选择“windows update”中的“启用或禁用自动更新”。

  • 然后进入到了设置窗口了，可以看到其中的下拉菜单项，打开下拉菜单项，选择其中的自动安装更新（推荐）。
