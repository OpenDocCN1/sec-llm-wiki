漏洞预警 |Atlassian Confluence官方发布多个严重漏洞通告

2019-04-09  

   

**事件来源**

近日，Atlassian 官方在发布的安全通告中修复了两个影响  Confluence Server 与Confluence Data Center的漏洞，Atlassian 官方将这两个漏洞定级为严重漏洞，漏洞编号是 CVE-2019-3395 与 CVE-2019-3396。  

  

  

**漏洞描述**

Confluence是一个专业的企业知识管理与协同软件，可以用于构建企业wiki，已经在超过100个国家，13500个组织中成功地应用于企业内网平台、知识管理及文档管理，涉及财富1000企业、政府机构、教育机构、财务金融机构及技术研究领域。包括IBM、Sun MicroSystems、SAP等众多知名企业使用Confluence来构建企业Wiki并面向公众开放。

  

CVE-2019-3395 是存在于 Confluence Server 与 Confluence Data Center 中 WebDAV 插件中的 SSRF 漏洞，官方将此漏洞定级为严重。攻击者可通过此漏洞迫使 Confluence Server 与Confluence Data Center 发送任意HTTP/WebDAV 请求。这意味着攻击者可以向你的主机发送请求并使其看起来这个请求是你自己发送的。 

   

CVE-2019-3396 是存在于Confluence Server 与 Confluence Data Center 中 Widget Connector 中的 SSTI （server-side template injection）服务端模板注入漏洞，官方将此漏洞定级为严重。通过此漏洞可实现目录穿越与远程代码执行。攻击者可以对Confluence系统进行任意更改（例如，更换登录页面以捕获密码），可以危及整个服务器。

  

  

**漏洞危害**

严重

  

  

**影响范围**

以下版本的 Confluence Server 与 Confluence Data Center 受到影响：

All 1.x.x,2.x.x, 3.x.x, 4.x.x and 5.x.x versions

All 6.0.x,6.1.x, 6.2.x, 6.3.x, 6.4.x, and 6.5.x versions

All 6.6.xversions before 6.6.12

All 6.7.x,6.8.x, 6.9.x, 6.10.x and 6.11.x versions

All 6.12.xversions before 6.12.3

All 6.13.xversions before 6.13.3

All 6.14.xversions before 6.14.2

  

 

**漏洞防护**

官方已发布更新，升级到最新Confluence版本，已修复版本如下：

Version 6.6.12 and higherversions of 6.6.x

Version 6.12.3 and higherversions of 6.12.x

Version 6.13.3 and higherversions of 6.13.x

Version 6.14.2 and higher

如果无法立即升级Confluence，临时解决方法是：

设置\>管理应用程序/加载项 ，在Confluence中禁用以下系统插件：

*   WebDAV插件
    
*   小部件连接器
    

升级Confluence后，可以重新启用这些插件。
