漏洞预警| Windows DHCP客户端远程执行代码漏洞

2019-01-10

   

**事件来源**

  

近日，微软发布编号为CVE-2019-0547的安全补丁，攻击者可以向客户端发送经特殊设计的 DHCP 响应攻击Windows系统。

  

**漏洞描述**

  

当攻击者向客户端发送经特殊设计的 DHCP 响应时，Windows DHCP 客户端中存在内存损坏漏洞。成功利用此漏洞的攻击者可以在客户端计算机上运行任意代码。

  

**影响范围**

Windows 10 Version 1803 for 32-bit

Windows 10 Version 1803 for ARM64-based

Windows 10 Version 1803 for x64-based

Windows Server version 1803 Server Core Installation

  

**漏洞防护**

  

此安全更新通过更正Windows DHCP客户端处理某些DHCP响应的方式来解决漏洞。
