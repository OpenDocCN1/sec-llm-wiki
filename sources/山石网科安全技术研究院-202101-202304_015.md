## **2.1   MP3****隐写**

使用MP3stego工具进行操作，其基本使用方法如下

加密：

encode -E hidden\_text.txt -P pass svega.wav svega\_stego.mp3

\-E 读取隐藏信息文件的内容，-P 设置密码

![](../Images/dd25687082b957db6f45e8aa02ba84d7.png)

解密：

decode -X -P pass svega\_stego.mp3

![](../Images/23c396a2e41cd078fb689e856181a898.png)

## **2.2   波形隐写**

### **2.2.1    摩斯密码**

波形中隐含摩斯密码，如下图所示，较长的蓝色即为“-”，较短的即为“.”，每一段由-和.组成，即为一个字符。

![](../Images/c830d5306c6ed85b83fcb500b53f4199.png)

也可以使用morse2ascii工具，这 是一个从PCM解码WAV文件摩斯密码工具

linux使用此命令安装：apt install morse2ascii

如果音频文件存在两个音频道，先对音频分离，再用morese2ascii

![](../Images/4335a1f1168b73ea4ab338c1e767cb45.png)

选择音频导出。

![](../Images/ef874b75302d0c0da3fb332eab83ced7.png)

![](../Images/02dafe58fead0d45f34648e5fa608bc6.png)

### **2.2.2     01字符串**

波形谱转换为01字符串，将单声道波形提取出来，接近1的变成1，接近-1的变成0，得到二进制,并转换为ASCII

![](../Images/6b33810001ed4fcb2b70899f79520305.png)

得到字符串110011011011001100001110011111110111010111011000010101110101010110011011101011101110110111011110011111101

此长度为105，可以除以7但是不能除以8，在每7位前边补0转换为ASCII。可用如下脚本进行转换。


**2.3   音频隐写**

音频中的频谱隐写是将字符串隐藏在频谱中，此类音频通常会有一个较明显的特征，听起来是一段杂音或者比较刺耳。

使用Audacity，选择频谱图，可看到隐藏的信息。

![](../Images/34754fa296284236de65789c15fcf3f9.png)

## **2.4   声音倒放**

音频中的声音听起来有点诡异，并且完全听不懂，猜测可能音频被倒放了。鼠标左键勾选音频，然后菜单栏效果->反向(时间)，进行恢复。

![](../Images/509d09915ca1ea4197619216f60c812a.png)

![](../Images/7961c93f6b76c05c068abd5462e17c58.png)

## **2.5   SSTV**

SSTV慢扫描电视（Slow-scan television）是业余无线电爱好者的一种主要图片传输方法，慢扫描电视通过无线电传输和接收单色或彩色静态图片。

播放音频文件，利用MMSSTV或者robot36进行接收，可显示传输的图片内容。

![](../Images/bd5410ad1dd9fb5e9e5daaae0324a3d9.png)

## **2.6   LSB隐写**

图片中有LSB隐写，音频中也对应有LSB隐写。使用 slienteye，点击File打开音频文件，点击decode 解密。

![](../Images/c0572a6c159da6ca2197bb8f4d3d0b1f.png)
