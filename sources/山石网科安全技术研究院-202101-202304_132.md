**0****1**** D1fFeReNcE\_F@1G**

可以看到如果存在字符串则为0.9....，不存在则为1.0

然后如果存在两个字符串数字就变小，试一下三个字符，发现数字变大，说明不存在三个字符。

这样就可以找到了所有的字符串：`578epasdfghjlvn{}gl`，猜测为flag{}，那么剩下的字符为`578epsdghjvnl`

再说明一点，如果j在8的右边，则数字变小，d不在8的右边则增大，那么根据这个规律写脚本爆破。

```


from pwn import *
```

  

可以看到5的话数字全部都是最小的，说明下一个字符串就是5，依次爆破即可，最后得到flag：`flag{5lgpsnd8j7vhe}`
