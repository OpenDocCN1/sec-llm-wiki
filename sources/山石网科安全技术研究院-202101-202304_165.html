01
安装Ghidra

建议下载最新版本的 Ghidra (https://Ghidra-sre.org/) ，【目前最新版发布在github上】点击 下载 Ghidra v9.1.2的红色按钮，但是如果您想下载旧版本，那么需要点击发布(Releases)版本:
图1.2-从官方网站下载 Ghidra

下载 Ghidra完整的归档文件(Ghidra _ 9.1.2 _ PUBLIC _ 20200212.zip)并解压后，您会看到下面的文件结构:
图1.3-解压后的 Ghidra 9.1.2结构

内容描述如下(来源: https://Ghidra-sre.org/InstallationGuide.html) 。
•docs: Ghidra 的文档和一些非常有用的其它资源，例如不同级别的 Ghidra 课程、一步一步安装的安装指南。
•Extensions: 可选的 Ghidra 扩展，允许您改善它的一些功能，并与其他工具进行集成。
•Ghidra: Ghidra 程序本身。
•GPL: 独立的 GPL 支持程序。
•licenses: 包含 Gidra 使用的许可证。
•server: 包含与 Gidra server安装和管理相关的文件。
•support: 允许您以高级模式运行 Gidra 并控制其启动方式,包括调试启动。
•ghidraRun: 用于在 Linux 和 iOS 上启动 Ghidra 的脚本。
•ghidraRun.bat: 批处理脚本，允许您在 Windows 上启动 Ghidra 。
•LICENSE: Ghidra 许可文件。
除了下载 Ghidra 的发行版(已经预编译)之外，您还可以自己编译该程序，下一节将对此进行阐述。

自己动手编译Ghidra
如果您想自己编译 Ghidra，那么您可以从以下 URL 下载源代码: https://github.com/nationalsecurityagency/Ghidra。
然后，您可以通过运行以下命令使用 Gradle 构建它:
gradle --init-script gradle/support/fetchDependencies.gradle
init
gradle buildGhidra
gradle eclipse
gradle buildNatives_win64
gradle buildNatives_linux64
gradle buildNatives_osx64
gradle sleighCompile
gradle eclipse -PeclipsePDE
gradle prepDev
这将产生一个压缩文件，其中包含 Ghidra 的编译版本:
/ghidra/build/dist/ghidra_*.zip
在启动 Ghidra 之前，确保您的计算机满足以下要求:
•4 GB RAM
•1 GB 存储空间(用于安装 Ghidra 二进制文件)
•强烈推荐双显示器
由于 Ghidra 是用 Java 编写的，如果在安装 Java 11 64位运行时和对应的开发工具包时，可能会显示以下错误消息：
•当Java 没有安装，您将看到如下提示:
"Java runtime not found..."
•当 Java 开发工具包 (JDK)丢失时，您将看到以下内容:
图1.4-缺少 JDK 的错误信息

如果您得到了这些消息中的任何一条，请从以下来源之一下载JDK:
•https://adoptopenjdk.net/releases.html?variant=openjdk11&jvmVariant=hotspot
•https://docs.aws.amazon.com/corretto/latest/corretto-11-ug/downloads-list.html

如何解决安装问题
Ghidra 的分步安装指南，包括已知的问题，可以在 Ghidra 的文档目录中找到文档 InstallationGuide.html进行查看。
也可以按照以下链接进行查看:: https://ghidra-sre.org/InstallationGuide.html.
您可通过以下链接来报告在 Ghidra 中发现的新问题:
https://github.com/NationalSecurityAgency/ghidra/issues

在安装好 Ghidra 之后，您将能够在 Linux 和 iOS 【macOs】上使用 ghidraRun 启动它，在 Windows 上使用 ghidraRun.bat 启动它。

Ghidra的功能概述
在本节中，我们将查看一些基本的 Ghidra 特性，以了解程序的整体功能。熟悉它也是一个很好的起点。

 创建一个新的 Ghidra 项目

正如您所注意到的，与其他逆向工程工具不同，Ghidra 不直接处理文件。相反，Ghidra 在项目中工作。让我们通过单击 File | New Project... 创建一个新项目。您也可以通过按下 Ctrl + n 快捷键来创建项目(Ghidra 的快捷键完整列表可以在 https://Ghidra-sre.Org/Cheatsheet.html 和 Ghidra 的文档目录中找到):
图1.5-创建一个新的 Ghidra 项目

此外，项目可以设置为非共享的或是共享的项目。因为我们想分析 hello world 程序，而不需要与其他逆向工程师协作，所以我们将选择 Non-Shared Project，然后单击 Next > > 按钮。之后，程序要求我们选择一个项目名称(hello world)并存储在硬盘上的哪个路径里:
图1.6- 选择项目名称和目录

该项目由 hello world.gpr 文件和 hello world.rep 文件夹组成:
图1.7- Ghidra项目结构

一个Ghidra项目(*.gpr 文件)只能由一个用户打开。因此，如果您尝试同时打开同一个项目两次，使用 hello world.lock 和 hello world.lock ~ files 实现的并发锁将阻止您这样做，如下面的屏幕截图所示：
图1.8- Ghidra项目被锁定

在下一节中，我们将介绍如何向项目中添加二进制文件。

导入文件到Ghidra项目

我们可以开始向 hello world 项目中添加文件。为了用 Ghidra 分析一个非常简单的应用程序，我们将编译以下用 C 编程语言编写的 hello world 程序(hello _ world.c)：
#include <stdio.h>
int main(){
printf("Hello world.");
}
我们使用以下命令来编译它：
C:\Users\virusito\Desktop\hello_world> gcc.exe hello_world.c
C:\Users\virusito>\
让我们来分析一下微软操作系统下的可执行文件 hello _ world.exe。首先，让我们将 hello world.exe 文件导入到项目中; 我们必须跳转到 File | Import file 目录。或者，我们可以按 I 键:
图1.9 导入一个文件到 Ghidra 项目

Ghidra 自动将 hello _ world.exe 程序识别为32位架构的 x86 Portable Executable 二进制文件。成功识别后，我们可以单击 OK 继续。导入之后，您将看到文件的摘要信息:
图1.10 Ghidra 项目文件导入结果摘要

通过双击 hello _ world.exe 文件或单击 Tool Chest 的绿色 Ghidra 图标，该文件将由 Ghidra 打开并加载:
图1.11-一个包含 Portable Executable 文件的 Ghidra 项目

在将文件导入到项目中之后，您可以开始对它们进行逆向工程。这是 Ghidra 的一个很酷的特性，允许您在一个项目中导入多个文件，因为您可以对多个文件进行一些操作(例如，搜索)(例如，查看一个可执行的二进制文件及其依赖项)。在下一节中，我们将看到如何使用 Ghidra 分析这些文件。

执行和配置Ghidra分析

您将被问及是否要分析该文件，并且您可能希望对此回答Yes，因为分析操作可以识别函数、参数、字符串等。通常情况下，您会想让Ghidra为您获得这些信息。确实存在许多分析配置选项。您可以通过单击它来查看每个选项的描述; 描述显示在右上角的描述部分:
图1.12-文件分析选项

让我们单击 Analyze 来执行文件分析。然后，您将看到 Ghidra CodeBrowser 窗口。如果您忘记分析某些内容，不要担心; 您可以稍后重新分析该程序(转到 Analysis 选项卡，然后自动分析‘ hello _ world.exe’...)。

探索 Ghidra CodeBrowser

默认情况下，Ghidra CodeBrowser 有一个精心选择的坞窗口分布，如下面的截图所示:
图1.13 Ghidra的CodeBrowser窗口

让我们看看默认情况下 CodeBrowser 是如何分布的:

1.和往常一样，默认情况下，在逆向工程框架中，在屏幕中央Ghidra显示了文件的反汇编视图。
2.由于反汇编级别有时是一个过于低级的视角，Ghidra 结合了自己的反编译器，该反编译器位于反汇编窗口的右侧。程序的主要功能由 Ghidra 签名识别，然后自动生成参数。Ghidra 还允许您在许多方面对反编译代码进行操作。当然，文件的十六进制视图也可以在相应的选项卡中找到。这三个窗口(反汇编、反编译和十六进制窗口)是同步的，为同一代码提供了不同的分析视角。
3.Ghidra 还允许您在程序中轻松使用导航。例如，要转到另一个程序部分，您可以引用位于 CodeBrowser 左上边缘的 Program Tree 窗口。
4.如果您更喜欢导航到一个符号(例如，一个程序函数) ，那么就转到符号树窗格所在的位置。
5.如果您想处理数据类型，那么再次转到下面的数据类型管理器。
6.由于 Ghidra 允许脚本逆向工程任务，脚本结果显示在底部相应的窗口中。当然，Bookmarks 选项卡位于相同的位置，允许您为任何内存位置创建有良好文档记录和组织的书签，以便快速访问。
7.Ghidra 在顶部还有一个快速访问栏。
8.在右下角，第一个字段表示当前地址。
9.在当前地址之后，显示当前函数。
10.除了当前地址和当前函数之外，还显示当前反汇编的上下文信息。
11.最后，在 CodeBrowser 的最顶部，找到了主工具条。既然您已经知道了 Ghidra 的默认视角，现在是学习如何定制它的好时机。让我们在下一节中讨论这个问题。

自定义Ghidra

这是 Ghidra 的默认透视图，但您也可以修改它。例如，您可以通过点击“窗口”菜单并选择一个您感兴趣的窗口来为Ghidra 添加更多的窗口:
图1.14-Ghidra 窗口子菜单中的一些项目

Ghidra 有很多令人惊讶的功能——例如，位于反汇编窗口右上方的工具条允许您通过移动字段、添加新字段、扩展反汇编列表中字段的大小来定制反汇编视图，等等。
图1.15-反汇编列表配置

它还允许您启用 Ghidra 的一个非常有趣的特性，这是它的中间表示或中间语言，通常称为“编码”。它允许您开发与汇编语言无关的工具，并以更友好化的语言来开发自动化分析工具:
图1.16-在反汇编清单中启用 PCode 字段

如果启用，则在清单中显示 PCode。正如您很快就会意识到的那样，这种PCode并不那么适合人类可读，但是它有时更适合脚本逆向工程的去实现一些任务:
图1.17-启用了PCode的反汇编清单

发现更多 Ghidra 功能

与其他逆向工程框架类似，其中的一些强大功能也包含在 Ghidra 中。例如，同其他逆向工程框架一样，您也有一个图形视图:
图1.18 -图视图下的hello world程序

正如您所见，程序的主要功能的图形视图如上，Ghidra有很多特性和窗口; 我们不会在本章中全部介绍，也不会修改和/或扩展它们。事实上，我们还没有全部提到。相反，我们将在接下来的章节中通过实践来了解它们。
