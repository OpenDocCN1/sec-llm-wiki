## 3.3 Implementation and Security Issues

  本书中我们的主要关注现代密码学背后的数学难题，但我们还是需要简要地提及一些与实现相关的安全问题。这里我们只是简单地描述一些例子，以表明构建一个安全的通信系统远不止是简单地使用基于数学难题的密码系统。
