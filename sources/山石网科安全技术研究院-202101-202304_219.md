# 第三届HCON线上安全技术峰会预告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMDUxNTE1Mw==&mid=2247493946&idx=1&sn=cbfdf36ff66be7a6a39d6ff1f6a773c4&chksm=fa523c84cd25b592fbedaefd504cfc977d1d90909089d1e5ab25d3ba2697fa4b9a9d7a19a687&scene=126&sessionid=1681374432#rd](http://mp.weixin.qq.com/s?__biz=MzUzMDUxNTE1Mw==&mid=2247493946&idx=1&sn=cbfdf36ff66be7a6a39d6ff1f6a773c4&chksm=fa523c84cd25b592fbedaefd504cfc977d1d90909089d1e5ab25d3ba2697fa4b9a9d7a19a687&scene=126&sessionid=1681374432#rd)

HCON全称是Hillstone Security Technology Conference (Online)‍，从2020年至今已是第三届，山石安研院的成立也即将到了第三个年头，因为一直都在疫情期间，所以到目前HCON还是保持在线上举行。

  

作为一年一度的线上信息安全技术会议，每一届都是干货满满。今年让我们一起探讨隐私保护、物联安全、智能安全、工控安全与虚拟化安全等当下‍网安最热的话题，来自山石安研院华东的工控安全实验室、密码安全实验室、信创安全实验室与华南的物联安全实验室、溯源取证实验室等研究团队分别为您带来新鲜出炉的硬核干货。届时将在腾讯会议、公众号直播等方式进行，敬请期待！:）
