# **一.    介绍**

近年来随着各种IOT设备漏洞越来越被大众所关注，漏洞利用所带来的危害也日趋严重。本文通过利用DVRF项目来进一步分析设备固件，挖掘固件中存在的安全漏洞。

该项目的目的是模拟真实设备环境，帮助人们了解 除x86\_64 空间之外的其他 CPU 架构，同时帮助安全爱好者发现路由器固件中的隐藏奥秘。
