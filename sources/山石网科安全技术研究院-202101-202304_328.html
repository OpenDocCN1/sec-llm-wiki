在1.2 一节中介绍的计算  的方法多少有点低效。这道练习将介绍一种适合计算机实现的计算 u 和 v 的算法。通常情况下它只会消耗很小的内存。

a. 下面是该算法的伪代码，该算法将会返回两个正整数 a 和 b 的最大公约数 g 以及满足式子  的 u 和 v。

b. 用你喜欢的编程语言实现上述伪代码。

python代码

def egcd(a,b):
   u = 1
   g = a
   x = 0
   y = b
   while y != 0:
       q = g // y
       t = g % y
       s = u - q*x
       u = x
       g = y
       x = s
       y = t
   v = (g-a*u)//b
   return (g,u,v)
