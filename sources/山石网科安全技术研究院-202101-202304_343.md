# 山石安研院2021年度十大重磅原创漏洞盘点

**TOP 1：CVE-2021-24074**

Windows TCP/IP协议栈远程代码执行漏洞，是一系列的漏洞，以往历史中很少有windows上的tcp远程代码执行漏洞，无需交互和身份认证就可以触发，漏洞挖掘者向我们展示了通过tcp/ip协议远程攻击windows系统的技术，影响所有windows系统（windows 11 未发布）。

 

**TOP 2：CVE-2021-26855**

Exchange Server的远程代码执行漏洞，该漏洞无需任何验证，直接可以获取远程邮件服务器的权限，威胁等级非常高，影响到Exchange Server 2013, 2016, 2019。

 

**TOP 3：CVE-2021-26877**

Windows DNS Server 远程代码执行漏洞，DNS Server在今年爆出了一系列的漏洞，我们选择了其中一个漏洞作说明，该系列漏洞针对于windows dns服务器，攻击者可以发送恶意的dns报文在目标机器上执行任意代码，威胁较大，尤其是企业内的域控服务器，影响所有server系列的windows产品。

 

**TOP 4：CVE-2021-31166**

Windows HTTP Server 远程协议栈内存破坏漏洞，该漏洞类型是UAF，未授权攻击者可以通过构造攻击数据包攻击目标服务器，成功利用可以在目标服务器上执行任意代码，20H1，20H2，Server 20H1和Server 20H2受影响。

 

**TOP 5：CVE-2021-1675**

windows打印服务漏洞，PrintSpooler是Windows系统中管理打印相关事务的服务，用于管理所有本地和网络打印队列并控制所有打印工作。Windows系统默认开启 Print Spooler 服务，普通用户可以利用此漏洞提升至SYSTEM管理权限，影响所有版本的windows系统。

 

**TOP 6：CVE-2021-31956**

很罕见的可以过chrome沙箱的本地提权漏洞，ntfs.sys驱动中的一个堆内存整数溢出漏洞，由卡巴斯基捕获在野利用链，该利用链使用了Chrome1day CVE-2021-21220/CVE-2021-21224 V8 RCE 漏洞实现远程代码执行，并串联了内核信息泄露漏洞CVE-2021-31955，Ntfs.sys 内核提权漏洞CVE-2021-31956 来实现沙盒逃逸，影响所有系列的windows产品。

 

**TOP 7：CVE-2021-28310**

也是一个本地提权漏洞，适用于app container，为内存越界写入漏洞，存在于dwmcore.dll中，它是桌面窗口管理器 (dwm.exe) 的一部分。DirectComposition 是 Windows 8 中引入的 Windows 组件，用于启用具有转换、效果和动画的位图合成，并支持不同来源（GDI、DirectX 等）的位图，是被很多人都忽略的一个组件，影响所有windows 10系列系统，该漏洞也是发现了在野利用，可见攻击者对win32k的整体功能及设计架构理解非常深厚。

 

**TOP 8：CVE-2021-42287**

域服务器权限提升漏洞，攻击者可以利用该漏洞将域内的普通用户权限提升到域管理员，影响所有windowsserver系列操作系统。

 

**TOP 9：CVE-2021-28474**

SharePoint 远程代码执行漏洞，该漏洞允许经过身份验证的用户在 SharePoint Web 应用程序的服务帐户上下文中的服务器上执行任意 .NET 代码。要成功进行攻击，攻击者需要 SharePoint 站点的SPBasePermissions.ManageLists 权限。默认情况下，经过身份验证的SharePoint 用户可以创建网站/子网站并拥有所有必要的权限。

 

**TOP 10：CVE-2021-38666**

Windows Remote Desktop Client 存在远程代码执行漏洞，攻击者可诱导用户连接到恶意的远程桌面服务器，从而利用该漏洞在用户主机上执行恶意代码，控制用户主机。

山石安研院作为一支硬核的国际安全研究团队，在2021年漏洞挖掘方面可以说也是硕果累累，本文筛选出了十个已经披露的严重漏洞，我们在微软操作系统中还发现大量的本地提权漏洞，也发现了很多新的、而且非常有趣的攻击面。其中CVE-2021-27088，CVE-2021-33774两个漏洞存在于windows 内核中，在Event Tracing功能模块的实现中存在内存破坏漏洞，攻击者可以利用该漏洞进行权限提升，漏洞级别为重要，微软最终在7月份完成了两个漏洞的修复工作。CVE-2021-41339 为我们在桌面窗口管理器核心库中发现的内存破坏漏洞，攻击者可以通过该漏洞实现自身权限的提升，漏洞级别为重要，在10月份微软完成了漏洞的修复工作。目前我们上报的部分漏洞厂商还没有完全修复，后续我们会持续输出安研院的最新攻击及漏洞研究成果。
