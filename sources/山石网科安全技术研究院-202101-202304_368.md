# Cynos 冒充Android游戏的恶意软件 感染超过900万部手机

**恶意软件分析师在 AppGallery 目录中发现了数十款游戏，其中内置了**Android.Cynos.7.origin**木马。该木马旨在收集用户的手机号码。至少有 9,300,000 位 Android 设备用户安装了这些危险游戏。**

该**Android.Cynos.7.origin**是Cynos程序模块的变型中的一个。该模块可以集成到 Android 应用程序中以通过它们获利。该平台至少在 2014 年就已为人所知。它的一些版本具有相当激进的功能：它们发送优质短信、拦截收到的短信、下载和启动额外的模块，以及下载和安装其他应用程序。我们的恶意软件分析师发现的该版本的主要功能是收集有关用户及其设备的信息并显示广告。

包含**Android.Cynos.7.origin**的应用程序会要求用户授予拨打和管理电话的权限。这允许木马获得对某些数据的访问。

![](../Images/5b52bef17d4c82e2e16070df40f85f59.png)

当用户授予权限时，木马会收集以下信息并将其发送到远程服务器：

*   电话号码
    
*   地理位置数据
    
*   WiFi 网络详细信息
    
*   移动网络参数和标识符
    
*   电话硬件和软件规格
    

乍一看，手机号码泄露似乎是一个无关紧要的问题。但实际上，它会严重伤害用户，尤其是考虑到儿童是游戏的主要目标受众。

即使手机号码注册给成人，下载儿童游戏也很可能表明儿童是实际使用手机的人。父母是否希望上述有关手机的数据不仅传输到未知的外国服务器，而且还传输给其他任何人，这是非常值得怀疑。

我们在 AppGallery 上的 190 款游戏中发现了**Android.Cynos.7.origin**，例如模拟器、平台游戏、街机游戏、策略游戏和射击游戏。超过 9,300,000 名用户已下载这些游戏（安装数量根据 AppGallery 上列出的每个应用程序的下载数量计算）。其中一些游戏针对讲俄语的用户：他们有俄语本地化、标题和描述。其他的则针对中国或国际观众。下面显示了包含该木马的游戏示例。

该威胁已通知了HUAWEI 应用市场。在本文发布时，包含该木马的应用程序已从 AppGallery 中删除。

适用于 Android 的 Dr.Web 防病毒产品成功检测并删除包含**Android.Cynos**木马的所有已知修改的应用程序，因此不会对我们构成威胁。
