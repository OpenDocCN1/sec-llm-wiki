# 山石安研院再次协助微软修复安全漏洞获得致谢

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMDUxNTE1Mw==&mid=2247490038&idx=1&sn=1f8af92a355cc7f55596dec6158bf027&chksm=fa51cc48cd26455ed1d900e9188a4f54060a05d2fbe0f04d3be1c9b20909a1c88a82eddaba74&scene=126&sessionid=1681374513#rd](http://mp.weixin.qq.com/s?__biz=MzUzMDUxNTE1Mw==&mid=2247490038&idx=1&sn=1f8af92a355cc7f55596dec6158bf027&chksm=fa51cc48cd26455ed1d900e9188a4f54060a05d2fbe0f04d3be1c9b20909a1c88a82eddaba74&scene=126&sessionid=1681374513#rd)

北京时间10月13日凌晨，微软发布10月份安全更新补丁。修复了一个由山石网科安全研究院的三位安全研究员报告的漏洞，并在官网上发布致谢信息，漏洞编号 CVE\-2021\-41399，影响最新的windows 11操作系统。 

  

![](../Images/8f8b72cbbfd745052d949aa9365b2fac.png)

图：微软官方致谢山石网科安全研究院三位安全研究员

  

![](../Images/b4fbdc3dddb7ef51e2d494bac21b6e28.png)

  

本月的安全更新共修复漏洞74个。包括**2个高危漏洞**，**71个严重漏洞**，1个低危漏洞，覆盖包括了 Windows操作系统、Exchange Server、Office、.NET、 Visual Studio等组件。危害范围广且较为严重，建议广大用户及时更新。
