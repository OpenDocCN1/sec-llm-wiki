# AST 注入  

什么是AST

\[AST\] https://en.wikipedia.org/wiki/Abstract\_syntax\_tree Abstract\_syntax\_tree

  

NodeJS中的AST

![](../Images/6665573e6510e1312c1343a19adbddc3.png)

在NodeJS中，AST经常被在JS中使用，作为template engines （引擎模版）和typescript等。对于引擎模版，结构如上图所示⬆️。

![](../Images/d413de6c746c7d01159969321fd59248.png)

如果在JS应用中存在原型污染漏洞，任何 AST 都可以通过在`Parser(解析器)`或`Compiler(编译器)`过程中插入到函数中。

  

在这里，你可以在没有过滤、没有经过`lexer(分析器)`或`parser(解析器)`验证的输入(没有被适当的过滤)的情况下插入AST。

然后我们可以向`Parser(编译器)`非预期的输入。

  

下面就是展示如何实际中在`handlebars`和`pug`使用AST注入执行任意命令

# Handlebars

`handlebars`是除 ejs 之外最常用的`template engine(模板引擎)`。

在较新的版本中是较为安全的，即使可以插入任何模板，也无法执行任何命令。
