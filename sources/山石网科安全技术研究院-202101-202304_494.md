# 漏洞通告 | Sudo缓冲区溢出漏洞（CVE-2021-3156）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMDUxNTE1Mw==&mid=2247487535&idx=1&sn=cee3cd0525de7cb0fefc8c510341215e&chksm=fa51c591cd264c87fbf1dbaf01843b7f626d8edd6a47b20a1295ada8a44624c6d0127d284273&scene=126&sessionid=1681374553#rd](http://mp.weixin.qq.com/s?__biz=MzUzMDUxNTE1Mw==&mid=2247487535&idx=1&sn=cee3cd0525de7cb0fefc8c510341215e&chksm=fa51c591cd264c87fbf1dbaf01843b7f626d8edd6a47b20a1295ada8a44624c6d0127d284273&scene=126&sessionid=1681374553#rd)

![](../Images/953c8100f487f18098206227de57e613.png)

**漏洞描述**

1.9.5p2之前版本的Sudo存在缓冲区溢出漏洞，攻击者可以使用精心构造的“sudoedit”命令可以获得root权限，即使用户不在sudoers列表中也可以利用。

  

**影响的版本**

从1.8.2到1.8.31p2的所有旧版

从1.9.0到1.9.5p1的所有稳定版本

1.8.2之前的版本不受影响

  

**检查是否受影响**

运行“sudoedit -s /”

如果存在漏洞会显示“sudoedit:”

![](../Images/fb028ba56624732256c7d16a792583c9.png)

如果不存在漏洞会显示“usage:”

![](../Images/ff9b245674d65ae6815b0b671455b606.png)

  

**poc**

| sudoedit -s '\\' \`perl -e 'print "A" x 65536'\` |
| --- |

  

**解决方案**

1.  受支持的发行版本都已经发布更新
    
2.  不受支持的发行版本可以自行编译新版本的sudo替换即可，sudo软件包下载地址：https://www.sudo.ws/dist/
