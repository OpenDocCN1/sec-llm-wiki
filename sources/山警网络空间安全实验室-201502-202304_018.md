# 2022藏蓝科技节

# 网络空间执法技能竞赛活动

# 圆满落幕

为深入学习贯彻习近平新时代中国特色社会主义思想，鼓励支持大学生开展科技创新活动，展示大学生科技创新成果，培养大学生直面问题、解决问题的本领，我院2022藏蓝科技节——网络空间执法技能竞赛活动的比赛于2022年11月19日成功举办，本场赛事由山东警察学院团委主办，山警网安社承办，特邀枣庄薛城公安局，江西警察学院，中国人民警察大学等对网络安全领域有兴趣的公安民警和大学生爱好者参加本次赛事活动。本次竞赛包含了web安全，二进制安全，算法，程序逆向以及安全杂项。全校2021和2022级学生参与了此次竞赛。在12个小时的紧张赛事中，各位参赛选手攻坚克难，不断突破，取得了优异成绩。

![](../Images/381a435245d9d5115fb8d75ab407ba1a.png)

此次比赛分为纳新组与专业组两个组别，纳新组由2022级热爱网络安全的新生组成，专业组由其他年级的学生与校外的公安民警等组成，竞赛过程精彩纷呈，展现了新时代预备警官，不怕困难，一往无前的坚定意志。最终按照参赛规则，在严格审核解题思路后，在纳新组与专业组分别产生了9名获奖选手（对于使用虚假信息注册导致无法顺利联系获奖选手，则进行顺延），名单如下。
