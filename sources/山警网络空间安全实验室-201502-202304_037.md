#### 2.解决内存大小统一问题

利用c32修改文件大小，图中大小单位为字节 在文件末位填充0x200(512)个0.

插入512个数字即可

且在lpe中pe editor中sizeofimage（镜像基址）修改大小为原大小+新节大小=36000 或者理解为：sizeofimage=voffset+vsize

### 详细介绍pe文件的各部分

注意：大部分16进制分析软件，将程序的16进制数据依据ascii码表翻译出。

#### PE头

定义程序部分各类数据的位置

大体上，程序可分为以下部分

| 指令 |
| --- |
| 只读数据 |
| --- |
| 数据（可读可写） |

##### DOS头（IMAGE DOS HEADER）

是为了兼容以前的dos系统而设的

在dos系统中指令和数据混合起来，成线性排列

###### 结构如下：

```
typedef

```
