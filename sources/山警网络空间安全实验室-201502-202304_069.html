https://www.runoob.com/go/go-environment.html

（下面是跟大佬学到的换源方法，亲测如果不换源，下载速度会相当的慢）

安装软件超时问题，需要换国内源：正常来说你需要安装Git之后go get不会报错。但由于网络问题，go get会非常慢

这个时候我们需要国内源来进行加速

首先需要我们开启Go的MODULL支持

 SETX GO111MODULE on

然后我们需要进行更改Go的GOPROXY值

  go env -w GOPROXY=https://goproxy.cn,direct

SETX来设置一下Windows的环境变量

 SETX GOPROXY https://goproxy.cn,direct

接下来就可以正常使用了

 go get -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder

安装好 subfinder 之后，会在用户目录的 go/bin 目录下看到二进制文件，可以使用，subfinder 的配置文件在用户跟目录下的 .config/subfinder 目录下, subfinder 使用介绍：录下, subfinder 使用介绍：

 https://tools.xazlsec.com/index.php/HT1130/138.html

三、主域名如何收集子域名

给大家安利一个工具，叫做oneforall，非常好用，可以轻松批量实现

 python3 oneforall.py –targets target.txt –brute True –req False run 

oneforall解析完是这样的，需要我们对其进行整合

 在oneforall 的更目录下，运行脚本，对results结果进行整合，输出 domain2ip.txt 和 iplist.txt 两个文件 
#!/usr/bin/env python3
#-*- coding: utf-8 -*-
import re
import os
def saveinfo(infolist):
    obj = open("domain2ip.txt", 'a+')
    for info in infolist:
        obj.writelines(info+"\n")
    obj.close()
def saveip(iplist):
    obj = open("iplist.txt", 'a+')
    for ip in set(iplist):
        obj.writelines(ip+"\n")
    obj.close()
def getinfo(filename):
    infolist = []
    iplist = []
    for item in open("results/" + filename):
        subdomain = item.split(",")[5]
        ips =  re.findall("(\d+\.\d+\.\d+\.\d+)", item)
        if subdomain != "" and len(ips) != 0:
            for ip in ips:
                infolist.append(subdomain + "|" + ip)
                if ip not in iplist:
                    iplist.append(ip)
    saveinfo(infolist)
    return iplist
if __name__=="__main__":
    filelist = os.listdir('results/')
    iplists = []
    for filename in filelist:
        print("[+]Tring get file: " + filename)
        if '.csv' in filename and '_' not in filename:
            iplist = getinfo(filename)
            iplists.extend(iplist)
    saveip(iplists)

看见e=3就以为是个低加密指数攻击，结果乱爆了好长时间也没爆出来

细审代码，flag长度是86，m是由85个\x00、flag和84个\x00组合来的，考点在在后边的加的84个\x00上

经实验，在数字前加0没有影响，在16进制后每加一个0，数字扩大16倍，在此题中m=flag^e*(16^(2*88))

因此可得c=flag^e16^504 mod n,化简得到c(16^504)^(-1)≡flag^e(modn)

之后就是简单的低加密指数攻击
