正文

附件是一个32位的exe文件，（一开始放到od动调，一大会没什么结果）正确的流程应该是用ida pro打开分析。

打开之后找不到main函数，只能是从pass，正确等词汇来入手了。

在字符串窗口看到了pass，应该是一道检验输入然后将算法逆向回去的题目。跟进pass去看看

弹窗pass，这个应该是检验成功之后才弹窗的，继续查看函数的调用情况。

发现是sub_4017F0函数在调用它，并且是有一个判断，str1=="KanXueCTF2019JustForhappy"

发现将a1经过一振操作之后赋给了str

执行循环的条件是*(int *)(a1 + 4 * v4) < 62 && *(int *)(a1 + 4 * v4) >= 0，这样的话执行循环的次数就取决于a1的值，那我们就继续看看此函数被调用的情况。

又跳到了这里。

分析这个循环，发现不同ascii码范围的字母进行不同的操作，转化为自然语言就是：ascii码大于57或者小于48的时候，执行ascii-48；满足上一条件之外满足ascii码大于122或者小于97的时候，执行ascii-87；满足上一条件之外满足ascii码大于90或者小于65的时候就弹窗

若以上条件都不满足，则执行ascii码-29.并将所得到的结果赋值给v5，即上一函数中的a1。

我们按照这样的思路写出算法逆向脚本:

ha = 'KanXueCTF2019JustForhappy'
abcdef = 'abcdefghiABCDEFGHIJKLMNjklmn0123456789opqrstuvwxyzOPQRSTUVWXYZ'
bpc = []
flag = ""

for i in range(len(ha)):
    bpc.append(abcdef.find(ha[i]))

print("bpc =", bpc)

for dw in bpc:
    if dw <= 9 and dw >= 0:
        flag += chr(dw + ord('0'))
    elif dw + ord('W') >= ord('a') and dw + ord('W') <= ord('z'):
        flag += chr(dw + ord('W'))
    else:
        flag += chr(dw + 0x1D)

print('flag{'+flag+'}')
#flag{j0rXI4bTeustBiIGHeCF70DDM}

绕过随机数方法

在一个pwn题目中学了一个逆向的技巧

v0 = time(0LL);
srand(v0);
strcpy(v8,"n0_One_kn0w5_th15");
for(i=0;i<=23;++i);
{
    for(j=0;j<=19;++j);
    {
        v1=j|v8[j]^0xf;
        s1[j]=rand()&v1;
    }
}

之后是一个验证环节。

里面会将那一串字符串进行一个随机，随机的种子是time。

那么我们显然不能够用常规方法进行过掉。因为毕竟是会跟时间为种子的随机数随机起来。

那么我们要知道，time这里的种子是秒级的，不是毫秒，那么我们可以在写exp的时候也同时启动一个time的种子，然后来将字符串进行同样的随机，以此来达到一个预测随机的目的。

因为time种子是秒级的，基本上都可以过。

v0 = libcc.time(0)
libcc.srand(v0)
s = "n0_One_kn0w5_th15_passwd"
s1 = ""

for i in range(20):
    v1 = i | ord(s[i]) ^ 0xF
    s1 += chr(libcc.rand() & v1)

sa("Password for admin:", s1)

2020级 AndyNoel | Breaking Grad  (Node.js prototype pollution)

principle

JavaScript的对象是基于原型产生的新生成的对象继承Object的属性和方法 toString constructor hasOwnProperty

攻击者可以通过改变__prototype__改变所有对象JS 对于Function和object联系密切

当function创建时，prototype这个属性就被当做objectconstructor属性就指向function

当object创建时 __proto__属性指向函数的prototype

constructor属性返回函数 constructor的constructor是全局函数的constructor

var person3 = new person("test",55);
person3.constructor; // person
person3.constructor.constructor; // f Function() {[native code]}

person3.constructor.constructor("return 1"); //重写 native code

person3.constructor.constructor("return 1")(); //调用

例子

所以改变

impact

改变使用对象属性的方法结果 从而导致RCE XSS SQL等等

目前，客户端的原型链污染并没有完全发掘（Bentkowski） 服务端的原型链污染的影响相较之下比较清楚

至少可以造成Node.js服务器拒绝服务，同时在链接其他漏洞后造成RCE XSS SQL等危害 (Posix)
