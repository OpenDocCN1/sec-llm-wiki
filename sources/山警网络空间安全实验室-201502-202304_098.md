#### IO\_FILE结构

ILE 在Linux系统的标准 IO 库中是用于描述文件的结构，称为文件流。FILE 结构在程序执行 fopen 等函数时会进行创建，并分配在堆中，然后以链表的形式串联起来，但系统一开始会自动创建的三个文件即stdin、stdout、stderr，它们是在libc上。

```


struct _IO_FILE_plus
```

IO\_file\_plus的结构大致包括这两个部分，一个是\_IO\_FILE file结构，还有一个是\_IO\_jump\_t \*vtable指针，简单来说就是IO\_FILE\_PLUS的结构是由io\_file结构还有一个指针构成的。整体的结构看起来是这样的：

![](../Images/92aba4d863d4c9a88673d6e769db31f9.png)

我们看到io\_file的结构里面有个\_chain这个指针指向stdin，我们继续跟踪下去我们发现结构是这样的\_chain->stderr->stdout->stdin。

需要注意的是，io\_file是\_IO\_FILE\_plus的一部分，\_IO\_FILE\_plus除了io\_file还有一个vtable指针。

vtable结构如下：

#### IO的利用  

##### 利用IO泄露libc（leak）

此方法常用于没有show功能的堆题中。

主要的思路就是修改`_IO_2_1_stdout_`的flags，还有`_IO_write_base、_IO_write_ptr`

常见的结构是这样的

```


int _flags;
```

我们需要做的就是将flags修改成0xfbad18\*\*，为了设置`_IO_CURRENTLY_PUTTING`=0x800，`_IO_IS_APPENDING=0x1000，IO_MAGIC=0xFBAD0000`

\_IO\_write\_base是要泄露地址的起始地址，\_IO\_write\_end是指要泄露的结束地址。之后在遇到printf或者puts的时候就将指向的内容打印出来，

我们惯用的方法就是将flags设置为0xfbad1800，然后将\_IO\_read\_ptr，\_IO\_read\_end，\_IO\_read\_base;设置为0，最后将\_IO\_write\_base的低位设置为'\\x00'。

##### FSOP

这一部分原理性的东西，有些不太理解，我尽力去写一些我所理解到的东西。

![](../Images/b773cb3448b19e892dde004ade75eeac.png)

（当然图是piao的）

\_IO\_list\_all，利用每个file的\_chain将stderr、stdout、stdin连在一起。有了这个链表我们就很好理解fsop的原理了。就是通过修改file链表中的节点来劫持程序的执行流。利用程序中的漏洞来覆盖\_IO\_list\_all(全局变量)来使链表指向一个我们能够控制的区域，从而改写虚表\*vtable。通过调用 \_IO\_flush\_all\_lockp()函数来触发,，该函数会在下面三种情况下被调用：

1：当 libc 执行 abort 流程时。

2：当执行 exit 函数时。当执行流从 main 函数返回时

3：当执行流从 main 函数返回时

当glibc检测到内存出现错误的时候函数的调用链为：

malloc\_printerr ->libc\_message->\_\_GI\_abort -> \_IO\_flush\_all\_lockp -> \_IO\_OVERFLOW

既然有了调用链，我们就可以通过劫持\_IO\_OVERFLOW来控制程序的执行流。

同时我们还需要绕过检测：

```


if (((fp->_mode <= 0 && fp->_IO_write_ptr > fp->_IO_write_base)   
```

只需要伪造fp->\_mode = 0， fp->\_IO\_write\_ptr > fp->\_IO\_write\_base即可。

在glibc2.24以及之后，程序会对vtable的合法性进行校验，不能想之前一样将其改为堆地址。

但是我们可以寻找到合法的指针—— \_IO\_str\_jumps。可以利用它来绕过检查。

看下 \_IO\_str\_jumps指向的结构

```


const struct _IO_jump_t _IO_str_jumps libio_vtable =
```

IO\_str\_overflow在虚表中的偏移为0xe0，所以我们在利用的时候，将\_IO\_str\_jumps结构偏移为0xe0的地方修改为gadget，然后将vtable的指针指向\_IO\_str\_jumps即可实现劫持。
