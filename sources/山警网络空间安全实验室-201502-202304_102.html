然后cd /sysconfig  进入/etc/sysconfig目录

ps -ef查看权限

网络连接

主机与外部的通信连接，提取网络端口，IP信息

使用命令：netstat。ipconfig

netstat -apn>netstat.log

ss -anp > ss.log

ipconfig -a > ipconfig.log

ip addr > ipaddr.log

注：netstat可以看到端口信息

netstat -lnp命令：netstat -lnpt查看tcp进程，netstat -lnpu查看udp信息

进程信息

查看当前系统中的进程信息，可以看出开启的数据库及服务器类型

使用命令：ps -ef、top

示例：ps aux > ps.log

注：ps -ef查看静态进程、top查看动态进程。top命令可以按照不同标准排序，比如输入大写的p可以按照占用cpu排序。

top命令需要退出，ctrl+c退出top命令。

如果问到电脑中了恶意程程序或木马可以使用这两个命令

Part2 非易丢失数据提取

系统账户

排查系统中的账户信息，黑客入侵往往会添加后门账户或者修改现有用户信息。

工具: cat /etc/passwd或者cat /etc/shadow

重点新增的用户、UID为0的用户，shell环境为/bin/bash的系统服务，空口令账户

命令行历史

Linux系统会将shell下执行的命令记录到用户家目录的.bash_history中

使用命令：history

cat /用户家目录/.bash_history

history>history.log

co ~./bash.history  /forensic/bashistory
防火墙规则

特定应用程序对外的端口通信

linux系统日志文件 路径/var/log

1./var/log/message——系统启动后的信息和错误日志

2./var/log/secure——与安全相关的日志信息

3./var/log/maillog——与文件相关的日志信息

4./var/log/wtmp——该日志文件永久记录每个用户登录、注销及系统的启动

5..bash_history——shell的日志

Keychain介绍

❝

iOS keychain 是一个相对独立的空间，保存到keychain钥匙串中的信息不会因为卸载/重装app而丢失, 。相对于NSUserDefaults、plist文件保存等一般方式，keychain保存更为安全。所以我们会用keyChain保存一些私密信息，比如密码、证书、设备唯一码（把获取到用户设备的唯一ID 存到keychain 里面这样卸载或重装之后还可以获取到id，保证了一个设备一个ID）等等。keychain是用SQLite进行存储的。用苹果的话来说是一个专业的数据库，加密我们保存的数据，可以通过metadata（attributes）进行高效的搜索。keychain适合保存一些比较小的数据量的数据，如果要保存大的数据，可以考虑文件的形式存储在磁盘上，在keychain里面保存解密这个文件的密钥。

通俗来讲就是个加密的用来存储ios应用的文件

里面包含开发者账号下（teamID），应用ID，账户名称，账户密码

可以利用KeyChain_dump工具导出到txt，此时可以直接查看明文密码

内存取证&USB流量分析 —— 【高校战“疫”】ez_mem&usb

下载附件是一个名为captured.pcap的流量包

80多mb里面肯定有文件，先binwalk一下

提取了两个压缩包，里面是data.vmem但是损坏打不开

用wireshark 文件 → 导出对象 → HTTP

把这些都导出来，然后binwalk一下upload_file.php，压缩包应该在这里

得到了data.vmem，接下来就要用到volatility,先看一下镜像版本

volatility -f data.vmem imageinfo

应该是WinXPSP2x86

再看一下进程

volatility -f data.vmem --profile=WinXPSP2x86 pslist

发现有explorer.exe和cmd.exe的进程

查看一下cmd的历史命令

volatility -f data.vmem --profile=WinXPSP2x86 cmdscan

发现了一个passwd:weak_auth_top100

查看一下输入框的内容

volatility -f data.vmem --profile=WinXPSP2x86 editbox

发现用资源管理器查看了C:\Documents and Settings\Administrator

看一下这里面有什么东西

volatility -f data.vmem --profile=WinXPSP2x86 filescan |grep "Administrator"

有个flag.img

提取一下flag.img

volatility -f data.vmem dumpfiles -Q 0x0000000001155f90 -D ./

看一下文件类型

file file.None.0xff425090.dat

先binnwalk一下看看

zip文件要密码，用上面找到的passwd:weak_auth_top100试试
