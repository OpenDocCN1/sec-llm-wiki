## 2020级 | Newiy Gnaw

### **Part1 Linux已丢失数据提取**

第一步最好是通过面板  系统

面板连接的前提：网络能够联通

```


date -R
```

###### **网络连接**

主机与外部的通信连接，提取网络端口，IP信息

使用命令：netstat。ipconfig

```


netstat -apn>netstat.log
```

注：netstat可以看到端口信息

netstat -lnp命令：netstat -lnpt查看tcp进程，netstat -lnpu查看udp信息

###### **进程信息**

查看当前系统中的进程信息，可以看出开启的数据库及服务器类型

使用命令：ps -ef、top

示例：`ps aux > ps.log`

注：ps -ef查看静态进程、top查看动态进程。top命令可以按照不同标准排序，比如输入大写的p可以按照占用cpu排序。

top命令需要退出，ctrl+c退出top命令。

如果问到电脑中了恶意程程序或木马可以使用这两个命令

###### **服务信息**

排查开机自启动的服务，一些恶意软件会将自己安装为服务。

工具：chkconfig --list | grep on

```

cat /etc/rc.d/rc.localtype
=service | grep enabled
```

### **Part2 非易丢失数据提取**

###### **系统账户**

排查系统中的账户信息，黑客入侵往往会添加后门账户或者修改现有用户信息。

工具: `cat /etc/passwd`或者`cat /etc/shadow`

重点新增的用户、UID为0的用户，shell环境为/bin/bash的系统服务，空口令账户

###### **命令行历史**

Linux系统会将shell下执行的命令记录到用户家目录的.bash\_history中

使用命令：history

```


cat /用户家目录/.bash_historyhistory

>history.log
```

###### **防火墙规则**

特定应用程序对外的端口通信

使用命令：iptables -L

###### **linux系统日志文件 路径/var/log**

1./var/log/message——系统启动后的信息和错误日志

2./var/log/secure——与安全相关的日志信息

3./var/log/maillog——与文件相关的日志信息

4./var/log/wtmp——该日志文件永久记录每个用户登录、注销及系统的启动

5..bash\_history——shell的日志

###### **linux系统web日志文件**

Apache日志

linux系统下Apache日志默认路径为/var/log/httpd/httpd.conf

###### **linux系统数据库日志文件**

查看Mysql日志文件位置

ps -ef 查看系统开启的服务器进程

find / -name         "\*.cnf"    my.conf

###### **linux的Rooykit数据排查**

打包网站数据

入侵检测分析后，复制相关日志文件到本地进一步分析。

打包文件名中包含jsp的文件，打包后的文件为`my_txt_files.tar:`

`tar cvf my_txt_files.tar 'find . -type f -name "*.jsp"'`

`tar czvg www.aaa.com.tar.gz /www/aaa/`

打包日志数据

```
tar czvf var_log.tar.gz /var/log


```

打包网站数据库

1）停止数据库：`Service mysqld.stop`

2)备份数据库：`mysqldump -h 192.168.1.100 -p 3306 -uroot -ppassword -database cmdb > /data/baskup/aaadb.sql`

3)压缩数据文件：`Tar czvf mysql_data.tar.gz /var/lib/mysql/`

> ❝
> 
> Keychain介绍

> ❝
> 
> iOS keychain 是一个相对独立的空间，保存到keychain钥匙串中的信息不会因为卸载/重装app而丢失, 。相对于NSUserDefaults、plist文件保存等一般方式，keychain保存更为安全。所以我们会用keyChain保存一些私密信息，比如密码、证书、设备唯一码（把获取到用户设备的唯一ID 存到keychain 里面这样卸载或重装之后还可以获取到id，保证了一个设备一个ID）等等。keychain是用SQLite进行存储的。用苹果的话来说是一个专业的数据库，加密我们保存的数据，可以通过metadata（attributes）进行高效的搜索。keychain适合保存一些比较小的数据量的数据，如果要保存大的数据，可以考虑文件的形式存储在磁盘上，在keychain里面保存解密这个文件的密钥。

通俗来讲就是个加密的用来存储ios应用的文件

里面包含开发者账号下（teamID），应用ID，账户名称，账户密码

可以利用KeyChain\_dump工具导出到txt，此时可以直接查看明文密码

附KeyChain\_dump地址

https://github.com/ptoomey3/Keychain-Dumper
