爱你哦



DVWA (Dam Vulnerable Web Application) 是用PHP+Mysql编写的一套用于常规WEB漏洞教学和检测的WEB脆弱性测试程序，包含了SQL注入、XSS、盲注等常见的一些安全漏洞。对于初学者而言，可以利用dvwa加深一下各种攻击的技巧





安装

推荐教程https://blog.csdn.net/qq_36512966/article/details/71036472，（此教程是在windows环境下安装dvwa）

注：安装过程中，可能会出现报错


解决方法：在config目录下，将config.inc.php.dist后缀.dits去掉即可

一切准备就绪之后，就可以开始dvwa的学习（不归）之路了。




初识dvwa

dvwa有很多模块，安全等级分为四级，从low到impossible。本文简单介绍几个模块，仅供参考。



Vulnerability: SQL Injection


       在安全等级为low下，通过简单地注入可以得到一些信息，具体操作如下：

      先提交1查询下

      然后再提交一个单引号，英文',报错，猜测一下sql的格式 select  * from name where id=' --  '

Vulnerability: Brute Force

（暴力破解）

      暴力破解，是指利用密码字典等爆破出用户密码，是常用的攻击手段之一。下面对Brute Force进行简单介绍。

Medium代码：


相比较low，加入了mysql_real_escape_string，可以防止大部分sql注入，但是依旧没有有效的放爆破机制。仍然可以用bp进行爆破

Impossible：

impossible中加入了完整的放爆破机制。当频繁登陆后，会锁定用户，也就无法继续爆破。并且加入了PDO防注入机制，防止了sql注入。
