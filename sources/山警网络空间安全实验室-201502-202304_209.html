一.什么是aircrack-ng

       aircrack-ng是一套测试WIFI安全的工具 。Aircrack-ng可以工作在任何支持监听模式的无线网卡上（设备列表请参阅其官方网站）并嗅探802.11a，802.11b，802.11g的数据。该程序可运行在Linux和Windows上。

主要针对以下几个方面：

监控：对数据包进行捕获并导出到文本文件中，以供第三方edit工具进一步处理


攻击：通过包注入重放攻击、反身份验证、假接入点等进行攻击


测试：检查WiFi卡和驱动程序功能（捕获和注入）


破解：WEP和WPA PSK（WPA 1和2）无线保密协议



这篇文章主要介绍几个常用的工具：

aircrack-ng:用以破解密钥

airmon-ng:用以开启无限网卡的监听模式（monitor）

aireplay-ng:进行洪水攻击，迫使某个设备断开与WIFI的连接

airodump-ng：进行无线嗅探，对握手包进行捕捉（至于什么是握手包，下面会讲到）

    通过一次破解过程，我们来了解这些工具如何使用。

二.破解WIFI密码

（破解他人路由器属于违法行为，此次破解过程我使用的是自己的路由器，请不要尝试破解他人路由器。）

准备工作：

1.一个带有监听模式的无线网卡，我使用的是LB-LINK的一款无线网卡，购买前一定要询问清楚卖家这款无线网卡是否支持监听模式。


2.aircrack-ng工具套件，aircrack-ng工具kali系统是自带的，我使用的kali是运行在虚拟机里的，有些地方需要注意，会在下面讲到。


3.一个强大的字典。强大的字典是破解无线AP的关键。使用WEP协议的路由器只需要足够数量的数据包就能破解，但现如今绝大多数路由器都是使用WPA协议，就只能通过字典进行暴力破解。所以我们需要的是强大的字典，kali系统自带字典。它位于/user/share/wordlists/rockyou.txt.gz 使用前用gzip命令解压即可。但毕竟该字典主要面向外国用户。我们需要一款符合国情的字典。毕竟外国人直接拿8888888当WiFi密码的还是少数。这里分享一个：链接: https://pan.baidu.com/s/1U9-sDoUOnOvH-AWtbiKSCQ 提取码: d5j7 。

       现在开始破解，首先安装好无线网卡，并将其连接到虚拟机上。



然后打开终端，使用ifconfig看下。

       wlan0就是无线网卡的id。命名就是根据接入设备顺序进行的，第一个是wlan0，第二个wlan1。没有什么特殊含义。

      网卡调试好以后，我们就可以开始破解WiFi。我们的思路是这样的：移动设备在要连接到无线AP时，与无线AP会发生如下四次握手过程：

       1、当一个无线客户端与一个无线AP连接时，先发出连接认证请求（握手申请：你好！）

　　2、无线AP收到请求以后，将一段随机信息发送给无线客户端（你是？）

　　3、无线客户端将接收到的这段随机信息进行加密之后再发送给无线AP （这是我的名片）

　　4、无线AP检查加密的结果是否正确，如果正确则同意连接 （哦～ 原来是自己人呀！）

我们要监听并捕获的就是在握手过程二者互相发送的握手包，而WiFi的密码就在其中。


现在开始使用aircrack-ng：

 

1.airmon-ng check kill 

停止所有对工具有影响的进程

2.airmon-ng start wlan0

开启无限网卡wlan0的监听模式


      此后网卡的id也会变为wlan0mon,以示其开启了monitor模式，也就是监听模式。

3.airodump-ng wlan0mon

进行WIFI嗅探，查看该区域的所有无线AP。


这就列出了附近所有AP的列表

列表中每项的含义：

BSSID:AP的MAC地址

PWR:网卡接收到的信号强度,距离越近信号越强

Beacons:接收到此AP发送的beacon帧数量

#Data:抓到的数据帧数量(WEP表示IV数量),包含广播数据帧

#/s:最近10秒内,每秒平均抓到的帧的数量

CH:信道号,(从beacon帧中获得),信道重叠时可能发现其他信道

MB:AP支持的最大速率

ENC:采用的无线安全技术WEP,WPA,WPA2,OPEN

CIPHER:采用的加密套件 (CCMP TKIP WEP40 WEP104)

AUTH:身份认证方法 (MGT PSK SKA OPEN)

ESSID:无线网络名称,隐藏AP此值可能为空,airodump从probe和association request帧中发现隐藏AP

STATION:STA的mac地址

这里我们需要关注的是BSSID、CH、DATA


       我们要选择破解的WIFI，最好选择DATA不为0的，因为DATA不为0也就代表有设备连接在AP上进行网络行为，我们可以对此进行截取，获取握手包。我这里使用的是自己的路由器，就是第一个2333，我们将对其进行破解尝试。

4.airodump-ng -c 6 --bssid 96:63:72:6B:E3:CF  -w /root/cap/  wlan0mon

针对目标WIFI接入点进行监听捕获握手包。

   这条命令中：

  -c :目标AP的频道

 --bssid ：目标AP 的MAC地址

-w：捕获的握手包的存放地址

      这就进入对目标AP的监听界面，STATION下的MAC地址就是连接到目标AP的设备MAC地址，这里是我的手机。


    此时已经进入了监听，只要等待移动设备重新连接WiFi进行握手包的抓取了，但是这样我们并不知道要等待多长时间，对一个黑客来说这是不可忍受的。所以此时可以使用下一个命令了。

5.aireplay-ng -0 2 -a 96:63:72:6B:E3:CF -c 14:5F:94:1C:5D:52 wlan0mon

       对连接在AP的设备进行洪水攻击，使其掉线后自动重连，从而获取握手包。

其中的参数：

-0 进行洪水攻击的次数，这里设定的是2次，如果设置为0，则表示不断攻击。

-a 目标AP的MAC地址

-c 连接在AP的移动设备的MAC地址

       此时我们再看右上角，会发现监听终端多了一个WPA handshake 这就代表握手包捕获成功。

可以按Ctrl + C 退出监听了

7.aircrack-ng -a2 -b 96:63:72:6B:E3:CF -w /usr/share/wordlists/rockyou.txt /root/cap/*.cap

对握手包进行暴力破解

    其中的参数是：

-a2:代表是WPA2的握手包

-b : 目标AP 的MAC 地址

-w: 字典地址

最后一个是握手包的地址

       跑出来啦

       跑包其实是一个一半靠运气的事，为了缩短时间我特意设了最弱的密码12345678，所以很快就跑出来了。

       当然，我们也可以把这项工作交给GPU来做：

首先要将cap文件转换为hccap文件

aircrack-ng /root/cap/*.cap -J /root/hccap/1


转换成功....


       其次利用工具Hashcat，Hashcat可以借助GPU的运算力破解各种不同算法的hash值。

使用如下命令

hashcat -m 2500 /root/hccap/1.hccap /usr/share/wordlists/rockyou.txt

     参数：-m代表hash函数的类型，其次是hccap文件路径，最后是字典文件路径。-m设置为2500代表 WPA/WPA2 的加密函数，输入hashcat -h可以找到。


       总而言之，如果要防御别人的攻击，最简单也是最有效的方式就是设置复杂度高的密码。
