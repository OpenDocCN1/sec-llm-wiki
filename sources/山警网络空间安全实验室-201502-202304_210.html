一.首先介绍下这个函数

create_function （ string $args ， string $code ）： string

根据传递的参数创建匿名函数，并为其返回唯一名称。

args   函数参数

code   功能代码

以上截自php字典，看不懂没关系，这个函数的作用就是创建一个新的函数，要不为啥叫create_ （我猜的），具体到我们的利用层面，就是我们可以利用它来执行一些我们想执行的东西。
