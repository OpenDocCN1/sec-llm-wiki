create\_function()代码利用来自于p神出的题目，近期不管是纳新题还是一些比赛都出现过这个函数的利用，所以，这次就对这个函数的利用进行一下总结。

  

  

一.首先介绍下这个函数

create\_function （ string $args ， string $code ）： string

根据传递的参数创建匿名函数，并为其返回唯一名称。

args   函数参数  

code   功能代码

以上截自php字典，看不懂没关系，这个函数的作用就是创建一个新的函数，要不为啥叫create\_ （我猜的），具体到我们的利用层面，就是我们可以利用它来执行一些我们想执行的东西。  

  

二.进一步介绍一下这个函数（不要嫌我啰嗦，这是利用它打题最重要的地方）

   首先举个栗子， create\_function （$arg，echo "hello,world"）

    你可以把它理解为

    function  fT($arg){

    echo "hello,world";

}

   至于执行结果，大家肯定都清楚
