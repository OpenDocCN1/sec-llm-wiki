## sql注入之二次注入

这次做ISCC CTF 中看到一道关于sql二次注入的题目，之后就想总结一下 一、 二次注入可以这样理解：攻击者将恶意数据储存在数据库中，之后 攻击者通过调用恶意数据来达到攻击的目的。 二、 有很多防御者会通过对传入的数据进行转义来达到防御的目的，但是当数据 储存到数据库的时候，被处理过的数据会被还原，所以攻击者可以二次调用 恶意数据已达到攻击目的。

我们来看一下部分注册源码：

```
1.  `$username = mysql_real_escape_string($_POST["login_user"]);`
    
2.  `$password = mysql_real_escape_string($_POST["login_password"]);`
    
3.  `$sql = "SELECT * FROM users WHERE username='$username' and password='$password'";`
    
```

mysqlrealescape\_string： 可以转义sql语句中的特殊字符 受影响的特殊符号有：

```
1.  `\x00`
    
2.  `\n`
    
3.  `\r`
    
4.  `\`
    
5.  `'`
    
6.  `"`
    
7.  `\x1a`
    
```

mysqlrealescape\_string 函数将我们上传的数据进行了转移处理 因此我们无法进行sql注入

我们尝试一下二次注入： 再次界面我们发现了一个可以注册用户的窗口 因此我们可以将恶意数据注入进数据库，等待调用 我们注册一个账户名为admin'#的账号 密码111 之后当我们进行密码修改的时候就可以二次调用我们输入的恶意数据

之后我们进行修改密码即二次调用 下面是修改密码时调用的sql语句

```

3.  `因此实际运行的是`
```
