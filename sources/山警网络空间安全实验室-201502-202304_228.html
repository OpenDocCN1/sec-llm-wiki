二、被动搜集

1.whois域名注册信息查询

   msf > whois testfire.net

可以看到有服务商、管理员邮件地址、域名注册日期和过期日期等有用的信息

2.nslookup与dig域名查询

（1）nslookup

         > set type=A

         > testfire.net

可以看到testfire.net域名被解析至65.61.137.117这一IP地址

（2） dig @<DNS服务器> <待查询的域名>

          dig @ns.watson.ibm.com testfire.net

dig命令还有很多用法，今后慢慢钻研

三、活跃主机扫描

1.NMAP（可以在msf命令行下使用）

  几条常用选项

 -PU：对开放的UDP端口进行探测确定存活主机。（-sn 快速扫描）

 -Pn：在扫描之前，不发送ICMP echo请求测试目标是否活跃。（在Internet环境）

 -sS：TCP SYN扫描，类似Metasploit中的syn扫描模块。

 -sF/-sX/-sN：这些扫描通过发送一些特殊的标志位以避开设备或软件的监测。

 -O：启用对于TCP/IP协议栈的指纹特征扫描以获取远程主机的操作系统类型等信息。

 -sV：系统版本检测。（-A：更详细）

比较懒，就把好几个选项一块用了，哈哈。扫描结束可以看到很多开放的端口，系统版本（虽然不确切）

四、服务扫描与查点

1.Metasploit的Scanner辅助模块

msf > search name:_version：查看所有可用的服务查点模块。

▲一般的

(1)［service_name］_version可用于遍历网络中包含了某种服务的主机，并进一步确定服务的版本。(http_version)

(2)［service_name］_login可对某种服务进行口令探测攻击

■常用的

(1)telnet_version

msf > use auxiliary/scanner/telnet/telnet_version

msf  auxiliary(telnet_version) > set RHOSTS 10.10.10.0/24

msf auxiliary(telnet_version) > set THREADS 100

msf auxiliary(telnet_version) > run

一般使用条件：不支持SSH协议的旧版的网络设备，管理员通常不愿冒风险升级他们重要设备的操作系统，大型交换机

没大有了。。。。

(2)ssh_version

简介：SSH是类UNIX系统上最常见的远程管理服务，它采用了安全的加密信息传输方式，通常管理员会使用SSH对服务器进行远程管理。

msf > use auxiliary/scanner/ssh/ssh_version

msf  auxiliary(telnet_version) > set RHOSTS 10.10.10.0/24

msf  auxiliary(telnet_version) > set THREADS 100

msf  auxiliary(telnet_version) > run

扫出来的那个就是OWASP Broken Web Apps v0.94靶机
