三、活跃主机扫描

1.NMAP（可以在msf命令行下使用）

  几条常用选项

 -PU：对开放的UDP端口进行探测确定存活主机。（-sn 快速扫描）

 -Pn：在扫描之前，不发送ICMP echo请求测试目标是否活跃。（在Internet环境）

 -sS：TCP SYN扫描，类似Metasploit中的syn扫描模块。

 -sF/-sX/-sN：这些扫描通过发送一些特殊的标志位以避开设备或软件的监测。

 -O：启用对于TCP/IP协议栈的指纹特征扫描以获取远程主机的操作系统类型等信息。

 -sV：系统版本检测。（-A：更详细）

![](../Images/ec60c1ef7bbbeb1b8c17279be0662093.png)

比较懒，就把好几个选项一块用了，哈哈。扫描结束可以看到很多开放的端口，系统版本（虽然不确切）

四、服务扫描与查点

1.Metasploit的Scanner辅助模块

msf > search name:\_version：查看所有可用的服务查点模块。

![](../Images/8fe93bad9e5e3a2e14742627ba0755ec.png)

▲一般的

(1)［service\_name］\_version可用于遍历网络中包含了某种服务的主机，并进一步确定服务的版本。(http\_version)

(2)［service\_name］\_login可对某种服务进行口令探测攻击

■常用的

(1)telnet\_version

msf > use auxiliary/scanner/telnet/telnet\_version

msf  auxiliary(telnet\_version) > set RHOSTS 10.10.10.0/24

msf auxiliary(telnet\_version) > set THREADS 100

msf auxiliary(telnet\_version) > run

一般使用条件：不支持SSH协议的旧版的网络设备，管理员通常不愿冒风险升级他们重要设备的操作系统，大型交换机

![](../Images/21245cd1c6f272fcbae5dec94e17cb36.png)

没大有了。。。。

(2)ssh\_version

简介：SSH是类UNIX系统上最常见的远程管理服务，它采用了安全的加密信息传输方式，通常管理员会使用SSH对服务器进行远程管理。

msf > use auxiliary/scanner/ssh/ssh\_version

msf  auxiliary(telnet\_version) > set RHOSTS 10.10.10.0/24

msf  auxiliary(telnet\_version) > set THREADS 100

msf  auxiliary(telnet\_version) > run

![](../Images/1e8adf1e8dae4135e250d19efae24e27.png)

扫出来的那个就是OWASP Broken Web Apps v0.94靶机
