0x1 前言

    

    从fastjson反序列化出了以后，就一直想复现这个漏洞，后来在实战中遇到fastjson，才写下这个复现过程。


0x2 环境搭建


    环境还是使用vulhub集成环境进行搭建，如果你觉着下载vulhub比较慢，可以将下面代码保存为：docker-compose.yml


version: '2'services: web:   image: vulhub/fastjson:1.2.45   ports:    - "8090:8090"


    然后在该目录下 docker-compose up -d 即可。


0x3 VPS环境搭建

    

    3.1 marshalsec

    使用marshalsec快速开启RMI和LDAP，需要从github下载一下marshalsec，然后使用maven编译一下，命令如下：

git clone https://github.com/mbechler/marshalsec.git # 下载marshalsec源码mvn clean package -DskipTests  #进行maven编译（前提已安装好maven）

    3.2 tomcat    

    搭建tomcat容器：

wget https://mirrors.tuna.tsinghua.edu.cn/apache/tomcat/tomcat-9/v9.0.27/bin/apache-tomcat-9.0.27.tar.gztar -xzvf apache-tomcat-9.0.27.tar.gzcd apache-tomcat-9.0.27./startup.sh
