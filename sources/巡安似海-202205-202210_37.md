
6\. 禁用JS缓存

![](../Images/c0dfe1549b29f223c6f49fc881d876bf.png)

![](../Images/d24f1af3bd8bc3be582abca3ef810e56.png)

如果是使用的CS4.3版本，则还需要更改`Profile`中的响应头配置，其中的  

```
header "Content-Type" "application/javascript; charset=utf-8";
```

修改为：  

```
header "Content-Type" "application/*; charset=utf-8";
```

即可正常执行命令回显。这里还是CDN的问题，但它具体做了什么让我们上不了线就不知道了。

  

7\. 测试上线，加载CDN配置文件  

```
./teamserver 1.2.3.4 ASXMAADADASD jquery-c2.4.3.profile &
```
