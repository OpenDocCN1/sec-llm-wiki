网上也有很多的相关文章，这里仅说一些最实用的方法 

首先，我们要去判断是否存在CDN，然后再去查找真实IP 

  

**0x01 判断是否存在CDN**

**1) 利用ping  
**

```

http://ping.chinaz.com/
```

使用各种多地 ping 的服务，查看对应 IP 地址是否唯一，如果不唯一多半是使用了CDN，同时要查看IP归属地 

![](../Images/8794de8254a84f1eae697b4d471c99b6.png)

  

**2) 利用nslookup** 

nslookup 进行检测，原理同上，如果返回域名解析对应多个 IP 地址多半是使用了 CDN 

有CDN：

![](../Images/e0b098d9aff553b38d325868bd8d5ed7.png)

无CDN：

![](../Images/b5252f589557845985a540e130e77379.png)

**0x02 查找真实IP**

**1) ****查找历史DNS解析  
**

```
https://dnsdb.io/zh-cn/search?q=host%3Abaidu.com
```

  

![](../Images/0190af787ac65af8df2feff8c5ad00c0.png)

`   `

`https://site.ip138.com/`

![](../Images/6805b1717507321e42dbb0b876e1e535.png)

  

相关网站：  

```

```

查找解析记录CNAME，A记录等等，如果记录和网址的ip相同，则表示真实ip，相反则表示有CDN

![](../Images/e838d1af9dbf2148e4f4a171e152194c.png)

**3) 利用子域名**

毕竟cdn流量也挺贵的，有时候会放过子域名加入cdn 

可以用子域名挖掘机，Subdomainbrute等等去查询子域名，获取子域名ip  

![](../Images/26af04029b2b2c7086fd4bfe5061ffc9.png)

  

**4) 利用邮件  
** 

很多网站存在注册功能，注册时获取验证码，他会向邮箱发送一封邮件，这时你可以显示邮件全文查看ip

![](../Images/f7cbb0dec033bf68eaab93c8f1a5e495.png)

  

**5) ****利用****网站漏洞：** 

如Phpinfo页面，GitHub信息泄露，Xss盲打，社工手段拿到管理员CDN账号等等
