漏洞2 任意文件读取

任意文件读取-image

通过FileInputStream函数进行文件读取，在读取过程中没有对路由进行过滤。在第8行对/image进行了替换，此时就可以控制路由进行目录穿越

@RequestMapping("image/**")  public void image(Model model, HttpServletResponse response, @SessionAttribute("userId") Long userId, HttpServletRequest request)      throws Exception {    String projectPath = ClassUtils.getDefaultClassLoader().getResource("").getPath();    System.out.println(projectPath);    String startpath = new String(URLDecoder.decode(request.getRequestURI(), "utf-8"));        String path = startpath.replace("/image", "");        File f = new File(rootpath, path);        ServletOutputStream sos = response.getOutputStream();    FileInputStream input = new FileInputStream(f.getPath());    byte[] data = new byte[(int) f.length()];    IOUtils.readFully(input, data);    // 将文件流输出到浏览器    IOUtils.write(data, sos);    input.close();    sos.close();  }

直接构造路由进行任意文件读取。此处需要通过"/image"弥补"../"，使得路由正确
