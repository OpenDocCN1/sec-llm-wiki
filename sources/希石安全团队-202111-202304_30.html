What is H1ve

H1ve是一款自研CTF平台，同时具备解题、攻防对抗模式。其中，解题赛部分对Web和Pwn题型，支持独立题目容器及动态Flag防作弊。攻防对抗赛部分支持AWD一键部署，并配备炫酷地可视化战况界面。

搭建环境

  • ubuntu 20.4


安装docker



下载相关依赖

sudo apt-get install -y yum-utils device-mapper-persistent-data lvm2 bind-utils

sudo apt-get install docker

sudo apt-get install docker.io

验证docker是否安装成功，如图显示版本号即为安装成功。

docker –version

将docker启动并加入开机启动

sudo systemctl start docker #或sudo service docker startsudo systemctl enable docker


安装docker-compose



1.安装epel-release

sudo apt-get install epel-release

2.安装python-pip

sudo apt-get install python3-pip

sudo apt-get install docker-compose

验证是否安装成功，显示如图信息为安装成功

docker-compose version


下载H1ve



如果没有git需要安装git

sudo apt-get install git

使用git下载

git clone http://github.com/D0g3-Lab/H1ve.git

或者访问http://github.com/D0g3-Lab/H1ve下载源码


docker镜像加速配置



Docker默认源比较慢所以配置一下阿里云镜像加速

网址：https://cr.console.aliyun.com/cn-hangzhou/instances/mirrors

按照操作手册进行配置，不同的系统也可以选择不同的参考


sudo mkdir -p /etc/docker #创建一个文件夹sudo tee /etc/docker/daemon.json <<-'EOF' #创建一个文件并写入数据{ "registry-mirrors":["https://******.mirror.aliyuncs.com"]}EOFSudo systemctl daemon-reload #重启dockerSudo Systemctl restart docker


运行H1ve



然后进入H1ve目录 然后开启docker

cd H1ve

sudo docker-compose -f single.yml up &

这个过程是在拉取镜像

注意：会遇到一些错误

错误详情:

解决方案:

将docker加入docker用户组

# 添加docker用户组，一般已存在，不需要执行sudo groupadd docker# 将登陆用户加入到docker用户组中sudo gpasswd -a $USER docker# 更新用户组newgrp docker

然后重新注销账户重新登录

然后重启H1ve

docker-compose -f single.yml downdocker-compose -f single.yml up

H1ve安装成功
