10月16日，深圳天朗气清，平安安全应急响应中心（PSRC）迎来了第六期白帽子安全沙龙。


本次沙龙有5位嘉宾带来精彩议题分享，内容覆盖攻击渗透测试、漏洞挖掘、攻防对抗等领域，干货满满。此外还设置有多轮抽奖环节，丰厚礼品给大家带来惊喜满满，为大家带来一场干货与奖品齐飞的知识盛宴。

接下来我们来一起回顾下本次沙龙的精彩内容！


精彩议题分享


议题1：《重复建设之再造一个漏洞扫描器》


无论在商业产品还是开源领域，都有许多关于漏扫的产品和介绍。那如何又快又准的打造一个属于自己的漏扫呢？在本次分享中，平安智慧城安全架构师陈炯昊为大家从设计思路到实战案例全方位的讲解了如何打造一个自己的漏扫，并从防守方视角分析和分享了建设经验。

议题2：《**行动中的攻防对抗体系研究》


本议题零丁洋实验室副主任蔚永强为大家分享了攻防对抗体系研究，以及执行**行动的成功经验分享，并从技术与管理的角度去分析目前**行动中存在的问题以及解决方案。

议题3：《渗透测试漫谈》


在本次沙龙分享中，平安科技高级安全工程师李伟坤与大家分享了他在渗透测试过程中进行快速有效精准定位的方法以及一些漏洞挖掘的技巧。此外还从开发的思路，帮助安全研究员快速进行代码审计，找出漏洞。

议题4：《webview远程执行漏洞的检测和防御》


Android API level 17以上的版本仍然存在远程代码执行安全漏洞，并依然在被广泛利用，那么该如何有效检测和防御呢？平安产险安全支持工程师陈伟杰为我们详细的介绍了Webview远程执行漏洞，以及该漏洞的多种检测和防御方法。

议题5：《攻防角度看外链钓鱼的奇淫技巧》


外链是一个老生常谈的东西。目前各大论坛或平台中，无论是基于站点本身，还是站点的插件，都对第三方站点的跳转进行了安全提示。本次演讲安全研究员高鹏分享了一种新方式，从Web、App的角度利用图片外链钓鱼，外链钓鱼的功与防。



议题前瞻抽奖环节惊喜连连



多轮抽奖环节，惊喜连连，丰富奖品接连不断！感谢补天漏洞响应平台、唯品会SRC、货拉拉SRC、陌陌安全对本环节的大力支持！

奖品包含JBL蓝牙音箱、魔膳师保温杯、华为手环6、PSRC抱枕、VSRC双肩背包、货拉拉车模、唯品会礼盒、补天T恤、小黄鸭蒸汽眼罩等多种礼品。大家不仅可以收获知识，还可以带着多重惊喜礼品，满载而归！

PSRC白帽子安全沙龙介绍



PSRC白帽子安全沙龙由平安安全应急响应中心举办，这里有行业顶尖白帽、排行榜传说大神带来的硬核技术干货、漏洞挖掘骚操作分享，更有超嗨白帽团建。


自2019年3月举办第一届沙龙，我们已经走进了上海、深圳、北京、成都4个城市，希望可以与业界各安全人士增进沟通交流，促进干货分享，共建网络安全，旨在网络安全探索、建设的道路上携手并进，一起同行。


主办方

平安安全应急响应中心（PINGAN Security Response Center，简称PSRC）隶属于平安集团，是外部用户向平安集团反馈各产品和业务安全漏洞的平台，也是平安集团加强与安全业界同仁合作交流的渠道之一。平安集团非常重视旗下各产品和业务的安全，本着对用户信息安全负责的态度， 平安集团致力于打造具备高安全性的产品。平安集团希望借此平台，与广大安全行业从业者、安全爱好者建立友好的互动，来共同提升平安产品的安全性。
