# PSRC迎新活动：首个漏洞积分翻倍

PSRC成立至今5年多，这一路上我们结交了无数的白帽子，有的白帽子成了同事，有的白帽子成了益友，也有的白帽子各知名企业重要的安全岗位上发光发热。感谢各白帽子对PSRC的关注与支持，平安有你，安全保障。

同时，PSRC也欢迎更多新的白帽子的加入，让PSRC注入新鲜血液，添加新生力量，一起为平安亿万用户的安全保驾卫航。**为此，PSRC特推出迎新活动！！！**

![](../Images/e37199ce2fc724d858e687730293c554.png)**活动时间**  
2020年10月15日00:00 - 2020年10月25日23.59  
**活动对象**  
PSRC（security.pingan.com）、平安慧聚（isrc.pingan.com）新注册并完成实名认证的白帽子。因报税需要，SRC注册手机号、姓名与提现银行卡对应的手机号、姓名一致方可成功提现。**活动范围**  
平安集团全部生产环境的资产，测试环境不参与本次活动。  
**活动规则**  
新白帽子提交的**首个有效漏洞，积分翻倍！**  
1、不限漏洞级别，严重到低危均翻倍：![](../Images/46db7238650c8861ed7db9367cd54316.png)2、不限注册时间，只要是注册以来首次提交漏洞的均可参加本次活动；3、本次活动评分标准参考《PSRC漏洞评分标准4.0》https://security.pingan.com/announcement/95.html**注：**1、**漏洞提交时需在漏洞标题中注明“迎新活动”**2、因报税需要，SRC注册手机号、姓名与提现银行卡对应的手机号、姓名一致方可成功提现。因未正确实名认证导致无法成功提现的PSRC概不负责。3、本次活动最终解释权归平安科技所有。
