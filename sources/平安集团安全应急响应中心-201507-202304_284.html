工作职责

1．负责PSRC平台的漏洞审核和运营等工作；

2．负责最新的安全漏洞研究，最新安全动态的跟踪与探索；

3．负责平安集团的信息安全事件监控和响应工作。


职位要求

1．全日制本科及以上学历，三年以上信息安全相关工作经验

2．对常见的安全漏洞（ web、系统）的原理、危害、利用方式及解决方案有深入的理解并有丰富的经验。

3．有一定代码编写能力。熟练掌握一门开发语言（如 java 、 php 、 Python 等）并可开发简单工具。

4．具有踏实的工作心态、良好的沟通能力和团队协作能力，能有效的跨部门跨公司协调工作。

5. 有独立渗透测试经验，或有在各SRC提交过高质量漏洞，或有SRC运营工作经验，优先录用。


工作地点

上海/深圳
