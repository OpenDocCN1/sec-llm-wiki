# 关于平安集团安全应急响应中心月度和季度奖励的细则

平安集团PSRC尊重并感谢每一位安全人士的付出，为了公平、公正的奖励提交高质量漏洞的安全专家，我们对月度和季度奖励的细则进一步完善和规范，具体奖励细则如下。 

月度奖励：

1、入围条件：当月提交至少两个安全漏洞，且被审核员评为严重级别，同时漏洞不能为同一个应用的相同漏洞类型。

2、获奖名额：评选0到3名安全专家。当超过3名入围，按当月提交各等级漏洞数量由多到少排序，取前3名，评选方法以严重、高危到历史贡献度的顺序进行评选；

*   按严重漏洞的数量评选
    
*    按高危漏洞的数量评选
    
*   当提交所有等级漏洞数量一致，按历史贡献度进行评选；
    

3、奖金额度：

*    第一名：奖金10000元等值万里通积分；
    
*    第二名/第三名：奖金各5000元等值万里通积分；
    
*    当获奖名额不足3名时，从第三名开始取消，直至全部取消；
    

4、发奖时间：每月下旬发放上一月的奖励；

5、公告公示：公示获奖名单、排名及奖金等内容，公示内容可关注PSRC网站及PSRC官方微信号； 

季度奖励：

1、入围条件：当季连续三个月每月提交至少一个被审核员评定为严重级别的漏洞；

2、获奖名额：评选0到3名安全专家。当超过3名入围，按当季提交各等级漏洞的数量由多到少排序，取前3名，评选方法以严重、高危到历史贡献度的顺序进行评选；

*   按严重漏洞的数量评选
    
*    按高危漏洞的数量评选
    
*    当提交所有等级漏洞数量一致，按历史贡献度进行评选；
    

3、奖金额度：奖金10000元等值万里通积分；

4、发奖时间：每年的1月下旬发放上年第四季度奖励，4月、7月、10月下旬发放当年上一季度奖励；

5、公告公示：公示获奖名单、排名及奖金等内容，公示内容可关注PSRC网站及PSRC官方微信号；

本奖励细则于2016年5月开始实施，对2016年4月及以后的月度奖励生效，对2016年第二季度及以后的季度奖励生效。

本奖励细则解释权归平安集团PSRC团队所有。
