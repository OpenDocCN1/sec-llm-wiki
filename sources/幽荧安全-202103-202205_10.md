**XSS漏洞类型**

  

**  反射/存储型 XSS**

  

       反射型xss通常是指恶意代码未被服务器存储，每次触发漏洞的时候都将恶意代码通过GET/POST方式提交，然后提交漏洞。存储型xss则相反，恶意代码被服务器存储，在访问页面时会直接被触发（如留言板等）。

  

**  DOM XSS**

  

    DOM XSS是页面中原有的JavaScript代码执行后，需要进行DOM树节点的增加或者元素的修改，引入了被污染的变量，从而导致XSS。如下图，其功能是获取imgurl参数中的图片链接，然后拼接出一个图片标签并显示到网页中。

![](../Images/8eb48e6a68445ea0f292d5be416e6fde.png)

  

    输入并不会直接被打印到页面中解析，而是等页面中的JavaScript执行后取出我们可控的变量，拼接恶意代码并写入页面中才会被触发，如下图。

********  伪协议********

   有时当我们鼠标停留在某处链接上时，会看到javascript:void(0)这样的链接。其实这是javascript伪协议，当我们点击或跳转到javascript伪协议时，浏览器并不会访问这个地址，而是把javascript:后面的内容当作javascript代码执行。我们可以利用javascript伪协议达到xss的目的，如：

  

标签触发

*   
*   
*   

```
<a href="javascript:alert(1)">xss</a><iframe src="javascript:alert(1)"></iframe><form action="javascript:alert(1)"><input type="submit">
```

  

跳转触发

*   
*   
*   

```
<script type="text/javascript">  location.href="javascript:alert(1)";</script>
```

**  CSP过滤**

  

    内容安全策略   (CSP，Content-Security-Policy) 是一个额外的安全层，用于检测并削弱某些特定类型的攻击，包括跨站脚本 (XSS) 和数据注入攻击等。无论是数据盗取、网站内容污染还是散发恶意软件，这些攻击都是主要的手段。如设置页面引用的Javascript文件只允许来自百度的子域：

  

*   
*   
*   

```
<?php  header('Content-Security-Policy: script-src *.baidu.com');?>
```
