**命令执行漏洞原理**

  

    如PHP中的system()函数：

*   
*   
*   
*   

```
<?php  $id = $_GET['id'];  system("echo ".$id);?>
```

      

    此时没有任何过滤，为避免url歧义，使用%26%26（也就是&&）成功实现命令执行

  

![](../Images/6ca68d9cad305fc65cb9c99f83933806.png)  

  

**命令执行漏洞利用**

  

    命令执行漏洞通常需要注入一些字符串来实现多条命令执行，如&&。

  

*   
*   

```
Windows  中有&&、||、%0aLinux    中有&&、||、;、$()、``、%0a、%0d
```

  

![](../Images/082fcea24ac83c315d233ac6ceaa0f1b.png)

  

![](../Images/f8217e9873508c41457972574326f9cb.png)

  

![](../Images/4f60d6fa8909abd37f50ebda0dcd36ce.png)

  

    其中符号%0a与%0d是因为换行才可以执行新的命令，符号\`\`与%()需要不被单引号包括才能得以解析，若被单引号包括则被当作字符串输出。

  

![](../Images/9a800c6a0ad00e7074c0196ba132d2fe.png)

  

    有时我们利用命令执行漏洞时需要注释后面的命令或字符串才不会报错，此时需要用到注释符，Windows中注释符为"::"，Linux中注释符为"#"。

  

![](../Images/41cf0719f8f32ae1e4967118ded6813a.png)

  

![](../Images/8ee7cb65b5ba83b241575010d3a9e477.png)

  

  

**命令执行漏洞绕过**

    

    过滤空格

  

*   
*   
*   
*   
*   

```
<?php  $id = str_replace(" ","",$_GET['id']);  echo $id . "<br>";  system("echo " . $id);?>
```

  

![](../Images/23863f20c15d2d5caa440644d94a873f.png)

  

Fuzz  

  

    使用工具Brup suite进行Fuzz，测试%00~%ff区间内那些可以实现绕过过滤空格（%20）

  

![](../Images/a7762331c4dfe4defe2bb64ad475819b.png)

      

    可以看到%28、%2b、%2c等都可以绕过过滤空格实现命令执行。  

  

![](../Images/de0d80a05dbf067be06e409a5a224735.png)

  

  

截取环境变量  

  

    在Windows系统中，环境变量%ProgramFiles%通常代表字符串C:\\Program Files，而这个字符串的第11个字符就是空格，我们可以使用截取符"~"将空姐截取下来，表达式为%ProgramFiles:~10,1%，代表从环境变量的第10个字符串开始截取一个字符串。

  

![](../Images/388f126b25158f1e03cc65b31c2b8445.png)

  

![](../Images/69c601fd8e3e33689a4adbcd2881e6db.png)

  

![](../Images/dd85a138f46cf68b82737f0d8b00b23f.png)

  

    在Linux中存在一个IFS(Internal Field Separator)环境变量，即内部字段分隔符，定义了bash shell的命令间隔字符，一般为空格。所以可以使用${IFS}的方式来代替空格。

  

![](../Images/5c40d5cdb0ae5deddf66a903b9d813af.png)

  

    也可通过$IFS$9的方式绕过，$9为当前系统Shell进程的第9个参数，通常为空字符。因为只注入$IFS时会出现错误，系统识别不了$IFS123，而后面加一个$9就行了，因为$后面为数字，且$只会读取一个数字。

  

![](../Images/08fd33ca03fab0401924dcf5ff0d6c8c.png)

  

![](../Images/859f6032756bc92cc37157ff3ee5d7fa.png)

  

![](../Images/f415871395f298166ae07b19424eece1.png)

  

    在Linux中还可通过{cmd,args}的方式绕过过滤空格，读文件时可以使用符号<与<>符号绕过过滤空格。

  

![](../Images/81285e947cad981c916d4c854b0c8461.png)

  

![](../Images/d724d8f2488bb133d4923447dff7f214.png)
