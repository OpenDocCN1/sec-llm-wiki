```
<?phphighlight_file(__FILE__);
$str1 = $_GET['str1'];$str2 = $_GET['str2'];if ($str1 != $str2 && md5($str1) == md5($str2) && !empty($str1) && !empty($str2)) {    echo "Grade 1 pass!";}
$str3 = $_GET['str3'];$str4 = $_GET['str4'];if ($str3 != $str4 && md5($str3) === md5($str4) && !empty($str3) && !empty($str4)) {    echo "Grade 2 pass!";}
$str5 = (string)$_GET['str5'];$str6 = (string)$_GET['str6'];if ($str5 != $str6 && md5($str5) === md5($str6) && !empty($str5) && !empty($str6)) {    echo "Grade 3 pass!";}
?>
```

首先看第一个，使用的是双等于，php弱类型比较产生漏洞，想要满足第一个判断只需要构造出MD5值为0e开头的字符串，这样的话弱类型比较会认为是科学技术法，0的多少次方都是0，因此可以绕过，有一些字符串的MD5值为0e开头，这里记录一下

*   QNKCDZO
    
*   240610708
    
*   s878926199a
    
*   s155964671a
    
*   s214587387a
    

还有MD5和双MD5以后的值都是0e开头的:

*   CbDLytmyGm2xQyaLNhWn
    
*   770hQgrBOjrcqftrlaZk
    
*   7r4lGXCH2Ksu2JNT3BYM
    

![](../Images/c1763641be48c64b10a3b476dbe04c60.png)

第二个因为是强类型比较，用0e开头的字符串是没办法绕过的了，但是PHP自身的特性使得可以提交一个数组，而md5函数传入数组的返回值都是NULL，这样就可以绕过强类型比较了，所以这里用GET传入?str3\[\]=1&str4\[\]=2就行了

![](../Images/059eb0b9872ed5c36e1c20efeff427ab.png)
