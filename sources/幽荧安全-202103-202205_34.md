# Apache Druid远程代码执行漏洞复现(CVE-2021-25646)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MTU1MTQ0MA==&mid=2247483656&idx=1&sn=a748e102ff447fe4a26b6e3460935b6e&chksm=cefd99b7f98a10a1105303c1f0e6a23ec0ff77afac3f5b4f0332db5292bab309e326baba40cb&scene=126&sessionid=1681659676#rd](http://mp.weixin.qq.com/s?__biz=Mzg3MTU1MTQ0MA==&mid=2247483656&idx=1&sn=a748e102ff447fe4a26b6e3460935b6e&chksm=cefd99b7f98a10a1105303c1f0e6a23ec0ff77afac3f5b4f0332db5292bab309e326baba40cb&scene=126&sessionid=1681659676#rd)

漏洞描述

Apache Druid包括执行用户提供的JavaScript的功能嵌入在各种类型请求中的代码。此功能在用于高信任度环境中，默认已被禁用。但是，在Druid 0.20.0及更低版本中，经过身份验证的用户发送恶意请求，利用Apache Druid漏洞可以执行任意代码。攻击者可直接构造恶意请求执行任意代码，控制服务器。

  

影响版本

Apache Druid < 0.20.1
