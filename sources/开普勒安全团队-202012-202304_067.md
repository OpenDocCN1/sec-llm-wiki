事件背景：

2022 年 6 月 2 日，Atlassian 发布了针对 CVE-2022-26134 的安全通报，CVE-2022-26134 是 Confluence Server 和 Confluence 数据中心中一个未经身份验证的严重远程执行代码漏洞。该漏洞在6月2日发布时未被修补，并且正在野外被利用。

Atlassian 于 6 月 3 日更新了他们的公告反映 Confluence Server 和 Data Center 的所有版本（无论是否受支持）都可能受到影响，但他们尚未确认最早受影响的版本。组织应安装修补程序或在紧急情况下应用变通办法。如果无法缓解任何版本的 Confluence 的漏洞，则应立即限制或禁用 Confluence Server 和 Confluence 数据中心实例。

  

**#  技术分析**

  

CVE-2022-26314 是一个未经身份验证的远程 OGNL 注入漏洞，导致在 Confluence 服务器（通常是 Linux 安装上的用户）的上下文中执行代码。鉴于该漏洞的性质，面向互联网的Confluence服务器面临非常高的风险。

去年，Atlassian Confluence遭受了类似的未经身份验证和远程OGNL注入——CVE-2021-26084。

该漏洞是影响 HTTP 服务器的 OGNL 注入漏洞。OGNL 有效负载放置在 HTTP 请求的 URI 中。任何类型的HTTP方法似乎都可以工作，无论是有效的（GET，POST，PUT等）还是无效（例如“BALH”）。

  

**# 全网扫描数据分析**

  

通过对全球网络通用端口进行端口扫描，配合Quake自身实现的Web指纹识别。可以了解到全球网络中Confluence服务器的分布情况。

以下是Quake平台针对全球Confluence 服务器情况的分析。

![](../Images/e6ebe40a06805e5ac28d7ca5f2d1574b.png)

图1 全球各个国家Confluence服务器分布情况 世界地图

  

![](../Images/1a526cd2e3b7b5a94a68ba2593ba6380.png)

图2 全球各个国家Confluence服务器分布情况-饼状图

  

根据Quake平台数据显示，截止2022年6月初，近一年当中全球共39,972个站点使用Confluence服务。Confluence服务使用量主要集中在美国，美国位居第一，共有111,722个，占比39.68%；中国位列第二，共有71,383个，占比24.34%；德国位列第三，共有63,849个，占比22.68%；爱尔兰有12,544个，占比4.45%。
