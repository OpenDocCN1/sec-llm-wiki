# 漏洞复现与预警CVE-2021-38666/CVE-2021-43233

**漏洞编号**

CVE-2021-38666

**漏洞危害**

当执行流执行进入漏洞的逻辑中时由于缺少必要的验证,导致内存空间被覆盖,使程序的内存空间被修改。攻击者可以利用漏洞进行拒绝报务攻击甚至远程代码执行。

**漏洞等级**

高危  

  

**漏洞编号**

CVE-2021-43233

**漏洞危害**

当远程桌面客户端在连接远程桌面处理某些通道信息时会触发远程代码执行漏洞。当用户连接到攻击者的恶意远程桌面的时候, 该漏洞可以被攻击者利用, 造成远程任意代码执行。

**漏洞等级**

高危

  

星棱实验室已完成CVE-2021-38666 与 CVE-2021-43233的复现。

![](../Images/34beec5262077bf6e7b269ae60b5003e.png)

  

  

公网并未发现有人透露相关poc和exp，目前发现有人利用POC噱头在github钓鱼，谨防钓鱼。

  

请尽快升级windows至最新版本。
