0x01 前言

作为一个脚本小子,不可避免的要去安装一些大佬写的软件。比如ARL、Viper,这些软件在使用的时候都需要用Docker去安装,所以通过本篇文章,我们来了解一下,什么是Docker,以及如何使用Docker.

Docker是基于Go语言开发的一款开源的免费的容器,在精通Go语言的基础上可以按照自己的想法进行修改。允许工作人员将应用打包至轻量级的容器里。有时候我们为了搭建一个漏洞测试的环境,其实没有必要把漏洞环境放到一个Linux系统中去,而是可以放到我们自己的Docker容器中.

0x02 正文

2.1 Docker的安装

Docker的架构

Docker的架构分为镜像(image)、容器(container)、仓库(repository).

镜像在运行时运行在容器中,类似于类和实例的关系.因此我们在使用Docker的时候,大多数是在容器中进行的.而仓库是保存镜像的地方.

Docker的依赖

Docker的依赖分为命名空间(namespace)和控制组(control group).

其中docker的命名空间类似于我们在学习编程语言C++中的命名空间,起到一个封装隔离的效果.

Docker中主要的命名空间有User、PID、IPC、Network.

其中User用来隔离用户名和用户组、PID用来隔离进程、IPC用实现跨进程通信访问、Network隔离网络.除此之外,Docker还可以隔离内核和版本.

而docker的控制组用于分配资源、达到资源限制、优先级设定、资源计量以及资源控制的目的.、

Docker的部署

笔者本次使用一套纯净的debain系统作为操作,安装社区维护版的docekr,在命令行如输入如下命令即可

apt-get install -y docker.io

下载完docker之后我们使用如下命令对docker进行简单的基本操作

#查看运行状态systemctl status docker #docker重启systemctl restart docker #查看docker版本docker version #查看帮助信息docker --help

假如我们下载一个容器,来检测docekr是否能正常运行.如果输出"haha",则说明docker可以正常运行。

docker run ubuntu echo "haha"

此命令会去仓库下载ubuntu的容器,并将其保存至如下目录中.

/var/lib/docker/containers

2.2 Docker基础操作

对于docker容器我们可以使用如下命令进行简单的操作

查看镜像

#查看所有镜像docker images -a #查看镜像完整iddocker images --no-trunc #查看镜像信息docker insepec ubuntu:latest #删除镜像docker rmi [镜像id]

使用此命令我们可以看到之前下载的ubuntu容器以及系统上保存的其他容器

拉取镜像

docker pull ubuntu #从docker仓库下载ubuntu镜像

列出运行容器与所有容器

#列出正在运行的容器docker ps #列出所有的容器docker ps -a #列出所有创建的容器docker ps -l

由此可以看出已经运行完的容器及其执行的命令,请注意第一项容器ID,我们可以根据此ID返回容器的配置信息.

返回容器配置信息

docker inspect [容器ID]

创建容器

docker run -i -t [镜像] /bin/bash#以别名运行容器docker run --name=ub1 -i -t [镜像] /bin/bash

可以看到已经进入到我们的ubuntu容器中

退出容器

如果想要退出容器,只需要先按住Ctrl+P、然后按住Ctrl+Q即可退出

进入容器

如果退出容器后还想重新进入,可以根据容器id结合如下命令进入容器中

docker exec -it [容器ID] /bin/bash

开关容器

#开启容器docker start [容器名]#关闭容器docker stop [容器名]

删除容器

docker rm [容器名]

守护式容器

守护式容器是长期运行、没有交互式会话,适合运行应用程序和会话的容器.

使用后台的方式来运行容器.

#在后台运行容器docker run -d [镜像] [执行命令]#以ub4别名运行,在后台执行相关命令docker run --name ub4 -d ubuntu /bin/bash -c "while true;do echo nihao;sleep 1;down"#转入运行中的容器docker attach [容器名]

请注意,以守护进程运行的容器,是没有交互式会话的,因此我们转入容器后只能看到容器运行的结果.

查看容器日志

docker logs [参数] [容器名]# -f 追踪日志变化,默认fasle# -t 返回结果加上时间戳# --tail 返回日志结尾,默认false

查看容器进程

docekr top [容器名]

2.3 Docker实战部署

我们尝试使用docker来部署一个网站,我们在访问一个网站的时候,一定是IP+PORT才能访问到,所以我们需要了解下docker端口映射的规则

#docker将所有端口进行映射docker run -P -it ubuntu /bin/bash#docker 只映射80端口,映射到本地的随机端口上docker run -p 80 -it ubuntu /bin/bash#docker 映射两个端口docker run -p 80 -p 3306 -it ubuntu /bin/bash#将docker的80端口映射到宿主机的8080端口上docker run -p 8080:80 -it ubuntu /bin/bash

接下来我们进行docker来实战部署一个web网站.

docker run -p 8080：80 -p 443 --name web1 -it ubuntu /bin/bash#升级dockerapt update#安装nginxapt-get install nginx#安装nanoapt-get install nano#安装vimapt-get install vim

此时我们进入/var/www文件夹可以看到默认网页已经出现.使用命令使得nginx配置生效

nginx -c /etc/nginx/nginx.confnginx -s reload

此时访问公网地址的8080端口,即可查看到nginx服务

2.4 Docker获取与推送

查找镜像

#查找和ubuntu有关的镜像docker search [镜像名]#查找3星以上的镜像docker search -s 3 [镜像名]#拉去镜像docker pull [-a] [镜像名]

可以看到搜索到不同版本与功能的ubuntu镜像。

推送镜像

有时候我们需要把镜像保存下来,譬如一些漏洞环境,所以需要docker来推送镜像到公有仓库中.

所以我们需要在hubdocker上注册账户,并且创建公有仓库。

#hubdocker网址https://hub.docker.com/

注册成功后在repositories处成功创建一个公有仓库

至此我们可以将自己本地搭建的docker容器封装好,上传至公有仓库,供他人使用.封装方法如下

首先将容器构建为镜像

docker commit -a "[指定作者]" -m "[镜像的信息]" "[容器id]" "[新镜像名]"

可以看到成功创建一个名为webngi的镜像。如果将其放置公有仓库,即可被别人访问.

当我们注册好hubdocker后,会得到账户名和密码.使用此账密在Linux服务器上进行登录

docker login

登录成功后我们封装好的容器打好标签,继而上传到公有仓库中去,命令如下

#对镜像打好标签docker tag [镜像名:镜像TAG] [hubdocker账户名/hubdocker仓库名:项目名]#推送镜像docker push [hubdocker账户名/hubdocker仓库名:项目名]

此时在公有仓库中出现我们上传的镜像,

可供他人拉取使用
