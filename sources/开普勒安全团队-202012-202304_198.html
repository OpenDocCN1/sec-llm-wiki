字符串搜索是计算机中常用的功能, 今天说一下效率比较高的KMP算法。    

KMP算法(Knuth-Morris-Pratt string-searching algorithm) 是一个著名的字符串匹配算法, 效率挺高, 但是有点复杂, 该算法由Donald Knuth 和 Vaughan Pratt在1974年构思, 同年James H. Morris也独自设计出该算法, 最终三人在1977年联合发表了该算法。


下面说一下KMP算法的各个变量表示，pat表示要匹配的模式串，长度为M。str表示主字符串，长度为N。

  KMP算法就是在str中查找pat的位置, 如果存在pat, 返回其第一个字符的下标(从0开始), 否则返回-1。

首先简单介绍一下KMP算法和朴素查找算法的不同点, 朴素的字符串查找很简单, 不停的遍历对比, 时间复杂度 O(NM), 如果str很长且重复字符较多的话, 效率会非常低, 下面是C++实现的朴素查找算法

     KMP算法就是在str中查找pat的位置, 如果存在pat, 返回其第一个字符的下标(从0开始), 否则返回-1。     

如果匹配不到完整的pat, 朴素算法会重复扫描str的字符, 举个例子, str = “adababababc”, pat = “ababc”    

在这个例子中朴素算法会不停的重复对比两个字符串    

但KMP的做法就会聪明很多, KMP算法会花费空间记录某些信息, 使str 的字符不会被重复扫描, 我们把记录信息的数组叫做next_state    

KMP的难点就是如何计算next_state数组中的信息并根据这些信息移动pat的指针j

你可能会疑惑, 为什么只有pat没有str, 因为构建next_state只需要pat就可以了, 这意味着在不同的str中寻找相同的pat只需要创建一个next_state就够了

下面说一下如何计算next_state中的信息    

我们可以认为匹配pat就是匹配状态, 还是上面的例子

str = “adababababc”,pat=“ababc”


 

0是起始状态, 5就是终止状态, 一旦pat到达终止状态, 说明在str中找到了pat, 如果当前状态为3, 说明找到了在str找到了”aba”


假设现在匹配到了状态4

 

但是遇到了字符a, 那么回到状态3是最好的

   


继续前进, 字符相同, 又到了状态4

继续前进, 顺利到达状态5, 匹配完成

接下来就是计算匹配失败回退位置的表, 对于匹配失败的点P的返回位置我们用next_state[P]来表示, 下标0和1的位置表示边界。    

next_state[0] = next_state[1] = 0    
如果我们已经计算出了next_state[P], 且 pat[next_state[P]] == pat[P],     
next_state[P + 1] = next_state[P] + 1  如果pat[next_state[P]] != pat[P],我们就看 pat[next_state[next_state[P]]]，是否等于pat[P]，如果相等则next_state[P + 1] = next_state[next_state[P]] + 1,不相等则再退一步, 直到相等或到0, 我直接在构造函数里写next_state的部分。
