虽然Linux发行版支持各种各样的饿GUI（graphical user interfaces），但在某些情况下，Linux的命令行接口(bash)仍然是简单快速的。Bash和 Linux Shell 需要输入命令来完成任务，因而被称为 命令行接口。

命令是计算机执行任务的指令。可以使用命令去关闭计算机，或者列出当前目录的文件列表，或当前文本的内容，或者屏幕显示一条消息。

如果你是一个新手，并尝试使用命令行接口，我们收集了各种基本的Linux命令来供你学习，帮你在各种Linux发行版中完成各种任务。虽然不是很详细，但是对Linux初学者，或普通用火，或管理员都是很有用的。

1.ls – List

ls会列举出当前工作目录的内容（文件或文件夹），就跟你在GUI中打开一个文件夹去看里面的内容一样。

![](../Images/26705e6f4638b6ab067654d5d3b0ba87.png)  

2.mkdir – Make Directory

mkdir 用于新建一个新目录

![](../Images/ec77e44179c06748df2f9772e78d4b85.png)  

3.pwd – Print Working Directory

pwd显示当前工作目录

![](../Images/3258b43c128c73079ba98d8be533bebc.png)  

4.cd – Change Directory

对于当前在终端运行的会中中，cd 将给定的文件夹（或目录）设置成当前工作目录。

![](../Images/36cc738942de3ffc624bfc3dffc9d575.png)  

5.rmdir – Remove Directory

rmdir 删除给定的目录。

![](../Images/92b6266056fee4cb98237de15bbc4fcc.png)  

6.rm – Remove

rm 会删除给定的文件或文件夹，可以使用rm -r 递归删除文件夹

![](../Images/38f993f11c2b8e8cd627ff174590a646.png)  

7.cp – Copy

cp 命令对文件或文件夹进行复制，可以使用cp -r 选项来递归复制文件夹。

![](../Images/ce1486b76047e76869716c512dded36e.png)  

8.mv – MoVe

mv 命令对文件或文件夹进行移动，如果文件或文件夹存在于当前工作目录，还可以对文件或文件夹进行重命名。

![](../Images/58e23ca441945fb565a597fcf937445b.png)  

9.cat – concatenate and print files

cat 用于在标准输出（监控器或屏幕）上查看文件内容

![](../Images/0d27a92bb8c435b145f65b27b8101a7c.png)  

10.tail – print TAIL (from last) >

tail 默认在标准输出上显示给定文件的最后10行内容，可以使用tail -n N 指定在标准输出上显示文件的最后N行内容。

![](../Images/57b7c1da852a603476c8ec2c8564bedd.png)  

11.less – print LESS

less 按页或按窗口打印文件内容。在查看包含大量文本数据的大文件时是非常有用和高效的。你可以使用Ctrl+F向前翻页，Ctrl+B向后翻页。

![](../Images/a5f97e910655f040455582dd7e4ff53e.png)  

12.grep

grep “” 在给定的文件中搜寻指定的字符串。grep -i “” 在搜寻时会忽略字符串的大小写，而grep -r “” 则会在当前工作目录的文件中递归搜寻指定的字符串。

![](../Images/4085d26e9cc162898bc09e4b4cf26c4a.png)  

13.Find

这个命令会在给定位置搜寻与条件匹配的文件。你可以使用find -name 的-name选项来进行区分大小写的搜寻，find -iname 来进行不区分大小写的搜寻。

find <folder-to-search> -iname <file-name>

![](../Images/9510bdf0e66d6174a148712ac399df6c.png)  

14.tar

tar命令能创建、查看和提取tar压缩文件。tar -cvf 是创建对应压缩文件，tar -tvf 来查看对应压缩文件，tar -xvf 来提取对应压缩文件。

![](../Images/cb2f46f949b019166ba8c8c50db246f9.png)  

15.gzip

gzip 命令创建和提取gzip压缩文件，还可以用gzip -d 来提取压缩文件。

![](../Images/7ac3207a5ecc8168c1ec5c4ca4bb20c4.png)  

16.unzip

unzip 对gzip文档进行解压。在解压之前，可以使用unzip -l 命令查看文件内容。

![](../Images/d8810f20740c441b1edbc339f06fb98f.png)  

17.help

–help会在终端列出所有可用的命令,可以使用任何命令的-h或-help选项来查看该命令的具体用法。

![](../Images/4c42cf6a35090fe224087a203a6b0841.png)  

18.whatis – What is this command

whatis 会用单行来描述给定的命令。

![](../Images/2f8763b3c45a8c66a43ee7170691996f.png)  

19.man – Manual

man 会为给定的命令显示一个手册页面。

![](../Images/9f987f44d4b365db9dc8f753171372ec.png)  

20.exit

exit用于结束当前的终端会话。

![](../Images/8a76038e9053a6739fd8dc9f15ebe3ce.png)  

21.ping

ping 通过发送数据包ping远程主机(服务器)，常用与检测网络连接和服务器状态。

![](../Images/9557115bf5782133275534fc3db9e2e0.png)  

22.who – Who Is logged in

who能列出当前登录的用户名。

![](../Images/cafae9207b031108f208c29c0d66e3fc.png)  

23.su – Switch User

su 用于切换不同的用户。即使没有使用密码，超级用户也能切换到其它用户。

![](../Images/d782cfa69c3a05c92c57d2a9858b934c.png)  

24.uname

uname会显示出关于系统的重要信息，如内核名称、主机名、内核版本、处理机类型等等，使用uname -a可以查看所有信息。

![](../Images/5caf6838d4892e5ffd83cae04c00ecc3.png)  

25.free – Free memory

free会显示出系统的空闲内存、已经占用内存、可利用的交换内存等信息，free -m将结果中的单位转换成KB，而free –g则转换成GB。

![](../Images/687a0ca80fb5e5b394f4cbc1a803c978.png)  

26.df – Disk space Free

df查看文件系统中磁盘的使用情况–硬盘已用和可用的存储空间以及其它存储设备。你可以使用df -h将结果以人类可读的方式显示。

![](../Images/f6652b22d29d92295b35e340a7295470.png)  

27.ps – ProcesseS

ps显示系统的运行进程。

![](../Images/a6246fd8953c0073f438f179e266de53.png)  

28.Top – TOP processes

top命令会默认按照CPU的占用情况，显示占用量较大的进程,可以使用top -u 查看某个用户的CPU使用排名情况。

![](../Images/22c21fc00997695a8eee092faf4a0519.png)  

29.shutdown

shutdown用于关闭计算机，而shutdown -r用于重启计算机。
