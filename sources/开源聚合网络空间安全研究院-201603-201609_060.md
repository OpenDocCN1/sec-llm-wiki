不论是谁给你介绍的，不论发过来的照片多么难看，不论你是否还有个bug要调试，都不要拒绝相亲。

长点心吧，你是在和异性见面，这是多么美妙的事啊！

有些程序员，因为 if then写多了，猪油逻辑蒙了心，变得矫情了，非常不随和。 有人介绍相亲就拿糖作醋，显得自己很高洁，很善于孤独，很喜欢独处，一个人完全可以独善其身的样子。 那副玉在椟中求善价，钗在奁内待时飞的模样，好像很屌。

这很不好！一点都不酷！

![](../Images/92c6f121826ab795e195dd30afbafb0b.png)  

男人么，在对女人的热爱上，一定要直白点才好！

曾经认识个老哥们，快50了，他有个口头禅：“那你给我介绍个女友？” 那种热爱生活，热爱女人的气场，常常让人感动到落泪~

虽则这是小事，但也很重要，因为情趣显露无疑。 注意这里不要搞混，情趣不等于奢侈，咱们强调的是，没钱也要追求一点情趣……

这些都是“快”餐。 “快”在男女关系中是大忌， 一定要追求“慢”，追求“持久”！哪怕花10块钱逛个公园，都比快餐店好。

有的程序员，相亲相多了有点疲惫，就喜欢速战速决，咖啡馆里见一面，不喜欢，10分钟就拍屁股回去改bug……

***3***聊天话题

很多女孩，会绕着弯盘问房子车子收入，对这个呢，孤傲的穷程序员们要理解。 毕竟咱们还处在发展中的特殊阶段，人们普遍还处在生存忧虑之中。 而女人么，在这种环境下，最优的择偶选择就是：能保证她及携带她DNA的后代，可以最大几率的生存下去。

所以，程序员在遇到女孩的盘问时，千万别不耐烦，更不要自卑或者自傲。 要不卑不亢的说：“我写一行代码价格是100元，一天能写500行。”

或者：“我的同事，刚刚把股份卖了一半，换了200万美金的cash”

![](../Images/f7f12345092f67b26359c7ec38dfd415.png)

尽量不要直白的说，你的月薪6800。哪怕是美金6800，也不要直接说出来。

这一关过了后，才可以谈点别的。 音乐旅游艺术体育科技都可以，不要谈跑车和私人飞机，你又不是王思聪……

旅游这个话题最安全。99%的女孩都已经在一次或两次的西藏，或者桂林，或者普吉岛的旅游中，净化过自己的心灵了。 所以谈旅游吧，女孩会很热情的介绍自己如何净化心灵的。 当然她们不会说自己的心灵为什么需要净化

一个大忌是，千万不要谈技术！！即便你能把 JAVA 多线程和垃圾回收机制谈得很精彩，那也不能给你加分。唯一可谈的技术话题是：iPhone 的操控体验。

表白， 这种来自东南亚影视剧的肉麻行为，是对我大中华极简主义实用主义文化的悍然入侵。

真是他妈的太肉麻了。

什么1000朵玫瑰，什么用花摆个花环，什么在商场餐厅里挂个横幅，然后大老爷们当着众人跪下，你以为接下来女孩会热泪盈眶，捂着脸抽泣？……

猫狗当众交配，男女当众表达感情，全都是极其极其惹人腻歪的事。

相亲时，哪怕第一次第二次见面，程序员都要能够大大方方的，盯着女孩的眼睛，说一句：我喜欢你。

有句名言：所有不以婚姻为目标的相亲，全都是耍流氓。

去相亲，最直接，最单纯的目标是：寻找一个自己喜欢的女孩。

程序员们，大胆泡妞去！先不要想婚姻。
