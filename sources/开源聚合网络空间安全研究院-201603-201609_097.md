# 【刷爆朋友圈】萌妹子iPhone丢了后，做了这样一件事……

![](../Images/7e5e0083de0bc1397fbe488cf1f37c5e.png)

大概故事是这样子的，女主人公是个萌妹子，发生了以下这样的事情！！！

之前在外地旅游的时候，妹子弄丢了一个iPhone。因为人在外地，所以没有抱着找回手机的希望。但是丢失了还是本能的开启了iPhone的查找模式和丢失模式。

事发快半年了，结果突然收到了“苹果”发来的邮件。

![](../Images/d2fc5565b83e9578c5c1063fa215c861.png)

当时的先只能说是太开森了，心里狂喊着苹果要不要辣么智能，赶快点开来看看位置。然而并没有看到，并且怀疑自己是不是跟现在的手机一个ID所以看不到。结果，过了两天，又收到了一封邮件。

![](../Images/0f4a9006e589a073397c9bde55db49cc.png)  

感觉又要离找回手机更近了一步，马上点开链接。填写相关的信息，然后还赶紧找淘宝里面找回手机服务的人咨询。结果，被告知这样的网站是钓鱼网站，不要填写。

顿时懵逼，我去。。钓鱼网站，居然我还遇到了钓鱼网站，还中招了!现在的手机也用了一样的ID，所以当时就方了，我马上找同事求救。

![](../Images/24edfb068e27d493c8b2264dc713e89c.png)  
![](../Images/1a310bdac61df2e9b059b8cfdcc1fc11.png)  
![](../Images/22b4b5dd5c882e7fd855b2c78a449a8d.png)

  

结果，半小时后，同事就把团队攻破了，看到里面有1000多被骗信息。然后，帮我把输入的信息全部删了，也提醒我改了密码。

本来故事到此结束了，没想到今天早上一上班，其他同事也知道这件事情，瞬间high了。

第一，他们超级无奈为什么我每天要跟大黑客在一起，还能干出这么蠢的事情。

第二，还给我科普了一下更逼真的钓鱼网站，特别是银行的钓鱼网站长什么样子。

第三，报仇啊!!!!必须报仇!!!居然敢搞我的人。

![](../Images/f80a69d2409e08c1d50a9fcd4ea886c2.png)  

于是，他们又开始了一系列狂拽吊炸天的反攻。额，至于做了什么事情呢，大概的思路如下：通过注入拿到了管理员的账号密码，提取了他所有的信息。例如：地址(辽宁铁岭)，QQ账号和密码，并且登录他的QQ，查看他的好友，QQ邮箱，还有其他各种消息。事已至此，鉴于我也没有什么金钱损失，之有找到一个同样被骗的辽宁当地人，看看能不能帮忙报个警神马的。

![](../Images/9ae20e19ca1d1d2752e66b7ccdbc65a3.png)  

后续的感受，之前圈外人总是对黑客有太多无解。但是经过这一件事，我只觉得他们是我我见过最仗义能以非技术人员的身份结束他们。对于网络安全一无所知的我，才惊觉原来的生活活的这么小心，生活中有太多的陷阱，但还好有一帮大黑客们帮我撑腰，就算智商是零的时候，还能有一群智商超群的人挽救我，我只能说混黑客圈的妹子，上辈子绝对拯救了宇宙。

当然了，在这个互联网+时代，无论是作为安全从业者还是互联网从业者，还有很多没有意识到被钓鱼balabala的亲朋好友们，我们没办法从技术的角度要求更多，但是至少可以做他们的守护者。
