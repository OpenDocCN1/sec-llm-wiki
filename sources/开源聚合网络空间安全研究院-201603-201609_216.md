# 还敢再爱吗？吓死宝宝了！“听说你爱我”网游盗号木马追踪

![](../Images/3f6ade97e4408784672633f5d1fef177.png)近期有玩家反映游戏遭木马盗号，并发现黑客就像阴魂不散一样随时都能控制电脑。根据网友反映的样本信息，360QVM团队进行分析，发现该木马以内存加载和恢复恶意代码的方式来躲避查杀，同时它还会开启3389端口并增加一个管理员帐户，使盗号者能够随时远程登录受害者电脑，即使木马被查杀也极易再次中招。

**木马盗号**

木马一共有四个文件，一个快捷方式，三个隐藏属性的文件，分别是一张图片，一个exe文件和dll文件，exe程序被加密：

![](../Images/0fad35ad22218553447791b85090a4d5.png)

![](../Images/8548e9bd9af85d6e87d7ab38668ce26e.png)

可执行程序是隐藏的，打开快捷方式之后显示了一张图片：

![](../Images/a1d0b81521d8b21a6f3f17f8e0ee2dd3.png)

       但是木马程序已经在后台开始运行。分析快捷方式文件“12浓雾之息.lnk”，我们找到了一个文件名：

![](../Images/b9efd100e7de96d9fdcfc1dee41baf9f.png)  
     这是被快捷方式启动的木马程序，继续分析找到这个木马程序，它首先会调用命令行显示图片：

![](../Images/39a5aacc28f1ea76df9a93ef65471362.png)  
     接着释放crossfire.exe文件和Release.dll文件到临时目录：

![](../Images/db474bbafa481fd46ad1f3c6bf7e9dce.png)

![](../Images/e5cd8ab72f481352457e4e7dbc22d5ca.png)

然后创建crossfire.exe进程：

![](../Images/6c6b60e7f073c153cde9c23766848732.png)  
     crossfire.exe的主要功能是修改Release.dll的前两字节，并且在内存中加载Release.dll。

![](../Images/d4ce552b1a3dcc4af7e391f88cf20374.png)

![](../Images/d8c35cebffeb2cf74e9c4ca129ce4d1c.png)

Release.dll经过修改之后，是一个加密的dll文件，

![](../Images/1ca18398163a0ba6e619d4598583cc95.png)  
里面有木马的主要功能：

1、遍历检测杀毒进程

![](../Images/89fded25ab527987a937f8ea5195490c.png)  
      2、查找游戏相关的信息

![](../Images/e288846820290079c1bc585f3f1f6f33.png)  
     3、获取键盘信息

![](../Images/2a29f7588334ab96a341941542c37105.png)

![](../Images/db179cdcf4414ad426d3ee087181ee51.png)

4、联网下载文件

![](../Images/0f398a108f65d614d64b1db72d4fef0c.png)  
     5、接受远程指令，开启3389，接受远程控制等

![](../Images/33fe2e002c1cb87a11a4fc7271967868.png)

![](../Images/774317d2e3267063bf389d58c699cdb2.png)

其中会判断3389是否开启，以及安全狗防护页面等

![](../Images/c9b19db222fabbb0d722d8386220ca74.png)

![](../Images/586bc9ef3974e279faab018bdb3bdc49.png)

由于具备了完整的远控和盗号功能 ，根据远控的域名信息**a19931108.com**，进一步分析牧马人信息：

![](../Images/9627f06a5dcbaaf71c02266a18648e83.png)  
      通过搜索1030889799@qq.com，我们找到了该QQ号的受害者以及牧马人的相关信息：

![](../Images/6d97f0a8044ef46b02f33e57bd72c79a.png)

![](../Images/73c8ee444696e6c3837e7aab2bf4b3a7.png)

![](../Images/a49242403e14d95b43a5d013f1a9e1f1.png)

根据木马查杀数据，从2月初到3月，该盗号远控木马已活跃了一段时间，主要通过游戏平台和聊天软件文件传输进行传播。

  

在此提醒游戏玩家，电脑“文件夹选项”的设置一定要显示文件类型的扩展名，以免被木马文件的名称和图标迷惑；如果杀毒以后发现电脑反复感染病毒，建议使用安全软件“防黑加固”，防止远程端口被黑客控制利用。
