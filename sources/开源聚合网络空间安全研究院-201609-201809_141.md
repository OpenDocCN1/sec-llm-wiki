# 【黑客工具】树莓派原来可以这么玩，实现WIFI窃听和嗅探！

![](../Images/538a98f4660fa3ae80a72e56539cf154.png "引导关注")Wimonitor是一款非常优秀的黑客工具，它不仅可以帮渗透测试人员省去配置虚拟机和无线网卡等一系列麻烦事，而且它的Web接口配置起来也非常的方便。

实际上，它就是一款TP-Link-MR3020路由器，只不过它使用的是自定义固件，并能够将监控到的网络数据包转发给主机电脑（Mac或Windows等主机），而我们此时就可以使用WireShark来对数据包进行分析了。

![](../Images/7d6ae30977e9359c6f2025b99bf20461.png)

但是，我们可不可以使用树莓派来实现一样的功能呢？答案当然是肯定的，因此在这篇文章中，我们将教会大家如何使用树莓派3B来搭建一个稳定的WiFi监控平台，并通过几个简单的步骤来将其模拟成一个Wimonitor。

01硬件要求

  

1.运行Windows的笔记本电脑（测试设备使用的是Windows 8.1）

2. 树莓派3B、Micro SD卡、电源适配器（USB 3.0足够驱动树莓派+无线网卡了）

3. 网线（连接树莓派和笔记本电脑）

4. 支持监听模式的无线网卡（例如TL-WN722N v1）

02安装配置

首先，将RASPBIAN STRETCH LITE刻到Micro SD卡中，这是一个轻量级操作系统，并且支持例如TL-WN722N之类的无线网卡，具体的步骤请参考【操作指南】(http://www.raspberry-projects.com/pi/pi-operating-systems/win32diskimager)。

刻录完成之后，我们可以通过在SD卡中创建一个名叫ssh的空文件（无需文件扩展名）来启用树莓派的SSH功能。

为了确保笔记本电脑能够跟Pi正常通信，最简单的方法就是用笔记本给Pi共享WiFi，这样就可以保证Pi的IP地址在192.168.137.x范围内。进入网络连接设置（ncap.cpl），右键点击Wi-Fi适配器，然后选择属性。在“Sharing”标签页中，选择需要插入Pi的以太网适配器，点击OK。

![](../Images/7988f416f2755cb4ec0eba47feb91aa9.png)

接下来，将Pi与笔记本主机连接，然后把SD卡插到Pi的卡槽中，将无线网卡插入到USB端口连接网线（笔记本主机-Pi），然后启动设备。

当Pi启动之后，它将会使用共享链接的IP地址，你可以在笔记本主机上使用nmap（对192.168.137.1/24子网进行主机搜搜）来查看Pi的IP地址。

![](../Images/647432922acf6810a2a31b477e966401.png)
