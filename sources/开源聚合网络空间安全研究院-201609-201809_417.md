导语

PentestBox是一款可以运行在所有版本Windows平台下预配置的便携式开源渗透测试环境

有人问，windows下有没有跟kali一样的功能，推荐大家试试pentest box：一个配合吾爱xp系统堪称完美安全windows的集成工具。

 前言

为什么又有一个渗透测试环境？

PentestBox不同于运行在虚拟机或者双启动环境的Linux渗透测试发行版。

它打包了所有的安全工具，并且可以在Windows系统中原生地运行，有效地降低了对虚拟机或双启动的需求我们发现超过50%的渗透测试发行版是运行在Windows系统下的虚拟机程序中，这激发我们创造了它。

（摘自官网）

CTRL + T ：要打开新的标签页

CTRL + C ：要关闭脚本/程序运行。

如果多个选项卡是开放的，那么你可以使用它们访问，number是选项卡的tab。例如，该数量将1对第一个选项卡，2代表第二个标签等。SHIFT+ ALT + numberCTRL + w ：关闭当前活动的控制台。

ALT +Enter ：全屏。
