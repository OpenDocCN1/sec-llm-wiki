1/0 MySQL扩展


PHP中MySQL扩展，虽然因为安全的原因，在PHP5.6及往上不在支持MySQL扩展库，但是还是要学习的，通过编写案例的方式来讲解。

1/1 案例


先说下操作数据库的大体思路吧，就是先获取连接-》选择数据库-》设置操作编码-》发送sql指令-》对返回的结果进行处理-》释放资源，断开连接。案例是一个在线词典查询。下面是创建表的sql语句：

1 create database worddb
2     create table words(
3          id int primary key auto_increment,
4          enword varchar(32) not null,
5          chword varchar(256) not null
6          );
7     insert into words(enword,chword) values ('boy','男孩')
8     insert into words(enword,chword) values ('school','学校')

2/0 MYSQLI扩展


其实mysqli扩展是mysql扩展的加强版，因为历史原因，有一些老程序员擅长面向过程写法，所以PHP设计者为mysqli设计了两套方案，一套面向对象，一套面向过程，甚至一个聊本里可以混着用，不过那样很怪，下面的案例都是采用面向对象的那套方案。

3/0 MySQL批量执行SQL语句


上面简单介绍了MySQL扩展和MySQLI扩展，接下来说一说批量执行sql语句。

先提一个需求，如果我们像数据库批量添加用户，如果按照之前的办法一条一条的发送sql语句来处理，这样很占用资源，并且效率低。所以采用批量执行sql语句的方式。接下来用两个案例来讲解，因为增加，修改，删除操作返回的是布尔值，而查询操作返回的是结果集，所以分来来处理比较好。


➤
3/1 批量执行dml语句


因为dml返回的是布尔值，所以处理起来也比较好处理。先创建表，顺便插入一条数据如下：

1create database test;
2use test;
3create table users(
4     id int(8) unsigned auto_increment primary key,
5     name varchar(128) not null,
6     password varchar(256) not null);
7insert into users(name,password) values('test','13579');


下面就是批量执行dml操作的代码：

 1  <?php
 2$mysqli=new mysqli("localhost","root","XFAICL1314","test");
 3if ($mysqli->connect_error){
 4    echo "连接失败";
 5}
 6$sqli="insert into users(name,password) values ('小利',md5('13568'));";
 7//批量执行dml操作时，注意上一级句的;和下一句的.两个符号
 8$sqli.="insert into users(name,password) values ('小利',md5('13568'));";
 9$sqli.="insert into users(name,password) values ('小利和小峰',md5('13568'))";
10
11$b=$mysqli->multi_query($sqli);
12if (!$b){
13    echo "插入失败";
14}else{
15    echo "ok!";
16}
17$mysqli->close();
18?>


然后访问页面，返回ok,说明插入到数据库了，现在打开数据库查看，果然插入进去了，如下图：

3/2 批量执行dql操作


批量执行dql操作的作用是一次性取回多个结果集，下面看案例代码：

 1  <?php
 2header("Content-type:text/html;charset=utf-8");
 3$mysqli=new mysqli("localhost","root","XFAICL1314","test");
 4if ($mysqli->connect_error){
 5    echo "连接失败";
 6}
 7$sqli="select * from users;";
 8$sqli.="select * from lsp";
 9//因为multi_query这个函数比较傻，不会去判断有没有下一个结果集，所以最后再用more_results函数检查一下。
10if ($mysqli->multi_query($sqli)){
11    do{     //从mysqli中取出第一个结果集
12        $result=$mysqli->store_result();
13            //显示mysqli $res对象
14            while ($row=$result->fetch_row()){
15                foreach ($row as $key=>$val){
16                    echo "--$val";
17                }
18                echo "<br>";
19            }
20                $result->free();
21            //判断有没有下一个结果集，如果没有退出循环
22            if (!$mysqli->more_results()){
23                break;
24            }
25            echo "<br>*************新得结果集<br/>";
26    } while ($mysqli->next_result());
27}
28?>

4/0 MySQL事务控制


上面简单介绍了MySQL扩展库，MySQLI扩展库，批量执行SQL语句，接下来说一说MySQL事务控制。


➤
4/1 数据库配置


说MySQL事务控制之前，先查看并修改数据库引擎，查看引擎的命令如下：

show engines


我们发现，只有InnoDB是支持事务的，所以先查看一下现在得数据库引擎：


发现是MyISAM，我们将它修改为InnoDB，打开配置文件my.ini，将“default-storage-engine=MYISAM”改为你想设定的，然后重启即可。修改成功后，然后下一步就是代码实现。


➤
4/2 案例


我们为什么需要事务控制呢？想一想，如果这是一个转账得场景，是不是需要同时控制住，必须我减金额得同时你加金额，任何一个出错都得转账失败。也就是说要保持一致。这也是要进行事务控制得必要性。下面看案例代码：

 1  <?php
 2header("Content-type:text/html;charset=utf-8");
 3$mysqli=new mysqli("localhost","root","XFAICL1314","test");
 4if ($mysqli->connect_error){
 5    echo "连接失败";
 6}
 7//将提交设置为假,因为事物一旦提交就没有机会回滚
 8$mysqli->autocommit(false);
 9
10$sql1="update  person set money=money-3 where id=1";
11//这里第二条语句我故意写错表名
12$sql2="update  persons set money=money+3 where id=2";
13
14$b1=$mysqli->query($sql1);
15$b2=$mysqli->query($sql2);
16if (!$b1 || !$b2){
17    echo "修改失败，回滚".$mysqli->error;
18    $mysqli->rollback();
19}else{
20    echo "修改成功！";
21    $mysqli->commit();
22}
23$mysqli->close();
24?>
