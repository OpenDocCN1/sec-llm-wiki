根据网上公开的poc可知，漏洞利用url是修改密码功能password\_change.cgi，且需要开启密码修改功能（1.890默认开启此功能），vulhub的镜像已经开启密码修改功能（如何开启密码修改功能请看后面附录二）。  

  

![](../Images/3d975e560e3ab4831c6033cb81eb2673.png)**修改密码**

  

不知道默认登录密码，进入容器中修改root密码为root

  

重新打开一个shell窗口，进入容器后不要着急退出，后面还会用到

```
docker 
```

进入/usr/share/webmin修改密码

```

./changepass.pl /etc/webmin root root
```

**附录一：**

  

上面说到需要开启修改密码功能才能利用漏洞，那么如果开启这个功能呢？

使用刚才改的密码（root/root）登录成功后，进入Webmin Configuration

![](../Images/6e90550dd0bd530f19ddd6d5b2544978.png)

  

在password expiry policy那里选择Prompt users with expired passwords to enter a new one，允许用户使用过期密码登录并修改一个新密码

![](../Images/987d86e54c5660aaa710be3e46f13bdb.png)

等待webmin重启，配置生效。查看docker容器里的/etc/webmin/miniserv.con，可以发现passwd\_mode的值已经从0变为了2

![](../Images/248ad22e205e640723edbf751587b480.png)

查看/usr/share/webmin/password\_change.cgi，可以发现红框部分会对miniserv.conf中的password\_mode值判断，为2时才enable

![](../Images/d53551bfb88de08677b8fbe44d66a692.png)
