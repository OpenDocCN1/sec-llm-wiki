生成社工属性的弱口令


宗旨是生成能满足密码复杂度要求又好记的密码。


1、获取账号


获取用户账号的方式：

a.中国常用名 Top500，常见组合：

       拼音的全拼+[数字]

       姓全拼+名的首字母+[数字]

b.招聘网站

c.社交工具（脉脉）

d.Google hacking

e.工号


2、密码分片


用户个人信息相关

a.姓名、昵称、ID、QQ

b.生日，男/女友生日，特殊纪念日

c.手机号，男/女友手机号

d.父母亲人相关信息

e.公司相关信息（域名、邮箱、公司电话、部门等）


习惯习性

a.键盘分布，SHIFT+键盘布局

b.特殊节日、纪念日、年份

c.好记的数字组合、字母组合

d.好记的特殊字符组合

e.特殊含义的单词

f.特殊含义的字母数字替换（我-5，是-4，o-0）


3、组合方式


由被检查方提供一份经常使用的默认密码清单最好，下面是其他的一些组合方式：

a.有社工密码可以根据之前的密码使用历史记录针对性的生成组合。

b.部门的密码使用习惯，趋于一致。

c.有含义字符@有含义数字，如姓名全拼@2017。

04
爆破工具

1、 Burp Intruder


这个工具不多做说明，现在渗透测试可能经常遇到一些客户端 js 文件对密码做加密处理发送给服务端的情况，推荐扩展https://github.com/c0ny1/jsEncrypter


使用示例

步骤：

尝试登录，使用浏览器调试模式寻找加密函数所在的 js 文件，通常在调试模式下选取登录元素，搜索使用的函数信息；

通过检查推导调用关系找到最终使用的加密 js 文件；

将加密 js 文件下载到本地；

利用 jsEncrypter 的 js 模板加载使用的加密函数；

使用 phantomjs 加载 jsEncrypter 的 js 模板；

使用 Burp 的 jsEncrypter 扩展连接 phantomjs 开启的服务；

测试加密效果；

使用 Burp Intruder 的 payload 处理功能，加载 jsEncrypter 对明文密码处理后执行爆破。

var fs = require('fs');
var logfile = 'jsEncrypter.log';
var webserver = require('webserver');
server = webserver.create();

var host = '127.0.0.1';
var port = '1664';

// 加载实现加密算法的js脚本
var wasSuccessful = phantom.injectJs('md5.js');/*引入实现加密的js文件*/

// 处理函数
function js_encrypt(payload){
    var newpayload;
    /**********在这里编写调用加密函数进行加密的代码************/
    var newpayload = hex_md5(payload)+"djmis";


    /**********************************************************/
    return newpayload;
}

if(wasSuccessful){
    console.log("[*] load js successful");
    console.log("[!] ^_^");
    console.log("[*] jsEncrypterJS start!");
    console.log("[+] address: http://"+host+":"+port);
}else{
    console.log('[*] load js fail!');
}

var service = server.listen(host+':'+port,function(request, response){
    try{
        if(request.method == 'POST'){
            var payload = request.post['payload'];
            var encrypt_payload = js_encrypt(payload); 
            var log = payload + ':' + encrypt_payload;
            console.log('[+] ' + log);
            fs.write(logfile,log + '\n', 'w+');
            response.statusCode = 200;
            response.write(encrypt_payload.toString());
            response.close();
        }else{
              response.statusCode = 200;
              response.write("^_^\n\rhello jsEncrypter!");
              response.close();
        }
    }catch(e){
        //console.log('[Error]'+e.message+' happen '+e.line+'line');
        console.log('\n-----------------Error Info--------------------')
        var fullMessage = "Message: "+e.toString() + ':'+ e.line;
        for (var p in e) {
            fullMessage += "\n" + p.toUpperCase() + ": " + e[p];
        } 
        console.log(fullMessage);
        console.log('---------------------------------------------')
        console.log('[*] phantomJS exit!')
        phantom.exit();
    }   
});
