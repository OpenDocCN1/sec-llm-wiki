上周，江海客牛谈到“战略冲突的首要规则是：进攻方总会取得胜利。赢得战略冲突的最好方法是采用攻势，例如外国情报机构提供假消息而不是阻止它获得消息，最终将削弱对手对其情报机构的信任——Robert M.Clark《intelligence Analysis》”

于是引起了一番有关情报的书籍的讨论。趁着周末把大牛们的推荐整理一下。


Robert M.Clark的Intelligence Analysis: A Target-Centric Approach《情报分析:以目标为中心的方法》就是刚刚开始说的。


Psychology of Intelligence Analsis

情报分析心理学

Forrester（独立技术和市场调研公司）专门研究情报市场的分析师Rick Holland推荐过这本《情报分析心理学》。他说如今的威胁情报用在网络对抗上，其实还属于很新的东西。就情报而言可以从“传统经典”中获取一些灵感。例如CIA的这本《Psychology of Intelligence Analysis》。这本书的英文版可以从CIA的官方网站下载，更好的是今年中文版也被翻译出版了。


Structured Analytic Techniques for Intelligence Analysis

写这本情报心理学的CIA老专家Richards J. Heuer, Jr.还出了另外一本《Structured Analytic Techniques for Intelligence Analysis》

Intelligence.Analysis.How.to.Think.in.Complex.Environments

国内也有前辈两年前就提到过这本《情报分析：如何在复杂环境下思考》，里面谈及到一些美军的情报分析理论，归纳出了十多种情报分析的手段和工具，例如“相关性分析”，“风格分析”、“文化分析”、“群聚分析”

  • Decomposition

  • Critical Thinking

  • Link Analysis

  • Pattern Analysis

  • Trend Analysis

  • Anticipatory Analysis

  • Technical Analysis

  • Tendency Analysis

  • Anomaly Analysis

  • Cultural Analysis

  • Semiotics Analysis

  • Aggregation Analysis

  • Recomposition

之前曾经拜读过一部分，书名中所说的“复杂环境”大致是指美军面临的是恐怖分子，现在往往已混杂成为正常社会中的一份子，不像传统战争那么敌我分明。因此归纳出以上的分析方法进行甄别，里面讲述的情报分析很重要一点思想是“假设”、“预测”。情报分析不可能一切条件都满足了才推导出结果。有时候需要大胆的假设，if xxx then xxx, else xxx
