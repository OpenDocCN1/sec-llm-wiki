# 阿里ASRC广州站雷峰安全沙龙八卦

继3.14 TSRC在广州举行下线沙龙，今天阿里ASRC在广州中轴线上的地标中信广场举办了第十五期的雷峰互联网安全沙龙。约80人的现场一下子就坐满了，还要加座。到场的除了一众白帽子，还有绿盟，蓝盾，腾讯，太平洋网，多玩等等众多本地的安全大牛，当然还有我厂。

**开场白的八卦**

这次沙龙感觉气氛特别好，因为沙龙活动从主持人XXX的一个问题——”谁可以列举出安全圈子里的美女“而一下子骚动起来了，于是乌云的肉肉，安全宝的”晶晶妹“立刻躺着中枪，哦，应该是金榜题名。除此之外，由主持人的互动问题下，论尽了安全圈内的”八卦“，从\*SRC，到阿里云的抗DDoS功绩，从圈内的安全团队，到国内外的CTF比赛，安全大会，一下子把现场气氛热起来了。

![](../Images/d72eac7e9fbd2df9b654c9f880708d6c.png)  
**名字由来的八卦**

一直以为是因为阿里在杭州，杭州有个雷峰塔，所以他们搞的沙龙叫”雷峰互联网安全沙龙“，今天才知道原来还有三层意思。一则雷峰塔之镇妖，镇住各种安全危险之意，二则是如雷锋一般好好学习，天天向上，交流提高，三则原来还有雷风恒卦之卦象，寓意恒心有成。着实是涨姿势了。  

**议题的八卦**

当然除了八卦，议题也很精彩ASRC榜首白帽子发哥的《配电网工控系统引发的血案》通过对网络拓扑的分析，识别出配电房为弱入口点，进而各种ARP，接入内网，扫描，0Day，直至直捣SCADA中控系统。还有网络尖刀羊小弟的《XSS漏洞挖掘二三事儿》。不过既是八卦不得不说阿里移动安全专家灵胎讲的《Android平台漏洞挖掘方法与技术》，从医学到化学，连同位素都搬出来了，着实是生动的阐述了“污点分析”大法(taint analysis)在挖掘移动应用漏洞上的奇效。
