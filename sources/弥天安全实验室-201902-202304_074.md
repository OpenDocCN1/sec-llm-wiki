**0x01背景介绍**  
  
Fastjson 是Alibaba的开源JSON解析库，它可以解析 JSON 格式的字符串，支持将 Java Bean 序列化为 JSON 字符串，也可以从 JSON 字符串反序列化到 JavaBean。相信利用过Fastjson漏洞的XDM都知道，该漏洞利用需要编写Java利用代码，然后在编译为class文件，在通过rmi/ladp等远程加载实现漏洞利用。  

  

![](../Images/575ac9d761eb37419f5df1db9acfc0d2.png)  
**0x02具体操作**  
  
1.通过使用Vulfocus docker环境部署该漏洞![](../Images/82c70349a16ab2661bd9abfb1a87a142.png) 2.对响应数据做简单分析判断为json格式，然后使用yakit工具插件进行漏洞识别![](../Images/8d0dd2a215912b99657d9991316b904d.png)漏洞识别![](../Images/0e3a39e78ba43738463f2883385632ff.png)3.通过dnslog判断是否可以正常解析![](../Images/153782c6575dc6f1379ed21457edb2af.png)4.漏洞存在，然后进行巧妙的利用，下载jndi\_tool工具

`https://github.com/wyzxxz/jndi_tool`
