**0x00漏洞简述**  
  

2017年9月5日，Apache Struts发布最新的安全公告，Apache Struts 2.5.x的REST插件存在远程代码执行的高危漏洞，漏洞编号为CVE-2017-9805（S2-052）。漏洞的成因是由于使用XStreamHandler反序列化XStream实例的时候没有任何类型过滤导致**远程代码执行**。

  

![](../Images/58443654ccfe66f43ec31cdc36803ec9.png)  
**0x01影响版本**  

Apache Struts 2.5 – Struts2.5.12

Apache Struts 2.1.2– Struts 2.3.33

  

![](../Images/58443654ccfe66f43ec31cdc36803ec9.png)
