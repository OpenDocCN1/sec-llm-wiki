**Solr**是一个独立的企业级搜索应用服务器，它对外提供类似于Web-service的API接口。用户可以通过http请求，向搜索引擎服务器提交一定格式的XML文件，生成索引；也可以通过Http Get操作提出查找请求，并得到XML格式的返回结果。

**启动vulhub环境：**

cd /vulhub/solr/CVE-2019-0193-RCE

docker-compose build

docker-compose up -d

创建一个名为test的Core：

docker-compose exec solr bash bin/solr create\_core -ctest -d example/example-DIH/solr/db
