环境安装

     nmap

yum install –ynmap

(下载)

nmap –v –A

(查看)


     xsltproc

yum install –y xsltproc

(下载)

xsltproc –V

(查看)



Nmap扫描测试输出test.xml报告

nmap192.168.43.0/24 -oX test.xml

(简单测试C段扫描部分扫描结果)

使用xsltproc把nmap的xml文本可视化，输出为htm

xsltproc -otest.htm test.xml
