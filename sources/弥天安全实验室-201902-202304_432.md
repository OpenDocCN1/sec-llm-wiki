# **环境安装**

     nmap

yum install –ynmap

(下载)

nmap –v –A

(查看)

![](../Images/b9c234915d2c205cc101406842f8fb71.png)  

     xsltproc

yum install –y xsltproc

(下载)

xsltproc –V

(查看)

![](../Images/5c973e239f69bfd57b49ce2e6fb5e267.png)
