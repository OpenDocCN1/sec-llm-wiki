# 第四届“强网杯”线下赛攻防混战结束，巅峰对决即将上演！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MjY3NDQ2Ng==&mid=2247484687&idx=1&sn=3e39dacfc130c537ea4cb49bc6e5b6ff&chksm=cf525b42f825d2542a5a8c704f22505ef813afc3bdcc008a7559b9f77b801999c38d17b2e9e3&scene=126&sessionid=1681670618#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MjY3NDQ2Ng==&mid=2247484687&idx=1&sn=3e39dacfc130c537ea4cb49bc6e5b6ff&chksm=cf525b42f825d2542a5a8c704f22505ef813afc3bdcc008a7559b9f77b801999c38d17b2e9e3&scene=126&sessionid=1681670618#rd)

9月16日，由**中央网信办、河南省人民政府**共同指导的第四届“强网杯”全国网络安全挑战赛在网络安全科技馆重磅启动。作为**2020年国家网络安全宣传周的重要活动**，大赛充分践行“网络安全为人民，网络安全靠人民”精神，多通道开展全网直播，向更多的人普及网络安全竞赛知识，全民大众一起共享国家级高水平网络安全竞赛盛宴。

  

今天是比赛的第二天，号角阵阵，誓言铮铮，32支战队已经在“强网杯”攻防混战的战场上酣战32小时。关于比赛的赛制和赛况，大赛组委会做了相应整理，希望可以让大家更加全面**了解网络安全竞赛知识，熟悉国际通用竞赛模式，充分感受守护者守护网络空间安全的风采和信念**。

  

![](../Images/ab74b45915836f28c7b6a3ede75d1c57.png)

  

**立足实战，极致创新**

  

本届“强网杯”线下赛创造性的混合了**三种竞赛机制**，分为两个阶段，32支精英战队需要先在16日-17日举办的攻防混战阶段，通过同时进行的git based AD和RealWorld(Escape)两种赛制模式进行比拼，由此遴选出的3支最强队伍将进入最终的SpeedRace巅峰对决阶段，开启“巅峰竞速”模式，争夺强网桂冠。

  

**git based AD**赛制是在原AWD模式下引入git模式维护题目patch，采用非零和计分方式。比赛设置5分钟为1轮，每轮选手可以通过攻击目标服务获得攻击分。赛题内容主要包括Linux与Windows平台应用层安全分析、操作系统安全分析、Web应用安全分析等，充分考察选手在攻防实战中对于各种网络安全技能的掌握能力和综合运用能力。值得关注的是，**git based AD赛制属于国内首发，充分彰显国家级网络安全竞赛高度**。

  

**RealWorld(Escape)**赛制为RealWorld竞赛模式，采用Jeopardy模式的动态积分制，同一题目分数随得分队伍增加而递减。选手可以通过平台在线排队上台演示，对真实软件漏洞进行现场破解。每次演示选手有3分钟网络连接时间和7分钟攻击测试时间。在规定时间内展示完成要求的攻击效果，即表示攻击成功，可获得RealWorld得分。赛题涵盖区块链、虚拟机、浏览器、CMS、思科路由器、Adobe PDF reader等诸多新兴技术领域和前沿安全热点，**极度贴近现实网络攻防思维**。让选手在极具实战化的比拼中，**深入了解新技术应用场景和新技术潜在安全风险，提高安全保障能力**。

  

**强强对决，招招制敌**

  

作为**中央网信办指导的国家级高水平网络安全竞赛**，第四届“强网杯”全国网络安全挑战赛的线下对决可谓是剑拔弩张，悬念迭起。

  

![](../Images/1131932564396120e23ba83f2149cc2d.png)

16日上午9点，32强战队迅速步入战场，开局不到10分钟，**Vider-Team**战队率先拿下tmnt题目一血，现场气氛成功点燃。11点06分，伴随着“花话费发废话的刘娘牛郎战队将挑战IEU”的广播声音在炫酷宏大的比赛现场响起，**花话费发废话的刘娘牛郎**战队的2个选手带着电脑走到现场破解演示区，“一顿操作猛如虎”后，“强网杯”线下赛首个RealWorld题目成功被破解。这也成功激发了其他战队的好胜心，**比赛首日共14个战队对11道RealWorld发起40余次挑战**，8个战队成功破解并得分。其中**Nu1L**战队做出2道RealWorld题目，分数暂居第一；**HAC**战队连续3次挑战IEU题目，终于在第3次挑战成功，**展现出对挑战RealWorld题目的热衷与认可**。

  

经过一天的激战，**比赛首日共有 3 个一血产生，Nu1L 和Whitzard战队分别以8021.95 分和5016.38分占据积分榜第一、二名**。作为上届“强网杯”的冠军队伍，**eee**战队的名次也一直备受大家关注。奇怪的是，直至16日首日比赛结束依然没有选择挑战RealWorld题，但因其AD赛的攻击防御得分均位居第一，所以总体排名高居第三。也许eee战队在“憋大招”。

  

果不其然，比赛第二天，**eee**战队在开赛一小时后率先拿下一道RealWorld题目一血，直冲积分榜第一名，**在接下来的5个小时内，又相继5次成功挑战RealWorld题，拿下9681.35的高分**。**0x300R**战队也毫不示弱，势如破竹，连续在RealWorld挑战中得分。高手对决，往往一念之间，第一名就有可能易主。下午14点40分，随着2个AD题目的下线，各大战队获取分数的途径减少，比赛进入白热化。

  

  

![](../Images/259b794b2bfd91002feda7a4f9004119.png)![](../Images/ef8958352e4a8dea169fc9323e16de09.png)

  

比赛现场，有一个很有意思的看点：在RealWorld比赛中，如果战队挑战成功不仅会获得相应积分，还会**额外收获一支象征胜利的小旗子**，意味着夺旗成功，**与“CTF夺旗”竞赛模式相呼应**，让比赛更具仪式感，更有互动性。随着太极八卦阵内的旗子变少，也就意味着有更多的战队挑战RealWorld题目成功，战队间的争夺也更加激烈。

  

![](../Images/e98cd0eef37ad8f5cc2595a381626c6d.png)

  

**黑灯时间，更具挑战**

  

距离当天比赛结束倒计时1小时，比赛的积分榜大屏突然封榜，选手无法访问本队得分和排名以及题目、单项得分等信息，同时比赛停止接受 RW 题解展示的排队申请。不要慌，这不是系统故障，而是竞赛组委会专门安排的“**黑灯时间**”，希望可以**让参赛选手将精力专注于比赛本身，激发高歌猛进、绝地反击的斗志**，以增加比赛的不确定性和激烈性。

  

截止今天17：00，持续了两天的攻防混战阶段正式结束，最终**eee战队**凭借强大安全战斗力锁定胜局，成为“攻防混战”阶段的第一名，将于明日与**0x300R战队和0ops战队**进入最终的巅峰对决阶段，开启“巅峰竞速”模式。三强鼎立，王者之争，谁将摘得强网桂冠，让我们瞩目以待！
