# 第四届“强网杯”创新作品赛获奖名单公布及路演参赛通知

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MjY3NDQ2Ng==&mid=2247484685&idx=2&sn=6bc49fddef1eb69fbaefd3cf26ee342a&chksm=cf525b40f825d256c155f6254f7685e1b847a3a611cbd2c0969c9c758c6ecfa4d657a955c33e&scene=126&sessionid=1681670618#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MjY3NDQ2Ng==&mid=2247484685&idx=2&sn=6bc49fddef1eb69fbaefd3cf26ee342a&chksm=cf525b40f825d256c155f6254f7685e1b847a3a611cbd2c0969c9c758c6ecfa4d657a955c33e&scene=126&sessionid=1681670618#rd)

2020年国家网络安全宣传周在郑州举办之际，根据第四届“强网杯”全国网络安全挑战赛总体安排，创新作品赛线下路演将于9月19日在国内首个网络安全科技馆举办。

  

线下路演为创新作品赛的最终评选环节，共有12个“最具商业价值潜力”候选作品的参赛团队到场展示，与投资人、行业大咖等评审对话，最终有机会获得专业评委、投资人进一步考察接洽，乃至价值投资的机会。本次大赛将进行全程直播，为普及前沿安全技术、曝光优秀作品和优秀人才，提升大赛影响力，吸引更多创投企业关注。

  

经过评审专家组严格按照评审细则多轮打分、层层选拔，本届创新作品赛的最终获奖名单和晋级线下路演争夺“最具商业价值潜力”候选作品名单如下：

  

![](../Images/a3dd4fde7ff983bd21c7c917bf36c0cd.png)

  

**路演主题**

安全感，中国梦——网络安全创新作品最具商业价值评选

  

**路演地址**

网络安全科技馆一层网络剧场

  

**路演时间**

9月19日 8:30-12:00

  

**路演准备**

12支入围赛队针对自己的作品，准备1分钟的作品视频和6分钟的路演PPT，允许各赛队将产品设备或者设计原型带到现场结合路演PPT进行讲解。

  

**路演流程**

*   9月18日下午5：00，各赛队需要提前到场地彩排，并抽签决定正式路演出场顺序。
    
*   路演现场将全程直播。路演共分为两个评比阶段，第一阶段为作品介绍和展示环节，时长6分钟；第二阶段为即兴答辩和投资意询环节，时长为3分钟。
    
*   路演结束后，将举行本届创新作品赛颁奖典礼。
    

  

**第一阶段——作品介绍及展示**  

每个赛队派出一名成员作为主讲人，首先播出本队的1分钟作品视频，然后开始进入6分钟的PPT陈述展示。陈述内容应包括产品/服务介绍、市场分析及定位、商业模式、团队介绍等，可配合设备产品进行展示。评委根据赛队的表现进行举牌打分，随后现场大众评审开始打分。两项总分超过60分的赛队可进入第二阶段路演。未达到60分的赛队将无缘第二轮赛程，回到观赛席观赛。

  

**第二阶段——即兴答辩及投资意询**  

本阶段时长为3分钟，参赛团队成员须全部上台，与评审专家进行面对面答辩。此时选手可以对自己的项目进行补充陈述，侧重介绍该项目的商业模式，以打动现场的评审投资人。评审也将对选手进行更深入的提问和交流。答辩结束后，现场评委如对赛队的作品项目产生投资合作意向时，参赛团队将与产生合作意向的投资人进行双向选择，如果双向选择成功，赛队将获得企业给予的投资、投产机会、相关政策支持、发放推荐信等多种形式的合作支持。如答辩结束后无投资意向出现，则比赛结束，选手返回观赛席位。

  

**颁奖典礼**

由路演现场结果前3名将产生“最具商业价值潜力”奖项冠、亚、季奖。成功达成合作意向的双方将上台举行签约仪式。

比赛过程中，评委可向心仪的赛队发放推荐信或发出邀约函，或获得高新区产投集团及评委进一步接洽或考察的机会。

颁奖典礼将为12支受邀参与路演的团队进行现场一、二、三等奖颁奖。其余12支获奖赛队所获奖项统一公示。

  

**评委构成**

评委团将由专家评审3人、企业投资人评委6人和大众评审55人，共64人共同组成。

专业评审将由全国知名网安方面的专家、国家网安专业院校教授组成。网安企业评委由国内网络安全企业派出的高级代表和投资人组成。55名大众评委为具备一定网络安全技能的从业者和爱好者组成。

  

**计分规则**

*   路演现场每个评委举牌记为5分，大众评审每人可投1分，总计满分为100分。
    
*   第一阶段赛队必须获得60分，方可进入第二阶段路演。如赛队第一阶段未能获得60分，将不能进入第二阶段路演，即失去与投资人牵手的机会。
    
*   全场分数前三的赛队将颁发“最具商业价值潜力”奖项证书。
    

  

**参赛须知**

*   路演团队需要在9月18日前抵达郑州，住宿点组委会统一安排，地点另行通知。
    
*   在获得路演资格后，各参赛队伍可以继续对参赛作品及路演材料进行完善和修改。
    
*   晋级路演的参赛团队成员须和参赛报名表成员一致，人数不得调整和更换。到现场的人数每队不少于2人。
    
*    路演签到时，所有队员须出具身份证原件，如未通过身份核验则视为放弃参赛资格和获奖资格。
    
*   参赛队伍自行携带作品、文档及设备，到路演地点进行演示。如对作品的演示环境有特殊要求，请提前与组委会协商。
    
*   参赛选手上台须着正装，或与自身项目相关的统一着装。
    
*   未到现场报到的团队将取消获奖资格，视为放弃大赛奖项。
    
*   其余获本届大赛三等奖的选手，组委会会后会邮寄奖状等奖项，不参加现场颁奖。
    
*   参加路演产生的所有费用（包括差旅费、住宿费、餐饮费等）由各团队自行承担。
    
*   各参赛战队应提前了解出发地防疫政策并提前做好相关准备，如因个人原因导致的隔离或核酸检测等相关费用应由个人承担。
