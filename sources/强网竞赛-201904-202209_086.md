# 第四届“强网杯” 全国网络安全挑战赛——青少年专项赛正式启动报名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MjY3NDQ2Ng==&mid=2247484671&idx=1&sn=03f5f53fff1c474cc9c7bb8f28c0b55e&chksm=cf525ab2f825d3a4ce6888da19a40d228db86687baa230a716dda4d683f62377001232335c3a&scene=126&sessionid=1681670623#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MjY3NDQ2Ng==&mid=2247484671&idx=1&sn=03f5f53fff1c474cc9c7bb8f28c0b55e&chksm=cf525ab2f825d3a4ce6888da19a40d228db86687baa230a716dda4d683f62377001232335c3a&scene=126&sessionid=1681670623#rd)

8月25日，第四届“强网杯”全国网络安全挑战赛——青少年专项赛正式启动报名。本次比赛旨在通过寓教于乐的竞赛形式，面向青少年普及网络安全知识，激发兴趣爱好，搭建展示平台，发掘、吸引更多青少年网安英才投身网络强国建设事业。

  

本次青少年专项赛将分线上赛和线下赛两个阶段，**线上赛包括科普赛、选拔赛；线下赛包括实践赛、创新赛、争霸赛**，组委会将根据“实践赛”和“创新赛”综合成绩，选出6支队伍晋级“争霸赛”，全面考察参赛选手网络攻防能力。

  

![](../Images/0648990c9fb0afff288bef6a7989f8a4.png)

  

**培育创新力量，发掘青少年网安英才**

  

近年来，云端、物联网、人工智能等新技术飞速发展，但随之而来的网络犯罪也日趋精密、复杂，以商业机密和个人信息为目标的网络攻击不断增多，对数字化虚拟世界与现实生活造成了日益严重的威胁。在可预见的未来，网络犯罪行为仍会随着科技的发展而不断精进。在此背景下，**加强网络安全后备人才的培养、提升创新潜能，将成为推动网络安全产业发展、应对未来安全威胁的重要举措。**

  

本次青少年专项赛不仅对网络安全知识进行考察，还将深入考察网络安全攻防实践能力，从而遴选出网络安全优秀人才；不仅为获胜者提供物质激励，还会为这些网络安全的“后起之秀”提供专业的网络安全技术指导以及精神奖励，帮助青少年网络安全英才尽快成长，探索建立有效的青少年网络安全人才协同培育新机制。

  

**寓教于乐，全面提升青少年的网络安全认知**

  

面向青少年群体，专项赛不仅体现了网络安全的专业性，还具备丰富的趣味性。进入线下赛的各支队伍将沉浸式进入网络空间科技馆内多个网络安全特色展区，参与包括密码破解、量子信息、数据隐写、脑力对抗等相关挑战项目。充满创意与互动性的项目将激发参赛青少年选手投身网络安全创新的兴趣，展现充满魅力的网络安全世界。

  

![](../Images/4d1f8942e0ca4734f7ff79997f69afe0.png)

  

作为**2020年国家网络安全宣传周**的重要活动之一，第四届“强网杯”全国网络安全挑战赛——青少年专项赛除了强化人才的培养之外，还设置了无门槛的网络安全知识科普环节，以线上答题的方式普及网络安全知识。这不仅有助于促进青少年网络安全知识技能教育推广普及，强化青少年对于网络安全的认知，还有助于激励引导青少年安全使用网络、防范网络安全隐患，提升网络安全能力水平。

  

  

  

目前，竞赛官方网站已经正式开放报名通道，所有拥有中国国籍(不含港澳台地区)、10-18周岁（**出生日期为2002年1月1日至2010年12月31日之间**）的青少年均可登录以下链接报名参赛：https://www.ichunqiu.com/2020qwb/qwtac 。同时，为帮助参赛选手积极备战，大赛组委会专门准备了赛前学习攻略，学习地址：http://www.youthsec.com.cn ，希望可以帮助各位参赛选手保持训练常态，以最好的状态迎接即将到来的考验。
