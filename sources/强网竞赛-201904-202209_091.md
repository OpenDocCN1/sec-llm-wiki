# 全国网安精英正式集结完毕，第四届“强网杯”即将拉开战幕！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MjY3NDQ2Ng==&mid=2247484668&idx=1&sn=73f2211a4481beef1bc918a90db9c5a8&chksm=cf525ab1f825d3a7e1a6a42687b10de8e594fcbb15ee63565468b40ada1bc5f6d3a2feb5b490&scene=126&sessionid=1681670628#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MjY3NDQ2Ng==&mid=2247484668&idx=1&sn=73f2211a4481beef1bc918a90db9c5a8&chksm=cf525ab1f825d3a7e1a6a42687b10de8e594fcbb15ee63565468b40ada1bc5f6d3a2feb5b490&scene=126&sessionid=1681670628#rd)

8月21日，由**中央网信办、河南省人民政府联合指导**的第四届“强网杯”全国网络安全挑战赛报名结束，来自全国各行业、各省市、各领域的网络安全精英正式集结完毕，一场高质量国家级网络安全赛事即将拉开战幕。

  

![](../Images/9621f73709052ff15a982a17f75368cc.png)

  

第四届“强网杯”全国网络安全挑战赛旨在**深入贯彻习近平总书记关于网络强国的重要思想**，致力于推动网络安全竞赛高质量发展，打造人才聚集和创新交流平台，**形成网络安全人才、技术、产业融合发展的良性生态**。

  

大赛自报名启动以来，一直备受社会各界瞩目。截止8月21日报名结束，第四届“强网杯”共吸引了来自全国31个省级行政区（港澳台除外）的3121支战队，报名参赛人数高达20061人，**赛事规模创历史新高**。

  

从报名情况来看，大赛聚集了**来自国家关键信息基础设施单位、重要行业部门、科研机构、网络安全企业、互联网企业以及社会力量**等全国各行业网络安全从业者、爱好者，汇聚了AAA 、eee、Nu1L等国内外知名网安战队。与此同时，大赛不乏众多**高校战队**报名参赛，作为祖国未来网络强国建设的主力军，他们将在“强网杯”的演练场上提升安全技能，在此消彼长的攻防实战中完成理论到实践的贯通转化，为“强网杯”大赛注入青春力量。

  

值得关注的是，本届大赛还吸引了众多**聚焦“新基建”，从事人工智能、大数据、区块链等新技术领域**企业的网络安全运营者主动参与，强化在推进新技术、新应用场景的同时，建立与业务水平相匹配的网络安全意识和安全防御能力。

  

![](../Images/f1426f7c9533a57322d53abb8519a463.png)

  

群贤毕至，少长咸集,各行各业的网络安全人才齐聚一堂，切磋技术、磨砺技能，践行“**网络安全为人民，网络安全靠人民**”的初衷，充分说明了网络安全竞赛正在成为培养、检验网络安全人才实战能力的重要途径。而“强网杯”作为国家级网络安全赛事，正在形成巨大的示范效应，**促进人才培养、技术创新、产业发展的良性生态建设，引领网络安全竞赛进入高质量发展新阶段**。

  

![](../Images/536ae3939dcdf84bcb42e8655401204c.png)

  

逐鹿强网，酣战在即！第四届“强网杯”全国网络安全挑战赛线上赛将于**8月22日-23日**正式开赛，3121支战队将争夺仅有的**32个**晋级席位，比拼的激烈程度可想而知。大赛组委会将时刻保持严谨、规范、认真细致的工作态度，全方位保障大赛顺利运转。同时，也在此预祝所有的参赛选手在接下来的比赛中取得优异成绩！
