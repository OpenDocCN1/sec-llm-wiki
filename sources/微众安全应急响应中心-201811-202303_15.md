**社招职位**

  

**01.**

安全攻防策略工程师

**岗位职责：**

1.  负责公司内部安全能力的对抗验证，持续评估与反馈安全能力。
    
2.  研究APT攻防技术，以专业黑客的视角，通过渗透等手段不断挖掘安全风险，并以技术驱动、沉淀攻防策略体系。
    
3.  对安全事件进行应急响应，及时解决出现的安全问题。
    
4.  参与公司各项安全规范和流程的建立与完善。
    
5.  持续追踪和运营相关领域情报收集、分析、挖掘，进行风险溯源。
    
6.  关注最新的安全动态和漏洞信息，及时修复公司相关系统的漏洞。
    

**岗位要求：**  

1.  本科及以上学历，对安全攻防有深入理解。
    
2.  在渗透测试、入侵检测、安全漏洞、应急响应等领域有一个或者多个方向有比较突出的经验和能力。
    
3.  熟悉shell/Perl/Python/Lua等至少一种脚本语言，能够独立开发安全测试工具。
    
4.  有强烈的责任心和学习意愿，良好的沟通交流、团队合作、抗压能力。
    
5.  了解网络安全行业相关动向，具备外部风险情报收集、分析、挖掘能力。
    
6.  无黑产经历，严守法律法规；大型互联网公司安全团队工作经验优先。
    

**岗位亮点：**

1.  参与大型互联网金融实战对抗，接触最新攻击手法，在对抗过程中学习成长。
    
2.  参与建设大型攻防演练平台，持续积累安全攻防策略的相关知识，成为该新型领域的优秀人才。
    

**02.**

基础安全系统开发工程师

**岗位职责：**

1.  参与各类安全产品的开发、架构优化工作。
    
2.  能独立负责相关软件模块需求设计、编码及测试工作。
    

**岗位要求：**  

1.  计算机专业或相关专业大学本科以上学历，有扎实的计算机学科基础，熟悉常见的数据结构和算法，2年以上工作经验。
    
2.  熟练掌握c++、go、python、java至少一门语言开发，有过相关安全项目的经验。
    
3.  理解Linux内核相关原理及Linux系统相关知识。
    
4.  有Spark、Flink相关开发经验的优先。
    
5.  良好的沟通技能，团队合作能力。
    

**岗位亮点：**

1.  能够接触到互联网银行的架构，了解到安全在互联网银行落地的最佳实践。
    
2.  可以快速学习和了解到最新的安全技术、方案。
    
3.  团队稳定，技术氛围好，给个人足够的成长空间。
    

**03.**

网络安全攻防工程师

**岗位职责：**

1.  负责红蓝对抗攻防演练，持续评估公司安全对抗能力反馈安全水位。
    
2.  研究前沿的安全技术、漏洞、情报和攻击手法。
    
3.  建设网络安全蓝军平台，提升自动化对抗能力。
    

**岗位要求：**  

1.  熟练掌握主流网络、应用、系统攻击技术及常用工具，熟悉常见安全漏洞原理及利用。
    
2.  跟踪前沿安全攻防技术，有漏洞挖掘/分析/复现能力。
    
3.  良好的沟通能力和团队协作精神。
    
4.  有较多APT实战成功经验者优先。
    
5.  有大型互联网实战对抗经验者优先。
    

**岗位亮点：  
**

参与大型互联网金融实战对抗，更全局地看待安全对抗。

  

工作地点：深圳

**校招职位**

  

**01.**

信息安全工程师-Go开发方向

**岗位职责：**

1.  参与WeBank安全系统开发建设；
    
2.  参与安全相关平台建设。
    

**岗位要求：**  

1.  计算机软件相关专业本科及以上学历；
    
2.  热爱信息安全技术；
    
3.  有一定的后台开发、网络编程等相关基础；
    
4.  至少熟练掌握一门编程语言，Python、JavaScript、Java、C、Go等不限。
    

**02.**

信息安全工程师-安全攻防方向

**岗位职责：**

1.  参与公司内部红蓝对抗、以及常规蓝军、业务蓝军项目；
    
2.  对Web/APP/IoT/Binary等进行风险评估；
    
3.  建设攻击知识库、工具库和自动化测试用例平台。
    

**岗位要求：**

1.  计算机软件相关专业本科及以上学历；
    
2.  热爱信息安全技术；
    
3.  精通主流的渗透测试方法论，工具和实践细节；
    
4.  有一定的漏洞挖掘能力，熟悉业界安全实践对各类风险的一般防御机制；
    
5.  至少熟练掌握一门编程语言，Python、JavaScript、Java、C、Go等不限。
    

**03.**

信息安全工程师-反欺诈方向

**岗位职责：**

1.  研究各个业务场景下的欺诈、盗号、技术攻击等恶意行为的数据特征，建立模型发现恶意行为；
    
2.  建设完整的安全运营数据指标体系，完善用户安全画像；
    
3.  业务安全评估，提供业务安全决策建议及依据；
    
4.  研究前沿数据挖掘、人工智能技术和黑产新动向，制定更加快准稳的安全解决方案。
    

**岗位要求：**

1.  信息与计算科学、数学与应用数学等专业本科及以上学历；
    
2.  了解数据挖掘项目过程，对常用数据挖掘算法有较深入理解，有相关应用经验者优先；
    
3.  了解大数据技术，熟练使用sql，掌握至少一种数据分析/挖掘工具，如Python、R、Shell、Scala、SAS等，了解Linux常见命令；
    
4.  较强的学习能力，优秀的逻辑思维和创新能力，积极主动，对数据敏感，热爱数据分析。
    

  

工作地点：深圳&武汉
