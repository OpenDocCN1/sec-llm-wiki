# Gartner发布2019《全球威胁情报市场指南》，微步在线再次成为唯一入选中国厂商

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NjA0NjI5MQ==&mid=2650165228&idx=1&sn=474900abf006832532007c4625e9a878&chksm=f448b450c33f3d46d70623d8eb828a47a725646d03776a298d8871a0efbb7e6f30b1a685a6f4&scene=126&sessionid=1681279203#rd](http://mp.weixin.qq.com/s?__biz=MzI5NjA0NjI5MQ==&mid=2650165228&idx=1&sn=474900abf006832532007c4625e9a878&chksm=f448b450c33f3d46d70623d8eb828a47a725646d03776a298d8871a0efbb7e6f30b1a685a6f4&scene=126&sessionid=1681279203#rd)

全球权威信息化咨询研究机构Gartner于2019年2月19日发布《全球安全威胁情报产品及服务市场指南》(Market Guide for Security Threat Intelligence Products and Services)，**微步在线（ThreatBook）再次****作为唯一中国厂商****，****入选****Gartner市场指南推荐供应商**。Gartner在报告中多次推荐微步在线作为全球代表性威胁情报厂商。

  

Gartner市场指南一直是企业采购的重要参考和依据。早在2017年微步在线就曾作为唯一的中国厂商第一次出现在了威胁情报市场指南中，代表着中国安全企业的威胁情报能力受到了国际市场的高度认可。

  

在最新发布的市场指南中，**Gartner特别筛选了“高可信”("credible vendors")的威胁情报厂商**，因此推荐的供应商数量有所减少，并按照商业化威胁情报服务、免费威胁情报资源、威胁情报平台等进行了分类。**微步在线被列入商业化威胁情报服务推荐名单，成为中国****乃至亚太地区****唯一入围供应商，与FireEye、Google(VirusTotal)、CrowdStrike等二十多家顶级的国际厂商同台**。

  

此外，在典型的威胁情报用户使用场景中，**Gartner也再次推荐微步在线作为代表厂商，建议用户应用威胁情报来增强现有安全设备的能力**，包括SIEM、防火墙、IDS/IPS、EDR、SWG等。这与国内广泛以威胁情报作为态势感知平台关键能力的趋势不谋而合。

  

Gartner坚持关注新兴和产生延续性价值的技术方向，于2013年首次提出威胁情报定义，并持续进行跟踪研究，在2017年、2019年连续两次发布《全球安全威胁情报产品及服务市场指南》，对威胁情报行业、市场、供应商进行系统性的梳理研究，并将全球范围内优秀的威胁情报供应商按照产品和服务类型进行分类和总结。在最新发布的市场指南中，Gartner认为，威胁情报不仅仅是一项功能，更应当成为安全市场重要的差异化因素。因此，企业应将威胁情报功能视为采购和运营安全产品和服务的差异化因素，并评估安全产品和服务中的TI（Threat Intelligence，威胁情报）能力，从而预测，预防，检测和响应企业当前的威胁形势。

  

Gartner预测，到2022年，20％的大型企业将使用商业威胁情报服务来为其安全策略提供信息。此外，Gartner提出，威胁情报不仅仅在金融和政府两个领域得到广泛应用，其他垂直行业如制造，通信和媒体，IT服务和软件，零售，医疗保健和公用事业等都正在利用威胁情报来进行安全的战略决策。

  

微步在线成立于2015年7月，是国内威胁情报领军企业。微步在线将情报能力和分析能力以专业检测设备/情报管理产品的方式输出给客户，帮助客户落地威胁情报能力、建立全方位的威胁监控体系。微步在线已累计融资1.65亿人民币，投资机构包括北极光、如山创投、高瓴资本(Hillhouse)等，2017-2019年多次入选全球网络安全500强(CyberSecurity 500)，并连续两次成为唯一入选Gartner全球威胁情报市场指南的中国公司。
