# 亚洲反病毒大会召开，微步在线研究者代表鲁玮克发表演讲

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NjA0NjI5MQ==&mid=2650165150&idx=1&sn=3bee70f42a4f2fd3b5e71ed6fcbbf943&chksm=f448b422c33f3d3417206f18f646075f65ffd9a1a085a0b3204aad9c41f20aa5ac9a90248ee7&scene=126&sessionid=1681279203#rd](http://mp.weixin.qq.com/s?__biz=MzI5NjA0NjI5MQ==&mid=2650165150&idx=1&sn=3bee70f42a4f2fd3b5e71ed6fcbbf943&chksm=f448b422c33f3d3417206f18f646075f65ffd9a1a085a0b3204aad9c41f20aa5ac9a90248ee7&scene=126&sessionid=1681279203#rd)

2018年11月28日至30日，2018亚洲反病毒大会在印度果阿召开。亚洲反病毒大会已经成功举办21次，本次大会共有25个亚太地区的计算机安全研究组织和公司参加，62位国际知名的安全研究人员登台分享。中国威胁情报公司微步在线也参与了本次会议，微步在线研究者代表鲁玮克在会上做了题为《DDoS攻击的组织、工具和技术》的分享演讲。

        

![](../Images/d3bd07eeb0aa27cfd76c702b16cfb63a.png)

右一为微步在线鲁玮克

  

亚洲反病毒大会（AVAR）是由亚洲反病毒研究者协会发起的行业性会议，也是全球最权威的反病毒安全会议之一，会议主办方AVAR（亚洲反病毒研究者协会）成立于1998年6月，其目的在于预防计算机病毒的传播和其给计算机带来的损害，加强亚洲反病毒研究者的相互合作。

  

 

![](../Images/2b889987ed344688aec42ec6a75634f5.png)

            

本年度AVAR的主题是The Dynamic Security Ecosystem，即动态安全生态系统。面对安全局势的日益复杂与不可控，建立动态的、具有适应性的安全生态系统成为目前从事反病毒研究的组织和个人所关注的重点。作为适应性安全生态系统的重要组成部分，威胁情报在抵御入侵、防护企业网络上一直起着重要作用，微步在线也在持续进行对情报与安全的技术研究与客户需求研究，并受邀参加多个国际研讨会议，与各国研究者交流技术成果、共享先进技术趋势。
