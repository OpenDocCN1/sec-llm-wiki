## 一、背景 

   思科在2018年3月28日发布关于Cisco IOS和Cisco IOS XE系统的安全通告，介绍了相关的22个漏洞，其中有三个漏洞等级为严重，分别为CVE-2018-0150、CVE-2018-0151和CVE-2018-0171，其余漏洞等级为高。2017年5月，Embedi安全公司研究员、俄罗斯白帽黑客George Nosenko在GeekPwn黑客大会上演示了一个思科交换机Smart Install的缓冲区堆栈溢出漏洞，即CVE-2018-0171，目前已公布PoC。

## 二、高危漏洞

  CVE-2018-0150、CVE-2018-0151和CVE-2018-0171相关的成因、影响和应对方法。CVE-2018-0150漏洞描述：该漏洞允许未经身份验证的远程攻击者使用默认账密登陆受影响的Cisco IOS XE设备。漏洞成因：因系统内存在一个隐藏的特权级别为15的账户，导致攻击者可能通过此账户默认账密远程登录受影响的设备，实现对设备的完全控制。影响范围：CiscoIOS XE 16.x应对方法：使用nousername cisco命令删除默认帐户，或者以管理员登陆设备更改默认密码。

  

详见 https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180328-xesc   

  

CVE-2018-0151 

  

 漏洞描述：CiscoIOS和Cisco IOS XE的QoS子系统中的远程代码执行漏洞。 

 漏洞成因：因程序没有正确的对数据包中的值执行边界检测，导致攻击者可通过向UDP 18999端口发送精心构造的恶意数据包，最终在目标设备上实现拒绝服务或远程代码执行。 

 影响范围：运行CiscoIOS和Cisco IOS XE软件的设备。 

 确认是否受影响：以管理员身份登录设备并在CLI中执行show udp命令  

  

应对方法： 

1、如不使用QoS系统的DMVPN功能，可关闭端口18999，或在CoPP控制面板添加如下策略拒绝来自UDP端口18999的流量。

  

` ! -- ACL for CoPP Undesirable UDP class-map `

`access-list 199 permit udp any any eq 18999 `

`! -- CoPP Undesirable UDP class-map `

`class-map match-all undesirable-udp `

`match access-group 199`

`! -- Undesirable UDP Policy Map `

`policy-map drop-udp `

`class undesirable-udp  `

`drop   `

`! -- ApplyUndesirable UDP policy Map `

` control-plane `

` service-policyinput drop-udp`

  

  

2、如需使用QoS系统的DMVPN功能，则通过软件更新进行漏洞修复。 

 详见https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180328-qos#fixed  

  

CVE-2018-0171 

  

 漏洞描述：CiscoIOS和Cisco IOS XE的Smart Install存在的远程代码执行漏洞，攻击者无需用户验证即可向Cisco设备的TCP 4786端口发送精心构造的恶意数据包，触发漏洞实现远程代码执行和拒绝服务。 

 漏洞成因：使用SmartInstall的网络包含一组被称为Clients的网络设备，由一个通用的第三层交换机或路由器作为Director来提供服务。Smart Install Client默认在TCP（4786）端口上开启了服务，由SMIIBC Server Process进程实现，用来与Smart Install Director交互。当SMI IBC Server处理恶意构造的ibd\_init\_discovery\_msg时会导致缓冲区溢出，因为smi\_ibc\_handle\_ibd\_init\_discovery\_msg函数未检查复制到固定大小缓冲区的数据的大小。此漏洞允许攻击者向Cisco设备的TCP 4786端口发送精心构造的恶意数据包，实现远程代码任意执行。 

  

 影响范围： 

 1、据Shodan等来源数据，超16万暴露在公网的设备受影响，其中美国、俄罗斯和中国受影响最大, 美国有55000台设备受影响，中国可能有14000台设备受影响。

 2、确认受影响设备：Catalyst 4500Supervisor EnginesCisco Catalyst3850 Series SwitchesCisco Catalyst2960 Series Switches 

 3、所有支持Smart Install Client模式的交换机都可能受此漏洞影响，包括但不限于：Catalyst4500Supervisor EnginesCatalyst3850SeriesCatalyst3750SeriesCatalyst3650SeriesCatalyst3560SeriesCatalyst2960SeriesCatalyst2975SeriesIE 2000IE 3000IE 3010IE 4000IE 5000SM-ES2 SKUsSM-ES3 SKUsNME-16ES-1G-PSM-X-ES3 SKUs 

  

 应对方法：如无需使用SmartInstall，可通过no vstack命令禁用该功能。如需使用，通过软件更新进行漏洞修复。详见https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180328-smi2  

  

三、在野攻击 

  

 1、2018年4月7日，据外媒报道，一个名为“JHT”的黑客组织利用CVE-2018-0171漏洞攻击了俄罗斯和伊朗的网络基础设施，造成路由器重启并导致网络中断。JHT覆盖了受漏洞影响的Cisco路由器的配置文件startup-config，留言“Don't mess with ourelections.... -JHT usafreedom\_jht@tutanota.com”。
