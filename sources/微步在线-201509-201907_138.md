# 微步在线入选全球网络安全500强

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NjA0NjI5MQ==&mid=2650164515&idx=1&sn=85138d22cd8e105031fea2722db904b6&chksm=f448b69fc33f3f89fb5b5a0fa764af07dfdce42e45db4482d6e83584c55981403845a167e1b1&scene=126&sessionid=1681279254#rd](http://mp.weixin.qq.com/s?__biz=MzI5NjA0NjI5MQ==&mid=2650164515&idx=1&sn=85138d22cd8e105031fea2722db904b6&chksm=f448b69fc33f3f89fb5b5a0fa764af07dfdce42e45db4482d6e83584c55981403845a167e1b1&scene=126&sessionid=1681279254#rd)

日前，全球领先的网络安全市场研究公司Cybersecurity Ventures发布了最新的全球网络安全企业500强（The Cybersecurity 500）名单，共有9家中国企业上榜，其中微步在线（ThreatBook）凭借着在威胁情报领域的领军产品、技术实力和“安全智能、情报驱动”的行业理念跻身九家上榜企业之中，是唯一一家专注威胁情报领域的公司，也是唯一一家成立仅2年左右的企业。同时入选的中国企业还有安天、绿盟、安恒、360等。

  

Cybersecurity Ventures每季度发布一次全球网络安全企业500强名单，这份名单包括了当今全球最具创新性力的安全企业。在评选这份名单时，Cybersecurity Ventures并非按照收入规模或团队规模对公司进行排名，而是根据公司所处细分行业、帮客户解决的问题、客户群体、CISO和决策者的反馈、评测机构反馈、咨询顾问反馈、公司增长、风险投资情况、产品评价、等等，从热门情况和创新力来进行综合评判，汇聚了全球领先的网络安全技术和服务公司。

  

“我们从多个不同的维度去评估网络安全公司”，CyberSecurity500创始人兼主编Steve Morgan说，“我们会评估这些安全公司的业绩增长、市场和客户情况，但同时我们也会评估当前行业面临的最大挑战是什么，网络安全公司是如何帮助客户应对这些挑战的”。

  

**前有Gartner全球威胁情报市场指南，后有全球网络安全企业500强名单，这意味着越来越多的安全领域的国际权威机构了解微步在线、认可微步在线，在强手如云的国际网络安全和威胁情报领域中，微步在线已成为一份不可或缺的中国力量。**

  

Cybersecurity Ventures这样评价微步在线：

![](../Images/f11ce245cb3275b3e0180ca7afd694ce.png)

“ThreatBook是中国第一家安全威胁情报公司，致力于提供实时，准确和独特的威胁情报来阻止攻击，发现威胁，跟踪不断发展的威胁和各种来源，以降低风险。 ThreatBook由来自亚马逊，阿里巴巴和微软等成熟组织的前高级安全专业人士创建，在脆弱性和恶意软件研究与分析，数据科学和工程大数据和云计算解决方案方面拥有数十年的专业知识。

  

“ThreatBook团队深入了解中国独特的网络安全景观，以及全球网络安全空间的国际视野，以及安全，威胁情报，分析和可视化等全面的专业知识。 ThreatBook在全球范围内提供各种威胁情报产品和服务，以帮助合作伙伴提高其安全产品的检测和防御能力，并使行业客户能够以快速，准确和具有成本效益的方式处理复杂的，不断变化的威胁。”
