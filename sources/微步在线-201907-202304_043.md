# 工信安全大会 | 微步战略签约国家工信安全中心并获两项大奖

1月9日至10日，以“数智转型 安全发展”为主题的2022年中国工业信息安全大会在北京隆重举行。微步在线作为新兴网络安全企业代表应邀参与了主论坛多个环节：在工业信息安全领域系列合作协议签约仪式上，**微步与国家工信安全中心签署战略合作协议**；在**信创安全“久安计划”**启动仪式上，**微步入选该计划首批合作伙伴名单**；在大会圆桌对话环节，微步同与会专家围绕探索产教融合新模式进行热烈讨论；在会上进行的工业信息安全产业发展联盟年度系列表彰中，**微步荣获“年度优秀成员单位”和“工业信息安全优秀应用案例”两项大奖**。

  

中国工业信息安全大会由国家工业信息安全发展研究中心（以下简称“国家工信安全中心”）、工业信息安全产业发展联盟持续举办，至今已成功举办5届。大会定位于推进落实国家工业信息安全发展重点任务，促进工信安全技术、产业、教育等综合保障能力提升等目标，是国内举办最早、会议规格最高、规模最大的工信安全领域盛会之一。

  

**战略合作签约 助推工信安全持续发展**

**在大会举行的工业信息安全领域系列合作协议签约仪式上，国家工信安全中心与福建省工信厅以及**微步在线、**飞****腾信息、中控技术等5家企业达成战略合作协议**。微步在线党支部副书记、公共事务负责人关普璟与国家工信安全中心副主任郝志强代表双方签署了战略合作协议。本次战略合作的达成，将深化各方在政策研究、标准制定、技术研发、科研创新、产业促进、人才培养等方面的合作，凝聚行业发展共识，全力助推工业信息安全产业持续向好发展。![](../Images/b0cc4ddff532ae38c173931355a6cc65.png)

  

当前，随着工业数字化、网络化、智能化与服务化的加速发展，工业信息安全整体面临的形势与挑战也日趋严峻。关普璟在会上表示，与传统网络安全相比，工业系统的目标价值更高，其安全系统的复杂程度远远高于传统的IT网络系统，在保障目标对象、安全需求等方面具有其特殊性，整个行业应建立起有效的安全管理及协同应对机制。微步在线将在国家工信安全中心的指导下，与各合作单位积极合作、协同发展，共同筑牢工业信息安全防线。

  

**“久安计划”启动 入选首批合作伙伴**

会议期间，**信创安全“久安计划”正式启动，微步在线凭借在信创安全领域的技术实力和实践经验成功入选首批合作伙伴名单**。“久安计划”由国家工信安全中心发起，旨在提升我国信创安全服务水平的能力提升行动。该计划聚焦信创安全综合能力提升、基础共性安全技术研究、安全生态环境服务三个方向，面向国内信创领域相关的企事业单位、科研机构及社会组织征集合作伙伴。此次成功入选该计划首批合作伙伴名单，再次体现了行业对微步在线的认可与肯定。

![](../Images/629926810763ad3f29c1f1671e7330a0.png)

  
当前，我国信创产业正在经历从“规划提出”、“实施落地”迈入“快速发展”的关键期。从2023开始，行业信创将接力党政信创，从金融、电信、交通逐渐向教育、医疗等行业扩散，预计未来五年信创“2+8+N”应用体系将全面落地。近年来，微步在线积极参与到信创安全建设工作中，旗下多款产品在信创安全领域的应用得到示范性认可。未来，微步在线将致力于共同推动“久安计划”落地实施，共同打造有利于信创产业发展的安全环境，为国家信创体系建设提供安全保障。  

**荣获两项大奖 凸显综合实力**

作为大会主办方之一，工业信息安全产业发展联盟自2017年成立以来，已经成为我国具有国际影响力的工业信息安全产业生态载体。微步在线作为联盟成员单位之一，多年来充分发挥自身技术优势和实践经验，积极配合联盟各项工作，协同产业链合作伙伴共同提升我国工业信息安全保障能力，在会上进行的**工业信息安全产业发展联盟年度系列表彰中，获颁“2022年度优秀联盟成员单位”**。

![](../Images/cd47ea76cd1e1935dc5759d30c4722b7.png)

![](../Images/6491b2c538a099a438e8f3f1ed634718.png)  
与此同时，**微步在线《电力关键基础设施中的工业互联网威胁感知技术及应用解决方案》在近百家参与单位报送的案例中脱颖而出，****获评“工业信息安全优秀应用案例”**。方案以“洞悉流量、聚焦威胁、融合情报、一站解决”为设计理念，暨通过流量全面梳理电力关基设施中的工业互联网资产攻击面和风险，针对工业互联网研发威胁模块聚集真实的安全威胁，有效应用数亿级的网络基础数据和可达99.99%准确度的威胁情报生产能力，一站式解决了工业互联网总部与各厂站的安全防护协同问题。  

**聚焦人才培养 共商校企合作**

网络安全的竞争，归根到底是人才的竞争。面对我国网络安全人才不断增大的缺口，如何健全人才培养体制成为业界关注焦点。在大会“探索产教融合新模式，构建协同育人新机制”主题圆桌对话环节，关普璟与来自中科大、北航、北邮以及国家工信安全中心等高校院所的专家学者进行了深入探讨。![](../Images/38dc2344640e06a3611c959e9ea86df6.png)  

关普璟表示，数字经济的发展为网络安全市场提供了机遇，同时也改变了网络安全防护的边界。随着实战防护需求与技术的不断发展，网络安全正从被动防御向实战攻防的主动防御转变，这对网络安全人才的实战能力提出了更高的要求。共搭“校院企地”合作平台，共推“产学研用”融合发展，对于加快网络安全人才培养起着至关重要的作用。

从实践中来，往实战中去。近年来，微步在线通过支持高校大学生网络安全竞赛、网攻防演练等方式积极助推网络安全人才实践。以去年为例，微步与北邮天璇Merak战队共同组织的“微步杯”MRCTF全国公开赛，吸引了各高校诸多战队参与。今后微步将与各高校和科研院所携手，在安全智库建设、人才培养交流、重大课题研究等方面深化合作，共同构建协同育人新机制。
