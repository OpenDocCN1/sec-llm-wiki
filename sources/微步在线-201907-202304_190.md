**概述**  
Apache Log4j2 是一个基于 Java 的日志记录工具，广泛用于业务系统开发，用来记录日志信息。由于 Log4j2 提供的 lookup 功能允许开发者通过一些协议去读取相应环境中的配置，却未对输入进行严格的判断，从而使攻击者可通过构造特殊的数据请求包，触发远程代码执行。因为 Apache Struts2、Apache Solr、Apache Druid、Apache Flink 等众多组件与大型应用均使用 Log4j2 作为基础组件，所以该漏洞影响范围很广，且漏洞触发后可执行任意代码，危害巨大。

  

从 Log4j2 漏洞（CVE-2021-44228）POC 曝出后，安全厂商纷纷跟进，给出缓解和防御措施。而此时黑客也不会错过这个覆盖面极广且利用门槛极低的漏洞，很快就将其直接应用到自身攻击的活动中。近期，安全研究人员就发现， Dridex 的运营组织 Indrik Spider 利用 Log4j2 漏洞的 RMI 方式进行攻击，下发 Dridex 银行木马和 Meterpreter 后门程序。![](../Images/761157386dcfa9ee1ad7e78d31ecc381.png)Dridex 是目前全球比较活跃的银行木马之一, 经过多年的发展演变，在对抗检测和分析方面非常完善，影响了约40多个国家和地区，每年造成几千万美元的财产损失。该木马主要通过伪装成税单、新冠疫情播报甚至是解雇通知等形式的钓鱼邮件进行传播。当用户打开钓鱼邮件附件中的文档，被执行的恶意宏代码下载安装 Dridex 银行木马，窃取受害者的计算机中的银行登录凭证，从而窃取受害者的财产。![](../Images/7a8b95a922be7651a961916dba374e95.png)Dridex 解雇通知钓鱼邮件
