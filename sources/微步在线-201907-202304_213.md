# 微步在线入选Gartner2021全球威胁情报市场指南

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NjA0NjI5MQ==&mid=2650170875&idx=1&sn=520f5a537701ed70e105a5ae1a5ce957&chksm=f4489e47c33f175105b905403645fa96c65f4b3df48f535884e9676f86bf86850a12b3a3da85&scene=126&sessionid=1681279051#rd](http://mp.weixin.qq.com/s?__biz=MzI5NjA0NjI5MQ==&mid=2650170875&idx=1&sn=520f5a537701ed70e105a5ae1a5ce957&chksm=f4489e47c33f175105b905403645fa96c65f4b3df48f535884e9676f86bf86850a12b3a3da85&scene=126&sessionid=1681279051#rd)

2021年12月17日，全球著名信息化研究咨询机构Gartner发布了《Market Guide for Security Intelligence Products and Services（2021）》（全球威胁情报市场指南）。作为从未缺席过威胁情报系列市场指南报告的网络安全公司，微步在线再度入选本次威胁情报市场指南，并进入Representative Vendor（代表性供应商）名单，入围产品为OneDNS互联网安全接入服务、X情报社区、本地威胁管理平台TIP（Threat Intelligence Platform）和威胁情报API。微步在线旗下已有多款产品获得了Gartner的推荐。

在威胁发现与响应领域，微步在线持续深耕，多次在市面上推出首创性产品。微步在线旗下结合了威胁情报技术与流量检测技术的NDR产品——威胁感知平台Threat Detection Platform（TDP）获得Gartner最新《全球流量检测产品及服务市场指南》提名。此外，微步在线旗下还有结合威胁情报技术与终端检测溯源技术的端点安全产品OneEDR，以及微步云沙箱S、免费蜜罐HFish等深受网络安全从业者信赖的工具型产品等，是微步在线多年来技术能力和产品独创化能力的有力体现。  
Gartner认为威胁情报市场由多种解决方案和服务组成，以帮助组织了解和准备应对他们自己独特的威胁状况，以加强预防和预测能力，并帮助改进其他操作工作，如事件响应(IR)、威胁搜索和漏洞管理(VM)。在过去一年中，微步在线助力疫情期间我国网络空间安全防护，率先发现我国台湾地区网攻组织“绿斑”攻击行为，在Log4j漏洞事件中迅速响应，出具的应急方案反应及时、影响广泛。  
微步在线于2021年12月与中国信通院联合发布了《2020年网络安全威胁信息研究报告（2021年）》，并对国家工业信息安全发展研究中心发布的《网络安全威胁情报行业发展报告（2021年）》提供研究支持。此次微步在线再度入选Gartner《全球威胁情报市场指南》，既表明了微步在线在威胁情报领域持续性保持国际领先地位的决心，也是微步在线凭借技术产品的高度专业性持续领跑国内威胁情报市场的又一强力佐证。
