# 国家网络安全宣传周法治日，微步在线亮相网络安全创新成果展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NjA0NjI5MQ==&mid=2650170212&idx=2&sn=fd3f89976e1da0fe519e027ef0f4778b&chksm=f44898d8c33f11ce1a57bc05bdafc16b18f1d942758ff8eaf2881c7dcbc752d517f5a821e023&scene=126&sessionid=1681279072#rd](http://mp.weixin.qq.com/s?__biz=MzI5NjA0NjI5MQ==&mid=2650170212&idx=2&sn=fd3f89976e1da0fe519e027ef0f4778b&chksm=f44898d8c33f11ce1a57bc05bdafc16b18f1d942758ff8eaf2881c7dcbc752d517f5a821e023&scene=126&sessionid=1681279072#rd)

  

2021年国家网络安全宣传周于10月11日-17日在西安举办。10月14日，法治日宣传活动以“共建网络安全、共享网络文明”为主题，在西安市陕西宾馆举办。中国下一代网络安全公司代表、威胁情报领军企业微步在线亮相网络安全创新成果展。

  
  
![](../Images/6f135c9946d5ab2183ae45d7c4fccfca.png)  
本次网络安全创新成果展将深度聚焦网络安全前沿动态，集中展示网络安全和信息安全的新技术、新成果和新业态。  
**微步在线将国内领先的威胁情报技术与流量检测、终端检测、DNS解析等网络安全技术深度结合，**研发并推广威胁感知平台TDP、本地威胁情报管理平台TIP、企业DNS威胁防护平台OneDNS、主机威胁检测响应平台OneEDR等一系列新一代威胁情报赋能的场景化威胁检测产品，跻身众多先进网络安全公司行列之中。  
在本次成果展中，**微步在线与观展嘉宾分享网络信息安全建设成果和经验，畅谈网络信息安全合作和持续发展之道，广泛获得观展嘉宾关注及认可。**  
![](../Images/f3ba107fd497c09424afdd3fc0b55dc4.png)

  

  

**关于微****步**

**微步在线是中国新一代网络安全公司代表性企业、网络威胁发现和响应专家。**

  
公司持续将威胁情报能力产品化，推出基于流量和终端的“云+流量+端点”全方位威胁发现产品线并赋能给客户，帮助客户建立全生命周期的威胁监控体系，**目前已有国家电网、中石油、工商银行、招商银行、光大银行、小米、京东、中信集团等来自能源、金融、智能制造、互联网等行业的大型企业客户。**

  
2020年，微步在线入选工信部网络安全技术应用试点示范项目，并以威胁认定总量排名第一的身份获评工信部网络安全威胁认定先进单位。2021年，微步在线获评由工业和信息化部认定的国家级“专精特新”小巨人企业称号，并成功入选第九届CNCERT网络安全应急服务支撑单位。

  
此外，微步在线是国家信息安全漏洞库（CNNVD）技术支撑单位、国家网络与信息安全信息通报机制技术支持单位。2018年，微步在线被中关村管委会评为中关村前沿技术企业，并获评“2018大数据与信息安全领域Top 10”。2019年，微步在线获“红鲱鱼亚洲100强”称号。

  

微步在线将继续深入贯彻落实习近平总书记关于总体国家安全观和网络强国战略思想，作为网络安全行业中新技术的开拓者、新成果的实践者和新业态的参与者之一，为营造安全清朗的网络环境而持续奋斗。
