**证监会发布《证券期货业网络安全等级保护基本要求》等2项金融行业标准，等保2.0开始行业化落实** 随着《中华人民共和国网络安全法》正式实施，等级保护2.0的正式启动，证监会根据国家网络安全等级保护相关标准，对证券期货业相关标准进行修订，**形成《证券期货业网络安全等级保护基本要求》（JR/T 0060—2021）、《证券期货业网络安全等级保护测评要求》（JR/T 0067—2021）并发布。**

  

预计在未来，重点行业将逐渐落实行业化的等保2.0标准，行业合规已在路上。  

     

  
**2021年勒索软件持续猖獗，钓鱼攻击或成重要攻击手段** 据 softpedia 消息，近日 NCC Group 的研究情报和融合团队 (RIFT) 针对全球日益增长的勒索软件攻击发布调研结果。相比2021年1-2月，4-6月的勒索软件攻击增加288%。  
其中4-6月期间的勒索软件数据泄露，**22%是因为 Conti 勒索软件，17%的数据泄露是 Avaddon 勒索软件造成（微步云沙箱可检测到以上两个勒索团伙样本）。**

  

勒索软件攻击的不断上升，则与新冠疫情爆发有着紧密联系。2019年9月至2021年4月，Palo Alto 通过监控URL过滤器检测到的防火墙流量和网络钓鱼站点，发现开始远程办公后，每周监控到的钓鱼页面在显著增加。

  

**由于员工不受企业防火墙保护，威胁元素增加，利用远程环境产生的钓鱼攻击进一步增多，给勒索软件攻击提供更多便利。**

  

  
**研究人员警告，当前4个新兴勒索软件组织非常活跃** 如今勒索软件攻击不仅频率与强度增加，而且已超出获取经济利益的范畴，对全世界的企业、医院、学校、政府都已形成威胁。

  

据 TheHackerNews 报道，近期Palo Alto网络安全研究人员发现4个针对企业以及关键基础设施异常活跃的勒索软件攻击团伙，**分别是 AvosLocker、Hive、HelloKitty、LockBit 2.0（微步云沙箱可检测到以上四个勒索团伙样本）。**

  

AvosLocker 是今年6月下旬出现的勒索团伙，之前还通过新闻媒体进行成员招募。Hive 与 AvosLocker 是今年同月出现的一个团伙，之前成功勒索过一家欧洲航空公司和3家美国公司。HelloKitty 被发现的版本是利用 VMWare 的 ESXi 管理程序来攻击 Linux 系统。  
LockBit 2.0 也是今年6月首次亮相，号称拥有世界最快的加密软件，还分发了一种名为 StealBit 的数据窃取程序。**针对勒索软件攻击，企业除做好资产暴露面管理、系统备份等基本措施，还需特别注意进行钓鱼邮件攻击防范。**    
**三大 API 漏洞成应用程序被攻击者控制主因，内部协作是解决关键** API 已经成为当今应用程序相互连接的重要工具。而在网络攻击中，攻击者会利用不同的API漏洞来攻击各种应用。

  

据 Threatpost 指出，目前，**API 的漏洞利用主要包括三种类型：目标损坏级授权、用户身份验证损坏和资产管理不当。**  

目标损坏级授权（BOLA），部分人将其定义为“针对目标访问请求的验证不充分”，它能够让攻击者通过重用访问令牌来执行未经授权的操作；

  

用户身份验证损坏，一般是指身份验证机制中的实施缺陷，这种漏洞允许攻击者冒充合法用户，例如自动化机器人执行的凭证填充进行；

  

资产管理不当漏洞，主要是由于环境隔离和管理不充分引起，使得攻击者能够访问安全性不足的API端点。

  
**想要避免 API 漏洞，需做好内部协作。**开发人员全面理解业务团队需求，更好提供 API 功能；安全人员需提前介入，在正式上线前发现并避免风险。  
  
  
**53%的企业无法通过内部数据聚合识别内部威胁** 据 HelpNetSecurity 消息，近日 Ponemon Institute 针对1249名IT及安全从业人员进行调查，发现**53%的企业很难在聚合数据时找到攻击者意图的关键指标，无法防止内部攻击。**

  

从数千个内部威胁调查和事件来看，分析师找到了内部威胁的杀伤链，分别是**侦查-规避-聚合-混淆-渗漏。**Ponemon Institute 创始人表示，安全专家对于洛克希德·马丁公司的网络杀伤链以及 MITRE ATT&CK 框架很熟悉，两者都描述了攻击的各个阶段以及外部攻击者使用的策略。

  

然而人类行为比机器行为更微妙，所以内部攻击遵循的路径略有不同，因此也需要现代的方法来对抗。很多时候，攻击者已经进行到第五步——渗漏时，企业都无法察觉。

  

对此，**如果能够找到合适的攻击者行为情报控制工具，做好明确的权限控制，将进一步降低风险。**  
  
**DDOS 攻击呈强化趋势，“高宽带”爆发式攻击增多** **根据最新数据显示，2021年上半年 DDOS 攻击的数量增长了四倍，整体攻击量翻了一番。**

  

Dark Reading 报道，安全公司 Imperva 从其客户遇到的将近5600次 DDOS 网络攻击中进行筛选分析，发现攻击者在缩短攻击时间的同时，也在不断增加攻击强度。超过一半的攻击持续了近8分钟，攻击者反复用大量数据来“淹没”同一家公司，其中单次的攻击速度甚至超过 1Tbps。  
**另外一个重要趋势，就是攻击者重新使用 TCP（传输控制协议）发送流量，使得攻击更难以识别。**

  

报告显示，TCP 流量从2020年的10%，增加到了32%。而 DDOS 攻击的数量与节奏双双增加的重要原因，在于疫情使得企业的网络服务面扩大，攻击者有更多的工具与攻击入口可进攻。**企业对此需要时刻做好攻击面梳理，不给攻击者可乘之机。**
