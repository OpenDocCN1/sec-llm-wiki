 关于今天的 HFish 蜜罐


冷知识：HFish 是由一位国人开发者编写的蜜罐框架，上手简单，文档友好。上线16个月，HFish 即在 Github 上获得2.8k个 star，在国内 Gitee 上成为安全类目 TOP5 的 GVP 项目。目前，HFish 即将满2周岁生日，今天的 HFish，和两年前相比有了一丢丢变化：

如今的网络环境危机四伏。黑客手持菜刀冰蝎蚁剑来去如风，企业端口节点有各种僵尸网络玩过界，时不时还要爆个勒索事件，搞安全的同胞们心脏和头发都不太能遭住。身为国内威胁情报的开服老玩家，我们自身在生产情报的时候也会大量用到蜜罐，深知一个好蜜罐对于企业安全的重要性。我们萌生了一个想法：给蜜罐加一个情报 buff，会怎样？

2020年底，微步在线收购 HFish。我们做的第一件事，就是把 HFish 接上 X情报社区的 API，然后又和我们本地化威胁情报生产平台（TIP）打通了。我们认为“蜜罐+情报”是一组黄金搭档：

首先，踩进蜜罐的肯定都不是好人，但之前我们不知道他是谁。现在可以拿着情报去对比，是哪家的、干过什么坏事、是该封 IP 还是干脆溯源？这些问题都能得到清晰的答案。

其次，既然踩进蜜罐的不是好人，那么这些真实的攻击就能用来生产准确、可靠的威胁情报，甚至还能拓线出更多情报数据。生产出来的情报可以用在流量、终端、防火墙、态势感知等等各种地方，而且很精准，不用担心是误报。

再次，蜜罐可以作为低成本的网络末梢和云端威胁感知探针，延长各种 XDR 感知触角，传统防御体系拦截99次不抵漏过的1次，蜜罐则反转防守方不利场景，99次未被发现抵不过被发现1次。
 
子曾经曰过：蜜罐 hacking 的不是技术，是人性……

自从收购 HFish，我们一口气发了5个版本，只为更方便你用蜜罐拿捏人性的弱点，让黑客落败于他们的贪嗔痴。

为此，最新的 HFish v2.5 版本在功能上就做了这些优化：

  • 新增主机蜜饵功能：能够精准溯源失陷主机；

  • 新增自定义蜜罐功能：支持自主开发 Web 蜜罐；
  • 新增风险账号功能：覆盖所有被攻击时使用的用户名账密，支持对企业账户关键字进行监测；
  • 新增 SSL 蜜罐功能：增加对 HTTPs 支持，可支持蜜罐在 HTTP 和 HTTPs 之间动态切换；
  • 新增多用户管理功能：根据用户反馈，增加多用户登录和分权管理页面；
  • 新增扫描感知功能：支持对全端口的 TCP/UDP 扫描以及 Ping 探测的感知；
  • 新增通用 TCP 端口监听功能：默认监听勒索软件常用探测端口，同时允许用户指定监听多个 TCP 端口，有利于用户环境存在的特种业务风险感知。

HFish 仍保持向所有企业和个人用户永久免费授权使用，您可以从  https://hfish.io 下载最新版。


 一条“鱼”的奇妙能力

除了生产和消费情报以外，现在的 HFish 还多了哪些能力？

安全与稳定：HFish 目前主打低交互和中交互蜜罐，共有十四种不同的交互形式，当前所有伪装服务都使用 Golang 语言重写，完全杜绝伪装服务被二次利用的隐患。

敏捷且易用：一条命令即可闪电部署 HFish 控制端，控制端支持 x64 位 Linux、Windows 主机，节点端支持 Linux、Windows 和 ARM 的 x32 和 x64 位环境。

高度自定义：支持对 Web 蜜罐的高度自定义，用户可以快速完成自己内网系统的模拟。

和其他安全产品的协同联动：HFish 所有的攻击日志、扫描记录、攻击首发、攻击溯源、告警等数据，都能通过 syslog、webhook、API 等多种方式，与网络防火墙、EDR、SOAR 等不同安全设备联动。

及时告警：HFish 能在未知威胁等入侵行为对信息系统发生影响之前，以自动或半自动方式，通过邮件、钉钉、企业微信、飞书等通讯工具输出给蜜罐管理者。
