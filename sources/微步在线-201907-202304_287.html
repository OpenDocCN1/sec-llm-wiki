近日，全球权威的 IT 研究与顾问咨询公司 Gartner 发布了《Hype Cycle for ICT in China, 2021（2021年中国 ICT 技术成熟度曲线报告）》，微步在线作为中国网络安全领域的新生力量和威胁情报领军企业，凭借在云安全领域领先的技术实力和全方位的产品矩阵，成功入选 Cloud Security（云安全）代表性厂商（sample vendor）。在连续 3 年入选 Gartner《全球威胁情报市场指南》之后，微步在线的技术实力和市场表现再获 Gartner 的高度认可。


技术成熟度曲线是为企业提供的评估新技术成熟度的典型工具，也是判断新兴数字化技术趋势、技术潜力和商业潜力的重要依据。Gartner 认为，中国云安全在成熟度上已达“青少年”阶段，并且将在 2-5 年内进入期望高峰期。

云安全是一个涵盖了包括云安全体系结构在内的，从人员和流程到技术的广泛概念。在中国，云安全的概念已扩展到商业运营安全管理。随着中国国家数字资产保护计划和“云”迁移趋势，云共享为企业的数据安全带来了新的挑战，更多的中国企业将网络安全纳入高优先级的任务列表。在这种背景下，企业需要建立新的安全管理体系，以尽快在多用户环境中从传统的数据中心安全转向云安全。



Gartner 认为，在云安全方面，中国大多数企业过去将目光更多集中于业务和边界保护，却缺乏安全框架的整体部署。新的时代背景下，网络攻击方式趋于规模化、专业化，国际地缘政治格局的新变化都促使企业的安全建设逐渐从合规走向实战化。因此，中国企业必须配备新的安全组织和工具，以覆盖数字安全领域，保护共享环境中的数据安全。


专注六年，微步在线作为国内第一批威胁情报公司，一直致力于利用云计算、人工智能、大数据等技术，提供专业的威胁检测产品与服务，打造专注防守方视角的专业服务团队，成为企业客户的威胁发现与响应专家。


目前，微步在线的安全云已经覆盖威胁情报、威胁检测与响应、威胁防护等多个场景服务体系，包含了威胁感知平台（TDP）、本地威胁情报管理平台（TIP）、微步在线云 API 在内的 9 款网络安全产品，建立全方位的威胁监控体系，助力提高企业安全实战化能力。


截至目前，微步在线已为银行、证券、互联网、能源、等多个领域的 300+ 标杆政企客户提供网络安全保障服务，威胁检测与响应作为新一代的安全技术与生产力，也已成为各行业头部客户的首选。
