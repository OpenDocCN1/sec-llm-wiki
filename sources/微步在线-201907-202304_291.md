2021年6月30日，在举国上下喜迎建党100周年之际，微步在线研究人员发现 sysrvhello 僵尸网络借机搞起小动作，通过 JBoss 远程命令执行、Hadoop 未授权访问漏洞、Laravel 远程代码执行等进行漏洞传播，该攻击活动对互联网环境影响较为严重，微步在线主机威胁与检测响应平台 OneEDR（以下简称 OneEDR）监测到恶意行为后立即发布告警。该攻击活动再次提醒我们，维护网络安全时刻不能松懈！**/****/** 事件起因  

2021年6月30日下午，风雨大作。雷雨声中，OneEDR 主机告警界面出现了2条告警信息：1）系统内部伪装成内核模块进程名的恶意进程；2）有可疑进程外连恶意软件（194.145.227.21）。

**/****/** 告警排查分析

## **1\. 告警详情分析**

在左侧菜单栏首页下的主机列表中点击第1条告警信息，查看详情得知，系统内部伪装成内核模块进程名的恶意进程 l48wzb 与恶意软件情报 IP 194.145.227.21 进行了通信。

![](../Images/684ca697c30fc7793d1ccb1c16d8dc95.png)  
  

排查 OneEDR 日志得知，主机通过访问 http://194.145.227.21 下载了 ldr.sh。  

![](../Images/db48826462c53c36701fef6232edcbd5.png)  
  
同时，查看 json 数据，识别出下载请求的 UserAgent 为 cve\_2017\_12149。  
![](../Images/6402bca41f526f654b9a59e617ff11b6.png)  
  
如下图所示，点击查看流程图发现，l48wzb 木马进行自我复制（kthreaddi），我们发现木马与 Cron 计划任务有关联，说明木马是由计划任务启动的，存在恶意的计划任务，以及执行了 netstat 、xargs 等命令。初步判定是为了加强自身隐蔽效果，防止被完全查杀。  
![](../Images/b96327ae80097464c4e2cf0e69ee435c.png)  
![](../Images/6962e18ee62e547c0f1ce1f7b9ae2ddb.png)  

该恶意计划任务每分钟执行一次。  

![](../Images/347d5eac9b6bd3dcecc1e9061d9e2196.png)  

## **2\. 攻击原因排查**

登录服务器后，经排查，这台主机的其他用户日志无异常信息，也无 SSH 爆破成功入侵行为，该主机除了 JBoss 应用外没其他应用服务。之后访问这台主机（IP：8080）的 JBoss 主页面，发现应用服务都出现了故障。

![](../Images/96a9a4c714b4f3db7f4eec2899a555f2.png)  

查看 JBoss 日志（jboss/server/default/log/server.log），发现 /invoker 有报错信息 。

![](../Images/d811aa66189c5586fa7331004e9f2707.png)  
  

同时，使用 # history 排查历史命令发现含有1条危险的命令；

![](../Images/bcaf8ed220e346908403c7c87bb12a35.png)  
  
使用 # ps -ef|grep l48 查看相关进程，在 OneEDR 告警界面也显示了可疑进程 pid 为 10420；![](../Images/0b8734657a6a4ef8b82d8c077dbd06b1.png)  
  
使用 # ll /proc/10420/exe 命令发现可疑进程被执行后删除了，可以先恢复 # cat /proc/10420/exe > /home/jboss/1 这个进程；![](../Images/637b88e6eac5cd786abfa5d10f871ed6.png)![](../Images/ac55f30c90ba90ab9d6e618dffb1eb8c.png)

为了保障自身的利益最大化，清除竞品、杀掉其他进程，比如扫描、其他挖矿程序等。让自身独占受害主机，卸载安全服务，这也是老僵尸网络常用的手法。![](../Images/c0c6648b1670563e8469c5515a515d05.png)

## **1\. 事件总结**  

本次事件是通过 OneEDR 网络、文件等系统行为发现中的，OneEDR 在主机上运用了行为规则、智能事件聚合等技术手段，实现对木马入侵事件的精准发现，能发现已知或未知的威胁。通过 OneEDR 的智能关联功能，可了解到安全事件的上下文以及主机、账号、进程等信息，通过“进程链”快速掌握事件的影响范围以及事件的概括，从而精准溯源。OneEDR 是一款专注于主机入侵检测的新型终端防护平台，通过利用威胁情报、行为分析、智能事件聚合、机器学习等技术手段。充分利用 ATT&CK 对攻击全链路进行多点布控，全面发现入侵行为的蛛丝马迹。  

## **2\. 事件思考**

1.  随着近几年5G物联网的迅速发展，物联网设备数量呈几何增长，物联网设备已经成为主要的攻击目标。
2.  随着云服务的不断增多，使用各种应用服务的主机也会越来越多，这会让僵尸网络迅速增加自己的 bot。与此同时，黑客租用的是国外匿名廉价的 VPS，它不但成本低，而且溯源难度较高，所以，以后僵尸网络只会越来越多。
3.  目前的僵尸网络以 DDoS 和挖矿的木马为主。

  

## **3\. 处置建议**

1.  清除定时任务并删掉里面涉及的文件；
    
2.  清理并删除名为 /tmp/随机目录/kthreaddi；
    
3.  把应用服务升级到最新的版本，切勿使用弱口令；
    
4.  WordPress、Jenkins、Redis 等服务组件配置强密码；
    
5.  非必须的情况下，不对外开放 Redis 端口。
