微步在线云 API 已正式接入开源蜜罐 HFish 的 0.6.4 版本。


HFish 是一个国人开发者开发维护的开源蜜罐项目，凭借轻巧、易用的特性，先后得到广大用户的支持，Github 上有将近 2500 Star，更是有相当比例企业用户依赖 HFish 保护自己的业务安全。

微步在线希望通过跟开源社区的合作，把 X社区的情报查询能力，S沙箱的样本分析能力，以及微步在线尤其出色的溯源响应能力，不断地开放给更广大的安全用户。

HFish 0.6.4 版本，目前对接了微步在线云 API 的 IP 信誉接口，X社区用户每日都有一些免费查询次数。只需将 X社区账号的 APIKey 添加进 HFish 的后台，当蜜罐捕获到攻击行为后，攻击者的来源 IP 信誉情报就会自动显示。

X社区账号 APIKey 获取方法：登录 X社区，点击右上角头像，进入“我的 API”查看。

福利别错过
为感谢大家的支持，X社区特意准备了一份福利。

大家 Star HFish 后，给 honeypot@threatbook.cn 发一封邮件，标题写上“社区福利”，正文列上您的 APIkey。

收到邮件 24 小时内，我们将把您的 IP 信誉查询权限扩容到 200 次/日。


之后大家对于 HFish 的任何使用问题，也欢迎在 X社区内进行交流！

本次与 HFish 的合作，是微步在线与开源社区合作的初步尝试，微步在线希望通过这样的合作，为开源社区贡献自己的力量。

创业 5 年来，微步在线从开源社区得到了大量的支持和灵感，这些支持帮助我们在今天的企业安全市场获得了很多的荣誉和认可。作为回馈，我们愿意向开源社区开放我们的产品能力。除了产品能力外，多年来我们对企业安全市场的理解和心得，甚至是我们自身的商业化能力，也愿意与开源开发者进行分享。

如果您也是开源安全产品的开发者，希望您能与我们联系，我们期待和您成为朋友。让我们一起把国产安全工具做的更好！
