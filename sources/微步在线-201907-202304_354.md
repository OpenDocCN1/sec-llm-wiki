# 微步在线助力全国首个省级数字政府安全指数发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5NjA0NjI5MQ==&mid=2650167607&idx=1&sn=36f6c376178f2a65607adcabf3e5b19f&chksm=f448a28bc33f2b9d217fc1fa2ce87a06b71007a2406de0fcaaf19a16936c89b0c431c13e574e&scene=126&sessionid=1681279117#rd](http://mp.weixin.qq.com/s?__biz=MzI5NjA0NjI5MQ==&mid=2650167607&idx=1&sn=36f6c376178f2a65607adcabf3e5b19f&chksm=f448a28bc33f2b9d217fc1fa2ce87a06b71007a2406de0fcaaf19a16936c89b0c431c13e574e&scene=126&sessionid=1681279117#rd)

日前，广东省政务服务数据管理局牵头主办了以“看见安全威胁，健全应急机制”为主题的“粤盾”2020广东省数字政府网络安全攻防演练活动，微步在线在本次演练活动前期调研阶段提供了数据分析支撑服务。

# 

  

同时，在本次活动的闭幕式上，广东省政务服务数据管理局联合微步在线在内的9家网络安全优秀单位共同发布了全国首个体系化、可落地的省级数字政府网络安全指数——2020广东省数字政府网络安全指数，将“看不见摸不着”的网络安全防护能力转化为具体可量化考核的评价指标，督促各地各部门升级安全防御体系，为公民信息安全和系统安全运行提供有力保障。

![](../Images/271d62fdd0b0b1c183af9576d0734e8d.png)

  

微步在线作为副组长单位，深度参与了“2020广东省数字政府网络安全指数”的编写工作。该安全指数主要包含安全管理、安全建设、安全运营、安全效果四个方面的评估指标，微步在线威胁感知平台TDP可对安全运营指标中的失陷检测、欺骗防御、异常行为检测、威胁情报感知及全流量监测提供支持，以帮助广东省各地市及时发现数字政府网络安全工作中的问题，促进网络安全防御体系升级。![](../Images/dff99c834f5fe713b04a40a8cf63b842.png)  

微步在线自成立以来便专注于威胁情报领域，已获得数百家政企客户和业内专家的认可。

多次入选全球网络安全500强；2017-2020 唯一连续入选 Gartner《全球威胁情报市场指南》的中国厂商；2017-2019夏季达沃斯论坛安保支撑单位；连续两届获得中国国际进口博览会网络安保贡献奖；2018-2019年度中国互联网网络安全威胁治理联盟威胁情报共享工作组组长；国家信息安全漏洞库（CNNVD）三级技术支撑单位；国家网络与信息安全信息通报机制技术支持单位。

  

微步在线希望可以将自身的威胁分析能力和情报数据能力赋能给更多的政府机构，提升其整体威胁监控能力，不断为我国的数字政府网络安全建设添砖加瓦。
