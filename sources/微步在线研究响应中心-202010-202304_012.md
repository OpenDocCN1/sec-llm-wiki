**金融威胁情报**

#### **FiXS ：瞄准墨西哥银行的新型 ATM 恶意软件**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：墨西哥，ATM，银行

**事件概述：**Metabase Q 研究人员于近日发现了一种名为 FiXS 的新型 ATM 恶意软件。自 2023 年 2 月以来，该恶意软件被用于攻击墨西哥银行，犯罪分子利用恶意软件使用外部键盘或 SMS 消息从 ATM 提取现金。目前，研究人员尚未确定 FiXS 恶意软件初始攻击向量，但指出 FiXS 使用外部键盘（类似于Ploutus）展开攻击。在 Ploutus 攻击中，攻击者可以利用 Ploutus 恶意软件使用外部键盘或 SMS 消息从 ATM 提取现金。**技术手法：**FiXS 是通过 CEN XFS API 实现在基于 Windows 的 ATM 上运行，类似于Ripper 等其他恶意软件。FiXS 恶意软件嵌入在一个植入程序中，嵌入式恶意软件 FiXS 使用 XOR 指令解码，通过 decode\_XOR\_key() 函数在每个循环中更改密钥。植入程序将嵌入的恶意代码存储在硬编码名称为“3582-490”的文件夹中，并将与植入程序相同的名称设置为 conhost.exe，然后通过“ShellExecute”Windows API 启动 FiXS ATM 恶意软件。然后通过外部键盘/触摸屏与其交互，在恶意软件支持的功能组合列表下方根据提示操作，在最后一次 ATM 重新启动 30 分钟后，利用 Windows GetTickCount API 取款。

**政府威胁情报**

#### **SYS01 stealer，旨在瞄准关键的政府基础设施和制造公司**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：stealer，政府

**事件概述：**SYS01 stealer 是一种新型信息窃取程序，旨在针对关键的政府基础设施员工、制造公司和其他部门展开攻击。近日，Morphisec 研究人员监测到 SYS01 stealer 攻击关键的政府基础设施员工、制造公司和其他行业。该活动始于 2022 年 5 月，攻击者通过使用谷歌广告和虚假的 Facebook 个人资料来瞄准 Facebook 商业账户，这些账户宣传游戏、成人内容和破解软件等内容，以引诱受害者下载恶意文件，旨在窃取敏感信息，包括登录数据、cookie 以及 Facebook 广告和企业账户信息。 **技术手法：**威胁组织首先通过引诱受害者点击虚假 Facebook 个人资料或广告中的URL，以下载一个宣称包含应用程序、游戏、电影等的 ZIP文件。 感染链分为两部分：加载程序和释放最终有效负载的 Inno-Setup 安装程序。加载程序通常是一个合法的 C# 应用程序，容易受到侧加载漏洞的影响，该漏洞带有一个隐藏的恶意动态链接库 (DLL) 文件，该文件最终被侧加载到应用程序中。这个合法的应用程序会释放 Inno-Setup 安装程序，该安装程序会解压缩到包含恶意脚本的整个 PHP 应用程序。PHP 脚本负责窃取和泄露信息，这些脚本使用不同的技术进行编码，加大反分析和检测的难度。 

![](../Images/c8f69271cfffc5b656f71546f94b923b.png)

**来源：**  
https://blog.morphisec.com/sys01stealer-facebook-info-stealer

#### **Hiatus 活动：HiatusRAT 恶意软件针对商业级路由器进行监听**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：HiatusRAT，路由器

**事件概述：**近日，外媒报道称一种前所未见的复杂恶意软件至少从 2022 年 7 月开始，以企业级路由器为目标，秘密监视拉丁美洲、欧洲和北美的目标，这个活动被 Lumen Black Lotus Labs 称为 Hiatus。截至 2023 年 2 月中旬， Hiatus 活动中大约有 100 台暴露在互联网上的设备受到攻击，一些受影响的垂直行业包括制药、IT 服务/咨询公司和市政府等。**技术手法：**

威胁组织通过部署两个恶意二进制文件在目标设备捕获数据包，一个称为HiatusRAT的远程访问木马和一个tcpdump的变体，监控与电子邮件和文件传输通信相关的端口上的路由器流量。一旦目标系统被感染，HiatusRAT 允许威胁组织与系统进行远程交互，收集路由器信息、正在运行的进程，并联系远程服务器以获取文件或运行任意命令，以及通过路由器代理命令和控制 (C2) 流量。

**来源：**  
https://thehackernews.com/2023/03/new-hiatusrat-malware-targets-business.html

#### **东亚数万个网站流量被劫持，重定向到不良网站**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：流量劫持

**事件概述：**网络安全公司 Wiz 报告称，自2022年9月上旬以来，攻击者入侵了数万个针对东亚受众的网站，将数十万用户重定向到不良主题内容的网站。攻击者使用管理 Web 应用程序的 FTP 客户端的合法凭据获得了对网站的访问权限，将恶意代码注入到面向客户的网页中，这些网页旨在收集有关访问者环境的信息，并根据用户所在的国家地区将用户区别性的重定向到其他网站。**技术手法：**攻击者使用管理 Web 应用程序的 FTP 端的合法凭据获得对网站的访问权限。一旦获得对目标网站的访问权限，攻击者就会通过添加一行 HTML 代码(以脚本标签的形式引用远程托管的 JavaScript 脚本)来修改现有的网页。只有实现 JavaScript  脚本中重定向逻辑检查的特定条件，该技术才允许将访问者重定向到目标网站。重定向的方式随着时间的推移而发生了变化，受感染网站的访问者最初被直接重定向，但从 2 月开始，通过伪装成合法网站的中间服务器进行重定向。![](../Images/b4eabdf1749ddd14b1ad91c8171f51e8.png)  
**来源：**  
https://www.wiz.io/blog/redirection-roulette

#### **透明部落APT组织利用虚假APP投递CapraRAT后门**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：透明部落，APT，APP，CapraRAT

**事件概述：**近日，ESET 发文指出 Transparent Tribe 威胁组织正在针对印度和巴基斯坦 Android 用户展开网络间谍活动。威胁组织以甜蜜陷阱和浪漫骗局引诱目标，通过木马化的安全消息传递和调用品牌为 MeetsApp 和 MeetUp 的应用程序分发 Android CapraRAT 后门，亦或者从伪装成这些官方分发中心的虚假网站下载恶意应用，然后从受害者的设备中窃取并泄露敏感信息。截至目前，多达 150 名可能具有军事或政治倾向的人员已经成为受害者。**技术手法：**威胁组织通过浪漫骗局引诱潜在的受害者，诱导目标手动下载和安装应用程序。受害者登录应用程序后，CapraRAT 便开始通过发送基本设备信息与其 C&C 服务器进行交互，并等待接收要执行的命令。基于这些命令，CapraRAT 能够进行渗透，接收命令下载文件、启动任何已安装的应用程序、终止任何正在运行的应用程序、拨打电话、发送短信、拦截收到的短信、下载更新并请求受害者安装它，窃取设备中的敏感信息。

#### **宏碁数据泄露？黑客声称出售 160GB 的被盗数据**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：数据泄露

**事件概述：**宏碁 (Acer Inc.) 公司是一家总部位于台湾的大型全球科技公司，设计和销售硬件和电子产品。近日，外媒报道称宏碁公司正面临来自化名为“Kernelware”的黑客的潜在数据泄露。据 Kernelware 称，宏碁所谓的违规行为发生在 2023 年 2 月中旬，导致大量敏感信息被盗，总计 160GB 的 655 个目录和 2869 个文件。并且 Kernelware 提出向感兴趣的各方出售数据库，还分享了被盗数据的样本以证明其真实性。样本项目列表包括机密幻灯片和演示文稿、技术手册、Windows 图像格式文件、各种类型的二进制文件、后端基础结构数据、产品模型文档以及有关手机、平板电脑、笔记本电脑和其他设备的信息。所谓的数据还包含替换数字产品密钥、ISO 文件、Windows 系统部署映像文件、BIOS 组件和 ROM 文件。内核软件要求使用注重隐私的加密货币 XMR (Monero)进行支付，并建议使用中间人来确保销售成功。目前，尚不清楚 Kernelware 售卖数据的真实性。3月7日，宏碁回应称检测到一起未经授权访问其维修技术人员文档服务器的事件，目前调查正在进行中，尚未发现任何消费者数据存储在该服务器上。![](../Images/235b8144ddd1be7b5ae27eb500c989f6.png)  
**来源：**  
https://www.hackread.com/acer-data-breach-hacker-sell-data/

#### **Word 中被曝存在严重 RCE 漏洞 CVE-2023-21716**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：Word，RCE漏洞

**事件概述：**

微软于近日针对 Microsoft Word 中允许远程执行代码的一个严重漏洞 CVE-2023-21716 发布 PoC，并在2月的补丁中发布更新及修复措施。目前没有迹象表明该漏洞出现在野利用，但尚不清楚来自 Joshua Drake 的当前 PoC 是否可以被武器化为一个全面的漏洞利用。微软警告称，由于用户只需在预览窗格中加载文件就足以开始入侵，不必打开恶意 RTF 文档，建议受影响的版本及时进行更新。

#### **美国奥克兰市疑似遭到 Play 勒索软件团伙破坏性攻击**

外媒报道称奥克兰市已于 2023 年 2 月 10 日成为勒索软件攻击的目标 ，它影响了除 911 调度、消防应急服务和城市金融系统之外的所有网络系统，奥克兰市立即进入紧急状态以加快恢复受影响的系统并尽快恢复其所有服务，但并未公开确认数据泄露。3月1日，Play 勒索软件团伙声称对自2月中旬以来对奥克兰市的IT系统进行的网络攻击负责，将奥克兰市在其勒索网站上添加为受害者，并声称窃取了包含私人、机密数据、财务和政府文件、身份证件、护照、个人员工数据，甚至称还包括证明侵犯人权的信息的文件。此外，勒索软件组织还要求奥克兰市在72小时之内缴纳赎金。截至目前，奥克兰市尚未公开回应是否缴纳赎金。**来源：**  
https://www.bleepingcomputer.com/news/security/play-ransomware-claims-disruptive-attack-on-city-of-oakland/

#### **警惕！利用经济下滑为诱饵针对招聘相关人员的钓鱼活动**  

外媒称攻击者正在利用持续的经济衰退，以工作为主题的网络钓鱼和恶意软件活动来瞄准求职者和雇主，攻击公司招聘人员并窃取敏感信息。网络钓鱼活动通过发送声称来自招聘机构的电子邮件来针对求职者，要求他们提供个人信息或登录凭据，试图在受害者的设备上植入AgentTesla、Emotet、Cryxos Trojans和 Nemucod 等知名恶意软件，恶意软件随后可用于窃取敏感信息或未经授权访问求职者的设备及其上存储的信息。建议您在关注招聘信息的时候，需警惕此类网络钓鱼攻击活动。
