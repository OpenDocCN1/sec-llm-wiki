#### **全球最大保险公司 AON 遭黑客入侵，客户数据发生泄露**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：金融，数据泄露，保险  

**事件概述：**

近日，总部位于英国的全球最大规模保险公司 AON 发文宣称，黑客在2020年12月29日到2022年2月26日期间入侵了其系统，导致其145889名北美客户的敏感信息数据疑似发生大‍规模泄露。泄露的数据信息包括驾照号码、社会安全号码以及福利登记信息。据 AON 称在其发现违规操作时，第一时间采取措施阻止未经授权的第三方访问数据，并且聘请外部公司展开调查和报告联邦调查局。目前，AON 已向受数据泄露影响的客户发送数据泄露事件通知，为受影响的客户提供信息监控服务。

此外，AON 还指出没有任何迹象表明未经授权的第三方可以进一步复制、保留或共享 AON 保险公司的任何数据，也没有任何迹象表明泄露的数据已遭到滥用。

 **来源：  
**https://www.infosecurity-magazine.com/news/AON-hack-sensitive-information/

#### **英国格洛斯特议会服务遭网络攻击中断，当地陷入混乱**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：英国议会，数据泄露  

**事件概述：**近日，外媒发表报道指出英国议会在去年12月遭到重大网络攻击中断后，致使许多当地人生活陷入混乱。据英国格洛斯特议会的一名议员指出，黑客利用专门用于破坏计算机的恶意软件入侵了议会系统，导致格洛斯特市居民的签名、地址、国家保险号码、银行详细信息和驾驶执照信息遭到大规模泄露，房屋销售、福利支付和规划申请被迫推迟。外媒还指出此次攻击漏洞与之前在苏联开展恶意攻击的黑客有关，但英国议会负责人并未正面回应攻击背后的黑客组织，而是对此回应称目前议会正在与 ICO 合作进行积极调查，如果有新的发现，会及时的向大家披露。

  

**来源：**  
https://www.gloucestershirelive.co.uk/news/gloucester-news/hackers-access-bank-details-signatures-7308173

#### **立陶宛最大能源公司 Ignitis 遭到大规模 DDoS 攻击**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：立陶宛，DDoS  

**事件概述：**

立陶宛最大能源公司 Ignitis 于近日遭受了大规模分布式拒绝服务 DDoS 攻击，此次攻击被 Ignitis 公司称为十年来最大的网络攻击，攻击严重破坏了其数字服务和网站。7月9日， Ignitis 公司在推特上发帖称 DDoS 攻击仍在继续，但已经控制了 DDoS 攻击对其系统造成的影响。该能源公司还表示当前任务是确保网站和系统正常运行，后续会评估并改进现有的流程进一步加强系统安全防护，以便在如此大规模的攻击下，减少外界攻击对系统服务造成的影响。

此次攻击疑似是亲俄黑客组织 Killnet 发起的，该黑客组织在其 Telegram 频道宣称此次攻击是由于俄乌战争中选择支持乌克兰针对立陶宛发起的最新一次攻击，渲染恐慌氛围。随后，立陶宛国防部副部长针对此次大规模 DDoS 攻击发表讲话称，这些攻击的主要目标是渲染、加剧该地区的紧张局势，并提醒该国民众不要过度关注此类网络攻击。

https://www.infosecurity-magazine.com/news/lithuanian-energy-ddos-attack/

#### **工控系统补丁：西门子、施耐德电气7月共修复 59 个漏洞**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：西门子，施耐德电气，漏洞  

**事件概述：**

西门子和施耐德电气在7月份的安全公告中共修复了59个漏洞。其中西门子发布的安全公告中共修复了46个漏洞，包括 SIMATIC CP 1543-1 通信处理器中提升权限执行任意代码的三个严重漏洞，这些漏洞只有在使用远程连接服务器 (SRCS) VPN 功能时才能发起攻击；SIMATIC eaSie 数字助理中的导致 DoS 攻击的严重漏洞；SCALANCE X 交换机可被用于 DoS 攻击或导致会话劫持的严重漏洞以及涵盖 PADS Viewer 产品中的 20 个漏洞。西门子已陆续开始发布补丁修复漏洞，并承诺某些产品在没有补丁可用之前会提供相应的缓解措施。

施耐德电气发布的安全公告修复了命令注入、DoS等13个漏洞，其中包括 SpaceLogic C-Bus Home Controller 产品中的系统命令注入的高严重漏洞；部分 OPC UA 和 X80 高级 RTU 通信模块存在可用于 DoS 攻击的高严重性漏洞以及四个可允许攻击者加载未经授权的中等严重性漏洞；针对 Easergy P5 保护继电器中的漏洞等。施耐德电气已针对这些漏洞发布补丁和缓解措施。

https://www.securityweek.com/ics-patch-tuesday-siemens-schneider-electric-address-59-vulnerabilities

#### **“老狐狸”定向攻击遭曝光，手法老道，相关行业亟需自查！**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag："老狐狸"，APT  

‍**事件概述：**  
微步在线监测到一个长期针对报社媒体企业实施定向攻击的 APT 团伙，由于该团伙成员手法老道且经验丰富，微步研究人员将其命名为“OldFox”（老狐狸），其主要特征包括：

*   OldFox 至少自2014年起开始活跃，近年来已成功入侵多家国内报社媒体的企业内网，大肆窃取企业内部敏感信息，并伺机投放非法链接。
    
*   OldFox 通常利用 Web 侧漏洞、暴破等方式入侵目标企业的 Web 服务器，在部署自制后门木马（基于开源工具 PRISM 后门）后，伺机在企业内网进行横向移动，窃取用户数据、内部文档等敏感信息，危害程度极高。
    
*   OldFox 选择的攻击目标分布在报社媒体、手机厂商、政府、金融等行业，攻击时多为手工操作，并大量使用自行编译的开源攻击工具，隐蔽性强。
    
*   OldFox 平均每三个月更换一次木马回连服务器地址，相关IP均位于美国、中国香港等地，警惕性高，具备较强的反侦察意识。
    
*   OldFox 与赌博、色情、诈骗等非法活动关系密切。
    

**技术手法：**OldFox 团伙一般会利用 Web 应用漏洞攻陷受害者 Web 服务器，部署后门木马建立初始立足点。为扩大战果，攻击者会将常用工具例如 sshd 替换为木马化版本收集 ssh 登录账号和密码，并使用内网扫描工具进行内网扫描，伺机进行横向移动。当攻击者横向移动到核心服务器例如数据库服务器后，会通过窃取数据和植入推广链接来获取利益。

#### **多款本田车型被曝严重漏洞，可解锁车**

### ![](../Images/d640975881a1e0faa4642b36d2d8ba74.png)  Tag：严重漏洞，本田

**事件概述：**

近日，Star-V 实验室安全研究人员发现了多款本田车型存在的漏洞 CVE-2021-46145，又被称为 Rolling-PWN 攻击漏洞。该漏洞存在于许多本田车型中实施防止重放攻击的滚动代码机制版本，而且该漏洞利用后不会在传统日志文件中留下任何痕迹。攻击者可利用该漏洞解锁受害者的车辆，打开车门，甚至启动车辆发动机。据研究人员称该漏洞影响2012年至2022年期间所有在售的本田汽车。

外媒报道还指出通用解决方案要求将车辆召回当地经销商处，但建议的缓解策略是在可行的情况下通过无线 (OTA) 更新升级易受攻击的 BCM 固件。

  

**来源：**  
https://securityaffairs.co/wordpress/133090/hacking/honda-rolling-pwn-attack.html

#### **omega 勒索软件瞄准全球企业进行双重勒索攻击**  

研究人员发现一种名为"omega"的新勒索软件正在瞄准全球组织进行双重勒索攻击，并要求受害组织缴纳数百万美元的赎金换取解密器。该勒索软件会将 .omega 扩展名附加到加密文件的名称中，并创建名为 DECRYPT-FILES.txt 的定制化勒索信。如果受害者不支付赎金，omega 团伙就会通过泄露站点发布被盗数据。截至目前，omega 的泄漏站点托管着152 GB的数据。**来源：  
**https://www.bleepingcomputer.com/news/security/new-0mega-ransomware-targets-businesses-in-double-extortion-attacks/

#### **警惕！针对亚马逊网购用户的网络钓鱼诈骗活动**
