#### **DeFi 平台 Inverse Finance 遭闪电贷款攻击，126万美元遭到损失**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Inverse Finance，闪电贷  

**事件概述：**

近日，外媒报道称一家名为 Inverse Finance 的 DeFi 平台遭闪电贷攻击，价值126万美元的加密货币失窃。这是近两个月内，Inverse Finance 第二次遭受闪电贷攻击，此前在四月份的攻击事件中，黑客从其获取 1560万美元。Inverse Finnace 发文回应称，针对此事件已暂停了借贷，并表示没有用户的资金被盗或者面临风险，此次事件也正在进一步调查当中。截至目前，官方尚未披露更多攻击事件细节。**技术手法：**攻击者通过使用闪电贷款来操纵协议货币市场应用程序(LP) 代币的预言价格，借用比他们发布的抵押品数量更多的协议稳定币DOLA，调用函数将合约上的WBTC和USDT货币兑换为ETH，然后通过多次交易将ETH发送到Tornado Finance，以此将差额收入黑客囊中。由于 Inverse Finance 被攻击的合约使用 YVCrv3CryptoFeed 作为 Inverse Finance DOLA借贷池的价格预言机，YVCrv3CryptoFeed价格预言机返回的价格会根据Curve USDT-WBTC-WETH池中不同代币的余额来决定Yearn的Vault代币价格，因此可被攻击者利用。**来源：**  
https://www.theregister.com/2022/06/17/inverse\_finance\_heist/

#### **Lyceum 组织以军事热点事件为诱饵，定向攻击中东能源部门**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Lyceum，能源，中东  

**事件概述：**近期，国内安全厂商监测发现了 Lyceum 组织瞄准中东能源部门的定向攻击活动。研究人员推断初始攻击入口可能是鱼叉式钓鱼邮件，攻击者通过诱骗受害者点击下载 docm 文件或者伪装的 SCR 屏幕保护程序。当攻击样本被下载执行后，会释放一个诱饵文件来迷惑受害者。据研究人员分析发现  Lyceum 组织在此次攻击手法具备以下特点：（1）Lyceum 组织通过 planet-informer\[.\]me 域托管攻击样本；（2）SCR 攻击样本实际为带有密码保护的 SFX 文件，SFX 解压得到的释放器会从伪装的 jpg 图片文件中提取后门和可执行文件数据；（3）一阶段释放器和后门依然沿用了 Lyceum 组织此前样本中使用的C#代码控制流平坦化手段。

#### **西门子、霍尼韦尔等多个OT设备制造商被曝受"ICEFALL"漏洞的影响**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：OT制造商，ICEFALL漏洞

**事件概述：**

近日，美国网络安全和基础设施安全局（CISA) 以及世界各地的其他政府机构合作披露了56个新的漏洞，这些漏洞统称为“ICEFALL”。这些漏洞主要影响为关键基础设施组织提供服务的多家的OT设备制造商，其中包括Siemens（西门子）、Motorola、Honeywell（霍尼韦尔）、Yokogawa、ProConOS、Emerson、Phoenix Contract、Bentley Nevada、Omron and JTEKT等。ICEFALL 漏洞被分为四大类：不安全的工程协议、弱加密或损坏的认证方案、不安全的固件更新和通过本地功能远程执行代码。  
据研究人员指出 ICEFALL 漏洞影响的产品不仅存在于工控行业、制造行业，也普遍存在于石油和天然气、化学、核能、发电、水处理和配电、采矿和楼宇自动化等行业，波及范围甚广。

#### **警惕！窃取用户密码的新型Android恶意软件MaliBot**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：MaliBot，Android  

**事件概述：**

近日，研究人员监测发现了一款新型 Android 恶意软件，并将其命名为 MaliBot。这是一系列针对 Android 用户的强大恶意软件中最新的一个，除了远程窃取密码、银行信息和加密货币钱包外，MaliBot 还可以访问短信、窃取浏览器 Cookie，并从受感染的安卓设备上获取屏幕截图、要求受害者授予监控设备和执行恶意操作所需的可访问性和启动器权限。并且还可以绕过多因素认证(MFA)。与许多安卓恶意软件威胁一样，MaliBot 的传播方式是通过 SMS 短信向用户的手机发送钓鱼信息或吸引受害者访问欺诈网站，诱使点击链接下载恶意软件。

截至目前，研究人员已经发现了两个用于分发 MaliBot 的恶意网站，其中一个是合法加密货币跟踪应用程序的伪造版本，其谷歌商店下载量超过一百万次。虽然 MaliBot 恶意软件目前仅针对针对西班牙和意大利银行的客户，但研究人员称随着时间的推移，MaliBot可能被添加到更广泛的目标的应用程序中展开攻击，造成重大破坏。  

**来源：**  
https://www.zdnet.com/article/this-new-android-malware-bypasses-multi-factor-authentication-to-steal-your-passwords/

**DarkElephant Group：一个瞄准东南亚国家展开窃密攻击的印度威胁组织**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：DarkElephant Group，APT，印度，东南亚  

**事件概述：**

DarkElephant Group是一个疑似来自印度的APT攻击组织，其主要针对印度境内的社会活动人士、社会团体和在野政党等，同时也会窃取印度周边国家如中国和巴基斯坦等的军事政治目标的重要情报。攻击者通常使用谷歌和雅虎邮箱伪装成收信人的好友或社会知名人士、知名机构，诱导内容紧随时事热点或与对方的工作方向密切相关，对于特别重要的个人目标能实施长达多年跨越多种系统平台的监控活动，而对于印度境外的别国军事政治目标，攻击者主要是以窃密和潜伏为主要目的。然后，该组织在向对方发送极具迷惑性的鱼叉邮件后，诱骗受害者运行具备多种免杀技巧、包含成熟商用远控木马载荷（NetWire、DarkComet、ParallaxRAT）。在过去近10年的攻击中，印度的网络攻击中心逐渐从巴基斯坦转移到中国。而通过对 DarkDarkElephant Group 组织的攻击活动后研究发现，印度相关机构不仅极为频繁对周边国家实施网络攻击，同时也将网络攻击手段广泛用于国内目标，甚至用攻击手段构陷其国内社会活动人士，相关组织行动隐蔽能力较强，值得高度关注与警惕。

**Java 库 Fastjson 被曝存在远程代码执行高危漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Fastjson，Java  

**事件概述：**

Fastjson 是一个流行的 Java 库，可用于将 Java 对象转换为其 JSON 表示形式。它还可用于将 JSON 字符串转换为等效的 Java 对象，处理任意 Java 对象。近日，研究人员披露了 Fastjson 库中一个高危漏洞 CVE-2022-25845，该漏洞与不可信数据的反序列化有关，允许攻击者绕过 Fastjson 中的 AutoTypeCheck 机制（AutoType 函数允许在解析JSON输入时指定自定义类型，然后可以将其反序列化为特定类的对象），实现远程代码执行。该漏洞影响所有依赖 Fastjson 版本 1.2.80 或更早版本的 Java 应用程序，并将用户控制的数据传递给 JSON.parse 或 JSON.parseObject API，而无需指定要反序列化的特定类。专家指出，近 5000 个 Maven 项目依赖于 Fastjson。最初，开发团队通过引入禁用 AutoType 的 safeMode 并实施类阻止列表来解决反序列化问题，从而解决了这个问题。不幸的是，专家们发现了如何绕过这些限制来实现远程代码执行，从而迫使开发团队引入新的修复程序。该漏洞已在2022年5月23日发布的1.2.83 版本中得到修复。

**来源：**  
https://jfrog.com/blog/cve-2022-25845-analyzing-the-fastjson-auto-type-bypass-rce-vulnerability/

#### **美国环境服务供应商遭勒索软件攻击，实验室检测业务被迫中断**  

总部位于美国的环境服务提供商 Montrose Environmental Group  透露其在上周末遭到勒索软件攻击，导致其实验室检测业务中断，某些实验室结果被迫推迟。Montrose Environmental Group 在美国各地运营着11个环境测试实验室，主要测试空气、土壤、水和其他物质的毒性和污染物。该服务商在发现网络入侵后，立即暂停了受影响的系统，通知了执法部门，并开始在网络安全专家的帮助下修复系统。

https://portswigger.net/daily-swig/ransomware-attack-on-montrose-environmental-group-disrupts-lab-testing-services

#### **警惕！冒充新包裹运输的骗局**

外媒报道称研究人员发现了两个目前正在流行的新包裹运输骗局，第一个是虚假的BHL，第二个是虚假的美国邮政服务警报，攻击者通过包裹警报信息、包裹运输信息为诱饵诱使收件人点击链接，然后重定向到网络钓鱼页面，窃取受害者输入的数据信息，用于金钱盗窃和身份盗窃。微步提示您切勿点击来源不明的链接，包裹运输为由的链接更需警惕点击。
