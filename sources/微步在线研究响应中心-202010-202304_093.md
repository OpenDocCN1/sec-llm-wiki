#### **MaliBot：一种在野发现的新 Android 银行木马**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：MaliBot，Android，银行木马  

**事件概述：**  
在多方机构针对 FluBot 银行木马进行执法行动后，研究人员在野发现了一种新的 Android 银行木马 MaliBot ，该木马主要针对西班牙和意大利的网上银行和加密货币钱包客户展开攻击。MaliBot 银行木马与其同类木马具备一样丰富的功能：允许它窃取凭据和 cookie，绕过多因素身份验证 (MFA) 代码，并滥用 Android 的辅助功能服务来监控受害者的设备屏幕。并且该恶意软件还旨在从 Google Authenticator 应用程序中窃取 2FA 代码，以及从 Binance 和 Trust Wallet 应用程序中窃取敏感信息。**技术手法：**MaliBot 银行木马主要通过将自己伪装成加密货币挖掘应用程序，例如 Mining X 或 The CryptoApp。这些应用程序旨在通过吸引潜在的目标访问欺诈性网站下载、分发恶恶意软件。恶意软件还会使用 smishing 作为分发媒介，通过访问受感染的智能手机的联系人并发送包含恶意软件链接的 SMS 消息来扩散恶意软件，窃取凭据、cookie及敏感信息。![](../Images/f961fd8fb4f25100974bbbd9af208b3c.png)  
**来源：**  
https://thehackernews.com/2022/06/malibot-new-android-banking-trojan.html

#### **美国科德角交通局遭到勒索软件攻击，数据发生泄露**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：勒索软件，数据泄露‍  

**事件概述：**6月13日，美国德角交通局 (CCRTA) 官方发文称其遭到勒索软件攻击，服务器的通信管理系统的访问受到了直接影响，员工被迫转用手动路线映射系统来进行 Dial-a-Ride巴士交通服务，但整体服务几乎没有中断。美国德角交通局在第一时间发现攻击行为后，与联邦调查局和马萨诸塞州警方展开合作，帮助恢复和响应交通局的工作，以确保固定路线和 Dial-a-Ride 正常运行，不会影响到客户。随后，LV 勒索软件组织出面发文称此次攻击事件背后的攻击者是自己，并且泄露了从美国德角交通局窃取的数据。本月初，该攻击者还声称利用 REvil 勒索软件攻击了CiCi 的披萨连锁自助餐厅。   

**来源：  
**https://therecord.media/cape-cod-transit-bureau-still-recovering-from-memorial-day-ransomware-attack/

#### **伊朗组织 Lycaeum 利用基于 .NET 的 DNS 后门攻击能源和电信行业**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Lycaeum，伊朗  

**事件概述：**Lycaeum 是伊朗背景的威胁组织 ，也称为 Hexane 或 Spilrin，曾使用 DNS 隧道后门针对中东的通信服务提供商展开攻击。近日，Lycaeum 组织利用一个新的基于.NET 的 DNS 后门针对能源和电信行业的公司展开 DNS 劫持攻击、执行命令、释放更多有效负载，与受害者共享在恶意网站上输入的任何信息（例如帐户凭据）并泄露数据。**技术手法：**攻击者首先向受害者投递一个包含恶意宏的 Word 文档，该文档伪装成伊朗军事主题的新闻报道，诱使目标启用文档中的恶意宏查看内容。如果目标在其 Microsoft Office 上启用宏以查看内容，则 DNS 后门将直接放置在 Startup 文件夹，以在重新启动之间建立持久性，执行 DNS 劫持攻击。除此之外，后门还可以接收来自 C2 的命令以在受感染的机器上执行，这些命令通过 cmd.exe 工具（Windows 命令提示符）运行，并将本地文件泄露到 C2 或从远程资源下载文件并释放额外的有效负载。![](../Images/66bc83e8f76eb768ac24936133df5c52.png)  
**来源：  
**https://www.bleepingcomputer.com/news/security/iranian-hackers-target-energy-sector-with-new-dns-backdoor/

#### **西门子和施耐德电气共修复了80多个影响其产品的漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：西门子，施耐德，漏洞  

**事件概述：**近日，西门子和施耐德电气发布了2022年6月的补丁公告，共修复了80多个影响其产品的漏洞。西门子发布了14条公告涵盖了59个漏洞。其中30个漏洞会影响SINEMA远程连接服务器及第三方组件。这些安全漏洞可能导致远程代码执行、身份验证绕过、权限提升、命令注入和信息泄露。在 Spectrum Power、Mendix、EN100、SCALANCE LPE9403、SINUMERIK Edge 和 Xpedition Designer 产品中均发现了这些严重漏洞。对于其中许多漏洞，西门子仅发布了缓解措施，补丁程序仍在开发当中。施耐德电气发布了8条公告修复了其产品中的24个漏洞，其中包含在 IGSS SCADA 产品的数据服务器模块中发现的7个可用于远程代码执行的严重漏洞， 在C-Bus 家庭自动化产品中发现的2个与身份验证相关的关键漏洞，StruxureWare Data Center Expert 产品中的凭据和数据反序列化相关的4个严重漏洞。这些漏洞可能导致 Conext ComBox 受到点击劫持、暴力破解和 CSRF 攻击的影响。EcoStruxure Cybersecurity Admin Expert存在的漏洞还可能允许设备欺骗和中间人攻击。截至发文，施耐德电气已针对相关漏洞发布了补丁。  
**来源：**  
https://www.securityweek.com/ics-patch-tuesday-siemens-schneider-electric-address-over-80-vulnerabilities

#### **美国凯萨医疗机构遭攻击，7万患者数据信息被泄露**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：数据泄露  

**事件概述：**近日，美国医疗巨头凯萨医疗机构 Kaiser Permanente 发布声明称其华盛顿州的7万名患者的医疗和个人信息可能在未经授权的情况下被泄露。此次信息泄露是由于该公司的电子邮件系统遭到非法入侵，患者的姓名、医疗记录号、服务日期和实验室检测结果等信息遭到泄露。但据医疗保健提供商称，其财务敏感信息(社会安全号码和信用卡号码)没有被泄露。Kaiser 医疗机构在攻击发生后数小时内拦截了非法访问，并迅速展开调查以确定事件的范围，及时有效的控制了攻击影响的范围。此外，Kaiser 医疗机构还称截至目前没有证据表明安全漏洞导致身份盗用或受保护的健康信息遭到滥用，但仍建议受影响的各方注意潜在的欺诈行为。针对此事件，Kaiser 在以后检测到未经授权的活动时会立即重置员工的电子邮件帐户密码，以避免攻击者通过邮件系统对 Kaiser 攻击。  

**来源：**  
https://portswigger.net/daily-swig/kaiser-permanente-data-breach-exposed-healthcare-records-of-70-000-patients

#### **伊朗威胁组织Phosphorus针对以色列和美国官员展开网络钓鱼攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Phosphorus，伊朗，网络钓鱼  

**事件概述：**  
近日，安全研究人员监测发现了一项伊朗威胁组织 Phosphorus 针对多名以色列和美国高级官员的网络钓鱼活动 。此次攻击活动至少可以追溯到2021年12月，威胁组织通过利用社会工程，使用真正被劫持的电子邮件链、假冒目标的知名联系人以及针对每个目标的特定诱饵展开攻击，窃取信息。**技术手法**：威胁组织通过破坏目标频繁联系的收件箱，劫持二者之间的现有对话，然后利用一个冒充同一联系人的欺骗性电子邮件地址继续对话，交换多条消息。威胁组织有时会使用真实文件作为交换的一部分，以增加骗局的合法性和相关性。

#### **微软发布6月补丁更新共修复了55个安全漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：微软，漏洞  

**事件概述：**近日，微软发布6月安全公告修复了55个漏洞，其中包括 RCE 漏洞、信息泄露、权限提升和内存访问越界等漏洞。受6月安全更新影响的产品包括 Windows操作系统、Microsoft Office、Hyper-V Server、Azure 和 Windows Defender。此更新中解决的一些严重的漏洞包括： 

*   CVE-2022-30136：Windows 网络文件系统 RCE 漏洞。攻击者需要对网络文件系统 (NFS) 服务进行未经身份验证的精心调用以触发漏洞。
    
*   CVE-2022-30163：一个 Windows Hyper-V RCE 漏洞，可通过 Hyper-V 会话上的特制应用程序利用。
    
*   CVE-2022-30139：一个 Windows 轻量级目录访问协议 (LDAP) RCE 漏洞，但利用前提是 MaxReceiveBuffer LDAP 策略设置为高于默认值。
    
*   CVE-2022-30164：Kerberos AppContainer 安全功能绕过漏洞，可以绕过执行用户访问控制检查的服务票证功能。
    
*   CVE-2022-30157：Microsoft SharePoint Server RCE 漏洞。攻击者必须经过身份验证并具有页面创建权限才可以利用漏洞。
    
*   CVE-2022-30165：Windows Kerberos EoP 安全漏洞。当通过 CredSSP 建立远程凭据保护连接时，可能会欺骗 Kerberos 登录过程。  
    

**来源：  
**https://www.zdnet.com/article/microsoft-june-2022-patch-tuesday-55-fixes-remote-code-execution-in-abundance/

#### **警惕！暑假期间以旅游为主题的网络钓鱼攻击激增**  

随着大多数国家取消与新冠肺炎相关的旅行限制，寻求乐趣的游客正在疯狂预订机票、住宿和旅游。而网络钓鱼攻击者也瞄准了这个时节，以旅游为主题的钓鱼诱饵展开攻击。诱饵关键词包括与暑假相关的关键词，并参考或模仿达美航空、美国航空、美国联合航空等知名航空公司和雅高酒店、全景旅游、梅里图斯酒店等酒店和旅游业组织等网络钓鱼邮件激增。目标被要求填写调查问卷，诱使其在钓鱼网站上输入个人信息，或者下载实际上是恶意软件的发票和信息，用户需提高警惕。  
**来源：**  
https://www.helpnetsecurity.com/2022/06/09/travel-themed-spam/
