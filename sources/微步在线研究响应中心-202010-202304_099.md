#### **SCPC 发布关于乌克兰2022年第一季度网络威胁形势的报告**

在俄罗斯对乌克兰的持续入侵后，乌克兰国家特殊通信和信息保护局下运作的乌克兰国家网络防御中心 (SCPC) 小组针对2022 年第一季度在乌克兰网络领域面临的网络威胁，发布了一篇关于2022年第一季度的乌克兰网络威胁局势报告。该报告主要强调了仅在这一年度乌克兰发生了将近 1400万件安全事件。其中 63% 的可疑事件是在部委和组织内部发现的，而另外 35% 的可疑事件影响了地区政府行政部门。

经 SCPC 分析发现，恶意软件分发、网络钓鱼或通过入侵收集数据以及对关键系统的入侵尝试是乌克兰敌对组织使用的主要方法，且攻击者专注于使用一整套恶意软件，包括远程访问木马、蠕虫、广告软件、间谍软件、窃取程序、键盘记录器、病毒、擦除器和其他木马。乌克兰哈尔科夫、基辅、第聂伯罗和利沃夫成为其他敌对组织的主要攻击目标。这些袭击乌克兰背后最活跃团体是俄罗斯联邦的代表，其中也包括一些军方支持的威胁组织：Armageddon/Gamaredon、IcedID/Trickbot、Sandworm、APT28/Strontium、APT29/Nobelium/Cozy Bear、SunSeed/Asylum Ambuscade 、InvisiMole、KillNet。而一些攻击来源则追踪到韩国、美国、印度和孟加拉国等国家，但 SCPC 称这并不意味着将网络攻击归咎于这些国家。

#### **哥斯达黎加社会保障基金疑似遭到 Hive 勒索软件袭击，部分服务停止运营**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：基金协会，CCSS  

**事件概述：**

近日，哥斯达黎加政府证实了其社会保障基金（CCSS）遭到网络攻击。哥斯达黎加社会保障基金也在推特上发表声明称，此次袭击始于5月31日凌晨，致使部分服务停止运营，但统一数字医疗系统和集中税收系统在内的几个工资和养老金数据库没有受到攻击的影响。目前 CCSS 正在对该事件展开调查，并试图恢复关键的服务，但目前尚无法确定这些服务何时会正常运营。据知情人士称，此次袭击背后的幕后黑手是 Hive 勒索软件，但由于 Hive 勒索软件与 Conti 勒索软件组织关联密切，Conti 勒索软件也存在的一定嫌疑。截至目前，哥斯达黎加社会保障基金尚未披露此次攻击的具体细节及幕后黑手。

此外，哥斯达黎加在本月遭到了多起勒索软件攻击，全国进入紧急状态。本月度勒索攻击破坏了该国的海关、税收平台、劳动和社会保障部，国家气象研究所以及其他多个政府机构，甚至导致哥斯达黎加城镇的一个能源供应商瘫痪。自攻击开始以来，该国财政部的数字服务一直无法正常运营。虽然哥斯达黎加在一月之内遭到致命性的勒索攻击，但该国依然拒绝支付赎金。

#### **ScreenCastify 插件被曝存在漏洞，可劫持网络摄像头**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：漏洞，摄像头  

**事件概述：**

近日，流行的 Chrome 扩展程序  ScreenCastify 修复了一个跨站点脚本 (XSS) 漏洞，该漏洞允许攻击者利用恶意网站劫持用户的网络摄像头并窃取录制的视频。虽然 Screencastify 修复了允许任何恶意网站劫持网络摄像头的 XSS 漏洞，但隐私和安全相关风险仍未得到解决，该问题可能允许员工或受感染网站以静默方式从 Screencastify 用户设备录制视频的问题。

**技术手法：**

Screencastify 请求访问用户的 Google Drive 并为其帐户创建永久Google OAuth 访问令牌，安装扩展程序时会自动授予访问 Chrome 的 desktopCapture API 和 tabCapture API 的权限。启用 Screencastify 录制视频，该视频将上传到Google Drive。然后攻击者利用窃取的 Google Drive OAuth 令牌下载创建的视频以及存储在Google Drive上的任何其他内容。

#### **WhatsApp 新骗局：允许攻击者劫持用户账户**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：WhatsApp，劫持账  

**事件概述：**

近日，国外一家网络安全公司发布报告称需警惕正在进行的 WhatsApp OTP 骗局，该骗局允许攻击者使用电话劫持用户帐户。目前，这种欺诈模式仅针对印度的 WhatsApp 用户，但专家警告称这种攻击几乎可以在任何提供类似转发服务的国家/地区展开，然后注销受害者的 WhatsApp 帐户，从而接管受害者的账户。

**技术手法：**

攻击者首先通过向受害者拨打电话，诱骗受害者拨打以 405 或 67 开头的电话号码，进行呼叫转移服务请求，将受害者呼叫转移到攻击者控制的号码。然后，攻击者启用 WhatsApp 注册过程以获取受害者号码，要求受害者通过电话发送 OPT。由于电话正忙，电话被定向到攻击者的电话，从而使攻击者能够控制受害者的 WhatsApp 帐户。

#### **黑客组织“海莲花”作战武器“Buni”最新曝光，瞄准Linux平台**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：海莲花，APT，Buni，Linux  

**事件概述：**

海莲花”，又名APT32 和 OceanLotus，是来自东南亚地区的黑客组织。该组织至少自2012年开始活跃，长期针对中国能源行业、海事机构、边防机构、卫生部门、海域建设部门、科研院所和航运企业等进行网络攻击。除中国外，“海莲花”的目标还包含全球的政府、军事机构和大型企业，以及本国的媒体、人权和公民社会等相关的组织和个人。拥有 Windows、Linux、MacOS 等不同操作系统的作战武器，覆盖移动端、桌面端、IoT多平台。  
在历史攻击手法中，APT32一直在尝试不同方法以实现在目标系统上执行恶意代码和绕过安全检测。微步情报局长期对 APT32 的研究与对抗中，于去年下半年捕获到了 APT32一个未公开的 Linux 后门 “Buni”，并且在威胁狩猎系统的持续监控下发现近期又再度开始活跃。更多内容需查看“[黑客组织“海莲花”作战武器“Buni”最新曝光，瞄准Linux平台](http://mp.weixin.qq.com/s?__biz=MzA5MDc1NDc1MQ==&mid=2247493881&idx=1&sn=064722433f5cf3d4d28714a17af095cc&chksm=90047329a773fa3f33341e4da8590eeb3965790cd2294b2e9c91032b8b4211e533b2d2b99585&scene=21#wechat_redirect)”。

#### **警惕！Windows 高危漏洞曝出在野利用，亟需自查！**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：MSDT 远程代码执行漏洞，在野利用

**事件概述：**

近日，微步情报局捕获 MSDT 远程代码执行漏洞情报以及在野利用样本，该漏洞可以导致远程代码执行，攻击者可以利用该漏洞直接获取目标系统权限。该漏洞位于 MSDT（Microsoft 支持诊断工具/ Microsoft Windows Support Diagnostic Tool）组件中，该组件用于 Microsoft 支持人员分析解决计算机上可能遇到的问题。该漏洞的在野利用样本无法在最新版本的 Office 中触发，因为其中利用的特殊的 Office 远程 OLE 对象自动加载方式已经被作为非安全问题修复（没有CVE编号）。但是攻击者依然可以使用 rtf 格式样本来实现自动触发漏洞，因此依然需要保持警惕。据悉，国外安全研究人员已于2022年4月发现 MSDT 组件远程代码执行漏洞的在野利用样本，而微软认为这不是一个安全漏洞，因此未进行修复。美国时间5月30日，Microsoft 发布漏洞通告，并提供了临时缓解措施。更多内容需查看“[警惕！Windows 高危漏洞曝出在野利用，亟需自查！](http://mp.weixin.qq.com/s?__biz=MzA5MDc1NDc1MQ==&mid=2247493880&idx=1&sn=4fafa95a7e7b05afbd99ea63eeb70766&chksm=90047328a773fa3eaf1447b3b6287c7276a48eb6f97a45592a3d768e907948eb46b5d6494871&scene=21#wechat_redirect)”。

#### **奥地利克恩顿州IT服务遭到勒索软件攻击，暂停护照签发**

BlackCat 勒索软件组织袭击了奥地利克恩顿州地区，政府IT服务出现大规模故障，数据发生泄露。与此同时，黑客组织要求奥地利克恩顿州提供500万美元的比特币赎金，以换取解密软件。但随后克恩顿州新闻处负责人对此次攻击事件回应称，该州不会支付赎金，也尚未有证据表明数据被窃取，而且所有数据都备份在备份系统中。
