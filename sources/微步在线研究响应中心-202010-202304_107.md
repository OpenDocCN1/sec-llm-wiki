#### **卡巴斯基发布《2022年勒索软件威胁趋势报告》**

2022年，勒索软件的活跃程度不亚于以往，世界范围内的企业饱受着勒索软件的威胁。与此同时，恶意软件的旧变种、新变种也卷土袭来，网络安全格局变幻莫测。近日，卡巴斯基研究人员从技术和地缘政治层面分析了 2021 年末和 2022 年发生的攻击事件，为打击网络犯罪及时的提供了威胁情报，分析了未来几个月可能出现的勒索软件威胁趋势：

*   趋势 1：威胁参与者正在尝试开发跨平台勒索软件

由于多年来越来越流行的大型游戏狩猎 (BGH) 计划，网络犯罪分子已经渗透到运行各种系统的越来越复杂的环境中。为了造成尽可能多的损害并使恢复变得非常困难，攻击者开始转向尝试加密尽可能多的系统。同时，这也意味着他们的勒索软件应该能够在不同的架构和操作系统组合上运行。克服这个问题的一种方法是使用“跨平台编程语言”（例如 Rust 或 Golang）编写勒索软件。

*   趋势2：勒索软件生态系统正在演变并变得更加“工业化”

就像合法的软件公司一样，网络犯罪组织也在不断地开发他们的工具包，重新命名他们的勒索软件，在此过程中改变点点滴滴，逐渐转向“工业化”。Lockbit 的演变，自 2019 年以来最成功的 RaaS 之一。

*   趋势3： 勒索软件团伙在地缘政治冲突中偏袒一方

在全球 Covid-19 大流行的初始阶段可以清晰的看到 Covid-19 相关的垃圾邮件和网络钓鱼电子邮件激增；2022年乌克兰的地缘政治冲突也是如此。通常在这样的地缘政治冲突中，人们会将网络攻击的来源与国家支持的威胁行为者联系起来，但网络犯罪组织和勒索软件团体也会“积极”采取行动。Conti 就在近期俄乌战争中选择了明确一方站队。俗话说，未雨绸缪，这同样适用于网络安全。近年来，勒索软件团伙从零散的团伙发展成为具有鲜明产业特征的企业。因此，攻击变得更加复杂和更有针对性，使受害者面临更多威胁。监控勒索软件组织的活动及其发展可以为我们及时的提供威胁情报，更好地进行防御。

#### **DeFi 平台 MM.Finance 遭到攻击，超 200 万美元被盗**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：DeFi，货币失窃

**事件概述：**  

MM.Finance 是一个DeFi 应用生态系统，也是 Cronos 区块链上最大的去中心化交易所。MM.Finance 于近日发表声明称其在一次域名系统（DNS）攻击中损失了价值200万美元的加密货币。此次攻击是攻击者通过将恶意合约地址注入前端代码，利用 DNS 漏洞修改托管文件中的路由器合约地址，窃取加密货币并通过 Tornado Cash 进行洗钱转移到攻击者钱包。MM.Finance 称除部分用户损失加密货币，此次攻击不会对其态系统代币产生任何其他影响，所有智能合约和用户的资金都是安全的。这意味着所有该平台生态系统代币都不会受到影响，用户无需对令牌感到恐慌。该平台还表示会为受影响的人执行补偿计划。截至目前，MM.Finance 表示已将追踪失窃货币踪迹，但尚未回应有关资金是否追回的信息。![](../Images/aeaf6c568f78bfa2a30074fd656e02f7.png)

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Conti，勒索，政府  

**事件概述：**

近日，哥斯达黎加多个政府机构遭到 Conti 勒索软件组织攻击，全国进入紧急状态。其中财政部、卡塔戈省电力服务行政委员会（Jasec）、国家气象研究所 (IMN) 、Radiográfica Costarricense S.A.  (Racsa)、哥斯达黎加社会保障基金 (CCSS)等机构均受到 Conti 勒索软件攻击的影响。由于政府程序、签名被打乱，财政部的数字服务一直无法使用，这严重影响了政府部门运营。随后，哥斯达黎加政府宣布进入国家紧急状态。

据外媒报道称，Conti 勒索软件团伙疑似向政府索要1000万美元的赎金，在政府拒绝支付后，勒索软件组织公开了672GB转储的数据，其中疑似包含哥斯达黎加政府机构的数据。![](../Images/2156d45dcd228347814f073d8ab0e80b.png)

#### **npm 供应链攻击：瞄准德国先进的工业公司展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：npm 供应链  

**事件概述：**  
近日，JFrog 安全研究团队发现并披露了旨在针对德国领先的工业公司进行供应链攻击的 npm 恶意程序包。该 npm 恶意程序包的有效负载是一种高度复杂、经过混淆的恶意软件，主要充当后门并允许攻击者完全控制受感染的机器。此外，该种恶意软件似乎是内部开发的，而不是基于公开可用的工具，且使用公共混淆。截至目前，研究人员尚未确定供应链攻击的幕后黑手，但其一方面体现了威胁组织的指标：

*   所有使用的代码都是自定义的；
*   该攻击具有高度针对性，并且依赖于难以获取的内幕信息（私有包名称）；
*   有效载荷是恶意的，并且包含简单渗透测试中不需要的功能（例如动态配置参数）；
*   上传的包没有描述或任何迹象表明它们被用于渗透目的。

另一方面，一些指标可能表明是渗透测试人员：

*   在npm 注册表中创建的用户名没有试图隐藏目标公司；
*   使用的混淆器是公共的，可以很容易地检测和混淆。

#### **FluBot Android 恶意软件通过短信活动瞄准芬兰展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：FluBot，Android，芬兰  

**事件概述：**

近日，芬兰国家网络安全中心(NCSC-FI)发布告警，称越来越多的 FluBot Android 恶意软件通过 SMS 和 MMS 感染传播，并且正在试图通过在银行和加密货币应用程序之上覆盖网络钓鱼页面来窃取受害者的财务凭证，用户需格外提高警惕。该恶意软件程序还可以访问 SMS 数据、拨打电话和监控传入通知，以窃取常见的登录凭据和临时身份验证代码。在2021年，芬兰当局仅在24小时内就监测到了70,000条恶意信息，也曾发出类似告警信息。

此外，芬兰当局还提示用户需警惕点击短信中的链接，应用程序亦需通过官方程序安装 APK。

**技术手法：**攻击者使用包括语音邮件、未接来电通知、SMS 链接等诱饵信息，将受害者重定向至托管 FluBot APK 的网站。待受害者感染恶意程序后，该程序要求受害者授予权限，然后通过联系人列表从受感染设备发送第二条 SMS 。但当恶意短信发送给 iPhone 用户时，攻击者还会展开付费订阅诈骗和其他欺诈攻击。![](../Images/0d7d7fe9fa4e5553a9d91db06588acc9.png)  

**来源：**  

https://blog.alyac.co.kr/4708  

**微步点评：**

如果您不幸被感染了，该怎么办？

*   如果您的设备已经感染了FluBot ，建议通过恢复出厂设置删除恶意软件。如果您从备份中恢复，您应该确保备份中不包含恶意软件。
*   如果您怀疑在感染此恶意软件后使用了银行应用程序，请联系您的银行并按照说明进行操作。此外，仔细监控所有交易并立即报告任何欺诈活动。建议更改被黑设备上使用的所有帐户的密码。
*   如果您是 iPhone 用户，无意中通过 FluBot SMS 订阅了付费服务，您必须联系您的运营商并请求取消订阅，且关闭订阅这些服务。

#### **伊朗组织 APT34 使用新的 Saitama 后门瞄准约旦政府展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：APT34， Saitama，约旦，伊朗  

**事件概述：**

APT34 也称为 OilRig、COBALT GYPSY、IRN2、HELIX KITTEN，是一个伊朗威胁组织，至少自 2014 年以来一直以中东国家和全球受害者为目标。该组织专注于金融、政府、能源、化学和电信行业展开攻击。近日，研究人员监测发现该组织使用名为 Saitama 的新后门瞄准约旦外交部政府官员展开攻击。**技术手法：**威胁组织通过伪装成约旦政府工作人员使用 Microsoft Outlook 帐户向受害者发送主题为“Confirmation Receive Document”且包含恶意附件的电子邮件。威胁组织使用具有诱导性的图像诱使用户启用恶意 Excel 附件包含的宏，进行 DNS通信，检索当前运行的任务进程，创建计划任务，并释放 .Net 编写的后门，执行其他恶意操作。**组织归因：**

*   Maldoc 的相似性；
*   受害者的相似性；
*   有效载荷的相似性。

#### **微软通报并修复了 Azure 漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：微软，漏洞  

**事件概述：**

近日，微软发布安全更新修复影响 Azure Synapse 和 Azure 数据工厂管道的安全漏洞 CVE-2022-29972。该漏洞存在于用于连接 Amazon Redshift 的第三方 ODBC 数据连接器、Azure Synapse Pipelines 的集成运行时 (IR) 和 Azure 数据工厂中。 攻击者可以利用该漏洞执行远程命令，访问和控制其他客户的 Synapse 工作区，从而允许他们将敏感数据（包括 Azure 的服务密钥、API 令牌和密码）泄露给其他服务。此外，微软还建议用户通过微软下载中心下载更新最新版本 (5.17.8154.2) ，这些更新可以安装在运行 .NET Framework 4.7.2 或更高版本的客户端和服务器平台的 64 位系统上，其中包括最新版本 Windows 11 和 Windows Server 2022。

#### **常见的 LinkedIn 骗局：谨防网络钓鱼攻击和虚假的工作机会**  

2022年5月9日，随着 LinkedIn  的广泛应用，越来越多的招聘者和求职者选择该招聘平台进行招聘和求职。网络犯罪分子也抛出越来越多工作机会诱饵瞄准 LinkedIn 社交网络平台展开攻击。攻击者通过虚假电子邮件中的链重定向到虚假的 LinkedIn 登录页面。诱使目标填写登录凭据，以此窃取 LinkedIn 用户名和密码，以及访问其他相同身份验证的所有其他服务。
