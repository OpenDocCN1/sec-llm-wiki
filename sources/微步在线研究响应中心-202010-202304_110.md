#### **威胁趋势 | 第三方 Web 脚本数据泄露威胁日益增加**

个人敏感数据盗窃是在线业务面临的最大威胁之一。这种危险，即通过各种各样的攻击媒介导致的数据泄露或数据破坏。其中包括物理盗窃设备、公司网络内的内部攻击以及网络钓鱼、恶意软件或第三方脚本。对于普通网站用户来说，攻击者在用户不知情的情况下窃取用户个人和敏感数据的风险日益增加。

攻击者也可以通过多种方式秘密地从不知情的网站访问者那里窃取数据。其中包括网络钓鱼等基本攻击，利用精心制作的电子邮件引诱受害者点击将用户重定向到恶意网站的欺诈链接。更复杂的攻击包括使用网站上的脚本秘密窃取用户的凭据、财务信息甚至医疗数据等。

通常，网站会出于广告或分析目的实施第三方脚本。在最近的研究中，研究人员发现第三方脚本劫持网站的频率更高。作为访客，通常很难识别欺诈行为。研究人员指出恶意第三方脚本在以下五个方面尝试提升权限：

*   浏览器登录管理器和自动填充误用：许多第三方脚本通过在网站上添加隐藏的登录表单窃取数据，用户无法识别这些恶意形式。相反，浏览器登录管理器使用存储的用户凭据填写它们并将它们发送给第三方。
    
*   社交数据泄露：许多网站运营商通过社交媒体登录提供商提供联合身份验证，用户可以使用简化的登录方式登录其社交媒体资料。攻击者可以通过嵌入第三方脚本的“第一方”网站的社交登录集成时获得访问权限，并可以查询社交媒体提供商的应用程序编程接口 (API)。
    
*   文档对象模型 (DOM) 泄露：如果攻击者在顶层实现了第三方脚本，它通常可以遍历完整的 DOM 树并泄露所有机密数据。使用这些脚本，攻击者甚至可以更改网站上的事件以跟踪用户行踪。
    
*   云环境中的数据泄露：它可以使攻击者获得对凭证存储的访问权限，并获取云环境的用户、管理员凭证。
    
*   手机传感器的数据泄露：第三方脚本可以访问移动传感器（例如 GPS、陀螺仪和运动传感器）并泄露传感器数据。
    

随着数字化转型使促使社会变得更加紧密，正确保护内容并确保敏感用户数据的安全性始终是首要考虑因素，且至关重要。  
**来源：  
**https://securityintelligence.com/posts/growing-danger-data-exfiltration-third-party-web-scripts/

#### **DeFi 平台 Deus Finance 遭到攻击，超1300万美元失窃**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：DeFi，货币失窃  

**事件概述：**

近日，DeFi 平台 Deus Finance 被曝遭到闪贷攻击，价值约1340万美元的加密货币失窃。区块链数据显示，攻击者通过一笔 1.43 亿美元的闪电贷购买了 950 万 DEI，即 Deus Finance 的稳定币，与美元挂钩。此次购买提高了 DEI 的价格，使攻击者能够偿还闪电贷款并净赚约 1300 万美元。Deus Finance 于4月28日在 Twitter 上发帖称用户资金安全，没有用户被清算；DEI 借贷暂时停止； $DEI挂钩已恢复。并声称此次攻击实际上不是经典意义上的闪贷攻击，而是涉及更复杂的攻击及利用 Solidly 加密交换平台上的 0day 漏洞。

闪电贷攻击已成为黑客攻击 DeFi 平台流行攻击方式。两周前，黑客从 DeFi 平台 Elephant Money 窃取了价值 1120 万美元的币安币；Cream Finance 在 2021 年遭受了三起不同的闪电贷攻击，2 月损失了 3700 万美元，8 月损失了2900 万美元，10月份 DeFi 平台损失了1.3亿美元。

#### **新南威尔士州交通局遭到网络攻击，数据隐私安全受到影响**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：新南威尔士州，交通局，数据安全  

**事件概述：**  
近日，新南威尔士州的交通局被曝遭到网络攻击，攻击者在其在线授权检查计划（AIS）应用程序中未经授权入侵了部分用户帐户，导致用户数据隐私安全受到影响。由于 AIS 授权检查计划要求用户提交在线申请时填写填写个人详细信息，包括他们的全名、地址、电话号码、电子邮件地址、出生日期和驾驶执照号码，新南威尔士州交通局网络攻击事件可能导致客户隐私数据发生泄露。由于黑客可能会试图利用这些信息发动攻击，交通局通知客户谨慎或者不回复任何声称来自新南威尔士州交通局的与任何安全问题有关的未经请求的电话、电子邮件或短信，以确保不落入黑客攻击的陷阱。此外，交通局还正在逐个通知受影响的用户，并且采取安全措施确保用户数据安全。  
**来源：  
**https://www.zdnet.com/article/transport-for-nsw-struck-by-cyber-attack/

#### **美国能源供应商 Riviera Utilities 遭到黑客入侵，客户信息暴露**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：数据泄露，Riviera Utilities  

**事件概述：**

5月2日，美国能源供应商 Riviera Utilities 发表声明称其部分员工电子邮件账户遭到入侵，攻击者获得了这些账户的临时访问权限，有限数量的个人信息遭到泄露。其中包括姓名、社会安全号码、驾驶执照或州身份证号码、护照号码、医疗信息、健康保险信息、信用卡或借记卡号码、卡到期日期等信息。Riviera Utilities 还称存储自动支付、银行汇票数据或其他个人信息的系统没有遭到入侵。此外，通过 Riviera 网站输入和提交的任何个人信息均不受此安全事件的影响。 

截至目前，Riviera Utilities 证实没有任何个人信息因该事件而被滥用。但是，出于谨慎考虑，该公司通知了可能受影响的个人，并且考虑向社会安全号码受影响的个人提供免费的信用监控服务。

#### **APT29 瞄准多个外交、政府组织展开网络钓鱼攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：APT29，俄罗斯，网络钓鱼

**事件概述：**

APT29 是 Mandiant 至少自 2014 年以来一直在追踪的俄罗斯间谍组织，疑似隶属于俄罗斯对外情报局 。从2022年1月中旬开始，Mandiant 监测发现 APT29 针对外交实体的网络钓鱼活动。威胁组织通过部署和使用 BEATDROP 和 BOOMMIC 下载器展开攻击，滥用 Trello、Firebase 或 DropBox 等合法 Web 服务增加防御规避能力。**技术手法：**威胁组织通过向目标投递伪装成大使馆的鱼叉式网络钓鱼电子邮件进行初始接入，利用 HTML smuggling 在目标系统或镜像文件中释放 HTML dropper ROOTSAW。该组织还利用恶意文档释放 HTA dropper，旨在交付和执行一个C语言编写的下载器 BEATDROP。然后遍历系统的用户名、计算机名称和 IP 地址，检索用户 ID，使用代理与 C2 通信，通过合法 Java 二进制文件 jucheck.exe 对修改后的 version.dll 进行 DLL 侧加载来执行 BOOMMIC，再通过注册表项创建持久性。  

![](../Images/e941cdd82463ca9f2f31e7befb42eb26.png)  

**来源：  
**https://www.mandiant.com/resources/tracking-apt29-phishing-campaigns  

**微步点评：**  
APT29在此次攻击活动中使用的恶意软件：

*   BEATDROP：BEATDROP 是一个用 C 语言编写的下载器，它使用 Atlassian 的 C&C 项目管理服务 Trello。BEATDROP 使用 Trello 存储受害者信息并检索要执行的 AES 加密的 shellcode 有效负载。然后，BEATDROP 将下载的有效负载注入并执行到挂起的进程中。
    
*   BOOMMIC：又称为 VaporRage，是一个用 C 语言编写的 shellcode 下载器，通过 HTTPS 进行通信。BOOMMIC XOR 解码下载的 shellcode 有效载荷并在内存中执行它。
    
*   ROOTSAW：又称为 EnvyScout，是一个 dropper 文件，其中包含 XOR 和 Base64 解码嵌入的 ISO/IMG 文件以进一步执行的 Javascript。
    
*   BEACON：是一个用 C/C++ 编写的后门，它是 Cobalt Strike 框架的一部分。支持的后门命令包括shell命令执行、文件传输、文件执行和文件管理。BEACON 还可以捕获击键和屏幕截图以及充当代理服务器、收集系统凭据、端口扫描和枚举网络上的系统，以及通过 HTTP 或 DNS 与 C2 服务器通信。

#### **苹果处理器被曝存在“Augury”漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Augury 漏洞，苹果

**事件概述：**

自 2018 年以来，像 Spectre 这样的基于硬件的安全漏洞一直是英特尔和 AMD 面临的一个严重问题。近日，Apple 最新的定制处理器被曝存在 Augury 漏洞。Augury 漏洞利用了 Apple Silicon 中存在的一种新颖的微架构数据内存相关预取器 (DMP)泄漏核心和任何指令都没有读取的数据。该漏洞会影响 Apple 的 M1、M1 Max 和 A14 处理器，也可能影响较旧的 A 系列芯片和较新的 M1 系列。虽然 Augury 漏洞只预取有效的虚拟地址，但其可以破坏 ASLR（地址空间布局随机化）成为严重漏洞利用的第一步。截至目前，Apple 尚未发布相关漏洞的补丁。  
**来源：  
**https://www.techspot.com/news/94452-augury-vulnerability-discovered-apple-silicon-mobile-chips.html

据信，此次攻击背后的组织是亲乌克兰组织，并且其24个目标域中，包括俄罗斯政府、俄罗斯军方和俄罗斯媒体等俄罗斯组织。

#### **Onyx：Chaos 勒索软件的新变种**  

2022年4月27日，安全研究员发现一款名为 Onyx 的新勒索软件。与当今大多数勒索软件操作一样，Onyx 威胁参与者会在加密设备之前从网络中窃取数据。然后，这些数据被用于双重勒索计划，如果不支付赎金，便威胁公开发布数据。研究人员还在补充说明中指出 Onyx 勒索软件 是 Chaos 勒索软件的新变种。

https://www.bleepingcomputer.com/news/security/beware-onyx-ransomware-destroys-files-instead-of-encrypting-them/

#### **英国国家医疗服务体系遭大规模网络钓鱼攻击**

INKY 报道称从2021年秋天持续到今年 4 月的这段段时间内，英国国家卫生服务 (NHS) 成为大型网络钓鱼活动的主要受害者。攻击者主要通过冒充品牌、凭据收集、劫持账户等技术展开攻击。由于企业/组织/个体都极容易遭到网络钓鱼攻击，研究人员建议需仔细检查发件人的电子邮件地址，还应该对不熟悉的新文档通知保持谨慎，并拒绝回复或点击来自从未联系过的发件人的电子邮件中的任何链接，以确保自身安全。
