#### **Intezer：制造业主要面临的网络威胁**

随着数字化转型正在推动制造业生产发展，但强大的在线系统也使制造公司的系统更容易遭受到网络威胁。根据 Checkpoint 数据显示，到 2021 年底，制造业同比平均每周的攻击增加了41%。而且与其他行业相比，制造业遭受的商业电子邮件泄露 (BEC) 攻击是其他行业的四倍。近年来，勒索软件攻击者试图通过对制造业的攻击来“破坏”全球供应链的支柱，以遏制下游供应链运营。以下为近期制造行业典型的攻击示例：

*   REvil 袭击了最大肉类加工公司JBS；
*   美国管道供应商 Colonial Pipeline 遭到 DarkSide 袭击；
*   最大的糖果玉米工厂遭到勒索软件袭击；
*    ........

据研究人员评估：预计2022年 年针对制造公司的攻击趋势将继续增加，以下为制造业企业应着重关注的主要网络安全风险：

1.  勒索软件威胁：

制造业企业成为勒索软件受害者损失的金额远超过了支付的赎金金额。他们可能因攻击导致生产中断而损失收入，以及恢复费用和罚款，还可能危及客户数据，失去客户的信任并损害公司的声誉。

2.  知识产权盗窃：

获得公司系统访问权限的攻击者可能会窃取知识产权 (IP)。由于大多数制造商依靠其 IP 来保持竞争力，因此公司知识产权被盗可能会迅速导致公司倒闭。 

3.  供应链攻击：

制造商的供应链通常由许多相互关联的公司、供应商、分包商和其他利益相关者组成，每个利益相关者都有自己的风险水平。对链中一个薄弱环节的攻击可能会蔓延并影响数千家公司和用户。 

4.  物联网攻击：

如果连接物联网的制造设备受到损害，可能会导致运营中断，甚至停止生产。此外，犯罪分子可能会破坏物联网设备以访问您的其他系统。 **来源：**  
https://www.intezer.com/blog/incident-response/cyber-threats-to-manufacturing-sector/

#### **Ever Surf  区块链钱包被曝存在漏洞，可完全控制受害者钱包**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：区块链，漏洞

**事件概述**：Ever Surf 是一个谷歌商店和苹果应用商店均可用区块链钱包，被称为 Everscale 区块链网络的跨平台信使、区块链浏览器。它目前在全球拥有近670,000个活跃账户，并声称已促成至少3160万笔交易。近日，Check Point Research 研究人员在 Ever Surf 钱包 Web 浏览器版本中发现的一个漏洞，该漏洞可以解密存储在浏览器本地存储中的私钥，也就是允许攻击者完全控制受害者的钱包和后续资金。 随后在研究人员向 Ever Surf 开发人员披露该漏洞后，Ever Surf  发布了一个桌面版本来缓解此漏洞。目前，该 Web 版本现已宣布外部弃用，仅应用于内部开发目的。区块链技术和去中心化应用程序（dAPP）在用户提供了许多便利的同时，由于dAPP 在浏览器内部运行，本地存储敏感数据，也更容易受到 XSS 攻击。![](../Images/57c471fd327bca806b2bcadcae843f13.png)**来源：**  
https://research.checkpoint.com/2022/check-point-research-detects-vulnerability-in-the-everscale-blockchain-wallet-preventing-cryptocurrency-theft/

俄乌战争蔓延之际，选择站队支持俄罗斯入侵乌克兰后的 Conti 勒索软件组织攻击了多个乌克兰组织，随后高调宣布瞄准美国及其北约盟国。而且在最新一次的攻击浪潮中，Conti 勒索软件组织至少攻击了五个哥斯达黎加政府实体，其中包括财政部、科学技术和电信部门等。据 Conti 发布的帖子称它已经获得了对大约 800 台服务器的访问权限，其中近1TB的数据遭到泄露，其中包括财政部人员的全名和电子邮件地址在内的900GB 的税务管理门户网站数据。哥斯达黎加财政部疑似成为了此次攻击浪潮中受影响最大的政府机构。Conti 勒索软件组织还声称社会发展和家庭津贴基金、劳工就业和社会保障部这两个政府实体也成为其最新受害者，但这两个政府实体目前仍处于在线状态，也尚未显示 Conti 组织入侵的信息。

#### **物联网僵尸网络 BotenaGo 变种瞄准 Lilin  DVR 设备展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：物联网，  僵尸网络  

**事件概述**：‍  
近日，外媒报道称 BotenaGo 物联网僵尸网络的新变种在野外出现，且瞄准 Lilin  DVR 设备展开攻击 。BotenaGo 由 AT&T Alien Labs 于2021年11月首次记录，使用 Golang 编写，且针对 Web 服务器、路由器和其他类型的物联网设备中的已知30多个漏洞展开攻击。BotenaGo 主要依赖外部程序来构建易受攻击的 Lilin 设备的 IP 地址列表，随后利用上述缺陷在目标上远程执行任意代码并部署 Mirai 有效负载。但该恶意软件无法以类似蠕虫的方式传播自身，只能用于攻击作为 Mirai 二进制文件输入提供的 IP 地址。由于僵尸网络的源代码只有2,891代码，且已被公开到 GitHub，BotenaGo 源代码极容易被其他犯罪分子滥用，成为其他新变种和新恶意软件的基础代码。

#### **Prynt Stealer：新型信息窃取软件****‍**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：信息窃取软件，Prynt Stealer  

**‍事件概述：**‍

近日，研究人员分析发现在不断增长的信息窃取恶意软件感染领域出现了一个新成员，名为 Prynt Stealer。Prynt Stealer主要针对即时通信应用程序、游戏应用程序、大量网络浏览器进行信息窃取。它不仅在提供强大功能的同时，还具备键盘记录器和剪辑器模块。研究人员称该信息窃取软件在制作的时候会优先考虑隐蔽性，其恶意代码具备二进制混淆和 Rijndael 加密字符串。

Prynt Stealer 与其他信息窃取软件不同的是，它的作者以基于时间的订阅方式出售该工具，比如每月100美元、每个季度200美元或每年700美元，但它也以900美元的价格出售终身授权。

**技术手法：**

首先，Prynt Stealer 会扫描主机中的所有驱动器并窃取大小低于 5,120 字节 (5 KB) 的文档、数据库文件、源代码文件和图像文件。接下来，该恶意软件针对存储在基于 Chrome、MS Edge 和基于 Firefox 的网络浏览器中的自动填充数据、凭据（帐户密码）、信用卡信息、搜索历史和 cookie进行检索；也会检查即时通信应用程序、游戏应用程序中有价值的数据；查询加密货币钱包目录并将其配置文件和数据库复制到 AppData 文件夹中，然后在渗透之前 ，枚举正在运行的进程、截取摘要并将其与主机中使用的网络凭据和 Windows 产品密钥捆绑在一起。‍

#### **新 APT 组织 Earth Berberoka 利用多种恶意软件针对赌博网站展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Earth Berberoka，APT  

**‍事件概述：**‍

近日，趋势科技研究人员发现一个新的APT组织 Earth Berberoka（又名 GamblingPuppet）。该组织主要以赌博网站为目标，具备 Windows、Linux 和 macOS 多平台攻击能力，还滥用以下恶意工具展开攻击：

*   Quasar RAT：一种基于 Windows 的开源 RAT，已被 APT 组织用于网络攻击；
*   AsyncRAT：一种开源 RAT，可用于通过加密连接远程监控和控制设备；
*   Trochilus ：一种可以逃避沙盒分析的隐形 RAT，可用于网络间谍活动。

**技术手法：**

恶意攻击者通过劫持加载模块加载恶意 dropper，dropper 在受感染的机器中创建并释放多个文件，以挂起模式启动并创建新线程，加载第三阶段 BasicLoader 的有效负载 MSVCPX00.dll。BasicLoader 会在桌面、文档、下载、音乐、图片和视频等目录中检索 BMP 文件，并将其加载到内存中执行。在此之后，恶意软件启动系统记录器记录线程，执行其他操作：管理交互式 shell、上传和下载文件、安装新模块、监控模块，使用 UDP（用户数据报协议）与命令和控制 (C&C) 服务器建立通信，实现后门功能等。  

‍![](../Images/de6f7bb334b81283b7a78d20e334c18d.png)‍‍  
**来源：  
**https://www.trendmicro.com/en\_us/research/22/d/new-apt-group-earth-berberoka-targets-gambling-websites-with-old.html**‍微步点评：**‍

为避免成为 Earth Berberoka 攻击的受害者，建议采用以下安全建议：

*   在点击链接或下载应用程序之前，正确审查电子邮件、网站和应用程序；
    
*   仅从受信任的来源下载应用程序；
    
*   注意恶意网站标志，例如语法和拼写错误；
    
*   通过托管电子邮件安全和反垃圾邮件保护阻止通过电子邮件到达的威胁，例如恶意链接；
    
*   使用有助于检测、扫描和阻止恶意 URL 的多层安全解决方案。

#### **微软发现新的 Linux 提权漏洞 Nimbuspwn**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Linux，权限提升，Nimbuspwn  

**‍‍事件概述：‍**‍  

4月26日，微软发布报告披露了一组统称为 Nimbuspwn 的新漏洞，这组漏洞可以让本地攻击者提升 Linux 系统权限，以部署从后门到勒索软件的恶意软件。这些安全问题如下：

1.  目录遍历 ( CVE-2022-29799 )：流程中的任何功能都不会清理 OperationalState 或 AdministrativeState。状态用于构建脚本路径，因此状态可以包含目录遍历模式（例如“../../”）以从“/etc/networkd-dispatcher”基本目录中逃脱。
    
2.  Symlink race：脚本发现和 subprocess.Popen 都遵循软链接。
    
3.  Time-of-check-time-of-use ( TOCTOU ) 竞争条件 ( CVE-2022-29800 )：发现脚本和运行脚本之间有一定的时间。攻击者可以利用此漏洞将networkd-dispatcher 认为属于root 的脚本替换为不属于root 的脚本。
    

任何对系统具有低权限的攻击者可以将上述漏洞链接在一起，通过发送任意信号升级到 root 权限，执行恶意操作。

#### **亲俄组织 Killnet 瞄准多个捷克组织展开  DDoS 攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Killnet，DDoS

**‍事件概述**‍：

继俄乌军事、网络战争蔓延之际，亲俄威胁组织 Killnet 于近期瞄准多个俄乌战争中俄罗斯的对手展开攻击，尤其是北约及其盟国。捷克首当其冲成为 Killnet 组织的攻击目标，捷克国家信息安全局、捷克铁路、卡罗维发利机场、帕尔杜比采机场以及公共管理机构近期一直受到威胁组织严重的 DDoS 攻击。在严重 DDoS 攻击袭击后，捷克信息安全局被迫中断了外国访问权限，捷克部分铁路应用程序无法正常使用，机场系统网络出现故障.......在捷克共和国的几个关键基础设施实体成功成为严重攻击目标后，捷克共和国政府发言表示这些攻击没有造成公民数据信息遭到泄露，并将这些攻击归咎于俄罗斯黑客，但并未透露攻击背后的组织。

#### **‍BlackCat 勒索软件至少入侵了全球60多个实体单位**  

‍美国联邦调查局发布告警称 BlackCat 勒索软件（又名ALPHV和 Noberus）于11月开始运营以来，全球至少有 60 个实体单位遭到该勒索软件组织的破坏。该勒索软件可以针对 Windows、Linux 和 VMWare ESXi 系统展开攻击，是一款复杂的勒索软件，建议企业使用一些缓解措施防御该勒索软件的攻击。

#### **‍‍‍警惕！以 “Azovstal”为主题针对乌克兰的网络钓鱼攻击‍‍‍‍‍‍‍‍**‍
