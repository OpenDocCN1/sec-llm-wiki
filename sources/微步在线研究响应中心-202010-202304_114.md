**2022年Q1季度公开披露的数据泄露同比激增14%**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：数据泄露  

**事件概述：**根据美国身份盗窃资源中心 (ITRC) 数据显示，2022年第一季度，美国公开报告的数据泄露数量同比增长了14%。ITRC 记录的绝大多数(92%)的入侵都是由网络攻击造成的，其中网络钓鱼和勒索软件是造成数据泄露的主要原因。在此期间，系统和人为错误也是造成数据泄露的原因，但仅占全部数据泄露的 8%，而物理攻击数量仅有3个 。医疗保健、金融服务、制造、公用事业以及专业服务是2022年第一季度数据发生泄露最多的行业。由于高度复杂的网络攻击加剧了身份欺诈攻击，企业需高度重视数据安全，我们每个人都必须增强安全意识，以确保数据生产、储存、流通的安全，减少导致数据泄露的不确定因素。   
**来源：**  
https://www.infosecurity-magazine.com/news/data-breach-disclosures-surge-14/

#### **全球最大的 NFT市场 Rarible 被曝存在漏洞，可导致用户NFT被盗**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：NFT，漏洞，货币失窃

**事件概述：**

Rarible 是全球最大的 NFT市场，月活跃用户超过200 万。近日，Check Point Research (CPR) 在 Rarible 中发现了一个安全漏洞，并于4月5日向 Rarible 报告了漏洞信息。该漏洞允许黑客通过制作恶意 NFT 来劫持用户帐户并窃取整个加密货币钱包。截至目前，Rarible 已经修复了该漏洞。

**技术手法：**  
攻击链始于受害者点击恶意 NFT 的链接，恶意 NFT 执行 JavaScript 代码并尝试向受害者发送 setApprovalForAll 请求，欺骗受害者提交请求并授予攻击者对该 NFT/加密令牌的完全访问权限，以此劫持账户并窃取加密货币钱包。

**来源：**https://therecord.media/researchers-find-vulnerability-in-rarible-nft-platform/

#### **英国政府官员成为间谍软件 Pegasus 攻击的新目标**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Pegasus ，英国政府  

**事件概述：**

近日，公民实验室报告称在英国首相办公室 FCDO（以前称为英国外交和联邦事务部）相关的设备上发现了 NSO Group Pegasus 间谍软件的感染痕迹。在2020年和2021年，英国官方机构还通报了多起 Pegasus 间谍软件感染英国政府的攻击事件。此外，加拿大研究机构还表示它已经确定了至少65名与西班牙加泰罗尼亚民间社会团体有联系的人已经成为 Pegasus 监控软件的目标或已经感染了监控软件。在 Pegasus 感染期间，西班牙境内的加泰罗尼亚正在进行一场政治分裂的民族独立斗争。与 FCDO 有关的感染疑似与阿拉伯联合酋长国有联系的 Pegasus 运营商有关，而 FCO 感染似乎与阿联酋、印度、塞浦路斯和约旦有关的 Pegasus 运营商有关。由于 FCO/FCDO 在不同国家都有员工，因此研究人员观察到的这些疑似感染可能与位于国外员工使用外国 SIM 卡的设备有关。

#### **夏威夷海底电缆网络成为黑客攻击的新目标**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：电缆，夏威夷  

**事件概述：**

近日，美国国土安全部调查人员表示一家运营电缆的夏威夷私人公司成为国际黑客组织的目标，该海底电缆为多个国家提供电话服务和互联网服务。执法人员在工作人员发现攻击的第一时间成功干预并阻止了攻击，避免造成了任何重大损害，但在阻止攻击之前，黑客可以收集允许访问系统的凭据。这家电缆运营商主要运营太平洋地区电缆连接，包括日本、澳大利亚和美国大陆等世界各地存在的各种海底电缆，其中有十几条电缆横跨太平洋海洋。尽管此次漏洞存在于服务器上，没有对电缆产生实质性破坏，但如果黑客攻击成功，冗余的网络路由也会受到影响，可能造成全州范围内大规模网络中断、数据泄露或产生更严重的破坏。

水下电缆系统是支持电信关键基础设施的 OT 的一部分，据 Nozomi Networks  研究显示水下电缆促进了 95% 的通信，OT设施破坏会对日常生活产生严重影响。早在之前的 Colonial Pipelines 网络攻击事件，此攻击关闭了美国东海岸的关键天然气管道，导致汽油短缺。随着越来越多的黑客组织将黑手瞄准了工控、关基行业，企业也应格外重视网络安全建设，防患于未然。  

**来源：  
**https://www.govinfosecurity.com/feds-disrupt-cyberattack-aimed-at-pacific-communications-a-18907

#### **Industrial Spy：一个新的数据泄露市场**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Industrial Spy，数据泄露  

**事件概述：**

近日，Malware HunterTeam 和 Bleeping Computer 报告称一个名为 Industrial Spy 新的数据泄露市场诞生，该市场主要出售被盗数据并向其成员免费提供被盗数据。其中公开的数据包括计划、图纸、技术、政治、军事机密、会计报告和客户数据库。Malware HunterTeam 研究人员还发现其恶意软件样本正在释放宣传该网站的壁纸，执行恶意软件后，它会在机器上的每个文件夹中创建 README.txt 文件，文件内容包括服务描述和 Tor 站点链接。但其壁纸包含错别字和其他错误，并且整个文本重复，该站点还可以免费获得一些数据转储，研究人员推测该团伙可能正在向威胁组织购买新的工具，并指出这些数据可能是从勒索软件团伙或其他黑客论坛的泄密站点下载的。目前，该数据泄露站点团伙已经创建了 Twitter 和 Telegram 账户进行宣传、推广、运营信息。

#### **俄罗斯威胁组织 Gamaredon 继续瞄准乌克兰展开间谍攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Gamaredon，APT，乌克兰，俄罗斯  

**事件概述：**Gamaredon（又名 Shuckworm，Armageddon）是一个具备俄罗斯背景的威胁组织。自2014年首次出现以来，Gamaredon 组织几乎将其业务集中在乌克兰。俄乌战争爆发以后，该组织针对乌克兰的攻击一直有增无减。近期，赛门铁克研究人员指出Gamaredon 威胁组织正在使用至少四种“Pteredo”恶意软件变种继续瞄准乌克兰展开间谍攻击。**技术手法：**攻击者通过在受害者设备部署 Pteredo 多个变体，旨在释放相同功能且使用相似混淆技术 VBScript 脚本文件，使用计划任务保持持久性，与不同的命令控制服务器进行通信，下载附加代码执行情报收集等恶意操作。四个变体具体信息如下：

*   Pteredo.B ：修改后的自解压 7-Zip 压缩文档，包含多个专注于数据收集和持久性建立的 VBScript。
    
*   Pteredo.C ：VBScript-ridden 变体，通过 API hammering 启动，以确保它不在分析师的沙箱中运行，依赖于从外部源获取 PowerShell 脚本并执行它们。
    
*   Pteredo.D：另一个混淆的 VBScript 释放器，它在获取有效负载、执行命令和擦除早期感染阶段的痕迹之前刷新 DNS。
    
*   Pteredo.E ：另一个混合了前三个功能的变体，例如重度混淆和 API hammering。

#### **联想 UEFI 固件被曝存在漏洞，几百万台笔记本电脑受到影响**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：漏洞，UEFI  

**事件概述：**

近日，ESET研究人员指出联想 UEFI 固件存在三个关键的漏洞，联想笔记本电脑型号均受这些漏洞的影响。攻击者可以利用这些漏洞在易受攻击的设备上部署和运行植入固件，禁用SPI闪存保护或安全启动，从而允许攻击者能够安装在系统重新启动后继续存在持久性的恶意软件，并允许恶意代码以最高权限运行。**漏洞信息：**

*   CVE-2021-3970：LenovoVariable SMI 处理程序中的一个潜在漏洞，由于对某些联想笔记本型号的验证不充分，可能允许具有本地访问权限和提升权限的攻击者执行任意代码。 
    
*   CVE-2021-3971：BIOS映像中存在一个潜在漏洞，在某些联想笔记本设备的先前制造过程中使用的驱动程序被错误地包含在 BIOS 映像中，这可能允许具有提升权限的攻击者修改NVRAM变量通过修改NVRAM变量来修改固件保护区。   
    
*   CVE-2021-3972：联想笔记本设备上存在的潜在漏洞，因为在制造过程中使用的驱动程序未被禁用，允许具有提升权限的攻击者通过修改 NVRAM 变量来修改安全启动设置。
    

截至目前，联想已针对这些漏洞发布相关补丁。

#### **新的网络钓鱼活动：攻击者旨在利用IcedID恶意软件感染乌克兰政府机构系统**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：IcedID，网络钓鱼，乌克兰，政府  

**事件概述：**

乌克兰计算机应急响应小组 (CERT-UA) 发现了新的网络钓鱼活动，该活动旨在利用IcedID 恶意软件感染乌克兰政府机构的系统。IcedID 恶意软件是一种银行木马，于 2017 年首次出现，其功能类似于 Gozi、  Zeus 和 Dridex等其他金融威胁。但该木马不会从其他银行恶意软件中借用代码，可以实现包括发起浏览器中间人攻击，以及拦截和窃取受害者的财务信息等功能。**技术手法：**攻击者通过投递包含名为“Mobilization Register.xls” 的Excel 文档的网络钓鱼邮件，诱使受害者打开文档启用恶意宏下载并运行可执行文件。下载的 EXE 文件将在受害者设备上解密并运行 GzipLoader 恶意软件。该恶意软件充当 IcedID 恶意软件的加载程序，下载、解密并运行 IcedID 恶意软件，以及提供数据盗窃身份验证服务。**来源：  
**https://cert.gov.ua/article/39609

#### **Yanluowang 勒索软件相关解密器发布**  

卡巴斯基发表报告指出 Yanluowang 勒索软件加密算法中存在漏洞，该漏洞允许通过已知明文攻击解密受影响用户的文件。Yanluowang 勒索软件于 2021年10月首次被发现，已被用于针对企业实体的攻击。这种勒索软件使用不同的方法对大于3GB和小于3GB的文件进行加密：较大的文件在每200MB后以5MB的条带部分加密，而较小的文件则从头到尾完全加密。正因如此，研究人员发现如果原始文件大于 3 GB，则可以解密受感染系统上的所有文件，但如果原始文件小于 3 GB，则只能解密小文件。  

**来源：  
**https://securelist.com/how-to-recover-files-encrypted-by-yanlouwang/106332/

#### **领英成为网络钓鱼重灾区，你中招了吗？**  

Check Point Research  (CPR)最新研究显示领英（LinkedIn ）已成为迄今为止网络钓鱼攻击中被模仿最多的品牌 。在 2022 年第一季度，冒充专业社交网站的网络钓鱼攻击占全球所有攻击的一半以上 (52%)。与上一季度第四季度相比增加了 44% 。2021 年，领英是第五大网络钓鱼模仿品牌。目前，领英已飙升至第一名，占今年迄今为止所有网络钓鱼攻击的一半以上。

与以往一样，抵御网络钓鱼威胁的最佳方法是发现可疑异常邮件，例如拼写错误的域、错误的拼写、错误的日期和其他可能暴露恶意电子邮件或短信的细节。

https://www.infosecurity-magazine.com/news/linkedin-impersonated-brand/
