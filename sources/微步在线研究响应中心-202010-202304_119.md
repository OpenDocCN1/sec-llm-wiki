#### **AT&T：防御撞库攻击的七种方法**

据 Help Net Security 报道称，研究人员在2020年10月至2021年9月期间检测到 2,831,028,247次撞库攻击，比上一年增长 98%。换言之，从2020年到2021年，撞库攻击的数量基本上翻了一番。并且有研究人员预测2022年，撞库攻击的数量将会再次翻番。那么如何防御撞库攻击呢？

1\. 凭证填充防御：TechRepublic 建议组织将他们的安全、欺诈和数字团队聚集在一起，讨论凭证填充和其他欺诈趋势，以及他们可以使用数字指标来协调他们的防御工作的方式。

2.实施多因素认证：凭证填充取决于恶意行为者可以将对凭证集的访问转换为对帐户的访问。多因素身份验证(MFA) 迫使攻击者提供另一个因素验证，从而增加了攻击者接管帐户的困难。

3\. 培养员工安全意识水平：通过培养员工的安全意识水平，组织可以在很大程度上阻止撞库攻击。

4\. 分析和基线流量的凭证填充迹象：建议组织为其流量（包括帐户活动）创建基线，并使用该基线来监控异常情况。

5\. 防止用户使用暴露的密码保护他们的帐户：信息安全人员需要监控网络是否存在数据泄露、信息转储和恶意行为者可能用来进行凭证填充的其他泄漏，及时发现暴露在外的密码数据信息。

6\. 实施设备指纹识别：团队可以使用操作系统、Web 浏览器版本、语言设置和其他属性对员工的设备进行指纹识别，然后组织可以利用该指纹来监控可疑活动。当出现异常行为时，安全团队可以提示员工提交额外的身份验证因素以增强账户的安全性。

7\. 避免使用电子邮件地址作为用户 ID：密码重用并不是增加撞库攻击风险的唯一因素，用户名和帐户 ID 的重用也是如此。

#### **马来西亚8家银行客户成为 Android 恶意软件攻击目标**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：马来西亚，Android  

**事件概述：**

据 ESET 研究人员称三个 Android 恶意程序瞄准8家马来西亚银行客户展开攻击，该活动始于2021年年末，旨在窃取银行凭据。其目标包括 Grabmaid、Maria's Cleaning、Maid4u、YourMaid、Maideasy 和 MaidACall，以及一家名为 PetsMore 的宠物商店，目标银行主要是 Maybank、Affin Bank、Public Bank Berhad、CIMB bank、BSN、RHB、Bank Islam Malaysia 和丰隆银行。

目前，尚不清楚恶意应用程序的下载量及恶意应用程序的感染范围。

**技术手法：**

攻击者通过创建冒充合法服务的虚假网站，以吸引受害者下载恶意应用程序或者将受害者定向到攻击者的服务器，要求受害者在他们的设备上启用非默认的“安装未知应用程序”选项。这些应用程序启动后虽然要求受害者进行登录，但攻击者并不会去验证输入登录数据的真实性。但当受害者需要付款时，恶意程序会将受害者重定向到虚假支付页面，要求受害者在8家马来西亚银行中选择银行输入信息进行付款，以此窃取银行凭证。在此期间允许攻击者会将所有受害者的 SMS 消息转发给恶意软件运营商，以防止银行发送双因素身份验证代码。

#### **Bearded Barbie 活动：双尾蝎组织瞄准以色列政府官员展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：以色列，APT，间谍攻击  

**事件概述：**

近日，Cybereason 监测发现中东地区威胁组织双尾蝎(APT-C-23)针对以色列官员展开攻击，旨在从目标群体的个人电脑和移动设备窃取敏感信息进行间谍活动。新的活动包含了两个以前未记录的恶意软件 Barb(ie) Downloader 和 BarbWire Backdoor，两者都使用增强的隐身机制来保持不被发现。此外，Cybereason 还在该活动中观察到了名为 VolatileVenom 的 Android 植入物的升级版本。

**技术手法：**

攻击者通过创建虚假FaceBook 账户等社会工程策略获取受害者的信任，然后将会话从 FaceBook 转移至 WhatsApp ，并诱使受害者打开一个包含色情内容视频的 .rar 文件，然后释放用来安装 BarbWire 后门的下载器组件 Barb(ie)。与此同时，恶意软件会进行反虚拟机和反分析检查，继续执行并收集有关机器的信息，包括用户名、计算机名称、日期和时间，正在运行的进程和操作系统版本，然后与嵌入式 C2 创建通信发送收集的信息，并下载 BarbWire 后门，执行后续恶意操作。

#### **西班牙电力巨头  Iberdrola 数据遭到泄露，超130万客户受到影响**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：数据泄露，能源  

**事件概述：**

西班牙电力巨头 Iberdrola 于近日证实遭到网络攻击，超130万客户的数据信息遭到泄露。与此同时，包括 Cercanías 当地铁路服务、西班牙议会以及区域机构在内的欧洲其他组织也遭到黑客攻击。Iberdrola 此次攻击事件泄露的信息包括身份证号码、地址、电话号码和电子邮件地址等信息，但表示客户银行账户详细信息、信用卡号码等敏感信息并没有遭到泄露。

目前，Iberdrola 公司已向客户发送告警信息，提醒客户要小心他们收到的任何电子邮件或其他信息，如果这些电子邮件或其他信息无法明确识别来源的可靠性，且邮件内容要求提供银行详细信息、信用卡或密码等信息，需要警惕这些邮件所附的任何文件及文中的链接。

#### **Dragos：针对欧洲工业基础设施的威胁**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：欧洲，工业基础设施，APT

**事件概述：**

电力、石油和天然气以及其他对我们日常生活至关重要的关键基础设施正日益受到网络攻击者的威胁，攻击者成功入侵工业控制系统 (ICS) 和运营技术 (OT) 可以破坏或篡改工业基础设施重要服务。近日，工控网络安全公司 Dragos 发表报告指出欧洲资产所有者目前面临的最大网络安全弱点是缺乏对其网络的资产可见性和薄弱的网络身份验证策略。此外，日益加剧的地区紧张局势可能会导致犯罪分子和其他对手对工业运营产生影响。特别值得关注的是地理上分散的工业运营，例如可再生能源发电、上游和中游石油和天然气、水和废水管理以及电力传输。Dragos 还在报告中重点指出了瞄准欧洲工业基础设施展开攻击的10个威胁组织： 

*   ParParasite：一个针对欧洲、中东和北美的公用事业、航空航天和石油和天然气的组织。他们使用开源工具和已知漏洞进行初始访问。
    
*   Xenotime：一个以欧洲、美国和澳大利亚的石油和天然气公司为目标的集团。据信该组织与俄罗斯有关。
    
*   Magnallium：一个最初针对沙特阿拉伯的石油、天然气和飞机公司，后来扩展到欧洲和北美展开攻击的组织。它被认为与国家资助的伊朗黑客组织 APT33 有关。
    
*   Dymalloy：一个针对欧洲、土耳其和北美的电力、石油和天然气以及其他先进工业实体的组织。
    
*   Electrum：该组织能够开发可以修改和控制 OT 程序的恶意软件，Dragos 研究人员表示，该组织参与了2016年12月对乌克兰电网的恶意软件攻击Crash Override（也称为 Industroyer ）。Electrum 与 Sandworm相关，属于俄罗斯 GRU 军事情报机构的黑客组织。
    
*   Allanite：一个以英国和美国电力行业的企业和 OT 网络以及德国工业基础设施为目标的组织，并利用访问权限对网络进行侦察，以潜在地策划未来的破坏性事件。该组织疑似为俄罗斯背景组织。
    
*   Chrysene：该组织至少从2017年开始活跃，以欧洲和中东的工业组织为目标，主要进行情报收集行动，以促进进一步的攻击。Chrysense疑似为伊朗背景的威胁组织。
    
*   Kamacite：一个至少从2014年开始活跃的组织，据信该组织对2015年和2016年对乌克兰电力设施的网络攻击负责。该组织与 Sandworm 存在关联。
    
*   Covellite：一个使用网络钓鱼电子邮件中的恶意附件攻击欧洲、美国和东亚的电力公司的组织。该组织被认为与拉撒路集团存在关联。
    
*   Vanadinite：一个针对全球工业组织中面向外部易受攻击软件展开攻击的黑客组织。

#### **“柠檬鸭”进化归来，旨在瞄准政府、能源等行业进行挖矿、窃密攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：LemonDuck，木马

**事件概述：**

LemonDuc 是一种主动更新且强大的恶意软件，主要以其僵尸网络和加密货币挖掘(XMR门罗币)而闻名。LemonDuck背后的团伙至少从2018年活跃至今，具备构造僵尸网络、木马开发能力，多平台攻击能力(Windows、Linux)。该团伙通过大量使用XMRig、ReflectivePEInjection、FreeRDP、GetPassHashes、SMBGhost等开源项目，降低开发、攻击成本。若其感染成功，组建僵尸网络，将发起大规模 DDoS 攻击和下载各种威胁木马。

近日，微步情报局近期捕获到多起 Zegost 变种木马以及伴随的挖矿攻击活动，经过确认是“LemonDuck”木马的新活动，分析发现 LemonDuck 木马进化归来，依旧使用钓鱼邮件、漏洞利用和USB等移动设备等三种传播方式，在内嵌的母体文件运行获取权限后，通过模块下载进行内网横移，进行大范围扩散传播。与此同时，研究人员还监测发现柠檬鸭更新了多个模块，包括 Zegost 变种木马、ClipBanker 信息窃取器和挖矿程序等。

#### **俄罗斯威胁组织 SaintBear 瞄准乌克兰多个实体展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：SaintBear，俄罗斯，乌克兰  

**事件概述：**

近日，研究人员监测发现俄罗斯背景威胁组织 SaintBear（又称为UAC-0056、UNC2589 和 TA471）正在通过使用嵌入宏的 Excel 文档来针对乌克兰多个实体展开攻击。SaintBear 是微步情报局早前披露的威胁组织，更多关于该组织披露细节可查看”[曝光！涉俄APT组织“圣贤熊”针对军队、政府展开经济犯罪和间谍攻击](http://mp.weixin.qq.com/s?__biz=MzA5MDc1NDc1MQ==&mid=2247490168&idx=1&sn=f90a029f00e700be70ec50df8b7b563b&chksm=900781a8a77008be8de4bed9c2564814265f677ff9f00825f113dba8fd3035cd0449ca9bf2aa&scene=21#wechat_redirect)“。

**技术手法：**

在此次攻击活动中，攻击者通过投递包含附件的网络钓鱼电子邮件，以“拖欠工资”为主题诱使受害者打开包含恶意宏的文档附件，静默释放嵌入的名为“base-update.exe”的第一阶段有效载荷，然后，以 Base64 格式从攻击者服务器下载其他有效载荷和可执行文件。其中Elephant dropper 是此次攻击中部署的初始可执行文件，使用被盗的 Microsoft 证书进行签名，执行 Elephant Downloader 下载植入物 Elephant Implant（GrimPlant 后门） 。Elephant Implant 会收集遍历操作系统信息、用户信息、文件信息，与80端口进行通信传输。

#### **PEAR PHP 存储库被曝存在供应链攻击漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：PHP，供应链，漏洞  

**事件概述：**

PEAR PHP 存储库被曝存在安全漏洞（PEAR 是 PHP Extension and Application Repository 的缩写，是可重用 PHP 组件的框架和分发系统）。该漏洞可能允许攻击者进行供应链攻击，包括获得未经授权的访问权限以发布恶意程序包和执行任意代码。

*   其中一个缺陷是在2007年3月最初实现该功能时提交的代码中引入的，与密码重置功能中使用密码不安全的 mt\_rand() PHP 函数有关，该函数可能允许攻击者“发现有效密码”在不超过50次尝试中重置令牌。借助此漏洞，攻击者可以劫持现有的开发人员或管理员帐户并发布已由开发人员维护的软件包的新木马化版本，从而导致广泛的供应链入侵。
    
*   第二个漏洞需要攻击者将其与上述缺陷链接起来才能获得初始访问权限，它源于pearweb 对旧版本 Archive\_Tar 的依赖，该版本易受高严重性目录遍历错误漏洞 CVE-2020-36193 的影响，导致任意代码执行。
    

目前，PEAR 已发布相关漏洞补丁，并努力将补丁部署在生产环境中。
