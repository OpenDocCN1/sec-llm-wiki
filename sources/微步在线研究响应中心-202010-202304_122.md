#### **企业如何防御欺诈？反欺诈机制又该如何完善？**

现如今，金融行业和大量在线交易（电子商务）的企业大都制定了反欺诈计划。但随着攻击者和企业反欺诈者的不断适应和发展，企业可以采取哪些措施来改进他们的反欺诈机制呢？

1\. 增强智能：随着欺诈者和企业的适应和发展，欺诈者的策略和技术也会快速的发展迭代，但企业几乎不可能达到有效应对快速变化的威胁形势。克服这一问题的更好的方式是在增加团队的情报能力的同时，寻找方法以无缝自动化的方式将这种情报编织到反欺诈团队的日常运营中。2\. 补充遥测数据：企业也许会查看单个交易或一系列交易，或在日志数据中寻找已知的活动模式。这时候就凸显了遥测数据的价值，可以围绕各种不同的活动、请求和事务提供独特的见解和重要的上下文。这种洞察力和背景相结合，有助于支持更好的决策。换句话说，它们可以支撑更可靠的欺诈检测。3\. 改进决策：关于某种行为是否具有欺诈性的决定通常不是二元的。相反，某些东西是欺诈的可能性是基于许多不同因素的概率。与任何基于概率的决策一样，其质量和准确性取决于许多不同的因素，包括输入数据的质量和准确性，以及数据的广度和覆盖范围。因此，改进、扩充和补充用来计算哪些活动可能是欺诈的数据将帮助您更准确地检测和减轻欺诈。4\. 分析会话：正如您可能已经收集到的，仅检查应用程序中的单个事务或单个活动是不够的。相反，需要一种更全面的方法来理解整个会话中正在发生的事情。只有通过分析会话和他们提供的所有相关上下文，反欺诈团队才能摆脱误报的概率。5\. 消除自动化：机器人不仅仅是一个安全问题。他们本质上是欺诈的前线。因此，消除自动化可以极大的提升企业反欺诈能力。6\. 统一安全和反欺诈：随着现代企业对风险管理作为一个专业的理解越来越成熟，安全和反欺诈团队的统一才有意义。  
**来源：**https://www.securityweek.com/six-ways-expand-your-fraud-program

**透明部落组织使用定制的恶意软件瞄准印度官员展开间谍攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：APT，印度，透明部落  

**事件概述：**透明部落，也称为 APT36 和 Mythic Leopard，是疑似与巴基斯坦有关的威胁组织，在印度次大陆非常活跃，旨在针对阿富汗和印度的政府和军事人员有关的个人和实体展开攻击。近期，思科研究人员监测发现透明部落针对印度官员最新的间谍攻击活动，此活动至少从2021年6月开始，主要利用模仿合法政府和相关组织的虚假域来传递恶意负载，包括用于安装基于 .NET 的侦察工具和 RAT ，基于 Python 的 stager 以及基于 .NET 的植入程序，可在受感染的系统上执行任意代码。**技术手法：**威胁组织通过投递与 COVID-19、Kavach 等政府相关的不同内容的诱饵文档，诱使受害者下载可执行文件。其中一个下载器可执行文件伪装成 Kavach（这是一种印度政府强制要求的双因素身份验证解决方案），用于访问电子邮件服务，以传递恶意工件。攻击者将受害者重定向到伪装成合法的印度政府或伪政府实体的恶意网站，下载恶意有效载荷，然后在端点上激活该有效载荷。然后从另一个攻击者控制的网站下载 Kavach 应用程序的 MSI 安装程序的合法副本并执行。最后，Kavach 应用程序的虚假安装程序被用于部署 CrimsonRAT 和其他恶意软件。![](../Images/c9695f803548805e4b2fc2363014d46f.png)**来源：**  
https://blog.talosintelligence.com/2022/03/transparent-tribe-new-campaign.html  
**微步点评：**该组织主要使用以下三个基于 Windows 的恶意软件家族来针对其目标开展间谍活动：

*   CrimsonRAT是一种基于 .NET 的植入程序，至少自 2020 年以来一直是该组织的首选恶意软件。多年来，透明部落利用 CrimsonRAT 开展的多项活动表明植入物的能力正在稳步发展；
*   ObliqueRAT 是思科在2020年初发现的基于 C/C++ 的植入物。ObliqueRAT 主要用于针对政府人员的高度针对性攻击，以及在隐身于攻击者的感染链。随着时间的推移，这种植入物的部署策略和恶意功能也在不断演变；
*   与 CrimsonRAT 和 ObliqueRAT 相比，透明部落使用的自定义恶意软件包括可轻松快速部署的下载器、dropper 和包含有限功能的轻量级 RAT。

#### **谷歌商店应用程序再曝恶意软件，旨在窃取 Facebook 凭据**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：谷歌商店，恶意软件，凭据窃取

**事件概述：**

继谷歌商店曝出存在多款恶意软件后，谷歌商店于近日又被曝出木马化的应用程序 Craftsart Cartoon Photo Tools，捆绑 Facestealer Android 恶意软件，该应用程序下载量超100,000次。Facestealer 是一种已知的 Android 威胁，过去曾通过木马应用程序潜藏于谷歌商店。根据 Malwarebytes 分析指出，当应用程序首次启动时，它会将用户引导至合法的 Facebook 主登录页面，并要求用户登录后才能使用该应用程序。然后，注入的恶意 JavaScript 会窃取登录凭据并将其发送到攻击者命令和控制服务器。然后，攻击者利用窃取的凭据从受害者的 Facebook 帐户中提取信息，包括电子邮件地址和 IP 地址、电话号码、对话和消息历史记录、信用卡详细信息、朋友列表等。

截至3月21日，该款捆绑 Facestealer Android 恶意软件的应用程序 Craftsart Cartoon Photo Tools 仍可在官方商店访问。如果您的设备安装了该款应用程序，建议您删除该应用程序，确保设备安全。

#### **朝鲜威胁 Kimsuky  瞄准特定的国内公司展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：朝鲜，Kimsuky，APT

**事件概述：**

AhnLab  于近日监测到 Kimsuky 组织正瞄准国内特定的公司通过投递伪装成 PDF 文档的 VBS 脚本展开攻击。由于此种攻击迷惑性极高，研究人员建议用户禁用“隐藏已知文件类型的扩展名”功能，从某个源头避免成为伪装成 PDF 文档的 VBS 脚本攻击的受害者。

**技术手法：**

攻击者首先会投递一个伪装成 PDF 文档的 VBS 文件，这个文件在扩展名前添加了“.pdf” 以欺骗用户。由于默认选中“隐藏已知文件类型的文件扩展名”，受害者可能会认为该文件是一个 PDF 文件。当受害者执行该脚本文件时，页面会显示正常的 PDF 页面，恶意VBS 脚本会在“C:\\ProgramData”路径中创建并执行一个 BASE64 编码的 DLL，恶意 DLL 会创建一个cmd.exe 进程并等待与C&C服务器进行通信，执行收集系统信息、任务列表、whoami 、网络用户等命令信息。

外媒报道称 LAPSUS$ 勒索组织归来后，泄露了他们声称从软件服务公司 Globant 窃取的70GB的数据。泄露的屏幕截图包含了一个文件夹列表，列出了来自世界各地的不同公司，包括 Arcserve、Banco Galicia、BNP Paribas CardifCitibanamex、DHL、Facebook、Stifel 等公司的文件夹，还共享了一个 torrent 文件，据称包含大约 70GB 的 Globant 源代码以及与该公司的 Atlassian 套件相关的管理员密码，包括 Confluence 和 Jira，以及 Crucible 代码审查工具。
