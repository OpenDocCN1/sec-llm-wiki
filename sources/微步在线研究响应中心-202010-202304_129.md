#### **Check Point：移动应用程序正在泄露你的敏感数据**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：隐私安全，数据泄露，移动应用程序  

**事件概述：**

据 Check Point 一份新的研究表明，由于后端云数据库配置错误，拥有数千万下载量的移动应用程序正在泄露用户的敏感数据。Check Point 对 VirusTotal 展开为期三个月的查询研究，以查找与 Firebase 云数据库通信的恶意软件扫描服务中列出的移动应用程序，其中发现 2113 个移动应用程序的 Firebase 后端由于配置错误可能暴露用户的敏感数据。这些配置错误可能是开发人员在编写代码时，投入大量资源来强化应用程序以抵御多种形式的攻击的同时会忽略云数据库的正确配置，从而使实时数据库暴露在外，导致数据泄露；也有可能是开发人员经常手动更改安全规则的默认安全配置来运行测试，应用程序发布到生产环境之前未锁定且未受保护，导致任何人可以对数据库进行读写，造成敏感信息泄露。

**https://www.itsecurityguru.org/2022/03/17/your-mobile-apps-are-exposing-your-data/?utm\_source=rss

#### **俄罗斯证券交易网站遭到匿名者攻击，网站离线**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：俄罗斯，匿名者  

**事件概述：**

在2022年2月24日俄罗斯入侵乌克兰领土后，俄罗斯 IT 基础设施网站遭到匿名者等黑客的攻击。在匿名者发起的大规模 DDoS 攻击后，俄罗斯证券交易所、联邦安全局、联邦政府分析中心、联邦体育部的官方网站被迫离线，用户无法正常进行访问。

外媒称此次网络攻击发生在3月15日，是匿名者组织正在进行的名为 OpRussia 行动的一部分。该组织社交媒体代表 @YourAnonNews 还在推特上还公布了目标域及其当前服务状态。

截至外媒报道之前，俄罗斯证券交易所、FSB 、莫斯科国际门户网站 、俄罗斯联邦体育部、俄罗斯政府分析中心尚处于离线状态。

#### **国内某硕路由器成为 Cyclops Blink 僵尸网络最新受害者**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：僵尸网络，路由器  

**事件概述：**

近日，趋势科技报道称攻击者利用 Cyclops Blink 僵尸网络瞄准国内某硕公司路由器展开攻击，受害国家集中于美国、印度、意大利、加拿大以及俄罗斯，目标行业似乎不包含经济、军事或政治间谍活动明显价值的行业。Cyclops Blink 是用 C 语言编写的模块化恶意软件，疑似是俄罗斯背景的威胁组织 Sandworm 创建的僵尸网络。

**技术详情：**

Cyclops Blink 僵尸网络主要使用动态加载 OpenSSL 实现 AES-256 加密，并使用 TCP 协议上的随机端口与 C2 服务器进行 TLS 握手，传输数据，接收命令执行加载恶意软件等操作。

#### **谷歌商店木马渗透率激增，野外发现 WhatsApp 模块的 Android 木马**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：谷歌商店，木马，WhatsApp，Android  

**事件概述：**

继谷歌商店接二连三曝出存在恶意程序后，安全研究人员监测发现谷歌商店的木马渗透率激增。这些恶意应用程序大多数属于用于各种诈骗的木马恶意软件家族，可以导致用户经济损失以及个人敏感信息泄露。其中谷歌商店存在的恶意应用程序 Top Navigation 下载量超过500,000次，Advice Photo Power 应用程序下载量超过100,000次。此外，在野外发现了一个作为 WhatsApp 模块构建的新 Android 特洛伊木马 GBWhatsApp、OBWhatsApp 和  WhatsApp Plus，此类木马主要通过社交媒体帖子、论坛、 SEO 中毒推广和暗网传播。

**技术详情：**

在木马化的非官方 WhatsApp 版本中，捆绑的恶意软件会尝试通过 Flurry stat 服务从谷歌商店和三星商店应用程序中获取通知，从命令和控制服务器接收到的 URL 下载一个额外的 APK，并以 OBWhatsApp 更新的名义请求用户安装它。然后，这个新应用程序被用来显示任意对话框，具有远程动态设置和更新的功能，允许攻击者将用户重定向到恶意站点。  

![](../Images/878dc5f86bf245ed68edf2f5017dc683.png)   
**来源：  
**https://www.bleepingcomputer.com/news/security/android-trojan-persists-on-the-google-play-store-since-january/  
**微步点评：**

远离这些应用程序的前提是避免从不知名的来源下载 APK，检查用户评论，在安装时仔细检查权限请求，以及之后监控电池和互联网数据消耗。

#### **伊朗威胁组织 MuddyWater 瞄准土耳其和阿拉伯半岛展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：伊朗，MuddyWater，土耳其  

**事件概述：**

MuddyWater，也称为“MERCURY”或“Static Kitten”，是美国网络司令部最近归属于伊朗情报与安全部 ( MOIS ) 的 APT 组织。这个威胁组织至少从2017年开始活跃，经常在北美、欧洲和亚洲国家针对高价值目标开展间谍、知识产权盗窃、勒索软件攻击活动。近日，思科研究人员监测发现 MuddyWater 威胁组织瞄准土耳其和阿拉伯半岛展开攻击，旨在受感染的目标系统上部署远程访问木马 (RAT)。

**技术详情：**

威胁组织主要通过网络钓鱼消息传递的带有恶意软件的文档 maldoc ，maldoc 是一个包含恶意宏的 Excel 文件，旨在触发感染链在端点上放置两个 Windows 脚本文件 (.WSF)，其中第一个充当调用和执行下一阶段有效负载的工具，第二个为基于 WSF 的 远程访问木马 SloughRAT ，该木马能够执行从其命令控制服务器接收到的任意命令。

![](../Images/d51e8a7ffa965c066e0d2ff91211b349.png)  
**来源：**https://blog.talosintelligence.com/2022/03/iranian-supergroup-muddywater.html  

**微步点评：**

1、MuddyWater 组织类别属性：

*   间谍：收集可以通过帮助推进其政治、经济或国家安全利益而使伊朗受益的对手或地区合作伙伴的信息；
    
*   知识产权盗窃：窃取知识产权和其他专有信息使伊朗受益，包括帮助伊朗企业对抗竞争对手、影响州一级的经济政策决策，或为政府相关的研究和设计工作提供信息等。这些活动主要针对私人和政府实体，例如大学、智囊团、联邦机构和各种垂直行业；
    
*   勒索软件攻击：MuddyWater 此前曾尝试在受害者网络上部署勒索软件，例如 Thanos，以破坏其入侵证据或破坏操作。
    

2、MuddyWater 组织关联：

MuddyWater 和 Phosphorus（又名 APT35 和 Charming Kitten）威胁组织共享字符串，且这些团体分别归属于不同的伊朗国家组织 MOIS 和 IRGC。

#### **Linux 系统被曝存在“脏管道” 漏洞，可以为用户提供 Root 权限**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Linux，漏洞

**事件概述：**3月10日，美国 CISA 发布告警信息，称 Linux 内核存在脏管道漏洞 CVE-2022-0847，攻击者可以利用该漏洞提升用户权限。Linux 内核 5.8 及更高版本，5.16.11、5.15.25 和 5.10.102 固定版本均受该漏洞的影响。该漏洞允许非特权用户覆盖只读文件中的数据，能够将代码注入根进程，可能导致特权升级。3月7日，推特用户 blast 针对 Linux 内核存在的漏洞发表了 PoC，它通过劫持（和恢复）setuid 二进制文件的内容来生成 shell。该漏洞已在 Linux 5.16.11、5.15.25 和 5.10.102 中修复，建议 Linux 用户及时获取并更新更高版本。  
**来源：  
**https://blog.malwarebytes.com/exploits-and-vulnerabilities/2022/03/linux-dirty-pipe-vulnerability-gives-unprivileged-users-root-access/

#### **俄罗斯创建 TLS 证书机构以逃避制裁**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：俄罗斯，TLS证书  

**事件概述：**

近日，西方政府实施制裁以阻止俄罗斯网站更新现有的 TLS 证书，通过浏览器阻止访问证书过期的网站。基于对俄罗斯实施制裁的国家/地区的签署机构不再支持俄罗斯服务，这使得许多俄罗斯网站没有切实可行的手段来更新即将到期的证书。证书过期后，Google Chrome、Safari、Microsoft Edge 和 Mozilla Firefox 等 Web 浏览器页面将显示告警信息，这可能会使许多用户不再访问该站点。3月10日，外媒报道称俄罗斯为解决制裁阻止证书续订后堆积的网站访问问题，创建了自己的受信任的 TLS 证书颁发机构 (CA)，帮助 Web 浏览器确认域属于经过验证的实体，并且加密用户和服务器之间交换的信息。

Chrome 或 Firefox 等其他浏览器的用户可以手动添加新的俄罗斯根证书，以继续使用具有国家颁发证书的俄罗斯网站。然而，这可能引发攻击者滥用俄罗斯 CA 根证书来执行 HTTPS 流量拦截和中间人攻击的担忧。这种滥用最终会导致新的根证书被添加到证书撤销列表 (CRL) 中。外媒指出这些行为将切断俄罗斯与全球互联网的联系，并将俄罗斯网民推向“Runet”时代。

### ****针对乌克兰基础设施的网络钓鱼攻击激增****  
Avast 报道称在俄罗斯入侵乌克兰之前，观察到乌克兰网络空间中的网络钓鱼攻击数量增加，攻击主要针对网络基础设施硬件生产商、域管理员以及不同领域的服务和机构，例如运输、网络托管、招聘人员和营销人员平台。攻击者通过投递包含RAT（远程访问工具）和密码窃取恶意软件（如AgentTesla或FormBook）附件的网络钓鱼电子邮件，以发票和付款相关话题为主题展开攻击，基辅（36%）、敖德萨（29%）、利沃夫（6%）、马里乌波尔（5%）成为网络钓鱼攻击的重灾区。
