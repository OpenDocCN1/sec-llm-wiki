#### **金融行业网络威胁研究报告**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：金融行业

**事件概述：**

近日，微步情报局从威胁情报视角出发，对金融行业机构真实环境中所面临的整体网络威胁进行深度统计分析并探究部分真实行业威胁事件，致力于为金融行业客户伙伴输出情报侧发现的威胁态势，为整体网络安全防御体系建设提供参考依据。本篇专题研究报告发现金融机构当前面临的网络威胁简要概括如下：

*   金融机构生产运营过程中面临着大批量的网络攻击活动，其中以源自互联网侧的网络渗透攻击为主、其次为钓鱼邮件攻击；
    
*   金融机构内部主机失陷占比最多的是挖矿木马，其次是僵尸网络及其下载衍生的各类家族木马，勒索病毒和 APT 类攻击占比最小，但依然存在真实攻击案列发生；
    
*   金融机构普遍存在内部网络资产暴露、敏感数据泄露等互联网侧威胁，黑客组织对金融机构敏感数据的兴趣逐渐升温；
    
*   金融机构供应链安全问题形势严峻，传统的网络、服务、运维等安全信任体系值得反思。
    

上篇主要讲述金融行业背景，基于互联网侧攻击态势分析、失陷主机统计分析、互联网暴露面及数据泄露统计分析等情报侧风险发现，阅读可查看“[专题报告|金融行业网络威胁研究（上）](http://mp.weixin.qq.com/s?__biz=MzA5MDc1NDc1MQ==&mid=2247492114&idx=1&sn=85b7906756b1d00c78363a36755d975a&chksm=900479c2a773f0d4b689b928d3e3cf8d5944a4029eaf549942b30e546e133c6c977745c92a37&scene=21#wechat_redirect)；下篇主要讲述全球金融行业网络威胁态势，基于金融企业安全建设现状分析、金融企业实战化能力提升典型实践案例提升企业网络安全实战化能力，阅读可查看“[专题报告|金融行业网络威胁研究（下）](http://mp.weixin.qq.com/s?__biz=MzA5MDc1NDc1MQ==&mid=2247492284&idx=1&sn=5fa58d5261c9497e65743817abf5b682&chksm=9004796ca773f07a11b26890b93b58642b4398052e8db71defbb086aa9d2adbb114eaceb667f&scene=21#wechat_redirect)。

#### **谷歌商店被曝存在伪装成 Android 防病毒软件的 SharkBot 银行木马**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：SharkBot，Android，谷歌商店  

事件概述：近日，NCC Group 研究人员在谷歌商店发现了一款伪装成具有系统清理功能的防病毒软件的 SharkBot 银行木马。该木马于2021 年10月首次发现，与其他银行木马不同的是可以通过模拟受感染设备上的触摸/点击按钮实现从自动转账系统 (ATS) 转账，拦截新通知并直接回复信息。截至撰写文章时，该木马仍然存在于谷歌商店中。**技术详情：**SharkBot 银行木马通过滥用 Android 设备的 Accessibility 权限，监测应用程序使用情况。当用户打开银行应用程序时，SharkBot 银行木马执行匹配的网络注入，窃取用户凭据，并从 C2 服务器接收命令以执行发送短信、更新配置文件、卸载应用程序、关闭AV工具等恶意操作。

#### **DanaBot 恶意软件针对乌克兰国防部进行 DDoS 攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：DanaBot，国防部，乌克兰，邮件服务  

**事件概述：**

3月2日，在俄罗斯入侵乌克兰期间，Zscaler 研究人员监测发现攻击者利用 DanaBot 恶意软件瞄准乌克兰国防部网络邮件服务器发起了基于 HTTP 的分布式拒绝服务 (DDoS) 攻击。DanaBot 于2018年首次被发现，是一个恶意软件即服务平台，旨在窃取凭据和进行银行欺诈。

研究人员认为此次攻击活动无论从时间还是目标角度出发，与2022年俄罗斯入侵乌克兰有着密不可分的联系，但目前尚不清楚这是否是个人黑客行为还是国家支持的行为，亦或许可能是假旗操作。如果攻击者的动机是攻击乌克兰，那么除了 DDoS 攻击之外，攻击者很可能还在使用 DanaBot 更典型的功能进行攻击，例如针对任何相关受害者进行凭证盗窃和文件窃取。

![](../Images/fd25bbce2838e8ceba1a892535b40351.png)

#### **罗马尼亚石油供应商Rompetrol疑似遭Hive勒索软件袭击，网站和应用程序暂停服务**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：石油供应商，Hive，勒索软件

**事件概述：**  
3月7日，罗马尼亚石油供应商 Rompetrol 证实遭到网络攻击，为保护数据安全，该公司暂时暂停了网站和 Fill&Go 应用程序的运营。攻击者疑似还入侵了 Rompetrol 的炼油厂 Petromidia，但 Petromidia 运营疑似未受到影响。据外媒 BleepingComputer 称 Hive 勒索软件团伙疑似是此次攻击的幕后黑手， 此勒索软件团伙要求 Rompetrol 石油供应商支付200万美元的赎金，以获取解密器并保证不泄露窃取的数据。

截至目前，Rompetrol 和其母公司 KMG International 网站均无法正常访问，但 Rompetrol 加油站可以正常运营，客户可以选择现金或银行卡付款。KMG  International 已向罗马尼亚国家网络安全局 (DNSC)报告此次攻击事件，以寻求帮助解决问题。

#### **FBI：RagnarLocker 勒索软件变种至少入侵了52个美国关键基础设施实体**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：RagnarLocker，勒索软件，美国，关键基础设设施

**事件概述：**

近日，美国 FBI  和 CISA 联合发布告警信息，称 Ragnar Locker 勒索软件团伙已经破坏了10个关键基础设施部门的至少52个实体组织的网络，包括关键制造业、能源、金融服务、政府和信息技术部门等。Ragnar Locker 勒索软件团伙自2019年12月下旬以来一直处于活跃状态，主要通过更改其工具、技术和程序 (TTP) 以保持隐藏状态。但据联邦调查局透露该组织通常使用 VMProtect、UPX 和自定义打包算法，在受害者的站点上部署自定义 Windows XP 虚拟机。RagnarLocker 勒索软件遍历所有正在运行的服务，并终止托管服务提供商通常用于远程管理网络的服务，然后尝试静默删除所有卷影副本，从而阻止用户恢复加密文件。

**来源：  
**https://www.ic3.gov/Media/News/2022/220307.pdf

**微步点评：**

缓解此类攻击的措施：

*   离线备份关键数据；
    
*   确保关键数据的副本位于云端或外部硬盘驱动器或存储设备；
    
*   保护您的备份并确保无法从数据所在的系统访问数据以进行修改或删除；
    
*   使用具有强密码的多因素身份验证，包括远程访问服务；
    
*   保持计算机、设备和应用程序的补丁和最新；
    
*   监控有关泄露 VPN 登录凭据的发布以及更改密码和设置的网络威胁报告；
    
*   考虑为从组织外部收到的电子邮件添加电子邮件横幅；
    
*   禁用未使用的远程访问/远程桌面协议 (RDP) 端口并监控远程访问/RDP 日志；
    
*   审核具有管理权限的用户帐户，并以最低权限配置访问控制；
    
*   实施网络分段。

阿根廷电子商务巨头 Mercado Libre 总部位于布宜诺斯艾利斯，是拉丁美洲最大的电子商务和支付生态系统。该公司拥有约 1.4 亿独立活跃的用户，业务遍及阿根廷、巴西、墨西哥、哥伦比亚、智利、委内瑞拉和秘鲁等 18 个国家。近日，Mercado Libre 称攻击者未经授权访问了其部分源代码和约30万用户的敏感数据、Mercado 的 IT 基础设施似乎没有受到入侵事件的影响。但勒索组织 Lapsus$ 称其已经访问了 MercadoLibre 和 Mercado Pago 的 24,000 个源代码存储库。

#### **TA416 组织利用 PlugX 变体瞄准欧洲政府实体展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：TA416，APT，PlugX，欧洲

**事件概述：**

随着乌克兰、俄罗斯冲突升级，Proofpoint 研究人员监测发现 TA416 威胁组织加快了针对欧洲政府外交实体、参与难民和移民服务的个人的攻击行动，且该组织目标方向与俄罗斯和乌克兰之间的紧张局势和现在的武装冲突吻合。TA416 组织通过 Web 漏洞来攻击受害者，然后通过电子邮件中的恶意 URL 投递各种更新后的 PlugX 恶意软件有效载荷。从历史上看，该组织主要提供网络漏洞 URL 和恶意软件 URL 以投递恶意软件。2022 年，该组织开始转变为分析用户，然后以社工的方式提供恶意软件 URL。这疑似是 TA416 组织在提升防御规避能力的尝试。 

**技术详情：**

从2021年11月初开始，该组织通过使用合法的电子邮件营销服务 SMTP2Go 冒充联合国大会秘书处会议服务助理向目标投递电子邮件，然后通过 DropBox URL 提供 PlugX 恶意软件。

**组织关联：**

TA416 与公开披露的集团“Red Delta”之间存在重叠。2020年8月和2021年 11 月的两次活动都针对欧洲外交实体，都利用 SMTP2Go 冒充可能与最终目标通信的外交组织展开攻击。

#### **惠普修复了影响笔记本电脑、台式机、PoS 系统的 UEFI  固件的16 个严重漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：惠普，UEFI，严重漏洞

**事件概述：**

网络安全公司 Binarly 研究人员在影响多个惠普企业设备的统一可扩展固件接口 (UEFI) 固件的各种设施中发现了16个高严重性漏洞：CVE-2021-39297、CVE-2021-39298、CVE-2021-39299、CVE-2021-39300、CVE-2021-39301、CVE-2021-23924、CVE-2021-23925、CVE-2021-23926、CVE-2021-23927、CVE-2021-23928、CVE-2021-23929、CVE-2021-23930、CVE-2021-23931、CVE-2021-23932、CVE-2021-23933、CVE-2021-23934。其中最严重的漏洞是影响固件系统管理模式 (SMM) 的内存损坏漏洞。笔记本电脑、台式机、销售点系统等多个惠普企业设备均受到这些漏洞影响。攻击者可以通过触发这些漏洞最高权限执行任意代码，并提供持久的恶意代码。这些代码在操作系统重新安装后仍然存在，并允许绕过端点安全解决方案 (EDR/AV) 、安全启动和基于虚拟化的安全隔离。

惠普已在2月份发布的 HP UEFI 固件更新修复了这些漏洞。

#### **俄乌战争冲突升级之际，新的擦除软件 RURansom Wiper 瞄准俄罗斯展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：wiper，RURansom，俄罗斯  

**事件概述：**

俄罗斯和乌克兰战争升级之际，网络战争也在如火如荼的进行当中。乌克兰机构在陆续感染了伪装成勒索软件的擦除器 WhisperGate 和 Hermetic Wiper擦除器后，趋势科技于近日披露加入了战争行列的新擦除软件 RURansom Wiper，该擦除器主要瞄准俄罗斯展开攻击。RURansom Wiper 使用 .NET 编程语言编写，通过以“Россия-Украина\_Война-Обновление.doc.exe”文件名将自身复制到所有可移动磁盘和映射的网络共享系统中，以蠕虫病毒的形式传播，使用硬编码 AES-CBC 加密。RURansom Wiper 加密文件的密钥都是唯一的，并且不会存储在任何地方，这使得加密不可逆。

与此同时，研究人员还发现了几个版本的 RURansom，其中一些版本会检查启动软件的 IP 地址是否在俄罗斯：如果该软件在俄罗斯境外发布，这些擦除器版本将停止执行。RURansom Wiper 开发人员疑似在俄乌战争中选择了乌克兰战队。
