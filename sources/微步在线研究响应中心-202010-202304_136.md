#### **专题报告 | 金融行业网络威胁研究(上)**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：金融专题，威胁态势、安全防御体系  

**事件概述：**  

金融行业作为网络安全防御体系建设要求最高、投入资力最大、现今网络安全建设落地最为健全的特殊群体，一直都是重点关注、研究的行业之一。基于微步在线已有的海量情报数据、金融行业客户积累，我们从威胁情报视角出发，对金融行业机构真实环境中所面临的整体网络威胁进行深度统计分析并探究部分真实行业威胁事件，致力于为金融行业客户伙伴输出情报侧发现的威胁态势、为整体网络安全防御体系建设提供参考依据。本篇专题研究报告发现金融机构当前面临的网络威胁简要概括如下：

*   金融机构生产运营过程中面临着大批量的网络攻击活动，其中以源自互联网侧的网络渗透攻击为主、其次为钓鱼邮件攻击；
    
*   金融机构内部主机失陷占比最多的是挖矿木马，其次是僵尸网络及其下载衍生的各类家族木马，勒索病毒和 APT 类攻击占比最小，但依然存在真实攻击案列发生；
    
*   金融机构普遍存在内部网络资产暴露、敏感数据泄露等互联网侧威胁，黑客组织对金融机构敏感数据的兴趣逐渐升温；
    
*    金融机构供应链安全问题形势严峻，传统的网络、服务、运维等安全信任体系值得反思。

#### **保险业巨头 AON 遭受网络攻击，系统受到影响**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：保险业，AON  

**事件概述：**

AON 是全球最大规模的保险业集团，提供广泛的解决方案，包括商业保险、再保险、网络安全咨询、风险解决方案、医疗保险和财富管理产品。近日，AON 在提交给美国证券委员会的信息中披露了网络攻击，部分系统由于攻击事件受到影响，但并未对 AON 运营产生严重影响。AON 在2月25日发现网络攻击，第一时间聘请了第三方协助展开调查。根据目前调研的信息，AON 表示此次网络攻击事件不会对公司业务、运营和财务状况产生严重的影响。

保险业一直以来都是网络攻击组织最中意的目标，因为保险公司提供的目标支付赎金的可能性会更大。早在2021年，保险巨头 CNA 就曾是 Evil Corp 勒索软件组织攻击的目标，该组织在当时支付了巨额赎金以防止数据泄露。

#### **俄罗斯国防部疑似遭到匿名者组织入侵，员工数据发生泄露**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：俄罗斯，国防部，匿名者，数据泄露  

**事件概述：**

继俄罗斯与乌克兰战争爆发后，匿名者组织于2月25日宣布对俄罗斯开展网络战争。26日，俄罗斯媒体网站“今日俄罗斯通讯社”下线，匿名者组织在其 Twitter上发表声明称已成功入侵俄罗斯国防部网站的数据库。此外，克里姆林宫 ( Kremlin.ru ) 的网站也无法正常访问，俄罗斯政府的门户网站和其他部委的网站运行速度减慢，但尚不清楚这是否为匿名者组织攻击的结果。

匿名者组织还对那些支持乌克兰军事行动的国家发起了攻击，泄露了白俄罗斯武器制造商 Tetraedr 约 200GB 的电子邮件（这家公司为弗拉基米尔·普京入侵乌克兰提供了后勤支持），GazpromEN 网站被迫下线等。该组织指出他们发动这一系列的攻击不是针对俄罗斯公民，而是针对俄罗斯政府展开的报复。

**BlackCat 勒索软件瞄准德国石油公司 Oiltanking 和 Mabanaft 展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：BlackCat，勒索软件  

**事件概述：**

近日，AT&T Cybersecurity  发布报告，称攻击者于2022年1月29日使用 BlackCat 勒索软件瞄准总部位于德国的石油公司 Oiltanking 和 Mabanaft 展开攻击，此次攻击事件并没有对 Oiltanking 和 Mabanaft 客户产生严重影响。但壳牌石油公司因为此次攻击被迫改变供应路线，以避免对德国燃料供应造成严重影响，但德国的233个加油站疑似因此次攻击事件受到影响，这些加油站其中一些流程不得不手动操作，接受现金支付。

BlackCat 是一款用 Rust 编程语言编写的勒索软件，于2021年11月中旬首次出现，针对多个平台（Windows 和 Linux）展开攻击，并使用代码来感染 VMware  ESXi 虚拟机管理程序。该组织主要通过“耻辱墙”网站来敲诈受害者，公开宣传他们最新的攻击活动。

截至文章发表时，AT&T Cybersecurity 已监测发现 BlackCat 勒索软件组织在2月的多起攻击活动。  

**来源：**https://cybersecurity.att.com/blogs/labs-research/blackcat-ransomware

**微步点评：**  
1、BlackCat 勒索软件具备复杂性、高严重性、三重勒索等特点。

2、BlackCat 勒索软件与 LockBit 共享基础架构，并使用与 LockBit 勒索软件类似的工具和命名方法。3、Oiltanking 是石油产品、化学品和气体的油库码头的物流服务提供商。该公司成立于1972年，是 Marquard＆Bahls AG 的子公司，总部位于德国汉堡。它在23个国家/地区拥有并运营着70个码头，总存储容量超过2000万立方米。

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：英伟达，勒索软件  

**事件概述：**  
美国芯片制造商巨头英伟达于近日疑似遭到 Lapsus$ 勒索软件攻击，开发人员工具和电子邮件系统在内的部分系统出现瘫痪，但英伟达的业务和商业活动并未受到影响。2月26日，受影响的部分电子邮件系统开始恢复正常工作。与此同时， Lapsus$  勒索组织声称他们破坏了英伟达网络，从中窃取了包含最新 Nvidia GPU 的完整芯片、图形和计算机芯片组文件信息的 1 TB数据，并且还在网上公开了英伟达员工的密码哈希值。

#### **微软官方商店被曝存在 Electron Bot 恶意软件，约 5,000 台计算机受到感染**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：微软商店， Electron Bot

**事件概述：**近日，Check Point 研究人员监测发现了一款恶意软件 Electron Bot，该恶意软件主要通过克隆 Subway Surfer 和 Temple Run 等流行游戏潜入微软官方商店，旨在 SEO 中毒攻击、社交媒体账户推广、广告点击欺诈、在线产品促销。该恶意软件于2018年底首次被发现，是一个后门，其功能在不断的演变和增加，支持远程命令执行和实时交互。截至目前，瑞典、以色列、百慕大和西班牙的约 5,000 台计算机受到 Electron Bot 感染。**技术详情：**

感染链始于受害者从微软官方商店中安装其中一个 laced 应用程序，受害者启动应用程序后，后台动态加载 JavaScript 投放器以获取 Electron Bot 有效负载并安装它。恶意软件会在系统下次启动时连接到 C2（Electron Bot\[.\]s3\[.\]eu-central-1\[.\]amazonaws.com 或 11k\[.\]online），检索其配置并执行任意命令。

![](../Images/87e7c1c239cec5df0c7282125fdb8515.png)

**来源：**  
https://research.checkpoint.com/2022/new-malware-capable-of-controlling-social-media-accounts-infects-5000-machines-and-is-actively-being-distributed-via-gaming-applications-on-microsofts-official-store/  
**微步点评：**如果您的设备不幸被感染，建议执行以下步骤操作清理感染及其上的恶意软件：

1、删除从 Microsoft Store 下载的应用程序；

*   转到设置 > 应用程序
    
*   在列表中找到应用程序并选择卸载
    

2、删除恶意软件的包文件夹；

*   查找目录：C:\\Users\\<username>\\AppData\\Local\\Packages
    
*   然后查找 Microsoft.Windows.SecurityUpdate\_cw5n1h2txyewy 和
    

Microsoft.Windows.Skype\_cw5n1h2txyewy ，并将其删除

3、从 Start Up 文件夹中删除关联的 LNK 文件。

*   查找目录：C:\\Users\\<username>\\AppData\\Microsoft\\Windows\\Start Menu\\Programs\\Startup
    
*   然后查找名为 Skype.lnk 或 WindowsSecurityUpdate.lnk 的文件并将其删除

#### **TiltedTemple  APT 使用 SockDetour 后门瞄准美国国防承包商展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：TiltedTemple ，APT，SockDetour，美国国防承包商  

**事件概述：**近日，国外安全厂商 Unit 42 发表报告披露 TiltedTemple  APT 使用 SockDetour 后门瞄准美国国防承包商展开攻击。该组织最早活跃于2021年7月，主要针对全球范围内的技术、能源、医疗保健、教育、金融和国防行业等组织。SockDetour 是一个以 64 位 PE 文件格式编译的自定义后门，旨在用作备用后门，以防止主要后门被检测与删除。它适用于运行带有侦听 TCP 端口服务的 Windows 操作系统，劫持与预先存在的网络套接字建立的网络连接，并通过套接字与远程威胁参与者建立加密的 C2 通道。SockDetour 既不需要打开监听端口来接收连接，也不需要调用外部网络来建立远程 C2 通道，极大的提升了其防御规避的能力。**技术详情：**攻击者使用 Donut 框架将 SockDetour 注入目标进程后，后门会利用 Microsoft Detours 函数库（该库旨在监视和检测 Windows 上的 API 调用以劫持网络套接字）调用 DetourAttach() 函数进行挂钩，当新连接到服务端口并调用 Winsock accept() API 函数时，对 accept() 函数的调用被重新路由到 SockDetour 中定义的恶意绕行函数。其他非 C2 流量返回原服务进程，保证目标服务正常运行，不受干扰。SockDetour 由此便能够在受感染的 Windows 服务器中无文件和无套接字地运行，并作为备用后门，以防止安全软件检测并删除主后门。

#### **VoIPmonitor 监控软件被曝存在多个严重安全漏洞**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：VoIPmonitor ，严重漏洞  

**事件概述：**VoIPmonitor 是一款在 Linux 上运行 SIP RTP 和 RTCP VoIP 协议具有商业前端的开源网络数据包嗅探器。近日，研究人员在 VoIPmonitor 软件中发现了多个严重的安全漏洞。如果成功利用该漏洞，未经身份验证的攻击者可以将权限提升到管理员级别并执行任意命令。漏洞信息如下：

*   CVE-2022-24259：GUI 的“cdr.php”组件中的身份验证绕过漏洞，未经身份验证的攻击者能够通过特制请求提升权限；
*   CVE-2022-24260：一个 SQL 注入漏洞，发生在 GUI 的“api.php”和“utilities.php”组件中，允许攻击者将权限提升到管理员级别并检索敏感数据；
*   CVE-2022-24262：由于缺少对存档文件格式的检查，通过 GUI 的配置恢复功能执行远程命令，允许不良行为者通过精心制作的文件执行任意命令。

研究人员在发现漏洞后立即向相关厂商报告了漏洞信息，VoIPmonitor 研究人员在2022年1月11日发布的 WEB GUI  24.97版本中对漏洞进行了修复。

https://thehackernews.com/2022/03/critical-security-bugs-uncovered-in.html
