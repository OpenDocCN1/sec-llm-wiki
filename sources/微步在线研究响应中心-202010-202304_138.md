**网络攻击的下一个主要浪潮：开源代码攻击**

开源软件现已成为技术创新的绝佳驱动力，但开源软件的普遍存在也带来了重大的安全风险。开源攻击方法对网络犯罪分子极具吸引力，因为它可以广泛且高效展开攻击。攻击者可以使用各种方法来混淆对开源项目做出的恶意更改，并且安全隐患的审查代码也会因项目而异。如果没有严格的控制措施来检测这些恶意更改代码，这些问题可能会被忽视，直至恶意更改后的代码被分发到众多公司，然后大规模曝发安全问题。开源代码仿佛也成为了网络攻击的下一个主要浪潮。然而，通过完全放弃开源避免开源攻击是不现实的，因为所有现代软件几乎都是由开源组件构建的。

与避免使用开源不同，更现实的方法是让安全和软件团队合作开发用于测试应用程序和软件组件的策略和流程及除了全行业努力保护基于开源代码构建的软件免受网络威胁外，组织还必须对其防御战略采取内部积极主动的方法，包括为自己开发的代码和所依赖的开源代码实施测试和控制程序，制定内部政策和指南，以识别使用开源软件的风险，并确定用于管理该风险的控制措施。这样做既可以使企业能够继续利用开源代码的优势，同时也可创建一个能够抵御未来攻击的环境。

**https://www.darkreading.com/vulnerabilities-threats/open-source-code-the-next-major-wave-of-cyberattacks

#### **新网络钓鱼活动：攻击者瞄准英国纯数字银行平台 Monzo 用户展开欺诈**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：网络钓鱼，Monzo，英国

**事件概述：**Monzo 是英国最受欢迎的纯数字银行平台之一，拥有超过400万客户。近日，Monzo 在 Twitter 发布推文称需警惕伪装成 Monzo 的网络钓鱼欺诈活动。该活动旨在通过诱使受害者点击链接验证账户，窃取信息，并接管受害者的 Monzo 账户。微步友情提醒您，Monzo 会通过应用程序或官方门户网站发布通知信息，不会使用 SMS 发送通知信息，也不会敦促用户点击应用程序外部的任何链接。**技术详情：**攻击者通过向目标用户投递伪装成来自  Monzo 的钓鱼邮件，诱使收件人点击链接将受害者重定向到虚假电子邮件登录的网络钓鱼站点，诱使受害者输入包括全名、电话号码和 Monzo PIN 的 Monzo 的账户信息，然后接管 Monzo 账户信息，获取 Monzo 账户的全部访问权限。

#### **乌克兰DDoS攻击背后黑手疑似浮出水面，白宫和英国政府将矛头直指俄罗斯情报机构**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：DDoS，乌克兰，GRU，俄罗斯

**事件概述：**

近日，外媒发表报道称白宫和英国政府将乌克兰大规模 DDoS 攻击与俄罗斯武装部队总参谋部（GRU）联系起来。美国国家网络安全顾问称俄罗斯威胁组织可能已将包括军事和关键基础设施网络在内的乌克兰政府作为目标，为收集情报和破坏性网络活动做好了准备，并且称俄罗斯政府应对乌克兰银行、政府机构遭遇的大规模 DDoS 攻击负责，因为已知的 GRU 基础设施向乌克兰的 IP 地址和域传输了大量的通信信息。英国政府也指出俄罗斯 GRU 是针对乌克兰的 DDoS 攻击的幕后黑手。随后，乌克兰情报机构网络安全负责人公开指责俄罗斯威胁组织 Gamaredon 与俄罗斯联邦安全局（FSB）协调了针对乌克兰银行和政府机构网站的大规模 DDoS 攻击。

#### **思科电子邮件安全设备产品受到严重 DoS 漏洞的影响**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：思科，DoS漏洞，ESA

**事件概述：**  
近日，思科发表公告称其电子邮件安全设备(ESA)受到漏洞 CVE-2022-2065 的影响。该漏洞是一个 DoS 漏洞，是由 DNS 名称解析中的错误处理不足导致的，目前该漏洞没有被恶意利用。攻击者可以无需身份验证即可远程利用该漏洞，通过发送由受影响的设备处理的特殊格式电子邮件信息来利用这个漏洞，导致电子邮件设备系统崩溃。思科还指出该漏洞只影响启用了 DANE 功能和配置为发送退回邮件的下游邮件服务器的设备，而思科电子邮件安全设备一般默认情况下不启用 DANE 功能。此外，思科还建议客户及时更新或打补丁，以防止潜在的漏洞利用。

**来源：**  
https://www.securityweek.com/malicious-emails-can-crash-cisco-email-security-appliances

#### **美国伊利诺伊州近15万名居民的健康信息遭泄露**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：数据泄露，美国

**事件概述：**美国伊利诺伊州近15万名居民的健康信息 (PHI) 在芝加哥南岸医院 ( SSH ) 和伊利诺伊州哈维的家庭基督教健康中心 ( FCHC ) 的数据泄露中暴露。SSH 于2021年12月10日发现恶意攻击行为，立即聘请了一家第三方数字取证公司来调查该活动并启动其紧急网络安全预案。经调查发现一些离职和现任医院患者和员工的数据可能已被未经授权的第三方访问，可能暴露的数据包括姓名、地址、出生日期、社会安全号码、健康保险信息、诊断、医疗保险和医疗补助信息以及财务信息。截至目前，SSH 并没有透露事件的确切性质，也没有说明在攻击期间是否有任何文件被泄露。 但 SSH 将为此次数据泄漏事件所有受影响的个人提供免费的身份盗窃保护服务。

#### **俄罗斯威胁组织 Sandworm 使用  Cyclops Blink 恶意软件展开大规模攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Sandworm，APT，俄罗斯，Cyclops Blink

**事件概述：**

美国和英国网络安全和执法机构于2月23日发布告警信息，称与俄罗斯情报机构有关联的威胁组织 Sandworm 利用恶意软件框架 Cyclops Blink 替换 VPNFilter ，并将 Cyclops Blink 部署到家庭办公室和小型网络防火墙硬件制造商 WatchGuard 的 Firebox 设备。该恶意软件通过虚假固件更新进入设备，并且即使在具有真实固件更新后仍可以在机器上持续存在，以 VPNFilter 相似的方式运行，并通过自定义僵尸网络传播。VPNFilter 曾被 Sandworm 组织用于2015年袭击乌克兰事件和2018年奥运会攻击事件。在2018年被思科研究人员曝光 VPNFilter 后，Sandworm 组织转向使用 Cyclops Blink 替换被披露的 VPNFilter。

![](../Images/9285cc026e26c547a433236875cd0740.png)  
**来源：  
**https://www.ncsc.gov.uk/files/Cyclops-Blink-Malware-Analysis-Report.pdf  
**微步点评：**1、Sandworm，也称为 Telebots，是影响工业控制系统的最危险的俄罗斯威胁参与者之一。该组织隶属于俄罗斯的主要情报局 (GRU)，对数以千计的美国和国际公司、组织、政治运动和政府进行了多次攻击。2、Sandworm目标行业：教育、能源、政府和电信。3、Sandworm目标国家：阿塞拜疆、白俄罗斯、格鲁吉亚、伊朗、以色列、哈萨克斯坦、吉尔吉斯斯坦、立陶宛、波兰、俄罗斯和乌克兰。4、Sandworm 工具：BlackEnergy、 Gcat、 PassKillDisk和 PsList。

#### **TunnelVision  组织利用 Log4j 漏洞部署勒索软件展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：TunnelVision，Log4j，勒索软件

**事件概述：**TunnelVision  组织是一个与伊朗政府结盟的威胁组织，主要活跃于美国和中东等地区。由于该威胁组织严重依赖隧道工具，以及它选择广泛部署这些工具的独特方式，SentinelLabs 将该组织活动命名为 TunnelVision。TunnelVision 组织正在广泛利用 1day 漏洞、Fortinet FortiOS (CVE-2018-13379)、Microsoft Exchange (ProxyShell) 和Log4j2  漏洞来获得对目标网络的初始访问权限以进行后期利用，运行恶意 PowerShell 命令、部署后门、创建后门用户、获取凭据并执行横向移动，用勒索软件感染未修补的 VMware Horizon 服务器。**组织关联：**

*   TunnelVision 战术与Phosphorus、 Charming Kitten 和 Nemesis Kitten 战术广泛重叠。
