#### **Anomali : 2022年企业组织面临的十大网络安全挑战**

据2022年网络安全洞察报告研究表明，87%的受访组织表示在过去三年中曾遭受网络攻击。而随着威胁的复杂程度逐步提高，组织缺乏威胁情报来识别威胁，数字化转型也不断增加了攻击面，企业也将面临越来越多的网络安全挑战。Anomali 最近发布的报告《2022 年网络安全洞察报告：网络弹性状态》确定了企业面临的十大安全挑战：

*   密切关注新出现的全球网络安全威胁；
    
*   数字化转型的速度和复杂性；
    
*   利用最新的网络安全解决方案（例如 XDR）；
    
*   缺乏熟练的网络安全专业人员；
    
*   未针对面临的风险类型定制解决方案；
    
*   缺乏集成的网络安全解决方案；
    
*   缺乏跨职能共享威胁情报的能力；
    
*   未充分利用支持调查的框架；
    
*   缺乏威胁情报信息；
    
*   对网络风险认识不足。
    

网络攻击变得越来越频繁，破坏性也越来越大，企业在不断面临新的挑战，网络安全专业人员需要适应不断变化的威胁形势以应对新的挑战。

#### **韩国加密货币平台 KLAYswap 用户遭 BGP 劫持，价值190万美元的加密货币失窃**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：加密货币，BGP劫持，韩国  

**事件概述：**2月3日，韩国加密货币平台 KLAYswap 被曝价值190美元的加密货币被盗，约325个钱包发生407笔异常交易。此次货币失窃事件是由于外部站点的 SDK 文件感染导致的，而不是 Klayswap 前端源代码和智能合约安全问题。据 KLAYswap 称，此次攻击持续了两个小时，Klayswap 为防止攻击造成进一步损害，将加密平台所有功能进行封锁和紧急检查，并表示将尽快对受影响的用户进行通知和赔偿。**技术详情：**此次攻击与大多数加密货币平台被黑客入侵的方式截然不同，大多数加密货币抢劫是攻击者破坏员工账户或破坏平台代码从受害者账户窃取资金，而此次攻击黑客的目标不是 KLAYswap 本身，而是使用 BGP 劫持提供恶意版本的 KakaoTalk 的 JavaScript SDK 文件，监控 KLAYswap 网站交易，劫持资金并将用户的资产发送到攻击者控制的钱包。![](../Images/5491c68037ad6928a733396f87dc9d62.png)

#### **FBI：美国关键基础设施遭到 BlackByte 勒索软件入侵**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：关键基础设施，美国，BlackByte，勒索软件  

**事件概述：**近日，据美国联邦调查局 FBI 透露，BlackByte 勒索软件组织在过去三个月中至少入侵了三个美国关键基础设施领域的网络。在此期间，BlackByte 勒索软件组织还声称窃取了49ers足球组织服务器上的数据。BlackByte 是一个勒索软件即服务 (RaaS) 组织，旨在加密受感染的 Windows 主机系统上的文件，包括物理和虚拟服务器。该勒索软件组织至少从2021年7月开始就一直活跃，针对全球企业展开攻击，以利用软件漏洞（包括 Microsoft Exchange Server）来获得对其企业目标网络的初始访问权限而闻名。  

**来源：  
**https://www.ic3.gov/Media/News/2022/220211.pdf

**微步点评：**

缓解 BlackByte 攻击的措施

*   对所有数据进行定期备份；
    
*   实施网络分段；
    
*   在所有主机上安装并定期更新杀毒软件，并启用实时检测；
    
*   更新/补丁发布后立即安装更新/补丁操作系统、软件和固件；
    
*   查看域控制器、服务器、工作站和活动目录中是否有新的或无法识别的用户帐户；
    
*   审核具有管理权限的用户帐户，并以最低权限配置访问控制，不要授予所有用户管理权限；
    
*   禁用未使用的远程访问/远程桌面协议 (RDP) 端口并监控远程访问/RDP 日志以查找任何异常活动；
    
*   禁用收到的电子邮件中的超链接；
    
*   登录帐户或服务时使用双重身份验证；
    
*   对所有账户进行例行审计；
    
*   确将所有已识别的 IOC 输入到网络 SIEM 以进行持续监控和警报。

#### **ModifiedElephant APT 组织针对印度人权主义者展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：ModifiedElephant，APT，印度  

**事件概述：**  
近日，SentineLABS 发表报告披露了 ModifiedElephant APT 组织的攻击活动。该组织至少从2012年开始活跃，主要针对印度各地的人权活动家、人权捍卫者、学者和律师展开攻击。ModifiedElephant  组织主要利用带有恶意文档的鱼叉式网络钓鱼来感染目标，传递恶意软件（例如 NetWire、DarkComet 和具有基础设施重叠的简单键盘记录器），使用商业上可用的远程访问木马 (RAT) 执行恶意操作。**组织关联：**

*   ModifiedElephant 针对的多个个人是NSO Group 间谍软件 Pegasus的目标或已经被感染；
*   ModifiedElephant 和 SideWinder 网络钓鱼电子邮件中时间和目标在 SentineLABS 数据集中重叠；  
    
*   ModifiedElephant 网络钓鱼电子邮件有效负载 ( b822d8162dd540f29c0d8af28847246e ) 与 Operation Hangover 共享基础设施重叠 (new-agency\[.\]us) 。  
    

**组织背景归因：**

*   ModifiedElephant 的活动与印度的国家利益高度一致，并且在有争议的政治指控案件中，ModifiedElephant 攻击与个人被捕之间存在明显的关联性。

#### **Apache Cassandra 数据库软件被曝严重漏洞 CVE-2021-44251**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：Apache，数据库，严重漏洞  

**事件概述：**

Apache Cassandra 是一个开源的分布式 NoSQL 数据库管理系统，用于跨商品服务器管理大量结构化数据。近日，研究人员披露了一个 Apache Cassandra 高严重性安全漏洞 CVE-2021-44251，该漏洞涉及启用用户定义函数 ( UDF )配置的特定场景，有效地允许攻击者利用 Nashorn JavaScript 引擎、逃离沙箱和实现不可信代码的执行。该漏洞可以被攻击者滥用以在受影响的安装上获得远程代码执行 (RCE)，并且有可能对系统造成严重破坏。当 cassandra.yaml 配置文件包含以下定义时，Cassandra 部署容易受到 CVE-2021-44521 的攻击：

*   enable\_user\_defined\_functions：true
    
*   enable\_scripted\_user\_defined\_functions：true
    
*   enable\_user\_defined\_functions\_threads：false
    

Apache Cassandra 用户可以升级到版本3.0.26、3.11.12和4.0.2以避免该漏洞可能的利用。  
**来源：**  
https://thehackernews.com/2022/02/high-severity-rce-security-bug-reported.html

### ****攻击者使用透明反向代理钓鱼工具包专注于绕过多因素身份验证展开攻击****  
外媒报道称透明反向代理（TRP）钓鱼工具包已成为攻击者绕过多因素身份验证 (MFA) 的流行方法。攻击者利用透明反向代理工具包通过中间人 (MiTM) 攻击窃取身份验证令牌。Proofpoint 研究人员称绕过 MFA 的网络钓鱼工具包正在迅速增加，也暴露出了 MFA 绕过工具包的安全盲点，准备好应对这些盲点，然后才能朝着新的方向发展。
