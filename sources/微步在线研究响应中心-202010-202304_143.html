金融威胁情报


BHUNT  恶意软件瞄准加密货币钱包展开攻击

  Tag：BHUNT，加密货币钱包

事件概述：
近日，外媒报道称在野外发现了一个瞄准加密货币钱包的新规避型窃取恶意软件 BHUNT，该恶意软件是一个用 .NET 编写的模块化窃取程序，能够窃取加密货币（Exodus、Electrum、Atomic、Jaxx、以太坊、比特币、莱特币）钱包、存储在浏览器中的密码以及从剪贴板捕获的密码。其受害者遍布全球，主要分布在澳大利亚、埃及、德国、印度、印度尼西亚、日本、马来西亚、挪威、新加坡、南非、西班牙和美国等国家。
技术详情：
攻击者通常利用 KMSPico 等工具作为初始感染媒介，当成功接入受害者设备时释放 dropper 和启动窃取程序的二进制文件。该二进制文件是一种 .NET 恶意软件，它包含以下不同的模块以促进其恶意活动，并将窃取到的数据回传到远程服务器。

  • blackjack：窃取钱包文件；

  • chaos-crew：下载额外的有效载荷；

  • Golden7：窃取来自剪贴板的密码；

  • Sweet_Bonanza：窃取浏览器存储的密码；

  • mrpropper：清理痕迹。

政府威胁情报


APT36 伪装成印度新德里陆战研究中心瞄准印度军事目标展开攻击

  Tag：APT36，巴基斯坦，印度，军事

事件概述：
APT36 （也称为 Earth Karkaddan、Operation C-Major、PROJECTM、Mythic Leopard 和 Transparent Tribe）是一个疑似具有巴基斯坦背景的威胁组织，主要以印度军事和外交资源为目标。该组织以使用社会工程和网络钓鱼诱饵进行初始接入而闻名，然后部署 Crimson RAT 恶意软件来窃取信息。近期，趋势科技研究人员发现该组织利用了一种与 Crimson RAT 名称、命令、功能都存在重叠的 Android RAT CapraRAT 展开的新攻击活动。
技术详情：
威胁组织首先向受害者投递恶意网络钓鱼电子邮件，以伪装成来自印度新德里的陆战研究中心 (CLAWS)的诱饵文档诱使受害者点击恶意链接下载另一个包含恶意宏的文档。当受害者启用宏后，便会下载隐藏在图像文件中的 ObliqueRat 恶意软件，然后通过创建一个启动 URL 自动运行 ObliqueRAT 恶意软件，实现恶意软件在受害者主机上的持久性。ObliqueRAT 会与 C2 建立通信，接收并执行来自 C2 的命令。该 RAT 还会在受害者设备上查询系统信息、遍历进程、终止某些进程、收集信息，然后将收集的信息通过 ZIP 压缩回传给恶意 C2。


来源：
https://www.trendmicro.com/content/dam/trendmicro/global/en/research/22/a/investigating-apt36-or-earth-karkaddan-attack-chain-and-malware-arsenal/Earth%20Karkaddan%20Technical%20Brief.pdf
微步点评：
用户可以采用以下安全措施来阻止 APT36 攻击：
  • 警惕打开不请自来的和意想不到的电子邮件，尤其是那些要求紧急的电子邮件；
  • 注意恶意电子邮件危险信号，其中包括非典型发件人域以及语法和拼写错误；
  • 避免点击电子邮件中的链接或下载附件，尤其是来自未知来源的电子邮件；
  • 使用托管电子邮件安全和反垃圾邮件保护以阻止通过电子邮件到达的威胁，例如恶意链接；
  • 仅从受信任的来源下载应用程序；
  • 警惕应用权限请求范围；
  • 获取多层移动安全解决方案，保护设备免受在线威胁、恶意应用程序甚至数据丢失等威胁；
  • 使用信誉良好的安全厂商的安全解决方案。

能源信息 | 2021年中国新增海上风力发电量超全球他国五年总和

  Tag：能源，风力发电

事件概述：
据全国能源信息平台最新报道，称中国2021年的海上风力发电量超过了过去5年世界上其他国家的发电总和。2021年中国海上风电量接近170亿瓦，已经超越之前海上风力发电世界第一的英国，此前英国海上风力发电量为100亿瓦。这种快速的增量意味着，中国目前拥有全球近一半的海上风电能，在全球540亿瓦的总风力发电量中占到260亿瓦。如果将所有太阳能和风能发电计算在内，中国2021年新增的可再生能源产能高达1.01亿瓦。而美国只有两个小型海上风力发电场，总容量为0.042亿瓦。中国有望在2030年达到碳排放峰值的目标，而中国领导人也表示中国将在2060年实现净零排放。

  Tag：数据加密，铁路，白俄罗斯

事件概述：
近日，白俄罗国家铁路公司的铁路系统服务器遭到一群自称为白俄罗斯网络游击队的黑客入侵，他们对服务器、数据库和工作站进行了加密以中断铁路系统的运营服务。白俄罗斯网络游击队要求释放需要医疗救助的50名政治犯，并希望俄罗斯军队远离他们的国家，以此进行要挟，如果满足他们提出的条件，便可以恢复白俄罗斯铁路系统的正常运营。该组织还在 Telegram 频道上分享了事件中失陷系统的屏幕截图，包括白俄罗斯铁路内部系统、Veeam备份服务器、Windows域控制器以及据称包含数10TB等待销毁的备份服务器的截图。

目前尚不清楚白俄罗斯网络游击队的攻击对铁路机构造成了多大程度的持久损害。据当地新闻报道，火车服务以及在线票务系统可能暂时受到影响。白俄罗斯铁路公司随后公开声明称一些系统会在1月25日早上重新上线。

高级威胁情报


TransparenTribe 行动：使用武器化的 COVID-19 诱饵文件瞄准印度展开攻击

  Tag：TransparenTribe ，COVID-19，印度

事件概述：
TransparenTribe 是一个疑似具有巴基斯坦背景的威胁组织，至少自2013年以来一直活跃，主要针对印度和阿富汗的外交、国防和研究组织展开攻击。近日，Lab52 研究人员发现疑似 TransparenTribe  组织使用武器化 COVID-19 的诱饵文件瞄准印度展开攻击。
技术详情：
威胁组织首先向目标投递一个 IMG 文件，该文件包含与印度中央政府45岁以上员工 COVID-19 疫苗接种相关的 PDF 诱饵文档和一些其他恶意组件，其中一个恶意组件是与 PDF 文档同名的快捷方式，它负责通过启动名为 doc.vbs 的 Visual Basic 脚本来启动感染，然后继续执行诱饵 PDF 文档和 Windows 可执行文件，运行嵌入式 Python 命令，构建 Python 脚本实现持久性，并将收集到的信息回传到 C2。

漏洞情报


WordPress 插件被曝漏洞， 20,000 个网站的用户面临网络钓鱼风险

  Tag：WordPress，漏洞

事件概述：
继 WordPress 插件曝出漏洞 CVE-2022-0215 ，约84,000个网站受到影响后，WordPress 插件又曝漏洞 CVE-2022-0218， 20,000 多个网站用户面临网络钓鱼的风险。此次被曝漏洞的是 WordPress 插件 WP HTML Mail，该插件用于设计自定义电子邮件、联系表单通知以及在线平台发送给其受众的一般定制消息。该插件与 WooCommerce、Ninja Forms、BuddyPress 等兼容。

WP HTML Mail 漏洞 CVE-2022-0215 是由于插件注册了两个用于检索和更新电子邮件模板设置的 REST-API 路由，这些 API 端点没有得到充分保护以防止未经授权的访问，因此导致未经身份验证的用户也可以调用和执行这些函数。该漏洞除了导致网络钓鱼攻击的可能性之外，攻击者还可以将恶意 JavaScript 注入邮件模板中，该模板将在站点管理员访问 HTML 邮件编辑器的任何时候执行。这可能会为添加新的管理员帐户、将站点的访问者重定向到网络钓鱼站点、将后门注入主题文件甚至完成站点接管开辟道路。

漏洞时间线：

  • 2021年12月23日，Wordfence 发现并向插件开发者报告漏洞信息；

  • 2022年1月10日，WordPress 回应漏洞信息；

  • 2022年1月13日， WordPress 发布漏洞安全更新。

俄亥俄州卫生系统遭到勒索软件袭击，216,478 名患者数据发生泄露

外媒发表报道称俄亥俄州卫生系统 Memorial Health System 遭到勒索软件攻击，216,478 名患者敏感数据信息遭到泄露，该事件迫使卫生系统暂停用户访问与其运营相关的所有信息技术应用程序，导致手术病例和放射学检查被取消，急诊被迫转移。据调查结果显示攻击者于2021年7月10日入侵了 Memorial Health System 系统，在1个月后部署勒索软件。在此次攻击消息披露的3天后，Memorial Health System 向勒索软件组织支付赎金以恢复正常运营。2022年1月12日，Memorial Health System 向受影响的患者发送关于此次数据泄露事件的通知信息，并为受影响的人员提供为期12个月的 Kroll 信用监控服务免费会员权益 。

新的网络钓鱼活动：冒充全球航运巨头马士基航运公司旨在安装 STRRAT 木马
外媒发表报道披露冒充全球航运业巨头马士基航运公司（Maersk Shipping）网络钓鱼活动，旨在使用虚假运输诱饵在受害者设备上安装 STRRAT 远程访问木马。该木马可以运行伪勒索软件模块以模拟感染、窃取信息甚至伪造勒索软件攻击。

  • 从 Outlook、Thunderbird 和 Foxmail 等电子邮件客户端窃取密码；
  • 运行伪勒索软件模块以模拟感染。
