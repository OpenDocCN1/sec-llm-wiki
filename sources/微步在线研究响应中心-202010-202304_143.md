#### **Heimdal Security：更新勒索软件免费解密器**

近年来，随着勒索软件组织的大肆发展，勒索软件数量逐步上升，越来越多的犯罪分子加入了勒索软件作案行列。2022 年勒索软件攻击依然会继续蔓延至整个数字世界。勒索软件来势汹汹，威胁无处不在，但很多企业尚未做好准备，勒索软件亦成为了许多企业倍感焦虑的网络威胁。

如果您的设备不慎感染了勒索软件，那么您是否应该第一时间缴纳赎金以确保数据安全和正常运营呢？相信很多人的答案是缴纳赎金，但这种缴纳赎金换取解密数据的行为会助长犯罪的风气，这种行为同样也是不安全的。所以，当您发现感染勒索软件后，建议第一时间采取以下步骤恢复数据：

#### **BHUNT  恶意软件瞄准加密货币钱包展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：BHUNT，加密货币钱包  

**事件概述：**近日，外媒报道称在野外发现了一个瞄准加密货币钱包的新规避型窃取恶意软件 BHUNT，该恶意软件是一个用 .NET 编写的模块化窃取程序，能够窃取加密货币（Exodus、Electrum、Atomic、Jaxx、以太坊、比特币、莱特币）钱包、存储在浏览器中的密码以及从剪贴板捕获的密码。其受害者遍布全球，主要分布在澳大利亚、埃及、德国、印度、印度尼西亚、日本、马来西亚、挪威、新加坡、南非、西班牙和美国等国家。**技术详情：**攻击者通常利用 KMSPico 等工具作为初始感染媒介，当成功接入受害者设备时释放 dropper 和启动窃取程序的二进制文件。该二进制文件是一种 .NET 恶意软件，它包含以下不同的模块以促进其恶意活动，并将窃取到的数据回传到远程服务器。

*   blackjack：窃取钱包文件；
    
*   chaos-crew：下载额外的有效载荷；
    
*   Golden7：窃取来自剪贴板的密码；
    
*   Sweet\_Bonanza：窃取浏览器存储的密码；
    
*   mrpropper：清理痕迹。

#### **APT36 伪装成印度新德里陆战研究中心瞄准印度军事目标展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：APT36，巴基斯坦，印度，军事

**事件概述：**APT36 （也称为 Earth Karkaddan、Operation C-Major、PROJECTM、Mythic Leopard 和 Transparent Tribe）是一个疑似具有巴基斯坦背景的威胁组织，主要以印度军事和外交资源为目标。该组织以使用社会工程和网络钓鱼诱饵进行初始接入而闻名，然后部署 Crimson RAT 恶意软件来窃取信息。近期，趋势科技研究人员发现该组织利用了一种与 Crimson RAT 名称、命令、功能都存在重叠的 Android RAT CapraRAT 展开的新攻击活动。**技术详情：**威胁组织首先向受害者投递恶意网络钓鱼电子邮件，以伪装成来自印度新德里的陆战研究中心 (CLAWS)的诱饵文档诱使受害者点击恶意链接下载另一个包含恶意宏的文档。当受害者启用宏后，便会下载隐藏在图像文件中的 ObliqueRat 恶意软件，然后通过创建一个启动 URL 自动运行 ObliqueRAT 恶意软件，实现恶意软件在受害者主机上的持久性。ObliqueRAT 会与 C2 建立通信，接收并执行来自 C2 的命令。该 RAT 还会在受害者设备上查询系统信息、遍历进程、终止某些进程、收集信息，然后将收集的信息通过 ZIP 压缩回传给恶意 C2。

![](../Images/3a34eacf98592c002ece3e68d3162625.png)  

**来源：  
**https://www.trendmicro.com/content/dam/trendmicro/global/en/research/22/a/investigating-apt36-or-earth-karkaddan-attack-chain-and-malware-arsenal/Earth%20Karkaddan%20Technical%20Brief.pdf  
**微步点评：**用户可以采用以下安全措施来阻止 APT36 攻击：

*   警惕打开不请自来的和意想不到的电子邮件，尤其是那些要求紧急的电子邮件；
*   注意恶意电子邮件危险信号，其中包括非典型发件人域以及语法和拼写错误；
*   避免点击电子邮件中的链接或下载附件，尤其是来自未知来源的电子邮件；
*   使用托管电子邮件安全和反垃圾邮件保护以阻止通过电子邮件到达的威胁，例如恶意链接；
*   仅从受信任的来源下载应用程序；
*   警惕应用权限请求范围；
*   获取多层移动安全解决方案，保护设备免受在线威胁、恶意应用程序甚至数据丢失等威胁；
*   使用信誉良好的安全厂商的安全解决方案。

#### **白俄罗斯铁路服务器被加密，运营被迫中断**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：数据加密，铁路，白俄罗斯  

**事件概述：**近日，白俄罗国家铁路公司的铁路系统服务器遭到一群自称为白俄罗斯网络游击队的黑客入侵，他们对服务器、数据库和工作站进行了加密以中断铁路系统的运营服务。白俄罗斯网络游击队要求释放需要医疗救助的50名政治犯，并希望俄罗斯军队远离他们的国家，以此进行要挟，如果满足他们提出的条件，便可以恢复白俄罗斯铁路系统的正常运营。该组织还在 Telegram 频道上分享了事件中失陷系统的屏幕截图，包括白俄罗斯铁路内部系统、Veeam备份服务器、Windows域控制器以及据称包含数10TB等待销毁的备份服务器的截图。

#### **这种僵尸网络或将危害物联网行业？案例分析+处置措施，看这里**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：僵尸网络，xmirg，木马  

**事件概述：**

在一个恬静的午后，微步情报局捕获一起僵尸网络攻击活动。此次攻击始于微步在线主机威胁检测与响应平台 OneEDR （下文简称 OneEDR ）监测到 xmirg 的木马进程告警信息，微步情报局的安全研究员第一时间针对此项告警展开详细技术分析。

#### **WordPress 插件被曝漏洞， 20,000 个网站的用户面临网络钓鱼风险**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：WordPress，漏洞  

**事件概述：**继 WordPress 插件曝出漏洞 CVE-2022-0215 ，约84,000个网站受到影响后，WordPress 插件又曝漏洞 CVE-2022-0218， 20,000 多个网站用户面临网络钓鱼的风险。此次被曝漏洞的是 WordPress 插件 WP HTML Mail，该插件用于设计自定义电子邮件、联系表单通知以及在线平台发送给其受众的一般定制消息。该插件与 WooCommerce、Ninja Forms、BuddyPress 等兼容。

WP HTML Mail 漏洞 CVE-2022-0215 是由于插件注册了两个用于检索和更新电子邮件模板设置的 REST-API 路由，这些 API 端点没有得到充分保护以防止未经授权的访问，因此导致未经身份验证的用户也可以调用和执行这些函数。该漏洞除了导致网络钓鱼攻击的可能性之外，攻击者还可以将恶意 JavaScript 注入邮件模板中，该模板将在站点管理员访问 HTML 邮件编辑器的任何时候执行。这可能会为添加新的管理员帐户、将站点的访问者重定向到网络钓鱼站点、将后门注入主题文件甚至完成站点接管开辟道路。

**漏洞时间线：**

*   2021年12月23日，Wordfence 发现并向插件开发者报告漏洞信息；
    
*   2022年1月10日，WordPress 回应漏洞信息；
    
*   2022年1月13日， WordPress 发布漏洞安全更新。

### ****新的网络钓鱼活动：冒充全球航运巨头马士基航运公司旨在安装 STRRAT 木马****  
外媒发表报道披露冒充全球航运业巨头马士基航运公司（Maersk Shipping）网络钓鱼活动，旨在使用虚假运输诱饵在受害者设备上安装 STRRAT 远程访问木马。该木马可以运行伪勒索软件模块以模拟感染、窃取信息甚至伪造勒索软件攻击。

*   记录用户按键；
*   方便遥控操作；
*   从 Chrome、Firefox 和 Microsoft Edge 等网络浏览器窃取密码；
*   从 Outlook、Thunderbird 和 Foxmail 等电子邮件客户端窃取密码；
*   运行伪勒索软件模块以模拟感染。
