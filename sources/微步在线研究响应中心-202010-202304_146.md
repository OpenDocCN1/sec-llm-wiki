**概述**  
Apache Log4j2 是一个基于 Java 的日志记录工具，广泛用于业务系统开发，用来记录日志信息。由于 Log4j2 提供的 lookup 功能允许开发者通过一些协议去读取相应环境中的配置，却未对输入进行严格的判断，从而使攻击者可通过构造特殊的数据请求包，触发远程代码执行。因为 Apache Struts2、Apache Solr、Apache Druid、Apache Flink 等众多组件与大型应用均使用 Log4j2 作为基础组件，所以该漏洞影响范围很广，且漏洞触发后可执行任意代码，危害巨大。从 Log4j2 漏洞（CVE-2021-44228）POC 曝出后，安全厂商纷纷跟进，给出缓解和防御措施。而此时黑客也不会错过这个覆盖面极广且利用门槛极低的漏洞，很快就将其直接应用到自身攻击的活动中。近期，安全研究人员就发现， Dridex 的运营组织 Indrik Spider 利用 Log4j2 漏洞的 RMI 方式进行攻击，下发 Dridex 银行木马和 Meterpreter 后门程序。

![](../Images/761157386dcfa9ee1ad7e78d31ecc381.png)

Dridex 是目前全球比较活跃的银行木马之一, 经过多年的发展演变，在对抗检测和分析方面非常完善，影响了约40多个国家和地区，每年造成几千万美元的财产损失。该木马主要通过伪装成税单、新冠疫情播报甚至是解雇通知等形式的钓鱼邮件进行传播。当用户打开钓鱼邮件附件中的文档，被执行的恶意宏代码下载安装 Dridex 银行木马，窃取受害者的计算机中的银行登录凭证，从而窃取受害者的财产。

![](../Images/7a8b95a922be7651a961916dba374e95.png)

**样本分析**使用 Log4j2 漏洞 RMI 方式成功攻击带有漏洞的主机后，受害主机会从hxxp://188.166.57.35:8000/Binary.class 下载编译好的 Java 文件执行。对Binary.class 文件反编译可知：当受害主机为 Windows 平台时，使用命令行启动 mshta 执行远程 HTA 脚本，而在其他平台下则下载执行 python 脚本m.py。![](../Images/9deeb8639134c0292d77f2a8ed18adbc.png)  

## **2.1 Windows 平台**

Windows 平台的 HTA 脚本将内嵌编码的 VBS 脚本释放到 C:\\ProgramData\\目录下执行。

![](../Images/b0bb456146f8ac7d0c47437f96d811c4.png)  

VBS 脚本从多个域名中遍历请求下载 payload，保存到 C:\\ProgramData\\目录下，使用 rundll32 启动执行导出函数 DllRegisterServer。

![](../Images/a0601a6595b49888648a123520d41b91.png)

VBS 脚本下载执行的 Payload 为 dll 形式的 Dridex 银行木马模块。要执行到真正的 Dridex 代码，需要进行两次解密加载。在解密加载的过程中有多次沙箱和调试的检测，并且用于加载内层的逻辑代码与垃圾代码层叠穿插，从而对抗静态检测和分析。首次解密加载得到中间加载层模块。  
![](../Images/16a7d0516ba7aeb5eeeaf08ce1672668.png)![](../Images/fa3464644789e2924b6f91f2f4b1d393.png)中间加载层模块的节对齐粒度经过特殊调整（正常对齐粒度为0x1000，该木马为0x10），使得反编译器不能正常加载。![](../Images/3a3676d76b802950c67fbc96e8aa181b.png)  
二次解密加载得到 Dridex 银行木马，执行真正的恶意代码入口 DllRegisterServer 导出函数。![](../Images/5ea851e0918b4ada299b25bf0dcbe5eb.png)  
Dridex 银行木马较为复杂，使用的 API 函数均通过动态库和函数名的 hash 值的方式动态导入，并且使用 VEH 异常处理机制，调用部分的函数。木马所使用的字符串均加密存储，并且在执行功能代码前会再次检测沙箱和调试环境。![](../Images/1107ffbd338b2c91d66200d6b32a2d15.png)![](../Images/1d7ef516b4fec362aaaa754fc73e2b2a.png)多次反沙箱和反调试检查通过后，木马会收集计算机信息，包括计算机名、用户名、安装的软件、系统环境变量等，作为上线请求的数据。

![](../Images/2669c03e8d0893593351dffdb0b0ce27.png)  

木马将 C2 地址编码在文件中，连接时遍历地址列表，直到找到存活的 C2。木马与 C2 之间建立 HTTPS 请求，将收集到的信息以 POST 请求的方式发送到C2, 接受后续的恶意模块执行。此次分析的样本中的 C2 地址为：51.159.52.196:443134.209.247.135:6602194.233.68.48:522889.31.56.58:593 ![](../Images/a427c56294f3014ad0e0fb23f127e977.png)

## **2.2 其他平台（Linux/Unix）**

Linux 平台下执行的 python 脚本经过 base64 编码，调用 exec 函数执行解码后的脚本。![](../Images/8c5e0e10d4df65fd1b2eb55f407199c8.png)解码后的脚本为修改后的开源 PythonMeterpreter 脚本，连接 C2  185.254.196.122:4445，接受执行控制命令，远控受害主机。  

![](../Images/464e3994e95e8267f91e9261721fdc86.png)

**后记**  
Log4j2 漏洞影响范围广，利用简单且可以远程执行任意代码，已经被各种攻击团伙用于投递勒索病毒和挖矿病毒，相信在以后会有更多的病毒通过 Log4j2 漏洞进行投递。同时 Log4j2 漏洞的补丁及绕过手法也不断更新迭代，因此安全运维人员应该关注安全动态、部署可靠的安全产品、及时安装补丁或采取缓解措施、以免遭受攻击，造成不必要的损失。![](../Images/002e6a0e687774c2369f5ec0965413af.png)另一方面，对于 Dridex、Emotet、Trickbot 等这些流行活跃的木马来说，钓鱼文档依旧是其主要的传播途径。因此，企业在做好设备层面防护的同时，还应该提高员工的安全意识，在日常的工作中，注意甄别钓鱼信息，谨慎点击可疑的链接和邮件。
