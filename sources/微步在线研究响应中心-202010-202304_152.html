威胁趋势


Threatpost ：2022年值得关注的5个网络安全趋势

2021年，又是网络安全行业多灾多难的一年：创纪录的勒索软件攻击数量，SolarWinds 的供应链的大规模破坏力，以及最近曝出的 Log4j 漏洞等。Threatpost 研究人员与行业专家于近日基于2021年安全事件指出了2022年值得关注的五个主要趋势：
1、政府对网络安全的兴趣和影响将越来越大
SolarWinds、Colonial Pipeline 攻击、间谍软件和隐私问题已经引起了全球政府的关注。专家们普遍认为，未来一年将充满新的法规和投资。在整个 2022 年，这些直接的网络威胁将继续成为政府关注的焦点。
2、社会工程学经久不衰
社会工程依然是最难解决的安全问题之一，因为没有合规治理或风险管理措施可以解决。到 2022 年，网络犯罪分子将继续依靠社会工程学来使他们的社会工程骗局发挥作用。
3、供应链攻击
由于该行业将开始改变其看待勒索软件的方式，更加关注切入点，转而关注如何预测和保护第一道攻击，使用数据科学来模拟突出供应链潜在弱点的场景。这样会伴随着更大的透明度和披露性，导致未来攻击者会更加倾向于供应链攻击。
4、勒索软件即服务（RaaS）转向中小企业
勒索软件即服务(RaaS) 帮助数字勒索成为一项蓬勃发展的业务。2022年，随着政府和大公司向网络安全领域投入大量资金，资金不足和人手不足的中小型企业成为勒索软件组织的主要目标。
5、2022年网络安全行业需要更好的协调
在过去的一年里，威胁组织已经表明他们有能力团结起来，通过协调来解决问题。而网络安全行业合作的并没有那么多，就像研究人员所说威胁行为者愿意联手共同取得成功，2022年网络安全行业也需要更好的协调来联合抵抗恶意威胁。

巴西银行 Itaú Unibanco 用户成为 Android 银行木马主要欺诈目标

  Tag：巴西银行，Android，银行木马

事件概述：

近日，Cyble 研究人员监测发现了一款 Android 银行木马，该木马伪装成巴西大型金融提供商  Itaú Unibanco 银行应用程序通过虚假的谷歌应用商店传播，主要针对巴西银行 Itaú Unibanco 应用程序用户展开欺诈。该银行木马旨在利用可访问性服务，在安装过程中不会请求任何危险的权限，从而降低了被 AV 工具检测到的风险。

技术详情：

攻击者将伪装成 Itaú Unibanco 银行应用程序的恶意软件托管在创建的虚假谷歌应用商店页面，降低用户的防备心理，欺骗用户安装该应用程序。当用户点击安装按钮后，用户会被要求下载 、安装APK。该银行木马执行时会尝试通过从实际的谷歌商店打开真正的银行应用程序，打开后便会劫持真实的银行应用程序更改用户输入的字段来执行欺诈交易。

事件概述：

据 Citizen Lab 透露，以色列 NSO Group 间谍软件 Pegasus 曾在2019年4月26日至2019年10月23日被用来多次攻击波兰参议员 Krzysztof Brejza，次数高达33次。Brejza 主要帮助右翼政府组织反对现任总理 Mateusz Morawiecki 的反对派运动。而 Brejza 智能手机里经过修改的照片错误地将他牵连到几起丑闻中，并被政府支持的新闻媒体分享。最终促使 Mateusz Morawiecki 以极其微弱的优势赢得了选举。

事件概述：
12月17日，施耐德电气发布通告称发现了影响 EVlink 电动汽车充电站的7个漏洞，其中包括1个关键漏洞和5个高危漏洞，这些漏洞均可通过应用补丁或缓解措施修复。攻击者利用这些漏洞需要物理访问系统的内部通信端口，也可以从本地网络甚至互联网发起攻击。这些漏洞可能会导致充电站的设置和帐户被篡改和泄露的风险，这种篡改可能导致拒绝服务攻击等行为，导致可以未经授权使用充电站、服务中断、无法向监管系统发送充电数据记录、修改和泄露充电站配置等。

Apache Log4j 再曝漏洞？不必恐慌，有前提条件！！！

  Tag：Apache，Log4j，中危漏洞

事件概述：
近日，微步在线获取到 Apache Log4j 2.17.0 任意代码执行漏洞情报，攻击者可以利用该漏洞执行任意代码，Log4j ≤ 2.17.0(不包括2.3.2和2.12.4)版本受漏洞影响。该漏洞的触发点是 Log4j2 提供的 JDBCAppender 功能。通过该功能可以将相关的 log 信息通过标准的 JDBC 写入数据库中，这个过程需要 JNDI 的支持，这也就造成了本次漏洞的本质原因。本次漏洞需要配置文件可控，利用条件较为苛刻，不必恐慌。
漏洞评估信息：

  • 公开程度：已出现在野利用

  • 利用条件：无权限要求

  • 交互要求：0 Click

  • 漏洞危害：中危(利用条件苛刻)

  • 影响范围：Log4j2≤2.17.0(不包括2.3.2和2.12.4)

微步情报局于12月29日捕获漏洞相关情报，发布漏洞预警信息，建议用户升级到Log4j 2.17.1 (Java 8)或2.12.4 (Java 7)或2.3.2 (Java 6)版本。完整内容需查看“Apache Log4j 再曝漏洞？不必恐慌，有前提条件！！！”

近日，微步情报局捕获到 Apache APISIX Dashboard 身份验证绕过漏洞情报。Apache  APISIX Dashboard < 2.10.1 版本均受该漏洞的影响。攻击者可以利用该漏洞未授权访问服务器信息, 可能会造成任意代码执行。Apache APISIX 是一个动态、实时、高性能的 API 网关， 提供负载均衡、灰度发布、服务熔断、动态上游、身份认证、可观测性等丰富的流量管理功能。
漏洞评估信息：

  • 公开程度：漏洞 POC 已公开

  • 利用条件：无权限要求

  • 交互要求：0 Click

  • 漏洞危害：高危

  • 影响范围：Apache APISIX Dashboard< 2.10.1

微步情报局于12月28日捕获漏洞相关情报，发布漏洞预警信息，建议用户升级到Apache APISIX Dashboard 2.10.1最新安全版本。更多内容需查看“在野利用曝出，Apache APISIX Dashboard高危漏洞，企业需警惕！”。

勒索专题



2021年12月27日

Shutterfly 遭到 Conti 勒索软件组织攻击，运营出现中断

外媒报道称美国摄影产品和图像共享公司 Shutterfly 遭到 Conti 勒索软件攻击，数千台设备数据被加密。据 Conti 团伙声称已经加密了Shutterfly 的 4,000 多台设备和 120 台 VMware ESXi 服务器，并创建了一个 Shutterfly 数据泄漏页面，其中包含 Conti 声称在勒索软件攻击期间窃取的文件屏幕截图，以此威胁Shutterfly，如果 Shutterfly 不支付赎金，勒索软件组织就要在数据泄露站点公开窃取的数据。

钓鱼专题



2021年12月23日

卡巴斯基发布关于常见的鱼叉式网络钓鱼技巧的报告

由于大公司员工都会偶尔收到旨在窃取公司凭据的电子邮件，企业员工学会辨别有针对性的网络钓鱼迹象已成为必然的趋势，以下是卡巴斯基发表指出了一些常见识别鱼叉式网络钓鱼的技巧：公司名称错误拼写、公司名称中出现多余词汇、出现公司具体内容（比如说收件人）、高度专业的话题等。如果您一旦收到具备上述问题的上述电子邮件，一定要小心警惕网络钓鱼。
