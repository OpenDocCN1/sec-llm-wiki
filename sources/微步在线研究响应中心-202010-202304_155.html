威胁趋势


2022年，值得关注的5个 SASE 趋势

安全访问服务边缘（Security Access Service Edge，SASE）是影响企业网络安全世界的最新安全趋势。2020年，SASE 又被称之为十年的安全趋势。随着进入十年内的第二年，围绕 SASE 的细微差别、收益和战略变得越来越清晰。SASE 不仅仅是一种关键的安全机制，它正在成为解决长期存在的 IT 和安全组织问题并提供公司和用户所需的安全/生产力平衡的力量。

在基于 Enterprise Strategy Group (ESG) 最近发布的一项针对 613 名 IT 专业人士的广泛 SASE调查中，Symantec 指出了5个值得关注的关键 SASE 趋势，已确定潜在的未来影响。

1、SASE 的发展有助于将网络安全团队从各自的孤岛中拉出来，使各个团队能够更好的合作。

2、由于企业需要数据上下文来降低敏感数据泄露到组织外的风险，数据上下文也将成为 SASE 对话中不断增长的部分。

3、ZTNA 是 SASE 对数字领导者的首要需求。

4、SASE 解决方案中首要属性将偏向于将本地和云解决方案连接在一起的混合选项，保证企业在采用 SASE 时保留现有功能，不降低效率。

5、客户希望转向多个 SASE 供应商，为各种关键功能选择同类最佳的方法。

金融威胁情报


DeFi 平台 Grim Finance 遭到攻击，价值3000万美元的加密货币失窃

  Tag：Grim Finance，DeFi，货币失窃

事件概述：

12月19日，DeFi 平台  Grim Finance  发表推文，称其平台在当天凌晨2:00左右遭到网络攻击，价值3000万美元的加密货币失窃。Grim Finance 在发现攻击后，立即采取措施并就攻击者的地址通知了参与运营的主要加密货币  Circle ( USDC )、Dai (DAI) 和跨链协议 AnySwap 的实体，以冻结攻击者进一步转移的资金。Grim Finance 称此次攻击是高级攻击，攻击者通过输入恶意代币合约来利用 Grim 的保险库策略，当平台仍在处理第一笔存款时，攻击者利用五个可重入循环来伪造五笔存款。

据 Fantom (FTM) Blockchain Explorer 的数据显示 Grim Finance 当天继续进行交易，并称其中一个与漏洞利用相关的地址持有 120 万美元的比特币 ( BTC )、170 万美元的 SpookyToken (BOO) 以及 13,700 美元的 FTM 代币。目前，Grim Finance 尚未公开披露其他相关信息。

由于黑客急于利用新兴行业的缺陷，日益流行的 DeFi 平台也成为加密货币行业的新挑战。

政府威胁情报


Earth Centaur 组织针对运输行业组织及政府机构的攻击量大幅增加

  Tag：Earth Centaur，政府，运输机构

事件概述：

Earth Centaur，以前又称为 Tropic Trooper，是一个长期运行的网络间谍威胁组织，自 2011年以来一直活跃。研究人员指出该组织最近攻击量大幅增加，似乎只针对运输行业的组织和与运输相关的政府机构展开攻击，且精通红队手法。该威胁组织可以绕过安全设置并保持其操作畅通无阻，且会根据不同目标使用不同协议的后门或使用反向代理绕过网络安全系统的监控，还精通使用开源框架有效地开发新的后门变种。

技术详情：

攻击者通过使用 ProxyLogon 漏洞和 webshell 访问易受攻击的主机后，使用 bitsadmin 下载下一阶段的加载程序（加载程序被检测为 Nerapack）和有效负载文件 (.bin)。在成功部署有效载荷后，攻击者可以通过开发的多个能够利用通用网络协议进行通信的后门 ChiserClient、 HTShell 、Lilith RAT、SmileSvr、Gh0st RAT 进行进一步恶意操作，接收并执行 C2 服务器的命令，上传和下载文件，收集感染主机名、IP等信息加密并回传到 C2，然后使用多种合法工具在受感染机器上转储凭据。最后威胁组织会利用工具清理事件日志，避免暴露其踪迹。

来源：
https://www.trendmicro.com/en_us/research/21/l/collecting-in-the-dark-tropic-trooper-targets-transportation-and-government-organizations.html
微步点评：
MITRE ATT&CK：

  • 初始接入：利用面向公众的应用程序

  • 执行：命令和脚本解释器（PowerShell、Windows Shell）+系统服务（服务执行）

  • 维持：去混淆/解码文件或信息+执行护栏+DLL侧加载+清除Windows 事件日志+Rundll32+匹配合法名称或位置+BITS工作+时间戳

  • 凭据访问：操作系统凭证转储（注册表中的凭据、LSASS内存）

  • 横向移动：远程服务（SMB/Windows 管理员共享）

  • 发现：账户发现（域账户）+域信任发现+文件和目录发现

  • 信息收集：Web协议+非应用层协议

  • 信息渗漏：通过Web服务渗漏（云存储）

工控威胁情报


PseudoManuscrypt 恶意软件被用来针对工业系统展开大规模间谍攻击

击

  Tag：间谍软件，工业系统

事件概述：

近日，卡巴斯基发表报告指出 PseudoManuscrypt 新型恶意软件针对工业系统展开大规模攻击。PseudoManuscrypt 恶意软件是卡巴斯基研究人员于今年6月份首次发现的新型恶意软件，主要针对工业、能源、建筑等行业，其受害者主要集中于俄罗斯、印度、巴西、越南和印度尼西亚等地区。

谁是 PseudoManuscrypt？ 

虽然该攻击活动与已知的 Manuscrypt 活动之间存在一些相似之处，但研究人员分析后尚未确定对新的攻击者，故将其命名为 PseudoManuscrypt。该恶意软件实则是一个名副其实的间谍软件，具备记录按键信息、收集有关已建立的 VPN 连接和保存的密码信息，窃取剪贴板内容，使用内置麦克风（如果计算机有麦克风）录制声音并捕获图像。并且该恶意软件的一种变体还可以窃取 QQ 和微信应用程序的凭据，捕获屏幕图像并具有尝试禁用安全解决方案的功能，然后将收集到的数据发送到攻击者的服务器。

如何感染系统？

PseudoManuscrypt 加载程序通过大量其他恶意文件的安装和创建许多不同进程的复杂链进入用户系统。这些链是多种多样的，但它们都是从伪造的盗版软件安装程序档案开始的。

  Tag：谷歌商店，Joker， Color Message

事件概述：
继谷歌商店多款应用程序被曝存在恶意软件后，谷歌商店应用程序 Color Message 于近日又被曝出存在恶意软件 Joker，这已不是 Joker 恶意软件首次出现在谷歌商店的应用程序中。最新曝出的这次 Joker 恶意软件是隐藏在名为 Color Message 的移动应用程序中，该款应用程序在从谷歌商店下架之前被下载了超过 500,000 次。研究人员以此还警告用户应该立即从他们的设备中删除 Color Message 以避免付费欺诈。

  Tag：Ognl 漏洞，codeql

事件概述：

近日，微步情报局研究人员复盘了利用 codeql '神器'挖掘 Ognl 漏洞，并从 Ognl 漏洞回顾、 Ognl 漏洞挖掘通用模式、 codeql 实战多维度展开剖析。由于'codeql' 是基于静态分析的，这也就是说 'codeql' 只从语义上分析了数据流的可达性，但至于是否可达并没有保证。同时，由于 'Java' 语言的某些运行时特性，也使得 'codeql' 在查找数据流的时候会存在遗漏的情况。研究人员将解决这两类问题的办法称之为辅助截断数据流向和辅助建立数据流向，分别对应着 'DataFlow::Configuration' 类的 'isBarrier' 和 'isAdditionalFlowStep'。

警惕！Log4j 2.16 已失守！漏洞详情曝光

  Tag：Log4j ，漏洞

事件概述：

近日，微步情报局捕获到 Log4j2.16 拒绝服务攻击漏洞 0day 相关漏洞情报，攻击者可以利用该漏洞攻击服务器，该漏洞影响Log4j ≤ 2.16.0 的版本。该漏洞是由于StrSubstitutor.java 中的 substitute 函数递归解析数据造成的，当攻击者构造恶意的payload传入时，该解析函数会抛出异常，从而导致拒绝服务攻击。

微步情报局安全研究人员还对网络上有一些关于 CVE-2021-45046 RCE 的描述信息进行分析，发现在 *unix  的环境下才能造成RCE。研究人员在之前的文章中，已经分析了Log4j2.15.0版本对 IP 和协议做了限制，但是可以通过 java.net.uri 和系统底层函数对 URL 处理的不一致绕过 IP 限制。完整内容需查看“警惕！Log4j 2.16 已失守！漏洞详情曝光”。
