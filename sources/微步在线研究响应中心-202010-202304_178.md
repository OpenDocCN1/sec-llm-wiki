#### **如果你的电子邮件被黑了，你该怎么办？**

由于电子邮件账户包含了大量个人信息，迫使电子邮件账户成为黑客目标的首选。那么如果你突然发现你的电子邮件被黑了，你接下来的反应一定是在想：“电子邮件帐户包含了大量个人敏感的隐私数据信息，如果大规模泄露了，我该怎么办“？答案是深呼吸，接下来的五个步骤可以帮助你阻止或最大限度地减少账户被盗造成的损失。

首先，要修改电子邮件账户密码，设置的密码一定是唯一不重复且复杂的密码。

其次，如果黑客修改了你的邮件账户密码，而你被锁定无法访问时，你可以使用电子邮件提供商的恢复服务，这将是你重新获取账户重新获取控制权的方式。

再次，黑客极有可能将其钩子插入你的联系人地址薄向其他联系人传播恶意软件。你应该及时向所有电子邮件联系人发送消息，告知你的电子邮件账户已被盗用，提醒好友不要打开你账户被盗期间的发送的电子邮件中的任何附件或链接。

然后，黑客可以通过多种方式获取您的电子邮件帐户信息，其中之一是使用恶意软件。 建议你使用全面的在线保护软件对你的设备进行彻底的病毒扫描，以确保您的设备没有恶意软件。如果您还没有扫描，请将定期扫描设置为自动运行。从长远来看，这将有助于你电子邮件及设备的安全。

最后，因为一次攻击事件可能会带来另一次攻击事件。此时如果有人可以访问您的电子邮件和其中的所有信息，他们可能拥有进行进一步攻击所需的信息。你需即刻检查银行、金融、社交媒体和其他服务上的账户，留意任何不寻常的活动。

#### **印度旁遮普国家银行（PNB）服务器被曝存在漏洞，导致客户数据在7个月内面临泄露的风险**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：国家银行，数据泄露，漏洞，印度

**事件概述：**

近日，网络安全公司 CyberX9 披露印度旁遮普国家银行（PNB）服务器中存在漏洞。该漏洞可以导致 PNB 交换服务器的管理员权限达到最高级别，共享所有访问权限，包括对所有电子邮件地址的访问。由于该漏洞为恶意攻击者提供了对整个银行系统的访问权限，直接导致1.8 亿旁遮普国家银行客户的关键财务和个人信息在长达七个月的时间内面临泄露的风险。与此同时，旁遮普国家银行确认了其服务器出现故障，但坚称受影响的服务器不存在敏感或关键数据，不会导致任何敏感数据发生泄露。而且由于受影响的服务器处在单独的 VLAN 段，客户数据、应用程序也不会因此受到影响。作为预防措施，PNB 已将受影响的服务器关闭。截至11月19日，该漏洞已经得到缓解。

#### **朝鲜威胁组织 TA406 针对外交官员展开攻击**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：朝鲜，TA406，APT，Kimsuky

**事件概述：**2021年11月，美国安全企业 ProofPoint 发表报告称，疑似与朝鲜有联系的威胁组织 TA406 针对来自北美、俄罗斯的高级官员、执法人员、经济和金融专家、外交政策专家、记者和非政府组织实施网络攻击，窃取用户凭据和财务数据。**技术详情：**该组织使用自己注册和控制的基础设施来托管捕获的网页凭据和恶意文档以及数量有限的合法、受感染网站作为基础设施。并使用 Gmail、Yandex 和 Mail\[.\]ru 电子邮件帐户伪装成合法实体借助 Star 和基于 PHP 的 PHPMailer 工具来分发诱饵进行网络钓鱼。TA406 利用钓鱼电子邮件的 URL 链接到 SendGrid 电子邮件传送服务，该服务将受害者重定向到攻击者控制的托管恶意负载或凭据收集页面的域。SendGrid 是一个用于合法商业目的的电子邮件营销平台，通常可以绕过电子邮件安全过滤器，使恶意攻击者重定向行为变得合法。  

**来源：**

*   KONNI 和 Kimsuky 组织曾均使用 TeamViewer 执行 HWP 文档，并且二者在攻击活动中使用了相同的资产：子域名\*\*\*\*.890m.com和\*\*\*\*\*.16mb.com，IP：202.168.155.156。

2、经关联分析发现，研究人员将 TA406 组织与朝鲜背景威胁组织 Kimsuky(KONNI、Thallium)的活动集群关联起来。但出于攻击者攻击行为和目标， ProofPoint 研究人员将 TA406 划分为 Kimsuky 组织的子组织，Kimsuky 细化的子组织还包括  TA408 和  TA427。

#### **Windows 新 0day 漏洞，可以让攻击者获得管理员权限**

### ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)  Tag：0day，Windows

**事件概述：**近日，安全研究人员公开披露了一个新 Windows 0day 漏洞的 POC，该漏洞是研究人员在分析 CVE-2021-41379 补丁期间发现的一个严重的本地权限提升漏洞，该漏洞是由于CVE-2021-41379 漏洞未正确修复导致的。恶意攻击者可以利用该漏洞轻松提升特权。Windows 10、Windows 11 和 Windows Server 2022在内所有受支持的 Windows 版本均受该漏洞的影响。
