**Android 银行木马 Toddler 针对欧洲银行用户开展攻击活动**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png) Tag：Tag：Android，Toddler，欧洲

**事件概述：**

研究人员发现了一种在欧洲肆虐传播的新型 Android 银行木马“Toddler”。Toddler又称为 TeaBot、Anatsa，主要针对西班牙、德国、瑞士、荷兰等地区进行攻击。该恶意软件在今年1月份由 Cleafy 披露，攻击了欧洲60家银行用户。Bitdefender 研究人员表示在今年6月份的时候，西班牙和意大利用户成为 Toddler 恶意软件的主要感染目标。PRODAFT 研究人员还称迄今为止，该恶意软件至少感染移动设备7,632 台，窃取凭据1,000多组。

**技术详情：**

该恶意软件主要通过安装包程序和 Android 应用程序等传播媒介传播，然后在受害者主机与 C2 通信下载专门制作的虚假登录界面，然后将下载的钓鱼页面视图放置在目标应用程序之上，诱使受害者输入银行账号密码，窃取凭据。该恶意软件还会尝试窃取其他账户记录，并且具备键盘记录、截取屏幕截图、拦截两步验证 (2FA) 代码、短信拦截、C2 通信、接收命令和将受感染设备连接到僵尸网络的功能。

**TA2721 组织针对金融行业开展攻击活动**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png) Tag：TA2721，APT，金融

**事件概述：**

近日，Proofpoint 研究人员发现威胁组织 TA2721 通过发送包含西班牙语诱饵的电子邮件进行攻击活动。TA2721 （Proofpoint 命名为 Caliente Bandits）主要针对银行、保险、制造、娱乐、农业等行业开展攻击活动，其目标组织主要包括美国、欧洲、南美洲的企业。自2021年4月开始，该组织主要通过每周发送电子邮件分发 Bandook 恶意软件针对全球实体组织中西班牙姓氏个体开展攻击活动。研究人员还声称在过去六个月观察到 TA2721 威胁组织攻击活动中使用的3个 C2，并表示该组织倾向于在一定的时间段（数周或数月）内使用相同的命令和控制基础设施进行通信。

 ![](../Images/111fe36cda601591cd3d561dfc87233d.png)

**技术详情：**

TA2721 威胁组织通常在攻击活动中向目标投递以“预算“或“支付”为主题的诱饵电子邮件，诱使目标下载恶意 PDF 文件。随附的 PDF 文件包含一个嵌入的 URL 和密码，目标点击 URL 下载包含恶意软件 Bandook 的加密、压缩的可执行文件。

在6月份的攻击活动中，TA2721 伪装成南美(通常是委内瑞拉和墨西哥)的公司发送含西班牙语信息的电子邮件，它们是从 Hotmail 或 Gmail 电子邮件地址发送的。TA2721 分发恶意软件的方式一改往日风格，直接在邮件信息中插入恶意 URL ，通过缩短的 URL 重定向到企业安全共享平台下载安装 Bandook 加密压缩文件。

### **厄瓜多尔国营企业 CNT 遭到 RansomEXX 勒索软件攻击**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png) Tag：国营企业，电信，RansomEXX，勒索软件**事件概述：**据外媒近日报道称，厄瓜多尔的国营企业 Corporación Nacional de Telecomunicación (CNT) 遭到 RansomEXX 勒索软件攻击，导致其业务运营、支付门户、客户支持服务中断。CNT 是厄瓜多尔的国营电信运营商，提供固定电话服务、移动、卫星电视和互联网连接服务。虽然此次攻击活动影响了 CNT 的综合服务中心和联络中心的流程服务，但 CNT 表示在此期间不会因未付款而暂停用户的服务。CNT 在7月16日称就此次攻击事件已向州检察长办公室提起诉讼，进行初步调查并追究责任。CNT 还在新闻声明中表示，公司和客户的数据是安全的，没有遭到泄露。虽然 CNT 对于此次攻击事件没有正式声明是勒索软件攻击，但 BleepingComputer 了解到 CNT 此次遭受的攻击活动是由 RansomEXX  勒索组织发起的，还分享了泄漏站点的隐藏链接。链接页面警告 CNT 需现在联系勒索软件组织缴纳赎金赎回文件，否则将泄露窃取的190 GB 文件，并在泄露站点页面上传了窃取的 CNT 部分文档内容截图，包括联系人列表、合同和支持日志等信息。目前，链接页面对公众隐藏，只能通过链接访问，这些隐藏页面通常包含在赎金票据中。随着勒索软件发展普遍化，RansomEXX  勒索软件组织还创建了 Linux 版本的 RansomEXX 勒索软件，以确保对所有关键服务器和虚拟机可以进行攻击。 ![](../Images/65831177628050633250b265f064a7a4.png) 来源：  
https://www.attack-secure.com/ransomexx-ransomware-hits-ecudaors-cnt-and-steals-190-gb-of-corporate-data/![](../Images/790a92541e41e2ced69229b2790abd2f.png)  

### **威胁组织针对乌克兰政府的网络钓鱼活动**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png) Tag：乌克兰政府、网络钓鱼**事件概述：**继 Fortinet 监测到威胁组织针对乌克兰政府早期的网络钓鱼攻击后，Intezer 研究人员于6月发现该威胁组织针对乌克兰和格鲁吉亚的政府机构的攻击活动。威胁组织通过发送鱼叉式网络钓鱼电子邮件进行攻击活动，内容涉及政府相关主题，包括退伍军人、乌克兰反恐行动（ATO）、格鲁吉亚境内流离失所者 (IDP)、格鲁吉亚私营部门组织和新冠肺炎。Intezer 研究人员表示此次攻击活动背后的威胁组织可能是俄罗斯背景威胁组织 APT28，虽然仅凭这次攻击活动与 APT28 的攻击活动的相似是无法将这次攻击活动归因于 APT28的，但受害者和对东欧地区的各个政府实体进行间谍活动的意图让 Intezer 研究人员相信 APT28 是此次攻击活动幕后黑手。**技术详情：**威胁组织在此次攻击活动中向目标投递包含恶意短 URL 或 PDF 附件的网络钓鱼电子邮件，利用 URL 将目标重定向到托管 ZIP 文件和恶意文档的 C2。恶意附件有 RTF、DOC、PDF、JS、LNK、EXE 等格式，其主要目标是从 C2 下载打包的有效载荷。在不同的文件类型和攻击阶段中，dropper 与 C2 通信交付打包的有效载荷的方法是不同的。打包的可执行文件将一个 AutoIt 有效载荷加载到内存中，然后将收集到的受害者信息回传给 C2 。![](../Images/fcaa709da9a7ed0528082177e395f2bf.png)

### **Nobellium 组织利用 0day 漏洞针对西欧政府官员发起攻击活动**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)Tag：Nobellium，APT，LinkedIn，西欧，0day**事件概述：**谷歌安全研究人员于近日披露了影响 Google Chrome、Internet Explorer 和 WebKit 浏览器引擎的4个 0day 漏洞信息，并且还透露其中 WebKit 浏览器引擎漏洞 CVE-2021-1879 被与俄罗斯有关的 APT 组织利用攻击西欧政府官员，通过 LinkedIn 消息向西欧国家的政府官员发送恶意链接。该漏洞影响 iOS 12.4至13.7的旧版本。谷歌研究人员没有将此次攻击活动归因于特定的 APT 组织，但微软研究人员认为此次攻击事件是由与俄罗斯有关的 APT 组织 Nobelium 发起的，Nobelium 组织还被认定为是2019年 SolarWinds 供应链攻击事件的幕后黑手。**技术详情：**在此次攻击活动中，攻击者通过电子邮件等方式向目标发送恶意链接，诱导用户访问，然后利用漏洞（CVE-2021-1879）绕过安全防护措施，最终将收集到受害者的身份验证信息通过WebSocket 发送到攻击者控制的 IP。 来源：

**Saudi Aramco 1TB 数据遭到泄露**

**** ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png)Tag：石油公司，数据泄露**事件概述：**7月19日，外媒 Bleepingcomputer 报道称，ID 为ZeroX 的用户（以下简称ZeroX）窃取沙特阿拉伯国家石油公司(Saudi Aramco)1TB数据并在暗网出售。沙特阿美此次泄露的数据部分时间最早可以追溯到1993年。Zerox 在给 BleepingComputer 的回应中声称是通过 0day 漏洞入侵沙特阿美的系统，访问并窃取了沙特阿美ITB的敏感数据。据 ZeroX 在暗网论坛上发布的帖子可知泄露的数据主要关于6家阿沙特阿美炼油厂的信息，具体信息包括：

*   14254名员工的完整个人信息：姓名、电子邮件、护照、身份证、家庭信息等；
*   与电力、建筑、工程、土木、施工管理、环境、机械、船舶、电信等相关系统的项目规范；
*   内部分析报告、协议、定价表；
*   位置图和精确坐标；
*   Aramco 客户名单、发票及合同等。

沙特阿美对于本次事件做出回应，认为本次数据泄露事件是由第三方供应商导致的，并未对沙特阿美的日常运营造成影响。ZeroX 还对此次交易设置662小时（大约28天的时间）的倒计时，在此期间内等待沙特阿美联系进行谈判，否则倒计时结束后将公开出售数据。Zerox 还透露，目前已有5位买家参与协商购买沙特阿美泄露的敏感数据。最后关于本次事件定性为是勒索软件攻击还是0day 攻击的结论存在不同的说法。![](../Images/e90748ea4b1ca8f4b9e8b009d2dfd893.png)

### **思科披露工业自动化设备公司研华科技监控软件存在严重漏洞**

### **MosaicLoader：新的 Windows 恶意软件**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png) Tag：MosaicLoader，Windows**事件概述：**Bitdefender 研究人员在调查 Windows Defender 中为特定文件名添加到本地进程排除列表时，发现了一个新的恶意软件家族，研究人员将其命名为 MosaicLoader。该恶意软件是 Windows 端恶意软件，其内部结构复杂，旨在混淆恶意软件分析人员并防止逆向工程。MosaicLoader 似乎是通过搜索结果中的付费广告提供的，旨在吸引用户寻找破解软件来感染他们的设备。恶意软件一旦植入系统，恶意软件就会创建一个复杂的进程链，并尝试下载各种恶意程序，从简单的 cookie 窃取程序、加密货币矿工，到成熟的后门程序 Glupteba。据 Bitdefender 研究人员称，该活动没有特定的目标国家或组织，MosaicLoader 恶意软件受害者数量还会在全球范围内激增。**技术详情：**MosaicLoader 恶意软件攻击流程：第一阶段：安装一个模仿合法软件图标和版本信息的 dropper，与 C2 进行通信下载包含第二阶段所需文件 appsetup.exe 和 prunp .exe .zip 的压缩文件到  %TEMP% 目录下。这些文件被解压到C盘目录下 PublicGaming 文件中。该 dropper 还会启动多个 PowerShell 脚本。第二阶段：appsetup.exe 进程用于在受害者系统上获得持久性。首先，MosaicLoader 添加一个新的注册表值，指向第二阶段的另一个组件 prun.exe。然后，MosaicLoader将 appsetup.exe 注册为一个名为“pubgame-updater”的服务定期运行，最后启动 prun.exe。第三阶段：恶意软件喷射器的目标是从托管恶意软件的攻击者控制的 URL 列表中下载恶意软件列表并执行它们。因此，Bitdefender 研究人员指出，它可以在系统上传播任何恶意软件。![](../Images/c8c8a85e5d008ea94c56fdfa75b5cc55.png)

### **StrongPity APT 组织首次部署 Android 恶意软件展开攻击**

 ![](../Images/84867acf6c0dfd44e0460087fbfba59e.png) Tag：StrongPity，APT，Android**事件概述：**近日，趋势科技研究人员在对叙利亚电子政务网站上 Android 恶意软件样本进行分析时，发现这是 StrongPity APT 组织首次利用 Android 恶意软件进行攻击活动。该 Android 恶意软件使用不同的证书签名，并通过重新包装的叙利亚政府的原始应用程序生成，且所有的原始应用程序均使用另一个证书签名。虽然一些杀毒厂商将该恶意样本识别检测为 Bahamut 组织，但趋势科技研究人员调查将这些样本与 StrongPity APT 关联起来。研究人员表示 StrongPity APT 组织倾向于重新包装良性安装程序以生成这些应用程序的木马化版本。同样，这些后门的主要功能是从受害者的计算机中搜索、收集和窃取文件。研究人员还表示，StrongPity APT 组织正在积极开发用于针对 Android 平台的新恶意软件。 ![](../Images/22937b9b75c0126386804aa8c796eaa1.png)
