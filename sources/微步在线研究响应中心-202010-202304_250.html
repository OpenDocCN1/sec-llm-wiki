金融威胁情报


Flubot 间谍软件窃取安卓银行账户信息

据 NCSC 披露，一款名为“FluBot”的恶意间谍软件正在 Android 平台上快速传播，该恶意软件旨在窃取密码、银行资料和其他敏感信息。研究人员表示，黑客会给攻击目标发送伪装成某快递公司的短信，在短信中会提示要求点击链接进行追踪快递包裹物流，一旦点击则会被诱导安装该恶意软件，FluBot 获得相应权限，包括密码、网上银行细节和其他个人信息在内的敏感信息将被窃取。同时，FluBot 还具有自传播的能力，它会访问受害者的通讯录并将含有恶意软件的短信发给通讯录里的联系人，正是这种利用联系信息的机制使 FluBot 的传播如此迅速。面对此类威胁，微步情报局提醒您，一旦收到不明来源的或含有链接的短信，不要轻易点击链接或者安装其提示的应用软件，如有相关软件安装需求，请从正规 APP 商店以及官方渠道下载、安装。

来源：https://www.ncsc.gov.uk/guidance/flubot-guidance-for-text-message-scam



针对美国 JPMorgan Chase 银行的两种新型网络钓鱼攻击

Armorblox 威胁研究人员于近期发现了针对摩根大通银行（JPMorgan Chase）的两起网络钓鱼攻击活动。这两次攻击活动均采用社会工程和品牌伪装策略，企图窃取目标客户的登录凭据。其中一起攻击是通过发送包含信用卡对账单及还款链接的电子邮件，并将安全设置中的垃圾邮件可信度（SCL）设置为“ -1”来绕过本地 Microsoft“垃圾邮件过滤”机制发起攻击，一旦收件人点击邮件中的链接就会跳转到攻击者伪造的 Chase 网站登录界面，并要求输入银行帐户密码。另一起攻击活动是伪造账户锁定流程，攻击者冒充 Chase 反欺诈部门通知收件人其银行账户因异常登录被锁定，并使用安全提示为主题的邮件作为社工手段来诱导收件人点击邮件中的虚假链接验证身份，以此窃取受害者银行凭据。微步情报局提示您，要遵循多因素身份验证和密码管理最佳实践方法，并且通过附件控件增强原生电子邮件的安全性。


来源：https://www.armorblox.com/blog/blox-tales-chase-credential-phishing-attacks/



意大利合作信贷银行 BCC 疑遭勒索软件攻击
据意大利媒体报道，意大利最大的合作信贷银行之一 Banca di Credito Cooperativo（BCC）遭到疑似 DarkSide 勒索软件团伙的网络攻击。本次攻击导致 BCC 的188个分支机构瘫痪，严重影响了其银行客户的正常工作服务。BCC 银行发布声明邀请客户使用自动取款机或家庭银行服务，并表示这些服务不受本次事件影响。该银行试图淡化遭受勒索软件攻击的问题，宣称问题的根本原因与通信系统的技术问题有关。由于一些未知的因素，Darkside 在站点上公布的名单中并未包含 BCC。截至目前为止，该银行已经解决了导致正常操作变慢的技术问题，计划最晚于5月3日之前恢复所有机构的运作。


来源：https://securityaffairs.co/wordpress/117360/cyber-crime/banca-di-credito-cooperativo-darkside-ransomware.html



政府威胁情报


华盛顿特区警察局遭到勒索软件攻击
近日， 华盛顿特区警察局遭到疑似俄罗斯背景的黑客组织 Babuk Locker 的勒索攻击，黑客组织声称窃取了警局 250GB 以上的数据，并在 Babuk Locker 网站上发布了部分数据截图，其中包括警方调查报告、当地犯罪团伙信息、面部照片、监狱人口信息和其他行政文件。若警方未在规定期限内支付赎金，他们便要向当地犯罪组织共享警方调查报告并曝光线人的相关信息。目前，该起事件仍在调查中。Babuk Locker 是目前最新的勒索软件组织之一，该团伙于2021年1月开始运营，已经成功打击了一些大公司，如西班牙电话零售连锁店 Phobe House 和 NBA 休斯顿火箭队。该组织最显著的特点之一是，其勒索软件有效负载能够加密存储在 VMWareeSXI 共享虚拟硬盘上的文件。目前，除了 Darkside 和 RansomExx 外，Babuk Locker 是第三个能够做到这一点的勒索软件组织。

来源：https://therecord.media/ransomware-gang-threatens-to-expose-police-informants-if-ransom-is-not-paid/



能源威胁情报


油田服务公司 Gyrodata 发生数据泄露事件

Gyrodata 是一家总部位于得克萨斯州休斯顿的油田服务公司，近日该公司发布一份声明指出，Gyrodata 于今年年初遭到 REvil 勒索软件攻击，发生数据泄露。经 Gyrodata 调查确定，在2021年1月16日至2月22日期间，攻击者未经授权多次访问了 Gyrodata 的某些系统并窃取了敏感数据，这些数据可能包含 Gyrodata 离职和在职员工的个人信息，具体包括姓名、地址、出生日期、驾照号码、社会保险号码、护照号码、W-2 税务表格以及与健康计划登记有关的信息。目前还不清楚勒索软件本身是否对 Gyrodata 造成了破坏，但该公司承认此次数据泄漏事件对员工个人和财务数据存在潜在影响。Gyrodata 表示，已经开始联系受影响的个人，并建立了专门的呼叫中心处理本次事件的潜在影响。

来源：https://hacker.observer/us-drilling-giant-gyrodata-reveals-employee-data-breach/



电源管理解决方案提供商 Eaton 产品中的严重漏洞可能允许攻击者中断电源

美国基础设施安全局 CISA 和电源管理解决方案提供商 Eaton 近期发表声明，指出 Eaton 智能电源管理器（IPM）存在6个高危漏洞，漏洞类型包括：SQL注入、 Eval 注入、不正确的输入验证、任意文件上传以及代码执行。Eaton 的 IPM 产品旨在通过允许组织远程监视、管理和控制其网络上的不间断电源（UPS）设备来确保系统的正常运行时间和数据完整性。攻击者可能利用 IPM 的这些漏洞中断电源。此次漏洞受影响的版本有 Eaton 智能电源保护器（IPP）v1.68 之前的所有版本，Eaton 智能电源管理器（IPM）和 Eaton 智能电源管理器虚拟设备（IPM VA）v1.69 前的所有版本。Eaton 目前已发布其智能电源管理器（IPM）软件的补丁程序，以解决一些潜在的严重漏洞，其中包括可能允许黑客中断电源的漏洞。


来源：https://www.securityweek.com/vulnerabilities-eaton-product-can-allow-hackers-disrupt-power-supply



TALONITE：专注于美国电力部门的威胁活动小组
TALONITE 是 ICS《Cyber security 2020 Year in Review》报告中首次披露的针对 ICS/OT 的四个新威胁组织之一。该组织主要针对美国电气行业，攻击目标包括美国国家工程和测量审查委员会 （NCEES）、北美电气可靠性公司 （NERC）、美国土木工程师协会 （ASCE） 和全球能源认证 （GEC）。TALONITE 利用电力和电网行业相关主题的恶意文档和可执行文件进行鱼叉式网络钓鱼，通过社会工程学诱饵文档分发 LookBack 和 FlowCloud 恶意软件，并滥用已签名的二进制文件代理执行。LookBack 和 FlowCloud 均为远程访问木马（RAT），且二者都可以进行凭据捕获。LookBack 恶意软件可以通过添加 Windows 注册表项来实现持久性，FlowCloud 还会从微软启动合法的 HTML Help Workshop (hhw.exe) 实用程序的重命名副本文件来存储捕获的主机数据。在对 TALONITE 追踪期间，并未发现该组织在受害者网络内部进行横向入侵。尽管目前 TALONITE 与任何已知的 ICS 蓄意破坏事件无关，但2019年的定向攻击表明，TALONITE 在较长时间内针对美国电力部门中的多个实体进行了初始访问和信息收集。这些已识别的行为和功能并不能排除 TALONITE 将来针对 ICS 的破坏活动，有足够的信息表明 TALONITE 组织是当前美国电力行业安全中的严重威胁。

来源：https://hub.dragos.com/hubfs/Year-in-Review/Dragos_2020_ICS_Cybersecurity_Year_In_Review.pdf




流行威胁情报


僵尸网络组织 Prometei 正在利用微软 Exchange Server 漏洞挖掘加密货币

Cybereason 近日披露了一个疑似俄罗斯背景的威胁组织利用已知的微软 Exchange Server 漏洞渗透网络，传播 Prometei 僵尸网络来挖掘加密货币。Prometei 是一种多模块僵尸网络，于2020年7月首次被披露，但 Cybereason 表示该组织的活动至少可以追溯到2016年。Prometei 利用与 HAFNIUM 攻击相关的已知的微软 Exchange Server 漏洞渗透到网络中，以进行恶意软件部署、凭据收集等。并且主要通过 SMB 和 RDP 在受感染机器上实现持久性的驻留，使用4台不同命令与控制的基础设施进行多频段通信，实现防御规避。Prometei 僵尸网络具有高度的针对性，它会根据每个受害者操作系统的版本部署相对应 Windows、Linux、Unix 版本的有效载荷。Prometei 僵尸网络的受害者遍布金融、保险、零售、制造业、公用事业、旅行和建筑等行业。


来源：https://www.prweb.com/releases/cybereason_discovers_global_botnet_campaign_leveraging_microsoft_exchange_vulnerabilities/prweb17886621.htm


Emotet 恶意软件在所有受感染的计算机上自毁

Emotet 是一种基于电子邮件的 Windows 端的僵尸网络，该僵尸网络因发起多个垃圾邮件活动和勒索软件攻击而臭名昭著。欧洲执法部门自今年1月宣布捣毁了 Emotet，并且开始向受感染的设备分发 Emotet“自毁模块”，“自毁模块”定于4月25日自动生效并将 Emotet 僵尸网络从感染的计算机中删除。这项有组织的活动至少涉及了700台服务器，荷兰、德国、美国、英国、法国、立陶宛、加拿大、乌克兰的执法机构参与了此次国际行动。Emotet 的“自毁模块”触发后将自动从设备中删除相关的 Windows 服务、自动运行注册表键，然后退出该进程，被攻击设备上的其他一切都不会受影响。Redscan 的研究人员表示，Emotet 的运营商在改进恶意软件之前总是倾向于长时间休息，这意味着 Emotet 的运营商可以利用此机会使恶意软件加载程序更具弹性。例如，使用动态技术来应对有组织的中断行动。他们还可以使用 Emotet 源代码创建较小的独立僵尸网络。这次大规模的恶意软件自毁删除操作是执法机构第二次从受感染的系统中删除恶意软件。4月初，美国政府采取行动，删除了因恶意利用  ProxyLogon 漏洞释放在受感染的 Exchange 服务器上的 Web Shell 后门。

来源：https://blog.alyac.co.kr/3731?category=750247


高级威胁情报


ClickStudios 密码管理器 Passwordstate 遭到供应链攻击
CSIS 安全小组研究人员于近日披露了针对 ClickStudios 密码管理器 Passwordstate 的供应链攻击。此次攻击通过名为 Passwordstate_upgrade.zip 的压缩包进行恶意更新，压缩包内包含注入恶意代码的 DLL 文件 moserware.secretsplitter.dll。DLL中的恶意代码会尝试连接 URL: https://passwordstate-18ed2.kxcdn[.]com/upgrade_service_upgrade.zip ,并利用 Container.Get() 函数检索加密代码，然后将 AES 解密后的方法传递给类函数 Loader ，直接在内存中执行恶意代码。恶意 DLL 使用的 C2 是内容交付网络（ CDN ），CDN 于4月22日早上7点关闭，所以并未检测到后续相关有效载荷。ClickStudios 在航空航天、银行、国防、医疗保健、公用事业和其他工业领域拥有约 29,000个企业和政府客户。Click Studios 建议受此次攻击事件影响的客户更改其帐户的所有存储密码，包括 VPN、防火墙、交换机、本地帐户和所有服务器等密码。目前，ClickStudios 已公开 Passwordstate 供应链攻击的 IOC ，以便企业客户判断自身是否受到此次攻击的影响。

来源：https://www.csis.dk/newsroom-blog-overview/2021/moserpass-supply-chain/


卡巴斯基发布2021年第一季度 APT 活动趋势报告

卡巴斯基全球研究与分析团队（GReAT）于近期发布2021年第一季度 APT 活动趋势报告。

  • 主要发现：SolarWinds 供应链攻击活动在其客户端上部署 Sunburst 后门。Sunburst 后门与 Turla 组织的 Kazuar 后门具有重叠性，二者共享 UID 生成算法，且初始睡眠代码以及混淆字符的 FNV1a 哈希高度相似。此外，多个威胁组织利用微软 Exchange Server 漏洞发起针对性攻击。

  • 欧洲：发现了基于 Web 开发服务器的工具包 FinFly Web 的最新部署痕迹——两个疑似由 FinFly Web 生成的 Web 服务器。其中一台服务器曾在2019年10月起开始活跃，在2020年12月被发现后随即关闭其状态。结合历史数据发现，它在2020年9月前后的很短时间内在仿冒 Mail.ru 服务的主机上处于活动状态，该服务器在今年1月又开始活跃，但目前并没有发现释放的有效载荷。

  • 俄罗斯：Sunburst 后门与 Turla 组织的 Kazuar 具有相似性。Gamaredon 组织利用国家文件分发系统（SEIEB）向乌克兰公共当局分发包含宏的恶意文档。ANSSI 将 Centreon 系统攻击活动与 Sandworm 攻击相关联。

  • 中东：Lyceum/Hexane 利用新的 C++ 后门和功能相同的 PowerShell 脚本取代了以前的 .NET 有效载荷。2020年11月捕获到一份针对阿拉伯联合酋长国的一所大学的恶意文档，该文档与 MuddyWater 组织的工具、通信方式、基础设施、TTP 高度相似。Karkadann 组织利用含有嵌入式宏的恶意文档触发感染链。该组织与近期针对中东地区水坑攻击的 Piwiks事件具有相似之处。

  • 东南亚和朝鲜半岛：Kimsuky 组织使用新的方法来分发恶意软件包。Lazarus 组织近期针对安全研究人员攻击活动的相关基础设施与 ThreatNeedle 集群相重叠。Bitter 组织在野利用零日漏洞实施攻击。


来源：https://securelist.com/apt-trends-report-q1-2021/101967/



漏洞情报


黑客利用 Mac OS 漏洞进行 Shlayer 恶意软件活动

黑客组织主要利用 Mac OS Big Sur的漏洞绕过macOS的文件隔离、Gatekeeper、Notarization 三种主要安全机制进行 Shlayer 恶意软件活动。Shlayer 是一种广告软件，可以拦截加密的网络流量（包括启用 HTTPS 的网站），并注入自己的广告，从而给运营商带来欺诈性的广告收入，通常是通过欺骗用户下载虚假的应用安装程序或更新程序来进行恶意软件安装，Shlayer 可以逃避内置的恶意软件扫描，并且在用户无感知的情况下就可以启动。黑客组织首先通过使用脚本作为主要可执行文件来手动制作应用程序捆绑包，且不会创建 Info.plist 文件，然后将应用程序放置在 dmg 文件目录中进行分发，当 dmg 挂起并双击应用程序时，plist 文件便可绕过 Mac OS 的主要安全机制执行恶意操作。Mac OS 的三种主要的安全机制是：1）文件隔离：在执行文件时提示用户并要求用户确认信息；2）Gatekeeper：检查代码签名信息，以确保应用程序来自受信任的开发人员并且未被篡改；3）Notarization：允许在软件运行之前自动扫描恶意内容。苹果公司已在 macOS 的 11.3  版本中修复了 Mac OS Catalin、Mojav、Mac OS Big Sur 中的多个安全漏洞，其中包括高危安全绕过漏洞 CVE-2021-30657。该漏洞是在 Mac OS 10.15 中发现的，10.15 以下的版本似乎没有受到该漏洞的影响。


来源：https://www.jamf.com/blog/shlayer-malware-abusing-gatekeeper-bypass-on-macos/
