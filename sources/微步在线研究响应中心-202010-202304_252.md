**金融威胁情报**

  
**朝鲜黑客利用网络浏览技术窃取比特币**国外研究人员称，与朝鲜政府有关联的黑客利用网络浏览技术，在去年年初开始的一项未被记录的攻击活动中窃取了加密货币。这些依赖于网络浏览活动基础结构的攻击使至少侵害了三个网店的客户，研究人员将这些攻击活动归因于 Lazarus APT（也称为 Hidden Cobra）。荷兰网络安全公司 Sansec 曾披露，Lazarus 组织自2019年就开始从美国和欧洲的大型零售商的网上购物者那里窃取支付卡数据。在这些攻击中使用的恶意 JavaScript 代码，收集了网上购物者在付款页面输入的支付卡详细信息。据 Group-IB 披露，该黑客组织从2020年开始攻击支持加密货币付费方式的网店。攻击者修改了来自“ clientToken =”活动的恶意 JavaScript，从而用受他们控制的地址替换了网店的比特币地址。这样，网上购物者的付款就会落入攻击者的钱包。通过对这些小规模的活动的跟踪分析，研究人员认为，这些只是黑客组织对一组新工具和策略的试运行，未来它们很可能被用于对付更大的目标。

**美国汽车保险供应商 Geico 发生数据泄漏**美国第二大汽车保险公司 Geico 近期发生数据泄露。Geico 表示，2021年1月21日至2021年3月1日期间，黑客利用在其他地方获取的 Geico 的客户信息，未经授权访问了其在线销售系统，以此获取其客户的驾照号码。Geico 认为，攻击者可能会利用驾照号码，以保单持有人的名义申请失业救济。Geico 称其已经对网站进行了安全加固，还增加了其他安全措施来防止进一步的欺诈或非法活动。对于受影响的客户，Geico 将提供为期一年的免费身份保护服务。Geico 同时提醒受影响的用户，注意来自所在州的失业机构的意外邮件，如果收到任何信息，应该立即联系该机构，并将其作为可疑的欺诈行为进行上报。

**加密货币奖励平台 Celsius 第三方邮件系统遭到黑客入侵**加密货币奖励平台 Celsius 称其第三方营销服务器遭到入侵，攻击者获得了其部分客户列表的访问权限。攻击者未经授权访问了一个备份的第三方电子邮件分发系统，该系统关联部分客户的电子邮件列表。一旦攻击者进入系统，就可以在未经授权的情况下，向列表中的客户发送欺诈性电子邮件。攻击者最终的目的是通过提示收件人向其个人钱包地址提供助记词（seed phrase），来窃取收件人个人数字钱包中的加密货币资产。

**俄罗斯紧张局势加剧，Gamaredon 针对乌克兰官员发起新攻击**Anomali 研究人员发现，与俄罗斯有关联的间谍组织 Primitive Bear（也叫 Gamaredon，Winterflounder）正在进行一项针对乌克兰官员的恶意活动，这项活动早在2021年初就开始了。在该活动中，Gamaredon 分发的恶意 .docx 文件，很可能是通过鱼叉式分发，该恶意文件试图通过模板注入来下载远程模板 .dot 文件。大部分 .docx 诱饵文件是用乌克兰语编写的，少部分是用俄语编写的，恶意文档中包含讨论被占领的克里米亚背景下的多个乌克兰政府机构、组织和公共实体以及俄罗斯情报机构的内容。为了使恶意文件看似更正规，Gamaredon 在文件中使用了与2021年1月至3月中旬相关的个人和事件实体的特定名称。通过这种利用真实事件来设计网络钓鱼攻击链路的方式，可以使该黑客组织的攻击更有效。研究人员表示，他们观察跟踪 Gamaredon 使用恶意 .docx 文件分发 .dot 文件已有一年多的时间，但该活动中使用的远程模板域在发现时已关闭。因此，目前尚不清楚该间谍活动的最终有效载荷。

**巴勒斯坦黑客利用社工手段欺骗法塔赫和哈马斯难民营政府官员安装监视软件**

Facebook于近期发布研究报告，报告中揭露了两个巴勒斯坦黑客组织一直在对政府官员、学生团体和安全部队进行网络间谍活动。黑客们利用伪造和失陷的社交媒体帐户来冒充年轻女性，还以法塔赫或哈马斯的支持者、各种军事团体、新闻工作者和活动家的身份与人们建立信任，从而诱使他们安装恶意软件。Facebook 表示，其中一个名为 Arid Viper 的组织与哈马斯的网络部门有联系，另一个与巴勒斯坦安全机构之一的巴勒斯坦预防安全局（PSS）有联系。Facebook 称攻击者使用了功能齐全的定制 iOS 监视软件，无需越狱即可从 iPhone 窃取敏感的用户数据。

**不安全的云存储导致 Eversource 发生数据泄漏**Eversource 是新英格兰最大的能源供应商，为康涅狄格州、马萨诸塞州和新罕布什尔州的430万电力和天然气用户提供动力。近期，由于不安全的云存储服务器导致该公司的客户信息泄漏，泄漏数据包括姓名、地址、电话号码、社会安全号码、服务地址和帐号。Eversource 在3月16日进行了安全审查，发现一个“云数据存储文件夹”的配置错误，导致任何人都可以访问其内容。该文件夹包含2019年8月创建的未加密文件，其中含有11,000名马萨诸塞州东部 Eversource 用户的个人信息。Eversource 称，他们在发现不安全的文件夹的第一时间便对其进行了安全保护，并开始调查该文件夹中存储了哪些数据。Eversource 声明，目前没有迹象表明这些数据被未经授权的人获取或滥用。

**工业系统 OpENer EtherNet/IP 堆栈存在严重漏洞**美国网络安全和基础设施安全局（CISA）于近期发布安全告警报告，称在 OpENer EtherNet/IP 协议栈中发现了多个安全漏洞，攻击者利用这些漏洞可以发起 DoS 攻击、数据泄露、远程代码执行等。目前暂未发现针对这些漏洞的利用。根据 CISA 的漏洞预警，此次共发现5个安全漏洞，分别是1) CVE-2021-27478，数类型之间的错误转化引发的安全漏洞，攻击者利用发送到有漏洞的设备的伪造的请求可以引发 DoS；2）CVE-2020-13556，攻击者利用伪造的网络请求可以引发远程代码执行；3）CVE-2021-27482，越界读取漏洞，攻击者利用伪造的请求可以读取设备上的任意数据；4）CVE-2021-27500，攻击者通过发送给设备的伪造请求可以引发 DoS 攻击；5）CVE-2021-27498，攻击者通过发送给设备的伪造请求可以引发 DoS 攻击。研究人员表示，攻击者只需要构造 ENIP/CIP 数据包发送到设备，就可以利用这些漏洞。

****流行威胁情报****

  

**卡巴斯基发布勒索软件家族 TOP5**

卡巴斯基于近期发布了勒索软件研究报告，公布了2019年以来最活跃的5个勒索软件家族，分别为：1）Maze（又名 ChaCha 勒索软件），于2019年首次被发现，并快速攀升到恶意软件的首位。在所有受害者中，这种勒索软件占了 1/3 以上的攻击。Maze 背后的组织是最早在加密前窃取数据的小组之一。如果受害者拒绝支付赎金，网络犯罪分子会以发布被盗文件进行威胁，Maze 还开创性地开始向媒体披露攻击，2020年9月，Maze 停止运营。2）Conti（又名 IOCP 勒索软件），Conti 出现在2019年末，在2020年期间非常活跃，占这一时期勒索软件受害者总数的13%以上。它的创造者仍然活跃。3）REvil（又名 Sodin，Sodinokibi 勒索软件），该勒索软件的首次攻击是在2019年初在亚洲被发现的，因其技术实力（例如使用合法的 CPU 功能绕过安全系统）迅速引起安全专家的关注。此外，其代码还包含了用于租赁的特征标志。4）Netwalker（又名 Mailto 勒索软件），在受害者总数中，Netwalker 占了 10% 以上。其目标包括物流巨头、工业集团、能源公司和其他大型组织。5）DoppelPaymer 勒索软件，其受害者约占总数的9%，其背后的运营者会综合使用多个恶意软件。

  

来源：https://www.kaspersky.com/blog/top5-ransomware-groups/39426/

**Lazarus APT 组织使用 BMP 图像隐藏恶意代码**

Lazarus 是朝鲜最活跃、最复杂的威胁组织之一，以韩国、美国和日本其他几个国家为目标。Malwarebytes 的研究人员近期发现了 Lazarus APT 组织针对韩国的鱼叉式网络钓鱼攻击活动，并发布了分析报告。在此次攻击活动中，被用来钓鱼的恶意文件是韩国某城市的展览会的参会申请表，打开后显示韩语的蓝色主题，并要求用户启用宏来查看文档。Lazarus 在本次活动中采取了一种很聪明的方式绕过安全机制，当受害者启用宏后，宏通过调用 MsgBoxOKCancel 函数开始，此功能会向用户发送弹窗消息，提示用户 Microsoft Office 版本过旧。显示消息后，它将执行以下步骤：

*   以 base64 格式定义所需的变量，例如 WMI 对象、Mshta 和文件扩展名，然后调用函数对 base64 进行解码。
    
*   获取活动文档名称并将名称与扩展名分开。
*   以 wDFormatHTML 作为参数，使用 ActiveDocument.SaveAs 创建 HTML格式的活动文档副本。将文档另存为 HTML 会将此文档中的所有图像存储在 FILENAME\_files 目录中。
*   调用 show 函数来保护文档。通过保护文档，可以确保用户无法对文档进行任何更改。
*   获取具有嵌入式 zlib 对象的图像文件。
*   通过调用 WIA\_ConvertImage 将 PNG 格式的图像转换为 BMP 格式。
*   获取一个 WMI 对象，以调用 Mshta 执行 bmp 文件。解压缩后的 BMP 文件包含一个 HTA 文件，该文件执行 JavaScript 脚本以删除 payload。
*   删除目录中的所有图像，然后删除由 SaveAs 函数生成的目录。

**Zebrocy 组织针对哈萨克斯坦展开的攻击活动分析**APT28，又名 Sofacy 或 FancyBear，具有俄罗斯背景，自2008年以来开始活跃，主要针对政府、军事和私人组织，该组织因入侵美国民主党全国委员会的电子邮件，试图影响美国总统大选而闻名于世。Zebrocy 被归因为 APT28 的一个子组织。据 SentinelOne 披露，在2021年3月发现 Zebrocy 组织一系列针对哈萨克斯坦的活动，其中涉及以 Delphi 编写的恶意软件 Delphocy，该恶意软件以前与 Zebrocy 相关。据说这些 Word 文档来自一家名为 Kazchrome 的哈萨克斯坦公司，它是世界上最大的铬矿石和铁合金生产商之一。研究人员一共发现了6个与该群集有关的 Delphocy Word 文档，这些文档都包含释放 PE 的相同 VBA 脚本。在6个 Word 文档中，有两个似乎是来自哈萨克斯坦的受害者上传至 VirusTotal 的。

### **SonicWall ES 爆出3个0day漏洞，已被在野利用**

美国 SonicWall 公司的电子邮件安全（ES）产品于近期被爆出存在3个安全漏洞，并且这些漏洞已在野外被积极利用。SonicWall ES 是一种旨在保护电子邮件流量和通信的解决方案，能够抵御通过电子邮件传播的高级威胁，例如勒索软件、零日威胁、网络钓鱼和商业电子邮件入侵 （BEC）。这3个安全漏洞分别是：1）CVE-2021-20021，可以未经授权创建管理帐户，该漏洞是由于 API 端点的安全保护不正确造成的，攻击者通过向远程主机发送特制的 HTTP 请求，创建管理员帐户。2）CVE-2021-20022，认证后任意文件上传，该漏洞允许经过身份验证的攻击者将任意文件上传到远程主机。3）CVE-2021-20023，认证后任意文件读取，目录遍历漏洞，允许经过身份验证的攻击者读取远程主机上的任意文件。攻击者可以组合利用这3个漏洞，以获得 SonicWall ES 设备上的管理访问权限和代码执行权限。研究人员表示，已发现攻击者利用这些漏洞，在易受攻击的设备中植入后门、访问设备上的文件和电子邮件，并在受害网络中进行横向移动。影响版本为 SonicWall  ES 10.0.9 和更早版本，以及 SonicWall HES 10.0.9 和更早版本。微步情报局在此建议提醒受影响的用户，尽快完成更新。
