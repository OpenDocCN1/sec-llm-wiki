**金融威胁情报**

  
**巴西金融公司 iugu 数据库配置错误泄露 1.7 TB 数据**

据国外安全研究人员披露，巴西金融科技 iugu 因为一个严重的安全漏洞暴露了公司所有客户的信息，用户的个人、银行和交易数据至少在一个小时内可在不受保护的服务器上获得。该安全研究人员在 Twitter 披露了这一严重事件，据他表示，4月7日发现的故障涉及所有 iugu 客户，在此期间对公众开放的数据总共 1.7 TB ，第三方可以从安全措施配置不当的服务器下载这些数据。此次事件泄露了从2013年到2021年的敏感数据，包括客户电子邮件、用户名、电话号码和地址、交易记录、文档和其他财务详细信息等。iugu 确认其数据库之一暴露了大约两个小时，仅泄露了备份数据中大约1％的可用信息，据该公司称，该问题已经解决，客户的个人信息、密码、凭证和银行信息没有被公开。

  

来源：https://canaltech.com.br/seguranca/vazamento-expoe-17-tb-de-dados-dos-clientes-da-fintech-brasileira-iugu-na-web-182312/

**印度股票交易平台 Upstox 数据泄露，涉及超250万用户**

印度股票交易平台  Upstox  发布公告称遭受黑客攻击，发生了严重的数据泄露事件，数百万客户的个人信息可能已经被窃取。泄漏数据包括：客户的姓名，联系信息，出生日期，银行帐户信息以及数百万个KYC（Know Your Customer）详细信息，Upstox 认为这些信息是  ShinyHunters 黑客团伙在访问公司的 Amazon AWS 密钥后盗用的。对 KYC 数据的泄露尤其严重，因为它可能包含身份证，护照，带照片的身份证件以及其他文件的扫描件，这些文件可以证明个人的住所，例如水电费账单。此类信息可帮助金融组织确定客户的真实身份，并打击洗钱和资助恐怖主义行为，但如果这些信息落入不法份子之手，则可能被身份盗用者和骗子滥用。

**BRATA 银行木马的多个新变种正在 Google Play 中分发，现瞄准美国和西班牙**最近，McAfee 移动研究小组在 Google Play 中发现了 Android 恶意软件家族 BRATA 的多个新变种，并且它们还伪装成安全应用扫描程序在 Google Play 中传播。在受害者安装后，恶意软件运行会假装扫描所有已安装的应用程序，实际上是在后台检查用户设备中是否安装了目标应用程序。如果检查到，它将根据用户设置的语言，提示用户安装特定的目标应用程序的虚假更新。这些恶意应用程序敦促用户更新 Chrome，WhatsApp 或 PDF 阅读器，但是其实际上并不会进行更新，而是滥用辅助功能以控制用户设备。除巴西外，在西班牙和美国也发现 BRATA 的最新版本可提供针对金融实体用户的网络钓鱼网页。研究人员还发现，攻击者在攻击目标列表中添加了一些西班牙和美国的金融应用程序，在最新的目标列表所显示的20个美国银行应用程序中，就有5个具有钓鱼地址。

**美国肯塔基州失业保险网站遭受网络攻击**

近期，美国肯塔基州失业保险办公室（Kentucky Office of Understance Insurance）网站业务系统遭到网络攻击后关闭，根据官方声明，攻击者试图未经授权访问 UI 客户数据。从4月9日12:01开始关闭其账户业务，并且这次攻击迫使该办公室重置了30多万个 PIN，以阻止欺诈者进入账户并转移福利金。根据官方消息，为加强系统的网络安全能力，失业保险办公室所有处理失业账户的网站和门户网站都被关闭，预计于4月13日上午12时恢复上线。

  
来源：https://www.govinfosecurity.com/kentucky-unemployment-insurance-site-shuttered-after-attack-a-16376

**美国监管机构称，数百家电力公司安装了 SolarWinds 后门程序**

美国监管机构日前表示，与北美电网监管机构共享数据的大约1500家电力公司中，约有四分之一表示他们安装了疑似被俄罗斯黑客植入后门的 SolarWinds 软件。电力公司没有报告黑客的任何重大后续活动，但是该行业的广泛曝光表明了保护电力公司免受供应链攻击具有一定的挑战性。据北美 NERC 公司称，少数下载了恶意程序的电力行业组织在其“operational technology”网络中使用了受影响的 SolarWinds 软件。NERC 还认为，鉴于该产品在电力部门的普及，该安全问题对电力部门的某些部分构成了“潜在威胁”。

  
来源：https://www.cyberscoop.com/nerc-solarwinds-backdoor-electric-sector/

**以色列又对伊朗的纳坦兹核设施进行网络攻击**

据外媒报道，2021年4月10日，伊朗总统鲁哈尼在伊朗核技术日线上纪念活动上下令启动纳坦兹核设施内的近200台 IR-6 型离心机，开始生产浓缩铀。在生产开始的第二天，伊朗纳坦兹核设施的配电系统就发生故障。据称没有造成人员伤亡，也没有任何核污染。以色列媒体 Kan 称，美国和以色列情报机构的情报消息来源表示，以色列摩萨德是对伊朗伊朗纳坦兹核设施进行网络攻击的幕后黑手，该行动导致核设施断电。伊朗原子能组织发言人 Behrouz Kamalvandi 最初报告说，该事件是核设施配电网“事故”的结果。但是，AEOI 负责人 Ali Akbar Salehi 表示，该事件不是意外，而是一次全面的袭击，他将其称为“核恐怖主义行为”。伊朗核设施已经不是第一次遭受攻击，早在2010年就发生过类似的攻击，即众所周知的 Stuxnet 攻击。还有2020年7月2日，纳坦兹核设施主大厅发生火灾，屋顶被烧毁。

  
来源：https://www.jpost.com/middle-east/incident-reported-in-iranian-natanz-nuclear-facility-664792

**NAME: WRECK 漏洞影响近1亿个 IoT 设备**2021年4月13日，国外安全人员披露了 TCP/IP 堆栈中 DNS 协议中统称为 NAME: WRECK 的9个安全漏洞，这些漏洞影响了至少4个 TCP/IP 堆栈，涉及至少1亿个 IoT 设备。如果被成功利用，攻击者可以窃取敏感数据、修改或使设备脱机以对制造行业中的政府或企业服务器、医疗机构、零售商或公司造成重大安全事故。攻击者还可以利用这些漏洞篡改住宅或商业场所的智能设备，以控制供暖和通风、禁用安全系统或篡改自动照明系统。Forescout 在其报告中表示，尽管某些协议并未正式支持压缩，但该功能还存在于许多应用中。值得注意的是，并非 NAME: WRECK 中的所有漏洞都可以被利用来获得相同的结果。利用单个漏洞可能不会造成太大影响，但如果攻击者将它们组合在一起来利用，就可能会造成严重破坏。  
来源：https://blog.alyac.co.kr/3699?category=750247

****流行威胁情报****

  

**隐藏在伪造的 Browserify NPM 软件包中的新型 Linux、MacOS 恶意软件**国外安全人员在 npm 注册表中发现了一个新的恶意程序包 web-browserify，其模仿流行的程序包 Browserify，在该恶意程序包的生命周期内被下载了1.6亿多次。该恶意程序包针对使用 Linux 和 macOS 操作系统的 NodeJS 开发人员。web-browserify 本身是通过组合数百个合法的开源组件而构建的，并在受感染的系统上执行广泛的侦察活动。并且，该组件所包含的 ELF 恶意软件可以躲避大部分杀毒软件的查杀。web-browserify 是由一个匿名作者创建的，该作者称自己是史蒂夫·乔布斯。一旦开发人员安装了 web-browserify，脚本就会从存档中提取并启动运行 Linux 二进制文件，该二进制文件会向用户请求提升的权限或 root 权限。 该恶意软件具有高级侦查和指纹识别功能。它使用另一个合法的 npm 组件 systeminformation 从受感染的系统中收集：系统用户名、操作系统信息（例如制造商/品牌）、有关 Docker 映像的信息、蓝牙连接的设备、系统上存在的虚拟机或启用了虚拟化的虚拟机、CPU 度，型号和核心、RAM 大小等其他信息。

**超过50万台华为安卓设备感染 Joker 恶意软件**

安全软件开发商 Dr.Web 发布安全研究报告，宣称在 AppGallery 中发现了10个看似无害，实则是携带恶意模块的工具软件和游戏软件，据调查，这些软件在华为应用商店下载的次数已超过53.8万。这些恶意软件包含用于连接到恶意命令和控制服务器以接收配置和其他组件的代码。恶意应用程序保留了其广告功能，包含了使用户订阅高级移动服务的组件。当用户下载后，这些软件可以正常使用但会请求通知和短信权限。当用户授予这些权限后，恶意模块就会悄悄发送增值服务短信进行订购，为防止用户发现恶意模块会删除订购短信。另外，为了不让用户发现话费减少的太快，恶意软件还将每用户订阅的服务限制在5个，并且攻击者可以随时修改该限制。

**高级威胁情报**

  

**伊朗背景的 APT34 组织回归，武器库更新**APT34 被认为是一个为伊朗国家利益服务的黑客组织，主要侧重于网络间谍活动，至少从2014年开始就一直处于活跃状态。该组织主要针对中东地区，涉及行业包括金融、政府、能源、化工和电信。Check Point Research 于近期发现了 APT34（又名 OilRig）针对黎巴嫩目标的新的攻击活动的证据，攻击中采用了新变体后门 SideTwist。自2019年一个名为“ Lab Dookhtegan”的实体泄漏 APT34 工具以来，该威胁组织一直在积极改造和更新其有效载荷库，以尝试避免检测，创建了几种不同的恶意软件变体，其最终目的仍然是相同的：在目标设备上驻足。从2018年的 DNSpionage 活动开始，就观察到 APT34 通过使用带有陷阱的工作机会文档通过 LinkedIn 消息直接发送给选定的目标个人。这项活动通过 HardPass 操作一直持续到2019年，其中以相同的方式使用了 LinkedIn 平台。在1月的最新活动中，黎巴嫩（APT34 的共同目标）提交给 VirusTotal 的文件样本中也有类似的工作机会文件。目前仍无法确认目标的初始交付机制。

**漏洞情报**

  

### **Chrome 爆出2个 0day**

近日，国外安全研究员发布了 Chrome 远程代码执行漏洞 0day 的利用代码。Google 在代码库和 beta 测试版中修复了此漏洞，但未将更新推送至正式版，因此该漏洞可以威胁最新的 Chrome 浏览器正式版（89.0.4389.114）。该漏洞涉及 JavaScript 引擎的 JIT 编译器，在即时编译过程中，由于逻辑问题生成了不安全的机器码，导致内存破坏和漏洞利用。如下图所示，如果手动关闭沙箱，Chrome 漏洞被利用并执行 shellcode，shellcode 内容是弹出计算器。该漏洞同样影响了 Chrome 浏览器和 Chrome 内核的 Edge 浏览器。但默认情况下，在沙箱内的浏览器漏洞利用不会有计算器弹出。（漏洞影响及处置办法请见：[Chrome 0day：小心！莫慌~](http://mp.weixin.qq.com/s?__biz=MzA5MDc1NDc1MQ==&mid=2247486847&idx=1&sn=96d68d98ea530952cbf86c1b013f6bec&chksm=900796afa7701fb9b14f0a7da10c5d8498f6fd62ea6d5e2c5c25bc138564a47f73a4cbd7bb51&scene=21#wechat_redirect)）
