05. Pony
2011年 Pony 首次在野外被发现，其主要攻击目标是欧洲和北美的用户。目前发现的最早的 Pony 版本为 1.7，最新版本为 2.2。Pony 主要支持的功能是窃取 FTP 客户端凭据，以及从浏览器中窃取加密货币钱包凭据和其他数据。尽管 Pony 在历史上经过了多次更新，但自从首次被微软发现以来，该恶意软件并未获得突破性的新功能。


发展时间线

  • 2015年 多个版本的源码泄露，导致该恶意软件流行

  • 2016年 添加了混淆等反调试手段，但整体流程及其功能未发生大的变化

06. Remcos

Remcos 是 2016 年起公开售卖的一款远控工具，至今已更新 66+ 个版本，几乎每个月都会更新 1-2 个版本。该工具由一家名为 Breaking Security 的公司出售，虽然该公司表示他们出售的软件只能用于合法用途，对于不遵守其最终用户许可协议的用户将撤销其许可证，但远程控制工具的贩卖给攻击者建立一个潜在的僵尸网络提供了所需的一切条件。


每个 Remcos 许可证的价格从 58 欧元到 389 欧元不等。其开发商 Breaking Security 还支持用户使用数字货币进行支付。这种远控可以完全控制和监测任何 Windows XP 及其之后的包括服务器在内的 Windows 系统。目前，Remcos 仍在出售：


Remcos 主要采用的传播方是钓鱼邮件，附件中包含内嵌了恶意宏的文档样本。目前网络上流行的 Remcos 样本变种一般使用 .Net、Delphi、Autoit 进行开发，并使用 CVE-2017-11882 漏洞利用代码与恶意宏作为攻击组合进行 payload 投放。


发展时间线

  • 2016年 首次公开发行

  • 2016年 v1.5，v1.6 版本发布

  • 2017年 v1.7，v1.8.0，v1.9.0 版本发布

  • 2018年 v2.0.0，v2.1.0 版本发布

  • 2019年 v2.2.0，v2.3.0，v2.4.0，v2.5.0 版本发布

  • 2020年7月10日 v2.6.0 版本发布


从发布说明来看，它目前仍很活跃，特别是小版本，作者几乎每几天就更新一次。

典型样本分析（v1.7 Pro 版本）

1. Remcos 启动时会先解密资源中的 “SETTINGS” 项，从而得到服务器IP、木马功能的各种配置和互斥体名称等。解密后的 “SETTINGS” 项将以 “@@” 作为分隔符，首先被解析，之后存入一个数组，并以数组的索引当作 KEY，方便后续利用 KEY 查找相应的数据。



2. Remcos 利用双重加密算法对 C2 配置信息和通信数据进行加密。解密后发现配置信息中包含 C2 地址、通信密码、互斥量、要窃取的电子邮件客户端凭证的目标服务商和键盘监听信息存放文件名称等信息。


3. 样本运行时将创建互斥体以防止重复运行。



4. 样本采用了多种方式进行反调试和反虚拟机。

(1) 检测自身进程空间是否存在 sbiedll.dll 模块，该模块是沙箱监控的重要模块之一，因此可以使用该方法来检测自身是否正运行在沙箱环境中。


(2) 查询注册表 VBOX 是否在沙箱环境中。


(3) 检测 PEB 是否在调试模式中。


(4) 检测 VM 虚拟机环境。


5. 通过 CMD 命令改变注册表项，更改系统的安全特性。


6. 把自身拷贝到 C:\\Users\\username\\AppData\\Roaming\\remcos\\remcos.exe\


7. 把自身副本文件添加进注册表自启动项实现持久化。


8. 解密生成的 .bat 脚本文件，实现启动副本文件。


9. 后续样本通过判定自身的路径以及前期生成的互斥体、注册表项，来执行不同的行为。如访问注册表项 HKEY_CLASSES_ROOT\\http\\shell\\open\\command 的键值获取到默认浏览器的路径，进而以挂起的方式打开。


10. 打印日志信息，1.7 Pro版本的样本会在代码里内嵌木马的版本和制造商 Breaking-Security 的信息。


创建浏览器进程成功之后在目标进程申请空间，把自身 PE 文件写入目标进程空间，在获取线程上下文，并设置目标进程 EIP 后恢复该挂起的进程，最终退出自身模块，剩余的恶意行为交给浏览器中注入的恶意代码来执行。


11. 创建新的线程 Hook 键盘消息，使用消息循环记录键盘操作，并在样本同一路径下生成 logs.dat 文件以记录获取到的按键数据。


12. 窃取系统中存在的浏览器的 cookies 和记住登录的信息。


13. 使用 WAVEFORMATEX 结构体相关 API 实现录音功能。


14. 接收并执行 C2 下发远程控制指令。其中包括键盘信息监听、文件操作、系统进程操作等远程控制操作。同时通过清洗浏览器 Cookies 信息迫使受感染设备用户在浏览器登录电子邮箱时重新输入用户信息凭证，配合木马的键盘监听功能及时记录用户信息凭证。

07. Hawkeye

Hawkeye 是一款窃取信息的恶意软件，在地下黑客市场出售，此恶意软件曾在 2016 年的一次大规模网络攻击活动中被广泛使用。2018 年，Hawkeye 的作者开始出售新版的恶意软件，被称为 Hawkeye Keylogger-Reborn v8。尽管 Hawkeye 一直在重申其本身仅用于教育目的，但从其功能来说显然具备了恶意行为的各种能力。


目前 Hawkeye 的主要传播方式是垃圾邮件，欺骗受害者打开并运行恶意软件，从而达到盗取受害者敏感信息的目的。


发展时间线

  • 2013 v1 版本发布，为简单的键盘记录器

  • 2017 v7 版本更新发布，将主 payload 程序加载到自己的进程中

  • 2018 v8 版本更新发布，将主 payload 程序注入到 MSBuild.exe、RegAsm.exe、VBC.exe 等进程中

  • 2019 v9 版本更新发布，可加载插件：密码查看器 WebBrowserPassView 和邮件密码恢复工具 MailPassView

典型样本分析（v8 版本）

1. HawkEye 核心 payload 会经过前期的好几层包装混淆，大部分样本采取的是 .net 加载解密资源和 autoit 的方法。


2. 加载 .net 资源段 ConfigurationFiles4 文件，dump 后是个 .net 编写的 dll 文件，通过 sdasad 函数调用 dll 的导出函数对资源进行再一次的解密，最终得到解密并执行的 payload 文件。


3. 解码后的 payload 也经过 ConfuserEx v1.0.0 的打包以保护自己。


4. 解密后的代码此样本将主 payload 代码注入到了 .net 框架下的 RegAsm.exe 进程。


5. 样本母体会对 vbc.exe 进行注入并窃取信息，可以把该注入的 PE 文件 DUMP 下来，发现此 PE 文件带有正规的签名，查找 “Nir Sofer” 公司的信息，发现此公司主要开发一些密码恢复相关的工具。由此可以看出窃取密码和浏览器数据的软件就是 “Nir Sofer” 公司开发的 “WebBrowserPassView” 和 “MailPassView” 应用程序。
