概述


Donot “肚脑虫” 是疑似具有南亚背景的 APT 组织，主要以周边国家的政府机构为目标进行网络攻击活动，通常以窃密敏感信息为目的。该组织具备针对 Windows 与 Android 双平台的攻击能力。


近日，微步在线情报局捕获到一批 Donot APT 组织最新投递的 Windows、Android 双平台恶意样本，经过分析得出以下结论：

  • 攻击所用样本都使用 .rtf 文件进行投递，利用 .rtf 文件进行模板注入或利用 .rtf 的漏洞投递并执行文件。
  • 疑似攻击目标为泰国，所使用的诱饵文档标题为“泰国皇家海军第82司令部参谋长课程.doc.rtf”、“OPS 清除详细信息”、“合同副本”等内容为标题，而诱饵文档几乎都为空，文档运行后无任何诱饵内容。
  • 我们对当前样本提取了 C2，并进行了拓线分析，发现 Donot 的资产在2月底已经被标记为恶意软件、远控。

样本分析


2.1 AM.rtf

AM.rtf 样本中嵌入了两个对象，一个是启动了宏代码的工作簿、另一个是名为 “file.zip” 的压缩包，压缩包内带有宏代码将执行的恶意文件。


查看启用宏的工作簿，可发现工作簿的作用为从文件 “file.zip” 中解压出文件，并释放到 C:\Winodws\Tasks 目录下，并为后续文件创建 .lnk 快捷方式实现开机自启。


从 “file.zip” 解压出的文件分别为 “commit.dll”、“pvr.js”、“sce.js”，创建的自启动 .lnk 文件 “carrier.lnk”与“host.lnk” 分别为 “scr.js”、“pvr.js” 实现持久化操作。


在运行过程中，“sce.js” 中没有任何代码，而 “pvr.js” 则启动 Runll32 调用 “commit.dll” 中的 “Solar” 函数。


 “Solar” 函数依然为下载器，并且有反调试、检测杀软等功能。如下图所示，利用虚拟机 VMware 后门 IO 端口反调试，检测到虚拟机则退出。

2.4 OPS_requirements.rtf

同样的使用模板注入的方式执行代码，从远程地址 http://requireplugin.xyz/jack/AaTCm1uhEJlKxjeAvwltK5pkzRasnhXo.dot 下载模板并执行模板内恶意代码。


下载回来的是一个 .dot 模板，模板内使用 CVE 2017-11882 漏洞，利用栈溢出再次从 C2 地址 requireplugin.xyz/ 下载 PE 文件执行。


下载回的 PE 文件，为 Donot 组织常用的下载器，在最终链接 C2 下载后续文件前，会通过连接维基百科检测网络状况，如果连接维基百科失败，则不会解密出最终的 C2 地址。


最终还是获取受害主机信息，将受害主机信息加密后，与字段 “data=” 相拼接并发往 C2 地址并下载后续内容。

总结


在本次捕获的样本中，根据能获取到后续的样本来看，Donot 和以往有所不同，不再使用 .doc 文档进行模板注入，而是使用 .rtf 文件进行模板注入，后续操作则和以往相同，模板利用计划任务执行后续载荷。本次样本的载荷都为 Donot 组织的下载器，只是在截至分析时，未能获取到最终的攻击载荷。


从域名来看，本次样本所有的第二阶段下载地址的 url，都是由 [domain\jack\随机字符] 组成，在最终载荷的下载中，使用 Windows 的函数或 WMI 查询受害者主机信息，加密后拼接在字段 “data=” 后，发往 C2 地址下载最终攻击载荷。
