前言


近年来，窃密类木马（PWS, Password Stealer）越来越流行。与传统的勒索、挖矿木马所不同的是，其主要攻击目标是为窃取用户的各种敏感信息，包括但不限于各种账号密码、登录凭据、电子货币密钥和各种文档资料等。


窃密类木马往往能为攻击者带来更多的收益，编写也更为精密。网络上曾出现过多种“声名显赫”的商业级木马，如 AgentTesla、FormBook、HawkEye 等，这些商业级木马一般由专门的高水平团队更新和维护，发展十分迅速，功能越来越丰富，配置越来越简单，同时售价也并不昂贵，大大降低了攻击者使用的门槛，因此备受攻击者的青睐。


窃密类木马最常用传播方式是钓鱼邮件。这些钓鱼邮件通常以时下人们最为关注的热门话题为题目，如在刚刚过去的2020年，“新冠疫情”相关内容无疑成为攻击者最常用的题目。在钓鱼邮件的附件中，我们经常能够发现包含宏病毒和漏洞利用相关代码的 office 文档，当用户点击并运行相关恶意代码后，木马将无孔不入，渗透到系统的方方面面，尽可能地窃取用户的各种敏感信息。


我们总结了近年来较为活跃的窃密类木马，从发展时间线、家族画像等维度对相关木马进行了介绍，并对于重要版本中的典型样本进行了详细分析，期待能够帮助读者更加全面地认识和理解窃密类木马。

01. AgentTelsa

2014年，Agent Tesla首次出现在一个土耳其语网站上，被作为一个键盘记录产品进行出售。虽然网站声称该产品仅向用户提供合法服务，但其所提供的绕过杀软、秘密捆绑程序和敏感文件传输等功能与窃密木马相比也不遑多让，甚至更为精密。因此人们更倾向于认为它是一种专门用来窃密的软件，直到后来，Agent Tesla 逐渐开始在地下论坛和黑客社区流行起来，售价一般从 15 美元到 69 美元不等，交易往往通过比特币等方式。


如今，Agent Tesla 历经多次代码改进，功能不断增强，已经成为能够盗取浏览器、FTP、VPN、邮箱和 WIFI 等多种敏感信息的专业窃密软件。


发展时间线

  • 2014年 首次公开在官网进行售卖

  • 2017年 采用 http 协议进行传输数据

  • 2018年 开始采用 smtp 进行数据传输

  • 2020年 添加获取 WIFI 信息功能，可窃取 WIFI 密码等信息

02. Lokibot

历史上，Lokibot 曾在多个黑客论坛出现，如2015年的 Carter、2015年的 lokistov 和2016年的 Anonymous 等。用户可在相关论坛中购买到定制样本，起初的价格400美金。之后，由于源码遭到泄露，网上逐渐出现很多其他版本，平均售价大约80美金。如今，Lokibot 主要以垃圾邮件附件的方式传播，其 Payload 多以 zip 压缩文件和包含 Office 恶意宏的文档形式出现。


发展时间线

  • 2015年 开始在地下论坛进行销售并提供私人定制

  • 2016-2017年 持续开发到2.0版本，增加多个模块如获取加密货币凭证等

  • 2018年 源码泄露导致价格下跌严重

  • 2020年 lokibot 依旧流行，并且增加了更复杂的混淆和 shellcode 代码

典型样本分析（2.0版本）

1. 样本的主要运行流程是，先进行初始化，再设置持久化，随后是和c2链接传数据。


2. 样本在初始化时会首先动态获取所需要的 API。


3. 样本通过创建互斥体防止重复启动。


4. 样本通过修改注册表自启动项来实现持久化。


5. 样本中记录了支持窃取敏感信息的应用，主要包括浏览器、FTP 客户端软件等。


6. 样本解密出 C2 地址，并进行连接通讯。


7. 样本主要通过 http 协议进行数据传输。


03. FormBook

FormBook 于2016年开始在互联网上售卖，开发者宣称其支持键盘记录、浏览器数据获取和屏幕截图等功能。与常规恶意软件不同的是，FormBook 并不在地下论坛和暗网上出售，而是堂而皇之地在一些公开的网站推广出售，如在 HackForums.net 论坛中曾出现过相关的宣传广告：


与此同时，FormBook 功能强大，支持键盘记录、文件恢复和剪贴板监控等多种功能，窃取信息的应用也十分广泛，几乎囊括了大多数的浏览器、即时通讯软件以及其他软件。


另外，FormBook 在反分析和反检测上的表现同样出色，相关木马经常会伪装成 Office 文档或 pdf 文件的图标等，具有很强的迷惑性。在运行后，会将自身注入到正常程序中逃避检测，最终与 C2 地址进行连接，并传输信息和接收指令。


发展时间线

  • 2016年 作者在互联网上公开售卖 FormBook

  • 2017年 样本发展到2.6和3.0版本

  • 2018年 样本开始使用 NTDLL 重载进行 API 调用

  • 2019年 出现使用 mshta.exe 和 VB 脚本来提高持久性

  • 2020年 利用新型冠状病毒大规模传播垃圾邮件

04. SmokeLoader

SmokeLoader 也被称为 Dofoil，是一种模块化的恶意软件。它主要功能是加载其他的恶意程序到受害主机上。但它自身也具备窃取数据的能力。SmokeLoader 在2011年出现，起初是被开发者在地下论坛进行售卖，通常 SmokeLoader 只会被售卖给俄罗斯的黑客或组织。SmokeLoader 比较有特点的地方是会频繁访问合法网站来试图隐藏自己的 C2。


发展时间线

  • 2011年 开发者开始在地下论坛销售

  • 2014年 开始只对说俄语的客户出售

  • 2017年 针对一些字符串进行 xor 加密，并在代码中加入大量混淆

  • 2018年 加入挖矿模块

  • 2019年 使用 PROPagate 方法进行注入，并更新防 hook 和反虚拟机机制

典型样本分析（1.2版本）

1. 样本首先分配内存并修改保护属性，以便于执行 shellcode。


2. 获取必要的 API 函数地址。


3. 开启一个新的自身进程进行 process hollowing 注入，注入的内容为 SmokeLoader 核心代码。


4. 样本代码中存在大量的混淆，并存在反调试机制。


5. 样本采用重载 ntdll 的方式来避免 hook。


6. 样本通过检测注册表项的方式反虚拟机。


7. 样本调用 NtOpenProcess 打开 explorer.exe 进程，准备注入。


8. 创建 Section，进行内存文件映射。


9. 读取样本内记录的 url。


10. 样本后续和 C2 地址进行通信。
