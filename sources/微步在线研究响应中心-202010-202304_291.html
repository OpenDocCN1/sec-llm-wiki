金融威胁情报


PGMiner：通过 PostgreSQL 传播的新加密货币挖矿僵尸网络
最近，Unit42 研究人员发现了一个新的基于 Linux 的加密货币挖掘僵尸网络 PGMiner，该僵尸网络以脆弱的 PostgreSQL 数据库为攻击目标，试图连接到矿池进行 Monero 挖矿。研究人员认为，PGMiner 是第一个通过 PostgreSQL 交付的加密货币挖掘僵尸网络。值得注意的是，恶意软件操控者不仅已开始对已确认的 CVE 进行武器化，且对有争议的 CVE 也进行了武器化。研究人员还指出，PGMiner 运营商之后可能会转向 Windows、Macos 系统。

来源：https://unit42.paloaltonetworks.com/pgminer-postgresql-cryptocurrency-mining-botnet/



IBM Trusteer 披露移动银行欺诈活动

IBM Security Trusteer 的移动安全研究团队最近发现了一个重大的移动银行欺诈活动，在每次攻击被拦截之前，几天之内就从欧洲和美国的金融机构窃取了数百万美元。攻击者利用移动设备模拟器的基础设施来设置数以千计的欺骗设备，通过这些仿真器重复访问数千个客户帐户，用自动化、脚本化和潜在性访问移动恶意软件僵尸网络或钓鱼日志的方式，掌握受害者的用户名和密码，发起并完成大规模欺诈交易，仅需几天就可以窃取数百万美元。研究人员表示，幕后黑手可能是一个有组织的团伙，有机会接触到熟练的手机恶意软件技术开发人员，以及精通欺诈和洗钱活动的人。


来源：https://securityintelligence.com/posts/mobile-emulator-fraud-robs-banks-of-10m-in-days/




能源威胁情报


SolarWinds 软件遭黑客入侵，影响多家电力及能源企业
据报道，SolarWinds 旗下的 Orion 基础设施管理平台遭到黑客恶意篡改，幕后黑手疑似是 APT29（也被称为 Cozy Bear，CozyCar，CozyDuke 和 Grizzly Bear）。攻击者通过将软件更新程序木马化，以污染供应链方式入侵了北美、欧洲等地区的政府，而科技、电力、石油、天然气和制造行业也深受其害。大多数企业在其 ICS 网络中使用了 SolarWinds 软件的受损版本 ，攻击者是否可以访问这些 ICS 网络取决于取决于这些公司的架构。确保供应链安全一直是电力公司和能源组织关注的焦点，专家表示，SolarWinds 公司的这场考验对该行业的其他人来说可能是一次学习经验。


来源：https://www.cyberscoop.com/solarwinds-hack-dragos-ics-breach/



工控威胁情报


POS 设备存在安全漏洞，攻击者可用其进行诈骗

销售终端设备制造商 Verifone 和 Ingenico 发布了 POS 设备安全漏洞的修复补丁，这些漏洞可能会让攻击者窃取支付卡数据、克隆支付卡或安装恶意软件，研究人员敦促设备所有者立即应用供应商提供的补丁。POS 设备主要容易受到默认密码设置的攻击，攻击者只需通过谷歌密码即可访问任何新设备。一旦获得了对这些设备中服务模式的访问，攻击者就可以利用堆栈溢出和缓冲区溢出漏洞执行任意代码执行，通过发送任意数据包、克隆卡、克隆终端、获得持久性来进行攻击。研究人员说，默认密码设置中的漏洞以及任意代码执行会影响 Verifone VX520、Verifone MX 系列和 Ingenico Telium 2 系列，这些产品都在广泛使用中。

流行威胁情报


Goontact：一种正在移动端兴起的针对亚洲地区的勒索软件

间谍软件 Goontact 通过 Telegram 和其他伪装的安全消息应用吸引 iOS 和 Android 手机成人网站的活跃用户，并窃取其信息以用来敲诈或勒索。该间谍软件的目标用户是三陪服务网站和其他性服务网站的用户，尤其是在中文国家、韩国和日本，窃取的数据包括电话号码、联系人列表、短信息、照片和位置信息。研究人员称，iOS 系统攻击窃取数据的能力较弱，基于 android 的攻击威胁能力更强。Goontact 是一种新的恶意软件，最好的活动发现于2018年。


来源：https://blog.lookout.com/lookout-discovers-new-spyware-goontact-used-by-sextortionists-for-blackmail



黑客利用 Pastebin  C2 通道传播 njRAT 木马

研究人员发现，njRAT 远程访问木马运营商正在利用 Pastebin C2 通道来承载有效载荷并逃避检测。njRAT（也被称为 Bladabindi）是一种流行的 .NET RAT，允许攻击者接管受感染的计算机，它支持多种功能，包括截屏，泄漏数据，键盘记录，杀毒程序（如防病毒程序）以及下载第二阶段有效负载等。攻击者利用 njRAT 从 Pastebin 下载并提供第二阶段有效负载，Pastebin 是一个流行网站，可匿名存储数据。攻击者利用这一服务发布恶意数据，恶意软件可以通过一个简短的 URL 访问这些数据，避免使用他们自己的命令和控制（C2）基础设施，能够大大降低被检测的概率。


来源：https://unit42.paloaltonetworks.com/njrat-pastebin-command-and-control/


Mount Locker 勒索软件具备双重勒索功能
BlackBerry 安全研究人员发现，MountLocker 勒索软件已经开发出新功能，使其能够扩大目标范围并逃避安全软件检测，并具有向被攻击者发起双重勒索攻击的能力。MountLocker 是勒索软件即服务（RaaS）的代表，自 2020 年 7 月以来一直处于活动状态。MountLocker 背后的攻击者利用具有损害凭据的远程桌面（RDP）来访问受害者的环境，通过 CobaltStrike Beacon 和 AdFind 进行部署，并通过 FTP 上传关键数据。MountLocker 使用 ChaCha20 进行文件加密，并使用 RSA-2048 进行密钥加密。MountLocker 在加密之前窃取文件，要求受害者支付巨额赎金，这种手段被称为双重勒索。


来源：https://blogs.blackberry.com/en/2020/12/mountlocker-ransomware-as-a-service-offers-double-extortion-capabilities-to-affiliates



高级威胁情报


越南 APT 组织海莲花利用 Facebook 传播恶意软件

越南 APT32 组织和孟加拉国的一个不知名的威胁组织通过 Facebook 账户和页面进行钓鱼攻击和恶意软件攻击，Facebook 已关闭了其账户。Facebook 安全人员称，越南团伙攻击行动主要在于向目标发送恶意软件，而来自孟加拉国的攻击行动则专注于通过跨平台来攻击账户，使目标账户和页面从Facebook上删除。总部位于孟加拉国的组织针对本地及海外的活动人士，记者和宗教少数派，入侵其 Facebook 帐户，并以 Facebook 使用规则为由禁用其账号。APT32，又称海莲花，是一个越南 APT 组织，至少从 2013 年开始活跃。APT32 主要针对越南的人权活动人士，以及多个外国政府（包括老挝和柬埔寨的政府）、非政府组织、新闻机构和一些企业。APT32 常用攻击手段包括社会工程、恶意 Play 商店应用、恶意软件传播等。


来源：https://about.fb.com/news/2020/12/taking-action-against-hackers-in-bangladesh-and-vietnam/



朝鲜 APT 组织 Thallium 仿冒韩国区块链公司文件发起恶意攻击
据韩媒报道，Thallium 组织利用伪装成韩国区块链公司的个人违约确认文件进行恶意攻击。该恶意文档的文件名包含特定人名，运行文档时会弹出诱导用户的安全提示，一旦用户点击允许内容，恶意的宏观代码就会启动，并与攻击者指定的命令控制（C2）服务器进行通信，窃取用户信息。文件的内容包含违法工人和业主个人信息，经确认，业主是韩国区块链解决方案公司。该文件内容与此前 Thallium 组织利用美国大选预测的攻击文件如出一辙。虽然尚未确定攻击者如何获得了相关文件，并将其用于攻击，但由于是包含个人信息的文件，所以不太可能是在网上自由公开的文件。

来源：https://blog.alyac.co.kr/3458



应急响应之 Linux 下进程隐藏

黑客获取系统 root 权限时，为了实现持久化控制往往会创建隐藏恶意进程，这为应急响应人员取证带来了难度，隐藏进程的方法分为两类，一类是用户态隐藏，另一类是内核态隐藏。用户态常使用的方法有很多，例如劫持预加载动态链接库，一般通过设置环境变量 LD_PRELOAD 或者 /etc/ld.so.preload，过滤 /proc/pid 目录、修改进程 PID 等等。内核态隐藏进程一般是加载恶意的内核模块实现进程隐藏，微步在线研究响应团队就应急响应场景中遇到过的 Linux 操作系统进程隐藏的手段以及检测方法进行了披露。
