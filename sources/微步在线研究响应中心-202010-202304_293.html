金融威胁情报


银行木马 TrickBot 针对固件攻击进行功能升级
据报道，银行木马 TrickBot 增加了一个名为 TrickBoot 的新功能，该功能利用易于使用的工具来检查设备是否存在众所周知的漏洞，然后将恶意代码注入设备的 UEFI / BIOS 固件中，达到持久存储恶意软件的有效机制，并使普通的反恶意软件解决方案无法检测到该恶意软件。TrickBoot 以引导过程开始的 SPI 闪存芯片为目标，利用流行的 RWEverything 工具中的 RwDrv.sys 驱动程序与 SPI 控制器进行交互，并检查 BIOS 控制寄存器是否已解锁。研究人员指出，TrickBoot 仅需要一小段代码，就可以对发现的任何易受攻击的设备进行加密。TrickBot 能够窃取凭据、电子邮件、财务数据和传播文件加密勒索软件的恶意负载感染系统，例如 Conti 和 Ryuk。为减轻此类威胁，建议保持固件最新，启用 BIOS 写保护，并验证固件完整性以防止未经授权的修改。

来源：https://eclypsium.com/wp-content/uploads/2020/12/TrickBot-Now-Offers-TrickBoot-Persist-Brick-Profit.pdf



支付卡处理巨头 TSYS 遭到勒索软件攻击

TSYS 是北美第三大金融机构的第三方支付处理器，也是欧洲的主要处理器。TSYS 提供支付处理服务、商业服务和其他支付解决方案，包括预付借记卡和工资卡。12 月 8 日， Conti 勒索软件团伙（也称“Ryuk”）发布消息称其从 TSYS 网络中删除了超过 10G 的数据，并声称到目前为止公布的数据只占他们在 TSYS 内部引爆勒索软件之前从该公司卸载的信息的 15%。TSYS 回应确认遭到攻击，但表示此次攻击并没有影响支付卡处理系统，并且已立即遏制了可疑活动，业务运行正常。


来源：https://krebsonsecurity.com/2020/12/payment-processing-giant-tsys-ransomware-incident-immaterial-to-company/



政府威胁情报


俄罗斯黑客利用 VMware 漏洞进行间谍活动

近日，美国国家安全局（NSA）警告称，与俄罗斯有关的黑客正在利用 VMware 漏洞进行网络间谍活动。受此漏洞影响的产品是 VMware®Workspace One Access，Access Connector，Identity Manager 和 Identity Manager Connector。要利用此漏洞，首先需要恶意行为者有权访问设备的管理界面。此访问权限可以使攻击者伪造安全断言标记语言（SAML）凭据，以发送看似真实的请求来访问受保护的数据。NSA 敦促相关机构和企业尽快应用供应商发布的补丁，以解决上述问题。


来源：https://media.defense.gov/2020/Dec/07/2002547071/-1/-1/0/CSA_VMWARE%20ACCESS_U_OO_195076_20.PDF



MoleRats 利用 Facebook 和 Dropbox 监视中东地区政府官员
据悉，MoleRats 黑客组织正在利用最近的外交活动来进行间谍活动。该组织利用带有耸人听闻标题的网络钓鱼邮件来监视中东地区的政府官员。他们利用 Facebook 和 Dropbox 等主流技术服务掩盖其恶意活动，并窃取数据。Cybereason 称，此次 MoleRATs 间谍活动发生在 10 月和 11 月，目标是埃及、巴勒斯坦领土、阿联酋和土耳其的政府官员。该网站的钓鱼邮件引用了沙特王储穆罕默德·本·萨勒曼、以色列总理本杰明·内塔尼亚胡和美国国务卿迈克·蓬佩奥之间的秘密会谈。调查结果显示，黑客使用 Facebook 来协调其活动，并使用 Dropbox 存储其间谍工具并窃取被盗数据。

来源：https://www.cybereason.com/hubfs/dam/collateral/reports/Molerats-in-the-Cloud-New-Malware-Arsenal-Abuses-Cloud-Platforms-in-Middle-East-Espionage-Campaign.pdf




工控威胁情报


33 个连接漏洞致使数百万个 IT/IoT 设备易受攻击

Forescout 研究实验室发现了 33 个漏洞（命名为 AMNESIA: 33），这些漏洞影响了数百万个IoT、OT 和 IT 设备。其中有四个漏洞很关键，攻击者可以利用它们来远程接管从智能冰箱到电网中工业网络交换机的设备。一旦攻击者利用了这些漏洞，就可以访问受影响设备上的数据或功能。这是今年第二次出现可能影响大量设备的 TCP/IP 堆栈漏洞。Forescout 报告指出，TCP / IP 堆栈中的某些漏洞允许利用设备，即使该设备仅位于网络中而没有运行特定的应用程序。由于TCP / IP 堆栈是开源的，单个漏洞往往很容易会悄无声息地在多个代码库、开发团队、公司和产品之间传播。Forescout 估计有 150 个信息技术，运营技术和物联网供应商易受 AMNESIA: 33 的攻击。


来源：https://www.forescout.com/company/resources/amnesia33-how-tcp-ip-stacks-breed-critical-vulnerabilities-in-iot-ot-and-it-devices/



流行威胁情报


富士康遭勒索软件 DoppelPaymer 攻击，索要 3400 万美元赎金
据报道，位于墨西哥华雷斯城的富士康 CTBG MX 工厂遭到勒索软件 DoppelPaymer 攻击，并被要求支付 3400 万美元赎金，该工厂网站已瘫痪。DoppelPaymer 称此次攻击针对富士康北美地区的非工作站，加密了约 1200 台服务器，窃取了 100GB 的未加密文件，并删除了 20-30TB 的备份内容。富士康表示正在对受影响的系统进行检查，并分阶段恢复运行。

来源：https://www.bleepingcomputer.com/news/security/foxconn-electronics-giant-hit-by-ransomware-34-million-ransom/



高级威胁情报


黑客雇佣组织开发出新型 PowerShell 后门

卡巴斯基研究人员发现了一个新的基于 Windows PowerShell 的内存后门 PowerPepper，该恶意软件由黑客雇佣组织 DeathStalker 开发，可以执行远程发送的 shell 命令。其植入程序通过各种技巧来逃避检测或沙盒执行，例如检测鼠标移动，过滤客户端的 MAC 地址以及根据检测到的防病毒产品调整其执行流程。DeathStalker 是一个雇佣黑客组织，至少从 2012 年开始活跃，目标涉及全球各地的组织机构和企业，包括金融公司、律所等。PowePepper 于 2020 年 7 月中旬从一个欺骗性的 Word 文档中被发现，它利用 DNS over HTTPS (DoH) 与 C2 服务器通信，从攻击者控制的服务器上传输加密的恶意 shell 命令。PowerShell 主要用于攻击亚洲、欧洲和美国的法律和咨询公司。


来源：https://securelist.com/what-did-deathstalker-hide-between-two-ferns/99616/



SideWinder 组织利用南亚问题进行鱼叉式网络钓鱼攻击

趋势科技最近发现了 SideWinder 组织用于传播恶意 LNK 文件并托管凭据的多个网络钓鱼页面服务器。该组织的目标主要包括在尼泊尔和阿富汗的多个政府和军事单位。发送收集的凭据后，一些网络钓鱼页面会将受害者重定向到其他文档或新闻页面。这些页面和文档的主题要么与 COVID-19 有关，要么与尼泊尔、巴基斯坦、印度和中国之间最近的领土争端有关。此外，这些诱饵似乎是通过网络钓鱼链接分发的。其中包括利用 CVE-2017-11882 漏洞的恶意 RTF 文件样本。SideWinder 在 2020 年非常活跃。今年早些时候，该组织被曝利用 Binder 漏洞攻击移动设备，还利用与 COVID-19 组织有关的诱饵文件对巴基斯坦、孟加拉国和中国发动了袭击。


来源：https://www.trendmicro.com/en_us/research/20/l/sidewinder-leverages-south-asian-territorial-issues-for-spear-ph.html



APT28 组织用 COVID-19 诱饵投递 Zebrocy

Intezer 研究人员在 11 月发现用于提交 Go 版本 Zebrocy 的 COVID-19 网络钓鱼诱饵。Zebrocy 是威胁组织 Sofacy 使用的恶意软件，也被称为 Sednit、APT28、Fancy Bear 和 STRONTIUM。该恶意软件于 2015 年首次使用，2017 年被卡巴斯基披露，主要用于针对从事外交事务的政府和商业组织。研究人员发现的诱饵包括有关国药国际公司的文件和民航总局的虚假撤离信，国药国际公司生产的 COVID-19 疫苗目前正在进行三期临床试验。诱饵文件是作为虚拟硬盘（VHD）文件的一部分提供的，要求受害者使用 Windows 10 访问这些文件。一旦用户双击该文件，则将安装该驱动器，并显示为外部硬盘驱动器。VHD 文件包括两个文件，一个包含国药控股国际公司演示幻灯片的 PDF 文档，和一个伪装成 Microsoft Word 文档的可执行文件，即用 Go 语言编写的 Zebrocy 恶意软件。


来源：https://www.intezer.com/blog/research/russian-apt-uses-covid-19-lures-to-deliver-zebrocy/




漏洞情报


Microsoft Teams 曝出零点击可蠕虫 RCE 漏洞
近日，安全研究人员 Vegeris 披露了 Microsoft Teams 的一个零点击、可蠕虫的跨平台 RCE 漏洞。该漏洞可能由 team.microsoft.com 中的新型 XSS（跨站脚本）注入触发，可以将特制的聊天消息发送到任何 Microsoft Teams 成员或渠道，并在无需任何用户交互的情况下在受害 PC 上执行任意代码，取得计算机完整访问权限，也可通过这些计算机访问公司内部网络。通过将受害者重定向到攻击者的站点或请求 SSO 凭据输入，该漏洞也可能会引发网络钓鱼攻击。该漏洞影响 2020 年 8 月 31 日以前的 MacOS、Windows 及Linux PC机版 App，包括 Teams macOS 1.3.00.23764 版、Teams Windows 1.3.00.21759 版及 Teams Linux 1.3.00.16851 版。

来源：https://github.com/oskarsve/ms-teams-rce/blob/main/README.md
