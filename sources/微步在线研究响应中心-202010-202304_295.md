**金融威胁情报**

  
**卡巴斯基发布对2021年金融攻击的预测**

继发布了2021年高级网络威胁预测之后，卡巴斯基又对2021年金融攻击进行了预测，包括：受COVID-19 影响，将会出现更多针对比特币的欺诈行为；MageCart 攻击将从客户端转移到服务器端；为提高利润，网络犯罪将会减少外包，偏向内部化；来自受经济制裁国家的高级威胁参与者可能更多地依赖于仿效网络犯罪分子的勒索软件；勒索软件团伙将会利用 0day 和 Nday 漏洞以获取更大利润；美国将加大网络犯罪的打击力度；网络犯罪分子可能会使用其他增强隐私的货币（例如 Monero）作为过渡加密货币向受害者收费；针对金融资产的敲诈勒索持续上升等等。卡巴斯基称 2020 年的大多数威胁将在明年持续存在。

  

来源：https://securelist.com/cyberthreats-to-financial-organizations-in-2021/99591/

  
  
**Gootkit 银行木马或可为 REvil 勒索软件服务**据悉，德国近日遭到 Gootkit 攻击。Gootkit 是一个功能强大的银行木马，自 2014 年以来一直存在，旨在窃取金融相关信息。在最新的攻击活动中，攻击者通过使用诱饵论坛模板来诱骗用户下载恶意文件，从而依靠受感染的网站对用户进行社交工程。分析发现，受害者会收到 Gootkit，在某些情况下则会收到 REvil（Sodinokibi）勒索软件。攻击者使用了一个非常聪明的装载器，执行一系列步骤来逃避检测。鉴于有效负载是使用随机命名的密钥存储在注册表中的，因此许多安全产品将无法检测到并删除它。研究人员发现这个装载器在某些情况下为 REvil 勒索软件服务，这是一项惊人的发现，银行恶意软件变成了勒索软件的加载器，这让不同的攻击者可以专注于各自最擅长的领域。

**政府威胁情报**

  

**俄罗斯 APT 组织 Turla 利用新恶意软件 Crutch 攻击欧盟国家**

ESET 研究人员发现，俄罗斯 APT 组织 Turla 使用了一款名为 Crutch 的新恶意软件，针对包括某欧盟国家外交部在内的知名目标发起网络间谍活动。Turla 组织（又名 Snake，Uroburos，Waterbug，Venomous Bear 和 KRYPTON）自 2007 年以来一直活跃在中东、亚洲、欧洲、北美和南美以及前苏联集团国家的外交和政府组织以及私人企业中。曾攻击过多个机构，如瑞士国防公司 RUAG、美国国务院和美国中央司令部。自 2015 年以来，Crutch 框架就被用于窃取敏感数据，并将其转移到 Turla 的 Dropbox 账户。专家认为，Crutch 是 Turla 使用的第二阶段后门，通过 DLL 劫持来获取 Chrome、Firefox 或 One Drive 上受损设备的持久性。Crutch 能够通过滥用合法的基础设施（这里指 Dropbox）绕过一些安全层，伪装成正常的网络流量，以便窃取文档并从其运营商那里接收命令。利用 Crutch 表明 Turla 组织拥有相当多的资源来运作庞大和多样化的武器库。

**物联网巨头 Advantech 遭到 Conti 勒索软件攻击**

工业物联网芯片制造商 Advantech 遭到 Conti 勒索软件攻击，数据库遭破坏，数据被窃取，黑客索要 750 BTC（超过1300万美元）的巨额赎金。Conti 是一种相对较新的勒索软件，首次出现于 2019 年 12 月，2020 年 6 月开始被广泛关注。有分析表明，Conti 是臭名昭著的 Ryuk 勒索软件的继承者。Conti 目前是 RaaS（勒索软件即服务），还建立了专门的数据泄露网站。因此它加入了勒索软件的行列，这些勒索软件不仅会加密受害者的数据，还会窃取数据，然后在受害者支付失败或拒绝支付赎金的情况下，将数据泄露到暗网上。  
来源：https://latesthackingnews.com/2020/11/29/advantech-suffered-conti-ransomware-attack-hackers-demand-750-btc-ransom/  
  

**工业自动化系统爆出高危漏洞 CVE-2020-25159**

安全公司 Claroty 的研究人员发现实时自动化（RTA）ENIP 堆栈中存在关键漏洞，远程攻击者可能会利用该漏洞来入侵工业控制系统。该漏洞为 CVE-2020-25159，它影响了 v2.28 之前的所有版本的 EtherNet/IP  适配器源代码堆栈。成功利用这一漏洞可能导致拒绝服务，缓冲区溢出可能允许远程代码执行。RTA 的 ENIP 堆栈已广泛应用于工业自动化系统，通过 Shodan 搜索引擎搜索与 ENIP 兼容的面向互联网的设备，发现了 8000 多个在线暴露的系统。操作人员必须更新到 ENIP 堆栈的最新版本以解决该漏洞。

  

来源：https://www.claroty.com/2020/11/17/blog-research-rta-enip-stack-vulnerability/

****流行威胁情报****

  

**Bandook 木马病毒新变种来袭**Check Point Research 发现，一个与哈萨克斯坦和黎巴嫩政府有关的网络间谍组织，利用变体 Bandook 的木马后门对全球多个行业发起了攻击。Bandook 在 2017 的 Dark Caracal 活动之后就沉寂了，最新一轮的攻击是由第三方提供的感染链。通过样本分析发现其攻击过程：通过 Microsoft Word 文档进行投递，诱饵文档多与贸易、政府文件有关，通过诱饵文档释放执行 Powershell 文件，Powershell 脚本从云服务中下载回文件，其中包含最终的后门加载器与正常文件，在执行加载器的同时执行迷惑受害者的正常文件。加载器会将执行功能的后门程序注入到 IE 浏览器中，与 C2 建立通信、传输信息，等待指令。在发现的 Bandook 野生变体中，使用了有效的 Certum 数字签名。除了后门功能外，这些变体版本还可以用作加载器，用于下载其他的恶意软件。

**供应链攻击活动通过恶意 npm 软件包分发 njRAT 木马**

Sonatype 在 npm 注册表中发现了新的恶意软件，该恶意软件与流行的远程访问木马（RAT）捆绑在一起。恶意软件包为：jdb.js、db-json.js，两个软件包均由同一作者发布。jdb.js  是一个与名为 njRAT aka Bladabindi 的远程访问木马 (RAT) 绑定的恶意软件包，模仿了合法的基于 NodeJS 的数据库库 jdb，包含三个文件：包含 njRAT 有效负载的 Windows 可执行文件 patch.exe；用于数据收集和侦查、启动 patch.exe 的 module.js；用于启动 module.js 的 package.json 清单文件。另一个恶意软件包 db-json.js 与正版 db-json 库的名称相同，看似无害，但是其暗中将恶意的 jdb.js 作为依赖项，也会使开发人员面临风险。近年来，njRAT/Bladabindi 的变种已经通过 YouTube 上的比特币骗局和 Excel 钓鱼邮件传播开来。

  

来源：https://blog.sonatype.com/bladabindi-njrat-rat-in-jdb.js-npm-malware

  
  
**Pay2Key 勒索软件加入威胁领域**

Check Point Research 报告称，新的勒索软件 Pay2Key 正在攻击以色列企业等目标。Pay2Key 是一个新的独特的勒索软件变种，与其他勒索软件家族没有明显的联系。该勒索软件是用 C++ 编写的，加密过程非常稳健，没有发现任何可以帮助研究人员开发加密密钥的漏洞。其他值得注意的特征包括现在臭名昭著的双重勒索策略，以及与其他勒索软件相比，解密文件的赎金相对较低，约价值 11-14 万美元的比特币。此外，攻击者会在加密发生之前的某个时间危害目标网络，以便当攻击者决定部署勒索软件时，可以在网络上快速传播恶意软件，在一小时内完成加密过程。

  

来源：https://securityboulevard.com/2020/11/pay2key-ransomware-joins-the-threat-landscape/

**越南 APT 组织“海莲花"利用挖矿技术隐藏间谍活动**据微软报告发现，越南政府支持的黑客开始在常规的网络间谍工具套件中部署加密货币挖矿软件。该越南黑客组为 Bismuth，又名 APT32、OceanLotus（海莲花），自 2012 年以来一直活跃，利用定制和开源工具集攻击大型跨国公司、政府、金融服务、教育机构、人权组织等，其主要目的是收集情报帮助越南政府处理外交、经济和政治决策。今年7-8月，该组织在对越南和法国的私营部门和政府机构发动攻击时部署了 Monero 挖矿程序，针对目标组织中的特定收件人用越南语量身定制的鱼叉式钓鱼邮件，在某些情况下，攻击者甚至与目标建立了通信，以增加打开嵌入其中的恶意文档的机会。攻击者大量使用 DLL 侧加载，将合法的 DLL 替换为恶意的DLL，并建立一个持久的 C2 通道，连接到被破坏的设备和网络。报告还指出，越来越多的政府支持黑客开始从事常规网络犯罪活动，俄罗斯、伊朗和朝鲜的黑客组织最近也被发现在从事网络间谍活动时从事获利性活动。

**漏洞情报**

  

**DarkIRC bot 利用 Oracle WebLogic 漏洞**Juniper 威胁实验室发现 Oracle WebLogic 软件上的 CVE-2020-14882 漏洞正被用于最近的攻击中。成功利用此漏洞可以执行未经身份验证的远程代码。据 Shodan 搜索引擎数据，目前互联网上可访问的 Oracle WebLogic 服务器有超过 3000 台。研究人员发现至少5种不同的攻击载荷。其中一个名为 DarkIRC 的 bot 可以执行一种独特的命令和控制域生成算法，该算法依赖于特定加密钱包的发送值。DarkIRC 具有浏览器窃取、键盘记录、比特币 Clipper、拒绝服务、蠕虫传播、下载文件、执行命令等功能。Oracle 在 10 月份修复了这个漏洞，并在 11 月发布了一个周期外的补丁来修复前补丁中的漏洞。

  

来源：https://blogs.juniper.net/en-us/threat-research/darkirc-bot-exploits-oracle-weblogic-vulnerability
