**金融威胁情报**

  

  
**QakBot 银行木马开始部署新的 Egregor 勒索软件**

新加坡全球威胁追踪和情报公司 Group-IB 近日发现，QakBot (又名 Qbot）银行木马犯罪团伙的策略发生了重大变化，从 ProLock 转为新的 Egregor 勒索软件。Egregor 的 TTP 与 ProLock 几乎相同，分析最近捕获的 Egregor 样本发现，Egregor 的可执行代码与 Sekhmet 非常相似。Egregor 自 2020 年 9 月以来一直在积极传播，迄今已经影响到 16 个国家的至少 69 家企业，主要针对制造业和零售业，比如游戏开发商 Crytek，书商 Barnes&Noble，以及智利的零售巨头 Cencosud。Group-IB 发现的最大的赎金要求是价值 400 万美元的比特币。

**近 5 万个 Fortinet VPN 漏洞可利用目标被公开，涉及政府和金融组织**某黑客发布了一份单行漏洞列表，可以从近 5 万个 Fortinet VPN 设备中窃取 VPN 凭据，易受攻击的目标包括全球各地的政府组织、商业银行以及金融公司的域名。涉及的漏洞为 CVE-2018-13379，这是一个路径遍历漏洞，会影响大量未打补丁的 Fortinet FortiOS SSL VPN 设备。通过利用这个漏洞，未经身份验证的远程攻击者可以通过特制的 HTTP 请求访问系统文件。攻击者可以从 Fortinet VPN 访问 sslvpn\_websession 文件来窃取登录凭据。这些被盗的凭据可用于破坏网络并部署勒索软件。该漏洞首次公开披露于2018年，由于企业的补丁进程非常缓慢，攻击者已经利用它很长时间。此前曾被曝用于入侵美国政府大选的支持系统。  
来源：https://www.bleepingcomputer.com/news/security/hacker-posts-exploits-for-over-49-000-vulnerable-fortinet-vpns/

**僵尸网络运营商从银行木马“移情”勒索软件**在 CyberCrimeCon 2020 上有安全专家表示，在勒索软件利润的驱动下，大多数僵尸网络运营商已放弃银行木马，转而运行加密锁定恶意软件攻击。勒索软件攻击持续上升，钓鱼邮件激增，勒索软件多样，医院和其他医疗机构遭受勒索软件攻击的事件明显增加。Group-IB 报告称，勒索软件团伙越来越多地采用附属方案，勒索软件运营商构建攻击代码和基础设施，然后招募附属机构将恶意代码植入系统。每有受害者付钱，附属机构和运营商就会分享利润。2019 年年中以来，这种附属项目的数量翻了一番。俄罗斯四大僵尸网络（Trickbot、 Dridex、 Qbot 和 Silent Night）都从银行恶意软件转向了加密锁定恶意软件。Group-IB 报告显示，2019 年下半年到 2020 年上半年，共发生了 500 多起有针对性的勒索软件攻击，其中一半可能是 Maze 团伙及其附属组织，或者 Sodinokibi 团伙。目前只有一小部分勒索软件攻击被公开曝光，这意味着勒索软件产生的实际利润可能高得多。Group-IB 称，僵尸网络运营商在过去一年中已经成功地使用 Ryuk（后来的 Conti ）、Kraken 和 Thanos 等勒索软件对 2500 多个不同的网络进行了加密。  
来源：https://www.bankinfosecurity.com/botnet-operators-drop-banking-trojans-for-ransomware-a-15455

**政府威胁情报**

  
  
**加拿大圣约翰市遭到大规模网络攻击， IT 基础设施瘫痪**

近日，加拿大圣约翰市遭到大规模网络攻击，严重破坏了整个 IT 市政基础设施。网络攻击导致整个市政网络关闭，包括城市网站、在线支付系统、电子邮件和客户服务应用程序。圣约翰市正在与联邦和省当局合作，从网络攻击中恢复过来。专家认为，此次袭击是由勒索软件团伙实施的，预计该市网络可能需要数周时间才能完全恢复运行。目前尚不清楚是哪个勒索软件家族发起的攻击。针对市政的勒索软件攻击变得相当频繁，美国已有多个城市遭受类似的攻击。

**英国敦促有关机构修复 MobileIron CVE-2020-15505 RCE 关键漏洞**

英国国家网络安全中心（NCSC）发布一则警报，敦促所有组织对 MobileIron 移动设备管理（MDM）系统中的 CVE-2020-15505 远程代码执行（RCE）关键漏洞进行补丁修复。该漏洞使攻击者无需身份验证即可在 MDM 服务器上远程执行命令。由于MDM 服务器需要公开访问来远程管理移动设备，这使它们成为威胁人员的有利目标。该漏洞于3月被披露，MobileIron 在 6月发布了补丁。NCSC 称，黑客团伙正在积极利用 MobileIron CVE-2020-1550 漏洞来破坏医疗保健、地方政府、物流和法律部门的网络。APT 组织和网络犯罪分子现在正在积极尝试利用此漏洞来危害英国组织的网络，所有使用易受攻击软件的组织应立即应用补丁。

**特斯拉 Model X 存在漏洞，黑客可在几分钟内盗走车辆**比利时研究人员发现，特斯拉 Model X 的无钥匙进入系统存在漏洞。这些安全漏洞可以通过特制固件远程更新 Tesla Model X 的 BLE 芯片，从而完全控制密钥和汽车。密钥一旦被破解，就可以在任何时候解锁汽车。研究人员称，由于配对协议的实现存在漏洞，可以使修改后的密钥与汽车进行配对，从而获得汽车的永久访问和驾驶权限。通过利用特斯拉 Model X 无钥匙进入系统的这两个弱点，黑客可以在几分钟内偷走车辆。特斯拉目前正在通过空中固件更新来解决影响 SUV 密钥的问题。

**新的 LidarPhone 攻击可以利用智能吸尘器进行窃听**

研究人员发明了一种 LidarPhone 攻击技术，这是一种针对智能吸尘器进行窃听的声学侧通道攻击，可以将智能吸尘器变成间谍工具。如今，大多数智能吸尘器都配备了提供智能导航和地图的激光雷达传感器，攻击者可以将它们转换成麦克风并获得周围的噪音读数。然后通过数据处理来消除噪声，最终获得所需的声音，这可以是人类的语音，也可以是附近计算机、扬声器或任何其他设备的声音。虽然由于一些限制使得 LidarPhone 不易被利用，但 LidarPhone 攻击具有重要意义，随着智能吸尘器的普及度越来越高，这种攻击会给数百万用户带来风险。研究人员认为，这类攻击同样适用于其他带有主动传感器的设备，包括智能手机。而且，这种攻击策略允许远程攻击者在不访问目标设备的情况下进行窃听。

**僵尸网络一直在默默扫描互联网上不安全的 ENV 文件**

过去两三年中，多个僵尸网络操纵者一直在大规模扫描那些暴露在 web 服务器上的 ENV 文件。ENV 文件，即环境文件，是开发工具常用的一种配置文件。Docker、Node.js、Symfony 和 Django 等框架用 ENV 文件来存储环境变量，如 API 令牌、密码和数据库登录。由于其所持有的数据的性质，ENV 文件应始终存储在受保护的文件夹中。根据安全公司 Greynoise 的数据，在过去的三年里，超过 2800 个不同的 IP 地址被用来扫描 ENV 文件；在过去的一个月里，超过 1100 个扫描器被激活。不安全 ENV 文件最终会被威胁人员下载，提取敏感凭据，然后破坏公司的后端基础设施。最终的攻击目标可能是窃取知识产权和商业秘密，勒索软件攻击，或安装隐藏的密码挖掘恶意软件。建议开发人员测试查看应用程序的 ENV 件是否可以在线访问，对于暴露的ENV文件，必须更改所有令牌和密码。

  

来源：https://www.zdnet.com/article/botnets-have-been-silently-mass-scanning-the-internet-for-unsecured-env-files/

**朝鲜 APT 组织 Thallium 利用伪装成 Chiras 的恶意文件攻击韩国企业**

近日，韩国流通大企业遭到勒索软件攻击，研究人员发现伪装成私人信息纸（俗称"Chiras"）的恶意韩文文件（HWP），该文件内容包括韩国政治、外交、社会等媒体报道和来源未知的谣言等。文件被伪装成公共机构用于发送公文的分发文档，无法修改/编辑。从攻击方式或特征来看，这些恶意文件似乎由朝鲜黑客组织 Thallium 制作。攻击者利用 Hancom Office OLE（对象连接插入）功能运行隐藏的 HTML 应用程序（HTA），然后与命令控制（C&C）服务器通信以执行其他命令。

**钱包黑洞：Lazarus 组织近期在加密货币方面的隐蔽攻击活动**

Lazarus 组织是一个长期活跃的 APT 组织，因为 2014 年攻击索尼影业而开始受到广泛关注，该组织早期主要针对韩国、日本、美国等国家的政府机构进行攻击活动，以窃取情报等信息为目的。自 2014 年后，该组织开始将全球金融机构，加密交易机构等为目标，进行敛财活动。近期，微步情报局通过威胁狩猎系统捕获到 Lazarus 组织在加密货币方面近期使用的样本，包含 Windows 和 MacOS 平台的版本，与之前的样本有显著变化。近期攻击活动使用的攻击样本对加密货币的用户有针对性，而且更加隐蔽，不易被发现。

**网络托管软件 cPanel 发现 2FA 绕道漏洞**

Digital Defense 的安全研究人员发现 cPanel & WebHost Manager (WHM) 网络托管平台的一个安全漏洞，影响 c\_Panel＆WHM v11.90.0.5（90.0 Build 5）。攻击者可以利用此漏洞绕过 cPanel 帐户的双因素身份验证（2FA）并管理关联的网站。该漏洞可能会产生巨大影响，因为网络托管提供商目前使用该软件管理全球超过 7000 万个域名。cPanel & WebHost Manager (WHM) 软件的 2FA 实现容易受到暴力破解攻击，攻击者可以猜测 URL 参数，绕过 2FA，利用这个漏洞需要攻击者拥有目标帐户的有效凭据。该漏洞已在 v11.92.0.2、v11.90.0.17 和 v11.86.0.32 中得到修复。
