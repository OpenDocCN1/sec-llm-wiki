**金融威胁情报**

  

  
**加密货币服务商 Akropolis 遭黑客攻击，损失 200 万美元**

近日，加密货币借贷服务公司 Akropolis 遭到“闪电贷”攻击，黑客窃取了价值约 200 万美元的 Dai 加密货币。Akropolis 管理员已暂停了平台上的所有交易，以防止损失扩大。闪电贷攻击是针对运行 DeFi（去中心化金融）平台的加密货币服务的常见攻击方式，这类平台允许用户使用加密货币借款或贷款，投机价格变化，并从加密货币储蓄的账户中赚取利息。闪存贷攻击是黑客从 DeFi 平台（如 Akropolis）贷款时，利用平台代码中的漏洞来逃避贷款机制并窃走资金。今年 2 月以来，此类攻击的数量一直在增加，其中最大的一次攻击发生在10月，黑客从DeFi 服务公司 Harvest Finance 窃取了价值 2400 万美元的加密货币。

  

来源：https://www.zdnet.com/article/hacker-steals-2-million-from-cryptocurrency-service-akropolis/

  

  

**美国银行系统遭到 Avaddon 勒索软件攻击，53GB 数据遭泄露**

Avaddon 勒索软件团伙攻击了美国银行系统公司。美国银行系统（ABS）是一家向美国金融机构和银行提供服务的公司。Avaddon 勒索团伙称已经获得了该公司超过 50GB 专有的数据，包括文件诸如贷款文件、商业合同、私人电子邮件、发票、网络共享凭据以及其他机密信息。目前尚不清楚有多少个人银行客户和金融机构因此受到影响。

![](../Images/68a0005646a2a9699cfcc2a5f12f98b3.png)

  
来源：https://securityreport.com/american-bank-systems-hit-by-ransomware-attack-full-53-gb-data-dump-leaked/

  

  

**金融业面临的持久网络威胁和新挑战研究报告**

几年前，针对金融服务行业公司的袭击还相对罕见。而近年来，随着网络入侵等能力和专业技术的提高，这类案件有所增加。据报道，智利和塞舌尔的银行，以及整个亚太地区核心银行系统供应商 Silverlake Axis 等金融技术公司都遭到了勒索软件攻击，黑客最近使用分布式拒绝服务（DDoS）攻击使与证券交易所相关联的网站脱机。BAE 系统公司与英国卡内基国际和平基金会安全局合作，发布了金融机构网络事件公共实例，并从持久威胁，不断发展的技术和新出现的挑战三个角度讨论了当前金融行业的安全形势。

**DarkSide 勒索软件计划在伊朗托管基础设施引发美国制裁**

DarkSide 勒索软件团伙本周宣布，为防止其数据泄露服务被关闭，他们正在伊朗和其他“未被承认的共和国”建立一个分布式、可持续的存储系统。使用此系统，如果一台服务器被关闭，数据仍将保留并在其他服务器上可用。由于向 DarkSide 支付的赎金可以用来支付伊朗基础设施提供商的新数据泄露系统，勒索软件谈判公司 Coveware 已将 DarkSide 勒索软件列入内部限制名单，不再为赎金支付提供便利。10月，美国财政部外国资产管制办公室（OFAC）曾发布公告，警告勒索软件谈判代表和美国企业，支付赎金可能导致违反制裁规定和罚款。除了制裁这些黑客组织，美国政府还对伊朗实施了制裁。

  

来源：https://www.bleepingcomputer.com/news/security/darkside-ransomwares-iranian-hosting-raises-us-sanction-concerns/

  

  

**美国被曝监视丹麦的政府部门和国防工业**

据丹麦广播电视台 15 日报道，丹麦防务情报局（FE）内部人员在2015年左右提交的一系列保密报告显示，美国国家安全局（NSA）利用与丹麦的情报合作，对丹麦的财政部、外交部等政府部门以及军工企业等机构实施监控，对途经丹麦通讯光缆上的隐私数据和信息进行搜集，还对丹麦的军机采购计划进行了非法的情报搜集。相关消息人士还称，除了针对丹麦进行了此类间谍活动之外，美国国安局还针对包括瑞典、德国、法国、挪威乃至荷兰在内的丹麦几个最亲密的邻国进行间谍活动。

**施耐德电气提醒用户提防 Drovorub 恶意软件 **施耐德电气本周发布一份安全公告，警示用户提防 Drovorub（一种 Linux 恶意软件）。美国机构在8月中旬发布了联合警告，称与俄罗斯总参谋部总情报局（GRU）有联系的、被称为 APT28 的网络间谍组织正在使用一种名为 Drovorub 的 Linux 恶意软件。Drovorub 包括植入器、内核模块 rootkit、文件传输和端口转发工具以及 C＆C 服务器。一旦将其部署到设备上，该恶意软件便允许其操作员下载和上传文件，以 root 特权执行命令以及进行端口转发。它还具有持久性和逃避检测的机制。Drovorub 会影响 Linux 内核版本 3.7 或更低版本的系统（由于缺乏足够的内核签名强制执行） ，而且它不能在启用了完全或彻底模式的 UEFI 安全引导的系统上实现持久性。施耐德电气已建议用户实施深度防御建议，以保护其 Trio Q Data Radio 和 Trio J Data Radio 设备免受恶意软件的攻击。

  

来源：https://www.securityweek.com/schneider-electric-warns-customers-drovorub-linux-malware?utm\_source=feedburner&utm\_medium=feed&utm\_campaign=Feed%3A+Securityweek+%28SecurityWeek+RSS+Feed%29

**制造业正在成为勒索软件攻击的主要目标**

随着网络犯罪组织越来越关注针对管理操作的工业控制系统（ICS），勒索软件已成为制造业的主要威胁。据安全公司 Dragos 分析，仅去年一年，针对制造业的公开记录的勒索软件攻击数量就增加了两倍。制造业的性质意味着工业和网络资产经常暴露在互联网上，从而为黑客团伙和勒索软件团伙提供了通过远程访问技术（如远程桌面协议（RDP）和 VPN 服务或未打补丁系统中的漏洞）访问网络的途径。截至 2020 年 10 月，仅在今年一年内，就发现至少 108 份报告包含 262 个影响工业设备的漏洞，其中许多漏洞可能会使网络容易遭受勒索软件和其他网络攻击。黑客通过获得对网络的足够控制权来部署勒索软件，通常还能够访问同样存在于网络中的知识产权和敏感数据。长远来看，这可能会造成更大损害。制造业需要采取一些措施，比如进行定期的架构审查以识别资产，确保设备和服务保持最新，以及进行“皇冠珠宝分析”以识别可能破坏业务连续性的潜在弱点。

  

来源：https://www.zdnet.com/article/manufacturing-is-becoming-a-major-target-for-ransomware-attacks/

**Malsmoke 团伙利用 Zloader 木马攻击成人网站访问者**  

研究人员发现，Malsmoke 团伙开始淘汰使用漏洞利用工具包传播方式，转而利用虚假的 Java 更新来诱骗成人网站的访问者。当浏览成人内容主题的诱饵页面时，会弹出恶意 Java 更新。更新程序是经过数字签名的 Microsoft 安装程序，其中包含许多库和可执行文件，其中大多数是合法的。受害者点击“更新”时，最终会下载 Zloader 恶意软件，进而将其注入到新的 msiexec.exe 进程中，以使用域生成算法（DGA）与命令和控制服务器联系。一旦确定，其将开始下载其他模块，并进行自身更新。

![](../Images/fd33d1aad568388d3a987d77ae265bf6.png)

  

来源：https://threatpost.com/attackers-porn-malsmoke-zloader-attack/161277/

  

  

**新的个人信息窃取者—— Jupyter 木马**

Morphisec 发现一个新的木马程序 Jupyter，攻击目标是企业和高等教育。该攻击主要针对 Chromium，Firefox 和 Chrome 浏览器数据，除了窃取用户信息，还具有在受感染系统上打开后门的其他功能，使攻击者可以执行 PowerShell 脚本和命令，以及下载和执行其他恶意软件的能力。Jupyter 安装程序会伪装成一个看似很重要的压缩文件，通常使用 Microsoft Word 图标和文件名。如果安装程序运行，它将安装合法工具，悄悄将恶意安装程序下载并运行到后台的临时文件夹中。一旦完全安装在系统上，Jupyter 就会窃取包括用户名，密码，自动完成功能，浏览历史记录和 cookie 在内的信息，并将其发送到命令和控制服务器。研究人员认为 Jupyter 来自俄罗斯，自5月以来一直很活跃。

**新的雇佣黑客组织 CostaRicto 主要攻击南亚地区的金融机构**黑莓公布了新的雇佣黑客组织 CostaRicto 的详细信息，该组织策划了遍及欧洲、美洲、亚洲、澳大利亚和非洲不同国家的攻击活动，受害者多集中于南亚地区，尤其是印度、孟加拉国和新加坡，主要针对金融机构。CostaRicto 是今年发现的第五个雇佣黑客组织，其他四个分别为 BellTrox（又称 Dark Basin）、DeathStalker（又称 Deceptikons） 、Bahamut 和 Unnamed group。CostaRicto 大多依靠窃取的凭证或鱼叉式网络钓鱼电子邮件作为最初的输入载体来发起攻击，这些邮件通常会传递一个后门木马，黑莓将其命名为 Sombra 或 SombRAT。后门木马允许 CostaRicto 操作员访问被感染的主机，搜索敏感文件，并窃取重要文件。该组织的攻击活动最早可追溯到 2017 年。研究人员还发现 CostaRicto 过去的攻击活动与俄罗斯军方黑客 APT28 有重叠，但可能是偶然事件。

  

来源：https://www.zdnet.com/article/blackberry-discovers-new-costaricto-hacker-for-hire-group/

  

  

**Lazarus 利用新型供应链攻击韩国政府和金融网站的用户**Lazarus 组织利用一种新型供应链攻击手段对韩国政府和金融公司网站的访问者进行攻击，以传递滴管恶意软件，最终在受害者的电脑上植入远程访问木马。韩国互联网用户在访问政府或金融服务网站时需要安装安全软件 WIZVERA VeraPort，Lazarus 利用这一点，从两家韩国安全公司非法获取代码签名证书，进而用来启动恶意软件的有效载荷。Lazarus 也被称为“隐藏眼镜蛇”（Hidden Cobra），因 2014 年索尼黑客事件而臭名昭著，也被认为与使用零日漏洞、 LinkedIn 钓鱼信息以及在包括 Dacls 和 Trickbot 在内的活动中部署木马的黑客有关。近年来，Lazarus 扩大了攻击面，不仅用于窃取企业的敏感数据，还用于危害加密货币组织。

**sshd 后门分析与团伙归类**

在很多 Linux 平台的应急响应过程中，会发现很多系统中存在 sshd 后门，虽然 sshd 后门已经存在 10 余年，但因没有公开资料讲解如何分析，多数安全人员不能发现 sshd 后门，更不清楚如何分析，从而导致系统中的 sshd 后门长期存在。sshd 后门常用功能是记录所有登录本主机的账号密码，以及增加万能密码，也有的会将账号密码传输到攻击者得到服务器中，攻击者可以利用后门或者获得后的密码直接进入系统，如入无人之境，长期的对目标系统进行侵害，属于 Linux APT 攻击技术。微步在线研究响应团队分享了两种分析 sshd 后门的方法以及 4 种 sshd 后门对应的黑客团伙，方便安全人员学习应用。

**Cisco Security Manager 高危漏洞已修复**

思科宣布已修复了两个可能允许未经身份验证的远程攻击者访问受影响系统上的敏感信息的漏洞：CVE-2020-27130，是一个关键的路径遍历漏洞，可以用来向受影响的设备发送精心设计的请求，并且可能导致攻击者从该设备下载任意文件；CVE-2020-27125，可能允许攻击者查看解决方案源代码中的静态凭据。这两个漏洞影响了Cisco Security Manager v4.21 和更早版本，已在 v4.2.2 版本中修复。同时，思科还将在即将推出的 Cisco Security Manager  v4.23 中修复多个 Java 反序列化漏洞（统称为 CVE-2020-27131）。这些漏洞可能允许未经身份验证的远程攻击者在受影响的实例上执行任意命令，并可能通过向受影响的系统上的特定侦听器发送恶意的序列化 Java 对象来触发。
