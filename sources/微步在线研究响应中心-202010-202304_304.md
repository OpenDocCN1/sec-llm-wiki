**Ghimob 银行木马攻击数百个 Android 应用程序**  
卡巴斯基实验室GReAT发现了一种新的银行木马 Ghimob，通过电子邮件伪装成与偿债相关的方式侵入 Android 移动设备。该木马很可能是由巴西一个名为 Guildma 的威胁组织部署的。研究人员称，Ghimob 是巴西首个移动银行木马病毒，正在感染拉美和欧洲国家的移动设备，很快可能也会攻击美国用户。这是一个在 Google Play Store 外部托管的欺诈应用，不仅针对银行客户，还针对加密货币交易所和金融科技公司。通过钓鱼邮件操作方法来散布恶意软件，诱使毫无戒心的用户点击恶意网址，下载 Ghimob APK 安装程序。Ghimob 安装后，帮助攻击者获得对设备的全面控制，远程截屏，记录用户在移动应用程序或在线领域键入的文本，并使用麦克风。GReAT 在分析报告中表示，Ghimob 是你口袋里的一个完全成熟的间谍: 一旦感染完成，黑客就可以远程访问被感染的设备，用受害者的智能手机完成欺诈交易，从而避免机器识别、金融机构实施的安全措施以及它们所有的反欺诈行为系统。

**美国司法部查获 10 亿美元比特币**

  

日前，美国司法部宣布没收价值 10 亿美元的比特币和其他加密货币。据称，这些资金与如今已经被取缔的暗网论坛丝绸之路（Silk Road）有关。其创始人罗斯 · 乌布利希在 2013 年 10 月被捕并判处无期徒刑。这可以说是美国司法部历史上最大规模的比特币没收行动。据报道，此次扣押事件的起因是观察人员注意到位于 “1hq3go3ggs8pfnxuhrytpcq5fgg8hbhx” 地址的一个数字钱包以一种神秘方式转移了 69369 枚比特币（约合 10.4 亿美元）。除了比特币，在交易中还发现了包括 Bitcoin S.V. 、比特币现金和比特币黄金等其他加密货币。在乌布利希的审判进行的时候，被盗的比特币总价值为 1340 万美元，如今竟已达到了 10 亿美元。

**英国对俄罗斯关于 COVID-19 疫苗的虚假信息发起网络行动**

  

据《泰晤士报》报道，英国 GCHQ 正在对俄罗斯企图破坏冠状病毒疫苗的努力进行黑客攻击。据称，这一网络攻势使用的工具与 2018 年打击伊斯兰国时使用的工具类似，目的是让其宣传机构下线。据称，针对俄罗斯黑客的策略包括对运营商的数据进行“加密”。几周前，《纽约时报》曝光了俄罗斯发起的一场旨在散播对 AstraZeneca 制药公司和英国牛津大学正在开发的一种 COVID-19 疫苗的安全性和有效性不信任的虚假信息宣传。而俄罗斯正在推广自己的疫苗 Sputnik V，该疫苗被研究人员斥为“有问题的数据”，并引发了对其快速跟踪和安全性的担忧。俄官方声明称这一虚假宣传活动是造谣，是为打击俄罗斯在抗击疫情上的努力，以及与英国在这一领域的合作。

**美国陆军公布漏洞赏金计划 “Hack the Army 3.0”**

  

美国陆军推出 “Hack the Army 3.0” 漏洞赏金计划，计划增加该计划的参与人数，并提供更多的攻击目标。“Hack the Army 3.0” 将于 12 月 14 日开始，一直持续到 1 月 28 日，或者直到所有资金都发放给获胜者为止。军方没有具体说明有多少资金可用。在 2019 年底，Hack the Army 2.0 获得了 27.5 万美元的奖励。这次，整个 Army.mil 域名都可能成为白帽黑客的攻击目标，但军方表示，只会奖励某些类别的漏洞的发现。其他可用的目标包括登录/认证服务和军队拥有的 VPN。

**EOL Windows 源代码泄露使 IoT 设备易受攻击**

  

前不久，Windows XP 和 Windows Server 2003 的源代码泄漏并发布在多个文件共享站点上，例如 Mega 和 4Chan。Microsoft 在 2014 年终止了对 Windows XP 的支持，在 2015 年终止了对 Windows Server 2003 的支持。像 Windows XP 和 Windows Server 2003 这样的 EOL 操作系统有数百个已知的漏洞，黑客可以通过这些漏洞渗透组织的 OT 网络。运行 EOL Windows 操作系统的 IoT 设备在医院中很常见。一个典型的中型医院平均有 75 种不同类型的医疗成像设备，其中继续依赖使用 Windows XP 和 Windows Server 2003 的设备非常多。不仅限于医疗保健行业中的 IoT 设备，此问题也影响到制造业等其他行业。

  

来源：https://unit42.paloaltonetworks.com/windows-xp-server-2003-source-code-leak/

  

  

**TCL Android 电视爆出高危漏洞**

  

最近，研究人员发现全球第三大电视制造商 TCL 的 Android 电视存在严重的安全漏洞。研究人员通过 nmap 扫描，发现了一系列开放的 TCP 端口，用浏览器访问从这些开放端口获得的 IP 地址会发生页面崩溃，有些浏览器会显示用户无权访问某个特定文件。测试地址 “http://10.0.0.117:7989/sdcard”，最终出现的是列出了整个文件系统。这是非常不安全的。研究人员称 TCL 对电视文件系统的几个文件夹做了关键性的修改，使这些文件可以被任意用户写入。研究人员认为这是非常不负责任的行为，TCL 应该公开整个漏洞修复过程。

**勒索软件 RansomEXX 推出 Linux 版本**

  

研究人员发现了一种新的文件加密木马，它被构建为一个ELF可执行文件，目的是在基于 Linux 的操作系统控制的机器上加密数据。经分析确认其为勒索软件系列 RansomEXX 的 Linux 版本。最近几个月，包括德州交通部（TxDOT）和柯尼卡美能达（Konica Minolta）在内的几家公司均成为其受害者，近日又攻击了巴西高级法院。RansomEXX 是人工操作的勒索软件，攻击者在获得目标网络访问权限后手动感染系统。启动木马程序后，它会生成一个 256 位密钥，用于加密受害者的所有文件，在 ECB 模式下可以使用 AES 块密码访问这些文件。AES 密钥由嵌入在恶意软件代码中的公共 RSA-4096 密钥加密，并追加到所有加密文件中。该勒索软件缺乏 C2 通信、反分析和终止进程等功能。与  Windows 版本不同，Linux 变体不会擦除可用空间。尽管 Windows 和 Linux 变体是由具有不同优化选项和不同平台的不同编译器构建的，但它们的相似性相当明显。

**台湾电子制造业巨头仁宝公司遭到勒索软件攻击**

  

全球第二大笔记本电脑代工制造商台湾仁宝公司在周末遭到勒索软件攻击。据 ZDNet 报道，仁宝员工与雅虎台湾记者分享的勒索信截图显示，此次事件的罪魁祸首是 DoppelPaymer 勒索软件团伙。据当地媒体报道，这起网络攻击可能影响了仁宝约 30% 的电脑。目前，该公司已关闭了网络以防止勒索软件的传播。仁宝公司高管解释说网络问题不是由勒索软件攻击引起的，仁宝的生产线没有受到网络攻击的影响。

**朝鲜 APT 组织 Kimsuky 利用 wsf 脚本的攻击活动**

  

微步情报局近期捕获到 Kimsuky 组织新一轮攻击活动，其所使用的 wsf 脚本组件为包含诱饵文件（“image\_confirm\_v2”）和后门组件的恶意载荷。wsf 脚本组件被执行后，同时释放出诱饵图片和后门组件，在后门组件中，将自身安装为 Windows Defender 更新程序以掩人耳目，然后向 C2 服务器发送明文主机信息，并下载加密的可执行数据，然后根据指令创建指定进程或内存加载执行其他恶意模块。微步在线旗下产品 TDP、TIP、威胁情报云 API、OneDNS 等均已支持对此次攻击事件和团伙的检测。

**xHunt 利用两个新 Powershell 后门攻击微软 Exchange 服务****器**

  

xHunt，又名 Hive0081，于 2018 年首次被发现。该组织的目标是科威特政府以及航运和运输组织。最近，Palo Alto 观察到 xHunt 入侵了科威特一个组织的微软 Exchange 服务器，发现了两个从未被检测到的 Powershell 后门：TriFive 和 Snugy，后者是之前发现的基于 Powershell 的后门 CASHY200 的变种。TriFive 和 Snugy 后门是 PowerShell 脚本，它们使用不同的命令和控制（C2）通道与参与者进行通信，从而提供对受感染的 Exchange 服务器的后门访问。TriFive 后门使用一个基于电子邮件的通道，该渠道使用 Exchange Web Services（EWS）在受感染电子邮件帐户的“已删除项目”文件夹内创建草稿。Snugy 后门使用 DNS 隧道通道在受感染的服务器上运行命令。

**黑客利用 CVE-2020-14882 漏洞攻击 WebLogic 服务器安装 Cobalt Strike 恶意软件**

  

Oracle 发现攻击者通过 CVE-2020-14882 利用 WebLogic 服务器安装 Cobalt Strike，这将允许持久远程访问受损设备。值得注意的是，CVE-2020-14882 漏洞是在几个星期前发布的补丁，随后 Oracle 修改了这个补丁。该漏洞的一个新变体（CVE-2020-14750）可用于利用 WebLogic 服务器，只需稍微修改一下利用代码。由于 CVE-2020-14882 和 CVE-2020-14750 都很容易被未经身份验证的攻击者利用，通过构造特殊的 HTTP GET 请求在受影响的 WebLogic 服务器上执行任意代码，获取系统权限，Oracle 建议立即应用更新补丁以防被攻击。
