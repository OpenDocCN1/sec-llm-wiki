# Kimsuky APT 组织利用 wsf 脚本的攻击活动分析

# **概述**

Kimsuky 组织是总部位于朝鲜的 APT 组织，又称 “Black Banshee”、“BabyShark” 等，至少从 2013 年开始活跃，该组织长期针对韩国政府、新闻等机构进行攻击活动，经常使用带有漏洞的 hwp 文件、恶意宏文件以及释放载荷的 PE 文件等恶意载荷，在今年上半年，该组织还曾使用新型冠状病毒作为题材进行攻击活动。

  

微步情报局近期通过威胁狩猎系统捕获到 Kimsuky 组织新一轮攻击活动中使用的 wsf 脚本组件和后门组件样本，经过分析有如下发现：

*   所使用的 wsf 脚本组件为包含诱饵文件和后门组件的恶意载荷，使用具有诱导性的文件名称 “image\_confirm\_v2”，而在以往 Kimsuky 的攻击活动中，还使用过 “COVID-19.hwp.wsf”、“bmail-security-check.wsf” 等等。
*   wsf 脚本组件被执行后，同时释放出诱饵图片和后门组件，在后门组件中，将自身安装为 Windows Defender 更新程序以掩人耳目。
*    之后在后门组件中向 C2 服务器发送明文主机信息，并下载加密的可执行数据，然后根据指令创建指定进程或内存加载执行其他恶意模块。
*    根据样本关联信息显示，本次攻击活动延续了之前该组织的攻击手法，直到  10 月份一直在进行中。
*   微步在线通过对相关样本、IP 和域名的溯源分析，共提取 6 条相关 IOC，可用于威胁情报检测。微步在线威胁感知平台（TDP）、本地威胁情报管理平台（TIP）、威胁情报云 API、安全 DNS（OneDNS）等均已支持对此次攻击事件和团伙的检测。

  

# **详情**

Kimsuky 组织经常使用钓鱼邮件针对韩国政府、新闻等部门发送带有恶意载荷的 Windows 脚本文件进行攻击，Windows 脚本文件 (\*.wsf) 是含有可扩展标记语言 (XML) 代码的文本文档，可包含与 Windows 脚本兼容的任何脚本引擎中的脚本，可在一定程度上降低用户警惕性，在本次攻击活动中使用的文件名称为“image\_confirm\_v2.wsf”（图像确认）。![](../Images/dd1642ec0446d41da7dde0ada3a785c8.png)  
在其以往的攻击活动中，其还使用过基于疫情、邮箱安全检查等为标题作为名称。![](../Images/35b6327b9916c6bf02249535c48d5090.png)  
wsf 脚本可以直接被双击运行，运行之后将会同时释放出后门组件和诱饵图片，诱饵图片如下图，图片来源为中国的一家公司“深圳市世纪欣阳科技有限公司”的厂房设备照片。![](../Images/d76a42ccc93dbff78b9930e32b94755a.png)  
样本执行流程如下图：![](../Images/56d847274c46b9840a14f8beed9cbf18.png)

# **样本分析**

## **1\. wsf 脚本分析**

脚本运行后会将 Base64 编码的数据释放到文件 %ALLUSERSPROFILE%/image.ft.b64 和 %ALLUSERSPROFILE%/image\_confirm\_v1.jpg.b64。![](../Images/59ceff6dad8db5e0f2464ee8f4d52f78.png)  
![](../Images/4658235b3d26aac32a9fa805c54cef1d.png)  
然后分别将两个文件 Base64 解码，恶意载荷文件 image.ft 依然留在目录  %ALLUSERSPROFILE%，而图片文件 image\_confirm\_v1.jpg 被移动到当前脚本运行目录，之后再打开图片文件模拟正常打开图片的假象，同时调用系统组件 powershell 和 regsvr32 执行 image.ft。![](../Images/939453ada08f4a84ccb29ba3f0d0d477.png)  
最后将脚本文件删除。![](../Images/7e3450423dec03707064984b4f395ade.png)  
并向服务器发送一个 GET 请求，表明当前操作已完成。URL：http://sejong-downloader.pe.hu/?uid=test\_ok![](../Images/296b026b5d8bb7a05826115b01e0cbb3.png)  

## **2\. 诱饵图片**

诱饵图片文件 image\_confirm\_v1.jpg 出处为“深圳市世纪欣阳科技有限公司”的厂房设备照片（https://sztianhao.en.china.cn/about.html），图片左上角均有中文“节约”字样，该公司是一家以经营无线网络设备为主的生产加工型企业。![](../Images/439875c8373b47f05db0247a2aea2402.png)

Backdoor 组件为 Dll 模块，含有 1 个导出函数 DllRegisterServer，在 DllMain 中没有有效代码，主要代码在导出函数 DllRegisterServer 中实现。![](../Images/3b35ceb5c99b7651968dd122875c8337.png)  
使用的字符串均以加密方式存储，执行后首先进入安装流程，将自身拷贝至 %ALLUSERSPROFILE%\\Software\\Microsoft\\Windows\\Defender\\AutoUpdate.dll。![](../Images/30686460fcb458a1eeb0b440be5cd818.png)  
设置注册表开机启动项以持久化，启动项名称：WindowsDefenderAutoUpdate。![](../Images/611908732e694c310543f42aca31ccae.png)  
![](../Images/27214c89010317f84019da91786925d4.png)  
利用 bat 文件自删除，并且重新启动自我复制后的 AutoUpdate.dll。![](../Images/1730205137fa2e3ed1d0ad10ae905fa0.png)  
![](../Images/26d71b8802938c2483b659f9a0834f86.png)  
再次执行后解密出互斥体名称 "DropperRegsvr32-20201013093656"，创建互斥体以保证只有一份木马实例运行，该名称含有明显的日期信息“2020/10/13 09:36:56”，且与编译时间戳相匹配，可以看到攻击活动直到 10 月份一直在持续进行。![](../Images/b103e2db20ba90e2bacc67eff05be2c1.png)  
然后创建两个线程，其中一个线程负责以 HTTP POST 方法向服务器发送主机信息，所有参数信息均放入 url 中发送，格式如下：/?m=a&p1={硬盘序列号}&p2={系统版本}-D\_Regsvr32-v1.1.24。  
![](../Images/261945c066ac18ca88a6eed80652ca98.png)

成功下载数据后，再次获取硬盘序列号，拼接为 "/?m=d&p1={硬盘序列号}"，并向服务器发送一次 HTTP POST 请求。![](../Images/1590d1d074b283705d07b377c5f5e7f4.png)  
![](../Images/50b1f2a034c81c675d03c568895ac2b1.png)  
读取下载到的临时文件数据，并使用以下算法解密，完成之后将临时文件删除。![](../Images/6ce943420d9df76eb3db11710458a2c2.png)  

根据指令可创建进程以及在内存中加载执行模块，以执行下阶段恶意行为，截至分析时，未能捕获到服务器所下发数据。

# **关联分析**

国外安全机构曾在6月份披露过该组织的一起攻击活动，当时攻击者伪装成 “Blue House”（韩国青瓦台）的安全电子邮件进行攻击（https://blog.alyac.co.kr/3071），将本次捕获样本与其中样本相比较，发现攻击手法基本一致，文件路径、文件名称、代码结构、开机启动项等多方面高度相似，例如字符串解密函数高度相似。![](../Images/cc0b941e1bdca6dd8bc7703d1691b135.png)  
Dll 名称同样包含 Dropper 字样，并且主要功能函数都在导出函数 DllRegisterServer 中实现。![](../Images/197a54718f5214f4a509804e95cc7616.png)  

# **结论**

Kimsuky APT 组织作为一个比较活跃的 APT 组织，其针对韩国的攻击活动也越来越多，这与具有相同背景的 Lazarus 组织有一定的相似之处，是一个值得关注的 APT 组织，根据本次攻击活动中样本的多维度信息对比显示，尽管与 Kimsuky 以往攻击活动中使用的组件存在微小差异，但由于 TTPs 相似度极高，故确信是 Kimsuky 组织进行的本次攻击活动。  

# **近期热点攻击事件**

1\. 朝鲜 APT 组织 Kimsuky 以“美国大选”相关主题的攻击活动  
2020 年 11 月 4 日，韩国安全机构 ESTsecurity 披露 Kimsuky 组织以“美国大选预测”为名义进行攻击活动，使用携带恶意 vbs 脚本的 hwp 文档进行攻击，这是该组织惯用的手法之一，文档样本信息如下：

| 文件名称 || 미국대선예측 - 미주중앙일보.hwp（美国大选预测-美洲中央日报） |
| --- | --- |
| 文件大小 || 36352 字节 (35.50 KB) |
| MD5 || 3fb0cfe3cc84fc9bb54c894e05ebbb92 |
| SHA1 || d1b609d02c6aa51f95c03a3d2886dbbf1c16bd12 |
| SHA256 || ca1b8c75357bf0f3c55de02c1c4ce8289e6cdd2338c9a4bec0cc8fdea379f1b5 |
| 文件格式 || .hwp |
| 最后修改时间 || 2020-11-01 02:23:35 |

  
文档以“Outlook and Tasks for U.S. North Korea Policy Post-Election”为题，且在后面附带韩文译文，原文是美国威尔逊中心研究员郑成章（世宗研究所首席研究员）预测的内容，原文链接：https://www.wilsoncenter.org/blog-post/outlook-and-tasks-us-north-korea-policy-post-election。![](../Images/019f8a7b57fa3e47114dc9d5397e146f.png)  
文档中的 VBS 脚本执行后会从失陷的服务器拉取下阶段的 VBS 脚本执行，以失陷的服务器作为跳板进行攻击活动是朝鲜 APT 组织 Kimsuky 和 Lazarus 惯用的手法之一，这两个组织在多种技术上有不同程度的重叠。![](../Images/1d6ce06e3cd3332f5e306fbedc4ca2ec.png)  
此次攻击活动手法延续了 Kimsuky 组织 2019 年曾被披露的名为“Smoke Screen”的攻击活动手法，url 的格式同样使用 xxx.php?op=1 的形式，后续行为也与“Smoke Screen”攻击活动有诸多重叠之处，可见 Kimsuky 组织一直保持着比较高的活跃程度，且对热点事件特别是政府相关事件保持很高的关注度。  
2\. 俄罗斯 APT 组织 Fancy Bear 对美国大选相关目标寻求攻击  
近期路透社报道，俄罗斯 APT 组织 Fancy Bear（又称 APT28、Sofacy 等）对美国印第安纳州和加利福尼亚州的民主党政党以及智囊团进行了尝试攻击，但攻击并没有成功，微软公司也指出了这些尝试的目标，包括外交关系委员会、卡内基国际和平基金会和美国进步中心。但俄罗斯大使馆否认了这些指控，称这是假新闻。另外微软指出 Fancy Bear 组织近期一直在寻找与美国总统大选有关的攻击目标，但是大部分攻击都没有成功，值得关注的是，该 APT 组织独特的历史行为预示着其后续破坏性攻击活动的风险。  
3\. 伊朗APT组织针对美国选举网站的攻击  
美国网络安全和基础设施安全局（CISA）和联邦调查局（FBI）近期披露伊朗 APT 组织针对美国选举网站的攻击，攻击者在 2020 年 10 月中旬向美国公民大规模传播选民恐吓电子邮件以及传播与选举有关的虚假信息，有意影响和干扰2020 年美国总统大选。攻击者使用 Acunetix 漏洞扫描器扫描了部分州选举网站，试图利用网站窃取选民登记数据，包括尝试使用已知漏洞、目录遍历、SQL注入、WebShell 以及网站的逻辑缺陷等，CISA 和 FBI 表示，已经确认攻击者在至少一个州成功获得了选民登记数据。  
4\. 小结  
社会工程学方案是很多 APT 组织攻击者的核心方案之一，而借助一些重大的、国际性的话题为诱饵进行攻击，可以让目标更加容易落入攻击者预先设置好的圈套内，当前，网络安全的攻防态势正发生快速演变，微步在线情报局会对关键性、重大性、国际性的事件持续关注跟踪，及时发现安全威胁并快速响应处置。
