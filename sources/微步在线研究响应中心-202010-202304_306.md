**金融威胁情报**

  

  

**Wroba 手机银行木马攻击活动由亚洲蔓延至美国**

  

卡巴斯基研究人员发现，Wroba 手机银行木马通过虚假的“包裹递送”短信通知攻击了美国多个州的 iOS 和 Android 设备。短信里有一个链接写着：“你的包裹已经发出去了，请检查接收。”用户点击链接会进入一个恶意站点，该站点会提示用户的浏览器已过期，需要更新。一旦用户点击"确定"，恶意应用就会下载。恶意应用安装到用户手机后，Wroba 可以发送短信、打开网页、从与金融交易相关的文件夹中获取文件、窃取联系人列表、拨打指定号码以及显示假网络钓鱼页面以窃取受害者的凭据。Wroba 已经存在多年，但此前主要针对亚洲用户。研究人员说，自今年年初以来，该恶意软件已经瞄准了世界各地的用户，主要集中在中国、日本和俄罗斯。虽然美国不在其攻击清单的首位，但网络犯罪分子正在向北美发展。Wroba 可以构建移动木马程序来访问设备上的所有内容，并且不会区分个人和企业数据。这对个人和企业用户都构成了重大威胁。  

来源：https://www.scmagazine.com/home/security-news/wroba-mobile-banking-trojan-targets-us-smartphones/

**黑客从 Harvest Finance 窃取2400万美元数字货币**

  

近日，黑客从 DeFi 服务公司 Harvest Finance 窃取了价值 2400 万美元的数字货币，包括价值 1300 万美元的 USD Coin (USDC) 和价值 1100 万美元的 Tether (USDT)。Harvest Finance 是一家门户网站，允许用户投资数字货币，然后利用价格变化获取少量利润。根据官方发布的消息，黑客在 Harvest Finance 上投入了大量的数字货币资产，然后利用加密漏洞将平台资金非法转移到其钱包中。攻击发生 2 分钟后，黑客还将 250 万美元返还给了该平台，但这一操作背后的原因仍不清楚。Harvest Finance 官方称，黑客在攻击中留下了大量可以识别个人身份的信息，并将其描述为“在加密界中是众所周知的”。Harvest Finance 承认攻击发生的原因是由于协议和工程实现上的漏洞，并称已经锁定了黑客，但出于隐私原因暂不公开。该公司悬赏 40 万美元，奖励 36 小时内任何找到归还被盗资金的人，36 小时后，赏金将降至 10 万美元。

**朝鲜 APT 组织 Kimsuky 以美国大选举预测分析为诱饵发起攻击活动**

  
据悉，韩国近日披露了朝鲜 APT 组织 Kimsuky 利用美国大选发起的一次攻击活动。利用社会对美国大选的关注，Kimsuky 使用社工和鱼叉式网络钓鱼的方法来获取信息。诱饵文档以美国总统选举预测为标题，内容包含英语和韩语翻译，诱导受害者点击执行，同时采用在 HWP 文档中嵌入 VBS 脚本方式，有效绕过杀软检测。

**日核监管局疑似遭到网络攻击**

  
日本核监管局（NRA）暂时暂停了其电子邮件系统，该中断很可能是由网络攻击引起的。NRA 在其网站上发布了一条通知，要求人们通过电话或传真与之联系，因其无法收发电子邮件。日本当局已对该事件进行了调查。据媒体报道，到目前为止，还没有证据表明日本核电站免受到网络攻击。美国政府警告说，有一个与朝鲜有关联的 APT 组织针对美国、韩国和日本收集有关核政策和制裁的情报。日媒报道称，一个未知的第三方设法获得了对日本核监管局网络的未经授权的访问。日本副外相冈田在新闻发布会上说，未经授权进入了 NRA 网络，并且尚未确认敏感和机密信息的泄漏。

**工控威胁情报**  

  

**T-RAT 2.0：通过智能手机进行恶意软件控****制**

  
研究人员 @3xp0rtblog 发现了一款使用智能手机和 Telegram APP 进行控制的恶意软件——T-RAT 2.0。攻击者可以通过 Telegram 基于文本的命令和 RAT 提供的命令按钮来控制 T-RAT。命令是英语的，但是大多数的帮助消息是俄语的，使用起来非常方便。T-RAT 有 98 个命令，主要功能包括：菜单导航、文件管理器、窃取器、剪贴器、监控和监听、 绕过、破坏系统及远程控制。

**新型勒索软件 RegretLocker 盯上 Windows 虚拟机**  
10月，一种名为 RegretLocker 的新型勒索软件被发现，它可以轻松更改系统安全性并加密所有文件。其在外观上是一种简单的勒索软件，没有冗长的勒索记录，并且使用电子邮件进行通信，但具有多种高级功能，允许它加密虚拟硬盘驱动器并关闭打开的文件进行加密。加密文件时，会将无害的 .mouse 扩展名附加到加密的文件名中，这通常在勒索软件感染中是看不到的。RegretLocker 使用 Windows Virtual Storage API 来挂载虚拟磁盘文件进而分别加密每个加密驱动器，利用 Windows Restart Manager API 终止在加密过程中保持文件打开状态的进程或 Windows 服务。当 PC 上检测到该病毒后，应立即删除该病毒，否则可能导致巨额资金损失。RegretLocker 目前还不太活跃，但这是一个需要密切关注的新家族。  
![](../Images/13433f3b9fbea3fe1d49ab8da76d1574.png)

**高级威胁情报**

  

  

**美人鱼 (Infy) APT 组织使用最新的 Foudre 后门进行攻击活动**  
美人鱼APT 组织（又称 infy, Prince of Persia, Foudre）主要针对政府机构进行攻击活动，最早的攻击活动可以追溯到2010年，该组织背后的来源为中东地区。其使用的后门由于其 C2 的请求中带有 infy 的路径故被名为 infy 后门。2017年使用了更新的后门 Foudre，2018年 Foudre 后门更新到第八版本。在本次的攻击活动中，其使用的是第21版本与第22版本。微步情报局及Gcow安全团队追影小组共同发现并分析了本次攻击活动，其使用了带有恶意宏的文档并且使用了新版本的 Foudre 后门。其更新了后门的一些操作，同时保留了相关的域生成算法，部分 C2 的请求参数具有一定的重合度，利用社工的方式诱导受害者运行到使用带有恶意宏提取嵌入的 ole 对象并且执行的方式释放并运行其打包 WinSFX 文档以执行相应的 Foudre 后门。经过样本分析，我们判断该组织大概率来自伊朗。

**漏洞情报**

  

  

**Google 披露 Windows 0day，该漏洞和 Chrome 0day 一起被黑客利用**

  
谷歌安全研究员近日发现了一个 Windows 0day (CVE-2020-17087) ，受影响系统包含 Win7 到 Win10 等版本。该漏洞与已知的 Chrome 0day (CVE-2020-15999) 一起被黑客利用进行针对性攻击。Chrome 0day 可导致攻击者在 Chrome 浏览器中执行恶意代码，而 Windows 0day 是攻击的第二步，可导致攻击者逃逸 Chrome 的安全容器并在底层操作系统上运行代码，即沙箱逃逸。Chrome 0day 已在 Chrome 版本 86.0.4240.111 中修复。Google 透露，微软计划在11月10日公布最新安全修补程式。但微软并没有确认这项释出安全修补的日期，微软表示将在最短时间内释出安全修补程式。微软发言人表示，针对这项 0day 漏洞的攻击本质上非常有限，且有针对性，还没有证据显示被广泛利用来进行攻击。  
来源：https://www.darkreading.com/threat-intelligence/windows-zero-day-used-with-chrome-flaw-in-targeted-attacks/d/d-id/1339350
