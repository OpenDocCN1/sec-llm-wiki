概述

Remcos 是 2016 年公开售卖的一款远控工具，至今已更新 66+ 个版本，几乎每个月都会更新 1-2 个版本。该工具由一家名为 Breaking Security 的公司出售，虽然该公司表示他们出售的软件只能用于合法用途，对于不遵守其用户许可协议的用户将撤销其许可证。但远程控制工具的贩卖给攻击者建立一个潜在的僵尸网络提供了所需的一切条件。

每个 Remcos 许可证的价格从 58-389 欧元不等。其开发商 Breaking Security 还支持用户使用数字货币进行支付。这种远控可以完全控制和监测任何 Windows XP 及其之后的包括服务器在内的 Windows 系统。

仍在出售的 Remcos：

大版本时间线：


从发布说明来看，它目前仍很活跃，特别是小版本，作者几乎每几天就更新一次。


关联事件

Remcos 传播方式一般都是钓鱼邮件，附带附件以及内嵌宏代码。

通过观察最新活动，是通过 COVID-19 钓鱼邮件进行传播，附件中包含一个使用误导性 PDF 图标的可执行文件，该可执行文件一旦执行便会启动商业化 Remcos 远控木马。该木马执行后将自身注入到系统默认浏览器中并添加到注册表。下载并执行命令，键盘记录，屏幕记录以及使用摄像头和麦克风进行录音录像等功能。

事件：冒充菲律宾海关利用 COVID-19 话题投递 Remcos RAT 木马。

2020 年 3 月 16 日，有研究人员观察到针对各种国际贸易公司的电子邮件活动。这些电子邮件冒充了菲律宾海关，并声称其中包含由于 COVID-19 疫情影响，关闭贸易等新法规的信息。这些电子邮件包含压缩的 Remcos RAT 可执行文件和 Microsoft OneDrive URL。

执行流程：

Remcos 启动时会先解密资源中的 "SETTINGS" 项，从而得到服务器IP、木马功能的各种配置、互斥体名称。解密后的 "SETTINGS" 项以 "@@" 为分隔符，被解析后存入一个数组，以数组的索引当作 Key，从而方便后续利用 key 找到相应的数据。

图示 Load 资源


图示 "SETTINGS" 资源段加密的数据


Remcos 会对 CC 配置信息和通信数据进行加密。

解密后发现配置信息中包含 C&C 地址（bogyz1-64752.portmap.io:6475）、通信密钥（此次分析样本为空）、互斥体（remcos_随机字符）、要窃取的电子邮件客户端凭证的目标服务商（yahoo，hotmail，outlook，gmail，mail）、键盘监听信息存放文件名称（logs.dat）等信息。

图示解密出的配置数据内容

通过 CMD 命令改变注册表项

“/k %windir%\System32\reg.exe ADD HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v EnableLUA /t REG_DWORD /d 0 /f” 以实现更改系统的安全特性。


把自身拷贝到C:\\Users\\username\\AppData\\Roaming\\remcos\\remcos.exe\


把自身副本文件添加进注册表自启动项实现持久化。


解密生成的 .bat 脚本文件，实现启动副本文件。


后续样本通过判定自身的路径以及前期生成的互斥体、注册表项，来执行不同的行为。
访问注册表项 HKEY_CLASSES_ROOT\\http\\shell\\open\\command 的键值获取到默认浏览器的路径，进而以挂起的方式打开。



打印日志信息，此次分析的样本是 1.7 Pro 的版本。
Remcos 木马的特点会在代码里内嵌木马的版本和制造商 Breaking-Security 的信息。


创建浏览器进程成功之后在目标进程申请空间，把自身 PE 文件写入目标进程空间中，获取线程上下文设置目标进程 EIP 后恢复该挂起的进程。


然后退出自身模块，剩余的恶意行为交给了浏览器中注入的恶意代码来执行。
创建新的线程 Hook 键盘消息，使用消息循环记录键盘操作，并在样本同一路径下生成 logs.dat 文件以记录获取到的按键数据。


窃取系统中存在的浏览器的 cookies 和记住登录的信息。



使用 WAVEFORMATEX 结构体相关 API 实现录音功能。


由于该 RAT 客户端在生成木马时候需要设置密码，即从资源 SETTINGS 项中解密配置信息的 PASSWORD 项，侦听端口和连接服务器时需要使用相同的密码才能连接成功，因此，该密码可用于身份验证和网络流量加密。

图示生成 agent 时的配置

未加 PASSWORD 的通信流量：明文传输

其特征是 [DataStart] 和 [DataEnd] 标记数据块，使用 |cmd| 来作分割符。


带有 PASSWORD 的通信流量：RC4 加密传输


接收并执行 C&C 下发远程控制指令。其中包括键盘信息监听、文件操作、系统进程操作等远程控制操作。同时通过清洗浏览器 Cookies 信息迫使受感染设备用户在浏览器登录电子邮箱时重新输入用户信息凭证，配合木马的键盘监听功能及时记录用户信息凭证。
