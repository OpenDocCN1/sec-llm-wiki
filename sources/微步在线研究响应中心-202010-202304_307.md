# **概述**

Remcos 是 2016 年公开售卖的一款远控工具，至今已更新 66+ 个版本，几乎每个月都会更新 1-2 个版本。该工具由一家名为 Breaking Security 的公司出售，虽然该公司表示他们出售的软件只能用于合法用途，对于不遵守其用户许可协议的用户将撤销其许可证。但远程控制工具的贩卖给攻击者建立一个潜在的僵尸网络提供了所需的一切条件。

每个 Remcos 许可证的价格从 58-389 欧元不等。其开发商 Breaking Security 还支持用户使用数字货币进行支付。这种远控可以完全控制和监测任何 Windows XP 及其之后的包括服务器在内的 Windows 系统。

# **关联事件**

Remcos 传播方式一般都是钓鱼邮件，附带附件以及内嵌宏代码。

通过观察最新活动，是通过 COVID-19 钓鱼邮件进行传播，附件中包含一个使用误导性 PDF 图标的可执行文件，该可执行文件一旦执行便会启动商业化 Remcos 远控木马。该木马执行后将自身注入到系统默认浏览器中并添加到注册表。下载并执行命令，键盘记录，屏幕记录以及使用摄像头和麦克风进行录音录像等功能。

事件：冒充菲律宾海关利用 COVID-19 话题投递 Remcos RAT 木马。

![](../Images/bd4643ccc47ba1dc631bea1ee6c73867.png)

2020 年 3 月 16 日，有研究人员观察到针对各种国际贸易公司的电子邮件活动。这些电子邮件冒充了菲律宾海关，并声称其中包含由于 COVID-19 疫情影响，关闭贸易等新法规的信息。这些电子邮件包含压缩的 Remcos RAT 可执行文件和 Microsoft OneDrive URL。

**执行流程**：

![](../Images/d09ba64073d90d14fcb96970484b87f0.png)

Remcos 启动时会先解密资源中的 "SETTINGS" 项，从而得到服务器IP、木马功能的各种配置、互斥体名称。解密后的 "SETTINGS" 项以 "@@" 为分隔符，被解析后存入一个数组，以数组的索引当作 Key，从而方便后续利用 key 找到相应的数据。

![](../Images/68f66b4b88bdfd0ee411988d3584b296.png)

图示 Load 资源

  

![](../Images/0b6abef990b2172f8c5db6055f4d134b.png)

图示 "SETTINGS" 资源段加密的数据

  

Remcos 会对 CC 配置信息和通信数据进行加密。

解密后发现配置信息中包含 C&C 地址（bogyz1-64752.portmap.io:6475）、通信密钥（此次分析样本为空）、互斥体（remcos\_随机字符）、要窃取的电子邮件客户端凭证的目标服务商（yahoo，hotmail，outlook，gmail，mail）、键盘监听信息存放文件名称（logs.dat）等信息。

![](../Images/69e36d1f4bd83f9850289b150772b12b.png)

图示解密出的配置数据内容

  

根据 Cisco 之前的研究，提供了一个简单的 python 解码器脚本，可供安全分析人员进行解码提取相关 IOC 数据：

https://github.com/Cisco-Talos/remcos-decoder/blob/master/remcos\_decryptor.py
