刚入手一台macbook m1 pro，32G内存真是不错。本来在一次渗透业务中，因甲方必须安装windows版本的vpn才能进入内网渗透，因为本人用的是mac，虚拟机又禁止安装那个软件，于是乎好久都不用mac了，算下来已经3年有余了。但是今年出的苹果笔记本"强者的强"实在太香了，于是入坑，所以各种安装虚拟机、各种软件等，这里介绍下Intellj idea 安装心得吧。


我们需要下载三个软件


一，安装 Intellij idea

官网地址：https://www.jetbrains.com/idea/download/#section=mac

直接下载mac版本即可，傻瓜式安装下一步即可，安装方法略过。


安装完成后，点击help，再点击 Register ，进入这里来激活，激活方法大家自行百度，这里登陆guan官方账号可以试用30天。


二，安装jdk1.8

官网地址：

https://www.oracle.com/java/technologies/downloads/#java8

我这里是直接找好java8下载的地址，如果哪天官网更新了，需要你自己去找下载地址。


下载之后双击安装，一律傻瓜式操作，然后打开mac的终端

进入家目录  

cd ~sudo vim .bash_profile

如图：

把以下内容，写入到.bash_profile

JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk1.8.0_311.jdk/Contents/HomePATH=$JAVA_HOME/bin:$PATH:.CLASSPATH=$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar:.
export JAVA_HOMEexport PATHexport CLASSPATH

如下图

wq 保存退出。输入以下代码加载生效

source .bash_profile

终端输入：java -version,正确显示java版本号算安装成功~

三，安装tomcat

官网地址：https://tomcat.apache.org/download-90.cgi


下载后，移动到根目录下的/Library下面,直接输入命令解压 

unzip apache-tomcat-9.0.55.zip



执行以下命令

cd /Library/sudo chmod -R 777 apache-tomcat-9.0.55cd /Library/apache-tomcat-9.0.55/binsudo ./startup.sh

安装完成后，在浏览器中访问”localhost:8080”,看到了Tomcat界面，则说明Tomcat已经成功启动了：

关闭tomcat，别忘记了

cd /Library/apache-tomcat-9.0.55/binsudo ./shutdown.sh

四，配置Intellij idea，创建javaweb工程

配置Project SDK 点下拉框

选择add JDK

如果这里有jdk1.8那么直接选择

如果没有，那么采取如下步骤，jdk的路径ru如下

/Library/Java/JavaVirtualMachines\jdk1.8.0_311.jdk

需要你手动选择这路径，但是如果没有设置过访问系统文件，这里是不显示的。



你需要显示你的mac磁盘到桌面，才有权限选择系统磁盘文件，

怎么操作？可以进入桌面，点击桌面空白部分，点击访达>偏好设置

勾选上硬盘这里

然后，选择 /Library/Java/JavaVirtualMachines/jdk1.8.0_311.jdk

下一步


下一步

完成


随便选


工程目录上点击右键，选择Add Framework Support

勾选web application

配置tomcat

新建

选择 Tomcat Server>Local

点击Configure 配置tomcat路径

点击 tomcat Home 

选择tomcat的路径，在/Library/apache-tomcat-9.0.55

取个名字

点击Fix

和工程名字保持一样


打开index.jsp
