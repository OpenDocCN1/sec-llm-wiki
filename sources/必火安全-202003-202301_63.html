     记得2018年的时候，给学生讲课用firefox55版本，还可以安装一些老版本插件，比如“hackbar.、hackbar、FoxyProxy Basic” ,让人一看就很动心，但是后来不知不觉中，我们用火狐的附加组件功能，再也搜不到那些老插件了



        迫不得已，只能用新版火狐或者延长支持版本去安装插件，但是这些版本都有着或多或少的bug，笔者发现，新版火狐安装hackbar，不能输入单引号“'”,或者某些情况下，不能提交请求...本来hackbar显示在页面下方就不舒服，你还有bug，实在是不爽至极...

        当然，你可以使用网上流行的什么tools版本、firefox49集成插件版本，绿色军团等，但是其一太卡了，打开一个浏览器，还要等上5秒钟，实在是无法忍受，其二，我还是喜欢自己的定制版本。

       今天，福音来了，某黑客大佬写的一款插件安装后可以安装任意插件

地址：https://github.com/JustOff/ca-archive/releases

        

0x01: 开始安装

环境工具：

1，firefox55版本

2，ca-archive-2.0.1.xpi

3，disable-add-on-signing.js

4，disable-add-on-signing-prefs.js

5，windows10操作系统内

关注公众号：“必火安全” 回复 firefox 查看所有文件下载地址


关闭更新，如果反应慢，先断网再关闭更新。

这里要55版本，56版本也可以成功，但是57肯定不行，所以最好别更新。


0x02：突破firefox签名

现在火狐强制签名了，直接安装外部插件不成功，突破firefox签名限制方法：

详情查看下面链接

https://blog.csdn.net/warcraftzhaochen/article/details/100110501

第一步：复制两个js文件到指定目录

假设你的火狐安装路径是D:\Program Files (x86)\Mozilla Firefox55\

那么将disable-add-on-signing-prefs.js拷贝到D:\Program Files (x86)\Mozilla Firefox55\defaults\pref\disable-add-on-signing-prefs.js    

另外一个文件就放到火狐安装目录即可

 D:\Program Files (x86)\Mozilla Firefox55\disable-add-on-signing.js 


0x03：安装插件


完成 0x02 步骤后，我们打开火狐浏览器。

1，把ca-archive-2.0.1.xpi 这个文件直接拖曳到浏览器窗体里，（随便拖到一个标签页里）就会弹出安装提示


2，我们点击添加：

3，点击确定并重启浏览器

4，点击Classic Add-ons Archive按钮，等待并刷新一下

5，输入hackbar 开始安装插件吧

-->安装插件稍微慢，请耐心等待。

期间可能需要再次点击 Install Now

-->点击添加


-->选择立即重启

-->页面出来了，帅帅的样子又回来了。
