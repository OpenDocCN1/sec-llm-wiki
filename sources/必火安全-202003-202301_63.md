# 情人归来，久违的Firefox插件定制化

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMjg0MTk5Mw==&mid=2247483724&idx=1&sn=e5d0786c50a8e3ca49d5ef4df6779b90&chksm=faac522acddbdb3cf15b897874ed2470add8b5289190f46df6462a8f2a5f0b59bddb19b5a253&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzMjg0MTk5Mw==&mid=2247483724&idx=1&sn=e5d0786c50a8e3ca49d5ef4df6779b90&chksm=faac522acddbdb3cf15b897874ed2470add8b5289190f46df6462a8f2a5f0b59bddb19b5a253&scene=27#wechat_redirect)

     记得2018年的时候，给学生讲课用firefox55版本，还可以安装一些老版本插件，比如“hackbar.、hackbar、FoxyProxy Basic” ,让人一看就很动心，但是后来不知不觉中，我们用火狐的附加组件功能，再也搜不到那些老插件了  

  

![](../Images/97f6e14218f0d458184e5f85da9da03d.png)

  

![](../Images/ec450f63270583a3f9ea9c417d58fd0a.png)

        迫不得已，只能用新版火狐或者延长支持版本去安装插件，但是这些版本都有着或多或少的bug，笔者发现，新版火狐安装hackbar，不能输入单引号“'”,或者某些情况下，不能提交请求...本来hackbar显示在页面下方就不舒服，你还有bug，实在是不爽至极...  

        当然，你可以使用网上流行的什么tools版本、firefox49集成插件版本，绿色军团等，但是其一太卡了，打开一个浏览器，还要等上5秒钟，实在是无法忍受，其二，我还是喜欢自己的定制版本。

       今天，福音来了，某黑客大佬写的一款插件安装后可以安装任意插件

地址：https://github.com/JustOff/ca-archive/releases  

        

**0x01: 开始安装**

环境工具：

1，firefox55版本

2，ca-archive-2.0.1.xpi

3，disable-add-on-signing.js

4，disable-add-on-signing-prefs.js

5，windows10操作系统内

关注公众号：“必火安全” 回复 firefox 查看所有文件下载地址

  

![](../Images/245f0606817c2d34b2355265a5e20b68.png)

关闭更新，如果反应慢，先断网再关闭更新。

这里要55版本，56版本也可以成功，但是57肯定不行，所以最好别更新。

![](../Images/b0a7dc44d543a6577faad3eb312d7651.png)

  

**0x02：突破firefox签名**

现在火狐强制签名了，直接安装外部插件不成功，突破firefox签名限制方法：

详情查看下面链接

https://blog.csdn.net/warcraftzhaochen/article/details/100110501

第一步：复制两个js文件到指定目录

假设你的火狐安装路径是D:\\Program Files (x86)\\Mozilla Firefox55\\

那么将disable-add-on-signing-prefs.js拷贝到D:\\Program Files (x86)\\Mozilla Firefox55\\defaults\\pref\\disable-add-on-signing-prefs.js    

![](../Images/81035ffb0e3c7342fdaeb41b4495a337.png)

另外一个文件就放到火狐安装目录即可

 D:\\Program Files (x86)\\Mozilla Firefox55\\disable-add-on-signing.js 

![](../Images/a10dd737c143ed8645f84dafcb61110a.png)

  

**0x03：安装插件**  

**![](../Images/4fc7476f1556230dba79604a90863b0b.png)**

  

完成 **0x02 步骤**后，我们打开火狐浏览器。

1，把ca-archive-2.0.1.xpi 这个文件直接拖曳到浏览器窗体里，（随便拖到一个标签页里）就会弹出安装提示

  

![](../Images/3c49ac27bc46fff09383f4f5e84a7c01.png)

2，我们点击添加：

![](../Images/fcb22840f3337f6c599db10f3cd120db.png)

3，点击确定并重启浏览器

![](../Images/868e28f2839602bf3e594431ae4a5ca1.png)

4，点击Classic Add-ons Archive按钮，等待并刷新一下  

![](../Images/1945880f0cf9e8d42c8980d45a600df7.png)

5，输入hackbar 开始安装插件吧

![](../Images/95a1161b4d3716deb45c9a1224dfeefb.png)

\-->安装插件稍微慢，请耐心等待。  

期间可能需要再次点击 Install Now

![](../Images/0e1577f363ad30c57d7c1867f396e1f9.png)

\-->点击添加

![](../Images/b630f959a02cf5f2e3e61c00a7087d65.png)

  

\-->选择立即重启

![](../Images/244bfb086199f8d21996ef68845d25a7.png)

\-->页面出来了，帅帅的样子又回来了。
