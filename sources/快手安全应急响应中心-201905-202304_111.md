# 30秒回顾快手安全「观火」沙龙！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU5MDg0MDc2MQ==&mid=2247484242&idx=1&sn=85553fa821806eba0e3a6f8a2228a098&chksm=fe395584c94edc921617e3110402657b28a87275afef8cb899fd9d08ae2c6b93b2f6b6b1092a&scene=126&sessionid=1681380137#rd](http://mp.weixin.qq.com/s?__biz=MzU5MDg0MDc2MQ==&mid=2247484242&idx=1&sn=85553fa821806eba0e3a6f8a2228a098&chksm=fe395584c94edc921617e3110402657b28a87275afef8cb899fd9d08ae2c6b93b2f6b6b1092a&scene=126&sessionid=1681380137#rd)

5月22日快手安全应急响应中心首届安全技术闭门沙龙会议在快手总部成功召开，快手安全和“火线Zone”社区7位同学进行了精彩的分享，吸引了60多位信息安全技术人员和管理者共同参与交流探讨。

![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)

快手安全蓝军负责人浩天带来的《KwaiSRC漏洞奖励计划及精品漏洞分析》主题演讲，介绍了**KwaiSRC第二个百万奖励计划**，并分享Node.js组合xss给PC带来的影响、人脸识别攻击样本分析、另类方式自定义发票金额带来的危害等多个漏洞案例。

![](../Images/a69c4080aee25e1abace5f5a681afd18.png)

![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)快手WAF负责人、高级安全工程师陈道光带来的《快手反入侵-红蓝对抗演进》，分享快手经历红蓝对抗阶初期段对于外网资产风险、IDC主机风险、办公网络风险的梳理和加固，以及第二次红蓝对抗常见的0day攻击、产业链攻击和APT手法的研究梳理。

![](../Images/a82d6482d6a0ebcf9ecbb0f009609023.png)

![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)

火线团队 3 位工程师带来的《火器工程师的自我修养》主题分享，表示火器目前已经建立了信息收集和分析平台.其中新版本包含了参数分析和URL数据分析和系统服务分析场景，并对数据进行可视化方便数据分析和处理.极大提高挖洞效率。

![](../Images/7d6a1f80ad219e7cd58d2468a93cdf38.png)

![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)

火线Zone优质创作者--「303 」带来的《企业级安全错误配置的攻防思考》分享，介绍了HOST碰撞方法，通过对IP和域名碰撞匹配，访问到绑定host才能访问的系统，列举了乌拉圭17岁高中生Ezequiel Pereira发现谷歌内部主机信息泄露漏洞的过程。

![](../Images/c450c8c3bbc3d81c11799f1032c947dc.png)

![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)

快手高级安全工程师林茂新带来的《对抗下的Java Webshell的生存之道》主题演讲，通过对Java Webshell的静态对抗、动态对抗、小Trick三个层面，介绍了对于对抗过程中如何寻找一个突破口，让webshell在目标系统中驻留的更久。  

![](../Images/0178b0e22c55c8fba7105eeca92ed99f.png)

![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)

火线平台TOP白帽子--「半夜不睡觉」带来的《使用逆向手段解决漏洞挖掘中的请求加密》分享，主要介绍了安卓、小程序和web的逆向手段，获取安卓代码脱壳、静态和动态分析方法，常见安卓逆向工具。

![](../Images/7a5e2940c1301afe44d82aa504814d9c.png)  
![](../Images/c18999c4defb3a4b94c6c9c05f350c11.png)快手高级安全工程师张艳生带来的《基于VMP的移动端可执行环境》主题演讲，介绍了快手在移动安全攻防建设过程中面临的风险及实践落地细节，重点分享了基于VMP的软可信环境，在跨平台、高强度、可定制等方向的技术架构及实现细节的披露，极大的保证了应用的运行环境的安全性、机密性。

![](../Images/c556421436411e1bb4bd00fcbe429faa.png)
