1、碎碎念

好久没来弄我的公众号了，9月自己的事情超级多，然后赶上国庆节回老家玩爽了，一上班又各种事情扑面而来，今天才得以喘息。


国庆在老家的时候，有一天梦到我接到了一个把字符串中所需的信息提取出来的需求，然后我就坐在电脑前面冥思苦想，接着就醒了。


神奇的是，我这两天向产品提了一个把短信文本中的URL提取出来做检测的需求，不禁想到国庆在家做的梦，感情自己还有点通灵的天赋。


就这这个需求，自己顺手也写一小段玩玩，请那个天天和我一起撸铁的基友不要嫌弃我写的差。


package main
import (  "fmt"  "regexp")
func main(){  s:="cc http://codingdict.com/questions/31481 aa http://a.net/h1 bb"  pattern:=regexp.MustCompile("(?i)\\b((?:https?://|www\\d{0,3}[.]|[a-z0-9.\\-]+[.][a-z]{2,4}/)(?:[^\\s()<>]+|\\(([^\\s()<>]+|(\\([^\\s()<>]+\\)))*\\))+(?:\\(([^\\s()<>]+|(\\([^\\s()<>]+\\)))*\\)|[^\\s`!()\\[\\]{};:'\".,<>?«»“”‘’]))")  result:= pattern.FindAllString(s,-1)  fmt.Println(result)}
