十多年前刚开始接触扫描器的时候，就觉得扫描器能够自动化的做目标存活检测特别有意思。

端午假期，我终于自己把这个需求实现了，一个简单的ping检查工具，可以使用不同的参数实现对域名、IP、网段、子网和文件的ping存活检查。

使用方法：

Mac系统要Sudo执行哟。

➜ $ sudo ./pingscan Please follow the below instructions:  -d string        输入一个域名  -f string        附上一个包含IP地址的文本文件  -i string        输入单个IP地址，如：192.168.1.1  -n string        输入一个IP子网，如：192.168.1.0/24  -r string        输入一段IP地址，如：192.168.1.1-192.168.1.2
