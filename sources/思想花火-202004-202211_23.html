近日，在学习使用golang的第三方库使用方法，学习到了一个很有意思的工具：brew，一个Mac或Linux的软件包管理器。

看见这个图标就好想喝一杯。

官网和完整使用方法：

https://brew.sh/index_zh-cn

https://zhuanlan.zhihu.com/p/59805070

安装命令：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"

想装点啥软件：

➜  $ brew install [name]

使用起来非常方便。


那新学了一个啥技能呢？各种格式文件转txt。。。。。

需要使用一个第三方库：import "code.sajari.com/docconv"

Git地址：https://github.com/sajari/docconv

GoDoc地址：https://godoc.org/code.sajari.com/docconv

不过，在使用他之前需要安装太多的依赖，按照ReadMe描述，还要装：

tidy, wv, popplerutils, unrtf,justext，这个时候，就可以用brew去安装。

然后，你就能将doc,pdf,html,rtf什么的转为txt了，把文本复制到自己想贴的地方，美滋滋。

package main
import (  "fmt"  "log"  "code.sajari.com/docconv")func main(){  res,err:=docconv.ConvertPath("a.pdf")  if err != nil {    log.Fatal(err)  }  fmt.Println(res)}
