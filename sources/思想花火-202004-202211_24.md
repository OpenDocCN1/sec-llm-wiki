# 第一次发现自己离疫情如此接近

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mjc0MDU1MQ==&mid=2452313710&idx=1&sn=97f97bebdcbb1455969185f6cf072b5b&chksm=b17e53c68609dad02118b8d2ce4e830da4b3ded1339f7951cf0a91830af3a8eb5a2529c99412&scene=126&sessionid=1681657718#rd](http://mp.weixin.qq.com/s?__biz=MjM5Mjc0MDU1MQ==&mid=2452313710&idx=1&sn=97f97bebdcbb1455969185f6cf072b5b&chksm=b17e53c68609dad02118b8d2ce4e830da4b3ded1339f7951cf0a91830af3a8eb5a2529c99412&scene=126&sessionid=1681657718#rd)

这两天，北京市的疫情响应又紧张了起来。我们组总共七个人，两个人被要求去做核酸检测了。大半夜的，又被通知开始AB班了。

其实，不管是03年的非典，还是今年春节武汉疫情肆虐时，我都没什么感觉，总认为离自己很远。可就在今天突然意识到，我可能就处在疫情身边而不自知，有点莫名的惶恐。自己感染了倒没什么，牵连了家人可就会内疚一辈子了。

![](../Images/0b159d62062b4983d5fc44572b357a48.png)

慌慌张张，晚上写了一个小程序，看看自己已经活了多久，还有多少日子。  

不曾想，自己已经度过了12,293天，生活不易，且行且珍惜。![](../Images/d917a56d31140185da0b85c4be4a9642.png)

![](../Images/9005c6fd9f9e44386755bcebe8082095.png)

再仔细一看，自己还剩31,537天，顿时又觉得，日子还长，天高地广，不应该把情绪沉浸在眼前的一些得失，比如股票赚了18%，升职失败什么的鸡毛蒜皮的事情里，还是要把注意力放在自己感兴趣的事情上，多多提升自己的能力最重要了。

![](../Images/9c40c8d64690460fad8c90b939770ebd.png)

**最后，****希望身边的人都没事，大吉大利，长命百岁！**

/*1、输入生日2、计算已经活了多久3、输入归期4、计算还剩多久*/package main
import (  "fmt"  "time")
func main(){  var nian int  var yue time.Month  var ri int  fmt.Print("请输入出生年份：")  fmt.Scanf("%d",&nian)  fmt.Print("请输入出生月份：")  fmt.Scanf("%v",&yue)  fmt.Print("请输入出生日子：")  fmt.Scanf("%d",&ri)  birthday:=time.Date(nian,yue,ri,0,0,0,0,time.Local)  rightnow:=time.Now()  var leapyear,unleapyear,daypast,dayleft int  for i:=birthday.Year();i<=rightnow.Year();i++{    if i%4==0{      leapyear++    }else {      unleapyear++    }  }  if rightnow.Year()%4==0 {    daypast=(leapyear*366+unleapyear*365)-birthday.YearDay()-(366-rightnow.YearDay())  } else {    daypast=(leapyear*366+unleapyear*365)-birthday.YearDay()-(365-rightnow.YearDay())  }
  fmt.Printf("您已经度过了 %d 天 \n",daypast)  fmt.Printf("您现在已经 %d 岁了 \n",daypast/365)
  fmt.Print("请输入去世年份：")  fmt.Scanf("%d",&nian)  fmt.Print("请输入去世月份：")  fmt.Scanf("%v",&yue)  fmt.Print("请输入去世日子：")  fmt.Scanf("%d",&ri)  death:=time.Date(nian,yue,ri,0,0,0,0,time.Local)  leapyear=0  unleapyear=0  for j:=rightnow.Year();j<=death.Year();j++{    if j%4==0{      leapyear++    }else {      unleapyear++    }  }  if death.Year()%4==0 {    dayleft=(leapyear*366+unleapyear*365)-rightnow.YearDay()-(366-death.YearDay())  } else {    dayleft=(leapyear*366+unleapyear*365)-rightnow.YearDay()-(365-death.YearDay())  }  fmt.Printf("你离去世还有 %d 天 , 约 %d 年 \n",dayleft,dayleft/365)  fmt.Printf("你的寿命是 %d 岁\n",death.Year()-birthday.Year())}
