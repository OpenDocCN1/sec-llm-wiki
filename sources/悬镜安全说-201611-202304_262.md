# 对不起，我们犯了一个重大的错误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwODc2NjgwMg==&mid=2649106324&idx=1&sn=6c22fc42f1364d833db9156b19618c8f&chksm=837b53a9b40cdabf5587dfb883198ea90e693db63f3bd33646c6858cb407b649e9aed1bc6e22&scene=126&sessionid=1681324141#rd](http://mp.weixin.qq.com/s?__biz=MzAwODc2NjgwMg==&mid=2649106324&idx=1&sn=6c22fc42f1364d833db9156b19618c8f&chksm=837b53a9b40cdabf5587dfb883198ea90e693db63f3bd33646c6858cb407b649e9aed1bc6e22&scene=126&sessionid=1681324141#rd)

ISC 中国互联网安全大会是亚太地区规格最高、规模最大、最具影响力的国际级安全盛会，2017年9月11-13日第五届ISC将在国家会议中心召开。悬镜作为云主机加固的领军品牌，会以参展商的身份参加本次大会。

![](../Images/498d0ac2e0e757301251720e52272ce0.png)

![](../Images/df500baaf4770a0180864f1015f1d804.png)

我们怀着激动而又兴奋的心情参加此次大会，细心地准备每一个环节，认真地制作每一项物料，没想到一个不可饶恕的错误还是发生了。

  

悬镜质量跟踪部的同事在对悬镜的产品服务质量及参展物料进行例行检查时，发现在ISC大会官方手册内的悬镜简介文案中，出现了多处错别字![](../Images/1de9f6667a94a725f3d0c5658e1e754c.png)![](../Images/1de9f6667a94a725f3d0c5658e1e754c.png)![](../Images/1de9f6667a94a725f3d0c5658e1e754c.png)。

  

而数以万计的ISC大会官方手册已经完成印刷制作，明天就将分发至每一个观众手中，错误已无法补救。

  

![](../Images/359111bd5e4d010ba29ab25ba1d1c634.png)

图1 ISC大会官方手册中的悬镜简介及错误

![](../Images/df500baaf4770a0180864f1015f1d804.png)

质量跟踪部发现问题后立即着手排查原因，很快发现，在8月底，悬镜运营部的妹子误将未经审核及确认的文案草稿提交给了ISC组委会，而文案终稿却静静地躺在那里![](../Images/9e26cc80cd6b165b7c22d30ccb269966.png)![](../Images/9e26cc80cd6b165b7c22d30ccb269966.png)![](../Images/9e26cc80cd6b165b7c22d30ccb269966.png)……

  

悬镜作为一个有责任有担当的团队，一直本着“**匠心品质，初心不改**”的理念，致力于为用户提供专业的产品及服务，对质量的把控一直是团队工作的核心，我们无法容忍自己犯下如此低级的错误，为用户造成了困扰和不便。

  

同时，此次错误的直接责任方——悬镜运营部，拥有非常丰富的大会参展和物料准备经验，但这次却因粗心大意造成了无法挽回的错误。因此，悬镜团队内部对相关责任人以及运营部门作出了通报批评和罚款处罚。

![](../Images/df500baaf4770a0180864f1015f1d804.png)

再此，悬镜团队要对广大用户郑重说一声：抱歉，这次我们让各位失望了。今后悬镜团队一定以此为戒，为用户提供更加专业的产品及服务，请看我们的表现![](../Images/d5995ad3168a2b1cc6682394cafe0085.png)![](../Images/d5995ad3168a2b1cc6682394cafe0085.png)![](../Images/d5995ad3168a2b1cc6682394cafe0085.png)。

  

为了表达我们的歉意，9月12日、13日两天，凡到ISC会场悬镜展台的小伙伴们，可以凭ISC大会手册中的错误页，领取小礼品一份，同时我们还会奉上精心制作的宣传册。

![](../Images/e2fbd4154df226edf0da499bb943a862.png)

  

最后祝大家能够在ISC大会上收获多多，同时欢迎大家来悬镜展台坐坐。
