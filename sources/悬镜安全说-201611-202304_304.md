# 为政企云安全保驾护航，安普诺正式加入CSA云安全联盟

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwODc2NjgwMg==&mid=2649105869&idx=1&sn=dd22edd3f9c66cad3646c5d1ccd020d2&chksm=837b51f0b40cd8e611e33aaa4f5a6f2ff1a96e6507591bf97d15feff4a6c6d93f8dc1d72069c&scene=126&sessionid=1681324161#rd](http://mp.weixin.qq.com/s?__biz=MzAwODc2NjgwMg==&mid=2649105869&idx=1&sn=dd22edd3f9c66cad3646c5d1ccd020d2&chksm=837b51f0b40cd8e611e33aaa4f5a6f2ff1a96e6507591bf97d15feff4a6c6d93f8dc1d72069c&scene=126&sessionid=1681324161#rd)

2017年4月28日北京安普诺信息技术有限公司（以下简称安普诺）正式加入国际“云安全联盟”（Cloud Security Alliance，CSA），成为其中国会员。

![](../Images/a97360b97f51e67581f0479db323b57d.png)

北京安普诺信息技术有限公司成为

CSA云安全联盟中国企业会员

**国际CSA云安全联盟为何选择安普诺?****？**  

CSA全球云安全联盟是中立的非盈利世界性行业组织，致力于国际云计算安全的全面发展。该组织发起于2018年，并在当年的全球信息安全产业大会（RSA大会，该会议是IT安全领域的权威科技大会）上宣布成立，其权威性和专业性受到国际公认。  

![](../Images/1b31206efed9932177eacc46e236d0c9.png)

CSA 云安全联盟Logo

  

云安全联盟CSA的使命：倡导使用最佳实践为云计算提供安全保障，并为云计算的正确使用提供教育，以帮助确保所有其它计算平台的安全。 

在行业内，加入CSA云安全联盟的门槛较高，目前，亚马逊、微软、阿里巴巴、腾讯、华为等国内外知名企业，是该组织的会员和合作伙伴。

![](../Images/f93fa4ca432b2178ca62747d8f9e0b45.png)图片来源CSA云安全联盟官方网站

![](../Images/022d4c44de7dc8ca7365ea8a3f97376d.png)

中国企业会员-截图来源CSA云安全联盟官网网站  

随着互联网云计算技术的迅猛发展，越来越多的企业将自身业务迁移到云端，随之而来的，是不容忽略的安全问题。

作为CSA中国企业会员，安普诺在创立之初便确立了**“云+端”一站式的防黑加固**技术路线，为金融、电商、高校及政企客户的各类应用服务提供从“云”到“端”的综合立体防入侵解决方案，并且在短短几年的时间内便迅速成长为了一个拥有专业安全品牌、广泛良好用户口碑及完备行业资质的新型安全服务提供商。

![](../Images/a341c178a70064d62fe7945e56372f06.png)

安普诺Logo  

  

2016至2017年间安普诺陆续通过了信息安全风险评估服务资质认证、ISO 9001质量管理体系认证、ISO20000信息技术服务群管理体系认证、ISO 27001信息安全管理体系认证等行业资质。

同时，悬镜安全实验室专业安全研究及服务人员均通过了CISP资质认证，核心安全团队均是国家信息中心“国信安全504红队”核心成员。

![](../Images/1bcce77274a1de892f661945a5d74f52.png)安普诺资质截图信息

  

  

**安普诺如何全方位的为用户的安全保驾护航？**

  

首先，安普诺建立了强大而又专业的安全团队—悬镜安全实验室，实验室核心成员来自北京大学信息安全实验室，具有多年的**漏洞挖掘、逆向分析、机器学习**等核心技能。  

目前，实验室主要职责是前沿安全技术研究和为企业客户提供专业的安全服务和安全咨询，主要包括基于深度学习的Web**威胁检测引擎研究**、**恶意样本分析**、**高级渗透测试服务**、**主机安全巡检服务**、**应急响应服务**、**服务器防黑加固**服务等方面的安全工作。

![](../Images/c82d94f396bdbb30b20eeec609604b27.png)

安普诺安全服务  

除此之外，悬镜安全实验室还负责全天候监控全球安全漏洞与威胁情报，自动化完成对重大安全漏洞、安全威胁情报收集，第一时间做出精准威胁预警，并提供实时有效威胁处置或缓解方案。

目前，安普诺旗下的悬镜安全实验室已面向金融、电商、政企客户以及应用开发商等行业推出“云+端”一站式综合防黑加固解决方案。

其中，企业安全服务主要包括高级渗透测试服务、安全巡检服务、应急响应服务、防黑加固服务等；安全产品主要包括悬镜服务器卫士、云脉Web威胁深度检测引擎、云诺Web威胁智能预警平台、云鉴漏洞扫描平台等。

![](../Images/f615a518f222fb2b28ba8a2ce3f3ae1d.png)

安普诺安全产品  

  

**新的起点推动业务安全保障 全面升级**

此次成为CSA中国企业会员，对于安普诺而言，既是一个挑战也是一次机遇。安普诺将积极、持续地参与CSA等标准组织的安全标准制定，利用自身在主机防黑加固和机器学习与安全交叉领域的技术优势，促进云主机及应用安全的全面提升。  

同时也会积极肩负云安全联盟正式成员的责任，携手联盟成员，共同推进云服务安全标准在国内的建立和推广，促进中国云计算的安全发展。
