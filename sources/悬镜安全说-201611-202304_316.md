# 国际资讯丨日本计划5-10年内开发一个防攻击卫星系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwODc2NjgwMg==&mid=2649105726&idx=2&sn=e48b016a6e2d5c83770c4e6004cc710a&chksm=837b5103b40cd8150df2020fc952f4addfc0455e75f428bc6c403a67c73fa54741576384536e&scene=126&sessionid=1681324166#rd](http://mp.weixin.qq.com/s?__biz=MzAwODc2NjgwMg==&mid=2649105726&idx=2&sn=e48b016a6e2d5c83770c4e6004cc710a&chksm=837b5103b40cd8150df2020fc952f4addfc0455e75f428bc6c403a67c73fa54741576384536e&scene=126&sessionid=1681324166#rd)

### 防攻击卫星系统将保护实现数据动态加密的卫星和地面站之间的传输。  

“根据拟议的计划，政府的目标是建立一个安全的通信网络，这是日本独有的国内安全通信网络，并刺激对私营航空航天业的投资。”Watertown Daily Times报道。

黑客验证卫星系统的雄心勃勃的项目由国家信息通信技术研究所所辖，隶属于政府，行业和学术机构。 

![](../Images/ce9e753391e736c3dcd51af536dbcd09.png)

  

目标是在五至十年内为商业目的提出该系统，通信部旨在通过开发一种在私营部门（即公司，组织）运行的安全通信系统来实现行业优势以低成本。

今年夏天，黑客防卫卫星系统的最终决定将会在2018财年的预算中纳入活动资金。

网络攻击是对卫星通信的严重威胁，卫星在我们的数字社会中起着至关重要的作用，几乎每个行业都受益于他们的服务，因此他们的安全是全球各国政府网络安全战略的支柱。

攻击者对卫星运营商构成日益严峻的挑战，更多的是商业卫星对军方的安全水平不足。 安全研究人员正在警告对卫星系统的成功攻击的可能影响，并敦促以设计方式进行安全建设。

卫星使用无线电波与地面基站进行通信，黑客可以拦截不可预测的后果。

可以解码加密数据的黑客可以窃取信息，操纵它或控制卫星。

![](../Images/19a480f66b5e04cd6fef440779325284.png)

  

各国政府考虑到民族国家行为主义者，犯罪组织甚至是一个孤独的黑客发动网络攻击的威胁。

主要关注的是中国黑客（可能是国家赞助的攻击者）进行的操作，过去已经违反了美国卫星的安全。

8月，中国政府推出了世界上第一颗量子卫星，将有助于建立空间与地面之间的“防范”通信。

据称国家资助的黑客在2007年和2008年干扰了美国两个卫星的运行情况，通过挪威的地面站进入卫星被用于气候监测。

黑客“实现了”Terra AM-1“卫星所需的所有步骤，但没有控制。 具有指挥权限的攻击者可以“拒绝或降级，伪造或以其他方式操纵卫星的传输”，或者简单地损坏或以其他方式破坏卫星。

![](../Images/9fb58f5e6d6a52c6feaf08109c46e61d.png)

  

日本政府的这个项目是在卫星上安装一个代码生成器，以便它们可以动态地加密数据。

“动态代码将使用光束发送到地面基站。 由于加密是动态的，黑客更难以解码数据，即使他们能够拦截传输。“Water Town Daily Times继续说道。

代码生成器是一个小立方体（每侧大约10厘米），可以轻松地安装在由每个侧面约30-40厘米的启动公司开发的微型卫星上。
