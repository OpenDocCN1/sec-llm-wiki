# 公安部宣布公安大学主要负责同志调整决定（附简历）

2019年10月11日，公安部在中国人民公安大学召开公安大学主要负责同志调整宣布会议。会议宣布，中央批准陈定武同志为副部长级干部，授予副总警监警衔，任中国人民公安大学党委书记。公安部党委研究决定，樊京玉同志不再担任中国人民公安大学党委书记，另有任用。

公安部党委委员、政治部主任刘钊同志出席会议并讲话，公安部政治部副主任、人事训练局局长冯延同志主持会议并宣读任职决定，陈定武、樊京玉、曹诗权三位同志作表态发言。校领导班子成员、副局级干部、校属单位党政主要负责人和正高职专业技术干部教师参加会议。

                       陈定武个人简历

陈定武，男，汉族，1961年7月生，福建福州人，中共党员，中国人民武装警察部队少将警衔。原公安部边防管理局局长、党委副书记。  

![](../Images/7980161a58d7eb252c167c38e55e0ce4.png)

  
历任福州郊区边防大队副大队长，福建省公安  
  
边防总队泉州市支队支队长，福建省公安边  
  
防总队司令部参谋长。  
  
。2006年至2010年担任中国第四支赴海地维和  
  
警察防暴队政治委员。  
  
2007年11月任广西壮族自治区公安边防总队  
  
总队长、党委书记。  
  
2011年8月任新疆维吾尔自治区公安边防总队  
  
总队长 、党委副书记。  
2012年7月晋升为武警少将警衔。

委书记。  
  
2015年12月任公安部边防管理局局长、党委
