# 日本情报人员为何非法来华进行测绘？

关注

  

   据日本共同社5月18日报道，在2017年以开发温泉为名在中国山东省和海南省等地进行地质调查而被捕的日本千叶县船桥市地质调查公司“日本地下探查”的负责人，因拍摄并测绘我方军事设施而在17日被烟台市法院判处5年零6个月有期徒刑。日媒称这或与山东的航母基地和海南的核潜艇基地等军事设施有关。据悉自2015年以来，已经至少有9名日本人因涉嫌在华实施间谍行为而被起诉，此次被宣判的则是第6人。日本的情报工作一直在其国家安全体系中占有重要地位，为此还建立起了各种分支繁多的情报系统。那么日本有哪些情报机关，情报工作又在日本的国家战略中发挥了怎样的作用？本期《出鞘》就来谈日本情报工作。  

![](../Images/92aa15dc9fd5f76212c52940dffb0f6f.png)

日本有重视情报的传统，早在16世纪便建立了相当活跃的情报网络，自明治维新之后，其情报网络更是加速扩建，并在军事扩张中扮演了重要角色。1878年日本陆军情报部首先问世，3年后宪兵部队也宣告成立，并在之后逐渐发展为集反间谍机构、特种警察部队和国内安全部为一体的情报组织。1884年日本又撤销海军省军务局，成立新的军事部，并其下设立专为日本海军提供情报服务的第5谍报课。二战时日本的情报网络发展到顶峰，其触角甚至延伸到南美，在阿根廷首都布宜诺斯艾利斯建立了庞大间谍网。

![](../Images/671ac61e231c0bec0d6e4a0b4eadda42.png)

在中国方面，日本最早对我进行谍报活动的组织之一便是日本近代第一个右翼团体——“玄洋社”。该社得名于“玄海怒涛，势可捣天”，玄海意指九州和朝鲜之间的一片狭长水域，虽然其面积不大，但却是日本侵略中国的必经之路。为了解当时中国清政府的总体情况，玄洋社仅在1882年便派出百人来华刺探情报，其后更是在上海成立所谓的同文书院（现日本爱知大学）。首任和第三任同文书院校长根津一不仅曾服役于日本陆军参谋本部，而且还曾领导过日本在华最早的两大间谍机构汉口乐善堂和上海日清贸易研究所，算得上是名副其实的老牌间谍。

![](../Images/4afc378d49eacd988ef621b164a02367.png)

根津一在该校最出名的“政绩”便是实施所谓“大旅行”的办学模式。“大旅行”即学生毕业前一年，用三个月到半年时间，以乘车或徒步的方式，按学院指定的路线深入中国内地进行调查旅行，并完成详尽的调查报告。这些报告有多详细？中国社科院美国研究所前所长资中筠的父亲资耀华，出生于湖南耒阳深山中的小山村“资家坳”，那里盛产一种高档无烟煤，但因交通不便而无法大规模运出。在当时所有的中国地图上都没有这个小山村的标注，但资耀华却在留学日本时，在日本图书馆藏有的同文书院调查报告中发现，其记载着湖南耒阳田心铺某处山上有无烟煤矿。

![](../Images/885d93bcafd214c05bf873c6eab6c407.png)

二战后的日本由于军力被限，以及走上了一条“经济立国”之路，便将情报工作的重点放在了搜集和分析经济与科技情报等方面。比如1978年在伊朗石油工人总罢工和霍梅尼上台之前，日本便提前获得情报，判断出伊朗石油供应可能出现问题。随后当年12月伊朗就宣布停止石油出口，由于情报获得及时，日本比较从容地渡过了后来的全球石油危机。当然日本经济情报能力的“强悍”也仅是相对而言的，比如1982年日本三菱电机公司和日立电器公司雇员就曾因企图窃取美国IBM公司的电子计算机技术情报而遭指控。值得一提的是，这也是美国历史上最大的工业间谍案件之一，当时共有21人涉案。

![](../Images/55c130166b25d34c82770878621ac952.png)

二战后很长一段时期，日本在情报工作上一直依附于美国情报机构，需要由美国向其提供对手（尤其是苏联和我国东北某邻国）各方面的情报和情报分析成品，这让日本情报部门经常感到非常被动。比如在1974年我国东北某邻国在向日本海试射导弹时，即使只有一海之隔日本也没有发现任何信息，还是在美国告知后才知晓。于是在冷战结束后，考虑到美日两国在经济等领域的摩擦越演越烈，热切希望跳脱“经济大国”这一单一角色的日本开始积极改组和发展情报体系，标志性事件是2003年发射日本首颗间谍卫星。

以上是日本情报发展的第一部分，小编将会在下期将余下介绍更新完成，敬请期待。
