# 特朗普要求美国企业撤离中国

美国政府官员证实特朗普或阻止美国公司在中国经营，他还没有下达命令，目前只要求美国公司撤出中国。  
![](../Images/5c38fe3455aababe0b9e29a91ed89ec2.png)  
两名白宫官员证实，特朗普总统有权强迫美国公司将业务迁出中国，不过澄清美国政府尚未下达正式命令。  
白宫经济委员会主任Larry Kudlow周日告诉美国有线电视新闻网（CNN）：“现在什么都没有发生。最终我们确实拥有这样的权力，但眼下不会行使该权力。”  
“特朗普总统对美国企业给出的建议是，你应该考虑将业务和供应链撤出中国；其次，我们希望你回到国内，这也是他在许多不同的场合以许多不同的方式对许多不同的公司给出的忠告。”  
美国财政部长Steven Mnuchin周日接受福克斯新闻网采访时发表了类似Kudlow的言论，声称总统有“很多选择”。  
之所以澄清美国总统的权力范围，是缘于特朗普周五发布了一系列推文。特朗普打算将此想法落实为行政令，而不是要求美国公司为旷日持久的贸易战做好准备，这加大了美国公司全面撤离中国的可能性。  
“因此命令我们那些优秀的美国公司立即开始寻找替代中国的方案，包括将贵公司迁回国内、在美国制造产品。”  
据白宫官员声称，强迫美国公司将业务和供应链撤出中国的能力属于1977年《紧急经济权力法案》的范畴。  
按照《紧急经济权力法案》，如果宣布国家处于紧急状态，应对“不同寻常的特殊威胁”，美国总统就有权监管美国公司的商业活动。这将促使总统拥有特别授权，以监管美国人从事的“任何外汇交易”。虽然特朗普在贸易摩擦期间已经下令对中国征收各种关税，但他尚未就中国贸易宣布国家处于紧急状态。

  

**8月26日，外交部发言人耿爽主持例行记者会。****有记者提问，美国总统特朗普近日要求美国企业离开中国，请问中方有何回应？**

  

对此，耿爽表示，大家可能都注意到了，没等中方作出回应，美国的股市和大宗商品的价格已经作出了回应，大幅下挫、下跌。另外我想大家也注意到了，美国各界人士纷纷对有关言论表示反对，国际社会也对这种极限施压的做法表示了担忧。

  

我上周说过，中美建交40年来，已经形成了“你中有我、我中有你”的利益格局和互惠互利的关系。强行让中美经济“脱钩”，势必威胁全球产业链、供应链安全，引发国际金融市场动荡，危及国际贸易和世界经济增长。这种做法与市场经济规律相违背，与自由竞争的规则相违背，与经济全球化的潮流相违背，必将遭到包括美国企业在内的所有利益攸关方的强烈质疑和反对。

  

中国经济发展到今天，内需已经成为增长的主要动力，发展运筹的空间十分宽广。与此同时，中国经济也已经深度融入了全球市场，与世界各国都建立了紧密的联系，辗转腾挪的空间也十分宽裕。今年1至5月，德国、韩国、日本、英国对华投资分别增长了100.8%、88.1%、18.9%和9.2%，欧盟对华整体投资增长了29.5%。所谓“美国企业撤出中国”更像是一句政治口号，而不是务实举措。即使现实中发生，自然也会有别人来填缺补位，到头来受损的还将是美国。

  

最后，耿爽强调，中美经济“脱钩”根本就不是缓解中美经贸摩擦的良方，更不是解决美国自身问题的出路。还是那句话，与中国经济“脱钩”就是与机遇“脱钩”，与世界“脱钩”，与未来“脱钩”。我们奉劝美方，要多多听取各界意见，算清利弊得失，务必要三思而行，切勿意气用事。
