# 守望

 清晨四点，万籁俱寂，黑夜正欲隐去，破晓的晨光慢慢唤醒沉睡的大地。手机铃声忽然从扫黑办响起，在空旷的大楼里是那么的清晰和突然。

![](../Images/b03d1b84ffc0e6b1e61258958efaead8.png)

 伏在案上短暂休息的韩文泽，一下子坐了起来，眼睛还没有睁开手就下意识的抓起手机，迅速起身，使劲挤了挤充满血丝的双眼，模糊地看到这是鸡西扫黑办的来电显示。他赶紧揉了揉眼睛，晃了晃混沌的头脑，提振下精神。他一手接听电话，一手拿起早已备好的圆珠笔详细地记录下督转的线索。放下电话，他轻靠在椅背上，微微抬起头，目光转向了晨曦初露的窗外，此时的他已然没有了睡意。工作填满了他的生活，他依旧努力的去把工作快速的向前推动，恨不得一下子就胜利收官。在他心中，不仅仅要有个完美的结局，也会是一个新的动人故事的开始。他沉思了一下，打开微信，左上角布满了红点。这段时间，他一边忙于线索摸排、信息录入、上传下达、资料汇总这些繁杂的扫黑办工作，一边又在侦办石某某的涉恶案件，忙得他恨不得分成两个人，还有十多个微信工作群，让他根本无暇理会个人的私信。而他确实很想打开一些私信，打开另一个充满温情的世界，却又怕这些私信让他流连忘返和心有旁骛。他不想一心二用或多用，他要在一个过程终结之后，爽爽快快的一无牵挂的去实现、去拥抱心中的梦想。他一处理完工作信息，便自然地锁上了手机屏幕。晃动晃动鼠标，电脑屏幕亮起，又开始专注地操作着表格，手指在键盘上飞快地敲击，响出悦耳的声音，就像他们有条不紊步步向前推进的节奏。不觉间，密集的脚步声在走廊里回荡，各办案单位民警涌入扫黑办，又一个紧张的工作日来到，大兵团集中全力去追歼那些隐匿的黑恶，不留一点死角。韩文泽有条不紊地分发着线索，一一讲解着查结的时限和报告的格式，然后又到白板前逐条涂改。在时光倥偬中不觉已是中午，一同侦办案件的战友，兴冲冲地来到他面前，告诉他已锁定石某某等三名嫌疑人的行踪。韩文泽不由长吁了一口气，连轴奋战了几个月有了结果，嫌疑人终于浮出水面。疲惫的他眉眼间顿时闪烁出灵动的光芒，赶紧交接完手头的工作，拎起时刻备齐的行李包，他要在影子还没有消失之前迅雷不及掩耳的出击，确保一击中的。鸡西、牡丹江、佳木斯……他马不停蹄，日夜兼程地奔波了2000多公里，又不知疲惫地连夜蹲守，终于将涉恶团伙的犯罪嫌疑人悉数捉拿归案。他一鼓作气，连夜突审了犯罪嫌疑人，案件终于有了突破性进展。检察院、办案区、看守所、扫黑办，他像个陀螺一样忙个不停。他是个忙人，对于亲朋却是一个失联很长时间的人。石某某恶势力犯罪集团的案件终于公开宣判，虎林扫黑除恶专项斗争第一回合完美收官。他终于可以安心地坐在椅子上，伸个懒腰，放松一瞬间。他突然想起了什么，掏出手机，又熟练地按上了那串号码，寻找让他怦然心动的足迹，内心充满幸福和喜悦的期待。他的脑海涌出那个身姿绰约，明亮动人的倩影。初次见面，她的一颦一笑扣动着他的心弦，他们总是有聊不完的话题，他时常抱着手机彻夜长谈，喜爱警察职业的她，甜美的声音，对未来的期待，每次都让他伴着温柔的爱意入眠。扫黑除恶，他冲上了第一线，他要以亲历的警察故事，让爱充满传奇。无暇与她说上一句话，更别谈见面。这几个月，他的通讯记录中有3000多通电话，只有几个是女孩的主动致电，可他都因公事缠身无情挂断。想主动打给女孩的时候都已是夜半三更，接通电话更是寥寥无几。此刻的他很想冲到女孩面前，与她一同分享这份沉甸甸的收获，分享一个警察的光荣和骄傲，还有……说不完的抱歉和思念。时光，会绷紧思念的弦，也会让一颗出生入死都不会犹豫的心，在幸福面前变得小心翼翼。他想象着电话的那一头，是期待？是怨恨？是漠然……？看了看等在那里的一串号码，他觉得连拨出的勇气都没有。他思来想去，编辑了一条微信，犹豫再三，鼓足勇气，伸出拇指，点击发送。可微信的回应，令他哭笑不得，上面赫然出现一个红色警示符号，显示着对方已开启了好友验证：你还不是他（她）好友。请先发送好友验证请求，对方验证通过后，才能聊天。他眼睛紧紧地盯着屏幕，不敢相信也不愿接受这样出乎意料的结果。他又发送了一遍，两遍，三遍，现实却一遍遍地屏蔽着自己那颗飞跃的心。沸腾的血在一点点冷静，他听到了自己的心跳。他再次仔细的看微信，看到最后一条留言：“对不起，我以为可以有很浪漫传奇的生活，可我渐渐发现，警察只可以让我仰视，却无法走进。我是一个普通的人，我要的是最普通的幸福……。”他呆愣住了。一个完美的结局，与一个不完美的结局交织在一起。这一瞬间，他感到沉重，也觉得轻松。窗外，天很晴朗，纯白的云朵漂浮着。阳光就在云彩里面。
