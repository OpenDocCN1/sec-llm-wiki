# 三国最优秀的情报分析师，却至死不得重用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650461831&idx=1&sn=cead08d499d03c829e023f0e52aa2717&chksm=8717f8ccb06071dabf4fe630632a06a92fd3a1b50eb6e225f658079a77077ea4289926bb5636&scene=126&sessionid=1681268385#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650461831&idx=1&sn=cead08d499d03c829e023f0e52aa2717&chksm=8717f8ccb06071dabf4fe630632a06a92fd3a1b50eb6e225f658079a77077ea4289926bb5636&scene=126&sessionid=1681268385#rd)

***本期导读：***

在三国时期，曹操身边也有一个情报高手，能有效分析情报，并且能将重要的情报准确的提取出来，就连人性都能算的到，为何他至死不得重用?

  

![](../Images/c720c5866dc81b50a62ac471051c7b35.png)

     刘晔(?-234年)，字子阳，淮南成德人，是光武帝刘秀之子阜陵王刘延的后代，三国时期魏国著名的战略家。刘晔年少知名，人称有佐世之才，是曹操手下举足轻重的谋士，他屡献妙计，对天下形势的发展往往一语中的。刘晔历仕数朝，是曹魏的三朝元老。

![](../Images/72d9b26fe9f116928c108bd129e32617.png)

     刘晔早年跟随刘勋，孙策见刘勋贪婪而无远见，便派使者卑辞奉献，劝刘勋兵发上缭，以便调虎离山。孙策使者说：“上缭很富足，因屡次欺侮我小国，我们想借你的大兵报仇，为你的外援，灭了上缭全归庐江。”刘勋听此言，又得孙策奉献的许多珠宝、葛布，大喜。全军庆贺，刘晔派人调查得知，上缭地方虽小，但城坚池深，易守难攻，另一方面孙策大军又有异动。于是对刘勋说：“若孙策乘其空虚，袭我后方，则主公大事去矣。”贪利的刘勋哪里肯听，兴兵伐上缭。孙策果然乘虚袭其后，刘勋穷迫，只好去投奔曹操。不久，刘晔也投归了曹操。

![](../Images/991920739345ef48f07ec8ec8b17bbfe.png)

      建安二十年(215年)，曹操征伐据守汉中的张鲁，任用刘晔为主簿。当时张鲁弟弟张卫领兵坚守，曹操攻阳平山上各个屯寨，但山势险峻难登，难以攻克;而且士兵死伤甚多，粮食又缺乏，曹操于是打算撤军，命令夏侯惇和许褚呼叫山上的军队撤退。此时有一些军队在夜里误闯张卫别营，营中士兵大惊四散，当时在军队后方的刘晔见此状分析认为张卫军心不稳，劝夏侯惇等不要退军。夏侯惇听后相信，于是回去告诉曹操，曹操于是进攻张卫，张卫不敌退走。张鲁不久投降，曹操得汉中。刘晔认为攻占汉中后令蜀人震惊，只要进攻他们就会望风归附，否则让诸葛亮、关羽、张飞等人稳定人心，据守险要，那日后就难以征服。随即劝说曹操攻蜀，但曹操不听。七日后，有从蜀地投降的人说蜀地人心惶惶，刘备斩杀惊惶者亦不能安定人心。曹操于是再问刘晔可否进攻，刘晔却说蜀中已人心安定，不能进击，曹操最终回师。

![](../Images/6a8ffebf8e171f9bc7b355ba27193a03.png)

     黄初元年(220年)，曹丕称帝期间，因为关羽战死，曹丕问群臣刘备是否会为关羽报仇，许多人认为刘备国力空虚不敢再战。刘晔派人调查发现，蜀国物价高涨，百姓生活水平下降，经过分析认为，蜀国荆州已失，国力衰微，又失勇将关羽，已无力供养数量庞大的军队。刘备已经没了退路，不战是死，战还有一线生机，必定会以为关羽报仇为借口开战。到了第二年，刘备果然出兵。

![](../Images/9964f9a953231dcfe8af6b0ca8eb3af0.png)

      事实上，刘晔是三国时期一位不可多得战略情报分析师，可是终生不得曹魏重用，曹操会听取刘晔的建议，但刘晔不同于荀攸、郭嘉，刘晔只是一个远程出谋的谋士而已。刘晔是皇室宗亲，本该被重用，可是掌权的曹操，对于刘氏人可没有好态度，纵使刘晔没有“兴复汉室”的想法，可他的身份注定和曹操不搭。更为尴尬的是，由于投向曹家，刘晔还让汉室皇帝起了戒心，对于这个族亲很是排斥。刘晔能力出众，可夹在曹家和汉室之间，终究难成大业。刘晔当时对于大局的把握，也毫不逊色郭嘉，而刘晔活的久，郭嘉早死，要是曹家肯用刘晔，或许三国的历史会是另一番天地吧！
