# 《情报学院#125期》情人沙龙第二期——情报十年，情报“纪”叙说

为了在公安情报系广大师生中营造一种“爱校敬业”的校园文化氛围，加深情报学生对“情报民警”职业精神和从业素养的理解和认同，6月24日下午，情报教研室在侦查楼201举办了一场别开生面的文化沙龙活动。情报系副主任孟军（挂职），教研室全体教师以及在校研究生和本科生参加了本次沙龙。

![](../Images/647ebff66875d817288b5ed70f5d8a1f.png)  

活动特别邀请威海市公安局指挥中心情报中心副主任、情报系优秀毕业生纪海松警官作为嘉宾和主讲人。纪海松警官向老师和同学们介绍了威海市局情报工作的现状以及近年来取得的巨大成绩。沙龙的互动环节，纪海松警官用鲜活事例讲述了自己毕业十年来在情报岗位上的成长经历和心路历程。 

本次沙龙适逢我院毕业季，通过引入优秀毕业生“真人诉说”和“零距离”面对面形式，提升了师生对“情报警察”的职业认同感。
