# 《情报学院#121期》里约奥运的安全系数有多高

 北京时间8月6日，里约奥运会开幕式才刚刚结束不久，就有一场令人遗憾的消息传来。据美联社报道，就在里约奥运会开幕式刚刚结束之后，主会场马拉卡纳体育场附近就传出命案，一个骑自行车的人遭枪击死亡，目前警方已经控制了现场。尽管警方来得很及时，但枪手还是逃跑了，而迄今为止，警方也没有对案件透露太多细节。![](../Images/a8d0277d4e90c2766b07e6f5087957da.png)

其实，这已经不是8月以来的第一次枪声了，当地时间8月4日凌晨，里约就爆发了一起激烈的枪战。据悉此次枪战并不是突发性的，而是里约警察局有组织有计划地同当地毒贩作战而进行的一场枪战。

![](../Images/d0825bce00a163a322ba41c9ebcf95f3.png)  

各国记者乘坐的两辆大巴车正好途径于此，不过幸好有惊无险。据记者透露，初步统计有6名当地人死亡，中方人员安全无恙。

  

除了枪战，此前曝光的里约近期犯罪高发也使许多人对里约奥运的期望变成了“安全第一，友谊第二，比赛第三”，甚至有网友称要放弃参加此次奥运会。下面笔者就来简单梳理一下里约最近的治安状况，为有去里约旅行的朋友们提供一些参考和建议。

  

**1、暴力犯罪、帮派火并再现“高峰”  
**据新华社报道，今年4月下旬，中国击剑队在里约入住的酒店位于该市著名的科帕卡巴纳海滩附近，队员和教练有次一起去酒店旁边的超市买水，由于数量较多，他们把水放到超市推车里，准备推回酒店。  
这时有三四名巴西小孩跑过来“帮忙”，一名小孩突然要抢走徐安琪的项链，好在徐安琪迅速用手抓住了项链，这时旁边的队友和教练围了过来，小孩们见状四散而逃。  
这不是第一次运动员在里约被抢。去年12月，英国运动员在奥运村附近被抢劫；5月，西班牙选手被持枪歹徒洗劫；6月，澳大利亚选手在海边被人抢走单车……  
奥运会步步临近，里约的治安状况却突然崩塌。

  

![](../Images/a3afbe298d9ce726ebdab4010ecf86fe.png)

图为安保人员进行训练

  

其实，从2008年开始，里约警方就专门成立了打击贫民区帮派的“清扫”项目，希望能让城市的治安环境得到改善。  
例如位于里约海滩附近的贫民区巴比伦尼亚，曾经，这里一度被认为是里约最安全的地区，但在最近几个月，这里的治安却突然急转直下。  
就连警方“清扫”项目的负责人也表示，“这里很危险，特别是晚上，帮派分子经常会朝我们的巡逻队员射击。”  
此外，在附近的草丛、灌木丛中，还多次发现被打死的尸体——这是不同贩毒帮派间“火并”后所留下的遗骸。  
连曾经“安定”的区域都是如此，其他城市区域的情况也就可想而知。事实上，自进入2016年以来，里约暴力犯罪的情况就一直不容乐观，甚至可以说每天都会有枪战发生。  
今年到目前为止，里约被打死的人数就已经达到了约2000人，也就是说，平均每一天，都会有9到10个人丧生。已经有超过50名警察在执法活动中丧生。  

![](../Images/dafb3f7491e3e9f096a6c94dfd8cf7f8.png)  

**2、工资只发一半，警察也是“受害者”**  
逐渐攀升的帮派暴力让市民和游客恐惧，而出生入死的警察同样也成为了“受害者”。  
7月初，超过100名警察和消防员来到里约机场，打出了写着“欢迎来到地狱”字样的横幅。他们在这里是为了抗议政府对他们欠薪，其中一名警察说，“我们是向外国来的游客展现巴西现状，他们（外国人）被欺骗了，我们也被欺骗了。”  
今年以来，已经有超过50名警察在执法活动中丧生，政府欠薪的举动更是让他们满心怨气——这也让里约改善治安状况的目标变得更加遥不可及。  
“我甚至都不能保证自己的安全。”刚退休不久的警察卡洛斯说，“我们不得不把自己的警徽和配枪都藏起来。”  
里约州的安全事务秘书长贝尔特拉梅也没有否认目前警方所面临的危机。  
“想想吧，如果你只收到一半的工资，怎么还能每天都遵照要求，去冒着生命危险工作？”  
在贝尔特拉梅看来，里约目前的安全管理状况，只能用“可怕和混乱”来形容。最近，他也在为了给警察争取资金而奔走中。  

![](../Images/3b9b0398fd9305f8e07d57734f6ca1ee.png)  

**3、安保部队威胁拒绝服务？**  
里约警方对于城市治安的掌控力已经处在了“崩溃”的边缘，这样的情况，无疑会给某些破坏分子留下“可乘之机”。  
贝尔特拉梅自己也表示，目前他最担心的问题还不是暴力犯罪，而是有可能出现的“恐怖活动”威胁。  
为了奥运会的安保，里约将额外出动由士兵和警察组成的8万名安保人员，分布在里约的街头和每一处奥运设施，以保卫观众、居民和运动员的安全。但盛会开幕前，又出现了意想不到的状况。  
据BBC报道，几支原本预定从外地进入里约的安保部队威胁拒绝服务，因为生活条件和欠薪的情况让他们难以接受。  
此外又有消息曝出，一些承担了核心安保任务的安保公司事实上并不具备足够的实际安保经验。  
不仅如此，粗糙的政府管理也让别有用心分子“入侵”巴西的难度大大降低。  
最近，巴西警方就截获了一个帮派，该帮派通过内部腐败官员，为外国人提供了超过70本货真价实的巴西护照。如果这样的情况大范围存在，无疑可能带来巨大的威胁。

  

看完了这些，想必您也对里约奥运会的安全系数有了一定的了解，最后送给大家一句话：“里约有风险，出门需谨慎”。
