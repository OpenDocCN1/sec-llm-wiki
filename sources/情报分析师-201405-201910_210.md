# 【情报学院\*沙龙】公安情报学系举行系列学术活动《情人沙龙》第二期

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650460938&idx=2&sn=e0a6f2bcdaaced550d17323ecd97f9ce&chksm=8717fd41b060745714eb459193cff439a5495074663f8bc02c7f2e38caeaca0daae96a8e4ffb&scene=126&sessionid=1681268418#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650460938&idx=2&sn=e0a6f2bcdaaced550d17323ecd97f9ce&chksm=8717fd41b060745714eb459193cff439a5495074663f8bc02c7f2e38caeaca0daae96a8e4ffb&scene=126&sessionid=1681268418#rd)

为更好地加强师生与公安实战部门的交流，增进毕业生与母校情谊，6月24日下午，公安情报学专业系列学术活动《情人沙龙》第二期——《情报十年，情报“纪”叙说》于侦查楼201举办。

本期主讲人为首届情报专业班优秀毕业生、威海市公安局指挥中心情报中心副主任纪海松。情报教研室全体教师、情报专业研究生，以及部分本科生参加此次沙龙。

![](../Images/23a38419648a1c43c081ed85aafe4688.png)

本次活动采取轻松的座谈方式进行。纪海松副主任具体介绍了威海市情报中心的工作情况，并结合自身10年来的工作经历为在座的师弟师妹提出宝贵建议。 

此次活动为在校学生提供了与工作在公安一线的专业情报警官面对面沟通交流的机会，使同学们受益匪浅。沙龙结束后，同学们纷纷表示学习的动力愈发强烈，要努力学好知识，为日后更好地从事公安工作打下坚实基础。
