# 《情报学院#113期》大数据反恐：中国势在必行！

去年11月25日召开的国家反恐怖工作领导小组专题会议上，公安部部长郭声琨提出，要运用大数据、云计算技术打击恐怖行为。“从海量的人流、物流、信息流、资金流中及时发现涉恐线索，做到预警在先、预防在前、敌动我知、先发制敌。”  
  
暴恐事件给社会造成的负面影响是深远的。面对恐怖事件我们要采取积极的应对措施，在互联网、大数据时代，恐怖分子在预谋、策划、实施犯罪时，或多或少会留下相应的信息。但是利用现有的技术和方法从中提取出反恐情报却比大海捞针还难。因为，这种恐怖主义信息在时序和空间上是不定和未知的，它们被淹没在海量的普通信息中。传统的数据库检索系统无法响应这类查询，人工识别、比照、监听技术，实施对已知目标的侦测都需要大量人力物力，而在浩如烟海的信息中寻找未知目标对象更是无能为力，但是运用大数据技术可以！  

  
**正确认识大数据的重大意义**  
大数据时代，就是指“数据已经渗透到当今每一个行业和业务职能领域，成为重要的生产因素”的时代。全球知名咨询公司麦肯锡最早提出这一观点。大数据时代，人们日常生活中的衣食住行，甚至所做的一切几乎都会留下数字痕迹，并集中表现为一组组形态、结构各异的数据。这些数据汇集在一起便形成了规模庞大、不断扩容的海量数据，即“大数据”。  
例如，春运期间，数千万旅客通过互联网、手机平台、电话等方式在铁路客户服务中心12306网站预订购买火车票，在极短的时间内，相关部门和企业的数据中心里就汇集了一批数量庞大的数据。这些数据的内容，涵盖了数以亿计旅客的个人背景、出行情况等多个方面，包括旅客姓名、身份证号、出发地、目的地、出发终到时刻、检票刷证信息等。掌握并分析这些数据，铁路部门可以针对热点线路、高峰时段科学地调配铁路运力，从而确保春运安全有序。反恐部门可以将这些信息通过大数据技术挖掘分析与比对，提炼成有用的行动性情报线索，应用于反恐工作的预知预警中。支付宝公司制作的“春运路线热点图”，从一个侧面展示了对上述海量信息进行汇聚后分析出的热点线路。  

  
线路热门程度：红色＞蓝色＞灰色

  
**大数据分析提高反恐能力**  
世界各国都高度重视发展大数据在科研、军事、金融、经济、通讯等行业的应用。2012年3月，美国奥巴马政府正式推出了“大数据的研究和发展计划”，据了解，美国政府NATGRID部门利用分析和研究来自情报和执法机构等21个不同来源的大量数据进行分析，包括通话、交通、电子邮件、聊天记录、视频等，以清晰勾勒出犯罪嫌疑人的行踪和面貌，对恐怖行为发生前，进行预警和事后分析排查。  
![](../Images/2fe6b76eec64ae71349cac01b0b0c9be.png)  
美国政府国家情报网格(NATGRID)利用大数据分析技术来研究和分析各种情报和执法机构的大量数据，以帮助跟踪嫌疑人，防止恐怖袭击。

  

2013年是我国IT业内一致认同的中国“大数据”元年，我国973计划也已经部署了相关的科研项目。目前，大数据已经逐步走入了我国社会生产、生活的各个领域。但与国外相比,我国在利用大数据技术反恐方面还有待完善和增强，应更多地利用大数据迅速发展的趋势和不断完善的技术，让其在反恐中发挥更大作用。可以让政府监控到公共领域细微的异常，及时启动预警机制。通过语种识别、声纹识别和关键词检测，可以分析人员地域、身份和交流内容，通过科技手段从海量的数据中分析过滤出涉恐分子的蛛丝马迹。  
![](../Images/ee1bb12634560fcdf5e20888ea4d1871.png)  
大数据带来的技术变革为我国反恐工作提供了创新性超越发展机遇。运用“大数据+反恐”战略思维，充分发挥大数据在反恐资源配置中的优化和集成作用，将大数据的创新研究成果与国家反恐需求深入融合，必将引领国家反恐综合能力的变革性创新！
