# 《情报学院\*第104期》教学比赛比什么？

日前，学院举办了一场规模盛大甚至史无前例的教学技能比赛，教务处全校总动员，全体教师磨刀霍霍。我有幸以评委身份参加了正高组的评审，全程观看了选手们两天十五场的比赛，印象深刻。参赛者既有功成名就宝刀未老的资深教授，也有风华正茂如日中天的年轻学者，大家都拿出了自己的看家本领，比赛现场烽烟四起精彩纷呈。教学内容，有的贴近现实、旁征博引，有的紧扣核心、步步为营；教学方法，有的循循善诱、润物无声，有的中规中矩、层次分明；教学风格，有的像浅唱低吟的诗人，有的如霸气外露的王者。很多评委感慨道，如果我们学校的课堂教学都能够达到这样的水平，那就太好了！作为警院人，我也深感自豪。根据我的了解，我院课堂教学整体水平，在全国公安院校中应该是执牛耳者，在贴近实战方面尤其如此，这是口碑，也是事实。对于教学型大学，这是极为重要的安身立命之本。

下面，我从教学技术的角度，以比赛规则为出发点，谈谈自己粗浅的想法——教学比赛比什么？

这次比赛规则大致为：时间50分钟，讲授内容自选，评比的内容包括课堂讲授、课件制作和教案制作，并且制作了详细的给分点。大家不要小看这个规则，实际上非常重要。

首先，比赛内容是自选还是随机抽取。赛前，有的教授讲，如果是教授组的比赛，就应该是把教材一放，随便翻到一个地方就讲，这才是教授的水平。话虽是一家之言，但的确有一定的道理。因为这种随机性，考察的是教师知识的系统性和应变能力。我和参加过公安部教学大赛的白晓峰教授聊过，公安部教学大赛的规则是，赛前两天随机抽取讲课主题内容和案例，参赛教师准备48小时，包括制作制作教案和课件，这个准备过程工作量极大。选手抽到的内容难易随有运气的成分，但对参赛者来讲，对课程整体把握能力、材料的组织能力和真正的教案课件制作水平是极大的考验。

其次，比赛时间是30分钟还是50分钟。据说，学院制定比赛规则，一开始是30分钟，后来改成了50分钟。这有区别吗？区别很大！比赛时间30分钟以内，属于短课时，时间够讲授一两个知识点，考察的是教师在教法教态方面的教学技能。网上有个节目——《超级教师》，比赛时间只有几分钟，节目短小精悍，但行家伸伸手就知有没有。这次比赛时间是50分钟，是完整的一堂课。对教学内容来说，50分钟可以讲3个以上的知识点，这考察的就不仅仅是教师的教学技能了，更考验的是耐心。通常来说，50分钟的课堂，对于讲授来说，会有至少两个容易导致学生困倦的时间节点。如何调节，是有一定难度的。但这和教学技能本身没有多大关系，更多属于教学经验层面上的。因此，如果是比教学技能，30分钟以内足以。50分钟的课堂比赛，更适合讨论课和训练课类型。

第三，讲授内容设计的难度。做过老师的都清楚，讲原理比讲分类或罗列难，讲大型案例比讲小案例难，用原理讲实时发生的大型案例更是难上加难，这一点，看看《新闻联播》和《新闻调查》你就能明白。教学比赛应该考察讲授内容的难度。这就好比跳水比赛，裁判会根据动作难度打分，你能说不科学吗？虽然我们很难把课程难度划分细致的等级，但真正的大师就是把具有相当难度的内容讲清楚，所谓深入浅出是也。

第四，参加比赛的是人还是课。这个问题和前几个问题都相关。打个比方，娱乐圈常把作品称之为“活”。内容不好演，但是名演员表演的节目，一般被视为“人保活”；内容好演，用好作品推出新人，自然被叫做“活保人”。课堂教学和这个类似，也存在人保课和课保人的现象。比如国际上有名的刑事情报分析课程，就是典型的课保人，由于课程是标准化开发，无论谁来讲授都差不多。而有些风格明显的教师，表达能力极强，无论讲什么都具有感染力，旁人很难模仿，比如易中天罗永浩袁腾飞等，这就是人保课。当然，教学技能实在不济，再好的课也教不好。反之亦然，现实中能够讲好数理化等看似枯燥课程的老师比比皆是。

依笔者浅见，教学技能大赛，强调的是教学技能，这包括教师在对所属领域内容的系统熟练掌握程度的基础之上，在相对时间内，搜集组织教学资料并有效组织教学的能力。既然是能力导向的教学技能大赛，教学技能无论如何是比赛的重点，这在教育测量学上叫测量效度。当然，信度也很重要，如何提高信度，恐怕要再写个小文了。

另外，虽然说是比赛，排序很重要，但不是唯一目的，作为赛事组织部门，要给获奖人员一定的评语，指出其优点特点所在，比如讲得好在什么地方，有哪些创新，还有什么地方可以改进等等。甚至设立一个创新奖，讲课未必中规中矩，但令人脑洞大开（笔者的偏爱），其价值也是非常大。讲评不但是给参赛者一个交待，更是给全体老师甚至是我们整体的教学指明了一个方向。正所谓“问渠那得清如许，为有源头活水来。”
