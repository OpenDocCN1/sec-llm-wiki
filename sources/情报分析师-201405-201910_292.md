# 【第71期】解密美国对华情报战.侦察篇（上）

1949年10月1日，中华人民共和国宣告成立。美国情报部门立即将目标对准了这个拥有数亿人口的“共产党敌对国家”，并通过人力和技术手段刺探“竹幕”后的秘密，以此作为美方隐蔽行动的依据和对华政策的指南。值得一提的是，溃逃到台湾的国民党政权虽为美国忠实盟友，但美国却将这个“小伙伴”也列入情报搜集的重要目标，尤其关注台海冲突的可能性及台湾大规模独创性武器的研发情况。

但长期以来，美国对华情报活动的细节极少对外披露，更鲜有官方正式评价。2011年6月，美国中央情报局、国防部和国务院等政府机构陆续公开了一批对华情报战档案（主要是冷战时期）。美国学者马修.爱德、杰佛瑞.里彻逊等对这些解密档案做了梳理、汇编，使外界得以重新解读那段曾被严密尘封的历史。本文特选登其中精华部分，其曲折跌宕堪为现实版《谍影重重》。

侦察篇

经过多年较量，美国承认自己刺探中国大陆情报的努力“屡遭失败”，并认为原因有三：第一，中国审查制度严格。事实证明，中央情报局（以下简称“中情局”）不仅很难在中国政府和军方高层招募到高级间谍，就连低端间谍网络也难以长期运作。第二，中共保密制度完善。由于无法破译中国的高级密码，通过飞机和卫星获取图像情报便成为美国对华侦察的主要方式。第三，美方资源投入不足。冷战时期，美国将侦察重点放在苏联和东欧地区，中国则居次要地位。相比而言，美国对台情报工作却“战果斐然”，甚至成功地影响了台湾核政策。

人力情报

在冷战期间，中情局针对中国大陆进行的人力情报活动，大都惨遭失败。早在二战结束之初，中情局前身——战略行动处和中央情报组的在华活动，就被斥为“成事不足，败事有余”。1946年4月，美国军方发现战略行动处的特工竟敢监视驻华美军高官，两家从此结下“梁子”。而美国国务院与中情局的长期恶斗也在中国内战时期拉开了序幕，双方关系一度势同水火。1949年1月31日，北平和平解放，美国认为蒋介石大势已去。此后不久，国务院要求中情局撤出中国大陆，因为“他们牵扯了国务院人员过多的精力”。中情局别无选择，只能遵从至1949年3月底，中情局已经关闭了上海站和广州站，只在香港保留了一个小规模的情报据点。到1949年9月新中国成立前夕，中情局留在中国的间谍网要么已自行瓦解，要么就是被中共安全部门摧毁。“随着在华情报搜集能力锐减，有关中国的相关情报在数量和质量上皆迅速下降。”

朝鲜战争的爆发，重新激活了美国对华人力情报活动。1950年6月至10月间，从英国和台湾的同行那里，中情局搞到了中国在东北集结军队的情报。另外，据在香港的一名美国间谍、中国航空运输公司前总经理陈投林（音译）报告：“40万中国军队已陈兵中朝边界，准备于10月18日或20日出兵（编者注：志愿军实际入朝时间为10月19日）。1950年秋，荷兰驻华使馆也向美方提供了类似情报，但这些重要信息都被华盛顿方面忽略了。

中国军队入朝后，中情局仍“无所事事”，连他们自己都私下认为“对朝鲜战争和中国事务的影响力几乎为零”。究其原因，主要是中情局与军方对情报主导权的恶性争夺，加之计划不力、经验不足，导致“（向大陆）空投的台湾间谍几乎无人生还”。由于成果寥寥，1952年，李奇微将军给中情局长写信抱怨：“有关中国军队的情报非常粗略、含糊，涉及中国东北、西伯利亚东南部等关键地区的情报，则大都是从台湾或香港搜罗来的二三流货色。我们手头的情报不是谣传，就是主观臆断。”为了找回颜面，中情局于1952年夏天在东京设立了一个北亚指挥所，全权负责针对中国、朝鲜的情报搜集和隐蔽行动，但成果依然乏善可陈。

朝鲜战争结束后，中情局和军方放弃了在中国大陆建立间谍网的努力，而把这项“业务”让给了更好斗的台湾情报部门。蒋介石政权曾向美方吹嘘，他们的间谍对大陆进行渗透必将“取得卓越战果”。但解密档案表明，尽管台湾方面费尽心机，其人力情报活动仍主要局限于大陆沿海地区，成绩“糟糕透顶”。从1953年开始，在中情局资助下，台湾每月向中国大陆空投2名间谍。然而到1955年秋，中情局认定这个行动已经失败，因为所有间谍着陆后不久即遭逮捕或被歼灭。失败原因主要是中情局的负责官员缺少经验，且对自己的对手一无所知，“共产党的严密控制使这些行动毫无成功可能”。于是，中情局派员飞赴台北告知蒋介石：空投行动必须停止！但台湾方面仍坚持将这一计划进行下去，并从金门和马祖派遣了大批间谍在大陆沿海秘密登陆，但这些行动同样沦为“彻头彻尾的悲剧”。

需要指出的是，冷战期间，中国大陆的叛逃者非常少，且多为低阶外交官，情报价值不高。当时除依靠台湾外，连审问香港偷渡客都被美方算作获取情报的“重要方法”。整个20世纪60年代，美国对华人力情报活动“萧条”依旧。中情局香港站负责人席尔瓦在回忆录中哀叹，“我们鲜有战果。尝试越多，失败越多。”他无奈地把中国称为“难以渗透的一块‘硬骨头’”。

直到20世纪70年代初，中情局才有机会重返大陆。中美关系缓和后，美国国务院在北京设立了联络处，工作人员中就包括中情局的一个秘密情报组。之后，美国军方也向北京派遣了武官。由于披上合法外衣，美国对华人力情报活动多少有些起色，但仍时常被中国安全部门发现。1995年，中国政府指控驻香港的2名美国空军武官“非法进入中国东南沿海的军事禁地”，随后将之驱逐出境。1996年，1名美国武官助手在海南搜集有关苏—27战斗机的部署情况时被拘捕。

当然，美国也从未放松过对台湾这个“小伙伴”的监控。从肯尼迪政府（1961年—1963年）开始，中情局台北站和美国驻台湾“大使馆”就开始秘密搜集蒋介石政权的情报，尤其是台军单独反攻大陆的实力和意图。约翰逊政府（1963年—1969年）时期，因为担心蒋介石的“反攻”计划会招致中美全面对抗，美国加大了对台间谍活动的力度。20世纪七八十年代，台湾的大规模杀伤武器研发计划引起美方重点关注。1975年4月，一名驻台“武官”搜集了有关台湾试验化学武器的情报。1987年8月，另一名“武官”报告了台湾制造神经性毒剂的情况。特别是1988年，中情局通过收买台湾核能研究所的一名副所长，获悉了台湾秘密发展核武器的内幕。由于担心引火烧身，美方强迫台湾当局终止了核武项目。

电子情报

二战中，美国的主要电子侦察机构——信号安全局，曾成功破译了绝大部分的国民党密码，但并未花大力气进行分析、研究。因为在当时，美方对中国（战区）的关注热情还赶不上对荷兰这样的欧洲小邦。很快，美国人就为自己缺乏远见付出了代价。1945年9月，马歇尔奉命前往中国调停国共纠纷，却得不到相关电子情报的支持。在他的强烈要求下，美国军方迅速行动起来，较短时间内便探明了国共两党的分歧所在。也正因为如此，美方对国共和谈最终破裂并不感到意外。3年内战期间，美国军方对中国的关注度再次急剧下降。1949年底，负责中国方向的电子情报员仅112名，尚不及苏联方向的二十分之一。

直到1950年3月，美国通信情报委员会才命令武装部队安全局（后改组为美国国家安全局），把中国作为一个“非常重要的目标”进行监视，但为时已晚。美国陆军位于冲绳的监听站只截获了大量未加密的中国商业电报，得到一些经济、交通、后勤和军队调动等方面的普通情报。而有关中国高层战略意图的高价值情报，武装部队安全局却很少能搞到，原因就在于此前他们没有重视对中共高级密码的破译工作。那段时间里，美国最可靠的电子情报来源居然是破译印度和缅甸驻华大使的外交电文，因为这2位大使可以频繁接触到中国领导人，尤其是周恩来总理。朝鲜战争爆发也未使美国的对华电子侦察工作“有所长进”。先是美国政府和整个情报界集体误判“中国不会武力介入”，这种错觉一直持续到中国发动第1次战役前。此后直到停战，关于志愿军的电子情报仍极度匮乏，而原因同样是无法破译中国军用密码。以至于板门店谈判时，美方对中朝代表立场的了解，只能靠截获朝鲜电报来获取。

朝鲜战争结束后，美国国家安全局（以下简称“国安局”）又把投入到中国方向的大部分资源转向苏联，因为苏联此时是美国斩头号敌人。1958年，对苏监视活动占去了国安局54%的人力、物力，而对华部分只占14%，其中又以监视中国空军和防空部队通信为主。通过分析中国的低级无线电通信，美方在1954年和1958年的台海危机期间，得到了大量有关中国军队调动和空军战机活动的情报。还是借助这一途径，美国对当时的中国经济状况有了较深入了解，包括黄金储备、货币价值、农业产量、贸易出口额、石油进口量、铁路运力、飞机产能和船舶制造实力等。除国安局外，美国海军和空军也派电子侦察机对中国沿海进行监视，以搜集中国预警雷达的相关情报。这种入侵式侦察的代价十分惨重，如1956年8月，1架执行监视任务的美国海军P4M—1Q侦察机被中国战斗机击落在距大陆海岸75公里处（编者注：据中国国防部网站介绍，1956年8月22日夜，一架美军P4M—1Q电子侦察机入侵中国领空，被空军飞行员张文逸击落在舟山衢山岛附近海面），16名机组人员全部丧生。

这一时期，台湾在美国对华电子情报战中扮演了重要角色，不仅为美国提供实施肮空侦察的飞行员，而且允许前者在岛上建立大量监听站。1953年5月，美国向台湾派遣了第1个电子情报组——美国陆军第9493技术行动组，负责对大陆沿台海地带雷达站进行监视。1954年7月，原驻菲律宾的美国空军无线电特遣队也转移到台湾，在台北以西21公里的树木口村建立了一处占地67万平方米的庞大监听站，负责截收中国大陆的空军和防空部队通信。至50年代末，美国军方已向该监听站派遣了多达数百名电子情报员，专事针对中国大陆的无线电监听工作。另外，在中情局资助下，台湾第34飞行中队（又称“黑蝙蝠”中队），于1958年开始利用P—2V飞机进入大陆领空执行电子侦察和间谍空投任务，但因屡遭中国军队迎头痛击，该计划被迫于1966年停止。其间，共有15架P—2V飞机被击落，148名国民党机组人员殒命（编者注：据国内媒体报道，先后有10架P—2V飞机被击落或意外坠毁，殉职人员达140多人）。

20世纪60年代，因为要全力满足越战巨大的情报需求，国安局只把8.4%的资源投向中国方向。尽管如此，美国的对华电子情报工作仍取得一些“成绩”：1960年秋，获悉中国将发展和试验核武器；1961年9月，侦知中国弹道导弹试验场位于中国西北的双城子（编者注：今甘肃酒泉卫星发射中心）：1962年6月，探明中国在台湾对面集结了大批地面部队和空军战机；1964年8月4日，“北部湾事件”爆发数小时后，发现中国开始加强中越边界防空力量；1964年8月6日，获悉中国在越南河内附近的一个空军基地部署了大批米格—17（编者注：歼—5）战机；1965年6月，在美国总统约翰逊宣布恢复对北越轰炸后的30天内，获悉中国已秘密向北越派遣了部队：1965年10月，中情局根据电子情报判断：中国向北越派遣了2.2万—2.9万人的铁道、防空和安全部队；1966年至1969年，通过对中国商业电报的分析了解到“文化大革命”的情况；1968年，通过截获的一段通话获悉北京军区正举行演习。

20世纪70年代，特别是尼克松访华并于1972年2月28日签署《上海联合公报》后，国安局降低了中国的目标级别。1977年4月，美军方人员全部撤离树木口，电子监听站被转交给台湾情报机关。当然，在这一时期，国安局和中情局并没有完全丧失对华电子侦察能力，如中情局在美国驻华联络处的屋顶就秘密安装了无线电截收设备，以监听北京及周边地区的军用和民用通信。另外，美国分别于1968年和1970年发射的“峡谷”与“流纹岩”电子侦察卫星也提供了新的情报渠道。在1979年中国对越自卫还击战爆发前及战争中，美国均准确探知了中越陆军的部署和空军活动情况。

20世纪80年代中前期，尽管中美关系不断改善和升温，美国情报部门却未因此降低对中国的关注度，而是利用卫星、飞机、地面监听站、潜艇和大使馆对中国进行了持续的全方位电子监控。冷战后，美国还利用电子情报对中国的国际形象进行“妖魔化”攻击。如1996，美国依据情报宣称，中方对美国政客进行“贿赂”。1998年，国安局又声称其截获的情报显示，一家中国国企与伊朗存在“秘密往来”。更有甚者，美国竟悍然侵犯中国主权。2001年4月1日，美国海军1架EP—3E侦察机在执行对华侦察任务时与中国歼—8Ⅱ战斗机发生空中碰撞，前者迫降在海南陵水机场。美方认为，飞机归还前已被中方做了拆解研究。

如前所述，台湾也是美国电子侦察的重要目标之一。有证据表明，美国曾对蒋介石的私人通讯进行过秘密监听，以实时获悉台湾反攻大陆的计划和行动。美国还通过这种方式得知蒋介石在台湾下达戒严令，是因为他对大陆的攻台计划“过于敏感”。
