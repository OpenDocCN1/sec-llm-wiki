# \[66\]《少数派报告》将成现实？伦敦警方试图预测犯罪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=207831774&idx=2&sn=b955397b9b3d1b6f21400999827c863b&chksm=168e6c9521f9e583bdba30c262b58c88c1c458845b04fa0d687d4d6344cb4debc6f9c4cbcbbd&scene=126&sessionid=1681268450#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=207831774&idx=2&sn=b955397b9b3d1b6f21400999827c863b&chksm=168e6c9521f9e583bdba30c262b58c88c1c458845b04fa0d687d4d6344cb4debc6f9c4cbcbbd&scene=126&sessionid=1681268450#rd)

伦敦警方正在测试一种系统，可以让他们抢在犯罪发生之前，就知道谁就有可能犯罪。然而，这并不像好莱坞电影《少数派报告》当中的系统，因为，它采用的预测技术目的是预测团伙犯罪。这是英国境内正在测试的第一款犯罪预测系统，尽管类似预测技术已经在世界各地进行了测试，甚至是部署投入实用。

该系统采用的软件由Accenture开发，工作原理是尽可能多的搜集嫌疑人的各种数据，同时通过警方系统来寻找以前的违法犯罪行为，并结合嫌疑人在社交媒体上的行为寻找各种可能的暗示。然后，它使用一种算法来决定一个人是否将在未来进行犯罪行为。它基本上是和假释系统类似，来判断一个犯人获释后是否会再进行犯罪行为。

Accenture公司公众安全负责人表示，这种系统可以让有限的警力资源，更有效地对付犯罪。这样做可以告诉警方，谁是最危险的人，这样警方就可以高效率地调用有限的资源进行应对。

显然，这已经引起了一些隐私和人权团体关注，他们要求伦敦警方更加透明地说明这个系统是如何工作的，谁已经上了这个系统的黑名单，以及收集的数据类型和细节。
