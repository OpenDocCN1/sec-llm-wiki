# 【51】新加坡邻里警岗制度

新加坡不仅环境优美、经济发达，在教育文化、城市管理，特别是社会治安等方面都有独到之处。新加坡是当今世界犯罪率最低、最安全的国家之一，新加坡警察工作高效、信息灵通、侦破案件快速，而这些则归功于上个世纪80年代初邻里警岗制度的建立。新加坡对警察实行三级管理体制，即警署、邻里警局和邻里警岗，邻里警局相当于我国的公安派出所，邻里警岗则类似我们的社区警务室。邻里警局具体负责邻里警岗警员的管理工作，统筹调配人力资源和物质资源，其触角深入社区及企业、社会团体等基层组织，为公众提供一流服务，同时充分调动社区民众与犯罪做斗争的积极性，形成“警社互动”、“警企互联”，真正实现了群防群治。

　　一起案件发生后，新加坡警察更关心的是“为什么会发生这样的案件？我该采取怎样的措施杜绝此类案件的再次发生？”“预防为主”的思想意识牢牢扎根于警员心中。

　　在新加坡，一线指挥官对警员的管理主要通过警员的工作记录、工作报告来考察警员实际工作情况。因此，警员的每一项工作都要记录，重要工作都要形成报告，指挥官进行批阅，指出下一步工作方向及工作中的漏洞与不足，重要情况则与警员面谈，共同讨论遇到的问题。

　　新加坡的警署一般设立规划部门、行动训练部门、人力资源部门、刑事调查部门等，邻里警局直接对警署指挥官负责。如新加坡裕廊警署，机关只有不到100人，而六个邻里警局的人员达600多人，可以看出警力部署的重点在基层。在一个社区内，新加坡尽量将职责任务相同或相近的人员纳入一个指挥官的统一领导下，以有效利用现有的人力资源。例如，社区巡逻警察就同时承担着高峰时段疏导交通的任务。对于我们来说，如何最大限度地调配好、利用好派出所的人力资源，则是一个值得深入研究的问题。

　　新加坡警察的高素质是闻名的，社区警察没有警种之分，他们要同时承担入户走访、调解纠纷、处理轻微犯罪案件、110快速反应、巡逻守候、现场勘查、维护交通秩序、处理交通事故等工作，真正做到了“一警多能”。新加坡的新警培训时间为六个月，培训内容与实际工作联系非常紧密，培训结束就直接上岗执勤。工作期间，每个警员都有厚厚的一本《程序手册》，像说明书一样详细说明每项勤务工作的要求与操作程序以及行文、表格样式等，警员只需严格执行就可以了。他们在注重基本工作技能训练的同时，也注重工作技巧的训练，如怎样与居民建立良好关系、与人沟通、如何说服别人接受自己的观点等。

　　新加坡社区警察的信息共享机制健全，各警局将收集到的各种信息，及时分门别类录入到计算机系统储存，供整个警察机关共享。在我国，加强派出所信息积累，实现信息共享，显然是应该重视的一项工作。
