# 【第50期】质疑现场警力配备不足 中国各界批管理部门疏忽酿踩踏惨祸

上海外滩跨年意外

**上海社科院学者王海良认为，上海办过世博会、亚信峰会等情况复杂得多、技术要求更高的活动，安保疏通都做得慎密，说明上海不是没有能力，这次是“不够用心”“有所松懈”。**

上海外滩跨年夜踩踏事件引起中国官媒、学者和公众质疑上海警方事发当晚警力配备不足，不解1200名警员如何维持30万人流的秩序，并认为政府有关部门轻忽松懈、缺乏警觉，给中国的金融中心上海敲响了社会管理亟待提升的警钟。

连续举办三届的外滩跨年灯光秀，2013年12月31日晚曾吸引近30万游客。但是考虑到往年人流量太大对交通造成压力，上海官方取消了本周三（12月31日）的外滩灯光秀。

不过由于很多人并不知情，想来外滩看浦江两岸夜景的外地务工人员、游客、学生等各路人潮又多，外滩这个开放空间的人流量周三晚间8时30分许其实已亮起了警戒的“红灯”，但有关部门没有及时控制疏导。

中国官媒新华社昨天援引权威部门消息指，当晚8时30分左右，外滩的人流量已接近2013年灯光秀时的规模，远超预期。上海地铁官方微博称截至当晚10时40分发布，上海全路网客流首次超过千万人次，达到1003万余人次，去年同期则还不到890万人次。

上海社科院学者王海良接受本报采访时说，从监测到人流陆续增多到事发，当局有约三个小时启动紧急调配措施：“为什么轻忽了？这是个明显的问题。”

新华社昨天发表的评论就直言，尽管踩踏事件的具体原因还未查明公布，但相关管理部门“显然难辞其咎”。踩踏事故虽然为突发事故，但1200警力如何维持几十万人的秩序？如果难以控制人流，能否及时有效组织力量控制人群的继续涌入？

管辖外滩警力部署的黄浦公安分局前天下午召开通气会时承认，监测画面监测到11时30分陈毅广场客流异常增多有滞留时，警员未能及时进入核心区域，花了5到8分钟来“突围”。

警方并表示，周三晚外滩人流量超过去年国庆当日的人流量，不过警力却比去年国庆节当日要少。去年国庆期间，澎湃新闻曾报道黄浦公安每天组织4000余人护卫外滩、南京路、豫园等热门景区的安保。

王海良认为，上海办过世博会、亚信峰会等情况复杂得多、技术要求更高的活动，安保疏通都做得慎密，说明上海不是没有能力，这次是“不够用心”，“有所松懈”。

他说：“民间自发组织的（跨年迎新）活动，政府不把它当成自己的事情恐怕不行。上海有2400多万常住人口，激动的时刻按照正常思路稍微挤一挤都会有问题，之前当然要主动规划，预先凭借以往的经验对几十万人可能出事的概率有个预判。”

上海交通大学城市科学研究院首席专家刘士林告诉新华社，当游客人数超过室内每平方米1人、户外每三平方米4人时，有关当局应该暂时关闭景区或者展览中心，疏散人群。

**网民：城市管理者该醒醒了**

复旦大学城市公共安全研究中心主任滕五晓建议，特大型城市应在安全管理上设立一个常态化的职能部门，统筹涉及城市安全的各个重要部门。

国际大都市上海的外滩迎新酿成36死的悲剧，新华社英文版过去两天也连续发文警告，上海虽在现代管理方面领先全国，却仍存在漏洞。这起事件给上海和所有地方敲响警钟，表明仍处于发展中阶段的全球第二大经济体中国，其社会管理依旧脆弱。

上海常住人口已超过2415万人，其中四成是外来人口。不少网民也表示，若再加上流动人口，上海城市的人口负荷不堪运转，吁请城市管理者们“该醒醒了”，“头痛医头脚痛医脚”的方式已不可行，要从根源上解决上海日趋尖锐的城市矛盾问题，控制总量人口，解决上海人文生活环境的各种乱象，提升民众素质。
