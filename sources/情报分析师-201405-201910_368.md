# 大数据告诉你112所高校校训

母校陪你走过青春中最美好的四年，相信母校的校训在你心中也一定留下了不一样的故事。

8月9日，人民群众喜闻乐见的《新闻联播》栏目推出了《校训是什么》系列报道，借此机会，为大家梳理了国内知名大学的校训。

本次梳理了112所985、211高校(华北电力大学、中国石油大学、中国地质大学、中国矿业大学拥有两个校区)的校训，并对它们进行了词频分析。

统计的初步结果，大家可以看下如下这个图，字体越大的出现的频率就越高。

看得有点眼花缭乱了吧。有没有发现，“求实”好像字体最大嘛。是的，统计发现，这些大学的校训中，“求实”一词使用的次数最多，共出现了21次，其次是“创新”的18次，接下来是“博学”的17次以及“厚德”的12次。

看完上面图表后，我们来看看校训背后的教育理念。

事实上，高等院校校训所采用的词汇语言反映了一个学校的价值取向，在一定程度上代表了办学者的教育理念，因而成为学校精神的代表。一些知名校训的传播，更提升了高校在学子心目中的地位，成为学校宣传最简明的标识。

如复旦大学“博学而笃志 切问而近思”的校训源自《论语》，从1915年提出至今已走过近百年光阴。在这样校训的熏陶下，年复一年培养出众多“自由而无用的灵魂”，形成了独特的复旦气质。

从各个高校的校训来看，其来源相当广泛。但其中，相当一大部分是来源于经典古籍。如中国人民大学的校训“实事求是”便是来自于《汉书·河间献王刘》;而清华大学的校训：自强不息，厚德载物则选自《周易》中的“天行健，君子以自强不息;地势坤，君子以厚德载物。”

而也有一部分校训来源于创办者的教育方针或是名家题词。如较为公认的北京大学的校训：思想自由，兼容并包就源自蔡元培任北京大学校长时提出的办学方针(北大现无明确校训，官网将“爱国、进步、民主、科学”称为传统精神，“勤奋、严谨、求实、创新”较少提);而南开大学的校训“允公允能 日新月异”则最早由张伯苓先生在1934年南开大学创办三十周年校庆纪念会上提出(其宣布宣布“公”和“能”为南开校训)。

而对于一些专业性的大学，其校训则反映了其自身特色。如在财经领域见长的上海财经大学其校训便是厚德博学，经济匡时。“经济匡时”由著名经济学家马寅初为其毕业生题写，寄望上财学子胸怀祖国、志存高远、服务于国家、奉献于时代、担负起天下兴亡的重任。而中国农业大学的校训“解民生之多艰，育天下之英才”则反映了农大百年不变的追求。

各校的校训不仅各有特色，也有许多相似之处。如在历史上同根同源的西安交通大学与西南交通大学的校训便都是“精勤求学 敦笃励志 果毅力行 忠恕任事”。
