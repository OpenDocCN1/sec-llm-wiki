# 【第28期】随笔：神秘的黑天鹅——反恐情报预警为什么那么难？

反恐情报的最高境界是什么？毫无疑问，是预警。所以情报经典著作《孙子兵法》里说“——所以动而胜人，成功出于众者，先知也”。可实践告诉我们，预警对于情报来说，是最难的事情。正如国外一位情报专家所说，凡是预测的都没有发生，发生发生的都没有预测。

反恐情报预警为什么这么难？因为情报人员遇到的是“黑天鹅”。 

 什么是黑天鹅，先讲个故事：在发现澳大利亚的黑天鹅之前，欧洲人认为所有的天鹅都是白色的，“黑天鹅”曾经是他们谈论社会和生活的一个约定俗成的惯用语，它指的是哪些不可能存在的事物或者不可能发生的事件。但是，这样一个似乎是不可动摇的信念，在第一只黑天鹅出现的时候，立即土崩瓦解。而只有在这个时候，人们认识天鹅的视野才刚刚打开。按照塔勒布的理论，所谓**“黑天鹅”来指称那些不可预测的重大事件**。

恐怖事件就是一只黑天鹅，“911”事件就是突出代表。这样的事件往往具有以下**三个特点**。**第一，稀有性**。它属于小概率事件，常常无迹可寻，出人意表，突如其来。**第二，冲击性**。它会产生极端影响，并且这种影响的事件是长期持续的；**第三，事后可预测性**。尽管它难以预期，但人们总是能在事后为他的发生找到五花八门的理由，并从而或多或少认为它是可理解、可预测的。

理论上，情报预警有两个层次：第一个层次是靠以往的经验进行规律总结，这就是白天鹅；第二层次是观测前兆，目的就是发现黑天鹅。 

基本来说，暴恐事件就是黑天鹅，黑天鹅属于小概率事件，发生的几率很小，并且无规律可循，且遵循必然发生原理。什么是必然发生，有些俗语可以说明这个问题，比如常在河边走，哪能不湿鞋？人在江湖飘，哪有不挨刀？上得山多终遇虎，走多夜路必见鬼等等。不管是多小概率的事情，只要做得多了，最终肯定是要发生的。假设某次暴恐事件真的被预警，但谁也不能保证会不会在其他时间以别什么形式发生。

那么，是否对黑天鹅就无能为力呢？非也。情报部门可以做的事情有：

首先要控制发生小概率事件的条件，也就是说作为风险管理者要发现更多隐性风险，危中取机。

其次，在情报分析方面，不能迷信大数据，尤其不能迷信数学模型，反恐情报分析不是解方程，这方面前车之鉴很多，如果预测错误必没有预测更糟糕。尽管所谓专家更有经验并掌握数据，有时候其实并不比公众更了解问题，只是更善于阐述，甚至是善于用数学模型把你弄晕。

第三，要关注人力情报的搜集。正如《孙子兵法》所言：“先知者，不可取于鬼神，不可象于事，不可验于度，必取于人，知敌之情者也”。人力情报的缺失是往往是反恐情报预警失利的重要原因，打响反恐的人民战争，这方面意义不容忽视。 

第四，预测很难，但预防可行。要尽量考虑到暴恐事件的严重性，并有针对性开展预防。

当然，恐怖事件发生的机制非常复杂，黑天鹅原理不能解释所有问题，但至少告诉我们反恐情报工作的艰巨性。最后推荐一本书：塔勒布《黑天鹅：如何应对不可预知的未来》一书中，塔勒布详细阐述了他的独门秘笈：对于运气、不确定性和小概率事件的持续关注。
