# 我所经历的一次生离死别——追忆我的学生赛买提

又是一年毕业季，这几天看了很多微信上关于毕业感慨的文章，有些如烟的往事浮上心头，其中一件，竟然是和学生的一次生离死别。

那是在十年前，我正在五局借调。在一次去往深圳公务的飞机航班上，一张报纸新闻映入我的眼帘——《公安民警深入新疆犯罪团伙虎穴勇斗歹徒壮烈牺牲》。我心里莫名的猜测，这名干警不会是刑警学院毕业的吧，因为在深圳，我院的毕业生实在是太多了。在文章的介绍中，的确提到，牺牲民警是中国刑警学院毕业。接着，我又有一个不详的预感，这个学生我是不是认识呢？翻开报纸的另一页，附有一张照片，一张熟悉的面孔，连同照片的名字——阿不都赛买提再次闯进我的视线，我不敢相信这是真的。

再看新闻的详细报道——阿布都·赛买提，生于1978年，为深圳市公安局布吉派出所的维吾尔族籍民警，从中国刑警学院毕业踏上工作岗位只有9个月。6月3日凌晨，为摸清操控小孩进行违法犯罪活动的团伙窝点，他孤身一人来到嫌疑人的住处，在那里遭受袭击，英勇殉职。至今，我仍然清楚地记得，赛买提身中三十余刀，其中十七刀是贯通伤。

霎时，眼泪模糊了我的视线。

我是赛买提的论文指导教师，记忆中的赛买提是个非常淳朴的孩子，他来自南疆农村，是2003年的毕业生。也就是说，到牺牲那天，他才工作了9个月。

一般来说，因为语言的关系，维吾尔族同学的毕业论文，指导老师不给予多大希望的，只要基本合格就行。但让我没有想到的是，赛买提是个非常认真刻苦的同学，在论文指导的过程中，主动和我谈，想写反恐方面的论文。毕业实习在家乡新疆，他搜集了不少这方面的案例，积累了很多资料，厚厚的一大本让我看。而且非常认真的和我讨论问题。

当然，论文的写作也是比较好的，即使和汉族同学比，也毫不逊色。我清楚地记得，他的成绩按照总分，在良好的学生中，排名第二，也就是说，还差一名就是优秀了。但当时，我没有因为他是一名维吾尔族学生而照顾他，按照实际排名给的成绩，虽然我有这个权利。但这也是我做过的一件非常后悔的事情——为什么没有给他一个优秀？！他的确够得上优秀！
