情报分析师

全国警务人员和情报人员都在关注


9.11之后不久就推出了国土安全咨询系统（HSAS），以警告该国可能发生恐怖袭击。它由五种威胁状况以及相关的建议防护措施组成。

1. 红色：严重状况。

2. 橙色：高状态。

3. 黄色：状态升高。

4. 蓝色：处于保护状态。

5. 绿色：低状态。

 

在大多数情况下，该国家/地区处于黄色中间位置，尽管在某些情况下，该风险已提高到橙色（高）。对于国家或地区变为橙色时（或当单独的航空安全恐怖主义警报将本地机场标为橙色时），您必须要制定响应计划。该计划应包括您和其他人（市政官员，企业和居民）可以在您的管辖范围内采取的一些普通的措施。 （有关这些措施的清单，请参阅框。）不管实际发生攻击的可能性有多高，或者采取措施的有效性如何，它们都可以帮助确保居民免受可能的攻击。HSAS在媒体上受到了广泛批评。 当您制定响应计划时，您也可能必须面对批评。由于在可预见的未来，我们不太可能将威胁级别降低到黄色以下，因此该系统被批评为三级而不是五级系统。也有人批评它没有提供明确的定义，说明“高、严重”这些级别所构成的条件，并且没有就每种情况下的操作提供实用的建议。然而，它的最大缺点是，它不是基于硬数据的，例如气象咨询。 天气预报是基于气象数据，涵盖了范围广泛的精确测量的天气变量，如大气压力、风速、潮汐预测、温度、预期降水等。当然，关于即将发生的恐怖袭击的确切信息很难获得，将某些威胁与该国特定目标或地区联系起来甚至更加困难。因此，对于每种可疑的攻击，数百甚至数千个城市都处于戒备状态，因为没有一个公认的方法可以根据潜在风险对目标进行评级。这会导致资源浪费和不必要的预防。 同时，也有可能导致大部分人口受到不必要的惊吓，从而触发了警报系统，最后导致了此警报系统失去了信誉。为了解决这个问题，最近的一些警报集中在该国的特定地区或特定的工业部门。我们正在考虑对该系统进行改进，并将与其他州和联邦警报系统更好地进行协调。同时，您别无选择，只能与HSAS合作并说服其他人也这样做。我们为橙色警报提供检查清单，这是最常见的，如果只是为了提醒您响应的复杂性以及所涉及的人员和组的广泛范围，那么检查清单就会很有用。

 

响应橙色警报的建议行动清单

警察主管清单

l 密切监视来自联邦，州和地方执法机构的所有可用安全和情报数据。

l 将访问所有关键信息的权限限制为仅关键人员。

l 对在敏感的公共建筑附近停车的车辆实施限制。

l 加强围绕重要建筑和重大公共活动的防御措施。

l 提醒警察和消防人员在应对事件时要小心。

l 检查建筑物和停车场是否有可疑包裹。

l 监视所有市政水库和集水区，废水处理厂以及其他敏感的公共设施。

l 在关键基础设施区域进行随机的道路检查站。

l 向紧急情况计划的所有人员提供建议，以进行轮班变更，任务分配，工作和救济周期，以及在情况恶化时的家庭护理和协助。

l 将部门应急资源，包括备用车辆和指挥所，分散到辖区内各个地点。

l 要求现场作战局司令官识别整个辖区的潜在指挥所和集结区，并将该信息转发给首长办公室。

l 与市长办公室、市政应急管理机构、消防部门和紧急医疗服务部门协调公共信息。

l 要求指挥官检查所有设备的操作准备情况。

l 酌情设置障碍物以控制交通流量。

l 与城市合作，确定并公开疏散路线。



 

市级官员(市长和市议会成员、城市管理者、消防队长、公共工程主管和其他应急人员)清单

l 审查当地的应急响应计划，并准备启动应急行动中心。

l 与同级政府部门协调应对计划。

l 与县卫生官员密切合作，发现可传播的疾病。

l 将所有应急管理和专门的响应小组置于回调警报状态。

l 员工要特别注意通过公共和私人邮件投递，收到的可疑或无人看管的包裹和物品。

l 将应急车辆放在在安全区域。如果可能的话，在室内停车场。

 

企业清单

l 做好适当的安全措施并保持正常运转。

l 指导员工向上级汇报可疑的活动、包裹和人员。

l 搜查所有的个人包和包裹，员工须在金属探测器下通过进入公司。

l 监控地下车库和装卸码头的进出情况；禁止在建筑物和基础设施附近停车。

l 检查和激活入侵检测系统、外部照明、安全围栏和锁定系统。

l 检查所有的货物；在适当的情况下，只接受（非现场的发货？）。

l 提醒员工加强安全意识，并设立一个适当的建筑物疏散程序。

l 制定一个适当的避难计划。

 

居民清单

l 由于行李检查和其他公共建筑和其他设施加强的安全措施，预计航班会延误。

l 通过拨打911向当地执法机构，报告关键公共设施或附近的所有可疑活动。

l 不要把无人看管的包裹或公事包放在公众地方。

l 组织应急物资包，与家人讨论应急计划。

l 对周围的环境保持警觉，不要让自己处于易受伤害的境地，密切留意孩子的活动。

l 与你的家人和邻居保持密切联系，以确保他们的安全和情绪。

l 监控全球事件和当地情况，以及当地政府的威胁警示。
