# 新手段|手机GPS在关闭状态下追踪用户轨迹

**一般的手机用户以为只要关闭手机上的GPS定位功能，他人就不能跟踪自己的行动轨迹，然而事实并非如此。**

  

在研究人员的最新测试中，研究人员使用了手机内部的其他传感器同样能进行定位功能。之所以开展这样的实验就是为了告诉普通用户，需要时刻留意手机的各种功能。

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1612227522019016707](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1612227522019016707)

这些功能一旦被利用就能发起旁路攻击，通俗地说，就是通过“曲线救国”的方式，即使在手机GPS定位关闭的情况下，也能获取用户的位置信息。因此从某种角度来说，手机是最好的监视工具。

  

![](../Images/020cb689a0df83ba30d0f4591e347b75.png)

  

研究人员选用了谷歌公司的安卓手机作为实验对象进行测试**，通过手机内部安装的各种传感器，例如加速度传感器、电子罗盘、陀螺仪，这些传感器都可以追踪到用户的位置信息。**

  

以上3种传感器的共同特点在于，只要手机的物理状态发生改变都会被记录下来。因此，只要用户携带着这款手机，只要手机发生了物理状态发生改变就会被记录保存，这和间谍工具有着异曲同工之处。

  

![](../Images/70bfb46c5ff30766bfb5a2bfc67dd1aa.png)

  

如果需要收集这些传感器的信息，只需要在手机上安装一个应用程序，在实验中，研究人员安装了一款手电筒应用程序后，这款程序便会在后台默认自动获取这些传感器收集的数据。  

以实验所在的城市波士顿为例，由于城市里有许多特殊形态的街道或马路转弯处，因此通过实验者身上携带的手机所收集的传感器信息，就能在最有可能的5个备选选项中，50%的可能猜出用户所在的位置。而对于一些繁华的市中心来说，由于网格化程度较高，反而不容易定位。

  

总而言之，收集到的传感器信息越多，定位的信息越准确。如果用户每天拿着自己的手机走过必经之处，那么就能绘制出用户的居住地、工作地、路线行进轨迹，准确率高达90%。  

随着智能手机的更新换代，这些内部的传感器精度也在不断升级，随着而来的就是准确率的不断提高。尽管在此次实验中使用的是安卓手机，但是由于一些应用程序在两者平台上所需求的权限相同，因此iPhone上也存在这样的问题。

  

实验最后，谷歌的发言人表示，最新的安卓操作系统Android P已经对应用程序的权限请求，特别是对一些传感器的权限请求进行了限制，防止用户的个人数据被滥用。  

而苹果公司方面尚未有任何表态。普通用户为了更好保护自己的隐私，尽可能从官方应用程序商店中下载应用程序，同时确保自己手机的操作系统时刻保持更新。
