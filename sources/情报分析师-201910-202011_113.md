# 恐怖组织使用加密货币的可能性与需求

**引言**  

鉴于资金在支持恐怖主义行动中的关键作用，反恐行动——特别是其分支领域——反恐金融(CTF)通常侧重于追踪疑似恐怖组织银行账户的资金流动，监控防止可能用于支持袭击和其他恐怖主义活动的金融交易。但是CTF战略对恐怖组织获取法定货币方面的成功，开始使人们担心——恐怖组织可能会增加使用比特币等数字加密货币来支持其活动。

**加密货币**

加密货币(Cryptocurrency），又译为密码货币、密码学货币，是一种使用密码学原理来确保交易安全及控制交易单位创造的交易媒介。加密货币是数字货币(或称虚拟货币)的一种 。

![](../Images/192e20da0b6da96205f5592a1122bdc4.png)

**加密货币去中心化的机制**

加密货币基于去中心化的共识机制 ，与依赖中心化监管体系的银行金融系统相对。去中心化的性质源自于使用分布式账本的区块链(Blockchain)技术。比特币在2009年成为第一个去中心化的加密货币。

**恐怖组织与加密货币**

为了了解恐怖分子使用加密货币的可能性，我们首先要考虑恐怖组织如何使用货币这一问题，然后再探求使用这种货币的需求和机会。我们可以从三个方面检查恐怖组织的资金使用情况:接收、管理和支出。我们研究恐怖组织所从事的金融活动类别主要包括：筹资、非法毒品和武器贩运、汇款和资金转移、攻击资金和运营资金。

| 活动名称 || 金融活动主要内容 |
| --- | --- |
| 筹款 || 获得捐助者的支持，特别是现金支持 |
| 非法贩运毒品和武器 || 收入来源 |
| 资金的汇款和划拨 || 发送或接收资金以支持组织活动 |
| 攻击资金 || 直接购买支持恐怖袭击的物资，并为袭击行动提供资金支持 |
| 运营资金 || 恐怖组织日常使用的资金支持，包括一般安全、通信和管理 |

  图1.恐怖组织从事的金融活动（来源于RAND智库报告）

 不难看出，所有这些类别都对恐怖组织使用加密货币构成了重大挑战:大额收据难以管理或以匿名方式支出，加密货币仍然需要基础设施来管理和支出。但随着加密货币技术的完善，恐怖组织使用加密货币的情况很可能会改变。加密货币技术的未来改进可能会对恐怖主义金融产生重大的长期影响。

通过研究一系列恐怖组织的金融交易案例，譬如基地组织及其附属组织、伊拉克和大叙利亚伊斯兰国(ISIS)、真主党、毒品恐怖组织和独狼袭击者等组织。尽管这些组织的目标不同，但他们对匿名、安全和现成资金流的需求，使得加密货币对他们来说具有一些潜在价值。

加密货币有为恐怖分子融资提供便利的潜力。恐怖组织是否会使用加密货币、以及如何使用加密货币系统，取决于可用的技术和加密货币属性，以及该组织的需求和能力。新的加密货币可能会带有恐怖组织所需求的属性

**加密货币的属性**

对于恐怖组织组织，通过研究他们所进行的五种金融活动(筹资、非法毒品和武器贩运、汇款和资金转移、攻击资金和运营资金)，也由此评估了加密货币属性在促进这些活动中的重要性。

加密货币的特性分别是是匿名性、可用性、安全性、可接受性、可靠性和容量。

1.匿名性，指的是隐藏和保护用户身份的能力。

2.可用性，是指用户可以轻松地进行交易和管理自己的货币。

3.安全性，是指加密货币基础设施确保交易和用户帐户的机密性、完整性和准确性的程度。

4.可接受性，指的是货币被用户社区接受的程度以及用户社区的规模。

5.可靠性，指的是用户所看到的事务的速度和可用性。

6.容量，是指加密货币基础设施中交易的平均总规模。

借助于对恐怖组织金融交易的评估，包括对其使用加密货币所具有的属性研究，比如加密货币市场的可靠性和数量，我们发现没有任何当前的加密货币能够满足恐怖组织的所有金融需求。然而，我们也注意到像比特币这样的加密货币，特别是可用性提高了的比特币，可以用于筹款，并且一些迹象正在证明，恐怖组织可能正在为此使用加密货币。

  

  

**实例证明**

2019年1月29日，哈马斯的一个分支—Izz ad-Din al-Qassam Briqades发起了一场运动，呼吁支持者通过向一个比特币地址捐款来资助其军事行动。这一努力对加密货币交换（cryptocurrency exchanges）、钱包提供商（wallet providers）和其他在加密领域促进交易的企业都有重大影响。

![](../Images/a00dba37993d7f5a44381ea15c043623.png)

                                         哈马斯

  （伊斯兰抵抗运动Islamic Resistance Movement）

   哈马斯的筹款活动已经不是第一次引起外界的关注。哈马斯早期的活动还包括al Sadacah和Jahezona jhadist的筹款活动。不久之前，在美国发生的一起案件中，一名女子代表ISIS使用加密货币清洗被盗信用卡诈骗的收益。还有大量证据表明，右翼新纳粹极端分子使用加密货币融资。恐怖分子和极端分子确实在利用网络探索这种新的金融技术的潜力。但需要注意的是，目前为止使用加密货币的活动所取得的成绩是有限的。

  

  

**结论**

目前加密货币作为恐怖主义融资的一种手段没有构成重大威胁。然而，如果加密货币开始增加匿名功能并提高安全性，再加上缺乏相关的国家法规，它们被恐怖分子潜在使用的风险将会增加。现今为止的加密货币一般都不能很好地与被审查的恐怖组织所需要的加密货币的全部特征相匹配，但可能被用于特定的金融活动。

在未来，加密货币的哪些特性会让它们更容易被恐怖分子使用，以及加密货币交易作为恐怖组织金融手段在未来的用途是不清楚的。尽管如此，加密货币最近取得的几项进展将有助于那些对世界各国构成恐怖主义威胁的最先进组织使用它们。加密货币的使用将特别有利于那些已经从事跨国筹款和犯罪活动的行为者。

我们的研究表明，如果出现了一种可被广泛采用又同时具备更好的匿名性、更好的安全性，并且受到松懈或不一致监管的单一加密货币，那么这种加密货币的潜在效用，以及它被恐怖组织使用的可能性，将会增加。即使没有这种货币出现，恐怖组织也会选择使用一些属性高度匹配该组织金融需求的货币，但使用的程度将取决于这种货币的生存能力。
