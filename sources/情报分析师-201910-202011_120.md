【摘 要】 区块链技术的发展对公安信息监管模式、警务运行机制、警务活动边界以及警务执法证据等提出了全方位的挑战。应主动融入区块链技术发展浪潮，利用区块链技术优化警务工作质效; 应立足警务实战需求，推动完善区块链相关政策法律法规体系; 应把握犯罪形势发展，加快组建、整合打处区块链违法犯罪活动专门力量; 应发动全警参与区块链社会宣传，强化全警区块链规范意识。   

  

【关键词】 区块链; 警务工作; 社会治理; 风险规制

  

![](../Images/027cd07aed22f9da0d386231d13e4b8e.png)

  

随着互联网 +、大数据、边缘计算、人工智能、物联网、5G、工业 5. 0 等信息技术快速发展及相互间深度融合，以信息科技和数据驱动的智能数字时代正加速到来并不断地影响和改变着我们的生活。2019 年 10 月 24 日，习近平总书记在主持中共中央政治局第 18 次集体学习时，就把握区块链技术发展现状和趋势相关问题作出指示，要求通过明确主攻方向、加大投入力度，进而将区块链技术作为核心技术自主创新的重要突破口，以该技术之集成应用推动新技术革新和产业变革，以该技术创新与发展为引擎推动攻克一批关键核心技术。习总书记的指示，深刻阐释了当前我国区块链技术的生成语境、发展方向、重点任务和安全措施。作为国家战略与核心技术自主创新之重要突破口，区块链具有高度的融合特性，它在数字经济时代金融、监管与民生等领域的重点应用，对推动数据共享、建设可信体系及优化运营成本、业务流程与协同效率等方面发挥着重大作用。

  

“警务发展的方向和角度归根结底是由社会发展的阶段性特点决定的。”［1］坚决打好防范化解重大风险攻坚战，是党的十九大报告作出的重大战略部署。在智能数字时代区块链技术介入背景下，处于社会风险聚集和爆发关键点上的警务工作势必迎来前所未有的挑战。警务工作应在准确把握区块链技术实质和发展方向基础上，做好新技术带来的社会风险应对并促进区块链技术与警务工作深度融合，进而更好地体现时代性、把握规律性、融合创新性，不断优化质效。

  

**一、区块链技术的技术逻辑与实践应用**

  

( 一) 区块链技术的技术逻辑

根据工业和信息化部 《中国区块链技术和应用发展白皮书 ( 2016) 》的定义，区块链是一种“采用加密、哈希与共识机制保证网络中每个节点所记录的信息 ( 亦称分布式账本) 真实有效的新的信息与网络技术”［2］。与以往的技术相比，区块链技术主要展现为 “自治”“可信”两大特点。它本质上是通过一串使用密码学相关联的数据块而搭建的一种无须任何中心节点、真正意义上去中心化的分布式 ( 点—点) 网络、账本数据库。通过记录并随时更新网际间所有交易信息，区块链上的每一个节点均能通过各自独立地记录网络信息以及相应的不同策略进行各项网络操作，单个用户可通过合法手段从中读取、写入信息。网络中具有强大运算能力的矿工会针对加密交易利用算法解密验证，创造出新的区块来记录最新交易，而新的区块将按时间顺序线性地被放置到原有区块末端，使账本不停地增长、延长，通过复杂的公共、私人密钥设置可通过区块链网络将整个交易账本实时广播［3］。网络中所有节点的信息通过区块链之共识机制确保了真实、可靠、同步，并对篡改信息予以禁止。其技术演进路径经历了数据库、区块链 1. 0、区块链 2. 0、区块链 3. 0 等几阶段。

  

在区块链 1. 0 版本中，主要是以区块为单位且兼具全网共享账本、源代码开源、非对称加密为主要特征的链块式数据结构，比特币等电子货币是其主要应用场景; 在区块链 2. 0 版本中，以分布式应用为主要特征 ( DAPP) ，通过创建共享式技术平台并向开发者提供支持 PoW、PoS、DPoS 等多种共识算法的 BaaS 服务，微软 Azure 等各种金融交易、公共和私人记录为其典型应用场景; 在区块链 3. 0 版本中，以价值互联网为内核的信息资产确权、流转加速区块链技术从金融领域向非金融领域扩散并实现全场景综合应用，区块链与大数据、云计算、人工智能、5G 和工业 5. 0 等的深度结合广泛应用于智能化领域，可信度提升，成为未来互联网的重要组成部分［4］。

  

在之前的社会信任体系中，作为人类社会发展基石之信任模型往往通过某个权威机构或组织以层层传递的信任链保证合约签订、货币发行、商品交易等社会经济行为之完成。在智能数字时代，基于数学、密码学及整个区块链系统的信息技术所塑造的信任模型将传统信任彻底颠覆，使互联网从单纯的信息流动赋予价值、责任意蕴，对人类经济社会活动和生产生活方式予以根本上的创新，开启了人类信息文明的新纪元［5］。目前，互联网受一些主流权力平台垄断，如 Google 通过算法推 荐 左 右 网 络 浏 览 者 能 获 取 的 新 闻 信 息; Amazon 通过算法定价为购物者 “量身定制”商品的价格; Facebook、Twitter、WeChat 等社交网络平台则控制着用户的个人隐私、社交信息。区块链的 “自治”属性使网络用户通过自主选择算法策略等方式自主占有、使用、处分、享有数据权益成为可能，其互联网权利之 “回归”对目前互联网组织与架构体系形成强烈挑战。此外，通过区块链匿名性、不可删除与篡改性、多方共维与账本共享等优势建构 “身份+行为+权属”存证链，实现 “人+物+行为”等多类型数据有效存续期间内的快速确权、认证，通过司法鉴定与公证、审计与仲裁、社会面第三方认证服务机构等多元公信主体联合参与共建的可信、实时区块链数据存证，为用户提供防伪保真、溯源鉴真功能，能有效解决当前各参与方在传统业务中的信任协同机制缺失、不畅问题。如阿里云邮箱与法大大开放式 SaaS 服务平台联合开发全球首款基于区块链技术的邮箱存证产品，用户可以通过将重要邮件的哈希值等特征数据同步保存至权威第三方机构，在纠纷发生时可以自行下载邮件全文发送至司法鉴定机构，对原始邮件特征数据与此前存证数据进行分析、比对后，生成相应司法鉴定报告，以科技力量推动司法鉴定业务信息化与交易信用塑造。

  

（二) 区块链技术的实践应用

目前，区块链在类型上分为公共、联盟、私有链: 公共链参与、读取、交易有效性确认实现全域开放，联盟链以其参与节点间良好连接状态而具有验证效率较高、运维成本低、扩展性与数据处理隐私性强等特点，私有链因其参与节点有限、数据使用与管理权限严格而满足不同的个性化需求。因此，区块链技术自 2009 年诞生至今，在金融创新、智慧物联网、知识产权保护、房地产交易、奢侈品销售、供应链与食品药品安全追溯等行业领域深度应用，使相关行业与区块链技术本身同时获得快速发展。截至目前，与区块链技术相关的比特币、以太坊、EOS、Hyper Ledger等多个公共区块链开发、应用平台为其快速开发与部署提供了方便、快捷的基础。譬如，在以太坊应用平台上，目前已部署超过 2667 个应用 ( D Apps) 和 4200 个智能合约 ( 即以数字编码形式定义承诺，交易双方无须彼此信任，一切交易均由代码强制执行) ，每日活跃用户数超过 2. 7 万，一 个 “基于区块链技术的分布式应用生态体系业已形成”［6］。金融机构等在支付领域利用区块链的分布式记账、透明性与去信任、共识机制与智能合约等特点，能显著提高业务处理效率、降低金融机构间对账和争端解决成本，拓展小额跨境支付业务实现普惠金融。如摩根大通 ( JPM) 创建了目前世界上最大的区块链支付网络，IBM 发布了其跨境区块链支付服务，万向控股与多家金融机构合作研发了区块链底层架构协议、物联网安全认证、现券与股权交易系统等多种区块链应用。

  

基于区块链 “自治”特性所衍生的各类自主分布式管理属性，业已被广泛应用到新组织结构、身份与隐私管理等相关领域。如以分布式组织模式为标签的史上最大众筹项目 “The DAO”和作为自治 身 份 管 理 平 台 ( Self － sovereign entity ) 的 Sovrin，前者尽管由于一个安全漏洞而导致最终失败，但其通过区块链技术所构建的一个网络分布式自治组织，在不到一个月的时间内便从 10000 多名用户手中筹集到价值约 1. 5 亿美元的资金; 后者则旨在不依赖任何中心机构前提下，使用户通过安全隐私 的 方 式 获 得 可 验 证 的 身 份 凭 证，实 现“我的数据，我做主”，从而使其尽最大可能地保护自我隐私成为可能。

  

在奢侈品销售、食品与药品追溯、防伪认证与供应链管理等领域，区块链基于密码学搭建的分布式账本数据库因其 “可信”特性得到深度应用。如英国 Ever ledger 公司基于区块链技术的不可篡改性与时间戳功能，将不可篡改的账本记录与其售出的每颗钻石的身份、交易信息等契合，截至目前，该公司共在区块链上上传了约 98 万份该类账本记录。法国巴黎的 Block Pharma 公司则将区块链技术 应 用 到 药 品 追 溯 与 防 伪 上，其 提 供 的Block Pharma 模块通过嵌入医药企业信息系统，将制药企业发布产品型号、QＲ 码等相关数据信息记录到区块链上，从而为药品提供各自独特的、相匹配的身份信息追溯服务。我国的京东集团通过“物联网+区块链+大数据”以及与监管部门、第三方机构、品牌商合作打造京东区块链防伪追溯开放平台，实现线上线下零售商品追溯与防伪，更有效地推动了品牌产权保护、消费者权益维护、电商平台信用等升级。

  

此外，基于区块链探索未来网络基础设施的架构的研究得到各国研究者们的广泛参与。区块链技术使融合互联网、工业互联网、卫星通信网络的下一代未来网络空间的 “人—设备—服务”获得统一身份认证、管理，使其相互间的可信通信以及基于智能合约的多智能体实时交易在区块链技术的助推下相关实现成为可能。

  

**二、智能数字时代区块链技术对警务工作的挑战**

区块链技术历经十余年发展，不断渗透到各行业并展现出良好发展态势，其应用领域扩展到诸如音乐下载、游戏设计、汽车租赁、婚礼举办、政策实施、城市建设等日常生活的方方面面。在社会治理领域，区块链技术有着分布式、透明性、可追溯性、公开性等优势，在促进社会治理结构扁平化、治理及服务过程透明化、治理技术信息化等方面具有重大价值，其深度应用还能提高治理数据安全性、提升治理民主与有序参与、重塑治理伦理与信任规则以及 “推动智慧治理和责任政府建设”［7］。在快速定义治理规则、促进社会治理模式升级的同时，有害信息在区块链中的传播也使其潜藏着巨大隐患。当前，大多数研究仍处于理论设计或小规模实验改进阶段，真正发挥区块链的价值，尚面临可扩展性、互操作性、有效监管、安全漏洞、技术限制等的挑战。

  

公安部门承担着刑事司法与社会管理的双重职能，无论是打击预防犯罪、社会治安综合管理、社会稳定与突发事件防控、行政服务等，都是其作为功能单元的社会治理具体行动，在社会治理体系中扮演着重要角色。在智能数字时代，信息科学技术在对警务工作技术赋能的同时，也对其提出巨大挑战。随着区块链技术的发展，当前警务工作在观念认识、运行机制、技术监管等许多方面都面临区块链技术的冲击，警务工作本身及其在社会治理网格中的角色嵌入也面临调整。

  

( 一) 区块链技术对公安信息监管模式的挑战

区块链技术的发展经历了民间自发尝试到企业主导、政府重视和引导等阶段，其最初诞生于一群被称为 “网络朋克”的无政府主义者群体中。作为区块链技术最早、最成功应用的比特币，被广泛应用于 “暗网”中，沦为网络洗钱、非法交易的隐蔽途径，为资助恐怖主义等违法犯罪活动提供了 “漂白”的工具。基于区块链技术的 ICO ( Initial Coin Offering，也即首次代币发行) 则被不法分子恶意利用，进而成为金融欺诈和非法吸收公众存款等违法犯罪活动的手段之一。“去中心化”作为区块链技术的最大优势属性，其分布式节点架构使修改区块链数据需控制具体区块链网络中超过 51%以上的 “全网算力”方为可能，而全网一半以上的节点一旦被控制将使区块链的最大优势不复存在。在互联网金融领域，区块链技术由于门槛较低并且会使所有交易信息透明化， “不法分子实施网络诈骗、黑客或木马侵入区块链系统等将带来严重侵害。”［8］。

  

区块链技术的核心技术要素是各数据模块按时间先后顺序相连、组成的链式数据结构以及依靠密码学方法保证数据不可篡改且不可伪造的分布式账本。相较于传统互联网、数据库，区块链有着数据安全的巨大优势。然而，技术本体之安全并不能确保其在应用、管理上的安全性，以区块链为媒介的有害信息传播将更具隐蔽性、破坏性。当前，网络信息监管主要是以网络内容治理为核心，以负面清单为基础，在政府主导下多部门主体协同进行［9］。公安机关在网络信息监管中主要承担执行者角色，以常规网上信息安全巡查进行预防，以具体执法办案事后补救，呈现被动模式。“安全”与 “发展”是网络信息监管中并存的价值，区块链技术使网络信息监管面临新的困难: 如何揭开区块链密钥而有效、及时审查具体网络信息内容? 如何与尊重隐私权合理期待、促进技术发展等价值追求相协调? 如何实现网络信息监管中的 “落地查人” 精准性、取证有效性?等等。

  

区块链技术相关的监管体系匮乏，再加之区块链的去中心化、加密等特点给网络非法言论监管、查处带来困难，利用区块链技术进行的犯罪共谋、准备实施暴恐活动、严重暴力犯罪活动等将更为隐蔽、复杂，与区块链相关的遗失、盗窃、攻击、投机、洗钱等新型违法犯罪现象不断产生，给公安机关有效侦查取证、精确打击带来挑战。例如，毒品犯罪、黑社会性质组织犯罪、间谍犯罪、恐怖活动犯罪、走私和破坏金融管理秩序犯罪、贪污犯罪等犯罪嫌疑人利用区块链去中心化、透明性、匿名性、可靠性、全球支付、分布式记账等特点进行违法犯罪活动，对犯罪主体与行为认定、跨境抓捕与国际刑事司法合作、信息化取证与证据规则等带来巨大挑战，亟须完善刑事一体化下的犯罪构成要件与诉讼证明、没收制度、情报信息、电子认证、诉讼保全等制度。 

  

( 二) 区块链技术对警务运行机制的挑战

随着公众有序参与、合作治理等行政模式变革，政府日益公开、透明，区块链技术之账 本、信息共享等属性可改变诸如数据存储、共享、透 明、溯源、程序等社会治理关键领域目前之局面，这在信息、金融、合规、文化、医疗等行业领域和公共服务场景中得到展现。社会治理区块链嵌入作为一种治理技术，迥异于传统的政治议程，通过区块链技术的潜在优势革新和改变目前的政府管理模式、逻辑、规则，将治理规则、逻辑渗透到算法、技术结构之中，基于区块链技术的治理不仅能见证规则生成路径、实现实时互动与不断完善，还能在对其记录后及时进行验证，从而进一步增加透明度，提高效率，推动完善、革新治理流程，凝聚共识，以数据、信息技术治理驱动智慧治理。区块链的应用基础在于群体参与和共享，该技术所采用的共识算法将从治理源头着手设计、重塑、完善治理规则，通过开放互通实现区块链的价值，通过拓展有序参与使所有参与者权利 平 等、责 任 平 衡，拓展社会治理的多元结构。

  

然而，在一个区块链系统中，可扩展性、无中心、安全性三者最多只能取其二，目前在一个区块链系统中完全获得此三种属性几乎是不可能的，面临着所谓的 “不可能三角”，而一个理想的区块链系统中此三种属性又是不可或缺的，三种属性间的折中与权衡是任何一个区块链系统之架构策略所普遍面临的共性困局。要想实现区块链的真正 “可信”，必须做到整个网络达成共识，进而对交易吞吐量产生影响。以目前典型平台的网络交易量与区块链计算速率为例，比特币每 10 分钟打包一个区块，以太坊每秒仅能处理约 15 笔交易，远低于淘宝每秒百万以上的交易吞吐量，这反映出目前的区块链交易吞吐量仍然较低。因而，对于区块链技术而言，在确保可信的前提下，克服可扩展性问题仍然道阻且长。

  

当前，优化警务运行机制、提升警务效能是全面深化公安改革的重要内容，各地公安机关基于这一共识目标，各自展开积极样本探索，从党建引领、技术赋能、管理变革、传统借鉴等方面予以融合创新，如 “警力下沉、警务前移” “调整和精简机构、优化职能配置” “共享资源、不同警种无缝对接” “向数据借力、优化指挥调度机制” “完善职级待遇与战时激励、激发队伍活力”，等 等。随着区块链技术的发展，技术嵌入警务对警务运行机制提出新的变革需求，如警务数据共享的安全性、层级性，警务管理、警务指挥、警务装备对技术如何回应，等等。与此同时，区块链技术本身广泛应用带来的技术风险、法律风险、道德风险对警情类型、执法方式、警企合作、警务公开等提出新的课题，警务运行机制提质增效亟须适应性调整。

  

( 三) 区块链技术对警务活动边界的挑战

当前，作为全球最大开源代码托管平台的GitHub 上有超过 6500 个活跃区块链项目，但各项目间使用的平台、开发语言、协议、共识机制和隐私保护方案等迥异，许多机构、组织、用户大多都在较小规模范围内尝试开发应用区块链技术，使其技术、平台多样化。要真正实现区块链技术的 “可信”之实践可行，则需确保区块链的规模足够大，因而要求将这些异构的区块链链接起来。然而，目前尚缺乏统一的技术标准对众多的区块链技术方案和系统整合以 “实现不同系统和应用间的访问、衔接”［10］。相比于互联网时代 “信息孤岛、异构数据融合与异构协议互操作”的桎梏，智能数字时代不同区块链之间的跨链互通、矛盾涤除将面临更大挑战，区块链面临着严重的 “互操作性”问题。

  

区块链技术的数据不可篡改、可追溯性使其还可被应用到溯源防伪领域。譬如，在食品安全领域，可通过区块链技术完善供应链与生产加工全流程体系，根除食品供应链等环节以及流转过程中的假冒伪劣问题; 在货币发行与流通领域，将分布式账本应用到跨领域精准管理以及基于区块链框架构建新型数字票据模式将成为可能; 在互联网金融领域，通过区块链的点对点数据授权共享机制，可为相关监管者、金融机构与用户提供更为完整可信的数据分析产品，与此同时，通过区块链存证系统的接口与互联网金融业务平台实时链接，可在保护业务隐私的前提下对互联网金融业实现有效事前监管、风险规制。区块链技术的分布式自治属性使其在认证、交易、多形式多主体组织协同等方面将发挥巨大作用，区块链技术为警务部门内部及其与社会公众间的互动模式提供新的建构张力，但其 “互操作性”也是技术与警务互动中亟须解决的难题，如何以区块链技术建构新的社会治理与警务运行互动机制，对警务活动边界提出了挑战。

  

当前，警务工作面临从传统的 “由人到案” 向 “由数据到人” “由数据到案”的现代模式转换，从人与人之间的接触办案、摸底排队向数据挖掘、云计算和情报信息比对的智能数字警务变革，信息技术拓展了警务活动的边界，而区块链技术的发展则将此推向深入。搭建跨平台、部门的社会管理数据平台，将推动公安部门与其他部门在社会面信息、基础信息方面的数据集成、共 享、流转，如当前公安部门出具的 “无犯罪记录证明”等纸质证明可通过加密的一体化数据归口管理电子介质得到快速呈现，具体鉴真时，对数据信息附条件、分场景触发读取。基于区块链技术的居民身份证将承载更多功能，进一步优化民众警务服务体验和生活便利。与此同时， “信息技术对公安工作产生巨大影响，大数据等不仅成为当前动态化警务情报信息等的新特性，也为完善立体化社会治安防控体系提供核心技术、手段支撑，对提高社会预警、决策科学性以及未来智慧化警务建设具有积极意义”［11］，区块链也将推动警务公开、参与、监督、程序透明、管理效率化与服务优质化，针对区块链、大数据等相关领域的警务业务部门分别建立，将使警务工作领域得到拓展。在警务工作场景中融入区块链技术，将进一步推动指挥模式层级优化、警务工作动态痕迹管理、侦查讯问询问工作以及录音录像制度的变革，在推进公安队伍正规化建设、执法规范化建设，以及智能化指挥办案平台和警务物联网、警务大数据等建设和深度应用。

  

然而，我国 地 域 发 展、行业状况存在差异，各地、各行业公安机关有着不同的资源优势、特殊情况、具体需求，区块链技术背景下的未来警务活动既不可千篇一律，也不能差异悬殊，在制定全国性政策指导意见的宏观指导下，如何激发基层活力，彰显行业特色，因地制宜、集中优势开展警务活动，将成为今后一定时期公安建设面临的重要挑战。

  

（四) 区块链技术对警务执法证据的挑战

将区块链的时间戳应用到公证、认证领 域，拓展了数据的可信性。政府的中心化权威是传统社会治理中公证可信度形塑的依归，但有限的数据维度、历史数据缺失、证据基础事实碎片化等，将使公证对象的一些有效信息严重缺失，而区块链相关属性优势所生成的不可篡改的数字化证明特质在数字版权、知识产权保护、证书鉴真、公益慈善与信托诚信等方面，将 “塑造全新的认证机制从而优化相关公共服务与管理水平”［12］。利用区块链技术不可篡改性的属性优势，将其应用到信用资产化和金融监管等领域将大大简化业务流程、推动信息公开和质效提升。例如，教育部门可利用区块链技术在解决学生信用体系不完整、数据维度局限、验证手段不足等问题上完善现有的学信网服务，建立学术诚信、学习履历与成绩追溯清单等; 税务部门可利用区块链技术改造现有的票证体系，节约行政资源，实现电子纳税凭证鉴真; 银行可通过区块链技术立体化分析小微企业的经营状况、资信情况、治理架构、投资方向等，进而评估其贷款偿还能力与资金风险; 卫生部门可通过区块链技术推进病例电子化，实时交流病人信息与治疗症结，在重大疑难病症上进行远程会诊，或在医患纠纷发生时及时通过完善程序公开定分止争、吸纳不满; 民政部门的公益项目可通过区块链技术完善信息公开、数据分析与评估，方便公众参与、社会监督，推进负责任、智慧化慈善公益，等等［13］。

  

区块链技术在我国出现伊始，理论和实务界便产生了有关区块链中形成和保存证据在诉讼中是否应得到承认的激烈争论。2018 年 6 月，杭州互联网法院在其判决中确认了原告提交的有关其著作权信息的区块链记录证据效力。① 此后，2018 年 9 月 3 日发布的 《最高人民法院关于互联网法院审理案件若干问题的规定》等司法解释，明确规定互联网法院应当确认区块链作为存储及验证电子证据的效力，正式明确了区块链证据在司法程序中的效力。

  

虽然云计算、大数据技术目前正飞速发 展，但区块链的容量有限使得区块数量随着数据爆炸成几何级数增长，存储的区块将面临上限。目前，区块链技术的计算效率有限，譬如，区块链技术在能源互联网等一些特殊领域的应用上，尚无法满足能源产销的实时性要求， “网络中的矿工需要不断进行哈希计算，将会消耗大量的电力资源。”［14］公安机关办理行政案件、刑事案件中将涉及大量的侦查取证工作，区块链技术的发展使得传统的电 子 数 据、视听资料等证据种类在办案中面临 新 的 技 术、法 律 难 题，基于区块链的侦查取证、证据收集使用、证据保存、审查判断、案卷制作与移送等问题给警务工作提出了新的要求。

**三、区块链技术背景下警务工作的应对**

近年来，大数据、云计算等与警务结合推动了公安信息化深度发展，各地公安机关收集、整理和利用的警务大数据规模不断跃升，数据与警力、装备、党建作为重要警务资源不断快速发展。智能数字时代，区块链技术与警务工作结合，推动传统的中心化数据库向 “中心化+去中心化分布式账本”立体化、多节点数据库架构转变，数据的价值得到更大范围、更广领域、更高速效、更深层次运用，区块链技术驱动下的服务国家治理体系与治理能力现代化的中国特色现代智慧警务正在快速生成。区块链作为互联网时代的颠覆性技术，其自身飞速发展及与大数据、人工智能、物联网、云计算、5G 等信息技术深度结合应用，使城市从物理时代不断跨越到智能数字时代，在助推解决社会治理顽疾与治理成本、重构社会信用体系与数据伦理、完善社会治理方式与有序参与、提高社会治理效能与智慧沟通等，从而推动公正、安全、有效、有序、和谐的社会自治方面产生巨大影响。然而，有害信息写入区块链传播，将使利用区块链进行诈骗违法犯罪活动大行其道。区块链技术是一把双刃剑，警务工作在此背景下需从以下方面予以积极应对。 

  

( 一) 主动融入区块链技术发展浪潮，利用区块链技术优化警务工作质效

警务工作需置身社会治理话语体系中主动寻求创新，譬如，“在反恐情报信息相关工作中应用大数据技术能有效助推数据融合、情报共享，通过数据碰撞、挖掘技术从海量数据中有效提取价值信息并对其进行深层次分析研判，相关数据分析与处理模型能满足反恐等临战对处理海量数据之科技需求，为警务实战提供有效支撑”［15］，作为智能数字时代关键技术的区块链技术亦然。通过把握区块链技术可为警务创新与社会治理警务环节寻求新的突破口，不断拓展警务工作场域，提升警务服务质效，强化违法犯罪打处力度，完善犯罪预防预警机制。警务部门通过与其他政府、社会主体多方协同，加快开发绿色社会治理区块链技术应用，助推社会治理数字化区块链建设。政工人事、指挥与通信、警务保障等部门可通过“个人身份+民警私有+警用装备”区块链助推现代警务精细化管理、警力智能实时调度与装备维保、情报导侦下的立体化合成作战、智慧公安 “党建云”与微教育训练及心理咨询服务、执法规范化与队伍正规化建设等的实现; 将创建、读取、写入权限布局在不同公安部门，构建网格节点并分级、分人、分事设限赋权，利用区块链的不可篡改性、可追溯性，将模块化数据与中心数据库实时碰撞比对，深度拓展警务区块链的应用场景;在公安机关内部，可在现有的经侦、网安、信通、交警等业务警种基础上组建基于区块链技术、大数据等的联合作战平台，从警务实战、便民服务角度，组织精英力量着力研究社会治理数字化，尤其是智慧警务区块链方面的算法、数据、算力，以技术方式创新社会组织运行方式、规则与治理体系、逻辑; 通过研制开发绿色、屏 蔽 有 害 信息的社会治理区块链技术应用，为 社 会 信 用 信息形成、共享、使用提供更为有效的渠道，以警务区块链技术为进一步完善信用社会提供技术支撑。

  

在社会治理领域，治理数据的安全性成为长期困扰各方的严重问题，而利用区块链技术的链式区块结构来存储、验证数据，辅之以自动化脚本代码构造的 “智能合约”编程、操作，可有效解决这一问题，其在社会治理领域塑造的创新性分布式架构基础与信息计算范式之特质，被认为是突破智能数字时代社会治理之网络安全问题的“杀手锏”，为社会治理智慧化全场景深度拓展带来新的可能。法律规则内容的可视化、执行的精准化一直是影响其实施效果、规制能力的重要因素，区块链技术的智能合约等为规则嵌入技术并推动共享、自治提供了可能，如将法律规则和政策要求的 “可操作性”“可复现性”内容编入智能合约并在一定场景触发下自动执行，而现有的主体则扮演着一种纠偏、矫治的角色，在执法和社会管理等领域，区块链技术引领工作方式、策略、机制的变革，大大提升 了 效 率［16］。当 前，DQB、流动人口、重点行业等警务信息化应用系统往往基于中心化的数据库框架，存在信息重复录入、数据库际间接口复杂、录入终端与人员素质局限等困境，在数据标准统一、应用系统间数据快速共享、数据库运维及安全投入等方面存在完善空间。根据笔者调研，“湖北公安政务服务平台”与公安云、荆门市公安局基于人脸识别和情报信息导侦的联 合 作 战 平 台、以警企合作驱动及打造“精准警务”为锚头的杭州城市大脑警务操作系统、各地公 安 机 关 以 “枫 桥 式 派 出 所” 创 建 与“互联网+大数据”为契机相结合的智慧警务建设探索以及公安部推动的经侦 “亮剑” “清网” “猎 狐”系列专项行动，等等，信息技术推动警务模式转型及警务改革创新试点探索样本愈演愈烈，在区块链技术及其与 AI 深度学习、5G、大数据等技术群结合下将催生更多警务应用场景。

  

在构造社会治理区块链系统时，必须从优化技术机制设计和完善制度法规上保证社会治理的安全、有序，严防有害信息利用区块链系统进行传播，营造健康和谐的社会治理网络空间环境。网络有害信息监管、筛查，基于区块链的涉众型经济犯罪侦查取证，利用区块链技术进行的计算机信息网络安全犯罪等，为当前警务工作带来新的挑战。在区块链获得广泛应用的过程中，有必要在保持其 “自治”优势的前提下，通过完善相关技术标准与法律政策规制路径等措施，将其融入现实世界之监管体系，保障其良性健康发展。

  

应强化数据挖掘、区块链密钥、区块链侦查取证相关工作，在现有 “一标三实”基础上完善社会治安综合治理方面的基础信息采集准确性、识别精确性、共享实时性，构建有害信息写入区块链传播的过滤机制［17］。在社区警务和警务服务中，推动建立溯源体系、区块链数字资产，利用区块链之共识机制、不可篡改属性防止有害信息写入区块链，从源头把控信息质量，为社区群众提供高品质的社会服务，有效解决社会信任缺失问题。此外，推动警务区块链嵌入智慧城市大脑建设，打造智能数字时代下的生产生活方式 “新体验”，例如，利用区块链技术服务智慧城市大脑在交通管理、事故快处方面的应用，强化严格、规范、科学、文明、公正执法，提高政府公共产品供给效率与公众的制度体验，其模型如下页图 1及图 2 所示。

（二) 立足警务实战需求、发展，推动区块链相关政策法律法规体系完善

随着区块链技术在社会治理领域的深度应用，亟须加快完善针对区块链技术的专门性制度法规体系。一方面，根据传统物权法理论，由于基于区块链的数据、信息、虚拟财产目前尚无法进行有效、精准确权、登记，当前和未来警情中将不可避免地遇到涉及区块链技术权益争议的个案，公安部门亟须从警务一线接处警与纠纷调处角度，通过试点办法、立法建议等总结实践经验，推动相关专门法律法规完善，对区块链价值网络上的权属问题予以确权; 另一方面，公安机关作为社会管理和刑事诉讼的重要主体，承担了保护人民生命财产安全、打击违法犯罪活动的核心职能，区块链技术的发展对警务工作提出了保护财产、侦查取证等新课题，公安机关应联合相关部门探索完善明确有效的社会治安区块链监管机制，有效应对区块链技术中的安全问题，保护区块链参与者的合法权益，为推动技术发展保驾护航，体现责任担当。需要结合新技术的发展，在现有的《网络安全法》《互联网信息服务管理办法》《信息安全等级保护管理办法》《信息网络传播权保护条例》《国家安全法》 《电子签名法》 《全国人民代表大会常务委员会关于加强网络信息保护的决定》等规定基础上，借鉴国外关于区块链技术规制的立法例经验，如美国在 1996 年的 《Communications Decency Act》法案中针对科技界的 “安全港”法律制度 ( safe harbor) ，在技术执法创新方面借鉴英国主要金融监管机构———金融市场行为监管局( FCA) 的 “金融技术沙箱计划” ( Fintech Sandbox program) ，在遵循程序法治等原则对新技术合理规制的前提下，允许企业尝试新的服务，使法律制度符合技术现实并建构互动张力［18］。针对以数字编码形式体现的智能合约呈现的合同文本确认及司法证据采信规则、网络空间安全治理等问题，从警务工作实际提出区块链财产保护机制、个人信息安全保护、证据属性及证明规则等问题的完善策略，如探索开发 “区块链+身份管理”，推动社会管理与服务、执法办案、指挥调度模式变革，将公民生物信息、信用和财产记录、行为轨迹、兴趣偏好、职业和教育等隐私信息与身份区块链相关联，并根据区块链授权、密钥进行有选择披露。在个人具体认证场景中，仅披露经区块链智能合约检验、处理的个人信息与行为记录而非直接将信息本体发送给对方，也即通过身份区块链实现个人信息的 “全域公开+快速认证获取+高速流转+隐私内容保密”，在不披露关联信息具体细节的前提下仅出示和生成证明主体在个性化场景下具有某种信息特质的 “数据”，推动信息特征、特质的多维深度运用，以方便快捷的网上身份认证将有限的基层警力从繁杂的常规社会管理事务中解放出来，并将其用在警务策略谋划、社区警务精细化服务质效提升、执法办案机制完善、面向实战化的警事科学研究、联动快速反应与服务中心和大局、防暴处突等 “刀刃”上，大幅度推动智慧警务大脑建设及信息科技驱动下的警力下沉和民警个体的凝心聚力。其部分应用场景如图 3所示。

区块链技术将塑造 “服务—治理”的新型治理模式，“公众通过服务自身有序、充分参与治理过程，从而创新政府运行方式。”［19］。在社会治理区块链系统中，公众可建立、修改、完善存储个人基本信息、相关数据的各自加密账本，并通过公钥、密钥等方式有选择地与代理机构分享该信息，或在具体参与社会治理、享受公共服务产品供给服务中向政府机构授权阅读或更改某些账本中的内容。如此一来，智能数字时代，未来社区中的居民将从被动、等待服务转为服务的积极参与者、提供者。公安机关作为承担政府社会管理和服务职能的重要部门，在深入推进放、管、服改革，优化营商环境背景下承担重要角色，在智能数字时代，区块链技术的嵌入将进一步提升警务工作效率、增加公共服务供给。社区警务模式、巡逻防控模式、便民警务服务等，将随着区块链技术的链接产生新的工作机制，如社区居民信息的精准识别、动态管控，社区居民有序参与联防联治，利用区块链技术搭建智能化、实时化、一体化警务便民服务场景，通过区块链+警务的深度融入，将使警务工作不断精准、靠前、主动、实 时，将不断提升警务工作效能，推进基层警务工作打、防、管、控、服一体化。

  

区块链技术对整个政府社会治理各职能部门提出了新的挑战，公安部门需与其他部门通过明确各监管部门的责任划分、规范监管模式等方式加强区块链技术的监管; 将区块链技术手段纳入相关领域监管体系，充分考虑区块链技术对现有监管运行机制的深远影响，通过强化新技术学习和技术规制路径有效嵌入，积极推动、参与区块链政策和规则的前期制定，完善社会治安综合治理领域区块链相关自治政策和现行法律框架的双向衔接，为其他领域区块链自治、监管等提供规制经验，确保随着技术发展与深度应用其在后期监管问题上的精确性、有效性［20］。公安部门应推动和固化技术提供者、司法者、监管者、执法者之间的互动磋商、联席会商、共建共治机制［21］，需与其他政府监管部门以及大型网络服务提供平台等，在明确、明晰部门权责的基础上加强协作、协调、衔接、对话，推动完善相关网络信息技术治理共识、治理伦理，在各自权责范围内对有害信息传播进行有效治理和监管，塑造自治、法治、技术、伦理多元化有效规制聚类集成，避免在监管和治理中出现矛盾。

  

( 三) 把握犯罪形势发展，加快组建、整合打处区块链违法犯罪活动专门力量

当前，我国正通过 “走出去”战略积极推动“一带一路”倡议等全球治理、区域共享发展和打造人类命运共同体，我国的海外利益在高风险地区屡次遭受侵犯等客观环境和现实状况加剧了我国海外利益保护的紧迫性。新时代网络治理的全球合作与国际纷争将更为激烈，区块链技术的发展对跨境合作执法、警务技术研究、全球警务合作与对话等提出了新的挑战，需以总体国家安全观为指导，防范误区，抓好统筹，以依法依 规、跨境合作、公私协作、综合施策等强化公安机关内部的优势力量聚类集成［22］。基于区块链技术的虚拟货币 长 期 以 来 都 是 我 国 监 管 的 重 点，早 在2013 年，人民银行、工信部、原证监会、原保监会及原银监会便联合发布了警示比特币有关风险的通知，明确声明虚拟货币由于未经法定机构发行而不具有与货币等同的法律地位，禁止其作为货币在市场上流通使用，禁止金融机构以其为服务或商品计价、买卖比特币或向客户提供比特币相关服务。2017 年 9 月，中央七部门联合发布通知，在中国境内取缔 ICO，禁止虚拟货币交易平台将虚拟货币与法定货币直接相互转换，将 ICO 明确规定为非法集资活动。随着 ICO 被取缔，许多虚拟货币交易将 ICO 业务移至中国境外或以更为隐秘的方式进行相关活动，利用网络关键词行骗、利用相关政策和个人信息诈骗等 “量体裁衣”式精准诈骗成为电信诈骗的主要形式，涉案金额巨大，手段日益复杂［23］，而区块链技术极有可能为其提供新的犯罪土壤。公安部门需从非法集资、非法发行货币、非法发行证券、金融诈骗及传销、计算机信息网络犯罪等多角度组织区块链技术的侦查办案力量，完善利用区块链技术的新型违法犯罪活动联动打处机制，尤其是利用区块链技术进行的涉众型经济犯罪的预警识别、情报挖掘。例如，在网络安全与执法方面，当前主要基于权威第三方机构架构的网络信任，在电子认证服务中成本大、效率低。在 “区块链+智能警务”模式下，则可通过完善与区块链相适应的政策法规体系，整合电子金融与商务、电子政务、信息执法等区块链技术行业与应用部门力量，构建电子认证服务产业联盟链，进一步强化、规范电子签名的司法效力。同时，依托信息技术发展趋势，推动现有居民身份证管理制度变革，开发基于区块链的数字化身份证并将其中的身份区块链设为公共链，保证链内个人信息不可见但全网公开，公安部门和其他服务部门通过专属的个性密钥定制，辅之以云计算、量子计算等手段，通过共识机制设定、智能合约实现信息动态实时监测、无障碍全网检索目标数据，以 “可靠”的大数据为个案侦查、重点人员管控、治安案件分析、犯罪预防等提供可靠依据。在完善大数据和互联网信息相关法律制度及公民隐私合理期待、证据证明规则等对大数据风险有效规制的前提下，可将基于区块链的相关信息取证直接作为案件事实认定的可采证据，让电子数据 “说话”和 “作证”，进一步提高司法效率，节约司法成本，捍卫司法公信，强化司法责任，用区块链技术为警务执法与司法赋能［24］，真正为一线执法办案人员 “减负”。

  

大数据侦查通过计算机技术对存储于网络与计算机系统中的海量数据予以收集、清洗、共享、挖掘和对比，在犯罪预防预测和犯罪侦破领域得到广泛应用，为发现犯罪线索、证据信息和犯罪嫌疑人提供手段支撑，但存在对一些基本权利、法律价值的挑战，并对保障数据安全、数据质量提出了新的难题［25］。区块链技术像人工智能技术、大数据技术一样，给警务工作带来巨大变革，在区块链相关应用工作中，不断发现并填补漏洞使得利用区块链规避法律义务的使用者无机可乘，如何固定关键证据、抓住罪魁祸首，对当前警务工作提出了新挑战。区块链中的智能合约效力尚未得到法律和司法正式确认，在实际监管和侦查工作中，以沟通区块链网络和现实世界的人为监管对象更为方便高效，但中介机构将随着无许可区块链提供的服务不断丰富而逐渐淡化角色，在实际的执法活动中将面临执法对象缺失的新的挑战。警务工作需组织专门队伍，完善信息技术化新型工作机制，强化监管科技，以应对新技术带来的社会治理隐忧，如通过完善 “个人身份信息+交通管理”集成区块链，要求从车辆生产销售伊始便强制为每辆车创建区块并将其与各部门行业物联网、交通运输联盟链关联，从而实现将车辆行车轨迹、流转与维保记录、违章信息等实时关联到本车辆区块链之中，实现与产权主体身份信息区块链同步写入、提取。在具体警情个案中，将犯罪嫌疑人的人脸、体态和行为、通信、网购记录、话单等主体多维特征信息，或作案车辆颜色、活动轨迹等信息输入，并以预设共识机制触发智能合约，自动进行数据挖掘清洗、碰撞分析、案件线索检索，根据车辆区块链锁定与案件相关的全部电子证据，会对当前点对点分散式、耗费大量时间物力且极易忽略关键信息的传统视频侦查模式带来颠覆性转变。

  

( 四) 发动全警参与区块链社会宣传，强化全警区块链规范意识塑造

区块链技术对当前技术体系、法律体系带来挑战的同时，也为激发社会创新、社会活力带来了新的突破口。区块链不仅是一种技术本体，还在未来数据治理中与法律政策存在融合、弥补趋势，链上治理、链上互动、链上风险防控等需要全警增强区块链规范意识，并通过日常警务和行政服务促进社会凝聚共识，寻求 “安全、秩序” 与 “发展、创新”价值之间的平衡［26］。紧盯新技术创新与执法工作理念变革，通过网络教育培训、警务微课程、专题讲座、跨区域与行业交流等形式，提升民警对区块链技术的观念认知、技术应用、风险防控能力，将区块链技术渗透到日常警务活动中，推动民警在自学互学的同时，积极参与宣传引导，通过网上网下多种途径，以案说法等形式加强民众对于安全使用区块链技术的知识宣传，提升民众知识产权意识和对区块链风险、相关违法犯罪活动的认识。在执法办案中，应重视民众的合理隐私期待及个人信息相关合法权益保护，鼓励民众自我规范、相互监督，发挥民众在区块链自治中的主体作用，通过增强使用者传播信息的规范意识、网络空间伦理约束，从源头上杜绝有害信息经由区块链恶意传播。

  

此外，在警务工作中还应注意到，通过区块链深度应用，可建立和保持网络参与者之间的社区合作，对法律和技术代码的交互关系加以利用，通过其优化配置组合实现有效监管，以算法规则来解决法律程序的效率、成本问题，补充法律规制的不足，利用法律和区块链技术之间的优势，拓展虚拟空间的实体化治理、有序参与，在实际警务场景中搭建多方参与、共治共享的多元化协同治理平台，创新基层社区警务工作模式和警务服务方式，以公众有序参与、监督建议推动警务公开，优化行政服务，提高警务工作质效。

  

总之，区块链技术不可篡改、可追溯性、可信任性等特点使其在智能数字时代存储和处理相关信息方面得到深度应用，当警务信息等政务信息被分布式存储于各节点后，各部门维护一个取得一致性共识的不可篡改、泄露的分布式加密账本，可最大限度地防范黑客攻击、信息失真，为警务工作高效、精准精细运行提供支撑。与此同时，区块链技术在公民信息场景中的应用，可有效破解自我证明方面的 “忒休斯之船”困境。然 而，区块链技术，其将人与事件之间的归属、排序方式在智能数字时代予以新的组合［27］，自身是一把机遇与挑战并存的双刃剑。在警务工作中的嵌入，还需回归技术本身，进一步了解技术本身及其背景，从而转变思维方式，弥合区块链自身规则与社会规则、法律规则、道德伦理间的冲突，正视区块链技术隐含的风险，强化合规性审查判断，推动治理方式和治理逻辑创新，充分利用其去中心化、创新性、颠覆性力量为警务工作赋能。
