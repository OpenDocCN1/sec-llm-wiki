# 郭声琨：强化“大数据治理”理念 提升智慧治理水平

       中共中央政治局委员、中央政法委书记郭声琨28日在第五次新时代政法工作创新交流会上强调，要坚定不移走中国特色社会主义社会治理之路，善于把制度优势转化为治理效能，总结推广疫情防控中的成功经验，加快推进基层社会治理现代化。  
![](../Images/2b3a44e8816f7030fb2dc78a60b311ce.png)  
　　       郭声琨指出，我国疫情防控取得的成效，再次彰显了中国共产党领导和中国特色社会主义制度的显著优势。要充分发挥党总揽全局、协调各方的作用，强化“党建引领”理念，打造基层社会治理共同体。要强化政治引领，引领广大基层干部群众深入学习习近平新时代中国特色社会主义思想，坚定不移走中国特色社会主义社会治理之路，确保基层社会治理始终保持正确方向。要强化组织引领，总结推广把党支部建在网格上、党小组设在楼栋里的做法，把党的建设延伸到社会最小单元，激活社会治理体系的基层细胞。要强化机制引领，创新基层党建与社会治理深度融合的体制机制，完善以基层党组织为枢纽、各类组织力量有机耦合的组织体系。　　郭声琨强调，要强化“全周期管理”理念，塑造基层社会治理新格局。要加强全程治理，把社会治理各环节作为完整链条，完善事前事中事后全程治理机制，实现全过程、全要素、全场景的动态治理、系统治理。要加强协同治理，横向上推动各主体、各部门信息互通、资源共享、工作联动，纵向上解决好层级过多、贯通不畅的问题，构建各个治理主体权责清晰、系统有序、协同配合、运转高效的治理机制。要加强源头治理，注重“治未病”，提升对各类风险预警防范、源头化解的能力。　　郭声琨要求，要强化“平战结合”理念，释放基层社会治理新效能。要立足平时强基础，把更多资源、管理和服务下沉到基层，推进基层社会治理和服务标准化建设，真正做到各项任务可操作、可量化、可评价。要着眼战时补短板，坚持实战实效标准，加强日常培训、实战演练，完善战时状态组织动员、快速响应、激励保障等机制，不断提升基层干部群众专业素养和应对突发事件的实战水平。　　郭声琨强调，要强化“大数据治理”理念，在确保个人信息安全的前提下，推动基层治理质量变革、效率变革，提升智慧决策、智慧治理、智慧服务水平。要充分发挥线上平台优势，打造“指尖生活圈”，为人民群众提供个性化、多样化服务。　　会上，12个地市党委政法委分别作了交流发言和书面交流，从不同侧面展示了疫情防控中加强和创新基层社会治理的经验做法。　　中央政法委秘书长陈一新主持交流会，副秘书长景汉朝、王洪祥、雷东生出席。会议以视频会议形式开到地市级，全国省市两级党委政法委机关干部在各地分会场参会。
