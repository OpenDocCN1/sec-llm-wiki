# 物联网和预测软件如何图像识别捕获犯罪分子

这是PASSAnT项目创造的三项新创新之一，这是由比利时倡议Interreg在荷兰和比利时港口处理犯罪。随着越来越多的非法移民试图前往英国，在荷兰 - 比利时边境附近的港口，人口走私活动急剧增加。荷兰城市Moerdijk，已被一些人称为“新加来”，特别是与偷渡者的斗争。荷兰警方在2015年抓获了500人，而2016年这一数字增加了一倍多，达到1280人。今年的统计数据尚未公布，但据Leon Verver称，这一数字仍在增长。Verver是荷兰技术代表，安全和安保研究所（DITSS）的警察兼主任。

显然这些人其中大部分是阿尔巴尼亚人，仍然相信英国是他们最好的选择。所以他们等到夜幕降临，才能爬到港口附近停放的卡车上。“这不仅仅是非法运输移民问题; 荷兰和比利时港口也涉及走私和爆炸物以及盗窃货物。

![](../Images/594f347fc341ae8a5522c67163f4792b.png)

图片来自网络

创建智能围栏，PASSAnT在利用新技术解决这些罪行。除了防入侵外，交互式围栏和智能相机软件也在不断发展。到明年年底，飞行员开始启动并运行。围栏包含类似于麦克风的传感器; 他们不只是检测振动，还要分析它们。因此，当有人不小心碰到围栏时，系统将不会通知警报控制室。但是当这种情况连续发生三次时，这其中包括天气条件等复杂情况外，传感器会分析暴风雨天和攀登栅栏的人之间的区别。虽然攀爬栅栏是非常明显的犯罪指标，但其他行为更难以识别。这就是图像分析软件的用武之地。

假设你沿着围栏行走并停下几次。或者如果你在遛狗，这种行为会被系统视为正常行为。另一方面，如果你独自携带一个大背包，那就会列入可疑对象。图像分析软件基于一种算法，该算法能够理解这些行为（如停止几次）和视觉线索（如携带背包）。把它想象成一个点系统：每个可疑元素都能获得一分。达到某个阈值时，系统将通知报告其安全警告。当发生这种情况时，他们会通过音频系统向这个人提问，或者派人员去巡察。

算法寻找什么？Verver可以列举一些“可疑”元素，但不知道整个列表。他确保我不会将像肤色这样的视觉特征用于分析，这也是非法的。但如前所述，特定类型的衣服确实可以作为标记。荷兰政府在数据科学方面投入大量资金来预测犯罪。一些城市利用CAS（刑事预期系统），这是一种“热图”系统，可根据以前的犯罪和人口统计数据识别犯罪热点。与此同时，警方正在运行大数据飞行员，以减少在埃因霍温的夜生活暴力时间，遏制鹿特丹的入室盗窃，并在鲁尔蒙德捕捉扒手。

![](../Images/064182b5004762cfac5ace45459ea6fe.png)

图片来自网络

最后一个名为“传感”的项目使用类似的智能相机软件，但却寻找不同的“可疑”方面，主要针对东欧罪犯。靠近荷兰 - 德国边境的鲁尔蒙德市与来自该地区的盗贼团伙进行斗争。

该系统结合了无线电跟踪（例如，检测罗马尼亚电话号码），车牌分析和行为图像分析（有人徘徊在街角）以向该地区的警察提供通知。在这种情况下，警察可以询问他们的身份证并检查他们的行李。当然，如果这群人成了一群罗马尼亚游客，享受一天的购物，那么谈话将会很短暂。但是，有人因为碰巧是东欧而更有可能被标记的事实引起了人们的注意。Verver了解这些担忧，但补充说，不仅仅是罗马尼亚电话号码或车牌引发了系统锁定，还有很多不同的信号。因此，无辜者无意中被系统选定的可能性相当小。

![](../Images/1d189e0c3cf2dc9a32c24552b029fda2.png)

图片来自网络

在解决隐私问题时依然是很严肃的话题，现在衡量预测性监管的有效性还为时尚早。在荷兰以外的许多国家，陪审团仍然不清楚它是否有效。在美国，探索预测性监管软件的主要提供者之一“PredPol”的研究显示了不同的结果。即使预测性警务被证明是有效的，像Verver这样的技术乐观主义者仍然需要征服大众的心灵和思想。

一个荷兰的研究探索警官体验使用预测软件CAS显示响应的感想。他表示，该软件没有告诉他们任何他们不知道的事情并且主要关注CAS领域是浪费资源。公平地说，其中一些问题可能会通过更多的教育来解决。其中一位受访官员提到他们根本不相信预测犯罪是可能的而没有提供任何有效的论据。荷兰政府最近宣布计划每年额外花费6400万欧元用于警察的大数据培训，因此将来他们可能会更好地了解数据分析的预期结果。

![](../Images/24da343598ba43fbb3d4bcd87a2413e8.png)

图片来自网络

Verver讲到，我们要给这些官员一些时间来适应这个新的现实。现在，警务将变得越来越以技术为基础，而不是每个人都为变革做好准备。但是，一旦我们能够向他们展示这将使他们的工作更轻松，街道变得更加安全，我很肯定他们会来欣然接受。现在，犯罪已成为数字化，荷兰警方比以往任何时候都更需要技术人才。查看他们提供的各种技术工作。
