# 长垣市公安局情指快反处置中心正式运行

“开赴执勤!”5月30日上午，随着长垣市公安局党委副书记、政委胡亚坤的一声命令，整装待发的60余名民辅警出发上岗，标志着长垣市公安局情指快反处置中心全面投入运行。  

![](../Images/d6b2d70078e7b9acb9fc0ea54897f7b1.png)

![](../Images/479876648043b3de0f4b463fffebede4.png)

![](../Images/9b18b783a52896eab469f856f6ef8638.png)

情指快反处置中心的组建是公安机关面临新形势、新任务的客观需要，也是长垣市局警务机制改革的有益探索，在长垣市委、政府的正确领导下，今年3月份，我市公安局在新乡市8县（市）中率先成立了情指快反处置中心，中心下设1个综合室、1个情报研判中心、1个指挥中心、3个快反处置组。其警种人员涉及特巡警大队、派出所等民辅警共计103名，对主城区设3个防控区。

![](../Images/b1a582e022d57cfe85274af40196127b.png)

情指快反处置中心根据长垣市城区的人口密度、重点部位、场所位置和发案特点，在主城区划定巡逻防控区域，科学设定待警点，打通情报、指挥、行动之间的壁垒，最大限度地缩短了接处警时间，实现了“情、指、行”一体化运作，为更有力地打击违法犯罪、做好治安防控奠定了坚实的基础。  

![](../Images/59ca7757ebf8d2371461409441400a2b.png)

![](../Images/3a0bc8cd6d49d97e30cfbea7d667d654.png)

长垣公安将把中心打造成打击违法犯罪的尖刀劲旅，切实提高公安机关打防管控能力，全力构建立体化、多角度、全方位的安全防范网络，震慑各类违法犯罪活动，为人民群众安全保驾护航。
