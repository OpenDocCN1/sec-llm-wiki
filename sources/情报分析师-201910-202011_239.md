# 犯罪圆周假设理论

曾经有学者运用了圆周假设，将犯罪人分为“守候猎取者”和“流窜袭击者”两类。所谓犯罪圆周，就是一系列杀人案件中地理位置最远的两起案件连接的直线距离为直径，直线重点为圆心，一次形成的圆圈。“守候猎取者”就是那些作案者其居住地和活动区域都在这一圆圈内的犯罪人。相反，“流窜袭击者”通常离开住所到另 一个地方去犯罪。圆周理论假定“守候猎取者”居住在他们的犯罪圆周内，而“流窜袭击者”居住在外面。

 这就是犯罪制图的具体运用，辅助确定目标和方向

# 犯罪制图

是对犯罪活动模式进行地图绘制、可视化并加以分析的过程。

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1340893339843117058](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1340893339843117058)

这个圆除了能对系列案的嫌疑人落脚点的推断起到作用外，对单一案件也能有一定的辅助作用，但在切入角度上有些不同。  

![](../Images/81f82dd3a51131054766764cedbba5ff.png)

已知左上方是嫌疑人挑选的作案地点，圆心是嫌疑人的临时落脚点，整个圆圈就是他的认知空间，什么是认知空间？我们可以简单理解为——你经常活动的、熟悉的范围。但警方在排查后发现嫌疑人早已不住在中心点，且没有正式工作。如果他更换了落脚点很可能还会选在在自己曾经的认知空间内，最后，警方在嫌疑人的第二落脚点附近将他抓捕归案。

其实，任何人包括罪犯，在逃亡中，都会向自己熟悉的地方或是和自己生活习性相似的地方逃跑，尤其是一个人在作案后或是受到追捕时，更渴望安全，在这种心理作用下，就会向着自己熟悉的地方逃跑。犯罪制图的部分模型技术分析手段恰是抓到了这一人性的特点。
