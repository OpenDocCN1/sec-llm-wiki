# 交通大数据告诉你城市不为人知的秘密

随着新能源汽车产业的发展，以及国家层面对其用户实行各项福利补贴和优惠政策，作为“绿色出行”的典型交通工具，新能源汽车越来越受到更多用户的青睐。新能源汽车在交通出行中也扮演着越来越重要的角色。

在“绿色出行”理念和“共享出行”的影响下，以摩拜为首的共享单车也受到了人们的广泛欢迎。除此以外，电动车也是当前比较热门的“绿色出行”方式，但在各一线和新一线城市中，外卖小哥在电动车用户群体中占据了较大的比重。

小编在摩拜、点我达（外卖小哥的电动车轨迹数据）、新能源汽车数据的基础上，选取我国的几个一线城市和新一线城市，对自行车、电动车、新能源汽车这三种交通工具在某一工作日的轨迹特征进行分析。

同时，小编也对这三种交通工具在城市一天中24小时的热度变化进行研究，比较各交通工具在各城市热点时段的差异。另外，小编还以北京为例，选取几个电动车轨迹密集区域，对其进行较深入地探讨。

首先分析的是以北上深为首的一线城市和以西安为代表的新一线城市。通过比较这四个城市，从轨迹覆盖范围的角度可以发现，新能源汽车、电动车、共享单车轨迹所覆盖的范围依次递减。

但从轨迹覆盖深度的角度，新能源汽车、电动车、共享单车的轨迹覆盖深度依次递增。另外，电动车的轨迹还呈现出区域性集中，但各区域之间比较零散的特征，这与外卖送餐多集中在各商业圈、各办公区的现状相符合。

  

![](../Images/e0e88aca96a5bda54271b1aaaf3eb93a.png)

  

通过对这三种交通工具出行热点时段的比较，新能源汽车和共享单车在各个城市的热点时段都呈现出两个早晚高峰。而来自于外卖小哥的电动车的轨迹，热点时段则集中于中午休息和晚上下班时段。

  

![](../Images/ecdd459295c1086c438f5190679197b1.png)

  

与其他城市相比，北京、深圳的新能源汽车热点时段的时间跨度更长，甚至持续到夜间10点以后，并且这两个城市新能源汽车的数量明显多于一同比较的其他城市。另外，成都作为“慢生活”城市的代表，新能源汽车的早上热点时段比其他城市出现的要晚，而晚上热点时段比其他城市结束的要早。

  

![](../Images/9fcc884fe5d7e65e342eb38b44890b63.png)

  

除深圳以外，共享单车在以上几个城市中的热点时段比较一致——朝8晚6。深圳共享单车的早上热点时段比其他城市明显要早1-2小时，而晚上热点时段则是比其他城市开始的要晚1-2小时。

  

![](../Images/72b6c770a7913c9176d4dd566cdec1ce.png)

  

从电动车的热点时段可以发现，相比较而言，北京、深圳、杭州和苏州的轨迹热点时段的时间跨度要长一些。

后面的几张图片是广州和除西安以外的一些新一线城市的新能源汽车轨迹、共享单车轨迹。它们各自的特征与北上深、西安的特征一致。新能源汽车的轨迹多出现在城市干道以及大的城市环线，而共享单车的轨迹则全部出现在城市干道和城市末端的支路，并且支路上的轨迹更多更密集。这更加体现了共享单车主要帮助人们解决“最后1公里”诉求的特征。另外，从图片中也可看出沈阳运行中的新能源汽车的数量较少，这可能与当地的气候有关。

  

![](../Images/8839e40aafa167d4c2f4e6a7e301ff3e.png)

  

![](../Images/0e1c74ece75e674a67983792f2fa3630.png)  

  

最后，我们以北京为例，选取了外卖小哥的五个电动车轨迹最密集的区域——上地、中关村、双井、通州和亦庄，以OD关系图的形式对它们各自区域内的订单情况进行分析（蓝色代表下单顾客，白色代表外卖商家）。

  

![](../Images/c5116f0ae6fb73534bd139d2b08ef3cf.png)

电动车（外卖）轨迹密集区域分布

  

![](../Images/13290b70c18b0400fd16de2ec139693a.png)

通过几个区域之间的比较，我们可以发现，被选取的区域都是北京热门的办公区域，但区域内的订单情况却有较大差异。由于上地、亦庄各是因中关村科技园和经济技术开发区而兴起，公司众多而周边餐饮资源较缺乏，所以这两者都是热门的外卖下单区。相比之下，中关村、双井的办公和餐饮资源配比比较均衡，既是热门的外卖下单区，区域内的餐饮又受到周边地区人们的青睐。而通州由于近几年才逐渐发展，周围居住的人群较多而周围配套的餐饮资源较少，也成为了热门的外卖下单区。
