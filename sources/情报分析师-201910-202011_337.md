# 强化警企合作 助力刑侦应用——以贵州刑侦与本地大数据龙头企业合作为例

根据公安部赵克志部长提出的公安工作“改革强警和实施大数据战略”两大战略任务，切实 把握好警务大数据要服务基层、服务实战、服务 一线“三个服务”原则，贵州省公安厅刑侦总队 在充分借鉴广东深圳、浙江杭州两地创建警企合 作实验室，整合本地资源手段，提升打击新型非接触性犯罪能力和水平的先进做法基础上，以贵 州省大数据发展战略为契机，有效整合省内大数 据龙头企业的海量资源及先进科学技术，全面向互联网进军，加强对依托互联网的刑事犯罪调查研究，通过打击新型非接触性犯罪，探索一条互联网条件下打击刑事犯罪的新路径。

  

  

1

  

  

![](../Images/73ebcdad8841fcf44639f95946822ac3.png)

立足战略高地，集聚发展要素 

![](../Images/a69d0414960d75b2d1e35a856f9cca1f.png)

贵州在新时代提出了深入实施大数据战略行 动的“144”总体思路。“一个坚定不移”推进大 数据战略行动向纵深发展。将大数据战略行动作为高速增长阶段向高质量发展阶段转变的重要抓 手，推动大数据发展跃上新台阶，在新时代实现 新的更大作为。“四个强化”集聚发展要素。强化 对现有大数据企业的支持力度、强化对大数据企 业的招商力度、强化对与大数据融合的高科技领 域企业的招商力度、强化对大数据等高科技领域 人才的引进力度，着力集聚大数据发展的各类资 源要素，通过量的增加引起质的飞跃。“四个加快 融合”推进高质量发展。把融合作为大数据的价 值所在，坚持以问题为导向，加快大数据与实体经济的融合，加快大数据与乡村振兴的融合，加快大数据与服务民生的融合，加快大数据与社 会治理的融合，推动实体经济转型升级，推进 农村产业革命，提高人民群众生活质量，提高政府治理能力和水平。深入实施数字经济、数 字治理、数字民生、数字设施、数字安全五大 攻坚战，加快推进数字产业化、产业数字化， 加快建设“数字贵州”，持续推动大数据融合发 展取得新成效。

  

  

  

  

2

  

  

![](../Images/73ebcdad8841fcf44639f95946822ac3.png)

深度对接研究，找准融合方向

![](../Images/a69d0414960d75b2d1e35a856f9cca1f.png)

从2017年开始，贵州省公安厅刑侦总队就主 动对接贵州省大数据龙头企业，结合刑侦信息 化、数据资源整合、数据标准规范、大数据建设 应用相关工作实际，采取现场参观考察、座谈交流、系统演示介绍等多种形式开展对接，达成了 初步共识，并决定集中一段时间开展细致、全面 的业务梳理和交流，准确把握双方的合作点和契合点。2018年3月，刑侦总队从贵阳、遵义、铜仁、黔东南、黔南5个市、州刑侦支队、刑侦大 队、派出所抽调了27名刑侦一线的业务骨干和专 家能手分期、分批、分领域与企业开展对接交 流。双方从公安机关打击刑事犯罪和社会治安综 合治理方面的应用场景和业务需求出发，就如何有效支撑打击防范工作，以实现业务与技术有效融合为总体方向，以解决工作中的痛点、难点、 盲点问题为目标进行广泛交流，对信息化顶层设 计、业务平台开发、数据标准统一、应用解决方 案、技术目标实现、资源整合应用六大层次进行 深入研究，围绕人、案、物、线索、要素五个方 面开展专题讨论，梳理出案件打击防范、网络虚 拟身份查证、虚拟行为检测分析、网络贩枪及钓 鱼木马线索发现、广电网络数据资源利用、阵地 控制支撑、公开社交群组监测、情报分析研判模 型开发、犯罪产业链条打击等需求。

  

  

  

  

  

3

  

  

![](../Images/73ebcdad8841fcf44639f95946822ac3.png)

发挥企业优势，提升应用能力

![](../Images/a69d0414960d75b2d1e35a856f9cca1f.png)

通过对接交流，双方认为贵州省本地大数据 龙头企业作为国企，具备移动内容云计算、自主 研发的分布式网络爬虫等可移植核心技术，其技 术路线的底层架构和实现方式与公安大数据发展方 向、技术路线基本一致，经过针对性的开发，可以 复制到公安业务应用中投入使用。同时，其特有的 能力开放框架模式能够快速整合当前互联网和大数 据领域内相关企业和公司资源、产品、技术为警务 工作所用，从而助力提升以下四个方面的能力。

  

发挥企业创新潜能，助力提升公安机关应对 不断变化的侦查办案应用需求的能力

当前，信息化建设流程较长，一般需要经过 层层提交、审批、决策、落实，从提出需求到应 用系统建成投入使用、产生实战效应通常都在一 年以上。随着科技手段的飞速发展，互联网内容、 形态的爆发式增长，犯罪类型及手法也在不断翻 新，变化速度远超传统信息化应用开发流程。公安 信息化建设发展速度大大滞后于犯罪手段翻新速 度，不断变化的侦查办案应用需求与依旧缓慢的信 息化建设流程之间有诸多不适应，存在打击犯罪的 能力手段追不上犯罪的发展变化的客观情况。我们 要迅速适应不断变化的需要，推进思维方式的转 变，创新改变信息化建设实现流程，才能从根本上解决当前的问题。与企业的合作可以充分发挥其 “快速响应实战需求、合理预判潜在需求、充分挖掘 隐藏需求”的能力，由被动追赶的现状转变为主动 适应、快速响应、主动出击、以快制快的新格局。

  

依托企业技术优势，助力提升公安机关信息 化建设应用的能力

当前正处在网络化、信息化变化迅猛，技术 迭代飞速发展的时代，要应对犯罪手段的快速发 展更迭，公安机关在信息化建设应用过程中需要 投入大量从事业务梳理、系统建设、软件开发、 数据库管理、大数据应用等方面的专业技术人 才、专家团队和技术储备，有效依托互联网公司 和大数据企业的力量，借助其特有的能力开放框 架模式，先行投入资金、技术、硬件、数据等资 源，针对公安机关提出业务需求，广泛引入先进大数据技术、成熟产品及资源，定制有针对性、 指向性、实战性、可操作性应用服务，实现无缝 衔接，最大化发挥集约优势，全面支撑公安信息化建设应用工作，为侦查破案提供有力的服务。

  

利用大数据技术的多样性和高速度，助力提 升公安机关信息广度和深度应用的能力

贵州省公安机关在长期的信息化建设应用过 程中已经积累了海量数据资源，具备一定大数据 处理、分析、应用能力。企业能够整合全省部分 用户信息及相关数据资源，丰富公安机关信息收 集手段，完善数据的多样性，促进不同行业间数 据的有效融合，双方合作还能盘活和挖掘广电系 统的数据“金矿”，在数据碰撞与关联中产生更大 的价值。另外，企业还可以依托自身资金使用的 灵活性和技术方面优势，为公安机关提供大数据 快速运算处理所需的软、硬件资源。

  

引入企业专业手段，助力提升公安机关网上 发现犯罪线索和预防犯罪的能力

目前，企业已基于自身版权云项目开发了全 网数据爬取功能模块，结合移动计算、人工智 能、视频指纹快速比对等先进技术实现了对指定 音频、视频、图像、文字数据内容在公共互联网 范围的海量爬取。该功能模块可结合公安机关具体 业务需求进行定制化开发，对符合案件侦查需求的 定向数据进行收集、清洗、筛选、分析。同时，帮 助公安机关将信息收集触角延伸向“深网”“暗网” 领域，全面提升公安机关互联网领域犯罪线索发现 及犯罪预防能力，最大化地延伸感知犯罪的触角。

![](../Images/73ebcdad8841fcf44639f95946822ac3.png)

明确发展路径，创新工作模式

![](../Images/a69d0414960d75b2d1e35a856f9cca1f.png)

建立全省防范打击非接触性犯罪警企合作平台

鉴于大数据条件下公安机关业务应用和能力 建设的需求，结合企业可以提供的支撑和服务能 力，由刑侦总队牵头，全面构建贵州省警企合作 战略，在贵州省公安厅信息化顶层设计的总体框 架下，以省厅“三合一”中心建设为载体，挂牌 成立全省防范打击非接触性犯罪警企合作平台， 逐步健全合作机制，制定目标任务，明确近、 中、远期规划，搭建非接触性犯罪全网监测中 心，开发服务于侦查实战的系统、工具、组件、 模型，为公安机关打击非接触性犯罪提供有效支 撑和服务，实现大数据的“聚、通、用”。同时， 面对公安机关内部合成作战已无法适应打击非接 触性网络新型违法犯罪需要的现状，构建与新时 期打击犯罪相适应的大数据背景下新型警务（侦 查）形态的总体工作思路，在原有反诈骗中心建

设基础上，提档升级建立贵州省公安厅打击刑事犯 罪大数据侦查中心，积极整合公安机关、工信部门、金融机构、互联网企业等优势资源，着力打造 集多部门专业人员、信息数据、技术手段一体的打 击整个非接触性网络新型犯罪的情报指挥合成作战平台，全面服务基层、服务实战、服务一线。

  

构建实现“政产学研”结合的工作模式

深入对接国家计算机网络应急技术处理协调 中心贵州分中心，在前期省厅与分中心在前期开 展“电信诈骗预警拦截系统”的良好合作基础上，深度开展相关平台建设运营工作。积极对接 贵州大学公共大数据重点实验室，引入其平台技术研发团队，增强合作科研力量。通过与国家计 算机网络应急技术处理协调中心贵州分中心和贵 州大学公共大数据重点实验室的全面对接，力争 形成四家单位战略合作伙伴关系，逐步构建“政 产学研”结合的工作模式。

  

加快推动具体项目落地“先行先试”

从实战应用的角度出发，采取互派人员进驻，联合开发的方式开展深度合作，进一步研发 运用大数据侦查手段，边建边用、以用促建、以 战促建，从而增强网络预警拦截，提高公安机关 对重大非接触性犯罪、涉众型经济犯罪、网络传销、网络贩枪等案件的防范打击能力。同时，加 强阵地控制能力，强化情报分析研判水平，逐步将 合作延伸至打击毒品犯罪、反恐怖活动、重点人员 动态管控、扫黄打非、网络赌博等涉及经侦、禁毒、反恐、情报、治安等警种、部门，切实提升公 安机关预防打击非接触性犯罪的能力和水平。

  

建立警企合作培养警务大数据人才储备计划

探索企业与贵州省刑侦部门、公安院校建立 常态化的大数据人才教育培训机制，提供大数据实 战应用、培训、实习的工作场地和环境，将刑侦部门的实战经验、公安院校的人力教育资源与企业场地、硬件和技术能力进行深度融合，开展实战教育培训、重点课题研究、业务应用拓展等方面的合作。
