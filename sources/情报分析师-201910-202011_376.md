# 公安大数据的 “三种形态”

摘要：2019年是公安大数据建设的深入推进之年。公安部部长赵克志明确提出，要坚持“边规划、 边建设、边应用”原则，围绕突出问题，狠抓建 设应用，全面提升服务实战能力，为新中国成立 70周年大庆安保工作提供有力支撑。“大数据”一 词起源于IT领域，指无法在一定时间范围内用常 规软件工具进行捕捉、管理和处理的数据集合， 是需要新处理模式才能具有更强的决策力、洞察 发现力和流程优化能力的海量、高增长率和多样 化的信息资产。由此判断，所谓大数据绝不是简单 的数据堆砌，更需要汇集、应用、挖掘三个阶段。  

  

**三种形态**

![](../Images/8ed3c2a7556f10dbb7507fea60b59446.png)

**图1 公安大数据三个发展阶段**

  

**数据汇集阶段，“看山是山，看水是水”**

近年来，全国公安大数据应用得到“跨越 式”发展，公安信息化应用平台也出现“井喷 式”增长。所谓“看山是山，看水是水”指的就 是在数据汇集阶段，单纯地将数以亿计的信息看 为单一数据而不是资源，过分强调数据整合共享， 最大限度扩充容量、种类，缺乏对数据的鉴别力， 无法提升其真实性和可变性，忽略了数据池本身的 复杂性和价值。简而言之，在这个时期，对于大多 数基层一线民警来说，公安大数据更多是一种综合 应用平台和媒介，主要作用是查找信息的“便利” 和“快捷” ，缺乏明确的指导性和预判能力。

  

**数据应用阶段，“看山不是山，看水不是水”**

到达第二阶段，大数据就不再是简单的数据 符号，逐步演变成了信息产品，具有一定的前瞻 性和预判性，进而出现了“云计算”，也就是所谓 “看山不是山，看水不是水”。大数据和云计算就 像硬币的两面，密不可分、缺一不可。美国洛杉 矶警察局利用大数据预测犯罪、麻省理工学院利 用手机信号分布建设城市规划等等，就是大数据 应用的实例。当前，我国公安大数据应用正逐步向第二阶段转变，出现了“公安云计算”雏形。云计算的核心是算法。好的算法和数据模型至关 重要，决定了大数据的信息处理速度。弊端是过 度依赖“建模”，可变性和延展性几乎为零。

  

**数据挖掘阶段， “看山又是山，看水又是水”**

随着技术水平和科研能力的不断提升，公安 大数据发展到第三阶段，其关键不再是数据和算 法，反而回归到人，即“看山又是山，看水又是 水”的返璞归真状态。这时候，数据分析师、精 算师、挖掘师将成为炙手可热的关键性岗位。数据 分析师将云计算成果进一步校正，去伪存真保留数 据最真实的本质，其指导性更高，也更有价值。数 据精算师可以通过成本控制，不断完善数据应用， 提出更为高效的工作方案，起到事半功倍的效果。数据挖掘师是二者的补充，可以最大限度提升信息 化产品延展性，从中找到规律性变化和发展趋势， 进而提高数据的可复制性，逐渐形成可模仿、可推 广的数据化经验和数字化战例战法。

  

**瓶颈性问题**

通过公安大数据发展的三个必经阶段和“三 种形态”，我们不难发现每个时期的难点和阶段性 难题。

![](../Images/db5cf9bdd3b872125d631febc4e14e05.png)

**图2 公安大数据三个发展阶段的瓶颈 **

  

  
  

**数据汇集阶段**

\_

  

\_

**信息采集量不足** 虽然不断加大基础信息采 集力度，采取了制度性、规范性措施，明确了奖 惩制度，但在实际工作中，受多方因素影响，信 息采集仍存在死角和盲区，有的是责任心问题、 有的是配合不到位问题。比如，有个地市出租房 租赁信息采集不彻底，导致有个逃犯居住在本地 无人知晓，等发现去抓捕，早已人去楼空，加之 现有法规处罚力度不强，只能简单对房主进行治 安罚款500元，收效甚微。

  

**虚假信息过多** 个别单位和民警过分追求信 息数量，虚报、瞒报各类数据以应对检查和完成指标考核任务。在清网行动中，曾经研判出一在 逃人员在沈阳一饭店有务工信息。但是，民警赶 到后发现饭店早已关门倒闭，只能无功而返。

  

**信息不鲜活 **采集的信息时效性不强，特别 是宾馆、旅店、洗浴等娱乐场所和服务行业上传 的信息明显滞后，导致突发情况发现不了、处置 不及时。同时，数据库中部分信息已明显超期， 如不及时清除，极容易影响最终研判结果。

  

  

  
  

**数据应用阶段**

\_

  

\_

  

**缺乏优质的核心算法和数据模型**

目前，现 有的警务综合应用平台多使用归类算法，即采取 同类项合并和关键字归类，通过简单堆砌和关联 形成信息产品。比如，研判某个目标对象时，大 多通过关联宾馆同住人、火车机票同乘人等方式 确定关联对象，但在条件设定上大多采取同时、 同地、同乘等同位素方式，导致错时入住、错站 乘车等情况发现不了。换句话说，现有的数据应 用分析模型多用数学方法解决问题，没有用公安 思维构建模型和算法。

  

**信息产品的评估性不足**

所谓信息产品评估 性，主要指结论性、判断性、规律性的结论。较 英、美、德等大数据应用较为广泛的国家而言， 我国公安信息产品仍处于初中级阶段，缺乏必要 的指导意见。比如，美国洛杉矶警察局的大数据 犯罪预测系统能充分考虑人口、季节、天气等变化 趋势，较为准确地预判案件高发区域和时段，有针 对性地开展巡逻防控，有效压低了可防性案件发生。

  

**虚假信息导致信息产品指导偏差** 大数据的 关键是数据流汇聚。云计算的根本是数据的真实 性。第一个阶段提到的信息滞后、冗余、造假等 问题，直接导致第二阶段我国公安大数据产品的 可信度、指向性有偏差。上文中提到的追逃案 例，因为虚假信息不仅未能及时将逃犯抓获，还 浪费了大量警力。

  

  

  
  

**数据挖掘阶段**

\_

  

\_

  

**缺乏高精尖人才**

目前，公安系统大数据应 用多为专业情报人员。不容忽视的是，情报人员 大多依靠长期的工作经验，人员调转会导致情报 部门短暂的“真空期”。同时，公安内部严重缺乏 数据分析师、挖掘师和精算师等高精尖人才。此 类人员大多为市场紧缺人才，属于高收入人群。公 安机关吸引人才力度不够，很难招揽。

  

**基层应用能力不足**

就现阶段情况看，各省市、地区公安机关信息化应用水平差距较大。很多 优秀的信息系统和平台无人会用，久而久之，平台 被闲置，甚至停摆。个别单位领导不重视大数据平 台，搭建平台为了赶潮流或应付检查。加之审批、 授权等问题，导致民警不会用、不爱用、不能用。

  

**人才培养存在断层**

虽然各地公安机关都开 展了信息化应用培训，但由于缺乏统一的教程、 教材、规范，各自为战的情况依然存在，最终导 致了各地信息化水平参差不齐。各级公安机关信 息化人才交流困难，岗位适应期过长。与此同 时，现有的信息化培训模式多以某一平台的应用 为主，高精尖信息化人才培养机制不完善，导致 此类人才断层现象严重，制约了公安大数据发展。

**数据汇集阶段**

\_

  

\_

  

**建立全国统一的信息采集系统 **

为解决信息采集不规范、数据标准不统一等问题，建议搭建 全国统一的信息录入平台，研发配套移动警务设 备或APP应用软件。通过模式化、标准化、程序 化的管理方式，统一全国公安机关信息录入标 准，通过后台数据筛查，去重、去伪、去冗余， 最终提升数据信息的质量，提高数据池的深度与 广度，避免重复建设。

  

**建立数据池管理规范**

进一步规范信息采集 标准、数据交换模块，根据数据类别和实战需 要，确定信息的采集、研判、消除时限，有效提 高数据池信息的时效性和真实性，提升使用价值。

  

**建立信息密级管理制度**

为充分保障公民个 人信息安全和企业商业机密信息安全，平台系统 和数据池要通过权限控制、审批控制、流程控制 等方式，科学确定信息密级和查阅权限，既要充 分保障信息安全，又不能阻碍公安实战需要。

  

  
  

**数据应用阶段**

\_

  

\_

  

**优化数据模型**

组织业务专家和公安专业人才，对现有的公安信息化平台进行会诊，通过 “诊脉——开方——抓药”的方式，对平台构建模 式、运行维护模式和数据信息研判模型进行综合 分析。取其精华、去其糟粕，力争通过一段时间 的调研分析，研究符合我国社会治安形势和公安 工作需要的数据模型，进一步提高数据研判的精 准度，提高数字产品的价值。

  

**优化数据算法**

参考外国先进经验，建立犯 罪预测、高危人群管控、交通信号灯控制、大型 活动安保预案、突发事件应急响应等数据算法， 实现警务信息化产品全面服务基层部门实战和日 常警务活动，推动信息化产品导侦、导防、导 控、导流等目标。

  

**推动公安物联网建设**

参照“云仓”模式， 将警用车辆、装备、武器和公共安全点位、电子 围栏、人像识别等设施纳入公安物联网，通过数 据算法，提供巡逻防控、应急处置等警务活动最 优方案，有效减少接处警时间和跨区、市调动警 力、武器装备时间，最大限度提升警务效能。

  

  

  
  

**数据挖掘阶段**

\_

  

\_

  

**完善高端人才引进计划**

通过职务职级保障、人才引进计划等方式，广泛吸纳业务水平高 的数据挖掘师、精算师、分析师进入公安队伍，争取最短时间内组建一支公安大数据精英团队， 尽力缩小人才缺口。

  

**建立公安大数据培训体系**

参照“精英理论”原理，根据各级公安机关实战需要，建立健 全公安专业信息分析师、省市县区公安信息化专 业人才梯队培养方案，因材施教、因人而异，科 学化、菜单式提供在线学习、专班培训，实现公 安大数据人才差异化培养和梯度储备。

  

**建立公安大数据交流和轮训机制**

公安大数据顶层设计人员和公安大数据分析师要建立异地 交流和随岗轮训模式。通过实际接触公安工作，进一步提高公安实战经验，在设计、应用、研判 过程中提供更符合实际需要的信息化产品，更接 “地气”

  

公安大数据战略意义重大，任重而道远。需要正确面对存在的问题和不足，最终实现数据大 统一、大融合、大研判，为新时代公安工作创新 发展提供强有力支撑。
