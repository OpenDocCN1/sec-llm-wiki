# 大数据时代智慧侦查的前瞻性探索

摘要：随着互联网技术和人工智能取得突飞猛进的 发展，在大数据时代到来的今天，我们还处于什么侦查阶段？我们又以什么方式迎接这个新的侦 查时代？成为当下刑事侦查面临的新课题。

![](../Images/621e41b044c1b9602ce3968033798fce.png)

  

  
  

**侦查的三个时代**

\_

  

\_

经过长期的侦查实践，我们不断理清对侦查 理念体系和发展阶段的困扰，提出将我国的侦查 活动分为三个发展阶段，即传统侦查时代、合成 侦查时代和智慧侦查时代。目前，我们正处于后合成侦查时代这一过渡阶段。

  

**传统侦查时代**

在传统侦查时代，侦查工作依靠的都是人力成本。基层民警靠着两条腿跑现场，靠着一张嘴 开展调查走访，靠着一支笔记录案件信息、制作 笔录等相关资料。这些资料和信息都落到纸张上 和侦查员的脑海里，师傅带徒弟的方式是学习侦 查最有效也是最快捷的手段和方法。在传统侦查 时代，连最受人民关注的命案都无法实现全侦破，八类案件侦破率也持续低下。审讯的艺术是最 受侦查员推崇的，就案办案，口供为王是公检法机关的共识。晋江的背包精神，诠释了案件发到哪， 背包打到哪，这也是传统侦查时代的典型特征\[1\]。

  

**合成侦查时代**

21世纪初，随着互联网技术的不断发展，个人计算机的使用突飞猛进，信息化革命悄然来 临，从传统侦查时代逐步迈入了合成侦查时代的 门槛。纸张记录的材料和侦查员脑海中的信息都 逐步形成电子数据存储到计算机里。刑事科学技 术手段随着人类科技的进步也取得重大进展，视 频监控技术开始广泛建设并用于案件侦查。命案 的侦破率也持续上升，公安机关的侦查业务重点开始向八类案件的侦破转移，对于两抢等重大暴力犯罪破案率也逐步取得了重大突破，正是在这 个时候合成侦查时代悄然到来。由于公安机关的行政化羁绊，造成了部门独立、资源分隔、信息孤岛、效率低下等多种制约，因而逐步催生出去行政化的合成侦查模式， 即打破部门界限，发扬特长，实现资源最大限度整合、信息最大化融通、手段最大程度集成，形成高效、流畅、集约的侦查模式。

  

**智慧侦查时代前瞻**

合成侦查时代持续发展了多年，逐步走到了 现在的后合成侦查时期。这个时期，各警种拥有 的数据资源都逐步汇集到科信部门。科信部门负 责处理加工这些数据，并对各警种提供数据接 口，为全警构建大数据体系提供能力支持。同 时，天网工程、雪亮工程开始建设，社会面视频 监控发展突飞猛进，互联网数据也不断向公安机 关汇集。数据中心利用侦查员和研判员多年的侦 查经验和技战法，侦查数据模型的建设也提上日程。各级公安机关对数据的使用意识越来越强， 随着互联网+人工智能的爆发式发展，各种大数据 算法能力持续提升，数据侦查迎来了发展的新机遇。

  

但是要强调的是数据大并不是大数据。大数 据指的是相关的理念、维度、计算能力和数据服 务意识彻底改变。要实现这个彻底改变，就必须 进行新的艰难探索，而大数据能力体系建设就是 一个强有力的抓手，带动了整体侦查理念质的飞 跃，在这个探索的过程中，就注定进入了一个新 的时代：智慧侦查时代。

  

随着科技的发展，捕捉数据要素的能力在逐 步强大，个人移动终端逐步普及，2018年底中国手 机用户突破了15亿，人在数据层面上业已成为透明人、数据人。一个犯罪嫌疑人，他随身携带了侦查 破案所需要的全部信息，指纹、足迹、DNA、声纹 等，出门还要带着一张脸，还要穿衣服，还要乘坐交通工具，还要带着用于移动支付的手机等等。随着数据不断向公安大数据中心汇集，这些时空的多 维度数据可以完全实现对人的刻画和定位。

  

对于多发性传统侵财犯罪，其基本规律就是 少数人做多数案件，掌握了少数人就控制了多数的案件。通过对这些前科人员的建库和特征打标，结合案件的信息关联，搭建人案关联的桥 梁，实现多发性传统侵财案件侦破质的飞跃。从 命案全侦破，到八类案件破案率取得重大进展， 再到多发性传统侵财案件破案率的持续上升，这 就是整个侦查体系不断攀登的过程，更是三个侦 查时代不断前进的脚步。

  

  
  

**智慧侦查的探索**

\_

  

\_

  

汇全警智慧，将最佳侦查经验、侦查思维程 序化，建立类案侦查模型；集全网资源，为侦查 模型提供多维度数据支撑，全面提升多发性传统 侵财犯罪的智能打击能力和水平，实现警力的无增长改善。

  

**重点攻坚方向**

安徽省芜湖市公安局主动适应本地传统侵财 案件多发的发展形势，积极应对实战新要求，坚 持“内部挖潜”与“外部借智”相结合，在目前 互联网数据使用还存在困难的情况下，依托公安 内部数据的深度挖掘，努力构建智慧侦查新模 式。通过汇总各种侦查技战法，基于大数据+人工 智能技术对人、案、物等业务对象定义智能侦查 模型，转变传统侦查为现代化侦查，转变人工侦 查为数据化侦查。

  

当前，市局主要针对入室盗窃、盗窃三车、 盗窃街面店、扒窃、砸车窃物五大类多发传统侵 财案件，研发数据侦查模型，构建智慧侦查打击应 用体系，为一线实战民警提供智慧“外脑”。智能打 击建设以侦查业务思路和流程为基础，使用已破案 件作为学习样本，经过整理标注形成训练集，结合 侦查经验、知识库，利用机器学习技术对模型进行 训练、验证、优化，生成智能侦查模型。打造一个 “互动式”侦查破案新通道，贯通侦查业务全流程， 实现“犯罪规律高度提炼、类案特征自动攫取、涉 案线索智能比对、累积打击准确有效”的目标。

  

**构建三大底库**

市局智能打击框架建设的基础是依托省市大 数据中心，通过搭建案件库、人员库、物品库三 大刑侦业务专题库，作为模型智能分析的数据基 础，实现数据资源的结构化处理。案件信息的数 据治理是源头，通过对案件信息进行标签化处 理，实现对发破案的精准描述，从而实现对涉案 人员和物品的精确刻画，为案件精准串并和犯罪 嫌疑人精准推荐提供数据支撑。

  

三大基础数据库主要来源于各业务警种的全 量数据资源，通过数据汇集和治理为智能侦查模 型搭建提供数据底库。以三大底库为基础，将侦 查经验和技战法转化为分析模型，把侦查员的形象 思维变为机器的逻辑思维，建立数据分析模型，向 人工智能发展，促使破案格局实现颠覆性改变。

  

**案件智能串并**

随着市局犯罪智能打击课题组研究的不断深 入，通过调取协同办案系统的全项数据，以及现 场勘验、案件分类加工、情报应用等系统平台的 技术串并案等多项数据门类，过滤条件还包含了 经纬度、作案时间数据和数据标签清理，开展了 智能串并案研究，取得较好成效。

  

通过对案件分类加工和现场勘验系统的全量 数据进行分析，利用已破案件和技术串并案的数 据开展数据分析和验证算法的有效性。针对案情 和现场勘验信息，使用智能语义识别技术自动对 案发时间、作案手段、损失物品等信息进行标签 化处理。基于案件现有信息，智能串并案模型自 动匹配案发前后芜湖市区发生的同类案件，随着 数据的不断更新和算法的不断迭代优化，不断提 升智能串并能力，按照TOP级排序推送可疑串案。

  

**嫌疑人智能推送**

侦查员、技术员、研判员在现场勘查、调查 走访、侦查研判的过程中，采录的信息不断触发 系统设定的比对模型，持续拓展案件线索，不断 提升案件的可侦度和嫌疑人的可疑度。智能串并 案模型推送串并案信息后，系统会自动匹配数据 推送嫌疑对象，按照TOP级不断进行更新。

  

通过案件现场经纬度和时间点位的结构化处 理，利用公安掌控的轨迹类数据与智能串并案件 进行模型匹配。案件智能串并之后，嫌疑人推荐模块根据设定模型运算规则自动推荐嫌疑人员。主要是采取人号对应、亲密度、轨迹伴随等大数据算法，对嫌疑人的嫌疑指数进行运算，以获得 更准确和稳定的预测指标。通过近10年的打处人 员数据统计，明确少数人做多数的案件，同类前科人员多次作案的典型特征，这也是开展嫌疑人 推送的基础。

  

**人案自动关联**

在当前的警务模式下，必须实现从警情为驱 动的“打击一元化”向以数据为驱动的“打击多 元化”新模式转变。通过大数据分析掌握工作主 动，精准驱动实战，开辟警力效能新的生成方 式，由固有的模式向数据到案、数据到人、数据 到线索的“人案关联”智能打击模式转移。

  

通过完善可视化关联、多维分析、智能比对 等功能，建设“可侦度”“嫌疑度”筛查模块，绘 制多发性传统侵财案件侦查思维导图和业务流程 图，不断提炼侵财类案技战法融入数据侦查思 维，智能引导融入侦查破案全环节，完善传统侵财类案侦查模型，搭建“人案关联”贯通新通 道，最终达到“研究犯罪规律，建立分析模型， 发现犯罪轨迹，锁定犯罪人群，快速智能打击” 的智慧侦查新方向。 

  

习近平总书记在全国公安工作会议上强调， 公安机关要坚持科技兴警，把大数据作为推动公 安工作创新发展的大引擎。为认真践行习近平总 书记的指示要求，积极迎接智慧侦查新时代，针 对当前公安机关人少案多，小案侦破难度大、效 率低等痛点，积极回应人民群众的期盼，依托大 数据，探索人工智能破案，实现打击效益最大化。
