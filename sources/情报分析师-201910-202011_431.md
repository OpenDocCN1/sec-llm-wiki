# 特种部队将军遭美军暗杀，土耳其力挺伊朗，送情报挖出以色列间谍

2020年1月4日，土耳其方面报道称，土耳其总统下令建造的土耳其情报总部新大楼将在1月6日正式开幕！土耳其情报总部的建筑群建设已经结束。土耳其总统将亲自出席1月6日的开幕式。据土耳其方面报道称，该建筑采用最新工程技术制造，土耳其情报大楼内部照片甚至没有公开。而土耳其情报大楼外形上采用了塞尔柱风格的，土耳其总统埃尔多安非常喜欢塞尔柱的建筑，甚至土耳其总统府也在塞尔柱的建筑计划中。  

![](../Images/52e6e627e9fe24fa38ca503e921f06bb.png)

土耳其新建设的情报大楼

土耳其方面称，土耳其情报总部将再增加一万名员工和间谍！此外，土耳其情报部门将在世界范围内更加活跃。土耳其总统埃尔多安认为，土耳其是中东地区的强国，必须发展了相当多的情报战线，土耳其总统埃尔多安将土耳其情报预算军费增加了十倍以上。目前，土耳其的情报人员、间谍在中东和欧洲都非常活跃。

![](../Images/0118c596ec8d3fd71a8f8952041c8abf.png)

航拍的土耳其情报大楼

土耳其方面称，土耳其情报局目前和伊朗、俄罗斯等国关系比较紧密，在伊朗特种部队将军苏莱曼尼被暗杀后，土耳其情报机构向伊朗提供了有关伊朗境内10名以色列特工的信息，这些特工后来被伊朗俘虏并杀死，从而报复以色列在伊朗进行的颠覆活动。土耳其情报局也对以色列造成了很大的打击，因为土耳其情报局大大削弱了以色列在中东的秘密势力，失去了许多特工。

![](../Images/d06dd4d67b4be6dcc0522cf0d4e15aa4.png)

西方国家对伊朗全力渗透

土耳其的情报活动在叙利亚，利比亚，索马里，苏丹，以色列，伊朗，沙特阿拉伯，埃及，阿拉伯联合酋长国，希腊，塞浦路斯，伊拉克，亚美尼亚，独联体国家，欧洲地区，尤其是德国，甚至土耳其情报局特工在拉丁美洲也有部署。

目前，土耳其拥有世界上最强大的情报服务网络之一，而土耳其情报局也采取了和仇敌以色列”摩萨德“间谍特工组织一样的手法，那就是秘密使用大规模暗杀、绑架。土耳其情报局对反击土耳其的武装分子展开了大规模暗杀，消灭了多位地区武装领导人。

![](../Images/9c87a75262256a7c4aef74ce3a201e3a.png)

伊朗情报部门现在目标就是找美国、以色列特工

土耳其方面报道称，在土耳其总统埃尔多安执政期间，美国中央情报局已经成为土耳其情报局最强大的敌人之一，美国中央情报局并且正在全世界积极发挥作用，例如，伊拉克、叙利亚和利比亚的代理战争就是美国中央情报局挑唆的。美国中央情报局目前大力支持打击土耳其的库尔德武装，所以土耳其情报局目前敌人和伊朗是一样的！
