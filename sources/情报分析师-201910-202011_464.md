# 央视记者采访：连环杀人案逃犯劳某枝落网细节，大数据成追凶者也

12月3日下午，福建厦门市警方公布20年前连环杀人案逃犯劳某枝落网的详细情况：经DNA比对鉴定确认了劳某枝身份。目前，未发现劳某枝潜逃厦门期间作案。

劳某枝是如何到案的？这二十年间她都去了哪？央视记者对厦门警方进行了采访。

![](../Images/96099dc8bb1d3beeb7e1b916cbde7ea5.png)

面对警察，劳某枝并未惊慌失措

  

![](../Images/b5faf27b69f952a748129e1df8d77b7d.png)

民警 林国强 ：今年以来公安部在全国开展“云剑行动”，“云剑行动”里面的比较重要的一部分就是追逃工作 。近期，思明刑侦大队对在辖区活动的人员，包括原来全国各地上网追逃的历年逃案，都进行了一遍梳理。

11月27日下午，厦门市思明公安分局刑侦大队通过大数据信息研判发现， 一名在厦门市思明区蔡塘广场附近活动的女子，与公安部在逃人员库中，江西籍逃犯劳某枝的信息高度相似。

  

![](../Images/e24fe8f914258204f957094a23173d88.png)

厦门警方立即与江西南昌警方取得联系，进一步获取有关逃犯劳某枝的情况，并第一时间前往该商场开展调查。  

  

![](../Images/463e77655c8371c47c945b4a79459a36.png)

  

11月28日上午11时，经精准研判、蹲点伏击，民警成功在厦门某商场将劳某枝抓获归案。

  

![](../Images/ff6af4e2ad5b112f4313e18dac30f5d5.png)

  

民警 林国强 ：我们是穿制服过去的，面对穿制服的警察，包括我们亮明身份以后，她并没有显得惊慌失措，而且也没有抗击抓捕或什么之类。

劳某枝拒不承认其真实身份

劳某枝到案后，厦门市公安局刑侦支队、思明公安分局立即组织专门力量对其进行审讯。劳某枝拒不承认其真实身份，自称是南京籍“洪某娇”。

  

![](../Images/a54342906dd8523eff0aee943c20fe9f.png)

民警 林国强 ：我们立即采集了她的血样进行技术检验，经过数个小时等待以后，最终揭晓这个嫌疑女子就是命案逃犯劳某枝 。

  

目前未发现劳某枝潜逃厦门期间作案

  

经初步调查，1996年，劳某枝伙同法子英在江西南昌杀害一家三口后，流窜多地作案。1999年7月，法子英在安徽合肥落网。而劳某枝隐姓埋名、使用多个虚假名字在全国多地潜逃，流窜于不同城市，靠在酒吧、KTV等场所打零工、短工为生。

直至今年11月28日，在福建省厦门市落网。目前，未发现劳某枝潜逃厦门期间作案，该案还在进一步侦查中。

![](../Images/f45ac036a636e6e36968ed0f8ca2c6e3.png)  

事件回顾

据安徽合肥市中级人民法院资料显示，落网的劳某枝及法子英（已于1999年12月28日被执行死刑）涉及多起杀人案案情。

资料显示，劳某枝，1974年生人，原系九江石油化工公司的小学教师。1996年5月，被告人法子英与劳某枝（女）窜至江西省南昌市。二人于6月2日住进一租房处后，即预谋绑架勒索钱 财 。由劳某枝化名“陈佳”在南昌市爱乐音夜总会坐台，物色到绑架对象熊启义。

![](../Images/60431814fa7a36c84a2c45cefa5f2a89.png)

  

7月28日上午，劳某枝打电话将熊启义诱骗至其租房处，法子英持尖刀逼住熊启义，后将其捆绑。法子英从熊启义身上抢走首饰、手表等物，并继续向其勒索财物。在逼迫熊启义说出家庭住址后，法子英于当日下午将熊杀害。当晚，法、劳二人携带从熊启义身上搜到的钥匙来到熊家，开锁入室后，法子英用尖刀威逼熊妻张莉交出财物，并将其双手反绑，双脚捆绑。

在抢得金银首饰、现金、债券等财物后，于29日凌晨将张莉及其三岁女儿杀害 。后经鉴定，被告人法子英、劳某枝抢劫的物品价值人民币3.027万元，现金人民币8090元，港币110元，美元10元，债券1000元，银行存单9.5万元。

1997年10月初一天，被告人法子英、劳某枝又窜至浙江省温州市，法子英在与被害人梁晓春商谈转租住房事宜过程中发现梁晓春有钱，遂与劳某枝预谋抢劫。

  

![](../Images/9239b431a1c2991fb7fe1f9dd70f7405.png)

图片来源：新安晚报

10月10日，被告人法子英携带一把尖刀与劳某枝来到梁的住处，法子英手持尖刀逼住梁晓春，将梁的手脚捆绑后逼其交出钱财。在从梁住处搜得现金、存折等财物后，法子英又逼迫梁骗一有钱人来梁住处供其抢劫，梁晓春被迫打电话将刘素清骗来。法子英在逼迫刘素清交出现金千余元、2.5万元存折后，也将刘的手脚捆绑。

法子英让劳某枝携带抢得的手机及2.5万元存折到银行提取现金 。在接到劳某枝得手的电话通知后，法子英将梁晓春、刘素清勒死，并从二人身上抢走欧米茄手表、雷达牌手表、手机、传呼机 等。

1999年6月底，被告人法子英、劳某枝窜至安徽省合肥市。7月1日二人住进租住的房屋后，即预谋准备工具绑架杀人，法子英在一电焊门市部以“关狗” 为名定制钢筋笼一只，劳某枝则到住处附近的旧货市场买了旧冰柜一台。

  

![](../Images/d5499b8e99506f5a3ee15bf0517c9f4c.png)

来源：警视窗  

  

7月22日上午，化名“沈凌秋”在合肥“三九天都”歌舞厅坐台的劳某枝打电话将物色到的绑架对象殷建华诱骗至其租房处。法子英手持尖刀胁迫殷建华，将其手脚捆绑锁进钢筋笼。为使殷相信二人是绑匪并尽快交出财物，法子英在合肥市六安路以有木工活要做为名，将一木工骗至其租房处，并当殷建华的面将木匠杀死。

在法子英的恐吓下，殷建华按法的意思写了二张字条给其妻刘某某，要刘交钱赎人。当晚9时许，被告人法子英叫殷打电话给其妻，让刘准备钱在合肥市长江饭店与其见面，法子英携带字条前去收钱，但因故未成。当晚11时，法子英再次打电话与刘某某约定次日上午9时见面。

7月23日上午，法子英逼殷建华又给其妻写了两张字条后，将殷勒死。之后，法子英携带自制手枪及殷写的字条来到殷家，向殷妻索要一万元。刘以筹钱为由让其在家中等待，随后向警方报案。法子英拒捕未遂，当场被警方抓获。

  

![](../Images/159053c60c3ebe631337f214d47410b8.png)

![](../Images/28542e099f41ff1aa0880c31628d9913.png)

图片来源：警视窗

当时，法子英被包围后，持枪负隅顽抗。最终他被合肥警方击断右腿后擒获，绑匪倒地时，手中还紧握着手枪。合肥警方《警视窗》电视栏目跟踪采访了整个案件的侦办始末，记录下惊心动魄的枪战过程。

  

![](../Images/9ebc1b2bc0723dc1a325afbf5cf27151.png)

来源：警视窗

  

1999年11月18日，该案件在合肥中院开庭审理，合肥中院审理认为，被告人法子英自1996年7月至1999年7月，伙同劳某枝流窜作案。在南昌，法、劳二人以勒索财物为目的，采用诱骗手段绑架并杀害七人，被告人法子英、劳某枝的行为分别构成绑架罪、故意杀人罪、抢劫罪 ，且犯罪手段特别残忍，犯罪情节特别严重，社会危害性极大。数罪并罚，被告人法子英被判处死刑，剥夺政治权利终身，并处没收个人全部财产。
