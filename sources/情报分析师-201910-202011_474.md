# 中途岛海战中日本人有多倒霉？

中途岛海战是二战太平洋战场的转折一战，这一战的惨败，让日军损失了四艘大型航母，海军航空力量遭到沉重打击，更为严重的是，在战略层面，这一战让美国赢得了动员自己强大工业潜力的时间，日本的速战速决变成了消耗战，而弹丸小国必然抵不过世界第一强的美国，由此注定了战争的结局！  

![](../Images/6353c50147ec21ff41e6a1e2092b4aed.png)

这一场海战中有太多鬼使神差的事情，仿佛命中注定一般！

![](../Images/01dcce4ee1ab3c0db317e4435ce627c9.png)

美军舰载航空兵部队

战役开始前，美军为了获悉日军的下一步动向，在情报方面下了很大功夫，但在截获的密电中，有一个非常可疑地标代号AF，美军情报人员不知道其指代何处，根据推测，美国人认为AF岛指的就是中途岛。为了验证这一点，美军让中途岛守军用明文向总部发电，谎称岛上淡水处理设备发生故障导致淡水供应紧张。不久之后，美国人果然截获了日本人的密电，称AF岛当前淡水供应紧张，由此美军便确定，日军的下一步进攻目标就是中途岛！情报战的成功让日本人丧尽先机！

![](../Images/1f50cad27768af1ef0e8ae2a8ee9b22b.png)

在中途岛海域警戒的美国战舰

日本联合舰队起航出征前，山本五十六与手下大将一起参加出征宴，席间上了一道菜，菜名竟与日语的“失败”异词同音，山本一时脸色大变！

![](../Images/ec0f51323f1acad90be17e20ecbb4edb.png)

日本联合舰队总司令山本五十六

日本此次战役重要目标在于占领中途岛，消除美国人对于日本本土的威胁，并获得向美国纵深进攻的前进基地，此战中，美军主力舰队位置是日本人最为关心的信息，为了监视美军舰队动向，山本派出了一支潜艇部队，在美国人前往中途岛的必经之路上设置了一道警戒线，一旦发现美军，立即上报！

![](../Images/b39822b1fa6ddb8fc32b6045f7ffe3e0.png)

美军潜艇

然而，不知何故，这支潜艇部队没有按照预定计划出发，原本6月1日便可抵达警戒阵地，结果晚了一天，而巧合的是，美军舰队在5月31日起航，在日军潜艇警戒线建立之前就已经走过去了，这一时间差导致日本人发现美军的时间晚了数天，直到大战开始几个小时后，日军巡洋舰上的侦察机才第一次发现美军舰队踪影！

根据作战计划，为了迷惑敌人，山本派出了一支包含两艘航母、多艘战列舰、巡洋舰在内的编队去攻击阿留申群岛，以分散敌人注意力。这绝对是一招臭棋，阿留申群岛与中途岛相隔甚远，在两个彼此互相不能支援的战场分兵作战，这是兵家大忌，何况这个战场还牵制了日军两艘宝贵的航母，试想如果这两艘航母没有去阿留申，而是在中途岛战场专职防空，掩护己方部队，保证战区的制空权，如果是这样，美军想要击沉日军航母是很难的事情，山本一向重视海军航空兵力量，然而在这最为关键的一战中，却将战列舰作为主力，以航母为辅助，看来山本对现代海战中制空权的重要性还是没有领悟到家！

![](../Images/529d3fd6a599be1590c0dc6e3337078b.png)

制空权对海战至关重要 图为舰队火力拦截敌军飞机

整场战役中，最为精彩的当属美军攻击日军航母的时刻了。日军舰队抵达攻击阵地后，在发起对中途岛的轰炸同时，也派出了侦察机在附近水域搜索可能出现的美国舰队，逗比的是，被指派的侦察机临阵掉链子，四架飞机中有两架发生了机械故障，起飞时间延迟了半个小时。

![](../Images/414fe210248cb9ed3baffb40ffd0ce99.png)

因为一直没有发现附近美军出没的踪迹，日本编队司令南云忠一下令将航母甲板上待命的鱼雷攻击机拆下鱼雷，换上炸弹，作为后续梯队对中途岛实施空袭，然而，就在换装间隙，那架修好的侦察机此时却报告发现美国人的舰队，南云急问舰队中有无航母，回答没有，南云稍放心。可是刚过十几分钟，这架侦察机又传回消息，美国人的舰队当中可能有航母...对于这模棱两可的情报，南云很是纠结。

![](../Images/a3dd0bd4939e7875c98fad759ca6a839.png)

美军侦察机发现日本舰队

最终，为了保证编队安全，消除美国航母力量的威胁，南云命令已经在换装炸弹的飞机再重新换上鱼雷，鱼雷炸弹堆满甲板，此时又值攻击中途岛的飞机返航，在航母上空盘旋等待降落，甲板上一时混乱不堪。

![](../Images/8b25e7b99195b2da83e7ef4687e9a17a.png)

美军战机

恰在此时，美军舰载机攻击群飞到了日本编队跟前！空中负责警戒的零式战斗机立即迎上去，日本飞行员技术精湛，不一会就将美军首先抵达的鱼雷攻击机编队干脆利落地消灭了，就在美军的鱼雷攻击机群将日军零式都吸引到了低空的时候，迟到的美军俯冲轰炸机临场，趁日军防守空虚之机，编队迅速俯冲直下，几乎近于垂直地冲向日本航母，一刹那间日本人头顶弹如雨下，仅5分钟时间，日军便有四艘航母被击中，爆炸引燃了甲板上的炸弹和鱼雷，航母遭受重创，陆续沉没。

![](../Images/1b328f597f9b6890f5ca9236b499687c.png)

日军航母被击中

航母被击沉，从中途岛返航的日本飞机找不到降落之处，只好迫降在附近海面。

![](../Images/fcdc95e2a1908ebca4974aab4fdb0188.png)

迫降在海面的战机

鉴于航母编队遭到毁灭性打击，山本五十六只得下令放弃原定计划，编队返航驶离战场，美军顺势乘胜追击，又击沉一艘日军重巡洋舰、击伤数艘巡洋舰、驱逐舰数艘！

![](../Images/34515e21daedb820ebb63f67058e559a.png)

被美军炸残的日本军舰

中途岛海战是日本明治维新以来海军的首次海战失利，这一战让日军损失了四艘主力航母以及大量训练有素的飞行员，其中还包括数名不可多得的王牌飞行员，自此之后，在太平洋战场上，美日航母力量对比发生了转折，日军颓势渐现，直至最终灭亡！
