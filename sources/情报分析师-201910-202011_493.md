# 美国特勤局特工是怎样炼成的？最后一项训练内容，让人感慨

众所周知，凡是美国总统公开出现的场合，其周围总是少不了身穿黑色西服，佩戴着墨镜和通讯耳机的彪形大汉。他们就像总统的影子一样，寸步不离地跟在总统身边，不停地用一双警惕的眼睛扫视着周围的情况，随时准备着应付各种突发事件。  

![](../Images/0844771d110e6b361cddd9136b0beb93.png)（总统身边的特工）

这些人就是隶属于美国特勤局的特工，是总统的全天候专职保镖。主要职责是保护总统、副总统，前总统和他们的配偶，以及外国元首到访时的安全。

当然，特勤局有时还会根据总统的命令，负责保护各国驻美大使馆、美国海军天文台和在华盛顿特区的白宫，或者执行一些秘密任务。

特勤局是美国历史古老的联邦机构之一，成立于1865年4月。最初的任务是调查市场上日益泛滥的假钞，总部设在华盛顿，是美国财政部的一个下属部门。在这个机构刚刚成立几天后，林肯就在华盛顿福特剧院遭到激进者约翰·威尔克斯·布斯的刺杀。

1901年，美国第25任总统威廉·麦金莱在布法罗遇刺，国会只好给白宫隔壁的财政部特勤局增加了两个编制，负责保卫总统等要员的安全。1902年,特勤局正式开始担负全天候保卫总统的任务。

从2003年起，特勤局被划拨给国土安全部，总部离白宫只有三个街区，其分部遍及全美几十个州，设有100多个办公室，甚至在海外也有十多个分支机构。

据不完全统计，特勤局共有雇员达6000多人。其中的一半以上，属于便衣特工，大约1300人是制服特警，其余的是技术人才和管理人员。

特勤局的便衣特工除了执行安全保卫任务外，还要负责金融案件的调查，如制贩假钞、伪造文件、信用卡诈骗等。

而制服特警的任务则非常明确，就是保卫任务。这些人最初来源于军方和华盛顿等城市的警察局，负责保卫包括白宫建筑群、财政部大楼及附属建筑和其他总统办公地、总统及其家人的安全。

![](../Images/530b5f47c0c20effc7dc08f52a42a1e8.png)

（在总统身边的特工）

特勤局不但拥有大量的特工人员，还配备有强大先进的火力。在纽约市布鲁克林区一座大厦的顶层，就是特勤局的军火仓库。里面有性能优越的手枪、冲锋枪以及散弹枪等。另外，特工们都配备有干扰狙击手的设备，能赶跑刺客的“燥音炮”及能准确识别刺客方位的狙击手定位器等。

要想成为特勤局的一名特工，**首先必须是美国公民，而且家世清白，自身没有任何犯罪记录和不良嗜好。****年龄要在21—37岁之间，体格强壮，耳聪目明。**

对特工的学历要求是在政府承认的**大学获得学士学位**，通过美国财政部执**法人员考试或司法警察考试**。同时，特勤局还要对这些人进行背景调查、测谎器试验、毒品筛拣、心理测试等一系列复杂审核。全部通过后，这些新特工才开始在位于马里兰州的詹姆斯·罗利中心接受为期28周的**魔鬼训练**。

这些训练内容包括武器使用、控制战术、水中生存技巧和体能训练，以及驾驶技术、擒拿格斗、炸弹拆除等特工基本技能训练。

特工们对第一堂课的记忆尤其深刻，他们会站在闷热的训练室里，整整9个小时，直到汗水将全身衣服湿透。还会因大声朗读训练规定和特工职责，把嗓子喊哑。

训练过程中充满了危险，特工们为了对付大规模杀伤性武器，有时要亲自钻入专门的毒气室内，尝试不同毒气带来的身体反应，实地演练救助被化学毒气攻击的保护目标。确保在以后的实战中能快速识别毒气种类，尽量缩短对总统的救助时间。

在跟踪训练中，所有特工都得学会易容化妆，尽量将自己和周围人群融为一体。运用娴熟的跟踪技巧，长时间跟踪目标。

![](../Images/89e9c5b091e4a485c51ed1cb98aedc29.png)（里根旧照）

同时，特工还必须具备超强的**抗击打能力**。他们在训练中会经常遭遇围殴，忍受长时间的拳打脚踢，直到失去知觉。并在清醒后，迅速回忆对方的体貌特征、说话口音等情报。

最为关键的是，特工要学会**随时为总统挡子弹**，做总统的人肉盾牌。在特工看来，比总统的防弹汽车还要坚固的，是自己的“肉盾”。

在美国历史上的40多位总统中，有遇刺经历的就超过10位，只有其中的4位殒命身亡。其余的全部靠着保镖的挺身相护，才捡回了一条性命。

1981年3月30日，刚刚就任总统的里根，在希尔顿饭店门口遭遇一个精神病患者的刺杀。枪手一共射出了6发子弹，总统秘书和特工麦凯锡各自为里根当了一枪。但还是有一发子弹命中了里根的肺部，后被紧急送到医院抢救，他才惊险地死里逃生。

训练特工的教练米克森说：“我们训练特工的核心素质就是，永远挡在子弹和总统之间，永远把总统的安全放在第一位。”

特工训练的最后一项内容，就是写遗书。教练会告诉学成结业的特工们：“祝你们好运，别忘了写份遗书。”

也许，对于危险无处不在的特工而言，这最后的一堂训练课确实意义非凡。
