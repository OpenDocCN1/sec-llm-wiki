# 澳大利亚情报界

构成澳大利亚情报界（AIC）和国家安全界的澳大利亚政府机构如下：

**治理实体**

**内阁国家安全委员会**

内阁国家安全委员会（NSC）是一个内阁委员会，是国家安全、情报和国防事务的最高部长级决策机构。它由总理担任主席，成员包括副总理、总检察长、财政部长、外交部长和国防部长。各个公共服务部门的秘书以及国防军司令、国家安全顾问、安全局局长、国家评估办公室和澳大利亚秘密情报局的局长\[1\] \[2\] \[3\] \[4\] 。

  

**国家安全事务秘书委员会**

国家安全事务秘书委员会（SCNS）（前身为情报与安全事务秘书委员会）是支持国家安全委员会的高级部门间委员会。它审议所有提交给国家安全委员会的重大事项，并在确保澳大利亚在所有国家安全问题上保持协调的政策方针方面发挥着强有力的作用。国家安全委员会的成员包括总理和内阁部的秘书、总理和内阁部负责国家安全和国际政策的副部长、总检察长部的秘书、外交和贸易部的秘书、国防部的秘书、财政部的秘书、澳大利亚国防军司令以及国家评估办公室主任。其他高级官员包括澳大利亚联邦警察专员、澳大利亚海关和边境保护局的首席执行官、澳大利亚犯罪委员会的首席执行官，以及澳大利亚安全情报组织、澳大利亚安全情报局、AGD、ASD和DIO的负责人也在需要时出席。

  

**澳大利亚和新西兰反恐怖主义委员会**

澳大利亚和新西兰反恐委员会（ANZCTC）是一个协调反恐能力、危机管理、指挥和控制、情报和调查职能的双边和政府间高级机构，由澳大利亚政府、澳大利亚州和地区政府以及新西兰政府的代表组成。其正式名称为国家反恐委员会（NCTC），2012年10月，新西兰政府成为其成员，以鼓励就与反恐有关的双边利益事项进行更密切的对话。它是根据2002年10月的政府间协议建立的，通过协调一个全国性的合作框架，即国家反恐计划，为澳大利亚社会的安全作出贡献。

  

**澳大利亚反恐怖主义中心和联合反恐怖主义委员会**

澳大利亚反恐中心（ACTC）是一个政府间多机构机构，负责协调澳大利亚的反恐工作。澳大利亚反恐中心提供战略指导，以确定战略反恐优先事项，协调反恐政策，通报行动反恐优先事项，评估优先事项的表现，并确定和解决有效协调反恐的障碍。ACTC的成员包括来自ASIO、AFP、ASIS、ASD、AGO、ACBPS、ACC、国防部、DFAT、DIBP和总检察长部的高级官员\[7\] 。

  

**国家情报协调委员会**

国家情报协调委员会（NICC）是为了确保澳大利亚的外交、安全和执法情报活动与我们的国家安全优先事项紧密结合并保持一致，并确保国家情报工作得到有效整合。该委员会由国家安全顾问担任主席，成员包括来自所有情报和安全机构的代表\[8\]\[9\]。

  

**国家情报收集管理委员会（NICMC）**是国家情报协调委员会的一个小组委员会，负责制定具体要求，并根据每个国家情报优先事项（NIPs）评估收集工作。它由国家评估办公室主任担任主席。

  

**国家情报开放源委员会（NIOSC）**是国家情报协调委员会的一个小组委员会，负责加强国家情报界开放源工作的协调和能力。它由国家评估办公室主任担任主席。

  

**国防情报委员会**

国防情报委员会（DIB）负责对军事情报和国防情报与安全小组进行监督和战略协调。国防情报委员会由负责情报和安全的副部长主持，包括来自ONA、国防科技组织、澳大利亚军队、澳大利亚皇家海军和澳大利亚皇家空军的代表。

  

**情报机构负责人会议**

情报机构负责人会议（HIAM）汇集了所有国家情报机构的一个分组，以审议与澳大利亚对外情报活动有关的具体问题。会议由国家评估办公室主任主持，负责国防情报、安全和国际政策的副部长出席会议。

  

**政策实体**

**总理和内阁部**

国家安全和国际政策组隶属于总理和内阁部，由负责国家安全和国际政策的副部长领导，就澳大利亚的外交、贸易和条约事务、国防、情报、不扩散、反恐、执法、边境安全和应急管理事务提供建议；协调与安全有关的科学和技术研究事务；并在制定整个政府的综合国家安全政策方面发挥协调领导作用。国家安全和国际政策组由三个部门组成，每个部门由一名第一助理国务卿领导。

  

**国家安全顾问（NSA）**\[13\] 是2007年至2013年陆克文政府和吉拉德政府时期存在的一个职位，是国家安全和国际安全政策和协调的首席顾问。

  

国际司就澳大利亚的外交、贸易、援助和条约事务及优先事项提供建议、协调和领导，包括双边关系、与区域和国际组织的关系、自由贸易谈判和海外援助计划的整个政府优先事项。它还包括亚太、美洲和中东处以及北亚、多边和贸易处。

  

国家安全司就军事行动、国防战略、反恐和关键基础设施保护等领域的综合、整体政府政策事项、优先事项和战略提供建议、协调和领导。该司分为国防处和国内安全处。

  

网络政策和情报司就网络安全、网络恐怖主义和情报协调事务领域的综合、整体政府政策事务、优先事项和战略提供建议、协调和领导。该司分为情报处和网络政策处。

  

**总检察长部**

总检察长办公室是澳大利亚的首席执法办公室，负责国家安全问题的业务协调，协调国家安全和危机管理安排，海外保护性安全和基础设施保护，并为国家安全和反恐事务提供法律和立法建议\[14\] 。

  

国家安全复原力政策司是国家安全和刑事司法小组的一部分，负责与发展对所有危害的复原力有关的政策、立法、建议和方案，包括关键基础设施保护、电子和身份安全以及保护性安全政策等领域。

  

国家安全法和政策司是国家安全和刑事司法小组的一部分，负责国家安全政策、能力发展、立法改革和咨询，包括国家安全法、外国战士、反恐、电信拦截和监视法、化学、生物、辐射和核、安全关切的化学品和打击暴力极端主义等问题\[16\] 。

  

**外交和贸易部**

国际安全司是外交和贸易部的国际安全和外国情报政策和治理协调实体。它分为三个部门，每个部门由一名助理部长领导。

  

反恐处负责协调国际反恐政策和活动。该处由助理国务卿级别的反恐大使领导。

军备控制和反扩散处负责协调国际军备控制、裁军和不扩散政策。

战略问题和情报处就战略问题、外国情报和其他国际安全事务提供分析、研究和建议。

  

**国防部**

国防部秘书和国防军总司令办公室是澳大利亚国防组织的综合二级指挥部，由国防部秘书和国防军总司令组成。它支持澳大利亚国防组织的战略和管理，并保持情报和安全战略和协调功能：\[17\] 。

  

国际政策司就澳大利亚的国防关系和澳大利亚国防军的行动向政府提供战略层面的政策建议。

  

战略政策处对澳大利亚的战略环境进行分析，为国防决策提供依据，包括军事能力的发展和使用、澳大利亚国防军的使用、参与某些国际项目，如防扩散安全倡议和出口管制。

  

**主要实体**

**澳大利亚安全情报组织**

澳大利亚安全情报组织（ASIO）是澳大利亚的国家安全服务机构，其主要作用是收集信息和制作情报，以便能够就可能危及澳大利亚国家安全的活动或情况向政府发出警告。ASIO法案将 "安全 "定义为保护澳大利亚的领土和边境完整，使其免受严重威胁，并保护澳大利亚及其人民免受间谍活动、破坏活动、出于政治动机的暴力活动、促进社区暴力活动、对澳大利亚国防系统的攻击以及外国干涉行为。ASIO还包括反恐控制中心，该中心负责制定和管理反恐优先事项，确定情报要求，并确保收集和分发反恐信息的过程完全协调和有效。国家威胁评估中心也是ASIO的一部分，负责分析对澳大利亚海外利益的恐怖威胁以及澳大利亚境内的恐怖威胁和暴力抗议的威胁\[20\] 。

  

ASIO的国家威胁评估中心（NTAC）准备评估恐怖主义和抗议暴力的可能性和可能性质，包括针对澳大利亚、澳大利亚人和澳大利亚在国内和国外的利益、特殊事件和澳大利亚的国际利益。威胁评估支持各司法管辖区和机构做出风险管理决策，以确定如何最好地应对威胁和减轻风险\[21\]。

ASIO的商业联络股（BLU）为私营部门和澳大利亚情报界之间提供了一个渠道。它旨在为行业安全和风险管理人提供可靠的、有情报支持的报告，使他们能够向行政管理层和员工权威性地介绍情况，并利用这些知识进行风险管理和连续性计划。

反恐控制中心（CTCC）是位于ASIO内部的一个多机构机构，负责制定和管理反恐优先事项，确定情报需求，并确保收集和分发反恐信息的过程在澳大利亚的反恐活动范围内得到充分协调和有效。CTCC有来自ASIS、AFP、ASD和AGO的高级代表\[23\] 。

  

**澳大利亚秘密情报局**

澳大利亚秘密情报局（ASIS）是澳大利亚的海外秘密HUMINT收集机构，其任务是根据政府的指示提供独特的外国情报服务，以保护和促进澳大利亚的重要利益。ASIS的主要目标是获取和传播有关澳大利亚境外个人或组织的能力、意图和活动的秘密情报，这些情报可能会影响到澳大利亚的利益和公民的福祉\[24\] 。

  

**国家评估办公室**

国家评估办公室（ONA）作为一个直接对总理负责的独立机构，对国际政治、战略和经济发展进行全面评估，并向内阁国家安全委员会的其他高级部长和政府各部门的高级官员提供建议和评估。ONA根据自己的立法运作，负责协调和评估澳大利亚的外国情报活动。它的信息来自于其他情报机构，以及外交报告、其他政府机构的信息和报告，以及公开来源的材料\[25\] 。

  

ONA的开放源码中心（OSC）收集、研究和分析开放源码信息以支持澳大利亚的国家安全。根据ONA法案规定的ONA任务，OSC专注于影响澳大利亚国家利益的国际发展。它的主要客户是构成澳大利亚国家情报界的各个部门和机构\[26\]。

  

**国防情报与安全小组**

国防情报与安全集团是国防部的一个组织，负责协调情报、安全和其他战略政策。它分为四个子机构，其中以下三个机构是澳大利亚情报界的主要实体。

  

**澳大利亚地理空间-情报组织**

澳大利亚地理空间情报组织（AGO）是由澳大利亚图像组织、战略军事地理信息局和国防地形局合并而成的，旨在通过图像和其他来源提供地理空间情报，以支持澳大利亚国防军和国家安全利益。

  

**国防情报组织**

国防情报组织（DIO）是国家军事情报和情报评估机构，在国家安全层面提供服务和建议，其任务是支持澳大利亚国防军、国防部和澳大利亚政府及国家安全决策，并协助澳大利亚国防军行动的规划和实施\[28\] 。

  

**澳大利亚信号局**

澳大利亚信号局（ASD）负责收集、分析和分发外国信号情报，是通信、信息、网络和计算机安全方面的国家权威。ASD还包括网络安全行动中心，该中心负责协调和协助对具有国家重要性的网络事件的行动反应，并通过其入侵检测、分析和威胁评估能力，为政府提供对网络威胁的综合理解\[29\] 。

  

澳大利亚国防部的澳大利亚网络安全中心（ACSC）负责信息和通信技术的安全操作和协调。ACSC还识别和研究新出现的威胁，并提供分析能力和技术来应对网络犯罪、网络恐怖主义和网络战争。ACSC整合了ASD的网络安全职能、国防信息局和国防科技组织的网络职能、总检察长办公室的计算机应急小组、AFP和ACC的网络犯罪调查员，以及ASIO的电信安全专家。

  

**二级实体**

**澳大利亚陆军情报团**

澳大利亚陆军情报团（AUSTINT，AIC）是澳大利亚陆军的一个军团，作为澳大利亚国防军的主要军事情报单位，为国防情报和安全集团以及澳大利亚国防军的主要指挥部和参谋部提供人员。

  

**澳大利亚联邦警察**

澳大利亚联邦警察（AFP）是澳大利亚联邦警察的一个部门，隶属于总检察长部。它为所有业务职能和犯罪类型提供刑事情报和其他情报能力。该部门分为行动情报小组，收集、整理、分析和传播有关澳大利亚联邦警察感兴趣的全国性重大犯罪问题的情报。情报业务领域扩展到与人口走私、非法毒品、人口贩运和性奴役、金融犯罪、反恐、高科技犯罪和儿童色情旅游有关的犯罪。

  

情报处是澳大利亚联邦警察局的刑事情报和国家安全情报部门。情报处以项目为导向，在职能上涉及多个司法管辖区，利用澳大利亚联邦警察国家总部和相关外地办事处的能力。

  

澳大利亚联邦警察局的联合反恐小组（JCTT）在每个州和地区的管辖范围内运作，由澳大利亚联邦警察局、州和地区警察以及澳大利亚安全情报组织官员组成。联合反恐小组进行调查，以防止、应对和调查澳大利亚的恐怖主义威胁和袭击。

  

澳大利亚联邦警察局的澳大利亚炸弹数据中心（ABDC）是澳大利亚有关非法使用爆炸物的信息和情报的主要来源。ABDC于1978年7月1日正式开始运作，因此它是世界上最古老的炸弹数据中心之一。ABDC既关注那些为了自身利益而使用爆炸物的罪犯，也关注那些为了恐怖主义而使用爆炸物和炸弹的罪犯。它保留了向其报告的所有与炸弹有关的事件的记录，无论其设计、目标或动机如何。澳大利亚高科技犯罪中心的工作人员由澳大利亚联邦警察和澳大利亚国防军的成员组成。

  

澳大利亚高科技犯罪中心（AHTCC）是一个位于澳大利亚联邦警察局的全国性密码犯罪和网络安全组织，其工作人员来自ASIO和ASD。

  

**澳大利亚犯罪委员会**

澳大利亚犯罪委员会（ACC）是总检察长办公室下属的国家刑事情报和调查机构。它有一系列的法定职能，主要是收集和传播情报，以及对全国性的严重和重大犯罪进行刑事调查。反恐委员会建议国家刑事情报优先事项（NCIPs），与联邦、州和地区机构合作，并保持类似于皇家委员会的持续权力。反恐委员会制定打击严重犯罪的国家议程，为国家严重犯罪的优先事项提供解决方案，并保持国家刑事情报的领先能力。

  

**澳大利亚海关和边境保护局**

移民和边境保护部的澳大利亚海关和边境保护局（ACBPS）负责管理澳大利亚边境的安全和完整性。它与其他政府和国际机构密切合作，侦查和阻止货物和人员的非法越境流动。

  

澳大利亚海关和边境保护局的反恐小组（CTU）提供一线反应能力，在有国家安全利益的人试图越过边界时采取行动。反恐小组能够在澳大利亚各地迅速部署，以解决国家安全问题，并在其他边境风险出现时酌情处理，并且是一个指定的使用武力的组织。

  

ACBPS的情报部门负责评估对边境和海关的新的和正在出现的威胁，并提供情报和目标，为减轻风险提供信息和支持。该部门由情报分析与评估处和行动情报处组成。

  

ACBPS的国家边境目标中心（NBTC）是一个边境安全情报组织，其目的是针对高风险的国际旅客和货物，特别是非法物质和潜在的恐怖分子。NBTC包括来自澳大利亚联邦警察局、澳大利亚情报组织、澳大利亚反腐败委员会、澳大利亚联邦运输部、农业部和运输安全办公室的工作人员。

  

ACBPS的战略边境指挥部（SBC）是边境安全的正式指挥和控制实体，不同于边境保护指挥部。战略边境指挥部由调查、合规和执法处以及特别调查和方案处组成，并在新南威尔士州/ACT、维多利亚州/塔斯州、昆士兰州、西澳大利亚州和中部设有区域指挥部。

  

边境保护司令部是澳大利亚皇家海军和澳大利亚海关和边境保护局的联合司令部，为澳大利亚的近海海域提供安全保障。它结合了澳大利亚海关与边境保护局和澳大利亚皇家海军的资源和专业知识，并与澳大利亚渔业管理局和其他政府机构合作，为澳大利亚的近海海洋安全提供了一个协调的国家方法。

澳大利亚保障和不扩散办公室

  

澳大利亚外交和贸易部的保障和不扩散办公室（ASNO）负责保障和确保大规模毁灭性武器的不扩散。ASNO由澳大利亚保障监督办公室（ASO）、化学武器公约办公室（CWCO）和澳大利亚全面禁止试验办公室（ACTBO）组成。ASNO确保澳大利亚履行《核不扩散条约》（NPT）、澳大利亚与国际原子能机构（IAEA）签订的NPT保障协议、《核材料实物保护公约》（CPPNM）以及澳大利亚的各种双边保障协议规定的国际义务。澳大利亚核安全局在核领域有四个主要责任领域，即在澳大利亚实施保障措施，对澳大利亚的核物品进行实物保护和安保，澳大利亚双边保障协定的运作，以及对原子能机构保障措施的运作和发展以及加强国际核不扩散制度作出贡献。ASNO还确保澳大利亚履行《化学武器公约》（CWC）和《生物武器公约》（BWC）规定的国际义务，同时促进其在国际上的实施，特别是在亚太地区。ASNO还为《全面禁止核试验条约》（CTBT）和CTBTO筹备委员会做出贡献。

  

**运输安全办公室**

运输安全办公室（OTS）是航空和海运部门的保护性安全监管机构，也是澳大利亚的主要运输安全咨询实体。作为基础设施和区域发展部的一个实体，运输安全办公室与各州和地区、其他政府机构、国际机构以及航空和海运业合作，以改善安全并防止运输安全事件的发生。OTS开发和提供运输安全情报，运输安全政策和规划，以及运输安全法规和遵守。

  

**国防安全局**

国防情报和安全组的国防安全局（DSA）为国防部各组和澳大利亚国防军提供保护性安全事务的支持。国防安全局的职责包括制定和颁布符合澳大利亚政府保护性安全政策的安全政策，监测和报告安全合规性、绩效和风险，调查严重和复杂的安全事件，为国防和国防工业安全计划成员授予安全许可，并进行许可的重新确认和重新评估，协助各小组和各部门执行安全政策，并管理国防工业安全计划。

  

**犯罪追踪**

CrimTrac是隶属于总检察长办公室的国家刑事信息机构。它负责提供国家治安信息服务，开发和维护各州、地区和联邦执法机构之间的国家信息共享服务，整合犯罪情报，并为经认可的机构提供国家犯罪记录检查。CrimTrac开发、维护并提供国家自动指纹识别系统、国家刑事调查DNA数据库、国家儿童罪犯系统、儿童剥削跟踪系统、国家警察参考系统、国家火器许可和登记系统、国家利益车辆登记系统和国家警察检查服务。

  

**澳大利亚交易报告和分析中心**

澳大利亚交易报告和分析中心（AUSTRAC）是总检察长部下的国家金融情报机构。它负责收集有关洗钱、恐怖主义融资和重大金融犯罪的情报并加以监管。
