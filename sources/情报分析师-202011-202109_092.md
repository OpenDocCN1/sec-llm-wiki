**zoom**

  

功能：查看来自 NASA 卫星的国际云图像 - 每天更新

网址：https://zoom.earth/#view=13.486474,144.7938,15z

![](../Images/72ec10e918b3eb2d1b82f74b529f5630.png)

  

**corona**

  

功能：列出由美国发射并在 1960-1972 年间运行的 CORONA 间谍卫星收集的超过 800,000 张图像

https://corona.cast.uark.edu/atlas#zoom=2&center=1330616,1362413

![](../Images/ba1d1f42e6127e3e66bbeb5283e79e7f.png)

  

**wigle**

  

功能：全球 Wi-Fi 网络映射。除了可能提供免费 Wi-Fi 的可能位置之外，它还显示 Wi-Fi 网络名称和接入点 MAC（硬件）地址

网址：https://wigle.net/

![](../Images/98b2fff1a4b6f4ff82648c111510886a.png)

  

**bbbike**

功能： 比较两张地图，例如比较必应和谷歌地图的相同位置图，看看目标位置的差异

  

网址：https://mc.bbbike.org/mc/

![](../Images/0f63e8006f60feafd7f6ad2c00fa5544.png)

  

**yandexmap**

  

网址：https://maps.yandex.com/

![](../Images/6900924ee8eb361dca7a257130cd2a0b.png)

  

**点击小图标可以查看该地的固定街景图片**  

![](../Images/551af5fb4fd5b381e8fbf1cd105225a2.png)

  

**n2yo**

功能：来自不同卫星的直播。它还提供有关被跟踪卫星及其覆盖区域的信息

  

网址：https://www.n2yo.com/

![](../Images/5cf38a520c4b203e2113d4f634ea87c5.png)

  

**Digitalglobe**

功能：易于使用的全球地图图像工具，带有高级搜索过滤器

网址：https://discover.digitalglobe.com/

![](../Images/70777182c79a9dbca66544fb52aaea48.png)

  

**Bing**

网址：https://cn.bing.com/maps

![](../Images/7ca2d45a41e58ed8b001465bc02b380b.png)

  

**newspapermap**

功在：地图上列出全球所有报纸，您可以根据位置和报纸语言进行过滤

网址：https://newspapermap.com/#49.71878,38.14453,4z

![](../Images/7bf7db4d5f4f6671640f99fc0b0fe827.png)

**viamichelin**

功能：在世界地图上显示游客、餐馆、酒店、交通和天气

https://www.viamichelin.com/

![](../Images/8913d75ea4172d72a4dcd42b1f607d69.png)

  

**polymaps**

功能:一个 JavaScript 库，用于在现代 Web 浏览器中制作动态的交互式地图，并支持放置不同的视觉呈现

网址：http://polymaps.org/

![](../Images/30229b6426acd624880f002901cc8886.png)

  

**freemaptools**

  

功能：查找地图上某个点周围的半径

网址:https://www.freemaptools.com/radius-around-point.htm

![](../Images/a5b0b5d10ee15f0e0a8aeb91449182d0.png)

**maperitive**

功能：这是一款基于 OpenStreetMap 和 GPS 数据绘制地图的 Windows 软件

http://maperitive.net/

![](../Images/be68eea46f2b6d0d728829807edb3f9e.png)

**maphub**

功能：通过添加点、线、多边形或标签以及自定义背景来创建交互式地图

  

https://maphub.net/explore
