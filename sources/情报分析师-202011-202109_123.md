# 蒂格雷冲突：马赫贝雷 · 德戈大屠杀的新细节

（原文作者：Giancarlo Fiorella   翻译校对：BB）

今年早些时候，我们与Newsy和BBC非洲之眼合作，对5段视频进行了地理定位，这些视频显示，在埃塞俄比亚蒂格雷地区的一个城镇马赫贝雷德戈附近，身着军装的人处决了平民。

  联合调查的结论是，大屠杀很可能发生在2021年1月的某个时候。录像中的士兵们讲的是阿姆哈拉语、埃塞俄比亚的行政语言和阿姆哈拉人民的母语。录像中至少看到一件军装，还显示埃塞俄比亚国旗的标记。

  2021年6月16日，社交媒体上出现了新的画面，显示士兵在悬崖边处决平民。对这段新录像的分析表明，这是我们以前报道的同一大屠杀的一部分。

  还可以从新素材中收集更多详细信息。在录像中看到一名士兵执行死刑的一块补丁上印有与最初录像中相同的埃塞俄比亚国旗颜色和标记。似乎正在录制录像的人还陈述了其所属的军事单位的名称。

  

![](../Images/fa24caaab03577327586c38d1f51c55c.png)

埃塞俄比亚蒂格雷地区的地图

  

  自去年11月以来，蒂格雷的冲突愈演愈烈，使该国联邦军队与蒂格雷人民解放阵线（TPLF）对峙。此后，它从邻国厄立特里亚的军队以及埃塞俄比亚阿姆哈拉地区到南部的亲政府民兵中抽调。

  数百万人流离失所，严重侵犯人权，包括处决、性暴力和强迫流离失所的情况被广泛报道。

  随着埃塞俄比亚走出激烈的选举期，该地区局势进一步升级——本周，埃塞俄比亚空军轰炸了蒂格雷的一个市场。

  

**马贝雷·德戈大屠杀**

  

  我们先前对马赫贝雷德戈大屠杀的调查得出结论，这五段录像是在蒂格雷地区马赫贝雷德戈镇（ማሕበረ ደጎ）以南的两个不同地点录制的。我们通过视频五标记了这些视频。虽然视频一至四是在执行处决的悬崖边拍摄的，但第五录像是在处决地点东北方约一公里处的一块田野里拍摄的。 

  

![](../Images/be45203ca5be0141fabc4a090cbbc808.png)

  

**新的视频**

  

  2021年6月16日，美国支持蒂格拉扬的新闻频道Tigray Media House（TMH）首次在网上分享了马赫贝雷·德戈附近的新录像。总共有大约1分38秒的额外镜头显示在悬崖边执行死刑的内容。Tigray媒体之家声称，这段录像与我们之前报道的马贝雷·德戈大屠杀有关。我们的分析证实了这一说法。

  根据新录像中的尸体数量，很可能在同一处决期间早期记录下来。新的录像包含的线索，不仅将其与原来的五个马贝雷德戈大屠杀视频联系起来，而且还可能提供更多的证据，说明谁犯下了杀人罪。 

  新镜头中可见的地理特征与我们上次调查中强调的地理特征相符。这些不仅包括悬崖，还包括视频左侧的岩层。

  原始视频和新素材在质量上存在显著差异。这是因为原始视频的格式差异，我们发现高分辨率的副本和新的视角，是我们从YouTube中发现的。这种质量差异与新素材的地理位置无关紧要。

  新的录像还进一步瞥见了至少一名执行处决的士兵肩上埃塞俄比亚国旗的颜色。

  在以前的调查中，我们强调了另一名士兵身上的类似标记。第五段视频中的一名士兵肩上似乎有同样的国旗补丁，上面印有埃塞俄比亚国旗的颜色。

  通过拆分和调整色道和增加视频中帧对比度的过程，我们能够增强显示标志补丁的图像中的颜色。

  正如我们在以前的调查中指出的，最近的开源图像显示，埃塞俄比亚武装部队现役军人目前佩戴了显示国旗的袖标徽章。 

  

**新的音频线索和新的调查线索**

  

  据俄勒冈大学的埃塞俄比亚翻译和传播学者古拜·冈达尔特·贝耶内说，我们咨询了视频中可以听到的谈话，录制录像的士兵称自己为法菲（ፋፊ）。

  在视频中，Fafi 将受害者称为"Woyane"（阿姆哈拉语：ወያኔ，蒂格里尼亚语：ወያነ），正如我们在上一出版物中解释的那样，这是一个绰号，大致翻译为"叛乱"，现在被用作被认为与提格雷人民解放阵线（TPLF）有联系的人的贬义词。法菲还说，他属于"第25师第1旅"。(25ኛ ክፍለጦር፣ 1ኛ ብርጌድ)但是我们无法证实这一特定信息。然而，据报道，蒂格雷地区部队的一名发言人在2月份说，他们伏击并打击了埃塞俄比亚国防军第25师的第二和第三旅。

  我们联系了埃塞俄比亚总统办公室以及埃塞俄比亚驻华盛顿和伦敦大使馆，要求对这个故事的细节发表评论，并询问在提格雷冲突期间，埃塞俄比亚军队第25师、第1旅或任何其他师是否曾在马赫贝雷德戈或附近。

  

  埃塞俄比亚驻伦敦大使馆告诉我们，它已将贝我们的请求转交"亚的斯亚贝巴相关官员"，但在公布之前没有收到答复。我们将与纽西继续努力核实据称与马贝雷·德戈大屠杀有关的录像。
