# 最终用户意图的发展和决定因素:专家系统的使用

     本研究旨在通过提出一个研究模型来预测最终用户对专家系统的意图和使用，该研究模型扩展了技术接受和使用统一理论的基本组成部分，包括专家领域、感知相关性、可靠性、专家系统质量和管理支持等直接和间接影响最终用户使用专家系统意图的其他相关因素。

介绍  

     专家系统是能够执行专门任务的计算机程序组sks基于对人类专家如何执行sa me的理解纽sks(叶和约翰逊，1995)。专家系统包括知识库、推理机、解释模块和用户界面。这些组件用于模拟专家决策扯ing (Yoon，Guimaraes，和奥尼尔，1995)。专家系统的独特之处在于，它们通常被开发来帮助做出非结构化的决策。

       随着企业在技术上投入大量资金以提高决策的效率和有效性，企业评估回报的需求也在增加。随着对分析大数据以做出更好的业务决策的关注，对专家系统的需求越来越重要，特别是那些与认知计算相关的专家系统，以获得有用的见解。据估计，到2020年，全球文本分析市场可能达到65亿美元，北美预计将成为最大的区域市场(爱迪生，2018年)。由于公司继续投资于专家系统技术，信息技术人员了解影响接受和使用专家系统技术的因素变得更加重要(Yoon，Guimaraes和O'Neal，1995)。对这些因素的理解加快了专家系统的实施和使用，世界经济论坛的创始人克劳斯·施瓦布总结了专家系统的结果，“过去，大的吃小的，现在是快的吃慢的，我每天都看到它。”(乔杜里，2017年)。

最终用户感知的外部影响  

       戴维斯(1989)提出，他的原始模型可以通过增加外部变量来扩展，这些外部变量可能直接或间接影响影响最终用户态度和意图发展的感知。当最终用户对变量很少或没有控制时，变量被认为是外部的(文卡特什和戴维斯，2000)。当用户接受新工作或在公司内更换工作时，他们可能会继承专家系统。为了便于理解外部因素对最终用户感知的潜在影响，必须熟悉组织使用的专家系统。在这项研究中，开发了衡量感知相关性程度、高层管理支持和组织内专家服务领域的量表。将这些因素作为外部变量进行衡量，将有助于调查对最终用户的感知是否存在直接或间接的影响，最终用户的感知决定了他们对在组织内使用专家系统的态度。

方法学  

      用SPSS和LISREL软件包进行分析。SPSS用于计算频率、均值、标准差、信度系数和主成分分析。采用验证性因子分析方法对主成分分析中确定的因子负荷进行验证。该验证以测量模型的形式进行，该模型由研究模型确定的六个因素组成。然后运行一个结构模型来测试研究模型和假设。扫描电镜软件包LISREL用于进行终审法院。根据科雷和李(2013年)提供的指南检查了因子载荷。四个拟合指数用于评估测量模型和结构模型的拟合优度。前三个指数，即标准拟合指数(NFI)、非标准拟合指数(NNFI)和比较拟合指数(CFI)，预计将超过0.9，表明拟合良好。

 数据分析

       初始测量模型与研究数据不太吻合，最终测量模型中包含了一些微小的修改。最初被确定为有问题的构造是专家系统领域，因此被排除在进一步分析之外。测量模型得到了确认，因为所有三个拟合指数都符合接受模型所引用的标准。使用扫描电镜的测量和结构模型，结果为NFI (0.98)，国家营养不良指数(0.98)和消费者价格指数(0.99)超过了0.9。

结果  

     除了H6(从感知质量到态度的路径)外，Hl-H7在0.01或更低时显著(图2)。关于两个外部变量(感知相关性和最高管理层支持)，HBa、H9a、HI1a、H9b和HI1 b在0.01或更低时显著。只有一个假设(H12b)达到0.05的显著性水平。最后，两个假设(HBb和HJOa)达到了0.10的显著性水平。在十七个提出的假设中，只有三个被发现是不重要的(H6:从感知质量到态度的路径；HIOb:从高层管理支持到绩效预期的路径；和H12a，从感知相关性到感知质量的路径)。模型中由标准化路径系数表示的最强关系是意图和使用之间的关系(0.98)，其次是可靠性和质量之间的关系(0.80)，然后是努力期望和态度之间的关系(0.68)。

讨论和影响  

      这项研究的结果在许多方面证实了以前使用UTAUT的研究结果(Alshare等人，2011；Alshare等人，2015年；Dwivedi等人，2017年；Palos-Sanchez等人，2017年；文卡特什和张，2010。)意向受最终用户态度的影响，强烈影响最终用户对专家系统的使用。努力期望比绩效期望对态度的影响更大。最终用户正在寻找一种更加用户友好、易于使用和学习的类型。系统的有用性。感知相关性通过绩效期望和努力期望对意向产生直接影响，对使用专家系统的态度产生间接影响，绩效期望和努力期望都对态度产生直接影响。高层管理支持通过努力期望对意向产生直接影响，对态度产生间接影响。

帕洛斯-桑切斯等人(2017)的研究与当前的研究论文一致，声称高层管理对使用专家系统的意图产生影响。然而，目前这部分研究的结果与艾哈迈德等人(2017年)的结果不一致。

对从业者和研究人员的启示  

       为了影响最终用户对专家系统的使用，管理层需要通过对专家系统的使用建立积极的态度并使专家系统的使用与他们的工作更相关来影响他们的意图。一个积极的态度可以通过关注努力期望和管理层更多的支持来建立，这也会影响努力支出尥西。本研究的结果为专家系统开发人员提供了关于影响最终用户意图和专家系统使用的因素的见解。通过了解影响专家系统用户的重要因素，专家系统开发人员可以在开发过程中考虑这些因素扫通用电气和售后服务。

研究的局限性  

       使用自我报告的量表来测量研究变量增加了常见方法偏差的可能性。由于研究调查是以在线方式进行的，这限制了研究人员评估其他方法的能力，而这些方法可以增强分析结果。最后，报道的领域主要包括服务和健康公司。征求其他行业(制造、医疗、软件等)的回应。)可以帮助区分可能对态度、意图和使用有更大影响的因素。这将有助于制定针对这些领域的激励计划和工作结构。这项研究的结果集中在企业管理的专家系统，特别是服务和健康公司，因此，这些结果应该在这样的背景下进行解释。

 结论  

       本文研究了影响最终用户意图和专家系统使用的因素。在这项研究中，我们提出了一个基于UTAUT的概念模型，并进行了实证检验。使用LISREL的结构方程模型，通过对美国不同商业部门的最终用户进行随机抽样，对测量和结构模型进行了测试。大多数提出的假设都得到了有力的支持。该模型建立在个人对专家系统的态度影响其使用专家系统的意图，进而影响实际使用的前提之上。
