# 用户对隐私保护行为的持续行为意向研究

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650483106&idx=2&sn=74a8751b147d1d026e2c0f5f89ab8aa1&chksm=871607e9b0618eff68ca56ccffd93199466555510c66039fff4fc6edee1521dd77c94b66885f&scene=126&sessionid=1681267486#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650483106&idx=2&sn=74a8751b147d1d026e2c0f5f89ab8aa1&chksm=871607e9b0618eff68ca56ccffd93199466555510c66039fff4fc6edee1521dd77c94b66885f&scene=126&sessionid=1681267486#rd)

      先前对隐私保护行为的研究发现，在线用户不合理地以保护换取便利，从而违背自己的隐私偏好。本文使用期望确认理论模型来解释在线用户对隐私保护实践的持续行为意向。它重新定义了便利性，以突出在实施隐私实践过程的各个阶段中涉及的人类行为。结果表明，早期的隐私实践经验影响着用户现在和未来的保护行为，而便利导向是人性的一个重要方面，不应被复杂的隐私实践所抑制。因此，为了更好地为在线用户服务，研究者和实践者在构建他们的隐私实践时都应该考虑在线用户对便利性的个人感知。

介绍

       许多在线用户对隐私有强烈的意见，并陈述他们的隐私偏好，但他们并不总是表现一致。在线用户，拥有很高的隐私偏好，很容易忘记保护他们的隐私信息。为什么一些在线用户的行为方式不同于他们的隐私偏好？先前的研究集中在评估在线用户陈述的隐私偏好。洪和Thong (2013)证明了用于衡量隐私偏好的项目的不同措辞可能导致在线用户的行为与隐私关注之间的不一致。在线用户总是表现出更高水平的隐私问题，这是由个人期望来衡量的(洪&童，2013)。期望测量受到“说话很便宜”问题的困扰，因为个人几乎不需要花费什么就能获得对其隐私的更大保护。事实上，大多数在线用户不会按照他们的隐私期望行事。

理论背景  

       进行了大量的研究来研究技术的接受和使用，其中大部分集中在对技术的初始接受的评估上(文卡特什，戴维斯和莫里斯，2007)。后来，有证据表明最初用户的接受和有经验的用户的继续使用之间的差异(卡拉汉纳，施特劳布，和切瓦尼，1999；文卡特什&莫里斯公司，2000年)。因此，一个在线用户随着时间的推移对技术使用的反应不能仅仅用接受模型来解释。源于心理学的期望确认理论被引入技术采纳研究，以解释用户在接受后阶段的反应为何以及如何变化。例如，Bhattachejee(2001)将ECT应用于广泛使用的技术接受模型(TAM戴维斯，1989；Venkatesh等人，。2003)建立了关注接受后感知的信息系统持续模型。对后验评估的理解是信息系统领域的一个热门话题(Bhattacherjee & Premkumar，2004；布朗，文卡特什和戈亚尔，2014)。对于信息系统的使用，接受后的期望比接受前的期望更重要，因为所有的组织都希望长期使用，以降低用户流失和寻找新用户的成本。本文建议实施隐私保护实践(例如，。密码、隐私声明和隐私封条)处于接受后阶段。

研究方法  

        一个3×3的受试者间析因实验被用来检验假设。设计的第一个因素涉及对隐私实践的自我参与角色的三个层次的操纵(低自我参与、中等自我参与和高自我参与)。设计的第二个因素涉及三种信息类型条件(低灵敏度信息、中灵敏度信息和高灵敏度信息)。受访者被随机分配到九个场景中的一个。在场景曝光后，每个受访者都参加了一项在线调查，询问他或她对场景中隐私做法的态度。

       本研究通过使用不同的密码策略来操纵隐私实践的自我参与角色的水平。使用这一程序可以避免受访者对不同隐私保护实践的不同体验(例如。隐私声明或隐私窃取),并强调人类行为在隐私实践的创建和使用过程中的重要性。如图2所示，具有低自我参与角色的密码策略很简单，需要较少的人工行为。相比之下，中度自涉和高度自涉密码策略包含更多要求和人类行为。这些操作还意味着回答者将场景与他们以前的密码使用经验联系起来。

结果  

        首先检查所有受访者的结构模型和信息敏感度级别。x气测试图1所示模型的结果是342.66，有144个自由度。消费物价指数为0.971，RMSEA为0.063.所有指标表明，整体结构模型相当合适。

       结构系数估计。表3和图3总结了标准化的结构参数估计。结构模型假设自我参与角色对感知有用性和感知便利性有相反的影响。这些假设得到了支持。自己参与角色对感知有用性有显著的正向影响(Y=0.386，p < 0.001)和显著的负面影响(y = -0.342，p < 0.001)。与预期一致，感知有用性和感知便利性都显著影响满意度。感知有用性(P = 0.656，p <0.001)比感知便利性(P = 0.498，p <0.001)具有稍微更积极的影响。此外，在感知的便利性和感知的有用性之间存在显著的、负面的、直接的影响(P = -0.170，p = 0.002)。

       此外，满意度对隐私保护实践的持续意向有显著的正向直接影响(P = 0.735，p < 0.001)。此外，正如预期的那样，在线用户对隐私实践的持续意图不受他或她的感知的直接影响。

讨论  

       这项研究的目标是辨别为什么在线用户的行为不符合他们的隐私偏好。在线用户对隐私保护实践的行为意向可以用当前研究建立的延续模型来解释吗？决定在线用户行为意向的变量有哪些？这项研究的结果表明，在线用户的隐私保护行为不是不合理的，可以预测。

       最后，研究结果显示，仅对于社交媒体账户，感知便利对感知有用性有直接影响。差异的一个可能原因是在线用户访问这些帐户的频率。例如，在线用户可能一天多次访问社交媒体帐户，而他们仅在必要时才登录论坛帐户。在线用户可能会认为登录和退出频率的增加更有可能暴露他们的信息。他们可能会认为存在失控的变量，即使他们遵循了所有的准则，也有可能访问他们的信息。在线用户希望花费更多的时间和精力来保护他们的信息，以减少频繁暴露的威胁。因此，当一个在线用户频繁访问一个帐户时，用户会不知不觉地牺牲部分便利来增强隐私保护。

含义  

       本研究的结果支持自我参与角色对个体感知的影响。理解自我参与角色是一个可以产生在线用户感知的、经过良好测量的结构是非常重要的。从在线用户的角度来看，如果个人对流程有更多的影响，并且由于可用性较低而感觉不太方便，那么他们相信可以提高性能。研究人员应该考虑个人对保护性技术的看法以及在线用户看法背后的变量。

       这项研究认为，使用在线账户的频率有可能成为一个相当大的变量，可能会影响在线用户的看法。便利性的影响与在线用户对实践有用性的感知没有很大关系。与以前的研究不同，目前的研究发现，在线用户只相信提高保护，以换取他们经常访问帐户时失去的便利。未来的研究应该检查访问的频率，以获得更多关于在线用户对隐私保护实践的看法的见解。

**局限性**

       这篇论文有几个局限性。首先，本科生样本可能会限制调查结果的普遍性；然而，在线人口主要由年轻一代组成。了解他们的行为很重要。未来的研究可以包括所有年龄的在线用户样本，并考察年龄对感知有用性和便利性的影响。

       第二，在目前的研究中，使用密码策略只是研究在线用户对所有隐私做法的行为的一种方式，尽管密码是典型的隐私做法，包括人类行为，容易被操纵。进一步的研究可以考察在线用户在不同实践环境下的感知。

       第三，常用方法方差可能威胁本研究的有效性。这项研究通过使用发展良好的量表降低了威胁的可能性，该量表由哈曼的单因素测试(Podsakoff等人，。2003)和匿名问卷。在哈曼的测试中，五个潜在变量的所有项目都没有通过探索性因素分析加载到一个因素上，这表明通用方法方差不是一个主要问题。未来的研究可以使用不同的方法来测量潜在的变量，例如测量实际的隐私行为而不是意图。

       最后，除了自我参与角色之外，还有其他属性会产生在线用户对隐私做法的看法。未来的研究可以在延续模型中加入更多的属性来研究在线用户的隐私保护行为。
