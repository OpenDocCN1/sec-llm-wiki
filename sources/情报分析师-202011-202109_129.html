帕洛阿尔托网络

网址：https://www.fireeye.com/blog/threat-research.html fireeye

传统上，公司已部署多种产品来满足其安全的远程劳动力需求，例如 Web 网关、下一代防火墙、安全虚拟专用网络、云访问安全代理(CASB) 解决方案、SD-WAN 等。这些不同的产品带有自己的策略管理和日志记录，从而增加了管理成本，并可能导致整个公司的安全状况出现差距。由于组织要求其用户无论身在何处都需要不间断、安全的访问，因此需要一种新的网络和安全方法。

这种新方法是安全访问服务边缘 ( SASE )。SASE 将软件定义的广域网 (SD-WAN) 和安全服务——防火墙即服务(FWaaS)、安全 Web 网关(SWG)、CASB 和零信任网络访问(ZTNA)——融合到一个单一的云交付服务中. 无论用户、应用程序或设备位于何处，SASE 都解决了提供一致、安全访问的挑战。由于它是单一服务，SASE 显着降低了复杂性和成本。
