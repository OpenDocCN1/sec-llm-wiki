无论是专业的计算机技术人员还是一般的普通用户，都可能遇到存储数据丢失的情况，带来各种麻烦甚至造成巨大损失。

万一误删或者丢失该怎么办呢？

数据恢复原理


硬盘数据恢复的原理主要是将删除的数据进行重新的组合，让它从之前“为空”状态转变为“显示”的状态。

更专业的讲，是指当计算机存储介质损坏，导致部分或全部数据不能访问读出时，通过一定的方法和手段将数据重新找回，使信息得以再生的技术。数据恢复技术不仅可恢复已丢失的文件，还可以恢复物理损伤的磁盘数据，以及不同操作系统的数据。数据恢复是计算机存储介质出现问题之后的一种补救措施，它既不是预防措施，也不是备份。

数据恢复软件

■ DiskGenius

DiskGenius，它是一款专业级的数据恢复及硬盘分区管理软件。它支持多种情况下的文件丢失、分区丢失恢复；支持文件预览；支持扇区编辑、RAID恢复等高级数据恢复功能。此外还有分区备份、分区还原、分区复制、磁盘复制等功能。

比起其他软件来说，DiskGenius更加全面、专业，同时它也是一款强大的硬盘分区工具和备份、还原工具。

最为重要的是，DiskGenius有绿色安全、免安装、免注册的版本可以使用，方便快捷，也是最为推荐大家使用的文件恢复软件。

金山数据恢复包括删除文件恢复、误格式化恢复、病毒感染丢失文件恢复、U盘/手机相机卡恢复、误清空回收站恢复、磁盘分区丢失恢复以及手机内置卡恢复等，可以恢复多种格式文件，包括文档、视频、照片、软件、压缩包等等。但对用户是有要求的，必须是付费会员才可以，遇到紧急情况需要处理可以去某宝买一个会员账号。

 WindowsFile Recovery

■  Windows File Recover是一款微软官方推出的免费命令行数据恢复软件，支持多种文件系统（比如NTFS、exFAT、FAT、ReFS），可对多种文件格式（比如照片、视频、文档等等）进行恢复。

Windows File Recovery支持三种恢复模式，各模式使用场景如下：

普通模式：用于最近删除过的文件恢复，支持文件格式为NTFS。

分段模式：用于恢复已删除一段时间的文件，或者对已经格式化过的磁盘执行恢复操作。

签名模式：针对FAT、exFAT、ReFS等文件系统恢复，此外如果其他恢复模式不顺利，也可用这个模式试一试。

恢复过程视文件多少而定，通常会有几秒或几分钟时间。命令完成后，将在目标磁盘上建立一个恢复文件夹（自动建立），所有恢复文件会被放置到这里。此外软件还会在恢复完毕后生成一份恢复报告，当然你也可以选择不生成。
