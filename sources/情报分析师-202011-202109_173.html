大数据背景下的网络舆情监控面临的挑战

大数据背景下，虽然改变了人们的生活方式、生产方式，获取信息数据的途径更加多样化，更加及时。但也使得网络舆情环境更加复杂，大大提升了网络舆情管理的难度。比如：如何有效处理海量数据、如何选择性的传播积极向上的信息、如何有效分散舆论话语权等，都是大数据背景下才出现的挑战，使得传统网络舆情监控系统已经无法满足实际要求，急需研究出更加先进、科学的网络舆情监控系统。在互联网中数据具有无限蔓延的特性，但网民所关注的能力是有限的，这二者之间存在较大矛盾，进一步提升了网络舆情监控的难度。此外，社会化媒体也使得信息传播速度更快，一些偏激的言论、观点在互联网上很容易找到“同类”，不断壮大，加剧了不良思想、不正确观念的传播速度和影响范围。总而言之，在大数据背景下，很多数据在网络上唾手可得，致使网络舆情监控管理的难度大幅度提升。

基于大数据的网络舆情监控系统

通过基于大数据的网络舆情监控系统，可将互联网中很多信息数据汇总到数据库中，构建全文索引，并对汇总的数据信息进行威胁度评估，并划分威胁等级，然后绘制图表进行直观清楚的呈现。基于大数据的网络舆情监控立足于Eclipse 集成化网络开发工具，通过 Java 语言，采用 B/S 架构，选择 TCP/IP 联合协议等，开发设计出 Bootstrap 风格的前台网页。并利用先进的 Spring+SpringMVC+MyBatis 的后台框架对网络舆情监控系统中的各项业务进行集中处理，通过先进的 Scrapy 式的爬虫框架，对互联网中舆情数据进行分秒级评估，并且还具有数据备份、存储及迁移的作用。为更好的管理数据库，数据管理系统采用了 Myspl5.7 版本，互联网中大数据一经发布，通过该系统就可能快速准确检索，同时融合了 ECharts 和 D3 可视化工具，可自动形成图表，清晰直观的显示各种数据。


系统功能模块的功能

数据信息采集模块还要具有以下功能：第一，构建一个网络舆情关键词库，并对关键词库中每个关键词进行循环检索，剔除无关数据，保留有效数据，通过自定义的方式，对网络舆情相关信息进行采集。第二，在进行个人信息采集时，需要获取个人发送内容的时间、信息等。第三，网络爬虫采取重点是在某一特定时间内，获取网络用户的各项信息，并将采集到的结果进行数据结构化存储，在采集过程中，可自主定义采集开始时间和停止。

如何运用大数据舆情系统进行公安情报收集

1、建立健全开源情报“信息工作基础化”改变过去搜集公安情报的被动方式，将大数据应用到收集情报工作中来，在相关的人员信息、场所信息、物品信息等方面收集信息。

2、加强开源情报网站信息共享突破信息接入。

3、及时进行相关信息查询。通过互联网舆情监测软件，设定所需监测的目标关键词，系统能够实时、全面、准确获取互联网中相关信息，自动对关注的目标进行跟踪监测。


提高情报大数据分析与技术开发能力

大数据分析与情报分析都是以数据挖掘为基础，即从数据中萃取情报的过程。针对庞杂丰富的信息资料，只有进行整序、浓缩并从中提炼有价值的情报信息才能发挥出其最大的价值。可通过分类、数据聚类、众包、数据融合和集成等技术，整合、处理、管理和分析。
