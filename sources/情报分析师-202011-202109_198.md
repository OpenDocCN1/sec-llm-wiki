# 基于推特情感分析的股票预测

# **摘要**

本文应用情感分析和机器学习原理来寻找“公众情感”和“市场情感”之间的相关性。我们使用推特数据来预测公众情绪，并使用预测的情绪和前几天的DJIA值来预测股市走势。为了测试我们的结果，我们提出了一种新的财务数据交叉验证方法，并使用自组织模糊神经网络对2009年6月至2009年12月期间的推特订阅源和DJIA值进行了验证，获得了75.56%的准确性.我们还基于我们的预测值实施了一个幼稚的投资组合管理策略。我们的工作基于博伦等人的著名论文，该论文以87%的准确率预测了相同的结果。

# **1. 介绍**

长期以来，股市预测一直是一个活跃的研究领域。有效市场假说(EMH)指出，股票市场价格很大程度上是由新信息驱动的，并遵循随机游走模式。虽然这一假设被研究界广泛接受为管理市场的核心范式，但一些人试图提取股票市场行为和对外部刺激反应的模式。

在本文中，我们检验了一个基于行为经济学前提的假设，即个体的情绪和情绪影响其决策过程，从而导致“公众情绪”和“市场情绪”之间的直接关联。我们对公开的推特数据进行情感分析，以找到公众的情绪和隶属度，分为4类——平静、快乐、警觉和善良(有点像模糊隶属)。我们使用这些情绪和前几天的道琼斯工业平均指数(DJIA)值来预测未来的股票走势，然后在我们的投资组合管理策略中使用预测值。

相关工作我们的工作基于博伦等人的策略\[1\]，该策略最近得到了媒体的广泛报道。他们还试图通过测量推特上人们的情绪来预测股市的行为。作者考虑了2008年所有推特用户的推特数据，并使用意见查找器和谷歌情绪状态简档(GPOMS)算法将公众情绪分为6类，即平静、警觉、确定、重要、善良和快乐。他们通过比较其检测公众对2008年总统选举和感恩节的反应的能力，交叉验证了由此产生的情绪时间序列.他们还使用因果关系分析来研究这样一个假设，即公众情绪状态(由民意调查工具和通用公共管理系统情绪时间序列测量)可以预测DJIA收盘价的变化。作者使用自组织模糊神经网络来预测DJIA值。他们的结果显示，在预测道琼斯工业指数(DJIA)收盘时的涨跌变化时，准确率高达87%。

论文的其余部分组织如下。第二部分简要讨论了我们解决问题的一般方法，接下来的部分更详细地讨论了各个组件。在第3节中，我们简要讨论了本文所使用的数据集以及所采取的数据预处理措施。第4节讨论了我们为本文开发的情感分析技术。第5节详细介绍了使用我们的情感分析结果预测DJIA值的不同机器学习技术，并介绍了我们的发现。在第6节中，我们使用预测值并设计一个天真的策略来维持一个有利可图的投资组合。
