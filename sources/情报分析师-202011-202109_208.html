搜索引擎

Search Engines



所谓搜索引擎，就是根据用户需求与一定算法，运用特定策略从互联网检索出制定信息反馈给用户的一门检索技术。搜索引擎依托于多种技术，如网络爬虫技术、检索排序技术、网页处理技术、大数据处理技术、自然语言处理技术等，为信息检索用户提供快速、高相关性的信息服务。搜索引擎技术的核心模块一般包括爬虫、索引、检索和排序等，同时可添加其他一系列辅助模块，以为用户创造更好的网络使用环境。



01

普通搜索引擎

General Search

普通搜索引擎是指根据一定的策略、运用特定的计算机程序从互联网上采集信息，在对信息进行组织和处理后，为用户提供检索服务，将检索的相关信息展示给用户的系统。搜索引擎是工作于互联网上的一门检索技术，它旨在提高人们获取搜集信息的速度，为人们提供更好的网络使用环境。普通搜索引擎就是正常的搜索引擎，百度、谷歌、会搜都是。

推荐

谷歌搜索引擎：www.google.com

BING搜索引擎:https://cn.bing.com



02

元搜索引擎

Meta Search

元搜索引擎适用于广泛、准确地收集信息。不同的全文搜索引擎由于其性能和信息反馈能力差异，导致其各有利弊。元搜索引擎的出现恰恰解决了这个问题，有利于各基本搜索引擎间的优势互补。而且本搜索方式有利于对基本搜索方式进行全局控制，引导全文搜索引擎的持续改善。

推荐

ISEEK搜索引擎:http://iseek.com/iseek/home.page

BIZNAR搜索引擎:https://biznar.com/biznar/desktop/en/search.html



03

代码搜索引擎

Code Search

代码搜索引擎是网站内部常用的检索方式。本搜索方式指在对网站内信息整合处理并分目录呈现给用户，但其缺点在于用户需预先了解本网站的内容，并熟悉其主要模块构成。总而观之，目录搜索方式的适应范围非常有限，且需要较高的人工成本来支持维护。

推荐

PUBLICWWW搜索引擎:https://publicwww.com

SEARCHCODE搜索引擎:https://searchcode.com



04

FTP搜索引擎

FTP Search

FTP（File Transfer Protocol，文件传输协议） 是 TCP/IP 协议组中的协议之一。FTP协议包括两个组成部分，其一为FTP服务器，其二为FTP客户端。其中FTP服务器用来存储文件，用户可以使用FTP客户端通过FTP协议访问位于FTP服务器上的资源。利用服务器管理工具，远程登陆ftp，实现两台计算机甚至多台计算机之间的数据、文件共享的功能，多用于文献学习，影视剧分享等。ftp拥有巨大的信息传输路径，所以当下人对其使用率非常之高的。

推荐

GLOBALFILESEARCH搜索引擎:https://globalfilesearch.com

SEARCHFTPS搜索引擎:https://www.searchftps.net



05

全文搜索引擎

Academic / Publication Search

一般网络用户适用于全文搜索引擎。这种搜索方式方便、简捷，并容易获得所有相关信息。但搜索到的信息过于庞杂，因此用户需要逐一浏览并甄别出所需信息。尤其在用户没有明确检索意图情况下，这种搜索方式非常有效。

推荐

PUBPEER:https搜索引擎:https://pubpeer.com

BASE-SEARCH搜索引擎:https://www.base-search.net/Search/Advanced



06

新闻搜索引擎

News Search

新闻搜索引擎新闻源，顾名思义，搜索引擎的新闻来源，搜索引擎经常光顾，采集新闻和相关行业信息的地方。对于一个专业的SEOer来说，了解和认识搜索引擎新闻源是很必要也是很重要的，为什么搜索引擎会把这些站点或者报刊作为新闻源呢？这些站点和报刊都具有一定的权威性，他们消息来源具有准确，即时，可靠等特点。

推荐

THEPAPERBOY搜索引擎:https://www.thepaperboy.com

FLIPBOARD搜索引擎:https://flipboard.com



07
