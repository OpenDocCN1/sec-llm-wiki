# 古代朝廷是如何保密的？从唐代保密制度探析如何保护国家机密

在信息化高度发达的当今世界，网络成为了窥视信息的鹰眼，国家机密的保护对于民生，军事，经济等等方面至关重要。而千年以前，中国古代社会王朝更替，大小国家分立，但生产力相对较为低下的时代，是否就不需要对国家机密进行保护呢？  

实际上，自进入封建社会以来，保密制度的发展就从未中断，在大唐得以完善，成为了后世的典范。于大唐而言，完备的保密制度和泄密惩罚措施，更是促进了这一庞大帝国的进一步发展，使得万国来朝的唐朝在一定的时期内都保持着至高地位，在保护国家安全的同时更影响着社会的方方面面。

![](../Images/6a532687871678b8c53db506f7850ccd.png)万国来朝

强大李唐缔造完善的保密制度

1\. 兴盛的大唐王朝

历史发展具有必然性和偶然性，唐朝在封建社会历史中占据的位置和时间都是其他王朝难以比拟的。唐朝不仅仅是封建王朝的顶峰，是万国来朝的盛世，是经贸发达的繁华，更是政治制度得到巨大发展和完善，起到承上启下作用的重要时期。

唐朝时期疆域面积一百二十多万平方公里，历经近三百年时间，从隋灭到唐兴不过才几代帝王的时间，这样的成就可以说是历史上少有。而唐朝当时的影响力已经深入到欧洲，唐刀成为了欧洲军队畏惧的存在。

所谓万国来朝，更是中国古代封建社会历史上唯一一个真的能够称得上万国来朝的朝代。明朝时期郑和下西洋宣扬国威，赏赐金银珠宝，以此来换取东南亚地区各国家的支持，但是唐朝时期，由于李氏本身就具有少数民族血统，因此在整个统治时期，李唐都展现出一番独特的开明风气。

而且唐朝经济发达，政治开明，百姓安居乐业，长安城真的成为了人人向往的大都市，因此吸引了周边众多属国前来朝贺。当时的唐朝和历史上著名的奥斯曼土耳其帝国，元帝国等等相比，丝毫不逊色，只是唐朝对外政策上更加偏向于和平外交，而非对外扩张战争。

![](../Images/d76a4ee9eba9390ae4febfde6e000b65.png)长安城

2.完善的政治治理体系

这样强大的国家实力，和治理国家的需要让唐朝不断地发展完善自身的政治制度和社会制度。比如科举制度，三省六部制度，台谏制度都是在唐朝时期完全建成并成为后世模板的。而保密制度的发展完善和这些制度是分不开的，保密制度需要真实的载体。

所谓保护的国家机密就是一些记载着重要信息，民生信息，军事安排等等一系列和国家发展至关重要的文书，这些文书都会相应的放在对应的政治机构中，而非集中起来放在一个保密的地方。

这些机密文件只是对外而言，平时的治理当中，官员和皇帝都是需要用到这些文书的。这就涉及到对应的官僚体系的完善程度和监察体系的完善程度是否足以支撑更加严格的保密制度的实施。比如唐朝的中书省，门下省，尚书省都存放着大量的文书，还有翰林院等等，除了对应高官能够翻阅以外，大部分官员是无法接触到这些文书的。

试想，如若监察体系不够完善，官员官官相护，结党营私泄露机密该如何？若官僚体系不够成熟，官吏选拔方式仍然停留在被世家大族垄断的局面，那怎么能保证官员都是心忧天下万民，胸中笔墨万千的有才之人呢？而没有强大的唐朝廷，又怎么能保证这偌大的治理体系的运行呢？

因此，保密制度在唐朝发展完善是必然的，也是只有到了唐朝这般强大繁华的时期，才能够促进保密制度的完善。

![](../Images/f286c483c6199468eecb017616aa01ee.png)唐朝三省

3.普遍的保密意识

除了大背景以外，唐朝的保密制度更像是一种思想，深入人心。唐朝统治者是历朝历代中被誉为最能建言纳谏的统治阶级之一。比如唐太宗李世民，千古一帝却也会在朝会上和魏征争得不休，并且最后还可能会听取魏征的意见。一方面是唐太宗个人开明的见地，一方面也是台谏制度和三省权利约束的原因。

但是不可置否的是，唐朝统治者，官员甚至百姓，都拥有比较强烈的保密意识，对国家机密，秘密文书等保护工作都比较重视。而保密制度通过相应的措施又被约束在君主和高官之中这一一定的范围之间流动，因此官员们也必须具有较强的保密意识，遵从相应的规定。

保密制度的相关规定和要求更是被明文规定记录在了《唐律疏议》之中，明确了泄密行为和泄密惩罚措施等等，以此来强硬地约束官员和百姓以及一些相关联的人员。

![](../Images/a374404974f4e92d40d886da7d5a48f0.png)李世民

要知道唐朝时期，万国来朝，长安城内各色人种都有，包括唐朝的政治体制内，也有不少少数民族或者是外国官员，想要实施严格的保密制度就需要严格的法律监督。虽然唐朝法律总体上来看不算是各朝各代中严苛等我存在，但是对于泄密者的惩罚却是比较严苛的。因此，由统治阶级带头，在民间也掀起了较为严格的保密意识。

完善的保密制度对李唐的影响

1.历史悠久的保密制度

李唐王朝虽然在中国古代封建社会的进程中代表了相对而言比较开明的年代，但是其本质仍然是中央集权，仍然是君主专制。因此一切的政治制度，社会制度，经济制度是为了君权服务的，保密制度也一样。

![](../Images/1599093b9a9cfafb411e5c7769a37baf.png)唐朝外国官员

保密制度和中央治理体系，中央到地方的治理体系都是相互镶嵌的，并不是独立在政治治理以外的一个制度，其主要影响也是反映在政治领域层面。这是保密制度的主要影响对象，而保密制度的实施，又和当时的社会生产力水平，科学技术水平息息相关。中国第一个封建王朝——秦朝，第一次出现了当时较为先进的保密手段——泥塑。

实际上泥塑这种保密手段早在春秋战国时期，各国传递军情的时候就用到了，只是秦朝到汉朝得到了更大的发展。后来一直到宋朝，清朝，更是出现了更具有保密性的手段。宋朝实封，清朝密奏。但是在保密手段的发展阶段中，却缺了唐朝。

![](../Images/202a62dbba5cf7b78d5b38ce75a13dd9.png)秦代封泥

2.唐朝泄密惩罚措施的作用

其实和其他几个朝代相比，唐朝更为注重其人的优势，对于需要保密的文书，并没有花费更大的精力去研究保密手段的更新。而是不断地完善官僚体系和政治制度，使保密制度和政治制度更加契合，以此来推动保密制度的实施。

三省六部中作为除了皇帝以外最高权力机关的三省长官，也是最有机会接触到密令或者保密文书的官吏，更是具有严苛的约束标准。对于泄露重要国家机密的官吏，或者是比之还严重，作为间谍在唐朝官僚体系中活动的人，其处罚力度应该算是唐朝律法中最重的方式之一。

3.人在保密制度中的主导作用

唐朝的保密制度之所以成为其治理能力的一种代表，除了其本身的完善和优势，还有就是在实施过程中一直走在正确的道路上。唐朝时期，上至三省长官下至地方县令，都严格地遵守唐朝保密制度。

![](../Images/1032b497a735a8ccd0d6db4a9c785dc3.png)唐朝官员

唐宪宗时期，中书省主书，官居七品，可以说是官阶不高，但是主书负责的是中书省的公文管理，撰写，校对，记录会议内容等等工作，可以说是离国家大事最近的小官员。因此，这样的官员拥有窃取国家机密的机会，而唐宪宗时期的中书省主书滑涣就是这样的人，把当时的三省长官都蒙在了鼓里。但是在唐朝严格的泄密惩罚措施下，他落得个自取灭亡的下场。

而这件事更是警醒着文武百官，成为了为官者不可为之事中最重要的事情之一。也正是因为唐朝保密制度的完备，惩罚体制的严苛，自己唐朝官员本身素质的提高，国家机密被泄密这种事情并不是特别常见，间谍活动更是可以到忽略不计的地步。

![](../Images/5a690ffcd6d7ce61192a6b86d4f836f5.png)唐宪宗

4.时间不能决定制度优越

唐朝的保密制度之所以可以称之为上千年历史中最辉煌灿烂的一个，更多的不是制度本身，而是实施的情况和得到的反馈。其实唐朝的保密制度也是从前朝留下来的制度基础上进行发展完善的。如果按时间来说，历史是向前走的，是否宋明清时期的保密制度实施情况和对国家机密文书的保护比唐朝更先进，更具有作用呢？

其实不是，明清时期对于国家机密文书的保护力度远远不及唐朝，但是其保密制度以及泄密惩罚措施远比唐朝要严苛。但是即使如此，明清时期仍然难以达到唐朝时期那样清明的政治。

![](../Images/50f86736b83988d56c805134f7f68aba.png)唐朝官员

5.合理运用方显其优越性

究其根本，明清时期统治者太过于依赖制度本身的力量而非制度与治理过程中的融合，而且明清时期宦官干政严重，贪污腐败现象频增。所以说，唐朝保密制度能够得到历史的认可的很大一部分原因是因为其发挥出了其他各朝各代相似制度难以发挥出来的效益。

制度本身不分好坏，在最适合的时代用在最适合的地方，并辅之以正确的手段，才能真正起到已过国家治理工具的作用。保密制度和泄密问题解决措施的完善保护了国家重要的信息，而国家机密得到保护又促进了国家治理体系的完善，使之形成一个良好的循环。

![](../Images/7bde6076976fb6ccbf0186c7dac98eec.png)明代贪污腐败

总结

唐朝保密制度得以完善，是历史的功劳，是在源远流长的历史长河中形成了坚实的基础，在唐朝时期得到完善的制度。保密制度涉及范围广，影响大，不得不让统治者付出更多的人力物力财力和心力去发展完善，使其能够适应本朝代的统治，促进封建君主专制的加强。

所以说，保密制度的完善本质上也是中央集权君主专制的加强，是封建王朝的发展标志。而从保密制度给唐朝乃至后世带来的影响可以看出，一个合适且有力的国家制度或者是措施，是能够促进国家发展，社会进步的，而在对制度的发展完善中更重要的还是加强其对国家治理体系和国情的适应程度，只有才能利国利民。
