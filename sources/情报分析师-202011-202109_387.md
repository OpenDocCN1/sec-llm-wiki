# 2021春运人群画像分析报告

有钱没钱，回家过年。这个中华大地流传已久的风俗，在2021年牛年农历春节被新冠病毒重新改写。新冠疫情下，受国家号召，不少人选择在工作的城市“就地过年”，这也改变了众多人回家过年的行程。那么，相较往年，春运返乡人口下降了多少？哪些城市回乡人口最少？坚持回乡过年的又是哪些人？过年前7天，每日互动个推大数据关注了春运期间，火车购票类APP活跃情况，及一线、新一线城市返乡人群情况，通过数据解读这个“特殊年”各大城市人口流动情况及返乡人群画像。  
春运热度降低，火车购票app活跃度下降5成以上  
  
随着2021年春节临近，各地近日纷纷发出倡议，号召市民留在本地过年。这些举措直接导致往年“一票难求”的春运火车票，在今年反而没那么难买到了。自春运车票预售期开始后，以12306、智行火车票等为代表的火车购票类APP春运车票预售期内的活跃度都有所下降，无论是节前车票预售还是节后返程车票预售情况都比较平稳，今年的春运抢票不再那么惊心动魄。![](../Images/689a98dfffe4d76694bc27ffd689d53d.png)  
数据显示，2021年春运节前车票预售期内，火车购票类APP活跃趋势十分平稳，平均活跃度仅为去年同期的53.6%，下降了46.4%。值得注意的是，在2021年春运节后返程火车票预售期内，火车购票类APP活跃情况更加“低调”，平均活跃度仅为去年同期的33.1%，下降了66.9%。2021年春运火车票节前、节后预售期火车购票类APP“平稳”的活跃情况也从侧面反映出，今年人们在“返乡过年”和“就地过年”两个选择中更倾向于后者。  
北京、天津返乡的人数较去年同期下降最高，超过7成  
2021年春运拉开大幕后，个推大数据洞察了2021年春运前七天（1月28日-2月3日）离城返乡的人口变化情况，发现在各地“就地过年”的号召和福利政策的双重影响下，有更多的人积极响应，做出了春节原地过年的决定。  
 ![](../Images/682c7746ee98bfbac7d5e371ce0e021f.png)  
其中，2021年春运前七天，19个一线、新一线城市返乡人口数量都较去年同期有较大幅度的减少，最高降幅超七成，最低降幅也近五成。今年春运前七天，在19个一线、新一线城市中的离城返乡人口数，排名前三的城市是广州、深圳、成都，而去年同期排名前三的是广州、北京、深圳。其中，北京和天津返乡人口下降比例最高。2020年12月25日北京率先提出“提倡市民群众在京过大年，党政机关干部带头在京过节”的号召，在疫情防控与“就地过年”倡议和补贴政策的多重作用下，今年春运前七天离京返乡的人数较去年同期下降了75.9%，降幅最大。“首都经济圈”里的天津也积极响应，在倡议的同时，还准备了留津红包、免费饺子等福利补贴方案。天津春运前七天“离津返乡”人数较去年同期下降了70.7%，降幅排名第二。  
今年春运大军的主力是哪些人？那么，今年的返乡人群都有哪些特征呢？个推大数据持续关注了19个一线、新一线城市这两年的春运返乡人群用户，并根据数据进行了画像。  ![](../Images/0aa55dccdbdf922f75985a397830cd14.png)从性别分布来看，2021年春运返乡人群男性占比54%，与2020年春运返乡人群相差不大。从年龄分布来看，往年，24岁以下人口是春运主力，在去年占返乡人数的近4成。而今年数据显示，24岁及以下人群在春节前7天返乡人口的占比只有18.3%，相较于去年同期下降幅度较大。这一方面说明，不少年轻人更倾向于留在工作地过年，另一方面也与高校提前放假，学子们得以“错峰”回家，提前返乡分不开。年前新冠肺炎疫情在我国部分省份出现零星、散点爆发。针对教育界“跨省人口流动”最大群体——高校学生，教育部提出“错峰放假”的应对措施。据中国网记者统计、梳理，进入新年，多地高校已提前在一月份就进入“寒假时间”，部分高校临时提前放假或延长假期，高校中最长寒假可达70天。![](../Images/85a25a6a9284c1cca85e8ac5b77f9b34.png)  
年轻学生缺席春运，也让“打工人”主力人群，25岁至44岁的人群成为了今年春运的主力军，占比达61.7%。再从消费分布来看，往年，高消费水平人群更愿意回家过年，往往是春运中的主力军。而今年，中等消费水平人群占比超过了高消费水平人群，占54.8%，较去年同期则上升不少，而高消费水平人群占比有所下降。
