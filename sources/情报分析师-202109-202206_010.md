# 实战指南：事实核查和揭穿

《事实核查与揭穿》实战指南是由北约战略通讯卓越中心编写，具有很强的实用性和参考价值。

基本内容

  

  

  

报告的第一部分探讨了是否有可能通过讨论事实核查工作之间的主要区别、打击错误和虚假信息背后的目标以及“适得其反的影响”的风险来评估揭穿的影响。

第二部分是最佳实践指南，比较了不同类型的事实核查和揭穿计划。

第三部分提出了建议，并描述了改进做法、评估影响和制定政策解决办法的未来前景。

![](../Images/b7c4e61dfe1b3559b4cabbef96fe418c.png)

该报告的附件全面概述了有关该主题的可用资源，包括手册，OSINT，视频和图像搜索以及社交媒体监控和网络分析工具。报告将关于该主题的学术辩论与作者自身经验中的真实实践相结合，采访了该领域的几个专家组织，如大西洋理事会，国家民主研究所，欧盟的东方战略司令部特别工作组，并与来自不同欧盟和北约国家的相关官员进行了讨论。对来自全球的200多项事实核查和揭穿行动进行了研究和评估。  

错误信息和网上传播的虚假信息是相对较新的现象，为限制此类内容的影响而制定的举措也是如此。关于事实核查和揭穿这两项关键对策的有效性的问题仍然存在。本报告开始审查最佳做法：它是什么，谁做的以及如何评估它。

什么是虚假信息和错误信息？

  

  

  

当今的信息环境越来越以错误信息和虚假信息的传播为特征。错误信息是指在没有任何误导意图的情况下传播的可验证的虚假信息。虚假信息是指为了经济利益或故意欺骗公众而创造、呈现和传播可验证的虚假信息。无论是在新闻文章或在线博客上发表，还是从新闻编辑室或政府新闻发布会上播出，误导性和虚假信息都会经常被有意和无意地产生和复制。

  
![](../Images/84803dcd768c2d6f104dfe11b7ddf4ad.png)  
![](../Images/8b2978c25e629d94a297379a008b2a50.png)

是否有可能评估揭穿的努力？

  

  

  

事实核查是检查一篇文章、新闻文章、演讲等中的所有事实是否正确的长期过程。它源于需要让当权者对其主张负责，传统上由记者，新闻编辑室和政治分析家进行。

揭穿是指揭露虚假或表明某件事不如它所显示的那样重要，不那么好或不那么真实的过程。总体目标是尽量减少潜在有害的错误和虚假信息的影响。揭穿的组织的主要目标包括：断言真相，对虚假信息的证据进行分类，揭露虚假信息和阴谋，归因于虚假信息的来源，建立能力和进行教育。

![](../Images/5778d033880272d759cb07c48482b2a5.png)

尽管揭穿和传统事实核查之间存在重叠，但需要注意以下几个区别：

  

揭穿通常不是无党派的。政府可以这样做来揭露“敌对”行为者，有时采取“运动”或“倡议”的形式。与此相反，事实核查是本着公正的精神进行的。

揭穿针对特定的参与者或主题。虽然事实核查的范围很广，但揭穿通常始于根据对其意图和行为的总体评估，决定谁的信息应该被纠正。

揭穿是战略性的。与事实核查不同，并非所有的谎言都应该平等地关注。

揭穿的重点是解决战略问题以减少伤害，而举措往往忽略了不太可能对其优先问题产生重大影响的错误和虚假信息。

  

1.    
    ![](../Images/84803dcd768c2d6f104dfe11b7ddf4ad.png)  
    ![](../Images/8b2978c25e629d94a297379a008b2a50.png)
    
    改进实践。
    
      
    
      
    

1.  了解信息环境。评估您可以学习/与之合作的现有计划以及您的目标受众（以确定他们认为可信的行为者，信息和渠道）。
    
2.  您要保护什么？通过明确目的（例如，保护选举与建立更广泛的媒体素养），您可以确定您将如何工作以及您将与谁合作。
    
3.  不同的策略和针对不同受众的定制消息传递。框架应根据主题和受众而有所不同。目标受众可能有不同的期望，因此您需要根据上下文仔细定制沟通策略。
    
4.  受众参与策略。最容易受到错误和虚假信息影响的受众不太可能参与长篇或压倒性的文章。寻找创新的格式，如游戏化。
    
5.  评估您自己的漏洞。一旦您确定了一个可信的声音来进行揭穿，您的组织可能面临的风险或漏洞是什么？
    
6.  选择你的战斗。资源和时间限制意味着您必须在选择参与的问题和参与者中具有选择性。
    
7.  回应应该在反驳信息、反驳叙事和反击品牌之间取得平衡。
    

3.    
    
      
    ![](../Images/84803dcd768c2d6f104dfe11b7ddf4ad.png)  
    ![](../Images/8b2978c25e629d94a297379a008b2a50.png)
    
    评估影响
    
      
    
      
    
      
    

1.  错误和虚假信息对策的测量和评估（M&E）仍处于早期阶段。其中一些研究测试了更正的措辞，以提供可能坚持的反信义的经验证据。其他研究测试在暴露于纠正信息后对事实的回忆。
    
2.  实验可以帮助解释人类的心理，并磨练针对特定行为改变的信息。这可酌情反映在指标中。许多其他目标本质上是政治性的，因为它们试图表明意图，施加成本并破坏对手的能力，支持盟友能力，减少社会脆弱性并安抚公众。
    
3.  这些指标应反映在对一项倡议可能产生的影响的任何评估中。但是，根据国家，问题和对手的不同，这些指标中的每一个看起来都可能非常不同。
    

5.    
    
      
    ![](../Images/84803dcd768c2d6f104dfe11b7ddf4ad.png)  
    ![](../Images/8b2978c25e629d94a297379a008b2a50.png)
    
    制定政策解决方案
    
      
    
      
    
      
    

1.  揭穿不是一个独立的解决方案。揭穿应与连贯的立法、威慑和复原力建设措施并驾齐驱。网络和联盟提供了重要的方向、保护和支持。与政府、政府间组织和慈善家等机构的协调对于该领域的一致性非常重要。这涉及澄清任务、目标、主题事项和地域市场。
    
2.  有机会利用资金来推动共享标准。可以做更多的事情来建立共享的标准，规范和实践，以便在组织内创建更加一致和一致的产品。
    
3.  从封闭的群组、聊天室和消息服务访问数据存在重大问题。数字平台有机会通过标签，推广和降级内容来对抗错误和虚假信息。政府可以通过合作或监管数字平台来支持这一点。
    
4.  授予组织实现特定目标的任务是至关重要的一步。提供一项足够具体的任务，以推动揭穿活动，但又足够灵活，以应对未来的挑战，这是政策制定者需要解决的一项重要能力。
