Creepy是一个开源的地理定位智能工具。它通过使用已经在其他地方发布的各种社交网络平台和图像托管服务来收集有关地理位置的信息。Creepy 使用基于确切位置和日期的搜索过滤器在地图上显示报告。这些报告以 CSV 或 KML 格式提供，以便导出以进行额外分析。今天小编就来给大家介绍一下如何使用Creepy。


Creepy 的主要功能分为主界面中的两个选项卡。“目标”选项卡和“地图视图”选项卡。启动 Creepy 将带您进入目标界面



在我们开始使用它之前，我们应该授权 Creepy 使用我们的 twitter 帐户以访问 twitter API。如果我们需要使用搜索功能，在 Creepy 中搜索 Twitter 用户，以及访问我们关注的具有非公开（受保护）时间线的 Twitter 用户，则此过程是必要的。这可以通过导航到编辑 → 设置来完成



单击“Authorize Creepy”，将调用网络浏览器并指向 twitter，在其中为我们的帐户提供用户凭据，我们将收到一个 PIN 码。将此 PIN 码重新插入 Creepy 并单击“确定”，授权过程完成。身份验证和授权过程使用 oAuth 协议，并且用户凭据不与应用程序本身共享。可以通过访问www.twitter.com上的帐户设置随时撤销授权. 设置中的下两个选项卡可用于指定访问 Flickr API 的密钥（如果有必要）（Creepy 带有预定义的 API 密钥，除非它不起作用，否则实际上不需要更改它），并指定目录在我们的本地磁盘中，应下载照片以便分析与地理位置相关的 EXIF 标签。




现在我们已经授权 Creepy 使用我们的 twitter 帐户并根据我们的喜好编辑设置，我们已经准备好使用该应用程序了。如果我们不知道我们想要“定位”的用户的 twitter 账号位置或 Flickr ID，我们可以使用这两个服务的内置搜索功能。



对于 twitter，我们可以通过用户名、全名和电子邮件进行搜索。对于 Flickr，我们可以通过选择相应的搜索按钮来搜索全名或用户名。搜索结果包括用户名、全名、用户的个人资料图片和一些附加信息，例如声明的位置（如果适用）。


双击正确的结果将填充顶部的文本字段。或者，我们可以手动提供 twitter 用户名或 Flickr ID，以防我们事先知道。



一旦我们对搜索查询感到满意，我们就会点击“地理定位目标”



地理位置信息检索可能是一个有点冗长的过程，具体取决于“目标”拥有的推文数量，这些推文中有多少包含需要下载和分析的照片。它可能需要 1-2 分钟，最多 1/4 分钟，因此请耐心等待。检索和分析结束后，我们会看到类似于以下内容的结果：



在左侧，我们可以看到以纬度、经度、时间戳三元组的形式包含所有检索到的位置的列表，而在右侧，我们可以看到包含所有位置的嵌入式地图，最初聚焦于检索到的最新位置。在用户界面的底部，有一个文本字段，其中包含有关检索过程的有用信息，例如分析了多少推文，以及有关 Creepy 在尝试访问目标服务时遇到的可能错误的信息。


从这里，我们可以使用嵌入式控件导航地图，或者只需简单地拖动地图并获得特定地理区域的详细概览或缩小并获得更广泛区域中检索位置的全局概览



或者，我们可以使用左侧的位置列表浏览结果。双击列表中的任何位置，将使地图聚焦于该特定地理位置，并且还将在地图下方的文本区域中显示相关的上下文信息。



正如我们所看到的，地理位置信息是从 twitter 中检索到的，我们还可以看到“目标”从该特定位置发布的推文以及指向 twitter 网站上实际推文的链接。（由于隐私问题，信息模糊不清）。右键单击列表中的位置，我们可以复制系统剪贴板上的经纬度元组，或者使用谷歌地图在浏览器中打开该位置。这在使用谷歌的街景我们可以获得真实世界的情况下非常方便，但可能不是目标位置的实时印象。


我们还可以从包括 Google（卫星、街道、混合视图）、Virtual Earth Maps（卫星、街道、混合视图）和 openstreetmaps 等列表中选择地图提供者和相关视图。




为各个“目标”检索到的所有地理位置信息都由 Creepy 内部缓存。这意味着下次我们需要搜索特定目标时，只会检索和分析最新的推文，并且将从缓存中加载所有以前已知的位置。通过这种方式，我们限制了对 twitter 和 Flickr API 的调用，以最大限度地减少达到因 API 限制而导致应用程序在一段时间内无法使用的可能性，我们最大限度地减少网络使用，并确保信息持久性以防“目标”决定擦除某些或在服务暂时不可用的情况下。此外，所有错误都会被缓存。例如，如果由于某种原因 Creepy 无法从某些图像托管服务下载和分析一些照片，


除了这种内部缓存之外，我们还可以选择以逗号分隔值 (.cvs) 文件的形式导出我们的结果，该文件可以导入任何其他应用程序。导出功能（Creepy → Export as）还可以将位置列表导出为 kml 文件，以便与 Google Earth 软件一起使用以进行进一步分析。
