# 分析师干货：情报分析报告写作指南

如何写一份专业的情报分析报告对于情报分析师来说是非常重要的事情。今天小编为大家推荐《情报分析报告写作指南》，使情报人员写一份完美而又专业的情报分析报告。  

  

情报收集和分析每天推动决策者作出改变世界的决定。各国领导人、其顾问人员、军事领导人和政府机构都依赖及时、准确的报告，以决定军事单位、国家武装部队或国家本身的命运。

  

这些决策者需要全球、国家和地方活动的解释，以审查情景的所有影响和可能的结果。收集、分析和向决策者报告这些事件是情报社区的工作。为了更有效地为国家服务，情报分析报告必须以客户为中心，满足客户的需要，并以明确、简明和有组织的方式回答他们的问题。

![](../Images/2765d9990b27746a0eee045c03ee45da.png)

各种类型的情报分析报告写作有不同的要求，从目前的情报报告到研究辅助。大多数分析员被分配当前的情报报告，以书面和口头报告形式提交，目的是使决策者随时了解世界重要事件的最新情况。

  

这些报告向政策制定者和情报界（I C）的其他重要成员提供信息，向他们提供“重大新发展的最初迹象”。此类报告可每日发表/发表，如美国总统每日简报(PDB)，或较少以周刊、期刊和其他出版物的形式发表。

  

这些报告中的信息往往对时间敏感，对决策者今后的决定或行动很重要。为了为决策者创造最佳产品，作者必须学会在有组织、清晰和简明的报告中集中关注客户的需求，并满足这些需求。

  

![](../Images/6180efbfaddc596c5a73dc140ad8943c.png)![](../Images/27fe70633ecef0d614979db9bea7109b.png)

**在写作之前的准备**

![](../Images/2d50b97cd9e5a69a1f1a28809c3cb751.png)![](../Images/8d537c8df0f1577bbef00c3551c92772.png)

  

首先，情报师在分析一个事件（无论是在场的、迫在眉睫的或预测的），这个事件足以影响他们的客户：政策制定者、决策者和其他客户。一旦决定了某一个事件或课题进行分析，分析师应该通过问自己一系列问题来理解重要因素。

  

分析师应该总应该对自己发问，认为是“情报过程或循环存在问题——答案不可避免地导致更多的问题。

  

质疑过程应该是：**事件的新情况；正在采取哪些不同行动以及为什么正在发生；谁是主要人物，他们的目标、关切和动机是什么；哪些因素可能导致成功或失败，以及每个因素的前景；这对美国和其他国家有何影响；对主要人物的影响及其可能采取的下一步措施；以及由此产生的不同情景及其影响。**

在这些问题之后，分析师必须通过回答这些问题并了解客户的需求师什么，他们想得到什么结果？具体问题可能不明确但客户可能需要一份关于某个事件的报告。

结构

![](../Images/2d50b97cd9e5a69a1f1a28809c3cb751.png)![](../Images/8d537c8df0f1577bbef00c3551c92772.png)

客户常常有时间需求，因此情报分析报告应首先提出要点。在结构上，报告应从明确的说明性标题开始。标题为报告的主题，经常作为名词短语书写，然后简要阐述报告的性质。例如，一份关于SARS的分析报告可能题为“SARS：21世纪第一次流行病的教训”。在这种情况下，SARS是名词短语。标题不需要一个名词短语，如果它提供了一个描述报告内容的快速而具体的语句。

  

在标题之后，报告应再次强调要点，说明目的。这应该写成“目的”。然后是一个以“解释”、“告诉如何”或类似短语开头的解释。如果标题明确无误，可以省略这一目的。

![](../Images/9f3776e4e132820c74fe4555261f5013.png)

假设BLUF透彻地介绍了该报告，分析人员随后应该附上支持段落。这些段落应该解释分析师的想法以及他们猜测的论点或结论的推理（Welch）。它应该遵循先呈现已知事物，然后关联分析家的结论的结构，就像文学分析文章的结构。然而，与大多数论文不同，这些文章应该是“清晰、合乎逻辑的段落”（Welch）。段落将是简短的，通常不超过六行打字。此外，各段必须保持重点，各段的要点和构想都应明确突出。

  

最后，分析报告分为三个部分，首先是一个内容提要，澄清和重述要点。这应该类似于结论，但必须继续侧重于关键信息，而不是总结他们的报告。第二部分专门讨论一节，包括情报方面的空白以及“否认和欺骗的可能性”。第三，分析师包括他的结束评论和引用。
