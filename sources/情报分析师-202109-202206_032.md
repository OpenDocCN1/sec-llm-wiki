# 两份国家安全大数据领域的分析报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650499804&idx=1&sn=9fa5234c75fa13019a888ffce1af7f83&chksm=87164497b061cd81974a690b5b317d934f1f65f0c28d316c19b672a5c752e99419fe7c5c42e8&scene=126&sessionid=1681267273#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650499804&idx=1&sn=9fa5234c75fa13019a888ffce1af7f83&chksm=87164497b061cd81974a690b5b317d934f1f65f0c28d316c19b672a5c752e99419fe7c5c42e8&scene=126&sessionid=1681267273#rd)

今天介绍两份重要报告：第一份报告“*国家安全中的大数据”*对澳大利亚国家安全界如何使用和管理大数据能力进行了高层次的分析。第二个报告“*国家安全中的大数据* —— *在线资源”*是一份背景文件，为政策制定者和公众提供了对大数据在国家安全中的关键概念、趋势和挑战的详细分析。

当前，大数据分析与机器学习算法一直是情报分析中备受瞩目关键驱动力。数据被谷歌DeepMind的AlphaGo首先超过当代的发展预测10年，Facebook已经开始使用类似的学习算法来检测和删除恐怖主义内容和消息。英国脱欧运动和美国的总统当选预测说明，大数据分析和算法生成的“新闻”如何影响公众情绪。  

![](../Images/3c6593f4d9295a6694e3de71d09bd5ab.png)

澳大利亚智库ASPI发布了两份研究出版物，这些出版物将引起关于国家安全大数据的公共政策对话的高度重视。  

**《战略洞察》报告《*国家安全中的大数据》****对在国家安全*中使用大数据的概念、应用和挑战进行了高层次的总结，并对大数据进行了一般且易于理解的解释。它最后就国家安全界应如何最好地管理其大数据的实施和使用提出了建议。

**ASPI的《*国家安全******大数据：在线资源*》**对这一棘手政策问题的关键概念、趋势和挑战进行了更详细的分析。

大数据现在被广泛使用，但关于澳大利亚政府应该如何使用和管理大数据能力的战略公共政策讨论并不多。生产力委员会关于数据可用性和使用情况的报告为如何改进数据治理的讨论提供了一个可喜的开端。然而，关于国家安全界使用大数据的讨论仍然很少。

![](../Images/81a12801bb48ad3de71494351b3655de.png)

相反，媒体主导的话语集中在政府强制的加密消息的“后门”和“元数据”的使用上。不出所料，没有公开讨论使用大数据的局限性，挑战和风险。改善澳大利亚的公共政策对话将是提高公众对大数据使用的信任的重要一步。  

国家安全领域的大数据可以帮助自动索引大量非结构化信息，并将其集成到可搜索的源中，用于知识发现的数据挖掘可以通过该数据来发现模式和相关性。然后，这些模式和趋势可以用于预测分析。

![](../Images/3e8a4b1ada82f14cc887c0089da2a4c0.png)

**同时，在大数据时代出现了一些挑战**

1.  首先，实施大数据技术和实践既复杂又昂贵。
    
2.  其次，假阳性和假阴性结果的统计问题，数据中存在偏见以及潜在的反馈循环意味着激进的大数据项目将需要同样广泛的审计和审查功能。保持这种审计和审查水平可能很困难，因为分析程序变得不那么可解释。
    
3.  第三，声誉风险可能来自大数据分析，这种分析是在没有严谨的情况下进行的，并造成伤害，就像“Robodebt”机器人争议中的情况一样。
    

此外，国家安全界以外的对手越来越多地使用大数据能力。针对Twitter帐户的黑客已经能够演示机器学习算法，这些算法可以自动了解有关目标的详细信息，根据这些详细信息定制个人兴趣的钩子，并发送自动化且高效的鱼叉式网络钓鱼通信。

针对大数据分析系统的对抗性攻击已被证明会破坏系统的预测性能。这些攻击能够“毒害”防病毒中使用的恶意软件检测算法，并导致自动驾驶汽车的视觉系统误解停车标志并导致碰撞。除此之外，对隐私和个人信息安全的广泛和持续的结构性侵蚀也主导了国家安全政策讨论。

为了有效应对这些挑战，从大数据分析的使用中受益，并提高公众信心和个人信息安全，需要在整个国家安全界和更广泛的澳大利亚政府中使数据治理更加明确和系统化。
