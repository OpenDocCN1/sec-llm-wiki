# 智库报告63页《大国竞争时代的战术》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650499268&idx=2&sn=8e326f1ceed417a8d31313d9e5adb1e9&chksm=8716468fb061cf9960effcb060b1911866f81a010412412f468c2371eb4297f6385ae3bcdf5f&scene=126&sessionid=1681267281#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650499268&idx=2&sn=8e326f1ceed417a8d31313d9e5adb1e9&chksm=8716468fb061cf9960effcb060b1911866f81a010412412f468c2371eb4297f6385ae3bcdf5f&scene=126&sessionid=1681267281#rd)

今天，陆军正在花费大量的时间和精力在大国竞争的背景下进行调整和创新。这种强调的很大一部分发生在战争的高级战术和作战层面。对当前运营环境以及我们的同伴和近邻威胁的调查表明，这些改革中的大部分恰恰发生在危机或冲突期间将特别中断的梯队中。因此，美国陆军的机动旅也必须适应。这一梯队的变革对于确保在今后冲突中取得成功同样至关重要。

![](../Images/4f74747786f63475054e2e3ed8c25ed9.png)

与此同时，从过去二十年的低强度冲突和反叛乱中，也有一些重要的教训需要记住。大国竞争的回归并不一定意味着大规模常规作战的回归。事实上，在不久的将来最有可能出现的与其他大国的冲突形式将不会像冷战时期的重大战斗交战。本报告分析了当前战争趋势以及美国最强大的竞争对手Z国和俄罗斯的能力。通过这样做，它试图将美国目前在培训，改革和现代化努力方面的做法与较低阶层将面临的现实相协调。

在第1部分中，本报告研究了当代冲突趋势，以挑战与新的、以大国为导向的战略思维相关的典型假设。低强度冲突的日益频繁，混合战术的兴起，武器向非国家行为者的扩散以及地下和城市地形的使用，使美国对手能够避免大规模作战行动。如果不加以解决，对危机或冲突中取得成功至关重要的战术组织将不那么有效。

![](../Images/1cfba613d958ce237e6a7c36d55d3c82.png)

然后，第2部分以这些趋势为视角，分析Z国和俄罗斯军队的作战能力和理论。虽然每个参与者都有不同的兴趣和目标，并使用不同的策略，但他们确实有一些共同点。他们对美国的看法和各自国防机构内的投资惊人地相似。每个国家还试图通过利用上述趋势来最大化对美国的长期不对称优势。通过想象朝鲜半岛和加里宁格勒附近的潜在冲突情景，可以突出未来作战行动中最重要的不对称性。

第3部分将这一分析应用于美国战斗机动旅，目的是提出可以提高大国冲突有效性的改革建议。这一分析表明，俄罗斯和中国的战争方式将要求美国在塑造行动和机动选择时使用作战旅。为了有效地做到这一点，常规部队可以在战术层面上做很多事情，如果我们过于严格地关注过去的大规模行动，我们可能会错过这些事情。特别是，常规部队应该重新审视特种作战部队——常规部队的整合概念，在短暂而激烈的动能事件中获得行动权，更快地获得火灾和效果系统，转向更加分散的任务指挥架构，并采用更好的城市和地下战争框架。虽然时间和物质资源总是短缺，但必须提高将参与这些冲突的部队的技术和文化素养。
