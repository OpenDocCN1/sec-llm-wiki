# 美国陆军威胁战术报告：朝鲜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650498793&idx=1&sn=964572f4a187c26d4cd7f818aba1a928&chksm=871648a2b061c1b4e741a3e52741941c21138710e347f8dc483d461ab26f293b4084ad3c6adb&scene=126&sessionid=1681267281#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650498793&idx=1&sn=964572f4a187c26d4cd7f818aba1a928&chksm=871648a2b061c1b4e741a3e52741941c21138710e347f8dc483d461ab26f293b4084ad3c6adb&scene=126&sessionid=1681267281#rd)

美国陆军出版系列技术出版物《美国陆军威胁战术报告：朝鲜》，报告指出，朝鲜半岛是美国在太平洋司令部（PACOM）的战略利益所在地，许多观察家指出，朝鲜是一个不可预测且可能不稳定的行为者。根据国防部在给国会和情报界的报告中的说法，由于许多原因，朝鲜“仍然是美国最关键的安全挑战之一。其中包括朝鲜愿意采取挑衅和破坏稳定的行为，包括攻击韩国，追求核武器和远程弹道导弹，以及愿意违反联合国安理会决议扩散武器。

非理性行为的一些最新证据包括：2014年底，金正恩26岁的妹妹被提升为政府高级职位，据称朝鲜在2014年底因可能上映一部嘲笑金正恩的电影而对索尼公司进行计算机黑客攻击，以及2015年4月处决了一名据称在会议期间打盹的国防部长。在过去的50年里，朝鲜零星地针对其敌人，特别是韩国，开展行动。

这些行动包括袭击韩国海军舰艇，俘虏一艘美国船只并将美国人质扣留11个月，劫持韩国航空公司的喷气式飞机，对韩国信号的电子战，包括全球定位卫星（GPS），以及对包括韩国总统在内的韩国官员的暗杀或企图暗杀。

1968年，北朝鲜精英军事人员企图袭击青瓦台，导致参与暗杀企图的所有31名渗透者死亡或被俘，包括三名美国人在内的71名人员死亡，另有66人受伤，因为北朝鲜特种部队人员试图逃回朝鲜领土。

![](../Images/3207f0c4756ca6331eb260c6c9d923a0.png)

这份朝鲜威胁战术报告（TTR）的目的是向陆军训练界解释朝鲜如何作战，包括其理论，部队结构，武器和装备以及作战职能。TTR还确定了特定于参与者的条件在决定性行动培训环境（DATE）和其他培训材料中的位置，以便这些条件可以在所有培训场所轻松实施。  

**内容摘要**

*   朝鲜是一个集权国家，金正恩是其最高领导人。
    
*   朝鲜是一个军人社会，在2400万人口中约有120万现役军人，另有770万在预备役部队中。
    
*   所有军事人员都在朝鲜人民军的保护伞下服役;朝鲜人民空军（KPAF）和朝鲜人民海军（KPN）主要支持人民军地面部队。
    
*   KPAF专注于国土防御和对KPA的近距离空中支援。
    
*   KPN的主要任务是保护朝鲜海岸线，并支持人民军特种部队（SPF）执行任务。
    
*   所有军事部门的大部分装备都陈旧过时，但人民军将其现代化努力集中在导弹技术上，这些技术可能为成功发射核弹头提供手段。
    
*   朝鲜拥有核武器，并正在对其导弹舰队进行现代化改造，以增加其核武库的攻击范围。
    
*   朝鲜拥有化学和生物武器。
    
*   人民军实行被动和主动伪装，以将其部队，总部和其他重要资源隐藏在空中。

**弱点分析**  

虽然朝鲜军队作为战斗力量可能具有一些积极的属性，但人民军也存在许多弱点。军队的大部分装备都是陈旧和过时的。朝鲜军方有意识地拒绝摆脱任何装备，并仍在使用可追溯到第二次世界大战的坦克。来自多代战争的这种广泛的军事硬件也会产生后勤问题。人民军的补给人员不仅必须找到各种设备的备件，人民军的维修人员还必须精通修理各种各样的车辆和武器。此外，朝鲜缺乏在几个月后支持人民军的后勤能力。由于燃料短缺和为一个资金短缺的国家运营车辆的成本，许多人民军士兵发现自己参与了公共工程项目或帮助农民种植水稻作物。花在非军事支援上的任何时间都比人民军士兵花在战斗训练上的时间少。即使是机械化部队和装甲部队，由于资源限制，他们的大部分训练时间都花在轻步兵训练而不是骑乘作战上。虽然人民军士兵可能在个人技能或小部队战术方面受过良好的训练，但与大多数西方军队相比，花在大型演习上的时间相形见绌。如果没有足够的时间和资源来实施大规模军事行动，当人民军第一次被迫在实战中执行这些行动时，人民军将永远面临陡峭的学习曲线。

![](../Images/e19f85a72771c629e7d99f87dbced2a9.png)

朝鲜非正统地使用挑衅手段，以从其敌人——特别是美国、韩国和日本——那里获得让步，这是一种危险。人们永远不知道朝鲜下一步会做什么，因为过去，朝鲜已经批准了对韩国政治领导人的暗杀企图，并在韩国特遣队在另一个国家时进行轰炸，潜艇对船只的突击袭击，无端的炮击，或已经地下隧道进入另一个国家。驻韩美军人员必须为来自朝鲜的意外做好准备。  

其中一起事件可能会使朝鲜半岛重新陷入全面战争。虽然停战协定自1953年以来一直存在，但停战协定只是等待签署和平条约或恢复敌对行动的停火。朝鲜和韩国之间的任何冲突都将不可避免地将美国带入冲突，因为韩国六十多年来一直是盟友。

![](../Images/e48b84b203c7012e7edafcc583a734fb.png)

朝鲜拥有核武器和将其运送到9，650公里的导弹，使其对驻扎在朝鲜，日本，阿拉斯加甚至美国大陆西海岸的美军构成威胁。更令人担忧的是，朝鲜于2015年1月23日首次成功试射了一枚潜艇的KN-11导弹，因为在不久的将来，朝鲜潜艇可以在发射核导弹之前默默地靠近目标，这将减少美国的预警时间。如果朝鲜认为其国家的生存受到威胁，朝鲜可能会使用任何可供其支配的核武器。人民军还拥有化学武器，其理论要求使用化学武器。朝鲜还参与生物武器研究，并可能使用具有进攻能力的生物武器。为部署到韩国而接受训练的美国军事人员必须做好在化学、生物或核环境中作战的准备。
