# **引言**

人工智能（AI）在最近几年发展非常迅速，这导致了广泛的应用，包括民用和军用。事实是，军方一直在追求更好、更快、更强的武器或技术，而这正是人工智能所提供的。正如Svenmarck等人所正确指出的，在军事领域，人工智能有可能影响 "所有的工作（即陆地、海洋、空中、空间和信息）和所有级别的战争（即政治、战略、行动和战术）"。

  

• 自主武器和武器定位

• 监视

• 网络安全

• 国土安全

• 后勤

• 自主车辆

  

出于这个原因，许多国家领导人、技术专家和学者都认为人工智能是革命性的；但他们对人工智能的看法却有所不同。具体来说，一些人认为人工智能是一个积极的发展，因为它将有助于减少人员伤亡，考虑到人力将被机器取代，而机器可以被部署到各种任务中，包括高风险的任务--同时它将提供战略和战术优势。然而，其他人警告说，如果控制和使用不当，人工智能可能会导致另一场世界大战的发生。

![](../Images/e854806fb17ce5482ce64a0d9aecefc3.png)

尽管人工智能仍处于初级阶段，但不可否认的是，它有能力改变安全部门的面貌，因此，它将改变国际体系中目前的经济和军事平衡。认识到人工智能的潜力，20多个国家已经宣布了他们的国家人工智能战略，更多的国家和非国家组织正在人工智能研究和发展（R&D）方面采取决定性的步骤。

  

然而，美国和中国被认为是该领域的领先国家；美国的目标是保持战场上的霸主地位，而中国的目标是在2030年之前超越美国，成为人工智能的领导者。不用说，这两个国家都产生了符合这些目标的独立国家战略，但最重要的是，美国的国家战略将中国的国家战略作为其主要参考点，反之亦然。

![](../Images/716ec75ccb8b84433a1cc627eacc3d5c.png)

# **了解人工智能**

人工智能被认为是第四次工业革命，在当今世界已经成为现实，许多专家认为，人工智能本身不应该被视为一种特定的武器，而应该被视为 "一种推动因素，一种具有多种用途的通用技术。"因此，虽然 "人工智能有可能促成一些军事创新，但它本身并不是一种军事创新。 "技术专家凯文-凯利将人工智能与电力相提并论，他说："就像电力给我们周围的物体带来动力一样，人工智能也会给它们带来智慧。"然而，技术专家不是唯一强调人工智能重要性的人。

  

人工智能自1956年以来一直在发展，但由于三个方面的发展，对这一领域的兴趣在2010年左右开始增加。7 人工智能自1956年以来一直在发展，但对这一领域的兴趣在2010年左右开始增加。

  

这是因为有三个有利的发展：

  
（一）有了大数据 "来源的能力。

（二）机器学习方法的改进。

（三）计算机处理能力的提高。

  

狭义人工智能（NAI）和一般人工智能（GAI）。狭义人工智能指的是玩游戏或图像识别等功能，而广义人工智能则是指能够达到人类水平的智能系统，足以完成一系列不同的任务。

  

目前，所有已知的人工智能发展都属于NAI，而就GAI而言，专家们普遍持怀疑态度，并认为需要几十年的时间才能达到其全部能力。与人工智能有关的一个重要问题，无论它是狭义的还是广义的，都是自主性的问题。下一小节简要介绍了使用人工智能所带来的自主性的范围。

![](../Images/3dd471259a4ed93202b23768ca5154db.png)

## **人工智能的军事应用**

人工智能的快速发展已经在不同的领域产生了积极的影响，包括医学或交通；然而，当涉及到军事应用时，人们提出了很多讨论。现在人们普遍认为，在未来，人工智能有能力改变军事活动，如后勤、情报、监视，特别是武器设计。10 目前，围绕着人工智能及其使用的不确定性在军事战略家中引起了很多争论。特别是，主要的讨论是关于致命性自主武器系统（LAWS）或被称为 "杀手机器人 "的系统。

  

美国的 "Maven项目 "11正被用来处理和解释从无人机拍摄的视频中获得的信息。(通过使用人工智能，无人机、飞机、船舶、坦克等将不需要人类来控制或指挥它们的行动。这方面的一个例子是以色列的哈比无人机，它已通过到接近完全自主的程度（它仍然需要由地面部队发射）。

![](../Images/28acd011a23863325cec579317636ae3.png)

应用较低水平的自主权，可以提到其他飞机，如空军全球鹰和陆军灰鹰无人机。对于这两种无人机，必须由操作者指挥飞机去哪里，然后由飞机自己飞行。因此，预计自主系统将取代人类执行那些被认为是 "枯燥、危险或肮脏 "的任务，这些任务可能包括长时间的情报收集和分析，清理被化学武器污染的环境，或清扫简易爆炸装置的路线。

  

随着数据算法的进一步发展，人工智能可能会被用于指挥和控制，包括战斗管理，通过分析大量的数据集并做出预测来指导人类的行动。

  

![](../Images/b6251aee72f57273e80b6e509065fe0b.png)

## **人工智能对战争特征的影响**

如前所述，很多讨论都集中在人工智能在军事领域的应用上。一方面，有些学者对人工智能的应用持怀疑态度，因为他们指出人类可能会失去对机器的控制，从而造成破坏。

  

国家，但也包括非国家行为者，包括恐怖组织，将能够使用人工智能系统，进一步加深战争的不对称性。另一方面，人工智能机器被认为是一个积极的发展，因为它们将在危险的战斗中取代人类士兵，因此人类的损失将减少，此外，这些机器可能被证明在人类无法忍受的长期行动中更加有益。

  

然而，尽管对人工智能的战争应用存在正反两方面的争论，专家们还是对人工智能对未来战争性质的影响规模进行了预测。在这种情况下，有三种可能的立场。1、小规模的影响，2、进化的影响，3、革命性的影响。
