# 美军：我们应该从旗舰莫斯科号的沉没中学到什么？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650497727&idx=1&sn=2f80163b6363241030ee4b0fcd716302&chksm=87164cf4b061c5e239a1819779c16a181181753dcb1a5ef86ba455d6c3d207267af00ab867f5&scene=126&sessionid=1681267297#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650497727&idx=1&sn=2f80163b6363241030ee4b0fcd716302&chksm=87164cf4b061c5e239a1819779c16a181181753dcb1a5ef86ba455d6c3d207267af00ab867f5&scene=126&sessionid=1681267297#rd)

![](../Images/a53c772273594b6bc643d533aed68dbe.png)

据外媒报道：尽管乌克兰在与俄罗斯军队的地面作战中证明了其军事坚韧不拔，但本周晚些时候，在乌克兰军方宣布用一对巡航导弹成功击中俄罗斯黑海舰队的旗舰后，冲突的观察者感到震惊。

![](../Images/2e851b5029f0d7b0ecc2c5d2354d69e6.png)

乌克兰军队是战斗中名副其实的失败者，击沉以俄罗斯首都命名的战舰莫斯科号，这不仅是一场战略胜利，而且是一场象征性的胜利。俄罗斯国防部发表了各种声明，表明该船遭受了意外火灾或爆炸，但一名美国高级国防官员告诉记者，该船确实被两枚乌克兰海王星导弹击中。但是，正如分析人士正在计算俄罗斯的损失对欧洲冲突的未来意味着什么一样，这样一艘备受瞩目的船只的沉没也引发了一些美国海军观察家更内省的问题：如果乌克兰可以用巡航导弹击沉一艘旗舰，那么美国船只在类似情况下会做得如何？三位海战专家告诉Breaking Defense，答案很复杂，但总的来说，美国海军在防御这种攻击或从中恢复方面处于更有利的地位。俄罗斯水面舰队的舰艇设计已经过时，存在缺陷，即使是一次成功的打击，也会导致灾难性的后果。他们的防御也没有像美国那样大力更新。此外，俄罗斯船员的明显无能可能在罢工后无法恢复中发挥关键作用 - 美国海军水手一次又一次地证明了这一技能。就其巡航导弹而言，新加坡南洋理工大学（Nanyang Technological University）研究员科林·高（Collin Koh）说。“中国海军也在稳步建设主要的水面作战舰艇，如果美军能够加强其反舰库，那么就可以以同样的方式对中国构成反威胁。

![](../Images/8bb989e81ffef11dec39f7bed2d82a49.png)  

据Koh称，有能力的反舰巡航导弹在全球军火市场上很容易获得，而中国已经积累了其中的“强大武器库”。Koh说，为了有效，导弹不必直接击沉一艘船 - 它只需要造成足够的破坏，使船员的注意力从发动攻击转移到保持自己漂浮。如果一支较弱的部队将大量导弹集中在一艘船上，他们很有可能击中一到两枚有用的导弹。莫斯科号在水面上最后时刻的细节仍然模糊不清，但人们一致认为，这艘船在罢工后没有立即沉没，而是在返回港口时因损坏而屈服。

![](../Images/2f6a44d008b8ba930998a8f19ca85c4b.png)

Koh指出，以色列海军在2006年经历了类似的事件，当时伊朗支持的黎巴嫩组织真主党设法从陆地上袭击了护卫舰INS Hanit。“罢工并没有击沉军舰\[哈尼特\]，而是使其停止行动。这一事件以及最新的莫斯科沉没事件强化了这样一种观念，即在今天的海战中，较弱的各方仍然可以对更强大的海军对手构成不对称威胁，“他说。船舶设计、升级防御和稳定水手的重要性但是，有几个原因可能是苹果和橙子来比较莫斯科号和美国海军目前的水面部队中的船只。第一个与莫斯科号和其他苏联舰队舰艇的设计有关，退役美国海军上尉、Telemus集团副总裁杰里·亨德里克斯（Jerry Hendrix）说。苏联生产于1970年代和1980年代，选择在甲板上存放进攻性武器。这意味着只需要一次良好的命中就能引发火灾，然后加热储存导弹的罐子，将它们变成滴答作响的定时炸弹。

![](../Images/444a7ce933c8ee955b70b564c2dc07ab.png)

  

“我不认为我们可以低估斯拉瓦级或基洛夫级或此时出现的Udaloys固有的糟糕设计，”亨德里克斯说，指的是仍在服役的不同苏联时代的船型。“俄罗斯人或苏联大量投资的这种特殊的船舶设计确实为这种级联失败做好了准备。相比之下，美国海军在甲板下方储存了进攻性弹药，这意味着如果火灾威胁要开始“烹饪”导弹，那么机组人员可以在造成更多损害之前迅速淹没空间。亨德里克斯说，另一个问题是，俄罗斯的水面舰队没有像其更强大的潜艇部队那样受到那么多的投资和关注，他们拥有“陈旧的”防空系统，这些系统根本不是为现代巡航和弹道导弹的轨迹而设计的，也不够敏感，无法进行较小的接触。另一方面，美国海军的宙斯盾作战系统几十年来一直在不断升级，以适应新的威胁。“我们的宙斯盾平台已经过设计，然后进行了升级，并进行了修改，专门针对从地面到弹道导弹轨迹的任何地方，这些轨迹几乎垂直下降，”他说。（据报道，Aegis于2016年在也门海岸拦截了一艘美国船只的导弹袭击。詹姆斯·福戈三世（James Foggo III）是一名退休的四星海军上将，现在领导海上战略中心，他今天告诉“突破防御”，船员本身也是一艘船能否克服攻击的关键因素。

![](../Images/683eb79fe7ea1acf4b9ea72307c6ab77.png)

他指出，莫斯科号沉没的时间恰逢即将到来的福克兰群岛战争40周年。在那场冲突中，有两艘船，一艘英国，一艘阿根廷，在与俄罗斯军舰发生的事情惊人相似的事件中被摧毁。  
福戈说，在这两种情况下，机组人员应该能够防御攻击，或者至少在事后减轻损害。在这两种情况下，机组人员都没有这样做。阿根廷船只有水密门，旨在隔离洪水，以防袭击破坏船体。福戈说，机组人员无法控制洪水，这表明他们的准备状态很差。据报道，在英国船只的案例中，船员没有看到导弹的到来。他说，随后，这艘船着火了，在返回港口之前蔓延并摧毁了这艘船。“除了\[关于莫斯科号\]的猜测之外，我没有任何事实，但我会告诉你，它有点像\[阿根廷船\]的情况。自满，“他说。

![](../Images/928dc8a199fc016c6f005e13bbf08a43.png)

“这对普京来说是一种尴尬”  
尽管俄罗斯国防部拒绝将莫斯科号改造成人工鱼礁归功于乌克兰，但它确实承认这艘船已经消失了。对于俄罗斯人来说，这可能是一颗很难吞咽的药丸。亨德里克斯说，将以该国首都命名的军舰送入这场战争“本质上是莫斯科发出一个信号，即我们在这里，我们将留下来。“所以不要低估这艘船损失的影响......这对普京来说是一种尴尬。这对俄罗斯来说是一种尴尬，对俄罗斯的国家声望是一个真正的打击。福戈说，他特别担心俄罗斯人在失去旗舰后会采取什么报复措施。他说，许多国家的旗舰通常维护良好，相对最先进的船只，旨在代表一个国家的最佳产品。有传言称，莫斯科是普京的最爱。福戈还指出，莫斯科的命运及其旗舰地位具有讽刺意味。在俄罗斯入侵的早期，乌克兰政府下令在敖德萨东北部的尼古拉耶夫港凿沉或故意击沉自己的海军旗舰“酋长萨哈伊奇尼”护卫舰，以防止俄罗斯人夺取它。Foggo说，当乌克兰是苏联的一部分时，莫斯科号和其他同级舰艇是在同一港口建造的。“这就是乌克兰旗舰仍然沉没的地方。现在，如果这是真的，乌克兰人击沉了黑海舰队的旗舰莫斯科，“他说。“只是——我的意思是，你不能编造这个。这就像一个好莱坞剧本。长按识别下方二维码加入情报学院知识星球
