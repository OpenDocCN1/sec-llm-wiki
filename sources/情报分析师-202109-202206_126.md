# OSINT改善执法

![](../Images/4f2371e9df69e166de12c52c437d4d34.png)  

开源情报(OSINT)是指任何人都可以“通过请求、购买或观察合法获取”的公开信息来源的任何情报。从执法的角度来看，OSINT可以帮助分类和核实事实，识别罪犯，了解意识形态，并认识到新出现的犯罪趋势。近年来，OSINT的可用性呈爆炸式增长。事实上，这种类型的情报提供了大量的信息，供情报和安全机构用来识别风险，并作出有效和及时的战略决策。

 

使用OSINT有几个优点和缺点。也许OSINT的最大优势是它比传统的信息收集工具便宜得多，因此提供了更大的潜在投资回报(ROI)。当州、县和市政当局面临预算削减时，执法资源往往会被削减，因此采用不仅有效而且成本更低的技术是有意义的。

 

*“也许OSINT的最大优势是它比传统的信息收集工具便宜得多，因此提供了更大的潜在投资回报(ROI)。”*

 

![](../Images/bac221d515cd3f6a4ed9b0b89625705a.png)

OSINT的另一个好处是，信息可以很容易地、合法地与其他机构共享。OSINT的最佳来源包括期刊、报纸、电视和广播、公共数据库、目录、公开讨论和论坛、政府报告、新闻通讯、博客、社交媒体平台、来自供应商的商业信息、搜索引擎、RSS源和网站。事实上，互联网的快速发展已经使其成为知识的主要来源。然而，需要特别关注的是要理解数量并不一定意味着质量，因此，任何开源信息都应该以批判性的眼光来看待其可信性和真实性。  

 

在OSINT中可以找到丰富的知识。极端主义个人和团体往往想要分享他们的目标和信仰，所以他们倾向于频繁地在各种媒体上发布信息来传播他们的信息。此外，犯罪分子享受他们认为互联网提供的匿名性。社交媒体平台已经成为犯罪教化和恐怖主义激进化的中心枢纽，如果调查人员不利用这一令人难以置信的情报来源，那将是愚蠢的。

 

![](../Images/b41f5aa628932743183d8a20544f46d3.png)

  

此外，由于公开来源被称为首选来源，这种类型的情报对公民自由的侵犯是最小的。特别是在社交媒体平台和其他公共在线论坛上，个人和团体自愿在这些网站上发布的内容基本上否定了未来任何侵犯公民权利的主张。

 

*“社交媒体平台已经成为犯罪灌输和恐怖主义激进化的中心枢纽，如果调查人员不利用这一令人难以置信的情报来源，那将是愚蠢的。”*

 

OSINT的最大缺点之一是由于互联网上大量的“噪音”而可能导致信息超载。因此，定位正确的信息可能会非常耗时。此外，OSINT通常不是现成可用的。相反，分析原始数据是必要的，以确定可信、有效和可验证的信息。即使最初的信息可能不是最好的，它也可以为进一步的调查提供一个起点。

![](../Images/d83d69482467e4af15bb725d78f891e9.png)

   

另一个障碍是分析人员在确定适当的OSINT方面可能缺乏足够的主题专业知识。与此相关的是，一个人对这些信息的固有偏见也可能降低这些信息的潜力。其他潜在的障碍还包括缺乏有效的分析工具，以及多家媒体报道dame的故事，从而可能会扭曲某个特定的消息来源，给它更多的可信性。

 

尽管存在这些潜在的缺点，但OSINT是一个重要的工具，应列入每个执法机构的全部工作表，因为其中可能有大量宝贵的信息。多年来，情报机构一直被批评没有充分利用可用的OSINT。从1996年的Aspin-Brown委员会到2001年的9/11委员会，再到2005年的大规模杀伤性武器委员会，增加使用现有的OSINT可能会导致截然不同的结果。

![](../Images/5cabf1616f51c12780da3834274df116.png)

  

*“OSINT是一个重要的工具，每个执法机构都应该使用它，因为其中可能蕴藏着丰富的宝贵信息。”*

 

考虑到罪犯的进化和越轨意识形态的传播，技术必须跟上。因此，执法机构应及时掌握获取情报的新方法，以加强对罪犯的识别和逮捕，并预防犯罪。的军事和安全机构已经公开接受OSINT和AI力量和资源乘数来提高他们的情报收集工作回避了问题的实质关于为什么警察机构一直不愿冒险让AI和OSINT增长他们的当前活动的一部分。虽然不能完全替代传统的情报收集工作和警务活动，但OSINT和人工智能提供了显著的成本效益提升，节省了宝贵的时间和人力资源，提高了一个机构的效率。
