# 10个对初学者最有用的OSINT工具

**OSINT或开源情报**是收集免费供公众使用的信息的过程。当你不得不为一个学校项目研究一个主题时，你会怎么做。您可以找出所有来源（在线和离线），从那里您可以挖掘信息并从中获取一些意义。  

在黑客攻击中，OSINT是情报收集中最重要和最基本的方面之一。您可以使用网站，搜索引擎，社交网络，博客，视频，播客甚至报纸来收集关键信息。

这种技术的美妙之处在于，它是如此普遍和明显，以至于每个人都已经使用它，他们只是还不知道它。难道我们不是都在网上搜索信息?

不断使用互联网上的免费和公共信息供个人使用。即使是现在，当您搜索"OSINT"并进入本文时，您也使用了OSINT！

但是出于黑客攻击的目的，在互联网上筛选一些你显然可以期望不那么容易找到的信息是不切实际和愚蠢的。这就像大海捞针一样。这就是这些工具派上用场的地方。

## **1\. Google dork**

**目标：搜索网页**  
你知道吗，如果你问谷歌正确的问题，你会惊讶于它能告诉你什么。  
使用 Google dork 查询执行智能和高级搜索操作，并查找：

*   否则很难找到的信息
    
*   不适合公众查看但未得到良好保护的信息
    
*   敏感信息，如用户名和密码、电子邮件列表、个人身份财务信息 （PIFI）
    
*   易受攻击的网站/系统
    

## **2\. LinkedIn**

目标：搜索员工信息  
使用LinkedIn获取公司的内部视图。它具有足够的员工信息（全名，工作角色，使用的软件），可用于执行模拟等社会工程攻击。  
您甚至可以通过深入研究员工的个人资料来查看该公司正在使用的技术。

### **3.****Wappalyser Plugin ****幻影师插件**

**目标：**查找网站上使用的技术  
许多公司使用易受攻击的技术，为黑客提供轻松的入口。在定位公司或机构时，您可以使用此工具来了解他们的网站框架并查找他们使用的技术中的漏洞。

![](../Images/a20c07bf947e8432b646ae7fd35e3daf.png)

### **4. ****CT and Sublist3r**

**目标：**枚举子域  
一个网站有许多子域。例如，blog.website.com 和 shop.wesbsite.com 是 website.com 的子域。这些子域可能容易受到许多网络攻击。使用这两个工具，您可以查看目标网站的所有子域。

**a. 证书透明度**

为域颁发的所有 SSL/TLS 证书均由证书颁发机构发布以供公众查看。这称为证书透明度 （CT）。  
使用 CT 日志 ，您可以搜索为目标公司颁发的所有此类证书，从而找到易受攻击的域。

示例：在 https://crt.sh 上键入** %.**stackoverflow.com 以查找其所有子域。

![](../Images/8cbd92a55c4630c1f7437ead5fffd4a5.png)

**b. Sublist3r：**  
专门为此 OSINT 技术设计的 python 工具是 Sublist3r。它使用许多搜索引擎和其他网站，如Google，Yahoo，Bing，Virustotal，DNSdumpster等，来制作网站的子域。黑客可以使用它来查找易受攻击的域。集成了 Subbrute 和 sublist3r，以结合其域枚举功能并创建功能强大的工具。

![](../Images/56b6e7651096064429464ac48512ef6c.png)

### **5. TheHarvester**

**目标：**查找电子邮件  
通过社交工程定位组织的最常用的方法之一是网络钓鱼。您可以使用此OSINT工具查找所有员工的电子邮件 - TheHarvester。它预装在Kali Linux中，并使用多个数据源（显然是公共的）来收集电子邮件，子域，URL，IP等。

![](../Images/6e54f6c22e46d3e013b5ac1095d9b303.png)

### **6. ****WHOIS**

**目标：**获取域名信息  
如果您知道如何使用它，那么有关公司的任何信息都可能很有价值。每个域都有其注册记录，其中包含创建日期，到期日期，更新日期，名称服务器，管理员联系人，注册人电子邮件，组织名称，地址，电话号码和其他技术信息等详细信息。使用WHOIS工具获取有关目标的域信息。

您可以使用此信息创建一个结构，并尝试在目标内部找到一种方法。例如，您可以使用注册人的电子邮件（通常是开发人员的电子邮件）使用12345678之类的内容作为密码来闯入网站服务器。你能猜到为什么这可以工作吗？在下面发表评论，我们会告诉您是否正确。

![](../Images/f9290ce68082da60c4e5aabfc4682198.png)

#### **7\. DNSRecon**

**目的：**查找 DNS 信息  
DNS 信息收集难怪是渗透测试的基本要求，因为它在映射网络基础结构方面提供了大量的帮助。这种OSINT技术的一个有用工具是DNSRecon（一种python脚本），它可以枚举一般的DNS记录，如MX，SOA，SRV，DNSSec，SPF，TXT等。  
它还可以执行Google查找，检查区域传输，暴力破解子域，进行反向查找和缓存窥探。

尝试使用以下命令暴力破解子域：  
**dnsrecon -D /usr/share/wordlists/subdomains-top1mil-5000.txt -d website.in -t brt**

![](../Images/e8d3dfa787d61b6d6b3b8fff9aa7e81f.png)

#### **8. ****WayBack Machine**

**目标：**查找旧网页  
网站不断更新，但可能仍在后端运行旧网页。如果您可以看到目标网站的所有网页，您可能会发现其中一些使用过时的技术，从而使它们容易受到攻击。  
那么，您如何回到过去并访问旧网页？

我们知道您在想什么。但是不，你不需要一台时间机器（尽管它会派上用场）。Wayback Machine有一个庞大的网页数据库，其中包含随着时间的推移而保存的网页。

![](../Images/4c725237894dfd5fcec6d1c20c1f66ac.png)

#### **9. ****Pipl**

**AIM：**挖掘一个人  
在互联网上挖掘一个人的所有信息需要付出艰苦的努力。多亏了人员搜索引擎，您可以合法地收集有关某人的每一点数据，以勾勒出他们的个人资料，这可以进一步用于创建针对其电子邮件帐户的潜在密码列表。

Pipl.com 就是这样一种工具（付费但值得每一分钱），它可以让您掌握一个人的整个在线状态。他们的电话号码，用户名，电子邮件，深网结果。基本上一切都很好。

![](../Images/23028a21704959bb703240b359118995.png)

#### **10. ****Shodan**

**目标：**访问每个设备  
忘记网站，你可以从连接到互联网的所有东西中挖掘智能，如网络摄像头，智能电视，建筑物，发电厂，冰箱，安全系统，我们可以继续前进，但你明白了。

使用 Shodan.io 搜索物联网。
