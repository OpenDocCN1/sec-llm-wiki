# 美国新冠疫苗虚假帖子工具—covaxxy

![](../Images/2dfa722f2b65b45d4241ad510727e65a.png)如今，社交媒体成为人们获取信息主要来源。社交媒体的言论、新闻是否真实可靠需要进一步验证。美国印第安纳大学社交媒体观察站（OSoMe）与米兰理工大学的同事合作进行，旨在跟踪和调查推特上的帖子如何影响COVID-19疫苗吸收率。并且该网站是公开免费面向大众的。

该网址为：CoVaxxy (iu.edu)

  

![](../Images/5e4d4376f4c66524db66081e21461132.png)

  

**该网站总共分为以下几个模块：**  

**一、美国各州疫苗接种帖子的地图**

在这个区域你可以选择接受一剂、接收两剂、未接种、分发的疫苗等地图分布情况。还可以选择接收一剂或者两剂的百分比。

  

![](../Images/cd422cc2ec09bcc99ca217ac7231e92f.png)

**二、在线讨论和疫苗的相关性**

在这个模块，使用人员可以看到有关于疫苗未接种的百分比以及低可信度来源帖子的相关分析、接种一剂的、接种两剂的分析。调节X、Y轴进行其他分析。  

![](../Images/1cd7dd15e45279ee0fab297365eff554.png)

  

**三、疫苗接收**  

可以观察到美国各个州对于分发疫苗的统计数量、接收一剂、两剂的统计数量等等。

![](../Images/a1e476c33565e777d324744f0774f0b6.png)

![](../Images/90f3b6cb24d3e121f9fae18fd27a5c4d.png)

  

**四、低可信度和主流来源**

在这个模块可以观察到低可信度的主要来源网址
