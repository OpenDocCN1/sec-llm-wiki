# 人工智能如何分析俄罗斯的下一步行动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650496844&idx=1&sn=3b6db54db7569a5b0c97c8c64f3dd623&chksm=87167107b061f8113f661ce382049682b13862f916c38c9f56905ffbf7dcd58ce850a742036b&scene=126&sessionid=1681267305#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650496844&idx=1&sn=3b6db54db7569a5b0c97c8c64f3dd623&chksm=87167107b061f8113f661ce382049682b13862f916c38c9f56905ffbf7dcd58ce850a742036b&scene=126&sessionid=1681267305#rd)

![](../Images/a53c772273594b6bc643d533aed68dbe.png)

随着情报分析师可以使用大量数据，新工具将帮助他们筛选和解释所有数据，但它们也将带来新的风险。  

![](../Images/815e8e25fd678193ebc45fb0cebfe142.png)

在3月初，有一种在乌克兰和几名俄罗斯士兵之间的无线电传输，从一条未加密的通道中被捕获，揭示了惊慌失措和困惑的士兵在炮火下撤退的过程。

当士兵们说话时，一个人工智能工具正在监听。他们说话的内容被自动捕获，转录，翻译和分析。使用Primer开发的几种人工智能算法，Primer是一家为情报分析师提供AI服务的美国公司。虽然目前尚不清楚乌克兰军队是否也拦截了通信，但使用人工智能系统大规模监视俄罗斯军队表明，这种监听模式在复杂的开源情报在军事冲突中的重要性日益增加。

![](../Images/aeef7226cc0f38c31e24d9b30bc3f8c9.png)

许多不安全的俄罗斯监听内容已被发布在线，翻译并在社交媒体上进行分析。其他数据来源，包括智能手机视频剪辑和社交媒体帖子，也同样受到审查。但是，使用自然语言处理技术来分析俄罗斯军事通信特别受到关注。对于乌克兰军队来说，理解截获的通信通常仍然需要人力分析人员在某个房间内工作，翻译信息和解释命令。

  

Primer开发的工具还展示了机器学习对于解析情报信息的价值。在过去的十年中，人工智能在图像识别、语音转录、翻译和语言处理方面的能力有了重大进展，这要归功于从大量训练数据中学习的大型神经网络算法。

  

使用 AI 的现成代码和 API 现在可以转录语音、识别人脸和执行其他任务，通常具有很高的准确性。面对俄罗斯的数量和火炮优势，拦截通信很可能对地面上的乌克兰军队产生影响。

![](../Images/2e54429162046456541736eebff4f5f2.png)

Primer已经销售了经过训练的人工智能算法，可以转录和翻译电话，以及可以提取关键术语或短语的算法。Primer首席执行官肖恩·古利（Sean Gourley）表示，该公司的工程师修改了这些工具，以执行四项新任务：收集从网络馈送中捕获的音频，这些音频使用模拟无线电接收器硬件的软件广播捕获的通信;消除噪音，包括背景颤动和音乐;转录和翻译俄语语音;并突出与战场局势有关的关键陈述。在某些情况下，这涉及重新训练机器学习模型，以识别军用车辆或武器的口语术语。

  

Gourley说，在飞行中训练和重新训练AI模型的能力将成为未来战争中的关键优势。他说，该公司向外界提供了该工具，但拒绝透露是谁。"我们不会说谁在使用它，或者他们用它来做什么，"Gourley说。其他几家美国公司在与俄罗斯侵略者作战时向乌克兰提供了技术，信息和专业知识。

![](../Images/d38e7045cdbf5330f36cb49af0ccc436.png)

  

一些俄罗斯军队使用不安全的无线电频道的事实令军事分析人士感到惊讶。这似乎指向了一场资源不足、准备不足的行动，智库新美国（New America）专门研究现代战争的高级研究员彼得·W·辛格（Peter W. Singer）说。

  

辛格说："俄罗斯在过去像车臣这样的冲突中使用公开通信的拦截来瞄准其敌人，因此，在所有力量中，他们应该知道风险。他补充说，这些信号无疑可以帮助乌克兰人，尽管分析很可能是手动完成的。"这表明了通信设备故障，一些傲慢，可能还有俄罗斯军方高层的绝望程度，"退休的澳大利亚将军和作家米克·瑞安（Mick Ryan）补充道。

  

哈佛大学间谍历史学家考尔德·沃尔顿（Calder Walton）说，俄乌特别军事行动表明，开源信息对情报人员来说是多么宝贵。面部识别软件已被用于识别冲突视频中的一些人。"就情报收集的性质和可用内容而言，处于绝对的分水岭，"沃尔顿说。

![](../Images/085b40042b20914d83693164c725e289.png)

这场冲突凸显了挖掘不同情报来源的重要性。例如，乌克兰军队可能通过在卫星，无人机或其他图像的天线附近寻找需要找的人，成功地瞄准了一些俄罗斯将军。俄罗斯军队也开始使用手机，有时会透露他们的位置和任务细节。

  

沃尔顿（Walton）即将出版一本关于过去100年俄罗斯与西方情报战的书的作者，他说，美国主要的信号情报机构国家安全局（NSA）以及英国的GCHQ很可能拥有Primer正在使用的各种工具的版本。

  

但Primer是越来越多的公司之一，这些公司可以使国防界和私营企业更容易获得这些技术。私营公司参与乌克兰战争，例如提供卫星通信和成像的公司，引发了人们对这些公司赋予的权力以及它们如何卷入国际冲突的质疑。

![](../Images/e5618db6253f60f483c88a8017e500d5.png)

利用开源情报数据意味着筛选大量信息。"开源情报的数量对任何人来说都不可能处理，"政策研究非营利组织战略与国际研究中心（Center for Strategic and International Studies）的高级研究员艾米丽·哈丁（Emily Harding）说，她在2022年1月写了一份关于使用人工智能挖掘开源情报的报告。

  

哈丁说，智能世界在使用机器学习工具分析图像方面已经变得更好了。对图像内容进行分类是展示现代人工智能力量的首要任务之一。哈丁说，Primer以其解析语言的能力而著称。

  

人工智能的最新进展可能会使该技术成为分析文本和语音的更强大的工具。近年来，人工智能已经能够使用文本总结或回答问题，这要归功于一种称为变压器的特殊大型机器学习模型。这种类型的AI模型能够更好地理解输入，例如句子中的一长串单词。这些已经产生了能够生成连贯的新闻文章甚至编写计算机代码来执行给定任务的AI程序。
