# 社交媒体分析工具——One Million Tweet Map

今天给大家推荐一个在线的社交媒体分析工具，One Million Tweet Map，该工具可以在世界地图中可视化汇总实时生成的推文，其中不仅包括 Twitter ，也有 Instagram 等社交媒体软件的推文。

**网址：https://onemilliontweetmap.com/**

![](../Images/b1858ae7547dc33506d601fb9e4187bc.png)

  

特点：

1.  地图显示的是24小时内的地理定位推文
    
2.  数据实时更新，仅保留24小时内的推文
    
3.  每秒都添加大约50条新推文
    
4.  支持使用过滤器来筛选你想要的信息  
    

  

接下来具体介绍该工具的用法：

  

**一、关键词、热词标签或发文作者名搜索**

  

![](../Images/d126417b62ac6279c5640976a2884d5a.png)

如图在搜索处输入Ukraine，地图就可以显示24小时内全球关于该关键词推文的状况

  

![](../Images/47eb4c6f2357bea0968d1d03d8d176e0.png)

点击右上角的分析按钮即可看见关于该词的相关搜索标签、国家、城市以及语言，并按照搜索热度进行排列  

  

**二、选择图层视角**

左侧可以选择热点地图、聚类以及昼夜三个图层，掌控搜集信息的热点分布、聚类数目以及发文时间，是十分方便的可视化选项，具体操作如图：

![](../Images/2b19e05d07589939903195bbd87487a4.png)

  

**三、情绪分析视图**

该工具利用情感算法，初步计算了推文所带有的的情感色彩，分为积极、中性、负面三个层面，对应绿色、黄色、红色三个颜色，同时也提供了可视化视图。每条具体的推文也有感情色彩的判断。具体操作如图：

![](../Images/018149ac10bb8edca180c2b0775ef525.png)

  

**四、时间过滤器**

时间过滤器可以分为5分钟、10分钟-20小时等12个时间段，方便进行精确时间推算，也能从当前开始收集推文。具体操作如图：

![](../Images/cec3c76d1e1afb29d5ccff3467173820.png)

![](../Images/9001ae5ab1c21337cdfe5590981a2540.png)

![](../Images/7e8e90c60bafde9265ef2081691dbd82.png)

  

最后，从每条推文来看，该工具上都有具体的来源，可做到准确溯源。
