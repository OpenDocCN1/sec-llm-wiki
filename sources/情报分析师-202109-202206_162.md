# 生物攻击与恐怖主义：FBI《刑事与传染病病联合调查手册》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650496536&idx=1&sn=51bd4b0a1aa0656cec5ac38ed93b2acd&chksm=87167053b061f945eb65ac0e16cd30c3210a88e98ffeff7a1d032d86d4de7b95904a64a8a219&scene=126&sessionid=1681267305#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650496536&idx=1&sn=51bd4b0a1aa0656cec5ac38ed93b2acd&chksm=87167053b061f945eb65ac0e16cd30c3210a88e98ffeff7a1d032d86d4de7b95904a64a8a219&scene=126&sessionid=1681267305#rd)

今天小编为您整理并推出美国联邦调查局（FBI)编写的《刑事与传染病联合调查手册》，该书主要是针对恐怖主义犯罪实施生物武器攻击采取的调查方法及详细教程。

![](../Images/b340c08e08c72eaf66166632f6383959.png)

随着 恐怖组织和个人对获取和使用生物制剂作为针对美国人口的武器表现出兴趣和意愿越来越突出，该领域进行联合调查的工作越来越重要。

  

在实际调查中， 故意释放的生物制剂最初可能很难与自然事件区分开来，公共卫生和执法部门可以实现各自的目标，但往往是重叠的目标，即查明生物制剂、防止疾病传播、防止公众恐慌和逮捕责任人。这可能导致执法和公共卫生调查的分离，为此，在首次调查可疑的生物突发事件时，合作符合公共卫生和执法部门的最佳利益，这包括促进相互了解和建立联合通信程序。

  

因此，该手册的最终目的是为了促进资源的利用，最大限度地加强执法部门和公共卫生部门之间的沟通和互动，努力减少应对生物威胁之前和期间的潜在障碍。

![](../Images/4ac29905d801f4f9baa6b94e9ab64afe.png)

  

**具体而言，本手册旨在：**

1.  概述执法部门和公共卫生部门的情况，以提高对每个学科的专业知识的掌握和理解；
    
2.  讨论应对生物威胁的刑事和流行病学调查程序和方法；
    
3.  确定信息共享的挑战，并提供可能的解决方案，以满足不同机构和管辖区的需要和管辖区的需要；
    
4.   展示有效的执法和公共卫生合作。
    

![](../Images/1ae665d1a206f1393ecdbee6f5d3c05e.png)

  

## **手册的主要内容：**

1.  ###### 恐怖组织和个人对获取和使用生物制剂作为针对美国人口的武器表现出兴趣和意愿。
    
2.  故意释放的生物制剂最初可能很难与自然事件区分开来，这可能导致执法和公共卫生调查的分离。
    
3.  在首次调查可疑的生物突发事件时，公共卫生和执法部门合作是最有利的，这包括促进相互了解和建立联合沟通程序。
    
4.  通过合作，公共卫生和执法部门可以实现各自独立但往往重叠的目标，即查明生物制剂、防止疾病传播、防止公众恐慌和逮捕责任人。
    
5.  鼓励执法部门和公共卫生部门阅读整本手册，而不是仅仅局限于各自的章节，这样每个社区都能了解另一个组织的不同目标和需求。
    
    ![](../Images/00f9d836b8461177db9dcb27f5a14e23.png)
    

## **公共卫生机构的主要工作：**

###### •   流行病学调查的最终目的是确定疾病的来源，并实施控制疫情和保护公众健康；

•  流行病学调查主要包括从病人访谈和调查中细致地积累信息，以及从监测系统中收集的数据。

  

**流行病学调查的目标包括：**

• 阻止疾病的传播（确定致病因子、来源、传播方式和危险人群）；

• 保护公众的健康（监测、医疗对策、健康教育）；

• 保护公共卫生和其他应对人员（防护设备和预防性疫苗/药物）；

•  流行病学调查的重要内容有；

•  检测异常事件；

•  确认诊断；

•  识别和描述其他病例；

•  确定接触源；以及制定和实施干预措施。

![](../Images/15412115f4c023e7c0439b76fbd444d9.png)

对临床标本的实验室分析是用来帮助医生做出明确的诊断。虽然大多数医生会等待明确的实验室结果来确认生物威胁剂的诊断，但医生可能会在实验室测试结果出来之前就开始治疗，因为疾病的早期治疗会增加病人从疾病中康复的概率。

  

检测生物制剂的实验室应达到适用的标准（如质量控制措施、生物安全和生物安保），并参加相关的能力测试。

![](../Images/3366cf389e98436623dd4794ed5f9b45.png)

  

## **执法机构的主要工作：**

###### 对生物威胁进行刑事调查的主要目标：

•  保护公众的健康和安全。

•  防止随后的攻击。

• 识别、逮捕和起诉肇事者；

•  保护执法人员。

  

如果公共卫生部门和执法部门在发生生物威胁事件之前已经建立了工作关系，公共卫生部门在调查初期与执法部门联系时可能会感到更加自如。执法部门应包括各种主题专家，如公共卫生，以协助确定生物威胁的可信度。一旦怀疑发生了犯罪，执法部门和公共卫生部门都应执行监管链程序。执法部门和公共卫生部门都应执行监管链程序，以确保对证据负责。

  

 如果不能适当地维护监管链，可能会使证据在审判中无法使用。在某些情况下，环境可能会被污染；因此，拥有经过专门培训的执法小组来处理以下问题是非常有用的。收集在受污染的环境中抓捕嫌疑人的证据，快速收集和测试以拯救生命的需要超过了正常的证据收集程序。

  

## **刑事和流行病学联合调查的主要内容：**

###### 刑事-流行病学联合调查模式由六个战略要素组成：

1.  建立关系；
    
2.  信息共享；
    
3.  联合威胁评估；
    
4.  联合调查；
    
5.  谅解备忘录/联合协议；
    
6.  联合培训和演习。
    

  

**开展联合调查的好处：**

• 执法部门可以接触到了解疾病流行病学的公共卫生专家，并可以提供相关的医疗信息；

• 公共卫生部门可以获得执法部门的案件信息，这有助于确定接触源和遏制疫情的发生；

  

在应对措施的早期阶段及时交流信息是至关重要的。  这两个学科都能获得独特的信息，有助于预防或检测生物威胁。利用两个学科的独特专长进行的联合威胁评估，可以帮助确定更快地确定事件的性质（故意的或自然的），从而对威胁作出更适当的反应。

联合调查可以在发生生物威胁时，通过交流实时调查信息，最大限度地统一执法和公共卫生部门的工作。执法部门和公共卫生部门之间的备忘录或联合协议对于在事件发生前确定角色和责任至关重要，并有助于确保在应对过程中各部门的做法一致。  

备忘录或联合协议中应包括的重要信息包括：信息共享触发器、联合威胁评估、联合调查、联合访谈以及共享调查结果的方法。

![](../Images/839792cca1d8807551a1d335ea1a3c52.png)

联合培训和演习是刑事与流行病学联合调查模式的重要内容，因为它们使公共卫生和执法部门能够测试、评估和完善其协议。修改协议以反映从演习中获得的经验教训，对于确保最佳做法的发展和随着时间的推移得到加强尤为重要。

  

总之，手册概述了执法部门和公共卫生部门的作用和责任，并指出联合刑事与流行病学调查模式是更有效地准备和应对生物威胁的一种最佳做法。通过实施 "刑事与流行病学联合调查模式 "的各种要素（如信息共享、联合威胁评估和联合调查/联合访谈），执法部门和公共卫生部门可以在应对生物威胁时最大限度地利用其资源，实现其各自和共同的目标。

  

手册中描述的程序和方法旨在作为一个指南。执法部门和公共卫生部门应修改本指南，以适应其机构、辖区或国家的具体需要、法规和权力。
