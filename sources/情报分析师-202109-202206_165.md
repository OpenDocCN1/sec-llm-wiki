# 情报信息技术专业委员会举办专题学术讲座

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mjc1MTkwOA==&mid=2650496488&idx=3&sn=eb797b9cf4712f70b590442a44dc37bc&chksm=871673a3b061fab585724b116472fef02064320a42b03eabf97c0f950bc3535069ffbbc9358c&scene=126&sessionid=1681267314#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mjc1MTkwOA==&mid=2650496488&idx=3&sn=eb797b9cf4712f70b590442a44dc37bc&chksm=871673a3b061fab585724b116472fef02064320a42b03eabf97c0f950bc3535069ffbbc9358c&scene=126&sessionid=1681267314#rd)

近日，情报信息技术专业委员会，情报研究中心举办学术讲座，题目是《江苏公安大数据实战应用人才建设发展的探索实践》，由江苏省公安厅大数据局张浩鑫副局长，数据实战室主任王金主讲。专家就公安大数据人才的需求、现状、选拔、培养、管理和实战应用进行了精彩的分享。情报信息技术专业委员会部分领导和专家，以及来自公安院校的教师和研究生参加了讲座，并对讲座做出了高度评价。
