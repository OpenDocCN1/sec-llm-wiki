# 报告52页|《通过情报主导警务减少犯罪》

 通过针对暴力犯罪的倡议，美国司法部司法援助局（BJA），司法项目办公室发布《情报主导警务减少犯罪》报告，报告方法已经确定了美国各地的许多执法机构在打击困扰其社区的复杂犯罪问题上取得了巨大的成功。这些机构努力的基石似乎是将以情报为主导的警务工作与其他举措相结合，以解决其犯罪问题。

![](../Images/fcf87c636b875684dfcfff0256ce9ddf.png)

  

本报告的目的是在犯罪和混乱领域以及恐怖主义之外，以情报为主导的警务（ILP）的新实验并介绍了其中一些取得了明显的成功案例。

  

报告为收集信息制定了一份协议，一个小组访问了十个机构，审查数据和政策并进行访谈。尽管这些机构表现出不同的运作方式和组织风格，但很快就可以看出，它们有某些共同点，对它们的成功至关重要。这些特点包括：

*   指挥部承诺
    
*   问题的明确性
    
*   积极合作
    
*   有效的情报
    
*   信息共享
    
*   明确的目标
    
*   以结果为导向的战术和战略
    
*   全面的调查
    
*   警官问责制
    
*   持续评估
    
    ![](../Images/2bab2b153665364682e9cd1a69f29ecf.png)
    

本报告中的案例研究证实了这样一个事实，即实施情报主导警务大大增强了这些高绩效机构获得成功的能力。  情报主导警务在这些机构中得到了不同程度的实施，并经常得到其他警务实践的补充，如社区警务、问题解决，以及基于强大数据收集和分析。

![](../Images/11ab1b538df62b8fcebecd76e7f035ce.png)
