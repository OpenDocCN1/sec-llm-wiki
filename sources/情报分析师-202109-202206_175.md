# 刚刚！美国发布《跨大西洋数据隐私框架》

欧盟委员会和美国宣布他们原则上达成了一项新的跨大西洋数据隐私框架，该框架将促进跨大西洋数据流动。经过近两年的不确定性，隐私领导者以欧盟委员会（EC）宣布的形式发布了一些好消息，涉及欧盟（欧盟，以及冰岛，列支敦士登和挪威 - 包括欧洲经济区）和美国之间关于新的跨大西洋数据隐私框架的原则协议。

![](../Images/a6e2fc6f3d94302569873dec4d21cbce.png)

# **基于新的框架：**

*   基于新框架，数据将能够在欧盟和参与的美国公司之间自由安全地流动；
    
*   一套新的规则和具有约束力的保障措施，将美国情报当局对数据的访问限制在保护国家安全的必要和相称范围内；
    
*   美国情报机构将采取程序，确保有效监督新的隐私和公民自由标准；
    
*   一个新的两级补救系统，用于调查和解决欧洲人对美国情报当局访问数据的投诉，其中包括数据保护审查法院；
    
*   处理从欧盟传输的数据的公司承担的强烈义务，这将继续包括通过美国商务部自我证明其遵守原则的要求；
    
*   具体的监测和审查机制。
    
      
    
    ![](../Images/c2dd5b81daa9991b808ed17e4740e885.png)
    

**具体的监督和审查机制：**

1.  充分保护转移到美国的欧洲人的数据，解决欧洲法院的裁决
    
2.  安全和可靠的数据流
    
3.  持久和可靠的法律基础
    
4.  具有竞争力的数字经济和经济合作
    
5.  持续的数据流支撑着每年9000亿欧元的跨境贸易
    

![](../Images/15c579beba36d4696ab2f65aac0ef1af.png)

## **采用跨大西洋数据隐私框架的后续步骤：**

在联合声明中，跨大西洋数据隐私框架是欧盟和美国之间"原则上"达成的协议。这意味着在文本最终确定之前，双方都有更多的工作要做。在制定下一步行动时，双方都对新框架将包括的内容进行了高层次的概述。

  

美国提供了新闻稿和情况说明书。 在新闻稿中，美国确定了它将通过总统行政命令采取的一般承诺，以实施这项新的"突破性协议"。

例如，美国表示，它不仅将创建一个"新的多层补救机制，其中包括一个独立的数据保护审查法院"，而且还"确保信号监视活动是必要的，并且与追求既定的国家安全目标相称"。 

  

十多年来，一个永久而成功的结构，以促进欧洲经济区和美国之间的跨境转移，这一新的安排将是为了减轻可预见的法律异议而制定的。双方都保证这一点，并坚定不移地坚持自己的意图。

![](../Images/2d459731f0f94bab8baeacbe3ed0124d.png)

## **跨大西洋数据隐私框架何时被采用？**

虽然许多细节仍不清楚，但美国和欧盟委员会表示，下一步将是将原则上的协议转化为法律文件。

首先，考虑到欧盟通过的最后两项充分性决定共93页（英国）和122页（韩国）。两者都比当前的隐私护盾框架长得多。

此外，美国必须通过行政命令实施的机制并非微不足道，特别是建立数据保护审查法院。也就是说，我们将继续关注本协议的发展，并期待在要求发布后向您更新。

一旦准备就绪，协议将根据《通用数据保护条例》的要求提交给欧洲数据保护委员会批准。

欧洲数据保护监督员还发表声明，原则上支持该协议，称赞他"认识到此类协议对加强欧盟 - 美国长期关系以及对隐私和数据保护重要性的相互理解的重要性的重要性。
