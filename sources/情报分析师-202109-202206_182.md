# 黑客攻击俄罗斯通讯：赫兹问题

截至最近，俄罗斯在乌克兰的战争导致许多人怀疑俄罗斯军队是否真的遭受了某种弊端，或者这仅仅是一种行为。

![](../Images/48c1d8674c4b3cf327c5df2e4434bffc.png)

据一些情报机构称，俄罗斯军队之间的无线电通信可能真的很差。事实上，俄罗斯军方似乎正在使用未加密的高频无线电进行远程通信，甚至使用手机与位于几公里外的其他部队进行通信。  

只有一些单位（可能是第90近卫坦克师）可能配备了更先进的软件定义无线电（SDR），如R-187P1 Azart或R-168-5UN-2战术无线电。例如，前者是第六代数字战术SDR，内置加密功能，旨在抵抗干扰攻击并在甚高频（VHF）/超高频（UHF）频段内运行。除此之外，这些无线电可以用作中继站，也可以使用GLONASS（一种俄罗斯天基卫星导航系统，基本上代表了传统GPS的替代品）或GPS。这些设备应该在长距离（长达350公里）上提供可靠和不间断的通信。

![](../Images/4bcc356f2810389fab273ba6b61895d4.png)

据俄罗斯政府官员称，Azart系列无线电促进了指挥和控制（C2）网络与部署在乌克兰领土上的其他系统之间的目标数据共享过程。但是，如果真的是这样，为什么俄罗斯士兵会恢复使用手机进行通信，而不是他们所谓的先进无线电系统？

这是一张乌克兰平民的照片，他发现了一架宝锋无线电UV-82HP，他声称在一次行动后被俄罗斯士兵遗弃了：

![](../Images/e0dc54f580e45e68645034e2e3dda5be.png)

该帖子说："占领者使用传统的模拟宝丰对讲机😂，您需要了解的有关大军的一切"。

电磁频谱，无线电频率和波的世界经常被分析人员忽视;它甚至更少被公众考虑。不过，它往往是军队的骨干。部队相互沟通的效率和/或有效性主要取决于他们的沟通有多好。

对于电子战从业者来说，利用宝锋UV-82HP并不是一项艰巨的任务。当涉及到他们的COMSEC / TRANSEC（通信和传输安全性）时，这些无线电非常不足。攻击者很容易将自己置于这些通信的中间并冒充其他人，甚至向另一个对话者提供虚假信息。作为一名乌克兰士兵，最大的好处是在俄罗斯军队中散布混乱和混乱，使他们放慢速度或诱使他们认为他们需要瞄准自己的同志，因为他们是敌人，而不是真正的乌克兰军队。

这是一种不对称的威胁。COMINT（通信情报）行动可以进行检测这些传输，以追踪和监视俄罗斯军队的动向，特别是当知道俄罗斯士兵正在使用手机进行通信时。

据报道，俄罗斯武装部队可以通过其RB-314V Leer-3 EW或RP-377U / UA EW系统干扰民用V / UHF通信，包括双向无线电和移动电话网络。

![](../Images/beab713f7918ee0a6b6f44e552248c49.png)

高频通信也具有很大的相关性，因为它们执行"超视距通信"。事实上，HF使用电离层在地平线上反弹无线电传输。高频也非常用于远程干线通信，在北约部队中具有与卫星通信相似的重要性。尽管如此，俄罗斯军队仍然可以使用国内军用级SATCOM。然而，对HF的偏好主要是由于高频无线电非常难以干扰。因此，这些传输，即俄罗斯的高频无线电传输，非常容易被拦截和利用用于情报目的。我们现在有三种情况需要考虑：  
1）俄罗斯军队根本不在乎有人可能正在拦截他们。  
2）他们可能以此为借口故意传递虚假信息，从而误导乌克兰军队。  
3）他们没有适当的硬件来加密他们的通信，因此通过安全通道传输。

如果配备正确的COMINT / COMJAM装备，这样的通信可能会被拦截甚至干扰/干扰，从而使俄罗斯军队很难在整个C2基础设施中协调其行动。乌克兰军队还可以通过定位其无线电传输的来源来了解俄罗斯军队在该领土上的真实位置。

那么，这里的关键要点是什么？在战争中，即使是电磁球也是一种攻击媒介，军队可以利用它来获得对敌人的战术优势。乌克兰人实际上可能会阻止他们的对手利用光谱，可能会减慢他们在领土上的行动和行动。这也表明，当正确的专业知识与正确的技术类型相结合时，可以多么深刻和微妙地影响冲突的结果。
