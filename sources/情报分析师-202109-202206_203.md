# 本文会教大家如何通过Firefox浏览器**将PDF 转换为 HTML 之后进行翻译**，  

  

**第一：**将链接复制到Firefox浏览器：https://translatewebpages.org/，会出现这个页面。

![](../Images/0c3e6f0f0df0b2013161fe7c64d5585c.png)

**第二****：**点击选择文件，上传你准备好的文档之后等待片刻。  

![](../Images/8989eed51b0505155cbba399d06722f4.png)

  

**第三：**文档会以这种形式进行展现，点击如下图所示的图标进行翻译。  

![](../Images/b377e3eb7c062cb04775fdbed9cb5105.png)

**第四：**选择中文（简体），你就会看到翻译后的页面。  

![](../Images/7b32ad6bfe963504af329cc403803c91.png)

![](../Images/10c57885496ada1966915e1f67e0343a.png)

  

**缺点：**将PDF 转换为 HTML 之后图片不会保留，只保留文字。所以在具体浏览时需要与原文进行对比。
