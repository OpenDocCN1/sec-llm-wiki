不确定拍的视频或照片是什么时间？如何通过测量阴影的长度来判断

对于开源研究人员来说，在视频或图像中确定时间可能是一项困难而又令人沮丧的任务。如果你幸运的话，你会得到一个简短的一瞥一个挂钟或手表，但在大多数情况下，你不会。然而，测量阴影，可以帮助提供一个解决方案。众所周知，利用阴影的角度来评估图像中的时间是可能的。SunCalc，一种模拟太阳在不同日期和不同地点在地球上空的运动的工具，可以相对容易地做到这一点。

然而，有时这些阴影的角度可能不清楚，或者在视频或图片中可能没有足够的参考点来准确地判断角度。


但是，正如阴影的角度可以用来计算太阳从北(方位角)的角度，所以阴影的相对长度可以用来计算太阳从地平线(高度)的角度。

当太阳在天空中升起时，阴影最初将指向西，并在中午左右达到最短长度之前就开始了。然后，当它们在日落前逐渐拉长时，它们将指向东方。这种可预测的长度变化可以用来判断时间。重要的是，没有必要知道投射阴影的物体的实际高度。重要的是成比例与物体相比较的阴影长度。这意味着本文中所看到的测量与物体和阴影的实际高度和长度无关。但由于我们只对它们的比例感兴趣，所以这并不重要。

为了使这一技术能够很好地工作，图像或视频需要满足以下几个条件：

  1. 必须知道图像的位置和日期。

  2. 物体及其阴影必须与摄像机大致成直角。

  3. 阴影必须与地平线(平地板)在地面水平上投射。

  4. 图像不应被镜头(如鱼眼镜头)过度扭曲。

最后，在执行这项技术时，应该注意到，在一天中，阴影将是一个特定的长度两次：上午一次，下午一次。因此，检查阴影的方向是很重要的。

示例一：受控条件

在这个例子中，我使用了我于2019年10月14日在耶路撒冷阿克萨大院拍摄的一张照片。让我们用比例长度技术来应用阴影，看看我们计算的时间。

耶路撒冷阿克萨大院

在这张照片中，可以看到一名安全部队成员靠在篱笆。我们可以看到，这幅画符合以下四个条件：

  1. 必须知道图像的位置和日期。

  2. 物体及其阴影必须与摄像机大致成直角。

  3. 阴影必须与地平线(平地板)在地面水平上投射。

  4. 图像不应被镜头(如鱼眼镜头)过度扭曲。

接下来，我们测量图像中物体和阴影的长度。请记住，这里重要的是这两种测量之间的比例，而不是实际测量本身。

耶路撒冷阿克萨基地增加了影子测量

然后我们前往SunCalc，将该地点设为Al Aqsa大院中的这一地点，并输入物体的高度为2.33米，SunCalc称之为“在物体水平上”。然后我们调整时间，直到阴影长度尽可能接近在图像中看到的(3.53米)。SunCalc输入过程详见下图。

Suncalc.org阴影长度的计算单击或点击查看完整大小的图像。

现在我们的时间是09：37。在进行这一分析之后，我检查了相机中的EXIF数据，发现它是在09：43拍摄的，相差仅6分钟。

例二：来自视频

在下面的例子中，我们从一段视频中看到一组人在观看沙特领导的联盟。空袭2015年5月12日在也门Zabid镇造成数十名平民死亡。

静态图像视频穆罕默德·哈达。

正如我们所看到的，左边穿白色衬衫的人的影子正以大致的直角投射在平面上。因此，我们可以测量阴影的长度，与投射它的对象的长度相比，以便计算时间。

在这种情况下，图像中的男子的身高为5.67厘米，而他的影子似乎只是从该男子的腿向右延伸至9.84厘米。

静态图像视频由Mohammad al-Hadad发布，并增加了阴影测量。

使用SunCalc然后，我们将“对象级别”(投射阴影的对象的高度)设置为5.67m，并更改时间，直到阴影长度尽可能接近9.84m为止。这给了我们16：14的时间。

Suncalc.org阴影长度的计算单击或点击查看完整大小的图像。

为了测试该方法的准确性，在这种情况下，我们可以改变15分钟的时间，两边的16：14，看看我们会得到什么样的阴影长度。

  • 16：14，阴影是投射物体高度的1.74倍。

  • 15分钟前，15：59的阴影是投射物体高度的1.51倍。

  • 15分钟后，1629的阴影是抛出它的物体高度的2.02倍。

静态图像视频由Mohammad al-Hadad发布，并增加了阴影测量。

正如我们所看到的，虽然这个影子计算所确定的时间应该算是比较粗糙的，但它仍然肯定是在15分钟之内，两边都是16：14。

在应用这种技术时，以这种方式建立时间窗口通常是有用的，而不是说明特定的时间。这可以很容易地通过调整SunCalc内的时间来完成，直到阴影的长度明显不再与计算一致为止。

结语

虽然这种技术比用阴影的角度来判断时间要困难一些，但是当没有足够的参考点来估计一个角度时，它仍然是有用的。只要满足了正确的条件，这项技术就可以相当准确，有时令人惊讶地是如此。
