# 本月，美国国会研究院发表《乌克兰军力》报告

       近日，美国国会研究院（CRS)近日发布了有关乌克兰军力的报告，CRS报告为美国国会提供预期和按需研究和分析，以支持其立法，监督和代表职责，所有报告均遵循CRS的核心价值观。  

![](../Images/139d06d41543b1713288ad2c9aaa7d7a.png)

  

**乌克兰军队**

      2014年，乌克兰军队面临着俄罗斯占领乌克兰克里米亚地区和入侵乌克兰东部的局面。观察人士指出，由于多年来的忽视和资金不足，乌克兰军队的实力有所削弱。从那时起，乌克兰武装部队取得了相当大的进步;他们努力采用北约标准，并得到北约和美国的大量援助。这些改革大多是在抵御俄国侵略的经验基础上开始的。改革从战术层面到战略层面，包括政治措施(如增加透明度，打击腐败，确保文官对军队的控制)和军事改革(如装备现代化，指挥和控制改革，以及日益专业化）。

      然而，仍然存在重大障碍，乌克兰的苏联遗留问题和俄罗斯对乌克兰部分地区的持续占领使改革进程变得复杂。自2021年底以来，乌克兰一直面临俄罗斯军队在其边境的大规模集结，以及俄罗斯进一步侵略的潜在紧迫威胁。美国国会议员表示有兴趣了解乌克兰的军事能力，以帮助指导政策制定，支持乌克兰捍卫其领土完整。

# **主要政策和战略文件**

      多份军事和国家安全文件阐述了乌克兰的军事战略、改革和国防政策。乌克兰2016年战略防御公报概述了实现北约标准的优先改革，)述了实施步骤。2018年，乌克兰继续推进改革进程，通过《国家安全法》，建立了一个协调和简化乌克兰国防规划的框架，实现了文官对军队的控制。

      乌克兰分别于2020年和2021年更新了《国家安全战略》和《军事安全战略》，阐述了国家安全和防务政策和目标。《国家安全战略》界定了乌克兰国家安全的主要原则，其中包括将俄罗斯确定为其国家安全的长期威胁，以及与欧盟、北约和美国发展更密切的关系。乌克兰2021年3月的军事安全战略取代了2015年的军事原则。

![](../Images/54c8d2c405fc2d91cc6e0532ce2b8a6c.png)

# **预算与国防工业**

       2018年的《国家安全法》要求，安全支出至少占国内生产总值(GDP)的5%，国防支出占总支出的3%的经济现实。然而，这通常意味着实际国防开支更低(约占GDP的2.5%)。2021年乌克兰的国防预算是1176亿格里*夫*尼亚(42亿美元)，1.27亿*(460*万美元)低于2020年的预算。此外，乌克兰的国防预算分配将分为维持军队所需的资金和支持其雄心勃勃的改革计划的资金。

     乌克兰从苏联那里继承了一个庞大的国防工业，生产各种各样的产品，包括坦克和装甲车、飞机、雷达和电子设备、导弹和舰船。防务集团Ukroboronprom监管着由130多家国有企业组成的国防工业。近年来，乌克兰官员制定了改革乌克兰国防委员会和增加透明度的关键目标，包括在2020年7月通过一项新的国防采购法律，以在国防采购中实施北约标准。

     尽管取得了一些进展，但在腐败、官僚机构效率低下、政治内斗和透明度低方面仍然存在重大挑战。

# **指挥和控制**

      指挥和控制一直是改革的中心焦点。乌克兰现在要求国防部长必须是平民，这是北约的一个关键要求。一些观察人士认为，随着前将军安德里·塔兰(Andriy Taran)在2020年取代首位支持改革的平民国防部长安德里·扎戈罗德尼克(Andriy Zagorodnyuk)，文官对军方的控制继续面临威胁。 

      军方还转向了更符合北约标准的指挥系统。目前，军队向武装部队总司令报告。

在三军统帅的领导下，改革将负责战略和部队规划的总参谋长和负责作战的联合部队参谋长的职责分开。向北约风格的指挥和控制的转变是一个持续的过程，因为尽管北约的训练和教育机会增加，但许多军官似乎仍然受到苏联和后苏联军事训练的影响。

![](../Images/2fcfea7e2c1307108d96f19e79e038f6.png)

**军队**  

      2014年，乌克兰国防部长表示，该国拥有6000名战备部队。今天，乌克兰军队的人数约为145,000-150,000人，并显著提高了其能力、人员和准备就绪。乌克兰陆军是乌克兰军队中最大的组成部分，包括机械化部队、装甲部队、导弹和炮兵部队、陆军航空兵和防空部队。军队继续按照北约标准实施改革，但仍深受苏联遗留问题的影响。正在进行的改革重点包括设备现代化、培训和改善人员管理。

       大多数设备是需要现代化的遗留系统的大规模升级版本。军队还在继续提高个人和单位水平的训练，这在2014年是一个显著的弱点。北约和美国的支持对训练工作至关重要，尽管大多数训练仅限于营级。

       乌克兰现役军人既有应征入伍的，也有签约的职业军人。根据法律规定，义务兵不能在前线服役，但在服役期满后，他们有机会签订短期或长期合同。乌克兰试图根据北约的标准建立一个专业的军士(NCO)部队。低工资、缺乏教育机会和住房短缺可以说是造成高流动率的原因，并限制了职业士兵和士官的保留。

![](../Images/e68eacf87ced35ee25a960103c495ccd.png)

**海军**

      在俄罗斯占领乌克兰克里米亚地区后，乌克兰海军损失了70%的船只和大量军官。之后，乌克兰的政治和海军领导层讨论改革海军，使其重新成为一个平衡的舰队，一个传统的大型和小型船只的组合，或一个“蚊子舰队”，专注于小型船只。

      2018年，乌克兰海军采用了《*到2035年乌克兰海军部队战略》，并选择*了蚊子舰队战略，理由是俄罗斯在黑海的主导海军地位和乌克兰有限的资源来采购更大的船只。此外，由于船舶设计和导弹技术的进步，乌克兰领导层认为，较小的船只可以实现海上威慑，并保卫乌克兰的海岸线和海域。然而，由于乌克兰海军和国防工业的利益相结合，要求建立一支更大的舰队，因此进展缓慢。

      此外，海军还包括两个海军步兵旅和许多海岸防御单位，装备有火炮和反舰导弹能力。海军陆战队步兵被认为是精英单位，有一个旅永久部署在马里乌波尔以外的亚速海。乌克兰最近也部署了新的国产导弹海王星海岸防御系统，其中包括一个新的反舰导弹。

**空军**

      与乌克兰海军一样，乌克兰空军在俄罗斯入侵期间也遭受了重大损失。俄罗斯在冲突期间捕获或击落了多架战斗机、战斗轰炸机、直升机和运输机。这些损失削弱了空军力量，此前，空军遭受了多年的忽视和资金不足。乌克兰的大多数飞机和防空系统都有30多年的历史。

       2020年，空军启动了一项广泛的现代化计划，即*2035年愿景*，承诺3200亿格里夫尼亚*(120亿*美元)购买新的多用途战斗机、教练机、运输机、无人机(包括土耳其Bayraktar TB2无人机)和防空系统。

      然而，这个数字是一个雄心勃勃的预测(乘以乌克兰年度国防预算)，考虑到乌克兰国防预算的实际情况，该预算可能会被修订。

![](../Images/3dbc9cfa1e72bfc03e3739b3505a87bc.png)

# **空袭和特种作战部队**

      乌克兰的空袭旅在对抗俄罗斯入侵乌克兰东部的战斗中发挥了关键作用。被认为是精锐部队的空中突击部队最初是受陆军指挥的轻步兵。由于需要和经验，乌克兰的空袭部队规模增加，并过渡到一个拥有更重型装备的独立指挥部。 

      分析人士普遍认为，组建乌克兰特种部队是2014年以来最显著的进步之一，尽管这支部队规模较小。在美国和北约的协助下，乌克兰特种部队按照北约的标准和原则行动;乌克兰第140特种作战部队中心于2019年通过了北约认证，允许其作为北约反应部队的一部分进行部署。

# **国民警卫队与国土防卫部**

      由于常规军队的限制，乌克兰依靠志愿营来帮助打击俄罗斯2014年入侵乌克兰东部的行动。这些营作为轻步兵行动，有一些有限的装甲和炮兵能力。观察人士对政府的控制表示担忧，因为寡头、政党和一些右翼极端组织创建或资助了大多数营。这些担忧导致乌克兰将大部分志愿部队纳入国民警卫队(National Guard)的指挥之下。国民警卫队于2014年在内政部内部成立。

      乌克兰还根据2022年1月1日生效的《关于民族抵抗基础的法*律*》，建立了新的后备部队。领土防卫部队由当地组织的25个旅(每个地区一个旅)和150个营(每个行政区一个营)，以及一个单独的服务部门。乌克兰计划招募13万名预备役军人，核心是1万名全职士兵。
