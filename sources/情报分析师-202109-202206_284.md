# 如何将社交媒体数据转换为有用情报

【摘要】本文是由Nathalie Wlodarczyk博士等人编辑的。本文强调了社会媒体可以提供有用信息的一些主要领域，并提出了设计和为社会媒体情报系统提供资源的决策者应该提出的问题。同时社交媒体应该如何适应现有的分析和决策过程。  

**一、**需要了解的**关于社交媒体使用平台事项**

（一）平台总共分为四类：

1.  社交网络（例如：脸书）
    
2.  博客和微博（例如：推特和新浪微博）
    
3.  内容社区（例如：油管）
    
4.  即时消息（例如；腾讯QQ、微信）
    

然而，这些平台的用途和功能越来越模糊——例如，Twitter正成为一个社交网络，同时也是一个微博平台，Facebook正日益成为一个即时通讯平台。像Youtube这样的内容网站上的图片和视频可以通过即时通讯服务在个人网络上迅速传播。社交媒体平台的使用因国而异。在不同地区和国家内部，互联网普及率存在很大差异。巴林有将近90%的人口可以上网，而伊拉克只有不到10%。互联网用户通常倾向于更年轻、更富有和城市人口，所以任何对社交媒体的分析都必须认识到数据所代表的人群——以及那些被排除在外的人群，因此不会在社交媒体数据中采样。

（二）不同群体使用社交平台的目的不同

互联网流量数据本身并不能告诉你不同的群体是如何出于不同的目的使用不同的社交网络。你不能通过查看热门数据来了解这一点，只能通过深入了解这些平台上使用当地语言的内容和消息。Twitter是埃及和突尼斯政治辩论的主要平台。在沙特阿拉伯，Twitter还被用来公开讨论政治敏感问题。Facebook是阿尔及利亚工人工会和政治运动组织支持者、宣布罢工和抗议活动的主要平台。巴林的青年团体广泛使用YouTube和Facebook来记录反政府抗议活动。这些通常不会在其他地方报道因而使用媒体类型的多样性强调了 你想要回答的问题的必要性。如果想要是用来衡量沙特民众对政治问题的情绪，Twitter可能是最好的数据来源。如果我们的目标是了解叙利亚不同的叛军派别正在使用什么武器系统，以及这些武器系统是如何演变的，那么Youtube将会有更大的用处。

（三）减少虚假信息

研究人员发现，即使是拥有认证账号和长期良好“社会声誉”的用户，以及他们的许多追随者，也会在未经验证的情况下迅速传播虚假信息。社交媒体已成为一个“有争议的公共场所”。通过为每个国家过滤出合格的消息来源列表，区域情报团队可以使用监控工具，以结构化的方式跟踪这些用户的推文，补充其他收集方法。这再次表明，成功利用社交媒体的方法是基于传统情报技术的应用。虽然这种方法不需要大量的专有技术，但它确实需要时间和资源来建立有价值和可靠的资源的知识库，并保持该列表的最新。

**二、运用社交媒体数据地理定位**

![](../Images/312c784b3688cb395c0d8402bb79c1a7.png)

目前，只有大约1%的推文包含经纬度数据，当人们选择在智能手机上分享自己的位置时，就会发送这些数据。随着手机使用量的增加，预计这一数字也会增加。这些信息可以用来评估人们在哪里发布关于抗议等特定问题的推文。通过长时间的数据聚合，可以看到活动的热点，并检测正常模式的变化。在一个城市的某个地区，突然有大量的人在发推特，这可能会促使分析者进一步调查是什么驱动了这种行为。

**三、建立一个监控系统**

有时候地理空间地图会很有用，因为它会告诉你在一个城市的某个区域有不寻常的活动集中，但是，分析人员需要对所发布的概念进行定性文本分析，以决定该活动是否与风险相关(人们发布twitter是因为镇上有大型音乐活动，还是因为有警察暴力的报道)?最重要的是，分析师需要理解从数据中得出的真正有效的推论是什么。任何成功的SOCMINT系统都必须在主题专家分析师、数据科学家和软件工程师之间的密切合作下开发。
