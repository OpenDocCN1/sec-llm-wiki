# 世界海关组织开发的信息监控地图

**Iris **是由世界海关组织开发的一款应用程序，用于监控开源信息并将这些信息实时呈现在图形风格的世界地图中。

  

**地图网址：**https://iris.wcoomd.org/?locale=en

  

**Iris有两个主要区域。**

**1\. 一个公共区域。**任何人都可以通过互联网访问，包括Iris地图。在Iris地图上，显示由Iris爬虫最后输入的新闻项目，以及由Iris地图显示的新闻项目。

在Iris地图上显示由Iris爬虫最后导入的新闻项目，以及由WCO发布的项目。

**2.会员区。**用户可以额外访问高级搜索，在那里他们可以看到不再在Iris地图上发布的历史数据。

  

Iris地图上不再公布的历史数据。作为会员区的一部分，经授权的用户还可以使用进一步的分析工具，并设置自动警报功能。

  

对于WCO的成员海关管理机构，为了登录和获得成员的账户，请通过WCO网站（www.wcoomd.org）登录。

注意：如果您在Iris中创建账户后在会员网站上更改密码，它不会自动更新到Iris中。同时，如果您在Iris网站上更新密码，也不会在会员网站上自动更新。
