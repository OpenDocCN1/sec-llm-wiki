# 人力情报的特点和人力情报收集者的特征

一直以来，人与人之间的互动是收集情报的重要工具，因此，作为更广泛的情报学领域的一个分支，人类情报学显得尤为重要。本研究探讨了人力情报的概念以及人力情报收集者的特征。本文分析了军事背景下的人力情报，以确定如何能够最好地利用它来支持军事行动。

‍

  

**一、人力情报的特点**

一般来说，情报活动，特别是人力情报的特点是保密，原因是需要保存和保护收集信息的来源。人力情报工作的目的是通过研究对手的能力、意图和弱点，以及研究行动发生的地形，来取得对对手的优势地位。从军事角度来看，情报可以被定义为 "处理有关潜在或公开敌对的外国、组织或分子的消息所产生的产品”。Bispo指出，情报是指来自相关的、有组织的和有背景的信息的知识。如果用知识金字塔来表示，情报在层次上要高于信息。情报本身并不是目的，而是支持决策过程的工具。华尔兹似乎也赞同这种观点，他将知识描述为经过分析、理解并与之前获得的信息相关联的信息。

![](../Images/63e35e25cdc1c67225dc61a9498cb834.png)

从上面的图片可以推断出，情报学的经验和理论基础，必须通过一个过程进行操作。知识是通过系统化和结构化的方式处理新闻来获得的，以便识别相关内容，发现隐藏或缺失的内容，以及处理被认为是必要的内容。

  

**二、人力情报背景**

人文情报是第一个情报学科，从长远来看，它仍然是最有效的，特别是针对使用不对称战术的目标。获得情报的最佳方式是从目标中收集信息，以发现谁、什么、何时、何地、为何以及目标敌人计划如何行动。然而，这种类型的秘密行动需要花费数年时间，因为它需要与有足够高水平的信息来源建立关系，以获得可以成为可操作情报的信息。公开的人力情报活动，如汇报巡逻情况、审讯被拘留者、与当地实体联络、与非政府行为者互动等，也是关于非对称力量的绝佳情报来源。这种情报来源包括人类通过直接观察行为、事件或物体从公开或保密来源收集的所有类型的数据和信息。人力情报可以提供关于目标的计划和意图、审议和决定、研发目标和战略、理论、领导、政治或军事关系、武器系统、物质和文化基础设施以及医疗条件的情报。因此，人力情报可以收集难以或有时无法通过其他手段收集的数据和信息。由此可以推断，人力情报在为非对称战争提供决策支持方面仍然一如既往地发挥着作用。

  

**三、人力情报局限性**

由于人力情报活动涉及人和人际关系，因此必须清楚其局限性，以便制定机制来减轻这些局限性。以下是已确定的局限性。

（1）人际关系技能\--与操作任何种类的设备的能力相比，人力情报更依赖于个人的先天或后天素质；

（2）人员不足\--人力情报收集者必须具备的技术和个人特征意味着，即使使用的资产经过仔细挑选，他们往往无法满足所有情报需求。因此，根据关键程度对这些需求进行优先排序是特别重要的；

（3）时间限制\--在人力情报活动中，时间是一个特别重要的因素，因为发展密切的关系和获得来源的信任需要花时间与他们在一起；

（4）语言障碍\--尽管人力情报收集人员可以使用翻译，如果他们不能与来源进行对话，这可能限制他们收集信息的能力，以及建立融洽关系的能力，因为收集人员和来源之间的互动是被 "过滤 "的；

（5） 不了解任务\--对任务和如何使用这些方法缺乏了解，往往导致人道情报收集人员被分配到本应由宪兵或反情报部门负责的任务；

（6）评估和传播信息\--制作和评估所收集信息的真实性所需的时间需要协调多种因素，以确保及时提供可操作的情报；

（7）地形\--当目标在难以进入的地区（如山区、沙漠等）开展活动时，地形可能构成挑战；

（8）人的因素\--情报单位应考虑到将开展人力情报行动的地区的当地居民，并熟悉他们的社会和文化背景。如果没有当地居民的支持，任何行动都将更难开展.

  

**四、人力情报收集者需要具备的特征**

人的因素在人力情报中起着关键作用，他们必须具备以下特征。

（1） 警觉性\--人力情报收集者必须在任何时候都保持警觉。收集者必须能够专注于所提供的信息，并通过分析来源的行为和正在发生的环境的安全性来不断评估其价值和真实性；

（2） 耐心和策略\--收集者必须有耐心，以便在接触中与来源建立信任和共鸣。任何爆发或不耐烦的表现都可能导致消息来源失去对收集者的尊重，变得不愿意传达信息；

（3）可信度\--收集者必须投射出专业和自信的形象，必须能够阐明复杂的情况和概念，要表现的可信和一致，避免做出无法兑现的承诺；

（4） 客观性和自我控制 \--如果收集者不客观，这可能导致他们不自觉地扭曲对所收集信息的分析，妨碍他们有效使用提问技巧。采集员在接触过程中不能失去主动权，如果谈话没有按预期进行，也不能表现出烦躁或愤怒；

（5） 适应性\--采集员适应不同性格和各种类型的地点、行动节奏和环境的能力，对人力情报行动的成功至关重要；

（6）毅力\--面对不合作的来源或来源可能阻止收集者实现目标的任何态度，坚韧不拔是成功的关键因素；

（7） 外表和举止\--收集者与来源互动时的个人外表和举止非常重要，因为来源也会评估和判断收集者，即使是无意识的。投射出一个积极的形象将使来源更愿意参与谈话；

（8）主动性 -\-建立和保持控制是成功接触的关键。这并不意味着收集者应该在身体上支配来源，但他们应该在谈话中采取主动，并将其引向预定的主题。
