# 勒索软件攻击是如何发生的

IBM Security X-Force Incident Response (IR) 已经响应了各个地区和行业的数百起勒索软件事件。当我们花时间分析这些事件时，已经出现了一个清晰的模式。尽管我们观察到数十个勒索软件组在全球范围内运行，其中许多都有多个附属组织在其下工作，但大多数勒索软件攻击者倾向于遵循类似的攻击流程和一套标准操作程序。勒索软件参与者可能正在交叉培训并相互分享他们最有效的技术，这正在成为许多勒索软件团体和附属机构的标准做法。但无论何种力量将勒索软件攻击者聚集在一起，安全防御者都可以利用对这些攻击的了解来更好地保护网络免受勒索软件攻击 并在攻击者完成最终目标之前抓住他们。  

**勒索软件攻击的五个阶段**

X-Force IR 团队观察到，大多数勒索软件攻击都以可预测的模式发生，我们将其分为五个阶段：初始访问、利用后立足点、侦察/凭据收集/横向移动、数据收集和渗出以及勒索软件部署。

虽然没有两个勒索软件事件完全相同，但通过分析对手在各种参与、运营商和地理位置的行为，X-Force IR 创建了这个通用攻击图，可用于识别逻辑控制和检测机会适用于大多数勒索软件运营商。

![](../Images/04bcf99e1daad674873f693a30faa63a.png)

**第 1 阶段：初始访问**

勒索软件攻击最常见的访问媒介仍然是网络钓鱼（MITRE ATT&CK 技术 1566）、漏洞利用，包括利用面向公众的应用程序（T1190）和外部远程服务（T1133），例如利用远程桌面协议。导致勒索软件事件的绝大多数网络钓鱼活动都在分发访问木马，例如 Bazar、TrickBot、QakBot或 Valak。

**第 2 阶段：开发后**

根据初始访问向量，第二阶段可能涉及中间远程访问工具 (RAT) 或恶意软件，然后使用攻击性安全工具（例如 Cobalt Strike 或 Metasploit）建立交互式访问。例如，X-Force IR 观察到 NetSupport Manager 被访问木马加载。然后将使用 NetSupport Manager 生成 Cobalt Strike 信标。

**第3阶段：理解和扩展**

在攻击的第三阶段，攻击者一直专注于了解他们当前可以访问的本地系统和域，并获取凭据以实现横向移动。本地系统侦察通常通过net、whoami、tasklist等内置工具来实现。

为了促进域侦察，勒索软件运营商继续利用开源实用程序“AdFind”。在 2020 年 X-Force IR 响应的所有勒索软件事件中，88% 的攻击使用了 AdFind。X-Force IR 还观察到勒索软件操作员使用 nltest 命令获取域控制器和特权帐户列表，然后再通过 AdFind 执行更全面的 Active Directory 侦察。X-Force IR 曾多次观察到勒索软件操作员将 AdFind 的输出重定向到一系列文本文件，然后将这些文件添加到存档并被泄露。

虽然许多访问木马可以获取凭据，但 X-Force IR 观察到勒索软件运营商通常利用 Mimikatz、ZeroLogon 和 PrintNightmare 获取用于其余攻击的凭据。

在 X-Force 观察到的大多数勒索软件攻击中，对 Active Directory 的利用是攻击中的关键关键，它为安全防御者提供了捕捉和阻止勒索软件攻击者或挫败他们的成功的机会。本博文末尾包含几项保护 Active Directory 的建议。

在 Active Directory 侦查之后，勒索软件运营商通常通过服务器消息块 (SMB) 或远程过程调用 (RPC) 协议横向移动。凭据收集可以根据需要在其他系统上继续，以获取域管理员权限。

**第 4 阶段：数据收集和泄露**

自 2019 年以来，X-Force IR 响应的几乎所有勒索软件事件都涉及数据盗窃和勒索软件的“双重勒索”策略。在攻击的第 4 阶段，勒索软件运营商的重点主要转向识别有价值的数据并将其泄露。

勒索软件运营商通常会在第 4 阶段通过 SMB、RPC 和远程桌面协议 (RDP) 横向移动到其他系统，以识别数据以进行泄露。X-Force IR 观察到勒索软件运营商利用一两个暂存系统在泄露之前收集数据，他们通过隧道 RDP 连接不断访问这些数据。虽然我们观察到某些勒索软件运营商从数据库中访问和窃取数据，但大部分数据收集都是通过 SMB 执行的。

数据泄露是攻击生命周期的一个领域，X-Force IR 观察到勒索软件运营商之间存在适度差异。WinSCP 和 RClone 等工具仍然是最常用的工具；然而，X-Force IR 已经响应了几起勒索软件事件，其中攻击者利用了自定义数据泄露工具或 BitsAdmin 等非本地工具。

**第 5 阶段：勒索软件部署**

尽管勒索软件开发者社区内的创新不断创造出新的恶意软件变种，但勒索软件有效载荷向目标系统的分发在勒索软件运营商中仍然相当普遍。

在 X-Force IR 响应的几乎每一个勒索软件事件中，勒索软件运营商都将域控制器作为勒索软件有效负载的分发点。

为了分发勒索软件，攻击者通常利用域控制器上共享的 SMB 并使用 PsExec、WMIC、RunDll32 或使用 CrackMapExec 等工具创建计划任务来执行有效负载。

**利用勒索软件攻击知识进行防御**

通过了解大多数勒索软件攻击的共性，防御者在识别和关注大多数攻击中大量利用的资产方面具有优势，包括 Active Directory 和域控制器。鉴于我们对勒索软件攻击流程的了解，以下建议包括网络防御者可以采取的具体措施，以最好地防御勒索软件攻击。

**限制特权访问**

1、将组织中的域管理员帐户数量限制在最低限度，并考虑创建一个自动化流程来定期删除域管理员组中不必要的成员。

2、从所有用户帐户中删除本地管理员权限，并将服务帐户的本地管理员权限限制在绝对最低限度。

3、应该对域管理员帐户的使用进行严格审核并发出警报，因为这是勒索软件运营商在 X-Force 今天观察到的大多数勒索软件攻击中获得目标的关键机制，因此此类组织应该开发自动警报以修改域管理员组。

**保护特权帐户**

1、将特权帐户添加到受保护的用户安全组，以降低组织内凭据暴露的风险。

2、利用托管服务帐户和本地管理员密码解决方案 (LAPS) 启用常见目标帐户的自动密码管理。

3、实施特权访问管理解决方案来管理和监控特权帐户和访问。

**安全活动目录**

1、审核并消除组织之间任何不必要的域信任，并确保正确管理和监控所需的跨域活动。

2、配置组策略以仅允许域管理员 (DA) 登录域控制器并禁止访问其他已加入域的 Windows 系统。

3、实施严格的网络分段策略，将对高价值资源的交互访问限制在特定的管理网络或跳转主机上。

4、部署组策略更改管理解决方案，其中必须先批准域策略更改才能链接到域。

5、将企业内的所有系统配置为拒绝通过旧协议进行的身份验证尝试。

6、了解 X-Force 和Tenable如何合作帮助组织防止 Active Directory 攻击。

**限制常见的横向运动途径**

1、尽可能通过网络分段消除通过 SMB、RPC 和 RDP 的横向移动路径。

**防御网络钓鱼威胁**

1、采用强大的电子邮件软件安全解决方案，可以在网络钓鱼电子邮件到达最终用户之前对其进行检测。即使解决方案无法检测到今天发送的所有网络钓鱼和鱼叉式网络钓鱼电子邮件，检测相当比例的网络钓鱼邮件的解决方案也可以减少您的组织受到基于网络钓鱼的威胁的风险。

2、利用用户意识培训，解决当今威胁参与者使用的现实世界电子邮件网络钓鱼技术。例如，教导最终用户勒索软件攻击者正在劫持电子邮件帐户并将自己插入正在进行的对话中，以将恶意附件或链接引入看似来自受信任用户的对话中。

3、对仅包含附件或链接的“回复所有”电子邮件保持警惕，其中包含非常简短的消息或没有消息。

4、强调“未付发票”是一种非常常见的网络钓鱼诱饵。

5、酌情结合其他现实世界的例子。

**专注于补丁管理**
