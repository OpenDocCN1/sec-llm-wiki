# 美国军方的黑客部门应对勒索软件团伙

**该部队的老板 Paul Nakasone 将军表示，美国军事计算机特工已准备好以勒索软件团伙和国家行为者为目标，只要他们对美国的关键基础设施构成威胁。**  

美国军方的黑客部门网络司令部正在采取积极措施打击以勒索软件为目标的美国组织的网络犯罪团伙。据该部门发言人称，这一决定是由5 月份的Colonial Pipeline 勒索软件攻击引起的。

发言人没有提到该部门将采取什么样的行动。尽管如此，他们确实确认目标将是试图劫持美国机构和企业计算机系统的犯罪团伙，据CNN 报道。

![](../Images/81a53467ea6e93bc5e7ba991f8a62dfb.png)

**网络罪犯和国家行为者是目标**

网络司令部负责人兼国家安全局局长保罗·中曾根将军透露，美国军事计算机特工已准备好以对美国关键基础设施构成威胁的犯罪团伙和国家行为者为目标。

中曾根早前表示，美国政府加大了对勒索软件运营商的打击力度，并希望首先切断他们的资金来源。在最近接受 《纽约时报》采访时，中曾根重申了该部门的承诺，并声称削减资金来源是打击勒索软件运营商的一个重要方面。

**俄罗斯拒绝采取行动**

白宫试图向俄罗斯政府施压，要求其对在俄罗斯境内活动的网络犯罪分子采取行动，但莫斯科似乎对所有并非针对俄罗斯的黑客视而不见。

据称，政府旨在打击的大多数犯罪集团都位于俄罗斯和东欧。美国总统乔拜登将于周二与俄罗斯总统弗拉基米尔普京进行视频通话，讨论网络安全问题。

![](../Images/09b387846be43ebede3c1ed9cb541005.png)

**殖民管道，JBS 攻击充当催化剂**

尽管此前曾发生过针对美国机构和企业的勒索软件攻击，但在对 Colonial Pipeline和JBS USA进行勒索软件攻击后，政府和有关部门实际上已经注意到了情况的严重性。

值得注意的是，Colonial Pipeline 供应了东海岸 45% 的燃料，而 JBS USA 是该国最大的肉类供应商。这两起袭击都发生在 2021 年。

这些攻击迫使美国政府停止将勒索软件攻击视为执法领域，因为犯罪团伙瞄准并影响了该国的关键基础设施。因此，需要采用实际操作的方法来处理该问题。
