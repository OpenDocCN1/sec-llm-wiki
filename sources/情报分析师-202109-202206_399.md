# 亚马逊被曝与英国情报机构秘密交易：用AI开展间谍活动

据英国《金融时报》26日报道，英国三家情报机构已与美国亚马逊云科技（AWS）签订合约，将其机密资料交给AWS托管，这一举措旨在强化数据分析和人工智能（AI）在情报活动中的应用。不过这笔秘密达成的交易也引发了外界对英国信息主权的担忧。

  

![](../Images/95ce50f56a0fcd6e7a9ddb2c9e864c35.png)

  

英国《金融时报》：亚马逊与英国情报机构达成协议，储存机密资料。配图为英国通信总部大楼。

报道称，亚马逊提供的云服务主要在于安全地储存绝密的信息，这项合作的达成能够让英国情报人员更方便地分享和分析从海外获得的海量数据。比如通过智能语音识别，英国情报人员能从截获的数小时录音中精准“认出并翻译”特定的声音。此外，英国政府通信总部（GCHQ）、军情五处和军情六处还可以通过这个平台，对彼此共享的数据库进行更快的检索。曾任英国国家网络安全中心（NCSC）负责人的西亚兰·马丁（Ciaran Martin）表示，有了这项协议，英国安全情报部门能够“在几分钟内，而不是几周或几个月的时间内，从大量数据中获取需要的信息”。马丁同时指出，这项合作不是为了“收集或囤积更多的数据”，而是为了“更加有效地利用现有的大量数据”。据4名知情人士透露，这份协议是在今年签署的。业内专家估计，未来10年，该协议的价值将在5亿至10亿英镑，但合作的细节仍被严格保密。此外在这项合作中，尽管AWS是一家美国公司，但英国情报机构的数据都将保存在英国，亚马逊将无法访问云平台上保存的任何信息。目前，英国政府通信总部拒绝对该部门与技术供应商的合作关系发表评论，AWS没有立即回应置评请求。路透社报道指出，面对竞争对手扩大使用人工智能以及数据爆炸的现状，英国政府通信总部一直在倡导采购一个高安全性的云系统，并由姐妹机构军情五处和军情六处以及其他政府部门——如国防部在联合行动中使用。早在今年2月，英国政府通信总部就宣称准备利用人工智能打击恶意虚假信息，以及诱捕和虐待儿童的犯罪行为。英国政府通信总部主任杰里米·弗莱明（Jeremy Fleming）表示，随着情报活动进入数字时代，利用人工智能将是该机构保证国家安全的转型的“核心”计划。不过这项最新的合作依然引发了关于英国数据主权方面的担忧。英国非营利机构“隐私国际”（Privacy International）执行董事古斯·侯赛因（Gus Hosein）表示，关于这笔交易，议会、监管机构和公众需要了解“许多事情”。“这是另一个令人担忧的公私合作关系，而且是秘密达成的。”侯赛因说，“如果这项合作最终达成，亚马逊将被视作全球情报机构的首选云服务提供商。亚马逊必须为自己的业务肩负起相应的责任。”英国与一家美国公司签约的举动也令一些专家感到意外。一名英国安全资深人士说，“主权很重要，从历史上看，安全技术一直是由内部建立和维护的，这是有原因的，”另外两名知情人士表示，英国方面其实最初希望找到一家国内的云服务提供商，但近年来英国企业既无法满足所需的业务规模，也无法提供所需的技术能力。马丁坦承，与海外供应商签约意味着“控制和限制供应商获取数据是极其重要的”。“但只要这家公司来自一个可靠的国家，你能够了解他们拥有的技术，就能够控制住风险。”本期编辑：CZS如有侵权，请联系管理员删除**通过“情报学院”知识星球可以阅读该资料的全都内容👇**![](../Images/5fa8497e18c7fd47aa351515d9893f1a.png)
