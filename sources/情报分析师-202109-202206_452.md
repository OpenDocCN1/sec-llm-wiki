# 情绪情报

1990年，我在《纽约时报》担任科学记者时，偶然发现了一篇小型学术期刊上的文章，作者是两位心理学家，即现在新罕布什尔大学的约翰-梅尔和耶鲁大学的彼得-萨洛维。心理学家约翰-梅尔（John Mayer），现在在新罕布什尔大学，和耶鲁大学的彼得-萨洛维。  
Mayer和Salovey首次提出了他们称之为 "情商 "的概念。"那些日子里，智商作为生活中的优秀标准的优势是毋庸置疑的；关于智商是由我们的基因决定的还是由经验决定的争论激烈。但在这里，突然出现了一种思考人生成功要素的新方式。我被这一概念所吸引，并于1995年将其作为本书的书名。像梅耶和萨洛维一样，我用这个短语来综合广泛的科学发现，将原本独立的研究线索汇集在一起--不仅是他们的理论，还有其他各种令人兴奋的科学发展，例如情感神经科学这一新生领域的最初成果，它探索了大脑中的情感是如何被调节的。我记得，就在十年前这本书出版之前，我曾有过这样的想法：如果有一天，我无意中听到两个陌生人的对话，他们都使用了情商这个词，而且都明白它的含义的意思，我就会成功地将这个概念更广泛地传播到文化中去。我不知道。  
情商这个词，或者说它的临时缩写EQ，已经变得无处不在，在一些不可能出现的场合出现，如卡通漫画《Dilbert》和《Zippy the Pinhead》以及《纽约客》上的Roz Chast的连环画中。我见过一些声称能提高儿童情商的玩具盒；失恋者的个人广告有时会在寻找未来伴侣的人身上大肆宣扬情商。我曾经在酒店房间里发现一个印在洗发水瓶上的关于情商的调侃。  
而这个概念已经传播到了我们星球的各个角落。据悉，EQ已经成为一个被认可的词，在德语、葡萄牙语、中文、韩语和马来语等各种语言中都有。(即便如此，我更喜欢EI作为情绪智力的英文缩写）。) 我的邮箱里经常有来自保加利亚的博士生、波兰的教师、印度尼西亚的大学生、南非的商业顾问、阿曼苏丹国的管理专家、上海的高管的询问。  
印度的商业学生阅读了关于EI和领导力的文章；阿根廷的一位CEO推荐了我后来写的关于这个主题的书。我还从基督教、犹太教、伊斯兰教、印度教和佛教的宗教学者那里听说，EI的概念与他们自己的信仰观有共鸣。最令我欣慰的是，这个概念被教育工作者热烈地接受，以 "社会和情感学习 "或SEL项目的形式出现。  
早在1995年，我只能找到少数几个向儿童教授情商技能的项目。十年后的今天，全世界有数以万计的学校为儿童提供SEL。在美国，许多地区甚至整个州目前都将SEL作为课程要求，规定学生必须在数学和语言方面达到一定的能力水平，他们也应该掌握这些生活的基本技能。例如，在伊利诺伊州，从幼儿园到高中的最后一年，每个年级都制定了SEL能力的具体学习标准。仅举一个非常详细和全面的课程的例子，在小学低年级，学生应该学会识别和准确标记他们的情绪，以及他们如何导致他们的行为。  
到了小学后期，同理心的课程应该使孩子们能够识别别人感受的非语言线索；到了初中，他们应该能够分析什么会给他们带来压力，什么会激励他们的最佳表现。而在高中，SEL的技能包括倾听和交谈，以解决冲突而不是升级冲突，并通过谈判获得双赢的解决方案。  
最后，我设想有一天，情商将被广泛理解，以至于我们不需要提及它，因为它已经与我们的生活融为一体。在这样的未来，SEL将成为各地学校的标准做法。同样地，诸如自我意识、管理破坏性情绪和同理心等情商素质将成为工作场所的必备条件，成为被雇用和晋升的 "必备条件"，尤其是成为领导层的必备条件。如果EI像IQ一样普及，并作为人类素质的衡量标准在社会中根深蒂固，那么，我相信，我们的家庭、学校、工作和社区将更加人性化和有滋养。
