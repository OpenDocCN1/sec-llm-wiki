# 关于情报官员失踪的争议加深了索马里的宪法危机

             （资料来源于网络，翻译：BB）  

  

  穆罕默德·阿卜杜拉希·法马乔(Mohamed Abdullahi Farmajo)声称：索马里首都摩加迪沙当前的局势仍然紧张，此前该国总统和总理在敌对民兵的支持下，就一名情报官员的失踪相互指责。为索马里国家情报和安全局(NISA)工作的25岁的伊克兰·塔利尔于6月失踪。据报道，她最后一次被看见是在摩加迪沙的家中，当时外面进入一辆政府车辆。《NISA报》称，塔利尔可能被基地组织的东非分支组织青年党绑架并处决。

  

  然而，通常一有机会就喜欢杀害索马里安全和情报人员的青年党否认与塔利尔的失踪有任何关系。针对这一意外的事态发展，总理穆罕默德·侯赛因·罗布莱谴责了NISA，并解雇了其主任法哈德·亚辛。据总理办公室称，亚辛没有回应关于塔利尔下落的官方请求。

  

  然而，周三，该国总统穆罕默德·阿卜杜拉希·法马乔宣布雅辛复职，此前他声称，宪法没有授权雅辛解雇情报机构的成员。法玛霍还指责罗伯在这个动荡的国家“鲁莽行事，可能导致政治和安全危机”。周三晚些时候，总理办公室宣布罗布尔不打算遵守总统的命令，因为这直接违反了宪法。

  

  法马乔总统星期四作出回应，宣布在即将举行的全国选举之前，总理任命和解雇政府官员的权力将被撤销。这些活动将于10月1日开始，11月25日结束。罗布总理再次表示，他不会遵守总统的决定，他称该决定是“非法的”。他还指责法马乔煽动摩加迪沙街头的武装冲突。

  

  与此同时，总统已经任命了一个新的特别委员会，负责对塔利尔的失踪进行官方调查。但这名失踪女子的家人表示，他们不信任该委员会，并要求由索马里军方进行调查。
