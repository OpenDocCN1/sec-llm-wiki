# 作为警察，你最尴尬的时刻是什么？

Quora上发布的一个问题问道：“对于警察来说，最尴尬或羞辱的经历是什么？前军官贾斯汀·弗里曼就以下主题发表了他的专业意见。

1.被发现穿着制服而没有你的值班武器。在我工作的地方，警察不允许把武器带进监狱，不得不把它们藏在巡逻车的后备箱里，或者放在入口口的一排特殊的密码箱里。在处理逮捕后，总是有可能忘记重新套上你的武器，你可以想象你用一个空的皮套到达一个活跃的骚乱中会显得多么无能。

2. 囚犯越狱。在我工作过的地区，有一些囚犯“滑倒袖口”（有足够的灵活性将他们的袖口从后面滑到脚下，让他们的手在他们面前），然后偷走他们所在的巡逻车。

![](../Images/55607bb35252ef162cebfb33714d04a3.png)

  

3. 意外暴露出执勤武器。

4. 被锁在巡逻车外。

5. 巡逻时煤气耗尽。

6. 在搜查被捕者并让狱卒找到违禁品时丢失违禁品。

7.在作证时被辩护律师殴打，无论他们是引导您了解程序异常还是让他们进入您的皮肤。

8. 在徒步追逐中失去嫌疑人。同样在车辆追逐期间，但远没有那么，因为你必须比嫌疑人更谨慎地驾驶，以保护无辜司机和旁观者的安全。

9. 丢失钥匙或电子门禁卡。

10.在警察学院期间必须适应（在跑步时从编队中掉出来等）。

11.在试图制服好斗的受试者时，用OC（胡椒）喷雾喷洒另一名军官。据了解，没有办法完全避免交叉火力或交叉污染，但有些命中比其他命中更直接。

12.激光（将枪支的枪口指向某人的方向）射击场上的人。

13. 忘记或误穿制服部件（例如，姓名徽章颠倒）。

![](../Images/711de16b5e8c21d34abbc7b5b218e9a8.png)

14.在去打电话的路上弄乱方向，要么开错路，要么在限速下行驶，试图让你的方位。如果您正在运行代码（灯光和警笛），则情况会呈指数级恶化。

15.如果有人发现（通常是你的现场训练人员进行检查）你的值班武器的腔室里没有一发子弹。这意味着如果你要拔出武器并扣动扳机，它会咔哒一声。

16. 轮班或培训迟到，或错过开庭日期。

17. 被迫使用私人住宅的洗手间，或向现场的公民求助。

18.必须回溯您第一次应该获得的信息。我曾经不得不回到监狱，因为我在DWI调查期间忘记问某些采访问题，并且不得不在事后很久开车到证人的住所，问一个我在初次采访中提出的重要问题。
