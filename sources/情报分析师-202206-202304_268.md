# 【情报评估】防范和应对巴基斯坦的致命洪水

巴基斯坦正在经历十年来最严重的人道主义危机，这是由极端暴雨和毁灭性的山洪暴发引发的。巴基斯坦73年历史上最普遍的洪水使该国三分之一的土地被淹没。

洪水影响了420多万人;近1，400人死亡，其中包括458名儿童，1，600多人受伤，50万人流离失所。自6月中旬以来，洪水已损坏了100多万所房屋，摧毁了130座桥梁和3000公里的道路。当局警告说，洪水可能需要长达六个月的时间才能消退。

![](../Images/6f6e9a7c20e6a627b5d06a74a4c0fd4f.png)

关键基础设施的破坏造成了严重的限制。这场灾难加剧了先前存在的气候、经济和公共卫生危机，妇女、女童和其他弱势群体首当其冲。超过640万人“迫切需要”人道主义援助，需要国际社会与当地行为体和巴基斯坦政府合作，解决眼前需求，同时为长期的预防和康复工作提供支持。

**问题1：受水浸影响地区的情况如何？**

**答案 1： **卫星图像揭示了破坏的程度。曼查尔湖是巴基斯坦最大的湖泊，位于东南部信德省的谢里夫附近，其挡土墙上周破裂，导致数千人逃离并淹没了数百个村庄。在洪水淹没了两个农村城镇之后，巴基斯坦进行了一次有争议的最后一次尝试，通过设计两个故意的违规行为来减轻对结构的压力。从人口稠密地区转移洪水。事实证明，它的努力是徒劳的：洪水淹没了大约400个村庄，影响了近135，000人，水位上升了六英尺。

**曼查尔湖， 信德省， 巴基斯坦**

*2022年8月7日至9月6日*

![](../Images/7e0e0917fe81c565b71b5cc3f6ad195c.png)

信德省继续看到创纪录的降雨量，水正在渗透到印度河的溢流水道中，被曼查尔湖等支流淹没。来自印度河岸边村庄的几名洪水幸存者踏上了前往距离谢里夫约230公里的苏库尔的危险旅程，希望获得食物和医疗援助。然而，苏库尔现在也被淹没在水下。  

**苏库尔， 信德省， 巴基斯坦**

*2022年8月2日至8月28日*

![](../Images/547e53b39955a24199806c9fdf0796f0.png)

信德省是受洪水影响最严重的省份，据报道有522人死亡，其中包括219名儿童，但其他地区也面临“世界末日”程度的破坏。在巴基斯坦最贫穷的省份俾路支省西南部，洪水摧毁了60%的房屋。自6月中旬以来，开伯尔-普赫图赫瓦省西北部已有近300人丧生，其中包括100多名儿童。洪水破坏了巴基斯坦吉尔吉特 - 巴尔蒂斯坦的数十座桥梁，数百公里的道路和供水线路以及1000多所房屋。旁遮普邦超过90万英亩的农作物，包括该国近一半的棉花，已被摧毁。  

**Q2：造成破坏的因素有哪些？**

**答案 2： **2022年4月和5月，巴基斯坦经历了61年来最热的月份，在印度西北部和巴基斯坦东南部造成近100人死亡。热浪“\[测试\]了人类生存能力的极限”，该国部分地区的温度超过122华氏度。今年早些时候，森林大火摧毁了45英亩的马尔加拉山国家公园。美国宇航局的一项研究表明，巴基斯坦的一些地区将很快变得不适合居住。巴基斯坦的金融和工业之都卡拉奇拥有1600万人口，预计到2060年将淹没在海水中。雅各布巴德被认为是世界上最热的城市，已经处于水下。

尽管早先有猜测，但气候专家表示，巴基斯坦的洪水主要不是由于冰川融化。该国拥有7，200多座冰川，是南极和北极圈外数量最多的冰川。尽管气温上升导致冰川以更高的速度融化，但伊斯兰堡的生态学家Parvaiz Naim声称，“到目前为止，这种洪水在当地具有重要意义，只是因为排放量相对较小。

根据伊斯兰堡智库可持续发展研究所的研究员Shafqat Munir的说法，南向降雨引发了灾难性的洪水。巴基斯坦位于南亚季风地区的远西边缘，主要是干旱的沙漠气候，通常降雨量远远少于印度部分地区。然而，巴基斯坦今年的降雨量是历史性的。该国的降雨量比30年平均水平高出190%，气象学家预测未来几周降水量将增加。信德省和俾路支省本季平均降雨量分别为784%和496%。

![](../Images/8ae6e63bb3a1be7fc62ca9163a2df899.png)

除了气候变化之外，其他几个因素也是洪水极端影响的原因。专家声称，巴基斯坦为多年拖延解决问题付出了代价。腐败、国家水资源管理不善、缺乏必要的基础设施和治理不善助长了危机，对最贫困和中产阶级的打击最大。

许多建筑物是非法建造的，或者建造得很差，以至于无法承受降雨和随后的洪水，有些建筑物是在以前受2010年洪水影响的地方建造的。地方政府当局往往缺乏打击非法建筑的能力。巴基斯坦陆军总司令卡马尔·贾韦德·巴杰瓦呼吁对那些在脆弱地点建造建筑物的人采取法律行动。

巴基斯坦各地继续非法采伐，尽管声称通过准军事部队控制了局势。巴基斯坦已经处于森林赤字状态，只有5%的森林面积，而全球平均水平为31%，由于森林火灾猖獗和无控制伐伐，森林砍伐率高于平均水平。树木限制了沉积物的沉积，并在极端降雨事件中稳定了土壤。随着森林砍伐的增加，巴基斯坦将更容易受到严重洪水的影响。

全球北方工业化国家过度生产碳排放也对全球南方造成严重的气候影响。巴基斯坦占世界人口的2.6%，但自1959年以来，它仅占全球碳排放量的0.4%，远低于其安全排放的公平份额。另一方面，全球北方国家已经超过了其配额92%，其中100家公司占排放量的71%。美国占世界人口的4%，但占全球碳排放量的13%，承担着“不成比例的责任”。全球北方在减少排放方面继续无所作为，将进一步助长全球南方国家气候引发的人道主义灾难。

![](../Images/512d74c2370769b04480deebe47974f3.png)

**问题3：洪水的短期和长期影响是什么？**  

**答案 3： **仅今年的灾难就将是灾难性的，但洪水加剧了巴基斯坦先前存在的经济和公共卫生危机。政府报告称，8月份的通货膨胀率创下了创纪录的27%，要求其满足重启国际货币基金组织（IMF）计划的条件，包括终止对石油的补贴和提高电力消费关税。政府接受了这些要求，这有助于避免违约，但给最贫穷和中产阶级带来了压力。

作为救助计划的一部分，国际货币基金组织批准了一项11.7亿美元的贷款，用于救灾工作。预计巴基斯坦还将获得160亿美元的商业贷款，140亿美元来自其他国际机构，以及20亿美元的外国直接投资。根据规划和发展部长Ahsan Iqbal的说法，该国迄今为止遭受的破坏成本可能“远远高于”目前估计的125亿美元。一些专家认为，这些贷款将进一步削弱巴基斯坦的经济地位。
