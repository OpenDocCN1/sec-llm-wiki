如果正在研究YouTube视频，则还有几种在线研究工具可用于获取有关该视频的更多信息。这篇文章将介绍如何对视频进行更深入的研究。

**研究工具**

## 

这里将介绍一些可用于在线研究视频的工具。

### **要查找的内容**

如果正在在线研究视频，则有3个基本研究目标需要寻找。

1 – **搜索视频。 **搜索视频有两个次要原因。

1a – 正在寻找信息，这些信息可能在视频中可用，但不知道该视频是什么。在这种情况下，正在根据主题寻找视频。

1b - 已经找到了一个非常感兴趣的视频，并且想要对其进行分析，但在执行此操作之前，需要找到原始视频。视频的副本可能会被更改或编辑，此外，可能有兴趣研究视频的来源。要查找原始视频，必须在线搜索该视频的其他版本，然后首先找到在线发布的视频。

2 – **尝试找出谁发布了视频。**这很困难，基本上涉及搜索youtube帐户用户名是否也用于社交媒体帐户。此外，可以查找在视频上发布的第一个评论者，或者可能是前几个评论者，因为他们可能知道发布视频的人。

可以使用他们的用户名搜索社交媒体帐户，并在他们的共同朋友中寻找潜在的候选人。搜索原始视频可能会发现它最初是发布在社交媒体帐户上的，这显然会使工作变得更容易。

3 – **分析视频内容。 **这项技能在很大程度上超出了本博客的范围，但确定了用于此类操作的工具和指南。如果您正在搜索视频以查看它们是否有有关特定主题（如个人，公司，立法）的信息，现在可以在youtube中进行单词搜索，以查看是否有人说了提及个人，公司或立法之类的内容。此功能可以帮助研究人员节省大量时间浏览不同的视频。

在验证手册（https://verificationhandbook.com/book/chapter5.php）中，有一个详细的指南，介绍如何对不同视频的内容进行分析，以执行查找位置或验证视频等操作。

### 1 – 搜索视频

搜索视频可能很困难。如果您正在寻找有关某个主题的视频，则可以尝试使用Petey Vid，这是一个基于文本的搜索引擎，专门搜索视频。基于文本的搜索，无论是PeteyVid还是Google，都只能搜索与视频相关的文本。因此，如果视频位于空白网页上并且没有关联单词，则搜索引擎无法找到它。

根据Bellingcat的Aric Toler的说法，目前没有办法对视频进行互联网搜索（这是指将视频实际上传到搜索引擎的想法，该搜索引擎将基于它查找其他视频，例如反向图像搜索）。

因此，下一个最好的办法是获取视频的缩略图照片，并对这些照片运行反向图像搜索。希望在尚未开始时搜索视频上出现的照片。将通过一个示例进行介绍。在撰写本文时，YouTube主页看起来像下面的屏幕截图：

![](../Images/7fceecb2effc6ea323c5645bb27f57a9.png)

因此，如果要搜索右上角的视频，则可以使用截图工具捕获视频中当前尚未播放的照片。将对此照片进行反向图像搜索：

![](../Images/de29f4702387ec073c6ba5d8797253e2.png)

国际特赦组织还为公众提供了一个名为Youtube DataViewer的工具，该工具从任何youtube视频中提取数据，并从视频中创建4个微图图象，可以使用这些图像进行反向图像搜索。例如，如果将youtube视频的URL粘贴到工具中并运行它，会得到以下结果：

![](../Images/905aa4051007fb1fdff341923da6ec84.png)

上面的结果显示了视频的名称和说明、视频 ID 以及上传视频的具体日期和时间。

如果我们向下滚动，会看到该工具从视频中创建了四个缩略图，可用于反向图像搜索，并且每张照片旁边甚至有一个链接可以执行反向图像搜索。

每张照片旁边还有一个链接，可用于进行反向图像搜索。

![](../Images/a546bf3a84197a2ac7dc1ae3809c03fa.png)

**3 – 视频内容分析**

### Youtube的计算机生成成绩单

Youtube有一项新功能，通过为每个视频生成脚本，使研究视频变得更加容易。要访问该功能，请单击右侧视频下方的三个点，然后单击“打开脚本”。

![](../Images/b6fec68d7907ee6528d3055a92908b51.png)

计算机生成的视频脚本显示在视频旁边。成绩单是可进行单词搜索的，因此可以通过搜索视频中提到的特定名称或公司来节省时间。在下面的屏幕截图中，搜索了Tina Larsen这个名字，并在成绩单中弹出。

  

请注意，成绩单还显示了说不同事情的时间。如果在文字记录中发现一些有趣的东西，可以单击单词，Youtube将自动将视频带到那个时间。

![](../Images/c1329829cde0ae92aa2da3cdf4fbecd3.png)

根据视频的不同，可能希望非常缓慢地浏览所有内容，以尝试分析背景或街道标志。可以使用 – http://www.watchframebyframe.com/

元数据查看器是一个很好的工具，用于在一个位置收集有关视频及其发布者的所有数据。视频何时发布，由哪个帐户发布，该帐户存在了多长时间，视频是否进行了地理定位等。

![](../Images/5a3d0ac0b43fe48fc26a8092e925c352.png)

如果视频没有地理定位，可以查看发布该视频的帐户（也称为频道）是否曾经对其任何视频进行过地理定位，这当然意味着帐户持有人的位置，甚至是原始视频本身。地理探测器-（https://mattw.io/youtube-geofind/)

![](../Images/7e4a3e63781dd7800ed8744a238a9ac6.png)

目前尚不清楚以下工具对于研究视频是否真的有用。

https://keepvid.com/ - 将允许编辑视频或将其转换为音频文件。

https://www.y2mate.com/en68 和 http://deturl.com/ - 将允许将视频作为视频或音频文件下载到本地。

**下载所有评论**

## 

可以使用以下过程下载YouTube视频的所有评论。第一次执行此操作时，需要执行许多步骤，但一旦设置完毕，其他时间就会快得多。将需要获取youtube api密钥（您只需要执行此过程一次），找到视频ID号，设置gitpod（仅一次），然后点击运行。

### **获取 YouTube API 密钥：**

首先，转到“https://console.developers.google.com/apis/credentials&#8221;。

点击同意条款和服务，然后点击“同意并继续”

![](../Images/6dd4377855e572803fe0915f5b380428.png)

接下来点击“选择一个项目”

![](../Images/1b2fcc1d1c6fa5f440cc611fd6235024.png)

然后点击“新建项目”

![](../Images/2cdea4c4106e84d57e9d35add3bd0820.png)

在下一个屏幕中，单击“创建”，然后在屏幕中单击“选择项目”，在左侧滑动“api &services”，然后单击“凭据”

然后单击“创建凭据”，然后单击“API密钥”

![](../Images/7621806103476648a516da8689b71eb0.png)

还没有完成，接下来单击左侧的“库”，然后在下一个屏幕中向下滚动到youtube，然后单击“youtube数据api v3”

![](../Images/87d19060d23fbfab1cc8f84e9c62c2fd.png)

在下一个屏幕中，单击“启用”。现在，您的 API 可以访问 YouTube 数据！要返回到您的api密钥，请单击左侧的“凭据”，将进入包含您的密钥的页面。

有关更多信息，API 文档位于此处 – “https://developers.google.com/youtube/v3/docs&#8221;
