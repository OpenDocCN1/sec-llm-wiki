# **作者的说明**

  

任何公开的间谍都将不可避免地面临审查，尤其是声称在9/11之后为四个西方情报机构的一些最敏感的反恐行动中担任双重间谍的人。

  

莫滕-斯托姆的故事之所以独特，是因为他在担任间谍期间收集了大量的视听证据和电子通信，这既证实了他的故事，又丰富了他的叙述。

  

![](../Images/1472554acf002889d7e4a6590c19ce2b.png)

他让我们不受限制地接触到的这些材料，包括：

  

*   阿乌拉基和前往也门与该人结婚的克罗地亚妇女录制的视频，即使在阿乌拉基被美国追捕的时候，这桩婚姻也是由斯托姆安排。
    
*   斯托姆（Storm）与阿-拉-伯和非洲的恐 -怖 - 分-子之间的几十封加密电子邮件，这些电子邮件仍在他的电脑硬盘上。
    
*   向索马里的一名恐怖分子汇款的记录。
    
*   与丹麦情报人员的短信，仍然保存在他的手机上。
    
*   斯托姆（Storm）与丹麦和美国情报人员谈话的秘密录音，包括2011年在丹麦与一名中央情报局特工会面的30分钟录音，期间讨论了斯托姆（Storm）针对恐怖分子的若干任务。
    
*   手写的任务笔记。
    
*   斯托姆（Storm）在2008年与阿乌拉基（Awlaki）会面后驾车穿过也门部落地区的视频和照片；2010年斯托姆（Storm）与英国和丹麦情报人员在瑞典北部的视频。
    

  

除非在尾注中另有说明，书中引用的所有电子邮件、信件、Facebook交流、短信和对话录音都是逐字复制的，包括拼写和语法错误。有些内容已从丹麦语翻译成英语。

  

![](../Images/2d580e6f315907c5179b3eb974a61bae.png)

斯托姆还提供了与他在冰岛的几位丹麦情报人员拍摄的照片。丹麦《日德兰邮报》的记者能够通过他们的消息来源确认这些特工的身份。

  

书中提到的几个人证实了斯托姆的故事的基本内容。为了他们自己的安全，我们没有披露其中一些人的全部身份。没有西方情报官员愿意公开身份。

  

斯托姆向我们提供了他的护照，其中包括从2000年起书中描述的每次欧洲以外旅行的出入境签证。他还分享了由丹麦情报部门使用的幌子公司 "莫拉咨询 "支付的酒店发票，根据丹麦的商业登记册，该公司在上市前就已经解散了。

  

此外，他还提供了几十张西联汇款的收据，记录了丹麦情报部门（PET）的付款情况。他的PET经手人在文件上列出了索伯格--PET在哥本哈根的所在区。

  

在书中对三个人使用了假名，以保护他们的安全或身份，这一点在第一次提到时就已明确。出于安全或法律原因，只使用了其他几个人的名字。书末附有一个戏剧性的人物。

  

本书包括阿语短语和问候语，在书末的档案中增加了一些照片和其他关于斯托姆工作的视觉见证。

  

在书的末尾，还增加了一个彩色图片部分。其中包括一张装有中央情报局25万美元赏金的公文包的照片、与阿乌拉基会面的手写笔记、解密的电子邮件、汇款收据以及在也门的沙布瓦省为会见该教士而拍摄的视频图像和照片。
