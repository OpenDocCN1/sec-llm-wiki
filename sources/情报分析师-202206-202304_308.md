# 如何利用书签创建自己的osint数据库

网上有许多网站，工具和提示可用于OSINT调查。但是，您如何控制自己的资源呢？您如何跟踪可以将哪个网站，工具或提示用于什么目的？您如何处理更改或源的丢失？现在是时候为您的调查添加更多结构了。在这篇推送中，您将了解如何使用**书签**编译自己的OSINT数据库。

**一、创建书签（以火狐浏览器举例）**

如果要创建书签，请右键单击书签工具栏，然后选择“*新书签...”*（请参阅下面的绿色箭头）。除了书签之外，您还可以通过这种方式创建文件夹（请参阅红色箭头）和分隔符（请参阅黄色箭头）。

![](../Images/17e46a952def3f7d22d07989224779d8.png)

如果您单击了“新书签...”，请在“名称”下输入新书签的名称（请参阅绿色箭头）。然后在“位置”下输入书签应指向的网站（请参阅红色箭头）。如果您想提及引用我们网站的书签，请填写以下书签。

![](../Images/e94880c344f44ec1137eb4c00cd1bf3e.png)

  

 如果您现在查看书签工具栏，您将看到添加了一个名为“Aware Online”的书签（请参阅绿色箭头）。如果您将鼠标移到此书签上，您还将看到此书签指向我们的位置（请参阅红色箭头）。如果您点击书签，您将被重定向到我们的网站。**二、创建您自己的 OSINT 数据库**  
现在您已经知道如何将书签，文件夹和分隔符添加到书签工具栏，现在是时候创建自己的**OSINT数据库**了。当然，您如何组织这完全取决于您，但我们喜欢在书签工具栏中使用类别和子类别。我们这是什么意思？例如，我们将“*网站*”，“*社交媒体*”和“*图片*”文件夹创建为主文件夹。我们将用资源填充这些文件夹，这些资源可以在我们在研究中遇到网站，社交媒体平台或图像时帮助我们（请参阅绿色箭头） 在上述主文件夹下，我们根据以下方式添加新文件夹：对于文件夹网站，例如，这些是“*注册数据*”，“*Web存档*”和“文本调查”。然后，我们将在这些文件夹中填写资源，以帮助我们调查网站的注册数据，存档文件和文本（请参阅红色箭头）。例如，在“注册数据”标题下，我们填写来源“SIDN”，“DomainBigdata”，“Whoxy”，“ViewDNS”，“Whois.com”和“Who.is”。这些都是可以帮助我们调查域名（以及网站）注册数据的来源（请参阅黄色箭头）。

![](../Images/927f72f730ef1937daa21517b551d76c.png)

  

## **三、创建自定义书签**

如果要在数据库中包含脱机源或说明，那也是可能的。例如，在您选择的文件中创建说明，然后保存此文件。我们在下面的文本文件中进行了解释，并将此文本文件保存在我们的计算机上，作为“测试.txt”。

然后单击文件的属性以查看文件位置。复制此文件位置并转到 Web 浏览器。然后键入文件位置（请参阅绿色箭头）并查看文件的内容（请参阅红色箭头）。为 URL 添加书签，以便您有一个解释的快捷方式。请注意，只要书签的位置指向文件的文件位置，您的书签才能正常工作。是移动还是删除文件？然后书签不再有效。

![](../Images/2c5509e10a1d330e3af2426ea634081c.png)

## **四、导入和导出**

如果要将书签复制到其他浏览器或另一台计算机上，则可以导出书签，然后将其导入。对于导入和导出，请单击菜单，“库”，“书签”，“查看所有书签”。然后选择书签工具栏，单击“导入并备份”并选择其中一个选项。
