# OSINT工具推荐

今天小编给大家推荐几款OSINT工具：

  

一、CheckUserNames

（https://checkusernames.com/）

  

![](../Images/8d6caf3a8c3cf5bb28f054bc8927e9da.png)

  

CheckUserNames是一个在线 OSINT 工具，可以找到 170 多个社交网络的用户名。这对于调查不同社交网络是否使用相同的用户名特别有用。不仅可以查找个人，还可以查找品牌和公司名称。

  

二、HaveIbeenPwned

（https://haveibeenpwned.com/）

  

![](../Images/cd83af3f19160cf00d70f720e47bc07f.png)

  

HaveIbeenPwned可帮助您查看您的账户过去是否曾被盗用。该网站由市场上最受尊敬的 IT 安全专家之一 Troy Hunt 开发，多年来一直提供准确的报告。

  

如果您怀疑您的账户已被盗用，或者如果您想验证第三方对外部账户的入侵，它是一个完美的工具。您可以跟踪来自各种来源的未经授权的网络访问，包括 Gmail、Hotmail、Yahoo 账户、LastFM、Kickstarter、Wordpress.com、LinkedIn 和许多其他流行网站。

  

一旦你介绍了你的电子邮件地址，你会看到结果，你会看到这样的东西：

  

![](../Images/9038a907af9b6466cfff27871e3af137.png)

  

三、BeenVerified

（https://www.beenverified.com/）

  

![](../Images/e7ecab60f1e6cd0448c453e101c8e862.png)

  

BeenVerified是一个类似的工具，用于从 Internet 上的公共记录中搜索人员。如果您正在进行 IT 安全调查，而您的目标是一个不知名的人，那么这对于获取有关世界上任何人的更有价值的信息非常有帮助。

  

完成后，结果页面将显示与该人姓名匹配的每个人，以及他们的详细信息、地理位置、电话号码等。找到后，您可以创建自己的报告。

  

BeenVerified 的好处在于它还包括犯罪记录和官方政府信息。

  

BeenVerified 背景报告可能包括来自多个数据库的信息、破产记录、职业历史、社交媒体资料，甚至在线照片。

  

四、ZoomEye

（https://www.zoomeye.org/）

  

![](../Images/88e0290c526d8142cedae1f78812e909.png)

  

ZoomEye是中国的物联网 OSINT 搜索引擎，允许用户从公开可用的设备和网络服务中检索公共数据。用户使用 Wmap 和 Xmap 来构建他们的数据库，对找到的所有信息执行广泛的指纹识别，最后过滤和整理以方便可视化。

使用 ZoomEye 可以获得哪些信息？

*   与网络和主机交互的 IP
    
*   远程服务器开放端口
    
*   托管网站总数
    
*   找到的设备总数
    
*   用户访问不同设备的交互式地图
    
*   漏洞报告
