# **美国在中东的军事基地？**

第一步是确定它可能属于的地点类型以及它可能位于哪个地理区域。

![](../Images/76d590e439ee21d60eff94f2c79013bc.png)

根据说明，这张照片是在中东拍摄的。这可以部分确认，因为停车标志（黄色）是阿拉伯语。在背景中，我们看到容器（紫色），在前景中，我们看到栅栏上的铁丝网（红色）。围栏后面似乎还有一辆救援卡车（“救援”）？

  

此外，街道名称（绿色）对应于美国城市和州的名称。这可能意味着它是美国的军事基地。我们恢复的第一个要素是，这张照片是在中东的美国军事基地拍摄的。但是哪一个呢？

  

# **确定军事基地**

# **阴影的力量**

下一步是确定它是哪个军事基地。为此，我首先从美国安全项目中检索了美国在中东的军事基地名单。我们可以在所有基地的地图上徘徊以找到确切的位置。但是，我们可以使用照片上可见的基础的特异性，并仅搜索此特异性。

  

为此，我们可以利用照片元数据来发挥自己的优势。实际上，在这种情况下，它们包含拍摄照片的日期。

```


$ exiftool image.jpg
```

日期和时间很有趣，因为我们在照片上有阴影。这个告诉我们，太阳几乎与“弗吉尼亚大道”标志对齐。标志与我们所在的道路平行，这意味着如果我们能够确定太阳的位置，我们就可以推断出道路的方向。

![](../Images/88100015713f2fc2789ad39616e530e9.png)

> 即使您没有元数据，也可以尝试使用照片的上下文和阴影来推断道路的角度，就像Nick Waters在调查加沙的罢工时所做的那样。

然后，我们可以使用SunCalc来识别拍摄照片时太阳的位置。我们只需要小心时区，因为元数据中的时间是电话时间（本地时间），而不是UTC-0时间。我们使用利雅得市作为参考点。

![](../Images/b89119dcbf610d583e684406dc865545.png)

现在，我们可以测量拍摄照片时太阳方向与水平线之间的角度。在这个例子中，这个角度几乎对应于摄影师所在道路的角度。

![](../Images/ea5c4b466034e8a4037bb1477c1ec4d3.png)

角度是36°，但太阳与标志不完全对齐，我们必须去除2°。

![](../Images/7aa7bf9c88630969bcb77fe9725938f4.png)

  

现在知道，拍摄照片的道路形成了一个34°的角度，带有一条水平线。现在，我们可以生成具有道路方向的图像，以便将其与中东美军基地的卫星图像进行比较。

我们使用 OnTopReplica 工具在地图上以透明度叠加道路方向。

# **街道的位置**

现在我们有了基地，必须确定照片的拍摄地点。基地相当大，有许多与我们确定的角度相对应的道路。为了简化视觉搜索，可以绘制一个更完整的顶视图，我们将覆盖在地图上。

![](../Images/b3057c2ad03fde0ee75209ec243f991c.png)

阿里夫詹营（来源：Google Maps）

  

# **学习一点点光学**

  

为了绘制顶视图，我们需要识别照片中存在的元素之间的距离。

![](../Images/7adbccdf5ecf3421f310e41c0f0364a8.png)

两座白色小建筑（紫色）和蜂窝塔（绿色）可能很有趣，可以包括在顶视图中，以及沿着集装箱的道路及其与“华盛顿路”的交叉口。为了计算相机和物体之间的距离，我们需要相机的焦距和传感器高度。可以从元数据中间接检索此数据。

```


$ exiftool image.jpg
```

了解手机型号后，可以从Camera FV-5设备数据库中检索其特性：

*   焦距：3.6毫米
    
*   传感器高度：3.5毫米
    

在计算到物体的距离之前，需要知道它的实际大小。对于这两座建筑物，我们可以将它们与附近的集装箱进行比较，一个集装箱高2.59米，因此估计高度为3米。

![](../Images/995df0d002e1c55c4c3d0f3923acc065.png)

![](../Images/5136d0adc96f01f24023d34a955ee1ff.png)

现在只缺少两个值，如果我们能识别其中一个，就可以计算另一个值，因为处于直角三角形中。根据集装箱，我们可以推断和估计两座建筑物与“华盛顿路”之间的距离。建筑物似乎在灰色/绿色容器的前面。

![](../Images/842d048068ff78ab39443194cf6f9b81.png)

估计交叉口和灰色/绿色容器之间的距离相当于10个容器，或120米。

![](../Images/39c5b776ef64f5c79c9914203b61c1b2.png)

使用毕达哥拉斯定理，现在可以计算出三角形的最后一条边：68m。

![](../Images/e90d2ccd3e7a49b530ea2c3edf83042b.png)

现在，可以修改图像以使其具有正确的比例。

![](../Images/61b43459fdc580ca40e633b220b36e15.png)

# 最后一步

在使用OnTopReplica在Google地球上使用顶视图之前，需要使用标尺工具对其进行校准，使其在地图上具有正确的大小。

![](../Images/4ab1d449415d5ef98c2c2fd33cd60a3d.png)

为了不错过位置，将地图分为Google地球中的几个区域，在进行过程中进行处理。

![](../Images/dc876ad5fab8511e6bba0185c29a1081.png)

我们终于找到了正确的地方！

![](../Images/852fe3bb275dbdbc3823b4dae33a9127.png)

# **结论**

然后，我们可以使用以下元素验证位置：

*   **墙（黄色）**
    
*   **建筑物（紫色）**
    
*   **蜂窝塔（绿色）**
    
*   **灌木丛（蓝色）**
    
*   **容器（红色）**
    

![](../Images/82ef26978a5ab59499e3d6e1a95b485d.png)

总而言之，尽管在创建顶视图时做出了不同的假设，但比例与现实相差不远，但相差几十米。但是，这使得查找照片的位置变得更加容易。要搜索的区域相对较小（4.5公里x 2.5公里），可以在没有俯视图的情况下完成。这主要是实施这种方法的借口，这在搜索更大的区域时可能很有用。
