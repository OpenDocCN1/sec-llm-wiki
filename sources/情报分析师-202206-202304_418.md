如何判断视频或照片来源和地理位置是情报分析师的必修课之一。今天情报分析师小编带大家了解如何使用OSINT来判断视频和图片的地理位置。这是一份详细的操作流程指南。关注收藏慢慢学习。

  

**介绍**

如果在Twitter上很活跃，或者如果密切关注叙利亚和乌克兰的战争，或者如果读过关于假新闻的文章，可能会注意到，现在有很多人已经通过验证在线视频材料来判断地理位置和拍摄时间作为职业或爱好。  

情报分析师广泛做的事情是使用开源信息来追踪图片的位置。开源信息可以是任何东西，但最常见的是在Google或Yandex上找到的图片，Google地图上的卫星图像和街景全景图以及Google Earth上的历史卫星图像。此外，分析师还利用Facebook和VKontakte等社交媒体上共享的可自由访问的数据。

在哪里拍摄？

*   使用哪些工具，如何找到它？
    

现在必须花时间思考想要使用的方法，以找出拍摄地点。必须找出可以使用哪些在线资源来确定该建筑物的位置。

开始思考全球地理定位爱好者常用的，最常用的工具：

*   谷歌地图。优点：街景覆盖伊斯坦布尔的大多数社区和地区。您还可以看到历史悠久的街景。它易于使用，您有一个3D工具，您可以启用该工具以查看某些建筑物，并且可以分析地形（要使用它，请在浏览器设置中启用硬件加速）。  
    缺点：没有历史卫星图像。
    
*   谷歌地球。优点：历史卫星图像，在这种情况下这很重要，因为正在根据超过10年的视频材料调查一个区域。  
    缺点：但看不到较旧的街景全景图，与谷歌地图相比，使用起来有点不舒服。
    
*   Yandex地图：也有土耳其的街景。甚至在谷歌推出街景视图之前，Yandex就已经拥有这项服务。换句话说，它也有较旧的全景图。当开始调查时，无法在最新的全景图和较旧的全景图之间切换，但是现在可以。另一方面缺点是无法用它看到旧的卫星图像。
    
*   谷歌搜索包括反向图像搜索。
    
*   Yandex搜索包括反向图像搜索。
    
*   谷歌翻译。毕竟大多数人都不会说土耳其语。别担心，可以用它来翻译非常基本的东西。
    

上面列出的工具是情报分析师使用的最典型的工具，无论位置或国家/地区如何，也可能希望使用提供更特定于伊斯坦布尔的开源数据的网站。

如果您在土耳其和伊斯坦布尔搜索街景服务，可能会发现伊斯坦布尔市有自己的网站，其中包含伊斯坦布尔地图，历史地图和卫星图像，街景和地形分析。

*   İstanbul Şehir Haritası.

**在继续回顾一下之前的发现**

现在知道了许多场景的拍摄地点，因此更容易找到剩余的位置。可以尝试立即找到一个位置，但这可能需要很长时间。当然，我们假设场景A是在场景B附近拍摄的，但情况并非总是如此，但是当几乎没有视觉线索时，值得首先找到更容易的位置，它可能会给一个提示，它可以在哪个区域。

分析了场景中的视觉线索，这些线索显示了我们想要找到的公寓，并得出结论：

1.  Uğur住在电影中的公寓靠近一个大广场。
    
2.  该广场周围环绕着围栏，可以很容易地与其他广场区分开来。
    
3.  广场上有泛光灯，表明附近可能有建筑工地或运动场。
    
4.  发现大多数场景都是在Kâğıthane，Beyoğlu和Eyüp地区拍摄的，因此希望专注于这个区域，更具体地说是Nurtepe。
    

# **没有技巧，只有纪律**

可以采取一些措施来更快地找到位置，例如，当商店名称或图片/视频上有显着地标时。在这种情况下，快速的Google搜索可能是找到感兴趣的位置所需的一切，但在很多情况下，我们并不那么幸运。

就是这样一个案例，除了在回顾中提到的4条线索之外，我们没有很多视觉线索可以参考。考虑到上述线索，来看看下面的地图：

  

![](../Images/e05b07c27b4f44336aee1ed9cb0e1a95.png)箭头表示Sokullu caddesi，圆形和椭圆形是潜在的候选者。

为地图添加了圆形和形状，这些只是首先检查的地方。为什么是这些地方？只是因为从远处看，它们似乎与视频中的视觉线索相对应。

1.  它们靠近房屋和公寓，看起来像是或可能是大广场，公园或游乐场。
    
2.  从这个距离来看，无法判断周围是否有任何围栏，需要使用某种街景来确定这一点。
    
3.  同上，不确定这些地方是否有泛光灯，但在其中一些地方似乎有一些足球场，这可能意味着那里也有一些泛光灯。
    
4.  所有这些地方都在Kâğıthane，Beyoğlu，Eyüp地区。其中一些在Nurtepe。
    

可能想做一个谷歌搜索来搜索该地区的所有公园，广场，游乐场和运动场，但现在选择不这样做。

在开始分析我在地图上放置的每个圆圈之前必须优先考虑。希望尽可能高效地做到这一点，因此必须在我们的脑海中列出一种清单（或者随意制作一个可能的地方的真实清单），从可以开始的地方开始。哪个地方最有可能纯粹根据它从上面看的样子来判断？Nurtepe的一个地方也许符合前面提到的条件。因此，从Nurtepe中可能具有泛光灯并且看起来最像正方形的地方开始，而不仅仅是像几个空地。
