# 海上力量的作用

海洋环境既是一种运输手段，也是一种资源。第一个方面显然是通过船舶运输的东西来表达的：集装箱，石油，矿物，我们日常生活中的许多物品和许多资源在我们使用它们之前就已经通过海洋了。数据也跨越海洋，因为海底电缆是互联网的核心，构成了“虚拟”世界的“真实”面孔。第二个方面，即资源，它要么是食物，主要是渔业，能源，石油和天然气的化石，要么是风力涡轮机和潮汐涡轮机的可再生，要么是矿物，从沙子开始，其开采鲜为人知，但对于包括建筑在内的许多活动至关重要。

![](../Images/427c589433cfd249c277f092b27709d1.png)

从十五世纪开始，与伟大发现的开始相对应，海洋的控制成为一个重要的话题。当时，英国沃尔特·罗利爵士（Sir Walter Raleigh）将其重要性理论化为：“谁拥有海洋，谁就拥有世界的贸易;谁持有交易，谁就拥有财富;谁拥有世界的财富，谁就拥有世界本身”。渐渐地，英国成为卓越的海上超级大国，取代了西班牙和葡萄牙，他们很快就被南美的殖民化所耗尽，这对它们来说太大了，无法与一个太陆地化的法国竞争。在19世纪末，英国控制着主要的海上航线，她的帝国幅员辽阔，拥有澳大利亚，加拿大和英属印度群岛的户外。

但进入二十世纪恰逢海洋新演员美国的到来。负责人阿尔弗雷德·马汉（Alfred Mahan），更新了罗利的理论，明确指出对海洋的控制通过对海上航线的控制，并且在这个问题上，一切都在海峡水平上进行。

![](../Images/f28e5f0cf6271c41f72dac5a3ed827e2.png)

从这个意义上说，关键的一年无疑是1914年：它对应于巴拿马运河的落成典礼，巴拿马运河是由山姆大叔控制的海上通道，但也对应于第一次世界大战的开始，第一次世界大战同时削弱了英国，因为冲突中花费的能量并不能弥补非洲的领土收益， 中东和太平洋。完成美国向20世纪下半叶海上大国转型的转折点是第二次世界大战。欧洲人，包括那些属于胜利阵营的人，太弱小了，无法维持他们的历史特权，特别是当殖民帝国由于政治和人口原因变得难以维持时。  

美国从战争中走出来，拥有一支庞大的军事和商船队（除其他外，这要归功于自由舰），并能够重建其在西方阵营的新盟友的舰队。此外，这种援助并不能阻止美国人使自己的利益战胜盟友的利益，就像苏伊士运河危机一样，他们反击了法国 - 英国的干预，这种干预在军事上设法通过外交手段重新控制了这一战略渠道。俄罗斯人几乎没有对这种对海洋的统治提出异议，俄罗斯人沦为一场以潜艇为象征的不对称对抗。重要的是要强调，俄罗斯没有直接进入海洋的机会，而海洋是美国的资源。

![](../Images/9da5295d93117547fa15ad162cc25df0.png)

海洋的力量是复合的，由相互乘以比加起来更多的元素组成。首先是进入大海，没有大海，一切都是不可能的。因此，作为一个岛国的英国，自然倾向于海上力量的投射。与两个大型海洋空间接壤的美国也受到青睐。事实上，珍珠项链战略的目标既是允许从新疆等外围地区出海，也是为了控制海上航线。此外，在当时，俄罗斯试图通过“争夺温暖的海洋”来发展其出海口。

一旦你掌握了进入大海的通道，就必须能够移动，这要归功于海上航线，尤其是战略通道。今天，美国人保留了对它的控制权，尽管中央王国试图编织它的网。例如，中国不想在巴拿马运河上动手，而是支持尼加拉瓜的一个竞争运河项目，即使后者暂时停止。交通也需要商船队，而中国是航运和造船业的冠军之一，美国人在很大程度上被抛在后面，受到保护主义《琼斯法案》（Jones Act）的阻碍，该法案维持着一支重要的商船队，但在全球化中被边缘化。

![](../Images/319246a5fc357608a8e8436a5c225152.png)

一般来说，在陆地空间主要由我们的人类社会控制的地方，海洋更多地逃避了这种现象，以至于它仍然是一个在许多方面需要征服的空间。极地地区，特别是冰冷的北冰洋，以及南极大陆周围的海洋，构成了人类的新边疆。海底及其矿产资源也往往不如陆地空间为人所知。
