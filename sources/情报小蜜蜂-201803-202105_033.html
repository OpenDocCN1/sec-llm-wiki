01

 Site

SecurityTrails


SecurityTrails提供DNS记录的当前数据和历史数据，这意味着你可以在任何给定的时间内找到网站托管IP的概况。除此之外，他们还提供了子域名概述，在DNS记录中，你可以找到有关运行邮件服务器的更多内容，以及其它技术信息，如SPF记录等等。

Link: 

https://securitytrails.com

Historical DNS information for a site


DomainBigData


如果你需要拥有历史Whois数据且完全免费的资源，DomainBigData是很不错的选择。你可以搜索域名，电子邮件或电话号码，甚至可以搜索名字，但要注意，在搜索给定名称时，它会返回所有名称相同的人的结果，因此可能不会指向同一个人。

Link: 

https://domainbigdata.com/

Now behind a Whois-proxy, but not in 2017


RiskIQ PassiveTotal


RiskIQ有一个公共数据库，可以在创建免费帐户后访问，它包含历史Whois数据，DNS信息，跟踪器，证书等更多内容。你可以通过IP地址进行搜索，找到其托管的网站，或者通过电子邮件地址注册的域名等。

Link: 

https://community.riskiq.com/

Finding domain names by Whois phone number


IPinfo.io


通过IPinfo.io，你可以找到有关ASN IP地址的信息。填写想了解的IP地址，可以得到有关所有者的信息，包括是否检测到VPN，TOR出口节点或代理以及滥用联系信息等，如果直接在URL中填写IP地址（如：https：//ipinfo.io/178.162.208.194），可以得到一个概述，如下所示。

Link: 

https://ipinfo.io/

IP address for de500.nordvpn.com


BGP Information


当你想研究一个IP地址时，可以使用ipinfo.io之类的网站来查询其基础信息，它会显示ASN（或它所属的IP地址块），被分配给谁以及其它相关内容，如果你想了解更多，例如该IP地址范围内的其他网站或在相同IP地址上运行的网站，可以访问Hurricane Electric BGP或BGP View网站。我个人更喜欢Hurricane Electric站点，因为它们不局限于ASN，在分配IP地址的子范围内也提供Whois信息。除此之外，他们还有一些额外的工具，例如“Looking Glass”，用于从世界各地的核心路由器运行多个跟踪路由。

Hurricane Electric: 

https://bgp.he.net/

BGP View: 

https://bgpview.io/

Shoutout to Jerry Vermanen, with this specific IP address within AS33915


ViewDNS


ViewDNS网站已经存在很长时间了，并在其概述中提供了许多有用的工具，你可以通过电子邮件地址查找域名，查询在给定IP上托管的网站，使用特定邮件服务器的网站，以及反向查找等等。

Link: 

https://viewdns.info

Revisiting the Norton scam again…


Reverse Analytics


Reverse analytics提供一项服务，你可以找到所有使用相同Google Analytics代码的网站，除了免费之外，该网站也有很高的检索成功率，即使免费套餐每次仅返回10个结果，也比其他搜索工具有用，后者会混淆结果内容，直到你付款为止。

Link: 

https://dnslytics.com/reverse-analytics

Finding connected sites


urlscan.io


urlscan.io可以扫描所有在线网站，保存屏幕快照并提供其网站构建技术的所有详细信息，除此之外，它可以深入解析HTTP请求，网站内的文本，IP历史记录，并可以通过比较扫描结果来跟踪一段时间内网站所做的更改。

Link: 

https://urlscan.io/

Screenshot and detailed information on a scanned web site
