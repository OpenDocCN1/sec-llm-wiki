Uncropping Media

Office Open XML Format


现在用于演示文稿、文档或工作表的最常用格式是Open XML Format，或简称为OOXML，文件扩展名末尾的X可以用来识别文件，即pptx、docx和xlsx。这些文件只是XML结构和媒体文件的压缩归档，你可以提取所有的内容，并得到原始大小的图像。

下面是一个小总结，可以发现从实际的pptx文件提取后得到的内容：

/docProps/ core.xml

文档属性，包括作者名，日期等等。

/media/

包含原始图片的文件夹，有时附带完整EXIF信息。

/ notesSlides /

所有讲义，每张幻灯片一个。

/tags/

带有“标记列表”的文件夹，向您提供了有关临时目录的信息。

/slides/

所有单独的幻灯片，甚至有可能找到实际文件夹结构的制造者。

快去解压docx，深入研究每个文件(或者使用现成的免费取证工具)，除此之外，下面还有一篇关于OOXML格式取证的硕士论文。

Link: 

https://pdfs.semanticscholar.org/753b/09eeaecd588449493b0449a2bbfc895705b2.pdf
