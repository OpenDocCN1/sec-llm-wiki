Domain Analysis

上周，在OSINT.team上，用户“Theo”分享了一个我从未听过的链接。Moz.com网站提供了一些免费工具，其中之一是域名分析，该工具可以深入了解关键词或用于特定网站的搜索。不仅可以方便地研究一些SEO问题（如https://osintcurio.us），还能找出用于查寻特定网站的搜索类型，然后您可以使用相同的搜索来查找其他可能的网站。


Link: https://moz.com/domain-analysis

Keyword analysis for https://osintcurio.us

Phishtank

在OSINT # 2019-41上，我分享了一个名为“PhishStats”的网站，这个网站提供了关于钓鱼活动的一些见解。当然，这并不是唯一的网站，几天后，Nixintel证明了这一点，他分享了“Phishtank”，一个令人敬畏的和惊人的快速网站，跟踪所有的钓鱼活动！


Link: https://www.phishtank.com/

UFS

开源工具，该机器人可抓取Facebook用户个人资料的几乎所有内容，包括用户时间轴上可用的所有公开帖子/状态，上传的照片，带标签的照片，视频，朋友列表及其个人资料照片（包括关注者，关注者，工作朋友，大学朋友等）
