Tool

Finding Hosts Behind Cloudflare

Francesco Poldi再次做到了！他创建了一个小工具，能够找到应用Cloudflare服务器的原始IP地址。虽然已经存在多种有相同功能的工具，但是他提出了一个全新的想法：在Shodan索引的网络服务器上找到网站相同的“图标”。当然，它在共享托管平台上作用有限，但是可以使用这个很棒的Python小脚本来找到具有自己专用服务器和IP的大型网站！


Link: https://github.com/pielco11/fav-up

OSINT.support

OSINT.support提供了新的Chrome扩展，所有不同的扩展程序现在都合并在一个工具中，您只需单击几下鼠标，就可以使用该工具在多个平台上查找帐户了。


Link: https://osint.support/#chrome-extensions

Site

Motorway Signs

前段时间，我在Youri发布的Quiztime挑战中寻找更多关于不同国家高速公路标志的信息。在四处浏览之后，我发现了一个收集世界各地的出口标志、距离标志和公路标志的网站。不确定它是否还在更新，但是如果你有更新的或原始内容，请随时发送给它!

另一个有趣的链接是欧洲路标的维基百科页面。当你试图匹配一个国家或地区所描述的标志时，可以使用这两种方法。


Link: 

http://www.brombeer.net/signs/

Wiki: 

https://en.wikipedia.org/wiki/Comparison_of_European_road_signs

Link: https://nixintel.info/osint/the-attrition-of-information-in-osint-why-acting-quickly-matters-and-how-to-recover-when-you-dont/

Reverse Image Searches

Craig Silverman前几天在Twitter上分享了一篇文章，解释了关于反向图像搜索引擎在何种情况下最有效的几乎所有的内容。除了技术的优缺点外，本文还提供了大量的测试及其结果。所以如果你的工作经常使用图片，那就看看这篇文章吧!

Meta Data

Fiete Stegers偶然发现了一个提供从任何文件中提取各种元数据服务的网站。我个人不会简单地在那里上传各种文件——尤其是那些包含敏感材料的文件——但我确实看到了它在你只有手机的情况下的一些用途。但无论如何使用，就元数据类型而言，它确实是完整的!


Link: https://www.get-metadata.com/
