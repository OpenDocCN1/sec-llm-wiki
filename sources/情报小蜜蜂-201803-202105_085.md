**Airbnb上的OSINT信息收集**

![](../Images/d66584193cd8eba64c2d0a4980d3164a.png)

最近，国外的开源情报爱好者发布了一篇帖子，我们也在星球上第一时间做了分享（想加入星球可以刷到文章尾部哦），讲述了在Airbnb上可能造成的隐私泄露问题。本文复现了那篇帖子的内容，并融入了自己的一些开源信息收集技巧，最后能顺利找出一些隐私信息。因此，在这里，先想提醒大家，涉及隐私的数据一定要注意保护。下面就来看看本文的分析方法。

![](../Images/74dce07cdf4b52b67469b7adbaaac4e9.png)![](../Images/74dce07cdf4b52b67469b7adbaaac4e9.png)![](../Images/74dce07cdf4b52b67469b7adbaaac4e9.png)

Airbnb是一家位于美国的点对点住宿公司，它允许注册房东提供住宿及招待服务。客人可以在Airbnb平台上预订住宿，还可以查看和预订当地体验服务，餐厅等等。房主可以列出自己的房屋信息并出租房屋，但规定非常严格，需要许多认证和协议。 

***01***

![](../Images/b79c964169edb853c17b7147f26c4a9a.png)

以图片上第一家房间为例，点进去之后发现该房间的位置为美国加利福利亚州的约书亚树沙漠荒野中，现在我们记录它的位置信息：joshua tree desert（以待后续查询使用）。

![](../Images/57bc9bbfccfd3d3e8e4d95fab2862b90.png)

然后点击房东来查看房东信息，如下图所示：

![](../Images/61b9a073ebe3bec5ad547494e8c165e5.png)

从房东信息里面我们可以看到，该房间的主人为斯蒂芬妮（Stephanie）和杰伊（Jay），其中Stephanie是一名建筑师，而Jay是《Arthur Magazine》的创始人及编辑，他们现在全职住在约书亚树，这里我们从Jay入手，记录他的名字及职业信息为：Jay+Editor（以待后续查询使用）。

接着我们在Google中输入关键字：Jay joshua tree editor（名字+地址+职业）,查询Jay的相关信息如下：

![](../Images/685016f1a2127715af4a3021dca7d0f8.png)

点击第一条信息出现关于Jay的名字以及曾经的职业经历：

![](../Images/67740274ec1d258bdc1acff4ef7ff4e4.png)

从该页面中获取Jay的名字为Jay Babcock，并记录下来，接着在Intelius中进行搜索：

![](../Images/b91dfafb1b348837425a8ea6e20366c4.png)![](../Images/d31ded5e6b4d640745d4d1a925c9e4eb.png)

在这个页面中我们发现了Jay Willard Babcock的地址在Joshua Tree CA，其亲戚为Stephanie Smith，在Arthur Magazine工作，这些信息与之前我们在Airbnb上面收集到的信息相吻合，由此推断，该页面所展示的信息即为房东详细信息。

  

***02***

除此之外，在Airbnb上面的地图搜索功能能够为我们提供特定位置的房东信息，例如我需要在美国纽约寻找一处合适的住所，通过筛选条件：日期、人数、房源类型、价格、位置区域、闪订以及其他的筛选条件找到一处纽约州位于East Village的住所：

![](../Images/580b6145a19fececfda7a6abff273111.png)

点击房东头像则会出现如下信息：

![](../Images/a54330cd304c689c5ecd8c7bf83e7ef2.png)

这里会显示房东何时在Airbnb上进行注册，个人简介，工作单位以及绑定了哪些社交媒体，例如在上述页面我们得知Reka绑定了facebook，但是却并没有公布其facebook主页，下面我们将利用一系列OSINT工具来进行深入挖掘。

（1）首先我们在Google中搜索关键字：reka HBO new York（姓名+公司+地址） 来寻找她的领英主页：

![](../Images/e36ac224a3c21cd710e1db922fcb2fbd.png)![](../Images/2e2eec12aef6338b900a024c56c00162.png)

这里我们找到之后主要记录其领英主页的网址为：https://www.linkedin.com/in/rekaposta/

（2）然后在rocketreach中输入reka的领英主页地址，即可查询相关信息（是否有绑定的Twitter账号、Instagram账号、邮箱等等）：

![](../Images/ceb64d229787ffcce167117db708b934.png)

这里主要记录其个人邮箱：rposta@gmail.com

（3）接着登录自己的facebook账号，启用通过邮箱来反查facebook profile ID的插件profile id extension，输入其个人邮箱即可获取到其facebook主页：

![](../Images/865d18a17debd5f5f1714cfc7c9d09cd.png)

（4）在获取了其facebook页面之后，发现除了头像信息之外并无其他个人信息内容，无法确定该主页为reka所有，此时我们手上的信息有其在Airbnb和facebook上的两张照片，因此可以通过商汤的人脸对比技术来进行判断：

![](../Images/af7b134aad59449e3a6e0d0df4f95db7.png)

这样我们就能确定，这个facebook账号即为reka所有。有一点需要注意的是，在Airbnb上的照片有两个人，而我们裁剪后只保留了左边，对右侧进行了删除。这是因为在评论区里面有一位曾经的住客评价reka与泰勒斯威夫特相像，因此在对比了轮廓、五官之后选择保留左边的照片进行比对。

***03***

最后，如果我们通过朋友推荐或者其他渠道得知约书亚树附近有一个名叫Jay的房东提供的房间和服务还不错，那么我们可以在Google中进行如下字符串搜索：site:https://airbnb.com “Jay” User profile “Joshua Tree”,这样操作的话，我们就不需要在Airbnb上花费时间去搜索，而在谷歌里面第一条就是该房间信息。另外Airbnb上的房东和房客的头像信息也是一个不错的开源信息来源，我们可以通过一系列的以图搜图软件来进行反向信息挖掘。

  
![](../Images/ca2d5e93b940fe725c339f4cf134cf71.png)![](../Images/ca2d5e93b940fe725c339f4cf134cf71.png)![](../Images/ca2d5e93b940fe725c339f4cf134cf71.png)![](../Images/b9a4caebd1dc8c33bb13c0ad215a07d1.png)

总而言之，开源情报收集技巧能够从一个线索里发现很多东西。在这里，我们既可以体会到开源情报收集技术的使用方法，同时也要提醒大家，注意保护自己的隐私信息，否则很容易被探测到哦。
