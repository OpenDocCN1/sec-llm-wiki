Tip

1 URL Expanders

bit.ly

tiny.cc

is.gd

goo.gl

…

大家都在网上看到过这些奇怪的网址。其实，它们是“URL shortners”，当空间有问题，或需要更易于阅读的链接时，它们为人们提供了一种发送简短网址以便在线共享的方式。问题在于，你不可能总是很容易地找到这个简短URL的真正含义，这就是OSINTtechniques的小列表派上用场的地方!


Link 1: https://www.expandurl.net/

Link 2: https://linkexpander.com/

Link 3: http://urlexpander.net/

Link 4: https://urlex.org/

Link 5: http://checkshorturl.com/

1 Chrome Extensions

上周，OsintSupport在twitter上发布了几个新的Chrome扩展，可以处理LinkedIn和Facebook相关操作。现在，如果你有一个电子邮件地址，并且想找到个人资料，你可以直接搜索LinkedIn和Facebook得到结果，当然，这些事情也可以通过上传你的“联系人列表”手动完成，但这为你省去了很多麻烦!安装与普通扩展略有不同，因为在商店中找不到它们，但页面顶部有一个明确的指导，所以去OSINT支持和添加这些扩展到您的Chrome吧!


Link: https://osint.support/
