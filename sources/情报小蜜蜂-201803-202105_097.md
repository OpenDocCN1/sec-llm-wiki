**攻击者伪造私人银行邮件“钓鱼”**

笔者最近收到了一封“有趣”的电子邮件，它来自Privatbank.com，主要用乌克兰语写成。虽然这个域名的网站是在2001年注册的，但在任何地方都找不到一家使用PrivatBank.com的知名银行，能找到最近的合法银行是privatbank.ua，一个著名的乌克兰银行，碰巧和这封钓鱼邮件使用了相同的标志。

邮件附件中包含一个AgentTesla keylogger / Infostealer版本，正文中的地址和电话号码来自花旗银行在雅加达的分行。PrivatBank.com网站重定向到另一个网站https://www.customer-service.net，这个站点也是在几年前注册的，目前位于cloudflare。唯一显示任何内容的页面就是欺诈/网络钓鱼页面。无论用户填写怎样的信息，最终都将重定向到https://www.customer-service.net/inquiry/dsinquiry.php?domainname=privatbank.com。

**通过偷渡式攻击分发的SEON Ransomware**

近期，研究人员发现，SEON Ransomware ver 0.2由GreenFlash Sundown exploit kit通过一个驱动攻击行动分发。执行加密后，SEON将删除原文件，显示赎金通知并添加'.fixt'作为加密文件的扩展名。

在加密例程之后，SEON将使用位于' %AppData%\\Local\\Temp\\startb '的批处理脚本，执行删除卷影副本的操作，以确保用户不能轻松还原所有数据。

**DoppelPaymer开始搞事**

近期，CrowdStrike®Intelligence监测到一种新型勒索软件变体，该变体将自己识别为BitPaymer。这种新变体是2019年6月开始的一系列勒索软件活动的幕后黑手，包括对德克萨斯州埃德库奇市和智利农业部的攻击。

笔者将这种新的勒索软件称为DoppelPaymer，因为它与INDRIK SPIDER操作的BitPaymer勒索软件共享了大部分代码。然而，在DoppelPaymer和BitPaymer之间也有许多不同之处，这可能意味着INDRIK SPIDER的一个或多个成员已经从这个组中分离出来，开始了自己的攻击操作。

**不慌~VLC未受严重漏洞的影响**

  

最近的一起安全警报引起了恐慌，人们认为VLC媒体播放器受到了一个没有补丁的关键漏洞的影响。问题是漏洞不在VLC中，而是在一个16个多月前替换的模块中。根据VLC开发人员Jean-Baptiste Kempf发布的一系列推文，这一切都始于Mitre在没有首先联系VideoLan的情况下为VLC Media Player中报告的bug创建了一个CVE。

该报告的bug是堆缓冲区溢出，这是libebml模块的一部分，早在16个多月前就在VLC中被替换。事实证明，报告用户使用的是一个较老版本的Ubuntu，其中包括一个易受攻击的libeml模块版本。在确定导致问题的原因之前，Mitre已经将CVE ID CVE-2019-13615分配给bug并将其添加到他们的数据库中。这导致德国CERT-Bund发布警告，VLC Media容易受到一个没有可用补丁的关键漏洞的攻击，截至目前，此警告已被修改。

**关于MegaCortex，我们所知道的**

当现代勒索软件首次发布时，攻击者会在广泛的网络中分发恶意软件，以便尽可能多地捕获受害者。在过去的一年里，勒索软件已经演变成更具针对性的企业攻击，并获得了巨大的收益，也正是因为看到了这个市场的前景，更多人加入了勒索软件领域。

研究人员已经发现并分析了一个名为MegaCortex的勒索软件样本，该软件以企业为目标进行针对性攻击。虽然Ryuk、BitPaymer和Sodinokibi (REvil)已经成为众所周知的“企业勒索软件”，但关于MegaCortex，人们仍然知之甚少。

**Watchbog变体新增BlueKeep代码**

新型Watchbog恶意软件变体可以扫描易受BlueKeep攻击的Windows计算机，以前的变体仅用于感染使用Jira，Exim，Nexus Repository Manager 3，ThinkPHP和Solr Linux漏洞攻击的Linux服务器。

“在新的Linux漏洞利用中，这个版本的WatchBog实现了一个BlueKeep RDP协议漏洞扫描模块，这表明WatchBog正在准备一份易受攻击系统列表，以便在未来瞄准目标，或者将其出售给第三方供应商以获取利润，”Intezer Labs说到。

BlueKeep是Windows远程桌面服务中存在的一个远程代码执行漏洞，它允许远程未经身份验证的攻击者运行任意代码，执行拒绝服务攻击，并可能控制易受攻击的系统。

**瑞典加密货币交易所Exchange QuickBit数据泄露超过300K用户**

据称，在NGM Nordic MTF上市的瑞典加密货币交易所QuickBit，通过一个不受保护的MongoDB数据库泄露了30万条客户记录，交易所在投资者关系委员会的一系列更新中证实了这一事件。QuickBit表示，外部承包商在尝试安全升级时没有保护数据。

报告中提到，QuickBit最近采用了第三方系统对客户进行补充安全检查。与此系统的交付相关，它已经在QuickBits防火墙外可见几天的服务器上，因此具有合适工具的人可以访问。在交付期间，数据库暴露了大约2％的QuickBit客户的姓名，地址，电子邮件地址和截断（非完整）卡的信息。
