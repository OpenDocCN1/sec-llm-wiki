1.    电子邮件包含VBS脚本，连接C2服务器后下载Trickbot Payload

Carbon Black最近了解到，一位客户收到了附有zip文件的恶意电子邮件，附件中包含了恶意VBS脚本。此VBS下载程序将连接到命令和控制服务器，然后将包含Trickbot的恶意负载下载到受害者的计算机上。在执行时，恶意VBS脚本将连接到命令和控制服务器“ hxxp:// bhrserviceaps[.]dk/78237_8219_9[.]php”，然后将名为“e.exe”的恶意负载下载到临时文件夹中。之后，它会将自身复制到文件夹%AppData%\wnetwork\里。

2.    恶意软件伪装成“损坏”文件进行攻击

Cofense发现了一个带有恶意附件的网络钓鱼活动，邮件附件中包含一个 “损坏”文件，但实际上它是可以运行的。在一些特定情况下，文件可以避开自动或手动分析，在目标环境中开始攻击。所谓“损坏”指的是缺乏文件首部，目的在于欺骗分析师，让他们认为附件是无害的，但事实上，无头文件会在打开附件时，或在尝试提取附件时使用特殊程序。该钓鱼活动试图利用信息超载特性，当处理大量信息时，分析师和自动防御有时会忽略错误文件，因为它们似乎是良性的，而在本文中，“损坏”文件会下载脚本以修复丢失的首部，然后在目标环境允许的情况下运行完整文件。

https://cofense.com/broken-file-hides-malware-designed-break-targets/

5.    小米预装安全应用程序中的漏洞

智能手机通常带有预安装的应用程序，其中一些是有用的，但有些根本就没用过，而且用户并不期望预先安装的应用程序对其隐私和安全性负实际责任。Check Point Research最近在世界上最大的移动供应商之一小米（Xiaomi）中，发现了一个预装应用程序中的漏洞。具有讽刺意味的是，它是预安装的安全应用程序“Guard Provider”，通过检测恶意软件来保护手机。简言之，由于进出Guard Provider的网络流量不安全，威胁行为可以连接到与受害者相同的Wi-Fi网络并执行中间人（MiTM）攻击。然后，作为第三方SDK更新的一部分，他可以禁用恶意软件保护并注入他选择的任何流氓代码来窃取数据，植入勒索软件或跟踪或安装任何其他类型的恶意软件。

6.    GandCrab 5.2勒索软件试图删除卷影副本

GandCrab 5.2勒索软件将追加7个随机生成的字符串作为每个加密文件的文件扩展名，并删除名为‘[generated file extension]-MANUAL.txt’的赎金记录，例如“office.doc.uahmthl”和“UAHMTHL-MANUAL.txt”。它还将更改受害者计算机的桌面背景，如下图所示。除此之外，GandCrab 5.2与之前的变体具有相似的行为。在GandCrab 5.2勒索软件加密文件后，它将尝试通过运行

“C：\ Windows \ system32 \ wbem \ wmic.exeshadowcopy delete”来删除卷影副本，以确保数据无法轻松恢复。

7.    垃圾邮件PNG文件隐藏LokiBot

最近笔者在安全电子邮件网关控制台查看时，发现了一些奇怪的垃圾邮件，附件具有.zipx扩展名，网关将该消息标识为PNG图像，图像本身类似于“JPG”图标，而主题行则是我们看到的与恶意软件相关的典型标识。但对样本的进一步分析表明，它是众所周知的LokiBot信息窃取木马。LokiBot是一种多用途模块化木马，试图窃取来自浏览器，邮件，FTP客户端和其他应用程序的密码和其他信息，以及大量其他功能。
