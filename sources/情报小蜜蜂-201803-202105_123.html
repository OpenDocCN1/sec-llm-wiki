前言

  万事开头难，学习固件逆向可不能一开始就卡在搭环境这一步。为了使初学者尽快的入门，本人将固件逆向搭环境的经验做个总结，以避免后继者重复踩坑。

正文

  “工欲善其事，必先利其器。”下面将介绍固件逆向中会用到的种种工具。第一款工具为binwalk，它是一个固件分析工具，用于协助研究人员对固件进行分析，文件提取等。Binwalk的安装十分简单，在Ubuntu下直接采用apt包管理工具进行安装为：

sudo apt install binwalk

binwalk功能强大，下面介绍下常用的两种功能。第一种是固件信息收集功能，直接执行命令：

binwalk re.bin

  第二个功能是固件文件提取功能，提取出固件的文件系统。直接执行命令。  

 binwalk –Me re.bin

  -Me选项代表递归提取，并将提取出的文件系统保存到了_re.bin.extracted目录中。进去目录，可以看到有这些文件。

  其中120200.squashfs是文件系统文件。对它的解压，需要用到专门的解压工具fmk（https://code.google.com/archive/p/firmware-mod-kit/downloads），下载最新的版本即可。解压后的文件夹名字为fmk。要想使用该文件，还需去fmk的src下对源文件进行编译。编译之前，需要安装必要依赖包。

  sudo apt-get install zlib1g-dev liblzma-dev

  然后进入src目的，分别使用这三个命令进行编译：

  ./configure

  make

  make install

  完成之后，即可对.squashfs的文件进行解压。解压命令为：

  unsquashfs_all.sh ./120200.squashfs

  这就完成解压，进入到squashfs-root文件夹中，可以看到相关文件目录了。
