一、漏洞介绍

         F5 BIG-IP是美国F5公司的一款集成了网络流量管理、应用程序安全管理、负载均衡等功能的应用平台。BIG-IP提供了应用程序加速、负载均衡、速率调整、SSL卸载和Web应用程序防护功能。其中CVE-2021-22986是未授权远程代码执行。该漏洞允许未经身份验证的攻击者通过BIG-IP管理界面和自身IP地址对iControl REST接口进行网络访问，以执行任意系统命令，创建或删除文件以及禁用服务。

二、影响版本

16.0.0 <= BIG-IP <= 16.0.1
15.1.0 <= BIG-IP <= 15.1.2
14.1.0 <= BIG-IP <= 14.1.3.1
13.1.0 <= BIG-IP <= 13.1.3.5
12.1.0 <= BIG-IP <= 12.1.5.2
