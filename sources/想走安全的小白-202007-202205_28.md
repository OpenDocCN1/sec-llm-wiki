### **一、漏洞介绍**

         Spring Boot框架是最流行的基于Java的微服务框架之一，可以帮助开发人员快速轻松地部署Java应用程序，加快开发过程。当Spring Boot Actuator配置不当可能造成多种RCE，因为Spring Boot 2.x默认使用HikariCP数据库连接池，所以可通过H2数据库实现RCE。

### **二、影响版本**

Spring Boot 2.x版本
