方法一:使用::$DATA进行绕过

 php在window的时候如果文件名后面加上"::$DATA"的话就会把::$DATA之后的数据当成文件流处理，不会检测后缀名。且保持"::$DATA"之后的数据当成文件流处理，不去检测后缀名。"::$DATA"数据流的目的就是不检查后缀名。但是注意只能是Windows系统，并且只能时php类型的文件。

②:使用burp进行抓包，修改文件名为phpinfo.php::$DATA

方法二:使用phpinfo.php. .进行绕过

 为什么要上传后缀名为. .的文件，这是因为有一个deldot()这个函数，这个函数的作用是会循环删除后缀名最后的点，因此即使是使用两个连续的点(php..)也无法绕过，因此在两个点中件加上一个空格，这样代码执行下来就是使用deldot()函数先去掉最外面的点，然后使用trim()函数去掉空格，因此上传的文件就变成了php.后缀，因为windows的文件命名规则最后面不能为点或空格等，因此会自动去掉php.中的点，文件名就会变成php后缀。

         通过查看源代码发现过滤了点和空格等字符，可以使用php. .(点空格点)来进行绕过，首先按照代码执行顺序，先执行deldot()函数过滤php. .(点空格点)后面的点，后缀名就会变成了php. (点空格)，然后执行trim()函数过滤php. (点空格)，后缀名变成了php.(点)，因此上传给服务器的文件就是php.(点)，但是windows的命名规则就是会把后面的空格、点等符号删除，因此上传的文件后缀名就是php，为什么不把后缀名写出php..(点点)，而非要在两个点之鉴加上一个空格呢？这是因为deldot()这个函数会不断检查文件后缀名中是否有点，只要文件后缀名中最后一个字符是点，就会一直去删除。这就是为什么要加上空格的原因。

Less12 利用%00截断绕过(十六进制)

0x01 Less12说明

查看源代码

$is_upload = false;$msg = null;if(isset($_POST['submit'])){    $ext_arr = array('jpg','png','gif');    $file_ext = substr($_FILES['upload_file']['name'],strrpos($_FILES['upload_file']['name'],".")+1);    if(in_array($file_ext,$ext_arr)){        $temp_file = $_FILES['upload_file']['tmp_name'];        $img_path = $_POST['save_path']."/".rand(10, 99).date("YmdHis").".".$file_ext;
        if(move_uploaded_file($temp_file,$img_path)){            $is_upload = true;        }        else{            $msg = "上传失败";        }    }    else{        $msg = "只允许上传.jpg|.png|.gif类型文件！";    }}

          从源代码中可以看到，文件路径此时是以POST方式进行提交的，而第11关则是以GET方式进行提交的。这两者的绕过思路是一样的，但是绕过方式略有不同。POST请求是以二进制流的方式进行传送，不会对%00自动解码，需要在二进制中对其进行修改。

get请求:请求的数据会附加在url之后并且以？分隔url和传输的数据，多个参数之间用&连接，会在URI中暴露出来 ；
post请求: 把提交的数据放置在http包的包体中，以二进制流的方式进行传送，不会对%00等进行自动解码，并不会暴露出来。
