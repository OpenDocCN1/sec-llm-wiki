一、文件包含漏洞介绍

0x01 文件包含简介

       开发者将相同的函数写进单独的文件中，需要使用某个函数时直接调用此文件，无需再次编写。这种文件调用的过程称为文件包含。

0x02 为什么要包含文件

      程序员写程序的时候，不喜欢干同样的事情，也不喜欢把同样的代码（比如一些公用的函数）写几次，于是就把需要公用的代码写在一个单独的文件里面，然后在其它文件进行包含调用。这就导致了文件包含的出现。

0x03 文件包含漏洞原理

       文件包含时由于每次调用的函数是不确定的，因此，在函数里面不能直接将被包含的文件写死，这样就必须使用变量来将用户输入的文件名传进去，这就导致了被包含文件是用户可控的，这样就可能会造成包含一些恶意文件，并且这些文件会在需要使用的时候将它们包含在特殊的代码中，这样包含的文件中的代码就会执行。如果没有针对代码中存在文件包含的函数入口做过滤，那么就可能会导致客户端可以提交恶意的语句，并且这些语句会交由服务器端进行执行。这样就可能会泄露敏感信息或者执行恶意代码。

二、文件包含相关知识介绍

0x01 文件包含漏洞的类型

      文件包含漏洞分为本地文件(LFI)包含和远程文件包含(RFI)。

  • 本地文件包含漏洞（Local File Include）

           当被包含的文件在服务器本地时，就形成的本地文件包含漏洞。 本地文件包含一般会配合文件上传漏洞进行利用。比如存在如下场景，当目标服务器上对上传的文件进行了限制，只能上传jpg类型的文件，但是如果目标服务器存在文件包含漏洞，就可以通过上传图片类型的一句话木马，然后配合文件包含漏洞，就可以成功解析php代码，使用菜刀拿到webshell了。

  • 远程文件包含（Remote File Include）

           远程文件包含和本地文件包含造成漏洞的原因是一样的，但是有一个前提条件就是php.ini中的配置选项allow_url_include必须为ON，这样包含的文件可以是第三方服务器中的文件，这样就形成了远程文件包含漏洞。如果可以进行远程文件包含，那么就可以在自己的VPS上写上一句话木马，然后使用远程文件包含，包含这个文件，这样就可以成功getshell。

       allow_url_include表示是否允许include/require打开URL（如http://或ftp://）作为文件处理。从PHP5.2开始allow_url_include就默认为Off了，这就表明一般情况下很难进行远程文件包含了。

0x02 文件包含常见函数

1.PHP文件包含相关函数如下

  • include()函数

    找不到被包含的文件，只会报错，但会继续执行脚本。

  • include_once()函数

    与include()函数类似，区别在于重复调用同一文件时，程序只调用一次。

  • require()函数

    找不到被包含的文件，会报错，并且停止执行脚本。

  • require_once()函数

    与require()函数类似，区别在于重复调用同一文件时，程序只调用一次。

  • fopen()函数

    打开文件或者 URL，如果打开失败，本函数将返回false。

  • readfile()函数

    该函数读入一个文件并写入到输出缓冲，若成功，则返回从文件中读入的字节数；若失败，则返回false。

2.JSP文件包含相关函数如下

  • java.io.File()函数

    打开一个文件的函数

  • java.io.FileReader()函数

    读取一个文件的函数

3.ASP文件包含函数如下

  • include file

    包含一个文件(包含文件的相对路径)

  • include virtual

    包含一个文件(包含文件的虚拟路径)

三、本地文件包含简单环境搭建

0x01 注意

      本地文件包含不需要开启allow_url_include，只要传入的文件参数参数是可控的就可以。

0x02 重点

       对于PHP环境，如果存在文件包含漏洞，被包含的文件会优先被当作php文件进行解析，如果被包含的文件中存在php代码，那么就会把文件类型按照php类型执行该文件中的php代码；如果不包含php代码，则会将其中的内容全部原样打印处理。(但是对于JSP来说，如果包含一个非JSP扩展名的文件时，即使其中的内容包含JSP，但是服务器也不会把该文件当JSP文件来处理)

0x03 本地文件包含作用

       使用本地文件包含主要可以做两件事，一件事是可以读取目标主机上的文件，另一种是结合文件上传漏洞getshell。第二种利用方式需要首先给目标主机上上传一个含有php类型代码的文件，然后使用使用文件包含漏洞执行其中的代码，然后getshell。

0x04 文件包含获取shell的条件

(1):攻击者需要知道文件存放的物理路径

(2):对上传文件所在目录拥有可执行权限

(3):存在文件包含漏洞；

①:为什么会使用php://filter呢？

     使用php://filter主要是为了查看php源代码，如果不使用php://filter，如果文件中包含php代码，那么将会直接执行php代码，就无法查看php源代码。
