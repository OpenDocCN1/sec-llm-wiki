Python是一种解释型、面向对象、动态数据类型的高级程序设计语言。它有着简单、易学、免费开源、可移植性等优点。

Python是纯粹的自由软件。

Python遵循 GPL(GNU General Public License)协议。Python语法简洁清晰，特色之一是强制用空白符(white space)作为语句缩进。

Python具有丰富和强大的库。它常被称为胶水语言，能够把用其他语言制作的各种模块（尤其是C/C++）很轻松地联结在一起。

我学习的时候是使用的python3，因此以后的分享也都是关于Python3的~~  

Python3

![](../Images/fee883414c674f9f000103bb4852a21d.png)

  

Python的3.0版本，常被称为Python 3000，或简称Py3k，是2008年开始发布的。相对于Python的早期版本，是一个较大的升级。注意Python3设计时没有考虑向下兼容，因此很多针对早期Python版本设计的程序都不能在Python 3.0上正常执行。

Python下载

Python官网：https://www.python.org/

从官网我们可以下载各个版本的Python。

  

linux/unix平台通过Source code下载。

linux下载源码包后通过以下命令安装Python

```

\# tar -zxvf Python-3.7.2.tgz
\# cd Python-3.7.2
\# ./configure\# make && make install
```

  

![](../Images/0f2bd8c6e70c4e9686391bb672714baf.png)

Windows和MacOS用户可以通过点击相应选项下载。

以Windows为例：

![](../Images/04692d5541d97c4b62b328ae7cd46d15.png)

点击后根据自己的操作系统选择x86或者x86-64的安装包进行下载即可，

web-based installer：基于网络的安装。就是通过网络安装，下载安装包后需要联网安装python。

executable installer：可执行安装。把要安装python需要的东西全部下载好然后本机安装。

embeddable zip file installer: 可嵌入的压缩文件安装。就是python打包成zip压缩包。
