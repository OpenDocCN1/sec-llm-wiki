ZoomEye 升级公告\[2017.12.15\]  

  
1\. 重新更新并开放 API 接口，兼容老 API 接口：  

> https://www.zoomeye.org/api

  

2\. 调整数据开放规则：

*   中国区 IP 相关数据只对中国并且实名认证用户开发；
    
*   未登录用户只能查询 1 页（20 条）IP 数据，登录用户可获得 100 页（ 2000 条）数据；
    
*   API 接口可以获取每月 100,000 条数据额度；
    

  
3\. 增加并更新了多个端口数据  
4\. 修复若干 Bugs 及加强用户体验

作为 ZoomEye(钟馗之眼) 前领导者，现社区核心成员，说几句吧...

  

之前写了篇纪念 ZoomEye 进入第 5 年的文章：[你拿走的不是天眼](http://mp.weixin.qq.com/s?__biz=MzA3NTEzMTUwNA==&mid=2651081237&idx=1&sn=9718a8cc7f867b8a53a40ce4e9e068bb&chksm=8485d50ab3f25c1c78797a7f99bd6c82e49f719c2451da7313d1554385190f23080e15bf7375&scene=21#wechat_redirect)，感兴趣的可以看看，看过的人其实应该能明白我想做些什么？

  

我重新创业有个核心方向对外一直没提，现在正式提下：我们会延续 ZoomEye 这个超级生态做特殊应用。和 ZoomEye 的关系在于：ZoomEye 是我们全球生态最重要的基础之一，我们通过一年的低调打磨，已经初步构建了一套全新体系能力，我们会做些细分领域的特殊应用，我们的特殊应用会回馈到 ZoomEye 这个超级生态，共同促进 ZoomEye 全球生态的大发展。

  

这些特殊应用可能不一定都会公布，但肯定会有公布的，敬请期待。

  

ZoomEye 已经是全球三大网络空间搜索引擎之一，但她的能量还没被足够挖掘，我希望通过我们的努力，能为这个网络空间安全带来点特殊的东西。借着 ZoomEye API 的回归，我和我的新团队，在厦门这座岛上，举杯相庆！因为我们知道，这过程，ZoomEye 经历了些什么。

  

感谢所有支持者！
