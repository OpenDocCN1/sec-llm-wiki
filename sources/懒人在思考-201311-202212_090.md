傻逼我当年学了 VB 家族（VB、VBS、VBScript，开发了小而挫的杀毒引擎、COSBlog系统等），然后傻逼又学了 Flash 及其脚本语言（ActionScript，在 Flash Web Hack 上有些许成绩），现在看看，全被时代抛弃了...  
  
幸好这个过程往前端安全走了走学了 JavaScript，现在看来，JavaScript 已经保值得不要不要的，前前后后一统天下。当年嫌弃的 Java（和 JavaScript 没半毛子关系）也如日中天。  
  
哎，选择真的比努力重要呀。  
  
想了想，还好还掌握了一些保值的玩意，如：C、Python、某些黑客技能、...  
  
现在越来越清晰未来保值方向了，选择真的太重要，节省一大把时间！

  

多说两句，对于未来保值方向，大多数人是很难有靠谱判断的，靠谱的判断方式就是你从一个跟风者/围观者成长为一个规则制定者或规则制定博弈过程的洞察者。只有这样，你才不至于出现选择恐惧症甚至被落下，要知道，现在时代变化实在太快太快了...

  

另外，当你变得优秀，你身边必然也都是优秀的人，你还怕被落下吗？  

  

你呢？留言说说你的。
