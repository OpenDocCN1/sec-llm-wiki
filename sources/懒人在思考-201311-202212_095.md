**高级软件开发工程师（2人）**  
  
岗位职责：  
负责公司安全产品的开发和维护  
  
岗位要求：

1.  熟悉常见Web安全漏洞及攻防技术，比如 SQL注入、XSS、命令执行、文件包含、XXE、SSRF 等
    
2.  主动关注国内外最新安全攻防技术，及时跟踪国内外安全动态
    
3.  熟练掌握至少一门开发语言（如：Java、PHP、Python）
    
4.  具有踏实的工作心态、良好的沟通能力和团队协作能力
    
5.  3 年以上工作经验（能力突出者，请忽略）
    

  

具备渗透实战经验的优先录取

知道 heige 的优先录取

有 Seebug ID 的优先录取  

  

地点：武汉

知道创宇招募产品经理，与黑客文化共舞，同护网络空间安全。

  

**产品经理**

  

职能：负责安全类产品的产品管理，产品运营管理工作  
  
岗位职责：

1.  产品规划和产品线路图设计（Roadmap）
    
2.  对产品市场表现负责，处理产品相关选型、资质，产品相关项目衔接等
    
3.  产品需求整理和转化为需求规格，对接开发组
    
4.  了解竞争对手的竞品状况，定期刷新竞争分析文案、招投标参数等内容
    
5.  对内部支撑人员进行培训和产品推广管理
    
6.  产品管理相关文档维护
    
7.  负责编写及更新服务及方案的主打胶片、方案介绍、营销素材和产品资料维护
    
8.  其他产品相关支撑工作
    

  

岗位要求：

1.  熟悉网络安全领域相关知识，熟悉各类安全产品及原理
    
2.  思维逻辑清晰，语言/书面表达能力强，同时具备较强的学习能力
    
3.  工作积极主动，具备敬业精神与工作责任心
    
4.  具有安全产品运维或安全产品开发经验者优先考虑
    
5.  3 年以上安全行业背景，2 年以上安全产品研发或测试经验
    
6.  具有良好的领导和组织协调能力，并富有责任心，能在较大压力下完成工作
    

  

具备下列任何一条经验者优先考虑：

1.  熟悉行业市场，军工、公安、运营商等行业有深入研究
    
2.  具备丰富的产品和技术解决方案经验
    
3.  有传统漏洞扫描器或漏洞管理产品管理研发或管理经验
    
4.  有大规模网络扫描产品研发或管理经验  
    

  

地点：帝都

  

简历发送：hr@knownsec.com，注明：应聘产品经理，来自「余弦」
