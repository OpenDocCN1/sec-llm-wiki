首先我需要说明下，这是一篇招聘贴 :)

  

是这样的，Python 这门充满惊喜的脚本语言应用场景非常广泛，如胶水一般处处紧密渗透，它已经是知道创宇的首选语言。

  

在知道创宇这八年，我用 Python 打造了大大小小许多黑客工具。对我来说用 Python 来实现我想实现的黑客工具是一件很愉快的事，它帮我屏蔽了很多底层的复杂细节，大多数时候我只需要专注在黑客工具的设计上，然后应用好 Python 那些语法、特性、模块即可。**有想法就能实现**，我要的就是这种感觉。

  

我知道，你要的也是这种感觉。我的招聘是这样的：

  

> 1.  我不需要新手，我希望你的编码实战经验至少 2 年；
>     
> 2.  编码方面，如果你恰好是 Python，那太好了，否则如果你用的是其他语言但是却愿意拾起这超级容易的 Python 来成为你未来事业的主要语言，那也行；
>     
> 3.  我希望你有黑客情节，这种情节会让你爱上你将选择的事业；
>     
> 4.  我希望你有思想有野心，这会让你绝不甘为平庸；
>     
> 5.  我希望你脚踏实地，这会让你打好持久战，而不是手高眼低、浮于表面、迷失初心；
>     
> 6.  我希望你有品味，这会让你对自己打造的东西充满挑剔，哪怕是一行代码；
>     
> 7.  我希望你渴望做些正事，我们都知道创造一个东西比写几行代码意义性与复杂度大太多了；  
>
