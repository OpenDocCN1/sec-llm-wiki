# 需不需要成为全栈工程师

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NTEzMTUwNA==&mid=207069133&idx=1&sn=502417b6476f55f986fec9116e1c8143&chksm=16d600d221a189c4662fdc67e4cc5c6e3271d1868fabe9c1b70786d2fc3ab87272e995123134&scene=126&sessionid=1681663967#rd](http://mp.weixin.qq.com/s?__biz=MzA3NTEzMTUwNA==&mid=207069133&idx=1&sn=502417b6476f55f986fec9116e1c8143&chksm=16d600d221a189c4662fdc67e4cc5c6e3271d1868fabe9c1b70786d2fc3ab87272e995123134&scene=126&sessionid=1681663967#rd)

是这样的，你需不需要成为全栈工程师，我不关心，我更关心的是我肯定需要，并且我肯定我的订阅者也会有很多人需要，对我来说成为全栈工程师是为了加深我的创造力，有时候我也会苦恼「我最大的困难是：正走在聚焦路上」，不过何为聚焦？我发现如果我每天少些扯淡、少见那些扯淡的人，那我就可以聚焦了，我要聚焦的是：把绝大部分精力放在创造力上。

  

明确这个聚焦本质后，成为全栈工程师对我来说是一种享受，我现在给大家分享下我的体验。  

  

要成为我自己认为的那种全栈工程师，我可能需要熟练十几种技能，都能熟练？不能的。以我最熟练的领域来做个启发吧，我在 Web2.0 Hacking 上做过很多猥琐的经典攻击，我非常明白一个道理，漏洞挖掘与漏洞利用都是一门艺术，很多时候一个漏洞摆在那，很多人没法利用好，就是 Exploit 过程没并真的发挥好，对我来说，我的利用过程会尽可能「借刀杀人」，善于利用环境已有的东西来做到攻击的完美。

  

我的目的是加深创造力，对我来说，很多时候我要善于利用已有的东西，重复造轮子的事我不会去做，除非逼不得已。

  

如果是这样来看，想成为我认为的这种全栈工程师，并不是一件难事，至少对我来说，要搞定一些系统已经是信手拈来。但是如果只是懂得拼凑，那还远远不够，根本谈不上「加深」创造力，一个 Bug 的出现可能是致命性的，但是你却没法深入调试并解决之，这就是所谓的「内功」。

  

这里需要强调下，创造力的加深需要同时走好两条线：专注 + 视野。

  

似乎是一个「深」一个「广」。但是仔细想想，这两者是纠缠的，平衡的，切忌顾此失彼，否则非常容易浮躁与迷茫，这也是我给新人们最大的建议，极简的建议，只占你大脑8个字节，不过背后的信息量可能会挤爆你的大脑。

  

成为全栈工程师后，我可以一个人观察这个世界，并实现自己想实现的东西，这个感觉当然很爽。对于更加复杂的体系，如果能遇到志同道合者，一起互补实现，那更是爽上加爽。  

  

成为全栈工程师的另一个好处是，在团队协作中，你能很好理解其他工程师的工作，他们在细分领域比你专业，他们的思维与成果，能引起你的最大共鸣，你很可能可以成为一名优秀的工程师 Leader。  

  

在我接触的圈子里，全栈工程师有好些个，有的人全栈到不可思议，和他们交谈时，你会享受这种共鸣的感觉。  

  

我享受这种感觉，我享受具备创造力。
