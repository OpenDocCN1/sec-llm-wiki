当你成为那只特洛伊木马之后

上上周穿插写了《浅析知道创宇研发技能表（一）》，这次穿插回来吧。


我昨天在朋友圈发了条消息：

我头疼的问题只有一个：正在走向聚焦的艰难路上。


我以前说过「精而悟道」，人得专注，但还得有一定的视野。有的时候我们为了追求所谓的「视野」而浪费大量不该浪费的时间，比如我有时候觉得写公众号就是浪费时间，当然现在不一定这样觉得。正因为这样的「觉得，不觉得」导致我几乎没法聚焦，这是个有趣的心理，你肯定也有。


为什么突然提这个？是这样的，其实打造这台黑客手机，并不是我擅长的，驱使我这样做的本质原因是「好奇心」。


进入黑客领域有10年了，算是有所小成，曾经聚焦5年和好友写了一本书《Web前端黑客技术揭秘》，两岸三地发行，现在已经第七印了，获得了优秀输出图书的荣誉，今年过年还发了点小奖金给我们。书出版的时候，我最大的感慨就是「精而悟道」，有人讽刺我骄傲，那是他根本不知道什么叫「悟道」的感觉，我并不觉得骄傲不好，前提是得有这样的资本。再说了，我岂是在这点小成绩就浮起来的人...


我真的聚焦5年写这书？其实如果回顾我在知道创宇的时光，只能说我在用业余时间去聚焦，工作上的内容几乎和我业余聚焦的没什么关系，但是为什么可以平衡好两者？这个问题，和我现在面对没法聚焦的问题本质是一样的：

在追求道的路上，那些看似没什么关系的东西，最后都有了关系，所谓的「殊途同归」。我在那条主线路上，并发走了 N 条小路，最后发现那些小路也属于主线路，始终缠绕。


并发？如果你了解程序的并发世界，如 Python 里的协程，你会发现我们人生轨迹确实如此，并不是真并发，而是不断切换我们处理任务的优先级，从一个任务切换到另一个任务，在外界看来这种感觉是一种「并发」，实际上我们只是在做最优美的快速切换。


以上的讨论，可以衍生出很多有趣的话题，这里不展开了，切换进本文正题。



正题就是这部黑客手机，用一加打造的，如果你是新读者，回复「h」，翻翻历史消息再来读这篇。前面几篇我们了解了如何打造出这部手机、如何 Wi-Fi 破解。


好，现在告诉你，当你连上目标 Wi-Fi 后（无论是你破解进去的，还是向咖啡厅服务员要密码连接进去的），在这样一个局域网内，你已经是「特洛伊木马」了，你可以做什么坏事？


曾经我的一段文字如下：

这时要黑你就比较容易了。

ARP 一下，嗅探你的网络流量，里面有你的各类隐私，可能就已经可以把你在互联网上的账号黑个遍，这种黑个遍是很多黑客都经历过的。

也许直接入侵到你电脑不行，但是通过篡改 HTTP 响应内容，替换下载文件等间接进入你的电脑。

来个猥琐小例子，假如你有百度网盘这类的服务时，知道你百度网盘的账号后，把里面的软件替换为有后门的，然后坐等你以后安装都中招……

还有你说路由密码是默认的，好，在有些路由里可以直接抓各类流量，然后专业的包分析工具一分析就都出来了。

或者麻烦点，DNS 记录修改下，然后照样抓包。


这段文字看去简单明了，不过你真的会玩？会玩的你真的了解其后本质？我的性格是，如果要玩透就必须「打破砂锅研究到底」，这种「打破砂锅」的机会留给你自己，在这我只做必要引导。


为了做出必要的引导，我来说一个故事吧。


有一天，我到了中关村那条创业一条街去参加某周年庆典，我这部黑客手机习惯性随身携带。


连入这个公共 Wi-Fi，开启 dSploit（手机 APP，你自己可以安装），然后就开始了经典的 ARP 攻击，接着是中间人攻击（MITM），整个过程非常顺畅，路过几个咖啡厅，抓了一堆数据包下来，随后围观了一群创业者们的百度、QQ、微博等账号，出于好意，我没兴趣深入。


在某个场所，ARP 后，网络太慢，导致管理员不得不登录路由器 Web 控制台查看情况，于是乎，监听到了路由器 Web 控制台账号密码，拿下路由器管理权限后，开启远程管理，开启 VPN 服务，又一个攻击跳板诞生。


ARP 怎么能这么厉害？其实可以说大家的安全意识还是极其薄弱，薄弱到令人发指，在我的世界观里，哪怕黑客攻击事件再怎么渲染、夸大宣传，你们大多数人还是那样的无动于衷，因为你们不相信那种被黑的「小」概率事件。如果我创建个全球最大的「绵羊墙」，只要被黑的都被提交到这个绵羊墙，这样的话，是不是好的？:)


当然我不打算这样做，吃力不讨好，这个世界还是这样更加有趣。


有些不错的路由器就自带了 ARP 防御功能，可是默认没开启，管理员当然也不知道开启，其实手机、PC 客户端有 ARP 防御软件，用户也不一定用。就好比，我们都知道火灾无情，却极少人家里有灭火器...


在同一个网段里，其实攻击手法还有很多奇技淫巧，这是黑客领域中极其重要的分支了（内网渗透），有机会我会自然而然地道来。


黑客世界的技能太多，多多益善的同时，精而悟道。当你在实战时，方可体会为什么要这样。
