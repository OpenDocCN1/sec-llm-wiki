提醒，看我文章的都请先做下这件事：拔掉伪善的面具，不谈仁义道德。

  

上篇文章是「关于 ThinkDo」，大家期望我写的东西很多，不过在我看来都只有一个：如何成为强大的黑客。

  

我还不强大，因为我发现我最近想做一件强大的事，出现了技术瓶颈，这个距离我心中的那种「强大」差远了，但是我发现一流的黑客，往往是团队，技能能很好互补，所以有些强大的事，可以以团队力量去搞定。

  

成为强大的黑客？先泼冷水，很难，难度超乎绝大多数自以为是黑客们的想象。

  

我1年多前写了篇极具我风格的文章《我眼中的黑客》，回复「**005**」可以查看。总结起来就是一句话：

> 黑客，是守正出奇，且具备创造力的群体。  

  

这是我眼中的黑客，也是我对自己的要求，我不指望你这样认为。

  

* * *

作为一名拥有分享精神的黑客，我在想后面的文章怎么写比较好，太多素材我可以信手拈来了，不过我不打算把你养成「拿来主义者」，我准备以一种我轻松，你不轻松的方式来写...  

  

先以「工具党」为切入点来写吧，以下是关于工具党的引子：  

  

> 黑客，不特殊，又很特殊。
> 
>   
> 
> 首先，这个世界如你这般想法与执行力的黑客不少，你一定要相信你现在想实现的那个工具，在世界的某个角落总会有一个在某方面天资胜你，却比你还努力的人，恰好这人写成了这个工具，恰好他还在 GitHub 上开源了。
> 
>   
> 
> GitHub 上你费劲心力发现并没如此合适的工具，你觉得你要成为世界上第一人时，别忘了，还有那么一大批黑客，他们要么是雇佣于国家，如：最近沸沸扬扬的「方程式组织」，要么是只有利益信仰的地下黑客。这些人的工具是他们决胜的武器，低调是他们的座右铭。
> 
>   
> 
> 作为一名职业黑客，总想有自己独家的黑客装备，其实这不是关键，关键问题是：会不会用得好。

  
最近我在玩一加手机，我在上面安装了 Kali NetHunter（看题图），很帅，安装容易，打造成自己能把玩顺利的却不那么容易，尤其是上面内置了全球众多知名黑客工具，这些黑客工具都很有个性，不一定会顺着你的脾气...  

  

选择一加的原因是因为，Kali NetHunter 官方的强烈推荐，并且是国产，性价比很高了。
