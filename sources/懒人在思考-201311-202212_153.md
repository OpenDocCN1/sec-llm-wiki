**ThinkDo**  

  

这条路，我一直在进化一个很牛逼的东西，此刻分享给你们，这个牛逼的东西，完善了我的世界观。

  

这个东西就是 GTD。

  

> 呵呵，嘿嘿，哈哈，GTD 什么玩意？哦！GTD 不就是 Get Things Done 嘛？早就有人提过这个了，什么神奇的？  

  

打住，打住。这东西确实是 Get Things Done 的缩写，但名词不重要，重要的是你真的理解其精髓了。  

  

这种精髓也是所谓的门道，门道这玩意意会不了，我也三言两语说不完，除非你已经开窍，此刻才能和我共鸣。还没开窍也没关系，以后细细品味我的分享会慢慢开窍。

  

暂时先回到本文标题的 ThinkDo，这个 ThinkDo 意思简单得很：想，然后做！

  

有人说：Idea 不值钱，值钱的是执行！

  

我想说：这些人根本没开窍，或者说这话不经过大脑，或者就是敷衍了事随口一说。

  

其实在我看来 Idea 可以很值钱，这就是 Think，也就是那种想象力，那种可以落地的想象力，注意「可落地」，因为这样才能做！

  

想象力和什么有关系？和你长期**专注**所积累的功力有关，和你的**视野**有关。有些人，才初出茅庐，路都走不好，就开始想飞，不摔死才怪，风口上的那只猪，也不是这种人可以站的上去的。  

  

很多很多人不缺乏执行人，不缺乏一腔热血，就缺乏这种可落地的想象力。

  

这就是我经常内部培训时说的的：**想象力瓶颈**。

  

1月份时，我在北邮沙龙做的《大数据黑客》内部分享时，就反复强调过想象力的重要性，为什么某些人可以黑掉全球，某些人即使手上有个好漏洞也仅仅是最初级的 Demo？想都想不到，怎么做？  

  

软件工程里，很多同学都应该知道下面这个典型的瀑布过程：

> 需求->需求分析->设计->研发->测试->运维/运营->反馈  

  

这个过程中，最最关键的是：需求分析后搞定设计，如果团队的「这种可落地的想象力」匮乏的话，那后面的研发等过程将会是一个悲剧过程，会导致项目不断变更，甚至夭折，这就是那些自嘲为码农的群体最大的痛苦。  

  

自嘲没用，痛苦也没用，有用的是尽快让自己、让团队突破想象力瓶颈。  

  

好，现在回到 GTD，我前面说了我一直在进化自己的 GTD，其实我还在不断进化团队的 GTD。GTD 是一系列好习惯的指数叠加，这会让你有这种牛逼的技能：想到了就可以做到，做，就能漂亮。  

  

GTD（Get Things Done）就是要搞定事情！此可谓 ThinkDo 的 Do 门道。

GTD 能让我们给出做事最佳途径，能让我们顺利搞定这件事。  

  

看到这还不理解 GTD，没关系，我后续的一系列想写的文章，多少会透露着我的 GTD 习惯，我的思维方式，别急，反正你要么刚起步，要么已经落后一大截，要么已经在开窍的路上，不差这个过程的煎熬。  

  

我前面有说到：

> GTD 是一系列好习惯的指数叠加。

  

比如，大家看本文开头的那个 FreeMind 图，此乃神图啊，此图是 FreeMind 这款免费软件做出来的，类似的软件如 XMind 等，这类软件可以帮助我们梳理我们的思维过程，做出来的图就叫做思维导图。

  

梳理思维过程做什么？如果你是《神探夏洛克》里的那个卷福，那你不需要这样的方式来梳理，因为他的大脑就是一座记忆宫殿，他做推理时可以在大脑里具象出立体思维模型，可以顺着模型路径不断延伸出去寻找记忆的关联点！你可以么？:)

  

你不可以！如果你可以，你就不是我的读者了，如果我可以，我都懒得和你们去分享了，我有那种技能，我有把握变得更加传奇:)  

  

既然，我们都是凡人，好吧，那很多时候我们都要不断梳理我们的思维、我们的记忆，FreeMind 就是这种绝佳的方式！当然如果你不习惯电脑上操作 FreeMind，你也可以拿起纸质笔记本来享受那种原生态梳理过程。还有一个好建议是，你可以买块大小适中的白板，写写画画，然后用印象笔记拍照归档，也是不错的方式。从现在开始，享受这个思维梳理过程吧！  

  

看吧，这就是一个好习惯，我的 GTD 里有 N 多好习惯，然后它们叠加，不是简单的叠加，而是指数叠加，我指的是，产生的正能量成指数级增长。

  

所以我可以说我做事的效率还是蛮高的，我在团队管理过程中，每天会并发很多事务，但是几乎都能有条不紊处理妥当，能把控那种平衡，如果没这种不断进化的 GTD，那我早吐血了。这过程真是心酸一把泪，以后慢慢道来。  

  

我的 GTD 习惯里还蔓延着一条大多数牛人没有的东东：黑客技能，这在我们面对的网络空间里，这是一种超能力，有时候稍微用到，效率倍增啊。以后慢慢道来。  

  

说到这，本文差不多了，已经描绘出了 ThinkDo，之后无与伦比的过程还是那句话：以后慢慢道来:)
