# 墙缝里的「老大哥」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NTEzMTUwNA==&mid=200270682&idx=1&sn=0c5466090574a1d7417b6cb914abaeb2&chksm=116e7c452619f553d6817e61ceecacf713a8d53dfe991ddfcfb6eecbc4da724205a2758edc57&scene=126&sessionid=1681664002#rd](http://mp.weixin.qq.com/s?__biz=MzA3NTEzMTUwNA==&mid=200270682&idx=1&sn=0c5466090574a1d7417b6cb914abaeb2&chksm=116e7c452619f553d6817e61ceecacf713a8d53dfe991ddfcfb6eecbc4da724205a2758edc57&scene=126&sessionid=1681664002#rd)

今天看到知乎有人邀请我回答下面这个问题：

> 大学校方监控学生的上网记录妥当吗？是否侵犯学生隐私？学校通过什么技术手段监控，并且推送通报批评的消息？
> 
> ![](../Images/b13d2536160ccc82c4169db38df00534.png)

这个问题的讨论非常激烈，大家可以点击本文底部的「**阅读原文**」看看。

**我的观点如下：**

这种监控流量与劫持的技术已经很成熟的，技术上没什么好探讨，能精确到姓名通常是上网需要登录一个特殊的客户端软件，输入实名认证后的账号密码，之后的流量经过校网络中心的统一出口，非加密数据都将一览无余，而某些加密数据如果投入足够成本也是可以解出。如果这种客户端软件类似曾经的奇葩「绿坝娘」的话，抓你本地任何行为都可以，哪怕你用了代理（你懂的）。

当然也有可能像我当年在校网络中心任职时，挨个宿舍统计每个人电脑的「MAC+IP+姓名」等信息那样。反正只要能实名，学校就能监管，当年我的母校没这样的奇葩行为，但是背后的技术原理是通的。  

这个学校在扮演「老大哥」这个令人发指的角色，为了做好这个「老大哥」，不知道内耗了多少人力物力。

引用一段关于「老大哥」的描述：

> 在小说《1984》里，乔治·奥威尔为我们描述了一个无处不在的「老大哥」形象：一个无时无刻无所不在的「老大哥」监视着所有的人的一举一动，无论是吃饭、睡觉、工作或者走在街上、躲进洞穴——包括思想活动。老大哥在这里象征着极权统治下对公民无处不在的监控。

更奇葩的是，居然篡改了用户上网流量，直接给你客户端弹出一个「通告提示」，这种技术很简单，就是篡改 HTTP 文本流量的响应内容，植入一段 JS 脚本，弹个框等方式进行「通告提示」。

最让人无法接受的是，「通告提示」里居然如此赤裸暴露学生隐私，隐私权被这个奇葩的「老大哥」糟蹋蹂躏，真是让人咬牙切齿！大学生上个黄网都被这样搞，真是个可怕的思维禁锢，我估计除了黄网，还很多其他敏感词呢。

躲在墙缝里的「老大哥」，你得低调点。
