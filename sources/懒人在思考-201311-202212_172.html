本着负责任的态度，我们在书的前言里还放出了本书的官网：web2hack.org，在这个官网上我们持续更新书的进度、相关资料、Bugs 修正等。我们正是这样认真的人。

最近这书似乎又进入了大众讨论的视野，微博上总有同学@我关于这书的信息，我最近也给相关单位做了内部培训，我感觉出大家对「Web 前端黑客」或「Web2.0 黑客」的着迷。本篇，我将带大家半只脚踏入「Web2.0 黑客」领域。

注：Web2.0 黑客的战场在 Web 前端（实际上就是浏览器层面上），所以这里说的「Web前端」==「Web2.0」。

Web2.0 科普

为什么说 Web2.0 呢？网络上对 Web2.0 的定义是：用户参与的社交网络形态。传统的 Web 是不会有用户参与的，或者参与形式很弱，比如新闻网站、院校公司等官网，这上面的内容由网站管理员发布，而用户更多是浏览浏览，有时还可以评论评论，这个模式就是传统的 Web 模式。而像 Facebook、微博、QQ 空间、朋友圈等都是 Web2.0 的经典代表，用户参与度非常高，这些就是我们常说的「社交网络」。

用户参与度高，意味着黑客也可以参与。在「社交网络」里，你很难知道你看到的信息里会不会有猫腻。

在 Web 世界里，你肉眼可见的都是 HTML/CSS/JavaScript 等代码描绘出来的。如果你在电脑前，可以随便打开一个网页，然后点击鼠标右键，找到「源代码」或「源文件」字样，打开的页面才是 Web 的本质，这里面满是 HTML/CSS/JavaScipt。

我简单科普下几个术语：

HTML：超文本标记语言，负责描绘 Web 世界的骨架；

CSS：层叠样式表，负责描绘 Web 世界骨架的布局、颜色、大小等；

JavaScript：脚本语言，负责控制 Web 世界骨架的动作；

在这样的 Web2.0 世界中，发生的攻击行为可以非常非常隐蔽，对于用户来说极难防御，这不是电脑上安装个杀毒软件就能搞定的，电脑上的杀毒软件只能杀电脑里的病毒，却对 Web2.0 里传播的病毒毫无办法。

更可怕的事，这种攻击已经流行好几年了，别说普通大众，就连很多安全专家都没这方面的意识。

Web2.0 黑客能做什么

黑客攻防手段很多种，Web2.0 黑客是最猥琐的一种，Web2.0 黑客的攻击往往是被动式攻击，黑客得准备好陷阱，诱惑目标踏入，而不是拿起「刀斧」直接攻击。

对于 Web2.0 黑客来说，他只需在「社交网络」里控制 JavaScript 代码的执行逻辑，就能拥有了控制这个「社交网络」的超能力。

JavaScript 代码是 Web 世界的灵魂，很多正常的功能都可以基于 JavaScript 代码来增进用户体验，比如一些常见的功能：关注好友、发布消息、发布私信、编辑内容、删除内容、修改配置等等，你在 Web 世界的一切操作，JavaScript 都有能力完成。所以一旦黑客能控制 JavaScript 代码的执行逻辑，就能设计出非常多邪恶的操作，包括拿下你的账号权限（所谓的盗号）。

做个小实验（无害）：

比如针对 weibo.com 的一个小玩笑，大家可以用 Chrome 浏览器（360安全浏览器/傲游/猎豹/QQ浏览器都可以）登录自己的微博，然后按 F12 打开「开发者工具」，在 Console 或控制台中，复制上如下代码，回车执行：

STK.core.io.ajax({method:'POST',url:'/aj/f/followed',args:{uid:1652595727}}); STK.core.io.ajax({method:'POST',url:'/aj/mblog/add',args:{text:'%40%E4%BD%99%E5%BC%A6%20%E6%88%91%E6%8E%89%E5%88%B0%E4%BD%A0%E7%9A%84%E9%99%B7%E9%98%B1%E9%87%8C%E4%BA%86%E2%80%A6%E2%80%A6'}});

刷新自己的微博看看，发生了什么？

Web2.0 黑客的战场在浏览器层面（包括基于浏览器内核的软件），所有的攻防都围观着浏览器。打开浏览器，就意味着你进入了 Web2.0 黑客的势力范围。你说你上个网，不开浏览器吗？其实，QQ 聊天框也是「浏览器」。

Web2.0 黑客入门

对于 Web2.0 黑客来说，常用的攻击武器有：XSS 与 CSRF，次要的有：逻辑漏洞、ClickJacking 等。XSS 在整个 Web2.0 攻击体系里占据主流位置，也是一个极度残忍的冷兵器，浏览器是它的战场，JavaScript 代码是他的主体。

这些知识点很难在一篇文章中科普完，我们的书《Web前端黑客技术揭秘》是国内唯一一本在这方面很全面的书（《Web之困》是另一角度，老外写的，国人翻译，也推荐），对于这点，我丝毫不隐晦……

虽然很多人跟风买了这本书，但却并没认真读完，这在我看来非常遗憾，书中我们给出了足够的料，有心人如果实践完，成为一名合格的「Web2.0 黑客」毫无问题。入门这本书需要的基础知识还是比较多的，比如前面说的 HTML/CSS/JavaScript，如果连这点语言都没法熟练，那就算了。

对于着急想入门的同学，可以在文章最后点击「阅读原文」查看我在知乎的一个回答「零基础如何学习 Web 安全？」

这个解答可以作为修炼基础的关键部分。

对于一名合格的黑客来说，绝不会限制自己的擅长领域，在我眼里的 Web2.0 黑客，不仅得具备 Web2.0 攻击的猥琐思想，还应该全方位了解渗透师的工作，让自己成为一名合格的渗透师，这个过程至少能精于一门语言，最终让自己具备足够的创造力。创造，而不是仅使用别人留下来的精华！
