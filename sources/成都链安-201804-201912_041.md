# 合作 | Keystore & Beosin成都链安正式达成战略共识

**合作 **

  

![](../Images/bd242a6f7c7cafae6c694257785c60e1.png)

  

**10月12 日，专注于提供企业级加密资产服务商的Keystore与Beosin成都链安正式宣布达成战略共识，开启合作关系。**

 

据悉，此番Keystore与Beosin成都链安所携手开展的战略性合作，是立足于双方对彼此业务的不断深入了解和互通，旨在进一步拓展双方业务的深度发展，同时构建起区块链生态的**『安全+信任』**基石。双方将着重在**智能合约安全审计、交易平台安全、安全威胁情报、资金安全保护、项目态势感知和安全风控、安全咨询和顾问、资产托管、企业网银和节点服务**等方面进行深度交流。

 

对于此次合作，Keystore方面表示，Beosin成都链安作为区块链安全领域的龙头企业，已**为全球多家链平台、交易所、钱包、智能合约等项目做出相关安全审计及部署业务**，Beosin成都链安也势必将为Keystore业务拓展带来更深远的影响。

 

而Beosin成都链安方面也表示，Keystore作为企业级加密资产服务商，在**安全数据存储、安全防护、数据隐私等维度所做出的成绩，亦是有目共睹的**。Beosin成都链安十分乐意携手Keystore，进一步为区块链领域保驾护航！

  

  

**What is Keystore?**

![](../Images/fd72ae7e0bec7c828a424fe0dffc8e45.png)

  

*   **Keystore是企业级加密资产服务商，提供全面的资产管理解决方案。**
    
      
    
*   Keystore以私钥的安全存储为核心，提供金融级信息安全防护和加密数据处理技术，和严格的信息安全人员编制及数据处理流程管理体系。
    
      
    
*   同时，系统内嵌智能财务和快捷支付模块，提供软硬件一体化支付 SaaS 及 API 接口服务、财务可视化报表、动态分析报告等服务。
    
      
    
*   此外，Keystore还提供了包括资产托管、交易经纪、节点服务以及加密资产聚合交易、量化交易等服务的安全架构，全方位保障资产安全。
    

  

**What is Beosin成都链安?**

![](../Images/827c545c4967f970626ed9eb51e4d9fb.png)

  

*   Beosin成都链安作为全球最早专门从事区块链安全的公司，由研究形式化验证技术、可信计算、移动端安全、内核安全等长达18年的电子科技大学杨霞、郭文生两位教授联合创立。
    
      
    
*   此外，**Beosin成都链安作为全球最早将形式化验证技术应用到区块链安全领域的团队，研发了全球领先的智能合约自动形式化验证平台VaaS；并基于此，建立了『一站式』区块链安全平台**，为区块链企业提供安全审计、资产追溯、隐私保护、安全咨询、威胁情报、安全防护等全方位的安全服务与支持。
    
      
    
*   Beosin成都链安所申请软件发明专利和著作权已余15项。
