# Beosin成都链安与 499Block达成战略合作

据官方消息称，**8月26日499Block全球第一大区块链女性社区与 Beosin成都链安达成战略合作。**

  

未来双方将在社区流量、项目推荐、资源共享、安全快讯、安全深度文章等方面进行合作，成都链安将用Beosin-安全舆情系统为499Block 提供7\*24小时安全新闻、漏洞快讯和威胁突发事件等各类舆情的发现与分析服务。

  

成都链安是全球最早专门从事区块链安全的公司，为客户提供安全咨询、安全审计、威胁情报、安全防护等全方位的区块链安全服务，已发布智能合约开发工具、基于形式化验证的一键式智能合约安全检测平台、态势感知平台、防火墙、链上资产溯源追踪系统、安全舆情系统等安全产品。

  

499Block凝聚了区块链行业最具影响力的女性从业者，联合世界顶级行业大咖一起定期举办线上线下交流活动。目前开设499小姐姐人物访谈，499加油站，499韩国站，499东南亚站等在线分享栏目，并迅速建立50个国际分叉群，覆盖全球区块链行业头部女性群体。
