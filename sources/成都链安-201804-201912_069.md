# Beosin成都链安与MXC平台达成安全战略合作

2019年8月20日，**MXC平台与Beosin成都链安达成重要合作。**  
Beosin成都链安将为MXC提供区块链安全服务，双方将在智能合约安全性审计，交易平台安全、安全威胁情报、资金安全保护、项目态势感知和安全风控、安全咨询和顾问、数字资产追溯和反洗钱等方面形成合作关系，共同促进行业生态安全建设。 MXC平台成立于2018年4月，总部位于新加坡，在全球拥有超过200万注册用户，日活最高超过20万用户，日交易量超过6亿美元。  
成都链安科技有限公司，成立于2018年3月，是全球最早专门从事区块链安全的公司，也是全球最早一批将形式化验证技术应用到区块链安全领域的公司。团队成员由从事信息安全长达10多年的海内外知名高校和实验室、具留学经历的教授、博士后、博士以及曾任职于阿里、华为等知名企业的精英组成。  
核心团队经过多年的技术积累，已经建立了“区块链安全开发、形式化安全验证到运行时安全监控与防护”三位一体的全生态安全产品生态。并且为区块链领域提供智能合约安全审计、区块链底层链平台安全检测、交易所安全、钱包安全、DApp渗透测试、资金溯源追踪和反洗钱服务等全方位的安全服务体系。  
公司已发布智能合约开发工具（Beosin-IDE）、基于形式化验证的一键式智能合约安全检测平台(Beosin-VaaS)、区块链应用运行时安全检测与防护平台（Beosin-Eagle Eye)、EOS防火墙（Beosin-EOSFW)、链上资产溯源追踪系统和安全舆情系统等安全产品。   
关于MXC平台

  

![](../Images/2a5a09f4dd9062e5611c5bede15021f4.png)  
MXC平台成立于2018年4月，总部位于新加坡，在全球拥有超过200万注册用户，日活最高超过20万用户，日交易量超过6亿美元。MXC平台以用户为导向，深度听取社区的声音。目前已获了得资本、创世资本、FBG、LINK VC、水木金融科技等机构及蔡文胜个人战略投资。并与节点资本、科银资本、JRR Crypto、共识实验室、加密愿景等多家投资机构达成战略合作。  
  
MXC平台提供币币交易，OTC交易，合约交易，交易挖矿，理财超市等版块。
