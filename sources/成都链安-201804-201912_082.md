# McAfee“不可破解”钱包Bitfi又被黑，安全研究员坐等赏金

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2NzUxMTM0Nw==&mid=2247484494&idx=3&sn=f3a822864568cedbeba510b861947794&chksm=fc9d5412cbeadd04ed366ac3c5ee04f0f84a5d173b487dd69846a442cd5ca532da5308b41ce2&scene=126&sessionid=1681369545#rd](http://mp.weixin.qq.com/s?__biz=MzU2NzUxMTM0Nw==&mid=2247484494&idx=3&sn=f3a822864568cedbeba510b861947794&chksm=fc9d5412cbeadd04ed366ac3c5ee04f0f84a5d173b487dd69846a442cd5ca532da5308b41ce2&scene=126&sessionid=1681369545#rd)

CCN 8月13日消息，McAfee硬钱包Bitfi自发布悬赏以来第二次被某安全研究员破解。

  

![](../Images/8d4f6da517e636f27302cf0be41356f8.png)

  

在硬件钱包Bitfi网站的主页上，公司董事长约翰·迈考菲的这几句话非常醒目：“世界上第一个坚不可摧的加密货币和数字资产存储。”  

  

![](../Images/85105c8916e91dc33e27da87072a5aab.png)

  

但是硬件钱包的安全无数次受到严重威胁。最近，根据Hard Fork报道，渗透测试和网络安全公司Pen Test Partners的安全研究员可以用Bitfi发送已签名的交易，这满足了获取硬件钱包奖金的一个重要条件。

  

“这是使用MitMed Bitfi进行的交易，我们将助记词和私钥发送到了一个远程的服务器上，”Pen Test Partner公司的安全顾问安德鲁·蒂尔尼在推特上说道，“看样子，我可以获得第二个漏洞赏金了。”

  

  

**三个条件**

  

  

与Bitfi公司第一次25万美元的奖金相比，这第二次仅仅10万美元的奖金略显微薄。在第二次的悬赏中，Bitfi要求黑客达到三个条件：即安全研究人员能够修改硬件钱包的固件并将其连接至Bitfi的仪表板，最后，在助记词和私钥被发送至第三方时Bitfi的仪表板仍旧显示运行正常。

  

佩尔·蒂尔尼称，这个团队能够大幅修改固件并且最终能够拦截硬件设备和钱包之间的通讯。为了证明这个设备仍然与控制面板相连接且顺畅运行，研究人员展示了屏幕上的信息。

  

  

**团队的努力**

  

  

据蒂尔尼称，黑进硬件钱包包括多位人士和团体的协作分工。

  

![](../Images/c67098c2fbd436d6fd2d983d7a492ae6.png)

  

  

据CCN最近的报道，在本月初，硬件钱包被一名信息安全专家攻破（即获得了管理和访问权限），他随后发现了一系列具有GPS和WIFI追踪者的应用程序。人们认为这是一个严重的安全问题，因为追踪程序与多个网络服务器相连接，其中还包括中国搜索引擎巨头——百度。

  

不到十天之后，一名15岁的黑客神童萨利姆·拉希德在这个设备上安装了毁灭战士游戏应用程序并成功运行。这引起人们对防护薄弱或者没有防篡改保护设备的担忧，恶意攻击者能轻易地安装有害程序使其便于操纵。除此之外，人们也担心，有了底层访问权限后，黑客可以轻松地重新设定这种设备。

  

对于整个事件，Bitfi公司的回应有着一系列的失误并带来了不好的公众影响。最后，在内华达州拉斯维加斯市举办的美国黑帽安全技术大会中，该公司获得“安全应对机制最差奖”。

  

成都链安科技团队建议，基于此钱包内核进行形式化验证可以增强关键权限的安全等级，进而有效的降低此类情况发生的概率，我们将继续跟进此事件。

  

VaaS（Verification as a Service）是成都链安科技有限公司自主研发的区块链形式化验证平台，采用了多种形式化验证方法和数学模型，为智能合约和区块链应用提供“军事级”的形式化验证服务，具有验证效率高、自动化程度高、人工参与度低、易于使用、支持多个合约开发语言、支持大容量区块链底层平台的形式化验证等优点。

  

VaaS平台的“一键式”形式化验证工具，可精确定位到有风险的代码位置和风险原因，有效的验证智能合约或区块链应用的常规安全漏洞、安全属性和功能正确性，从而显著提高其安全等级。相关研究成果已申请软件发明专利5项。

  

2018年5月20日，工信部发布了《2018中国区块链产业白皮书》，在“区块链安全保护”章节中，详细介绍了成都链安科技有限公司研发的VaaS形式化验证平台，VaaS还荣获了“OKEx 最佳安全审计合作伙伴奖”。未来，VaaS平台将逐步支持其它主流区块链平台的形式化验证工作，将为更多的区块链平台提供形式化验证服务。
