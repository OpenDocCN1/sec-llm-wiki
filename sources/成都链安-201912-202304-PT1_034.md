# 【喜讯】成都链安上榜“2022 年成都市新经济梯度培育企业-‘双百企业’名单”

近日，2022年成都市新经济梯度培育企业建议名单公示完毕，******成都链安作为全球头部以及成都本土的优秀区块链安全企业上榜“2022 年成都市新经济梯度培育企业-‘双百企业’名单”。******

  

![](../Images/c70a161ca01b06a3abcfbaaf24afab38.png)

根据《2022年成都市新经济梯度培育企业建议名单》，******本次共有1130家企业入选，包含30家示范企业、100家双百企业，以及1000家种子企业******，涵盖了生物医药大健康、卫星互联网、新型显示、电子信息、人工智能大数据等多个成都优势产业赛道，不仅更加全面，涵盖更多中小微企业，并且更加聚焦“专精特新”领域。

  

根据成都市政府印发的《成都市新经济企业梯度培育若干政策措施》，成都市新经济梯度培育企业是指聚焦数字、智慧、绿色、安全等重点发展领域，以新技术为核心驱动，具有创新能力强、成长速度快、产业模式新、发展潜力大等特征的企业。******根据企业的技术领先、营收规模、融资能力、人才团队、绿色认证等情况，建立新经济种子企业、新经济双百企业、新经济示范企业3个梯度的培育库。******分层分级开展精准培育和服务，打造一批产品卓越、品牌卓著、创新领先、治理现代的一流企业集群。

  

成都链安作为一家致力于区块链安全生态建设的全球领先区块链安全公司，多年来坚持以技术创新引领行业发展，致力于搭建起我国“自主创新、自主可控”的区块链安全技术和保障体系，现已申请软件发明专利和著作权40余项。

  

自成立以来一直致力于区块链安全生态建设，已获前海母基金、联想创投、复星高科、成创投、任子行等知名机构的多轮投资。并已与工信部、中国信通院、网信办、公安等执法监管机构，以及包括蚂蚁链、腾讯区块链、微众银行、万向区块链、布比等国内外100多家区块链头部企业建立了深度合作关系。是工信部“网络安全技术应用试点示范项目”单位、CNVD国家区块链安全漏洞平台技术支持单位、中国信通院区块链安全检测的主要技术合作单位、中央网信办“国家区块链创新应用试点”参与单位、国家互联网应急中心“区块链安全技术检测中心”的主要技术合作单位、四川省区块链安全工程技术研究中心依托单位，参与了多项国家级区块链安全技术标准和白皮书的撰写，承担了多项国家级、省部级项目。

  

基于公司实力和行业认可，成都链安获得了、产业区块链企业100强、四川省区块链优秀企业、中国区块链企业百强榜等诸多荣誉。

  

由衷感谢成都市新经济发展委员会对成都链安的高度认可，本次上榜“2022 年成都市新经济梯度培育企业-‘双百企业’名单”也是对成都链安的激励和鞭策，未来成都链安将继续发挥自身优势，为全球区块链安全生态继续保驾护航。
