# **  网信办：积极利用区块链等数字技术创新创业**

  

  

# 中央网络安全和信息化委员会近日印发《提升全民数字素养与技能行动纲要》，对提升全民数字素养与技能作出安排部署。《纲要》提出，引导支持新兴职业群体，积极利用5G、人工智能、虚拟现实、大数据、区块链等数字技术创新创业。

  

  

**02**

  

  

  

# **教育部：以区块链等新技术赋能中文教学不断创新模式**

  

  
教育部官方网站近期发布《关于政协第十三届全国委员会第四次会议第2624号（教育类091号）提案答复的函》，其中指出以大数据、云计算、区块链、5G网络、人工智能等为代表的新技术，赋能中文教学不断创新模式、优化业态，为国际中文教育创新发展奠定了坚实基础。  

  

**03**

  

  

  

# **海南：公安机关应当运用区块链等现代信息技术提高执法能力和效率**

  

  
海南省人民政府近日审议通过《海南省公安机关警务辅助人员管理规定》，自2022年1月1日起施行。《规定》表示，海南省和市、县、自治县人民政府公安机关应当运用人工智能、大数据、区块链、移动互联网等现代信息技术，优化工作岗位和流程，提高执法能力和效率，合理使用辅警。（海南省公安厅官网）  

  

**04**

  

  

  

# ** 云南36个区块链项目完成备案**

  

  
国家互联网信息办公室近日发布了第六批共202个境内区块链信息服务名称及备案编号，其中云南省共有13家企业的14个项目备案成功。至此，全省累计有36个项目完成区块链信息服务备案。截至目前，已有超过40家区块链技术服务企业入驻云南省区块链中心，100余家机构和企业加入云南省区块链产业联盟。云南省区块链中心表示，下一步将持续引进和培育“专精特新”区块链企业，探索利用区块链等技术，更好地服务实体经济、赋能产业，打造良好的区块链产业生态圈，加快推动区块链技术和产业创新发展。（昆明日报）  

  

**05**

  

  

  

# **北京市地方金融监管局：培育区块链、人工智能等领域的全球标杆企业**

  

  
北京市地方金融监管局印发《北京市关于促进数字贸易高质量发展的若干措施》，其中提到提升数字贸易核心产业竞争力，培育大数据、云计算、物联网、移动互联网、高端软件研发、卫星互联网、工业互联网、区块链、人工智能等领域的全球标杆企业。  

  

**06**

  

  

  

** 湖北计划到2025年建成区块链服务网络湖北省主干网**

  

  
湖北省政府日前印发《关于全面推进数字湖北建设的意见》， 文件指出，到2025年，建成13万个5G基站，行政村5G网络通达比例达到80%，一体化大数据中心体系日益完善，建成区块链服务网络湖北省主干网。（极目新闻）  

  

**07**

  

  

  

# **重庆成跨境金融区块链平台应用场景落地最多省市之一**

  

  
截至2021年9月末，重庆外汇管理部全辖共计便利跨境贸易融资和结算223亿美元。重庆已成为跨境金融区块链平台应用场景落地最多的省市之一。跨境金融区块链服务平台，是国家外汇管理局牵头建设、部委层面首个在国家网信办备案的区块链平台。  

  

**08**

  

  

  

# **  南京市信息中心启动政务云区块链平台建设工作**

  

  
日前，南京市信息中心启动政务云区块链平台建设工作，为实现全市政务区块链“一盘棋”打好“地基”，相关采购工作目前已经启动。  

  

**09**

  

  

  

**中宣部副部长庄荣文：提升人工智能、5G、区块链等安全防护能力**

  

  
中央宣传部副部长，中央网信办主任、国家网信办主任庄荣文在人民日报发表《营造良好数字生态》文章指出，提升网络安全防护能力。防范应对数字新技术新应用安全风险，密切跟踪发展动态，提升人工智能、5G、区块链、工业互联网、车联网等安全防护能力。

  

**10**

  

  

  

# **建设银行与九家机构共同签署大宗商品区块链平台合作协议**

  

  
在第四届进博会中央企业交易团签约活动上，建设银行与中化能源、中国联油、麦格理银行、中远海能、中国银行、沙特阿美能源基金、招商局能源运输、三井物产和万向区块链等九家机构共同签署合资协议，成立合资公司TradeGo Pte. Ltd.（大宗易行），搭建基于区块链技术的大宗商品国际贸易数字化服务平台。  

  

**11**

  

  

  

# **  “区块链赋能乡村振兴” 闭门研讨会：区块链将会深度应用于乡村振兴**

  

  
近日，“区块链赋能乡村振兴” 闭门研讨会在清华大学互联网产业研究院成功召开。本次研讨会汇集40余位来自政府、高校等相关行业的专家学者共同探讨区块链助力乡村经济振兴，赋能农业走向数字化的路径与前景，认为未来区块链将会更深度的应用于“乡村振兴”中。（光明网）  

  

**12**

  

  

  

**潍坊科技学院创建“农蔬区块链”重点实验室**

  

  
潍坊科技学院依托农蔬区块链建设项目，组建“农蔬区块链”团队，与贵州大学联合创建“农蔬区块链”重点实验室，获批建设潍坊市重点实验室。此前农业农村部信息中心联合中国电信集团有限公司、山东省农业农村厅、潍坊市人民政府及坊子区委区政府启动“区块链+韭菜”试点项目，标志着“区块链+”在农产品质量安全智慧管控上的应用迈出了开创性的关键一步。（大众日报）  

  

**13**

  

  

  

# **  深圳福田建立基于区块链的“疫苗安全一网监管平台”**

  

  
深圳市福田区政务服务数据管理局日前透露，福田区充分运用数字技术打造了专门的“疫苗安全一网监管平台”，利用区块链技术为疫苗从生产到完成接种全过程数据上链、赋码，实现一码可追踪疫苗形迹，确保疫苗从“产”到”用”各环节数据不可篡改、有迹可循，有效控制疫苗安全隐患的发生。（人民网）  

  

**14**

  

  

  

# **发改委国家信息中心单志广：区块链在不动产领域大有前途**

  

  
2021不动产数字化峰会上，发改委国家信息中心信息化和产业发展部主任单志广在《“十四五”数字化发展与智慧化升级新形势》的主旨演讲中表示，数字化要实现从“互联网+”到“智慧+”的转型，利用“互联网+”带来的流量驱动的效应，“人工智能+”带来的算法驱动效应，还有“区块链+”带来的可信驱动，这是未来不动产数字化转型最依靠的路径和技术路线，特别是区块链在未来的不动产领域里有非常大的前途。（《科创板日报》）

  

**15**

  

  

  

# **  报告：区块链在金融行业应用专利明显高于其他行业**

  

  
在2021年首届中国数字金融峰会暨区块链创新论坛上，智慧芽创新研究中心联合科创板日报发布《2021全球区块链及中国区块链金融专利创新及科创力报告》（以下简称报告）。报告数据显示，截至2021年10月31日，全球区块链专利申请量合计约5.5万件，中国是目前在该领域专利申请数量最多的国家，约3.3万件，占比约63.2%，但专利质量仍有发展空间。报告指出，区块链技术在金融行业的应用专利明显高于其他行业。全球区块链金融专利申请数量超过2775件，中国申请数量超过1750件，排名第一。（中国金融新闻网）  

  

**16**

  

  

  

**  网信办发布第六批境内区块链信息服务备案清单**

  

  
据官方公告，根据《区块链信息服务管理规定》（以下简称《管理规定》），国家互联网信息办公室依法依规组织开展备案审核工作，现发布第六批共202个境内区块链信息服务名称及备案编号。  

  

**17**

  

  

  

**  联合公民组织在第26届联合国气候变化大会上发起区块链倡议**

  

  
在苏格兰格拉斯哥举行的COP26新闻发布会上，一群来自技术环境领域的专家向世界各地的公民讲述了如何用区块链技术改善气候行动的协调和支持。GloCha联合公民行动（UCO）气候赋权组织作为一个位于奥地利克拉根福的基于区块链的准国际组织在COP26上启动。它现在将寻求利用区块链技术与联合国可持续发展目标保持一致，推进气候变化目标。  

  

**18**

  

  

  

** 人民日报：广目卫星未来将结合区块链等技术为可持续发展作出更大贡献**

  

  
《人民日报》（2021年11月10日14 版）刊文《观测效率更高 数据全球共享》，文章指出，我国日前在太原卫星发射中心用长征六号运载火箭成功发射广目地球科学卫星。未来，广目卫星将获取海量数据，结合大数据、人工智能、区块链等技术，为可持续发展作出更大贡献。  

  

**19**

  

  

  

**杭州市中级人民法院：以区块链技术为基础探索长三角一体化金融治理平台**

  

  
上海金融法院与南京市中级人民法院、杭州市中级人民法院、合肥市中级人民法院、苏州市中级人民法院在线举行《长三角区域金融司法合作协议》签署仪式，杭州中院表示将以区块链技术为基础，与合作法院一同探索长三角一体化金融治理平台。  

  

**20**

  

  

  

**  费城推出“市政府区块链”项目**

  

  
费城的首席创新官Mark Wheeler周一宣布一项将区块链技术引入市政领域的倡议，邀请区块链和智能合约领域的工作人员与该项目工作人员联系，以了解加密技术如何在市政领域发挥作用。（State Scoop）
