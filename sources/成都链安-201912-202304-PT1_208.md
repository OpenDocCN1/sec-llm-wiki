# **杭州市中级人民法院：以区块链技术为基础探索长三角一体化金融治理平台**

  

  

# 11月4日下午，上海金融法院与南京市中级人民法院（以下简称南京中院）、杭州市中级人民法院、合肥市中级人民法院、苏州市中级人民法院在线举行《长三角区域金融司法合作协议》签署仪式，杭州中院表示将以区块链技术为基础，与合作法院一同探索长三角一体化金融治理平台。（证券时报）

# **市场监管总局田世宏：区块链标准化工作对于支撑区块链技术与管理创新等具有重大意义**

  

  
近日，第一届全国区块链和分布式记账技术标准化技术委员会（以下简称“区块链标委会”）成立大会暨第一次全体委员会议采取线上线下结合的方式在北京召开。中钞区块链技术研究院院长张一锋作为首届委员出席会议。会上，市场监管总局党组成员、副局长田世宏指出，区块链标准化工作对于支撑区块链技术与管理创新、推动数字经济发展、建设网络强国具有重大意义。区块链标准化工作要贯彻落实好《国家标准化发展纲要》，要抓好顶层设计、重点攻关、实施应用及国际突破等工作。

# **山东省首家“区块链”公证处入驻烟台自贸片区**

  

  
近日，山东省首家“区块链”公证处――山东省烟台市蓝海公证处正式揭牌并入驻山东自贸试验区烟台片区，成为复制推广国务院改革试点经验、打造自贸试验区法治营商环境的又一生动实践。（山东自贸试验区烟台片区）

# **北京市人社局：区块链工程技术人员年薪中位值超48万元**

  

  
日前，北京市人力资源和社会保障局发布《2021年北京市人力资源市场薪酬大数据报告》，报告基于2020年度相关调研数据，按照行业、职位、群体等维度对薪酬数据进行了分析，并首次发布了30个新职业的薪酬水平。在新职业薪酬排行榜中，最高的为区块链工程技术人员，薪酬中位值达487106元，紧随其后的为信息安全测试员，薪酬中位值为323810元。

# **观点：元宇宙是整合区块链等多种新技术产生的新型互联网应用和社会形态**

  

  
新华社刊文《元宇宙到底是个啥，会催生一个怎样的“平行世界”？》。清华大学新闻与传播学院教授沈阳认为，元宇宙是整合多种新技术而产生的新型虚实相融的互联网应用和社会形态，它基于扩展现实技术提供沉浸式体验，以及数字孪生技术生成现实世界的镜像，通过区块链技术搭建经济体系，将虚拟世界与现实世界在经济系统、社交系统、身份系统上密切融合，并且允许每个用户进行内容生产和编辑。

**中央美术学院启动“全球区块链艺术与管理实验室”**

  

  
中央美术学院中法艺术与设计管理学院与观唐文化启动“全球区块链艺术与管理实验室” ，将结合中法学院在艺术与设计管理方面的学科优势，聚焦当下区块链艺术的创作、展示、研究与交易领域，在科技、艺术与管理的视野下持续关注区块链艺术的发展及研究，并在中央美术学院开设全球第一个区块链艺术与管理专业方向。未来，实验室将开展多项关于区块链艺术的讲座、研讨、出版以及教学活动，使区块链艺术与管理成为中法学院艺术与科技板块的重要办学特色之一。（中国新闻网）

# **武汉城市大脑利用区块链技术实现城市资源整合**

  

  
11月3日至4日，以“数实融合·绽放新机”为主题的2021腾讯数字生态大会在武汉举行。据大会现场举行的武汉智慧城市成果发布仪式透露，武汉目前已搭建起以“武汉城市大脑+六大智慧应用+二十多个应用场景+市民码标准”为主体的智慧城市架构。武汉城市大脑是武汉智慧城市的基石，由“数据中枢、人工智能中枢、应用中枢、区块链技术枢”四大部分所组成。作为武汉市数据资源和公共服务能力的承载平台，武汉城市大脑实现了整合城市资源、感知城市运行、智能辅助研判和应用建设支撑等功能。（每日新报）  

  

**08**

  

  

  

# **区块链促进气候基金会在COP26上推出BITMO平台**

  

  
11月4日，在苏格兰格拉斯哥举行的COP26会议上，区块链气候基金会将推出BITMO平台，这是一个帮助各国实现其气候目标的创新工具。BITMO平台允许《巴黎协定》的签署方在以太坊区块链上作为NFT发行和交换碳信用。当各国在COP26会议上进行谈判时，BITMO平台已经准备好启动，可以根据《巴黎协定》快速启动国际碳交易，以推进《巴黎协定》第6条，并利用区块链技术创建一个有效、高效和及时的全球碳市场。（PR Newswire）  

  

**09**

  

  

  

**深圳中行落地首批贸易金融区块链平台二期项目跨平台融资业务**

  

  
为提升贸易融资便利化水平，助推粤港澳大湾区互联互通，作为跨平台项目的首批合作银行之一，中国银行深圳市分行于10月27日成功联动中国银行（香港）完成首笔中国人民银行贸易金融区块链平台（简称“贸金区块链平台”）二期项目试点，落地跨平台、跨境数据互通下的首批进口贸易融资业务，进一步拓宽了深港两地贸易金融区块链平台互联互通的深度与广度。（证券时报网）

  

**10**

  

  

  

# **汇丰完成内地与香港区块链平台二期对接首批试点交易**

  

  
汇丰宣布，在内地贸易金融区块链平台（“贸金平台”）和香港贸易联动平台（“贸易联动”）完成第二期对接项目后，已在内地和香港两地分别作为首批试点银行，成功为两地企业客户通过跨平台互联互通完成了首批三笔跨境贸易融资交易。据悉，“贸金平台”与“贸易联动”近日完成了第二期对接项目，正式进入试运行阶段，应用场景从一期的内地出口、香港进口进一步扩展至涵盖内地进口、香港出口，进一步加强两地贸易金融区块链平台的互联互通。（北京青年报）

# **湖北省运用区块链等信息技术手段推进交易采购平台信息化建设**

  

  
近期，湖北省交易（采购）中心发布《湖北省公共资源交易和政府采购事业发展“十四五”规划》，《规划》锚定“全省一网”目标，以“数字湖北”建设为契机，加快“数字赋能”，充分运用现代云计算、大数据、区块链、AI智能化等信息技术手段，大力推进省、市、县一体化的交易采购平台信息化建设。（中国经济导报）

**云南投资993万元建食品安全信息区块链追溯项目**

  

  
11月2日，云南省发展和改革委员会披露的信息显示，省发展改革委已原则同意《关于云南省重点食品（产品）安全信息区块链追溯项目可行性研究报告》，该项目估算总投资993万元。《报告》中的项目建设内容主要为“一个中心、一个体系、三大应用、一套基础设施”。一个体系，即制定云南省食品（产品）安全信息区块链追溯平台地方标准体系。三大应用，即建设全省食品（产品）安全信息区块链追溯平台、云南省食品安全信息网（包含食安云南门户网站、企业小程序端应用、业务协同系统、食安委公文交换系统、农村自办宴席监管系统等多个应用）、网络外卖智能化监管应用。（昆明日报）

# **证券日报：区块链技术将使数字底座安全可信**

  

  
《证券日报》刊发文章《数字化转型浪潮滚滚，区块链造就可信“数字经济底座”》，文章指出：多位业内人士认为，以区块链、隐私计算为代表的技术正在为人类协作建立信任基础、确保数据安全有序流动提供了“革命性”的工具，这些技术形成的产业本身也是可信经济的重要组成部分。伴随相关标准化的推进，这些技术还将形成更大合力，助力可信经济释放更大价值。

# **上海高院：探索应用“区块链”等技术，运用司法科技高效化解金融科技纠纷**

  

  
最高法召开新闻发布会，发布《人民法院服务和保障长三角一体化发展司法报告》暨典型案例，并回答记者提问。上海市高院副院长陈昶答记者问时说，上海法院还探索应用“区块链”等技术，加强电子数据在司法审判中的深度应用，运用司法科技高效化解金融科技纠纷，积极推动金融案件全流程网上办案体系建设，进一步提升审判质效，得到社会广泛认可。（红星新闻）

# **德克萨斯州副州长Dan Patrick任命区块链事务工作组成员**

  

  
德克萨斯州副州长Dan Patrick宣布任命Sen. Angela Paxton、Claire Barber、Christopher Calicott、Patrick Hatfield、Jason Kelley和Robert Villaseñor加入区块链事务工作组。Dan Patrick表示“要使德克萨斯州继续成为商业的温床，我们必须走在创新的最前沿。我相信区块链事务工作组将为德克萨斯州在未来几十年成为区块链重量级角色勾勒出一条清晰的道路。”区块链事务工作组是在第87届议会期间由1576号众议院法案创建的，旨在为德克萨斯州区块链行业的扩张制定总体规划，并推荐与区块链技术相关的政策和州投资。（星球日报）  

  

**16**

  

  

  

**国资委：运用区块链、大数据等新一代信息技术深化法治央企建设**

  

  
国资委印发《关于进一步深化法治央企建设的意见》，其中提出，运用区块链、大数据、云计算、人工智能等新一代信息技术，推动法务管理从信息化向数字化升级，探索智能化应用场景，有效提高管理效能。深化合同管理、案件管理、合规管理等重点领域信息化、数字化建设，将法律审核嵌入重大决策、重要业务管理流程，通过大数据等手段，实现法律合规风险在线识别、分析、评估、防控。（金十）  

  

**17**

  

  

  

**最高人民法院：积极推进区块链等现代科技在司法领域的深度应用**

  

  
最高人民法院近日正式发布《最高人民法院关于加强新时代知识产权审判工作为知识产权强国建设提供有力司法服务和保障的意见》。《意见》指出，加强智慧法院建设，提升知识产权审判信息化水平。扎实推进信息技术与法治建设融合促进，积极推进互联网、人工智能、大数据、云计算、区块链、5G等现代科技在司法领域的深度应用，全面加强智慧审判、智慧执行、智慧服务、智慧管理，实现信息化建设与知识产权审判深度融合。适应信息化时代发展，探索更加成熟定型的在线诉讼新模式和在线调解规则，积极推进跨区域知识产权远程诉讼平台建设，加强司法大数据充分汇集、智能分析和有效利用。  

  

**18**

  

  

  

**经济日报：随着区块链技术的应用，短视频平台应及时制止侵权行为**

  

  
经济日报刊文《短视频版权问题“短视”不得》。文章表示，保护版权，平台应该主动作为。一方面，加大对正版内容和原创内容的采购和生产力度，努力实现规范化、正版化的运营模式；另一方面，运用先进技术手段，做到主动审核，积极履行平台主体责任和通知删除义务。技术缺陷不能成为监管缺位的借口。过去，很多平台声称短视频用户规模大、技术更迭快，给监管带来较大困难。随着区块链、人工智能等先进技术的应用，对于明显侵权行为，平台将有可能做到及时制止，精准打击。

**报告：全国已有超过33个省市出台区块链专项政策**

  

  
据不完全统计，截至目前，全国已有超过33个省市出台区块链专项政策，除了财政奖励、房租减免、人才补贴等支持措施，不少地方都在政策文件中明确鼓励成立区块链专项基金。统计的33个地方区块链专项政策文件中，有16个地方明确提出由政府国有资本主导设立区块链产业投资基金或子基金，其中，海南、广州、娄底、苏州的文件中明确（子）基金金额为10亿元或不低于10亿元。另外，有4个地区政府表示利用现有政府引导基金对区块链企业提供支持，9个地区政府则鼓励民间资本设立区块链产业基金，政府给予相应支持。（盘古星链）

**全国首个区块链知识产权保护工作站揭牌成立**

  

  
10月29日下午，全国首个区块链知识产权保护工作站在深圳市信息服务业区块链协会揭牌成立。深圳市市场监督管理局知识产权保护处处长曾尧东表示，深圳市信息服务业区块链协会知识产权保护工作站的成立，是深圳市进一步完善知识产权保护社会治理网络的重要一环，希望协会充分发挥工作站的平台作用，落实并推进区块链知识产权保护工作，提升区块链行业知识产权保护意识，完善知识产权维权与保护体系。（深圳市信息服务业区块链协会）
