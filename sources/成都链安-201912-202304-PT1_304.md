# 乌鲁木齐市政府及华西证券领导一行莅临成都链安调研考察

2021年3月26日下午，**乌鲁木齐市政府及华西证券领导一行**前往成都天府软件园进行实地调研考察。作为**专门从事“区块链安全”领域**的成都本土标杆企业——**成都链安科技有限公司**（以下简称“成都链安”）热烈接待了乌鲁木齐市政府及华西证券领导一行。

 

本次领导一行共计12人，莅临成都链安开展调研考察工作。成都链安创始人&CTO**郭文生教授**、成都链安副总裁&战略发展总监**曾薇女士**热情接待了来访领导一行，并陪同参观以及组织座谈。

 

来访领导一行先后参观了成都链安的安全实验室、七星研究室、研发中心以及各办公区域，通过**实地考察、交谈询问、技术座谈**等方式，对成都链安当下的发展情况作出了全面和深入的了解。

![](../Images/785b0eb4618a8834a243da366ee117f5.png)

  

在企业荣誉文化廊，成都链安副总裁&战略发展总监**曾薇女士**向来访领导一行详细介绍了成都链安**“让区块链生态更安全”**的使命和愿景，致力于为全球区块链生态的安全发展保驾护航。同时，曾薇女士还针对成都链安的**行业地位、战略实力、发展历史、荣誉资质、合作伙伴**等各个维度开展介绍。

 

她提到，在各政企领导的大力支持下，成都链安有幸取得了**诸多行业荣誉和资质认证**。目前，成都链安作为工信部“网络安全技术应用试点示范项目”、中国信通院区块链安全检测的主要技术合作单位、CNVD国家区块链安全漏洞平台的主要技术支持单位、国家互联网应急中心的“区块链安全技术检测中心”的主要技术合作单位、四川省区块链安全工程技术研究中心（筹）运营单位、成都区块链安全工程技术研究中心的依托单位、成都高新区区块链公共技术平台等，已**参与到多项国家级区块链安全标准和白皮书的撰写**。

![](../Images/b3e26f503d975ed14f95e15077a6699e.png)

  

随后，领导一行与郭文生教授、曾薇女士组织座谈交流。会上，**郭文生教授**向乌鲁木齐市政府及华西证券领导一行莅临成都链安调研考察表示欢迎和感谢，并集中汇报了成都链安自主打造的**全生命周期安全解决方案——“链必安（Beosin）一站式区块链安全服务平台”**，获得了领导一行的高度关注和一致好评。

 

调研考察期间，乌鲁木齐市政府及华西证券领导一行对成都链安在“区块链安全”领域所取得的成绩给予了**充分肯定和高度赞扬**，并表示未来将**持续关注**成都链安的发展，以推动区块链安全领域的有序发展。
