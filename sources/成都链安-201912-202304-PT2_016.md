# 成都链安分别牵头承担并参与合作两项科技部国家重点研发计划项目课题

**引言**

日前，为落实《国家中长期科学和技术发展规划纲要（2006-2020年）》《2006-2020年国家信息化发展战略》提出的任务，**科技部国家重点研发计划**启动实施。**成都链安科技有限公司**（简称：成都链安）联合各事业单位及知名高校，分别参与到**两项**科技部国家重点研发计划项目课题的立项工作当中。

作为其中一项项目课题的**牵头承担单位**，成都链安成功协调组织该项目课题的顺利实施；同时，作为另一项项目课题的**合作单位**，成都链安协助依托单位完成该项目的各项工作开展。

 

值得一提的是，科技部国家重点研发计划是针对事关国计民生的重大社会公益性研究，以及事关产业核心竞争力、整体自主创新能力和国家安全的战略性、基础性、前瞻性重大科学问题、重大共性关键技术和产品，为国民经济和社会发展主要领域提供持续性的支撑和引领，有利于突破国民经济和社会发展主要领域的技术瓶颈。

 

此次获批的两项项目课题重点关注**区块链安全防护**和**公有链监管需求**。分别作为两项项目课题的**牵头承担单位和合作单位**，成都链安将基于区块链安全形式化验证技术、数字货币反洗钱与追踪溯源等前沿技术，开展面向区块链（公有链、联盟链）的安全检测、安全防护和安全漏洞挖掘等技术研究，实现对区块链系统全方位、全生命周期的安全监管，建设具备区块链违法犯罪活动智能识别和追踪溯源调查能力的区块链监管平台。

  

以1024重要讲话**“要把区块链技术作为核心技术自主创新重要突破口”**作为指导方针，深度贯彻科技部国家重点研发计划的相关要求，成都链安将兼顾区块链系统的**安全防护与安全监管**，不断打造区块链安全监管技术和安全保障体系，进一步探索面向公有链、联盟链的各项技术研究，以推动我国区块链产业发展脱虚向实、规范合规，搭建起我国**“自主创新、自主可控”**的区块链安全技术和保障体系。
