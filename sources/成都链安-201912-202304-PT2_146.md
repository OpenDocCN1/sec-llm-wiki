# Consensus Cell Network & 成都链安正式达成战略共识

3月25日，新一代全球去中心化自治组织Consensus Cell Network与全球领先的区块链安全公司成都链安正式达成战略共识，宣布携手开启合作。**成都链安对Consensus Cell Network旗下Cell Wallet完成初步安全审计。至此，双方将专注于加强区块链生态的安全建设，持续为区块链事业保驾护航。**

 

此番，Consensus Cell Network与成都链安达成战略共识，基于对双方业务的不断加深和互通，旨在进一步地拓宽双方业务的深度布局，以**高效、友好、安全**为核心驱动力，推动区块链生态加速与实际应用集合发展。双方将着重在**智能合约审计、加密资产钱包审计、资产安全保护、态势感知和安全风控、安全咨询和顾问**等方面开展深度合作。

 

关于本次合作行为，Consensus Cell Network方面认为，**成都链安作为全球最早专门从事区块链安全的公司**，通过不断革新和发展，已成为了**全球领先的区块链安全公司**，成都链安过硬的技术实力和优质的产品服务，必将协助Consensus Cell Network推动长远愿景的实现。

 

成都链安方面则表示，将不遗余力地为Consensus Cell Network提供专业和全面的安全解决方案支持，以**Beosin『一站式』区块链安全平台的各项安全服务和安全产品**，助力Consensus Cell Network形成一体的区块链综合生态网络，推动传统互联网加速迈向价值互联网时代。

**关于Consensus Cell Network**

  
  
![](../Images/ce33593b82bc99d3f66faef7dafbf912.png)

**Consensus Cell Network是由开发者和用户共同赋能的，集技术研究、应用开发、风险投资、企业服务、教育传媒、公益慈善六大板块为一体的区块链综合生态网络。**

  

Consensus Cell Network致力于区块链技术探索、应用研究与人才培养，以人类愿景为驱动力，提升区块链应用的普及速度和社会对区块链的认知水平，推动**传统互联网加速迈向价值互联网时代**。在应用层面，Consensus Cell Network将以去信任化、透明化的智能协议重塑传统应用场景，在去中心化金融、社区、游戏等垂直领域给用户带来全新体验。

  

**关于成都链安**

  
  
![](../Images/7e91ed115151d42c29313c3b820bb7dc.png)

**成都链安科技有限公司，全球领先的区块链安全公司，成立于2018年3月，致力于区块链安全生态建设，总部位于成都。**公司已获前海母基金、联想创投、复星高科、成创投、分布式资本等知名机构的多轮投资。

  

成都链安也是**最早将形式化验证技术应用到区块链安全领域**的公司，研发了全球领先的智能合约自动形式化验证平台VaaS，并基于此，建立了**Beosin『一站式』区块链安全平台**，为区块链企业提供安全审计、虚拟资产追溯与AML反洗钱、隐私保护、威胁情报、安全防护、安全咨询等全方位的安全服务与支持。

  

成都链安以**『让区块链生态更安全』**为使命，以**『成为全球第一的区块链安全公司』**为愿景，不断打造区块链安全颠覆性和核心技术，为全球区块链企业的安全保驾护航。
