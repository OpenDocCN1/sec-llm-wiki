# 内容科技·产业创新 | 成都链安荣获首届人民网内容科技创新创业大赛全国总决赛『创业人气奖』

2020年1月5日，由**人民网、厦门市人民政府**指导，人民网创业投资有限公司、厦门市工业和信息化局、厦门市湖里区人民政府主办，厦门市湖里区工信局协办的**『首届人民网内容科技创新创业大赛总决赛暨颁奖盛典』**盛大启幕。

![](../Images/808ea1fd61ebd0347f046ac7e3ff6fb8.png)

▲大赛总决赛现场

  

**成都链安CMO 高子扬**携由成都链安科技有限公司自主知识产权研发的面向区块链安全领域的集成性安全矩阵防线——**『Beosin一站式区块链安全平台』**，参加了全国总决赛路演，并斩获**『创业人气奖』**荣誉。

![](../Images/5dc52b68645725f064f50793a9233e39.png)

▲『成都链安』 X 『创业人气奖』

  

值得一提的是，成都链安是本次成功入围大赛全国总决赛的**唯一一家专注于区块链安全建设**的公司。在2019年12月，成都链安就依托于『Beosin一站式安全服务平台』，通过初赛、复赛的**层层筛选**，在百花齐放的激烈竞争中，**成功出线**！

 

大赛组委会和评审团从『Beosin一站式安全服务平台』的**创新性、实用性、核心团队构成、市场分析及商业模式、技术能力、盈利模式**，以及**与『内容科技』概念的契合性**等各维度进行综合评审，纷纷对其未来潜力表示认同。

 

在本次全国总决赛路演现场，成都链安CMO 高子扬针对『Beosin一站式区块链安全平台』在**安全审计、资产追溯与AML反洗钱、隐私保护、威胁情报、安全防护、安全咨询**等方面具备的亮点和优势，进行了详细而系统的阐述，博得在场一片赞誉。

![](../Images/052fb7aa8ab2fcef198bed87556ec5f8.png)

▲成都链安CMO 高子扬

  

  

**内容科技，引导创业创新**

  

  

据了解，人民网所倡导的**『内容科技』**概念主要指的是对内容产品的供给与消费链条、内容产业的组织与分工模式，产生重大影响的**人工智能、大数据、区块链、云计算、物联网**等新兴技术，以及由这些技术所催生的新业态、新应用、新服务。

  

而『Beosin一站式安全服务平台』从**部署、研发、上线**都经由成都链安潜心钻研、深入耕耘，这既是来自核心团队在安全领域深耕18年的**技术实力展现**，亦是成都链安面向区块链安全领域进行广阔布局的**长远愿景**。

![](../Images/7a6b8d9540b0d89c00fe7038b7647a92.png)

▲大赛欢迎墙

  

  

**响应国家战略部署，聚焦区块链安全**

  

  

同时，『Beosin一站式安全服务平台』的推出不仅是成都链安实现**自身企业价值**的媒介，同时也是成都链安积极响应国家战略部署，建立起**我国『自主创新的区块链安全技术和保障体系』**的重要举措。

  

成都链安CMO 高子扬在路演现场对『Beosin一站式安全服务平台』进行了针对性和系统性的介绍：就现阶段来说，该平台涵盖了**八大安全服务**，**六大安全产品**，针对不同的业务取向和需求，成都链安都能够提供**精确和专业**的服务支持。

![](../Images/ef27237922d9cd468e13ac45253e7fc2.png)

▲大赛路演台

  

  

**一站式护航，助力区块链事业发展**

  

  

得益于『Beosin一站式安全服务平台』的推出和后续升级，成都链安致力于将其打造为专注于区块链安全**最专业和最全面**的一站式安全平台矩阵，以助力我国区块链事业**正向、积极、健康**发展。

  

国家战略层面强调要**把区块链作为核心技术自主创新的重要突破口，加快推动区块链技术和产业创新发展**。我国区块链事业更好更快地发展，离不开来自稳固的安全防线作为支撑，『Beosin一站式安全服务平台』将以全方位的绝对优势，为区块链事业**保驾护航**！

  

![](../Images/7caa384496e18124940918a2f31e7227.png)

▲现场座无虚席

  

感谢**人民网**对成都链安的肯定和认可，我们将以**『让区块链更安全』**为发展内核，**『Beosin一站式安全服务平台』**为发展主力，不断壮大，不断成长！
