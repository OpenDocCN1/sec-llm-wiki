前言：

      最近做了一些项目，其中有的需求是需要白名单才能进行访问测试，而由于直接使用服务器进行测试效果不是很好，也因为客户不能给太多的白名单，所以只能多个人走一台云服务器去进行测试。

        而通常来说，一个白名单大家想一起使用的话，就需要搭建隧道，最常见的方法，大致就是linux的ssh隧道，frp隧道，openvpn，socks4/5的代理等等。

        但是以上的几种都有各种各样的局限性，比如说我遇到的，如果我的服务器是windows的，那么ssh隧道就不行了，frp隧道有一定的风险性，而且不适用于多人共用，socks隧道倒是没什么，但是有的时候确实会影响抓包测试，会有漏包的情况。

       所以这里介绍如何使用免费的，不用花钱去购买的vpn服务器，当然了云主机当然得花钱了。

        

**0X01 搭建VPN服务器**

  

首先，进入windows server 2012 r2界面后，打开服务管理器

然后一直下一步

“服务器和功能”选项，选中远程访问

![](../Images/1c4f62c3969cf5d9ce6fd936bf6548ef.png)

  

然后点击下一步

![](../Images/645b90f2ecd478947d54450a97ecc1b0.png)

  

点击下一步，直至“角色服务”，选中如下

![](../Images/016886a6bd8d0122aaaa9419976ac90b.png)

![](../Images/a6fedc65e8221415706a19035c5cadc0.png)

![](../Images/9428f2986f257aaad38f7aa449050edc.png)

![](../Images/7c4ad55f46c18deb0fad0d62b484fb97.png)

![](../Images/b51e65f50cb364f0f4d7e643b5af5168.png)

![](../Images/8cc13a9bf01f7dd1c182cdc1f178602d.png)

  

![](../Images/7a14733f887b9da924fa51a1e99763bf.png)

  

然后为VPN创建用户  
net user 用户名 密码 /add #创建新用户  
net localgroup administrators 用户名 /add #将新建用户添加到管理员组中  
这里就不演示了，创建好用户后，进入到用户组去为他配置网络

  

![](../Images/58830d08b547f258309eeeeae2fe264e.png)

![](../Images/5435bcbf47eb5737e1ae8b5fcab21951.png)

  

设置好后，返回自己的机器，使用windows自带的vpn介入即可

![](../Images/b42f6d12f7f38acbc404808d5d7a3324.png)
