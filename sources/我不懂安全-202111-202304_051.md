**0X02  标准头与主main函数  
**

C语言调用任何外置的函数的时候都需要对应的头文件去引用，例如我们最常用到的输入与输出函数，需要使用 #include <stdio.h>去调用**，**要调用不同的函数有时候就需要引用其他的头文件，当然了头文件除了内置的，也支持引用自己生成的，后续会为大家介绍到。

头文件引用有两种形式：#include < stdio.h> 和 include "dao.h"。  
用< >引用的一般是编译器提供的头文件，编译时会在指定的目录中去查找头文件（调用内置的）。用""引用的一般是自己写的头文件，编译时，编译器会在项目所在的文件夹中进行查找

  

示例代码如下：

dap.h

*   
*   
*   
*   

```
#pragma once
int a =10;int b = 6;
```

![](../Images/cd812b24d72cf0caf2c2b6695e313e74.png)

ConsoleApplication3.cpp  

  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>      //内置的头文件#include "dao.h"       //自定义头文件
int main(){    int c = a + b;    printf("%d", c);    return c;}
```

  

![](../Images/af185ba4cd49da7f1aa1fc38a11f274a.png)

  

项目生成的话，此处演示的是x86架构生成，点击生成->生成解决方案/重新生成解决方案(快捷键：F7 / alt + ctrl +F7)，此处演示的是点击本地windows调试器，因为这样的话可以用来调试代码，也可以直接生成并运行

C语言与其他语言的区别并不仅仅是格式，同时还有主main函数，实际上学习过笔者分享的go语言的朋友后续会发现，二者十分的相似。

**0x03 四大类型  
**

为什么先写四大类型呢，因为输入函数与输出函数涉及到一个不同类型不同占位符的知识，在C语言中输出函数与输入函数的用法与其他语言是截然不同的

  

**整数类型**

这里面不讲解过于多的内容，因为C语言整数类型很复杂，分长整型、短整型、有符号整型和无符号整型等，这里仅介绍一部分，有兴趣的小伙伴可以自行拓展。

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>
int main(){    int Num;    Num = 100;    printf("八进制显示是：%o,\n十进制显示是：%d,\n十六进制显示是：%x", Num, Num, Num);    getchar(); //相当于断点，防止程序一闪而过    return 0;}
```

![](../Images/1d1b46d97e69b92d5b7c2269a4fa9dc1.png)

  

这里可以看到，C语言是需要初始化变量的，int Num; 作用便是初始化变量，定义变量的类型，当然了大家也可以直接写成 int Num=100; 而在C语言里，无论是输出函数printf()或者是输入函数 scanf() ，在对变量进行输入/输出的时候是不能直接对变量进行引用的，需要首先使用其对应的占位符号去占位而后引用，这里涉及到了内存地址相关的知识。  

  

而本次int型案例，使用的是 %o 八进制占位；%d 十进制占位; 以及%x 十六进制占位

  

若是直接对变量进行输出打印，会出现什么结果呢？

![](../Images/967432189598093127e239a2eaff4bbb.png)

  

这里拓展一点点，那就是在C语言中区分整型为有符号位和无符号位，在前面汇编的讲解中曾经介绍过有符号位和无符号位的一些相关知识，感兴趣的小伙伴可以往前翻翻 - 汇编语言基础

  

*   
*   
*   
*   
*   
*

```
Int占32位的时候，最高位为符号位(X86与X64)
0111 1111 1111 1111 1111 1111 1111 1111   正值
1111 1111 1111 1111 1111 1111 1111 1111   负值
取值范围为 -2^31 至 2^32 -1
```

  

简单引用这个的概念是防止大家使用的值超过了取值范围导致的溢出异常

**0x04 字符串与数组**

  

字符串在C语言中其实就是一串字符类型的组合，通常展现形式其实就是数组，在二进制中，末尾以00结尾，在这里仅做简单的介绍，在后续中会对字符串和数组单独的做一个较为详细的讲解

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>
int main(){    char str[] = { '1','2','3',0};    char str_1[] = { "123"};    char array[128] = { '1','2','3' };    printf(" str:%s\n str2:%s\n array:%s ", str,str_1,array);    return 0;}
```

![](../Images/6b9d0946fae2f30ea9c1bfc7abdbb911.png)

  

这里面第一个str字符串，采用的是字符型拼接，0结尾证明他是一个字符串或者是数组；char代表类型，str代表数组名称，\[\]代表数组长度，为空则代表未对数组长度做限制，{}里面的内容则是代表数组的内容，可以不与数组长度对应，但是不能超过数组长度，否则会报错。

  

  

若是不对数组的长度做限制，同时不使用0结尾那么会变成什么样子呢？(实际上笔者测试的时候，若是现在数组的长度与数组的字符个数一致的时候，不以0结尾，也会导致输出异常，所以建议数组的长度应至少大于字符的个数)

![](../Images/e2ac31e76b6e5270f91f2ea4c3b7f411.png)

  

**0x05 常量  
**

  

常量，顾名思义，就是不会发生改变的量被，在C语言中通常使用define来定义常量  

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>#include <string.h>#define PI 3.141592654   //定义一个常量
int main(){    int R = 2;    float C = 2 * R * PI;    printf("%f", C);    return 0;}
```

  

示例代码为计算一个半径为2的圆形的周长，在这里面，π就是一个常量

  

![](../Images/1a552368909423d25531f10c43a96e3f.png)

  

除了使用define来定义常量外，我们还可以使用const来定义常量

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>#include <string.h>
int main(){    const int age = 20;   //const 被定义为常量了，在程序里不可修改    int c = age * 2;    printf("%d", age);    return 0;}
```

**0X06 输入与输出函数**

  

上面使用到了字符串的输出函数 printf() ，在上述的四大类型里面已经介绍了不同的类型的变量输出需要使用不同的占位符，那么这里就轮到了输入函数的介绍

  

区别于其他语言，C语言是没有input函数的，在c语言里的输入函数常见的有

scanf()   scanf\_s()   getchar()  gets ()  fgets()  ......这里主要介绍scanf以及scanf\_s两种，其余的后续在详细介绍字符串的内容的时候会给大家讲解

```
#include <stdio.h>
int main(){    int Num;    scanf("%d", &Num);    //scanf()是输入函数，但是他是不安全的，若是想用的话需要在“属性”->“C++”->“预处理器”->“编辑”内添加_CRT_SECURE_NO_WARNINGS    //scanf_s()是安全函数，但是用起来会比较麻烦 scanf_s("%d",&num,10)    return 0;}
```

  

scanf实际上并不安全，所以需要我们使用的时候手动添加c++的预处理器

scanf\_s() 用法如下

  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#include <stdio.h>
int main(){    char Num[10] ;        printf("请输入八位数字密码");    scanf_s("%s", &Num, 9);    printf("%s", Num);    return 0;}
```

![](../Images/4e5169fb40709397bca3f3b53a02bd2b.png)

  

大家从上述代码中，其实可以看出来，scanf\_s后面多了一个参数，9。他的作用其实是限定输入的字符长度，防止发生堆栈溢出，若是输入的长度大于限定的9，则会不返回任何内容；由于我限定的是字符串类型，所以实际上我输入12345678的时候，真正的情况应该相当于

char Num\[10\] = {'1','2','3','4','5','6','7','8',0}

所以如果我输入123456789，未返回任何内容
