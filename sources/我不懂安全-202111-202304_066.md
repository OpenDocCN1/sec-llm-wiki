# 社会工程学工具Seeker

Seeker是一款利用社会工程学定位访问者地理位置的工具

前置工具：

Seeker、ngrok

下载seeker：https://github.com/thewhiteh4t/seeker

    Ngrok：https://dashboard.ngrok.com/get-started/setup

 

下载后执行install.sh安装seeker。

![](../Images/10d07ffbed79e96c430461d7a4b613cc.png)

执行seeker.py ，选择seeker提供的google Drive, File URL随便写，这时seeker已经开启了钓鱼网站的web服务。

![](../Images/e107e3ecdaeefec893f9bde4c4267bcf.png)

使用ngrok设置反向代理，映射到公网

![](../Images/d3141c7fb7659c16c7dd357ed43cab8a.png)

当然也可使用生成短链接的网站：https://sina.lt/缩短URL

![](../Images/25c84f3c96b77eaf3fe5bfaf71f2c5bd.png)

访问生成的恶意地址

![](../Images/ff94afcde72acc6351193ee83cd1816c.png)

首次访问会跳出，获取地理位置的提示

![](../Images/ba891a6c4e0aabf6c883e77e71418144.png)

这样Seeker后端就接收到了来自访问设备的相关信息，包括操作系统、浏览器、IP以及运营商等等，当然还有一个Google Map的URL。  

![](../Images/8e909d54f3620f35cdc8959cb9c0bc6d.png)
