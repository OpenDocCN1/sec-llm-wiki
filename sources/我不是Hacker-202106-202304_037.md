前言

Covid19 旅行通行证管理系统是一个使用PHP和MySQL 数据库开发的基于 Web 的应用程序项目。此项目为用户提供了一个可以在 covid 19 的限制下提交旅行通行证的在线平台。该应用程序是使用 Bootstrap 和 AdminLTE 模板开发的。

  

其code参数未进行过滤，存在登录前SQL注入，本文对此漏洞进行复现。
