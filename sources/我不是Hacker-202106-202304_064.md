**H2**

  

H2 是一个用 Java 编写的开源关系数据库管理系统，可以嵌入到应用程序中或以客户端-服务器模式运行。根据 Maven 显示，H2 数据库引擎被 6,807 个组件使用。

  

**揭开面纱**

  

1\. 其实此漏洞影响的是H2数据库的web控制台

2\. 默认控制台不允许远程访问

  

略显鸡肋。。

**复现**

  

启动H2数据库web控制台

*   
*   
*   

```
$ java -cp h2-1.4.197.jar  org.h2.tools.Server -tcp -webTCP server running at tcp://192.168.1.13:9092 (only local connections)Web Console server running at http://192.168.1.13:8082 (only local connections)
```

  

打开允许远程访问开关

**2种方式：**

\- 设置 -webAllowOthers 属性为 true

\- 也可以在web页面设置

![](../Images/0900644eb6c04383fa6965be3b29a75a.png)

  

允许远程连接后，H2 控制台将能够通过 JNDI 从远程服务器加载自定义类。根本原因与 Log4j CVE-2021-44228 相同。

如果 Driver Class 设置成 javax.naming.Context class， getConnection函数就会实例化一个对象并调用lookup函数，从而触发利用链。

  

*   
*   
*   
*   
*   
*   
*   

```
else if (javax.naming.Context.class.isAssignableFrom(d)) {    // JNDI context    Context context = (Context) d.getDeclaredConstructor().newInstance();    DataSource ds = (DataSource) context.lookup(url);    if (StringUtils.isNullOrEmpty(user) && StringUtils.isNullOrEmpty(password)) {        return ds.getConnection();    }
```

**修复**

  

2.0.206版本禁止从远程加载自定义类

