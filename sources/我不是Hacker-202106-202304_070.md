三:  漏洞复现🐋

  

  

  

  

  

在官方的更新文件中，查找到修改的文件

  

  

![](../Images/900128b2ffdf9e3f4beda43b02ab7cde.png)

  

  

官方删除了某个方法

  

*   
*   
*   
*   

```
function getDisplayUrl(url, apiClient) {        return apiClient.getUrl('Images/Remote', { imageUrl: url });    }

```

  

  

  

下载漏洞版本源码，查找该接口对应的文件

**Jellyfin.Api/Controllers/RemoteImageController.cs**

  

  

![](../Images/0fb4404b1e090791dcfc067c0f92a15d.png)

  

  

其中接收的参数为 imageUrl ，后续的代码片段存在SSRF漏洞
