背景

JFrog 安全团队发现了tensorflow中的一处代码注入漏洞，该漏洞会在本地稳定触发，在某种特定的情况下，也会导致RCE，CVE编号为CVE-2021-41228。


Tensorflow

TensorFlow是一个基于数据流编程（dataflow programming）的符号数学系统，被广泛应用于各类机器学习（machine learning）算法的编程实现，其前身是谷歌的神经网络算法库DistBelief。


-- 摘自百度百科


影响版本


Tensorflow < 2.7.0


漏洞详情

漏洞存在于saved_model_cli 模块中，这个模块的作用是保存用户的模型。


攻击者可以控制--input_examples 参数的输入内容，并在其中加入恶意的Python代码，从而导致代码注入漏洞。


preprocess_input_examples_arg_string函数


def preprocess_input_examples_arg_string(input_examples_str):

 input_dict=preprocess_input_exprs_arg_string(input_examples_str)

        ...


调用了preprocess_input_exprs_arg_string,函数


def preprocess_input_exprs_arg_string(input_exprs_str):

    input_dict = {}


  for input_raw in filter(bool, input_exprs_str.split(';')):

      ...

        input_key, expr = input_raw.split('=', 1)

      # ast.literal_eval does not work with numpy expressions

      input_dict[input_key] = eval(expr) # pylint: disable=eval-used

  return input_dict

input_exprs_str 就是用户控制的输入内容，可以看到标红的 eval 十分显眼，我们可以传入代码，让eval执行，从而触发代码执行漏洞。


修复建议

使用到saved_model_cli 模块的开发者，务必升级Tensorflow到2.7.0版本。
