前言

每周累计下载量接近 2200 万的2个流行的 NPM 软件包中存在后门，这是又一起十分典型的供应链攻击。攻击者未授权访问开发者的账号，并对代码进行了投毒。

![](../Images/3c5653c34e4d4d57771d825a6787c38e.png)

![](../Images/5dcba60865b9934391b8224fcd45742f.png)![](../Images/155b381b1a5f764179c2ad2d89ac3459.png)  
一、coa：命令行参数解析器

2.0.3 及以上版本开始的所有 coa 版本（2.0.3、2.0.4、2.1.1、2.1.3、3.0.1 和 3.1.3）都受到影响，建议受影响的用户根据11 月 4 日发布的 GitHub公告，对coa进行降级

![](../Images/5dcba60865b9934391b8224fcd45742f.png)![](../Images/155b381b1a5f764179c2ad2d89ac3459.png)  

二、rc：配置加载器

1.2.9、1.3.9 和 2.3.9 版本存在后门，建议用户降级到 1.2.8 版

![](../Images/5dcba60865b9934391b8224fcd45742f.png)![](../Images/155b381b1a5f764179c2ad2d89ac3459.png)  

三、总结

对其中的恶意软件样本的进一步分析表明，它是一个 DanaBot 变体，（一种用于窃取凭据和密码的 Windows 恶意软件）。与上个月发生的两起类似事件相呼应，这些事件导致UAParser.js 被攻陷，并发布了盗版的 Roblox NPM 库。
