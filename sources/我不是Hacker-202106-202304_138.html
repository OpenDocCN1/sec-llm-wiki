一、MaianCart

MaianCart是一款功能强大的开源购物平台，具有界面美观，功能完善等特点，深受国外开发人员喜爱。


二、漏洞版本

v3.0 <= maian cart <= v3.8


三、环境搭建

1. 下载漏洞源码

链接: https://pan.baidu.com/s/1lgqt4MyZnQOq48cxNubSHA 提取码: 1a0s

2. 解压并将core文件夹复制到你的web目录中，重命名为cart


P.S. 这里我用的mamp，可以用lamp或wamp搭建

unzip maian_cart_v3_8.zipmv maian_cart/core xxxxx/web_root/cart


3. 修改 control/connect.php文件

依次填写 数据库host，db用户名，db密码，数据库名

P.S. 注意要在mysql中建好设置的这个数据库名，否则会报错


91行，需要修改默认的密钥，随便改就行


4. 访问安装目录

http://test.com:9202/cart/install/


5. 一直点下一步，然后点击安装数据表

中间如有错误，百度排查下环境问题


6. 安装demo网站


7. 重命名install文件夹

mv install install_bak


8. 大功告成

后台页面：

http://test.com:9202/cart/admin/



四、复现

此漏洞无需认证，直接运行Poc


python3 poc.py http://test.com:9202/ cart


成功getshell
