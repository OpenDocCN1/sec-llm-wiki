一、前言
渗透测试中比较常见的数据库就是Mysql，但是拿到的基本都是mysql权限的，这时就需要进行权限提升。Mysql权限提升主要方式有两种，MOF和UDF，下面会分别对其进行介绍。

二、MOF

1. 原理


关于 mof 提权的原理其实很简单，就是利用了 c:/windows/system32/wbem/mof/ 目录下的 nullevt.mof 文件，每分钟都会在一个特定的时间去执行一次的特性，来写入我们的cmd命令使其被带入执行。


2. 利用条件（苛刻）


1) windows 03及以下版本

2) mysql启动身份具有权限去读写c:/windows/system32/wbem/mof 目录

3) secure-file-priv参数为空


3. MOF文件


托管对象格式 (MOF) 文件是创建和注册提供程序、事件类别和事件的简便方法。文件路径为：c:/windows/system32/wbme/mof/，其作用是每隔五秒就会去监控进程创建和死亡。


MOF文件每五秒就会执行，而且是系统权限，我们通过mysql使用load_file 将文件写入/wbme/mof，然后系统每隔五秒就会执行一次我们上传的MOF。MOF当中有一段是vbs脚本，我们可以通过控制这段vbs脚本的内容让系统执行命令，进行提权。


4. MOF文件利用


1) 上传MOF文件到有读写权限的目录

2) 文件导入c:/windows/system32/wbme/mof/

select load_file("C:/Documents and Settings/testtest.mof") into dumpfile "c:/windows/system32/wbem/mof/nullevt.mof"

P.S. 这里不能使用outfile，因为会在末端写入新行，因此mof在被当作二进制文件无法正常执行，所以我们用dumpfile导出一行数据

6. 关于Mof提权的弊端


我们提权成功后，就算被删号，mof也会在五秒内将原账号重建，那么这给我们退出测试造成了很大的困扰，所以谨慎使用。那么我们如何删掉我们的入侵账号呢？


cmd 下运行下面语句:

net stop winmgmt

del c:/windows/system32/wbem/repository

net start winmgmt


三、UDF

1. 原理


UDF提权是利用MYSQL的自定义函数功能，将MYSQL账号转化为系统system权限

编译


2. 利用条件（苛刻）


1) Mysql版本大于5.1版本udf.dll文件必须放置于MYSQL安装目录下的lib\plugin文件夹下。

2) Mysql版本小于5.1版本。udf.dll文件在Windows2003下放置于c:\windows\system32，在windows2000下放置于c:\winnt\system32。

3) 掌握的mysql数据库的账号有对mysql的insert和delete权限以创建和抛弃函数，一般以root账号为佳，具备`root账号所具备的权限的其它账号也可以。

4) 可以将udf.dll写入到相应目录的权限。


3. 提权步骤


1) 检查 secure_file_priv

show global variables like 'secure%';

- 当 secure_file_priv 的值为 NULL ，表示限制 mysqld 不允许导入|导出，此时无法提权

- 当 secure_file_priv 的值为 /tmp/ ，表示限制 mysqld 的导入|导出只能发生在 /tmp/ 目录下，此时也无法提权

- 当 secure_file_priv 的值没有具体值时，表示不对 mysqld 的导入|导出做限制，此时可提权


2) 检查 plugin

select Host,user,plugin from mysql.user where user = substring_index(user(),'@',1);

- 当 plugin 的值为空时不可提权

- 当 plugin 值为 mysql_native_password 时可通过账户连接提权


3) 查看系统架构

show variables like '%compile%';

这里是 x64 位的系统，我们可以去kali中 /usr/share/metasploit-framework/data/exploits/mysql/ 目录下载64位的 .dll 文件。(由于我这里MSF更改过，所以路径有所不同)


4) 检查 plugin目录

show variables like 'plugin%';

当前mysql用户需要有写此目录权限
