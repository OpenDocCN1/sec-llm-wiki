一、前言

如何让requests在发送请求包的时候，header中默认带上我们自定义的字段呢？

注意，这里说的不是这种

headers = {"Poc-Tag": "test"}

resp=requests.get("test.com", headers=headers)

而是，只发送请求，header就会默认带自定义字段

resp = requests.get("test.com")

print(resp.request.headers)


>> {"Poc-Tag": "test"}

这时就需要对requests库进行修改啦


二、简单分析

1. 下载requests库源码

https://github.com/psf/requests

2. 有两个需要重点关注的文件

1) requests/utils.py

找到 定义默认header

def default_headers():

    return CaseInsensitiveDict({

        'User-Agent': default_user_agent(),

        'Accept-Encoding': ', '.join(('gzip','deflate')),

        'Accept': '*/*',

        'Connection': 'keep-alive',

    })

默认header是指发送请求的时候，未指定header，requests 库发送的默认header

2) requests/sessions.py

class Session(SessionRedirectMixin):

可以看到，这里把请求的各种参数进行了封装，我们看

headers=merge_setting(request.headers, self.headers, dict_class=CaseInsensitiveDict)

request.headers就是用户传入的header，self.header可以看到就是requests库默认的header

跟进merge_setting函数，发现其实这个函数是将两个header相结合，优先选择用户传入header中的字段，然后从默认字段中提取前者没有的字段，进行整合


那思路就很清晰了，直接在requests库默认header处添加我们自定义的字段，就能被整合到最终发包的header中


三、开始魔改

直接修改 requests/utils.py 中的 default_header()


这里加了一个Poc-Tag字段


注意：添加字段的值如果为 None，则发包header中，不会出现你自定义的这个字段

def default_headers():

    try:

        poc_tag = os.getenv("POC_TAG")

    except:

        poc_tag = None

    return CaseInsensitiveDict({

        'User-Agent': default_user_agent(),

        'Poc-Tag': poc_tag,

        'Accept-Encoding': ', '.join(('gzip', 'deflate')),

        'Accept': '*/*',

        'Connection': 'keep-alive',

    })

注：如果想修改默认UA，可以修改 default_user_agent()


四、源码安装requests

在下载的requests源码根目录执行

python setup.py install

即可安装魔改后的requests库


注意：如果已安装，请先卸载

pip uninstall requests -y


五、测试

headers = {"aaa": "bbb"}

resp = requests.get("test.com", headers=headers)

print(resp.request.headers)


>> {'Content-Length': '0', 'aaa': 'bbbb', 'Accept-Encoding': 'gzip, deflate', 'Accept': '*/*', 'User-Agent': 'python-requests/2.25.1', 'Connection': 'keep-alive', 'Poc-Tag': 'test'}

大功告成，我们发送的所有request请求都会带上Poc-Tag啦
