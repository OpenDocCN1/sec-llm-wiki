一、前言

如何让requests在发送请求包的时候，header中默认带上我们自定义的字段呢？

注意，这里说的不是这种

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

headers = {"Poc-Tag": "test"}

resp=requests.get("test.com", headers=headers)

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

而是，只发送请求，header就会默认带自定义字段

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

resp = requests.get("test.com")

print(resp.request.headers)

  

\>> {"Poc-Tag": "test"}

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

这时就需要对requests库进行修改啦

![](../Images/896f14b746c7d143fdf245a056dc7e16.png)![](../Images/65292ebca0529d90271607a38d53a98a.png)  
二、简单分析

1\. 下载requests库源码

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

https://github.com/psf/requests

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

2\. 有两个需要重点关注的文件

1) requests/utils.py

找到 定义默认header

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

def default\_headers():

    return CaseInsensitiveDict({

        'User-Agent': default\_user\_agent(),

        'Accept-Encoding': ', '.join(('gzip','deflate')),

        'Accept': '\*/\*',

        'Connection': 'keep-alive',

    })

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

默认header是指发送请求的时候，未指定header，requests 库发送的默认header

2) requests/sessions.py

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

class Session(SessionRedirectMixin):

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

可以看到，这里把请求的各种参数进行了封装，我们看

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

headers=merge\_setting(request.headers, self.headers, dict\_class=CaseInsensitiveDict)

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

request.headers就是用户传入的header，self.header可以看到就是requests库默认的header

跟进merge\_setting函数，发现其实这个函数是将两个header相结合，优先选择用户传入header中的字段，然后从默认字段中提取前者没有的字段，进行整合

  

那思路就很清晰了，直接在requests库默认header处添加我们自定义的字段，就能被整合到最终发包的header中

![](../Images/896f14b746c7d143fdf245a056dc7e16.png)![](../Images/65292ebca0529d90271607a38d53a98a.png)  
三、开始魔改

直接修改 requests/utils.py 中的 default\_header()

  

这里加了一个Poc-Tag字段

  

注意：添加字段的值如果为 None，则发包header中，不会出现你自定义的这个字段

![](../Images/c269dac0fc263116f1e8900449fac1dc.png)

def default\_headers():

    try:

        poc\_tag = os.getenv("POC\_TAG")

    except:

        poc\_tag = None

    return CaseInsensitiveDict({

        'User-Agent': default\_user\_agent(),

        'Poc-Tag': poc\_tag,

        'Accept-Encoding': ', '.join(('gzip', 'deflate')),

        'Accept': '\*/\*',

        'Connection': 'keep-alive',

    })

![](../Images/88d7ec96d7ec59eb3b6023c78f019b13.png)

注：如果想修改默认UA，可以修改 default\_user\_agent()

![](../Images/896f14b746c7d143fdf245a056dc7e16.png)![](../Images/65292ebca0529d90271607a38d53a98a.png)
