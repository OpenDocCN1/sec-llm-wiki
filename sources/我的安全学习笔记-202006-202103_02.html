GitHub 有许多功能可帮助开发者改进和维护代码的质量，例如GitHub 为拥有 Advanced Security 许可的客户提供额外的安全功能。

关于 Advanced Security 功能

GitHub Advanced Security 许可提供以下额外功能：

  • 代码扫描 - 搜索代码中潜在的安全漏洞和编码错误。更多信息请参阅“关于 代码扫描”。

  • 依赖项审查 - 在合并拉取请求之前显示依赖项更改的全部影响以及任何有漏洞版本的详情。

需要注意的是，这里的CodeQL无法分析纯JSP的项目（mvn编译后没有classes的项目），会提示下面的错误：


在CodeQL本地进行测试也是一样的报错，如下：


因为我上面使用的是 openrasp-testcases/java/vulns/  漏洞代码项目，是纯JSP的，没有.java 有编译的字节码文件夹classes，CodeQL的工作原理是在使用相应的编译工具进行项目编译的过程中，通过收集项目编译过程中产生的信息，并以此生成数据库。CodeQL生成它理解的代码转变成的数据库，再结合CodeQL提供的语法和编写各种QL文件，就可以形成各种漏洞的检测模型。 

重点：CodeQL透过编译过程生成数据库，CodeQL无法分析未被编译的代码。

参考：https://paper.seebug.org/1324/

结束语：

      本笔记通过在GitHub上创建免费的organizations和repository，体验了GitHub Advanced Security产品里面的依赖库漏洞检查和代码安全漏洞扫描（以CodeQL为例子，在Marketplace还有更多的其他的代码检查工具）。对于个人开发者目前是可以免费体验GitHub提供的这些功能，对于提升代码质量发现安全漏洞确实有一些帮助的。唯一的不好的是，代码扫描需要仓库是公开的，不便于扫描私有项目（手工扫描后，再设置为私有项目）。不知道有没有命令行工具方便实现自动化使用了GitHub Advanced Security产品的强大功能。

    另外CodeQL是一个很不错的白盒扫描利器，非常值得投入时间研究，如何学呢？当然是抱各位大佬的大腿快速上手了～
