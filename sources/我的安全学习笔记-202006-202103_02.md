GitHub 有许多功能可帮助开发者改进和维护代码的质量，例如GitHub 为拥有 Advanced Security 许可的客户提供额外的安全功能。

关于 Advanced Security 功能

GitHub Advanced Security 许可提供以下额外功能：

*   代码扫描 - 搜索代码中潜在的安全漏洞和编码错误。更多信息请参阅“关于 代码扫描”。
    
*   依赖项审查 - 在合并拉取请求之前显示依赖项更改的全部影响以及任何有漏洞版本的详情。

第一步，

*   Dependabot alerts —依赖库漏洞版本告警，官方文档：https://docs.github.com/cn/github/managing-security-vulnerabilities/viewing-and-updating-vulnerable-dependencies-in-your-repository

*   Code scanning alerts —分析仓库中的代码，查找安全漏洞和编码问题。
    

官方文档：https://docs.github.com/en/github/finding-security-vulnerabilities-and-errors-in-your-code/about-code-scanning

  

这个代码漏洞扫描功能不开发给个人开发者使用，仅适用于组织且必须为公开的项目才可使用。如下图所示：

![](../Images/b3e75df1685319def0f906daf3c028be.png)  

创建一个组织并创建项目https://github.com/coffeehb-org/testt\_codeql，在设置repository为private的描述中有这一条说明：“Code scanning will become unavailable”，如下图所示：

![](../Images/fe00dbd3b1c0c982fc7217da2dc1ce06.png)  

设置为公开项目后，可以就可以使用该功能了。如下所示：

![](../Images/1f5f01287d651c0ccbabfea803fb1fc5.png)  

点击“Set up code scanning”进入代码扫描配置，这里有多种扫描分析方式，我们使用GitHub官方的CodeQL分析：

 ![](../Images/e7ff8dfc1d66c9a107a5c5bd6cd8b4ba.png)  

找到“CodeQL Analysis” 点击“Set up this workflow”

![](../Images/e34fc3302224eb98e6567b13ece0c53b.png)  

提交 CodeQL 分析工作流，无需对其进行任何更改，直接提交到master分支。到下面这个地址可以看到当前的工作任务

https://github.com/coffeehb-org/testt\_codeql/actions

![](../Images/70834589313c00d53f18e5b5e75095f8.png)  

需要注意的是，这里的CodeQL无法分析纯JSP的项目（mvn编译后没有classes的项目），会提示下面的错误：

![](../Images/eda5d93aae61ca6499d085f954c50197.png)  

在CodeQL本地进行测试也是一样的报错，如下：

![](../Images/7732c8fea16192c8468d90d359f380e4.png)  

因为我上面使用的是 openrasp-testcases/java/vulns/  漏洞代码项目，是纯JSP的，没有.java 有编译的字节码文件夹classes，CodeQL的工作原理是在使用相应的编译工具进行项目编译的过程中，通过收集项目编译过程中产生的信息，并以此生成数据库。CodeQL生成它理解的代码转变成的数据库，再结合CodeQL提供的语法和编写各种QL文件，就可以形成各种漏洞的检测模型。 

重点：CodeQL透过编译过程生成数据库，CodeQL无法分析未被编译的代码。

参考：https://paper.seebug.org/1324/

结束语：

      本笔记通过在GitHub上创建免费的organizations和repository，体验了GitHub Advanced Security产品里面的依赖库漏洞检查和代码安全漏洞扫描（以CodeQL为例子，在Marketplace还有更多的其他的代码检查工具）。对于个人开发者目前是可以免费体验GitHub提供的这些功能，对于提升代码质量发现安全漏洞确实有一些帮助的。唯一的不好的是，代码扫描需要仓库是公开的，不便于扫描私有项目（手工扫描后，再设置为私有项目）。不知道有没有命令行工具方便实现自动化使用了GitHub Advanced Security产品的强大功能。

    另外CodeQL是一个很不错的白盒扫描利器，非常值得投入时间研究，如何学呢？当然是抱各位大佬的大腿快速上手了～
