2020-6-27日，拿到了从刷机大佬那里买来的nexus 5x手机，现在可以放开了“搞机”了呀，这里分两部分来讲，一部分为手机端【模拟器端】，另一部分为PC端的环境准备。

一、准备环境：

【Android手机】

Nexus 5x手机、原生的Android 8.1.0系统、刷入了SuperSU 获得Root 

【模拟器】

Mumu模拟器1.9.5(20200320), 网易编译的AOSP内核，Android6.0.1，提供完全Root 


手上的nexus 5x手机并非刷的AOSP root包，所以ADB shell没有root权限，adb remount 挂载目录失败的，如果需要读写一些系统目录，需要这样：

adb shell 进入普通shell，再su切换到root，再挂载/目录

mount -o rw,remount /

再在root的shell下，进行系统目录的操作。


二、安装burp证书到系统目录

       这里以Burpsuite代理抓包工具为例子，导出它的证书安装为系统证书，这样以后进行APP安全测试时，可以设置全局代理方式进行抓包分析https请求。

  1. 配置burp代理，访问http://burp/ 下载证书

  2. 执行2条命令

openssl x509 -inform DER -outform PEM -in cacert.der -out cacert.pemopenssl x509 -subject_hash_old -in cacert.pem （得到一个hash 比如：9a5ca275）

    3. push 到手机的临时目录

mv cacert.pem 9a5ca275.0adb push 9a5ba575.0 /data/local/tmp/adb shell进入使用su切换到rootcp 9a5ba575.0 /system/etc/security/cacerts/


到此，burp证书导出为系统证书安装完成～


三、安装Drozer Agent

         

        Drozer是MWR Labs开发的一款Android安全测试框架，Drozer是一种交互式的安全测试工具，Drozer允许你一个普通android应用的身份与其他应用和操作系统交互。

下载地址：https://github.com/mwrlabs/drozer/releases/download/2.3.4/drozer-agent-2.3.4.apk

具体配置与使用，后续可以参见我其他的Drozer相关的笔记，这里简单描述一下：

1、下载安装Drozer Agent

adb install drozer-agent-2.x.x.apk

2、PC上安装所需要的依赖库【pip install drozer===2.4.2】

如有报错，根据报错安装缺失的模块比如：

pip install protobufpip install pyOpenSSLpip install twisted

3、端口转发

adb forward tcp:31415 tcp:31415

4、PC端连接Agent

drozer console connect

四、配置Frida Server

Frida是一种动态插桩工具，可以插入一些代码到原生应用的内存空间去，（动态地监视和修改其行为）。Frida是跨平台的开源Hook框架，支持Win、Mac、Linux、Android甚至IOS平台下的Hook。

下载：

https://github.com/frida/frida/releases

具体参见笔记《Frida Hook学习之基础篇》，需要注意的是尽量使用高版本的Frida进行测试，兼容性和稳定性更好。

将frida-server 放置在/data/local/tmp/目录下，每次启动需要如下命令：

转发配置，启用firda-server命令

adb forward tcp:27042 tcp:27042adb forward tcp:27043 tcp:27043adb shell su -c "/data/local/tmp/frida-server -D"

adb命令后台启动Frida-server



五、Xposed配置

Xposed是一个强大的Android Java层Hook框架，编写Xposed插件可以实现很多黑科技。

Xposed的安装前你的手机 必须 Root，我不敢拿买到的手机进行Xposed配置。这里为了避免手机不稳定甚至变砖，我就在Mumu模拟器里面完成这一套的环境搭建。

Mumu模拟器提供ROOT权限的，但是需要在模拟器的设置里面，手动勾选，开启ROOT权限。


  • Xposed 官方下载安装器：

https://repo.xposed.info/module/de.robv.android.xposed.installer

我下载的是这个：

https://dl.xda-cdn.com/4/3/9/3/0/8/2/XposedInstaller_3.1.5.apk?key=_tuoUT8qQ5pBDSYkbtWExg&ts=1593329003


  • 点击【安装/更新】,选择【Install via recovery】

  • 等待【下载】，重启到【Recovery】模式，期间请勿操作

  • 耐心等待，刷完会自动重启，打开【Xposed Installer】，显示框架已激活。



Xposed框架已经安装和激活，现在可以安装一些插件进行想要的Hook了。

七、PC端 Android Studio安装

下载安装Android Studio

https://developer.android.google.cn/studio/

配置选择SDK，NDK

从菜单栏选择 Tools > Android > SDK Manager，选中SDK Tools标签，选中 选中 CMake 和 NDK 旁的复选框


最后在local.properties中添加ndk.dir，然后就可以用Android Studio进行Android项目开发了。


八、脱壳神器-FRIDA-DEXDump

     对APP进行分析，主要是想看看某个地方的业务逻辑。但是现在的APP被各种免费的/商业的加固混淆工具保护着。

面对越来越难脱掉的壳，FRIDA-DEXDump 是一个不错的选择。

     具体的介绍参考《FRIDA: 一吻便杀一个人，三秒便脱一个壳》https://mp.weixin.qq.com/s/x8_aa762wpsvA4nhSLoppQ

    项目地址：https://github.com/hluwa/FRIDA-DEXDump

    安装方式：

        1、配置和启动Frida-Server

        2、下载这个项目，使用命令pip install -r requirements.txt 安装依赖库

        3、在模拟器或手机上打开需要脱壳的APP

        4、执行DEXDump，pyhton main.py 

        5、完成脱壳工作
