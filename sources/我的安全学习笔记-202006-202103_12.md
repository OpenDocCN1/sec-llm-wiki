二、安装burp证书到系统目录

       这里以Burpsuite代理抓包工具为例子，导出它的证书安装为系统证书，这样以后进行APP安全测试时，可以设置全局代理方式进行抓包分析https请求。

1.  配置burp代理，访问http://burp/ 下载证书
    
2.  执行2条命令
    

*   
*   

```
openssl x509 -inform DER -outform PEM -in cacert.der -out cacert.pemopenssl x509 -subject_hash_old -in cacert.pem （得到一个hash 比如：9a5ca275）
```

    3. push 到手机的临时目录  

*   
*   
*   
*   

```
mv cacert.pem 9a5ca275.0adb push 9a5ba575.0 /data/local/tmp/adb shell进入使用su切换到rootcp 9a5ba575.0 /system/etc/security/cacerts/
```

![](../Images/bc10cacecba3dd6a1cb340ed8a287370.png)  

到此，burp证书导出为系统证书安装完成～

四、配置Frida Server

Frida是一种动态插桩工具，可以插入一些代码到原生应用的内存空间去，（动态地监视和修改其行为）。Frida是跨平台的开源Hook框架，支持Win、Mac、Linux、Android甚至IOS平台下的Hook。

下载：

https://github.com/frida/frida/releases

具体参见笔记《Frida Hook学习之基础篇》，需要注意的是尽量使用高版本的Frida进行测试，兼容性和稳定性更好。

将frida-server 放置在/data/local/tmp/目录下，每次启动需要如下命令：

转发配置，启用firda-server命令

*   
*   
*   

```
adb forward tcp:27042 tcp:27042adb forward tcp:27043 tcp:27043adb shell su -c "/data/local/tmp/frida-server -D"
```

**adb命令后台启动Frida-server**

五、Xposed配置

Xposed是一个强大的Android Java层Hook框架，编写Xposed插件可以实现很多黑科技。

Xposed的安装前你的手机 必须 Root，我不敢拿买到的手机进行Xposed配置。这里为了避免手机不稳定甚至变砖，我就在Mumu模拟器里面完成这一套的环境搭建。

Mumu模拟器提供ROOT权限的，但是需要在模拟器的设置里面，手动勾选，开启ROOT权限。

![](../Images/50644a82fd5725d5f6be8d667f86f16a.png)  

*   Xposed 官方下载安装器：
    

https://repo.xposed.info/module/de.robv.android.xposed.installer

我下载的是这个：

https://dl.xda-cdn.com/4/3/9/3/0/8/2/XposedInstaller\_3.1.5.apk?key=\_tuoUT8qQ5pBDSYkbtWExg&ts=1593329003

  

*   点击【安装/更新】,选择【Install via recovery】
    
*   等待【下载】，重启到【Recovery】模式，期间请勿操作
    
*   耐心等待，刷完会自动重启，打开【Xposed Installer】，显示框架已激活。
    
      
    

![](../Images/0e1409b897cf3511c0cdcb9f770a870c.png)  

Xposed框架已经安装和激活，现在可以安装一些插件进行想要的Hook了。

**八、脱壳神器-FRIDA-DEXDump**

     对APP进行分析，主要是想看看某个地方的业务逻辑。但是现在的APP被各种免费的/商业的加固混淆工具保护着。

面对越来越难脱掉的壳，FRIDA-DEXDump 是一个不错的选择。

     具体的介绍参考《FRIDA: 一吻便杀一个人，三秒便脱一个壳》[https://mp.weixin.qq.com/s/x8\_aa762wpsvA4nhSLoppQ](https://mp.weixin.qq.com/s?__biz=MzIzNDE3NjI0MQ==&mid=2247483672&idx=1&sn=65a33cda5bfb95f6f7ada186e4f77174&scene=21#wechat_redirect)

    项目地址：https://github.com/hluwa/FRIDA-DEXDump

        3、在模拟器或手机上打开需要脱壳的APP  

        4、执行DEXDump，pyhton main.py
