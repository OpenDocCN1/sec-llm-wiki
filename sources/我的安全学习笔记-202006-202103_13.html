一、准备环境：

        MuMu模拟器、frida-server-12.8.14

连接模拟器命令：

adb connect 127.0.0.1:7555 MUMU模拟器

adb connect 127.0.0.1:62001 夜游神模拟器

adb connect 127.0.0.1:21503 逍遥模拟器


二、配置frida-server

    下载frida-server

     https://github.com/frida/frida/releases

下载你需要的frida-server版本的包，解压出来是可执行的二进制包

部署到Android设备.

adb push frida-server /data/local/tmp/chmod 700 /data/local/tmp/frida-serverchmod a+x /data/local/tmp/frida-server 

转发配置，启用firda-server命令

adb forward tcp:27042 tcp:27042adb forward tcp:27043 tcp:27043adb shell /data/local/tmp/frida-server -D

Mac或其他PC上安装：

pip install frida-tools

【安装frida-tools就可以用python连接使用Frida了】

    frida   12.9.4【提供frida-trace，frida-ps，frida，frida-discover等命令】

    frida-tools   7.2.2【python使用库】

    当Frida配置好后，可以使用一些命令来做些hook操作等。

    

三、举几个栗子

命令一、查看在线设备：

        frida-ls-devices


命令二、 查看某设备的正在运行的所有应用, 返回进程ID，应用名，包名

        frida-ps -D socket -a


命令三、搜索某一类包名的应用

frida-ps -U|grep -i tenfrida-ps -U|grep -i oppo


命令四、frida 加载SSL unpinning hook js脚本。【大杀器，不解释】



https://github.com/coffeehb/FridaHook/tree/master/HTTPS%E6%8A%93%E5%8C%85%E7%9B%B8%E5%85%B3 frida-ps -U|grep -i kfcfrida -U --no-pause -f com.yek.android.kfc.activitys -l hooks.js



命令五、跟踪APP

frida-trace -R -i open com.meituan.retail.v.android

可以看到APP所有open函数的打开记录
