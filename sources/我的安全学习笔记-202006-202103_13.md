**一、准备环境：**

        MuMu模拟器、frida-server-12.8.14

连接模拟器命令：

adb connect 127.0.0.1:7555 MUMU模拟器

adb connect 127.0.0.1:62001 夜游神模拟器

adb connect 127.0.0.1:21503 逍遥模拟器

  

**二、配置frida-server**

    下载frida-server  

     https://github.com/frida/frida/releases

下载你需要的frida-server版本的包，解压出来是可执行的二进制包

部署到Android设备.

*   
*   
*   

```
adb push frida-server /data/local/tmp/chmod 700 /data/local/tmp/frida-serverchmod a+x /data/local/tmp/frida-server 
```

**转发配置，启用firda-server命令**  

*   
*   
*   

```
adb forward tcp:27042 tcp:27042adb forward tcp:27043 tcp:27043adb shell /data/local/tmp/frida-server -D
```
