# ***2、bandit***

## ***2.1 项目地址***

bandit是一个OpenStack Security下的python代码审计项目，最牛的是通过AST模块将源代码转换为Python语法树并对语法树节点进行测试的思路。其项目地址为：https://github.com/openstack/bandit

  

## ***2.2 环境部署***

操作系统  Kali2.0 Rolling

语言环境  python 2.7.13 （该工具适用于Py2.x或Py3.x）

![](../Images/8220aa20807a6df16e8c8434f7f59925.png)

 （1）   创建虚拟环境

virtualenv bandit-env

![](../Images/1eccade955aa193f3bd5b4ae4b465808.png)

（2）   安装bandit

pip install bandit

![](../Images/f7ae24a104b5a0aebde1af9486be5fa5.png)

 

## ***2.3 静态扫描***

安装成功后，直接执行bandit -r code’s path

# ***3、pyvulhunter***

## ***3.1 项目地址***

pyvulhunter是一款python注入 inject 工具，但作者已经2年没更新。主要是通过递归查找出所有可控参数，判断是否为危险函数，若是则报漏洞，其项目地址为：

https://github.com/shengqi158/pyvulhunter

  

## ***3.2 环境部署***

直接下载到本地，运行judge\_injection.py即可   

![](../Images/0155e9909f111caf17fae73e10670e49.png)

 

## ***3.3 静态扫描***

运行脚本judge\_injection.py，使用帮助参数\-h

pythonjudge\_injection.py -h

![](../Images/e1a5c9497a044b12a092e6e3b29dc4b5.png)

根据提示对代码尝试进行SQL注入扫描，

pythonjudge\_injection.py -s -d /home/Yxiu/Desktop/xxyy

![](../Images/dd79c550626193d8ba8ac85f18fa3575.png)

 

## ***3.4 结果分析***

查看终端界面中返回的内容，主要是一些untrited\_func\_name、func,record\_param等信息，结合源码判断不存在危险函数与参数。

![](../Images/236752ac8c752250189c67405fa20f80.png)

  

  

# ***4、cobra***

## ***4.1 项目地址***

Cobra定位是自动化发现源代码中大部分显著的安全问题，对于一些隐藏较深或特有的问题建议人工审计。据了解，针对python支持基础的匹配规则，但还不支持语法语义的解析。其项目地址为：

https://github.com/WhaleShark-Team/cobra

##   

## ***4.2 环境部署***

Kali-rolling中进行最新cobra的部署

![](../Images/5ba61e2247c68a08b3039d32898707e1.png)

### **4.2.1 安装特殊依赖**

apt-get installflex bison

![](../Images/ce45a3461d7b4e9306d8ff7d200e7ca7.png)

 **4.2.2 下载安装cobra**

git clonehttp://github.com/WhaleShark-Team/cobra.git && cd cobra

pip install -r requirements.txt

![](../Images/6327c854414a821d91077a0ea664af06.png)

 

## ***4.3 静态扫描***

最新版cobra安装部署已经很简单，直接执行cobra.py文件查看运行方式

python cobra.py --help
