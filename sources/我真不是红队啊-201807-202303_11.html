前言：

一直以来都想写一个自己的扫描器，但因为种种原因搁置了起来。最近因为hvv打的心疲力尽，才把这个想法付出行动。

设计思路：

我个人是倾向于一个被动式的扫描器，也就是以HTTP代理为媒介去测试我所有访问过的地址。这样省略了我自己单独去进行测试。

模块设计：

1.SQL注入2.信息泄露3.弱口令测试4.XSS5.SSRF

暂时只想到了这些，原因是这些都比较方便我们测试。可以以少量的payload且不会被WAF拦截。这一篇主要是说HTTP代理的框架设计以及信息泄露的思路。

代理初始化：

public static bool StartProxy() {

       if (proxyServer == null)
       {

          proxyServer = new ProxyServer(); //初始化代理服务器
          proxyServer.BeforeRequest += OnRequest; //添加请求事件
          proxyServer.BeforeResponse += OnResponse; //添加返回事件

          ExplicitProxyEndPoint explicitProxyEndPoint = new ExplicitProxyEndPoint(IPAddress.Any, Config.Port, true); //绑定IP以及端口
          proxyServer.AddEndPoint(explicitProxyEndPoint);

          proxyServer.Start(); //开始监听
          regResponse = new RegResponse();

          Config.form1.PortMsg.Text = $"Port:{Config.Port}";
          Config.form1.OpenState.Text = $"开启状态:开启";

       }

       if (proxyServer != null) {

           return true;

          }

      return false;

}
