### 超全局变量覆盖导致SQL注入

首先是全局初始化参数:

```
1.  `if (0 < count($_GET)) {`
    
2.  `    foreach ($_GET as $s_key => $s_value ) {`
    
3.  `        if (!is_array($s_value)) {`
    
4.  `            $_GET[$s_key] = addslashes(strip_tags($s_value));`
    
5.  `        }`
    
6.  
    
7.  `        $s_key = $_GET[$s_key];`
    
8.  `    }`
    
9.  
    
10.  `    reset($_GET);`
     
11.  `}`
     
```

上面的代码会将GET所接受的参数自动注册为变量，如下demo所示：

```
1.  `<?php`
    
2.  
    
3.  `foreach($_GET as $key => $v){`
    
4.  `    $$key=$v;`
    
5.  `}`
    
6.  
    
7.  `echo $admin;`
    
8.  `?>`
    
```

### urldecode利用不当导致SQL注入:

go.php:

```
1.  `include_once "inc/session.php";`
    
2.  `$OA_USER = str_replace(array(",", "\\\"", "\'", "\"", "'", "\t", "\\", "\\\\", "%27", "%22"), array("", "", "", "", "", "", "", "", "", ""), $OA_USER);`
    
3.  `$APP_UNIT = str_replace(array(",", "\\\"", "\'", "\"", "'", "\t", "\\", "\\\\", "%27", "%22"), array("", "", "", "", "", "", "", "", "", ""), $APP_UNIT);`
    
4.  `$OA_USER = urldecode($OA_USER);`
    
5.  `$APP_UNIT = urldecode($APP_UNIT);`
    
6.  `$query = "select MEMBER_ID from CONNECT_CONFIG where MEMBER_NAME='$APP_UNIT'";`
    
7.  `$cursor = exequery(TD::conn(), $query);`
    
```

首先使用str\_replace绕过过滤危险字符:

```
1.  `$APP_UNIT = str_replace(array(",", "\\\"", "\'", "\"", "'", "\t", "\\", "\\\\", "%27", "%22"), array("", "", "", "", "", "", "", "", "", ""), $APP_UNIT);`
    
```

然后使用urldecode解码:

```
1.  `$OA_USER = urldecode($OA_USER);`
    
```

所以我们只需要传:

```
1.  `%25%252727`
    
```
