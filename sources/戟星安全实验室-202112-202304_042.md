##   

0x00  NIM介绍

  

## 

1\. Nim 是一门开源的编程语言

2\.  Nim 的独到之处在于它可以编译成其他编程语言代码（主要是 C 语言和 JavaScript）

3\.  将 Nim与 C 语言或 JavaScript 代码集成在一起可以获得最大的价值

4\. Nim 可以生成高质量的 C 语言代码，避免出现 C 语言的典型错误（如内存泄露和数组指针错误）
