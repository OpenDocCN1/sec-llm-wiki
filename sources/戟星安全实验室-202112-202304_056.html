0x01  Frida框架介绍


frida是一款基于python + java 的hook框架，可运行在android、ios、linux、windows等各平台，主要使用动态二进制插桩技术。

1、插桩技术

插桩技术是指将额外的代码注入程序中以收集运行时的信息，可分为两种：

(1)源代码插桩[Source Code Instrumentation(SCI)]：额外代码注入到程序源代码中。

(2)二进制插桩（Binary Instrumentation)：额外代码注入到二进制可执行文件中。

●静态二进制插桩[Static BinaryInstrumentation(SBI)]：在程序执行前插入额外的代码和数据，生成一个永久改变的可执行文件。

●动态二进制插桩[Dynamic Binary Instrumentation(DBI)]：在程序运行时实时地插入额外代码和数据，对可执行文件没有任何永久改变。


你能用DBI做些什么呢？

访问进程的内存在应用程序运行时覆盖一些功能从导入的类中调用函数在堆上查找对象实例并使用这些对象实例Hook，跟踪和拦截函数等等


0x02  Frida框架安装


Frida安装部署分为两个部分：PC端和Android端

 

1、PC端

PC端使用Python安装，建议使用anaconda，不推荐直接本机里的Python，因为在本机的Python在环境变量的控制上会有一些问题（针对不同机器）。

 

Anaconda的安装和使用就不在赘述了，不难。在conda中，用 base环境就行，不需要另外安装环境。

pip install fridapip install frida-tools


2、Android端

Android端的安装最为关键，主要是两部分：模拟器或者真机的选择；frida-server下载和安装

 

（1）  模拟器或者真机的选择

针对mac m1用户这里推荐使用Google自带的模拟器，可以通过官网去下载。



部署好模拟器或者真机之后，打开开发者模式USB调试，这一点是搭配adb使用，下面有一小节列出了adb的常用命令和相关用户，不清楚的小伙伴可以继续浏览学习哦~

 

（2）  Frida-server下载和安装

 

下载地址：

https://github.com/frida/frida/releases

一定要对应手机设备架构下载，下载带有server关键字的

 

下载完之后，解压后通过adb push到设备的临时目录

adb push frida-server-12.2.25-android-arm64 /data/local/tmp/

启动frida服务并连接：

 

adb shell 进入shell环境，cd 到临时目录下，给frida-server文件设置权限

chmod 777 frida-server-12.2.25-android-arm64


然后运行frida服务文件：

./frida-server-12.2.25-android-arm64


最后进行端口转发：

adb forward tcp:27042 tcp:27042adb forward tcp:27043 tcp:27043

0x06  frida-dexdump暴力搜内存


1、介绍

Frida-dexdump是一个在内存中查找和转储dex的frida工具，已支持安全工程师分析恶意软件。

2、安装
pip install Frida-dexdump


3、使用

快速转储前台应用程序：

frida-dexdump -FU


或者像这样指定和生存应用程序：

frida-dexdump -FU -f com.app.pkgname

 

其他参数选择：

-o OUTPUT, --output OUTPUT Output folder path, default is './<appname>/'.-d, --deep-search          Enable deep search mode.--sleep SLEEP              Waiting times for start, spawn mode default is 5s.



随便找一款自带软件尝试注入：



首先，我们先要找出该应用的加载类

adb shell pm list packages -f | grep"youtube"



可以看出该类名为：com.google.android.apps.youtube.music

 

然后启动脚本：

frida-dexdump -U -fcom.google.android.apps.youtube.music

 


0x06  Objection框架


1、介绍

Objection是一款移动设备运行时漏洞利用工具，该工具由Frida驱动，可以帮助研究人员访问移动端应用程序，并在无需越狱或root操作的情况下对移动端应用程序的安全进行评估检查。需要注意的是，该工具不涉及到越狱或root绕过，通过使用objection，我们可以很大程度地降低这些安全限制以及沙箱限制。

 

Objection针对所有支持的平台，提供了下列核心功能：

-   修复IOS和Android应用程序，潜入了Frida实用工具
-   与文件系统交互，枚举条目以及上传/下载的文件
-   执行各种内存相关任务，例如列举加载的模块以及相关的输出
-   尝试绕过或模拟越狱/root环境
-   发现加载的类并列举对应的方法
-   执行常见SSL绑定绕过
-   针对目标应用程序，从方法调用中动态导出参数
-   与内联SQLite数据库交互，无需下载其他数据库或实用外部工具
-   执行自定义Frida脚步


2、常用命令
