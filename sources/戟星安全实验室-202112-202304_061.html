0x01 原理


网上很多讲解文章了，这里还是简单提一下
MySQL服务端支持（load data local infile导入数据）远程读取目标本地文件，当远程连接数据库时，蜜罐可伪造服务端向攻击者发送读取文件的恶意请求。sql语句如下：
LOAD DATA LOCAL INFILE 'C:\WINDOWS\system32\drivers\etc\hosts'INTOTABLE test FIELDS TERMINATED BY'n';


0x02 读取微信id、手机号


数据库配置，流量分析网上已经有很多文章了，不再去细看，直接上效果。
读取系统默认文件C:\Windows\PFRO.log（有个bug没解决，python socket大于4kb文件读取，实测网上方法都不行）获取到攻击者操作系统用户名，正则匹配然后取出现次数最多的为当前用户名。

res =  re.findall(r'Users\\(.*)\\AppData',  content)  # Users\Administrator\AppDatares =  Counter(res)for key,  value in res.items():    if (value == max(res.values())):        username = key  # 次数最多的认为是正在使用的用户名        break
