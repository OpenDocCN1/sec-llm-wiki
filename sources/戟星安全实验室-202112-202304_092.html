0x00 测试微信版本




0x01 burpsuite+Charles实现代理抓包


  • 下载激活

Charles下载地址（可能需要挂代理）

https://www.charlesproxy.com/

一路默认安装，使用网上的激活码激活

Registered Name ：https://zhile.ioLicense Key：48891cf209c6d32bf4


  • 配置代理



配置http和https代理为burpsuite监听，下方可配置搜索引擎不在代理范围内



0x02 通过burpsuite获取小程序包


通过微信自带代理设置方式登陆（这里不能用Charles代理，因为app类型的包它不转发）


查看微信保存路径



路径下的wx开头文件夹内有wxapkg包，但是这个是加密的（PC端加密，安卓和ios是不加密的）



这里直接删除已有的包文件夹



然后在微信中重新打开小程序



经过过后burpsuite有类型为app的通信，这里的小程序包是未加密的


直接将服务器返回右键复制到文件，以wxapkg为后缀，删除http消息头



0x03 通过解密文件获取小程序包


  • 解密工具

go版本

https://github.com/BlackTrace/pc_wxapkg_decrypt

python版本

https://github.com/kksanyu/pc_wxapkg_decrypt_python

由于go版本需要编译，在这里我下载python版使用命令格式如下：

python main.py --wxid 微信APPID --file 输入文件 --output 输出文件


  • 解密包

PC端本地的wxapkg都是加密过的，可以看到与burpsuite导出的完全不一样



使用命令解密，wxid就是apkg包上层文件夹名，输入文件用双引号避免参数错误，python3缺少加密库就用pip3命令装一下pycryptodome

$ py -3 main.py --wxid wx34b9f47827e4801d--file "C:\Users\user\Documents\WeChatFiles\Applet\wx34b9f47827e4801d\152\__APP__.wxapkg" --output dec.wxapk



解密后的wxapkg是可以直接看到一些文件路径信息的，如果看不到大概率是解密失败了




0x04 反编译wxapkg（支持分包）


  • 安装node



一路默认安装，cmd执行npm -v查看版本，表示安装成功



  • 使用图形化界面工具直接反编译


下载地址

https://github.com/xuedingmiaojun/mp-unpack

releases里面有linux和windows两种，自行选择



运行exe（自解压）



因为不一定能反编译成功，所以注意查看日志



导出压缩包，里面就是已经反编译过的小程序源文件



  • 使用wxappUnpacker反编译

下载地址

https://github.com/xuedingmiaojun/wxappUnpacker

安装依赖，实测要安装的比项目描述里多，依赖如下

npm install uglify-esnpm install js-beautifynpm install vm2npm install esprimanpm install escodegennpm install cssbeautifynpm install css-treenpm install cheerio

如果安装速度慢了就设置换源为阿里的

npm config set registry http://registry.npm.taobao.org

安装完毕后执行命令反编译wxapkg包（这里使用burpsuite保存的那个测试），程序会自动处理分包

$ bingo.bat tianfutong1.wxapkg






0x05 代码审计


  • 导入项目

安装小程序开发工具

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html



使用微信开发者工具打开导入项目




因为是反编译的代码，界面相关的大概率会问题，所以会报错，不过这不是我们关心的



  • 关键字搜索

这里已经进入代码审计阶段了，更多的是看个人经验，简单提两个简便方式

1、使用搜索功能，搜索如api.js、config.js之类的文件调用，大概率能直接看到程序接口部分




2、使用正则匹配的方式搜文件内的关键字如password、key，如

KEY.=.".*?";



user.*?name



通过正则找一下关键代码，然后看接口调用，再去burpsuite重点关注一下，可提高漏洞发现的概率


0x06 通过手机（模拟器）获取小程序包



手机安装微信后，使用adb命令导出wxapkg包

 

安卓保存路径：

/data/data/com.tencent.mm/MicroMsg/{用户ID}/appbrand/pkg/

iOS保存路径：

/var/mobile/Containers/Data/Application/{程序UUID}/Library/WechatPrivate/{用户ID}/WeApp/LocalCache/release/{小程序ID}/）


使用usb连接手机，手机开启usb调试模式（或者同时打开仅充电允许调试），执行adb命令查看设备



adb shell进入查看内部文件系统（注意手机提示授权），手机没root是无法提取的，这里我不想把个人机器root，就换模拟器吧



adb连接进入mumu模拟器（或者直接文件浏览）adb connect 127.0.0.1:7555



登陆微信访问小程序（依旧是天府通）后提取包，先确认wxapkg路径



当前路径

/data/data/com.tencent.mm/MicroMsg/489a0ea57e9feb6c08b26c78e9bff8b5/appbrand/pkg

根据大小和时间区分小程序包



adb导出命令如下：

adb pull /data/data/com.tencent.mm/MicroMsg/489a0ea57e9feb6c08b26c78e9bff8b5/appbrand/pkg/_1830473956_152.wxapkgC:\Users\stly\Download



打开wxapkg查看，是未加密的
