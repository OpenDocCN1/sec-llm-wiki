0x00 Cobaltstrike简介


Cobalt Strike是一款美国Red Team开发的渗透测试神器，被圈内人称为CS。CS分为服务端和客户端，为一对多的工作模式，团队可分布式协作操作。
Cobalt Strike集成了提权，凭据导出，端口转发，socket代理，office攻击，windows exe 木马生成，windows dll 木马生成，java 木马生成，文件捆绑，钓鱼等功能。同时，Cobalt Strike还可以调用Mimikatz等其他知名工具，广受大佬们的喜爱。

0x02 安装运行


  • 团队服务器

服务器：kali 192.168.205.134

团队服务器最好运行在Linux平台上，服务端的关键文件是teamserver和cobaltstrike.jar，将这两个文件放在同一目录下运行：


启动服务端：

./teamserver   192.168.205.134  123456

 #192.168.205.134是kali的ip地址，123456是密码


后台运行，关闭当前终端依然运行：


nohup  ./teamserver   192.168.205.134  123456     &

这里CobaltStrike默认监听的是50050端口，如果我们想修改这个默认端口的话，可以打开teamserver文件，将其中的50050修改成任意一个端口号

 


如果启动不了要赋予teamserver权限

Chmod +x    teamserver

 

  • 客户端

Linux启动：

./cobaltstrike或 java -XX:+AggressiveHeap -XX:+UseParallelGC -jar cobaltstrike.jar

Windows启动：双击cobaltstrike.exe



输入服务端IP，端口默认50050，用户名任意，密码为之前设置的密码，点击connect。第一次连接会出现hash校验，这里的hash等于前面的启动teamserver时的hash，直接点击‘是’即可连接到团队服务器上。



  • 避坑项

这里可能出现连接超时等情况



检查方法：

  1. 检查端口是否正常开启；

  2. 检查安全组是否正确配置；

  3. 关闭防火墙；

0x04 创建监听器


windows/beacon为内置监听器，包括dns、http、https、smb四种方式的监听器；windows/foreign为外部监听器，配合Metasploit或者Armitage的监听器。

点击Cobalt Strike -> Listeners->Add。

name：为监听器名字，可任意payload：payload类型HTTP Hosts: shell反弹的主机，也就是我们kali的ipHTTP Hosts(Stager): Stager的马请求下载payload的地址HTTP Port(C2): C2监听的端口

   


点击save即创建成功

  • 提权

当使用CS获取到一个权限，但是获取的当前权限较低，如普通用户或者administrator权限，我们想提到最高权限如system。可以使用提权功能

右键被控主机——>Access——>Elevate


亲测Windows Server 2008R2、 Win7及以下系统可用。Win10不可用



此时只有两个可以提权的payload



我们也可以自己加入一些提权脚本进去。在Github上有一个提权工具包，使用这个提权工具包可以增加几种提权方法: https://github.com/rsmudge/ElevateKit。我们下载好该提权工具包后



选择cna文件，点击打开

  • Sock4代理

在获取交互式shell之后，我们可以执行系统命令，如果主机在内网，要继续进行内网渗透 的话，我们可以利用sock4代理


依次点击Pivoting->SOCKS Server选项，并设定相应的端口号，此处系统默认的端口号为48224，只要端口未被占用即可





通过火狐浏览器安装proxy扩展插件，并设定sock4代理，ip就是cs的IP,配置完成以后，便可以成功访问到内网主机192.168.205.1/24的web应用


我们也可以应用 proxychains 工具，进行内网探测，参考链接如下：
