0x01前言


Windows系统渗透测试过程中从webshell拿到系统主机权限之后，会遇到非system权限的情况，由于绝大部分基础命令和信息收集对权限要求不高，加之hw实战中提权system权限对比如普通tomcat权限加分不过50。所以自己对系统提权方向研究不是很多，通过网上方法借鉴和同行hw的朋友经验，大致分为漏洞提权、配置提权、进程提权、命令提权几个大的方向，相对知识点和文章不管是否冷门都写的比较详细，这里只罗列以下部分在实战中简单有效使用的Windows服务器系统提权方式。


0x02漏洞提权


看到网上有介绍关于利用MSF、CS和evil等这些后渗透框架提权的，其文章也写了效果不够理想，感觉只能作为工具辅助。这里重点介绍以下漏洞exp的提权方式：

https://i.hacking8.com/tiquan 在线辅助提权网址，这个用的比较多。快捷方便



只需要通过目标系统主机的systeminfo命令，将其信息放到网站查询即可，可以查询到系统有没有可以利用的提权漏洞补丁。然后再根据发现的漏洞编号去GitHub查找利用就行。Tips：实际使用命令可以用systeminfo ｜more会避免一些坑。



与此同时，还有一个离线python版的Windows提权辅助工具：

https://github.com/AonCyberLabs/Windows-Exploit-Suggester



操作也相对比较简单，只需要一个漏洞的database和有systeminfo信息的txt文档：效果其实和在线版的差不多。



首先下载更新exp的数据库，这里以xls和xlsx的文档格式给出：

./windows-exploit-suggester.py--update

 


然后更新载入pip2的xlrd库：

pip2 install xlrd --upgrade

使用工具语法检测可以用来利用的提权漏洞：

./windows-exploit-suggester.py --database 2021-08-03-mssb.xlsx --1.txt



提权相关的漏洞利用exp可以从这里下载：

https://github.com/SecWiki/windows-kernel-exploits




0x03命令提权


Windows和Linux一样，也可以使用命令实现提权，但是数量方面可利用的就远没有Linux那么多。

Attention命令提权：Attention命令就是我们使用的at，经常用来定时关机。At 15:00 shutdown -s，我们可以上传cs生成的exe脚本，使用at命令定时执行，攻击机监听就可以上线system权限的主机：at 21:00 /interactive +shell目录即可。

sc命令提权：sc能与控制服务器和已经安装的设备进行通信，我们基本使用其命令：

sc [Servername] command Servicename[Optionname= Optionvalues]

按照网上的配置大概使用：

sc Create syscmd binPath= "cmd /K start"type= own type= interact

然后执行sc start syscmd,就得到了一个system权限的cmd。




0x04其他


Windows 中实现特权升级的最终目标是获得作为管理员或系统用户运行的权限，主要讨论普通权限的提升，类似于Windows系统内部使用的PsExec工具使管理员用户提权到system不在考虑的范围内。

此外，还可以利用RDP，将低权限用户添加到管理组，然后生成管理员

net localgroup administrators username /add

还可以通过抓取管理员密码hash，然后登陆管理员账号；通过黄金白银票据等等来获取管理权限等，但具体和提权的又不太沾边。以下罗列一些冷门或者有操作风险的方法：

1、替换服务提权（替换某个服务exe，比如SER-TU，可将原有的删除，再传一个同样的SER.exe上去，等待服务器重启）；

2、2003ODAY提权（如果服务器是2003的，那么就可以利用2003ODAY利用工具来进行提权了）；

3、数据库提权（mysql：数据库版本小于5.7、具有root权限、没有开启安全模式；mssql：获取mssql数据库密码的root权限使用倒入注册表执行system命令）。
