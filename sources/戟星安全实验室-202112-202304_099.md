0x01前言

![](../Images/c064c19db7f76866ee5920d442f4ae3e.png)

  

Windows系统渗透测试过程中从webshell拿到系统主机权限之后，会遇到非system权限的情况，由于绝大部分基础命令和信息收集对权限要求不高，加之hw实战中提权system权限对比如普通tomcat权限加分不过50。所以自己对系统提权方向研究不是很多，通过网上方法借鉴和同行hw的朋友经验，大致分为漏洞提权、配置提权、进程提权、命令提权几个大的方向，相对知识点和文章不管是否冷门都写的比较详细，这里只罗列以下部分在实战中简单有效使用的Windows服务器系统提权方式。

0x04其他

![](../Images/c064c19db7f76866ee5920d442f4ae3e.png)

  

Windows 中实现特权升级的最终目标是获得作为管理员或系统用户运行的权限，主要讨论普通权限的提升，类似于Windows系统内部使用的PsExec工具使管理员用户提权到system不在考虑的范围内。

此外，还可以利用RDP，将低权限用户添加到管理组，然后生成管理员

*   

```

```

还可以通过抓取管理员密码hash，然后登陆管理员账号；通过黄金白银票据等等来获取管理权限等，但具体和提权的又不太沾边。以下罗列一些冷门或者有操作风险的方法：

1、替换服务提权（替换某个服务exe，比如SER-TU，可将原有的删除，再传一个同样的SER.exe上去，等待服务器重启）；

2、2003ODAY提权（如果服务器是2003的，那么就可以利用2003ODAY利用工具来进行提权了）；

3、数据库提权（mysql：数据库版本小于5.7、具有root权限、没有开启安全模式；mssql：获取mssql数据库密码的root权限使用倒入注册表执行system命令）。
