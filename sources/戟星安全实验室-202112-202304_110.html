0x01 代理抓包




Charles和Proxifier

Charles能抓模拟器的包，但无法抓app的（估计是流量不识别），而且模拟器出口包没法精确。



Proxifier压根抓不到包。



无验证

安装burpsuite证书即可抓包https，没啥好说的，

客户端本地证书验证

burp配置，burp添加本机出网网卡抓包。



postern代理app（推荐使用），在Google Play商店下载app，这里通过在别的模拟器提取出apk包安装。



模拟器安装postern，打开app添加代理，填写burp抓包地址端口。



设置代理规则，不知道目标app访问地址，就先代理所有地址全部流量。



打开app，查看burp流量，https流量已被解密，应用域名关键字是btghl。



代理指定域名，通过域名关键字代理，过滤不需要的流量。



重新打开app后可抓到btghl的流量，再去打开浏览器访问百度，没有百度的流量，已达到流量过滤目的。

对app的反爬测试之apk逆向分析-frida绕过ssl pinning检测 - Eeyhan - 博客园 (cnblogs.com)，根据反编译结果，这个是证书加载函数，前面是证书文件流，后面是密钥

kInstance.load(iopen1, sl.toCharArray());


我们只需要导出这两个参数即可拿到证书和密钥，android证书处理总计也就那么几个函数，往这个方向搜索就好办多了


手动定制frida hook js脚本，不会smail处理没成功导出证书

function hook_password() {

Java.perform(function () {

var KeyStore =  Java.use("java.security.KeyStore");

KeyStore.load.overload('java.io.InputStream', '[C').implementation = function (inputStream, password) {

console.log("password is:", JSON.stringify(password));

console.log("cert is:", inputStream);

return this.load(inputStream, password);

}

})

}

setImmediate(hook_password)
