# Spring Cloud Gateway Actuator API SpEL表达式注入命令执行（CVE-2022-22947）

01

风险说明

  

  

  

**   Spring Cloud Gateway是Spring中的一个API网关。其3.1.0及3.0.6版本（包含）以前存在一处SpEL表达式注入漏洞，当攻击者可以访问Actuator API的情况下，将可以利用该漏洞执行任意命令。**

  

  

02

影响版本

  

  

  

  

*   **3.1.0**
    

  

*   **3.0.0 到 3.0.6**
    

  

*   旧的、不受支持的版本也会受到影响

04

修复建议

  

  

  

受影响版本的用户应应用以下补救措施:

\- 3.1.x 用户应升级到 3.1.1+;

\- 3.0.x 用户应该升级到 3.0.7+;

\- 如果不需要网关执行器端点，则应通过 management.endpoint.gateway.enabled: false 禁用它;

\- 如果需要执行器，则应使用 Spring Security 对其进行保护，请参阅\[https://docs.spring.io/spring-boot/docs/current/reference/html/actuator.html#actuator.endpoints.security\](https://docs.spring.io/spring-boot/docs/current/reference/html/actuator.html#actuator.endpoints.security\]。

已修复此问题的版本包括：

\- 3.1.1+

\- 3.0.7+禁
