# Jellyfin SSRF （CVE-2021-29490）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMjE3MjEyNQ==&mid=2247484855&idx=1&sn=39b29173e8f7cba6aff023bc96428357&chksm=c1f92a05f68ea3134ffa815a60dbc164560af27b0e38893516887be27bb505445ef9c7fcd29c&scene=126&sessionid=1681659572#rd](http://mp.weixin.qq.com/s?__biz=MzkyMjE3MjEyNQ==&mid=2247484855&idx=1&sn=39b29173e8f7cba6aff023bc96428357&chksm=c1f92a05f68ea3134ffa815a60dbc164560af27b0e38893516887be27bb505445ef9c7fcd29c&scene=126&sessionid=1681659572#rd)

01

风险说明

  

  

  

**        Jellyfin 是一个免费的软件媒体系统，它通过多个应用程序从专用服务器向最终用户设备提供媒体。10.7.3 之前的版本容易通过 imageUrl 参数遭受未经身份验证的服务器端请求伪造 (SSRF) 攻击。此问题可能会暴露内部和外部 HTTP 服务器或通过 HTTP \`GET\` 可用的其他资源。**

  

02

影响版本

  

  

  

**Jellyfin < 10.7.3**
