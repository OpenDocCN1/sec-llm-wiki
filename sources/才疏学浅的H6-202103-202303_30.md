# Metabase任意文件读取 (CVE-2021-41277)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMjE3MjEyNQ==&mid=2247484666&idx=1&sn=0b8bb4ac043c1e132d9a2b9ad81bac50&chksm=c1f92b48f68ea25ea1f012055c6b0dd5d3cfe01f4c463887e7d1b451d15217ca52f44017b071&scene=126&sessionid=1681659572#rd](http://mp.weixin.qq.com/s?__biz=MzkyMjE3MjEyNQ==&mid=2247484666&idx=1&sn=0b8bb4ac043c1e132d9a2b9ad81bac50&chksm=c1f92b48f68ea25ea1f012055c6b0dd5d3cfe01f4c463887e7d1b451d15217ca52f44017b071&scene=126&sessionid=1681659572#rd)

01

背景介绍

  

  

  
  

       近期, Metabase被爆出存在任意文件读取，攻击者可以在未经身份认证的情况下直接读取系统敏感文件。漏洞利用方式简单，影响较大，CVSS评分9.9，危害等级严重。  

  
  
![](../Images/d6f4779993f437d5122923e49487ec49.png)

  

02

组件说明

  

  

  
  

       Metabase是美国Metabase公司的一个开源数据分析平台。

漏洞源于产品的 （admin-settings-maps-custom maps - add a map 操作缺少权限验证，攻击者可通过该漏洞获得系统敏感文件。

  

        影响版本：

*   
*   

```
metabase version < 0.40.51.0.0 <= metabase versionmetabaseversion < 1.40.5
```

  
  
![](../Images/d6f4779993f437d5122923e49487ec49.png)
