漏洞说明

  

        Apache ShenYu 是应用于所有微服务场景的，可扩展、高性能、响应式的 API 网关解决方案。 

  

        Apache ShenYu Admin 存在身份验证绕过漏洞。Shenyu Admin Bootstrap 中 JWT 的错误使用允许攻击者绕过身份验证，攻击者可通过该漏洞直接进入系统后台。 

  

  

影响版本  

  

*   
*   

```
        Apache ShenYu 2.3.0        Apache ShenYu 2.4.0  
```
