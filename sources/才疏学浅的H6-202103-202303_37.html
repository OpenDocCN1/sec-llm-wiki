漏洞分析





环境搭建：本次使用docker进行的环境搭建。

首先创建一个config文件夹；

mkdir -p /home/data/gitlab/config （非root用户需要加上sudo）

新建并且进行编辑文件：

/home/data/gitlab/docker-compose.yml

gitlab:    image: gitlab/gitlab-ce:13.10.1-ce.0    restart: always    hostname: '192.168.153.142' #使用自己的IP    environment:        GITLAB_OMNIBUS_CONFIG: |            external_url 'https://192.168.153.142:8443'            nginx['redirect_http_to_https'] = true            letsencrypt['enable'] = false            nginx['ssl_certificate'] = "/etc/gitlab/nginx.pem"            nginx['ssl_certificate_key'] = "/etc/gitlab/nginx.key"            # Add any other gitlab.rb configuration here, each on its own line    ports:        - 8443:8443    volumes:        - ./data:/var/opt/gitlab        - ./logs:/var/log/gitlab        - ./config:/etc/gitlabgitlab

在同目录下新建自签名证书；

openssl req -new -x509 -days 36500 -nodes -out config/nginx.pem \   -keyout config/nginx.key -subj "/C=US/CN=gitlab/O=gitlab.com"

最后启动。
