# Spring Boot 目录遍历（CVE-2021-21234）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMjE3MjEyNQ==&mid=2247484463&idx=1&sn=40466d0dd60df34b5235580cd06aa634&chksm=c1f92b9df68ea28b207345f6224922cf75a91a54e4c3eb7077c14c9e3fd79eb2fdbba3e1cc74&scene=126&sessionid=1681659577#rd](http://mp.weixin.qq.com/s?__biz=MzkyMjE3MjEyNQ==&mid=2247484463&idx=1&sn=40466d0dd60df34b5235580cd06aa634&chksm=c1f92b9df68ea28b207345f6224922cf75a91a54e4c3eb7077c14c9e3fd79eb2fdbba3e1cc74&scene=126&sessionid=1681659577#rd)

01

风险说明

  

  

  
  

spring-boot-actuator-logview 是一个简单的日志文件查看器作为Spring Boot执行器端点，在 0.2.13 版本之前存在着目录遍历漏洞，编号 CVE-2021-21234。漏洞本质是Spring Boot 执行器通过请求的参数来指定文件名和文件夹路径，经过组合拼接达到目录遍历，虽然源码中检查了文件名（filename）参数来防止目录遍历，但是没有检查文件夹（base）参数，造成了目录遍历

  
  
![](../Images/d6f4779993f437d5122923e49487ec49.png)

  

  

02

漏洞分析

  

  

  
  

环境下载:https://github.com/cristianeph/vulnerability-actuator-log-viewer  

下载启动后，访问：http://localhost:8887/manage/log，如下图所示：

![](../Images/b96474d73c58a1e1dfc401373e03270a.png)

多么熟悉的小黄叶啊～～～

通过访问不存在的文件报错，可以定位到漏洞触发的点：

eu.hinsch.spring.boot.actuator.logview.LogViewEndpoint.view

![](../Images/867e02d156d06fd6db8dcf0809233cf1.png)

定位到源码处：

![](../Images/6363c13951975ec8c35641c4a1c2d823.png)

看到view方法接收了文件名（filename）和路径（base）参数，通过securityCheck方法对文件名进行了安全检查，定位到该方法：  

  

![](../Images/fee4f7240ba3874734d5caa6211c164c.png)  

Assert断言filename中是否存在"..",有则报错，无则通过，神奇的检查！  

通过Debug看到并没有对base的检查，检查了个寂寞！  

![](../Images/971300768632600be7b452e3acb85c4c.png)  

![](../Images/80a0b2758ebeca2d9dbddb0653a3ba8a.png)
