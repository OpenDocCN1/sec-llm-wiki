# **0x01、确定目标**

当你看见了某厂家SRC有活动的时候，要先确定SRC收录范围，有很多大厂的收录范围其实很大 但是网站写出来的会很少，但是他会写等，举个例子，以京东SRC为例![](../Images/ff19b5c5e7c75ba9ecf218932f68e2d2.png)这个域名有一个等字，说明收录范围有很大 不止上面这些，我们可以把和京东有关联的域名都收集到一起 范围越大 资产就会越多，同样的你比别人挖到的漏洞可能就会越多。  

* * *

  

# **0x02、icp备案查询**

我们可以看一下爱企业查 或者企查查之类的企业信息查询来找厂商的关联厂商或者控股公司等，关注一下股权穿透图。这里给大家推荐一个工具 是狼组师傅们开发的（原谅我只是白嫖）作用就是企业基本信息（法人、电话、公司地址等等）· 企业ICP备案号以及网站· 企业APP信息· 企业微信公众号信息· 企业微博信息· 子公司的基本信息· 供应商信息· 等等https://github.com/wgpsec/ENScan使用截图可以看一下输入公司名字![](../Images/cfabfe6ab6ba7b709456166ca40fc12e.png)最后会生成一个表格文件![](../Images/f16955fc550ba34d97416101b5b6c61f.png)这里有很多域名可能是百度的子公司 或者是一些其他项目 这些域名自己划分一下然后进一步收集其他信息 百度也是会收的不局限于SRC平台给的域名 给的可能是核心业务边缘业务也是会收的 而且边缘业务可能安全性做的没有核心业务那么好。

# **0x0****5****、子域名工具收集**

拿到域名了我一般就开始收集子域名了子域名收集有两种形式 有通过whois之类的api接口查找的 还有一种是靠字典去爆破。子域名不光有子站之类的 也有可能会存在后台 登录系统等比如这个的子站就是一个后台管理![](../Images/2d26cf50d03086543c6c9bbf4f3e72c1.png) 推荐一个工具（Oneforall） 这个是靠着api来收集子域名的工具 （我比较推荐使用这种 这种不会占用系统资源 而且会很快）https://github.com/shmilylty/OneForAll  
使用方法：![](../Images/ac1bdfc0654990631e428e987d2baa8d.png)跑完以后会生成一个表格文件 ![](../Images/602c9fc0a9fd1870026c3b40a55b4112.png)也会有一个文本![](../Images/7f90c60bd1b2a6454457bb51ef836bfb.png)收录范围其实很大，只有你细心就会发现有很多资产的 把域名收集全以后再进行。
