0x00 背景介绍

Lotus  Domino/Notes 主 要 由 四 个 部 分 产 品 组 件 组 成 ：Domino  Server 、Administrator、Notes 和 Designer，其中 Domino Server 是服务器，其余是客户端应用程序。


Lotus Domino Server 是服务器端组件。一般分为 Domino 邮件服务器、Domino 应用服务器和 Domino 企业服务器三类。经过对配置文件的设置，就能实现办公自动化系统协同工作、工作流管理、信息发布和共享等功能。

Domino 结构的核心技术是对象存储机制，是结构的基础，基础之上就是存储对象的相关操作服务，第三层是应用程序接口(API)。


Lotus Domino Administrator 是用来管理 Domino 服务器的客户端。它不执行日常操作，而是可以让用户从相关界面便捷的实现所有管理操作，包括注册用户信息管理、数据库配置、配置文件设置、跟踪、状态统计等用户和服务

器的管理。


Lotus Notes 是客户端应用组件。它提供了友好简单的操作界面供用户使用，是日常工作环境平台。通过连接 Domino 服务器，实现日常工作中的电子邮件的收发、日程安排和提醒等功能。


Lotus Domino Designer 是客户端应用开发环境。它是一个针对 Notes/Domino 数据库使用的开发工具，能够操作各种 OA 系统的元素。它使开发员轻松构建符合需求的应用程序。


Domino Server、Administrator、Notes 和 Designer 能够构成一个工作流管理系统。

.NSF 扩展名代表 Notes Storage Format（.nsf），是一种数据库格式，也称作应用程序，通常由 Lotus Notes 客户端和 Domino 服务器使用。这些数据库的其中一些例子包括 Names.nsf、Admin4.nsf、Log.nsf 及用户的邮件文件。


Names.nsf，也称作 Domino Directory，其中之前的某些版本称为 Public Address Book 或 Name and Address Book，此数据库可由每台服务器上的 Lotus Domino 自动创建。Domino Directory 是有关用户、服务器和群组，以及可能会添加的自定义项的信息目录。它包含 Server 文档 Configuration Settings、Person 文档，及 Domain、Connection 和 Internet Site 文档。Domino Directory 也可作为管理员用来管理 Domino 系统的工具。

http://192.168.3.173/names.nsf

Log.nsf，每台 Domino 服务器均含有日志文件（LOG.NSF），可报告所有的服务器活动，并可提供有关该服务器数据库和用户的详细信息。日志文件会在首次启动服务器时自动创建。

http://192.168.3.173/Log.nsf

Admin4.nsf，Administration Requests 数据库（ADMIN4.NSF）可在首次启动服务器时自动创建。Administration Process (AdminP)将要执行的工作请求储存在 Administration Requests 数据库中。

http://192.168.3.173/Admin4.nsf

0x03 后台命令执行

Domino Web 应用服务器检查外来请求中的 URL，并确定该请求针对的是 Domino 数据库中的文档还是文件系统中的 HTML 文件。如果请求针对的是 HTML 文件,将同任何其他 Web 应用服务器一样,为 Web 客户端提供文件服务。若请求针对的是 Domino 数据库中的内容， Domino 将与数据库交互作用，为 Web 客户机处理消息,或将信息从 Web 客户机存入数据库。
