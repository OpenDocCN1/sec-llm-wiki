# 域渗透中使用 DCSync 获取明文密码细节记录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU3MTU3NDk4Mw==&mid=2247484055&idx=1&sn=b8731a4405e1d903381a969568f2efd5&chksm=fcdf5d3fcba8d429755b7bbf0d2a4c046f9ccf378e258e97ad4df625e4a9a4ee94e391fa48b9&scene=126&sessionid=1681400847#rd](http://mp.weixin.qq.com/s?__biz=MzU3MTU3NDk4Mw==&mid=2247484055&idx=1&sn=b8731a4405e1d903381a969568f2efd5&chksm=fcdf5d3fcba8d429755b7bbf0d2a4c046f9ccf378e258e97ad4df625e4a9a4ee94e391fa48b9&scene=126&sessionid=1681400847#rd)

0x00 背景

进行内网渗透时，会经常使用到 DCSync 技术去导出域内所有用户 Hash 。如果练习多的话，在不同环境中使用 DCSync 获取到的结果大部分是密文的情况，但是在有的环境中获取到的结果是明文。今天正好有空闲时间就看了下，如果在AD用户与计算机中创建计算机或者用户时，选取特定配置项，再修改密码，使用 DCSync 可以获取到明文密码。

  

0x01 DCSync 获取密文 Hash

获取用户帐户列表

command：net user /domain

![](../Images/ebe69ed7c137b84f2aa6b65798cfdab2.png)

  

DCSync 获取指定用户 Hash

command：dcsync de1ay.com mssql

此处获取 mssql 用户的 Hash 值，如下图所示，返回的是密文 Hash。  

![](../Images/0a4280b35ea1b55e22e459794df4180d.png)

  

0x02 DCSync 获取明文密码

添加域用户

用户名：C4

口令：1qaz@WSX

![](../Images/e1bac669ad09da55b278a68e51b65f2a.png)  

  

设置用户属性-使用可逆加密存储密码

在Active Directory 用户和计算机中创建新用户，在创建用户时勾选使用可逆加密存储密码。

![](../Images/8c26bf233cad1a27d136266342e0785a.png)

  

DCSync 获取用户明文密码

command：dcsync de1ay.com c4

![](../Images/986630631b0d55de0cc6b3e9a8ca63d6.png)
