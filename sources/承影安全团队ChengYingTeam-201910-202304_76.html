源码分析

反编译 weblogic.jar 文件，查看 weblogic.application.utils.PathUtils.class 发现生成路径名称方法：

    public static String generateTempPath(final String s, final String s2, final String s3) {
        final StringBuffer sb = new StringBuffer();
        if (s != null) {
            sb.append(s);
        }
        if (s2 != null) {
            sb.append("_").append(s2);
        }
        if (s3 != null) {
            sb.append("_").append(s3);
        }
        return s2 + File.separator + Long.toString(Math.abs(sb.toString().hashCode()), 36);
    }

大佬文章对此进行深入分析，利用公开代码可获取随机路径。
