0x01 企查查等企业查询平台

企查查作为一个查询企业各种关系的平台，各种资本关系都囊括其中，资本的关联情况也是信息收集时应该注意的一个要点。我们要通过这些平台来关联出和目标有相关的各种公司、各种关系。

  

举个栗子：

某次拿到自己的渗透目标为【a.com】上的某系统的某权限，当我们对【a.com】所在的系统摸排完之后发现并没有可以突破的点，此时我们通过企查查等平台关联发现，【a】公司还有下属公司【b】【c】【d】，并且其中【d】是一个科技型的公司，专门开发各种信息系统，其中有部分直接提供给【a】使用，那么我们就可以针对【d】继续开展信息收集。

  

通过上述查询我们可以获取的信息如下：

*   
*   
*   
*   

```
xxx a 科技有限公司  对应域名：a.comxxx b 科技有限公司  对应域名：b.comxxx c 科技有限公司  对应域名：c.comxxx d 科技有限公司  对应域名：d.com
```

0x02 网络空间搜索引擎

常用的几个搜索引擎无非就是fofa 、shadon、 zoomeye (已经自断双臂，现在不香了)。下面我一一列举我在信息收集阶段都会做的一些操作。前面通过企查查得到一些域名，虽然还不够全，但是我们已经可以根据扩展出来的信息进行进一步的信息收集了，此时我们可以重点关注【d.com】来进行信息收集，在此我也详细列举一些常见的收集方法。

  

fofa重点语法  

fofa第一式：domain大法

语法：*domain="d.com"*  

![](../Images/fb7b7caf58908e740109f75750816655.png)

  

语法解读：

1.  可获取一部分二、三甚至N级域名（需要注意的是，直接是域名的对应的IP很有可能是CDN的IP）
2.  一部分IP地址，甚至是地址段（需要筛选掉CDN，剩下优质/纯净的IP做好记录）

  

语法扩展

重点看下图：  

![](../Images/04734fe5e551b316581390b3eed6c22a.png)

  

如图中【1】处寻找状态码为301、302跳转的域名，点击【2】的箭头，需要关注的字段如下：

1.  Organization
    
2.  CommonName
    
3.  DNS Names
    

对应的字段自己打开看吧  

  

fofa第二式：cert大法  

语法：*cert="d.com"*  

查询证书为【d.com】的资产同时适用于上面通过domain语法查到的各种域名，扩大攻击面。

  

语法解读  

1.  获取所有证书为【d.com】的域名，IP资源
    
2.  获取的域名、IP资源全部真实有效
    

  

提升汇总现有资源

通过domain、cert两个语法，我们可以获取大量ip、域名资产，接下来就要针对这些资源进行总结提升。

需要做以下几方面的事情：

1.  IP资源汇总排序（这一步主要目的是确定目标IP段资产）
    
2.  N级域名汇总（这一步主要目的是获取该目标域名命名规律，为后期猜解一些关键信息提供支持）
    
3.  去除冗余信息，根据域名、IP，确定业务段。
    

  

现有信息扩展

根据上面的资产，大致划分目标IP段资产，进行分段资产探测。

再举个栗子：

确定一个疑似目标IP段为：1.1.1.1/24

语法：IP=“1.1.1.1/24”

  

语法解读  

列出所有这个ip段的资产信息，进行业务识别与漏洞匹配。此步骤会列出各种服务，需要我们仔细甄别是否为目标的资产。

篇幅限制，其他几个大数据搜索引擎用法类似，只是语法不一样，照这个思路来就可以了。

  

0x03 本信息收集方式优缺点  

优点  

1.  避免大规模扫描，引起目标警觉，所有操作都是在第三方平台上进行的信息收集。
    
2.  收集信息准确度高，资产收集更全面。
    
3.  容易收集到一些敏感的服务信息。
    
4.  条理性强，逻辑思维清楚。
    

  

缺点

1.  信息收集过程中，目标规模越大，数据处理越耗费时间、精力。
    
2.  需要手工操作识别的东西较多。
    

  

0x04 总结  

信息收集作为渗透测试最基础的一个环节，也是最重要的一个环节，信息收集全不全面决定了你之后攻击面的大小，也决定了你能否拿到目标的权限。

  

*\*注：此方式为红队队员应该必备的技能，同时也适用于各种护0网、攻防演练的场景，还适用于各种SRC挖洞，实用性还是比较高的。*

*\*注2：方法只是方法，此方法搭配车轮战术会有意想不到的效果。*
