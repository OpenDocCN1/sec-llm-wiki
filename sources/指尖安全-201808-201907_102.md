## **概述：**

近日phpcms2008版本被爆出可控的缓存文件写入任意内容漏洞，该漏洞由type.php产生

![](../Images/17b573a26e5c9b4a14b3990cd6b7696b.png)  

我们可以看到$template参数可以由外部传入，只进行了是否为空的判断直接就传入template()函数继续执行，template()函数在/include/global.func.php文件中。

![](../Images/41e14e5f6a3942dd0ec6bd68e19a921d.png)  

在template()函数中中，$template参数交给了template\_compile()函数处理，而template\_compile()函数在include/template.func.php文件中：

![](../Images/7287db89d9c414cf0de3fc2b2df7a428.png)  

我们来看第七行

```
$compiledtplfile = TPL_CACHEPATH.$
```

```
TPL_CACHEPATH
define(
```

最后直接生成路径被写入content中导致漏洞的产生
