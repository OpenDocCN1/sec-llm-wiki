# 苹果最新版本Mac和MacBook疑似内置比特币白皮书

来源：钛媒体

钛媒体App 4月6日消息，据Bitcoin Magazine发推特透露，比特币白皮书已预装在苹果苹果最新版本的Mac和MacBook上，可通过简单的终端命令或导航 Finder打开，在Finder终端中输入以下命令：

```
1.  `open /System/Library/Image Capture/Devices/VirtualScanner.app/Contents/Resources/simpledoc.pdf`
    
```

用户需要导航到 Macintosh HD -> System -> Library -> Image Capture -> Devices。按住 Control 单击 VirtualScanner.app 并显示包内容，然后打开内容 -> 资源文件夹 -> simpledoc.pdf。

![](../Images/389c84632e444d1c7439255f43ba3357.png)

VirtualScanner.app 是一个虚拟扫描仪应用程序，允许用户通过 macOS 系统中内置的 Image Capture 应用程序扫描图像。 它可以将虚拟扫描仪的输入数据从应用程序路由到其他应用程序。VirtualScanner.app 可以与多个不同类型的应用程序兼容，并允许用户通过设置扫描选项来扫描文档或图像。VirtualScanner.app 通常用于测试或调试扫描设备的兼容性。

据悉，比特币白皮书被用作名为“Virtual Scanner II”的设备的示例文档。此设备对某些用户是隐藏的或默认情况下未安装。有用户猜测，苹果公司或将通过相关功能从比特币交易中赚取佣金。
