# 如何通过Android手机查找IP地址

我们的手机是怎样通过Internet发送数据并且每次都到达正确的目的地？答案是通过IP地址。Internet协议（IP）地址是一串数字和符号，主要是分配给网络或连接到该网络的设备后，登陆互联网使用。

![](../Images/1f1d66306840c460fe1fd36acbb48efb.png)

我们可以将IP地址视为信件的回信地址，将信件视为Web请求。数据包在网络发送之前使用IP地址进行编码。像Android手机这样的设备首先连接到网络，然后在通过手机访问网络。**所以****IP地址****网络和****手机****需要唯一的标识符—本质上是两种类型的地址****：****公网IP地址和****私有****IP地址。**

![](../Images/16f9774c87a88a18401bb23156612d32.png)

**互联网服务提供商****（****ISP****）****为****你****的网络分配一个公共IP地址，该网络为连接到各个设备提供私有IP地址。**

Internet协议（IP地址）是有两个版本：IPv4 和 IPv6。Internet协议版本IPv4只有40亿个唯一地址。但随着越来越多的设备上线，全世界的 IPv4 地址都快用完了。IPv6 随之诞生，IPv6 的使用是无限的，它解决了IP地址数量不够的问题，但IPv6的构成更复杂。

相对于IP地址的宏观使用，我们个人通常可以使用IP地址排除和修复一些常见的连接问题，那么我们要如何获取IP地址？其实有一个简单的方法，在Android手机上查找IP地址也很简单，只需要几个步骤，公网IP地址的查询过程更加简单。

**如何在Android****手机****上查找公共私有IP地址****和公网IP地址****？**

**一、Android手机查找私有IP地址**

我们先来看看你的安卓手机的私有IP地址。通常私有IP地址对于 Android 智能手机是唯一的。

可以通过以下步骤查找，同时有些 Android手机可能使用略有不同的菜单布局或语言，界面略有差别：

*   **打开****手机****设置**
    
*   **找到关于手机**
    

![](../Images/9738ebff3002aede7e85878808826cb6.png)

*   **查看Android手机状态信息**
    

![](../Images/9aac1e2c2d1f983a4331ed1adb991b6a.png)

这时你就可以看到你的Android手机私有IP地址显示在状态页面上。

![](../Images/9cf33075acb13bf648a78dbf9bb897c4.png)

我们也可以通过 Wi-Fi网络的详细信息连找到Android手机私有IP地址。

①打开设置应用程序。

②转到 Wi-Fi 并连接到您的网络。

③点击网络名称以显示其详细信息，可以在底部找到私有IP地址。

手机制造商之间的菜单标题可能略有不同，但用户界面应该或多或少相似。如果连接成功的话私有IPv6 和 IPv4 地址将一起列出。

**二、Android手机查找公网IP地址**

**公网****IP地址更容易找到。**因为连接到同一网络的所有设备是共享一个公网IP地址，因此当你的Android手机与你的笔记本电脑或游戏机具有相同的IP地址，是很容易通过多种方式查到的。但是当连接到公共Wi-Fi或朋友的网络时，IP 地址会发生变化。

①在您的 Android 手机上打开首选浏览器。

②导航至https://www.ipplus360.com/或者https://www.ipuu.net/Home等IP地址查询网站，在网站的首页可以直接查看你手机网络的公网IP地址信息。

![](../Images/2d53b1668fedce92e44e7e4d97f196e5.png)

因为你是通过IP地址访问互联网，一般情况下IP地址查询网站会自动识别。如果你不喜欢这样，可以考虑在Android手机上下载并设置VPN服务。
