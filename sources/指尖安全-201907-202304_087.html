导语

今天给大家介绍关于国内外数据服务商的IP定位查询免费API接口的测评，一共整理了有十多家服务商的多维度测评内容，包含有网站名称、免费查询入口、定位结果和价格等等。鉴于篇幅过长，将分为三期推送。

我们使用统一的IP地址，在各个API上进行查询，分别是Ipinfo、ipgeolocation、纯真，同时结合公司介绍、技术、API价格、返回字段等多维度进行测评，今天将推送第一部分。我们一起来对比看一下吧。

Ipinfo

公司介绍

l 网站名称：https://ipinfo.io/

l ipinfo成立于2013 年，公司团队属于全球分布型，成员分布在5大洲和10个不同的国家，共有18名工作人员。

l 主要业务为IP地理位置查询API、vpn代理监测。合作客户有NIKE、CBS、Tencent、NPM、Graylog等，合作过的客户高达100000+。

API查询

查询接口地址：https://ipinfo.io/

返回字段：Ipinfo产品有9种，除了IP地理位置查询API外还有ASN信息、公司信息、隐私信息、滥用信息和域等API。

价格

ipinfo有免费版本，其余版本是按照次数收费，基本版：15万次查询99美元/月，标准版：25万次查询249美元/月，商业版：50万次查询499美元/月，也可根据需求定制。

ipgeolocation

公司介绍

l 网站名称：https://ipgeolocation.io/

l 由巴基斯坦拉合尔的JFreaks Software Solutions开发建设的。ipgeolocation专长包括数据分析和基于位置的应用程序开发。

l ipgeolocation 的诞生源于客户相关的项目中对IP定位的服务的需求。2018年5月发布了 API 的第一个公开版本。

l 数据库包含超过2500万个IP地址范围，是全球最大的IP数据提供商之一。通过专有爬虫每天扫描所有注册表中的IP地址分配，并将其位置跟踪到城市级别的准确性。除此之外还有与 ISP合作以及用户报告的条目保持数据库最新状态。

API查询

查询接口：

https://ipgeolocation.io

https://ipgeolocation.io/ip-location/

返回字段 

1. IP地理位置定位API：

准确的IP位置查找

  

2. 天文学API：

提供日出、日落、月出、月落、太阳方位角、月亮方位角、太阳高度、月亮高度、太阳与地球的距离和月球与地球的经纬度或者IPv4、IPv6 地址的时间日期。适用于热爱摄影、远动、旅行、天文学等场景。 

Comprehensive Sun and Moon data：通过提供关于给定日期和位置的黄昏时间、不同的太阳和月亮参数返回字段如下。


Getting Astronomical Information from a Location Coordinates：可以通过一个位置的纬度和经度作为查询参数来获取天文信息。


Getting Astronomical Information from an IPv4 or IPv6 Address：从 IPv4 或 IPv6 地址获取天文信息。


3.时区 API：时区 API 提供时间和日期相关信息

Detailed Timezone Data：详细的时区数据。

价格

ipgeolocation发展十分迅速，ipgeolocation的产品有三款IP地理位置定位API、天文学API、时区API这三款产品都可以免费使用但是每月有限定次数，超过次数就要收费，返回的字段和信息都不相同，也可以根据自己需求进行定制。

纯真

网站名称：https://www.cz88.net/

公司介绍

l 2005年，纯真IP库正式上线。作为一个免费的IP库，纯真在过去近20年时间里，为国内互联网行业IP数据库行业的运营和构建奠定了珍贵的基础。

l 纯真IP数据库主要针对国内数据，缺少海外数据。

l 在IP归属地的风口下，2022年的夏天纯真被BRT（上海腾徽软件科技有限公司）收购，正式走上了商业化的道路。


API查询

返回字段：纯真API的返回字段，除了基础的地理位置以外，还有蜜罐、秒拨等安全信息反馈，剩余的信息是按照版本进行展示，也可根据需求定制。


价格

纯真api按照次数收费，不同版本有不同价格，也可以根据个人需求定制。 

总结


我们通过对比表来看一下三家地理定位的区别，三家IP地理位置查询结果Ipinfo是中国-广东省-深圳，显示到城市。ipgeolocation是香港特别行政区-九龙-黄大仙区。


纯真IP地理位置API为中国－河南－郑州－金水区、IP实验室商业版为中国－香港。


三家整体对比基本定位都可到城市，纯真和ipgeolocation可以到区县。


除了地理定位API，每家其他产品也有所不同，IPinfo有VPN也就是虚拟网络检测结果；IPgeolocation的API，还有专门的天文学API与时间API，返回信息有日出日落等时间信息更多样化，应用的范围和行业更为广阔；而纯真的API精确度可以到区县，同时还有蜜罐和非真人检测，对网络安全更有帮助。
