## **导语**

今天给大家介绍关于国内外数据服务商的IP定位查询免费API接口的测评，一共整理了有十多家服务商的多维度测评内容，包含有网站名称、免费查询入口、定位结果和价格等等。鉴于篇幅过长，将分为三期推送。

## **ipgeolocation**

### **公司介绍**

l 网站名称：https://ipgeolocation.io/

l 由巴基斯坦拉合尔的JFreaks Software Solutions开发建设的。ipgeolocation专长包括数据分析和基于位置的应用程序开发。

l ipgeolocation 的诞生源于客户相关的项目中对IP定位的服务的需求。2018年5月发布了 API 的第一个公开版本。

l 数据库包含超过2500万个IP地址范围，是全球最大的IP数据提供商之一。通过专有爬虫每天扫描所有注册表中的IP地址分配，并将其位置跟踪到城市级别的准确性。除此之外还有与 ISP合作以及用户报告的条目保持数据库最新状态。

### **总结**

![](../Images/8d5c85f153fbc314faf27f1f62acf2df.png)

  

我们通过对比表来看一下三家地理定位的区别，三家IP地理位置查询结果Ipinfo是中国-广东省-深圳，显示到城市。ipgeolocation是香港特别行政区-九龙-黄大仙区。

  

纯真IP地理位置API为中国－河南－郑州－金水区、IP实验室商业版为中国－香港。

  

三家整体对比基本定位都可到城市，纯真和ipgeolocation可以到区县。

  

除了地理定位API，每家其他产品也有所不同，IPinfo有VPN也就是虚拟网络检测结果；IPgeolocation的API，还有专门的天文学API与时间API，返回信息有日出日落等时间信息更多样化，应用的范围和行业更为广阔；而纯真的API精确度可以到区县，同时还有蜜罐和非真人检测，对网络安全更有帮助。
