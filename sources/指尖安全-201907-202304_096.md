# 境外黑客组织正在对我国网络设施发起攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNDk0MDQ3OQ==&mid=2247487790&idx=1&sn=0cb6620f4c55ad8bcb93f2165ca98cee&chksm=fa24f4fecd537de80787af753e5c42b94465b8ac4e50a3fd1a03e344980c7af5cd58a98c4c38&scene=126&sessionid=1681312476#rd](http://mp.weixin.qq.com/s?__biz=MzUyNDk0MDQ3OQ==&mid=2247487790&idx=1&sn=0cb6620f4c55ad8bcb93f2165ca98cee&chksm=fa24f4fecd537de80787af753e5c42b94465b8ac4e50a3fd1a03e344980c7af5cd58a98c4c38&scene=126&sessionid=1681312476#rd)

近期，根据推特用户蓝黄蜂 @\_Blue\_hornet 推文，境外黑客组织以我Guo资助ELS为由针对性的对我国网络设施发起有组织的网络攻击，并在twitter及tg公布了数个单位系统源码，指尖安全随即对其进行了跟踪。

从该组织近期公布的源码分析，该黑客组织利用了近期公布的Spring Cloud Function SPEL RCE，该漏洞可直接获取服务器权限，使用该系统的单位应尽快升级整改。

  

影响版本：Spring Cloud  3~3.2.2

  

![](../Images/6e2323c835c31badaa54ff1d15c54fb7.png)

安全建议：

  

1、及时下架服务器，切断黑客攻击路径，全面自查。

2、除了漏洞修复，查杀后门，还应排查相关服务器、容器、中间件、数据库等等...

3、如数据已经发生泄露，鉴于我Guo政务内网安全现状，有条件的建议进行全面内网排查，以防更大层面的数据泄露事件！

4、老生常谈，安全无小事，及时补丁、及时升级！
