```
1.  `  1. Capture the request using burpsuite.`
    
2.  `  2. Send the request to burp scanner.`
    
3.  `  3. Proceed with active scan.`
    
4.  `  4. Once the scan is finished, look for SQL vulnerability that has been detected.`
    
5.  `  5. Manually try SQL injection payloads.`
```
