# 天融信网络安全公开课

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNDk0MDQ3OQ==&mid=2247486895&idx=1&sn=9c4112de6cbd9fed3af55216828d9bc1&chksm=fa24e87fcd536169fadbc8ffc85a5094872d7e3ef3c383c281571f6391144a644380b1255d03&scene=126&sessionid=1681312511#rd](http://mp.weixin.qq.com/s?__biz=MzUyNDk0MDQ3OQ==&mid=2247486895&idx=1&sn=9c4112de6cbd9fed3af55216828d9bc1&chksm=fa24e87fcd536169fadbc8ffc85a5094872d7e3ef3c383c281571f6391144a644380b1255d03&scene=126&sessionid=1681312511#rd)

近年来，网络安全受到国家和社会各界的广泛关注，没有网络安全就没有国家安全。在信息时代，网络安全对国家安全牵一发而动全身，网络安全为人民，网络安全靠人民，维护网络安全是全社会共同的责任，需要政府、企业、社会组织、广大网民共同参与，共筑网络安全防线。网络安全公开课 第二期专门针对热爱网络安全行业的爱好者开设，课程包含情报收集、Web测试、服务器沦陷、密码的生成与爆破、内网端口转发、DDoS和CC攻击、智能手机安全共7节内容。为行业专业人士提供独特的安全视角，全面提升网安爱好者的安全认知能力。
