但是该方法在实际的运用中局限性还是很大的，因为在 mssql2005 及其以后，mssql对系统存储过程做了权限控制，`Ad Hoc Distributed Queries` 组件默认是不被启用的。

![](../Images/55b540a9c80aab201600f1d682c1d4e5.png)

*   开启 Ad Hoc Distributed Queries 组件
    
    ```
    exec sp_configure '
    ```
    
*   关闭 Ad Hoc Distributed Queries 组件
    
    ```
    exec sp_configure 'Ad Hoc Distributed Queries',0 reconfigure exec sp_configure '
    ```
    
*   查看是否开启相关存储  
    \`\`\`sql  
    select name,value\_in\_use from sys.configurations where name like ‘%Ad Hoc Distributed Queries%’
    

select name,value\_in\_use from sys.configurations where name like ‘%cmdshell%’
