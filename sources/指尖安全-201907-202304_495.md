# 腾讯布开放安全中台，能否撬动千亿安全市场？

随着数字化时代加速到来，以5G、AI、IoT、云计算与量子通信等新科技不断发展，推动数字化经济呈现蓬勃发展态势，但科技创新所带来便利的同时也面临着越来越复杂多样的安全风险。

  

# 网络安全市场将达千亿级，腾讯布局网络安全to B市场

  

新技术普及和应用，数字化进程加速到来，网络安全作为一个新兴产业也得到了全球众多国家政策大力支持，此外，企业安全面临数字化时代也日益严峻，近年来，全球网络安全市场呈爆发式增长。依据IDC预测，全球IT安全相关支出到2019年将增长9.4%至1031亿美元，到2022年将达到1338亿美元。

  

值得一提的是，中国作为全球最具活力市场，人工智能与物联网得到迅猛发展，并伴随5G网络部署，万物互联成为可能，各界对安全需求剧增，到2022年中国网络安全市场将达到千亿的规模。腾讯安全玄武安全实验室负责人TK教主在CSS互联网安全领袖峰会上表示，中国网络安全市场规模从由2016年200亿，增长到今年6月份已经达到600亿。

![](../Images/2baec4e8ebdf700e0a4055d66f4cb2ea.png)

另外，依据IDC最新调查报告显示，到2023年中国IT安全硬件市场规模将达到110亿美元（约760亿元人民币），未来5年年复合增长率为25.5%，可以看出安全市场的需求增大。

  

# 伴随万物互联发展趋势，安全威胁也在急剧扩张

  

随着企业部署物联网规模日益扩大，以及业务上云，企业能得到快速创新，伴随而来也面临越来越多未知安全风险 ，尤其产业互联网时代到来，安全威胁更加隐蔽、复杂，也更具破坏性。企业应对安全安需求也强劲，避免带来巨大损失。

  

寻求产业转型升级的企业要如何应对产业互联网下的安全挑战，实现高质量发展，是亟待解决的问题。传统安全解决方案，也已无法满足数字时代“安全原生”的属性和日益复杂的业务场景安全需求。

  

![](../Images/be6d374cbc8a27a5c0b802dac4221722.png)

CSS互联网安全领袖峰会上，腾讯云与智慧产业总裁汤道生分析产业互联网时代，安全发展的两大特点：一是产业互联网时代安全威胁突发性更强、破坏性更大，一旦遭遇网络攻击，可能造成极大社会影响和经济损失；二是产业安全降本增效价值逐步显现，已成为数字时代企业核心竞争力之一，在金融、零售领域尤其明显。

  

为此，腾讯宣布开放多年积累的安全中台能力，降低企业客户的安全建设门槛，致力于成为产业数字化升级的安全战略官。据腾讯副总裁丁珂介绍，腾讯通过多年积累的安全中台打造了一个可对外复用的动态的安全模型，为企业客户提供模块式、可迭代的安全服务。

  

# 传统安全遇挑战，企业如何应对新型安全威胁

  

企业安全建设不再只是CIO和CISO事情，已上升为企业CEO一把手工程。企业的CEO需要牵头以战略视角进行安全规划，从情报、攻防、管理和规划维度，构建企业的“安全战略观”，将过去被动防御的模式升级为主动防御体系。这在面对不断扩张的黑灰产引发的薅羊毛、金融欺诈、广告点击欺诈、拖库撞库等业务安全问题，尤为重要。

  

腾讯拥有自主可控的安全技术以及云、管、端一体化的安全运营体系，海量的业务场景，十亿用户的服务经验。在过去20余年的发展中，腾讯积累了大量的黑产大数据样本，每天数百P的数据运营能力，这些是腾讯安全对抗黑产攻防的武器。

  

腾讯开放的基础安全能力和平台业务能力，能帮助企业应对转型过程中不断出现的新业务、新场景的安全需求。腾讯安全推出的“灵鲲、星云、天御”等几大业务解决方案，在泛金融、泛互联网、智慧零售等领域都有非常好的实践和应用，并且取得了不错的成效。

    

如果说能力开放是流水线生产出来的商品的话，腾讯还将为客户打造摆满商品的货架，更进一步的提出配送服务和全程的质保。腾讯通过安全中台打造了一个可对外复用的动态安全模型，为企业客户提供模块式、可迭代的安全服务，既可以为小企业提供情报攻防、规划管理的模块能力，也可以帮助大中企业构建属于自己的安全中台，将腾讯的安全能力和范式输出，进而具体的服务于客户的业务场景

  

腾讯副总裁丁珂再次表示，产业互联网时代发展带来企业上云需求，给安全产业发展带来很多增量市场机遇；以往中国传统安全在企业IT投入占比只有3%左右，但在腾讯智慧政务等项目实践中发现，一些新业务场景的安全占比已经远远大于这一比例，产业数字化发展带来的安全市场变量日益显现，腾讯希望和安全产业链伙伴携手共建、共享产业安全增量红利。

  

腾讯将全面开放多年积累的安全中台能力，并按需被集成到生态伙伴的解决方案中，实现能力与产品互补，提升生态伙伴的安全服务能力及业务竞争力。马斌认为，安全行业伙伴各有所长，作为P17的发起者，腾讯愿意将自己深入产业互联网实践，服务10 亿级用户及海量业务场景所积累的安全大数据、技术共享给生态伙伴，与大家强强联合，优势互补。

需要指出的是，网络安全攻防的本质是人与人之间的较量，目前我国网络安全人才培养与行业需求严重脱钩。截止目前我国培养专业网络安全人才10万人，预计到2020年，网络安全人才需求将达140万人。

  

由于高端网络安全人才匮乏，腾讯在网络安全人才方面也早有布局，此前腾讯网络安全学院和国内多所高校达成了合作协议，对安全人才建设，搭建产学研合作交流平台，最终形成发现、培养、转化生态链。通过腾讯安全旗下的赛事品牌TCTF平台选拔有潜力的学生，再通过腾讯安全联合实验室的“言传身教”提供专业培养机会和就业资源，同时还将有机会参与国内外顶级信息安全赛事，形成一个由高校理论教育到企业技能培养到国际赛事锻炼的完整人才培养闭环。
