CSS是谁？

互联网安全领袖峰会（Cyber Security Summit，简称“CSS”）是由腾讯公司、中国电子技术标准化研究院等企事业单位共同创办，得到了国家网信办、工信部、公安部等国家部门的大力支持和指导。由腾讯主办的 CSS 正在演变成一个由全球企业共同构建的网络安全平台。

峰会始终致力于聚合互联网产业领域与网络安全行业的力量，共筑“互联网产业安全交流与合作平台”，共建“互联网安全新生态”，进而推进产业快速、稳定创新，为国民经济的升级转型和蓬勃发展做出贡献。

互联网安全领袖峰会于 2015 年首届举办以来，四年来共吸引来自互联网金融、智能汽车、物联网、智能硬件等多个热门产业领域的顶尖企业 500 余家参与，是全球规模最大、价值最高的互联网产业安全交流与合作盛会。

CSS2019与以往有何不同？

第五届互联网安全领袖峰会（简称“CSS2019”）由腾讯主办，以“产业升级 安全升维”为主题。主题背后凝结的是腾讯安全在产业加速数字化转型背景下对安全价值的重新思考：互联网发展进入下半场——产业互联网时代，传统产业与数字科技加速融合，带来生产内容和生产模式的本质变化，安全不再仅仅是产业发展的命脉和底线，已经成为核心生产力之一。

本届大会共设置7大特色专场：TSec腾讯安全探索分论坛、金融安全专场、云安全专场、大中型政企通用安全专场、Future Power 50安全新锐力量专场、大交通安全专场、产业与安全标准化专场。大会将联动安全产业各群体，邀请包括安全上市企业领袖、新锐安全力量、学术界安全先锋到来，对金融安全、云安全、大数据安全、大交通安全、产业与安全标准化等领域的未来趋势进行探讨和预测。

6、【TSec腾讯安全探索论坛】

主题：前沿科技尖端对抗

时间：2019年7月31日 全天

专场介绍：腾讯安全探索论坛（TSec）是腾讯安全打造的一个全球前沿、尖端安全技术的高质量安全信息交流平台，也是互联网安全领袖峰会（Cyber Security Summit，简称“CSS”）的重要组成部分。TSec聚焦当前最具含金量与亮点的云安全、移动安全、物联网安全以及人工智能等多领域的安全技术，为全球信息安全的发展，提供学术和技术创新支持。TSec不仅仅是一个全球信息安全领域尖端技术展示与未来趋势探讨的盛会，更作为全球前沿技术首发地，加速技术创新、共享重要技术成果，持续提升连接价值，搭建一个长期、持续的沟通合作平台，让更多国内外尖端安全研究、前沿安全技术在这里汇聚。
