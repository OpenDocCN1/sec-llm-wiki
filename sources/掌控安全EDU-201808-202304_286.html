一

前言

2019年11月26日，kali Linux官网发布了Kali Linux 2019.4发行版，此版本和之前相比变动很大，系统界面、主题、壁纸都灿然一新。

最重要的是！Metasploit更新到了5.0版本！

这是他们自2011年4.0版本发布以来的第一个重要版本，包括数据库和自动化API，新的规避功能以及整个系统的可用性改进。”

2019.4涉及到的一些新更新内容包括：
（1）默认桌面改为XFCE，替换为原有的Gnome。
（2）使用新的主题模式Undercover，更接近于Windows桌面。
（3）Kali-Docs迁移到GitLab网站。
（4）使用BTRFS，支持系统更新后回滚。
（5）重新引入软件包PowerShell。
（6）Kali NetHunter引入Kex Manager，支持HDMI外接显示器。
（7）支持8GB的SD卡。
（8）加上正常的错误修复和更新。





二

下载

首先去kali官方https://www.kali.org/downloads/ 
下载新版本的镜像文件可根据自己需求选择。

如果是虚拟机建议下载这个版本，有vmware和virtualBox（根据需求选择64位或者32位，现在一般都是64位）




三

安装

下载完成后找个自己合适的位置解压缩包
（一般不要在c盘你懂的）
找到后缀位vmx的文件，右键选择使用vmware打开

 

打开之后直接点击开启虚拟机，（选择我已复制）初始用户名为root密码为toor。

 


四

注：下载的vmware和virtualBox的版本不需要换源，但需要更新。

更新源和更新软件（遇到选项一路回车让他默认就好）。
 

 

五

解决中文“麻将问题”

1.在命令行输入”dpkg-reconfigure locales”。进入图形化界面之后，（空格是选择，Tab是切换，带*是选中），选中zh_CN.UTF-8，确定后，将zh_CN.UTF-8选为默认。
 
界面下选项，上下键可以下拉，排序为从a-z排序，空格选中语言，tab键切换到ok，再回车确认进入下一步

 


在这里我们用上下键选择语言zh_CN.UTF-8后tab切换到确认直接回车

 


 

2.做完这些后在终端输入：apt-get install xfonts-intl-chinese  和 apt-get install ttf-wqy-microhei 来安装中文字体

 

3. 终端输入：reboot重启 系统，到登录界面，右上角语言列表注意是否为zh_CN.utf8,点开列表，确定选中的为中文-中国

 


注：登陆之后如果字体没有切换成功，那么再重启选择一次
