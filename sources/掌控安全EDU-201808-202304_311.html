什么是GPS？

我们通常所说的 GPS 全球定位系统是由美国国防部建造完成，目前在太空中共有31颗卫星在同时运作，一般我们需要至少4颗卫星来完成三角定位。（这就是为什么需要北斗）

GPS卫星同时发送民用L1和军用L2两种无线信号. 我们通常使用的是没有加密的L1民用 1575.42MHz 的超高频波段。



2

为什么GPS能够被欺骗呢？

GPS“用户端”接收卫星所发送给它的信号，从而让它知道自己现在在哪里，这种传播是由卫星单向传输给GPS接收器的。


如果我们想办法模拟卫星信号，从而发送一个虚假的信号给GPS接收器，那么目标会接收到我们GPS 模拟器所发送出的信号，而不是卫星的信号。


为什么目标无法分清卫星？

这里有一个先决条件：GPS模拟器所发送的信号需要比卫星发送的信号强。

而卫星在太空中发送，信号传播经过了很多距离，这一点很容易做到。


是不是感觉太过儿戏？

是的！实际上内网中的ARP欺骗，无线广播电台的RF劫持，都是类似的原理。

比如：假如我模拟好电台的发射源，然后将射频全频段覆盖时，附近路过（被我信号覆盖）的所有行人、车辆接收端，都会被劫持，即：无论调频至任何段，收到的都是我们所设定好的内容。

无人机

我们讲一讲无人机案例，技术分析后再做防御分析



劫持
这事儿大家一想就很简单了，飞控主要也是依赖于GPS。
早在2011年的时候，伊朗就在跟阿富汗接壤的地区，捕获了一架美国的RQ-170隐身无人侦察机，近年新闻又曝出伊朗捕获了美军最新的MQ-9死神无人机（捕获能手啊）。

此项技术的基本操作是：通过电子信号干扰使其进入自动驾驶状态，再适配无人机，重新校准其GPS 使其改变飞行航线。


民用

无人机“黑飞”事件时有发生，除了劫持还可以怎么简单解决呢？
禁飞区：无人机在禁飞区是不能起飞的，即使是到达了禁飞区也会自动降落。
基本操作：模拟禁飞区GPS信号，使其以为预设的程序控制飞机自动降落。

使用HackRF小试GPS欺骗

实验环境：HackRF、GPS、天线


1、GPS 信号里包含了3种常用信息：

Pseudorandom code:简单的ID码, 用来识别每颗卫星.
Ephemeris data:包含卫星的运行状态, 时间日期等信息,这在通过卫星来定位时起到非常重要的作用.
Almanac data:包含有每颗卫星的轨道信息，以及卫星在某个特定时段将出现的具体位置.


2、下载编译GPS仿真器代码（gps-sdr-sim）

git clone https://github.com/osqzss/gps-sdr-sim.git

cd gps-sdr-sim

gcc gpssim.c -lm -O3 -o gps-sdr-sim


3、查询你想要的GPS经纬度信息

http://www.gpsspg.com/maps.htm

（例如：无锡东站：百度地图：31.6032020000,120.4665760000）

然后按照这个经纬度信息来通过GPS仿真器生成GPS仿真数据

./gps-sdr-sim -e brdc3540.14n -l 31.603202,120.466576,100 -b 8



如果要是欺骗时间，则可利用-T参数

-T 2017/10/11,07:00:00 -b 8


4、用HackRF来发射我们在步骤3中模拟生成的伪造数据即可

执行结束后，当前目录会生成gpssim.bin文件，这个文件保存的就是我们模拟生成的GPS数据。

ackrf_transfer -t gpssim.bin -f 1575420000 -s 2600000 -a 1 -x 0

（命令参数解析：指定GPS数据，用-f来指定频率为1575420000 ，即民用GPS L1波段频率，用-s来指定采样速率2.6Msps，开启天线增益，指定TX VGA(IF)为0）



完成上述步骤

劫持无人机 - GPS欺骗难点

在高端场景的实际劫持应用中，有两个难点。

1、对频，如果无法和劫持目标适配，那么信号再强也无济于事。

2、解密，传输数据如果被加密，需破解加密功能，才可模拟。

XN297L芯片的具体通信状况

从数据报文里面可以发现PID码仅仅只有两个比特位，因此这里使用的PID并不是为了防止重放的，而是用来去除重复数据报文的。
仅仅两个比特位的PID码可以在短时间内遍历，所以重放应该是可行的，确认了这一点之后，就可以展开下面的劫持操作了。
