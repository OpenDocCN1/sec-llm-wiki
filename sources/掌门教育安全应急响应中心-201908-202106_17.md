# 掌门教育SRC上线啦~

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NTMxODExNQ==&mid=2247483657&idx=1&sn=20051100411aa81edf4f401d485d49db&chksm=ebef4f85dc98c693db72761bef8b9aff74ecede11d918df48221b97f7f4227c512d0fe7e5df3&scene=126&sessionid=1681381597#rd](http://mp.weixin.qq.com/s?__biz=MzI4NTMxODExNQ==&mid=2247483657&idx=1&sn=20051100411aa81edf4f401d485d49db&chksm=ebef4f85dc98c693db72761bef8b9aff74ecede11d918df48221b97f7f4227c512d0fe7e5df3&scene=126&sessionid=1681381597#rd)

       掌门教育安全应急响应中心（Zhangmen Security Response Center）上线啦！官网地址：https://security.zhangmen.com。

  

        作为一家负责任的互联网在线教育公司，掌门1对1非常重视信息安全问题，为此组建了信息安全部并持续加大安全投入，我们一直在不断努力提升自身安全能力和完善、优化公司整体信息安全体系。

  

        为了邀请并鼓励安全圈的资深人士、专家、白帽子、团体和个人积极参与并提交高质量的安全漏洞，我们承诺，对每一位报告者反馈的问题都会有专人确认、评估、跟进并及时反馈最新处理进展，并且根据《掌门教育安全漏洞处理流程和评分标准》给予感谢和奖励。
