# 骗局揭秘-银行短信验证码

随着互联网技术的不断发展，网上银行、手机银行等新兴互联网支付手段给我们的日常生活带来了很多方便。然而，一些不法分子却利用这些产品的安全认证不完善以及用户安全意识淡薄的特点，展开一连串的诈骗骗局，造成用户的经济财产损失。  

  

如下让小编详细介绍这种典型的诈骗案例，并分析其原理，提醒大家提高安全意识，谨防上当受骗！

  

  

****事件回顾****

1. 小李接到一个电话，对方声称是某游戏公司的“工作人员”。说发现小李使用了尾号为0849的银行卡刚进行了一笔消费，用于其公司的游戏点卡，购买金额为5800元。银行基于安全考虑，特打电话询问此笔交易是否本人操作，若不是，可以协助其取消该交易。小李一听，非常紧张，因为他确实有一张尾号为0849的卡，但是卡还在他的手里呢，怎么会有这种消费呢。银行“客服”人员表示，请小李先不要惊慌，先自行通过网银等手段查询一下余额是否存在异常，稍后其会再次致电。

  

2. 电话挂断之后，小李急忙查询了一下自己的银行卡的余额，一查吓一跳，发现卡里竟然真的少了5800元钱。

  

3. 正在焦急之时，刚刚的电话号码再次来点。小李向其确认了自己账户确实有余额减少的情况。对方表示，他们已经将该笔交易拦截，可以帮小李操作退款，稍后会有一条短信发送到小李的手机上，只要小李提供一下收到的6个数字，资金就又会退到小李的账户上。

  

4. 果然短信来了，但在短信上除了有六位数字的验证码外，还明确写着“您正在进行一笔转账操作，请勿将本验证码告诉任何人”。

  

5. 小李此时觉得此事有蹊跷，果断挂断了接到的电话，并拨打了银行的客服电话。银行客服人员听了小李的描述后，明确表示，其遭遇了电话诈骗，切勿相信，并向其揭秘了本骗局。

  

  

**骗局揭秘**

**原来，小李此次遇到的就是当前非常“高端”的电话诈骗行为。****骗子的诈骗手段如下：**

**用户个人信息搜集**

首先，骗子团伙中有一些技术人员，专门负责收集用户个人隐私数据。他们通过多种渠道和手段获取用户的姓名、身份证号码、手机号码、常用邮箱、常用银行卡号、常用密码等数据。其中姓名、手机、邮箱等数据可能会来源于我们日常生活中再各处留下的联系方式，如快递、办会员卡登记单等。但那么机密的密码是怎么获取到的呢？

  

其实，这些数据通常来源于一些黑客对网站的入侵。黑客利用网站的漏洞获取网站数据库权限后，获取了用户敏感的信息，其中可能就包括用户登录的密码内容。这些庞大的数据组成了一个叫社工库的系统（社工：社会工程学的简称）

  

![](../Images/78469c6ef2cb11fab7979a5f8c571caa.png "QQ截图20151209164044.jpg1449650690227")

  

网上也会有一些社工库平台。这些平台整合了大量被盗取的用户信息，提供了可查询的界面，只要输入你常用的用户名、邮箱、qq号等，你的密码信息可能就一览无余。

  

![](../Images/116a442042d5e811855f058818451968.png "QQ截图20151209164135.jpg1449650709827")

  

**尝试登录用户的银行账户**

有了这些用户的个人信息后，诈骗团队就会利用这些数据去试着登录用户的网银、电话银行等系统。如果用户安全意识不强，恰巧银行的密码与被泄露网站登录的密码相同，则诈骗人员可以对其账户进行基本的操作，该用户也就成了潜在的被诈骗对象。

  

![](../Images/8e289f88a184876fd68d983cdbb07820.png "QQ截图20151209164149.jpg1449650727862")

  

**制造恐慌情绪**

很多银行的电话银行、网上银行等为了用户理财的方便，在购买本行推出的理财产品、贵金属等产品时，只要登录成功不需要额外认证，即可快速进行消费。

  

这种给用户的便利竟然成了骗子们实施诈骗中利用的一个重要漏洞。他们使用被盗账户中的部分余额购买了银行的理财产品。由于活期余额与理财分属不同的账户，因此在查余额时，确实会出现余额减少的情况。同时，由于资金一直在账户的总额中，因此部分银行不会发送短信将该类操作造成的资金变动通知客户。（其实此时通过拨打银行客服电话，或网银自行操作，可以将理财的钱再转回活期账户，用户资金并不会减少。）

  

**转账骗局**

骗子会利用受骗者焦急的心理，借机通过网银等，操作该账户进行转账操作。注意，此时是真正的转账行为，将把资金转到他行其他账户。而支付的凭证，最重要的内容就是短信验证码。一旦这个内容被骗子拿到，钱就很难再追回了。

  

  

**防范手段**

**了解骗局之后，我们需要在以下方面必须加强防范。**

 **1. 切记：不要将短信验证码告诉任何人**

这点切记，不要将验证码短信告诉任何人。同时，在短信中，通常也会标明此次验证码的用途，如转账、登录认证等。一定要对此类信息予以关注。

  

![](../Images/e7c50290b19324e6188c102b42a5b35d.png)  

  

**2、加强个人安全意识**

在不同的网站注册，应尽量使用不同的密码。同时，应注意个人隐私保护，不要轻易提供个人的手机号码、真实姓名、身份证号码等。

  

**3、移动端安全**

不要在手机上安装不知名的小软件，因为这些软件很可能会劫持你的短信验证码、银行卡账户等敏感信息，并利用这些信息进行交易。

另外，在使用手机、平板电脑时，不要轻易root或越狱，因为这样将给应用程序非常高的权限。

  

**4、防范虚假银行客服电话**

银行的号码通常为5位的短号码。若大家接到其他号码声称为银行客服，大家一定要加强防范。

另外，在接到电话时，若号码非+86开头，也一定要当心了。如接到电话号码为+1 95588，那也不是真正的银行客服号码，因为+1并不是中国的地区电话编码。这可能是个网络电话。

  

**5、当心伪基站**

一些诈骗人员会利用伪基站技术，利用运营商的漏洞冒充银行的号码发送虚假短信。为防范这种工具，大家可以在手机上安装“搜狗号码通”等相关软件来识别伪基站短信。

  

  

**一些银行的应对措施**

当前，部分银行针对这种骗局已经调整了购买理财产品的支付验证手段，购买理财产品时，也需要输入短信验证码，方可购买。
