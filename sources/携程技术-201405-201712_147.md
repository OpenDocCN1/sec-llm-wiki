# 资讯 | 携程人工智能成果再获全球顶级学会AAAI认可

国内在线旅游企业的科技感越来越浓。上周，携程旅行网在上海密集展示了一系列新科技成果。近日，携程科研团队撰写的深度学习主题的论文成果，又被大洋彼岸的顶级学术会议AAAI（美国人工智能协会）录用。这也意味着，携程在人工智能+旅游细分领域的研究达到国际前沿水平。

  

AAAI是国际人工智能领域的顶级学术会议，其论文代表当今人工智能技术研究的最高水准，它既是AI学术泰斗讨论和发布学术成果的主阵地，也是Google、微软等公司的AI知名项目成果论文的重要出版机构。如今，携程也正式迈入了AAAI顶级科技企业成员。

  

据悉，这篇题为《A Hybrid Collaborative Filtering Model with Deep Structure for Recommender Systems》的论文，是携程基础业务部BI团队基于其自主研发的通用化推荐系统而撰写。该推荐系统项目此前还获得上海经信委专项基金支持，在携程内部上线一年来，已取得显著的业绩提升效果。

  

据携程技术中心BI团队负责人于磊介绍，不同于传统OTA企业的技术产品，该推荐系统采用了大量人工智能技术，比如论文中提及的深度神经网络的自动编码技术。该系统目前陆续落地了50余个个性化场景，取得巨大的业绩提升，有些场景的转化率甚至提升了13倍之多，极大地提升了携程用户在产品购买以及实际出行中的体验。

  

今年以来，携程网已经在人工智能技术获得诸多突破。不久前，携程呼叫中心正式上线了新一代机器人系统，客服机器人处理业务已占机票预订客服总量的近40%。携程也是首家大规模使用客服机器人系统的在线旅游公司。此外，携程网还推出智能门锁、酒店空气检测、专属客服等一系列技术创新产品。

  

据Q2财报显示，携程在研发领域的费用支出接近40%，远高于其对标的美国在线旅游网站 Priceline，甚至也高于Google、Amazon等“技术派”科技企业。从这一方面看，携程成为技术公司的野心不容小觑。受此利好影响，华尔街预测携程营收和利润将快速增长，2017年运营利润率将攀升至20%。
