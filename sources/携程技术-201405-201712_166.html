10月23日，由携程技术中心主办的React Native Meetup在携程上海总部凌空SOHO举办。关于React Native话题的火热程度，先上图你们来感受下。



携程技术中心相关负责人表示，作为上海互联网的领军企业，携程希望通过搭建这样的平台，逐步构建起上海的技术分享氛围，让上海技术圈的小伙伴，也能有更多的选择和机会，在一起交流、学习和进步。


React Native Meetup上都分享了哪些精彩内容？




《React Native优化实践》——赵辛贵


赵辛贵目前主要负责React Native框架在携程内部的使用推广和性能优化。


在他看来，RN框架自身还不够成熟，稳定性、性能，和Native相比，都还有一定的差距。为了让RN达到类似Native的体验和稳定性，以及将该技术尽可能低成本的引入到携程各个业务团队，提高开发效率，他们对RN做了大量优化。


在本次分享中，他介绍了携程的 Ctrip React Native 框架的组成和业务应用情况；以及对 React Native 的性能优化，包括携程在 React Native 拆包（各业务独立打包，实现动态更新）、页面预加载（实现页面秒开）等多方面的性能优化方案。




《React Native项目实战之火车票业务探索之旅》——姚瑞琼


作为一枚91年的年轻程序媛，姚瑞琼从2016年年初开始就主要负责 React Native 方案在火车票业务线的实践，先后参与并负责汽车票RN独立版、携程App抢票RN版的开发迭代。目前在携程上线的RN页面中，火车票事业部占了一半以上。


为什么火车票业务线对于RN如此感兴趣？姚瑞琼介绍说，火车票BU作为携程体系下的重要环节，要兼顾良好的App用户体验及迅速的业务迭代，一个月左右一个App版本的节奏很难满足，而React Native跨平台、媲美原生App的用户体验以及无需发版的升级模式等优势无疑让人眼前一亮。


在分享中，她着重介绍了火车票在RN实践过程中踩过的坑和对应的解决方案。




《波罗蜜全球购的RN实践》——好大


好大是波罗蜜的移动技术经理，也是公司的早期员工，主要负责移动端的开发。


对于波罗蜜来说，随着其业务量和业务范围的增加，采用原生的方式越来越难以满足日益增加和变化的需求。他们同样需要一套更加灵活的技术框架更快更好地支撑业务，同时获得更好的用户体验，所以其选择了 React Native。


在“吃螃蟹”的过程中，波罗蜜遇到了很多需要解决的实际的工程问题。在分享中，好大主要介绍了在“波罗蜜全球购”中 RN 的使用情况以及如何搭建一个“简单，实用，可靠”的 RN 发布系统。




而在最后的圆桌环节，活动进入高潮。场上讲师和场下的程序员们，就RN实践中最大的挑战、RN和H5的融合以及RN的发展前景等等问题，展开激烈的讨（si）论（bi）。
