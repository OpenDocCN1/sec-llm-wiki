# 第三届携程UED产品设计大会圆满落幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MDI3MjA5MQ==&mid=401848957&idx=1&sn=e87088efbf00cb5a1ac2a5da28b64cbe&chksm=344045490337cc5f28134b115abebf245ced9767b7e0330fc0dc919e592175377a4680cf56d3&scene=126&sessionid=1681375347#rd](http://mp.weixin.qq.com/s?__biz=MjM5MDI3MjA5MQ==&mid=401848957&idx=1&sn=e87088efbf00cb5a1ac2a5da28b64cbe&chksm=344045490337cc5f28134b115abebf245ced9767b7e0330fc0dc919e592175377a4680cf56d3&scene=126&sessionid=1681375347#rd)

12月19日，以“数据时代的产品与设计”为主题的携程UED产品设计大会在上海壹秀秀场完美落幕。自2013年创办以来，携程UED大会因云集业界大牛，分享干货众多而在同业间树立了良好口碑。今年的大会更因硅谷知名数据专家张溪梦、Twitter前产品设计负责人Cennydd Bowles等重量级讲师的出场而备受关注，观众云集，场面火爆！

会议当天，携程网CTO叶亚明先生率先登场，他在直达主题的简短演讲中分享了“走出你的庐山”主题：颠覆的力量常来自外界，虽然渐行渐进但一旦质变发生便不可逆转，行业中人却往往“身在此山中”，对变化失去了敏锐判断，因此要“识得庐山真面目”，就该勇于变革，走出自我束缚的圈子。之后，出自互联网名企的资深专家向在座千余位产品经理、UED从业者及院校学生分享了他们在工作中如何运用数据的力量设计出更加符合用户需求的产品。

![](../Images/dcaaaf1af723ab4dec291bda85075e69.png)  
携程旅行网CTO叶亚明

Twitter前产品设计负责人Bowles结合他的工作经验，系统地阐述了产品设计各阶段所面临的挑战与机会，并指出互联网行业并非简单由数据驱动，而是经由数据引导，推动业务；GrowingIO创始人，前Linkedin高级总监张溪梦认为，针对用户的指标须以数据衡量并可从数据中洞悉更多信息，Linkedin通过数据对比辨识出产品不同生命周期中用户的细分类型，快速部署分析任务后，快速得到结果并迭代到产品中。而Yahoo亚太区移动产品与设计总监李怡洁通过台湾Yahoo的几个成败案例，形象说明了设计需针对目标而非仅作为手段，优秀的产品设计须在转化率指标外更有超越用户预期的惊喜。去哪儿集团副总裁、地面事业部CEO胡洁则从业务层面讲述了去哪儿地面门票部门在数据指导下，短期内快速扩张的经验。

稍后的圆桌论坛上，来自携程、同程和去哪儿三家主流OTA的产品负责人与来自在线旅游新锐自在客、跟谁游的创始人坐而论道，就在线旅游行业的产品与创新、市场发展趋势等话题展开头脑风暴，合作互补外也不乏针锋相对，不同观点和理念碰撞出新鲜的思想火花。  

![](../Images/e81d029ba57597b6012357794c892485.png)  
  

当天下午的交流则由来自百度、天猫、京东、微软、点融、车享网、自在客、美人记及携程网的专家们用实实在在的案例分析与讨论，从在线旅游到互联网金融，从O2O生活服务到车享平台，各行各业应运大数据背景所创造的产品与设计，及其背后蕴含的理念转变给在场听众留下了深刻印象。

  

不少与会者表示，这样规模的产品设计分享在上海互联网业界尚不多见，希望以此契机，推动同行间交流互动，共同加速进步，为用户创造更多优质的产品与使用体验。
