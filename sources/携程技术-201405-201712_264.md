# 2015 Ctrip Cloud Meetup 圆满落幕！

编者注  

随着云计算技术的日益成熟，越来越多互联网企业开始使用开源云平台方案构建自己的私有云，实现各类资源（计算、网络、存储）的弹性扩展，提高运维效率，最终实现应用的快速部署，为互联网业务争取宝贵的时间。近年来，开源云计算平台OpenStack 助跑互联网企业实现第一代云计算平台的搭建，做到了应用的小时级发布。如今，Container 技术的兴起，为下一代云平台实现分钟级别甚至秒级部署提供了可能......

  

12月5日，由携程主办的2015 Ctrip Cloud Meetup在携程总部凌空SOHO举行。虽然天气寒冷，天空中还飘起了小雪子，但丝毫没有阻挡技术爱好者参加这次活动的热情。参加此次技术盛宴的既有互联网公司的技术总监、OpenStack开源社区的技术大拿、也有战斗在云计算第一线的开发者和DevOps们，还有热心钻研前沿技术的同学们。大家借此齐聚一堂，分享一手的实际经验，从不同的角度探讨云计算技术问题。

![](../Images/339bc766cb389459a830f2e807582d79.png)  

  

活动开场，携程旅行网CTO叶亚明先生（Eric）为大家带来了一个主题为《In and out of history 》的简短演讲。Eric的到场充分体现了携程对云计算的重视与支持，值得一提的是携程私有云和桌面云就是在他的大力主导下逐步形成今天的规模。他回忆20年前在美国初识Amazon产品的情景，结合IBM与微软的故事，提出了一个很有意思的现象：行业颠覆者往往都是外行，而且是带来“麻烦”的破局者。同时，Eric还带来一张有趣的曲线图，显示着一个颠覆行业的创新者可能前十年都如同冰山一样潜伏水底，等到时机来临，出现的则是几何数量级的爆发成长。Eric在最后提到：“历史是无法做A/B Testing的，如果携程没有在三年前开始着重发力无线应用，肯定就会在今天痛失良机。” 之后的问答环节，Eric特地拿出从硅谷带回的奖品，鼓励大家提问。互动中引人深思地就“浮出水面”的标准给出了他的回答：让大众都知道并真正使用你的产品。

![](../Images/c210d9bcc656d3465442d4b35eb24fc8.png)  

![](../Images/76f062a5a8fc2344cc342294d0c7b1e4.png)  

  

第一个分享是来自蚂蚁金服的“吴老板”吴峥涛。他给大家带来了《蚂蚁Ant Container Service介绍》。吴老板给大家介绍了ACS的背景, 对比了开源社区的成熟方案: kubernetes, swarm/compose, 介绍了docker生态圈的基本情况, 针对如何使用docker, 吴老板基于传统企业对容器使用的真正需求, 列举了业界主流方案的利弊，极大的开阔了大家的视野, 也给正在考虑使用容器的同行们提供了极有意义的参考. 最后吴老板还介绍了ACS Driver/Plugin的技术细节，给大家带来了一场真正意义上的干货演讲。

![](../Images/40122db8ce7c037ff577cb7023301f89.png)  

  

美团云的网络研发专家叶晋阳，为我们带来的是《SDN在美团云的应用》。早在2013年美团云就将全部服务迁移到云上了，此次分享也是关于sdn相关实践的干货。美团云平台涉及私有、办公、公有各个方面，涉猎很广。叶晋阳首先介绍了美团使用Open vSwitch和Openflow实现网络拓扑分发服务的方法（通过分布式的网络控制器，来对整个网络进行路由管理），阐述了ovs的优点和一些美团的历史经验，分享了基于VXLAN的虚拟网络方案，并预告了很多将要发布的公有云功能，真是值得期待。  

![](../Images/797fdfd62781b943fd27c67e919e80cc.png)  

  

短暂午休之后，技术爱好者们又早早的聚集在会场等待下午的第一场分享。

![](../Images/8de1a923df067dc4802229ed5cc21775.png)  

  

下午第一场是来自京东的鲍永成，介绍了《京东私有云技术之路》。京东云由虚拟机、容器及裸机组成，使用OpenStack进行管理。京东很早就基于OpenStack进行二次开发，容器服务也于一年半前上线，针对公司内部情况在很多地方进行了自己的定制，自研、重写了很多组件。针对集群部署，京东使用预先做好的镜像，自研了一套配置工具进行部署、升级，避免了很多坑。最后分享了京东的troubleshooting经验和DevOps心得。携程和京东有着很多相似的技术背景，在这次分享会上携程的工程师向鲍永成先生热情的咨询和探讨，双方觉得受益良多。  

![](../Images/ffb67b5e9ab666891c4ef7cc38e37405.png)  

  

《BGP在Neutron中大行其道》是“大师兄”龚永生携同IBM美女工程师朱娜带来作为Openstack核心网络组件的neutron的前沿技术分享。BGP即边界网关协议，是运行在TCP上的一种自治系统的路由协议，当下，Neutron中越来越多的特性在引入BGP，从而提高系统的可扩展性或者进一步扩大Neutron的外延。龚永生及朱娜分享介绍了BGP的概念和在neutron中的应用，通过大胆假设、小心求证，全面详细的讲解了neutron中最前沿的BGP应用。BGP的到来给Openstack网络提供了又一份色彩，开源使人越发有新的思考。BGP的引入也许代表着传统网络技术厂商欲证明他们仍然宝刀未老，让我们拭目以待！

![](../Images/79f6a40f4ab00f52d439cc38f5c24ebc.png)

![](../Images/d9c1e90c2b7f30e0542d3774d9806548.png)

  

UCloud苏元鹏带来的分享是《海量对象存储平台的设计与运营之道》。什么是好的架构设计？苏元鹏告诉我们：好的架构并不是非常复杂的架构，而是简单高效的架构，能够保持可用的架构。好的架构，应该要做到高内聚低耦合，要有清晰的层次结构：接入层、业务逻辑层、存储层，要能够互相分离，能够平滑扩展。UCloud在雪崩保护和容灾的解决方案中，系统能够将轻量和重量的任务分离，在需求超过系统能力的时候选择拒绝部分请求以免发生雪崩，并且动态调整策略，将突发事件对整个系统的影响降到最低。而容灾，需要系统按照各模块的重要程度进行划分，选择不同的容灾措施，以免在出现灾害时整个系统崩溃。

![](../Images/417a9df5e0a46cc4928c0b5d0f07eb5d.png)  

  

最后压轴的是携程罗勇和刘俊分享的《Ceph在携程的落地》。携程云平台研发经理罗勇首先描绘了携程云团队的新规划，然后详细介绍了今年私有云和桌面云取得的成果。接着，资深存储工程师刘俊上台介绍了ceph在携程的落地过程。刘俊首先介绍了携程目前使用的存储服务的现状和规模，接着介绍了Ceph的部署架构和工作原理、Ceph RGW的数据流、Ceph RBD中kRBD和Qemu RBD的区别和选择。以酒店图片特征值和跨数据中心持续交付这两个场景，讲解了如何应用Ceph满足业务部门的使用需求，其中跨数据中心持续交付使用了携程云团队自主设计开发的跨数据中心数据同步解决方案－COS。在分享的最后，刘俊介绍了两个携程的存储规划：网盘以及MySQL测试环境。

![](../Images/f9e8bce58304853d7562b4469d31678b.png)

![](../Images/3f234990b9f05d34d771fe06c787f837.png)
