# 携程获中国著名商标金奖

近日，第二届“中国商标金奖”评选结果公示揭晓，携程旅行网作为唯一一家在线旅游服务企业入选“商标创新奖”，提供优质服务是携程深耕旅游业16年来始终不曾改变的宗旨，也是被众多用户认可的原因所在。据了解，日前，携程客户服务部高级总监裴晓丽等还受邀参加了“全国工商行政管理部门12315消费维权业务培训交流会”，分享了在客户服务领域的多年积累与心得。

![](../Images/e0516df444d2411282043b8784b175cd.png)

优质的服务更易获得用户口碑

“中国商标金奖”评选活动每两年举办一届，由国家工商总局负责组织、推荐、草拟获奖名单，并经世界知识产权组织审定后共同进行表彰。据了解，今年举办的第二届“中国商标金奖”共评出了7个“商标创新奖”、7个“商标运用奖”以及6个“商标保护奖”。携程是唯一一家入选榜单的在线旅游企业。

携程作为国内领先的在线旅游服务企业，其规模化的优质服务一直以来都为用户所认可，创业至今16年来已吸引了超过2.5亿的庞大用户群体，其服务模式也一直都是业界同行模仿的对象。据悉，携程拥有近万名的庞大客户服务团队，呼叫中心能够保证7\*24小时、全年无休地为用户提供预订、资讯、投诉等各项服务。

近两年，在市场价格竞争较激烈的情况下，携程于2014年年底提出了“放心的价格、放心的服务”的核心服务理念，重点提升服务质量的核心优势，以此为手段在激烈的市场竞争中占据了绝对的领先优势，获得更多用户的信任和良好的口碑。

服务为业内典范 携程受邀参与交流、培训

在获评中国著名商标金奖“商标创新奖”的同时，携程客户服务部高级总监裴晓丽也受邀参与了在深圳举行的“全国工商行政管理部门12315消费维权业务培训交流会”，并分享携程领先的用户权益保护机制及先进的客户服务流程。据了解，该培训交流会由国家工商总局消保局牵头，共邀请邀请了全国各省市工商局150位负责人。

在培训交流会上，裴晓丽详细介绍了极具携程特色的用户权益保障措施。在预订酒店时，携程会为预订成功后房源变更以及到店无房的游客，提供了贴心的首晚房费赔付承诺。同时，携程为因特殊原因退订机票的用户给予了充分的保障；旅游方面，携程以其全程一站式的服务体验为用户解决所遇到的一切问题，六重旅游保障更好地保证出行用户的利益，1亿元重大自然灾害保障基金的设立也免去了用户的后顾之忧。

此外，从2014年下半年开始，携程还将大数据技术项目引入进了呼叫中心，通过后台的数据实时解析并推测用户的来电意图，电话平均接通时间从8秒缩短至2秒，平均服务时间从2分钟减少至1分钟，极大地改善了用户体验，并降低了服务成本。这也从另一个侧面证实了利用大数据提升服务质量的可操作性，推动互联网服务企业进一步发展并完善用户的管理。
