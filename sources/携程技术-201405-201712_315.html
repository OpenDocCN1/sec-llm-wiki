携程私有云
Ctrip



携程私有云，基于OpenStack二次开发打造携程私有云品平台，目标是提供完整的基础设施即服务（IaaS），主要用于管理开发、测试、生产环境IT基础设施，支持提高开发、运维效率。自从2012 第一次发布以来，已经成功在南通、上海数据中心完成多IDC部署，其中，裸机部署服务（bare metal provisioning )正管理着超过携程3000物理机，虚拟机管理服务（Virtal Machine management ）已经成功部署了KVM、VMWare 将近7000的虚拟机；另外，Ctrip Cloud还实现和多个运维系统对接，比如remedy工作流系统等，有效支持实现“一键”自动化环境准备，大大提高运维效率。

Ctrip Cloud Architecture v1.0


弹性云计算

在云系统中，计算资源通常通过两种方式来提供:

第一种是直接使用物理机，主要用在以下虚拟机不能满足的场合，比如：Hadoop 集群，数据库服务器、openstack 计算节点等。

第二种是提供虚拟机（KVM、VMware），主要作为大部分生产、测试应用主流服务器场合。


Hybrid Hypervisors Management



裸机部署

通过定制开发openstack 的nova-compute Driver，利用开源项目Razor 提供的OS自动安装引擎，实现物理裸机灵活的、自动化的部署。该服务主要功能有：

1、针对不同型号的服务器做硬件设置(包括固件升级, 拷机, 设置raid, ilo, bios),

2、不同操作系统的自动安装,

3、操作系统安装完成后的软件配置管理.

4、部署单自动部署相应系统

5、上线单自动将机器切到生产网段


虚拟机管理

主要支持KVM 和VMware 2种Hypervisors 的虚拟机管理，可以通过cloud API 或者UI 对虚拟机生命周期进行统一管理，同时还通过镜像快照，租户管，权限管理等功能。


云存储

携程云存储，主要通过对开源项目Ceph 分布式存储系统进行优化，直接重用其服务RADOSGW、RBD、CEPH FS提供的对象存储、块存储、文件存储。为携程发布系统（Tars）、openstack 镜像服务（glance）提供可靠、统一的分布式存储。


Unified Storage for Ctrip Cloud with Ceph


三方系统集成API

为了让第三方系统能规范、高效接入携程云服务，Orca-Gateway 作为一切外部系统调用cloud service的统一入口，实现CMDB数据同步，日志审计等相关服务。
