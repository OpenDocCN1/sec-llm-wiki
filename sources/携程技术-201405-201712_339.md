# Apple Watch正式亮相，携程App成首发应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MDI3MjA5MQ==&mid=203761911&idx=1&sn=c20a6bcf5d2484a39f401e27ea2c2a4b&chksm=2f96d7c318e15ed57eaaafcbb2f7ade700335b16d19d21cad99a1480f3e7e3c27f11f5fc913a&scene=126&sessionid=1681375368#rd](http://mp.weixin.qq.com/s?__biz=MjM5MDI3MjA5MQ==&mid=203761911&idx=1&sn=c20a6bcf5d2484a39f401e27ea2c2a4b&chksm=2f96d7c318e15ed57eaaafcbb2f7ade700335b16d19d21cad99a1480f3e7e3c27f11f5fc913a&scene=126&sessionid=1681375368#rd)

 

北京时间2015年3月10日凌晨，Apple Watch正式对外发布，作为苹果公司的最新款产品，Apple Watch官网对两款国产应用进行了推荐，携程旅行App是其中之一。对此，携程相关负责人表示：“Apple Watch的发布及对我们App的推荐，意味着移动端旅行服务迎来了新的发展契机，携程将一如既往地考虑用户需求，始终引领旅行服务的时代潮流。”

 

 

![](../Images/6f4219e458d1cdf59e493811f9eaccdd.png)  

**旅程信息抬手可查**

据介绍，Apple Watch上的携程旅行App最主要的两项功能是便携式查询和实时提醒，在Apple Watch上下载并安装携程旅行App后，用户只需通过蓝牙功能与iPhone上的携程旅行App相关联，就可使用Apple Watch查看最近三次未出行的行程信息，Apple Watch也会根据行程进行相应提醒。

 

据了解，用户点击Apple Watch上的携程旅行App图标后就能查询一年内的所有行程信息，查询方式通过手指左右滑动完成。“所有行程都按出行时间排序，操作便捷，信息详细清晰，一目了然。”此外，用户在不进入携程App的情况下，亦可通过自下而上的滑动方式，打开Apple Watch的Glances界面，实时查看行程概览。

 

AppleWatch的提醒、推送功能同样别具一格，在关联两个设备上的携程App后，Apple Watch会自动提醒用户相关酒店、航班信息，酒店信息包含酒店名称、地址等等；同时，于航班起飞前Apple Watch会自动提醒用户起飞时间。

 

AppleWatch的推送以震动形式表现，用户在感知震动后只需抬起手并保持2秒左右，Apple Watch就会自动显示推送内容，查看多条推送内容时上下滑动操作即可。携程相关负责人称赞说：“Apple Watch真正做到了让旅行行程信息抬手可查。”

**引领移动端旅行服务新潮流**

 

“Apple Watch作为移动端的衍生产品，拥有极大的发展前景。”携程旅行网相关负责人称，“2013年，携程正式开启了由OTA向MTA转变之路，截至2014年4季度中期，携程旅行App累计下载量已经超过4亿，累计激活数超过1.8亿，成为国内第一的在线旅游App。此次Apple Watch的发布让携程看到了在线旅游服务业今后发展新的可能性。”

 

对于Apple Watch的发布及官网首页的推荐，携程方面给出了极高的评价，“可穿戴式设备的逐渐流行，或许意味着又一个时代的到来，携程也将始终关注用户生活习惯的改变和需求的变换，以满足用户的个性化需求为标杆，始终引领旅行服务的时代潮流。”
