# 寻星之旅II——上海站第一阶段笔试结束

寻星之旅II——携程技术中心校园招聘回归大本营，本周在同济大学（嘉定校区）和复旦大学（张江校区）连停两站。

  

【携程技术品牌魅力大，挤爆现场】

由于两所学校所处地并非上海市中心，校招小分队的成员起初还略担忧到场人数会不及预期，但实际两场当天的情况却是在距离宣讲会正式开始前半小时，陆续前来的同学们就已站满了会场。现场除了上海本地院校的同学们，还有来自浙江、苏州、安徽、成都等地的同学们，最远的当属来自北京的同学。虽然在成都和北京也已设立过专场，但仍有未能来得及赶去的同学们，风尘仆仆的特地飞来上海参加，就只为一张携程技术中心的入场券，足见携程技术品牌的影响力已深入校园。

![](../Images/ee843392398e37da056780689ed77a80.png)

  

【宣讲会，让了解更深入】

作为全球市值前三的在线旅行服务公司，携程技术中心一直是携程的核心竞争力之所在，很多现场的同学们表示原本只是通过网络、电视、广告等媒体知道携程，但听完宣讲会后，真真切切的对携程及携程技术中心有了更深入的了解，尤其是对旅游市场的前景和携程技术中心的工作氛围、培养体系等了解的更充分。因为了解，所以放心，也更愿意加入携程，与携程大家庭一同实现亿万人的旅游梦想，同时也成就自己的精彩人生旅程。

  

【互动有礼，皆欢喜】

高校学子们向来是携程重要关注的群体，为了能更好的造福来听宣讲会的同学，此行我们还特地带来了由携程地面SBU倾情赞助的2014上海世界音乐季的门票，显然此举也确实为现场的气氛增温不少。在互动环节，同学们纷纷踊跃参与，最终现场共有数十位同学获得演出门票，还有部分同学获得了携程订制的特色礼物。

![](../Images/89db1426f3fcafb711e92aa0557517d6.png)

  

据不完全统计，来到现场参加宣讲及笔试的人数近千人，所有笔试的答卷及简历均已带回总部，目前正在紧张阅卷中。我们将尽快与通过笔试的同学进行电话邀约安排面试，请大家耐心等待。

至此，寻星之旅II——2014携程技术中心校园招聘还剩广州站、杭州站以及上海交通大学站，还请大家继续关注我们的寻星之旅活动。精彩仍在继续，敬请期待！
