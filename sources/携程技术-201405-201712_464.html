我们很萌哒，但工作起来我们也很猛哒！快叫上你的好盆友，一起加入携程吧！

今天给大家带来的是开发类的岗位，如果有朋友在看机会，快分享给他！如果有合适的人选，快推荐给我吧！


带领一个10余人的高效率团队. 将会同时扮演项目经理，系统架构师以及高级开发经理的角色。 同时负责三方面的工作：产品设计，开发管理，及产品项目管理，产品设计部分的工作是根据产品经理提出的产品需求及功能定义，设计该系统的整体架构及功能模块和数据模块，定义系统及功能模块的具体工程指标， 撰写产品工程需求文档等。 作为开发经理，负责搭建及维护一个高效率的开发团队，负责组织产品的工程设计、开发工作、测试及发布。 项目管理部分的工作包括负责协调团队同其他团队及部门的合作，跟踪产品的开发进度，监控产品交付时间及质量。

这是一些有挑战性,同时也提供积累多方面经验及技能的职位. 适合有意接受挑战和有强烈自我提高意愿的人。

高级研发经理（自动化产品发布平台）

岗位职责：

1、负责组建和管理开发团队(开发经理角色)；

2、负责提出系统架构设计方案（系统架构师角色）；

3、负责开发任务的需求分析、开发计划制定(开发经理角色)；

4、带领及指导开发团队进行产品设计、研发、管理；

5、部分参与关键模块的实际代码开发；

6、与其他部门项目经理、架构师和测试经理进行技术沟通、交流，相互配合完成任务(项目经理角色)；

7、协调组员间以及组员与其他部门的沟通交流。

任职要求：

1、6年以上软件开发相关工作经验，三年以上团队开发管理经验或产品架构设计经验。近期有实际从事代码开发的经验；

2、深入了解软件开发生命周期及流程，能合理分配开发任务并保证进度和质量；

3、具备面向对象的设计思路和经验，具备较好的文档能力及良好的编码风格；

4、同时精通C#及Python 或JAVA；

5、熟悉项目研发流程及管理；

6、有.Net 及Linux系统架构经验者优先考虑；

7、了解持续集成，持续发布及有发布系统设计及开发经验者优先考虑；

8、熟悉数据库设计及了解关系数据库connection机制，session等者优先考虑；

9、有Jenkins等开源软件者、有IAAS或PAAS工作经验、有跨国公司工作经验者优先考虑；

10、具有良好的沟通能力、协调能力和团队合作精神，乐于接受挑战。

技术专家

岗位职责：

1、携程网站， 无线， 服务， 引擎，及内部业务系统的软件开发；

2、对相关的软件和模块进行日常支持， bug 修复和发布维护；

3、 参与软件架构和设计的讨论；

4、参与和主持未来产品架构的设计。

任职要求：

1、全日制大学本科以上学历，硕士优先，计算机、软件工程及相关专业毕业；

2、8年以上.net及其相关的开发经验；精通.NET开发及应用框架；

3、ASP.Net网站或应用程序开发平台和编程工具，ASP/ASP.NET/VBSCRIPT/JAVASCRIPT/C#等；

4、精通 SQL Server 2005/2008 ，熟练使用 SQL 语言，能熟练使用存储过程、视图、自定义函数等，并对数据库建模与优化有一定的理解；

5、如果精通其他高级编程语言和平台也完全可以， 例如Java， C++

6、5年以上互联网经验；

7、具备面向对象的设计思路和经验，熟悉软件开发流程、体系结构，具备很强的文档能力及良好的编码风格；

8、能充分理解用户需求和功能描述，能够进行大型系统的架构设计， 能掌握未来技术趋势

9、作为技术专家，指导和解决开发过程中遇到的各类技术难题，保证软件开发正常进行；

10、思路清晰，工作规范，良好的沟通能力、很强的团队协作精神和责任心；

11、 善于学习新的软件方法和技术，并带领技术团队共同进步与分享；

12、有跨部门技术合作和交流的能力，如果有OTA行业经验， 将很受欢迎。
