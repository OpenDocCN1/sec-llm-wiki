# OpenStack携程应用之路技术培训干货分享

‍‍ 昨天报道吴毅挺同学作为“第六届中国云计算大会-OpenStack企业应用之路技术培训”大会培训讲师，在会上和大家分享VDI方案及案例分析以及跨Hypervisor管理最佳实践之后，很多同学发来消息询问现场的干货有哪些，小编为大家揭秘如下：‍

1.  现场听众对携程的私有云以及虚拟桌面云项目非常感兴趣，频频提问，并对目前的进展之快表示惊讶。
    
2.  无论是部署规模、还是对OpenStack研发的深入程度，携程在国内都属于前列。
    
3.  携程的私有云平台和虚拟桌面云项目都进展良好，我们基于OpenStack做了大量二次开发，将所有的开发、测试环境全部迁移到openstack管理，VMWare到KVM的迁移已经实施部分，生产环境OpenStack初步实现与流程系统的集成，审批后即能自动部署，Bare MetalProvisioning已支持所有主流机型，大大提高了在携程业务、流量高速增长情况下基础设施的扩容速度；仅过去半年我们的vm数量就增长了1倍。
    
4.  虚拟桌面云已经部署近1000个桌面，分布在上海呼叫中心以及如皋卫星办公室，我们的目标是要打造支撑携程超过万人的多呼叫中心云桌面平台。
    
5.  携程在今年计划更多的参与到开源社区，满足自己需求之后，要逐步跟上社区进度，并争取对社区有所贡献。
