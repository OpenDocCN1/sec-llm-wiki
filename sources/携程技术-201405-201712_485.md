 您将有机会和旅游领域的业务、流程、研发、基数数据、资深机器学习专家等领域的专家合作。和我们一起理解问题、解决问题、驱动问题。您将会分析产品、操作、流量、用户甚至财务绩效相关的数据，从而能够更好的驱动业务发展的机会。您将有足够的支持把你的发现变成业务成果，一起分享Ctrip成功的业务结果。

 如果你想挑战高并发、高访问、高可用的的网站后台服务开发，想挑战海量用户的个性化推荐服务，享受海量数据处理的乐趣，我们欢迎您的加入！

  

招聘岗位：

Web Service/API高级工程师

**岗位职责：**

1、开发实现高并发高响应7×24的Web Service/API；

2、 架构设计、详细设计和代码实现；

3、单元测试、集成测试、性能测试和压力测试；

4、发布上线和生产故障处理；

5、持续优化、改进、重构既有系统；

6、文档撰写；

7、训练和培养其他同事。

**任职要求：**

1、全日制大学大专及以上学历，计算机及相关专业毕业；

2、4年以上软件开发工作经验，2年以上互联网工作经验；

3、熟悉Java/Http Web Service/SOA/XML/Json；

4、熟悉SQL SERVER、Oracle、MySQL等数据库之一的开发；

5、熟悉NoSQL、消息队列、分布式内存、流式计算等技术；

6、熟悉常用的数据结构， 算法， 设计模式；

7、熟悉数据序列化技术，熟悉常见序列化格式如XML, JSON, Proto-buf等；

8、熟悉并发和多线程编程；

9、熟悉Linux基本操作命令和代码部署到Linux环境的应用服务器；

10、熟悉任意一种应用服务器Tomcat、Jetty或者web logic、Apache的配置及其优化；

11、具备极强的团队合作精神，对工作有热情，能够在一定压力下工作；

12、有大型网站开发经验者优先。

13、有良好的技术文档撰写能力和良好的技术专研能力。

  
数据科学家/资深算法工程师

**岗位职责：**

1、带领团队，负责机票，酒店，度假等业务部门专项数据分析项目需求确认，完成交付；

2、通过数据挖掘建立模型和效果评估，后续监控和持续改进工作；

3、与业务方，技术研发部门合作，对产品和业务提供建设性建议，跟踪模型的实施，定期优化算法和业务策略；

4、带领团队成长，跨部门合作。

**任职要求：**

1、计算机，统计，应用数学相关专业；

2、熟悉数据挖掘、机器学习、统计学的常用算法；

3、扎实的编程基础，精通Java\\C++\\Python任一语言，有R,Matlab，Hadoop编程经验者优先；

4、有推荐系统，计算广告项目经验优先；

5、良好的沟通协调能力，能够主动学习相关知识；

6、热爱互联网及相关技术。

  

大数据工程师

**岗位职责：**

1、互联网大数据ETL开发和优化、workflow job调度设计、存储过程开发、自定义函数开发、报表制作；

2、生产运营：程序部署，配置管理，日常Workflow job异常处理；

3、数据运营：数据查询、数据修复。

**任职要求：**

1、本科及以上学历。3年及以上相关工作经验；

4、有大数据处理经验，如hadoop map/reduce编程，Pig/Cascading/Hive/Mahout之一使用经验；

5、热爱互联网，对技术研究和应用抱有浓厚的兴趣，有强烈的上进心和求知欲，善于学习和运用新知识；

6、良好的逻辑思维能力，有较强的沟通能力和逻辑表达能力，具备良好的团队合作精神和主动意识；

加分要求：

7、熟悉任意一种ETL工具和报表工具优先；

8、有Linux环境工作经验优先；

9、熟悉任意一种脚本语言shell/perl/python/php优先
