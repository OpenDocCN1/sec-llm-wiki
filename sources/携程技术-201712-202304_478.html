一年一度的携程技术沙龙前端专场又和大家见面了。

 

在过去一年的时间里，前端世界发生了很多变化，各类框架的优胜劣汰、生态完善，以及各类小程序平台的涌现，PWA的普及，甚至小游戏的开发。每一次新技术的出现，对开发人员来说，既是一场狂欢的盛宴，却也不免带来恐慌。

 

携程技术沙龙前端专场，以"新一代前端技术实践"为核心理念，把最新的技术和最佳的实战呈现给大家。此次沙龙，我们邀请了阿里、支付宝、百度、携程、Egret的小伙伴，他们中既有业界的前端大咖，也有新晋网红，将一起为我们呈现一场精彩的前端盛会。

 

期待也相信，在这里你将尽情享受到新技术带来的喜悦兴奋，也能消除心中的恐慌。

议题介绍

《面向前端工程师的机器学习引导课》

携程古映杰

携程度假研发部高级研发经理。负责前端框架和基础设施的设计、研发与维护。开源库 react-lite 作者。

深入研究 react 体系，提出了一种 Isomorphic-MVC 的前端架构思路，整合为 react-imvc 框架，已在携程度假研发部得到大范围的使用和验证。对函数式编程(Haskell)、人工智能（特别是机器学习）有一定涉猎。

 

议题简介

面向前端工程师，使用熟悉的前端技术 JavaScript，讲解机器学习里的基础概念和算法。

演示可在浏览器里运行的机器学习 DEMO，包括拟合线段中心点，拟合矩形中心点，线性回归，AI玩Flappy-Bird和2048游戏，识别手写数字等效果。

 

听众收益

了解机器学习的基本概念，了解人工智能对前端开发的可能影响。


《mvvm 前端数据流框架精讲》

阿里黄子毅

阿里数据技术及产品部高级前端。目前在阿里数据中台前端团队，负责数据产品相关业务，涉及框架、工程效率、平台建设等技术规划。

前端精读创办者、数据流框架 Dob 作者、可视化编辑器 gaea-editor 作者、react-native-image-viewer 作者、曾维护数套前端组件库。

 

议题简介

无论你是 Angular、Vue，还是喜爱 Mobx 的 React 开发者，都已经在使用 mvvm。但很多人对 mvvm 的了解，还停留在双向绑定阶段，这无论是对面试，还是业务开发都存在风险。

作为 mvvm 数据流框架 Dob 作者，通过在阿里内部实践的过程中不断遇到的问题，对 mvvm 前端数据流有了较为深刻的理解，希望通过这次分享，帮助大家更高效地使用 mvvm。

 

听众收益

1. 如果重头写一个 mvvm 框架，该从哪下手；

2. mvvm 框架的局限性，以及原因；

3. proxy 给 mvvm 带来了什么；

4. 如何同时使用 Redux 和 Mobx ；

5. reactive 与 mvvm 的联系与区别；

6. 分析各种类型数据流适用的场景，而不要在 mvvm 一棵树吊死；


《PWA的探索与实践》

百度彭星

百度前端技术部资深前端工程师，Brilliant Open Web团队成员。目前为Lavas团队负责人，负责百度在PWA方向上的工作，帮助站点减小接入PWA的成本，致力于提升Web站点的用户体验。

 

议题简介

PWA 是在 Web 端具有颠覆性的一个概念，在苹果宣布 iOS 11.3 版本将支持 Service Worker 之后，更是吸引了大批开发者的关注。

在国外已经被普遍接受，很多站点也已经改造成 PWA，如：twitter，并且取得了非常好的成绩，twitter lite 平均用户停留时长增长 65%，在国内，PWA 的概念也越来越被广泛接受，微博，饿了么等很多大型的站点都已经改造成 PWA，并且也会越来越多。

但是，何为 PWA，该怎么将普通的站点改造为 PWA 站点呢，以及改造 PWA 应该注意哪些点，应该采用什么技术，什么样的设计方式等等，很多开发者都不知道。

本分享将会解答大家这些问题，让站点开发者少走点弯路。

 

听众收益

1. 什么是 PWA；

2. 了解 PWA 的关键技术点；

3. 如何应用 App Manifest Service Worker 打造 PWA 站点；

4. 改造过程中应该注意哪些问题；


《白鹭带你玩转跳一跳类小游戏开发》

白鹭时代王省伟

白鹭时代游戏高级开发工程师。带领团队开发了《斗地主》、《德州扑克》等 H5 游戏，参与开发《修罗武神 H5》、《富翁时代》H5 游戏项目。先后就职于小米、盛大网络、腾讯文学等公司。

 

议题简介

2017年12月，随着微信最新版本的发布，蓄势已久的“微信小游戏”终于来了。在2018微信公开课 Pro 上，微信游戏产品总监孙春光透露，小游戏的累计用户已经达到了 3.1 亿。2017年移动游戏的自然人总计4亿多，微信小游戏用 20 天就达到了这样的成绩。

本次将主要分享微信小游戏的现状和发展，以及如何创建和发布微信小游戏。游戏开发中常见的资源加载、场景切换、音频播放、内存优化；使用 Tween 动画库，进行跳跃画，形变，舞台的整体位移等缓动动画的实现。

 

听众收益

了解小游戏的基本情况，对小游戏的开发产生兴趣，并且能快速简单的使用白鹭引擎开发一款小游戏。


《支付宝小程序的开放架构》 

支付宝何一鸣

支付宝高级前端技术专家，支付宝小程序前端框架负责人。2010 年加入阿里，先后负责 kissy/ant-design/ant-design-mobile 等基础类库的核心研发工作，目前专注于跨端技术的研究。

 

议题简介

支付宝小程序依托自身的技术能力和开放服务，为开发者提供了触达亿级用户的机会。我们不仅提供高效的开发框架，易用的开发者工具，还在监控，发布，数据分析方面给开发者提供全方面的支持。

支付宝小程序对外更是一套开放架构，未来支付宝将和合作伙伴 app 一起打造共赢的小程序生态。

 

听众收益

了解支付宝小程序的基本原理以及提供的能力，学会如何开发一个支付宝小程序。
