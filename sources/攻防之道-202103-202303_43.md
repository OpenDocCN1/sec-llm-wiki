Fortify是惠普旗下AST （应用程序安全测试）产品 ，其产品组合包括：Fortify Static Code Analyzer提供静态代码分析器（SAST），Fortify WebInspect是动态应用安全测试软件（DAST），Software Security Center是软件安全中心（SSC）和 Application Defender 是实时应用程序自我保护（RASP）。其中SCA 产品是最为出名的代码审计产品与Checkmarx 齐名，也是代码审计人员的首选工具。

**软件启动&配置**

扫描代码，最常用的就是Audit Workbench，直接启动

![](../Images/749c493614d96a379ece7a33abdde442.png)

  

通过这里启动，默认不能指定maven 打包的一些项目，目前Java 项目依赖maven 的情况越来越多，特解决下如何与maven 联动进行编译。  

  

maven 配置具体步骤如下：

**指定maven 或lib 目录之后，发现的漏洞或代码缺陷会更多更全面**

1.  首先保障电脑 的maven 环境已经配置好
    
2.  解压 \`D:\\Program Files\\Fortify\\Fortify\_SCA\_and\_Apps\_20.1.1\\plugins\\maven\\maven-plugin-src.zip\` 
    
3.   此目录中有2个压缩包，一个是binary，一个是source，直接解压src 目录，不要bin 目录（容易报错）
    
4.  进入目录执行 \`mvn clean install\` ，将自动安装 \`sca-maven-plugin\` 到本地仓库
    
5.  可以正常使用Fortify 来扫描 maven 项目
