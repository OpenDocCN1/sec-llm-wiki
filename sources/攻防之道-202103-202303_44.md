#01 漏洞背景

  

继[Spring Cloud Gateway RCE](http://mp.weixin.qq.com/s?__biz=MzIyNDcwODgwMA==&mid=2247484479&idx=1&sn=686eae93eb25c70a9bf72e96273ea9e3&chksm=e80b9590df7c1c867db351d8a1cb1e9fb044c59a91a4e64c63eb0a8cb2a6c0b0aff107807cbc&scene=21#wechat_redirect) 之后，Spring 全家桶再爆一漏洞，目前暂无CVE 编号，但是基本可以确定是Spring core 相关的RCE 漏洞，

  

漏洞影响范围

1.  JDK >=9 
    
2.  使用Spring Framework或Spring 衍生框架
    

  

#02 漏洞防护建议

  

目前官网并未发布相关补丁，可以使用WAF 或相关安全设备，将 "class.\*", "Class.\*", "\*.class.\*", "\*.Class.\*"  等关键特征放入自定义拦截规则。

#04 知识点补充

Spring Framework 知识点补充

Spring Framework 是一个应用广泛的web 框架，是企业构建web应用的首选框架，总计由20个小模块组成；包含Core 容器，数据访问(DAO、jdbc、ORM)，Web，AOP，Messaging等。  

本次漏洞涉及到的模块就是Core 容器中的spring-core，与spring-beans 共同提供框架的基础功能，包含控制反转(IoC)、依赖注入(DI)。

  

Core 容器中所有模块列表  

*   spring-core  ❌
    
*   spring-beans
    
*   spring-context
    
*   spring-context-support
    
*   spring-expression（SpEL）
