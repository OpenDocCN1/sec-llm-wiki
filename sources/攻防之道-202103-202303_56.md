3、创建处理json 的漏洞入口

springboot 中使用controller来进行url 的控制，关键代码如下：逻辑很简单，获取客户端输入，转换成JSON 对象（Fastjson其实就是一个Java 第三方库，可以操作对象和字符串。这里可以看到fastjson 的一个作用：

*   **反序列化**\--将字符串转换为user 对象，常用的还有另外一个功能：
    
*   **序列化**\--将对象转换为字符串）：
    

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
    @RequestMapping("/add")    @ResponseBody    public JSONObject add(@RequestBody String data){        String userdata=data.replace("\r\n","");        logger.info(userdata);
        //字符转对象        JSONObject user= JSON.parseObject(userdata);        JSONObject result=new JSONObject();        result.put("msg","success");        result.put("code","200");        result.put("data",user);
        return result;    }
```

\* 代码说明：第3行通过RequestBody 直接获取请求体内容赋值给data 形参

**漏洞触发点在第8行，在将字符串转换为JSONObject 对象（反序列化）的时候产生了问题**
