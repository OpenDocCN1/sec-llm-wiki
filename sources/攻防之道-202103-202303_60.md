# 容器化的福音-NSA 发布Kubernetes 加固指南

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNDcwODgwMA==&mid=2247484098&idx=1&sn=39106949dc61bc1ae3d3126f8a27c5a1&chksm=e80b936ddf7c1a7ba22968f830f19f9a89359f2599ecffb7585c6a32876ebf58a847b29df771&scene=126&sessionid=1681659605#rd](http://mp.weixin.qq.com/s?__biz=MzIyNDcwODgwMA==&mid=2247484098&idx=1&sn=39106949dc61bc1ae3d3126f8a27c5a1&chksm=e80b936ddf7c1a7ba22968f830f19f9a89359f2599ecffb7585c6a32876ebf58a847b29df771&scene=126&sessionid=1681659605#rd)

随着容器化市场的日益完善，8.3 号，NSA 、 CISA 联合发布Kubernetes 安全加固指南，为了帮助企业更好地应用开源组件 K8S，也是很贴心了

> NSA（National Security Agency）国家安全局
> 
> CISA（Cybersecurity and Infrastructure Security Agency）网络安全和基础设施安全局
> 
> 【不是审计人员考证的那个CISA吆】

  

报告中认为，K8S 主要的威胁来源有以下3个：  

1.  供应链攻击  
    
2.  威胁行为者  
    
3.  内部威胁
    

  

主要包含以下7部分内容：

1.  扫描容器和pods 是否存在漏洞和错误的配置
    
2.  以最小权限运行容器和pods
    
3.  利用网络隔离降低可能发生的危害
    
4.  利用防火墙限制非必须的网络连接，并启用加密保护机密性
    
5.  利用强认证和授权限制用户和管理员的访问同时减少受攻击面
    
6.  启用日志审计功能，以便管理员监控活动、发生潜在的恶意活动时也可及时告警
    
7.  周期性评审K8s 的设置，同时开展漏扫工作确认风险被正确的识别、应用安全补丁
