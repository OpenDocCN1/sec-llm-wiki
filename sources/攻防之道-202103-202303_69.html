        漏洞风险提示       


5月25 日VMware 官方发布通告，纰漏VMware vCenter Server 存在远程代码执行漏洞（CVE-2021-21985，CVE-2021-21986）


风险评分：6.5-9.8

风险评级：Critical（严重）

受影响产品：

  • VMware vCenter Server (vCenter Server)

  • VMware Cloud Foundation (Cloud Foundation)


漏洞摘要


vSphere Client htlm 5 存在多出漏洞


漏洞详情



利用场景

vSphere Client htlm5 中的Virtual SAN Health Check组件（默认启用的插件，无论是否使用都会受影响），由于缺少对输入信息的校验，导致存在远程代码执行漏洞，通过构造恶意的请求，经过网络发送到目标服务器端口（通常为443），利用成功可以在服务器执行任意命令


修复情况


产品版本修复版本

vCenter Server

7.0

7.0 U2b

vCenter Server

6.7

6.7 U3n

vCenter Server

6.5

6.5 U3p


应对建议



VMware 在企业中使用较广泛，多用来做企业级虚拟化平台，建议各个管理员及时升级，避免造成损失。

此外，如果您仍然对该漏洞有疑问，或有其他安全顾虑，欢迎评论，我们可提供专业的安全咨询与审计服务，帮助您完善项目的安全建设。
