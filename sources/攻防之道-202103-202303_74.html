在MIT 的BSS 上曾有这样一个问题：

“你觉得是谁最厉害的程序员，为什么？”

虽然大家在回复中声明，最厉害的程序员排名不分先后，然而大部分人仍把Bill Joy 排在第一位。


Bill Joy？
年轻的程序员估计很少知道他是谁了，但是他的作品你一定知道，今天我们来一起领略这位大神的传奇风采。



PART 1  /1975年秋天


· 大神相见· 

Unix光环加身的大神Ken Thompson休了一个长假，他回到了自己的母校，加州大学伯克利分校，他将在这里以访问学者的身份待一学年。 


（Unix、Go发明人、83年图灵奖得主Ken Thompson）


在伯克利分校，Ken Thompson把Unix v6 安装到了最新的机器PDP 11/70上面，并且开设了一门Unix的课程。

他不仅讲解理论，还在晚上带着大家阅读一行行的Unix内核代码，向大家解释为什么这么做。 

每个晚上，学生们都围绕在Ken Thomphson周围，瞪着一双双求知的大眼睛，聆听Unix作者的教诲，实在是太幸福了！

这些学生当中有一个研究生，Bill Joy，也是我们故事的主人公。

（BSD 系统发明人Bill Joy）


· 黑客精神· 

Ken Thompson通过Unix在伯克利大学激发了黑客精神。 


有一天Ken Thompson在PDP 11/70 机房“闲逛”的时候，在Unix上随手写了一个不太完善的Pascal编译器，这令Bill Joy大开眼界，原来黑客就是这么玩的啊！


Bill Joy在用Pascal写项目作业的时候，很快他发现了编译器的缺陷，他也决定做一个黑客，把这个编译器改好。 


那时候没有IDE，他们使用一个叫ed的文本编辑器来程序，ed也是大神Ken Thompson写的，但是它实在是不好用，后来有人写出了em，Bill Joy和Chuck又改进了em, 把它变成了en ，然后是eo, ep...... ex，有一点必须要提一下，当时并没有显示器，大家用的都是teleprinter ，就是下面这个东东:


(teleprinter )


题外话：

40年前，电脑没有显示屏。

30年前，大多数电脑还不能放在写字桌上，因为太大了。

20年前，世界上还没有一张网页。

10年前，搜索引擎还不存在，原因是网站太少，没有搜索的必要。



你想在文档中任意移动光标，选取要编辑的文本段落？对不起，不行！你只能以行为单位进行上下移动，想改这一行的某个词，对不起，不行，你得删除这一行，然后重新输入！（难怪vi 也是类似的操作）


当时的程序员过的都是什么日子啊！


后来，伯克利大学购买了一批叫做ADM-3A的终端，在屏幕上终于支持可以随意移动的光标了！Bill Joy 欣喜异常，他重新设计了ex, 增加了“可视化模式”，ex变成了大名鼎鼎的vi（目前vi 的升级版，读者了解更多的应该是vim 了）。


（vi 编写hello world）


vi这个编辑器让无数程序员爱不释手，更让无数程序员从入门到放弃，还和另外一个神器Emacs开启了长达几十年的论战：到底谁是最好的编辑器？


编程界有个笑话，

    说：如何让计算机生成随机数呢？    

    答：让新手退出vi。 



PART 2  / 1977年BSD 诞生


“休假”满一年的大神Ken Thompson返回贝尔实验室， 他虽然走了，但是他撒播下的黑客的种子开始萌芽。 

Bill Joy和其他同学此时对Unix内核越来越感兴趣，与此同时，他的Pascal编译器有着良好的声望，很多人都想要一份Copy，Bill Joy突发奇想，为什么不把Pascal编译器，ex编辑器（还有后来的vi编辑器），以及其他对Unix的一起打成一个新的系统包，重新分发呢？


于是在1977年早些时候，著名的Berkeley Software Distribution 系统，即BSD 诞生了！ 


（BSD logo）

BSD发布之后大受欢迎，各个学校和公司都在使用，后来相继发展出了FreeBSD，NetBSD，OpenBSD，NeXTSTEP等， 其中NeXTSTEP最终演化成了苹果公司名扬天下的MacOS（苹果PC 端系统，但是一般来讲都认为MacOS 起源是Unix）。

PART 3  /  手写TCP/IP 协议


另外一个传奇，是有关TCP/IP协议：

当时，国防高级研究计划局（DARPA）主导了计算机网络的发展，由于BSD的良好表现，伯克利学校获得了DARPA的合同，DARPA 希望能增强BSD系统，以便可以应用在DARPA的网络。
TCP/IP协议栈是互联网的基石，光是读懂这些协议就很难了，更别说实现这些协议了。 

BBN把TCP/IP协议栈实现之后，DARPA要求Bill Joy整合进BSD，意外是，此事被Bill 义正言辞的拒绝了，理由很亮眼---BBN的TCP/IP性能太差劲，还不如我自己写一个！

Bill Joy 很快就手写了一个高性能的版本的TCP/IP 协议实现，并顺利整合进BSD系统。当被问到是怎么实现TCP/IP的时候， Bill Joy说：“这非常简单，你只要读一下协议，然后写代码就行了”，大神就是这么简单。

一个人打败一家公司，或许这就是天人吧。

PART 4  /  大神创业


1979年，获得了伯克利的电气工程与计算机科学硕士学位
1982年，作为联合创始人创立了Sun 公司，同时作为首席科学家一直到2003年。在这期间，大神的事迹依然在持续：

Network File System文件系统的主要设计人，
微处理器 SPARC 的主要设计者（SPARC是Sun工作站的核心，每年给Sun带来几十亿美元的营收）


PART 5  /  传奇的一生


有关Bill Joy的传说相当多，但毫无疑问Bill大叔算是一代神人。被《财富》杂志评为“互联网时代的爱迪生”

    

随便列举一些：   

  1. SUN创始人兼首席科学家（90年代的SUN大约如现在的Google）      

  2. 神器vi的作者

  3. TCP/IP 协议栈的实现者

  4. csh(c shell)的作者      

  5. PBS纪录片Nerds 2.0.1中Eric Schmidt（当时还在Novell）爆料Bill Joy可能只花了一个周末写了BSD内核    

  6. 当年DARPA让BBN公司一组人为BSD开发TCP/IP协议栈Bill大叔以质量太差拒绝加入BSD内核，转而自己实现了一套      

  7. Sparc处理器设计者之一（软硬通吃）      

  8. 开发了Java中的Jini部分
