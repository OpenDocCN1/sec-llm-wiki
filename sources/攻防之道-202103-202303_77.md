# Burp suite 2020光标选不准问题--已解决

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNDcwODgwMA==&mid=2247483889&idx=1&sn=ff27e88b568392bc93e09991f89525da&chksm=e80b905edf7c1948a75e818582cffa4a9b6c110c2a40689ac301128cb56e4aa91b8db25e6758&scene=126&sessionid=1681659615#rd](http://mp.weixin.qq.com/s?__biz=MzIyNDcwODgwMA==&mid=2247483889&idx=1&sn=ff27e88b568392bc93e09991f89525da&chksm=e80b905edf7c1948a75e818582cffa4a9b6c110c2a40689ac301128cb56e4aa91b8db25e6758&scene=126&sessionid=1681659615#rd)

  

**问题现象**

今天入手了一台新电脑，安装上Burp suite v2020 新版，发现文本框中的光标选不准、有偏移，光标选中的部分文字挤在一起，重叠了。经过多方搜寻，终于找到解决方法了，请往下看

  

  

**解决方法**

  

  

**【原因分析】：**

由于我电脑的分辨率比较高，所以默认是125%的缩放。但burp suite不支持这个缩放比，由于缩放的原因导致burp suite的文本框光标出现偏移，多选也选不准。

  

**【电脑默认缩放与布局】：**![](../Images/86cdf2fef9fceb5687e7a03605a10348.png)

**【解决方法】：**

  

启动burp的时候，编辑启动脚本，新增下面参数：

*   

```

```

下面是全部参数，可直接复制使用  

*   
*   
*   

```
@echo offstart "burpsuite" /B "javaw.exe" -Xmx8G -XX:-UseParallelGC -noverify -javaagent:BurpSuiteLoader.jar -Dfile.encoding=utf-8 -Dsun.java2d.uiScale=1 -jar "%~dp0burpsuite_pro_v2021.2.jar" %*exit 0 
```

  

该参数强制burp的缩放比为100% ，加上该参数后会导致burp 字体非常小，可以通过调节burp 字体大小解决
