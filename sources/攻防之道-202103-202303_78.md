近期使用钉钉沟通的项目比较多，但是经常碰到对方撤回消息的情况，索性找了个工具防止消息撤回，之前只使用过微信的防撤回，没想到钉钉的也有，试了下还不错，有需要的自取。  

## 1.X 使用方法

1.  确认操作系统为 Windows XP - Windows 10 （32/64位皆可）。
    
2.  使用本程序前请先关闭钉钉进程，否则会弹出如下提示框并退出本程序。
    
    ![](../Images/4756bbbf24810a9628342d7fa478a1a9.png)
    
      
    
3.  以**管理员身份**打开此程序，正常情况下弹出如下界面
    
    ![](../Images/b362cb751f6635758c2117e703b5f72a.png)
    
      
    
    一般情况下，程序会自动获取钉钉安装路径；如果获取失败，请点击右边 "..." 按钮手动选取钉钉程序安装位置。
    
4.  单击 "点我打补丁" 按钮，不出意外的话，会显示 "补丁成功，重启钉钉后生效" 字样。
    
    ![](../Images/b581b8edb2eb72b7a8650f733de941d3.png)
    
5.  如果想恢复原始钉钉功能，则只需点击 "撤销补丁" 按钮即可。
    

**PS. 因为本程序互联网搜索找到，只通过windows 自动杀毒进行了扫描，如有疑问，建议下载源码编译使用。**
