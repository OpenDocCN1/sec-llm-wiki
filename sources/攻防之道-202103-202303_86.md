全球网络安全形式严峻，网络安全事件频发，“不知功，焉知防”，本公众号主要介绍些网络安全世界的攻击与防护知识，为网络安全行业的发展尽一份绵薄之力。  

![](../Images/53f97001b4b165a30e7ea6c16ccec41c.png)

作为开篇文章，本文主要介绍一些网络安全术语：  
  

| **术语  
** || **释义  
** |
| --- | --- |
| 攻击者 || 威胁的诱因，作为恶意的角色，他们试图更改、破坏、窃取或禁用计算机系统上保存的信息 |
| 防御者  
 || 利用各种技术，加固、分析、监控网络状况，将攻击者拒之门外  
 |
| 网络攻击  
 || 对系统的机密性、完整性、可用性、抗抵赖性的危害行为  
 |
| 肉鸡  
 || 被黑客入侵并被长期驻扎的计算机或服务器 |
| 抓鸡  
 || 利用安装量大的程序的漏洞，使用自动化方式获取肉鸡的行为  
 |
| webshell  
 || 通过web 入侵的一种脚本工具，可以据此对网站服务进行一定程度的控制，类似于web 服务器上的后门，可以通过浏览器直接访问 |
| 一句话木马 || 通过向服务器发送一句简短的代码，配合本地客户端实现webshell 功能的木马，代码量一般都只有一行    ‍ |
| 弱口令 || 指那些强度不够，容易被猜解的密码，例如，1234、123456、abc、12345678 等  
 |
| 跳板机  
 || 一个带有辅助作用的机器，利用这个机器作为攻击的中转站，来攻击其它主机，一般与肉鸡连用  
 |
| 白帽子  
 || 作为正义的一方，发现漏洞被不会用来恶意利用、破坏，而是报告给厂商，让厂商及时修复  
 |
| 黑帽子  
 || 作为恶意的一方，发现漏洞并加以利用，更多的情况伴随对金钱的欲望  
 |
