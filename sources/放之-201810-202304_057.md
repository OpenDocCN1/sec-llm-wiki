# 如何下载Orielly网站的图书

我个人比较倾向于用电纸书阅读，但由于Orielly上的图书要么在Web上看，要么在Orielly自己的App上看，其实是比较麻烦的。后来用SafariBook工具下载了一段时间还蛮好用的。分享一下。 当然直接在Orielly的APP或者网站上做笔记也是蛮好的。

  

注1：下载图书不涉及版权问题，Orielly账户权限正常。               

注2： 用户名密码方式下载比较简单，此处介绍SSO方式的下载（其实也很简单）

  
  
步骤一 · 下载安装SafariBooks  
  

```

git clone https://github.com/lorenzodifuccia/safaribooks
```

  
  
步骤二 · 登陆Orielly通过Console获取Cookies文件  
  

```
 javascript:(
```

  

  
  
步骤三 · 下载图书  
  

指定需要下载的图书ID即可，此处示例为软件架构基础这本书在Orielly的ID

```


cp ~/Downloads/cookies.json .
```
