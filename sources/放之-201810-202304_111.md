# 青椒鸡蛋

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3ODAzNjg5OA==&mid=2247483919&idx=2&sn=739991ea4e3347d057f0639afe58448c&chksm=cf1890c2f86f19d476f957bd25dc10ce3cca65f89cdee94dc41868d874458da1335771662d81&scene=126&sessionid=1681322247#rd](http://mp.weixin.qq.com/s?__biz=Mzg3ODAzNjg5OA==&mid=2247483919&idx=2&sn=739991ea4e3347d057f0639afe58448c&chksm=cf1890c2f86f19d476f957bd25dc10ce3cca65f89cdee94dc41868d874458da1335771662d81&scene=126&sessionid=1681322247#rd)

取青椒3个，洗净切块备用。打3-5个鸡蛋碗中，顺着一个方向搅拌。热锅烧油，油温九成热时倒入鸡蛋。鸡蛋液会迅速膨胀，此时轻轻翻动。待炒出香味放入青椒翻炒2分钟。最后放入盐，翻炒均匀即可出锅。

  

味道： 已经忘了中午吃的时候是什么味道了。现在看着只是觉得饿。

注： 鸡蛋本身鲜香，所以无需过多调料。当然视个人需求而定。另爱吃辣的选辣椒。
