# 山药排骨汤食记

取小排两根剁成二指宽小块，洗净备用。小锅烧水，其中放入大葱葱段一节，葱叶少许，姜片一片。水开期间，准备备料。香菇三至四颗，剔除茎，仅留香菇帽；切三段三指宽左右大葱；六颗红枣洗净；干辣椒两颗（可不放）；八角一粒；二指宽山药十余段。水开后放入小排焯水，至水再次沸腾。焯出后置于温水中等待。刷锅，其后接冷水。随即捞出小排入锅，并将辅料，香菇，红枣，大葱，山药一一入锅。大火烧开后，加入食盐，转小火一小时。闭门等待，然而香气弥漫，过厨房，穿客厅，至卧室最里，书桌之旁。待出锅，入厨房，似葱香而非葱香，清新，弥而不腻。起锅，闻山药之香，淀粉之香，有朴素之感。盛于勺中，有肉香及诸香混合。品汤，微辣，但不够咸；不油，不腻，不腥。极馋，食欲大增，食肉，似糯非糯，柔，透。其中有骨，脆且有嚼劲。立时两大碗，饱。
