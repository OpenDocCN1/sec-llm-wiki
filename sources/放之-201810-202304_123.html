    Openresty 入门

以下实践均在Centos下完成

openresty是一个基于nginx且内部集成了大量精良的 Lua 库的高性能web平台

安装

配置

1.编辑配置文件

配置文件内容如下

worker_processes  1;error_log logs/error.log;events {    worker_connections 1024;}http {    server {        listen 4996;        location / {            default_type text/html;            content_by_lua_block {                ngx.say("I am here")            }        }    }}

2.加入环境变量

我这里是source ~/.zshrc ,依照自己的shell的配置文件即可

3.让我们使用http_load来压测一下看看

wget -c http://soft.kwx.gd/tools/http_load-12mar2006.tar.gztar -xz http_load-12mar2006.tar.gzcd http_load-12mar2006makeecho http://127.0.0.1:4996 > url./http_load -p 20 -s 5 url

至此你已经完成了Openresty的HelloWord级别的教程... 之所以选择Openresty是因为一次搜索Nginx记录request和response的日志时发现的。后来又看到Openresty还扩展了lua和redis模块的时候，想着用来做下发处置会十分方便，就开始进行基础的学习了。
