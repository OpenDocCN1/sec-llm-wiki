批量生成 payload，关键的命令无非是分别列出各项支持的条目，然后进行输出。不过目前只是针对 linux平台的做了输出。将 $(grep linux $PAYLOADSLIST)替换为 $(cat $PAYLOADSLIST)即可输出所有。

  • msfvenom-l formats

  • msfvenom-l encoders

  • msfvenom-l payloads

完整脚本如下，根绝自需修改。

  1. #!/usr/bin/env bash
  3. ENCODERSLIST='encoders.list'
  4. PAYLOADSLIST='payloads.list'
  5. # also you can use `msfvenom -l formats` to generator your encodeformat
  6. ENCODEFORMAT='bash sh c java perl pl powershell ps1 py python rb ruby vbscript'
  8. mkdir -p linux
  9. mkdir -p windows
  10. mkdir -p osx
  11. mkdir -p android
  13. echo "[*] Generator your encoders list file"
  14. msfvenom -l encoders | awk '{print $1}' | sed '1,6d' > $ENCODERSLIST
  16. echo "[*] Generator your payloads list file"
  17. msfvenom -l payloads | awk '{print $1}' | sed '1,6d' > $PAYLOADSLIST
  20. for linuxpayload in  $(grep linux $PAYLOADSLIST)
  21. do
  22.     for format in $ENCODEFORMAT
  23.     do
  24.         echo "[+] Generate payloads from: $linuxpayload"
  25.         for encoder in $(cat $ENCODERSLIST)
  26.         do
  27.             fpath=`echo "$linuxpayload"_"$encoder"."$format" | sed -e "s/\//\_/g"`
  28.             msfvenom -p $linuxpayload -e $encoder -f $format -o linux/$fpath
  29.         done
  30.     done
  31. done
