# 甘愿被骗

上周，读完王小波《黄金时代》的前二天，我在地铁口买了份觊觎已久的烤地瓜。彼时正是下班高峰，街道两旁行人匆匆。而雨点打在身上，却不似曾感觉。别人都拿这本书当做黄色小说来看，我也不例外。知道这么小说已经很久了，然而却没有完整的读过。可能是没有人与我共同“墩”“这伟大的友谊”，亦或我的黄金时代早已消逝不见。幼时总是有许多时间，可以肆意阅读，纵使可读的书籍不多，但耗上一整段的时间，必然大快朵颐。不管怎样，我总是把这本书读完了，作为《王小波文集》开篇的一本书。然后，却兴趣索然，不愿继续下去。我知道这是大脑在作祟，犹如进入贤者模式一般，爽过了一把，就要歇歇。 随着一个人的长大，谎言和欺骗是人生中必不可少的历程。无论是希望与否，这些是是非非都会不期而遇。站在路口，看着红绿灯闪烁跳动，车来车往，烤地瓜已经不再烫手，香味却更加诱人。 上海这座由两千多万人口组成的城市，可以说是承载着众多的梦想。不管是高楼林立的办公大楼，还是鳞次栉比的小区。许许多多的人背井离乡来到此地拼搏，为了生计，为了逐梦。总之，不得不承认的是外地人作为上海重要的组成部分，为这座城市带来了生机。而我，也正是这万千的外地人中的一个。

绿灯亮了，我随着人流涌至对面。在上海，坐地铁若是不得要领的话，很可能是要被挤得惨不忍睹。鼻息之间尽是汗臭。夏天有一段时间，总能碰到一个或几个汗臭的人，与你间隔不足几厘米。甚至贴在一起，让人无法忍受。后来有一天，发现自己也突然散发出阵阵恶臭。不禁惭愧不已，为以前自己轻易揣摩别人而感到羞愧不安。只能欺骗自己，一时而已，一时而已。 欺骗这件事，人性使然。形形色色，不足为奇。有骗人为生者，有自欺欺人者，有甘愿被骗者，种种如此，各行各业，都有自己深不见底的秘密。所谓圈子，有此而来。所有的原因我们都知道，但也不愿去做那个正确的事情，亦或，从来没有正确。正如较为流行的一句话，叫做小孩才分对错，大人只看利弊。怎么理解各有各的看法。我不甘愿被骗，更不愿骗人。 圈子就是圈子，外面的想进来，里面的想出去。围城就这样形成，一层又一层的圈子叠加到一起。我到了饭店，跟老板说还是老样子。老板娘告诉我烤地瓜的骗了我，起码多了一倍。我想我是不甘愿被骗的，还有一些生气。虽然几十块块钱并不算多，但这样被骗又算什么事情呢？因为这根本不是钱的问题！我以前总听人说，这不是钱的事情，最初我并不明白，后来才觉察到真的并不是好心情没了，胃口也就没了。烤地瓜的香味逐渐散去，等到回到地方的时候，已经平常如斯了。和小贩A理论，退了钱。顺带帮助另外被骗的两个人挽回了损失。只是觉得这是一件有意义的事，值得去做。 后来侥幸参加了极棒，会后又看到了一众运营的文章，我想说点什么，都已经被淹没在一片高声欢呼之中。秤是一个可以衡量重量的东西，却没办法衡量质量。 再后来，我碰见一个人，问他买的那块烤红薯多少钱。他说十六。我告诉他你可能被骗了，那个人告诉我：”骗就骗了，反正无所谓“。 我，不喜欢这种人。不作为的人多了，圈子才会越来越结实。![](../Images/cafc3f83ebdfda89eb7fe5196cc03e2a.png)欺骗的谎言透不过墙，人也就会不得不成为甘愿被骗的那个。
