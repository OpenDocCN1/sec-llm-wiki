# 众测国家队！“今朝安全众测平台”正式启动运行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247488990&idx=2&sn=cfc4fa6e37a890638929859732844cb9&chksm=c1476763f630ee752c6146fc419328ac22de54acadb8da574b4f7b335cf119d23102fda32868&scene=126&sessionid=1681323313#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247488990&idx=2&sn=cfc4fa6e37a890638929859732844cb9&chksm=c1476763f630ee752c6146fc419328ac22de54acadb8da574b4f7b335cf119d23102fda32868&scene=126&sessionid=1681323313#rd)

2021年5月19日，由中国信息产业商会指导，中国信息安全测评中心组织运营的“今朝安全众测平台”正式启动运行，面向全行业提供网络安全众测服务。同日，“今朝网络安全众测委员会”成立，中国信息产业商会会长聂玉春担任名誉主任委员，沈昌祥院士、倪光南院士、方滨兴院士为特邀顾问，张峰主任担任主任委员。委员会由来自中国信息产业商会、中国信息安全测评中心以及18家网安企业的有关领导和专家代表共同组成。“今朝安全众测平台”启动运行发布会在北京国谊宾馆并期成功召开。“今朝网络安全众测委员会”的委员代表共同参与了“今朝安全众测平台”启动运行仪式。![](../Images/39b0ae617cdc1d12777181a10ecb7900.png)*图：“今朝安全众测平台”启动运行仪式  
*中国信息安全测评中心开展众测工作，是落实党中央战略部署和习近平总书记总体国家安全观要求、顺应网络安全新形势新任务新要求、履行国家赋予的信息安全漏洞分析与风险评估职能的一项重要工作举措。中国信息安全测评中心将联合信息技术产业和网络安全产业，以基础软硬件产品为主要目标对象，依托“今朝安全众测平台”，参考国家信息安全漏洞库（CNNVD）相关标准规范，提供科学公正、沟通顺畅、响应及时、评定可靠的漏洞审核和评价，开展高质量众测服务工作。中国信息安全测评中心开展众测工作不以盈利为主要目的，依托“今朝安全众测平台”，探索建立联合运营的众测业务模式，充分发挥业界其他安全众测平台的既有优势，通过凝聚网络安全业界优势，打造多方合作、互利共赢的特色化网络安全众测平台，进一步提高我国国产软硬件产品和关键信息基础设施的安全防护能力，建立强大的安全屏障，为我国网络强国建设事业保驾护航。**▶ 相比其他众测平台，今朝众测有何不同？**据今朝网络安全众测委员会秘书长吴润浦介绍，有定位、做法、效果三点不同**1.定位不同。**今朝平台的定位更高，主要目的是为了防范和化解可能影响国家安全的基础软硬件系统的漏洞风险和隐患。今朝平台本身并不追求盈利，不搞竞争替代，将作为一个中立、公平、公正、客观的服务平台，积极推动相关政策标准的制定、拓展服务对象和领域、宣传和评价测试工作，为各方创造价值，助力发展。**2.做法不同。**今朝平台在建立之初就集合了从上到下、各级各类型的网安中坚力量，成立了网安众测委员会，目的是解决当前国内众测工作遇到的问题和瓶颈。通过努力，让重视自身软硬件安全、心系国家安全的企业脱颖而出，让愿意为国家网络安全事业贡献力量的安全研究团队及成员得到更多认可、得到更大回报、价值得到更大体现。让优秀的众测平台有更大的发挥空间，工作成绩得到国家、行业和社会的关注，展现众测工作独特作用和魅力。**3.效果不同。**今朝平台会根据软硬件产品的重要程度，定向邀请国内顶尖安全研究团队参与测试，并采用多种方式方法动员和调动团队的积极性，要让测试结果达到较高的安全标准，不仅仅要合规，而是要对抗有组织有目的的攻击者，甚至是国家级的攻击者。对所有测试过的软硬件产品，测评中心等相关单位会将作为长期跟踪研究的目标，纳入日常工作范畴，不断为产品提供持续漏洞风险监测、通报、技术支持等保障服务。**▶ 发布会掠影**![](../Images/107cb255c5283d7d86ca554973f627f4.png)*图：会议主持 中国信息安全测评中心副主任 李守鹏*“今朝安全众测平台”启动运行发布会在北京国谊宾馆成功召开。发布会以“群贤毕至谋众测，志存高远话今朝”为主题，由中国信息产业商会指导，中国信息安全测评中心和中国信息产业商会信息安全产业分会共同主办，北京中测安华科技有限公司协办。中国信息产业商会会长聂玉春、中国工程院院士沈昌祥、中国信息安全测评中心主任张峰，来自国家部委和行业主管部门、中国信息产业商会、中国信息产业商会信息安全产业分会以及网络安全领域的几十家相关企业和技术团队代表，部分新媒体代表参加了发布会。张峰主任、聂玉春会长、沈昌祥院士为发布会致辞，麒麟软件有限公司副总经理董军平、上海纽盾科技股份有限公司董事长杨腾霄等企业代表，以及腾讯安全玄武实验室负责人于旸、北京白帽汇安全研究院负责人赵武等技术团队代表进行了发言。![](../Images/dfcdab8ac9ab73e7f6f7d850508065a9.png)*图：中国信息安全测评中心主任张峰*![](../Images/05f3ee68b31b24dd6af87951b9f27f17.png)*图：中国信息产业商会会长聂玉春*![](../Images/2f9614d793901034b58628881c50a02e.png)*图：中国工程院院士沈昌祥*![](../Images/9ab9903bc6b9e60ad945e446703d036e.png)*图：企业和技术团队代表*
