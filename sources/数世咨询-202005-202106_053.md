稳健增长的成绩背后，逃不脱最基本的底层逻辑——帮助用户“降本增效”。

我们知道，数字化转型最大的变化是架构的变化。原来的架构，以数据中心为核心，最终用户偏向静态，80%资产部署在本地，有明确的DMZ边界，安全设备及防护手段都是基于此构建的；而数字化转型后新的架构，是以混合云为核心，存在大量的移动端工作场景，SaaS服务模式50%（欧美），需要的是端到端的自动化。疫情爆发后，全球的数字化进程被迫提速，但传统网络环境与配套的安全防护手段，很难在短时间内跟上这个突然加快的进程，为了临时应对提速的数字化进程，大部分用户机构只有在原有基础上尽力修补。在预算有限、时间紧迫的情况下，用户优先选用兼具网络基础设施建设能力与安全防护建设能力，并将这两方面能力进行融合的既有供应商。Fortinet 很好地满足了客户这一急迫需求。不止于此，随着短时间内的压力逐渐缓解，随后几年内，整合现有优势安全能力、重建安全驱动的网络体系将会是用户的必然选择。据Gartner的调研，“到2025年，超过四分之三的大型企业将会主动进行安全供应商的整合战略”。用户这样的选择，背后的底层逻辑，仍然是“降本增效”的价值诉求。但碎片化的安全行业，是一个“没有寡头、只有诸侯”的行业，为满足客户的这一诉求，目前来看唯一的路是用尽量少的交付接口，为用户提供最多的安全能力，并避免增加集成复杂性。Fortinet的选择是，构建无处不在的坚实的 Security Fabric 安全架构。![](../Images/5408cda31af75be165ec3a162113889c.png)**▶ 核心技术 FortiOS**Fortinet 全新的 Security Fabric 安全架构，由 FortiOS 及多个场景化落地方案组成。其中核心技术 FortiOS 更新至7.0版本，提供了超过300项的新功能，涵盖零信任、SASE、SD-WAN、OT/IoT、云原生、SOC&NOC等多项关键能力。FortiOS 为架构所需的所有安全特性提供了原生的集成能力，所有边缘的安全一致性得到保证，能够适应多云平台的场景。去年，Fortinet 凭借 FortiOS 这一个OS，将两个产品送入Gartner 魔力象限 LEADER（网络防火墙和广域网边缘基础设施）。**▶ 安全驱动的网络**FortiSASE 是覆盖所有访问边缘的云原生安全平台，提供完整的边界接入能力。在云交付接入边缘保持统一的防火墙、安全和网络策略，为分支机构远端用户提供可扩展、高性能的安全接入，同时，SaaS交付模式也保持了网络和运营的灵活性，改善用户体验，降低支出成本。**▶ 零信任访问 ZTNA**FortiOS 7.0 支持每个 FortiGate 客户开箱即用零信任网络访问(ZTNA) 功能，这使得 Fortinet 成为唯一一家支持基于防火墙的 ZTNA 的厂商。与传统 VPN 相比，零信任“从不信任，永远验证”，具备细粒度基于应用的会话级控制等优势。数世咨询下半年会有零信任相关的能力指南报告发布，届时会有详细论述，这里不再赘述，请大家持续关注。**▶ 自适应云安全**从网络、平台、到应用，FortiOS 7.0 实现了自下而上混合云、多云多应用的全覆盖，对云上的原生应用，包括国内阿里云等云厂商在内，做到了无缝集成，且所有的云上用统一的安全策略提供自适应的安全保护，具备深度可见性。**▶ FortiXDR 终端安全解决方案**此次升级，FortiEDR 升级到了 5.0 版本，覆盖平台更全，安全效能与 SOC 效能都有显著提升。同时凭借 Security Fabric，FortiXDR 天然具备了 XDR 所需的扩展检测能力与扩展响应能力，对用户来说，更具价值的是，它由 Fortinet 一家供应商向整个用户团队提供一体化集成与自动化方案，减少了大量的定制与协调工作，降低了采购成本与沟通成本，还是降本增效！**▶ FortiSPU-NP7 **Fortinet 还公布了新一代 Hyperscale 安全芯片 FortiSPU-NP7，该芯片提供了2 x 100 G接口、1亿并发会话、每秒200万新建会话、200 Gbps 吞吐能力、75 Gbps IPSec VPN 等革命性升级，支持超大规模 Hyperscale 级别应用性能，为大规模数据中心及骨干网提供最大化的保护，**▶ Security Fabric 安全无处不在**Fortinet 将核心技术 FortiOS 升级为7.0，通过场景式方案实现了数字化暴露面的全面覆盖，通过深度集成将管理的复杂性有效降低。伴随着数字化转型的一路创新，我们能看到的还有开放的情报共享、AI驱动的高效安全运营、400+生态合作伙伴带来的安全生态动态协同。我们相信，数字世界中的 Security Fabric 将无处不在。  
**数世点评**  

Fortinet的优势在于“稳“。

在目前的中美大环境下，一家做安全的外企，国内能做到20%的增长，一方面是数字化转型这样的市场刚性需求驱动，另一方面更重要的还是要靠产品的过硬质量。对本地化售后力量几乎为0的外企来说（Fortinet国内原厂纯售后仅有30人），一台FortiGate能够稳定运行几千天不出问题不重启，这才是用户心智占有率的基石。

有了发展的基石，不轻易追热点，稳扎稳打，慢慢建立生态，才能有稳健的长远发展。同时，对于碎片化严重的安全行业来说，生态不是简单的做加法，随着公司规模不断扩大，收购并购新产品新团队进入，一定要围绕公司原有的核心基石产品来做整合，把收购过来的东西，技术上做集成，产品上做反向赋能。如此基石才能更为牢固，基石之上的支柱才能立的更多、更坚实。

“稳“中求胜。
