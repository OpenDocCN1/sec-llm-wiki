# 数世咨询招聘分析师

因业务发展需要，现数世咨询面向业界公开招聘。

  

招聘职位：市场或技术分析师

岗位要求：具备IT及网络安全基础知识，良好的沟通能力，自我驱动力强，有主动学习新知识的习惯。

岗位职责：网络安全行业的访谈、调查、研究，撰写报告，提供咨询。

薪资待遇：面议

  

企业优势：

与700+安全厂商、100多家资本方、国家部委有着长期深度的联系，业内资源最丰富；

天然的第三方身份，可靠的口碑和专业的影响力，个人发展空间自由且潜力巨大，同时分析师是一种终身职位，经验越多越受人尊敬；

能为个人快速的学习成长提供良好的基础与条件，具备宽广的视野并能站在国家与产业的高度，了解、评价企业与技术，判断未来趋势；

良好的沟通氛围、和谐的团队文化；

居家办公模式，无需打卡通勤上班；

优秀人才可分配期权，合伙人级别可承诺公司原始股份。

  

机构简介：

  

国内数字产业领域中立的第三方调研机构，以数字时代为背景，提供网络安全行业的调查、研究与咨询服务。数世咨询于2019年12月27日工商注册，2020年2月份正式开始运营。在短短的一年时间里，业内首创网络安全三元论，并基于三元论先后发布了《中国网络安全能力图谱》、《网络安全成熟阶梯》、《网络安全细分领域能力指南》、《网络安全企业图谱》、《网络安全能力100强》等一系列研究报告，均在业内引起较大反响，并受到主管部门、地方政府、资本方、行业用户、安全企业和各类研究机构的广泛关注。
