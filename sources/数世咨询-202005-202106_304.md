# DigiCert的“大市场”和“小问题”

除了经常和网站数字证书打交道的网站运营人员，一般人对DigiCert这家做数字证书起家的公司并不熟悉，但是如果看到“企业数字证书市场占有率第一”，“福布斯全球企业2000强里有80%的企业受到它的保护”，“日均连接次数280亿次”（Google的日均连接数也只是这个数量的5倍）等描述后，相信所有人对DigiCert的最直观感受就是——“大”。如今，TLS/SSL、物联网及 PKI 身份验证及加密解决方案提供商 DigiCert 的确做到了全球第一，从市场这个角度来说，它是最“大”的。  

虽然拥有了“大”市场，但同时它还要解决很多“小”问题。

自2020年9月1日起，浏览器社区（Apple、Chrome、Mozilla等浏览器厂商）强制要求（新签发的）公信TLS证书有效期不得超过1年。

这是什么概念？以前，TLS证书曾经允许的最长有效期限是5年，现在只有当初的5分之一。如此一来，新签发的短证书，加上原来已签发，但尚未到期的长期证书混杂在一起，再加上自签发证书、僵尸盲点证书等意外情况，传统的excel表格和日程提醒已经无法有效满足网站运营人员的需求。一不留神，你的网站就可能被浏览器标注为“不可信”。对于很多企业的在线业务来说，这会造成直接的经济损失。

更短的证书生命周期，就意味着企业需要更加“小”粒度的灵活证书资产管理方案。证书发现能力、敏捷管理、自动化等都是目前证书管理的实实在在需求。

此外，除了福布斯企业2000强这样的大型客户，对于没有能力自建PKI的“小”企业来说，还需要云化或基于容器可扩展的数字证书产品。

面对这些“小”问题，DigiCert通过CertCentral®、DigiCert ONE等新的产品功能，以及创新的多年期证书订阅套餐服务，为用户提供了针对性解决方案。

通过CertCentral® TLS 证书管理平台，DigiCert向中国客户提供新的多年期证书订阅套餐，帮助中国客户自动化执行年度证书购买、简化证书更新等过程，全面管理整个证书生命周期，为企业减轻数字证书的管理负担。此外，用户还可通过多年订阅中的价格折扣降低成本，订阅周期最长可达6年。

除了有效减少证书中断，DigiCert CertCentral® 的以下功能还能帮助用户进一步节省时间，例如：

*   支持客户服务器上运行的几乎所有 ACME 客户端的新订单
    
*   支持跨越多服务器的更大规模网络自动化和检测
    
*   利用感应器进行易于管理和可扩展的 ACME 部署
    
*   与 OEM 解决方案（例如F5、Citrix、NetScaler、A10）以及流行的服务器编排和管理平台进行无缝集成
    
*   通过 API 接口进行定制自动化，从而将 DigiCert 工具和客户系统整合在一起
    
*   通过 CertCentral® 控制台自动更新配置
    

对于没有能力自建PKI的广大中小企业，DigiCert ONE提供了一种整体的PKI管理方法。它基于容器设计，允许用户在任何环境中快速部署。在不同规模的端到端用户和设备管理中，只需很短的时间就可以推出新服务。

解决了“小”问题，DigiCert的能力在中国这个“大”市场也得到了验证。自 2001 年以来，DigiCert 已发展为中国最大的数字证书供应商，中国三大运营商和排名前6的商业银行都通过 DigiCert 的产品和解决方案来保护自己的网站。通过吸收中国员工和支持人员、设立区域数据中心和定制的中国中级证书等方式，DigiCert 中国已成功实现本地化运营。
