# 凭借SD-WAN，Fortinet“出圈”了？

在Gartner不久前发布的2020年度广域网基础设施魔力象限（Magic Quadrant for WAN Edge Infrastructure）报告中，分析师使用了“拥挤”来形容该细分市场的现状。魔力象限中，处于LEADERS领导者象限的厂商有6家之多，而在前两年（2018、2019），这个位置的厂商数量分别是3家和2家。如果加上CHALLENGERS象限中的两家，一共8家厂商。我们来看看这8家都是什么来头：![](../Images/c255cde23123f4625d12c2e905e85268.png)四个类型，每类2家，恰好平均地分属不同细分行业。来路不同，但都在执行力、前瞻性这两个维度充分打动了Gartner的分析师。上面这个简单统计，说明了市场对SD-WAN的需求仍处在旺盛期，这块蛋糕仍在整体不断做大，越来越多的厂商都能在这一领域找到自己的一席之地。鲨鱼虽多，但好在海很大。为什么是SD-WAN？SD-WAN从诞生之日起，它所涉及的技术，没有一种是非常前沿的技术。它的设计目的是用各种成本较低的链路代替昂贵的私有专线或者MPLS。但是目前阶段，很多企业不愿意完全放弃有业务质量保证的专线，所以更倾向于部署混合网络，即在保留原有私有专线的传送关键数据的基础上，根据业务优先级，将部分相对不重要的流量动态迁移到云端和公共宽带网络，包括无线LTE网络上。不难总结出，大部分用户需要的是这样的SD-WAN：

*   高性价比，节省成本是第一诉求
    
*   简单易上手，就像配置家用路由器一样
    
*   能针对业务场景进行应用识别和优化
    
*   和已有第三方解决方案进行编排和集成
    
*   支持云连接
    
*   支持4G/5G LTE
    

加之近两年勒索病毒、挖矿木马等安全威胁肆虐，一旦安全事件发生，必要时，用户要求能够对存在威胁的分支网络进行隔离，以免影响全局网络的安全性与稳定性。因此，SD-WAN用户又增加了“具备安全功能”这一需求，例如NGFW下一代防火墙。因此，安全厂商，特别是网络控制类安全设备厂商转型做SD-WAN，就具备了成熟的理由和条件。安全驱动的SD-WAN解决方案，也成为了更多市场所认可的选项。为什么是Fortinet？  
今年的魔力象限中，LEADERS里有一条拥有安全基因的“鲨鱼”——Fortinet，它在前两年还是CHALLENGER挑战者的角色，今年不但大幅右移，进入领导者象限，而且一度跃升到了第二的位置。

![](../Images/46f19beb85537c58b9ab7d00375e7417.png)

既然SD-WAN技术门槛不高，玩家众多，就不存在通杀全场的银弹。这家做防火墙硬件盒子出身的“鲨鱼”，是如何从后院游泳池跃入SD-WAN这片蓝色海洋的呢？在Fortinet的SD-WAN解决方案中，数世分析师认为，以下几点让人印象深刻：

*   FortiGate这样一个防火墙产品，从10+到1000+，不同规模，全线型号，都具备SD-WAN能力，只需使用较新的FortiOS版本（如v6.2+），无需额外授权，防火墙直接免部署变SD-WAN；
    
*   去年发布的首款SD-WAN专用ASIC 芯片Fortinet SoC4，让FortiGate在CPE设备方面提供高性能的同时，还具有极高的性价比。据称结合线路方案后，相比传统专线方案，能够帮助用户节省费用40%-60%，这对用户采购部门非常有吸引力；
    
*   OS层面每年有1个大版本更新，每次功能更新数量在两位数以上，且全部功能都是自研，这使得用户的体验好感度提升会很明显；
    
*   新的编排器，简化了配置和运营，使其具备了大规模部署、跨国部署、跨洲部署能力；
    
*   积极与运营商和云服务商的激进合作策略，使其与云的连接更加全面和深入，针对SaaS应用的精准识别和流量选路分路也让Fortinet在门店零售、全球在线教育等多个场景下的表现，会给用户带来更加直观的体验；
    
*   安全方面，从必要的NGFW功能到集成SASE，这是Fortinet的基因，也是传统优势。
    

硬件、软件、性能、管理、生态合作、安全等多个环节的微创新叠加在一起，形成飞跃，满足、甚至超出用户对SD-WAN的需求预期，Fortinet就这么出了圈。“出圈”这事靠谱么？众所周知，Fortinet是一家安全厂商，而实际上SD-WAN是网络设备，因此，Fortinet算是“出圈”。那么问题来了，出圈这事靠谱吗？回答这个问题前我们先来看一个模型： ![](../Images/c723beaf20a42534925e0987c9811363.png)*上图是前段时间，数世咨询发布网络安全能力图谱时，在业内首次提出的「网络安全三元论」。（详见链接：*[*《2020年度珍藏：中国网络安全能力图谱（完整版）》*](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247484926&idx=1&sn=9657ffb58a99611cf8ea787e5a16dc48&chksm=c1477743f630fe552805b7a5552cc35c7fdaeb2773d1a00adfb1491aa13772e49e397358f106&scene=21#wechat_redirect)*）*业内传统的对网络安全能力的梳理大多集中在安全专业技术上（图中右下角红色端点），但实际的情况是，离开信息技术的基础环境，网络安全技术是不存在的，而离开业务需求与应用场景，安全保障手段就无法落地。不同的信息环境和应用场景决定了网络安全解方案也不尽相同。回到SD-WAN，用户采用SD-WAN的本质目的是“降本增效”，“降”——网络基础设施成本，“增”——业务场景下的效率和体验。Fortinet 安全驱动的SD-WAN解决方案，就是将其擅长的**安全能力**与**基****础网络环境、业务应用场景**（与云服务商的合作、对业务场景下SaaS应用的精准识别和优化）三者结合在了一起。Fortinet 从2016年开始才进入这一领域，只用了不到5年时间，就来到了魔力象限第2，全球市场占有率排第3，获评Gartner增速最快供应商。“出圈”一事，靠谱。当然，客观的讲，Fortinet的“出圈”也并不是已经完全做到位了。例如SD-WAN业务的收入占比目前只有15%；硬件盒子厂商的基因仍然很深，如果想要学习友商的订阅付费模式等等，这些都需要过程和时间。但不管怎样，Fortinet已经给我们打了个样。实际上在整个网络安全圈，已经呈现出“出圈”的趋势。如，做数据安全的开始做大数据分析，做上网行为的开始做应用交付，做防火墙的做SD-WAN自然也是顺理成章的事。国内安全产业要做大，安全厂商要“出圈”，以上这三个方面的结合，缺一不可。
