# 开源网安获数千万元A轮融资，聚焦软件安全产业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247485111&idx=2&sn=32d74290db94aa98fe25d262abddb1d7&chksm=c147740af630fd1c349a28233ec43742c327b60e0ec9312339cad98e81150b6c7f79caa6b1b8&scene=126&sessionid=1681323409#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247485111&idx=2&sn=32d74290db94aa98fe25d262abddb1d7&chksm=c147740af630fd1c349a28233ec43742c327b60e0ec9312339cad98e81150b6c7f79caa6b1b8&scene=126&sessionid=1681323409#rd)

2020年，“软件安全行业创领者 ”——开源网安完成A轮融资。此轮融资由松禾资本、匠一基金共同完成。开源网安在获得此轮融资后，将继续加大团队建设、产品完善、市场布局、技术研究等，全力促进公司产品、服务的日趋完善。  
开源网安自2013年成立以来，**专注“软件安全开发”**技术领域和**“软件安全行业”**，为客户提供软件安全开发生命周期 (S-SDLC) 解决方案、DevSecOps解决方案、完整的拥有“自主知识产权”的软件安全开发工具链（IAST、SAST、SCA、FUZZ、RASP）和软件安全开发人才培养课程体系CWASP。

![](../Images/8fe220bafa6c82d3974905af385c109c.png)开源网安业务全景图

  
开源网安总部在深圳，同时设有北京、上海、广州、武汉、成都、合肥分支机构。团队由来自华为、思科、微软等行业顶级的软件开发安全专家组成，团队核心成员从业经验均为10年以上。潜心专注打磨软件安全全生命周期的相关产品、解决方案及安全服务。  
作为**软件安全行业创领者**，开源网安积极践行“**让企业交付更安全的软件**”的核心理念，全力帮助企业提升软件产品的安全与质量。开源网安拥有大量世界500强和国内头部企业的成功案例，同时公司产品可完全替代Gartner应用安全魔力象限“领导者”厂商的产品。目前，开源网安已在金融、能源、政府、监管、通讯、软件、教育等行业积累了大量成功案例，并在各类项目实践过程中结合各行业的客户实际需要和应用场景，有效地提升其软件开发、安全管理工作的效率和质量。服务客户包括不限于：平安银行、中信银行、微众银行、国信证券、中国石油、国家电网、南方电网、华为、百度、金蝶软件、碧桂园、IBM等大型企业。   
在国家大力促进发展软件产业高质量发展的形势下，开源网安将响应号召、把握机遇、深化应用，为国内软件安全开发技术领域、软件产业及网络安全保障的发展提供更坚固有力的支持。  
越是基础，越要谨慎，IT产业侧重点从早期业务先行，转变为现在的发展+安全并行。软件安全作为IT产业的底层部分，逐渐引起企业越来越多的重视和投入，可以预见软件安全行业将会迎来更多的机遇。同时随着国家对基础软件行业的大力扶持，软件安全市场会迎来爆发。  
国内的大型基础软件、工业软件的核心技术和能力相对薄弱，各类企业和用户在国产化替代的进程中会面临更多的安全风险。而对于一些大型的IT厂商要求合作方共同形成“国产化替代链”，以降低未知安全风险和安全成本。综合各种因素来看，未来的一段时间内，国内基础软、硬件和重要IT安全服务将保持强劲的发展趋势。  
公司从成立多年到现在，一直倡导以产品技术为核心，一朝一夕、一步一个脚印，踏实务实，不浮躁；团队延续了低调务实、居安思危的风格，坚信“板凳要坐十年冷，烧不死的是凤凰。”
