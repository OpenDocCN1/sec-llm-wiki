# 迈克菲IPO欲揽6亿美元 公司估值36亿美元

如果股票在高位股价售出的话……  
据报道，迈克菲公司（不是那位传奇创始人）寻求在即将到来的首次公开募股（IPO）中筹集6亿多美元资金。此前几周，迈克菲的首次公开募股（IPO）申请中，欲筹集资金暂填为1亿美元，而投资者估计，最终金额可能超过20亿美元。从S-1表格看，该公司将以每股19~22美元的价格向市场推出3100万股。现有股东将拿出600多万股变现。如果以22美元高位股价出售股票，这笔交易将使迈克菲的市值达到36.4亿美元。迈克菲在申请材料中称：“我们估计，此次募股所得净收益约为5.88亿美元，如果承销商完全行使购买权买入额外A级普通股份额，则净收益约6.12亿美元。”材料中补充道，部分资金将用于偿还公司的部分债务和购买B级股票。迈克菲在美国投资招股说明书中声明，截至2020年6月27日，该公司的产品“守护了超过6亿台设备”。截至2020年6月27日，迈克菲今年上半年净利润为3100万美元；上一财年（2019年），公司营收26亿美元，净亏损2.36亿美元。正如此前报道的，与拆分时英特尔安全11亿美元的季度收入相比，迈克菲的收益相当不够看。回顾历史，2010年，迈克菲以76.8亿美元卖身英特尔，股价重回29.93美元的黄金年代。四年前，英特尔将手中多数迈克菲股权出售给私人股本公司TPG。长期以来，迈克菲的防病毒产品在电脑用户中口碑并不怎么好，尤其是2018年的更新恶作剧导致运行迈克菲端点安全的计算机崩溃之后。同年晚些时候，一家安全公司声称，尽管发布了两个修复补丁，但迈克菲True Key软件中的提权CVE尚未完全解决。也许此次IPO将揭示出迈克菲藏了十年的一些压箱底金融或技术魔法。®注：约翰·迈克菲（John McAfee），迈克菲公司创始人，于20世纪90年代卖掉了公司，上周因涉嫌逃税和违反美国证券法而被捕。他丰富多彩的经历很可能在这位74岁老人即将面临的法律诉讼中留下浓墨重彩的一笔。*关键词：迈克菲；IPO*▼往期精彩回顾▼[迈克菲9月28日申请IPO](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247484999&idx=2&sn=2898e4f7622c14d299adad35ec6d05c4&chksm=c14774faf630fdecbd402472a70e70f9f8d4f3b95e6a890620828d55a36b4366657743ecc5fc&scene=21#wechat_redirect)
