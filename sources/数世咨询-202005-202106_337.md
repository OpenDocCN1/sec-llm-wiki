# Palantir低调上市

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247484999&idx=1&sn=4b7c09ec772709f7692954fcac2ba854&chksm=c14774faf630fdecac02ee212f4cf959edc97b80f260f7813bc835efacb057799bb5d7f4cf45&scene=126&sessionid=1681323414#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247484999&idx=1&sn=4b7c09ec772709f7692954fcac2ba854&chksm=c14774faf630fdecac02ee212f4cf959edc97b80f260f7813bc835efacb057799bb5d7f4cf45&scene=126&sessionid=1681323414#rd)

![](../Images/e43122920b5a6a606ded58fe0b3e9d6f.png)9月30日，因司法和国家安全工作而惹争议的数据分析公司Palantir，在华尔街低调亮相，估值超过200亿美元。  
Palantir公司得名于《指环王》中神秘的万能魔眼石。这家公司选择不筹集资金但可以公开交易股票的方式直接上市。没有敲钟，没有大肆宣传，Palantir在纽约证券交易所以代码PLTR开盘上市。当天午后，Palantir以10美元的价格开盘，市值约为217亿美元，接近私人投资者的估值。 一番波动之后，Palantir收于9.73美元，市值约为211亿美元。这家成立于硅谷但最近搬到丹佛的公司宣称，其技术平台帮助抓捕恐怖分子，确保民众安全。但是一些激进主义者认为，Palantir的技术搜集财务记录、社交媒体帖子、通话记录和互联网记录，为无视隐私权和基本人权的大规模监视提供了前所未有的机会。大赦国际（Amnesty International，国际特赦组织）在本周的一份报告中称，Palantir与美国当局签订的合同以寻求庇护者为目标，“对公司尊重人权的责任提出了严重质疑”。报告表示，根据联合国准则，Palantir“有责任避免造成或助长人权侵犯，并应解决其所涉人权影响”。在对大赦国际的回应中，Palantir称其与美国海关与边境保护局没有签订任何合同，并声称这是对其活动的“合并和扭曲”。在招股章程中，Palantir表示其为“旨在保护民众安全的”国防和情报机构提供软件，并补充称，公司避免使用其他大型科技公司所用数据跟踪技术。该公司表示：“我们的软件用于锁定恐怖分子和确保士兵安全。我们已经站队，并且很清楚我们的合作伙伴重视我们的承诺。”**追踪本拉登**为应对911恐怖袭击，Palantir成立于2003年，从美国中央情报局（CIA）风险投资部门获得了启动资金。据报道，其预测分析曾帮助美国军方定位本·拉登（Osama bin Laden）和跟踪中东的武器流向。颇惹争议的“预测警务”实践中也使用了Palantir平台，用来帮助执法、检测医疗保险欺诈和抗击新冠疫情。尽管数据操作和算法保密，但Palantir声称，公司所遵循的路线图比同行竞争对手更合乎道德（如果这行有道德可言的话）。该公司今年将总部迁至丹佛，其中部分目的就是区别于硅谷竞争对手，彰显其卓尔不群的“道德性”。Palantir称：“从一开始，我们就一再拒绝售卖、收集或挖掘数据的机会。”Palantir备受争议的源头之一是其联合创始人兼大股东Peter Thiel。他是Facebook的早期投资者，也是2016年大选时支持特朗普的极少数科技高管之一。自诩为社会主义者的首席执行官Alex Karp无视对公司的批评，坚称科技公司不应为公共政策负责。Palantir去年营收7.43亿美元，亏损5.8亿美元，上市将给公司招致新一轮的审查。 投资者面临的一个问题是非传统的治理体系。独立技术分析师Richard Windsor表示，该公司的“投票机制会极度偏向其创始人，使投资大众面临为公司的错误决策付出经济代价的极大风险。”Palantir创始人持有的B级股1票抵A级股10票，还有具备可变投票权的新类别。 这种机制下，除非全部创始人都离世，否则在世的创始人享有公司的完全控制权，其他股东则对公司毫无发言权。*关键词：数据分析；上市*
