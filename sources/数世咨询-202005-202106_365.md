# 2020中国(济南)网络安全高峰论坛举行

9月6日上午，2020中国(济南)网络安全高峰论坛在济南山东会堂举行。本届论坛以“新基建下的工业互联网网络安全”为主题，旨在深入贯彻落实习近平总书记“网络强国”重要思想，坚决维护网络安全，全力推动新基建下互联网健康发展。国家互联网应急中心副主任杨君佐，山东省委网信办副主任赵树岭，国家计算机网络与信息安全管理中心山东分中心主任安茂波，国家计算机网络与信息安全管理中心山东分中心副主任兼总工程师赵煜，中国信息安全测评中心副主任温哲， 济南市委常委、宣传部部长杨峰，济南市副市长、市政府党组成员、市公安局局长吴德生，济南市副市长、市政府党组成员孙斌出席活动。以及相关主管单位、学术机构、协会联盟、化工龙头企业、网络安全企业、知名学者、媒体等600余人参加本次论坛。📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1508239998943346689](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1508239998943346689)本届论坛由山东省委网信办、山东省公安厅、中国信息安全测评中心、国家计算机网络与信息安全管理中心山东分中心指导，济南市委网信办、济南市工业和信息化局、济南市公安局主办，山东云天安全技术有限公司等单位承办。本届论坛由北京赛博英杰科技有限公司董事长谭晓生主持。济南市委常委、宣传部部长杨峰，山东省委网信办副主任赵树岭，山东云天安全技术有限公司董事长李峰为高峰论坛致辞。论坛上，中国科学院院士钱锋、中国工程院院士沈昌祥、中国科学院复杂系统管理与控制国家重点实验室主任王飞跃、中国科学院信息安全国家重点实验室教授吕述望、中国化工集团大数据首席科学家冯恩波等专家学者做了主旨演讲。中国工程院院士倪光南发来了视频致辞。中国网络安全行业内最专业且具影响力的研究媒体“数说安全”，在论坛中发布了“2020中国网络安全市场全景图”。  
![](../Images/3d9bb624118450b4cc211c38daa5356c.png)钱锋院士指出，我国石油和化学工业面临着产品结构性矛盾突出，产业布局不合理，信息孤岛情况突出、业务间缺少协同，能耗高、安全环保压力大等问题。因此，亟待依托工业互联网，一方面全面打通企业外部产业链供应链信息，实现供应链现代化；另一方面打通企业内部网络，实现产业链高端化和价值链最大化，从而推动石油和化学工业高质量发展。并针对工业互联网赋能石油和化学工业高质量发展，给出了标准、基建、平台、生态、人才等方面的发展建议。沈昌祥院士提出，“新基建"作为国家经济发展战略，正在显现出强大动能，聚焦新旧动能转换，助力信创产业迈向新高度。环境与市场机遇对网络安全提出了严重挑战，必须有效应对垄断网络空间霸权威慑，以主动免疫可信计算筑牢网络安全防线。王飞跃教授指出，“新基建”是建设智慧社会基础设施的开始，在确保新旧动能转换、新旧产业升级的同时，为构建新型智能化基础设施打下坚实基石。为此，“新基建”下人工智能面临的安全态势与对策，成为全球各国关注的核心问题。并从平行智能和平行安全的角度对此进行了讨论。吕述望教授指出，讲网络空间安全，一讲主权，二讲不受制于人。中国的网安世态不容乐观，网络主权是建设出来的，是租不来的，网络空间要不受制于人就要创新，创新网络强国建设！冯恩波博士讲到，流程工业的运行优化技术软件体系，有其复杂性、可复制性差、技术壁垒高的特点，同时企业数字化智慧化工作极大地依赖于具体项目执行人的业务能力。在每一个项目完成后，所积累的数据分析结果和知识，一般都是以文档形式保存，很难固化成为一种自动的知识型应用系统，因而极大地浪费了企业的知识资源和数据资源。冯博士从知识自动化的角度，讨论流程工业软件自主化，提出一些观点和建议，并对典型案列进行解析。山东云天安全技术有限公司的董事长李峰和CTO张俭峰在致辞和主旨演讲中指出，对于新基建下的工业互联网安全，要以“云+网+端+验”为核心，构建“打防管控”的多重网络防御与预警安全运营服务系统，并进而生成三种能力,即应用场景服务能力，自我进化能力，网络安全作战能力，从工业资产探查、漏洞监测到安全方案规划、安全设施运行监控、安全事件响应、工控系统网络安全攻防对抗等一系列事件，建立集感知、分析、安全、控制、优化、培训于一体的自下而上解决痛点、痒点和盲点的平台，不断提升工控系统安全防范能力，最终提高企业的本质安全水平。
