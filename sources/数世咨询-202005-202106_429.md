# 电子商务黑客新招：利用图片元数据藏匿信用卡信息盗取器

![](../Images/18be33126432cd2f331feda9f4961170.png)在新型黑客攻击活动中，网络犯罪团伙将恶意植入代码隐藏在图像文件的元数据里，秘密盗取被黑网站访客输入的支付卡信息。6月底，信息安全公司Malwarebytes的研究人员称：“我们发现信息盗取代码隐藏在图像文件的元数据中（一种隐写术），并由受黑客控制的在线商店秘密加载。”“搭配上另一个有趣的被盗信用卡数据渗漏方案，这套隐写偷盗术才算得上完整。当然，网络罪犯用来收集赃物的方法，同样采用了图像文件作为伪装。”这种进化中的攻击战术常被称作Web信息刮取或Magecart攻击，随着黑客不断发现注入JavaScript脚本的新方法而出现。错误配置的AWS S3数据存储桶，以及利用内容安全策略向黑客控制下的Google Analytics账户传输数据，都是执行JavaScript脚本注入的途径。**使用隐写术在EXIF中隐藏信息刮取器代码**依托在线购物的蓬勃发展，此类攻击通常将恶意代码插入被黑站点，秘密收集用户输入的数据，并将之发往网络罪犯的服务器，以此获取购物者的支付信息。![](../Images/d680da0d5ae368f29db7f30cfe1b8cd7.png)Malwarebytes发现，在为期一周的黑客活动中，信息刮取器不仅存在于运行WooCommerce WordPress插件的在线商店里，也包含在可疑域名（cddn.site）网站图标的EXIF（可交换图像文件格式）元数据里。每张图像都嵌入了有关图像本身的信息，例如相机制造商和型号、照片的拍摄日期和时间、位置、分辨率、相机设置，以及其他详细信息。黑客利用此EXIF数据执行了一段JavaScript代码，这段代码就隐藏在网站图标的“版权”字段中。研究人员表示：“与其他信息刮取器一样，这段信息刮取代码抓取的也是输入字段的内容，而这些字段往往承载的是网购者的姓名、账单地址和信用卡详细信息。”除了使用Base64格式对捕获的信息进行编码，并反转输出字符串，黑客还以图像文件的形式传输被盗数据，借以隐藏渗漏过程。Malwarebytes声称此次黑客行动可能是Magecart Group 9所为，且信息刮取器的JavaScript代码采用WiseLoop PHP JS Obfuscator库加以混淆。![](../Images/140180d9d1e237df54e1cf0c4a8ed18c.png)*图中文字：

**下：用FormData API将被盗数据作为网页图标image/x-icon发送。*利用图像作为攻击途径来入侵电子商务网站的事，Magecart组织不是第一次干了。早在5月份，安全研究人员就发现，有几个被黑网站的结帐页面上加载了恶意图标，合法在线支付表单因而被替换为伪造的欺诈性表单，然后用户的银行卡信息经由这些虚假表单失窃。**滥用DNS协议从浏览器中渗漏数据**数据窃取攻击不一定局限于恶意信息刮取器代码。安全研究员Jessie Li演示的另一种技术中，可以利用DNS预取来从浏览器窃取数据。DNS预取是一种减少延迟的方法，用于在请求资源（如文件、链接）前解析跨域DNS查询。这款名为“browsertunnel”（浏览器隧道）的开源软件由服务器和客户端组成，服务器解码工具发送的消息，客户端JavaScript库编码并传输这些消息。![](../Images/137dc2ac2bd65ea6ef6d1b1f81de3c96.png)消息本身是经过编码的任意字符串，存放在浏览器解析的顶级域名的子域名字段。该工具监听DNS查询，收集入站消息，解码这些消息就能抽取相关数据。换句话说，“browsertunnel”可用于在用户执行特定网页操作时大量收集敏感信息，然后伪装成DNS流量渗漏到黑客的服务器。DNS流量不出现在浏览器的调试工具中，不会被网页的内容安全策略（CSP）阻止，企业防火墙或代理也常常不会检查DNS流量，所以DNS流量是在受限情况下偷运数据的理想媒介。*关键词：图像元数据；DNS预取*
