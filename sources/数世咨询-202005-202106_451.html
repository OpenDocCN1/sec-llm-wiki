评估新工具时哪些用户体验最为重要？

难以操作的安全工具越来越多，是网络安全主管和安全从业人员最不愿意看到的。那么，评估新工具时，他们主要考量什么呢？
网络防御领域的猫鼠游戏中，坚实的检测算法和高效的防御技术是重中之重。但是，如果工具本身死板笨重难以操作，那就算有最完美的后端引擎也无济于事。
可用性对于安全工具是否能发挥效用至关重要，而且不仅仅是在工具面对最终用户的时候才体现出重要性。由于要面对的控制面板太多，且需管理的安全产品组合不断增加；在有效使用工具方面，安全管理员、分析师和其他利益相关者已经分身乏术。他们最不想看到的，就是难以操作的安全工具越来越多。
近日，多位安全高管和资深产品设计师，分享了他们在评估新工具的用户体验时最为看重的特质。以下就是他们从业多年的经验之谈。
方便部署
“如果不得不等待中断窗口、网络调整或部署代理，那评估得分肯定不会高。我们需要的是可以干净利落地部署并顺畅运行的解决方案。前不久，我们实现了一个新的反垃圾邮件/网络钓鱼/恶意软件解决方案，全面部署这个解决方案耗时不到 10 分钟。既不用配合网络流量安装设备，也不用处理中断窗口。我们只是将我们的电子邮件平台接入新服务，然后，几分钟之内，14 个不同国家和地区的数万用户就都受到保护了。这才是解决方案的正确部署方式。”
——John Masserini，Millicom Telecommunications 全球 CISO
操作门槛应尽可能低
“对管理员而言，安全工具的可用性可谓十分重要，因为他们往往要兼顾太多解决方案，而手里的资源又太少。所以，以最少的培训正确配置和维护解决方案的能力，才是安全解决方案成功的决定因素。”
——Jayanth Gummaraju，Banyan Security CEO
容易上手的图形用户界面 (GUI)
“我敢肯定，一些安全老手并不关心 GUI。他们更喜欢用命令行玩转一切（如果有命令行接口的话），因为他们认为这样更高效。然而，在我看来，即使不需要 GUI 的高级安全专家，仍可看到 GUI 的价值，因为 GUI 更便于工具推广使用，从而提升威胁可见性和降低安全风险。”
“给工具配上用户友好的 GUI 还有个好处：可供更广泛的团队成员使用。也就是说，你不用依赖团队中经验最老道的员工，还可以让新成员快速上手。再者，便于使用的界面也有利于风险治理等其他部门访问数据，让他们无需求助核心安全团队即可获取工作所需的宝贵信息。”
——David Levine，Ricoh USA 信息安全副总裁兼 CISO
切勿扼杀命令行的力量
“跟大家一样，安全运营中心 (SOC) 分析师也欣赏有用且优雅的用户界面 (UI)，认为这种界面能帮助自己快速纵览全局。但同时，分析师常常需要深入挖掘取证数据的细节。这种情况下，API 或命令行接口通常就优于漂亮的 GUI 了。”
——Phil Neray，CyberX 物联网和工业网络安全副总裁
配置即代码
“尤其是在应用程序安全领域，友好的 GUI 并不总能转化为可用性改善。开发运维工程师在跨 5 万个构建作业扩展配置时，基于 UI 的方法本质上是限制而非促进，会妨碍快速全局配置的能力。而依赖‘配置即代码’的方法恰能完美适应这种情况。当今大多数持续集成系统为什么都更重视采用配置即代码的流水线配置，而不是相应的 UI 组件，原因正在于此。”
——Utsav Sanghani，Synopsys 高级产品经理
开放平台
“弄清楚怎样将解决方案接入开放平台，好方便共享数据，让所有团队都能使用通用控制面板。每年发布一个版本修复漏洞或满足要求，让产品更便于使用。这些就是我们要在我们的合作伙伴身上找寻的特质。”
——John Masserini，Millicom Telecommunications 全球 CISO
简化管理
“安全团队不堪重负是个公开的秘密：人手太少、时间不够、工具太多太复杂。工具应该成为能力倍增器。如果难以使用，那么工具带来的问题就多于收益，会拖累事件响应和检测，浪费资源，并使分析人员陷入困境。”
——Joe Payne，Code42 总裁兼 CEO
生成概要
“优秀的安全工具可以指导用户采取正确的措施，而不是以‘灵活性’的名义呈现无止境的选项目录。优秀的安全工具梳理大量数据，呈现便于采取行动的概要，支持用户决策。优秀的安全工具预测用户想要做什么，提供顺畅的用户体验帮助用户快速达成所愿，从而减少摩擦。”
——Lior Neudorfer，Guardicore 产品副总裁
别让配置成为苦差事
“观察 Web 应用防火墙 (WAF) 的工作方式，你会发现很多 WAF 最终都被束之高阁，因为将 WAF 安全插入 Web 流量并调校减少误报很难，难到甚至妨碍系统运营。所以，操作人员可用性甚至是真正部署下去的关键组成部分。”
——Andy Ellis，阿卡迈 CSO
警报保真度影响用户体验
“对于安全人员来说，用户友好的工具可以推动更广泛的快速采用，但用户友好度的推动作用，可能不如工具为解决关键问题提供的功能那么强大。在威胁检测与监视领域，考虑到功能本身的效率，利用 AI/ML 及其他行为技术提供更高置信度的解决方案，通常被认为是更加用户友好的。
——Deborah Golden，德勤风险与金融咨询公司美国网络风险服务主管
