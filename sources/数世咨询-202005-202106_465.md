# 安全技能测试新平台：针对6种需求最大的安全岗位

为企业招聘到合适及胜任的员工是人力资源部门的职责，因此对应聘人员的能力测试是招聘流程中的核心工作。国外安全公司Cynet最近推出了一优化招聘流程工作的，针对安全技能测试的自动化在线平台：https://cybersecurity-skill-tests.com/。该平台汇集优化了几百个招聘安全技能的相关问题，并针对6种需求最大的安全岗位划分了难度级别，每个级别含25个问题，涉及到每种职位所需的各种重要知识。而且，为了防止应聘者作弊，平台保证每次出的问卷内容都不会一样。有招聘需求的企业可以在平台上将应聘者的姓名、邮件和应聘职位填入，问卷就会自动生成并发送给应聘者。一旦应聘者把问卷答完，招聘方就能够在招聘面板上看到应聘者的分类以及答题所用时间等信息，帮助招聘方快速的把优秀者挑选出来。![](../Images/e13b3bce98e89539830bfe06c10ed8bb.png)下面是6种需求最大的安全岗位描述：**SOC经理**负责建立和监管安全事件的监测、管理和响应等工作流，同时确保合规和流程动态修改，以完成运营目标。**SOC分析师**负责初始警报分类、快速响应、调查、缓解措施管理和主动威胁检测。**恶意软件分析师**通过逆向工程、静态/动态分析等方法研究已经发现的恶意软件，并对这些恶意软件针对目标企业的威胁性质提供建议。**安全架构师**负责组织IT网络的安全系统设计、建立、测试和实施，保护业务和客户数据。**IT安全人员**负责IT与基础网络安全的策略和标准，该岗位适用于对安全技能有需求但却无力设置专职安全岗位的组织。**事件响应人员**对整个安全运营的生命周期负责，从初始的可疑活动分析到取证调查，了解入侵事件的影响范围、根源因素，到最终的缓解与恢复工作。*关键词：安全人才；人才招聘；技术测试；*
