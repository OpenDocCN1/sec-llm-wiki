# 2020年度网络安全八大前沿技术

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247484604&idx=1&sn=d9f48330df729a0b2b41fb7a41ae07b6&chksm=c1477601f630ff1781be237d35e37e1804a70ed209dbe29df0e9f01d860595aea0d5ee13681a&scene=126&sessionid=1681323470#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247484604&idx=1&sn=d9f48330df729a0b2b41fb7a41ae07b6&chksm=c1477601f630ff1781be237d35e37e1804a70ed209dbe29df0e9f01d860595aea0d5ee13681a&scene=126&sessionid=1681323470#rd)

继数世咨询发布[热点市场、潜力技术](http://mp.weixin.qq.com/s?__biz=MzIzNTkxMTI4MQ==&mid=2247484242&idx=1&sn=4b79dda50f865a39af1abca20ecf6eb4&chksm=e8dea24cdfa92b5adeb2bde2ec67bcb57d7d5af41c0c3e4c9d7990377b331cda45fd3dcb5191&scene=21#wechat_redirect)与[市场前瞻](http://mp.weixin.qq.com/s?__biz=MzIzNTkxMTI4MQ==&mid=2247484365&idx=1&sn=c3742df65cd2e52932fa72c788a58a67&chksm=e8dea2d3dfa92bc59e84c06c3c381a1dd9a49b6244641c06b8f951fdfce285fd468d2d1069be&scene=21#wechat_redirect)两个年度报告之后，本次推出网络安全八大前沿技术。这些技术绝大多数位于概念市场的阶段，能否落地均带有一定的未知因素，但其中蕴含的技术理念和设想，或能激发更多的智慧产生。值得关注的是，在八项前沿技术中，有五项属于通用概念（技术）领域，意味着重大的创新总是源自于基础性技术的变革。

**2020年度网络安全八大前沿技术**  

  

  
AI防火墙  

**所属领域：**访问控制

**所属分类：**防火墙

![](../Images/f3a1a1d6f6ff0577b4750ae009dcaea3.png)

  

**成 熟 度 ：**概念市场

**代表厂商：**华为、新华三

![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**以AI芯片为决定性因素，注定以软件为核心的网络安全厂商无法企及。但AI芯片专注的是运算而不是对抗，因此未来的成本问题决定着网络安全厂商的介入程度。

  

  
边信道  
**所属领域：**计算对象**所属分类：**物理安全

![](../Images/4e4702f83a635680c92154c192585564.png)

  
**成 熟 度 ：**无**代表厂商：**无![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**全球最知名的边信道研究在以色列本-古里安大学，至今为止已经研究并测试成功数十种攻击方法。韩国科学技术研究院也有相关研究。该项技术主要受到情报机关和军方的关注，且大多集中在概念验证阶段，国内尚未公开披露这方面的研究。

  

  
电磁脉冲攻击与电磁压制  
**所属领域：**计算对象**所属分类：**无**成 熟 度 ：**无**代表厂商****：**无![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**纯暴力破坏行为，极端状态下使用，如战争。电磁脉冲攻击(EMP)可以摧毁附近所有正在运行的电子产品，电磁压制可导致电子产品暂时失效。由于只在军方使用，没有进入商用市场，因此暂未列入数世咨询的网络安全能力分类。

  

  
同态加密  
  
**所属领域：**通用概念**所属分类：**密码**成 熟 度 ：**概念市场**代表厂商：**沙海信息![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**同态加密的理念是无需解密的使用加密数据。表面上看，如果拥有海量计算能力的云服务商同时拥有了同态加密技术，云应用的最大阻力，数据安全，就可以得到完美解决。但实际上，同态加密需要的计算能力和内存资源非常之大，即使是云服务商也无法负担。目前能够商用的只是一些折衷办法，如针对某待定查询的专项计算，或是高度敏感的少量数据等。

  

  
机密计算  
  
**所属领域：**通用概念**所属分类：**密码**成 熟 度 ：**概念市场**代表厂商：**阿里云![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**由于同态加密短期内很难突破性能瓶颈，而基于硬件的TZ可信区域只是起到了隔离作用，于是出现了一个折衷方案，机密计算。与TZ一样，运算时数据是明文，但机密计算把运行环境进行了加密。目前，全球许多大型科技公司看好机密计算的前景，并成立了机密计算联盟。

  

  
量子密钥分发(QKD)  
  
**所属领域：**通用概念**所属分类：**密码**成 熟 度 ：**概念市场**代表厂商：**国盾量子![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**量子状态的不稳定性，导致技术、工程、成本、应用等层面面临着诸多挑战。虽然国外如瑞士、美国、澳大利亚等民营企业，包括国内的国盾量子已经推出了商用产品。但严格意义上来讲，QKD目前还只处于研究试用阶段。

  

  
后量子密码  
  

**所属领域：**通用概念

**所属分类：**密码

**成 熟 度 ：**无

**代表厂商：**无

![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**美国国家标准技术研究院在2016年发布了抗量子计算标准的招募计划，谷歌的基于点阵密码技术的NewHope已经嵌入到浏览器中进入试用阶段。量子计算时代，最危险的不是量子时代的密码破解，而是当下。各国政府都在收集现在无法破解的高度敏感的加密数据，等待使用量子计算来解密。

  

![](../Images/cd2912cbc9ce9a594971af4c1cfc6781.png)

  

  
IPV6扫描  
  
**所属领域：**通用概念**所属分类：**无**成 熟 度 ：**概念市场**代表厂商：**盛邦安全![](../Images/123a4f1aa3fc94740125e07000af421b.png)

**数世点评：**基于IPV6的互联网面临许多亟待解决的问题，其中网络空间安全的基石，网络空间资产的管理工作，在“地球上每一粒沙子都有IP”的情况下，如何展开？国内已经有科研机构和安全厂商展开探索，目前暂未列入数世咨询的网络安全能力分类。

  

  

**注：**数世咨询将市场成熟度划分为四个阶段，概念市场、新兴市场、发展市场、成熟市场：

**概念市场：**已提出新技术的概念和原理，但具体的框架和方案需要结合计算环境的发展进行摸索。

**新兴市场：**出现较为成型的框架和方案，并形成少量的收入，但多数用户尚在观望，需要应用环境的支持和进一步的市场实践，以丰富功能和验证效果。

**发展市场：**该技术已有较为成熟的产品及典型案例，市场开始进入快速增长期。

**成熟市场：**已得到业界普遍认可，市场进入稳定期。

本报告中的市场成熟度和代表厂商仅指国内。
