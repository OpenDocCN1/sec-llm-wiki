一、背景介绍 


数字经济时代下，数据展现出了巨大的潜在价值，在深刻改变人们生活方式的同时，也成为了国家社会治理和企业生产的重要抓手。《中华人民共和国数据安全法》格外引发关注，其要求“重要数据的处理者应当明确数据安全负责人和管理机构，落实数据安全保护责任”。此外，《网络安全法》、《个人信息保护法》、《网络安全等级保护》、《数据安全能力成熟度模型（DSMM）》等法规标准也都对数据安全人才培养和人员能力提出了清晰的要求，数据安全专业人员已成为保障数据安全与依法合规的关键因素。拥有专业的数据安全管理和技术人才已经成为数字经济时代不可或缺的重要安全保障。 


为落实国家层面法律法规的相关要求，服务国家数据安全治理体系的构建，提高人们的数据安全意识，提升企业或组织的数据安全能力成熟度，促进数字经济的健康持续发展，培养数据安全专业人才，大数据协同安全技术国家工程研究中心和贵州大数据安全工程研究中心推出了注册数据安全官（Certified Data Security Officer，CDSO）、注册数据安全工程师（Certified Data Security Engineer，CDSE）和 DSMM 测评师人才培训。


目前，大数据工程中心已与工信部人才交流中心达成“一考双认证”的合作模式，2022年4月21—24日将于线上召开第一期培训班，为更好的培养数据安全领域专业人才，特举办本次公开推介会进行宣传推广。
