# 软件开发安全供应商Snyk收购云安全公司Fugue

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247492223&idx=2&sn=dfc89a263aaa57fb56d2afaa53d49e09&chksm=c14490c2f63319d4dada01fd279aee045742440a83d958ed30bebe1a892ab8ff9d2abfdfc51c&scene=126&sessionid=1681323182#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247492223&idx=2&sn=dfc89a263aaa57fb56d2afaa53d49e09&chksm=c14490c2f63319d4dada01fd279aee045742440a83d958ed30bebe1a892ab8ff9d2abfdfc51c&scene=126&sessionid=1681323182#rd)

![](../Images/bd5f353d543883788cabf7b538945f49.png)

  

2月18日，Snyk宣布收购云安全与合规公司Fugue，踏足云安全领域。这是Snyk一年半内的第五次收购。  

  

Snyk计划将Fugue的云安全态势与策略管理技术整合到其Snyk Developer Security Platform中。与此同时，Snyk还将开始集成Fugue的DevSecOps技术。

  

在声明中，Fugue联合创始人兼首席执行官Josh Stella称：“今天我们与Snyk联手，但我们初衷未改，仍旧以‘携手开发者共筑安全’为使命，且随着我们面前机会的指数级增长而大幅拓宽。我们很高兴现在能够在更多地方接触更多开发人员，帮助他们不仅构建未来，而且成功捍卫未来。”

  

在过去的一年半里，Snyk收购了CloudSkiff、FossID、Manifold和DeepCode。去年年末，Snyk还完成了F轮融资，收获6亿美元。

  

**数世观点**  

开发安全是一个之前被忽略的，需求巨大的市场，从供应链到编码，再到应用上线和迭代运营，覆盖了机构业务的全生命周期。从这个层面来看，就不难理解Snyk的一系列收购行为了。
