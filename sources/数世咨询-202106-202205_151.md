# 云原生安全公司Securonix获10亿美元融资 2022继续网络安全投资风潮

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247492190&idx=2&sn=563ac882fdc88e1701a4a1ca73950d5f&chksm=c14490e3f63319f50d68ef3d295a57f6d6882985814a772d70cc22af011bb40794b5c296fa9d&scene=126&sessionid=1681323187#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247492190&idx=2&sn=563ac882fdc88e1701a4a1ca73950d5f&chksm=c14490e3f63319f50d68ef3d295a57f6d6882985814a772d70cc22af011bb40794b5c296fa9d&scene=126&sessionid=1681323187#rd)

去年，网络安全领域投资热情高涨，正是在这种形势下，云安全分析与运营厂商Securonix喜提投资公司Vista Equity Partners注入的超10亿美元成长资金。

  

Vista的投资是2021年11月以来第二笔超过10亿美元的融资。第一笔是云安全厂商Lacework在D轮融资中收获的13亿美元，且这笔融资距离该公司在上一轮融资中筹集到5.25亿美元仅仅几个月时间。Securonix本轮融资由Vista领投，Eight Roads Ventures和Volition Capital跟投，所获资金将用于加快多个领域的发展壮大，例如产品工程、人才招聘、云运营，以及威胁检测和捕捉技术。

  

Securonix身处竞争相对激烈的安全信息与事件管理（SIEM）市场。除SIEM之外，该公司还提供用户实体与行为分析（UEBA）和安全编排、自动化与响应（SOAR）方面的功能，并将这三种功能整合进基于SaaS的统一平台。Securonix表示，其平台可赋予企业分析大量安全相关信息的能力，帮助企业快速大规模检测和响应威胁。

  

去年，分析公司Gartner将Securonix列为SIEM领域的领导者和远见者，认为该公司在数据隐私控制、威胁情报能力和托管服务合作伙伴支持方面具有优势。本周，Securonix在宣布收获大笔资金注入时表示：作为一家增长快速的创新型公司，过去12个月里，公司年度经常性收入和员工人数均实现翻倍增长。

  

SANS研究所新兴安全趋势主管John Pescatore表示，考虑到Securonix的业绩和及其最接近的竞争对手Splunk的市场表现，Vista对Securonix投以极大信任是合情合理的。

  

Pescatore称：“Splunk在SIEM市场上的表现非常好，且已上市，因此其财务状况是透明的。”在最新的SIEM供应商分析中，Gartner已将Securonix列于Splunk之上，并认为SIEM本身是平稳增长的40亿美元以上规模的成熟市场。Pescatore指出：“Securonix处于以较低价格取胜的有利地位。他们有可能从Splunk那里分一杯羹，挖走一块市场份额。”

  

风险投资公司Thomvest Ventures投资总监Ashish Kakran表示，Securonix之所以能够吸引超过10亿美元的投资，是因为它解决了许多企业的痛点。 

  

Kakran称：“大规模安全就是个海量数据处理问题，有太多出自多个来源的警报、事件、日志需要存储、排序和分类。”Kakran表示，Securonix一直是此类企业中的产品创新者，携其云原生架构和对混合云部署的支持，在与大型老牌企业的竞争中取得了成功。

  

**昭示又一个创纪录的投资大年？**

  

Vista对Securonix的投资是2022年截至目前网络安全行业最大的一笔投资，而此前一年的网络安全投资额度也是史上最高。Momentum Cyber新出炉的市场数据显示，2021年风险投资比2020年翻了一番，同时网络安全行业的并购（M&A）数量同比增长了两倍。Momentum Cyber表示，投资者在1043起融资交易中向网络行业豪掷约295亿美元。其中80多起交易的金额超过1亿美元。而286宗并购交易中，有14宗价值10亿美元或以上。

  

Pescatore说道：“在投资者眼里，网络安全是以技术为中心的市场，比整体技术市场更稳定、增长更快，尤其是在美国以外的地区。”

  

他认为，至少在某些大规模融资交易中，投资者的思考逻辑是：企业想要的是少数几个大而美的“百货商店式”安全供应商，由这些供应商提供一系列的技术。Pescatore表示，多年来这种想法不断被证明是错误的，但仍旧存在且不时重现。

  

Pescatore称：“我认为Securonix可能会在SIEM市场上受到很多冲击，公司应该对此多加关注。”他指出，如果Securonix转而将Vista的投资用来每种产品都搞一下，那它可能就不会那么成功了。想想以前的赛门铁克和CA Technologies，这些都是妄图在安全领域大包大揽而失败的案例。

  

IT-Harvest首席研究分析师Richard Stiennon表示，Securonix这笔融资交易很可能为又一个网络安全行业大年奠定了基础。 

  

Stiennon说道：“这是一轮大额融资。只有Lacework收获过比这更大额的投资。像Securonix这样的融资往往会更加激发投资界的热情，所以我预计2022年将打破2021年所创下的融资纪录。” 

  

Stiennon补充称，其他纪录或许也会被打破。“大额投资往往预示着18个月内就会IPO，所以我会对这些高估值供应商保持关注。”
