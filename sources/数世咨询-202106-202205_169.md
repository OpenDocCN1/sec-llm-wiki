# 漏洞缓解平台Vicarius获2400万美元A轮融资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247492062&idx=2&sn=f1790a183b7fd9ea7632091b2290607a&chksm=c1449363f6331a758d01d1a1ec0ab8227067ecc68bf55cdda92f2805468bb6bdc2ff3aa8336b&scene=126&sessionid=1681323192#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247492062&idx=2&sn=f1790a183b7fd9ea7632091b2290607a&chksm=c1449363f6331a758d01d1a1ec0ab8227067ecc68bf55cdda92f2805468bb6bdc2ff3aa8336b&scene=126&sessionid=1681323192#rd)

![](../Images/0803a8424ae02dd4ede7944066aaa287.png)

  

网络安全公司Vicarius开发自主端到端漏洞缓解平台。2月9日，该公司宣布于AllegisCyber Capital、JVP和AlleyCorp领投的A轮融资中收获2400万美元。Okta、SecurityScorecard和Exabeam的高管也参与了本轮融资。

  

Vicarius计划用这笔资金在年底前将自己的员工数量增加两倍，并加强销售、支持和工程业务，服务好自身150多家客户。该公司目前拥有25名员工，并在纽约和以色列均设有总部。

  

Vicarius由Michael Assraf、Yossi Ze'evi和Roi Cohen于2016年创立，为IT和安全团队提供完全自动化的整合平台TOPIA，可评估、排序和修复应用、资产与操作系统中的漏洞。

  

该公司表示，传统网络扫描工具重在漏洞发现或补丁管理，无法适应不断变化的居家办公基础设施。Vicarius提供云优先集成解决方案，可弥合漏洞发现与漏洞缓解之间的缺口，满足当今转向远程办公和云应用的安全需求。

  

Vicarius首席执行官Michael Assraf表示：“安全与IT之间的错位和随之而来的摩擦已经困扰行业15年之久，而且至今仍未解决。根据我们在两种岗位上的工作经验，我们非常了解缺乏顺畅解决方案的痛苦和挫败感。通过将漏洞缓解过程整合进同一平台，并消除产品孤岛和沟通渠道封闭所导致的复杂性，我们将安全团队和IT团队捏合到一起，共同采取行动减小风险。”

  

JVP普通合伙人Gadi Porat指出：“Vicarius拥有强大的团队、清晰的愿景和卓越的技术。不过，我们最欣赏的可能还是他们修复受损系统的决心。这种解决问题的精神让他们具备了成为市场领导者的巨大潜力。我们很高兴能够参与促成Vicarius的愿景，帮助他们执行市场进入策略。”

  

**数世点评**  

漏洞管理的难点在于，漏洞发现是主动的，漏洞修补是被动的。成本是有限的，漏洞是无限的。因此，漏洞管理虽然始终都是网络安全体系的基础技术，但实际使用效果一直差强人意，更加突显了这个细分领域的创新价值。
