# IPO喜报丨奇安投资投后企业永信至诚科创板成功上市

永信至诚高管与奇安投资CEO王鹏飞等领导和嘉宾鸣锣开市

2022年10月19日，奇安投资投后企业北京永信至诚科技股份有限公司（以下简称“永信至诚”）成功登陆科创板，开启了永信至诚发展的新篇章。

上市仪式现场，永信至诚董事长蔡晶晶、总经理陈俊与奇安投资CEO王鹏飞、北京市相关领导及其他嘉宾共同为永信至诚IPO开市敲钟，一起见证这一历史时刻。

![](../Images/44491e531f4c61857a295aa94d80a19e.png)

永信至诚成功登陆科创板

永信至诚成立于2010年，是国家级专精特新“小巨人”企业，荣获北京市科技进步一等奖，拥有近20项发明专利和200多项软件著作权，是网络靶场和人才建设领域的领军企业。公司以“给世界带来安全感”为使命，秉承“人是安全的核心”主导思想，聚焦网络安全科技创新，着力于解决产业数字化转型缺乏安全测试环境、网络安全人员实战能力不足、政企用户缺乏主动防护能力等问题，致力于成为中国网络空间与数字时代安全基础设施关键建设者。

永信至诚以网络空间平行仿真及攻防对抗类技术为核心，推出以网络靶场系列产品为核心，以安全管控与蜜罐产品、安全工具类产品、安全防护系列服务、网络安全竞赛服务以及线上线下培训服务等为配套的创新且完善的“产品X服务”体系，已成为国内网络攻防领域的龙头企业。

此次IPO上市，是永信至诚公司发展历程中的重要里程碑，公司将抓住中国网安产业的战略机遇，依托多年的技术积累和客户的长期信任，以此次登陆科创板为契机，加快内涵式增长和外延式发展，乘势而上，再攀高峰，实现新的跨越式发展。

作为专门聚焦网安行业的专业化投资机构，奇安投资基于对网络安全的长期研究和专业认知，早在2018年就坚定看好以网络攻防能力为核心的细分赛道，基于对永信至诚创始团队的技术能力、市场意识、管理经验和成长性的信任，重仓投资了永信至诚。并在之后的四年间与公司携手同行，积极当好“副驾驶”，为公司提供了一系列务实多样的投后赋能，不仅协助公司进行了系统深入的战略规划，积极参与公司多轮融资和IPO规划，并基于投后近30家网安企业，积极促进公司与产业链上下游和生态企业全面的链接和合作。

奇安投资创始合伙人王鹏飞表示，永信至诚是一家非常独特的网安企业，他的独特之处在于不仅为客户授之以鱼，更重要的是能为客户授之以渔。在过去的几年中，国家级攻防演练使市场从合规需求向实战攻防迈出了关键性一步，客户网络安全防护意识、防护水平大幅提升，也给更多专注技术创新、具备实战能力的网络安全厂商提供了良好的发展机会。永信至诚抓住了难得的机遇，坚持技术创新和业务创新，形成了以网络攻防能力为核心，以网络靶场为基础，围绕网络防护、攻防演练、攻防竞赛、攻防培训、安全管理、以及人才培养等构建了全方位、立体式的产品和服务体系，真正体现了为客户安全能力赋能，为世界带来安全感的独特价值。在长期陪伴的过程中，奇安投资与永信至诚一起实现了共同的成长。

未来，随着中国网安产业从合规转向实战、从成本中心转向业务价值、从外挂式走向内生式、从边缘产业向基础设施演进，网安企业也将从百舸争流到千帆竞进，我们坚定看好网安产业未来的持续高速成长和价值释放。奇安投资将一如既往，持续助力更多的优秀企业加快成长，为中国网安产业的健康发展贡献自己的力量！
