# 奇安投资：五载砥砺不停辍

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247495510&idx=2&sn=d3d62993ed54a2c532bba628cc805515&chksm=c1449debf63314fd1c1973e478ebdb2380b8d052492baf231b3b121e58a735b5c6d5b725eb78&scene=126&sessionid=1681323086#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247495510&idx=2&sn=d3d62993ed54a2c532bba628cc805515&chksm=c1449debf63314fd1c1973e478ebdb2380b8d052492baf231b3b121e58a735b5c6d5b725eb78&scene=126&sessionid=1681323086#rd)

2017年6月1日，行业期盼已久被称为网安领域基本法的《网络安全法》正式实施，从法律层面正式确立了网络安全这一国家战略，这标志着网络安全行业进入了一个全新的发展阶段。刚刚从央企上市公司高管岗位“下海”的王鹏飞敏锐地意识到，中国作为一个网络大国要变为一个网络强国，网安产业的发展壮大至关重要。国内网安产业经过前面20年的培育，亟需借助资本的力量快速成长，但是由于网安行业技术门槛高、产业碎片化、细分赛道多、企业体量小，一般投资机构很难深入，也鲜有专业化的投资机构。于是，成立一支专注网安的产业基金的念头在王鹏飞心中逐渐成型。王鹏飞找到当时刚从360拆分出来独立运营的网安龙头企业奇安信集团董事长齐向东，两个胸怀发展壮大中国网安产业理想情怀的行业老兵一拍即合。在奇安信的支持下，2017年9月20日，奇安投资应运而生！从此，一群对网安行业充满理想和情怀的年轻人陆续从天南地北汇聚到一起，在创始合伙人王鹏飞的带领下，开始了一条助力网络强国建设、构建网安行业生态、赋能创业企业成长的探索之路。

2017-2022年，是中国网络安全产业发展波澜壮阔的五年。《密码法》、《数据安全法》、《个人信息保护法》、《关键信息基础设施安全保护条例》等法律法规相继出台，国家级攻防演练使市场从合规需求向实战攻防迈出了关键性一步，客户网络安全防护意识、防护水平大幅提升，也给更多专注技术创新、具备实战能力的网络安全厂商提供了良好的发展机会。伴随着网安行业的快速发展，网安资本市场也如火如荼，五年中网安赛道已经逐渐成为一个新的投资风口。过去五年，累计诞生了十几家网络安全上市公司，其中不乏奇安信、深信服等行业龙头企业，网安一级市场更是于2021年创造了超过150亿元融资金额的历史新高。

回顾奇安投资的第一个五年，王鹏飞表示，作为一家新锐基金，奇安投资已经完成了两期基金的募集，总管理规模近20亿元。在网络安全、信息安全及网络空间安全领域累计投资了近30家企业，其中奇安一期基金投资的第一个项目永信至诚即将登陆科创板，多个项目已进入IPO筹备流程。公司先后获得了清科、投中、36氪、融中、母基金周刊等行业权威机构评选的“最受创业者欢迎的投资机构”、“最具成长价值的创业投资机构”、“最具软实力投资机构”等多项殊荣以及行业的尊重和口碑。短短五年，我们已经初步完成了第一个阶段的战略目标，即成为一家**专注网安赛道最具影响力的创业投资机构**。

**五载砥砺不停辍----选难走的路做难做的事**

谈及五年的体会和经验，王鹏飞将其总结为：**选难走的路做难做的事**。

**所谓难走的路，就是坚定不移地选择了一条迎难而上的专业化和市场化之路。**

**专业化是奇安投资认为的立足之本。**这就要求每个项目经理首先要不断修炼六项认知能力，即不仅知投资、更要懂产业，不仅知财务、更要懂企业，不仅知技术、更要懂行业，不仅知表象、更要懂本质，不仅知现象、更要懂规律，不仅知现状、更要懂趋势。其核心是要求项目经理能够不断总结推演行业、企业的发展规律和产业演进趋势，不仅从宏观和微观看待投资，还需要把握中观的技术、需求及供给现状，以真正找到投资的本质。在具体的专业化能力建设上，奇安投资对项目判断维度做了划分，即将一个项目定义从好技术、好产品、好公司、好项目、好窗口多个维度进行评判，层层递进，以真正回答“为什么值得投、为什么安全边际充分、为什么现在投”的关键问题。在投资策略上，奇安投资不对项目阶段做限定，即全面覆盖网安领域各阶段项目。对初创期项目，重点把握行业关键性技术难题和产业发展大趋势，关注项目的创新性，通过专业认知能力发现投资价值；对成长期项目，着重关注其成长性，提防成长陷阱，依靠赋能服务能力提升投资价值；对中后期项目，挖掘其与奇安生态企业之间的连接性，强调资源整合潜力，通过资源整合能力创造更大的投资价值。

**市场化是奇安投资认为的生存之道。**虽然背靠奇安信这个“网安一哥”，奇安投资本可以围绕奇安信做好战略投资就可以，不用考虑投资回报和退出，完全可以舒舒服服作一个CVC（企业创投机构），但是团队还是选择了市场化这条难走的路。2019年，奇安投资成功引入国投集团、国贸资本和金融街资本旗下市场化平台国兴投资和熙诚金睿，同时建立了团队持股计划，实现了股权多元化改造，成为了一家混合所有制的市场化投资机构。对于选择怎样的市场化之路，王鹏飞表示，不同于行业很多机构完全由团队持股或者绝对控股，我们这种机制安排一方面可以将奇安信的产业资源优势和国投、国贸及金融街资本的资本资源优势相结合；另一方面可以将国有股东在管理规范方面的优势和团队的积极性及创造性相结合。几年来，在经营管理方面，公司充分发挥股东会、董事会的作用，按照法人治理结构，实现了规范管理；在投资决策方面，充分发挥投委会、咨询委员会的作用，实现了科学决策；在团队激励方面，我们不追求团队和个人利益短期最大化，我们的目标是把蛋糕做大，团队在此基础上获得长期持续的激励。

“网安是一个战略性新兴产业，GP既要有家国情怀和星辰大海，也要有竞进开拓、合作共赢的精神。只有这样才能实现健康、持续的发展。”王鹏飞总结，“专业化决定了我们能走多高，市场化则决定了我们能走多远”。

**而所谓“难做的事”，即是锲而不舍地去探索和建立差异化和生态化。**

一支优秀的基金，必须拥有自己的差异化护城河。奇安投资实践中积累形成的第一道“护城河”是**“以研助投、投研联动”**。重视投研始终是奇安投资业务团队的基因，已经融入了日常的投资工作中。在项目获取和筛选方面，通过全行业赛道扫描、生态平台筛选、产业链深入挖掘的方式，对行业内具备投资价值的项目进行全面覆盖和细致筛选。在投资研究方面，通过全员参与、分工协作，对某一细分方向进行全面的行业调研与项目扫描，集中兵力在一定周期内明确细分领域投资逻辑和可选标的，这种方式既能够快速明确投资方向，又能够统一认知，在不断研究、讨论、碰撞、复盘中统一思想，找到真正具备投资价值的项目。第二道“护城河”是“**以管促退、管退一体”。**奇安投资的投后管理被细分为三个方面，即基础管理、日常监控和增值服务。在项目投资进入一定阶段后，为每个项目制定针对性、差异化的退出策略，根据退出策略的不同在投后管理的各个部分有所侧重，保证投后管理以终为始。第三道“护城河”是“**产融结合、重组并购”。**作为专注网安行业的产业基金，奇安投资不仅关注项目的商业价值，更加关注项目的产业价值，不仅仅作为投资机构，更把自身定位为创新工场和加速器，通过对项目产业价值的挖掘和赋能，对项目进行孵化和加速成长，适时为项目寻找产业整合、并购重组机会。

**作为产业资本，奇安投资非常重视生态建设。**按照王鹏飞的观点：**“创业公司始于创新、兴于资本、成于生态”**。因此，奇安投资正在不断构建一个日益壮大的产业和资本良性互动的生态体系。主要参与方除了投后企业、网安上市公司外，还包括行业主管单位、行业协会、产业智库、甲方客户、产业园区、专业媒体、商业银行等各类主体。围绕全国网络信息安全创业投资服务联盟、北京网络安全大会、安全创客汇等联盟和品牌活动平台，精心参与筹划组织，引导生态间主体进行密切交流与多维度协同。未来，更吸纳更多主体加入，进一步激发生态内主体主观能动性，自主进行内部合作，以最终实现产业资源增强，网安生态影响力不断提升的目的。以“安全创客汇”为例，该品牌活动已成功举办7届，脱颖而出的70家优秀企业后续已累计融资超过40亿元，新兴方向技术创新型企业不断被挖掘及展现出来，一批网络安全新锐通过安全创客汇获得业内专家、甲方客户的高度认可，为业务发展和品牌宣传均提供了良好的发展机遇。

**扬帆竞进再启航----在不确定中寻找确定性**

根据工业与信息化部《网络安全产业高质量发展三年行动计划(2021-2023年)(征求意见稿)》，2023年中国网安产业整体规模将超过2500亿元，指导电信等重点行业网络安全投入占信息化投入比例达到10%。据预测，未来5-10年，网安产业将保持20%的年均复合增速，市场规模将超过1万亿元。

奇安投资又将如何规划自己的下一个五年？王鹏飞表示，未来的五年，是充满不确定性的五年。奇安投资下一个五年的战略目标是进一步将自身打造成为**立足网安行业最专业的产业投资机构**。如何实现这一目标，**关键是在不确定性中寻找确定性。**

**一是回归业务，洞察项目的确定性。**奇安投资认为，投资尽调中，对项目业务实质的准确洞察至关重要。在项目初步尽调中，奇安投资会从行业价值链、产业价值链、管理价值链三个角度对一个项目进行拆解，找到项目资源投入的重点与匹配度、问题和挑战、优劣势及核心能力，在此基础上通过一套内部的蛛网图工具，进一步清晰地勾勒出项目的定位、竞争优势和短板，结合外部环境分析，从中更多地洞察项目本身的确定性。

**二是全面尽调，降低项目的不确定性。**在项目进入正式尽调环节，奇安投资既会根据初步分析的结论，对项目重点优劣势做针对性尽调，又构建了全面的尽调清单，该清单涵盖了项目基本情况、产品与业务、财务、法务等多个方面，二级分类涉及项目方方面面全部细节内容。这样能够在尽调环节中，既始终围绕着核心投资逻辑进行验证，又不遗漏可能出现的细节风险，全面降低项目的不确定性。

**三是投后管理，维护项目的确定性。**奇安投资的投后团队会为每个投后企业量身定制一套投后管理方案。首先是对项目的投后系统性分析，全面分析项目投后管理重点，如战略、产品、销售、品牌、渠道、管理、团队等。其次是在投后管理中，会结合宏观环境及项目投后整改跟踪，以及定期对投资逻辑进行重判，及时更新投后策略，对项目风险进行把控，维护项目的确定性。

**四是参与经营，把握项目的确定性。**奇安投资在过去五年的投后工作中的显著特点，是作为副驾驶参与到项目的经营中，同时做到帮忙不添乱。在实际工作中，项目经理与创始团队频繁互动，始终围绕企业发展现状、未来目标及战略达成、战术执行及关键资源获取，协助企业对内外部环境、优劣势动态变化、经营目标跟踪分析、预算管理及策略优化进行多方面分析，参与到企业的战略经营决策中，以把握项目的确定性。

**五是赋能服务，增加项目的确定性。**赋能服务是奇安投资提升投后项目价值、增加项目确定性的重要手段，主要包括产业资源协同、协助融资、助力企业经营等方面。在产业资源协同方面，奇安投资为所有被投企业绘制了生态地图，积极为被投企业间的合作搭桥牵线，投后企业间的技术交流、业务协同、渠道共享已经颇具规模。在协助融资方面，奇安投后团队联合项目经理为正在融资的项目制定融资规划，对接投资机构，为投后企业提供融资建议，以更好地对接资本市场。投后企业后续轮的投资人不乏中国电子、腾讯、国投、国风投、红杉、IDG、元禾、金融街资本等知名企业和投资机构。通过发挥自身的主观能动性，增加项目的确定性。

**六是重组并购，创造项目的确定性。**随着国内网安产业的进一步发展，预测未来五年，国内网络安全行业资本市场会向海外趋势看齐，主要以重组并购为主。奇安投资将择机设立重组并购基金，重点围绕一批初创期、成长期企业做布局，针对业务协同强、团队融合可能性高的项目间，寻找重组并购机会，实现产业整合及项目外延式增长，创造项目的确定性。

**过往皆为序章，未来行则将至**

回首过去展望未来，王鹏飞表示，奇安投资能在短时间取得一定的成绩，一方面得益于国家对网安产业的高度重视。习近平总书记关于“没有网络安全就没有国家安全”的重要指示为网安行业的发展指明了方向，今天网安已经上升为国家战略，行业整体得到了的快速发展。如今越来越多的政府引导基金和市场化的母基金开始关注和支持专注网安的GP，越来越多的创业企业开始主动寻求专业化基金的投资。另一方面，也是由于自身清晰坚定的战略定位，奇安投资从成立之时就确立了致力于成为中国网安行业最专业、最具影响力的投资机构的愿景和构建网安行业生态、赋能创业企业成长的使命。五年来，我们始终不受机会驱使，而是由使命和愿景驱动，不忘初心，坚守本源；始终秉承竞进、合作、诚信、务实的核心价值观和守正居奇、守常思变、守拙成巧、守恒致远的经营理念，栉风沐雨、砥砺前行；始终与投资人同心，与创业企业同行，深耕行业、厚植产业；始终坚持专业化、市场化、差异化、生态化的经营方针，锐意进取、竞进奋发。

未来五年，随着中国网安产业从合规转向实战、从成本中心转向业务价值、从外挂式走向内生式、从辅助产业向基础设施演进，网安企业也将从百舸争流到千帆竞进，我们坚定看好网络安全产业未来的持续高速成长和价值释放。我们希望网安行业创业者坚持产品技术创新，以客户需求为本，以组建具备平台化、生态化、数智化能力的全球化网络安全公司而努力！也希望更多投资机构关注和扶持网安产业的提质升级，共同实现中国网安产业的共生、共享、共赢！

栉风沐雨践初心，关山初度路犹长。站在新的起点上，奇安投资将继续秉承构建网安行业生态、赋能创业企业成长的初心和使命，乘势而上、扬帆奋辑、续写芳华、再攀高峰。未来奇安投资将累计投资超过100家优秀的网络安全企业，为中国网安产业的繁荣发展贡献自己新的力量！
