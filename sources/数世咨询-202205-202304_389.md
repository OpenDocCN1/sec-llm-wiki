# Hack US：黑掉我们，钱你拿走

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247494180&idx=1&sn=137d8b8ec40f48e2d3bbb5e41527f8c8&chksm=c1449899f633118f3f5cec99bf1579f1c264a6d00afb7be86426a77ef63e63922a720c033dab&scene=126&sessionid=1681323122#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247494180&idx=1&sn=137d8b8ec40f48e2d3bbb5e41527f8c8&chksm=c1449899f633118f3f5cec99bf1579f1c264a6d00afb7be86426a77ef63e63922a720c033dab&scene=126&sessionid=1681323122#rd)

美国国防部设立短期漏洞赏金计划，为面向公众的系统和应用漏洞报告支付赏金。

  

Hack US漏洞赏金计划已于美国独立日（7月4日）启动，计划持续到7月11日，将根据所报告漏洞的严重程度分发奖金。

  

美国国防部（DoD）总共拿出11万美元用于奖励捕获漏洞的黑客。高严重性漏洞可带来500美元或以上的奖金，关键漏洞价值至少1000美元，并为特定奖项预留了高达5000美元的奖金，例如\*.army.mil最佳发现奖就价值3000美元。

  

这项计划是美国国防部与漏洞赏金平台HackerOne合作运营的，该平台此前就与国防部联手开展了为其12个月的试点计划。如今，试点计划已于今年4月结束，美国国防部启动Hack US漏洞赏金计划，为发现漏洞的黑客发出金钱奖励。

  

美国国防部在其计划概述中写道：“这项扩展计划旨在为安全研究人员给出条款和条件，以便他们能够挖掘可公开访问的国防部（DoD）信息系统（包括Web资产）中的漏洞，并将所发现的漏洞提交给国防部。”

  

在威胁数量和复杂程度不断上升的时代，作为巩固安全防御的又一工具，漏洞赏金计划在私营公司和公共机构中越来越普及。

  

网络安全供应商Digital Shadows首席信息安全官兼战略副总裁Rick Holland向媒体透露：“漏洞披露和漏洞赏金计划可以成为有效的网络安全工具，让你‘物有所值’。这些计划可以补充内部流程，扩展防御者的漏洞管理策略。公司能够将漏洞披露的分类与管理外包给第三方。”

  

Holland补充道：“不设置漏洞赏金计划的技术公司已经落后于时代了。鉴于如今几乎所有公司都可以称之为技术公司，大多数面向公众的公司应该设置漏洞披露或漏洞赏金计划。”

  

风险缓解公司Cyber Vulcan高级技术工程师Mike Parkin表示，此类计划还为安全研究人员提供了经济激励，刺激他们去发现威胁公司和机构的漏洞。

  

“由于现代代码的绝对复杂性和应用程序之间错综复杂的大量交互，我们很有必要让更负责任的眼睛来寻找缺陷。”Parkin向媒体说道，“我们知道恶意黑客这么做是为了发现他们可以利用的漏洞。诚实的研究人员也应该有某种形式的激励。”

  

今年4月，微软将其漏洞赏金计划的奖金额度提高了30%，奖励在其Office 365产品中发现“高影响”漏洞的道德黑客，而Meta则是在2021年12月扩大了其计划，纳入了Facebook抓取攻击。抓取攻击涉及使用自动化工具从用户个人资料页面等来源“抓取”信息。

  

从这方面看，全球漏洞赏金市场增长迅速。根据All the Research的研究，从2020年到2027年，这一领域将从2.231亿美元增长至超过54亿美元。投资也将流入漏洞赏金供应商手中。今年1月，HackerOne宣布在E轮融资中收获4900万美元，而欧洲公司Intigriti则在4月宣称筹集到2230万美元。

  

这种情况毫不令人意外。根据漏洞情报与检测公司Edgescan的调研，2021年Web应用和网络基础设施中发现的漏洞有20.4%不是高风险就是重大风险。漏洞赏金计划能帮助降低公司及其合作伙伴和客户的风险。

  

“漏洞赏金计划对组织和安全研究人员来说都相当成功。”集成软件供应商Synopsys Software Integrity Group研究员Ray Kelly向媒体透露，“严重安全漏洞很容易让组织的客户群面临风险。有效的漏洞赏金计划限制了此类漏洞的影响。为漏洞报告付出的赏金有时会超过六位数，这听起来可能很多。但是，组织修复零日漏洞和从中恢复的成本可能会造成数百万美元的营收损失。”

  

今年4月结束的试点计划“国防工业基础漏洞披露计划”（DIB-VDP）中，美国国防部与14家自愿参与的公司将141项资产纳入了道德黑客审视的显微镜下，但对该计划的兴趣促使美国国防部将之扩大到包括41家公司和348项资产的规模。总共有288名HackerOne研究人员提交了1015份报告，其中401份被认为可采取修复措施。

  

新计划由首席数字和人工智能办公室（CDAO）、数字服务局和美国国防部网络犯罪中心（DC3）与HackerOne共同运营。根据美国国防部的说法，总奖金中的7.5万美元将按照先提交、先授予的方式发放。另外3.5万美元则留作特别漏洞奖励，例如Hack US活动最佳发现奖，以及陆军、海军、空军、海军陆战队、天军和海岸警卫队等部门领域的最佳发现奖。

  

Bugcrowd创始人兼首席技术官Casey Ellis表示，DC3升级自身漏洞披露计划，将付费漏洞赏金计划纳入其中，可谓明智之举。

  

“我们早已部署了大量技术，而且部署新技术的速度只会越来越快，而我们的对手也在持续精进，变得更加熟练、更具侵略性和更加多样化。”Ellis解释道，“当然，新安全技术解决方案也在不断涌现和使用，但归根结底，网络安全从根本上讲是人的问题，因此人员也极有可能越来越多地在防护互联网方面发挥重要作用。”
