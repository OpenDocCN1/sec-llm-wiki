# \[调研\]网络安全早期阶段融资发展迅猛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNzA3MTgyNg==&mid=2247493326&idx=2&sn=912961b53629433c7030c36710315f2f&chksm=c1449473f6331d65a3096270c56ac0b01e906a237cb9738365e2250fb6ac80649839be99ac1b&scene=126&sessionid=1681323142#rd](http://mp.weixin.qq.com/s?__biz=MzkxNzA3MTgyNg==&mid=2247493326&idx=2&sn=912961b53629433c7030c36710315f2f&chksm=c1449473f6331d65a3096270c56ac0b01e906a237cb9738365e2250fb6ac80649839be99ac1b&scene=126&sessionid=1681323142#rd)

![](../Images/8dca6b98954df585c5faa898b87b46f5.png)

  

位于美国华盛顿特区的网络安全风险资本公司和孵化器DataTribe表示，2021年第一季度网络行业种子轮和A轮融资持续平稳。  

  

尽管经济低迷对所有垂直行业的整体交易量产生一定影响，但网络领域交易预计韧性更强。

  

DataTribe报告称，网络领域种子轮融资交易的规模同比增长了87%（从2021年第一季度的270万美元增长到2022年第一季度的500万美元），A轮融资交易规模则增长了35%（从2021年第一季度的1000万美元增长到2022年第一季度的1350万美元）。至于估值，种子轮交易增长了133%（从770万美元增长到1800万美元），A轮融资交易增长了59%（从2830万美元增长到4500万美元）。

  

![](../Images/26361f4ddc5b0c3f1b77cf864b8cbe6a.png)

  

如果经济低迷持续，所有垂直行业的交易估值和规模都会下降，但网络领域受到网络犯罪和全球冲突蔓延至网络空间的推动，韧性反而更强。

  

DataTribe还总结了俄乌冲突对IT和软件开发团队的影响。据估计，俄乌冲突现已导致乌克兰、俄罗斯和白俄罗斯的20万工程师受到影响，预计乌克兰未来还将有30万工程师受到冲突影响。

  

“企业和独立软件供应商正忙于从印度和拉丁美洲等地区为其离岸开发团队补充人手。这加剧了新冠肺炎疫情和辞职潮导致的招聘压力，使得启动新项目或扩大团队变得非常困难。不论公司规模大小，软件开发各个过程都可能会遭到人才流失的影响。特别是，由于外包比招聘员工更实惠、更灵活，初创公司创新将会放缓。”

  

DataTribe的报告还提供了网络领域其他方面的洞见，例如数据泄露与攻击模拟（BAS）系统、软件物料清单（SBOM）、中小型企业（SMB）网络保险，以及联邦新法对网络准备度的积极影响。
