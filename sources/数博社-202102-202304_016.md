# NIST 宣布前四种抗量子密码算法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMDIxMjU2MA==&mid=2247487717&idx=1&sn=5905b9ef90bf1ad1ec575739271b906d&chksm=c19715daf6e09ccc7e1682634345d2a83a3c9c70787082469acf3fc688301694f3a94694fe8c&scene=126&sessionid=1681312585#rd](http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247487717&idx=1&sn=5905b9ef90bf1ad1ec575739271b906d&chksm=c19715daf6e09ccc7e1682634345d2a83a3c9c70787082469acf3fc688301694f3a94694fe8c&scene=126&sessionid=1681312585#rd)

美国商务部国家标准与技术研究院 (NIST)选择了第一套抗量子加密算法，旨在“抵御未来量子计算机的攻击”。

后量子密码学 ( PQC ) 技术包括用于通用加密的 CRYSTALS-Kyber算法，以及用于数字签名的CRYSTALS \-Dilithium、FALCON和SPHINCS+ 。

NIST 在 2017 年 1 月启动了标准化进程，在一份声明中说： “其中三个选定的算法基于一系列称为结构化格的数学问题，而 SPHINCS+ 使用散列函数。”

密码学是现代计算机网络中信息安全的基础，它的优势来自于使用传统计算机解决数学问题的困难——例如，分解大型复合整数。

如果量子计算机足够成熟，将对当前的公钥算法产生巨大影响，因为在传统计算机上可能需要数万亿年才能找到正确的密钥来解码消息，而这可能只需要几天或几小时，使他们容易受到暴力攻击。

该机构表示：“如果大型量子计算机建成，它们将能够破解当前使用的许多公钥密码系统。” “这将严重损害互联网和其他地方数字通信的机密性和完整性。”

使问题进一步复杂化的是一种称为“现在破解，以后解密”的严重威胁，其中网络对手收集今天发送的敏感加密数据，希望在未来量子计算可用时破解它。

据说 NIST 选择的四种抗量子算法依赖于经典计算机和量子计算机都难以解决的数学问题，从而保护数据免受密码分析攻击。

该机构还计划在最终确定后量子密码标准之前再加入四种算法，这一过程预计将在大约两年内完成。

也就是说，美国网络安全和基础设施安全局 (CISA) 与 NIST 一起“强烈”建议组织按照后量子密码学路线图开始为过渡做准备。
