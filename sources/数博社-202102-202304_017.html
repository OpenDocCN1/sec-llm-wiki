你还记得《蝙蝠侠 - 黑暗骑士》中的那个场景，蝙蝠侠使用一个系统来聚合来自无数手机的活动声音数据，以创建任何给定地点正在发生的事情的元声纳馈送吗？

这与我们在 CrowdSec 所做的事情是一个有趣的类比。通过汇总来自我们社区的入侵信号，我们可以清楚地了解世界上的非法黑客行为。

经过 2 年的活动并每天分析来自 160 个国家/地区的数万用户的 100 万个入侵信号，我们开始拥有准确的“蝙蝠侠声纳”全球网络威胁源。并且有一些有趣的要点需要概述。

多面的网络威胁

首先，全球网络威胁是高度多样化的。在查看报告的攻击类型、其来源以及恶意 IP 地址背后的自治系统 (AS) 时，我们看到了什么？

扫描仪和蛮力尝试仍然是我们社区看到并排名第一的最流行的入侵媒介。非常合乎逻辑，因为监视是更高级入侵的第一步。我们社区看到的扫描活动主要是端口扫描或基于 HTTP 的探测。

在黑客使用的不同入侵类型中，对敏感服务（SSH、电子邮件、管理员 URL 等）的蛮力尝试是 #2。不是突破性信息，但当研究表明暴力攻击占全球网络攻击的 6% 时，将其视为主导也就不足为奇了，尤其是因为它仍然是自动化和部署最简单、成本最低的攻击之一（你好脚本小子）。因为它很容易被反击，人们会认为它很少起作用，但是，嘿，6%！

Log4J 还没有完成

在我们社区看到的最流行的漏洞利用尝试中，我们有 Log4j。您确实很喜欢去年的风暴，即一个用于 Apache 的简单开源日志记录实用程序如何接管网络安全世界并给网络安全专家带来无尽的头痛。而且，当然，犯罪世界非常乐意通过自动扫描机器人来利用它来寻找易受攻击的服务。

好吧，我们的社区见证了这场风暴。披露后的 12 月高峰期过后，事情稍微平静了一些，但 Log4j 的扫描活动再次开始，尽管处于较低但稳定的水平，由机器人推动。

关键信息是，如果您认为自己因为“营销”风暴过去而受到保护，请三思而后行。

仍然有非常激进的活动试图利用该漏洞。

例如，几周前，我们社区的大部分区域被扫描，因为 IP 地址 13.89.48.118 在不到 12 小时内被 500 多个用户报告。它加入了社区黑名单上的 20000 多个其他 IP 地址以进行补救。

IP 地址：网络犯罪分子的核心资源

IP 地址很少永远是恶意的，而且它们的声誉可能一天一天地发生变化。随着社区不断共享有关它们的信息，任何更新都可以立即传输给用户。从长远来看，它提供了有关 IP 地址攻击性持续时间的宝贵数据。

这是登陆 CrowdSec 数据湖（标记为恶意）的 IP 地址数量的快照。值得注意的是，网络犯罪分子确实在更改他们用来进行攻击的 IP：

* 其中只有 2.79% 是我们数据库的永久成员

* 12.63% 的收集到的 IP 每周都会发生变化

* 每日续订率为 1.8%

**自治系统有不同的方法来缓解受损 IP **

每个 IP 都是由 AS（自治系统）管理的地址池的一部分。AS 是具有统一路由策略的广泛网络或网络组。每台连接到 Internet 的计算机或设备都连接到一个 AS。通常，每个 AS 由单个大型组织运营，例如 Internet 服务提供商 (ISP)、大型企业技术公司、大学或政府机构，并因此负责 IP 地址。

CrowdSec 社区共享的每个攻击性 IP 都由其 AS 丰富。这与攻击性持续时间的数据相结合，可以清楚地了解 AS 如何管理受损 IP。

虽然简单地查看受损资产的数量可能是一个角度，但它不一定是公平的。并非所有运营商的规模都相同，有些运营商比其他运营商托管“风险更高”的服务（你好过时的 PHP CMS）。

同一 AS 中所有 IP 的平均恶意持续时间表明运营商在识别和处理受损资产方面的尽职调查。平均持续时间的分布用指向领先云提供商报告最多的 AS 位置的箭头显示。例如，在 AWS，被盗地址平均会被盗 3 天。天蓝色 9 天。在图表的最后，来自中国或俄罗斯的 AS（令人惊讶……）对受损 IP 采取行动的“速度较慢”。
