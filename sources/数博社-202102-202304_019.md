# 微软：针对Windows 和 Microsoft 365软件的自动补丁计划已经正式开启

微软表示，Windows Autopatch 是一项自动使 Windows 和 Microsoft 365 软件保持最新状态的企业服务，从今天开始普遍可用。

Windows Autopatch 于 4 月首次宣布， 当时微软表示将从 2022 年 7 月开始向拥有 Windows 10/11 Enterprise E3 或更高版本许可证的微软客户免费提供（它于 6 月初达到公开预览版）。

这项新服务自动管理 Windows 10 和 Windows 11 质量和功能更新以及驱动程序、固件和 Microsoft 365 企业应用程序更新的部署。

对于已注册的租户，Windows Autopatch 将更新编排从组织转移到 Microsoft，IT 团队不再承担规划整个更新过程（包括推出和排序）的负担。

微软高级产品营销经理 Lior Bela说： “我们很高兴地宣布，这项服务现已普遍提供给拥有 Windows Enterprise E3 和 E5 许可证的客户 。”

“微软将继续在每个月的第二个星期二发布更新，现在 Autopatch 有助于简化更新操作并为 IT 专业人员创造新的机会。”

Microsoft 提供了管理员在 Windows Autopatch 中注册设备必须执行的以下步骤（您可以 在此处观看包含更详细说明的视频）：

*   在 Microsoft Endpoint Manager 管理中心的租户管理刀片中找到 Windows Autopatch 条目
    
*   选择租户注册
    
*   选中复选框以同意条款和条件，然后选择“同意”
    
*   选择“注册”
    

为租户设置后，Windows Autopatch 将自动将设备群分成四组设备，称为测试环。

“测试环”包含最少数量的设备，“第一环”大约占企业环境中所有端点的 1%，“快速环”大约 9%，“宽环”其余 90% 的设备.

更新逐步部署，从测试环开始，并在允许设备性能监控和更新前指标比较的验证期后转移到更大的设备集。

Windows Autopatch 还具有内置的暂停和回滚功能，这些功能将阻止更新应用到更高的测试环或自动回滚以帮助解决更新问题。

“一旦你将设备注册到 Autopatch 中，该服务就会完成大部分工作，”Bela 周一补充道。

“但通过 Microsoft Endpoint Manager 中的 Autopatch 刀片，您可以微调环成员资格、访问服务健康仪表板、生成报告和提交支持请求。”
