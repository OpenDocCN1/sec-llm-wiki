# 思科表示不会修复报废 VPN 路由器中的零日 RCE

思科建议报废小型企业 RV 路由器的所有者在披露不会修补的远程代码执行漏洞后升级到更新型号。

该漏洞的编号为 CVE-2022-20825，CVSS 严重性等级为 9.8（满分 10.0）。

根据思科安全公告，该漏洞的存在是由于用户对受影响设备上传入的 HTTP 数据包的输入验证不足。

攻击者可以通过向基于 Web 的管理界面发送特制请求来利用它，从而以根级别权限执行命令。

## 影响和补救

该漏洞影响四款小型企业 RV 系列型号，即 RV110W Wireless-N VPN 防火墙、RV130 VPN 路由器、RV130W Wireless-N 多功能 VPN 路由器和 RV215W Wireless-N VPN 路由器。

此漏洞仅影响在 WAN 连接上启用了基于 Web 的远程管理界面的设备。

虽然默认配置中未启用远程管理功能，但使用 Shodan 进行的简短搜索发现了暴露的设备。

要确定是否启用了远程管理，管理员应登录基于 Web 的管理界面，导航到“**基本设置 > 远程管理**”并验证相关复选框的状态。

思科声明他们不会发布安全更新来解决 CVE-2022-20825，因为这些设备不再受支持。此外，除了关闭 WAN 接口上的远程管理之外，没有其他可用的缓解措施，无论为了更好的整体安全性，都应该这样做。

建议用户在迁移到供应商积极支持的 Cisco Small Business RV132W、RV160 或 RV160W 路由器之前应用配置更改。

思科 去年警告说，在披露他们不会修复通用即插即用 (UPnP) 服务中的关键漏洞后，管理员应该升级到更新的型号。

本周，思科修补了 思科安全电子邮件中的一个严重漏洞，该漏洞 可能允许攻击者绕过身份验证并登录到思科电子邮件网关的 Web 管理界面。
