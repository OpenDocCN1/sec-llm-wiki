# 思科安全电子邮件和 Web 管理器的严重缺陷让攻击者绕过身份验证

思科周三推出了修复程序，以解决一个影响电子邮件安全设备 (ESA) 和安全电子邮件和 Web 管理器的关键安全漏洞，未经身份验证的远程攻击者可以利用该漏洞绕过身份验证。

分配了 CVE 标识符CVE-2022-20798的绕过漏洞在 CVSS 评分系统中被评为最高 10 分中的 9.8 分，并且源于当受影响的设备使用轻量级目录访问协议 ( LDAP ) 进行外部身份验证时不正确的身份验证检查。

“攻击者可以通过在受影响设备的登录页面上输入特定输入来利用此漏洞，”思科在一份公告中指出。“成功的利用可能允许攻击者未经授权访问受影响设备的基于 Web 的管理界面。”

该漏洞据称是在技术援助中心 (TAC) 案件的解决过程中发现的，它会影响 ESA 以及运行易受攻击的 AsyncOS 软件版本 11 及更早版本、12、12.x、13、13.x 的安全电子邮件和 Web 管理器， 14 和 14.x 以及满足以下两个条件时 -

*   设备配置为使用外部身份验证，并且
    
*   设备使用 LDAP 作为身份验证协议
    

另外，思科还通知客户另一个影响其小型企业 RV110W、RV130、RV130W 和 RV215W 路由器的严重漏洞，该漏洞可能允许未经身份验证的远程攻击者执行任意代码或导致受影响的设备意外重启，从而导致拒绝服务(DoS) 条件。

该漏洞被跟踪为CVE-2022-20825（CVSS 评分：9.8），与传入 HTTP 数据包的用户输入验证不足有关。然而，思科表示，它既不计划发布软件更新，也不计划发布解决该漏洞的变通办法，因为这些产品已经报废。
