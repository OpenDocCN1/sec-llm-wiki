研究人员警告说，攻击者不要增加使用免费的浏览器自动化框架。

  

### 浏览器自动化框架

根据一份报告，名为 Browser Automation Studio (BAS) 的框架包括可用于恶意活动的各种功能。该框架是一个仅限 Windows 的自动化环境。

*   该框架的技术门槛非常低。怀疑是故意的，以吸引更多的贡献者和内容开发者。
    
*   与此同时，地下经济中的威胁行为者推动他们创造定制工具的时间。
    

  

### 攻击载荷

*   研究人员观察到与 BlackGuard、Bumblebee 和 RedLine Stealer 等恶意软件相关联的 C2 IP 地址与 Bablosoft 的子域进行通信。
    
*   此外，一些主机与 XMRig 和 Tofsee 矿工链接，它们与第二个子域指纹\[.\]bablosoft\[.\]com 通信，以使用帮助矿工隐藏其行为的服务。
    

  

### 关于BAS 

BAS 框架由 Bablosoft 开发，该公司提供各种其他自动化和实用工具。

*   该框架于 2021 年 2 月被发现，包括在 Google 的 Chrome 浏览器中自动执行任务的能力。
    
*   据信，恶意软件活动的运营商与 Bablosoft 子域 (downloads\[.\]bablosoft\[.\]com) 相关联，以下载其他工具，以作为其利用后活动的一部分。
    

  

### 结论

根据已经使用 Bablosoft 网站上提供的工具的攻击者数量，专家预计 BAS 将在未来成为威胁参与者工具包中更常见的组件。因此，组织应实施唯一密码并阻止用户使用受损凭据。
