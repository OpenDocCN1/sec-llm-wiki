一半的 IT 领导者将密码存储在共享文档中

原文：http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247487474&idx=1&sn=964d1d38f6fcbcfa9094d1ca85d0bdda&chksm=c1970acdf6e083dbbf392637c11c050dffbaa2a272fa2bcaab05f5c773c1f0c54f6a723a86f6&scene=126&sessionid=1681312599#rd

一项新的研究表明，近一半 (46%) 的 IT 和安全领导者仍将公司密码存储在电子表格等办公文档中，这使他们的组织面临重大的网络风险。


身份管理供应商 Hitachi ID 对 EMEA 和北美的 100 名高管进行了调查，以更好地了解其密码管理的安全性。


据估计，每个员工可能拥有多达 70-100 个密码和“分散的秘密”，攻击者可以利用这些密码和“去中心化机密”来访问和移动组织。


尽管几乎所有(94%) 的受访者都声称他们需要进行密码管理培训，其中 63% 的人表示他们每年会进行一次以上的培训，但许多人似乎并没有遵循自己的建议。只有 30% 的人表示他们使用公司提供的密码管理器，有些人甚至使用笔和纸。


“当近一半的组织仍在将密码存储在电子表格和其他文档中，8% 的组织将密码写在便签上时，这就提出了一个重要的问题，即密码管理培训的效果如何，”日立 ID 首席执行官尼克布朗说。


“不安全的密码仍然是网络攻击的主要原因，仅靠教育显然是不够的。”


对于离职员工带来的风险，也提出了问号。只有三分之一的受访者表示他们“有点”（20%）、“中等”（8%）或“非常”有信心（5%）他们可以在急需终止时传输密码、终止访问并保持业务连续性一个员工。


去年，一位信用合作社的前雇员为了报复被解雇而销毁了 21GB 的公司数据，其中包括 20,000 个文件和近 3500 个目录。


尽管一位同事要求该公司的 IT 支持提供商禁用该女性的网络访问权限，但她显然能够正常使用她的用户名和密码大约 40 分钟。


在 Hitachi ID 研究中，约 29% 的受访者表示，他们在过去一年中经历过员工离职后无法访问系统的事件。
