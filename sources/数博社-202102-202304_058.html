黑客现在在 Windows 事件日志中隐藏恶意软件

安全研究人员已经注意到一个使用 Windows 事件日志来存储恶意软件的恶意活动，这种技术以前没有公开记录在野外攻击中。

该方法使攻击背后的威胁行为者能够在文件系统中植入无文件恶意软件，攻击中充满了旨在使活动尽可能隐秘的技术和模块。

将有效负载添加到 Windows 事件日志

卡巴斯基的研究人员收集了恶意软件样本，因为该公司产品配备了基于行为的检测和异常控制技术，将其识别为对客户计算机的威胁。

调查显示，该恶意软件是“非常有针对性”的活动的一部分，并且依赖于大量定制和商业可用的工具。
攻击中最有趣的部分之一是将 shellcode 有效负载注入到密钥管理服务 (KMS) 的 Windows 事件日志中，该操作由自定义恶意软件释放器完成。

卡巴斯基首席安全研究员丹尼斯·莱格佐（Denis Legezo）表示，这种方法“在恶意活动期间首次‘在野外’使用”。

投放器将合法的操作系统错误处理文件 WerFault.exe 复制到“ C:\Windows\Tasks ”，然后将加密的二进制资源投放到同一位置的“ wer.dll ”（Windows 错误报告），用于 DLL 搜索顺序劫持加载恶意代码。

DLL 劫持是一种黑客技术，它利用检查不足的合法程序从任意路径将恶意动态链接库 (DLL) 加载到内存中。

Legezo 说，dropper 的目的是在磁盘上加载以进行侧面加载过程，并在事件日志中查找特定记录（类别 0x4142 - ASCII 中的“AB”。如果没有找到这样的记录，它会写入 8KB 块加密的 shellcode，稍后将它们组合起来形成下一个 stager 的代码。

“删除的wer.dll是一个加载程序，如果没有隐藏在 Windows 事件日志中的 shellcode，它不会造成任何伤害”——卡巴斯基首席安全研究员 Denis Legezo

卡巴斯基分析的新技术可能会变得越来越流行，因为用于将有效负载注入 Windows 事件日志的源代码已经在公共空间中提供了很短的一段时间。

技术先进的演员

根据活动中使用的各种技术和模块（渗透测试套件、自定义反检测包装器、最后阶段的木马），Legezo 指出整个活动“看起来令人印象深刻”。

他告诉 BleepingComputer，“该活动背后的演员本身就相当熟练，或者至少拥有一套很好的相当深刻的商业工具”，这表明是 APT 级别的对手。

攻击中使用的工具包括商业渗透测试框架 Cobalt Strike 和 NetSPI（前身为 SilentBreak）。

虽然攻击中的一些模块被认为是定制的，但研究人员指出，它们可能是 NetSPI 平台的一部分，无法获得用于测试的商业许可证。

例如，名为 ThrowbackDLL.dll 和 SlingshotDLL.dll 的两个木马可能是同名的工具，已知它们是 SilentBreak 渗透测试框架的一部分。

“我们从内存中的最后一个阶段开始研究，然后使用我们的遥测技术，能够重建几个感染链”- Denis Legezo

调查将攻击的初始阶段追踪到 2021 年 9 月，当时受害者被诱骗从文件共享服务 file.io 下载 RAR 存档。

然后，攻击者传播了 Cobalt Strike 模块，该模块由一家名为 Fast Invest ApS 的公司的证书签署。该证书用于签署 15 个文件，但没有一个是合法的。

研究人员告诉 BleepingComputer，在大多数情况下，具有这种最后阶段功能的目标恶意软件的最终目的是从受害者那里获取一些有价值的数据。

在研究这次攻击时，卡巴斯基没有发现与之前与已知威胁参与者相关的活动有任何相似之处。

在与已知对手建立联系之前，研究人员将新活动跟踪为 SilentBreak，以攻击中最常用的工具的名称命名。
