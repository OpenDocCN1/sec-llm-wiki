# 网络间谍使用 IP 摄像头部署后门，窃取 Exchange 电子邮件

一个新发现且非常隐秘的高级持续威胁 (APT) 组织正在破坏公司网络，以窃取参与公司交易（如并购）的员工的 Exchange（本地和在线）电子邮件。

Mandiant 研究人员发现了威胁参与者并将其跟踪为UNC3524，他们表示该组织已经展示了其“先进”的能力，因为它保持对受害者环境的访问超过 18 个月（在某些情况下）。

“一旦 UNC3524 成功获得受害者邮件环境的特权凭据，他们就开始向本地 Microsoft Exchange 或 Microsoft 365 Exchange Online 环境发出 Exchange Web Services (EWS) API 请求，”Mandiant 说。

“在每个 UNC3524 受害者环境中，威胁行为者都会针对邮箱的一个子集，将他们的注意力集中在从事企业发展、并购和 IT 安全工作的执行团队和员工身上。”

UNC3524 可以通过在不支持安全监控和恶意软件检测工具的网络设备上部署一个新发现的名为 QUIETEXIT（使用开源 Dropbear SSH 软件作为灵感开发）的后门来持续存在。

在一些攻击中，UNC3524 还在 DMZ 网络服务器上部署了 reGeorg web shell  （由 NSA 链接到俄罗斯赞助的 APT28/Fancy Bear 组织的版本），以创建 SOCKS 隧道作为其受害者网络的备用接入点。

![](../Images/339740f2c0c1cf7afbd351c817474ab1.png)

  

通过在这些设备（例如，无线接入点控制器、SAN 阵列和负载平衡器）上部署其恶意软件，UNC3524 大大延长了初始访问与受害者检测到其恶意活动并切断访问之间的时间间隔。

然而，即使发生这种情况，Mandiant 表示，威胁组织“没有浪费时间通过各种机制重新破坏环境，立即重新启动他们的数据盗窃活动。”

QUIETEXIT 后门命令和控制服务器是僵尸网络的一部分，该僵尸网络通过破坏 Internet 暴露的 LifeSize 和 D-Link IP 视频会议摄像机系统（可能使用默认凭据）构建。

在获得访问权限并部署其后门后，UNC3524 获得了受害者邮件环境的特权凭据，并开始通过 Exchange Web 服务 (EWS) API 请求针对本地 Microsoft Exchange 或 Microsoft 365 Exchange Online 邮箱。

他们通常窃取“在特定日期范围内工作的执行团队和员工，从事企业发展、并购或 IT 安全人员”收到的所有电子邮件，而不是挑选感兴趣的电子邮件或使用关键字过滤（这是俄罗斯支持的 Cozy Bear/APT29）。

鉴于 UNC3524 使用了以前与多个俄罗斯支持的黑客组织（包括 APT28 和 APT29）相关的策略和工具，Mandiant 表示，归因是模糊的，无法将此活动与特定的威胁组织联系起来。
