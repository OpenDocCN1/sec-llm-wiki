# 大多数电子邮件安全方法无法阻止常见威胁

整整 89% 的组织在过去 12 个月内经历过一次或多次成功的电子邮件泄露事件，这转化为巨额成本。

绝大多数安全团队认为他们的电子邮件安全系统对最严重的入站威胁（包括勒索软件）无效。

这是根据 Cyren 委托并由 Osterman Research 对使用 Microsoft 365 电子邮件的企业客户进行的一项调查得出的，该调查检查了对网络钓鱼、企业电子邮件泄露 (BEC) 和勒索软件威胁、成为代价高昂事件的攻击以及应对准备情况的担忧袭击和事件。

“安全团队经理最担心的是，当前的电子邮件安全解决方案无法阻止严重的入站威胁（特别是勒索软件），这需要安全团队在用户触发危险威胁之前有时间做出响应和补救，”周三发布的报告称.

不到一半的受访者表示他们的组织可以阻止电子邮件威胁的传递。相应地，不到一半的组织将其当前部署的电子邮件安全解决方案评为有效。

对假冒威胁的保护被认为是最不有效的，其次是检测和阻止群发网络钓鱼电子邮件的措施。

因此，几乎所有接受调查的组织都经历过一种或多种类型的电子邮件泄露，这也许不足为奇。

事实上，89% 的组织在过去 12 个月中经历了一种或多种成功的电子邮件泄露类型。而且，根据该报告，自 2019 年以来，每年的电子邮件泄露数量几乎翻了一番，其中大部分是由于成功的网络钓鱼攻击破坏了 Microsoft 365 凭据。

总体而言，根据调查，成功的勒索软件攻击在过去三年中增加了 71%，Microsoft 365 凭据泄露增加了 49%，成功的网络钓鱼攻击增加了 44%。

## 无效的防御方法

深入研究电子邮件防御失败的地方，这些公司发现，令人惊讶的是，使用电子邮件客户端插件让用户报告可疑消息的情况继续增加。现在，有一半的组织正在使用自动电子邮件客户端插件，供用户报告可疑电子邮件，以供训练有素的安全专业人员进行分析，高于 2019 年调查的 37%。

安全运营中心分析师、电子邮件管理员和电子邮件安全供应商或服务提供商是最常处理这些报告的群体，尽管 78% 的组织会通知两个或更多群体。

此外，调查发现，现在大多数公司都提供有关电子邮件威胁的用户培训：超过 99% 的组织至少每年提供一次培训，七分之一的组织每月或更频繁地提供电子邮件安全培训。

“更频繁的培训减少了一系列威胁标记 在每 90 天或更频繁地提供培训的组织中，员工遭受网络钓鱼、BEC 或勒索软件威胁的可能性低于每年仅培训一到两次的组织，”根据报告。

此外，调查发现，更频繁的培训会导致更多消息被报告为可疑消息，并且在经过安全专业人员分析后，这些可疑消息中被证明是恶意的比例更高。

到现在为止还挺好。那么故障在哪里呢？一个有关发现：只有大约五分之一 (22%) 的组织会分析所有报告的恶意邮件。

这些公司表示：“当员工没有收到安全专家的裁决时，他们应该如何自行确定所报告消息的恶意性尚不清楚。”

总体而言，调查还显示，组织使用至少一种额外的安全工具来补充 Microsoft 365 中提供的基本电子邮件保护。但是，调查发现，它们的实施效果各不相同。

报告解释说：“附加工具包括 Microsoft 365 Defender、安全意识培训技术、第三方安全电子邮件网关或第三方专门的反网络钓鱼插件。” “使用这些工具有多种部署模式。”

这些公司得出的结论是，这些漏洞和无效的防御通常会转化为组织的主要成本。

报告称：“成本包括事件后补救、手动从收件箱中删除恶意邮件，以及浪费时间对被报告为可疑但被证明是良性的邮件进行分类。” “组织还面临一系列其他成本，包括警报疲劳、网络安全分析师流动和监管罚款。”
