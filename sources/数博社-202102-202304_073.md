实用程序可用于“指示对手的存在或攻击的进展”

Deepfence 推出了新的开源工具 PacketStreamer，它可以从多个来源捕获网络流量，以揭示潜在的黑客行为。PacketStreamer传感器收集远程主机上的原始网络数据包，应用过滤器，并将它们转发到中央接收器进程，在那里它们以 pcap 格式写入。可以使用传输层安全性 ( TLS ) 压缩或加密流量流。该公司表示，传感器对远程主机的性能影响很小，它们可以在裸机服务器、Docker 主机和 Kubernetes 节点上运行。然后，用户可以处理 pcap 文件或将流量实时提供给 Zeek、Wireshark 或 Suricata 等工具，或作为机器学习模型的实时流。

### 用例

Deepfence 社区和产品负责人 Owen Garrett 表示，主要应用程序可能是检查服务器正在处理哪些请求以进行调试、事件取证和威胁搜寻活动。“系统管理员可能会发现调试正在运行的应用程序很有用，”他告诉The Daily Swig。“网络安全团队可能会发现捕获网络流量以进行事件后取证或支持威胁搜寻活动很有用。研究人员可能会发现捕获真实流量进行研究很有用。”他说，围绕使用机器学习来了解网络流量的活动也越来越多。“目标是准确地建立‘正常’流量的基线，识别异常值和可能的异常，然后将这些异常关联起来以识别可能表明存在对手或攻击进展的事件序列，”他说。Deepfence 的 ThreatStryker 攻击分析和威胁评估平台使用此过程从生产平台捕获流量以进行取证和异常检测。该公司声称，据其所知，没有其他简单、轻量级、可扩展的方法可以跨多个云从 K8s、VM 或 Fargate 等虚拟化环境捕获和流式传输数据包。“问题在于现代计算环境与传统环境有很大不同——它们是基于云的，跨越大量服务器，并使用虚拟化技术和容器平台，”Garrett 说。“PacketStreamer 采用现代网络捕获并将其转换为现代云原生环境。”加勒特说，公司欢迎贡献，到目前为止，它已经收到了很好的反馈。“我们有许多改进计划和要求，”他说。“我们将首先记录更多用例，包括有关如何将数据从 PacketStreamer 馈送到常见数据存储和分析工具（如 Redis、Apache Kafka 和 Elasticsearch）的详细信息。”  

# PacketStreamer 简介：云原生平台的分布式数据包捕获

PacketStreamer是一个开源工具，可以同时捕获来自多个远程源的网络流量，并将数据聚合到单个 pcap 日志文件中。它是用 golang 编写的，支持从 Kubernetes 节点、Docker 主机和裸机/虚拟机服务器进行网络捕获。

# 为什么要网络捕获？

良好网络安全实践的一个基础是能够从攻击面的前后捕获攻击者 TTP（战术、技术和流程）。诸如Sysdig Falco之类的工具从正在运行的工作负载（进程更改、文件系统访问等）中捕获 TTP 信号，并可以提供本地入侵的迹象，但仅这些信号只能说明攻击事件的后期故事。

组织需要看到更大的背景，这就是网络捕获和分析发挥作用的地方。观察网络流量可以在成功入侵之前揭示攻击者的行为，例如针对特定漏洞的侦察活动和武器化。观察流量还可以揭示横向传播和渗漏活动。

例如，在log4j 漏洞利用中，几乎所有的初始信号都是基于网络的。针对多个工作负载的初始 JNDI 侦察、然后触发向攻击者侦听器的传出请求（信标）的 JNDI 请求、检索要运行的 Java 类的后续请求……所有这些都是网络活动，无法通过 on- 识别工作负载传感器。您从工作负载遥测中获得的第一个信号可能是安装了漏洞利用工具包（例如加密矿工）。

# 我可以用 PacketStreamer 做什么？

使用 PacketStreamer，您可以将流量捕获活动扩展到跨越大量目标系统。例如，如果您运行蜜罐服务器来收集攻击 TTP，您可以使用 PacketStreamer 来侦听流量并在中央接收器上聚合所有捕获的流量。

在下面的示例中，我们在三台蜜罐服务器上安装 PacketStreamer：一台安装了基本 WordPress的主机，一台具有邀请NGINX配置的主机以 200 OK 消息响应每个请求，以及一台运行honeydb服务的主机。

## 蜜罐服务器

我们的蜜罐服务器运行一系列网络和其他服务，并定期接收来自远程主机的侦察流量。我们将使用 packetstreamer 捕获流量并将其转发到目标接收器：

```
\# 更新 sensor-remote.yaml 以将流量发送到目标
\# 接收器 IP 地址和端口sudo packetstreamer sensor \\ 
     --config contrib/config/sensor-remote.yaml
```

## 接收服务器

我们的接收服务器位于防火墙后面，侦听端口 8081 以获取来自蜜罐传感器的流量：

```
packetstreamer 接收器 --config contrib/config/receiver.yaml
```

接收服务器将聚合的捕获流量写入日志文件，例如/tmp/dump\_file。您可以通过多种方式查看和处理该日志文件，例如使用tshark解码选定的协议：

# Deepfence 如何使用 PacketStreamer？

PacketStreamer 也是 Deepfence ThreatStryker产品不可分割的一部分。ThreatStryker 从云工作负载和网络流量中收集攻击者 TTP。它对它们进行分类以确定 TTP 类型和潜在意图，并关联信号以确定攻击如何实时展开。

据我们所知，没有其他简单、轻量级、可扩展的方法可以从虚拟化环境（K8s、VM、Fargate）和跨多个云中捕获和流式传输数据包。我们正在开源此工具，以使用户能够：

*   捕获并保留流量以进行事后分析和取证
    
*   支持跨广泛目标基础设施的威胁搜寻活动
    
*   尝试针对网络流量使用机器学习等新方法来检测异常
