我们很高兴地宣布Deepfence ThreatMapper 1.2.0的发布，自 2021 年 10 月第一个开源版本以来，它提供了重要的功能升级。ThreatMapper 1.2.0 增加了以下功能：

*   攻击路径可视化，对最可利用的漏洞进行更复杂和更具代表性的计算
    
*   支持发现和扫描 AWS Fargate 工作负载的漏洞
    
*   支持与 Google Chronicle 集成
    
*   社区贡献增加对 ThreatMapper 传感器的 ARM 支持，为 IoT 和边缘用例打开威胁映射
    

这个主要版本还包括大量受社区启发的性能改进和错误修复、对 Kubernetes 和容器托管工作负载的更好支持、更好的注册表扫描、改进的报告生成和 UI 增强。

自开源发布以来，ThreatMapper 项目已在 GitHub 上增长到 1,000 多颗星，从 DockerHub 获得了 10,000 次拉取，并有助于帮助用户识别其正在运行的应用程序中的易受攻击的组件，例如 log4j 实例。它会在各种环境中扫描漏洞，包括在Raspberry Pi上运行的工作负载！

# ThreatMapper 1.2.0 的主要功能

## 攻击路径可视化和最可利用的漏洞计算

ThreatMapper 的主要目的是帮助您识别需要在生产应用程序中首先解决的关键安全漏洞，因为它们会带来最大的安全风险。这个最新版本包含大量增强功能，使您能够做到这一点。

## 攻击路径可视化

通过查看 VPC 和安全组，找到直接面向 Internet 的服务相对容易，但要找到更下游、代理后面并间接接收潜在恶意流量的易受攻击的服务要困难得多。ThreatMapper 通过不断将漏洞与网络流量关联起来，帮助找到所有这些隐藏的攻击路径。

ThreatMapper 的新攻击路径可视化在单个图形中显示最严重的漏洞，说明外部攻击者可能遵循的潜在路线来定位和利用这些问题：

![](../Images/dd476be9ea97b4d95d4f95db6e970749.png)

此可视化说明了利用这些漏洞的潜在攻击路线。您可以立即采取响应措施，例如使用 Web 应用程序防火墙保护应用程序流量，以限制暴露，同时您的开发人员负责更新、测试和重新部署易受攻击的应用程序。

## 最可利用的漏洞

ThreatMapper 的最可利用漏洞计算考虑了有关已发现漏洞的各种重要特征，以便根据漏洞利用的难易程度对它们进行排名——包括受影响漏洞的严重性、攻击向量、与外部攻击面的接近程度等。1.2.0 版本对该计算进行了增强，以更加重视网络可访问性和受影响工作负载的实时网络连接的存在，以及其他启发式方法，以便对高严重性的相对风险进行更具代表性的评估漏洞。

![](../Images/fde9a986195616feee4304e414123226.png)

## 支持 AWS Fargate

通过我们的企业ThreatStryker产品添加的功能，ThreatMapper 现在完全支持 AWS Fargate 工作负载。ThreatMapper 由两个组件组成——一个管理控制台和一系列部署到生产平台的传感器。在 AWS Fargate 环境中，ThreatMapper 传感器代理使用任务定义部署为边车容器，它们会自动注册到您的 ThreatMapper 管理控制台。

借助此功能，您可以监控广泛的应用程序资产，包括多个云和部署环境以及多种云模式——容器、无服务器、裸机和虚拟机。

## 支持谷歌编年史

我们在 ThreatMapper 中的通知、SIEM 和票务集成范围内添加了对Google Chronicle的支持。Google Chronicle 正在成为 Splunk、Elasticsearch 和 Sumo Logic 的常见替代品。ThreatMapper 可以将漏洞扫描的结果和用户活动的审核日志推送到 Google Chronicle 以进行离线分析和操作。

## ARM 支持

没有活跃的开源社区支持，开源软件就不会发生。我们很高兴 1.2.0 版本具有社区贡献，增加了对 ThreatMapper 传感器的 ARM 支持，这为 IoT 和边缘用例打开了安全可观察性和威胁映射。

我们很想向社区成员armourvx 大声疾呼，因为他们为 ARM 调整了 ThreatMapper 传感器，并通过在Raspberry Pi上运行传感器来证明这一点！

# ThreatMapper 1.2.0 的其他变化

在 ThreatMapper 1.2.0 中，您还会看到：

*   改进漏洞扫描，更广泛地支持 containerd 和 Kubernetes 平台。您可以通过单击或 API 调用扫描整个 Kubernetes 集群——节点和 Pod。复杂扫描速度的提高减少了完全扫描图像中的操作系统和语言组件所需的时间。
    
*   注册表扫描的增强功能，包括对 AWS ECR 目标账户角色 ARN 的支持、更好的进度反馈以及对基于标签的工件过滤的支持。
    
*   用于离线使用的更好的报告生成（PDF 和 xslx），改进了过滤和对下载过程的修复。
    
*   多项 UI 和用户体验改进，例如无需配置电子邮件中继即可邀请用户进入管理控制台的能力，以及针对容器和其他工作负载报告的更多元数据，以便您更轻松地识别它们。
