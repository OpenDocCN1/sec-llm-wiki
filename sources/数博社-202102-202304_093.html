黑客开始武器化 TCP 中间盒反射以进行放大的 DDoS 攻击

在理论上提出新颖的攻击机制六个月后，首次在野外检测到利用称为TCP 中间盒反射的新放大技术的分布式拒绝服务 (DDoS) 攻击。

“攻击 [...] 滥用易受攻击的防火墙和内容过滤系统来反映和放大受害机器的 TCP 流量，从而产生强大的 DDoS 攻击，”Akamai 研究人员在周二发布的一份报告中表示。

研究人员补充说：“这种类型的攻击危险地降低了 DDoS 攻击的门槛，因为从体积的角度来看，攻击者只需要 1/75（在某些情况下）的带宽量。”

分布式反射式拒绝服务 ( DRDoS ) 是分布式拒绝服务 (DDoS) 攻击的一种形式，它依靠可公开访问的 UDP 服务器和带宽放大因子 (BAF) 以大量 UDP 淹没受害者的系统回应。

在这些攻击中，攻击者向目标资产发送大量包含伪造源 IP 地址的 DNS 或 NTP 请求，导致目标服务器以放大的方式将响应传递回位于欺骗地址的主机，从而耗尽带宽发给目标。

这一发展是在 2021 年 8 月发表的一项关于新攻击向量的学术研究之后进行的，该攻击向量利用中间盒和审查基础设施中 TCP 协议实施中的弱点来对目标进行反射式拒绝服务 (DoS) 放大攻击。

虽然 DoS 放大攻击传统上滥用 UDP 反射向量——由于协议的无连接性质——非常规攻击方法利用中间盒中的 TCP 不合规性，例如深度数据包检测 ( DPI ) 工具来进行基于 TCP 的反射放大攻击.

据说利用该方法的第一波“明显”攻击活动发生在 2 月 17 日左右，攻击了银行、旅游、游戏、媒体和网络托管行业的 Akamai 客户，其流量峰值达到 11 Gbps每秒 150 万个数据包 (Mpps)。

Akamai 安全情报研究团队 (SIRT) 负责人 Chad Seaman 告诉 The Hacker News：“该向量已被单独使用，也被视为多向量活动的一部分，攻击的规模正在缓慢攀升。”

基于 TCP 的反射的核心思想是通过发送特制的 TCP 数据包来触发体积响应，从而利用用于执行审查法律和企业内容过滤策略的中间盒。

事实上，在云安全公司观察到的一次攻击中，一个 33 字节有效负载的SYN 数据包触发了 2156 字节的响应，有效地实现了 65 倍（6533%）的放大系数。

“主要的收获是新的载体开始在野外看到现实世界的滥用，”西曼说。“通常，这是一个信号，表明随着 DDoS 领域知识和流行度的增长以及更多攻击者开始创建工具来利用新向量，可能会出现更广泛滥用特定向量的情况。”

“防守者需要意识到我们已经从理论转向实践，他们应该根据这个他们可能很快在现实世界中看到的新向量来审查他们的防守策略，”希曼补充道。
