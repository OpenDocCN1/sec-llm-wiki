俄罗斯发布使用 DDoS 攻击攻击其基础设施的 IP 和域列表

随着持续的俄乌冲突持续升级，俄罗斯政府周四发布了一份包含 17,576 个 IP 地址和 166 个域的庞大列表，据称这些列表是针对其国内基础设施的一系列分布式拒绝服务 (DDoS) 攻击的幕后黑手.

俄罗斯国家计算机事件协调中心 (NCCCI) 发布的清单中的一些引人注目的域名包括美国联邦调查局 (FBI)、中央情报局 (CIA) 以及《今日美国》等多家媒体出版物的网站， 24News.ge、megatv.ge 和乌克兰的 Korrespondent 杂志。

作为其应对 DDoS 攻击的建议的一部分，该机构正在敦促组织隔离网络设备、启用日志记录、更改与关键基础设施元素相关的密码、关闭自动软件更新、禁用网站上的第三方插件、强制执行数据备份、并提防网络钓鱼攻击。

“使用俄罗斯 DNS 服务器。使用公司 DNS 服务器和/或电信运营商的 DNS 服务器，以防止组织的用户被重定向到恶意资源或其他恶意活动，”NCCCI 补充说。

“如果您组织的 DNS 区域由外国电信运营商提供服务，请将其转移到俄罗斯联邦的信息空间。”

这一事态发展之际，地面战争已被数字领域的一连串网络攻击所补充，黑客活动组织和其他自卫行动者支持两国攻击政府和商业实体的网站并泄露大量 个人数据。

据全球互联网访问监管机构NetBlocks称，尽管据报道，乌克兰不同地区（如 Mariupol 和 Sumy）出现了广泛的互联网中断，但据说俄罗斯已对该国境内的 Facebook 访问设置了广泛的限制。

那不是全部。乌克兰成功召集了一支由来自世界各地的民间黑客组成的志愿“IT 军队”，推出了一系列新目标，其中包括白俄罗斯铁路网络、俄罗斯本土的基于卫星的全球导航系统 GLONASS，以及 MTS 和电信运营商等电信运营商。直线。

“朋友们，你们已经做到了不可思议！但现在我们需要尽可能地动员和加强我们的努力，”IT 军队 Telegram 频道上的一篇帖子写道。

与此同时，Conti 勒索软件组织在上周宣布效忠俄罗斯后公开泄露其攻击方法时尝到了自己的药，此后宣布“我们已经启动并运行，我们的基础设施完好无损，我们将全力以赴油门，”根据标题为“还没有卡梅拉登！”的消息。在其黑暗的门户网站上。

在相关的发展中，美国财政部表示，它正在制裁一些俄罗斯寡头和实体，因为他们向政府提供直接和间接支持，并开展“专注于在乌克兰社会问题上挑拨离间”的全球影响力行动。

“拥有适当网络技能的独狼和有组织的威胁行为者可能会直接攻击他们国家的敌人或招募其他人加入协同攻击，”Trustwave SpiderLabs 研究人员说。“这些活动，再加上旨在‘准备’物理战场的特定恶意软件使用，可能会成为一种更广泛使用的策略，以削弱一个国家的防御能力、关键基础设施或通信流。”
