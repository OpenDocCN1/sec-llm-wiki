# APT攻击溯源 | 美国白宫将乌克兰 DDoS 攻击锁定在俄罗斯 GRU 黑客身上

今天，白宫已将最近摧毁乌克兰银行和国防机构网站的 DDoS 攻击与俄罗斯武装部队总参谋部（也称为 GRU）联系起来。

“美国政府认为，俄罗斯网络行为者可能已将包括军事和关键基础设施网络在内的乌克兰政府作为目标，以收集情报并为进行破坏性网络活动做好准备，”网络网络副国家安全顾问 Anne Neuberger说。

“我们认为，俄罗斯政府应对本周对乌克兰银行的大规模网络攻击负责。”

“我们拥有连接俄罗斯主要情报局或 GRU 的技术信息，因为已知的 GRU 基础设施被视为向乌克兰的 IP 地址和域传输大量通信。”

纽伯格还补充说，尽管这些事件“影响有限”，但这些事件可能是俄罗斯为其他更重要的努力做准备的一部分，为可能入侵乌克兰领土的更具破坏性的袭击“奠定基础”。

“俄罗斯喜欢在阴影中行动，并依赖于长期的归因过程。鉴于此，我们正在迅速采取行动，将 DDoS 攻击归因，”Neuberger 补充道。

乌克兰 SBU 情报机构网络安全负责人 Ilya Vityuk 也指责俄罗斯协调了本周针对乌克兰银行和政府机构网站的攻击。

然而，克里姆林宫否认了所有指控，发言人德米特里佩斯科夫表示，俄罗斯与拒绝服务攻击完全无关。

“而且，正如总统本周早些时候所说，如果俄罗斯通过不对称活动攻击美国或盟国，例如针对我们公司或关键基础设施的破坏性网络攻击，我们准备作出回应，”纽伯格说。

拜登总统今天还补充说：“我们正在大声并反复呼吁俄罗斯的计划。” “不是因为我们想要发生冲突，而是因为我们正在竭尽全力消除俄罗斯可能为证明这一点而提供的一切理由。”

Neubergerer 提到的事件是本周早些时候针对属于乌克兰军方和国有银行网站的在线服务的 DDoS 攻击。  

周二，乌克兰国防部和武装部队以及该国的两家国有银行 Oschadbank（国家储蓄银行）和 Privatbank（乌克兰最大的银行）在遭到 DDoS 攻击后被取缔。

虽然乌克兰国防部的网站被关闭，但Oschadbank和Privatbank的网站仍然可以访问，即使客户无法登录他们的网上银行账户。

袭击发生在乌克兰安全局 (SSU) 周一发布的新闻稿之后——其网站自周三以来一直无法访问——称该国目前正成为“大规模混合战争浪潮”的目标。

据 SSU 称，这场运动的最终目标是引发焦虑并削弱乌克兰人对国家保护他们的能力的信心。

乌克兰计算机应急响应小组还警告针对乌克兰当局的攻击，该攻击由 Gamaredon 黑客组织（之前由乌克兰安全和特工部门与俄罗斯联邦安全局 (FSB) 关联）协调。

Mandiant 情报分析副总裁 John Hultquist 表示：“得知乌克兰的 DDOS 攻击是由 GRU 进行的，这不足为奇。俄罗斯的军事情报部门在网络攻击和该领域的其他活动方面是同行中最具侵略性的。” ，告诉 BleepingComputer。

“我们已经看到他们多次实施 DDOS 攻击，用来骚扰和破坏机构。此类事件嵌套在更大的活动中并不罕见，这些活动可以采取多种形式，从黑客攻击和泄漏到严重的破坏性攻击。"

* * *

*更新：*英国政府还指出，俄罗斯 GRU 黑客是本周针对乌克兰的 DDoS 攻击的幕后黑手。

“英国政府判断俄罗斯主要情报局（GRU）参与了本周针对乌克兰金融部门的分布式拒绝服务攻击，”外交、联邦与发展办公室发言人说。

“这次袭击显示了对乌克兰主权的持续无视。这一活动是俄罗斯对乌克兰采取侵略行动的又一例证。”
