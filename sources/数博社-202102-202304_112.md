# 攻击者可以通过发送恶意电子邮件使思科邮件安全设备崩溃

思科已发布安全更新以包含影响其产品的三个漏洞，其中包括其电子邮件安全设备 (ESA) 中的一个高严重性漏洞，该漏洞可能导致受影响设备出现拒绝服务 (DoS) 状况。

该漏洞的标识符为 CVE-2022-20653（CVSS 评分：7.5），源于DNS名称解析中错误处理不足的情况，未经身份验证的远程攻击者可能滥用该漏洞发送特制电子邮件并导致拒绝服务。

该公司在一份公告中表示： “成功的利用可能允许攻击者导致设备无法从管理界面访问，或者在一段时间内处理额外的电子邮件消息，直到设备恢复，从而导致 DoS 状况。” “持续的攻击可能导致设备完全不可用，从而导致持续的 DoS 状况。”

该漏洞影响运行 Cisco AsyncOS 软件、运行版本 14.0、13.5、13.0、12.5 和更早版本的 Cisco ESA 设备，并且“启用了 DANE 功能并配置了下游邮件服务器以发送退回邮件”。DANE是基于 DNS 的命名实体身份验证的缩写，用于出站邮件验证。

思科认为 ICT 服务提供商 Rijksoverheid Dienst ICT Uitvoering (DICTU) 的研究人员报告了该漏洞，同时指出没有发现任何恶意利用的证据。

另外，这家网络设备制造商还解决了其 Prime 基础设施和演进的可编程网络管理器和冗余配置管理器中的另外两个缺陷，这些缺陷可能使攻击者能够执行任意代码并导致 DoS 条件 -

*   CVE-2022-20659（CVSS 评分：6.1）– Cisco Prime 基础设施和演进的可编程网络管理器跨站点脚本 (XSS) 漏洞
    
*   CVE-2022-20750（CVSS 分数：5.3）– Cisco StarOS 软件 TCP 拒绝服务 (DoS) 漏洞的 Cisco Redundancy Configuration Manager
    

几周前，思科发布了影响其 RV 系列路由器的多个关键安全漏洞的补丁程序，其中一些获得了 CVSS 严重性评分最高的 10 分，这些漏洞可能被武器化以提升权限并在受影响的系统上执行任意代码。
