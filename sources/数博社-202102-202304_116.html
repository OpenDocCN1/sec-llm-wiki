谷歌将隐私沙盒引入 Android 以限制用户数据的共享

原文：http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247486892&idx=1&sn=5e1b5db428aa4d0f192ae70af0fe221b&chksm=c1970893f6e08185165295f0c9dcb9ba00aabe64edfd319a6d1df7f44f38e8e93c2fff432dc1&scene=126&sessionid=1681312627#rd

谷歌周三宣布了将其隐私沙盒计划引入 Android 的计划，以期将其以隐私为重点但破坏性较小的广告技术扩展到桌面网络之外。

为此，这家互联网巨头表示将致力于构建防止跨应用跟踪的解决方案，例如 Apple 的 App Tracking Transparency ( ATT ) 框架，有效限制与第三方共享用户数据，并消除广告 ID 等标识符在移动设备上。

“Android 上的隐私沙盒建立在我们在网络上的现有努力的基础上，为改善用户隐私提供了一条清晰的道路，同时又不会危及对免费内容和服务的访问，”Android 安全和隐私产品管理副总裁 Anthony Chavez，说。

Privacy Sandbox于 2019 年推出，是 Google 对一组技术的总称，这些技术将逐步淘汰第三方 cookie 并遏制隐蔽跟踪，如指纹识别，通过减少网站可以访问的信息量来密切关注用户的在线情况活动。

但与 Apple 的 ATT 不同，该 ATT 要求所有应用程序在通过其他应用程序和网站跟踪它们之前征求用户的明确同意，新的多年项目旨在通过提供保护隐私的方式来启用移动广告，同时采取限制措施来取得平衡减少不同应用程序之间的跟踪。

预计苹果在 iOS 和 iPadOS 上的反跟踪变化将使 Meta Platforms 等广告驱动的公司在 2022 年损失 100 亿美元的收入，这家社交媒体公司称其为“对我们的业务来说是一个相当大的逆风”。谷歌还将 ATT 称为一种“生硬”的方法，这种方法可能无效，并且可能“导致用户隐私和开发者业务的结果更糟”。

尽管如此，这家 Alphabet 旗下的公司表示，它打算至少再支持现有的基于标识符的广告平台两年，并在未来发生任何变化之前向行业发出实质性通知。测试版计划在今年年底发布。

这一发展是在谷歌去年收紧其关于使用广告 ID 的政策时发生的，如果用户选择不接收基于兴趣的广告或广告个性化，开发人员将无法使用它。该更改预计将于2022 年 4 月 1 日通过 Google Play 服务更新推广到所有 Android 手机。

广告标识符是一个唯一的、用户可重置的字母和数字字符串，连接到单个设备，允许广告技术公司根据用户在不同应用程序中的在线行为和活动来推断用户的兴趣。

此外，Google 将要求应用声明“com.google.android.gms.permission.AD_ID”权限，以在运行 Android 12 及更高版本的设备上查询广告标识符，同时使其目标应用无法访问孩子们。

预计新系统还将包括一个用于 Android的FLEDGE API ，该 API 可以跟踪用户在应用程序内的行为，并将他们划分为“自定义受众定位”组。此外，谷歌正在推出其所谓的SDK Runtime，以“减少用户应用数据的未公开访问和共享”以及第三方 SDK 的使用。

在英国竞争和市场管理局 ( CMA )批准该公司在网络和 Android 上的应用程序中开发隐私沙盒计划并以解决竞争问题的方式设计它的努力后一周，广告技术大修到来并使消费者受益。

谷歌在移动设备上更换应用程序跟踪的彻底改变类似于其在网络上删除第三方 cookie 的提议，这一转变反映了 Apple Safari 和 Mozilla Firefox 的转变，这两家公司最近都默认阻止了第三方 cookie年。

但此举因过于不透明而遭到监管机构和隐私权倡导者的强烈反对，促使该公司将变更推迟到 2023 年底，并停止其有争议的基于FLoC的基于兴趣的广告方法，转而采用新的Topics API。

“通过主题 API 提案，浏览器将根据用户在称为 epoch 的时间段内的浏览活动推断用户的主题，目前建议为一周，”该公司表示。“为每个时期选择的主题将从该时间段内用户的前五个主题中随机选择。”

因此，当用户出于广告目的访问支持 Topics API 的网站时，浏览器将共享他们感兴趣的三个主题的轮换子集——最近三周中的每个主题——从前五个主题池中随机选择，其中然后可以由网站与其广告合作伙伴共享以投放相关广告。

主题还解决了 FLoC 的最大问题之一，它不仅可以防止广告提供商知道用户浏览了哪些网站，而且还可以让营销人员通过 IP 地址和其他方式识别用户，从而泄露比当前第三方 cookie 系统更多的信息。随着时间的推移记录他们的队列参与。

谷歌表示，其在 Android 上使用 Privacy Sandbox 的目标是创建“增强隐私的广告解决方案，用户知道他们的信息受到保护，开发人员和企业拥有在移动设备上取得成功的工具。”
