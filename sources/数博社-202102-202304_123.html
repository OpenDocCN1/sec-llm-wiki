帐户接管（ATO）攻击，一场猫捉老鼠的游戏

ATO 攻击正在演变。Cequence Security 的常驻黑客 Jason Kent 讨论了新型网络攻击在野外的样子。

Cequence 安全威胁研究团队在去年 6 月至 12 月期间对超过 210 亿次应用程序交易进行了分析，基于 API 的帐户登录和注册交易量增加了 92%，达到 8.5 亿次以上。强调攻击者和开发人员一样喜欢 API 的事实，同一数据集显示对登录 API 的帐户接管 (ATO) 攻击增加了 62%。

ATO 对最终用户的最初影响是恐慌——他们经常收到类似这样的消息：“您收到了来自您最喜欢的零售商/社交媒体/金融机构的密码重置通知，因为您的帐户已被盗用。”

成为帐户接管的受害者并不是很有趣，并且会导致人们想要停止与帐户所在的组织开展业务。对业务的影响不仅是潜在的客户流失，而且由于销售损失、基础设施成本超支和品牌受损，这些影响可以直接影响到利润。

ATO 攻击技术的演进

ATO 技术已经超越了常用的高强度、高容量凭证填充，包括使用特定用户名和密码的有条不紊的低速和低速攻击。

这些模式在对具有重要社会影响力的公司和个人的攻击（即评论、推荐等）中得到了最好的例证。对他们来说，帐户接管是一个长期存在的问题，其目标不一定是从被盗帐户中窃取，而是用它来放大正面或负面信息。

在 2021 年 7 月中旬至 9 月下旬期间，我们调查的一个组织经历了四个不同的攻击-防御周期，概述如下。

  • 第 1 阶段：在 7 月的第一周启用了 ATO 缓解措施，产生了立竿见影的影响。机器人消失了——但只持续了大约一周。

  • 第 2 阶段：机器人从 7 月下旬开始报复性回归，持续了近两个月，大肆攻击，消耗高达 80% 的所有登录流量。在这个阶段，攻击者每隔一天就不断地调整他们的努力——寻找防御中的弱点。他们还使用数十万个干净的住宅代理 IP 来分发他们的行为并掩盖他们的身份和位置。

  • 第 3 阶段：又一次试图隐藏在众目睽睽之下，在此阶段，攻击者从高容量转向低速和慢速，混合了他们的规避技术。攻击者被看到对良好的浏览器指纹进行逆向工程并种植合法的 cookie 配置文件（包括特定于站点的和常见的网络工具，如谷歌分析）。在超过三周的时间里，机器人活动从未超过总流量的 20%。

  • 第 4 阶段：机器人活动已降至几乎历史最低点。

此处观察到的模式以前在其他客户环境中以一种或另一种形式出现过。机器人会安静一段时间，然后他们会复仇。监控 bot 论坛证实，botters 经常通过分享想法、探索未受保护的向量（如已弃用的 API）进行协作，所有这些都是为下一次攻击做准备。成功的防御需要持续保持警惕，监控所有类型的端点——Web、API 和移动，以及您的同行之间以及与您的保护提供商之间的协作。

ATO 是越来越多的组织面临的一个问题，因为威胁参与者想要窃取礼品卡、访问一键式购买并主导炒作销售以购买和转售库存。通过这个分析，我们看到，速度和活力都在上升。所有拥有经过身份验证的应用程序的组织都应考虑监控 ATO，并构建缓解措施以确保其客户满意度保持较高水平。
