VirusTotal 黑客：查找托管在 VirusTotal 上的被盗凭据

原文：http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247486761&idx=1&sn=0d73f7c22df91c5ee19f9dde1e36e792&chksm=c1970816f6e08100ccf0f2ee8c703c28a686ee4f7339b92b112b95c0ddcae9a3b7e400101f9b&scene=126&sessionid=1681312635#rd


SafeBreach 的研究人员发现，用于分析可疑文件、URL 和 IP 地址的流行在线服务 VirusTotal 可用于收集被恶意软件窃取的凭据。

事实上，凭借 600 欧元的 VirusTotal 许可证，他们只需使用一些工具执行简单的搜索，就已经设法收集了超过 1,000,000 个凭据。

被盗凭据的来源

凭证包含在常见的信息窃取者和键盘记录器用来从受感染机器中窃取它们的文件中。

SafeBreach 的安全研究主管 Tomer Bar 告诉 Help Net Security，这些文件最终可能会托管在 VirusTotal 上，因为黑客使用 VirusTotal 来促进出售受害者的数据，或者攻击者错误地上传了这些文件。

它们也可能由不知道它们包含敏感信息的第三方（例如，安全研究人员或托管 C2 服务器的公司）上传。最后，一些环境被配置为自动将文件上传到 VirusTotal 以验证它们是否“干净”。

查找凭据被盗的文件

就像谷歌搜索可用于搜索易受攻击的网站/系统、物联网设备和敏感数据（这种方法被称为谷歌黑客或多克）一样，VirusTotal 的 API 和工具（VT Graph、Retrohunt 等）可用于查找包含被盗数据的文件。

为了证明这一点，研究人员编制了一份这些文件的名称列表，获得了每月一次的 VirusTotal 许可证，允许他们进行搜索、探索 VirusTotal 的数据集并执行恶意软件搜索——然后开始搜索它们。

没多久就找到了一些。根据恶意软件的不同，这些文件包含电子邮件和社交媒体账户、电子商务网站、在线支付服务、游戏平台、在线政府服务、流媒体平台、在线银行账户和加密货币钱包私钥的凭据。

他们还将其中一些文件与各种黑客论坛和电报组上的被盗凭据的特定卖家联系起来，并表明在某些情况下，犯罪分子可能很容易发现访问恶意软件的 C2 FTP 服务器的凭据并使用它们“收集”被盗凭据。

“我们的目标是识别犯罪分子可以通过 VirusTotal 许可证收集的数据，”Bar 指出，并表示他们已经证明了这种被称为“VirusTotal Hacking”的方法可以大规模使用。

“使用这种方法的犯罪分子可以使用无感染的方法在短时间内轻松收集几乎无限数量的凭据和其他用户敏感数据。我们称其为完美的网络犯罪，不仅是因为没有风险且付出的努力非常低，而且还因为受害者无法保护自己免受此类活动的侵害。在受害者被原始黑客入侵后，大多数人对上传和存储在 VirusTotal 和其他论坛中的敏感信息知之甚少。”

研究人员通过其子公司 Chronicle 敦促 VirusTotal 的所有者谷歌定期搜索和删除包含敏感用户数据的文件，并禁止上传这些文件的 API 密钥，并添加一种算法，禁止上传包含敏感明文数据或加密的文件附有解密密码的文件（作为文本或包含在图像中）。

他们还指出，防御者应该利用恶意软件的不安全 C2 通信协议（与托管公司合作）来沉陷或终止 C2 服务器。
