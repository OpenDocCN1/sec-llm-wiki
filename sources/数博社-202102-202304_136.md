# 美国网络司令部将 MuddyWater 与伊朗情报联系起来

美国网络司令部周三表示，名为 MuddyWater 的黑客组织与伊朗情报机构有关。

“MuddyWater 是一个伊朗威胁组织；此前，业界曾报道称，MuddyWater 主要针对中东国家，也针对欧洲和北美国家，”网络司令部在一份通知中说。

“MuddyWater 是伊朗情报与安全部 (MOIS) 的下属部门。”

网络司令部在推特上表示，MuddyWater 正在使用一套恶意软件进行间谍活动和恶意活动，其归属由 FBI 国家网络调查联合特遣部队提供。

“MOIS 黑客组织 MuddyWater 正在使用恶意软件的开源代码，”它说。

“MuddyWater 和其他伊朗 MOIS APT 正在使用 DNS 隧道与其 C2 基础设施进行通信；如果您在网络上看到这种情况，请寻找可疑的出站流量。”

除了通知之外，MuddyWater 恶意软件样本也被上传到 VirusTotal，包括PowGoop DDL sideloader和使用 DNS 隧道的 Mori 后门。

“当运行非恶意可执行文件 GoogleUpdate.exe 时，Goopdate.dll 使用 DLL 侧加载来运行。然后 goopdate.dll 将对 goopdate.dat 进行去混淆处理，这是一个用于去混淆处理和运行配置的 PowerShell 脚本。txt，”网络司令部在详细说明 PowGoop 工作原理的一个实例时说道。

“Config.txt 是一个 PowerShell 脚本，它与 PowGoop C2 服务器建立网络通信。它使用修改后的 base64 编码机制与 C2 服务器之间发送数据。C2 服务器的 IP 通常在 config.txt 中硬编码。”

11 月，美国、英国和澳大利亚的网络当局将利用 Fortinet 和 Exchanges 漏洞的攻击归咎于伊朗支持的攻击者。

“FBI 和 CISA 观察到这个伊朗政府资助的 APT 组织至少从 2021 年 3 月开始利用 Fortinet 漏洞，并至少从 2021 年 10 月开始利用 Microsoft Exchange ProxyShell 漏洞，以便在后续行动之前获得对系统的初始访问权限，其中包括部署勒索软件，”一份联合新闻稿称。

“ACSC 也知道这个 APT 组织在澳大利亚使用了相同的 Microsoft Exchange 漏洞。”

当局表示，攻击者并没有针对特定的经济部门，而是仅仅专注于尽可能利用漏洞，然后在操作之后，他们试图将最初的访问转变为数据泄露、勒索软件攻击或勒索。

同月，微软表示，2020 年国家资助的伊朗黑客对 IT 服务公司的攻击几乎不存在，但 2021 年的潜在攻击超过了 1500次。
