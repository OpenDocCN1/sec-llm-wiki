# 新的 Abcbot 僵尸网络追逐中国云提供商

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMDIxMjU2MA==&mid=2247486626&idx=1&sn=229b0ceb77fd19c89a3afdb9283b3c35&chksm=c197099df6e0808bd7cd51220a9c75236583aa81910328fda620f85de1cd32ee22b08d81eda4&scene=126&sessionid=1681312639#rd](http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247486626&idx=1&sn=229b0ceb77fd19c89a3afdb9283b3c35&chksm=c197099df6e0808bd7cd51220a9c75236583aa81910328fda620f85de1cd32ee22b08d81eda4&scene=126&sessionid=1681312639#rd)

安全研究人员发现了一个新的恶意软件僵尸网络，在过去几个月中，它专门针对中国云托管服务提供商的基础设施。  

Cado Security 在今天的一份报告中表示，名为 Abcbot的僵尸网络的目标是阿里云、百度、腾讯和华为云等公司托管的服务器，这与 趋势科技 和 奇虎 360 Netlab之前的调查结果相呼应 。

“我的理论是，如华为云，腾讯和百度的新的电信运营商都没有成熟的东西像AWS，其中包括在云实例部署在一个不安全的方式自动报警，” CADO安全的马特·缪尔告诉 *记录* 在本周的一封电子邮件。

“阿里巴巴云肯定存在的时间更长，因此其安全服务更加成熟，但值得注意的是，在趋势科技 \[最初\] 看到针对华为云的恶意软件之后，我们分析的新样本针对的是其他中国云提供商，”缪尔补充道。

Abcbot 的攻击通常针对这些公司托管的 Linux 服务器，这些服务器使用弱密码保护或运行未打补丁的应用程序。

找到初始入口点后，Abcbot 会部署一个 Linux bash 脚本，禁用 SELinux 安全保护，为攻击者创建后门，然后扫描受感染主机以查找其他恶意软件僵尸网络的迹象。

如果发现竞争恶意软件，Abcbot 会杀死已知与其他僵尸网络相关的进程以及与加密挖掘操作相关的进程。

然后，它还采取了其他僵尸网络未曾见过的步骤，即删除 SSH 密钥并仅保留自己的密钥以确保它们是唯一可以连接的密钥。

Muir 说，这种行为表明其他团体正在使用类似的技术，Abcbot 开发人员也发现并决定阻止。

“或者，他们可能正在从之前的活动中删除自己的密钥，”缪尔还告诉我们。

Muir 说，Cado 研究人员分析的 Abcbot 样本仅包含将受感染系统作为 Abcbot 僵尸网络的一部分的功能。

但是，趋势科技之前分析的样本包括加密货币挖掘模块，Netlab 分析的样本包括 DDoS 攻击功能。

考虑到 Abcbot 为终止它没有自行生成的加密挖掘进程而采取的步骤；可能它的最终目的毕竟是为攻击者产生加密货币利润。

目前，Cado 和其他研究人员仍然不知道 Abcbot 僵尸网络的规模。

“鉴于恶意软件针对特定的 CSP，这表明传播相当有限，”Muir 说。

Cado 安全研究人员补充说：“传播方法（通过 known\_hosts 的枚举）绝对意味着它已经超出了它最初打算瞄准的 CSP 的边界。”
