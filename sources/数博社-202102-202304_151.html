Web 应用程序攻击猛增，是时候保护 API 了

原文：http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247486623&idx=1&sn=f1355a2e070c71d305921b7bc79795e1&chksm=c19709a0f6e080b6192255a5b6015912fad8b31d1b42d7359dc723b0a24ef6e24dbaf676d53a&scene=126&sessionid=1681312643#rd

Imperva 的一项研究显示，自 2019 年 10 月以来，针对英国企业的Web 应用程序攻击增加了 251%，使组织和消费者都面临风险。

在对近 470 万起与 Web 应用程序相关的网络安全事件进行的研究中，Imperva 研究实验室发现攻击平均每季度增加 22%。最令人担忧的是，此类攻击的增长率继续上升，从 2021 年第二季度到第三季度激增了 67.9%。

最显着的增长之一是远程代码执行 (RCE) / 远程文件包含 (RFI) 攻击，增长了 271%。RCE / RFI 攻击以企业网站和服务器为目标，被黑客用来窃取信息、破坏服务器甚至接管网站并修改其内容。

Web 应用程序攻击激增，导致数据泄露

Web 应用程序攻击激增的后果是数据泄露的急剧增加。今年早些时候，Imperva 研究实验室发现 50% 的数据泄露始于 Web 应用程序。随着漏洞数量每年增加 30%，被盗记录的数量以惊人的 224% 的速度增长，预计到 2021 年底将有 400 亿条记录被泄露，其中 Web 应用程序漏洞可能造成大约 20 个十亿。

Imperva技术总监Peter Klimek表示：“大流行使企业迫切需要尽快启动各种数字化转型项目，这几乎可以肯定是这次攻击激增的驱动因素。”

“应用程序开发本身不断变化的性质也非常重要。从 DevOps 的角度来看，API 的快速扩散和向云原生计算的转变等发展是有益的，但对于安全团队而言，应用程序架构的这些变化以及随之而来的攻击面增加使他们的工作变得更加困难。”

API 保护的重要性

与欺诈和网络犯罪有关的损失在大流行期间失控，国家欺诈情报局估计仅 2021 年上半年就损失了约 13 亿英镑，是同期损失金额的三倍多2020 年。这些数字表明，该问题将在 2022 年全年继续恶化。

“企业通过其 Web 应用程序看到的流量比以往任何时候都多，尤其是API，”Klimek 继续说道。“现在超过 70% 的网络流量来自 API，这意味着企业的曝光率只会越来越高。仅仅拥有 WAF 并希望获得最好的结果是不够的——企业需要投资于全面的 Web 应用程序和API 保护(WAAP) 堆栈，其中包含 RASP 和高级机器人保护等元素，使他们能够保护从边缘到数据库的所有内容。”
