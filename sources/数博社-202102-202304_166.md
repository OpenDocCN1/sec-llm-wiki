# 网络司令部和国家安全局局长：网络安全是一项团队运动

当今许多最大的网络挑战威胁到集体利益，必须通过持续的集体行动来应对。

  

在这个战略竞争时代，外国利用网络行动窃取信息、影响人口和破坏产业。威胁和影响是共同的：我们的对手针对所有人——政府、行业、民间社会等——和网络犯罪分子勒索赎金并挟持我们的大小企业，并威胁数百万人依赖的关键基础设施。

  

未来，公共部门和私营部门之间的相互合作需要为所有美国人提供更安全、更安全的在线环境。

  

美国网络司令部和国家安全局寻求通过加强我们的能力、准备和弹性来应对这种不断变化的威胁。我们通过客场比赛来做到这一点。美国网络司令部与网络空间中的广泛对手针锋相对。我们保卫国防部的全球信息网络，在防御和进攻范围内开展行动，并为国防部长和战斗指挥官提供网络空间选择，这些选择在战略竞争时代变得越来越重要。

  

NSA 的网络安全使命是预防和消除对国家安全系统、国防部和关键基础设施的威胁，重点是国防工业基础。美国国家安全局利用其在外国信号情报、漏洞分析和技术专长方面的“超级力量”来执行其使命。

  

网络安全是一项团队运动：问题的范围和规模太大，任何一个组织都无法单独解决。私营和公共部门，包括州和地方同事，必须越来越多地相互依赖和补充，以对抗这些威胁并改善集体防御。

  

虽然联邦政府的任务是协调和领导这场斗争，但全国 85% 以上的关键基础设施，包括网络和通信网络，仍然掌握在私人手中。因此，我们每天都在努力提高透明度，同时与私营部门网络安全专业人员进行有效整合。我们的目标是共同实现一个共同目标，也是美国网络司令部和国家安全局最重要的任务领域之一：保卫国家。

  

鉴于颠覆性技术的飞速发展，尤其是在机器学习和自主系统方面，美国网络司令部和美国国家安全局在面对当今挑战或需要为明天的问题确定解决方案方面并非孤军奋战。这就是为什么 USCYBERCOM 和 NSA 与学术界、工业界和国际合作伙伴在技术推广方面的投资是合作的并且已经产生了回报。

  

通过 NSA 新成立的网络安全协作中心，该机构与私营部门合作，防止和消除对国家安全系统、国防部和国防工业基地的威胁。该中心与我们的美国政府合作伙伴共享威胁信息，以协助他们保护关键基础设施，在提供可操作的外国网络威胁信息以预防和消除网络威胁的能力方面提供比较优势。NSA 作为其信号情报任务的一部分开发的网络威胁情报是双向信息交换的关键驱动力。

  

美国网络司令部与我们 DreamPort 合作设施的马里兰州创新与安全研究所合作，将越来越多地追求“如果？” 场景，与工业界和学术界合作开发工具和技术。例如，对手可以使用机器学习来创建完全人工但令人信服的在线内容，称为“深度伪造”。为了检测和揭露这些虚假内容，美国网络司令部必须运用自己的机器学习技术和能力。仅靠人工分析不足以应对以我们对手的速度和规模生成的材料。

  

针对我们国家关键基础设施的勒索软件日益引人注目的威胁是另一个必须通过全球社会方法来应对的国家安全挑战。该方法的一部分是国防部的“向前防御”战略，由美国网络司令部实施，持续参与网络活动以威慑、拒绝和破坏敌对活动。结合我们合作伙伴的贡献，我们的网络效果任务非常强大。

  

为所有美国人维护一个安全可靠的在线环境是一项集体利益；享受这种环境的好处需要速度、敏捷性和团结一致的努力。USCYBERCOM 和 NSA 今天在网络空间面临的挑战不仅仅是我们一个人——从简单的网络攻击到勒索软件再到间谍活动，全社会都必须防御恶意网络事件。这种不断变化的环境对我们构成共同威胁，也是我们可以团结起来的共同事业。

  

随着威胁的不断演变，我们用来应对威胁的创新方法也将不断演变。网络作为一项团队运动，今天的挑战可能成为共享成功解决方案的明天机会。
