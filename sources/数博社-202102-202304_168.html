网络安全生态系统

介绍

这是一个正在进行的项目，旨在捕捉包含网络安全、隐私和风险的行业布局。

地图项目是来自生态系统每个区域的视觉效果、定义和示例的组合。从多个角度看待生态系统是应对其庞大性的最实用方法。



访问控制

验证

自适应认证

概述：基于用户上下文（例如位置、设备等）动态触发的身份验证策略。

示例： SecureAuth、Okta


生物识别技术

概述：使用身体或行为特征来验证和验证身份。

示例： 清除、证明、无钥匙


联合身份

概述：多个身份验证系统使用预定义的合同和属性映射共享身份数据。通用标准包括 SAML 和 OAuth 2.0。

示例： Okta、Ping Identity、Stytch、WorkOS


多重身份验证 (MFA)

概述：结合两个或多个身份验证要求（例如密码和一次性令牌）以提高安全性的身份验证。

示例：Duo Security、Authy、Trusona


单点登录 (SSO)

概述：使用单个会话向多个系统进行用户身份验证。过去通过代理使用基于 Web 的会话实现。

示例：Oracle 访问管理、Symantec SiteMinder


社交登录

概述：使用来自社交网络的身份验证登录第三方站点。

示例：Facebook 登录，使用 Slack 登录


授权

数据访问治理

概述：用于在非结构化数据（电子表格、文档、PDF 等）上获得可见性和实施访问控制策略的系统。

示例：Varonis、StealthBits、SailPoint 文件访问管理器、Immuta


目录服务

概述：用于收集有关用户、设备和资源的信息以进行身份验证和授权的存储库。LDAP 是目录服务的通用标准。

示例：Microsoft Active Directory、ForgeRock 目录服务、JumpCloud


身份治理和管理 (IGA)

概述：用于管理帐户和凭据、访问配置和身份治理的系统。

示例：SailPoint、Oracle 身份治理


特权访问管理 (PAM)

概述：用于管理用户、共享帐户、机密、密钥和其他高风险凭证的特权（提升）访问权限的系统。

示例：CyberArk、BeyondTrust、HashiCorp Vault


客户身份 (CIAM)

概述：用于控制客户对应用程序的访问和管理客户资料信息的系统。

示例：Okta、ForgeRock、Ping Identity、FusionAuth


身份证明

概述：用于根据生活史或从公共和专有数据源聚合的其他数据来验证用户身份的服务。

示例：Trulioo、Jumio、Checkr、Truework、AU10TIX


应用安全

API 安全

概述：用于预防和监控恶意攻击和 API 滥用的流程和工具。

示例：Salt Security、Wallarm、42Crunch


机器人管理

概述：用于评估网站机器人和阻止恶意活动的技术和工具。

示例：PerimeterX、Netacea、Imperva 高级机器人检测、形状安全


软件构成分析

概述：识别在代码库中使用开源软件以评估安全性、质量、许可和其他软件供应链风险的过程。

示例：Veracode、WhiteSource、Sonatype、Cloudsmith


静态和动态应用程序安全测试 (SAST/DAST)

概述：用于识别应用程序中安全漏洞的方法和工具。

示例：Snyk、Acunetix、Stackhawk、Cobalt Strike


Web 应用程序防火墙 (WAF)

概述：保护 Web 应用程序或 API 免受破坏 Web 应用程序安全性和可用性的漏洞利用、机器人和攻击的系统。

示例：F5 Advanced WAF、Signal Sciences、Cloudflare Web Application Firewall、Reblaze


区块链和 Web3

概述：用于保护和管理区块链和 Web3 平台风险的工具。

示例：valid.network、Fireblocks、GK8、NuID、Remme


云安全

云访问安全代理 (CASB)

概述：帮助保护和管理基于云的 SaaS 应用程序和基础设施的使用的平台。

示例：Netskope、Bitglass、McAfee MVISION Cloud


容器和工作负载保护

概述：用于保护不同云环境中的容器和工作负载的流程和工具。

示例：Orca、Aqua、Portshift、Intezer Protect


管理与合规

概述：云环境配置的持续管理、监控、策略实施和合规性。

示例：Bridgecrew、CloudCheckr、Cloudanix、Stacklet、Armor


微分段

概述：在工作负载级别将网络逻辑划分为安全段的技术和工具，并根据每个段的风险和要求进行特定控制。

示例：Guardicore


认证和培训

认证

概述：管理机构提供的官方网络安全专业认证计划。

示例：认证信息系统安全专家 (CISSP)、认证信息系统审计师 (CISA)、认证道德黑客 (CEH)


训练

概述：关于网络安全相关主题的教育和学习课程或材料。

示例：SANS Institute、The Cyber Mentor、Cybrary


网络犯罪

高级持续威胁 (APT)

概述：有组织的威胁行为者团体，他们出于政治或经济原因未经授权访问网络。

示例：舒适熊、双龙


僵尸网络

概述：受攻击者有组织控制的受感染设备网络。

示例：Mirai、Necurs、Bredolab


暗网

概述：互联网站点和服务的隐藏区域，只能通过专门的 Web 浏览器或代理访问。

示例：The Hidden Wiki、ProPublica、Daniel、Silk Road


欺诈和诈骗

概述：旨在诱使用户共享敏感信息的内容、网络钓鱼、垃圾邮件和其他欺诈活动。

示例：市场欺诈、帐户接管 (ATO)、就业诈骗


恶意软件

概述：网络犯罪分子开发的侵入式软件，用于窃取数据或破坏系统和网络。

示例：Pegasus、Petya、Morris 蠕虫


勒索软件

概述：一种特定类型的恶意软件和相关技术，用于在支付赎金之前限制对数据或其他资源的访问。

示例：REvil、WannaCry、DarkSide


欺诈和交易安全

概述：监控、检测、预防和补救欺诈性交易和活动的系统和流程。

实施例（一个或多个）：筛，Riskified，推断，长石砂岩实验室，BioCatch，螺栓欺诈保护，MagicCube，移位，Datavisor，合金


治理、风险和合规性

治理

GRC

概述：用于自动化和集成企业、运营和 IT 风险管理流程和数据的系统。

示例：RSA Archer、LogicGate、ServiceNow GRC


指标和仪表板

概述：用于跟踪和显示关键绩效指标以衡量网络安全风险和有效性的工具。

示例：UpGuard，自定义内部仪表板


政策和程序

概述：用于管理个人访问组织系统和数据的规则的书面文档和工具。

示例：SANS 安全策略模板、Zavanta、Tugboat Logic 信息安全策略生成器


安全意识

概述：培训、指导和工具，用于教育组织内的用户如何保护自己和公司资产免受损失或损害。

示例：KnowBe4、CybSafe、Living Security


职责分离 (SOD)

概述：自动执行多人之间共享的责任以执行关键流程。减少欺诈和错误。

示例：SAP 访问控制、Pathlock


标准和框架

概述：用于系统地管理安全和风险的策略和控制的书面指南。

示例：NIST 特别出版物 800-53、ISO 27002、ISACA COBIT


风险

网络保险

概述：专业商业保险，用于防止与网络安全相关的损失，包括数据泄露、勒索软件和其他事件。

示例：AIG Cyber Insurance、Chubb Cyber Insurance、Liberty Mutual Cyber Liability


企业风险管理

概述：在执行层面识别、管理和补救公司范围内的风险。

示例：COSO ERM 集成框架，ISO 31000


风险评级

概述：评估和量化组织的网络安全风险级别。

实施例（一个或多个）：BitSight，SecurityScorecard，CORAX


遵守

审计员和评估员

概述：被授权进行独立审查并证明符合法规和标准的公司。

示例：普华永道——信托解决方案，德勤——审计与鉴证，安永——鉴证，毕马威——审计，Trustwave


合规自动化

概述：用于自动化合规流程和持续控制监控的工具。

示例：Vanta、Secureframe、Tugboat Logic、Drata、非常好的安全性


规定

概述：执行政府制定的法律的官方规则。由授权的政府机构实施和维护。

示例：HIPAA、Sarbanes-Oxley (SOX)、通用数据保护条例 (GDPR)


第三方保证

概述：第三方代表客户对服务提供商的服务、内部控制和风险进行的检查。结果记录在合规报告中。

示例：SOC 2、ISO 27001


政府和非政府组织

机构

概述：专门从事网络安全政策、研究和保护的政府机构。

示例：国家安全局 (NSA)、网络安全和基础设施安全局 (CISA)、联邦调查局 (FBI)、美国国家标准与技术研究院 (NIST)


国际组织

概述：专门从事网络安全政策、研究和保护的国际政府组织。

示例：国际刑警组织、北约网络防御、联合国反恐办公室


非政府组织

概述：专门从事网络安全政策、研究和保护的非营利组织。

示例：电子前沿基金会 (EFF)、互联网观察基金会 (IWF)、信息安全论坛 (ISF)、互联网安全中心 (CIS)


大学

概述：公立和私立大学的网络安全研究和教育计划。

示例：公民实验室、斯坦福互联网天文台、麻省理工学院斯隆的网络安全


基础设施安全

网络安全

DDoS 缓解

概述：用于限制和防止分布式拒绝服务攻击中断的服务。

示例：Cloudflare DDoS 保护、Radware Cloud DDoS 保护服务、Akamai Prolexic


DNS/DHCP/IPAM

概述：网络上使用的 DNS、DHCP 和 IP 寻址的服务和管理。

示例：OpenDNS、Cloudflare DNS、BlueCat


防火墙

概述：网络安全设备根据规则调节网络流量。

示例：CheckPoint 防火墙、思科安全防火墙、F5 高级防火墙管理器、Palo Alto Networks 下一代防火墙


入侵检测系统（IDS）/入侵防御系统（IPS）

概述：监控和防止网络流量匹配已识别安全威胁配置文件的系统。

示例：CheckPoint 入侵防御系统、Cisco Secure IPS、Juniper SRX


网络访问控制 (NAC)

概述：提供对访问网络的设备的可见性和控制的系统。

示例：Aruba 安全网络访问控制、Netshield、Portnox


安全网络

概述：通过额外的安全控制来增强网络的策略、流程和工具。具有多个与网络安全相关的功能的相邻域。

示例：Exinda Network Orchestrator、Forescout


安全网络网关

概述：过滤用户发起的互联网流量并执行公司和监管内容策略的系统。

示例：Authentic8、Palo Alto Networks Prisma Access、Menlo Secure Web Gateway、Zscaler


SSL 可见性

概述：提供对加密网络流量的可见性以进行监控和威胁分析的工具。

示例：F5 SSL Orchestrator、Broadcom SSL Visibility Appliance


虚拟专用网络 (VPN)

概述：使用户能够安全、私密地浏览公共互联网站点并通过公共网络访问私有网络的系统。

示例：NordVPN、ProtonVPN、PulseSecure


无线网络安全

概述：通过无线网络防止损坏和未经授权的访问。

示例：7SIGNAL、WatchGuard Secure Wi-Fi、Aruba Wireless


端点安全

应用控制

概述：用于防止在端点上执行恶意软件和未经批准的应用程序的方法和工具。

示例：Thycotic Privilege Manager、McAfee Application and Change Control、VMware Carbon Black App Control


端点检测和响应

概述：安装在端点上的工具，用于记录监控和威胁调查的关键活动。

示例：SentinelOne、Cybereason、Tanium Threat Response、Sophos Intercept X Endpoint


端点保护

概述：保护端点免受威胁的软件，包括恶意软件、勒索软件、网络钓鱼和数据盗窃。

示例：卡巴斯基、CrowdStrike Falcon 端点保护、SparkCognition DeepArmor


主机入侵防御系统 (HIPS)

概述：基于端点的入侵检测和防御系统，用于监控和分析端点上的内部和网络流量，以预防和检测威胁。

示例：McAfee Host Intrusion Prevention


安全桌面

概述：管理端点以遏制威胁和安全的企业网络访问。

示例：Hysolate、Absolute、Ivanti


数据中心安全

备份和恢复

概述：用于创建、存储和恢复数据副本以防止数据丢失的过程和工具。

示例：Veritas、Rewind、Hewlett Packard Enterprise 数据保护


安全存储

概述：用于维护数据安全性和完整性的流程、硬件和设施。

示例：Commvault、Veeam、Iron Mountain


消息安全

概述：用于保护消息传递和通信基础设施的流程和工具，主要关注基于电子邮件的威胁。

示例：ProofPoint 电子邮件安全和保护、GreatHorn、IRONSCALES、Area 1


投资者

天使投资人

概述：独立的个人投资者或一群投资于早期网络安全公司的个人投资者。

示例：Silicon Valley CISO Investments、SYN Ventures、Cyber Seed Fund I


私人产权

概述：后期私募股权公司和投资银行拥有大量网络安全公司。

示例：Thoma Bravo、Vista Equity Partners、Momentum Cyber


风险投资

概述：拥有大量网络安全投资和退出的机构风险投资公司。

示例：Andreessen Horowitz、Sequoia、AllegisCyber Capital、ForgePoint Capital


媒体

分析师

概述：涵盖网络安全公司和趋势的公司和独立分析师。

示例：Gartner、Forrester


图书

概述：作者撰写有关网络安全主题的书籍。

示例：Bruce Schneier、Matt Bishop、Victoria Baines


活动

概述：与网络安全相关的会议和活动。

示例：RSA 会议、DEF CON、Oktane


消息

概述：媒体和独立记者报道网络安全新闻和事件。

示例：CyberWire，本周安全，tl;dr sec


出版物

概述：关于网络安全主题的杂志、期刊和其他数字媒体。

示例：SC 杂志、ISACA 杂志、CISO 杂志


移动安全

概述：工具保护存储在移动设备上的敏感信息，包括智能手机、平板电脑和可穿戴设备。

示例：Lookout Mobile Endpoint Security、Deep Instinct Mobile Security、SIRIN LABS


物理安全

联网汽车安全

概述：保护车辆电子系统、软件和数据免受恶意攻击。

实施例（一个或多个）：Foretellix，SafeRide，Otonomo


互联家庭安全

概述：保护家庭电子系统、软件和数据免受恶意攻击。

示例：Bitdefender BOX、CUJO AI、SAM、Plume HomePass


固件安全

概述：保护计算机或设备的固件免受损害。

实施例（一个或多个）：梯形，Eclypsium，Vdoo


物联网 (IoT) 安全

概述：物联网 (IoT) 设备和连接网络的安全性。

示例：Armis、Regulus、Bastille、Karamba Security


运营技术 (OT) 安全

概述：监控和控制工业控制系统 (ICS) 安全性的工具。

示例：Claroty、Tenable.ot、Star Lab


供应链安全

概述：在整个软件和物理供应链中识别威胁并降低风险。

示例：RunSafe、iTrust、Kodiak Hub


隐私和数据保护

消费者自由

个人数据经济

概述：使个人能够拥有自己的信息并从销售数据中获利的平台。

示例：Meeco、digi.me、CitizenMe


隐私助理

概述：帮助用户了解和管理对其私人数据的访问的工具。

示例：MySudo，我被 Pwned，Jumbo


合规与管理

同意管理

概述：用于通知用户有关个人数据收集和收集明确同意的系统和流程。

示例：UserCentrics，Osano


数据隐私请求自动化

概述：支持个人数据请求和根据数据隐私法使用的流程和工具。

示例：Transcend、DataGrail、Metomic


隐私管理

概述：支持隐私立法和个人数据权利管理的流程、活动和工具。

示例：OneTrust 隐私管理、TrustArc、WireWheel


隐私设计

数据匿名化

概述：用于编辑和匿名数据以实现安全数据共享的工具。

示例：Privitar、Hazy、Statice


隐私开发者工具

概述：使开发人员更容易将隐私纳入软件并在构建和支持软件时遵守隐私法规的工具。

示例：Ethyca、Tanker、Dataswift


匿名通讯

概述：用于保护和匿名用户互联网流量以隐藏位置、使用和身份以防止网络监视或流量分析的工具和协议。

示例：Tor Project、Freenet、Invisible Internet Project (I2P)


数据库安全

概述：保护数据库免遭入侵的工具、控件和流程。

示例：Fortinet FortiGuard Database Security、IBM Guardium、Baffle


数据发现和分类

概述：扫描数据源以查找和分类结构化和非结构化数据的过程，重点关注敏感和/或受监管数据。

示例：BigID、ActiveNav、Tanium Reveal、Varonis 数据分类引擎


数据丢失/泄漏预防

概述：检测和防止敏感数据传输的系统。

示例：Code42、Forcepoint 数据丢失防护、McAfee 全面防护


电子发现

概述：用于调查和法律请求的电子信息的识别、收集和存储。

示例：相对论、Logicube、Nuix、Consilio


加密

概述：使用密钥将纯文本数据从可读形式转换为受保护形式。

示例：Boxcryptor、Post-Quantum、Virtru、ID Quantique


文件完整性保护

概述：监控操作系统、数据库和应用程序文件变化的解决方案。

示例：Tripwire 文件完整性管理器、Qualys 文件完整性监控


公钥基础设施

概述：为用户身份、设备身份和安全端到端通信建立和管理公钥加密的基础设施。

示例：Entrust、Keyfactor、Let's Encrypt、Venafi


权限管理

概述：帮助公司保护数字内容（视频、图像、文件等）免遭未经授权的分发和复制的软件。

示例：Vera、Seclore EDRM


安全协作

概述：通过加密通信渠道进行私人消息传递和信息共享的平台。

示例：Signal、Mattermost、Silent Circle


代币化

概述：用于将敏感数据转换为掩码值或没有意义值的随机字符串的过程和工具。

示例：Skyflow、StrongSalt、Evervault


专业的服务

咨询

精品店

概述：小型专业服务公司内的专业网络安全、隐私或风险咨询实践。

示例：Krebs Stamos Group、Mandiant、Praetorian


大的

概述：大型专业服务公司的网络安全、隐私和风险咨询实践。

示例：埃森哲、普华永道、德勤


管理服务

托管检测和响应 (MDR)

概述：高级网络安全功能和系统的外包管理和监控，包括威胁情报、威胁追踪和事件响应。

示例：eSentire、Arctic Wolf、Red Canary


托管安全服务提供商 (MSSP)

概述：基本网络安全功能和系统的外包管理和监控。

示例：Optiv、IBM、Verizon


外包

概述：特定网络安全功能的外部管理（通常是操作任务）。通常专注于降低成本。

示例：Wipro、TCS、Infosys


人才市场

众包

概述：特定网络安全服务的公共平台，例如漏洞赏金。

示例：HackerOne、BugCrowd


自由职业者咨询

概述：通过雇主为 1099 名工人提供短期网络安全工作或合同的平台。

示例：PwC Talent Exchange、EY GigNow、Accenture Contractor Exchange


安全操作

监控和操作

分析

概述：用于主动监控和分析安全数据的数据分析平台。

示例：Awake、Exabeam、Darktrace


应用程序性能监控 (APM)

概述：用于应用程序监控、跟踪、诊断和性能的软件。该域与具有一些常见网络安全功能的网络安全相邻。

示例：Datadog、New Relic、Sentry


数据管理

概述：从多个工具中提取、规范化和丰富安全数据的流程和工具。

示例：Monad


员工监控

概述：用于记录和衡量员工活动和生产力的监控工具。

示例：Controlio、TeraMind


网络性能监控

概述：用于可视化、监控、优化、故障排除和报告网络运行状况和可用性的平台。

示例：NetScout、SolarWinds 网络性能监视器


安全信息和事件管理 (SIEM)

概述：用于整合和关联日志数据以识别安全事件的工具。

示例：Sumo Logic、LogRhythm、Securonix、Rapid7 InsightIDR、Elastic SIEM


用户行为分析 (UBA)/用户实体行为分析 (UEBA)

概述：根据用户行为模式检测威胁的流程和工具。

示例：Gurucul、LogPoint、Exabeam 行为分析


漏洞评估与管理

赛博靶场

概述：动手网络安全攻击培训和实践的平台。

示例：Hack the Box、Cyberbit Cyber Range


渗透测试

概述：故意攻击应用程序、网络和基础设施，以识别可利用的漏洞。

示例：Wireshark、Metasploit、NMAP


社会工程学

概述：操纵人们暴露机密信息、允许未经授权的访问和其他人类可利用的漏洞的技术。

示例：Cofense，Proofpoint


漏洞管理与测试

概述：用于发现、分类、确定优先级和修复软件和基础架构漏洞的流程和工具。

示例：Qualys、Tenable、ThreadFix


更换管理层

资产管理

概述：用于识别和管理 IT 资产及其潜在安全风险的流程和工具。

示例：Jamf、Axonius、Armis


配置管理数据库 (CMDB)

概述：用于存储有关硬件和软件资产的信息的数据库。CMDB 主要用于 IT 服务管理；但是，大部分数据适用于安全操作。

示例：ServiceNow CMDB、Solarwinds CMDB、JupiterOne


补丁和系统管理

概述：通过补丁程序使应用程序和基础架构保持最新状态以解决错误和漏洞的流程和工具。

示例：Tanium 补丁、Solarwinds 补丁管理器、ManageEngine 补丁管理器


事件管理和响应

欺骗

概述：通过模仿真实资产作为陷阱和诱饵来欺骗和抓住攻击者的工具和技术。

例如（S）：加纳利，幻影攻击检测系统，TrapX


扩展检测和响应 (XDR)

概述：聚合和分析数据以改进威胁检测和事件响应的系统。

示例：Anomali、Cynet、FireEye XDR


取证

概述：跟踪和分析网络、移动设备、计算机和存储设备上的数据以进行网络犯罪调查。

示例：AccessData、The Sleuth Kit、EnCase


安全编排、自动化和响应 (SOAR)

概述：从各种安全运营来源收集数据的系统和流程，以定义事件响应活动和工作流程、确定其优先级和自动化。

实施例（一个或多个）：FireEye的螺旋，Cyware，泳道，尖齿


威胁情报

概述：用于了解组织当前或未来威胁的情报收集。

示例：Recorded Future、RiskIQ、ZeroFox、Digital Shadows
