CISA、联邦调查局 (FBI)、澳大利亚网络安全中心 (ACSC) 和英国国家网络安全中心 (NCSC) 发布了一份联合网络安全咨询报告， 强调高级持续威胁 (APT) 正在进行的恶意网络活动FBI、CISA、ACSC 和 NCSC 评估的组织与伊朗政府有关。FBI 和 CISA 已经观察到这种由伊朗政府资助的 APT 利用 Fortinet 和 Microsoft Exchange ProxyShell 漏洞在后续操作（包括部署勒索软件）之前获得对系统的初始访问权限。

联合网络安全咨询 AA21-321A 提供了观察到的策略和技术，以及 FBI、CISA、ACSC 和 NCSC 评估的可能与伊朗政府资助的 APT 活动有关的妥协指标。FBI、CISA、ACSC 和 NCSC 敦促关键基础设施组织应用咨询中列出的建议，以降低来自伊朗政府资助的网络行为者的危害风险。 


联合网络安全咨询警报 (AA21-321A)：伊朗政府资助的 APT 网络参与者利用 Microsoft Exchange 和 Fortinet 漏洞推进恶意活动

原始发布日期：2021 年 11 月 17 日 | 最后修订：2021 年 11 月 19 日


概括

注意： 本公告使用 MITRE Adversarial Tactics, Techniques, and Common Knowledge (ATT&CK®) 框架，版本 10。请参阅ATT&CK for Enterprise了解所有参考的威胁行为者策略和技术。


该联合网络安全咨询是联邦调查局 (FBI)、网络安全和基础设施安全局 (CISA)、澳大利亚网络安全中心 (ACSC) 和英国国家网络安全中心 (NCSC) 之间分析工作的结果) 以突出 FBI、CISA、ACSC 和 NCSC 评估的与伊朗政府有关的高级持续威胁 (APT) 组织正在进行的恶意网络活动。FBI 和 CISA 观察到，这个由伊朗政府资助的 APT 组织至少自 2021 年 3 月起利用 Fortinet 漏洞，至少自 2021 年 10 月起利用 Microsoft Exchange ProxyShell 漏洞，以便在后续操作（包括部署勒索软件）之前获得对系统的初始访问权限。

伊朗政府资助的 APT 参与者正在积极针对美国多个关键基础设施部门的广泛受害者，包括运输部门、医疗保健和公共卫生部门以及澳大利亚组织。FBI、CISA、ACSC 和 NCSC 评估参与者专注于利用已知漏洞而不是针对特定部门。这些伊朗政府资助的 APT 参与者可以利用这种访问权限进行后续操作，例如数据泄露或加密、勒索软件和勒索。

该公告提供了观察到的策略和技术，以及 FBI、CISA、ACSC 和 NCSC 评估的可能与伊朗政府资助的 APT 活动有关的妥协指标 (IOC)。

FBI、CISA、ACSC 和 NCSC 敦促关键基础设施组织应用本公告的缓解部分中列出的建议，以减轻伊朗政府资助的网络行为者的危害风险。

有关 IOC 的可下载副本，请参阅AA21-321A.stix。

有关伊朗政府资助的恶意网络活动的更多信息，请参阅us-cert.cisa.gov/Iran。


技术细节

威胁行为者活动

至少自 2021 年 3 月以来，FBI 和 CISA 已经观察到伊朗政府资助的 APT 参与者利用 Microsoft Exchange 和 Fortinet 漏洞瞄准多个关键基础设施部门的广泛受害者，以促进恶意活动。观察到的活动包括以下内容。

  • 2021 年 3 月，FBI 和 CISA 观察到这些伊朗政府资助的 APT 参与者在端口 4443、8443 和 10443 上扫描 Fortinet FortiOS 漏洞CVE-2018-13379 的设备，并枚举 FortiOS 漏洞CVE-2020-12812和CVE- 2019-5591。伊朗政府资助的 APT 参与者很可能利用这些漏洞来访问易受攻击的网络。注意：有关此活动的先前 FBI 和 CISA 报告，请参阅联合网络安全咨询：APT 参与者利用漏洞获得未来攻击的初始访问权限。

  • 2021 年 5 月，这些伊朗政府资助的 APT 参与者利用 Fortigate 设备访问托管美国市政府域名的网络服务器。elie攻击者可能使用该用户名创建了一个帐户，以进一步启用恶意活动。注意：有关此活动的先前 FBI 报告，请参阅FBI FLASH：APT 攻击者利用 Fortinet 漏洞获得恶意活动的初始访问权限。

  • 2021 年 6 月，这些 APT 参与者利用 Fortigate 设备访问与一家专门从事儿童医疗保健的美国医院相关的环境控制网络。伊朗政府资助的 APT 参与者可能利用分配给 IP 地址的服务器91.214.124[.]143以及（162.55.137[.]20FBI 和 CISA 判断这与伊朗政府的网络活动有关）进一步启用针对医院网络的恶意活动。APT154.16.192[.]70攻击者从 IP 地址访问了医院的已知用户帐户，FBI 和 CISA 判断该地址与伊朗政府的攻击性网络活动有关。

  • 截至 2021 年 10 月，这些 APT 参与者已利用 Microsoft Exchange ProxyShell 漏洞CVE-2021-34473——在后续操作之前获得对系统的初始访问权限。

ACSC 认为这个 APT 小组也使用了澳大利亚的相同 Microsoft Exchange 漏洞（CVE-2021-34473）。

MITRE ATT&CK 战术与技术

FBI、CISA、ACSC 和 NCSC 评估以下与此活动相关的策略和技术。

资源开发 [ TA0042 ]

APT 攻击者使用以下恶意和合法工具 [ T1588.001、T1588.002 ] 来实施企业范围内的各种策略。

  • Mimikatz凭据盗窃[ TA0006 ]

  • 用于权限提升的WinPEAS [ TA0004 ]

  • SharpWMI（Windows 管理工具）

  • WinRAR 用于归档收集的数据 [ TA0009 , T1560.001 ]

  • 用于传输文件的 FileZilla [ TA0010 ]

初始访问 [ TA0001 ]

伊朗政府资助的 APT 参与者通过利用影响 Microsoft Exchange 服务器 (CVE-2021-34473) 和 Fortinet 设备（CVE-2018-13379、CVE-2020-12812 和 CVE-2019-5591）的漏洞获得了初始访问权限 [ T1190 ] .

执行 [ TA0002 ]

伊朗政府资助的 APT 参与者可能对任务调度程序 [ T1053.005 ]进行了修改。这些修改可能会显示为无法识别的计划任务或操作。具体而言，以下既定任务可能与此活动相关联：

  • SynchronizeTimeZone

  • GoogleChangeManagement

  • MicrosoftOutLookUpdater

  • MicrosoftOutLookUpdateSchedule

持久性 [ TA0003 ]

伊朗政府资助的 APT 参与者可能已经在域控制器、服务器、工作站和活动目录 [ T1136.001、T1136.002 ]上建立了新的用户帐户。其中一些帐户的创建看起来与网络上的其他现有帐户相似，因此特定帐户名称可能因组织而异。除了无法识别的用户帐户或伪装成现有帐户的帐户外，以下帐户用户名可能与此活动相关联：

  • Support

  • Help

  • elie

  • WADGUtilityAccount

渗出 [ TA0010 ]

FBI 和 CISA 观察到通过端口 443 进行的出站文件传输协议 (FTP) 传输。

影响 [ TA0040 ]

APT 参与者强制在主机网络上激活 BitLocker 以加密数据 [T1486]。相应的威胁笔记要么发送给受害者，要么作为 .txt 文件留在受害者网络上。赎金记录包括赎金要求和以下联系信息。 

  • sar_addr@protonmail[.]com

  • WeAreHere@secmail[.]pro

  • nosterrmann@mail[.]com

  • nosterrmann@protonmail[.]com 


检测

FBI、CISA、ACSC 和 NCSC 建议使用 Microsoft Exchange 服务器和 Fortinet 的组织调查其网络中的潜在可疑活动。 

  • 搜索 IOC。收集已知错误的 IOC 并在网络和主机工件中搜索它们。注：IOC 参见附录 A。

  • 调查暴露的 Microsoft Exchange 服务器（已打补丁和未打补丁）是否受到威胁。 

  • 调查远程桌面协议 (RDP)、防火墙和 Windows 远程管理 (WinRM) 配置的更改，这些更改可能允许攻击者保持持续访问。 

  • 查看域控制器、服务器、工作站和活动目录以查找新的或无法识别的用户帐户。

  • 查看无法识别的计划任务的任务计划程序。此外，手动查看操作系统定义或识别的计划任务中未识别的“操作”（例如，查看每个计划任务预期执行的步骤）。

  • 查看防病毒日志以了解它们被意外关闭的迹象。

  • 在意想不到的位置寻找 WinRAR 和 FileZilla。 

注意：有关发现恶意网络活动的其他方法，请参阅由 CISA 与澳大利亚、加拿大、新西兰和英国的网络安全机构共同撰写的联合咨询技术方法来发现和修复恶意活动。 


缓解措施

FBI、CISA、ACSC 和 NCSC 敦促网络防御者应用以下缓解措施来降低被这种威胁破坏的风险。

补丁和更新系统

  • 更新/补丁发布后立即安装更新/补丁操作系统、软件和固件。 

  • 立即修补受此通报中确定的漏洞影响的软件：CVE-2021-34473、CVE-2018-13379、CVE-2020-12812 和 CVE-2019-5591。

评估和更新阻止名单和许可名单

  • 定期评估和更新阻止名单和许可名单。

  • 如果您的组织未使用 FortiOS，请将 FortiOS 使用的关键工件文件添加到您组织的执行阻止列表中。应防止任何安装或运行该程序及其相关文件的尝试。

实施和强制执行备份和恢复政策和程序

  • 定期备份数据，气隙和密码保护离线备份副本。

  • 确保关键数据的副本无法从数据所在的系统中进行修改或删除。 

  • 实施恢复计划以在物理上独立、分段、安全的位置（例如，硬盘驱动器、存储设备、云）维护和保留敏感或专有数据和服务器的多个副本。 

实施网络分段

  • 实施网络分段以限制对手的横向移动。 

保护用户帐户

  • 审核具有管理权限的用户帐户，并根据最小权限和职责分离的原则配置访问控制。 

  • 需要管理员凭据才能安装软件。 

实施多重身份验证

  • 尽可能使用多因素身份验证，特别是对于网络邮件、虚拟专用网络 (VPN) 和访问关键系统的帐户。 

使用强密码

  • 要求所有使用密码登录的帐户都拥有强大的、唯一的密码。

保护和监控 RDP 和其他有潜在风险的服务

  • 如果您使用 RDP，请限制它以限制通过内部网络访问资源。

  • 禁用未使用的远程访问/RDP 端口。

  • 监控远程访问/RDP 日志。 

使用防病毒程序

  • 在所有主机上安装并定期更新防病毒和反恶意软件。 

安全远程访问

  • 只使用安全网络，避免使用公共 Wi-Fi 网络。 

  • 考虑安装和使用 VPN 进行远程访问。

降低网络钓鱼风险

  • 考虑为从组织外部收到的电子邮件添加电子邮件横幅。

  • 禁用收到的电子邮件中的超链接
