# 为什么访问控制已成为打击网络犯罪的重要战线

*Hiscox 的一份报告发现，自 2019 年以来，企业在网络安全方面的支出翻了一番。2N TELEKOMUNIKACE 首席产品官 Tomáš Vystavěl 调查了为什么访问控制已成为打击网络犯罪的重要资产。 *

今年早些时候，Hiscox 发布了其《2021 年网络就绪报告》。该报告基于对美国、英国、西班牙、荷兰、德国、法国、比利时和爱尔兰的 6,000 多家公司的调查。最引人注目的发现之一是，在过去两年中，每家企业在网络安全方面的支出增加了一倍多。

然而，这种增加的支出是对日益增长的威胁水平的理性回应。根据 Hiscox 的研究，与 2019 年相比，2020 年更多的公司成为犯罪分子的目标，去年遭受攻击的企业中有 28% 成为了五次以上的目标。近一半的受访者表示，他们认为自大流行开始以来，他们的组织变得更容易受到网络攻击，在拥有 250 多名员工的企业中，这一比例上升到 59%。在这些目标企业中，大约六分之一的企业表示，网络安全事件威胁到了其业务的生存能力。调查还发现，大约六分之一的网络犯罪分子曾要求付款，其中一半以上已付款。

Hiscox 继续评估公司在六个不同能力领域的成熟度，这些领域包括安装、运行、管理和治理有效安全系统所需的要素。这六个领域之一是“身份和访问管理”，在所有接受调查的公司中，它排在榜单的倒数第二位。

## 为什么访问控制是网络安全计划的重要组成部分？

事实是，在网络安全方面，访问控制并不总是优先考虑，许多公司仍在这一领域“迎头赶上”，但这种情况正在迅速改变。现在，越来越多的公司意识到，如果访问控制系统受到损害，建筑物的日常运营——以及因此，其居民——可能面临风险。

这些公司正在优先采取措施来应对最紧迫的威胁——尤其是五个：

1.  中号的-在中间人攻击（MITM） -的攻击，黑客连接到网络和窃听终端设备之间的通信。这样，开门密码和设备登录密码就可以被破解。
    
2.  密码/字典攻击——黑客试图猜测进入设备的密码的攻击（通常使用密码生成器并尝试不同的选项）。
    
3.  未经授权连接到 LAN 网络\- 对讲机或读卡器可以安装在房屋外面，存在有人会破坏对讲机并使用 UTP 电缆连接到 LAN 网络的潜在风险。
    
4.  对讲机摄像头的未经授权查看——经常发生 IP 摄像头安装有默认密码，基本上任何人都可以连接到它并观看正在发生的事情。
    
5.  针对移动设备的恶意软件攻击——基于移动凭据的访问控制系统越来越受欢迎，主要是因为它们提供了便利。然而，它们也一直是黑客的目标，他们试图通过凭证盗窃、监视和恶意广告来攻击智能手机。

这些威胁不仅限于网络领域。如果犯罪分子能够潜入建筑物，破坏访问控制也可能构成物理威胁。即使没有破坏物理安全，网络攻击也可能造成数百万的监管处罚、破坏核心业务功能并威胁企业声誉。

## 保护访问控制系统免受网络攻击：什么是基本的交战规则？

很明显，威胁级别正在增加，公司应该采取一些基本的“良好实践”措施来保护其 IT 系统的各个方面。例如，使用强而复杂的密码，定期对 IT 基础设施进行安全审计以识别和消除可能的漏洞，并培训负责保护建筑物 IT 基础设施的安全团队了解最常见的威胁以及如何解决这些威胁。

最重要的是，特别关注访问控制，公司可以遵循一些额外的规则，这些规则可以产生巨大的差异：

*   遵循经过验证的安全控制框架。其中两个最受尊重的是 ISO 27001 和 SOC 2。它们指导公司创建安全的系统和流程。
    
*   确保访问控制系统包括使用加密和多步身份验证。这可以保护设备、控制器和移动设备之间的通信，并确保没有用于“维护目的”的后门。
    
*   创建一个独立的网络，专门用于处理敏感信息的设备，并确保它们之间的通信是加密的。将这些设备放置在一个独立的虚拟局域网 (VLAN) 中，并确保已安装设备或软件的制造商默认使用 HTTPS、TLS、SIPS 或 SRTP 等实施协议。
    
*   创建具有不同权限的不同帐户。这样做可确保用户只能对其特定任务进行更改，而管理员将获得更大的权限来管理建筑物和所有关联的帐户。
    
*   定期更新软件。在设备上安装最新固件版本对于降低网络安全风险非常重要。每个新版本都通过实施最新的安全补丁来修复在软件上发现的错误。
    
*   培训您的员工避免社会工程威胁。人为因素是任何系统中最脆弱的部分，攻击者可以诱使人们犯下安全错误或泄露敏感信息。因此，有必要定期培训员工并投资于他们的网络安全意识。
    

这些规则并不复杂，遵循它们也不需要很昂贵。事实上，随着对抗网络攻击和数据泄露的战争愈演愈烈，哪家公司能够忽视它们？
