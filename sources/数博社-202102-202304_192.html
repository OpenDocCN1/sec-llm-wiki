网络攻击者发起攻击的七大动机

对许多组织而言，实施基于风险的安全计划和针对自适应网络威胁行为者的适当控制可能是一项复杂的任务。了解驱动网络攻击的基本动机后，组织可以更好地识别自己的资产可能面临风险的位置，从而更有效地解决已识别的风险。本文将讨论 Rational Actor Model (RAM) 以及网络攻击者的七个主要内在和外在动机。

威慑和安全理论从根本上依赖于人是理性行为者的前提。RAM 基于理性选择理论，该理论假设人类是理性的，会采取符合自己最大利益的行动。一个人做出的每个决定都基于内部价值计算，该计算会权衡行动的成本与收益。通过改变决策的成本效益比，可以相应地改变决策，从而改变行为。 

在这一点上应该指出，“理性”依赖于个人对成本和收益的计算。在谈到理性行动者模型或威慑时，至关重要的是要理解“理性”行为是促进个人利益的行为，因此，行为可能因人、群体和情况而异。因此，不可能通过威慑来预防所有犯罪。有些人会简单地权衡犯罪的利弊，并根据他们个人的内在价值计算确定“值得冒险”。

虽然一些犯罪学家反对 RAM 支持其他模型，但据传闻，很难对模型的价值进行争论。有争议的是，即使是恐怖分子也使用 RAM 模型，并经常选择“成功”有相当好的确定性的目标。这再次呼应了风险管理模型和理性决策模型。这个概念在所有行为领域都重复出现，包括网络犯罪。

了解 RAM 对探索人类动机很重要。简而言之，驱动人类行为的动机有两种。内在动机和外在动机。内在动机是由内部奖励驱动的动机。它包括令个人满意的动机。吃东西、爬山和看一部很棒的电影都是内在动机行为的例子。 相比之下，外在动机是那些导致外部奖励的行为。为工资工作、玩彩票和犯罪都可能是外在动机行为的例子。毫无疑问，在这一点上，读者已经确定行动可以是内在和外在动机的。 

通过对理性行为者和动机理论的理解，现在可以讨论网络攻击的动机。应该注意的是，“犯罪”一词并未使用，因为它是一个法律术语，攻击可能会也可能不会被视为犯罪。因此，使用了更通用的“攻击”术语。一般来说，尝试网络攻击的人有六种不同的动机。这被创造为 Mark Heptad（是的，在这位作者和创造者之后）。六七动机是：

  1. 金融（外在） -的个人身份信息（PII）盗窃，  然后将其货币化是网络攻击的经济动机的一个典型例子。这种动机主要由有组织的犯罪集团实施，在针对零售商和医疗保健提供者的网络攻击中占很大比例。 

  2. 社会/政治“黑客行动主义”（主要是内在的）——社会或意识形态问题为一些人攻击组织发表声明创造了动机。美国政府系统遭到黑客攻击和污损，攻击者在其中发布贬低资本主义或民主言论的信息，这将是黑客行动主义的一个典型例子。

  3. 间谍活动（外在的） ——一般来说，我们认为网络间谍活动是盗窃知识产权，但也可以侧重于盗窃与收购、营销计划和其他类型数据相关的机密信息。民族国家行为者被认为是最大的网络间谍攻击者群体，但也有公司对竞争对手进行网络间谍活动的例子。

  4. 报复（内在）-心怀不满的员工或前员工是那些通常承担大部分基于报复的网络攻击的人。这条新闻充斥着心怀不满的前雇员攻击前雇员的故事。

  5. 滋扰/破坏（内在的）-有些人的内在动机只是为了制造混乱和破坏而仅仅出于其他原因攻击组织或个人。这是不幸的，但却是事实。一个很好的例子是臭名昭著的银行劫匪“狡猾的”威利萨顿。有一个关于他为什么抢劫银行的虚构故事。当被问到时，据报道，他说他抢劫银行是因为“钱就在那里”。事实上，他说他“只是喜欢抢劫银行”。金钱不是一个激励因素。

  6. 战争/防御（外在） -在21日世纪，它是不负责任的忽视的事实是民族国家，甚至“爱国者黑客”在任何启动或防御对手的发挥。中断供应链、破坏离心机和其他攻击可归类为战争/防御驱动。2010 年发现的用于摧毁伊朗离心机的震网病毒只是这种动机的一个相关例子。

  7. 便利化（外在的）——网络攻击者经常使用代理和其他系统来攻击他们的最终目标。出于这个原因，重要的是要注意一些组织和系统可能只是方便的目标，可以启用和促进攻击者的行动。考虑僵尸网络。系统受到损害，使它们能够攻击其他系统。僵尸网络内系统的入侵只是用来促进另一次攻击。另一个例子是在暗网上销售非法产品的人。他们会经常破坏系统，然后将隐藏服务放置在该特定系统上。这为他们的行为提供了一定程度的抽象，并在涉及执法的情况下提供了合理的否认。

维恩图中最准确地描述了动机，因为它们并不相互排斥。攻击者可能有多个针对特定组织的动机。此外，不同的攻击者可能有不同的动机。考虑一家大型建筑公司的例子。可以预见的是，地球解放阵线 (ELF) 等组织可能会尝试发起攻击以发表政治或社会声明，而敌对民族国家可能会攻击该组织以窃取知识产权。 

评估其安全状况并开发基于风险的安全框架的组织可以很好地考虑各种潜在的与动机相关的威胁。美国国土安全部很好地阐明了安全、风险和决策之间的实际关系，因为它被描述为一种制定安全决策的方法。这在美国国家标准与技术研究院 NIST 800-37 风险管理框架中得到了进一步的改进，它说：

“……对于作战计划的制定，必须对威胁、脆弱性和影响的组合进行评估，以确定重要趋势并决定应在哪些方面努力消除或降低威胁能力；消除或减少漏洞；并评估、协调和消除所有网络空间操作的冲突……”（NIST，2010 年，第 3 页）。（强调）

与高管交谈并听到常见的一句话“我不相信我们是目标。我们没有任何人想偷的东西。” 这种立场忽略了人们受不同因素驱动的事实。最近，在为一家大型工程机械制造商举办的活动上发言时，我提出了一个问题：“为什么有人要攻击你的公司？” 一位非常精明的参与者简洁地回答“因为我们摧毁了地球”。她是对的。虽然有人想要攻击那家公司的原因可能有很多，但如果不考虑这样一个事实，即有人可能会以消极的眼光看待“毁灭地球”并希望通过攻击他们来发表声明，那就太天真了。

您可以提出一些问题，以确定哪些因素可能会使您的组织成为网络攻击的目标。

  1. 您的组织是否拥有任何 PII 或“受监管数据”，例如支付卡数据、医疗保健数据、社会安全号码或银行账户？（出于经济动机的攻击）

  2. 您的组织是否有一个全球或大型品牌与可能被视为冒犯某些群体的事物相关联？例如，您的组织是否支持政府组织？您的品牌是否会被某些人认为与“美国资本主义”或“帝国主义”有关？您的组织是否生产可能煽动极端分子的产品或服务？一个例子是动物试验或采矿。（黑客主义）

  3. 您的组织是否拥有专利和商业秘密？即使是专门的流程也可能存在风险。（间谍）

  4. 您的组织是否支持美国军方？一个例子是供应链管理或制造可以被军方使用的零件？（战争/防御）

  5. Nuisance 和 Revenge 是通常为了简单地造成伤害的内在令人满意的价值而采取的行为。所有公司都受制于这些。

在考虑组织面临的威胁和相关风险时，还必须考虑可能驱使攻击者的动机。通过这样做，组织可以更有效地应用适用的控制措施，因为攻击动机通常会推动攻击方法。例如，考虑民族国家网络间谍活动和知识产权盗窃。许多报告表明，此类攻击的主要方法是高级持续威胁 (APT)。那些想要窃取支付卡数据的人通常会在销售点系统 (POS) 上安装恶意软件，目的是窃取磁条数据。进行风险分析的公司在评估风险时最好考虑这些动机。
