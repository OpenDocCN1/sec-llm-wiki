# 为什么 XDR 是 2021 年的顶级安全计划

作者：Doron Davidson，SecBI BD 创始人兼副总裁。

在决定 2021 年进行哪些网络安全投资之前，企业必须优先考虑。我们的安全覆盖范围最大的差距是什么？我们今年的预算目标应该在哪里？哪种解决方案最能改善我们的安全状况？

根据 Gartner 的说法，如果您有能力在 2021 年仅承担一项重大安全项目，那么扩展检测和响应 (XDR) 应该是您的首选。原因有很多，我们将在本文后面讨论。

首先，SecBI 想了解企业对 XDR 的看法，以及他们是否计划采纳 Gartner 关于实施的建议。我们在 C 级和 SOC 中的企业安全专业人员中进行了一项调查，以评估他们在 XDR 上的立场。各种角色对我们的调查做出了回应，我们认为这准确反映了企业中 XDR 利益相关者的多样性。由于 XDR 是一种统一多种安全产品并跨越大量运营孤岛的解决方案，因此 IT 和网络安全组织内的许多不同角色都会感受到它的影响（即收益）。

显然，XDR 的有益效果是大多数企业想要和需要的。正如我们在SecBI XDR 调查报告中指出的那样，近 80% 的安全专业人员表示 XDR 应该是他们组织的首要网络安全优先事项。更重要的是，他们正在这样做，因为 75% 的组织计划在 2021 年或 2022 年实施 XDR。这是对 XDR 的巨大信任投票。

我们相信 XDR 在过去几个月中获得的巨大吸引力是因为我们相信 XDR 是一个能够真正兑现将各种工具集成到统一威胁检测和响应操作中的承诺的平台，而***不是***另一种工具为已经捉襟见肘的团队创建更多警报。XDR 是一种解决方案，可以自动化和集成他们已经部署的工具，因此公司可以全面加强他们的安全状况。

当我们询问企业他们打算如何使用 XDR 以及他们期望获得什么时，我们发现 59% 的安全专业人员希望在他们的基本 KPI——MTTD（平均检测时间）和 MTTR 上实现真正和可衡量的改进（平均响应时间）。更重要的是，45% 的人希望在无需聘请额外的网络安全专家的情况下获得更好的安全性能，而这些专家既昂贵又难以获得。

这种事半功倍的需求似乎是由安全预算驱动的。我们的大多数受访者表示，他们组织的安全预算保持不变，近四分之一的受访者预测预算会减少。停滞不前的预算似乎也表明，让更多人参与孤立的安全运营并不会提高 MTTD 和 MTTR。此外，专家安全资源的成本和稀缺性意味着基于人员的响应无法随着警报的步伐而扩展。

![](../Images/0d56a8ba5e09c9059b80ddf4b23242e5.png)

企业拥有大量的安全工具。他们缺乏的是集成和智能自动化，因此安全团队可以查看和了解他们面临的复杂的多向量威胁，并快速有效地做出响应。

毫不奇怪，我们的调查发现只有 6% 的企业依赖单一供应商进行安全运营。绝大多数 (94%) 在多年来构建安全基础设施时部署了来自多个供应商的一流工具。为了最大限度地从 XDR 中获益并最小化风险，94% 的人采用与供应商无关的 XDR 平台是有意义的，该平台能够集成来自多个供应商的安全控制的安全数据并自动响应。在这方面，我们相信与供应商无关的 XDR 的价值可以轻松传达给管理层。公司对现有安全工具的投资不仅会得到保护，而且这些工具的性能和功效也会得到加强。

XDR 是唯一一项能够融合和关联网络安全库中所有单点产品的投资，从而使威胁检测和响应操作能够集成、自动化且更加有效。

## 获得多供应商安全性？获取通用 XDR。

XDR 有两种主要方法。Palo Alto 等供应商支持一种方法，他们将自己的安全产品组合与**专有**XDR 平台集成。另一种方法是由**通用**XDR 供应商（如 SecBI）推广的，其敏捷的 XDR 平台提供了与供应商无关的覆盖，以实现企业已经部署的端点、网络和云安全工具的无缝集成和互操作性。

专有 XDR 最明显的缺点是供应商锁定，这需要整个网络安全架构依赖于一个供应商。

使用 Universal XDR，组织拥有多少不同的安全系统和工具并不重要。无需更换旧工具或与单一供应商保持一致。相反。通用 XDR 有助于从组织现有的安全架构中提取更多价值，并利用它来提供更好、更广泛的保护。这对于在安全基础设施上投资数百万美元的企业来说至关重要。
