什么是网络攻击？

网络攻击是企图未经授权访问组织的网络，目的是窃取数据或执行其他恶意活动。网络攻击主要有两种类型：

  • 被动：攻击者可以访问网络并可以监控或窃取敏感信息，但不对数据进行任何更改，使其保持完整。

  • 主动：攻击者不仅获得未经授权的访问，而且还修改数据，删除、加密或以其他方式损害数据。

我们将网络攻击与其他几种类型的攻击区分开来：

  • 端点攻击——未经授权访问用户设备、服务器或其他端点，通常通过用恶意软件感染它们来破坏它们。

  • 恶意软件攻击——用恶意软件感染 IT 资源，允许攻击者破坏系统、窃取数据并造成破坏。这些还包括勒索软件攻击。

  • 漏洞、漏洞利用和攻击——利用组织中使用的软件中的漏洞，获得未经授权的访问、破坏或破坏系统。

  • 高级持续威胁——这些是复杂的多层威胁，包括网络攻击和其他攻击类型。

在网络攻击中，攻击者专注于渗透公司网络外围并获得对内部系统的访问权限。通常，一旦进入内部，攻击者就会结合其他类型的攻击，例如破坏端点、传播恶意软件或利用网络系统中的漏洞。

常见的网络攻击类型有哪些？

以下是攻击者可以用来渗透您的网络的常见威胁媒介。

1. 未授权访问
未授权访问是指攻击者未经许可访问网络。未经授权的访问攻击的原因包括弱密码、缺乏针对社会工程的保护、先前被盗用的帐户和内部威胁。

2. 分布式拒绝服务 (DDoS) 攻击 攻击
者构建僵尸网络、大量受感染设备，并使用它们在您的网络或服务器上引导虚假流量。DDoS 可能发生在网络级别，例如通过发送大量 SYN/ACC 数据包，这可能会使服务器不堪重负，或者在应用程序级别，例如通过执行复杂的 SQL 查询使数据库瘫痪。

3. 中间人攻击
中间人攻击涉及攻击者拦截您的网络与外部站点之间或您的网络内的流量。如果通信协议不安全，或者攻击者找到了规避安全的方法，他们就可以窃取正在传输的数据、获取用户凭据并劫持他们的会话。

4. 代码和 SQL 注入攻击
许多网站接受用户输入，但未能验证和清理这些输入。然后攻击者可以填写表格或进行 API 调用，传递恶意代码而不是预期的数据值。该代码在服务器上执行并允许攻击者破坏它。

5. 提权
一旦攻击者侵入您的网络，他们就可以使用提权来扩大他们的影响范围。横向提权涉及攻击者获得对额外的相邻系统的访问权限，而纵向提权意味着攻击者为相同的系统获得更高级别的权限。

6. 内部威胁
网络特别容易受到恶意内部人员的攻击，他们已经拥有对组织系统的特权访问权限。内部威胁可能难以检测和防范，因为内部人员不需要渗透网络来造成伤害。用户甚至行为分析 (UEBA) 等新技术可以帮助识别内部用户的可疑或异常行为，从而有助于识别内部攻击。

网络保护最佳实践

隔离您的网络
避免网络安全威胁的一个基本部分是根据安全要求将网络划分为区域。这可以使用同一网络内的子网来完成，也可以通过创建虚拟局域网 (VLAN) 来完成，每个虚拟局域网的行为就像一个完整的独立网络。分段将攻击的潜在影响限制在一个区域，并要求攻击者采取特殊措施来渗透并访问其他网络区域。

规范通过代理服务器
访问 Internet 不允许网络用户未经检查就访问 Internet。通过透明代理传递所有请求，并使用它来控制和监视用户行为。确保出站连接实际上是由人执行的，而不是机器人或其他自动化机制。白名单域以确保企业用户只能访问您明确批准的网站。

正确放置安全设备
在网络区域的每个交界处放置防火墙，而不仅仅是在网络边缘。如果您无法在任何地方部署成熟的防火墙，请使用交换机和路由器的内置防火墙功能。在网络边缘部署抗 DDoS 设备或云服务。仔细考虑将负载平衡器等战略设备放置在何处——如果它们位于非军事区 (DMZ) 之外，它们将不会受到您的网络安全设备的保护。

使用网络地址转换
网络地址转换 (NAT) 可让您将内部 IP 地址转换为可在公共网络上访问的地址。您可以使用它使用单个 IP 地址将多台计算机连接到 Internet。这提供了额外的安全层，因为任何入站或出站流量都必须通过 NAT 设备，而且 IP 地址较少，这使得攻击者难以了解他们连接到的主机。

监控网络流量
确保您完全了解传入、传出和内部网络流量，并能够自动检测威胁并了解其上下文和影响。结合来自不同安全工具的数据，可以清楚地了解网络上正在发生的事情，同时认识到许多攻击跨越多个 IT 系统、用户帐户和威胁媒介。
