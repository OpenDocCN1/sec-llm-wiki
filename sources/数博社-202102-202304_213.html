什么是横向运动？

横向移动是攻击者用来系统地横穿网络以访问或损坏有价值的资产或数据的一种方法。

攻击者使用工具和方法来获取访问权限和特权，这让他们可以在网络中的应用程序和设备之间横向移动，以隔离目标、映射系统并最终到达高价值目标。

这个怎么运作

横向移动往往发生在端点或服务器的初始妥协之后。这种攻击方法需要额外泄露用户帐户凭据。使用这些帐户凭据，攻击者试图未经授权访问其他节点。

当攻击者收集有关环境的信息时，他们会同时尝试窃取凭据、利用错误配置或隔离软件漏洞，以便深入挖掘网络。然后攻击者使用横向移动来控制受感染网络中的关键点。这些额外的位置帮助攻击者保持持久性，即使安全团队在受感染的机器上检测到它们。

横向移动安全挑战

研究表明，攻击者在横向移动期间花费了80% 的攻击时间。虽然最初的妥协发生得相对较快，但从被入侵的节点转向最终目标是一个更长的过程。攻击者大部分时间都在从最初的违规行为过渡到最终目标。

尽管在网络中，在最初的入侵期间，攻击者还没有执行他们首先渗透目标环境的有害行为。如果您可以在此阶段识别它们，您可能会结束攻击。因此，识别横向运动可能非常有效。

但是，监控内部网络具有挑战性。例如，组织已经尝试使用日志分析、机器学习、SIEM 和基于异常的检测。然而，由于数据量庞大，即使是最具创新性的分析解决方案也会产生误报。因此，许多安全团队无法调查大部分警报。

横向移动和高级持续威胁活动

一个高级长期威胁（APT）是有针对性的和延长的网络攻击，其中攻击者访问没有被发现在延长的时间长度的网络和停留。APT 攻击的目标通常是窃取数据或破坏目标环境。

APT攻击的结果包括：

  • 泄露的敏感数据或信息，包括员工或用户信息

  • 知识产权盗窃，包括专利或商业秘密

  • 对关键组织基础设施的破坏，包括数据库删除

  • 破坏关键基础设施的物理操作

APT 攻击中使用的横向移动盗窃技术

在 APT 攻击中，攻击者首先收集目标组织的数据，包括其组织结构和网络环境。然后将数据用于社会工程计划以进入网络，通常是通过破坏端点。

一旦攻击者在目标环境中的端点上站稳脚跟，他们就会开始收集有关其他计算机和用户帐户的信息，并尝试从端点的内存或网络流量中获取用户帐户凭据。这些凭据使他们能够访问环境中的其他端点或服务器。

内部侦察

攻击者收集信息，例如操作系统、网络层次结构和服务器中使用的资源，以映射环境并了解敏感数据的存储位置。

攻击者可以使用一些操作系统实用程序进行内部侦察：

  • Netstat — 显示机器当前的网络连接。用于查看更多关键资产或了解它们所链接的网络。

  • IPConfig/IFConfig — 提供对位置信息和网络配置的访问

  • ARP 缓存— 向物理地址提供 IP 地址的信息。用于针对单个机器或用于逃避技术。

  • 本地路由表— 显示主机的当前路由和通信路径。

  • PowerShell — Windows 脚本和命令行工具。

渗透其他计算机

攻击者使用窃取的凭据远程访问桌面。IT 支持人员通常以这种方式访问桌面，因此远程访问通常与持续攻击无关。此外，攻击者还可以访问域凭据以登录服务器、网络系统和交换机。

攻击者使用远程控制工具以网络中的其他桌面为目标，并执行诸如调度任务、执行程序和控制系统上的数据收集等步骤。

攻击者使用内置系统或 IT 支持工具，例如：

  • 远程桌面协议（RDP、PsExec、AT、VBScript 和包括 Metasploit 在内的开源工具。

  • PowerShell 和 Windows Management Instrumentation (WMI) 是攻击者使用的一些较新的技术。

凭据盗窃技术

一旦进入网络，攻击者就会寻求转移到新的领域并扩大他们的控制范围。攻击者挑出他们想要访问的其他“领土”，然后努力获取登录凭据。

要访问这些领土，攻击者可以使用以下技术：

  • APR 欺骗——攻击者可以通过生成无根据的虚假 APR 回复和请求，将自己置于交换网络中的通信中。这是典型的中间人攻击。

  • DNS 响应程序——攻击者利用被盗凭据访问域注册系统并修改信息。域名服务 (DNS) 是一种用于将域名定向到可访问信息的 IP 地址的技术。

  • SMB 中继——依赖于大多数公司使用的 NTLM 版本 2 身份验证。攻击者可以使用它来侦听网络以验证用户身份，而无需密码。因此，他们可以捕获流量、重定向流量并获得对系统的未经授权的访问。

横向运动技巧

工具可能会有所不同，但典型的策略是访问权限较低、受保护较低的资产，然后增加权限并开始在网络上寻找有价值的目标。

分布式组件对象模型

Windows DCOM 是透明的中间件，它通过远程过程调用扩大了远程系统上的组件对象模型 (COM) 的范围。

攻击者可以使用 DCOM 作为横向移动技术，并通过 Office 应用程序和其他具有易受攻击方法的 Windows 对象远程获取 shellcode 执行，或执行当前文档中的宏。

服务的利用

攻击者可以利用服务、内核、程序或操作系统软件中的编程错误来远程执行代码。

攻击者查看远程系统是否存在漏洞，这可以通过例如网络服务扫描来实现。攻击者寻找易受攻击的软件、可能指向漏洞的补丁的缺失，或可用于包含或隔离远程利用的安全软件。

管理员共享

管理共享是 PsExec 风格攻击的中心，它为攻击者提供了对系统根目录的访问权限。此外，每个分区的隐藏共享为攻击者提供了对远程系统硬盘的读写访问权限。

传递哈希

攻击者可以在不知道明文密码的情况下使用密码的加密散列来访问远程服务器。一旦他们获得了密码哈希，攻击者就会将它们转移到其他服务。他们不需要对哈希使用字典或蛮力攻击。

过票

使用 Kerberos 票证。攻击者不需要访问帐户的密码。攻击者获取有效 Kerberos 票证的有效帐户以进行凭证转储。

自动化工具使用的横向移动

横向运动的传统概念：人为因素

横向移动传统上是由人类攻击者采取的一系列手动措施。攻击者将手动获得对安全环境的访问权限，隔离最有价值或易受攻击的目标，进入其他受信任资产，扩大其访问范围，最终转向高价值目标。

今天横向运动

今天，横向移动已经自动化和商品化，因此通常由自动化机器人和工具部署。横向运动自动化的实例包括：

  • WannaCry——一种勒索软件攻击，发生在 2017 年 5 月。这次全球网络攻击利用了一个很大程度上未打补丁的 Windows 漏洞进行横向移动。WannaCry 是一种勒索软件蠕虫，它在多个计算机网络中传播。感染 Windows 计算机后，它会加密 PC 硬盘上的文件，使用户无法访问，然后迫使用户以比特币支付赎金以解密文件。WannaCry 恶意软件检查“终止开关”域名; 如果未识别，则勒索软件会加密计算机的数据。然后，它试图利用 Windows Server 消息块 (SMB) 漏洞，访问 Internet 上的计算机并横向访问当前网络上的计算机。

  • WannaMine——一种加密货币挖掘恶意软件，于 2017 年 4 月公开。它需要组织的 CPU 能力来挖掘门罗币。该恶意软件利用 Mimikatz 凭据收集器来获取合法凭据并在网络中横向移动。如果它无法获得凭据，它将利用 EternalBlue 漏洞。WannaMine 使用“生活在陆地上”的持久性策略，包括 Windows Management Instrumentation (WMI) 永久事件订阅。该恶意软件具有无文件特性，并利用 PowerShell 进行感染。它使用凭证收集器 Mimikatz 来访问合法凭证，使其传播和横向移动。如果失败，则蠕虫会试图通过 EternalBlue 攻击远程系统。

  • EternalBlue — 是由美国国家安全局 (NSA) 创建的漏洞。它于 2017 年 4 月 14 日被 Shadow Brokers 黑客组织泄露，例如用于帮助执行 2017 年 6 月 27 日的 2017 NotPetya 网络攻击。它利用了微软执行服务器消息块（SMB ） 协议。EternalBlue 既可用作横向移动的方法，也可用作初始折衷向量。

  • NotPetya——卡巴斯基实验室的研究人员声称，组织是一种新型勒索软件的目标，他们称之为 NotPetya。卡巴斯基数据显示，迄今为止已有 2,000 名用户受到攻击，乌克兰和俄罗斯的组织首当其冲。赛门铁克的研究人员认为，像 WannaCry 这样的勒索软件正在利用 EternalBlue Microsoft Windows 漏洞。
