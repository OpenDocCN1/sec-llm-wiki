# 谷歌支持对这些关键开源项目的安全审查

谷歌最近承诺向管理开源安全优先事项和帮助修复漏洞的团体提供 1 亿美元，现在它已经详细说明了它选择支持的八个项目。 

就在上个月，Linux 基金会 宣布将直接资助人们从事开源项目的安全性工作。它得到了谷歌、微软、开源安全基金会和 Linux 基金会公共卫生基金会的支持。当发现错误时，Linux 基金会会协调修复。  

基金会和同行正在通过开源技术改进基金 (OSTIF)进行的安全审计来寻找以前未知的问题。这些项目包括两个 Linux 内核安全审计。

现在，谷歌已经全力支持 OSTIF 的大部分即时审计计划。 

“谷歌的支持将允许 OSTIF 启动托管审计计划 (MAP)，该计划将深入的安全审查扩展到对开源生态系统至关重要的关键项目，”谷歌开源安全的安全通信经理 Kaylin Trychon 说团队。

谷歌资助的八个审计项目中最大的可能是 Git，这是由 Linux 内核创建者 Linus Torvalds 创建的“事实上的”版本控制软件 ，它构成了 GitHub 和 GitLab 等平台的基础。

  

OSTIF 指出：“Git 是 C 中第二重要的应用程序，也是所有平台中第十大最重要的应用程序，”他补充说，“毫无疑问，它是世界上最重要的开源软件之一。”   

其余的是用于 Web 开发的重要 JavaScript 和 Java 工具和框架，包括：Lodash，一个用于 Web 开发的现代 JavaScript 实用程序库，用于 Chrome 和其他浏览器；Laravel，一个PHP Web 应用程序框架；SLF4J 或 Java 的 Simple Logging Facade；用于 Java 的 Jackson-core JSON 和 Jackson-databind 包；和 Httpcomponents-core 和 Httpcomponents-client。 

“为这一轮选择的八个库、框架和应用程序将从安全改进中受益最大，并对依赖它们的开源生态系统产生最大影响，”Trychon 解释说。 

Google 的贡献将帮助 OSTIF 发现并修复关键开源项目中的错误。 

OSTIF 已经确定了总共25 个 MAP 项目的资助目标，其中包括谷歌迄今为止资助的八个项目。其他获得资金支持的项目包括开发人员使用的知名系统和工具，例如 Drupal 和 Joomla Web 内容管理系统、webpack、reprepro、cephs、Facebook 维护的 React Native、salt、Gatsby、Google 维护的 Angular、Red Hat Ansible 和 Google 的 Guava Java 框架。   

在美国总统乔拜登上个月与美国顶级科技公司会面后 ，谷歌宣布了一项 100 亿美元的承诺，用于改善扩大零信任计划、帮助保护软件供应链并增强开源安全性。
