# 蓝牙 BrakTooth 漏洞可能影响数十亿台设备

![](../Images/c207966df0f00b8ae4f32763900c75b0.png)

统称为 BrakTooth 的漏洞正在影响在来自十多个供应商的片上系统 (SoC) 电路上实现的蓝牙堆栈。

这一系列问题影响了从消费电子产品到工业设备的各种设备。相关风险范围从拒绝服务、设备死锁条件到任意代码执行。

### 受影响的产品种类繁多

新加坡科技设计大学的研究人员发布了有关 BrakTooth 的详细信息——商业蓝牙堆栈中的一个新的安全漏洞系列。

他们评估了来自包括英特尔、高通、德州仪器和赛普拉斯在内的十多家 SoC 供应商的 13 款蓝牙设备。

深入挖掘，研究人员发现超过 1,400 个产品列表受到 BrakTooth 的影响，该列表包括但不限于以下类型的设备：

*   智能手机
    
*   信息娱乐系统
    
*   笔记本电脑和台式机系统
    
*   音频设备（扬声器、耳机）
    
*   家庭娱乐系统
    
*   键盘
    
*   玩具
    
*   工业设备（例如可编程逻辑控制器 - PLC）
    

考虑到受影响的产品种类繁多，说 BrakTooth 影响数十亿台设备可能是准确的估计。 

该研究人员说，与BrakTooth组安全缺陷相关的风险由轰然设备固件，或者蓝牙通信不再可能，任意代码死锁状态从拒绝服务（DoS）的范围。

发起 BrakTooth 攻击的人需要 ESP32 开发套件、自定义链接管理器协议 (LMP) 固件和运行概念验证 (PoC) 工具的计算机。

![](../Images/c90102a190e022cd95e6ee2bf578b58a.png)

在 16 个 BrakTooth 漏洞中，其中一个被跟踪为 CVE-2021-28139 的风险高于其他漏洞，因为它允许任意代码执行。

它会影响带有 ESP32 SoC 电路的设备，该电路可在众多用于家庭或工业自动化的 IoT 设备中找到。

研究人员通过使用 LMP Feature Response Extended 数据包更改执行器的状态。

在英特尔的 AX200 SoC 和高通的 WCN3990 SoC 上运行的设备容易受到发送格式错误的数据包时触发的 DoS 条件的影响。

受影响的产品列表包括戴尔的笔记本电脑和台式机（Optiplex、Alienware）、Microsoft Surface 设备（Go 2、Pro 7、Book 3）和智能手机（例如 Pocophone F1、Oppo Reno 5G）。

研究人员在他们的发现发表之前通知了他们发现其产品易受 BrakTooh 攻击的所有供应商，但只有其中一些已被修补。

![](../Images/816fde9eb2a1fac2436b9cc394f7d27a.png)

Braktooth 集合中的漏洞针对 LMP 和基带层。目前，他们已经分配了 20 个标识符，还有一些待处理，请参考以下 16 个问题：

1.  功能页面执行（CVE-2021-28139 - 任意代码执行/死锁）
    
2.  截断的 SCO 链接请求（CVE-2021-34144 - 死锁）
    
3.  重复的 IOCAP（CVE-2021-28136 - 崩溃）
    
4.  功能响应泛滥（CVE-2021-28135、CVE-2021-28155、CVE-2021-31717 - 崩溃）
    
5.  LMP 自动速率溢出（CVE-2021-31609、CVE-2021-31612 - 崩溃）
    
6.  LMP 2-DH1 溢出（等待 CVE - 死锁）
    
7.  LMP DM1 溢出（CVE-2021-34150 - 死锁）
    
8.  接受截断的 LMP（CVE-2021-31613 - 崩溃）
    
9.  无效的安装完成（CVE-2021-31611 - 死锁）
    
10.  主机连接泛滥（CVE-2021-31785 - 死锁）
     
11.  相同主机连接（CVE-2021-31786 - 死锁）
     
12.  AU Rand Flooding（CVE-2021-31610、CVE-2021-34149、CVE-2021-34146、CVE-2021-34143 - 崩溃/死锁）
     
13.  最大插槽类型无效（CVE-2021-34145 - 崩溃）
     
14.  最大插槽长度溢出（CVE-2021-34148 - 崩溃）
     
15.  计时精度无效（CVE-2021-34147 和另外两个待处理的 CVE - 崩溃）
     
16.  分页扫描死锁（待定 CVE - 死锁）
