# CISA 警告不要在暴露于 Internet 的系统上使用单因素身份验证

美国网络安全和基础设施安全局 (CISA) 本周将单因素身份验证 (SFA) 添加到一个非常短的“高风险”网络安全实践列表中，这些实践可能导致威胁行为者将目标对准政府组织和私营部门实体。 

  

  

根据 CISA，当用于对支持关键基础设施运行的系统进行远程或管理访问时，SFA（一种仅要求用户提供用户名和密码的低安全性身份验证方法）是“危险的，并且显着增加了国家安全风险” . 

  

  

“使用单因素身份验证对支持关键基础设施和国家关键功能 (NCF) 运行的系统进行远程或管理访问是危险的，并且显着增加了对国家安全、国家经济安全以及国家公共健康和安全的风险，” CISA 解释道。

  

  

网络犯罪分子可以轻松保护对受单因素身份验证屏蔽的系统的访问，因为众所周知的事实是，密码很容易通过网络钓鱼、键盘记录、网络嗅探、社会工程、恶意软件、暴力破解等多种技术被窃取或猜测-force 攻击，或凭证倾销。

  

  

CISA 建议改用多因素身份验证 (MFA)，因为这种方法使威胁参与者更难甚至不可能成功发起攻击。除了作为不良做法的单因素身份验证之外，还有使用生命周期终止（或停止支持）的软件和默认（或已知）凭据，CISA 将其描述为“危险”。 

  

  

根据谷歌、纽约大学和加州大学圣地亚哥分校的联合研究，MFA 可以防止 100% 的自动化机器人、99% 的批量网络钓鱼攻击和大约 66% 的针对性攻击。 

  

  

“你的密码并不重要，但 MFA 很重要！根据我们的研究，如果你使用 MFA，你的帐户被盗用的可能性就会降低 99.9%，”微软身份安全总监 Alex Weinert 说。 

  

  

CISA 还开设了一个 GitHub 不良实践讨论页面，试图让 IT、专业人士和管理员提供反馈并分享他们在减轻网络攻击风险方面的专业知识。

  

  

此外，CISA 正在考虑在目录中添加一些其他做法，包括—— 

  

• 使用弱加密函数或密钥大小 

• 扁平网络拓扑

• IT 和 OT 网络的混合 

• 每个人都是管理员（缺乏最低权限） 

• 使用以前受损的系统而不进行消毒 

• 通过不受控制的网络传输敏感的、未加密/未经身份验证的流量 

• 身体控制不佳 

  

  

“尽管所有组织都应避免这些不良做法，但它们在支持关键基础设施或国家关键职能的组织中尤其危险。CISA 鼓励所有组织查看不良做法网页并参与必要的行动和关键对话以解决不良做法实践，”CISA 补充道。
