# 为什么勒索软件黑客喜欢周末假期

今年进入阵亡将士纪念日周末，是肉类加工巨头 JBS。在 7 月 4 日之前的星期五，IT 管理软件公司 Kaseya以及超过一千家不同规模的企业。劳动节是否也会引起高调的勒索软件崩溃还有待观察，但有一点很清楚：黑客喜欢假期。

  

真的，勒索软件黑客也喜欢固定的周末。但是长的？当每个人都与家人和朋友一起狂欢并刻意避免任何与远程办公室相关的事情时？这就是好东西。虽然这种趋势并不新鲜，但本周 FBI 和网络安全和基础设施安全局发布的联合警告强调了威胁已经变得多么严重。

  

对攻击者的吸引力非常简单。勒索软件可能需要时间才能在整个网络中传播，因为黑客会努力提升权限以最大限度地控制大多数系统。任何人注意到的时间越长，他们造成的伤害就越大。反病毒公司 Emsisoft 的威胁分析师 Brett Callow 说：“一般来说，威胁行为者会在人们开始拔插头的可能性较小时部署他们的勒索软件。” “攻击被发现和中断的可能性越小。”

  

即使它被发现的时间相对较快，许多负责处理它的人也可能在池边，或者至少比正常的周二下午更难找到。安全公司 Red Canary 的情报总监 Katie Nickels 说：“直觉上，防御者在假期可能不那么专心是有道理的，这在很大程度上是因为工作人员减少了。” “如果在节假日期间发生重大事件，维权者可能更难以调集必要人员迅速做出反应。”

  

正是那些重大事件可能引起了 FBI 和 CISA 的注意；除了 JBS 和 Kaseya 事件之外，毁灭性的殖民管道攻击发生在母亲节周末。（不是一个为期三天的周末，但仍然会造成最大的不便。）这些机构表示，他们没有任何“具体的威胁报告”表明类似的攻击将在劳动节周末发生，但它不应该像任何如果有人这样做，有点惊讶。

  

同样重要的是要记住，勒索软件是一个持续的威胁，对于每一次引人注目的汽油短缺，都有数十家小企业在任何特定时间争先恐后地向网络犯罪分子发送比特币。2020 年，受害者向 FBI 的互联网犯罪投诉中心报告了 2,474 起勒索软件事件，比上一年增加了 20%。根据 IC3 的数据，黑客的需求在同一时间段内增加了两倍。这些攻击并非都集中在为期三天的周末和 Hallmark 假期。

  

事实上，正如 CISA 和 FBI 所承认的那样，周末通常会受到骗子的欢迎。Callow 指出，向 ID Ransomware 提交的文件（由安全研究员 Michael Gillespie 创建的一项服务，可让您上传赎金记录或加密文件以找出究竟是什么攻击了您）往往会在周一激增，因为受害者已返回办公室查找数据加密。

  

黑客的战略时机也有其他形式。卡洛说，对学校的袭击在春末和夏季急剧下降，因为那时与恢复相关的紧迫性要小得多。当他们从孟加拉银行偷亿$ 81，朝鲜的拉撒路组定时抢劫趁不仅孟加拉国和美国之间的差异周末，在前者，它的周五和周六，也是农历新年，整个太大的节日亚洲。

  

确实，一些大型勒索软件团伙——其中包括DarkSide、Ragnarok 和 REvil——最近已经解散或下线。副国家安全顾问安妮·纽伯格周四在新闻发布会上表示，美国情报机构最近发现勒索软件“减少”。但安全研究人员警告不要松一口气。“像 Pysa、Lockbit 2.0、Conti 和许多其他勒索软件组织继续对组织造成重大损害，”Nickels 说。“即使一个或多个占主导地位的勒索软件家族消失了，它背后通常还有另一个权利来填补空白。” 在同一次简报中，纽伯格还提醒各组织在长周末之前“保持警惕”。

  

不幸的是，为潜在的黑客攻击做准备并不是在周五下午关闭各种舱门的问题。到那时，已经太晚了；攻击者往往潜伏在受损系统中，并在最合适的时机发动攻击。进行严格防御的最佳时间通常是在勒索软件真正攻击之前的几周。“大多数入室盗窃发生在中午，但您不仅要锁上房子，”卡洛说。

  

也就是说，公司和个人可以采取一些措施来更好地保护自己免受黑客攻击，无论是在长周末之前还是之后。FBI 和 CISA 的建议与大多数网络安全情况的最佳实践相呼应：不要点击可疑链接。对您的数据进行离线备份。使用强密码。确保您的软件是最新的。使用两因素身份验证。如果您使用远程桌面协议（一种 Microsoft 产品，它历来被证明是攻击者的流行切入点），请谨慎操作。也许这个周末可以多留几个人待命，以防万一。
