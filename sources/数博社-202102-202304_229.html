网络犯罪分子购买管理员凭据以加强对云部署的攻击

Lacework 分析发现，SSH、SQL、Docker 和 Redis 是过去三个月最常见的目标。

根据Lacework 的 2021 年云威胁报告第 2 卷，公司现在应该将网络犯罪分子视为业务竞争对手。 

报告作者建议这种思维转变有两个原因： 

  1. 网络犯罪分子正在努力通过勒索和勒索直接获利。 

  2. 他们还旨在通过窃取资源来间接获利。

Lacework 实验室分析了来自其客户的遥测数据和其他数据，以确定云部署面临的不断增加和不断增加的安全威胁。根据该报告，过去几个月最有趣的趋势之一是对访问云帐户的需求不断增加。这体现在从 Initial Access Brokers 向云帐户出售管理员凭据时。分析还发现对存储桶、数据库、编排系统和交互式登录的扫描和探测持续增加。

Lacework Labs 以基于 MITRE ATT&CK 技术的方法跟踪威胁活动。该报告确定了过去几个月中这些著名的攻击者策略、技术和程序：

  1. 用户执行：恶意图像 [T1204.003]

  2. 持久性：种植体内部图像 [T1525]

  3. 执行：部署容器 [T1610]

Lacework 分析师今年也一直在跟踪TeamTNT。研究人员今年早些时候发现，由于恶意帐户接管，包含来自 TeamTNT 的恶意软件的 Docker 镜像被托管在公共Docker存储库中。分析人员发现了多个案例，其中网络犯罪分子使用在 GitHub 上暴露的 Docker Hub 机密来暂存恶意图像。 

云服务探测

该报告分析了 2021 年 5 月 1 日至 7 月 1 日的流量，以识别云威胁。分析表明，SSH、SQL、Docker 和 Redis 是过去三个月中最常被攻击的云应用程序。安全研究人员专注于AWS环境中的cloudtrail 日志，尤其是 S3 活动。他们发现 Tor 似乎更频繁地用于 AWS 侦察。大多数活动来自以下来源：

  • 60729:"Zwiebelfreunde eV"

  • 208294：马库斯·科赫”

  • 4224:"CALYX-AS"

  • 208323：“应用隐私基金会”

  • 62744:"QUINTEX"

  • 43350:"NForce Entertainment BV"

排名前三的 S3 API 包括 GetBucketVersioning、GetBuckAcl 和 GetBucketLocation。

Lacework 分析师建议采取以下步骤来保护云环境：

  • 确保 Docker 套接字不会公开暴露，并且适当的防火墙规则、安全组和其他网络控制到位，以防止对网络服务的未经授权的访问。

  • 确保基本映像来自受信任的上游来源并经过适当审核。

  • 实现基于密钥的 SSH 认证。

  • 确保通过控制台在 S3 存储桶上设置的访问策略不会被自动化工具覆盖。 

  • 围绕 S3 存储桶创建对 S3 策略和自动化进行频繁审计，以确保数据保持私密性。

  • 在 Redis 实例中启用保护模式以防止暴露在互联网上。
