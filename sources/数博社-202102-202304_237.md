# 介绍

威胁和保护矩阵或 (TaSM) 是一种面向行动的视图，用于保护和支持Ross Young创建的业务。简而言之，如果 Cyber 从事收入保护业务，那么我们需要制定纵深防御计划，以应对我们公司面临的最大威胁。该矩阵允许公司使用 NIST 网络安全功能（识别、保护、检测、响应和恢复）覆盖其主要威胁，以构建强大的安全计划。执行此活动的组织将更好地了解如何保护他们的公司，因为他们填写了减轻重要威胁的保护措施。记住魔鬼在细节中，因此我们选择了塔斯马尼亚魔鬼作为项目标志。

![](../Images/80117f3074e322ee0e25b45c4278292b.png)

示例：如果您纵观信息安全行业，您会注意到针对公司的最大数据泄露通常涉及网络钓鱼、勒索软件、Web 应用程序攻击和供应商/合作伙伴数据丢失。请注意，您可以将其他人添加到矩阵中，例如内部威胁或您的环境独有的任何内容。

以下是您可以制定纵深防御计划以减轻公司这些威胁的一种方法。

# 向计划添加指标

现在您已经构建了您的 TaSM，重要的是查看您列出的保护措施。并非每项保障措施都同样重要。如果一切都很重要，那么没有什么是真正重要的。想一想您作为一个组织要关注的保障措施。这些可能是阻止威胁最有效的方法。这些保护措施也可能是您最有机会改进的地方。选择一些可以放置关键指标的保护措施，并通过添加一个红框来突出显示它们。这将允许您将进度从您的指标映射到您的 TaSM。记住什么得到衡量就完成了，完成了什么得到了资助。

![](../Images/37d25ca4f6b02dfcc1df6e684ac169ae.png)

# 创建网络报告卡

在概述您想要改进的保障措施之后，您的组织应该创建一些关键指标和记分卡。这个例子有一些需要注意的地方，但可以随意修改。1) 按技术、人员和流程对事物进行分组，以展示如何利用组织的多个领域。2）按季度显示进度。如果新季度有所改善，则将进度标记为绿色，如果下降，则将其标记为红色，如果没有取得进展，则将其标记为黄色。3) 目标有多种形状和大小，应不时重新评估。目标可能是理想的，例如 0 漏洞。虽然 100% 的客户满意度或 0 漏洞等理想目标可能无法实现，但它们显示了组织想要的趋势。最后，使用您的记分卡讲述一个可以与执行领导团队分享的故事。请注意，这个故事是虚构的，并不反映真实的公司。

# 使用 TaSM 增强威胁建模

当我们寻找在组织中应用 TaSM 的其他方法时，可以利用 TaSM 的一种方法是在威胁模型中。示例：开发人员团队可以将显示关键属性（例如（加密层、访问控制方法和数据类型））的数据流图与 TaSM 结合使用，以确定项目中的关键问题。由于架构审查委员会看到在威胁模型讨论期间使用了大量 TaSM，架构师可能会确定需要企业解决方案的常见威胁或保护措施。

# 使用 TaSM 帮助改进风险委员会

由于网络威胁不是唯一的威胁类型，我们还应该研究如何在风险委员会中更广泛地采用 TaSM。所需要的只是一个额外的列来列出公司内的组织。想象一下，如果每个组织都分享他们的前 3-5 个威胁。您的风险委员会可以展示公司如何以一致、充分、合理和有效的方式减轻其最大威胁。此外，它还允许委员会合作以从多个角度解决威胁。示例：网络如何利用人力资源和法律流程来帮助应对造成品牌损害的网络钓鱼攻击。

# 这些条款是什么意思？

为确保正确使用 TaSM，请务必了解矩阵中使用的术语的定义

### 威胁

CNSS 将威胁定义为可能对组织运营产生不利影响的任何事件。可在此处找到常见威胁类型的示例STRIDE-LM

### NIST 函数

5 个 NIST 网络安全框架功能允许您创建纵深防御策略，以确定您将如何保护业务。

1) 识别 识别功能有助于形成对管理系统、人员、资产、数据和能力风险的组织理解。关键目标：确定所有容易受到此类威胁的人员、流程或系统。

2) 保护 保护功能支持限制或遏制威胁影响的能力。关键目标：如何通过消除或阻止漏洞来限制攻击的威胁

3) 检测 检测功能定义活动以及时识别事件的发生。关键目标：如果您无法阻止威胁（即保护阶段），您怎么知道它正在发生，并且您的公司正在遭受伤害

4) 响应 响应功能包括与事件相关的适当活动，以尽量减少影响。关键目标：如果威胁已经实现，您如何防止额外的经济损失、声誉损失、不合规或侵犯隐私

5) 恢复 恢复功能包括确定适当的活动以维持弹性计划并恢复在网络安全事件期间受损的服务。关键目标：您如何达到与事件发生前相同或更好的状态
