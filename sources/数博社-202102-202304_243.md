# 心怀不满的勒索软件关联公司泄露了 Conti 团伙的技术手册

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyMDIxMjU2MA==&mid=2247485780&idx=1&sn=97795d1fbbdf2e71fcd96f0739e9b6f2&chksm=c1970c6bf6e0857d09635af302fd269e70b634078c52f9164e3d78e58dfab8ba45c3e1f8aa8f&scene=126&sessionid=1681312679#rd](http://mp.weixin.qq.com/s?__biz=MzkyMDIxMjU2MA==&mid=2247485780&idx=1&sn=97795d1fbbdf2e71fcd96f0739e9b6f2&chksm=c1970c6bf6e0857d09635af302fd269e70b634078c52f9164e3d78e58dfab8ba45c3e1f8aa8f&scene=126&sessionid=1681312679#rd)

Conti 勒索软件计划的一名心怀不满的成员今天泄露了 Conti 团伙用于培训附属成员如何在被黑公司内部访问、横向移动和升级访问权限的手册和技术指南，然后在加密文件之前泄露其数据。

今天早些时候在一个名为 XSS 的地下网络犯罪论坛上泄露了这些文件，该文件由一个个人共享，该个人似乎对 Conti 团伙支付给他们以破坏公司网络的钱少有问题。

此外，该个人还发布了一个名为“ *Мануали для работяг и софт.rar* ”的RAR压缩文件，大致翻译为“*劳动者手册和软件手册**.rar* ” 。

该档案 包含 37 个文本文件，其中包含有关如何在网络入侵期间使用各种黑客工具甚至合法软件的说明。

例如，泄露的手册包含有关如何执行以下操作的指南：

*   使用 MEGA 帐户配置 Rclone软件以进行数据泄露
    
*   将AnyDesk 软件配置 为受害者网络中的持久性和远程访问解决方案 \[一种已知的 Conti 策略\]
    
*   配置和使用 Cobalt Strike 代理
    
*   使用 NetScan 工具扫描内部网络
    
*    在虚拟专用服务器 (VPS) 上安装 Metasploit 渗透测试框架
    
*   使用Ngrok 安全隧道通过 RDP 连接到被黑的网络 
    
*   在公司的被黑网络中提升并获得管理员权限
    
*   接管域控制器
    
*   从 Active Directory 转储密码（NTDS 转储）
    
*   执行 SMB 暴力攻击
    
*   强力路由器、NAS 设备和安全摄像头
    
*   使用 ZeroLogon 漏洞
    
*   执行Kerberoasting攻击
    
*   禁用 Windows Defender 保护
    
*   删除卷影副本
    
*   附属公司如何配置自己的操作系统以使用 Tor 匿名网络等

勒索软件即服务 (RaaS) 操作造成的泄漏极为罕见；然而，今天共享的数据并不是安全研究人员所说的开创性的。

泄露的文件包含 Conti 和其他勒索软件团伙多年来在以前的入侵中使用的基本攻击策略和技术指南。

然而，泄漏将帮助一些安全公司整合更强大的防御手册，他们可以向客户推荐这些手册，以提高他们检测 Conti 入侵的能力——现在确切地知道 Conti 附属公司可能执行的操作。
