# 网络风险管理公司 Safe Security 融资 3300 万美元

**网络风险衡量和缓解平台提供商 Safe Security 本周宣布，已获得 BT 集团牵头的 3300 万美元战略投资。**  

Safe Security 表示，这笔资金将用于将其工程团队的规模扩大一倍，并增加公司的研发支出。

  

作为投资的一部分，BT 将拥有在英国使用和销售 Safe Security 产品的专有权，将网络风险管理平台纳入其产品组合。此外，两家公司将共同开发新产品。

  

Safe Security 成立于 2012 年（前身为 Lucideus），总部位于加利福尼亚州帕洛阿尔托，使用人工智能实时衡量和减轻网络风险。

  

Safe Security 使用的评分模型是作为麻省理工学院的一个联合研究项目构建的。分数是在宏观和微观层面计算的，旨在帮助客户检测网络攻击或预测违规的可能性。

  

“\[BT\] 与 Safe Security 的投资和战略合作伙伴关系将进一步加速我们的愿景，即使 SAFE 评分成为衡量和减轻网络风险的行业标准。通过将 BT 的全球影响力和能力与 SAFE 提供网络风险状况实时可见性的能力相结合，我们将从根本上改变全球衡量和管理网络安全的方式，”Safe Security 首席执行官 Saket Modi 说。

  

  

**背景情况：**

  

Safe Security 总部位于加利福尼亚州帕洛阿尔托，旨在利用人工智能帮助组织实时降低网络风险。它使用在麻省理工学院作为联合研究项目构建的评分模型——该模型通过人工智能引擎运行网络安全传感器、外部威胁情报和业务数据，以生成分数和组织面临的美元价值风险。莫迪说，这些分数是在宏观和微观层面计算的，可以针对特定的业务线和部门进行衡量。

“Safe Security 于 2012 年与我的另外两位联合创始人 Rahul Tyagi 和 Vidit Baxi 从 IIT Bombay 孵化为一家网络安全服务公司，”莫迪通过电子邮件告诉 VentureBeat。“我们为全球财富 500 强公司 \[和政府\] 提供了各种网络安全服务，例如红队、漏洞评估、渗透测试和董事会培训等等……2020 年初，我们推出了网络安全和数字业务风险量化平台 Safe，并率先推出网络安全领域的一类新产品\[它\]带来了一种主动管理、衡量和减轻网络风险的独特方式。这使安全和风险管理领导者不仅能够使网络安全成为明智的业务决策，而且还能帮助他们更有效地与所有利益相关者进行沟通。”

## 计算风险

莫迪断言，虽然网络攻击多年来不断发展，但对于大多数高级商业领袖来说，网络安全仍然是一个不透明的概念。他说，组织经常投资于端点检测和响应、防病毒、防火墙等产品，而不知道其违规可能性的“前后”影响。

莫迪说：“安全和风险管理领导者继续通过专业术语来评估网络安全，并不断添加网络安全产品以对网络攻击做出被动响应，而不是主动防御。” “相比之下，Safe 平台提供了对多种威胁向量的当前和历史评估，包括人员、流程、技术和第三方——然后用 0 到 5 之间的‘违约可能性分数’进行量化……评分算法经过训练与麻省理工学院和 IIT Bombay 合作，研究来自其研究和分析团队的网络保险索赔数据和黑客分析。”

  

Safe 的竞争对手包括VisibleRisk和Exabeam，以及Viso Trust、SecurityScorecard和RiskLens。但莫迪表示，在客户投资于数字业务风险量化、第三方风险管理和内部威胁分析的推动下，该公司去年的收入增长了 270%，预计未来 12 个月将增长“六倍”。

“大流行已显着加速了全球企业的数字化进程，随着组织向数字原生设置转变，网络安全成为第一要务，”莫迪继续说道。“\[例如，一家\] 财富 50 强快速消费品公司使用我们的平台来管理其跨供应商和分销商的第三方风险，他们将基于问卷的评估的见解与由外而内的评估和由内而外的评估相结合，以为其环境中的所有关键第三方获得统一的实时风险态势。一家财富 250 强银行使用我们的平台获取对其收入贡献最大的关键业务部门的实时网络风险状况。\[和\] 美国排名前五的医疗保健提供者之一

  

莫迪表示，本轮融资的收益将用于增加 Safe 在美国的收入，并将公司的研发支出增加三倍。除此之外，Safe 计划到 2021 年底将其工程团队增加一倍，达到 200 多人，并将总人数增加到 300 多人。
