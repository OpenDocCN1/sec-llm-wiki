GitHub 在一份公告中解释说，它会扫描包含 PyPI 和 RubyGems 注册表机密的存储库。

GitHub 最近更新了其见解，以包含 PyPI 和 RubyGems 注册表机密的存储库。这种方法可以保护数以百万计的 Ruby 和 Python 程序员，他们可能会无意中将机密和凭据提交到他们的 GitHub 存储库。 


GitHub, Inc. 是使用 Git 的软件开发和版本控制 Internet 托管服务。它提供了 Git 的分布式版本控制、源代码管理及其功能。GitHub 为用户提供具有可用安全功能的高级安全许可证。这些功能也可用于 Github.com 上的公共存储库。 


GitHub 最近报道说，公开 PyPI 和 RubyGems 机密（例如密码和 API 令牌）的存储库现在会定期扫描。 


要利用此功能，开发人员必须确保为其存储库激活 GitHub Advanced Security，这是公共存储库的默认情况。 


“对于 GitHub.com 上的公共存储库，这些功能是永久启用的，只有在您更改项目的可见性以使代码不再公开时才能禁用，”GitHub 表示。 


秘密或令牌是可以在使用服务时验证自己的字符串，类似于用户名和密码。 第三方 API 应用程序通常在其代码中利用私有机密来访问 API 服务。因此，应该小心不要泄露秘密，因为这可能会导致更广泛的供应链中发生更多的攻击。 


除其他外，GitHub 可能会检查错误提交的 npm、NuGet 和 Clojars 的秘密。 


正如所观察到的，GitHub Advanced Security 的列表目前支持 70 多种不同类型的综合性机密。 


该公告进一步写道：“对于其他存储库，一旦您拥有企业帐户的许可证，您就可以在组织或存储库级别启用和禁用这些功能。更多信息请参阅“管理组织的安全和分析设置”和“管理存储库的安全和分析设置”。如果您有企业帐户，则整个企业的许可证使用情况会显示在您的企业许可证页面上。更多信息请参阅“查看您的 GitHub Advanced Security 使用情况”。


GitHub 在发现密码、API 令牌、私有 SSH 密钥或任何其他已在公共存储库中披露的秘密时通知管理员。例如，最近推出的 PyPI 和 RubyGems，注册表维护者将删除公开的授权，并通过电子邮件向开发人员发送原因。 


GitHub 软件工程师 Annie Gesellchen 在一篇博客文章中解释说：“如果我们找到了，我们会通知注册表，他们会自动撤销任何泄露的机密并通知其所有者。” GitHub 的 RubyGems 和 PyPI 合作的好处在于，它可以在几秒钟内自动撤销已披露的机密，而不是等待开发人员采取手动操作。 


自动保密扫描使用户提前一英寸，以保护开发人员的基础设施免受无意泄漏并提高供应链的安全性。
