# 使用 MITRE ATT&CK 识别 APT 攻击

安全团队和研究人员依靠对工具、例程和行为的公开记录分析来更新自己在网络安全领域的最新发现。已发布的信息可作为已知策略、技术和程序 (TTP) 的参考，以安装针对高级持续威胁 (APT) 的防御并防止可能发生在各自行业中的攻击。  

然而，拥有防御攻击的理论知识与亲身体验大不相同。公布的例行程序、工具和行为可能与每个目标公司或行业对犯罪集团的执行不同。此外，这种差异很大程度上取决于被妥协公司的研究环境。鉴于投入研究的大量精力和资源以及进入手段，这些威胁参与者将确保他们每次都能找到不同的方法，在观察时保持隐藏，秘密发送命令和接收信息，掩盖他们的流量，并感染更多设备以越长越好。这就是研究人员、分析师和技术解决方案的用武之地。

  

在检测到来自他们的一台服务器的可疑命令和控制 (C&C) 流量交换后，一家公司的安全团队致电我们调查和分析流量。我们可以访问有限数量的机器和数据来研究反馈和事件日志，包括磁盘和内存映像。但是，如果没有端点检测和响应 (EDR) 或跨层检测和响应 (XDR) 解决方案，就无法收集可能在无法访问的系统环境中未被发现的所有样本和工具。这限制了调查和安全团队制作完整的地图和攻击归因。

## **范围和初步分析**

根据对日志的初步分析，共有 62 台机器被感染：其中 10 台是服务器，13 台是带有能够进行文件抓取和数据泄露的二进制文件的机器，22 台是带有后门壳的机器，其余的则托管其他工具和被滥用用于加载恶意二进制文件的正常应用程序被滥用用于攻击。

![](../Images/2124d81dd44e7545dedf16196198d0e4.png)

该后门允许攻击者使用 cmd.exe 执行命令。Mimikatz 等工具也被用于获取用户帐户。网络扫描工具被用来寻找要感染的其他机器，并被包含在恶意网络中，这进一步允许后门远程投放其他工具。要运行远程删除的可执行文件，要么创建了计划任务，要么使用了 wmic 进程创建命令。在一些情况下，后门的副本被丢弃，而被丢弃和执行的工具也各不相同。

攻击者主要针对 PDF 和 Microsoft Office 文件等文档文件。此外，根据二进制文件的时间戳和感染的广泛程度，这些攻击很可能已经发生了很多年。我们比较了我们在 MITRE ATT&CK 中发现的例程和工具，并注意到观察到的技术与 APT32 和 APT3 都匹配，除了一些无法关联的不同技术。

## **分析和归因**

考虑到技术的变化，我们分析了例程使用的工具和关系集群，并使用安装数量最多的五个端点目标连接。我们发现了六种类型的数据泄露工具、六种后门和五种用于不同目的的杂项工具。其中许多工具利用了公司的内部系统和软件，例如他们的文档管理系统，以及 MySQL 后端数据库等。我们还发现了六个将工具连接到恶意程序的关系集群，以及四个可以与先前记录的 APT 组和子组活动相匹配的入侵集。我们在论文“ Finding APTX: Attributing Attacks via MITRE TTPs ”中详细讨论了这些工具和关系。

![](../Images/a3711c1c7dd8c32a172c5690b95e1730.png)

我们将攻击归咎于使用不同工具集的团体，并且与其他研究人员已经发表的其他团体有着密切的联系。书写风格也很广泛，这可以从工具的包装或“揭示”程度之间的对比中看出。此外，考虑到目标是持续的信息窃取、数据更新和长时间存在，同时保持隐藏在系统中，因此每个入侵集的数据泄露过程中的冗余并不令人意外。

不幸的是，受害组织处于一个独特的位置，可以记录他们可以用作参考的妥协指标 (IOC)。考虑到当今可用的技术解决方案（例如 EDR 和 XDR），未定义的日志可能能够证明和识别创建完整入侵地图所必需的缺失链接。

这些解决方案可以减少识别和重新创建攻击如何发生的事件所需的时间。尽管如此，合作安全和调查团队在识别、预防和减轻威胁方面发挥着至关重要的作用，尤其是在归因于责任团体方面。虽然该过程可能并不简单，但一旦确定了事件和工具的相关性，确定所使用的技术和工具就可以带领安全团队保护整个公司结构。
