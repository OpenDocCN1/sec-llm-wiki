# 控制网络风险：发现和阻止 ICS 威胁

工业控制系统 (ICS) 是智能工厂不可或缺的一部分，但恶意行为者可能会利用这些系统的安全漏洞进行网络攻击。因此，企业应在其网络安全战略中解决 ICS 中的薄弱环节。

  

企业和工业设施依靠控制系统来管理、指挥或调节构成其运营的设备和系统。由工业控制系统 (ICS) 运行的流程不仅“保持正常运转”，而且有助于提高生产力和安全性。从温度和传感设备到生产线和安全设备，一切都由 ICS 管理。

  

过去，这些系统属于工程部门的管辖范围，因此它们的设计和配置侧重于功能和流程。但在 9/11 之后，政府和企业开始更加关注网络安全。ICS 的管理转移到 IT 团队，因此，所有网络安全监控和缓解都以 IP（互联网协议）网络层为中心。ICS 安全从任务保证到信息保证。

  

工程部门下的系统既不由 IT 团队管理，也不由 IT 团队保护。这意味着多年前由工程团队管理但今天仍在使用的控制系统设备（例如过程传感器、执行器和驱动器）不具备网络安全功能。它们无法进行身份验证或网络日志记录，而且大多数无法升级。这是一个严重的问题，因为陈词滥调是正确的：安全性取决于最薄弱的环节。攻击者将尝试通过所有可能的安全弱点进入企业网络。

  

任何针对企业和大型组织的综合安全计划都应包括针对 ICS 中薄弱环节的网络安全政策。由于他们管理企业运营的许多重要方面，因此保护这些控制系统也将保护工人、宝贵的数字资产和有形财产。

趋势科技的研究人员还在2019 年 5 月将一个设计为小型企业的智能制造蜜罐上线，并让其运行了 7 个月。第一次攻击发生在蜜罐上线一个月后。蜜罐暴露的时间越长，研究人员观察到的恶意活动就越大、越复杂。这表明，拥有关键客户且安全性不足的企业是攻击者的成熟目标。

  

## **ICS 攻击向量图**

  

要完全了解针对 ICS 环境的威胁，确定可能的攻击媒介很重要。

  

首先，有些设备没有任何网络安全元素。现代技术通过这些可靠、准确和安全的传感器、控件和执行器提高了生产力。但如前所述，他们缺少一个关键因素：网络安全。因此，攻击者可以将这些小型且不安全的设备用作企业网络的入口点。

  

在某些情况下，攻击者可能会破坏 IT 环境中的操作技术 (OT) 网络。（OT 直接监控或控制工业设备或流程，而 ICS 是该组的一个子集。）示例包括使用恶意软件对服务器的攻击、对人机界面 (HMI) 的 Web 应用程序攻击以及危及来自网络路由器。

![](../Images/1ea841fced233759cdb7b302f4819dfc.png)

在其他情况下，攻击可能来自对现场网络设备的物理攻击或在补丁、固件或软件更新期间将恶意软件注入系统的软件攻击。

  

这些案例强调企业需要彻底了解他们可能面临或已经面临的威胁。针对 ICS 环境的潜在攻击者不计其数，也有相对容易的攻击可以在 OT 网络上发起。

## **ICS 环境的安全策略**

  

解决 ICS 安全中的弱点并非易事。企业需要应对过时的设计方面、第三方应用程序中的安全问题以及许多其他问题。这些只是他们需要克服的一些挑战：

*   未知设备和与 OT 网络的连接
    
*   原始设计中缺乏安全性
    
*   易受攻击且不安全的第三方应用程序和操作系统
    
*   可能难以保护的遗留系统和环境
    

  

降低 ICS 环境中的网络风险还需要深入了解网络环境，包括传感器、过程控制、协议和通信。安全规划人员还应该清楚地了解环境中的网络威胁和攻击媒介。

  

ICS 环境中的网络风险影响着许多行业，包括电力、石油和天然气、制造、制药、医疗保健和运输。由于网络攻击可能对关键行业和一般业务产生潜在影响，因此建议每个组织实施全面的网络安全战略。一个好的起点是行业标准。根据经营的业务类型，管理机构可以执行不同的标准。接下来，企业应根据组织的目标和目标实施网络安全框架。这可以通过制定一个跨越四大支柱的有凝聚力的计划来实现：人员、流程、技术和文化。

![](../Images/39bdd220ac4f51d55a593cf417032878.png)

组织还可以开展一些基本活动来降低网络风险。其中包括加强帐户凭据、禁用未使用的物理和网络服务端口、加密系统配置文件以及限制可以访问网络的 IP 和媒体访问控制 (MAC) 地址。

企业迫切需要部署网络安全措施来保护 ICS 环境。当然，在实施新的工具和政策时，有必要的预防措施。所有与控制系统一起使用的网络工具在用于实时 OT 网络之前都应该经过充分的离线测试。ICS 环境的适当技术应该以集成的方式离线测试，然后在线测试。这些技术包括由 Trend Micro 和 TxOne Networks 开发的OT 网络安全技术套件。

  

危险事件可能源于无保护传感器之类的小事。企业和工业设施，尤其是那些承载着宝贵的公司资产并容纳数千名员工的企业和工业设施，应定期更新和升级其安全性，以跟上不断变化的威胁。涵盖 ICS 环境所有级别的全面安全计划有助于确保企业资产和员工安全无恙。
