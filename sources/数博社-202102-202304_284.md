# 研究人员发现第一个已知的针对 Windows 容器的恶意软件

安全研究人员发现了第一个已知的恶意软件，称为“ Siloscope ”，它针对 Windows Server 容器感染云环境中的 Kubernetes 集群。

“Siloscape在很大程度上混淆的恶意软件通过Windows集装箱瞄准Kubernetes集群”，说单位42研究员丹尼尔Prizmant。“它的主要目的是在配置不当的 Kubernetes 集群中打开一个后门，以运行恶意容器，例如但不限于加密劫持者。”

Siloscape 于 2021 年 3 月首次被发现，其特点是采用多种技术，包括针对 Web 服务器等常见云应用程序，通过已知漏洞获得初步立足点，然后利用 Windows 容器逃逸技术突破容器的限制，在底层节点上获得远程代码执行。

容器是一个隔离的、轻量级的筒仓，用于在主机操作系统上运行应用程序。恶意软件的名称——silo escape 的缩写——源自其主要目标是逃离容器，在本例中，是筒仓。为了实现这一点，Siloscape 使用了一种称为线程模拟的方法。

![](../Images/0733927969a70564883bf802e66acc83.png)

“Siloscape通过模拟其主线程来模仿CExecSvc.exe特权，然后在新创建的符号链接上调用 NtSetInformationSymbolicLink 以脱离容器，”Prizmant 说。“更具体地说，它将其本地容器化 X 驱动器链接到主机的 C 驱动器。”

获得此权限后，恶意软件会尝试滥用节点的凭据在整个集群中传播，然后使用 Tor 代理匿名建立与其命令和控制 (C2) 服务器的连接以获取进一步指令，包括利用计算Kubernetes 集群中的资源，用于加密劫持，甚至从受感染集群中运行的应用程序中窃取敏感数据。

“与其他针对容器的恶意软件不同，这些恶意软件主要以加密劫持为重点，Siloscape 实际上并没有做任何会伤害集群的事情，”Prizmant 说。“相反，它专注于不被发现和无法追踪，并为集群打开后门。”

在获得对 C2 服务器的访问权限后，Unit 42 表示它发现了 23 名活跃的受害者，该服务器总共托管了 313 名用户。根据 C2 服务器的创建日期，据说该活动至少在 2020 年 1 月 12 日左右开始，这表明该恶意软件可能只是一年多前开始的更大活动的一小部分。

“与大多数专注于资源劫持和拒绝服务 (DoS) 的云恶意软件不同，Siloscape 不将自己限制在任何特定目标上，”Prizmant 指出。“相反，它为各种恶意活动打开了后门。” 除了安全地配置 Kubernetes 集群之外，如果容器化被用作安全边界的一种形式，还建议部署 Hyper-V 容器。
