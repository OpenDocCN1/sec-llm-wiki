# 未来十年，全球勒索软件攻击的成本将超过 2650 亿美元

全球勒索软件事件的成本预计将失控，到 2031 年将超过 2650 亿美元。  

  

勒索软件现在是最具潜在破坏性且非常流行的恶意软件类型之一。如果勒索软件登陆易受攻击的系统，文件通常会被加密，用户被锁定，并要求付款（通常是加密货币）以换取解密密钥。 

  

在勒索软件应用程序的最新发展中，运营商还会在攻击期间窃取信息，并威胁要在暗网上的泄漏站点上发布这些信息或将其出售，从而使受害者付出代价的压力加倍。 

  

目前，将勒索软件转变为利润丰厚的“商业”机会的一些最知名团体是 Maze、Neflim、Clop 和 DarkSide，后者在在一次破坏性的袭击破坏了美国各地的燃料供应后，他们从 Colonial Pipeline 勒索了440 万美元。 

  

Cybersecurity Ventures 预测，到2031 年，勒索软件造成的损失可能在全球范围内造成2650 亿美元的损失，基于这种类型的网络犯罪，每几秒钟就会发生一次攻击，同时攻击企业和消费者。 

  

目前，网络安全机构估计勒索软件今年将花费我们大约 200 亿美元，是 2015 年的 57 倍。 

  

该公司发布的最新估计是基于事件同比增长 30% 得出的。

  

勒索软件感染可能会导致高昂的保险费和支出，需要聘请网络取证公司来调查事件、损害限制或系统修复、数据丢失，以及可能向攻击者支付费用以检索关键系统或防止数据泄露。 

  

最新估计还包括攻击期间和攻击后的业务中断、声誉损害以及勒索软件事件后员工培训的费用。 

  

Palo Alto Networks 表示，仅勒索软件的支出就从 2019 年的 115,123 美元飙升至 2020 年的 312,493 美元，同比增长 171%。近年来记录的最大需求是 3000 万美元。

  

尽管全球各地的政府官员都参与其中，包括美国总统拜登等人最近签署了一项行政命令，要求联邦机构努力改善该国的网络安全态势，但勒索软件事件只会变得更糟。 

  

“尽管当局最近成功打击了几个勒索软件团伙，但这种特殊类型的恶意软件已被证明是九头蛇——砍掉一个头，几个头出现在它的位置——所有迹象都表明，未来十年的问题将同样严重，”网络安全风险投资公司指出。
