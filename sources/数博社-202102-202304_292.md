# NSA：国家级APT组织网络攻击近期常用的 5 个安全漏洞

美联储警告说，民族国家行为者再次追捕美国资产，这一次是一连串的网络攻击，这些攻击利用了影响 VPN 解决方案、协作套件软件和虚拟化技术的五个漏洞。

根据周四发布警报的美国国家安全局 (NSA)称，名为 APT29（又名 Cozy Bear 或 The Dukes） 的高级持续威胁 (APT) 组织正在“对易受攻击的系统进行广泛的扫描和利用，以期获取身份验证凭据以允许进一步访问。”

它补充说，目标包括美国和盟国的国家安全和政府网络。

研究人员警告说，主动攻击的五个漏洞是已知的，修复了来自 Citrix、Fortinet、Pulse Secure、Synacor 和 VMware（详情如下）平台中的安全漏洞，组织应立即修补这些漏洞。

Cisco Talos 的研究人员在周四的相关帖子中表示：“其中一些漏洞也有可用的 Metasploit 模块，目前正在被广泛利用。” “请注意，其中一些漏洞利用了利用 SSL 的应用程序。这意味着用户应该启用 SSL 解密……以检测对这些漏洞的利用。”

美国国家安全局已将 APT29 与俄罗斯的外国情报局 (SVR) 联系起来。消息传出之际，美国正式将最近的SolarWinds 供应链攻击归咎于SVR，并因俄罗斯的网络攻击以及拜登总统所说的干预美国选举而对俄罗斯实施制裁。

## 5个被积极利用的漏洞

根据美国国家安全局的说法，以下内容在网络间谍活动中受到广泛攻击：

*   CVE-2018-13379 Fortinet FortiGate SSL VPN（路径遍历）
    
*   CVE-2019-9670 Synacor Zimbra 协作套件 (XXE)
    
*   CVE-2019-11510 Pulse Secure Pulse Connect Secure VPN（任意文件读取）
    
*   CVE-2019-19781 Citrix Application Delivery Controller 和网关（目录遍历）
    
*   CVE-2020-4006 VMware Workspace ONE Access（命令注入）
    

“两个 VPN 系统、两个虚拟化平台和一个协作解决方案中的漏洞似乎是一个强大的组合，”New Net Technologies 安全研究全球副总裁 Dirk Schrader 告诉 Threatpost。“其中四个已经 12 个月或更长时间，这对美国的整体网络卫生来说不是一个好兆头，因为在 NIST 的 NVD 中，所有这些都被评为严重甚至危急。看起来对手可以依靠缺乏与基本网络安全控制相关的勤奋，在大流行时期更是如此。”

## CVE-2018-13379

Fortinet FortOS 中的目录遍历漏洞允许未经身份验证的攻击者通过发送特制的 HTTP 资源请求来访问和下载系统文件。“这可能会导致攻击者获得 VPN 凭据，这可能允许在目标网络中初步立足，”思科 Talos 表示。

美国国家安全局解释说，这是由于路径名对受限目录的不当限制引起的。它影响 Fortinet FortiOS 6.0.0 到 6.0.4、5.6.3 到 5.6.7 和 5.4.6 到 5.4.12。

民族国家问题仍在继续：4 月初，联邦调查局和网络安全与基础设施安全局 (CISA)警告称， APT 正在积极利用该漏洞。

## CVE-2019-9670

此错误是 Synacore Zimbra Collaboration Suite 邮箱组件中的 XML 外部实体注入 (XXE) 漏洞。攻击者可以利用它来访问凭据以进一步访问或作为进入目标网络的初始立足点。它会影响 8.7.11p10 之前的 Synacor Zimbra Collaboration Suite 8.7.x。

## CVE-2019-11510

在 Pulse Secure VPN 中，一个关键的任意文件读取缺陷使系统容易受到远程、未经身份验证的攻击者的利用，这些攻击者希望获得对受害者网络的访问权限。攻击者可以发送特制的 URI 来触发漏洞利用。它会影响 8.2R12.1 之前的 Pulse Connect Secure (PCS) 8.2、8.3R7.1 之前的 8.3 和 9.0R3.4 之前的 9.0。

“攻击者可能会滥用它来访问敏感信息，包括私钥和凭据，”思科 Talos 研究人员解释说。

去年 4 月，美国国土安全部 (DHS) 开始敦促使用 Pulse Secure VPN 的公司更改其 Active Directory 帐户的密码，此前数次网络攻击针对的是先前修补了 VPN 系列中相关缺陷的公司。

当时，国土安全部警告说，已经利用该漏洞获取受害者凭据的攻击者正在使用这些凭据在组织中横向移动，从而使补丁变得毫无用处。

然后在 9 月，对一个未命名的联邦机构的成功网络攻击归因于对该漏洞的利用。根据当时 CISA 的警报，“网络攻击者可能通过利用 Pulse Secure 中的已知漏洞 CVE-2019-11510 从未打补丁的机构 VPN 服务器获取凭据。” “CVE-2019-11510 ......允许远程、未经身份验证的文件检索，包括密码。CISA 已经观察到联邦政府对 CVE-2019-11510 的广泛利用。”

## CVE-2019-19781

Citrix Application Delivery Controller (ADC) 和网关中的这个严重目录遍历漏洞可以允许远程执行代码。它于 2019 年 12 月首次被披露为零日漏洞，此后思杰在数十个概念验证漏洞利用和激增的漏洞利用尝试中推出了补丁。

它会影响 13.0.47.24、12.1.55.18、12.0.63.13、11.1.63.15 和 10.5.70.12 之前的 Citrix ADC 和网关版本以及 SD-WAN WANOP 4000-WO、4100-WO、5051-0000000000000000000000000000000000000000000000000000000年之前10.2.6b 和 11.0.3b。

## CVE-2020-4006

最后，VMWare Workspace One Access、Access Connector、Identity Manager 和 Identity Manager Connector 中的命令注入漏洞允许在底层操作系统上执行任意命令。但是，成功的漏洞利用确实需要配置器管理员帐户的有效凭据，因此它必须与另一个错误链接才能使用它。

尽管如此，美国国家安全局在 12 月警告说，尽管补丁在几天前推出，但外国对手正在利用该漏洞。它说，国家行为者正在利用该漏洞窃取受保护的数据并滥用共享身份验证系统。

它影响 Linux 上的 VMware One Access 20.01 和 20.10、Linux 上的 VMware Identity Manager 3.3.1 – 3.3.3、VMware Identity Manager Connector 3.3.1 – 3.3.3 和 19.03、VMware Cloud Foundation 4.0 – 4.1 和 VMware Vrealize Suite Lifecycle经理 8.x。

## 如何防范网络攻击？

NSA 推荐了几种保护组织免受攻击的最佳实践：

*   补丁发布后，尽快更新系统和产品。
    
*   假设会发生违规；审查账户并利用可用的最新驱逐指南。
    
*   禁用外部管理功能并设置带外管理网络。
    
*   在网络边缘阻止过时或未使用的协议，并在客户端设备配置中禁用它们。
    
*   采取妥协发生的心态：为事件响应活动做好准备。
