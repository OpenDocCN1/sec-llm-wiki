FBI 与 Have I Being Pwned 共享已泄露的密码

FBI 很快将开始与在执法调查期间发现的 Have I Being Pwned 的“Password Pwned”服务共享泄露的密码。

Have I Being Pwned 数据泄露通知站点包括一项名为Pwned Passwords的服务，该服务允许用户搜索已知的泄露密码。

使用此服务，访问者可以输入密码并查看该密码被发现的次数。例如，如果我们输入密码“password”，该服务会声明它已在数据泄露中出现 3,861,493 次。



今天，Have I Being Pwned 的创建者 Troy Hunt宣布，FBI 将很快将在执法调查期间发现的泄露密码提供给 Pwned Password 服务。

通过提供此提要，FBI 将允许管理员和用户检查已知用于恶意目的的密码。然后，管理员可以在密码被用于凭证填充攻击和网络漏洞之前更改密码。

“我们很高兴能与 HIBP 合作开展这一重要项目，以保护在线凭证盗窃的受害者。这是公共/私人合作伙伴关系在打击网络犯罪方面的重要性的另一个例子，” - 网络助理总监 Bryan A. Vorndran部门，联邦调查局。

FBI 会将密码作为 SHA-1 和 NTLM 哈希对共享，然后可以使用该服务进行搜索或下载作为 Pwned Password 的离线密码列表的一部分。

Password Pwned 允许用户将泄露的密码下载为 SHA-1 或 NTLM 散列密码列表，Windows 管理员可以离线使用这些密码，以检查它们是否在其网络上使用。

您可以下载按字母顺序或流行程度排序的哈希列表。例如，下面的列表显示NTLM哈希值'32ED87BDB5FDC5E9CBA88547376818D4'被使用了超过2400万次。



这个 NTLM 哈希值用于密码“ 123456 ”并不奇怪。

为了促进这种新的合作伙伴关系，Hunt 通过 .NET Foundation将 Password Pwned开源，并要求其他开发人员帮助创建“密码摄取”API。

FBI 和其他执法机构可以使用此 API 将泄露的密码输入到 Password Pwned 数据库中。
