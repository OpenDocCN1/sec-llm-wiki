翻译一篇发表于北约JAPCC期刊第31期的文章《新兴技术带来的网络安全挑战》，作为国家网络空间安全建设的参考，不代表同意文章中的观点和立场。


介绍



到2020年4月末，华为与中国移动一起在千人营地附近海拔6,500 m的海拔高度``珠穆朗玛峰''的``世界屋顶''上安装了首个5G基站，提供了无价的无线服务。与登山者和研究人员的交流。在Qomolangma山（珠穆朗玛峰的藏语名称）北侧的峰会上，最高的5G塔提供高清直播，并监视环境和科学活动。

华为一直是全球信息通信技术（ICT）的领先提供商之一，并且正在全球范围内寻求5G技术的商业化，包括在中尼边境最高的山峰，炎热的沙漠等极端环境中科威特，俄罗斯亚北极地区和南美潮湿的热带稀树草原。这家IT公司中的巨头成立于1987年，是全球第二大制造商，拥有全球智能手机市场18％的份额，并拥有180,000多名员工。

最初，华为在中国南方的深圳生产用于手机网络的通信设备，由前中国人民解放军军官创建，他也是中国共产党的成员。由于华为创始人的军事背景及其作为5G蜂窝网络设备供应商的主导作用，越来越多的国家对此表示关注，并对信任其产品和服务持严重保留态度。5G网络和智能设备由于设计和制造漏洞（甚至是故意的）而造成的安全风险和威胁异常高，难以缓解。由于存在这些风险，英国国家网络安全中心（NCSC）发表了一篇评论（第14号 2020年7月）更改了对华为在国家5G网络中的存在的初步安全评估，建议政府完全禁止这家中国技术公司，并在2027年之前从英国移动提供商的网络中删除其5G套件。该决定将产生重大影响在英国推出5G技术。然而，控制这样的承诺和先进的移动网络的“敏感部位”，用了十年之久的影响的可能性，将有可能不仅是通信，但也有一些基于5G基础架构的最尖端技术的。

新兴技术



无人驾驶汽车，人工智能（AI），机器学习（ML），自动化，虚拟化，智能城市，区块链网络，大数据，物联网（IoT），感官互联网，云计算和量子计算只是其中一些目前正在开发的大多数变革性创新，这些创新正在极大地改变着社会，金融，商业和军事环境。在未来的五到十年中，这些新兴的数字技术及其所产生的复杂应用将在几乎所有日常活动中，尤其是在军事行动中，带来新的机遇并带来新的挑战。

由于5G的独特技术特性（包括比现在快十倍的数据速率），支持大量已连接设备的能力，几乎没有延迟，持续的移动性，能效和服务可靠性，因此不断开发新的工具和服务。仅由于5G的组件和功能，才有可能连接数十亿个智能设备，例如``万物万物''（X2X），从多个网络收集和分析大数据（云计算）以及建立对等网络（区块链）。技术为不断发展的新信息时代提供了条件。

例如，虚拟化是一种沉浸式技术，可以提供有效的网络卫生生态系统。它使计算环境更加独立于物理基础架构，并创建了虚拟方案。虚拟化可以与人工神经网络和其他系统一起预先确定网络的漏洞以及这些单独技术的影响，从而提供增强弹性的优势。虚拟化旨在更好地了解网络功能和漏洞。这些知识将支持网络威胁情报（CTI）跟踪恶意攻击并维持所需的安全标准。

云计算，5G技术和实时虚拟环境可以使军事训练和演习达到创新和敏捷性的新水平。可访问性和灵活性将成为新的高级移动模拟的关键功能，受训人员将根据自己的步调和自己的空间进行学习。此外，扩展现实（XR）–包括增强现实（AR），混合现实（MR）和虚拟现实（VR）–已通过小型化和增强的处理能力得到了高度发展和支持。特别是在Covid-19大流行期间，XR成为下一个无处不在的计算平台，不仅在游戏方面，而且在远程培训，零售购物，工作和社交方面，都发挥了更加重要的作用。

自2019年以来，英国陆军一直在研究一个项目，将从个人训练转变为基于XR的集体训练。使用先进的XR头戴式显示器（HMD），几十名受训人员可以在同一个虚拟世界中根据敏捷的操作需求在各种培训场景中一起操作。这种基于XR的高科技集体系统也可以部署为移动培训服务。

这导致了其在空中环境中的应用，在该环境中，通过改善人机协作和沟通，该技术对于空空作战尤为重要。为了使这种复杂的空中操作自动化，必须达到一定程度的信任，可伸缩性和自治性。人机交互建立在三个自治级别上：半自治（人在环）；人为监督的自主权（人在环）；完全自主权（人为控制外）。8自主性和智慧是确定“现实—虚拟连续性”范围，改变人类经验，增强态势意识和完善决策过程的关键因素。联合空中领域的新通信模式和无限的连通性还可以改变整个北约的指挥与控制（C2）水平，甚至可以进一步增强这种网络化操作环境的互操作性。

2020年8月20日，美国国防高级研究计划局（DARPA）完成了其AlphaDogfight试验（ADT）项目，该项目可被视为AI，虚拟化，自动化，ML和云计算等多种先进技术合作的缩影。在AI驱动的“飞行员”与经验丰富的美国空军F-16飞行员之间进行的为期三天的模拟空战“比赛”中，前者在所有五轮模拟空战中均不败。通过先进的算法，Heron Systems的F-16 AI代理快速有效地学习了如何执行人类飞行员无法比拟的激进而精确的演习。 可视范围内的空战演习（混战）清楚地表明了人们对军事航空航天环境中的AI和自主功能的兴趣日益浓厚。

网络空间挑战



无论多么明显，这些技术将在不久的将来从根本上改变人们的工作，沟通，思维甚至战斗方式，同时引起人们的极大关注，即国家资助的参与者可能会干扰和破坏其功能和服务，从而对具有战略意义的网络。5G技术可能会大大增加黑客的攻击面和进入点的数量，因为存在大量连接的设备（从婴儿监视器到冰箱和火警），但安全功能较弱。但是，不仅低成本的互连设备会引入漏洞，而且这些设备之间的通信可能是5G安全性中最薄弱的环节。根据这个理由，同样，云计算技术由计算机存储，前端技术（笔记本电脑，个人计算机），网络基础架构和基于云的应用程序组成，这些应用程序也可能被破坏和利用。大多数此类风险既适用于扩展的商业云（Google Cloud Services，Microsoft Azure，Amazon Web Services），也适用于用于分类操作和安全敏感数据的较小规模的云服务。速度和安全级别定义了不同类型的云，并取决于“非本地”和“本地”设备。但是，在利用多云功能和好处的同时，满足基本的安全需求（尤其是从军事角度而言）可能是具有挑战性的。 自主物流信息系统（ALIS）是一种复杂的，基于Web的，互连的，分布式的军事后勤服务，为世界第五代战斗机F-35 Lightning II提供支持，是在军事行动中集成先进技术的典范。

连接速度的提高以及广泛的服务和应用程序将带来大量新的安全挑战。恶意软件，网络钓鱼，中间人（MitM），分布式拒绝服务（DDoS）和社会工程学攻击每天都在增长，带来了许多挑战并感染了数字生态系统。毕竟，未来的大国竞争可能不会在战场或董事会中进行，而是会在智能手机，计算机和支持它们的数字基础设施上进行。在中国和俄罗斯这样的国家，政府和私营部门密切合作，开发和部署具有全球影响力的新技术和应用，他们认为这对他们的网络空间主权至关重要。2017年6月1日，即《中国网络安全（互联网安全）法》实施三年后，又发布了另一份题为《网络安全审查措施》的文件，为``关键信息基础设施（CII）''产品设定了安全和供应链标准规则和服务应适用。

网络威胁情报



尽管引入了更多漏洞，但新兴技术还可以通过提供有用的工具来清理网络威胁状况，从而为解决网络安全挑战提供重要帮助。例如，AI可以跨各种全球网络自动收集，分析和传播情报和有价值的信息，从而能够根据最佳预防策略指示网络攻击并缓解异常情况。CTI是所有军队从防御和进攻角度应对网络威胁的重要因素。根据2020年1月发布的网络空间作战联合联合原则（CO），“……网络空间的行动自由可能与控制陆，空，空或海一样重要。” 在日益相互联系的环境中，“在战略，运营和战术级别之间进行区分更加困难”。由于网络空间是作战领域，“需要将作战重点转移到任务保障上”。管理一个可以预测和预防网络攻击的实时，动态，复杂框架，可以真正改变游戏规则，以'确保功能和资产的持续功能和弹性……对于在任何情况下执行北约任务至关重要的功能至关重要操作环境或条件”。

有效的CTI主要处理利用ML和先进的AI技术，并通过动态的特定知识库来理解潜在的威胁以及可能促使对手发动攻击的因素。20种 精致的ML工具，再加上复杂的AI算法，可以最大程度地提高攻击归因的准确性。结合使用这两种技术可以“发现事件之间的相关性，这些事件可能是随机出现的，与人眼无关”。只有人工智能才能实时分析如此大量的信息…… ' 因此，训练AI和提供ML流程需要增加来自各种来源的数据。因此，监视用户信息并分析用户行为，设备使用情况，网络活动，位置和应用程序数据可以成为保护和威胁的来源。

令人惊讶的是，许多黑客团体在攻击军事目标或民用设施时都不会改变其程序，这使得归因成为一项简单的任务。在大多数情况下，这些参与者在部署新的自动化工具（即漫游器  ）之前，只是将其行为暂停了特定时间。基于此模式，可以使用自动化来跟踪和分析原始威胁情报提要，并提供快速而可靠的信息，这些信息可以揭示某些情况是否已随特定标准发生了变化。

ML和AI算法还可以通过将需要由人工操作人员处理和解决的安全事件和查询的数量减少到10％，从而将事件状态从“人在循环中”转移到“人在空中”，从而增强事件管理。-循环级别。此外，云服务和基础设施不仅具有存储各种来源的大量数据的固有能力，例如军用空中平台的数百个传感器[估计从IoT设备生成的每日数据超过5兆字节（10亿兆字节） ）] ，还可以建立规则和惯例集，可以在提供高安全性标准的所有不同数据集之间进行复制。令人难以置信的是，对于航空航天和国防供应链，在云环境中使用区块链技术甚至可以进一步保护和简化流程。特别是，这将为供应链中的所有组件创建“数字身份”，并能够以安全方式作为安全分类帐来跟踪链中的移动。

结论



这些新兴技术的非凡功能扩展并赋予了网络空间以超越Internet自身超连接性的能力。但是，这些突破不仅具有极大的优势。扩展的网络基础架构和增加的连接设备（甚至是未连接的设备）数量也增加了入侵的漏洞。此外，在大量与Internet连接的节点之间处理和共享的海量数据越来越成为利用和破坏的目标。

寻求开发复杂的操纵和监视方法，特别是通过利用新兴技术的国家和非国家行为者，将在未来几年内形成地缘政治领域的冲突。信息生态系统“变得受到更多的污染，细分和严格控制”， 使得民主国家更加难以建立适应力并应对外部威胁。因此， 利用新兴技术可能提供的工具和功能，协调，同步和执行网络空间和信息活动将“故意产生可比的反作用，这对于联盟在和平，危机和冲突中的成功运作至关重要”。
