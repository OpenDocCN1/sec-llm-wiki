# 趋势 | 美国国防部更新作战云战略

国防部最近开始了一项雄心勃勃的数字现代化战略，旨在在现代战场上保持竞争优势。**愿景的核心部分是国防部云战略，该战略将有助于实施新计划，支持国防战略（NDS）和其他作战任务**。

![](../Images/0948ce34a432d282d06572ede05f60d9.png)

**国防部云战略**

**云技术现在是NDS的核心，但直到最近它仍在很大程度上充当企业云**。国防部的现代化已经到了关键时刻，有效支持作战能力的云将对保持竞争优势至关重要。

![](../Images/deb5325b6770455f24afd3ee8959373d.png)

**国防部云战略使国防部数字现代化战略成为可能，而国防战略数字化战略又反过来支持国防战略和作战必要性。**（波士顿咨询集团）

国防部在过去十年中开发了具有某些独特特征的企业云。迄今为止，企业云主要建立在企业和业务用例上，包括Office 365 Government和SAP on Cloud。其次，已启用物理隔离，独特且与众不同的构建的设计原则，以维护部门的合规性和安全性指南。

![](../Images/c0cb338edc9ddefc3c105327aa0deb5b.png)

在一系列关键优先事项的推动下，围绕该技术的思维方式现在已转向建立云作为作战能力的基础。这些优先事项中的第一个是实现指数级增长，其次是大规模构建AI和应对网络挑战的需求。因此，该倡议已从一项业务转变为一项战略性的战争当务之急。但是，我们如何影响这种变化并发展呢？

### **战术云应用场景**

**1.偏远地区战术云场景**。云计算使用户可以更便宜地存储数据并远程访问数据，这是该部门数字现代化战略的核心原则。随着分布式战争的到来，该部门将需要在偏远地区可用的战术云功能。

**2.战场环境战术云场景**。军方希望在战术环境中处理诸如无人机航拍画面或车载传感器数据之类的数据，而不是将其传输回数千英里之外的数据中心，这一过程会占用宝贵的带宽并且占用过多资源时间。

**3.战斗人员战术云场景**。需求正在推动大型云提供商在远程环境中为战斗人员提供更小的服务器和处理设备方面的投资。例如，空军的高级战斗管理系统显然是需要的，该系统通过无限期交付，无限量合同使用来自供应商Microsoft和AWS的云服务。

**4.舰船环境战术云场景**。在微软，联合作战正在促使公司考虑如何将云计算功能带入相互联系且充满挑战的环境中，例如为一艘舰船配备支持云的设备或为每个战斗小组提供一个数据中心。  

**5.战术云安全访问场景**。在IBM，客户要求提供一种云环境，该环境将允许用户访问跨安全类别的数据。前国防部首席信息官兼IBM公共部门客户开发总经理Terry Halvorsen表示：“我们对更多的移动环境（包括可以在多个\[分类\]级别运行的分布式，移动环境）越来越感兴趣。” 。

  

### **实现战斗云的五个因素**

以下五个转变将影响战斗云的实现：

1.  **下一代安全模型**：AWS 政务云和Microsoft Azure 政务云之类的生态系统是符合政府初期对云模型的要求，但是，在与世隔绝的飞地和专用的基础设施上建立部署云环境，需要更多技术创新。具有合理的安全孤岛的“数字堡垒”模型必须随着云原生架构以及诸如零信任之类的下一代安全模型的结合而不断发展。
    
2.  **边缘交付和处理**：国防部将数据和计算能力更接近作战人员，从而改变了从战术核心存储，处理和交付数据的方式。强调在传感器一侧直接进行处理的好处。这些好处包括减少等待时间和增强AI决策能力，但是在边缘操作时需要更加关注安全性。
    
3.  **敏捷收购**：强大的云基础在以敏捷方式进行购买和构建方面，在快速发展能力方面发挥着至关重要的作用。在国防部为获取定制软件而开发的“软件途径运营”的指导下，获取工作也在不断发展。其次，一些服务分支现在正在建立本地云软件工厂，以加速产品开发和工程。海军黑珍珠就是一个很好的例子。
    
4.  **自动认证**：联邦风险和授权管理计划（FedRAMP）的指南以及操作授权（ATO）流程为政府系统的授权和认证提供了早期的机制。DevSecOps通过在软件开发生命周期的每个阶段以及技术堆栈的每个层中插入安全实践和控件来构建敏捷获取的基础。通过帮助自动化控制和合规性来减少摩擦。
    
5.  **全域操作**：有许多对全域操作至关重要的命令。例如，对海洋，陆地和空中作战的关注必须扩大到包括空间，网络和电磁等新领域。随着Space Force的兴起，诸如Azure Space和AWS Ground Station的产品应运而生。全域操作还保证了某些具有企业范围的服务和平台可以大规模部署，并具有通用的数据和服务结构。人工智能是这一类别中的关键用例。
    

### **三个关键动作**

为了实施这些指导原则，国防部需要在战术上多做三件事，以便针对这一愿景迅速采取行动。

**行动1：评估当前能力成熟度**

该部门应寻求重新评估关键任务核心和企业服务，以最大程度地发挥能力，为合作伙伴建立共同的环境和基础，以建立作战能力。

**行动2：采用数据和数字平台方法**

为了将数据传递给边缘人员和战斗人员，强烈建议使用数据和数字平台（DDP）的概念。DDP是一组功能，数据和技术的紧密结合，可实现大规模的用例快速交。

**行动3：启用战斗能力并朝北极之星迈进**

利用用例驱动的方法来开发作战能力，利用云基础和现代支持者至关重要。现在是时候根据战机的成本和价值来调整优先级了。这意味着将重点放在近期任务成果和数字能力上。
