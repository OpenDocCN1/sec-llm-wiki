# 案例 | 城市网络攻击威胁-电网攻击

2015年去年12月23日下午，乌克兰西部伊凡诺-弗兰科夫斯克地区的居民正准备结束工作日，并穿越寒冷的冬季街道。在Prykarpattyaoblenergo控制中心内，该中心将电力分配给该地区的居民，运营商也正接近他们的轮班结束。但是，就在那天有一个工人在办公桌上整理文件时，计算机上的光标突然突然跳到了屏幕上。  

  

他看着它有目的地导航到该地区变电站中控制断路器的按钮，然后单击一个框以打开断路器并使该变电站脱机。屏幕上弹出一个对话窗口，要求您确认操作，操作员凝视着目瞪口呆的光标，光标滑到该框上，然后单击以确认。某处在城市外的区域，他知道，数以千计的居民刚刚失去了他们的灯和加热器。

  

操作员抓住他的鼠标，拼命试图抓住光标的控制权，但是它没有反应。然后，当光标朝另一个断路器的方向移动时，机器突然将他从控制面板中注销。尽管他疯狂地尝试重新登录，但攻击者更改了密码，阻止他重新输入。他所能做的就是无奈地盯着他的屏幕，而机器中的鬼魂又一个又一个地按一下断路器，最终使大约30个变电站脱机。攻击者并没有就此止步。他们还同时袭击了另外两个配电中心，使离线变电站的数量几乎翻了一番，使超过23万居民陷入了黑暗。好像还不够，

  

**辉煌的计划**

袭击了乌克兰电力中心的黑客-第一个确认的黑客砍倒了电网-不会是偶然的机会主义者，只是偶然发生在网络上并发动了攻击以测试其能力；根据对黑客行为进行广泛调查的新细节，他们是熟练而隐秘的战略家，他们精心策划了几个月的攻击，首先进行侦察以研究网络和虹吸管操作员的凭据，然后在精心设计的舞蹈中发动同步攻击。

  

“这真是太好了，”协助调查的罗伯特·M·李说。Lee是美国空军的前网络战运营官，并且是关键基础设施安全公司Dragos Security的共同创始人。他说：“就复杂程度而言，大多数人总是\[专注于\]攻击中使用的恶意软件。” “对我而言，使尖端技术变得成熟的是物流，计划和运营以及……在整个过程中发生了什么。这是非常复杂的。”

  

乌克兰很快就将矛头指向了俄罗斯。Lee拒绝将其归因于任何演员，但表示在行动的各个阶段之间有明确的界限，表明不同级别的演员在袭击的不同部分工作。这就增加了攻击可能涉及完全不同的各方（可能是网络犯罪分子和民族国家行为者）之间协作的可能性。

  

“这必须是一支资金雄厚，训练有素的团队。…\[但是\]它不必是一个民族国家，”他说。最初可能是网络罪犯获得了最初的网络访问权，然后将其移交给了进行其余工作的民族国家攻击者。

  

  

  

  

  
专家说，无论如何，成功的袭击为美国的发电厂和配电中心提供了许多教训。相比之下，乌克兰的控制系统比美国的控制系统更安全，这是因为它们已从具有强大防火墙的控制中心业务网络中很好地进行了细分。但是最终他们仍然不够安全-远程登录SCADA网络，控制网格的监督控制和数据采集网络的工作人员不需要使用双重身份验证，这使攻击者能够劫持他们的凭据并获得对控制断路器的系统的关键访问权限。

  

乌克兰的电力并没有很快耗尽：所有受灾地区仅需一到六个小时。但是，根据美国最近的一份报告，在袭击发生两个多月后，控制中心仍未完全运作。参与调查的乌克兰和美国计算机安全专家说，攻击者重写了16个变电站中关键设备上的固件，从而使他们无法响应操作员的任何远程命令。电源已打开，但工人仍必须手动控制断路器。

  

专家说，这实际上比美国可能会有更好的结果，因为这里的许多电网控制系统没有手动备份功能，这意味着如果攻击者在这里破坏自动化系统，对工人来说可能会更难恢复力量。

  

**攻击时间表**

美国的多个机构（包括联邦调查局和国土安全部）帮助乌克兰人调查了这次袭击。在接受更广泛调查的计算机安全专家中，有Lee和Michael J. Assante，他们俩都在华盛顿特区的SANS研究所教授计算机安全，并计划今天发布有关其分析的报告。他们说，调查人员惊喜地发现乌克兰的配电公司拥有大量的防火墙和系统日志，可以帮助他们重建事件，这对任何公司网络来说都是罕见的盛事，但对于关键基础设施环境而言却很少见。很少具有强大的日志记录功能。

  

根据Lee和协助调查的乌克兰安全专家的说法，攻击始于去年春季的鱼叉式网络钓鱼活动，该攻击针对的是IT员工和系统管理员，这些员工在多个负责乌克兰各地配电的公司工作。乌克兰有24个地区，每个地区分为11至27个省，每个地区都有一家不同的配电公司。网上诱骗活动向附有恶意Word文档的三家公司的员工发送了电子邮件。当工作人员单击附件时，将显示一个弹出窗口，要求他们启用文档的宏。如果他们遵照执行，一个名为BlackEnergy3-的程序（会感染欧洲和美国的其他系统）会感染他们的计算机，并为黑客打开了后门。该方法之所以引人注目，是因为这些天来大多数入侵都利用了软件程序中的编码错误或漏洞。但是在这种情况下，攻击者利用了Microsoft Word程序中的有意功能。利用宏功能是90年代的老派方法攻击者最近经历了多次攻击。

  

最初的入侵仅使攻击者到达公司网络。但是他们仍然必须使用控制网格的SCADA网络。两家公司明智地将这些网络与防火墙隔离开来，因此，攻击者只有两个选择：要么找到可以让他们冲破防火墙的漏洞，要么找到另一种进入防火墙的方法。他们选择了后者。

  

在几个月的时间里，他们进行了广泛的侦察，探索和映射网络并获得对Windows域控制器的访问，在Windows Domain Controllers中管理网络的用户帐户。他们在这里收集了工作人员凭证，其中一些用于网格工作人员用来远程登录SCADA网络的VPN。一旦进入SCADA网络，他们就会慢慢为攻击做好准备。

  

首先，他们重新配置了不间断电源1或UPS，它负责为两个控制中心提供备用电源。仅仅让客户陷入困境是不够的-当大范围地区的电力中断时，他们也希望运营商保持盲目性。李说，这是一个令人震惊和激进的举动，对于电力公司而言，这种举动可被解释为“大操蛋”。

  

每个公司的网格使用不同的分发管理系统，在侦察阶段，攻击者仔细研究了每个网格。然后，他们编写了恶意固件，以替换十几个变电站中的串行到以太网转换器上的合法固件（这些转换器用于处理从SCADA网络发送到变电站控制系统的命令）。一旦发生断电，取出转换器将阻止操作员发送远程命令来重新合闸断路器。Lee说：“在工业控制环境中，*从未*进行过针对特定操作的恶意固件更新，” Lee说。“从攻击的角度来看，这真是太棒了。我的意思是他们做得很好。”

  

美国配电网使用的是乌克兰使用的相同型号的串口转以太网转换器。

配备了恶意固件的攻击者已准备好进行攻击。

  

在12月23日下午3:30左右的某个时间，他们通过被劫持的VPN进入SCADA网络，并发送命令以禁用已经重新配置的UPS系统。然后他们开始打开断路器。但是在这样做之前，他们对客户呼叫中心发起了电话拒绝服务攻击，以防止客户致电报告中断情况。TDoS攻击类似于DDoS攻击将大量数据发送到Web服务器。在这种情况下，该中心的电话系统充斥着似乎来自莫斯科的数千个虚假电话，以防止合法呼叫者通过。Lee指出，此举说明了攻击者的高度复杂性和计划性。网络犯罪分子，甚至某些民族国家行为者，往往都无法预料所有突发事件。他说：“精明的演员所做的是，他们甚至在不太可能的情况下共同努力，以确保他们涵盖了可能出问题的所有方面。”

  

此举无疑使攻击者有更多时间完成任务，因为当劫持机器的操作员注意到发生了什么事时，许多变电站已经被拆除。但是，如果这*是*俄罗斯对乌克兰发动的政治攻击，则TDoS可能还有另一个目标，李和阿桑特说：激怒乌克兰客户，削弱他们对乌克兰电力公司和政府的信任。

  

  

  

当攻击者打开断路器并从电网中移走一连串的变电站时，他们还重写了一些变电站串行到以太网转换器上的固件，用其恶意固件替换了合法固件，并使转换器此后无法操作且无法恢复，无法使用接收命令。“一旦……重写固件，就不会再回头了（以帮助恢复）。您必须在该站点上并手动切换操作。” Lee说。“对这些网关进行固件修改后，就意味着它们无法恢复，除非他们获得新设备并对其进行集成。”

  

完成所有这些操作后，他们随后使用一种称为KillDisk的恶意软件来擦除操作员站中的文件，从而使它们也无法使用。KillDisk擦除或覆盖基本系统文件中的数据，从而导致计算机崩溃。因为它还会覆盖主启动记录，所以受感染的计算机无法重新启动。

  

一些KillDisk组件必须手动设置，但是Lee说在两种情况下，攻击者使用了逻辑炸弹，该炸弹在攻击发生约90分钟后自动启动了KillDisk。大约在下午5点左右，与此同时Prykarpattyaoblenergo在其网站上发布了便条，这是第一次确认客户已经知道的信息-某些地区已经断电-并向他们保证发烧是发狂的找出问题的根源。半小时后，KillDisk完成了肮脏的契约，并让电力运营商对造成大面积停电的原因几乎没有疑问之后，该公司随后向客户发布了第二张便条，称中断的原因是黑客。

  

**俄罗斯是原因吗？**

乌克兰情报界已完全确定说，俄罗斯是这次袭击的幕后黑手，尽管它没有提供证据支持这一说法。但是考虑到两国之间的政治紧张关系，这并不是一个牵强的方案。自从俄罗斯于2014年吞并克里米亚以来，俄罗斯与乌克兰之间的关系就变得紧张起来，克里米亚当局开始将乌克兰拥有的能源公司收归国有，这激怒了乌克兰所有者。然后，就在12月乌克兰大停电发生之前，亲乌克兰的激进分子攻击了向克里米亚供电的变电站，在俄罗斯吞并的地区和俄罗斯海军基地造成200万克里米亚居民无电。人们普遍猜测，乌克兰随后的停电是对克里米亚变电站的袭击的报复。

  

但是针对乌克兰电力公司的攻击者至少在攻击克里米亚变电站之前六个月就开始了行动。因此，尽管克里米亚的袭击可能是随后袭击乌克兰电力公司的催化剂，但很显然，这并不是最初的动机。李说，法医证据实际上表明，攻击者可能并没有计划在乌克兰夺取政权的时候，而是在克里米亚袭击后匆忙了计划。

  

他说：“查看数据，如果他们计划和收集情报的时间更长，他们似乎会受益并能够做更多的事情。” “因此看来他们可能已经赶上竞选了。”

他推测，如果俄罗斯对这次袭击负责，其推动力可能完全不同。例如，最近，乌克兰议会一直在考虑一项法案，以对乌克兰的私有电力公司进行国有化。其中一些公司由与普京有密切联系的强大的俄罗斯寡头所拥有。李说，对乌克兰电力公司的袭击可能是向乌克兰当局传达的一个信号，即不要实行国有化。

  

这种分析得到了攻击的另一个方面的支持：事实上，如果黑客也决定物理上破坏变电站设备，那么造成的损害可能比他们所遭受的损害要大得多，这使得停电后恢复供电变得更加困难。美国政府在2007年发生了一次攻击，该攻击显示了黑客如何仅通过远程发送21行恶意代码即可物理破坏发电机。

  

李说，有关乌克兰电网攻击的一切都表明它的主要目的是发送信息。他解释道：“'我们希望被别人看到，我们想向您发送消息，'。” “这很像黑手党，哦，你认为你可以带走克里米亚的力量？好吧，我可以带走你的力量。”

  

不管停电的意图是什么，它都是首例攻击，为各地电网的安全保障树立了不祥的先例。Prykarpattyaoblenergo的操作员不知道那一天他的鼠标光标有什么闪烁。但是现在已经警告负责世界电源的人们。这种攻击是相对短暂且良性的。下一个可能不是。
