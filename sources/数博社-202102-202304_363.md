# 论剑 | 突破和攻击模拟（BAS）技术

突破和攻击模拟（BAS）技术通过模仿基于多向量方案的现实的完整网络攻击周期，来作为您可信赖的“对手”，以此来测试公司的网络弹性。

Gartner将突破和攻击模拟（BAS）技术定义为工具：

> “这允许企业使用软件代理，虚拟机和其他手段，持续，一致地模拟针对企业基础架构的整个攻击周期（包括内部威胁，横向移动和数据泄露）。”

根据《全球市场展望》，BAS市场在2018年占了93.94百万美元，预计到2027年将增长到16.6十亿美元，复合年增长率为37.8％。以下是两（2）个因素将推动该市场的增长：

*   优先考虑安全投资
    
*   管理漏洞的复杂性
    

**好的BAS技术应回答以下问题：**

*   我的重要资产是否真正安全？
    
*   如何在合理的时间范围内检测，预防和缓解从突破点到关键资产的网络攻击？
    
*   我可以用最少的精力反复测试我的安全控制，包括人员，流程和技术吗？
    
*   我可以对组织的关键资产进行“安全”的APT网络攻击吗？
    
*   如何确定已发现漏洞的补救步骤的优先级？
    
*   我可以为要验证安全控制的优先级/自定义要运行的网络攻击方案的优先级/自定义？
    

  

方法步骤

**BAS基于以下模拟攻击生命周期的步骤：**

*   扫描资产
    
*   利用资产
    
*   对其他资产重复上述两个步骤
    

  

![](../Images/0ad0e11b2548bd24ed608e6e058dcc3b.png)

为了模仿对手，BAS技术正在考虑以下攻击生命周期框架或它们的组合。

![](../Images/32964e1e942dcaf952b84efa7f4a4400.png)

**攻击生命周期框架可以帮助组织：**

*   了解针对网络攻击的安全风险
    
*   评估并验证人员，流程和技术在网络攻击期间的行为是否符合预期
    
*   在人员，流程和技术方面，计划和优先考虑其环境中的安全性改进，以便在将来抵御网络攻击
    

此外，它利用MITER ATT＆CK®框架来描述众所周知的TTP。

  

![](../Images/4c29ec7dadb8442f92c3a4a9bca95eec.png)

  

MITER ATT＆CK®帮助组织了解攻击事件的阶段。该项目于2013年开始，目的是记录基于现实世界观察结果的全球范围内的对手战术和技术知识库。**该框架可以用作清单，并构建不同的攻击模拟方案，以测试是否可以检测或阻止以下快照，攻击向量**：

*   网络钓鱼，鱼叉式网络钓鱼和鲸鱼式网络钓鱼攻击
    
*   身份验证攻击
    
*   恶意程序创建
    
*   流程注入攻击
    
*   持久性方法
    
*   来自可疑进程的网络出站/入站连接
    
*   命令与控制（信标，持久性网络出站访问）
    
*   通过不同的秘密渠道（HTTP，DNS，ICMP，SMTP等）进行数据虹吸
    
*   模拟整个APT组，例如APT29，钴组，深熊猫，Drangonfly，Equation，浑水，OilRig，Turla等，以测量您的网络安全状况
    
*   …
    

**一个概念性的网络攻击模拟方案可以是：**

*   运行模拟方案
    
*   测试任何检测或预防控制
    
*   收集所有证据，包括分别优先考虑的漏洞，相关TTP和优先考虑的补救步骤
    
*   开发更好（或增强）的检测或预防控制
    
*   重复场景
    

  

![](../Images/33701acdae5ddd80ae6dd62663390dcd.png)

  

# 主要好处

*   持续模拟针对整个杀伤链框架的网络攻击
    
*   挑战并衡量您已经部署的安全控制技术
    
*   测试您的安全操作，威胁搜寻和事件响应准备能力
    
*   根据已知的TTP验证您的安全状态
    
*   优先确定已发现的漏洞
    
*   优先考虑任何补救措施
    
*   在业务期限内向管理层显示风险
    
*   快速的安全投资决策和计划
    

  

# BAS供应商

尽管市场很新鲜（大约4-5年），但BAS市场似乎仍然很拥挤。我找到了16个商业供应商，加上至少8个开源项目。

# 结论

BAS技术将继续存在。BAS技术似乎是防御测试的宝贵补充，并且肯定会增强整个漏洞管理过程。这些工具的想法是以循环方式测试检测和预防安全控制。这些自动化工具不同于自动渗透测试开发工具，例如具有抗扰性和Core Impact的CANVAS由核心安全。这些具有传奇色彩的工具为渗透测试人员提供了轻松利用服务的机会。另一方面，BAS工具用于运行端到端网络攻击场景或“ APT”活动的模拟。这些工具将根据各种众所周知的策略，技术和程序（TTP）来识别漏洞和安全漏洞，从而全面掌握公司的安全状况。
