**斯诺登曝光的美军《关键得分》计划项目被称为美军网络空间作战搜索引擎，通过该搜索引擎可以检索到任何人的网络资产及网络行踪信息，本期就为读者介绍一下该计划的相关情况。**

***01***  

**网络安全风云榜**

 

**《关键得分》计划概况**

 

**【项目目标】**

  

X-KEYSCORE是NSA绝密项目之一，可以对各种网上行为进行监视和分析处理的系统，是与谷歌功能类似的分布式数据采集和分析框架。X-K EYSCORE 将其他项目筛选出的数据包进行分析处理为NSA人员提供分析和搜索的功能，斯诺登将该系统描述为一个搜索引擎，该引擎提供了“一站式服务”，用于访问内容，元数据以及实时跟踪和监视用户活动，从而实现对网络空间攻击目标的发现与确定。

  

![](../Images/1e1a7d95af52f695010cc1521de4bbb2.png)

  

**【全球部署】**  

  

X-KEYSCORE在全球150个站点有700台服务器（2013年数据），可对3天内的数据进行暂存，被称为NSA的谷歌系统。分析人员可以通过姓名、电话号码、IP地址、浏览器等多种关键字来查找目标网络活动的内容数据和元数据。凭借该系统，NSA可对互联网上特定目标的一举一动尽收眼底。据报道，仅2008年以前，X-KEYSCORE就协助定位了300余名恐怖分子。

  

![](../Images/3ef18d969c20aa3bf85591ce3e65ad25.png)

  

  

                            

**【数据源】**

  

1.  CIA / NSA特别收件服务（F6）；
    
2.  NSA特殊来源操作（例如PRISM，MUSCULAR和INCENSER）。
    
3.  外国卫星数据（FORNSAT）。
    
4.  MARINA元数据存储库。
    
5.  TRAFFICTHIEF元数据存储库。
    

与其他许多情报机构共享对XKEYSCORE的访问权限。2012年，GCHQ的TEMPORA程序是XKEYSCORE数据（EFF01）的最大来源。

  

**【关联项目】**

1.  PRISM –用于通过FBI从服务提供商处收集内容和元数据的NSA程序。
    
2.  MUSCULAR – GCHQ程序，用于从服务提供商数据中心收集批量数据。
    
3.  INCENSER – GCHQ程序，用于从光纤电缆收集批量数据。
    
4.  TEMPORA – GCHQ程序，用于批量数据收集和缓冲。
    
5.  TRAFFICTHIEF – NSA存储库，用于存储有关选定目标的元数据。
    
6.  MARINA –用于批量Internet元数据的NSA存储库。
    
7.  PINWALE –选定内容的NSA存储库。
    

 

***02***

**网络安全风云榜**

 

**《关键得分》计划原理**

 

**【主要功能】**

a)    吸收国家安全局和合作伙伴机构的大量收集计划中的“全部摄入量”。

b)    联合查询机制允许分析师使用单个查询来搜索多个数据库。

c)    内容和元数据可以使用“强选择器”和“软选择器”进行搜索。

d)    可以创建用于匹配特定种类数据的规则，并将其存储在系统中。

e)    可以通过监视网络流量来识别容易受到攻击的计算机系统。

f)     文档可以追溯到其作者。

g)    生活模式分析可以建立个人资料或找到与个人资料匹配的个人。

  

![](../Images/fafb3193e61a5344fa494b196b009de6.png)

   

该系统结合了用户界面，数据库和算法，以选择其他监视程序已经收集的特定类型的内容和元数据。可以使用“强选择器”（例如电子邮件地址）和“软选择器”（例如关键字）（ACU01）检索数据。可以创建用于标识特定种类数据的规则，并将其存储在系统中。例如，分析人员可以通过规则来选择Tor用户，这些规则选择与Tor相关的网络搜索以及与Tor网络（NDR01）的连接。XKEYSCORE还具有提醒分析人员特定电子邮件和IP地址活动的功能。

  

**【AppID，指纹、微插件】**

除非以一种可以搜索的方式整理和组织原始数据，否则收集大量原始数据不是很有用。为了解决此问题，XKEYSCORE从原始数据中提取并标记元数据和内容，以便分析人员可以轻松地对其进行搜索。

 

这是通过使用称为GENESIS的自定义编程语言编写的称为appID，指纹和微插件的规则字典来完成的。其中的每一个都可以由类似于目录树的唯一名称来标识，例如“ mail / webmail / gmail”，“ chat / yahoo”或“ botnet / blackenergybot / command / flood”。

 

一份详细介绍XKEYSCORE appID和指纹的文档列出了几个示例。Windows Update请求似乎属于“ update\_service / windows” appID，而正常的Web请求属于“ http / get” appID。XKEYSCORE可以使用“旅行/ airblue”指纹自动检测Airblue的旅行路线，并使用“浏览器/手机/ iphone”指纹自动检测iPhone Web浏览器的流量。

当新的流量流入XKEYSCORE群集时，系统将针对这些规则中的每一个测试被拦截的数据，并存储流量是否与模式匹配。2010年的幻灯片演示说XKEYSCORE包含近10,000个appID和指纹。

  

![](../Images/51876a10a4df3681c3f0ebee6820fca0.png)

  

AppID用于识别被拦截的流量协议，而指纹则可以检测特定类型的内容。每个截获的流量流最多可以分配一个appID和任意数量的指纹。您可以将appID视为类别，将指纹视为标签。

 

如果多个appID与单个流量匹配，则选择“级别”最低的appID（级别较低的appID比级别较高的appID更具体）。例如，当XKEYSCORE评估来自Yahoo邮件的文件附件时，以下幻灯片中的所有appID将适用，但是只有“ mail / webmail / yahoo / attachment”将与此流量相关联。

  

![](../Images/043f6617de5dceefe08abd47a10feea3.png)

  

为了将它们结合在一起，当阿拉伯语用户登录到Yahoo电子邮件地址时，XKEYSCORE将存储“ mail / yahoo / login”作为关联的appID。该流量将与“邮件/阿拉伯”指纹（表示语言设置）以及“邮件/ yahoo / ymbm”指纹（检测Yahoo浏览器cookie）匹配。

  

![](../Images/03048cd96bad11564795bc5479920b94.png)

  

有时，GENESIS编程语言在很大程度上依赖于布尔逻辑，正则表达式和一组简单函数，但其功能却不足以进行检测某些类型的流量所需的复杂模式匹配。在这种情况下，正如一张幻灯片所言，“高级用户可以使用C ++来表达自己。” 用C ++编写的AppID或指纹称为微插件。

 

这是“僵尸网络/ conficker\_p2p\_udp\_data”的微插件指纹的示例，这是棘手的僵尸网络流量，没有复杂的逻辑就无法识别。僵尸网络是被黑客入侵的计算机的集合，有时是数以百万计的计算机，这些计算机是从一个点进行控制的。

  

![](../Images/a0d8f9fa5d95c46248edb0e7e27f5f8a.png)

  

这是另一个使用C ++来检查拦截的Facebook聊天消息并提取详细信息（如关联的电子邮件地址和聊天消息的正文）的微插件。

  

![](../Images/0b64f612cbc18038d51e89f81a365577.png)

  

2009年的一份文档详细描述了四代的appID和指纹，它们仅能扫描拦截的流量中的关键字，最后以编写可在数小时内部署到全球现场站点的复杂微插件的能力结束。

 

**【功能插件】**

X-Keyscore 中包含了如下功能插件：

1.    E-mail 地址插件：通过用户名和域名来索引会话中的所有E-mail 地址

2.    提取文件插件：通过文件名和扩展来索引会话中的任何(来自：湖北教育网www.edu-hb.com)文件

3.    完整日志插件：索引收集到的每个 DNI 会话。通过标准的N-tupple(IP、端口、Casenotation)来索引数据

4.    HTTP 解析器插件：索引客户端 HTTP 流量(然后跟踪)

5.    电话号码插件：索引会话中的每个电话号码(例如电话本或签名处的号码)

6.    用户活动信息插件：索引 Webmail 和聊天内容，包括用户名、在线好友、特定 cookies 等。

**网络安全风云榜**

 

**《关键得分》项目定位**

 

DNI（互联网情报数据）发现的四个层次，Xkeyscore是最上层，而最底层叫做“Trafficethief流量窃取”，属于网络数据分析层次，然后层层分析，包括内容分析、行为分析，最后将这些分析结果通过Xkeyscore展示出来。

  

![](../Images/61b790f00010d95d91a425f28db820b7.png)

 

**X-KEYSCORE在建设中也充分引入了民间技术能力，例如大数据公司Palantir的海量数据分析和可视化分类服务能力为X-KEYSCORE提供了有力支撑**。
