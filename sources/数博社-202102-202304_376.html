勒索软件2020：影响全球组织的攻击趋势

勒索软件是所有行业和地区的组织所面临的最棘手（也是最常见）的威胁之一。而且，勒索软件攻击事件继续增加。同时，勒索软件威胁参与者正在调整其攻击模型，以适应组织为从这些攻击中恢复而做出的改进。

截至2020年9月，今年IBM Security X-Force事件响应中有四分之一的攻击是勒索软件造成的。勒索软件事件似乎在2020年6月爆发。当月，IBM Security X-Force今年迄今为止已纠正了所有勒索软件攻击的三分之一。

图1：X-Force在2020年分析的勒索软件相对攻击量（来源：IBM Security X-Force）

对于IBM Security X-Force而言，勒索软件在2020年的重要性因这种攻击类型给全球范围内的企业造成的沉重损失而凸显。随着勒索需求的增加和将勒索软件与数据盗窃和勒索技术相结合的攻击，这一损失变得更加沉重

热点现象


  • 赎金的需求呈指数增长。在某些情况下，IBM Security X-Force的赎金要求超过4000万美元。

  • Sodinokibi勒索软件攻击是IBM Security X-Force在2020年迄今已响应的勒索软件事件中的三分之一。

  • 攻击者发现学校和大学成为勒索软件攻击的更具吸引力的目标，尤其是当他们以虚拟方式开始上课或由于COVID-19而在混合环境中进行实验时。

  • 在2020年针对所有勒索软件攻击的41％IBM Security X-Force中，这些攻击是针对具有运营技术（OT）网络的组织的。

这篇文章将重点介绍IBM Security X-Force最经常观察到的勒索软件类型。它还将涉及勒索软件攻击技术中一些更令人关注的趋势，例如勒索软件和勒索软件混合攻击，以及公司可以采取哪些措施来应对这种新的猛攻，而这种猛烈攻击可能是对其运营造成的毁灭性威胁。

勒索软件攻击趋势

从2020年第二季度的数据来看，与上一季度相比，IBM安全X-Force事件响应得到的勒索软件攻击数量翻了三倍还多。它们代表了我们团队在2020年4月至2020年6月期间应对的事件的32％。

目标

在目标方面，IBM Security X-Force观察到勒索软件攻击的总体变化。勒索软件对制造公司的打击最大。这些占今年到目前为止已响应的所有事件的近四分之一。专业服务部门是第二大针对性行业，已经遭受了17％的勒索软件攻击。政府组织以13％的攻击率排在第三位。

对这三个行业的攻击表明，勒索软件威胁参与者正在寻找对停机时间容忍度较低的受害者，例如制造网络。要求高正常运行时间的组织每天可能会因运营中断而损失数百万美元。因此，他们更有可能支付赎金以重新获得对数据的访问并恢复操作。

除了这些领域外，IBM Security X-Force还注意到整个2020年对学术机构的勒索软件攻击呈上升趋势。特别是当学校和大学以虚拟方式开始上课或由于COVID-19而在混合环境中进行实验时，攻击者发现他们可以成为勒索软件攻击的诱人目标。

一个集群在五月和2020年6月袭击高校已扩大到在八月和九月的其他学术机构，与大学支付赎金范围从$ 400,000到$ 1百万，希望在教师，学生和研究的敏感信息不被公开发布。

地理位置

尽管勒索软件攻击继续遍及世界的各个角落，但今年迄今为止，亚洲和北美受到的打击最大。它们分别占IBM Security X-Force在2020年响应的勒索软件攻击的33％和30％。

在最近几个月中，欧洲也经历了勒索软件的大量活动，占IBM Security X-Force事件响应小组修复的攻击的27％。这些数字表明，尽管勒索软件攻击通常在地理上是不可知的，但它们往往将重点放在他们可以针对的企业人口密度更高的地区。

2020年不断发展的勒索软件策略

在IBM Security X-Force进行的补救中，勒索软件攻击技术和方法出现了一些令人担忧的趋势。其中，最令人担忧的是对混合勒索勒索软件混合攻击的新关注，即攻击者在加密之前会窃取公司的敏感信息。如果受害者选择不支付解密密钥的费用，攻击者将威胁要公开释放被盗的信息。

这种策略使许多受害者陷入了22级陷阱的境地。即使他们能够从备份中还原加密的文件，他们也可能遭受数据泄露，数据丢失和客户记录的损失，并且必须支付监管罚款，更不用说修复受损的声誉。在某些情况下，怀疑攻击者是根据组织必须支付的监管罚款来命名赎金的，这是使他们考虑支付费用的另一种压力策略。

随着攻击者实际上窃取公司数据，勒索软件攻击也已成为数据泄露，并伴随着此类事件带来的相关风险和隐患。这种趋势迫使安全管理人员重新评估风险，并相应地调整事件响应，灾难恢复和业务连续性计划。

Sodinokibi：与有组织犯罪集团ITG14相关

IBM Security X-Force在2020年最经常看到的勒索软件病毒是Sodinokibi（也称为REvil），这是一种勒索软件即服务（RaaS）攻击模型，今年已利用混合勒索软件和勒索攻击进行攻击。

该恶意软件参与了勒索软件和数据盗窃攻击，在某些情况下，其运营商无法强迫受害者付款时，其操作员偷走并拍卖了互联网上的敏感数据。

2020年，Sodinokibi占所有IBM Security X-Force勒索软件使用量的29％，这表明与其他勒索软件相比，Sodinokibi参与者更擅长获取受害者网络。


图2：2020年按IBM Security X-Force参与度排名靠前的攻击勒索软件系列（来源：IBM Security X-Force）

根据我们的分析，自2019年4月成立以来，Sodinokibi至少宣称拥有140个受害组织，其主要行业目标包括批发业（19％），制造业（18％）和专业服务业（16％）。美国组织受Sodinokibi的打击最大，约占遭受其攻击的组织的60％，其次是英国，澳大利亚和加拿大。

根据IBM Security X-Force的估计，超过36％的Sodinokibi受害者已经支付了赎金，而12％的受害者在黑暗的网络拍卖中出售了敏感数据。在这些拍卖中，数据价格从5,000美元到超过2000万美元不等。此外，我们评估了至少32％的Sodinokibi勒索软件受害者已被使用该勒索软件的人泄露了数据。

我们的研究还表明，Sodinokibi攻击者在确定赎金请求时会考虑受害组织的年收入，已知请求的金额为受害公司年收入的0.08％至9.1％。该组织似乎将其索要的赎金数额调整为一个受害者组织，Sodinokibi索要的最高赎金数额为4,200万美元，最低的约为1,500美元。我们对2020年Sodinokibi勒索软件利润的保守估计至少为8100万美元。

在我们对Sodinokibi勒索软件的研究中，我们发现了证据表明ITG14（与FIN7共享战役重叠）是至少一个与这些攻击有关的附属组织。在调查了与Sodinokibi勒索软件攻击相关的Carbanak后门之后，我们发现该Carbanak示例类似于新的Carbanak 64位变体，该变体已与ITG14工具和技术相关联。我们还评估了该样本仅由小组使用。这使我们得出结论，ITG14至少是一个与Sodinokibi RaaS提供商签约以提供这些攻击的附属组织。

迷宫：使用Buer装载机

IBM Security X-Force还观察到2020年持续的Maze勒索软件攻击，占今年迄今为止观察到的勒索软件攻击的12％。Maze还使用RaaS和混合勒索勒索软件模型，并在公共博客上宣传其受害者-与Sodinokibi相似。迷宫在专业服务部门中将目标锁定为受害者，大部分袭击了北美和欧洲的组织。

在RaaS模型下，多个威胁组正在向组织提供Maze勒索软件，从而创建了可以与Maze勒索软件相关联的多种策略，技术和程序（TTP），这已被多家安全厂商所强调。在这些TTP中，IBM Security X-Force观察到了一种潜在的新发现策略：使用代码签名的Buer Loader来维持立足点。Buer装载机于2019年底首次出现在黑暗的网络上出售，并且已收到一些更新。它能够下载和执行其他有效负载，建立持久性并通过HTTPS协议进行通信。攻击者还可能使用Buer Loader下载并安装了Cobalt Strike，这是2020年在Maze攻击中使用的非常常用的工具。

蛇/ EKANS：对工业控制的新威胁

2020年最令人关注的勒索软件品种之一是EKANS，即SNAKE（反拼写为EKANS），最早于2019年12月中旬发现，占2020年迄今IBM Security X-Force所观察到的勒索软件攻击的6％。

EKANS勒索软件能够杀死受害设备上的几个关键进程，包括与工业控制系统（ICS）操作直接相关的某些进程。鉴于与其他勒索软件相比，该勒索软件可能对物理过程产生更大的影响，因此此功能对ICS和连接OT的系统具有重要意义。由于2020年IBM Security X-Force观察到的所有勒索软件攻击中有41％是针对与OT连接的行业的，因此潜在的EKANS攻击的影响是巨大的。

IBM Security X-Force对EKANS勒索软件样本的分析表明，它是使用Go编程语言（一个开源项目）编写的。第一步，勒索软件尝试解析受害者的内部域名。如果勒索软件无法解析域名，它将使用此步骤作为终止开关并终止。此外，该恶意软件会在加密过程发生之前搜索几个与ICS硬编码相关的过程，以终止该过程。该恶意软件的这一方面类似于MegaCortex，IBM Security X-Force已对其进行了分析，对其进行了一些修改。实际上，除了数十种之外，在MegaCortex勒索软件中还可以找到EKANS被设计用来杀死的十二种硬编码进程。

打击勒索软件攻击

2020年的勒索软件攻击方法在许多方面使受害者处于比我们之前观察到的更加困难的境地。随着时间的流逝，使用勒索软件勒索受害者的人的需求增加，在某些情况下增加到4000万美元以上。一些勒索软件将攻击与勒索技术结合在一起，以公司最关键的系统和流程为目标。

如果攻击者能够进入网络，加密文件并威胁要泄漏被盗的数据，则某些组织可能会倾向于支付赎金。决定付款的因素很多，并且没有一个单一的演算适用于所有组织。

“ FBI不支持为勒索软件攻击而支付勒索。支付赎金并不能保证您或您的组织会取回任何数据。它还鼓励犯罪者将更多的受害者作为目标，并鼓励其他人卷入这种非法活动。”


如果您的组织一直是勒索软件的受害者，我们建议您寻求一种可以恢复数据并减轻声誉损失的解决方案，而不是向攻击者付款。在勒索软件攻击的某些情况下，IBM Security X-Force恶意软件反向工程师已经能够创建定制解密器来恢复加密文件。尽管这种解决方案往往是例外而不是规则，但它强调了在诉诸勒索赎金之前探索各种选择的重要性。

赎金付款会鼓励攻击者继续其活动，验证其业务模型并激励其他网络犯罪分子参与此类攻击活动。但是，即使在这些困难的情况下，公司也可以采取一些措施来帮助降低风险并最大程度地减少损失。

  • 建立和维护离线备份。确保具有只读访问权限的攻击者可访问性安全地存储了文件。对于组织而言，备份文件的可用性是一个重要的差异因素，可以帮助他们从勒索软件攻击中恢复。

  • 实施一项策略以防止未经授权的数据被盗，尤其是在将大量数据上传到攻击者可能滥用的合法云存储平台上时。

  • 利用用户行为分析来识别潜在的安全事件。触发后，假设发生了违规。审核，监视与特权帐户和组有关的可疑滥用并迅速采取行动。

  • 在进入企业网络的所有远程访问点上都采用多因素身份验证-尤其要注意保护或禁用远程桌面协议（RDP）访问。已知多种勒索软件攻击会利用弱RDP访问来获取初始进入网络的权限。

  • 使用渗透测试来确定企业网络中的薄弱环节和应优先修补的漏洞。特别是，我们建议对CVE-2019-19781实施缓解措施，该措施已被多个威胁参与者用于在2020年首次进入企业，包括勒索软件攻击。此外，请考虑对以下经常利用的软件漏洞进行优先补救（如果适用）：
