**中间人攻击是一种危害性大但隐蔽性强的网络攻击模式，一般大众往往遭受损失后还难以察觉。中间人攻击能够同时对多个潜在目标开展网络劫持攻击，实施成功的前提是需要一个接近潜在目标的“跳板”，通过这个“跳板”对目标的通信进行劫持和接管。中间人攻击主动构建新的网络攻击路径，同时能够影响的潜在目标更加广泛，是在一地部署能够影响多个目标的网络攻击模式，与此同时，攻击者比以往任何时候更加隐蔽，因此，需要大家高度警惕****。本期，为大家介绍中间人网络攻击的相关情况。**

   

# **什么是中间人攻击？**

 

![](../Images/5a514333e7d067022286baca460585d4.png)

  

中间人攻击（MITM）是一种常见的网络安全攻击，它使攻击者能够窃听两个目标之间的通信。攻击发生在两个合法通信的主机之间，从而使攻击者可以“侦听”他们通常不应该听的对话，因此被称为“中间人”。

 

 

# **中间人攻击如何工作？**

 

**MITM****攻击通常包括两个阶段：拦截和解密。**

**阶段1：拦截**

在拦截阶段，网络罪犯可以通过开放或安全性较差的Wi-Fi路由器和/或通过操纵域名系统（DNS）服务器来访问网络。攻击者然后扫描路由器以查找漏洞和可能的进入点。尽管网络犯罪分子还可以使用更高级的方法，例如IP欺骗或缓存中毒，但这通常是通过弱密码来完成的。

 

一旦确定了目标，攻击者通常会部署数据捕获工具来访问和收集受害者的传输数据，从策略上重定向流量或以其他方式操纵用户的Web体验。

 

**阶段2：解密**

MITM攻击的第二阶段是解密。这是对被盗数据进行解码并使网络罪犯易于理解的时候。可以将解密的数据用于多种恶意目的，包括身份盗用，未经授权的购买或欺诈性的银行活动。在某些情况下，中间人攻击除了破坏业务运营并给受害者造成混乱之外，其目的没有什么明显的目的。

 

**阶段3：技巧**

网络犯罪分子使用多种方法来进行MITM攻击。一些常见的技术包括：

*   模仿已建立的互联网协议（IP），以诱骗用户提供个人信息或刺激所需的操作，例如启动银行转帐或更改密码
    
*   将用户从已知目标重定向到虚假网站，以转移流量和/或收集登录凭据和其他个人信息
    
*   模拟Wi-Fi接入点以拦截任何网络活动并收集个人信息
    
*   创建非法的安全套接字层（SSL）证书，即使连接已被破坏，该证书也会向用户提供安全连接的外观
    
*   将流量重定向到不安全的网站，然后该网站收集登录凭据和个人信息
    
*   窃听包括电子邮件在内的网络活动以收集个人信息并通知进一步的欺诈活动，例如网络钓鱼企图。
    
*   窃取包含个人信息的浏览器cookie
    

 

# **中间人攻击的主要类型**

 

**1.****会话劫持（Session hijacking）攻击**

在这种类型的MitM攻击中，攻击者劫持了受信任的客户端和网络服务器之间的会话。在服务器继续会话的同时，认为计算机正在与客户端通信，攻击计算机将其IP地址替换为受信任的客户端。例如，攻击可能会像这样展开：

1.  客户端连接到服务器。
    
2.  攻击者的计算机控制了客户端。
    
3.  攻击者的计算机将客户端与服务器断开连接。
    
4.  攻击者的计算机用其自己的IP地址替换客户端的IP地址，并
    
5.  欺骗客户端的序列号。
    
6.  攻击者的计算机继续与服务器对话，并且服务器认为服务器仍在与客户端通信。

**2.ARP****欺骗（ARP Spoofing）攻击**

ARP是地址解析协议。它用于将IP地址解析为局域网中的物理MAC（媒体访问控制）地址。当主机需要与具有给定IP地址的主机进行对话时，它将引用ARP缓存以将IP地址解析为MAC地址。如果地址未知，则会发出请求，询问带有IP地址的设备的MAC地址。

 

希望冒充其他主机的攻击者可以响应其不应使用自己的MAC地址进行响应的请求。攻击者可以使用一些经过精确放置的数据包来嗅探两个主机之间的私有流量。可以从流量中提取有价值的信息，例如会话令牌的交换，从而获得对攻击者不应访问的应用程序帐户的完全访问权限。

![](../Images/e1cc36ce2b330bfa9adce597929ac7a6.png)

 

**3.DNS****欺骗（DNS Spoofing）攻击。**

 

DNS与ARP将IP地址解析为LAN上的MAC地址的方式类似，DNS将域名解析为IP地址。使用DNS欺骗攻击时，攻击者尝试将损坏的DNS缓存信息引入主机，以尝试使用其域名（例如www.onlinebanking.com）访问另一台主机。这导致受害者将敏感信息发送到恶意主机，并认为受害者正在将信息发送到受信任的源。只需将DNS服务器的地址解析为攻击者的地址，就已经可以对IP地址进行欺骗的攻击者可以更轻松地对DNS进行欺骗。

**4.WiFi****热点欺骗（Access point spoofing）攻击。**

 

手机，平板电脑和笔记本电脑会自动记住它们连接到的网络的名称（技术上讲，这被称为网络的SSID）。用户通常启用不安全选项以自动连接到已知的Wi-Fi网络。但是问题在于此选项依赖于SSID。只要设备处于另一个具有相同SSID的Wi-Fi网络的覆盖范围内，设备就会尝试连接。

![](../Images/3df078e5f2a3126f75fa7cb6cb2b0bae.png)

攻击者可以使用相同的SSID创建一个恶意访问点，以便恶意访问点附近的员工设备将自动发送身份验证请求。通过使用PEAPv0 / EAPMsCHAPv2协议，再加上对接入点证书的不存在或错误的验证，攻击者可以获取身份验证中使用的质询-响应值。有了这些数据，攻击者就可以暴力破解带有相同SSID的合法网络的密码哈希。员工甚至可能都不怀疑自己受到了攻击。

 

尽管涉及的看似复杂和费力，但此类攻击在现实世界中还是经常发生。在75％的Wi-Fi安全测试中，PositiveTechnologies能够使用类似的攻击来拦截身份验证数据。

![](../Images/c9c4866365440a71bdb8bde548f8748f.png)

一种利用这种技术的方法是对目标公司的员工可能聚集的地方进行“水坑”攻击。这可能是商务中心，餐厅或最近的公共汽车站的入口：员工的设备在看到熟悉的SSID后将尝试连接到攻击者的网络。这既简单又有效，因为攻击者可以轻松地从大量设备中获取身份验证数据，而无需涉足客户端的构建。

![](../Images/689fac9a95df4f19c018b76df16fa4a1.png)

如果无线网络连接到LAN，并且使用域帐户进行访问，则成功的暴力攻击意味着可能对内部网络进行攻击，攻击者可以访问电子邮件帐户等关键资源。

![](../Images/bda6fe3c11c81dae466c1e8001c0e381.png)

配备无线网卡的设备通常会尝试自动连接到发出最强信号的接入点。攻击者可以建立自己的无线接入点，并诱骗附近的设备加入其域。现在，攻击者可以操纵所有受害者的网络流量。这很危险，因为攻击者甚至不必在受信任的网络上即可执行此操作-攻击者只需要足够近的物理距离即可。

 

**5.HTTPS****欺骗（HTTPS spoofing）攻击。**

  

**虽然可以使用多种技术来解密在MITM攻击中被盗的数据，但实际上实际上只有两种：SSL剥离和SSL劫持。**

这些攻击规避了SSL证书强制执行的安全性。当您的Web浏览器与Web服务器联系时，第一个联系是使用普通的http进行的。然后，将用户重定向到安全SSL（https）协议。黑客利用SSL条带或SSL降级攻击来利用这个小窗口。

![](../Images/f0e1a5d02f72fca1a2cf21fbfb2ec9dc.png)

**SSL****劫持是解密这些通信的第二种方法**。在这些攻击中，黑客在TCP握手过程中将伪造的身份验证密钥传递给用户和应用程序。实际上，当中间的人控制整个会话时，这建立了看似安全的连接。在这种情况下，攻击者会秘密地中继并可能更改两方之间的通信，而两方认为他们直接在相互通信。

例如，爱丽丝（Alice）可能在写鲍勃（Bob）信息，说明要在哪个银行帐户中存入支票。相反，介于爱丽丝（Alice）和鲍勃（Bob）之间的克里斯（Chris）截取了对话并将其银行帐号放在消息中。

![](../Images/e3a9af370c664f32cd62c7e0eb48485d.png)

 

**6.IP****地址欺骗（IP spoofing）攻击。**

  

IP欺骗意味着一台计算机冒充具有不同的IP地址-通常与另一台计算机具有相同的地址。仅靠IP欺骗不足以抵御MITM攻击。但是，攻击者可能会将其与TCP序列预测结合使用。

 

大多数Internet连接都是使用TCP / IP（传输控制协议/ Internet协议）建立的。当网络上的两个设备使用TCP / IP相互连接时，它们需要建立一个会话。他们使用三向握手来做到这一点。在此过程中，它们交换称为序列号的信息。接收者需要序列号来识别其他数据包。借助序列号，设备可以知道将接收到的数据包放在一起的顺序。

 

在这种情况下，攻击者首先嗅探该连接（侦听）。这在本地网络上非常容易，因为所有IP数据包都进入网络，并且可以被任何其他设备读取。攻击者了解序列号，预测下一个序列号，然后发送一个伪装成原始发件人的数据包。如果该数据包首先到达目的地，则攻击者将拦截连接。

![](../Images/302dc88707b8b5719f8a3c9baad22565.png)

让我们回到Nancy，这次他想尝试使用TCP序列预测进行IP欺骗：

1)    南希用她的笔记本电脑以10.0.0.42的身份加入您的本地网络，并运行嗅探器。嗅探器软件可让她查看通过网络的所有IP数据包。

2)    南希想拦截您与网关（10.0.0.1）的连接。她在您（10.0.0.102）和网关之间寻找数据包，然后预测序列号。

3)    在适当的时候，南希从她的笔记本电脑发送了一个数据包。该数据包具有网关的源地址（10.0.0.1）和正确的序列号，因此您的笔记本电脑会上当。

4)    同时，Nancy遭受DoS攻击，淹没了真实的网关。网关工作较慢或暂时停止工作。Nancy的数据包先于网关的数据包到达。

5)    南希说服您的笔记本电脑，她的笔记本电脑是网关。现在，她说服网关说她的笔记本电脑是10.0.0.102（您），并且MITM攻击已完成。

 

**7.BGP****路由器（BGP Router）攻击。**

  

更为温和的BGP路由注入可以采用中间人攻击的形式。要成功地对BGP进行TCP劫持攻击，需要满足以下条件：

*   正确匹配源地址
    
*   正确匹配源端口
    
*   正确匹配目标端口
    
*   如果应用了BGP TTL安全性，则正确匹配TTL
    
*   正确匹配TCP序列号（对于盲目的远程攻击者来说是一个很大的麻烦，但是当您可以嗅探该部分时，这不是一个问题）
    
*   绕过TCP选项MD5身份验证（如果应用）

# **中间人攻击典型案例**

 

斯诺登曝光的文件显示美国很早就利用中间人攻击模式开展网络攻击行动，NSA部署了名为“SECONDDATE”的“中间人”攻击技术，以“影响客户端和服务器之间的实时通信”，并“将网页浏览器秘密重定向”至NSA名为“FOXACID”的恶意软件服务器。“SECONDDATE”不仅可以用于针对特定嫌疑人的“手术刀式”攻击，也可以被用于发起大规模恶意软件攻击。针对不同应用系统采用不同攻击框架，如通过代号为“QUANTUMHAND”的“旁观者”攻击中，NSA将自己伪装成Facebook服务器。当目标登录Facebook网站时，NSA将发送恶意数据包，使目标计算机认为其正在访问真正的Facebook网站。通过将恶意软件隐藏在看似普通的Facebook页面中，NSA将可以攻击目标计算机，并从计算机硬盘中获取数据。

![](../Images/7bd34af53accc0edf136a1a5f9085b91.png)

此外，影子经纪人披露的NSA开发的路由器渗透监控工具——SECONDDATE的代码中出现了14次。SECONDDATE是NSA用来发起中间人攻击的尖端武器，甚至有报道称SECONDDATE能够破解加密无线网络信号（NSA的另外两个WiFi中间人攻击工具代号MAGIC SQUIRREL 和 MAGICBEAN）。以上案例能够充分显示出美国对于中间人攻击模式运用已经到达炉火纯青的地步。

# **如何抵御中间人攻击**

 

随着中间人攻击的复杂性不断提高，检测这些事件变得越来越困难。在许多方面，预防技术都可以为此类攻击提供最佳保护。但是，企业和其他大型组织也可能希望通过监视和检测功能来增强其安全性。

  

**对于企业组织的防护建议：**

*   要求网络用户选择强密码并定期进行更改
    
*   在所有网络资产和应用程序上启用多因素身份验证（MFA）
    
*   开发和部署强大的加密协议
    
*   为所有网络资产配备虚拟专用网（VPN）功能
    
*   部署全面的威胁监视和检测解决方案
    
*   细分网络以确保包含潜在的违规行为
    
*   对员工进行开放式Wi-Fi网络的风险教育
    

**对于个人来说，安装针对中间人攻击的检测功能可能不切实际，但是遵循常规的网络安全技术可以帮助防止入侵。为个人用户推荐以下最佳做法**：

*   安装恶意软件检测安全软件
    
*   创建强密码并定期更改密码
    
*   启用多因素身份验证功能
    
*   避免使用开放的Wi-Fi网络和/或安全性较差的公共网络
    
*   始终确保您正在浏览安全的网站，如URL中的https：//所示
