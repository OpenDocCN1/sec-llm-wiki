# 企业如何应对新时代数据安全挑战？数安行给出答案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTM0NTM2OQ==&mid=2247488176&idx=1&sn=598131e7b092bcdd95d611e575ac74ca&chksm=c055ec06f7226510c3f1baec92a080657a58fd36e994b75f464f7b85bf8e0b125c60d9ec1910&scene=126&sessionid=1681268788#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTM0NTM2OQ==&mid=2247488176&idx=1&sn=598131e7b092bcdd95d611e575ac74ca&chksm=c055ec06f7226510c3f1baec92a080657a58fd36e994b75f464f7b85bf8e0b125c60d9ec1910&scene=126&sessionid=1681268788#rd)

随着数据逐渐变成新时代生产生活的支柱，数据安全也日益成为保障经济发展、社会稳定和国家安全的重要基石。与此同时，数据所面临的安全风险也急剧增加，如何精准识别基于数据自身的风险，如何符合法律法规要求，成为数据安全治理与防护的前提条件。

  

目前，数据安全面临多项挑战。为满足合规检查，数据安全建设添加各种产品，存在重复建设和建设周期长的情况；各类安全产品之间缺乏有效的联动和统一调度管理，安全风险应对能力难以得到真正提升。因此，诊疗一体的数据安全平台正在成为企业更理想的选择，其能够实践多种功能，如数据发现、数据脱敏、数据标识、数据分类分级、数据管控等，践行一致性的安全策略，提升有效性和效率，从而促进数据安全建设及运营，让防护和治理不留盲区。

  

而且，数据具有多样性、复杂性等特征，如果没有合适的数据安全风险评估方法和体系，就无法针对性地摸清所有面临的安全风险，也无法评估与法律合规要求的差距。同时，随着《数据安全法》和《个人信息保护法》相继推出，以及各行业数据安全标准的不断完善，数据安全风险评估已经成为开展数据安全治理工作的基础，是各行业机构必要的数据安全保护义务，其作为数据安全建设的基础和前提，在发现数据安全威胁和风险方面意义重大。

  

数安行关注到，近日，国际权威IT咨询机构Gartner发布了《2022中国网络安全技术成熟度曲线》(Hype Cycle for Security in China,2022)报告，报告将**数据安全平台（DSP）和数据风险评估（DRA）列入快速上升的技术萌芽期（Innovation Trigger）。**

  

**根据Gartner的定义，DSP涵盖了各种场景下的数据安全保护需求，以数据发现和数据分类分级为基础，混合了多种技术来实现数据安全防护，其提高了数据的可见性及其广泛的使用，并改进了数据的管控方式，帮助企业做出更明智的决策，为企业和社会带来更好的数据价值发挥和安全保障结果。**

**DRA是开展数据安全治理工作的基础，其关注全方位的数据安全风险，包括数据传输、个人隐私、数据生命周期管理、技术漏洞等。我国法律和监管要求促使各企业将DRA的影响评估扩展到国家安全和公共利益，当组织的数据处理活动涉及重要数据、大量个人信息和跨境传输时，DRA成为必要路径。**

可以看到，DSP、DRA正与上述数据安全的新诉求和新方案不谋而合。Gartner表示，处于技术萌芽期的新兴技术拥有令人期待的创新潜力，本质上具有颠覆性，是未来行业技术演变的重要趋势方向。

  

而数安行从创立初始便以助力用户的数字化转型为目标，前瞻性地观察思考数据安全风险本质和挑战，创造性的建立AI驱动的零信任数据运营安全平台，其能够实现全类型多源数据资产发现及风险分析、全流程数据流动治理与风险感知以及自适应精准化的数据安全防护，做到诊疗一体，从数据标识到数据分类分级，打通各个孤立的数据安全模块，形成全局态势、总体态势。

  

另外，数安行数据运营安全平台着眼于整个数据生命周期，能够帮助用户进行数据风险评估，梳理清查组织内的数据资产类型、数量以及分布位置支持文件内容、个人信息以及数据血亲关系的多维度快速检索，并支持数据使用链路的智能聚合及快速溯源，实时感知数据违规使用及流转风险，能够完美符合企业的合规需求，保障隐私安全。

  

新技术带来新力量，新力量产生新趋势，数安行作为数据安全领域的创新者，会不断求新求变革，为数据安全做出贡献。

关于数安行

北京数安行科技有限公司以数据运营安全为理念，以AI人工智能技术为核心驱动，聚焦数据运营安全，助力数字化转型，致力于让用户的数据安全地创造价值。公司以承载和保护每一个用户的数据运营安全为愿景，持续创新，合作共赢，成就用户。公司核心团队拥有十余年网络安全与数据安全经验，服务于政府、军工、金融、运营商、互联网、教育、高端制造等各行业客户。

关于数据运营安全

数据运营安全（DataSecOps）核心是在数据运营中内嵌数据安全属性，解决数据运营过程中的数据安全问题，以一个产品或平台的方式运行。其目标是在不影响数据业务流程正常运行的情况下更有效的保护组织内的敏感数据资产，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员。
