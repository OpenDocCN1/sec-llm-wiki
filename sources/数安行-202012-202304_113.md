# 数安行入选【网安新兴赛道及厂商速查指南】多项赛道

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTM0NTM2OQ==&mid=2247486521&idx=1&sn=f77ee6be88fa2887529e0597a2f61219&chksm=c055f28ff7227b99a39fd13379889a0821a96a93d82809e16a0931f82df2d408ec8703c0d8a1&scene=126&sessionid=1681268854#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTM0NTM2OQ==&mid=2247486521&idx=1&sn=f77ee6be88fa2887529e0597a2f61219&chksm=c055f28ff7227b99a39fd13379889a0821a96a93d82809e16a0931f82df2d408ec8703c0d8a1&scene=126&sessionid=1681268854#rd)

3月29日，专注于网络安全行业发展与市场营销态势的“安全营销喵喵站”发布「Cyber Security Billboard·网安新兴赛道及厂商速查指南」（2022年）第2版（下文简称“指南”）。本次指南得到了国内外近千家厂商的积极参与和反馈。指南的制定旨在助力企业安全负责人、渠道合作伙伴和安全从业者及时了解网安行业的新兴赛道及前沿产品，在项目产品选型时，高效检索细分赛道和代表性厂商。

  

![](../Images/b379f9c15d95628e281f8988cba995f8.png)

  

数安行凭借着在数据安全领域的深耕和产品理念的创新，被《指南》中的**零信任、数据安全平台DSPs、数据安全治理DSG、数据泄露防护DLP、数据运营安全、数据隐私**6个细分领域收录。这不仅彰显了数安行在数据安全领域的雄厚实力，也践行了数安行“让数据安全地创造价值”的初心。

  

![](../Images/11908f16c229d4ec2f3b2eee03a479f3.png)

  

在社会及企业进入数字化转型的大背景下，面对传统安全产品难以有效应对新生数据安全威胁的情况，数安行站在数据运营的角度重新理解数据安全问题，在国内首先提出**数据运营安全（DataSecOps）**的防护理念，为数据运营内嵌数据安全属性，旨在不影响数据业务流程正常运行的情况下更有效保护组织内的敏感数据资产，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员。

  

基于该理念，数安行创造性地建立了**以零信任数据安全架构为基础，以人工智能技术为核心驱动的数据运营安全平台**，通过管理跟踪各种类型、各种来源的个人隐私数据、政务数据及商业秘密数据，建立敏感数据资产全景视图，促进数据快速流转及安全协作共享，防范内部敏感数据违规滥用风险，基于数据角色及用户风险进行自适应的精准动态防护，打造以数据运营为核心的数据安全生态体系。

  

作为一种创新的数据安全治理方式，该平台在不改变网络架构、不改造业务的情况下,从数据本体防护角度出发，提升数据运营过程中数据自身的安全性，保证数据运营过程中数据的安全，同时不影响数据正常流转效率及业务的正常运行。

  

数安行核心团队在数据安全领域已经耕耘十余年，产品服务于政府、军工、金融、运营商、互联网、教育、高端制造等各行业客户，并收获了客户们的一致好评。此次《指南》中，数安行以强势姿态领跑六个赛道。未来，数安行会顺应数字时代发展趋势，持续聚焦数据运营安全，不断完善数据安全技术及产品，致力于为客户提供更好的服务和体验。

关于数安行

北京数安行科技有限公司以数据运营安全为理念，以AI人工智能技术为核心驱动，聚焦数据运营安全，助力数字化转型，致力于让用户的数据安全地创造价值。公司以承载和保护每一个用户的数据运营安全为愿景，持续创新，合作共赢，成就用户。公司核心团队拥有十余年网络安全与数据安全经验，服务于政府、军工、金融、运营商、互联网、教育、高端制造等各行业客户。

关于数据运营安全

数据运营安全（DataSecOps）核心是在数据运营中内嵌数据安全属性，解决数据运营过程中的数据安全问题，以一个产品或平台的方式运行。其目标是在不影响数据业务流程正常运行的情况下更有效地保护组织内的敏感数据资产，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员。
