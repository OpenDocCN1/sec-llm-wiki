2021年9月1日，《数据安全法》正式施行，明确了数据安全领域内治理体系的顶层设计，通过规制数据处理活动、保障数据安全、保护个人和组织合法权益、维护国家主权和安全，引领和促进数据的开发利用，对数据活动处理者提出更高的数据合规要求。

 

在此，对《数据安全法》作出逐条细致解读，准确领会法律的深刻内涵与作用，把握核心要点，方能合规使用数据，正确激发数据潜能，让数字经济发展与数据安全保障有的放矢。

 

立法节奏之快前所未有

 

《数据安全法》于2018年10月开启研究起草，从2020年6月初次审议到2021年6月三审通过仅短短一年，速度之快在我国的立法节奏中十分少见，充分体现了《数据安全法》立法的紧迫性和社会各界的殷切期望。

 

从客观需求和必要性上来看，随着数字经济时代来临，数据作为一种新的生产要素，也是企业、社会和国家安全的重要战略资源，必须通过立法建立健全各项制度措施，切实加强数据安全保护，维护公民、组织的合法权益，才能促进数字经济健康发展。

 

从外部环境来看，美国、欧盟及全球多个国家、地区已经相继出台了数据安全保护的法律条例，数据主权关系到国家安全，《数据安全法》将成为国家大数据战略中至关重要的法治基础，我国健全数字规则即是要保护数字安全以及参与全球数字规则制定和数字治理。

 

作为我国首部关于数据安全的专门法律，《数据安全法》将与《网络安全法》及《个人信息保护法》一起，全面构筑中国信息及数据安全领域的法律框架。

 

立法原则：数据利用与数据安全的平衡

 

《数据安全法》经过多轮审议和修改，最终公布版的指导原则较之前版本发生了较大变化，即，法律并非单纯地强调保障数据安全，而是同步强调促进数据开发利用。法律条款的核心维度旨在鼓励数据依法合理有效利用，保障数据依法有序自由流动，促进以数据为关键要素的数字经济发展。



第二章 数据安全与发展，用一整个章节的篇幅非常坚定地阐述了国家大数据战略，在产业体系层面设计了一整套规划，工信部、科技部等相关部门将会主导推广大数据在各行业、各领域的创新应用，国务院有关部门将会制定、修订有关数据开发利用技术、产品和数据安全相关标准，逐步形成完整的产业支撑。


立法不是为了限制数据的利用，‍‍而是为了限制数据的滥用，这是数字时代下数据的一大特性，发展与安全并重，开放和共享是数据合理有效利用的前提，而数据安全又是开放和共享的关键基石。


数据的利用和数据的安全在未来是同等的地位，这就意味着，安全厂商在提供相关安全产品及方案时需要摒弃传统的防护阻断思路，在数据的开发利用过程中嵌入安全属性而不影响其发挥价值；涉及数据处理活动的企业组织在开发利用数据的同时，需要将安全性同步进行考虑，而不是作为外围的、事后的一种补充手段。


为数据提供全阶段的安全保障


在《数据安全法》中，「数据处理活动」作为一个核心词汇贯穿全文，诸多条款并没有特别指明某项规定针对的是数据的存储阶段、使用阶段或传输阶段，而是用“开展数据处理活动”进行概括提炼。


本质上，数据处理活动包含了数据的收集、提供、存储、使用、加工、传输、公开等全部阶段，因此，数据安全的合规建设将不再是一个单点的问题，需要关注到数据的整个生命周期。这指明了数字时代下数据安全的另一大特性，安全保障能力需要覆盖数据处理活动的各个不同维度，如果只关注某一特定环节的安全，将会存在明显的短板。


行业监管 + 属地监管双路径并行


针对数据安全的监管，未来将会形成行业 + 属地的横纵双向路径。


行业监管层面，工业、电信、交通、金融、自然资源、卫生健康、教育、科技等主管部门承担本行业、本领域数据安全监管职责，将基于《数据安全法》并结合本行业的业务特点、特定场景、数据处理过程中的中心和特性等，来细化出行业专属的监管条例，建立起本行业的数据安全防护及监管的有效‍‍策略。


目前，该趋势已在部分行业明显呈现，如中国银保监会于2021年1月印发《中国银保监会监管数据安全管理办法（试行）》，明确监管数据安全管理实行归口管理，细化监管数据采集、存储和加工处理的具体要求；工信部于2021年1月印发《工业互联网数据安全保护要求》，规定工业互联网数据安全保护的范围及数据类型，工业互联网数据重要性分级与安全保护等级划分方法。


属地监管层面，最近几年，在全球范围内，数据的存放、开发利用呈现明显的属地化特征，数据出境成为一个高度敏感的话题，国家一直积极参与数据安全相关国际规则和标准的制定，促进数据跨境安全、自由流动。


对于企业来讲，需要格外注意数据因形态和身份发生转变而面临的不同层级的监管要求。存放于数据库、服务器、终端等不同域的数据可能是一张图片、一个文档、一个字节流等等，形态千变万化；同时，同一份数据对于不同主体来说，身份也会随时发生转化，比如对于企业而言的用户信息，对于客户而言可能属于个人信息，对于国家而言可能属于关键基础设施信息，企业需要同时兼顾不同维度的数据保护和监管要求，这也成为企业数据安全建设中的一个巨大挑战。


对于安全厂商来讲，数字时代的数据安全防护方案不能止步于解决某一环节、单个域内的安全问题，需要提供的是面对数据在不同形态、不同属性情况下，能同时解决不同层级的合规要求和真实的数据处理过程中存在的安全隐患的方案。


以下为正文部分的逐条解读


第三章 数据安全制度


该章节明确了数据安全保护的各项基本制度，如数据分类分级保护制度、数据安全应急处置机制、数据安全审查制度。这些制度将共同构建企业履行数据安全保护义务和国家单位进行监管的依据。


// 第二十一条



在海量数据面前，一视同仁地对所有数据施行同等级别的防护既不现实也十分低效，高价值的数据显然需要更严格的保护机制。如果没有实时的数据分类和管控，企业可能低估或高估数据集的价值，导致不准确的风险评估。因此，对数据的分类分级还是后续一切防护措施的基础。


// 第二十二条



顶层机制的建立意味着从企业到行业、从地方到国家将会建立统一的数据安全大平台，预测推断数据安全态势感知类产品或方案在未来将会迎来较大的发展空间。


// 第二十四条 - 二十六条



国家将依法对影响或可能影响国家安全的数据处理活动进行国家安全审查，除去存储、使用、公开等，跨境传输也是一种数据处理活动。面对国际上一些越来越越界的限制甚至制裁，我们需要有对等的反制措施，上述规定即提供了法律依据，让我们在未来的贸易战中有法可依地进行自保。


第四章 数据安全保护义务


该章节主要面向商业数据，以及和个人信息的融合，是涉及数据处理活动的运营主体最需要关心的部分，明确规定了企业在面对法律监管时需要做什么。


// 第二十七条



针对“在网络安全等级保护制度的基础上，履行上述数据安全保护义务”，企业普遍存在疑问，等级保护和数据安全应该是怎样的关系？


自等保2.0施行以来，该标准成为了网络安全行业最重要的驱动力，需要明确的是，等级保护是安全保障的底线，满足等保合规要求仅仅只是及格，需要在此基础之上建立健全全流程数据安全管理制度，组织开展数据安全教育培训，采取相应的技术措施和其他必要措施保障数据安全。


落实数据安全保护责任制，对于企业来说将会在架构上进行调整，设立首席数据官或数据安全管理部门的角色，来负责担负主体责任。


// 第二十八条



“符合社会公德和伦理”的阐述比较抽象，这是大陆法系的法律条文的一个特征，高度概括但拥有最终解释权。当出现根据法律条款不易判断的事件时，将会依据社会公德和伦理来进行约束，相信《数据安全法》未来将会和《个人信息保护法》以及其他相关法律条文形成有效的关联和互动。


// 第二十九条



该条规定是所有企业必须要做的事。在技术层面来讲，即在数据的全生命周期内都必须加强风险监测，发现问题立即补救，并且需要告知用户和主管部门。


这意味着，企业只要开展数据处理活动企就必须同步实施实质性的安全保障动作，两步“告知”也进一步说明了，数据安全事件很难完全杜绝，它在或多或少地持续发生着，但是，一旦发生事故，企业必须得知道发生了事故，对事件有一定的判断和掌控，能最大程度及时挽救。


// 第三十条



该条规定存在较大的解释空间，“重要数据的处理者”——需要明确什么是重要数据，“定期开展风险评估”——需要明确时间周期。


从风险评估报告应当包括的内容看，“重要数据的种类、数量”即为数据分类分级的结果和规模，这也就是前文所述进行数据安全建设的基础；“开展数据处理活动的情况”即为需要掌握数据全流程的流转轨迹，并判断面临的潜在风险；“应对措施”即为不能只监控不处理，需要有相应的技术手段去缓解风险的发生和事故的后果。


对于企业来说，风险评估报告需要报送给所属行业的主管部门，因此需要自研或借助第三方方案建立一套数据资产发现及风险分析、全流程数据流动治理与风险感知以及防护的体系。


// 第三十一条



关键信息基础设施数据的出境适用《网络安全法》的规定，其他数据的出境在《数据安全法》施行以前还处于真空地带，这也成为了部分中概股强行闯关赴美上市的原因之一。


2021年7月10日，国家互联网信息办公室发布关于《网络安全审查办法（修订草案征求意见稿）》公开征求意见的通知，其中规定，掌握超过100万用户个人信息的运营者赴国外上市，必须向网络安全审查办公室申报网络安全审查。以此来确保关键信息基础设施供应链安全和数据安全。


// 第三十二条


收集数据必须合法、正当，不得窃取或以其他非法方式获取数据。这样的表述看似笼统，其实全面限制了所有的窃密手段，无论是黑客入侵、商业间谍窃密、内部员工顺走、第三方供应商泄露……只要没有经过运营主体的同意，一切的方式和手段都是“不合法”、“不正当”的。


// 第三十三条



随着大数据技术的成熟和发展，大数据在商业上的应用越来越广泛，有关大数据的交互、整合、交换、交易的例子也日益增多，大数据交易所、三方服务机构也随之应运而生。未来，数据交易工作将会在阳光下进行，条款和约束更加清晰。


// 第三十五条



放眼国际，美国FBI曾因数据安全隐患和侦查犯罪给微软、facebook等企业下发调令调取数据，这样的执法行为是一把双刃剑。在国内，对于企业来说，这样的规定将对头部的平台型厂商形成强有力的约束，防止手握大量公民隐私数据和国家关键信息基础设施数据的巨头跑偏。


// 第三十六条



这里强调，向外国提供数据，必须要通过我国主管机关的批准。夹在跨境中间的企业往往处于两难境地，即针对一些关键敏感数据，外国司法或执法机构要求必须提交，但我国审查必然无法通过，这时企业该何去何从？立法即为了明确，在涉及国家安全的层面，不能退缩和让步。


第五章 政务数据安全与开放


该章节主要面向政务数据，规定国家机关的义务与责任。


// 第三十八条



与企业一样，国家机关开展数据处理活动，同样需要依法履行、照章办事，有义务保护好经手的数据安全，这是对国家权力的一种约束。


// 第三十九条



国家机关首先自身需要建立健全数据安全管理制度，落实数据安全保护责任；同时，还需要在各行各业下大力推动，让制度更广泛地落地。既有执行责任，还有监管责任。


// 第四十条



国家机关的电子政务系统建设和维护，需要走标准的招投标流程；第三方供应商在执行项目的同时，需要同步履行数据安全保护义务，即第四章中所有面向企业的规定，都必须全部履行。


更重要的是，第三方供应商“不得擅自留存、使用、泄露或者向他们提供政务数据”。建立和维护电子政务系统其实就意味着第三方供应商能够获取政务数据的控制权，但是法律的约束需要他们能够自证确实没有留存和使用，需要在一个相对安全的环境和风险可控的流程中来建设和维护系统，才能够有效地划分和鉴别数据安全保护义务的落实情况。


第六章 法律责任


《数据安全法》经过几轮的审议，处罚力度在整体上有所提升，不同层级的处罚额度，根据造成安全事故后果的严重程度而定。


被主管部门发现存在安全风险的，首先进行约谈，及时进行整改。不履行数据安全保护义务、不告知安全事故、不定期开展风险评估并上报的企业（不一定发生了安全事故），处5万元-50万元罚款。拒不改正或者造成大量数据泄露等严重后果的，处50万元-200万元罚款。危害国家主权、安全和发展利益的，处200万元-1000万元罚款。


公众可能担心，如果某个违法行为能够为企业带来超过罚款额度的收益，那么企业可能就会铤而走险，法律同时规定了造成严重后果者可以责令暂停相关业务、停业整顿、吊销相关业务许可证或者吊销营业执照，依法追究刑事责任，这将是企业无法承受的重罚。


违规向境外提供数据的处罚力度整体上更上一个台阶，处10万元-100万元罚款，情节严重者处100万元-1000万元罚款，并可以责令暂停相关业务、停业整顿、吊销相关业务许可证或者吊销营业执照。


在逆全球化的趋势下，各国都意识到数据蕴含的价值，它可以挖掘出一个人的一切，也可以挖掘出一个国家经济运行的真实状态，因此，数据的属地管辖已经跟国家安全深度绑定，立法既是对企业的约束，也是对企业的保护，更是对国家安全的有力维护。

关于数据运营安全

数据运营安全（DataSecOps）核心是在数据运营中内嵌数据安全属性，解决数据运营过程中的数据安全问题，以一个产品或平台的方式运行。其目标是在不影响数据业务流程正常运行的情况下更有效的保护组织内的敏感数据资产，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员。
