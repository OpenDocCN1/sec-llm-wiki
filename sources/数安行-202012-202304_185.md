# 谷歌安全服务商发布SaaS数据安全报告 揭示文件安全最大风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTM0NTM2OQ==&mid=2247484525&idx=1&sn=c5971edc6b45b4390034838745ee5a90&chksm=c055fadbf72273cd891e5491fc549217f29b2d5c7f8e80d957b0e34395b34f8c05a837b7a529&scene=126&sessionid=1681268882#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTM0NTM2OQ==&mid=2247484525&idx=1&sn=c5971edc6b45b4390034838745ee5a90&chksm=c055fadbf72273cd891e5491fc549217f29b2d5c7f8e80d957b0e34395b34f8c05a837b7a529&scene=126&sessionid=1681268882#rd)

近日，谷歌应用管理及安全服务商 BetterCloud 发布一份数据安全报告——《SaaS Data Security Report 2021: Top Risks in File Security》，通过调查500 多名 IT 和安全专业人员，以及来自数千个组织和用户的 BetterCloud 内部数据，分析出当前企业组织主要面临的数据安全问题以及敏感信息泄露的严重程度。

  

![](../Images/7dd7dc8dd5a59af485a611c08325f552.png)

  

疫情笼罩之下的2020年，远程办公变得更加普遍，同时也加速了企业的数字化转型和 SaaS 模式的采用。《报告》的调查数据显示，**近一半的企业表示，他们最关心的安全问题是不知道敏感数据的位置；超过70%的企业表示，最大的数据泄露风险源于善意但疏忽的员工**；只有35%的受访者信任终端用户会负责任地共享和存储公司数据。此外，随着2021年全球重新开放，业务恢复，文件及数据安全事件飙升了134%，违规行为在整个企业中泛滥。

  

![](../Images/580884b3527c27f7f183f1fde29dfff2.png)

  

基于这些鲜活的调研数据，数安行DSO实验室安全专家分析指出，在社会整体进入数据时代的大背景下，数据安全问题确实已经不同以往了。

  

首先是**风险往往从内部积聚，并蔓延在数据运营的各个过程中**。这和传统安全视角下，我们认为的高风险点有较大的差异。曾经，外来的攻击才是导致系统崩溃、数据丢失的主要原因，但是企业进入数字化转型后，数据快速增长并且流动频繁，跨部门、跨角色的协作共享越来越多，大部分人都会参与到数据运营过程中来。

  

这种变化提升了企业的数据利用效率，但是敏感数据也面临着更复杂的暴露风险和扩散滥用风险，而且随着参与数据运营的用户对数据形态和流转途径越来越熟悉，一些恶意泄露风险会增加。同时又因为数据在流动过程中才能发挥其价值，那么一些恶意的攻击窃取行为就会盯上数据流动过程中的薄弱环节，这些环节大部分在组织内部，各种计算侧环境中，而不是系统或网络的边界处。

  

等这些风险堆积到内外网边界时再去处理，防护压力巨大，而关注边界处的数据泄露和外部攻击的安全防护手段在面对这种风险时，既无检测感知能力，也没有响应保护能力。也正如《报告》所说，大部分的数据安全问题其实源于员工的疏忽，不受控、不规范的内部运营、操作才是产生风险最主要的源头。

  

因此，在数字时代下，转变安全防护的视角和思路是势在必行的。前面分析了这些风险的源头，存在于数据运营的各个环节，既然风险是因为数据运营而生，那防护自然也应该围绕数据运营展开。数安行由此提出了**DataSecOps（数据运营安全）**的理念，核心是在数据运营中内嵌数据安全属性，解决数据运营过程中的数据安全问题，其目标是在不影响数据业务流程正常运行的情况下更有效的保护组织内的敏感数据资产，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员。

  

是的，企业需要转换思路以数据为中心来保护好敏感数据资产，这也就牵扯出数据时代的第二个安全难点，**数据每天都在指数级地增长、高频地流动，海量的数据中，政务数据、个人隐私数据以及商业秘密数据等等敏感数据资产都有哪些，都在哪里，经由过谁手，又将会去哪里？**不能看清并追踪敏感数据的流转情况，防护将永远都处在盲区之中，这也是《报告》中大部分企业最头疼、最现实的难题。

  

数安行在进行DataSecOps理念的实践落地过程中，首先要具备的就是**敏感数据资产的全类型识别及准确分类能力**。数安行数据运营安全平台支持上万种数据格式的识别及内容深度解析，内置上千种的数据分类规则模型，同时借助基于小样本机器学习的数据精细分类智能模型，可以对各个行业、各类法律合规对应的数据资产进行快速准确的分类分级。帮助用户梳理清查组织内的数据资产类型、数量以及分布位置，自动创建数据资产全景视图，感知数据资产暴露风险及违规滥用风险。

  

下一步，就是对**敏感数据进行全流程的标注跟踪以及流转轨迹的智能聚合追溯**。数安行具备持续的敏感数据跟踪能力，可以对业务数据、网络数据以及计算侧分析数据进行跟踪聚合，对敏感数据的状态、内容及流转轨迹进行完整的跟踪溯源，实时感知数据的扩散风险，对于违规滥用行为及时响应处理，通过数据全链路跟踪分析对于一些恶意的数据变形泄露以及一些APT攻击窃取、勒索病毒加密破坏等都可以进行准确的识别以及及时的响应处置。

  

同时，数安行的防护处置是基于**数据角色及用户风险的自适应精准防护**，内置轻量化的敏感数据防护工具箱，以分布式风险识别为驱动，动态感知数据在各业务流程环节以及各类数据角色使用过程中的风险，根据风险级别、使用环境、流转环节以及用户角色等差异提供最精准最适宜的防护手段，不影响数据正常流转效率及业务的正常运行。

  

数字时代，数据的安全和业务的发展是相伴相生的，安全是数据能够成功驱动业务创新、发挥作用的前提和保障。数安行将持续聚焦DataSecOps，助力数字化转型，致力于让用户的数据安全地创造价值。

关于数据运营安全

数据运营安全（DataSecOps）核心是在数据运营中内嵌数据安全属性，解决数据运营过程中的数据安全问题，以一个产品或平台的方式运行。其目标是在不影响数据业务流程正常运行的情况下更有效的保护组织内的敏感数据资产，对敏感数据的扩散及滥用风险进行快速响应，将数据安全防护策略传递至参与数据运营的所有人员。
