1、证监会就《证券期货业网络安全事件报告与调查处理办法（征求意见稿）》公开征求意见。

　　《证券期货业网络安全事件报告与调查处理办法（征求意见稿）》主要修订内容如下：

　　一是将网络安全事件责任主体限定为提供证券期货相关服务的机构。

　　二是明确了对证券期货服务机构采取监督管理措施。

　　三是与相关法律法规使用相同的用语。

　　四是对信息系统进行了统一分类。

　　五是增加了定量描述系统服务能力异常的方法。

　　六是提出了统一的网络安全事件分级方法。

　　七是完善了网络安全事件报告流程。

　　八是网络安全事件处罚更加具有针对性和灵活性。

2、勒索攻击高发于MySQL服务器。

   研究人员称之为PLEASE_READ_ME的双重勒索勒索软件活动正在攻击全世界连接Internet的MySQL数据库。这项运动至少可以追溯到2020年1月。研究人员发现，到目前为止，它已经突破了全球现有的超过500万个面向Internet的MySQL数据库中的超过83,000个。黑客使用无文件勒索软件来利用MySQL服务器中的弱凭据。进入后，攻击者锁定数据库并窃取数据。

3、新的注入技术可提取PDF中的敏感数据。

   PortSwigger公司的安全研究人员周四记录并描述了一种新的注入技术，该技术能够从PDF文件中提取敏感数据。新的代码注入技术实质上允许黑客注入代码，以在PDF文档的范围内发起XSS攻击。恶意黑客能够将PDF代码注入“逃避对象，劫持链接，甚至执行任意JavaScript”到PDF文件中。造成此问题的原因是易受攻击的PDF库无法正确解析代码。

4、数据管理提供商Skyflow筹集了1750万美元A轮融资。

   成立于2019年的Skyflow专注于简化组织访问、管理和管理客户数据的方式。该公司提供了一个由所谓的多态加密(polymorphic encryption，利用最新的令牌化和加密算法)驱动的零信任数据库。该公司还为开发人员提供了API，让他们不必担心合规、隐私或数据安全问题。

5、Azure支持基于客户管理的密钥对SQL Database Hyperscale进行透明数据加密。

   对于Azure SQL Database中的Hyperscale服务层，支持自带密钥（BYOK）的TDE现在已普遍可用。透明数据加密（TDE）通过加密静态数据，可以保护Azure SQL Database、Azure SQL Managed Instance和Azure Synapse Analytics中的Synapse SQL免受恶意脱机活动的威胁。使用BYOK的TDE改进了服务管理的密钥，为客户提供了使用和管理Database Encryption Key (DEK)的全面和细粒度控制，DEK也称为TDE保护器。Azure Key Vault功能以及通过可选的FIPS 140-2 Level 2和Level 3验证的硬件安全模块为政府和金融客户提供更高级别的安全保证。
