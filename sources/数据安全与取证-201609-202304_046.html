我最近买了一台新的MacBook Pro，初始化完成后，便开始安装东西，为手机测试做准备。我会写一组关于如何配置Mac的说明，让即便不熟悉终端的人也能模仿学习。

免责声明：请谨慎执行下文中提到的指令，并自行承担风险。如果操作得当，下文中的任何操作都不会对设备造成危险。

终端（CLI）

（1）终端是什么：

我们即将开始使用终端，如果您对此不甚了解也不用担心，跟随我的操作也可以实现预期的效果。按住“command+空格”键，“Spotlight Search”（中文名：聚焦）将出现在电脑屏幕上。在弹出的搜索框中键入“terminal”可在搜索结果中选择相应的程序。

（2）如何使用：

①按住command和空格键

②在Spotlight Search 中输入“terminal”

③单击Terminal可以打开这个程序

④右键单击Dock栏中的Terminal，在弹出的下一级菜单中使用鼠标点击Options，然后在弹出的下一级菜单中点击Keep in Dock，便可以把Terminal固定在Dock栏中。

Xcode

（1）Xcode是什么：

Xcode是苹果的开发平台，它的一部分被用于iOS和Mac数据的常规取证工作。下载需要时间，这将取决于网速。

（2）如何使用：

在Mac上打开App Store并搜索Xcode，然后下载即可。

Homebrew

（1）Homebrew是什么：

此时需要通过Homebrew来安装一些Apple没有安装的东西。

（2）如何使用：

①打开浏览器，进入brew.sh网站。（注意：不要进入homebrew.sh）。

②当页面打开时，直接在“Install Homebrew”下查看，并整行复制以下内容：

2. /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)" 

将刚刚复制的内容粘贴到终端中，然后按回车键。（如果此时要求输入密码，则输入的访问机器的用户密码即可，因此您需要成为设备管理员。此外，当输入密码时，屏幕上不会显示任何内容，不必因此着急。）

按下回车键后，输出的内容将告诉您脚本即将安装的东西，此时需要再次按回车键进行安装，这个过程需要几分钟的时间。

SQLite数据库浏览器

（1）SQLite数据库浏览器是什么：

对于日常数据库研究和分析，我首选SQLite Browser。

（2）如何使用：

1. 只需转到sqlitebrowser.org/dl/并下载和安装适当的版本。

或者使用 Homebrew方法安装：在官网的下载页面上列出了Homebrow下载方式，其中包含通过Homebrawe安装应用程序的命令，您可以使用它来安装SQLite数据库浏览器。

如果您选择通过Homebrew安装：

在终端中，键入“brew cask install db browser for sqlite”并按“return”。

Hex Fiend

（1）Hex Fiend是什么：

一款免费的十六进制查看器。我会将文件拖放到应用程序中，以便快速检查文件内容。

（2）如何使用：

直接访问ridiculousfish.com/hexfiend下载和安装。

或者，使用Homebrew方法安装：

若要检查Homebrew是否能够安装某个实用程序，只需键入brew search hexfiend并按return即可

结果显示，有一个名为“hex fiend”的Cask，所以可以像以前一样通过Homebrew安装。

在终端中，键入“brew cask install hex fiend”并按“return”。

libimobiledevice

（1）libimobiledevice是什么：

我们将使用“iproxy”程序，该程序支持通过TCP服务访问iDevice。它允许将“localhost”（译者注：localhost原意指本地服务器，此处代指前文中提到的iDevice）映射到设备，从而允许USB和越狱设备进行SSh连接。如果您不知道TCP、SSH或“localhost”是什么意思，请不要放弃。因为一旦完成设置，并且iDevice已越狱，则只需要在终端中键入一些命令就可以了。您便可以实时浏览iDevice的文件系统了！

（2）如何使用：

1. 在终端中，键入brew search libimobiledevice

2. 结果显示“libimobiledevice”可用，因此键入brew install libimobliedevice并按return键

现在，Mac配置完成了！我们在Dock中放好了应用程序，以便快速访问，准备好了Xcode，设置了SQLite数据库浏览器、十六进制查看器，最后设置好了通过USB与iDevice通信的实用程序。可以根据个人偏好调整安装或设置，但如果您遵循这些说明，您的Mac就可以进行iDevice测试了。

如果您成功地遵循了上述说明，那么恭喜您，您的iOS测试进度条将达到51%！第2部分即将推出，将可视化和简化越狱过程，请将iDevice做好测试准备。
