# 如何处理被擦除的iPhone

如果在调查和搜证期间找到一部被擦除过的iPhone手机，应该如何处理呢？

![](../Images/dd49a455b3a1a1aad0a068e78e32be36.png)

首先也是很重要的一点，如果无法在iPhone被擦除前恢复设备中存储的数据，那么解密所需的加密密钥将会永远消失。但是，假使设备被擦除已成既定事实，我们该如何处理？本文将带你了解三种可供尝试的方法。

![](../Images/efc3b4a14ad7c8d9dd9c31886a4ea841.png)

**电脑中存储的数据（Windows 或者 Mac）**

你可以在电脑中搜索：

**①Lockdown certificates**

*   C:\\ProgramData\\Apple\\Lockdown
    

**②iOS Backups**

*   C:\\Users\\\\AppData\\Roaming\\Apple Computer\\MobileSync\\Backup
    
*   C:\\Users\\\\Apple\\MobileSync\\Backup
    

**③Synced CrashLogs**

*   C:\\Users\\\\AppData\\Roaming\\Apple Computer\\Logs\\CrashReporter\\MobileDevice
    

**④MediaStream**

*   C:\\Users\\\\AppData\\Roaming\\AppleComputer\\MediaStream\\
    

**⑤iPodDevices.xml**

*   C:\\Users\\\\AppData\\Local\\AppleComputer\\iTunes\\iPodDevices.xml
    

![](../Images/09aa8983a6bfdb9d8dff0b3ebb59ee23.png)

**iCloud存储的数据**

*   iCloud备份
    
*   同步数据 (例如 联系人, 照片, 短信)
    
*   钥匙串
    

![](../Images/22bba322aafe50658fb87931622faaf0.png)

**同步设备存储的数据**

*   iPad
    
*   Apple Watch
    
*   Apple TV
    
*   Apple HomePod
    

将设备连接到电脑，使用各种工具可以提取到的基本设备信息包括：

*   产品类型
    
*   型号名称
    
*   型号号码
    
*   IMEI
    
*   序列号
    
*   ECID
    
*   iOS版本
    
*   CPU
    
*   充电时长
    
*   电池寿命
    
*   蓝牙地址
    
*   Wi-Fi地址
    
*   蜂窝地址
    
*   储存容量
    
*   储存使用信息
    

如果是易受checkm8攻击的设备，可以尝试使用取证工具或者checkra1n来获取整个文件系统。

一般情况下，不易受checkm8攻击的设备也可以尝试。当设备处于"Hello"屏幕时，可以使用物理按钮组合开始生成"sysdiagnose"（按住两个音量按钮和侧边按钮1-1.5秒）。

生成的系统诊断文件可以使用任何能够提取crash日志的工具提取。

![](../Images/f746ac234a538988ff8d08dd6d1e8a4e.png)

在被擦除的设备中，最有分析价值的文件有：

*①\\logs\\MobileInstallation\\mobile\_installation.log.0（或 mobile\_installation.log.1）*

搜索特定字符串”Did not find last build info; we must be upgrading from pre-8.0 or this is an erase install.”

![](../Images/a8d5db5d886310d46e4d11d8d7162bf1.png)

对应于擦除时间，显示为太平洋时区 (Cupertino)。

*②\\logs\\MobileLockdown\\lockdown.log*

搜索特定字符串 "\_load\_dict: Failed to load /private/var/root/Library/Lockdown/

data\_ark.plist.".

![](../Images/31a4de6b8162c4c6327278b61788c0e2.png)

对应于擦除时间，显示为太平洋时区 (Cupertino)。

![](../Images/31a4de6b8162c4c6327278b61788c0e2.png)

*③\\logs\\MobileContainerManager\\containermanagerd.log.0*

搜索特定字符串 "containermanagerd performing first boot initialization".

对应于擦除时间，显示为太平洋时区 (Cupertino)。

![](../Images/ccc847fd40505c912190020a7e638100.png)

*④\\logs\\powerlogs\\powerlog\_YYY-MM-HH\_MM\_SS\_XXXXXXXX.PLSQL*

它拥有PowerLog文件的内部结构 (只需将其重命名为 CurrentPowerLog.PLSQL)。它会包含有关电池级别的信息，从而发现设备是否和何时在充电。

*⑤\\WiFi\\wifi\_scan\_cache.txt*

包含设备探测到的Wi-Fi网络。其中可能包含 SSID和BSSID。

总之，即使无法恢复用户数据，但至少可以准确了解设备何时被擦除以及在生成系统诊断文件之前在其上发生了什么。如果足够幸运，可以在WiFi缓存中找到SSID和BSSID。
