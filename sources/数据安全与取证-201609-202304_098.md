# 如何免费获取和配置Windows恶意软件分析虚拟机

如果你想要建立自己的恶意软件分析实验环境，通常需要了解如何下载和配置一个用于恶意软件分析的Windows虚拟机：

第一步：安装虚拟化软件；

第二步：获取Windows虚拟机；

第三步：‎更新VM并安装恶意软件分析工具‎；

第四步：隔离分析虚拟机并禁用 Windows Defender AV‎；

第五步：分析恶意软件；

![](../Images/720e564ffac5b57243591b0e0419931f.png)

**安装虚拟化软件**

安装一款适合你的虚拟化软件。VirtualBox和Hyper-V都是不错的免费选项。如果你想为实验室设置一个无头服务器，那么VMware vSphere Hypervisor(以前称为ESXi)也许是不错的选择，它也是免费的。

如果要使用VMware Workstation，你将需要商业版本:Windows和Linux的Workstation Pro或macOS的Fusion Pro。免费版本并不支持快照，然而在检查恶意软件时，你需要通过快照恢复虚拟机的状态来开始新的调查或回溯分析步骤。VMware提供30天的免费试用。

![](../Images/800a141f7b21badc111b1210ec887801.png)

**获取Windows虚拟机**

如果你没有购买Windows的授权版本，你可以从微软下载一个免费的Windows 10虚拟机。进入微软Edge下载虚拟机的页面——https://developer.microsoft.com/en-us/microsoft-edge/tools/vms/ 选择 "MSEdge on Win 10 (x64)"，并挑选与你安装的虚拟化平台相匹配的平台。

![](../Images/ba0bcc8de3d97100060eb0be5b9c58e4.png)

如果使用macOS，你可能无法解压文件的内容，除非你下载一个解压软件，如The Unarchiver。

在下载和解压文件后，按照正确的步骤来启动虚拟机。例如，对于VMware，你应把文件解压到一个专门的文件夹，然后打开名为 "MSEdge - Win10.vmx "的文件。

这个虚拟机中的Windows操作系统在90天后到期。微软建议：“在你第一次安装虚拟机时设置一个快照，以后可以回滚到这个快照。”

微软分配给这个虚拟机的密码是 “Passw0rd！”。你在启动虚拟机时不需要输入密码，它会自动登录，但你在配置操作系统或安装软件时可能需要使用密码。

![](../Images/e822aec7026c7e11fb294cd916ec9921.png)

**更新VM并安装恶意软件分析工具‎**

当你第一次启动虚拟机时，它将能够连接到互联网，前提是你的物理主机有互联网接入。你可以利用这个连接将操作系统更新到最新的补丁级别，并安装恶意软件分析工具。

接下来，安装恶意软件分析工具。这里推荐一些Windows免费工具，用于在实验室分析恶意软件。

*· 行为分析：Process Monitor, ProcDOT, Process Hacker, Wireshark*

*· 代码分析：PeStudio, IDA Freeware, x64dbg, Scylla*

你还可以使用FLARE VM发行版，其中会自动安装很多免费的恶意软件分析工具。

![](../Images/a55d2470619aea8da5c5f1875e530010.png)

你也可以在虚拟机中安装一些实用工具，如VirtualBox Guest Additions和VMware Tools。这些工具是虚拟化软件所附带的，并且能在物理主机和虚拟机之间便捷地共享剪贴板内容和文件。不过它们的存在会稍微增加恶意软件可能检测到虚拟化环境或设法逃脱的机会。

如果不使用虚拟化软件所支持的文件共享方法，就需要确定如何在虚拟机内外传输文件。从虚拟机内访问USB是一个合理的选择。另一个是SFTP：可以启用Windows内置的SSH服务器，然后从物理主机或使用SFTP客户端（如WinSCP）从另一个虚拟机进行访问。

![](../Images/33a26685273b646eb20b7264044a4013.png)

**隔离分析虚拟机并禁用 Windows Defender AV‎**

首先关闭你的虚拟机。

可以禁用虚拟机的共享文件夹，以使恶意软件更难逃脱。例如，在VMware Workstation Pro中，进入虚拟机>设置...>选项>共享文件夹，然后点击禁用。

改变虚拟机的网络设置，使其没有任何网络访问。例如，在VMware Workstation Pro中，你可以通过进入虚拟机>设置...>硬件>网络适配器并选择 "仅主机"，将其放入 "仅主机 "模式。

![](../Images/07ea5ec399ba6978d56a1b96259ba213.png)

仅限主机网络的虚拟机也有可能物理主机的虚拟网络适配器通信。为了更好地隔离，可以考虑为虚拟机定义一个专门的虚拟网络，然后配置虚拟机使用该自定义网络。不过如此操作，将无法使用SFTP工具在虚拟机和物理主机之间传输文件。

 接下来，启动你的虚拟机，现在它已经不再连接到物理网络上了。

在虚拟机内禁用Windows Defender Antivirus，这样防火墙就不会干扰恶意软件分析工作。建议使用组策略来做到这一点，以避免Windows定期重新启用防火墙。也可以选择使用组策略来禁用Windows更新。

一旦虚拟机按你习惯的方式配置好了，就做个快照。

在分析恶意软件时要注意避免感染错误的系统，并尽量减少你的“标本”（恶意软件分析对象）利用虚拟机逃逸漏洞感染主机的机会。强烈考虑将一台物理主机专用于此类研究；不要将该系统用于其他任务，也不要将其连接到生产网络。

![](../Images/520e0fe6fc6de1dca0c03511b6918085.png)
