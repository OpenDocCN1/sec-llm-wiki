在过去几年中，智能可穿戴设备的使用显著增加。苹果公司推出Apple Watch后，这款智能手表一直广受用户欢迎；根据调研机构Above Avalon统计，全球佩戴Apple Watch的用户人数破亿，占据着该领域的主导地位。

从 2015 年开始，苹果公司制造了多款不同型号的搭载WatchOS的设备，WatchOS是专为Apple Watch开发的一款基于 iOS 的可穿戴操作系统。

早在 2015年，Heather Mahalik 和 Sarah Edwards 就在最初的 Apple Watch 上对该设备进行了一些初步的创新研究。

自那时以来，关于如何从此类设备中提取数据的研究并不多。在过去的几个月里，我一直在研究这个主题，探寻提取和分析存储在Apple Watch内部存储器上的数据的方法。

在提取方面我们有三种选择：

· 获取配对 iPhone 的备份

· 直接将Apple Watch连接到计算机

· 云（提取同步健康数据）

分析配对iPhone的备份

iPhone的逻辑提取是众所周知的。您可以通过 iTunes 或使用您选择的取证工具备份 iPhone。

提取 iPhone 备份后，您可以对其进行分析以获取有关配对 Apple Watch 的信息。在本文中，我将使用iBackupBot工具来进行数据提取，该工具可用于 Windows 和 MacOS，以及Windows 的 SQLite Expert 。

我们可以通过分析设备规格开始研究Apple Watch。

在 \HomeDomain\Library\DeviceRegistry.state文件夹中， 我们可以找到以下三个文件：

· historySecureProperties.plist

· stateMachine-.PLIST

· activestatemachine.plist

· history.plist

historySecureProperties.plist文件包含配对 Apple Watch 的序列号（Serial Number）、唯一设备识别符（UDID）、Wi-Fi Mac地址和BT Mac地址。

stateMachine-.PLIST文件包含配对状态（通常包含PairSuccess值）、配对时安装在 Apple Watch 上的 WatchOS 版本和配对时间戳（以Apple Cocoa Core Data格式存储  https://www.epochconverter.com/coredata）。

activestatemachine.plist 包含与 stateMachine-.PLIST类似的信息，增加了在进行备份时安装在设备上的 WatchOS 版本。

\HomeDomain\Library\DeviceRegistry 文件夹包含一个以 stateMachine-.plist 文件的 GUID 值命名的子文件夹：该文件夹包含来自 AppleWatch 的备份数据。

在各种文件和文件夹中，以下文件和文件夹最受关注：

NanoAppRegistry文件夹包含有关已安装应用程序的信息。在下图中，您可以找到有关 Facebook应用的信息以及程序包版本（Bundle Version）, 显示名称（Display Name）, 程序包标识符（Bundle Identifier）和程序包名称（Bundle Name） 。

NanoMail\Registry.sqlite文件包含有关同步电子邮件帐户的信息。

在SYNCED_ACCOUNT表中，您可以找到设备上设置的每个电子邮件帐户的显示名称（Display Name）和电子邮件地址。

在MAILBOX表中，您可以从设备上设置的每个电子邮件帐户的文件夹和子文件夹中查找电子邮件组织。

NanoPasses\nanopasses.sqlite3数据库包含Apple Watch钱包中可用的"Pass"（通行证）列表。对于每个通行证，您可以找到Type_ID、组织名称（Organization Name）、 摄取日期（Ingest Date）（以Apple Cocoa Core Data格式存储）和描述（Description）。

一些通行证还会有“Encoded Pass”（编码通行证）字段，这是一个二进制 plist 文件，包含有关通行证的详细信息。二进制 plist 文件可以从数据库中提取，保存为单独的文件，并使用 plist 查看器（例如 plist 编辑器）打开。在以下截图中，您可以看到与 Booking.com 酒店预订相关的编码通行证。编码通行证可以使用 SQLiteExpert打开并保存为单独的文件。

然后可以用plist编辑器打开该文件以提取有关预订的特定信息，如酒店名称和地址，客人姓名，支付价格，预定电话以及入住和退房的日期。

NanoPreferencesSync文件夹包含与Apple Watch配置相关的各种文件。最有趣的子文件夹之一是 \Backup\Files\，其中包含有关表盘的信息，所有者可以使用从 iPhone 同步的图片进行自定义设置。在以下截图中，您可以找到存储在那里的所有文件的详细信息。

每个文件都是一个zip文件。

该文件包含：

· Face.json提供"表盘"详细信息，包括创建日期（以 Apple Cocoa Core Data 格式存储）

· Resources 文件夹，包含 JPG 格式的表盘图片和包含图片信息和元数据的plist文件

从Apple Watch提取数据

有一个选项可以直接从 Apple Watch 中提取数据。需要满足以下特定要求和限制：

1.您需要一种将计算机连接到 Apple Watch 的方法。正如有关提取 Apple Watch 和 Apple TV 的文章所述，Apple Watch S1、S2 和 S3 可以使用适配器。我们对 Apple Watch 4 的适配器一无所知。

2.连接到计算机时，必须配对 Apple Watch 才能访问数据。如果 Apple Watch 受到密码保护且密码未知，则无法生成配对。

3.WatchOS 上没有运行备份服务，因此无法直接创建 Apple Watch的备份。

4.近期版本的 WatchOS 没有公开的越狱方法。

考虑到这些限制，我们可以从连接的 Apple Watch 中获取三种不同类型的数据：

1. 设备信息和安装应用程序列表

2. 通过 AFC（Apple File Conduit）协议进行文件提取

3. 设备日志

设备信息和已安装的应用列表

通过在连接到配对Apple Watch的 Windows 或 MacOS 计算机上使用 Elcomsoft iOS Forensic Toolkit ，您可以使用"I"（information即信息）选项来提取设备信息。

此命令生成三个文件：

Ideviceinfo.plist

Applications.txt

Applictions.plist

ideviceinfo.plist文件包含有关设备的详细信息，包括硬件型号、WatchOS 版本、序列号、UDID、设备名称、Wi-Fi 和蓝牙地址、时区和实际设置时间。

它还包含有关磁盘总容量、系统总容量、数据总容量、可用总数据和本地语言的信息。

Applications.txt文件包含已安装的应用程序列表，包括程序包标识符、程序包版本和程序包显示名称。

Applications.plist文件包含有关已安装应用程序的详细信息，包括应用路径和容器文件夹。在以下截图中，您可以找到Uber应用的信息示例。

通过 AFC(Apple File Conduit)协议进行提取

通过在连接到配对Apple Watch的 Windows 或 MacOS 计算机上使用 Elcomsoft iOS Forensic Toolkit包，您可以使用"M"（Media）选项提取通过 AFC 协议可用的媒体文件。

提取后，您可以使用您最喜爱的取证工具（本示例中为 X-Ways forensics）分析数据。

DCIM文件夹包含从 iPhone 同步的图片。

与原始图片相比，图片大小进行了调整，但它们仍会包含有趣的元数据，如相机型号名称和原始提取时间戳。

iTunes_Control\iTunes文件夹包含一个名为MediaLibrary.sqlitb的文件以及相关的共享内存（SHM）和预写日志（WAL）文件。此 SQLite 文件包含有趣的信息，如用户的 iCloud 帐户 ID 以及用户从 Apple 商店获得的媒体（歌曲和电影）和电子书列表。此文件包含与同一 iCloud 帐户同步的所有用户设备进行购买的信息。

数据库包含 36 张表格。_MLDatabaseProperties表包含 iCloud 帐户 ID。

要从数据库中提取有意义的数据，您可以使用以下 SQL 查询：

selectext.title AS "Title",ext.media_kind AS "Media Type",itep.format AS "File format",ext.location AS "File",ext.total_time_ms AS "Total time (ms)",ext.file_size AS "File size",ext.year AS "Year",alb.album AS "Album Name",alba.album_artist AS "Artist", com.composer AS "Composer", gen.genre AS "Genre",art.artwork_token AS "Artwork",itev.extended_content_rating AS "Content rating",itev.movie_info AS "Movie information",ext.description_long AS "Description",ite.track_number AS "Track number",sto.account_id AS "Account ID",strftime('%d/%m/%Y %H:%M:%S', datetime(sto.date_purchased + 978397200,'unixepoch'))date_purchased,sto.store_item_id AS "Item ID",sto.purchase_history_id AS "Purchase History ID",ext.copyright AS "Copyright"fromitem_extra extjoin item_store sto using (item_pid)join item ite using (item_pid)join item_stats ites using (item_pid)join item_playback itep using (item_pid)join item_video itev using (item_pid)left join album alb on sto.item_pid=alb.representative_item_pidleft join album_artist alba on sto.item_pid=alba.representative_item_pidleft join composer com on sto.item_pid=com.representative_item_pidleft join genre gen on sto.item_pid=gen.representative_item_pidleft join item_artist itea on sto.item_pid=itea.representative_item_pidleft join artwork_token art on sto.item_pid=art.entity_pid

此查询将提取有关用户购买的详细信息，包括标题、媒体类型、文件大小、总时长（歌曲和电影）、帐户 ID、购买数据和购买历史 ID。对于存储在 Apple 手表上的购买记录，您还会找到文件名。

通过 AFC 协议提取的 Purchase文件夹中可以找到相应的文件：

PhotoData 文件夹包含与同步照片相关的文件。您可以在这里找到的最有趣的信息Photos.sqlite数据库和Thumbnails (缩略图)文件夹。

Photos.sqlite文件包含有关存储在设备上的照片的信息。

此文件结构的详细解释参阅：https://www.forensicmike1.com/2019/05/02/ios-photos-sqlite-forensics/。

解析此文件的SQL查询参阅：https://github.com/kacos2000/queries/blob/master/Photos_sqlite.sql。

Thumbnails (缩略图)文件夹包含存储在 Apple 手表上的图片的缩略图。您可以用 iThmb Converter分析 ITHMB文件，并可能找到已删除图片的缩略图。

提取设备日志

通过在连接到配对Apple Watch的 Windows 或 MacOS 计算机上使用Elcomsoft iOS Forensic Toolkit，您可以使用"L"（Logs）选项提取此信息。

我强烈推荐阅读我与Heather Mahalik以及Adrian Leong (Cheeky4n6monkey) 撰写的文章 “Using Apple “Bug Reporting” for forensic purposes” 。

在这项研究中，我们强调了使用系统诊断配置文件从 Apple 设备中提取数据的重要性。这种方法也在Apple Watch上进行了测试，生成了一个包含大量有用信息的完整 TAR 文件。在下面的截图中，您可以找到从 Apple Watch 中提取的sysdiagnos 日志。

我们还开发了各种脚本来解析在 sysdiagnose 获取期间可用的一些文件。

这些脚本可从GitHub https://github.com/cheeky4n6monkey/iOS_sysdiagnose_forensic_scripts获得。

在sysdiagnose日志中可以找到的一些最相关的信息是：

MobileActivation日志，包含有关随时间安装的构建版本、硬件型号和产品类型的信息。另外，它还详细介绍了操作系统升级。在以下截图中，您可以在 Apple Watch 的Mobile Activation日志上看到该脚本的执行情况。

MobileContainerManager日志，包含有关应用程序卸载的信息，这可能具有历史意义。在以下截图中，您可以在 Apple Watch 的MobileContainerManager 日志上看到脚本的执行。

MobileInstallation 日志，包含有关应用程序卸载的信息，这些信息可能具有历史意义。在以下截图中，您可以在 Apple Watch 的 MobileContainerManager 日志中看到脚本的执行情况。

PowerLog日志，包含有关用户与设备交互的信息。Sarah Edwards在她的演示（PDF）和她的开源工具包 APOLLO中已经研究和描述了这个数据库的结构。在下面的截图中，您可以看到 APOLLO 对从 Apple 手表中提取的 PowerLog 的执行情况。

WiFi日志可用于提取设备连接的网络列表。最容易分析的文件是 com.apple.wifi.plist，其中包含每个网络的详细信息，包括 SSID、BSSID 和上次加入日期。BSSID也可用于使用像Wigle这样的服务来反向查找Wi-Fi网络的位置。

结论：

Apple Watch的提取和分析是与时俱进的。考虑到全球销售的可穿戴设备数量不断增加，我们需要更多的研究和测试。在本文中，我们展示了一些您可以在提取数据后精简的有趣信息。
