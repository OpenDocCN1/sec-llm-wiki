可能几周内，iOS 11.4 系统即将上线！



目前，已经有不少人更新了beta版进行测试，结果是——对普通用户而言没什么太大的区别，但对于公检法等执法机关来说可是欲哭无泪啊！


（欲哭无泪的可能还有两个公司：GrayShift 和 Cellebrite）


因为 iOS 11.4 最大的新特点就是：


USB Restricted Mode！

（USB限制模式）


这个新模式，很可能会让前段时间因破解iPhone而名声大噪的GreyShift和Cellebrite两家公司断了“钱”途！


1. 详解USB Restricted Mode 功能


此次在iOS 11.4 的Beta版本中，设置USB Restricted Mode的目的是为了提高安全性，根据苹果的“开发者文件”所说的，其功能展现方式为：


如果想要iOS设备与USB配件交互，用那么在用苹果的「闪电接口」（lightning connector）连接时，必须保证该iOS设备是没有锁屏的，或者输入解锁密码，才能实现数据连接，且二次连接的有效期最多一周。


这官方说明有些绕，我给大家具体解释一下。


在「USB限制模式」下，如果想要通过USB获取iOS设备的数据，只能通过以下三种情况：


  1. 连接iOS设备时，只有当该设备为解锁状态，才可以建立数据连接；

  2. 当iOS设备为锁屏状态时，连接后得输入密码，才可以建立数据连接；

  3. 距离上一次连接成功的时间为7天之内，即便“锁屏+不知道密码”，再次连接信用过的设备也可以建立数据连接。


第1种跟第2种区别不太大，知道密码的只能是本人了，毕竟拿到别人手机的时候刚好没锁屏的概率太小。而第3种获取数据的方式就比以往严苛了：放在以前，信任过的设备是可以多次连接的，而现在却加了7天的限制，超过七天就得重新用第1种或第2种方式。


如若不然，接入的数据线就只能充电，而且仅仅是充电！


在普通用户看来，此举毫无疑问——更安全！

但站在公检法的角度上，尤其是像苹果与FBI抗衡这样的事件屡次发生之后，此举无疑又湮灭了取证的一丝希望。


2. 为什么这次要限制USB？


大家还记得震惊取证界的GrayKey吗？


对，就是那个声称能够把一切iPhone产品破解的小盒子。


虽然 GrayShift 公司一直对其破解方法讳莫如深，从不愿意透露半句，生怕苹果知道了他们的破解方法给堵了去路，但这一次苹果的做法很可能从根源上断绝了破解的可能。


我们都知道，苹果的系统很封闭，唯一能和外界交互的出口就是苹果的「闪电接口」—— lightning port ，各种配件的连接都得通过它来完成，我们也经常性地选择“信任”。


因此，就目前来看，可以说所有的「破解之法」都是通过寻找这个闪电接口中的漏洞完成的。


还记得GrayKey小盒子上的两根数据线么……


传说中1万5千美元一套的小盒子


对，主要还是靠这个接口去破解获取数据。那么现在，USB Restricted Mode 模式下，这两根数据线插入到设备中，结果估计不容乐观啊……


（对了，在iOS11.4 的这个模式下，将手机连入电脑时，甚至都不会再出现“是否信任该电脑”这个弹窗了）


3.苹果取证之路更难走


要说这个新操作对取证的影响，不言而喻——Gray key 这把钥匙连门都找不着了，cellebrite也用不了了，执法部门只能找别的办法。


要说方法，可行的无外乎这几种：

1. 猜密码、尝试解锁！（如果可以就好了）

2. 对嫌疑人好（qu）言（da）相 (cheng) 劝 (zhao)；

3. 在7天内就把数据从设备中获取出来。（这才是正途啊）


问题是：天知道上次连接是在什么时候啊！😂


在iOS11.4发布之际，小编诚心祝愿所有的取证专家都能有这幸运的7天……
