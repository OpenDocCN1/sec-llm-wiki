# 在儿童色情的问题上，计算机取证该怎么做？能怎么做？

大家好！本期，Wendy想提出一个思考问题：作为取证人员，我们的注意力一直都放在更尖端的技术和更好用的工具上，却是否忘了从一开始我们决定做取证的初衷是什么？

  

其实，取证的角色在本质上和警察是一致的，都是为了守护那些可爱的人们，替他们站在第一线去和罪恶作斗争。然而，当罪恶将魔抓伸向我们未来的希望——孩子们，取证人员应有的情怀是想办法如何弥补法律的漏洞，用技术的力量去保护他们。

  

一起来看看邹锦沛教授在2017ISS网络安全生态峰会上如何针对儿童色情问题的进行探讨并对计算机取证提出疑问的。

  

**正文**  

  

通常我喜欢讲一些故事、案例，讲一点能唤醒你的故事。这是09年发生在香港的案例，香港环保署助理署长因为观看色情网站面临革职。

![](../Images/daa1eb1421792f90bdd6f626e2fa2b7f.png)

  

有20%的男性承认在工作中在线观看色情作品。一周内哪一天最多人看色情？星期天。学生都看，学生是什么时候看的？做功课的时候。

![](../Images/bca3d7e4e7fd03225d12eea92ae305dc.png)

  

昨天我们看到很多CEO、COO分享了议题，你们都知道是首席执行官、首席运营官，你们听过**CPO**吗？**首席色魔**。今天我和大家讨论关于网络色情的案例。

![](../Images/69e1d8c309099aa3c2003ec0c8d4943c.png)

  

在香港，成人色情网站并不是犯罪，而**儿童色情，无疑是严重的罪行**。

![](../Images/b1cf7a9937474134ec1e27914fe489ab.png)

  

香港一商会会长曾经因藏2万儿童色情照被判刑。如果你的电脑里面、手机里面有儿童色情照，这就是犯罪。

![](../Images/7444570f96ef831b5974ddd0506d008c.png)

  

什么也不用解释，持有儿童色情物品就是犯罪，**但问题是什么是“有”？**

![](../Images/50571099b8d7c3fc18ad7a826d2e4c63.png)

![](../Images/8c0ca04fa822a108b22f5932b5464c2e.png)

嫌犯往往辩称他不知道儿童色情作品存在，同时如果嫌犯在合理期限内已经将作品删除，恢复出来的不算。这就是今天我跟大家讲的两个问题：

**1\. 他自己知道不知道儿童色情作品的存在？**

**2\. 他在合理的期限内删除了，有没有科学的方法来证明其罪？**

  

![](../Images/cb3f57ea3e705eb13a3f07aed38461fd.png)

另一个案例：如果在疑犯电脑里找到5万儿童色情照片，没有人会相信他什么也不知道。**那只有一个我们怎么算？他知道不知道？两个、五个、十个、二十个呢？有科学模型吗？**

  

![](../Images/929817aab8a5f3771a2be8c2e3ab5f2b.png)

如果只有一个，他知道就是犯罪，但是好多时候他们都是不知道，好多时候他们都没有修改，他的儿童色情照片有一个，我们怎么知道他知道还是不知道。**第一是去法庭，被告承认喜欢看；第二是所有的照片都是一起下载；第三是他不知道儿童色情照片。香港法庭对抗环节，检察官问，疑犯说我不知道，这就需要有更加科学的方法来证明**。

  

法医DNA的问题，在犯罪现场发现了一根头发，数学模型会计算出头发不是被告的概率值，重复的实验，第二是子弹轨迹，数学模型，重复的实验。**在计算机取证领域，有没有这个公式？**

![](../Images/a853aa65710710de5bf9c42b85dc3f62.png)

  

法医学是应用在刑事跟民事案，观察和实验对物理和自然界的结构和行为进行系统研究的智力和实践活动。

![](../Images/a1c3a31b9baa6427aab599181ff4dd7c.png)

**科学的方法是什么？系统的观察、测量和实验，以及对假设的表述、检验和修正。**

![](../Images/41f603e77d6fe9e18daec23ee71516da.png)

  

计算机的取证，科学，有科学的方法吗？你们有没有做实验？刚刚丁老师说了好多工具，取证，但**有些工具什么取证方法，有没有什么实验？这就是科学，一个简单的问题，一个复杂的模型，这是我们要的吗？这是我们算出来的**。

![](../Images/cccecf0d1f6fd34e0918463027d9cf11.png)

![](../Images/ffe064215c13f9c8551aa855fed74357.png)

  

可以看两个案例，2010年香港一个儿童色情案例，有一个电脑里面**有上万个图像，其中248个是儿童色情的**，他说什么也不知道，我们**用我们数学模型可以算出来随机浏览活动的结果的几率不超过2.5%**。

 ![](../Images/dbdd0ff76186179cfab4952aeb573407.png)

  

还有一个案例，被告有超过714430个下载图像文件，其中**有84个儿童色情图像文件，我们算出来随机浏览活动的结果几率是不超过4%的**。

![](../Images/2c9ed056e72f3b3d67f3933b5a2abb81.png)

  

我们的论文《An approachto quantifying the plausibility of the inadvertent download defence》供大家参考。

![](../Images/8f1b0fbd1c0dc06efa03033c4b1bd76f.png)

 

我们常常听到：“我的工具比他工具多”、“我的工具找不到，你的工具找到吗？”其实**法庭需要的是可重复的实验**。

![](../Images/d0f73ec3b0813c270c36906b67739b6f.png)

 

除了在香港大学做科研，还有其他人在做吗？NIST他们这个科研中心主要就是几个方向，就是专注于改善指纹，枪械，工具痕迹，牙科及其他模式的统计基础实证分析。还包括计算机、音视频等数字证据分析，这是他们做的方向。

![](../Images/2b8bfc1ec8a843fc4af8b3a544308295.png)

  

他们的工作不仅限于传统法医学，还包括计算机、视频、音频等数据证据分析。

![](../Images/90e21f85f2cbdb61f9631191e666c633.png)

![](../Images/14ff53d3e8c330d6b4f5e12281f0df7f.png)

  

法医学在解决犯罪、使犯罪者绳之以法、保护无辜者免受错误定罪方面发挥着关键作用。卓越的法医科学中心将侧重于模式证据和电子证据。

![](../Images/c06e9c0cc5ef9b5d178009f5f11cf04e.png)

**计算机取证，我们有重复的实验吗？**

![](../Images/000835c30d55e70734f550c595fe3598.png) 

NIST里面有一个项目，叫CFTT，是通过制定是通用工具的规范、测试程序、测试标准、测试集和测试硬件，建立一种测试计算机取证工具的方法。测试项目也可以用来确保计算机取证工具始终如一地产生准确和客观的结果。这个Computerforensics tool testing handbook都可以在网上下载。

![](../Images/541206d42cab611aa193ba305c35f191.png)

![](../Images/1abfb0acf0812994d66bb5bdf2645cc4.png)

![](../Images/c0544443784a043d18efea9e6bb4308b.png)

  

**因此计算机取证的发展，下一步是科学的方法、重复的实验。**谢谢各位！
