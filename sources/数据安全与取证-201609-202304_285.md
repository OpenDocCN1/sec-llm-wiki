# “黑洞监控视频取证分析系统” 正式发布

“黑洞视频取证分析系统”，是天宇宁达全力打造的一款针对不同类型的视频进行取证、恢复和分析的专业工具，支持的视频类型包括4大类：视频监控设备、个人录像设备、安卓手机、计算机硬盘。2016年10月21日，“黑洞监控视频”取证分析系统率先发布。

监控视频是目前在刑事案件中遇到的最多，也是实战中恢复难度最大的一类。由于视频监控设备多数采用嵌入式文件系统，视频普遍采用压缩的MP4或H264编码，更因为监控视频多数采用多通道循环写入的方式，造成视频恢复难度大，恢复效果较差。

“黑洞”针对监控视频恢复采用了独特的算法，能够对硬盘中的现有视频、删除的视频、未覆盖的视频碎片进行彻底搜索和恢复。即便硬盘中早期录制的视频已经被覆盖了99%，但是只要有存在几秒甚至仅仅1帧的残留视频，“黑洞”也能够将其彻底恢复。实际案件中，我们从不同品牌的视频监控设备中，恢复找到了几天、几周甚至几月前的残留视频

区别于国际现有视频恢复工具  

  
01/深入

A：可以最大程度进行数据的深度恢复，不会遗漏任何区域。

B、独特MP4恢复算法，恢复视频完整，恢复效果极佳，

C、支持全盘扫描、文件系统扫描、剩余空间扫描等多种扫描方式，不放过每一个残留块。

  
02/智能  

A：突破了FAT32文件系统下的MP4碎片恢复算法，智能碎片重组，不会出现其他产品的大量2MB视频碎片。

B：支持时间过滤、大小过滤、通道过滤，快速定位所需的关键视频碎片。

C：支持图形化碎片分析，显示物理位置和碎片构成，判断形成原因。

  
03/高效  

A：支持视频抽帧、缩略图查看、预览播放等效果，快速找到所需的视频，缩短工作时间。

B：跨段搜索技术，特别是针对TB级数据，缩短5-10倍时间。

C：支持GPU加速技术，进一步提升视频分析效率
