# 智慧街区：数字化转型的新战场

**摘要**

街区是城市一定区域范围内政治、经济、文化等社会活动的有机载体，也是人流、物流、商流、信息流、资金流和价值流交汇流通的核心节点，随着数字化触角不断向城市“神经末梢”延伸，智慧街区逐渐兴起，成为提升基层社会治理服务水平、优化营商环境的“先手棋”，展示城市特色风貌和形象气质的“样板间”，推动需求侧管理、支撑“双循环”战略的“突破口”，将为商贸、民生、文化、旅游各领域融合发展创造新空间，为城市数字化转型开辟新战场。

![](../Images/1fb3e7e96d3d8798f976a1727fa4d1b7.png)**1.概念初探，新形势下的新机遇**

**1.1.智慧街区是数字城市建设的进一步下沉和聚焦**

街区链接着市民、企业、政府三类主体，服务于生产、消费、生活三大环节，是城市发展活力的集中体现。智慧街区是数字城市建设的“缩影”和基层生动实践，是信息化从城市层面向街区层面下沉和聚焦的具体表征，其核心是以数字技术打通街区发展各类主体、各类要素、各个环节，赋能提升街区管理服务效能，优化营商环境，推动区域经济社会数字化转型。一方面，数字城市的大量应用需要以街区为载体落地实施，包括街区的公共安全、市容市貌、市场监管、便民服务等场景；另一方面，智慧街区建设具有以点带面示范、辐射推广的作用，在街区层面开展数字化应用先行先试探索和模式创新，能够为数字城市整体建设提供有益参考借鉴，加速推广覆盖。随着新一代信息技术的不断渗透延伸，智慧街区与智慧社区、智慧园区、数字乡村一样，有望成为未来数字化发展的新战场。

  

**1.2.智慧街区是提升社会幸福感、安全感、获得感的重要手段**

街区作为城市的基础单元，更贴近基层、贴近企业、贴近民生，智慧街区建设能够成为链接政府、企业、市民三类主体的桥梁和纽带，让各类主体直接受益，全面提升社会整体幸福感、安全感、获得感。

**一是市民生活更便捷。**智慧街区遵循“以人民为中心”的建设理念，围绕“食、住、行、游、娱、购”各环节，通过4G/5G/WiFi建设，为市民提供高速泛在的网络服务，利用互联网、物联网、人工智能等技术对公交站、路灯、商超、停车位等设施进行数字化升级改造，为市民提供更加便捷和人性化的数字服务。

**二是营商环境更优化。**智慧街区贯彻落实深化“放管服”改革要求，围绕工商注册、证照办理、银行贷款、减税降费、行政审批等各类事项，全面优化办事流程，为市场经营主体提供线上线下一体化、一站式“互联网+政务服务”，推动构建市场化、法治化、国际化营商环境，进一步激发市场主体活力，全面助力“六稳”“六保”工作。

**三是社会治理更高效**。智慧街区作为市域社会治理现代化的重要内容，通过搭建智慧街区管理平台，整合打通街区治理、公共安全、市场监管等各领域数据，实时掌握街区“人、地、事、物、情、组织”运行态势，并通过大数据分析、预警预测、指挥调度，全面提升街区治理科学化、精细化、智能化水平，增强群众安全感。

  

**1.3.智慧街区是扩大升级信息消费、畅通经济内循环的突破口**

消费既是人类一切生产活动的最终目的，也是支撑经济增长的首要力量。随着国家“双循环”战略的开启，消费作为拉动经济增长的“三驾马车”之一，在扩大内需、形成强大国内市场过程中的地位日益凸显。智慧街区能够从供给侧和需求侧两端发力，扩大升级信息消费，推动经济供需内循环畅通。

**一是丰富消费供给，优化消费体验，推动供给侧改革。**当前，信息消费已成为创新最活跃、增长最迅猛、辐射最广泛的经济领域之一，对拉动内需、促进就业和引领产业升级具有重要作用。2020年10月14日，国家发改委联合13部门出台《近期扩内需促消费的工作方案》，围绕消费供给提出四大方面、19条具体措施，覆盖了线上消费、服务消费、实物消费等消费重点领域。智慧街区充分利用5G、云计算、人工智能等技术，优化消费服务体验，加快教育、养老、医疗、文化、旅游等消费产品、服务、模式和业态创新，以及线上线下消费融合，不断提升消费供给能力。

**二是激发消费需求，挖掘消费潜力，加强需求侧管理。**我国拥有世界上最庞大的内需市场，但消费供需不完全匹配，需求侧存在结构性问题，亟需通过供给需求“两手抓”，提升经济整体效能。2020年中央经济工作会议提出“加快构建以国内大循环为主体、国内国际双循环相互促进的新发展格局，要紧紧扭住供给侧结构性改革这条主线，注重需求侧管理”。智慧街区建设能够打通生产、分配、流通、消费各环节壁垒，基于数据洞察分析消费者个性化、多元化需求，以需求牵引供给，以供给创造需求，加速消费习惯养成和消费黏性提升，进一步激发消费市场潜力，推动消费结构升级。

**2.多方发力，探索实践成效初显**

**2.1.以点带面，政策红利持续释放**

近期，在促消费、扩内需的主基调下，国家和地方层面出台了一系列政策，有序推进智慧街区建设，政策驱动引领效能逐渐释放。

**国家层面，**国务院《关于促进消费扩容提质形成强大国内市场的实施意见》《国务院办公厅关于以新业态新模式引领新型消费加快发展的意见》强调加快推动智慧街区建设，促进线上线下互动、商旅文体协同。商务部《推动步行街改造提升工作方案》提出要聚焦管理智能、运营高效的目标，推动街区数字化改造。2018年以及2020年，商务部在全国范围内分批开展步行街改造提升试点项目，共计试点23条步行街。2020年，首批步行街改造提升取得阶段性成效，南京夫子庙、杭州湖滨路、重庆解放碑等5条步行街跻身全国示范步行街。

![](../Images/a38279fb616a154078732bc0efcefeb5.png)

**地方层面**，各省市积极出台政策，围绕基础设施、管理、服务等要素布局智慧街区建设。从各省市相关政策也可窥见，以5G为核心的信息基础设施和以智慧井盖、智慧灯杆、智慧导视牌等为核心的融合基础设施成为各地智慧街区建设的标配，智慧街区成为“新基建”的主场战之一。数字化管理平台和公共信息服务平台是各省市相关政策中的热词，也是智慧街区统筹建设和管理的重要抓手。此外，部分省市政策在街区商业经营方面也下足了功夫，以浙江省为例，《浙江省商圈服务大提升行动方案》提出了商圈智慧商务、智慧设施、智慧服务、智慧营销、智慧环境、智慧管理等“六大”场景应用创新，促进商圈经济繁荣、品质高端、服务齐全、智慧共享。

**2.2.示范带动，各地争创先进典型**

**南京夫子庙**——作为中国古代文化枢纽、金陵历史人文荟萃之地，南京夫子庙以“小服务、大智慧”实现了历史印记与现代时尚的碰撞。聚焦街区智慧服务，夫子庙构建了“1+3+N”架构体系，依托1个综合管理指挥中心，面向游客、商家、政府等3方主体，嵌入智慧停车、智慧公厕、智慧路灯、智慧垃圾桶、智慧导游、智慧消防、应急处置、投诉处理等N项功能模块，打造了自助童车、自助寄存、机器人智慧E站、刷脸支付、5G+VR等多种应用场景。此外，夫子庙秦淮风光带官网、智慧夫子庙、慢享秦淮等APP和小程序进一步丰富了智慧街区体系，实现了对“老底子+新风貌”的最好诠释。

**杭州湖滨街道**——作为全市首个纳入杭州后“城市大脑”建设的街道级专班，以数据为抓手、以平台为枢纽，整体智治、迭代更新，打造成为“醉杭州”新样板。2018年，基于湖滨商圈人流管控的目标，湖滨街道和杭州市旅委联合打造“湖滨智芯”平台，实现了客流数据的实时抓拍。2019年，湖滨步行街开始向智能治理延伸，构建了“1+4+4”“最智慧”步行街系统架构，“1”指智慧街区综合管理平台，包括街区治理、智能出行、智慧商业、城市大脑（数字驾驶舱接入该板块）等四大板块；“4”指平台接入的城管、市监、消防、公安4个部门；第二个“4”指智慧灯杆、智能导视牌、广告牌系统、无障碍地图服务等4个智慧终端与服务系统。在疫情大背景下，湖滨步行街进一步夯实网络基础，搭建“湖滨在线”数字驾驶舱，全面赋能街区数智治理与服务。

**成都宽窄巷子**——以“科技+消费”为核心，打造成为“场景正引流+新消费体验+智慧化管理”三位一体的全国特色商业步行街典范。宽窄巷子搭建了智慧运营平台，接入客流管理、安全管理、经营管理、物联管理、信息管理和消费体验六大模块，充分整合典型5G、宽窄私域流量平台宽窄云、美团点评等资源，实现设施智能、营销精准、服务便利、放心安全的目标。宽窄巷子在以智慧化手段促进消费方面亮点纷呈。在线下，通过建设智慧商圈大屏、智慧摄像头、餐饮系统软硬件设备等，实现街区客流和消费动态实时监测；在线上，通过大众点评、美团等APP推介“宽窄巷子”品牌馆，创新“到店套餐”、“代金券”、“买单”等引流新模式，推动线上线下消费融合。

**3.前路漫漫，未来发展任重道远**

**3.1.路径不清晰**

智慧街区作为基层治理、公共服务、市场经营等活动的综合型载体，涉及主体、环节、业态众多，现阶段处于政策驱动、试点推广阶段，仍存在建设路径不清晰问题，赋能提升城市治理服务水平与激活市场经营活力存在一定割裂。从目前商务部以及各地市发布政策来看，主要聚焦在数字基础设施建设、城市综合治理以及公共服务方面，首批入选的5条全国示范步行街建设亮点也与此“相互呼应”。而阿里、腾讯等互联网巨头提出的智慧街区、智慧商圈等解决方案更侧重于以数字技术、平台链接商家，创新商业模式，盘活街区实体经济。如何推动政府侧与企业侧建设路径、定位深度融合，打通以数据赋能“街区治理-公共服务-市场经营”的闭环，仍有待进一步探索。

  

**3.2.特色不突出**

现阶段智慧街区建设的亮点、特色大多体现在数字技术应用层面，与本地特色底蕴的结合相对不足，容易陷入“千篇一律”的困境，难以“破局出圈”。一是智慧应用场景挖掘不深。各地智慧街区重点聚焦在抢抓5G发展先机，在此基础上布设各类融合基础设施，包括智能井盖、智能灯杆、智能导视频等，而以数据融通赋能应用场景创新较少，各地智慧建设内容趋同、特色不够凸显。二是地方特色融合不深。近两年，西安大唐不夜城“出圈爆红”，该街区以数字化手段提升“场景力”，打造沉浸式体验，以文化赋能西安“夜经济”繁荣发展，但这类智慧街区寥寥无几，大部分街区缺乏类似“梦回唐朝”的国民文化大IP。此外，地方政府重视程度不够，街区运营服务创新不足，也难以打造出“琴键”“喊泉”“不倒翁”等现象级场景。

  

**3.3.模式不成熟**

智慧街区“硬建设”投入大，政府建设运维负担重，盈利模式不清晰导致智慧街区后续运维困境重重，迭代建设难以持续。一方面，智慧街区正处于初期建设，主要由政府财政出资，重点布局智慧灯杆、导视牌、井盖、垃圾桶、公厕等“硬建设”领域，投入远远大于“软建设”。在智慧街区运营闭环尚未打通、盈利模式不清晰的情况下，“硬建设”投入将给政府带来极大的财政负担。另一方面，街区的人流量大，对各类“硬建设”后期运营维护提出了更高要求。例如近年来公交电子站牌就从交通“新宠”沦为“摆设”，初期投入大、后期运维难，被认为是智慧城市“鸡肋”建设。因此，探索可持续、长效运营的新模式将是智慧街区建设亟待解决的重大课题。

**4.三方协同，共建智慧街区生态**

**4.1.政府侧：强化统筹，找准路径定位**

政府作为智慧街区建设的指导者，一方面要在政策规划、组织协调、资金扶持、应用示范等方面发挥统筹引导作用，加强各级各部门数据共享、业务协同，同时注重激发市场主体活力，加强资源要素对接，审慎包容、放管结合，吸引社会各方力量共同参与智慧街区建设；另一方面，要充分结合自身地域、人文、资源等优势，从服务民生、服务企业、促进经济发展角度出发，找准方向和定位，打造街区特色IP和个性标签，避免智慧街区“千篇一律”。

  

**4.2.企业侧：模式创新，注重建设运营**

企业是智慧街区的主要参与者，既包括面向消费者的市场经营主体，也包括为智慧街区建设提供数字技术、产品、服务和解决方案的厂商。对于市场经营主体，要积极拥抱数字化带来的经营理念创新、商业模式变革，充分利用新一代信息技术优化内部管理效能，加强消费产品供给，提升消费服务水平；对于智慧街区厂商，要从各类主体的实际需求出发，在加强技术和产品能力创新的同时，进一步探索智慧街区长效化建设运营模式，实现健康可持续发展。

  

**4.3.市民侧：协同参与，共建共治共享**

市民是智慧街区建设的出发点和落脚点，也是智慧街区建设的受益者和监督者。因此，市民一方面要充分参与到智慧街区建设中，加强对于新型消费产品、服务模式的接受能力，参与消费需求侧管理，以需求倒逼供给创新；另一方面，市民要充分发挥监督、投诉、评价、协商、互助等作用，在街区治理、消费服务、公共安全等方面加强协同参与，推动构建依法经营、公平竞争、诚实守信的市场环境，打造共建共治共享的街区治理新格局。
