# “双循环”格局之下，数字技术赋能营商环境建设空间更加广阔

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNzQyMTEyMQ==&mid=2247484565&idx=1&sn=a1d6f805822b07d34e1082984d757d82&chksm=9713ef3ba064662d8843faa4866727400c70f351858de2a4ac9e871a1589e30d77ef51b4505f&scene=126&sessionid=1681269227#rd](http://mp.weixin.qq.com/s?__biz=MzIwNzQyMTEyMQ==&mid=2247484565&idx=1&sn=a1d6f805822b07d34e1082984d757d82&chksm=9713ef3ba064662d8843faa4866727400c70f351858de2a4ac9e871a1589e30d77ef51b4505f&scene=126&sessionid=1681269227#rd)

营商环境是建设现代化经济体系、夯实高质量发展的重要基础，是区域政务环境、法治环境、市场环境、社会环境等方面的综合体现，也是衡量城市整体实力的重要指标。近年来，各级政府均将优化营商环境作为关键工作部署，尤其随着新一轮数字政府建设的推进，数字技术赋能成为营商环境建设的重要支撑。近段时间，中央提出“以国内大循环为主体、国内国际双循环相互促进”的新发展格局，进一步强调扩大内需和扩大开放，城市、产业、要素等层面均展现出新的发展态势，营商环境的内涵不断扩展，数字技术的作用空间更加广阔。

  

****优化营商环境是城市谋求高质量发展的关键举措****

  

随着国家和各级政府对营商环境重视程度不断提高，优化营商环境的政策条例密集出台和推进，“放管服”改革持续深入，数字技术全面推进营商环境建设，我国营商环境全球排名不断上升，各地营商环境得到极大改善，为全球商业提供更多机遇，为我国经济进一步高质量发展提供了坚实的基础。

  

**1.1.各级政府将优化营商环境作为关键工作部署**

  

  

**各级政府高度重视深化“放管服”改革、优化营商环境工作，近年来部署出台了一系列有针对性的政策措施，优化营商环境工作取得积极成效。**7月21日，国务院出办公厅台了《关于进一步优化营商环境更好服务市场主体的实施意见》，进一步聚焦市场主体关切，对标国际先进水平，破解企业生产经营中的堵点痛点，强化为市场主体服务，从持续提升投资建设便利度、进一步简化企业生产经营审批和条件、优化外贸外资企业经营环境、进一步降低就业创业门槛、提升涉企服务质量和效率及完善优化营商环境长效机制等方面做出规定。各地均结合地区实际出台相应政策措施。

![](../Images/16f3441c07d9c0633ee3d5c8988fcd79.png)

资料来源：现代数字城市研究院根据公开资料整理

  

《广州市优化营商环境条例(草案)》是首个粤港澳大湾区开展的优化营商环境立法，将会进一步推进广州优化营商环境法制化建设。《北京市新一轮深化“放管服”改革优化营商环境重点任务》，被称为北京营商改革3.0，涵盖商事、工程建设、市政建设、营商保障和市场监督等方面十二大任务。在抗击疫情背景下，国家、部委和地方政府优化营商环境政策条例的发布和实施，能够对我国经济稳定发展起到基础保障作用。

  

**1.2.营商环境是提升城市竞争力的源头活水**

  

  

**营商环境优劣与城市发展的诸多要素相互关联影响，良好的营商环境能够引领人才、项目流入城市，是城市软实力和竞争力提升的源头活水。优化营商环境是集聚人才重要途径，**优质的营商环境意味着强大的人才招引能力，以杭州为例，近年来杭州相继出台“人才新政27条”、人才“若干意见22条”、“国际人才引育留用机制”等，打造“热带雨林”式的人才生态，营造一流营商环境，近4年杭州人口年均净流入超20万，具备强大的经济社会发展潜力。**资本和项目向营商环境优势地区集聚****，**以嘉兴为例，推出“企业服务直通车”平台，负责兜底受理企业的“疑难杂症”，出台服务企业“36计”等举措，在2019年长三角26个城市营商环境排名中总分位列第四，在浙江省内仅次于杭州位居第二，2018年下半年以来，14个百亿项目落户嘉兴，夯实了城市的发展后劲。

  

**1.3.营商环境评价排名成为城市的重要名片**

  

  

**营商环境成为地区发展水平和发展能力的重要指征，成为城市对外展示的重要名片，营商环境评估体系不断丰富，参与营商环境评估成为重要抓手。**世界银行《全球营商环境报告》从开办企业、获得电力、办理建筑许可等8个指标领域开展分析，我国营商环境全球排名从2018年的78位升至2020年第31位，连续两年成为全球优化营商环境改善幅度最大的十大经济体之一。国内目前也有很多营商环境评估和研究，如国家发改委的《全国营商环境试评价》，2018年第一轮评价包括22个城市，2019年扩大到40个城市，预计2020扩大到全国城市，目标是构建科学、对标国际和具有中国特色的中国营商环境评价指标体系。全国工商联的《万家民营企业评价营商环境报告》，从总体、城市、区域三个层次，根据政务环境优化、企业要素环境保障、法治政府建设、深化放管服改革成效等角度来进行评价。万博新经济研究院定期发布《中国城市营商环境指数评价报告》，粤港澳大湾区研究院发布《城市营商环境报告》、《广州营商环境报告》和《四川省可持续营商环境研究报告》等区域性研究报告，都提出相应营商环境评价指标或评价标准。城市在各类营商环境报告中的排名或指数，切实影响着城市的对外形象和招引能力。

  

**“双循环”格局下营商环境建设面临新形势**

  

国家战略谋划“以国内大循环为主体、国内国际双循环相互促进”的新发展格局，未来时期内拉动内需和扩大开放将成为经济发展的关键举措，落脚到城市层面，面对常态化疫情防控下的经济发展命题，拉动数字消费潜力、提振数字产业能级成为破题之道。伴随着数字经济迎来发展浪潮，数据作为生产要素的价值被逐步认识和挖掘，着力培育数字经济发展环境和数据要素流通环境已经成为城市营商环境建设新的重要内涵。

  

**2.1.国家层面：战略谋划“双循环”新发展格局**

  

  

**中央战略谋划加快形成“以国内大循环为主体、国内国际双循环相互促进”的新发展格局，为我国经济发展指明了方向、明确了任务。**在当前国际环境复杂剧变、不稳定性不确定性明显增强的大背景下，以“内循环”为主体带动“双循环”旨在通过发挥内需潜力，更好利用国际国内两个市场、两种资源，培育新形势下我国参与国际合作和竞争新优势。**以国内大循环为主体，**要求充分发挥我国超大规模市场优势和内需潜力，我国拥有14亿人口、4亿中等收入群体，人均GDP突破1万美元，潜在的经济活力和发展活力强劲，专家指出，今后几年我国自身内循环可以拉动百分之几的经济增长。**国内国际双循环相互促进，**要求进一步扩大开放，优化升级我国产业链供应链布局，吸引更多全球企业落户中国、留在中国，增强我国经济的韧性，使得国外产业更加依赖中国供应链和产业链，更加依赖中国的巨大消费市场，让世界分享中国扩大内需战略的发展成果。面对“双循环”发展格局，从扩大内需和扩大开放两个层面而言，均需大力保护和激发市场主体活力，以改善营商环境作为重要着力点，推动产业和消费“双升级”。

  

**2.2.城市层面：促进经济持续向好发展是工作的重中之重**

  

  

**面对当前和今后一个时期国内外环境变化和疫情带来的经济下行冲击，多举并进促进经济持续向好发展是工作的重中之重。从短期来看，**疫情给企业生产经营带来巨大影响，且近期将保持常态化疫情防控形势，企业面临成本上涨、用工短缺、资金紧张等压力和挑战，各级政府将“六稳”“六保”作为今年政府工作的关键内容。**从中期来看，**城市要抓住扩大内需和消费升级机遇，着力推动消费扩容提质，加快释放信息消费等新型消费潜力，全面营造良好消费环境。**从长期来看，**谋求经济高质量发展是城市各项工作的核心要义，营商环境建设需要长期耕耘投入。营商环境的内涵随着发展环境变化而不断扩展，政府需从更精准、更深入的角度审视和推进营商环境优化工作，加速手段、方式、模式的变革和发展，适应快速变化的市场形势。

  

**2.3.产业层面：数字经济迎来发展浪潮**

  

  

**随着云计算、大数据、物联网、人工智能、5G和区块链等新一代信息技术迅速发展，数字经济成为增长新动能，营造良好的数字产业发展环境成为营商环境建设的题中之义。从规模上看，**2019年，我国数字经济增加值规模达到35.8万亿元，占GDP比重达到36.2%，其中数字产业化增加值达7.1万亿元，产业数字化增加值约为28.8万亿元。**从增速上看，**2008到2018年，我国数字经济增速均显著高于同期GDP增速，并且自2011年以来，数字经济与GDP增速差距有扩大趋势，2018年我国数字经济名义增长率为20.9%，高于同期GDP名义增速约11.2个百分点。**从细分领域来看，**预计2020年，我国规模以上工业企业电子商务销售额达到11万亿元，工业互联网产业规模达到3万亿元，医疗健康服务业规模超过8万亿元，同时新产业新业态不断涌现，如信息服务产业、共享经济以及数字技术向传统产业融合渗透等。要紧抓数字经济强势发展的机遇，营造良好的数字经济发展环境，夯实持续健康发展基础，提高数字科技产业规模占比，打造数字产业集聚发展格局。

  

**2.4.要素层面：数据成为新的生产要素**

  

  

**数字技术的发展和应用带来经济生产方式、社会运行方式、国家治理方式的变革，数据蕴含的价值被逐渐认识和挖掘。各地纷纷出台政策引导数据开发和利用，**2010年至今，全国31个省（自治区、直辖市）共出台了125份省级政府层面与政务数据治理直接相关的政策文件，强化数据的战略资源定位及其对经济社会的赋能作用；2015年9月国务院发布《促进大数据发展行动纲要》，是我国发展大数据的首部战略性指导文件，围绕政府数据开放共享、推动产业创新发展、强化数据安全保障等方面做出部署；今年4月，《中共中央国务院关于构建更加完善的要素市场化配置体制机制的意见》明确指出“要加快培育数据要素市场”，正式明确数据的生产要素属性。**先进地区围绕数据要素的价值发挥已经开展有益的探索实践，**不同于传统生产要素，数据本身不创造价值，数据要素通过赋能传统要素价值发挥、优化资源配置效率及投入替代而形成价值创造的乘数效应，多地围绕数据资产管理、数据共享开放及数据应用等领域开展先行先试，如上海和浙江率先进行公共数据开放立法，明确政府开放数据的边界和要求；广西成立北部湾大数据交易中心，对外提供数据服务并形成多种盈利模式；上海、深圳等地举办开放数据创新应用大赛，带动企业和社会数据开放，加速数据融合应用。数字环境逐步成为营商环境的重要内涵，培育数据要素市场、加速数据要素流动成为政府优化营商环境的新议题。

  

**数字技术作用空间更加广阔**

  

**3.1.助力各项政策和企业决策精准实施**

  

  

**数字技术应用到关联分析、综合研判、流程优化等环节，能够大幅提升政府各项举措和企业生产经营决策的科学性、精准性和有效性。优化营商环境政策的实效发挥需要依托切实可行的执行手段，**诸如疫情后各地政府纷纷出台企业保经营、稳发展的政策举措，包括减税降费、金融服务、水电气价格优惠等，可通过大数据开展企业画像，精确识别帮扶对象。**企业生产经营决策愈加依赖数据支撑，**如安全生产监测和预警、经营管理、物流售后等，需不断丰富各类园区、特色小镇的数字化服务功能，以数字驱动助力企业经营效率和质量不断提升。

  

**3.2.厚植数字经济发展环境**

  

  

**面向传统产业数字化转型和数字产业化发展，营造良好的数字经济发展环境，聚力打造数字产业集聚生态。以“上云用数赋智”为抓手提升城市数字产业扶持力度，**推动龙头企业能力壮大，鼓励技术创新，调动科技型企业、科研机构加大研发投入，提升对数字化生态的招引能力，对中小微企业提供数字化转型所需的基础能力和工具。**优化对企业数字服务的种类和层次，**充分发挥市场的力量，鼓励各类平台、开源社区、第三方机构参与数字发展环境建设，持续创新服务模式，将数字技术充分融入“放管服”改革，开展基于场景的业务流程再造以及“不见面审批”服务场景构建，为企业提供政策、金融、人才等方面的支持。

  

**3.3.培育新产业新业态新消费**

  

  

**顺应数字技术应用场景的不断增多和人们的消费方式和消费习惯的改变，着力培育新新产业、新业态、新消费，打开数字市场空间。要重点谋划创新发展举措，**加强企业发展培育，吸收先进模式和经验，如建立城市机会清单，以发布会等形式为载体，为广大创新企业提供展示平台和合作桥梁，凝聚人才、动能和生态，培育共享经济、新零售、在线消费、无接触配送、互联网医疗、线上教育等业态的成长土壤。**重点突破“信创+”、“新基建+”为代表的新场景应用，**丰富5G技术应用场景, 积极开展消费服务领域人工智能应用试点,加快信创生态营造，加大数据要素供给，提升新经济发展能级。

  

**3.4.强化数字监管手段**

  

  

**强化对数字经济发展、数字产业培育、数字消费过程的监管，不断丰富监管手段，扩大监管范围。增强数据要素流动和应用过程监管，**探索区块链技术在数据汇聚、治理、应用、开放过程的应用，为数据要素价值发挥提供可信环境。**增强对企业行为的监管，**强化企业信用评价机制建设，既要支持包容创新，又要规范市场秩序，推动重点关注对象在不同地区连续监管，如泸州、宁波、嘉兴等10个城市共建跨区域社会信用体系，签署信用城市联盟合作协议，通过交换红黑名单等信息，加大跨区域守信联合激励和失信联合惩戒力度。
