# 数据产品超市——海南公共数据资源开发利用新模式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247490591&idx=2&sn=6c40bf2833bda8727a791a8028bc42f7&chksm=c22824f4f55fade283ab851a88211a1cf62b4927940f6d3a7b3f7f905de7fe43ee2842664afe&scene=126&sessionid=1681269453#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247490591&idx=2&sn=6c40bf2833bda8727a791a8028bc42f7&chksm=c22824f4f55fade283ab851a88211a1cf62b4927940f6d3a7b3f7f905de7fe43ee2842664afe&scene=126&sessionid=1681269453#rd)

近年来，数据已成为国家基础性战略资源，并与土地、劳动力、资本、技术等传统要素并列成为生产要素之一。为了加快培育数据要素市场，释放数据要素的价值，全国各省市也在加快探索数据开放共享的模式。

作为全国八大公共数据资源开发利用试点省之一，海南省高度重视大数据及信息化的建设，相继出台《海南省大数据开发应用条例》《海南省公共数据产品开发利用暂行管理办法》等规定，以推进海南省公共数据资源开发利用，创新数据产品的开发与数据服务方式。为此，海南省大数据管理局创新性提出了数据开发利用新模式：基于我省“七个一”的大数据能力底座，建设集数据开发，流通交易，安全保障为一体的系统平台——**海南省数据产品超市**。 

**什么是数据产品超市？**

![](../Images/a70317900e735fb89915a6a84fd49630.png)

海南省数据产品超市是一个开放性的生产与交易服务平台，通过引进具有技术服务能力和研究分析能力的大数据企业和机构，进行数据产品开发生产、供需对接，交易的不是原始数据，而是对数据加工处理后的结果，创新了数据产品与数据服务的方式。 

数据产品超市采用“前店后厂”的模式，以“七个一”大数据能力底座为基础对数据进行归集和共享，在数据开发平台中对数据清洗加工生成数据产品，最后在数据产品超市交易门户上架数据产品，通过流通交易实现数据价值的变现，形成了数据产品开发利用全生产链。在数据流通的全周期中，数据产品超市利用联邦学习、多方安全计算等隐私计算及区块链技术，实现了“数据可用不可见”，“用途可控可计量”，确保数据安全。

**超市可提供哪些产品和应用场景？**

![](../Images/d62a1d60fbafe689e9caebe85ee26c71.png)

数据产品超市可提供多样化的数据产品，目前已上架250多个数据产品，类型包括数据分析报告、数据报表、数据模型、数据服务、软硬件设备等，目前产品覆盖了科技创新，公共安全，财税金融，法律服务，生活服务等十余个领域。例如，在生活服务领域，超市近期主推的产品“健康易通”，该产品是一款数据集成创新产品，利用大数据开发技术，将健康码、疫苗接种、核酸检测、通信大数据行程码等数据互联互通，可实时统计被核验人员的健康状况，用户只需出示身份证或人脸识别，可3秒内高效完成“人、证、码、温”四合一验证，充分发挥了健康数据的价值，为防疫相关部门提供信息化支撑。

**如何使用数据产品超市？**

![](../Images/19c93f466414f0c7ce032fec44d33583.png)

数据产品超市实行“会员制”管理，企业和单位用户可登录超市门户网站，通过注册成为超市会员，即可在超市中进行数据产品的开发生产、供需对接。在成为会员后，企业和单位用户还可通过申请认证成为产品提供方或产品开发方，获取产品上架、开发的权限。在超市门户的产品中心，会员可浏览、下单数据产品，若上架的产品无法满足需求，会员可在超市门户的需求大厅发布采购需求，超市将组织产品提供方或开发方进行需求应答，会员可根据应答方案择优选购。在数据产品超市中，买卖双方可实现数据产品的需求发布、需求应答、产品开发、产品上架展示、产品交易等供需对接的流程。此外，在超市门户的资源目录中，会员可浏览当前开放共享的数据资源，可按需向数据产品超市提出数据资源的申请，进行数据产品的开发利用。

**数据产品超市解决什么问题？**

数据产品超市通过搭建安全可信的数据开发和交易平台、建立合规的数据授权机制、建立专业丰富的生态服务，可实现公共数据资源合理合规地流通，安全可信地开放和开发应用。在政府侧，基于公共数据资源开发利用平台，通过政务业务的大数据场景化应用，打通政务服务利企便民的睹点、难点和痛点，形成“科学决策、高效执行、精准监管、智慧服务”的工作机制；在企业侧，基于数据产品超市与行业的数据连接，推进社会数据汇聚共享应用，激发创新活力，激活企业竞争力，促进生产方式、产业链组织、 商业模式、企业形态创新，加速产业数字化转型和新兴数字产业发展。通过大力推进公共数据资源和社会数据资源的场景化应用发展，全面提高数字化政务服务效能，使公共服务更便捷、城乡市管理更高效、交通出行更畅通、人民生活更智慧，打造智慧共享的新型数字生活。
