# 快狗打车IPO背后：数据合规风险是上市棘手难题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247490576&idx=2&sn=5319a7be4b9fdd6e744f5bc3d50eb1ff&chksm=c22824fbf55fadede466294ceb6c68e7f817caff4c408f4758001d0764b34588113a3bb7fda0&scene=126&sessionid=1681269458#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247490576&idx=2&sn=5319a7be4b9fdd6e744f5bc3d50eb1ff&chksm=c22824fbf55fadede466294ceb6c68e7f817caff4c408f4758001d0764b34588113a3bb7fda0&scene=126&sessionid=1681269458#rd)

港交所披露，快狗打车通过港交所上市聆讯。若进程顺利，其将成为港股同城物流科技第一股。

  

从最新的聆讯后资料中可见，快狗打车在风险因素中细化了涉及数据合规的问题，提及受到与数据安全相关的复杂且不断变化的法规及监督约束。

  

近年来，我国针对网络数据安全、用户隐私方面的法律法规不断更新，监管愈发严格。上市公司披露数据安全、用户隐私等风险已成为必要选项，甚至已经和财务数据披露达到同等重要的地位。监管侧的相关问询问题颗粒度也在逐渐细化。

  

对于拥有大量数据的科技平台公司而言，需谨慎应对数据合规带来的挑战，避免因法规及监管的不断变化所带来的不确定性风险。数据合规风险是棘手难题，处理得当也能成为公司的竞争优势，投资者的“定心丸”。

**1：数据合规已成为科技公司上市必答题**

  

快狗打车成立于2014年，系58到家旗下的线上同城物流平台，前身为58速运。2017年，GOGOX与58速运合并，并在之后更名为快狗打车。快狗打车是2020年中国内地交易额第二大的线上同城物流平台，叠加香港市场的交易额后，快狗打车在亚洲线上同城物流的市场份额达到68%。

  

从最新的聆讯后资料中可以看出，快狗打车亏损仍在持续，并且月活和订单量出现双下滑。

  

除却货运物流赛道挤压的挑战外，快狗打车的数据合规问题同样值得关注。这也是科技公司上市之路成为绕不开的必答题。

  

快狗打车在中国内地以“快狗打车”为品牌，在亚洲及其他国家则以“GOGOX”品牌提供服务，现总计覆盖5个国家及地区的超340个城市。

  

对于货运数据，与常规个人信息保护显著区别的在于其收集的个人信息是和货物信息绑定的。“我们的业务收集、产生及处理大量的个人、交易及行为数据。”快狗打车在招股书中指出。

  

浙江垦丁律师事务所合伙人李晋沅分析，传统的个人信息往往是孤立的，但在快狗打车的业务过程中，人和物的数据合二为一，并以此来进行用户画像。

  

公开报道显示，快狗打车每天处理数T的数据，并开展各种真实场景的模拟。这能持续提升快狗打车技术团队效率和准确性。

  

李晋沅告诉21世纪经济报道记者，目前该类业务的发展需要更多的数据来源，仅仅凭借人和物的交易数据构建用户画像仍很粗糙，尤其是在同城物流中，大量用户的交易频率不足以支撑建立起完整的用户画像。故而为了更精准地触达用户，快狗打车需要更多的不同种类数据来支撑用户画像的建立，这其中就涉及到数据交易和数据传输。 

  

可以看到，快狗打车招股书中明确指出，大量数据带来许多固有风险，包括“解决与隐私及共享、安全、保障和其他因素有关的问题；遵守与收集、存储、使用、处理、传输、披露或保护个人信息及其他数据有关的适用法律、规则及法规，包括监管及政府机构就该等数据提出的任何要求。”

**2：变化的法律法规带来合规成本上升**

  

数据合规风险不仅仅是公司业务的事情。

  

去年7月，网信办对多家赴美上市公司开展网络安全审查。随即，中办、国办联合发布《关于依法从严打击证券违法活动的意见》，强调加强中概股监管，完善数据安全等相关法律法规；网信办发布《网络安全审查办法（修订草案征求意见稿）》，扩围了审查对象，将数据处理活动纳入网络安全审查范围，并且要求掌握超过100万用户个人信息的运营者赴国外上市，必须审批。

  

除却国内监管政策变化外，国外的监管环境日益复杂，可能对中国企业赴美上市造成障碍，甚至加速中概股企业退市。

  

大成律师事务所高级合伙人邓志松指出，美国2021年生效实施的《外国公司问责法案》要求企业必须提供审计工作底稿以便审核，而中国法律对于向境外提供财务审计底稿有着严格的限制，且《数据安全法》第36条明确禁止境内企业未经境内主管机关批准，向外国执法机构提供存储于境内的数据。

  

事实上，已有多家中概股公司(如阿里巴巴、京东、网易等)陆续到港交所二次上市。去年12月，滴滴也已宣布“退美赴港”。

  

“港股上市时间短，披露信息较少，手续简便，对于很多企业成为首选，一方面能够节约企业成本，另一方面，对于投资者而言也是双赢，否则很多与投资者签署的对赌协议将会成为压垮企业的最后一根稻草。”李晋沅指出。

  

不过目前来看，相关政策仍未细化，对上市公司而言仍具有不确定性，可能带来合规成本的大幅提升。

  

比如，赴港上市的网络安全审查细则仍未明确；《打击证券违法活动的意见》主要包括高水平指引，详细实施措施尚未颁布；《数据出境安全评估办法（征求意见稿）》、《网络数据安全管理条例（征求意见稿）》其最终版本和生效日期未定……

  

“有关数据保护及隐私的法律、法规及标准的解释和适用范围仍不确定且在不断变化。”快狗招股书中指出，“另外，有关数据保护及隐私的法律、法规及标准在不断发展，并可能因司法管辖区不同而有所不同。遵守新的及不断变化的国际要求可能会使产生大额成本，或者要求我们改变我们的业务做法。”

**3、用工问题愈发受到关注**

  

对于货运物流平台来讲，提供用工需求与人力资源高效对接渠道的同时，其平台用工权益保障问题关注度越来越高。

  

在招股书中，快狗打车对旗下司机注册方式、福利待遇等问题进行了披露。招股书提到，截至2021年9月30日快狗平台共拥有约490万名注册司机，超过16.5万名活跃司机，其中有57,389名司机可提供平台及企业服务。

  

“在中国企业经营合规性要求越来越高的大背景下，对于出行、同城货运等相关平台企业而言，平台用工本就是其业务的重要组成部分，在上市等阶段对用工权益保障相关问题进行披露已是必然的趋势。”中国社会科学院法学研究所社会法室副主任王天玉认为，此类企业在进入资本市场时，其与劳动提供群体之间的关系也是反映业务生态和管理机制的重要指标，这也是用工问题在企业IPO过程中愈发受到关注的重要原因。

  

2021年10月11日，交通运输部会同公安部、人社部等16个部门联合印发了《关于加强货车司机权益保障工作的意见》，再次强调合理确定及调整平台规则，公开披露相关规定，支持同城货运平台企业纳入职业伤害保障试点等问题。

  

王天玉表示，目前从平台灵活就业人员职业伤害保障的定位来看，该保障要求是社会保险制度的组成部分，也体现着下一步的政策走向，如果职业伤害保障全面落实，就意味着将平台设定为平台劳工的社保义务人，缴纳职业伤害险将会成为平台企业必须履行的义务。

  

劳动法律法规的趋严给吸纳了大量新业态就业的相关平台带来不小压力，对业务及其盈利能力造成不利影响。

  

快狗打车在最新的聆讯后资料中更详尽地介绍了用工的风险，也提及上述的相关法律文件。快狗打车还表示：“目前不与平台司机签订雇佣协议或建立雇佣关系。因此不对无雇佣关系的平台司机支付社会保险或住房公积金。然而，倘日后颁布新的法律法规，要求我们作出该等供款，我们的营运成本将大幅增加，我们的业务及财务状况将受到重大不利影响，且我们目前的业务模式可能不再可持续。”

**4、数据安全风险披露越发重要**

  

近年来，我国针对网络数据安全、用户隐私方面的法律法规不断更新，监管也呈现愈发严格的趋势。

  

上市公司主动披露数据安全、用户隐私等风险，逐渐成为必要选项。

  

工信部信息通信经济专家委员会委员、中南财经政法大学数字经济研究院执行院长盘和林指出，完整的信息披露能够促进资本市场信息对称性，辅助投资人做出客观的评价。这一方面体现出投资人对企业合规风险的关切程度与日俱增，另一方面则体现出上市公司也意识到公开风险点，保持信息透明对于稳定投资人预期至关重要。

  

“自从墨迹天气IPO因为数据合规问题（包括但不限于）被否之后，证监会在近几年已经对30余家企业问询数据合规问题，而且问题的颗粒度呈明显细化的趋势。可以肯定的是，证监会对拟IPO企业的数据合规方面监管将会越来越严。”李晋沅指出。

  

他表示，这就要求拟IPO企业在申报材料时候，要格外注意数据合规，做好主动申报。如果没有做好主动申报，证监会和发审委等机构不会坐视不理，势必会进行问询，而前期没有做足功课，那么等待企业的将是多轮问询，这对于企业IPO的成本，无论是时间成本还是经济成本都是一个巨大的挑战。

  

在李晋沅看来，数据安全风险披露已经和财务数据披露已经达到了同等重要的地位。

  

邓志松也认同数据安全风险披露的重要性，并指出“数据合规本身不是为了制约上市公司，而是从公司长远发展的角度出发，减少因数据安全、用户隐私问题而对公司、用户甚至国家产生不利影响的潜在风险。”

  

他认为，上市公司应当根据现行法律法规，梳理自身业务情况，初步搭建系统的数据合规体系，并时刻关注立法动态，不断根据新的要求更新合规体系，以规避法律、监管和市场风险。另外，近年来，监管机构对APP违法违规收集使用个人信息的监管力度不断加大。相关平台公司也应严格自查，及时整改，以规避监管风险。
