# 合肥数据要素流通平台正式上线 全国百家数商签约入驻

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247490537&idx=1&sn=84d6db9ea05dcceb1f804a4b67d6d37d&chksm=c2282302f55faa14831f02f8e9358d3da0b4e52856e50080bad64b8fb50b9a545714cd2c1f41&scene=126&sessionid=1681269477#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247490537&idx=1&sn=84d6db9ea05dcceb1f804a4b67d6d37d&chksm=c2282302f55faa14831f02f8e9358d3da0b4e52856e50080bad64b8fb50b9a545714cd2c1f41&scene=126&sessionid=1681269477#rd)

12月17日，合肥数据要素流通平台在2021中国（合肥）数字经济创新峰会上正式上线。现场超过百家数据要素市场供应商、需求商、服务商正式签约入驻，上线当日即成首笔交易。  

![](../Images/bfe9219a39757e0bad9b2a4e26929e1d.png)

  

  

**合肥数据要素流通平台正式上线****搭建数据要素流通平台**  
  

  

为贯彻落实国家、省、市十四五规划和2035年远景目标要求，推进数据要素市场化配置，促进数据流通交易，赋能区域经济社会发展，合肥市数据资源局会同合肥市大数据资产运营有限公司筹建合肥数据要素市场，共同探索数据要素流通创新应用场景。围绕建设统一、有序、规范的数据要素市场目标，搭建合肥数据要素流通平台。

平台聚焦人工智能、工业互联网、金融、科研等4大应用场景，提供数据集、API、数据服务、解决方案等多元化产品，以及数据定制、数据标注、数据治理、算法建模等增值服务。目前平台提供超过100项专业数据产品，汇聚优质数据资源超20亿条，数据总量超过20PB。

通过推动数据要素市场供给侧改革，增加公共数据、社会数据有效供给，汇聚大数据产业全链条服务商，以数据要素驱动产业数字化转型升级。

  

![](../Images/841a565d14baac98cc538d4ce21a5f95.png)

  

**全国百家数商集中签约入驻****打造“335”数据要素流通体系**  
  

  

合肥数据要素流通平台创新打造三率先、三定位、五支撑的“335”数据要素流通体系。

三率先即在全国范围内率先培育数据要素入场流通模式、率先开展公共数据授权运营试点、率先进行数据产品确权登记探索。

三定位即做数据产品“生产者”、数据交易“服务员”、流通平台“运营商”，通过政府数据、社会数据授权，提供质量好、价值高、需求大的数据产品，做到以应用来牵引；及时对接各类数据要素供需，准确提供数据服务，成为数据流通的重要枢纽，做到有需求必响应；通过创建优质可信数据交易环境和市场化的体制机制，建设面向全国、合肥特色的数据要素综合服务平台，做到先入场再交易。

五支撑即依托规则、资源、技术、服务、人才五大支撑建设平台。与高等院校、科研院所、专业律所合作，形成分级分类、安全管理、风险防控等数据要素流通规则。发挥合肥数据要素产业创新联盟作用，为平台提供多方资源支撑。引入多方安全计算、联邦学习、数据沙箱、区块链等技术，实现数据“可用不可见”、“相逢不相识”，确保数据全流通周期安全。依托合肥市先算中心、大数据产业示范园、数投基金，提供优质算力、物理空间、金融投资等配套服务支撑。借助合肥综合性国家科学中心人才优势，为合肥数据要素流通交易提供人才支撑。

合肥数据要素流通平台上线当天同步举办首批数商入驻签约仪式，超过百家数据要素市场供应商、需求商、服务商正式入驻合肥数据要素流通平台。

  

**平台上线当日即成首笔交易****探索数据要素流通创新应用场景**  
  

  

合肥数据要素流通平台面向政府与企业，提供数据要素产品入场流通的功能，数据供应商、数据需求商经过前置身份认证、资质审核后，即可在平台开始数据要素交易，并利用区块链技术，对产品上架、申请、审核等流程进行登记存证，确保交易环境安全可信，交易流程可查找可追溯。

上线当日，由大智慧财汇数据科技有限公司研发的“企业预警通”成为首单成交的数据产品。该产品是大智慧财汇公司将人工智能和大数据处理技术运用于金融市场及企业风险监控环节的专家级金融产品。

“企业预警通”产品通过合肥数据要素流通平台申请上架，并经前置审核后生成数据产品凭证。安徽恒富化工科技有限公司需了解其行业供应链企业详细工商情况，进行合作风险评估。于是通过平台对“企业预警通”产品进行申请，平台根据其应用场景进行审核，审核通过后双方进行数据产品流通，合作达成后，平台生成数据流通凭证。

  

据悉，合肥数据要素流通平台下一步将打造数据要素流通、交易技术创新、产业生态培育“三”大中心，激发数据要素的乘数效应，健全数据要素生态，支持在数字经济新产业、新业态和新模式中体现数据的生产要素作用，在数据要素流通方面开展“合肥探索”。
