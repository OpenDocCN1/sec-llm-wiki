# 美国重提《2021年在线隐私法》，呼吁建立数字隐私机构进行监管

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247490514&idx=2&sn=15706457fe9cc1111cc9948544ed5394&chksm=c2282339f55faa2f43b6b02e931a3c152f6356b2a38809f5475e91383d4b1b949f87a3626912&scene=126&sessionid=1681269489#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247490514&idx=2&sn=15706457fe9cc1111cc9948544ed5394&chksm=c2282339f55faa2f43b6b02e931a3c152f6356b2a38809f5475e91383d4b1b949f87a3626912&scene=126&sessionid=1681269489#rd)

**点击上方蓝字获取更多新鲜资讯**11月18日，美国众议员Anna G.Eshoo和Zoe Lofgren宣布，她们已在美国国会重新引入《2021年在线隐私法》。**该法案创建了用户数据权利，对收集和使用用户数据的公司施加了限制和义务，并要求建立数字隐私机构 (DPA)以执行隐私法。**更新后的立法包括几项改进的条款和额外的隐私保护，例如在DPA中增加一个民权办公室，并授权州隐私监管机构与州检察长一起执行。Eshoo指出，美国的立法将恢复和保护美国人民的隐私权，确保每个人都能控制自己的数据，公司应对侵犯隐私的行为负责，政府应提供严厉且公平的执法。Lofgren表示，在线隐私法通过保护用户数据和为在线公司制定明确的标准来解决问题，防止个人信息滥用。公司如果不能收集数据，就不能利用这些数据操纵美国人牟利。《在线隐私法》通过以下方式保护个人、鼓励创新并恢复对科技公司的信任：**创建用户权利**——该法案授予每个美国人访问、更正或删除其数据的权利。它还创造了新的权利，例如让用户自主决定公司可以保留数据多长时间。**对公司施加明确的限制和义务**——该法案将公司收集、处理、披露和维护的数据量降至最低，并禁止公司以歧视性的方式使用数据。此外，公司必须以简单明了的语言获得用户的同意。**建立数字隐私机构（DPA）**——该法案将建立由一名董事领导的独立机构，该董事由总统任命，并由参议院确认，任期六年。DPA将实施隐私保护并调查侵权行为。**加强执法**——该法案授权州总检察长强制执行违反该法案的行为，并允许个人任命非营利组织在私人集体诉讼中代表他们。Eshoo和Lofgren于2019年11⽉5⽇⾸次推出了《在线隐私法》。“《在线隐私法》将⼤⼤有助于遏制数据处理。它包含许多强⼤的数据保护条款，以及对公司如何处理我们数据的有意义的限制，最终将把⼈⽽不是公司置于数据政策的中⼼。这是国会应该考虑的严肃全⾯的隐私⽴法类型。”负责任的技术伙伴关系和政策总监RishiBharwani说 。
