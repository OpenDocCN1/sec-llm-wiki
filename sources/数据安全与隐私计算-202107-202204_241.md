# 数据交易所赋能财富管理行业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247490480&idx=1&sn=1bc196b1ef56b11e72909ab15728e3f6&chksm=c228235bf55faa4d70cd52697c286409a440ffd53c99d2a17a0ebd3b7b901614614721788d57&scene=126&sessionid=1681269503#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247490480&idx=1&sn=1bc196b1ef56b11e72909ab15728e3f6&chksm=c228235bf55faa4d70cd52697c286409a440ffd53c99d2a17a0ebd3b7b901614614721788d57&scene=126&sessionid=1681269503#rd)

本文是北京金控集团副总经理李岷在《银行家》杂志社主办的“中国金融创新论坛”暨2021中国金融创新成果线上发布会上发表的演讲。论坛主题为“银行数字化转型：路径与策略”。

  
财富管理行业发展至今，已经形成了一个巨大的市场。目前国内财富管理机构主要有公募基金、银行、信托、保险、银行理财子公司等，规模非常庞大。据统计，我国居民储蓄存款规模已突破100万亿元，公募基金规模突破23万亿元，银行理财产品规模接近26万亿元，信托市场规模接近20万亿元，保险市场规模约24万亿元。此外，私募股权基金市场规模接近19万亿元。

  

****未来，中国的财富管理行业将发展成为一个逐步健全、逐步多元、逐步稳健的智能运营市场****

  
  
  

  

无论是银行、基金，还是证券、保险，各类金融机构都在推动财富管理的标准化和敏捷化迭代发展，这个过程孕育在财富管理的各个环节。但是，无论财富管理市场如何发展，都离不开对客户的了解、分析和评估，都离不开对宏观经济、细分行业和微观投资标的深入研选。财富管理机构基于客户需求进行相应的资产管理方案设计、投资研究组合管理、投资交易和后续组合运营，以及全流程风险控制，这也是财富管理市场发展的主流运营趋势。  
在这个趋势之中，智能化将是财富管理行业未来最主要的发展方向。客户无论是通过智能终端还是网站，都会接触到各家财富管理机构的前端，从“元宇宙”这个视角来看，同时存在一个与线下服务市场平行的虚拟服务财富管理市场：客户从App里获得虚拟理财师提供的理财规划、理财信息；财富管理机构通过虚拟理财师与客户交流的映射数据实现对客户的认知把握和风险评估，进而为客户提供资产管理方案；后台运营团队可通过智能投资研究的整体算法，为客户匹配相应的财富管理产品和组合服务；投资经理通过量化配置算法和投资标的动态交易管理客户细分组合；客户也可根据自身需求和市场变化及时调整组合安排，实现这些组合的再平衡。在资产组合管理过程中，包括组合的绩效、后续的再投资及相应的风险调控，智能化管理理念已经渗透到每一步：从营销到投资研究、投资决策、行业大类分析，再到资金清算结算、运营和全流程风控，基于数据的、覆盖前中后台全流程的智能化财富管理，已经成为未来发展的大势所趋。

  

****数据交易所在数据安全法和个人信息保护法规范下，可以通过提供算技支持、算力支持和算料支持，助力财富管理市场的发展****

  
  
  

  

在算技支持方面，数据交易所交易的不仅仅是数据，还有大量数据服务及底层技术。比如在为客户进行风险评估以及适当性评估的过程中，通过联邦学习、多方安全计算、可信执行环境等隐私计算技术跨越客户在社交、电商、政务、金融等不同数据孤岛之间的壁垒，实现客户信息保护与多维数据的共享和利用。通过这样的数据交易对客户进行风险评估、投资经验评估等，能够让我们更全面真实的对客户群体进行画像，有助于财富管理机构提供更加优质的服务。  
在算力支持方面，各家财富管理机构大都独立于自有科技系统和企业架构之下。那么，如何在投资研究、行业分析、组合量化深度学习模型应用方面开展连续的跨市场智算，如何跨越投资标的背后的产业互联网数据墙、在市场中实现更多的动态数据共享，如何通过自然语言处理和生物标识解析等技术大范围对股票、债券、衍生品标的进行空天数据整合以及全天候动态估值，算力的支撑必不可少。数据交易所背后逐步构建的算力超级资源，将逐步成为财富管理行业的第三方算力支撑。在算料支持方面，投资管理模型、投资研究逻辑引擎、客户风险评估模型、运营模型、客服RPA（机器人流程自动化）及其背后的知识图谱等等，都需要大规模数据的试算支持。数据交易所在逐步尝试数据托管和汇聚的过程中，将依法合规搭建模型测试环境，助力财富管理机构创新算法，共享资源进行计算、测试和优化。数据交易所从算技、算力、算料等各个维度，为各家财富管理机构提供智能化的工具和多元化的场景，并探索打造未来新技术应用的试验田。  
财富管理市场规模巨大，其创新发展离不开数据的交易。大数据交易所将财富管理市场作为主要拓展方向，必将为财富管理市场注入更多新鲜的活力。这种活力一方面是创新的活力，另一方面是科技的活力，但背后的根源其实是数据要素作为新型生产要素的活力。
