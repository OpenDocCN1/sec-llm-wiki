# 乌镇峰会| 神奇“隐身衣”让隐私更安全

近年来，人工智能在很多场景里正逐渐替代人工或与人类协作，成为人类的眼睛。然而，这些主流应用场景的背后，往往也藏着由技术性缺陷导致的算法安全风险。如何提高人工智能的安全性、可靠性？近日，在2021年世界互联网大会——“互联网之光”博览会的中国互联网投资基金主题展区，一款由清华人工智能研究院成果转化公司瑞莱智慧带来的“隐身衣”吸睛全场。据该公司有关负责人介绍，“隐身衣”上印刷的特定对抗图案，能使监控系统的检测算法出错，一旦穿上便可以实现“隐身逃逸”。信息安全的本质是攻防升级，通过开发类似的“隐身衣”可以找到现有AI系统存在的安全漏洞，从而针对性的进行防御升级。本次互联网大会，中国互联网投资基金携48家所投优秀企业共同参展，作为互联网股权投资领域的“国家队”，中国互联网投资基金积极发挥政府性基金示范引领作用，专注专业开展互联网领域投资布局，助力网络强国建设和数字经济发展。责任编辑：马江来源：新华网
