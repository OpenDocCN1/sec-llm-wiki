# 小米挪车呼叫专利获授权：让挪车既方便又保护隐私

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247490439&idx=2&sn=1912573d8ed291ea7ba346077ff5edc6&chksm=c228236cf55faa7a2c873b59167e4425eb5d11b45c2f184ed25c6b831b1eeffaa2449abcb7bc&scene=126&sessionid=1681269517#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247490439&idx=2&sn=1912573d8ed291ea7ba346077ff5edc6&chksm=c228236cf55faa7a2c873b59167e4425eb5d11b45c2f184ed25c6b831b1eeffaa2449abcb7bc&scene=126&sessionid=1681269517#rd)

9月7日消息，北京小米移动软件有限公司“挪车呼叫方法、装置、设备及存储介质”专利获授权，公开号为 CN110649936B。  
![](../Images/f413d2027e6fd6506bd9196a0b4bc640.png)  
企查查专利摘要显示，该专利属于无线通信领域，所述方法包括：通过投影组件投影显示临停信息，并进入工作状态；工作状态下，若接收到对挪车呼叫按键的触发操作，则通过麦克风采集本端语音；通过无线通信组件向目标终端发送本端语音，并通过无线通信组件接收目标终端发送的对端语音；通过扬声器播放对端语音。IT之家了解到，采用该申请实施例提供的方案，通过投影组件投影显示临停信息，可以提醒有挪车需要的人联系用户，当接收到对挪车呼叫按键的触发操作时，通过麦克风采集本端语音，并利用无线通信组件实现双方通信，在为有挪车需要的人带来方便的同时，隐藏用户的个人信息，保护了用户的隐私，从而提高了安全性。
