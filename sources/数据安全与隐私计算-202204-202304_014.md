# 云南省首个！《大理州数据治理工程—数据安全与数据要素化工程总体方案》通过专家论证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247501908&idx=2&sn=a9999ba8da2df68780b14bc9dda6c304&chksm=c22bf0bff55c79a9f9e9fc70ab0c021ebe9773caba1eaba63c7959197d67fc353e5e699ed157&scene=126&sessionid=1681269288#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247501908&idx=2&sn=a9999ba8da2df68780b14bc9dda6c304&chksm=c22bf0bff55c79a9f9e9fc70ab0c021ebe9773caba1eaba63c7959197d67fc353e5e699ed157&scene=126&sessionid=1681269288#rd)

![](../Images/4ba15b88101343e3ef45c8529da4f9ef.png)

3月30日，由中国电子、中电数创联合大理州数字经济办组织召开的“大理州数据治理工程—数据安全与数据要素化工程总体方案专家论证会”在大理成功举行。**由中国电子牵头完成的《大理州数据治理工程—数据安全与数据要素化工程总体方案》**（以下简称《总体方案》）通过专家论证，标志着**大理州数据要素化试点迈出重要一步，为数字大理的发展夯实基础**。作为**云南省首个立足区域实际的数据治理工程方案**，《总体方案》也为探索云南省数据要素市场化配置改革树立了标杆。  
![](../Images/185530a38abc2535fc8f3617770c5f78.png)  

  

此次论证会由中国经济体制改革研究会副秘书长、中国经济改革研究基金会秘书长石明磊担任专家组组长，成员由来自中国经济体制改革研究会、云南省通信学会、北京大学、清华大学、昆明理工大学、建设数字云南领导小组专家组等机构的权威专家组成。  
![](../Images/a3d1ee191ce98783019e489562fd7a5f.png)  
中国电子数据治理工程指挥部向专家组汇报了《总体方案》的核心内容。专家组就《总体方案》进行充分质询与讨论，认为该方案在深入调研分析基础上，紧扣国家和省级政策要求，结合大理实际，从工程设计、制度文件、标准规范、产业服务四个方面系统谋划了大理州数据要素发展路径，符合国家、省关于数据要素市场化配置改革的总体要求和发展思路。同时，**《总体方案》强调在数据安全合规前提下**，建立健全完善的数据要素制度体系、技术体系、市场体系，思路清晰、结构合理，具有较强的前瞻性和可操作性，**对加快数据要素市场化配置改革、培育与完善数据要素市场具有重要的指导意义**。会上，专家组一致同意通过论证。  
下一步，中国电子数据治理工程指挥部将与大理州共同推进《总体方案》的全方位落地，并在文旅、能源、环保等几个重点领域先试先行，积极稳妥推进数据治理工程试点，激发数据要素价值。  //  ![](../Images/793a57d6d5fb380410f4894b93f9cb4b.png)

  

大理州委书记杨国宗表示：当下，探索数据合规高效流通，激发数据要素价值，已经成为推动经济高质量发展的新引擎。大理州抢抓数据要素发展先机，与中国电子携手在云南省内率先发起城市数据治理工程相关研究，致力于为云南省数据要素市场化配置改革探索出一条安全、高效、可行的实践方案，打造数字时代的“大理样板”。下一步，大理州将坚决贯彻落实《中共中央、国务院关于构建数据基础制度更好发挥数据要素作用的意见》（简称“数据二十条”）[构建数据基础制度体系 “数据二十条”来了！](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247499282&idx=2&sn=b7a743b0217837e917b2ce1133bba919&chksm=c22bc6f9f55c4fef00845cdf6181e0a1bf4666d4c64ae896e40a4e581d0b57a11bf5c3f4ecc6&scene=21#wechat_redirect)，立足国家、省数据要素市场化配置改革的战略要求，基于《总体方案》，形成完备的数据要素统筹协调机制，加快数据基础制度构建和数据要素市场培育，将大理州建设成为云南首个、全国领先的数据要素市场化改革试点城市，全面激活数字经济发展动能，抢占数字经济发展制高点。  //  ![](../Images/efd842dce1bf261bf02a86486ee9d15a.png)

  

中国电子所属桑达股份高级副总裁、中电数创总经理王晓亮表示：《总体方案》是继2021年中国电子与大理州签署“共建数据要素市场化试点城市合作协议”之后的重要合作成果，将助推大理州数据要素市场化配置改革迈上新台阶。未来双方将进一步推动“制度+技术+市场”三位一体的总体实施架构在大理州顺利落地，有效破解当前数据安全和数据要素市场化痛点和难点，盘活数据资源，释放数据价值、培育数据产业，助推“数字大理”和“数字云南”建设，为数据要素市场化配置改革贡献力量。

  

大理州委常委、大理市委书记字德海，副州长鲁旭俊等政府领导，桑达股份副总裁周崇毅，助理总裁乔亲旺，中国电子数据治理工程指挥部相关负责人，数字大理建设运营有限公司等领导参加本次论证会。
