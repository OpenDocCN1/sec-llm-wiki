# 青岛开展公共数据运营试点！探索数据要素市场化配置“青岛”模式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247497533&idx=1&sn=46bb1fe3667e36db278cc7c8bb555140&chksm=c22bcfd6f55c46c05a98187e15b7bd80e2cf8a75d9e319bc51e54fce0411aa6d31d40c6d956c&scene=126&sessionid=1681269384#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247497533&idx=1&sn=46bb1fe3667e36db278cc7c8bb555140&chksm=c22bcfd6f55c46c05a98187e15b7bd80e2cf8a75d9e319bc51e54fce0411aa6d31d40c6d956c&scene=126&sessionid=1681269384#rd)

公共数据涉及社会生产生活的方方面面，蕴藏着巨大的经济和社会价值。

日前，**由青岛华通国有资本投资运营集团有限公司下属青岛华通智能科技研究院有限公司作为试点运营单位，聚焦公共数据资源化、资产化、价值化，面向社会各界需求，提供公共数据产品和服务，盘活公共数据资源价值，探索培育数据要素市场生态体系，激发数字经济活力**。

**盘活数据价值**

公共数据运营是一项创新型工作，当前，各地均处于路径探索阶段，运营思路和模式各不相同，尚未有成熟经验可借鉴。青岛市数据基础雄厚、产业优势明显、应用场景丰富，在制度规范建设、应用场景挖掘、数据流通交易等方面优势明显，为公共数据运营打下了坚实的基础。

在制度规范建设方面，2012年，青岛市率先在全省开展公共数据汇聚、共享和开放工作，此后围绕数据目录编制、质量管控、共享交换、分类分级、开发利用、安全保障等全流程，制定了一系列制度规范和技术标准，为公共数据运营奠定了坚实的基础。**目前，正在研究起草青岛市数据要素市场化配置改革三年行动方案、青岛市公共数据运营试点暂行管理办法，进一步为公共数据运营提供政策保障和制度保障**。

在应用场景挖掘方面，已在金融、交通、医疗、消费等领域进行了广泛调研，明确了应用场景，部分已实现落地。比如，在金融领域，已为信易贷、金企通等金融服务平台提供了200余类数据，帮助金融机构进行风险研判，提高贷款审批效率，赋能普惠金融发展，目前，支持贷前审查、贷中放款和贷后跟踪涉及金额总数约1232亿元，放贷总额约372亿元，惠及企业近9万家；与海尔财务公司共建设线上“数字实验室”，已支持海尔财务公司利用公共数据为“工赋青岛”平台上2.2万家企业提供用户画像和交易对手风险判断服务。当前，青岛围绕24条产业链、10大新兴产业园区建设，开展建群强链、招大引强、育苗倍增、创新赋能、要素保障专项行动，应用场景丰富，前景广阔。

在数据流通交易方面，数据服务、数据资产评估、数据交易等业态不断丰富。随着城市数字化转型，集聚了一批金融、交通、数字贸易等领域数据服务商。启动了数据资产评估试点，莱西市正开展数据资产申请、受理、审核、发证等登记工作，农业、制造业、建筑业等6个领域相关单位已完成注册。**在全国率先建成了海洋数据交易平台，制定了一套数据确权、数据质量评估、数据资产化、数据定价方法，通过联盟链进行数据确权，实现数据所有权和使用权分离，交易过程全程追溯，已初步实现海洋数据交易**。

**夯实城市治理“数字底座”**

数字要素本身不仅是新的经济增长点，还能赋能各行各业，带动各个领域实现数字化升级，成为驱动城市能级跃升的新引擎。

在强化政府侧公共数据支撑方面，青岛将建设全市一体化大数据平台，统筹汇聚全市各级各部门政务服务、城市治理、产业发展、物联感知等公共数据，为公共数据运营提供丰富的数据支撑。

在构建公共数据治理体系方面，青岛将以公共数据运营试点为核心，推进公共数据开发利用，根据市场发展需求，逐步引入和培育数据资源服务、数据资产评估、数据合规咨询、数据开发、数据经纪等“数据服务商”，不断丰富数据要素主体，推进数据要素资本化。

在打造丰富多样的应用场景方面，在点上，加大宣传，在金融、商贸、文旅、医疗等领域挖掘应用场景，做出亮点特色。在面上，支持各区（市）依托优势产业资源，加大数据招商力度，以数据要素赋能特色产业园区建设，包括海洋、影视、工业互联网、医疗健康、虚拟现实、文旅、商贸等领域，推动产业数据开发利用。

在加强制度保障体系建设方面，青岛将以法律法规、组织架构、制度规范、技术标准建设为核心，打造系统完备、上下配套、层次分明、科学规范的制度体系，从数据产权、流通交易、收益分配、安全治理等方面对公共数据价值发挥作出规范。

浪潮奔涌，城市进阶的新窗口已开启。青岛市大数据局相关负责人表示，下一步，青岛市大数据局将坚持系统观念，打造“1+1+N”公共数据运营体系（1个公共数据总体支撑+1个公共数据治理体系+N个公共数据应用），推动政企数据供需对接、有序流通、深度融合、创新应用，探索公共数据要素生产、流通、应用、收益分配机制，引入和培育一批数据服务商，构建一批分行业数据要素产业园区，推动青岛市数据要素市场加快发展，激发数字经济活力。
