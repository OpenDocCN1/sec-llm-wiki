# 国内首批网络安全保险签约仪式在沪举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247495880&idx=2&sn=6f187b03091afb90b931e34efcb43a65&chksm=c22bc823f55c41350ae853e6a7fea1d73991fd159eb3c2b8c42ee1bc659358368b5206c8b2dd&scene=126&sessionid=1681269398#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247495880&idx=2&sn=6f187b03091afb90b931e34efcb43a65&chksm=c22bc823f55c41350ae853e6a7fea1d73991fd159eb3c2b8c42ee1bc659358368b5206c8b2dd&scene=126&sessionid=1681269398#rd)

![](../Images/484d7018aca07b103eaed5558048ae64.png)

  

2022年7月26日，以“城市新纪元·未来新消费”为主题的2022上海信息消费节开幕。会上，隆重举行了国内首批网络安全保险的签约仪式。

  

![](../Images/37302b119b03c992bb6860761e06f148.png)

本次消费节开幕式由上海市经济和信息化委员会、长宁区人民政府主办，中国信息消费推进联盟、上海市信息服务业行业协会承办，在上海市经济委和上海保监会的联合推动下，进行了此次签约仪式。

  

会上，相关代表进行了分享，随着网络空间与物理世界的深度融合，对于企业用户来说，面临两个很大的挑战：

  

1、在全球日益猖獗的网络犯罪新形势下，网络安全变得越来越复杂和严峻，带来很大的安全方面的挑战；

  

2、国家颁布和实施了《网络安全法》、《数据安全法》及《个人信息保护法》等多项法律法规，关于合规和安全建设，给企业用户也带来新的挑战。

  

除了自身可以加大安全投入，还有谁可以在安全风险和事件发生时进行托底呢？

  

答案就是：网络安全保险。

  

近几年，全球因网络安全事件造成的经济损失达到数万亿美元，在此背景之下网络安全保险应景而生。

  

网络安全是数字发展的生命线，而网络安全保险是分散网络风险的有效工具，通过积极开展保险产品创新与服务优化工作，促进保险与科技的双向赋能，通过建设“保险+服务+科技”三位一体的网络安全保险服务新生态，为广大企业提供一站式的网络安全风险管理服务，让网络安全保险切实成为企业数字化的基础能力。

  

据相关报道，网络安全保险去年全球的规模达到100亿美元，而我国去年还不足1亿人民币，具有巨大的市场前景。

  

而对于安全企业来说，需要新的产品和服务模式创新，在事前评估、事中风控、事后应急等环节形成标准化和规范化的产品和服务新范式，来振兴整个信息安全行业。

  

网络安全保险是网络安全的最后一道防线，也是给企业的一颗“定心丸”，我们相信，网络安全保险未来可期。
