# 《中国算力白皮书（2022年）》：“算力五力模型”全面评价数据中心算力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247495103&idx=1&sn=cbb7a247aa1e164b947e9d236b27e2ab&chksm=c22bd554f55c5c4213f46f4d45a5ec7af6d1a5319c55a3672ad517e1b47e539177cf6198efdc&scene=126&sessionid=1681269403#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247495103&idx=1&sn=cbb7a247aa1e164b947e9d236b27e2ab&chksm=c22bd554f55c5c4213f46f4d45a5ec7af6d1a5319c55a3672ad517e1b47e539177cf6198efdc&scene=126&sessionid=1681269403#rd)

![](../Images/484d7018aca07b103eaed5558048ae64.png)

  

2022年7月29-31日，由工业和信息化部、山东省人民政府主办的2022中国算力大会在山东济南举行。在“智能凝聚新动力，算力开创新未来”分论坛上，中国信息通信研究院云计算与大数据研究所副所长李洁对《中国算力白皮书（2022年）》进行了精彩解读。

![](../Images/f5a8fb9d552893e4ebf2c8e18ec0b311.png)

李洁表示，党的十八大以来，工业和信息化部深入贯彻落实习近平总书记重要指示批示精神，大力推进以新一代通信网络为基础、以数据和算力设施为核心、以融合基础设施为突破重点的新型信息基础设施体系建设，打通经济社会发展的信息“大动脉”，为经济社会的数字化转型以及高质量发展奠定坚实基础。2021年7月，工信部发布《新型数据中心发展三年行动计划》明确提出，推动CPU、GPU等异构算力提升，逐步提高自主研发算力的部署比例，推进新型数据中心算力供应多元化。

  

白皮书聚焦国内外算力整体规模，通用算力、智能算力、超算算力和边缘算力的市场、技术等内容。基于单一指标难以全面评估数据中心的算力能力的现状，白皮书提出“算力五力模型”，为数据中心算力评估体系提供新的模型和方法，更好地指导和建议业界判断行业发展趋势，为数据中心未来算力规划和部署提供思路。
