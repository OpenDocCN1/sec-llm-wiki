# 欧盟各国监管机构禁令频发，谷歌将被禁止追踪数百万用户数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247492781&idx=2&sn=3217605532acd07511081ba018c88091&chksm=c22bdc46f55c555054cb625048115003105fbda82a7624210a2042d79375c312b60117d615c4&scene=126&sessionid=1681269417#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247492781&idx=2&sn=3217605532acd07511081ba018c88091&chksm=c22bdc46f55c555054cb625048115003105fbda82a7624210a2042d79375c312b60117d615c4&scene=126&sessionid=1681269417#rd)

![](../Images/4853a50a4dc6c8db33986c2f5080e2dc.png)  

欧盟近期监管谷歌对于其在移动搜索引擎行业和应用程序中垄断权力的滥用，现在，欧盟中越来越多的国家正在追查谷歌数据分析工具（Google Analytics），因为它被发现违反了《通用数据保护条例》（GDPR）。  

![](../Images/fbf02be97dd3140c34e39b4b315de514.png)

  

意大利数据保护机构发现，当地的一家网络出版商Caffeina Media Srl使用谷歌数据分析工具时不符合欧盟数据保护标准，**该数据分析工具收集了许多类型的用户数据，**包括设备 IP 地址、浏览器信息、操作系统、屏幕分辨率、语言选择以及访问网站的时间，最重要的是，**这些用户数据会被转移到美国**。监管机构称，这是一个“没有足够数据保护水平的国家”。目前，意大利监管机构给了该网络出版商Caffeina Media Srl公司90天的时间将其账户从谷歌数据分析工具转移出来，并且监管机构警告了其他正在使用谷歌数据分析工具的网站注意检查自己的合规性。

  

实际上，**意大利已经是第三个禁止谷歌数据分析服务的国家**。在此之前，法国的监管机构国家信息与自由委员会 (CNIL) 和奥地利的数据保护局都宣布了相同的禁令，而谷歌对这些禁令提出的上诉和辩护都被予以驳回，因为谷歌无法让监管机构相信谷歌在将用户数据传输到美国之前，谷歌会对来自欧洲的用户数据进行匿名处理。这些禁令将导致谷歌被禁止追踪数百万用户数据。

  

据AndroidPolice称，监管机构禁止本地网站使用谷歌数据分析工具的一大理由是欧盟法院2020年做出了名为“Schrems II”的裁定，这使得被称为“隐私保护”的框架中部分原则无效，而无效的部分中就包括向美国转移数据的措施。

  

AndroidPolice称，谷歌将在2023年关闭通用数据分析（Universal Analytics）平台，该平台严重依赖跟踪器来收集网站访问者的详细信息。谷歌数据分析工具4（Google Analytics 4）在使用追踪器方面有所松动，但仍可以通过其他方法获得大量相同的数据，因此可能不会赢得欧盟的青睐。
