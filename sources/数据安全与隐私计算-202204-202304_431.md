# 湖北省通信管理局开展网络和数据安全督导检查

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247491538&idx=2&sn=e29be6f275a48d817f13717bb479258c&chksm=c2282739f55fae2f28f54ba98e328e8b3a148eac59a775ce8c2a360219863ef6359764c38907&scene=126&sessionid=1681269427#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247491538&idx=2&sn=e29be6f275a48d817f13717bb479258c&chksm=c2282739f55fae2f28f54ba98e328e8b3a148eac59a775ce8c2a360219863ef6359764c38907&scene=126&sessionid=1681269427#rd)

![](../Images/4853a50a4dc6c8db33986c2f5080e2dc.png)

  

为督促基础电信企业贯彻落实《湖北省通信管理局关于开展2022年电信和互联网行业网络和数据安全检查的通知》要求，近日，湖北省通信管理局党组成员、副局长付景广带队赴湖北电信、湖北移动及湖北联通公司开展网络和数据安全督导检查。

![](../Images/0cf910b63a2fc34766f896a75e0d110d.png)

  

检查组听取了各企业网络和数据安全体系建设、自查整改工作情况汇报，重点了解了各企业网络和数据安全工作组织领导与责任体系、制度建设与落实以及技术措施与手段建设等方面情况。

付景广指出，为切实做好党的二十大网络和数据安全保障工作，全面提升行业网络和数据安全工作水平，湖北省通信管理局对网络和数据安全检查工作进行了专项部署，各企业要高度重视，制定专项工作方案，严格对照法律法规和标准规范，认真组织开展自查评估，对发现的问题和隐患要认真整改，确保检查工作取得实效。

付景广就进一步做好网络和数据安全工作提出了五点要求：

**一是要提高政治站位，充分认识网络和数据安全工作的重要性紧迫性。**要深入学习贯彻习近平总书记关于网络安全的系列重要讲话精神，统筹发展和安全，树牢风险意识，坚持底线思维，保障行业高质量发展。

**二是要压实主体责任，不断健全网络和数据安全责任体系和问责机制。**要依法依规构建主要负责人负总责，分管领导具体抓，牵头部门统筹协调，相关部门各负其责的网络和数据安全的工作格局，加大考核问责力度。

**三是要加强制度建设，持续完善企业内部网络和数据安全制度体系。**要结合实际，细化实化“三同步”、定级备案、数据分类分级、评测评估、风险隐患动态排查整改、应急管理、教育培训等制度机制，切实提升相关工作制度化规范化水平。

**四是要强化技术手段，进一步增强网络攻防对抗能力。**要以技术促管理，建设完善资产管理、数据管理、访问控制等管理手段，要加强态势感知、漏洞扫描、防拒绝服务攻击等专业化、集约化攻防平台建设。

**五是要增强全局意识，积极拓展网络空间安全支撑保障服务。**要在做好自身安全的基础上，发挥行业优势，为重点用户、重要行业提供安全服务，做好重大活动安全保障工作。
