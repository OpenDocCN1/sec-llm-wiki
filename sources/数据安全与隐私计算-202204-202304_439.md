# 《网络安全法》迎来五周年 共谋数据安全新征程！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzM0NzA3Ng==&mid=2247491390&idx=1&sn=4852052923fa21162dc6734d4fdabb3f&chksm=c22827d5f55faec3783cf2744b123462182171fe2135587b182ba6a33547c70ea86a0312b57e&scene=126&sessionid=1681269432#rd](http://mp.weixin.qq.com/s?__biz=MzkyNzM0NzA3Ng==&mid=2247491390&idx=1&sn=4852052923fa21162dc6734d4fdabb3f&chksm=c22827d5f55faec3783cf2744b123462182171fe2135587b182ba6a33547c70ea86a0312b57e&scene=126&sessionid=1681269432#rd)

**2022年6月1日，《中华人民共和国网络安全法》（以下简称《网络安全法》）正式实施迎来5周年。**中央网信办网络安全协调局发布五周年短片。  

  

![](../Images/c6c89777cdc35484d7a96d9b5769327e.png)

  

  

**点击下方视频查看短片内容****：**

  

作为国家实施网络空间管辖的第一部法律，《网络安全法》标志着我国网络安全工作有了基础性的法律框架，意味着建设网络强国的制度保障迈出了坚实一步，彰显了党和国家对网络安全问题的高度重视，**在中国网络安全史上，具有里程碑式的意义。**

![](../Images/8127cfbca89403c020938ab3a787c0f7.png)

  

《网络安全法》实施的五年，是《密码法》《数据安全法》《个人信息保护法》《网络安全审查办法》等网络安全配套法规政策密集发布的五年。数据安全已成为网络安全的核心与重点。在数据作为第五大关键生产要素，成为有力赋能数字经济，重塑国家竞争优势，提升国家治理现代化水平的重要基础性战略资源的时代背景下，如何与时俱进地发挥数据安全能力，促进数据价值提升，值得深入思考与探究。

  

数据作为新型生产要素，只有流动、分享、加工处理才能创造价值。数据价值提炼面临的主要问题有共享与交换、计算与分析、安全与治理。数据安全是数据应用的基础，也是实现数据资产化的前提条件。解决数据安全问题，应在识别数据资产并做好数据分级分类的基础上，从安全管理、技术防护两大方面考虑，改变数据安全“被动防御”的局面，积极打造“攻防兼备”立体化、动态化的数据安全防护体系。

  

从组织具体落实层面来说，可从数据安全治理的角度来着手，围绕数据安全治理的数据分级分类、角色授权和场景化安全三个核心理念，落实数据安全管理要求。针对数据全生命周期，不但要在各个环节考虑数据的安全防护措施，而且还应从一体化的数据安全策略出发加强风险管控，落实数据安全动态防御。面对当前海量的数据和用户的应用场景，应充分利用大数据分析和人工智能技术来加强数据安全保护。

  

数据正以前所未有的力度赋能数字经济高质量发展，数据安全问题已成为数字经济时代关系国计民生核心问题之一，在应对机遇与挑战的过程中，需要国家、数据所有者、数据安全厂商等多方参与。
