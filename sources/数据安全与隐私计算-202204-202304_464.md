# 中国数据交易实践趋势报告发布，把脉数据流通新发展，共话数据应用新未来

5月17日下午，“瓯江论数 数安中国”2022数据安全发展大会系列活动——数据交易思享会上，来自政府部门、数据领域、律师事务所、南都大数据研究院等机构专家以及行业企业代表齐聚温州，聚焦数据要素市场化新热点，把脉数据流通新发展，共话数据应用新未来。

 

在思享会上，中国网络空间安全协会、温州市委网信办、南都大数据研究院联合发布《布局与破局——中国数据交易实践趋势报告（2022年）》，报告共分为四个章节，分别从数据交易实践与布局、数据交易创新与破局、数据交易难题与对策来讲述。

 

  
  

后台回复“**趋势****报告**”，获得报告全文

  
  
  

**在数据交易创新与破局章节中，报告指出：**

 

1、立法先行：                

 

截至2022年1月份，全国共有56部有关数据的地方性法规、政府规章相继出台，其中省、自治区、直辖市和设区的市地 方性法规17部、经济特区法规1部、政府规章38部。北京、上海、深圳等数字化转型前沿省市，推动的地方性数据立法备受关注，特别是在数据交易问题上被赋予很高期待。

 

多地数据条例，均要求建立健全数据交易管理制度、规范交易行为、培育交易市场。《深圳经济特区数据条例》提出“政府应当推动建立数据交易平台并引导市场主体通过该平台进行数据交易”，《上海数据条例》要求“允许市场主体通过依法设立 的数据交易所进行数据交易”。两地都允许市场主体在数据交易平台之外依法自行进行数据交易，甚至允许市场主体对交易的数 据依法自主定价，政府主管部门进行引导，不会主动干预或限制。

 

2、平台谋变：  

 

面对确权难、定价难、互信难、监管难等行业瓶颈，上海、北京等地数据交易所也进行较多探索创新。北京国际大数据交易所是国内首家基于“**数据可用不可见，用途可控可计量**”新型交易范式的数据交易所。

 

针对确权难，北京国际大数据交易所利用**区块链、隐私计算**等先进技术，将数据交易全过程上链存储，通过官方的数据确权登记平台进行登记后，数据产品除敏感信息不可见外，其来源、用途、权属、流转过程都清晰可查。数据产品还将被按照分级分类管理原则，智能匹配相应的交易模式，**保障数据来源可追溯、 内容防篡改、主权可确认、利益可分配、过程可监管**。

3、合规建设：  

 

专家认为，具有政府背景的大数据交易所若能为企业数据安全提供**合规科技、风险评估与安全认证，并为个人信息提供可交易的规则**，企业将会有较大动力进场内交易。在法律层面应确立 大数据交易所的安全保障义务，对数据交易上下游风险担负守门 员责任，预防相关数据风险，承担数据治理责任。专家建议出台 中国版“数字守门人”制度，明确超级平台、大型平台、中小平台的标准和义务。

 

从当前的法律法规来看，公共数据的共享、开放，个人数据的可携权已经被提出，相关筹备及试点工作正在展开。在新法新规出台并制定的情况下，应给市场更多一点时间，方便了解、判断下阶段数据交易市场的方向与痛点。就实践情况而言，主要障碍不在于大方向上的规划，而在于细节标准尚未统一，合规与不合规之间的界线不清晰,但这恰恰需要通过实践活动进一步探索, 各界应该有一定耐心，让市场主体充分参与实践活动并归纳总结新的经验。

 

**在报告第四章节中，报告指出当下面临的部分难题：**

 

1、核心技术创新不足支撑不够  
  

研究发现，在数据安全保障、权属界定、价值挖掘、创新应用等核心领域，**应用A****I****区块链、隐私计算等技术创新依然不足**, 核心技术支撑不够，无法满足多样化的现实需求，导致“脱媒” 交易现象严重。

  

2、缺乏有效治理，阻碍数据流通  

研究发现，目前政府和互联网平台汇聚大量高价值数据，但伴随“大量”而来的是“混乱”“无序”、尤其是政府数据普遍缺乏有效治理，**不能提供持续、多源的、标准化的数据资源，阻碍数据流通**。政府对数据分类不明确，参与数据交易过程监管力 度不到位，数据脱敏、清洗、交易等关键环节缺少高效畅通的内部监督渠道，数据交易后纠错机制也不完善，缺乏高效的应对处理机制。

 

**报告针对以上问题给予的建言：**

 

1、推进数据市场标准化，降低流通壁垒与成本  

专家建议鼓励数据交易场所和交易机构、数据商、第三方服务机构、协会等多方市场主体在数据交易模式、数据交易流通标准规范、相关服务机制、技术应用等方面加强交流合作，突出审慎创新和先行先试，探索形成可复制可推广的经验做法。重点在数据资源管理规范、数据要素标准体系规范、数据交易技术安全规范等通用标准方面开展研究，推进市场标准化工作，降低数据交易流通壁垒和成本。

 

2、完善数据交易市场层级结构，培育生态体系  

  

专家建议依托数据交易所，探索培育以公共数据、个人数据、产业数据、跨境数据等主题数据空间为核心的专业数据市场。借鉴证券市场设置主板、中小板、科创板、新三板等不同市场层级做法，完善数据交易市场的层级结构，并探索建立不同层级数据交易需满足的进场标准、监管条件、交易规则等配套运行管理机制。培育多样化数据供需市场、交易场景，以及由数据交易机构、数据商和第三方服务机构等共建而成的数据交易市场生态体系。统筹考虑交易所、交易中心和交易平台等多层级数据交易场所和机构协同发展，增强不同机构间的互联互通。

  

来源：中国网络空间安全协会、温州市委网信办、南都大数据研究院
