# 首届数据安全共同体计划成员大会|数据安全产品能力专项检验证书颁发

2023年3月3日，由中国信息通信研究院安全研究所主办，大数据应用与安全创新实验室承办的首届“数据安全共同体计划成员大会”在京成功召开。在大会颁奖仪式上，奇安信网神信息技术(北京)股份有限公司、中电科网络安全科技股份有限公司（成都卫士通信息产业股份有限公司）、中移（苏州）软件技术有限公司、中国电信股份有限公司陕西分公司、北京神州绿盟科技有限公司、杭州美创科技有限公司、北京和鸿盈科技术有限公司等7家企业现场获颁“数据安全产品能力专项检验证书”。

![](../Images/6c71c5d6616fb009279545e21aa8fe3e.png)

为帮助安全厂商评估自身产品技术能力，更好地满足电信网、互联网、金融、医疗、能源等行业用户实际业务需求，推动数据安全产品技术水平的不断提升。自2021年起，中国信通院安全研究所大数据应用与安全创新实验室开展了“**数据安全产品能力验证计划**”，测评涉及的数据安全工具、系统、平台、产品，类型包括数据分类分级管理、数据异常行为监测、API安全管控、数据脱敏、数据库审计、数据水印、数据安全管控平台，共7种。迄今“数据安全产品能力验证计划”已为基础电信企业、安全企业、互联网企业完成了6期百余款数据安全产品的检验测评工作。

今后，“数据安全产品能力检验计划”将在“数据安全共同体计划”框架下联合各方力量持续深化，积极拓展评测能力与行业影响。[**“数据安全产品能力验证计划（第七期）”——数据脱敏进阶测评启动已启动**](https://mp.weixin.qq.com/s?__biz=MzkwODI0OTQ3MQ==&mid=2247485068&idx=1&sn=35defb76b20cb3261c4cd72331b6200e&scene=21#wechat_redirect)，行动详情及新闻动态敬请关注中国信通院官网、“数据安全共同体计划”公众号及光明网专栏、“大数据应用与安全创新实验室”官方公众号。
