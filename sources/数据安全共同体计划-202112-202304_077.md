# 数据安全“星熠”案例评审工作圆满结束

为推动数据安全产业蓬勃、可持续发展，发挥优秀案例示范引领作用，加强优秀案例推广，2022年7月，“数据安全共同体计划”启动了数据安全“星熠”案例征集活动，吸引了金融、IT、科研、制造等行业的多家企业积极参报，申报案例涉及**数据安全合规治理实践、隐私计算技术应用、sdk产品和数据安全技术与产品应用**四个方向。10月9至28日，“数据安全共同体计划”对申报材料完成初审工作。11月11日，数据安全“星熠”案例终审评审会在京召开。本次会议，由来自高校、科研机构、企业的数据安全领域专家组成评审组，对通过初审的参评案例进行评审。

![](../Images/5cf123b6b9d1d3ebe1c628c528815a02.png)

本次专家评审采取案例演讲及答辩形式进行，以线上线下相结合的方式开展。评审专家秉持公平公正、实用可行、注重创新的原则，从解决方案立意的创新性、撰写的规范性、研究的先进性、数据和结论的可信度以及推广示范应用价值等角度出发，对各个申报案例进行评分。下一步，数据安全“星熠”案例征集活动中遴选出的优秀案例将于近期通过“**数据安全共同体计划**”相关网站、公众号等平台进行公示。数据安全“星熠”优秀案例名单将在12月举办的**数据安全共同体成员大会（2022）**上公布，敬请关注。[![](../Images/04b3e42e56667e12164eb5a9bfe0e2e9.png)](http://mp.weixin.qq.com/s?__biz=Mzg5MDcxODc5NA==&mid=2247486726&idx=1&sn=8d33d25310c425b7ef22cee53370ac68&chksm=cfd91223f8ae9b35e1260994e5d55388bb2438a1cd4a458d17dec26c83a356dbdcdd16f288ab&scene=21#wechat_redirect)
