# 数据安全共同体计划征稿启事

2020年，《中共中央国务院关于构建更加完善的要素市场化配置体制机制的意见》对外公布，明确把数据作为一种新型生产要素写入文件，与土地、劳动力、资本、技术等传统要素并列为要素之一。2021年，《中华人民共和国数据安全法》和《中华人民共和国个人信息保护法》相继出台实施，标志着数据安全保护法治时代的真正到来。数据安全产业发展也逐渐获得业界高度重视。2021年底，中国信息通信研究院（以下简称“中国信通院”）联合60余家高校、科研院所、企事业单位共同发起“数据安全共同体计划”，旨在坚持以数据开发利用和产业发展促进数据安全，以数据安全保障数据开发利用和产业发展，落实国家数据安全产业生态建设工作布局。为提高数据安全水平，强化全行业数据安全保障能力，“数据安全共同体计划”现面向社会公开征稿，欢迎相关研究领域的专家学者、科研人员踊跃投稿。征稿文章在通过审核后将在“数据安全共同体计划”公众号及相关网站推广、发布。对于投稿质量优秀的企业和个人，我们将在年底进行颁奖并提供一定的奖励。 **征稿范围**  
  

本次征稿包括数据安全合规治理、数据安全产业、个人信息保护、移动应用安全等数据安全相关方向的文章或短视频。

**征稿类型**  
  

  

**1、实践案例**数据安全技术/解决方案等在各行业的应用案例介绍，包括开展行业、依据、目标、过程、体系、框架、技术及落地情况等内容。**2、标准解读**针对现有国家标准、行业标准中的重点要求，从产品和服务的落地、企业内部管理实践等角度进行说明。**3、专家解读**以专家角度针对有关国内外数据安全和个人信息保护相关法律法规、行业主管部门最新政策文件等进行解读，或对算力网络、云计算、5G、轻型密码等领域的研究成果、技术创新、最新应用技术等给出专业的分析、建议、预测等。**4、合规小课堂视频**围绕数据安全合规、个人信息保护工作热点、要点，以短视频（时长十分钟左右）形式介绍优秀合规实践，指导行业相关方开展数据安全、个人信息保护等工作，主题包括但不限于：重要概念解读、标准落地指南、安全合规实战、技术解决方案前瞻等。**5、知识科普**针对人民群众易误解概念，常见安全陷阱，实用保护技能等方面，以生动活泼、简明扼要的方式进行科普。可以采用短视频或文章的方式。**6、****深度分析**针对较复杂的现象、问题进行深入全面的调查研究、理论分析、技术解析，理清因果关系、内在逻辑，提出专业观点及建议。**7、每月观察**提供从重大发布、监管动态、行业动态、精彩观点、国际要闻、媒体热搜等角度，收集梳理数据安全和个人信息保护的相关新闻等内容。**投稿方式**  
  

本次征稿活动长期、持续进行。投稿文章应属于作者的原创性科研成果，数据真实可靠，具有重要的学术价值与推广应用价值。文章控制在2000-3000 字之间，内容包括题名、正文、作者信息等，采用word文档提交。投稿时请作者按照征稿范围投递至联系人邮箱。
