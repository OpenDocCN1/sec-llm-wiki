# 数据安全“星熠”案例征集|安全技术与产品应用案例征集

随着《数据安全法》和《个人信息保护法》陆续出台，国家对数据安全的重视程度达到了前所未有的新高度，各行业数据安全监管力度也在持续增强。为帮助安全厂商评估自身产品技术能力，提升数据安全产品技术水平，自2021年起，中国信息通信研究院（以下简称“中国信通院”）安全研究所开展了“数据安全产品能力验证计划”，迄今已启动六期专项行动（新闻链接：[中国信通院“数据安全产品能力验证计划（第六期）”——数据异常行为监测进阶测评启动](https://mp.weixin.qq.com/s?__biz=MzkwODI0OTQ3MQ==&mid=2247484808&idx=1&sn=b0c855d04b337ca28943184844866eb3&scene=21#wechat_redirect)），完成了50多家企业百余款数据安全产品的检验测评工作。为发掘优秀示范性产品，促进数据安全生态链各环节的交流与合作，推动数据安全产业蓬勃、可持续发展，2022年7月，中国信通院依托“数据安全共同体计划”启动了[数据安全“星熠”案例征集活动](http://mp.weixin.qq.com/s?__biz=Mzg5MDcxODc5NA==&mid=2247485711&idx=1&sn=128a763aa3a4faa9db1607eb295d4e52&chksm=cfd9162af8ae9f3c41df244988cb17b4cf4439a2a80218703992cf9728f8351d370ec1ff53ac&scene=21#wechat_redirect)，其中包括征集安全技术与产品应用案例，旨在加强优秀案例推广，为电信、金融、医疗、教育、能源等行业用户的数据安全产品选型提供参考依据，进而提升行业整体数据安全保障能力。欢迎各相关单位积极参与，申报优秀案例。![](../Images/755e64d71858fdfb120193c458341db7.png)**申报主体**（1）在中国境内注册的企业、事业、科研院所、学校等单位，行业组织，团队或个人；（2）申报项目的创意、产品、技术及相关专利归属申报单位、团队或个人，申报主体拥有自主知识产权，且无知识产权纠纷；（3）行业应用企业、运营商和方案提供商可联合参与申报。![](../Images/755e64d71858fdfb120193c458341db7.png)**申报案例范围**征集各垂直行业的数据安全技术与产品优秀解决方案和应用实践。“垂直行业”包括但不限于信息消费、融合媒体、工业互联网、车联网、物流、港口、采矿、电力、油气、农业、水利、教育、医疗、文化旅游、智慧城市等行业领域。“安全技术与产品”类型包括但不限于：数据分类分级、数据库审计、数据脱敏、数据异常行为监测、应用程序编程接口（API）安全、数据水印、数据加密、数据安全管控平台等。![](../Images/755e64d71858fdfb120193c458341db7.png)**申报要求**

申报案例需具备创新性、先进性、有效性，其中创新性包括项目的技术路线、解决方案、产品设计的独特性与创造性；先进性包括项目的研究方法、核心技术在行业中的领先程度；有效性包括项目在安全问题各环节的预期效果。

![](../Images/fb88f1bc7674c442d60b238e9035839d.png)**申报流程**

*   申报企业填写报名表（点击文末“阅读原文”即可下载），并发送至邮箱caojing1@caict.ac.cn。后续工作人员将根据报名情况反馈案例申报书，申报企业需于9月30日前将申报材料电子版发送到联系邮箱。
    

*   2022年10月，数据安全共同体计划将对申报材料首轮筛选。
    

*   2022年11月，数据安全共同体计划专家将对申报材料二轮评审。
    

*   2022年12月5日至9日，遴选出的优秀案例将通过“数据安全共同体计划”相关网站、公众号等平台进行公示。
