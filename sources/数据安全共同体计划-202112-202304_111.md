# 数据安全峰会2022 | SDK安全专项评测证书颁发

2022年7月28日，由中国信息通信研究院（以下简称“中国信通院”）安全研究所主办、数据安全共同体计划、大数据应用与安全创新实验室承办的“数据安全峰会2022”在京成功召开。在峰会证书颁发仪式上，深圳市和讯华谷信息技术有限公司、上海世全网络科技有限公司、上海优比客思科技有限公司、北京百度网讯科技有限公司、高德软件有限公司、每日互动股份有限公司、上海倍孜网络技术有限公司、北京鸿享技术服务有限公司、北京易数科技有限公司、北京美数信息科技有限公司、广州市玄武无线科技股份有限公司等11家企业现场获颁“SDK专项评测证书”。

![](../Images/89b8fcb46836088b34e5bdb030fc6ee8.png)

![](../Images/d1f52906eff44f1d56b1ebc056b7e409.png)获颁“SDK安全专项评测证书”的企业代表合影自2021年6月以来，中国信息通信研究院安全研究所发起“**SDK安全专项行动**”，紧跟信息技术发展趋势，依托大数据应用与安全创新实验室在数据安全、移动安全等领域的深厚积累，通过前瞻研究和实践探索，形成了覆盖安卓、iOS等多平台的完整测评体系，迄今已发起了四期专项行动，已有近五十款SDK产品报名参与，得到业内积极反馈和广泛认可。未来，SDK安全专项行动将在“数据安全共同体计划”框架下联合各方力量持续深化，积极拓展评测能力与行业影响。专项行动将开放第五期报名，行动详情及新闻动态敬请关注中国信通院官网、“数据安全共同体计划”公众号及光明网专栏、“大数据应用与安全创新实验室”官方公众号。

**数据安全共同体计划**

**（data security community）**

  

“数据安全共同体计划”为了促进《数据安全法》《个人信息保护法》落地实施，推动数据开发利用和数据安全领域的技术推广和产业创新，致力于促进数据安全产业链各环节的交流与合作，推动数据安全政策、技术、人才多要素良性互动，构建数据安全产业生态共同体。
