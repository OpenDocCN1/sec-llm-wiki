# 标准动态｜《企业数据安全体系规划与建设实施方法》行业标准编制组第一次线上研讨会顺利召开

随着《数据安全法》、《个人信息保护法》相继出台，区域性数据安全相关法规政策接连发布，行业主管部门数据安全和个人信息保护专项工作密集开展，数据安全监管力度持续增强，如何满足数据安全法律法规政策要求，切实防范数据安全风险，成为企业数据安全建设工作的核心目标。‍

  

为帮助企业和机构顺利开展数据安全体系规划与建设工作，中国信息通信研究院（以下简称“中国信通院”）牵头编制行业标准《企业数据安全体系规划与建设实施方法》，标准提出以数据为核心保护对象的企业数据安全体系规划与建设实施方法论，包括企业数据安全体系规划和建设的基本原则、实施流程、实施方法等内容，为企业数据安全体系规划和建设提供指导建议。

  

2022年4月21日，标准编制组针对《企业数据安全体系规划与建设实施方法》行业标准草案稿召开了第一次线上研讨会，数据安全领域相关企事业单位30余名专家参加了会议。

  

会上，中国信通院安全研究所专家首先介绍了标准编制的背景、目的及编制内容。随后，成都思维世纪科技有限责任公司、天融信科技集团股份有限公司、上海观安信息技术股份有限公司、深信服科技股份有限公司、北京炼石网络技术有限公司、北京明朝万达科技股份有限公司、IBM（中国）有限公司、郑州信大捷安信息技术股份有限公司、OOPO广东移动通信有限公司、腾讯云计算（北京）有限责任公司、北京奇虎科技有限公司、中国移动通信集团浙江有限公司、神策网络科技（北京）有限公司、杭州大拙信息技术有限公司等编制组专家对标准的框架和主要内容进行了热烈讨论，提出了有针对性的修改建议，为标准的进一步完善打下基础。

  

本次研讨会为数据安全领域相关企业和专家提供了良好的交流平台，在有效沟通中拓展了数据安全相关标准编制思路和研究方向，为数据安全产业健康发展提供助力。
