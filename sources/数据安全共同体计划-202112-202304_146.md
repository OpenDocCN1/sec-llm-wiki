# 关于召开数据安全领军企业对产业发展的示范带头作用研讨会的通知

2021年9月1日正式施行的《中华人民共和国数据安全法》明确提出“国家支持数据开发利用和数据安全技术研究，鼓励数据开发利用和数据安全等领域的技术推广和商业创新，培育、发展数据开发利用和数据安全产品、产业体系。” 数据安全产业进步与发展离不开领军企业的引领和带头作用。

  

数据安全共同体计划高度关注数据安全产业发展，在行业主管部门指导下正在开展数据安全领军企业相关研究工作。为进一步明确数据安全领军企业对产业发展的模范先锋作用，引导数据安全产业大中小企业融通创新、共同发展，现计划于4月19日举办“数据安全领军企业对产业发展的示范带头作用研讨会”，研讨会将围绕数据安全领军企业在标准制定、技术研发、产品推广、产业融合等领域对产业发展的积极影响等开展观点分享和讨论。

  

现向数据安全共同体计划成员单位发出诚挚邀请，请意向参与企业于4月14日17点前在线报名。

  

会议时间：

2022年4月19日（周二）14：00-17:00

  

接入方式：

本次研讨会将通过“腾讯视频”线上开展。

  

报名方式：

请有意参会的企业，下载报名表报名。
