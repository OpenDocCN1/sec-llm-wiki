# 工作动态丨数据安全合规治理推进小组第一次研讨会成功召开

    2022年3月16日，“数据安全合规治理推进小组”第一次研讨会成功召开，本次研讨会就数据安全合规治理实施方案进行了深度解剖，对数据安全合规治理实施目标框架、数据安全组织架构、制度体系、实施过程中的各环节中的关键工作、输出物等进行了研讨，为下一步数据安全合规治理工作在电信、互联网、金融、电力等行业的落地实施打下了良好的基础。

  

    会上，天融信专家艾龙分享了电力行业数据安全治理实践，以及以治理为引导构建持续的数据安全运营机制的建设思路。充分分析了电力行业现阶段行业背景和政策，围绕新型电力系统中大数据、云计算、人工智能等技术的引入所带来的数据安全风险，结合电力行业实际，从调研分析、治理评估、行动规划、体系设计、制度规范、分类分级、风险评估、技术保护等方面具体阐述了数据安全合规治理的实践的全过程。 

  

    上海观安专家刘德林解读了金标委发布的《数据生命周期安全规范》，从“数据生命周期安全框架”入手，结合实施案例，介绍了银行业的数据安全合规的治理体系、敏感数据分类分级、数据安全治理实施步骤，组织架构建设，制度建设等方面的经验，为银行业构建数据安全合规治理体系建设提供参考。

  

   “数据安全合规治理推进小组”于2022年1月18日正式成立，小组成员由业界知名安全专家组成，围绕各行业数据安全合规治理痛点问题进行研讨并给出规范化的解决方案，为各行业数据安全合规治理工作建立统一的操作细则，同时分享实践中的经验和优秀案例，指导企业和第三方服务机构开展标准化的数据安全合规治理建设工作。

  

    现诚邀业界同仁加入“数据安全合规治理推进小组”，共同推动数据安全产业生态高质量发展，聚焦先行示范，助力行业数据安全合规建设。
