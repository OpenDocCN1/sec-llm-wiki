# 信通院ICT深度观察报告会丨观安信息分享数据安全治理框架建设经验

    12月21日，由中国信息通信研究院（以下简称“中国信通院”）主办的2022中国信通院ICT+深度观察报告会——数据安全产业分论坛在线上举行。论坛特邀业内知名专家围绕数据安全技术与产业发展相关议题展开探讨，多维度分享精彩观点。观安信息首席安全顾问刘德林先生出席论坛，并分享数据安全治理体系框架建设经验。

保卫数据资源，打响大数据时代“安全防卫阻击战”

  
  
  

    数字经济飞速发展，对数据要素的掌控和利用能力，已成为衡量国家之间竞争力的核心要素，数据成为重要的国家资产和基础战略资源。在数据价值越发突出的同时，数据资产面临的安全风险与日俱增。这几年来，数据安全事件频频发生，对个人隐私、社会公共信息、企业商业机密、国家情报等敏感数据造成了严重安全威胁。

  

    刘德林表示，企业机构需要遵循数据安全原则，以数据安全分类分级为基础，建立覆盖数据生命周期全过程的安全防护体系。他认为，企业可以通过建立健全数据安全组织架构，明确信息系统运维环节中的数据安全需求，全面加强数据安全保护能力。

 

 

![](../Images/f1b2d96a455d4d7f19a26af55bd99b46.png)![](../Images/182046b7ffdef219f594815e3a5d140c.png)

建立数据安全治理体系，铸就大数据时代“铜墙铁壁”

  

    发展数字经济、加快培育发展数据要素市场，必须要把保障数据安全放在突出位置。2021年9月1日，《中华人民共和国数据安全法》正式施行。《数据安全法》的颁布实施标志着我国数据安全领域进入有法可依、依法建设的新发展阶段。在《数据安全法》后，《个人信息保护法》等数据安全领域相关法律法规陆续颁布施行。

  

    在刘德林看来，数据安全领域多部法律的相继颁布，对企业机构的数据安全保护提出了更加严格的要求。着力解决数据安全领域的突出问题，有效提升数据安全治理能力成为企业机构数据安全体系建设的首要任务。

  

    数据全生命周期涵盖收集、传输、存储、处理、共享、销毁共六个阶段，针对数据全生命周期的安全管理也是企业开展数据安全管理的核心和难点工作。刘德林建议，围绕数据全生命周期安全，从组织架构、原则/政策/程序、数据、文化、道德和行为、人员/技能/能力、服务/基础设施/应用程序六大领域开展数据安全治理，明确组织架构、建立数据安全制度体系，开展数据安全评估，实施数据安全建设、审计与监督。涉及组织内多部门协作、全流程制度、体系化实现技术、专业化人才培养等一系列工作，建立覆盖数据生命周期全过程的数据安全治理体系。

  

    数据安全治理任重道远，企业机构要抓住信息化发展的历史机遇，在合规保障及风险管理的前提下，实现数据的开发利用，保障业务的持续发展，确保数据安全与业务发展的双向促进，最大程度释放数据价值。

数据安全共同体计划简介

  

“数据安全共同体计划”是为了促进《数据安全法》《个人信息保护法》落地实施，推动数据开发利用和数据安全领域的技术推广和产业创新，集产、学、研、用于一体的综合性交流平台，致力于促进数据安全产业链各环节的交流与合作，推动数据安全政策、技术、产品、人才多要素良性互动，构建数据安全产业生态共同体。
