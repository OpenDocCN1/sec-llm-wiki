# 信通院ICT深度观察报告会｜凡泰极客：FinClip助力企业移动应用端数据安全生态建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5MDcxODc5NA==&mid=2247483876&idx=1&sn=37cb7312290f6caf66781e469c9f9b31&chksm=cfd91ec1f8ae97d7182822acce288d003a510395028699b09581d9607ff46f4369ce36a914f8&scene=126&sessionid=1681268982#rd](http://mp.weixin.qq.com/s?__biz=Mzg5MDcxODc5NA==&mid=2247483876&idx=1&sn=37cb7312290f6caf66781e469c9f9b31&chksm=cfd91ec1f8ae97d7182822acce288d003a510395028699b09581d9607ff46f4369ce36a914f8&scene=126&sessionid=1681268982#rd)

    2021年，《数据安全法》和《个人信息保护法》相继出台，国家对数据安全的重视程度达到了前所未有的新高度。强化全行业数据安全保障能力，落实数据安全法律法规政策离不开数据安全产业链和生态的有力支撑。在新一轮科技变革和产业变革推动经济发展，我国进入扎实推进共同富裕的关键历史阶段，数据安全产业生态建设对促进我国数字产业健康有序发展具有重大意义。

  

![](../Images/0e3c76c6d54f4799d6f6751c99640dff.png)

  

    12月21日，中国信息通信研究院组织举办的“2022中国信通院ICT+深度观察报告会-数据安全产业分论坛”在北京圆满落幕。会议邀请了业内知名专家围绕数据安全技术与产业发展相关议题作主题演讲，凡泰极客资深产品专家任馨怡受邀出席大会并分享了《小程序安全沙箱 SDK 助力企业构建数字化新生态》的主题报告。

  

    主题分享开篇，任馨怡就抛出了两个经典问题：1）安全、数据是不是只与大机构相关？2）安全、数据是不是一个成本部门？带着这两个问题，任馨怡通过详细介绍凡泰极客FinClip SDK 产品及其应用探索向与会嘉宾进行了深入浅出的讲解。

  

    凡泰极客由一群来自国内外顶级金融及互联网跨界工程师于2017年创办，始终致力于通过一套自主创新、中立可靠、灵活开放的企业级云原生移动应用数字引擎为数字世界的高效运行提供坚实的基础支撑，加速推动百行千业数字化转型。

  

    据介绍，凡泰极客旗下核心产品 FinClip 是市场上领先的企业端小程序解决方案。凡泰极客抓住企业数字化转型过程中构建数字生态连接能力的需求，向市场提供了兼容互联网主流小程序技术的轻应用平台——FinClip SDK，帮助企业IT打造自己的应用商店，开发、上架、管理与风控以小程序形态存在的碎片化业务场景，以乐高组件方式组装业务应用，赋能业务部门进行跨组织、跨机构、跨行业、跨终端的数字生态运营。

  

  

![](../Images/686c25877b9fbde5d258e1758baa7961.png)

  

   

    通过嵌入式沙箱 SDK，FinClip SDK可以嵌入任何 App 企业并私有化运行，可以实现企业数据隐私保护，杜绝信息安全泄露。通过 FinClip SDK 企业可实现自行拥有类似互联网大平台的能力，且已实现 SDK 插件化和平台企业高度可订制等功能。

  

![](../Images/6b8c872fe721063d847becf7a3bafb9b.png)

  

    任馨怡介绍，凡泰极客希望用小程序轻松连接世界，FinClip SDK 的核心优势主要体现在以下几个方面：

  

![](../Images/975aa19e7bfb0d6e4947ced1fd865bdb.png)

核心优势

![](../Images/c064c19db7f76866ee5920d442f4ae3e.png)

  

   1）沙箱技术能够在不下载安装升级卸载现有原有 App 的情况下，实现原生 App 的正常运行和 App 之间的快速跳转、分享转发

   2）多终端支持(Android、iOS、Windows、Linux、PC、车载系统)、连接不同硬件设备终端

   3）自带“应用商店”

   4）企业全私有化拥有，安全合规可控

   5）乐高化，让企业快速“组装”业务场景

   6）兼容互联网主流小程序标准，无需学习新技术，能利用大量开发者资源

   7）插件化连接不同基础技术提供商

   8）小程序连接客户

   9）开放接口连接应用开发者

  

  

    如何利用小程序安全沙箱 SDK 实现企业自身数字化新生态？凡泰极客FinClip SDK 给出了答案。任馨怡介绍称，FinClip SDK 使 App “组件化”，可实现企业外部生态引进来，公司业务走出去，具体表现为：

    1）功能生态更全：兼容微信，快速引入；

    2）需求响应更快：松散耦合，敏捷迭代；

    3）距离用户更近：分享裂变，快速索引；

    4）服务提供更准：灰度发布，千人千面等。

数据安全共同体计划简介

  

“数据安全共同体计划”是为了促进《数据安全法》《个人信息保护法》落地实施，推动数据开发利用和数据安全领域的技术推广和产业创新，集产、学、研、用于一体的综合性交流平台，致力于促进数据安全产业链各环节的交流与合作，推动数据安全政策、技术、产品、人才多要素良性互动，构建数据安全产业生态共同体。
