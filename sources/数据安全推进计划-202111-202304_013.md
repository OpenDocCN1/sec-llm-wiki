# 【重磅公布】数据安全推进计划2022年度表彰名单公示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247488263&idx=1&sn=79daa1255cbf1dc9f975640eec7025d4&chksm=cf2feeb2f85867a48feddac2264bd287aefe9b3a83d37918f2fa54dbf7601a2aa1c34b06cee0&scene=126&sessionid=1681269050#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247488263&idx=1&sn=79daa1255cbf1dc9f975640eec7025d4&chksm=cf2feeb2f85867a48feddac2264bd287aefe9b3a83d37918f2fa54dbf7601a2aa1c34b06cee0&scene=126&sessionid=1681269050#rd)

**数据安全推进计划**  
2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）联合三十余家企业正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。截至目前，数据安全推进计划共有成员单位352家。DSI成员单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。  
  
  
2022年DSI在成员单位、智库专家及各行业组织的大力支持与帮助下，围绕数据安全开展了一系列工作，共产出6份报告指南，开展6项标准研究，举办沙龙研讨10期、行业峰会2次，发布智库文章18篇，成果丰硕！

 

为表彰2022年度数据安全推进计划优秀成员单位及优秀个人，数据安全推进计划特设立**年度优秀组长单位、年度优秀贡献单位、工作组年度突出贡献单位、年度优秀贡献个人、年度优秀演讲家、数安智库年度优秀创作者、数安智库年度优秀专家**等奖项。现将年度奖项公示，公示期为2023年3月17日至2023年3月24日。公示期结束后，将在[**2023年3月30日召开的数据安全推进计划第一次全体会议**](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247487984&idx=1&sn=1ae0742b267819bdc81be9dd7964100f&chksm=cf2fec45f8586553ee609de03ed0c883897f7345d31581e7688b9dea4e28d0221b5d32388bda&scene=21#wechat_redirect)上颁发证书，欢迎广大成员单位参会！
