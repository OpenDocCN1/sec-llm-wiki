# 《数据安全产品与服务观察报告》编制工作启动，现征集参编单位！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247487832&idx=1&sn=f355396a5f947af860fb4f6866c434a5&chksm=cf2fecedf85865fb779f2415f16d7cd42bc971fffbffe9c4fc4f5cf36a218da635ff819f475b&scene=126&sessionid=1681269054#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247487832&idx=1&sn=f355396a5f947af860fb4f6866c434a5&chksm=cf2fecedf85865fb779f2415f16d7cd42bc971fffbffe9c4fc4f5cf36a218da635ff819f475b&scene=126&sessionid=1681269054#rd)

随着各行业企业的数字化转型持续深入，数据安全事件频发，亟需加强数据安全技术应用，支持数据安全产品及服务持续创新，保障广大用户的数据安全。《数据安全产品与服务图谱》是数据安全推进计划在数据安全产业研究领域的系列研究成果，历经两轮业内专家研讨。2023年1月，[《数据安全产品服务图谱（2.0）》](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247487483&idx=1&sn=8acaab6be23e7a87fdf89b8801da6ae9&chksm=cf2ff24ef8587b581e0782c8460075b7eca88b04b57dfee5be7ae8663be2f3eec6004e5cc3b3&scene=21#wechat_redirect)（简称“2.0图谱”）于第二届数据安全治理峰会发布，广受业内好评与关注。

为进一步分析我国数据安全产品与服务市场现状，洞察数据安全市场的未来趋势，数据安全推进计划（DSI）联合中国通信标准化协会大数据技术标准推进委员会（CCSA TC601）**启动《数据安全产品与服务观察报告》编写工作。**

本次报告编写周期为4周，计划于3月中下旬召开发布会。现面向2.0图谱参与单位，征集参编单位及专家。**本次征集活动截止时间为2023年2月15日（星期三）**，欢迎2.0图谱参与单位及专家踊跃报名。
