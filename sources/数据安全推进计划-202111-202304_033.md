# 数安智库 | 2023年度专家征集入库正式启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247487818&idx=1&sn=fa9dc1a0900976ec9ab232108ce3005a&chksm=cf2fecfff85865e96cc82c3ba263923ae7234789fffc5f3492cbd168de31f74fb5d3ac0bc823&scene=126&sessionid=1681269059#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247487818&idx=1&sn=fa9dc1a0900976ec9ab232108ce3005a&chksm=cf2fecfff85865e96cc82c3ba263923ae7234789fffc5f3492cbd168de31f74fb5d3ac0bc823&scene=126&sessionid=1681269059#rd)

数据是国家新型生产要素和基础战略资源的代表，数据安全已成为保障数字强国建设、护航数字经济发展的安全基石。2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进法律法规及监管政策的落实。目前，DSI共有参与单位337家，遍布电信、互联网、金融、汽车、安全厂商等行业。

  

![](../Images/ff1ed15a45ef56e594b2c0d7bb18ff8c.png)  
为广泛凝聚国内数据安全领域的专家力量，推动我国数据安全建设工作的高质量发展，DSI于2022年3月面向社会广泛征集数据安全领域专家129位，成立数安智库。一年来，智库专家多次参与标准讨论、沙龙分享、评估评审、征文活动等工作，积极为数据安全行业发展贡献力量。  
为更好的发挥智库力量，助力行业建设，**现启动2023年度数据安全专家入库事宜：**  

**征集时间**

![](../Images/475eeff0b9aff0975db6490d079b830a.png)  
自本通知发布之日起，截至2023年3月10日。  

**征集范围**

![](../Images/475eeff0b9aff0975db6490d079b830a.png)面向社会征集数据安全相关法规政策专家、咨询专家、技术专家。  
  
（1）法规政策专家需具备五年以上安全相关法律、地方法规研究经验，具备一定的法律法规条例制定经验更佳。  
（2）咨询专家需在安全相关领域公司有五年以上咨询经验。  
（3）技术专家需具备五年以上漏洞研究、数据防护、行为监控、权限管理、安全审计等相关领域的工作经历。  

**专家职责与权益**

![](../Images/475eeff0b9aff0975db6490d079b830a.png)  
数安智库将作为DSI智力支撑，参与到DSI各项工作中（任期一年），包括但不限于：（1）研讨决策DSI工作方向，牵头或参与DSI各项工作。  
（2）审定DSI各项工作成果，包括不限于研究报告、评估评测结果、标准。  
（3）作为演讲嘉宾参与DSI举办的沙龙、会议、培训等活动。  
（4）数安智库专家将优先获得DSI部分成果。  

**入库流程**

![](../Images/475eeff0b9aff0975db6490d079b830a.png)  
（1）DSI将根据报名信息（报名方式见文末）对专家进行初步审核。  
（2）对于通过初步审核的专家，DSI将通过访谈形式进行再次沟通，最终确认是否纳入DSI专家库。  
（3）DSI将为专家库专家颁发正式聘书。
