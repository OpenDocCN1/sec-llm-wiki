# 重磅 |《大数据 密钥管理系统技术要求》发布，征集首批评估单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247487815&idx=1&sn=f0b4b6d045b77e78dfae56afda25f96c&chksm=cf2fecf2f85865e4098e7b80a1f63520da670abb34cda52ef71fcf5abe5483a9455be94b7151&scene=126&sessionid=1681269059#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247487815&idx=1&sn=f0b4b6d045b77e78dfae56afda25f96c&chksm=cf2fecf2f85865e4098e7b80a1f63520da670abb34cda52ef71fcf5abe5483a9455be94b7151&scene=126&sessionid=1681269059#rd)

2023年1月5日，在第二届数据安全治理峰会上，《大数据 密钥管理系统技术要求》正式发布，由中国信息通信研究院云计算与大数据研究所大数据与区块链部工程师郝志婧进行介绍。

![](../Images/682a60a52ef6411c25fb8ed694776150.png)

  
在政策要求和企业需求的双驱动下，密钥管理成为企业安全工作的重要内容，密钥管理系统可满足用户的密钥管理需求。2022年8月，由中国信通院牵头，联合卫士通、联通数科等十余家单位专家共同编制《大数据 密钥管理系统技术要求》。  

►►►

**以下为现场PPT分享实录**

![](../Images/c042b485eb8dd2acf79212da5848d300.png)近年来，数字经济不断发展，复杂多元、规模庞大的数据所蕴含的经济价值和社会价值逐步凸显。密码技术在保护敏感数据、防止数据泄露、数据应用合规等方面发挥着至关重要的作用。密钥丢失或被盗，会为业务系统及数据带来严重损失，造成安全事故。

同时，国家要求采用商用密码技术、产品和服务集成建设的网络和信息系统进行商用密码应用安全性评估。密钥管理是商用密码应用安全性评估中的重要组成部分。

在政策要求和企业需求的双驱动下，密钥管理成为企业安全工作的重要内容。

密钥管理系统覆盖密钥的全生命周期，保护密钥的保密性、完整性和可用性，可以满足用户的密钥管理需求。

![](../Images/e56c15d44798400f3b81e26d195ca517.png)为进一步规范密钥管理系统技术体系，准确度量密钥管理系统技术水平，提升密钥管理系统的功能和性能，中国信通院云大所依托中国通信标准化协会大数据技术标准推进委员会（CCSA TC601）展开密钥管理系统规范编制工作。

![](../Images/514dd4de874f4d0cfd06de4559d79558.png)2022年8月，《大数据 密钥管理系统技术要求》编制工作正式启动，由中国信通院牵头，联合卫士通、联通数科等十余家单位专家共同编制，于12月份编制完成，现已进入评测单位征集阶段。

![](../Images/a82328ec79db4318be12df4c1352b581.png)密钥管理系统规范覆盖**密钥管理、密码设备管理、密码服务管理、产品管理四个能力域、22个能力项，共有80余条技术要求。**

![](../Images/e55832477544f17632c967ad3e953cec.png)未来，将从**持续评估、交流分享、标准迭代、案例征集**四个方面开展工作，期望通过相关工作完善密钥管理系统规范，提高密钥管理系统产品水平。

![](../Images/7b0f2ca51f50d1f0d196d92d7ee8d46b.png)

评测参与流程为：确定评测项目>商务合同确认>评测技术对接>评测时间排期>实际评测执行>组织专家评审>正式颁发证书。

![](../Images/249606da11b7d6bf5a28f6da3d0ddb56.png)
