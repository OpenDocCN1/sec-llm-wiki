# 大会前瞻 | 《数据安全产品与服务图谱2.0》亮点快报

数据安全技术是数据安全厂商立足之本，产品与服务的持续创新是厂商发展之阶。随着各行业企业的数字化转型持续深入，数据安全事件频发，亟需建立健全数据安全产业，支持数据安全产品及服务厂商通过数据安全技术的持续创新与应用保障广大企业的数据安全。  
为深化调研我国数据安全产品与服务市场现状，数据安全推进计划（DSI）联合中国通信标准化协会大数据技术标准推进委员会（CCSA TC601）面向数据安全技术产品、综合平台、全流程服务的116家厂商企业，开展两轮数据安全产品与服务调研，合计调研488款产品及服务，并形成《数据安全产品与服务图谱2.0》（以下简称“2.0图谱”）。2.0图谱将于2023年1月5日第二届数据安全治理峰会发布，敬请期待！

1

**观察数据安全厂商发展特点**  

2.0图谱通过评估百余份调研问卷数据，从厂商资质与营收、专利课题研究、产品及服务的市场布局与表现等方面，将数据安全厂商分为三大类型，对三类数据安全厂商的特点与发展现状进行观察与分析。  

2

**盘点数据安全产品与服务现状**  

2.0图谱对数据安全通用类产品、数据安全综合类产品、数据安全服务及其细分品类进行统计与分析，从产品及服务的技术应用、市场分布、发展趋势等方面情况进行总结。  

3

**分析数据安全产品与服务发展风向**  

2.0图谱通过分析当前数据安全产品及服务的技术应用、市场分布与表现等情况，明确数据安全厂商有待发掘的新领域，指出未来数据安全产品与服务发展的新风向。  

在2023年1月5日于北京举办的**第二届数据安全治理峰会**上，数据安全推进计划将发布《数据安全产品与服务图谱2.0》。更多报告详情，敬请关注2023年1月5日第二届数据安全治理峰会！![](../Images/8305a74d1717606b287ddebfc05ffc88.png)

** 数据安全推进计划**

  

2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。计划发起后受到全行业广泛关注和讨论，目前DSI拥有316家成员单位。DSI成员单位广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。**DSI入会咨询：姜铎 13521786562**
