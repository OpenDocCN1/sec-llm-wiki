# 数据安全推进计划第六批成员名单公布！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247486470&idx=1&sn=4590d6fba7cd1706db0da74ce8642f19&chksm=cf2ff1b3f85878a5792c6b6d995c7a6a1d211192b5051a7e1117d453cd0ed883619185f7b2a9&scene=126&sessionid=1681269083#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247486470&idx=1&sn=4590d6fba7cd1706db0da74ce8642f19&chksm=cf2ff1b3f85878a5792c6b6d995c7a6a1d211192b5051a7e1117d453cd0ed883619185f7b2a9&scene=126&sessionid=1681269083#rd)

2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。计划发起后受到全行业广泛关注和讨论，第六批一共20家企业通过审核，加入DSI，目前DSI拥有超过273家成员单位。DSI成员单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。

（DSI第六批通过企业名单见附录）

  
***2022年DSI工作小结：***

*   **数据安全标准方面**，制定了《大数据 数据防泄漏产品技术要求》《大数据 数据安全网关技术要求》《大数据 数据水印溯源产品技术要求》《大数据 数据安全运营管理平台技术要求》。目前相关[**评测评估**](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247486065&idx=1&sn=06b39a0e5ffb05783430f5b74f57b931&chksm=cf2ff7c4f8587ed2e0786111fae5770dd8df963604af2f927b690e5495a5f0a33ce670880c73&scene=21#wechat_redirect)均已开启，评测事宜可联系郝志婧：15712890577。  
    
*   **产业研究方面**，发布了国内首个《数据安全产品与服务图谱1.0》，私信回复“图谱”，即可下载《数据安全产品与服务图谱1.0》高清版。图谱收录了来自70家企业的301款数据安全产品与服务项目，全面系统的梳理了数据安全防护检测、数据安全运维运营、数据安全共享流通、数据安全服务四大板块，展现了当前数据安全市场现状，为企业按图选型提供了有力支撑。[**《数据安全产业与服务图谱2.0》征集已开启，欢迎各企业积极参与！**](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247486459&idx=1&sn=c4d9f66a284d8033c26f9c371d273139&chksm=cf2ff64ef8587f585da1105e79d5f015097f4fc4e70fb9cc7472b4db6380444d4f42048d0ba3&scene=21#wechat_redirect)  
    
*   **活动方面**，举办了数据安全服务实践、数据安全风险管理、数据安全运营管理平台的应用为主题的数安talks，每场活动在线观看人数均超过1000人次。数安talks第八期将于2022年8月26日开展。  
    
*   DSI在上半年**成立了汽车、金融工作组**，并组织开展多次组会，确定年度目标。工作组将聚焦行业数据安全关键问题，在政策解读、研究产出、关键问题研讨、案例汇编等方面持续开展工作。接下来，DSI还将陆续成立其他行业工作组。  
    
*   DSI于4月20日正式**成立数安智库**，截至目前，共有130位专家加入DSI数安智库。截至目前，数安智库专家已产出多篇数据安全方面的高质量文章（均已发布在DSI公众号）。未来数安智库将致力于深化行业研究，健全标准体系，开展人才培训。

  
为进一步推动数据安全产业发展，汇聚力量，凝聚共识，数据安全推进计划将继续征集第七批成员单位，欢迎更多企业加入我们，共同建设数据安全产业生态。
