# 首批“可信数安”评估评测结果公布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247485403&idx=1&sn=897bbb682fe4fc4ab253fa32bfd70cd9&chksm=cf2ffa6ef8587378c64e5e19bdc55b0c90784a2aa4f064ae2d8982fb37f658c7e3129c3f45d4&scene=126&sessionid=1681269091#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247485403&idx=1&sn=897bbb682fe4fc4ab253fa32bfd70cd9&chksm=cf2ffa6ef8587378c64e5e19bdc55b0c90784a2aa4f064ae2d8982fb37f658c7e3129c3f45d4&scene=126&sessionid=1681269091#rd)

2022年6月21日-22日，首批“可信数安”评估评测专家评审会举行。评审会专家由来自中国信息通信研究院、中国科学院信息工程研究所的专家组成。评审环节包括资料审核、质询与答疑、集中评议，共计16家企业的25项产品/服务通过了本次评审。

**关于“可信数安”评估体系**

“可信数安”评估体系是国内首个面向数据安全需求方及数据安全供应方的体系化、市场化数据安全能力评估体系。一方面面向建设需求方开展企业级、系统级数据安全评估，协助各组织提升安全能力，实现以评促建效果；另一方面面向建设供应方开展产品评测及服务能力评估，筛选优秀的产品与服务，推动技术及服务水平的进步。
