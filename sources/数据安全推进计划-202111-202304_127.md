# 重磅！《数据安全产品与服务图谱1.0》正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247485261&idx=1&sn=dd8d04e0e9c12c5de6289fd454242966&chksm=cf2ffaf8f85873eecc579c0d8c4aa3382386dc501f1146d04c09308609a7f3dd7638b2bcde12&scene=126&sessionid=1681269091#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247485261&idx=1&sn=dd8d04e0e9c12c5de6289fd454242966&chksm=cf2ffaf8f85873eecc579c0d8c4aa3382386dc501f1146d04c09308609a7f3dd7638b2bcde12&scene=126&sessionid=1681269091#rd)

2022年6月28日上午，中国信息通信研究院（以下简称“中国信通院”）联合中国通信标准化协会在京召开了2022大数据产业峰会。会上中国信息通信研究院云计算与大数据所大数据与区块链部副主任李雪妮正式发布**《数据安全产品与服务图谱1.0》**，并对基本内容进行了解读。

  

**《数据安全产品与服务图谱1.0》**（以下简称“图谱1.0”）由数据安全推进计划（DSI）联合中国通信标准化协会大数据技术标准推进委员会（CCSA TC601）编制，旨在梳理我国数据安全产品与服务的发展情况，掌握数据安全产品及服务的市场现状，从而帮助需求方更好的筛选数据安全产品与服务，标齐甲乙方对于数据安全产品与服务的认知，洞察数据安全市场的未来趋势。

图谱1.0收录了来自**70家**企业的**301款**数据安全产品与服务项目，梳理了**数据安全防护检测、数据安全运维运营、数据安全共享流通、数据安全服务**四大板块，展现了当前数据安全市场现状，能够为选型工作提供参考。
