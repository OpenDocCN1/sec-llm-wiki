# 2022年大数据产业峰会数据安全分论坛成功召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247485206&idx=1&sn=e1a5aed5a609ae429899b2c9967e0de6&chksm=cf2ffaa3f85873b530078c4efce3473bf0272e1ec88f955bb45d6915852ea7a985b5ed3811d4&scene=126&sessionid=1681269091#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247485206&idx=1&sn=e1a5aed5a609ae429899b2c9967e0de6&chksm=cf2ffaa3f85873b530078c4efce3473bf0272e1ec88f955bb45d6915852ea7a985b5ed3811d4&scene=126&sessionid=1681269091#rd)

2022年6月29日上午，中国信息通信研究院（以下简称“中国信通院”）召开2022大数据产业峰会数据安全分论坛。此次峰会由中国信通院、中国通信标准化协会指导，中国通信标准化协会大数据技术标准推进委员会主办。数据安全分论坛由数据安全推进计划、数据资产联盟、金融数据智能联盟承办，中国IDC圈协办。

  

  

![](../Images/2237a18caa0a93cf87a84d3e53943bc6.png)

  

本次数据安全分论坛由中国信通院云计算与大数据研究所大数据与区块链部副主任（主持工作）姜春宇主持。工业和信息化部网络安全管理局数据安全处四级调研员张洪、中国信通院云计算与大数据研究所所长何宝宏出席并致辞。 

![](../Images/94cdcc6a4fa4efc349fe9ad588b13a3f.png) 工业和信息化部网络安全管理局数据安全处四级调研员  张洪

张洪在致辞中指出，“政府引导、行业自律、多方联动”的数据安全格局已初步形成。工业和信息化部高度重视数据安全工作，在部党组关心支持下立足《数据安全法》及国家数据安全工作协调机制赋予的职责和使命，从政策标准制定、安全合规管理、产业发展环境营造等方面，加快行业数据安全管理工作的推进。下一步，工业和信息化部将深化巩固已有工作基础，从完善政策标准、夯实监管基础、强化能力建设、加快产业发展四方面综合施策，持续推进。

![](../Images/f8ecf2344c7646634bbc92f3413ac64e.png) 中国信通院云计算与大数据研究所所长  何宝宏

何宝宏在致辞中指出，加强数据安全保障成为数字经济时代最紧迫的议题。中国信通院发起数据安全推进计划，邀请金融、电信、汽车、能源等行业企业共同搭建交流平台，丰富数据安全生态建设。同时打造“可信数安”评估体系，坚持“以评促建”，推动行业健康发展。未来我们将在标准体系建设、评估评测推进、行业关键问题研究、业内人才交流等方面继续开展工作。 

![](../Images/d7c778b8298dfe1712f2d7a0f7d2dc48.png) 中国信通院云计算与大数据研究所副所长  魏凯

中国信通院云计算与大数据研究所副所长魏凯以《数据安全推进计划工作简介》为题，分享了数据安全推进计划（以下简称“DSI”）的工作内容、成员情况、服务项目、成果产出及未来工作方向。同时，还在会上宣布了DSI金融工作组、DSI汽车工作组的正式成立，公布组长、联席组长、副组长、成员单位名单，并启动新成员招募。此外，数安智库专家团队也在该环节正式亮相。

![](../Images/fcfa3896547517b7096640bc5f41a7e6.png) 中国信通院云大所大数据与区块链部副主任  李雪妮

中国信通院云计算与大数据研究所大数据与区块链部副主任李雪妮以《“可信数安”评估体系发布暨首批“可信数安”评估评测证书颁发》为题进行了分享，从“可信数安”评估体系构建背景、构建意义、评估框架、评估依据、首批评测结果等方面进行了介绍。该体系是国内首个面向数据安全需求方及数据安全供应方的体系化、市场化数据安全能力评估体系。一方面面向需求方开展企业级、系统级数据安全评估，协助各组织提升安全能力，实现以评促建效果；另一方面面向供应方开展产品评测及服务能力评估，筛选优秀的产品与服务，推动技术及服务水平的进步。

![](../Images/0b72b1efd7c6a3d3c68781d2ae21be7a.png) 江苏保旺达软件技术有限公司副总裁  刘险峰

江苏保旺达软件技术有限公司副总裁刘险峰以《构建合规和安全双驱动的数据安全整体防护体系》为题进行了分享，并在分享中指出需要基于合规驱动和数据安全攻防驱动，构建数据安全能力体系、合规体系、策略体系、组织体系、运营体系，以保障企业数据安全合规，防范数据安全风险。同时介绍了该数据安全体系在企业的实践和落地案例，并对数据安全产业未来发展提出思考和建议。

![](../Images/c9ca748189016f65f4d04e10ed9181fb.png) 北京亿赛通科技发展有限责任公司CTO  朱贺军

北京亿赛通科技发展有限责任公司CTO朱贺军带来《综合数据安全治理运营管理平台建设》的主题分享。他在分享中指出平台化管理是数据安全治理的基础和必要能力，通过集合资产识别、资产梳理、分类分级、安全防护、风险监测、持续运营等安全能力，形成一站式的数据安全运营管理平台，可以有效达成数据资产可视、数据威胁可管、数据风险可控、数据血缘可溯的目标。

![](../Images/29c0e9d3bd99b4077363e27914534de9.png) 御数坊创始人及CEO  刘晨

御数坊创始人及CEO刘晨带来《协同化智能化数据治理与安全一体化解决方案》主题分享。分享中介绍了数据治理与数据安全的背景、需求与政策趋势，提出了构建数据资产、数据认责与数据安全一体化的数据治理方案。指出通过构建业务、管理、技术、数据多维协同的数据组织与工作机制，并基于智能化引擎实现的数据资产发现与分类分级，能够赋能组织实现数据资产可视、数据权责清晰、数据质量提升与数据安全可控。

![](../Images/eb2a2b7e31af894b491357663203d4db.png) 成都卫士通信息产业股份有限公司数据安全专家  张兆雷

成都卫士通信息产业股份有限公司数据安全专家张兆雷以《科技化合规审计助力个人信息保护与数据安全》为题进行分享。他在分享中强调了合规审计工作的重要性，介绍了卫士通在个人信息合规审计平台建设方面的积累。该平台通过内外部联合审计模式，助力企事业单位精准定位合规风险，快速完善合规措施，同时服务审计部门便捷固化审计证据，高效完成审计工作。

分论坛上，各位演讲嘉宾倾囊而出，数千名线上观众热情参与，论坛圆满成功！未来，我们将携手各行业、各企业继续深耕数据安全建设，提供优质交流平台，促进行业不断向前发展。期待下次再见！
