# 中国信通院李雪妮：数据安全推进计划工作简介

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484984&idx=1&sn=19caed264f1a243d0ba91d8509cb6cec&chksm=cf2ffb8df858729bcb9ddb40857dd64b1a75820032eb6596820eddae7f1cd70766bd66009516&scene=126&sessionid=1681269095#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484984&idx=1&sn=19caed264f1a243d0ba91d8509cb6cec&chksm=cf2ffb8df858729bcb9ddb40857dd64b1a75820032eb6596820eddae7f1cd70766bd66009516&scene=126&sessionid=1681269095#rd)

2022年5月13日下午，中国信通院云计算与大数据研究所、数据安全推进计划（DSI）、中国通信标准化协会大数据技术标准推进委员会（CCSA TC601）、卫士通信息产业股份有限公司、长春吉大正元信息技术股份有限公司、阿里云计算有限公司共同举办“数安Talks”第六期《加密技术在数据安全的应用实践》。

  

本次“数安Talks”邀请卫士通信息产业股份有限公司、长春吉大正元信息技术股份有限公司、阿里云计算有限公司的数据安全专家作为分享嘉宾，对加密技术在企业的落地实践进行分享，直播观看达1000余人次。
