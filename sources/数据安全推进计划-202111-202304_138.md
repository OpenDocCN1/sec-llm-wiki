# 第四批名单公布！数据安全推进计划成员单位超200家

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484912&idx=1&sn=2a551c9e70efbdef25d1bf6c3d451cb5&chksm=cf2ff845f85871534e310fbe09ac5b63a75ae026ab023965e875ad61feee73f480fac12f56b1&scene=126&sessionid=1681269095#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484912&idx=1&sn=2a551c9e70efbdef25d1bf6c3d451cb5&chksm=cf2ff845f85871534e310fbe09ac5b63a75ae026ab023965e875ad61feee73f480fac12f56b1&scene=126&sessionid=1681269095#rd)

2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。计划发起后受到全行业广泛关注和讨论，第四批一共32家企业通过审核，加入DSI，目前DSI拥有超过200家成员单位。DSI成员单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。（DSI第四批通过企业详细名单参见附录）

2022年DSI在数据安全标准方面，制定了数据防泄漏产品技术要求、数据安全网关技术要求、数据水印溯源产品技术要求、数据安全运营管理平台技术要求；研究报告方面，正在编写《数据安全产品与服务图谱》《数据安全治理实践指南2.0》；活动方面，举办了《数据安全服务的实践与应用》《金融行业数据智能化分类分级应用》为主题的数安talks。此外，DSI还成立了超过110人的数安智库，未来将深化行业研究，健全标准体系，开展人才培训。

  

为进一步推动数据安全产业发展，汇聚力量，凝聚共识，数据安全推进计划将继续征集第五批成员单位，欢迎更多企业加入我们，共同建设数据安全产业生态。
