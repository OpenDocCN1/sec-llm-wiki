# DSI走进成员单位绿盟科技

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484889&idx=1&sn=8edf52456d6cbd51bd98dfef7f5b12b2&chksm=cf2ff86cf858717afad684f874b00fde32b60d568474aa00cc354f870f30324896f7c6a07b8c&scene=126&sessionid=1681269095#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484889&idx=1&sn=8edf52456d6cbd51bd98dfef7f5b12b2&chksm=cf2ff86cf858717afad684f874b00fde32b60d568474aa00cc354f870f30324896f7c6a07b8c&scene=126&sessionid=1681269095#rd)

近年来，我国数字化进程加快，相关法律法规不断完善，监管日趋严格，安全问题更加复杂多元，传统安全已无法应对新形势下的数据安全挑战。2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在推进企业的数据安全建设，推动促进《中华人民共和国数据安全法》等法律法规及监管政策的落实。计划发起后受到全行业广泛关注和讨论，截止目前，共有168家企业参与其中。DSI参与单位均为业内龙头企业，行业广泛分布于电信、互联网、金融、安全厂商、汽车、医疗等领域。

  

2022年4月22日，DSI办公室李雪妮、秦书锴、贾真走进DSI成员单位——绿盟科技集团股份有限公司。绿盟科技集团运营商事业部行业技术总监雷新、高级安全研究员陈磊博士、数据安全专家张岩等出席交流会。

  

绿盟科技集团股份有限公司，成立于2000年4月，在国内设有50余个分支机构为政府、金融、运营商、能源、交通、科教文卫等各大行业用户与各类型企业用户，提供全线网络安全产品、全方位安全解决方案和体系化安全运营服务。绿盟科技高度重视安全研究和技术创新，在数据安全、云安全、工业互联网、物联网安全、5G安全领域进行积极探索，为绿盟科技的核心竞争力和持续创新能力提供了有力的保障。

  

![](../Images/8503f14cc6fda5f45333e370b1ea3dfe.png)

  

交流会上，绿盟科技高级安全研究员陈磊博士、数据安全专家张岩与中国信息通信研究院DSI办公室与会领导一起，就数据安全治理、数据安全合规评估、数据安全防护、隐私保护技术、以及大型集团企业项目的数据安全平台建设经验等话题上开展深入交流。绿盟科技对于云大所的数据安全推进计划(DSI)提出建议与方法，特别在开展企业数据安全自评估、合规评估控制方法、合规评估策略等议题上进行互动，各抒己见，充分交流实践思路。

  

绿盟科技认为，数据安全推进计划应扎根于整体社会的数据安全生态建设，有效落实国家数据安全战略，推进企业数网融合的安全践行理念，加强企业数据要素流动评估。同时，绿盟科技还重点介绍了如何有效开展数据安全治理体系和隐私保护技术：

  

**1）绿盟数据安全治理体系：**

  

绿盟科技总结出了一套完整而科学的数据安全治理方法论，简单讲就是“知”、“识”、“控”、“察”、“行”。

  

知是分析政策法规、梳理业务及人员对数据的使用规范，定义敏感数据；识则是根据定义好的敏感数据，利用工具对全网进行敏感数据扫描发现，对发现的数据进行数据定位、数据分类、数据分级；控是根据敏感数据的级别，设定数据在全生命周期中的可用范围，利用规范和工具对数据进行细粒度的权限管控；察就是对数据进行监督监察，保障数据在可控范围内正常使用的同时，也对非法的数据行为进行了记录；行即是进行知、识、控、察的不断闭环运行，通过运营不断消除数据安全的中高危风险。

  

**2）绿盟数据隐私保护技术：**

  

陈磊博士介绍了绿盟在数据安全与隐私计算方向上的一些技术研究和实践。从合规要求出发，同时兼顾企业自身数据安全开发利用和数据安全需求，绿盟提出了两种赋能数据安全流转的技术方案：一种是基于数据脱敏的明文数据共享方案，该方案适用于需将原始数据提供给接收方进一步进行处理和统计分析的业务场景；另一种是基于隐私计算的计算结果方案，该方案适用于数据高度敏感只能提供计算结果和训练模型的业务场景。围绕这两种数据安全流转方案，随后介绍了隐私计算平台和数据安全产品在算法、技术上的创新性研究和突破，应用和实践案例；以及参与的数据安全标准和研究报告、论文和专利等情况。

  

  

随后，李雪妮介绍了DSI近期的工作成果以及后续的工作计划。截至目前，**DSI共开展9项标准制定，59项评估评测服务、5场数据安全公开课，以及两项研究报告。**DSI后续将在五个方面开展工作：**一是**开展数据安全领域技术、应用、产业相关研究，撰写相关标准、研究报告、白皮书；**二是**深入行业开展数据安全治理研究，促进行业数据安全能力提升；**三是**发掘数据安全治理优秀案例，促进行业应用推广；**四是**促进人才培养及行业交流，定期举办公开课、培训会等活动；**五是**依托DSI专家库，推动数据安全难点、重点问题研究。

  

最后，DSI办公室李雪妮与绿盟科技集团运营商事业部行业技术总监雷新就双方后续的合作方向进行了深入探讨。李雪妮表示，接下来DSI将继续按计划开展各项数据安全工作，并建立人才培训与认证体系，凝聚行业共识，推动数据安全发展。雷新表示，绿盟科技一直重视数据安全领域的前沿技术突破和产品能力创新，目前已经形成数据全生命周期流转防护能力的产品、服务以及面向各行业覆盖全场景的体系化解决方案。未来，绿盟科技将继续专注于数据安全领域，并深化与DSI的合作，共同助力数据安全行业发展，提升行业数据安全建设水平。
