# DSI走进成员单位数安信

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484868&idx=1&sn=b313739a5ed3c092c54ccc014c2c194c&chksm=cf2ff871f8587167227183c30959c01cbde8c79bcca48ce80b8f26b7a9d15ddd662dceae17f6&scene=126&sessionid=1681269100#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484868&idx=1&sn=b313739a5ed3c092c54ccc014c2c194c&chksm=cf2ff871f8587167227183c30959c01cbde8c79bcca48ce80b8f26b7a9d15ddd662dceae17f6&scene=126&sessionid=1681269100#rd)

近年来，我国数字化进程加快，相关法律法规不断完善，监管日趋严格，安全问题更加复杂多元，传统安全已无法应对新形势下的数据安全挑战。2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在推进企业的数据安全建设，推动促进《中华人民共和国数据安全法》等法律法规及监管政策的落实。计划发起后受到全行业广泛关注和讨论，截止目前，共有168家企业参与其中。DSI参与单位均为业内龙头企业，行业广泛分布于电信、互联网、金融、安全厂商、汽车、医疗等领域。

  

2022年4月21日，DSI办公室秦书锴、贾真走进DSI成员单位——数安信（北京）科技有限公司。数安信技术总监胡国华、研究院院长刘绍宇出席交流会。

![](../Images/9eaf753fcd3772ec955324a14d61cf61.png)

数安信专注提供法律加科技数据合规一体化解决方案，通过资深团队对法律的深刻理解并结合可信计算、大数据以及人工智能等科技手段，为客户提供“数据隐私、安全、合规及第三方风险评估与防范”等标准化产品、解决方案及拓展服务。公司聚焦数据合规及安全技术领域，深度参与数据安全国家标准与行业标准研制，并已申报多项技术发明专利。

交流会上，胡国华和刘绍宇重点介绍了数安信创业的愿景，力争成为国内在数据合规领域的领先厂商。数安信创立以来，已经积聚了一批法律和技术领域专业技术人员，并已深入参与了包括医疗、政务在内的行业数据合规标准研制，同时也快速开展了数据合规检测与数据安全等相关产品与解决方案的研发和试点工作。结合国内近年来推出的一系列数据安全相关的法律和法规，数安信主打数据合规与安全解决方案，并与业内各相关机构在数据合规与安全的咨询、培训、评估、标准研究等方面展开了广泛深入的合作，希望为相关行业的数据合规提供有力支撑。

  

随后，秦书锴、贾真介绍了DSI近期的工作成果以及后续的工作计划。截至目前，DSI共开展9项标准制定，59项评估评测服务、5场数据安全公开课，以及两项研究报告。DSI后续将在五个方面开展工作：一是开展数据安全领域技术、应用、产业相关研究，撰写相关标准、研究报告、白皮书；二是深入行业开展数据安全治理研究，促进行业数据安全能力提升；三是发掘数据安全治理优秀案例，促进行业应用推广；四是促进人才培养及行业交流，定期举办公开课、培训会等活动；五是依托DSI专家库，推动数据安全难点、重点问题研究。

  

最后，双方就后续的合作方向进行了深入探讨，结合双方各自优势能力，确定了在标准研究、培训及评估认证，以及医疗行业数据安全等相关领域进行深入合作。期望通过双方的合作，共同助力数据安全行业发展，提升行业数据安全建设水平。
