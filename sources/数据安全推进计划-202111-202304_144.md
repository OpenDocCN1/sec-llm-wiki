# DSI走进成员单位安恒信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484858&idx=1&sn=ec4425306449dbab89b367ef09c64a55&chksm=cf2ff80ff858711922e81fa23683b656e2b8000b05d63a9063e8749f3afb53ac71c6184d11c3&scene=126&sessionid=1681269100#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484858&idx=1&sn=ec4425306449dbab89b367ef09c64a55&chksm=cf2ff80ff858711922e81fa23683b656e2b8000b05d63a9063e8749f3afb53ac71c6184d11c3&scene=126&sessionid=1681269100#rd)

近年来，我国数字化进程加快，相关法律法规不断完善，监管日趋严格，安全问题更加复杂多元，传统安全已无法应对新形势下的数据安全挑战。2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在推进企业的数据安全建设，推动促进《中华人民共和国数据安全法》等法律法规及监管政策的落实。计划发起后受到全行业广泛关注和讨论，截止目前，共有168家企业参与其中。DSI参与单位均为业内龙头企业，行业广泛分布于电信、互联网、金融、安全厂商、汽车、医疗等领域。

  

2022年4月12日，DSI办公室魏凯、姜春宇、李雪妮、秦书锴、贾真走进DSI成员单位——杭州安恒信息技术股份有限公司。安恒信息副总裁钟诚、副总裁林明峰、销售经理史坤、业务拓展专家柏雪出席交流会。

  

  

安恒信息成立于2007年，自成立以来一直专注于安全领域。安恒信息以云安全、大数据安全、物联网安全、智慧城市安全、工业控制系统安全及工业互联网安全五大方向为市场战略。凭借强大的研发实力和持续的产品创新，已形成覆盖网络信息安全生命全周期的产品体系，包括安全基础产品、安全平台以及安全服务。

  

  

**交流会上，林明峰介绍到，安恒提出CAPE数据安全架构，即以数据为中心驱动安全体系建设。**要求安全和风险管理领导者必须使用以数据为中心的保护和监测的技术和工具，以应对关键数据的威胁和合规性问题。与主要业务利益相关方配合，建立组织范围的数据安全战略，制定适当的数据安全策略，以平衡业务目标，为减小和应对风险和威胁，确定不同敏感数据所需的数据安全控制。在政务信息共享平台建设场景中，以数据为中心的数据资产是多元安全防护的复合体。在做好网络、主机、应用等一应基础设施安全建设的基础上，既要做好政务信息共享平台层面的基础设施安全加固，又要将数据安全防护和风险控制从点到面拉通形成安全策略一致的体系；既要对数据形成资产化的精细管理控制，又要对数据做到全生命周期流转的安全防护和流转过程中的风险感知；既要对数据安全事件快速定位溯源，又要在溯源过程和日常审计中形成风险监控能力；既要有人机高度结合的运营管控对接，又要不断迭代形成智能化学习自动化运营。因此，可以将数据安全核心能力分为：基线核查能力、数据梳理能力、数据保护能力和监控预警能力。

  

  

**随后，李雪妮介绍了DSI近期的工作成果以及后续的工作计划。**截至目前，DSI共开展9项标准制定，59项评估评测服务、5场数据安全公开课，以及两项研究报告。DSI后续将在五个方面开展工作：一是开展数据安全领域技术、应用、产业相关研究，撰写相关标准、研究报告、白皮书；二是深入行业开展数据安全治理研究，促进行业数据安全能力提升；三是发掘数据安全治理优秀案例，促进行业应用推广；四是促进人才培养及行业交流，定期举办公开课、培训会等活动；五是依托DSI专家库，推动数据安全难点、重点问题研究。

  

  

**最后，云大所副所长魏凯和安恒信息副总裁钟诚就双方后续的合作方向进行了深入探讨。**魏凯表示，接下来DSI将继续按计划开展各项数据安全工作，并建立人才培训与认证体系，凝聚行业共识，推动数据安全发展。钟诚表示，在国家数字化进程加快，相关法律法规不断完善，监管日趋严格的背景下，安恒信息将继续专注于安全领域，并深化与DSI的合作，共同助力据安全行业发展，提升行业数据安全建设水平。
