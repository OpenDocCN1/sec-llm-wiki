# 亿赛通张赛：数据安全服务的实践与应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484734&idx=1&sn=cebdead09f498907d942c777bb367f45&chksm=cf2ff88bf858719d8843c41288221c69cb816200cf9e80cbe2bd5e90057e808cf1bb97e7ef9a&scene=126&sessionid=1681269100#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484734&idx=1&sn=cebdead09f498907d942c777bb367f45&chksm=cf2ff88bf858719d8843c41288221c69cb816200cf9e80cbe2bd5e90057e808cf1bb97e7ef9a&scene=126&sessionid=1681269100#rd)

  

2022年3月31日下午，中国信通院、中国通信标准化协会大数据技术标准推进委员会（CCSA TC601）、数据安全推进计划（Data Security Initiative, 以下简称DSI）共同举办“数安Talks”（原数据安全公开课）第五期《数据安全服务能力专场》。

  

中国信通院云计算与大数据研究所副所长魏凯对本次“数安Talks”发表了致辞，云计算与大数据研究所大数据与区块链部高级业务主管李雪妮主持了本次“数安Talks”。

  

![](../Images/426ef795606bc5f55aa8441af9e6c7bc.png)

  

魏凯介绍了DSI自2021年9月1日成立以来，在数据安全理论技术研究、数据安全评估评测服务、数据安全标准体系建设、行业交流平台搭建等方面的工作成果，表达了DSI作为公益性合作项目，依托大数据协同安全技术国家工程实验室、中国通信标准化协会大数据技术标准推进委员会、中国互联网协会数据治理工作委员会开展具体工作，打造健康规范的数据安全生态体系，全方位提升企业数据安全能力的成立愿景，最后对长期支持DSI各项工作的企业单位、专家个人表示感谢，期待DSI与各行业、企业单位携手共进，行稳致远，深耕数据安全，为国家数字经济发展保驾护航。

  

本次“数安Talks”邀请360（北京奇虎科技有限公司）、北京亿赛通科技发展有限责任公司、御数坊（北京）科技有限公司的数据安全专家作为分享嘉宾，对数据安全服务能力的建设内容与方法论、数据安全服务实践经验进行分享。本次“数安Talks”直播观看达1000余人次。

  

![](../Images/bb28a712a15e60b995c05d3f7b021e9f.png)

  

亿赛通数据安全资深咨询专家通过对亿赛通以往数据安全服务的实践案例，指出了分类分级对于企业进行数据安全建设的重要性，并分享了亿赛通数据安全服务体系与具体建设经验。

  

以下为部分PPT及介绍。

  

亿赛通基于对数据安全服务驱动力和方法论的沉淀，将重点聚焦在数据的权限和场景方面，分阶段实现数据安全体系化建设。从业务需求、资产梳理、分类分级、策略制定、技术落地、制度优化和人员培训等方面提供完整的数据安全服务，切实帮助企业实现对数据安全事件的有效管控。

  

![](../Images/bd39c913d734817b4020f52e65f8dea9.png)

  

亿赛通专家在课程中提到，数据安全服务应覆盖数据安全建设全生命周期，涉及梳理、规划、建设和执行等阶段。在数据安全体系建设初期即引入咨询服务，通过指导企业数据安全体系合规建设，提升数据安全保障能力，同时配合有效的技术工具，使企业数据安全防护能效最大化，整体促进企业数据安全建设发展。

  

![](../Images/c8b61853c997cb617c57cdee0e186c9a.png)

  

亿赛通的数据安全建设方法论，提出以数据安全为中心，围绕“一个中心，四个领域、五个步骤”的全工作场景、全业务流程、全生命周期数据安全服务方案。大力开展数据安全治理、数据资产分级分类、数据安全风险评估、数据应用安全等领域相关工作，建立数据管理长效机制，夯实数据基础工作，支撑数据模型的运行。后续完善重点领域管理能力，管理体系完善建设，加强优化组织、制度、技术、人员闭环管理，推进数据管理各领域工作全面开展和数据安全管理能力全面提升，全面提升企业的数据安全建设成熟度。

  

![](../Images/aa2d078da91460be283cfdae168b0109.png)

  

随着数据安全态势愈发严峻化，数据安全服务成为业务的主旋律之一，全面体系化的专业服务与解决方案，是各行业的需求痛点。现有客户对安全的期望也在不断的变化，不仅要通过技术来满足安全需求，更对前期规划及后期运维服务提出了更高的要求，安全服务成为企业数据安全建设的切入点，高质量的安全服务不仅可以进一步提升客户安全体系的能力，同时也可以加深安全厂商与企业客户双方的粘性，加深对企业的了解，对症下药。通过安全服务工具的开发、安全体系的建设，帮助客户得到智能化的安全服务体验，与企业实现安全能力共建，为企业安全保驾护航。
