# 征文启事|数据安全推进计划等你来投

近年来，国家数字化进程加快，相关法律法规不断完善，监管日趋严格，安全问题更加复杂多元，传统安全已无法应对新形势下的数据安全挑战。为推动我国数据安全建设工作的高质量发展，2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）联合三十余家企业正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在推进企业的数据安全建设，推动促进《中华人民共和国数据安全法》等法律法规及监管政策的落实。

  

“数据安全推进计划”公众号是由中国信通院打造的数据安全行业资讯分享平台，关注者来自政府机构、各行业项目采购方、安全公司等。本次征文活动由“数据安全推进计划”公众号发起，文章在通过审核后均将在该公众号上进行发布。

  

**0****1****征稿介绍**

本次征稿将设5个专栏，分别是政策解读、行业产业观察、企业实践、技术解读、前沿资讯。

  

****政策解读****

·国内外数据安全法律法规及政策解读

  

**行业产业观察**

·各行业数据安全深度观察

  

**企业实践**

·企业数据安全治理实践

·多场景下数据安全解决方案实践

  

**技术解读**

·数据安全前沿技术解读

·数据全生命周期安全技术梳理

·数据安全技术应用现状及未来发展研判

  

**前沿资讯**

·国内外最新数据安全相关新闻

·近期重大数据安全事件收录

  

**0****2****投稿收获**

DSI自发起以来，受到全行业的广泛关注。截至目前，DSI共收到近300家企业的参与申请。目前，已有168家企业正式成为DSI的参与单位。参与单位广泛分布于电信、金融、互联网、汽车、云公司、安全公司、软件与大数据企业、通信、隐私计算、律所等行业领域，均为业内龙头企业。此外，DSI通过组织标准讨论、技术沙龙、高端峰会、公开征集等形式汇聚了一大批优秀的数据安全专家，包括技术专家、咨询专家、法律专家，并成立专家库，共同研究数据安全前沿动态，深入行业关键应用场景，探讨并解决数据安全面临的难点、痛点。通过DSI搭建的行业交流平台，促进企业凝聚共识，推动数据安全建设发展。

  

通过本次征文活动，投稿者不但可以藉由这一机会记录思想成果，分享数据安全工作经验，还能够在整个行业平台上展现自己或供职企业的能力。

  

我们每年会组织开展投稿评比，评比包含专家评分及文章阅读量两个因素（专家主要来自于DSI专家库）。对于供稿优秀的企业和个人，我们将在年底进行颁奖并提供一定的奖励，敬请期待！

  

**0****3****征稿要求**

****文章篇幅****

建议每篇2000-3000 字之间。

  

**文章主题**

围绕数据安全这一主题进行创作。

  

**注意事项**

请勿单纯宣传本公司商业产品或服务。

提交作者信息。个人简介100字左右，包含所在公司、联系方式、从业经验、研究领域等。
