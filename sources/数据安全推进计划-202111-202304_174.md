# 关于征集数据安全推进计划专家入库的通知

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484115&idx=2&sn=2fb04dfa043c6b7b37efd51f00962066&chksm=cf2fff66f85876707ec10df5084c24bd2b49cf7e6debfdddfbd3564620782a4588b8340ae5ed&scene=126&sessionid=1681269108#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484115&idx=2&sn=2fb04dfa043c6b7b37efd51f00962066&chksm=cf2fff66f85876707ec10df5084c24bd2b49cf7e6debfdddfbd3564620782a4588b8340ae5ed&scene=126&sessionid=1681269108#rd)

  

数据是国家新型生产要素和基础战略资源的代表，数据安全已成为保障数字强国建设、护航数字经济发展的安全基石。2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《中华人民共和国数据安全法》等法律法规及监管政策的落实。目前，DSI共有参与单位168家，遍布电信、互联网、金融、汽车、安全厂商等行业。

![](../Images/ff1ed15a45ef56e594b2c0d7bb18ff8c.png)

  

为广泛凝聚国内数据安全领域的社会力量，推动我国数据安全建设工作的高质量发展，DSI决定成立专家库，现面向社会公开征集数据安全相关法规政策专家、咨询专家、技术专家。相关事宜通知如下：

  

**征集时间**

自本通知发布之日起，截至2022年3月20日。  

  

**征集范围**

数据安全相关法规政策专家、咨询专家、技术专家。  

  

（1）法规政策专家需具备五年以上安全相关法律、地方法规研究经验，具备一定的法律法规条例制定经验更佳。

  

（2）咨询专家需在安全相关领域公司有五年以上咨询经验。

  

（3）技术专家需具备五年以上漏洞研究、数据防护、行为监控、权限管理、安全审计等相关领域的工作经历。

  

**专家权利**

专家库将作为DSI智力支撑，参与到DSI各项工作中，包括但不限于：  

  

（1）参与决策DSI工作方向，牵头或参与DSI各项工作。

  

（2）审定DSI各项工作成果，包括不限于研究报告、评估评测结果、标准。

  

（3）作为演讲嘉宾参与DSI举办的沙龙、会议、培训等活动。

  

**专家确定流程**

（1）DSI将根据报名信息（报名方式见文末）对专家进行初步审核。  

  

（2）对于通过初步审核的专家，DSI将通过访谈形式进行再次沟通，最终确认是否纳入DSI专家库。

  

（3）DSI将为专家库专家颁发正式聘书。
