# 数据安全推进计划公布第三批参与单位名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484115&idx=1&sn=58a83fdee7ee3e7b6e43dfecdb124fec&chksm=cf2fff66f8587670021cb68a582fb9fc4c8623a935b88b10d5ba57fe4bd5f87eb8f459e11694&scene=126&sessionid=1681269108#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484115&idx=1&sn=58a83fdee7ee3e7b6e43dfecdb124fec&chksm=cf2fff66f8587670021cb68a582fb9fc4c8623a935b88b10d5ba57fe4bd5f87eb8f459e11694&scene=126&sessionid=1681269108#rd)

  

2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。计划发起后受到全行业广泛关注和讨论，截止目前，共有168家企业参与其中。DSI参与单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。（DSI第三批通过企业详细名单参见附录）

  

2021年DSI在数据安全标准制定、公开课推广、行业报告研究、评估评测开展等方面，得到了参与单位及社会各界的大力支持，取得了丰硕的研究成果，为数据安全生态建设提供了有力支撑。

  

为进一步推动数据安全产业发展，汇聚力量，凝聚共识，数据安全推进计划将继续征集第四批参与单位，欢迎更多企业加入我们，共同建设数据安全产业生态。
