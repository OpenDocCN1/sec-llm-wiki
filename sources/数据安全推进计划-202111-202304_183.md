# 数据安全推进计划（DSI）第三批参与单位开放征集

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247484031&idx=1&sn=111d42ba2e69d52d75ee8f77306b706b&chksm=cf2fffcaf85876dc2be9f3ed6418e69790a72785540ee29951df389ad72f6a00eee98551d93e&scene=126&sessionid=1681269233#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247484031&idx=1&sn=111d42ba2e69d52d75ee8f77306b706b&chksm=cf2fffcaf85876dc2be9f3ed6418e69790a72785540ee29951df389ad72f6a00eee98551d93e&scene=126&sessionid=1681269233#rd)

  
背景

2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）联合三十余家企业正式发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”），旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。DSI自发起以来，受到全行业的广泛关注，共有来自电信、金融、互联网、汽车、云公司、安全公司、软件与大数据企业、通信、隐私计算等行业领域的138家企业正式成为DSI的参与单位。（企业详细名单参见附录）

  

![](../Images/8c70bc1c3695e34db700dd1d11e8de45.png "图片 1.png")

  

在众多参与单位的共同努力下，DSI自发起以来，在标准研制、报告产出、培训研讨、评估评测方面取得了丰硕的成果。

  

**1、标准制定方面，**DSI依托中国通信标准化协会大数据技术标准推进委员会完成了《数据安全服务能力分级要求》、《数据分类分级工具技术要求与测试方法》、《数据审计工具技术要求与测试方法》、《数据安全治理能力评估方法》4项标准的制定工作，得到了近50家数据安全企业的支持。目前，更多标准工作正在快速推进中，请联系：

**2、评估评测方面，**推动面向需方的数据安全治理能力评估（33家参与）、数据安全风险评估、个人信息保护评估，以及面向供方的数据安全产品评测（首批9款产品参与）及服务能力评估（首批17项服务参与），受到业界广泛好评。最新评估评测结果已在2021年数据安全产业峰会暨可信隐私计算高峰论坛上发布。更多咨询请联系：

**3、行业交流方面，**DSI联合InfoQ、DataFunTalk、华为云、百度、小米、启明星辰、天空卫士、安恒信息等机构举办了多场数据安全相关主题交流，并推出DSI数据安全公开课系列活动，内容覆盖《数据安全法》解读、数据安全治理体系建设、数据安全防护体系实践等，帮助成员单位理解法规，提升意识，理清建设思路。

  

**4、报告产出方面，**DSI面向参与单位发放调研问卷，收集参与单位在数据安全工作中面临的挑战和需求，并整理发布《2021年数据安全行业调研报告》。

  

“数据安全推进计划”是一个公益性合作项目，依托大数据协同安全技术国家工程实验室、中国通信标准化协会大数据技术标准推进委员会、中国互联网协会数据治理工作委员会开展具体工作，致力于打造健康规范的数据安全生态体系，帮助企业了解监管要求，全方位提升企业数据安全能力。主要工作内容包括：1、搭建交流平台，最新政策法规解读；2、开展数据安全方法论和技术体系研究；3、建立健全数据安全标准体系；4、依托标准打造数据安全咨询与评估评测解决方案；5、开展数据安全人才培训。

为进一步推动数据安全产业发展，汇聚力量，凝聚共识，数据安全推进计划将继续征集第三批参与单位，欢迎更多企业加入我们，共同建设数据安全产业生态。
