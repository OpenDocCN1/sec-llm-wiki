# 数据安全推进计划（DSI）参与单位名单公布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247483727&idx=2&sn=20e163aaa2eaf86d1960b2021d4071f2&chksm=cf2ffcfaf85875ecc748947dfa99a290f96af71a4fa97075d7bb744d7027902f46fefe6a6fd8&scene=126&sessionid=1681269238#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247483727&idx=2&sn=20e163aaa2eaf86d1960b2021d4071f2&chksm=cf2ffcfaf85875ecc748947dfa99a290f96af71a4fa97075d7bb744d7027902f46fefe6a6fd8&scene=126&sessionid=1681269238#rd)

  
背景

数据安全作为发展数字经济、加快培育数据要素市场的重要保障，是各方的关注焦点。《数据安全法》和《个人信息保护法》颁布实施，为数据安全法治化提供了良好的政策环境。为了推动法律法规的贯彻落实，促进数据安全产业的健康有序发展，2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）联合30余家企业发起“数据安全推进计划”（Data Security Initiative，以下简称“DSI”）。

  

DSI作为一个公益性合作项目，依托大数据协同安全技术国家工程实验室、中国通信标准化协会大数据技术标准推进委员会、中国互联网协会数据治理工作委员会开展具体工作，致力于打造健康规范的数据安全生态体系，助力数据安全监管政策落实，促进数据安全技术交流，推广数据安全最佳实践，提升数据安全治理水平。

  

DSI主要工作内容包括：

（1）搭建交流平台，解读最新政策法规；

（2）开展数据安全方法论和技术体系研究；

（3）建立健全数据安全标准体系；

（4）依托标准打造数据安全咨询与评估评测解决方案；

（5）开展数据安全人才培养。

  

DSI发起后分别在9月、10月征集了第一批和第二批参与单位，受到全行业广泛关注和讨论，共收到了200余家企业的申请，经过严格审核，共138家企业正式成为DSI参与单位。DSI参与单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。（DSI参与单位详细名单见附录）

  

DSI发起近三个月以来，开展了标准制定、评估评测、行业交流、专题培训等多项工作，为参与单位提供了多项专业服务。

  

**1、标准制定方面，**DSI依托中国通信标准化协会大数据技术标准推进委员会启动了4项标准的制定工作，得到了60余家企业的大力支持。目前《数据安全服务能力分级要求》《数据分类分级工具技术要求与测试方法》《数据审计工具技术要求与测试方法》《数据安全治理能力评估方法2.0》已基本完成。

  

**2、评估方面，**在工业和信息化部网络安全管理局指导下持续开展针对数据拥有方的数据安全治理能力评估（以下简称“DSG评估”），并于近期重磅推出了针对数据安全服务提供方的数据安全服务能力评估。

  

DSG评估目前已开展了3批33家企业的评估工作，包括联通数科、蚂蚁、百度、度小满、天翼云等企业。目前，第四批DSG评估和首批数据安全服务能力评估的参评单位征集已经启动，欢迎大家咨询。更多信息请联系：

**3、评测方面，**中国信通院大数据产品测试序列首次增设数据分类分级工具、数据审计工具等数据安全产品的评测项目。

  

数据分类分级工具评测作为一套度量方法，主要关注工具的数据源管理能力、规则管理能力、数据分类分级能力和系统管理能力，涵盖了从数据源发现到分类分级结果应用的全流程技术要求。目前，已完成4家企业的评测工作。

  

数据审计工具评测包含审计对象管理、审计规则、响应能力、追踪溯源能力、统计报表能力、分析能力、日志管理能力以及系统管理能力八个能力域，将数据操作的各个阶段的审计进行规范，填补大数据时代数据审计工具技术要求的空白。目前，已完成2家企业的评测工作。

**4、行业交流与专题培训方面，**DSI联合中国信通院、中国通信标准化协会大数据技术标准推进委员会启动了“数据安全培训系列研讨会”活动，旨在加强行业数据安全交流，促进行业数据安全能力提升，共同探讨数据安全实践之路。DSI已在11月19日和11月30日成功举办了两场研讨会，参与者众多，反响热烈。研讨会明年将会继续举办，每月一期，敬请期待！
