# 中国信通院数据安全产品能力评测正式启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NjY3MDE3MA==&mid=2247483664&idx=1&sn=62442c42a76e2f93895db7f9055ebf2a&chksm=cf2ffca5f85875b36cfce3f404b8efa587cbae2e1ae404a697c357be44ec80a12bda2c47b3eb&scene=126&sessionid=1681269242#rd](http://mp.weixin.qq.com/s?__biz=Mzg3NjY3MDE3MA==&mid=2247483664&idx=1&sn=62442c42a76e2f93895db7f9055ebf2a&chksm=cf2ffca5f85875b36cfce3f404b8efa587cbae2e1ae404a697c357be44ec80a12bda2c47b3eb&scene=126&sessionid=1681269242#rd)

  

随着《中华人民共和国数据安全法》的施行，“依法治数”成为时代的必然趋势。数据安全技术作为防范数据安全风险的能力底座，是企业数据安全治理过程中的重要支撑。为规范数据安全技术开发利用，衡量数据安全产品能力，中国信息通信研究院（以下简称“中国信通院”）**将****数据分类分级工具、数据审计工具纳入大数据产品测试序列，并正式启动评测服务。**

  

**0****1****一、数据分类分级工具评测**

数据分类分级作为数据安全的关键环节，是数据安全治理实施的基础。大数据、AI等新技术的应用，使数据分类分级工具的功能性、效率、准确性得到提升，但行业缺少针对数据分类分级工具的度量准则。数据分类分级工具评测作为一套度量方法，主要关注工具的数据源管理能力、规则管理能力、数据分类分级能力和系统管理能力，涵盖了从数据源发现到分类分级结果应用的全流程技术要求。为企业提供准确度量数据分类分级技术水平的依据，也为数据分类分级的技术提升提供指南。

**0****2****二、数据审计工具评测**

  

数据审计工具是数据安全工作中重要的工具之一。目前，数据库审计相关的标准与评测方法繁多，但是以数据为中心，围绕数据操作相关的审计标准仍处于空缺阶段。数据审计工具评测将数据操作的各个阶段的审计进行规范，填补大数据时代数据审计工具技术要求的空白。数据审计工具评测包含审计对象管理，审计规则，响应能力，追踪溯源能力，统计报表能力，分析能力，日志管理能力以及系统管理能力八个能力域。能够全面客观地评价数据审计工具的功能，为企业在选择相关产品时提供参考。

**报名参测步骤如下：**

**1.【商务合同确认】**

确定评测意向并进行商务合同确认。合同签订后进行后续流程。

  

**2.【评测技术对接】**

商务合同确认后，向参评企业提供详细版本的评测方法，内含明确的评测用例供参评企业进行内部评估及评测前准备。参评企业筹备期间相关技术问题可向技术咨询联系人咨询。

  

**3.【评测时间排期】**

参评企业对于详细版本的评测方法完成内部评估，确认可以实际进行评测后，可与技术咨询联系人商议具体的评测时间完成评测排期。评测排期有限，先到先得，若排期过晚无可使用时间，实际评测将延期至下一批次执行。

  

**4.【实际评测执行】**

参评企业与技术咨询联系人商议完成排期后，将由具体评测人员负责与企业联系，在排期期间内共同协作完成评测。

  

**5.【组织专家评审】**

评测周期结束后，将召开专家评审组会议，对完成评测的参评企业及其产品报告进行评审，通过专家组评审方可获得证书。

  

**6.【正式颁发证书】**

首批数据分类分级工具评测、数据审计工具评测的证书拟定在2021年12月“2021数据安全产业峰会暨可信隐私计算高峰论坛”上正式颁发。

  

**报名截止时间：**

首批评估评测的报名截止时间为11月24日。

  

  
  

2021年9月1日，中国信息通信研究院（以下简称“中国信通院”）联合三十余家企业正式发起**“数据安全推进计划”（Data Security Initiative，以下简称“DSI”）**，旨在帮助企业建立健全数据安全建设，推动促进《数据安全法》的落实。计划发起后收到全行业广泛关注和讨论， DSI第一批成员单位征集共收到150余家单位的申请。经过严格审核，共有103家企业正式成为DSI参与单位。DSI参与单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。目前，DSI第二批成员单位正在征集中，欢迎更多企业加入，携手共建数据安全产业生态。
