**中国上百个重要信息系统被美国植入木马程序**  
6月28日，国家计算机病毒应急处理中心（CVERC）和360公司发布报告披露，中国多家科研机构曾遭到美国国家安全局一款漏洞攻击武器平台“酸狐狸”的网络攻击。该报告还指出，美国国家安全局曾在至少上百个中国国内的重要信息系统植入木马程序，时至今日，多个木马程序仍在运行并向美国国家安全局传送情报。  
![](../Images/3dae2b0c369b51c01ee4dca3915464be.png)

（来源：环球网）  

  
**9款App违法违规收集、使用个人信息**  
针对人民群众反映强烈的App非法获取、超范围收集、过度索取权限等侵害公民个人信息的违法违规现象，海南省互联网信息办公室依据法律和有关规定，组织对省内用户量大、与民众生活密切相关的一批即时通信类的App收集使用个人信息情况进行了技术检测，检测结果显示“同城觅聊”“花盼”等9款App存在不同程度违法违规收集使用个人信息的行为。  
![](../Images/d1e180afca949227716461dba5e90470.png)  
**BOSS直聘、运满满、货车帮恢复新用户注册**6月29日，BOSS 直聘通过官方微博宣布，经报网络安全审查办公室同意，即日起恢复“BOSS 直聘”的新用户注册。此外，满帮同样通过官方微博宣布即日起恢复“运满满”、“货车帮”的新用户注册。  
![](../Images/e38107e40f3d4572d83b9475d4b00998.png)

（来源：IT之家）

  
**工行领取“罚单”：收集与业务无关的消费者金融信息**  
近日，中国人民银行长沙中心支行披露的行政处罚信息显示，工商银行湖南省分行存在包括错报、漏报投诉数据、收集与业务无关的消费者金融信息等在内的九项违法行为，被警告并处91.8万元罚款。  
![](../Images/b9e1b96415836ce3ae0b3b0fa03a0c6b.png)

（来源：中国人民银行长沙中心支行）

  
**美知名零售商泄露2300万用户信息案落幕**美国联邦贸易委员会宣布，针对此前定制商品零售商CafePress泄露超2300万用户个人信息一事做出最终决定，要求该公司向受数据泄露影响的受害者赔偿共50万美元。同时，全面加强数据安全保障，实行多重身份认证机制，将收集和存储的用户信息数量降至最低。  
![](../Images/0ebdcfc56af15fef6d05225218d1669a.png)（来源：隐私护卫队）  
**QQ大规模盗号，给好友群发不雅照**  
6月26日晚，QQ遭遇大规模盗号事件，大量的QQ用户在互联网平台发文称，自己以及身边的朋友、家人、同事都遭遇了被盗号的情况。腾讯回应称：此次事件主要原因系用户扫描过不法分子伪造的游戏登录二维码并授权登录，该登录行为被黑产团伙劫持并记录，随后被不法分子利用发送不良图片广告。  
![](../Images/38937db360ce8963ca07eeeb99b1d188.png)

**谷歌将被禁止追踪数百万用户数据**欧盟近期监管谷歌对于其在移动搜索引擎行业和应用程序中垄断权力的滥用，现在，欧盟中越来越多的国家正在追查谷歌数据分析工具（Google Analytics），因为它被发现违反了《通用数据保护条例》（GDPR）。多个禁令将导致谷歌被禁止追踪数百万用户数据。

**加州总检察长办公室网站泄露大量持枪人敏感信息**  

加州总检察长办公室网站上线后被人发现上面放有可公开访问的持枪人敏感信息，信息包括持枪人的姓名、种族、住址、生日和许可证日期及类型。在当前枪支问题冲突严重的美国，这些信息可能成为控枪主义者的报复利器。

**OT充满安全漏洞**

  

安全供应商Forescout旗下研究部门Vedere Labs新近发布的研究报告发现，用于控制工业设备的运营技术（OT）设备存在大量网络安全漏洞。Vedere Labs在摩托罗拉、西门子和霍尼韦尔等供应商的20条常用OT产品线中发现了56个漏洞，其中多个漏洞可致远程代码执行。

  

![](../Images/5125810e127ed3e14178b6f9c3faf0d2.png)

（来源：数世咨询）  

**高危漏洞并不意味着要最先修复**

  

大多数企业都会关注通用漏洞评分系统(CVSS)框架中对缺陷的评分，评分范围从0到10，并根据漏洞的特点，分为低、中、高和极危。但现实情况是，对于许多企业来说，大多数漏洞都不会对它们构成威胁。安全公司Rezilion在5月发布的一项研究报告显示，组织中约85%的漏洞并没有加载到内存，也就意味着不能够真正被利用。

  

![](../Images/84aae64bde7054c7b11353fef4a052cd.png)

（来源：数世咨询）

**80%的公司遭遇身份相关数据泄露**

**如何正确保护 API 变得越来越紧迫**

Imperva发布了一项新研究，揭示了易受攻击或不安全 API 的全球成本不断上升。对近 117,000 起独特的网络安全事件的分析估计，API 安全隐患每年会导致 41-750 亿美元的损失。

  

![](../Images/7ada973665ea81747f10275ff0ddab71.png)

  

事实上，收入至少为 1000 亿美元的企业遇到 API 不安全的可能性是中小型企业的 3-4 倍。数据表明，随着这些成熟的组织加速数字化转型，大公司特别容易受到与暴露或未受保护的 API 相关的安全风险的影响。

**应用程序接口（API）防护技术发展研究及对策建议**

应用程序接口（Application Programming Interface，API）是一些预先被定义的接口或协议，用来实现和其他软件组件的交互。API在应用架构上实现了软件的模块化，具备可重用、可扩展能力，已经成为应用系统中广泛使用的核心支撑技术之一。APP、小程序、智能家电、政务平台、数据交换等都在大量使用API相关技术。

**国家网信办发布《互联网用户账号信息管理规定》**

6月27日，国家互联网信息办公室发布《互联网用户账号信息管理规定》，自2022年8月1日起施行。《规定》旨在加强对互联网用户账号信息的管理，保护公民、法人和其他组织的合法权益，促进互联网信息服务健康发展。
