**Kaiser Permanente数据泄露影响7万人**  

  

近期，美国医疗保健提供商 Kaiser Permanente 多达7万名患者的医疗保健和个人信息遭到泄露，包括姓名、病历编号、服务日期以及健康计划提供者的实验室检测结果信息。

  

![](../Images/e914639dd0ac6841d78bb0486e933f89.png)

（来源：安全客）

  

**注意！这几种东西千万不要发朋友圈**

**‍**  

**随着各地高考结束，**这几种东西千万不能发朋友圈：① 高考准考证；② 个人身份证；③ 考生号及密码；④ 志愿填报表；⑤ 成绩单；⑥成绩查询页面截图；⑦ 个人录取通知书。

  

![](../Images/78e4c92aba3633713a7a506d9e1f1a18.png)

  

如果个人信息被别有用心的人从朋友圈或者其他社交平台获取到，可能会被利用实施精准诈骗！

（来源：人民法院报）

  

**杭州两家科技公司被重罚140万**

  

近期，杭州市市场监管局依法查处了两家开发销售“搬店”软件非法获利的企业。据介绍，该软件利用“爬虫”技术，在电商平台抓取指定店铺及其商品数据，供他人在其他电商平台进行自动化、批量化的“盗图抄店”。

  

![](../Images/f854bc8eb92d6e84bfd0a73d9ff94f68.png)

  

经统计，一年来，在未取得相关平台或平台内经营者的授权同意的情况下，这两款“搬店”软件共非法“爬取”近2000万条相关数据。（来源：杭州市监督市场管理局）![](../Images/8f003f1dcb38775a05c515bfc14d6f82.png)

**Microsoft Defender新增隔离功能**

  

微软为Microsoft Defender for Endpoint新增隔离功能，可以在部分设备被黑客攻破的情况下，防范黑客在内网中横向移动。

  
![](../Images/499a528e15d75ff63b07518784a4b27f.png)  
执行方式也相当简单粗暴，设备被标记为受到威胁后会阻断所有通信，不过功能太新了所以只适用于Windows 10及以上或Windows Server 2019及以上的系统，如果真想用这个功能得先把所有设备的系统版本排查一遍。

（来源：安全客）

  

**Apache HTTP Server 请求走私漏洞**

近日，安恒信息 CERT 监测到 Apache 官方发布安全公告，修复了一处 Apache HTTP Server 的 HTTP 请求走私漏洞，该漏洞允许攻击者将请求走私到AJP 服务器。  
（来源：安恒信息）

**东数西算战略加持，国家政策持续赋能**

东数西算工程，指的是通过构建数据中心、云计算、大数据一体化的新型算力网络体系，将东部算力需求有序引导到西部，优化数据中心建设布局，促进东西部协同联动。

  

![](../Images/1d36167b0b48d7a24d14c3a6df20a2bc.png)

  

数据中心是新基建有序运行的基础保障，而数据则是贯穿新基建的生命线。在聚焦于数据中心的政策文件中，有关数据资源管理、流通以及数据安全问题也被反复提及。

**赋红码是否涉嫌行政权滥用**

近日，河南村镇银行储户被“赋红码”一事引发关注。多名储户反映，本打算前往郑州与有关部门沟通“取款难”问题，但扫码登记后变为“红码”。  
![](../Images/90dd6b63883a62d9b0dc634de25cfc4c.png "imagefile")  
对此，对外经贸大学数字经济与法律创新研究中心主任许可表示，健康码不能用于防疫之外的目的。如果将健康码用于维稳，这显然是严重违法的，构成了行政权滥用，这种行为也违反了个人信息保护法规定的合法、正当、必要和诚信原则。

  

详情请看：[五问赋红码：健康码可否用于防疫之外？是否涉嫌行政权滥用？](https://mp.weixin.qq.com/s?__biz=MTk1MjIwODAwMQ==&mid=2651194048&idx=2&sn=7595c1d43fc2d10a13a0215cf460b25e&scene=21#wechat_redirect)

  

**《网上银行系统信息安全通用规范》解读**

《网上银行系统信息安全通用规范（JR/T 0068-2020）》针对银行业金融机构的网上银行系统，在收集、分析评估检查中发现的网上银行系统的信息安全问题和已发生的网上银行案件的基础上，对网上银行系统的安全技术、安全管理、业务运营提出了具体的安全要求。

  

详情请看：[《网上银行系统信息安全通用规范》技术解读](https://mp.weixin.qq.com/s?__biz=MjM5Njc3NjM4MA==&mid=2651114594&idx=2&sn=4ba057b09cb51ff0a636a74d0ebc6360&scene=21#wechat_redirect)

  

**云原生数据防泄漏(DLP)架构与实践指南**

随着国内外数据合规监管要求趋严，企业IT架构逐渐云化，SaaS应用的逐渐成熟，以及2020年以来全球COVID-19疫情给企业带来的远程办公数据泄露问题，都给DLP架构升级带来了新的机遇，企业选择DLP技术方案时，不再仅仅局限于终端、网络和邮件的DLP，而是逐渐趋向于选择在零信任、云原生、CASB和SASE等新技术领域驱动之下的全新DLP解决方案。

**蓝牙信号可追踪智能手机**

智能手机、智能手表、健身手环等移动设备常以每分钟500 蓝牙beacon的速率用来传输信号。这些beacon可以用于苹果的“Find My”丢失设备追踪服务、疫情追踪APP、连接智能手机到其他设备等。  
![](../Images/92390384b6ceec177da271ebfc35e314.png)  

加州大学圣地亚哥分校研究人员通过分析证明蓝牙信号也可以作为指纹，用于追踪智能手机设备和个人移动。

**（来源：嘶吼）**![](../Images/4c61511e71c64948d765432e2571d3e6.png)

![](../Images/4300a25ea3d10c5ef9dc685f93656a6b.png)**网信办修订《移动互联网应用程序信息服务管理规定》**

2022年6月14日，国家互联网信息办公室发布新修订的《移动互联网应用程序信息服务管理规定》（以下简称“新《规定》”），自2022年8月1日起施行。

  

![](../Images/a7079cd0d27f57f8369a2998b8c91d7c.png)

  

新《规定》共27条，包括信息内容主体责任、真实身份信息认证、分类管理、行业自律、社会监督及行政管理等条款。

****（来源：国家互联网信息办公室）****
