# 国企担当！数安公司受邀为省属企业提供技术支撑

**浙江数安 ·**

  

近日，杭钢集团浙江省数据安全服务有限公司受邀成为**省国资委指定技术支撑单位**，为浙江省属企业网络和数据安全自查工作提供专业技术服务。

![](../Images/0438a31d9c37df2487d8c555787e1c4f.png)

在省国资委发布的通知中，要求省属企业针对网络和数据安全工作落实情况，**全面开展安全自查评估及问题整改**；邀请浙江数安全程参与技术指导，旨在提升省属企业网络和数据安全建设能力，确保重大活动期间网络空间安全。浙江数安将协助各省属企业，从网络安全管理制度和保障体系建设、网络安全防护、数据安全保护、个人信息和用户权益保护等方面进行自查评估，查找安全漏洞与风险隐患，补齐工作短板。在认真梳理各单位实际情况的基础上，浙江数安将**定制化制订服务方案，涵盖核心业务系统应急演练、网络与数据安全培训、网络与数据安全风险评估、数据安全审计等服务内容**，为省属企业全方位查漏补缺，筑牢网络空间安全“护城河”。

本次自查坚持“以查促改、以查促建”，推动各省属企业对检查中发现的风险隐患快速落实整改，进一步提升风险意识，确保自查成效。浙江数安将以专业的技术服务能力和咨询经验，坚决扛起国企责任担当，**为省属企业网络和数据安全能力建设贡献专业力量**，以实干实效迎接党的二十大胜利召开。
