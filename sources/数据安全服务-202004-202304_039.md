# 世界500强！杭钢集团首次上榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMDM1MDgzNA==&mid=2247485618&idx=1&sn=57d91003b873afad9448de42b01a721c&chksm=e8b5822fdfc20b394a6529ff7165b6e186d2b6c535cd33dfba525e8d959f3185e94bf12b86e5&scene=126&sessionid=1681268841#rd](http://mp.weixin.qq.com/s?__biz=MzIzMDM1MDgzNA==&mid=2247485618&idx=1&sn=57d91003b873afad9448de42b01a721c&chksm=e8b5822fdfc20b394a6529ff7165b6e186d2b6c535cd33dfba525e8d959f3185e94bf12b86e5&scene=126&sessionid=1681268841#rd)

![](../Images/04ffcfdf053eef9fe6ef5075f970c334.png)8月3日，《财富》杂志发布2022年世界500强排行榜，浙江数安股东公司杭州钢铁集团有限公司**首次入围榜单**，名列第336位。 ![](../Images/c9d7a948bdad226a8f7cf9bc8a9c0376.png)（图片来源：今日杭钢）  

杭钢集团先后经历了三次创业浪潮，现已发展成为一家拥有“2+2”产业格局，即以**钢铁智造、现代流通**为战略优势产业，以**节能环保、数字科技**为战略新兴产业的大型现代企业集团。目前，杭钢集团共有包括**浙江数安**在内的全资及控股企业173家，其中一级全资及控股子公司36家，控股上市公司2家。

杭钢集团**把****数字科技****产业作为重点布局的战略性新兴产业****，**聚焦“数字基础构建者、数字应用开拓者、**数字安全赋能者**”的定位，抢抓浙江省委数字化改革重大机遇，以半山基地“一镇两园三区”数字经济特色小镇建设为载体，加快壮大数字经济生态圈，争当服务数字建设、壮大数字经济的生力军。

  

  

在此背景下，杭钢集团携手安恒信息、每日互动三方于2019年底合资组建浙江省数据安全服务有限公司，为**政府数字化治理和企业数字化转型**保驾护航。

  

浙江数安作为国内首家**国有控股的数据安全企业**，致力于解决数字经济建设中数据安全和隐私保护问题。其**核心产品浙江省大数据联合计算平台是浙江省数字经济新基建的标志性项目**，平台创新采用隐私计算新方法——**多方中介计算**，用先进技术保障数据计算和流转全过程的公平透明，实现数据所有权和数据使用权分立，解决数据交互的信任和隐私保护问题。同时公司**已推出数据安全咨询、数据安全审计、数据安全成熟度能力评估等安全服务项目**，从制度、管理等流程体系建设上助力企事业单位提升数据安全能力。

  
![](../Images/33e3c0c10b5fd4440b3e8e1bba1de7fa.png)（图片来源：今日杭钢）  

一直以来，股东公司统一业务协同目标，助推浙江数安快速发展。此次，浙江数安将把握契机，充分利用股东公司优势资源，打造自身硬实力，进一步开拓市场，向全省乃至全国数据安全领域第一梯队进发。
