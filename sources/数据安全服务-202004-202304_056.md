# “**浙江数安作为杭钢集团投资的国内首家国资控股的数据安全企业**，一直以技术和管理的双重创新为数字化改革保驾护航，以国企担当肩负起保护数据安全的历史使命和国之重任。而**浙江省大数据联合计算平台作为浙江数安的拳头产品**，致力于为政府和企业数字化转型提供全方位数据安全解决方案，为合作伙伴实现‘数据可用不可拥、数据不流转数据价值流转’的数据价值。”

3月8日，《浙江日报》以《春天里再出发 杭钢集团以数字化改革引领高质量发展》为题对杭钢集团进行了专题报道。杭钢以数字基础构建者、数字安全赋能者、数字应用开拓者为定位，找准数字经济发展赛道和着力点，打造“十朵云”，构建数字产业新生态，将数字经济转变成产业筑梦的新蓝海。

**春天里再出发**杭钢集团以数字化改革引领高质量发展  
      破立之间，数字化改革在之江大地引领起一场全方位、系统性变革。新旧之间，数字化改革也让杭钢集团实现从“炼铁成钢”到“点数成金”的转型传奇。　　这些年，将数字经济转变成产业筑梦的新蓝海，杭钢找对了方向，也干出了成效。　　去年，全省数字化改革大会召开后，杭钢集团第一时间召开党委扩大会议，研究部署贯彻落实措施。“作为浙江省较早把发展数字经济作为主业的省属国企，杭钢集团深入贯彻浙江省委数字化改革工作部署精神，强化数字化认知，树立数字化思维，加快推动数字科技产业发展，加快构建数字产业生态。”杭钢集团董事长张利明说，杭钢将以“数字基础构建者、数字安全赋能者、数字应用开拓者”为发展定位，切实为全省数字化改革工作贡献国企力量，展现国企担当。**      找准“跑道”突破重点， 跑出高质量发展加速度**　　2015年，杭钢集团以壮士断腕、破釜沉舟的决心和勇气，有序平稳地关停了半山钢铁基地。全面融入、主动拥抱数字经济，找准杭钢数字经济发展赛道和着力点，推进产业数字化、数字产业化，助推杭钢高质量跨越式发展。　　从2016到2021，弹指5年间，杭钢集团半山基地的转型升级路径越来越清晰：围绕数字经济，坚定建设数字经济小镇。小镇建设以半山基地为载体，以数字科技为驱动，打造数字科技特色产业园区，赋能传统产业转型升级。在杭钢自留地面积1743亩的半山基地里，规划形成“一镇两园三区”的产业布局。　　另一方面，杭钢依托自身资源优势，成立了多个数字化、平台化、产融化、绿色化、国际化的数字科技企业平台，与多个地方政府形成了全方位、多层次、市场化的战略合作，与之江实验室、中国电信、中国联通、安恒信息、每日互动等一批头部企业形成产业联盟，优势互补开展战略投资、股权投资、技术创新、创业孵化等多种形式的互惠合作，创造出令人惊叹的杭钢奇迹。　　截至目前，杭钢集团数字产业共有5个项目列入了浙江省新基建重点项目，总投资约206亿元，为杭钢集团产业转型注入强劲动能。趁势而上，抢抓机遇，今年杭钢又提出打造“十朵云”，构建数字产业新生态。　　——建设打造“两朵”基础设施云，为全省数字基建提供算力新保障。投资188亿元建设的“浙江云”和“杭钢云”两座超大型数据中心，规划超20000个机柜、装载超300000台服务器，是目前全国单元区内规模最大、最节能的数据中心。两座数据中心的建成投运，将为全省工业互联网、智能制造、数字金融、智慧城市、未来社区、智能环保等行业提供重要的算力保证。　　——加快布局“六朵”行业服务云，为全省数字化改革提供应用新场景。包括在建的“国资云”“职教云”“智慧能源云”和拟建的“海洋云”“教育云”“健康云”等，努力形成“行业云集”。行业云将分别支撑国资监管平台，服务长三角区域职业教育和产业发展，为政府和企业提供能源和碳排放监测、绿色金融服务，推进全省智慧海洋工程实施，构建全省统一的教育智治系统，为全省各级各类医疗卫生机构提供行业云服务。　　——积极构建“两朵”数据密钥云，为全省数字经济提供安全新底座。杭钢“信创云”已于2021年9月正式通过了中央网信办的云安全评估，成为全国第一个通过国家评审的、以信创为基础的全国产化云平台，也是国内第一个可同时服务党政“政务云”以及行业云的“信创云”平台，并成功入围2021年数字技术融合创新应用优秀实践案例；“浙江省大数据联合计算平台”具有原始数据可进不可出、可用不可拥、数据匿名、算法透明等重要特点，为隐私计算领域提供了全新思路和探索方向，项目已获评2021年浙江省数字经济“五新”优秀案例。　　接下来，杭钢集团将继续补链、强链、延链，坚持以“大、优、特”项目为支撑，培育和引进新兴产业，加快打造数字安防、智能计算等数字产业集群，积极承接浙江省数字化改革新项目，打造并形成更多标志性成果。**      聚力“应用”向难而行，激发共同富裕新动能**　　2021年，是一个特殊的节点——数字化改革元年，恰逢浙江高质量发展建设共同富裕示范区起步之年。　　这是一次系统的探索——改革力量，能否撬动经济社会数字化转型，推进共同富裕示范区建设扎实开局？杭钢也把这个课题留给了自己。　　破题——从“小切口”破题，老问题找到新解法。　　2015年以来，一系列纲领性文件连续出台，期望通过持续深入推进产教融合改革，促进教育链、人才链与产业链、创新链之间的有机融合，解决科技革命、产业变革与高等教育系统之间的结构性失衡问题。“学校培养的技能人才只是‘毛坯’，与企业工作岗位的实际需求还有不小差距。我们需要全社会更多的元素，加入到整个技能教育培训生态圈。”浙江省人力资源和社会保障厅相关负责人说。      提高站位、打破常规，赋能职业教育发展。杭钢集团的长三角产教融合智慧云平台正是在这样的背景下构建的。“该云平台将重点打造实训与就业智能撮合、数字教学资源分享、远程能力考评、教学设备设施云端共享等功能，通过数字化、智能化校企多边合作，服务职业教育‘产、教、训’有机融合。”浙江杭钢职业教育集团负责人说。　　“我们希望通过打造长三角产教融合智慧云平台，推动地方数字教育及职业院校应用终端的接入，发挥资源集聚生态效应和信息技术效率优势，促进优质教育资源共享。”杭钢集团总经理林亮说。　　聚焦群众所需，民生“小幸福”，也能牵引出改革“大场景”。“智治农污”就是杭钢集团推进农村生活污水治理数字化改革的重要实践。      青草依依，鱼游水中，污水处理设备不分昼夜地运转。最近，在象山县石浦镇鸡鸣村生活污水处理终端，浙江省环保集团象山有限公司的设备管理人员根据“智治农污”新概念，对终端机房的设备做了进一步检验升级。通过监控及网络连接，鸡鸣村生活污水处理终端与总部中控平台实现实时数据画面连接，技术人员不用出门就可以接收到各种监测数据。　　近年来，杭钢集团下属浙江环保集团助力象山对城乡一体化管理平台进行升级改造，通过平台功能模块升级开发、增加管网监测设施、入户污水管及主干管网节点窨井盖二维码标签定制，实现了农村生活污水治理设施全过程、全覆盖、精细化、智能化管理，真正实现了“污水靠蒸发”向“绿水绕人家”的根本性转变。　　数字化改革，让数据冲到了前沿。数据要素需要在融合共享中释放更大价值，但又该如何在数据开放和数据安全之间找到平衡？　　去年春天，以“安全：数字化改革之根基”为主题的2021西湖论剑·网络安全大会成功举办。由杭钢集团、每日互动、安恒信息联合成立的浙江省数据安全服务有限公司作为国内首家国资控股的数据安全企业在成果展上精彩亮相。浙江数安以技术和管理的双重创新为数字化改革保驾护航，以国企担当肩负起保护数据安全的历史使命和国之重任。　　当下，作为浙江数安的拳头产品，浙江省大数据联合计算平台成为各方关注的亮点。平台采用隐私计算等数据安全领域的前沿科技保障数据的流通安全，管控数据的用途用量，成为政务数据开放和企业数据流通的安全基座，是实现“群众少跑腿、数据多跑路”的平台保障。　　林亮说：“大数据联合计算平台要在混沌的数据世界里开辟出一个客观、安全、可信的‘中立国’，为政府和企业数字化转型提供全方位数据安全解决方案。为合作伙伴实现‘数据可用不可拥、数据不流转数据价值流转’的数据价值。”　　下一步，杭钢将继续深化探索，让更多破解群众所急所忧、所思所盼的重大应用在杭钢诞生，让一个个充满时代感、未来感的多跨场景在杭钢落地，以数字化改革推进共同富裕实践，创新更多“杭钢样本”。　　**杭钢“十朵云”：**　　•“两朵”基础设施云：“浙江云”“杭钢云”　　•“六朵”行业服务云：“国资云”“职教云”“智慧能源云”“海洋云”“教育云”“健康云”　　•“两朵”数据密钥云：“政务云”和“信创云”
