# 近日，浙江省数字经济发展领导小组办公室公布2021年浙江省数字经济“五新”优秀案例。**浙江省数据安全服务有限公司的“浙江省大数据联合计算平台的隐私计算新技术-多方中介计算”获评“新技术”优秀案例。**

![](../Images/6c1ec422594a9ebaff3d4e96d35f3305.png)

**2021年浙江省数字经济**

**“五新”优秀案例**

![](../Images/5370d4a9d914cd1bef52a8befdd2e4f4.png)  
**多方中介计算是数安公司团队创新研发的一种新的隐私计算技术**，是指多方数据在独立于数据方和用户的受监管中介计算环境内，通过安全可信机制，实现分析计算和匿名化结果输出的数据处理方式，是一个计算管理系统。多方中介计算的关键是中介计算环境或平台，它是数据方与用户之间信息数据供需的中间桥梁，提供了一个隐私计算的安全可信监管环境。![](../Images/ac188b11baea48fc05474052548e6e8f.png)▲应用多方中介计算的浙江省大数据联合计算平台界面多方中介计算技术具有数据可进不可出、可用不可控、数据匿名、算法透明、安全经济、可监管等突出优点，有着重大的应用价值，为隐私计算领域提供了全新思路和探索方向。

浙江数安获此殊荣后，将秉持更加坚定的决心和信念，继续致力于数据安全技术的探索研究，推动数据共享融合技术的发展，为数据安全能力提升贡献专业力量。
