# 《数据安全法对大数据产业的影响和趋势》闭门畅谈会成功举办

7月12日由浙江省数据安全服务有限公司和京衡律师事务所联合主办的《数据安全法对大数据产业的影响和趋势》闭门畅谈会成功举办。会上由京衡律师事务所张豪律师对刚刚公布的《数据安全法（草案）》进行深度解读，指出国家通过立法，促进和保护数据产业的发展与合法权益，突出强调了行业对数据安全保护的主体责任，为行业间的数据交换共享明确了法律责任边界。浙江省数据安全服务有限公司总经理孔俊，在会上分享了数安公司打造可审计、可回溯、易操作、安全性高的大数据联合计算平台，基于区块链技术实现数据所有权和数据使用权分离，以促进企业之间、企业同公共部门之间的数据在安全、合规、可控的情况下实现共享融合，真正实现数据可用不可拥，安全可见又可验。

![](../Images/f1ba2d517382f21c71fda6cf7919a6c4.png)

图为京衡律所张豪 数安公司孔俊 的分享现场  
会上其他数据相关企业代表分别就《数据安全法（草案）》将为企业和产业带来的影响发表了见解。乾冠信息安全研究院深入分析了数据安全监督管理体系建设；安恒信息分享了构建多方数据安全交换方案的技术理念；深普科技介绍了数据资产保护和动态脱敏系统的逻辑架构和运维模式；人保财险则从保险角度分享了网络信息安全的风险防范；云通数达从国际视角出发介绍了跨境服务中的数据安全保障方案。

![](../Images/86e36c8429936d92768579b1f3e1ed50.png)

畅谈会现场  

此次畅谈会不仅有专业的法律解读，还有对未来数据产业的发展和趋势的独到见解，此外，会议还吸引众多数据相关企业和律所一同加入探讨。

**解读：顶层设计  以安全促发展**

《草案》中提出以数据安全保障数据开发利用和产业发展的同时，也能以数据开发利用和产业发展促进数据安全，并首次**赋予了数据交易活动以正当的法律地位**，是对中共中央提出的“引导培育大数据交易市场，依法合规开展数据交易”的有力回应，预示着我国大数据产业将在法律指导下调整步伐高速发展。

此外，《草案》中专门用了一章对**政务数据安全与开放**进行描述，表明政府作为社会治理的主体，同样也是海量数据拥有者，正加速建立**以数据为新的生产要素的安全协同治理体系**。

作为一部统筹数字经济时代“安全与发展”的法律，《草案》明确鼓励数据依法合理有效利用，保障数据依法有序自由流动，这无疑是国家对数据产业发展发出的冲锋号，以法律手段保障并推动数据产业的快速前进。

**共瞻：企业使命  以技术护安全**

中国信息通信研究院7月发布的《中国数字经济发展白皮书（2020年）》显示，2019年，我国数字经济增加值规模为35.8万亿元，占GDP比重高达36.2%，数字经济在国民经济中的地位进一步凸显，**数据的安全保护愈加迫切。**

目前，政策和法律已明确**支持数据开发利用和数据安全等领域的技术推广和商业创新，培育、发展数据开发利用和数据安全产品和产业体系**。所以在制度红利下，数据安全企业也将加大科技投入，集中精力研发数据安全产品，构建全方位的数据安全防护生态。

数据安全企业将承担历史重任，以技术手段构建数据安全解决方案，赋能大数据产业发展、促进数据智能经济升级。
