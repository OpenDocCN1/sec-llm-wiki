# 省长袁家军宣布浙江云计算数据中心项目开工 数安亮剑杭钢数字经济主战场

7月10日上午，浙江云计算数据中心项目开工仪式在杭钢举行。省委副书记、省长袁家军宣布项目开工，省委常委、常务副省长冯飞出席仪式并讲话，杭州市委副书记、市长刘忻，阿里巴巴集团董事局主席、首席执行官张勇，杭钢集团党委书记、董事长张利明发言。浙江省数据安全服务有限公司（简称：数安公司）作为杭钢数字经济成员企业、安恒信息和每日互动作为数安公司股东企业受邀出席仪式。  

![](../Images/a36f186629a828e564a8d3deffdfb3cb.png)

开工仪式主席台

  

开工仪式上，省委常委、常务副省长冯飞指出浙江云计算数据中心项目的开工，标志着我省数字新基建重大标志性项目建设已驶入“快车道”。他要求全省上下要以此为新的起点，积极创建领先的新型基础设施产业链生态，彰显我省“重要窗口”建设的标志性成果。  

![](../Images/cec8cd1cdbcb88369867d93f697f58a0.png)

开工仪式现场  

  

杭钢集团党委书记、董事长张利明在讲话中提到，杭钢集团正在全面推进转型升级，大力发展数字经济等创新产业。杭钢集团与安恒信息、每日互动持续紧密合作，共同成立浙江省数据安全服务有限公司，为数据智慧化融合应用提供全方位安全保障，并将助力浙江云计算数据中心项目的顺利开展。  

![](../Images/5faae88982b07203828dd9c128af266e.png)

从左向右依次为：

数安公司董事长周耀邦、杭钢集团副总经理刘树林、

安恒信息董事长范渊、每日互动董事长方毅

  

数安公司作为杭钢集团数字经济产业板块的重要企业，成立以来得到了省政府及有关部门的大力支持。其核心产品大数据联合计算平台可以承载民生数据和经济数据的计算融合及智慧应用，同时专业的安全服务技术能力为数据提供全方位的安全保障，助推数据充分释放要素价值，为我省“重要窗口”建设贡献力量，为我省乃至全国数字经济的快速发展保驾护航。 ![](../Images/7f657f770160e8f9cd43f5cc9ba3f4c4.png)
