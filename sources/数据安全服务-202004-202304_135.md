# 杭钢副总经理刘树林赴安恒信息调研 展望数安服发展新格局

杭钢副总经理刘树林一行赴安恒信息调研，与安恒信息董事长范渊，数安服董事长周耀邦共谋数安服业务版图。

  

6月17日，杭州钢铁集团有限公司副总经理刘树林在浙江省数据安全服务有限公司董事长周耀邦，首席安全官杨锦峰、副总经理徐敏的陪同下，赴杭州安恒信息技术股份有限公司走访，就数安服公司的业务发展规划进行调研，安恒信息董事长范渊、高级副总裁刘博、总裁助理吴小珍接待并陪同调研。  
![](../Images/0b143343916cf651cc2f82f9ea4b2c73.png)  
在调研中，刘树林一行深入了解了安恒信息的发展历程、目前的发展状况和未来规划，在谈及数安服的发展规划时，他强调数安服要充分发挥公司的金字招牌影响力，充分利用资源优势，大力拓展市场，同时也希望公司放大自身特点和优势，打磨产品和服务，打造核心竞争力，在数据安全领域占据领先之地。  
![](../Images/d42dc80e919f2a11575f247c79edd199.png)  
范渊在研讨会上提出要积极拥抱当前国家鼓励数据开放应用的政策形势，因势利导，将业务做实。而数安服作为杭钢数字经济板块的重要一环， 要将护航数字经济发展的使命夯实记牢，将专业可信的数据安全服务向更多领域和行业延伸。  
![](../Images/6513adea50a70eb63c409d91d20f4fc2.png)  
杭钢集团副总经理刘树林的这次安恒信息之行，为数安服在业务方向上再次指明了方向，相信在股东公司的大力支持和指导下，数安服在数据安全领域已经准备好以过硬的服务能力和技术实力服务于我省乃至全国的数字经济大发展。
