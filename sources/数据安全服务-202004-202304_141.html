公司简介




浙江省数据安全服务有限公司成立于2019年12月31日，由浙江省数字经济转型的排头兵杭钢集团，联合国内领先的网络信息安全公司安恒信息、数据智能服务商每日互动共同发起成立，整合各方优势资源，旨在解决数字经济建设中数据安全和隐私保护问题，探索数据资源开放、流通、共享的制度创新、技术创新和应用创新，有效推动“数字产业化、产业数字化、城市数字化”的数字经济大发展。





招募岗位




本次招聘岗位有：

综合类岗位：人事行政专员、品宣文秘专员

市场类岗位：售前咨询

技术类岗位：研发经理、产品经理、web前端开发工程师、JAVA后端开发工程师

有意者请将简历发送至：49651415@qq.com 



（1）人事行政专员

【岗位职责】

1、起草、审核、发放公司各类文件、报告、管理办法等；

2、负责公司各类会议的会务工作；

3、负责公司印信的印制、交接、销毁工作，并对部门级印章进行使用管控；

4、负责公司宣传品、名片、杂志的印刷联系、报销及快递、机票费用的核实报销；

5、负责员工考勤、人员招聘和入职手续办理；

【岗位要求】

1、本科及以上学历，企业管理、工商管理相关专业，1年以上工作经验；

2、具备一般英语读写能力，具备较强的电脑操作能力，能熟练运用各种相关办公软件；

3、熟悉公司企业管理、目标管理知识及其实际应用，掌握基础的人力资源管理知识；

4、工作细心、认真负责，具备良好的沟通表达能力、抗压能力及团队协作精神，有较强的文字组织能力。


（2）文秘品宣专员

【岗位职责】

1、负责公司领导讲话稿、各类总结、报告材料的撰写

2、做好办公室相关会议的资料收集准备及相应会议纪要起草、审核

3、负责公司网站更新内容拟稿，提交上级审核后实施发布。

4、负责提炼企业文化，推动和维护企业文化建设工作。

5、负责公司公众号更新内容拟稿，提交上级审核后实施发布。

6、负责公司宣传资料的审核制作

7、负责司介绍PPT的更新和维护

【岗位要求】

1、中文、新闻或其他相关专业

2、熟练操作各种办公软件、有良好的文字表达能力、熟悉公司相关法律法规

3、较强的对内、对外沟通能力，具备全面的行政管理能力，有较强的责任心


（3）售前咨询

【岗位职责】

1.售前交流：对市场商机进行分析判断，制定应对策略，面向客户进行售前交流；
2.方案编写：根据客户需求提供针对性解决方案，并进行方案的汇报和讲解；
3.招投标：配合客户完成包括招投标文件的策划组织编写及现场讲标答疑；
4.培训包装：整理销售工具、售前工具，对产品及方案进行市场推广、传递价值；
5.咨询规划：为战略客户提供安全咨询规划，引导客户需求、协助销售推进；
6.负责和研发部、市场部门密切配合，负责相关的沟通、技术支持、技术文档撰写等工作。

【岗位要求】

1.本科以上学历，3年以上相关工作经验，熟悉信息安全领域；
2.丰富的方案设计、标书应答、用户交流经验，良好的写作和口才、良好的沟通能力，工作条理性强，具有很强的责任心和团队合作精神；
3.对市场需求敏感度高，能够及时获取相关需求信息，挖掘整理项目需求；

4.具有网络与信息安全体系建设、咨询、审计经验。

5.能接受短期出差。

6.具备CISA/CISSP/ISO27001/PMP/CISP等证书者优先；


（4）研发经理

【岗位职责】

1. 负责系统架构设计、项目开发管理，对产品开发交付进度、系统安全性、稳定性负责；

2. 负责研发团队组建、管理、培训等，提升研发团队的技术能力和研发效率。

【岗位要求】

1. 4年以上java开发经验，3年以上平台架构设计经验和团队管理经验
2. 精通java技术、Spring Framework，熟悉 Spring Boot、Spring Cloud等微服务框架
3. 熟悉平台类系统的构架设计、系统分析、性能优化及系统安全
4. 有从0到1组建技术团队的经验，能建立研发优化制度和流程，提升产品质量和发布效率
5. 负责过两个以上不同类型的产品设计和研发流程
6. 有信息安全领域相关产品工作经验者优先考虑

7.具备CISA/CISSP/ISO27001/PMP/CISP等证书者优先



（5）产品经理

【岗位职责】

1.负责数据安全产品规划、业务流程设计、功能设计、产品优化等工作
2.沟通客户的业务需求，进行产品需求分析，撰写产品需求规格说明书
3.定期对产品、竞品、行业等进行数据分析并评估，并提出产品改善计划，不断改善产品功能，提高用户体验
4.与开发人员紧密结合，确保产品实施进度和质量，对产品最终上线的质量和效果负责

【岗位要求】

1.具有3年以上2B或2G产品规划和体验设计相关经验
2.优秀的逻辑分析、判断和沟通能力，能与业务方沟通复杂业务需求
3.能独立负责产品设计工作，面试时需展示界面或原型
4.熟练使用Axure、Visio、Mindmanage、PPT等办公软件公软件
  熟悉产品流程图绘制以及产品需求文档(PRD)及技术功能描述文档的撰写
5.优秀的逻辑分析、判断和语言表达能力，有较强的文字功底优先
6. 有中台应用或信息安全领域相关产品工作经验者优先考虑

7.具备CISA/CISSP/ISO27001/PMP/CISP等证书者优先


（6）web前端开发工程师

【岗位职责】

1. 根据产品需求，完成需求分析并进行对应的功能设计
2. 与UI设计、产品及后端人员及时沟通，保证产品的质量和开发进度
3. 熟悉用VUE/ES5/6/HTML/CSS并结合现代框架来丰富web产品的用户体验
4. 熟悉敏捷开发，编写高质量的、可维护性的代码
5. 不断优化现有的产品，努力提高系统速度，稳定性和可扩展性；不断提升用户体验

【岗位要求】

1. 2年及以上2B或2G产品的Web前端开发经验；
2. 理解MVVM原理，至少熟悉Vue前端框架、了解nodeJS；
3. 熟悉浏览器运行时细节，了解 HTTP 协议；
4. 具备较强的沟通能力和良好的学习能力；
5. 注重设计模式、前端工程化、模块化开发及代码架构设计，有前端改进与优化经验优先；
6. 对前端微服务化、大屏开发有经验者优先

7.具备CISA/CISSP/ISO27001/PMP/CISP等证书者优先


（7）JAVA后端开发工程师

【岗位职责】

1. 负责核心产品的开发和维护工作，编写和维护模块功能的代码
2. 攻关系统遇到的技术瓶颈，提升系统的高并发处理能力
3. 对线上突发问题进行及时响应并解决
4. 持续对线上系统进行性能优化及稳定性提升

【岗位要求】

1.本科及以上学历，具备2年以上JAVA开发经验；
2.扎实的JAVA编程基础，对Spring, Mybatis等开源框架具有深入的理解；
3.理解JVM的工作原理，包括内存模型、GC机制、性能优化等；
4.熟悉关系型数据库设计及SQL，熟悉Redis，熟悉linux系统常用操作命令；
5.对微服务架构及容器化知识具有一定的了解
6.良好的编程习惯和沟通能力，能够承受较强的工作压力和强度，具备强烈的工作责任心

7.具备CISA/CISSP/ISO27001/PMP/CISP等证书者优先
