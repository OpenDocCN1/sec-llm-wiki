杭州数梦工场科技有限公司
//


杭州数梦工场科技有限公司（简称“数梦工场”）创立于2015年3月，总部位于杭州云栖小镇，在全国三十一个省市设有分支机构，在北京、杭州、南京、广州、郑州、长沙、成都、兰州成立技术创新中心，公司80%以上为技术人员。



数梦工场聚焦大数据、人工智能、区块链等核心技术，提供全栈大数据产品及行业解决方案，为客户提供顶层设计、产品服务、培训赋能、持续运营的全生命周期服务。


//
数据服务链DSC 解决方案
//


数梦工场数据服务链DSC (Data Service Chain)解决方案，把多种数据使用场景抽象成数据服务，如数据汇聚、数据推送、数据交换、数据查询、统计分析、比对订阅等，可以快速支撑开发和上线多种数据服务。支持水平部门间的横向级联以及垂直部门间的纵向级联，通过横纵向数据服务链联盟，打造全国信息资源“一盘棋”，实现数据资源的资产化、数据资产的服务化、数据服务的价值化，数据服务的即插即用。


  • 数据资源目录：

数据服务链提供的各种服务都以数据资源目录为载体，通过数据资源目录实现数据服务相关的开发、发布、展示、检索、订阅、使用、维护、监控、优化完整过程。


  • 数据服务：

数据服务链对数据服务进行全生命周期的监督管理，以数据服务的形式支撑各种业务场景。数据服务全生命周期包括：服务开发、服务发布、服务订阅、服务调用、质量监控和优化提升。


  • 数据级联 ：

数据服务链提供横向、纵向的级联功能，可实现目录和服务的级联，通过数据服务链联盟，建设全行业覆盖的“数据高速公路”，实现全国信息资源“一盘棋”


  • 数据高铁：

数据高铁功能是在生产系统和业务应用之间搭建了一条实时高速通道。数据高铁提供跨网传输能力，通过代理可实现跨网透传，中央控制节点管控跨网节点，可实现跨网任务一次配置，全链路生效，避免多次多级配置的复杂性和一致性问题。


  • 统计分析：

数据服务链提供时间维度、部门维度、应用维度、API服务维度、健康维度等多维度的统计分析功能。


//
DTForce大数据安全解决方案
//


数梦工场DTForce大数据安全（以下简称DTForce）解决方案，以“大数据技术驱动保障大数据安全”的理念，围绕数据全生命周期的安全保障，通过大数据安全能力驱动，为数字经济转型的客户提供数据安全风控、敏感数据资产管理、数据安全防护、数据安全运营的能力。
