# 正奇学院·安全创业营二期开营仪式，百位网安创始人齐聚北京

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzMDE5MDI5Mg==&mid=2247489722&idx=1&sn=9c0582c5bdc04f34313ccb3cee83a521&chksm=c27f5e01f508d71739ef8760de0ec42f4130161bc9b82db7754f8aa005e592471d610af6c8ee&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzMDE5MDI5Mg==&mid=2247489722&idx=1&sn=9c0582c5bdc04f34313ccb3cee83a521&chksm=c27f5e01f508d71739ef8760de0ec42f4130161bc9b82db7754f8aa005e592471d610af6c8ee&scene=27#wechat_redirect)

2021年3月26日，近百位国内网络安全菁英齐聚北京春晖园国际会议中心，原来是正奇学院·二期创业营的38位同学们开学啦！  

![](../Images/68801efbe43daf105dea41f78bea1716.png)

▲正奇学院·安全创业营二期学员合影  

  
正奇学院-安全创业营由北京赛博英杰科技有限公司董事长谭晓生先生创办，旨在为安全领域创业者开设综合性实战课程与提供创业加速服务，打造健康的安全领域创业环境，帮助广大安全领域创业者解决创业路上的实际问题，科学创业，少走弯路，健康发展，同时为优秀的安全领域创业企业提供投融资等资源性服务。  
![](../Images/816586f21c686d27382043a1dc37dcfe.png)▲正奇学院创始人谭晓生  
  
正奇学院一期于2019年9月——2020年1月开班，共有来自33家公司的34位创始人/联合创始人/合伙人等相关负责人参加。目前一期学员中已有九家学员企业成功拿到投资，发展迅速。此外，在国内各大比赛中，一期学员企业也都取得了不俗的成绩。其中，中国网络安全产业联盟（CCIA）评选成长之星中占三 ，中国网络安全产业联盟（CCIA）评选潜力之星中占十，BCS安全创客汇十强中占二 ，ISC创新大赛十强中占三。其中，金睛云华获得2020星星之火IT创新项目大赛第一名。  
    已获得融资的一期学员（9家）  ▼

![](../Images/098040a61ab100d0f41425816df9923e.png) 

正奇学院·安全创业营二期的招生工作已于2020年12月底结束，共有来自37家公司的38位创始人/联合创始人等相关负责人通过面试获得入学资格，其中创始人、总经理、法人共25人，占比接近66%，80后居多。

二期的37家学员所属企业分别来自7个省份和直辖市，包括北京（19家）、广东（7家）、河南（3家）、江苏（2家）、山东（2家）、上海（2家）、浙江（1家）、内蒙（1家）。创业时间在10年以上的企业7家，创业时间在5-10年内的企业为10家，创业时间5年以内的企业为20家，占比最多，接近54%。 二期的37家学员所属企业中，23大类产品技术方向中，覆盖了16大类；8类安全服务方向中，覆盖了5大类。  
开学之后，安全创业营二期的学员们将以周末集训的方式完成十天的学习之旅，学期为五个月。  

**二期开营亮点盘点**

  
  
  
1**行业大咖云集**安恒信息高级副总裁袁明坤、奇安信集团副总裁陈华平、深信服副总裁胡斌、阿尔法公社创始人Alex、安在创始人张耀疆、赛博谛听创始人金湘宇（NUKE）、数说安全创始人于江（仙儿）等网络安全领域的研究专家、投资者等出席了此次开营典礼。  
![](../Images/47d862bdce99fb723b74300cd66e763d.png)  
  
2 **近百家企业的聚会**“希望和学弟学妹们多一些交流互动。希望一期和二期的同学们，大家能团结在一起，共同做点事情，让国产的安全真的能在这个世界上站住脚，让别人看一看，我们其实是一个团结的团队，是一个团结的民族。”已经毕业的一期学员中有26人专程赶来参加正奇学院二期的开营典礼。两期学员代表了网络安全产业的新兴力量，学员企业的合作与化反，也会促进行业的发展与进步。  

![](../Images/8ccd1ecb8208c7cf6765d40f36ca7a17.png)

▲正奇学院·安全创业营一期、二期学员大合影

  

3 **课程设置四大亮点/八大模块**由于创业安全公司的创始人多是技术或产品背景，有过安全公司运营经验的成员很少，所以在公司发展节奏控制、产品规划、销售体系构建、内控、政府关系处理等方面的知识体系并不完善。  
针对这些问题，二期创业营的课程进行了更加精准化、体系化的优化更新，同时，延续了原有课程中突出的行业老鸟带队、实战认知课堂、企业诊断与测评、关键资源对接的四大亮点，课程内容涵盖了企业战略、商业战略、产品管理、服务体系、营销创新、投融资管理、企业经营、研发技术共八大模块，以满足学员们的实际需求。
