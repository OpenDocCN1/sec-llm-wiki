# 2020年全国网络与信息安全管理职业技能大赛正式启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzMDE5MDI5Mg==&mid=2247488730&idx=4&sn=b693db7101048c4a154256b738099f7b&chksm=c27f5261f508db77a0f51ef9c76943861924809f294632513acf6c61aa7766e5bcfd6587f0f6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzMDE5MDI5Mg==&mid=2247488730&idx=4&sn=b693db7101048c4a154256b738099f7b&chksm=c27f5261f508db77a0f51ef9c76943861924809f294632513acf6c61aa7766e5bcfd6587f0f6&scene=27#wechat_redirect)

为全面贯彻落实习近平总书记关于网络安全工作和技能人才工作的系列重要指示精神，加快培养大批网络安全高素质劳动者和高技能人才，持续推进网络安全群防群治，有力促进互联网企业和联网单位加强信息安全管理员队伍建设，“2020年全国行业职业技能竞赛—全国网络与信息安全管理职业技能大赛”于8月正式启动。此次大赛作为国家一类大赛，由公安部、人力资源和社会保障部、全国总工会共同主办，公安部第三研究所、上海市公安局、上海市人力资源社会保障局、上海市总工会、浙江日报报业集团联合承办。  
自2018年以来，“全国网络与信息安全管理职业技能大赛”已连续举办两届，累计吸引来自全国知名互联网企业、互联网单位和相关单位从就业人员5万余人报名参与，80余万人次通过网络观看竞赛直播活动，大赛已成为网络与信息安全领域具有广泛影响力和号召力的品牌赛事，对于提升全社会网络安全责任意识，加强网络安全专业技术人才队伍建设起到了良好的推动和促进作用。  
据了解，此次大赛采用“初赛+决赛”形式，从即日起持续到9月底。初赛由各地公安机关、人力资源和社会保障局、总工会共同负责本赛区竞赛组织、决赛选拔和确定决赛队伍等工作。决赛采用现场比赛的形式分线下赛和直播赛。考虑到企业及行业实际情况，大赛设为双人赛项，设置网络安全管理员和信息安全管理员两个职业工种。  
大赛将对标世界技能大赛网络安全项目，打造高规格、高质量竞赛体系，持续推动以赛促训、以赛促学。各职业工种分设一等奖、二等奖、三等奖和优胜奖，在大赛所获得成绩将与职业技能等级鉴定和晋升挂钩。各职业工种获得全国线下赛决赛前3名的队伍选手且为职工身份，经人社部核准后，将被授予“全国技术能手”荣誉；获得直播赛第1名并符合条件的职工身份选手，可在次年度由其所在地按程序优先推荐评选“全国五一劳动奖章”。  
“网络安全为人民，网络安全靠人民”， 2020年全国网络与信息安全管理职业技能大赛线上报名通道已正式开启（www.inspc.org.cn），让我们积极参与，履行网络安全防护责任，提高安全防护能力，切实形成全社会共同维护网络安全的强大合力，为中国网络强国建设贡献坚实力量。
