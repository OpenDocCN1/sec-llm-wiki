# 疫情之下，六方云成功融资数千万

2020年初，突如其来的疫情，使国内大量中小企业处于停摆状态，很多企业面临生死考验，投资机构对被投企业的选择也表现的更加谨慎。但在如此焦灼的疫情下，六方云逆势成功获得数千万B轮融资，由知名投资机构达晨财智领投，密码资本担任独家财务顾问，这体现了资本市场对六方云公司及团队的高度认可！ 

![](../Images/ce870761d516a39c77a4fdfc6a2d699c.png)

  
**打造技术领先的“新安全”公司**六方云是一家技术领先的“新安全”公司，借助人工智能技术、工控安全、网络安全和大数据安全相关技术，仿生人体免疫系统，针对工业互联网和物联网提供“主动防御”产品和解决方案。六方云在工控安全、网络安全、云安全、大数据安全四大产品线基础上，实施“+AI战略”构建“AI纵深防御体系”，基于先天智能“AI+战略”构建“AI威胁免疫体系”，推动工业互联网安全由被动防御向主动防御方向发展。神探是六方云AI威胁免疫体系中的第一款产品，它成功地将AI技术应用到工业信息安全和云安全领域，取得了“高于90%威胁告警准确率、低于5%的威胁告警误报率”的显著成效，在鞍钢集团、上汽集团、潍柴动力、大唐电力、青海油田、上海石化、延长石油等众多国内关键基础设施、军工、智能制造、政府等客户中获得一致认可和赞誉。

**上升产业+高端人才，实现“以技术保障技术”** 

![](../Images/2f833bcd65fd0c855a050241b32688d3.png)

▲六方云董事长&创始人 任增强  
六方云董事长任增强表示：工业互联网安全、云安全、人工智能安全是“新安全”，是未来，而未来世界发展的主要推动力来自于技术。六方云坚持以吸引和团结有共同价值观的人才为核心，持续不断地耕耘攻坚，实现“以技术保障技术”，用最先进的技术解决国家在互联网高速发展中的安全问题，保障国家工业互联网战略、云安全战略、以及新基建安全的实现，让万物安全互联。工业互联网安全和云安全作为等级保护2.0和关键信息基础设施安全保护的重点关注领域，必将成为未来重要的网络安全赛道。在达晨财智、盛宇投资等合作伙伴的支持下，六方云将继续加大对该领域的研发投入，保持产品技术领先，打造让万物安全互联的“新安全”公司，为国家的发展做出贡献！  
达晨财智是我国第一批按市场化运作设立的本土创投机构，截止目前，达晨财智共管理23期基金，管理基金总规模300亿元；投资企业超过510家，成功退出169家，帮助其中92家企业上市，是国内规模最大、投资能力最强、最具影响力的创投机构之一。  
达晨财智业务合伙人迮钧权表示：达晨坚定的看好中国工业互联网安全和人工智能两大方向。六方云创始人任增强曾创立联想网御，打造了当时国内最大的安全公司，后来又创立网神，网神于2014年被奇虎360收购，创造了国内安全领域最大的并购纪录。六方云创业团队丰富的安全领域从业经验、前瞻性的技术研发定位以及多次成功的创业经验，是达晨投资六方云的最核心原因。后续融资过程中，达晨也将继续加码，支持六方云对业务方向和技术方向的不断探索。![](../Images/361e7bf98137159eea3c0192b7cbd2f6.png)
