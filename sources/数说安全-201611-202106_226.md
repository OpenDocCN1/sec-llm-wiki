最近一周，由于原油和疫情双重影响，全球股市巨幅震荡，美股一周内两次熔断，更是创出历史最大跌幅。在不确定的资本市场环境下，更要回归商业的本质，关注企业的基本面研究。  
这一个多月美股16家上市网络安全公司陆续发布了2019财年年度报告，我们为大家梳理了这16家企业的主要经营情况，从**营业收入、营业收入增长率、净利润、人均毛利**4个方面进行了数据对比，并对国内知名度较高的5家网络安全公司**FORTINET、FIREEYE、OKTA、PING IDENTITY、QUALYS**进行了重点介绍。  
注：美股各企业财年周期和年报披露时间差别较大，国内知名度较高的SPLUNK、CHECK POINT、PALO ALTO、CROWDSTRIKE等企业目前还未披露2019财年报告，我们后面会持续跟踪，还请大家多多关注。

  

由于近期市值动荡频繁，文末我们更新了全球网络安全上市公司市场排行，请参阅。

  

**营业收入**  
在营业收入方面，FORTINET以21.6亿美元、约150亿人民币的营收规模遥遥领先，第2至第5位的分别是：SOLARWINDS 9.3亿美元、FIREEYE 8.9亿美元、PROOFPOINT 8.9亿美元、OKTA 5.9亿美元。

**净利润**  
在净利润方面，FORTINET以3.3亿美元净利润位列第一，QUALYS、CYBERARK、SOLARWINDS分别位列二至四位。

**业务简介**  

Fortinet面向企业、通信服务提供商、政府客户提供整体网络安全解决方案。通过集成的Fortinet Security Fabric平台，为客户应对网络攻击提供自动保护，检测和响应。Fortinet的重点业务领域包括：

*   网络安全：包括防火墙、下一代防火墙、安全Web网关、SSL解决方案、SD-WAN解决方案，入侵防护、SSL 数据泄漏防护、VPN、交换机、无线控制器以及广域网边缘安全。
    
*   关键基础设施安全：包括安全访问Wi-Fi和交换机。
    
*   云安全：通过虚拟防火墙和其他软件产品，为公共和私有云环境提供安全保护，包括电子邮件和Web应用。
    
*   端点保护、物联网和运营安全：Fortinet提供核心端点保护、APT防护、事件监控和响应方案。

**业务简介**

FireEye提供基于情报的全面网络安全解决方案，使组织可以准备、预防、调查、响应和补救网络攻击，包括针对本地、云、混合和关键基础架构环境的攻击。FireEye的网络安全产品和服务产品组合，可通过以下方式帮助客户最大程度地降低代价高昂的网络安全漏洞的风险：

1.  在攻击发生之前验证现有网络安全控制措施的有效性；
    
2.  检测并防止其他安全控件错过的攻击；
    
3.  能够更有效地管理安全操作，包括针对漏洞警报管理，调查和响应；
    
4.  提供评估、培训和其他战略安全咨询服务，帮助组织提高其抵御攻击能力。
    

  

FireEye的核心竞争优势包括：

1.  采用机器学习，基于行为和基于规则的威胁检测，分析和关联技术
    
2.  来自威胁传感器和虚拟机全球网络的、基于攻击者的和基于受害者的威胁数据的连续流，以及安全分析师、顾问和专家收集的威胁情报，得出有关威胁和威胁参与者的情报。
    
3.  源自过去15年对数千次重大违规事件的响应积累的安全专业知识。
    

  

**经营情况**

1.  2019年营收8.89亿美元，与2018年相比增长了7%。Billings金额9.26亿美元，与2018年相比增长了8%，
2.  2019年GAAP毛利率为收入的65%，2018年为67%。非GAAP毛利率为收入的73%，2018年为收入的75%。GAAP营业利润率为收入的负24%，2018年为负22%。非GAAP营业利润率为收入的1%，而2018年为收入的3%。GAAP每股净亏损为 1.24美元，2018年GAAP每股净亏损为 1.27美元。2019年非GAAP摊薄后每股净收益为 0.05美元。
3.  2019年经营活动提供的现金流为6800万美元，2018年经营活动提供的现金流为1700万美元。

  

**增长战略**

1.  提升市场渗透率。依靠市场教育来提高客户对当今网络攻击的认识，向用户充分展现公司安全解决方案和服务的价值。潜在客户通常没有将其IT预算的特定部分分配给公司的高级安全解决方案，这是值得争取的销售机会。
    
2.  安全验证软件（例如Mandiant安全验证平台）和安全操作平台（例如FireEye Helix）的市场处于开发的早期阶段，存在着巨大的增长潜力。
    
3.  加大研发投入，提升现有平台的性能和功能。
    
4.  加大在销售和市场营销方面的投入力度，提高市场知名度，影响更多潜在客户并推动公司产品、订阅、平台和服务的采用。市场教育对于争取新的IT预算资金或将更多现有的IT预算资金分配给高级威胁防护，安全验证和安全运营管理解决方案，尤其是公司的解决方案和FireEye Helix平台至关重要。潜在客户认识到对高级威胁防护解决方案，安全验证和安全运营管理解决方案等的关键任务需求的迫切程度，将推动公司获得新客户并增加续订和后续销售的能力机会。
    
5.  提升销售生产力。公司销售组织由内部销售团队组成，这些团队与外部渠道合作伙伴协作。公司的直销团队是按地区组织的，针对的是大型企业和政府客户。公司将进一步扩大内部销售团队，并与渠道合作伙伴合作，以扩大中小企业客户群。
    
6.  加大国际市场教育方面的投资，提高公司在全球市场的知名度，加深国际市场销售团队对公司及公司的解决方案的认知，更高效地将潜在客户转化为签单客户，推动收入增长的速度。
    
7.  实施优化客户获取和保留方案，让现有客户随着时间的推移扩展其部署，购买公司的其他解决方案。在向新客户进行首次销售之后，专注于扩大与客户的关系，以销售其他产品，订阅和服务。向现有客户群的销售采取增量销售的模式，介绍对用户有价值的更多解决方案，托管服务和专业服务，以扩大他们对技术的部署。后续销售可在客户关系的整个生命周期内增加收入，显著提高公司的销售和营销投资回报。

**业务简介**  
Ping Identity致力于让用户从任何设备安全访问任何服务，应用程序或API。智能身份平台可以利用AI和ML分析设备，网络，应用程序和用户行为数据，以做出实时身份验证和安全控制决策，从而增强用户体验。平台不断检测异常并仅在必要时自动插入其他安全措施，例如多因素身份验证。智能身份平台可以跨云，混合和本地基础架构进行部署，并提供一整套全面的集成，可以扩展到数百万个身份以及数千个云和内部部署应用程序。  
智能身份平台由六个解决方案组成，这些解决方案可以单独购买，也可以作为一组集成产品购买：SSO，MFA，访问安全性，目录，数据治理和API智能。智能身份平台可以保护所有主要用例，包括客户，员工，合作伙伴和物联网，企业还可以使用平台为员工和商业伙伴提供从任何设备到他们需要提高生产力的应用程序，数据和API的安全无缝访问。

1.  Ping Identity认为在现有的客户群中存在大量追加销售和交叉销售的机会，通过添加标识和用例以及销售新的解决方案和解决方案包，增加对现有客户的销售。

**业务简介**  
Qualys成立于1999年，是全球知名的漏洞管理与IT合规性解决方案SaaS服务提供商。Qualys Cloud Platform集成了多种应用程序套件，包括资产管理、IT漏洞管理&威胁监控防护、web漏扫&WAF、政策&安全配置&PCI合规性检查等，Qualys Cloud Platform使用最新的威胁情报和高级关联以及机器学习功能，可以自动识别全球混合IT环境下的基础设施、终端、云端实例、容器、移动设备、IoT设备等资产（私有环境或私有云依赖轻型硬件设备或软件代理），并进行漏洞和错误配置的自动检查，确定威胁的优先级，自动部署补丁程序，并持续跟踪补救措施的有效性，在未修复漏洞前将资产隔离，以经济高效的方式帮助客户获得其IT资产清单以及这些IT资产安全性与合规性的统一视图，在提升企业安全运营效率的同时降低其合规成本。
