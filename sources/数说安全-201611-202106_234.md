# 安恒9.45亿，山石6.74亿，安博通2.63亿，行业保持高速增长

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzMDE5MDI5Mg==&mid=2247488771&idx=1&sn=279cd2d7f01a53b97c459affeddebf5c&chksm=c27f53b8f508daaecaa60604a6be939cda5490ca71c62bdc8d630de264d3ca209344e3e475ed&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzMDE5MDI5Mg==&mid=2247488771&idx=1&sn=279cd2d7f01a53b97c459affeddebf5c&chksm=c27f53b8f508daaecaa60604a6be939cda5490ca71c62bdc8d630de264d3ca209344e3e475ed&scene=27#wechat_redirect)

这周，科创板三家网络安全公司发布了2019财年业绩快报。**安恒信息营收9.45亿**，同比增长50.85%,这个增速表现不错。**山石网科营收6.74亿**，同比增长19.97%；**安博通营收2.63亿**，同比增长34.72%；从这三家公司披露的财务数据来看，行业依然保持高速增长。  
**安恒信息**  
![](../Images/786ec2dc8ab6c6d864ccef6bdda09e45.png)**二、经营业绩和财务状况情况说明 ****（一）报告期的经营情况、财务状况及影响经营业绩的主要因素。 **报告期内，公司实现营业总收入 945,182,300.56 元，较上年同期增长 50.85%；归属于母公司所有者的净利润 93,589,262.69 元，较上年同期增长 21.74%；归属于母公司所有者的扣除非经常性损益的净利润 81,167,701.48 元，较上年同期增长 40.38%。报告期末公司总资产 2,173,794,364.77 元，较上年同期增长143.73%；归属于母公司的所有者权益 1,551,735,489.25 元，较上年同期增长206.15%； 2019 年公司整体经营状况稳定向好，主要得益于：网络信息安全行业的快速发展；公司持续进行研发投入和新产品开发；加强了市场开拓和渠道合作，进一步深化了战略布局；提升了项目管理、质量管理和技术服务等综合能力。  **（二）上表中有关项目增减变动幅度达 30%以上的主要原因说明： **1、公司营业总收入同比增长 50.85%和归属于母公司所有者的扣除非经常性损益的净利润同比增长 40.38%的主要原因是所处行业持续快速发展，且公司云安全、大数据、物联网等新一代网络信息安全产品销量增长较快，同时公司顺应行业发展趋势加快推进安全服务业务。 2、总资产同比增长 143.73%主要原因是报告期内完成首次公开发行股票，获得募集资金导致的货币资金增加所致。 3、归属于母公司股东的所有者权益同比增长 206.15%及归属于母公司所有者的每股净资产同比增长 129.61%主要原因是报告期内完成首次公开发行股票，获得募集资金导致资本公积增加及营业利润增长导致的未分配利润增加所致。 4、股本同比增长 33.33%主要原因是公司于 2019 年 11 月发行 1,851.8519万股新股所致。   
**安博通**  
![](../Images/3d5643caac92e0aa7c7b394048645b71.png)** 二、经营业绩和财务状况情况说明 ****（一）报告期的经营情况、财务状况及影响经营业绩的主要因素。**报告期内，公司实现营业收入 26,317.50 万元，同比增长 34.72%；实现利润总额 8,670.59 万元，同比增长 22.85%；实现归属于母公司所有者的净利润7,560.19 万元，同比增长 22.83%；实现归属于母公司所有者的扣除非经常性损益的净利润 7,082.01 万元，同比增长 18.03%；报告期末总资产 107,059.06 万元，较期初增长 243.54%；归属于母公司的所有者权益 100,149.58 万元，较期初增长 292.10%。 公司积极深耕网络安全市场、始终坚持技术创新和产品创新、深入调研行业用户需求，大力加强新技术、新产品研发，持续增加研发投入，报告期内公司安全产品销售增长较快，使公司营业收入有所增长。   
**（二）主要指标变动原因分析 **1.营业总收入同比增长 34.72%，系报告期内公司安全产品销售增长较多所致。 2.总资产同比增长 243.54%，归属于母公司的所有者权益同比增长 292.10%，归属于母公司所有者的每股净资产同比增加 194.08%，主要系公司首次公开发行股票并募集资金，使公司总资产与净资产大幅增加所致。 3.股本同比增加 33.33%，系公司首次公开发行股票 1,279.50 万股，使公司总股本增加所致。   
**山石网科**  
![](../Images/c0e8c2ce9f225eebd0b51e070259adb7.png)**二、经营业绩和财务状况情况说明 ****（一）报告期的经营情况、财务状况及影响经营业绩的主要因素** 2019年度，公司实现营业收入67,457.07万元，与上年同期相比增长19.97%；实现归属于母公司所有者的净利润9,119.41万元，与上年同期相比增长32.33%；实现归属于母公司所有者的扣除非经常性损益的净利润 7,418.94 万元，与上年同期相比增长 0.82%。 报告期内，公司经营情况和财务状况良好，业绩稳定增长，主要系公司持续推进市场开拓和渠道建设，进一步加大研发投入、丰富产品线，主营业务收入较上年同比增加所致。 2019 年归属于母公司所有者的扣除非经常性损益的净利润同比增长较低，主要原因系 2018 年公司拆除 VIE 架构并进行业务重组，报告期内同一控制下企业合并产生的子公司期初至合并日的当期净损益对非经常性损益净额影响较大，扣除同一控制下企业合并产生的影响后，调整后扣除非经常性损益后归属于母公司净利润同比增长 19.68%，与营业收入的增长趋势一致，如下表所示： ![](../Images/c7746e64edd54b46a1ae5a01c60eaac7.png)**（二）主要指标增减变动的主要原因** 1、公司 2019 年度实现归属于母公司所有者的净利润 9,119.41 万元，与上年同期相比增长 32.33%，主要原因系公司 2019 年度营业收入增长，同时取得的软件产品增值税退税和科技项目政府补助较上年有所增加； 2、公司 2019 年末总资产 162,719.42 万元，与上年同期相比增长 117.90%， 主要系报告期内公司首次公开发行股票募集资金导致货币资金增加所致； 3、公司 2019 年末归属于母公司的所有者权益 137,907.93 万元，与上年同期相比增长 231.24%，主要系报告期内公司首次公开发行股票募集资金导致资本公积增加、营业利润增长导致未分配利润增加所致； 4、公司 2019 年末股本 180,223,454.00 元，与上年同期相比增长 33.33%，主要系报告期内公司首次公开发行 45,056,000 股新股所致； 5、公司 2019 年末归属于母公司所有者的每股净资产 7.65 元，与上年同期相比增长 148.38%，主要系报告期内公司首次公开发行股票募集资金导致资本公积增加、营业利润增长导致未分配利润增加所致。   
注：1.本报告期初数同法定披露的上年年末数。  2.以上财务数据及指标以合并报表数据填列，但未经审计，最终结果以公司2019 年年度报告为准。
