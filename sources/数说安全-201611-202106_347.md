# 启明星辰董事长：2018年经营回顾及未来策略

![](../Images/f7c76e680f28a765f6daa19d2a6fd579.png)10月30日，启明星辰针对投资者们开展了一场业绩说明会（三季度投资者关系活动），启明星辰的董事长和高层们在会议中进行了经营回顾及未来展望，充分体现了公司与品牌的价值所在。

  

**启明董事长王佳在会议中指出：**

“年初的战略规划得到了良好的落地，也在考虑明年组织结构和激励机制的变革。公司战略布局日益完善，最重要的是**全国安全运营中心**的建立，提升公司区域市场和竞争能力，盈利模式开始发生转变。安全运营业务已在成都、济南、郑州三门峡、湖北宜昌开展起来，还有郑州、西宁、昆明、杭州、天津、南昌、无锡、青岛等城市陆续启动。今年全年签单有望达1.5亿以上。

  

此外，我们还将在天津滨海新区设立公司的人工智能研究中心，在无锡设立物联网安全研究中心，在重庆设立工业互联网安全研究中心，在西安设立涉密业务研究示范区，为当地的重要大客户、国家关键基础设施、重要信息系统提供技术支撑。同时，也在与三大运营商合作共建针对他们客户的运营中心，针对一带一路的国际网络环境设立安全运营中心。我们的团队提升非常明显，研发在很多方面引领市场。

  

我们在很多重点行业取得良好的增长，包括轨道交通、央企、电信、能源、政府、金融、教育等，个别行业因改革、机构调整原因导致项目延迟，预计明后年会出现强劲增长。

  

目前市场对第三方独立安全的认知又推进了一步，我们正处在科技重构社会的快速进程当中，第三方独立安全成为平衡发展风险的方式和抓手，比如云安全和云平台分开，安全和大数据信息化分开，这样更有利于保障数据安全。《网络安全法》规定安全和信息化要同步设计和运维，安全和信息化是两个独立的东西，未来安全甚至会前置。所有科技都是双刃剑，安全就是怎么去控制好科技的风险，我们需要提前研究很多应用的风险，比如人工智能、无人驾驶等。独立的安全越来越被认可，我们几乎所有的客户都认可需要独立的网络安全运营商。”

  

**![](../Images/f7c76e680f28a765f6daa19d2a6fd579.png)启明星辰在会议中，向投资者介绍了启明目前在各安全新领域中，取得的可喜进展和实施计划：**

*   **物联网安全**：启明将成立物联网子公司，推出视频安全监控等解决方案，后续在工业互联网、物联网的安全会落地；物联网的可视化管控平台，这个是与我们物联网安全紧密相关。
    
      
    
*   **云安全**：新一代云安全资源池全能产品会在四季度发布，满足云等保的要求。
    
      
    
*   **工业互联网安全**：启明与国家工业信息安全发展研究中心达成战略合作，是唯一的网络安全企业。入围工信部三个工业互联网研发项目，接下来会有更多合作，在研究经费和试点推广会得到支持。工控安全启明已有三四年的积累，今年应会有过亿收入，在此领域，公司（启明）是做得最好的。
    
      
    
*   **移动安全**：子公司辰信领创是首批拿到国产自主可控防病毒资格的公司，公司还将为公安app认定和检测工作提供技术支撑。
    
      
    
*   **人工智能安全**：公司已发布云端威胁情报平台，与公司运营中心、中小企业saas平台都是数据来源，会对公司在人工智能方面的研究形成支撑。下个月还会发布基于UEBA的防护系统，把实体行为做人工智能的分析，是人工智能和网络安全的结合，也是未来平台化的方向。
    
      
    
*   **安全运营**：今年研发也有很大进展，安全运营平台将会更加标准化，未来设立安全运营中心的成本会进一步下降，服务方式和收费方式也会更加标准。
    
      
    
*   **态势感知和关保平台**：发布了态势感知和关键信息基础设施保护平台新版本。
    
      
    
*   **视频安全**：发布了视频安全防护系统，在平安城市、雪亮工程、应急指挥、治安管理发挥越来越重要的作用。
    

  

启明指出，希望明年可以做的更好，并表示网络安全是国家投入越来越大的领域。

  

**![](../Images/f7c76e680f28a765f6daa19d2a6fd579.png)在交流环节中，启明也透露了一些投资者十分关注的问题。**

  

Q

****1、三季度退税情况如何？****

答：增值税退税前三季度进度有点慢，金额比去年同期少了2000万，后面还会陆续有些月份的退税会进来；年度预计的时候我们是预计退税到8月份，考虑了部分退税进度的影响。

  

Q

******2、下游行业每个版块的基数和体量情况？******

答：政府领域相对比较大些，一般是40%左右，然后就是央企、电信、金融、能源等，轨道交通基数相对比较小，但这两年增速非常快。今年由于个别行业的影响，导致我们增速整体没有那么明显。

  

Q

******3、工业安全的进展？******

答：去年工控做了3000万，今年预计有望过亿，工控现在大的子行业布局我们都做的比较好，与东方电气成立的合资公司已经发现200多个自动控制漏洞，因为每个子行业不同，所以工控需要与行业结合；我们之所以把物联网研究中心放在无锡，因为那边有1000多家物联网企业。虽然目前体量还不够大，最重要的是布局很好。合作伙伴包括国网、大型烟草企业、东方电气等，要在行业内具有可复制性。  

  

Q

******4、等保2.0落地带来的影响？******

答：国家政策都有合规性的要求，对于规模化的企业优势更加凸显，因为小的公司很难从解决方案层面去满足用户需求。等保2.0是个合规性的政策，是针对我们客户的要求，护网行动今年我们全面参与，展示了我们低调负责的形象和专业水准。

  

Q

******5、对安全运营中心未来发展的展望？******

答：对于我们已经展开的运营中心收入有两块：客户粘性很强一般不会换运营商，一签至少三年，我们会不断扩充客户数量，把当地有独立需求的客户比如公安都接入，与运营商合作在政企市场拓展运营，硬件和场地今年已经投入的，明年硬件这些就不用额外投入，我们预期是明年翻倍增长。安全运营的定价不是特别统一，一年几百万到千万级，在这个基础上可以拓展更多政企客户，政务之外，还有税务、公安、社保等等。对我们这样规模的企业来说，将会受益于竞争壁垒提高，客户粘性加大，市场集中度提升。安全运营是新业务，在各地拓展时会遇到不尽相同的情况，随着业务成熟度的不断提升，业态也将会随之稳定下来，形成标准化的产品。

  

Q

******6、公司回购事项和大股东减持的进展如何？******

答：回购目前已通过董事会审议，还需股东大会通过。减持主要是为了解除质押，质押比例不高。

  

  

Q

******7、销售费用率下降原因？******

答：前三季度研发费用随着投入的加大而增加，销售费用进行了一些控制，但也处于合理范围内。

  

  

Q

******8、公安大数据业务情况？******

答：公安大数据业务，成都子公司有，合众数据也有，这个是属于我们泛安全的领域。今年也发布了公安业务大数据应用联盟解决方案，可实现公安跨省域海量数据共享。公安团队今年从政府里面独立出来，这个子行业明年有希望翻倍增长。
