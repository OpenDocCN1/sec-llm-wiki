数说安全



术语通常会成为一些新手进入行业的障碍。语境不统一，经常会出现老鸟口若悬河，新手一脸懵逼的情况。今天给大家汇总一些网络安全常用词汇和缩写。简单释义，不求甚解，有兴趣的同学可以自行脑补。


词汇或缩写释义
adaptive security自适应安全 Garnter提出的一套方法论
AIArtificial intelligence 人工智能
anti-fraud反欺诈
anti-spam反垃圾邮件
anti-virus防病毒
APIApplication Programming Interface 应用程序编程接口
Appliance装置，一般指硬件盒子类的设备
APTAdvanced persist threat 高级持续威胁
backdoor后门
biometrics生物识别，基于生物特征的认证技术
blacklist黑名单，whitelist 白名单
blockchain区块链
botnet僵尸网络
BYODBring your own device 带自己的设备，用自己的设备办公
C&C或C2，comand and control 控制肉鸡的服务器
CACertificate Authority 证书授权中心
CASBCloud Access Security Broker 云访问安全代理
confidentiality机密性
container容器
crawling爬虫
critical infrastructure关键基础设施
CVECommon Vulnerabilities & Exposures，公共漏洞和暴露，一个国际的披露漏洞的组织
CWPPCloud Workload Protection Platform 云工作负载保护平台
data breach数据泄露
DDOSDistributed Denial of Service 分布式拒绝服务攻击
deception欺骗，指基于欺骗技术的产品
DLPData Loss Prevention 数据泄露防护
EDREndpoint Detection and Response 终端检测与响应
EMMEnterprise Mobile Management 企业移动管理
encryption加密
exploit of vulnerability漏洞利用
forensics取证
GDPRGeneral Data Protection Regulations 一般数据保护条例，欧盟
geopolitical地缘政治
Government Regulations政府合规
GRCGovernance Risk and Compliance 治理、风险与合规
IAMIdentity and Access Management 身份与访问管理
ICSindustrial control system 工业控制系统
IDaaS一种基于身份认证的SaaS服务 ID=identity
identity theft身份劫持
IDSIntrusion Detection System 入侵检测系统
insider threat内部威胁
intergrity完整性
IoCIndicator of Compromise 损害指标 指遭到安全攻击的一些迹象
IoTInternet of Things
IP ReputationIP信誉库
IPSIntrusion Prevention System 入侵防御系统
IpsecIPSec=Internet Protocol Security IP协议安全性 IPsec VPN 一种VPN技术
IRincident response 事件响应
killchain杀伤链，用来描述攻击活动的过程
lateral movement横向移动，指攻击成功后进一步寻找攻击目标
machine learning机器学习
malware恶意软件
MDMMobile Device Management 移动设备管理
MDRManaged Detection and Response 管理检测和响应，一种高级别的安全服务
MFAMulti-factors Authentication 多因素认证
micro-segmentation微分段，也有叫微隔离的
MSSPManagement Security Sevice Provider 管理安全服务供应商
NACNetwork Access Control 网络准入控制
NGFWNext generation firewall 下一代防火墙
NTANetwork Traffic Analysis 网络流量分析
on premises本地部署，指部署在企业内部
OTPOne time password 一次性口令
PAMPrivileged Account Management 特权账号管理
patch补丁，指修复bug或漏洞的增强程序
penetration testing渗透测试
phishing钓鱼，指这里指网络钓鱼
PKIPublic Key Infrastructure 基础公钥设施
POEPower over ethenet 一种接口类型，通过以太网接口供电
privacy隐私
proactive defense主动防御、积极防御
ransomeware勒索软件
reconnaissance侦查
resilience弹性的
reverse proxy反向代理
sandbox沙盒，也有叫沙箱
SDNSoftware defined network 软件定义网络
SDPsoftware defined perimeter 软件定义边界
security automation安全自动化
security awareness安全意识
security orchestration安全编排
SIEMSecurity Information and event management 安全信息与事件管理
SOCSecurity Operation Center 安全运营中心，NGSOC 下一代SOC
Social Engineering社会工程学
SQL injectionSQL注入，一种Web攻击方法
SSLSecure Sockets Layer 安全套接字层 ssl vpn 一种vpn技术
SSOSingle sign on 单点登录
suspicious可疑的
threat hunting威胁捕获
Threat Intelligence威胁情报
UEBAUser Entity and Behavior Analysis 用户和实体行为分析
URL-FilteringURL过滤
UTM统一威胁管理管理
virtualization虚拟化
VPNvirtual private network 虚拟专用网
vulnerability脆弱性，一般泛指漏洞
WAFWeb Application Firewall，Web应用防火墙
XSS跨站脚本攻击，一种Web攻击方法
Zero Day零日漏洞，一般指未公开的漏洞
