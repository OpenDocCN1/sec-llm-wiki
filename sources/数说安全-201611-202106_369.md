术语通常会成为一些新手进入行业的障碍。语境不统一，经常会出现老鸟口若悬河，新手一脸懵逼的情况。今天给大家汇总一些网络安全常用词汇和缩写。简单释义，不求甚解，有兴趣的同学可以自行脑补。

  

| 词汇或缩写 || 释义 |
| --- | --- |
| adaptive security || 自适应安全 Garnter提出的一套方法论 |
| AI || Artificial intelligence 人工智能 |
| anti-fraud || 反欺诈 |
| anti-spam || 反垃圾邮件 |
| anti-virus || 防病毒 |
| API || Application Programming Interface 应用程序编程接口 |
| Appliance || 装置，一般指硬件盒子类的设备 |
| APT || Advanced persist threat 高级持续威胁 |
| backdoor || 后门 |
| biometrics || 生物识别，基于生物特征的认证技术 |
| blacklist || 黑名单，whitelist 白名单 |
| blockchain || 区块链 |
| botnet || 僵尸网络 |
| BYOD || Bring your own device 带自己的设备，用自己的设备办公 |
| C&C || 或C2，comand and control 控制肉鸡的服务器 |
| CA || Certificate Authority 证书授权中心 |
| CASB || Cloud Access Security Broker 云访问安全代理 |
| confidentiality || 机密性 |
| container || 容器 |
| crawling || 爬虫 |
| critical infrastructure || 关键基础设施 |
| CVE || Common Vulnerabilities & Exposures，公共漏洞和暴露，一个国际的披露漏洞的组织 |
| CWPP || Cloud Workload Protection Platform 云工作负载保护平台 |
| data breach || 数据泄露 |
| DDOS || Distributed Denial of Service 分布式拒绝服务攻击 |
| deception || 欺骗，指基于欺骗技术的产品 |
| DLP || Data Loss Prevention 数据泄露防护 |
| EDR || Endpoint Detection and Response 终端检测与响应 |
| EMM || Enterprise Mobile Management 企业移动管理 |
| encryption || 加密 |
| exploit of vulnerability || 漏洞利用 |
| forensics || 取证 |
| GDPR || General Data Protection Regulations 一般数据保护条例，欧盟 |
| geopolitical || 地缘政治 |
| Government Regulations || 政府合规 |
| GRC || Governance Risk and Compliance 治理、风险与合规 |
| IAM || Identity and Access Management 身份与访问管理 |
| ICS || industrial control system 工业控制系统 |
| IDaaS || 一种基于身份认证的SaaS服务 ID=identity |
| identity theft || 身份劫持 |
| IDS || Intrusion Detection System 入侵检测系统 |
| insider threat || 内部威胁 |
| intergrity || 完整性 |
| IoC || Indicator of Compromise 损害指标 指遭到安全攻击的一些迹象 |
| IoT || Internet of Things |
| IP Reputation || IP信誉库 |
| IPS || Intrusion Prevention System 入侵防御系统 |
| Ipsec || IPSec=Internet Protocol Security IP协议安全性 IPsec VPN 一种VPN技术 |
| IR || incident response 事件响应 |
| killchain || 杀伤链，用来描述攻击活动的过程 |
| lateral movement || 横向移动，指攻击成功后进一步寻找攻击目标 |
| machine learning || 机器学习 |
| malware || 恶意软件 |
| MDM || Mobile Device Management 移动设备管理 |
| MDR || Managed Detection and Response 管理检测和响应，一种高级别的安全服务 |
| MFA || Multi-factors Authentication 多因素认证 |
| micro-segmentation || 微分段，也有叫微隔离的 |
| MSSP || Management Security Sevice Provider 管理安全服务供应商 |

| NGFW || Next generation firewall 下一代防火墙 |
| NTA || Network Traffic Analysis 网络流量分析 |
| on premises || 本地部署，指部署在企业内部 |
| OTP || One time password 一次性口令 |
| PAM || Privileged Account Management 特权账号管理 |
| patch || 补丁，指修复bug或漏洞的增强程序 |
| penetration testing || 渗透测试 |
| phishing || 钓鱼，指这里指网络钓鱼 |
| PKI || Public Key Infrastructure 基础公钥设施 |
| POE || Power over ethenet 一种接口类型，通过以太网接口供电 |
| privacy || 隐私 |
| proactive defense || 主动防御、积极防御 |
| ransomeware || 勒索软件 |
| reconnaissance || 侦查 |
| resilience || 弹性的 |
| reverse proxy || 反向代理 |
| sandbox || 沙盒，也有叫沙箱 |
| SDN || Software defined network 软件定义网络 |
| SDP || software defined perimeter 软件定义边界 |
| security automation || 安全自动化 |
| security awareness || 安全意识 |
| security orchestration || 安全编排 |
| SIEM || Security Information and event management 安全信息与事件管理 |
| SOC || Security Operation Center 安全运营中心，NGSOC 下一代SOC |

| SSL || Secure Sockets Layer 安全套接字层 ssl vpn 一种vpn技术 |
| SSO || Single sign on 单点登录 |
| suspicious || 可疑的 |
| threat hunting || 威胁捕获 |
| Threat Intelligence || 威胁情报 |
| UEBA || User Entity and Behavior Analysis 用户和实体行为分析 |
| URL-Filtering || URL过滤 |
| UTM || 统一威胁管理管理 |
| virtualization || 虚拟化 |
| VPN || virtual private network 虚拟专用网 |
| vulnerability || 脆弱性，一般泛指漏洞 |
| WAF || Web Application Firewall，Web应用防火墙 |
| XSS || 跨站脚本攻击，一种Web攻击方法 |
| Zero Day || 零日漏洞，一般指未公开的漏洞 |
