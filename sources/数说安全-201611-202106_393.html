Palo Alto Networks（以下简称：PAN）作为全球下一代防火墙（NGFW）的领导厂商之一，9月7日发布了2017年年报（PAN财年是每年7月31日）。我们一起读一读PAN的年报，了解一下全球领先的网络安全厂商的经营情况和最新动态。

公司简介

  • Palo Alto Networks成立于2005年，总部位于美国加州硅谷的圣克拉拉；

  • 截至2017年7月31日，一共有员工4562人；

  • 截至2017年7月31日，在150多个国家拥有超过42500名终端客户；

  • 截至2017年7月31日，全球有超过4400家渠道合作伙伴；

  • 2017财年，营业收入合计17.6亿美元，营业收入增长率为27.8%;

  • 2017财年，经营亏损1.79亿美元，营业利润率为-10.2%，累计赤字8.37亿美元；

  • 2017财年，人均产值38.6万美元，人均毛利28.2万美元；

最新动态

2017.9

We also expect to release two new cloud-based subscription offerings: 

GlobalProtect cloud service subscription, which provides our Next Generation Security Platform as a cloud-based service for remote offices and mobile users; 

Logging Service subscription, which functions as the central cloud-based repository for all application data and logs, and allows end-customers to collect data without needing to plan for local processing power and storage. 

//2017.9将释放两个基于云的订阅，GlobalProtect云服务订阅（PAN运营一个多租户，基于云的安全基础设施；远程办公和移动用户可以不再购买设备或软件，用户可以使用PAN的服务快速添加或删除远程位置和用户并按需建立和调整安全策略；从描述来看，应该是通过Vsys实现多租户隔离，通过VPN实现远程接入进而提供的FWaaS）和日志服务订阅（基于云的集中日志存储服务，允许用户收集上下文丰富的增强型网络日志，包括所有应用数据和日志）。



2017.6

We announced the next phase in the evolution of our Next-Generation Security Platform:

Palo Alto Networks Application Framework. Our cloud-based Application Framework will introduce a new SaaS consumption model under which our end-customers will be able to rapidly implement cloud-based security applications developed by us, third-party developers, or other security vendors, without having to deploy or manage additional products. We expect our Application Framework to become generally available in the early 2018 calendar year, with continuous and ongoing introduction of new security applications.

//2017.6 PAN发布了下一代安全平台演进的下一阶段：Palo Alto Networks应用框架。基于云的应用框架将引入一种新的SaaS消费模型，允许用户快速部署由PAN、第三方开发者、其他安全厂商开发的基于云的安全应用，用户可以不再部署管理额外的产品。预计2018年上线，并持续不断引入新的安全应用。这个涉及到商业模式的转变，是一盘大棋，PAN能下成什么样需要进一步观察。


2017.2 

We expanded our family of firewalls with the launch of several new appliances: 

PA-220, for small branch offices and remote locations; 

PA-800 series, for medium-sized networks and branch and remote office environments; 

PA-5200 series, for high throughput environments in a compact form factor; 

three new VM-Series virtual firewall models, support cloud and virtualization initiatives ranging from virtualized branch offices to data center and service provider deployments. 

PAN-OS 8.0, an important software release that expands security for public and private clouds, provides new SaaS application security functionality, and also provides the capabilities to prevent the theft and abuse of stolen credentials.

//2017.2 PAN扩展了防火墙产品线，发布了几款新的硬件：PA-220（适用于小型分支机构和远程办公）、PA-800系列（适用于中等规模网络、分支机构和远程办公环境）、PA-5200系列（适用于高吞吐环境的紧凑型产品）以及三款新的VM-Series虚拟化防火墙（支持云和虚拟化部署）；同时发布了PAN-OS 8.0，一个重要的软件版本。这个版本扩展了公有云和私有云的安全，提供新的SaaS应用安全功能并能够防止盗用和滥用偷来的凭证。

业务及产品简介

PAN的下一代安全平台由三个主要元素构成：

1.下一代防火墙：硬件设备和基于云的软件；

2.高级端点防护：在各类终端上阻止网络攻击（运行恶意代码和软件漏洞利用）；

3.威胁情报云：提供核心情报能力，SaaS应用安全和自动分发预防措施以防范网络攻击。

Firewall Appliances and Software. 

防火墙设备和软件为不同性能需求而设计，基于吞吐量分级，从PA-200（企业分支机构）到PA-7080（大规模数据中心和服务提供商）。VM-Series是虚拟形态产品，应用于虚拟化和云环境，支持VMware、Microsoft、Amazon和KVM／Openstack环境。

Panorama. 

Panorama是全局集中安全管理解决方案，能够全面管理部署在用户网络或公有云上物理设备和虚拟设备。提供策略管理、设备管理、软件授权和更新、日志集中管理和报表、日志集中存储等功能；

Subscription Offerings. 

订阅服务是平台的一部分. 包括：Threat Prevention（IDP特征库）、URL Filtering （URL库）、WildFire（云或本地沙箱检测未知威胁）、GlobalProtect（VPN，扩展企业物理网络边界，基于位置确定网关并自动建立连接）、VM-Series（虚拟设备订阅，有期限或永久许可，可应用于VMware’s NSX and ESXi、Microsoft’s Hyper-V、 Red Hat KVM hypervisors、AWS cloud、Azure cloud）、Traps Endpoint Protection（防护终端免遭恶意代码和漏洞利用，融合WildFire）、AutoFocus（为用户安全运维团队提供威胁情报能力，IoC）、Aperture（为IT允许的SaaS应用提供内容控制，防止共享机密数据和恶意内容）、GlobalProtect cloud service（17年9月释放，FWaaS）、Logging Service（17年9月释放，日志服务）

Support & Professional Services. 

为用户和渠道合作伙伴提供标准支持、高级支持和4小时高级支持。渠道合作伙伴运营PAN授权支持中心提供level-one和level-two支持，PAN在全球的区域支持中心提供7*24小时的level-three支持。专业服务指现场支持、专家根据用户具体需求设计和实施有效安全方案、在线和面授培训，这些服务由授权合作伙伴提供。

竞争分析

企业安全市场的特征是不断改变和创新，竞争非常激烈。应用、威胁和技术的改变导致客户需求演变以应对威胁并让应用更安全。我们的竞争对手分为三类：

1.大型网络公司，如Cisco、Juniper

2.独立安全厂商，如Symantec、Checkpoint、Fortinet、Fireeye

3.与平台中某些特性相竞争的提供单一解决方案或云安全服务厂商

随着我们市场的增长，它将吸引更多高度专业化和规模更大的销售商，他们可以继续更有效地获取客户或捆绑销售他们的产品。我们市场上的主要竞争因素包括：


1.产品特性、可靠性、性能和有效性；

2.产品线的广度、多样性和适用性；

3.产品可扩展性和与其他技术基础设施集成的能力；

4.价格和总拥有成本；

5.遵守行业标准和认证；

6.销售和市场推广力度；

7.品牌知名度和美誉度。

PAN总结的竞争优势：平台的特性与性能，易于集成的产品，总体拥有成本


管理层讨论与分析

  • 平台使用了一种创新的流量分类引擎，它通过应用程序、用户和内容标识网络流量，并在网络、端点和云上提供一致的安全性。

  • 下一代安全平台由三个主要元素组成：下一代防火墙、高级端点保护和威胁情报云。

  • 最近三个财年总收入分别为18亿美元、14亿美元和9亿2810万美元，增长率分别为27.8%和48.5%。

  • 增长来自于采用了混合SaaS收入模型（hybrid SaaS revenue model），它由产品、订阅和支持组成。这种模式将使我们在不断增长的终端客户基础上，从经常性收入中受益。

  • 截至2017年7月31日，我们在150多个国家拥有超过42500名终端客户。

  • 销售采用一种两层的间接履行模式（two-tiered, indirect fulfillment model），即将产品和服务销售给分销商，然后将其销售给我们的经销商，然后转售给我们的最终客户。

  • 产品收入在2017财年增长到7.09亿美元，占总收入的40.3%，比去年同期增长了5.7%（产品收入来源于设备销售）。

  • 订阅和支持收入在2017财年增长到11亿美元，占总收入的59.7%，比去年同期增长了48.7%（订阅为客户提供防病毒、防入侵、网络过滤和恶意软件防御的服务）

  • 在2017年2月，收购了LightCyber。LightCyber的技术通过行为分析的加入扩展了我们平台的功能，为未来一个新订阅提供了基础。

  • 业务增长、短期和长期的成功取决于许多因素，包括我们扩大我们的技术领导能力，扩大我们的客户基础，扩大我们的平台部署和支持我们的客户并关注客户的满意度。


财务分析


  • 产品销售来自于设备的硬件销售，还包括Panorama和VM-Series；产品销售收入7.09亿美元，同比增长5.7%，产品销售收入增长率相比上一财年下降了31个百分点；产品销售收入占总体营业收入的比率近三年一直下降，从15年的53.1%下降到了40.3%；

  • 订阅和支持服务周期一般为一至五年，这部分收入保持高增长；订阅收入5.5亿美元，同比增长54.3%，相比上一财年增长率67.8%略有下降，增速放缓；支持收入5亿美元，同比增长48.7%，相比上一财年增长率57.5%略有下降，增速放缓；订阅和支持部分收入占总体营业收入的比率近三年一直增长，从15年的46.9%增长到59.7%；

  • 美洲营业收入为12.4亿美元，同比增长27.1%，占总营收的71%；欧洲、中东和非洲营业收入为3.2亿美元，同比增长29.5%，占总营收的18%；亚太去营收2亿美元，同比增长29%，占总营收的11%；各个区域增长率相比上一财年均有下降。


  • 近三年毛利率分别为72.9%、73.2%和72.9%，总体较为平稳，其中产品毛利率为71.2%，订阅与支持毛利率为73.9%；近三年营业利润率分别为-10.2%，-11.4%和-10.8%，已连续三年亏损；

  • 近三年研发支出占营业收入的比率分别为19.7%，20.6%和20%，研发支出总体较为平稳；近三年销售及市场费用占营业收入的比率分别为52.2%，53.9%和52.7%，平稳运行在高位；近三年管理费用占营业收入的比率分别为11.3%，10%和10.9%，17财年管理费用小幅上升；




仙儿简评


  • PAN总体营业收入依然保持良好增长，订阅及支持依然保持高速增长态势，但产品收入增速大幅下降为未来业绩成长埋下隐患。由于PAN的商业模式是混合SaaS收入模型，订阅及支持服务部分的增长依赖于部署PAN设备或软件的客户数。产品收入增速放缓是先行指标，会对未来订阅和支持服务收入产生负面影响。

  • PAN今年6月发布的PaloAlto Networks应用框架，这个可能比较重要。PAN构建一个开放平台，允许客户、第三方开发者和其他安全厂商在上面部署安全应用。这是要构建一个“安全生态”？产品销售增速下滑，可能是欧美市场对安全产品的需求出现了结构性变化，现行商业模式已无法支撑未来的高速增长。经过多年技术和品牌积累，PAN现已具备构建平台的实力。这个平台就是PAN未来新的增长点，PAN的商业模式也从“做产品”升级到“做平台”。仙儿目前对这个应用框架理解有限，观点可能存在偏颇，仅供参考。
