# 八一八网络安全企业员工薪酬（一）启明星辰

说在前面

        笔者从投资视角观察网络安全行业，分享个人对国内外网络安全企业财报的数据分析，希望能够感知网络安全行业未来发展趋势与方向，对投资行为提供数据参考。笔者将分若干个专题对数据进行分享，希望对读者有所帮助，一点点也好。

  

        对于网络安全企业来说，人力成本占总成本比重较大，因此对企业薪酬的跟踪能快速感知企业内部变化。人力成本与营业收入的比率一方面可以反映企业的商业模式优劣，另一方面也能说明企业的人力成本控制能力。投资者偏爱用更少的人力成本获取更多的营业收入的公司。根据统计数据显示，启明星辰公司人力成本占营业收入的比率这些年一直维持在40%左右。这个值是否优劣只有对比同行业其他企业才知道，在后续的系列文章中将给出此项数据的对比。

  

![](../Images/8603df255415489cc5a0c221fc8aece8.png)

        我们再来看看启明星辰最近几年员工人数的变化情况。在2011年年报中启明星辰员工人数为1141人，在2012年员工人数增至2167人。启明星辰在2011年6月公告收购网御星云，但在2011年年报中两家公司并未合并报表，合并后员工人数在2012年的年报中才体现出来。2014年启明星辰先后完成对书生电子和合众数据两家公司的收购，2015年3月启明星辰收购安方高科，上述收购均在当年年报完成报表合并。由此看来，近几年启明星辰公司人员规模扩张几乎都是通过收购行为完成的。

  

![](../Images/f0e6b4312c8859e7208298cf56a8aa6e.png)  

        

        根据2015年启明星辰员工总人数为2981人，其中研发人员1206人，其他技术人员（销售支持）579人，销售人员603人，管理人员157人，其他人员（财务、生产、行政等）436人，占比情况详见下图所示。启明星辰本科及以下员工占比高达90%以上，研究生及以上占比不足10%。对于高科技行业对企业创新能力，研发能力和高精尖技术攻关能力要求较高，虽然教育程度不能完全代表业务水平，但启明星辰高等教育程度员工比重偏低。后续也会提供行业其他企业的员工教育程度数据，读者可自行比较。

![](../Images/f289e907b5aa0fd35bf9a81379676820.png)  

  

        在来说说启明星辰公司员工平均薪酬福利的变化情况，近5年启明星辰薪酬福利年平均复合增长率约为11%，此项数据高于国家统计局发布的薪酬增长的平均水平。在2013年启明星辰薪酬福利相比2012年增长了近40%，增长幅度不小，可能是大幅调薪或高奖金支出所致，也可能是网御星云员工薪酬福利高于启明星辰，在合并报表中将均值拉高。在2014年平均薪酬支出下降了，一般来说平均薪酬下降可能由于高薪员工大批离职，或并购低薪酬公司所致。我们知道14年启明星辰收购了书生电子和合众数据并合并报表，笔者猜测这两家公司员工平均薪酬低于启明星辰，因此合并报表后拉低了平均薪酬福利这项数据。2015年启明星辰员工平均薪酬福利上涨了20%以上。需要说明的是，这里给出数据是公司为员工支出的费用（包括五险一金等），如果想估算启明星辰员工的平均薪酬可采用以下方法：假设启明星辰平均月薪为x，奖金为n，那么平均薪酬福利支出约等于x\*1.5\*12+n，假设奖金为2个月薪酬，那么2015年启明星辰员工平均工资约为1万元，其他年份请各位自行计算。

  

![](../Images/1912fc1e0b7e7db8d7bd64cf983d20c3.png)  

            

        研发人员能否开发出好产品，销售人员能否将好产品转化为营业收入，是企业的关键能力。最后，我们看一下研发人员和销售相关人员的平均薪酬情况。2015年启明星辰研发人员的平均薪酬为26.5万，远高于整体平均薪酬。请大家注意这项数据是笔者粗算，研发投入可能还包括研发过程中支出的一些其他费用（年报中未明确列示），但研发人员薪酬福利应该是比重最大的一部分，此处的计算忽略研发投入中的其他费用，后续对比其他公司此项数据也按照相同方法处理。销售薪酬福利数据就相对可靠些，在利润表销售费用一项中明确列出。前面提到过，2015年启明星辰销售人员603人，一共支出薪酬近3亿元，平均薪酬福利近50万元？这个数据好像不和逻辑。通过笔者研究发现，销售费用中职工薪酬一栏应包括支持销售的非研发技术人员，共计579人。重新计算后销售人员的平均薪酬福利约为25万元，这个数据看上去更真实一些。假设非研发技术人员的薪酬福利为公司的平均水平，那么启明星辰销售人员的平均薪酬约为30万元。
