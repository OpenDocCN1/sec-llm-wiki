# SASE丨一年融资三轮，亿格云获资本加持，完成数千万元A+轮融资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzMDE5MDI5Mg==&mid=2247499453&idx=4&sn=329739a2c978155aab4ca2345082d2ce&chksm=c27cb806f50b3110ce0367f226b9c60f63fc5a0229946544cfe11644aea8a05e66c791920410&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzMDE5MDI5Mg==&mid=2247499453&idx=4&sn=329739a2c978155aab4ca2345082d2ce&chksm=c27cb806f50b3110ce0367f226b9c60f63fc5a0229946544cfe11644aea8a05e66c791920410&scene=27#wechat_redirect)

近日，杭州亿格云科技有限公司（简称：亿格云）正式宣布完成数千万元A+轮融资。本轮融资由**靖亚资本**领投，**未来启创基金**参与共同投资。亿格云CEO葛岱斌表示，本轮融资主要用于夯实产品技术、拓展行业客户、交付客户服务及建设团队人才。为进一步打造亿格云在办公安全领域的SASE技术竞争力，同时凭借新引入投资者的行业优势，加速技术与业务深度融合。

  

投资圈有一段“黑话”：天使轮看人，A轮看产品，B轮看数据，C轮看营收，IPO看利润。一句话生动地说明不同阶段的企业投资亮点。毫无疑问，一年内融资三轮的SASE安全服务商亿格云无论是**团队**还是**产品**都受到资本的认可与关注，大步向前迈开奔跑的步伐。

  

亿格云成立于2021年，秉持“让企业安全极致简单”的服务理念，在企业数字化转型过程中，帮助企业以**更低成本、更高效率**建设更加安全、更好体验的办公安全体系。为此，亿格云提供了All in One的办公安全解决方案——亿格云枢，解决**企业移动和远程办公安全、数据安全、终端安全**等问题，用一个客户端即可提供**零信任安全访问（ZTNA）、数据防泄漏（XDLP）、防病毒、威胁检测响应（XDR）、上网行为管理和桌面管理**功能。

![](../Images/7fc365d468ad5c4300acf67cccd78345.png)

数字时代，办公模式已经变了。

  

IDC数据预测，至2023年，全球2000强企业或组织中，70%将采用远程或混合办公优先的工作模式。根据Gartner联合腾讯研究院发布的《2022年混合安全办公白皮书》报告指出，全球范围内的混合办公已成常态，且在将来仍有很大的增长空间。同时，混合办公模式下，安全的重要性已经被企业和员工在相当程度上关注。相关调研显示，当被问及混合办公的重要要素时，**安全（68.3%）**排在了受访者认为**第二重要的要素，仅次于效率（82.6%）**。

  

在这个充满未知与市场潜力的办公安全赛道，对标国际厂商，拥有实打实技术能力的**国产化SASE**替代厂商屈指可数，而亿格云便是其中的一个。

 

为区别于传统安全厂商，亿格云的创始团队用“一个云来保护企业的办公网安全”的理念和产品逻辑结合，取名为”亿格云“。其中寓意远不止于好记，更是突出**云端化部署的高效与便捷。**

  

  

**从办公安全切入**

**数字企业的”解忧“平台—亿格云枢**

  

在创始团队看来，服务理念与使命能决定公司的市场有多大，而核心产品则很大程度上决定了公司能走多远。

  

故而亿格云在打造核心竞争力上，进行了多方位部署，一是组建专业人才队伍去**打磨产品与技术**，二是通过不断的**市场拓展**，让更多企业客户能了解、使用、并信任亿格云。在这样的背景下，亿格云自主研发的零信任SASE一体化办公安全平台——「亿格云枢」，呱呱坠地。

  

自2021年成立后的第一个合同落地以来，亿格云枢已经在每个客户的反馈中迭代了数十次的功能。从**零信任安全访问（ZTNA）、全域数据防泄漏（XDLP）、到办公网络加速、终端安全一体化**等，每一次的功能上线，都代表着客户的真实需要与诉求。

  

在被问及客户在**办公安全中一般会有哪些挑战**的时候，亿格云CEO葛岱斌是这样总结的：

NO.1

  

首先，企业在做传统安全建设过程中往往需要**部署多个乃至10多个安全产品**来达到安全防护效果，而这些安全产品间互不打通，最终的安全效果往往不尽人意。

NO.2

  

其次，伴随企业数字化转型加快、**多分支机构，远程办公、移动办公**成为常态，而不同场景下的**安全策略不统一，安全水位不一致**，会给企业带来更多安全隐患。

NO.3

  

再者，传统安全建设带来的**繁、重、贵**（采购成本、运维成本、人力成本等）大大降低了安全建设的效率，很多中小企业也没有机会去做全面的安全防护，**亟需轻量且普惠**的安全产品。

NO.4

  

最后，终端多款安全产品的**堆叠**，**占用大量资源**，给员工带来了极大**不便利和不流畅**的办公体验，影响办公效率。

NO.5

  

......

还有诸多的客户声音源源不断传来。基于此，以零信任为理念，SASE安全架构落地的服务也正式走上了正轨。

  

如今来自**智能制造、金融、游戏、泛互联网、消费**等诸多行业头部的企业客户纷纷与亿格云开展深入合作，而亿格云枢便是为企业办公安全量身打造的**“防护罩”**。

![](../Images/dec63021a5388494247e94ec3e07d3c9.png)

近期亿格云作为甄选厂商选入《国产化替代指南》SASE、零信任等多领域。对标Zscaler、Netskope等国际厂商，亿格云枢通过构建一朵集中管控安全的“云”、一张全球办公加速的“网”和一个安全能力合一的“端”，形成云网端融合的云原生安全体系，以 SaaS 化的服务提供多项安全能力，为企业带来了如下收益：

  

**（一）**

对企业网络架构** 0 入侵**和现有应用** 0 改造**，即可收敛互联网暴露面，快速落地**零信任安全访问**，用基于身份、持续验证的动态访问控制能力建立企业安全新边界。

  

**（二）**

能够**统一管控**办公网的网络和安全策略。

  

**（三）**

无论在**总部、分支，还是居家、移动办公**，都具备**全场景一致**的**高安全水位.**

  

**（四）**

SaaS 化部署带来的 **15 分钟**完成启用的极致高效。

  

**（五）**

借助全球加速网络改善移动和远程办公的网络质量，通过**轻量化、稳定、安全功能**合一的客户端，以少量的资源占用实现**极佳的网络**和**终端用户体验**。

  

自成立以来，亿格云已累计服务超过50家上市公司和独角兽企业，覆盖超20万个终端。包括**吉利控股、传音控股、零跑汽车、广联达、涂鸦智能、怪兽充电**等行业头部客户。亿格云以及旗下产品亿格云枢多次获得了行业内外的奖项认可，多次跻身各类安全创新大赛全国十强。

  

对于未来的期许，葛岱斌及其团队表示：“我们将持续在SASE等前沿技术加快步伐，保持创新，踏实服务客户，不断根据客户需求迭代产品体系和解决方案，加速技术、产品和复杂多变的业务场景深度融合，努力做好客户的办公安全防护。让客户反馈的‘**一体化融合、轻量便捷、无感体验、快捷交付、弹性灵活、加速网络**...’赋能到每一个数字化企业。”

  

  

  

**投资人观点**

**靖亚资本** 

一

2022年整个企服行业包括SaaS赛道虽然面临着挑战，但亿格云依旧能在逆境中稳扎稳打，稳步向前，无论是在亿格云枢产品的领先创新性，客户服务数量，还是行业覆盖度等方面都取得了明显的增长，进一步夯实了在国内SASE领域的引领地位。

  

亿格云创始团队在安全领域的技术研发实力和客户服务经验都有着十多年的积累，掌握着国内领先的SASE安全架构技术。我们十分看好其扎实的技术基础和产业布局，期望能跟亿格云一同成长，实现「安全服务千万企」。

**未来启创基金**

**一**

SASE作为一种新兴的安全体系架构，针对多种访问场景提供融合性的广域网、边缘安全访问能力，并减少企业的运维复杂度。亿格云正在这一新的安全体系上进行产品自研与创新，非常符合当下企业对于数据安全、终端安全、应用安全、网络安全的切实诉求。因此，我们非常看好这一革新的产品与技术，我们期待在中国企业未来数字化安全转型的路上，会看到更多亿格云枢的身影，也期待创新的零信任SASE产品能为更多企业带去安全保障服务。
