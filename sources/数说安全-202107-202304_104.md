# 电网千万网络安全项目招标：技术服务、商用密码安全评估、平台软件、风险评估

近日，南方电网发布2022年网络安全技术服务、平台软件采购、商用密码应用安全性评估、网络安全风险评估招标公告。招标人为广东电网有限责任公司广州供电局，项目预算共1454.71万。  

  

项目概况和招标范围：(一)项目概述：标的1 标包1-11 (2022年网络安全技术服务)通本项目为广州供电局日常的网络安全工作提供技术支持，遵循网络安全相关法律法规、南方电网公司网络安全相关管理规范等要求，落实网络安全“三同步”工作，巩固、加强网络安全支撑能力，持续完善数字化网络安全保障体系。标的1 标包12（2022年商用密码应用安全性评估）：本次商用密码应用安全性评估工作根据《中华人民共和国密码法》第二十七条中规定法律，行政法规和国家有关规定要求使用商用密码进行保护的关键信息基础设施，其运营者应当使用商用密码进行保护，自行或委托商用密码监测机构开展商用密码应用安全性评估。针对安全保护等级为第三级的信息系统。根据评估要求，依据GM/T0054-2018《信息系统密码应用基本要求》的第三级指标开展密码应用安全性测评。标的1 标包13（2022年网络安全风险评估）：为广州供电局系统与设备提供安全风险评估，通过分析和评估各单位的网络与信息系统以及物联网设备，以及两者所承载的信息所面临的安全威胁和存在的漏洞，以检验当前其安全防护措施是否有效，确保各项安全策略得到贯彻落实，制定有效的安全策略制定，实施动态安全防护，有效并且迅速地预防攻击行为，为控制和解决安全问题提供解决方案思路。标的2（2022年平台软件采购）：通过平台软件采购，确保广州局数字化实施计划及2022年项目建设目标顺利实现，同时有利于实现广州局软件正版化的目标，提高系统的运行效率和可靠性，避免软件版权的法律风险。
