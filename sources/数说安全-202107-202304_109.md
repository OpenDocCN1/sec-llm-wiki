# 天防安全物联网身份验证获 Gartner《2022中国安全技术成熟度曲线》推荐

近日，国际权威调研机构Gartner发布《2022中国安全技术成熟度曲线》报告（《Hype Cycle for Security in China, 2022》），受到全球各界关注。报告中，**天防安全**作为国内物联网安全创新者荣膺入选，在物联网身份验证（IoT Authentication）领域被推荐为代表厂商。

![](../Images/98719c8cf3b931a0223698098fa8e9a4.png)正如Gartner报告所述，物联网身份验证（IoT Authentication）达到了顶峰。物联网身份验证与中国其他实体建立了对大量物联网设备的信任。![](../Images/58abe02dcdae26cef2daf376acb253ef.png)物联网（IoT）身份验证是一种对事物（通常是设备）的身份建立信任的机制，这些实体与设备、应用程序、云服务、网关或在物联网环境中运行的人类用户进行交互。物联网的认证考虑了物联网设备的潜在资源限制、它们内部运行的网络的带宽限制以及各种物联网实体之间交互的机械化性质。  
物联网解决方案为优化流程或获取新的收入提供了新的机会。工业物联网（IIoT）通过更好的制造自动化来推动。联网汽车、智能城市、智能家居和智能可穿戴设备等市场正在迅速增长。然而，这些连接设备连接了网络和物理世界的桥梁，并打开了新的威胁载体。物联网设备需要可信的身份和强大的设备认证，以减轻网络攻击。

  

天防安全系列产品可提供可信的身份和强大的设备认证完整解决方案。天防安全专注于物联网安全领域，一直深耕视频网络安全细分赛道，紧密围绕 “严控边界、纵深防御、主动监测、全面审计”和雪亮工程“全程可控”的要求，结合视频监控网络的现状和需求，推出了视频监控网络安全领域系列产品和解决方案。

  

未来，天防安全将继续加大在视频安全研究领域的攻防对抗能力、攻击面发现和攻击面收敛能力的技术投入，不断加强和丰富产品及服务能力，为客户提供更优质的服务，赋能平安城市、天网工程、雪亮工程、智能交通、智慧城市等重大项目，筑牢我国公共视频监控安全防线。
