# 数据分类分级具体怎么做？傲天科技发布落地产品

随着数据安全上升到国家安全层面和国家战略层面，数据的分类分级已经成为了数据安全治理的必选题，但同时也是一道难题。  
  
分类分级是数据安全的基础性工作，是对数据实施安全保护措施的重点和前提。**当前数据分类分级存在难点主要聚焦在：**  
**1、指引性缺失。**目前只有在金融、证券、工业互联网为数不多的行业有相应的分类分级指引，其他行业缺乏相应的规范指引；**2、落地较难。**数据分类分级规范指引中数据的颗粒度不够精细，同时面对组织内散落各个业务系统中动辄几千、上万张数据资源表的情况时，工作量巨大且落地难度更大；**3、难以运营。**缺乏相应的体系化的制度流程和规范，使得分类分级难以得到持续维护及运营。  
4月25日，**数据要素与数据安全一体化治理倡导者--傲天科技发布的《数据分类分级系统》产品，为这一难题提供了新的解决方案。****![](../Images/b810ce74c36c09e724f3254711171b17.png)**

  

傲天发布的《数据分类分级系统》，基于数据分类分级知识库以及NLP算法对数据进行标识匹配和智能补全，让敏感数据发现和识别由“人力服务”变成“机器自动”，生成数据资产全景目录和数据分类分级报告。  
**客户基于“资产目录”和“数据报告”能够更清晰的对组织内的敏感数据做精准的保护。**

数据分类分级知识库，是本次发布的数据分类分级产品一大特征。  
**目前傲天数据分类分级知识库已积累近150万行参考标准数据，能够有效提升数据分类分级约40%的实施效率。**  
该知识库中，目前主要包含了各个行业以及地方政府已对外发布的分类分级指南中的数据，同时采集政府开放网站中的分类分级数据作为机器学习样本，根据算法得到规范化的分类分级参考数据。  
**傲天《数据分级分类系统》当前对政务大数据、医疗、电信、证券等行业适配最佳，其他行业需要做一定的适配。**
