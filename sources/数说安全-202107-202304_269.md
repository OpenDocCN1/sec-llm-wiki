# 零信任丨「亿格云」完成近亿元Pre-A轮融资，投资方红杉中国

亿格云旨在构建下一代企业安全架构，解决办公安全隐患，助力企业数字化转型

  

# 近日，国内零信任企业安全服务商杭州亿格云科技有限公司（以下简称“公司”）宣布完成近亿元的Pre-A轮融资，投资方为红杉中国。本轮募集资金将主要用于安全技术团队的扩张、业务市场拓展、亿格云枢™产品平台研发以及产品交付。

  

![](../Images/8155f354e4d3bd5dd505750b34d28323.png)

#   

# 当前，企业数字化转型逐步深入，在疫情防控的加速催化下，企业办公方式发生了翻天覆地的改变。据艾瑞咨询发布的《2021年中国综合移动办公平台行业研究报告》表示，综合移动办公平台和效率办公类APP月活跃数较2020年1月疫情初期增长289.9%，标志着混合办公时代悄然而至。但与此同时，开放协同的办公方式也带来了新的挑战，企业安全边界正在逐渐“瓦解”。

  

# 伴随着企业办工形态的变化，企业IT基础设施也正走向深度云化，这背后预示着云安全产品将有更大的市场空间。而其特有的灵活性、低成本、易运维等特性逐步受到行业热捧。

  

# 随着2021年《数据安全法》正式发布，数据安全工作首次升至国家安全最高监管层级，各企业为了响应监管，也在不断提升数据安全防护能力。无独有偶，IBM安全研究报告显示，2021年企业平均每起数据泄露事件成本为424万美元。可见，数据安全的防控举足轻重，零信任安全市场潜力巨大。

  

# 成立于2021年7月的亿格云科技是一家为企业提供更简单、安全、稳定的安全办公一体化解决方案的公司，核心团队主要来自于阿里云安全的产品和业务骨干，对云安全产品技术和客户的需求把握都具备业内领先的能力。

  

# 亿格云科技自主研发的零信任SASE产品——「亿格云枢™」平台，提供零信任安全访问、终端安全防护（XDR）、数据安全防护（XDLP）、全球应用加速的一站式办公安全解决方案。

  

# 谈及亿格云枢™平台的最大优势，亿格云科技创始人兼CEO葛岱斌表示，亿格云枢™平台最大的优势在于能够更简单、更高效地帮助企业提升安全水位。“通俗地讲，办公安全对于每家企业来说都至关重要。但传统办公安全方案大都依靠多家安全厂商的众多安全产品堆叠，这些碎片化的安全布控带来的是居高不下的采购成本与繁重的运维任务。亿格云通过云枢平台™一体化集成了办公安全所需的各项能力，15分钟内即可快速部署上线。通过一个客户端即可对各类安全风险进行管控，大大降低了硬件采购成本和IT运维成本，让办公安全更简单。我们希望未来能服务更多行业创新企业，让办公安全不再是“奢侈品”。

  

# 目前，公司已服务涵盖AIOT、游戏、零售、电商、互联网等多个领域的数十家行业头部企业，为企业提供了安全办公一体化解决方案，并获得了客户的广泛认可。“我们欢迎更多人才加入亿格云，共同扬起中国网络安全事业新浪潮。”葛岱斌说道。

  

# 红杉中国合伙人周逵表示：“在数字化转型浪潮的推动下，企业安全云化成为趋势，可以非常好地解决安全碎片化、安全人才极度短缺以及安全运维成本过高等难题。基于此，我们十分看好亿格云的团队和产品方向，他们在零信任安全概念下基于SASE架构搭建了完全创新的办公安全解决方案，可以帮助企业在数字化转型过程中更好地解决企业安全的痛点。我们希望亿格云能继续通过技术创新去探索网络安全的价值和意义，为网络安全行业添上浓墨重彩的一笔。”
