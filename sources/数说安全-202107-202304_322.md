# “中国队”刷新世界最强人工智能榜单，360超越脸书和图灵奖团队登顶

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkzMDE5MDI5Mg==&mid=2247494513&idx=2&sn=716adc94739348b7715529a9ba8a9255&chksm=c27cadcaf50b24dc1bb2482a360b1dd78530c4f882dafeadf3652a2e6ae10a11eaa28593f7a1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkzMDE5MDI5Mg==&mid=2247494513&idx=2&sn=716adc94739348b7715529a9ba8a9255&chksm=c27cadcaf50b24dc1bb2482a360b1dd78530c4f882dafeadf3652a2e6ae10a11eaa28593f7a1&scene=27#wechat_redirect)

最近，一支中国团队刷新了“世界最强“人工智能榜单。 在世界顶级人工智能挑战赛OGB(Open Graph Benchmark)中，360人工智能研究院凭借“国产自研“知识表达模型登顶高难度任务榜单OGB-wikikg2，在与蒙特利尔大学、Meta（原Facebook）、阿里巴巴等顶尖高校实验室和科技巨头的同场竞技中脱颖而出。据悉，这是中国数字安全企业首次登顶该榜。 

![](../Images/d1d77866edca6daa9d9705e99f4ae49a.png)

（OGB-wikikg2 榜单，360人工智能研究院登顶，前五名中“中国队”占三席） OGB挑战赛由斯坦福大学于2019年发起，是国际公认的知识图谱基准数据集代表，相当于知识图谱领域的“世界杯“。由于知识图谱擅长挖掘和表达潜在数据关系，在智能搜索和数字风控等领域应用价值巨大，受到了越来越多的关注。 OGB挑战赛以“任务”形式发布赛题，囊括节点性质预测、图性质预测等前沿技术，以难度高、规模大、场景复杂著称。同时，由于斯坦福大学的权威性和公共性，OGB吸引了大批国际顶尖实验室组队参加，也成为科研院所和科技巨头的科技成果试金石。 据悉，此次360人工智能研究院登顶的榜单任务OGB-wikikg2由维基百科知识库演进而来，数据量庞大且极具应用价值，经斯坦福大学整理后，在知识图谱完整性上设置了技术关卡。该任务包含250万余个实体及535个关系类型，形成了1700多万条关系，需要识别海量实体和复杂关系，利用模型预测和验证新三元组任意节点间的关系，并精准表达隐藏关系，对知识图谱模型的归纳及泛化能力提出了极大的挑战。 据360人工智能研究院负责人介绍，此次参赛提交并公开的模型是360自主研发的原创模型，已应用于数字安全、互联网等领域。“参赛的初衷是为了与世界顶级团队同场竞技，验证这套原创模型的创新性和先进性。“ 记者在OGB官网发现，OGB-wikikg2任务榜前五名中，360人工智能研究院占有两席，分列榜首和第三。第二名是来自伦敦大学和Meta的联合团队，其中Meta的 FAIR实验室被誉为人工智能行业翘楚。第四名则是来自蒙特利尔大学的MILA实验室，由图灵奖获得者Yoshua Bengio领衔。同样闯进前五的，还有一家来自中国的AI创业公司。 当前，知识图谱技术已逐步成熟。在中国，相关应用需求处于高速成长阶段，但技术层面依然存在很大挑战。360人工智能研究院负责人告诉记者，投入“国产”模型研发，能够逐渐减少这个领域对技术进口的依赖。 据了解，360人工智能研究院作为三六零(股票代码：601360.SH)集团的前沿科技研发部门，研发成果已服务数亿用户。该研究院在复杂场景中积累了大量算法能力，自主研发的视觉内容理解和行为识别、知识图谱构建与应用、图文多模态表示等技术已应用于智慧生活、数字安全、智能搜索等多个实用场景。
