# 2021年网络安全市场关键词热度榜

过去一年，我们构建了中国网络安全市场BI平台，应用大数据技术对**中国网络安全市场需求侧数据**进行了跟踪。截止2021年12月31日，全年总计跟踪到134004个网络安全相关项目，并对相关市场数据进行了清洗、分类与汇总分析。  
热词是感知市场变化非常好的角度，但每个人接收的信息是不同的，对热词和热度的感知更多是定性而非定量。我们通过数说安全BI平台对**近3000个与网络安全强相关的关键词做了数据量化方面的研究与分析**。  
用网络安全市场关键词，对我们数据平台的全量数据进行词频统计，得到下面的词云图。

![](../Images/50230be531c46a01224ca0394204b862.png)

  

**分析师提示**

  

  

字体的大小代表这个关键词在全年项目中被提及的次数,颜色代表该关键词热度变化情况。从需求侧来看，**我国网络安全市场主要围绕等级保护展开建设；防火墙、防病毒、VPN、入侵防御、上网行为、漏洞扫描、日志审计等网络安全基础产品仍然是市场需求最大的品类。**

  

此外我们也发现不同行业的偏好会有一些差异，比如**防勒索软件在医疗行业热度较高，僵木蠕检测则主要集中在电信行业等**。

  
  

  

词频代表市场基数，词频的变化代表市场需求的变化情况。哪些市场在增长？我们总结了**2021年中国网络安全市场增速最快的20大热词**如下：

**分析师提示**

  

总体来说这些热词所代表的业务领域市场基数还不太大，但代表了未来市场的方向。热词涵盖了零信任、数据安全、威胁管理、终端安全和开发安全等几个方向，这几个方向都是最近几年网络安全行业内讨论最多、热度最高的话题。

  

由此可见，**网络安全市场的供需关系是相互影响的。企业不仅要适应市场需求，更需要引领和创造市场需求，避免较低水平竞争，推进网络安全产业高质量发展。**
