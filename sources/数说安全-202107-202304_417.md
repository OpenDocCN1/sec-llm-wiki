# 数据安全快速升温：639万大数据安全、百万数据安全管理平台建设；云安全高速增长：400万云安全资源池；今日网安标讯268项

今日汇集267个网安相关招标项目，包括639万辽宁省公安厅大数据安全访问平台、146万工业互联网数据安全风险监测追溯与综合管理平台等。针对数据安全、云安全、物联网安全等热点方向，精选部分招标项目进行展示。网安专项招标预告及招标项目汇总表格见文末，全部网安相关项目可联系徐工。

  

**数说安全推出按省份、行业、产品的网安标讯订阅服务，包括提前1-2个月公布的招标预告，助力营销团队，把握全国各省、各行业及细分产品品类的项目机会。如有需要，欢迎扫描文末微信二维码联系徐工。**
