**0x01 漏洞简述**

IBM WebSphere Application Server是一款功能强大、高效、安全的应用服务器软件，适用于各类企业级应用的开发和部署。它为开发人员和管理员提供了优秀的功能和工具，可以满足不同的业务需求。

  

此漏洞由IIOP协议上的反序列化造成，未经身份认证的攻击者可以通过IIOP协议远程攻击WebSphere Application Server，在目标服务端执行任意代码，获取系统权限，进而接管服务器。

  

建议广大用户及时将IBM WebSphere Application Server升级到最新版本。与此同时，请做好资产自查以及预防工作，以免遭受黑客攻击。

  

**0x02 影响版本**

►9.0.0.0 <= IBM WebSphere Application Server 9.0 <= 9.0.5.7

►8.5.0.0 <= IBM WebSphere Application Server 8.5 <= 8.5.5.19
