# 「Cyber Security Billboard」发布，斗象科技入选24条网安新兴赛道

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMjcyNzA5Mw==&mid=2247488526&idx=1&sn=48de061102e247e7267bfd9f56f78a54&chksm=96db1fd4a1ac96c22282c9251b3b74ab09d7561794bbed88d1860cb63d5615617e1c5b72d13b&scene=126&sessionid=1681379534#rd](http://mp.weixin.qq.com/s?__biz=MzIwMjcyNzA5Mw==&mid=2247488526&idx=1&sn=48de061102e247e7267bfd9f56f78a54&chksm=96db1fd4a1ac96c22282c9251b3b74ab09d7561794bbed88d1860cb63d5615617e1c5b72d13b&scene=126&sessionid=1681379534#rd)

  
  

近日，「Cyber Security Billboard·网安新兴赛道及厂商速查指南」发布，第一版共发布99个新兴产品赛道，收录420+国内厂商，350+家国际厂商，旨在助力企业安全负责人、渠道合作伙伴和安全从业者及时了解网安行业的新兴赛道及前沿产品。

  

斗象科技凭借自身实力，强势入选**24条新兴赛道**。

据了解，斗象科技入选的赛道分别为：网络检测与响应/网络流量分析、高级持续性威胁防护、弱点/漏洞优先级技术VPT、基于风险的漏洞管理、漏洞评估、安全运营中心、安全意识培训、靶场/攻防实训、动态应用安全测试、网络空间资产测绘、网络资产攻击面管理、蜜罐/欺骗诱捕、反钓鱼/钓鱼检测、沙箱、数据泄露防护、安全编排自动化与响应、物联网安全、API安全、加密流量分析、容器安全、web应用和API保护、微隔离/微分段、威胁狩猎、自动化攻击模拟。  

  

其中，**网络检测与响应/网络流量分析**（NDR/NTA）赛道中，**斗象科技入选代表性厂商**。

![](../Images/0710f9ac6f2dbec85af97a73b7a499bd.png)

斗象的**PRS-NTA全流量安全计算分析平台**利用旁路镜像的方式采集并存储网络全流量日志，拥有强大的计算架构，是一个以数据分析为核心的新一代安全计算分析平台。

  

斗象科技作为中国新一代网络安全科技创新领军企业，未来也继续投身于网络安全生态的构建，不断用创新技术迭代提升产品在新兴赛道上的竞争力，持续为社会各界的政企用户夯实信息基础设施的安全底座、守护清朗的网络空间。
