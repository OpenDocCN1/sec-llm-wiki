# 斗象智能安全7月漏洞威胁关注TOP5

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMjcyNzA5Mw==&mid=2247484989&idx=1&sn=8d8f0554836100777dbfe36b726ce4da&chksm=96db0de7a1ac84f1da31e70b35b47f790d6f5a6fbdb2a423bfa9bca531aa36d5d492770ede52&scene=126&sessionid=1681379553#rd](http://mp.weixin.qq.com/s?__biz=MzIwMjcyNzA5Mw==&mid=2247484989&idx=1&sn=8d8f0554836100777dbfe36b726ce4da&chksm=96db0de7a1ac84f1da31e70b35b47f790d6f5a6fbdb2a423bfa9bca531aa36d5d492770ede52&scene=126&sessionid=1681379553#rd)

斗象智能安全根据2020年7月斗象智能安全漏洞情报平台关注热度反馈，整理产生「漏洞威胁关注TOP5」排名，其中Cisco ASA/FTD设备任意文件读取漏洞(CVE-2020-3452) 成为本月最受关注的漏洞。

斗象智能安全CRS「漏洞情报」功能，依托漏洞盒子和斗象TCC团队在攻防对抗领域的技术积累，将风险关联资产进行决策，集漏洞情报挖掘、发布、资产漏洞识别验证、专家服务为一体的综合解决方案。未来我们将定期发布漏洞威胁关注排名榜单，欢迎大家持续关注。
