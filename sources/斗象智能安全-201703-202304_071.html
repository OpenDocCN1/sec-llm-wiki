机器学习引领沙箱技术革新，斗象智能安全新产品MAC发布

在众多网络攻击手段中，恶意软件是一种简单有效并且具有很大危害性的攻击手段，随着自动化程序的出现，恶意软件的制作和传播速度大幅增加，恶意软件威胁网络和系统漏洞的方式也在改变。恶意软件一直在变化，即使是侦查到，它们也会自动调整和变化，依靠单一的技术手段难以防范。

一般来说，传统的恶意软件检测技术分为两类：基于异常的检测和基于签名的检测。而每种检测方法又根据具体的检测方式再细分为静态、动态和混合态三类。但这几类传统检测方式都存在严重局限性，如检测准确性低、占用大量计算机性能等。
今天，斗象科技正式推出摒弃规则驱动的沙箱检测模式，结合机器学习与高级统计分析，多模型融合方式，精准识别网络中潜在恶意文件的全新产品——MAC 恶意软件智能分析中心。


No.1

产品特性

多模型融合决策，有效降低误报

MAC以AI技术为核心，基于动静态多模型检测方法，结合多种监督学习，如模糊哈希技术、异常聚类技术、信誉估值技术等，融合决策方式对网络中的潜在恶意文件进行综合评估与检测，有效降低单一检测方式而造成的误报。

内置多个反病毒引擎，快速识别已知威胁

内置丰富反病毒引擎，对符合条件的文件以及该文件的操作进行病毒检测，同时将检测结果与威胁数据与多模型进行综合评估输出，为用户提供多维度的风险检测结果分析。

集成动态行为，满足不同场景下检测需求

内置的沙箱能够模拟 Windows 7 和 Linux 等常见操作系统，并根据文件类型自动选择合适的运行环境，同时支持多目标批量检测，检测结果实时输出。

独立产品形态，可灵活对接PRS-NTA分析系统

MAC为独立的产品形态，支持独立运行，同时内置丰富的系统配置选项，可灵活对接第三方或PRS-NTA分析系统。

自研高效检测引擎，满足多种形态的文件分析

自研高效的检测引擎，可根据检测目标信息分配检测资源，支持 PE 可执行文件(EXE、DLL、CO等)，Office 文档(DOC、XLS、PPT等)，PDF，HTML，Script，MSI，SWF，JAR，LNK ，ELF，各种压缩包(ZIP、RAR、7Z等) 等多种检测对象。

灵活配置，提供完善文件管理能力

MAC也可与PRS分析系统NTA进行合并使用，同时支持集群化部署与运行，提供细粒度的检测与存储配置，满足用户对文件信息的多元化管理需求。

详细的分析报告

您可以通过直观的 Web 界面查看沙箱综合分析报告，也可以通过 API 获取到详细的检测结果和凭证。

3、办公网络文件传输安全检测：配合PRS-NTA解析网络中的文件传输协议，提取文件进行安全检测，支持如：HTTP, SMTP，FTP，SMB，WebMail等
