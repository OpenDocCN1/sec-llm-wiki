引言：企业信息安全建设是个持续投入的过程，不仅需要知道“我”有什么、“我”没有什么，且需要持续关注正在发生的什么与“我”有关.威胁情报(Threat Intelligence）、态势感知(Situation Awareness)等，都是持续关注并搜集与“我”有关的正在发生的事情.CVE(通用漏洞披露)基本涵盖了企业信息系统基础设施相关的所有安全漏洞，监控CVE可以算作威胁情报中的应用安全情报收集.

本文分享使用python脚本实时监控推特(Twitter)账号@CVEnew的CVE披露的方方面面.

一    CVE 数据源

对于CVE数据的拉取来源，主要有如下两种方式，第一种是监控账号@CVEnew的推文(Tweets)，另一种是文件(JSON, XML各种格式)使用以下网址进行下载

https://nvd.nist.gov/vuln/data-feeds

感兴趣可参见如下网站：

https://cve.mitre.org/cve/data_feeds.html.


由于监控账号@CVEnew相对于文件下载方式更加实时，所以本文选取监控@CVEnew账号（后续还可在此基础上监控其他Twitter大佬的账号，获取更多的情报）

二    编写python脚本获取数据

2.1    申请Twitter开发者权限

Twitter 给开发者提供了接口用于获取 Twitter 数据，前提是申请到开发者账号（由于Facebook开发者泄露用户数据给政府等事件，导致Twitter收紧开发者策略，不久以后申请开发者权限需要审核）.

首先你需要有一个 Twitter 账号（可能首先还需要学会fan墙），随后打开网页https://apps.twitter.com/app/申请一个app，(目前申请app还很容易)，进而拿到CONSUMER_KEY和ACCESS_KEY用于调用Twitter API.

2.2    学习API文档

要调用API获取数据，首先调用 oauth 传入 ACCESS_KEY 等进行授权，然后才能调用数据接口

Twitter提供两种接口：一种是常规API可pull数据，另一种是流式(streaming)接口，使用长连接实时推送数据

详细文档需要者可参考如下网址：

https://developer.twitter.com/en/docs/tweets/filter-realtime/overview

2.3    借助tweepy包，调用推特API

tweepy 将Twitter API 的请求连接维护、响应数据解析进行包装，方便调用. 可直接 pip install tweepy 进行安装，为了防止不兼容问题，这里使用virtualenv虚拟环境,步骤如下所示：

①pip install virtualenv安装virtualenv虚拟环境

② virtualenv monitor_cve 生成一个全新的 python 环境，接下来便可切换目录 cd monitor_cve，执行命令 source bin/activate，激活当前环境（deactivate退出当前环境，之后 python 及 pip 的所有操作都在这个目录下发生）.

③安装相关包pip install tweepy，pip install requests.

④编码

》程序写得比较简陋：启动两个子线程，一个用于获取实时数据，一个用于将数据发送到邮件，用队列保存数据


》为了避免干扰，实时数据缓存一定时间后才会发送邮件（或者数据存库后，每天定时发送邮件）（上面这种写法存在程序强退后，子线程仍在运行）

如果没有队列中没有数据，send子线程暂停半小时；队列中有数据暂停5分钟后将所有数据发送到邮件（@CVEnew的推文是伪实时的，隔段时间会发送N个推文）


》小编建议对于一些仅仅想要接收 CVEnew(uid=821806287461740544) 相关推文，可直接使用如下所采用方法

twitterStream.filter(follow=[‘821806287461740544’])，

(其中track=[‘python’],表示只接收含有python的推文)



on_status 函数获取实时数据，返回了关于 @CVEnew 相关的推文（转发、艾特等），from_creator用于过滤主动发出的推文



以上代码就可以接收到基本实时的CVE披露邮件

三    开启监控

3.1    由于通过代理fan墙才可访问Twitter，python脚本需要设置代理访问

目前pip方式安装的tweepy中的streaming接口不支持proxies，需手动修改代码

参照下图，修改给出的如下文件

monitor_cve/lib/python2.7/site-packages/tweepy/streaming.py


3.2    安装shadowsocks CentOS客户端给tweepy提供代理：

pip install shadowsocks

新建 ss.json 配置文件，格式如下

{
“server”:”35.231.1.1″,
“server_port”:8388,
“local_address”: “127.0.0.1”,
“local_port”:10800,
“password”:”xx”,
“timeout”:300,
“method”:”aes-256-cfb”,
“workers”: 1
}

启动客户端 sslocal -c ss.json -d start // 后台进程方式启动

tweepy 中设置 requests socks5 将代理 twitterStream = Stream(auth, listener, proxies = {‘http’: ‘socks5://localhost:10800’, ‘https’: ‘socks5://localhost:10800’})

pip 安装的 tweepy，修改代码后，使用socks5代理会出现错误可安装privoxy将socks5代理转http代理 （yum install privoxy,  vi /etc/privoxy/config,  forward-socks5 / 127.0.0.1:10800 . , service privoxy start）

（从github上下载源码不需要修改代码且支持socks5代理的，git clone git://github.com/tweepy/tweepy.git && cd tweepy && python setup.py install）

3.3    运行monitor_cve.py脚本，开启监控

借助screen(yum -y install screen)让python脚本后台方式运行：

screen-L python monitor_cve.py
