# **Wordpress <= 4.9.6 任意文件删除漏洞**

        WordPress是如今使用最为广泛的一套内容管理系统。根据 w3tech 统计，全世界大概有30%的网站运行着WordPress程序。

       近期RIPS团队公开了一个Wordpress的任意文件删除漏洞（需要登录），目前该漏洞仍然未修复（2018年06月27日），该漏洞影响 Wordpress 最新版 4.9.6。

## **一 漏洞分析**

## 1 .文件 **/wp-includes/post.php** 中：

## ![](../Images/928cbe8ca865c8e2906be8aa068bfc55.png)

`$meta['thumb']`来自与数据库，是图片的属性之一。代码未检查 `$meta['thumb']` 的内容，直接带入 `unlink` 函数，如果 `$meta['thumb']` 可控则可导致文件删除。

  

2.文件 **/wp-admin/post.php** 中：

  

![](../Images/0b7555b97eaa0feee4eef7874332b6f5.png)

  

`$newmeta['thumb']`来自于 \$_POST[‘thumb’] ，未经过滤直接将其存入数据库，即上一步的 `$meta['thumb']`可控。

具体分析可见：

WARNING: WordPress File Delete to Code Execution          https://blog.ripstech.com/2018/wordpress-file-delete-to-code-execution/
