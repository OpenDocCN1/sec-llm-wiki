# 科创板新股申购专题——市场化机制日趋完善，优质标的稀缺性逐步显现【方正新兴产业】

**核心观点**

  

  

**科创板的发行节奏进入常态化，增量供给将持续。**自10月份以来，科创板的新股发行节奏进入新常态，板块持续发行新股、供给总量快速提升，根据申报企业的受理情况，预计板块将继续维持当前的发行节奏。

  

**新股“破发”体现市场更趋理性，利好中长期健康发展。**科创板新股上市后，普遍向理性价值区间快速回归，10月份以来新股上市首日的平均涨幅大幅收窄、个股表现分化仍显著，上市后价格普遍较发行价回落。截至11月26日，科创板已有8只新股陆续出现破发，新股“破发”体现出市场交易更趋理性客观，中长期有利于市场的平稳健康发展。

  

**科创板新股发行平均溢价率77.8%，发行估值溢价仍显著。**目前已发行的64只新股平均发行市盈率近60倍，发行PE较所属行业平均溢价77.8%，85.9%的科创板新股发行PE高于所属行业，科创板新股的发行估值溢价仍较高。

  

**市场化定价机制发挥效力，推动新股合理定价。**伴随近期科创板新股供给预期提升、首日涨幅收窄、板块个股破发等现象，市场化定价机制的约束力逐步显现。11月19日祥生医疗公告发行定价低于投价报告的建议价格区间，反应网下机构判断逐步出现分化、报价更趋靠拢个股价值，新股发行询价的市场化程度提升，市场化询价机制改革逐步显效，未来新股发行估值将更趋合理。

  

**优质标的稀缺性逐步显现，新股申购向价值靠拢。**科创板未来供给预计将持续稳增，年内板块上市个股数量有望达到70-80个，年内总募资规模有望超过900亿元，预计年内A类科创板打新收益合计约达3000万元(除中国通号)。**近期新股上市表现趋弱、个股分化仍显著，进一步凸显优质标的稀缺性，建议短期在新股发行估值仍较高的情况下，选择科技含量较高的优质标的参与新股申购。**

  

  

**风险提示**

  

科创板新股首日涨幅不及预期；个股表现分化加剧；股价发生大幅波动；相关法律法规调整。

  

1    

**科创板新股上市表现趋稳，高成长性个股更受关注**

**科创板申报企业受理进入常态化，申报企业集中三大科创主题。**截至2019年11月26日，科创板发审委已受理179家申报企业，其中66家已发行、9家已通过发审委审核、22家进入证监会注册环节、9家暂停注册程序、23家撤回材料或注册失败。企业的申报数量在7月26日科创板开市后锐减，9月份以来，随着发审委审议会的召开常态化，申报企业数量回升，9-10月每月新增受理企业数量8-11家。申报企业的科创属性仍集中在信息技术、高端制造、医药生物，三大主题合计占总申报量的比例逾八成。在地区分布方面，北京、江苏、上海、广东、浙江的企业合计125家，占总申报量近70%。

2    **新股首日涨幅收窄，市场交易日趋理性**

  

**2.1  科创板发行常态化，新股供应有望持续**

  

**科创板新股发行节奏进入新常态，新股供给总量快速提升。**随着申报企业受理节奏加快，科创板新股的发行节奏也进入新常态，新股数量快速提升，截至11月26日，已有66只新股陆续进入发行程序，其中10月份发行22只新股、11月发行10只。自7月26日首批25只科创板新股集中挂牌后，10月上市7只新股，11月至今已上市16只新股。

**2.2  新股发行估值溢价仍显著，平均溢价率达77.8%**  
  

**科创板已公告的64只新股平均发行市盈率近60倍，平均溢价率77.8%。**截至11月26日，已公告的64只新股平均发行市盈率为59.17倍，其中，微芯生物发行PE 468倍、中微公司发行PE 171倍，为目前最高，除微芯生物外，63只新股的平均发行PE为52.69倍。科创板新股发行PE较所属行业平均溢价77.76%（除微芯生物，63家新股发行PE平均溢价56.48%）。**85.9%的科创板新股发行PE高于所属行业，科创板新股的发行估值溢价仍显著。**

  

![](../Images/74d1b56b7d9b79075df8d4055fd5445e.png)

  

**2.3  11月至今首日平均涨幅下降至62%，个股估值快速向理性价值区间回归**

**稀缺性溢价下降，首日涨幅进一步收窄。**截至11月26日，已上市的56只新股首日开盘价平均涨幅127.0%，首日收盘价平均涨幅125.4%、首日均价平均涨幅115.3%。10、11月上市的个股数量分别为7只、16只，首日平均开盘涨幅113.1%、62.2%。其中，11月上市的卓越新能的首日开盘涨幅仅为9.48%、久日新材的首日收盘涨幅6.42%，创板块新股的首日开盘、收盘涨幅新低。新股的首日换手率则持续稳定高位，平均为75.85%。新股的首日振幅显著收窄，显示市场交易日趋平稳。**10月以来，伴随科创板新股供给节奏加快、总量提升，新股稀缺性溢价下降，上市后首日涨幅大幅下滑，个股表现分化仍显著。**

3    **网下机构新股报价分化，市场化定价机制显效**

**新股定价首次低于投价报告价格区间，市场化定价机制逐步发挥效力。**伴随近期科创板供给预期提升、新股首日涨幅收窄、板块个股破发等现象，市场化定价机制的约束力逐步显现。11月19日，祥生医疗公告发行定价为50.53元/股，较投价报告的建议价格区间（50.57-55.62元）下限低0.04元。**近期，以主承销商的投价报告为参考的新股入围价格分位逐步下移、入围价格的范围扩大，在新股上市后普遍表现较弱、股价出现破发的影响下，网下机构参与新股报价更加靠拢个股价值，投资判断逐步出现分化、报价集中度下降，机构的报价更加独立、审慎、理性，新股发行询价的市场化程度提升，市场化定价机制改革逐步显效。**

4    **科创板****网下账户数量保持平稳，年内打新收益规模约3000万元**  
**4.1  10月至今网下账户数量稳定，网下中签率有望保持0.15%-0.20%区间**  

**网下询价账户数量整体保持稳定，近期参与询价账户数平均约为4300个。**10月以来，网下询价的账户数量整体保持平稳，10月、11月参与询价的账户数平均分别达4317、4264个。其中，联瑞新材的网下参与询价账户数量最高，达4697个；卓越新能参与账户数量最少，仅为3313个。10月至今，入围账户数量平均为3695个，其中获配的六类账户（A+B类）平均为2418个、C类账户平均1145个。**进入11月，网下参与询价的平均账户数量略有下降，但整体市场参与热情仍较高，个别新股的参与账户数量显著减少，反应部分机构开始有选择性的参与新股申购。****随着新股首日涨幅收窄、上市表现分化、打新风险增加，未来机构参与科创板新股网下询价将更加结合企业的盈利能力、市场空间、科技含量等价值因素。**

**科创板新股网下发行占比约六成，10月以来网下六类账户获配比例下降。**截止目前，板块已发行新股的网上、网下平均发行比例分别为32.6%、59.5%，战略配售发行比例平均为7.9%，发行比例整体保持稳定。目前，只有澜起科技、中国通号、金山办公三家向除保荐券商及公司高管之外的其他战略投资者配售发行新股。截至11月26日，六类账户的网下获配比例平均为77.2%，C类平均获配比例22.8%。自10月以来，六类平均获配比例较之前的81%下滑至72%，C类平均获配比例则由19%提升至28%，主要原因为10月至今的C类获配账户数量较之前出现大幅台阶式增长。10月至今C类获配账户数量平均达到1145个，较6-9月的平均数量增长143.6%，六类获配账户的平均数量达到2418个，较之前增长66.8%，C类获配账户数量的增加一方面来自新增账户，一方面为C类账户的报价准确性提升。

**10月以来网下中签率较之前有所下滑，预计科创板网下中签率将维持在0.15%-0.2%区间。**10月至今发行的科创板新股平均网下综合中签率0.2048%，A类（公募、养老金、社保、年金、保险）平均中签率0.2169%，B类（QFII）平均中签率为0.2096%，C类（其他）平均中签率为0.1779%。其中，金山办公由于新股发行总量较高、网下申购上限较低，网下综合中签率达到0.9262%，A类中签率1.0471%，为目前科创板网下中签率最高。除金山办公，10月至今发行的新股平均网下中签率0.1720%，较7-9月发行的新股0.2960%的网下平均中签率下降0.1240 pcts；A/B/C类平均中签率分别为0.1791% / 0.1737% / 0.1585%，较7-9月发行新股的三类网下平均中签率（0.3069% / 0.2907% / 0.2585%）分别下降0.1277 / 0.1170 / 0.1000 pcts。尽管10月以来新股的中签率有所下降，但近期网下参与的账户数量保持平稳，预计未来网下中签率将维持在0.15%-0.20%区间。

**4.2  科创板新股首日涨幅大幅收窄，A类1.5亿产品打新收益率达15.2%**

  

**10-11月A类单只新股平均首日收益规模约15万元。**截至11月26日，科创板56只已上市新股的首日开盘/收盘平均涨幅为127.0% / 125.4%，开盘/收盘价对应A类账户顶格申购的打新收益合计为3363 / 3315万元（除中国通号为2462 / 2327万元），A类的平均单只新股收益规模达60.05 / 59.20万元（除中国通号为44.76 / 42.30万元）。10-11月新股发行数量回升但首日涨幅下滑显著，10月、11月A类的平均单只新股首日开盘收益分别为15.73 / 14.47万元，首日收盘收益分别为17.06万元/14.02万元，较7-9月单只收益规模显著收窄。  

![](../Images/5439bdd50fafedad2e83315ef357f39a.png)

![](../Images/9785ed349801934ef6a4f90bbf61c4ab.png)

  

科创板新股的发行进入常态化，未来供给将持续稳增，我们**预计****年内板块上市个股数量有望达到70-80个。**除中国通号，科创板新股的平均单只募资规模为10.98亿元，**年内板块总募资规模有望超过900亿元。**除中国通号，三类投资者顶格申购的单签规模分别为32.2、30.5、27.6万元。目前，科创板新股首日涨幅收窄，以首日平均涨幅125%测算，**除中国通号，年内三类投资者顶格申购的科创板打新收益规模预计约达：**

**A类：****32.2万元\*75只\*125%=3018.8万元**

**B类：****30.5万元\*75只\*125%=2859.4万元**

**C类：****27.6万元\*75只\*125%=2587.5万元**

![](../Images/2c76005c655b495786bedd9c2a193c4c.png)

截至11月26日，以新股首日开盘涨幅计，**A类投资者1.5亿元、2亿元、2.5亿元、5亿元规模产品对应的科创板打新收益率分别达到15.21%、12.61%、10.09%、5.04%。**伴随科创板供给增加、发行进入新常态，目前个股发行PE溢价仍较高，但新股稀缺性溢价下降、首日涨幅收窄，以及个股表现分化均提升打新风险。**未来随着询价市场化程度进一步提升，新股发行估值有望更趋合理。****随着近期新股上市表现趋弱、个股分化仍显著，优质标的稀缺性逐渐凸显，建议短期在新股发行估值仍较高的情况下，选择优质新股标的参与申购。**
