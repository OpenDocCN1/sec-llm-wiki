用stream-nginx做DNS与转发劫持代理


    一直以来nginx作为http-server被大家熟悉，其实nginx还有一个stream-nginx部件，最近我们有一个“内翻”的需求，需要用到dns代理和劫持的功能，dns服务，智能dns服务有不少方案，而stream-nginx就可以作为一个开源的dns server方案。这个方案的特点是，开源了整套服务的所有代码:nginx,c,lua全部都有。


Part

1

安装maxmind依赖

```

git clone https://github.com/maxmind/libmaxminddb.git

 

make

make check

sudo make install

sudo ldconfig

```


Part

2

安装nginx


```

export LUAJIT_LIB=/usr/local/openresty/luajit/lib

 

export LUAJIT_INC=/usr/local/openresty/luajit/include/luajit-2.1

 

 

```


Part

3

安装dns-server扩展模块


```lua

/configure —prefix=/opt/nginx \

        --with-ld-opt="-Wl,-rpath,/usr/local/openresty/luajit/lib" \

        --with-stream \

        --with-stream_ssl_module \

        —add-module=/stream-lua-nginx-module-bloody-dns-server

       

make

sudo make install

```


Part

4

部署dns-server服务


```

worker_processes  1;

daemon on;

master_process on;

error_log logs/error.log warn;

pid       logs/nginx.pid;

 

stream {

    lua_package_path '$prefix/lualib/?.lua;;';

 

    init_by_lua_block {

        jit.opt.start("minstitch=2")

    }

 

    server {

        listen 1235 udp;

 

        content_by_lua_block {

            require "dns_server".go()

        }

    }

}

 

events {

    accept_mutex off;

    worker_connections  1024;

}

```


Part

5

启动服务


nginx -c nginx.conf


Part

6

总结


服务启动后，具体的需求暗可以直接在lua中实现了，之后我们介绍一些更具体的应用场景。
