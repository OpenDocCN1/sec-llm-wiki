  前两天拿到了一个IP列表，几万个IP吧，然后拿到了一份各个机房的地址段列表，要把IP按照各个机房给分开，我想着也不是啥难事儿啊，取了IP列表，取了地址段列表，找个模块函数是否属于该网段，循环对比，完事儿了，写个小脚本就OK了。

  我选择了常用的IPy模块作为ip处理模块，该模块的IP类用法，IP(’192.168.1.1/24’)，IP(’10.0.0.1’)，使用也简单，判断一个IP是否在一个网段里：

‘192.168.1.100’ in IP(‘192.168.1.1/24’)

返回True则属于该网段，False则不属于该网段。

  很快我就把脚本写完了，没想到运行的时候出了问题，主要是因为遇到了这样一个网段：*.*.*.192/25。

  下面啰嗦一下基础知识，各位可以跳过，根据子网掩码位数，该网段总地址数是128个，子网掩码为255.255.255.128，第一个IP是*.*.*.128，最后一个可用的是*.*.*.255。

这样的一个网段，我开始也纳闷儿，以为是写错了，觉应该是*.*.*.192/26吧，结果根本没有写错，彪哥告诉我现在的IP都使用CIDR表示法，子网掩码位数之前的IP不一定非得是首个IP。但这样的一个网段IPy模块下的IP类竟然不识别，报的错误是IP数超出了网段本身，然后就猜到估计IP类计算IP数字的方法是默认将表示法中的IP作为首个IP来计算的，他只计算了192到255的IP数量，一共64个，但根据子网掩码位数算出来该子网应该有128个IP，然后就GG了。

  这就没办法了，换模块吧，翻到了ipaddr模块，谷歌在2014年2月份做的，安装方法不再赘述，搜了一下，发现国内把使用方法翻译成中文作为使用指导的文章非常少，导致像我这样的万年伸手党也只能去翻英文的API Documentation（http://pythonhosted.org/ipaddr/）。下面是自己搞的使用介绍，有不对的地方希望各位多多原谅并帮助我改正。

类：BaseIP、IPv4、IPv6

使用实例：

创建一个网段的对象：

ips = ipaddr.IPNetwork(“192.168.1.1/24”) 或ips = ipaddr.IPv4Network(‘192.168.1.1/24’)

创建一个IP地址的对象：

ip = ipaddr.IPAddress(“192.168.1.2”) 或ips = ipaddr.IPv4Address(‘192.168.1.2’)

查看网段地址的掩码： ips.hostmask

查看网段的广播地址：ips.broadcast

查看网段的IP数：ips.numhosts

IP是否在网段内：

Bool = ips.Contains(ip)

从一个大网段中清除一个小网段,返回结果是一个列表：

ips1 = ipaddr.IPNetwork(“192.168.1.1/24”)

ips2 = ipaddr.IPNetwork(“192.168.1.1/26”)

ips1.AddressExclude(ips2)


获取网段对象的每个IP：

for ip in ips:

print ip

  比较两个网段的大小：

a = ips1.CompareNetworks(ips2)

ips1 < ips2    a = 1

ips1 = ips2    a = 0

ips1 > ips2    a = -1

  大致的用法差不多就这些了，IPv4类继承了BaseIP类，自己多了一些特殊使用的方法，大家使用的时候可以自行看一下。
