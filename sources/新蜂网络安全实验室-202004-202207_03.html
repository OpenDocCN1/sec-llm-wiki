一、了解mongodb的条件查询

首先举例说明mongodb进行条件查询的方法：
//启动mongod服务
systemctl start mongod

//启动客户端
mongo

//指定数据库
use test_DB

//向集合中插入三个文档
db.col.insert({
    title: 'mongodb教程',
    description: 'mongodb是一种nosql数据库',
    by: '彭瑞',
    likes: 200
})
 
db.col.insert({
    title: 'Java教程',
    description: 'Java是Sun公司于1995年5月推出的高级程序设计语言。',
    by: '彭瑞',
    likes: 150
})
 
db.col.insert({
    title: 'PHP教程',
    description: 'PHP是一种创建动态交互性站点的强有力的服务器端脚本语言。',
    by: '彭瑞',
    likes: 100
})

//查看集合和文档
show collections
db.col.find()
可以看到前面插入的三个文档。

//下面是条件查询。获取"col"集合中"likes"大于100的记录：
db.col.find({likes : {$gt : 100}})
 
//获取"col"集合中"likes"大于100并且小于200的记录：
db.col.find({likes : {$lt :200, $gt : 100}})
 

二、php文件中用于数据库连接和查询的代码

//连接到mongodb数据库
$m = new MongoClient();
//选择数据库
$db = $m->test;
//选择集合
$collection = $db->users;
//获取用户通过表单提交的账号和口令
$data = array(
'username' =>  $_REQUEST['username'],
'password' =>  $_REQUEST['password']
);
//在集合中根据账号和口令进行查找
$cursor = $collection->find($data);
$string = json_encode($data);
echo $string;
可以看到，代码中没有对用户提交的账号和口令进行过滤。

若用户提交的账户/口令是user1/password，那么提交给mongodb数据库引擎的数组为：
$data = array(
'username' => "user1",
'password' => "password"
);
 
在mongodb中执行的代码为：
db.users.find{
{
"username":"user1",
"password":"password"
}
}
 

三、nosql注入

由于对用户输入没有做任何校验，那么可以通过构造一个永真的条件进行NoSQL注入。

构造下面的payload：

username[$ne]=1&password[$ne]=1

对于PHP本身的特性而言，由于其松散的数组特性，如果我们提交var=1，那么意味着变量名为var，值为1。如果提交var[$ne]=1，就意味着var=array("$ne=>1")，var成了一个关联数组，该数组中有一个元素，名为$ne，元素的值为1。于是，php提交给mongodb的数组变为：
$data = array(
'username' => array("[$ne]=>1"),
'password' => array("[$ne]=>1")
);
而在mongodb中执行的代码变为：
db.users.find{
{
"username":{$ne:1},
"password":{$ne:1}
}
}
{$ne:1}代表一个数组，但是这种形式会被mongodb理解为条件查询。这样，针对一个单个目标的查询就变成了条件查询。在集合中找到一个username字段不为1并且password字段也不为1的文档，这个条件是满足的，所以查找一定是有结果的。这样攻击者可绕过身份验证，直接登录。
