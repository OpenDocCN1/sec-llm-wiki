# 一、**操作目的和应用场景**

本文介绍Linux系统中进行文件传输的方法，主要用于后渗透过程中。在本文的每个例子中，标题中的命令都是在Linux服务器上执行的。 

# 二、**平台及工具版本**

Linux服务器：CentOS 7，192.168.43.234（部分CentOS 7系统无法实现的，在Kali Linux系统中实现）远程主机1：Linux Mint 20，192.168.43.237远程主机2：windows xp，192.168.43.87
