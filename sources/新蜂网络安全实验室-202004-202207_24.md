# 一、**操作目的和应用场景**

## （一）**目的**

debian 10.8.0系统部署使用t-pot 20.06蜜罐平台，用于研究常见的开源蜜罐程序。 

## （二）**简介**

T-Pot是基于Linux平台的网络安装程序。20.06版本T-pot中的蜜罐程序全部以docker方式部署，这样我们可将网络接口上捕获的流量路由到匹配容器中的蜜罐程序，并将蜜罐程序限制在它自己的环境中，不会相互影响。T-Pot中主要包含下面的蜜罐程序：  

| 蜜罐程序 || 说明 |
| --- | --- |
| ADBHoney || 基于TCP/IP的Android调试桥的低交互蜜罐 |
| ciscoasa || Cisco ASA防火墙的低交互蜜罐，能够检测CVE-2018-0101、DoS和远程代码执行漏洞 |
| citrixhoneypot || 检测和记录CVE-2019-19781(Citrix ADC的RCE)扫描和攻击尝试 |
| conpot || 低交互式的工业控制系统的蜜罐 |
| cowrie || 中等交互式的SSH / Telnet蜜罐 |
| dicompot || 医学数字成像与通信(DICOM)蜜罐 |
| dionaea || 基于Python开发的低交互蜜罐，设计目的是诱捕恶意攻击，获取恶意攻击会话与恶意代码程序样本 |
| elasticpot || Elasticsearch 蜜罐 |
| glutton || 低交互蜜罐 |
| heralding || 可收集凭证的蜜罐 |
| honeypy || 低交互的蜜罐，但是具有更多的中等交互蜜罐的能力 |
| honeysap || 专用于SAP服务的低交互搜索蜜罐 |
| honeytrap || 低交互蜜罐，用来观察对TCP或UDP服务的攻击 |
| ipphoney || 互联网打印协议蜜罐 |
| mailoney || SMTP蜜罐 |
| medpot || SMTP蜜罐 |
| tanner || 是Glastopf（Python语言开发的Web蜜罐，能提供各种基于漏洞类型的模拟) 的后继 |

  

# 二、**操作步骤**

## （一）**安装****debian 10.8.0虚拟机**

ISO镜像文件下载地址：https://chuangtzu.ftp.acc.umu.se/debian-cd/current/amd64/iso-cd/debian-10.8.0-amd64-xfce-CD-1.iso虚拟机配置，内存：8GB，CPU：4核。 

## （二）**在****debian虚拟机中安装****T****\-pot**

## 1、 **使用国内安装源**

### 

sudo vi /etc/apt/source.list  //加入下面的内容deb http://mirrors.163.com/debian/ buster main non-free contribdeb http://mirrors.163.com/debian/ buster-updates main non-free contribdeb http://mirrors.163.com/debian/ buster-backports main non-free contribdeb http://mirrors.163.com/debian-security/ buster/updates main non-free contrib deb-src http://mirrors.163.com/debian/ buster main non-free contribdeb-src http://mirrors.163.com/debian/ buster-updates main non-free contribdeb-src http://mirrors.163.com/debian/ buster-backports main non-free contribdeb-src http://mirrors.163.com/debian-security/ buster/updates main non-free contrib保存退出  
2、 **安装需要的软件**

### 

sudo apt install net-tools git docker docker-compose  
3、 **网卡设置混杂模式**

### 

sudo ifconfig ens33 promisc  
4、 **将普通用户添加到****docker**

### 

sudo usermod -aG docker tsecsudo systemctl restart docker  
5、 **将项目克隆到本地**

### 

git clone https://github.com/telekom-security/tpotce  
6、 **开始安装****T-Pot**

### 

cd tpotce/iso/installer/sudo ./install.sh --type=user T-Pot版本选择STANDARD![](../Images/3dd6c7fa4d93cf31c93e72b650f56b20.png) 设置web用户名：webuser1![](../Images/528c9ddd5663e320a30e0cc5ef97b6fa.png)  
设置web用户密码：123456![](../Images/e88c600db4fd070f8796db50e3978727.png)  
安装完成后系统会自动重启。  
7、 **T-P****ot****ssh**

### 

安装程序会自动修改ssh server的端口号，本例中改为64295。![](../Images/e697d0ea83311a16db66585da4b193bc.png)   
ssh -p 64295 user1@192.168.242.183  //重新连接虚拟机时要指定端口号 

## （三）**使用****T-P****ot****蜜罐**

## 1、 登录**web界面**

### 

http://192.168.242.183:64297/  
![](../Images/fcd84d749fcf77b58af2e866e68b6297.png) 输入前面指定的用户名和密码：webuser1/123456![](../Images/ed2270fa26cd972f6d4539662590d4f5.png)  
可以看到，有Cockpit、Cyberchef、Elasticsearch Head、Kibana、SecurityMeter、Spiderhead等多个模块。  
2、 **Cockpit**

### 

点击Cockpit，输入操作系统账户和口令后登录。Cockpit是一个轻量级的web图形操作界面，让用户在Web浏览器中查看服务器，然后用鼠标执行系统任务。包括启动容器，管理存储，配置网络和检查日志等。![](../Images/d0c0ab06b3696b51375a46fa8c50ad50.png) 系统标签页，查看虚拟机系统运行情况![](../Images/377d835b82b372bbcfe08e29142a4244.png)  
容器标签页，查看蜜罐容器的运行状况：![](../Images/04f0ded3d154ee6a5eb8bd2e3d60839c.png)   
除了已经安装和运行的容器，还可以下载新镜像：![](../Images/d8b992e7cd0ade440dc149c9b81f380d.png)  
终端标签页，进入root，运行脚本dps.sh，查看T-Pot组件运行情况![](../Images/d3aa17505becc15391c416f6fd09c7b6.png)  
3、 **Cyberchef**

### 

CyberChef是一个用于加密、编码、数据分析的开源web应用。![](../Images/95db95c71e321581dfbb4cde77fff83e.png)将左侧的模块拖动到Recipe区域，在input框中输入要转换的内容，在output中可得到转换后的结果。  
  
4、 **Elasticsearch Head**

### 

Elasticsearch Head是一个插件，用于查看Elasticsearch的运行状态、进行rest请求模拟，以及检索数据。  
![](../Images/c297fe245e9f8fdcf5c578ea4a82229f.png)   
5、 **Kibana**

### 

Kibana是用于Elasticsearch的开源数据可视化仪表板。它在Elasticsearch集群上建立索引的内容之上提供可视化功能。用户可以在大量数据的基础上创建条形图，线形图和散布图，或者饼图和地图等。选择Kibana模块，进入Dashboard。列表列出了TPot所有包含的蜜罐服务，提供了总面板（T-Pot），以及各个蜜罐分别的监控面板。![](../Images/00d1a5fb06e705b42b9aa688d1d1e19a.png)  
进入T-Pot面板进行ssh/telnet暴力登录，nmap端口扫描等基本攻击，面板会更新所有捕捉到的攻击![](../Images/ecfce2a953b4d45c5485cce41f3053bc.png)   
并展示ssh/telnet登录用户密钥对，攻击IP等信息![](../Images/97c58435dd2c482b7af6e05f2d0255a5.png)  
所有运行的蜜罐程序都会在/data目录下生成与其名称相同的文件夹，用于存放各自监控所产生的日志记录。我们可尝试针对日志进行自动化分析，以更方便快捷地发现攻击行为并进行处理。
