# 一、**操作目的和应用场景**

Immunity Canvas使用bluekeep模块对windows 7 sp1进行攻击并通过监听器shell窗口部署后门程序。

 

# 二、**平台及工具版本**

| 虚拟机网络地址 || ubuntu 1804：192.168.242.176  windows 7：192.168.242.180 |
| --- | --- |
| 虚拟机中的软件 || ubuntu 1804：Immunity Canvas |

 

# 三、**操作步骤**

## （一）利用**windows 7的bluekeep RCE漏洞进行攻击**

cd /home/user1/Canvassudo python runcanvas.py  //启动canvas//要了解Canvas的安装和基本使用方法，请看本公众号发表的另一篇文章《ubuntu 1804系统安装使用Immunity Canvas软件》添加目标主机：192.168.242.180（windows 7 sp1，4G内存的虚拟机）![](../Images/24cb23315d65033084412ce04f1539de.png)  
搜索攻击模块：bluekeep![](../Images/0d46ba94e234788f0bb2aad30da0db4b.png)  
在搜索结果中双击bluekeep，在弹出的对话框中选中允许在目标主机上执行代码，并且指定目标主机的内存大小为4G。![](../Images/7a114b74db25c6d930a34881bc70cc3b.png)  
点击OK按钮开始攻击，在canvas log窗口可看到攻击执行的过程：![](../Images/b4746cfc8b71b1330056ec9091984571.png)  

## （二）在监听器**shell窗口进行操作**

## 1. 了解监听器**shell窗口**

### 

获得远程主机的控制权后，将自动弹出监听器shell窗口。鼠标放在监听器shell窗口工具栏的某个图标上，可查看该图标的含义。点击工具栏的“PWD”图标（对勾图标），查看当前所在的文件系统路径：![](../Images/ac69a59c9072574988c5c41dbd606c65.png) 在窗口上部的文本框输入要执行的命令，例如ipconfig，点击工具栏的“piped command”的图标（插头已插入图标），执行命令：![](../Images/6082917ff8ae6d8741c2981261090965.png)   
清空文本框，输入c:\\，点击“change directory”图标（磁盘图标），切换目录：![](../Images/8ed6068fae81f493984e2736f5767cd1.png)  
点击“Get Directory Listing”图标（文件夹图标），查看当前目录中的文件列表：![](../Images/a3e60f2559359b457e68d26a21b0565e.png)   
清空文本框，输入c:\\windows\\notepad.exe，点击“spawn a process”图标（齿轮图标），执行记事本程序。虽然记事本程序界面没有显示在屏幕上，但是在任务管理器中已经可以看到notepad.exe进程了。![](../Images/97a40acefcda6d80a59305d114de7083.png) 点击Browse按钮，选择要上传的文件，如/home/user1/examples.desktop。点击向上的箭头按钮，上传文件到目标主机的当前目录。再次点击磁盘图标，可以看到，文件已经上传成功了：![](../Images/b97783e0489991cb55d4553ff113b039.png)  
点击工具栏中的“open filesystem browser”图标（小房子图标），打开文件系统浏览器：![](../Images/8810242270a0ecdf048ce7d0c5cd7687.png)双击盘符，可展开查看目录的内容，在这里可进行文件的上传和下载操作。  
 2. **部署木马程序**

### 

既然canvas的监听shell窗口有这样的功能，我们可以上传木马程序并执行。  
(1) **制作木马程序**

#### 

Modules—Trojans，双击BuildCallbackTrojan，在弹出窗口中填写连接信息：![](../Images/c6f314349aa2fd47433d8afb81313589.png)点击OK按钮，将在Canvas目录中生成木马文件。![](../Images/afc8fba2dac9cf9ffbf8c9bfb2278258.png)  
(2) **上传木马文件**

#### 

在监听器shell窗口清空文本框，输入目标主机上的路径，如c:\\，点击工具栏的切换目录图标，切换当前路径为C盘根目录：![](../Images/3cc4517504265a28d3546ef80c51b6f7.png)  
在监听器shell窗口点击Browse，选择trojan.exe  
![](../Images/9f6e33a66e968556da157023f66ba687.png)完整路径为：/home/user1/Canvas/trojan.exe 点击工具栏的向上箭头图标，上传文件到目标主机的C:\\。之后查看当前目录中的文件：![](../Images/24c86d2fce11d358c0f9c4d6a371a9fa.png)可以看到trojan.exe，说明木马上传成功了。  
(3) **执行木马程序**

#### 

文本框输入c:\\trojan.exe，点击“piped command”，启动木马程序。之后弹出了新的监听器shell窗口，说明trojan.exe执行成功。在主界面的node tree窗口，可以看到除了安装了canvas的LocalNode之外，还有两台win64Node，分别是通过bluekeep漏洞和木马程序得到的：![](../Images/d843ee0f20ff31de4ef220a01eb06cd1.png)  
四、总结本文简单介绍了使用Canvas进行RCE攻击以及并部署后门程序的方法，希望对大家的工作有所帮助。
