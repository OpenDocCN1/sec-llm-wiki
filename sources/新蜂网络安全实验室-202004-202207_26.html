例如在ubuntu 1804虚拟机中安装以docker方式使用awvs。

//安装docker
apt update
apt install docker.io

//docker hub搜索镜像
docker search awvs
第一个是我们需要的，该镜像中awvs的版本为13，build日期为2020年10月。
 
//docker pull拉取镜像到本地
docker pull secfa/docker-awvs
 
//将宿主机的13443端口映射到Docker容器的3443端口
docker run -it -d -p 13443:3443 secfa/docker-awvs
 
//访问容器所在宿主机的IP地址
https://192.168.242.176:13443
 
//输入账号信息后登录
admin@admin.com/Admin123
 
//查看许可证：Administrator—配置文件
