//安装dockerapt updateapt install docker.io  
//docker hub搜索镜像docker search awvs![](../Images/0acb62f09c71798b243a4f08185b9022.png)第一个是我们需要的，该镜像中awvs的版本为13，build日期为2020年10月。  
 //docker pull拉取镜像到本地docker pull secfa/docker-awvs //将宿主机的13443端口映射到Docker容器的3443端口docker run -it -d -p 13443:3443 secfa/docker-awvs //访问容器所在宿主机的IP地址https://192.168.242.176:13443![](../Images/ba772545c2b2502239768398fdaee1b1.png) //输入账号信息后登录admin@admin.com/Admin123 //查看许可证：Administrator—配置文件![](../Images/10d31f721d458ad2d68f3c2512ed8c78.png)已经破解，无需自己动手。
