一、操作目的和应用场景

在ubuntu 1804系统中，安装和使用immunity canvas软件。
官方推荐在Linux系统中使用该软件。

一、操作步骤

（一）虚拟机中安装canvas

1、下载Immunity Canvas
将Immunity Canvas软件下载到虚拟机中的/home/user1目录，解压缩。

2、 安装canvas所依赖的软件

sudo apt-get update
sudo apt-get -y install python-pip
sudo apt-get -y install gtk2.0
sudo apt-get -y install python-glade2
sudo apt-get -y install python-nacl python-bcrypt
sudo pip install pycrypto
sudo pip install pyasn1
sudo pip install diskcache==4.1.0
sudo pip install asn1tools
sudo apt-get install -y python-pycurl
sudo apt-get install -y libcanberra-gtk-module
sudo pip install pycurl
sudo pip install requests
sudo pip install pygame==1.9.2
注意必须指定pygame的版本。

3、 在canvas中安装需要的软件

cd /home/user1/  //进入user1的home目录
mv Immunity\ Canvas\ 7.26/ Canvas  //重命名目录，不能有空格 
cd Canvas
bash ./installer/linux_installer.sh  //继续安装相关的python包

（二）使用canvas

1、 虚拟机开启X11转发

vi /etc/ssh/sshd_config  //修改下面的属性
X11Forwarding yes
X11DisplayOffset 10
X11UseLocalhost no
保存退出
systemctl restart ssh  //重启ssh服务

2、虚拟机内启动 canvas

ssh -X user1@192.168.242.172  //宿主机重新连接到虚拟机
sudo python Canvas/runcanvas.py  //启动canvas
宿主机中即可显示Canvas的界面：
 

canvas的界面可以分为三个区域，分别是：
红色：canvas可以做的事情
蓝色：canvas所知道的东西
黄色：canvas正在做的事情
