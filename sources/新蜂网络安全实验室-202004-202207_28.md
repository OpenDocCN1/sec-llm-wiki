# 一、**操作目的和应用场景**

在ubuntu 1804系统中，安装和使用immunity canvas软件。官方推荐在Linux系统中使用该软件。  

# 一、**操作步骤**

## （一）**虚拟机中安装****canvas**

1、下载Immunity Canvas将Immunity Canvas软件下载到虚拟机中的/home/user1目录，解压缩。  

## 2、 **安装****canvas****所依赖的软件**

### 

sudo apt-get updatesudo apt-get -y install python-pipsudo apt-get -y install gtk2.0sudo apt-get -y install python-glade2sudo apt-get -y install python-nacl python-bcryptsudo pip install pycryptosudo pip install pyasn1sudo pip install diskcache==4.1.0sudo pip install asn1toolssudo apt-get install -y python-pycurlsudo apt-get install -y libcanberra-gtk-modulesudo pip install pycurlsudo pip install requestssudo pip install pygame==1.9.2注意必须指定pygame的版本。  
3、 **在****canvas中安装需要的软件**

### 

cd /home/user1/  //进入user1的home目录mv Immunity\\ Canvas\\ 7.26/ Canvas  //重命名目录，不能有空格 cd Canvasbash ./installer/linux\_installer.sh  //继续安装相关的python包  

## （二）使用**canvas**

## 1、 **虚拟机开启****X11转发**

### 

vi /etc/ssh/sshd\_config  //修改下面的属性X11Forwarding yesX11DisplayOffset 10X11UseLocalhost no保存退出systemctl restart ssh  //重启ssh服务  
2、虚拟机内启动 **canvas**

### 

ssh \-X user1@192.168.242.172  //宿主机重新连接到虚拟机sudo python Canvas/runcanvas.py  //启动canvas宿主机中即可显示Canvas的界面：![](../Images/8bb5af9de3697f3db395fb545432c55f.png) 

### 

canvas的界面可以分为三个区域，分别是：红色：canvas可以做的事情蓝色：canvas所知道的东西黄色：canvas正在做的事情![](../Images/ca45bfc1955b564f2c75a559c76df96d.png)  
3、 **对目标主机发动直接攻击**(1) **指定目标主机地址**

#### 

点击“Target Host”，在弹出的窗口中输入目标主机的IP地址：![](../Images/c9ce1ecfd30d1f8c0390a161c9f00598.png)  
添加之后，目标主机地址出现在界面上方的Current Target框中。![](../Images/f0238e90657f36666d12a1fd3f3116ff.png)  
(2) **添加回连地址**

#### 

回连地址就是目标主机在shellcode执行后主动连接到的IP地址。蓝色区域Node Tree—Node Management，右键点击Local Node，在弹出的菜单中选择网卡，点击“Set as callback interface”。![](../Images/232b10658cd1d8991d657894d8163d17.png)  
(3) **探测远程主机类型**

#### 

Modules—Recon—osdetect，输入目标主机地址：![](../Images/34abacb923c7e4e85ed46e57aa10022f.png) 从探测结果中可以看到，目标主机是windows xp![](../Images/8690e699fefaba09058052ea5ca5a35d.png)  
(4) **扫描远程主机端口**

#### 

Modules—Recon—portscan![](../Images/74e2115f3915a41bdd1affe543583a70.png)目标主机打开了445端口。  
  
(5) 执行**EXP**

#### 

点击search，输入ms08\_067，点击GO按钮。双击返回结果中的模块名称，在弹出窗口中指定操作系统版本，可选择Autoversioning，自动检测操作系统版本：![](../Images/af2686a135ec2f7a1086b0fb3ca3736e.png)   
漏洞利用成功：![](../Images/57828b6eba260770e2f983c9f5415969.png)
