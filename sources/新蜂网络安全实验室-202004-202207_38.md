# 以docker容器的形式运行vuls

**一、操作目的和应用场景**

大家好，我是彭瑞。

对于系统管理员来说，每天的安全漏洞扫描以及软件更新任务是非常繁重的。为了避免生产环境没有及时进行安全更新，很多管理员不会选择使用安装管理器所提供的自动更新选项，而是选择进行手动更新．这样就会导致下列问题出现：

*   系统管理员不得不持续关注NVD（美国国家漏洞数据库）或类似数据库中更新的新漏洞；
    
*   如果服务器端安装了大量的软件，那么系统管理员也不可能监控所有这些软件；
    
*   通过分析来确定哪台服务器存在新的漏洞很费劲，分析一两台服务器也就罢了，分析太多累死人；
    

于是就有了Vuls这个工具。Vuls是一个针对Linux/FreeBSD系统的无代理漏洞扫描器，使用go语言编写。Vuls拥有以下几种特性：

*   一旦数据库中新增了跟自己系统相关的漏洞时，通知管理员；
    
*   服务器在受到漏洞影响时，通知管理员；
    
*   自动执行漏洞检测，以防止管理员忽略某些应用；
    
*   使用CRON或其他方法自动生成常规漏洞报告，以帮助管理员更好地管理漏洞；
    

有了Vuls之后，系统管理员的工作发生了下面的变化：

![](../Images/a9d752437ac48d86412f8602f3a05854.png)

  

如果选择在操作系统中手工安装Vuls和相关软件，那么过程会比较繁琐，还不一定能安装成功。除手工安装外，也可以通过容器技术将Vuls及相关的软件封装在镜像中，用户通过下载镜像、创建容器来使用Vuls。这样就无需安装软件了，非常方便。

下面我们通过容器技术，使用一种比Vuls官方推荐更简单的方法来实现Vuls的部署和使用，目的是初步了解Vuls的作用和用法。  

  

**二、平台及工具版本**

host系统：linux mint 19.3

软件：docker、vuls

虚拟机管理程序：virtualbox 6.1

虚拟机：CentOS 6（被检测的系统）

计算机硬件：小米笔记本电脑

  

**三、操作步骤**

（一）获取镜像

docker pull actanble/vuls  //下载vuls的docker镜像（非官方）

![](../Images/c84fad82a71de0223a6cacc42aa0689f.png)

  

**（二）运行镜像**

docker run -itd --name=vuls-server -w /root/ actanble/vuls bash  //运行镜像，生成容器，在容器中运行bash

\-i  //保持交互

\-t  //分配伪终端

\-d  //后台运行容器

\-w  //设置容器中的工作目录

![](../Images/f74163855504ea450fb54e500553adec.png)

  

docker ps  //查看运行中的容器，可以看到vuls容器正在运行

![](../Images/8ec5444cedf389af4b4187c23946d0df.png)

  

**（三）在镜像中进行配置**

docker attach vuls-server  //进入到容器的bash

  

ssh-keygen -t rsa  //在容器中生成证书

![](../Images/744553d576cbee08817af6e7a3367765.png)

  

ssh-copy-id -i /root/.ssh/id\_rsa.pub root@192.168.1.11  //将公钥复制到被检测的主机

![](../Images/c2e17379c5cf4003337dce1bf752ca83.png)

  

ssh root@192.168.1.11  //从容器中ssh到被检测主机（部署公钥后无需账户/口令验证）

yum -y install yum-\*  //在被检测主机上安装yum相关的软件，用于Vuls的深度测试

exit  //断开与被检测主机的连接，回到容器。注意：如果此时不小心输入了两次exit，就会退出容器，容器就会停止，需要使用docker start命令重新启动容器

docker start vuls-server  //如果容器停止了，再次启动容器

docker attach vuls-server  //重新进入docker容器

  

vi config.toml  //编辑扫描配置文件，设置被检测主机的信息以及扫描模式

\[servers.CentOS6\]

host = "192.168.1.11"

port = "22"

user = "root"

keyPath = "/root/.ssh/id\_rsa"

scanMode = \["fast"\]

指定了被检测主机的IP地址、ssh服务端口、登录用户名和密钥路径，选择了快速扫描模式。除了fast模式之外，还可以选择fast-root模式和deep模式，。

保存退出。

  

vuls configtest  //检查配置是否存在错误

![](../Images/2b929578072524668d51471cb701a52e.png)

没有报错，说明配置正确。

  

**（四）扫描漏洞**

1、扫描

vuls scan  //扫描目标主机漏洞

![](../Images/aabb9331aa99dcbf68a2658b48cb7123.png)

Vuls根据配置文件的被检测主机的信息进行扫描。由于选择了fast模式，扫描很快完成。

  

2、查看报告

vuls report  //查看报告

![](../Images/d197fd2eb0cd6f684cabff6c6c3c9415.png)

检测到漏洞2354个，其中高危漏洞410个，中危漏洞1469个，低危漏洞473个。

![](../Images/36af66a5ea033ebdcb07420b3f9197bd.png)

报告的EXPLOIT字段显示Y，代表可以在exploit-db中找到相应的exploit（漏洞利用程序）。

  

3、查看扫描结果中的漏洞信息

vuls tui  //字符界面查看扫描结果

![](../Images/3caa4a829be16c87fdcba599fb441755.png)

通过tab键来进行窗口的切换，通过方向键来翻页，可以查看每个漏洞的详情。

  

4、加固后的复测

yum upgrade  //被检测的主机更新全部软件，之后再扫描一遍漏洞进行对比

![](../Images/b2bcaab4b739781686f65b793da2a0b2.png)

reboot  //更新完成后重启服务器

vuls scan  //再次扫描

![](../Images/dab1c313696cf6d257530fe9747f14e3.png)

这次检测到927个漏洞，其中高危149个，中危443个，低危335个。更新软件之后整体漏洞数量减少了1427个。

  

**（五）管理容器**

docker stop vuls-server  //漏洞扫描完成后停止容器，回收系统资源

docker start vuls-server  //停止后再次运行容器

docker rm vuls-server  //删除容器，容器删除后不会影响镜像，使用前面运行镜像的命令还会创建新的容器

![](../Images/e37fcc060886b98639d72d97aa96d9ee.png)

docker rmi actanble/vuls  //确定不再使用Vuls，可删除镜像，回收磁盘空间
