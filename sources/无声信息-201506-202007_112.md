**国家互联网应急中心开通勒索病毒免费查询服务**

  

![](../Images/d5cbcf1d18e3e0ddc4e0b9c9bd55e19a.png)

  

从国家互联网应急中心获悉，为了有效控制WannaCry勒索病毒的传播感染，国家互联网应急中心近日开通了该病毒感染数据免费查询服务。2017年5月12日，WannaCry勒索病毒利用Windows SMB（“永恒之蓝”）漏洞在全球快速传播，造成全球计算机大范围感染。

  

（来源：cnbeta）

  

2

**几大 Git 平台仓库被劫，黑客欲勒索比特币**

  

  

![](../Images/d770e08bde2c9ae68207d73b6f355519.png)

  

数百名开发人员的 Git 仓库被黑客删除，取而代之的是赎金要求。攻击于5月3日开始，包括 GitHub、Bitbucket 和 GitLab在内的代码托管平台都受到了影响。 目前已知的情况是，黑客从受害者的 Git 仓库中删除了所有源代码和最近提交的 Repo，只留下了 0.1 比特币（约 ¥3850）的赎金票据。

  

（来源securityaffairs）

  

3

**黑客窃取美国和加拿大201家校园在线商店的数据**

  

![](../Images/416a97d0f2a3dee10e1b8777c82f1558.png)

  

趋势科技在周五发布的一份报告中称，位于美国和加拿大的201家校园网上商店发现恶意代码，这些商店为美国176所大学和21所加拿大大学提供服务。安全研究人员称之为Magecart攻击，黑客将恶意JavaScript代码植入在线商店的结账和支付页面以记录支付卡数据，然后将其上传到服务器，并在地下网络黑市上出售。

  

（来源：zdnet）

**Firefox火狐浏览器已推送“插件失效”证书修复补丁**

  

![](../Images/91acad1a26c61c642da764625a82cd52.png)

  

Mozilla现在宣布他们推出了一个修复程序，并表示：我们的团队已经确定并推出了针对Release、Beta和Nightly的所有Firefox浏览器桌面用户的修复程序。修复程序将在接下来的几个小时内自动应用于后台。不需要采取任何有效步骤来使插件再次起作用。

  

（来源：ithome）

**日本国防部门将首次持有用于反击的病毒软件**

  

![](../Images/18f895124f3a39dd7a0dea782a3bc7b3.png)

  

日本政府消息人士29日透露，作为遭到动摇日本国家安全的网络攻击时的反击措施，政府已基本决定将在防卫省编制和持有电脑病毒。这将是首次把干扰对方信息通信网络的病毒作为防卫装备持有，成为日本在互联网孕育而生的网络空间的新应对措施。2019年度内将完成编制工作。

  

(来源：securityaffairs）

  

  

6

**警方查封全球第二大暗网黑市**

  

![](../Images/181b8221116b950e535833a87c59e12d.png)

  

据外媒Techspot报道，近日警方已查封全球第二大暗网黑市。德国当局领导的这项努力导致三名嫌疑人被捕，这是近两年调查的结果。警方还没收了超过55万欧元现金以及多辆车、电脑，数据存储和“ 6位数的加密货币比特币和门罗币”。另外两名嫌疑人在美国被捕，被描述为“销售致幻毒品最多的供应商”。

  

（来源：bleepingcomputer）

**开发人员在移动版Chrome中发现被称为“盗梦空间栏”的网络钓鱼方法**

  

![](../Images/81fa18d5722ceb10e0c22339f56db169.png)

  

据外媒Neowin报道，网络钓鱼并不是一个关于网络安全的新话题，尽管经常会发现新的和创造性的方法来实施这种做法。其中一种方式是新发现并巧妙地被命名为“盗梦空间栏”的网络钓鱼方法。

  

（来源：cnbeta）

  

8

**中国一智能城市监控系统数据库被发现没有密码保护**

  

![](../Images/b221028a005f52afbd3cbdec49243a87.png)

  

智能城市设计旨在让居民生活更轻松，但如果它的监控系统数据泄露？John Wethington发现，一个智能城市数据库没有密码保护可以直接通过浏览器访问。该数据库是一个Elasticsearch数据库，储存了数GB数据，包括数百个人的人脸识别扫描。数据储存在阿里云上。阿里巴巴发言人称，数据库是客户创造的，托管在阿里云，他们总是建议客户使用安全密码保护其数据。他们已经通知了客户，迅速解决了问题。数据库提供了部分智能城市工作的见解。

  

（来源：solidot)

  

  

9

**以色列国防军首次以空袭方式成功阻止激进组织哈马斯的网络攻击**

  

![](../Images/29b965c389b2c0b8d2dd290a5cf7367d.png)

  

以色列国防军（IDF）近日表示已经成功阻止了加沙地带的激进组织哈马斯（Hamas）上周末发起的网络攻击，并对该建筑进行了空袭。这也是IDF首次通过物理攻击方式来打击网络攻击。由于哈马斯和ID在过去三天内发生了多次互相攻击，从而导致了严重的暴力事件。在上周六的战斗中，IDF表示哈马斯发起了针对以色列的网络攻击，但是并没有透露具体的攻击目标。但以色列时报称，哈马斯的目的是“\[破坏\]以色列公民的生活质量”。IDF表示这次网络攻击并不复杂，而且在进行物理打击之后哈马斯将不再具备网络能力。

  

（来源：zdnet）

  

  

10

**美四大电信公司因出售消费者位置数据遭集体诉讼**

  

![](../Images/af26a595c9223cf469afb3c076b5c44b.png)

  

当地周四，律师们对美国四大电信公司提起诉讼，指控它们在各种位置数据丑闻中所扮演的角色。针对T-Mobile的起诉书称，“由于其疏忽和故意的行为包括无法解释的不遵守其自身隐私政策，T-Mobile允许访问原告和集体诉讼成员CPI和CPNI”，其中提到了机密专有信息和客户专有网络信息，后者则包含位置数据。 针对T-Mobile、AT&T和Sprint的投诉基本相同，都提到了每家运营商最终是如何向一家名为Securus的公司提供数据的。针对Verizon的投诉只针对Securus一案。 获悉，每个诉讼涵盖了电信运营商个人客户在2015年4月30日至2019年2月15日期间的近值：Verizon 1亿、AT&T 1亿、T-Mobile 5000万、Sprint 5000万。起诉书指出，每桩诉讼都是以每家电信公司至少一名客户的名义提起的，他们要求在审判中确定未指明的赔偿金额。

 

（来源：cnbeta）
