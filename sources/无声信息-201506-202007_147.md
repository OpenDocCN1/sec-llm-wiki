# 无声信息与七牛云达成战略合作 共筑网络安全防线

2018年12月13日下午，七牛云董事长吕桂华一行与无声信息董事长黄勇一行签署了战略合作框架协议，双方将充分发挥各自资源、技术优势，共同打造更完善的安全产品。

![](../Images/e763137cdac74aa76871938ece104bf9.png)

  

自2018年11月以来，双方高层领导对此次合作高度重视，并多次组织双方团队就下一代安全产品的能力升级和技术融合进行沟通讨论，希望在安全领域能充分发挥各家之所长，打造更贴近市场需求，具备更强应用能力的产品。经历了销售市场、产品技术上的多次碰撞后，双方终于在今天将此次合作落地，并在签约现场对今后的合作模式进行深度沟通。

  

![](../Images/68c7568413beb15025a8e087b2f9cc35.png)

  

无声信息董事长黄勇表示，在网络空间治理的产品项目上，将由技术能力融合作为切入点，提升市场的服务能力，达成合作共赢。

  

七牛云吕桂华总裁表示此次合作对双方具有重大意义，双方将多年沉淀积累的技术能力和应用场景相关理念融合，竖立行业门槛，深度服务市场。

  

![](../Images/b930f9cffdac4364fd3e6360e68249b0.png)

  

  

未来，无声信息与七牛云将不断加强合作，形成优势互补、互惠共赢的战略伙伴关系，共建网络安全新生态，开启合作新篇章。
