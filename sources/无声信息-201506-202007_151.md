# 中国网络安全产业联盟领导莅临无声信息参观调研

11月28日，中国网络安全产业联盟促进网络安全产业发展政策措施调研座谈会在无声信息举行。

  

中国网络安全产业联盟调研专家组中国网络空间安全协会副秘书长陈晓桦、中国网络安全产业联盟副秘书长许玉娜、中国电子技术标准化研究院专家等一行5人莅临公司。无声信息董事长黄勇携公司高管出席了本次座谈会。

  

![](../Images/3a6d15f5732888a90edaddd56f8ee815.png)

  

  

座谈会上，无声信息董事长向来访领导介绍了公司概况和产品情况。随后，调研组专家又深入了解了无声信息的业务范畴，双方从金融、财税、人才、知识产权保护政策等多角度出发，针对网络安全产业发展、网络安全人才培养等问题进行了交流。针对如何留住网络安全人才、如何扩大企业规模、加大投资力度、如何优化市场准入机制、如何营造健康的市场生态环境等亟需解决的问题进行了研讨。

调研组专家充分肯定了无声的阶段性成果，并就无声未来发展提出了若干宝贵意见和建议，本次座谈会圆满结束。

  

**关于无声信息**

 

  

无声信息汇聚了国内外顶尖专家学者、技术精英等200余人，遵循“以攻验防、以攻促防、攻防兼备、体系防御”的理念，主要从事网络空间攻防技术研究和产品开发，在网络攻防、数据信息等方面拥有20多项自主可控核心技术，包括安全监测、渗透攻击，态势感知与预警、应急处置，舆情追踪、反诈骗等方面。
