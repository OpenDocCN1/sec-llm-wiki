# 无声信息亮相2018关键信息基础设施安全优秀产品、解决方案颁奖典礼

2018年11月22日，由中国关键信息基础设施技术创新联盟主办，**无声信息**、安天、任子行等企业协办的“2018关键信息基础设施安全优秀产品、解决方案”颁奖典礼暨金融关键信息基础设施保护论坛在京召开。

  

**无声星冕网站安全智能监测与防护平台荣获“补天奖”优秀产品之应用前景奖，亮相颁奖礼。**

无声信息助力论坛成功举办

  

  

**2018关键信息基础设施安全优秀产品、解决方案颁奖典礼**

  

“2018年关键信息基础设施安全优秀产品、解决方案”评选活动共计150余家企业参加，经过安全主管部门及金融行业安全专家层层选拔，最终仅30家企业产品及方案获奖。

  

**无声信息无声星冕网站安全智能监测与防护平台**凭借其优质的服务体验、全方位的技术保障及在用户口中的良好口碑，赢得用户及行业的认可，荣获**“优秀产品之应用前景奖——补天奖”。**

  

![](../Images/d6d443da75e474108c73586ff22dba96.png)颁奖仪式  

  

  

**关于无声星冕网站安全智能监测与防护平台**

  

![](../Images/24f80065a24ef4fc8a186f22e3e40160.png)

  

**无声星冕网站安全智能监测与防护平台**通过测绘区域内网站基础情况、分析安全威胁和风险、提供安全监测与防护、对网站攻击事件进行反制、溯源跟踪攻击者/组织，实现网站基础信息与安全状态可感知、可监测、可预警、可监管、可预防的目标。与主管部门密切协作，预防和减少信息安全事件的发生，提升区域网站整体安全能力。

  

![](../Images/b7dc939b28da1fba1bd0f7101e0d1a59.png)

  

**关于无声信息**

  

无声信息主要为中央和国家网信、公安、安全、军队，以及能源、交通、金融、政务等行业服务。公司汇聚了国内外顶尖专家学者、技术精英等200余人，遵循“以攻验防、以攻促防、攻防兼备、体系防御”的理念，主要从事网络空间攻防技术研究和产品开发，在网络攻防、数据信息等方面拥有20多项自主可控核心技术，包括安全监测、渗透攻击，态势感知与预警、应急处置，舆情追踪、反诈骗等方面。
