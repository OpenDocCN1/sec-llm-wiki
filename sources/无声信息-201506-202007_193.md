# 个人信息安全一定要避开这几个坑

1**不晒票据信息**

  

很多人喜欢晒火车票、登机牌、快递单、购物小票等票据，却忘了将姓名、身份证号、二维码等进行模糊处理，这些都是比较常见的个人信息泄露行为。快递单含有网购者的姓名、电话、住址，车票、机票上印有购票者姓名、身份证号，购物小票上也包含部分姓名、银行卡号、消费记录等信息。稍不注意就有可能引起不法分子的注意，甚至发生财产及人身损失。

  

无声信息专家提醒

对于已废弃的包含个人信息的资料，一定要妥善处理。

晒照片时要谨慎，不晒包含个人信息的票据，也可以通过设置分组来分享照片，缩小照片可见的范围。

  

![](../Images/86906922826a73b3e35f5adffdae290c.png)  
  
2不轻易透露个人信息

  

有些家长在朋友圈晒孩子照片，描述文字很可能不经意间泄露包含孩子姓名、就读学校、所住小区等私人信息。在微博、QQ空间、贴吧、论坛与陌生人交流互动时，有时会不自觉地说出或者标注对方姓名、职务、工作单位以及所在位置等真实信息。这些信息有可能会被不法分子利用，很多伪装身份实施的诈骗案件，都是利用了微博泄露的个人信息。此外，微信中“附近的人”这个设置，也经常被利用来看到他人的照片，也是不法分子的重点目标。

  

无声信息专家提醒

在微博、QQ空间、贴吧、论坛等社交网络要尽可能避免透露或标注能够确定真实身份和位置的相关信息；发布信息一定要通过设置分组来避免所有人看到个人信息；与陌生人交谈时也要谨慎，避免透露个人信息。

  

![](../Images/7cac7ecf11f629fc5826b3a0a71451db.png)

  

3慎重参与网络调查扫码

  

微博中经常会碰到以赠送小礼品形式开展的各种网络“调查问卷”、购物抽奖活动或申请免费邮寄资料、申请会员卡等活动，一般要求填写详细联系方式和家庭住址等个人信息，或需要扫描商品码或支付二维码。不法分子可能轻松获取个人信息，很多黑客也通过恶意二维码套取用户的个人信息和银行信息进行诈骗，在微博上一定要注意扫码安全。

![](../Images/71df02cf95d1de8f77ce089d884cbae9.png)  

  

无声信息专家提醒

不轻信网络折扣、免费活动信息；

参与此类活动前，要选择信誉可靠的网站认真核验对方的真实情况，不贸然填写导致个人信息泄露；

审慎点击陌生人发送的支付链接、商品链接；

不随意扫描各种免费活动的二维码，避免手机中木马病毒而造成更大的经济损失。

  

4切莫传发不实信息

  

很多人在微博上看到一些新奇的新闻事件时，喜欢随手转发。但在转发过程中，从未考虑事件的真实性，也没有考虑过负面事件可能带来的社会影响。这种事件时有发生，但还未引起大家足够多的重视，负面社会影响可能会触犯国家多个管理办法或法律，切莫因一时好奇而成为不良信息的搬运工或不法分子的替罪羔羊。

  

无声信息专家提醒

不要随意在微信、微博、论坛、QQ等通信平台上散布或转发未经权威部门证实的消息，不要盲目跟风转发。对于自己不能确认的消息，可以咨询相关平台、媒体部门或求助于警方，切勿随意转发。

  

5切勿连接不熟悉的免费WIFI

  

外出时，很多人习惯在智能手机的网络设置中选择了WiFi（无线网络）自动连接功能，这样可以自动连接公共WiFi。但是，大众对真假公共WiFi的辨识能力不高，WiFi安全防护功能也比较薄弱，黑客只需凭借一些简单设备，就可盗取WiFi上任何用户名和密码。

  

![](../Images/297d19e67d44a500a4d5af576a9b5138.png)

  

  

无声信息专家提醒

不随意连接公共网络；

登录网银或者支付宝时，最好使用4G手机流量；

通过专门的APP进行金融活动；

为了保护自己的个人信息，最好把WiFi连接设置为手动。
