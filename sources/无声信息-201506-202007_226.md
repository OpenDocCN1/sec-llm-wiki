# 无声信息董事长黄勇先生荣膺“2017年度成都市突出贡献企业家”

2月2日，2017年成都中外企业家新春联谊会暨优秀企业家颁奖盛典在成都举办。成都市级部门相关领导、成都企业联合会负责人及成都市各界企业家代表共400余人参会。

会议宣读了“关于表彰2017年度成都市十大优秀企业家、最具社会责任家、突出贡献企业家、创新明星、创业明星的决定”，**无声信息董事长黄勇先生被评为“2017年度成都市突出贡献企业家”****。**

无声信息董事长黄勇先生作为信息和网络安全研发的专家，在该领域沉淀近20年。长期致力于信息网络安全高新技术研发，并在技术实践和推动信息安全产业发展方面做出显著贡献，创新地提出平台化“可感知”安全服务理念，引领着信息和网络安全行业的发展方向。

![](../Images/e7b30085ade40e9f0f9446fabd78e828.png)

  

  

关于无声

  

无声信息2000年成立于成都，在黄勇先生的带领下，十七年来专注于信息安全领域的产品研发和服务，现拥有双螺旋安全研究院、产品研发团队、大数据研究所三大独立的研发团队和业界一流的专家团队，客户群分布于政府、金融、能源、电信、教育等领域。

  

沿着“可感知、可监测、可监管、可预测、可预防”的技术路线，无声信息现已成功研发出四大核心网络安全产品线，包括态势感知、流量、情报、攻防四大产品线；安全服务方面，一流的安全专家团队为客户提供等级保护建设、风险评估、安全加固、渗透测试、应急响应等服务，已成为深受信赖的安全服务提供商。

  

![](../Images/b140f0e617553088e8a2f7b1af932f8d.png)

  

  

  

不忘初心，砥砺前行

  

在十多年的沉淀和积累后，无声信息迎来了在产品和服务方面的厚积薄发。未来，无声信息将在网络安全和信息化战线上持续创新，为客户提供高品质的服务，助力安全中国！
