# 不区分威胁数据、威胁信息、威胁情报，何谈信息安全？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTYwMjM3Mw==&mid=2651681472&idx=1&sn=967eeb02655ff3cdf772ee7a615a5819&chksm=80e3ffeab79476fc80a9a676e1db0a58fe875c06bf5cc4c34a1c061c6544f18befe0941b4438&scene=126&sessionid=1681375099#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTYwMjM3Mw==&mid=2651681472&idx=1&sn=967eeb02655ff3cdf772ee7a615a5819&chksm=80e3ffeab79476fc80a9a676e1db0a58fe875c06bf5cc4c34a1c061c6544f18befe0941b4438&scene=126&sessionid=1681375099#rd)

当今世界，计算机互联网技术飞速发展，网络信息已经成为社会发展的重要组成部分。与此同时，计算机网络安全也面临着前所未有的威胁，网络信息资源的安全与保密日益成为人们关注的焦点。威胁是网络与信息安全研究人员十分关注的安全问题，那么如何理解威胁数据、威胁信息和威胁情报呢？

  

  

  

威胁数据

  

![](../Images/c220e2f9868ba28fc5a7599d04fe2db0.png)  

威胁数据通常可以通过各种各样的感应器、监测设备较为容易地、大量地获取，它们通常都是从采集终端上收集上来的单个原始数据，能够陈述单一的无可争议的威胁事实。比如说互联网网页上的一个威胁IP访问请求，这个数据就是简单记录了威胁IP的这个事实。在没有进行数据分析之前，计算机还不知道这个数据有什么价值，存在什么样的意义，是不是威胁或风险，有没有危害等等，甚至计算机认为这就是一个没有任何含义的记录。因此，我们可以将威胁数据理解为**对一个威胁行为的最原始记录和描述**。

  

威胁信息

  

![](../Images/91b0aaa73a8c783a72ccb8c493453138.png)  

虽然获取原始的数据非常容易，但有用的数据往往掺杂在大量的非威胁数据中，因此要获取有意义、有价值的信息是非常困难且费时的。威胁信息就是原始的威胁数据被识别分析后的结果，也就是说，威胁信息不再是原始的、单个的威胁记录，而是一连串的、互相联系的原始威胁数据结合起来后产生的内涵。这个时候，计算机已经能够识别出哪些数据具有威胁性了，也可以确定这些威胁数据组合起来后产生的威胁信息是有用的，而且这些威胁信息能够回答计算机提出的简单问题，比如：这个信息是有害的吗？这些威胁信息的目标是什么？因此，我们可以将威胁信息简单地理解成**由一串威胁数据相互联系产生的具有判断性的基本问题依据**。

  

威胁情报

  

![](../Images/ecc77f8950d89cc4c12f81c829ecd6ed.png)

威胁可能同时来自网络的内部和外部。目前，信息安全人员越来越多地关注威胁情报这一概念。针对威胁情报，Gartner把它定义为基于证据的知识，包括上下文、机制、指标、隐含和可操作的建议，针对一个现存的或新兴的威胁，可用于做出相应决定的知识。SANS研究院把威胁情报定义为针对安全威胁、威胁者、利用、恶意软件、漏洞和危害指标，所收集的用于评估和应用的数据集。这样，威胁情报就是可以用于决策的解决方案了，比如网络攻击的来龙去脉，作为威胁情报，可以帮助公安机关确定犯罪嫌疑人。所以说，构成威胁情报既有可能包含威胁信息也有可能包含有助于威胁分析的一般信息。因此，我们可以把威胁情报理解为**对海量的、包含威胁信息在内的各种信息进一步筛选和分析后，通过各种处理后关联出来的具有解决复杂问题能力的决策依据**。
