# Xshell系列软件被植入后门，建议更新到最新版本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTYwMjM3Mw==&mid=2651680585&idx=1&sn=3d1cbdb118f910da1966592011bb1940&chksm=80e3e263b7946b751fe499881b699374cac66fb71b7355ada24d64b076a66cb8bc0f587a7f4c&scene=126&sessionid=1681375103#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTYwMjM3Mw==&mid=2651680585&idx=1&sn=3d1cbdb118f910da1966592011bb1940&chksm=80e3e263b7946b751fe499881b699374cac66fb71b7355ada24d64b076a66cb8bc0f587a7f4c&scene=126&sessionid=1681375103#rd)

  

NetSarang是一家以提供安全连接解决方案的公司，其产品以Xmanager Enterprise, Xmanager, Xshell, Xftp, Xlpd为主。

 

近日，国外某安全公司发现NetSarang的Xmanager, Xshell, Xftp, Xlpd等产品中，发布的nssock2.dll模块中存在恶意代码，在Xshell 5.0.1322和Xshell 5.0.1325两个版本中均已确认恶意代码存在。

  

![](../Images/f8994ade60a51f6434441f513acc5c70.png)

  

漏洞信息

  

   

漏洞类型：后门

  

   

危害等级：高危

  

   

影响版本

  

根据今天(2017/08/14)NetSarang的安全公告，受到影响的软件版本有：

  

Xmanager Enterprise 5.0 Build 1232

Xmanager 5.0 Build 1045

Xshell 5.0 Build 1322

Xftp 5.0 Build 1218

Xlpd 5.0 Build 1220

  

漏洞危害

  

存在后门的版本会向nylalobghyhirgh.com发起请求传输敏感数据（或上传用户服务器账号密码）。

  

漏洞检测方法

  

打开Xshell工具，点击帮助-关于Xshell(A)查看当前版本，如果版本为Xshell  5.0.1322或Xshell  5.0. 1325，请更新到最新版本Xshell 5 Build 1326。

  

解决办法

  

及时升级到官方的最新版本。
