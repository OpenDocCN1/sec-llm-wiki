# 无声信息助力“信息安全铁人三项赛之企业赛”成功召开

赛事简介  

信息安全铁人三项赛是由中国信息安全测评中心指导，中国信息产业商会信息安全产业分会主办，教育部高等学校信息安全专业教学指导委员会协办，中国信息产业商会信息安全产业分会人才建设专业委员会和北京西普阳光教育科技股份有限公司承办的面向大学生以典型实际应用环境为背景的公益性实战技能大赛。大赛分“数据分析对抗赛”、“企业计算环境安全对抗赛”、“个人计算环境对抗赛”三项赛事，由高校和企业联合组队，并组建铁人三项赛训练营，推动校企人才培养选拔，实现人才从高校到企业的无缝对接，实现校企的深度融合。

  

4月22日，信息安全铁人三项赛西南赛区之“企业计算环境安全对抗赛”在成都信息工程大学正式打响，无声信息携手成都大学参加了本次比赛。

![](../Images/95aec837ea9545a327753f15ff04e999.png)

（信息安全铁人三项赛比赛现场）

企业计算环境安全对抗赛是模拟企业真实网络环境下的一场安全对抗赛，侧重考察参赛选手对企业网络架构的认知能力、网络安全风险认知能力和网络安全防护能力。通过模拟企业典型网络架构，并融入包括云计算、工控安全、无线接入和可信计算在内的多项新技术特性，让参赛选手通过比赛对企业所需的业务技能和安全人才有了更深入的认识和理解。

![](../Images/f7405700a3dffefc1bfd3dac6cd36af4.png)

（本次比赛采用夺旗赛形式展开激烈角逐）

  

本次共有来自成都大学、成都东软学院、电子科技大学、贵州大学、重庆邮电大学、四川大学、成都信息工程大学共7支战队参赛。

如火如荼的战队对抗赛期间，“聚力信安人才 共塑产业未来”研讨论坛同时隆重举行。中国信息安全测评中心资质评估处副处长、众多高等院校、行业企业、协会代表出席本次研讨会。与会嘉宾就“聚力信安人才 共塑产业未来”展开热烈讨论，重点讨论了在“4.19”讲话一周年之际，如何充分发挥产学研一体化的融合，通过高校与企业的投入与协作，形成良性的互动关系，促进学校课程体系及人才培养改革，开拓学生视野，提升学生实践与理论综合能力；同时企业也可以锁定、收获高质量的人才，继而实现高校与企业的双赢。

![](../Images/1b446d66a1f9ef97c0bda41ac482e76d.png)

在研讨会论坛上，无声信息董事长黄勇先生做了精彩主题演讲，分析了网络生态繁荣发展的今天，面临的严峻的网络安全威胁；网络空间安全领域中，基础设施安全、应用安全、数据安全所对应的技术空间安全和社会空间安全这两个维度相互影响，而在基础设施监测等方面，未来还有诸多发展潜力和空间。

![](../Images/b90288f136ad9d1052e99abb73b6ab2d.png)

黄勇先生还表示，对信安人才的培养，应当加强学科建设，合理把握各领域系统化的培养，为企业输送出更多实践性人才、综合型人才。在网络信息安全已提升为国家战略的今天，应当抓住机遇，把人才聚集起来，校企合作共同努力，为信息安全产业创造出更加辉煌的明天。  

  

无声信息助力人才培养

无声信息作为国内领先的安全服务提供商，深耕信息安全领域十七载。无声信息‍‍响应国家“网络强国”的号召，不断努力创新，立志成为国家网络安全战略安全的核心力量。

无声信息十分重视人才培养及人才储备，为推动网络安全行业的长远发展和网络安全人才的培养提供助力，始终坚持与教育行业共同携手，保持深度校企合作的理念。

未来，我们希望能与更多的院校、机构合作，为我国网络安全教育的普及和国家网络空间安全防御体系能力的提升建言献策，贡献力量。
