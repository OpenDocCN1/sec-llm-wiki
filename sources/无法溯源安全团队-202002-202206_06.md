前言

    无聊的人总爱怀念过去。前几天晚上总是睡不着，翻了翻旧号里封存了好几年的QQ空间。看着N年以前发的那些说说，只能用 中二来形容那时自己了。然后看到一个评论，回想起了那时青涩的时光，后来上大学之前换了个号，旧 号的好友被选择性转移，剩下的都直接删除了，所以过去这么多年，留下的线索仅有一个说说下面的评 论了，看看能不能找回点啥吧。 

![](../Images/df065c7b5dcd9b6c719466f3a71c666e.png)

信息收集

    对方的qq空间设置只有好友可以查看，用好友添加功能看了下资料卡信息，好吧能得到的只有生日，应 该是真实信息，依稀还记的她是白羊座的。

![](../Images/29d9341d1dc01dcc32392dbb811333c2.png)

    先走一下qq的申诉流程，可以看到手机号的开头，这里星号太多没法利用，不过可以为后面收集到的信 息做对比

![](../Images/d67ee83bab86b0e079366f5176bcda0d.png)

    拿着qq号去各大搜索引擎搜一下，看看有没有什么痕迹，找到的只有一个腾讯微博，翻了下也没什么有 用内容。 

    那就一步到位，去TG里的社工裤查一下老密

![](../Images/c84ff6debd37dd3b9cb83d4aa3b4a3fd.png)

    再配合reg007，看看能不能搞到一些可以登录的站点

  

![](../Images/ca9a011b00610ba1960236f81c53d06c.png)

    运气还不错，用老密登上了几个，最有用的算是爱奇艺吧，看了下爱奇艺的观看历史什么的，居然都是 空的，这小姑娘不看剧的嘛。。

![](../Images/05613823f9b9fb31503183730e003ef8.png)

    没关系，在翻一下吧，看到安全中心有绑定信息，这里手机号开头正好可以和之前申诉的那个手机号对 应上，可以确定是目前在用的手机号了，但是星号还是很多，根本没法利用

    ![](../Images/2b8bace020e40f0164f3bce675af2682.png)

    继续翻爱奇艺的用户中心的那些功能，看看有什么能深入利用的，发现账号保护哪里手机号只隐去了四 位，那么工作就又可以继续进行了

![](../Images/27662387ca9877d19d2cef55457dc36e.png)

号码枚举

    写了个枚举小脚本，0000-9999替换四位\*号，这里为了保护隐私，部分数字用x来代替

*   
*   
*   
*   
*   
*   

```
#!/usr/bin/env python # -*- coding:utf-8 -*- file = open('phonenumbers.txt','w') for i in range(1,10000):     file.write("18xx%04dxx3\n" % i)     file.close()
```
