引言


    渗透过程中总有一些特殊场景需要使用各种隧道来绕过防火墙的各种规则，而rdp作为windows的远程管理协议往往不在防火墙的考虑范围内。由于防火墙的规则，当只能通过一台windows服务器进入内网情况下，而且有着层层监控的情况下，我们可以去使用RDP隧道来去连接我们的目标机器



安装和配置


首先你需要安装mingw

apt-get install mingw-w64

apt-get install mingw-w32

其实上述这条命令看你自身情况，kali自身是携带的mingw-w32是默认编译32位程序，上面这条命令是安装64位的，如果你想先用32位你就可以忽视64位的安装



然后使用命令

git clone https://github.com/V-E-O/rdp2tcp.git

cd rdp2tcp

然后开始使用make编译

make client
make server-mingw32

第一条是编译连接程序

第二个是被连接的程序，这里是编译32位

生成以下文件:

  • /server/rdp2tcp64.exe

  • /client/rdp2tcp


    

接下来需要安装的是xfreerdp

    

echo "deb http://pub.freerdp.com/repositories/deb/bionic/ freerdp-nightly main " >>/etc/apt/sources.list
wget -O - http://pub.freerdp.com/repositories/ADD6BF6D97CE5D8D.asc | sudo apt-key add -
apt-get update
apt-get install freerdp-nightly

如果上述办法行不通你也可以

git clone https://github.com/FreeRDP/FreeRDP.git
cmake .make
make install

这俩个办法看你心情去安装

安装之后会在你的opt目录下面出现

/opt/freerdp-nightly

如果出现在这个则代表安装成功

接下来就是链接

/opt/freerdp-nightly/bin/xfreerdp /v:windows的ip地址:端口 /u:账号 /p:密码! /cert-ignore /rdp2tcp:/root/rdp2tcp/client/rdp2tcp

登录服务器，上传rdp2tcp.exe并运行

使用rdp2tcp/tools/rdp2tcp.py来管理tunnel

将本地445端口的流量通过rdp tunnel转发到目标机上
