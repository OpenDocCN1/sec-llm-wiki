疑似B站2亿余条用户帐户信息遭泄露

**7月6日，一张暗网叫卖2.2亿余条B站用户信息的截图在网上流传，泄露数据疑似包括用户账号和手机号，价格为0.5比特币或17.72以太币。**

据悉，泄露数量具体为221,223,698条，包括UID和手机号。除了在帖子里展示的少量数据，帖主还提供了总计超过50万行的样本数据。经核实，发现UID基本上都能 对应B站账号，对应的手机号则有些是空号，有些可以打通，但暂未证实手机号与UID指向同一用户。

![](../Images/67ea4114e41b9d6b093edf83c3568f0f.png)

7日晚，B站 对此作出回应，称“疑似用户数据泄露”的网传信息不实，公司经过全面技术排查和分析对比，确认网传的泄露数据为错误信息。

**0****2**  

连锁酒店巨头万豪国际遭数据泄露

**万豪国际连锁酒店遭遇新的数据泄露事件，攻击者从该公司网络中窃取了约20GB的文件。**

据悉，攻击发生在6月，一黑客组织利用社会工程欺骗马里兰州一家万豪酒店的员工以进入其电脑。该威胁者没有进入万豪的核心网络。

![](../Images/8aeb34a22a7adc828bc57684e0296e62.png)

攻击者称，被盗的数据包括客人的信用卡信息及客人和员工的机密信息。但万豪酒店称经调查确定，被访问的数据主要包含有关酒店运营的非敏感内部业务文。同时表示正在准备通知300-400人有关这一事件，并已通知相关执法机构。

**0****3**  

北美IT服务巨头遭恶意软件攻击，官网等多个系统下线

**总部位于新泽西州的信息技术 (IT) 产品和服务提供商 SHI International 近日证实，7月4日其网络遭受到恶意软件攻击。**

攻击发生后，SHI的一些网站页面也返回Amazon CloudFront/S3 SHI 错误。在评估其系统的完整性和调查安全事件时，SHI 被迫将其部分系统下线，包括公司的公共网站和电子邮件。

![](../Images/0563d6ae0a04a852cffefa308ea67b89.png)

SHI表示，客户数据在攻击期间并未被泄露，其供应链中的第三方系统也没有受到影响。

**0****4**  

网络攻击致使美国多个州无法发放失业救济金

**7月6日消息，一家软件公司遭受网络攻击，导致美国多个州成千上万民众的失业救济金和求职援助受到影响。**

美国田纳西州的服务商Geographic Solutions在6月26日公告称，该州服务即将中断。直到6月30日上午，失业救济金网站仍处于离线状态。田纳西州约有12000人依 靠失业补助生活，目前他们仍然没能拿到救济金。

![](../Images/83f257746fbea1be336e8f78fada2a64.png)

目前还不清楚，Geographic Solutions公司究竟 是遭遇到勒索软件攻击，还是其他类型的网络事件。另外，也不明确到底有多少个州受到事件影响。Geographic Solutions公司发表声明表示，没有任何个人数据遭到访问，网络运营中心也未出现数据删除迹象。

**0****5**  

HackerOne员工窃取漏洞报告，向受影响客户索取钱财

**HackerOne 平台的一名员工窃取了通过该平台提交的多份漏洞报告，并将报告披露给受影响客户，获得经济报酬。**

HackerOne 平台指出，这名恶意员工因其中的某些漏洞报告得到了经济报酬。该平台通过追踪款项来源后发现，始作俑者是负责为“很多客户计划”分类漏洞披露的其中一名员工。

![](../Images/ccdaca354b5169c1ff0bb089f6fc353a.png)

6月30日，HackerOne 平台终止了与这名员工的雇佣关系。并单独联系出于恶意或合法目的而导 致漏洞报告遭访问的客户，告知他们漏洞披露遭访问的日期和时间。

**0****6**  

黑客公布伊朗钢铁制造企业近20G绝密文件

**当地时间7月7日，攻击三家伊朗钢铁制造企业的黑客组织Predatory Sparrow发布了所谓的近20GB绝密数据，其中包含公司文件。**

该组织表示，19.76GB的文件只是即将发布的“第一部分”。这次发布的数据中似乎包含一张钢铁设施内部的图像。

![](../Images/55e9ee0767d7bb0f7b7fd0c1774ad8ef.png)

该组织6 月 27 日声称入侵三家伊朗钢铁制造企业，初步报告显示，这次袭击扰乱了工厂的运营，但钢铁公司和伊朗政府否认它有任何重大影响。

**0****7**  

Mangatoon 遭数据泄露，暴露了 2300 万个账户信息

**漫画阅读平台 Mangatoon 遭遇数据泄露，黑客从不安全的 Elasticsearch 数据库中窃取了属于 2300 万用户帐户的信息。**

上周，数据泄露通知服务 Have I Been Pwned  (HIBP) 在其平台上增加了 2300 万个 Mangatoon 帐户。泄露帐户信息包括姓名、电子邮件地址、性别、社交媒体账户身份、来自社交登录的身份验证令牌和加盐的 MD5 密码哈希。

![](../Images/d24f6b5b87ce303cc0d5d32b214f3e4a.png)

据悉，本次数据泄露因不安全 Elasticsearch 服务器导致，攻击者从使用弱凭据的 Elasticsearch 服务器上窃取了数据库。

02高级威胁分析  
![](../Images/4b75dcd7f2052b03fda0d137cc9bf97e.png)**0****1**  

新的 0mega 勒索软件针对企业进行双重勒索攻击

**一项名为“0mega”的新勒索软件针对全球范围内的组织进行双重勒索攻击，并要求支付数百万美元的赎金。**

0mega是 2022 年 5 月发起的一项新的勒索软件，已出现许多受害者。

勒索软件会将 .0mega 扩展名附加到加密文件的 名称中，并创建名为 DECRYPT-FILES.txt的勒索记录。赎金记录是针对每个受害者定制的，通常包含公司名称并描述攻击中被盗的不同类型的数据。此外还会威胁受害者，如果不支付赎金，0mega 团伙将向其商业伙 伴和贸易协会披露此次攻击。

赎金记录包括一个 Tor 支付谈判网站的链接，其中包含受害者联系勒索软件团伙的方式。要登录该站点，受害者必须上传他们的赎金记录， 其中包括该站点用来识别受害者的唯一 Base64 编码。

![](../Images/ea01e6aeb7ea122ab819cfa9c098a212.png)

与几乎所有以企业为目标的勒索软件操作一样，0mega 运行一个专用的数据泄露站点，如果不支付赎金，威胁行为者将使用该站点发布被盗数据。

0mega 的泄漏站点目前托管着 152 GB 的数据，这些数据是在 5 月的一 次攻击中从一家电子维修公司窃取的。

![](../Images/4b9a8aebc5a349fc239724614ea925e9.png)

  

03网络安全监管动态  
![](../Images/4b75dcd7f2052b03fda0d137cc9bf97e.png)**0****1**  

美国防部推出“Hack US”公网资产漏洞奖励计划，奖金池11万美元

**美国国防部推出了一项为期一周的漏洞奖励计划，名为“Hack US”。如研究员能从国防部所拥有的公开可访问资产中找到高危和严重漏洞，则可获得奖励。**

这项新的漏洞奖励计划是国防部漏洞披露计划的一个简短延伸，在 HackerOne 平台运行。该计划将在7月4日至7月11日期间向全球的漏洞猎人和安全研究人员开放。

![](../Images/a20d7c76b597cc52dacbe5696ec2087e.png)

该计划的奖金池是11万美元，将遵循谁先提交谁得赏的原则为漏洞报告分配7.5万美元，直到该7.5万美元耗尽。3.5万美元将作为漏洞奖赏。美国国防部还指出，这项计划面向全球公众，即使是政府员工也可在下班后参加。

04网络安全研究报告  
![](../Images/4b75dcd7f2052b03fda0d137cc9bf97e.png)**0****1**  

NPM 供应链攻击影响数百个网站和应用程序

**最近的研究表明，可追溯到 2021 年 12 月的 NPM 供应链攻击使用了数十个包含混淆 Javascript 代码的恶意 NPM 模块来破坏数百个下游桌面应用程序和网站。**

研究发现，该活动背后的威胁行为者使用仿冒域名来感染正在使用流行软件包的开发人员，如umbrellajs 和 ionic.io NPM 模块。

该活动中使用的一个恶意 NPM 包（icon-package）有超过 17,000 次下载，旨在将序列化的表单数据泄露到多个攻击者控制的域。此外，用于泄露数据的域之间的相似性表明，该活动中的各个模块都在单个参与者的控制之下。

![](../Images/067a70cc972ed8e4c2f3bd109abccb79.png)

研究人员已编制用于 IconBurst 供应链攻击的恶意程序包列表 ，但其影响尚未确定，因为无法知道自 12 月以来通过受感染的应用程序和网页窃取了多少数据和凭据。经不完全统计，NPM 模块的总下载量已超过 27,000 次。目前， NPM 注册表中仍然存在一些 IconBurst 恶意 程序包，可供下载。
