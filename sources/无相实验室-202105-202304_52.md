沃达丰遭破坏性攻击，致葡萄牙全国大面积断网

**国际电信巨头沃达丰葡萄牙公司遭到破坏性网络攻击，导致4G/5G、固话、电视等网络全部中断，仅3G网络勉强恢复可用，给葡萄牙数百万用户造成了不便甚至混乱。**

据悉，本次攻击始于上周一晚上。攻击迅速摧毁了沃达丰葡萄牙子公司的 4G 和 5G 网络，并停止了固定语音、电视、短信以及语音和数字应答服务。

![](../Images/46dccbe1bac0df329556c9d3d786a955.png)

该当地新闻报道，数以百万计的客户无法拨打语音电话，发送短信，使用互联网，或访问有线电视。其他企业和公共服务也受到 影响，包括救护车运营商、消防部门和医院。

**0****2**  

Puma 因第三方勒索攻击遭受数据泄露

**2021年12月，Puma的北美劳动力管理服务提供商之一Kronos被勒索软件攻击，导致Puma数据遭到泄露。**

据悉，Kronos 本月早些时候向几位司法部长办公室提交了违规通知，其中指出攻击者从 Kronos 私有云 (KPC) 中获取了 Puma 员工及其家属的数据，包括社会安全号码。

![](../Images/73613a5dfadda4b1fed67720c7fb0f2f.png)

此前黑客还在 8 月份窃取了 Puma 内部应用程序的源代码，并将其在 Marketo 数据泄露门户上出售。此次袭 击得到了彪马公司公关负责人的证实。

**0****3**  

Maze、Egregor 和 Sekhmet 勒索软件的主解密密钥在线泄露

**上周三，Maze 、Egregor 和 Sekhmet 勒索软件系列的主解密密钥由其恶意软件开发者在论坛公开，并称这是一次有计划的泄密。**

这些密钥由一个名为“Topleak”的用户在论坛上共享，该用户声称自己是所有三个操作的开发者。在用户泄露的文件中，有一个名为“M0yv”的恶意软件的源代码 ，该团伙武器库的一部分。

![](../Images/6c6a3b762d4d0fb4db575c8b4b5da6c8.png)

目前已证实泄露的解密密钥是合法的，并允许免费解密由三个勒索软件系列加密的文 件。

**0****4**  

虚假的海盗湾网站正对数百万用户传播恶意广告

**调查发现，5个伪装成著名BT盗版资源网站海盗湾的恶意站点，每月向超过700万名用户提供恶意广告。**

根据调查，这些站点以一些免费下载内容作为诱饵，向用户提供恶意广告，其中名为Thepiratebay3.to的站点吸引了绝大部分流量，每月有超过600 万访问者点击其登陆页面上的恶意广告，而 thepiratebays.com 和 thepiratebay2.to 的月访问量也超过了 30万 次。

![](../Images/0c44d7d592b9b4a1bc282e719107cc44.png)

网络犯罪分子使用恶意广告来诱骗用户进行点击，以在用户设备上传播恶意程序以及有效载荷，实现对用户设备系统布置后门，窃取受害者的个人数据、安装勒索软件或其他恶意行为。

**0****5**  

数字日程安排平台FlexBooker泄露数百万客户的数据

**近日，数字日程安排平台FlexBookerr被指控暴露了数百万客户的敏感数据，包括用户电话、邮件地址等。**

据悉，该公司用来存储数据的 AWS S3 存储桶没有实施任何安全措施，数据完全暴露在互联网上，任何使用网络浏览器的人都可以轻松访问。

![](../Images/51a41484e521c5a21b9f18eed12d18a1.png)

暴露的 1900 万份文件包括全名、电子邮件地址、电话号码和日程安排详细信息。目前已有黑客在地下论坛出售属于 Flexbooker 的私人数据。

**0****6**  

欧洲最大的汽车经销商遭到勒索软件攻击

**欧洲最大的汽车经销商之一Emil Frey上个月遭到勒索软件攻击。**

Emil Frey于 2 月 1 日出现在 Hive 勒索软件的受害者名单上，并确认他们在 1 月份遭到攻击。

![](../Images/a78f23c322fcce9d00012f5f9a5edd60.png)

该公司发言人称：攻击活动发生在2022 年 1 月 11 日，几天后，受影响系统恢复并重新开始商业活动。但他拒绝透露攻击事件详情，关于是否有客户信息被窃取也未可知。

02高级威胁分析  
![](../Images/da3a5e394a2900d451154dcd2e437e3f.png)**0****1**  

恶意软件利用Windows 11更新进行攻击

**在微软宣布 Windows 11 的广泛部署阶段，恶意攻击者利用虚假的 Windows 11 升级安装程序，诱使Windows 10 用户下载和执行 RedLine 窃取恶意软件。**

RedLine 窃取程序是目前部署最广泛的密码、浏览器 cookie、信用卡和加密货币钱包信息抓取程序，因此其感染可能会对受害者造成可怕的后果。

据悉，攻击者使用看似合法的“windows-upgraded.com”域来进行活动的恶意软件分发部分。该站点伪装成 Microsoft 站点，如果访问者点击“立即下载”按钮，会收到一个 1.5 MB 的 ZIP 存档，名为“Windows11InstallationAssistant.zip”，直接从 Discord CDN 获取。

![](../Images/448e92850a20187d7ff4bf9feb57e92c.png)

解 压缩文件后生成一个大小为 753MB 的文件夹，当受害者启动文件夹中的可执行文件时，一个带有编码参数的 PowerShell 进程就会启动。

然后，启动一个 cmd.exe 进程，超时时间为 21 秒，超时后，从远程 Web 服务器获取一个 .jpg 文件，该文件包含一个 DLL，其内容以相反的形式排列，可能是为了逃避检测和分析。

最后，初始进程加 载 DLL 并用它替换当前线程上下文。该 DLL 是一个 RedLine 窃取器有效负载，它通过 TCP 连接到命令和控制服务器，以获取恶意任务指令。

![](../Images/d7761b0b2cbcc8b42c429928751b3412.png)

目前，该分发站点已关闭，但攻击者很可能已构建其他恶意站点继续进行攻击活动。这类恶意网站是通过论坛和社交媒体帖子或社交软件进行宣传的，因此除了官方的 Windows 升级系统警报外，建议不要轻信任何其他宣传，点击未知来源的升级链接或补丁，如需升级更新Windows 11系统请选择官方渠道。

03网络安全监管动态  
![](../Images/da3a5e394a2900d451154dcd2e437e3f.png)**0****1**  

程序员离职当天“删库跑路”，被判刑10个月

**上海市杨浦区人民法院消息，一名29岁的程序员未经公司许可，在离职当天，私自将即将上线的系统代码全部删除，构成破坏计算机信息系统罪，被判处有期徒刑10个月。**

刑事判决书显示，录某1992年出生，2021年3月入职上海某公司，负责代码研发工作，同年6月，录某从公司离职。离职当日，录某未经许可用本人账户登录代码控制平台，将其在职期间所写项目代码删除，导致公司原定按期上线项目延后。

2021年9月23日，录某因涉嫌犯破坏计算机信息系统罪被刑事拘留，同月30日被逮捕。法院认为 ，被告人录某违反国家规定，对计算机信息系统中存储数据进行删除，后果严重，其行为已构成破坏计算机信息系统罪，后判处录某有期徒刑十个月。
