**01**  
  
  
  
**戴尔现多个高危漏洞，近3000万台电脑面临被远程控制风险**

戴尔客户端BIOS内的BIOSConnect功能存在4个严重漏洞，这些漏洞会影响129款型号近3000万台戴尔电脑，攻击者可以借此远程执行任意代码（RCE）、颠覆操作系统、破坏设备。

研究人员表示，攻击者可以利用这些漏洞在预启动环境中远程执行代码，获得设备的控制权，还可以颠覆操作系统。

![](../Images/2670c13d1542b19cb90ab8ab2e376292.png)

BIOSConnect是戴尔SupportAssit的一部分，后者是一种技术支持解决方案，预装在大多数基于Windows的戴尔设备上。它具备系统恢复和固件更新功能，通过HTTPS连接到戴尔的后台服务器，下载操作系统镜像，帮助用户在本地磁盘镜像损坏、被替换或不存在时恢复其系统。

本次漏洞将影响129款型号的戴尔设备，包括个人笔记本电脑、商务笔记本电脑、台式机和平板电脑，共计约3000万台。

研究人员在分析报告中指出，这四个漏洞累计严重程度为8.3级。这些特定的漏洞允许攻击者远程利用主机的UEFI固件，并获得该设备上的最高控制权。

第一个漏洞（CVE-2021-21571）是针对远程代码执行漏洞进行利用的开端。一旦第一个漏洞被利用，将恶意代码传回到了受害机器内，攻击者就可以选择三个不同的独立溢出漏洞（CVE-2021-21572、CVE-2021-21573、CVE-2021-21574）进行攻击，其中任何一个都可以在目标设备上获得预启动RCE权限。

戴尔在5月28日推出了服务器端更新，以修补CVE-2021-21573和CVE-2021-21574，还发布了BIOS客户端固件更新，以解决其余两个漏洞。

  
  
  
  
**02**  
  
  
  

**威刚拒绝支付赎金，Ragnar Locker公布700GB数据**

近日，威刚拒绝支付赎金，勒索团伙Ragnar Locker已经将700多GB的威刚数据公布在网上。这些数据是以13个受密码保护的档案形式上传的。

Ragnar Locker在存储平台MEGA上发布了元数据档案，最大的文档接近300GB。从档案名称来看，可能包含财务信息、保密协议等类型的详细信息。该组织还发布了几张截图证明其持有的威刚数据。

![](../Images/1e728addb75604fc2ffcb3cd99f67859.png)

据悉，MEGA平台在接到报告后，迅速关闭了该组织的账户并禁止访问该组织的共享文件。MEGA的工作人员称，这些数据并未被广泛下载。

  
  
  
  
**03**  
  
  
  

**亚太互联网络信息中心由于配置错误数据泄露**

近日，亚太互联网注册机构 APNIC 称，因配置错误，导致 WHOIS 管理员密码被暴露了三个月，可被公开访问。

APNIC 表示，监管公开暴露了 APNIC 的 WHOIS SQL 数据库的转储文件，其中包含用于验证数据库对象更改的密码、公司联系方式，以及与内部事件响应小组 (IRT) 相关的密码和联系方式。

![](../Images/41d045b5ac588a9661fa41d98a3d6d9c.png)

在6 月 18 日发布的安全警报中，APNIC（“亚太网络信息中心”的简称）表示，其工作人员将数据库复制到一个被认为是私有的谷歌云存储‘存储桶’中，导致这些信息的泄露。

据悉，6 月 4 日APNIC收到独立安全研究人员的警告后，纠正了配置错误并删除了转储文件。且已完成了为期四天的重置所有维护者和 IRT 密码的工作，其中一些是手动完成的，以“最大限度地减少对网络运营的干扰”。

APNIC 承认“密码可能会被恶意行为者从散列中导出”，WHOIS 数据可能“因滥用而损坏或伪造”。

APNIC 表示，目前仍在评估泄露数据情况，以确定是否应该采取任何进一步的补救措施。建议 APNIC 资源持有者不要重复使用以前的密码，并更新使用该密码的其他帐户。

  
  
  
  
**04**  
  
  
  

**与巴基斯坦有关的黑客使用 ReverseRat 攻击印度电力公司**

一疑似与巴基斯坦有关联的黑客组织，在持续攻击南亚和中亚地区的政府和能源组织，在受损的 Windows 系统上部署远程访问木马。

据悉，受害者分布在印度、阿富汗等地区，包括政府以及输电组织、发电输电组织等能源组织。该攻击行为可追溯到 2021 年 1 月。

本次攻击活动中，攻击目标具有高度针对性，且攻击者采用的策略、技术和程序 (TTP) 依赖于开源代码。攻击者通过修改注册表项来隐藏自己，使其在不引起注意的情况下在目标设备上持久驻留。同时受害者将下载了两个代理，一个驻留在内存中，而另一个则是旁加载，从而使黑客能够在受感染的工作站上持久存在。

![](../Images/035569298b58500f6159fc7d10f6a28e.png)

攻击通过网络钓鱼电子邮件或消息发送恶意链接，点击该链接后，会从受感染域下载包含 Microsoft 快捷方式文件 (.lnk) 和诱饵 PDF 文件的 ZIP 存档文件。诱饵文件主要描述了迎合印度的事件，伪装成通过CoWIN在线门户注册和预约 COVID-19 疫苗的用户手册，而其他一些则伪装成孟买工兵团。

  
  
  
  
**05**  
  
  
  

**微软误签名 Windows 流氓驱动，可加载 rootkit 恶意软件**

据悉，微软近日签名了一个流氓第三方驱动 Netfilter，该驱动包含在游戏社区中传播的 rootkit 恶意软件。

目前尚不清楚 rootkit 是如何通过微软的证书签名过程的，微软表示正在调查，并将“完善”签名过程、合作伙伴访问策略和验证。没有证据表明恶意软件作者窃取了证书，微软也不相信这是国家资助的黑客所为。

根据微软的说法，Netfilter 流氓驱动程序的影响有限，它针对游戏玩家，rootkit 只能在“后利用”中工作 —— 用户需要在 PC 上获得管理员级别的访问权限才能安装该驱动。换句话说，除非用户特意加载该驱动，那么 Netfilter 将不会构成威胁。

微软表示，将与驱动制造商合作，向 Windows 用户推送干净的驱动程序。

  
  
  
  
**06**  
  
  
  

**超过8亿条与WordPress用户相关的记录被泄露**

近日，一个配置错误的云数据库在其所有者得到通知之前暴露了超过 8 亿条与 WordPress 用户相关的记录，包括用户登录地址、用户名、名称、邮箱等信息。

![](../Images/898853a5c9f5e6f32c7806cb1e64f780.png)

安全研究人员称，美国托管服务提供商DreamHost将这些数据存储在互联网上，且没有密码保护。泄露的 8.14 亿条记录可以追溯到该公司管理的 WordPress 托管业务 DreamPress，并且似乎可以追溯到 2018 年。

据悉，泄露的数据中有管理员和用户信息，包括 WordPress 登录位置 URL、名字、电子邮件地址、用户名、角色、主机 IP 地址、时间戳以及配置和安全信息。一些泄露的信息与 .gov 和 .edu 电子邮件地址的用户有关。

目前，相关数据库已采取措施保障其数据安全。但尚不清楚该数据库暴露时间，数据泄露范围等信息。

本次泄露事件，可能会使用户面临网络钓鱼的风险。建议WordPress的用户谨慎对待陌生的邮件，谨防被恶意攻击者实施钓鱼攻击。
