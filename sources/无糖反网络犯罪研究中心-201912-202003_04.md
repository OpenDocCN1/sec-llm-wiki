**南通检察院逮捕诈骗犯罪嫌疑人**

2020年3月16日，江苏省南通市崇川区检察院对一名诈骗犯罪嫌疑人实施逮捕。犯罪嫌疑人陈某通过微信发布口罩销售广告，在收取多名“微商”货款后，陈某利用虚假发货订单、物流信息等手段，实施诈骗。初步查明，陈某诈骗包括两名云南省“微商”在内的30多个代理商，数额高达300余万元。目前，赃款已经全部追缴到位。下一步将尽快明确各被害人损失数额并及时发还赃款。

  

**三台检察院逮捕涉疫诈骗犯**

2020年3月16日，四川省绵阳市三台县检察院对一起以出售口罩名义实施网络诈骗案的犯罪嫌疑人陈某作出批准逮捕决定。陈某通过微信朋友圈发布有大量口罩出售的虚假信息，在收到货款后，便携款至成都，购得7000元的卫生纸，打包成46件快递包裹预发往各地，实施诈骗。据统计，全国各地受害人30余名，订单涉及口罩44万多个，涉案金额100余万元。目前，案件正在进一步办理当中。

  

**“大唐天下”、“智天金融”特大网络传销案二审开庭**

2020年3月11日，贵阳市中级法院和黔南州中级法院分别二审开庭审理了“大唐天下”和“智天金融”特大网络传销案。据公开信息显示，“大唐天下”犯罪团伙通过“大唐天下商城”、“唐人街商城”平台，以消费返利等为诱饵，大肆进行网络传销活动，在全国发展会员183万余人，传销层级高达158层，涉案资金160亿余元；“智天金融”传销犯罪团伙虚构盈利前景，发展“代持股”、“分红股”等销售模式，四处发展下线，在全国发展会员11.7万余人，吸收传销资金10亿余元。

**陕西宣布取缔网贷业务**

2020年3月15日，陕西省地方金融监督管理局发布《网络借贷行业风险提示函》称，按照国家统一部署，陕西省持续开展网络借贷风险专项整治，截至目前，注册在陕西省的19家网贷机构均未完全符合“一个办法三个指引”要求，并均未通过省互金整治办和省网贷整治办检查验收。

  

陕西金融局称，网贷机构停发新标，不影响已签订借贷合同的借贷双方有关权利义务，借款人应继续履行还本付息义务，存在恶意逃废债行为的借款人将会对自身信用造成不良影响。

  

**GitHub收购npm**

2020年3月17日，全球最大的代码托管平台GitHub发布公告称，该公司已经签署了一份收购npm的协议。收购完成后，用户可以继续免费使用npm公共注册表，付费用户可以在不久之后将私有npm包迁移到 GitHub Package。GitHub表示，打算将其打赏功能（GitHub Sponsors）扩展到npm的生态中。对于付费使用npm Pro、Teams、Enterprise的私人注册表用户，GitHub和npm也将继续支持。

  

**微软谷歌等联手打击新冠疫情虚假信息**

2020年3月17日，微软、谷歌、Facebook、Twitter以及Reddit等公司日前宣布，他们正在联手提供有关新型冠状病毒肺炎的准确信息。微软旗下职业社交网站LinkedIn和谷歌旗下视频平台YouTube也加入了该行动。这些公司发布的联合声明指出：“我们正在帮助数百万人保持联系，同时共同打击有关新冠病毒的欺诈和错误信息，在我们的平台上提供权威内容，并与世界各地的政府医疗机构协调分享更新的关键信息。”

  

**首个新冠血型感染研究发布**

2020年3月17日，国内8所科研机构联合完成了最新新冠病毒研究并发表，研究主要探讨ABO血型与COVID-19易感性的关系。初步分析得出的结论是：A型血患者更易感染，O型血相对风险较低，AB型血和B型血的结果没有达到统计学意义，是否易感COVID-19，还不能就此得出明确结论。另外，统计结果显示，ABO血型分布在不同年龄组、不同性别之间没有太大变化。也就是说，年龄、性别与COVID-19的易感性没有什么关联。
