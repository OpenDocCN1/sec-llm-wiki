# 天水侦破冒充领导诈骗案丨李沧打掉洗钱犯罪团伙——涉网犯罪每日情报

***案件打击***

  

**揭阳警方破获网络交友诈骗案**

近日，广东省揭阳市公安局空港区分局登岗派出所破获网络交友诈骗案，民警抓获嫌疑人1名。

  

经审讯，嫌疑人郑某供述，在微信上伪装成一名女大学生，与颜某进行交友并发展为情侣，后以交房租、买东西、日常开销等向颜讨要财物，至今通过微信红包和转账方式向对方收取2万多元和手机、首饰等物品的犯罪事实。目前，案件正在进一步办理中。

  

**天水警方侦破冒充领导诈骗案**

近日，甘肃省天水市公安局麦积区分局侦破冒充领导诈骗案，警方辗转广东东莞、肇庆、中山、珠海、佛山、深圳、汕头，浙江义乌等省市，成功抓获犯罪嫌疑人13人，扣押银行卡30余张、冻结涉案资金账户20余个、追回资金15万元。目前，案件正在进一步办理之中。

![](../Images/dea3ef3739cd1453bd5085de9854a5aa.png)

  

**黄石警方打掉涉嫌“帮信”犯罪团伙**

2021年8月30日，湖北省黄石市公安局黄石港区分局花湖派出所打掉涉嫌“帮信”犯罪团伙，民警在黄石及武汉抓获嫌疑人9名，涉案金额达1500余万，非法获利110万，涉案银行卡账户200余个。

  

经审讯，嫌疑人连某、施某供述，勾结串联境外电信诈骗人员，在多地利用当地中介卡头，将辖区居民利诱至事先开好的宾馆内，替境外电信诈骗团伙跑分洗钱。至案发，涉案金额已达1500余万，该团伙非法获利110万。目前，案件正在进一步办理中。

![](../Images/b2195be14a96fdcd0ee763013d93720d.png)

  

**顺平警方破获冒充领导网络诈骗案**

近日，河北省保定市顺平县公安局破获冒充领导网络诈骗案，民警奔赴山西、唐山、宁波等地先后抓获嫌疑人5名。

  

经查，该团伙以“领导”的名义添加受害人微信，经过一阵嘘寒问暖后，便以需要周转资金为由让受害人向对方账户内转账40万元钱，得手后将其拉黑。目前，该案正在进一步的侦办当中。

![](../Images/2ebd700de1d5efd0f96d31f7e91d0117.png)

  

**合肥警方侦破冒充**

**教师收费网络诈骗案**

2021年8月29日，安徽省合肥市公安局侦破冒充教师收费网络诈骗案，专案组在广西省南宁市和宾阳县等地先后抓获实施诈骗的嫌疑人10名，初步核实涉及安徽、湖北、四川、江苏等地50多位家长被骗案件。

  

经查，该团伙盗用老师QQ号，在家长群内发布“报名信息”，以缴纳学费、书本资料费、校服费等费用为由，要求学生家长向指定账户转账或扫二维码付款实施诈骗。目前，案件正在进一步侦办中。

![](../Images/4a440d9394dba1cccd5234f900d93fa9.png)

  

**李沧警方打掉洗钱犯罪团伙**

近日，山东省青岛市公安局李沧区分局天水路派出所打掉洗钱犯罪团伙，民警远赴广东汕头抓获嫌疑人8名，初步统计，该案涉案流水高达8000余万元，共计破获电信诈骗类案件10余起。

  

经查，嫌疑人通过在各地高价收购银行卡、手机卡，为电信网络诈骗犯罪团伙提供“洗钱”服务。目前，案件正在进一步办理中。

![](../Images/1008c21ffc448bcd9271623ac89d880a.png)

  

**长春警方破获电信诈骗案**

近日，吉林省长春市公安局莲花山分局破获电信诈骗案，民警共抓获嫌疑人21人，捣毁2个电信诈骗窝点，扣押作案手机35部、电话卡100余张、电脑19台。

  

经查，该诈骗团伙非法购买公民个人信息，联系上线提供诈骗QQ群号码，招聘员工专人培训后每天向全国各地拨打数万个诈骗电话，受害人遍布全国。目前，案件正在进一步侦办中。

![](../Images/1177ae9bd48805e33091b5a13b6a6c90.png)

  

**重庆警方打掉洗钱犯罪团伙**

近日，重庆市公安局九龙坡区分局二郎派出所打掉洗钱犯罪团伙，民警抓获嫌疑人8名，当场查获大量用于转账的银行卡、手机和微信支付宝账号等作案工具。

  

经查，嫌疑人代某发现，利用银行卡帮人转账可以收取每笔4%的高额手续费，便大肆纠集他人，通过各种渠道搜罗银行卡和各类移动支付的帐号密码来转账牟利，共通过转帐“洗白”的电诈赃款已达400万以上，该团伙获利近20万元。目前，案件正在进一步侦办中。

![](../Images/f079bad2a769bb92dd0869231a03500a.png)

  

**唐山警方破获跑分洗钱案**

近日，河北省唐山市公安局路北区分局破获跑分洗钱案，民警抓获嫌疑人周某、徐某抓获。

  

经审讯，嫌疑人周某供述，自今年2月份开始从事网络“跑分”洗钱犯罪活动，涉案电诈赃款共计人民币1.25亿元；犯罪嫌疑人徐某帮助周某操作平台，并提供银行卡供周某使用。目前，案件正在进一步侦办中。

![](../Images/5394672abd1fb691b48a1ac0ec0f7a86.png)

  

***热点事件***

  

**公安机关深入推进**

**“净网2021”专项行动**

2021年9月2日从公安部获悉，今年以来，全国公安网安部门按照公安部党委部署要求，紧密结合党史学习教育和“我为群众办实事”实践活动，深入推进“净网2021”专项行动，对群众深恶痛绝的利用手机卡开卡环节恶意注册、出售网络账号的违法犯罪活动进行依法严厉打击，取得阶段性成效。

  

截至目前，共抓获违法犯罪人员1.6万余名，对其中6700余人采取刑事强制措施，有力维护了人民群众合法权益。

  

**安徽8月份依法处置一批**

**违法违规网站和账号**

8月，安徽网信系统突出暑期时间节点，联合省直相关单位，深入开展未成年人网络环境专项行动，集中整治影响青少年身心健康、妨碍青少年上网学习的突出问题，全面清理低俗色情、校园霸凌、暴力血腥、封建迷信等违法不良信息，奋力为广大青少年营造积极健康的网络空间。

  

省网信办会同省通信管理局，依法查处违法违规网站33家，协调有关平台依照用户服务协议关闭或禁言账号63个，移送违法违规线索85件，清理涉未成年人网络违法和不良信息8953条。

  

根据网民举报及巡查发现，“首页官网”“技术小站”等21家网站传播赌博色情等违法违规信息，被依法注销备案；六安、亳州、滁州、芜湖等市网信部门严格落实属地管理责任，依法约谈霍山论坛网、“涡阳论坛”微信公众号、“凤阳老乡圈”微信公众号、“芜湖身边事”微博账号等负责人31人次。宿州等市网信部门责令“爱游盟”等12家违法违规网站自行注销备案。
