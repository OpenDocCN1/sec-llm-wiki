用法：

C:\\Users\\Administrator\\Desktop>fastir\_x64.exe -h

usage: fastir\_x64.exe \[-h\] \[--packages PACKAGES\] \[--output\_dir OUTPUT\_DIR\]

                      \[--output\_type OUTPUT\_TYPE\] \[--dump DUMP\]

                      \[--profile PROFILE\] \[--homedrive HOMEDRIVE\]

  

FastIR

  --packages PACKAGES   List of packages all,memory,registry,evt,fs,health.

                        And advanced packages: filecatcher,dump use:

                        --packages all or --packages fs,memory

  --output\_dir OUTPUT\_DIR

                        Output directory path

  --output\_type OUTPUT\_TYPE

                        Specify output format (json or csv)

                        functionalities, --dump list
