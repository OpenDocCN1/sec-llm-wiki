# 衡南捣毁GOIP犯罪窝点丨浙江破获特大虚假投资诈骗案——涉网犯罪每日情报

***案件打击***

  

**沐阳警方捣毁“两卡”犯罪团伙**

近日，江苏省宿迁市沐阳县公安局捣毁3个“两卡”犯罪团伙，抓获犯罪嫌疑人17人，斩断了非法贩卖“两卡”的黑灰产业链，有效保护了群众的合法权益。

![](../Images/2147421e586191a060f7474bb6d0bdf2.png)

  

**根河警方破获电信网络诈骗案**

近日，内蒙古呼伦贝尔市根河市公安局反诈中心民警横跨5省3市，成功破获一起涉案250余万元的电信诈骗案，抓获犯罪嫌疑人7名，缴获涉案手机9部、涉案银行卡25张。目前，案件正在进一步深挖侦办中。

![](../Images/512d5fd8872d6f9c4834042093e8b373.png)

  

**衡南警方捣毁GOIP犯罪窝点**

近日，湖南省衡阳市衡南县公安局刑侦大队、茅市派出所联手捣毁一处放置GOIP犯罪窝点，抓获犯罪嫌疑人3名，缴获GOIP设备一套、手机卡51张。

  

经查，该团伙从手机卡贩处大量购买手机卡，驾驶车辆流窜放置GOIP设备，为缅北诈骗团伙提供话务支撑。目前，案件正在进一步侦办中。

![](../Images/766ffb7b980b01a6249b375d56e804a6.png)

  

**南岔警方打掉“洗钱”犯罪窝点**

近日，黑龙江省伊春市南岔县公安局打掉一个“洗钱”窝点，警方奔赴陕西省西安市、渭南县，抓获犯罪嫌疑人7名，查获涉案手机卡和银行卡40余张、作案手机12部。

  

经审讯，该团伙对与境外电诈犯罪嫌疑人通过网络勾连，组织无业青年通过银行卡、微信等社交软件“洗钱”的犯罪事实供认不讳。目前，案件仍在继续工作中。

![](../Images/aaccccc455e078a4feff681463a68221.png)

  

**凌云警方破获电信诈骗案**

近日，广西百色市凌云县公安局成功破获一起电信诈骗案，警方奔赴四川省成都市，抓获犯罪嫌疑人2人，扣押作案手机6部、银行卡11张。目前，案件还在进一步侦办深挖当中。

![](../Images/331e518bc86a36639b956d7933f251eb.png)

  

**浙江警方破获特大虚假投资诈骗案**

近日，浙江省金华市公安局破获一起境外特大虚假投资诈骗案，抓获犯罪嫌疑人452名，查封房产6套，扣押豪车3辆。

  

该案侦查共历时6个月，串并全国案件676起，案值1.57亿元，团伙头目及主要成员均系东南亚某国电诈窝点回流的犯罪嫌疑人。

  

经查，该团伙通过拨打电话以股票投资的名义引诱事主加入荐股群，前期以指导老师上课预测股票涨停骗取信任，后以该虚假股票投资平台高额收益为诱饵，诱导事主下载该APP进行转账投资，在骗取大量资金后直接关闭平台。

![](../Images/ebbbc21347c0d46082c7fd5fadc842f8.png)

  

**长白警方破获新型网络诈骗案**

近日，吉林省白山市长白县公安局成功破获一起新型网络诈骗案件，抓获犯罪嫌疑人4人。

  

经审讯，犯罪嫌疑人对利用虚拟货币搬砖盈利的虚假信息，引诱被害人投资，后骗取被害人钱款的犯罪事实供认不讳。目前，案件正在进一步侦办中。

![](../Images/60fe2bada0958e0e15f989a0d963c969.png)

  

**荷塘警方捣毁帮助信息网络犯罪团伙**

近日，湖南省株洲市公安局荷塘区分局反电诈中心联合月塘派出所成功捣毁涉嫌帮助信息网络犯罪团伙，抓获犯罪嫌疑人7名。

  

经查，文某某自今年以来组织刘某、陈某等人利用其名下银行卡，帮助境外诈骗团伙“跑分”，金额高达上千万。目前，案件正在进一步侦办中。

![](../Images/29ae68075506a6cd9a4b12547658f934.png)

  

***反制动态***

  

**娄星区打击治理电信网络新型**

**违法犯罪中心正式揭牌成立**

2021年6月16日，湖南省娄底市娄星区打击治理电信网络新型违法犯罪中心在娄底市公安局娄星分局刑侦大队正式挂牌成立。娄底市公安局娄星分局政委李建中、副局长周志林与娄星区委国安办副主任王黎丽共同为该中心揭牌。娄星区打击治理电信网络新型违法犯罪工作联席办，分局刑侦大队及网安大队，中国电信、移动及联通三大运营商，中国建设银行、中国农业银行、中国银行以及招商银行等九大银行正式进驻该中心。

  

该中心分别设置了资金流区、信息流处置区、综合研判处置区、反欺诈防范区等4个功能区，建立完整的预测预警、宣传防范、紧急处置、合成研判、落地打击工作机制以及反电信网络诈骗工作运转流程，是资源整合的数据中心、研判打击的指挥中心、科技手段的支撑中心、新型犯罪的研究中心、反诈防骗的宣传中心、部门联动的协调中心，是集风险研判、诈骗预警、最新骗局曝光、侦查宣传等功能于一体名副其实的反诈“战斗机”，它的成立吹响了娄星区电信网络诈骗“集中歼灭战”的冲锋号。

  

该中心将充分发挥“六个中心”作用，实现警银、警通数据互联互通，建立快速堵截涉案资金、快速拦截诈骗电话、快速预警提醒群众联控机制，最大限度减少和挽回人民群众的财产损失。

![](../Images/26fc18ba3b7046bd6c86d9f28ddfe3a4.png)

  

***热点事件***

  

**公安部新闻发布会通报全国公安**

**机关****深入推进打击治理电信网络**

**诈骗****犯罪的工作举措和成效**

 2021年6月17日，公安部在京召开新闻发布会，通报全国公安机关深入推进打击治理电信网络诈骗犯罪的工作举措和成效等情况。公安部刑事侦查局局长刘忠义、公安部刑事侦查局副局长姜国利、上海市公安局刑侦总队总队长石毅君、浙江省公安厅刑侦总队副总队长王火剑出席并回答提问，公安部新闻发言人李国忠主持。

  

2021年1至5月，全国共破获电信网络诈骗案件11.4万起，打掉犯罪团伙1.4万余个，抓获犯罪嫌疑人15.4万名，同比分别上升60.4%、80.6%和146.5%。成功劝阻771万名群众免于受骗，为群众挽回经济损失991亿元。2021年5月，全国共立电信网络诈骗案件8.46万起，与4月相比下降14.3%，案件持续高发的势头得到了一定遏制。

  

公安部新闻发言人李国忠表示，打击治理电信网络诈骗犯罪，事关人民群众切身利益，事关社会大局稳定，事关国家经济安全，事关党和国家形象。公安机关将毫不动摇坚持依法严打方针，不断把打击治理工作向纵深推进。同时，希望广大媒体广泛宣传，动员人民群众共同努力，坚决打赢这场防诈反诈人民战争。
