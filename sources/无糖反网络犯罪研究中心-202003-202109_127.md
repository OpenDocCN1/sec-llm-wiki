# 岳阳警方侦破特大跨境电信诈骗案丨凌云警方打掉 “民族资产解冻”类诈骗团伙——涉网犯罪每日情报

***案件打击***

  

**岳阳警方侦破特大跨境电信诈骗案**

2021年5月2日至4日，湖南省岳阳市公安局侦破“3.19”特大跨境电信诈骗案，警方奔赴广东、福建两地，抓获犯罪嫌疑人15人，收缴扣押大量电信诈骗设备和赃款赃物。经审讯，该团伙对2020年以来以东南亚某地为据点，对国内公民大肆实施电信诈骗的犯罪事实供认不讳。目前，该案正在进一步深挖侦办中。

![](../Images/dd59fd562f4d18b90d0cd85d1a737e5c.png)

  

**凌云警方打掉**

**“民族资产解冻”类诈骗团伙**

近日，广西百色市凌云县公安局打掉“民族资产解冻”类诈骗团伙2个，抓获嫌疑人10人，扣押涉案现金7万元、车辆2辆、POS机2台、银行卡20张，查实涉案资金200万余元，冻结涉案资金70万元。目前，该案正在进一步深挖侦办当中。

![](../Images/24771cf70415fc8cd352a0eafd839694.png)![](../Images/3f6f07dbef1be2da9796abd7b6a2a468.png)

  

**鄂州警方捣毁“GOIP”犯罪窝点**

近日，湖北省鄂州市公安局鄂城区分局花湖派出所捣毁一个“GOIP”犯罪窝点，抓获犯罪嫌疑人3名，收缴电脑1台、GOIP设备3台、手机19部、电话卡24张。目前，案件正在进一步办理中。

![](../Images/42a5ee2de30c08c8f9ced548388f4995.png)

  

**让胡路警方打掉**

**帮助信息网络犯罪团伙**

近日，黑龙江省大庆市公安局让胡路区分局打掉一个帮助信息网络犯罪团伙，抓获犯罪嫌疑人6名。经审讯，犯罪嫌疑人杨某娟等6人对2021年2月通过抖音认识上家，微信联络，先后以银行卡刷流水、地下钱庄洗钱等理由发展下线，将10套银行卡、电话卡、U盾出租给电信诈骗犯罪团伙，累计转移赃款1000余万元，从中赚取好处费2万余元的犯罪行为供认不讳。目前，案件正在进一步侦破中。

![](../Images/6bc328ea4472e67002b583fe1b443722.png)

  

**上海警方打掉 “帮信”犯罪团伙**

近日，上海市公安局金山区分局成功侦破“断卡”行动以来最大一起GOIP案，打掉2个“帮信”犯罪团伙，警方奔赴河南焦作、江苏无锡等地，抓获犯罪嫌疑人15名，查获GOIP设备15台及13800余张电话卡。目前，案件正在进一步侦查中。

  

![](../Images/eb26c7ff1f927a475bb2fee3db6798b9.png)![](../Images/4d57386bc9f343dd13eacf5da0d1f424.png)

  

**长春警方打掉“洗钱”犯罪团伙**

近日，吉林省长春市公安局成功打掉一个帮助电信网络诈骗组织洗钱的犯罪团伙，抓获犯罪嫌疑人4名，涉案金额近600万元。目前，案件正在进一步工作中。

![](../Images/8a73609f61a0f8da5e4d6fb8dade5fcc.png)

  

**爱民警方打掉“洗钱”犯罪团伙**

近日，黑龙江省牡丹江市公安局爱民区分局刑事侦查大队打掉一个“洗钱”犯罪团伙，警方奔赴辽宁省丹东市、锦州市等地，抓获犯罪嫌疑人5名。经讯问，五名犯罪嫌疑人分别交代了其使用信用卡、POS机、银行卡转账等方式为境外一电信网络诈骗犯罪团伙提供“洗钱”服务，分赃比例按每人每天每张卡500至1500元不等，从事犯罪活动至今，每人每月可最多获利几十万元。目前，案件正在进一步侦办中。

![](../Images/8d0add38a35369cf2a9bf2e86d011c10.png)

  

**兴庆警方破获系列诈骗案**

近日，宁夏银川市公安局兴庆区分局刑事侦查大队成功破获涉嫌网络刷单、投资等系列诈骗案件12起，抓获犯罪嫌疑人1名，涉案金额达100余万元。目前，案件正在进一步侦办中。

![](../Images/5659e97d4059f3c4e53d51f1b4ea7f8f.png)

  

**镇平警方打掉跨境赌博犯罪团伙**

近日，河南省南阳市镇平县公安局成功抓获36名跨境赌博犯罪嫌疑人，查扣作案手机40余台，银行卡40余张，冻结关联银行卡60余张，梳理登记经“代理人”推广参与涉嫌参与跨境赌博人员千余人。经查，涉案平台叫“凤凰彩票”，其服务器设在境外，通过在国内招募代理人，进行虚假推广宣传，“拉人头”参与网络赌博。目前，拘留犯罪嫌疑人31人，逮捕2人。

  

**桂林警方打掉“跑分”犯罪团伙**

近日，广西桂林市公安局成功打掉5个“跑分”窝点，共抓获犯罪嫌疑人22名，查获手机86部、电脑7台、银行卡114张、U盾2个、公章1个。初步查明涉案资金流水超5亿人民币。经审讯，犯罪嫌疑人对他们利用“跑分平台”帮助犯罪团伙进行资金转移活动的犯罪事实供认不讳。目前，案件正在进一步办理中。

![](../Images/c84dbc405ff66468a5c6bc81393ffede.png)

  

**天宁警方摧毁裸聊诈骗团伙**

近日，江苏省常州市公安局天宁区分局摧毁一裸聊诈骗团伙，警方分赴云南楚雄、湖南长沙，抓获犯罪嫌疑人9名，在全国串并案件20余起，涉案资金近千万元。经查，该犯罪团伙采取裸聊过程中录下受害人视频，并以将视频发给其通讯录好友为由向受害人实施敲诈勒索的方式，引诱受害人进行转账。随后通过专业洗钱团伙将涉案资金进行转移。目前，警方正对案件线索进行深挖。

![](../Images/bba2c4c0aff9224ec0daede785df52d4.png)

  

**池州警方侦办跨境赌博案**

近日，安徽省池州市公安局梅龙分局快速侦办一起跨境赌博案，警方奔赴广东、浙江等地，抓获犯罪嫌疑人19人，查封冻结涉案银行卡300余张，冻结涉案资金1300余万元。目前，案件正在进一步侦办中。

![](../Images/d4213bb2609fb142a9a195c028947dd3.png)

  

**和政警方破获电信网络诈骗案**

近日，甘肃省临夏州和政县公安局成功破获一起电信网络诈骗案，警方奔赴湖南、黑龙江等地，抓获犯罪嫌疑人3人。经询问，三名犯罪嫌疑人对自己以办理网络贷款的名义实施诈骗犯罪行为供认不讳。目前，案件正在进一步审理中。

  

***反制动态***

  

**湖南省启动“拒绝跨境赌博”**

**主题宣传周活动**

2021年5月7日，湖南省打击治理跨境赌博机制在长沙市锦泰广场组织举办“拒绝跨境赌博”宣传周启动仪式，并开展为期一周的宣传展，加强常态化社会教育，营造拒赌反赌浓厚氛围。下步，全省打击治理跨境赌博机制将进一步深化打击治理各项措施，持续巩固和扩大战果；进一步总结探索源头治理方式方法，充分发挥机制各成员单位的职能作用，整合资源力量，形成工作合力；进一步协调广大媒体集中宣传报道，阐述跨境赌博违法犯罪行为的危害，引导群众认清赌博本质，远离赌博深渊，全力维护人民群众合法权益和社会稳定。

**广东省启动“拒绝跨境赌博”**

**主题宣传周活动**

***热点事件***

  

**淘宝违禁信息管理规则变更：**

**新增非法资金获取的充值卡类商品**

近日，淘宝官方发布了《虚拟类商品相关规则变更公示通知》，进一步加强淘宝网虚拟类商品市场的管理和引导。此次规则变更于2021年5月7日进行公示通知，将于2021年5月14日正式生效。  

  

据悉本次主要变更点:

1.  调整部分规则表述，使表意更清晰，更易于理解;
    
      
    
2.  《淘宝网数字娱乐行业须提供官方授权的商品目录》调整为《淘宝网须提供官方授权的虚拟类商品目录》，并调整部分商品品类、违规情形、处置力度;
    
3.  新增“通过非法资金或渠道获取的充值卡类商品或充值服务”“利用外挂性质的辅助软件、存档等方式进行游戏代练服务或获取游戏币、游戏道具等虚拟物品”至《淘宝平台违禁信息管理规则》;
    
4.  取消生活服务、网店网络服务、数字娱乐行业的服务评级分数的要求。
    

值得一提的是，《淘宝平台违禁信息管理规则》规则变更后，在涉及欺诈、盗窃、作弊、骚扰他人等商品或服务类要求中，通过非法资金或渠道获取的充值卡类商品或充值服务纳入非法所得的商品范围，这种情形每次扣B类12分。
