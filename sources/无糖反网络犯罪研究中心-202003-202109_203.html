案件打击


蒙城警方摧毁电诈团伙

近日，安徽省亳州市蒙城县公安局摧毁一个利用“网络刷单”实施诈骗的犯罪团伙，抓获犯罪嫌疑人8名。该案不仅抓获了实施电信诈骗作案的“幕后金主”，同时也摧毁了为犯罪提供帮助的“平台搭建”、“开卡”、“贩卡”、“洗钱”、“车手”等相关黑灰产业链，对该犯罪团伙实施了全链条打击。目前，其他在逃人员正在追捕，案件正在进一步办理中。


邓州警方破获帮助

信息网络犯罪活动案

近日，河南省南阳市邓州市公安局赵集派出所破获一起帮助信息网络犯罪活动案，抓获犯罪嫌疑人2名。


经审讯，2020年11月份，嫌疑人高某和杜某将本人身份证办理的银行卡三件套卖给他人使用，给多名受害人造成经济损失。目前，案件正在进一步侦办中。


广州警方打掉涉“两卡”犯罪团伙

近日，广东省广州市公安局从化区分局摧毁了一个非法开办、买卖 “两卡”的团伙，抓获卡商、卡农共8人，初步核实案件27宗。


经审讯，犯罪嫌疑人供认为谋取私利，在从化区组织人员非法开办电话卡、银行卡，以约2000元一套贩卖给卡头，然后输送给境外人员用于实施电信诈骗的事实。目前，案件正在进一步侦办中。


通榆警方破获帮助

信息网络犯罪活动案

近日，吉林省白城市通榆县公安局刑警大队破获一起帮助信息网络犯罪活动案，抓获犯罪嫌疑人2名。


经查，犯罪嫌疑人于某出售各类银行卡、电话卡，为电信诈骗犯罪提供帮助，涉案金额高达70余万元。目前，案件仍在进一步侦办中。


寿阳警方破获帮助

信息网络犯罪活动案

2021年2月19日，山西省晋中市寿阳县公安局破获一起帮助信息网络犯罪活动案，抓获犯罪嫌疑人4名，扣押手机4部、银行卡10余张。


经审讯，该团伙多次利用银行卡用于帮助电信诈骗犯罪团伙进行转账，涉案金额达到300余万元，并从中获利2万余元。目前，案件还在进一步侦办中。


汉中警方破获特大电信诈骗案

2021年2月21日，陕西省汉中市公安局汉台区分局破获一起特大电信诈骗案，警方奔赴湖南长沙、湘潭等地市，抓获犯罪嫌疑人5名。


经查，该团伙通过收买、出售支付宝账户，供洗钱“跑分”团伙使用，从中获利。目前，案件正在进一步侦办中。


广灵警方破获帮助

信息网络犯罪活动案

近日，山西省大同市广灵县公安局成功破获一起帮助信息网络犯罪活动案，抓获犯罪嫌疑人3名。


经审讯，三名犯罪嫌疑人对其从2020年10月以来，通过微信拉人进群帮助实施电信诈骗的犯罪事实供认不讳。目前，案件正在进一步深挖中。


忻州警方破获网络直播电信诈骗案

2021年2月20日，山西省忻州市公安局直属分局成功侦破一起冒利用直播平台实施电信网络诈骗的案件，抓获犯罪嫌疑人1名。


经审讯，犯罪嫌疑人张某龙对其利用短视频直播平台冒充他人诈骗受害人王某新、董某禄等人共计10000余元的犯罪事实供认不讳。目前，案件正在进一步侦办中。


霞浦警方破获冒充领导诈骗案

近日，福建省宁德市霞浦县公安局破获一起冒充领导诈骗案，警方分赴安徽、广西、云南三地，抓获犯罪嫌疑人4名，涉案金额达68万元。


经审讯，四名犯罪嫌疑人对自己出售、收购银行卡，帮助他人进行诈骗、网络赌博等违法犯罪进行资金结算的行为供认不讳。目前，案件在进一步侦办中。


反制动态


跨境赌博首次入刑

从严从快线上线下全面打击

近日，公安部公布了2020年破获跨境赌博案件的成绩单。截至2020年12月底，共破获各类跨境赌博案件3500余起，打掉涉赌平台2260余个、非法技术团队980余个、赌博推广平台1160余个、非法支付平台和地下钱庄1960余个，抓获犯罪嫌疑人7.5万余名。


3月1日起，刑法修正案（十一）将正式施行，跨境赌博首次写进刑法，这意味着，跨境赌博将面临更严厉的打击。

热点事件


奇安信发布春节期间DDoS攻击报告

2021年2月22日，奇安信旗下羲和实验室发布了春节期间DDoS攻击报告。


报告显示，春节期间奇安信星迹DDoS观测系统累计观测到反射放大DDoS 攻击事件 65912 个，涉及被攻击 IP 57096 个。与春节前一周相比，DDoS 攻击事件数增加约 25%，被攻击 IP 数增加 37%。


根据羲和实验室司南平台统计的被攻击 IP 地理分布显示，被攻击 IP 数量排名前五的国家或地区分别是中国香港、美国、英国、中国大陆及法国。


绝大部分（约 68.3%）被攻击 IP 分布于中国香港（被攻击 IP 23731 个，全球占比约 41.6 %）和美国（被攻击 IP 15244 个，全球占比约 26.7%）。中国大陆有 1770 个被攻击 IP。春节假期期间，国内被攻击 IP 主要分布于我国东部及南部省份。


*以上信息由无糖学院反网络犯罪情报研究中心收集提供
