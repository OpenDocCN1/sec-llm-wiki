案件打击


通城警方破获帮助信息网络犯罪案

近日，湖北省咸宁市通城县公安局成功侦破某网络公司帮助信息网络犯罪活动案及网络开设赌场案，警方奔赴湖北、湖南、江苏、浙江、广东、海南、辽宁等7省17市，抓获嫌疑人41人，扣押涉案电脑65台、手机92部，涉案资金超1亿元，冻结资金1500万余元，及时查封“我爱花牌”APP。


目前，通城县人民法院依法对被告单位某网络科技有限公司及许某某等10名主要被告人涉嫌犯帮助信息网络犯罪活动罪一案公开开庭审理，10名被告人均认罪认罚。因该案涉案人员众多，且涉案金额巨大，将择期宣判。下级推广员及其他涉案人员已另案审理。


上海警方捣毁“杀猪盘”诈骗团伙

近日，上海市公安局嘉定区分局捣毁一个以炒股投资为名的“杀猪盘”电信诈骗犯罪团伙，警方奔赴湖北省武汉市，在当地警方的大力配合下，抓获犯罪嫌疑人71名。据初步调查，该案受害人分布在全国各地，涉案金额达600余万元。目前，案件正在进一步侦查中。


森林警方破获电信诈骗案

近日，甘肃省森林公安局白龙江分局成功破获“12·22”电信诈骗案，警方奔赴广西，抓获犯罪嫌疑人4名，扣押涉案POS机7部、银行卡40余张、平板电脑1部、手机7部、假公章4枚，冻结赃款17万余元。目前，此案正在进一步侦办中。


镇平警方破获帮助信息网络犯罪案

近日，河南省南阳市镇平县公安局枣园派出所成功打掉一专门为跨境赌博平台提供资金流转的犯罪团伙，抓获犯罪嫌疑人5人。


经查，该团伙自2020年10月以来，长期隐蔽在河南省为网络诈骗平台、跨境网络赌博平台提供银行卡服务，涉案金额高达1000余万元，非法获利10余万元。目前，案件正在进一步侦办中。


南昌警方破获帮助信息网络犯罪案

近日，江西省南昌市公安局红谷滩区分局破获一起帮助信息网络犯罪案，警方奔赴广东省，抓获犯罪嫌疑人4名。

反制动态


衡东县公安局反电诈中心揭牌成立

2021年1月20日，湖南省衡阳市衡东县公安局反电诈中心正式揭牌成立，副县长、公安局长农勇，政委洪卫出席仪式并揭牌。在家局党委成员、局属相关单位负责人共计30余人参加仪式。


衡东县公安局反电诈中心从刑侦大队、网安大队和合成作战中心抽调精干警力组成，现有民警5人，职工1人，协警3人，牵头防范打击电信网络诈骗犯罪，为全县公安机关提供信息数据和技术支撑。

热点事件


抖音开展打击诈骗专项行动

近日，抖音数据显示，11-12 月，在“啄木鸟专项行动”中通过自主研发的智能反欺诈系统，结合模型策略，拦截涉嫌诈骗涉嫌诈骗违规行为882397次，封禁涉嫌诈骗帐号184964个，其中涉嫌“杀猪盘诈骗”帐号112726个、涉嫌“购物诈骗”帐号24088个、涉嫌“宠粉诈骗”帐号20763个、涉嫌“刷单诈骗”帐号20031个，其他类别诈骗相关帐号7356个。


针对“杀猪盘”类诈骗行为，抖音表示其研发了新型策略模型，基于异常帐号行为风险识别、内容风险识别以及作弊行为聚集关联性风险识别，从头像、签名、内容、互动等多维度挖掘风险帐号，并结合专家审核团队进行人工判断进行作弊拦截与帐号处罚。


央行征求意见：强化支付领域

反垄断等监管措施

2021年1月20日，央行官网公布《非银行支付机构条例（征求意见稿）》。《条例》共六章，七十五条，强化了公司治理要求，实施全方位、全流程监管；首提支付领域反垄断监管措施，明确界定相关市场范围以及市场支配地位认定标准；并加大对持牌机构为无证经营支付业务的机构提供支付业务渠道行为的处罚力度。


在分析人士看来，此次《条例》标志着数字经济时代我国的非银支付监管进入深化落实阶段，同时提出史无前例的支付反垄断方针，将对整个市场产生深远影响，为促进非银支付行业健康、可持续发展带来积极意义。


Gitee 发布 2020 开源年报

2021年1月21日，代码托管服务码云Gitee发布了2020年的开源年报，报告显示，Java 稳居语言占比第一，小众语言增速迅猛。虽然占比较去年（50%）有不小的下跌， 但 Java 依旧是使用最多的语言(38%)，前五名的语言较去年变化较小，PHP 超越 Python 成为了第三位。


此外，报告显示，Rust 和 Dart 连续2年保持高速增长。而易语言虽登顶增速榜，但其总量与其他语言相比仍非常稀少，与主流编程语言仍有较大的距离。
