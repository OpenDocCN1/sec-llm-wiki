案件打击


广州警方破获网络诈骗案

近日，广东省广州市公安局交通分局破获网络诈骗系列案，警方奔赴广东、湖南、河北、辽宁、黑龙江等地，打掉犯罪团伙1个，抓获犯罪嫌疑人8名，核破案件82宗，缴获作案手机346台、POS机16台等物品，涉案金额1680余万元。目前，该系列案还在进一步调查取证，深挖扩线。


泰州警方捣毁非法贩卖银行卡犯罪团伙

近日，江苏省泰州市公安局海陵区分局成功打掉一非法贩卖银行卡犯罪团伙，抓获犯罪嫌疑人11名。


经查，2019年9月以来，该犯罪团伙非法贩卖银行卡20余张，用于境外实施违法犯罪活动，非法资金流动金额上千万元，获利20万余元。目前，案件正在进一步侦办中。


岳阳警方侦破帮助

信息网络犯罪活动案

近日，湖南省岳阳市岳阳县公安局筻口中心派出所在经侦大队和网技大队的大力协助下，成功侦破一起帮助信息网络犯罪活动案，警方奔赴广东省东莞市，抓获犯罪嫌疑人3名。目前，案件正在进一步侦查中。


通许警方破获帮助

信息网络犯罪活动案

近日，河南省开封市通许县公安局四所楼派出所会同厉庄派出所、邸阁派出所，成功破获一起帮助信息网络犯罪活动案，警方奔赴云南省临沧市，抓获犯罪嫌疑人5名。


经审讯，段某等5名犯罪嫌疑人对涉嫌帮助跨境网络赌博的犯罪事实供认不讳。目前，案件正在进一步办理中。


武汉警方打掉电信网络诈骗团伙

近日，湖北省武汉市公安局江夏区分局大桥派出所打掉一个诈骗团伙，抓获犯罪嫌疑人4名，查获用于实施诈骗的数台办公电脑、大量银行卡和话术本、收入登记表等资料。


经查，该团伙利用被骗的受害人急于追回损失的迫切心理，在百度贴吧等平台广泛发布帮助客户成功维权的虚假广告，植入微信、QQ帐号等联系方式，在朋友圈和空间编造成功追回被骗资金的照片、截图。


通过精心编写的话术伪装成为专业维权的资深律师团队，一旦有人主动联系上他们，就会进入他们精心打造的陷阱。目前，案件正在进一步办理中。


湘阴警方破获“杀猪盘”诈骗案

近日，湖南省岳阳市湘阴县公安局破获一起“杀猪盘”诈骗案，警方奔赴广东省，抓获犯罪嫌疑人1名。


经查，2020年7、8月份，嫌疑人李某伙通过引流平台诱导受害人添加其同伙（均已到案）伪装成的女性微信号，再利用事先准备好的话术剧本与受害人聊天获取信任，确定“暧昧关系”或“恋爱关系”后，以过生日、发生事故等理由向受害人索要微信红包或转账，以此实施诈骗。


经查实，该团伙累计作案12起，涉案金额130000元。目前，案件正在积极侦办中。


临澧警方摧毁特大电信网络诈骗团伙

近日，湖南省常德市临澧县公安局在市公安局反电诈中心的大力支持下，摧毁一个特大电信网络诈骗团伙，警方远赴天津市、河北省、北京市、湖南省保靖县、黑龙江省等地，抓获非法买卖银行卡四件套、非法提供银行卡等信息的犯罪嫌疑人11人，查获银行卡四件套177套，涉案金额流水高达3亿多元。目前，该案仍在进一步调查之中。


相山法院宣判特大跨境电信诈骗案

2020年12月31日，安徽省淮北市相山区人民法院公开宣判7·12特大跨境电信诈骗案。


经审理查明，2018年5月至2019年9月期间，被告人方某、姚某某、秦某等人结伙分别中国武汉和柬埔寨金边市以公司、部门、团队形式，招募成员分别担任直播间讲师、业务员、管理人员等职务，组成电信网络诈骗集团，使用U-COIN、V-COIN 、FHEX、Coinearn、BtcGet等平台，以投资ICCT、SIT、SDS、DCRC、SOOT、GHCC等虚拟币的名义，针对中国公民实施电信网络诈骗活动。该犯罪集团在柬埔寨金边和武汉对中国公民实施电信诈骗，涉案金额达3000余万元。


相山区法院对张某飞等79名被告人以诈骗罪分别判处十二年六个月至三年不等有期徒刑，并处人民币一百二十万元至五万元不等罚金；违法所得依法予以追缴，退赔被害人损失；扣押的作案工具依法予以没收。

虾米音乐：2月5日0点起停止音乐服务

2021年1月5日，虾米音乐发布官方公告表示，由于业务调整，2021年2月5日0点停止虾米音乐服务。虾米官方对此回应称，虾米音乐未来将转向更多音乐商业场景服务，“我们将依托新成立的‘音螺’平台持续探索创新，服务音乐人及业内合作伙伴。” 


虾米音乐2006年诞生于杭州，前身叫EMUMO，后更名虾米网、虾米音乐。2013年，虾米音乐被阿里巴巴收购，2015年虾米音乐与天天动听合并组建成阿里音乐，两款产品继续打差异化路线，2016年，天天动听正式更名为阿里星球。


2019年9月，网易云音乐获得阿里巴巴、云锋基金等共计7亿美元融资，这被认为是虾米音乐将会被阿里巴巴放弃的信号。不过，网易云此次融资后，网易公司仍单独享有对网易云音乐的控制权。


GitHub 公布年度开发者报告

2021年1月4日，GitHub 公布年度开发者报告，报告显示，目前 GitHub 平台拥有 5600 万名开发者，今年增加的人数大约 1000 万左右，预计未来 5 年内，这一数字也将翻倍增长，2025 年达到 1 亿人以上。


从地理分布来看，美国以 22.7% 的比例占据全球最大开发者来源的位置，但相比 2015 年的 30.4% 有所下降，占比 9.76% 的中国与占比 5.2% 的印度正快速追赶，GitHub 预计 2030 年情况会发生逆转，中国成为全球最大开发者来源。


在开发语言受欢迎程度方面，JavaScript 依然是最受欢迎的开发语言；在去年超越 Java 成为第二名的 Python 今年也保住了这个名次；TypeScript 在这一年来迅速蹿升 3 名，成为第四热门开发语言。
