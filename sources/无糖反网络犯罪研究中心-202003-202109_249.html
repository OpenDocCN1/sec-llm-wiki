一个难题挡了我很久，说给你们听听：是一个“SMDDoor”，git上这么描述，“The proof-of-concept smbdoor.sys driver is a silent remote backdoor that does not bind new sockets or perform function modification hooking. Instead it abuses undocumented APIs in srvnet.sys to register itself as a valid SMB handler. It then listens on the already-bound ports 139/445 for special packets in which to execute secondary shellcode. In several ways, it has similarities with DoublePulsar and DarkPulsar, as well as ToxicSerpent.”。

一、环境、程序


地址：https://github.com/rootm0s/WinPwnage


这是一个py程序，基于py2和py3的，

如果是2，要pip install -r requestments.txt；

如果是3且低于3.4的，同上；如果高于，则不需要；


这个py程序可以打包成exe可执行文件，如下操作：

pip3 install pyinstaller

pyinstaller --onefile main.py



二、相关运行


1、参数



分别有：

--scan，扫描；

--use，运用；

--id，方法号码；

--payload，载荷；



2、三大功能：UAC、Persist、Elevate；

以scan为例，

1）main --scan uac


2）main --scan persist


3）main --scan elevate
