# 神器：Pcap包分析工具BruteShark

   在流量分析这块，没介绍过什么工具；近日，发现一款流量分析神器工具BruteShark，推荐给大家。  

  

    BruteShark是一种网络取证分析工具（NFAT），可以对网络流量（主要是PCAP文件）进行深度处理和检查。它包括：密码提取、构建网络地图、重建TCP会话、提取加密密码的哈希值，甚至将其转换为Hashcat格式，以进行离线穷举攻击。

  

    有两个BruteShark版本，一个基于GUI的应用程序（Windows）和一个命令行界面工具（Windows和Linux）。

  

    该项目的主要目标是为安全研究人员和网络管理员提供解决方案，使他们能够进行网络流量分析，同时努力找出可能被潜在攻击者用来访问网络关键点的弱点。同时在CTF比赛中对数据包的分析中提供巨大的帮助。

**3、软件功能：**

1)提取和编码用户名和密码（HTTP，FTP，Telnet，IMAP，SMTP ...）；

![](../Images/616f772adabaf771a4379f42a41b4f79.png)

  

2)提取身份验证哈希并使用Hashcat（Kerberos，NTLM，CRAM-MD5，HTTP-Digest ...）对其进行破解；

![](../Images/e387e61aacb2c61df153c9266fddff74.png)

  

这两个模块负责提取和编码用户名和密码以及身份验证散列。实际上，模块负责更新两个显示表，即密码表和散列表。虽然用户名和密码可以直接使用，但哈希最常用于更复杂的攻击，比如“传递哈希”(pass-the-hash)或强迫它们获取密码。BruteShark 与 Hashcat 集成，因此所有提取的散列都可以转换为 Hashcat 输入文件。

  

3)建立可视化网络图（网络节点和用户）；该模块负责通过识别网络中的组件以及它们之间的连接来建立网络地图。可以将网络地图导出到 JSON 格式，以便使用 “图数据库 Neo4j” 等外部工具进行分析。

![](../Images/5ec493a6f1a9be296e444f7da2612cbf.png)

  

![](../Images/66814c542c29318a9e636ca2331196a3.png)

  

4)重建所有TCP会话；

![](../Images/f2b0bed56b553cb86f1da3ce07616d7b.png)

  

5)文件（图片等）提取；模块试图从 UDP/TCP 会话中提取文件(因此，请注意，为了使这个模块有效，应该打开“ Build TCP session”/“ Build UDP session”)。

  

![](../Images/08ace0223481589974c6ae72b96838d3.png)
