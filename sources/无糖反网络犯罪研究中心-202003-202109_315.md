# 【一线直击】恒山公安分局侦破非法利用信息网络制售假证案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMzkzNDA1Mg==&mid=2247486476&idx=2&sn=70ad550c2348d90130f7d0988a992555&chksm=9b9a4087acedc991c7956e148747e55a8c55beeacca8711377c1a8b2167761e263bcbd00267f&scene=126&sessionid=1681279759#rd](http://mp.weixin.qq.com/s?__biz=MzAxMzkzNDA1Mg==&mid=2247486476&idx=2&sn=70ad550c2348d90130f7d0988a992555&chksm=9b9a4087acedc991c7956e148747e55a8c55beeacca8711377c1a8b2167761e263bcbd00267f&scene=126&sessionid=1681279759#rd)

# 9月22日，恒山公安分局成功侦破“20200822”非法利用信息网络制售假证案，打掉了一个横跨湘、粤、苏、沪四省的涉嫌制贩假证犯罪团伙，斩断了一条利用制贩假证非法牟取利益的链条。  

  

![](../Images/96e7811419b88460687dea8647409d5b.png)

  
今年8月份，恒山警方发现，有人能通过网络办理假证件。经进一步核实，在浏览某生活服务类网站时，发现一条办证信息，信息中留有办证联系微信，添加该人微信后，办证人声称可以不用考试直接办理各种证件，并可在政府相应网站进行验真。  
警方凭借职业敏感认为：这极有可能是一起利用制贩假证非法牟取利益的犯罪链条。分局领导立即指派精干警力对该线索开展网上侦查。在前期侦查的基础上，民警果然又发现一个利用互联网发布虚假广告。该网站以免考拿证为由办理多种虚假特种行业从业证书，并以“可在政府网站查询到证书编号”为诱饵，公开贩售假证牟利。  

![](../Images/25878112b98a6b74e1daed4f2381264e.png)

  
侦查中发现，该制售假证团伙极其老道狡猾，善于在虚拟的网络世界中隐藏自己。在接下来的侦查工作中，专案民警运用各自专长，从不同方面角度进行分析研判，并进行案件会商，终于找到了嫌疑人的蛛丝马迹，很快掌握了以湖南人颜某为首的网络制售假冒特种行业证件的违法犯罪证据。  
该团伙由运营人员、网站制作及维护人员、验真二维码制作人员、下线代理人员、制证信息推广等人员组成，通过网上虚假宣传，吸引特种行业从业人员前来办理证件非法牟利。  
仅在2018年以来，犯罪嫌疑人在广东东莞、湖南郴州等地制作假证，办理假冒特种行业证件6万余个，非法获利数百万元。他们为骗取受害人信任，嫌疑人制作了“国家安全生产证书查询系统”、“ 国家应急管理部特种作业查询系统【官网】”、“国家应急管理部特种作业考核平台”等10余个仿冒国家政府机关网站，并将制证人员信息录入仿冒网站供受害人查询。  

![](../Images/35442f9a59259774b4119a876b8b250b.png)

![](../Images/cbd1771a8b52180a6af6110076e16581.png)  
9月15日，恒山公安分局多个抓捕小组奔赴湖南郴州、湖南湘潭、广东东莞、江苏太仓、广东广州等地开展摸排工作。由于该团伙成员联系十分密切，抓捕环节如果团伙内有一人漏网，其他犯罪成员便会立即四散躲藏，这给抓捕工作带来很大困扰。经过大量工作，警方终于掌握了该团伙全部成员活动规律及其落脚点，抓捕时机已经成熟。22日，在专案组领导统一指挥和当地警方积极配合下，收网行动共抓获犯罪嫌疑人10人，扣押手机31部、电脑18台、平板电脑5台、制证机2台、扣押资金90余万元，扣押假证及半成品1300余个，涉案金额5000余万元。其中，该网站制作及维护，验真二维码、验真公众号制作人员等“一条龙”网络犯罪活动的主要嫌疑人全部到案。至此，一个横跨湘、粤、苏、沪四省的涉嫌制贩假证犯罪团伙被彻底摧毁。
