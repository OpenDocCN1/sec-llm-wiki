案件打击




乐陵警方侦破特大电信诈骗案

近日，山东省德州乐陵市公安局成功侦破一起特大电信诈骗案，抓获犯罪嫌疑人1名，涉及案件180余起。经审讯，自2015年开始，犯罪嫌疑人李某通过为他人办理贷款以缴纳保证金，包装费，手续费为由实施诈骗。目前，案件正在进一步审理中。


湛江警方捣毁特大网贷诈骗团伙

近日，广东省湛江市公安捣毁2个特大网贷诈骗团伙，抓获嫌犯161人，刑拘116人，捣毁犯罪窝点5个，初步止付涉案资金近千万元人民币。


经查，以林某、莫某为首的2个诈骗团伙在湛江和广州分别开设“湛江某文化传媒有限责任公司”、“广东某网络科技有限公司”等5家互联网公司，在网上推广虚假贷款、投资理财诈骗等网站，引诱网民进入网站贷款，从而实施诈骗。目前，案件还在进一步审理中。


伊通警方破获民族资产解冻类诈骗案

2020年7月29日，吉林省四平市伊通县公安局辗转杭州、温州、金华、永康、瑞安等地，成功破获一起民族资产解冻类诈骗案，抓获犯罪嫌疑人6人。


经查，2017年至2019年期间，该团伙以解冻皇家国外遗产为名，大肆开展民族资产解冻诈骗活动，并通过微信群发展会员，收取每名会员几十元到几百元不等会费，涉案资金流水近百万元。目前，警方依法对6名嫌疑人刑事拘留。


玉林法院警宣判“斑美拉”特大传销案

2020年8月4日，涉案超43亿元人民币的“斑美拉”特大传销案，在广西玉林市玉州区人民法院一审宣判。


法院审理查明，2014年12月至2018年10月案发，余石容与闭何成经谋划后，在香港注册成立亚洲斑美拉美容养生机构有限公司，申请注册“容玺”商标，以销售“容玺排毒套餐”、“容玺护肤套餐”美容产品为由，建立加会员、拉人头、发展层级下线、限定进货量做不同等级代理、通过其上下层级购买产品提获报酬的传销模式。


法院依法判决，余石容等19名被告人因犯组织、领导传销活动罪，分别被法院判处有期徒刑12年至2年不等的刑罚，并处罚金人民币总计超2.7亿元，依法没收财产约7亿元，追缴后上缴国库。


盘山警方侦破“7.09”电信诈骗案

2020年7月29日，辽宁省盘锦市盘山县公安局分赴福建省泉州市和龙岩市展开抓捕行动，在当地警方的帮助下，成功抓获犯罪嫌疑人7名，扣押笔记本电脑4台、手机20部、银行卡20张，共冻结涉案资金85万元。


经审讯，该团伙利用他人银行卡、支付宝等支付结算工具，为电信诈骗等犯罪团伙转账1000余万元。目前，案件正在进一步审理中。


盐湖警方打掉“跑分”洗钱犯罪团伙

2020年7月30日，山西省运城市盐湖区公安分局打掉一个通过“跑分”平台为非法交易提供支付、结算渠道的犯罪团伙，抓获犯罪嫌疑人11人，扣押各类支付账户及银行卡300余个，作案手机60余部，涉案流水达5000余万元。


经查，2019年以来，犯罪嫌疑人许某、吴某等人介绍联系开始为某平台进行“跑分”洗钱等活动，该团伙以游戏工作室名义发展多名下线人员通过收买和代办等手段，使用他人信息注册的对公账户、第三方支付账户及银行卡、U盾、电话卡等，为平台“跑分”洗钱活动提供帮助。目前，案件正在进一步侦办中。


“鲁易购”传销案一审宣判

近日，山东省临沂市兰陵县人民检察院对外披露“鲁易购”传销案一审判决书。兰陵县人民检察院指控：2016年4月，沈德同等人成立鲁某道集团，通过山东省鲁某购电子商务有限公司对社会公开发布“鲁某购大众电商创业项目”，以许诺高额回报的方式进行宣传，要求参加人员通过投资一定数额资金成为鲁某购商城会员后，再以购买易铺宝的方式盈利。


同时，鼓励会员通过发展下线的方式拉拢其他人员进行投资，根据会员发展下线的人数及所发展下线人员的投资数额，获得对应级别的津贴、收益。


法院依法判决，被告人谭某珍犯组织、领导传销活动罪，判处有期徒刑三年九个月，并处罚金人民币十万元，依法追缴被告人谭某珍违法所得人民币2414485.20元，并予以没收，上缴国库。


石首警方打掉特大电信跨境诈骗团伙

2020年7月24日，湖北省石首市公安局组织警力分赴天津、河南等地，一举将境外从事电信诈骗案的4名嫌疑人抓获归案，打掉一个涉案价值过千万元的特大部督、跨境电信诈骗团伙。


经审查，该团伙在菲律宾针对国内股民实施荐股“杀猪盘”式电信诈骗，作案40余起，涉案资金1000余万。目前，案件在进一步深挖中。


宝应警方破获特大系列通讯网络诈骗案

近日，江苏省扬州市宝应县公安局成功摧毁一个通讯网络诈骗团伙，破获案值达数千万元的特大系列通讯网络诈骗案件，串并案件外省、市案件15起，现已抓捕犯罪嫌疑人11人。


经审查，该团伙是以游某为首，伙同张某、全某、李某等人组成的一个通讯网络诈骗团伙，以网贷、快递配送等为由，通过注册空头公司、租用他人银行卡和支付宝、网络购买账号等方式，实施诈骗，涉案资金高达数千万元。目前，案件在进一步深挖中。

黑莓推出开源逆向工程工具

近日，黑莓方面宣布推出一个新的开源工具“PE Tree”，旨在减少逆向工程恶意软件所需的时间和精力。


该公司表示，PE Tree 使得逆向工程师可以使用 pefile 和 PyQt5 在树状视图中查看可移植可执行（Portable Executable，PE）文件，从而降低了从内存中转储和重建恶意软件的门槛，同时提供了社区可以建立的开源 PE 查看器代码库。


PE Tree 还与 HexRays 的IDA Pro 反编译器集成在一起，从而可以轻松导航 PE 结构，以及转储内存中的 PE 文件并执行导入重建，在识别和阻止各种恶意软件方面至关重要。


该工具采用 Python 开发的，并支持Windows、Linux 和 Mac 操作系统。它可以作为独立应用程序或 IDAPython 插件安装和运行，从而使用户可以检查任何可执行的 Windows 文件并查看其组成。
