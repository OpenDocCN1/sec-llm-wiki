***案件打击***

  
  

  

**虎门警方打掉“网络交友”诈骗团伙**

2020年6月，广东省东莞市虎门镇公安分局打掉一个诈骗团伙，抓获犯罪嫌疑人44名。

  

经查，该团伙利用微信、QQ等社交软件，通过“摇一摇”、“寻找附近的人”等方式，冒充女性身份添加陌生男子为好友，与男子聊天拉近关系并发展网上男女朋友关系。取得被害人信任后，嫌疑人便以生活所需或生病买药等各种理由向被害人索要钱财，实施诈骗。目前，案件正在进一步侦办深挖中。

  

**内蒙古警方破获特大跨境网络赌博案**

近日，内蒙古二连浩特市公安局成功破获一起特大跨境网络赌博案。经警方多线侦查发现，该团伙在境外搭建“万利游戏”赌博平台（平台上共有17款赌博APP），并在国内招募大量代理人发展赌徒。

  

专案组通过梳理涉赌人员资金流水，还发现天津盈付通有限公司、青岛中诺有限公司涉嫌帮助赌博平台，多次给涉赌人员支付佣金。

  

警方分赴北京、天津、广东、福建、浙江、河北等地，查获代理人员300余名，冻结涉案账户6000多个、涉案资金7000余万元，抓获涉案人员82名，采取强制措施69名，收缴涉案赌资、佣金共计700多万元。目前，案件在进一步侦办中。

  

**道滘警方打掉“网络交友”诈骗团伙**

2020年6月17日，广东省东莞市道滘镇公安局对一诈骗团伙展开抓捕行动，一举打掉3处涉嫌网络交友诈骗的窝点，现场抓获犯罪嫌疑人11名，起获作案手机10余部、银行卡10余张。

  

经查，该团伙成立某电子科技公司，对外招募员工时声称在网上向客户推销POS机、信用卡等可以赚取提成，但要求交纳9600元的入会费。员工进入公司后，接受组织“洗脑”，继而一起实施诈骗。

  

团伙成员冒充年轻女性在微信上猎取诈骗对象，在取得事主信任并与事主发展成男女朋友后，以生病、丢钱包等各种困境为由骗取事主的钱财。目前，案件仍在进一步审理中。

***热点事件***

  
  

  

**微博发布公告：解散112万个涉黄、**

**违法违规内容微博群**

2020年6月28日，根据微博官方发布的公告，近期，微博接到网友投诉称，有部分微博群内存在大量的涉黄、违法和其他的违规内容。站方根据投诉线索，主动解散违规的微博群112万个。

  

同时，对其中疏于管理微博群且情节严重的群主、群管理员、群隶属人采取了限制建群功能、禁言和关闭账号等处置措施。

  

微博表示，通过网友投诉和站方核实，发现在微博群组管理上确有漏洞，微博将进行严格的自查自律。并将新组建的普通群成员人数上限调整为100人；新组建的粉丝群成员人数上限调整为3000人。

  

**深圳市消委会：消费者租借QQ/微信帐号**

**存严重安全隐患**

2020年6月29日，深圳市消委会发布提醒，广大消费者应保护好自己QQ/微信帐号密码，合规使用，尤其是租借QQ/微信帐号的行为存在严重安全隐患。深圳市消委会强调，租借QQ/微信帐号存三大严重安全隐患：

  

**一、个人信息安全有隐患。**个人隐私脱离防护，个人信息敏感内容可能会被收集或在黑市上出售；

  

**二、资金安全有隐患。**好友对帐号租借不知情，不法分子借助号主身份向好友实施借款借贷、恶意骚扰或欺诈；

  

**三、帐号安全有隐患。**帐号随时存在被盗风险，如被利用开展垃圾营销、招嫖或散播不良信息等恶意行为，将导致帐号违规被封停。个人信息安全、资金安全、帐号安全等全部脱离防护，严重还将承担法律责任，租借QQ/微信帐号存严重安全隐患不容小觑。

  

**微软发布已删除文件恢复工具**

**Windows File Recovery**

近期，微软发布了一款免费的已删除文件恢复工具 Windows File Recovery，如果遇到误删重要文件，格式化硬盘，硬盘数据损坏，可以试试 Windows File Recovery 来恢复文件。

  

该功能支持：根据文件名、路径、关键词、格式来恢复，格式支持图片、音频视频文件、PDF、Office 文档、ZIP 等。支持 NTFS、FAT、exFAT 和 ReFS 文件系统，支持机械硬盘、SSD、USB 优盘和内存卡。不过 该功能是命令行工具，对于初级用户可能略有难度。

**微信“搜一搜”正式开放服务搜索接入**

近日，微信官方宣布，微信“搜一搜”服务搜索正式向各行业开放接入。微信表示，通过这项服务，优质的服务可以快速“出圈”，被更多用户便捷获取，品牌商家也可通过服务吸引更多流量，提升品牌知名度。满足以下条件的商家们在公众号后台配置服务信息后，服务就有机会在搜索结果中展示：

1、用于开通服务搜索的公众号注册时间已满6个月，且已获得微信认证；

2、服务不属于社交、医疗、游戏等类目。

  

商家们可登录微信公众平台，在微信“搜一搜”-“搜索功能”中点击“服务搜索”进入页面。在服务搜索页，点击“编辑”打开服务配置页，选择“添加服务”。填写服务信息并保存，即可提交审核，审核通过后，服务将在搜索结果中展示。
