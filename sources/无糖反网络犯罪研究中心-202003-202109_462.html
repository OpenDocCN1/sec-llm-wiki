案件打击




江苏警方破获特大侵犯公民个人信息案

2020年5月7日，江苏省南通市公安局破获一起特大“暗网”侵犯公民个人信息案，抓获犯罪嫌疑人27名，查获被售卖的公民个人信息数据5000万余条。该团伙通过多种途径收集大量商家信息，并非法购买包括期货、外汇投资人等公民个人信息数据，在“暗网”交易平台上兜售。同时，还通过“暗网”交易平台批量购买“股民”、“车主”、“银行”、“房产”等行业的公民个人信息，转卖获利。目前，案件正在进一步侦办中。


蕲春法院宣判“链城亿购”传销案

2020年5月4日，湖北省蕲春县人民法院对外披露了一起网络传销案。该团伙在网上加入由四川链城科技有限公司推广的“链城亿购”无人超市项目，只需投入998元就能成为平台会员，每购买一单产品产生16元收益，收益70%可提现，30%作为平台消费券使用，推荐其他人成为会员并购买商品，可获得对应奖励。至“链城亿购”平台崩盘，王某利发展下线会员75人，收到传销资金219万余元；王某、王某某与高某泉等人合伙经营的荣誉董事账号发展下线层级达74人，收取传销资金540万余元。


蕲春县人民法院依据相关法律的规定，对3名被告人判处3年6个月到2年不等的有期徒刑，并处8万元到5万元不等的罚金。


金溪警方破获“杀猪盘”诈骗案

2020年5月1日，江西省抚州市金溪县警方成功破获一起“杀猪盘”式电信诈骗案件。该团伙通过婚恋网站、聊天交友工具等筛选易上当人群，再与受害人“谈恋爱”获取信任后，引诱其参与网络赌博，实施诈骗。警方共抓获犯罪嫌疑人56名，查获涉案金额数百万元。目前，案件正在进一步侦办中。


娄底警方破获“网上投资”诈骗案

2020年5月3日，湖南省娄底市公安局娄星分局长青派出所联合刑侦大队，成功侦破一起电信诈骗案件。该团伙以成立“某商务有限公司”为掩护招揽业务员，对业务员进行话术培训后，业务员通过微信加人，对在聊天中有购买股票意向的“客户”，大肆推荐其加入“某投资平台”，然后通过平台1:10配资收取高额手续费，并通过制作虚假的股市利好，实施诈骗。警方共抓获犯罪嫌疑人8名，涉案金额200余万元。目前，案件仍在进一步审讯深挖之中。


反制动态




桐柏公安反诈骗中心揭牌启用

2020年4月29日，河南省南阳市桐柏县公安局反诈中心正式启用。据悉，该“反诈中心”由县公安局、各商业银行及通信运营商派员入驻，内设预警劝阻、资金信息查控、研判侦查等功能小组，实行“24小时全天候运行，实时合成作战”工作模式。

GitHub 新功能公布

2020年5月7日，GitHub Satellite 2020 线上活动上，GitHub 宣布了一系列新功能：Codespaces、论坛、代码漏洞扫描、密钥扫描功能。GitHub Codespaces 集成了在线版 Visual Studio Code（此功能也配合了 VS Online 改名为 VS Codespaces），完全云端的全功能开发环境，立刻可以在 GitHub 开发而无需配置本地开发环境。GitHub Codespaces 开发功能免费，但构建功能按需付费，Beta 期间完全免费。GitHub Discussions 是新的论坛功能，方便开发者社区讨论或互助。


2019年度垃圾和钓鱼邮件报告

2020年5月7日，卡巴斯基发布2019年垃圾邮件和钓鱼邮件分析报告。报告中数据显示：

1、垃圾邮件占邮件总量56.51％，比2018年高4.03%；

2、垃圾邮件最大来源是中国占21.26％；

3、垃圾邮件中44％大小不到2 KB；

4、恶意垃圾邮件中最常被检测到Exploit.MSOffice.CVE-2017-11882；

5、反钓鱼系统触发467,188,119次；

6、有17％的用户经历过网络钓鱼。


中国警方“亮剑”贷款类电信网络诈骗犯罪

2020年5月7日，从中国公安部获悉，全国公安机关“云剑-2020”打击贷款类电信网络诈骗犯罪集群战役当日正式打响，北京、河北、上海、江苏等15个省市公安机关同步开展集中收网行动。截至7日15时，各地共捣毁为贷款类电信网络诈骗犯罪团伙提供服务的违法1069短信平台57个，抓获犯罪嫌疑人798名，扣押手机、银行卡、电脑等一大批涉案工具。同时，公安部部署15个省市公安机关对持有牌照的160余家涉案1069短信平台注册商进行约谈。


嘀嗒出行被曝五一活动虚假宣传

今年五一期间，嘀嗒出行推出了五一集卡活动，邀请好友助力可得现金奖励，达到100元即可提现，提现时间为5月7日。活动结束当天，部分网友表示无法提现成功，甚至账号被封，无法登陆。


对此，嘀嗒出行发布声明称，在5月7日即五一活动红包提现日期，嘀嗒出行反作弊技术团队监测到有异常账号进行违规操作。为防止互联网黑灰产业链利用平台活动非法牟利，暂时封禁了所有疑似风险账户及相应余额提现功能，并针对所有疑似风险账户进行逐一排查，截至5月7日16:00，嘀嗒平台已解禁部分正常账号，其余疑似风险账号将在仔细排查后，陆续解禁。
