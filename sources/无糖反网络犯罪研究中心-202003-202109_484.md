**文昌警方打掉电信网络诈骗团伙**

2020年4月13日，海南省文昌市公安在前期线索研判的基础上，成功打掉一个流窜在文昌市各乡镇实施电信网络诈骗的儋州籍犯罪团伙。警方共端掉电信诈骗窝点1处，抓获犯罪嫌疑人4名，查扣人民币5万余元，涉案POS机4部，银行卡22张，手机卡31张，银行卡电子密码器4个。目前，犯罪嫌疑人已被依法采取强制措施，相关案件正在进一步办理当中。

  

**甘谷“2•24”电信诈骗案告破**

2020年4月13日，甘肃省天水市甘谷县警方成功告破“2•24”电信诈骗案。自今年2月份以来，该诈骗团伙通过以互联网出售医用口罩实施诈骗。警方共抓获犯罪嫌疑人8名，涉案金额60余万元，涉及案件13起。目前，案件正在进一步办理中。

**宾县警方打掉三个电信网络诈骗团伙**

2020年4月15日，黑龙江省哈尔滨市宾县公安局成功打掉3个电信网络诈骗团伙。该团伙以办理贷款为诱饵，利用他人信息办理银行卡“五件套”，再以每套5500元的价格转卖给上游电信网络诈骗分子，从中获取高额非法利益。警方共抓获犯罪嫌疑人56人，冻结对公账户83个，扣押工商营业执照37份、公章111枚，扣押、冻结涉案资金120余万元，涉案金额600余万元。目前，案件相关工作正在进一步进行中。

**石河子市反电信诈骗志愿服务队成立**

2020年4月13日，新疆石河子市北子午路派出所联合老街街道办事处从辖区单位、工商业主和学校等各行业招募志愿者150多名，成立首支反电信诈骗志愿服务队。该队伍将深入街道社区、校园、商户、企业等单位开展反诈骗宣传活动，将防范知识传递给广大群众。

**芒果TV与PP视频取消默认自动续费功能**

2020年4月13日、14日，芒果TV，PP视频分别向浙江省消费者权益保护委员会提交整改回复函，就4月8日浙江省消保委约谈中提到的相关问题说明整改方案和整改进度。针对自动续费扣款未提醒问题，芒果TV、PP视频表示对购买连续包月的消费者，已在扣费前通过发送站内消息、手机短信等形式，主动提醒用户即将扣费；同时主动告知消费者退订方式，消费者可随时取消。

  

**8起涉“黄”“非”典型案件被通报**

2020年4月14日，全国“扫黄打非”办公室通报了6起制售传播淫秽色情信息重点刑事案件和2起网络行政案件，涉及网络直播淫秽表演、开办淫秽色情网站及APP、以及网络水军删帖牟利等违法违规行为。

  

全国“扫黄打非”办公室相关负责人表示，将继续保持对网络涉“黄”涉“非法出版物”行为的高压打击态势，在“新风”集中行动中严厉查处制作传播淫秽色情信息问题严重的互联网企业和个人，全链条打击违法犯罪分子，并将对典型案件加大曝光力度。

  

**GitHub核心功能免费开放**

2020年4月14日，GitHub 的CEO Nat Friedman在官网上发布声明说：“我们很高兴宣布，我们将为所有 GitHub 用户提供方便无限协作的私有库。且GitHub 全部核心功能对所有人免费。”现在，开发团队可以在GitHub上面协作处理各种开发工作，包括CI/CD持续集成和部署，项目管理、代码审查等等，同时团队付费定价也有所降低，从每月9刀下调到了每月4刀，即刻生效。

  

**360发布五大人脸识别终端**

2020年4月15日，360城市安全集团视觉科技正式推出5款人脸识别终端硬件产品、5套人脸识别管理软件，以及5大智慧解决方案。5款人脸识别终端硬件产品包括人脸抓拍机、人脸核验比对机、闸机头、门禁、IC卡模块。五大场景推出了一体化智慧解决方案，包括智慧园区、智慧校园、智慧楼宇、智慧机场、智慧政务大厅。据介绍，此次发布的软硬件均通过360攻防实验室攻防检测，具备超强的防伪算法，有着远超国际的安全标准。
