# twitter 提取特定的恶意软件或钓鱼url

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMzkzNDA1Mg==&mid=2247497361&idx=2&sn=3e24d9c0f522a5dcf09532863e600a52&chksm=9b99ba1aacee330c43942f62bb056f196c1cae753d86d893e23f100249900036c04c20afb150&scene=126&sessionid=1681279561#rd](http://mp.weixin.qq.com/s?__biz=MzAxMzkzNDA1Mg==&mid=2247497361&idx=2&sn=3e24d9c0f522a5dcf09532863e600a52&chksm=9b99ba1aacee330c43942f62bb056f196c1cae753d86d893e23f100249900036c04c20afb150&scene=126&sessionid=1681279561#rd)

    看到老外的一篇帖子：“从twitter帖文中提取恶意软件或钓鱼url”，也不知道有什么用，当威胁情报？还是记录下来先做个笔记吧。

  

    这个作者在twitter上提取带有hxxp或hxxps的帖文，因为这类url通常用做记录一个恶意软件或钓鱼url，所以他写了个程序来自动爬取相关内容并放在网站供人解析下载。该网站为：twitter.threatintel.rocks。

  

使用方法：

1、curl https://twitter.threatintel.rocks/ --silent | jq

![](../Images/6bad611fea77a90bd77a84d8410c4b0e.png)

  

2、检索url

JQ 还允许我们对检索到的内容应用过滤器。一个简单的 cURL 命令在 'malicious\_urls' 数组上带有一个过滤器，向我们展示了所有报告的 URL 转换回其原始形式。

curl https://twitter.threatintel.rocks/ --silent | jq -r '.malicious\_urls | .\[\]'

![](../Images/0910e263f77cb5a1cc0366bf5f8f7b86.png)

  

3、从报告最多的 URL 生成 IP 地址列表

以下命令允许您从恶意 IPs 数组中提取所有值并在出现时对其进行排序。

curl https://twitter.threatintel.rocks/ --silent | jq '.malicious\_ips |  .\[\]?' -r | sort | uniq -c | sort -nr

  

![](../Images/7ea1a8e0141d96b0fe0453b54ce6cd54.png)
