# 于都打掉网络招嫖诈骗团伙丨当阳打掉特大网络赌博团伙——涉网犯罪每日情报

***案件打击***

  

**呼和浩特警方破获电信诈骗案**

2022年5月10日，内蒙古呼和浩特市公安局新城区分局破获电信诈骗案，民警抓获网络逃犯1名。

  

经查，犯罪嫌疑人莎某某名下银行账户涉嫌电信网络诈骗，涉案资金高达36万余元。目前，正在进一步移交中。

  

**福鼎警方破获吸粉引流案**

2022年5月8日， 福建省宁德市福鼎市公安局破获吸粉引流案，民警抓获犯罪嫌疑人3名，当场查获电脑6台、手机11部、手机卡3张。

  

经查，该团伙成员冒充某知名招聘平台的客服，以网络招聘为幌子寻找目标人群，让目标人群添加该团伙提供的微信等社交账号，为诈骗团伙从事电信网络诈骗活动“引流”，提供更精准的受害人员群体。目前，该案正在进一步侦办中。

![](../Images/5678880c71c0da244a9f3e76c1f68213.png)

  

**大冶警方破获网络交友诈骗案**

2022年5月10日，湖北省黄石市大冶市公安局还地桥派出所破获网络交友诈骗案，民警抓获犯罪嫌疑人1名。

  

经审讯，嫌疑人董某供述，冒充女性通过交友软件与受害人刘先生交往，以“生意不好、周转不开”等理由多次向刘先生借钱，总计诈骗4万元人民币。目前，案件正在进一步办理中。

![](../Images/9590c4dcb22a984df6426714ae0aae84.png)

  

**于都警方打掉网络招嫖诈骗团伙**

2022年5月7日，江西省赣州市于都县公安局打掉网络招嫖诈骗团伙，民警抓获团伙成员3人，涉案金额近20万元。

  

经查，嫌疑人赖某等3人假扮年轻女性，使用网络社交软件，广撒网添加男性为好友，以提供特殊服务的名义引诱受害人，在指定的购买页面上购买各类产品，待受害人付款购买后立即拉黑对方。目前，案件正在进一步办理之中。

![](../Images/8f6dce4d03cea677a1ff9b96deb76a89.png)

  

**长治警方破获冒充熟人网络诈骗案**

近日，山西省长治市公安局潞州区分局破获冒充熟人网络诈骗案，民警抓获犯罪嫌疑人4名，涉案金额10余万元。

  

经查，嫌疑人冒充受害人微信好友以急需转钱但不方便操作为由，让受害人向指定账户转账。目前，案件正在进一步侦办中。

  

**当阳警方打掉特大网络赌博团伙**

2022年5月7日，湖北省宜昌市当阳市公安局组织40余名警力分赴武汉、荆州等地共抓获嫌疑人19名，成功打掉一特大网络赌博团伙。

  

经查，湖北籍嫌疑人董某、陈某兴、汪某群共同注册公司，开发具有赌博功能的棋牌类APP，架设和租赁国内、香港及美国的服务器，通过利用代理形式扩充参赌人员参与网络赌博，并从每局输赢中抽水渔利。该团伙至案发时，共组织1万余人进行网络赌博，参赌人员涉及荆州，以及湖南、四川、重庆等多地，每天活跃用户达600多人，涉赌流水逾1000余万元，非法获利100余万元。同时查明，团伙技术人员还通过暗网贩卖程序源代码进而获利。目前，案件正在进一步审理中。

![](../Images/3fd28dc317133ecc8d5bd24fee7882b7.png)

  

**上海警方破获团购海底捞网络诈骗案**

2022年5月7日，上海市公安局普陀区分局甘泉路派出所破获团购海底捞网络诈骗案，民警在杭州警方的配合下抓获嫌疑人1名。

  

经审讯，嫌疑人王某某供述，虚构“海底捞”团购渠道，联系受害人声称团购返现，共诈骗3名受害人数千元。目前，案件正在进一步侦办中。

  

**涵江警方打掉“跑分”洗钱犯罪团伙**

2022年5月6日，福建省莆田市公安局涵江区分局成功捣毁一个为网络赌盘、电信网络诈骗进行“跑分”洗钱的犯罪团伙，分别在6个“跑分”窝点抓获犯罪嫌疑人13名，现场扣押作案电脑、手机50余部。

  

经查，2021年以来，该团伙利用收购的支付宝账号为境外网络赌博、诈骗等平台“跑分”转移资金达2000万元。目前，案件正在进一步侦办中。

![](../Images/56a7d4a2a1b255f7780b2a805069aaf5.png)

  

**秀山警方打掉为境外犯罪**

**提供帮助的涉诈“黑灰产”团伙**

近日，重庆市秀山县公安局打掉7个为境外犯罪提供帮助的涉诈“黑灰产”团伙，抓获犯罪嫌疑人24人，缴获GIOP设备6台、电话卡68张、银行卡12张，挽回经济损失50余万元。

  

经查，这些犯罪团伙为境外诈骗犯罪分子提供技术支持并为其掩饰、隐瞒犯罪所得，涉案金额数百万元。目前，案件仍在侦办中。

![](../Images/fb10611e5236f338c31cfb2384af41aa.png)

  

**永昌警方破获跑分洗钱案**

2022年5月7日，甘肃省金昌市永昌县公安局破获跑分洗钱案，民警在重庆抓获犯罪嫌疑人10名，扣押用于作案的手机17部、银行卡38张。

  

经查，该团伙有组织进行开卡“跑分”。目前，案件正在进一步侦办中。

  

**平台曝光**  

  

**重庆市九龙坡区警方通报一起**

**“共享车位投资”非法集资案件**

近日，重庆市九龙坡区警方通报一起以投资共享车位为名义的非法集资案件。2018年九龙坡警方接到多位市民报警称，参加了某外省停车管理公司重庆团队的“共享车位投资”项目推介会，在平台投资一段时间后公司人去楼空。

  

重庆市公安局九龙坡区分局经侦支队接到报警后立案调查，先后抓获涉嫌非法吸收公众存款的朱某、蔡某、刘某等4名主要涉案人员。经查，朱某伙同蔡某、安某、刘某等人，先后利用外省两家停车管理公司的名义向川渝黔等地不特定公众宣传“共享车位投资”项目，通过召开宣讲会、见面聊天、微信宣传、实地考察等方式，直接和间接吸引重庆地区700余人进行投资，涉案金额达700余万元。然而，投资人的投资款并未用于修建宣称的车位。

  

***热点事件***

  

**中央网信办：4月主要商业网站平台**

**受理网络侵权举报43.96万件**

2022年5月11日，中央网信办举报中心发布主要商业网站平台2022年4月份网络侵权举报受理处置情况，2022年4月，微博、抖音、百度、腾讯、知乎、哔哩哔哩、小红书、快手、豆瓣、网易、新浪、搜狐等主要商业网站平台重点受理泄露他人隐私、侮辱谩骂、造谣诽谤等网络侵权举报达43.96万件。

  

其中，微博受理相关举报375927件，抖音受理相关举报17432件，百度受理相关举报17166件，腾讯受理相关举报11638件，知乎受理相关举报8609件，哔哩哔哩受理相关举报4843件，小红书受理相关举报1742件，快手受理相关举报942件，网易受理相关举报454件，新浪受理相关举报321件，豆瓣受理相关举报314件，搜狐受理相关举报198件。
