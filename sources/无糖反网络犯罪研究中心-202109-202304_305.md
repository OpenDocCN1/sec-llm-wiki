# 南京侦破特大网络交友购物诈骗案丨新丰打掉冒充女性诈骗团伙——涉网犯罪每日情报

***案件打击***

  

**通渭警方破获网络赌博案**

2022年4月13日，甘肃省定西市通渭县公安局破获网络赌博案，民警抓获多名犯罪嫌疑人。

  

经审讯，孙某、刘某、王某等人供述，在某平台小程序以打麻将、斗地主方式通过赢取积分后支付现金的赌博犯罪行为。目前，案件正在进一步办理中。

  

**依安警方打掉“跑分”团伙**

2022年4月13日，黑龙江省齐齐哈尔市依安县公安局打掉“跑分”团伙，民警先后分赴广东、陕西、湖南、河南、先后抓获犯罪嫌疑人16名。

  

经审讯，犯罪嫌疑人张某等人供述，其受雇于梁某为境外多个赌博网站、电信诈骗团伙，进行资金结算洗钱的犯罪事实。目前，案件正在进一步工作中。

![](../Images/6c0e758ad1a76337d896eb3d02347d50.png)

  

**新丰警方打掉冒充女性诈骗团伙**

近日，广东省韶关市新丰县公安局打掉冒充女性诈骗团伙，民警现场抓获温某等4人，并收缴作案工具一批经审讯，温某等4人供述 ，自2022年3月份以来，其团伙利用手机、电脑、变声器等工具冒充女性，通过微信交友、聊天，以假装生病、索要礼物等借口实施诈骗的犯罪事实。目前，案件在进一步侦办中。

![](../Images/9bf45a7cc94b176f1fcba0754750b3df.png)

  

**南宁警方捣毁涉诈团伙**

2022年4月12日，广西南宁市公安局高新区分局捣毁涉诈团伙，民警抓获犯罪嫌疑人5名，现场查获作案手机3部、电话卡8张。

  

经查，该团伙以宁某强为首，在一些小众的社交软件上接收境外诈骗团伙的指示后，便用事先准备好的作案手机和收购来的电话卡实施诈骗。通过多部手机架设渠道，帮助境外诈骗嫌疑人拨打国内受害人电话实施电信诈骗，共获利7000余元。目前，案件正在进一步侦办。

![](../Images/4e2998c1229335523b56d77301351fb0.png)

  

**固始警方打掉网络诈骗团伙**

2022年4月14日，河南省信阳市固始县公安局打掉网络诈骗团伙，民警抓获犯罪嫌疑人12名。

  

经查，嫌疑人胡某伙同叶某等人通过购买某商场虚假投资平台，在城区组建某投资总公司，在潢川县成立分公司，招聘业务员在网上虚构身份，采取远程操控等手段，以交友的方式让人在其购买的虚假平台上充值，后占为己有，至案发以来共诈骗金额37万余元。目前，该案正在进一步办理之中。

  

**聊城警方打掉跑分犯罪团伙**

2022年4月14日，山东省聊城市公安局茌平区分局打掉跑分犯罪团伙，民警抓获犯罪嫌疑人6名。

  

经查，犯罪嫌疑人司某通过特定软件与境外电信网络犯罪集团建立联系，组织张某、杜某等人，使用银行卡为电信网络犯罪集团提供转账服务，涉案资金流水达到1300多万元。后嫌疑人张某脱离司某，独自与境外电信网络犯罪集团联系，纠集崔某、王某、杜某等人使用银行卡提供转账服务，涉案资金流水达到500多万元。目前，案件正在进一步侦办中。

![](../Images/a5ff1a87fa2342e554f9cd56b8cb0b86.png)

  

**大连警方打掉话务引流的犯罪团伙**

2022年4月11日， 辽宁省大连市公安局打掉话务引流的犯罪团伙，民警抓获犯罪嫌疑人10名、缴获涉案GOIP设备1台、手机卡130余张。

  

经查，犯罪嫌疑人张某广泛寻找身边朋友提供手机卡，为境外电信诈骗团伙架设话务转接设备。目前，案件正在进一步侦办中。

  

**武汉警方破获跑分洗钱案**

近日，湖北省武汉市公安局硚口区分局破获跑分洗钱案，民警抓获犯罪嫌疑人4名，现场查获银行卡10余张、手机11部、现金4万余元。

  

经审讯，嫌疑人肖某供述，将银行卡交予曹某等人使用，为电诈分子进行跑分洗钱操作，涉案金额150万元。目前，案件还在进一步侦办中。

![](../Images/f14f02349073b35dbd3250b73876b912.png)

  

**南京警方侦破特大网络交友购物诈骗案**

近日，江苏省南京市公安局江宁区分局侦破特大网络交友购物诈骗案，民警赶赴外省抓获犯罪嫌疑人62名。

  

经查，该团伙成员打造离异带孩的单亲妈妈形象，利用在婚恋网站收集的客户信息，按照设定好的话术联系受害人进行网上交友，再以孩子、自己过生日等理由，诱骗受害人在犯罪嫌疑人事先搭建的虚假购物网站上，付款购买红酒、牛排、玉石等物品。自案发，该诈骗团伙作案300多起，涉案金额超千万元。目前，案件审讯和后续抓捕工作正在进行中。 

![](../Images/bc1e9d5d0042473e61212faa81141eff.png)

  

**盐湖警方破获跑分洗钱案**

2022年4月11日，山西省运城市公安局盐湖区分局破获跑分洗钱案，民警抓获犯罪嫌疑人5名，并在作案窝点扣押了涉案电脑一台，追缴违法所得11600元。

  

经查，犯罪嫌疑人崔某民经人介绍，得知用银行卡给“打鱼”赌博平台“上分”过账走流水可获取高额非法收益后，纠集亲朋好友使用名下多张银行卡给赌博平台“上分”过账。经国家反诈平台查询，该团伙用于过账的银行卡涉及全国多起电信诈骗案件，涉案资金流水达70余万元，从中非法获利2万余元。目前，案件正在进一步侦办中。

**热点事件**  

  

**3月全国受理**

**网络违法和不良信息举报1258.6万件**

2022年4月16日消息，据网信办官网通报，2022年3月全国受理网络违法和不良信息举报1258.6万件，环比增长2.1%、同比增长16.5%。

  

其中，中央网信办违法和不良信息举报中心受理举报37.2万件，环比增长17.2%、同比增长116.7%；各地网信办举报部门受理举报84.3万件，环比增长11.0%、同比下降20.5%；全国主要网站受理举报1137.1万件，环比增长1.0%、同比增长18.8%。

  

在全国主要网站受理的举报中，主要商业网站受理量占60.9%，达692.8万件。

  

**三部门整治网络直播短视频领域乱象**

近日，中央网信办、国家税务总局、国家市场监督管理总局日前联合印发通知，决定开展为期两个月的“清朗·整治网络直播、短视频领域乱象”专项行动。《专项行动》提出的工作目标是，聚焦各类网络直播、短视频行业乱象，分析背后深层次原因，着力破解平台信息内容呈现不良、功能运行失范、充值打赏失度等突出问题。要求创新规范管理方式方法，健全网络直播、短视频综合治理体系，进一步压实平台信息内容管理主体责任。

  

《专项行动》以集中整治“色、丑、怪、假、俗、赌”等违法违规内容呈现乱象为切入点，进一步规范重点环节功能，从严整治功能失范、“网红乱象”、打赏失度、违规营利、恶意营销等突出问题。

  

《专项行动》将从严整治重要功能运行失范问题。整治开屏页面呈现各种打色情擦边球的“泛黄”、低俗内容。整治部分直播平台设置“性感”“诱惑”等庸俗媚俗频道；严格规范部分直播平台开设抽奖、竞猜、返利、夺宝等活动，坚决打击变相实施博彩诱导用户参与赌博行为。从严整治连麦PK环节恶俗惩罚问题。
