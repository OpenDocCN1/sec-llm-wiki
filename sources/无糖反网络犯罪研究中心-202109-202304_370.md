# Pwnkit检查和利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMzkzNDA1Mg==&mid=2247495184&idx=2&sn=fb07a1ec082d1231c41d421080059349&chksm=9b99a29bacee2b8d34bc45cdfa7c28ec57cc97d3a8c846d32a793134a9c418eb92579fd5bc83&scene=126&sessionid=1681279602#rd](http://mp.weixin.qq.com/s?__biz=MzAxMzkzNDA1Mg==&mid=2247495184&idx=2&sn=fb07a1ec082d1231c41d421080059349&chksm=9b99a29bacee2b8d34bc45cdfa7c28ec57cc97d3a8c846d32a793134a9c418eb92579fd5bc83&scene=126&sessionid=1681279602#rd)

    Linux Polkit组件中pkexec程序存在权限提升漏洞(编号：CVE-2021-4034)。pkexec应用程序为linux系统预装工具，漏洞影响ubuntu、Debian、Fedora、CentOS等主流Linux系统。Pwnkit是一个利用polkit将权限提升到root的漏洞。这篇文章展示了如何使用 Ubuntu重现它，以及如何检查系统是否易受攻击。

  

    我们单位的主页上专门对此漏洞进行了预警。正好在值班，就找了相关的资料，进行了复现，并给出了检测办法。

  

漏洞原理：

https://www.qualys.com/2022/01/25/cve-2021-4034/pwnkit.txt

  

作者提到的危害性：

这个漏洞是攻击者梦想成真：

*   pkexec 默认安装在所有主要的 Linux 发行版上；
    
*   pkexec 自 2009 年 5 月创建以来就存在漏洞；
    
*   任何非特权的本地用户都可以利用此漏洞获得完全的 root 特权；
    
*   虽然这个漏洞在技术上是内存损坏，但它可以立即、可靠地以一种独立于架构的方式被利用；
    
*   即使 polkit 守护进程本身没有运行，它也是可以利用的。
    

  

攻击样本：

https://github.com/berdav/CVE-2021-4034.git  

  

**一、在Ubuntu21.04上试验**  

在docker中拉入21.04版本，按以下操作：

1、安装gcc

apt-get install gcc

2、安装policykit-1

apt-get install policykit-1

# **四、结论**

    由于这不是一个可以远程触发的漏洞，我认为这不应该意味着 log4shell 级别的恐慌，但是该漏洞的公开可用性、利用它的易用性以及它适用于大多数发行版的事实应该只意味着一件事：打补丁！
