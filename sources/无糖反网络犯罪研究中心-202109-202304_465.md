   CrowdStrike Services 创建了 SuperMem，这是一个开源的 Windows 内存处理脚本，可帮助调查人员快速地处理内存样本。

  

“winSuperMem.py”是一个 Python 脚本，它将以快速、有选择的方式解析 Windows 内存样本。它由一种分类类型的方法支持，使该工具易于使用，因此更易于取证分析师使用。分类类型方法包括三种类型：快速、全面和综合。

Quick Triage

`python3 winSuperMem.py -f memdump.mem -o output/ -tt 1`

## Full Triage

`python3 winSuperMem.py -f memdump.mem -o output/ -tt 2`

## Comprehensive Triage

`python3 winSuperMem.py -f memdump.mem -o output/ -tt 3`

![](../Images/6eb445cc29fcc03b6df3759eecee72c1.png)

注意：winSuperMem.py是在Linux环境中开发的，未在Windows上运行测试。应该可以配置在Windows系统上运行的脚本。

SuperMem 目前包含的处理功能有：

Volatility 3.根据所选的分类类型，SuperMem 将运行所选的 Volatility 3 插件。为 SuperMem 选择 Volatility 3 是因为它的速度和输出格式。此外，每个插件都可以配置唯一的参数。

1.  Volatility 3。根据选定的分类类型。
    
2.  批量提取器。每种分类类型都将使用内存映像上的默认参数运行 Bulk Extractor。
    
3.  字符串。每个分类类型都将在内存映像上运行 Unicode、ASCII 和 Big-Endian 字符串。
    
4.  EVTX 。根据选择的分类类型，SuperMem 将使用默认参数在内存映像上运行 EVTXtract。
    
5.  提取文件。根据选择的分类类型，SuperMem 将尝试转储文件，例如加载的 DLL、驱动程序、进程、注册表配置单元和其他特定文件类型和路径。
    
6.  收集 IOC。根据所选的分类类型，SuperMem 将尝试从 Volatility 3 NetScan 输出中收集非私有 IP 地址并将它们添加到 IOC.csv 文件中。
    
7.  Palso。根据选择的分类类型，SuperMem 将在整个输出目录中运行 log2timeline，解析转储文件和 Volatility 输出。然后 SuperMem 将对输出运行 psort 并生成活动的超级时间线。 
    
8.  Yara。仅针对全面分类，SuperMem 将基于提供的 Yara 文件跨转储的驱动程序、进程和 DLL 运行 Yara。
    

# 安装内容：

 SuperMem 有一些 Python 依赖项，可以使用以下命令安装：

`pip3 install -r requirements.txt`

`另外，还要安装：`

1.  Install Python 3
    
2.  Install Python 2
    
3.  pip3 install -r requirements.txt
    
4.  Install Volatility 3 Framework
    
5.  Install Volatility 2 Framework
    
6.  Download Volatility 2 Community Plugins
    
7.  Install Bulk Extractor
    
8.  Install Plaso
    
9.  Install Yara
    
10.  Install Strings
     

  

执行：

  

```
python3 winSuperMem.py -f memdump.mem -o output -tt 3
```
