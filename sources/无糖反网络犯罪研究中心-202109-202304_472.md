# 鄂州破获虚拟币投资诈骗案丨小榄破获杀猪盘网诈案——涉网犯罪每日情报

***案件打击***

  

**广安警方破获“网络招嫖”诈骗案**

近日，四川省广安市公安局前锋区分局破获“网络招嫖”诈骗案，民警抓获嫌疑人1名。

  

经审讯，嫌疑人薛某供述，通过上传美女图片伪造同城定位，引诱嫖客上钩，再以交定金、服务费、保证金等为由实施诈骗，涉案金额8万元。目前，该案正在进一步办理中。

  

**东至警方打掉跑分洗钱犯罪团伙**

近日，安徽省池州市东至县公安局打掉跑分洗钱犯罪团伙，民警在蚌埠市抓获嫌疑人5名，现场扣押作案手机五部、银行卡三十余张、扣押人民币13000余元。

  

经查，该团伙通过“纸飞机”聊天软件联系境外从事网络赌博、电信诈骗等违法犯罪活动的“上家”，并用银行卡、微信、支付宝频繁转账帮助“上家”转移资产，并从中获利。目前，案件正在进一步侦查中。

![](../Images/56d42006618c3ba82d95adb8daf24342.png)

  

**定州警方打掉“跑分”洗钱犯罪团伙**

2021年10月10日，河北省保定市定州市公安局打掉“跑分”洗钱犯罪团伙，民警在本地及北京抓获嫌疑人6名。

  

经查，该团伙在明知对方从事电信诈骗违法犯罪活动的情况下，仍带着各自的银行卡到帮助上家“跑分”洗钱，并从中获利，其中一嫌疑人名下五张银行卡流水达30余万元。目前，案件正在进一步侦办中。  

![](../Images/0789a6e33d5526a21c336dcf6e08b902.png)

  

**小榄警方破获杀猪盘网络诈骗案**

近日，广东省中山市公安局小榄镇分局破获杀猪盘网络诈骗案，民警在河源市先后抓获嫌疑人4名。

  

经查，该团伙通过微信途径添加受害人，通过对受害人嘘寒问暖获取受害人信任，再推荐受害人到某投资平台进行投资从而实施诈骗，涉案金额133万元。目前，案件正在进一步侦办中。

![](../Images/823feee40aa1ad09d430103240a5d1a5.png)

  

**六安警方打掉利用**

**“跑分平台”洗钱团伙**

近日，安徽省六安市公安局裕安区分局打掉利用“跑分平台”洗钱团伙，民警抓获嫌疑人20名。

  

经查，该团伙以每天100到150元的价格，使用被招募来的市民银行账户，为境外诈骗团伙提供洗钱服务。目前，案件正在进一步深挖之中。

![](../Images/1eda5a1ec76e29d427653218d220cb8b.png)

  

**鄂州警方破获虚拟币投资诈骗案**

2021年10月9日，湖北省鄂州市公安局鄂城区分局破获虚拟币投资诈骗案，民警赶赴武汉、黄冈抓获嫌疑人20名。

  

  

经查，该团伙由主要嫌疑人胡某通过直播间或者网络社区授课，吸引人员来到山寨虚拟货币投资平台“炒币”，开展诈骗。目前，该案正进一步办理中。  

![](../Images/219b02fa659af13ea4f7164393872757.png)

  

**泾阳警方破获网上刷单诈骗案**

近日，陕西省咸阳市泾阳县公安局破获网上刷单诈骗案，民警赶赴浙江台州抓获嫌疑人3名，打掉一个通过网络刷单实施诈骗的犯罪团伙，涉案金额7万余元。

  

经审讯，嫌疑人陈某波供述，自今年七月份以来，驾驶一辆红色领克牌轿车，曾在陕西、四川等地以刷单套现为由实施诈骗的犯罪事实。目前，案件正在进一步办理中。

![](../Images/f30ca67f879055ad58bae4b0749db794.png)

  

**河池警方破获冒充熟人电信诈骗案**

近日，广西河池市公安局指挥南丹、天峨两地警方破获冒充熟人电信诈骗案，民警分赴南宁市区、宾阳、德保、宁明等地，抓获嫌疑人21名，端掉新型网络诈骗全链条窝点8个，查获扣押作案工具笔记本电脑16台、银行卡23张、手机30台、POS机2台、U盘9个。

  

经查，嫌疑人吴某平等人所在团伙通过钓鱼网站盗取QQ账号密码并冒充好友实施诈骗；嫌疑人李某、凌某春等人所在团伙为上述诈骗团伙提供洗钱转账服务，通过从中抽取“佣金”获利。

  

据统计，该团伙共计盗取QQ账号达10万余个，在反诈平台关联诈骗案件35起，涉案资金15.6万余元。目前，案件正在进一步办理中

![](../Images/8b70a878615d2f7db111646a51f20adb.png)

  

**沈阳警方打掉洗钱犯罪团伙**

近日，辽宁省沈阳市公安局打掉洗钱犯罪团伙，民警抓获嫌疑人10名，并现场查获各类银行卡70余张、银行口令牌若干以及POS机一部。

  

经查，嫌疑人罗某供述，其与雍某在网上结识后，两人组织多人先后流窜全国各地开办银行卡，为境外诈骗和赌博等犯罪团伙转账洗钱的犯罪事实。目前，案件正在进一步侦查之中。

![](../Images/165081300ef0aa4ab7ad7b49e0cc35bb.png)

  

**沙市警方破获跑分洗钱案**

2021年10月12日，湖北省荆州市公安局沙市区分局破获跑分洗钱案，现场查获一利用银行卡为诈骗团伙“跑分”洗钱的窝点，当场抓获13名涉案人员、收缴作案手机17部、查获吸毒工具3套。

  

经审讯，该窝点组织者凡某、李某供述，在多地租用民宿、宾馆等场所，组织他人携带银行卡前来为诈骗团伙“跑分”洗钱。目前，案件正在进一步深挖中。

![](../Images/ce8da18f96e7cae1d1c97f89bf506918.png)

  

***热点事件***

  

**上海证监局三大铁律规范**

**券业人员自媒体展业**

近日，上海证监局向辖区内券商下发《关于规范证券从业人员利用自媒体工具开展业务活动的通知》。据悉，这是监管针对一个月前蔡钧毅直播导流中疑似宣传虚拟币、导致投资人大幅亏损所采取的行动。

  

在《通知》中，上海证监局指出，辖区内某证券分析师因涉嫌诈骗罪被刑事拘留，与其不当使用自媒体工具开展业务活动有关。为保护投资者合法权益，上海证监局提出三点措施，并要求辖区内券商对照自查，切实加强对员工利用自媒体工具展业行为的管控，提升风险管理有效性。

  

具体如下：一是完善内部管理，严格规范员工自媒体展业行为。二是优化监控方式，有效发挥日常监控作用。三是加强合规管理，提高合规执业教育。

  

下一步，将进一步加大对辖区证券从业人员利用自媒体工具开展业务活动的日常监管。

  

**重庆召开PUSH弹窗突出问题**

**等四大专项整治工作推进会**

2021年10月13日，重庆市“饭圈”乱象、PUSH弹窗突出问题、商业网站平台和自媒体违规采编发布财经类信息问题、互联网用户账号运营乱象专项整治四大专项整治工作推进会在市网信办召开。会议贯彻落实习近平总书记关于打造清朗网络空间的重要指示要求，总结前阶段工作成效，部署下阶段重点工作，全力打造天朗气清、生态良好的网络空间。

  

今年以来，重庆网信开展 “四大专项整治”以来，全面清理相关账号、群组2000余个，查删各类有害信息2.1万余条，关闭违法违规网站140余个，下架APP 400余个，受理处置网民举报线索3860余条；约谈并整改有关明星经纪公司；严肃约谈“十六番旅行”APP负责人，并依法作出罚款30万元的行政处罚。通过各部门通力协作，形成了专项整治齐抓共管工作格局，取得了良好整治效果。
