加密传输

首先是加密

原封不动的解密一下就好：

一个数连续两次异或另外一个数还是他自己，类似这样的函数：

def jiami(key,text):
    miwen = ''
    for i in range(0,len(text)):
        miwen = miwen+chr(ord(text[i])^ord(key[((i+1)&15)]))
    return base64.b64encode(miwen.encode("utf-8"))
