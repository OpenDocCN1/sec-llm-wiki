C value,id,is_ flag --dump

200-APi

题目回顾：

这里好像有个什么 APi ， 链接在此

http://101.231.137.47:20006/index

， 能用它获取

/tmp/flag.txt 中内容吗？Flag 包含大小写和符号噢。

解题思路：

1、 首先在页面 input 中输入任意字符，观察页面回显和请求方式。

2、 发现实际数据是以 JSON 格式通过 RESTful 风格的 API 进行请求和响应的。

3、 尝试将 HTTP 请求的 Content-Type 由 application/json 修改为 application/xml，并将

json 数据格式化成 XML 并提交。

4、 发现服务端也可以接受 xml 格式的数据。

5、 构造畸形的 XML 实体进行提交，读取系统当中的 flag 文件，获取 flag 文件内容。


curl -i -H "Content-Type: application/xml" -X POST -d '<?xml version="1.0" encoding="UTF- 8"?><!DOCTYPE rooENTITY file SYSTEM "file:///tmp/flag.txt">]><xml>&file;</xml>'

100-Atom-附加题

题目回顾：

您觉得这个网站华丽吗？或许您可以获权搞点新鲜的~ 地址：

http://101.231.137.47:20008/login.php

账户:test，密码:123456

解题思路：

打开赛题地址 http://101.231.137.47:20008/login.php 显示出登录界面，输入题目里提供的账户和密码，进入网站前台，点开里面各种页面并没有发现利用点。


回到最初的登录点，可以从登录入手。打开 BurpSuite 并开启代理模式，并设置好浏览器的代理。重新登录看下 BurpSuite 有没有什么信息。


从 BurpSuite 里的 Cookie 能看到 admin=0，在这里把 0 改为 true，之后点击 Forward，经过连续 3-5 次的修改，成功进入后台!

从后台部分页面能看到 FLAG 的影子。但提交上去提示不成功，可能并不是最终的 flag，其实真正的 flag 在后台首页源代码里。flag{84cf946137bfa59a0d64868b8ea4bfcd} 提交成功！
