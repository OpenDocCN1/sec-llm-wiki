## cookie登录

通过解密数据库登录获取cookie，再用cookie登录web

解密脚本：https://github.com/horizon3ai/vcenter\_saml\_login

```
python vcenter_saml_login.py -p data.mdb -t 
```

然后会生成相应的cookie，访问 `ui` 路径进行 cookie 替换即可

```

```
