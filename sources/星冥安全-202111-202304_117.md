#### **● ****定位域管**

在一个域中，当计算机加入域后，会默认给域管理员赋予本地系统管理员权限。因此，域管理员均可以访问本地计算机，且具备完全控制权限。定位域内管理员的两种渠道：日志和会话。日志是指本地机器的管理员日志，可以使用脚本或Wevtutil工具导出并查看。会话是指域内每台机器的登陆会话，可以使netsess.exe或PowerView等工具查询（可以匿名查询，不需要权限）。

1.psloggedon.exe

下载地址：https://docs.microsoft.com/en-us/sysinternals/downloads/psloggedon

通过检查注册表HKEY\_USERS的key值来查询谁登陆过，需要调用NetSessionEnum API，某些功能需要管理员权限

```

```

![](../Images/4c196205255c6c3fdf4cc214587d2cb3.png)

指定计算机名称

![](../Images/91b4537f33aeea155057c03e2b8db215.png)

2.PVEFindADUser.exe

用于查找活动目录用户登录的位置、枚举域用户、以及查找在特定机器上登录的用户，包括本地用户、通过RDP登陆的用户、用于运行服务和计划任务的用户。（注：该工具需要配置.NET Framework 2.0环境，而且需要管理员权限）

```

```

![](../Images/24765cb80a3d3b1ba37cb25a510ca349.png)

3.netview.exe

Netview是枚举工具，使用WinAPI枚举系统，利用NetSessionEnum找寻登陆会话，利用NetShareEnum找寻共享，利用NetWkstaUserEnum枚举登陆用户。同时，netview.exe能够查询共享入口和有价值的用户。netview.exe的绝大多数功能不需要管理员权限。

下载地址：https://github.com/mubix/netview

```

```

![](../Images/228c94c02bf0f8f6ede2306d3687ca17.png)

4.powerview.ps1

powerview是一款powershell脚本，集成在powersploit工具包中。

Invoke-UserHunter:找到域内特定用户群，接收用户名、用户列表和域组查询，接收一个主机列表或查询可用的主机域名。它可以使用Get-NetSessions和Get-NetLoggedon（调用NetsessionEnum和NetWkstaUserEnum API)扫描每台服务器并对扫描结果进行比较，从而找出目标用户集，使用不需要管理员权限。

下载地址：https://github.com/PowerShellEmpire/PowerTools/tree/master/PowerView
