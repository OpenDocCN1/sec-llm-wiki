### iptables转发端口

接下来做一下端口转发，使得可以通过Ubuntu机器的NAT网卡进行访问

*   
*   
*   
*   
*   
*   

```
sudo iptables -t nat -A PREROUTING  -p tcp -d 192.168.126.140 --dport 60080 -j DNAT --to-destination 192.168.6.11:80sudo iptables -t nat -A POSTROUTING -p tcp -s 192.168.6.11 --sport 80 -j SNAT --to-source 192.168.126.140sudo iptables-save
192.168.126.140是NAT网卡，相对虚拟机来说是物理网卡192.168.6.11  是qemu虚拟网卡，相对虚拟机来说是虚拟网卡
```
