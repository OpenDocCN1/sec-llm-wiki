xxl-job-admin搭建

1.1 环境说明
  • Maven3+
  • Jdk1.8+
  • Mysql5.7+
  • xxl-job-admin 2.2.0（源码安装）
安装xxl_job需要以上环境，直接apt安装即可。
xxl_job官网源码下载地址，下载2.2.0版本：
https://github.com/xuxueli/xxl-job/releases



1.2 安装mysql
直接apt安装，安装的版本为5.7
apt install mysql-server


安装完成之后密码为空，需要将密码修改和xxl_job的一致，xxl-job数据库账号密码为：root/root_pwd
xxl-job数据库账密信息，文件路径：/home/xxl-job/xxl-job-2.2.0/xxl-job-admin/src/main/resources/application.properties


进入mysql，使用mysql数据库，然后执行如下命令修改密码为：root_pwd
update user set authentication_string=password("root_pwd"),plugin='mysql_native_password' where user='root';


修改完成之后，重启mysql：systemctl restart mysql


接着创建xxl_job的数据库：mysql> create database xxl_job;

导入数据：source /home/xxl-job/xxl-job-2.2.0/doc/db/tables_xxl_job.sql;

nacos和springcloudgateway搭建

2.1 nacos安装说明
Nacos 依赖 Java 环境来运行。如果您是从代码开始构建并运行Nacos，还需要为此配置 Maven 环境，请确保是在以下版本环境中安装使用:
  1. 64 bit OS，支持 Linux/Unix/Mac/Windows，推荐选用 Linux/Unix/Mac。
  2. 64 bit JDK 1.8+；下载 & 配置。
  3. Maven 3.2.x+；下载 & 配置。
  4. 建议: 2核 CPU / 4G 内存 及其以上



2.2 环境准备
JDK1.8下载，下载地址：
https://www.oracle.com/webapps/redirect/signon?nexturl=https://download.oracle.com/otn/java/jdk/8u351-b10/10e8cce67c7843478f41411b7003171c/jdk-8u351-linux-x64.tar.gz
也可以直接使用命令安装：apt-get install openjdk-8-jdk


nacos源码安装下载，下载1.4.1版本。
下载地址：
https://github.com/alibaba/nacos/releases?page=2



2.3 安装JDK及nacos
更新软件包列表：apt-get update
使用命令安装jdk1.8：apt-get install openjdk-8-jdk


版本为：1.8.0_352


解压nacos安装包：unzip nacos-server-1.4.1.zip


进入到目录bin目录：nacos/bin


赋予权限，执行命令
chmod +x *bash startup.sh -m standalone


访问需要加上nacos路径，查看文件也可以知道web路径


访问：http://10.30.7.107:8848/nacos/#/login


添加一些配置文件


修改nacos默认密码，nacos密码修改为：bolean@1q2



2.4 nacos服务开机自启
开启启动项目录：/lib/systemd/system/
在该目录下新建文件：nacos.service
文件内容如下，修改java目录以及nacos运行脚本的目录即可
[Unit]Description=nacosAfter=network.target
[Service]Environment="JAVA_HOME=/usr/bin/java"Type=forkingExecStart=/home/spring-nacos/nacos/bin/startup.sh -m standaloneExecReload=/home/spring-nacos/nacos/bin/shutdown.shExecStop=/home/spring-nacos/nacos/bin/shutdown.shPrivateTmp=true
[Install]WantedBy=multi-user.target


设置服务开机启动
systemctl daemon-reload systemctl enable nacos.service systemctl start nacos.service


重启之后，成功开机启动nacos服务。



2.5 安装springcloudgateway
使用IDEA新建springcloudgateway的模块

打开之后，这里删除了test部分，没用

<?xml version="1.0" encoding="UTF-8"?><project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">    <modelVersion>4.0.0</modelVersion>    <parent>        <groupId>org.springframework.boot</groupId>        <artifactId>spring-boot-starter-parent</artifactId>        <version>2.6.2</version>        <relativePath/> <!-- lookup parent from repository -->

ExecStart=/usr/bin/java -jar /home/spring-nacos/springcloudgateway/spring-cloud-gateway-0.0.1-SNAPSHOT.jarRestart=alwaysWorkingDirectory=/home/spring-nacos/springcloudgateway/[Install]WantedBy=multi-user.target

systemctl enable spring.service

redis搭建

3.1 安装redis
下载4.0.10版本 redis，下载、解压、编译。
wget http://download.redis.io/releases/redis-4.0.10.tar.gztar xzf redis-4.0.10.tar.gzmv redis-4.0.10 /usr/local/rediscd /usr/local/redisapt-get updateapt-get install gccapt-get install makemake


该环境没有make，apt安装即可：apt install make
安装完之后，再次执行：make


安装好之后，再次编译：make


二进制文件编译完成后在src目录下，将编译好的文件复制到/usr/bin/目录下
cd src/cp redis-server /usr/bin/cp redis-cli /usr/bin/



3.2 修改配置文件
编辑文件：vim /usr/local/redis/redis.conf
bind 127.0.0.1改为bind 0.0.0.0



设置密码，同一个文件中设置，默认是注释掉的，设置密码为：nbsg@123456
requirepass nbsg@123456



服务启动：redis-server redis.conf
成功登录：redis-cli -h 10.50.0.78 -a "nbsg@123456"



3.3 服务开机启动
把安装包下 redis.conf 配置文件复制到/etc/redis下，命名为：6379.conf
mkdir /etc/rediscp redis.conf /etc/redis/6379.conf


将启动脚本复制到/etc/init.d/目录下，重命名为：redisd
cd utils/cp redis_init_script /etc/init.d/redisd


修改脚本内容，修改redis-server和redis-cli的绝对路径
修改后的路径


使用 sysv-rc-conf服务管理工具将redisd服务的运行级别改为2，3，4，5。
安装sysv-rc-conf
apt-get install sysv-rc-conf


需要加源
vim /etc/apt/sources.list
deb http://archive.ubuntu.com/ubuntu/ trusty main universe restricted multiverse
apt-get update
apt-get install sysv-rc-conf



安装好之后，运行，执行命令：sysv-rc-conf


即进入服务管理界面。
然后将redisd的2，3，4，5级别全部选中（空格键，或者鼠标点击也行），q键退出


开启服务

service redisd start
