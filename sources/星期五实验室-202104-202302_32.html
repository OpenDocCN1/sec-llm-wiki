1.背景介绍

Spring Framework 的核心功能可用于开发任何Java应用程序，但也有一些扩展可用于在 Java EE 平台之上构建 Web 应用程序。

Spring 框架旨在通过启用基于 POJO 的编程模型使 J2EE 开发更易于使用并促进良好的编程实践。在JDK9+环境下，远程攻击者可以通过构造特殊语句插入恶意代码导致远程代码执行(CVE-2022-22965)。这个漏洞的poc和exp已在网上公开，由于利用方式比较简单，危害极高，建议及时升级Spring Framework版本。

星期五实验室第一时间复现了该漏洞。

目前木链科技BoleanGuard®工控安全审计平台、工业安全综合管理平台、工业互联网安全运营平台已支持该漏洞检测，工控网络安全靶场已添加该漏洞的复现实验。
