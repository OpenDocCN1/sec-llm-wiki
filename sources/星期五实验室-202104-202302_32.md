# 1.背景介绍

`Spring Framework` 的核心功能可用于开发任何`Java`应用程序，但也有一些扩展可用于在 `Java EE` 平台之上构建 `Web` 应用程序。

`Spring` 框架旨在通过启用基于 `POJO` 的编程模型使` J2EE` 开发更易于使用并促进良好的编程实践。在`JDK9+`环境下，远程攻击者可以通过构造特殊语句插入恶意代码导致远程代码执行(`CVE-2022-22965`)。这个漏洞的`poc`和`exp`已在网上公开，由于利用方式比较简单，危害极高，建议及时升级`Spring Framework`版本。

星期五实验室第一时间复现了该漏洞。

**目前木链科技BoleanGuard®工控安全审计平台、工业安全综合管理平台、工业互联网安全运营平台已支持该漏洞检测，工控网络安全靶场已添加该漏洞的复现实验。**

![](../Images/7f79d3a07974c892f83ab19c86457f13.png "null")

在这里发现的是攻击`ip`为`45.56.102.131`和`172.105.89.223`的记录，其中包括了它的`payload`信息。

# 3.payload分析

经过分析这种`payload`对远程服务是完全无害的，且不会对程序造成影响。

```
/?class.module.classLoader.URLs%5B0%5D=0
```

如果目标易受攻击，大概率返回 `400` 状态码。如下图：

![](../Images/79facd12582734fe9ca9f370737ee36a.png "null")

如果目标不易受攻击，可能会返回其它状态码，如`200`状态码。如下图：
