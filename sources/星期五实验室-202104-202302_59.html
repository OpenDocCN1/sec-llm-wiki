在这里一共有两个大模块，一个是auxiliary/server/socks_proxy，包含socks4a和socks5， auxiliary/server/socks_unc，包含socks_unc，据说有时候socks5的代理不是很稳定。


在设置代理之前，需要添加路由：

先看下当前的路由：route print

或者使用：run autoroute -p

run post/multi/manage/autoroute

use auxiliary/server/socks_proxy
