# **1.简单介绍**  

GRFICS（工业控制系统仿真框架）由5个VirtualBox虚拟机组成。在仅主机的虚拟网络上相互通信。这个靶场主要是模拟一个化学反应，攻击者需要在理解modbus协议的基础上关闭这个化学反应，或者取得操作员电脑权限，上传恶意的PLC程序使这个反应发生爆炸。

## **Simulation VM**

这台虚拟机（ChemicalPlant）运行一个由模拟远程 IO 设备通过简单 JSON API 控制和监控的真实化学反应。然后，这些远程 IO 设备由 PLC VM 使用 Modbus 协议进行监视和控制。这台虚拟机位于 ICS 子网 (192.168.95.0/24) 中，IP 地址为 192.168.95.10-192.168.95.15。

  

![](../Images/80760a1ded21c35baf137e51ae5922a4.png)

  

**Programmable Logic Controller**

  
这台PLC虚拟机(PLC\_2)是OpenPLC的修改版本，它使用旧版本的libmodbus库，具有缓冲区溢出漏洞。这台虚拟机位于ICS子网（192.168.95.0/24）中，ip地址为192.168.95.2。  

![](../Images/825cc4e5c1688b992ee239f2011fcaa3.png)

  

**Human Machine Interface**

  

这台HMI虚拟机（ScadaBR，数据采集与监控系统）主要包含使用免费ScadaBR软件创建的操作员人机界面。该HMI用于监视PLC收集的检测结果并将命令发送到PLC。这台虚拟机位于DMZ子网（192.168.90.0/24）中，ip地址为192.168.90.5。

  

![](../Images/ca1c59af0d80dabbb3ae2494497f742f.png)

  

**PfSense Firewall/Router**

  

防火墙虚拟机（PFSENSE）提供DMZ和ICS网络之间的路由和防火墙功能。WAN接口位于192.168.90.100的DMZ子网（192.168.90.0/24），LAN接口位于192.168.95.1的ICS子网（192.168.95.0/24）。

  

**Engineering Workstation**

  

工作站虚拟机是一个Ubuntu 16.04机器，用于使用OpenPLC的软件。这台虚拟机位于ICS网络（192.168.95.0/24），ip地址为192.168.95.5。

![](../Images/33ef0a41db470570107cc2abee253f50.png)

再次打开wireshark，查看eth0网口的流量，过滤modbus流量，查看详细信息。

![](../Images/0fc8c62edfe5d98150b9c7cad403d6fc.png)

  

可以看到有很多数据包在读取寄存器

  

![](../Images/3a59bd03d6ef058fdd63d1a11296dd22.png)

  

这里发现01功能码，也就是图中的read coils( 读线圈寄存器)，可以理解为继电器状态，发现数值为0，可能代表开或者关闭状态，尝试将它修改为1。

  

![](../Images/c3e03a061c4c44598df3ea15ffbba2b9.png)

# **5.上传恶意PLC程序**

  

这里假设拿下了workstation虚拟机，打开模拟化学反应的PLC程序。这个程序在chemical文件夹里面。

  

![](../Images/19cd180edb097acb8e937050176a50cd.png)

  

打开后点击main可以看到主程序。上方是变量列表，下方是一些功能块。

  

![](../Images/effc0a0f68cd5d364ddd072bd8033398.png)

  

最下方的run bit变量与进程运行有关，也就是之前我们修改的变量。

  

![](../Images/b5b9247944ab26a395e3d507fb69707f.png)

  

打开初始化功能块功能块，查看里面的设置，其中press\_sp\_c的值为55295。表示压力设定值为多高，如果太高，会对ICS产生破坏。
