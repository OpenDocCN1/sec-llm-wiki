#### 3.4 提权

  

回到正题，第一个flag内的提示告诉我们，我们需要访问root目录下的flag(上面英文可以直接百度翻译)

  

尝试`cd root`，发现权限不够，看来接下来需要做的就是提权了。

  

![](../Images/15bd1daacbfae9b6145eb882d8e8355d.png)

  

先列举一下alice的权限，发现在/user/bin/php目录下有root权限

  

```
sudo -l
```

  

![](../Images/429a03b46dffa89384bc8f806dae087c.png)

  

php有root权限，那就好办了啊，直接调用system命令读flag就行了

  

```
sudo php -r 'system("cat /root/flag");'
```

  

![](../Images/afb321dcdea4935ceb1ae2afec858dbb.png)

  

读 **/root/flag** 发现没有这个文件，想到第一个flag的文件名是 **flag1.txt** ，那么第二个flag的文件名应该就是 **flag2.txt** 了，尝试读 **flag2.txt**。

  

```
sudo php -r 'system("cat /root/flag2.txt");'
```

  

读取成功！

  

![](../Images/e3669cb58fd1c7d4e91a3e57e877aef9.png)

  

当然也可以php弹一个bash出来，然后在root目录下发现flag2.txt

  

```


sudo php -r 'system("/bin/bash");'
```

  

![](../Images/9cdd0f2684c59d71cd0ced711b3c9a1b.png)
