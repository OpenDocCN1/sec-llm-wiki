**前言**

谷歌搜索引擎不仅是强大的搜索工具，同时也是一款强大的黑客工具。在web网站的漏洞SQL注入中，也是比较容易被发现的。利用谷歌搜索语法："inurl:id="，就可以发现许多带有参数的URL，而往往有些URL中的参数是存在SQL注入的。  

我尝试了搜索了一波PHP语言编写，并且存在参数的站点  

![](../Images/ebde4df25449065f236aeb18ab22bcde.png)

  

**过程记录**

1、点击进入网站

![](../Images/4c29d997144b4131b4897f621686630d.png)

  

2、测试参数“id”是否存在注入，添加单引号后，网站报错，可能存在SQL注入

![](../Images/dd03adfab3d92c5f28825287fca5a1b9.png)  

  

3、这里脚本小子直接掏出了SqlMap  

python sqlmap.py -u "targeturl"  

![](../Images/e4cdd585a0adde00c8e0a246d46966ec.png)

可以看出确实存在SQL注入

  

4、好奇的我决定瞧一瞧数据库  

python sqlmap.py \-u "targeturl" --dbs

![](../Images/d290d6740e42645e7faa9adbc86900fd.png)

  

5、这能忍吗？我就再看一眼![](../Images/768da211f166918d618b9803e2ddc08b.png)

python sqlmap.py \-u "targeturl" -D isc --tables

![](../Images/676dbd96444bb325fe712a86e3c6c7d7.png)

没啥好看的，我要溜了
