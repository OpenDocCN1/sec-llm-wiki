**前言**  

这里所说的LAMP分别代指Linux、Apache、Mysql、Php。DVWA是一款基于Php和Mysql开发的Web靶场练习平台，集成了常见的Web漏洞，例如Sql注入,XSS，暴力破解，文件上传等常见漏洞。本文详细讲解了DVWA靶场的安装。

**过程记录**

dvwa 靶机前提需要搭建一个 LAMP 环境。这里是以 Centos7 为例。在此之前我们需要配置一下防火墙规则，否则我们部署的 DVWA 会有几个选项因为权限问题 不通过。

1.关闭 firewall(防火墙)：

systemctl stop firewalld.service #停止 

firewall systemctl disable firewalld.service #禁止 firewall 开机启动

  

2.关闭 SELINUX

vi /etc/selinux/config #打开配置文件

#SELINUX=enforcing #注释掉 

#SELINUXTYPE=targeted #注释掉 

SELINUX=disabled #需要修改的地方

:wq! #保存退出

  

3.重启一下机器

reboot

  

4.清空防火规则

iptables -F

  

**一、apache**

1.安装 apache 

yum -y install httpd

  

2.开启 apache 服务 

systemctl start httpd.service

  

3.设置 apache 服务开机启动 

systemctl enable httpd.service

  

4.查看 apache 运行状态 

systemctl status httpd

![](../Images/4b96eed0ba9085e289e23463121655bf.png)

在客户端浏览器中打开服务器 IP 地址，会出现下面的界面，说明 apache 安装成功  

![](../Images/d94f12c91186dd4b875d5819cc8597f3.png)

  

**二、Mysql**

这里为什么要安装 MariaDB 而不是 Mysql 呢？因为 Mysql 已经被别人收购了，有着闭源的风险，所以厂家使用了 MariaDB 代替 Mysql，MariaDB 是 Mysql 的其中一个分支，其中的 语法大部分都是相同的。

1.安装 mariadb

yum -y install mariadb mariadb-server

  

2.开启 MySQL 服务 

systemctl start mariadb.service

  

3.设置开机启动 MySQL 服务 

systemctl enable mariadb.service

  

4.查看 mariadb 运行状态

service mysqld status  

  

5.设置 root 帐户的密码 

mysql\_secure\_installation

然后会出现一串东西，可以仔细读一下，如果你懒得读，就在提示出来的时候，按 Enter就好了，让你设置密码的时候，你就输入你想要的密码就行，然后继续在让你选择 y/n 是，Enter 就好了；当一切结束的时候，你可以输入 mysql -u root -p 的方式，验证一下；

![](../Images/fd3511e6bc325b090b2f004a35a048fe.png)

当看到以上画面时，即代表 mysql 安装成功，输入 exit 即可退出数据库界面。

  

**三、php**

1.安装 php

yum -y install php

  

2.重启 apache 服务 

systemctl restart httpd 或者 systemctl restart httpd.service

  

3.将 PHP 和 MySQL 关联起来 

yum -y install php-mysql

  

4.安装常用的 PHP 模块 

yum -y install php-gd php-ldap php-odbcphp-pear php-xml php-xmlrpc php-mbstring php-snmp php-soap curl curl-devel libjpeg\*php-imap php-pear php-mcrypt php-bcmath php-mhash libmcrypt php-devel

  

5.重启 apache 服务 

systemctl restart httpd.service

  

6.权限控制 

chown apache:apache -R /var/www/html

  

7.测试 PHP 安装是否成功

cd /var/www/html

vi info .php # 输入下面内容 

:wq!#保存退出

在浏览器中输入“虚拟机的 ip/info.php”若看到系统的信息则说明 php 安装成功

![](../Images/1feb5000c8afe112caa2575b24dbd6ac.png)

自此 LAMP 环境就搭建好了，接下来就是部署 dvwa 了。

  

**四、DVWA**

1.首先是下载 DVWA（http://www.dvwa.co.uk/）

![](../Images/8f73d052b0a1d302b12d6297fde87eab.png)

  

2\. 解压 DVWA 压缩包

yum install unzip -y #下载解压工具

unzip DVWA-master\_\\(1\\).zip 

ls DVWA-master

![](../Images/4109d3f76c5b00e644f041b174b1e0d9.png)

  

3.移动到 apache 根目录下和修改所有权

mv DVWA-master /var/www/html 

chown -R apache:apache /var/www/html/\* 

cd /var/www/html/

![](../Images/5774518c45ed21aa1dbb149feab1cfa8.png)

  

4\. 查看 DVWA 的配置文档,配置 DVWA 

vi config.inc.php.dist 

cp config.inc.php.dist config.inc.php

![](../Images/e8a48978b70fb5ea4d82e4529364dac1.png)

这里还有一个公钥和私钥需要填写，提供一组，随便用，复制粘贴即可

![](../Images/0d9878374ffe8c1eb56550dd3d87dd6c.png)

  

5.allow\_url\_include 这里也是必须要配置的一个地方 

vi /etc/php.ini 

systemctl restart httpd

![](../Images/724ceed2bf3befdd27ec3b7dbcbeeef0.png)

最后当所有的状态都为绿色，代表我们设置成功了，就差最后一步

  

6.自动创建 DVWA 的数据库

![](../Images/f7513aa41ae36b59f222bbb607100897.png)

7.进入后台，就搭建成功了
