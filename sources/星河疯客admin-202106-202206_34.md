# 某大学教务系统后台信息泄露漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2OTYzNTExNQ==&mid=2247483692&idx=1&sn=6ccf16f77812c6146a18d2ada88e3c05&chksm=ce9b4468f9eccd7e390f6607d8565439d90b08aeab469cf541ff5a4e428e3a1bd63cd11b57e7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2OTYzNTExNQ==&mid=2247483692&idx=1&sn=6ccf16f77812c6146a18d2ada88e3c05&chksm=ce9b4468f9eccd7e390f6607d8565439d90b08aeab469cf541ff5a4e428e3a1bd63cd11b57e7&scene=27#wechat_redirect)

**前言**  

此漏洞已经提交CNVD漏洞平台。此文章仅供学习交流使用。萌新小白，不喜勿喷。  

**过程记录**

1.首先进入网站首页。熟悉的某教务管理系统，目前还有很多高校采用这套教务系统。

![](../Images/a64d75b3a1a52b44a700aa1eb1490ecd.png)

  

2.某管理系统会记录登录日志，而有的学校没有对此日志文件做保护机制，导致了敏感信息的泄露。这里的敏感信息有用户名、密码和 IP 地址。用御剑扫描存在的日志文件。  

![](../Images/851a0ad2d2e5f22f7a2629d4d0c17bf8.png)

3.这里可以看出来该学校对于所有的登录都有保存日志。随便点开一个，可以查看到学号和密码以及 IP 地址。 

注：由于对方服务器是英文版的 windows 搭建的，所有当我直接访问时是乱码。所有我开 了一台英文版的 Windows 服务器打开时，虽然也有乱码，但是账号和密码能看见。  

![](../Images/9708426cc61bfa0eaed4a1eadd2e2add.png)

红色方框内就是账号和密码。密码是经过特殊加密的，虽然我破解不开，但是到这里已经心满意足了。我反手就是上报CNVD，哈哈哈
