## 前言

做渗透测试项目本来是不搞逆向的，但是组长提供了一个信息收集的思路，可以把APP反编译出来查里面的子域名，资产等等，于是开始搞APP反编译。

## 1、在线反编译

很简单方便的一个方法，只要打开网页，把APK放进入，就可以在线反编译了，不过速度比较慢，对于比较大型的APK还是不要用这种方法，容易出错。

### 2.2 APTtool

#### 2.2.1、下载apktool.jar

![](../Images/28cdeb96e8391922a676569bbc2d5d2c.png)

#### 2.2.2、生成apktool.bat

下载好apktool.jar之后，新建一个文件夹将apktool.jar放进去，然后在此文件夹下新建一个文本文档，将以下代码输入进去

```



@echo off
```

**注意：代码中的apktool.jar的名字需要与刚才下载的apktool.jar名称一致。**

然后我们保存一下，重命名为apktool.bat

#### 2.2.3、进行反编译

将需要进行反编译的文件与APKTOOL放在一起

![](../Images/d4c24fe3d3ef2f0c86bb0f6ef9eba269.png)

然后，打开命令行界面，定位到apktool文件夹，输入以下命令：

```
apktool.bat d -f  xxx.apk  -o text
```

**注意：（命令中xxx.apk指的是要反编译的APK文件全名， text为反编译后资源文件存放的目录名称，即为：apktool.bat d -f \[apk文件 \] -o \[输出文件夹\]）**

如果出现报错，参考以下内容：

```


> 1.Input file  was not found or was not readable.
```

解决方案：

*   • 1和2是因为apktool升级到2.0以上时，使用方式已经替换，格式为：`apktool d [-s] -f <apkPath> -o <folderPath>`，参数具体的意思可以直接打apktool回车(windows)查看帮助。
    
*   • 3是因为apktool版本过低导致，请升级到最新版本，地址：https://bitbucket.org/iBotPeaches/apktool/downloads
    

如果编译成功，会出现以下信息，并输出一个text文件夹。

### 2.3 反编译得到Java源代码

将要反编译的APK后缀名改为.rar或.zip，并解压，会得到classes.dex文件。

![](../Images/12cd25028c1e73c35e28a2a4f6a3cd81.png)

这个classes.dex文件就是java文件编译再通过dx工具打包而成的。

然后我们找到之前准备好的dex2jar文件夹，在文件夹中打开命令行，输入命令

```
d2j-dex2jar.bat classes.dex
```

**注意classes.dex文件的路径，我这里是把classes.dex放入了dex2jar文件夹中。** 看到如下回显说明反编译成功了，并在dex2jar文件夹中生成了一个classes-dex2jar.jar文件。

![](../Images/7e6497d482498d98ab941b8e1660cf54.png)

![](../Images/b030e984d1db694318955df6ecba0b81.png)

然后拿出提前准备好的工具jd-gui，打开后长这个样子

![](../Images/4610ac4946ed834fc2fec84e85509852.png)

把刚才生成的classes-dex2jar.jar直接拖进去。

![](../Images/00575a2e3abbff57c064f0d00eec7aa3.png)

然后就可以直接看到apk的Java源代码了。

### 错误信息

#### 0x01 若弹窗未检测到SDK环境，说明工具未检测到系统的jdk环境，进去后手动输入即可。

![](../Images/01c2bf26abaff31971090af561afcb1a.png)

点配置，选择Java，然后手动选择jdk的路径。

![](../Images/042deeb84a1b119f285eb5d12682d919.png)

![](../Images/21a0fa42ed4465731addfdcdf01dba34.png)

配置好之后直接将待反编译的APK文件拖进Android Killer工具中。

#### 0x02 若出现乱码或编译失败问题，考虑是否是jdk版本太高或太低,我这里用的是jdk1.8。

#### 0x03 若出现`APK反编译失败，无法继续下一步源码反编译!`,原因是apktool版本太低，更新apktool即可。

下载地址：https://connortumbleson.com/apktool/，尽量下载最新版本。下载好之后，打开 AndroidKiller，依次点击 Android -> APKTOOL管理器 -> 添加，得到下图弹窗；

![](../Images/128f8d623da447e404cd86d8b258ecbf.png)

点击路径，找到刚才下载的最新的apktool.jar，选好路径后输入apktool参数：`–only-main-classes`

**报错中提示是由于非法 dex，这是因为 apk 里有加密过后的 dex 文件，比如有些 apk 的 assets 目录下有加密后的 dex 文件，添加 –only-main-classes 参数即可,注意：这一步是关键，一定不能省略！**

![](../Images/6c0ea12bbaa8a71cefa47542a491b38f.png)

然后在 APKTOOL 管理器 弹窗尾部，重新选择默认的 Apktool 版本为 apktool\_2.4.1.jar；

![](../Images/d20dd293a27014638889fea480d7364c.png)

然后重启Android Killer即可。

#### 0x04 如果一直卡在：正在反编译APK代码，请稍等…… ,

![](../Images/6c22ea18c422cbac07464fc06a7d569b.png)

可以尝试关闭工具重新打开，打开后直接双击刚才的工程。

![](../Images/5f192a64622a794159cf5e5452e591ed.png)

然后，可看到直接分析完成。

![](../Images/34ed759a3ad3e6be58ec7f2ae0da7e71.png)

我们在此处按`Ctrl+F`，在搜索框中输入`http`或`https`或其他内容，即可看到APK文件中的子域名或其他资产。

![](../Images/d1cf5dd9192ad446b7961dff8c0ec7f2.png)
