**漏洞描述**

7月21日，Atlassian官方发布了2022年7月的安全更新，其中涉及到Confluence Server的多个漏洞，其中CVE-2022-26138为一个硬编码漏洞。当Confluence Server或Data Center上的Questions for Confluence app启用时，它会创建一个名为disabledsystemuser的Confluence用户帐户。此帐户旨在帮助将数据从应用程序迁移到 Confluence Cloud的管理员账号中。该帐户通过使用硬编码密码创建并添加到confluence-users组中，在默认情况下允许查看和编辑 Confluence 中的所有非受限页面。未经身份验证攻击者可以利用所知的硬编码密码登录Confluence并访问该组有权限访问的所有页面。![](../Images/b36d52a915e2f11390619b7160a59c53.png)

**相关介绍**

Atlassian Confluence Server是澳大利亚Atlassian公司的一套具有企业知识管理功能，并支持用于构建企业WiKi的协同软件的服务器版本。

**利用范围**

Questions for Confluence app == 2.7.34Questions for Confluence app == 2.7.35Questions for Confluence app == 3.0.2

**漏洞分析**

## **环境搭建**

此次漏洞分析环境可参考[CVE-2022-26134 Confluence OGNL RCE 漏洞分析](http://mp.weixin.qq.com/s?__biz=Mzg3NDcwMDk3OA==&mid=2247483775&idx=1&sn=2a6eeede0ac6c65900572e07b19f3f8f&chksm=cecd88a2f9ba01b49c1079d1ffcf3d89a4a6792378cd56abf4a29e22727a8a90dee86806b359&scene=21#wechat_redirect)。

进行搭建。分析源码为confluence-questions-3.0.2.jar或者另外两个版本。

## **代码分析**

动态调试之前，在配置文件default.properties中可以找到所创建用户的相关信息，其中的username和password都是固定的。

![](../Images/5bcb9093f756e00b34cb05ffac137e3b.png)

紧接着在com.atlassian.confluence.plugins.questions.util#BuildInformationManager处打下断点。

![](../Images/5bcacc4fdb6b315782461b66d1e46e2b.png)

开启debug模式，随后在confluence中上传confluence-questions.jar应用。

![](../Images/06fea4479545300551abf8824052bdb7.png)

在安装应用的过程中，会从配置文件中获取到固定的账号信息。

![](../Images/b0263e84ae5a10f5f3db391decd3a4d1.png)随后进入com.atlassian.confluence.plugins.questions.service.UserCreatorServiceImpl实例化UserCreatorServiceImpl对象。![](../Images/4418566196668e34061f69fbd22b2753.png)继续跟进，会进入下面的addPredefinedPermittedDisabledUser方法。![](../Images/0cc6c98e85f7cc1c81dc8005fdf3fdce.png)

在此，固定disabledsystemuser用户完成创建并将其添加到confluence-users组。

![](../Images/b430b8ebf7cb24321348e4ffa822b60c.png)

## **漏洞复现**

成功上传Questions for Confluence应用程序。![](../Images/ed2c6642ee6dda0aed640d78b045fe1c.png)

使用硬编码密码创建的账号进行登录。

![](../Images/37d5bf435f01e2cf96615639752bc757.png)成功登录，且该用户拥有管理员权限。![](../Images/141774cff4351dc0573d07306ddf548c.png)![](../Images/0972437e879b907632e8c6672e52af27.png)

**修复建议**

参考官方公告中的修复建议：

更新Questions for Confluence扩展至以下安全版本:

2.7.x >= 2.7.38 (Confluence 6.13.18 到 7.16.2)

Versions >= 3.0.5 (Confluence 7.16.3 之后的版本)
