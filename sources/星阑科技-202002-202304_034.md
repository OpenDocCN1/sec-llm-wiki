# 一封来自北京软协的感谢信

近日，**北京软件和信息服务业协会向星阑科技发来感谢信**，对星阑科技过去一年来对北京软件和信息服务业协会的全方位支持和卓越贡献表示感谢。 

![](../Images/976f78a1d94bd0fbcbc97004bd197ae9.png)

**感谢信中提到：**“这一年，贵公司积极参与产业互联网创新发展论坛等各类交流活动，为协会的品牌提升做出了卓越的贡献；积极参与行业各类调研，建言献策，为搭建畅通的政企沟通桥梁提供了依据参考：积极参与软件和信息服务业综合实力企业、社会责任建设倡议、各类创新案例征集等工作，为《2022北京软件和信息技术服务业综合实力企业报告》《北京软件和信息服务业社会责任建设白皮书（2022)》《2022前沿数字技术创新应用案例集》等一系列成果发布提供了强有力的支持；积极参与协会多个团体标准的编制，共同发布了《软件和信息服务业诚信企业评估规范》等6项团体标准…为此，我们向贵公司长期以来的关心和支持致以诚挚的感谢！”星阑科技自成立以来，一直基于AI深度感知和强大的自适应机器学习技术，帮助用户迅速发现并解决面临的安全风险和外部威胁，并凭借持续的创新理念和以实战攻防为核心的安全能力，发展成为国内人工智能、信息安全领域的双料科技公司。为解决企业API安全问题，公司从攻防能力、大数据分析能力及云原生技术体系出发，提供全景化API识别、API高级威胁检测、复杂行为分析等能力，构建API Runtime Protection体系。其API安全产品“萤火”拥有不同应用场景的解决方案，适配服务器、容器集群、微服务架构以及云平台等多种架构，全面覆盖企业API安全风险。可以通过API资产梳理、漏洞管理、威胁监测、开放式数据平台、运营与响应能力，解决企业API漏洞入侵、行为异常、数据泄露等核心风险，缓解企业的API风险。目前该产品已在金融、政府、运营商、互联网等众多行业落地，得到了客户的一致认可。![](../Images/4da1099d29073a53b126c94b14f3c74b.png)

与此同时，星阑科技积极履行作为创新型网络安全企业的责任，从自身商业模式、技术优势入手，积极参与了由工业和信息化部网络安全产业发展中心牵头组织的《数据传输安全白皮书》的编写，首个云原生API安全标准的编制工作，主动融入国家和社会需要的各个层面。

一直以来，星阑科技与北京软件和信息服务业协会在科技创新、标准制定、产业落地等领域都展开了全方位、多维度、深层次合作。此次发来的感谢信更是对我们工作的认可和鼓励。未来，星阑科技将继续与协会携手合作，持续投入并整合更多力量，共建产业生态圈，积极推动产品、解决方案和应用的创新与落地，为客户提供可靠、安全、高效的数字化产品及解决方案，助力中国网络安全行业高质量发展，为数字经济生态的安全、健康发展贡献力量。
