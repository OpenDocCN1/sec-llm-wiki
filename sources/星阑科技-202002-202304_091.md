**为什么制造业比其他行业经历的API相关事件更多**

最近一份调查报告，对600名英国和美国首席信息安全官和网络安全专业人员进行调查，报告显示，制造业比其他行业经历的API安全事件更多。企业组织拥有超过15，000个API，调查显示，其中四分之三的受访者都经历过与API相关的事件。

![](../Images/e174f483ba3c569a6ad37b7a7f7673d3.png)

  

该报告调查了六个行业领域，分别是：金融服务，零售和电子商务，医疗保健，政府和公共部门，制造业以及能源和公用事业。其中，制造业的API事件发生率最高（79%），部署API安全平台的可能性最小（不到30%），并且进行API安全测试的频率最低。

  

从直觉上讲，制造业将是一个落后的状态：它们在一个非常异构的环境中运行，有许多不同的遗留系统，并且由于24/7运行的经济压力，可能没有机会测试或升级系统。

**该报告强调了业界的一个共同关注点：不完整的 API 清单。**超过四分之三的制造业受访者表示，他们对当前的API资产没有准确的了解。仅这一事实就使他们面临重大且无法量化的风险。

**使用 Azure 破解 API 令牌**

  

最后，Dan Epp发布了一个有趣的阅读，内容是关于使用 Azure 计算资源破解 API 令牌的可行性。

![](../Images/c2d95d3e238f805d21c8318383d0939f.png)

Epp 尝试破解在与易受攻击的 API 应用程序 crAPI 会话期间捕获的 JWT 签名密钥，并使用流行的哈希猫工具在标准桌面上暴力破解 JWT。鉴于所使用的算法的强度和任何合理长度的密钥，成功的攻击可能需要几十年的时间 - 这显然是完全不切实际的。

但是，Epp 碰巧是微软安全 MVP，因此有幸能够访问 Azure 资源。他介绍了如何将 Azure VM 与合适的 GPU（例如 NCv3 系列虚拟机）结合使用，该虚拟机为云破解提供了最佳性价比。为了演示，Epp 在不到一分钟的时间内破解了 crAPI 的签名密钥，估计成本为 1 美元，但是，这只是一个 5 个字符的密钥。

  

  

**显然，在现实世界中，不太可能找到如此短的签名密钥。Epp 对较长的键给出了以下估计值：**

**• **6 个字符：约 14 分钟

**• **7 个字符：约1 天

**•** 8 个字符：约00 天

**•** 9 个字符：约23 年

  

与以往一样，标准建议适用：使用最大可能的密钥和最强的算法。
