# 2022无锡（北京）科技合作洽谈会上星阑科技签约重大科创项目

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247495699&idx=1&sn=ce70af1c7fd34d9e9b669890f9a8b8bf&chksm=c0075d8ff770d499dc61f95ac6f9636565cf4cec3136fc5e4bc8cffc5dfc77a67d9a8c706434&scene=126&sessionid=1681375555#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247495699&idx=1&sn=ce70af1c7fd34d9e9b669890f9a8b8bf&chksm=c0075d8ff770d499dc61f95ac6f9636565cf4cec3136fc5e4bc8cffc5dfc77a67d9a8c706434&scene=126&sessionid=1681375555#rd)

![](../Images/54d0f0b14645ed5807656babdac56cf6.png)

近日，2022无锡（北京）科技合作洽谈会在京顺利举行，京锡两地各界精英济济一堂，共话合作创新，共谋发展大计，进一步对接京津冀科技创新资源，释放科创名城“锡引力”，打响创新引领“太湖牌”，拓展无锡合作“朋友圈”。![](../Images/6e0334d4b3bdd97ecf90e2a83aa1b7ca.png)

活动现场，74个战略合作以及重大科技合作项目签约，项目总金额达到202.34亿元，其中市政府与中国生物技术发展中心签订战略合作协议，国新风险投资管理有限公司与无锡市创新投资集团有限公司就国风投生物科技（无锡）战略合作项目签约。**星阑科技与无锡市新吴区政府就合作建设“萤火·API智能防护引擎安全智能运维中心”项目在现场进行了签约。**

![](../Images/8a004348677f986d273a52c1d3110f96.png)新吴区又称无锡高新区，是无锡的主要经济支柱区域之一，在2021年实现地区生产总值2200亿元，增速无锡市第一，主要经济指标增速领跑全市。在智慧城市建设方面，新吴区以区城市运行管理中心为核心，全面探索和推进大数据、区块链、元宇宙等新一代信息技术在智慧城市建设中的场景应用，已落地智慧城市项目近百个。在坚持推进新技术应用同时，新吴区坚定秉持“技术创新，安全先行”的理念，在全国区级政府中率先在政务API安全领域展开布局，与星阑科技就政务信息系统API资产管理、API风险监控、API攻击识别、政务数据安全、居民个人信息保护等方面展开了全面合作，并联合建立新吴区API安全智能运维中心，进一步提升“法治新吴、平安新吴”水平。![](../Images/581f7b22972fda4facf3cccdbe3bde32.png)作为此次合作项目的核心技术支持平台——星阑科技“萤火·API智能防护引擎”，已实现从资产-风险-事件-数据等多个维度实现对API使用情况的实时监控、异常访问的可视化。该方案对流量中的API进行自动聚合、分类、自定义标签化管理，通过高可视化、已操作的界面进行展示，便于管理员实现API安全的统一监测。该方案充分适配传统IT架构及云原生容器化、微服务架构，全面覆盖企业API安全风险。此外，“萤火·API智能防护引擎”还可以基于企业级大数据分析平台以及机器学习数据实体识别算法，提供符合ISO PI PII标准以及金融、政府、通信行业细分标准的敏感数据实体识别与分类分级能力，并在此基础上针对API恶意攻击事件、数据泄露事件、撞库攻击进行实时告警，使企业能够从容应对漏洞攻击、黑客入侵、数据泄露以及账号滥用风险。该方案还通过AI驱动的数据模型分析每一次API调用，区分正常访问与恶意攻击，自动更新防御逻辑，联动API网关实现毫秒级攻击拦截，在不影响业务的可用性与性能的前提下，主动发现API攻击向量，解决企业API资产梳理、漏洞入侵、数据泄露问题。

未来，星阑科技将坚决响应习近平总书记提出的“筑牢网络安全防线”号召，继续加强与各地、各级政府部门的交流互动，分享星阑在API安全领域的前瞻观察与实践，与网络安全同行一道，共筑我国API安全“长城”。
