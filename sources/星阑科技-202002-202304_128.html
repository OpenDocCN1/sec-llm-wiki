No.1

数以千计的应用程序泄露 Twitter 访问令牌漏洞


漏洞详情：总部位于新加坡的网络安全公司CloudSEK在一份报告中表示，共有3207个移动应用程序泄露了有效的Twitter用户密钥和密钥信息。大约230个应用程序被发现泄露了OAuth访问令牌和访问机密。

漏洞危害：当攻击者设法得到这些密钥后，就能够以关联的 Twitter 用户身份进行操作，这些信息为攻击者提供了访问用户Twitter帐户并执行各种操作的机会，包括：

  • 阅读信息；

  • 代表用户转发、点赞或删除消息

  • 删除关注者或关注新帐户

  • 修改账户设置，例如修改头像


小阑修复建议

可以通过以下方法防止令牌和密钥泄漏：

  • 执行代码审查以识别本地不安全存储的实例。

  • 确保源代码中包含运行时变量的文件未随应用程序一起提供。

  • 使用源代码扫描工具（例如 Semgrep）扫描存储库中的代码以识别存储的凭据。

  • 定期更换 API 密钥，并制定密钥撤销策略以防泄露。



No.2

Golang中的参数走私攻击


漏洞详情：Oxeye 的安全研究团队在基于 Golang 的应用程序中发现了一个安全漏洞。

漏洞危害：在某些情况下，由于使用了不安全的 URL 解析，它会让威胁参与者绕过基于 HTTP 请求参数的验证。当基于版本 1.17 或更高版本构建的基于 Golang 的公共 API 与运行早期版本的后端服务进行通信时，就会出现问题，从而导致恶意行为者可以走私包含查询参数的请求，否则这些请求将被拒绝。


小阑修复建议

升级所有版本的 Golang，使用替代方法来解析查询，通过去除无关分号或使用其 Semgrep 规则来识别易受攻击的代码来清理 URL。


No.3

Zulip Server 中的提权漏洞


漏洞详情：Zulip server是美国Zulip公司的一款开源的团队聊天应用程序。安全研究人员披露了 Zulip Server API 中一个关键权限提升漏洞的详细信息，该漏洞源于驻留多个组织的zlip Server部署很容易受到攻击，在一个组织中创建的邀请(可能是一个具有较高权限的角色)可以被用来加入任何其他组织。这绕过了对用户电子邮件地址所需域的任何限制，可以用来获得对只有邀请才能访问的组织的访问权。

漏洞危害：由于 Zulip Server 5.4 及更早版本中的授权检查不正确，组织成员可以制作一个 API 调用，将组织管理员权限授予其机器人之一。

影响范围：Zulip Server 的所有版本，最高为 5.4

漏洞评级：中


小阑修复建议

立即升级到 5.5 版本。升级补丁以修复漏洞

补丁获取链接：

https://github.com/zulip/zulip/security/advisories/GHSA-6xmj-2wcm-p2jc
