# 星阑科技受邀第三届GIEC科技创新峰会进行主题演讲

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247494989&idx=1&sn=5099f809056ba52aa18726703969c2be&chksm=c00740d1f770c9c7be0b229eaa275eb16929703eeb2accc39eedadffa68ad88dcdbe29cf6b89&scene=126&sessionid=1681375565#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247494989&idx=1&sn=5099f809056ba52aa18726703969c2be&chksm=c00740d1f770c9c7be0b229eaa275eb16929703eeb2accc39eedadffa68ad88dcdbe29cf6b89&scene=126&sessionid=1681375565#rd)

![](../Images/54d0f0b14645ed5807656babdac56cf6.png)

  

近日，GIEC第三届互联网文娱科技创新峰会在上海圆满收官。此次峰会以“技术赋能 流量共生”为主题，重点聚焦游戏、社交直播、音视频、电商、教育、出海等行业，围绕互联网Ai智能、大数据、云计算、5G、移动应用、区块链、信息安全等行业创新技术和场景实践应用展开探索交流。**星阑科技安全专家汤青松受邀参加，并以“安全工具可视化编排架构设计与应用”为主题进行了演讲分享。**

![](../Images/d78c6107c0269f16a17aac05c95ed436.png)

GIEC互联网文娱峰会是聚焦国内外互联网企业最具前瞻的行业峰会，已在上海、北京连续成功举办两届，同时在上海、深圳、北京、浙江等地区连续举办相关闭门研讨会。峰会始终以技术赋能驱动商业变革为主旨，聚焦互联网元宇宙、游戏、社交直播、音视频、教育、电商、出海、泛娱乐等行业，以决策层、技术层、运营管理层、信息安全层为探讨交流群体，共同探索互联网文娱行业新大陆。

安全工程师日常会用到大量工具和接口，不同的场景所使用的工具、安装方法、数据格式也都有所不同。熟悉这些工具或接口需要花费大量的时间和精力，而且由于工具之间数据不一致，通常需要人工将数据加工才能进行流转，会浪费大量精力在重复工作中，例如站点渗透测试、0day应急响应、日常代码审计等。而可视化编排平台集成了大量工具，可以在平台中通过拖拽工具，快速完成私人订制的工作流，所以在此次互联网文娱科技创新峰会上汤青松为大家分享了，安全工具可视化编排的架构设计和业务上的应用场景。

![](../Images/94efcc870756e1916ab47e91e2033fa7.png)

汤青松表示，在安全场景的编排中蜻蜓收集不同来源的安全需求场景，运用人机结合的方法进行工具编排，在定制化场景下达到降本增效的目的。蜻蜓编排平台可以为安全团队提供定制化的流程和控制，加速日常工作的数据流转。安全团队的大量日常事务性工作也可以借助蜻蜓加以自动化。蜻蜓的装备市场还可以帮助工程师快速编排适合自己的场景，节约工程师时间。

除此外，在资产梳理场景中，蜻蜓支持云端资产、内网资产、代码资产、域名资产等丰富的组件，开箱即用。除此外，蜻蜓还可以为漏洞检测、信息收集、代码审计等提供方便。

![](../Images/398ae2667a75f96562e05f87a7b3b5a1.png)

最后，汤青松表示，在产品的研发和创新过程中，星阑科技一直与时俱进，跟进行业最新的趋势及发展动态，致力于助力各行各业企业实现安全运营。未来，星阑科技也将不忘初心，专注于产品研发，继续提升在行业中的影响力，为安全行业发展贡献出一份力量。
