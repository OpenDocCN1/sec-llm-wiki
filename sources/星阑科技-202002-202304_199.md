# 双重认可！星阑科技入选“2022数据安全产业竞合力洞察报告”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247493319&idx=1&sn=17f3f3c8e605d5299623e43e04689c94&chksm=c0074b5bf770c24d88fecaacf98c21341914f4f4af7325d3fb4beb3f96d48a01fdcc156a5355&scene=126&sessionid=1681375596#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247493319&idx=1&sn=17f3f3c8e605d5299623e43e04689c94&chksm=c0074b5bf770c24d88fecaacf98c21341914f4f4af7325d3fb4beb3f96d48a01fdcc156a5355&scene=126&sessionid=1681375596#rd)

![](../Images/54d0f0b14645ed5807656babdac56cf6.png)  

  

近期，由嘶吼安全产业研究院撰写的《2022数据安全产业竞合力洞察报告》（以下简称报告）正式发布。报告通过对参与厂商的竞合力洞察分析，提供了数据安全厂商及其产品、服务和解决方案的竞合视角，深挖数据安全产业的真实发展情况，为资方和甲方提供细节参考。**星阑科技系列产品凭借在数据安全领域强劲实力与影响力，成功入围《2021年数据安全企业厂商竞合力图》以及《数据安全产业需求行为全景图谱》中解决数据资产梳理/分类分级问题、解决数据安全合规问题、解决数据访问控制问题三大类别。**![](../Images/36fff8502167e9fa69cad38219445d8d.png)

报告历时两个月的调研、撰写，百余家数据安全厂商踊跃参与，共同深入分析厂商竞合力、盈利模式、发展阶段、典型案例及未来趋势，系统地总结了数据安全产业的市场规模及竞争壁垒，最终成功打造了《2021年数据安全企业厂商竞合力图》和《数据安全产业需求行为全景图谱》。

![](../Images/ed44427db3c6d8179465030d13bce81c.png)

智能时代，大数据技术在各行各业的应用不断深入，应用场景与范围加速扩展，为行业决策提供了科学依据，为企业改革创新、高质量发展提供了强大动力，但在数据采集、存储、分析、共享等环节面临的隐私安全等风险也不容忽视，数据安全事件时有发生，因数据泄漏给企业带来巨大损失的事件也数不胜数，因此，全力保障各行业数据安全助力企业安全发展也成为重中之重。星阑科技作为一家创新型的公司，一直紧跟时代发展方向，持续注于数据安全的技术研究，力图为客户带来高质量的安全产品和服务。

![](../Images/f706294061c583a0c2bca8ca83620a88.png)

随着数字化进程不断加快，API在应用环境中变得越来越普遍，带来的数据量比以往任何时候都要多且更复杂多样。传统基于数据统计的API管理技术方案有其局限性，星阑科技产品可以通过资产-风险-事件-数据等多个维度实现对API使用情况的实时监控、异常访问的可视化。对流量中的API自动聚合、分类、自定义标签化管理，并以可视化的方式便于管理员进行探索和调查，从而实现API安全统一监测。对于备受关注的企业敏感数据，星阑科技产品可以基于企业级大数据分析平台以及机器学习数据实体识别算法，提供符合ISO PI PII标准以及金融、政府、通信行业细分标准的敏感数据实体识别与分类分级能力，并在此基础上针对API恶意攻击事件、数据泄露事件、撞库攻击进行实时告警，使企业能够从容应对漏洞攻击、黑客入侵、数据泄露以及账号滥用风险。

![](../Images/df69386073ba489d817dffd353f33eb5.png)

数据要素是数字经济深化发展的核心引擎，未来，随着数据安全产业市场规模不断扩大，星阑科技作为网络安全的专精型企业，也必将坚定不移地履行企业社会责任，为国家在数字时代的高质量发展保驾护航。
