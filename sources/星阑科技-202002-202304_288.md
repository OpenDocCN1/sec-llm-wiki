# 喜报｜星阑科技荣获第六届清华校友三创大赛全国十强！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247491134&idx=1&sn=91601b5ddc4d7954cbe656d461c9babc&chksm=c004b3a2f7733ab4a5f3d3eddc7ed56c132f033f8703a13d7ee440bddde82089e934669786d6&scene=126&sessionid=1681375641#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247491134&idx=1&sn=91601b5ddc4d7954cbe656d461c9babc&chksm=c004b3a2f7733ab4a5f3d3eddc7ed56c132f033f8703a13d7ee440bddde82089e934669786d6&scene=126&sessionid=1681375641#rd)

![](../Images/54d0f0b14645ed5807656babdac56cf6.png)

  

由清华校友总会、郑州市人民政府主办的“汇智清华 筑势中原”第六届清华校友三创大赛AI大数据全球总决赛在郑州中原科技城成功举行。经过激烈比拼，评委公开评议，最终种子、成长、天使三组分别诞生比赛十强。**得益于殷实的技术积累和行业创新应用，星阑科技脱颖而出，跻身全球总决赛AI大数据天使组十强。**![](../Images/9f7319df714e072049664040701fc34c.png)总决赛路演现场，星阑科技首席运营官都基泽介绍了星阑在万物互联时代下对API安全探索。他提到，随着互联网、大数据、云计算、人工智能、物联网等信息技术的飞速发展，智能信息化时代正悄然来临，并深刻地影响着人们的工作、生活方式。数字经济发展速度之快，辐射范围之广、影响程度之深前所未有。在这个过程中携带大量敏感数据的API通信已成为流经所有业务系统的“血液”，其安全风险与数据风险急需解决。![](../Images/5266909e3d505e2d73e0ca96ee304da0.png)

他表示，为解决企业在数字化转型过程中的安全问题，星阑科技技术团队走访了几十家客户，调研分析了国内外众多安全产品，最终推出了创新型API安全防护平台“萤火”。“萤火”拥有不同应用场景的解决方案，可以实现对API使用情况的实时监控，异常访问的可视化。对流量中的API自动聚合、分类、自定义标签化管理；并以树状图的方式便于管理员进行探索和调查，从而实现API统一管控。其次，“萤火”还基于AI深度感知和大数据分析，通过API统一管控、API风险发现、API实时监控技术，构建了事前、事中、事后多层次、立体化的防御体系，使企业可以从容应对漏洞攻击、黑客入侵、数据泄露以及账号滥用风险，从而守护数字世界的每一次网络调用。

据悉，**去年星阑科技就已经凭借优秀的表现，在第五届清华校友三创大赛TMT/AI大数据/5G区块链全球总决赛种子组取得了优异的成绩，今年在天使组再次获奖无疑是对星阑的高度认可。**志行万里者,不中道而辍足，未来，星阑也将不断超越自我，在API安全领域继续发力，坚持科技驱动、创新赋能，深度挖掘市场需求，不断优化升级产品与服务，为网络安全行业注入新技术，加快行业发展进程！

  

**关于大赛**  

第六届清华校友三创大赛在全球设有十大赛区，包含种子、天使及成长三大组别，互联网与新媒体、AI大数据、健康医疗、先进制造、集成电路与物联网、人居环境与乡村振兴、文创体育与美好生活七大赛道；本次AI大数据赛道全国有111个项目报名，60个项目通过赛区决赛入围全球总决赛。

![](../Images/f7617ab224fa8e9feeaed132f44c5c14.png "好看的图.png")

  

**关于星阑**  

北京星阑科技有限公司（以下简称“星阑科技”）成立于2018年11月，总部位于北京，在深圳、上海等地均设有分支机构，是一家以安全攻防技术为核心、数据智能为驱动的网络安全科技公司。

星阑科技基于AI深度感知和强大的自适应机器学习技术，帮助用户迅速发现并解决面临的安全风险和外部威胁，并凭借持续的创新理念和以实战攻防为核心的安全能力，发展成为国内人工智能、信息安全领域的双料科技公司。为解决API安全问题，公司从攻防能力、大数据分析能力及云原生技术体系出发，提供全景化API识别、API高级威胁检测、复杂行为分析等能力，构建API Runtime Protection体系。
