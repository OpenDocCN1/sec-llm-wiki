# 深入调研，交流合作｜华为公司来我司调研

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247490980&idx=1&sn=86f2ecf57d0ea84b40adb4a82f0380c5&chksm=c004b038f773392e0bf9826a3cadc74345027a0e72e1d06eb0f4ba04986157a04081b6979af2&scene=126&sessionid=1681375646#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247490980&idx=1&sn=86f2ecf57d0ea84b40adb4a82f0380c5&chksm=c004b038f773392e0bf9826a3cadc74345027a0e72e1d06eb0f4ba04986157a04081b6979af2&scene=126&sessionid=1681375646#rd)

![](../Images/54d0f0b14645ed5807656babdac56cf6.png)

  

12月13日上午，**华为公司技术专家等一行三人到访公司调研考察，就海淀区政府联合华为公司建设“自主可控软件产业基地”进行交流座谈。**星阑科技CTO徐越、融资与政府事务总监顾博天一同出席了此次交流会。双方共同探讨了产品研发过程中的一些技术问题和未来发展规划，并达成合作共识，为高效实现合作成果转化奠定了良好的基础。![](../Images/d3dbf7113de4a11814b2f3dfa40ab8c2.png)

交流会上，顾博天首先对海淀区政府和华为公司专家一行的到来表示热烈欢迎，并就公司发展概况、战略定位以及现状进行了简单介绍，全面直观的展示了公司近年来的发展成果。他表示，星阑科技的发展得益于海淀区政府长期以来对于科创企业，尤其是对网络安全企业的支持，同时华为公司作为星阑科技早期服务的客户也在公司发展过程中给予了重要的帮助，**星阑科技愿意全力支持、配合海淀区与华为公司，建设“自主可控软件产业基地”和“国家网络安全产业基地”，助力相关产业发展。**他还介绍，公司自成立以来一直致力于凭借世界一流的攻防能力和成熟的云原生体系技术栈，力图为客户带来高质量的安全产品和服务，从而实现了公司又快又稳的发展局面。

随后，星阑科技CTO徐越，就产品的一系列情况进行相关介绍和讲解。他表示，近年来，互联网、大数据、云计算、人工智能、区块链等技术加速创新，日益融入经济社会发展各领域全过程，数字化浪潮席卷全球，企业纷纷顺应趋势进行数字化转型。星阑科技主动加强形势研判，抓住市场机遇，充分利用自身优势，**为企业客户提供高质量的安全产品和7\*24小时更专业的安全服务，帮助企业实现覆盖事前事中事后，贯穿全过程、全方位、全领域的安全检测和安全治理，构建API Runtime Protection体系，确保企业在数字化转型过程中的API安全。**![](../Images/0644c75492da45d6a57f818a2a871a39.png)

相关介绍结束后，调研组对星阑在软件开发管理流程的完备性、软件开发工具链的使用类型、软件开发研发流程每年的投入资金规模和痛点、业务增长过程中，对研发工具的诉求及生态合作等问题上进行了详细的了解，对公司取得的成绩及产品给予充分肯定和认可。调研组表示，华为公司协助海淀区政府计划建设自主可控软件产业基地，发挥华为技术积累优势，精准扶持区内自主可控软件产业发展，希望星阑可以与调研组建立沟通机制，将研发、生产、市场化中遇到的问题和困难反馈给调研组，协助调研组不断完善基地建设方案，助推基地效能最大化。

华为公司表示，华为作为国内领先的拥有自主知识产权、可控可信技术储备的科技企业，已经在多个技术领域上处于世界领先水平。华为此次与海淀区政府合作，投入大量资源，意在扶持和推动海淀区的自主可控软件行业的发展，进一步助力首都的软件行业全面实现自主可控发展。**华为公司与星阑已经在终端网络安全领域展开了较为深入的合作，希望未来星阑与华为生态体系进一步加强合作，扩大产业合作领域，共同推动政府、金融、运营商、互联网等行业企业的数字化高质量发展，实现互利共赢。**![](../Images/20dbe7d395b63060a94ce7c1fbd45304.png)未来，星阑科技将进一步加强产品的创新与应用，充分发挥软硬件协同优势，不断深化与海淀区政府、华为公司在各领域的合作，为企业API安全体系建设提供星阑方案，为国家软件研发自主可控化、网络安全行业发展做出新的贡献。
