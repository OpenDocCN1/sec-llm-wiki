# 实力认证｜星阑科技入选《CCSIP 2021中国网络安全产业全景图》多领域！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247490904&idx=1&sn=d22d92e3becb89286218d21abb6d000d&chksm=c004b0c4f77339d235bd16dd0bc604cf2bd17de54cf1bb4b9476730e7f106953b8afd4ee753e&scene=126&sessionid=1681375646#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247490904&idx=1&sn=d22d92e3becb89286218d21abb6d000d&chksm=c004b0c4f77339d235bd16dd0bc604cf2bd17de54cf1bb4b9476730e7f106953b8afd4ee753e&scene=126&sessionid=1681375646#rd)

2021年12月6日，国内安全行业门户FreeBuf旗下FreeBuf咨询正式发布《CCSIP 2021中国网络安全产业全景图》（第三版）。**星阑科技作为一家以安全攻防技术为核心、数据智能为驱动的网络安全科技公司，凭借出色的创新能力和专业的安全产品成功入围三大安全模块。**相较第二版，CCSIP 2021全景图第三版对原有19个安全模块及80个细分领域的厂商收录进一步调整优化，并且新增1个安全模块（前沿技术）及7个细分领域。它们包括无线安全、SD-WAN、SWG、数据安全管控（平台型）、工控靶场（和安全靶场为包含关系）、SASE、拟态防御。《CCSIP 2021中国网络安全产业全景图》（第三版）最终展示87个细分安全领域，收录578家安全厂商，为企业安全建设及产品选型提供参考。

![](../Images/c057dd336e1149619b01850d616c03f2.png)

**数据安全：**

数字化转型是数字经济时代社会基座的重要组成，面对日益复杂的网络安全态势，星阑科技产品“萤火”基于企业级大数据分析平台以及机器学习数据实体识别算法，提供符合ISO PI PII标准以及金融、政府、通信行业细分标准的敏感数据实体识别与分类分级能力，并在此基础上针对API越权事件、数据泄露事件、撞库攻击进行实时告警，使企业能够从容应对数据泄露以及账号滥用风险。萤火API安全分析平台自推出以来已经服务于多个行业的典型API数字化应用场景，为众多行业用户数据筑牢安全屏障。 ![](../Images/e02aedeeb379f9af175b85204142700b.png)

  

**云安全：**

中国在产业数字化经济转型和新基建的推动背景下，云原生技术的应用正在普及深化中，而受限于云原生的建设步伐，云原生安全市场和相关建设仍处于早期孕育阶段。云原生环境是一个完全API化的场景，API几乎承载了所有的服务间调用，所以星阑科技一直致力于在云原生时代下，守护好企业的API通信，不仅可以防护南北向的流量，也可以提供东西向的全流量的安全防护，有效保证云原生应用的安全性。此次全景图在云安全模块，星阑科技成功入选云原生安全细分领域，也体现了业界对星阑云原生研究的肯定。![](../Images/818367a4012eb942f3e0c0ff36b47549.png)

**安全服务：**

星阑科技经过多年的技术沉淀和实践经验，为客户提供高质量、更专业的安全服务。通过产品部署和本地化人员服务，帮助客户及时发现风险并进行有效处置，将影响控制在最小范围内。除此以外，我们还汇集一线红队与StarCross Portal实验室的漏洞研究成果，帮助客户更好的完成渗透测试，全方位发现漏洞，检验系统的安全性，同时生成测试报告，提供修复方案与加固建议，防患于未然。![](../Images/d542cddec76a510a4bd1eb9d0b8ea6df.png)

星阑科技本次入选全景图多个细分领域，是业内对公司产品专业性的充分认可。面向未来，星阑科技将致力与更多企业用户建立新型伙伴关系，深刻了解客户业务，赋能客户构筑全面、智能的API安全防御体系，满足企业用户在数字化转型和持续创新发展方面的全方位安全需求。

  

**关于星阑**

北京星阑科技有限公司（以下简称“星阑科技”）成立于2018年11月，总部位于北京，在深圳、上海等地均设有分支机构，是一家以安全攻防技术为核心、数据智能为驱动的网络安全科技公司。

  

星阑科技基于AI深度感知和强大的自适应机器学习技术，帮助用户迅速发现并解决面临的安全风险和外部威胁，并凭借持续的创新理念和以实战攻防为核心的安全能力，发展成为国内人工智能、信息安全领域的双料科技公司。为解决API安全问题，公司从攻防能力、大数据分析能力及云原生技术体系出发，提供全景化API识别、API高级威胁检测、复杂行为分析等能力，构建API Runtime Protection体系。**产品“萤火”基于实战攻防经验积累以及智能数据分析模型，可以解决不同场景下API安全风险，帮助客户更好的守护API安全。**
