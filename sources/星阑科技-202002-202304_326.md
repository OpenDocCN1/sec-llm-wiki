# 专业、创新、突破｜星阑科技在Xcon峰会进行精彩分享！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247489440&idx=1&sn=467e3c04e61367e57cf23d1b39d95c6d&chksm=c004ba3cf773332a1249e86892608b4b60e615eb92658f4d15bcb75d7203c1897299934b0c7a&scene=126&sessionid=1681375661#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247489440&idx=1&sn=467e3c04e61367e57cf23d1b39d95c6d&chksm=c004ba3cf773332a1249e86892608b4b60e615eb92658f4d15bcb75d7203c1897299934b0c7a&scene=126&sessionid=1681375661#rd)

10月12日上午，备受业界瞩目的Xcon 2021安全焦点信息安全技术峰会在北京昆泰酒店顺利召开。星阑科技Portal Lab负责人丁湛钊以**“迈向二进制的LLVM”为题在峰会进行了一场精彩的分享**，与国内知名网安企业的专家共同探讨专业性技术议题。![](../Images/ced6c4ac08d53d522da04dc0ebd7c9b8.png)

Xcon安全焦点信息安全技术峰会（XFocus Information Security Conference）创办于2002年，是迄今为止国内信息安全领域历史最悠久、最权威、知名度最高的闭门型技术峰会。**今年的主题是“重拾圆点·致敬无限”**。峰会创立20年来，以前瞻性的知识与技术促进国内安全技术的发展，已经成为国内最高级别的技术探讨和交流平台，并在国际范围内享有极高声誉与影响力。同时大批行业人才在此平台涌现，峰会**对国家信息安全技术探索、学术探讨、人才培养、行业交流、国际交流起到重要推动作用**。

![](../Images/9ef4c68b079aa681d910e1589c607a8b.png)

峰会现场，丁湛钊讲解了LLVM本身，作为一个开源编译器架构的使用场景，讲解了LLVM的基础结构，还提到LLVM用于二进制分析的优缺点，作为静态分析神器，LLVM在源码分析方面提供了极强的分析能力，基于LLVM中间语言，可以支持任意可翻译到LLVM中间语言的编程语言的分析。但是，在议题中提到，LLVM在用于二进制分析时则会受到一些限制，这主要是由于LLVM中间语言的抽象层级过高导致的。

![](../Images/db62d0dc1ec0f1f1820b1d259b2cd8b8.png)针对LLVM用于二进制分析的问题，在议题中提到一种解决的思路，由于LLVM的核心是LLVM-IR，但LLVM IR本身的特性使其并不适用于二进制级程序分析，为实现二进制级程序分析，我们可以通过借Ghidra现有功能，对其进行改造、重构，利用Pcode IR对应LLVM IR，尝试构造类似LLVM的结构，将各部分分析组建可分离使用，其中的成果之一是sleighcraft，可使用Rust/Python/NodeJS进行pcodr ir的提升和反汇编。![](../Images/3f7c8aadbd9525f321c9308faa5f1ae0.png)

最后，议题提到，目前我们虽然对LLVM二进制级改造有了一些初步的进展，但是还有许多值得改进的地方。星阑科技Portal Lab实验室成员接下来还将以反编译器场景为路线，持续开发算法，为二进制分析“LLVM”化提供基础。

  

未来，星阑科技技术团队还将继续同行业内权威安全专家共同探讨专业性技术，并不断提高团队技术能力进行更加深入的安全研究，继续努力分享更多具有权威性和前瞻性的技术研究成果，展示星阑实践，彰显星阑实力。
