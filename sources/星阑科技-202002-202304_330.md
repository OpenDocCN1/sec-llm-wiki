# 创造更多可能！星阑科技亮相2021世界互联网大会&进行产品发布！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247489329&idx=1&sn=2d7a70f8e56dc9ed9517437d857dfe52&chksm=c004baadf77333bb14c70837bc6ed9b9be302eabc9339b4220bc12f13cc3e7796a3c3bd60714&scene=126&sessionid=1681375661#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247489329&idx=1&sn=2d7a70f8e56dc9ed9517437d857dfe52&chksm=c004baadf77333bb14c70837bc6ed9b9be302eabc9339b4220bc12f13cc3e7796a3c3bd60714&scene=126&sessionid=1681375661#rd)

9月25日-28日，2021年世界互联网大会乌镇博览会，在浙江乌镇举办。**星阑科技携API安全产品及解决方案亮相2021世界互联网大会“互联网之光”博览会，****展示公司新技术研发与实践成果。**

![](../Images/a8e8b878f38232b629c405b5848420ef.png)

世界互联网大会是由国家网信办、科技部、工业和信息化部以及浙江省人民政府共同主办，本次大会的主题是“迈向数字文明新时代——携手构建网络空间命运共同体”。来自各国政府、国际组织、行业机构、中外互联网企业、高校智库、科研机构的代表近2000余人共同围绕大会主题展开交流。作为大会的重要组成部分——“互联网之光”博览会，聚焦互联网发展新趋势和新前沿动态，着力展示云计算、大数据、人工智能、区块链、网络安全等领域的新技术、新产品，以及经济、社会、政府等各领域各行业数字化改革的最新应用成果。

![](../Images/cb87d534329f0ba9a5373b1f9b751585.png)

9月27日上午，星阑科技CEO王郁在大会上以**“大数据时代的API安全探索”**为题向参会人员分享在这个数字化转型的时代星阑科技对API安全的探索过程。

  

王郁首先讲述了在这个**大数据时代，守护API安全的重要性**，他提到：当前，我们正处于信息爆炸式增长的大数据时代，数据已成为新兴的生产要素，是国家基础性和战略性资源，在数字时代下，无论是互联网商业创新还是传统企业数字化转型，都推动了API经济，API在给企业发展带来巨大便利的同时，API安全已经成为企业时刻需要关注的安全问题，缺乏良好防护策略的API服务，不仅会对用户的使用体验以及个人隐私带来威胁，而且还会使企业面临未知的安全风险。

![](../Images/a3d1597d59cd56e08feea323b8e32ee1.png)

随后，王郁又给大家展示了星阑在API安全产品，分享了实践经验。他讲到：为解决API安全问题，公司从攻防能力、大数据分析能力及云原生技术体系出发，提供全景化API识别、API高级威胁检测、复杂行为分析等能力，构建API Runtime Protection体系。星阑科技产品“萤火”可以解决传统方案无法解决API安全问题，并为客户提供不同应用场景的解决方案。在产品功能上，“萤火”通过**API统一管控、API风险发现、API实时监控**技术，对每个用户、设备、业务的行为模式进行自动分析建模，从容应对漏洞攻击、黑客入侵以及账号滥用风险。在敏感数据保护上，“萤火”可以基于企业级大数据分析平台以及机器学习数据实体识别算法，提供符合ISO PI PII标准以及金融、政府、通信行业细分标准的敏感数据实体识别与分类分级能力，在API传输中的敏感数据过程中进行识别，针对敏感数据可以进行脱敏处理或者实时拦截，防止敏感数据泄露。

![](../Images/b8384930634ecd4628a755c5383fc6dc.png)

最后，王郁表示：在全球抗击新冠肺炎疫情的背景下，数字世界同步应对变局，展现新技术聚合社会、愈合世界的魔力。星阑科技将把握数字时代新机遇，培育创新发展新动能，开创数字合作新局面，为数字经济发展添砖加瓦。
