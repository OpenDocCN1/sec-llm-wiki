# 【转载】星阑科技在第六届“创客中国”网络安全中小企业创新创业大赛获奖！

2021年9月18日，由工业和信息化部、财政部指导，工业和信息化部网络安全产业发展中心（工业和信息化部信息中心）、成都市经济和信息化局、成都高新技术产业开发区管理委员会联合主办的第六届“创客中国”网络安全中小企业创新创业大赛决赛在成都高新区圆满收官！  
工业和信息化部网络安全产业发展中心（工业和信息化部信息中心）副主任李新社、成都市经济和信息化局总经济师陈星明，成都市经济和信息化局网络信息安全处处长李坦、成都高新区新经济发展局大数据与网络安全产业处处长杨容辉，以及多个网络安全领域专家评委、企业代表出席了本次大赛。  
![](../Images/dd768799d6d89214b44e54bbb4c56d89.png)  
经过网络筛选、项目初审、复赛和决赛环节的激烈角逐和层层选拔，最终，**星阑科技从众多网络安全优秀项目团队中脱颖而出，夺得大赛企业组的第二名。**

  

![](../Images/6f260de702a5e4b68782dd1e1c7a3931.png)

  

![](../Images/4d33d0e1c4d489b5481d293ee1771b29.png)

  

![](../Images/8e5e0873c0d1eedcb61ded0b659e5809.png)  

创新，是网络安全行业发展的根本动力，也是应对数字化转型期间未来数字风险、保障数字经济高质量发展的关键。可以说，持续创新就是企业的生存命脉。未来，星阑科技作为国内云原生安全厂商的优秀代表，将持续创新，加速研发与实践相结合，通过与上下游厂商、企业用户的共同努力，共同捍卫企业云原生环境下的安全，为中国云原生安全添砖加瓦。
