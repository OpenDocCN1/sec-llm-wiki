# 万众瞩目 强势问鼎｜星阑科技荣获ISC 2021创新独角兽沙盒大赛冠军！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NjEyMjA5OQ==&mid=2247486931&idx=1&sn=2b5f9e16349e145693a3b0e934e0e356&chksm=c004a04ff7732959213a80b46a55c4388f718218db61945b8d42bb7fe4f7732ac76c804015fd&scene=126&sessionid=1681375676#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NjEyMjA5OQ==&mid=2247486931&idx=1&sn=2b5f9e16349e145693a3b0e934e0e356&chksm=c004a04ff7732959213a80b46a55c4388f718218db61945b8d42bb7fe4f7732ac76c804015fd&scene=126&sessionid=1681375676#rd)

安全创新战场群雄并起，顶尖对决博弈一触即发，作为ISC 2021第九届互联网安全大会的重磅环节，创新独角兽沙盒大赛将各界对于网络安全的期待与关注提升到新的至高点。7月28日上午，经过现场激烈的路演角逐与严格评选，星阑科技从50家复赛企业中脱颖而出**荣获ISC 2021创新独角兽沙盒大赛冠军**，并成功入驻未来数字安全名人堂。![](../Images/e12a51deb4c63217fae33ffa1c536fca.png)路演过程中星阑科技CEO王郁以“构建智能化API安全体系”为题，从API安全的过去、现在和未来出发，为大家带来了一场精彩的演讲。他表示：在现代IT应用架构中，API通信如“血液”般承载了绝大多数的应用数据交换，为解决API安全问题，星阑从攻防能力、大数据分析能力及云原生技术体系出发，提供全景化API识别、API高级威胁检测、复杂行为分析等能力，构建API Runtime Protection体系。![](../Images/fbfba36857ce7dbd556f3f5d8f1fcf5a.png)

提到公司关于API安全产品的创新，王郁表示：萤火 (API Intelligence) 拥有不同应用场景的解决方案，包括企业通用API安全防护方案、容器集群API安全防护方案、微服务架构API安全防护方案等。可以实现对API使用情况的实时监控，异常访问的可视化。对流量中的API自动聚合、分类、自定义标签化管理；并以树状图的方式便于管理员进行探索和调查，从而实现API统一管控。

![](../Images/e7cb42e69e7489b0013593913a03adac.png)

创新，是行业发展的根本动力，也是应对未来数字风险、保障数字经济高质量发展的关键。ISC 2021创新独角兽—沙盒大赛作为中国的SandBox（创新沙盒大赛），拥有“网络安全行业奥斯卡”之美誉，大赛以创新为唯一评判标尺，构建起多领域、多层次、多维度的网络安全创新企业竞演空间，旨在挖掘出安全领域不同维度的创新结晶，打造出未来数字安全名人堂。

![](../Images/3d26fcdb82ac0ac555931f629f8d7e5c.png)

志坚方可励行，行稳才能致远。此次创新独角兽沙盒大赛只是一个开始，惟创新者行稳致远，创新发展是应对风险挑战的稳定器。未来，星阑科技将继续坚持创新理念，应对风险挑战中抓住新的机遇，赢得新的辉煌。
