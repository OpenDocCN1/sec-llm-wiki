# 【转载】ISC 2021创新独角兽沙盒大赛十强名单出炉，巅峰对决一触即发！

7月19日，ISC 2021创新独角兽沙盒大赛决赛入围名单震撼出炉。大赛以创新为唯一评判标准，经历了近一个月的层层筛选，十家网络安全创新黑马成功杀出重围，将于7月28日迎来入驻未来数字安全名人堂的荣耀时刻，并同时将对巅峰决赛中的三强座次发起最后冲击。

 **初赛合议环节，在360政企安全集团助理总裁、ISC品牌主理人卜思南的主持下，北京赛博英杰科技有限公司创始人、董事长谭晓生，360政企安全集团首席战略官潘柱廷，360集团副总裁张伟，元起资本创始合伙人何文俊，密码资本创始人王钊，赛迪顾问业务总监高丹，数世咨询创始人李少鹏，北京华顺信安科技有限公司联合创始人郑政等十余位专家评审，分别从技术、投资、发展等不同层面作出最终协商评判。**

  

  

**决赛入围榜单如下：**

 

**公司：北京星阑科技有限公司**

**项目领域：API安全**

项目简介：在现代IT应用架构中，API通信已如“血液”一般承载了绝大多数的应用数据交换，但目前由API安全问题所导致的事件频发，API生态体系面临着严重的安全威胁。为解决API安全问题，星阑科技从攻防能力、大数据分析能力及云原生技术体系出发，提供全景化API识别、API高级威胁检测、复杂行为分析等能力，构建API Runtime Protection体系，守护数字经济的每一次API调用。

![](../Images/102d2b69d2ad1891b6bd184410e677e5.png)

**公司：上海雾帜智能科技有限公司**

**项目领域：安全编排自动化与响应（SOAR)**

项目简介：雾帜智能研发的HoneyGuide智能风险决策系统是首款以AI+SOAR为核心的安全协同作战平台，通过虚拟作战室、AI机器人和可视化剧本编排，帮助安全团队加速威胁响应与处置，提升运营自动化，实现风险自适应治理。

 

**公司：北京绎云科技有限公司**

**项目领域：零信任安全**

项目简介：绎云科技研发的信域安全云网遵循零信任原则，采用软件定义网络技术，为用户打造全覆盖、全感知、全管控的隐匿智能化网络，在数字化转型过程中，帮助客户保障业务和数据安全、满足合规要求、提升运营能力、提高管理效率。

 

**公司：深圳开源互联网安全技术有限公司**

**项目领域：软件开发安全**

项目简介：开源网安专注软件安全领域，以平台、工具、培训为三大抓手（分别是S-SDLC平台、S-SDLC工具链、CWASP软件安全开发课程培训体系），提供成熟的软件安全开发全生命周期解决方案(S-SDLC)、DevSecOps解决方案和完整的软件安全开发工具链（IAST、SAST、SCA、FUZZ、RASP），为客户实现软件产品快速安全交付保驾护航。

 

**公司：北京瑞和云图科技有限公司**

**项目领域：云安全**

项目简介：传统安全建设方案是一系列安全设备的堆叠，不仅建设成本高而且运维难度大。瑞和云图将SASE赋能给云安全2.0，在用户侧部署一个轻量级的安全CPE，利用隧道拉通边缘云安全节点以及安全运营中心，实现云、边、端的融合。不仅将安全能力在云端集约化实现降本增效，而且可以把复杂的安全分析集中在云端，彻底解决买了一堆盒子但是不解决问题的长期痼疾，充分发挥了安全运营中心的效能。通过这种将安全建设转化为长期订阅式的安全服务，既能满足政策的合规要求，也能快速有效响应客户的实际安全需求。

 

**公司：北京天地和兴科技有限公司**

**项目领域：工业互联网安全**

项目简介：油气管道是油气生产设施的重要组成部分，油气管道的生产控制系统应用了自动化、网络通信、计算机技术、信息技术等新技术，给企业带了方便的同时也给系统带来了很大的网络安全隐患，天地和兴按照国家网络安全法提出的“同步规划、同步建设、同步使用”的三同步原则，利用当前先进的网络安全防护理念、技术与产品，构建网络安全立体的防护体系，满足标准合规性要求。同时，按照企业多级管理职能，设计构建全网工控安全管控与运营体系，形成多级联动机制，实现全网动态安全监测、风险可视、通报预警与联动处置，提高网络安全综合管控与防护能力。

 

**公司：中云网安**

**项目领域：Web安全**

项目简介：中云网安通过18年的算法研究与算法训练，率先将机器学习算法应用到Web安全防护领域。其以核心专利算法为驱动力，通过学习被防护对象的多重逻辑，为其打造专属的自安全免疫模型，建立具有自我成长能力的综合性Web安全防护平台——AI Web 防护者平台。

 

**公司：北京惠而特科技有限公司**

**项目领域：工业互联网安全**

项目简介：围绕工控环境高可靠低时延要求，解决病毒有效防护，阻断病毒传播，抵御漏洞利用，异常操作行为检测，惠而特通过基于智能的工业环境全流量分析技术和针对工业互联网研发的轻量级零信任纵深防御技术，以推动“产、学、研”共同发展为目标，构建工业互联网3+1安全体系，为国家关键信息基础设施运行安全提供全方位的安全防护。

 

**公司：上海物盾信息科技有限公司**

**项目领域：零信任安全**

项目简介：物盾安全打造了针对于物联网场景的物安盾(wShield) 产品，该产品能够轻松适配于各个智能终端设备，且具有低消耗和高稳定性特点。同时与零信任网关、零信任控制器配合，通过物联零信任安全管控系统进行统一管理，实现强有力的本体安全保护、接入安全保护与终端安全保护。

 

**公司：北京青笠科技有限公司**

**项目领域：数据安全**

项目简介：青笠科技专注于数据处理和交换安全，让数据使用更放心。公司的主要产品为应用数据安全治理平台，平台包含数据透视与梳理、敏感数据分级分类工具、业务系统使用安全审计、应用数据安全审计、数据脱敏、数据水印、数据加密等多个可统一管理的低耦合模块，用于帮助企业洞察数据分布情况、实现敏感数据自动化的分级分类、对数据的处理和交换进行全面精准的审计并且识别该过程中的风险，同时提供动态脱敏和加密等多种主动数据保护机制，防止数据泄露。结合专业的数据安全专家服务，可以帮助大型机构、监管单位构建私有的数据安全运营中心，同时也为中小型用户提供SAAS化的数据安全运营中心服务。

 

纵观榜单，本次将入驻未来数字安全名人堂的十强创新势力分别代表了API安全、安全编排自动化与响应、软件开发安全、云安全、Web安全、工业互联网安全、零信任安全、数据安全等不同领域的前沿创新能力，是具有未来发展潜力和推动行业进步的核心引擎。面对即将开启的巅峰对决，已经入围决赛的十强黑马也将火力全开，为冲榜夺冠放手一搏。在这场万马酣战即将迎来收官之时，谁将最后问鼎，还请拭目以待。
