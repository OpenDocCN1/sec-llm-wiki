***星阑科技招聘***

![](../Images/8894a43d41aaa60e65bd6ad6de98c13b.png)**关于我们**![](../Images/8894a43d41aaa60e65bd6ad6de98c13b.png)

北京星阑科技有限公司成立于2018年11月，是一家以安全技术为核心、AI技术为驱动的网络安全科技公司。创立至今，一直以“通过AI技术为企业植入信息安全的运营大脑, 赋能企业安全运营人员成为信息安全专家”为使命，致力于提供智能化网络安全解决方案，形成网络安全防御的检测—响应—处置—运维的智能化、自动化闭环，以应对政府、企业所面临的日益严峻的网络安全威胁，让网络空间更加安全与智慧。

![](../Images/8894a43d41aaa60e65bd6ad6de98c13b.png)**招聘岗位**![](../Images/8894a43d41aaa60e65bd6ad6de98c13b.png)

**云安全开发工程师（全职/实习）**

岗位职责：

负责公司云安全产品的开发，部署与维护。

  

任职要求：

1.熟悉Python, flask且对数据结构和算法有了解；

2.熟悉常用的云供应商（AWS，阿里云，腾讯云，华为云…）服务接口，以及云基础知识；

3.有基础的安全知识，对不同层面的威胁，漏洞都有认识，知道对应的best practice；

4.热爱技术或者热爱信息安全工作。

  

综合素质要求：

逻辑能力，综合分析能力，责任心，团队合作意识。

**前端UI工程师（全职/实习）**

岗位职责：

负责产品的设计以及配合项目需求提供前端页面支持。

  

任职要求：

1.熟练使用 HTML5JSCSS3 等前端技术；

2.1年以上使用 Vue 进行项目开发的经验，熟练使用 Vue 前端框架；

3.掌握前端调试、性能优化、单元测试等相关技术；

4.熟悉常用可视化开发工具和算法库（如 ECharts ），具有数据可视化开发经验；

5.熟悉 ECMAScript 2020 的新特性；

6.熟练使用 Git 版本管理工具;

7.2年以上 Web 前端开发经验，能独立完成前端开发工作。

**渗透测试工程师（全职/实习）**  

岗位职责：

负责红队渗透与常规渗透测试任务的执行。

  

任职要求：

1.熟练掌握常规web漏洞的挖掘与利用；

2.熟悉各类系统机制，能灵活利用进行溯源分析或者防护绕过；

3.至少掌握一门常见语言的审计能力；

4.至少掌握一门语言的快速开发能力；

5.具备较强的自我学习能力，能快速掌握未知的知识；

6.具备良好的团队合作能力，能与团队协作完成大型项目。

**安全工程师（web安全）（全职/实习）**

岗位职责：

负责跟进业内先进技术，0day漏洞挖掘，1day漏洞武器化，开发丰富红队武器库，支持渗透业务。

  

任职要求：

1.对php、java、python、node等有深入研究经验；

2.具备较强的自动化开发能力；

3.具备漏洞挖掘与利用经验；

4.具备较好的分享意识，乐意和小伙伴讨论技术，分享能力。

**安全工程师（红队开发）（全职/实习）**

岗位职责：

负责跟进国内外优秀红队工具思路，进行内部红队工具开发与维护

  

任职要求：

1.具备一定的逆向能力，能对已有样本进行分析提炼；

2.熟练掌握C/C++、C#、golang等一门或多门语言开发；

3.掌握杀软对抗（反沙盒、混淆等）技术；

4.熟悉windows开发，熟悉各类win32API,熟悉windows内核；

5.熟悉linux内核开发，了解rootkit等技术；

6.掌握常见通讯协议，熟悉网络编程。

**安全工程师（大数据/机器学习方向）****（全职/实习）**

岗位职责：

负责利用大数据分析或者机器学习的手段构建攻击检测模型，可以在海量数据中定位攻击，并可以将模型植入产品中。

  

任职要求：

1.了解渗透测试流程，掌握常见攻击方法方式，清楚各类攻击特征；

2.熟练使用一门编程语言，对数据结构和算法设计有较为深刻的理解；

3.熟练掌握机器学习常用算法，并有利用相关技术解决实际问题的能力或经验；

4.至少掌握一个或多个Mapreduce、Hive、Storm、Flink、flume、spark、Kafka、Oozie/azkaban、ES、solr等大数据生态技术栈，具备海量数据开发和调优能力。

**解决方案专家（售前方向）（全职）**

岗位职责：

1.协同销售识别商业机会，提供解决方案和售前技术支持，维护良好的客户关系；

2.负责编写项目建设方案、投标文件、实施方案、测试方案和其他技术文案；

3.负责项目售前支持工作，包括公司产品介绍、技术交流、需求分析、方案讲解、产品培训等；

4.详细分析并引导客户业务需求，结合公司信息安全技术、产品和服务进行需求分析，帮助客户进一步梳理和明确解决方案；

5.辅助产品研发部进行国内、外安全产品调研，提供应对客户需求的产品解决方案；

6.配合公司产品、销售及研发团队规划产品及服务相关的发展策略；

7.完成领导要求的其他事宜。

  

任职要求：

1.熟悉信息安全领域的相关技术及主要安全产品，3年以上售前和解决方案工作经验；

2.支持过5款以上信息安全产品的方案撰写和售前支持工作，有从零开始支持产品售前工作经验者优先考虑；

3.良好的人际沟通和交流能力，独立承担过8个（形成销售合同）以上客户售前交流工作；

4.具有优秀的团队协作能力，了解基本软件开发知识，可通过绘制软件流程图、简单UI界面的方式将客户的需求转化为产品需求；

5.具有优秀的逻辑思维能力和文字表达功底，要求文档逻辑严谨、格式统一、语言规范；

6.能够熟练使用办公软件，包括格式调整、网络拓扑图绘制、基本图形制作、基础动画定义；

7.熟悉招投标文件中的技术及产品部分文件编写，参与过5个以上项目的招投标工作；

8.对云计算主要产品或相关技术有一定的了解，理解云计算基本工作原理，了解云环境和传统环境的主要差异；

9.具有安全服务、攻防售前工作经验可优先考虑；

10.有售前主管、经理工作经验可优先考虑；

11.本科以上学历，能力优秀者可放宽；

12.具有CISP、CISSP、ITIL、CCSK等证书者优先考虑；

13.可接受短期出差工作安排。

1\. 负责制定星阑科技品牌策略，以及推广计划，包括但不限于星阑科技自媒体平台的日常运营及推广工作；

4\. 有较好的文字功底，熟悉互联网媒体形式，有较强的审美能力，文案功底及创新思维；

5\. 具备高度的工作热情，执行力强、工作责任心强，能承受工作压力，能适应出差，具备高度的敬业和团队合作精神。

**系统安全研究员（全职/实习）**  

岗位职责：  

1.通用二进制级漏洞挖掘，包括对开源软件等进行漏洞挖掘；

2.探索前沿漏洞挖掘方法，包括fuzzing，符号执行等；

3.根据CVE编写1day或Nday漏洞利用；

4.根据业务需求，进行特定系统的二进制漏5.洞挖掘和漏洞利用编写相关任务；

6.可根据需要，撰写漏洞研究分享相关文章；

7.完成其他业务所需的系统级漏洞相关任务。

  

任职要求

1.熟练掌握IDA、Binary Ninja、Radare2等静态分析工具的使用，熟练掌握gdb、x64dbg等动态调试工具的使用；

2.具备二进制漏洞相关知识，具备对栈溢出、堆溢出、整数溢出、类型混淆等二进制漏洞类型的深入理解；

3.具备逆向能力、阅读大中型软件源码能力；

4.有漏洞挖掘经验优先；有CTF竞赛经验，且取得较好成绩者或参加国际比赛者优先

**实验系统研发工程师（全职/实习）**  

岗位职责：  

1.研究转化实验级IDS/威胁狩猎类产品需求，对学术成果进行工业级转化；

2.对产品前沿方向进行探索实验；

3.搜集跟进产品向前沿，了解产品相关学术、工业前沿发展。

  

任职要求：

1.具备扎实的计算机基础，可以快速学习论文中提到的新技术、新知识；

2.熟练使用一种或多种编程语言，了解多种编程语言；

3.具备足够的文档化能力；

4.能够熟练阅读英文文档、论文，并对文档、论文内容进行整理；

5.热爱学习新知识，对计算机各领域愿意了解尝试。
