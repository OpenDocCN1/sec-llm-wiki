**14:00-14:05**

**14:05-14:35**

演讲主题：《那些可用作木马的 Android 漏洞》

演讲嘉宾：卢瑀涛（奇安信盘古石取证实验室，安全研究员。主要从事 Android/Linux 漏洞挖掘、分析与利用的工作）

在当今仍然“不健全”的 Android 生态环境里，恶意 Android 木马仍然是个影响广大用户的棘手问题，终端上个人信息泄露和资产流失的新闻也频出不穷。而且，当今恶意木马的攻击技术也愈发复杂。未知攻焉知防，此次议题将为给大家分享几个能用作编写 Android 木马的通用漏洞，从而提升大家对于高级 Android 木马方面的安全意识。

  

1**4:35-15:05**

演讲主题：《对SQL Server CLR在红队行动中利用的探索》

演讲嘉宾：吕盟（安恒信息水滴实验室安全研究员）

因为数据库服务的特殊性，数据库在红队行动中的价值较高。议题简要分析了常规的利用手法，然后介绍了SQL Server CLR的特点，并展示了几种通过CLR实现的利用手法。目的为了抛砖引玉，希望能与大家共同探讨。

  

**15:05-15:35  ** 

演讲主题：《深入浅出IoT安全》

演讲嘉宾：郑鑫(奇安信奇物安全实验室研究员，物联网IoT安全公众号小编，主要从事物联网安全、无线电安全研究）

如今物联网设备越来越走近人们的生活，IOT安全也变成了我们不得不关注且越来越重要的问题，此次议题将给大家介绍如何从零开始研究物联网IOT安全，分别从硬件层面、代码层面、通信层面和云服务层面来分析几款设备。

  

**14:00-17:00  **

Village Time

▶ Base station security

近年来信用卡盗刷事件频频发生，伪基站更是防不胜防。通过该Village我们将走进伪基站，亲身体验伪基站带来的危害，了解如何针对伪基站进行防范

![](../Images/3aae871c88608be7d2923fea43de8ac2.png)

▶ Nano Lock picking Village  

Lock picking指开锁的艺术。尽管撬锁经常被与犯罪联系起来，但对于合法职业的锁匠来说是最基础的一门技术了，同时开锁技巧也可以被当做一项有用的生活技巧来学习，更或者仅仅作为一种爱好。在全球大多数的城市中，只要不将它用作犯罪目的，学习开锁技术都是可行且合法的。Lockpick Village的目的在于让我们了解到不同锁类的安全性，以便在今后的生活中挑选购买安全性更高的锁具。

![](../Images/233ae0028e84e3127aa7f0b5578fc3a3.png)

▶ Radio security

你是否想过随着通信技术的发展，万物互联的趋势不可阻挡，现在的各种智能移动设备、智能家居设备、智能医疗设备、智能交通设备、智能穿戴设备、智能网联汽车，甚至是飞机、卫星等都安装了大量的无线传输模块近场如通信NFC、射频RF、无线传输ZigBee、蓝牙BLE、WIFI等，并通过无线介质进行信息传输，如果无线传输协议存在安全问题，攻击者就可以对无线数据进行监听、破解、重放、欺骗等，实现对目标的入侵与控制。传统安全中因为物理隔离无法接触到目标，看似不可能完成的入侵，在无线安全领域中可能会变得轻而易举。
