# 带你发现身边无孔不入的的针孔摄像头

随着科技的不断发展进步，虽然给我们带来了生活上的便利，但是大家的隐私也逐渐受到了侵犯。在日常的新闻事件中，屡屡爆料出发现针孔摄像头偷拍。相对于普通摄像头，针孔摄像头具有体积小，隐蔽性好的特点，主要用于暗访调查取证，但是在不法分子的手中，却变成了他们偷拍谋取非法利益的工具。

  

![](../Images/92556bf021b4edb3305b5cb2cc342cfb.png)

  

下面来给大家介绍几个可以发现针孔摄像头存在的方法以及他们的原理吧！

  

1**相机摄像头**  

  

经常旅行出差的小伙伴一定听过这样一个“妙招”：当你入住了一个酒店房间之后，首先关掉电源总开关，拉上窗帘，确保一个足够黑暗的环境，然后拿出你的手机，打开相机，进入拍摄模式，到处走走，看看有没有可疑的小红点，那可能就是一个藏在暗处的针孔摄像头啦。

  

这个方法科学吗？首先它是科学的，肉眼不可得的红外线确实会被相机镜头给捕捉到。但是，这个方法能够成功实行，需要满足两个前提。其一这个摄像头是红外摄像头，会发射红外线。其二，用来拍摄的手机未添加滤波片，不会过滤红外线。也就是说，你得有台“古董机”，还得恰好碰上个“古董摄像头”，才能成功应用这个办法。这两个要求显然很难同时满足，甚至满足一个要求都很难了。

  

2**手机APP**  

  

不过小伙伴们不要太担心，在反偷拍阵营中也有号称可以一键识别针孔摄像头的手机App，例如“某手机版安全卫士”，这类App可以通过扫描局域网内设备的方式，找到酒店等场所中隐藏的摄像头。操作也十分的简单，只要将手机连入房间的WI-FI，然后打开App，点击“一键检测”并等待一段时间，就能在屏幕上看到检测结果，这好像比开手机摄像模式还easy啊。

  

那这款App的原理是什么呢，对无线通信和网络知识稍有了解的小伙伴，应该很快就看穿了。当手机连接到某个局域网时，可以发送特定的指令，来获取局域网中其他设备的MAC地址。MAC是网络设备制造商生产时写在硬件内的唯一标识数据，通常为12个16进制数，每两个16进制数用冒号隔开，它大致就长成这样：08:00:20:0A:8C:6D。

  

MAC地址具有唯一性，可以通过它查到对应的设备和厂商信息，再进一步判断是否为针孔摄像头就可以了。

3**WI-FI探针**  

  

WI-FI探针其实是一个AP，它定时的广播一个Beacon帧，来通知附近可连WI-FI的设备，这有一个AP快来连接呀，而设备们也会定时广播一个probe帧去问附近的AP，我能连你吗？MAC地址就包含在这个probe帧中。因此只要在探针的覆盖范围内，只要这个针孔摄像头开了WI-FI，即便两者不再同一个网络环境，WI-FI也并没有连接到任何AP，都是可以被收集到的。

Probe Response代表这个信息属于一个手机probe帧，Acknowledgment这里可以获取到无线终端设备的MAC地址信息，同样查询一下生产厂商便可以确认是否是针孔摄像头的地址，这一步同样也可以用wireshark来捕包完成。

  

因为不再有网络环境的限制，利用这种方式发现的MAC地址数量，可能会剧增，但也不需要慌张，遇到这种情况先冷静确认一下，说不定你找到的10几个摄像头可能是酒店的安保摄像头呢。同样的这种方法也并不是万无一失的，毕竟除非24小时持续扫描，面对那种狡猾的偷拍者，将自己设备的MAC地址伪装成人畜无害的样子，并且将无线功能设定为定时开启，半夜三点才去上传偷拍的视频的。我们还需要继续精进技艺呀。
