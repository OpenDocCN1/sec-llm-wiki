**设计思路**

  

现在常用的 linux 维持权限的方法大多用 crontab 和开机自启动，同时使用的大多是msf 或者其它的 tcp 连接来反弹 shell ,这种做法比较容易被管理员发现。所以我们想有一个非 tcp 连接、流量不容易被怀疑的后门，并且在大量的 shell 的场景下，可以管理 shell ，因此采用 reptile+ishell+merlin 的组合。

  

**Reptile**

Reptile 是种 LKM rootkit，因此具有很好的隐藏性和强大的功能。

> LKM的全称为 Loadable Kernel Modules，中文名为可加载内核模块，主要作用是用来扩展 linux 的内核功能。LKM的优点在于可以动态地加载到内存中，无须重新编译内核。由于 LKM 具有这样的特点，所以它经常被用于一些设备的驱动程序，例如声卡，网卡等等。当然因为其优点，也经常被骇客用于 rootkit 技术当中。

Reptile 具有的功能

> *   **Give root to unprivileged users**
>     
> *   **Hide files and directories**
>     
> *   **Hide processes**
>     
> *   **Hide himself**
>     
> *   **Hide TCP/UDP connections**
>     
> *   Hidden boot persistence
>     
> *   File content tampering
>     
> *   Some obfuscation techniques
>     
> *   ICMP/UDP/TCP port-knocking backdoor
>     
> *   Full TTY/PTY shell with file transfer
>     
> *   Client to handle Reptile Shell
>     
> *   Shell connect back each X times (not default)
>     

Reptile 用的是传统的反弹 shell ，就算加了一些混淆，流量也十分明显，所以我们不打算用 Reptile 的反弹功能，而采用了前五个功能。同时 reptile 还有很强的兼容性，作者在下面的系统上都测试过了

** 安装 **

reptile的安装比较简单，只需要安装一些依赖就可以直接安装

```
apt-get install vim gcc make g++ unzip -y
apt-get -y install linux-headers-$(uname -r)
```

安装reptile

```
cd Reptile-master
chmod +x ./setup.sh
./setup.sh install
```

ICMP SHELL

  

ICMP Shell（ISH）是类似于 telnet 的协议。它允许用户连接到远程主机并仅使用 ICMP打开和发送数据就可以打开 shell 。ICMP Shell是用C语言编写的，用于UNIX环境。

ICMP 虽然不是新技术，但是 ICMP 具有很好的隐蔽性，结合 reptile 可以隐藏 pid，达到我们想要隐藏后门的效果。

**总结**

在维持权限的路上任重而道远，围绕隐蔽性做文章，因此有个好的rootkit是十分重要的。而在后门中，围绕的重点要么是不为人注意的协议，要么是较新且没有广泛使用的协议。而当这两者组合起来，就能做到很好的维权。首先，reptile 隐藏了 Merlin 和 ish 的 pid 及 tcp 连接，普通管理员无法在系统里察觉到异常，而如果在交换机或者路由器查看，也是正常的 https 流量以及正常的 https 端口。除此之外，就算封了 Merlin 的 ip 和端口，还有 tsh作为备用，不至于一次就失去了权限。  

当然，对于 linux 维持权限的方法不止这些，还需要探索更多的 linux 维持权限的方法，这样才能更好的维持住权限。现在的工具集也还有一些不足，比如更好的隐藏开机自启动，需要进行深入的探索。
