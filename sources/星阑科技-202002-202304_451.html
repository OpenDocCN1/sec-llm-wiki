美国旧金山当地时间2月24日下午，SECURITI.ai 公司在RSAC 2020创新沙盒比赛中脱颖而出，斩获RSAC 2020创新沙盒冠军。接下来，就让小阑陪着大家一起看由前方记者 —— 星阑科技CEO王郁和密苏里大学都基泽博士带来的报道吧~


SECURITI.ai


SECURITI.ai 引入了 PrivacyOps 的全新概念，通过 Privaci People Data Grapher 和用户信息之间的相互映射，生成个人数据关联报告，不仅能在充分利用数据的同时，还能遵守各项和个人隐私相关的法律法规。如果从隐私和合规的角度考虑，具备相当大的市场前景。凭借着创新性的市场占位，在今天的创新沙盒上，SECURITI.ai也获得了创新沙盒的冠军。

ForAllSecure


ForAllSecure 是由 David Brumley （原卡耐基梅隆大学信息安全系主任）所创建的一所公司，旗下的产品 Mayhem 参与了本次展览 (小阑觉得对CGC了解的童鞋应该会有些耳熟，它们就是在Defcon CGC上出现的自动攻防系统)。Mayhem 定位于下一代模糊测试 fuzzer ，主要采用 tried-and-true 型的导向性模糊测试和符号执行相结合的测试技术，高效挖掘漏洞。


Mayhem使用了 git trigger 和 Mayhem 形成闭环，使模糊测试能持续化的整合到代码开发和安全测试的流程中。截止目前，Mayhem已经发现了超过20个严重漏洞，包括MatrixSSL, MATIO,Das u-Boot ,Netflix，DIAL reference, OpenWRT, H20等。

Sqreen


Sqreen 定位于企业级的应用安全平台，通过向应用内植入micro agent，使得应用具备统一的防护性以及安全透明性。根据需求的不同，还可以提供   RASP、APP 内置防火墙、Automation Playbooks 、账户接管防护、 APP 级资产和防御管理、交互式安全测试等。


本次 sqreen 亮点在于解决了RASP和WAF等产品的信息孤岛性，便于安全管理人员能够在应用的粒度上，进行不同应用的安全控制和资产风险管理。


/sqreen solutions/


AppOmin


AppOmin 产品主要的需求点在于，针对目前的SaaS应用，由于SaaS服务提供商的安全配置和特性对企业来讲具备较大的不透明性，很多企业无法掌握SaaS应用的安全配置和日志等数据，同时由于不同SaaS服务提供商的安全配置异构性，企业需要投入很多人力成本去进行相应的维护，造成安全人员负担较重，精力不足，从而导致了各种问题的产生。


因此，企业用户需要一个能够提供SaaS安全可视化的解决方案，在一个统一的平台上对SaaS应用进行安全管理。



如图所示，AppOmni 可以集成化的对企业所采用的 SaaS 服务进行管理，图中演示了在 salesforce 和 dropbox上的安全管理页面。 


vulcan


号称新一代威胁解决方案的 vulcan ，整合了漏洞管理与运维平台，可以通过 remediation-driven 的方式进行整体资产漏洞的检测和闭环的修补，帮助安全团队快速修补风险点。vulcan 平台能够通过API将常用的安全、运维、IT 工具结合起来，从而能够有效的对检测到的问题实施联动修补，完成闭环、并能对整体资产进行安全管理。


/ vulcan 演示画面/


Obsidian


Obsidian 是一家为 SaaS 应用提供无缝安全，在安全团队在不影响日常业务的情况下，快速发现、调查并响应内部安全问题的公司。Obsidian 通过以身份为中心的独特方法，甚至能够阻止针对 SaaS 和云服务的最强攻击手段。

Obsidian 通过 API 的整合，无需部署就可以在几分钟内上线，几小时内得出结果。在不影响正常业务的同时给安全团队提供可见度和可控性。他们也是唯一一家为大多数云服务提供威胁检测并且能够提供漏洞修补的公司。

/ OBSIDIAN 宣传手册/



INKY


INKY是一家基于云邮件安全问题解决公司，主要以阻止诈骗邮件、病毒和钓鱼邮件为主。其主要方法是通过计算机视觉，人工智能，以及机器学习技术来截获恶意邮件。INKY 具有自我驱动性，便捷性，以及自我学习能力。在无需修改邮件系统的情形下，可以对用户提出警告，确保用户能安全的处理邮件，同时还能帮助用户查看、追踪被阻止的威胁。



BLUBRACKET


BLUBRACKET 公司是第一家全面解决大公司代码安全问题的公司，在保证开发人员能够安心合作与创新的同时，也能确保安全人员也能够在晚上安心睡觉。BluBracket 公司不仅可以通过检测源代码来避免安全风险的产生，而且能在不改变开发人员的工作流程或生产力下保护相关源代码。


随着越来越多的有价值的信息转移到代码中，越来越多的代码转移到云中，保护公司代码比以往任何时候都更加重要。BluBracket 在能够发现并对代码进行分类的同时，还能检查和监测安全风险，并能更好的保护好有价值的代码。



Elevate Security


Elevate Security 公司着重解决了安全问题当中人这一关键要素，Elevate Security 通过利用现有的数据（员工是否深入了解组织部门和雇员的潜在风险）来给员工的安全意识评分，并通过员工之间的分数比较来促使大家增强安全意识。同时该平台也会提供工具来让雇员们更好的提高安全意识。


TALA


由于当前 Web 体系中存在 JS 供应链的安全问题，并且当前的 Web 防护方案仍处于重服务端而轻客户端的现状，因此很多用户暴露在前端威胁中（典型的如 XSS等）。Tala 这家公司通过自动化的部署以及动态调节安全策略来保护网站和 Web 应用对抗高级威胁。Tala 通过一个 AI 引擎来记录分析网站的行为，从使 Tala 能够自动化识别最佳浏览器本地动态，实现 Web 安全策略的自动化动态调整，同时激活 CSP, SRI, HSTS 等其他安全标准。防止了各种可能出现的针对客户端的攻击，并努力保留了网站的性能。


（据小阑了解，他们的部署模式是在 Web 站点或者中间件亦或者 CDN 上面插入一些修改，并通过这些修改产生 CSP 等防护机制，从而保护客户端安全。）









北京星阑科技有限公司（简称星阑科技）是一家以安全技术为核心、AI技术为驱动的信息安全科技公司。致力于提供最前沿的智能化网络安全解决方案，用以解决政府、企业所面临的日益严峻的网络安全威胁。目前的主要产品均基于最前沿的图神经网络，包括智能边界防护引擎以及AI自动化漏洞挖掘系统，能全面提升客户的安全防护能力并有效降低安全运维成本。
