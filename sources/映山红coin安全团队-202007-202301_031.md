# Xposed是什么？

  

  

  

![](../Images/6ec1f75484ffd4a8a6113cf649288851.png)

  

Xposed是安卓手机上的一种框架，是一个由xda开发的框架，安装之后，可以让很多软件在这个框架里面去运行。Xposed框架只从开发出来以来，就收到广大安卓玩家们的青睐，隐隐约约有第一‘安卓神器’的名头。

![](../Images/6065c8667e4a690bbf6e933254ffb7e8.png)

  

  

# Xposed有什么用处？

  

  

![](../Images/f0ba10f05ba2433b7f4f1e8c3afbc3a4.png)

Xposed框架相当于一款很特殊的安卓app，最主要的功能还是提供新的平台，我们的安卓用户可以通过xposed框架搭建起平台，从而安装更多的系统级应用，实现我们很多的功能。

  

  

# Xposed框架的原理

  

  

![](../Images/df000fc905c3dee849a9c9021bba68e4.png)

Xposed框架的原理就是替换掉，安卓系统里面/system/bin目录下面的文件，从而实现对安卓系统某些功能上的接管，给我们很多安卓玩家来提供更多的权限， 更有利于我们安卓逆向技术去修改更多的东西，让我们可以去玩更多的安卓上的东西。也是安卓逆向技术很不错的一个框架，很实用。

  

  

# 修改后会有风险吗？

  

  

有，但是比我们直接修改的风险要低的多，因为我们是基于xposed框架的app去修改系统，所以会比我们直接修改系统文件的风险要低很多，对于我们新手来说是一个很不错的框架，当然风险概率虽然小，一不小心也有可能把系统给弄崩了，但这个情况也还是很小的，我们不要好奇很多就行。
