# **截止2018年12月，目前我国市场上监测到的APP为415w款**

**![](../Images/d10bd65589cfa50d0551791714559c73.png)**

2月28日，中国互联网络信息中心在京发布了2018年互联网发展状况统计报告，统计显示，截止2018年12月，我们市场上监测到的移动应用程序（APP）在架数量为449W款。

同时该报告显示，截止2018年12月，我国本土第三方应用商店移动应用数量超过268w款，占比59.7%；苹果商店（中国区）移动应用数量约为181w款，占比为40.3%

  

来源：工信部

  

**苹果发布iOS 14.0.1修复了重启后默认应用重置的错误**
