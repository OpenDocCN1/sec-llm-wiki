# **苹果iOS 14现漏洞！重启设备会重置邮件与浏览器设置！**

苹果于美国当地时间周三发布了iOS 14，该系统最值得注意的功能之一是能够将第三方邮件和浏览器应用程序设置为苹果Mail和Safari的默认替代程序。

  

![](../Images/6727e81b63614f8e4a5e348f0b23cb15.png)

  

  

发布后第二天，苹果最新发布的移动操作系统iOS 14更新似乎出现了安全漏洞，当设备重置或重启时，该漏洞会清除自定义的默认浏览器和邮件设置。

 

在社交媒体上，谷歌Chrome的一名工程师已经承认了这个问题，尽管苹果很可能会推出某种修复措施。

 

iOS 14的推出并不像过去的版本那样顺利，因为苹果只给了开发者不到一天的时间来准备应用程序的更新。然而，目前还不清楚是什么原因导致了重启漏洞。

来源：36氪

  

# **美国商务部最早本周日禁止美国区域应用商店分发TikTok和微信应用**

![](../Images/f34e5f8a31b5ad1fa406c7c3b9d82d9f.png)

  

路透社消息，美国政府最早将于9月20日禁止美国TikTok和微信应用商店下载。据路透社报道，美国商务部打算在当地时间周五发布新的命令，最早在9月20日（周日）禁止美国民众从应用商店下载热门视频分享应用TikTok。过去几周，TikTok的中国母公司字节跳动一直在与微软和甲骨文等美国公司进行谈判，目标是创建一家新公司TikTok Global，以满足特朗普政府对用户数据安全的担忧。

 

字节跳动与美国云计算公司甲骨文公司进行了一段时间的认真谈判，并提出协议成立一家名为 "TikTok Global "的新公司，以解决美国的安全问题。字节跳动仍需要得到美国总统特朗普的批准，才能默许达成协议，防止被禁，能否达成协议还存在疑问。

 

美国商务部还表示，不会寻求强制美国民众删除这些应用或停止使用它们，但会禁止进一步更新或下载新的应用。一位商务部官员说："我们的目标是企业高层。我们不会对个人用户下手。"

来源：cnBeta.com
