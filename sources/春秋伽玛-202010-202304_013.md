## m3chat

### 题目考点：

### 题目解析

#### 利用 RSA-LLL 攻击来计算私钥

![](../Images/8db1ea6c601152950e80ab5c596c5e29.png)

观察程序逻辑，在开始的时候需要校验证书的有效期，如果过期了，会提示输入新证书，并写入`license.lic`文件。

![](../Images/7266c7fe4a3b78b2f99f8d922c3fa6d6.png)

题目的证书是通过 `RAS` 验证算法进行验证

#### RSA 加密

RSA的加密过程可以使用一个通式来表达

```

密文＝明文E mod N密文＝明文E mod N
```

也就是说RSA加密是对明文的E次方后除以N后求余数的过程,从通式可知，只要知道E和N任何人都可以进行RSA加密了，所以说E、N是RSA加密的密钥，也就是说E和N的组合就是公钥，我们用(E,N)来表示公钥

#### RAS解密

RSA的解密同样可以使用一个通式来表达

```

明文＝密文D mod N明文＝密文D mod N
```

也就是说对密文进行D次方后除以N的余数就是明文，这就是RSA解密过程。知道D和N就能进行解密密文了，所以D和N的组合就是私钥 所以我们现在只要获得 D 即可计算出私钥这里的d不是直接就知道可以使用rsa-lll算法破解出来的，因为正常的`RSA`的话`e`是`0x10001`，比较小的，但是这里的e非常大，通常情况下e比较大的情况适用于RSA wiener attack，但是这里的话尝试使用wiener攻击脚本发现无法获取d，于是才进一步思考LLL攻击的可能

#### 利用堆溢出 来获取libc地址

溢出点是 在 `type` 为`0x2003` 这个函数 函数的主要作用为 `私聊`

![](../Images/7a7bc9e8670ba523f3abcca09d2dd627.png)

源程序思路是，把要私聊的内容保存到数据库中，在拼接sql语句时未对输入的内容进行长度限制，从而导致堆溢出。

我们输入的内容是通过 zlib 压缩算法进行压缩过的 当我们输入很多相同的字符时，就会被压缩的很小，所以`license` 结构体的name字段只有`0x100`的大小但是可以存放`0x1000`的数据
