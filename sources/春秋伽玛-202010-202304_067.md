但是继续向下看可以发现攻击者的爆破思路是：  

```

padding + char(i) + char(i)
```

这显然是不正确的，应当更正为：

```

padding + char(i) + char(j)
```

那么思路已经有了，需要选手编写一个 `ROS Node`向某个节点发送形如以上爆破结构的包，直到某个节点发送了带 `flag`的回复。但是还需要解决以下两个问题：

*   某个节点到底是 `/key_publisher`还是 `/core_server`
*   通讯协议是怎样的

首先解决第一个，其实根据名字就可以推断应该是向 `/core_server`发送数据，事实上选手可以通过编写节点试图向 `keypulisher`发送消息，会发现得到一个报错。

第二个，通过分析流量中的请求与回应，可以得到数据结构。

于是编写代码，为了方便可以先按https://docs.ros.org/en/galactic/Tutorials/Writing-A-Simple-Py-Service-And-Client.html所述进行ROS环境配置与Demo编写，同时由于题目使用了自定义类型，需要按https://docs.ros.org/en/galactic/Tutorials/Custom-ROS2-Interfaces.html也跑通。
