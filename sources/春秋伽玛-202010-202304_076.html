00 楔子

作为春秋杯秋季赛“勇者山峰”赛道专题，本题并没有设置很高的难度门槛，对于想学习合约的同学来说，是一个比较不错的练习题目。
题目预设的漏洞点如下：
1. 前端js代码审计，重放攻击
2. 合约交互漏洞，addAccount重放攻击
3. 合约逆向，逻辑漏洞，payToUser任意用户地址余额转移
4. 多用户注册，薅羊毛攻击
5. 正常游戏通关

比赛结束后，一共有6位选手注册账户，5位选手成功获取flag，4位选手成功提交题目，3位选手提交wp，2位选手使用游戏通关玩法，1位选手使用合约漏洞攻击并取得一血，嗯，就是这么等差数列。

01 正常游戏通关

我们来看下一般情况下的通关逻辑。

首先注册账户，填写好自己的钱包地址、邮箱、token信息后，进入如下页面。

根据提示玩左边的游戏，按S键后，开始游戏。

游戏的界面应该还可以，左边的mario代表生命，右边的world代表世界。

可以分析js代码，从众多的js代码中，找到mario跟world的一些相关内容。比如：

02 bug环节

在比赛运维期间，依旧出现了喜闻乐见的玩bug系列。

之前大晚上写合约，代码写的迷迷糊糊，导致 sendGift 合约代码给写成了transfer。然后在很多次测试中居然还没发现这个bug，简直离谱了...

好吧，正确的代码是应该是如下方法：

    function sendGift(address payable addr_,uint256 amount_) public onlyPlayer{
        _mint(addr_, amount_);
    }

本来这个是可以触发一个漏洞点的，但是最后发现，很多人玩游戏居然不涨coins。仔细检查后发现是这个问题，简直想吐血。

因为在比赛中，如果贸然中止合约而创建一条新的合约，明显会对比赛产生比较大的影响。所以在比赛中仅仅是修改了交互时调用合约的逻辑，本来的接口走向是 前端 saveMoney -> 后端 saveMoney -> API sendGift -> contract sendGift，经过思考之后，决定将API调用的方法改成 payToUser，这样在前端看起来逻辑是正常的，只不过本来是合约主动印发coins变成了由owner被动发coins...，不管怎么说，反正暂时问题是解决了～ 

什么？你问如果owner的coins发完了怎么办？hhh，owner可以自己印发哒。


03 coins重放攻击

言归正传，我们可以把目光聚焦在coins的发送上，coins是根据我们游戏中获取的金币数量决定的，所以每次游戏之后，应该会有一个请求跟后端代码进行交互，发送当前回合获取的coins数量。所以，我们可以使用chrome分析网络请求。

查找一下发送请求的代码，不难在levelState.js中发现它的身影。从图中可以看出，代码使用jq的post方法，将 coins 发送到 /saveMoney 接口。

既然我们知道了coins的发送方法，那么我们可以尝试着使用bp或者别的工具抓包重放，便可以让coins很快的增加了～

但是有的同学发现了，修改coins之后，发现服务器返回了一个failed的问题，然后以为是存在什么验证逻辑，就没继续测试了。其实这里只是一个很简单的判断，仅仅是判断了每次请求中coins的数量是不是大于200，如果大于200，那么就返回failed，否则的话，就正常往合约中发送数据。


04 合约的分析

我们从web页面中可以获取到的信息基本就是这么多，接下来得开始合约的分析了。

从web页面中可以获取到合约的地址，其实不从web页面，从我们自己的metamask中也可以看到合约的地址，是 0xA658070ae2b6701570C7eF04ac5765a825A37013。跟踪进入之后，发现合约是一个共享的状态，所有选手都可以在合约上进行自己的操作。

同时还没有开放源代码，我们只能使用在线分析工具来进行分析。

以太坊合约代码分析工具网址是：https://ethervm.io/decompile/ ，我们可以输入以太坊 上的合约地址，便可以获取合约的evm汇编代码(https://ethervm.io/decompile/rinkeby/0xa658070ae2b6701570c7ef04ac5765a825a37013)。

05 addAccount重放攻击

此处的 addAccount 没有做验证，允许多次重复执行，仅仅是将 _allowAccounts 中的地址标记为 true。

所以此处可以重复调用，可以编写攻击合约如下：

// by 本题一血 pikachu
contract hack {
    Test target = Test(0xA658070ae2b6701570C7eF04ac5765a825A37013);

    function hack1(uint times) public {
        for (uint i=0;i<times;i++){
            target.addAccount(address(0x1B338bcB47a7Cdbbe369223548e78DC64ECDe8ba));
        }
    }
}

08 结语
