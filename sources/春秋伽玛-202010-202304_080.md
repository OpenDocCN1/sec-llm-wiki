Web:easy\_fastjson

  

下载附件使用 `jd-gui` 反编译阅读源码：

找到 `com.easy_fastjson.controller` 包，下面有个 `hackMe` ：

![](../Images/27b23b5748179f89b8e335f75a1d203a.png)  

阅读源码会发现只有两个主要函数：

`hackme`:这个函数主要是把开头把 `L和;`两个字符的 `unicode` 编码和 `ascii` 编码都解码了，因为 `fastjson` 是会自动解码`unicode` 和 `ascii` 的，这里的意思 是不能使用 `L` 和 `;` 的编码。

然后用正则表达式，匹配出了 `@type` 指定的类。

最后到 `dont_want_bypass_me` 函数会发现这里把开头的 `L`  和 结尾的 `;` 替换成空。

最后才进行了 `JSON.parse`。既然是 `fastjson` ，我们看看 `pom` :

```
<dependency>
<groupId>com.alibaba</groupId>
<artifactId>fastjson</artifactId>
<version>1.2.42</version>
</dependency>

```

`1.2.42` 的，版本很低，`1.2.42` 有一个绕过方法是前面两个 `L` 后面两个 `;`

参考文章（https://xz.aliyun.com/t/7027#toc-16）

![](../Images/124e3a1f4b5adb897fe4e48341b69e58.png)

但是这里缺过滤删除了，并且也不能使用 `unicode` 编码。  

但是进入 `fastjson` 内部，会发现：

![](../Images/2fb150e2b47769a37c078c4008403917.png)

  

如果是 `L` 开头并且 `;` 结尾，那么就会一直递归删除，而这里删除的步骤只删了 `20`次，那么我们只要把 `L` 多写几次就行了。

  

并且这里的代码开启了 `autotype` 和 `SupportNonPublicField`，所以我们可以使用  `TemplatesImpl`这个 `payload` 即可
