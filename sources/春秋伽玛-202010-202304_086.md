# 该如何玩转美团网络安全高校挑战赛？

Hi，同学们：

  

很开心的通知大家，由美团安全应急响应中心（MTSRC）、美团校园招聘团队、美团科协联合发起，永信至诚提供技术支持的第四届美团网络安全高校挑战赛从11月15日已经开始报名啦！  
小编悄悄说：近期北方的冬天真的好冷呀，真想抱着烤红薯在家里躺平。但是发现好像还有好多同学对活动云里雾里吖，那么该如何玩转这场比赛呢？请往下看！

![](../Images/8758861e56b745ac99877606c9eb25e0.png)

  
![](../Images/402408ccc34c7d39de576cedfbabc4c3.png)**SMALL RED FLOWER****参与人群**

  

本届网络安全高校挑战赛中的**每一位参赛选手**，都可成为“校园宣传委员”，完成任务即可领取小红花。**未参赛或不符合参赛资格的选手，参与宣传均无效。**

[![](../Images/01079b8df3fdc0e351f52a885d6c3671.png)](http://mp.weixin.qq.com/s?__biz=MzI5MDc4MTM3Mg==&mid=2247488589&idx=1&sn=78736b75f42869cb4136f665cfdae728&chksm=ec1bf59edb6c7c887f20fff1558c017bc53885984e5eed479f29bccaf455bbe157c00fb67401&scene=21#wechat_redirect)

![](../Images/402408ccc34c7d39de576cedfbabc4c3.png)**SMALL RED FLOWER****宣传周期**

11月15日-12月10日

  

![](../Images/402408ccc34c7d39de576cedfbabc4c3.png)**SMALL RED FLOWER****宣传任务**

在下方任务清单中，每完成一项任务，即可领取相应数量的小红花！执行宣传任务前请务必查看每一项任务的小红花领取规则，避免不符合要求无法领取小红花。

![](../Images/eee4edf2248a9012b2516bfb0b36c8d7.png)

  

![](../Images/402408ccc34c7d39de576cedfbabc4c3.png)**SMALL RED FLOWER****奖金**

每朵小红花可兑换现金奖励，兑换比例1:5（即1朵小红花，可兑换5元现金），所有奖金将在比赛结束后统一进行结算、发放。

  

![](../Images/402408ccc34c7d39de576cedfbabc4c3.png)**SMALL RED FLOWER****领取小红花**1\. 前往美团安全应急响应中心官方网站https://security.meituan.com，注册你的账号；  
2\. 完成所有你想执行的宣传任务后，将每一个任务的截图或照片、以及其他必要信息，提交至：https://wenjuan.meituan.com/survey/4873972（或扫描下方二维码打开）

![](../Images/2bb46343e6498047dc4f638d56dbcbc2.png)

  

3\. 比赛结束后，运营同学将统一审核上传的截图及照片，审核通过即在你的美团安全应急响应中心的个人账号中充值小红花（安全币），小红花（安全币）可直接兑换现金或其他礼品。

  

有任何问题可添加运营同学的微信（942761431）。
