01


Strange Samples

出题人：Galaxy@W&M

题目考点为 Image Scaling Attacks 图片缩放攻击，是攻击机器学习有关图片训练模型的一种攻击方式，原理简单来说就是：根据不同图片缩放算法的特点，修改图片像素的权值，把其中一些需要用到的像素突出，从而达到在图片缩小后使图片内容发生变化的效果
相关文章链接：

  • https://zhuanlan.zhihu.com/p/279284305

  • https://scaling-attacks.net/#portfolioModal1

  • https://bdtechtalks.com/2020/08/03/machine-learning-adversarial-image-scaling/

  • https://www.aminer.cn/research_report/5f3cd59d3c99ce0ab7bc7ecb


攻击及防御方式官方已开源：
https://github.com/EQuiw/2019-scalingattack
本题直接在官方公开的项目源码中稍作修改，并未更换CV库，只更换了图片源以及图片的缩放算法，根据攻击原理，我们想要得到缩放攻击后的图片，就必须要知道目标图片的大小、进行缩放的库和缩放算法，根据题目描述我们可以得知目标图片都为正方形，而想要进行缩放攻击，目标图片的大小也要远小于原图片，根据这些已知信息，写类似如下脚本进行爆破。
import cv2
pic = cv2.imread("xxx\\1.png")

flag = 1
for i in range(1,100):
    pict = cv2.resize(pic, (i,i), interpolation=cv2.INTER_NEAREST)
    #cv2.imshow('', pic)
    cv2.imwrite("xxx\\output\\%d.png"%(flag), pict)
    flag += 1

当库以及缩放算法都正确时，我们通过爆破图片大小，可以得到一系列经过缩放处理后的图片，在其中就可以找到目标图片

通过爆破图片大小，当缩放到50x50时，可以得到一系列图片

一共25张图片，但是其中有两种经过了混淆，所以无法直接使用gaps拼图，可以写个脚本，也可以手撕一下，还原图片可以得到压缩包密码

压缩包密码：$wQX5#Cy

解压之后得到FLAG文件，打开是U+hex编码，在线网站一把梭，可以得到一串emoji

尝试解codemoji解不开，说明是emoji-aes，接下来寻找密钥

我们再仔细观察题目所给的图片，可以发现在一些区域明显存在两种缩放像素的重叠

可以推测同一张图片中还通过另一种不同的图片大小或缩放方式映射了另一张不同的图片，可以经过尝试算法和爆破大小，得到另一种缩放算法为cv2.INTER_LANCZOS4，图片大小为64x64，这次得到的图片可以直接利用gaps一把梭，得到aeskey：$@qOj9

Baby_steg

出题人：L1near@W&M

解题思路

1. 首先对flag1.txt进行uudecode，得到flag.7z
sudo apt-get install sharutils
uudecode flag1.txt


2. 然后使用github上的工具(7z2hashcat)提取出password.7z的hash值


3. 用hashcat进行爆破:

hashcat -m 11600 '$7z$2$19$0$$16$abc477f84f711f5530432e64418c8392$3167568243$16$12$40a31f0f88ac7b9a9acdc6cbb7d23f23$8$00' -a 3 "?d?d?d?d?d?d" --force



4. 得到密码321456，打开得到flag.7z的密码，解开flag.7z，得到图像加密脚本和加密后的图片。

5.编写图像解密脚本，得到flag：

import numpy as np
import cv2
import sys

def unshuffle(arr, size, indexes):
    result = [0] * size

    for i, ind in enumerate(indexes):
        result[ind] = arr[i]

    return np.array(result)


def decode(image):
    for j in range(520,541):
        np.random.seed(j)
        to_show = cv2.imread(image)
        to_show_array = np.asarray(to_show)
        image_size = 1298

        for i in range(to_show_array.shape[0]):
            indexes = list(range(image_size))
            np.random.shuffle(indexes)
            to_show_array[i] = unshuffle(to_show_array[i], image_size, indexes)

        gray = cv2.cvtColor(to_show_array, cv2.COLOR_BGR2GRAY)
        cv2.imwrite('result{}.png'.format(j), gray)

def main():
    if len(sys.argv) != 2:
        print('error!')
        exit(1)
    decode(sys.argv[1])

if __name__ == '__main__':
    main()
