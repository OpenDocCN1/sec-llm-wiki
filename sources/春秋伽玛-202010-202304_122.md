**密码学安全研究员**

**薪资：20-30K x 14薪**

**岗位职责**

1.全球密码学题目收集分类整理

2.高校密码学方向技术培训

3.国密、商密算法安全研究

4.对公司软硬件产品加密算法安全分析

5.密码学相关的其他工作内容

**任职要求**

1.熟悉常见编码，如hex、URL编码、morse code 、JS fuck 、uuencode 、base家族等。

2.熟悉古典密码，如移位、曲路、云影、栅栏、替代密码。

3.熟悉分组密码的工作模式：ECB/CBC/OFB/CFB/CTR等。  
熟悉分组密码和序列密码、DES/AES基本加解密。

4.熟悉分组密码CBC bit翻转攻击、选择密文攻击、padding oracle攻击。

5.熟悉Feistel结构分析、攻击伪随机数发生器。

6.深入了解公钥密码、RSA、直接模数分解，费马分解和Pollard rho分解。

7.熟悉公约数模数分解 、其他模数分解方式、小指数明文爆破、选择密文攻击、LLL-attack。

8.熟悉Wiener攻击、 Boneh Durfee攻击、共模攻击、广播攻击、相关消息攻击、 DSA。

9.掌握哈希碰撞 、长度扩展攻击。
