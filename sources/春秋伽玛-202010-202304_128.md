题目出的比较简单，就这么几个点：  

1\. 题目框架 laravel2\. 有上传点，但是文件名不可控3. `/image` 路由使用`getimagesize()`函数读取用户传入的文件地址，返回图片大小。4\. 题目使用`preg_match("/&lt;\?|php|HALT_COMPILER/i", $content)`，对上传的文件内容进行检测，ban 掉了很明显的 phar 文件的使用的关键字符串以及一些 php 文件的特征5\. 传入文件地址的路由`/image`被 nginx 配置文件禁止访问，所以即使绕过了上面文件内容检查也需要绕过这个限制传入`phar://`触发反序列化

```

所以综合以上题目的基本设置，我们可以基本有以下想法：

1\. 结合 laravel 这个众所周知的热门 CTF 反序列考点，以及`getimagesize()`这个文件操作的函数，不难发现这个题目的考点就是 phar 反序列化。这里因为我前面设置的坑比较多，而且感觉现场挖链的题目不是很好，所以就直接拿了个有链子的框架做了（纯粹是又懒又菜挖不到。

2\. 既然确定了后面的考点，怎么绕过对于 phar 文件内容的检测呢？这个我们简单回顾一下当初 black hat phar 反序列化的议题，扣扣细节就可以知道了，phar 文件其实有 tar 压缩的格式，可以用来绕过这个关键字的过滤

  

![](../Images/ba544d1693fe42115593aaa709ff1a48.png)

  

3\. 既然绕过了 phar 文件内容的限制，那么就剩下 nginx 路由限制了。我们可以在 nginx/apache 的配置里面都看到 HTTP/2 的配置，其实线下赛没必要这么配置，既然这么配置那肯定是有用的。所以随便搜一下我们可以知道有 HTTP/2 Smuggling 用来 bypass 这个路由限制。不知道或者忘了的小伙伴可以复习一下：

https://labs.bishopfox.com/tech-blog/h2c-smuggling-request-smuggling-via-http/2-cleartext-h2c

1.1

;
```

春秋留言  

  

  

1\. 用 phar tar 格式的时候需要有后缀，像 sess\_a 这种 PHP session 虽然可以写进去，但是没有文件后缀名，无法正常反序列化，这里我没有仔细 debug 这个问题，不清楚是什么问题，如果有大佬知道的话麻烦告诉一下，如果可以的话，就可能直接利用 session 进行反序列化了。

2\. HTTP/2 也是个很神奇的东西，L3H 的师傅说当时命令执行的回显被吃了，卡了半天，原本成功了的以为没有成功。这个我在题目设计的时候弄 HTTP/2 也弄了很久，大部分时间在配置 nginx/apache HTTP/2 上面，所以不是预期做的话就会有很多奇奇怪怪的东西。（至少我能保证预期是肯定可以正常回显的。)

3\. 抛开赛制不提，我问了一些师傅关于这个题目的看法，大部分表示因为看到路由限制还限制了 phar 文件内容就没有看了（就去看 PK 体制的题目了，SAD ）

4\. 整体来说，这个题目设计并不是很好，特别是防御上，由于不太严格的 check 基本上 ban 了 phar 协议都可以防御成功了。但是本着题目分享一些小技巧的中心思想，还是最终设计成了这样（麻烦师傅们把刀收一下。

5\. 随着 PHP 的发展，在 php 8 之后 phar 将不会再自动反序列化，也就是说 phar 反序列化这种 CTF 考点也将成为 php 绝唱。昨晚还有一个师傅跟我交流说原本把 tar 这个点打算用在某个大型 CTF 上，还说我浪费了考点逼得他换题了，不过换个说法说还好我及时发出来了，也避免了考点重复（哭。希望他能送我一个免费鹅

  

整体来说这个题目出的考点都不是什么很新颖的考点，但是看到某处的wp没有完全 get 到题目考点是比较让出题人难受，所以这里就简单把之前这个题目考点写一下，与大家分享。
