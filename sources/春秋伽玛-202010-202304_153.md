# “纵横杯” 网络安全竞赛线上赛判罚修正公告

经IDLab战队申诉并举证，该战队内选手通过某种主流即时通讯软件传递文件时出现了同名文件内容被替换问题。经裁判组反复测试及向第三方即时通讯软件技术团队求证后，确认存在文件名称相同内容不同传输时被替换的可能性。

  

结合IDLab战队的举证视频及第三方即时通讯软件技术团队沟通情况，决定撤销对该战队的违规判定。

  

同时，组委会也将该软件存在的问题反馈至其技术团队，也提醒各位参赛选手在日后的比赛中坚持通过平台下载题目附件。

  

感谢IDLab战队的理解以及对裁判质询工作的配合。
