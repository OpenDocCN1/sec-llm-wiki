# IDA使用快捷键汇总

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMjM5Njc4MA==&mid=2247486116&idx=1&sn=c284fef488eb10289d30209fc5b856a9&chksm=96de0fa7a1a986b118e968fdaf15a243ee9290b946222f2e59ee5995cc2730b1633a960b2882&scene=126&sessionid=1681448444#rd](http://mp.weixin.qq.com/s?__biz=MzIwMjM5Njc4MA==&mid=2247486116&idx=1&sn=c284fef488eb10289d30209fc5b856a9&chksm=96de0fa7a1a986b118e968fdaf15a243ee9290b946222f2e59ee5995cc2730b1633a960b2882&scene=126&sessionid=1681448444#rd)

| 快捷键 || 作用 |
| :-: | --- |
| 空格键 || 反汇编窗口切换文本跟图形 |
| :-: | --- |
| ESC || 退到上一个操作地址 |
| G || 搜索地址或者符号 |
| N || 重命名 |
| 分号键 || 注释 |
| ALT+M || 添加标签 |
| CTRL+M || 列出所有标签 |
| CTRL +S || 列出二进制段信息 |
| C || 光标地址出内容解析成代码 |
| P || 在函数开始处使用P，从当前地址处解析成函数 |
| D || 数据类型切换：db---dw----dd可以设置 |
| A || 解析成ASCII，即识别成字符串 |
| U || 解析成未定义的内容 |
| X || 交叉引用 |
| F5 || C伪代码 |
| ALT+T || 搜索文本 |
| ALT+B || 搜索16进制 搜索opcode 如ELF文件头 |
| CTRL+ALT+B || 打开断点列表 |
| F7 || 单步步入 |
| F8 || 单步步过 |
| CTRL+F7 || 运行到函数返回地址 |
| F4 || 运行到光标处 |
| Y || 修改函数原型 或者 变量类型 |
| H || 10进制 和 十六进制 进行转换 |
| ALT+K || 修改选中指令sp value |
| ALT+G || arm与thumb指令转换 |
| TAB || 伪C代码与arm指令对应切换 |
| R || 字符转换：95 ---> “\_” |
