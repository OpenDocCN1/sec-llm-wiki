frida是一款基于python + java 的hook框架，可运行在android、ios、linux、winosx等各平台上，主要使用动态二进制插桩技术。


1
frida工具的安装


1.安装python3.7,如下图所示。



2.配置python的环境变量，如下图所示。



3.打开cmd输入命令：pip install frida进行安装，如下图所示。




4.打开cmd输入命令：pip install frida-tools安装frida工具，如下图所示。

      


注意：如果报错，需要更新，执行命令：python -m pip install --upgrade pip，等待frida工具安装成功即可。


5.frida工具安装完成后,执行命令:frida -help,测试是否安装成功，如下图所示。




2
下载frida-server文件，运行frida-server


注意：frida-server文件的版本一定要和你安装的frida版本一致！

  

1.把frida-server文件发送至手机的/data/local/tmp里面，输入adb shell 命令，再输入su命令取得root权限，执行命令cd /data/loca/tmp到对应的目录，如下图所示。


2.然后ls -l在列表里找到server的文件名，给到chomd 777 权限，如下图所示。
