# IDA调试环境搭建

通过前面几天的分享，我们掌握了IDA静态分析so文件的操作方法，但想要更加具体地对程序进行分析，动态调试是必不可少的，而在动态调试之前，则需要搭建IDA动态调试的环境。  

  

1创建安卓自带模拟器

  

1.在SDK中找到AVD Manager.exe程序，如图1.1所示。 

  

![](../Images/a44fb5446bda898685e609f115f4d4b9.png)

                               （图1.1）

  

2.双击打开程序，如图1.2所示。

  

![](../Images/13a6a6f31cf01981bc5f9e68df58e75b.png)

                               （图1.2）

  

3.点击页面右侧的“Create”按钮，创建相应的模拟器，如图1.3所示。

  

![](../Images/e5c365c1e30e12d9512983045e3dd80a.png)

                               （图1.3）

4.在模拟器中设置一系列的参数值，点击OK，如图1.4所示。

**AVD Name：**模拟器名称，可随意取名。

**Device：**设备类型，选择Nexu5。

  

![](../Images/e2de8a663bae7d9f12e2a0d1d2da6395.png)

                               （图1.4）

5.创建完毕，直接点击start启动。

  

  

2运行android server

  

1.在IDA6.8目录下，找到android server文件，拖至桌面，如图1.5所示。

  

![](../Images/61d6b4a1838c766a845b270f8a0ad948.png)

                               （图1.5）

2.使用adb命令把android server文件push到模拟器中，如图1.6所示。

  

![](../Images/a1866ff4ac36a290a9f47275fe75f8ec.png)

                               （图1.6）

3.使用adb命令连接模拟器，来到目录cd /data/local/tmp下，使用ls命令列出这里的文件,如图1.7所示。

  

![](../Images/37af28d2d912719a94ed59ba5ef04378.png)

                               （图1.7）  

  

4.给这个文件一个777权限：chmod 777 android\_server，如图1.8所示。

  

![](../Images/0b9c0814c284b486198da931743e94d0.png)

                               （图1.8）  

  

5.使用ls -l列出全部文件，-l是详细信息，如图1.9所示。

  

![](../Images/cf80f8c08017d631c150a4919a7b1820.png)

                               （图1.9）  

  

6.如果修改权限成功，会出现提示,如:rwxrwxwx，表示此文件有了各种操作的权限，r代表可读，w代表可写,如图1.10所示。

  

![](../Images/190462724608486db0e90f5432360611.png)

                               （图1.10）  

  

7.运行此文件，如果出现23946这个提示，则视为成功，如图1.11所示。

  

![](../Images/029698ae2e3584bc2e22df55382129cb.png)

                               （图1.11）

  

8.新打开一个cmd窗口，进行端口转发，此处转发的端口号与上面运行android\_server时产生的端口号一致，如1.12所示。

  

![](../Images/31cc7ae6c27dfb0316b1b88bcd913628.png)

                               （图1.12）

  

3IDA附加+勾选三项

  

环境搭建完成之后，将准备好的apk文件安装包安装在模拟器（真机）上，如图1.13所示。

adb :Android 调试桥 (adb) 是一种功能多样的命令行工具，可让用户与设备进行通信。

**install：**表示安装软件

**adb install xxx：**xxx表示安装的软件的包名

  

![](../Images/de35ddd06cbbc1f6126d75dbd9aaf3bf.png)

                               （图1.13）

  

1.上述步骤完成后，开始使用IDA，如图1.14所示。

  

![](../Images/6952947173de62a60202ce30ec2ebe2f.png)

                               （图1.14）

2.进来后，选择attach下的Android debugger选项，如图1.15所示。

  

![](../Images/10f59eab55668e309773ad4dd863e099.png)

                               （图1.15）

3.点击后出现一个窗口，Hostname是主机名称，同样也是本地的ip地址，Port即端口，就是刚才的23946，password可省略不填写，如图1.16所示。

  

![](../Images/8bfaa3db5f2397d7ec05f5a7b7cca7d3.png)

                               （图1.16）

4.点击OK，出现Choose process to attach to这个界面，此页面包含一系列的包名，如图1.17所示。

  

![](../Images/5ae77edf45a43f68c5bd5a8e98784f03.png)

                               （图1.17）

**注意：如果列表没有应用程序的包名，可以回到程序，点击程序运行。**

  

5.选中待调试的包名，点击OK，如图1.18所示。

  

![](../Images/1e5978d57246eef2173cff2d5a3a007e.png)

                               （图1.18）

6.出现一个窗口，继续点击OK，此时显示附加成功，如图1.19所示。

  

![](../Images/625d72c5b5d8b8ff689b17490776344e.png)

                               （图1.19）

7.此时模块列表还没有断下来，也就是说so模块还未加载进来，选择此页面中Debugger option选项，如图1.20所示。

  

![](../Images/6643bf7053fded209150b253474f651e.png)

                               （图1.20）

8.勾选Events列表下的三个选项：Suspend on process entry point、 Suspend on thread start/exit和 Suspend on library load/unload，点击OK，如图1.21所示。

  

![](../Images/df61cbe9b7f73e876f788e2dcc10c715.png)

                               （图1.21）

9.点击OK，开始运行，如图1.22所示。

  

![](../Images/c9db7df600dc4e7fd54d35b19047ae72.png)

                               （图1.22）

10.此时对应的so库被加载进来，接下来就可以进行下断，从而进行IDA动态调试。

  

  

4小结

  

通过本次的分享，我们已经掌握了IDA动态调试的环境搭建，总得来说有以下大致五个步骤：

1、先在IDA里面找到android\_server,然后发送到真机。

2、在cmd里面运行android\_server并且端口转发。

3、在IDA里面配置主机号和端口号。

4、附加调试程序的进程。

5、进来后勾选三项，然后F9运行程序。
