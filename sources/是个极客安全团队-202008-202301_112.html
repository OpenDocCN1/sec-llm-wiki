篡改APK名称


以土豆视频篡改为优酷视频为例：


1.第一步，打开AndroidKiller工具，把“土豆视频”APP拖入到AndroidKiller工具里，开始自动反编译，反编译完成后会弹出一个窗口，如图2.1所示。点击“否”后，可以看到土豆图标旁边有三项内容：名称、包名以及入口。“、土豆视频”是程序的名称，要篡改的APK名称就是修改这个字符串，第二项包名即应用程序包名，第三项入口即程序入口界面，如图2.2所示。


                               （图2.1）


                               （图2.2）


2.第二步，点击“工程搜索”，在编辑框里输入“土豆视频”四个字，点击“搜索”按钮，搜索过程大概需要30秒左右，如图2.3所示。


                               （图2.3）


3.搜索完成后，将搜索到的“土豆视频”字符串全部改为“优酷视频”四个字，在上图中的替换字符栏里输入“优酷视频”，点击“全部替换”如图2.4所示。


                               （图2.4）


4.替换成功后，点击“编译”按钮进行回编译，这个过程大概需要30秒的时间，最后一步，打开雷电模拟器，将刚刚编译好的程序拖入模拟器中，安装运行，效果如图2.5所示


                               （图2.5）





篡改APK图标



1.点击“工程管理器”，找到“AndroidManifest.xml”文件，双击打开，在“AndroidManifest.xml”文件里查找“application”签，再找到“application”里的“android：icon=@drawable/icon”属性，icon就是应用程序图标的名字，进行全局搜索“icon”，会搜索到很多很多结果。


若想快速搜索路径，则需要在“MANIFEST.MF”文件中进行搜索，快速且精准，如图2.6所示。


                               （图2.6）


2.找到“MANIFEST.MF”文件，在搜索字符栏输入“/icon.png”，搜索到的结果如图2.7和2.8所示。


                               （图2.7）


                               （图2.8）


 技巧一：在“META-INF”文件夹中的“MANIFEST.MF”文件搜索。

 技巧二：搜索“/icon.png”，而不是icon。


3.继续后面的操作，搜索“/icon.png”文件，找到对应路径下的图片进行替换。替换完成后，进行回编译。接下来，打开雷电模拟器，将刚刚编译好的程序拖入模拟器中，安装运行，实现效果如图2.9所示：


                               （图2.9）





小结


篡改APK名称：

APP → AndroidKiller  → 反编译  → 工程搜索  →

输入APP名称  → 搜索  → 全部改为新APP名称  → 编译 →

雷电模拟器→安装运行


篡改APK图标：

工程管理器 → AndroidManifest.xml →

“application”标签 →“android：icon=@drawable/icon” →“META-INF”→ MANIFEST.MF → 搜索“/icon.png → 替换图片
