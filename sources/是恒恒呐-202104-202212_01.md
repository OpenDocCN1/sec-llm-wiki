**一：对课程和学员负责，重视：**

```
1.以初学者的学习角度出发，安排课程内容，以便让小白更好吸收。
```


```
4.培训讲师会不定期收集学员对本课程的改进建议：    并根据反馈对课程内容及时进行改进，有任何问题欢迎随时联系讲师      
```

```
5.安排课程作业，不定期展开阶段性实战技术考核：    通过作业和考核内容的答疑，来不断督促学员学习和总结。    （根据学员个人情况安排，不强迫）      
```

```
6.讲师不定期询问学员学习进度和自身学习问题，进行答疑和记录。
```
