1.禁用windows update  

![](../Images/637132e3af33d0d35d4a055e6396118f.png)![](../Images/795f63c8f2728df9697a16a7d1ad02b8.png)

2.关闭防火墙

![](../Images/3907f290f3489bfa91424c75257e3822.png)

  

3.通过检测POC，发现主机易攻击

检测POC：

![](../Images/a59b5f405121255f09adbec10edfec4c.png)![](../Images/de9110e066f9b22d70735afdb8259903.png)

  

4.在kali中生成木马：

使用msfvenom模块生产木马

msfvenom -p windows/x64/meterpreter/bind\_tcp LPORT=6666 -b '\\x00' -i 1 -f python

![](../Images/f597beb71da63602804ef90657741031.png)

用生成的shellcode将POC文件里exploit.py中的一部分替换掉，直接复制粘贴，将buf替换成USER\_PAYLOAD保存  

![](../Images/91c51227be6a921b3e8163bcb574091e.png)

替换完成  

![](../Images/9f61f5c1dc9ef80ebbd8db3a6b6835da.png)

5.开启msf监听  

成功开启监听端口：6666

![](../Images/b59cd55d4cab199ae0a41b45556d45ad.png)

  

6\. 运行exploit.py脚本：

该脚本虽说是远程代码执行脚本，但有可能导致目标ip死机，蓝屏，重启等后果。也有可能目标主机不受到任何影响。如果出现physical read primitive failed，则多次尝试执行exploit.py几次，就会成功了，这个exp是有一定概率的。
