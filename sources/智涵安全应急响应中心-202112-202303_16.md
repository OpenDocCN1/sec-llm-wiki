# CVE-2021-36934 Windows提权漏洞复现

靶机环境：Windows10 1909

首先输入icacls C:\\windows\\system32\\config\\sam查看系统安全性，输出BUILTIN\\Users:(I)(RX)，表示系统易受到攻击

![](../Images/89ddac5565a6e82f62afc30cce71da16.png)
