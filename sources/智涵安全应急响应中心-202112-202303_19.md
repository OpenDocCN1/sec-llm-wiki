# 远程桌面服务远程代码执行漏洞（CVE-2019-0708）分析报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2ODcyMDEyNQ==&mid=2247483704&idx=1&sn=6bbb306d04c806d229b6a7825bdd67d9&chksm=cea94daaf9dec4bc0b08a0f00efc37bf73334e8b13a4b2cc31872f370d5bf046351249bb0a5d&scene=126&sessionid=1681408780#rd](http://mp.weixin.qq.com/s?__biz=Mzg2ODcyMDEyNQ==&mid=2247483704&idx=1&sn=6bbb306d04c806d229b6a7825bdd67d9&chksm=cea94daaf9dec4bc0b08a0f00efc37bf73334e8b13a4b2cc31872f370d5bf046351249bb0a5d&scene=126&sessionid=1681408780#rd)

**（CVE-2019-0708）**

漏洞介绍

当未经身份验证的攻击者使用 RDP 连接到目标系统并发送特制请求时，远程桌面服务（以前称为终端服务）中存在一个远程代码执行漏洞，即“远程桌面服务远程代码执行漏洞”。

漏洞影响版本

Windows 7

Windows server 2008 R2

Windows server 2008

Windows 2003

Windows xp

漏洞利用过程

过程为实验靶机，而非以上服务器

use   exploit/windows/rdp/cve\_2019\_0708\_bluekeep\_rce

set rhost 10.xx.xx.xx 

//这里的ip填写受害机地址

修复建议

1\. 在运行受支持版本的 Windows 7、Windows Server 2008 和 Windows Server 2008 R2 的系统上启用网络级别身份验证 (NLA)

您可以启用网络级别身份验证以阻止未经身份验证的攻击者利用此漏洞。启用 NLA 后，攻击者首先需要使用目标系统上的有效帐户对远程桌面服务进行身份验证，然后攻击者才能利用该漏洞。

2\. 在企业外围防火墙阻止 TCP 端口 3389

TCP 端口 3389 用于启动与受影响组件的连接。在网络外围防火墙阻止此端口将有助于保护位于该防火墙后面的系统免受利用此漏洞的企图。这有助于保护网络免受源自企业外围的攻击。在企业边界阻止受影响的端口是帮助避免基于 Internet 的攻击的最佳防御措施。但是，系统仍可能容易受到来自其企业范围内的攻击。
