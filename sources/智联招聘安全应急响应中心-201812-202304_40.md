满族屯满族乡，位于科右前旗西北部，是全国唯一以畜牧业为主的满族自治乡。这里最为出名的便是那充满神奇色彩和历史传说的科尔沁草原。但满族屯偏远的位置，致使曾经辉煌的草原未能赶上中国经济发展的时代班车。

  

我们本次捐赠的满族屯学校是一所九年制边境乡村学校。建于1984年，目前有在校学生234名，教职工70 人。**本次教育公益活动，由完美世界工会联合会与完美世界、智联招聘、爱奇艺、滴滴、小米、贝壳、VIPKID、微博 8 家企业的安全应急响应中心（SRC）联合发起。整个活动，在4月23日（世界读书日）开启直到5月31日结束，企业SRC与新老白帽们一起伸出圆梦之手！**

  

**爱心白帽 公益挖洞**

国家越来越富强，社会越来越进步。我们熟练的在网络世界里驰骋，每天都享受着科技带给我们的便捷和快乐。但仍然有那么一群孩子，为了上学，他们要走最泥泞的路，翻过一个又一个山坡，每一个脚印都是为了完成“我的梦”。你愿意和我一起牵手，帮助那些在草原追梦的孩子吗？用白帽子的方式，来帮助他们完成梦想吧！

  

一个“低危”能让一个孩子吃上香喷喷的米饭，一个“中危”能让一个孩子背上崭新的书包，一个“高危”能解决一个孩子一学期的生活费，一个“严重”能资助一个孩子顺利完成学业。在这个读书日，让我们帮助孩子有书可读，才是这个节日存在的重要意义。

**企业联合活动规则**

白帽子自愿参加企业联合教育公益活动。活动期间向参与企业联合教育公益活动（ZPSRC、PWSRC、MISRC、DSRC、71SRC、BKSRC、VKSRC、WSRC）的任意一家提交漏洞报告即视为报名参与。

  

**\***  活动期间，若白帽子满足向参与企业联合教育公益活动物资捐助的 SRC 提交有效**中危**漏洞报告达到**三家**及以上，白帽子将会收到所有提交有效中危漏洞的SRC准备的精美礼品一份，同时获得由完美世界工会联合会发放的捐赠公益证书。

（建议白帽子的 ID 在所有参与企业联合教育公益活动的 SRC 平台上保持一致，以便后续统计）

  

**\***  活动期间，写下对学生们的祝福和鼓励，分享到微信、微博、Twitter、Facebook 等渠道邀请更多国内外白帽朋友参与！截图发送至任意一家参与教育公益活动的企业 SRC 微信后台，活动结束将随机抽取白帽子获得礼品一份。

**03  活动奖励**

1、活动期间在 ZPSRC 提交有效**高危**漏洞，在享受漏洞积分翻**2倍**的同时，ZPSRC 将以提交有效高危漏洞白帽子的名义向学校捐赠1000元物资，并在活动结束后在公众号发文致谢。

  

2、活动期间在 ZPSRC 提交有效**中危**漏洞，在享受漏洞积分翻**1.5倍**的同时，ZPSRC将额外赠送ZPSRC定制T恤一件 。

  

3、活动期间在 ZPSRC 提交有效**低危**漏洞，ZPSRC 将送出ZPSRC定制笔记本一个。

  

4、凡在活动期间向ZPSRC提交有效漏洞的白帽子，ZPSRC 将在活动结束后在公众号致谢所有白帽捐赠者。

  

5、漏洞报告标题前请备注【企业联合公益活动】

陶行知先生曾说：“教育乃立国之本，强国之基”。本次企业联合教育公益活动，8家企业联合为满足屯学校送去最紧缺的物资。包括：（文具套装、彩笔套装、书包、跳绳、满语图书、羽毛球拍、足球、篮球等）。在克服运输等重重困难之后，我们希望通过大家的努力，能够为满足屯学校的孩子们带去一缕春日的温暖希望。
