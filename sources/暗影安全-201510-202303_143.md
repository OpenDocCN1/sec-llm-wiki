# 一键X卫星不是梦，中国空间站操作界面“天地交互”亮了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MzA3OTgxOA==&mid=2657160745&idx=1&sn=dbf8fe09fc0d8e602d80c57abb1523ff&chksm=f1d4fcccc6a375da9b4236aef48faf10c4af52d1d781d5dce7298ff0c54c00a1fec672371418&scene=126&sessionid=1681404820#rd](http://mp.weixin.qq.com/s?__biz=MzI2MzA3OTgxOA==&mid=2657160745&idx=1&sn=dbf8fe09fc0d8e602d80c57abb1523ff&chksm=f1d4fcccc6a375da9b4236aef48faf10c4af52d1d781d5dce7298ff0c54c00a1fec672371418&scene=126&sessionid=1681404820#rd)

6月17日，航天员聂海胜、刘伯明、汤洪波先后进入一键X卫星不是梦，中国空间站操作界面“天地交互”亮了核心舱，标志着中国人首次进入自己的空间站。  

我们也从央视新闻的报道中首次看见了空间站系统的操作界面。据介绍，需要航天员操作的界面均使用中文，例如机械臂状态的控制，以及报警消息查看等操作。考虑到这套系统的使用者是中国航天员，因此全部使用中文也不足为奇。

整体来看，空间站系统的操作界面非常“原生”，虽然跟现代 UI 相比美观度略有逊色，不过这种实用朴素的“工业风”倒也符合空间站系统的定位，毕竟保证界面直观、操作准确、系统稳定才是需要优先考虑的因素。

由于官方公开的消息有限，暂时未能了解到这套图形界面采用了哪款框架，当然也可能没有使用框架。唯一曾公开报道过的相关信息是中国航天有一套 SpaceOS 操作系统。

提到这些“上天”设备的操作界面，去年发射的 SpaceX 龙飞船 (Crew Dragon) 所使用的触摸屏控制台可谓令人印象深刻。
