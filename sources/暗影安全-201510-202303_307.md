# F-Scrack（服务弱密码检测脚本）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MzA3OTgxOA==&mid=2657159139&idx=1&sn=e47046fb90ef13bf77de5c3917006c4d&chksm=f1d4f506c6a37c1029d68e6e53eff088a73b960d6de02a88d17f152859db385369d6286e484f&scene=126&sessionid=1681404871#rd](http://mp.weixin.qq.com/s?__biz=MzI2MzA3OTgxOA==&mid=2657159139&idx=1&sn=e47046fb90ef13bf77de5c3917006c4d&chksm=f1d4f506c6a37c1029d68e6e53eff088a73b960d6de02a88d17f152859db385369d6286e484f&scene=126&sessionid=1681404871#rd)

1.  功能  
    齐全的python编写的轻量级弱口令检测脚本，目前支持以下服务：FTP，MYSQL，MSSQL，MONGODB，REDIS，TELNET，ELASTICSEARCH，POSTGRESQL。
    
2.  特点  
    命令行，单文件，绿色方便各种情况下的使用。  
    无需任何外库以及外部程序支持，所有协议均采用插座与内置库进行检测。  
    兼容OSX，LINUX，WINDOWS，Python的2.6+（更低版本请自行测试，理论上合理运行）。
    
3.  参数说明  
    python F-Scrack.py -h 192.168.1 \[-p 21,80,3306\] \[-m 50\] \[-t 10\]  
    \-h必须输入的参数，支持ip（192.168.1.1），ip段（ 192.168.1），ip范围指定（192.168.1.1-192.168.1.254），ip列表文件（ip.ini），最多限制一次可扫描65535个IP。  
    \-p指定要扫描端口列表，多个端口使用，隔开实例：1433,3306,5432。未指定即使用内置交替端口进行扫描（21,23,1433,3306,5432,6379,9200,11211,27017）  
    \-m指定线程数量默认100线程  
    \-t指定请求超时时间。  
    \-d指定密码字典。  
    \-n不进行存活探测（ICMP）直接进行扫描。
