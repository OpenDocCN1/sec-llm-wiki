# 从内存提取mysql密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MzA3OTgxOA==&mid=2657159120&idx=1&sn=d8934db3e7319417a0adf89e3342c7ea&chksm=f1d4f535c6a37c235c7fc9a2261ca2f38a7367ce71560601ffd31f76427f4d3b909b167a2e33&scene=126&sessionid=1681404876#rd](http://mp.weixin.qq.com/s?__biz=MzI2MzA3OTgxOA==&mid=2657159120&idx=1&sn=d8934db3e7319417a0adf89e3342c7ea&chksm=f1d4f535c6a37c235c7fc9a2261ca2f38a7367ce71560601ffd31f76427f4d3b909b167a2e33&scene=126&sessionid=1681404876#rd)

mysql客户端读取密码，将其写入一些已分配的内存，然后释放它；

主要目标是获得通过tty传递的密码，但有时它也获得从命令行（-pxxxxxx）传递的密码。

经过测试 mysql Ver 15.1 Distrib 10.3.13-MariaDB, for Linux (x86\_64) using readline 5.1
