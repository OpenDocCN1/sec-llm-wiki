    今天要为大家介绍的是Conpot

    Conpot是一款低交互式服务器端的工业控制系统蜜罐，其设计易于部署，修改和扩展。它具有易于定制和行为模拟等特点，并且可以通过真实的HMI进行扩展。在Honeynet项目下构建和维护。


使用Docker快速安装通过预构建的图像

安装Dockerdocker pull honeynet/conpotdocker run -it -p 80:80 -p 102:102 -p 502:502 -p 161:161/udp --network=bridge honeynet/conpot:latest /bin/shconpot -f --template defaulthttp://MY_IP_ADDRESS 确认设置。


从源代码构建docker镜像

安装Docker克隆此仓库 git clone https://github.com/mushorg/conpot.gitsudo make run-dockerhttp://MY_IP_ADDRESS确认设置。


从源代码构建并使用docker-compose运行

安装docker-composegit clone https://github.com/mushorg/conpot.gitcd conpot/dockerdocker-compose builddocker-compose up永久作为守护进程运行 docker-compose up -d
