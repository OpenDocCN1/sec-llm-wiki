trape是一种识别工具，可以让你跟踪任何人，你可以得到的信息非常详细。


通过去识别现有的网站所登录的用户，来追踪一个人的虚拟身份


已经支持的网站：

  • Facebook的

  • 推特

  • VK

  • 书签交易

  • Gmail的

  • tumblr

  • Instagram的

  • Github上

  • 到位桶

  • Dropbox的

  • Spotify的

  • 贝宝

  • 亚马逊

  • Foursquare（新）

  • Airbnb（新）

  • 黑客新闻（新）

  • 松弛（新）

使用方法：

如何使用它

首先卸载该工具。

git clone https://github.com/boxug/trape.gitcd trapepython trape.py -h

如果它不起作用，请尝试安装位于文件requirements.txt中的所有库 

pip install -r requirements.txt

执行的例子

Example: python trape.py --url http://example.com --port 8080
