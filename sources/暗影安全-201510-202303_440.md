## 项目简介

Bdtunnel是一个由C#写的安全隧道工具，并且支持多种协议，可以在不同的网络环境下使用，比如说绕过防火墙的限制,你只需要在防火墙外的一台机器部署上Bdtunnel Server，然后本机在链接上去就可以获得完整的网络访问权限，并且通讯是加密的，可以避免被监控。

支持的协议如下：  
– HTTP binary (性能好，兼容性好，代理兼容)  
– HTTP SOAP (最大兼容，代理兼容)  
– TCP binary (最大性能)  
– IPC (仅用于测试目的)

## 使用方法

下载了之后，首先配置服务端：

打开 bdt.bin-1.6\\Server\\BdtServerCfg.xml

> <service  
> name = “BdtServer”  
> protocol = “Bdt.Shared.Protocol.HttpBinaryRemoting”  
> port = “802” #首先修改这里的端口，将其改成你需要监听的端口  
> />

然后找到：

> <users>  
> <corbier＃这个是用户名  
> enabled = “false” ＃将这个该厂true，表示启用该用户，你可以自己添加一个  
> password = “123s” ＃这个是密码  
> admin = “false”  
> stimeout = “12”  
> ctimeout = “1”  
> />  
> <jacky  
> enabled = “false”  
> password = “touch”  
> admin = “false”  
> stimeout = “12”  
> ctimeout = “1”  
> />  
> </users>

配置完成后运行server即可。

然后是client的配置

他提供一个GUI的操作界面，如下，只要点击红色标志位置就可以配置了，配置很简单 只要输出对应的服务器ip，账号密码，端口即可，然后就在本地监控1080端口的socks5代理服务
