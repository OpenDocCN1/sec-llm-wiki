**项目简介：**

* * *

  

   HackaZon 是一个免费的渗透测试练习环境，他是由rapid7开发的，

也就是metasploit的所在的公司。

   由于应用包括基于REST的接口，AJAX功能和移动客户端（JSON，XML，GWT，AMF），用户需要的最新应用安全测试工具和技术来发现所有的漏洞

# 特征

*   REST Support - http://www.w3.org/2001/sw/wiki/REST
    
*   GWT Support - http://www.gwtproject.org
    
*   AJAX and Standard HTTP Requests are Supported
    

# 技术细节

*   PHP Version – 5.4
    
*   PHP Framework – http://phpixie.com/
    
*   JS – http://jquery.com/ & http://knockoutjs.com/
    
*   CSS – http://getbootstrap.com/
    
*   DB – MySQL 5.5 with InnoDB Support
    
*   Web Server – Apache 2.0

**安装：**

* * *

  

1.  下载代码
    
2.  将DOCUMENT\_ROOT设置成下载的程序中的 /web目录， 并且确认开启了REWRITE模块。
    
3.  复制 /assets/config/db.sample.php 到 /assets/config/db.php
    
4.  修改数据库信息 /assets/config/db.php
    
5.  打开 http://yoursitename/install
