# 社工利器—theHavrest

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MzA3OTgxOA==&mid=402297500&idx=1&sn=17fed5c74b18f54eb7bdd3a8317bff8c&chksm=784f60794f38e96f2a9c584c5d1261716eabf52de4da49a91603ab4c8d3a9e54bb90364e068f&scene=126&sessionid=1681404951#rd](http://mp.weixin.qq.com/s?__biz=MzI2MzA3OTgxOA==&mid=402297500&idx=1&sn=17fed5c74b18f54eb7bdd3a8317bff8c&chksm=784f60794f38e96f2a9c584c5d1261716eabf52de4da49a91603ab4c8d3a9e54bb90364e068f&scene=126&sessionid=1681404951#rd)

TheHavrest能通过搜索引擎自动化收集目标的相关email，子域名，主机ip，雇员信息，开放端口和banner信息，是社工安全检测的一把利器。

相比msf的auxiliary/gather/search\_email\_collector模块，这款工具效果更佳。

使用方法：  
./theharvester.py -d microsoft.com -l 500 -b google  
./theharvester.py -d microsoft.com -b pgp  
./theharvester.py -d microsoft -l 200 -b linkedin

当然你也可以./theharvester.py -d microsoft.com -l 500 -b all
