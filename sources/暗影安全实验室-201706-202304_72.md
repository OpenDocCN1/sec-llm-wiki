**导读：**闲暇之余拿起手机玩把游戏，不失为一个放松的好方式，今天我们来聊聊"王者荣耀"，作为手机端MOBA类游戏，则是不少人的首选，你打到什么段位了？上中下野辅，你爱玩哪路？最拿手的英雄是什么？拿到五杀的第一个英雄还记得是哪个吗？你是不是偷猪爱好者……青铜到黄金，大多是游戏萌新，多打钱发育就容易取得胜利；铂金段位，有了对游戏的初识，开始注重阵容搭配，帮帮队友也就OK了；钻石段位，鱼龙混杂，大神玩家都容易折戟于此，感慨不愧是“永恒钻石”，这个段位的玩家，是熟练掌握了几个英雄，又有了大杀四方的经历后，萌发出天大地大我最屌的热血暴躁小青年心态，不管队友抢位置，游戏里死了就心态崩溃的怨队友，不玩了挂机了送起来投降了下一把了，搅得我方鸡犬不宁。这时候突现一款“王者荣耀助手”，分分钟让你上王者，你是否心动？

近期暗影移动安全实验室监测到一批以"王者荣耀助手"为主题的家族病毒木马，研究员分析发现这类样本捆绑8款扣费SDK，私自监听并删除用户短信，并发送订购短信、锁屏勒索钱财、盗取QQ号等恶意行为。

5秒后大战即将开始:

  

![](../Images/69bd68ae53cde5e23e659ec9f362391c.png)**1. 基本概述**

通过研究员深入分析，发现这类样本总体分为两种类型：

Ø 第一种是典型的以捆绑多个恶意SDK和恶意子包，从C&C服务器获取SP订购号码，屏蔽用户手机的短信广告，在用户未知情的情况下，私自发送扣费短信，订购完成后删除指定短信内容；

Ø 第二种是通过锁屏、修改设备PIN码等方式，让用户设备无法正常使用，然后要求用户支付赎金解锁，同时盗取用户的QQ号码，详细流程图如图1所示：

    基本的流程图：

图1 基本流程图   

上述流程图可知，流程1捆绑了8款恶意支付SDK,通过集成SDK和恶意子包的方式后台实现恶意操作，流程2实现勒索、盗取QQ号码等，其恶意行为主要为：

（1）上传用户隐私信息到服务器；

（2）访问服务器获取SP号码和短信内容；

（3）发送服务器下发的短信内容到SP号码；

（4）监听手机短信，禁用短信广播，使用户接收不到短信提醒；

（5）对订购业务的二次确认短信进行自动回复；

（6）私自删除与程序恶意行为相关的短信等；

（7）锁屏勒索钱财；

（8）盗取QQ号码。

# 3. **总结**

该批打着“王者荣耀”旗号的恶意样本，针对的主要是企图通过获取辅助等内容去破坏游戏公平的人群。

“王者荣耀助手”类样本通过集成大量恶意SDK来执行恶意行为，行为逻辑简单高效且易于批量制作，一直被黑产团队所青睐。它们往往打着各类热门游戏的辅助工具、破解版等的旗号或者通过色情暗示等方式来招揽用户，在用户中招后马上执行恶意行为，让用户措手不及，造成用户资费损失。

而勒索类样本和隐私窃取样本，其制作成本更低，还打着“收徒”、“加QQ群”、“联系QQ”、“盗取QQ号”的旗号，针对的人群可能更低龄化，在“小而无畏”的低龄人群中更具有传播力。  

# 4. **安全建议**

（1）如果已被感染，应该尽快卸载软件，并向安全人员寻求建议。

（2）坚持去正规应用商店下载软件，避免从论坛、网站等下载软件，可以有效的减少该类病毒的侵害。

（3）安装安全软件，能有效的识别已知的病毒。

（4）关注”暗影实验室”公众号，获取最新移动安全动态。

（5）当发现感染手机病毒软件之后，可以向“12321网络不良与垃圾信息举报受理中心”或“中国反网络病毒联盟”进行举报，使病毒软件能够第一时间被查杀和拦截。
