# web渗透

扫描一下目录

```
gobuster.exe dir \-u http://192.168.1.4/site \-w directory-list-2.3-medium.txt  \-x php,asp,jsp,txt
```

![](../Images/037dacd318970f5fe1394f7e869fc1ac.png)

发现有个txt，打开后发现写了一个目录/war-is-over

![](../Images/104b8f9c6eb77c7e5493ed27fde03c7b.png)

访问该目录，发现有很多的字符串

![](../Images/64db7c82328b4deb35b1042d4a17dea7.png)

最后面有个等号，首先想到的是base64编码，因为字符串太多了，所以采用文本文档模式进行转换。

![](../Images/b6539182f99c4f76c1422683c8664e0e.png)

转换后发现最前面有个PK的字符，作为以前的CTFer，肯定发现他是一个zip压缩包格式，重命名改为.zip

![](../Images/df035de49388edfc4a5d3ce85a409878.png)

解压后发现需要密码，直接爆破一下。首先利用zip2john转换成hash值，然后把自带的字典给解压一下。

```
zip2john Result.zip > result
```

```
gunzip /usr/share/wordlists/rockyou.txt.gz
```

![](../Images/0af9db6a8a06c073594feb5fe65263c6.png)

```
john result \--wordlist\=/usr/share/wordlists/rockyou.txt
```

![](../Images/998b1c6da46ad2e16e3d026d9edbb6da.png)

爆破出密码为：ragnarok123

解压后发现是一个无格式的文件，010editor查看hex值，头文件是FF D8，是jpg格式的图片

![](../Images/e60760938a76f96ce7f99fa8fa24fd9f.png)

打开图片，没发现什么

![](../Images/be3ee7a4a562f5bb2e693c9dd51a57bb.png)

因为靶场提示了是CTF类型的，所以一般看到图片，想到的是会不会用隐写术。binwalk分析一波

![](../Images/de35a0e5ca45d67543f17ac6797f5c0c.png)

发现还有隐藏了zip，foremost分离一波

![](../Images/f40c1ed3d39196fce23837754e649d30.png)

```
#Printable chars are your ally.
```

![](../Images/8a7dbe74614d78667b9cd68946fd196d.png)

那么我们用python生成第29个素数

```
#!/usr/bin/env python3
\# -\*- coding:utf-8 -\*-

n\=0
for i in range(200):
    if i<2:
        continue
    for j in range(2,i):
        if i%j\==0:
            break
    else:
        n\=n+1
        print("第",n,"个",":",i)
```

# root 提权

当使用Ragnar用户登陆时，一登陆会自动sudo,可能有个自启动任务

![](../Images/fbc4c3571e25bd481a570bab7c58da26.png)

根目录下查找，发现一个.profile，cat一下

![](../Images/71baf0db7596f9c188ee350af58fe671.png)

看到了有个sudo的执行命令，这就是为什么一登陆就会进行sudo提权

```
sudo python3 /usr/local/bin/rpyc\_classic.py
```

通过查看这个py文件，知道这是一个rpyc远程调用的库，构造payload

```


import rpyc
```

```
python3 exp.py
```

执行完这个文件后，再次登陆后使用

```

sudo -s
```
