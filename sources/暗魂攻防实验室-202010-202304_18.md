# 0x02 web渗透

我们直接访问这个文件，可以直接下载

![](../Images/317e75c152dd0202e654a3085025316e.png)

一看这个就是CTF中的ook(Brainfuck)加密

![](../Images/dd77053c1216e3033ba45d8699d26269.png)

解出来是一段文字

```
您可以以来宾身份进入矩阵，密码为k1ll0rXX
注意：实际上，我忘记了最后两个字符，所以我将其替换为XX。请尝试您的运气，并找到正确的密码字符串。
```

直接就生成一个密码字典，可以用kali的crunch，我比较懒，直接用易优生成一个两位数的小写字母+数字的密码，并用修改功能把前面的字符串加上

![](../Images/eacf952252345377eae4e2fc6204f538.png)

就得到了这样的字典

![](../Images/c4a38f756a4fe1b1700e953bcfcb87a0.png)

然后使用guest爆破ssh

```
hydra \-l guset \-w 10 \-vV \-P /root/superdic1.txt \-t 16 \-f 10.x.x.x ssh
```

![](../Images/e6a5e34f732693108e6e96f0691961b5.png)

爆破出账号密码：guest|k1ll0r7n

  

# 0x03  权限提升

直接ssh登陆，登上去发现连个ls命令都没有,好像常用命令也用不了，受到了-rbash的限制

![](../Images/63d8215f32432a71926f5df6b744bef6.png)

慢慢尝试，发现vi命令可以使用，百度搜了一下，好像用vi也可以提权，百度可以搜rbash绕过

![](../Images/39fa161a47ad1c5d00d2ff5bec9cad17.png)

用vi提权后ls可以使用，但是su啥的也不行

![](../Images/25cd6c776ee273a94eed6072906497e9.png)

找了一篇提权文章，使用这个方法可以

```
http://t.zoukankan.com/zaqzzz-p-12075132.html
export PATH\=$PATH:/bin/
export PATH\=$PATH:/usr/bin
```

![](../Images/4e0e2aea95374311acb2186ef091b3b1.png)

密码就是上面爆破的密码，直接就切换到root了

![](../Images/5933f559c9a4e391d04826da82aa404e.png)
