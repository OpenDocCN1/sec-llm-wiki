# 0x10：杂项8

![](../Images/11c32cfb922a6b90d1ee743c6b6994d2.png)

下载附件，得到一张图片

![](../Images/29cead40ab210e6fadcc895ec2676e11.png)

 查了一些资料，得知此题与CRC校验有关，附上找到的代码

```
import zlib
import struct
filename = 'flag.png'
with open(filename, 'rb') as f:
    all\_b = f.read()
    data = bytearray(all\_b\[12:29\])
    n = 4095
    for w in range(n):
        width = bytearray(struct.pack('>i', w))
        for h in range(n):
            height = bytearray(struct.pack('>i', h))
            for x in range(4):
                data\[x+4\] = width\[x\]
                data\[x+8\] = height\[x\]
            crc32result = zlib.crc32(data)
            if crc32result == 0x91918666:
                print("宽为：", width, int.from\_bytes(width, byteorder\='big'))
                print("高为：", height, int.from\_bytes(height, byteorder\='big'))
```

 将这个py脚本与图片放在同一个路径下，在py3的环境中运行，得到宽和高。
