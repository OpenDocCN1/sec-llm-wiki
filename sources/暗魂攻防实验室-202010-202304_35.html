（其中Windows Server 2012的外网ip为192.168.24.174）

 

经端口探测，发现靶机开放7001端口（Weblogic）

 

利用CVE_2020_2551执行命令上线CS

发现该主机为双网卡


由于该主机为Windows Server 2012高版本，尝试修改注册表并强制锁屏，在虚拟机上模拟输入密码解锁操作可成功读取到明文密码

打开3389端口，尝试直接RDP远程连接

 远程连接失败后猜测是存在防火墙，查看防火墙策略

 

根据上图可以看到，防火墙仅允许7001端口入站，但同时又允许ICMP协议出站数据包太大

 

因此可以使用ICMP隧道

使用fscan扫描10.10.20.0/24网段

 

发现该网段10.10.20.7 Win7设备存在MS17_010漏洞

使用该DMZ区主机作为跳板机，开启一个socks4服务端口

 

在外网VPS使用pingtunnel开启server端

 

在该DMZ区主机使用pingtunnel开启client端，将7777 socks4端口进行转发(VPS:7777<->10.10.20.12:7777)

 

此时即可通过ICMP隧道搭建起来的socks4服务访问10.10.20.0/24网段

 

 


 


将cs的beacon对话转发至msf

 


通过该session利用ms17_010漏洞渗透Win7主机

 

这里由于不存在双向路由，使用bind_tcp主动连接内网主机

本次靶场渗透所踩的一些坑：

1、meterpreter通道无法上传>6M的文件，<6M的文件虽然会报超时，但是实际上是有完成上传上去的2、ew搭建的为socks5，cs beacon自带搭建的为socks4，版本错误是无法正常连接的3、在Win7主机与DMZ区主机间无法搭建frp（应该是防火墙的问题）4、DMZ区主机ping德通Win7主机，但Win7主机ping不通DMZ区主机，因为防火墙只允许ICMP出站5、在DMZ区主机上使用ew lcx_tran转发socks端口时失败（应该也是防火墙的问题）


虽然每一台主机该获取到的系统权限是都拿到了，但是对于期间所遇到的种种坑因个人水平底下及实战经验不足仍无法解答，望各位师傅慷慨解答，我定虚心请教学习！
