经端口探测，发现靶机开放7001端口（Weblogic）

![](../Images/d18559dbec87fed26a5c82b41186b3cc.png)

 

利用CVE\_2020\_2551执行命令上线CS

![](../Images/3884a89f89847253f04a5cf1eafab5c3.png)

发现该主机为双网卡

  

![](../Images/c5f9a1bf55fd381b7877d7387e5f10ce.png)

由于该主机为Windows Server 2012高版本，尝试修改注册表并强制锁屏，在虚拟机上模拟输入密码解锁操作可成功读取到明文密码

![](../Images/22f96fddc7a55b0e297b3578a4dc31de.png)

  

![](../Images/fba1dd341310615c7a531f9e22f3404e.png)

如上图，获取到了一个本地管理员账户

打开3389端口，尝试直接RDP远程连接

![](../Images/0ff564836eeb5df9a29ab6d56546288f.png)

 远程连接失败后猜测是存在防火墙，查看防火墙策略

![](../Images/a808365f1cd10593e68813fd56863c7c.png)

 

根据上图可以看到，防火墙仅允许7001端口入站，但同时又允许ICMP协议出站数据包太大

![](../Images/a7b97f7d11259e1e220ba1bde18c2e2a.png)

 

因此可以使用ICMP隧道

使用fscan扫描10.10.20.0/24网段

![](../Images/0ab89e13903dcb372682093d930d2dda.png)

 

发现该网段10.10.20.7 Win7设备存在MS17\_010漏洞

使用该DMZ区主机作为跳板机，开启一个socks4服务端口

![](../Images/85d3ffd623bc5743a7033cb6415d972f.png)

 

在外网VPS使用pingtunnel开启server端

![](../Images/efbfd1ad55e6cf08b12f14c5b4b94041.png)

 

在该DMZ区主机使用pingtunnel开启client端，将7777 socks4端口进行转发(VPS:7777<->10.10.20.12:7777)

![](../Images/793e0ca9cda8bdc9179f76e41c509d04.png)

 

此时即可通过ICMP隧道搭建起来的socks4服务访问10.10.20.0/24网段

![](../Images/f7b1ef9650a741392051a48c1726edb2.png)

 

![](../Images/19bd3ba6b66e561317037d440930f0a4.png)

 

  

 ![](../Images/2caf6bc6ca56d13622dda027170a96c8.png)

  

将cs的beacon对话转发至msf

![](../Images/f218f36044ea66949235e196bf3f0c39.png)

 ![](../Images/ec69797f7bbdf7947a416dc2da576def.png)

  

![](../Images/4196a6db5e3f88085eb3a14c986bf54c.png)

通过该session利用ms17\_010漏洞渗透Win7主机

![](../Images/c665e62b8e69fc5aa12100f968a5832b.png)

 

这里由于不存在双向路由，使用bind\_tcp主动连接内网主机

![](../Images/3806888e70f369d252694531532b4424.png)

本次靶场渗透所踩的一些坑：

*   
*   
*   
*   
*   

```
1、meterpreter通道无法上传>6M的文件，<6M的文件虽然会报超时，但是实际上是有完成上传上去的2、ew搭建的为socks5，cs beacon自带搭建的为socks4，版本错误是无法正常连接的3、在Win7主机与DMZ区主机间无法搭建frp（应该是防火墙的问题）4、DMZ区主机ping德通Win7主机，但Win7主机ping不通DMZ区主机，因为防火墙只允许ICMP出站5、在DMZ区主机上使用ew lcx_tran转发socks端口时失败（应该也是防火墙的问题）
```

  

虽然每一台主机该获取到的系统权限是都拿到了，但是对于期间所遇到的种种坑因个人水平底下及实战经验不足仍无法解答，望各位师傅慷慨解答，我定虚心请教学习！
