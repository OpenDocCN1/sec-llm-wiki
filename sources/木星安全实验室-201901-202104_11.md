# 可以实现隐蔽持久性的Outlook后门

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1Mzk4Mzc5MA==&mid=2247485735&idx=1&sn=f809a274bede0f799d2f263fb6a32a4d&chksm=fbebc366cc9c4a70e16665d53d1ecf7c6dab875f5928fbba07865acaa9e56a830709caa33dc1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1Mzk4Mzc5MA==&mid=2247485735&idx=1&sn=f809a274bede0f799d2f263fb6a32a4d&chksm=fbebc366cc9c4a70e16665d53d1ecf7c6dab875f5928fbba07865acaa9e56a830709caa33dc1&scene=27#wechat_redirect)

  

2019年，我一直在研究新的隐蔽持久性技术。这些技术（误）用目标计算机上的程序插件，激发了我的灵感。比较有趣的目标是浏览器，电子邮件客户端和发消息的app，因为它们通常在系统启动后启动。

  

浏览其他人的文章时，我发现@bohops写了一篇叫《VSTO：可能破坏应用程序白名单规则的有效载荷安装程序》（https://bohops.com/2018/01/31/vsto-the-payload-installer-that-probably-defeats-your-application-whitelisting-rules/）的文章。他展示了如何创建“恶意VSTO”，并将其安装到Office中。他的结论是，如果账户没有特权，vstoinstaller.exe会弹出窗口(“ClickOnce”)，请求用户许可：

  

![](../Images/2fbc774d26efad7505be0ac8ef8c7a88.png)

（@bohops的屏幕截图）

  

从攻击者的角度来看，绕过“ ClickOnce”弹出窗口非常有价值，因此我决定对vstoinstaller.exe安装VSTO加载项的方式进行更深入的研究。单击这个弹窗，启动Procmon，过滤vstoinstaller.exe进程。首先，查看HKCU的注册表项，这是安装的关键部分。

  

![](../Images/c5878d9441e88525ca0f4826b7b36e47.png)

  

![](../Images/b3e0953c75964fbfb25445e485042b58.png)

  

这些注册表项很有趣，且和VSTO的安装相关。我再次卸载插件，用vstoinstaller.exe /uninstall删除特定的注册表项。

  

![](../Images/25fce3483eaf3a0b74b11e333e32190f.png)

  

用常规方法再次安装VSTO会再次触发弹窗，所以我卸载了已经安装的VSTO。

  

![](../Images/3350f52c556ab2f18cbc7b59fcacf6dd.png)

  

接下来，我编写了一个PowerShell脚本，设置正确的注册表项和值，测试Outlook加载项是否将由Outlook加载，任何请求用户同意的窗口都不会弹出来。我认为绕过“ ClickOnce”弹窗的技术归根结底就是在HKCU:\\Software\\Microsoft\\VSTO\\Security\\Inclusion\\中添加用于签署VSTO的证书的公钥。

果然，它奏效了！加载项是Outlook在启动时安装和加载的，没有弹出窗口。

  

![](../Images/ece28e59e568774ca25283cd55d8db8f.png)

  

查看Sysinternals的AutoRun，可以看到VSTO加载项没有被检测到。

  

![](../Images/978d1980346597776c4b9218c7248491.png)

  

  

  

  

**MSRC**

  

  

我已经联系Microsoft安全响应中心，但是由于这并不违反安全规则，所以这个bug不被认为是漏洞，无法修复。

  

  

  

  

**检测**

  

  

检测这种持久性技术，要在以下路径上监视“ RegistryEvent值集”事件（Sysmon事件ID 13）：

  

*   
*   
*   
*   
*   

```
HKCU:\Software\Microsoft\Office\Outlook\Addins\HKCU:\Software\Microsoft\Office\Word\Addins\HKCU:\Software\Microsoft\Office\Excel\Addins\HKCU:\Software\Microsoft\Office\Powerpoint\Addins\HKCU:\Software\Microsoft\VSTO\Security\Inclusion\
```
