一、安全风险概要


1.     漏洞编号/名称

CVE-2020-1938 Apache Tomcat文件包含漏洞

2.     漏洞等级

高危

3.     影响版本

Apache Tomcat 6
Apache Tomcat 7 < 7.0.100
Apache Tomcat 8 < 8.5.51
Apache Tomcat 9 < 9.0.31

4.     漏洞背景

Apache Tomcat服务器AJP协议存在文件包含漏洞，攻击者可利用该漏洞读取或包含 Tomcat 上所有 webapp 目录下的任意文件，如：webapp 配置文件或源代码等。如果网站具有上传功能，可以通过上传含有恶意代码的文件并包含的方式来执行远程代码。
 
该漏洞的利用方法已经在网上公开。

三、修复方案

 
目前 Apache Tomcat 已发布9.0.31、8.5.51及7.0.100版本针对此漏洞进行修复：
https://tomcat.apache.org/download-70.cgi
https://tomcat.apache.org/download-80.cgi
https://tomcat.apache.org/download-90.cgi
Apache Tomcat 6 已经停止维护，建议升级版本来修复漏洞。
 
如果暂时无法升级Tomcat，可以通过关闭 AJP协议来作为临时的缓解措施。
 
打开 tomcat 根目录下的conf/server.xml 把下面的配置删除或者注释掉，重启 tomcat 生效：
<Connector port="8009" protocol="AJP/1.3" redirectPort="8443" />
 


 
如果无法升级，又需要使用AJP协议，可以通过配置secret来设置AJP协议的认证凭证，设置的secret必须是强密码，重启 tomcat 生效。
<Connector port="8009"protocol="AJP/1.3" redirectPort="8443"address="YOUR_TOMCAT_IP_ADDRESS" secret="YOUR_TOMCAT_AJP_SECRET"/>
