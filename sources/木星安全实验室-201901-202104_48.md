# 【安全风险通告】Windows CryptoAPI 欺骗漏洞(CVE-2020-0601)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1Mzk4Mzc5MA==&mid=2247484079&idx=2&sn=7fcb25bd4789c98dc536af2b74dd5758&chksm=fbebc8eecc9c41f893c6c79d7412a153d7de2600569e1fe4787e0f94495311bca7b327061921&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1Mzk4Mzc5MA==&mid=2247484079&idx=2&sn=7fcb25bd4789c98dc536af2b74dd5758&chksm=fbebc8eecc9c41f893c6c79d7412a153d7de2600569e1fe4787e0f94495311bca7b327061921&scene=27#wechat_redirect)

## **1. 漏洞编号/名称**

       CVE-2020-0601

## **2. 漏洞等级**

高危

## **3. 漏洞****描述**

        Windows CryptoAPI (Crypt32.dll) 验证椭圆曲线加密 (ECC) 证书的方式中存在欺骗漏洞。        攻击者可以通过使用欺骗性的代码签名证书对恶意可执行文件进行签名来利用此漏洞，从而使该文件看似来自受信任的合法来源。用户将无法知道该文件是恶意文件，因为数字签名看似来自受信任的提供程序。        成功的利用还可以使攻击者进行中间人攻击，并对有关用户与受影响软件的连接的机密信息进行解密。 

## **4. 影响版本**

Windows 10Windows Server 2016Windows Server 2019 

## **5. 修复建议**

        a. 使用Windows 自动更新功能将补丁更新到最新版本。        b. 到官网漏洞公告处下载Windows版本对应的补丁进行更新： https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2020-0601
