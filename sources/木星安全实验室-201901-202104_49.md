# 【安全风险通告】WebLogic远程代码执行漏洞（CVE-2020-2546、CVE-2020-2551）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1Mzk4Mzc5MA==&mid=2247484079&idx=1&sn=18c54094d07c7d15b4b84f25e34e37bf&chksm=fbebc8eecc9c41f89ff30b1c006094e5689a1d5be94a6484a72c98f85f2ac87bd4bffced9819&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1Mzk4Mzc5MA==&mid=2247484079&idx=1&sn=18c54094d07c7d15b4b84f25e34e37bf&chksm=fbebc8eecc9c41f89ff30b1c006094e5689a1d5be94a6484a72c98f85f2ac87bd4bffced9819&scene=27#wechat_redirect)

## **1. 漏洞编号/名称**

            CVE-2020-2546、CVE-2020-2551

## **2\. 漏洞等级**

     高危**3.  漏洞****描述**        WebLogic是Oracle开发的Java EE应用服务器。Oracle在2020年1月15日发布了1月份的安全补丁，修复了WebLogic的多个漏洞。其中的存在两个高危漏洞(CVE-2020-2546、CVE-2020-2551)。攻击者可利用 T3 协议和IIOP协议执行远程代码。 **      4. 影响版本**    CVE-2020-2546:    Oracle WebLogic Server 10.3.6.0.0    Oracle WebLogic Server 12.1.3.0.0     CVE-2020-2551:    Oracle WebLogic Server 10.3.6.0.0    Oracle WebLogic Server 12.1.3.0.0    Oracle WebLogic Server 12.2.1.3.0    Oracle WebLogic Server 12.2.1.4.0 

## **5. 修复建议**

     a.  Oracle官方已经发布安全补丁，部分版本的补丁需要到1月31号发布，请留意官网公告，到Oracle官网下载补丁进行升级，补丁需要使用授权账号登录下载：https://www.oracle.com/security-alerts/cpujan2020.html  
   b. 如果不能及时打上安全补丁，可以通过以下措施作为临时的解决方案：    CVE-2020-2546：如果业务未用到T3协议，可以通过禁用 T3 协议来防止漏洞利用：   1) 进入WebLogic控制台，点击域进行域配置。   2) 在base\_domain的配置页面中，进入“安全”选项卡页面，点击“筛选器”，进入连接筛选器配置。在连接筛选器中输入    weblogic.security.net.ConnectionFilterImpl    接着在连接筛选器规则中输入   127.0.0.1 \* \* allow t3 t3s允许访问的IP \* \* allow t3 t3s\* \* \* deny t3 t3s     ![](../Images/ab268862d0e425781efaaf859a5868a6.png)3) 重启WebLogic 服务器使更改生效。  
  
CVE-2020-2551：可通过关闭IIOP协议作为临时的解决方案。在WebLogic控制台中，选择“环境”->“服务器”-> ”AdminServer”->”协议”-> IIOP ，取消“启用IIOP”的勾选。并重启WebLogic，使配置生效。
