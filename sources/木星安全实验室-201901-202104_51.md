# 【安全风险提示】Citrix ADC和Citrix Gateway远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1Mzk4Mzc5MA==&mid=2247484069&idx=2&sn=a13160933cbb569e33f30109d09093e3&chksm=fbebc8e4cc9c41f2473054a911d02e56eaa7ff763d042b5bcff69f03814ae671780035b272aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1Mzk4Mzc5MA==&mid=2247484069&idx=2&sn=a13160933cbb569e33f30109d09093e3&chksm=fbebc8e4cc9c41f2473054a911d02e56eaa7ff763d042b5bcff69f03814ae671780035b272aa&scene=27#wechat_redirect)

**一、安全风险概要**  

  

## **1.    漏洞编号/名称**

CVE-2019-19781 CitrixADC和Citrix Gateway远程代码执行漏洞

## **2.     漏洞等级**

高危

## **3.    影响版本**

Citrix ADC和Citrix Gateway版本13.0所有受支持的版本Citrix ADC和NetScaler Gateway版本12.1所有受支持的版本Citrix ADC和NetScaler Gateway版本12.0所有受支持的版本Citrix ADC和NetScaler Gateway版本11.1所有受支持的版本CitrixNetScaler ADC和NetScaler Gateway版本10.5所有受支持的版本 

## **4.     漏洞背景**

Citrix ADC 是一款应用交付和负载均衡解决方案，无论您的 Web、传统和云原生应用托管于何处，均可提供高质量的用户体验。这款解决方案提供多种形式和部署选项，不会将您限制在单个云中。汇集功能许可允许在云部署之间移动功能。 Citrix Gateway 是一款客户托管解决方案，支持在内部和任何公共云中部署，如 AWS、Azure 或 GoogleCloud Platform。Citrix Gateway 能够为用户提供针对保障生产力所需的所有虚拟、SaaS 和 Web 应用程序的安全访问和单点登录。 Citrix ADC 和Citrix Gateway 存在一个远程代码执行漏洞，攻击者在未授权访问的状态下可执行任意代码。 该漏洞的利用方法已经在网上公开。 

# **二、复现过程**

  

访问如下地址，如果出现下图的情况，则存在漏洞/vpn/../vpns/cfg/smb.conf 

![](../Images/4566d6957af258ffd0cf40527c0c8e19.png)

通过利用该漏洞，可以上传恶意的文件，造成远程代码执行。 

![](../Images/09553192fd936267e894c9b93f0c2d83.png)

2\. 作为临时的修复方案，可以设置访问控制，拒绝对以下URL的访问： /vpn/../vpns/\*
