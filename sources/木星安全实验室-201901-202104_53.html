一、预警概要


1.    漏洞编号

CVE-2019-11043

2.    漏洞等级

严重

3.    漏洞背景

  2019年9月14号至16号，在长亭举办的Real World CTF比赛中，来自Wallarm的安全研究员在向服务器发送%0a（换行符）时，发现服务器返回异常信息，疑似存在漏洞，当Nginx使用特定的fastcgi配置时，存在远程代码执行漏洞，但是该配置并非Nginx的默认配置，当fastcgi_split_path_info字段被配置成^(.+?\.php)(/.*)时，攻击者可以构造payload，进而造成远程代码执行漏洞，且经过发现，该配置已经被广泛使用，危害较大。
 

4.    漏洞影响范围


当Nginx+php-fpm的服务器有如下配置时，就有可能造成远程代码执行漏洞
 
location ~ [^/]\.php(/|$) {
  ...
  fastcgi_split_path_info^(.+?\.php)(/.*)$;
  fastcgi_param PATH_INFO       $fastcgi_path_info;
  fastcgi_pass   php:9000;
  ...
}

三、修复方案

结合现实情况，在不影响业务的情况下，在Ngin找到存在漏洞的配置文件并删除：
fastcgi_split_path_info ^(.+?\.php)(/.*)$;
fastcgi_param PATH_INFO $fastcgi_path_info;
