【漏洞预警】WebLogic反序列化漏洞（CVE-2019-2890）

0x01 漏洞编号
        CVE-2019-2890

0x02 漏洞等级
         严重

0x03 漏洞描述
         WebLogic是Oracle开发的Java EE应用服务器。Oracle 在 2019年10月15日发布了10月份的安全补丁，修复了CVE-2019-2890漏洞。攻击者可利用 T3 协议的反序列化漏洞执行远程代码。该漏洞攻击复杂度低，无需用户交互，漏洞等级为严重。


0x04 漏洞影响范围   
WebLogic Server 10.3.6.0
WebLogic Server 12.1.3.0
WebLogic Server 12.2.1.3


0x05 修复建议
1.  Oracle官方已经发布安全补丁，可到Oracle官网下载补丁进行升级：
https://www.oracle.com/technetwork/security-advisory/cpuoct2019-5072832.html

2.  如果不能及时打上安全补丁，可以通过禁用 T3 协议来防止漏洞利用：
    a) 进入WebLogic控制台，点击域进行域配置。
    b) 在base_domain的配置页面中，进入“安全”选项卡页面，点击“筛选器”，进入连接筛选器配置。
    在连接筛选器中输入
    weblogic.security.net.ConnectionFilterImpl
    接着在连接筛选器规则中输入
   127.0.0.1 * * allow t3 t3s,0.0.0.0/0 * * deny t3 t3s 
    c) 重启 WebLogic 服务器使更改生效。
