0x01 漏洞编号

CVE-2019-0708

0x02 漏洞等级

严重

0x03 漏洞描述

微软5月14号发布了针对远程桌面服务的远程代码执行漏洞CVE-2019-0708的补丁，该漏洞影响了某些旧版本的Windows。远程桌面协议（RDP）本身不容易受到攻击。此漏洞是利用预身份验证，无需用户交互。这意味着未来利用此漏洞的任何恶意软件都可能像2017年的WannaCry恶意软件一样在易受攻击的计算机间传播。

易受攻击的系统包括Windows7，Windows Server 2008 R2和WindowsServer 2008。可以在Microsoft安全更新指南中找到相应补丁下载  。使用支持版本的Windows并启用自动更新的计算机将自动受到保护。 

不支持的系统包括Windows2003和Windows XP。如果您使用的是不支持的版本，可以在KB4500705中为这些不支持的Windows版本打补丁。 

Windows 8和Windows 10不受此漏洞的影响。

通过启用网络级别身份验证（NLA）可以作为临时的防护措施 ，因为NLA在触发漏洞之前需要进行身份验证。但是，如果攻击者具有可用于成功进行身份验证的有效凭据，则受影响的系统仍然容易受到远程执行代码执行（RCE）的攻击。 

出于这些原因，强烈建议所有受影响的系统无论是否启用NLA都应尽快更新补丁。  

 

0x04 漏洞影响范围

Windows XP, Windows Server 2003, Windows 7, Windows Server 2008 R2和Windows Server 2008


0x05 修复方案

Windows XP,Windows Server 2003 漏洞公告及补丁下载地址：

https://support.microsoft.com/zh-cn/help/4500705/customer-guidance-for-cve-2019-0708


Windows 7, Windows Server 2008 R2和WindowsServer 2008漏洞公告及补丁下载地址：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0708


如果未能及时打补丁，建议暂时关闭远程桌面服务。

 

打补丁操作步骤：

下面以Windows7 x64的系统打补丁为例：

在桌面点击左下角的win图标，输入cmd, 点击运行

       

在cmd 输入systeminfo命令查看操作系统和补丁信息

可以看到系统为Windows7x64

接着打开安全补丁下载地址

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0708

 

根据操作系统版本下载相应的4499175补丁，如果是其它系统，则下载其它系统相应的补丁

下载完后双击运行补丁：

安装完后重启，再次通过cmd 运行systeminfo，查看KB4499175补丁是否安装成功：
