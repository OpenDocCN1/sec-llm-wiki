一

**案件概述**

  

法国国家信息自由委员会（CNIL）在2018年至2019年期间收到了有关法国年金协会（以下简称“SNAF”）16起投诉，即在要求删除和更正个人数据时遇到了困难。

  

经在线检查和听证会调查，CNIL发现SNAF侵犯了数据主体权利，违反数据更正请求和删除请求的义务。因SNAF侵犯数据主体要求更正、删除权利以及不与CNIL合作的行为（如未在指定期内做出整改），CNIL对其处以3000欧元的罚款。

  

二

**违规行为**

  

| 

**•** 违反遵守数据更正请求的义务（GDPR第16条），SNAF未在正式通知规定的时限内完全回应其收到的更正请求。然而，SNAF在诉讼期间作了更正。

 |
| --- |
| **•** 违反遵守数据删除请求的义务（GDPR 第 17 条），SNAF未删除所有提出请求的投诉人的数据。 |
| **•** 违反实施处理活动登记册的义务（GDPR第30条），而SNAF的主要活动是处理个人数据。 |
| 

**•** 违反与CNIL合作的义务（GDPR第31条），经屡次提醒，未在指定期限内做出整改。

 |

  

三

**处罚决定**

  

根据GDPR第83条第1款和第2款的相关标准，GDPR第16、17、30和31条所构成的违规行为，考虑到SNAF的规模和财务状况，处以3000欧元的罚款似乎是有效的、成比例的和劝诫性的。
