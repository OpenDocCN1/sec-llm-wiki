# 域外执法 | 丹麦：因数据安全问题对律师事务所处以50万欧元罚款

**一**

**案件概述**

  

丹麦数据保护机构Datatilsynet建议对丹麦律师事务所SIRIUS处以 50万欧元的罚款，原因是律所对于其所掌握的客户数据等信息缺乏安全保护措施。该罚款源于2020年3月的一次数据泄露事件，黑客获得了该律师事务所服务器的访问权限并对其进行了加密。调查显示，当黑客入侵时，SIRIUS正在对其服务器实施多因素身份验证（multifactor authentication，MFT）。

  

**二**

**案件事实**

  

**2020年3月，SIRIUS的律师在遭受黑客攻击后向挪威数据保护局报告了个人数据安全漏洞。在这次攻击中，黑客获得了该律师事务所服务器的访问权限并对其进行了加密，其中包含有关该公司客户和交易对手的信息。这造成了有关人员的信息落入未经授权的手中的严重风险，从而可能对相关人员造成损害。**

  

数据保护局的Betty Husted说：“律师事务所会处理大量需要特殊保护的信息。在这种情况下，SIRIUS 的律师缺乏基本的安全措施，导致客户信息被泄露。虽然人们无法100%确保自己免受黑客攻击，但GDPR中的有关规则要求数据控制者努力避免风险的发生。”

  

在具有大量具有特别保护性质的个人数据的系统中，如果妥协会给数据主体的权利带来高风险，**数据控制者必须采取特别合格的安全措施，以确保不会发生对个人数据的未经授权的访问。**因此，当使用者创建对此类 IT系统的远程访问时，必须已实施验证措施，例如多因素登录。

  

丹麦数据保护局始终根据**GDPR第83条对案件的严重性进行具体评估。**

  

在评估是否应处以罚款时，丹麦数据保护局强调，SIRIUS 的律师在使用远程访问系统时没有实施预期的最低限度的安全措施，如果受到损害，数据主体的安全将面临高风险。

  

丹麦数据保护局在关于罚款数额的提案中，特别强调了侵权行为的性质和严重性，以及法规的要求，**即每个案件的罚款必须有效、与侵权行为相称，并具有起到威慑作用。**

  

此外，SIRIUS的律师在违规发生时正在实施多因素身份验证解决方案。同时，丹麦数据保护局强调，SIRIUS 的律师在案件披露方面表现得非常合作。

  

最终，SIRIUS 的律师因在使用具有特别保护性质的个人数据设置远程访问公司 IT 系统时未实施基本安全措施而被罚款50万欧元。
