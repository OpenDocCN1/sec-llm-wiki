# 《金融机构外部数据管理实践白皮书》开放征集参与单位

数据时代，越来越多的行业走向数字化创新转型之路，金融业作为数据产生与汇聚的富矿，在数字化转型中一马当先。银监会2018年发布的《银行业金融机构数据治理指引（征求意见稿）》中指出“数据已经成为银行的重要资产和核心竞争力，高质量数据是提升银行经营管理效率、提升监管效能的重要基础”。促进数据与金融行业的融合，释放金融创新活力和应用潜能已成为未来发展的趋势。在数据流通监管态势和企业合规意识不断提升的内外作用下，金融机构外部数据管理的重要性愈加凸显。  

  

然而，现阶段围绕外部数据管理，各类机构仍然面临数据准确性低、利用成本高，合规疑虑多等痛点。为全面了解金融机构在外部数据引入前、引入中、引入后各环节的现状，梳理链路条上整体存在的管理风险和问题，中国信息通信研究院云计算与大数据研究所联合建设银行、工商银行、邮政储蓄银行、交通银行、浦发银行等多家金融机构启动编写《金融机构外部数据管理实践白皮书》。

  

白皮书将聚焦各机构的外部数据管理实践经验，梳理外部数据的全生命周期管理中的要点，探索可落地实现的最佳解决方案，为金融机构引入外部数据提供管理及技术层的决策参考指导。
