# 活动|one bug one tree，共建互联网安全防护林！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNTA5MzI3Mg==&mid=2650592066&idx=1&sn=e18085b706ae8b8a1bfb0645c0efab19&chksm=f0e41f35c7939623b67200cd4b7b1f3c9c5095e4651be8f22cc0bcc7dbe824e7c7ecbc3f10a0&scene=126&sessionid=1681379183#rd](http://mp.weixin.qq.com/s?__biz=MzIzNTA5MzI3Mg==&mid=2650592066&idx=1&sn=e18085b706ae8b8a1bfb0645c0efab19&chksm=f0e41f35c7939623b67200cd4b7b1f3c9c5095e4651be8f22cc0bcc7dbe824e7c7ecbc3f10a0&scene=126&sessionid=1681379183#rd)

活动背景：为了肯定安全极客对于互联网安全保护的贡献，饿了么SRC计划从即日起，加入由蚂蚁金服发起的、面向安全圈开放的合作项目“**互联网安全防护林**”计划。

  

one bug（漏洞/情报）= one tree 

将无形的“网络安全保障”

等价于有形的“现实环境保护”

  

十九大以来，国家持续倡导“公益扶贫”和“环保扶贫”的发展主题，“互联网安全防护林”项目的推出，将通过植树造林等环境保护措施，改善地区恶劣的生产生活条件，推动当地经济发展，具有重要的民生价值和社会意义。

在网络安全的这条路上，任何人都可能成为受害者，网络安全带来的威胁就如同现实环境中的土地沙化一般，只有全民共进才能形成巨大的保护力量。

**参与“互联网安全防护林”，为你的网络安全保卫行动，赋予更大的社会价值！**

  

![](../Images/54a5ccf498b5daca728147b76bc548ed.png)

通过饿了么SRC，参与“种树”！

  

**\- 活动详情 -**

  

1、即日起，在ESRC平台提交**中危及以上级别**安全漏洞或安全情报，确认有效后，我们将以提交者的名义，捐赠一棵树（包含1棵灌木、2平方草方格及10年的精心养护），并发放电子版“捐赠证书”；

2、单人可累计，但“捐赠证书”不再重复发；

3、本活动暂限200棵，送完即止；

4、如有疑问，可与小编联系。
