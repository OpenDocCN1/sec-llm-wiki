1  姿势0x0：屌丝抓包篇

  

屌丝买不起真机, 只好用模拟器抓包, 其中心酸谁人知, 当然android模拟器很多, 古董级速度的avd, 速度飞快的genymotion, 还有游戏模拟器靠谱助手, droid4x等等, 选择一款自己喜欢的就好

我这里选了一款游戏模拟器droid4x(海马玩), 主要是可以支持大部分android app, 据说新版本广告好多, 不过老版本可以拼接地址去下载, 下面开始摆出我们的姿势

其中我们可以看到当前模拟器的ip是10.0.3.15

模拟器默认的网关是10.0.3.3  (可以安装busybox或者shell工具去看)

所以内部代理我们设置proxy  10.0.3.3    port  8080

  

然后在PC机器上我们设置我们的抓包工具

![](../Images/fc89f23208cd146846206d7874d019f8.png)  

  

除此之外, droid4x模拟器还做了很多端口转发规则, 其中我们比较关心的是adb的转发规则

2

**抓取https的包**

如上配置之后便可以抓http的包了,但是还不能抓https的包

设置好burpsuite代理后,使用浏览器访问指定端口,将证书文件下载下来 

![](../Images/2c96eac6d11484a9e04dd74fc9fd9e9c.png)  

右键->安装证书(这样在windows下就可以抓https的包了)

将证书导出

使用IE浏览器->Internet选项->内容->证书->导出

我这里导出的是cer格式的(android系统上必须是这个格式)

![](../Images/b8a9d6fed1460a5df438e07df1dd8694.png)  

●通过adb把证书push到sdcard

adb push D:\\xxx.cer /mnt/sdcard

●在手机中选择

设置->安全->从sdcard中安装证书

然后在按照上面的设置好代理就可以抓取https的包了

2姿势0x1: 手工测试篇

抓来的包, 要做一些简单的手工测试, 比如sql xss 越权 爆破….等等

Sql xss的点后面我们讨论, 这里谈谈爆破和越权

**● ****越权检测**

一些新业务上线后, 往往可能会存在越权的点, 基本思路就是改一些id, 然后在自己的token下居然还能访问其他的用户的id的数据, 这样一个越权的点就产生了, 这样就可以通过越权的点写一个脚本, 把所有其他用户的受保护数据批量爬取下来。

在burpsuite中我们可以把感兴趣的包, 在repeater中单独测试, 然后修改某些值, 看看服务器是否会返回正常的包。

  
![](../Images/22e70b62a093a482bbe90144d19ced35.png)  

**●验证码爆破**

有的时候,我们会对某些密码相关的值比较感兴趣, 比如手机验证码

下面我们演示如何用任意手机号注册某app(当然修改密码也是这样的)

  

![](../Images/dfd8091442365411810e785dc7ced945.png "7.png")

①. 注册填好相关信息, 点击获取验证码  

  

  

![](../Images/1c0687f6030ee6483f1ea4c6b9253f84.png "8.png")

②. 将抓到的注册的包添加发送到Intruder 并把注册码勾选为fuzz变量。

  

  

![](../Images/b36554b23b7b2b355908ae257beb5cb0.png "9.png")

③. 设置好payload字典。  

这种验证码可以自己写脚本生成一个字典文件, 比如某个区段的值放在前面

  

  

![](../Images/fa75771d05ec9f6e015bff0829f663ee.png "10.png")

④. 开始攻击  

Intruder-> Start attack

  

  

然后就开始跑,当一个长度值明显不一样的时候,可能就是跑出验证码了, 当然服务器对次数做了限制, 可能就没法暴力破解了。

  

![](../Images/2a225911447073a66f788c6e105c0646.png)  

  

一般来说:

6位以及以上的验证码难以暴力破解

4位的验证码容易被暴力破解

暴力破解生成字典 我们可以采用一个区段 减少破解时间

3姿势0x2 自动化测试篇

**sql****注入检测**

我们可以用burpsuite+sqlmap来进行初筛, 然后在去手工验证。

在burpsuite中我们可以直接设置导出的log。

![](../Images/13b10945126565e66efb9a39d3331e0c.png)  

sqlmap批量扫描

    python sqlmap.py -l 文件名 --batch -smart

    batch：自动选yes。

smart：启发式快速判断，节约时间

![](../Images/fe00c3b2d3b89969797d437a10bbc908.png)  

  

![](../Images/d5e3a61a2d62b869e7d190f139e1a1a8.png "14.png")

  

扫描的结果保存在

  

  

注入的信息保存在对应的文件夹下的log文件,payload信息如下,然后在去手工验证

![](../Images/69abf42c981e2491455abf5d798b7e1f.png)  

  

当然, 最好的方式还是写成自动化的, 解放生产力, 比如代理端把抓取的包存入数据库, 后端用脚本去检测sql xss 越权等不安全的点进行自动化检测, 将可能存在的安全威胁点存入数据库, 然后相关安全人员再去验证相关的点是否存在
