# 哗啦啦安全团队招聘

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4NTc0MjAwMg==&mid=2247484094&idx=1&sn=76f076f103d83a36d979606862364b8e&chksm=cfa50263f8d28b75e7071c1d7527643ce0c82ee5c732c0b0854cea64bf43b09b6c83ebf352b5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg4NTc0MjAwMg==&mid=2247484094&idx=1&sn=76f076f103d83a36d979606862364b8e&chksm=cfa50263f8d28b75e7071c1d7527643ce0c82ee5c732c0b0854cea64bf43b09b6c83ebf352b5&scene=27#wechat_redirect)

    代友发布招聘帖，**哗啦啦安全团队**招聘安全工程师，详情如下：

    **岗位1：渗透测试工程师  
    岗位职责**  
    1）漏洞的发掘，授权下进行深度的安全测试；  
    2）参与安全产品开发提供渗透攻防思路；  
    3）跟踪国内外安全动态，对安全事件中的漏洞进行分析、研究、挖掘，并进行预警提供应急响应和调查取证服务；  
    **岗位要求**  
    1）3年以上渗透测试经验，具备独立开展渗透工作的能力；  
    2）熟悉渗透测试步骤、方法、流程，具备独立开展渗透工作的能力；  
    3）熟练掌握WEB安全和漏洞挖掘，熟悉漏洞的原理、方法、利用手段及解决方案；  
    4）熟悉代码安全审计（PHP/ASP/JSP/Python）的流程、方法及主流代码审计工具的使用，并挖掘常见漏洞；  
    5）至少掌握Python/Ruby/Perl/PHP/等两门脚本语言；  
    6）在t00ls、WooYun、Freebuf、Seebug、exploit-db.com等网站发布过漏洞。

    **岗位2：安全合规工程师  
    岗位职责**  
    1）负责安全法律法规解读，对安全行业的法律法规有较强敏感性，并从甲方安全视角给出合规解决方案；  
    2）负责个人信息安全合规与数据安全合规整体规划与落地；  
    3）根据合规要求识别合规风险，跟踪各项合规要求的落实情况，对于未符合项督促推动整改；  
    4）负责各类安全审核工作；  
    **岗位要求**  
    1）具备甲方安全公司工作经验者优先考虑；  
    2）对主流安全技术和产品或行业安全标准等有十分深入了解；  
    3）沟通能力强，具有较强的组织能力、推动能力，富有团队协作精神；  
    4）组织和配合项目、法务、合规等部门，统一信息，对齐需求，明确影响；  
    5）调动相关团队实现上述解决方案的落地；  
    6）确保信息充分同步，风险得到有效控制，降低产品安全风险。

    **岗位3：数据安全工程师  
    岗位职责**  
    1）依据数据安全法律法规及国内外标准，建立公司数据安全治理体系；  
    2）推动数据安全专项治理工作（数据资产管理、数据加密、数据脱敏、API治理、隐私管理等）；  
    3）深入公司业务，对数据进行盘点和分类分级，制定数据分类分级管理规范；  
    4）制定数据安全生命周期管理策略，包括数据的采集、传输、存储、使用及销毁等；  
    5）结合公司业务情况，识别数据使用场景，评估数据安全风险，并结合行业最佳实践，给出可行的解决方案；  
    6）负责推动数据安全落地工作，梳理数据安全需求，并引入数据安全管理相关工具。  
    **岗位要求**  
    1）3年以上信息安全领域工作经验；  
    2）熟悉数据安全相关法律法规，了解数据安全国内外动态，对《网络安全法》《数据安全法》《个人信息保护法》有一定理解；  
    3）熟悉数据安全管理体系相关标准，深入理解DSMM数据安全成熟度模型；  
    4）具备基础安全能力，熟悉等级保护、ISO27001等标准，熟悉ISO27701及GDPR者优先；  
    5）熟悉数据安全风险评估、数据保护技术、数据生命周期管理标准及规范；  
    6）了解数据安全相关产品和解决方案，熟悉加密、脱敏等数据安全相关技术优先；  
    7）具备良好的服务精神及团队合作能力，工作积极主动，乐于分享，有责任心，具有优秀的沟通能力；  
    8）具有互联网行业数据安全实践经验者优先；  
    9）具有数据跨境方案经验者优先。

    **岗位4：工程效能工程师  
    岗位职责**  
    1）负责公司DevSecOps安全工具链相关开发工作；  
    2）负责公司安全工具、平台等开发工作；  
    3）负责ELK等日志安全策略分析工作；  
    4）关注业界DevSecOps最新安全动态、新安全技术及发展趋势。  
    **岗位要求**  
    1）具备较强的编码能力，有安全开发工具研发经验；  
    2）精通应用安全相关理念，有SDL、SDLC、DevSecOps相关工作经验；  
    3）熟悉威胁建模、风险评估、代码审查等；  
    4）熟悉常用应用安全测试工具的原理，如：SAST、DAST、IAST、RASP、SCA等；  
    5）熟悉安全模型、架构、主流安全技术和产品，知识面广泛；  
    6）熟悉主流信息安全相关标准，如NIST SP 800系列、ISO27001、COBIT等；  
    7）熟悉各种安全攻防技术以及安全漏洞原理，了解如何对WEB等相关攻击进行检测和防御；  
    8）熟悉DevOps流程，熟悉流行的CI/CD工具链；  
    9）具备良好的服务精神及团队合作能力，工作积极主动，乐于分享，有责任心，具有优秀的沟通能力。

    **岗位5：安全治理工程师  
    岗位职责**  
    1）负责办公网安全域规划、IT 安全基础设施和系统的建设和运维；  
    2）负责 IT 网络与系统建设的安全审批、风险评估、安全产品选型，并提出安全加固方案，推动安全方案落地；  
    3）负责办公网交换机、防火墙、无线等网络系统的维护及管理；  
    4）负责AD、上网行为管理，终端准入、防病毒、零信任网关、终端安全等产品的维护及策略优化；  
    5）负责信息安全防泄密工作；  
    6）负责办公网受勒索、挖矿病毒攻击等安全事件应急响应  
    **岗位要求**  
    1）3年以上互联网公司安全经验；  
    2）熟悉终端准入、EDR、DLP、IDS、沙箱、杀毒、行为管理、邮件安全等产品的使用、部署、运营；  
    3）熟悉安全事件应急响应流程；  
    4）熟悉 windows 安全、mac 安全、网络安全、邮件和 DNS 等 IT 基础设施安全工作；  
    5）熟悉 Shell/Python/Golang 等其中一种语言优先；  
    6）熟悉内网渗透技术优先。

以上工作地点北京西直门凯德MALL，投递简历/问题咨询： **lixueqing@hualala.com**  

**团队介绍**  

“哗啦啦”是服务于连锁餐饮企业的一站式闭环解决方案提供商品牌，已签约餐饮商户超40万，所服务客户年交易总额超5000亿人民币，占中国餐饮行业交易总额的10%。安全部门主要负责公司整体风险管理。

团队负责人李学庆也是行业资深老人了，曾在京东、摩拜、特斯联从事安全工作，百度词条有收录，号称“京东安全第一人”，经验丰富。
