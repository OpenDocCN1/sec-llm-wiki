墨迹天气早在数月前就开始为其全新硬件产品的发布制造声势，终于在昨天，这一产品揭开了神秘面纱。它叫「空气果」，能够检测室内的温度、湿度、二氧化碳和 PM2.5 含量，并在数值超标时发出警报。  

  

**产品介绍**

  

空气果的工业设计相当出色，外观看起来很像 Google 此前试图推出的音乐播放器 Nexus Q，为一体成型的铝合金外壳和亚克力白色面板。除了一枚实体开关外，空气果的日常操控不需要进行任何直接触碰。只需用手在屏幕上方拂过，即可在温度、湿度等数值之间进行切换。

  

空气果的屏幕会在空气状况不佳时点亮报警，并配有不同颜色的呼吸灯来表明污染程度。再加上其 400 多克的重量和单手可持握的体积，空气果能够很好地融入日常的家庭和工作环境。

  

![](../Images/870e013b171e7ef585f95d75d5d9c556.png)

  

当然，来自手机端的支持也是必不可少的。用户可以通过墨迹天气 App 与空气果进行连接，从而实时接收环境质量预警，了解到自己家人和朋友所处的空气情况。

  

**又一个气象局？**

  

如果墨迹天气仅仅只是推出这样一款空气检测器的话，很难让人对其抱有更多信息。空气果还有室外版，能够采集户外的空气数据。它在与室内版进行无线连接后将数据传到云端，这样空气果室外版就像是一个个小型的空气监测站。

  

墨迹天气的设想是，当空气果足够密集的时候，就能够形成相对准确的空气数据。当墨迹天气成为权威的空气数据发布方时，其未来的发展空间是很大的。

  

![](../Images/3ffce6e80aa03bd7247d5887833025b4.png)

  

然而事情可能并没有想象的那么简单：首先，虽然墨迹是移动端的老牌天气 App，但气象监测是综合多个学科的专业作业，我们并不知道空气果这样的硬件产品提供的数据是否足够准确，能否当作企业或组织取信的依据还值得商榷；

  

其次，墨迹天气等于是在国家现有气象系统之外再建一个新的民间系统，其数据采集过程不是官方的「PGC」，而是众多用户参与的「UGC」，当两种数据发生冲突时应当以何为准？（就像 PM2.5 的美使馆和环保局数据总是不一）

  

**成本会是最大短板？**

  

当墨迹天气 CEO 金犁在发布会上报出它 999 元的售价时，八九百人的会场瞬间安静了一会。根据金犁的解释，空气果机身是和 Macbook Pro 一样的 CNC 铝合金材质，内置工业级传感芯片，这个价格其实等于成本价。但是对于普通家庭用户来说，以几乎千元的价格买一个室内空气检测器并不是一件容易的事。

  

前不久由 TCL 和 360 联合发布的可联网空气净化器售价才 1000多元。如果不能迅速投入规模化生产以降低单品成本和售价的话，空气果的市场情况难以让人保持乐观。

  

**想成为智能家居总控台？**

  

其实相比空气果室外版形成的气象系统，我更关注金犁提到的 API 开放。通过用户授权，空气果可以与空调、空气净化器、加湿器等家电实现数据共享。目前墨迹天气已经与美的、澳柯玛、芬妮、Dream Maker 等厂商达成合作。

  

根据官方数据，墨迹天气已有 2.7 亿用户，日活跃用户达到 4500 万。在我看来，空气果开放 API 只是第一步，它未来可能要成为的是智能家居的控制中心。只要与空气果连接，用户就能同样通过墨迹天气 App 来遥控各个家电，以及获取相关通知。而墨迹天气亦可通过其移动端向用户推荐合作厂商的产品。相比成本更高、耗时更长的室外气象站建设，智能家居领域或许会是墨迹天气真正实现软硬结合的突破口。
