# 微信“搞大”了？听听高冷 PM 如何吐槽

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200304648&idx=2&sn=e53a7ce3b52cbef65779b2f32b59961e&chksm=eb8515bedcf29ca8e3c019dc2f1bba8f7f7d9af6af447b34a3da39c481c34b435220a5ac068d&scene=126&sessionid=1681313826#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200304648&idx=2&sn=e53a7ce3b52cbef65779b2f32b59961e&chksm=eb8515bedcf29ca8e3c019dc2f1bba8f7f7d9af6af447b34a3da39c481c34b435220a5ac068d&scene=126&sessionid=1681313826#rd)

微信成了事业部，必将承载越来越多的内容和功能，但挑剔的 PM 们并不一定看好它的膨胀。

  

**编辑说**

* * *

腾讯在移动互联网时代的核心产品，巨大的用户量，无数媒体的分析与追捧让微信一直在赞誉中成长。微信真的做到了白璧无瑕么？让我们听听一位 PM 不同的声音吧。（这位 PM 很害羞，所以就匿名了，但是欢迎在文章下评论和他交流，他会匿名回应你哦。）  

  

注：配图不针对任何账号、人，仅为配合文章内容，请理解:)

  

这是一篇对微信的吐槽，并不是那么正经的分析。如果你也和我一样被微信的某些瑕疵困扰，欢迎发送微信和我讨论。

  

**朋友圈**

* * *

朋友圈我觉得是还算不错的功能：我会关心好友们近况怎么样，毕竟不是所有事都会在聊天的时候聊。  

  

![](../Images/0bd3d7769d24317aee17e2edd037efaa.png)

  

朋友圈只能看到好友的内容，结果在好友的状态更新里常常看到A 在自己状态更新的回复里说“好了，总结一下大家的问题，统一回答 巴拉巴拉”，问题是大家的问题是什么啊？怎么看得没头没脑的。原来是因为我没有关注 A 的其他好友 B、C、D… ，所以我是没办法看到 B、C、D… 们的回复的，所以整个状态更新的会话里，充满了不明所以的回复。

  

![](../Images/e604dba4618a7e588e7ebd34ae9ce77a.png)

Twitter 的 @ 机制我觉得不错，如果我的好友 @ 了另外一个我没有关注的人，那么这条信息是不会出现在我的时间线里的，也就不会有没有上下文的会话出现的问题了。

  

和上条对应的，因为在朋友圈里我看不到我原本不认识的人的任何信息，所以我是不可能通过朋友圈来扩大我的好友圈子的（这个问题在群聊里算是可以部分解决，不过朋友圈和群聊两边对应的可能不是同一批人群啊。）

  

总的来说，我个人比较喜欢 Path 的逻辑：以朋友圈为主体，聊天为辅，可以通过好友更新的回复里发现一些有意思的新的潜在好友。

  

**公众号**

* * *

然后很奇怪的事发生了，本来是熟人社交的微信里，突然混进了和熟人完全没有关系的公众帐号。我要看自媒体在博客、微博上不能看么，为什么要在微信里看？  

  

![](../Images/a0e8a882b246cb1fed0b95df0d9c7a26.png)

  

好啦，我其实知道为什么。因为“博客太分散啦、维护成本太高了、传播能力不够啊”，因为“微博没落啦、都是僵尸帐号发垃圾信息”，“看我微信朋友圈上一条信息多少人点赞，有多少好友转发了。这些才是有价值的传播啊。”

  

一方面，我才不关心多少人“赞”我的东西呢，你真觉得赞就发个有价值的回复咯；另一方面，朋友圈里个人状态更新在好友圈子里传播挺好的，因为其他人确实可能对这些信息不感兴趣。

  

但是公众号啊，是想公共传播的内容啊，要先关注了才能浏览就不说了，我就当成是订阅 RSS 的变体吧。但是分享出去还是只有好友才能看见，一点都不“公众”啊，我想分享到别的地方还得先“拷贝链接 - 打开浏览器 - 用浏览器分享”，这是移动互联网时代么，感觉是前互联网时代呢… 对比下来，微博公众多了吧。

  

![](../Images/dca93eff1e642c854b939c946384dede.png)

  

另一方面呢，公众帐号一对一的发布内容方式，让公众帐号的读者之间没法互相联系上，而在博客、微博上，我可以很简单的看到别的读者，共同参与讨论啥的（虽然可以分享到朋友圈讨论，但是这也是上面提到的问题，朋友圈的好友和原本可以公共讨论的人不是一群人）。

  

现在一些公众帐号常用到的“微社区”，虽然可以把读者们聚合起来，但是他们在“微社区”里聊的事，其实和公众帐号发的内容可能并没太大关系，内容和交流被剥离了。

  

![](../Images/b01faa148287aff1194f2b44b5d9ee13.png)

  

要承认的是，微信公众帐号的维护成本确实比独立博客低，也可以简单的获得关注者的数据，对自媒体是有帮助的。但是，其实推广公众帐号不是那么简单的事，一方面，因为分享朋友圈的内容是限于好友可见的，所以传播力和可发现程度是会打折扣的；另一方面，如果要在微信外的渠道推广，其实要求自媒体原本就带别的传播渠道（目前常见的是通过别的微信公众帐号啊、原本的微博啊、播客、博客、线下二维码来传播），没有任何基础的小众自媒体真的能发展的很好么… 这个我没什么研究，不敢说。

  

![](../Images/fdeca7346103253a238c6a8f5ebecede.png)

  

**服务号**

* * *

先是服务号，其实这功能本身我没什么吐槽的，在微信里查银行信息（招商银行）啊、叫车（XX叫车）啊、博物馆导览（国家博物馆）、打印照片（印美图）什么的轻量级功能，确实是方便了开发者，不用花大钱去开发 app 了。不过可能就是一种洁癖，感觉像是一棵桃树上长出来几枝杏出来，略觉得别扭。  

  

![](../Images/b874e05781973bb7612687e593474536.png)

  

然后是微信支付，在微信里买东西啊啥的，其实算是服务号的功能扩展，毕竟有的简单服务能够直接支付挺好的，但是就是长在微信里就洁癖性的觉得不舒服。特别是现在还扩展到别的支付、甚至线下支付。（支付宝这种专门做支付的来做这种我比较爱，不过支付宝的公众服务帐号一股扶不起来的感觉。）

  

![](../Images/6b563f33af03b4582e2f6e34be5bbc63.png)

  

游戏功能挺好的，利用好友关系来做社交轻量级游戏，虽然 Android、iOS 原生都有这个功能，不过微信的好友关系信息毕竟更准确。

  

![](../Images/3210c1d020337decde25528432607997.png)

  

总的来说，和 IM、好友社交相关的我觉得都还行（虽然 Android App 做的不怎么样），别的叠加进去的东西虽然不可否认效果确实不错，但是就是让人觉得别扭。（而且换了不是腾讯来做，能像现在这样成功的可能性很小吧。）

  

**开发者**

* * *

从开发者角度稍微说两句，这方面其实更多的是开发者的贪心，而非微信开发架构的问题  

  

因为服务号每月只能推 4 条信息但开放接口多，订阅号每天可推送一条信息但开放接口少，所以开发的时候要做一些抉择：是想做服务还是做内容订阅。

  

![](../Images/961cc6051eaa7ac2eaff5faa734870af.png)

  

如果开发者确定就只做服务号，其实确实可以实现一些不错的功能。如果开发者确定就只做订阅号，基本功能也是够了。

  

问题就是，往往开发的时候既想要服务号的富功能接口，又想要订阅号的推送频率，所以出现一些在订阅号里利用各种方式来实现富功能的做法，最常见的一种方式是调用Web app来实现许多强交互的功能，但是微信的内置浏览器其实并不怎么好，另外还有下面的一个问题。

  

**单线程**

  

来一条新消息，我点开之后就从旧的信息跳到了新的信息里去，看完后也没有办法直接回到上一条查看的信息里。对于聊天来说，这个问题不是很大。

  

![](../Images/caee5ad6fe1cd542c047754b38044d0e.png)

不过对公众帐号来说，我文章看到一半，我GF来了一条微信信息，我是不是该立即看呢？看的话，我再回来看这篇文章变得特别麻烦（即使收藏了查看也很麻烦）；不看的话，当心有生命危险…

  

对于上面说到的 Web App 来说就更严重了，跳出之后，这些 Web App 相当于关闭了。也就是说，这些 Web App 随时有被其他信息打断的危险。（常见的看起来很美好但是实际没有什么用的举例包括：36kr在微信里做的的直播节目、荔枝fm的播客收听一类的。）
