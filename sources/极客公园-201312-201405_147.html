1. XP 今起退役 微软三折推销 Win8

来自新浪科技

今天，微软将正式停止对 Windows XP 系统的技术支持，虽然用户能继续使用 XP 系统，但继续使用安全风险加大。为鼓励用户迁移到更高版本的系统，微软已经与 360、腾讯达成合作，共同推出 Windows 8 优惠升级计划，价格相当于原价的三折。

简评：只要花 299 元就可以升级到 Win 8，何乐而不为呢？

2. 英荷两国政府向微软付费以延长 XP 支持协议

来自腾讯科技

根据荷兰政府与微软达成的这项协议，后者将在 2015 年 4 月份以前继续向荷兰 Windows XP 用户提供支持。在此以前，英国政府已经决定向微软支付 550 万英镑，从而令 Windows XP 系统获得一年的额外支持。

简评：不论是哪的政府部门，动作总是最慢的。

3. 传韩国制造商为苹果 iTV 制作显示器面板

来自腾讯科技

报道称，韩国证券公司 IBK Securities 的分析师在报告中透露：“一家不愿透露姓名的本地供应商正在为苹果制造 65 英寸的产品，但考虑到苹果的 iTV 当前正在测试中，苹果是否会将这款屏幕用于量产还不好下定论。”

简评：Google TV、Fire TV 都已经来了，iTV 也不远了。

4. 腾讯股价盘中跌破 500 港元 市值跌破万亿

来自网易科技

腾讯昨日开盘大跌，盘中跌破 500 港元，最低至 497 港元，总市值 9413.20 亿港元，跌破万亿。近一个月以来，腾讯股价跌幅最高已达到 23%。有分析称，腾讯开始了一系列减法，搜搜、电商纷纷被剥离。长期来看，腾讯的利润增长点或将减少。

简评：腾讯做减法，利润增长点真的减少了吗？

5. 消息称 Dropbox 获 5 亿多美元信贷融资

来自腾讯科技

据消息称，Dropbox 已经获得了 5 亿多美元的信贷融资。在此之前的几个月中，Dropbox 已经从风投资本和私募资本等投资方手中融资 3.5 亿美元。Dropbox 此次信贷融资中的部分资金将用于建设旗下数据中心，其它资金还将用于发展公司的总体业务。

简评：Google Drive 最近大幅下调价格或许是这次融资的出发点。
