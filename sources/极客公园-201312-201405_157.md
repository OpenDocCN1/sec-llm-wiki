# 微软Build 2014大会首日，不容错过的三大亮点

微软 Bulid 2014 开发者大会已经开始，在首日的主题演讲上，微软发布了哪些值得关注的东西呢？

  

**Windows Phone 8.1 更多功能**

* * *

对于移动设备操作系统来说，搅局者 Windows Phone 8.1 虽然占据的市场并不大，但依然有着许多死忠粉，而为了继续从 iOS 和 Android 的手中夺取粉丝，微软继续为大家带来了更多新特性。  

  

**Cortana 语音助理**

  

8.1 的重大更新之一，虽然苹果的 Siri 和谷歌的 Google Now 早已发布，但是微软之前一直忙于完善 Windows Phone 系统的其他基础功能，这次也是终于腾出手来完成了语音助理的功能，除了搜索和自我学习这些功能外，Cortana 与 Siri 最大的不同在于开放了大量 API，开发者可以通过 Cortana 协议让自己的应用实现更多的功能。

  

![](../Images/987ac50fb3d6cd4a29e269521a29b25a.png)

  

**操作中心**

  

与 Android 和 iOS 一样的下拉通知中心，Windows Phone 8.1 的 Action Center 将把快捷设置、通知推送等信息整合在一起，让用户可以轻松便捷地开关 Wi-Fi、蓝牙或飞行模式等。

  

![](../Images/920b1da35788871629b0238db12bab49.png)

  

**动态磁贴**

  

动态磁贴毫无疑问是 Windows Phone 的标志性特性，在极度扁平化的同时提高获取信息的效率，而在 8.1 中，动态磁贴将可以调整尺寸，并且可以设置是否开启三栏动态磁贴以及添加背景图片。

  

![](../Images/e89f5852e4fcdf600216bdd0722e7a47.png)

  

**升级支持**

  

新推出的 WP 手机均将配备 Windows Phone 8.1 系统，而 8.1 系统最快将在 4 月底或 5 月初提供升级。此外，微软宣布目前市售的所有 WP 8 手机均可升级 WP 8.1，甚至包括最便宜的诺基亚 Lumia 520。

  

**全新应用架构**

  

Windows Phone Store 完成了与 Windows Store 的融合，并且采用了全新的应用架构，使得用户只要一次购买，之后在多个平台和多个设备上都可以共享，微软显然希望 Windows Phone、Windows、Xbox 三大平台实现程序通用后可以像苹果一样，构建起一个体验良好、观感一致的封闭生态圈。

  

**Windows 8.1 提升交互**

* * *

此次升级将在 4 月 8 日开始推送。由于此前 Windows 8 过于关注触控操作而被软件开发者们指责，微软这次在 Windows 8.1 的升级中增强了鼠标键盘等传统外设的操作感，除了在开始屏幕优化了传统鼠标操作外，最有意思的莫过于微软恢复了此前群众呼声非常高的传统开始菜单，虽然已经被改成了 Modern UI ，但确实是开始菜单哦！  

  

![](../Images/92d2b25c5aa1b7f80441d97c2a01b818.png)

而为了应对苹果的操作系统全面免费化攻势，微软也在免费化方面做了一些尝试，面向物联网和屏幕小于 9 英寸的移动设备的 Windows 操作系统都将免费。

  

**三款新机，来自诺基亚**

* * *

埃洛普在成功把诺基亚搞死了之后，终于荣归故里，带着诺基亚百年老店的牌子为微软的 Windows Phone 手机背书，而这次微软开发者大会除了为当前旗舰 Lumia 1520 发布了新款绿色机型外，也推出了三款配备全新 WP 8.1 操作系统的 Lumia 新机。  

  

**旗舰机型 Lumia 930**

  

基本配置与 Lumia Icon 类似，5 英寸 1920\*1080 分辨率的康宁第三代大猩猩屏幕，高通骁龙 800 系列 2.2 GHz 的四核处理器，2 GB 运行内存与 32 GB 存储空间，2000 万像素的卡尔蔡司认证 PureView 摄像头，2420 毫安并支持 Qi 无线充电的电池，四色可选，将在 6 月登陆国际市场，售价 599 美元（约合人民币 3670 元）。

  

![](../Images/dc0700b1e47aa23c28635286c8dc4101.png)

  

**入门机型 Lumia 630/635**

  

这两款设备均为面向入门级的消费市场，微软希望他们能够取代之前 Lumia 520/620 成为全新的 Windows Phone 普及设备。4.5 英寸 800\*480 分辨率的屏幕，高通骁龙 400 系列 1.2 GHz 的处理器，1 GB 运行内存与 8 GB 存储空间，500 万像素的摄像头，并配备了一颗 SensorCore 协处理器可以记录用户的运动情况，共有五色可选。

  

![](../Images/9ce0b430874fc207aaf17825b07ef69e.png)

  

不同之处在于 Lumia 630 为 3G 手机，而 Lumia 635 则支持最新的 4G 网络（按照惯例应该是没有 TD-LTE 支持的），并且 Lumia 630 还有支持双卡双待的版本。两款手机都将在 5 月率先登陆亚洲市场，Lumia 630 单卡版售价 159 美元（约合人民币 956 元），双卡版 169 美元（约合人民币 1048 元），而 Lumia 635 售价为 189 美元（约合人民币 1172 元）。
