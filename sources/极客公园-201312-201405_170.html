如果你能在极客公园的线下活动上找到合适的 UI 设计师，那么你愿意参加我们的线下活动么？刚才还在踟蹰并从嘴里蹦出「我还是喜欢宅」的郑宋帅，不由自主地凑过身来，眼中放出了渴望的光芒，腼腆和失语双重状态叠加在了一起，或许我们能帮他找到理想国中缺失的板块。

90 出生年的郑宋帅利用业余时间，独立开发出了名为 VVebo 的新浪微博第三方客户端，其利用 iOS 7 交互特性，实现了让人眼前一亮的微博查看，转发等功能，简洁的设计风格让其与众不同。2013 年 7 月 8 日开始立项，从最初的想法，到架构，交互等慢慢打磨，三个月后制作了 VVebo。对于如此之快的开发速度，郑宋帅微微一笑：「我写代码比较快，公司的东西弄完就可来做自己的事了。」



在山西长治长大的他，从来也没想到自己有一天将成为独立开发者。高二没毕业，自学了一些 Java 开发后只身一人来到北京。慢慢有了些积蓄，他立刻入手了心仪已久的 iPhone，当郑宋帅从 Java 转向 iOS 开发时，App Store 应用触到了引爆点，此时各种小型创业公司如雨后春笋般冒出，移动应用踏上了开发浪潮。

但随后公司增多，刷榜开始变得严重，郑宋帅的个人开发者之梦几次暂停和重启，并将继续。


辍学生混入用友

我觉得高考没什么意思，很多东西自己就可以学会，早点进入社会还能积累生活经验。家里也没有反对，北京没有什么认识的人，我妈资助了些钱，合租了房子，就在北京呆了下来。


在长治第五中学高二读了一半，郑宋帅的心思早已飞出了窗外，在家自学了一段时间编程后，坐上了去北京的火车。

山西虽然里北京不远，但这个毫无工作经验，甚至连高二都未读完的少年，有些担心。「辍学生」这个在硅谷时髦的标签还未飘到中关村，心理没底的他，自拟了一份简历，填上了在其认知范围内最优秀的内容：84 年出生，毕业于太原理工大学，计算机专业。面试时为了显得和简历上年龄一样成熟，特意熬夜留了点碎胡子。

也记不得当时简历上填的工作经历是什么，郑宋帅回忆，在网上搜了几家隶属于互联网公司顺手填到了表格中。

这份定制的「敲门砖」在第二天就起到了效果，他接到了用友通知面试的电话。后来他们才发现那是一份假简历，不过我已经进来了，他们也就没说什么？，郑宋帅腼腆一笑。

当这个胡须渐渐变硬的少年开始厌倦了每天重复的工作，除了维护早已没有什么技术含量的 ERP 项目外，郑宋帅发现已经没有什么新技术值得学习，重新学习 Java 框架的劲过去后，已经等不急扑向心中那个未知的 iOS 开发，1 年后离开这家公司。

从用友离开后，随即加入了一家名为黑麦的公司（Rye Studio），黑麦主要面向儿童开发益智的 iOS 应用，有声电子书和智力游戏开发。在黑麦的 2~3 年里，郑宋帅主要是为孩子制作一些鱼或恐龙等卡通 App。

不过由于黑麦制作的 App 需要产生一些特殊效果，并没怎么用到 iOS 的原生控件，郑宋帅觉得自己的开发梦想还在远方。


独立开发的启动，暂停，重启

也想到过社保、医保这些问题，但是想到能独立开发，那还是很好的。


离职后郑宋帅感觉终于有了一试身手的机会，拥有了真正的独立开发者身份，开发应用为生的目标里自己越来越近。



如果能将 iPhone 上的内容截长图应该挺好玩，于是名为 Piiic 的应用诞生，打开你要分享的内容，截图，滑动，再截图，直到装进了所有内容。Piiic 将为你生成一条长长的图片，分享给你的朋友。

不少越狱用户对 Piiic 钟情，将自己越狱后安装的插件用 Piiic 展示出来，小试牛刀后，初尝甜头让郑宋帅兴奋不已。接着这股热情，之后又开发了一些其他应用。

在程序圈内著名的论坛 V2EX 上，郑宋帅看到了一家创业公司的招聘消息，由于之前长图得到肯定，作为合伙人之一加入了这家新公司。

这家 20 人的创业公司前期融资较少，大家以外包为主，剩余时间来尝试新项目。在家远程办公的郑宋帅发现外包项目耗时并没有想象中多，藏在心中那个「个人开发者」不自觉地又蹦了出来。


流畅、流畅、流畅！

不这样做就打心眼里不舒服，可能是强迫症吧。 


13 年 7 月底，郑宋帅开始对微博产生了兴趣，新浪原生客户端中规中矩，没有什么亮点。而从名噪一时的墨客，再到由专业设计公司 eico design 发开的 weico 等第三方客户端，都被郑宋帅把玩过一段时间。

weico 的流畅性不好，在切换夜间模式时加载过久，此外郑宋帅更倾向墨客这种从后往前看的浏览方式。墨客虽然更新细致，由于作者身处海外反馈速度比较慢，目前还没有 iOS7 的适配。

而 App Sotre 里其他微博都似乎从同一个模子里刻出来。Tweetbot 和 Tweet7 两个 Twitter 第三方客户端引起他的注意，随后将 Twitter 无论免费还是收费的客户端都下载一遍，发现每一家都能能找到特殊的亮点。

不流畅或交互感不强等缺陷，没能让任何一款客户端在他的手机上停留太长时间，Twitter 和微博本质上有区别，没有什么可以借鉴之处，为何不自己来开发一个？

当真正开始动手写程序时，郑宋帅才明白为何 weico 会卡顿。不得不调试了一个月后才跳过 weico 的瓶颈。



重心在调试程序的流畅性后，郑宋帅第一版 VVebo 却离现在的 VVebo 越离越远，心理很急躁，时间流逝得太快，而自己的应用却仍然不见踪影。

急于上线却不巧将 debug 工具勿打包到了文件包内，被苹果退回。这次意外推倒了他胸中那个摇摆的稻草，推翻重来并重新设计了 icon，这就是我们现在看到的 VVebo。


他的理想国

越狱本身是好的，提升了体验，但在国内只是逃避付费。如果能做互联网服务肯定比做 App 更开心，互联网服务相比 App 能影响很多很多人。


Piiic 获得了 6、7 万下载量，最初为收费 App，由于破解太多，不得已转为内置购买，遭到用户反对后又再次改回 0.99$，郑宋帅坦言没赚太多钱，除了破解外，很多下载量来自于限免。

VVebo 一直没有收费，除了自认为依然有待提高外，Piiic 的破解阴影在他心中挥之不去。VVebo 的后续发展也让他开始犹豫，毕竟微博服务不是自己的，将受限于该平台。

新浪微博查看话题、搜索、私信、赞、分组等功能对于普通开发者不开放，需要二次申请，置于通过理由是什么，郑宋帅猜测是用户量。即便如此，申请后私信、搜索和赞依旧不开放。只好依靠民间手段，才解决了以上问题。

郑宋帅没再深入考虑自己和新浪微博的关系，Twitter 和微博到底有什么不同。



他发现自己和网友正在建立一种微妙的关系，觉得如果得到用户的认可之后，后续的产品或许能继续被大家接受，再寻找收费的办法。这样就能够维持自己独立开发的生活。

UI、程序、推广和修漏洞，收集用户反馈集多任务于一身，让无畏的郑宋帅有感到疲倦。

线下认识的开发者寥寥无几，大都不给力。互联网将全国各地的开发者串联在一起，只有回到这只无形的网上，郑宋帅才能有所宽慰，但他不知道这些人到底是谁，是否能和他一起构建这个理想国。

柚子茶终见底，我问你的梦想是什么？郑宋帅身体靠向沙发，做出了一个畅想的姿势，但显然这个问题早已在他的脑海里深思熟虑过，马上给出了自己的目标：「挣够 2000 万，然后就鼓捣自己喜欢的东西。」

郑宋帅的经历正如他「写得很快」的代码一样，一溜烟跑到了同龄人的前面，然而依然逃离不了阅历尚浅给他带来的限制，到底如何才能挣到这 2000 千万，他想应该是要创业，但具体做什么还没想好，在他的理想国里还缺少一名出色的 UI 设计师，还好他的旁边已经坐了一位长发的姑娘。
