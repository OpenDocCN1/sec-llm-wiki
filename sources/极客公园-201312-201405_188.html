如今越来越多的人参与到跑步这项运动，考虑到地点的可选择性极多，运动需求的简单，时间的可协调性以及锻炼的充分，我们不仅相信跑者会持续上升更有理由相信，跑步的衍生可能性也在无限扩充。



跑步的玩法其中最为人所知的是 Nike+（fuelband，nikeplus 社区，nikerunning 等 apps），作为全球第一大运动品牌 Nike 的营销策划早已炉火纯青，使得 Nike+ 的新运动科技里程碑已经打下。2013 年中 Puma 在日本 Apps store 和 Google Play Store 推出了其下首个跑步社交软件 Run Navi，RN 最大的特点是根据 runner 喜好设置路程和具有人性化的过往钟情地点提示和分享社区，不过登陆的地区实在有限。



兴趣产生社交产生团队，三者是相互关联的，而产品在我们个时代不在是以企业愿意生产什么产品为主导而是消费者愿意消费什么样的产品，这就是我们说的以用户为中心。市场发展饱满必然流向衍生市场，即所谓的配件，Nike+ sensor 不必多说，国内的广告早已满天飞。而相比 Nike+ sensor，Jawbone 系列的则相对闭塞，而且不论是 Jawbone up 的产量到购买人数和市场反响都远远不及 Nike+，我认为最直接的因素是价格，Jawbone 的外形非常适合日常佩戴，而且基于 Bluetooth 4.0 电量消耗也极其优秀，至今 Jawbone up 2 价格仍维持四位数。



相比起 Jawbone 系列的丰富功能体验而言 Misfit shine 在使用上则显得有点不够看，shine 在数据记录上目前仅显示运动项目和持续时间，而在睡眠记录上仅仅只有总时间和深度睡眠时间，BTW，最惨不忍睹的是睡眠模式需要敲击三下，多少人睡觉前忘记敲这货三下。



我想对于 running 衍生市场到这里你也该有一定的了解了，在我看来 running 衍生市场的模式的公式是：


Apps+Equipments，高附加值的地方在于用户在使用后对于品牌的了解以及后需付费，就是免费加内购。


我还想强调的一点是这个公式不是永远的定律，因为最有可能打破这种平衡的是来自于用户品牌的忠诚度和对于品牌的参与，就这点而言，不得不提，New Blance 的 Color Run 以及 Nike 的 Lunar Run 10km，相比后者，前者更加声势浩大，Color Run 强调它们的活动是地球上最欢乐的 5km 跑程，丰富色彩的冲击，年轻人奔跑自由和欢乐中强大的感染力，2013 年 Color Run 登陆北京，广州，2014 年 3 月深圳开跑，看看这几年 NB 的鞋子是如何充斥你身边的朋友的脚下，你就能清清楚楚感受到 NB 的魅力和对于用户的经营多么出色，这就是裸科技的力量。



从目前参与人数和跑步市场的消费潜力来看，可穿戴设备的春天并没有来到。
