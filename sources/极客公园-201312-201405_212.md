# “二次元”生产力：你为毛这么宅？

**宅并不代表无所事事不能创造价值，而只是一种生活方式。我们不妨从一个 90 后宅男的视角看看宅在互联网的影响下所做出的一系列创新来修正我们对这一人群的“误解”。**

  

我出生于一九九四年，标准的九零后，同时也是一个宅男；一个和很多同为宅男的伙伴们共同沉浸于创造的喜悦之中的人。

  

作为一个整天在网上，和同龄的宅们没日没夜聊天的我，想说说属于这一代的宅文化和宅文化下的互联网创新。

  

**宅 \\zhái\\ n. 指经常呆在家里不愿出门的一类人**

  

同许多同龄人一样，我偶尔会盯着窗户外面发呆，幻想着那些根本不会发生的事情周末会在家里闷着，或者做设计或者敲代码，或者一部动漫接着一部动漫的追下去，再或者干脆懒洋洋的披着被子在床上没干劲滚来滚去——好像五月病会持续到十二个月一样。

  

然而，就是这样的一群人，和 80 后、70 后一样，都拥有着对于未来的向往和属于自己的追求；为自己想达成的事情而拼命、而忘我。

  

然而，我们的父辈可能无法理解，这群宅孩子们面对屏幕每天所在做的事情；或许也没办法理解“宅”所代表的真正内涵。

  

**宅 \\zhái\\ v. 指呆在家里做一件事情，坐到头顶长蘑菇也不出门晒阳光的行为**

  

宅不仅是窝在家里；宅们拥有面对屏幕去奋力做自己想做的事情的力量。有人能够对着一道数学题一抠抠到大天亮，宅们也能对着一份代码手册一读读一晚；面对自己喜欢的事情时，每个人在面对令自己着迷的事情时，都一样——执着的可爱。

  

还记得非常清楚，我曾经对着一段 JS 代码怎么改也改不明白，一行一行的操作一直到后半夜，对着报错拍桌子、到厨房倒了一杯冰水，看着代码无奈的叹了口气，接着查手册、对代码动刀子。

  

也记得非常清楚，同为宅男的我的两个朋友，一个人教另一个人写 cpp，夜夜奋战。

  

宅们，一样在做事。

  

**宅 \\zhái\\ adj. 宅的，指由宅们在家中坑出来的东西**

  

宅们，是真真正正在做事情的，也真真正正的做出来过事情。

  

**萌娘百科：宅们堆出来的动漫百科**

  

动漫宅们是绝对不会否认萌娘百科的权威性，说到宅，我认为萌娘百科应该被放在第一位；它是由一大群宅们共同撰写、共同维护、集资并维护起来的一个百科网站。宅们可以在萌娘百科上编辑各种宅文化词条，去传播自己的想法。

  

![](../Images/d72c07edcd951bfb4ce748f0c50c87f6.png)

  

我对于萌娘百科印象最深的就是那个从颈部到脚背形成了一个凄惨平面的更新姬了，这是一个由三四个人共同维护起来的二次元人物，我把她视作联系萌娘百科所代表的文化聚合物与身边这些人的一个纽带。

  

无论和萌娘聊天还是浏览萌娘百科，给我最深的感受就是自由、放松和欢乐。

  

这也是我认为宅文化中的核心元素：令人感到极大的快乐。

  

![](../Images/2d60584968e7a7d97263d30bed596f19.png)

  

萌娘百科是一种特殊文化碰撞的产物，从中也能看出宅们对于自己心爱的东西所表达出的情感。

  

不计回报的付出，只为能给同为宅的另一个人带来快乐与欢笑。

  

**SAO Utils:用爱堆出的软件 **

  

“360 误报/拦截等造成的问题请不要当 BUG 提交, 我也只能以『宅』的名义保证 SAO Utils 的纯洁性”，重点不是前一句是后一句——以宅的名义去保证。看到这句话时我受到了很大的触动。

  

![](../Images/f0e6a950c3346a32a2d7b1ea36d3b7e6.png)

  

这是一款桌面快速启动软件，以动漫《刀剑神域》内游戏 SAO 的 UI 界面为蓝本设计；和音速启动之类的软件类似，能够帮助用户更加快速的访问到自己的程序。

  

这软件的作者也是一个画师。我不太会看画，不过透过的他画能感觉出一个宅静下心来对着自己喜欢的事情而痴迷，清新的画风和细腻的笔触，令我印象非常深刻，同时也留下了这是个能沉得住气做事的人的印象。

  

说实话，写这样一个程序光是用想的就知道会多让人头疼了，然而这款软件的开发者却做到了并且做的很好。同时软件的开发者也在以『宅』的责任心去维护这款软件，让他变得更好。

  

因为想做，便放开手去做，因为大家都喜欢，所以便不计得失的去呵护，我们常说的无私，在宅文化中，不也就是这样毫无改变的呈现出来了么？

  

**萌卡:激情·创造·开放 **

  

萌卡项目组的头目跟我是比较好的朋友，我俩还是在别的网站一起给别人干活的时候认识的。后来他开始自己干，在 github 上开箱子，维护起了一个游戏王的游戏社区。

  

![](../Images/fd6711619b8c5eb51ceea6367094bce3.png)

  

当初我只是觉得他可能是没事闲出蘑菇想找点事情做，于是便找这个头目商量着给网站设计一套首页，改改程序的 UI，商量下什么地方要做哪些改变，因为一件小事情有一点分歧，便在环聊里面讲对方揉来揉去。只为了能对用户负责，让大家开心。

  

后来慢慢的，很多人开始聚集起来，帮助他来维系这个社区。一个个分支项目由不同领域的宅们撰写代码、调试、上线。上万名玩家聚集起来享受这群宅为他们带来的美好时刻。

  

萌卡的这群宅们拥有其他群体所少有的那种激情，工作学习之余全力投入项目的维护，筹钱。

  

现在的萌卡正在非常健康且稳定的成长着，萌卡的玩家管理成员没了之前那份幼稚和独断，而玩家也变得更加体谅开发者的辛苦。

  

我和玩家曾经在萌卡的聊天室里聊天，有一个人跟我说非常感谢萌卡项目组能发起并且维护这个项目，我说我们都在做我们所喜欢的事情，你喜欢玩而我们喜欢去开发，做点什么东西；这个项目中的人，无论是发起者还是维护者、参与者都在享受着这一切。

  

![](../Images/edc53c0af05de6f94f19ddf1eb7eb9a7.png)

  

萌卡项目组的所有内容都是开源的，你可以非常容易的在 github 上找到他们写的每一行代码并且免费的使用它们。这种开放与无私也是属于宅文化的非常重要的一个元素。

  

**Fcitx:严谨认真下的宅物**

  

说实话我是刚刚和宅友聊天的时候才知道原来我认识的那个家伙是 Fcitx 的作者（之一），原来我只知道他对 KDE 的贡献很大，当得知这件事的时候，简直吓死我了。

  

![](../Images/b1bff2583fd938aa65254a35f4baa47f.png)

  

Fcitx 的业界口碑不用多说，这是一个几乎所有 Linuxer 都知道的软件；我主要想讲讲作者这个人。

  

我们认识这家伙的时间不长，大概一年左右。他给我的感觉正如这个章节的小标题：严谨认真；同时也非常的稳重，在探讨观点时，如果出现了分歧他总是会非常礼貌的表达自己的想法，很温和的提出异议。

  

![](../Images/88808da4c46954b0aa63a2d221093c3b.png)

  

我们偶尔会在一起探讨一些圈子内的话题，从动漫到科技再到一些比较旁门左道的小技术有的时候甚至也谈论谈论做菜购物之类的小话题；他给我们的感觉就是很温和，从不用很激烈的词汇，几乎每句话之前都会加一个“ˊ\_>ˋ”。对于自己的产品，他曾在自己的博客上说过大概是这样的意思的话：我希望给用户更多的选择，为此宁可去牺牲一些易用性，比如 Fcitx 不会收集用户的键入信息。

  

宅圈的人的作品给我的感觉都是这样的：干干净净；没有去做什么越界的事情，也没有做什么擦边的事情。他们在以『宅的标准』去衡量、去创造，为同为宅的其他人考虑着。

  

『宅』的大家，都是普通人。

  

但是这些人在创造着自己的价值，传递着快乐。

  

**宅 \\zhái\\ num. 宅代表了一个很大的数字**

  

宅，并不仅仅意味着一个人坐在电脑前面，滚键盘敲鼠标，屏幕后面，是一个缤纷的世界；宅们与其他人生活在同一个世界中，但却以另一种方式聚集在一起，共同维系着另一个不太一样的次元。

  

我觉得，宅意味着自由、意味着分享、意味着欢乐、也意味着一种责任。

  

这里有你我，更有大家。屏幕后面的世界就像我们小时候与同桌所讲的悄悄话一样，不被身边的人所知道；然而，总是有人知道的。

  

以上就是我对一个不可能被新华字典或牛津字典收录的词的理解，它确实有着非同反响的意义。

  

『宅·改变世界』
