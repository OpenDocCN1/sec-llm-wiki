早在一年前，Ubuntu Touch OS 刚刚发布的时候，还没有获得硬件厂商的支持。而去年 7 月份，Ubuntu 的母公司 Canonical 在Indiegogo 上众筹，希望能打造超级手机 Ubuntu Edge 的项目也失败了，现在 Canonical 和 魅族 终于在 MWC 展示了成果，搭载 Ubuntu Phone 版的魅族 MX3 已经亮相。


根据前方记者的线报：搭载 Ubuntu 的魅族 MX3 系统版本为 14.04，目前仍处于内部测试阶段，还存在不少小 Bug，但操作流畅度已接近他自用的 Nexus 5。


消息来源：cnbeta


对 Canonical 来说，拥有了一个不错的硬件厂商合作，终于能够推出搭载 Ubuntu Touch 系统的手机。对魅族来说，Canonical 是魅族国际化道路上的一个跳板，同时也不至于把鸡蛋只放在 Android 这一个篮子里。


除了等，不知道该干什么


今年 CES 消费电子展前后，就有消息传言魅族将要推出 Ubuntu Touch 系统的手机，而后魅族官方微博发布了几张白色 MX3 运行 Ubuntu Touch OS 的照片（现已被删除），几乎可以确定合作的真实性。



2 月 11 日，Canonical 的副总裁 Cristian Parrino 拜访魅族，据说是共商大计，确定合作的一些事宜。随后 2 月 20 号，Ubuntu 在官方网站上 公布了合作伙伴，魅族和西班牙手机制造商 bq 均在其列，两家都计划今年推出搭载 Ubuntu Touch 系统的手机。



Ubuntu Touch 还是有不少创新点，手势操作，注重内容呈现，手机系统与桌面系统的转化与融合等等，详情可以看极客公园之前撰文《详解手机版 Ubuntu：创新不少，前途不明》。从发布 Ubuntu for Phone 这个项目后，就一直没有一个很好的设备能够体验 Ubuntu Touch OS，魅族 MX3 的硬件搭载 Ubuntu 系统，还是能够让不少人有所期待的。


首先你得有个手机


尽管 Firefox OS 的东家 Mozilla 和中兴、LG 、华为等厂商已经推出搭载 Firefox OS 的手机，但主打低端市场，无法进入主流用户的视野，同时也没有一款给人印象的标志性产品。由 Jolla 推出搭载 Sailfish OS 的手机上市后，不少测评也认为表现并不出色，部分手势让人疑惑，运行 Android 应用崩溃、卡死，这些新兴的移动 OS 都面临各种问题。


Ubuntu Touch OS 推出这一年也是不瘟不火，没有一款手机能够很好的体验 Ubuntu 系统。对 Canonical 来说，Ubuntu 需要一个合适的手机来承载，此次和魅族的合作，以魅族对产品雕琢的风格，我是很期待 Ubuntu 版的魅族手机。Canonical 在国内除了喜欢 Linux 的极客们，主流用户心中几乎没有什么印象，魅族在国内的品牌形象和用户群体（在国内拥有很多铁杆的粉丝——煤油），这对于 Ubuntu 在国内市场的渗透都是很好的资源。



魅族的 黄章今年宣布复出，在营销层面上，也会比以往投入更多的资源。相比各大厂商把 Firefox OS 当备胎，只是把它当作在 Android 之外的一个备选方案，Ubuntu Touch 要比 Firefox OS 更幸运一点。


Ubuntu 将是魅族的国际化跳板


在今年 CES 展会上，魅族副总裁李楠就表示，魅族将于 2014 年第三季度进军美国市场。除了肯定会在美国推新款 Android 版魅族手机之外，推出 Ubuntu Touch 系统的魅族手机也不出意外。对魅族来说，打开国际市场需要搞定国外的各种资源，Canonical 在国际上的影响力将是魅族国际化的跳板。Ubuntu 本身也拥有很多社区和粉丝，魅族不会一开始就陷入很尴尬的境地。有 Canonical 的合作支持，魅族搞定国际运营商的难度也降低了不少。


魅族副总裁此前也李楠表示，开源系统在国外需求很大，可以在 Google 生态系统之外做出一些新突破。如果搭载 Ubuntu Touch OS 的手机体验不错，同时没有 Android 等系统专利限制，应该会笼络一批开源爱好者，但只有开源爱好者为其开发应用，没有商业开发商来开发优秀的应用，主流用户可能并不买账。


鸡蛋还是得分几个篮子装


今年 MWC 上，好几家厂商推出 Firefox OS 的手机，诺基亚发布基于 Android 系统的 Nokia X 低端机，三星除了发布 Galaxy S5，还发布了 Tizen 系统的智能手表，传闻 Tizen 系统的手机也将发布。


对于手机厂商来说，都不想把鸡蛋放在一个篮子里，当然自家的篮子不算（比如苹果），哪天 Google 收紧政策，活法也就变了。如今移动 OS 三足鼎立的局面能否被打破，我个人的观点是应该会有下一个移动 OS 崛起，而且一定是基于 Web App 的，尽管现在 Web App 的体验差很多，但还是有不少机会的，基于 Web App 能解决现有移动 OS 的一些问题，比如无需下载的时间，比如用服务代替应用等等。


在众多新兴的移动 OS 上，能软硬件结合做好很不错体验的仍然没有，魅族和 Ubuntu 的合作或许能为这个市场带来一些新的血液。
