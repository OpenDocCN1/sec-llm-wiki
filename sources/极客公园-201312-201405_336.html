1. 联想 23 亿美元收购 IBM 低端服务器业务

来自新浪科技

昨日，联想在港交所发布公告称，将以 23 亿美元收购 IBM X86 服务器硬件及相关维护服务。收购价中包含 20.7 亿美元现金和向 IBM 定向发行 1.82 亿股联想集团股票。联想通过此次并购，将成为全球第三大服务器厂商。

简评：联想用了五年时间来消化 Thinkpad，这次要花多久时间呢？

2. 京东千万美元收购今夜酒店特价

来自腾讯科技

今夜酒店特价 CEO 邓天卓在微信确认，京东商城已经完成了对今夜酒店特价的收购，收购金额在千万美元级，置换方式为现金 + 股票，今夜酒店特价原有投资人已完全退出，邓天卓将担任京东商城副总裁。

简评：刘强东称京东在 2014 年有五大目标，其中有两点分别是渠道下沉和 O2O，而买下今夜酒店特价对这两点都有帮助。

3. SEC 暂停“四大”执业资质致中概股周四普跌

来自腾讯科技

由于未能遵守 SEC 要求提供与会计造假调查相关的文件，美国法院决定处罚四大会计师事务所的中国分部，6 个月内不得为在美上市公司提供审计服务。此事件导致周四中概股普跌，当当网最高跌幅达 15%。

简评：中国有关法律法规，未经监管部门许可，中国会计师事务所不得擅自向境外提供审计底稿。中美两国在法律上的差异与冲突让一些公司有机可乘。

4. 特斯拉公布在华零售价：起价 73.4 万元 中国税负占 30%

来自网易科技

特斯拉电动车(Tesla)昨日正式公布 Model S 中国零售价，Model S 85kWh 在中国的起售价为人民币 73.4 万元，这款车型在中国的价格与在美国一致，多的只是不可避免的关税、运输费用和其他税费，其中中国税负占据了车价的 30%。特斯拉称这是“一个公正的价格”。

简评：现在只要 25 万定金，土豪们就可以预定一台 Tesla Model S 啦！

5. 微软第二财季业绩超预期盘后股价涨超 4%

来自新浪科技

微软今天发布了 2014 财年第二财季财报。报告显示营收增长 14%；净利润增长 3%。因第二财季业绩超出华尔街分析师预期，推动其盘后股价上涨逾 4%。

简评：微软这样的庞然大物能实现营收大幅增长实属不易。
