# 杀死比特币

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&appmsgid=100109313&itemidx=3&sign=73386cad759d1f25b147e189a15f2854&scene=126&sessionid=1681314988#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&appmsgid=100109313&itemidx=3&sign=73386cad759d1f25b147e189a15f2854&scene=126&sessionid=1681314988#wechat_redirect)

不想再看到比特币的身影？那么该如何杀死比特币呢？

  

**来自政府的影响**

  

比特币在经过了11月后的大涨和几次阴跌、回暖、暴跌后又回到了月初的起点。 从这一个月的行情看，从月初的不到2000一个，一路涨到巅峰的7000元一个，某些媒体和宣传以及一些看不见的资本运作起到了作用，剧烈下跌时毫无疑问也有背后操作的影子，在网上有流传一些相关传闻和资料都可以参考。

  

其间三次剧烈下跌，一次是在美国承认比特币的地位后，价格迅速被拉上巅峰明显虚高后下跌到3500左右；值得注意的是，后两次的暴跌则是来源于有人透露来自于政府的消息，包括五部委不承认比特币货币地位和“规范管理”，以及约谈第三方支付平台禁止与参与比特币业务。

  

![](../Images/e989abd403245410a43150c21f1b33fc.png)

  

不承认比特币的货币地位很正常，因为政府面对新事物往往趋向于保守稳妥的态度，而承认其为商品，允许自担风险的情况下自由交易这属于意料中的反应，用一些网友的话来说叫做“不禁止就是利好”。但是消息传出来之后，价格突然下滑，并且呈加速的趋势，几个小时内从接近7000迅速下跌到5000之后持续阴跌。

  

之后是微博某人士透露了一条消息说第三方支付平台禁止参与比特币业务。这也很好理解，政府一向对外汇控制严格，比特币这样无国界的支付系统必定会给这样的控制打开一个大缺口，监管、交易所实名制都在意料之中。不可思议的事情又发生了，在消息大量流传之后，突然价格又猛烈下跌，这次惨烈到直接跌回2100，此时距离顶峰可以算是腰斩再腰斩了。

  

我在QQ群交流的过程中发现大家对于政策的解读偏向消极，认为这次是政府插手了，没法玩了。类似的消息传了几手后甚至变为“政府禁止比特币了”，令人啼笑皆非。结果是，某些在较高价位入场的玩家忍痛“割肉”，惨淡离场。当然，某些精明的玩家高抛低吸，手中的币怕是翻番了，最高兴的应该属于外盘玩家，在下跌最狠大家最恐慌的那几天，MT.GOX 的价格甚至比国内高出近1000元，不少人在某些交易平台暂停充值之前的那段时间光搬砖都不知道搬走了多少比特币（也许包括莱特币），大量币从中国流失出去被外国玩家买走了。

  

**如何封锁比特币？**

  

我们换一个角度思考，假设你是政府，你非常非常痛恨比特币，不想看到比特币再在境内出现，你会怎么办？

  

1：交易所承担着普通散户买入卖出比特币的业务，属于比特币去中心化系统的一个稍微中心化的环节。正如面对黑客的攻击，交易所往往是最脆弱的并且最容易被攻破的，政府要“处理”比特币也应该会首先考虑交易所吧？政府能做的措施可以包括直接要求关闭交易所，然后域名不予解析，交易所就没法做下去了，可能会退到海外，海外也很简单，用一些技术手段进行封锁即可。

  

当然，这对于习惯在境内交易所注册个帐号，充值后进行比特币交易的普通网民的确会造成一些困难，但是当涉及到如此大量的金钱时，购买一些代理以及注册境外交易平台的帐号就不是什么大不了的事情了，境外几个交易平台包括 MT.GOX，BTC-E 等只需要提交有效的身份证明信息就可以注册并且交易，有的境外交易平台还有中文界面，简单方便。

  

![](../Images/33ef24e7a7adbe956cb8b7dd73b283d7.png)

  

2：既然玩明的不行，那就玩暗的吧，找一群网络专家，分析比特币客户端包括挖矿和同步块等操作的协议特征，并且进行封锁就行了。有意思的地方就在这里，假设按照传统服务比如 C/S 架构（客户端/服务器架构），一个中心给所有客户提供服务，那么只需要封锁服务器端就能使整个网络瘫痪。问题是比特币是一个精心设计的分布式金融系统，该系统的特点是互相不信任并且不惜占用大量磁盘空间的代价也要单结点保存全网信息，实际效果就是，除非你能同时封锁所有比特币客户端结点，否则封锁就是无效的，因为任何一个结点都可以恢复全网信息。

  

封锁境外网站，很简单，只需要在国际出口的防火墙添加一条过滤规则即可；境内网站则所有网站都必须备案，否则会有一批人专门审查并且做出封锁的决策，境内的服务要想做生意能不乖乖执行？而比特币的高度分布式设计则使得封锁结点必须在全网内部都布下才有效果，因为只要任意两个结点之间没有被过滤，则照样能同步。假设境内到境外的出口只有一个，那么部署一个防火墙即可，如果境内有N个比特币结点，最糟糕的情况是每两个结点之间都得封锁。中国有多少个比特币结点，或者说有多少台计算机可以运行比特币客户端，你可以数一数……如果想有效地完全封锁比特币，也许最好的方法就是关闭一个地区的 Internet（这发生的几率非常低）。

  

3：如果明的、暗的，都不太容易实现，那么正如某专家建议的，不妨顺着比特币的规则，动用政府掌握的大量大型计算机（包括精心定制的大量矿机）的超强算力，快速挖矿并且控制大量比特币，可行吗？老实说，在比特币创始早期，的确有这个可能，只要掌握了大量算力不但可以快速挖矿甚至可以发动51%攻击，而目前全网的算力已经达到9000000 GHash/s 以上，等于全世界那么多矿工都在保护着比特币系统的安全运作，想一个人或一个集团掌握足够强大的算力不是说不可能，但难度一定非常之大。

  

可以看到政府能采取的手段很多，有的也非常有效，但是若要完全封锁比特币则代价非常大，政府不得不多权衡利弊，退一步说，假设比特币真的以某种手段被“驱逐”出中国了，那比特币就会死亡吗？也许会比特币真的会死亡，但绝对不会因为这个原因，假设没有中国，比特币一样可以在世界其他范围活的很好，就像中国没有 Youtube 和 Facebook，难道这两家网站就会因为无法进入中国市场而倒闭吗？显然不会。

  

**技术层面的原因**

  

相对于政策，更加值得担心的是来自技术层面的原因，假设以下极端情况出现：

  

1：一个月后量子计算机横空出世并且实际使用，可以从公钥“秒推”出私钥，那简直是灾难性的破坏力。

  

2：SHA-256 被某数学家破解或者一定程度破解了，造成了和量子计算机一样的破坏力。

  

这些情况当然有可能发生，而且一旦发生后顾过哦非常严重。有人认为 Satoshi Nakamoto 早就想好了面对量子计算机破坏性计算力的对策，我个人认为不太靠谱。虽然网络上对 Satoshi Nakamoto 这个人的真实身份有很多猜想，包括数学家、密码学家、某个团体、甚至是某个政府下的组织，但是毫无疑问，Satoshi Nakamoto 几乎没有可能是未来人，也就是说他不会见识到量子计算机真实运作下会产生什么样的力量，那她如何对一个没有见过的东西想出有效对策？

  

同时它选择了 SHA-256 等密码学标准，理由就是它相信这些手段在目前应该是安全的，否则如此多的安全界人士早就找出了漏洞。所幸的是，比特币客户端（包括协议）是一个可更新的系统。假设上面那些极端情况真的出现了，怎么办？比特币基金会一定会第一时间发现这个问题，并且发出公告暂停当前客户端运作，等到解决方案出现后（比如迁移到新的加密算法等等）再推出新版本客户端同时恢复所有客户端运作，此时在破坏性的故障产生时间点之后的所有块全部作废，之前的则保留，这样，比特币系统又回复到正常状态。

  

**要的是什么？**

  

回想11月暴涨暴跌的那段日子，大家手里拿着一样的比特币，大家面对着一样的行情，为什么有人镇定自若高抛低吸，有的人持币面对过山车一样的行情无动于衷，有人匆忙入市惨淡割肉？为什么有人说“我今天赚了/亏了几个币”有的人则说“我今天赚了/亏了多少钱”？我觉得除了交易的手段、经验、消息之外，还有一个很重要的因素就是对比特币了解的程度。你得知道到底比特币是什么东西，到底是什么支撑着比特币系统的运作而支撑比特币的东西有多强大，到底比特币优势在哪？有什么弱点？

  

而掌握这些知识，你可能需要阅读一些比特币原理的入门文章，包括 Satoshi Nakamoto 的那篇所谓“创世论文”，这些很多网站都有中文的，花不了多少时间。如果你没有计算机背景和密码学的知识，也许还需要购买一本写得好一点的系统一点密码学相关图书并认真阅读，这种书有很多价格也不贵。碰上不懂的知识和名词记得查 Wikipedia，这上面都总结得很好。

  

如果你有计算机软件开发背景那 Bitcoin 的源代码也是不错的参考资料。只有在充分了解了比特币的原理和足够的细节，才知道你要的到底是什么，是比特币、是人民币、还是经验。有人说，应该抛开技术单纯从“经济”看比特币，我认为，抛开技术看比特币就像抛开技术看 Internet 一样滑稽，因为比特币在现实世界能产生的作用几乎完全来自于它技术上的设计和实现。

  

**价值和影响**

  

我想比特币对于各种人都是有一定价值和影响的。

  

假设你是一个软件技术爱好者比如程序员之类的，毫无疑问比特币是一个罕见的得到大规模应用的分布式系统，它的源代码一定是经过无数顶级安全专家的审核，代码在安全性上一定被改得无懈可击、接近完美。这样一份代码包括相关的论文和资料对于任何一个软件开发者尤其是网络系统软件开发者都是非常珍贵的资料。

  

假设你是一个投资者，并且比较了解比特币系统的运作方式，还相信比特币未来会发展到很大规模并且取得一定成功，那么比特币也许也是一个非常好的投资品。不过请注意，既然比特币是一个前所未有的开创性的实验，那么失败也完全是有可能的，如果你决定要投资，请仅仅拿出力所能及的本金（比如你拿出价值为N的资产换成比特币或者矿机，当天晚上能好好睡觉，即使比特币第二天因为某些原因失败了，价值变为0，你也能笑着说“赔了就赔了，那就算了”）。

  

假设你认为比特币跟自己没有一点关系，或者坚信它是所谓“庞氏骗局”，那也没问题，只要不参与不投资，你一分钱也不会损失。但是假设它一旦成功了，你也许立即拥有一个全球性的支付系统，购买国外产品或服务也许会非常方便。

  

**激动人心的实验**

  

我认为，比特币是这个时代中一个非常神奇、非常振奋人心的发明和激动人心的实验，这样一个通过运行在 Internet 上的分布式金融系统到底能否行得通，能否经受住检验，又会给这个世界带来什么变化，我们可以一同参与并且一同见证。
