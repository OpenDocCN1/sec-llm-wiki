# 汽车厂商扎堆CES 2014，看点全收集！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&appmsgid=100109313&itemidx=2&sign=51d9de309da1d4708e12778c5d2bec92&scene=126&sessionid=1681314988#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&appmsgid=100109313&itemidx=2&sign=51d9de309da1d4708e12778c5d2bec92&scene=126&sessionid=1681314988#wechat_redirect)

作为全球最大的消费类电子产品展览会，CES 吸引了越来越多汽车厂商的关注。2014 年度的 CES 大展有哪些汽车厂商的重头戏呢？

  

如果一年一届的车展向人们展示的是下一年汽车的发展趋势，那么 CES 则会告诉我们 2020 年的汽车是什么样子。近年来，作为全球最大的消费类电子产品展览会，CES 吸引了越来越多汽车厂商的关注。福特、奥迪以及丰田等 CES 常客各家的尖端技术也都是在 CES 上首次亮相的。2014 年度的 CES 将于 1 月 7 日开幕，请大家注意，本届的汽车科技领域的重头戏将是：自动驾驶技术。

  

自动驾驶是目前各大厂商都在发力研究，关注度仅次于电动化的一个领域。在 2013 年里，我们已经了解到日产、奔驰、奥迪等厂商，均要在 2020 年这个时间点推出自家的全自动驾驶汽车。目前，搭载 Intelligent Drive 技术的奔驰自动驾驶 S500 已经完成了首秀，而日产半自动驾驶的 Leaf 电动车也已经在日本当地取得了上路牌照。除了德国和日本，另一个汽车大国美国，也已经有加利福尼亚、佛罗里达、内华达以及密歇根（审议中）允许自动驾驶汽车上路行驶。在 CES 2014 上，自动驾驶将成为参展的汽车厂商中最热门的话题。

  

首先，奥迪会在本届 CES 展示其最新的自动驾驶技术：向我们展示一辆自动驾驶的奥迪，是如何在乘客下车后自发寻找停车位驻停的。在上一届 CES 大会上，奥迪的高管曾对外展示了他们所研发的自动技术相关的硬件设备，包括类似于 Google 自动驾驶汽车所采用的类似的传感器阵列等。而本次 CES，奥迪将演示实实在在的自动驾驶。

  

然后是福特，一家看起来很具备互联网基因的汽车公司。本次 CES，他们展示的重点并不是自动驾驶，而是 V2X 技术。V2X，即 Vehicle to Infrastructure，车辆与基础设施之间的通讯。与之对应的一项技术叫做 V2V，即 Vehicle to Vehicle，车辆间通信。福特将向我们演示，V2X 技术是如何向驾驶员预警另外一辆车的行为的。V2X 虽然不是自动驾驶技术，但却是自动驾驶汽车不可或缺的辅助技术，也是汽车智能安全的基础技术。

  

说到奔驰，大家一定最期待全新 S 级的自动驾驶。本次 CES，奔驰的重头戏仍然与自动驾驶有关，那就是 Steering Assist 系统。这套系统并不是纯碎的自动驾驶，但在车辆行驶较慢的道路上，这项技术能发挥出自动驾驶的效果来。最重要的是，与我们期待的全自动驾驶的奔驰 S 级不同，这项技术离我们更近，已经被集成到全新的 S500 车型中。

  

当然也少不了零部件供应商的参与，比如德尔福（Delphi）。据悉，德尔福将在本次 CES 2014 上向我们演示一件非常酷的技术：一辆配备 Autopilot 自动驾驶系统的 Tesla Model S。此前 Tesla CEO Elon Musk 曾对外表示自动驾驶的 Tesla“不可避免”，而且目前也正在研发这一技术。幸运的是，很快我们就能看到自动驾驶的 Model S 会有怎样的表现了。

  

再一个就是丰田。不过本次 CES 上，丰田不会展出自动驾驶技术（尽管已经具备相应的技术成果了），也不会是电动汽车，而是其最热衷的氢燃料电池汽车 FCV。不过这似乎没有什么新意，因为 FCV 概念车在今年 11 月份的东京车展已经亮相过了。

  

接下来是安吉星（OnStar）。本次 CES，安吉星将演示集成其最新数据服务的雪佛兰 Corvette。当然，最令人期待的还是安吉星的 App Shop，据说可以让驾驶员在上面选择各类应用。从名称上来看，这应该是一个车载应用商店。2013 年初，通用曾宣布，为了增强车内移动互联网的使用体验，新款的车型中将集成 4G 网络连接。顺便提一句，奥迪曾在洛杉矶车展宣布其 A3 车型会集成 4G 连接，所以此次 CES 我们或许会看到这一技术的应用。

  

除了上述这些厂商外，对于汽车领域的新技术，我们还可以期待马自达的 OpenCar（一项类似于福特 AppLink 的开源车内互联平台）以及伟世通（Visteon）最新的中控台显示技术。
