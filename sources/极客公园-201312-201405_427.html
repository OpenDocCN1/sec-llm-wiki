李书福论战王小川：IT 与汽车，谁会革谁的命？

原文：http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&appmsgid=100106142&itemidx=2&sign=8b4c17847460a39b718af91f667bea48&scene=126&sessionid=1681314991#wechat_redirect

在汽车工业里，如果被动安全是 1.0 时代，那么主动安全就是 2.0 时代。不过，在以互联网为代表的 IT 行业开始逐步渗透进汽车这已经有 128 年历史的传统行业中时，所谓的汽车安全 3.0 时代也已经拉开了序幕。从减少伤亡数量，到降低事故几率，我们下一步期待的，就是避免事故发生。要做到这一点，汽车不得不借助互联网的基因。


在 2013 年度（第二界）汽车安全论坛上，吉利汽车、沃尔沃汽车董事长李书福与搜狗 CEO 王小川，就汽车与互联网在汽车安全领域的融合进行了激烈的论战。


IT 要想革汽车的命，可能吗？


传统汽车制造商都有些固步自封，缺乏创新。而互联网产业则或许能给这个汽车行业带来新的活力。看到 Tesla、Google 等汽车行业搅局者，如何提升汽车的用户体验，这责任似乎也推到了互联网人身上。


在 2008 年，搜狗与一家全球顶级汽车制造商达成了合作，搜狗输入法将被移植到后者的汽车平台上。这看起来是美事一桩，可以帮助搜狗扩展平台，但实际上却遭遇了重重瓶颈。最大的障碍，就是汽车行业做研发的周期，比互联网行业要长得多。当搜狗的团队几个月就能完成新产品的研发时，而汽车公司的研发周期则要以年单位。


这大概是互联网公司与汽车公司在硬件平台上合作，所遇到的最意料之中的阻碍。“这个使得我们对汽车厂产生了畏惧，包括后来的导航等等技术我们都绕着走。”王小川说道，“现在手机的导航体验已经远远超过了车载的屏幕，在数据的更新升级，在语言的播报，在周边信息查找里面，手机现在的导航服务远远超过了车载的能力，这是互联网公司本身的基因所在。”


由于在用户体验上存在着巨大的差距，所以互联网公司与汽车厂商的合作存在一种无法避免的“断层”。针对这一点，王小川在李书福面前丝毫不客气，说一定要“倒逼”汽车厂商，即通过互联网产品的用户体验反过来影响汽车，把主动权握在自己手里，而不是被框在车企的思维里。“以前我们找汽车厂商要求做定制，但我们发现这样就把我们互联网的理念打破了。（因为）我们以前是以用户为中心，但是一定制，就变成了以厂商的裁决人员为中心。要用互联网的理念和思维消灭汽车厂商。”王小川说道。


王小川的这番言论，一是点出了汽车厂商在进行产品研发时反射弧太长；二是点出了由于用户体验的差别，互联网公司开始“倒逼”汽车厂商，摆脱框架的束缚。


未来汽车就是四个轮子加一台计算机


针对 IT 公司与汽车厂商之间的关系，李书福觉得，王小川所谓的“倒逼”其实就是革命，因为“这个倒逼可以把人逼死，把一个行业逼跨”。“如何面对这场革命和面对这么一个倒逼的一个现象，汽车公司如何更早的更好的做出反应，更加科学主动的融入这场倒逼的革命潮流当中去，这个首先我们要思考这个问题。”李书福讲到。所以说，作为传统汽车厂商的一个代表，李书福也是间接认可了王小川的说法，即汽车厂商在创新上的固步自封，必须要主动引入互联网的基因，避免被“逼跨”的命运。


那么当互联网的基因渗透到汽车厂商后，汽车未来会朝着一个什么方向发展呢？李书福给出了一个极端的预测：“四个轮子加一台计算机，然后加一块大电池。”这样看似荒诞的说法，仔细思考一番，倒也是不无道理。现在汽车的电动化进行已经开始，未来毫无疑问燃油汽车会被新能源汽车所取代。电动汽车的出现，将进一步加快汽车模块化的进程，最终车辆的构成就只有底盘、电池、车轮以及计算机了。汽车的发展，将逐渐互联网化。


“我想这个是跑不了的。至于说这个时代什么时候到来？确实看看你们 IT 行业倒逼力量有多大？你逼的速度有多快？你怎么个逼法，这个很重要。”李书福对王小川说道。其实李书福所说的目前已经有了案例，那就是 Tesla。在他看来，Tesla 这家公司“特殊的市场，特殊的时代，所产生的特殊的产物。”虽然目前 Tesla 的份额还很低，但它代表了未来发展的方向。


同时，在互联网技术的辅助下，汽车的安全性也会进一步增强。目前汽车还是由人驾驶，而当未来汽车实现了智能化之后，计算机将接管这个庞大的机械体。按照李书福的话讲，汽车会变得像篮球一样灵活，“想到哪就滚到哪”。谈及智能汽车，李书福特别提到了沃尔沃的 XC90 车型。据他透露：“明年投放市场的 XC90，要实现高度的智能化。”


面对“倒逼”的问题，李书福首先承认了汽车厂商在创新层面存在弊端，但似乎也并未把希望寄托在 IT 企业身上。从他对未来汽车发展的终极形态的预测来看，这一步步都下去，缺少不了 IT 企业的支持（因为关键部件就是计算机），但车企自身积极地做出反应还是最重要的。

电脑能不能接管汽车？

李书福认为，未来汽车的将由电脑操控，而驾驶人将得到彻底的解放。不过一谈及自动驾驶，与期待满满的李书福相比，王小川却有些失望。今年在试乘了一辆自动驾驶的汽车后，他表示自动驾驶汽车的体验“并不舒服”。

王小川列举了两种情形。其一是这辆自动驾驶汽车在正常行驶时太过于保守，留下了较大的车距，“我估计是它认为前面的车随时可能会停下来”。其二是在遇到红灯时，理应在前车的一段距离之前就提前减速刹车，而自动驾驶汽车则认为前方 100 米没有障碍，变得“很激进”，“冲到快跟前的时候才刹车”。所以，王小川认为，真正拥有舒服体验的自动驾驶汽车还是离我们很远的，需要长期的积累。


在听完王小川讲述的经历后，作为沃尔沃董事长的李书福按捺不住了，他反驳道：“小川刚才说的自动驾驶，那一定是假冒的。你自动驾驶的前提比人开的要好，你刚才讲的这些技术沃尔沃三年之前已经应用了，其他汽车厂跟在屁股后面。”


虽然试乘自动驾驶汽车时并没有良好的体验，但王小川还是十分期待沃尔沃的 XC90 会又怎样的表现。像李书福说的，明年上市的新 X90 会实现高度的智能化。相信在汽车安全领域拥有几十年经验的沃尔沃不会让王小川再度对自动驾驶技术失望。尤其是智能驾驶方面，沃尔沃的 CitySafety 已经做得比较出色了。


汽车与 IT，哪个更复杂？


易道用车的 CEO 周航提出了一个看法，那就是现在的汽车做得那么复杂？这种复杂，主要体现在当前的汽车没有一套一体化的计算能力，也不是一个一体化的架构。他还认为，目前汽车上还存在大量的空间可以集成各类传感器做统一运算。“汽车本身是应该有巨大的空间去容量多传感器的，不管车内传感器还是车外传感器还是设备传感器”，周航说道，“传感器的拥有量如果是现在的 N 倍，可能会成为真正的智能汽车。”主持人说这是来自 IT 界人士的“一个忠告”。


对此，李书福做出了反驳。他认为汽车并不复杂，真正复杂的是 IT。“现在全世界，换人类都在联合研究人的大脑思维技术，这是人类到今天为止最后要攻克的难关，至于四肢啊等都研究透了，脑子没有研究透，你看上去是四肢啊很复杂，其实不是的，最复杂的是脑子，汽车也是一样的，但是它再复杂也复杂不过 IT，IT 太复杂了。”李书福如是说。


就在李书福与周航针锋相对时，王小川表态了。他觉得，讨论汽车与 IT 谁更复杂的问题是没有意义的：“汽车复杂还是不复杂已经不重要了，你就看这个结果里面谁能够让用户真正在里面得到这样一个实惠，让他用起来爽，不管是收费还是免费。”所以，产品的复杂程度不是关键。关键的是，产品的最终的使用体验要让用户爽起来。


我同意王小川的观点。其实汽车与 IT，谁更复杂这个问题要从不同的角度考虑就会得出不同的结论，但至少在用户体验上看来，汽车界还是要向 IT 界学习的。无论怎样，最终服务的都是用户，复杂与否，用户体验提升了即可。


当汽车厂商有了大数据，会去做 IT 吗？


要把互联网基因注入汽车企业，就要充分理解 IT 企业的精神。概括一下，无非就是两点：一是用户体验至上，二是用数据说话。对于沃尔沃来讲，自动驾驶和智能交通都会积累出大数据，而这些数据是互联网公司所不能抓取的。那么李书福领导下的沃尔沃，会试水 IT 大数据吗？


李书福的回答也在意料之中：“20 年前福斯特、通用都在搞 IT，因为那个时候 IT 刚刚开始，他们希望在这个领域里面有所发展，然后来帮助自己的行业有所发展。作为一个企业来讲一定要做的很专，汽车公司就是汽车公司，IT 就是 IT，你想把这两大行业都吃下来，管理层就分心了，一分心，两个都搞不好，或者说一个都搞不好。”


总之，李书福认为，汽车行业与 IT 行业之间，不必非得争个你死活我，最重要的是相互依存以及合作。如何把汽车与 IT 更好地融合在一起，使人们的交通更加便捷，这才是最核心的问题。我们今后要从狭义的理解进入广义的理解，或者从广义的理解融入更多的行业，使更多的行业和汽车这个行业融在一块，为人类的行，以及工作、生活更好的融合在一起，使汽车给人类带来更高级的享受，这才是大家共同追求的。


关于汽车企业做 IT 或者 IT 企业做汽车，我们也见过不少的先例。比如两家韩国公司为例：现代汽车也生产一些消费电子产品，但品牌影响力远不如三星；而三星旗下也有一家三星汽车（与雷诺合资），但知名度也远不如现代。所以，对于汽车企业与 IT 企业来说，专注是最重要的。对于搜狗来讲，如果我们期待王小川会向汽车圈发力的话，日益智能化的中控系统或许是第一个着陆点，因为任何平台上的操作系统，都离不开输入法的支持。
