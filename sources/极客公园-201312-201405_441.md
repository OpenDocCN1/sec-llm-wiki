# Automatic：汽车的智能插件与省油利器

﻿本文编译自 wired 作者系 Joseph Flaherty

  

当我们开车的时候，由于对油门刹车不合理的控制，一年下来，因为这些简单的事情就能将你的钱包削薄好几层。全世界的有车一族，回想一下，刨去获得驾照前那几个月的培训，是否还有其他机会获取有关驾驶相关的知识？就这样因为伴随在身上一些不正确的坏习惯，平白无故投掷了大把学费——也许你自己不曾察觉。

  

不过幸运的是，旧金山一个叫做 Automatic 的公司发明了一种同名工具，最大的特色就是能够通过调整驾驶习惯帮你节省燃油，以及即时提供发动机信息，可谓有车一族的福音。当你将这款车载插件静悄悄的安置在你车里的 OBD-II 端口上后，通过蓝牙连接苹果手机或者安卓设备上与其相关的 APP，它就能能在手机屏幕上显示汽油、车速里程和发动机的相关信息。

  

![](../Images/d04708318ac366c983040cf6c030dc30.png)

  

尽管单单收集这三方面的信息还是没办法搞清一个人的驾驶习惯，不过 Automatic 通过这三项指标及对发动机运行效率的数据收集，不断修正人们的驾驶习惯，平均就能帮司机们省去 30% 的油钱。 听起来不可思议？那么看一下 Automatic 的大致功能。

  

**速度提醒**

  

让人重新学习良好的驾驶习惯还算简单，可是当你驾驭一辆马力十足的汽车时，也许眼睛一眨时速就超过了 120 迈。窗外的风景尚且没有看够，谁有心情不时低头喵时速表？而 Automatic 的解决办法是，在驾驶途中，这个小玩意会不时发出三种清脆的提示音，让你随时知晓在速度与激情中——由于不正确的加速与刹车，在排气管里又多排出了不少多余的油钱，这听起来是不是有点像在玩赛车游戏。

  

每个驾驶员都觉得自己的车技不是盖的，尤其是那些在喜欢在街上横冲直撞的事逼司机。——Miljkovic（Automatic 的创始人）

  

**提升发动机效率**

  

这款工具虽然隶属机械类，背后却包含斯坦福教授 B.J. Fogg 提出的一个叫 Behavior Model 的理论，帮助你将发动机的效率发挥至最大化，其实就是利用上一条对司机驾驶习惯的规范带来的直接好处。举个实例更明了的解释：如果你下班的途中通过 Automatic 的提示调整速度，也许你到家的时间会比平时晚 5 分钟，但是这样一个月下来却能够省掉 50 美元的油钱。

  

平均每个人每年在汽油上的花销竟然高达 3000 美元……人艰不拆。——Miljkovic

  

**故障自检**

  

Automatic 还有一些你平时不希望发生——但却至关重要的功能。万发生了车祸，Automatic 会将当事人的位置以短信形式发送给他的家人，并通过电话为其提供现场协助。另外用户也可以随时通过手机知晓发动机是否需要即时维修。

  

我很高兴，人们在 1998 年的老款雅阁中能够拥有跟当下中高端的奔驰车一样的功能。——Miljkovic

  

![](../Images/433f89597b2e36d4da535ab603e73a0d.png)

  

还有一点，当用户停车加油时，Automatic 会使用地理定位数据来判断距你最近的加油站，然后再使用自己的数据库和每日价格信息来计算用户需要支付的金额。虽然只是个小功能，却体现了 Automatic 的智能化与贴心。当大多数 APP 设计者还沉迷在提升体验的流畅度和下载的极速感时，Automatic 团队已在极力开拓更具野心的事业——用 APP 做作为他们的工具来重塑人类行为。这需要在科学技术和人文心理两方面达至精巧的平衡。不仅界面的操作要流畅，而且在纠正驾驶员们坏习惯的时候也不能让他们感到不爽。

  

最后，最重要的信息，Automatic 的售价为 99.95 美元，兼容所有 1996 年之后出产的汽车。
