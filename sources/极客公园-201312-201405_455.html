前几天我去一间酒吧喝酒，发现旁边椅子上有一个36cm*43cm*15cm 的箱子，上面印着小米科技的 Logo ，心想，这种大小的包装，到底是小米的什么产品？趁旁边的人没注意，我把箱子迅速收在我口袋里，带了回家。我想，这应该是小米的某位工程师喝醉了酒，把产品落在酒吧里了。


以上故事纯属虚构，如有雷同，肯定不是我和小米的公关同学一起杜撰的。


小米路由，从官网上线到现在，已经收到数十万个公测申请，但事实上，小米只准备了500台工程机。而我有幸拿到了编号为0234的机器，因为是工程机，按照小米的套路，想必是要让发烧友作为第一批用户的，而发烧友最爱干的事就是，折腾，所以……

二、易用性测试


虽然工程机是面向发烧友的，但在正式推出市场时，小米路由还是要面向一般用户。


对于普通人来说，设置路由是一件很头疼的事。虽然大多数男性极客都希望路由的配置越麻烦越好，这样便于他们更多地接触女神（们），但对于小米来说，它必须将路由做得足够简单，因为很可能这款路由是你奶奶第一款会自己配置的路由。


一个小米员工曾经跟我说，“我老婆基本上是 IT 白痴，有一次我把小米路由拿回家让她玩，她居然自己配好并能上网了，然后我们就愉快地做爱做的事去了”。


怀着对这名小米员工半信半疑的态度，我从2种方式测试了路由的首次使用易用性。


1、家庭拨号接入方式




我的操作步骤是这样的：

  • 插上路由电源

  • 在电脑WiFi 里搜索小米路由并连接

  • 连上路由后在浏览器打开 miwifi.com

  • 在接下来的界面里设置了运营商的帐号和密码

  • 在接下来的界面里设置了路由的名称和密码

  • 自动重启，手动重新连接

  • 可以上网了

2、作为 AP 接入


这一次，我尝试全程用手机（Nexus 5）来操作。



操作步骤是这样的：

  • 插上路由电源

  • 在电脑WiFi 里搜索小米路由并连接

  • 连上路由后在浏览器打开 miwifi.com

  • 在接下来的界面里设置了路由的名称和密码

  • 自动重启，手动重新连接

  • 可以上网了

总的来说，我认为配置的过程还是比较简单的，至少不需要用户去浏览器敲让人费解的 192.168.1.1。


但是，对于少数人来说，配置过程可能不太流畅。如果你的手机或电脑默认是连着代理的，你的浏览器可能打不开 miwifi.com ，这时，你是无法对路由进行初始化的。


另一个需要小米路由团队去解决的问题是，如何在路由重启后，让用户更“傻瓜化”地连上路由。因为当路由初始化后，路由的名称很有可能变了，用户需要重新选择新的 SSID 进行连接，或许对于熟悉电脑的人来说，这不会是个问题，但对于普通大众来说，或许可以寻找一种，如前文所说，更“傻瓜化”的方式让他们“无缝地”使用路由。


三、功能测试


和传统的路由一样，小米路由提供了 Web 管理界面，里面的功能可以梳理成以下结构图：



挑几个有趣的功能说一说。


1、简单友好的后台


作为苹果 AirPort 的使用者，我认为苹果的路由配置界面是非常友好的。从极路由开始，新一代的路由，在界面和用户体验上都下了不少功夫，让用户感受到自己其实不是个专业网管，而是个普通的网民。小米路由的后台也是如此，大大的文字、留白、图形化设计，没有太大的特色，但也没有让人感到不舒适。小米路由的 Android 客户端界面也挺友好的，如图：



2、支持小米帐号登录，远程管理


从前文的功能结构已经可以看到，小米路由支持小米帐号登录，这是为了便于远程管理。远程管理除了可以查看路由的参数之外，还可以让路由进行远程下载等。



3、内置 1T 硬盘，支持 USB 扩展


我拿到的这款路由是带2.5 寸1T硬盘的，同时路由后面还带了一个 USB 插口。除了可以和局域网内所有的设备共享硬盘外，还可以远程让路由在家下载电影等。显然，运营商会不高兴的。


4、插件模式


和极路由等一些之前已经推出的“智能路由”类似，小米路由支持插件模式。默认的插件有小米应用商店加速、苹果 App Store 加速、路由备份、迅雷云加速等。



可以想象，未来这会是小米路由很重要的一条战线。


5、路由备份功能


地球人都知道小米和金山的关系，如果不知道，可以搜一下雷老板的简历。小米路由的插件里有一款“路由备份”的应用，开发者显示的是“金山云”。购买小米路由的人会被赠送100G 的金山云空间，只要往硬盘里的“路由备份”区存储文件，这些文件就会被同步到金山云。


6、与迅雷紧密合作


除了给用户赠送一年的迅雷白金帐号之外，小米路由还支持通过迅雷云播下载电影。试想一下，你在办公室里通过远程管理的方式让小米路由在家下载电影，路由随即通过迅雷网络进行下载，你回到家就能观看。



似乎，小米与迅雷的关系非同一般。


根据这个功能，我们有理由猜测两件事：

  • 未来小米路由的所有下载行为很有可能都通过“迅雷离线”进行

  • 小米路由可能会支持各种通用的下载协议和下载通道（工具）

7、路由快连功能


目前，这算是小米家族设备的特权。


如果你全家使用的都是小米设备，那么，小米手机、小米电视和小米盒子等终端将可以无需输入任何 WiFi 密码即与小米路由直接连接。是否允许这些设备使用你的路由，只需要在手机客户端上点一下“允许”按钮。


8、DLNA 方式共享文件


小米路由自带的硬盘，可以通过 DLNA 的方式将文件共享到局域网。小米家族的设备均默认支持。对于普通 Android 或 iOS 设备，可以通过安装一些第三方软件，来查看局域网里的 DLNA 网络，并播放共享出来的视频等。


听起来很复杂，其实大多数时候，用户不需要关心这些属于。



9、支持 LAMP


这是让我很兴奋的功能，根据测试，目前这项功能并未完全开放。


小米路由自带了一整套 LAMP，也就是 Linux+Apache+Mysql+PHP。换句话说，你可以在小米路由上搭建一个网站，比如搭建一个基于 Wordpress 的博客。


如果你的路由公网 IP 是固定的，那其实你相当于有一台服务器了，将域名绑定到这个公网 IP，接下来你将能轻松地让外界访问你共享到网站上的爱情动作片，等等等等。


如果你的路由公网 IP 是动态的怎么办？


我也不知道会怎么办，或许小米未来会给用户分配一个动态变更 IP 的三级域名？


四、不止是路由


作为第一代产品，小米路由确实是够发烧级的，CPU 双核1G，内存 256 M DDR3，1T HDD 硬盘。支持11ac WiFi 。


据我所知，互联网大公司们都在开发他们的路由器，各个公司开发路由的原因都不太一样，有些可能认为握住路由这个流量入口，让用户更“安全”；有些可能为了获得用户的行为数据；有些可能希望将路由打造成“个人私有云”，通过一片一片的私有云，组建一个更大的云天空。


小米路由的定位在哪里，战略是什么，这里先不做探讨，但如果你仔细看了这篇文章，其实你已经能看出一些线索。


不管如何，在路由器上，互联网公司必有一仗。
