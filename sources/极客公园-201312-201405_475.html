汽车之家在纽交所上市

来自腾讯科技：

汽车之家周三正式在纽交所挂牌交易，开盘价 30.16 美元，较 17 美元发行价上涨 77.4%；收盘定格于 30.07 美元。以收盘价计算，汽车之家市值约 31 亿美元。IPO 之后汽车之家创始人李想持股比例为 4.9%，CEO 秦致持股 3%。以此计算，李想身价 1.54 亿美元，秦致身价约 9400 万美元。


【点评】看看人家汽车之家的年终奖。

微软考虑砍掉 WP 和 Windows RT 授权费

来自网易科技：

微软从 Windows Phone 授权商获取利润，但诺基亚占到 Windows Phone 阵营 80% 的市场份额，微软收购诺基亚手机业务之后，就失去了 Windows Phone 授权费中的大头。微软操作系统主管特里-梅尔森正在慎重考虑是否向设备厂商免费提供 Windows Phone 和 Windows RT 操作系统。免费版的 Windows RT 和 Windows Phone 可能会推动设备制造商生产更多的产品，转而提升开发者的兴趣，为这些平台打造应用。


【点评】收购诺基亚之后，微软 Windows Phone 授权费也没的收了。

雅虎邮件宕机 梅姐亲自道歉

来自腾讯科技：

雅虎邮件服务最近几天一直问题不断，自周一以来，雅虎邮件的宕机问题一直没有完全解决，一些用户也因此受到了影响。此次宕机主要是由雅虎一座邮件数据中心的硬件问题引起。针对此宕机事件，雅虎的首席执行官玛丽莎·梅耶尔通过 Twitter 向用户道歉。


【点评】梅姐亲自道歉，怎么忍心不原谅。

亚马逊发布网购趋势报告

来自网易科技：

昨日亚马逊中国正式揭开“亚马逊美好生活秀”的序幕，同时亚马逊还发布了 2013 年网络购物趋势报告，从网购人群、网购品类、地域以及移动购物方式四个方面揭晓了中国的网络购物趋势。

  • 趋势一：网购人群多样化是长期趋势，男性和年轻人群体占据消费主体。

  • 趋势二：购物品类呈现多元化发展。

  • 趋势三：地域分布日趋广阔。

  • 趋势四：移动端购物高速成长。

【点评】其实这趋势，不用亚马逊发布也能看出来。
