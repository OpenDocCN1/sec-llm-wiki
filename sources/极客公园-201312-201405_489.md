# 手把手教你如何打造极客老爸

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&appmsgid=100098811&itemidx=2&sign=1c79a6d5516487961147f15e4eaa73f0&scene=126&sessionid=1681314997#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&appmsgid=100098811&itemidx=2&sign=1c79a6d5516487961147f15e4eaa73f0&scene=126&sessionid=1681314997#wechat_redirect)

这是一名从事 IT 行业的人员写给老爸的 Mac 使用说明，内容翔实，解释详细。另外本篇文章的头图就是作者的 Macbook，至于他那位极客老爸，就在文尾啦。

  

买了新款的 RMBP，服役了好多年的小白终于退役。本来是准备二手卖了。后来老爸说要，于是就给他寄过去了。

  

老爸 1999 年的时候跟我一起去电脑学校学电脑，我从第二台个人电脑开始就转用 Mac 了（现在已经是用第 5 台了），而老爸用了这么多年还是 PC。肯定用不惯 OS X 系统，于是我用 Keynote 写了这个文件，取名叫：“我是教程—双击打开我”，扔在它的桌面上。
