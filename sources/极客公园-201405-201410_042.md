> > \[核心提示\] 上线五年的 WebQQ 今天宣布下线，这背后到底有着怎样的意味？
> 
> 如果你在今天访问 WebQQ，会发现已经变成一个告别页面。
> 
> > 相聚有时，后会无期。2009 - 2014，走过许多风雨，依然无法陪你一生。。。
> 
> WebQQ 上线的五年时间，经历了从客户端到网页，再从 PC 端到移动端的转变。它本身就是腾讯在自身战略和产品技术的一次大练兵，也为腾讯在网页端复杂交互的技术储备提供了支撑。
> 
> ## 长达五年的实验品
> 
> 五年前上线的 WebQQ，被看做是腾讯作为一家技术型产品公司做的前沿尝试。在此之前基于 Web 的交互级产品都处于尝试阶段，并没有大公司主动跟进。
> 
> 腾讯在 WebQQ 产品上，融入了即时通讯、QQ 音乐、网页浏览器等功能。最重要的是支持跨平台，支持 IE、Firefox、傲游、Opera、Chrome、Safari 等多种浏览器，不论在 Windows 还是在 Linux 系统下，都能满足大家随时随地上 QQ 聊天。
> 
> 这在腾讯初期多平台覆盖不足的情况下，提供了一种变相的解决方案。此外由于 WebQQ 基于网页技术，也受到了大量封锁 IM 通讯的外企员工欢迎，只要能打开网页就能上 QQ。
> 
> 由于使用 WebQQ 的用户可能经常使用公用电脑，他们还给用户提供了自定义表情漫游、聊天记录七天漫游的功能，这极大程度上满足了大量网吧党的聊 QQ 需求。
> 
> WebQQ 最大限度地减少了电脑性能或操作系统对用户的限制，特别是对于喜欢简洁高效的商务用户，以及那些临时在境外、酒店、机场或咖啡吧使用公用电脑的用户来说，WebQQ 在确保安全性的前提下大大提高了使用效率。
> 
> 此外，在 webQQ 3.0、Q+ 的版本上，腾讯开始大规模引入第三方应用打造 Web App Store，包括音乐、小说、办公、资讯等服务。这应该是国内首款，大规模推进开放平台的 Web 产品。
> 
> ## 功成身退的先头军
> 
> 这五年时间发生了很多变化，首先腾讯利用 WebQQ 测试开放平台的目的已经达成，而覆盖更多产品的「腾讯开放平台」已经成为主导。
> 
> 第二是腾讯在多平台覆盖上取得进展，无论是拥有基本功能的 Linux QQ，还是持续更新的 Mac QQ，都已经对腾讯之前在多平台覆盖的不足进行了改善。
> 
> 第三网页技术存在的局限性，WebQQ 是在 HTML5 尚未普及的情况下上线的，采用了大量的 JS 、Ajax 来完成复杂交互。但在 PC 产品持续演进的情况下，WebQQ 要实现同步演进需要更多的成本，而且排查维护要更困难。
> 
> 体量不够大，也不能赚大钱，维护成本还高，结果也就可想而知了。
> 
> 最后，也是最重要的一点。即时通讯的重心已经从 PC 转移到移动端，腾讯已经成功打造「手机 QQ」与「微信」的双雄制霸，而且移动市场无论增长潜力、收入潜力都远高于 PC，所以仅仅是作为 PC 领域补充者的 WebQQ 停摆也就不足为奇了。
> 
> 总结 WebQQ 的功成身退：使命已达，把接力棒交到下一个选手。
