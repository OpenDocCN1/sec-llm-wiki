## iPhone6 尚未获得中国入网许可?

  

来自：新浪科技

  

新华社报道称，苹果公司的iPhone6在中国通过了一项关键的监管障碍，但仍未获准在中国销售。这是中国官方首次暗示苹果最新款手机在其最重要市场之一延迟发售的原因。上周早些时候，苹果公司仅表示，iPhone6首日发售地区不包括中国，但没有解释延迟的原因。

　　

iPhone6已获得监管机构批准使用国内频率，但它仍需获得一项入网许可牌照，然后才能在中国销售。苹果公司拒绝置评。

  

**点评：** 这个大家已经已经心照不宣的原因就差得到官方认可了。

## 爱立信退出手机芯片领域

  

来自：新浪科技

  

爱立信日前宣布将停止芯片开发，并表示将部分投资转至无线网络领域。“芯片市场亦面临着竞争激烈、价格侵蚀以及技术创新不断加快的种种挑战。”在媒体发来的邮件中，爱立信认为，要在这个瞬息万变的市场获得成功需要进行大量的研发投资，因此，爱立信作出上述决定。

  

**点评：**爱立信在芯片市场的战线收缩是否意味着客户对该产品市场竞争力的质疑呢。

## Chromebook或逐渐取代 Windows 笔记本

  

来自：cnBeta

  

目前，由于谷歌控制着移植平台 App Runtime for Chrome，应用开发者不能直接把安卓应用移植到Chromebook上。目前，谷歌只向Chromebook移植免费的安卓应用，因为两种平台收入分成协议不同。Google Play应用商店中开发者的分成比例是 70%，Chrome Web Store 应用商店中开发者的分成比例是 95%。

  

谷歌首批向 Chromebook 移植了4款安卓应用——Vine、Evernote、Duolingo 和 Sight Words。将安卓应用移植到Chromebook 是谷歌在6月份的I/O开发者会议上公布的一项计划的一部分，目的是消除安卓和 Chromebook 之间的壁垒。

  

**点评**：安卓和 Chrome OS 融合，微软将面临不小的冲击。

## 英特尔无线充电碗年底开售

  

来自：腾讯数码

  

英特尔总裁Brian Krzanich日前宣布，他们在今年CES展上展示的智能无线充电碗将在年底正式发售。

  

在今年年初的时候，这款无线充电碗只不过是一个概念产品而已，但外界对其展现出的兴趣让英特尔把它变成了现实。这款设备背后的理念非常简单：不少人会在门边放置一个碗碟来盛放车钥匙等小物件，而这款无线充电碗就是在此基础上进行的升级。

  

**点评**：放在碗里怎么边充电边玩手机呢？
