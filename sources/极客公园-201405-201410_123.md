> > \[核心提示\] 4 款应用作为试点登陆 Chromebook，这会成为你购买 Chromebook 的理由么？
> 
> 谷歌在 Chrome 博客上宣布第一批 Android 应用已经正式登陆 Chromebook。这些应用保持了手机或平板上的浏览方式，而你此时除了像使用移动设备一样使用 Chromebook 的触摸屏像进行操作，还支持通过鼠标和键盘来代替操作。
> 
> 这 4 款应用作为首批试点应用登陆 Chromebook ：
> 
> *   Duolingo：免费的语言学习软件
>     
> *   Evernote：笔记软件
>     
> *   Sight Words：幼儿阅读学习应用
>     
> *   Vine：短视频应用
>     
> 
> 该项目由 Chrome 和 Android 的负责人 Sundar Pichai 在今年 7 月份的谷歌开发大会 Google I/O 上宣布未来在 Chromebook 上将能运行 Android 应用，该计划被命名为 App Runtime for Chrome。
> 
> Pichai 表示将 Android 应用迁移到 Chrome 平台只需要一点点技术支持，以及稍加调整一下界面即可。几个月过去了，谷歌还是在单独和这些开发者们一一对接，希望这些即将发布的应用不会让我们等得太辛苦。
> 
> ## TNW：Android 用户有了购买 Chromebook 的新理由
> 
> 对谷歌来说，将数以百万 Android 应用移植到 Chromebook 上不仅能快速扩充现在 Chromebook 上应用贫瘠的尴尬，同时将 Chromebook 和 Android 设备更加紧密地联系在一起。
> 
> 我们可以畅想一下未来，当你的手机电池耗尽时，信息通知还能直接在 Chromebook 里推送出来。
> 
> ## The Verge：多加入一些没有网页版的应用吧
> 
> 说实话，目前上线的这 4 款应用没能给我带来惊喜，这些应用在各个移动端上已经覆盖了本地应用，同时他们也提供了强大的网页版。
> 
> 目前 Chrome OS 选择的本地应用虽然能帮助用户解决基本问题，但依旧有很大的局限性。Chromebook 主打低成本市场，通过 Android 给 Chromebook 输血显然十分划算，避免了构建新生态圈的麻烦。
> 
> ## Arstechnica：Android 和 Chrome OS 的相似性为该计划提供了便利
> 
> 谷歌承诺不会有太复杂的迁移技术成本，他们似乎通过本地客户端将 Android 内部框架装载到了 Chrome OS 中，这两个操作系统都是基于 Linux，使用库，和 App 框架，我们猜测他们是否使用了 Dalvik 和 ART。
> 
> 这些 Android 应用在桌面上的显示效果和其他为 Chrome 专门制作的应用类似，用户可直接在 Chrome Web Store 上直接下载。如果说虚拟机有什么好处，谷歌给我们做了很好的示范。
> 
> ## CIO.com:希望谷歌能打动开发者
> 
> 实际上这已经是谷歌为 Chrome 做的第二次招亲计划，去年谷歌推出了 Chrome Apps，鼓励开发者利用 HTML5 和 Javascript 为 Chromebook 提供例如离线支持，桌面通知以及 USB 外设支持等。但没能引起开发者太多关注。
> 
> 不过即便这次谷歌的努力获得了成功，也无法避免现在应用在各个平台割裂的使用体验，如果这次谷歌能将众多开发者揽入自己的旗下，想必以后大家就不会再说 Chromebook 就只是一个浏览器笔记本了。
