[核心提示] 假设这次收购成真，将是私密社交鼻祖 Path 的重生之路，也会是苹果打造高逼格社交平台的开始。

当 Path 已经渐渐消失在我们的视野中时，一条收购信息又让它重新袭入我们的记忆里。

美国媒体 Pando Daily 最先报道，苹果或将收购曾经大热如今已经走了多年下坡路的社交应用 Path。该媒体引用内部消息称，苹果与 Path 的收购交易「基本上已经敲定」。让其可信度增加的蛛丝马迹是，Panda Daily 发现 Path 的首席执行官莫林（Dave Morin）出现在苹果新品发布会现场的第一排，而第一排通常只为苹果高管预留。当天，Jony Ive 就和刚刚加入苹果核心设计团队的著名设计师 Marc Newson 坐在一起。

然而，当媒体向莫林进行求证，莫林表示：「我们不会对谣言和猜测进行评论。」通过他拒绝发表评论的态度似乎间接证明，这一消息也许只是谣言，苹果进行收购的可能又微乎其微了。

坦白的说，苹果将收购社交网络 Path 的消息来源并不权威，而 Pando Daily 本身是一家知名度不高的科技博客。外媒也普遍认为这个收购「不太可能」。在美国乃至全球的社交网络市场，Path 已经沦为三流，另外目前已经到了生存困难、苦苦挣扎的阶段。向来擅于制造烟雾弹和神秘感的苹果，并未表态。

假设这场收购真的发生，将会给双方带来什么。

Path：私密社交的重生

在微信以暴雨狂风之势来临之前，Path 曾经是国内一切高逼格文艺小清新们的最爱，大走极简风的页面风格、文艺范儿十足的字体设计都是被宠信的理由。接下来 Path 顺利的登顶 iOS App Store 热门应用榜单，拒绝大佬谷歌的收购邀请，鼎盛期估值曾达 10 亿美元。

它的特点是主打相互认识的好友之间的私密社交，分享内容并不对外公开。注册用户设定 150 人的好友上限，鼓励用户只建立高质量的连接关系。甚至为了极致的用户体验，很早开始就宣布放弃广告盈利这条途径。

不过，在移动聊天工具的势头盖过传统社交工具的背景下，WhatsApp、Snapchat 等工具如日中天，Path 的市场影响力却越来越微弱。目前，Path 的活跃用户规模仅为 1000 万人，和一线社交应用完全不在一个数量级上，而之前，面对阅后即焚模式的成功，Path 也进行了改革，不再长期保留用户的分享内容，转向阅后即焚模式。

放弃广告盈利这条途径后，Path 也一直且行且摸索盈利途径。仿照 Line 依靠销售诸如表情「贴」（sticker）和照片滤镜等虚拟商品进行盈利，不乐观；仿照 Evernote 推出高级订阅服务，让 Path 用户享有特殊的内容、功能和存储服务，依然不乐观；仿照微信，发布一款独立的 message app「Path Talk」，走上社交网络+聊天 app 的道路，其 status 栏里会实时刷新好友的动态——好友是否正靠近你、他正在听什么歌、是否处于 available 的状态等。

今年 1 月，Path 曾展开新一轮融资，当时 Path 估值不到 4 亿美元。缩水 6 亿美元的情况下，苹果的收购也许是它重生的最好机会。

苹果：做高逼格的社交应用

对于苹果而言，虽然从未进入传统的网页社交领域，但是苹果依靠 iOS 生态系统，成功「培养」出了手机聊天工具 iMessage，成为足以和 WhatsApp 竞争的「世界级」聊天工具。据悉，iMessage 目前的月度活跃用户，已经超过了两亿人，而且在全球覆盖了许多的国家。

因此，外媒界纷纷表示，坐拥 iMessage 聊天产品的苹果，在移动聊天社交盛行的大背景下，完全没有必要去收购 Path 这样一个生存都存在问题的三流社交工具。

然后对于擅于放烟雾弹和制造神秘感的苹果，有时候也未必摸得准它的路数。也许它就是想做一款高逼格的社交应用。

稍加回忆就可以，戴着 Beats 家的魔声耳机听 U2，用 Path 分享一天的小确幸心情，曾经是一个文艺时髦青年的标配。而苹果如今已经收购了 Beats，也邀请 U2 助兴苹果发布会了。

因此也有业内人士估计苹果有意将 Path 的功能理念整合到 iMessage 当中，打造一个类似「苹果」独家的内部社交网络。这个概念并不新奇，Google 就曾经打造了一个基于社群和圈子的社交网络 Google +，一度运营的还不错，只是后来慢慢淹没于 Gmail、YouTube 等其他平台的幕后，甚是可惜。

经这么一分析，虽然这笔交易成不成仍然是未知数，但其实可以有。
