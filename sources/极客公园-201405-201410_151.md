> > > \[核心提示\] 在微软任职 16 年的张亚勤今天正式宣布离职，他做了什么，影响了什么？
> > 
> > > > 微软公司今天宣布，微软全球资深副总裁、微软亚太研发集团主席、研究院院长，张亚勤因个人原因离职。
> > > > 
> > > >   
> > > > 
> > > > 另据《南华早报》报道，张亚勤可能加盟百度，担任新业务总裁，直接向李彦宏汇报工作。
> > > > 
> > > >   
> > > > 
> > > > ## 加入微软 16 年：使命达成
> > > > 
> > > >   
> > > > 
> > > > 张亚勤 1999 年加入微软，历任任微软亚洲研究院院长、微软全球副总裁、微软中国董事长、微软全球资深副总裁、微软亚太研发集团主席，负责微软在亚太地区的科研及产品开发工作。
> > > > 
> > > >   
> > > > 
> > > > 张亚勤任职期间，微软亚洲研究院在数字多媒体、多通道用户界面、无线及网络及数字娱乐拥有丰富研究成果，并有多项技术成果转移我们日常用到的 Office、Windows 产品中。
> > > > 
> > > >   
> > > > 
> > > > 张亚勤还曾负责微软 Windows Mobile 以及 Windows CE 平台，分别定位于智能手机和手持 PDA，这两大平台是现在 Windows Phone 的前身。
> > > > 
> > > >   
> > > > 
> > > > 基于此前的工作成果，2006 年张亚勤整合微软亚洲研究院、微软亚洲工程院等多个部门创立微软亚太研发集团。这是微软海外最大的技术创新机构，负责领域包括基本研究、科技创新和孵化、产品开发、以及战略合作。
> > > > 
> > > >   
> > > > 
> > > > 2012 年主导微软创投加速器，在中国互联网产业孵化 88 个科技创业公司，2014 被评为中国最佳孵化器之一。
> > > > 
> > > >   
> > > > 
> > > > 对于自己在微软 16 年的工作经历，张亚勤称：
> > > > 
> > > > > 我用了 16 年的时间，完成了加入微软时对公司的承诺，现在是听从心声、听从新的「使命召唤」的时候。  
> > > > 
> > > > ## 增强百度技术人才竞争竞争力
> > > > 
> > > >   
> > > > 
> > > > 近两年，百度在自身的技术研发上有较大动作。2013 年成立「深度学习研究院」（现更名为深度学习实验室），核心成员包括 NEC 研究院 Media Analytics 部门主管余凯，前 Facebook 资深科学家徐伟，AMD 异构系统首席软件架构师吴韧。
> > > > 
> > > >   
> > > > 
> > > > 2014 年，百度邀斯坦福人工智能实验室主任吴恩达任首席科学家，负责百度研究院工作，百度研究院下设硅谷人工智能实验室、北京深度学习实验室和北京大数据实验室。
> > > > 
> > > >   
> > > > 
> > > > 这些举措，意味着百度将会在基础技术研发上进行大规模投入，同时吸引全球顶尖技术研发人才，加入百度研究院的行列。
> > > > 
> > > >   
> > > > 
> > > > 张亚勤在负责微软亚洲研究工作后，曾吸引大量科学研究人才加入。如果此次张亚勤加入百度，意味着百度在全球技术人才竞争中又下一城。
> > > > 
> > > >   
> > > > 
> > > > 张亚勤此前在与极客公园创始人张鹏的对话中，讨论了大量与人工智能、机器学习相关内容，他的丰富经验及其符合百度在百度大脑、深度学习上面的方向，将有助于百度在相关技术上获得进展。
