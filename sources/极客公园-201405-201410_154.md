> > \[核心提示\] 在这个团聚的日子里，极客公园祝您和您的家人节日快乐！不知道你有没有想过，用科技去改变家人的生活呢？
> 
> > ### 
> > 
> > ### **亲爱的你：**
> > 
> > 见字如面。
> > 
> >   
> > 
> > 不可免俗的，祝你和你的家人中秋节快乐。无论出门在外还是归家团聚，我们凝望的是同一个月亮，寄托着同样的记挂与惦念。
> > 
> >   
> > 
> > 不知道这个中秋节，你送给家人的是鲜肉月饼、所在地的特产、还是其他礼物？或者，你有没有想过，将自己每天享受的科技便利，同样带给自己的家人呢？
> > 
> >   
> > 
> >   
> > 
> > 和讲参数、拼配置的我们不同，对于父母一辈的人，实用更重要。他们不需要智能机的处理器芯片有四个核心，只要能顺利的发送给你微信，在屏幕上看到你的脸就会很开心。
> > 
> >   
> > 
> > 偶尔你以为「老古董」的父亲、母亲，在接受新事物的时候意外的快。在没有经历下面的事情时，我和你也曾有一样错误的想法。
> > 
> >   
> > 
> >   
> > 
> > 首先，是关于「电纸书老爸」的故事。
> > 
> >   
> > 
> > 今年亚马逊官方的翻译比赛中，我有幸获奖一台 Kindle Paperwhite2。可是已经有了一台一代机器，如果把奖品送给连智能机都不喜欢的老爸，他能接受么？
> > 
> >   
> > 
> > 于是挑选了父亲喜欢的书装进去，设置为系统中的大字号。贴好屏膜，选了一款薄荷绿的保护套，赶在父亲节前快递回家。
> > 
> >   
> > 
> > 更幸运的是父亲刚好是父亲节当天收到了 Kindle，在通过视频示范了简单的操作后，抗拒鼠标的父亲大人，竟然如鱼得水的翻起了里面的书，并给出了「这个字儿够大，还方便」的评语。
> > 
> >   
> > 
> > ![](../Images/50488ed35b2aab9c65abb779c962408a.png)
> > 
> > （调大字体的 Kindle，可以适应眼睛已经花了的父母的需求）
> > 
> >   
> > 
> > 现在我的「电纸书老爸」常常和客人炫耀他的「科技产品」，因为有了 Kindle 而不被眼花困扰的父亲，在同伴里一定很骄傲吧。
> > 
> >   
> > 
> > 好的科技，真的可以改变家人的生活体验。
> > 
> >   
> > 
> >   
> > 
> > 还有我的「平板老妈」。
> > 
> >   
> > 
> > 如果想为父母选一款用得到的产品，平板一定是智能机以外不二的选择。
> > 
> >   
> > 
> > 平板待机时间长，屏幕较智能机大，同时不失便携的优点。
> > 
> >   
> > 
> > 安一个 QQ，设置好网络和账号，父母们只要点一下你的头像，再点一下对话框下方的「摄影机」，就可以和展开你视频了。
> > 
> >   
> > 
> > 父母们可以拿着平板用摄像头对着一堆衣服，询问你中秋节要带走的是哪件；也可以对着电脑屏幕，询问你家里电脑出了什么毛病。他们不用再僵硬的坐在摄像头前，像被监视一样不自在了。
> > 
> >   
> > 
> > 我的妈妈用平板一边和我视频，一边带我参观装修好的新家。她再也不用劳心费神的打字，心疼长途电话费，可以尽情的诉说她的生活和思念了。
> > 
> >   
> > 
> > 她还探索安装了各种的 App，有一天对我说，「下厨房很好用！」
> > 
> >   
> > 
> > ![](../Images/a5fa9e47e59ec8d19a94e6ada6dee9ff.png)
> > 
> > （26岁的张明，为了让爸妈学会微信，花费十来个小时手绘了一本微信使用说明。）  
> > 
> >   
> > 
> > 还有手机上的微信，如果你的父母不习惯打字，一定要在这个中秋节教会他们。
> > 
> >   
> > 
> > 好的科技，真的可以改变你和家人的沟通方式。
> > 
> >   
> > 
> >   
> > 
> > 如果单单说产品，这就要变成推销文了（笑）。
> > 
> >   
> > 
> > 其实科技改变的不仅仅是物质层面，他可以给你力量，给你生活的勇气。
> > 
> >   
> > 
> >   
> > 
> > 2012 年的冬天我的父亲罹患重病，我和我的母亲每天都在痛苦焦灼中徘徊。
> > 
> >   
> > 
> > 那时丁香园还是一个我不知道的论坛，春雨医生、家庭用药更是听都没听说过。
> > 
> >   
> > 
> > 受费曼的启发（数学家费曼的未婚妻患有肺病，费曼读遍相关医学书寻找治疗方法），虽然每天需要照顾父亲没有办法去图书馆，但可以在晚上借助互联网的力量去了解疾病和治疗方案。
> > 
> >   
> > 
> > 在下载并阅读了大量和父亲相关的医学论文后，对父亲的病情有了深刻的了解。可以在医生给出治疗方案后讨论细节，给父亲讲现在输入他身体的是什么药物有什么作用，告诉母亲安心不用担心，这些药物的确是对父亲有益、不会伤害到父亲的。
> > 
> >   
> > 
> > 你可能说，医学术语读不懂。
> > 
> >   
> > 
> > 搜索引擎、相关疾病论坛、甚至百度百科、果壳、知乎，所有互联网的一切都可以帮助你，只要你愿意。
> > 
> >   
> > 
> > 当然医生们的临床经验丰富得多，这些储备的疾病、药物知识会给你治疗的信心，帮助你和你的家人减少恐惧，更好的和医生沟通，防止不必要的麻烦和矛盾。
> > 
> >   
> > 
> > 托了医生和互联网的福，我的父亲得以在一个半月后出院回家静养。
> > 
> >   
> > 
> >   
> > 
> > **恐惧源于无知，而知识就是力量**。这也是我对科技、对互联网有深厚情感的原因。
> > 
> >   
> > 
> > 好的科技，能够改变你获取知识的方式，从而赋予你和你的家人力量。
> > 
> >   
> > 
> >   
> > 
> > 现在，我想在母亲的手机里安一个「Yo」。工作忙时不方便打电话，「Yo」一下，母亲就知道我在想念她。
> > 
> >   
> > 
> > 她也可以在做饭的时候「Yo」我一下，不必慌乱的去按文字和语音了。
> > 
> >   
> > 
> > 这些，都是在我身上真实发生的故事，你也可以试试看。
> > 
> >   
> > 
> >   
> > 
> > 在询问了极客公园的同事们用科技改变家人生活的例子后，我的同事 61 告诉我，她通过一款名为「糖尿病心天地」的 App 提醒患有糖尿病的奶奶吃药。这款 App 可以在你设定的服药时间提醒你向指定号码（比如 61 的奶奶）发送服药提醒短信。
> > 
> > ![](../Images/fcf5258b7e306eae846f18b72f66ad79.png)
> > 
> > （「糖尿病心天地」提醒短信的方式）
> > 
> >   
> > 
> > 但 61 的方式很特别，奶奶年纪大用老人机不会看短信，61 就将自己发来的短信铃声设置为一串时间不短、不同于其他短信、也不同于手机铃声的音乐。
> > 
> >   
> > 
> > 奶奶一听到这个特殊的声音，就会想起，到了服药时间了。
> > 
> >   
> > 
> > 要是说这与设定的手机闹钟有什么区别，就是奶奶听到这段音乐的时候，想到已经年老的自己有人惦念记挂。会想起自己可爱的孙女在关心着自己，这种心情和听手机闹钟，是完全不同的吧。
> > 
> >   
> > 
> >   
> > 
> > 我的另一位同事晓青，更是用科技改变父母生活的典范：「我给我爸妈都配了 iPhone、iPad、电视盒子、Kindle、Jawbone UP、各种视频网站会员、迅雷会员、各种游戏、各种 App，教他们用导航软件自驾游、用 AirPlay 看电影、用淘宝支付宝、用 Google、Gmail、iCloud、Facetime，教他们看到谣言要先 Google 和搜果壳……他们的生活基本属于彻底改变了。还有各种新闻客户端，他们都不订报纸了。」
> > 
> >   
> > 
> > 晓青送给父亲的 360 随身 Wi-Fi，差点被父亲的同事「重金」买走。
> > 
> >   
> > 
> > 听说晓青的父亲，现在最喜欢的应用是 Flipboard 呢。
> > 
> >   
> > 
> > ![](../Images/7d007afde537b770d57d86befad621a8.png)
> > 
> >   
> > 
> > 还有，如果你的父亲也喜欢你「炫酷」的 Mac，你却苦于不知道怎么教父亲使用 Mac OS，极客公园曾发布的《手把手教你如何打造极客老爸》能为你提供不小的帮助。
> > 
> >   
> > 
> >   
> > 
> > 云端如何发展，机器能不能取代人类，人工智能会不会毁灭世界？
> > 
> >   
> > 
> > 这些「高大上」的科技的确是人类的未来重点，但在它们面前，「当下」——家人、生活、情感并非卑躬屈膝，而是互为弥补的。
> > 
> >   
> > 
> > 父母进入中年，如果刚巧你不在身边，电脑出问题不会修理，新的科技产品不会使用，常常会使他们有「被时代抛弃」的危机感，常常觉得「不懂你」。
> > 
> >   
> > 
> > 消除父母的错觉，让他们可以通过网络和各种智能终端看到你，通过各种应用和智能终端体验科技生活的便利，体验世界的变化。
> > 
> >   
> > 
> > 就像小时候父母教我们认识世界一样。
> > 
> >   
> > 
> >   
> > 
> > 「冷冰冰」的科技可以也有脉脉温情，要不要用科技试试看改善一下父母的生活？
> > 
> > 这个中秋节，就看你啦！
