> > 那么什么是「沙盒游戏」？我们常玩的很多游戏，无论是经典的超级玛莉还是丧心病狂的 Flappy Birds，都有比较明确的目标——通关或者得到更高的得分，沙盒游戏这些游戏最大的不同在于沙盒游戏大多不强迫玩家完成指定的目标，游戏也具有更高的自由度。  
> > 
> >   
> > 
> > Minecraft 是沙盒游戏中的极致。这里不存在任何剧情以及任务系统，也不存在什么电子竞技，也就不需要一些网游和 RPG 游戏一样疯狂的跑任务、过剧情，也不需要苦练技术与玩家对抗，更不需要无数次的投入金钱获取更多的资料片或者是游戏中的领先地位。
> > 
> >   
> > 
> >  ![](../Images/afca70b1b24415857242877d6fd49177.png)
> > 
> >   
> > 
> > Minecraft 模拟了一个虚拟世界，而这个世界甚至是无限大的，只不过，在 Minecraft 的世界里，你面对的是无数的五颜六色的方块，这些方块代表着泥土、石头、木头等等物品。玩家可以像玩积木一样用这些各色的方块搭建自己的建筑，也可以用不同的物品进行合成，获得更多有意思的新东西。在这里，没有太多的规则与限制，也没有传统意义上的通关与 Game Over，你可以为自己设定一个有意思的目标，然后不断的玩下去。Minecraft 让人们的创造力在这个虚拟世界中疯狂生长，因为「在这个世界里，你所有的材料都是方块状的，但你的想象不是」。
> > 
> >   
> > 
> >  ![](../Images/c75f0f52721f919c8dec294b7f0610b6.png)
> > 
> >   
> > 
> > 由于游戏的高度自由性和可玩性，这个在 09 年才开始开发的游戏在几年的时间内便迅速的风靡了全球，至今，Minecraft 的注册用户超过 4000 万，付费版总销量高达 1600 万份，而且在全世界范围内有着各种大大小小的游戏社区。玩家们制作了各式各样的教学视频，讲述自己在 Minecraft 中的探险故事，创造了无数个有趣的建筑和世界，Minecraft 已经不再是一个游戏，而是一个富有创造力的平台。
