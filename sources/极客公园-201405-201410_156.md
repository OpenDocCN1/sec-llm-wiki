> > \[核心提示\]Material Design 在今年的 Google I/O 大会上公布后，逐渐有产品加入这个行列。本周 Chrome 和 Evernote 也投入了它的怀抱。
> 
> > ## Chrome
> > 
> >   
> > 
> > 6 月份的 Google I/O 大会上，Material Design 惊艳亮相，宣告 Android 系统将迎来一次设计元素的全面统一和升级。彼时 Chrome 手机版产品经理演示的炫酷交互和显示效果给很多人留下了深刻印象。
> > 
> >   
> > 
> > 虽然 Chrome Beta 早已在发布会后不久就已经推出了 Material Design 的版本，不过毕竟大多数用的还是正式版本。终于，两个多月后，Chrome 本周同时在 Android 和iOS 平台推出了备受用户期待的正式版的 Material Design 设计。
> > 
> >   
> > 
> > Chrome 的图标在色彩上有细微变化，标签页的卡片滑动界面更具动感和顺畅性。不过也有不少手机配置不高的人表示，新版 Chrome 的效果有些卡顿。这就要看 Google 愿不愿意为了这群低端机用户做出妥协了。
> > 
> >   
> > 
> >  ![](../Images/5e4cdbff77bc463f65df674e946ba3ab.png)
> > 
> > 更新版本：37.0.2062.117
> > 
> >   
> > 
> > 推荐指数：★★★★☆
> > 
> >   
> > 
> > 评分理由：Chrome 本身的浏览功能已经非常强大，现在又拥有了更加炫丽的交互设计，第三方浏览器的危机再度加深。
> > 
> >   
> > 
> > ## Evernote（印象笔记）
> > 
> >   
> > 
> > Evernote 在设计方面一向非常用心，针对 Windows、Mac、iOS 和 Andriod 等各个平台都采用各自配套的设计风格。
> > 
> >   
> > 
> > 本周更新的 Evernote Android 6.0 版本宣告正式加入 Material Design 行列，整体的界面风格和交互都进行了完全的变化。首先就是整体界面扁平化，绿色系的主色调更加明艳。左侧抽屉简化为账户、所有笔记、笔记本、标签和探索等几个条目。新建功能挪到了主界面右下角的浮动按钮。
> > 
> >   
> > 
> >  ![](../Images/454c34049bb1b9783907692dbbb66a7c.png)
> > 
> > 更新版本：6.0
> > 
> >   
> > 
> > 推荐指数：★★★★★
> > 
> >   
> > 
> > 评分理由：Evernote 不仅顺应了 Android 系统风格的趋势，而且在本次更新中极大简化了产品设计，易用性有了较大提升。
> > 
> >   
> > 
> > ## 搜狗号码通
> > 
> >   
> > 
> > 曾获得极客公园创新产品评选大奖的一款产品，创造性地采用众包模式来辨别陌生号码。同时一直很「本分」地做着产品更新和改良，没有去做号码助手之类的事情。
> > 
> >   
> > 
> > 虽然从版本号来看是一次重大更新，但搜狗号码通的产品形态依然没有产生太大变化，最主要的就是在拨号界面根据用户拨打或接入的对象进行一些生活服务信息的推荐；其次就是对原本的「生活黄页」功能进行了进一步优化，新增了租房和找工作版块；此外还可以在通知栏里常驻一个生活服务类号码的搜索框。
> > 
> >  ![](../Images/1f41e9875b050cb06b3e7d9f4514d143.png)
> > 
> > 更新版本：3.0.0
> > 
> >   
> > 
> > 推荐指数：★★★★☆
> > 
> >   
> > 
> > 评分理由：虽然没有多么华丽的设计和交互，但仍不失为一款优秀的功能导向型产品。
> > 
> >   
> > 
> > ## Uber
> > 
> >   
> > 
> > 著名的私人叫车服务 Uber 不久前宣布开放给 API 给其他产品，在率先更新的 Android 版本中，已经加入了对 Opentable 的支持。用户可以通过自己的用餐时间预约 Uber 前来接送。
> > 
> >   
> > 
> > Uber 在此次更新中，终于把国内的地图换成了百度地图。此前由于一直使用 Google 地图，因众所周知的原因致使定位经常出现巨大偏差，饱受司机和乘客诟病。iOS 版本的更新可能还要再等一阵子。
> > 
> >   
> > 
> >  ![](../Images/3d223341f8668604946e7054575a06bc.png)
> > 
> > 更新版本：3.12.7
> > 
> >   
> > 
> > 推荐指数：★★★☆☆
> > 
> >   
> > 
> > 评分理由：产品使用体验对国内用户来说依然比较不适应。
> > 
> >   
> >

> > Wunderlist 是要把跨平台进行到底，本周如期发布了 Windows 8 和 Windows Phone 版本，从而让微软的用户们也能拥有与苹果、Google 用户同等的服务。

> >  ![](../Images/661c9b0c543e58e090ed09ebf6fb1873.png) ![](../Images/a72bd6c8fca2909683e49c19190b1cf5.png)
> >

> > 
> >   
> > 
> > 推荐指数：★★★★☆
> >
