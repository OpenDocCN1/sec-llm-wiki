# 手机保险会成为标配吗

> > \[核心提示\] 一年之后，如果智能手机用户还从未听说过「手机保险」，可能真的就 out 了。
> 
> > 魅族 MX4 的发布对我而言是一种刺痛，因为其划算的价格和周全的手机险。
> > 
> >   
> > 
> > 半个月之前，我的 MX3 刚刚因为进水被送往珠海返厂检修，在客服淡定的电话回访中，我得知了需要 1650 元的维修费。（新发布的 MX4 才不过 1799 而已。）
> > 
> >   
> > 
> > 由于人为原因，也由于当时根本没有手机险这回事儿，这 1650 的维修费并不可以由厂家承担。
> > 
> >   
> > 
> > 为什么这么贵，维修部给我的答案是，由于手机进水，导致主板发霉，不仅需要换显示屏还要换主板。显示屏的价格是 800 元，主板价格 850 元。
> > 
> >   
> > 
> > 我这才意识到原来给手机买保险也是刚需。  
> > 
> >   
> > 
> > ## 为什么需要手机险
> > 
> >   
> > 
> > 手机险这东西乍一听有点矫情。不就一台手机么，几千元的事儿，比这贵的多的电脑都不用保险，给它买干嘛。
> > 
> >   
> > 
> > **首先，人们最能接受的保险通常与切身利益密切相关，而今，智能手机占据了每个人生活中的大量时间，它是人们接入虚拟世界的重要入口，某种意义上已经成为了人体的延伸。**
> > 
> > 在智能手机日益普遍的今天，手机的使用场景普遍超过了 PC。美国市场研究公司尼尔森的最新调查显示，2012 年第四季度至 2013 年第四季度期间，美国 iPhone 和 Android 用户的应用使用量增长了 65%，每月应用使用时间从 23 小时 2 分钟，增长到 30 小时 15 分钟。
> > 
> >   
> > 
> > 在中国，一些手机已经开始围绕硬件入口建立自己的生态圈，尽管还没有具体的数据显示平均使用时长，但从人们的日常生活中可以看到，手机已经占据了碎片化时间的方方面面。
> > 
> >   
> > 
> > 你可以一天见不到你的女（男）朋友，但你可以一天不见你的手机吗？
> > 
> >   
> > 
> > **其次，随着手机越智能，融合在产品中的新技术越多，它的稳定性和耐用性就越需要时间来检验。目前越来越多的智能手机选用大尺寸、玻璃材质屏幕、更强大的芯片，这使得他们注定无法做到像非智能手机那样可以更好适应各种极端环境和意外损伤。**
> > 
> > 例如，单从屏幕技术来说，在追求工艺和美感的趋势下，手机的全贴合技术已经成为主流。
> > 
> >   
> > 
> >  ![](../Images/d99642fa7605d8ec05053dd679b67d53.png)  
> > 
> >   
> > 
> > 所谓的全贴合技术，就是通过 OCA 光学胶将玻璃盖板与液晶屏以无缝隙的方式完全贴在一起。
> > 
> >   
> > 
> > 我们知道，手机屏幕分为玻璃盖板，触摸屏和显示屏，这三部分之间是需要两次贴合的。贴合方式分为全贴合和框帖两种，传统的框帖通过双面胶的形式将触摸屏与显示屏的四角贴合在一起，中间存在空间层，不仅容易进灰，显示效果也会大打折扣。
> > 
> >   
> > 
> > 全贴合则不会存在空间层的问题，不会进灰，显示效果也更好。显示屏也因为与玻璃盖板紧密结合而变得更轻更薄。
> > 
> >   
> > 
> > 全贴合技术虽然好，但也面临一个问题，就是屏幕出现问题后，触屏会受到影响，返修成本会增高，同时，由于各手机维修点缺乏手机的维修设备，包括真空贴合机、拆屏机、除泡机等，受损手机还需返厂维修，增加了更多的成本。（我的手机出现屏幕进水之后，就是先送往中关村，再返厂到了珠海维修中心）。
> > 
> >   
> > 
> > 当刚出生的「脆弱」手机遇到比抗摔性测试复杂得多得大千世界，它的风险无时不刻不在增加。贴膜和买手机壳这种做法，对于追求极致体验的用户来说，一点也不极客不是么？
> > 
> >   
> > 
> > **再次，手机保险保的不仅是一台智能手机背后的数千元钱，而是用这样一种方式让用户放下对新的创新产品的观望和对于质量的心理负担。**
> > 
> > 如今的智能手机已经过了单纯比拼价格和参数的时代，正在更强调与人的情感连接，往小了说是维系粉丝，往大了说则是强化品牌。但还这种对用户情感认同的经营很有可能会因为致命的质量问题而功亏于溃，而手机保险则传达了一种自信，尤其是对于一个新的品牌或者新的产品创新，这种自信的姿态能够迅速赢得用户的信任感，降低用户在接受新事物时的心理负担。
> > 
> >   
> > 
> > ## 全产业链都爱「手机险」
> > 
> >   
> > 
> > 在魅族的手机险之前，其实已经有很多手机厂商推出了类似保险，比如锤子的碎屏险，用户需要只要购买了 200 元的意外保险服务，在一年内，屏幕或后玻璃因意外损坏，都可享受两次免费换新服务。除了锤子，小米 4 也提供 99 元的购买保障服务，可在手机意外损坏时获得免费维修。荣耀 6 开出了 100 元的保价，保修范围包括跌落碎屏、液体泼溅、环境因素、硬物磕碰等。
> > 
> >   
> > 
> > 手机险并非手机厂商的专利，最早的尝试者是渠道商迪信通，早在 2009 年，手机连锁卖场迪信通就曾与天安保险公司合作，在上海推出国内首个「手机保险」业务，其中就包括意外事故损坏所需的置换新机或维修的费用进行赔偿。保险分为四档：一千元及以下价格的手机保险费为一百元。一千元以上，两千元及以下的价格的手机保险费为两百元，以此类推，保险费上至四百元封顶。
> > 
> >   
> > 
> > 就连手机安全厂商也尝试在免修范围之外提供保险服务，比如，去年，网秦就推出手机硬件保障业务。网秦的「手机保」分为三个期限让用户进行选择：20-50 元/月，80-250 元/6 个月和 150-400 元/12 个月。一旦损坏，快递免费上门拿回手机，修好后再送还给用户。
> > 
> >   
> > 
> > ![](../Images/df740e942369e4ccccfb2dfbe279b4d6.png)  
> > 
> >   
> > 
> > 甚至连跟硬件生态风马牛不相及的支付宝最近也打上了手机险的主意，今年的 7 月 11 日，支付宝就在官方微博中发布信息称将再出新险种——手机碎屏意外保险，拥有这一新险种只要支付 19.9 元。相对于一次几百元的换屏费用，这个价格更加合算。
> > 
> >   
> > 
> > 就在各方势力纷纷看上「手机险」的机会时，手机厂商显然应该更加主动，将可能的不确定性减少到最小。
> > 
> >   
> > 
> > 将手机险交付给第三方无论对于手机厂商还是消费者来说都不算是好主意。对于手机用户而言，各种保险的理赔标准都有所不同，以支付宝的保险为例，19.9 的价格只能理赔一次，保险金额则以专业维修机构评定标准为准，而鉴定工作仍然要交给手机售后维修商。
> > 
> >   
> > 
> > 既然专业的维修无法绕过手机厂商，那么手机厂商完全可以将此业务划归在自己的范围当中。
> > 
> >   
> > 
> > 魅族的 89 元已经很亲民了，未来会有更多的手机配套手机险，至于价格么，就看手机厂商愿不愿意在这上面做文章了。
