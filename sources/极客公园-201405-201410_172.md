> > \[核心提示\] 百度准备如何做一个「连接者」，在今年的百度世界大会上，百度推出的两个杀手锏又是什么？
> 
> > 今天，2014 年百度世界大会在北京召开。百度世界大会从 2006 年举办至今，是每年百度年度战略方向的发布平台，在今天的百度世界大会上，百度高调提出了连接的概念，比起前两年百度在移动互联网战略上的防守态势，此番的组合拳可谓踌躇满志。
> > 
> >   
> > 
> > 百度准备如何做一个「连接者」，在今年的百度世界大会上，百度推出的两个杀手锏又是什么？
> > 
> >   
> > 
> > ## 连接人与服务的百度直达号
> > 
> > 关于百度直达号，百度官方的介绍是这样的：「百度直达号是商家在百度移动平台的官方服务账号，基于移动搜索、地图、个性化推荐、@ 账号等多种方式，让顾客随时随地直达商家服务。」
> > 
> >   
> > 
> > 百度「直达号」将通过智能推荐把企业的过客变成顾客，而 80% 的流程服务可以在直达号完成，包括在线完成预约支付环节。同时，直达号还包含 SNS 社交能力，用户可以与服务商进行实时交互，对服务人员进行评论，同时分享到社交平台上。
> > 
> >   
> > 
> > ![](../Images/42c099d51c678a2c779f19f7bb4a8d72.png)  
> > 
> >   
> > 
> > 在大会上，百度 CEO 李彦宏表示：「过去一年里还有一个很明显的趋势，越来越多的消费者通过移动搜索寻找『服务』。用户对于百度的期望发生了变化，在移动互联网时代，搜索引擎的作用由过去的连接人与信息变成连接人与服务。」
> > 
> >   
> > 
> > 无论是在更早些的百度第二季度财报会还是在百度轻应用编程马拉松活动上，百度都将连接视为一大重点。百度直达号，即是百度对于「连接人与服务」的解决方案。
> > 
> >   
> > 
> > 其实不难发现，百度直达号是百度轻应用的一种延续，百度直达号将移动搜索的入口，轻应用搭建的服务框架以及百度的支付方案整合在了一起，借此实现百度在移动端提出的「入口——场景——支付」理念，建立了一个 O2O 的生态闭环。
> > 
> >   
> > 
> > 在「为传统服务行业向互动互联网转型提供解决方案上」，百度与微信有着截然不同的策略。
> > 
> >   
> > 
> > 百度直达号更多依赖其在搜索上的优势，百度直达号的入口是百度移动搜索以及地图服务，而通过搜索可以更高的对应用户的需求，也就是百度所说的「高转化」。百度直达号不需要用户关注特定的服务就可以通过直达号与用户的需求与服务对接，这对于「拉新」具有很大的优势。
> > 
> >   
> > 
> > 未来在 O2O 领域，百度直达号将与微信的公众号产生直接的对抗。
> > 
> >   
> > 
> > ## 建议连接人工智能与现实的额百度大脑
> > 
> > ## 百度高级副总裁王劲举例说明了目前「百度大脑」将人工智能化为现实的例子：
> > 
> >   
> > 
> > *   在图像搜索中，如果用户拍下一束不知道名字的花，想了解更多信息，百度大脑将通过拍摄花，根据用户属性，通过百度大脑将学生推荐到百度百科，而对于养花者可以通过「直达号」推送到附近的花店。
> >     
> > *   在语音搜索中，如果用户听到一首陌生的歌曲，拿起手机可以告知是什么歌，普通听众将导入百度音乐听歌，而歌星粉丝可以通过「直达号」导入票务服务下单选座和支付。
> >     
> > *   在健康方面可以帮助用户预诊断，导向附近的医院，同时进一步帮助挂号、选择专家和就诊，连接患者和医疗企业。
> >     
> >       
> >     
> > 
> > 百度现在有 20 多个云计算中心，在今年 6 月 30 日刚刚落成的云计算中心投资高达 47 亿。实际上，「百度大脑看的见的部分，有服务器和云计算中心，但更重要的是他看不见的那部分，那个被称为深度学习、人工智能的算法」。
> > 
> >   
> > 
> > 「百度大脑」将被打造成世界上最大规模的深度学习神经网络，也就是并不一味扩大数据规模，而是更多利用算法模拟人脑的思维和学习过程，使其能处理更加复杂的事。
> > 
> >   
> > 
> > 王劲用花名识别的例子简单解释了百度大脑是如何帮助我们实现人工智能的：
> > 
> >   
> > 
> > 当我们用拍一个花的照片，这个花的照片就会被转化成 0101 的数据流，被输入到百度大脑，百度大脑会拿这个跟我们存储在中心里面的海量的数据进 行比对，经过一层一层的识别，经过整个算法和比对之后知道原来这是一朵花，这个花的名字是什么，同时我们也能够找到跟这个花相关的这些所有的信息，这是百度大脑模拟人脑进行思维、思考辨认自然界的一个过程。
> > 
> >   
> > 
> > ![](../Images/3217b984ab0a23440764300c7be1280e.png)  
> > 
> >   
> > 
> > 在今年，百度请来了人工智能领域的专家，在线教育平台 Coursera 的联合创始人吴恩达做百度的首席科学家。未来「百度大脑」可能会在技术上有更多的突破，也会将更多的人工智能新成果传达到现实中来，比如说与直达号的整合，比如集成了视听说的新产品 BaiduEye，比如中国的无人驾驶技术。
