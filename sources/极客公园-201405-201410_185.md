> > > ## GooReturnMe：找回丢失的物品
> > > 
> > > 每个人都有丢失物品的时候，有人很幸运，拾金不昧的人通过种种途径找到了失主。有人比较悲催，可能失主想还给你都不知道你的联系方式。
> > > 
> > > 通过GooReturnMe你可以获得一个唯一的物品编码，当有人捡到你丢失的物品时，可以通过GooReturnMe提供的贴纸查看如何归还给你，以及你承诺的奖励。
> > > 
> > > **网址：**GooReturnMe.com
> > > 
> > > ![](../Images/dda37f2eb88cad54e26ce626cffb4257.png)
> > > 
> > > ## DialZoo：和朋友的邮箱直接语音对话
> > > 
> > > 只需要输入对方的电子邮箱地址，系统会自动启动麦克风，对着说话就可以了。然后DialZoo会将这段录音发送到你输入的电子邮箱。点击就可以听声音了。可以理解成基于电子邮件的微信。
> > > 
> > > **网址：**dialzoo.me
> > > 
> > > ![](../Images/b822ed921a8b44c3121bc3f0004ae466.png)
> > > 
> > > ## SpareSquare：兼职广场
> > > 
> > > SpareSquare以简洁为特色，你只需要填两项内容：我希望别人做什么；我愿意支付什么。
> > > 
> > > 比如你希望有人帮你设计一个Logo，而你愿意支付15美元。不适合大型项目，就适合能快速完成的项目，比如发个帖子、处理一个图片什么的。如果是涉及到需要多次交互才能完成的项目如做一个电商类的网站，可能不太适宜。
> > > 
> > > **网址：**sparesquare.com
> > > 
> > > ![](../Images/cd4bbace90490602d7a88870996127fb.png)
> > > 
> > > ## Sportyapp：和附近的人一起运动起来
> > > 
> > > 是不是经常向运动，想打打乒乓球、羽毛球、篮球……找不到一起玩的人，而这些体育运动如果只有你一个人就无法开心的进行。如何找到附近的小伙伴一起玩耍？sportyapp这个手机应用只提供一个功能，查看附近和你有共同体育爱好的小伙伴。
> > > 
> > > **网址：**sportyapp.com
> > > 
> > > ![](../Images/e7e021229d285b39f0e4df77de3d9341.png)
> > > 
> > > ## Roundio：身边的新鲜事和正在发生的活动
> > > 
> > > 快速查看你身边的一切动态：正在上演的演出、比赛、活动……对一个经常到各地走一走的同志，此类服务非常有价值。总呆在宾馆里多没劲，拿起手机打开roundio，发现附近有一场热闹的免费街舞，过去看看热闹也不赖。
> > > 
> > > **网址：**round.io
> > > 
> > > ![](../Images/1dbd2b76cd825bd74954092c0016b25a.png)
> > > 
> > > ## glasswire：实时监测异常网络流量
> > > 
> > > 这是个桌面程序，下载安装后可以事实监测你的PC网络流量。都是哪些进程在占用你的带宽，他们都和哪些地方的主机建立了联系。一般来说，你常用的那些网站他都会放在信任列表里，如果突然有某个异常的链接占用大笔资源，程序就可以马上报警，提醒你或许该杀毒清木马了。
> > > 
> > > glasswire名字起的很好，将线路上的一切都变得透明。这个程序的作者好像刚被中了木马，便立志开发了这个软件。世界需要这样的Geek。
> > > 
> > > 网址：glasswire.com
> > > 
> > > ![](../Images/645a0ff88c07e7206ddcbc49b14454ff.png)
> > > 
> > > ## kevlar：秘密信息阅后即焚
> > > 
> > > 这是Snapshot和Secret的合体。你可以在kevlar上创建任何的秘密信息，然后将这条消息的链接发给朋友，朋友阅读完毕后，这条消息将会被永久的删除。只能阅读一次。
> > > 
> > > 不过可以QQ截图哦。理论上来讲，互联网上就没有什么秘密，想彻底删除一条消息也越来越难。
> > > 
> > > 网址：kevlar.io
> > > 
> > > ![](../Images/ed7dbccd53f42ed57405cb4e59e6913c.png)
> > > 
> > > ## salaryfairy：预测你的薪资水平
> > > 
> > > 只需要用你的Linkedin账号登录，salaryfairy就会收集你的职业生涯和社交关系信息，并根据各地的薪酬水平估算你适合的薪资水平。如果比你现在的工资高，可以找你老板要求加薪了！这和前段时间的基于微博的职业生涯影响力产品有很相似之处。
> > > 
> > > 网址：salaryfairy.com
> > > 
> > > ![](../Images/6a7a07076f38b0dd9605a2f881ba4895.png)
> > > 
> > > ## DomainIQ：域名信息智能查询工具  
> > > 
> > > 只需要输入域名，DomainIQ就能反馈让你吃惊的信息，比如这个域名的注册人以及他名下的其他域名，这个域名的经手人历史信息……做域名投资的人一定会很关心这类信息。
> > > 
> > > 另外，DomainIQ提供的信息被政府机构、法律界所信任。
> > > 
> > > 网址：domainiq.com
> > > 
> > > ![](../Images/bac35523d222a1a59065c2f3c1337e27.png)
> > > 
> > > ## domainnamebrain：域名大脑
> > > 
> > > 域名是网址的灵魂。可是COM域名被抢注好多年，基本没什么好资源可以想到了。那如何才能注册到自己希望的域名呢？domainnamebrain域名大脑提供了各种复合工具，用字典词库、热门程度等各种维度帮你组合域名，帮助你筛选适宜自己的域名。是创业者、个人站长、域名投资者不可缺少的工具，不过现在的词库都是英文前后缀，中文拼音不支持。
> > > 
> > > 网址：domainnamebrain.com
