# 2014百度世界前瞻：轻应用托起O2O之重

> > > > Connecting——连接人与服务。
> > > > 
> > > >   
> > > 
> > > 这是 8 月 2 日和 3 日，由百度举行的「2014 百度轻应用 Hackathon 编程马拉松」活动所提出的口号。这场活动中最值得注意的就是有来自餐饮、零售百货、医疗和金融等多个传统领域的企业来到现场。他们在现场与开发者对接需求，由开发者结合其特性在百度轻应用平台进行开发。
> > > 
> > > 这场活动所选的时间点颇有一些预示的意味。因为 1 个月后，即本周三的 9 月 3 日，2014 年百度世界将拉开帷幕。百度世界是百度公司一年一度最重要的的产品与技术发布会，通常会在会上公布下一年度的核心战略。
> > > 
> > > 在 2013 年的百度世界上，百度提出要解决应用分发中大量中长尾应用得不到有效推广的状况，因而推出「轻应用」，旨在通过百度的搜索入口和场景帮助开发者带去流量和用户。那么，今年的百度世界将会为轻应用赋予哪些新的使命，带去何种新的变化？
> > > 
> > > ## 轻应用的产品价值
> > > 
> > > 在轻应用平台正式上线不久时，百度主推的有 4 类内容：「新闻阅读类」、「营销商品类」、「生活服务类」和「旅游出门类」。极客公园曾采访了接入百度轻应用的典型产品——景点通。CEO 沈卓立当时认为，景点通将大部分只有短时间需求的用户定位为浅层用户，未来在轻应用内做流量导入即可，而少部分有长期需求的忠实用户仍然会回归功能更加完善的本地应用。
> > > 
> > > 从某种意义上说，百度轻应用逐步承袭了 PC 端百度推广的逻辑：关键词匹配、高流量导入，从而快速变现。百度在移动端提出了**「入口——场景——支付」**的理念，就是将轻应用聚焦到离钱更近的领域。由此，百度在年初推出了自家的支付工具「百度钱包」，并且将与用户消费直接相关的「生活服务类」轻应用当作重点方向，主打票务、酒店、挂号等。百度旗下的糯米和去哪儿即通过轻应用获得了较大的收入增长。
> > > 
> > > 而百度更大的目的在于对传统行业产生影响，主要的方法就是为其带去更为直接的客源。在传统的关键词推广里，用户抵达商家服务需要经过搜索、关键词匹配、页面展示、客服沟通等多重环节，使得导入的流量真正转化为有效交易的成交量有限。**轻应用则通过类似于本地应用的呈现形态，将商家的服务信息通过搜索匹配后直接展示给用户，并且在其中直接进行支付和交易。**
> > > 
> > > 所以这一年来，百度并没有把太大精力放在轻应用的接入量增长上，而是探索更多能够与移动搜索相匹配的场景。
> > > 
> > > ## 轻应用的路径：搜索结果，还是独立产品
> > > 
> > > 百度轻应用在上半年重点推介了两款产品：轻拍和百度考霸，这两者都是百度自行研发的轻应用。百度在 5 月初的一个小范围技术沙龙「西二旗夜话」上，探讨了 O2O 场景内的连接方式，其中重点讨论的就是以「轻拍」为代表的通过图像识别技术直接呈现服务的方式。轻拍在 3 月底与电影《超验骇客》合作了一次活动，就是让用户通过拍摄电影海报，即可直接跳转到电影票的购买页面，通过内置的百度钱包进行支付。
> > > 
> > > 而就在前几天万达、百度和腾讯合作成立电商公司的发布会上，李彦宏在发表的演讲中举例称：
> > > 
> > > >   
> > > > 
> > > > 假如说一个人在万达广场上走，突然发现一个女孩子穿的裙子很漂亮，这时只要拍一张照片你就可以知道，在万达哪一家店、哪一个专柜正在卖这条裙子。如果我在街边看到一个电影的海报，只要拍下这张海报就可以知道万达影院几点几分放映，可以选哪个座位，并通过线上的支付方式完成所有的操作。
> > > > 
> > > >   
> > > 
> > > 这正是百度所提倡的由图像识别进军 O2O 的典型场景。
> > > 
> > > 百度考霸是百度在今年暑期主推的另一款轻应用，它通过百度的搜索和分析能力，整合并结构化网上关于高考择校的各类信息和知识，为高考考生提供决策建议。与轻拍相比，它不只是一种功能，而是具备系统信息处理的独立产品，只不过是通过轻应用这个途径进行呈现。百度考霸在对外推广时，也是以独立产品的方式来进行介绍，需要在搜索框里直接搜「百度考霸」才能调用出这个轻应用，没有匹配高考、填志愿之类的关键词。
> > > 
> > > **除了通过搜索关键词来分发轻应用，百度似乎在尝试将一些轻交互、重内容的产品直接以轻应用的形式展现给用户，摆脱本地应用的框架。**这背后是百度在个性化推荐和自然语言处理等方面的持续投入，从而实现更加多元化的搜索形态展现。
> > > 
> > > ## 轻应用「重装上阵」
> > > 
> > > 7 月下旬，投行摩根士丹利在研报中看好百度搜索的货币化能力，将其股票上调至「增持」级。几天后，百度 2014 财年 Q2 财报发布，移动营收在总营收中所占比例首次达到 30%，推动股价升至年度最高点。
> > > 
> > > 虽然目前移动广告和分发扔是百度移动营收的主要来源，但移动端的用户特性使得百度看到了在 O2O、支付等以用户为导向的多样化商业模式的巨大潜力。**轻应用在未来百度的移动战略中可能会发生这样一些变化：**
> > > 
> > > 1\. 轻应用不再只是封装 HTML5 页面的技术手段，而会取代现有的百度关键词推广，成为百度在移动端为客户进行广告呈现的主要形态，它比传统的点击跳转具备更高的交互性和到达率；
> > > 
> > >   
> > > 
> > > 2\. 传统条目式的搜索结果在移动端的体验不佳，用户需要搜索引擎给直接出想要的答案，而不是一堆需要自己一条条点开的标题。轻应用让「所搜即所得」更近一步，它能够直接展示用户最需要的搜索结果，从而在最短路径内获得信息或完成交易，在其背后是大数据分析、个性化推荐和人工智能等技术投入的支持；
> > > 
> > >   
> > > 
> > > 3\. 基于轻应用的移动分发被提到和本地应用分发同等重要的位置，百度的 Clouda 技术一直试图将轻应用的体验提升到与本地应用相媲美的地步，虽然仍有差距，但当百度能够为开发者提供稳定的服务，从底层的云服务、开发框架，到应用层的流量导入、支付等，确保开发者持续获得收益，轻应用就能够得到与本地应用同等的重视，百度现有的移动分发也会多出一块新地盘。
> > > 
> > >   
> > > 
> > > 基于上面这些变化，百度轻应用需要建立更加完善可持续的闭环，尤其是越来越多的开发者接入以后，其中一些关键问题必须加以解答：
> > > 
> > > 1\. 当用户通过搜索入口到达某个轻应用场景时，如搜索「电影票」，哪家的服务会得到展示？是百度自家的糯米，还是美团旗下的猫眼？这就涉及到，**当某一行业出现多个服务提供商时，百度如何对它们进行合理分发，来帮助其到达用户？**
> > > 
> > > 2\. 百度轻应用借助其搜索入口，无疑能够在适当的时机为商家或开发者带去巨大流量，但这种流量并非可持续的，具有较大波动性，如景点通轻应用每到节日和小长假期间就会暴涨，但在平时的表现就很一般。对商家来说，尤其是百度所想要去连接和影响的传统行业，稳定的客流是他们的核心诉求。换言之，**就是如何提供稳定且持续的流量**；
> > > 
> > >   
> > > 
> > > 3\. 同样是「连接」人与物，微信因其 IM 的本质，拥有超强的粘性和高频的交互。但搜索往往是一种即时性和随机性很强的用户行为，用户并不能对搜索结果产生忠诚。即使搜索为轻应用带去流量，但**无法沉淀成稳定的活跃用户的话，轻应用也会面临「管道化」的境况，即成为开发者将用户导入本地应用的通道**。
> > > 
> > >   
> > > 
> > > 在前文所举的例子里，可以看到百度已经在尝试对上述问题给出解决方案。是否会有更加具体和完善的产品策略，还要等到两天后的 2014 百度世界上才能知晓答案。
