> > \[核心提示\] 游戏直播，这个看似存在于宅男中的小众需求，是如何被 Twitch 做成 10 亿美元的大生意的？
> 
> > > Twitch 是什么？你可以把它理解为游戏领域中的 Youtube。在这个电子竞技视频平台上，用户可以在线观看游戏主播实时进行的游戏直播和解说，从近些年一直热门的 Dota 和 LOL 到传统的魔兽争霸、星际争霸这样的实时战略游戏甚至是十分小众的独立游戏都有覆盖。
> > > 
> > > ![](../Images/fcec5f1cf75449a2918b8f40c8400ece.png)  
> > > 
> > > Twitch 的业务看似小众，却已经成为全美最大的流量黑马：今年年初，《华尔街日报》登出了一家美国的网络服务商统计的全美互联网峰值时期流量来源，榜单中 Twitch 赫然在列，而且排名高达第四位。在视听网站上，仅次于 Netflix 和拥有 Youtube 的 Google。
> > > 
> > > 目前，Twitch 的月活跃用户数高达 5500 万， 很多游戏的在线观看人数达数万人。
> > > 
> > > 游戏直播，这个看似存在于宅男中的小众需求，是如何被 Twitch 做成 10 亿美元的大生意的？
> > > 
> > > ## 为什么是Twitch ？  
> > > 
> > > 自在线游戏诞生后开始就逐渐出现的游戏直播其实并不是一个新鲜的行业，在很长一段时间中存在于游戏发烧友的人群中，但多数并不成规模，Twitch 却把游戏直播变成有潜力叫板视频网站的好生意，它是如何颠覆传统的游戏直播的？
> > > 
> > > ### **不做媒体做社区**  
> > > 
> > > 只是看些高手的游戏视频去哪里看不到？甚至很多人有这样一个疑问：看别人玩游戏有意思吗？他们为什么不自己去玩？
> > > 
> > > 其实，在 Twitch 上做直播的不仅仅是一些游戏高手或者职业玩家，当然，一个人看别人玩未必很有意思，但是，如果是一群人在看呢？即便几个朋友坐下来只是聊聊天也并不显得无趣。更何况游戏如同足球一样可以为观众带来期待与欢乐。
> > > 
> > > ![](../Images/8fa4e272af4ba2fef82291b1ea4a6e27.png)  
> > > 
> > > 从本质上来说，Twitch 并不是一个类似于 ESPN 等体育频道的节目集合或者是一种单纯的直播技术平台。而是一个游戏爱好者的社区。
> > > 
> > > Twitch 诞生以来就具有一个社区的两个必要条件：
> > > 
> > > 1.具有共同点的用户
> > > 
> > > 由于 Twitch 本身做的是游戏直播，所以 Twitch 所聚拢的用户群体实际很集中。对于视频的上传者，他们往往都是游戏高手甚至是竞技游戏的职业选手。对于观众，他们大多是游戏的爱好者。
> > > 
> > > 2.话题
> > > 
> > > Twitch 所直播的游戏本身就拥有大量的话题，而直播中的动态画面实际又提供了更多新的话题。
> > > 
> > > Twitch 利用这两点构筑了一个汇聚了全世界游戏爱好者的社区，而视频直播内容是一种传达信息和连接用户的载体。
> > > 
> > > 与传统的直播频道不同，Twitch 可以实现主播与观众，观众与观众之间的即时互动。所有的评论都会即时的呈现在右侧的聊天区域内。
> > > 
> > > 主播可以实时的看到观众的反应从而掌握观众到底喜欢什么样的视频直播，观众之间也可以产生有意思的话题增加视频直播的趣味性。观众不再是过去只能接收信息的观众，而变成了一个个社区的参与者。
> > > 
> > > ### **有参与感的交互**  
> > > 
> > > ![](../Images/54870ae49df534d6eaf8d78be22ba980.png)
> > > 
> > > 在今年年初，有网友利用 Twitch 设计了一个可以由众多网友共同操作的“口袋妖怪”，游戏中每个指令都由观众输入指令决定。最终经过了 16 天的时间成功通过了这一游戏。
> > > 
> > > “无限猴子定理”出自一本谈论概率的书籍，具体来说指：「让一只猴子在打字机上随机地按键，当按键时间达到无穷时，几乎必然能打出任何给定的文字，比如莎士比亚的著作」。很多人觉得这只是一次「无限猴子定理」式的实验，实际上，这更是一种交互式媒体的新实验。
> > > 
> > > Twitch 使得观众可以即时的与主播交流，因此 Twitch 也出现了让观众参与节目的可能，甚至，会出现诸如由所有观看直播的网友共同玩「口袋妖怪」这样的无主播节目，观众可以产生更多的互动甚至影响整个节目的决策。
> > > 
> > > 从极客公园之前的报道中不难发现，无论是 pixiv 这样的原创画作网站还是 A、B 站这样的视频弹幕网站，社区属性、参与感都是关键词，这都将是新形态社交网络的基础。
> > > 
> > > ### **打通用户的盈利模式**  
> > > 
> > > 在国内，过去的几年，随着 Dota，LOL 等游戏的崛起，中国的游戏直播也逐渐地火热了起来，并且出现了不少人气极高的游戏直播主播。然而，大部分游戏主播实际上无法直接的将自己的服务转换为自己的收入。更多的是积攒够了足够的人气后开设淘宝店，售卖游戏周边产品甚至是零食小吃。实际上，这样的模式加大了主播在其他领域精力的消耗，并且会影响视频直播的质量。
> > > 
> > > Twitch 是怎么做的呢，Twitch 对于游戏直播频道设定了「订阅」服务。也就是说，观众可以直接向游戏视频主播付费，而订阅的收入大部分会进入主播的口袋，少部分收入会归 Twitch 所有。
> > > 
> > > 对于很多不够专业，但是表现力十足的主播，通过积累人气获取收入变的容易，主播不需要自寻渠道盈利，可以将更多的精力投入到游戏直播的录制上。而付费玩家可以在有更少人的「仅限订阅者」模式中聊天，可以与主播有更多直接交流的机会，甚至能和主播一起游戏。
> > > 
> > > ## **为什么值 ****10 ****亿美元？**  
> > > 
> > > 通过高黏性的社区、可持续的商业模式，Twitch 的平台上源源不断产生优质的游戏直播内容，但这些看似都与电商风马牛不相及，然而，亚马逊愿意为之付出 10 亿美元的代价究竟是看上了 Twitch 什么？  
> > > 
> > > ### **顶尖的流媒体直播技术**  
> > > 
> > > 流媒体直播在技术上难度要比播放已存在服务器中的视频大，即便如优酷这样拥有海量用户的视频服务公司，在「老罗约战王自如」的直播中几乎所有用户都感受到了很严重的卡顿。
> > > 
> > > Twitch 的初创团队在经验上并不丰富，然而他们在技术上的探索比很多大公司走的更远。他们将遇到的问题进行了细分，将复杂的问题分解。深入与硬件设备的专家聊，研究现有的数据传输技术，研究如何利用 CDN 进行流媒体直播等种种在技术上的不断追求，打造了一个十分高效的流媒体直播平台，使得 Twitch 得以用不大的投入维护一个数千万活跃用户的用户群体。
> > > 
> > > ![](../Images/322e9a352efed35847505cd5d976b4e0.png)  
> > > 
> > > 而 Twitch 也不仅仅支持 PC 这一平台的直播，近年 Twitch 已经开始支持 Xbox、PS 平台游戏的直播，甚至在手机上都可以使用 Twitch 做游戏直播。
> > > 
> > > 无论是技术高度还是可扩展性、功能性上，目前的流媒体直播平台，能达到 Twitch 的水平的几乎没有。流媒体在未来的重要性不言而喻，在过去一年，亚马逊在获取流媒体视频的版权上花费了 10 亿美元。Twitch 的技术积累显然可以让亚马逊的视频领域竞争中收益。
> > > 
> > > ### **打通视频与游戏服务的连接**  
> > > 
> > > 亚马逊在最近一年内，推出了不少影音服务，比如 Prime Instant Video 以及 Prime Music。在游戏领域，亚马逊收购了主机游戏开发商 Double Helix，推出了主打游戏功能的 Fire TV。不难发现，亚马逊在未来很有可能会试图转型为一个服务型的公司，而不再是扮演一个网络零售商的角色。
> > > 
> > > ![](../Images/c65238e73dfcfa1799b319f3b2cf475f.png)  
> > > 
> > > 「占领客厅」是众多诸如微软、索尼游戏巨头的目标，准备转型服务的亚马逊显然也不会放过这一市场，收购 Twitch 可以让亚马逊目前既有的服务产生一个连接的节点。并且，社区属性产生的粘度会使亚马逊在游戏影音这一话题足够多的领域收益良多。
