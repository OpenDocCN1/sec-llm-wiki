# 渐冻人霍金：无法禁锢的伟大灵魂

> > \[核心提示\] 霍金给整个人类的智慧财富无时无刻不在提醒我们，渐冻人这个特殊的群体正在备受病痛折磨，但是，他们依旧有着神圣的生命和伟大的灵魂。
> 
> > 他歪斜着躺在轮椅上，表情木然呆滞，牙齿突兀地暴露在外面，他只能发出机器的声音，那是他用眼睛的移动、面部的动作所输入的一个个字母所转换的，这是他与外界的唯一联系。
> > 
> > 他是史蒂芬·霍金。
> > 
> > 一位的伟大的理论物理学家，一位肌萎缩侧索硬化症 (ALS) 患者，一位被世俗称作「渐冻症」的病人。
> > 
> > ## 步入黑暗
> > 
> > 阳光从窗外照进病榻，脊椎检查后的刺痛还未消散，就连同内心的郁结搅在腹中，梗在胸腔内，宛如巨石在喉。眼前模糊一片，周围的一切都变得不真实：上一秒明明还在跟一个派对上认识的女孩仰望星空聊着最喜欢的音乐，下一秒却发现自己躺在草坪上身体不听使唤地无法站起来了。
> > 
> > 霍金刚刚患病的时候记得自己的双腿是矫健而有力的，在牛津大学的赛艇俱乐部中，身材并不高大的他总是处于舵手的位置，掌握着整个赛艇的方向和转速。他还记得他带领队员在对抗赛获得冠军时的欢呼声和崇拜的目光。但是那句冷冰的话让他从此步入黑暗：「你的大脑将一直清醒，大脑中的运动神经元控制着身体的运动，但它们正在死亡。你的肌肉将渐渐停止运动。」
> > 
> > ![](../Images/2938e2dd07bd1aba91106c4045d9bfb2.png)
> > 
> > 这一年，霍金刚刚 21 岁，在准备剑桥的研究生，被诊断出患有肌萎缩侧索硬化症 (ALS)。医生预言，他还可以再活两到三年，这是大多数患病者的生命年限。比癌症更残酷的是，一旦患上 ALS，患者的肢体将从下到上丧失行动能力，而这个病症以现有的科学手段无法延缓，无法治愈。他将从走路摔跤，无法写字，四肢失去控制，到无法说话，无法呼吸，最终窒息而死。
> > 
> > ## 果壳中的宇宙  
> > 
> > 1970 年，丧失行动力的霍金只能坐在轮椅上，1985 年，他进一步丧失了说话能力，只能靠眼球的移动传达指令。但是，他奇迹般的还活着，ALS 剥夺了他的全部，但是这个残酷的病症唯一留给他的那个清醒而健全的大脑，原本是一个悲惨的诅咒，但在他身上，这却成了整个人类的幸运。
> > 
> > 霍金远远超越了当年医生给他下的死亡判决，并留下经典而不朽的理论和著作——奇点定理、黑洞、霍金辐射、《时间简史》、《大设计》、《果壳之宇宙》……这些让世人震惊的理论与著作都是霍金在患病后的成果。
> > 
> > ![](../Images/ae39433b892b340ec514bb4237faa28d.png)
> > 
> > 头脑灵敏的他，在被封闭在失能的躯壳里面以后，向外界传达自己的思想是一个极其艰难的事情。ALS 患者每发一个音都十分困难。一位来自瑞典的渐冻人林奎斯特（Ulla-Carin Lindquist）在临终前这样写道：「我想说的话似乎到了鼻腔那儿就下不去了。我感到自己的颚部好像裂开了一般。软颚似乎在不断地松懈……我的嘴现在也只能呼呼发出一些不可识别的声音，听起来就好像留声机的唱片在用错误的速度播放一样。」
> > 
> > 但是，霍金的「声音」从没停止。1970 年代初，霍金与彭罗斯合作发表论文，阐释了奇点定理，指出如果广义相对论是正确，宇宙大爆炸前必然有奇点存在，成为首篇重要文章。4 年后，霍金在《自然》杂志中提出，黑洞发出一种能量，最终导致黑洞蒸发，该能量被命名为霍金辐射，引起全球物理学家重视。新发现被认为是多年来理论物理学最重要的进展。
> > 
> > 这些理论解释了困惑人类千年已久的问题：宇宙从何处来，它又向何处去，宇宙有一个开端么，如果有的话，在此之前发生了什么，时间的本质是什么？
> > 
> > 霍金尝试着把问题的答案告诉给更多的人，他先后用常人无法想像的方式撰写了科普著作《时间简史》，《黑洞、婴儿宇宙及其他》，《果壳之宇宙》《大设计》等书籍。其中，《时间简史》一书总销量超过 2500 万册，堪称奇迹。
> > 
> > 自 21 岁患上肌萎缩侧索硬化（ALS），霍金已经与 ALS 病斗争了 50 多年。这 50 年间，这个拥有世界上最灵敏大脑的科学家通过一台台仪器冲破果壳的禁锢，与无限的宇宙相连。那是加利福利亚州的科学家沃尔特为无法发声的霍金编写了名为均衡（Equalizer）的电脑程序，可以让他利用手中的开关选择屏幕上的字母，眼部和头部的运动也可以用来操作开关。
> > 
> > 2012 年，随着疾病的恶化，霍金的脸部肌肉恶性萎缩，传输效率也逐渐降低，每分钟只能讲出一个英语单词。这一次，面部识别技术被采纳，在因特尔提供给霍金的新设备中，语言输出系统可以从他嘴角、眉毛的抽搐中获取文字。
> > 
> > 在所有人都觉得悲伤的病症中，霍金有着他招牌式的幽默和诙谐——他像孩子般兴奋地在个人博客中写道：「这个系统可以让我更好地与外界交流，我现在每分钟可以打出 15 个单词。它还可以发出不同的声调，我的声音就不再像科幻电影里地机器人 Delak 一样了，唯一让我不太喜欢的是，这个机器发出的是美国口音。」
> > 
> > 对于霍金来说，科技的进步是他的幸运，因为在 ALS 没有治愈方法的今天，科技是他唯一的伙伴，是他把自己的智慧与世界联通的唯一手段。
> > 
> > 在《果壳之宇宙》一书中，书的引言引用了莎士比亚剧本里哈姆雷特的话：「即使被关在果壳之中, 我仍是无限宇宙之王。」这句台词，不仅是对宇宙的理解，更像是这个被困在轮椅上的科学家勇敢的宣言。
> > 
> > 在渐冻人这一族群中，霍金无疑是最受关注的一个，但这个世界上还有数十万像他这样的 ALS 患者。而霍金给整个人类的智慧财富无时无刻不在提醒我们，有一个特殊的群体的身体正在备受病痛折磨，但是，他们依旧有着神圣的生命和伟大的灵魂。
> > 
> > 所以，攻克 ALS 疾病，是一个值得让整个人类为之奋斗的目标，不仅仅是为了纪念霍金的伟大贡献，更是为了拯救千千万万个与你我一样的向往自由，但是却被禁锢在「果壳」中的灵魂。
