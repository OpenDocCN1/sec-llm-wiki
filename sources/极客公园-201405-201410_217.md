# 智能硬件：下一个互联网入口？

> > \[核心提示\] 究竟什么才是智能硬件？手机、手环、电视，还是盒子？或者智能硬件应该是一个入口，通向用户所期待的服务。

> > 
> > ## 解读智能硬件
> > 
> > 智能硬件这个词大家已经很熟悉了。最早是智能手机以及智能手环这种智能的可穿戴设备，我们认为智能硬件是通过科技及软硬件结合的方式对已有的设备进行改革。后来智能家居的小设备有了 WIFI 和蓝牙通讯功能，我们可以远程操控、定时开关，我们认为它是智能的。
> > 
> > 再后来智能这个词似乎变成了商业广告的词汇，我们说智能洗衣机可能针对全自动洗衣机有功能上的改进。国内某品牌推出了智能无霜冰箱，我很好奇，和之前的无霜冰箱相比智能在哪？
> > 
> > 功能点和技术上的改进，就可以说它是智能的吗？对于这种智能这个词的滥用，导致了消费者的混淆。到底什么是智能，绝对的智能定义是怎么样的呢？有一些创业者把智能硬件公式化，认为智能等于「硬件＋云端数据＋APP 应用」等于智能硬件。
> > 
> > ![](../Images/06816b920c6ab65a9dc778b4854530e4.png)
> > 
> > 这个到底对不对？我首先问三个问题，为什么智能硬件这么火？为什么智能硬件能够成为互联网团购泡沫破裂以后成为了资本眼中的一块香饽饽？又是什么驱动了互联网的巨头和我们传统的家电企业，都涉及到智能硬件这个领域？
> > 
> > 在与同行产品经理谈论一个产品的时候，我们刚开始会以一个产品的功能、提供的某一些服务是不是智能的来划分智能硬件。后来发现每个人对于产品的理解都不一样，有一些人用智能手机玩游戏、上网看视频，对于他来说可以上网的手机就是智能手机。所以透过表面现象看到本质，我认为智能代表的是服务，是内容，而硬件是传感器，是载体。
> > 
> > 对于智能手环而言，智能体现在基于云端的健康服务，硬件是佩戴在手腕上采集心率和身体指标的传感器。对于智能电视而言，智能体现在增值的视频服务，硬件是视频内容播放的载体。
> > 
> > 智能硬件相当于基于大数据、基于云服务的入口。我们可以回顾一下关于入口的一个故事。
> > 
> > ## 入口竞争
> > 
> > 1994 年微软把 IE4.0 浏览器和 Win95 第一次绑定，打响了争夺的第一枪。经过了这么多年，后来者不断进行公司内部的产品整合，不断进行用户体验的提升，但也只撼动了浏览器入口的半壁江山。
> > 
> > 2005 年浏览器涉及到国内，大家意识到对于互联网争夺的必要性，抢夺我们的默认主页，抢夺浏览器默认的标签栏、搜索栏，甚至增加广告拦截的机制把别人的广告拦在外面。当有成熟的流量的商业模式来支撑这个入口时，各大厂商从软件本身的阵营当中走了出来。有安全浏览器，视频浏览器，有最快速，最简洁的，占用内存最小的浏览器，后来对于入口的争夺不止是浏览器的领域，大家发现桌面更直观。
> > 
> > ![](../Images/1d4a177a23db76e424ee35f738b0adfc.png)
> > 
> > 现在我们喊的口号是「反对占领中环」，2006-2010 年我们的口号是「占领桌面的右下角落」。2010 年的时候出现了一个事情，右下角两大巨头开始顶上了。十一月份我在上班的时候，突然弹出一个窗口，「你使用 xx 的杀毒软件就不能用我的通信软件」了。可见对于入口的争夺已经进入了白热化的阶段，不惜牺牲用户的利益来争鱼死网破，你死我活。
> > 
> > 2011 年电视机从 720P 到 1080P 到 4K，最重要的是可以上网了。不止是视频厂商在这里进行了广大的激烈的争夺，连电商也希望把电视做成第二入口。但是智能电视的争夺到后来慢慢凉下来了，大家发现做智能电视还是那几家传统的厂商。我个人认为这个电视的摊子太大，做屏幕、音响、操作界面，有很多的创业公司甚至是巨头都没有能力来做这件事。
> > 
> > 2012 年盒子的出现，再到 2013 年，智能家居和物联网的概念又再度来袭，做机顶盒只能做电视，做智能路由器不但可以做 PC 和路由设备和电视，还能占领我们传统的家电、小型、轻量的智能家居设备。
> > 
> > 智能路由器代表了一个家庭的互联网的入口。现在是很多的创业的公司在智能路由器上来做，但是我相信在不久的将来，会有我们更大型的互联网巨头也会杀入到行业当中。
> > 
> > 大家为什么来争夺这个入口？因为谁先抢占了这个入口，谁就可以将自己基于云端，大数据，真正的智能的服务推送到用户的手中。
> > 
> > ## 智能硬件的未来
> > 
> > 智能硬件的收费模式目前处于初级阶段，用户还需要为硬件和入口买单。但从电信行业的发展来看，早些年我们需要花几千块钱来买一部手机，每个月还要向电信运营商支付月租费。后来发现把月租费给运营商就可以免费的得到一个手机，智能硬件是不是也能这样呢？
> > 
> > 我们在买一个手环的时候，是真正需要一个手环？需要一个传感器？我们买手环的时候，真正看到的是他能够给我们的生活提供什么样的服务，能通过大数据的积累给出什么样的健康建议，以及如何进入我们的生活。
> > 
> > 所以我认为未来智能硬件的商业模式会逐步的从购买单一的产品，向购买一个入口来购买服务转移。未来购买智能手环时，我们不是跟硬件企业买硬件产品，很可能跟医疗机构、健康机构购买健康服务。
> > 
> > ![](../Images/b05f4c20fd9c402158d5847b8b48f35d.png)
> > 
> > 生产方面手机制造商和运营商是分离的，智能硬件未来会怎么样呢？我认为未来智能硬件发展会让做硬件的人更专注于做硬件，做服务的人更专注于做服务。让互联网企业有互联网思维的人把服务做好，让有硬件供应链能力的大佬们把硬件做到最便宜、功能做到极致。这样才能真正让用户得到最好的体验，将用户体验能够做到极致。
> > 
> > 现在的智能硬件不乏让人眼前一亮的产品，但我们的服务还没有做起来。相对的移动互联领域已经成熟，最开始支持游戏和上网等基本功能，自从软件与传统行业的整合，推出的服务能够真正的改变人们的出行方式。这样的服务希望通过同行不断的资源整合，能够在不远的未来从智能硬件领域推出一个真正改变人的生活、让大家觉得用这款产品生活真的方便、跟以前不一样的一款服务。
> > 
> > 那么微动到底做什么？我一直在说一个入口，有的时候你会认为在移动互联领域，手机的 APP 是一个入口，手环、手表是一个入口。微动的想法是你伸出双手的时候，已经进入了移动互联和物联网的领域，伸出双手就可以享受到基于第三方、大数据、云端服务的体验，谢谢大家。
