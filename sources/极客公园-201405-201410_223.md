# 未来支付不可错过的六大变化

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200858116&idx=3&sn=52704a0245eb4c4ec1300b26a75dbcbb&chksm=eb8da7b2dcfa2ea42f0175cf064921d317cc7341d834f6970da751142056dcb629203133d46b&scene=126&sessionid=1681312995#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200858116&idx=3&sn=52704a0245eb4c4ec1300b26a75dbcbb&chksm=eb8da7b2dcfa2ea42f0175cf064921d317cc7341d834f6970da751142056dcb629203133d46b&scene=126&sessionid=1681312995#rd)

> > \[核心提示\] 未来支付领域，将会继续发生哪些变化？有哪些新的机会？
> 
> > 数字支付的兴起，支付渠道的多元化，支付领域正在产生变化。未来，这些变量仍将继续发酵。
> > 
> > 未来使用什么货币，怎么付钱，支付渠道会有哪些变化？可以跟我们一起看一看。
> > 
> > ## 1、二维码带来的 O2O 支付机会
> > 
> > 二维码是连接线上和线下的好工具，这在营销和传播领域已经得到了印证。但其实二维码更可以变成一键支付工具，无论是对商家还是消费者，都是好事一件。
> > 
> > ![](../Images/b6916cc2c8dc4e05048fc5264616e4d3.png)
> > 
> > 星巴克年初在 iOS App 中，新增了二维码支付功能。顾客只需摇一摇手机就能获取一个付款二维码，店员直接扫码就能完成首款，用户还可以自愿多支付一些小费。目前这项功能仅限于美国用户。
> > 
> > ![](../Images/283c7defca74f15d75adb814153dd20f.png)
> > 
> > 7 月 25 日，顺丰开始在深圳地区试水微信支付业务，用户只需通过微信「扫一扫」快递员给到的二维码，就能完成支付，当然前提是用户开通了微信支付。新的二维码功能将会全面覆盖电话、App、微信下单等顺丰现有的寄件方式，并有望在全国范围内推广起来。
> > 
> > ## 2、非接触式支付正在兴起
> > 
> > ![](../Images/87271ef1a90f3510f2c67711d86d08ca.png)
> > 
> > 在生活中的小额日常支付，非接触式支付正在，MasterCard PayPass、Visa payWave、中国银联闪付，都在拼抢这一块市场。从体验看，小额免输密码更简单、更快。
> > 
> > 如果你附近有麦当劳，可以去体验一下这种「晃卡」的支付体验。
> > 
> > 更大的机会是，借助声波、二维码、指纹等方式，信用卡本身将有机会数字化。用户可以自行选择卡片消费，而无需携带卡片本身。
> > 
> > ![](../Images/3f283daa95e51166a25c03d98073850a.png)
> > 
> > 而在 2013 年底，支付宝也宣布和银泰合作。合作银泰门店的所有收银台都已支持使用支付宝钱包付款，消费者打开手机上的「支付宝钱包」，选择「当面付」，分别可以扫码支付与声波支付，其中声波支付还可以在没有网络的情况下通畅使用。
> > 
> > 个人亲身试用的感受，支付宝的声波支付很敏捷，减少了主观上的物理操作，而且无需签名和纸质回单，简单而轻松。
> > 
> > ## 3、电子货币，从金融工具到消费工具
> > 
> > 以比特币为首的电子货币，在过去留给大家的最大印象就是投机工具。一个货币，如果没有进入到市场上被消费，就算不上是真正意义上的货币。尽管我曾经用比特币从推友中买了一部 Nexus 5，但这代表不了什么。
> > 
> > ![](../Images/376f5e8b137a104cdadd64995d98e034.png)
> > 
> > 目前美国新蛋、戴尔、星巴克均已支持比特币支付，这些「传统商家」的认可，意味着比特币的价值已经进入一个相对稳定甚至看涨的阶段。这似乎是在初期的投机炒作后，比特币又重新回到了发展轨道。
> > 
> > 交易平台、ATM、消费商家、整合型支付平台正在一步步补齐，比特币拥有无国界、抗通胀的优势，未来值得期许。
> > 
> > 当然，以上说法仅限中国之外。目前受限于官方规定，比特币的落地仍然走在法律红线。
> > 
> > ## 4、身体支付，无须借助外部介质
> > 
> > 支付需要的外部介质会越来越少，会充分利用已有设备的能力。未来，指纹、人脸、视网膜、虹膜、声纹甚至皮下芯片等生物体征，都可能成为用户授权支付的方式。
> > 
> > ![](../Images/a50cd6d52f9d101ad72e5f3a62ddfc94.png)
> > 
> > PulseWallet 这家公司主张用静脉进行支付，每个人的静脉图像保持不变且不会出现重复，所以为扫描静脉图像进行支付提供了可能。它通过内置的红外相机拍摄用户静脉图像，确认身份后从已绑定的信用卡中扣款。这是一种非入侵式的支付体验，你可以通过「你自己」来证明「你自己」。
> > 
> > ## 5、无人支付，没人也能付钱
> > 
> > 当你产生一个消费行为，直到你付账的的全过程，都完全没有人的参与，这是怎样一种体验？不需要人值守，自动提供服务，自动收款，效率极大地提升。
> > 
> > ![](../Images/0b9d4dda1d0103f160db52c9304c3155.png)
> > 
> > 支付宝在北京和无忧停车合作试点「智能停车」：汽车在车库入口时，高清摄像头会自动识别车牌号并放行。取车前，系统会自动发送包括停车场名字、停车时间和车费信息在内的缴费页面，车主可以直接在公众号中缴纳停车费。
> > 
> > 如果你想要体验，可以前往北京清华科技园、北京人民医院、世贸百货 3 个停车场试用。
> > 
> > 通过摄像头、传感器、数字支付结合的无人支付，将在停车场、收费站、自助购物等领域极大提升效率。
> > 
> > ## 6、银行卡的智能化
> > 
> > 从 1915 年银行卡被发明开始，银行卡越来越成熟，但也越来越缺乏变化。以 Coin、万卡为代表的多合一刷卡设备刷新了大家对银行卡的认知，但未来可能不止如此。
> > 
> > ![](../Images/f4d2c23bb790197f56ac840b3592162e.png)
> > 
> > 在跟万卡 CEO 王博的交流中，他们获得最大的技术突破在于：**通过可弯曲的柔性电池、以及芯片技术结合，可以把具备无线连接能力的设备，做到跟银行卡一样薄。**
> > 
> > 这意味着未来的银行卡也许可以整合 U 盾，可以打电话，可以刷公交，可以整合你生活中的其它卡片。
> > 
> > 截止去年年底，中国信用卡的发卡量已达 1.9 亿张。如何基于这样一个大的体量，让卡片承载除支付之外的更多功能，融入消费者的生活里，这是「银行卡」的下一个机会。
> > 
> > ## 支付的未来：融合与提升
> > 
> > 支付是科技创新中不可或缺的环节，上面我们总结到的这些支付领域的新趋势，从支付方式、渠道、场景都对现有的支付方式做出了大量新的想法和可能。
> > 
> > 不断融合新出现的科技技术，提升用户支付的能力和范围，将会为我们未来的生活带来极大的便利。
