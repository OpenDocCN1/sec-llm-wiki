# 明星怎样从互联网产品中掘金？

> > \[核心提示\] 广告代言的方式正走向落伍，互联网产品和明星的合作正在出现新的形态。
> 
> > 最近关于美国老牌好莱坞影星汤姆·汉克斯（Tom Hanks）的最大新闻，倒不是他又出演了哪部电影，而是一款和他一样「老气」的 App。
> > 
> > 汤姆·汉克斯老当益壮，不仅依然活跃于影坛，更于数天前跨界推出了一款模拟老式打字机的 iPad 应用——Hanx Writer。该应用高度还原了打字机敲击时的动态和音效，同时在应用启动界面还有汤姆·汉克斯的签名。
> > 
> > 就是这样一款简单的产品，在复古潮流和汤姆·汉克斯的强大号召力之下，居然迅速登顶多个国家的 AppStore 榜首，收获了上百条评论和高达四星半的好评。
> > 
> > 无独有偶，今年夏天最火爆的手游之一「金·卡戴珊：好莱坞」，正是由美国娱乐界名媛金·卡戴珊（Kim Kardashian）亲自打造。这款养成类游戏让玩家扮演金·卡戴珊的角色，体验奢华的明星生活，一步步将自己培养成国际巨星。
> > 
> > 「金·卡戴珊：好莱坞」在 AppStore 上同样获得了骄人战绩，上线一个多月就登上了应用下载量第一和收入排行榜第四的位置。它的营收成绩同样出人意料，上线五天即获得 160 万美元进账，分析师认为它的全年收入将达到 2 亿美元。
> > 
> > ![](../Images/53c416deb316662b11626861e4e7f320.png)
> > 
> > ## 明星应用何以火爆？
> > 
> > 当然，上面说的两款产品不会由汤姆·汉克斯和金·卡戴珊本人开发，其背后各有一个成熟的团队来进行开发和运作。
> > 
> > 「金·卡戴珊：好莱坞」的游戏开发公司是美国的 Glu Mobile 工作室，它此前推出的手游「猎鹿人」在 iOS 平台也获得了较高评价。「金·卡戴珊：好莱坞」的成功让 Glu Mobile 的股价涨幅超过 58%。
> > 
> > Hanx Writer 的开发者 Hitcents.com 同样是一家游戏公司，「画个火柴人」（Draw a Stickman）、「激战毛毛虫军团」（Battlepillars）等知名游戏都是它的作品。
> > 
> > 其实无论国内外，借助名人效应做应用早已屡见不鲜。麦当娜早在 2010 年就推出了其官方 App，而国内则在 2012 年掀起过一波名人 App 的浪潮，诸如王力宏、吴秀波、杨幂等都曾推出过面向粉丝的 App，但不久后就销声匿迹。同样是名人应用，汤姆·汉克斯和金·卡戴珊为何能够获得这么大的成功呢？
> > 
> > *   首先，作为一款产品而言，具备一定水平的开发能力是必备条件。Hanx Writer 和 「金·卡戴珊：好莱坞」的开发者都是成熟的专业游戏开发商，开发和运营经验丰富，它们做出的产品能够达到让用户满意的质量；而那些名人 App 多数为外包团队制作，界面粗糙，内容更新缓慢，导致用户体验极差。
> >     
> > *   Hanx Writer 和 「金·卡戴珊：好莱坞」的是典型的免费增值模式产品，通过内置的道具和装备等来获得收入，收费的地方都经过了精巧的设计；名人 App 往往赤裸裸地售卖单曲、签名本、明信片等，且互动性不佳。
> >     
> > *   Hanx Writer 上线之前，汤姆·汉克斯就已经在纽约时报上撰文，表达自己对老式打字机的情怀和热爱，做好了前期预热；而金·卡戴珊在媒体上一直保持着高度曝光，她的明星生活是很多女性追捧的对象，而「金·卡戴珊：好莱坞」所瞄准的正是女性用户。
> >     
> > 
> > ![](../Images/8eb5a3dda17566e13af0f195b994dd87.png)
> > 
> > 这也就解释了，为什么在 2012 年国内那波名人 App 中，韩寒的「ONE·一个」能够存活至今并维持百万量级的用户规模。「ONE·一个」的开发者是 Clover·四叶新媒体，AppStore 里口碑甚佳的 iDaily、Days Matter 都是它的作品。而「ONE·一个」在后期运营上也坚持了内容型产品的定位，持续为用户提供优质的文章。
> > 
> > ## 应用开发推广的新机遇
> > 
> > 国内的新应用推广一直面临着传播渠道单一的问题，此前的魔漫相机、脸萌、神经猫等都依靠微信朋友圈火起来。其实，随着国内娱乐产业的日益成熟，丰富的明星资源同样能够成为 App 的推广资源。
> > 
> > App 和明星的合作可以绕过传统的广告代言模式，采用新的分成或口碑传播模式。根据娱乐新闻媒体 TMZ 的报道，卡戴珊将从 Glu 的这款手游中获得 45% 的净利润分成，如果该游戏能实现 2 亿美元的收入，则意味着卡戴珊可以分得 8500 万美元。要知道，卡戴珊 2013 的收入为 2800 万美元。
> > 
> > 而对汤姆·汉克斯来说，Hanx Writer 里付费购买的打字机样式带去的分成虽然并不多，但这款产品的气质与他的个人形象高度一致，起到了品牌传播的效应。
> > 
> > 对于这两款产品的开发者来说，明星既是很好的传播枢纽，也是游戏设计的 IP（Intellectual Property）资源。这比单纯围绕明星本身做的产品更能向其他非粉丝的用户普及。
