# same：「无聊社交」的高留存率之谜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200854581&idx=2&sn=e3992e485383c4a3aae59f92215e5552&chksm=eb8db183dcfa38957cd6adcb05ac4ff84928b2b706e3ec3d311c474ee9030e15bfa8e9dabc0c&scene=126&sessionid=1681312995#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200854581&idx=2&sn=e3992e485383c4a3aae59f92215e5552&chksm=eb8db183dcfa38957cd6adcb05ac4ff84928b2b706e3ec3d311c474ee9030e15bfa8e9dabc0c&scene=126&sessionid=1681312995#rd)

> > \[核心提示\] 一个不到 10 人的小团队，一款几乎从不推送、产品设计上无关注、无关系沉淀的「无聊社交」产品，如何做到漂亮的的留存率？
> 
> > > 「我活了二十多年，这是我见过最闲极无聊的 App。」
> > 
> > 一位网友这样评价 same。
> > 
> > Same 上线于 2012 年夏天，是一款主打陌生人间状态社交的移动产品。在这里，用户创建了上万个纷杂的主题频道，以图文音乐等形式记录着自己的日常生活状态：吃饭、抽烟、等人、加班、坐马桶……所有人看起来都很闲，光是随手拍照，你就能找到拍冰箱、拍井盖、拍 bra 等几十个流派的同好。而在一个名叫「专注呼吸二十年」的频道，里面的人只交替反复地发两个字：呼、吸。
> > 
> > 没有 LBS 功能，没有性别筛选，无法导入通讯录或微博好友关系，如果说它是基于兴趣的社交，其实兴趣的味道也不是特别浓。如果你在 same 中，对某人的发言感兴趣，你能做的只有给对方点一个「同感」，或者直接私聊过去：hi，你也在呼吸啊？
> > 
> > 就是这样一个无厘头的 App，放眼望去，全是无聊的陌生人在打卡、自拍、自言自语，你会不会觉得，这个少年有点前途堪忧？
> > 
> > 那么也许这组数据会让你吃惊。几天前 same 工程师刘旸在知乎晒出了一张留存率数据：
> > 
> > > 次日留存一直保持在平均 50% 以上，5 日后留存在最近一周也达到了 30%。

> > 
> > 值得一提的是，same 整个团队不到 10 人，几乎不给用户推送内容。作为一款弱需求、弱关系、弱运营 App，Same 是怎么把留存率做到这么高的？
> > 
> > ## 反主流设计：无关注、无沉淀
> > 
> > 社交产品的思路通常有这么几种：熟人靠圈子，匿名靠爆料，陌生人社交靠机缘巧合。「缘分」这一抽象概念的表现形式也有很多种，有的产品把它简化成了「摇一摇」，有的则用算法为你推荐「可能感兴趣的人」。但 same 的做法是，设计了一套超扁平的社区。
> > 
> > 在社交这件事上，主流产品仍维持着关注或双向关注的人际关系模式，大家已经习惯了交换 ID、互加好友、折腾一份关注列表。而在一个无聊社交 App 里，真的有必要关注一个人，让他的消息（如呼、吸……）挤爆我们的 timeline 吗？
> > 
> > Same 没有这样做，这正是它与其他产品的差异所在：无关注。一方面，无关注干掉了那令人焦虑的消息列表，以及「关注」与「取关」之间的烦恼。另一方面，摆脱了「粉丝数」这项考量，没有了「小透明」与「大大」的分别，same 社区中的每一位用户都是平等的普通人。
> > 
> > 在各代主流网络社交产品中，风光总是由少数老资历用户和明星用户占据着。而使用过 same 的人，总会感叹它的包容性和活跃度——即使是初来乍到的新人，发一条自己随意创制出来的内容，也可以获得良好的反馈效果。这种来自陌生人的源源不断的激励，是 same 互动的一大特色。
> > 
> > same 没有其他社区通常会采用的激励性手段，如转发数、评论数、精华、热榜、推荐等；所有频道内容都按事件流排列，同一个频道内，所有内容被他人浏览的机会都是均等的；用户和内容不能被检索——而这些，无一不是「内容沉淀」的杀手。
> > 
> > same 想得很明白，它是一个无聊社交 App，不是社交媒体，也不是专业社区，内容只是与陌生人形成话题的引线。这种引线应该是不断流动、扩充的，内容沉淀反而不利于用户刷新自己。试着想想看，当第十个陌生人夹着一条你去年的状态找你聊天时，你会用什么样的表情去面对？
> > 
> > 正是「无关注、无沉淀」的超扁平社区结构，把用户从熟人关系和社交规则的捆绑中解放出来，鼓励他们不断地发现更多有意思的人，让每个人真诚、有趣的一面，都能被他人发现。
> > 
> > ## 宽松氛围不运营
> > 
> > 两年前，豆瓣阿北曾在极客公园大会上提出过「不运营」的说法，并不是真的不招运营，而是不刻意地用运营掩饰产品的不足。他认为，运营所做的事情都应该由产品来实现。
> > 
> > 比起其他一些社交产品在运营方面投入的大量人力物力，same 算不算这种「不运营」呢？
> > 
> > 正如前文中所说的，same 早已在基因中将所有游戏规则设计写好，小秘书在其中扮演的戏份非常少。它的社区结构使它呈现出强烈的「去中心化」特点：没有明星用户，没有事件营销，没有内容推荐。由于内容不会通过人际关系大规模传播（用户只能把内容单独分享给某个近期联系人），也就不存在病毒营销、谣言传播的温床。
> > 
> > 另外，出于对用户和每一条消息的尊重，same 的运营机制相当平柔，小秘书通常不会删除消息，而是把对不符合频道氛围的内容进行折叠的权力交给了频道主。即使频道主洁癖发作，将某条内容折叠了，这条消息也仍显示在作者的时间线上。
> > 
> > 当然，same 的运营工作也一直没闲着，经常会结合 App 自身气质发起一些很搞的活动，如「脚拍（不是拍脚）大赛」。
> > 
> > 在这种宽松的氛围中，用户可以尽情释放能量。再加上可爱的 UI 设计，语音贴纸，高效的聊天系统，以及无处不在的彩蛋，也为 same 吸引来不少忠实用户。
> > 
> > ![](../Images/6f2e6f7d0420455f37c0a931203fc08b.png)
> > 
> > *虽然是一款无聊 App，same 的玩法却很多样*
> > 
> > 尽管 same 经常被拿来同豆瓣相比较，但我个人感觉它的气质更接近另一个社交网站，饭否：二者的设计上都极为简洁、舒适，内容都以「记录生活」为初衷，用户之间相对平等，话唠，卖萌，没节操，对熟人关系敏感而排斥。由于种种原因，饭否团队已经解散，目前只是在前员工的义务维护下如幽灵船般运转，却仍有着极高的用户忠诚度和活跃度。饭否某种意义上的成功，证明了这类产品的独特魅力，same 漂亮的留存率，也许仅仅是一个开始。
> > 
> > 当主流社交产品的缺陷陆续显露出来，疲惫的用户也在寻找新鲜、有趣、无压力的社交新方式，same 作为一款气质独特的社交产品，把浮躁世界中的陌生人社交做得温柔善意，毫无做作，它的做法是值得思考的。
