# Hippo-ADK ：二手手机也是生产力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200841865&idx=1&sn=302d99c9a5225cd3e3f7742d7ab34b0c&chksm=eb8de73fdcfa6e2904533010b349c3bfa47c9956f0317d63a1d328c01ada990efd0946d40d43&scene=126&sessionid=1681312998#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200841865&idx=1&sn=302d99c9a5225cd3e3f7742d7ab34b0c&chksm=eb8de73fdcfa6e2904533010b349c3bfa47c9956f0317d63a1d328c01ada990efd0946d40d43&scene=126&sessionid=1681312998#rd)

> > \[核心提示\] 硬件创新正在重回手机，能否借助二手手机富余的计算能力，用手机替代硬件传感器？这将加快硬件从构思到 demo 的迭代时间。
> 
> > IDC 预测未来几年智能设备将保持高速增长，当下的热潮才刚刚开始。在智能生活到来前，基于基础硬件模块的创新却面临着两个问题：
> > 
> > 1.硬件成本高，组建好一个硬件原型需要各种 PCB 板和元器件。
> > 
> > 2\. 存在硬件资源冲突风险：不同输出接口可能发生冲突（Ardunio 每一 I/O 接口只能同时输出一种信号）。
> > 
> > 此外，电路板和铜线散发出阵阵高等数学般的恐惧，让普通爱好者敬而远之。硬件创新能否变得更简单？
> > 
> > 最近上线 kickstarter 的中国团队 Hippo Device 提供了一种新颖的解决方案——Hippo-ADK。
> > 
> > Hippo-ADK 是基于 Ardunio 的安卓手机创意实现平台，将手机中的传感器为自己所用。手机和 Hippo 开发板连接后，你就可以直接调用手机中的各种传感器，摄像头等硬件。Hippo ADK 利用智能手机内部资源，已经实现了自平衡机器人、视频监控等各种 DIY 原型开发。
> > 
> > ## 手机资源等待解放
> > 
> > 美国国家航空航天局从 1961 开始实施阿波罗登月计划，使用的第三代计算机每秒的计算速度从几十万到几百万次。而如今双核主频 1GHz 手机，即使每一个时钟期进行一次运算，每秒都能完成 10 亿次运算。此时千元下的红米手机都已配置了 MTK 4 核 1.5GHz 芯片。
> > 
> > 手机的计算能力在过去几年取得了大幅度的提升，然而我们沉迷于太空版愤怒的小鸟的时间却远远超过登月的思考。
> > 
> > 能否借助手机富余的计算能力，用手机替代硬件传感器，这将加快硬件从构思到 demo 的迭代时间。
> > 
> > 手机中包含传感器、通信模块、摄像头等硬件模块，也包含图像、语音识别等软件算法功能。其中摄像头、音频以及识别算法都是 Arduino 几乎不能实现的任务。Hippo Device 将 Hippo-ADK 的硬件资源进行了封装，用户无需同时在硬件、Android 端进行开发以及协议适配。只需在 Android 端使用 Hippo Device 提供的 JAVA API 或者图形化编程界面即可完成软硬件互动应用。
> > 
> > ![](../Images/58aa667352af8dc144c6d38676fcdb5c.png)
> > 
> > 由 Hippo-ADK 改造而成的自平衡射击机器人
> > 
> > 这样，省去购买其他元器件的成本和存储空间并且避免了接口冲突，只要一部二手手机，一块 Hippo 开发版，创客们就可以利用他们尝试硬件创新了。对于非深圳地区的创客，这将消除淘宝购买元器件的时间延误，而聚集了大量软件开发者的北京，创业者们的软硬结合化学反应被催化。
> > 
> > ## 硬件创新回归手机？
> > 
> > 小米手环并没有将其他手环杀死，恰恰给这片虚火泼了盆冷水。79 元的价格让围观者跌破眼镜，确实逼近了手环批量生产后的成本价 59 元。**当小米手环的利润远远低于小米手机时，躁动的创业者应该明白：穿戴设备仍旧只是手机的附属品。**
> > 
> > 无论是智能手环还是智能手表，目前在续航时间和计算能力上都不足以独立于手机之外。小米手环可以续航 30 天，但功能也只停留在计步和睡眠检测，所有数据通过云端处理并由手机显示。锁屏解锁和来电提醒巧妙地绕过了计算耗电的难关。
> > 
> > 在可穿戴普及之前，社交和大数据只是美好的愿景。相比于蓝牙耳机，可穿戴设备只是有较好的移动客户端，以及丰富的传感器。
> > 
> > 这类新产品售出之后都会产生大量未曾定义的数据。以 Jawbone 和 Fitbit 的血压数据为例，Jawbone 额外包含心律数据，Jawbone 在不同时间进行采集，Fitbit 则先显示一定时间内的平均值，然后是一个序列测量值，另外，对于同样数据，名称不一样。希望使用他们的数据，开发者不得不分别阅读文档，再跟他们的云端接口做集成，一旦集成产品种类太多，难度非常大。
> > 
> > ![](../Images/87b5e9fffb0d9700cf07c702481ab95a.png)
> > 
> > Jawbone 和 Fitbit 的血压数据的不同代码结构
> > 
> > 苹果和谷歌已经开始将这盘散沙收拢到手机内，今年的 WWDC 上苹果针对健康领域和家居领域推出了 Cloudkit 和 Homekit，随后，在 Google I/O 推出的 Google Fit 可以收集不同来源的数据，帮助用户追踪数据。
> > 
> > **更低功耗的芯片被开发出来时，首先将被利用到占据你每天使用时间最长的设备上，短期内这台设备依旧是手机，只有当手机无法完成时才可能产生新的平台。**
> > 
> > 「我们希望能做成更多的创客玩具。」
> > 
> > 交谈结束，Hippo-ADK 的创始人杜鹏，在电话一端畅想下了未来。
> > 
> > 稍作停顿，电话那一端将后半段话传过来：「毕竟很多伟大的创新就是从玩开始的。」
