我是一个独立音乐爱好者，每天都使用 Spotify 收听歌曲。一直以来，我用它都很开心，但是任何一款伟大的产品，都仍然会有提升的空间。在快速可用性测试后，我们发现了一些在使用 Spotify 功能时遇到麻烦的问题。

我的目标：

发现用户在 PC 端使用 Spotify web 版本时：查找、组织和分享音乐中的痛点。

Spotify Web App

正如你所看到的，有很多问题会在这里，我不打算在这里讨论它们。相反，让我们来看看一些重点的变化，可以让使用 Spotify 有一个更愉快的体验。

问题与方案

问题 1：搜索结果难以筛选

（1）用户希望能够定制自己的搜索结果。我的一个用户曾经说，「我不使用 Spotify 的原因是，我用它发现任何东西都很难。」

如图所示，用户希望找到标题包含「游客」的歌曲。

用户在搜索栏中输入「游客」，但结果无法进行分类或筛选，于是用户找不到预期想要的歌曲。

如果试试这么设计呢？

在每个分类旁边加上筛选的小箭头，允许用户通过艺人或专辑甚至发布日期排序/筛选歌曲列表会怎么样？正像富有才华，受人尊敬的设计师丹尼尔·布尔卡说的那样，「...... 用户不是要试图将结果分类地更好...... 他们正试图筛选出结果。」

（2）在 Spotify 的分类展示中，有这些项目，比如：专辑，艺人，资料，歌曲列表和歌曲，但是他展示的方式却让用户感到十分迷惑，因为他们长得太像了。

如果试试这么设计呢？

可以有一种方法巧妙的区分这些结果，我在下图进行了详细说明。

1. 频道标签名称替换掉了所有的大写字母

2. 删除了查看全部以免造成混乱

3. 为了区别内容，在视觉上我做了一些改变，比如专辑我添加了表示录音的 icon

4. 艺人资料喔添加了一个表示人物的 icon 来区分这部分内容

问题 2：工具提示令人混淆

在用户认知中，「＋」意味着「添加」，而不是其他的意思比如「保存」、「关注」、「空白」，因此 Spotify 对「＋」的解释让用户感到迷惑。

1. 「按一下这个按钮，我觉得会将这首歌添加到我的播放列表。它会保存在哪里？」

2. 天哪！太令人迷惑了！

3. 为什么这里会出现这个功能？

在测试中，所有第一次使用使用该功能的用户都点击「+」号来添加第一首歌曲到他们的播放列表。即使他们后来意识到这不太对，还是有一半的用户仍然再次小心点击了它。这个图标也显示为「追随」和「空」在不同的页面，如下图所示。用户对这种不一致感到非常困惑。

在鼠标划过的时候，「＋」提示保存，但是我会保存在哪里？

然而这里「＋」却代表关注

在播放列表页面，此按钮没有工具提示，这显然是没有帮助的

如果试试这么设计呢？

「＋」的图标表示添加功能，让用户可以选择播放列表并把歌曲保存到这个播放列表里。

在用户点击「＋」后，出现下拉列表，用户可以选择添加到自己已有的播放列表或创建一个新的播放列表。

问题 3：我为什么关注？

这里的关注按钮让所有使用它们的人感到迷惑，每个用户都认为他们关注的艺人会在左侧面板的关注按钮下展现，但事实并非如此。

1. 我关注的那些艺人在哪里？

2. 「following」是什么意思？

3. 我仍然使用搜索来找到艺人而不是使用关注功能

用户希望关注页面可以为他们展示他们已经正在关注的艺人，而现在，页面只有三个选项。

左侧面板的「follow」按钮会让用户认为来到这个页面可以查看到自己关注的艺人

如果试试这么设计呢？

在关注页面添加已经关注的艺人模块，展示艺人最新动态，巡回演出时间和清楚的的购买票务信息。
