> > \[核心提示\] 微信发布了 5.4 版，新增了哪些亮点？让我们一起来看看
> 
> > 今天，微信官方正式发布了 5.4 版本，目前仅上线了 iOS 版，Android 版本预计将于稍晚放出。5.4 版微信的重大更新包括：微信搜索支持搜索更多内容、正式适配 iPad 平板电脑。
> > 
> > 以下为官方 5.4 更新说明
> > 
> > 1\. 现在除了搜索联系人和聊天记录，还可以搜索公众号、公众号文章、收藏、微信功能
> > 
> > 2\. 查看图片时，可以识别图中的二维码
> > 
> > 3\. 面对面收钱：通过二维码给身边的人转账
> > 
> > 4\. 适配iPad
> > 
> > ## 搜索功能支持更多内容，微信搜索初见雏形
> > 
> > ![](../Images/6287345dbf6972997d478546cba0ff71.png)
> > 
> > 微信 5.4 对搜索进行了增强，除了此前能搜索的联系人、群聊外，新版本新增了对以下三类内容的搜索功能：
> > 
> > 1\. 公众号：查找与关键词匹配的微信公众账号，包括订阅号与服务号
> > 
> > 2\. 公众号文章：查找与关键词匹配的微信公众账号文章
> > 
> > 3\. 收藏：查找用户微信收藏中与关键词匹配的内容
> > 
> > 4.微信功能：查找与关键词匹配的微信功能，如查找附近、摇一摇等，相当于一个
> > 
> > 微信新版本增加了对公众账号、以及公众帐号文章的搜索，意味着微信用户将不仅只将微信作为一个社交工具，依靠大量公众订阅号与服务号，用户将能够从微信信息大海中找到自己想要的信息，构建一片完整的搜索新生态。预计这将会对目前市场的主流传统搜索，如百度、360 搜索、搜狗造成影响。
> > 
> > 值得注意的是，在去年 9 月被腾讯 4.4亿 美金战略投资后，搜狗在 6 月 9 日宣布搜狗搜索正式支持对微信公众号以及文章的支持。
> > 
> > 而被业界所看重的微信服务号，也将极大地获利于微信搜索的增强。如未来微信用户可能会通过如下关键词进行搜索：
> > 
> > *   快递
> >     
> > *   二手交易
> >     
> > *   北京租房
> >     
> > *   我要订外卖
> >     
> > *   …
> >     
> > 
> > 预计随着微信流量的成长以及社交链式传播的优势，基于微信搜索的搜索引擎优化（SEO），将会逐渐成为一个新的热点。
> > 
> > **总结**：微信 5.4 通过对搜索功能的增强，弥补了微信随着功能不断增加，在信息索引方面的不足，帮助用户更快找到需要的内容，同时也扩展了微信的应用范围。
> > 
> > ## 智能识别图片二维码，强化虚实转化
> > 
> > ![](../Images/826adc89480437750e8471947aa8c011.png)
> > 
> > 二维码是商户转化线下客户的最主要方式，而如果是用户通过拍照发送到微信朋友圈里的二维码，通常识别需要先保存，然后再点击选择图片识别，流程非常麻烦。
> > 
> > 微信 5.4 可以智能识别有二维码内容的图片：点击查看包含二维码的图片，长摁屏幕即可快速识别二维码内容，并直接呈现内容。
> > 
> > 预计，这一功能将增加二维码内容在微信中的传播率，也会有更多商家使用「微信扫描二维码」来进行营销活动。
> > 
> > ## 增加对 iPad 设备的兼容，大屏微聊不是梦
> > 
> > ![](../Images/2b1a657b3aa2bf957e74d983292e7cf1.png)
> > 
> > 微信 5.4 还新增了对 iPad 平板电脑的支持，总有那么一些用户，如对屏幕有偏好的设备的长辈、采用功能机与 iPad 搭配的学生、或者喜欢一边看电影一边刷朋友圈的白领，他们希望能够在大屏幕设备上面使用微信。
> > 
> > 根据我们的测试，目前 iPad 版微信仅仅是对手机版的 UI 做了放大，尽管运行没有黑边，显示也更清晰，但是生搬硬套手机 UI，难免用起来太费劲。
> > 
> > ![](../Images/27b5b41d6e23cbaecd5918dfb65b798f.png)
> > 
> > iPad 版微信可以支持与手机版同时在线，用户在首次使用可以选择是否同时使用，如果是的话可以通过手机扫描二维码一键登录。
> > 
> > **我们进行了一个奇怪的实验：微信目前有手机版、iPad 版、Mac 版、网页版，是否可以支持四设备同时在线呢？**
> > 
> > 我们测试的结果是「否」，微信 5.4 在手机之外只能额外支持一个设备同时登录，之前登录的设备会被自动登出。
> > 
> > **提醒**：目前 iPad 设备在 App Store 内暂时还无法搜索到微信，如果你遇到这个问题，可以调整顶部筛选功能为「仅 iPhone」。
> > 
> > ## 二维码收款，身边支付更方便
> > 
> > ![](../Images/e133636b1aa8a07c80ae28ff8b7405e9.png)
> > 
> > 微信 5.4 版还对微信钱包的转账功能进行了更新，当选择面对面收钱时，将会弹出二维码支出，让经常 AA 聚餐的用户支付更便利。
> > 
> > 作为常年支付宝用户表示，之前没有转过账的朋友使用二维码的确还不错，但大家在一起的时候「咻咻咻」的声波支付更方便更性感，希望微信下一步会支持。
> > 
> > 最后，欢迎大家在微信打开上方二维码，长摁测试微信钱包「二维码支付」功能。
