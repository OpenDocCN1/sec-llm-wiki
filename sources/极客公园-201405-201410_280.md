# 科技让人更有尊严：高科技轮椅 WHILL

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200788703&idx=3&sn=0a64b668d2aaa762d83c03a78f27cc8f&chksm=eb82b769dcf53e7f5a4d460b92d4d36d4f65ba2351eab0dcf45e920de6288fc282cc0b1a5da6&scene=126&sessionid=1681313001#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200788703&idx=3&sn=0a64b668d2aaa762d83c03a78f27cc8f&chksm=eb82b769dcf53e7f5a4d460b92d4d36d4f65ba2351eab0dcf45e920de6288fc282cc0b1a5da6&scene=126&sessionid=1681313001#rd)

> > \[核心提示\] 科技除了利用自己技术、设计上的优势，让生活更有质量，还能让一些人生活得更有尊严。
> 
> > ## 前言
> > 
> > 轮椅是很多功能障碍人士、老年人必须的工具的，但是传统的手摇轮椅或电动轮椅都会给人感觉一种「坐在上面的是残疾人」的固有印象，我们会觉得 X-man 里 X 教授很酷，也是因为他坐在一个科技感十足的轮椅上，你会认为这是一种新的个人化交通工具，而不是一辆带着「残障人士」标签的轮椅。
> > 
> > ![](../Images/7fac409c33f638f8dc87a2981d53bcdf.png)
> > 
> > ## 概览
> > 
> > WHILL 就是一辆让乘坐人更有尊严的轮椅，非常现代、漂亮的外形，充满人性化设计的功能，足以应付各种生活场景的变化模式。WHILL 甚至可以作为新时代的个人交通工具适用于任何人。
> > 
> > 📹 [None](None)
> > 
> > ## 功能 & 特点
> > 
> > 首先，WHILL 的外形非常具有现代感，带有科技感的指示灯、金属材质与光滑的曲面共同组合成 WHILL 的外观，人们看到 WHILL 后都会称赞它漂亮的外形，并且不再认为乘坐者是一个孱弱的「功能障碍人士」或随时需要帮助的老人。
> > 
> > ![](../Images/9e769a9fbed63c903a2ba027e6d3acee.png)
> > 
> > WHILL 的前轮采用了独特的设计，这使得 WHILL 的转弯半径只有 72 厘米，乘坐者可以在狭小的空间内灵活转动。
> > 
> > ![](../Images/e84b1ad12dccb0c954d6b40307bbd7f0.png)
> > 
> > 四驱的动力输出设计让 WHILL 可以适应各种复杂的地形，草地、雪地、砂石路面以及轻松上坡。
> > 
> > ![](../Images/2275e4b16ca2b489917edf8813d08014.png)
> > 
> > WHILL 还配有手机 App，你可以用 App 遥控 WHILL 或者设置控制敏感度、最大速度以及加速度等参数。
> > 
> > ![](../Images/b5d1faf9a8b893449939c49534e809d7.png)
> > 
> > WHILL 可以选择两种控制方式，一个类似鼠标的控制器或者人机工学摇杆，这样可以满足各种人群对操作的需求。
> > 
> > ![](../Images/1240190689837052ed0e56f9899d1f56.png)
> > 
> > WHILL 的座椅可以向前伸出，方便你坐在 WHILL 上也能很舒服的够到桌子，两侧的控制副手也能竖起，给手臂留出充足的活动空间。
> > 
> > ![](../Images/afff53aaddbb20e172b1a73098fe97c5.png)
> > 
> > WHILL 只有 60 厘米宽、83 厘米长，可以轻松放进汽车的后备箱，在室内使用也不会因庞大而觉得不便。
> > 
> > ![](../Images/87032e8101643528246934d3590444e4.png)
> > 
> > 刹车灯、水杯网、挂包的挂钩以及正面的照明小灯一应俱全，WHILL 的所有细节都是以生活场景中实际的需求出发。
> > 
> > ![](../Images/86c98d0a24861f1e63bac3473163b7a6.png)
> > 
> > ![](../Images/ceeed87ed74a9c01413d736c41267445.png)
> > 
> > ![](../Images/bd54a52c6261715f73cb3bd4897bfb29.png)
> > 
> > WHILL 大致的续航是 20 公里，两个 12v 50Ah 的电池，充电时间大于在 5 小时，重量（带电池）为 90 公斤。最大载重 100 公斤。
> > 
> > ## 点评
> > 
> > WHILL 充分诠释了科技如何更好得为人性服务这点，通过优雅的设计、贴心的设计让使用者有极佳的体验。并且为特殊的使用群体带来更多的尊严，这点是 WHILL 最令人赞赏的地方——所有的功能、设计都围绕「人」来展开。
> > 
> > ![](../Images/1d71a10eccca463e02686cb108795982.png)
> > 
> > 我们希望智能化、新技术不光是少数人尝鲜、炫耀的「玩具」，也能成为让生活更有质量，更有尊严的「伙伴」。
> >
