# 再也不怕忘带 iPhone 数据线的手机壳：CasePlug

> > \[核心提示\] iPhone 手机壳一直是一个拼创意与设计的地方，从背夹电池到开瓶器，从支架到工具箱，总有人把 iPhone 背后的一厘米发挥出新的可能。
> 
> > ## 前言
> > 
> > 和采用 micro USB 的 Android 设备相比，iOS 用户经常会焦头烂额的寻找数据线充电、同步，那些什么随身携带的数据线也常常被忘在家里派不上用场。
> > 
> > ## 概览
> > 
> > CasePlug 从根本解决了忘记随身携带充电线的问题，因为它把一个标准的 USB 接口做到了手机壳里。你可以只将戴着 CasePlug 的手机直接插在电脑、充电头上同步、充电。
> > 
> > 📹 [None](None)
> > 
> > ## 功能&特点
> > 
> > CasePlug 标准的 USB 接口带来最大的便利就是随时充电，任何一个可以供电的 USB 口都会成为你的移动电源，包括笔记本、充电头甚至飞机上的娱乐系统等等。
> > 
> > ![](../Images/1c878eeb5e034cfa613a8a8a2b57325e.png)
> > 
> > ![](../Images/4d7184e3f5368ba6d796f81c809332bf.png)
> > 
> > 此外，CasePlug 背面的 USB 接口在弹出后还可以 180°旋转，15 个档位可以让你的 iPhone 插在任何刁钻角度的 USB 口上，并通过旋转尽量不遮挡边上的插头、接口。
> > 
> > ![](../Images/aca440d48af93ee005ca17d22cd5e5c2.png)
> > 
> > CasePlug 背后的 USB 接口也可以成为手机支架，配合 180°旋转，你可以让 iPhone 以任何舒服的姿势立在那里。
> > 
> > ![](../Images/8532b5b3e562b3a39d7a44c6b9b2dbf5.png)
> > 
> > CasePlug 也可以插在车载系统的 USB 口上，让你的 iPhone 成为车载导航、电话。
> > 
> > ![](../Images/826ce0a044b50e6acb974cd020bb109c.png)
> > 
> > 附带的车载 USB 延长线可以让车载系统不带 USB 的人也把 iPhone 用 CasePlug 方便的固定在中控台上：一头接上点烟器转 USB，另一头粘在中控台，把你的 CasePlug 插进去即可。
> > 
> > ![](../Images/0384cfbea290bf54ed557c49fa7d0aeb.png)
> > 
> > CasePlug 还有一些很讨人喜欢的优点，比如厚度仅仅 4mm，重 39g；声音从 iPhone 底部扬声器通过正面的开口传导至正面留出的发声孔，并且还能放大声音。
> > 
> > ## 点评
> > 
> > iPhone 固执得采用自家专用接口也衍生出了不少配件、外设相关的生意。好无疑问 CasePlug 是把 USB 接口发挥得最好的之一。
> > 
> > 在功能、实用性方面 CasePlug 已经足够优秀了，唯一阻挡它的可能是有些丑陋的外观，尽管提供了一些可选颜色，但是依旧无法掩盖这是一款「男性用户味道」十足的产品。这可能是 CasePlug 唯一的缺憾了吧。
