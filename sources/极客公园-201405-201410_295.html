手游将有新金矿，但学神经猫必死

[核心提示] 一大波 HTML5 游戏充斥在朋友圈信息流，过于短视而急于用微信套现的行为，注定无缘这一波移动页游的未来。

在极客公园上一篇对爆款游戏的稿件中，我们预测类似「围住神经猫」这样的「基于微信朋友圈传播」HTML5 游戏将会大规模爆发。

而在这最近一周，我们看到有大量的游戏开发商和个人开发者，已经在开始打造数量众多的「游戏链接工场」，意图通过多款简单游戏的流量互推，复制「围住神经猫」的成功。

但，狂欢过后很可能是一地鸡毛。

警惕被滥用的微信朋友圈

我们可以回想到，当纪念碑谷这样一款拥有极度巧妙构思、精美设计的游戏出现时，无论是苹果 AppStore、各大媒体、用户绝不吝啬溢美之词，争相向身边朋友推荐，即便这是一款售价不菲的付费游戏。

HTML5 提供了更简单、更直接的游戏创作方式，但这并不意味着廉价与劣质。当无数的抄袭、复刻游戏泛滥在朋友圈中，结合微信对待「美丽说&蘑菇街」事件的态度，来自微信官方的封杀也就不远了。

知名科技评论人 keso 在接受极客公园的采访时表示：

我不认为这些游戏有什么意义，就像流感，来得快去得也快，就像什么都不曾发生。而且利用朋友圈的传播，也对朋友圈的信息流形成严重干扰。微信不可能放任第三方仅仅来此揩油。

世界上永远不缺小聪明，缺的是愿意埋头做事的聪明人。

从 PC 游戏的发展历史看，Flash 小游戏是早期页游的典型生态，但到后期制作精美的即时策略、模拟经营、MMORPG、休闲竞技等类型的游戏才是市场的主流。

仅仅想要依靠赚快钱的心态，简单把已有游戏做 HTML5 化，滥用微信朋友圈进行信息轰炸，注定对于这一波由微信引发的 HTML5 新浪潮是过客。真正能够赢得市场，只会是那些潜下心去研究这些新技术带来的颠覆性，做出好产品的游戏开发商。

HTML5，越来越低的开发门槛

赵新是一个独立游戏开发者，他的正职是一家手游公司。看到微信页游的机会，他用了两天时间就开发了一款名为「你能比我砍得快么！」的 HTML5 网页游戏。

各种开放的 HTML5 游戏引擎是他能够快速完成开发的重要原因，这款游戏基于一款名为 egret 的开源 HTML5 游戏引擎。开发者可以从 Github 网站获取它的源代码，从而了解和学习它的核心细节。

游戏引擎让游戏很容易地在各种浏览器中运行，并在不同平台浏览器里提供近乎一致的用户体验。iOS、Android、Windows Phone … 你只需要开发一个版本就可以在几乎所有系统上运行。

更重要的是，HTML5 作为一项基于 WEB 的开放标准，意味着数量众多的非游戏行业的工程师与设计师，可以投身到游戏行业。你可以像写网页一样写游戏，而无需太多的额外学习，而且大量的文档与插件可供使用，这本身就是一种巨大的改变。

HTML 技术给游戏行业带来的：更低的门槛与成本、更丰富的人才储备、更具弹性的跨平台优势。

微信页游是下一座金山

HTML5 游戏相比传统端游有巨大的优势，游戏即点即开、按需下载、开发成本与周期更低，营销推广可以获得翻倍的转化率。而以微信为代表的移动社交应用的兴起，将会解决 HTML5 游戏的分发难题。

目前微信游戏中心中的 22 款游戏，如知名的天天系列与全民系列，几乎每一款新出的游戏都能登上应用商店的前五位置，充分证明了微信在社交游戏领域的能量。

而 HTML5 游戏无需安装，可以让用户在不离开微信的情况下进行游戏，在游戏结束后可以便捷地查看和分享游戏数据。优秀 CP（内容提供商）的加入，也会帮助微信打造围绕自身的「微信游戏圈」，提升对用户的粘性。

目前「QQ 空间手机版」已经率先引入了第三方游戏，可以被看作是社交与 HTML 结合的范例。内置了霸气水浒、西游争霸、侠行天下、群雄 OL、QQ 水浒等多款 HTML5 网页游戏，其中不乏用户量百万以上的产品。

可以预期的是，微信未来将会在游戏领域为优秀的 CP 提供工具与能力的支持。能否在这一过程中胜出，取决于开发商在 HTML5 游戏领域的资金投入及人才技术储备，是否做出了真正优秀的游戏产品。

拥有微信这样的国民级应用，HTML5 技术准备就绪，如果你不想要错过这一波大潮，赶紧去做一些好游戏作品吧！
