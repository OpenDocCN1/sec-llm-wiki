# 你为什么卸载澎湃新闻客户端?

> > \[核心提示\] 好的字体应该能够「修复那些已然割裂的图文关系；修复读者对内容的敏感度；修复那些被损伤的视力，以及想像力。所有的视觉修养都是从字体开始的。」
> 
> > 7 月 22 日早上醒来，半睡半醒中阿冬发现朋友圈中满满都是《我心澎湃如昨》。阿冬身在媒体圈，朋友们或「流泪」或「矫情」的转发评论促使她点开链接。不长不短的发刊词看完，阿冬感觉心中某个角落颤抖了一下，却说不出感觉。点击分享之后，阿冬并没有添加任何评论性注释。
> > 
> > 今天我问阿冬，澎湃新闻端还在用吗？感觉怎么样？
> > 
> > 阿冬顿了顿，说，卸掉了。字体太奇怪，看多了眼睛疼。
> > 
> > ## 澎湃新闻端用的是什么字体？
> > 
> > 弄清这个问题，首先我们要了解一个概念：
> > 
> > 什么是衬线体？
> > 
> > 在罗马时代，人们非常喜欢在字母顶点使用短而小的横线做为装饰，这种被称为「serif」的装饰物就是「衬线」。现在，人们用「serif」表示衬线字体，即在字的笔画开始、结束的地方添加额外的装饰，且这种字体的笔画粗细会有不同。「Sans serif」则表示没有这些额外的装饰，且笔画的粗细差不多的无衬线体。
> > 
> > ![](../Images/11fe8f8584c5ad2f057ddbb0fbe57988.png)
> > 
> > 传统的正文印刷认为，衬线体能带来更佳的可读性。特别是在大段的文章中，衬线可以增加阅读时对文字的视觉参照增加识读性。而无衬线体往往被用在标题、较短的文字段落或者一些通俗读物中，给人一种休闲轻松的感觉。
> > 
> > 如今的人们越来越喜欢用无衬线体，因为看上去「更干净」、「简洁」。
> > 
> > 在中文字体中，宋体就是最标准的衬线字体之一。但由于强调横竖笔画的对比，在远处观看时较细的横线会弱化，导致识别性的下降。论文中常常用来做题目的黑体，则是一种标准的 sans serif 字体。
> > 
> > ![](../Images/dd31875702a3b7040da02da7d4557b0f.png)
> > 
> > 澎湃新闻客户端显示情况
> > 
> > 这时回过头看澎湃新闻客户端，它采用的正是类似「方正精宋」的衬线体。自宋代雕版印刷术诞生与纸张流行，宋体一直被认为是最适合印刷正文的字体。诚然衬线体用在报纸、杂志等纸质媒介上会有较好的阅读感受，但受分辨率、屏幕大小等诸多不可控因素影响，用于手机端阅读时会产生各种各样的问题。
> > 
> > 尽管澎湃客户端在字体的选择上已经做出了努力，采用了一款笔画较粗的衬线宋体克服屏幕障碍，但习惯了无衬线字体阅读的手机端用户显然并不买账。
> > 
> > ## 屏幕上应该用什么字体？
> > 
> > 汉代许慎在《说文解字》中记录隶书诞生：「秦烧经书，涤荡旧典，大发吏卒，兴役戍，官狱职务繁，初为隶书，以趋约简。」书写工作的大量增加、竹简的广泛使用促进隶书的诞生，将篆书圆转的笔画换作方折，提升了书写速度的同时还提高了竹简上的辨识效率。
> > 
> > 雕版印刷术和纸张的流行促成了宋体的诞生，棱角分明、笔画尖锐的宋体既保留了传统书法的典雅与形态美，也保证了印刷文本的清晰。
> > 
> > 电脑、平板、手机……各种各样的屏幕几乎霸占人们全部的阅读时间，从竹简到纸张再到屏幕阅读的媒介已经发生了变化，具有极细的笔画或带装饰角的文字很容易受屏幕光渗的影响而不易识别，适用于传统媒介的字体已不再具有优势。  
> > 适应屏幕的字体特点包括：
> > 
> > **1.中宫较大**：利用人眼的知觉偏差，中间部分增大利于字体识别，显得更加清晰。
> > 
> > ![](../Images/65e52ee0ea5604cfb5a5e3a99763e34e.png)
> > 
> > 调整中宫后的效果
> > 
> > **2.正负形空间平衡**：笔画的粗细直接影响字符白空间的分布，屏幕自发光的特点使得文字容易产生笔画模糊。对字型架构进行调整并增加笔画之间的间距的字体，可以提高屏幕上文字的可识别性。
> > 
> > ![](../Images/953389a3c2c4227fd10878fa4c110133.png)
> > 
> > 调整字形结构后的效果
> > 
> > **3.字体笔画粗细适当调整**：笔画过细，很容易被光“吃掉”使文字变得支离破碎。适当调节过笔画粗细的字体，可以防止屏幕越亮越敏明显的光线侵蚀问题。
> > 
> > **4.字面大小合理**：运用“第二中心线”原理等调整字面，微软雅黑就是利用此原理增大字面的设计字体之一。
> > 
> > ![](../Images/24bd5b790883158b6d472fa5edf8cc04.png)
> > 
> > 调整字面后的效果
> > 
> > **5.笔画极简化**：使用无装饰风格，减少繁复的细节装饰处理效果，使文字更加规律化、理性化、数据化。
> > 
> > ![](../Images/c6c5f415a1770feccb7285fe127ccbe4.png)
> > 
> > 笔画简化后的效果
> > 
> > **6.笔画交叉处减淡处理**：视觉错觉使笔画交叉处显得格外黑，减淡连接处的黑色程度更适合屏幕显示。
> > 
> > ![](../Images/9c253176beba332671bdd79e5e8833c1.png)
> > 
> > 调整交叉处后的效果
> > 
> > **7.字体灰度处理得当**：不论衬线体还是非衬线体，大段文本都会产生大片灰度空间。因此调整过字与字间的距离，黑白正负空间得到均匀分布的字体，可以获得视觉上的协调。
> > 
> > ![](../Images/21538847a2e11cdffac729f9175be8ab.png)
> > 
> > 西文字体通过字母距离对灰度进行处理
> > 
> > 综合以上条件，Windows 系统推出的「微软雅黑」字体与 Mac OS 的雪豹新简体「Hiragino SanS GB」被认为是目前比较适合屏幕的字体。微软雅黑打破传统文字结构的设计方式，放大中宫结构使文字更加饱满。同时特别压扁了文字使上下距离增大，阅读起来更为清晰。
> > 
> > 而雪豹新简体细致的细节更注重字体的品质，更适合阅读类应用及对字体苛求的设计类阅读。
> > 
> > 谷歌日前推出的「思源字体」，同样是一款针对汉字、清晰直观的无衬线字体。
> > 
> > ![](../Images/72b48d3aa49508d954856c08631b48c6.png)
> > 
> > ## 实例、以及一点小建议
> > 
> > > 好的字体不一定是具有风格和个性的字体。合适的字体，加上恰如其分的文字编排，正如美国字体设计师Donald Tarallo所言，应该能够「修复那些已然割裂的图文关系；修复读者对内容的敏感度；修复那些被损伤的视力，以及想像力。所有的视觉修养都是从字体开始的。」
> > 
> > ![](../Images/5acd5d61a6c94317b0a32512092664b1.png)
> > 
> > 阅读类客户端多选用黑体
> > 
> > 不论是《人民日报》、《三联生活周刊》还是《外滩画报》，阅读类应用大多选择黑体，「更保险」、更适合快速阅读。
> > 
> > 至于澎湃新闻端为何逆势而行选择一款宋体，大概是作为「专注时政新闻的媒体」，保持与纸媒一致严肃性。
> > 
> > 况且字体除了不妨碍阅读，审美也是不容忽视的属性。当屏幕ppi飙高了，物质基础稳定了，阅读的同时欣赏笔画间的对比、笔锋转折亦不为过。发刊词展现出的情怀，不难解释这一缘由了。
> > 
> > 习惯了无衬线体阅读的用户，忽然被这一字体侵扰，难免不会吃不消。
> > 
> > 或者澎湃新闻端可以参考 kindle 自带三款字体的系统设计，不止设置「大」、「中」、「小」三款字号，增加一款无衬线字体选项供用户选择，也不失为折衷方案。
> > 
> > 因为功利化阅读这种事和审美扯上关系，一切就都变得复杂了啊。
