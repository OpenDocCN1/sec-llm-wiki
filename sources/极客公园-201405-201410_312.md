# 社交网络上的自己，你真的了解吗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200744816&idx=2&sn=cf9c08cc6091e46ca8bdc09dfef00cb7&chksm=eb8262c6dcf5ebd01baafcaa35620e7931d513efa3646c9286307a6911479fa1f17e9b3ea144&scene=126&sessionid=1681313118#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200744816&idx=2&sn=cf9c08cc6091e46ca8bdc09dfef00cb7&chksm=eb8262c6dcf5ebd01baafcaa35620e7931d513efa3646c9286307a6911479fa1f17e9b3ea144&scene=126&sessionid=1681313118#rd)

> > \[核心提示\] 我们每天用大量的时间混迹社交软件，那些我们无意识的行为和想法，也被记录在网络上。问题是，你真的了解网络中的你自己吗？
> 
> > 关于 Facebook 诱导性实验的争论还远未结束，最近，美国在线约会网站 Okcupid 也承认使用用户数据做实验，在 Okcupid 看来，它们没有必要对用户 say sorry, 因为只要使用互联网，每个人都可以成为被实验的对象。暂且抛却对这种说法合理性的质疑，让我们来看看，这些年，社交网站到底做了哪些实验，有什么有趣的结果。
> > 
> > ## 社交还得看脸
> > 
> > **别在用什么「内涵」、「气质」这些词来忽悠自已了，你真的只愿意和长得好看的人约会。**
> > 
> > 在 OkCupid 对用户进行的三次实验中。为了研究外貌在交友中的重要性，网站在 2013 年的盲目情感日（Love is Blind Day）。这一天「擅自」移除了所有用户资料中的照片，不出所料，网站流量瞬间严重下滑。
> > 
> > ![](../Images/5ef39ce481e6e749415cc2e9e29de662.png)
> > 
> > 而在另一个实验中，OkCupid 让用户分别给其他用户的长相和品德打分。研究发现，用户对照片的关注度要远高于文字。那些长相有魅力的人，即使个人资料几乎是空白，也可以在品德评估中获得高分。除了相貌之外，选择约会对象还会受到其他因素的影响么。答案是肯定的。
> > 
> > 在第三项颇受争议性的实验中，OKCupid 擅自修改了网站内容，有意将匹配度仅为 30%（理想匹配度为 100%）的用户撮合在一起，并且告知用户他们的匹配度为 90%。反过来，OKCupid 还故意调低彼此合适的用户的匹配度。结果发现，数据上不相配的两个人，在「合适」这样的数据匹配暗示下，仍然会交换信息并且约会。可见，**在约会中，来自外界的心理暗示会大大影响与约会对象的互动。**
> > 
> > **对相貌上不占优势的人来说，营造一个合适的心理暗示也可能成为俘获对方的重要砝码。**
> > 
> > ## 朋友圈里晒幸福，多多益善
> > 
> > 我们很容易认为，如果朋友圈的好友总是炫富秀恩爱，天性妒忌的人多多少少会感到不爽。而在 Facebook 的情绪实验中，用户所发布的情绪色彩与其社交圈中的情绪色彩更趋向于相同。也就是说，如果有一天早上，你刷朋友圈，发现每个人都在抱怨：「北京的天气实在太糟糕」，你也很可能会发一条「糟糕」的状态。
> > 
> > Facebook 的试验在近 70 万名 Facebook 用户的信息流中加入了要么更积极要么更消极的内容。研究发现，信息流中被加入更积极内容的用户发布了更积极的内容，而被加入更消极内容的用户发布了更消极的内容。来自积极和消极群组的大约 15.5 万名用户，每人「在实验期间至少发布了一条状态更新」。
> > 
> > ![](../Images/950b48a5dcb27dbb38810ce5c9c5c02a.png)
> > 
> > 研究还发现，那些很少被情绪性信息流包围的用户不大可能去表达自己的情感。这就可以解释，网络上的情绪表达会影响到在线的社交参与程度。
> > 
> > **在线消息影响我们的情绪体验，而在线的情绪体验又会影响到我们线下的实际行为。这么说来，如果想拥有一个平静的心情，不妨适时关掉你的社交网络。**
> > 
> > ## 不同圈子的好友一起忽悠最有杀伤力
> > 
> > 你是一个意见很强的人，拒绝任何不靠谱的推销，当你的七大姑八大姨都说一个东西好时，你把表示不屑，如果你的同事、同学、朋友等不同圈子的人天天都在说时，你还把持得住吗？
> > 
> > 美国康奈尔大学的社会学家乔恩·克莱恩伯格（Jon Kleinberg）在 Facebook 上进行了一项实验，从 Facebook 的数据库中调出了 5400 万封电子邮件加以研究。
> > 
> > 具体来说，Facebook 网站有个功能，即搜索每一位用户的电子邮箱，然后群发一条邀请信，邀请这位用户的朋友也加入 Facebook。这封邀请函同时还会把受邀对象的朋友当中已经加入 Facebook 的人的名字一并附上，以造成一种「大家都在玩脸书 Facebook」的印象。实验设计了一个软件，统计了受邀对象在何种情况下才会真心接受这条新信息，也就是决定加入 Facebook。
> > 
> > 分析结果显示，信息传播的效率和接触信息的次数关系不大，一个受邀者接受一个好友邀请后决定加入 Facebook 的概率，和他接受了四个好友邀请后决定加入的概率没有差别。但是，**邀请者所隶属的社交圈子的数量则对最终结果有着直接的影响，数量越大效果就越好。**
> > 
> > 也即是，如果四个邀请者分别来自不同的背景（比如同事、朋友和家人），比他们全都来自同一个背景的效果要好很多。
> > 
> > ## 上班族：周五下午最开心
> > 
> > 相对于以上三个实验来说，在 Twitter 上进行的这个实验可能有些无趣，它使用 Timeu.se 这个网页工具来研究人们所发的推文，借此了解人们是如何利用他们的时间。在实验者 Scott Golder 看来，这项实验正是将我们平常会忽略的信息永久地记录下来。
> > 
> > ![](../Images/db6899d51f2c8bd995dd294153ab2267.png)
> > 
> > 在对 240 万用户的 5 亿条推文进行分析后，研究者发现一些有意思的细节，比如，人们在推文上输入「啤酒」后，大约七个小时会输入「喝醉」；每周最愉快的工作时间是周五下午的 3 点到 6 点；每周五晚上的网络情况最糟糕；早餐中，熏肉比香肠更受欢迎。
> > 
> > 这些看似不重要的数据对广告营销者而言有着不同寻常的意义，如果有快餐人员在周五下午三点给你送上冰淇淋，你应该不会拒绝吧。
