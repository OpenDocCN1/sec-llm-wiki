# 也说Facebook的「保存」功能：信息洪流中的内容沉淀

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200737461&idx=3&sn=34f3173df1555f520c6052e4498ca130&chksm=eb827f03dcf5f615482fc1e163bcdd8b83b70b04659537a305a894ced2cc0dac111b9ae8e38a&scene=126&sessionid=1681313118#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200737461&idx=3&sn=34f3173df1555f520c6052e4498ca130&chksm=eb827f03dcf5f615482fc1e163bcdd8b83b70b04659537a305a894ced2cc0dac111b9ae8e38a&scene=126&sessionid=1681313118#rd)

> > \[核心提示\] 社交产品如何为用户更好的推荐优质内容？Facebook 的保存功能也许是个很好的尝试。
> 
> > 在社交 App 里刷信息流已经成为很多人一有空闲就会进行的动作，看着一条条新闻或朋友们的动态从眼前划过颇有其乐无穷的感觉。然而当你身处一些「临界点」环境，例如出地铁、过马路时，突然看见一片有意思的文章，但当时又没法细看怎么办？
> > 
> > Facebook 对此给出了自己的一种解决方案，它在本周初正式推出了其此前已经内测了一段时间的「保存」功能，用户可以将自己在时间线里看到的感兴趣的内容添加到「已保存」中。有趣的是，这些被保存的信息还可以选择分享给好友。
> >

> > 
> > ![](../Images/d914baf7c66c047476607f7338d95409.png)
> > 
> > 如何让用户能够及时捕捉到那些对他们有价值的信息，是所有社交类产品都面临的共同问题。随着 Facebook、Twitter、新浪微博里面的好友和关注对象越来越多，各种并无多大意义的信息势必会涌入信息流当中。如果那些其实正是用户感兴趣的 优质内容因为受到时间和环境的制约，无法当场进行观看和阅读，等到事后又难以再找到，这对产品本身来说也是一种损失。
> > 
> > 除了传统的新闻媒体以及各类新闻阅读 App，社交网络已俨然成为用户获取资讯的重要途径。国外曾经有人表示自己只靠 Twitter 就能够以最快速度了解到所有想要知道的新闻，微博对国内的很多人来说承担着同样的职责。所谓「碎片化时间」成为诸多产品激烈争夺用户的战场，但是我们真的 只能接受「碎片化阅读」，任凭信息不分优劣都随之流逝吗？
> > 
> > 答案是否定的。
> > 
> > 从互联网诞生到今天，虽然人类的语言并没有发生质的变化，但人们互通交流的方式却在互联网上发生了翻天覆地的变化。曾经的博客和 BBS 时代让热爱创作和阅读优质内容的人分别找到了各自的归属，然而 SNS 和微博客的出现让人们越来越短地阐述自己的观点，值得阅读的深度内容也只能藏身于一条条短链接后面静候发掘。
> > 
> > 当多数人选择这样的表达方式以后，作为观众的用户也只能在其影响之下变得越来越浮躁。互联网技术和产品的进步使得内容创作与分享呈现出信息大爆炸的态势，但零碎的内容和以时间线为主的组织形式却并不能给人们带来有价值的信息沉淀。
> > 
> > 于是帮助用户发现好内容成了社交产品必然履行的职责。Facebook 此前推出新闻阅读应用 Paper，能够抓取用户在 Facebook 分享的文章等内容，并将其划分到单独的新闻、商业、体育等不同栏目。此举正是通过独立产品的形式，让用户能够阅读来自 Facebook 的优质内容。Twitter 和新浪微博也都能够让用户收藏自己感兴趣的信息，其目的就是让用户得以在信息洪流中留住那些有价值的部分。
> > 
> > 当我们在浏览时间线时，我们其实依然是在消费内容，只不过获取形式与传统的新闻阅读有所不同。从产品层面来说，Facebook 推出「保存」功能其实还是在延续社交产品们一直努力的方向——为用户呈现最有价值的内容。
> >
