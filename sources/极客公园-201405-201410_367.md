# 短视频或许应该这么玩

> > \[核心提示\] 那么每一个阶段，短视频应该有不同创新的玩法：可以到处涂鸦的短视频？可以接龙的短视频？甚至是从第三方硬件导入的各种短视频？Why not？ So cool 不是吗？ 　
> 
> > ## 8PM和印美图的启发
> > 
> > 最近有两个产品打动了我，一个是以 8 秒短视频交友的应用“8PM”，一个是硬件创业项目“印美图”。“8PM”让我看到的第一款以短视频为基础社交媒介，采用了类似于国外的 Tinder 你情我愿，选择“爱心”或者“X”，只要双方互相都选择的是“爱心”，即可进一步的社交互动。当然我不得不承认，它打动我还有另外一个原因，就是它认同了 8 秒这个短视频的时长标准。“印美图”作为首个基于微信控制的 LOMO 打印机，我和它的创始人黄昱钊提出了关于在其硬件上实现短视频 card 的想法，很快我们就见面沟通具体的实现方式。

> > 
> > 传统的短视频应用玩法，诸如微视、美拍、秒拍等等，毫无例外的都是通过工具录制一段短视频，然后像烹饪一样，添加各种佐料和辅助食材，最后上桌分享出来。在我看来， 短视频应用绝对不仅仅如此的平庸和局限，它一定有更加好玩的地方亟待我们去发掘。 　
> > 
> > ## 短视频可以尝试的各种玩法　
> > 
> > 视频就像文字、图片和声音一样，是一种媒介，媒介的价值在于承担输入和输出信息的桥梁。短视频逃离不出媒介这个根本属性，只不过从媒介的存储信息的时长而言，它有长有短。因此从媒介的角度而言，短视频应用是工具，但仅此而已吗？录制制作完了一条短视频，人们需要与人分享，需要在分享过后获得其他人们的反馈。既然如此，**那么短视频分享应用更是一个用户通过分享生活的美好瞬间而期望获得某种正向反馈的社区，这也是我之前一直在思考如何从工具到社区的进化，终极进化就是成为一个短视频分享平台了**。那么每一个阶段，应该有每一个阶段不同创新的玩法。
> > 
> > ### **可以到处涂鸦的短视频：**
> > 
> > 这个想法来自于 facebook 最新的应用 slingshot，用户点击 shoot 拍照，之后可以选择 Draw 按钮，此时此刻就会出来一个轻松愉悦的音调，用手指在屏幕上滑动就可以进行涂鸦创作了，选择 use 就可以直接发布给好友了。整个下来我会觉得很有意思，长按 shoot 按钮进入短视频拍摄模式，只不过目前貌似短视频不支持涂鸦。
> > 
> > 我在想 why not？如果加上涂鸦的功能，我们是不是可以在创作的界面加上简单的涂鸦词语或者图形，而不是绞尽脑汁我下面的文案应该怎么写；如果加上涂鸦的功能，我们是不是可以点击“reshoot”恶搞一下好友的视频，而不是我拍完了，孤零零的躺在那；如果加上涂鸦的功能，我们是不是举办一个涂鸦大赛，甚至搬到城市、社区的大街小巷呢？Why not。
> > 
> > ### **可以接龙的短视频**：
> > 
> > 这个想法来自于传统的接龙小游戏， 我们其实可以看到很多应用的爆红都是来自于某种好玩有趣的小游戏。这种玩法在桌面互联网时代，微博、人人等社交网络风靡一时是非常兴盛，比如速配小游戏、姻缘小测试等等。那么把这种游戏场景和思维嫁接在短视频应用上会发生什么反应呢？
> > 
> > 我在想 why not？如果加入接龙功能，我们拍摄一段短视频（当然要留有一定的时间让别人可以衔接上去），然后通过微信分享或者产品内@好友，邀请好友一起来玩，是不是更加互动有趣；如果加入接龙功能，我们拍摄一段短视频，像微信漂流瓶一样扔进大海，任其漂泊，惊喜可能随时都会来敲门；如果加入接龙功能，我们同样的是不是可以举办一场缘分对对碰的游戏呢，如果相互协作的是一对异性的话，那么就会天降桃花，尽管这可能会受到帮助情人出轨的道德质疑。
> > 
> > ### **无处不在的短视频：**
> > 
> > 谁规定了用户使用短视频应用的传统路径一定是打开 App icon，点击 App 内的拍摄按钮，然后制作、分享视频。前面提到短视频应用不仅仅是工具，它需要向社区进化，需要向平台进化。社区和平台需要优质的内容和有效互动的关系链沉淀，这是一个后向的结果，因此在前端，我们没有必要在乎用户是通过短视频 App 本身生产内容还是通过第三方的 App 在生产内容，甚至是通过手机厂商的原始相机、相册还是像 Google Glass，iWatch 这样的穿戴式设备。作为平台，只要保证第一，我有优质的内容，第二，用户在我这里互动和社交。
> > 
> > **因此短视频应用在适当的时候应该果断把自己的基础能力开放给合作伙伴，甚至可以和硬件合作伙伴一起来研发如何来提升拍摄和制作高水准视频的水平**（后端的高技术处理，前端的脑残门槛），我们和合作伙伴共享基础能力，但是社区、平台必须牢牢掌握在手。 　　
> > 
> > 短视频在入口的布局需要更加多元化，当然作为终极进化的平台梦想，短视频应用所能够做的远不如此。在和印美图的黄昱钊聊天时，我就特别的希望现在有一家硬件公司，将哈利波特小说电影中的视频报纸变为现实。那里面的视频其实就是不足 8 秒的短视频嘛，为什么不能人们在短视频应用中记录、制作和分享的短视频放在我家的墙壁上呢？Why not？ So cool 不是吗？
