# 智能汽车的「五个」发展方向

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=200537498&idx=1&sn=82f70395a01aeed256bd65585d5bd3c6&chksm=eb86882cdcf1013a30a143608c4d80c705dff4251a136a36337ef7195ab771682b28664f82db&scene=126&sessionid=1681313254#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=200537498&idx=1&sn=82f70395a01aeed256bd65585d5bd3c6&chksm=eb86882cdcf1013a30a143608c4d80c705dff4251a136a36337ef7195ab771682b28664f82db&scene=126&sessionid=1681313254#rd)

> > \[核心提示\] 智能汽车将走向可感知、可连接、人格化、去特征化、共产化，将给车主和乘客带来全新的用户体验。
> 
> > ## 一、可感知
> > 
> > 可感知就是把真实的世界转换成数字的世界，通过输出结构化的数据，可以被人和智能设备所能理解。
> > 
> > 有三个方向：人感知到汽车、汽车感知人以及汽车感知到周围环境。目前市面上密集发布的 OBD 产品的方向就是人感知到汽车，让车主能够实时跟踪车辆的保养状态。
> > 
> > 未来的汽车就像一个裸体的女人，全身都有神经细胞，布满了传感器，汽车的任何细微的感觉车主都能感觉的到。
> > 
> > 想象一下这样一个场景：当酷热的夏日，车内温度过高时，汽车会自动开启空调降温，这不就是智能汽车吗？汽车的传感器并不是只局限在 OBD 上面，也可以是摄像机、手机或者富含传感器的智能穿戴设备。
> > 
> > 当车主进入汽车的时候，手机跟汽车是一体的，像车速、行驶方向、行驶轨迹、车内温度等数据这些数据没有必要通过汽车来获取。
> > 
> > 另外一个方向是汽车对人的感知。譬如，iPhone 的 Touch ID 就做到了手机对人的感知，不是机主不能解锁。
> > 
> > 未来的汽车也一定是这样的，不是车主你开不走汽车，谁也盗不了。顺着这个方向能做的应用还有很多，譬如汽车能感知到车内有没有小孩子，能感知到驾驶员有没有喝酒、是男是女等等。汽车是人的高级私人管家，只有认识人才能更好地服务车主。近日福特和英特尔公布的「Mobii」项目就是沿着这个方向研发的一个例证，通过面部识别和手势操作来实现汽车对人的感知。
> > 
> > 最后是汽车对周围环境的感知。这一点是自动驾驶的基础。周围环境包括汽车前面的静态的或者动态的障碍物、车后有追尾风险的汽车、倒车时车后的障碍物、下车时周围穿行的车辆等等。物理世界是非常复杂的，有很大的随机性和不可预测性，通过图像识别技术来提取出障碍物从而实现自动驾驶将会是一个非常漫长的过程。
> > 
> > ## 二、可连接
> > 
> > 通过跟手机的连接，车主可以在车内通过语音助手或者车机安全地体验到手机的功能，包括：接打电话、收发短信、地图导航、收听音乐和网络电台等。
> > 
> > ![](../Images/2c9eb7e2e3093b1cd55fa3875419d684.png)
> > 
> > 连接的主要目的就是避免资源重置、减少冗余。有了苹果的 CarPlay 方案，用户从在公司搜索目的地到在车内的导航再到下车后的步行导航是连续的，不是分开的，本来就是一个应用，没有同步的问题，这让车主感受到的是前所未有的便利。
> > 
> > 对于车厂来说，连接也可以让它们甩掉影音娱乐应用的包袱，把精力集中到针对智能汽车的研发上来。等等，我为什么说手机？因为手机是连接智能家居、智能汽车、可穿戴设备的中枢，只要连接上了手机，就进入了互联网。
> > 
> > ## 三、人格化
> > 
> > CarPlay 把 Siri 引入到汽车就是汽车人格化的一个开始。未来的汽车就是一个机器人，说到这里，你是不是眼前浮现出电影《汽车总动员》里面的场景呢？
> > 
> > 有了 Siri，汽车就有了一个新的大脑，取代了之前车机的地位。它不光能听从你的命令，还能根据你说话的情绪播放相应风格的音乐，还能根据当前时间、当前位置揣测出用户的需求给用户做出他想要的生活服务推荐。就近儿广告平台在这一领域展开了深入的探索。
> > 
> > 譬如开车的时候，到了饭点，Siri 可以通过就近儿服务根据车主的喜好结合当时的心情在即将到达一家合乎自己的口味的餐馆的时候告知车主：「前方有一家 xxx 餐馆比较适合你，你是否在这里就餐？「这就免去了车主繁杂的搜索周边餐馆的过程。Google Auto 也有类似的功能，在车主驶离公司的时候，Google Now 会主动地告知用户周边有哪些新开的餐馆或者推荐一些适合车主口味的餐馆。
> > 
> > ## 四、去特征化
> > 
> > CarPlay 刚推出的时候，很多车厂其实内心是有抵触的，原因就是 CarPlay 让汽车在车机上的差异没有了。一部汽车只要支持 CarPlay，不管车载 OS 是什么操作系统，都支持统一的应用，有统一的用户体验。但是产品的去特征化是社会发展的必然，车厂也拗不过大势的。
> > 
> > 产品为了满足规模化生产的需求逐步地放弃自有的繁杂的特征的进程几千年来一直在进行。OBD 产品也是一样的道理，使用同样的 OBD 产品，在不同的汽车上体验是一样的，没有差异。
> > 
> > 相信在不久的将来，会有更多的智能车载硬件诞生，推动汽车去特征化的进程。汽车本身也在去特征化，特斯拉开放专利就是一个明显的信号。
> > 
> > 如果小米公司利用这些专利技术开发了一款小米电动汽车，价格跟小米手机一样低的让你连连叫好，同时也保持了小米的不是那么差的品质和对用户的亲和力，势必将会对现在的汽车品牌造成巨大的冲击。
> > 
> > ## 五、共产化
> > 
> > 一个家庭至少一部车不光造成了道路的拥堵、环境的污染，也造成了资源的浪费。互联网通过连接解决了资源的共享问题，即共产化。
> > 
> > 大部分家庭用户乘坐汽车就是为了解决譬如接送孩子上学、户外郊游等运输目的。当你问周边人为什么买车的时候，他们一般给你这样的答复：」下雨天打车不方便。「
> > 
> > 这说明运输是大部分车主购车的主要理由。基本的交通运输需求去除奢华的设计，可以迅速降低汽车的生产成本。就像北京满大街都有公共租赁自行车一样，有了基于互联网的汽车资源统一调配，结合来自「端」的自动忙闲状态反馈，未来大部分人也不需要购置汽车，下雨的时候通过 app 点一下按钮就能叫来一部周围闲置的车。
