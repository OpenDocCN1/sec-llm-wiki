谷歌收购音乐服务 Songza

来自：网易科技

谷歌宣布收购流媒体音乐服务 Songza，但收购金额不详。未来几个月，Songza 公司的智能播放列表将与谷歌 Play 音乐或 YouTube 进行整合。不过，目前 Songza 将暂时继续以独立的应用程序形式出现。

这次收购凸显了流媒体音乐市场竞争日益激烈，苹果、亚马逊和谷歌都希望通过提供流媒体音乐服务来差异化旗下移动产品。

苹果的 Beats 音乐曾在今年一月推出基于用户心情、位置和活动的播放列表定制功能。但 Songza 实际早在 2010 年就提供了这种播放列表创建方式。该公司于 2011 年推出了 Songza 移动应用，目前为止服务于 550 万活跃用户。

点评：音乐是个性化最典型的代表，谁先提供了个性化的音乐，谁就能在音乐产业上最先获得海量的忠诚用户。

买不起 Model S？ 特斯拉下一代电动车将降价

来自：网易科技

特斯拉汽车工程部副总裁克里斯·波利特（Chris Poritt）周二表示，公司正在研发一款价格更加亲民，且与 Model S 和 Model X（将要推出的 SUV 款式）在设计风格上均存在明显差异的第三代电动汽车。

该款车型此前被命名为 Model E，但特斯拉于数个月前放弃了这一商标。根据波利特的描述，Model E 将定位与宝马 3 系争夺市场，换而言之，该款车型在设计上会较 Model S 更短更窄。

此外，Model S 上所采用的铝制车身也不会应用到新型号上，取而代之的很可能是价格更低的钢制车身。特斯拉还会重新设计电池组，以确保锂离子电池“刚好足够用”。随着特斯拉超级电池工厂的产能逐步释放，该公司旗下电动汽车的成本亦会大幅降低。

点评：Tesla 通过中档的 Model S 做出了口碑，那么接下来 X 与 E 将分别从高端与入门两个方向进一步培养用户对电动车的认知。

人事变动频繁 Twitter 任命前高盛高管担任 CFO

来自：搜狐IT

Twitter 在今日提交的 SEC 文件中披露，迈克•古普塔（Mike Gupta）已不再担任其 CFO 一职，前高盛集团高管安东尼•诺托(Anthony Noto)将代替古普塔担任该公司新任 CFO，后者现在的职位为 Twitter 战略投资部高级副总裁。

在过去几个月，Twitter 管理层频繁出现变动。近几个月里，Twitter COO 阿里•罗哈尼（Ali Rowghani）和负责北美媒体业务的克洛伊•斯莱登(Chloe Sladden)已先后离职。

古普塔在 Twitter 为期 4 个月上市过程中扮演了重要角色。尽管古普塔并未离开 Twitter 公司，但据悉，由于华尔街对古普塔在处理投资者关系方面所作出的努力并不认可，因此他本人承受着巨大压力。

点评：Twitter 自诞生之日起就面临着管理层混乱，但是这乱糟糟的人事变动却没有影响 Twitter 成为这个世界跳动的脉搏。

苹果组建语音识别团队 或抛弃 Siri 技术提供商

来自：腾讯科技

苹果拥有语音助理服务 Siri，Siri 的技术是来自语音识别技术公司 Nuance。但一些人工智能研究者认为，苹果即将改变策略。苹果已经组建了自己的语音识别团队，团队正在开发基于神经网络的 Siri 服务。

去年，苹果招募了微软语音识别项目高管亚历克斯·阿赛罗（Alex Acero）。阿赛罗在微软工作了接近 20 年，如今他是苹果 Siri 小组的一名高级总监，直接领导 Li Deng 和 Dong Yu，二人正是当年邀请辛顿出席惠斯勒会议的微软研究者。

但微软研究部门主管彼得·李认为，要想追赶上微软和谷歌，并且采用神经网络，苹果还需要六个月的时间。神经网络将大幅改进 Siri 服务。他表示：“除了 Siri，所有主流语言服务都已采用神经网络算法。Siri 的转型只是时间问题。”

点评：当 Siri 成为苹果在汽车、家庭重要的人机交互通道后，自然会将 Siri 核心的技术握在自己手中。

Windows 9预览版今秋发布 正式版明年推出

来自：腾讯科技

ZDNet 网站周一援引知情人士的消息称，微软将于今年晚些时候发布 Windows 9 预览版，而正式版将于 2015 年上市。

众所周知，微软当前正忙于 Windows 8.1 的第二版更新。但知情人士称，微软更大的计划是于明年推出下一代操作系统 Windows 9。

Windows 9的开发代号为“Threshold"。今年稍晚些时候微软将率先发布一个 Threshold 预览版，而面向公众的 Threshold 预览版将于今秋发布，即微软发布 Windows 8.1 第二版更新后不久。

点评：在 Windows Phone 还没有做到一年一个大版本系统更新时，难道桌面版的 Windows 要一年一个更新么？
