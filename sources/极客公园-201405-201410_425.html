Nokia X2：这一次，微软学会了做安卓设备的正确姿势

By 龚星源 ｜ 2014/06/26

核心提示

首先，这是一台 Android 设备，其次这才是一台搭载微软服务的设备。只有首先保证这是一台合格的 Android 设备，才能更好地推广自己的服务和特色。

北京时间昨天下午三点，微软在诺基亚官方博客发布了 Nokia X2。可以看到，在 Nokia X2 上，微软终于学会了做 Android 设备的「正确姿势」：首先，这是一台 Android 设备，其次这才是一台搭载微软服务和有诺基亚特色的设备。只有首先保证这是一台合格的、不打折扣的 Android 设备，然后才能更好地推广自己的服务和特色。在 Nokia X2 上，微软/诺基亚的态度与之前看待 Nokia X 时发生了巨大的变化：

  • 在配置水平上，追赶同价位的竞争对手，使用能够保证 Android 系统基本体验的配置。

  • 在硬件设置上，根据 Android 系统本身的特性设置机身按键，降低操作体验门槛。

  • 在软件特性上，顺应 Android 系统自身特点，首先保证完整的基本功能。之后再考虑适当加入自身特色的界面和功能。

Nokia X 的前车之鉴

第一代 Nokia X 虽然在发布之初引起了巨大的轰动，但这样的「轰动」更多的是因「诺基亚开始做 Android 设备了！」这件事情本身的话题性带来的各种讨论，对于实际的销量帮助并不大。

如果说 Nokia X 在中国市场卖得不好还可以用「本土千元机太强势，中国不是诺基亚的重点入门级市场」作为借口，那么在印度这样获得诺基亚重点推广的典型「亚洲发展中新兴市场」又如何呢？

我们可以看到，即使在印度，第一代 Nokia X 系列产品也并没有很好的市场表现。以印度市场最大的综合类电商网站 FlipKart 为例：

  • 在 FlipKart 的智能手机销量排行总榜上，摩托罗拉和三星占据了前五名，而排得最靠前的诺基亚设备是第十位的 Lumia 520，至于 Nokia X，即使是最畅销的黑色款也仅仅排在第二十位。

  • 在相当于中国「千元机」市场的印度「万元机」（售价低于一万卢比）入门级市场区间中，Nokia X 也排不到前十。最畅销的黑色款排在第十五位，在它之前，是黑白两色 Moto E、四种三星入门级 Android 设备、三种入门级 Lumia 设备和五种印度本土品牌 MicroMax 的 Android 设备。

在这样的情况下，Nokia X 系列设备在印度市场很难实现诺基亚为它安排的使命：

  • 弥补 Lumia 设备在价格上略偏高的劣势，在入门级价格段上争取用户？实际情况恰好相反，尽管 Lumia 520 和 Lumia 525 要比 Nokia X 贵 1000 卢比左右，它们仍然要远比 Nokia X 更能争取用户——在万元机区间的排行榜上，有三台 Lumia 52x 设备排在 Nokia X 前面。

  • 作为微软云服务的载体，吸引更多没有先前使用习惯束缚的新入门级用户进入微软生态圈？实际情况不如人意：由于 Nokia X 太缺乏竞争力，绝大部分印度入门级市场的新智能手机用户仍然进入了 Google 的生态圈。尤其具有讽刺意味的是，主打「纯原生 Android 体验」的 Moto E 系列设备反而极为畅销，黑白两色长期分别占据 FlipKart 排行榜的第一第二位。

造成这种情况的原因很多，归纳起来，主要是这样一些：

  • Nokia X 本身配置太低且优化不佳，一方面无法提供流畅的 Android 体验，另一方面无法与同价位的三星和摩托罗拉竞争对手竞争。性价比很低不受消费者青睐——反观自发布以来一直占据 FlipKart 畅销榜首的 Moto E，其配置明显比 Nokia X 高，价格则比 Nokia X 更低，其搭载的原生 Android 优化很好，能够提供远比 Nokia X 流畅的软件体验。

  • 诺基亚和微软为了体现自身「特色」，在硬件设计和系统功能上做出了很多损害 Android 用户体验的修改。比如与低端 Asha 设备保持一致的单返回键设计，和由 FastLane 界面同时充当多任务切换器和通知中心的做法。给用户带来了很多不便。

总之，诺基亚和微软在推出 Nokia X 时，过分注重「保持」和「添加」自己的特色，而忽视了作为一台 Android 设备所必须的东西（配置水平、按键设置、系统特性……），这是导致 Nokia X 用户体验不佳，无法在市场竞争中获得成功的原因。

Nokia X2 做对了什么？

总的来说，微软和诺基亚在规划 Nokia X2 硬件和软件的态度上发生了一次完全逆转：

  • 对 Nokia X 来说，它首先是一台诺基亚设备，其次是一台搭载微软服务和生态体系的设备，最后才是一台 Android 设备

  • 对 Nokia X2 来说，它首先是一台 Android 设备，其次是一台搭载微软服务和生态体系的设备，最后才是一台诺基亚设备

提高配置水平

Nokia X 性能低下的处理器和 512MB 的内存是最令人诟病的问题，基本配置的低下，导致进行主屏幕磁贴位置调整等基本操作时经常卡顿，应用之间切换时出现“请稍候”也是家常便饭。

Nokia X2 则在硬件上进行了幅度较大的提升，现在其基础配置已经与最成功的畅销机型 Moto E 基本一致：高通骁龙 200 的处理器和 1GB 的内存，从 Moto E 出色的使用体验来看，只要诺基亚/微软对系统优化得当，保证流畅的基本体验完全不是问题。

除了处理器和内存这些决定应用体验的基本硬件配置之外，另一个获得明显提升的地方是摄像头组件。 500 万像素摄像头、LED 补光灯和前置摄像头的加入，让诺基亚在这些「肉眼可见」的方面追上了竞争对手的主流配置水平。

采用更合理的硬件设置

为了凸显「诺基亚特色」，与更低端的 Asha 设备保持一致，前代 Nokia X 在机身正面只设置了一颗返回键，如需退回桌面，用户必须采用「长按返回键」这样的操作。这种无视 Android 系统基本硬件设置需求，给用户操作添麻烦的做法遭到了大量的抱怨，在 Nokia X2 上，微软「顺应民意」将 Home 键加了上去。尽管仍然与 Google 对原生 Android 的要求和业界惯例有差别，但是在很大程度上确实弥补了之前的单返回键设置造成的麻烦。

补足系统缺失特性

尽管「看上去很美」，但用一个 Fastlane 界面同时取代通知中心和多任务切换界面的做法，在实际使用中仍然会带来很多问题。

在 Nokia X2 中，微软终于想明白，和完全从零开始，一切全都自己说了算的 Asha 智能平台不同，Nokia X 系列终究是 Android 设备，如果要保证软件体验，那么首要的原则是尊重 Android 本身的基本系统结构和特性设定。

在 Nokia X2 上，我们看到微软奇迹般地将之前从 Android 中砍掉的基础特性几乎全部加了回来：多任务切换器、真正的通知中心、更完整的系统设置项快捷操作，这些在 Nokia X 中被认为「太 Android」「不诺基亚」的特性，现在全部加了回来。

这种改变，意味着从 Nokia X2 开始，在系统的基本特性上，X 系列设备和其竞争对手的 Android 设备基本看齐，可以基本不再在基础特性上为用户带来不便。

进一步融入 Windows Phone 特色功能

在确保硬件配置保证体验，基础特性不打折扣之后，作为一台微软/诺基亚设备，Nokia X2 仍然需要在界面和体验上保持「微软特色」。

在 Nokia X2 中，我们看到微软在不损害 Android 本身正常工作的情况下把 Windows Phone 的主屏操作体验完整地搬到了 Android 上，除了 Nokia X 时期的动态磁贴主界面以外，按照首字母进行排列并可以进行快速跳转和过滤的应用列表界面、长按返回键进入多任务管理界面等特性也被完整地复刻了过来。

在 Nokia X 上，人们会觉得除了主屏幕上的方块看上去比较像磁贴以外其界面操作体验其实跟 Windows Phone 没什么联系。而到了 Nokia X2 时期，除了多出一个 FastLane 界面和没有实体搜索键以外，Nokia X2 在系统层面的操作上与 Windows Phone 的区别确实已经变得很小。

Nokia X2 的市场前景

尽管微软在 Nokia X2 的软件和硬件上都做对了很多事情，但是 Nokia X2 的市场前景恐怕不会比它的前代 Nokia X 好太多。

Nokia X/XL/X2 所处的入门级智能手机市场，最基本的特征是消费者群体对「性价比」的敏感度非常高。我们可以看到，即使 Nokia X2 做出了很多顺应潮流的升级，与它的主要竞争对手相比其性价比依然低下。

仍然以印度为例，Nokia X2 的 99 欧元指导价格换算以后超过 8000 卢比，加上各种税收和费用售价会更高，而目前排在 FlipKart 畅销榜榜首的 Moto E，定价仅为 6999 卢比，在线上渠道价格更低。

而与 Nokia X2 处于同一价位段（8000-8500 卢比）的多为印度本土品牌中的著名产品，比如价格几乎一致的 MicroMax Canvas 2.2，这是一台搭载 MTK6582 四核处理器，拥有 800 万像素后置摄像头和 200 万像素前置摄像头这样配置的设备，在所有配置水平上完全超越 Nokia X2，从顾客购买评价来看，实际使用体验也相当不错.

总之，即使不在中国这种「国情特殊」的市场，Nokia X2 仍然面临着「性价比几乎低于所有对手」的问题——同为国际品牌，摩托罗拉和三星总是在更低的价格区间提供硬件配置几乎一致的设备；而在同一个价格区间，印度本土国产厂商提供的大量「性价比神器」则在配置上远高于 Nokia X2.

更为雪上加霜的是，随着 Google 在其 I/O 2014 开发者大会上宣布为印度本土厂商提供完整的「交钥匙」快速出货方案，大量经过 Google 认证足够保证基本体验，而成本被进一步压低的原生/准原生 Android 设备即将到来（4.5 寸双卡双待中等配置，价格低于 100 美元）。届时 Nokia X2 所面临的上述困境只会进一步加剧。

总之，用搭载微软服务和 Windows Phone 风格界面的设备来「引诱」更多用户进入微软生态圈，这样的策略看起来依然更像是一个美好而不切实际的幻想——与其不断地推出缺乏竞争力的奇怪设备，不如与印度本土厂商谈谈 OneDrive 和 Outlook 这些微软应用的预装？
