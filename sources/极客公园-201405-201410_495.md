# 苹果生态观：相似风格、独特交互、无缝协作

当前时代的操作系统平台竞争，已经不再是单个平台特性和一两个杀手级应用的竞争。观察近年的微软 Build 大会、苹果 WWDC 和 Google I/O，我们会发现竞争已经呈现出这样的特点：

  

**「应用生态」是最重要的竞争筹码**

  

不管是桌面还是移动设备操作系统，是否拥有完备的第三方应用生态系统，是决定操作系统前景的关键，因此：

  

· 优质精美、数量庞大的第三方应用软件库成就了 iOS 和 Android；

  

· 即使强大如微软，也没有办法让消费者接受缺乏应用的 Modern 界面（Windows RT 惨淡的销量是最显著的表现）和应用质量差距明显的 Windows Phone（在全球绝大多数市场仅有个位数的占有率）。

  

**硬件没有贵贱之分，只有使用场景之别**

  

桌面系统最为重要，移动场景和其它设备重要性较弱的时代已经过去。对于一家巨头来说，其旗下的桌面电脑、平板、手机、智能电视…… 这些设备都是同一个生态环境中的一员，它们相互协作，共同满足用户在不同场景中的需求。

  

**账号系统和云端服务是完整生态的基础**

  

不同的硬件属于同一个生态，依据不同场景满足用户的不同需求。要达成这种状态，一个功能完善、运行稳定的云端服务是基础。用户以帐号作为进入云端的钥匙，依赖云端服务在不同的设备间同步重要个人数据、无缝迁移工作任务，是这个时代里的典型用户行为。

  

在构建生态方面，微软、苹果和 Google 走了非常不同的三条道路，而从今天结束的 WWDC 2014 主旨演讲环节来看，苹果在构建自有生态方面的路线已经非常明确——相似风格、独特交互、无缝协作。

  

**相似风格——让用户熟悉，给用户归属**

* * *

OS X 10.10 Yosemite 的这次升级，不出所料在界面风格方面向 iOS 看齐，具体的特性包括：  

  

· 毛玻璃层叠效果的广泛应用。和 iOS 7 一样，新版 OS X 也大幅应用了毛玻璃效果，毛玻璃半透明效果带来的是多个窗口层叠时的上下层次感和秩序感。这样的使用感受与 iOS 如出一辙。

  

· 界面元素大幅简化。和 iOS 7 一样，新版 OS X 也对界面元素进行了重新梳理和大幅简化，界面工具条占用的尺寸大为减少，更多的面积留给了内容。

  

· 配色风格的变化。OS X Yosemite 采用了和 iOS 一样的亮色高对比度配色风格，一些应用程序图标（备忘录、Reminder、Safari 浏览器……）的主体图案也向 iOS 看齐。

  

· 新字体。和 iOS 7 一样，新版 OS X 使用了 Helvetica Neue 作为英文基准界面字体，取代了从十几年前 OS X 最初发布开始沿用至今的 Lucida Grande 旧字体。

  

通过这些改变，苹果让 OS X 和 iOS 获得了非常相似的界面风格，从界面元素、风格、配色到字体，确保了用户在 OS X 和 iOS 之间反复转换交替使用，视觉上不会存在不适和断层感。

**独特交互——各尽所能，而不是强行嫁接**

* * *

与微软试图用基于动态磁贴的同一套界面和交互来通吃各种设备不同，苹果此次仍然坚守了「不同形态设备各自拥有经过针对性优化的交互体系」的原则。  

  

我们可以看到，即使是在视觉和风格上已经趋于一致，OS X 仍然只为键盘和触控板/鼠标操作进行优化，并没有如很多人预期的那样扩大界面元素的尺寸，没有为触屏操作做任何优化。整个 OS X 系统在交互体系上也仍然高度统一，没有像其主要竞争对手一样把基于鼠标键盘操作的传统桌面和为手指触控优化的新版界面强行嫁接在一起。

  

同样是在此次更新中，我们看到苹果为 OS X 与电脑触控板的配合做了更多操作上的优化，「苹果笔记本触控板足够好用无需外接鼠标」的传奇得到了续写。

  

![](../Images/e9560d1e879abc68ff86a9bd36291770.png)

即使界面风格趋于一致，苹果仍然非常地清楚：

  

· 键盘和触控板是属于桌面/笔记本电脑的高效操作方式，电容触屏手指点选是属于手机/平板电脑的高效操作方式。

  

· 让电脑的归电脑，让移动设备的归移动设备，如需提高电脑的操作效率，应该持续地优化系统与键盘/触控板的相互配合，而不是给电脑加装触控屏让用户在已经要使用键盘和触控板/鼠标的情况下还要时不时伸手在屏幕上指指点点。反之亦然。

  

· 坚持一种始终如一、简洁可靠的交互体系，比将两种截然不同的交互体系嫁接捆绑在一起体验更好。

  

**无缝协作——紧密的配合与平滑的转换**

* * *

从三年前 iOS 5 和 OS X 10.7 的时代起，苹果就一直在探索不同设备形态之间无缝协作的功能和体验。基于 iCloud 实现各个设备间数据的无缝云端同步，一直是苹果希望达成的目标。  

  

截止到 OS X 10.9 Mavericks，不同苹果设备之间无缝协作的能力其实已经很强——不同平台的同一套应用（其中包括第三方应用，比如 Clear 和 Byword），通过 iCloud 同步文档和数据，已经是非常普遍的功能。

  

![](../Images/cd536ffa83136c2dd51ed6e53695bafa.png)

而 OS X 10.10 和 iOS 8 在无缝配合方面又一次得到了巨大的提升：

  

· 用户可以在 Mac 上管理 iOS 设备的电话短信等基本功能。例如 iPhone 收到来电时可以在 Mac 上直接接听，收到短信时可以在 OS X 桌面信息应用中直接回复。

  

· 使用 iPhone 开个人热点带 Mac 联网非常简单，只需在 OS X 的无线图标下拉菜单栏中一次点击即可自动完成手机和电脑两端的操作。

  

· Handoff 功能。当 iPhone/iPad 放在 Mac 旁边时，文档、邮件、网页浏览等基础需求类操作可以在设备间无缝同步，用户可以随时在不同设备间无缝切换，自然地完成自己的操作任务。这一过程不再需要依赖 iCloud，只要设备在位置上相互靠近即可进行。

  

可以看到，让 OS X 和 iOS 设备之间的协作和交替使用更简洁，体验更好，是苹果希望在此次大更新中达成的目标。苹果非常希望在不同形态的设备间达成无缝、简单、易用的协同工作体验，而从 WWDC 2014 的这次大更新来看，苹果距离这样的目标又近了很多。

  

**结语**

* * *

可以看到，苹果对于 OS X 和 iOS 设备间「哪些东西可以统一，哪些东西不能统一」的问题一贯思路非常清晰：  

  

· OS X 和 iOS 在界面风格上应该相互和谐，让用户不致有割裂和断层的感觉。

  

· OS X 和 iOS 在交互体系上应该互相独立，基于键盘/触控板的桌面设备和基于触摸操作的电容屏移动设备各自存在最适合自己的交互方式，因此二者都不能强行照搬对方交互体系的经验。

  

· OS X 和 iOS 之间的协同工作和交替使用体验应该尽量无缝。OS X 设备和 iOS 设备都是苹果生态圈里的重要成员，没有贵贱之分，只是因为硬件形态不同而各自适用于不同的场景。改善它们在协同工作和交替使用时的体验，可以更好地满足用户根据场景灵活选择设备实现自身需求的体验。

  

苹果这样的做法，与微软和 Google 的做法差别很大。不过我们可以看到，在 Windows 8 时代强行嫁接两种截然不同用户界面的微软，似乎也意识到了「让键鼠的归键鼠，让触屏的归触屏」的重要性。

  

在 Windows 8.1 和后续更新中，微软承诺迎回开始菜单、允许非触屏设备用户开机直接起动到传统桌面、允许将触屏应用放在传统桌面上运行，这不能不说是向苹果路线的一种靠拢。
