# 火速轻应用：在石缝里穿行的 HTML 5 挑战者

> \[核心提示\] 在 HTML 5 时代会产生新的平台级公司么？这家像黄鳝一样的创业公司伺机而动。

微信朋友圈里的 HTML 5 宣传页面让轻应用这滩死水出现了涟漪，随之出现了例如「微贴」、「场景应用」等 HTML 5 宣传页公司。

而伺机已久的赵九州则找到了来自新浪微博的产品经理冯兴华，创办了一家应用聚合平台——火速轻应用，这个轻应用商店将一个个 URL 地址封装成本地应用的形态添加到用户桌面，打开后继续在火速轻应用提供的浏览器中访问。

公司就像一条体表湿润的黄鳝，找到岩石中的缝隙，在其中自由穿行。

视频网站采用线性方式为用户提供内容，如果用户搜索的《何以笙箫默》版权被别家买走，视频网站则将拥有版权的《武媚娘传奇》推送给用户。

火速轻应用直接解决用户的点状需求，不用寻找买有《何以笙箫默》版权的应用，**在火速轻应用把播放地址封包成独立应用推荐给用户。**

未来这种模式还可被套用在租房和找工作这类信息聚合场景中。

已经有 4000 款轻应用被火速轻应用收录，在他们看来，目前 HTML 5 已经能够代替 80% 的简单交互和内容展示，今日头条、下厨房和顺风快递查询都已经可以在火速轻应用中流畅使用。

## 找到缝隙就钻进去

在这个未来必将和互联网巨头交锋的领域，火速轻应用早已做好找到更大的石洞庇护。赵九州曾经和国内一家手机厂商谈过合作，对方被火速轻应用未来可能带来的变革心动，但考虑到他们的用户规模还未达到收购地步而婉拒。

这条黄鳝从不和生存过意不去，看到了趋势的缝隙就立即钻进去。

赵九州告诉极客公园，现在下载了火速轻应用并在一个月内登陆两次的有效用户已经达到 300 万，其中微信朋友圈的病毒式推广让他快速获得 100 万用户。

当去年基于 HTML 5 开发的游戏「围住神经猫」上线 48 小后，IP 数据窜升到 241 万，PV 达到 1026 万。这个异常的数据立马让火速轻应用团队看到机会。

随即把它克隆了一版推送到朋友圈，当游戏任务失败后，提示用户将该游戏添加到桌面，从而引导下载火速轻应用，并借着这个趋势每周推送一款 HTML 5 游戏。

当微信开始限制同一链接的分享次数后，分享轻应用到朋友圈的用户将获得积分红包。此时，分享任务系统和推广换量都已经在计划中。

今年一月火速轻应用获得了创新工场的 Pre A 轮 1500 万人民币的投资，这部分资金的重要使命即是通过各种方式引入更多用户。

## 解放垄断在巨头手里的内容

微信选择了苹果类似的封闭生态圈，为了更好的体验，对内容进行挑选，在朋友圈中好友发布的内容会根据一套「评价标准」被过滤出你的时间线。

对于希望靠内容盈利的制造者而言这是一个危险的信号，在去年结束的微信公开课上，微信公布的数据显示订阅号 80% 的内容是通过朋友圈分享被发现的，大量的公众账号内容需要找到出口。

火速轻应用最早的版本只是分发轻应用和游戏，现在也开始尝试内容。赵九州认为**未来用户移动端的用户不会关心内容从什么地方来。**

现在火速轻应用里的内容来自合作方爱微帮，爱微帮作为内容采集方会搜集微信里公众号的内容。从而定期向用户推送好玩内容。内容提供方的内容增添了新渠道，原有的广告继续被保留，流量依旧导流给内容提供方。

这种方式获得了今日头条的认可，在火速轻应用版的今日头条中已经将页面下方安装今日头条提示去除。

此外，HTML 5 的生态需要更多的工具支持，一些 HTML 5 页面还用的是百度统计，由于 HTML 5 页面不需要刷新，其中重要的交互次数被遗漏。

收费也是一个问题，不少游戏还是通过 SP 时代的短信扣费，而使用支付宝需要一个完整的 SDK，其实他们需要的只是一段 JS 代码。

在年后他们将发布三款开发者工具：

开发工具蜻蜓：在 5 分钟内帮开发者搭建一个自己的轻应用，开发者只要根据模板选择产品类型、提供相关图片、设置好积分机制。

流量分发平台云游：为众多应用提供 HTML5 内容的合作频道的方式，让用户不用下载火速轻应用的客户端，也可以在其他 App 里直接体验到 HTML5 内容。

以及统计与支付工具。

赵九州认为无论是百度还是 UC ，没能将轻应用推广起来的重要原因在于自身的贪婪，视频和音乐这类高流量内容已经由他们提供，给开发者预留的空间不够。

「这不是个强技术含量的事情。」赵九州说。

火速轻应用并非技术优势，无论是现在的应用商场还是即将正式上线的蜻蜓和云游，他们和去年百度引发的轻应用热时期的工具类似。

而黄鳝没有特殊的攻击本领，但适应能力强，在河道、湖泊中都能生存。

如果说火速轻应用真的能把握住 HTML 5 的趋势，他们的自信则来自对用户需求的敏锐判断和更加本土化的行动方式。
