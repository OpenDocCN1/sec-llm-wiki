## Windows 10 Mobile 预览版有望在下月推出

*来自 CnBeta*

微软最近发布了两个 Windows 10 Mobile 应用程序到 Windows Phone 商店，显示它准备在不久的将来推出 Windows 10 Mobile 预览版。虽然微软会在今天的活动上公布 Windows 10 Mobile 部分细节，但是 Windows 10 Mobile 预览版可能要到几个星期之后才能发布。

Windows 10 Mobile 操作系统据称支持 ARM 和英特尔平板电脑，以及 Windows Phone 设备。微软此前曾表示，所有支持 Windows Phone 8 的 Lumia 手机都将被升级到 Windows 10 Mobile。

**点评：**WP 7 和 WP 8 总是有点半死不活的感觉，Win 10 Mobile 能拯救微软在移动系统的占有率吗？

## Netflix 第四季度净利 8300 万美元 同比增长 73%

*来自 网易科技*

Netflix 今天发布了截至 12 月 31 日的 2014 年第四季度财报。报告显示，公司该季度营收 13.05 亿美元，同比增长 36%；净利润 8300 万美元，同比增长 73%；合摊薄后每股收益 1.35 美元，去年同期为 0.79 美元。

其中：营收 13.05 亿美元，去年同期为 9.62 亿美元，上季度为 12.23 亿美元；总用户数 5739 万人，去年同期为 4435 万人，上季度为 5306 万人；付费用户数 5448 万人，去年同期为 4143 万人，上季度为 5065 万人。

**点评：**随着带宽不再是问题，流媒体正在取代很多以前的本地服务，至少，去年对于流媒体是飞速增长的一年。

## 亚马逊修建风力发电厂 为数据中心提供能源

*来自 网易科技*

亚马逊也加入了再生能源科技公司的行列。该公司目前致力于利用可再生能源为云计算服务（AWS）提供电力。亚马逊周三表示已经与 Pattern 能源集团签署了 13 年的合作伙伴关系，两家公司将会一起修建和经营规模 150 兆瓦的风力发电场。

新风力发电厂的修建地点在印第安纳州 Benton County，官方名称为「亚马逊网络服务风电场（Amazon Web Services Wind Farm）。」亚马逊计划在 2016 年 1 月提供约 50 万兆瓦时的电能。美国 2012 年的平均居民用电消费是 10837 千瓦时，所以亚马逊的新风电场每年可以为 46000 家庭提供电力。

**点评：**公司大了，电费当然是个问题。

## Facebook 采取行动打击虚假新闻

*来自 新浪科技*

Facebook 周二称，该公司已采取措施打击「恶作剧」和虚假新闻，这些信息能在其拥有 13.5 亿名用户的在线社交网络中像野火般蔓延开来。Facebook 称，该公司已经推出了一种新选项，允许用户将一则新闻故事标记为「故意捏造或欺诈性新闻」，以降低恶作剧新闻传播的可能性。

Facebook 称其不会从其网站上删除虚假新闻，而是会将恶作剧报道列入其算法设计的考虑因素，而算法是用户帖子能传播多广的决定性因素。Facebook 对此解释道：「如果一个带有指向某篇文章的链接的帖子被许多人标记为恶作剧报道，或是被许多人选择删除，那么其在信息流 (News Feed) 中的传播率就会降低。」

**点评：**社交网络传播力量巨大，降低假新闻传播力量确实很有必要。

## 微软斯巴达浏览器原生支持 Chrome 浏览器扩展

*来自 CnBeta*

微软会在今天向外界揭示 Windows 10 消费者预览版，并且炫耀新的斯巴达浏览器。根据 Neowin 网站报道，斯巴达浏览器将原生支持 Chrome 浏览器扩展，以提升斯巴达浏览器对开发者的吸引力。另外，Chrome 浏览器开发者也在努力让 Chrome 浏览器扩展可以在斯巴达浏览器上正常工作。

这些消息证明斯巴达浏览器和 Chrome 浏览器之间存在不少相似性，这种做法也可以节省开发商不少时间。之前，开发者针对一款新浏览器，不得不重新开始研发一个新的扩展。而现在，他们可以简单地把他们的 Chrome 扩展交给斯巴达浏览器，以最小的努力迅速覆盖两种浏览器。

**点评：**一大堆插件是我留在 Chrome 的主要原因。如果确实如此，我倒是很想尝试下 Spartan。
