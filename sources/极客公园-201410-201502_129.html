[核心提示] 今天小米召开了 2015 年首场发布会，发布了 2299 元的小米 Note ，3299 元的小米 Note 顶配版和 499 元的头戴式耳机几款产品。

你方唱罢我登场，在沉寂了一段时间后，小米召开了 2015 年首场发布会，发布了 2299 元的小米 Note ，3299 元的顶配版小米 Note 和 499 元的头戴式耳机几款产品。

相比起简约的发布会邀请函，这次小米在微博上的预热活动可谓下足了功夫。用如蝉翼、有来头、若鸿毛、不同凡、喜临门、刀斩麻、操胜券等缺字的成语预告了本次发布会的内容，非常有趣。

让我们把这些成语补充完整，通过它们梳理一下今天的小米发布会。

「稳」操胜券

发布会开始雷军首先介绍了小米生态链的合作伙伴，并播放了一段很「暖心」的小米生态链伙伴的视频。下一步小米计划通过推出通用智能模块、通用控制中心和通用云服务来让小米生态链普及起来，真正进入到大众的生活中去。


把朋友搞得多多的，把敌人搞得少少的

雷军介绍了小米生态链的合作策略：开放、不排他、非独家；小米愿意和所有厂商合作，甚至包括格力。小米生态链的布局正在有条不紊的进行，优势也逐渐凸显了出来。


「薄」如蝉翼

接下来就到了今天的主角小米 Note 登场了，同时不可免俗地开始了与 iPhone 6 Plus 的对比。

小米 Note 采用了双曲面玻璃+金属边框的设计，屏幕为 5.7 吋负液晶视网膜屏，NTSC 色域高达 95%。与 iPhone 6 Plus 相比，机身更小，但是屏幕更大，屏占比很高。

小米 Note 采用了索尼 1300 万像素光学防抖相机，值得一提的是镜头并没有突出。整机厚度 6.95mm，重量仅有 161g，比 iPhone 6 Plus 还薄了 0.75mm，轻了 11g。

以下是一些现场真机图：



虽然小米 Note 的配置比较保守，仅采用了骁龙 801 处理器，3GB 内存，支持4G双卡双待；但作为一款大屏手机，小米 Note 整机的尺寸、重量控制在一个比较合理的范围内，后期还会增加强大的单手操作模式。

售价方面，16GB 版 2299 元，64GB 版 2799 元。别急，「发烧」的配置还在后面。


不同凡「响」

大家都以为小米会发布一款音响，但其实是小米 Note 的 HiFi 系统。小米 Note 采用了 ESS ES9018K2M 音频解码芯片，支持APE、FLAC、DSD、WAV 等无损音乐格式及 192kHz / 24bit 录音室品质格式输出。

小米 Note 的外放采用了 Smart PA芯片，声音特别宏亮，雷军开玩笑说它将会成为父母的广场舞「神器」。


除了 HiFi 系统，还有一款加一联创推出的头戴式耳机，由李泉等知名音乐人参与调音，售价 499 元。

不过雷军也承认音质确实是非常主观的事情，但小米对声音的探索还是值得鼓励的。

「双」喜临门

为了满足发烧友对性能的追求，小米还推出了一款小米 Note 顶配版，外观与小米 Note 一致，但配置更加强悍。用雷军的话说是：「将发烧进行到底」。

小米 Note 顶配版采用了20nm 制程的高通骁龙 810 处理器，4GB LPDDR4 内存，64GB eMMC 5.0 高速闪存，屏幕分辨率也升级为 2K 级别，售价 3299 元。


以上就是这次发布会的全部内容。对了，发布会结束后小米还送了到场粉丝一件新年礼物：小米小盒子。

「小米小盒子」这个名字很 Q ，可以看做小米盒子的 Mini 版，号称是世界上最小的网络机顶盒，售价 199 元。小米小盒子主打视频观看功能，拥有超 14 万小时海量正版内容，比上一代小米盒子内容量提升 64%。

不论是 2299 元的小米 Note / 3299 元的顶配版本，还是在生态链上的稳固布局，小米正从一个 2011 年手机市场的「搅局者」，逐渐变成手机甚至是大众消费电子领域领导者，让我们期待小米 2015 年的表现。

发布会后记：

今天的发布会还有两个现象值得关注。一个是有大量的外国媒体和厂商参加，可以看到各种肤色，听到各种语言；当 Hugo Barra 现身时还引起了一阵骚动，国外市场的一些碰壁并没有影响小米正变得越来越国际化。

还有一个是在会场外，三大运营商的通信应急车齐聚，会场内手机信号和数据流量都很畅通，而且开放的 WiFi 速度也出奇的快。这种在看不到的地方所做的努力，让我们感受到了小米的诚意。
