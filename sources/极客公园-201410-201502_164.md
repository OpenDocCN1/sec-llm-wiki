## 前言  

世界上第一个遥控器到底是谁发明的已经没办法去考证了，但 1955 年尤金·波利发明了首个名为「闪光自动化装置」（Flash-Matic）的无线电视遥控器，从此便激发了人们对控制设备的需求与创造。遥控器也从技术、需求、交互等方式上不断地更新换代。

![](../Images/f1a4775b41778545558be3691d16cae4.png)

我大概统计了一下周围人使用遥控器的情况：平均每个人家中有 3-5 个遥控器，每个遥控上大约有几十个按钮。可是我们真的需要这么多按钮来帮助我们吗？

很多时候遥控器不再是一个好助手，而变成了麻烦制造者，我们想要的也许仅仅就是一个逻辑统一、操作便捷的遥控器。来看看旋钮控制器 SPIN remote 吧，它让我们的操作和遥控变得更加简单。

![](../Images/9a347b003908cd6e5af181faab4ea9ef.png)

## 概览

SPIN remote 是一款远程控制器，可以学习遥控器的信号，从而替代多个遥控器。通过旋转和触摸的新兴交互方式控制家电。

## 功能 & 特点

SPIN remote 在你触碰它的时候它会自动激活。通过简单的设置，可以用你的 SPIN remote 调节灯光亮度，音量大小，换频道，调节室内温度等等。更酷的是，首次旋转还可以一次打开多个设备，例如到家后通过首次旋转同时开启灯光、电视、机顶盒、空调。

![](../Images/2ea74e0378e65a1f823617835bddbc3c.png)

SPIN remote 通过朝向不同的设备来分别控制它们，它还拥有检测运动、旋转、定位和触摸的传感器，可以区分正反向旋转、识别你在桌子上画圆的操作、识别你朝向的设备等等。通过智能的分析，SPIN remote 将你的行为转化成相应的命令并发送给相关的设备。例如，

![](../Images/12c527919a4b01c10e295ffb7f42667d.png)

SPIN remote 可以通过低功耗蓝牙和家中的智能设备连接，它还能够识别红外信号，这样可以学习旧设备遥控器中的命令。

![](../Images/ca445a1c8c8b6a655c3821ae5e105f7d.png)

通过 SPIN remote 的手机APP，可以将没有红外功能的智能手机当成万能遥控器使用。通过 App 设置 SPIN remote ，还可以创建自己的预设，添加新设备，配置智能触控板等，还可以结合不同的功能和旋转自定义你所独有的方式。

![](../Images/a51c5aa6e05e4242f23fc38b294e9e9f.png)

SPIN remote 开发团队也正在开发一些新的功能，例如「Find Me」，点击 app 响应按钮，SPIN 发出声音和闪烁 LED 灯。「SPIN spider」通过多个 SPIN spider 相互连接，使得红外信号可以连接到任何地方，而不需要直射。

开发团队还开发了 API / SDK， 你可以用 SPIN remote 连接到任何你想要连接的设备，或者把它变成一个游戏控制器等等，可以尽情发挥创意。底部智能触控板包括五个触控区域，四周的LED灯，都可以自定义、甚至自定义你独有的交互方式。

## 点评

SPIN remote 改变了控制的交互方式，将旋转和触控变成对应的操作。旋钮式的操作会比点按式操作更加易于调节大小，但是 SPIN remote 中的「换频道」实在是「鸡肋」，包括它的形状也让人不禁要问，握持真的方便吗？但它可以集成所有的遥控装置的功能和它的开放性，包括这种控制交互方式还是给我们很大的启发。

希望今后再购买新设备后，仅仅需要与现有的类似 SPIN remote 遥控装置配对即可，而不需要再使用各式各样的遥控装置，从而真正颠覆遥控器的存在。也希望通过不断地迭代和优化，让控制也变得更加简单高效。
