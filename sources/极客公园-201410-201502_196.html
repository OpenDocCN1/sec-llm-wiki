柯达即将在 CES 上推智能手机

来自 腾讯科技：

柯达首席执行官奥利弗•舒尔特（Oliver Schulte）表示，他们将发挥公司的传统优势，开发一系列设计精美的移动设备，让用户在瞬间拍摄、编辑、共享、存储和打印精彩的照片。

柯达不会自行制造智能手机，负责这项任何的是移动设备制造商 Bullitt Group。Bullitt Group 曾经为建筑公司卡特彼勒（Caterpillar）制造手机。

点评：手机似乎成为了各个行业的新载体，但功能如此细分的手机真能打动消费者么？

特斯拉 Roadster 充电行程提升至 400 英里

来自 凤凰科技：

对 Roadster 跑车升级后，其单次充电行驶里程从原来的 244 英里提升到 400 英里，几乎实现翻番，升级后的 Roadster 跑车单次充电行驶里程超出传统汽车单次加满油箱后的行驶里程。

点评：Roadster 跑车的单次充电行驶里程超越了当前公司的旗舰车型 Model S。

消息称大众点评再获新一轮 8 亿美元融资

来自 新浪科技：

消息人士透露大众点评网近日再获新一轮融资，融资额逾 8 亿美元。获得融资后大众点评将加速团购、餐厅预定、酒店、电影等全线业务扩张。官方未予置评。

点评：在获得腾讯 4 亿注资后，点评收购下游公司，再加上美团不断进攻，看来需要进一步的资金补给。

开源海盗湾项目 The Open Bay 成 Github 本周最热门项目

来自 cnBeta:

种子网站 isoHunt 在不久前再次推出了 The Open Bay 网站，该网站基于开源设计，允许任何人打造自己的在线海盗湾，并在 GitHub 上共享了该项目的源码。在上线一周左右，在 GitHub 上已经有 1841 次关注，522 次标记。

点评：成为 Github 上的热门项目大概意味着将远离主流人群视野。

英农场为动物戴数码项圈改善无线信号

来自 网易科技:
