> \[核心提示\] 魅族在今天发布了子品牌魅蓝的第一部手机：魅蓝 Note，配置「强悍」，外观向 iPhone 5c 致敬，价格 999 元。

今天下午，魅族今年的第四场发布会在国家会议中心如期举行，今天的主角是魅族全新子品牌魅蓝的首部手机：魅蓝 Note

## 参数，还是参数

> Talk is cheap, show me the code.

在对国产厂商一通「数落」之后，魅族科技总裁白永祥引用了 Linus （ Linux 之父）的一句话来阐述魅族的品牌精神。

![](../Images/838af555fe30d9d12f50ac6e5c9361bd.png)

随后发布了「魅蓝」子品牌，魅蓝 Note 也终于正式登场。

![](../Images/026b29168541c14cbee745a387d630ba.png)

魅蓝 Note 每公布一个参数都伴随着「魅友」的欢呼。魅蓝 Note 是采用了 64 位「真 8 核」处理器，并配备 2G 内存和 16GB 存储空间，电池容量为 3140mAh，配备低功耗蓝牙 4.0 技术。

![](../Images/4e17371fb0425ce1e56a866d513c2d33.png)

作为魅族首款双卡双待设计手机，魅蓝 Note 支持移动/联通双 4G 网络。另外魅蓝 Note 采用双频 WiFi（2.4G+5G）及两种全球卫星定位系统（GPS+GLONASS）。

![](../Images/b15067ea22f7ea94622725ddc16101a0.png)

魅蓝 Note 后置摄像头为 1300 万像素，配备双色温闪光灯，支持全高清 1080p 摄像和慢动作视频录制。前置摄像头 500 像素，采用 F/2.0 大光圈，支持实时调整滤镜。

现场展示了前后摄像头的拍照样张，具体效果怎样希望不要「呵呵」了。

![](../Images/34a18a42405574a1c3eff17d8cb485b8.png)

![](../Images/c6df225f748593813b4749d965eab0d6.png)

魅蓝 Note 采用了 5.5 寸 1080P 屏幕，官方宣称在色域、对比度、亮度和显示效果上均会带出色的体验。

![](../Images/14f26beef5c06cc4a27bf83595b06e96.png)

  

## 重新定义了 iPhone 5c

比起参数，我更好奇魅蓝怎样「致敬」邀请函中的 iPhone 5c 的后盖。

的确，魅蓝 Note 采用了和 iPhone 5c 一样的注塑工艺，一样的背部弧线，一样的多彩颜色设计，只是屏幕更大了一些。说魅蓝 Note 重新定义了 iPhone 5c 也不过分。

![](../Images/373bc5913ff54957397bdc3e88958610.png)

与外界猜测的不同，在公布魅蓝 Note 999 元的价格后，发布会就匆匆结束了，并没有更多的新品，也没有透露魅族未来的计划。

![](../Images/6ab6047cecc3b4ce224a9728d7c55755.png)  

对于魅族的自我定位，魅族科技总裁白永祥如此形容：

>   
> 如果不是三宅一生，褶皱的美感就会被熨斗铲平；如果不是香奈儿，女性露出膝盖是禁忌；如果不是圣罗兰，女人这辈子与男裤绝缘；如果没有魅族，年轻人手中永远缺少品质。  

魅族将魅蓝 Note 定位于年轻人的「高品质手机」，便宜的价格和时尚的外观是否能受到年轻人的喜欢呢？让我们拭目以待。

## 结语

今天的发布会白永祥频繁使用了「友商」这个词，更是多次将魅蓝 Note 与红米 Note 进行比较，作为千元机市场的后来者，魅族的野心可见一斑。

魅蓝 Note 是否能重新定义千元机还需要市场的检验，但随着它的发布，魅族在高中低三档手机的布局已经完成，更加开放的心态也会在 2015 年为魅族带来更多的想象空间。不过就像上次 MX4 pro 发布会后说的一样，如何让消费者买到好产品仍是目前魅族面临的最大问题。
