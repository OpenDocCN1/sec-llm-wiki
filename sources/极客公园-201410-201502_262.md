> > 2014-12-20 14:00 | 腾讯汇
> 
> > 电子游戏渐渐的已经融入了人们的生活，成为了大部分人生活中不可或缺的一部分，游戏市场当然也处处充满竞争。提到穿着背带裤的大胡子水管工，我们立刻就能联想到超级马里奥；提起巨龙、火焰与红色系的设计，《魔兽世界》便会跃然于眼前。可见，创意对于一款游戏是至关重要的。一款游戏，要如何在第一时间抓住玩家眼球并提供良好的用户体验？对此，一个优秀的设计团队又能做些什么？
> > 
> >   
> > 
> > 除了扎实的「手头」功夫，优秀的推广类设计团队在品牌、营销、创意、市场、广告等领域也要有所了解。有竞争力的设计师，更需要在创新呈现技术、氛围营造、互动设计、品牌形象打造等方面具有敏锐的探测力。
> > 
> >   
> > 
> > 探索过神秘的「数据决策」，领略了不可思议的「网游历史」，本期「探秘游戏方法论之创意魔法书」就将针对游戏创意与设计对用户体验的影响进行分析。
> > 
> >   
> > 
> > **讲师介绍**
> > 
> > 李若凡，腾讯互动娱乐市场部设计总监，腾讯游戏官方设计团队 TGideas 负责人，一个设计师、插画师、游戏文化推动者，当然也是一位骨灰级玩家。
> > 
> >   
> > 
> > **报名条件及课程形式**
> > 
> >   
> > 
> > 由于课程内容要求，需要报名者对电子游戏或创意设计有一定了解为宜。请于报名时详细填写自己的个人资料，如你所在的公司名称、职位、从业经历等。我们将对通过的同学进行电话确认及短信通知，届时请注意查收。  
> > 
> >   
> > 
> > 「探秘游戏方法论」采用计分制 workshop 形式，期间会穿插提问讨论和交流，根据各组回答的质量和积极程度来计分。总分前三名小组都将现场获得特殊奖品。
> > 
> >   
> > 
> > **课前作业**
> > 
> > 针对一款以「爽快打击感」为卖点的格斗类手游，进行平面广告的创意表达构思。答案请填写报名页面下方「个人介绍」处，如字数限制了你的表达，可发送你的想法至 liuyi@geekpark.net，并留下你在极客公园的账号信息。认真完成课前作业的报名观众将会有更高几率通过审核。
