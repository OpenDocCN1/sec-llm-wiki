## 《时代》2014 风云人物候选人:库克、马云入选

*来源：网易科技*

据国外媒体报道，《时代》杂志「2014 年度风云人物」候选人名单本周一正式出炉。苹果 CEO 蒂姆·库克（Tim Cook）因 iPhone 6/6 Plus 的疯狂热销，和公开承认自己「同性恋身份」，而再度获得提名。此外，率领阿里巴巴摘得「全球最大规模 IPO」头衔的马云，也是八名候选人之一。

《时代》「2014 年度风云人物」最终人选将于本周三揭晓。

**点评：**库克其实在 2012 年就入选过年度风云人物，感觉这次再次入选妥妥的了。

## 德国工会号召亚马逊工人举行新罢工

*来源：新浪科技*

德国一家工会向亚马逊发出警告称，工会工人将在圣诞节到来以前进一步采取罢工行动。

在一年中最繁忙的假期购物季节全面展开之际，德国 Verdi 工会周一号召工人发起罢工，藉此向亚马逊施压，要求该公司就 1 万名仓库工人的薪资问题展开谈判。该工会最初是在亚马逊位于巴德赫斯费尔德的业务部门号召发起此次罢工的，但随后莱比锡的亚马逊员工也已决定加入。工会希望亚马逊将仓库工人分类为零售行业员工，并与其签署工资协议；但亚马逊则认为仓库工人是物流员工，并表示其工资高于同业水平。

**点评：**所以亚马逊一直在想打造一支机器人大军。

## 谷歌云平台加入微软 Windows 2008 R2 支持

*来源：网易科技*

谷歌周一宣布，Google Cloud Platform（谷歌云平台服务）从今起开始新增对 Microsoft License Mobility、Windows Server 2008 R2 Datacenter Edition 以及 Chrome RDP 的支持。

同时，Windows Server 2008 R2 Datacenter Edition 服务器操作系统也加入到谷歌云支持中，但仍是测试版。谷歌表示，如今仍有大量用户在使用 Windows 服务器提供服务，因此希望能在谷歌云平台中开到对微软产品的支持与部属能力。谷歌指出，对 Windows Server 2012 和 Windows Server 2012 R2 的支持仍在开发中。公司未明确给出具体的发布时间。

**点评：**服务用户远比建立壁垒更重要。

## 强奸案促新德里政府对 Uber 服务颁布禁令

*来源：新浪科技*

美国打车服务 Uber 已被禁止在印度首都新德里运营业务，原因是上周末一名女性乘客指控称，Uber 的一名司机对其实施了强奸。新德里警方上周日逮捕了名叫 Shiv Kumar Yadav 的 32 岁男子，并认定他是这桩强奸案中的 Uber 司机。该男子尚未就此发表言论，目前还不清楚他是否已聘请代表律师。

Uber CEO 特拉维斯·卡拉尼克 周一在该公司博客上发表声明称，新德里政府并未要求对商业司机进行背景调查。他表示：「上周末在新德里发生的事件令人害怕」，并表示 Uber「将与政府合作建立起当前商业交通牌照计划中缺少的背景调查」体系。

**点评：**Uber 今年在很多地方都受阻了，但是被禁的理由却完全不同。
