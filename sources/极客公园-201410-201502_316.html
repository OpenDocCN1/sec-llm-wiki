[核心提示] 以孩子的眼光看，市面上的儿童手环还有什么值得改进的地方呢？

有人说，如果想了解孩子，请蹲下来跟他们聊天。如果我们把视角放低，以孩子的眼光看，市面上的儿童手环还有什么值得改进的地方呢？


不好用

妈妈告诉我，带上这个手表后她在家里就可以随时知道就我在哪里，就不用担心我走丢了，可是这个手表真有那么神奇吗？如果我被坏人蜀黍带走了，爸爸妈妈真的能通过手表找到我吗？有一回跟爸爸逛商场，因为跑到一个文具店跟他走散了，过了很久他才找到我，把我都急哭了。

  • 画外音：大部分儿童穿戴产品采用了 GPS + LBS 的定位方式。LBS 定位的误差很大，通常控制在 150 米内就很不错了；GPS 定位相对准确，误差能减小到 5~10 米内，可是遇到室内定位就没办法了；并且通过 GPS 定位很耗电，鉴于这些儿童穿戴设备的体积，续航会成为一个问题。

妈妈教过我在危险的时候可以按这个「一键求助」的按钮，她就知道我遇到危险了。但如果我真的被坏人带走了，我一定吓哭了，肯定想不起来去使用它，而且要是坏人蜀黍把我的手表扔掉了怎么办呢？

  • 画外音：儿童失踪案件在美国虽然也很常见，得益于 Code Adam 这种全民预警机制，绝大多数失踪的孩子都会被找回来。因此，要想解决儿童失踪问题，不仅仅只是一两个可穿戴产品能做到的，这需要需要全民的参与和努力。现在的这些儿童可穿戴产品的定位功能只能作为父母查看孩子位置的一个参考，切不可过于信任他们而掉以轻心。


不好看

你们这些大人考虑过我们感受么？我才不愿意带着这些丑丑的手表，同学肯定会笑话我的。

我也不喜欢这个样子的手表，它们看起来不好看还特别厚，带起来肯定不舒服。我还是喜欢爸爸送我的《冰雪奇缘》的手表，上面画着安娜公主呢，同学们都羡慕我。

  • 画外音：儿童穿戴产品首先要符合儿童的「审美」，才能获得他们的亲睐，比如可以和当下流行的动画片或漫画合作，推出受小朋友喜欢的产品。并且如果仅仅为了提供一个定位功能，完全没有必要非要做成可穿戴产品。


不安全

下面这个手表看起来就像草莓味水果软糖的样子，我好想咬一口尝尝啊。它还有两个「触角」，如果我带着手表趴在桌子上，刚好就能咬到，虽然妈妈告诉我上面有细菌不能咬，可我就是忍不住啊。

  • 画外音：对于这种针对儿童的科技产品，在健康方面的要求要比一般产品更加严苛。大家一定想到了，上面这个厂商肯定会说明采用了「奶嘴级」的材料。问题是：光考虑了「触角」本身不怕咬，有没有想到暴露在空气中或者戴在手腕上蹭到衣服所带来的细菌？小朋友咬了细菌是不是就进到嘴里了？为了祖国的下一代，希望厂商们能够想稍微想的远一点。


我不喜欢这些手表，我害怕带了这种手表以后爸爸妈妈就不去学校接送我了，我还是希望他们能多花些时间陪陪我。而且这些手表都不好看，要是上面有我喜欢看的动画片人物的话，我可以考虑考虑。你们这些大人可不要骗我们哦。
