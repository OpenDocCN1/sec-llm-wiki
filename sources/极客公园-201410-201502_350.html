[核心提示] 微信 Wi-Fi 来了，它到底怎么用？为何最近两年如此多 Wi-Fi 类产品出现？

张小龙赋予微信「连接一切」的使命，公众账号、微信支付被看作是微信向企业、商家 O2O 渗透的重要棋子，而这都只是开始。

稍早时候，微信正式上线「微信连 Wi-Fi」(简称：微信 Wi-Fi)官网，根据官网介绍，商户可以通过加入「微信 Wi-Fi」来获得触达用户的渠道，用以营销、销售。

在这个「没有 Wi-Fi 不能活」的时代，微信 Wi-Fi 显然更能够拉动商户与微信互动能力的有力武器。

微信 Wi-Fi：一头连用户，一头连商户

据了解，「微信 Wi-Fi」目前仍然属于测试阶段，目前仅接受「已完成微信认证」的公众账号用户申请。

根据微信官方的帮助文档，微信认证仅面向企业、网店商家、媒体、政府及事业单位、其他组织开放。而从产品逻辑看，更多是面向拥有「实体经营能力」，即实体商户开放。

消费者在合作商户可以快捷地连接 Wi-Fi 网络，而不再需要问店员无线密码是多少。而微信将会通过三大部分来为商户提供服务：

  • 直达入口：微信首页免费推广入口， 触达4亿潜在用户。

  • 近场服务：近距离精确了解用户动线消费等行为，推送精准的场景化服务。

  • 微信体系：微信公众号，微信支付等一系列微信服务打通，低成本实施。

和微信官方确认：其中直达入口是指用户在连接合作商户提供的 Wi-Fi 后，可以直达商户的主页（可以是公众账号，也可以是自行设置的H5页面），让商户拥有触达消费者的能力，已进行后续的进一步的营销与销售。

而微信体系则是指包括公众号、微信支付等，能够帮助线下商户逐步完成营销、展示、交易的 O2O 闭环工具。

举个例子：

用户进入一家咖啡店连接 Wi-Fi 后，可以直接关注商户的微信公众号来查看优惠并直接下单。

后台会自动分配桌号并适时将订单内容传送到店内的订单管理系统，在完成消费后消费者可以分享图片到朋友圈获得优惠券，并对本次消费进行评价。

换言之，微信 Wi-Fi 是帮助商户与消费者进行多次连接的开始工具，而不是在销售完成后，与消费者的连接就完全中断。

竞争白热化的 Wi-Fi 共享市场

最近两年，围绕在 Wi-Fi 共享这一块的竞争的产品就包括迈外迪、支付宝钱包、WiFi 万能钥匙、WiFi 伴侣、爱无线等一系列产品。

其中迈外迪是目前国内最大的商用 Wi-Fi 提供商，在 2013 年底被小米科技战略投资，小米用户在进入到迈外迪合作的咖啡、餐饮、商场、影院等场所，将能够免费连接 Wi-Fi 网络。近期最新消息是迈外迪确认接受大众点评和另一家国内企业的数亿元投资，金额将在近期公布。

支付宝钱包在 2014 年 5 月推出「支付宝 Wi-Fi 平台」，商户可以加入这个平台为用户提供免费 Wi-Fi 服务，同时商户能够吸引用户关注「支付宝服务窗」，在后续向消费者推送营销内容，并有望与支付宝的支付服务进行协同交易。

而 WiFi 万能钥匙据披露则拥有 5 亿用户，最高日激活用户数达 200 万，拥有 7 亿个 Wi-Fi 热点。这款从盛大创新院时期脱身的 App 目前已经分拆成为独立公司，由陈大年领纲担任 CEO，声称三年不上市。

归根结底，Wi-Fi 热点之争实际是 O2O 场景之争，Wi-Fi 是传统线下商户营销、交易、互动全面线上化的最有效管道，谁拿到了 Wi-Fi 管道的控制权，谁就拿到了 O2O 格局的入场券。

从更进一步的角度讲，如果一家公司每天拥有 2 亿用户的 Wi-Fi 流量，本身就具有极大的想象空间。

商用 Wi-Fi 的发展可分为四个阶段：

  • Wi-Fi 布网：只是帮助商户拥有 Wi-Fi 的能力

  • 广告分成：用户连入 Wi-Fi 网络后弹出广告，依靠广告来获取分成。已经被验证收益太低，太分散且不平衡，难以形成一个较大的市场。

  • O2O 场景：让用户可以方便地进行连接，并且可以使用服务商提供的一些工具来让交易更简单便捷，可以基础地进行一些会员的营销和管理，成为 O2O 的连接点。

  • 数据时代：获得了用户的数据，如何去支撑商户的营销与销售，甚至把 Wi-Fi 本身变成一种全新的营销管道。

目前各家正处于第三个「O2O 场景」，各家都在试图让自己的服务更快速地抵达商户，以占据 O2O 的关键连接点，进而带动自家的支付、营销等服务的镇长。

而在未来，数据则是决定 O2O Wi-Fi 的关键要素。它将决定互联网公司、服务商、商家、消费者，将如何最大限度挖掘 Wi-Fi 这条 O2O 通道的价值。
