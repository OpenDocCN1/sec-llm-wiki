[核心提示] 从微软宣布纳德拉接替鲍尔默成为新任 CEO，到现在短短十个月时间，微软的股价涨幅接近 40%，纳德拉到底为微软施了什么样的魔法，让这个软件业的传统巨头迎来了新的春天？

在上周五，微软的股价超过了美孚，成为了仅次于苹果公司，市值第二高的上市公司。虽然目前不如上个世纪市值超过 6000 亿美元的巅峰时期，但是微软目前的股价已经达到了近十几年来的新高，从微软宣布纳德拉接替鲍尔默成为新任 CEO，到现在短短十个月时间，微软的股价涨幅接近 40%，纳德拉到底为微软施了什么样的魔法，让这个软件业的传统巨头迎来了新的春天？

破壁

在过去，微软用 Windows 构建了一个足够庞大的帝国，大部分的个人用户以及很多企业办公电脑都使用了微软的 Windows 系统。微软也依靠出售 Windows 系统以及旗下的办公软件 Office 获得了大量利润。

然而，事物总是在发生变化的。一方面，Linux 凭借着便于移植和开源的特点几乎成为了服务器系统上的不二之选。另一方面，移动互联网在短短几年内快速发展，iOS 与 Android 则是这个市场中的主流，而微软 Windows Phone 的市场表现却一直不温不火。与此同时，PC 的增长出现了滞缓甚至是倒退。也就是说微软被卡在了瓶颈，一方面难以快速占领服务器市场以及移动市场，另一方面自己有优势的 PC 市场渐现饱和。对了，微软试图打通移动端与传统 PC 端的新系统 Windows 8，用户还并不买账。

在鲍尔默时代，微软的战略是「设备与服务」。在设备方面，既包含 Xbox 这样的硬件设备，同样也包含被微软收购的诺基亚。微软收购诺基亚，更多意义在于通过诺基亚这个传统手机巨头的影响力，不断推出 Windows Phone 手机然后可以获得更多更稳定的系统份额。自有设备的意义正是在于保护自家的操作系统在市场中的地位甚至是其他自家服务的地位，这更像是一个防御措施而不是一次向其他领域的扩张。

然而，诺基亚已不再是占据了最大市场份额的那家手机公司，用户也变的与以往不同——换机频率更高，如果对手机硬件或者系统不满意，那么他们的下一款手机很可能会切换品牌甚至切换系统。收购诺基亚并没有为微软的 Windows Phone 份额带来任何提升。

假如你的家中有一座高墙，恐怕很难有勇气大破这座高墙，来直面更多的不可知。然而，如果不打破这座高墙，也就无法看到墙外面的世界，同时也很难有更多的发展机会。

纳德拉上任后做的最重要的一件事就是打破了微软之前构建的壁垒，也就是让微软变的更加开放，甚至去拥抱自己过去的对手。在 Microsoft Build 大会上，纳德拉甚至表示「微软喜欢 Linux」。

Office 推出了 iPad 版和适用于手机的版本，还将继续推出适合平板运行的 Android 版。

.NET 框架一方面宣布开源，另一方面表示会与 Linux 以及 Mac OS X 进行适配，也就是说未来可以在其他系统中使用 .NET 进行开发了。而新版的 Visual Studio 更是可以支持 Andoird 与 iOS 相关软件的开发。

对于 IE 这个浏览器，微软推出了基于自家云服务 Azure 的 Remote IE，开发者可以不需要再安装 Windows 就能在其他系统上测试所开发的网页是否完美适配 IE 了。

过去的 Office、.NET 甚至 IE 都是十分封闭的，离开了 Windows 或者 Windows Phone 平台，这些服务要么完全无法使用，要么体验不佳。纳德拉上台后，这些服务都成为了新的节点，而不再需要围绕 Windows 运行。在过去属于 Windows 附属的应用在未来都有可能获得新的商机，因为使用的场景将变的更广，而不单单是面对 PC 时的单一场景，也不是 Windows Phone 这个份额相对小的小众平台。甚至连 Windows 这一微软最核心的业务也存在着更多产生变化的可能性。

从软件商到服务型互联网公司

纳德拉提出的「移动优先、云优先」战略与之前鲍尔默的战略看似有很大不同，但是实际却是对于过去战略的一次全新诠释。无论是移动优先还是云优先，都意味着微软将会从过去软件商变成一个更互联网化，更注重服务的公司。

而服务，也是鲍尔默的战略中所强调的。只不过现在微软开始加速了向服务优先转变的进程。

微软在 iOS 以及 Android 平台推出的 Office 不仅不是像过去一样一次性卖软件授权，转用订阅的形式销售，还向免费用户开放了浏览文件以及基本的编辑功能。

Office 还接入了 Dropbox，让用户可以在云端有了更多的选择，文件不必须存在微软的 Onedrive 下。而且用户现在既可以方便的使用 Dropbox 的协同工作功能，又能在 Dropbox 里直接对 Office 文件进行编辑。

微软从「卖授权」转向了「卖服务」，也意味着微软旗下的软件会更加注重用户体验而不再是过去功能的不断强化。用着不爽，用户在下个月就可能不会继续选择订阅服务。同时用户也有了只为自己需要的功能花钱的可能，不会因为为了用一个小功能而不得不为整个套件付费。另一方面，服务也需要更大的用户量作为基础，所以微软也会开放更多过去需要付费的功能给免费用户，然后再针对企业用户以及部分高端用户提供更多支持与高级功能。

纳德拉的上台推进了微软的开发以及向服务化转型的进度，微软这个传统巨头在短短几个月时间内完成了转身。正如资本市场所呈现的结果，全新的微软将会迎来新的春天。
