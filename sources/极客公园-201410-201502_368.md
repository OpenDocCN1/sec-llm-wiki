## 前言

Blocks 是由英国的一家可穿戴设备初创公司提出的一款和Google 的模块化手机 Project Ara 概念类似的模块化手表，你可以根据自己的需求，选择相应的模块来定制它，可以说是一款完全 Freedom of Choice 的手表。

## 概览

Blocks 模块化手表目前拥有 3 块模块化屏幕，分别是矩形屏幕、圆形屏幕和 E-ink 屏幕，并且每块屏幕都包括了处理器、蓝牙和电池。此外，Blocks 还有将近 20 块其他功能的模块，与主模块共同组成完整的 Blocks 模块化手表。

## 功能 & 特点

Blocks 的声音模块可以让你用语音控制它，包括回复邮件或呼叫联系人；指纹模块可以让你的隐私更安全，无论是解锁你的手机还是打开你的电脑，它都能做到；可自定义功能的可编程按钮模块就像手表上的「快按钮」，可以一键拍照或播放音乐等等；当然，额外电池模块、储存模块、照相模块、SIM 卡模块、心率监测模块、手势模块、GPS 模块等等样样俱全，功能就不一一介绍了。

Blocks 模块化手表最大的特点就是功能高度定制化，所以不管你喜欢 Moto360 的圆表还是 Apple Watch 的方表亦或是 GEAK Watch Ⅱ 的E-ink屏幕，Blocks 都能满足你。

![](../Images/e0ba2a86ac89aea37387c352b34cb986.png)

Blocks 将会支持 iOS 和Android 设备，同时还开放了开发平台，任何人都可以为它开发程序，甚至可以为它开发模块。

## 点评

Blocks 抓住了目前智能可穿戴设备功能或者样式单一的缺点，利用模块化设计理念使之变得多样化，在智能可穿戴领域红海中吸引了足够多的眼球。不管是 Google 的 Project Ara 还是 Blocks 或许会是未来智能设备发展的趋势，但是在通往现实的路上可能还需要一步一个脚印的来。
