## 诺基亚 CEO：未来将专注服务业务 不再制造手机

来自 网易科技：

诺基亚 CEO 拉吉夫·苏瑞（Rajeev Suri）近日在伦敦的分析师会议上详细阐述了公司旗下网络设备、Here 地图以及技术等业务部门未来几年的发展重点。同时苏瑞还表示诺基亚未来将不会重返手机业务。

**点评**：没有了手机，诺基亚的品牌价值将支撑起这些兴起的服务。

## Uber 将整合 Spotify：打的自动播放乘客歌单

来自 腾讯科技：

据媒体披露美国时间本周一， Spotify 和 Uber 将联手向 Uber 乘客提供音乐服务。据猜测，Uber 给每一个司机都提供了免费的手机，用于提供载客信息，Uber 将会在相关的软件中捆绑音乐流媒体服务，司机可以将音乐输出到车载系统中播放，另外在行车过程中，可以进行暂停、进入下一首等操作。

**点评**：当易到用车都开始推美甲服务了，如果 Uber 在国内照办这套模式是不是有些小清新？  

## 只向学生开放的应用 Yik Yak 获 7500 万美元融资

来自 网易科技:

Yik Yak 是一款让你可以看到附近人们在讨论什么的应用。其另一大特点是匿名性。

Yik Yak 成立于 2013 年，在 2014 年美国大学春季学期开始的时候，迅速在校园流行起来。Yik Yak 在美国 App Store 免费社交应用的榜单里已经排到了前十，超过了 LINE，WeChat，LinkedIn。　

**点评**：匿名功能让社交产品更刺激，当人数逐渐增多，不良信息被举报，社区又失去了活力，这大概就是匿名产品的悖论。

## Netflix 关闭公开 API 停止支持多款第三方应

来自 新浪科技:

Netflix 周五关闭了公开 API，不再支持多款利用这一 API 开发的第三方应用。这些第三方应用此前可以帮助用户获得来自 Netflix 的电视剧、电影和其他数据。

**点评**：从 2012 年以来 Netflix 不断上涨的股票证明了 Netflix 的把握。

## 手艺学习网站 Craftsy 再获 5000 万美元融资

来自 腾讯科技：

手艺学习网站 Craftsy 近日在第四轮融资中获得了超过 500 万美元资金，其获得的风险资本总计达到近 1000 万美元。

Craftsy 本质上是一种巨大的开放式网络课程（MOOC），一种电子学习方式，这种方式通过像 Lynda 这样的网络先驱和可汗学院（Khan Academy）这样的后来者而变得流行。

**点评**：国内教育网站过得不怎么开心，估计还是受应试教育的牵绊，更何况是这种不会让考试加分的网站。
