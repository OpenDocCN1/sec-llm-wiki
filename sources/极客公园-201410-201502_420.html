[核心提示] 微软向那些不使用 Windows 的开发人员伸出了橄榄枝，背后的推力则来自自家的云服务 Windows Azure。

微软刚刚发布了一款名为 RemoteIE 的应用，它允许开发人员无需安装 Windows 在 Mac 或 Android 上可直接运行 Windows10 预览版中最新版 IE 浏览器。

微软向那些不使用 Windows 的开发人员提供了橄榄枝，但 IE 市场份额的下降让此举缺少兴奋度。

根据今年 6 月份 Adobe Digital Index 发布的一份报告，算上桌面和移动浏览器市场 Chrome 在美国共获得 31.8% 的市场份额，而 IE 只有 30.9%。

通过在操作系统中捆绑 IE，并重金投入研发，互联网诞生时红极一时的网景第二代浏览器 Navigator 被打败，微软因此独霸浏览器市场。IE 取代的网景浏览器的历史将会重演么？

IE 已不是微软的重心

为何 IE 已经不是最受欢迎的浏览器，我们从吴军写的《浪潮之巅》中看到了一个有趣的视角：

打败网景公司后，接下来在微软内部展开了一场大的争论，公司今后的发展到底是应该以视窗为中心进入企业级市场，还是以浏览器 IE 为中心进入互联网市场。

这场争论最终以视窗派获胜而告终，理由是如果世界经济遇到危机，或者互联网是一堆泡沫，那么以视窗为核心的战略可以确保微软平稳地度过危机，而以浏览器和互联网为核心的策略可能让微软遭受灭顶之灾。

因此 IE 下降成 Windows 下的一个应用软件。从此，IE 对微软的重要性从战略层面下降到战术层面。但是在互联网泡沫中生存下来的雅虎和进化出来的谷歌则彻底剥夺了微软在互联网领域的机会。

此外，移动市场的缺失让微软桌面端的优势难以直接转换到新潮流中，市场调研机构 Netmarketshare 发布的 2014 年 10 月手机操作系统的数据报显示，Windows Phone 市场份额仅为 2.38%。

微软将赌注压到云上

相比通过 IE 获取互联网早期入口，微软将新的赌注压到云上。

RemoteIE 基于 Azure RemoteApp，其实质是在设备上用微软 Azure 虚拟机的远程桌面/远程应用中的 IE 浏览器。

在 Windows Azure 介绍页面上将其作为主打特性列在介绍页面：

Azure RemoteApp 帮助员工保持高效率，无论他们身在何处、使用何种设备 - Windows、Mac OS X、iOS 或 Android。

Windows Azure 被认为是 Windows NT 之后的 16 年来微软最重要的产品，微软计划将 80% 的资源和研发力量投入到云计算项目中。

微软在 2008 年 10 月洛杉矶的专业开发者会议上，正式推出自己的云计算 Windows Azure——这一产品涵盖了私有云、公共云，并囊括 IaaS、PaaS 和 SaaS 多重领域。

今年 10 月 20 日，微软在美国旧金山召开「未来的微软云」新闻发布会，CEO 萨特亚·纳德拉介绍财富 500 强企业中，已有 80% 公司使用 Azure 云服务平台，其营收运转率（revenue run rate）接近 44 亿美元。

此时世界上最大的云软件公司之一 Salesforce.com 去年收入超过 40 亿美元，亚马逊提供的 Amazon Web Services，估计年收入也可达到 40 亿美元。
