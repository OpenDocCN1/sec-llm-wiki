> \[核心提示\] IT 业男女比例的不协调已是不争的事实，而今，一向被忽视的女程序员们慢慢开始被关注。

Ellen Ullman 是一位美国女作家，出过书，也写过专栏。她的大多数文章和小说都分析计算机编程领域人性化的一面。在之前，她的身份是一名软件工程师。在纽约时报的专栏中，她曾写过自己作为程序员中罕见的女性所遭遇的尴尬。

“我是一名普通的程序员，编写着在复杂的人机交互和操作系统的核心运行的代码，我为我的工作制定时间表，并在截止时期之前完成它们。这些都没有让我能够在工作中突出。相反，人们关注的焦点在于我是一个女程序员，他们潜在的疑问是，一个女生怎么能写代码。”

Ellen Ullman 做了很多事情去克服这种偏见，然后她发现，唯一能够拯救她的就是对工作的热爱。

Ellen Ullman 不是个案，IT业中不平衡的男女比例是不争的事实。2010 年，软件工程学家 Justin James 曾撰写过一篇论文：IT 界的性格失衡：女程序员们都去哪里啦。文中，作者发现，在女性的职业选择中，科技作者，数据管理者所占的比重都比程序员要大。

女性并不是不喜欢计算机领域。而是因为 IT 界的刻板印象，文化差异，以及女生从小所接受的教育环境都导致大多数女性没有涉足软件开发。

Justin James 认为，趋势的扭转需要从教育与培训，文化的改变做起。

如今，已经开始有一些组织在筹备这样的工作。

**1.Rails Girls **

Rails Girls 是一个非营利组织，创立于芬兰，熟悉编程的人应该知道，Rails 是基于计算机语言 Ruby 的网页开发框架，2010 年的 11 月，Rails Girls 的第一次活动在赫尔辛基举办，致力于在一两天内帮助女孩们学会和体验用 Rails 开发简单的网页。

四年的时间内，Railsgirls 的活动已经遍及上海，新加坡，柏林等多个国家和城市，全球有 Ruby 社区的地方都会举办 Railsgirls 的活动。

Rails Girls 在 2012 年第一次登陆中国，先后在北京、西安、上海、深圳、广州和成都等地区举办活动。其中在北京已经举办了五次。

![](../Images/e5a2f2245a5febafc9accb758406c715.png)

Railsgirls 北京地区负责人文洋告诉极客公园，活动最初萌生于北京的 Ruby 社区，社区会有自己的线下技术分享活动，2012 年年底，当得知国际上有一个 Railsgirls 的组织在举办类似的活动，就加入进来。

Railsgirls 的组织者来自于 Ruby 社区的程序员，大家利用自己工作的空余时间来举办这个活动。

一位曾在 Railsgirls 北京线下活动担任教练的同事说，Railsgirls 的活动通常有 20 多个教练，面向 60、70 个学员，基本上是一对二的教学。

一位参与过 Railsgirls 活动的女孩就在后期发展成为活动的教练。

Railsgirls 希望学员把学习的内容传播给更多的人，在报名人员的筛选上，组织人员更乐于挑选乐于分享，喜欢传播的女孩儿。

**2.Made With Code**

Made With Code 是谷歌在今年 6 月 启动五千万年美元投资的项目，旨在让还在校的妹子们，更早的接触到代码、学习代码。

Google 发起并联合了多家组织包括 MIT 和 TechCrunch，它们将为女学生们提供一个优良的代码学习环境。

女孩儿们将看到代码是如何在我们没有意识到领域被使用，从智能手机上的 app 到视频游戏，音乐，这样，它们就可以用代码创造一些有趣的，有价值的和有创造力的在线作品。

一个初学者的项目包括设计一个手环，然后创建使用 3D 打印机，并邮寄到新的编码器，它可以让那些没有经验的学习者以更加直观方式体会。

![](../Images/98d18d53ca4785123070e4c88286ea62.png)Made With Code 网站也已经上线，整个网站色调轻松活跃，其中的内容主要是启发妹子们，开始动手写代码。

网站上还有一些线上社区，用户可以分享她们的观点，家长和孩子可以从中获得编程的建议，谷歌还鼓励举行聚会，让女孩儿们聚集在一起。

一家来自华盛顿的非盈利组织就获得了 Made with Code 的赞助，将召集当地 100 个女孩儿，为她们展示编程可以做的事情。

**3.Girl Develop it**

Girl Develop it 也是一家国际非盈利组织，Girl Develop It 网站联合创始人萨拉·吉普斯认为，编程不仅是件很有趣的事情，它还可以增加女性的吸引力，吉普斯说：“我早上穿着连衣裙上班，到公司后就坐下来进行编程，我感到很满足。”她希望有更多的女士加入这一行业。

Girl Develop it 主要为 18 岁以上的成年女性提供简单实用的软件开发教程和服务支持。

![](../Images/f1a326f9ceb23e0f44fbb256a01c5889.png)

尽管仍然处在发展的早期，该组织已经获得了资金上的支持。教授的时间分为四个小时和八个小时不同的区间，内容涵盖各个层面，包括对 web 概念的介绍，移动设计和开源 web 开发框架。

每三个月，她们会在咖啡厅至少举行一次聚会，还会为学院提供 web 相关项目的支持。

未来，Girl Develop it 还希望为学员颁发奖学金。

在技术领域女员工占比 17% 的数据背后，所掩盖的是：第一个程序员就是女性，第一台电子计算机 ENIAC 的编译和部署也得益于 6 名女程序员。女性在电脑编程上的地位似乎一直被忽略了，是时候让她们认识到自己的潜能了。
