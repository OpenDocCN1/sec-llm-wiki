# 后「西游」时代，手游 IP 如何保持长效竞争

> \[核心提示\] 在如今「无 IP，不游戏」的国内手游市场，大量基于 IP 的手游大作却并未达到应有的市场预期。而凭借着「西游系」IP 建立起游戏帝国的网易下一步会怎么走？

## 「西游系」的 IP 红利还能持续多久?  

![](../Images/8a1bcd5f3911dc0e63db1ffa6de0319f.png)

在端游时代，网易的成功离不开对「西游系」IP 的开发。自 2001 年成立在线游戏事业部以来，网易凭借着《大话西游》和《梦幻西游》这两个系列的产品积累了大量的忠实用户。据官方数据显示，在《大话西游 2》的同时在线人数在突破十年最高的 126 万的同时，《梦幻西游》的最高同时在线人数一度达到了 271 万。

![](../Images/0e999646f1b4cfd4ce5183733086c1b0.png)

在手游时代，网易依旧延续了在端游上的「西游系」IP。虽然网易第一款真正意义上的自研手游《迷你西游》的表现并不尽如人意，但随着去年 11 月《乱斗西游》 的上线，网易开启了在手游领域的全面进攻号角。凭借着优秀的游戏设计与体验，《乱斗西游》不但斩获了「App Store 中国区 2014 年度精选游戏」的荣誉，还一直位列 iOS 畅销榜前十的位置。随后，网易又将其在端游上的经典西游 IP 《梦幻西游》延续到了移动端。据官方数据显示，《梦幻西游》的同时在线人数最高达 170 万，与端游同款一道成为了同时在线人数最高的国内游戏。

![](../Images/257b9158a53de955a8e7d3eb86048a63.png)

除了在研发上的大力投入，网易在中国游戏业内地位的奠定离不开对「西游系」 IP 的开发。与西方魔幻题材的神话与游戏类似，「西游」的故事承载的是东方民族对传统侠义伦理的探索和追求。从传统的小说、电视、电影到如今的游戏，带有民族特性的侠义精神带入感是这一类题材作品成功的共性。一个健康且有持续生命力的游戏公司应该有自己独霸市场的领先自研产品，这一点网易做到了；但要想在红海一片的游戏市场永葆青春，单靠一个系列的 IP 产品必然会带来玩家的审美疲劳以及资本市场对商业模式的拷问。网易的解决方案是用经典的传统武侠 IP 来延续「西游系」 IP 所承载的侠义精神。根据 5 月 20 日网易游戏十五周年发布会上透露的消息，网易目前已拿下古龙系的全套 IP ，再加上原有的「天下」等系列 IP，网易正在探索后「西游」IP 时代的侠义 IP 新路径。

## 多样化 IP 政策的价值放大效应

作为天然的导量渠道，IP 所代表的不仅仅是单纯地对原作进行传承，更是极高游戏体验、设计细节和关卡逻辑的集中体现。相较于近两年市场上「IP 热」所衍生出的同质化游戏泛滥的现象，网易没有一味地跟风去进行大批量的 IP 采购，而是围绕多年积攒起来的 IP 风格进行精选投资和多样化价值延展。

![](../Images/fa43e8317d1d2cf27ab3220673f94ba7.png)

一方面，在进行经典 IP 回炉重造的同时，网易通过影视、动漫等一系列优质 IP 的授权开始进军受众更广的中、轻度休闲游戏领域。通过对《大富翁》、《猫和老鼠》、《小时代》和《功夫熊猫》等人气 IP 的代理发行与引进，网易希望通过由重度游戏向轻度游戏的转型来弥补此前在 IP 风格上的单一性。

另一方面，用户会变得越来越精明，也越来越挑剔。大小游戏厂商们针对游戏的高投入也使得用户对游戏的知识和体验要求飞速增长。可以看到的是，游戏相关的创业型团队的实力在不断提高，但市面上的好产品却在逐渐减少，这是整体用户需求增长速度与行业厂商成长速度间的矛盾。为了解决这一矛盾，网易的思路是「走出去，引进来」。在国外优质游戏苦于国内渠道与文化差异难以进军中国市场的同时，网易积极地与国外优秀厂商展开了授权和 IP 代理合作。也正是因为如此，中国的玩家们才能在国内市场上体验本土化的暴雪系游戏。

![](../Images/ce63a29f76a264c945784a3849426760.png)

与此同时，随着近两年电竞的火爆，网易对 IP 的价值的线上开发也延伸到了线下。在以 MMORPG 和 ARPG 为核心打造了系列经典 IP 后，网易针对旗下游戏产品进行了电竞化探索，其中最为典型的要数手游《乱斗西游》了。根据网易官方给出的数据监测显示，目前《乱斗西游》平均每天会进行 8000 万场对战，而在近期刚结束的 IET 《乱斗西游》电竞比赛项目中，约有 109 万人进行了在线观看。此外，国内知名电竞俱乐部 VG 近日也宣布了成立国内第一支电竞手游职业战队的消息，而这支战队的主攻对象正是《乱斗西游》。

## 腾讯游戏唯一的挑战者？

![](../Images/45aa416792f67ec126666d78585aa822.png)

上一个将腾讯游戏拉下神坛的是现象级手游《刀塔传奇》，而这次的挑战者网易却不仅仅是想在小规模战役中战胜对手几次那么简单。当外界以为 2014 年 App Store 畅销榜又会被腾讯垄断时，网易《乱斗西游》的出现结结实实地打了这些人的脸。如今，延续端游传奇的《梦幻西游》手游甫一上线便登上了畅销榜冠军的宝座病长时间保持。

![](../Images/1d1beb22c7b1b0d91575380311431752.png)

对于这两家国内游戏界的巨头公司而言，网易凭借着其在端游时代建立的雄厚根基在重度精品手游的研发有着稳固的优势；如今，依托 IP 构筑的多样化布局，网易通过自研、代理并重，产品布局多样化的思路补全了此前不擅长或未涉猎的空白领域。而在腾讯一方，依托自身巨大流量的优势，同样遵循「自研＋代理」思路的腾讯游戏更加注重中、轻度游戏的纵深发展，其细分布局和游戏数量也领先网易一个身位。从短期来看，网易和腾讯在国内游戏市场上各自占据了一方细分市场且具有绝对优势，要想渗透进另一方的领域势必会牺牲部分己方主导市场的份额，这无疑会给对手和其他厂商提供瓜分用户和收入的机会；所以，短期内双方真刀真枪的兵戎相见不大可能发生，更多的可能是依托自身产品线进行 IP 精品化研发与采购，以更加完整的游戏生态去迎击相对「跛脚」的另一方。

如今，在中小游戏 CP 混战的国内市场，两大巨头的战略方向选择也成了很多厂商关注的重点。是站队随流把握趋势红利还是避其锋芒选择差异化竞争成为了行业关注的热点话题。借用丁磊的话说：“手游不是为了利益盲目跟风，游戏公司不应该怕慢，让品质走在前面，把利益摆在后面，这样才能获得长线成功。”
