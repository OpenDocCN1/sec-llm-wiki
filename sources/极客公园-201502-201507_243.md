## 前言  

最近北京的天气可真是阴晴不定。早上还是晴空万里，到了晚上就可能就下起了瓢泼大雨。于是，极客公园一位曾经在气象局工作过的同事成了这两天「最可爱的人」。

「眼观六路，耳听八方」的他可以准确地告诉我们什么时候天晴，什么时候下雨。但如果你身边缺少这样一位砖家，就只能依靠「不靠谱」的天气预报了。

现在的手机都拥有强大处理能力，为什么不能通过增加外置的传感器让它成为我们随身携带的小型「气象站」呢？

![](../Images/b0f1dce4f4e732c10d4b5f0d9b442ae5.png)

今天难极客之选向大家介绍的 Weather Point 就是这样一款产品。

## 概览

Weather Point 外观很像风靡一时的 XX 按钮，同样是插在耳机插孔使用，只不过体积更大一些。我们先通过下面的视频了解一下 Weather Point 有什么特点：

## 功能&特点

Weather Point 内置温度、湿度、光电和气压四个传感器，能够监测产品周围的温湿度，紫外线光照及大气压强的天气状况，实现对天气四要素的实时监测——并结合传感器数据实现对天气情况的预测。

![](../Images/367382c50a411272c7f4d99b6db65b1d.png)

相比起成百上千里外的气象站，随时随地使用的 Weather Point 可以说是真正的「当地天气」。

更为重要的是，Weather Point 在使用时不需要联网，完全基于本地获取的数据进行气象分析，与天气预报相比在时效性上更胜一筹。

![](../Images/af33a28d11789a73057f7d845bcde0fb.png)

Weather Point 可以挂在钥匙环上，使用的时候就不会再手忙脚乱地去寻找了。将它插到耳机里，手机端 App 便能显示出温湿度等数据和天气预测。

![](../Images/3fb3ce05755452e11e44d12ea6a39722.png)

Weather Point 还将开放 SDK 给其他软件使用，可以辅助一些天气软件提高天气象预报的准确度。当然，它也可以帮助一些健康计步类软件获取更加精确的信息。

![](../Images/9bee983fe23c36c7ff7f99a730ca158e.png)

## 点评

与其他插在耳机孔的扩展设备相比，Weather Point 拥有丰富的传感器，让我们的手机可以拥有更加有趣的功能。

![](../Images/2b41b44df3e79a3912e5b6aa4ea56f91.png)

而 Weather Point 除了可以帮助各位极客「亮骚」，更加实用的地方在于它可以帮助户外爱好者不依赖网络环境获取更具时效性的天气状况。
