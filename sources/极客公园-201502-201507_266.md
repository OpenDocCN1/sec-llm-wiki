> \[核心提示\] 互联网的魅力不仅是推动传统行业按部就班的技术升级，而是用跳跃思维带来通向未来的更优路径。

美国西海岸洛杉矶的霍桑设计中心(Hawthorne Design Studio)，这也是曾经诞生 Model S 的地方。

多年以后，这里也许会像因苹果而知名的旧金山的芳草地艺术中心一样家喻户晓，尽管短短二十分钟的发布会上，特斯拉的 CEO 伊隆·马斯克依旧时而结巴地进行产品演讲，但在 theverge 的编辑 T.C. Sottek 看来这却是继乔布斯在 2007 年首次发布 iPhone 以来最让自己震撼的发布会。

五月一日这一天，特斯拉能源（Tesla Energy）解决方案正式发布，它将为家庭、商业和公共事业提供一整套电池方案，以逐步培养一个清洁能源的生态系统，帮助世界逐渐脱离化石燃料。从此，在科技公司，汽车公司之外，特斯拉有了另一个新身份——一家清洁能源公司。

在这个新产品层出不穷的时代，我们经常会为一款优秀的产品鼓掌，而若有一款产品能让我们放声尖叫，让我们感到想象力被放飞，智商被碾压，直觉会告诉我们：这是一个能够改变我们未来的东西。

## 让人疯狂的特斯拉能量墙

特斯拉推出了超级充电站来消除用户的历程焦虑，而能量墙就像是没有被阉割的合约机一样让人疯狂。

![](../Images/3af4e4ce71e6593c5bcc19e538a9e72a.png)（能量墙解决家庭多方面用电问题）

具体来说它提供了以下功能：

*   转移负荷，节省经济开支——它可以在电力需求低谷的时候低价充电，在电价更高的需求高峰时段输出电能
    
*   增强太阳能源自给能力——电池能够存储过剩的太阳能发电，以便在没有太阳的时候使用
    
*   电力备份——在断电的时候提供电力保障
    

能量墙包含特斯拉锂电池包、液态热量控制系统，和一套接受太阳能逆变器派分指令的软件。这一整套设备将被无缝安装在墙壁上，并能和当地电网集成，以处理过剩的电力，让消费者灵活使用自己的能源储备。

此外特斯拉能源公共事业应用让特斯拉站在了道德和商业的制高点上：提供多样的公共事业量级的可再生的电网服务。

这场发布会带来的余波让我会想到了上周刚结束的上海国际车展，软件出生的博泰和从战争时代诞生出的吉普在同一时代的不同纬度上绽放着自己的想象力。

## 用户体验和驾驭感的较劲

互联网公司谈的是解决用户痛点和提升用户体验，软件公司出生的博泰展出的 Project N 概念车更像是一部大号的手机。

Project N 没有车钥匙，通过虹膜监测识别车主，特斯拉 Model S 17 寸的触摸屏幕令人惊艳，而 Project N 提供了 48 寸的屏幕，几乎消灭了实体按键，方向盘、仪表盘都可以折叠下去，在这个第二私人空间里你可以看电影、睡觉。

![](../Images/559900fa3febf98636aa6da27bceab6b.png)（Project N，博泰集团创始人及董事长应宜伦和博泰集团执行董事兼整车 CEO 沈晖）

在现场发布会上有两个细节让我印象深刻，掀被式的设计除了带来超跑般拉风的造型，博泰集团执行董事兼整车 CEO 沈晖提及另一设计初衷是希望腿脚不变的母亲方便上车，车轮饰板被替换成了一块屏幕，用户可以像替换手机屏保一样更换画面。

据博泰集团创始人及董事长应宜伦介绍这台概念车的 70% 技术已经实现，预计在 2018 年上市。

虽然整车依旧是和传统汽车厂商合作生产，但软件公司造车的理念让我们看到更多的情感因素。

Jeep 移动智能全路况概念体验系统则是传统汽车厂商互联网试水的代表。Jeep 给这套系统这样的定位：「Jeep 未来的设计理念仍将以驾驶体验为核心，兼具优雅与现代气质之余，令驾驶者专注于驾驶本身。」

![](../Images/11a0522887a253a39bbbc3110097d2d0.png)（移动智能全路况概念体验系统）

这套颇像飞机驾驶舱的操控空间由驾驶员、中控台、副驾驶三块 12.3 寸横向排列显示屏组成，并覆以透明保护罩增强保护与提升视觉清晰度。

选取纯天然 Cognac 真皮和 Walnut 实木，搭配哑光面铝材与顶级陶瓷，作为这套概念系统的材料。

在这辆行驶在森林中的概念车里，除了感受到引擎带来的推背感，驾驭者还定能不自觉地享受着驾座上散发出的真皮味。
