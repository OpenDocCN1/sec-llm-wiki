# 可监测血糖的谷歌隐形眼镜或两年内上市  

来自 搜狐科技：

谷歌的隐形眼镜目前已经达到医用标准，并已送入美国食品药物管理局（FDA）进行审批。该眼镜可以用来帮助用户实时监测血糖。至于隐形眼镜的充电问题，谷歌称眼镜中某种物质和眼泪中血糖发生反应时产生的电流足以保证隐形眼镜的日常用电量。

**点评**：谷歌隐形眼镜将成为糖尿病患者的福音，再也不用滴血监测了。

## Windows 10 整合 Autodesk Spark 并大力推广 3D 打印功能

来自 cnBeta：

Autodesk 的 3D 打印解决方案—Autodesk Spark 将被整合至 Windows 10 当中，这意味着 Windows 开发人员可免费获得 Spark 的 API 来帮助他们进行 3D 打印技术和微软平台的融合工作。

**点评**：有了微软为 3D 打印背书，3D 打印机的价格应该会直线下降吧。

## 美国无人机监管将放宽

来自 新浪科技：

FAA 无人机监管办公室负责人 Jim Williams 在无人机 Data X 大会上表示，将对无人机飞行的使用规定进行调整。这次调整放宽了无人机飞行的要求，未来将允许无人机飞出视线外。

**点评**：随着传感器技术地不断改变，无人机一定会变得更加安全，飞行的范围也会变得更大。

## 12.9 英寸 iPad 延期 9 月量产

来自 腾讯科技:

相比苹果目前的平板电脑——7.9 英寸的 iPad mini 和 9.7 英寸的 iPad Air——新的 iPad 将配备一个 12.9 英寸的大屏幕。此外，新的 iPad 也许还将配置苹果合作伙伴 IBM 的触控笔或企业应用程序。

## IBM 预言 5 年内智能电脑将具备人类味觉等 5 种感觉

来自 cnBeta:

电脑等机器将越来越像人一样去感受这个世界。比如说具有认知能力的电脑在观看一幅画的时候，并不仅仅将其当作一组描述颜色的数据点、色素和线条，相反，它会将画作为整体来看，并能够理解画作所表达的含义。

**点评**：想要知道眼前的这道菜是不是好吃，想买的这件衣服材质是否优质，目前的大部分电子设备是不能够完成的，未来这种情况就有可能发生改变了。
