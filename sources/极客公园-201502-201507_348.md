步子大了会怎么样来着？  

最近关于乐视超级手机的话题在网上被炒的火热，不但各路明星、大 V「齐上阵」进行造势，乐视 CEO 贾跃亭更是放出了众多挑战苹果「封闭系统」的言论。  

相信大家对于这种营销方式已经司空见惯了，我们就不做过多评价了。但不得不承认，为了宣传新品乐视也是蛮拼的。

今天下午，乐视正式在北京五棵松体育场发布了超级手机，我们一起来看看它究竟为何如此高调吧。

## EUI——手机 UI 的新形态

在超级手机正式亮相前，贾跃亭首先向大家介绍了很多关于超级手机所使用 EUI 的亮点。

![](../Images/fb4952a6abaf53de602a7c3ed9016b16.png)

EUI 采用了「多类桌面」的设计，乐见桌面试图打破应用与 UI 边界，将内容在桌面聚合起来；LIVE 桌面在横屏下操作，支持 3 路直播流同时播放，采用乐视独家的解决方案；应用桌面让手机 UI 系统从原有无需分类排列向以围绕内容而设计。

内容方面，乐视网、乐视音乐和乐视体育将为超级手机提供丰富的演唱会、体育直播、MV 等视频资源。而 Le Cloud 及 Le Store 将帮助 EUI 更好地实现跨平台（手机、电视、汽车）使用。

乐视将 EUI 定义为「横跨终端的交互中枢」，并试图通过其在内容上的优势打造一个乐视生态圈，这种愿景是很美好的，但 EUI 到底好不好用还是由用户说了算。  

## 三款手机和一个 VR 设备

这次发布会乐视一共发布了三款手机：乐 1、乐 1 Pro 和乐 Max。

![](../Images/aab3231614c326de376a5f985291112b.png)

乐 1 特别的地方在于采用联发科最新的 Helio X10 芯片（MT6795），采用 2.0 GHz Cortex-A53 核心，是联发科目前最强的手机芯片。乐 1 售价 1499 元。

乐 1 拥有 1.2mm 超窄边框，不过由于外观之前已经曝光的差不多了，并没有发布会上所说的「窒息感」。需要注意的是，乐视所提到的「无边框 ID」 ，指的当然是手机熄屏的时候。

![](../Images/0991161e96e06a6bd477e7b3d1bcaba7.png)

乐 1 Pro 的配置与最近发布的一些手机并无太大区别：骁龙 810 处理器、4GB 内存 、2K 屏幕、双 4G 、Hi-Fi 芯片等等。值得一提的是，乐 1 Pro 采用了 USB Type C 接口，售价 2499 元。

![](../Images/814118f30a1e09378b09e08d5ead708b.png)

乐 Max 是个大家伙，配备了夏普定制的 6.33 英寸 2K 屏，2100 万像素 OIS 后置摄像头及索尼最新的 IMX230 CMOS 传感器，支持指纹识别。乐 Max 售价暂未公布，贾跃亭说会由全民定价，但具体形式还不清楚。

![](../Images/415fcde7827802fc72f36bd1020d584a.png)

![](../Images/78c633b0f82d1b0421f923d1ef46ef09.png)

对了，这次发布会还介绍了一款 VR 设备超级头盔，不过还需要一个月才能面世。（这样真的好吗......）  

![](../Images/85a5d028afd472f7178ac6fe23036276.png)

这次发布会还公布了一个有意思的购买方式：每购买一年 490元的乐视全屏影视会员服务，硬件价格将直降 300 元，也就是说一次性购买 5 年会员手机相当于免费得——这完全是拿自己平台的内容来吸引用户。

## 一场用力过猛的发布会

发布会一开始，乐视就拿苹果著名的广告《1984》来进行「颠覆」，而「苹果」、「生态」和「超级」可以说是这次发布会最频繁出现的三个字眼，乐视高调地在五棵松体育场推出了自己的三款手机。  

作为新晋的手机厂商，乐视在用户需求把握、产业链控制和渠道选择上还会面临很多挑战。大家的胃口已经被吊起来了，期待它接下来的表现，同时也希望乐视不要用力过猛「闪了自己的腰」。
