## 微软确认将结束 Internet Explorer 品牌的使命

*来自 cnBeta*

微软现在已经证实它正在为斯巴达浏览器起名，这个正式名称将取代 Internet Explorer 品牌。微软的首席营销官克里斯•卡波塞拉透露，该公司目前正致力于一个新的名称和品牌，用于命名预装在 Windows 10 当中的浏览器，Internet Explorer 将依然存在于某些版本的 Windows 10 当中，主要是为企业提供兼容性，但新的斯巴达浏览器将有正式名称，并会做为 Windows 10 用户访问网页的主要方式。

微软认为只要通将微软的名字加在浏览器新品牌前面，就能吸引英国很大一部分 Chrome 浏览器用户转投微软这款新浏览器。微软显然正在为浏览器新名称进行市场调研的名字，但目前还不清楚微软最终决定采用什么名称进行命名，但是微软已经打算在这个名字前面加上「微软」两字。

**点评：**换了内核改了名，微软能把浏览器的份额抢回来吗？

## 索尼第三财季净利润同比涨 241% 全年仍将亏损

*来自 新浪科技*

索尼发布了截至去年 12 月 31 日的 2014 财年第三季度财报，净利润同比增长了 2 倍多，但全年仍将继续亏损。索尼表示，净利润增长主要得益于智能手机、PS 游戏机和成像传感器业务的强劲表现。但同时，公司整体业绩被其他业务的营收下滑所拖累。

第三财季，索尼销售额为 2.567 万亿日元 (约合 212.13 亿美元)，与上年同期的 2.411 万亿日元相比增长 6.5%。运营利润为 1821 亿日元 (约合 15.05 亿美元)，与上年同期的 889 亿日元相比增长 104.9%。

**点评：**你觉得索尼会再度崛起吗？

## Win 10 增加生物学验证功能 脸部、虹膜可登陆

*来自 新浪科技*

微软将为定于今年晚些时候推出的 Windows 10 操作系统增加一种自动计量生物学登录功能，这将是该公司首次提供这样一种跨设备服务。这种功能名为「Windows Hello」，意味着用户将可扫描自己的脸部、虹膜或指纹来验证身份，从而登录 Windows 手机、笔记本和 PC。

这种功能是微软为使其产品变得能在更大程度上与用户进行自然互动而采取的最新措施，此前该公司已为 Xbox 游戏机配备了 Kinect 动作传感器，并为 Windows 手机推出了 Cortana 个人助理服务。

**点评：** 微软正在提供跨平台的体验，这也正是微软的主要策略之一。

## Uber 宣布开放 API 允许第三方应用集成 Uber 服务

*来自 网易科技*

Uber 周二更新旗下打车平台 API，提供一项名为「Request endpoints」的新功能。该功能将允许第三方集成 Uber 体验至自家应用中。

Uber 首次为打车平台发布 API 是在去年 8 月，但该版本仅能让开发者将乘客的「目的地」等信息发送至 Uber 官方应用。因此开放第三方接入是 Uber 作出的一项重大改进。

**点评：**开放 API 意味着 Uber 更大的野心，未来成为一个全新的平台也说不定。

## 谷歌 Play 商店将采用新的评级系统

*来自 cnBeta*

谷歌 Play 商店将采用新的评级系统，在此评级系统下，谷歌 Play 商店当中的应用程序和游戏，不再采用一个全球标准来评级，而是将基于它们针对的地区和年龄组进行评级，将反映出不同地区用户的喜好。新的评级系统生效之后，开发者在提交应用程序和游戏之前，谷歌将发放一份问卷给开发者，让他们自己指定产品的等级，提交之后，除了谷歌自己进行评级之外，还邀请了来自世界各地的不同评级机构进行监督。

除了新的评级标准，谷歌表示，他们将提供更深入的拒绝说明，向开发者说明他们提交的应用程序或者游戏为什么被拒，因此开发人员可以轻松地修复并重新提交他们的应用程序和游戏。

**点评：**要是苹果也能提供更深入的拒绝说明该多好。
