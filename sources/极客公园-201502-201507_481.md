# 苹果和谷歌员工餐厅的秘密

> \[核心提示\] 硅谷的员工餐厅，不管是苹果的又贵又难吃，还是谷歌的高大上却免费，都是公司的核心业务使然。

如今中国人去硅谷，到谷歌吃一次员工餐似乎已经成为标配。为了照顾来自世界各地的员工，这里有各种风味的美食，还有宽敞的空间和不错的装饰；更重要的是，里面的食物都是免费的，只要你由谷歌员工带进去，就可以吃个饱。所以很多来硅谷旅游的中国人都会托朋友认识谷歌员工，我听说里面的许多中国籍员工已经不胜其扰。

而奇怪的是，在硅谷和谷歌齐名的苹果却是另一番情景。我只去那里吃过一次，发现里面的餐厅小而拥挤，而且所有食物都不是免费的。总而言之在那里吃饭一点都不是享受，大部分人都是匆匆吃完离开，因为你的周围站着都是找位的人，他们眼巴巴的望着你，等着你吃完走人然后占领你留下的桌子。

作为世界上市值最高的科技公司，高大上的苹果为什么会在员工餐上如此苛刻？我曾经很长时间不得其解，而我问过一些苹果员工他们也说不出一个所以然。直到有一次我遇到《财富》杂志的资深编辑 Adam Lashinsky, 他研究和报道苹果公司已经十几年。我们聊到这个话题，他哈哈大笑起来，然后告诉我，这其实是公司文化使然。

**在苹果，保密是深入员工骨髓的信条**。员工培训的第一天，就被告知要严格保守工作秘密，除非你的老板或工作搭档，不应该跟任何人聊起你的工作；即便是苹果同事，不该说更不该问。这种文化于是延伸到公司的餐厅文化里。餐厅是交流的场所，而一群员工坐在一起吃饭，肯定会不可避免聊到自己的工作，这是苹果想极力避免的；**所以苹果刻意制造不好的餐厅环境，避免员工间碰面聊起工作。**

而在谷歌，却是一种开放的文化。谷歌鼓励员工之间互相讨论工作，既可以互相学习，也可以互相激发灵感。员工还可以自由组织讨论会和内部聚会。如果某个员工听说另一个组的项目更有意思，可以申请加入另一个组。（这里插一句，我听说不久前中国某著名天使投资人跑到谷歌园区召集一批中国工程师开会，主题只有一个——给中国的创业公司挖技术合伙人。令人惊讶的是，谷歌明知此事却并没有阻止。）

那么为什么苹果奉行如此保密的公司文化，而谷歌却是自由开放的？

我记得 Adam 是这样给我解释的。**苹果基本是一家靠卖硬件为生的公司**，它的产品周期往往长达一年，比如 iPhone 5s 出来之后要等一年才能等到 iPhone 6。如果新一代产品的外形功能事先泄露出去，消费者会提前很多获得新产品的预期，这样他们会倾向于购买下一年的新产品而不是当下产品。苹果将会由于消化不了库存，带来灾难性的后果。

谷歌却不一样。这是一家互联网公司，它的产品大部分是软件，而软件的产品迭代周期很短，随时都可以发布新的版本和补丁去代替旧的产品。所以在谷歌，保密不是一个必选项。**与此同时，谷歌是一家注重创新的公司，员工之间的脑力激荡无疑更容易激发新的创意，所以谷歌故意建造豪华的员工餐厅来吸引员工逗留更长时间。**

总而言之，如果把两家公司比作国家的话，**苹果更像是封闭的东方式的精英治国**，苹果的核心团队负责创意和设计，其他人负责执行（比如 Jony Ive 的设计团队只有十几个人，但却是苹果最重要的部门）；**而谷歌却更像是西方式的民主开放国家**，所有人可以参与到国家建设中来。

如今在硅谷，传统的朝九晚五的 8 小时工作制已经坍塌，不久前 Elon Musk 还公开表示，那些想朝九晚五生活方式的人不要来自己的公司。正是如此，公司的场所和员工之间发生了越来越多的交集。Facebook 以注重效率著称，创始人小扎提倡的是 Move fast, break things 式的黑客文化。为了让员工节约更多时间在工作上，Facebook 在园区里给员工配置了一应俱全的设施，从健身房到洗衣房，还有应有尽有的会议室。

Sam Lessin 是 Facebook 的前 VP，他前不久从 Facebook 辞职，去妻子 Jessica Lessin 创立的科技媒体 Information 当了一个实习生（是的，实习生，你没看错），而工作地点也从硅谷搬到了旧金山城里。有一次我在 Jessica 的办公室见到了 Sam, 我问起他换工作后有什么感受，他抱怨说，以前在 Facebook，从吃饭到健身都是几分钟的走路时间，对于他这样的宅男是完美的生活方式；而如今他却要花很长时间去健身房和餐馆。更令他抓狂的是，以前约人见面，在 Facebook 随便找一间小会议室就可以搞定，而如今却要去散布在旧金山城里的咖啡馆见人，每次都会增加至少 20% 的时间成本。

**所以一家公司从餐厅到会议室，一切的一切，都是公司的核心文化和价值使然——比如苹果讲究保密，谷歌注重开放，Facebook 关心效率。**所以对于中国公司来说，一味模仿是没有意义的，重要的是找到和自己公司业务价值能够契合与匹配的场所文化。
