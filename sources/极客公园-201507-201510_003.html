前言

智能化的浪潮已经开始影响到传统的家庭安防领域，我们已经可以在市场买到很多的智能摄像头，以小蚁为代表，这些产品往往价格便宜，配合智能手机，可以实现远程监控等功能。不过这些智能摄像头更像是给传统的电脑摄像头加了几个功能，对比专业家庭监控系统还是有很大差距。

有没有这样一个监控摄像头，它拥有媲美专业家庭监控系统的功能，同时又更加易用呢？一家来自美国旧金山的创业团队就设计了这样一款这样的监控摄像头——Angee。

概览

Angee 的宣传语是「第一个真正的自动家庭安全系统」，我们先通过一段视频来看一下这个特别的监控摄像头。

功能特点

独特的监控触发机制

很多传统的家庭监控设备要求用户在出门时必须手动设置密码才能打开监控，这样的结果就是虽然很多人已经装上了监控设备，不过不少人出门时根本就没有打开监控。

之所以出现这种情况，是因为监控设备无法判断用户是否出门，而 Angee 则巧妙地利用了一个用户随身携带的设备——手机。

Angee 可以和用户的手机通过蓝牙配对，当用户出门时，手机蓝牙和 Angee 断开连接，Angee 会自动开启监控模式。当用户回家后，Angee 检测到用户手机的蓝牙，Angee 会自动解除监控模式。此外，Angee 还拥有一个备用的语音识别模式，如果用户的手机没电了，可以通过语音识别来解除监控模式。

可旋转摄像头 + 门窗传感器

摄像头是监控设备的核心部件了，而为了实现更灵活、更大范围的监控，Angee 配备了一颗可以 360 度旋转的摄像头。

除了可以旋转，这颗摄像头还会自动识别并记录家庭成员的特征。如果有人进入房间，Angee 会根据之前记录的数据来判断是你的亲戚朋友来了还是有人入室盗窃。如果是入e室盗窃，Angee 会通过智能手机的 App 远程通知主人并实时传输视频，同时由于 Angee 的摄像头可以 360 度旋转，一旦有小偷进入，基本不可能逃过 Angee 的法眼。


为了进一步扩展 Angee 的监控范围，该团队还为 Angee 开发了一种安装在门窗上的 security tags 传感器，security tags 传感器可以将收集到的数据实时传输到 Angee 中。通过配对多个 security tags 传感器，用户可以大幅度扩大 Angee 的监控范围。

不止于安全

除了用作监控摄像头之外，Angee 还加入了类似于亚马逊 Echo 的语音控制功能（Angee 的外形和亚马逊 Echo 也有几分相似）。用户可以通过 Angee 设置日历、查询天气或者拨打电话，甚至还可以把 Angee 作为摄像机来录制视频。不过Angee 能实现的功能远没有亚马逊 Echo 丰富，而且 Angee 一时半会也不会支持中文。

点评

家庭监控系统需要解决的问题实际上非常简单——当你不在家时，监测家里发生的事情。不过想要解决这个看起来很简单的问题，却需要进行非常复杂的思考和设计。

传统监控设备解决了这个问题，不过在易用性上往往有所欠缺，Angee 试图在保证功能性的前提下，大幅降低用户的使用门槛。和现在国内风风火火的智能摄像头相比，Angee 在功能上要更加强大，360 度可旋转摄像头，Security Tags 和语音识别等功能都是前者所不具备的。

在众多的家庭监控设备中，Angee 是一款设计独特同时潜力巨大的产品，Angee 为未来的家庭监控描绘了一个美好的愿景，剩下的问题就是 Angee 公司能否尽快将这款特别的监控摄像头推向市场。
