怀旧讨论：你为何 Root 你的第一部手机？

这是一篇怀旧向的文章，里面充斥着大量的老旧名词，请确认你能理解第一代「搞机人」的「心酸历史」。


第一代的「搞机人」从荒芜的土地上播种出「root」、「刷机」等等一系列的玩法，现在的很多国产的 Android 机即使不 Root，不刷机，也远比以前的机器好用。但当时有太多人就是冲着 Android 手机的可玩性高入了 HTC 的大坑。那么昔日的极客们当时拿到第一部 Android 是为什么会想着去 Root 呢？

编者注：本文用户体验部分编译自 Xda-Developer。

更「正常」

当 HTC Desire HD 刚刚上市之时，我就入手了它。一开始这部手机用起来特别不错，然而不久之后在声音上面出了一点儿问题。大家都知道，手机耳机插入的时候，状态栏都会显示一个耳机已插入的图标。而我的手机在没有插入的时候，也会显示。在这种状态下，我既收不到消息提醒，打电话也不能听见声音。这致使我开始寻找解决方案——解锁，Root，刷入第三方固件……我的刷机（大坑）生涯也就开始了。

编者的第二部 Android 设备也是 Desire HD，编者表示，除了上面那位极客的问题之外，这部设备还有其他种种问题……比如，当你打电话的时候，距离感应器会关闭屏幕，然后它就永远不会「复活」过来了，你只能拔电池。有时候刷机能够将这些小毛病解决掉（因为这是官方固件的问题），有时候你只能放弃掉这台设备了。

更炫酷

我的第一部智能手机是三星的 Galaxy S，恰好我的哥哥和我在同一天买了同样的手机。几天后，他故意在我面前展示他「新手机」——UI 和我的手机完全不同，过渡动画很炫酷，短信界面也超赞。我完全地被震惊了，于是我开始四处找寻比我哥更炫酷的界面。

最后我找到了 XDA 论坛（搞机的极客们应该都知道这个论坛）上面有各种各样的定制化 ROM，但是无一例外地都标明了「需要 ROOT」和「第三方 RECOVERY」这可难倒了我。我开始从零学起，里面的各种名词让我摸不着头脑，而期间我的手机「变砖」了 3 次。不过最后看见我哥惊讶的神情，我感觉这一切都是值得的…

他问我：「你对你的手机做了什么？」我告诉了他，我这几周是怎么折腾过来的，然后我反问到：「你这几周不也是这么过来的吗？」他回答：「并没有啊，我只是从 Playstore 里下载了 GoSMS 而已啊。」

搞机的极客们都经历过这样的事情，我们花了几个月的时间，调试完美某个特性，而「他们」仅需要从主题商店里下载一个程序就好了……

更清爽

圣诞节的时候，我购入了一台 Kindle Fire HD，当时我正享受着我的「越狱」后 iPod touch 4。我正想着，要不要「解放掉」我的新玩具，但阅读过论坛里关于刷机失败的后果之后，我又不想把事情变得更糟。在打算放弃之际，我还是没有忍住，将机器 ROOT 了。

我像是打开了新世界的大门——锁屏界面 Amazon 的广告没了，没有强制的系统升级了，可以安装 Playstore 了，并且可以做到很多我的 iOS 设备做不到的事情。后来，我装上了 Xposed 框架，尝试了各种各样的可定制化 ROM，比如 Chameleon OS CM 11……

Kindle Fire 用户会 ROOT 他们的设备很好理解，毕竟在平板电脑上显示广告实在是让人忍不了。当然，CM 能提供近乎于原生系统的体验要比一些像 Amazon 一样的第三方厂商强上不少。所以 Amazon Firephone 开售一个月仅卖出 26,400 台也一点让人不吃惊。（数据来自 Com Score）

更简洁

几年前，我入手了 HTC Explorer，它居然只有 150 MB 可用空间，这让我惊呆了！我只安装几个 App，系统就开始提醒我内置空间不足。于是我也踏上了 ROOT 之路。而且，今后我购买 Android 手机的时候，一定会上论坛检查下，这款手机是否为论坛鼎力支持着，如果不是，那我情愿不买这部手机。

很难想象，居然还会有手机在购买之初就只剩下 150MB 可用空间，但在 2011 年（HTC Explorer 手机上市那年）这样的情况很常见。那时手机几乎都可用拓展内存，而且都被运营商给「绑架」了。所以到现在会有手机厂商主打「无运营商捆绑」牌。

时过境迁的今天，人类已经忘却了 Android 机器曾经多么地「难用」，早就失去了想要 ROOT 的理由。曾经年轻的极客们，一部分已经失去了对待 Android 的耐心，转投 iOS 阵营了；还有一部分还在追求他们的本心——ROOT 再搞机。那么，到底 ROOT 是为了什么？为了 Xposed 框架带来的炫酷插件？为了 ROOT 完全掌控自己的手机？还是其他？屏幕前的极客们，你为什么要 ROOT 你的手机？

这些就是来自 XDA 论坛上，第一代「搞机人」的成长历史，也许诸位极客中，还有比这些人资历更老的玩家。这会儿分享你的「搞机」故事也不迟。来吧，大叔们，还等什么呢？
