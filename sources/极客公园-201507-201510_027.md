# 交通部对专车表态了！可能影响你叫车的5个问题

> 关于争议许久的出租车和专车市场，交通部终于有了表态。

![](../Images/e4494f584c0d3785a114fb5d41e37472.png)  
今天下午，交通部发布了深化出租汽车行业改革指导意见（以下简称《指导意见》）和网络预约出租汽车管理办法（以下简称《管理办法》），并在未来一个月的时间中，向社会公开征求意见。

《指导意见》和《管理办法》可能会对专车市场带来什么影响呢，我们总结了5个要点。  

### **▌****1.「专车」的新名字叫啥？**

预约出租车或者网络约租车

《指导意见》中，将出租汽车分为巡游出租汽车和预约出租汽车，巡游出租车会有专门的标识。

### **▌****2.它和一般的出租车有什么不同？**

一般的出租车可以即招即停，也可以提前预约，专车只能预约，不可以即招即停。（其实我们之前打专车都是用平台叫到的）。

如果专车在路上载客，专车和专车平台都会被罚款。专车司机受到 500 元以上 2000 元以下罚款，平台则面临 1 万以上，3 万以下的罚款。

### **▌****3.成为「专车」有哪些条件？**

限制条件多了：

> *   车辆为 7 座以下乘用车
>     
> *   车辆性质也变了，要登记为出租客运，取得出租汽车类别的《道路运输证》。
>     
> *   驾驶人若想成为网约驾驶员，应取得相应准驾车型机动车驾驶证并具有3年以上驾驶经历，符合相关安全驾驶条件。  
>     
> *   车辆须安装卫星定位装置、应急报警装置。
>     

看来，普通私家车要成为运营车还要在交委备案，满足以上条件才可以成为专车。

### **▌****4.以后打「专车」的价格是多少？**

两个影响因素：政府指导或市场调节

平台要合理确定网络预约出租汽车运价，并实行明码标价。

针对各个平台的补贴和打折优惠问题，《办法》指出三点：

> *   不得以低于成本价格进行不正当竞争
>     
> *   不得有为了排挤竞争对手或者独占市场的价格倾销运营，扰乱正常市场秩序  
>     
> *   如果运营企业要实行市场奖励、促销等行为，需提前10天将奖励、促销等方案向社会公告。
>     

以后，补贴大战会越来越少了，而且，提前一个多星期，我们就会知道专车的补贴力度和价格。

### **▌****5 .滴滴、Uber 这些平台会做什么？**

平台会承担一定的管理和监督责任：

> *   保证接入车辆合法合规
>     
> *   提供24小时不间断运营服务  
>     
> *   明确服务项目  
>     
> *   公布服务质量承诺  
>     
> *   建立服务评价体系和乘客投诉处理制度，如实采集与记录驾驶员服务信息  
>     
> *   在提供网络预约出租汽车服务时，提供驾驶员姓名、照片、手机号码和服务评价结果，以及车辆牌照等信息。  
>     
> *   使用符合规定的出租汽车计价器，向乘客出具相应的出租汽车发票。
>     

由于对平台的规范越来越具体，专车的样子也会越来越相似，下次，打专车你也可以向司机要发票了。

*附文：各家专车平台的表态*

*   **优步中国：**
    

作为行业的主要参与者，优步中国会认真领会管理办法的精神，并积极参与整个办法制定过程。一旦管理办法在征求意见之后正式颁布实施，我们会以此为标尺，主动适应行业发展的新常态，并全力配合新规的落实落地工作。

事实上，优步中国独立运营实体的建立、服务器的完全境内运营、有关互联网资质的取得和报备，作为本土化进程重要的部分，都已经完成。我们已经和各地方政府在积极沟通交流中，会在地方实施细则颁布后，第一时间申请网络约租车所需要的资质和证照。

优步中国还表示，目前公布的只是征求意见稿，还不是最终的管理办法。而且，最终还要看各地的执行细则。「我们在各地都注册有分公司，目前已经有15家。优步历来是去中心化运营的，以城市为中心。」

*   **神州租车：**
    

我们将认真研究《办法》的规定，并向主管部门反馈相关意见和建议。同时，我们将按照《办法》的有关要求，尽快主动与各地管理部门做好对接。

*   **嘀嗒拼车：**
    

嘀嗒拼车有两个基本的原则，正符合交通部鼓励的「不以盈利为目的的汽车共享出行方式」。

这两条基本原则是： 预设路线：嘀嗒拼车的车主和用户均为预先设置出行路线，以确保双方是顺路共享搭乘； 不以盈利为目：拼车费用的确认是以拼车过程产生的费用进行分摊为原则。
