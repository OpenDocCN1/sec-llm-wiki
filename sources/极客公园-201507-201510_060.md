# 想买辆北京全天候不限行的特斯拉SUV？先排一年队吧

几个小时之前，特斯拉 CEO Elon Musk 在弗里蒙特工厂正式向第一批车主交付了Model X。Model X 最初预计在 2013 年上市，但是由于在设计和制造过程中遇到了很多麻烦，特斯拉一再推迟 Model X 的上市时间，现在 Model X 的预定订单已经被排到了明年。  

![](../Images/f95a78bed69af2dcfc8784bb50dcbd2d.png)

和之前的 Model S 一样，Model X 的早期购买者会得到一辆签名版，用户可以自定义 Model X 的电池和性能配置，标准配置包括了双电机全轮驱动以及鹰翼车门。

## 放大版的 Model S

Model X 延续了 Model S 家族式的设计语言，并且两者之间的相似点还不止于此，Model X 的动力系统和去年发布的双电机四驱版 Model S 相同。正因为如此，Model X 是世界上最快的汽车之一。在更恶劣的气候条件下，比起后轮驱动版的 Model S，Model X 会有更好的表现。

![](../Images/7da339d3cc7be8b251ae96e8d0e09ca5.png)

Model X 采用了七座设计，虽然 Model S 的行李厢也能安装一个备选的第三排儿童座椅, 不过这只能算是一个折中方案。如果你的车要经常带上五六个人，Model X 会远比 S 更舒适。

## 依然难以置信的快，续航里程稍短

Model X 使用了源自 Model S 的双电动引擎，前电机 259 匹马力，后电机 503 匹马力，最高时速可达 155 英里/小时。Model X 的极速版从 0 到 60mph 的加速时间仅仅需要 3.2 秒，和售价超过 15 万美元的保时捷 911 Turbo 差不多。

![](../Images/173479d0bb86beac329b6948d4bc123c.png)

根据美国国家环境保护局 ( EPA ) 的能耗评定，Performance 版本的 Model X 比对应的 Model S 续航里程（253公里）要少 3 公里，非 Performance 版本则要少 13 公里。不过如果配备 90kWh 的电池，Model X 至少可以跑上 250 公里。

## 可能是世界上最安全的汽车

Model X 的电池组位于底盘正下方，低重心可以降低汽车侧翻的风险。所有 Model X 都标配自动紧急刹车和防侧撞系统，配备了前视摄像头、雷达、360 度声呐传感器，可以实现自动辅助驾驶功能。除此之外，Model X 还配有独有的空气过滤系统，车内空气的纯净度可以达到医疗级别，特斯拉号称 Model X 是全世界「最纯净车内空间」的SUV。

## 量产家庭用汽车中最炫酷的车门

![](../Images/cc6d3f6c8c2455c51e93f282a6e0cf31.png)

Model X 最大的卖点之一就是「鹰翼」式车门，「鹰翼」车门的打开幅度非常大，打开车门后，用户完全可以毫不费力的装进一个大箱子。同时，「鹰翼」能够向上开启，即便在非常狭窄的停车位也不会影响车门打开。这种炫酷的设计过去往往都只能停留在概念阶段，Tesla 能把这种炫酷的设计应用在量产的汽车中显得非常不可思议。

## 未来一段时间内特斯拉都不会发布比这更贵的车

Elon Musk 的下一个计划是 Model 3，对于特斯拉来说，Model 3 可能比 S 和 X 加一起还要重要。由于 S 和 X 价格都非常非常的昂贵，大多数消费者只会梦想着有一天能够买一辆，而 Model 3 则会是一款针对主流大众市场的产品，售价在三万五千美元左右，如果 Musk 能能够兑现自己的承诺，同时特斯拉的产能也没有问题的话，Model 3 的销量会远超 S 和 X。

## 充电桩是个大问题

特斯拉用户可以免费使用超级充电站，每个超级充电站都有多个充电桩，可以同时为多辆 Model S 和 Model X 充电。值得一提的是，充电桩的充电速度非常快，充电不到半小时就能获得 200 公里的续航里程。直到 2016 年底，基本美国的各大州都会拥有超级充电站。

![](../Images/604c33e6bca594958e724a05ce2cc670.png)

不过相比北美，特斯拉在亚洲的进展就没那么理想了，特别是在中国，充电桩的建设一直没有多少进展。

## S 来了，X 还会远吗

今天特斯拉还宣布正式进入「北京市新能源汽车摇号目录」。北京市民可通过摇号取得北京市新能源汽车购车资格，特斯拉车主可以在北京市全天候不限行驶。

![](../Images/dcc7169022fe9c4e438a5ee2a4373d61.png)

特斯拉共有 6 款车型进入北京新能源汽车摇号目录，分别是 Model S 70D、Model S P85D、Model S 85D、Model S P85、Model S 85 和 Model S 60。或许用不了多久，我们就可以在路上看到 Model X 了。
