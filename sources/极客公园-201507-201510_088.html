三星一直因为它万年不变的大塑料机身而饱受诟病，今年的 S6 一改往日塑料机身的设计，用上了金属的边框和双面玻璃的设计。到了 Note 5 这一代，设计语言更加成熟，虽然并没有用上像 Edge 一样的大曲面屏，但三星将曲面的设计挪到了背面。

虽说已经不是第一次有厂家在手机背壳弧线下功夫，但 Note 5 背面弧线设计的手感真的很赞。不信？看看外媒是怎样评价这股背面弧线的设计的吧！

从 Note 5 说开去

Note 5 是我上手握持最好的设备之一，特别是手机的握持感异常舒适。近几代产品中，有很多设备在握持手感上的设计很走心。举例来说，之前的 Moto G 就像是手中的一次革命，当我第一次入手 Moto G 的时候，我简直不敢相信，这样一部低端机居然能够和我的手掌如此地契合，并且单手操作毫不费力——它让我手中的 Note 3 自愧不如。

Note 5 选择将弧线挪到了背部，而不是采用曲面的屏幕。这是一项改善体验的决策，并且能让手机颇具艺术感，因为不像其他拥有背部弧线的手机，Note 5 的屏幕无论是表面还是边边角角都能保持扁平，这使得它从手机设计中脱颖而出。但是，今天我们谈论的主角并不是 Note 5。

如今，有很多手机在手感上都有卓越的体验，比如骨灰级粉丝热爱的 Moto X 系列的手机。那，是什么让手机拥有「好手感」呢？

当手感和设计之间能达到一个平衡，而不是为了博取噱头之时，它们才能完美地融合在一起。

促成「好手感」的因素很多，有些与材料相关，有些与实际的设计相关。然而，在「贴合手掌」和「牢靠的握持感」之间仍然存在一定的区别。合手的设计能够帮助你很好地拿住手机，但是光滑的金属或者玻璃表面却会妨碍握持感。这就是为什么「设计」这个部分如此之重要了：一台手机的材质和设计对于手感来说，额外重要。

过去几年里，智能手机的表面上几乎用遍了各种材料，包括皮革，木材，金属，碳纤维和磨砂材质等等。不过，金属和玻璃被普遍认为是高档的材质，而且当大部分制造商试图赚取口碑的必选材料。

就个人来说，我要为 Moto 和其他给用户提供不止一种的可选背壳材料的厂家鼓掌。他们提供的可选背壳，比如不同种类的木材，真皮，添加了很多个性化，可定制的选项，其中不乏一些渐渐被其他厂商接受并借鉴的创意。即使可拆卸电池和内存卡卡槽的设计渐行渐远，我们现在还能见到很多设备，为了提升手机质感，冒险采用可拆卸的后盖，如 LG G4，一加 2，和 ZenFone2。这些手机都从这样的设计中受益良多。同时，为了得到好的握持感，它们也采用了背壳弧面的设计。但是不同手机采用的不同材质，使得它们之间的手感各异。

好手感，怎么造？

在我看来，没有简单的、万能的「好手感」手机的制作方法。这需要考虑到多重因素，而且我们也知道那些手感绝佳的手机在设计，材质，大小等等方面，风格各异。如果一定要做出一个总结的话，那么我想，一定包含以下几个因素：

  • 背部弧线

这不仅仅指的是背部弧线，还应该包括边缘。手感舒适手机的弧线并不是一成不变的。举例来说，Note 5 背面是扁平的，而背部的边缘则是弧形的； ZenFone 2 围绕着任何轴线都是弧形的； LG G4 有有一个宣称比任何手机都对称的弧面；而 Moto X 的弧线则是全平衡的。它们给予手的舒适感不尽相同，而且其中一些弧线还没有也没有得到完美地呈现。

  • 倒角

当手持设备时，采用倒角设计增大了大拇指可触及的区域，也减轻了手持设备时，边缘带来的割裂感，提高了屏幕的单手可触及区域，也让手机放在手机里更方便，更安全。

  • 纹理和材质

手机的纹理可以增加手机的握持感或者使手机更加光滑，但是这个因素与手机整体的几何学设计密切相关——如果不采用倒角设计，弧面边缘和收窄的宽度，Note 5 的玻璃材质将会成为最滑溜的手机。同样，手机边框的材料也会有助于或者区分用户体验，很多厂商都选择了金属倒角边框的设计，但是如果设计和完成得不好，那么体验就会特别糟糕，比如 Note 4。

  • 重量

找出一个完美平衡的点很困难。这就像世上其他的许多事情一样，任何极端都会带来不友好的用户体验。有人喜欢重一点的手机，上手会有安全感；也有人喜欢轻一点儿的手机，这样能够很容易的一手操控。还有另外一个次要的因素也会影响手感——手机重量的分布。所以这个因素的影响也是见仁见智。

当我上手过许多 2015 年的手机之后，我觉得很多手机厂商已经在「设计」和「材质」方面倾注了许多精力。然而去年的「薄度竞赛」让许多厂商拼了命去把手机的厚度减少一毫米。所以今年各大厂商也会削尖脑袋在手机「设计」和「材质」上取悦用户。今年的背部弧线的设计也会变得更加常见。

编者个人也是倾向于手机手感的提升，而不是毫无休止地追求手机更轻更薄。有些国产厂商高歌着「用户体验第一」在「追求极致」的道路上一去不复返，然而除了更轻更薄，还有更差的续航，更糟糕的手感，用户体验也不见得会有什么提升。

手机制造不是简单粗暴地堆砌硬件，还需要软件的调教优化，当然用户友好的设计也是必不可少的。所以对于已经成为手机标配的背部弧线「设计」，诸位极客看官们怎么想？它是否真是「优质手感」手机的象征？
