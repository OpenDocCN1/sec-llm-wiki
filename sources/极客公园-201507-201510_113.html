开源模块手机>>开源 + 模块 + 手机。正如名字一样，RePhone 想要赋予手机另外一种存在方式。


「开源」作为一种为产品提供开发最终源材料的理念，已经逐渐大众所接受。诸多产品通过开源促使用户来自己拓展用途，丰富社区，增加代码或者设计的流传度。目前越来越多面向开发者的硬件产品实现开源（例如 Arduino，Raspberry Pi 等）。

不过今天极客之选想要给大家介绍的并不是类似 Arduino 这种看起来无从下手的硬件开发设备，而是一套开源模块化手机——RePhone。

提到模块化手机，许多朋友们自然会想到 Google 的 Ara，用户可以按照功能选择自行选择对应模块加装至 Ara 上，而且模块化手机能够有目的地减少不必要消费成本，如果哪坏了，直接换对应的部件就好。不过由于 Ara 过于笨重的体积和接二连三的跳票，使得人们对其的期望值一减再减。

Rephone 与 Ara 相比，虽然没有 Google 的庞大后台支持，但基于 MTK 的 SDK（软件开发工具包）创造了一个全新的 RePhone 系统，同时，将于明年全面支持安卓系统。

概述

RePhone 是一套由深圳矽递科技有限公司（SeeedStudio，目前为全球前三大开源硬件制造商）开发的一套模块化手机组件。其外观和内部 UI 都可以由机主自行定制，也可以通过自行编程再进行拓展其他模块搭建一款只属于自己的个性化手机。

功能&特点

  • 重新思考手机的原有形态

RePhone 包含的 Xadow GSM 模块让用户能够轻松的把它固定或缝制在任何物体的表面赋予其通信属性。

通过将 RePhone 安装在不同物品上，或许能够给机主带来不一眼的思考。无论是学生、老师、艺术家、工程师、极客甚至初学者都可以通过 RePhone 来重新思考、组合、设计，进而去改变手机的固有形态，让手机更符合自己的个性化需求。

对于新手程序员，RePhone 提供了基于 Arduino、 Lua、JavaScript 等的丰富全部的技术指导文档和示例代码；资深程序开发者则能利用 RePhone 提供的 API（应用程序接口），深入彻底的玩转 RePhone；

  • 满足不同程度的开发者

RePhone 的设计理念是将其内部功能实现开源和模块化，其外观和内部 UI 都可以按照机主的想法自行定制。通过使用不同的材料，比如说：纸，皮，皮革，3D 打印甚至激光切割来完成手机的外观结构，亦可通过设置 IFTTT（「if this then that」，一种通过流程将各种信息串联）操作手机，开发 SDK，Lua 和 JavaScript 编程来增加 RePhone 的可玩性和自由度。

  • 支持和兼容其他开源硬件

不仅如此，RePhone 还拥有许多不同功能的扩展模块；作为一款与 Arduino 兼容的开源硬件产品，用户能够通过 Arduino IDE 对 RePhone 进行编译及上传程序，并且扩展其他功能。

除此之外，Rephone 也同样兼容 Pebble Time 智能手表。现有的Xadow手机模块都可以兼容Pebble，并以表带的形式呈现。增加 Pebble 的可玩性。RePhone 通过在第一期兼容Arduino与Pebble Time两个在开源社区极富影响力的平台，病承诺在后续的版本陆续推出拥有更强大兼容性的模块，逐步提高可玩性和便捷性。

点评

RePhone 正如名字一样想要赋予手机另外一种存在方式。可以自行选择定制外观和内部程序也十分地接地气并且适用不同水准但又追求不同的人们。

或许我们可以将 RePhone 应用到更加场景化的地点，设想一下，我们可以把它制成一款儿童手表，如果在必要时候可以让孩子自己呼救。我们也可以把它作为一块事故报警器，通过拓展外部设备增加烟雾监测，一旦超标可以自行拨打报警电话。

总之因为开源，所以一切皆有可能。

开放的态度和多样的搭配方式不同于一般系统开发板给人以「高门槛」、「专业级」的印象，更加有助于提高开发者们的开发兴趣，当然这或许会导致一些关于安全性的问题，毕竟手机已经涉及到通讯和身份验证，如果某位小白被误导烧录了不怀好意的危险代码，就会对信息安全造成隐患。
