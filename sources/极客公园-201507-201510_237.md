## ****▌******前言**

除了键盘，通常我们都会在美术工作者或设计师的电脑前看见一个绘画板，他们用它更快速准确的来进行绘图创作或者控制 PS 等做一些精细的图片处理。但你一定不会想到也许玩音乐的，甚至是程序猿也会需要这样一款触控输入装置，它能够帮你的输入变得更便捷，为你带来特殊的触控体验，你想试一下吗？

## ****▌******概览**

Sensel 是一款带有压力感应的多点触控输入设备，它不仅能够代替绘图板，还能够「变身」键盘、音乐控制器、电子琴等等任何你能想到的装置，也许你吹口气它都能感受到。我们一起先通过介绍视频看看这个输入「多面手」究竟如何吧：

## ****▌******功能特点**

Sensel 使用了新一代的多点触摸触控，一次能够检测 16 个接触点，并且拥有独有的专利压电网技术，与一些传统绘图板不同，它的压力感应不是在一只特殊的笔上，而是整个面板都能够感受到压力，类似于拥有 Force Touch 的面板，并且敏感度比它还更强。

  

![](../Images/c3646e0db220a16de46ef83035eb76d5.png)

  

作为一个输入设备，它能够让人们能够以一种全新的方式和计算机程序进行交互。由于压力感应敏感度高，Sensel 不仅可以检测你的手指，像笔刷，毛笔轻刷的压力都能感受到。

  

![](../Images/86c04e8fe01385770421a4aaff03e4ad.png)

  

Sensel 的尺寸类似于一个 iPad，这是有目的地做可以使变形和覆盖易于携带。装置下方的光滑的触控表面大约拥有 20,000 个传感器元件，每个间隔只有1.25 mm 。不像其他的触摸技术，只能感测导电物体，Sensel 传感器元件能检测到非导电物体，并且还能感测到具有高动态范围的压力。

![](../Images/a669f6f2ee01e961131a7d96f2d49f15.png)

更有意思的是，Sensel 的「变身」功能，配合一些覆盖薄膜，能够将 Sensel 变成蓝牙键盘、电子琴、电子鼓、带调色板的画板、音乐控制器甚至游戏控制器等等。并且它能够自动检测这些变化，并作出相应的触控支持。

  

![](../Images/0fc38e3a9123f76d7bfa917b6c9ccfa6.png)

  

当然，除了这些已经拥有的覆盖薄膜你也可以根据自己的实际用途，自己制作一个独一无二的控制方案。Sensel 团队自己开发了一个简单的基于 Web 的拖放界面，你无需做任何编码就能够设计自己的覆盖薄膜，并且能够利用 3D 打印自己的设计。如果你喜爱开发，也可以使用 Sensel API 来获取触摸数据在其他任何应用程序中使用。

  

![](../Images/460e9c0226f4df55016b5c89c467f6c1.png)

  

除了这些，Sensel 还拥有一个加速计，LED 和蓝牙模块，在它不大的体积内集成了这么多的功能还是很实用的。内置的电池据官方说中度使用能够使用一个星期左右，待机时间一个月。

![](../Images/dea31502a72c304c2569f4e45a378980.png)

## ****▌******点评**

作为一个简单的输入装置，Sensel 团队真正赋予了它一个画板的职责，能使用真正的毛笔，笔刷在上面绘画，完全和传统的绘画感受相同。

![](../Images/8d3f88bd089d38ea0a672c1746849580.png)

而且他们还开辟了更多的玩法，不仅仅适用于绘画设计工作者，就连工程师都能够的通过它很轻松的控制自己的机械，这种高精度触控感受说不定还能给我们带来更多的控制体验。
