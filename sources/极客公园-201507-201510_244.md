# 我们熟悉的蓝牙，未来还能怎么「玩」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=213615275&idx=3&sn=a74e6b8e12685563a3b4a9b70fb1f96a&chksm=ecceff1ddbb9760b30ad8bb80e9ce806f0b0f36c0194b413d08dd378802415003dd67ffee1a1&scene=126&sessionid=1681311736#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=213615275&idx=3&sn=a74e6b8e12685563a3b4a9b70fb1f96a&chksm=ecceff1ddbb9760b30ad8bb80e9ce806f0b0f36c0194b413d08dd378802415003dd67ffee1a1&scene=126&sessionid=1681311736#rd)

从功能机到现在人手一部的智能手机，让我们对蓝牙早已经不陌生了。根据研调机构 ABI 统计，2014 年蓝牙设备年度出货量为 30 亿部。

  

但事实上，蓝牙设备出货量历经 10 年的发展才达到 10 亿部的数字，IHS Technology 更预测这个数字将呈线性成长在 2018 年有望翻倍，增长到 44 亿部。获得井喷式式的增长后，蓝牙技术还有什么好玩的方向呢？

![](../Images/ea0ae3ab2f32d0b673d65fdf47a5cab5.png)***各种各样的蓝牙设备***

人们对移动设备越来越依赖，也有越来越多的活动在室内进行，而 GPS 这样的室外导航在室内中有些死角而且很容易受到建筑物的干扰，而且精准度和耗电量让它并不能够胜任简单快捷的室内定位。所以，就出现了基于蓝牙技术的 Beacon，它成为一种理想的室内定位的解决方案。

  

## ****▌******Beacon 能用来干什么？**

简单来说，Beacon 就是一个小型的信息基站，可以应用在室内导航、移动支付、店内导购、人流分析、物品跟踪等等所有与人在室内流动相关的活动之中。Beacon 技术做到的是通过 Bluetooth Smart （智能蓝牙）向通信覆盖范围内的移动设备捕捉和推送信息。

  

它的应用场景非常的广阔，通过 Beacon 可以进行室内定位并提供相应的服务，如在百货商场及时推送品牌促销信息、在机场为旅客定位登机口和餐饮设施的位置、或在博物馆向游客推送身旁的文物信息等。在这些应用场景中，Beacon 的位置是固定的，用户通过智能手机 app 可以获取这些位置信息。

![](../Images/7bf7bf64af9326b4ec659c828a4dc2eb.png)

Beacon 的首要任务就是允许 app 确认两者之间的相对位置，并借助这一位置信息实现更多功能。例如，而对于商场的 Beacon 应用，根据店铺 ID 规划 Beacon ID 会更合适，这样 app 就能够判断出用户是走进了左边的这家李宁，还是右边的那家耐克，然后就可以很轻松的推送固定的优惠措施了。  

  

Beacon 还可以通过信号强度就能够很轻松的推算用户的相对距离。比如距离为一米时，信号强度是多少多少，所以我们就可以通过接收器（例如手机）测量到的信号强度推算出相对应的距离。

  

针对走进商场或店铺的顾客、机场里走近值机柜台的旅客等。而对于其他一些应用，可能需要用户十分靠近特定的 Beacon 时，才会提示用户。比如占地较小、陈列物密集的博物馆或美术馆的导览系统，就需要在参观者十分靠近特定的展品时才会提示相应的展品信息。

  

关于 Beacon 的文章已经有很多了，但可能大家知道的更多的是关于 iBeacon 的。iBeacon 是苹果自己的低功耗蓝牙数据传输规范，是苹果公司的专利。iOS 设备对 iBeacon 提供原生支持，不过 Android 开发者也能使用这一协议为其他平台开发应用。

  

但是，还有一些其他的 Beacon 广告形式规格，例如 Radius Network 的 AltBeacon。AltBeacon 是开源的，可应用于任何平台而不受限制。它最近还刚刚发布了面向安卓系统的开源 API。

  

通过 Beacon 将产品和促销信息发送给顾客；博物馆和美术馆等也可以开发专门的应用，向走进展厅的参观者发送展厅主题介绍、或对在展品前驻足的参观者发送详细的展品信息等；机场还可以用 Beacon 追踪所有旅客的动向。

  

虽然 Beacon 的功耗很低，但现在研究人员们也正在考虑其他「能量获取」技术，例如从杂散 RF 信号吸收能量，目前看来最有希望的解决方案很可能是无线充电技术，届时能够让蓝牙设备将能吸收来自附近（通常在 5 米左右范围内）的能量。以后必需支持类似于 Wi-Fi 的模式，使咖啡馆、机场、酒店和办公室全都具有「充电热点」，以便我们能够随时为可穿戴设备充电。

  

## ****▌******对 IPv6 技术的支持**

而最近好像火热的已经不能引起大家兴趣的智能家居也在适应各种各样的连接方式。去年，蓝牙更新了 4.1 版本，开设了支持 IPv6 的接口，部分蓝牙技术联盟成员陆续推出自家开发的 Bluetooth Smart 网状网络解决方案，用户可以创建蓝牙设备的网状网络，实现像 ZigBee 一样的自组网。

  

智能手机好像已经成为目前大多数智能家居产品的控制中心。许多产品都在依靠手机或者网关进行连接控制，而我们可能还不太习惯让智能恒温器与健身手环直接连接，让电饭锅和手表直接相连，有了新一代的蓝牙技术，这些看似不可思议的关联随时可能变成现实，大家能够无限发挥自己的想象力。

  

为什么这么说呢？因为 IPv6 实现了物联网世界中的互操作性，它让开发者们能够创建更多解决方案，不仅局限于个人区域网络、而是拓展到更广泛的物联网当中。这样就不在需要网关的支持，能够更自由的连接。

![](../Images/6e5c3c241e77a8cbe5ed2e493717243d.png)***NORDIC演示自家支持 IPv6 的蓝牙技术***

但现在 IPv6 的技术都是各家蓝牙厂商自己开发的，互相之间还不能很好的兼容，而今年三月，蓝牙技术联盟宣布成立 Bluetooth Smart Mesh 工作组，这个工作组助力 Bluetooth Smart 技术实现标准化的 Mesh 网络（无线网格网络），以后就会统一这一标准，这也是为什么 Mesh 技术一直备受关注的原因。

  

## ****▌******蓝牙设备的未来**

除了 Beacon 的更加普及，和对 IPv6 技术的支持，低功耗蓝牙的应用场景将更加广泛，功能也越来越丰富。今后也许使用 NORDIC 芯片方案的智能咖啡机也能够和使用 NXP（飞利浦公司创立的半导体公司） 蓝牙芯片的小米体重秤，甚至再和 Dialog 蓝牙芯片的小米手环，三者之间不需要任何网关甚至手机的连接，相互之间通过蓝牙就能够很快捷的进行「交流」了。

  

相信未来蓝牙的技术还能够融入到更多的应用场景中，支持自组网、更精准的室内定位、更长的使用时间都让蓝牙有了更多的想象空间。设备间的自由通信也许能在未来让我们真正的感受到「智能」的所在。
