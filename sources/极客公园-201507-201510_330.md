# 玩艺术的要提升自我修养，用什么App显得像圈内人？

> **一款玩艺术的 App，一款「返回」艰难的 App，一款志趣高尚的 App。**

「仓廪实而知礼节」，对文化艺术的满足是我们满足衣食住行后更高层次的精神文化需求。如果你是个喜欢逛画廊、看个展的文艺青年，那不妨了解一下这款叫「艺术狗」的 App，你可以随时通过自己的手机浏览一些有品质的线下艺术展，并且和志同道合的爱好者进行线上交流。

「艺术狗」分为四个板块——最核心的「展览」在第一页，用户能看到近期结束的线下展览；第二部分是「热门」，罗列了一些对艺术作品的热门评论；之后是「发现」，通过「发现」用户能对部分艺术机构和艺术达人进行关注；最后一栏是用户中心。

![](../Images/508852f9aa5a73d4aa16f110b1d7e12f.png)

## UI 设计简洁有余，精细不足

「艺术狗」的 UI 设计风格明显，以黑白两色为主，无论是 Logo 还是应用内界面都非常简洁，并且在滑动浏览内容时，还会将本已经做得很窄的上下菜单栏进行隐藏，让内容占满整个屏幕（可能是为了尽可能地排除干扰，让用户能更专注地欣赏艺术作品）。

简洁是好事，乍看起来也很大气、精练，但如果深入到细节处仍贯彻这样简洁的风格就不免有些荆人涉澭的味道。「艺术狗」似乎把除了艺术展示图以外的任何东西都简化了，包括展览简洁、作者介绍、展馆等内容之间没有明显的分界或边框的概念（大多只以虚化的细线来划分）；不同部分的文字也只以加粗来进行区分，内容不多时尚可，但只要内容稍多就会出现纷繁错乱的感觉，不能轻易区分。

![](../Images/d31bbe41a475a033155c3b5d2fd535f2.png)  
架构简易直接，但「返回」操作实在闹心  

「艺术狗」的架构思路不算复杂，主要就是展览、作品、展览机构、用户几部分，互相之间的跳转切换很方便，思路清晰。只是还是一样，由于界面太多追求简洁导致很多跳转的链接处不是很显眼。

在这还要说的就是「艺术狗」一个最让人无奈同时也是使用体验很差的地方，那就是——没有「右滑返回」的操作设定啊。这对现在大多数已经习惯了滑动返回操作的用户来会带来一些不适。毕竟如今大屏手机横行，这种情况下还要求用户吃力地够到左上角去点返回按钮，这样的设计确实有些反人类了。更让人哭笑不得的是，在一些界面进行下滑浏览时左上角放置返回键的菜单还会隐藏起来，这对本已经不容易的返回操作来说无疑是雪上加霜。

## 内容品类丰富，画质稍显不足

就内容上来说「艺术狗」虽不能算包罗万象，但也基本把北京、上海等的主要城市涵盖在内，还包括了一些地方的小展，其内容包括画展、摄影、雕塑、装置、录像、行为艺术等等，种类比较齐全，用户基本能找到自己感兴趣的内容。

不过虽然展览数量有了保证，但其中一部分的质量却有些差强人意。摄影和雕塑等尚且可控，但一到画作展览就容易出现质量参差的情况。有些画作由于尺寸问题，放在一页画面里就不得不牺牲画质，这样的对用户的感观会有较大影响，但也是出于无奈之举吧。

![](../Images/9ae5c0f18c45586b05479c60a3cb1fa8.png)

## 初学者必备的艺术入门课

在专设的热门评论板块里，「艺术狗」会将一些作品和相关的热门评论贴出来，大家可以对评论进行点赞也可以和评论进行探讨。在这里用户能看到不少独特或精辟的见解，以及对作品的思考。如果你是刚入门的艺术爱好者，这里很适合你去学习怎么评价和欣赏一件艺术品，也可以 get 很多提升自己格调的论据和例句，像是「作者在这幅画里表现出了挣扎和迷茫，而风格上有着 19 世纪中叶几个印象派大家的影子……」。

但如果你是一个资深的艺术爱好者，那么可能在这你并不能轻易找到自己需要的。要用几句话来评价一件好的艺术品难免片面，大多是碎片式的话语和结论，能用寥寥数语对一件艺术品准确又全面的点评毕竟稀少。

所以在「艺术狗」里，用户可以对艺术初窥门道，但通过这样一款 App 让自己成为艺术达人还是有些难度。

![](../Images/8f7637207f83986d93c31e676871a6a4.png)

## 还算美味的艺术快餐

「艺术狗」通过移动互联网拉近了艺术和普通人的距离，很大程度上节省了人们欣赏艺术作品的时间成本，随时随地就能在手机里看到全国各地的大小艺术展。但同时，艺术又是一件很复杂很主观的事，App 中的图片只能展示作品的一个角度，丢失了很多细节，难以细细品味。如何能够通过 App 把用户引导到现实的艺术展上，是「艺术狗」未来可以探究的方向。

![](../Images/c346116e9cf652ac355663d2088e19e6.png)

***这样一款 App 可以是一份丰富可口的艺术快餐，如果你想要拥有生活格调和艺术品味，你可以先试着成为一条「艺术狗」，然后做好你的自我修养。***
