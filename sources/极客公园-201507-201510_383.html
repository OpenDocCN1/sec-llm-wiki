2015 年 8 月 5 日 Note5 的量产版谍照爆出。这张谍照毫无悬念地证实了大家的猜测，玻璃材质的前后面板加上全金属框架——你是否想起了上半年三星的另一款旗舰产品？没错，这简直就是一台带着笔，放大版的 S6 edge。

Note5 借鉴了 S6 系列的设计语言，一体化的机身，加上改良过的背面弧线，让这款平板手机同时兼具靓丽的外观和舒适的握持手感。第一眼看上去，与国产手机小米 Note 有几分相似，更有网友吐槽说，这俩货是互相借鉴，小米借鉴了 S6 edge 的曲面玻璃面板——只不过是背面呈弧形，而三星的 Note5 则是借鉴了小米的背面弧形面板。

一体化的大潮

在我们讨论 Note 系列转投一体化设计之前，首先我们要理解的问题是为什么一体化会迅速成为当下手机设计界的弄潮儿。一体成型机身最为明显的优势在于工艺上，其封闭的机身能够让空间得到极大的利用，完全一体成型的手机甚至只需留出 SIM 卡插槽，为手机做到更轻更薄争取到了更多的空间，亦或者把争取到的这点儿空间用于增加续航，如 LG G2 的异型电池：

（图为 LG G2 的异形电池）

然而，总会有部分消费者并不买一体化成型手机的账。

Note 系列产品的定位

初代 Note 严格地来说，是瞎猫撞上死耗子，开拓了一片新的细分市场，掀起了一股大屏潮。Note 系列的持久续航（换新电池满血复活的快感简直难以言喻）和自带的那只笔，都是为了提高工作效率。于是就有了后来的分屏操作和小窗模式，再到后来为了提高自家安卓手机安全性的软件 KNOX 等等。效率和安全性则是商务手机最为看中的两点。相对于自家 S 系列的产品，Note 系列的商务气息要浓厚得多。

（图为三星安全软件KNOX）

上半年发布的 S6 edge 被誉为「颜值最高」的旗舰，借鉴了 S6 系列设计语言的 Note5 也顺理成章地为了 Note 系列的颜值担当。然而一体化的机身却将 Note 系列的传统优势舍弃掉了——可拆卸电池，可拓展内存。相信许多 Note 系列的拥趸都曾经体验过 Note 令人瞠目的续航能力，在很多评测机构的测试结果里，Note 系列手机的续航成绩都名列前茅。再加上可以拆卸电池，这使得 Note 系列成为了对续航能力有要求的使用者的最佳选择之一。各代 Note 系列旗舰都能称得上当时的性能怪兽，加上可拓展的内存卡槽，使它能够轻松地面对各类大型游戏，无论是其炫酷的画面还是其感人的外置数据包空间需求，然而这些都可能毁在 Note 系列的颜值担当 Note5 上。

Note 系列还剩下什么？

没了备用电池，不能插内存卡，换来一台玻璃机身的 Note5，不是真爱的「棒粉」都退散了，那么新的 Note 还剩下什么？大屏优化经验和那只笔。

大屏手机好用，或者不好用，与个人喜好有关，同样与厂家优化有关。三星从最早开始做大屏手机 Note 系列，直到 Note5 已经积累了大量的大屏手机优化经验。从最开始的单手输入模式，「侧面按键」到缩小屏幕手势，这些优化经验和思路，在当时是各大厂家借鉴参考的典范，在现在的各个输入法的单手模式，MIUI 单手模式呼出的方式等等，都能看到三星优化思路的影子。

（图为三星输入法的单手模式）

（图为三星 Note4 的缩小屏幕模式）

另外 S Pen 是 Note 系列区别于其他大屏手机最大的财富。三星在这支笔上做足了功夫，围绕这支笔开发出了各种各样的功能，同时为了提升电磁笔的使用体验，三星还入股了 wacom——就是 Surface Pro 2 上备受好评的那只电磁笔的制造厂商。另外，新的 S Pen 不是拔出来的——轻轻地按下 S Pen 的尾端，就能弹出笔来。

在 S5 遭遇滑铁卢之后，三星总算拿出些许诚意来了，终于舍弃掉了为人所诟病的万年大塑料机身，然而初次使用金属边框的 Note4 由于其糟糕的设计——金属边框将 2.5D 弧面屏幕玻璃完全包裹，并没有为三星电子挽回些许颓势。上半年发布的 S6 系列，由于其出色的工业设计，将金属边框与前后玻璃面板完美的结合，一扫之前的颓势。那么作为借鉴了 S6 系列设计语言，Note 系列「颜值最高」的 Note5 是否能够力挽狂澜，将三星带上复兴的正途呢？
