2015年8月5日，note5 的量产版谍照爆出，金属边框和双面玻璃材质，简直就是Galaxy S6 Plus

2015年8月5日，note5 的量产版谍照爆出。在这张谍照中，毫无悬念地证实了大家的猜测，玻璃材质的前后面板加上全金属框架——你是否想起上半年三星的另一旗舰产品？没错，这简直就是一台带着笔，放大版的 s6。

Note5 充分继承了 s6 的设计语言，一体化的机身，加上改良过的背面弧线，让这款平板手机和在美观的同时兼具舒适的握持手感。「向 XX 致敬」风格的设计，在如今的手机界，已蔚然成风，自己旗舰手机也不放过，三星的这种设计思路已经延续了好几代——如当时风靡一时的 s3 和 note2，s3 和后来的 s4。也许是一体化的设计实在是大势，note 系列也只能望风而从，三星的设计师也懒得费脑子，就直接套上 s6 的设计，于是 note5 就有了今天大家看 note5 的谍照了。

一体化的大潮

在我们讨论 note 系列转投一体化设计之前，首先我们要理解的问题是为什么一体化会迅速成为当下手机设计界的弄潮儿。一体成型机身最为明显的优势在于其工艺上，其封闭的机身能够让空间得到极大的利用，完全一体成型的手机甚至只需留出 sim 卡插槽，为手机做到更轻更薄争取到了更多的空间，亦或者把争取到的这点儿空间用于增加续航，如 LG G2 的异型电池：

同时，由于手机的储存元件和电池都是内置的，这样的做法能够避免由于劣质外置元件影响用户体验。

然而，总会有部分消费者并不买一体化成型手机的账。

Note 系列产品的定位

初代 note 严格地来说，是瞎猫装上死耗子，开拓了一片新的细分市场，掀起了一股大屏潮。Note 系列的持久续航（换新电池满血复活的快感简直难以言喻）和自带那只笔，无一例外地都是致力于提高人们效率，于是就有了后来的分屏操作，后来的小窗模式等等，再到后来为了提高自家安卓手机安全性的 knox。Note 系列的手机相比于自家的 s 系列，商务的气味似乎更为浓厚。


上半年发布的 s6 被誉为「颜值最高」的旗舰，借鉴了 s6 设计语言的 note5 也顺理成章地为了 note 系列的颜值担当。然而一体化的机身却将 note 系列的传统优势舍弃掉了——可拆卸电池，可拓展内存。相信许多 note 系列的拥趸都曾经体验过 note 令人瞠目的续航能力，再加上一块可拆卸电池，续航已经可以傲视市面上大部分手机；各代 note 系列旗舰都能称得上当时的性能怪兽，加上可拓展的内存，能够轻松地面对各类游戏，无论是其炫酷的画面还是其感人的内存空间需求。这些都毁在了 note 系列的颜值担当 note5 上。

Note 系列还剩下什么？

没了备用电池，不能插内存卡，换来一台玻璃身的 note5，不是真爱的「棒粉」都退散了，那么新的 note 还剩下什么？大屏优化经验和那只笔。

大屏手机好用，或者不好用，与个人喜好有关，同样与厂家优化有关。Note 从最早开始做大屏手机开始，直到 note5 积累了大量的大屏手机优化经验，从最开始的单手操作，单手输入，侧面按键到缩小屏幕手势，这些优化经验和思路，短时间内其他厂商无法超越的。

另外区别于其他大屏手机的 s pen 是 note 系列最大的财富，三星在这支笔上做足了功夫，围绕这支笔开发出了各种各样的功能，同时为了提升电磁笔的使用体验，三星还入股了 wacom——就是 surface pro 2 上大家好评电磁笔的制造厂商。另外，新的 S pen 不是拔出来的，而用手按出来的——轻轻地按下 S pen 的尾端，就能弹出笔来。

在 s5 遭遇滑铁卢之后，三星总算拿出些许诚意来了，终于舍弃掉了为人所诟病的万年大塑料，然而金属边框的 note4 并没有为 note 系列挽回些许颓势，作为 note 系列颜值最高的「s6 plus」是否能够力挽狂澜，将三星带上复兴的正途呢？
