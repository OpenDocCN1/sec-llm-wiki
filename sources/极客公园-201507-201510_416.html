[核心提示] 终于等到了摆脱 Win 8 的这一天，不过 Win 10 真的有传说中的那么好吗？

此刻我正静静地坐在我的另一部华硕笔记本电脑前，因为从今天（7 月 29 日）零点开始，微软的最新一代操作系统——Windows 10 正式开始向全球范围的用户进行推送。微软官方将其称为有史以来最好的 Windows 操作系统。

其实早从去年 10 月开始，微软就在启动了 Windows Insider 项目的开放注册，从全世界招募了数百万名用户来参与到 Windows 10 预览版的前提体验和反馈当中。这是微软首次大规模地让普通用户参与到操作系统的共同合作开发。

当然，关于 Windows 的那个神奇的「生死循环」也让饱受 Windows 8「折磨」的用户期待满满。Windows XP 将我们从 Windows ME 中解救出来，并一举成为最受欢迎的操作系统，至今仍拥有大量使用者；Windows 7 让被 Windows Vista 摧残的电脑焕发新生。现在，Windows 10 又要来拯救 Windows 8 了。

如何升级 Windows 10？

微软此次对中国地区可谓破费心思，除了传统的 OEM 预装和官方更新之外，还和 360 安全卫士、腾讯电脑管家共同提供 Windows 10 的升级推送。据微软中国地区的高层透露，选择 360 和腾讯为合作方就是看中了这两家在中国 PC 用户中的庞大使用量，这将大大有利于 Windows 10 的快速普及。

Windows 10 同时也搭上了「免费」的招牌，如果你是 Windows 7 或 Windows 8 的正版用户（且运行的是最新版本，即 Windows 7 SP1 或 Windows 8.1），即可免费升级到 Windows 10。从 6 月份开始，不少 Windows 7 和 8 用户的都出现了一个「获取 Windows 10」的徽标，用户确认预订后将会第一时间收到 Windows 10 的升级。但是 Windows Vista 和 XP 用户想用 Windows 10 的话就不得不花钱购买了，中国区价格亦是不菲，家庭版售价 888 元，专业版 1799 元人民币，从家庭版升级专业版则需要 879.99 元。

对于「老大难」的盗版能否正常问题，微软方面表示他们会先验证原系统是否正版。即使成功升级，也会在桌面右下角始终显示水印，提示用户使用正版。

Windows 10 到底好在哪

1、 开始菜单归来

Windows 8 最惨遭诟病的地方莫过于取消了开始菜单，原先的开始按钮只能用于在传统界面和 Metro 界面之间进行切换。而 Windows 8 巨大而缺乏信息量的动态磁贴在 PC 机的鼠标操作中体验近乎灾难。

开始菜单在 Windows 10 上的回归并不仅仅是功能上的恢复，而是在同时吸取 Windows 7 和 Windows 8 特性基础上进行的重新设计。动态磁贴被集成到了开始菜单里，你可以自行选择把哪些传统和 Metro 应用固定到开始菜单。

2、 多任务管理和虚拟桌面

就像 iOS 和 Andriod 的「相互借鉴」一样，Windows 10 新的多任务切换界面和 Mac OS X 的 Mission Control 非常相似，通过点击任务栏里的一个专门按钮，就能够唤起显示所有窗口缩略图的多任务视图。

此外，呼声已久的虚拟桌面终于来到了 Windows 10，同样是通过上述任务栏专用按钮，你可以新建虚拟桌面，并通过 Windows 徽标键+Ctrl+左/右的组合操作来进行虚拟桌面的切换。嗯……没错，和 Ubuntu 的操作方式几乎一样。

眼看越来越多程序员和工程师们投入 OS X 的怀抱，微软终于坐不住了。

3、 智能助理 Cortana

苹果有 Siri，Google 有 Google Now，于是微软有了 Cortana（在中国她有个名字叫「小娜」…）。Cortana 被直接集成到了 Windows 10 开始菜单里，并在一个独立的页面里结合了网页搜索、本地搜索和智能搜索，这使得 Windows 一直以来不甚理想的搜索功能得到了较大的改善。从我的个人使用感受来看，已经很大程度上超越了 OS X 的 Spotlight 功能。

4、 浏览器 Microsoft Edge

虽然改了名，Windows 的新浏览器 Edge 缩写还是个「E」。早在前期的众多体验和测试中，Microsoft Edge 在启动速度、加载速度等方面均表现得相当优秀。不过它最大的一个特性就是网页标注功能，你可以在当前网页上添加标注后发送给好友，当然这个操作的体验在平板上会好很多。此外，Cortana 也被集成到了 Edge 里，如果你懒得输入的话，说话就好。

5、 游戏和 Xbox

Windows 10 的到来对于游戏爱好者来说绝对是一大福音，全新的 Xbox 应用将能够自动同步你所有的游戏积分和成就。根据微软官方的说法，未来你将能够在所有运行 Windows 10 的设备上玩 Xbox 游戏。现在你已经可以把 Xbox 的内容投射到 Windows 10 的 PC 设备上，而不用一定连接一台电视。

关于 Windows 10 的一些小细节

Office

随着 Windows 10 的到来，Office 办公套件会预装在操作系统里。对于所有屏幕大小在 10.1 寸以下的设备（包括 iOS 和 Android），微软将提供一个「通用版」的 Office，你可以在这些设备上观看文档、表格和幻灯片。但如果你希望使用完整的 Office 功能的话，就需要进行一次性永久购买，或者成为 Office 365 的付费订阅用户。

Continuum

Windows 10 依然没有放弃平板之梦，只不过使用了更加合理的处理方式。只要你开启了这个名为「Continuum」的功能，当你为平板连接外置键盘时，屏幕上显示的就是传统 PC 操作界面；而当你摘掉键盘后，就会呈现另一个更适合平板操作的界面。

Companion Phone

微软似乎很有信心通过 Windows 10 来从其他平台手中夺回一部分用户，于是内置了「Companion Phone」功能，作用是可以直接将 iOS 和 Android 等设备中的联系人等数据导入到 Windows 设备中。

关于开发者

今年上半年召开的 Build 2015 开发者大会上，微软宣布了 Windows 通用平台 UWP（Universal Windows Platform），基于此平台开发的应用可在所有 Windows 10 及以上的设备运行。也就是说，开发者可以通过这套工具同时开发并适配运行 Windows 10 的 PC、平板、手机和增强现实等设备。

对于游戏开发者来说，UWP 的意义也许更为重大，想象一下，原本只是想开发一款 Xbox 游戏的，结果顺手把 PC 版和移动版也给做了……

Windows 10，以及 Windows 1×？

「史上最好的一代 Windows 操作系统」、「这将是我最后升级的 Windows 操作系统」、「支持最为广泛的操作系统」……

自从 Windows 10 推出第一个预览版以来，微软高管便不断发声力挺，并向外界构建了一个基于 Windows 10 的完美物联世界。不过这个世界到底何时呈现在我们面前，还得看 Windows 10 到底能占据多大的市场空间。
