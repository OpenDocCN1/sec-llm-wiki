[核心提示] 本周，在亚马逊中国运动相机馆上线活动上，GoPro 亚太区市场与销售总经理钟平滔与大家分享了一些 HERO4 Session 新品容易被忽略的技术细节。

7 月初，GoPro 发布了新款运动相机 HERO4 Session。与 HERO4 相比，它的体积小了 50%，重量轻了 40%，是迄今为止 GoPro 所推出的最小巧产品。

HERO4 Session 可拍摄最高 1440p30 帧率视频和 800 万像素照片。和 GoPro 之前产品不同的是，HERO4 Session 还自带防水，不借助防水壳就可实现 10 米下潜。机身顶部的按键可以快速切换拍摄/关闭状态。

虽然外观部分是最明显的变化，但 HERO4 Session 绝对不只是一款「Mini」版的 GoPro 那么简单。本周，在亚马逊中国「运动相机馆」上线活动上，GoPro 亚太区市场与销售总经理钟平滔与大家分享了一些 HERO4 Session 容易忽略的技术细节。

又一个入门产品？

在 GoPro 的产品序列中，已经拥有了 HERO 和 HERO+ LCD 两款入门级的产品，售价最低 998 元起。

而 HERO4 Session 国行售价 2998 元，相同价位的 HERO4 Silver 能够拍摄 4K/15 帧视频、12MP 照片，甚至还带有触摸显示屏——虽然性能上不出彩，但这不意味着 HERO4 Session 就是一款「入门产品」。

首先 1080p60 帧的视频拍摄可以满足大多数的视频拍摄需求；而体积缩小带来的阻力减小和负重减轻让 HERO4 Session 适用性更广，是一款更加「纯粹」的运动相机。

有意思的是，HERO4 Session 的正方体机身与宝丽来之前发布的 CUBE 非常相像，不禁让人浮想联翩。但根据钟平滔介绍，其实它在 3 年前就开始研发了。

是否会减少使用时间？

HERO4 Session 内置了不可更换电池，容量略有缩小（1030 mAh）。但在使用时间上，HERO4 Session 并不会缩短，甚至还会超过其他产品。

HERO4 Session 使用 Micro USB 接口

每次停止拍摄时 HERO4 Session 便会处于完全关闭状态而不是待机，也可以通过关闭相机的 WiFi 进一步省电。当然，不可更换电池的设计对于重度用户来说还是不够方便。

只有一个按键够用吗？

GoPro 在调研后发现，大多数用户都有使用惯性和偏爱的设定，单个按键可以让相机的操作逻辑更加简单——按下开始拍摄，再按下关闭。

其实在 HERO4 Session 还有一个「隐藏按钮」：Hilight Tag 。可以在拍摄中进行「打点标记」，也用于一些简单的设定，例如打开/关闭 WiFi 模块。HERO4 Session 配备了一个单色小屏幕，可以显示基本的参数和无线连接状态。

红框处为 Hilight Tag 按键

双麦克风有什么用？

如果你在骑车时用过 GoPro，回放时一定能听到明显的「噗噗」风声，尤其在缺少防水壳的情况下会更加明显。

红框处为麦克风位置

HERO4 Session 配备两个麦克风，一个位于摄像机正面，一个位于背面。在有风环境下或高速运动时，可以自动切换至噪音较小的麦克风，从而获得更好的录音效果。HERO4 Session 的麦克风还采用了一种类似人耳耳膜的设计，浸水时也能保证录音效果。

配件是否兼容？

HERO4 Session 配备了全新的附件：标准保护框、低架保护框和球头卡扣。配合保护框使用，HERO4 Session 可兼容所有 GoPro 固定底座搭配使用。

低架保护框让 HERO4 Session 拥有更贴近表面的安装方式，粘贴在头盔等装备上时会更加稳定，同时可以很方便地进行前后调节；球头卡扣可以不用卸下相机就能轻松改变拍摄方向，在这之前需要借助第三方配件才能实现。

低架保护框和球头卡扣可以进行多角度调节

保护框的安转会带来方向的问题，HERO4 Session 支持「自动旋转」。在反向安装摄像机时，可自动将拍摄方向调整为正面朝上，因此无需在后期制作中再翻转视频片段（需要进行一次开关机过程才能完成切换）。

控制 app 有什么变化？

目前 HERO4 Session 的 Protune 高阶模式仅支持视频调节，相机的高阶调节会在之后的固件更新中提供。

GoPro 正在进行手机 app 和后期处里软件 GoPro Studio 的汉化工作。最快 8 月份就能用上简体中文版的手机 app，这将首个新增的语言。除此之外，GoPro 也即将推出培训 app ，包括「每日最佳视频」、「每日最佳照片」等栏目。

运动相机越做越小是必然的趋势，有传闻 GoPro HERO5 也将采用立方体的设计。虽然在拍摄性能上没有突破，但在 HERO4 Session 产品上还是看到了 GoPro 对于运动相机新的理解——更加小巧易用，让用户可以专注于拍摄的内容。

Nicholas Woodman 创立 GoPro 之初的一个诉求就是制造一种能够绑到运动员手臂上的便携相机，更加小巧的 HERO4 Session 又朝着这个方向前进了一步。
