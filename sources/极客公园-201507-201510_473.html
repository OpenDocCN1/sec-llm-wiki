[核心提示] 曾活跃在无数中国青少年硬盘中的王涛现在要以一种新的形式活跃在你的电脑和手机里。

在中国球迷圈，王涛在某种程度上是一个可以与其前辈黄健翔齐名的前央视解说。在遵循了前辈的脚步离开央视创业后，王涛的北半球国际有限公司获得了经纬创投 A 轮 2500 万人民币的投资。面对突如其来的角色转变和资本青睐，王涛的表现正如他在接受「极客公园」采访时所穿的那件印有其标志性解说语的 T 恤那样，「来了个敲山震虎」。

从央视编导到创业公司 CEO 的角色转变

2014 年，《新周刊》评选出了「年度最佳体育节目主持人」，王涛成为了继黄健翔和刘建宏这两位前央视著名体育解说后的第三位获奖者。唯一的不同是，王涛的身份是 cctv 体育节目的编导，而不是真正意义上的主持人，他的所有解说节目均是由自己和妻子在家里完成的。在致颁奖词时，他发表了一些关于现状艰难的牢骚，而这些牢骚也传到了央视领导的耳里。

「我并没有觉得我做得有什么不对，我所做的这些都是基于我的兴趣，而我做这些也是为了体育频道和自己负责的节目。事实上，我也感谢了 cctv 为我提供的平台和机会，但领导却选择性地忽略了这些内容。」

从那以后王涛在台里的地位开始变得愈发尴尬，走或不走成为了他很长时间的纠结。在黄健翔和刘建宏先后离开央视开始在互联网领域崭露头角时，王涛似乎也看到了些许希望，而相比于两位前辈，王涛在互联网上的影响力可能要更大。于是，在 2014 年 4 月，王涛正式从央视离职开始全职做他的公司——北半球传媒。

虽然从 2009 年开始王涛就已经开始从事相关视频的制作工作并已实现盈利，但以「电视人」的身份进军互联网还是引来了不少质疑。对此，王涛倒觉得自己是个互联网属性很强的人。

「我制作的很多内容其实都是通过互联网进行的传播，从最早的实况足球解说到现在我们所做的各种节目。在那个时代，实况足球更像是一个自媒体，拥有着成百上千万的用户。我花两个月时间录了将近两万条解说并通过大量的下载和传播获得了口碑效应，而现在，我们的产品也是非常互联网化的。」王涛表示，虽然是传统电视人出身，但他一直保持着对互联网的热衷和学习，虽然比 90 后和 00 后要慢一拍，但还是一直在不断地学习各种移动应用的产品逻辑。

而比质疑更难承受的是自己在角色转换过程中面临的适应问题，其中最大的变化是王涛离核心业务越来越远了。

「我其实特别爱做内容和创意，但现在我更多地得做团队管理、资本运作以及公司发展规划等方面的工作，我得去兼顾很多我不懂的部门，比如说技术部门，我只能看 App 的最终呈现，从最终呈现的内容来反过来给他们提要求。这也是我比较苦恼的，就是从一个内容制作者变成一个管理者，这是一个极大的挑战。」

王涛觉得自己不是一个好的管理者，但肯定是一个能够好好学习管理的管理者。在尽力去学习管理的同时，他还会继续去创造内容。至少，现在王涛还没能培养出能够完全替代他的人。而对于「北半球」来说，最核心的竞争力莫过于优质内容的创作。

我不做没有意思的事情

作为一个以优质视频内容为核心竞争力的平台，王涛对视频内容的把控十分严格。

「我对视频制作最大的要求是要有意思，我不做没有意思的事情。如果这个东西做出来我自己都不想看的话我就不会去上线，不管是正的，还是谐的，搞笑的还是煽情的，一定是制作者自己想看的。」

在节目内容的呈现上，王涛对这一原则的把控也为他赢得了像苏亚雷斯、梅西和托雷斯这样国际知名球星的尊重。

在足球圈浸淫多年的王涛拥有着很多西班牙的球星资源，并且和其中的很多成为了十分要好的朋友。在一期「足球各种嘿」中，王涛将有过「咬人」行为的球员苏亚雷斯制作成了一个僵尸的形象。这期节在被苏亚雷斯的经纪人看到后，他表示苏亚雷斯看了这个后会很生气，但是经纪人看完后却很开心，于是便提议让苏亚雷斯自己来演。

「我当时觉得可以去和苏亚雷斯探讨下这件事，我想告诉他在中国其实有一种精神叫自黑，当你有一个缺点的时候，你越是藏着大家就越会觉得你装，也越不喜欢你。但你要说勇于自我调侃，大家就会觉得你是个心很宽的人，就觉得对你没有敌意了。我们就觉得苏亚雷斯应该懂得自黑，他一旦懂得自黑之后大家就会觉得很可爱，所以我们就用这样的方式和他进行沟通。」

最终，王涛通过打麻将吃「一万」（苏亚雷斯曾在赛场上咬过一位名叫伊万诺维奇的球员）这种有意思的方式制作了一期节目。反响自然是不错的。

同时，在北半球新装修的办公室中，除了一座球衣博物馆，整个办公环境都充满了球场的元素：更衣室、替补席，甚至每个新员工都会有自己独立编号的球衣和加盟仪式。

从内容生产到文化群落

在之前的很长一段时间，王涛和他的北半球国际制作出来的视频都依靠着像优酷、腾讯和爱奇艺这样的互联网视频平台进行着传播。慢慢地，王涛发现当这些平台用他们的资源帮他推广的时候，视频的播放量就会高；而当他们不推的时候，王涛就得用尽自己的一切方法去推广自己的产品。到头来王涛发现，自己辛苦制作出来的视频其实都是在帮助这些平台，而北半球并没有真正的积累下来自己的用户。

「因为我们有很多好的视频，但其中的很多并没有得到推广，他们也没有给一个很好的回报，我们并没有得到很好的尊重。那时候我们觉得我们应该运营自己的用户和平台，所以我们决定回收我们所有的视频。我们需要自己尊重自己的产品，把产品线回收，回收之后我们并不是单纯地把它们放到一个平台上让大家看，这只是最简单的一个功能，我们希望能够带着大家一块儿去玩儿，一块儿去参与。只要你是平台上的注册用户，你就能参与到节目中去。」

据王涛介绍，北半球国际即将上线一个名为「骚客」（Soccer 的谐音）的移动应用，除了自身制作视频的集合，还会尝试在电商、球迷文化以及 UGC 视频等方面做一些尝试。

在电商的尝试中，王涛并没有选择单纯地开通线上商城，而是通过与内容的结合来打造优质用户购买行为。为此，王涛专卖制作了一档名为「收下你的球衣」（「脱下你的球衣」）的节目。

「每个球星脱下了一件球衣，这件球衣就成为了一段历史和经典。所以我们会找到很多球星从职业生涯开始到结束的球衣，从托雷斯最早的 35 号到他现在在马竞的 9 号，一共 37 件球衣。集齐以后我们先把这 37 件球衣的故事讲一遍，从球衣文化的角度和托雷斯职业生涯的角度来做一期节目。在下一期节目中我们会带着这些球衣到托雷斯那里让他签名，签完之后进入我们的北半球博物馆。此外，我们还会让托雷斯签二到三十件本赛季的球衣，等到新赛季开始的时候我们会对球迷发售这些新赛季的球衣，因为我们打通了渠道。」

在「骚客」中，这种发售方式其实是一种很隐蔽的服务，王涛不会在节目里刻意提及要去哪里买球衣，但会引导用户去了解一些新赛季球衣的功能和变化，然后在底部提供一个链接，用户可以通过这个链接来购买。王涛认为，现在球迷的消费其实很乱，在网上购买的球衣很难辨认真假，而在「骚客」里，他们可以保证是真的，而且是同类里面最便宜的，因为北半球国际已经打通了渠道。

除此之外，王涛还希望通过现场足球视频的方式来生成更多的 UGC 内容。王涛对「极客公园」的记者表示，目前北半球在国外签了很多热爱足球的专业电影人才，他们去到一些一线的聚乐部比赛现场去拍摄，然后最后形成节目。这样一来，一些一手的独家视频就能以碎片化的方式在社交平台上进行着传播，而在之后他们也会选取一些有意思的选题进行整合。

「未来我们希望让更多的人成为我们的拍客，拍的好的话我们会给他骚客的视频认证，还可以拿到我们的记者证，我们还可以对他开放球星专访的权益。我们的一系列节目其实都可以将线上线下打通，每一档节目也都是一档真人秀。我们将这些节目内容与我们自己的 App 打通，在用户使用 App 的同时也形成了节目。」

一个好 IP 的背后需要什么

近两年，国内掀起了一股基于 IP （intellectual property，即知识产权）的创业风潮，然而掌握了个人和众多优质视频 IP 的王涛却认为自己还没有将 IP 的价值最大化。

「我们之前对 IP 的利用其实一直都很差，因为原来的体量很小，没有专门运营和推广的人，所以吃了很多这方面的亏。但是现在我们正在逐步改善这一情况。」

王涛告诉「极客公园」，一个 IP 要想做好，最重要的就是把 IP 所承载的内容做踏实，只有超过 80% 的人都认可内容价值的时候，一个 IP 才能被称为优质 IP；同时，一个 IP 在诞生后必须要做有针对性的推广，就好像电影宣发一样，只有推广到了正确用户的手中，一个 IP 才能真正做起来；除此之外，IP 必须具有一定的可持续性和外延拓展，不然很容易被用户忘掉。总而言之，一款好 IP 的打造应该是内容制作、渠道和拓展等多方面的一体化，就好像万合天宜所做的那样。

目前，北半球国际的主要盈利在视频的版权和广告收益上，电商仍处在预上线阶段。在未来，王涛希望通过个人在实况等领域的 IP 开发和优质 IP 的培养衍生出更多良性的商业模式。为此，王涛也对比了虎扑和懂球帝这两个业内标杆性的体育应用。在王涛眼中，虎扑和懂球帝在内容和运营上都做得足够漂亮，也是多年的积累达到的成就，再想做同样的事情会变得异常地艰难。

「我预测，在四五年后视频会成为移动互联网的宠儿，对短视频和中长视频的需求应该是很旺盛的，到那时候我们的优势就会体现出来。现在让我去和其他做的好的体育应用比，不论是在用户积累还是其他方面肯定都不如他们，但对未来我很有信心。」王涛认为，视频节目本身就存在一定的门槛，不是每一个团队都能做好视频，也不是每一个视频团队都适合做足球类视频。北半球国际也是因为有了这几层门槛之后才能做一些差异化的东西。

「比我们好的视频团队有很多，但能把节目做得这么精良，又能理解足球同时又能把足球娱乐化的团队并不多，这也是我们的核心竞争力。有人说北半球的核心资源是球星资源，我觉得其实并不是，很多平台的球星资源都比我们多，我们其实是踏踏实实地把每一个资源转化为节目并形成自己的 IP，所以才显得好像我们的球星资源很多。」

在采访结束后，王涛向「极客公园」的记者表示，自己其实也是挺「极客」的一个人。从闭门录制近两万句实况足球解说词到将个人 IP 和节目内容极致化，王涛在完成角色转变的同时也在一个新的领域延续着自己独一无二的极客风格。

毕竟，不想创业的电视编导不是好解说。
