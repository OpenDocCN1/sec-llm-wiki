金立又发了一款三天三夜不用充电的手机

这款手机的电池容量大到「超乎你想象」，它也许能给你安全感。


2015 年 12 月 21 日，在广东东莞的金立工业园区，金立举办了一场与众不同的发布会。金立选择了在自己的工业园区发布了自己的手机新品。这似乎是向我们表明，产品品质过硬，不畏惧向消费者展示他们的生产线。而金立的董事长刘立荣则在开始的致辞中，表示「将会成为生存时间最长的企业」，这与他们手机主打的「超级续航」不谋而合。那么这款产品所谓的「超级续航」到底能续多久呢？

对称的设计理念

这部手机秉承对称的设计理念，所以我们可以看到这台设备的上下边框也是对称的，就连手机的 Home 键也是沿中轴对称，上下留白一致。在手机背面也是一样。手机摄像头居中，闪光灯居中，就连降噪麦克风也放在了中轴线上。与此同时还采用了 USB-Type C 的接口，在兼顾对称的同时，也赋予了这台手机快速充电的功能。

不过金立毕竟没有细致到老罗那种程度——侧面虽然两个卡槽也是对称的，然而按键却出卖了它。音量、电源等按键全都集中在手机的右侧，前面板的距离感应器与前置摄像头也不像乐视的乐 1s，对称分布在听筒两旁。

说完设计理念，就该到了手机的材质。毫无意外的，这部手机采用的也是全金属的机身，加上后盖三段式的设计。但值得一提的是，全金属的设计从外沁到里——手机内部电池仓也采用了全金属的框架。前面板采用的是 2.5D 弧面玻璃，略微高出手机中框。正面的 Home 键与三星、魅族等 Android 手机一样，兼具指纹识别功能。扬声器被放在了手机背面，这可能会影响到日常接听电话。

续航：最大的卖点

这场发布会自始至终都贯彻着一个关键词——超长续航，这也是金立 M 系列手机的主要卖点。目前市面上主流的 Android 手机电池容量基本维持在 3000mAh 左右，稍微「激进」一点儿的则是采用了 4000mAh 的电池。这回金立做的更「激进」，直接将手机里塞入了一块 5020mAh 的电池。

大电池带来的第一个问题是手机的体积。众所周知，手机里占用空间最大的部件便是手机电池，金立的电池容量要大于其他手机。那么它是怎样做到这一点的呢？

首先手机屏幕采用的是色域达 97% 的 Super AMOLED 的屏幕，在节省电量的同时，也能减少手机的厚度。其次便是各家厂商经常使用的一招——弧形机身。这能有效地降低视觉厚度，但手机摄像头还是避免不了微微凸起。当然，无论采用什么材质，什么设计，即使能降低手机的厚度，目前电池的重量还是减轻不了的，所以这款手机拿起来很有「厚重感」。

大电池带来的另一个问题充电时间。如之前所述，这款手机采用了 USB-Type C 的接口也支持快速充电功能，但这个 Type C 接口只是「做的形状像」还是真的能带来 Type C 所具备的带来的「快速充电」和「高速数据传输功能」呢？这个有待考证。这款产品还延续了双充电芯片设计，充电时可有效降低手机温度，增强安全性。

为了续航，手机采用的 CPU 主频为 1.3 GHz，由 MTK 出品的 MT6753。虽然低主频的 CPU 能够有效地控制手机功耗，但性能上却乏善可陈。如果仅做日常用途，也许这颗 CPU 仅仅「够用」。同时这颗 SoC 还采用了 GPU（图像处理芯片）动图优化——简单的来说，就是在类似于微信聊天中播放 GIF 图之时，手机能够智能识别场景，并对图像处理进行优化，有效地降低手机耗电。

为了续航也为了安全

在软件优化上面，金立的主要方向还是考虑到续航，比如显示后台高耗电程序，协助用户监测手机电量优化情况。在保证高续航的同时，在软件上面，这款产品还兼顾到了安全性——除了常规的指纹支付，隐私应用之外，金立还考虑到邮件的易用性和安全性的问题，不仅简化了邮箱的登录步骤，还给邮箱加了把「指纹锁」。

当然，其中最让人感兴趣的是金立的「Ami 换机」功能。号称支持所有的 Android 手机全数据迁移——不仅连用户的通讯录，照片能够转移，还能将用户的应用甚至是应用的数据完全迁移，比如用户单机游戏的通关记录，应用的偏好设置，都能「无损地」转移到新手机里去。发布会上，卢伟冰甚至表示：「你们可以不用这款手机，但你们一定要试试 Ami 换机。」

继安全与续航之后，金立也推出了自己的「金立漫游」功能，这项功能与小米的「小米漫游」，和华为的「天际通」相类似，能够给出国的用户以相对较廉价的数据费。
