谁是今年最优秀的智能手机？——YouTube 科技达人评测

YouTube 科技达人 Marques Brownlee 评出了自己眼中今年最优秀的智能手机，结果很可能出乎你的意料。


不知不觉中，2015 年只还剩下十天。在过去一年中，国内外厂商热热闹闹地发布了很多智能手机，在这些产品中，你认为哪款才是今年最优秀的智能手机？相信大家心中都有自己的答案，下面我们就来看看一位国外科技达人的观点。

MKBHD 是 YouTube 上订阅量最高、最有影响力的科技类频道之一，作为 MKBHD 的播主，Marques Brownlee 从屏幕尺寸、摄像头、电池等方面出发，评出了自己心目中 2015 年最优秀的智能手机。

最佳大屏手机

第一名：三星 Galaxy Note 5

Note 5 配备了一块 5.7 寸、分辨率高达 2K 的 AMOLED 屏幕，在保证了轻薄机身的基础上，Note 5 还配备了一块容量较大的电池（3000 毫安时）。三星还针对 Note 5 的大屏幕量身定做了多款软件，提高了 Note 5 的生产力。

第二名：LG V10

V10 是 LG 年底推出的全新产品，它取代 G4 成为了 LG 的新一代旗舰。V10 配备了一块 5.7 的 IPS 屏幕，并在顶部增加了一块 2.1 寸的副屏，可以实现更多有趣实用的功能。

提名：Nexus 6P，三星 Galaxy S6 Edge+

最佳小屏手机

第一名： iPhone 6s

iPhone 6s 是一部真正没有妥协的小屏旗舰，也是苹果迄今为止最优秀的智能手机，虽然它轻薄的机身也付出了一些代价（电池续航），但 A9 处理器让 iPhone 6s 上的运行速度难以置信地快。

第二名：索尼 Z5 Compact

索尼 Z5 Compact 继承了 Z5 和 Z5 Premium 身上的很多优点，包括出色的性能、优异的摄像头和不错的续航，这让 Z5 Compact 成为一款优秀的小屏幕手机。

最佳摄像头

第一名：三星 Galaxy Note 5 / S6 Edge+ / S6 / S6 Edge

三星今年推出的这四款 Galaxy 旗舰手机都配备了 1600 像素的摄像头模块，成像效果基本相同。它们拥有出色的解析力、生动的色彩和不错的动态范围，同时，这几款手机的 4K 视频录制效果也不错。

第二名：LG V10

自动模式下，LG V10 的成像效果在很多情况下可以媲美 Note 5，你还可以通过手动模式进一步提高挖掘 V10 的潜力。LG V10 最大的亮点是视频拍摄的手动模式，如果你打算用手机拍很多视频的话，LG V10 是最好的选择。

提名：iPhone 6s Plus，Nexus 6P

这两款手机的摄像头同样快速可靠，成效素质也还不错，另外特别需要注意的是，以上提到的这几款手机在成像上的差距并不大。

最佳廉价手机

第一名：一加手机 X

一加 X 在美国的无合约版售价仅有 250 美元，而它的机身材料和做工都远比这个价位的其他产品出色。此外，一加 X 还配备了一块 5 寸 1080p 分辨率的 AMOLED 屏幕、金属边框、microSD 卡槽以及可定制化很高的系统（编者注：海外版一加 X 预装了接近原生安卓的氧 OS）。

第二名： Moto X Style (即 Moto X Pure)

Moto X Style 拥有出色的硬件配置以及接近原生安卓的操作系统，在推出时，Moto X Style 是摩托罗拉最高端的智能手机，而它的售价却只有 400 美元。

提名：一加手机 2，Nexus 5X

最佳电池续航

第一名：Moto Droid Maxx 2 (Moto X Play)

Droid Maxx 2 配备了一块容量高达 3630 毫安时的电池，摩托罗拉表示 Droid Maxx 2 可以正常使用两天。同时， Droid Maxx 2 配备了一块效果不错的 1080p 屏幕和接近原生安卓的操作系统。如果你是一个手机重度用户，Droid Maxx 2 应该也足以满足你对续航的要求。

第二名：Nexus 6P

虽然电池容量没有特别大（3450 毫安时），但配合预装的 Android 6.0 Marshmallow 系统，Nexus 6P 的电池续航比市面上大多数手机都要优秀。

提名： LG V10，LG G4

LG 的这两款手机都配备了容量较大的可更换电池，这也是目前最有效的「快充」方案。

最大进步手机

黑莓 Priv

毫无疑问，Priv 是黑莓史上最优秀的智能手机，虽然它依然很贵，而且不是每个人都会喜欢黑莓定制的安卓系统和 PRIV 的实体键盘，但在经过这么多年后，看到黑莓可以改变自己推出更加优秀的产品，还是很令人兴奋的。

最佳手机设计

三星 Galaxy S6 Edge+

在「千机一面」的手机市场，稍微在形态上有所创新就能获得很多关注，Galaxy S6 Edge+就是这样一款产品。它的弧面屏幕和金属边框完美地融合在一起，能让你在众多手机中一眼发现它，希望明年我们可以看到更多三星推出的「Edge」系列手机。

最特别手机屏幕

第一名：Moto Droid Turbo 2（国内版为 Moto X 极）

Droid Turbo 2 的屏幕使用了摩托罗拉开发的 ShatterShiled 技术，这让它成为一块真正摔不碎的屏幕。

第二名：索尼 Z5 Premium

Z5 Premium 配备了一块分辨率高达 4K（3840×2160）屏幕，虽然目前在日常使用中， 4K 分辨率不会带来明显的体验提升，但在未来，尤其是 VR 领域，Z5 Premium 的 4K 屏幕拥有非常大的潜力。

最令人失望手机

HTC One A9

即便不考虑 A9 和 iPhone 有多么相似，作为替代 HTC One M9 的产品，A9 在产品上也做出了太多的妥协。由于处理器的性能限制，A9 不支持 4K 拍摄，以往 HTC 手机上出色的 BoomSound 扬声器也被换成了主页键，但愿明年 HTC 能推出一款优秀的产品。

年度最佳智能手机

第一名：Nexus 6P

Nexus 6P 拥有出色的屏幕、续航和摄像头，它的性能和做工也都无可挑剔，Nexus 6P 是一部几乎没有妥协的手机，而且它 499 美元起的售价比很多「旗舰机」都要便宜。

第二名：三星 Galaxy Note 5

Note 5 拥有目前智能手机中最优秀的屏幕和最优秀的摄像头，虽然不是每个人都喜欢三星的 TouchWhiz 操作系统，而且它的背面还异常容易沾惹指纹，但这些都不是什么大问题。

提名：Moto X Style，iPhone 6s / 6s Plus，Microsoft Lumia 950 XL
