我们早已习惯了通过喝茶或咖啡来提神醒脑，有没有想过未来会出现一种电子装置，以更加「简单粗暴」地方式达到同样的效果呢？

最近我体验了一款特别的可穿戴设备：「情绪调节器」Thync，它试图通过神经调节技术来达到和咖啡因同样的效果。乍听起来有点荒诞，它的实际表现究竟如何呢？

颇具未来感的外观

Thync 分为 Module 和 Strips 两部分。Module 相当于 Thync 的「发电机」，它看上去就像一个星际迷航里的飞船，中间的条形指示灯颇具未来感。Thync 在使用前需要先对 Module 进行充电，然后通过蓝牙和手机进行配对。

Module 底部拥有两个金属纽扣，与 Strips 连接后可以输送电脉冲。打开 Module 的开关，按照 app 上的教程把 Strips 粘在身体上对应的位置就可以开始工作了。

需要注意的是，Strips 并不能无限次重复使用，我用了几回后已经明显感觉塑胶的粘性不如之前了。

「提神」、「放松」二选一

Thync 的原理来源于医学实验中广泛运用的经颅直流电刺激（tDCS），临床上还用于老年痴呆、抑郁症等疾病的治疗研究。

「电刺激」让 Thync 听起来难免有些恐怖，但实际上它只是给人耳后或脖颈后的皮肤作用了极其微小的直流电。Thync 作用的是人体皮肤，而不是特定的神经系统或者是肌肉，这与大多数直接刺激脑外部的 tDCS 研究还是不同的。

Thync 拥有两种模式：「Energy」和「Calm」，同时对应两种不同的贴片。模式切换需要通过手机 app 来控制。

根据网上查阅的资料得知：「tDCS 对皮质兴奋性调节的基本机制是依据刺激的极性不同引起静息膜电位超极化或者去极化的改变。阳极刺激通常使皮层的兴奋性提高，阴极刺激降则低皮层的兴奋性。」

打开开关后，身体对应的位置会有一些酥麻的感觉，在手机端还可以调节电刺激（VIBES） 的强弱。当强度在 80% 以上时，会有明显头疼的感觉。整个过程需要十几分钟，但是效果可以持续半个多小时。

两种模式都使用后，我觉得「Calm」的效果更明显些，可以很快让大脑进入一个放送的状态，甚至有一点微醺的感觉。而「Energy」给我的感觉只是电流的强度更大了一些。

还有很多不确定性

必须要承认的是，Thync 现阶段还有很多不确定性：身边不同的朋友体验也不尽相同，而以我个人为例，也并不是每次使用都有明显的效果。同时作为一款「准医疗器械」，Thync 使用的 tDCS 技术目前并未通过美国食品药品监督管理局（FDA）的认证，也让它缺少了一些说服力。

不过，就像之前极客公园向大家介绍的「个人基因监测」一样，未来我们的生活中会出现越多的这样的医学研究成果。如果 Thync 这样的「情绪调节器」能够获得稳定的效果，灵活地运用「提神」和「平静」两个模式可以大大提高我们的工作效率以及生活质量。

Thync 的官方售价为 199 美元。不久前中国亚马逊「海外购」上线了「亚马逊发明家」项目，引进了很多国外初创团队的酷品，Thync 就是其中之一。如果你想亲自体验一下 Thync 具体有没有效果，也欢迎发邮件至 caoqi@geekpark.net 报名申请。
