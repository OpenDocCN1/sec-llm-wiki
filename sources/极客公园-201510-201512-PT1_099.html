谷歌推出了自己的「生产力」平板 Pixel C，但大家似乎并不买账

今年，随着微软 Surface 系列平板电脑的热销，各家似乎都在忙着推出自己的「生产力」平板，继 iPad Pro 之后，谷歌旗下的第一款平板的 Pixel C 也于昨日正式开卖，其中 32GB 版在美国地区的售价为 499 美元（约合 3200 元），配套的蓝牙键盘售价为 149 美元（约合 957 元）。

各家外媒也在 Pixel C 上市前拿到了产品并进行了体验，我们来看看他们是怎么看待这款产品的。

这并不是一台 Nexus

首先需要说明的是，虽然谷歌之前推出过 Nexus 7、 Nexus 9 等平板产品，但这次的 Pixel C 平板并不是 Nexus 系列，而是属于 Pixel 系列。和 Nexus 系列由合作伙伴生产不同，Pixel 是谷歌自己的团队做出来的。如果说 Nexus 是谷歌用来展示旗下的安卓软件平台的，那 Pixel 产品线则是谷歌用来展示其硬件设计能力的。

Chromebook Pixel

2013 年推出的 Chromebook Pixel 就是 Pixel 团队的代表作品，它的售价超过 1000 美元，功能和售价不到它四分之一的其他 Chomebook 产品没什么区别，但是 Chromebook Pixel 的设计和做工足以媲美甚至超越苹果的 MacBook。

而作为 Pixel 系列的第一款平板电脑，Pixel C 的设计和做工自然也非常优秀。

从尺寸上看，Pixel C 比 iPad Air 2 要稍微大上一圈。虽然这两款平板都使用了玻璃和铝作为主要材质，但无论看起来还是摸起来，这两款产品的感觉都完全不一样。和 iPad Air 2 相比，Pixel C 的设计要更加硬朗，和之前的 Chromebook Pixel 有几分相似之处。Pixel C 可能还是史上做工最好的安卓平板，整机的做工严丝合缝，按键和接口处的做工也无可挑剔。

系统优化似乎有些问题

和做工同样优秀的是 Pixel C 的屏幕，Pixel C 配备了一块 10.2 寸、分辨率高达 2560 x 1800 的屏幕（ppi 为 308），它的屏幕长宽比大概为 1.4 ：1，基本相当于标准 A4 纸的长宽比，因此除了横屏使用，Pixel C 的屏幕也很适合竖屏观看。

Pixel C 比 iPad Air 2 要稍微厚一些，没有过分追求轻薄给 Pixel C 带来了不错的续航，在外媒 The Verge 的测试中，Pixel C 日常使用续航可以超过 11 小时，而在莫博士（Walt Mossberg）的测试中，Pixel C 可以连续播放 9 小时 42 分钟的视频，比 iPad Air 2 大概少一小时。

谷歌还给 Pixel C 配备了几乎是平板电脑中最强的硬件，包括支持 64 位计算的 Nvidia X1 处理器，3GB 内存以及 USB Type-C 接口。但可能是系统优化问题，和去年的 Nexus 9 一样，Pixel C 的系统流畅性欠佳。The Verge 在使用后表示：「Pixel C 经常会出现莫名其妙的延迟和卡顿，在打开 App 和多任务切换时尤为明显，谷歌的安卓团队似乎仍然没搞明白如何充分利用 Nvidia 的芯片。」

外接键盘——设计的是不是有些聪明过头了？

谷歌给 Pixel C 设计了一个同样精致的外接键盘，这个键盘通过蓝牙连接，连上 Pixel C 平板后，平板还可以直接给这个外接键盘充电，用户完全不用考虑键盘的充电问题。

此外，Pixel C 的外接键盘通过磁铁牢牢吸附在平板上的，正常使用时基本不可能不小心分开。用户还可以自由调节平板和键盘之间的角度，比 iPad Pro 那个固定角度的官方键盘要好不少。

不过这个外接键盘和 Pixel C 平板的连接方式很特别，用户需要先同时把键盘和平板平放且键盘面和屏幕正面朝上，然后把平板部分「滑」到键盘上。另外，用户还可以把这个键盘吸附到 Pixel C 的屏幕上，把它当作保护壳来使用（如下图），不过吸附上之后无法像打开笔记本电脑那样拿开键盘，用户必须把这个键盘从屏幕上「滑」出来。

谷歌甚至专门附带了一张使用说明来解释应该如何用正确的「姿势」连接键盘和平板，The Verge 执行主编 Dieter Bohn 表示:「在不看说明书的情况下，我周围至少有五个人无法搞明白如何把键盘和平板连起来。」莫博士也吐槽了这个键盘的连接方式：「我向谷歌询问了这个问题（键盘和平板的连接方式），谷歌的一位员工告诉我，用户很快就会习惯这种连接方式，不过我还没习惯。」

同时，由于 Pixel C 的屏幕只有 10 寸，为了让键盘的尺寸和平板保持一致，键盘上没有足够的空间来容纳全尺寸键盘，Pixel 团队的做法是去掉像括号和波浪号这样不常用的按键，以尽可能地扩大键帽尺寸。但由于缩减了键盘上的按键数量，用户会需要一段时间才能适应这个键盘。

App 可能是最大的短板

下面又到了老生常谈的时间。安卓手机的 App 数量和质量都已经足以媲美 iOS 平台，但在平板上，这两者之间还存在明显的差距。莫博士说：「谷歌长期忽略对平板电脑 App 的支持和优化，每当我询问谷歌公司的高管时，他们通常都会说优秀的手机 App 在大尺寸的平板上表现也会很出色，但所有用过 iPad 的人都能看出手机 App 和专门为平板优化过的 App 的区别。」

具体在 Pixel C 上，由于大部分 App 是直接把手机的 App 放大，很多 App 在运行时会出现大量没有被利用的空白区域。除此之外，由于很多第三方 App 没有横屏模式，即便是插上外接键盘，这些 App 也会在竖屏模式运行（如上图）。

如果说安卓平板上第三方 App 的使用体验不佳还可以理解，谷歌自己的 App 在 Pixel C 上也体验糟糕就显得无法原谅了，比如说 Hangout 和 Google Docs，虽然它们都是谷歌自家的 App，但在 Pixel C 上看上去依然更像是手机 App 的放大版，完全不像是可以提高生产力的工具。

除了 App 质量糟糕之外，Pixel C 上搭载的安卓 6.0 系统还没有分屏功能，微软、三星和甚至苹果都为自家的产品加入了分屏功能，而事实证明屏幕上同时运行两个程序也的确有助于提高效率。尤其是考虑到 Pixel C 的屏幕比例为 1.4 ：1，如果同时左右运行两个 App，这两个 App 可以维持基本相同的长宽比，也就是说 Pixel C 的屏幕是很适合分屏使用的，因此 Pixel 在软件上没有分屏功能显得有些不可思议。

最好的安卓平板也和生产力没多少关系

随着 Pixel C 的上市，苹果、微软和谷歌这三家全球最大的科技公司都拥有了自己设计的平板电脑，不过和前两家公司不同，谷歌并不在意 Pixel 系列产品的销量，这一点从 Chromebook Pixel 和 Pixel C 的定价上就能看出来。

谷歌希望 Pixel 系列可以成为同类产品的标杆，所以他们做出了 Pixel C 平板，而 Pixel C 的确可能也是目前最好的安卓平板，但由于不完善的软件生态，最好的安卓平板依然不是一款优秀的平板电脑，简单的给它加上一个外接键盘也无法把它变成一台真正的「生产力工具」，外媒 The Verge 最后这样评价 Pixel C:

「谷歌的 Pixel 团队设计了出色的硬件，但安卓团队却没有给它装上足够优秀的软件，安卓系统可能并不是谷歌眼中的下一代平板操作系统，或许谷歌未来会把 Chrome OS 和安卓系统融合起来，创造出一个真正优秀的平板操作系统。平板计算的未来还没有真正到来，所以我还是决定买一台 iPad。」
