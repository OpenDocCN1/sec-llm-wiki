# 给每条资讯打包，全世界都变得井井有条＃iOS｜挖App

> 当我们把所有看到的消息都用「List」来展示，你就会发现就算再多资讯都是那么「有理有条」……

*「挖App」是极客公园的一档App体验栏目，每天为大家发现一些国内外新奇、好玩的手机应用。*![](../Images/9a586e8b97b0d7e8423d288c872fd8d8.png)清单应该算是帮助我们整理思路、更好表达的最有效方式。生活里我们都很喜欢在各种不同的情景里列出各式各样的「List」，关于购物、代办事项、旅游、美食、生活…… 清单似乎可以把一切都变得井井有条。那，想过当把「List」这样的形式结合到社交中去会是什么样、会变得很有意思吗？带着好奇心，来看看下面这款应用就会知道了。

「The List App」就是这样一个将「List」贯穿始终的社交应用，在这里用户发布的所有消息都会是以清单的形式展现，同时好友的所有消息也是一样以列表的形式发布出来，通过它，用户们可以用一种全新的方式开始一段聊天。

## **原来 List 可以用来玩逻辑、资讯、吐槽……**

首先，「The List App」的界面其实和大多数的社交应用差别不大，**整体给人的感觉就像是一个特别版的 Twitter**。主要的界面也类似地分为了「Home」、「Discover」、「Notification」以及「Personal」个人主页。

![](../Images/1a5b3c1b3338653b3ffa1fcae6a6d6e0.png)

在「Home」页中，用户看到的是自己所关注的好友发布的「List」，**在一开始并没有好友的情况下会先给用户推荐一些活跃用户**，**好让用户更快地了解这些「List」该怎么玩**。在这些推荐的关注里会有多种不同类型的，一共有「Featured」、「Trending」两类。

![](../Images/08b890c9a4f408de73e4f73bb7b63ffa.png)

通过「Home」页中的列表用户可以看到各种各样的信息，像是关注** The New York Times** 后可以看到**每天的重要新闻都会以列表的形式排列着一条一条展示出来**，或者一些用户从**生活中找出的规律**、**做某件事情的步骤**、**处理某些尴尬问题的建议**、**风趣的吐槽**、**给自己下决心的任务清单……** 等等，只要能想想到的文字表达，在这都会看到它们的「List」版本**，玩法很多，多的是有趣的用户。**

![](../Images/0bce2e6f807ad43c1f62e522a2c4530f.png)

## **细化单个信息，而不再是信息流**

面对资讯时代的信息洪流「The List App」一样选择了将信息分类细化，不过「The List App」不同的是将单个信息进行了规整细化，变成「List」的形式无形中让每条信息都具有了一定的条理性和逻辑框架，使阅读起来更加顺畅。

![](../Images/1246432615e9d3665cc4cf502808d92b.png)

在「The List App」中用户想要发布自己的「List」也不用担心梳理不出思路，通过主屏右上角的那个添加符号就能来到「List」的编写页面。这会以分栏填写的方式来辅助用户，第一栏是标题，然后是描述，最后的就是列「List」了。「The List App」为用户提供了两种「List」模式，**以圆点标识**或**以数字序号标识**；用户还**可以将自己的「List」设定为开放式**，即**每个人都能参与讨论，添加完善「List」**。并且除了文字外，「The List App」还支持添加图片和定位信息。

![](../Images/b84f025d9c7178421dfd295e82c691d0.png)

**总的来说，这样的「List」模式下资讯的获取变得很有趣，特别当阅读杂糅的大信息量资讯时，它帮助梳理逻辑的功能就更加凸显。**

以这样「List」的形式来进行阅读和资讯获取，不一定会有更高的信息获取速率，不过一定可以为你带来一种全新的资讯体验，就算海量信息，但每一条看起来都有理有据，井井有条。

这样「强行有逻辑」的方式，你愿意尝试吗？
