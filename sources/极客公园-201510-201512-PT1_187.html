电脑主机究竟可以有多小？

年初 Intel 推出的 Compute Stick 把电脑主机放到了只比 U 盘稍大的体积内，并且它还预装了完整的 Windows 操作系统，随后，联想、宏碁等厂商也推出了这类的「电脑棒」产品。不过由于体积和性能的局限，这类产品往往无法流畅运行 Windows 操作系统。

Intel Compute Stick （左）和华硕 Chromebit （右）

近日，华硕也推出了一款「电脑棒」产品 Chromebit，不同的是，Chromebit 使用了 ARM 处理器，预装了 Chrome OS 系统。

比U盘大一点的电脑主机

相比传统 PC 主机，华硕 Chromebit 显得非常娇小，它的三围只有 123 x 31 x 17mm，重量也只有 75g。Chromebit 的外壳材质为磨砂塑料，有黑色和橙色两种颜色可选。

Chromebit 的设置过程非常简单，只需要把它插到电视机或者显示器的 HDMI 接口上，再连上电源线就可以了。需要注意的是，Chromebit 机身上没有任何实体按键，接通电源后就会立刻开机。在 HDMI 连接器的另外一侧有一个 USB 2.0 接口，这也是 Chromebit 上唯一的接口。

如果你的显示器或电视机的 HDMI 接口在机身侧面，Chromebit 连接起来不会有丝毫问题，不过如果 HDMI 接口在机身后面的话，需要显示器或电视机距离墙壁有至少 25 厘米的距离，以容纳 Chromebit 和其他的 USB 设备。此外，你也可以使用华硕附送的 30 厘米的 HDMI 延长线，把 Chromebit 接到延长线上使用。

性能比想象中要好

华硕 Chromebit 采用了 Rockchip 的型号为 RK3288-C 的 SoC，最高主频 1.8GHz，这颗 SoC 采用了 28nm 工艺，处理器架构为 Cortex A17，GPU 为四核心 Mali T764，运行内存 2GB，并内置了 16GB 存储。

显然，RK3288-C 的性能无法和 PC 中常见的酷睿 i 系列处理器相比，不过四核心 Cortex A17 搞定轻量级的 Chrome OS 应该问题不大。

实际上，由于 Chrome OS 本身的原因，Chrome OS 并不支持像 Adobe Photoshop 或者 Premiere Pro 这种需要高 CPU 和 GPU 带宽的应用，使用更高的硬件配置并不会带来多少体验上的提升，反而会大幅提高价格。目前来看，华硕 Chromebit 选择这颗 SoC 是一个相对合理的选择。

在 TechRadar 编辑 Chuong Nguyen 的测试中，Chromebit 可以流畅播放 4K 视频，在打开多个 Chrome 网页，运行 Google Docs 并同时播放 YouTube 上的 60fps 4K 视频时，Chromebit 也基本可以保持流畅。

对比使用 Intel Atom 处理器的惠普 Stream 11，华硕 Chromebit 要稍微慢一点，不过这两者都要比 Intel 的 Compute Stick 快上很多。Chromebit 上的 Chrome OS 系统在系统启动速度上也有绝对优势，对比之下，Intel Compute Stick 的 Windows 系统感觉要花上一个世纪的时间才能启动。

最佳的「电脑棒」解决方案

通过预装 Chrome OS，华硕似乎找到了目前「电脑棒」系统的最佳解决方案，虽然 Chromebit 的 Rockchip 处理器理论性能一般，不过在 Chrome OS 上，Chromebit 的性能表现要比不少采用 Intel 处理器、预装 Windows 系统的「电脑棒」还要出色。

同时，由于 Chromebit 搭载了发热更小的 ARM 处理器，散热相对更容易控制，不需要使用额外的散热风扇。而且由于 Chrome OS 对本地存储的要求较低，厂商也不需要过多考虑本地硬盘速度和容量的问题。

除了像 Compute Stick，Chromebit 这种直接内置桌面操作系统的「电脑棒」，Remix Mini 这样搭载安卓系统的设备也可以实现类似的功能，Remix Mini 使用的 Remix OS 在安卓系统的基础上，大量借鉴了Windows 的特性，给安卓系统加入了传统桌面、开始菜单、任务栏等功能， 除了支持 ARM 处理器，现在Remix OS 正在进行对 x86 架构的适配。过不了多久，我们可能就会看到搭载 Remix OS 的「电脑棒」了。

对于家里有一台闲置显示器的用户来说，Chromebit 是一个完美的解决方案，对于中小企业来说，Chromebit 也是一个非常值得考虑的选择，当几年后需要更新电脑时，只需要拔下来 Chromebit，换上搭载更新的「电脑棒」即可，可以大大降低升级硬件的成本。

当然，由于运行 Chrome OS，Chromebit 使用时仍然需要科学上网。
