# 墙内开花墙外香？看外媒如何评价一加 X

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=401427328&idx=2&sn=3df5abf3529171d2dbe2d81cc19f5d03&chksm=f7983636c0efbf20e7ff3e0fea9555a57f5aeac15a4185aa3389f91249f3483144575fe5e5b8&scene=126&sessionid=1681311666#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=401427328&idx=2&sn=3df5abf3529171d2dbe2d81cc19f5d03&chksm=f7983636c0efbf20e7ff3e0fea9555a57f5aeac15a4185aa3389f91249f3483144575fe5e5b8&scene=126&sessionid=1681311666#rd)

由于在使用习惯、软件生态等方面存在很多差别，同样一款产品在中外科技媒体中获得评价往往有很大的差别。  

具体到智能手机，外媒普遍偏爱接近原生安卓的操作系统，对国内一票「类 iOS」安卓则不大感冒。**国外媒体对价格的概念和我们也有很大的不同**，在大多数外媒眼中，300 美元（约 1916 元）也还是「budget smartphone」（廉价智能手机）。此外，欧美地区的 LTE 制式比较复杂，能不能支持最常见的 LTE 频段也是一个重要的考量因素。

![](../Images/98987a85685dcd64a3dbefc4047379a8.png)

一加 X 是一加在上个月底发布的一款「轻旗舰」，配备双面弧面玻璃，**金属边框**，高通骁龙 801，2GB / 3GB 运存，国内售价 1499 起，需要注意的是，国内的一加 X 预装氢 OS，国外版的一加 X 则预装接近原生安卓的氧 OS。

一加 X 推出后引发了不少的争议，很多人吐槽它价格昂贵、系统难用，同样一款手机，各家外媒又是怎么看的呢？

## Ars Technia：上一代旗舰手机依然足够出色

一加Ｘ现在依然很难买到，如果你可以幸运的买到它的话，绝对是一笔超值的买卖。花 249 美元，你就可以买到一部做工出色同时性能优异的智能手机。软件方面，我们非常喜欢一加保留原生安卓元素，只增加一些额外功能的做法，如果一加的软件更新可以更快点就好了。

一加Ｘ并不支持美国地区的所有 LTE 网络，再加上老旧的 Wi-Fi 芯片以及不支持 NFC，一加 X 在网络连接上有所欠缺。我们可以花 210 美元在亚马逊（美国）购买到和一加 X 配置相近的 Nexus 5，Nexus 5 的摄像头不如一加 X，但是支持 LTE Band 12 同时软件升级更快。当然，我们还可以花 180 美元购买第三代 Moto G，但它只配备了骁龙 410 处理器和 720p 分辨率的屏幕。

249 美元很难买到一款精美的智能手机，一加 X 的价格虽便宜，但却不会让你感到廉价，我们很喜欢一加 X，只是它现在太难买到了（一加 X 在我国并不缺货……）。

## UberGizmo：一加 X 太超值了！

![](../Images/8d037cb35fb8bc6b6c0aa1f58a163f8c.png)

一加再一次证明了一款手机的性价比可以有多么出色，从硬件上来看，一加 X 基本就是 2014 年的旗舰手机，从设计上看，一加 X 好于 2014 年绝大多数智能手机，249 美元的定价让一加 X 拥有极高的竞争力。

邀请购买机制让购买一加 X 变得有些麻烦，而且一加在美国也没有实体店可以让顾客亲自体验手机，不过如果有机会的话，我强烈建议你试一下这部手机。

## TechnoBuffalo：可以原谅一加 X 的不完美  

优秀的廉价手机是一加的标签，虽然一加 X 并不是这家公司最强大的产品，但可能是一加最重要的产品。大概两年前，这家来自中国的手机公司通过一款超高性价比的手机（一加手机 1）震惊了手机市场，一加 X 延续了这种策略，而且价格更便宜（250 美元）。

一加 X 远不是一款完美的手机，它不支持美国几个重要的 LTE 网络频段，也不支持 NFC，这两点都足以很多消费者望而却步。我非常期待下一代一加 X 手机，经过少量的修改后，一加 X 完全可以成为一加最重要的产品，即便它没有搭载最新的硬件。

如果你想买一部低价手机，我强烈推荐一加 X，只是提醒下你可能无法获得稳定的 LTE 连接，不过考虑到 250 美元的价格，我们似乎可以原谅一加 X 的某些不完美。

## Android Authority：年度最超值智能手机之一

一加 X 拥有出色的做工和优秀的硬件，考虑到它的价格，一加 X 可能是一加迄今为止最超值的产品。

我们认为一加 X 是一部很棒的手机，但是必须要加上「考虑到价格」这个限定词。由于采用上一代的硬件，一加 X 的生命周期可能不会很长，对于在美国使用 LTE 网络的用户来说，一加 X 的网络支持是个不小的问题。但就现在来看，一加 X 是我们今年见过的最超值的智能手机之一。

## ZDNet：软硬件都令人印象深刻

一加 X 预装了氧 OS（国内版预装氢 OS），氧 OS 很接近原生系统，运行流畅，也没有垃圾软件。

![](../Images/b92959eb3979c04fbdc14767c62ee089.png)

一加 X 是一部非常优秀的廉价安卓手机，我们对这部手机也没有太多可以抱怨的地方。我们希望一加可以给一加 X 的触摸按键加上背光，一加 X 虽然支持双 SIM 卡，但如果你想插 microSD 卡，就不得不占用一个 SIM 卡槽。

以上这两点都不是什么大问题，无论是软件还是硬件，一加 X 都是一款令人印象深刻的产品，如果你只有 200 英镑的预算，一加 X 绝对值得你好好考虑。

**从外媒的评价可以看出，相比国内，一加 X 在国外的争议要小很多，除了 LTE 频段支持不完善之外，一加 X 还是比较符合欧美人的使用习惯的，在中国稍显昂贵的售价放在欧美地区依然很有竞争力，大家怎么看一加 X？**
