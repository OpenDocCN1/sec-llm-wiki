# 指望 Lumia 950 来拯救 WP？似乎不大靠谱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=401356741&idx=3&sn=b7c03ac11c500d085fe03c100944f24b&chksm=f7994a73c0eec3654914c6596cc709236ab37eaa52b2be8d734d03b2d0f3130440a25fadbf7e&scene=126&sessionid=1681311666#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=401356741&idx=3&sn=b7c03ac11c500d085fe03c100944f24b&chksm=f7994a73c0eec3654914c6596cc709236ab37eaa52b2be8d734d03b2d0f3130440a25fadbf7e&scene=126&sessionid=1681311666#rd)

聊产品前，我们先看几个数字：根据上周三 Gartner 发布的智能手机市场数据，2015 年第三季度，Windows Phone 手机的销量为 587 万部，其中 Lumia 手机 580 万部，市场份额仅为 1.7% ，销量和市场份额都比去年同期大幅下降 (销量 903.3 万，市场份额 3.0%）。  

**距离上一款 Windows Phone 旗舰手机 Lumia 930 发布已经过去了接近两年的时间，这在「苹果一年双旗舰，安卓月月有旗舰」的背景下是一件不可思议的事。**与此同时，随着微软推出 iOS 和安卓版的 Office 办公套件，Windows Phone 在办公软件上也不再拥有独占性优势。

在这种背景下，Lumia 950 和 950 XL 来了，这两款手机搭载了目前市面上最出色的硬件，也是第一批运行 Windows 10 移动版系统的手机。Lumia 950/950 XL 是不是微软的诚意之作？我们看一下来自各家外媒的体验。

## 外观廉价，售价高昂

![](../Images/66d345b7cf19abf2fc71ae4f13336401.png)

从外观上看，Lumia 950 是一款很乏味的产品，它有明显的塑料感，缺乏设计特色，可能更糟糕的是，Lumia 950 看上去和微软过去几年推出的众多廉价 Lumia 手机没多少区别。说得好听点，Lumia 950 保持了设计的延续性，说的不好听，Lumia 950 看起来很廉价。

不过 Lumia 950 并不廉价，Lumia 950 在美国的售价高达 600 美元，比 Nexus 6P 贵上很多，只比 iPhone 6s 稍微便宜一丁点。Lumia 950 配备了高通骁龙 808 处理器（Lumia 950 XL 为骁龙 810），3GB 内存，32GB 存储，支持 microSD 卡，3000mAh 电池，内置无线充电且支持快速充电，5.2 寸 2K AMOLED 屏幕，是 2015 年底中高端手机的标准配置。

## 优秀的摄像头，但不再独一无二

摄像头一直是 Lumia 的重要卖点，Lumia 950 的相机也没有让人失望。Lumia 950 搭载了 2000 万像素的摄像头，配备光学防抖和三色温闪光灯，支持 4K 视频拍摄。外媒 Ars Technia 对 Nexus 6P、iPhone 6s Plus 和 Lumia 950 进行了实拍样张测试，Lumia 950 在多数测试中排名第一，最差的也是排名第二。另外，Lumia 950 的拍照速度非常快，没有 Lumia 1020 上那种卡顿的感觉。

![](../Images/8c9b46cfb523bd8ebdbe01dad3ee50d6.png)

Lumia 950 相机的问题并不是相机本身。一两年之前，如果你非常在意手机摄像头的成像品质，Lumia 是一个无法被忽略的选择，即便它的系统不好用。但现在市场上已经有很多手机拥有出色的摄像头，即便 Lumia 950 的摄像头依然非常出色，但它已经无法像 Lumia 1020 那样傲视群雄。

## Windows Hello 不好用

既然硬件很无聊，相机也没有明显优势，Lumia 950 的成败只能依靠软件了。微软花了好几年的时间试图去统一智能手机、平板电脑和 PC 平台，Windows 10 就是它的终极作品。

![](../Images/2417955b3fd3623065d6f5a2d85991df.png)

不过虽然内部代码和 PC 相同，Windows 10 的操作界面和 Windows Phone 8.1 没有多少区别。在 Windows 10 上，动态瓷砖、字母顺序排列的 App 列表、乏味的过度动画都还在，如果你不喜欢 Windows Phone 8.1，你也不会喜欢上 Windows 10。

Lumia 930还支持 Windows Hello，用户可以通过看手机登陆系统，这个功能看起来很炫酷，识别率也不错，但是识别速度有些太慢。使用时还必须把手机放在距离脸很近的位置，走在路上使用是一件很尴尬的事情，外媒 The Verge 在 Lumia 950 上体验过 Windows Hello 后表示：「使用 Windows Hello 还不如直接输入密码来的快，比指纹识别的速度差的更远。」

## Continuum：手机还变不成 PC

真正让 Lumia 950 和 Windows 10 区别于 iPhone 和安卓手机的是 Continuum 功能，理论上，Continuum 可以把手机变成能实现近乎完整功能的 PC。

![](../Images/9c451ddae0d929b4184c8aae55128f1e.png)

*微软 Display Dock *  

要实现 Continuum，用户需要额外花 99 美元购买微软的 Display Dock 或者是一个支持 Miracast 的转换头，一个鼠标和键盘（蓝牙和 USB 都可以），以及一个外接显示器。外接显示器上显示的不仅仅是手机屏幕的放大版。Continuum 会识别出外接显示器的尺寸和分辨率，然后显示出一个包含开始菜单和动作中心的 PC 桌面。外接显示器上的任务和手机完全独立，你可以一边在大屏幕上播放电影，一边手机上处理邮件。

![](../Images/134b2999f8f69d7158bc94050752bea7.png)

在 Continuum 中，Office 办公套件，Edge 浏览器等 App 会自动适应大屏幕，使用体验非常接近 PC，用户还可以通过 Alt-Tab 在 App 之间切换。Lumia 950 的性能可以搞定大部分操作，不过在使用 Edge 浏览器时会感觉到性能有些不够用，如果打开很多标签，Edge 浏览器会变得很慢，网页会经常地重新载入。Continuum 最大的问题是支持的 App 实在太少了，绝大多数还是微软开发的，目前支持 Continuum 的第三方 App 数量可以忽略不计。

The Verge 编辑 Dan Seifert 这样评价 Continuum :「我并不觉得带着一大堆 Continuum 配件比带一部笔记本电脑方便多少，况且现在 Continuum 实现的功能比起笔记本电脑还要差上很多。可能有些企业会认为 Continuum 是一个完美的「瘦客户端」解决方案（员工可以通过一个手机来完成所有工作），但对于大多数人来说，Continuum 还没有多少实用价值。」

对了，Windows 10 也没有解决 Windows Phone 最大的问题——第三方 App。这句话我们已经说了好多年了，不过现在依然没有任何要解决的迹象，Windows 平台的 App 数量和质量比 iOS 和安卓依然有很大差距。

## Lumia 950 能不能拯救 Windows Phone？

![](../Images/ca2ad9a3754782e0455b277c8b180ebc.png)

**The Verge：微软不在乎 Windows 手机的市场份额有多低**

微软非常清楚它在移动操作系统上面临的巨大挑战，从发布会上象征性地展示以及明显不够用心的 Lumia 950 中，微软在移动操作系统上的策略也表现得越来越清晰：Nadella（纳德拉）领导的微软并不在乎 Windows 在手机中的市场份额有多低，而是把更多的精力放在吸引用户使用它的 App 和服务上。和几年前不同，现在我们在其他平台上也能体验到微软的产品和服务。

如果你指望 Lumia 950（以及 950 XL）可以解决之前 Windows 手机上的所有问题，你可能要失望了。不过对于大多数人而言，我们会非常乐意在 iPhone 上通过 Outlook 来管理邮件（编者注：The Verge 把微软 Outlook 评为 iOS 上最优秀的邮件 App）。

**CNET：微软的智能手机之路会越走越难**

我相信依然会有几个人愿意购买 Lumia 950，Lumia 950 的硬件还不错，我也喜欢 Windows 10 在视觉上的升级（虽然幅度很小）。Continuum 是一个不错的想法，但是问题太多无法在日常使用，在软件生态方面，微软距离 iOS 和安卓越来越远。总体来看，我实在找不到花 600 美元购买这款手机的理由。

在我看来，相比 Lumia 950，三星 Galaxy S6，华为 Nexus 6P 和 Moto X Style 都是更好的选择，后两者的价格还要更便宜。看到微软这样的表现我也很心塞，但微软的智能手机之路会越走越难。

**Ars Technia：并不是微软亟需的产品**

我认为 Lumia 950 的虹膜扫描仪是个错误，微软应该使用体验更出色的指纹识别。尽管 Continuum 某些方面表现不错，不过它目前支持的 App 太少了，至少在现在，Continuum 不能成为你购买 Windows 手机的理由。

Lumia 950 和 950 XL 填补了 Lumia 手机高端产品线的空白，对于 Windows Phone 的粉丝（我是其中之一）而言，Lumia 950 可能是一款非常值得期待的产品。但是 Lumia 950 的价格过于昂贵，Windows 的生态圈也没有多少吸引力，Lumia 950 可以让 Windows Phone 避免倒闭的命运，但它可能并不会给 Windows 手机带来多少新用户。

**WSJ：它仅仅只是一部手机**

如果有一天，手机可以替代我们的个人电脑，我们会选择那些可以安装我们喜欢的 App 和服务的手机，也就是 iPhone 和安卓。即便是你非常依赖微软的 App 和服务，iPhone 和安卓手机上也都有了。

微软似乎想通过 Lumia 950 证明自己对个人电脑和手机的理解，但我实在找不到理由推荐用户花上 600 美元购买微软的这种概念。至少在现在来看，你的手机……还仅仅只是一部手机。
