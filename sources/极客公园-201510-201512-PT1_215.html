「Nvidia 芯」的手机为何越来稀有？答案在这儿丨科普向

说起 Nvidia，电脑玩家们都会想起 GeForce 系列显卡——一台电脑不配备 GeForce 系列的高端独显，都不好意思说自己的是游戏用 PC。但就是这么一家在图形处理芯片方面具有权威的公司，在移动处理器领域却不那么「顺风顺水」。

说到移动端处理器，大家首先会想到的是，高通，联发科，甚至是三星的猎户座和华为的海思。可还有多少人能记起来，划时代的第一款「双核」和第一款「四核」处理器都出自 Nvidia 之手。

从 Nvidia 初代作品说起

早在 2008 年之时，Nvidia 就以 Tegra 系列处理器进军移动端处理器。那时，还没有我们熟悉的 Android 手机。当时风靡一时的是，Windows Mobile 手机（简称 WM 手机）。Nvidia 将它在桌面端优势运用到了移动端，第一代 APX 2500 芯片内建 GeForce 核心，支持 OpenGLES 2.0 和 Direct3DMobile 标准。它还支持 720P 的 MPEG-4 与 H.264/MPEG-4 AVC 的解码。输出方面，它支持 HDMI 1.2 和双显示输出。

反观当时的高通，第一代处理器 MSM7225，在当时还没有搭载独立的 GPU 模块 Adreno。再看看与高通平分秋色的联发科，还在专注于山寨手机——2011 年底才发布了Android 智能手机平台 MT6573，正式进军智能手机市场。

可以说，Nvidia 的前景是一片光明的。这个时候，Nvidia 顺势推出了自己的移动端处理器品牌 Tegra。

在 CES2010 展会上，NVIDIA 发布了全新的 Tegra 2 平台，这是基于 ARM 核心的第二代 Tegra 平台。采用了最新 40 纳米技术的芯片的耗电量低于之前产品，双核 ARM Cortex-A9 CPU。

高通也拿出了自家的双核解决方案——那颗被机友所诟病「胶水双核」。之所以说它是胶水双核是因为它采用的是「异步双核」构架。所谓异步双核，是说两个 CPU 核心工作互相可以不同步，可以工作在不同的频率下。相对应的真正的双核是「同步双核」，两个 CPU 频率同进同退。

而「异步双核」更深层次上是意味着，两个 CPU 核心不能「同时」工作，而是「轮流」工作。就是说，这两个核心不能同时接受工作，而且必须你一次我一次地轮流接受工作。那么每当两个核心都空闲时，异步双核就会有一个核心至少闲置一个周期来等待分配任务，相应的同步双核却可以立刻同时投入到新的工作中去；或者当一个任务需要执行时，本该在这个周期接受任务的核心却还忙于上一个任务，这是另一个核心即使空闲也不能接受当前任务，那么又会闲置一个周期。

最后的结果就是，异步双核的效率不如同步双核。这一阶段，Tegra 2 这颗处理器让它名声大噪，不过 Nvidia 的时代也即将落幕。

高通时代：买基带送芯片

然而 Nvidia 在图形处理上的优势，并不是永远的。至少在接下来的「四核时代」，Nvidia 连续失好几城。Nvidia 大吹特吹的GPU和游戏性能，在Tegra3 时期，远远地被高通、三星等 SoC 甩在身后。

让我们看看 GlBenchmark 截图

第一颗四核 CPU 是 Tegra 没错，但这颗 CPU 从年初跳票到年中，上市之时，其性能还不如高通前一代的 Adreno 2XX 系列，之后高通 APQ8064 上市，其集成的 Adreno 320 GPU 已经全面超过 Tegra 3了。

再回到技术层面上——这次是指通讯技术。高通，作为在通讯领域深耕多年的老牌厂商，尤其是在 CDMA 技术领域，无人能出其右。此外，在通讯基带上面，需要投入大量的科研成本，用于调试各种不同的制式。在调试完成之后，还要考虑到手机功耗问题，再将之集成在芯片上面。集成本身就是一项重大的工程，现在只有高通能在集成和高性能上做出一个良好的平衡。

在手机处理性能过剩的今天，即使 Nvidia 在 GPU 上造诣精深，相对于高通也并没有任何优势。毕竟，手机的基础功能在于「通讯」上面，这恰恰是基带提供商高通所擅长的。也难怪会有「买高通的芯片，其实就是买高通的基带」这样的说法。Tegra 3 让 Nvidia 颜面扫地，曾经知名的芯片厂商沦为二线。

Nvidia：性能怪兽的曙光

在 BaseMark X 测试中，Tegra X1 的成绩为 56.9FPS，作为对比，苹果 A8X 为 40.2FPS，而 Tegra K1 则是 36.3FPS。

3DMark 1.2 版 Unlimited 模式中，Tegra X1 的成绩为 58448，作为对比，苹果 A8X 为 31781，而 Tegra K1 则是 36688。

GFXBench 3.0 Manhattan 1080p (Offscreen) 测试中，Tegra X1 的成绩为 63.6FPS，作为对比，苹果 A8X 为 32.6FPS，而 Tegra K1 则是 31.7FPS。

不拿最新的 iPad Pro 的 A9X 处理器作对比的话，目前 Tegra X1 配得上最强的移动处理器称号——毕竟苹果的 A9X 只为 iPad Pro 专供。

但即使 Nvidia 「屠龙有术」，却鲜有手机需要如此强劲的 GPU——对于大多数手机而言，它们需要的是稳定的信号，和够用的 GPU，而不是 Tegra 这样的图像性能怪兽所具备的。

不过 Nvidia 并没有放弃移动端处理器这个市场，它瞄准的是游戏市场（平板电脑）和车载市场。

这一点也不难理解，大多数平板电脑和车载终端对于通讯基带的要求并不高。由于大多数平板电脑都是作为娱乐之用，这对于芯片的图形处理能力要求很高；而车载终端对能耗控制并不敏感。这些都是 Nvidia 相较于其他移动端处理器的特点。

最近 Nvidia 又更新了自家的产品，Shield Table K1 虽然在配置上几乎没有变化，其激进的定价（$199）是 Nvidia 不会退出的最好证据。正是在手机 CPU 市场上的节节败退，才让 Nvidia 幡然醒悟。或许，在今后不久我们就能看见 Nvidia 芯片在汽车行业的可视化平台大展拳脚了。
