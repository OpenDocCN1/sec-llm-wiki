> **未来头条 —— 发现那些带来改变的，并在未来有希望带来更大改变的产品和产品极客。**

> > 2015年，极客公园最后一场未来头条系列活动，依旧要带给你不一样的惊喜，爱产品的你，一定不能错过！
> > 
> >   
> > 
> > **本期演讲核心提示：**
> > 
> > *   **洋葱**：离开 DNSPod 和腾讯之后，「奶罩」（吴洪声）再出发后的新创业项目。而这颗被创新工场汪华和小米雷军都看好的「洋葱」，会不会像 DNSPod 一样再一次推动行业进步？本想做个更好的「Google Authenticator」，但却在几经尝试后为产品找到了更好的出路。来听听他，一层层剥开这颗不容小觑的「洋葱」。
> >     
> > 
> > *   **弥财**：一个比利时人，想给中国正在崛起的中产阶级们，开发一个可以通过算法计算投资组合的理财服务平台，把专业理财服务的门槛降低，让理财本身更有效率，更有据可循。为此，他到长江商学院完成了创业「预科」，之后创立「弥财」。他能不能在 P2P 和各类宝宝们拼杀的互联网金融市场里，成功另辟蹊径？
> >     
> > *   **Rokid**：这可能是极客君目前见到的最靠谱的家庭机器人了。当机器人眼看着要成为下一个热热闹闹的创业高潮时，我们应该如何理性看待，又该抱有怎样的期待？Dan Wong，曾分别任 Nokia 和三星中国区副总裁，这位有着丰富的消费级电子产品行业和产品经验的老兵，会和我们聊聊他的理解。
> >     
> > *   **方橙**：想求租店铺却屡屡被坑？想招租却迟迟找不到靠谱的伙伴？方橙通过立体多维的数据一键式解决你的烦恼：哪些商铺在出租？不同城市最火的店铺是什么？目标人群有哪些？位置，面积，周边店铺品牌，客流量等基本信息更是一并囊括。搭建商业地产信息平台打通线上线下供需的产品理念，不失为一个可以尝试的方向，2015 年看厌了各种名不副实的 O2O 和互联网+，来看看这家公司如何加持「商业地产」。
