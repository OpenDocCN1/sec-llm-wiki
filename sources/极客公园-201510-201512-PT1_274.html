在成功的业务诞生前，往往夹杂着激情和混乱。


编者注：

本文故事内容基于《一网打尽：贝佐斯与亚马逊时代》整理而来。

在亚马逊今年第三季度的财报中，一改习惯性亏损状态，每股摊薄收益 17 美分。大大高出市场预期，股价大幅上涨逾 11%，达到历史最高。

最大的功臣则是亚马逊的 AWS（Amazon Web Services）云计算服务，其几乎与亚马逊整个北美市场的电子商务业绩持平。而这项带领亚马逊二次进化的服务却是在极其偶然的情况下产生的。

长期「故意」亏损让华尔街对亚马逊兴趣索然，谷歌成为了硅谷的新宠儿，「技术驱动的形象」闪闪发光。

亚马逊的 CEO 杰夫·贝佐斯（Jeff Bezos）却从没低下他标志性的脑袋，以轰鸣的笑声向短视的华尔街致敬，在他心里亚马逊就是一家技术公司，但这看起来都像是贝佐斯的一厢情愿，此时亚马逊的收银主要还是来自「网络商店」零售商模式。

A9 计划：亚马逊的证明计划

2003 年 10 月亚马逊的第一个研发中心在帕罗奥图市（Palo Alto）中心成立，被命名为 A9（algorithms 算法单词的缩写）。

贝佐斯将这个证明计划压宝在了 A9 部门上，A9 不仅致力于改造亚马逊网站上的产品搜索，而且还向谷歌发动了直接攻击，他们在和谷歌合作的基础上还开发出了一款通用的网络引擎。

这项计划的负责人是乌迪· 曼博（Udi Manber），他拥有华盛顿大学的计算科学博士学位，并出版了引起硅谷行家关注的权威性著作《算法导论：一种创造性方法》，同时拥有在雅虎鼎盛时期工作的经验。

A9 赋予了曼博一个自由的舞台，他可以在这里尝试大胆的想法，其中大部分都与亚马逊的核心业务没有关系。

这样的自由空间带给了他们一些惊人的创意，例如在 A9 的搜索结果上自动匹配相关的商店信息和餐厅所在街道照片，这正与谷歌两年前宣布谷歌街景有异曲同工之妙。

开设了一个名为 Clickriver 的广告服务，允许广告商购买亚马逊网站搜索结果链接，随后这项业务成为了大量收入来源。

曼博的团队专注于搜索引擎引发的抽象问题，而此时亚马逊的网站正在遭受由于数据延迟造成的长时间搜索等待问题。

和曼博搜索技术相辅相成的搜索引擎部门变得沮丧。

和远在帕罗奥的 A9「小分队」不同，在西雅图亚马逊总部要负责个性化、自动化商品、公关、电子邮箱营销部门以及搜索引擎部门的 500 多名员工。

感到无望后西雅图内部开始进行自己搜索引擎开发，他们想要使用开源工具 Lucene 和 Solr 重建亚马逊的搜索引擎服务，几个月后向贝佐斯展示了原型产品。

外地作战的曼博觉得受到了内部的突袭。

当年一月谷歌一位老员工在帕罗奥图的一家餐厅私人房间为曼博设宴，但就像是预设好的程序，在吃饭时谷歌联合创始人谢尔盖·布林加入了这场私人饭局，更佳戏剧性的是，谷歌 CEO 施密特在吃甜点的时候出现了。

二月曼博收到了成为谷歌搜索团队负责人的邀请，与世界上顶尖算法工程师一起工作的诱惑实在太大，一场漂亮的全场紧逼掐掉了 A9 的伟大计划。

曼博离开一年后，A9 计划开发的通用搜索引擎关闭，分区视图被谷歌街景并购。

极其偶然地迈上成功之路

在 2002 年图书出版商奥赖利（Tim O` Reilly）向贝佐斯展示该公司发明的一个复杂工具——Amarank，可以每隔数小时访问亚马逊并复制奥赖利出版公司的书籍及其竞争对手书籍排名。

奥赖利建议亚马逊开发现在看来常见的 API 接口，这样第三方就能很方便地获取其价格、产品和销售排名数据。奥赖利叙述了自己对亚马逊未来的设想：第三方可以将亚马逊上的书店进行打包分配，甚至建立其自己的网站。

贝佐斯被这个想法打动了，或许这是让亚马逊成为技术公司的新途径，立即将这个想法传递给几位主管。

有趣的是在亚马逊内部已经进行了类似的研究，一名名叫罗伯·弗雷德里克（Rob Frederick）的年轻工程师正在设计上述的 API，其允许手机等移动设备访问亚马逊网上商店。

在贝佐斯的推动下，一套更丰富的 API 接口被设计出来，其他网站可以根据亚马逊的目录展示出产品的价格和说明，并且可以接入亚马逊的支付系统和购物车。

当年的春天在亚马逊举办的第一次开发商会议上，亚马逊邀请了所有企图破解亚马逊系统的外界人士，正式介绍了这项刚命名为 AWS 的服务。

现在的媒体报道中，创始人作为公司的灵魂被赋予了太多的光环，而随着公司规模的增长，创始人在业务层面的贡献会逐渐降低，他们会失去一线员工敏锐的嗅觉，甚至决策时前后矛盾。

身处正高速成长的创业公司，你会发现一些逆转局势的想法正是来自于和你一样每天忙得晕头转向的普通员工。

对于创始人来说需要做的是向贝佐斯一样制定成为一家科技公司的战略，为此鼓励更多创新甚至是制造混乱，而满怀抱负的你，则需要像罗伯·弗雷德里克那样，不被公司的混乱所干扰，在时机来临前留在亚马逊。
