我用这个「安卓机顶盒」攒了台近似 Windows 体验的迷你电脑

Remix Mini 与普通的电视盒子看起来没什么区别，不过一旦接上显示器，你一定会发出「什么鬼！」的感叹。


最近从同事那里收了一台二手显示器。一方面是为笔记本换个大屏幕，更重要的原因是为了好好体验一下 Remix Mini——一台运行高度定制的 Android 系统，能够获得部分近似 Windows 操作体验的「迷你安卓电脑」。

从外观和接口来看，Remix Mini 与你家里的电视盒子没有太大区别。唯一比较特别的地方在于它正面的 Logo 其实是一个触控开关，不过我还没有习惯它，经常误操作。

接上显示器就会发现 Remix Mini 的特别之处：开机后你会看到一个 Windows 式的桌面，甚至还有「回收站」这样的图标，而底部任务栏和通知栏的设计也让人怀疑这到底还是不是 Android 系统。

Remix Mini 所运行的 Remix OS 「借鉴」了很多 Windows 的特性，它的出发点是让 Android 系统更加适合在大屏幕上使用。对于这样一款系统，你可以把它当成一个「畸形」去看待，当成又一个「然并卵」的产品，但我真正体验后觉得它还是有很大的潜力。

无限「拟真」 Windows 的操作体验

最早接触到 Remix OS 其实是通过 Remix 自家出品的平板。这款产品由于外观跟 Surface 太过于相像引起了一些争议。不过从整个系统体验来看，它确实是我用过最舒服的 Android 平板。

这个「舒服」来源于「窗口模式」下多个应用窗口可以并列显示；来源于「任务栏」式的系统后台可以方便地切换、关闭应用；来源于 control+v、Alt+Tab 这些熟悉的 Windows 快捷操作。Remix OS 以并不复杂的方式解决了 Android 平板适配不同应用分辨率的问题。大屏优化这件事为什么 Google 自己没有做呢？

▲Remix OS 1.5 截图

通过融合 Chrome OS 和 Android 系统的优势可以获取更加丰富的用户行为数据，为广告主提供更加精准的投放。但从用户体验的角度出发为大屏幕定制 Android 系统，或者开发一款真正桌面系统并不能获得更明显的收益提升，这也给 Remix OS 这样的修改系统留下了发展空间。

有意思的是，Remix OS 的设计团队技德科技的联合创始人&CEO 周哲是谷歌第 103 号员工，负责开发了第一代 Google 广告 60% 的代码，并先后参与了 PRC 和 Google Talk 等产品的开发，另外两位联合创始人也都有过在 Google 任职的经历——浓重的「Google 基因」也为 Remix OS 增加了不少说服力。

过去的几个月，Remix OS 从 1.5 升级到 2.0，Remix Mini 也顺理成章地成为首款搭载新系统的设备。这「0.5」的变化可不是简单的升级——如果说 Remix OS 1.5 仍是一款针对平板优化的 Android 系统，同时加入了一些 Windows 的习惯操作；那 Remix OS 2.0 则是去无限「拟真」 Windows 的操作体验，朝着生产力工具的方向发展了。

▲Remix OS 2.0 的桌面

Remix OS 2.0 用一个「以假乱真」的 Windows 桌面取代了 Android 系统「x 宫格」式的桌面，而应用列表隐藏到了左下角的「开始菜单」里，你可以通过拖动把它们的快捷方式放到桌面上，也可以在桌面上创建文件夹，鼠标的右键操作也得以保留。

除了模仿 Windows ，Remix OS 在很多高频的操作上也有自己的思考。我经常从「截图」功能来入手去观察 一个系统的交互逻辑。在 Remix OS 系统里，你可以从通知栏的开关或键盘的「PrtSc」呼出截图工具，点击不同的窗口或手动拖动就能控制截图的范围，点击即可保存到相册，就像使用 QQ 截图工具一样简单。

不过问题依然存在：既然有了 Windows，为什么还需要这样一款系统呢？答案或许是 140 多万的 Android 应用。

大大降低拥有 PC 的门槛

「回想一下在生产力场景中，PC 还存留的优势是什么——更贴近使用习惯的系统操作方式。劣势呢——大众对应用所产生的认知变化」，「未来是属于 apps 的，而非 .exe」，这两段话来自于 Remix 的宣传手册，我也很认同。

每次回家我都要帮父母把电脑上各种「流氓软件大礼包」卸载掉，但是他们却特别强调要把「360 安全桌面」留下——它简化了电脑软件的安装步骤，并将它们以 app 的形式展现出来，相比传统的 Windows 桌面，它的操作更像早已熟悉的手机和 iPad。

如果给父母们配置好 Remix Mini ，他们可以根据不同的需求直接寻找对应的 app，而 Remix OS 的应用商店是与豌豆荚进行合作，这也可以有效避免他们乱装软件「中招」，还是能给我们省不少心的。

如果你的工作不需要一天都盯着电脑，很多时候打开它们只是为了刷刷微博，看看视频。而很多欠发达地区的人群需要一台电脑更多的是为了上网、聊天等简单的操作，这些 Remix OS 都能很好地完成。键鼠、显示器加 Remix Mini 组成的「安卓电脑」会大大降低拥有一台 PC 的门槛，丰富的 Android 应用资源也能满足不同人的需求。

我们无法用平板去很好地办公，因为很多生产力场景中并不适合触控的操作，Remix OS 结合了 PC 上的操作方式，同时拥有以 Android 的应用生态资源，简化了原本 PC 上需要的装软件的操作步骤。

▲Remix OS 1.5 截图

但我认为 Remix Mini 目前这样的设备不会成为你的主力电脑，Remix OS 目前也无法让你脱离 Mac、Windows 去办公。但是它提供了一种成本较为低廉的「Android PC 」解决方案，让原本很多「大材小用」的工作变得简单起来，让普通的电视、闲置的显示屏也能变成一个智能设备。

为普通的显示器「装入系统」

尽管 Remix Mini 可以作为电视盒子使用，甚至可以绕开广电总局对盒子类产品的诸多限制，但是对于鼠标和键盘的高度依赖以及遥控器的缺失，让它更适合搭配显示器使用而不是电视。既然这样，有没有可能直接把 Remix OS 装进显示器里呢？

事实上，技德科技正在与 ViewSonic 、AOC 等显示器厂商进行合作，尝试把 Remix Mini 这样硬件的植入到显示器内，让普通的显示器变成一个自带操作系统「智能显示器」——插上键盘鼠标就能满足许多轻量化的办公需求，而这个成本并不会增加很多。

相信你也在街上见过大屏幕宕机的画面——一个经典的 Windows 蓝屏。其实很多广告、公共信息的展示屏幕背后都有一个落满了灰尘的电脑主机，而这些并不重度应用场景使用电脑还是很大材小用的，其实一台运行 Remix OS 的主机就能很好地完成这些工作，操作上几乎没有任何学习成本。

除了显示器、大屏幕，未来投影仪也可以植入 Remix OS，插入 U 盘就能直接播放里面的内容了，不需要再通过手机、电脑去调节。 Remix OS 的潜力在于，它可以把普通的显示设备变成一个多媒体工具，一个轻量级的生产力工具，能用更低的成本完成一些原本需要电脑来进行的工作。

「运行在电脑端的 Remix OS 安兔兔轻松就能跑十几万分」，根据技德科技 CEO 周哲的介绍，目前 Remix OS 已正在进行对 x86 架构的适配，这意味着未来上网本也能运行这样一个「轻便」的系统了。你也可以把它安装到 U 盘里，变成一个名副其实的口袋系统——这又为 Remix OS 增加了更多的想象空间。

在我几天的体验中，发现 Remix OS 2.0 还存在很多需要改进的地方。比如桌面分辨率经常修改失败，无法调节鼠标的灵敏度，有时会出现应用假死的情况等等。但是确实已经能从 Remix OS 2.0 上看到了不小的潜力和技德科技想要做「Android PC」的思路。

未来有很多大屏幕都可以利用 Remix Mini 这样的设备去驱动，而 Remix OS 2.0 这么一款更适合 Android 大屏幕运行的系统，没准就真让这家公司做成了。
