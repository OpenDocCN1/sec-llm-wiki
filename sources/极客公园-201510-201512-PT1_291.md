# 微软想告诉你，马教主和尔康在咆哮时到底是什么心情

> 微软开发了一款应用告诉你，马教主在咆哮的时候内心其实有点兴奋，还有点恐惧；而尔康则非常淡定。

![](../Images/43872382bfe41cab4a43120ff59caeea.png)  
对于微软公司的**牛津计划 (Project Oxford)**，很多人可能不太熟悉；但如果说起上半年非常火的**「用照片猜年龄」**的应用 How-Old.net，很多人就会恍然大悟了，这个分不清同龄的郭德纲和林志颖年纪的好玩儿应用就是这个团队做出来的小应用。

![](../Images/a8bcbd7629b37b023e7a394ab968047d.png)

而昨天，这个专注于人工智能领域的团队宣布，他们已经开发了一款专注于情绪识别的技术，利用**面部识别技术**，它可以从你的照片当中读取到你当时的情绪，难道连情绪也无法隐藏了？

## **像猜年龄一样猜情绪**

使用这个功能很简单，如同猜年龄的 How-Old.net 一样，用户只需将照片上传至此网站（https://www.projectoxford.ai/demo/emotion#detection），系统就会自动使用面部识别软件和人工智能技术，情绪识别引擎将会计算出照片中的人可能涉及到的八个可能的情绪值，八种情绪分别是：**愤怒**，**厌恶**，**蔑视**，**恐惧**，**快乐**，**中性**，**悲伤**和**惊奇**。

来看看马教主马景涛在咆哮是内心的情绪是怎样的：

![](../Images/0810805db37403dd7bd4583f46a4310e.png)*▲我们可以看到，马教主此时当然是愤怒居多，然而微软很敏锐地抓到了其中一丝的恐惧和莫名的兴奋*

根据微软自己简单的解释，**系统会根据它在训练过程中接收的一系列照片归纳出一些识别情绪的要点，然后它会根据这些点判断人的情绪**。

有了这个有趣的应用，程序员们可以想一些有趣的主意了，比如可以设计一个 App，根据女朋友开心的程度去**将照片排序**，这样你可以只选择看女朋友的笑脸而非生气时的脸；或者你也可以设计一个浏览器插件，根据这个技术选择**过滤掉网页中那些不开心的照片**。这些都看我们程序员朋友们脑洞能开多大了。

而且，虽然这个应用看起来比较奇葩，但其实不管是在科技上还是在商业上，这都是一个值得关注的新产品。比如一些商业研究机构就可以根据这样对用户面部情绪的分析，得出很多值得注意的问题。

![](../Images/d248121d1d0f13d2e99cfbb033879502.png)

*▲尔康的这个明显不准嘛。。。连我这个蓝孩纸都感受到了其中的愤怒，它竟然告诉我是中性的*  

这个应用主要运用的是微软牛津计划的** API(application program interface)** 技术，之前的 How-Old.net 也用的是这个技术。同时，与此同时，牛津计划还公布了其他几个相关的小应用，比如可以在视频中追踪面孔的应用，以及还有监测个人讲话声音的应用。不过这些应用都还是初级阶段，后续的开发值得继续关注。

## **牛津计划非常「牛」**

牛津计划是微软公司在去年春天推出的、主要关注于人工智能和机器学习领域的一个计划。在在其中文介绍中，其官方的专业介绍是「提供一组基于 REST 架构的 API 和 SDK 工具包，帮助开发者轻轻松松使用微软的自然数据理解能力为自己的解决方案增加智能服务。」由于微软投入了大量的关于人工智能方面的研究力量，并拥有强大的数据计算能力，因此，开发者们可以在微软的帮助下做到许多他们自己无法做的事。

![](../Images/8b5a9aff30a26bb430b34c516eac8d0c.png)

在一些媒体看来，虽然如同猜年龄一样，这也只是一个很小的应用，但这代表了微软的一个发展方向。在不久之前，微软 CEO Satya Nadella 就说过，他想要在个人电脑的**人机交互方面创造一种新的方式**，而这一系列的应用为我们展示了一种初步的构想:在可以了解用户的情绪之后，机器如何同用户进行进一步的交流会是大家下一步的期待。

## **发展潜力很大**

当然，目前这个应用还无法像真人一样完全识别出人的情绪（当然，从某种程度上说这也是不可能的），但是它的发展潜力非常大。微软剑桥研究院的负责人 Chris Bishop 就展示了这个工具如何在同一时刻追踪多个人及多种情绪。而微软自己也希望那些专长不在人工智能领域的开发者们可以利用这样的技术去融合进自己的产品当中去。这当然也是我们用户所期待的。
