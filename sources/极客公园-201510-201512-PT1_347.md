## 前言  

键盘和鼠标几乎每天都在用，我们好像已经离不开它们了，这些已经让我们习惯了的工具，就像那些「靠谱的老办法」，但要想拥有更高的效率，就需要来尝试一些特别的新工具。

从手机键盘到触摸操作的体验相信大家已经感受到便捷之处了，但从「二维触摸世界」切换到立体的输入方式依旧会成为主流吗？之前极客之选也介绍过 Leap Motion 这样的设备，体验都很新奇，今天就再看一款可穿戴的手势输入设备 Gest 能否俘获你吧。

![](../Images/45c2dbfa3e0b99caf62dfeafbd92e48f.png)

## 概览

Gest 是一种可穿戴的设备，可以让你用双手控制你的的计算机或移动设备，未来也会发展成为虚拟现实的控制设备，先通过短片了解一下吧：

## 功能&特点

Gest 可以让你用双手以一种更直观的方式工作。简单的滑动手指，就能够在应用程序之间进行切换；伸出一个手指左右移动就可以控制鼠标；扭动手掌便能在 Photoshop 中调整滑块；你甚至可以抓住你的 3D 模型，旋转查看它。

![](../Images/41503931ad392a1e96adf47affa335be.png)

Gest 是操作电脑等设备时的一个新途径。它能够量化你的手和手指位置，有足够高的精确度，所以你可以用它直观的方式进行控制。

Gest 的佩戴尺寸是适合所有人的，但它的内心是能够「记住」你的。每个人的控制手势都是不相同的，但随着时间，Gest 会学习如何适应和执行常见的手势，指向，滑动，弹，抓，转动等等动作。

![](../Images/5925a635e5a75b746c4a1602b432ae31.png)

它还非常灵活，你可以编写自定义手势到设备上，从此只是做一个简单的动作就能得到你想要的操作。例如，撤销的动作可能是手指向左滑动。你还可以监控自己的自定义手势，以确保精度和准确度。

精度和速度方面，Gest 采用低功耗蓝牙（BLE）连接所有的设备，它的手指跟踪技术的延迟在 40-60 毫秒之间，在硬件上它还拥有 15 个分散开来的传感器，这也让它的精度更好，能够识别更准确的手势。

![](../Images/a98f6135fac508a63a58875a652ec3d1.png)

有了精度和识别准确的基础，我们才能用它做更多的工作，首先让人想到的就是设计工作，例如 Photoshop，随着手指的简单轻弹，很轻松的就可以添加图层、调整数值、撤销动作或者改变你的画笔大小，让创作更简单。

![](../Images/289b61d6e8bb14ee02d10ac7f9123283.png)

拥有 Maya、 3DS 或者 AutoCAD 这些三维建模工具的人也同样能够轻松的转动查看 3D 模型。

![](../Images/140a3a0690eecc692b4d57facfb6a9d0.png)

其实 Gest 最让人期待的功能就是打字。有时候我们也不得不对手机键盘的输入效率无奈，便携式键盘也很少能满足高效，舒适，准确。所以 Gest 团队希望解决这个问题。

这也是他们加入打字功能的初衷，虽然现在打字系统还只是一个实验性的功能，但是需要一些有勇气「第一个吃螃蟹的人」来帮助测试和完善制度。如果你已经拥有「盲打」这种技能，想尝试一下隔空打字，就一定要选择购买两个 Gest 控制器来解锁输入功能，体验一些在任何地方抬手就能打字的感受。

![](../Images/98d672d2aa09e7819931059eeae9212d.png)

Gest 团队已经建立了一个 API，让你可以使用手的位置和移动数据。并且开发了高效移动处理算法，使复杂的手势识别功能在极低的延迟下就能完成。 如果你不希望直接使用计算过后的处理运动数据，他们也能提供原始传感器数据，将提供 Java 和 Python 的 API。

![](../Images/d5dd22c91438ec159f7f6e228e86e3c7.png)

有了这些功能之后，在未来开发者也能够通过它的 SDK 与 VR 或者 AR 设备进行集成，将它作为更棒的辅助 VR 设备配件。

## 点评

Gest 的打字功能和使用方式，不禁让我们对未来的输入设备有了更多的想象，而不仅仅是局限于常见的鼠标键盘遥控器。

![](../Images/9bfbbd8273a42cbff55071d0acfec86b.png)

但 Gest 目前最大的痛点就是精准度，如果精准度体验不能让人满意，人们还是会回到古老一点但靠谱的输入设备上去。不过一旦它足够「聪明」，足够精准，还是会吸引很多人为它买单，并且作为主力输入设备的。
