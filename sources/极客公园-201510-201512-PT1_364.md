# Chrome OS 和 Android 合并的真相到底是什么？

> 上周刚说Chrome OS和Android要合并，现在又说不合并，真相到底是什么？

![](../Images/e3608f0f236ef4836b28ba8db0112b91.png)  
我们刚刚报道过[ Google 要合并 Chrome OS 和 Android 的消息](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=400558315&idx=2&sn=aff595eb624434aea413839f27be2ee2#wechat_redirect)。不过，一个周末之后，消息来了个大逆转，Google 又发声明说自己要保留 Chrome OS 了。这种面对全世界打脸的行为肯定不会是 Google 的恶作剧，但他们到底是怎么打算的呢？

## **目前应该不融合，但以后呢？**

在其官方博客中，Google 公司的 Android 和 Chrome 高级副总裁 Hiroshi Lockheimer 这样解释道：

> **「我们一直在努力想办法将这两个操作系统的优点融合在一起，而且我们没有要将 Chrome OS 逐步淘汰的计划。」**

为了提供更多的证据以证明这一点，Lockheimer 在博客中还提到，Google 对 Chromebook 的用户有 5 年的软件自动更新的承诺，因此，这说明如果不想违背承诺，Google **至少要继续运行 Chrome OS 到 2020 年**。

此外，Lockheimer 还在文中列举了很多的数据以证明 Chrome OS 对 Google 的重要性。比如 Chromebook 在教育领域有着巨大的存在感，在 150 个国家和地区，有超过 200 万的教育用户正在使用 Chrome OS 相关的服务；而 Chromebook 也在 Amazon 上卖得非常好。

而在昨天在北京举行的 TechCrunch 峰会上，Eric Schmidt，这位 Google 母公司 Alphabet 的执行主席在采访中却打起了太极，他说道：

> **「随着技术的发展，一个（操作系统）融合另一个是很可能的」。**

Schmidt 没有正面回应 Chrome OS 和 Android 是否真的要合并，但从他的回答来看，我想这样可能性还是很大的，不过诸位读者也可以自己去理解。

![](../Images/58740f0e2f423b81cc13583199696b9e.png)

从 Google 的博客和 Schmidt 的回应，我们会看到这更多的是 Google 对 Chromebook 和 Chrome OS 用户的一个安慰性举动，因为在教育和商业领域还是有不少 Chromebook 的用户的。然而，从上面**「融合二者的优点」**的说法来看，之前报道中提到过的 Google 想要将二者的优点融合起来开发一个新的操作系统的意图仍然十分明显。

## **似乎踏进了一个两难的境地**

但这样的举动也让 Google 在操作系统和企业级用户战略方面陷入了一个比较尴尬甚至是危险的境地。

众所周知，企业级大用户是最不喜欢改变的，任何一个改变都要经过很多的考量。如果 Google 如之前所报道的那样—在 2017 年就用自己新的操作系统代替 Chrome OS，那 Google 就需要自己去考虑一点：**你的用户是否有这个耐心和决心去打翻自己的原有规划、花费很长的时间去适应一个还未得到证明的新系统？**

![](../Images/408b2bd326adc6b109d310fa895ea623.png)

因此，对于 Google 来说，只是一个让他们感到两难的时刻，一方面，他需要为那些已经支持了 Chrome OS 一段时间的用户们负责，尤其是当他们已经为了这个新系统付出了很多的情况下；另一方面，Google 也已经意识到了，Chrome OS 在操作系统届很难有什么更大的作为了。

## **循序渐进可能更好**

因此，对于 Google 来说，更好的方法可能是**循序渐进**。

对于 Chrome OS 的企业级用户来说，好的部分是：它真的是一个建立在浏览器基础上的系统。只要 Google 将底层代码告诉他们，他们还是可以继续自己的工作。但波及到普通消费者领域是不可避免的，不过商家可以通过其他补贴的方式来弥补消费者的损失。

而随着这些一步步的行动，Google 可以渐渐地扩大 Android 系统的影响力，比如其新推出的 Pixel C 平板电脑，通过这样吸引人眼球的相关新产品，Google 可以逐渐消除 Chromebook 的影响力。

![](../Images/7a48e66163d3f4d785b39bb29539249f.png)

通过在不同层级、不同形态的设备上广泛应用 Android 系统，或者是通过类似的方式逐渐推广其新的系统，Android 系统的影响力将会大大加强，而 Chrome OS 将会逐渐收缩成为一块小的业务部门，专门为那些暂时还不愿意改变的用户服务。

## **结语**

当然，这样的设想都只是媒体们的纸上谈兵而已，事情究竟是怎样的？Google 在这方面究竟有着怎样的想法，这些大家都还在猜测。不过，Chrome OS 真的已经到了该改变的时刻了。

而正如我们之前谈到的那样，微软选择使用一个系统去打通全平台，而苹果则坚持不同的设备不同的系统。Google 当然也有自己的考虑，但他们到底会做出怎样的选择，目前尚无定论，也许他们会走出一条新路呢？
