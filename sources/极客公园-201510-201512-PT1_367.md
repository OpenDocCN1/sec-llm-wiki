极客头条：Google：谁说我们要抛弃 Chrome OS 了？

**来源：Google Chrome Blog,Business Insider**

在众多报道分析 Google 可能将会把 Android 和 Chrome 操作系统合并在一起出炉之后，搜索巨头 Google 终于坐不住了——它承诺将会在很长一段时间里支持两个系统的维护。

Google 在其 Blog 头条位置，提醒我们它的「五年之约」——也就是说, 今年发布 Chrome 设备保证更新到 2020 年。

Google 的反应显然是为了安抚客户，尤其是学校和企业——他们大举投资 Chromebook，作为一个低成本、易于管理的 Windows 笔记本电脑或苹果 iPad 的替代品。

企业中任何形式的改变, 甚至升级补丁和杀毒，更新微软的 Windows 操作系统，都必须通过层层审查批准, 更不用说全面升级到新的 Windows 10。(这就是为什么美国海军花费了数百万让微软仍为 14 岁「高龄」的 Windows XP 操作系统提供支持)。

但是 Google 确实又在 Blog 入口处的文章表示，「我们在研究将两个最好的系统融合在一起的方法」，这从侧面证实了那些报道——Google 正在开发一种 Android/Chrome 混血的操作系统。

所以 Google 确实想要杀死 Chrome OS，但它做不到。

**点评：**合并之前与我等天朝上民半毛钱关系都没有，合并后就未必了——毕竟市场上份额最大的手机操作系统是 Android。不过，对于 MIboy 肯定没有太大的冲击。

## 大疆与 Canonical 联手推出无人机内嵌式计算机

**来源：TechCrunch**

## Google X 雄心勃勃：2017 年实现无人机配送

**来源：Theverge**

Google Wing 项目的领头人 Dave Vos 告诉参与华盛顿的一场空中交通管制大会的与会人员，他的目标是在 2017 年推出无人机配送业务。鉴于 FFA（美国联邦航空局）还没有制定出，关于无人机如何运作，尤其是在人口稠密的地区运作的最终解决方案，Dave 提出了非常积极的时间目标。

除了管理上的不确定性，无人机还没有测试避让的传感器技术，以避免「空中事故」。也没有让无人机相互沟通，以及和与传统飞机相互沟通的标准，而这些将是将空中交托给无人机配送队之前，必须完成的事情。

**点评：**「哟哟，网购还送一台无人机啊」某网购用户语。——这将是今后无人机丢失的主要原因。

## 小米本月开始在非洲销售智能机 在中国以外寻求增长

**来源：凤凰科技**

小米将从本月开始在非洲销售智能机，该公司希望通过持续的海外扩张来抵消本国市场增长放缓带来的影响。

小米将一系列手机销售职能交给了一家非洲经销商，这显示出小米在其它市场复制其创新的在线销售模式的难度。

## 黑莓第一款 Android 手机本周上市

**来源：DroidLife**

AT＆T 公司周一表示，将从本周五开始在其零售商店销售黑莓公司最新的 Android 智能手机 Priv。而黑莓官网也将从本周五开始正式出货。AT&T 为 Priv 提供的两年合约价为 $249，或者通过 AT&T 的 Next 计划购买 Priv，最低月供仅需 $24.67。目前还没有其他运营商上线 Priv 的消息。

黑莓 Priv 作为黑莓第一款 Android 手机，定位高端市场，除了拥有一块 5.4 英寸 QHD AMOLED 显示屏外，还保留了标志性的黑莓全键盘。采用高通骁龙 808 处理器，32GB 存储空间，3GB 运行内存，1800 万像素摄像头。

**点评：**黑莓憋了这么久的 Android 手机终于上市了，不知道会不会有黑莓的粉丝第一时间充值信仰？
