# 微软也知道 HoloLens 太贵，所以他们选了华硕做制造商

> 如同自家旗下的 Win10 一样，微软似乎连 HoloLens 也要下放给同门兄弟。

![](../Images/65ed7e5939963b8a2ba0c94bdd0164ab.png)  
关注 AR/VR 领域的极客们一定对于微软旗下的 HoloLens 不陌生吧？微软在 10 月初公布了开发者版的售价——$3000，并且发货时间为 2016 年的上半年。

![](../Images/73a8eadd926badcde5cb3a0b6d84985e.png)

「没有任何电缆，无需连接电脑，无需连接手机。」微软的 Windows 设备副总裁 Terry Myerson 表示，相对于需要一台电脑的 Oculus Rift 或者一台手机的 HTC Vive ，作为一款单独设备来说，这个价格是值得的。

![](../Images/3c674a5e0bd266eea6ff7ff6a13f7dd3.png)

对于一款炫酷的产品来说，昂贵的价格并不能挡住「真爱粉」的购买热情。但对于普通人来说，这个价格简直接受不能。不过，HoloLens 或许不止微软一家做哦……

## **Win 阵营厂商或将加入战局**

华硕，作为世界上第六大的 PC 生产厂商，正在与微软商谈关于制造一款华硕旗下的 HoloLens 的事项。华硕 CEO 施崇棠 (Jonney Shih) 与微软 Windows 和设备部门执行副总裁 Terry Myerson，将消息透露给媒体。如果两方达成协议，华硕将会成为第一个 HoloLens 的第三方厂商。这有可能推进 AR（增强现实）的发展。

![](../Images/39f5620edd7a4296fe2e06246d894596.png)

那么为什么华硕会成为第一个「外部厂商」呢？为 HoloLens 创造出一个市场环境——尽管微软有心开发 AR 市场，但高达 $3000 的售价，实在难以让人看出任何诚意。而作为生产「物美价廉」PC 的厂商，华硕将可能为 AR 的爱好者们提供另外一个可承受的售价。

> 「我们在硬件领域的所作所为，都是为了促进 Windows 生态环境发展。」Myerson 表示，「这就是为什么我们会投资，创建一个全新的品类」。

## **Surface 引发的矛盾**

诸位极客们都知道，早在 2012 年之时，微软发布了全新的产品 Surface，那是微软第一次涉足 PC 硬件制造领域。而这件事情，直到 Surface 发布前夕，各大 PC 制造商才得到消息。

![](../Images/c9e170c785b44c4226f026b432fca05c.png)

而今年 Surface Book 的发布，似乎惹到了华硕，再一次激化了两者之间的矛盾。而微软方面一次又一次地强调自己生产笔记本电脑，纯粹是为了激励同为 Win 阵营的厂商们。这一次 HoloLens 的首家制造商选择了华硕，不排除微软为了安抚华硕，这个原因。

![](../Images/ea7272f504fc96c7037cb6a9a7c3212b.png)

毫无疑问，PC 厂商的销量陷入了低谷。所以无论是 Surface Book 也好，还是 HoloLens，微软似乎都在向同处 Win 阵营的队友们表示，[游戏笔记本不是唯一出路，我们需要的是更好的设计](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=400079033&idx=2&sn=0dedc2fc6f2b4df8448089fbff768b77&scene=21#wechat_redirect)，我们需要搭建 Windows 生态。

> 「我们不想与华硕竞争，」Myerson 总结道，「那并不是我们的目标……我们希望的是，人们能够回家使用他们熟悉的 Windows。」

![](../Images/0bf1ca9a5dabed28463f3cfe855bb992.png)

微软作为 Win 阵营的主导者，在构建 Windows 生态中当仁不让地挑起重任。所以今年会有 Surface Book 一样作为 Win 阵营的设计标杆的产品，也会有 HoloLens 一样的「黑科技」来表达出阵营鲜明的特色。

不过，如何平衡曾经与自己一同「攻占全球」的第三方厂商的利益，将会成为一个问题……这次微软用 HoloLens「平复」了华硕的「情绪」。那么，下次呢？
