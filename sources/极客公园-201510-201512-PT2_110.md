# 什么？打印机也能谈情说爱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=215194429&idx=3&sn=b5449215b92dfcd28b78c9b63f979c92&chksm=eca6e68bdbd16f9db0f2caef03b90abb2f453bc9f489182b74bf6c58298b64dbc0b6f377dfbc&scene=126&sessionid=1681311700#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=215194429&idx=3&sn=b5449215b92dfcd28b78c9b63f979c92&chksm=eca6e68bdbd16f9db0f2caef03b90abb2f453bc9f489182b74bf6c58298b64dbc0b6f377dfbc&scene=126&sessionid=1681311700#rd)

这两天，编辑部里来了个新玩意儿：一台名叫咕咕热敏打印机（可惜它并不能咕咕叫 = \_ = ）。

  

起初身边的同事们觉得这台像超市小票打印机的东西没啥了不起，不过当他们见到我用手机操控它打印的今日事项和深藏手机中的搞怪照片后，咕咕打印机一下子就变得受欢迎了起来。

  

随后，有的同事用它打印 Kindle 的笔记，有的同事把咕咕打印机打印流程拍下来放到朋友圈泡妞儿，还有的伙伴开始用打印出的糗照勒索基友……小小的一个热敏打印机被玩出了很多花样。

  

![](../Images/bcef3479bd2d62d5689c07b6778d9301.png)

  

当然，作为一款还在众筹阶段的产品，它还存在一些可以改进的地方：比如一台打印机目前只能绑定一部手机，或多或少地影响大家一起使用的便利性。

  

但整体来讲，咕咕热敏打印机的体验还是不错的。如果你是一名喜欢日常记录的笔记少年，那么这款打印机能够节约你不少空间，如果你打算想给另一半送去一个特别的祝福，这款打印机能够帮你注入更多的「内涵」。
