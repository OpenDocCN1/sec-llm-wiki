# 为了让 Chrome 不那么臃肿，Google 砍掉「应用启动器」功能

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=404961712&idx=3&sn=d41c78be1cda1d2b29094af48f23ac8c&chksm=f8564406cf21cd1048982829ddcd14cad2176842704ec351c9ee81ac7e37132fded008e6226b&scene=126&sessionid=1681311572#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=404961712&idx=3&sn=d41c78be1cda1d2b29094af48f23ac8c&chksm=f8564406cf21cd1048982829ddcd14cad2176842704ec351c9ee81ac7e37132fded008e6226b&scene=126&sessionid=1681311572#rd)

** Chrome  **  ** 产品观察 **

**

我们都知道，Google Chrome 是在全世界范围内都非常受欢迎的一款浏览器，在全球的浏览器市场中的地位仅次于微软 IE，而且它的市场份额还在不断上升。

其中的原因当然是因为 Chrome 是一款功能非常全面、使用也非常方便的浏览器，它既为用户提供了种类非常多的工具；也想了很多办法，让用户在使用这些工具时能够尽可能地便捷。其中，**Chrome 应用启动器（Chrome app launcher）**就是其中很重要的一个工具，尤其对于那些患有重度「Google 依赖症」的用户来说，这款工具让他们在使用 Chrome 浏览器中的许多服务时会非常快捷。

然而昨天，Google 宣布他们将会在今年 6 月在 Windows、OS X 以及 Linux 平台上停止这款工具的运行。

****************“******************让用户更快捷打开 Chrome 应用的工具**

Google 是在昨天在自己的官方博客上宣布这个消息的。Google 工程部门的负责人 Marc Pawliger 在博客中说道：

> Chrome 应用启动器是用来帮助用户在浏览器之外更轻松地打开 Chrome 应用的一款工具。但我们发现，在 Windows、OS X 以及 Linux 这些系统上的用户更喜欢在浏览器中打开应用。另外，由于 Chrome 一贯持续的简洁设计态度，这款工具将会从在 Windows、OS X 以及 Linux 平台上移除，只会保留在 Google 自己的 Chrome OS 系统中。

![](../Images/0f2ffebae074340ff78dada5173980d7.png)

如果你不清楚 Chrome 应用启动器是什么的话，那一方面说明你可能对这款浏览器挖掘得不够，但另一方面也说明这款工具的存在本身就比较尴尬。

Chrome 应用启动器是 Google 在 3 年前上线的一款工具。它可以被固定在 Windows 系统任务栏以及 OS X 系统 Dock 上的图标，用户点击它之后，它就会为你弹出你已在 Chrome 中安装了的应用，点击具体的应用就能直接在 Chrome 浏览器中打开它。当然，这里需要注意的是 Chrome 应用启动器只负责管理 Chrome 当中的应用（App），插件（Plug-in）和扩展（Extension）不在它的管理范围内。

![](../Images/ae0ed8388a9ce046a696fcbab7ed3d56.png)

Google 原本的意图是想让用户在使用诸如 Chrome 应用商店、Google Docs、Google Drive 这样的应用时更加便捷，但很显然，用户们并没有接受这个想法。因此，Google 也不得不在昨天做出了这个决定。

****************“******************为 Chrome **「减负」的举措****

对于 Google 为什么要做出这个决定，我们也许可以从 Google 几个月前的一次举动中就能看出征兆。

在去年 10 月中旬，Google 宣布他们决定停止 **Chrome 通知中心（Notification Center）**功能。当时他们给出的理由是**「使用这个功能的用户太少」**。而这次他们给出的理由也大同小异，不过这显然只是其中的一个原因。![](../Images/a6d6d1cd3876f4a2a21e72e0a3eb167a.png)

除了使用人数之外，更重要的原因也许在于**外界对 Chrome 持续增长的臃肿以及过度耗电的批评**，相信大家可能都对此有所察觉。在过去的几年中，Google 为 Chrome 添加了许多诸如应用启动器以及通知中心这样的附加功能，他们想让 Chrome 脱离「单纯的浏览器」的范畴，让它成为用户桌面系统管理的一个组成部分。然而，用户似乎并不买账，因为这些功能既增加了 Chrome 的运行负荷，又让它变得迟缓，并且给用户带来的作用也比较有限。

因此，这两次连续的举措似乎表明 Google 意识到了用户的不满。正如 Venture Beat 所说，**「Google 终于意识到了用户不想在她们的实际的操作系统之上还有一个『浏览器操作系统』」**。

事实上，如果用户想要打开那些 Chrome 应用，他们只需要打开 Chrome 浏览器，打开一张新的标签页，然后你就能在书签栏的最左侧看到你的 Chrome 应用图标，点击它就可以了。这个过程也许才更符合用户的想法。

****************“******************结语**

不过，如果你很喜欢 Chrome 应用启动器，那也不用着急，这个功能将会在未来的几个月中逐渐被移除。从未来的几周开始，当用户安装新的 Chrome 应用时，Chrome 将不会再为你显示 Chrome 应用启动器；而目前正在使用 Chrome 应用启动器的用户也将会在未来收到 Google 发给你的相关通知。到了 6 月，这项功能就将正式消失。

不过，对于大多数 Chrome 用户来说，这也许不是一个坏消息呢，至少你的 Chrome 能变得稍微精简一点。
