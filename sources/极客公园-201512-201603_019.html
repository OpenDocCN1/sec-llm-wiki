如果微软的浏览器也能使用 Chrome 的插件，你会选谁？

相信对于使用 PC 上网的用户来说，浏览器是否好用在很大程度上决定了他们的上网体验。而在浏览器的整体体验中，许多浏览器品牌都选择通过增加丰富的浏览器插件来提升他们的使用体验，其中来自 Google 的 Chrome 自然是其中的翘楚。根据今年年初的数据，在全球目前的浏览器市场中，除了 IE 浏览器还凭借其传统优势占据第一之外，Chrome 已经牢牢把持了第二的位置，并在不断侵蚀着 IE 的份额。而在其中，我们甚至看不到微软另一款产品 Microsoft Edge 的名字。

而最近，微软终于决定开始在自己在 Windows 10 系统中最新的 Microsoft Edge 浏览器中测试插件功能。并且在昨天，根据相关消息，他们也开始开发能将 Chrome 浏览器中的插件移植到 Edge 中的工具。这一系列的行动代表了微软想要在 Edge 上发力的决心。

“为 Edge 添加插件

事情要从去年开始讲起。

自从去年 7 月 29 日 Window 10 系统正式上线以来，Microsoft Edge 浏览器就成为了微软着力推广的一款产品，而业界对这款产品的评价也不错，很多人都觉得这款浏览器在使用体验、流畅度以及设计感上都非常好。然而，由于功能还不够完善以及浏览器市场的白热化竞争，Edge 并没能真正在市场上引起很大的反响。

因此，在去年 10 月的时候，就有消息称微软将会在 Edge 浏览器中添加插件功能，不过时间要推迟至 2016 年，这一消息也得到了微软自己的确认。

于是，在上周，微软官方发布了声明，表示他们已经开始在 Windows Insider Fast Ring 用户中开始测试添加插件的功能，不过目前只提供 3 种测试插件，分别为翻译、鼠标手势和 Reddit 增强套件。但微软承诺将会在今年为其增加更多的诸如 Adblock 这样常用的插件。

而在同时，微软还为 Edge 添加了不少改进的措施，比如新的「固定标签页（Pin tab）」功能，用户可以在某个网页标签上点击右键，将其固定在顶部的任务栏中。同时，还在地址栏中增加了右键直接「粘贴并搜索」的功能。不过，这几个新功能都是 Chrome 早已有了的功能。“连接 Edge 与 Chrome

而在昨天，根据微软高级产品经理 Jacob Rossi 的消息，微软已经开始准备在 Edge 浏览器中添加更多的插件，他们正在开发一款移植工具，让 Chrome 浏览器中的插件能够在 Edge 中运行。Jacob Rossi 是在自己的 Twitter 中公布这一消息的，他同时还表示这一工作还在进行中，并且「不会支持所有的 API」。

事实上，如果没有这个最新的消息，那么微软之前的开放插件功能也只不会引起太大的火花。毕竟对于开发者们来说，为了 Chrome 开发插件带来的回报要远大于 Edge 所能带来的回报，毕竟双方在用户数量上还是有着非常大的差距。因此，微软想要通过开发连接二者之间的移植工具来吸引更多的开发者。

同时，我们可以预想的是，微软也会将这个功能继续移植到其他诸如 Firefox 以及 Opera 等多个浏览器上，以此提升 Edge 中的插件数量。不过，这究竟会给 Edge 带来多大的用户提升恐怕值得怀疑，毕竟让用户更换一个熟悉的浏览器可比给他们一个新的插件要难得多。

“结语

不过，这个产品究竟何时才能上线还未可知，但我们应该可以在下个月初的 2016 Microsoft Edge Web 峰会上看到更多关于这个产品的消息，届时极客公园也将为您带来相关的报道。而如果 Edge 能在这些细节的功能上加快追赶 Chrome 的脚步，那也许它会成为 Chrome 最有力的竞争对手。
