# 「延时摄影」结合「镜头慢放」，手机视频从未如此有质感｜挖App

随着视频慢慢成为社交网络的新宠，可悲的是我们手机视频的呈现手段还停留在恶搞和加贴纸的阶段，内容质感上总是被照片碾压……**在画面效果上作改进无可厚非，但也别忘了视频最大的优势在于——多了「时间」这一展现维度。通过操纵时间轴，掌控视频的播放速度才真正能发挥其优势，这就是为什么「延时摄影」和「镜头慢放」会让普通视频获得脱胎换骨的效果提升。**今天推荐的正是一款从呈现维度上提升手机视频质感的拍摄软件，让你的视频拥有电影般的镜头感……  

「Catch 简影」是一款与众不同的视频拍摄软件，可以让简单的手机视频拍出充满节奏变化的电影感。**通过拍视频的同时抓拍下精彩瞬间，再用不同速率播放拍摄内容，抓拍的镜头慢放，其他部分则是加快倍速。**远近虚实、重点突出，在结构和展现维度上都充满层次感。

********“********用简单的方式，创造出惊艳的观感

「Catch 简影」的拍摄模式非常简单，第一次打开应用就会有新手引导教程。会直观地告诉用户在录制视频的同时拍摄三张照片，既对视频中的精彩瞬间进行抓拍，而这些抓拍镜头则会在视频中以「慢放」效果呈现。**重点突出，就像电影中给关键镜头的慢放特写一样，在试听和观感上会带来不小的冲击。 **

****![](../Images/534e9b0fa09cc66c295ad8a9d9324da8.png)****

而「Catch 简影」目前将视频的拍摄模式标准化，这样的「限制」旨在可以最大程度的降低用户使用的学习成本。让用户只需要按照步骤拍摄，就能创作出手机视频往往不具备的快慢特写的电影效果。

![](../Images/e064d7a0cfafa28699998f1fbfaead5b.png)

  

「Catch 简影」的视频播放主要分为了普通部分的快放和重点镜头的慢放，**「慢放」效果采用了估算视频帧间运动并进行插帧的技术；而「快放」时则采用了类似微软的延时摄影 App—「Hyperlapse」的防抖技术，让镜头在加速快放时效果更好一些。 **  

可以说「Catch 简影」的出现让手机小视频的拍摄增加了一个新的维度，引入时间轴的操控概念让视频创新不再停留在表面内容，而是深入到拍摄手法上。

********“********除了拍摄手法创新，也是优秀的小视频应用

除了独特的「抓拍慢放」模式以外，「Catch 简影」同样是款很优秀的小视频拍摄应用。在完成视频的基础拍摄后，对内容的后期处理的工具这里也一应俱全。例如在视频中加入字幕、动画贴纸、滤镜……等效果，**并且在关键镜头中还可以添加「跟踪标签」，跟踪标示某个移动物体。**

![](../Images/757a60ac3cab861ecf49ac17332c2cb5.png)

「Catch 简影」的质感除了视觉端同样存在于听觉部分，应用内置的添加背景音乐的功能也很有调性，提供了很多十分适合作 BGM 的音乐，并且标出了每首歌对应的曲风，如清新、浪漫、愉悦、舒缓、动感……等，更方便用户挑选合适的音乐。  

![](../Images/26fcf2130d83148730428053372e47a0.png)  

********“********精致和简单，使它有别于竞品

**「Catch 简影」的界面相比于国内很多流行的小视频软件来说很简单，在 UI 设计上比较克制，一共菜单、拍摄和视频社区三个界面，这三个界面可通过上滑滑动来直接切换，内容干净简洁。**总体使用下来，不会感到臃肿和繁琐，足够精致也足够简单，工具的属性更强一些。

![](../Images/3e4d4855b9056000494b3979f4137ba0.png)

同时「Catch 简影」也向「极客公园」透露了目前「Catch」只是一个特殊场景中的有趣拍摄工具，而未来则要成为一个潮、奇趣、新青年的视频UGC 社区，期望用自己有趣的拍摄方式和调性创造一个生产优秀作品的用户社区……可以一起来看看他们亮眼的宣传视频：
