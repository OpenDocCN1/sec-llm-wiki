 Galaxy S7 / S7 Edge    手机评测  


除了下半年的「iPhone 7」，今年最受关注的智能手机莫过于三星的「年度旗舰」Galaxy S7 和 S7 Edge 了，过去几天，大家可能已经被三星 Galaxy S7 / S7 Edge 各种上手、评测、体验「刷屏」了。

根据相关的协议，从昨天凌晨开始，多家外媒也相继放出了 S7 / S7 Edge 的正式评测，下面我们就来看看它们是如何评价这两款产品的。

“The Verge： 弧面屏的最大优点是让手机变窄

从外观上看，S7 和去年的 S6 没多少变化，它们采用了相同的设计（S7 背面换成了更大弧面的玻璃）、相同尺寸的屏幕（5.1 寸、分辨率 2K）以及相同的金属加玻璃材质。

Galaxy S7 Edge 和 iPhone 6s Plus （来自 The Verge）

相比之下，S7 Edge 在设计上发生了很大的变化。虽然 S7 Edge 将屏幕尺寸增加到了 5.5 寸，但凭借双曲面屏幕和更窄的边框，S7 Edge 的机身宽度并没有增加多少，对比 iPhone 6s Plus、LG G4 等类似屏幕尺寸的手机，S7 Edge 的机身要窄很多。配合前后双曲面玻璃，S7 Edge 摸起来有些像一块被水长期冲刷过的鹅卵石，在我摸过的无数手机中，S7 Edge 可能是最舒服的一部。

S7（以及 S7 Edge）采用了一颗 1200 万、F/1.7 光圈的摄像头。虽然像素有所降低，但 S7 的成像效果依然很出色。不过相比去年已经很优秀的 S6，S7 没有质的提高。此外，当光线不足时，S7 的成片依然有些偏暖或者偏黄。当你在手机上将照片放大时，S7 有些照片会有些锐化过渡。

S7 和 S7 Edge 还加入了一个屏幕常亮的功能，它可以在只点亮屏幕上少量像素点的情况下，让 S7 和 S7 Edge 显示时间、日期、甚至图片，但无法显示通知。此外，和 Moto 的主动显示不同，S7 和 S7 Edge 上在常亮时屏幕是无法触摸的。

S7 和 S7 Edge 并不完美，三星的软件依然「配不上」它的硬件，但这两款手机将屏幕、摄像头、性能、电池续航等这些手机最基本的东西都做的很优秀，加上精美的设计和出色的材质，在 Android 手机中，我不认为有哪部手机能比 S7 / S7 Edge 更精美。

在 S7 和 S7 Edge 之间，后者明显更加出色，弧面屏幕让 S7 Edge 在使用 5.5 寸大屏的情况下，依然保持了出色的手感。S7 Edge 是我用过的最优秀的智能手机之一，可能也是目前最优秀的 Android 手机。

The Verge 评分 ：8.8（Galaxy S7），9.1（Galaxy S7 Edge）

（编者注：9.1 是 The Verge 有史以来给智能手机打过的最高分，之前的最高分是 iPhone 6s 的 9.0）

“Marques Brownlee：S7 Edge 的软件体验脱了后腿

过去一段时间，你可能已经听到了无数关于 Galaxy S7 Edge 的赞美了，今天我想说点不一样的东西：S7 Edge 的缺陷。

从硬件上看，由于 S7 Edge 的背面依然采用了镜面的玻璃材质，这导致它的背面极易沾染指纹，而且拿在手里会很滑，为了获得更好的握持手感，你可能有必要在背面贴一张防滑贴纸。不过想比起硬件上小小的不完美，S7 Edge 最大的问题依然是它的软件体验。

安卓手机下方的三颗按键几乎已经形成了「约定俗成」的方案，无论是 LG、索尼手机上的屏幕虚拟按键，还是其它采用屏幕外实体按键的手机厂商，几乎都是左边返回键、中间主页键、右边多任务键，不过三星依然固执的把返回键和多任务键的位置颠倒过来。

另外一个问题是 S7 Edge 系统的应用抽屉。应用抽屉本来是应该方便查找应用的，但在默认设置下，S7 Edge 上的应用抽屉排列却似乎没有任何规律，App 和文件夹零零散散地分布在应用抽屉中，新安装的 App 会自动被放在最后。当然，我们可以按照「a-z」的字母顺序给应用抽屉排序，但奇怪的是，这种情况下新安装的 App 依然会被放在应用抽屉的最后。

S7 Edge 还内置了太多无用的软件，我手上的这部 S7 Edge 内置了两个邮件 App、两个照片 App、两个语音助手、三个音乐 App 以及一堆三星自家的应用，此外，如果你像我一样使用的是 Verizon 定制机，还会额外内置十多个运营商「大礼包」。

需要说明的是，我并不是指 S7 Edge 不值得购买，相反，S7 Edge 是我最喜欢的安卓手机之一，只是 S7 Edge 的其它方面太过优秀，才让这些小毛病变得比较显眼。

“CNET：贵，但值得买

S7 和 S7 Edge 的电池容量分别为 3000 和 3600 毫安时，比 S6 和 S6 Edge 有了明显的增加（这也导致 S7 系列要更厚、更重一些），这两款手机均支持有线和无线快充。

Galaxy S7 和 S7 Edge 在我们实验室的测试中表现极为出色，其中 S7 Edge 可以连续播放 20 小时的本地视频，S7 也可以坚持 16 个小时，相比之下，iPhone 6s 只坚持了 10.5 个小时。在实际使用中，S7 和 S7 Edge 都可以满足一整天的使用，不过如果你观看很多在线视频或者导航的话，你还是需要每天晚上充电。

在性能方面，S7 / S7 Edge 也没有什么需要担心的，即便是对性能要求极高的游戏也能轻松搞定，详细的性能测试大家可以参考上面的表格。

跑分从上到下依次是 Geekbench 3 单核、Geekbench 3 多核、3DMark Ice Storm Unlimited

Galaxy S7 和 S7 Edge 在美国的裸机售价约为 650 美元和 750 美元（编者注：国行售价分别为 4888 和 5688），这个价格显然不便宜，但我认为是值得购买的。相比 iPhone 6s，Galaxy S7 拥有更丰富的功能，同样精美的设计、更多的定制化空间和顶级的硬件配置，而 S7 Edge 还拥有更大的屏幕、更长的续航以及诱人的「瀑布式」曲面屏幕。

“Engadget：三星的「s」年

S7 和 S7 Edge 搭载的系统中，增加了一个叫做 Game Launcher 的功能。它的原理就是把你手机上所有的游戏汇聚在一起，以更方便地使用和管理这些游戏 App。

虽然概念听起来很简单，但 Game Launcher 用起来却有些不那么靠谱。Game Launcher 会自动扫描并汇总手机内安装的游戏 App，但在我使用时，它居然把 Slack 这个通信 App 加入到了游戏列表中。

不过除此之外，Game Launcher 用起来还是挺不错的。当你玩游戏时，手机屏幕的角落里会出现一个小红点（如上图），点击这个小红点可以呼出很多实用功能，包括关闭手机提醒、锁定手机上的触摸按键、截图甚至录制游戏视频。虽然我并不怎么热衷手机游戏，但我相信很多人会非常喜欢这个功能。

相比 S7，S7 Edge 软件上最明显的区别就是 Edge UX，呼出方式依然是从屏幕边缘向内划动。S7 Edge 默认有四个功能面板：用于添加 App 快捷方式的 Apps Edge、用于添加联系人的 People Edge、用于添加某些应用内功能（如自拍、写邮件）的 Tasks Edge 和雅虎新闻，此外，三星还提供了指南针、日历、天气等功能面板可供下载。

我个人并不觉得上述这些功能面板有多少实用价值，不过好在三星在试图开发这块曲屏的功能，这本身就是件好事。

Galaxy S7 和 S7 Edge 就像是三星「s」产品，它们在上一代已经很出色的 Galaxy S6 / S6 Edge 的基础上做了进一步的改良和完善。如果你想购买一部最新的、同时屏幕尺寸不是很大的 Android 手机，Galaxy S7 值得你考虑；如果你热衷时尚，S7 Edge 在「拉风」的外观下，依旧保持了不错的续航。

S7 和 S7 Edge 是今年第一批上市的旗舰手机，未来一段时间会有更多的旗舰产品上市，但我们已经可以明确的说，这两款手机配得上「旗舰」之名。
