# 作为一款 To-do 类应用，颜值太高未必是件坏事#iOS｜挖App

印象里 To-do 类的应用总是层出不穷，各式各样的清单、列表，多到无从下手。而随之而来的是一种将效率作为首要因素的设计思路，To-do 应用效率为先这无可厚非，不过一条道闷头走总不是好事。在大家都在追求极简、高效的时候，一款放弃了极致效率却在 UI 稍加用心的 To-do 应用就变得尤其显眼。  

「Everlist」就是这样一款反趋势的清单应用，在兼顾基本效率的原则上它将更多的精力放到了 UI 设计上，更多留白和同一页面内更少的内容让和其他同类应用比起来更多了几分精致，不那么毫无空隙、火急火燎地安排每件事。

> **下载地址见文末**

**“**在「精致度」上下足功夫

「Everlist」在近期所见的 To-do 类应用中绝对算得上处在了颜值顶端，**主页中事件按照分类排列在不同的卡片状集合中，这些集合都会配有一张十分悦目的照片，待办的事项以灰色的字体罗列在卡片另一半的白色部分。**整体看起来十分清爽，配上图片也让整体看起来更精致。

![](../Images/d3adc2640b90f16a409bebe1114e7e79.png)

事项分类最初只有「Inbox」、「Work」、「Travel」、「Groceries」这四类，用户可以自行添加，添加后会随机为这个分类配上一张精美的图片。

![](../Images/394268700c24e785237144ea32351d5a.png)

**「Everlist」在细节处不可谓不用心，细心的用户就能发现，在编辑待办事项的时候如果在标题中加上相应的英文单词，「Everlist」就会自动识别并在事件开头加上一个的简单的对应图标，**虽不是非常实用的功能，但这样隐藏起来的小细节的确会在使用中给用户一些意想不到的惊喜。

![](../Images/1269a0daa722881d14c818e73b40aa91.png)**“**简单的核心功能设计，它并不只是个「花瓶」

虽然一直再说「Everlist」的美观和精致，但作为一款 To-do 应用它的基础功能也十分完善。**简单并突出核心功能是「Everlist」的设计思路，完善的事件归类设定也让整个应用显得很井井有条。**首先是在主界面内事件被按照用户自定义的类型划分，在添加和查找时都有比较清晰的思路；**其次在低栏中又会按照「今天」、「这一周」和「所有事件」这三类来划分，用户可以直观看到今天有哪些事要做，这一周又有哪些事等着自己。**

![](../Images/43d5388e8e4d69e97be288d55692cf1f.png)

在添加待办事件的过程中，「Everlist」只有标题、日期、时间、类型、重复方式和注释几个选填项，甚至都不能插入图片等附件。它只留住了最基础最核心的几个功能，它能做好事件提醒，但并不能给你这以外的更多支持。

![](../Images/a977253111d4d53150d09680eeaaac54.png)

在待办事件的列表中，每个事件后方都会有勾选框，勾选标记为完成。不过勾选后事件并不会直接消失，而是被划掉且用更浅的颜色显示，只有再点击后发的「×」才会将事件从整个列表中除去，这样的细节方便用户对日程完成的概况能有个更全面的掌握。

![](../Images/31ffd4cd7333db7aa53cf340c555ed71.png)

**并且「Everlist」也支持滑动操作，对待办事件左右滑动也可以完成标记、延后、恢复……等操作，**不过滑动操作并不支持全局，在某些二级菜单界面想要返回只能点选上方的返回按钮，稍显麻烦。

![](../Images/bd971a6008f6e3e7430d4c600fbedf52.png)

**总之，和大多数的 To-do 类应用追求高效和全能的思路不同，「Everlist」更像是一款专门用来帮助用户享受生活的清单 App。它的功能能满足最基础的需求，而它的精致能给你在安排日程时多两分惬意……**
