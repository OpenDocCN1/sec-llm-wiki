Model 3将于月底亮相 对于特斯拉成败至关重要

来源：凤凰科技

根据特斯拉网站披露，Model 3 电动汽车将于本月底亮相。特斯拉邀请函只是声称将在「加州南部地区」举办新产品发布会。

Model 3 将几乎能决定特斯拉的成败——至少对于其大幅增加销量的梦想来说如此。继去年推出的面向高端用户的 Model X 后，它将 Model 3 定位为——起步价仅为 3.5 万美元的大众车型。外界对 Model 3 还所知不多。预计其行驶里程将为 200 英里 (322 公里) 左右。

转向大众市场是特斯拉股票物有所值 (指较高的市盈率) 的关键，也是特斯拉在内华达州建立超级电池工厂的主要原因。该工厂将于明年投产，如果 Model 3 畅销，电池不会出现积压；否则，投资 50 亿美元建设的超级电池工厂，将成为特斯拉一个沉重负担。除价格外，外界对 Model 3 还所知不多。预计其行驶里程将为 200 英里 (322 公里) 左右

点评：一提电动车，大家一定会想到特斯拉，但是你一定没想到它卖得并没有想象中好，希望 Model 3 能够为它带来转机。

看完特斯拉，宝马也要做辆智能汽车

来源：engadget

正式跨入第 100 年的宝马，认为未来与其竞争的将不再是凯迪拉克或者是奥迪汽车，而是 Uber 共乘服务或者是 TrueCar 车价电商网站这些近期大幅度崛起的网络服务。根据路透社的报道，宝马的 Klaus Froehlich 认为该公司现阶段的任务，是要在这些网络公司环伺之下依然能保障自己的运营模式，否则「将像富士康之于苹果那样，只能提供生硬的金属料件给后者」，最终隐居幕后成就更大的公司。

因此，对他个人而言，打造最智能的汽车将成为该公司的未来的核心竞争力。为了这样的目标，宝马近期大刀阔斧地改变公司的人事政策，引进更多软件工程师到了 50:50 的比例，并且向外寻求更多相关人才。

点评：如此看来，宝马是为数不多的敢于创新的车企...智能汽车的爆发点可以期待。（虽然窝并买不起，也摇不到号）

别以为苹果不会受到病毒的威胁！

来源：Cnbeta

据路透社报道，苹果公司用户成为黑客首次针对 Macintosh 电脑的攻击目标。Ransomeware 是目前增长最快的一种网络安全威胁因素，被感染的计算机数据将会被加密。之后，受害者需要支付一定的赎金以获取密码来解锁数据。一些安全专家预测，这些被勒索病毒感染的用户向网络犯罪分子支付的赎金总额已经超过数亿美元。

苹果公司的发言人表示，苹果公司上周末已经采取一定的措施来防止黑客的入侵。但他并未透露更多的防范细节。

点评：如果暗中窃取不了数据那不如直接勒索你，不论你是用什么操作系统，你都要重视计算机安全。
