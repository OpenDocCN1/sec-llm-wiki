当所有人都以为索尼在 MWC 上不会发布重要的手机新品时，索尼却给了我们一个大惊喜——全新的 Xperia X 系列产品线。

索尼这次一共发布了三款该系列的手机新品，分别是 Xperia X、Xperia XA 和 Xperia X Performance。这三款产品有很多共同点，比如都采用了 5 英寸的屏幕、Hi-Res「小金标」以及相同的青柠金、玫瑰金、石墨黑、春雪白四种配色，不过在硬件配置、机身材质等方面，这三款手机又形成了明显的区分。

## “Xperia X：颜值更高的「Xperia Z」

一眼看上去，Xperia X 就像是 Xperia Z3 的「孪生兄弟」，正面的传感器、扬声器、摄像头的位置几乎都和 Z3 完全一致。  

不过 Xperia X 在机身细节上还是有不少的改变，背面材质从 Z3 的玻璃换成了金属，正面使用了 2.5D 弧面玻璃。索尼还在 Xperia X 上采用了一种「tone-on-tone」喷涂工艺，让手机的正反面保持统一、连贯的颜色。

![](../Images/e7fe66424156ece1aa3c8606f2aeb9bd.png)

Xperia X 的前后摄像头像素分别为 1300 万和 2300 万，索尼表示 Xperia X「从启动相机并完成拍摄只需要 0.6 秒钟」。此外，索尼还给 Xperia X 的摄像头加入了叫做「预测混合对焦」（Predictive Hybrid Autofocus）功能。在拍照时，用户可以选择拍照对象，Xperia X 的摄像头可以自动追踪拍照对象的移动，从而提高拍摄运动物体时的成功率。

索尼 Xperia X 配备了骁龙 650 处理器以及 3GB 的运行内存，电池容量为 2620 毫安时，运行 Android 6.0 Marshmallow 操作系统，内置 32GB 的存储空间且支持 microSD 卡拓展。

“Xperia X Performance：性能最强的索尼手机

如果你觉得 Xperia X 的骁龙 650 不够用，可以考虑下 Xperia X Performance，它搭载了高通目前最强的骁龙 820 处理器，运行内存则依然是 3GB。此外，**Xperia X Performance 还是这三款手机中唯一可以防水的**，防尘防水等级为 IP68。

除了处理器和防水防尘能力之外，Xperia X Performance 和 Xperia X 基本就没多少区别了。这两款手机采用了相同的 5 寸 1080p 屏幕，均配备了前置双扬声器，**侧边的方形电源键上也都集成了指纹识别功能**。

![](../Images/0d49110cb3aa1208be2dc810c7998f54.png)

此外，黑色和白色版 Xperia X Performance 的机身背面增加了特殊的细线纹理，不过除此之外，Xperia X Performance 和 Xperia X 在外观上几乎完全相同。

## “Xperia XA：定位最低，边框最窄

如果说 Xperia X 和 Xperia X Performance 延续了 Xperia Z 系列设计风格的话，Xperia XA 则更像是索尼的中端产品 Xperia C5 Ultra 的等比例缩小版。  

Xperia XA 采用了超窄边框的设计，机身宽度仅有 66.8 毫米，比 Xperia X 和 Xperia X Performance 都要更窄一些。

![](../Images/94425801971732ab636177b360bd7a16.png)

配置方面，Xperia XA 明显比上两款产品低一些。Xperia XA 的屏幕分辨率仅有 720p，处理器换成了联发科的 MT6755，2GB 运存以及 16GB 内置存储，前后摄像头像素被降到了 800 万和 1300 万，电池容量也被缩水到了 2300 毫安时。此外，Xperia XA 的电源键是圆形的，**不支持指纹识别**。

“取代 Xperia Z ？

从三年前发布第一款 Xperia Z 手机开始，Xperia Z 系列一直是索尼手机的旗舰级产品。这也让 Xperia X 这条产品线变得非常有趣，弧面玻璃、金属后盖、「tone-on-tone」喷涂工艺等元素让 Xperia X 可以在外观上与 Xperia Z 系列区别开来；而从硬件配置上来看，Xperia X 系列也不简单的是 Xperia Z 在中低端的补充，尤其是 Xperia X Performance，它的性能甚至比 Xperia Z5 系列手机还要强。  

未来 Xperia X 会不会取代 Xperia Z 成为索尼的旗舰产品？或者是下一代的 Xperia Z6 还留着什么「大招」？
