消费版 HTC VIVE 即将于 4 月发售，售价 799 美元

据国外网站泄露，消费者版本的 HTC VIVE 将于今年 4 月开启预售，售价为 799 美元（比 Oculus Rift 贵 200 美元）。在这套设备中将附带两个手柄，一对「Light House」的 base station 进行室内捕捉，当然还包括了两个游戏。

此外，HTC 与 VALVE 联合发布了新应用：「Valve phone service」。在这套服务中，我们可以在 VIVE 头戴设备上接听电话，回复消息，查看日历等。

结合体验过的Oculus Rift CV1 来看， HTC VIVE Pre 定价 799 美元的价格所带来的体验还是可以接受。总得来讲，这套产品还是很值得期待。明天极客公园将会亲临 MWC 现场体验更多的 HTC VIVE Pre 的 DEMO 。更多信息将会随时更新。

当然，想要良好运行 HTC VIVE PRE 其实并不难，大概配置如下：

  • GPU: NVIDIA® GeForce® GTX 970, AMD Radeon™ R9 290 同档或更高配置

  • CPU: Intel® i5-4590 / AMD FX 8350 同档或更高配置

  • RAM: 4 GB 或更多

  • 视频输出: HDMI 1.4, DisplayPort 1.2 及以上

  • USB 接口: 1x USB 2.0 及以上

  • 操作系统: Windows 7 SP1, Windows 8.1 及以上, Windows 10 

从以上配置我们不难发现，HTC VIVE Pre 与 Oculus Rift CV1 对主机的要求相差不多。对 VR 感兴趣的发烧友直接配这么一套就好咯。
