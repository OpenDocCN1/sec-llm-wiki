历时 16 年的「超级访问」近期宣布停播，这挡在内地风光一时的娱乐访谈节目留下了辉煌的收视奇迹之后不得不和观众告别。而说起停播的原因和二人的转型有关，李静在微博中写道：「我们这十六年好像做了一场好长的梦，昨晚终于结束了……好斑斓哪……那一场叫做青春的梦……醒了，我该去追下一场梦了……」。这下一场梦两个老搭档已经在进行中了，就是现在在做的投资。

从娱乐圈到创投圈

李静想起早年自己创办公司的经历，「当年我在麦当劳写 PPT，现在我希望别人遇到自己所谓的伯乐，然后把别人成功的经验和失败的经验都来帮助我」。从主持人到创业者再到投资人，李静是他们身边胆子特别大的人。李静则笑答有好奇心、有胆、有趣，是她追求的生活态度。

李静去年发起了基金「星创投」，吸纳了那英、梁静、蒋雯丽、戴军等娱乐圈朋友，身经百战的企业界明星周航、王江。

Coffee Box 是「星创投」投资的第一个项目。在成立「星创投」之前，李静就已经和「连长」王江是好朋友，说起「连长」大家都不会陌生，航班管家的 CEO，作为天使投资人投了 UC 浏览器、美团等。后来连长做了 Coffee Box，李静就「鼓动」戴军去做天使投资人，「这个人可以让你下半生衣食无忧」，李静向戴军这样介绍连长。30 秒后，戴军就答应了，成了 Coffee Box 的天使投资人。

要做改变生活方式的咖啡

李静说因为咖啡是要送人的，所以应该有一个盒子，又是咖啡就叫 Coffee Box，这个名字就自然而然的就出现了。

连长说做 Coffee Box 这个主意是他三年前在星巴克「蹲点儿」想出来的。「我曾经连续几个下午在北京星巴克咖啡厅，对每个人做了详细的记录，连续 3 个下午的记录就可以知道其中 30% 是外带。」「我们想做一个自己能够生产，能够外卖的咖啡品牌，做一个咖啡的闭环。」于是 Coffee Box 就这样诞生了。

「无处不在，传情达意」是 Coffee Box 强调的品牌含义，想喝咖啡时候通过连咖啡的微信公众号下单，咖啡在 15-30 分钟之内就能送到，哥伦比亚优质咖啡豆和澳洲牛奶，「翻杯不洒」的外送杯型，专利的外送盒包，保证了送到用户手中的咖啡依然滚烫，口味和品质不变。你也可以选择下单送给亲戚和朋友，连长认为咖啡不仅仅是提神的饮料，它应该是一种生活方式，还是连接人与人之间的关系的载体。

「有 70% 的人希望送的咖啡当中有一段寄语，就是他希望咖啡有一个传情达意的方式。比如说这杯咖啡很温暖，或者今天你过的好吗？客户会有这样的需求」

明星做背书只能「锦上添花」

李静觉得，明星做投资并不能「雪中送炭」，只能「锦上添花」，如果公司没有提供优秀的服务和产品，明星效应反而会增加用户的失望度。Coffee Box 的第一批消费者是圈内的明星，有明星做背书，产品闪着光环也有不少「麻烦」，明星最大的特点就是挑剔。品鉴过很多东西，嘴就特别刁。

「这些明星奶奶们、明星大哥们，其实事儿特别多。但是他们给 Coffee Box 挑的毛病才是最大的价值所在。」

作为 Coffee Box 的天使投资人，戴军走到哪里都会拿一杯 Coffee Box 的咖啡。李静透露，那英在录《中国好声音》的时候，为了帮 Coffee Box 做宣传，拿着咖啡就去送给周杰伦了。如此支持 Coffee Box 不仅因为这是李静和戴军自己投的项目，还因为能够和自家的生意互补。李静在上海开了首家美妆咖啡体验店，是一家「让女人们既可以体验化妆，又可以坐下来喝杯咖啡的店」， 体验店自然不以销售为主导，而 Coffee Box 入驻之后辐射到周边消费咖啡的人群，一天能卖 200 杯左右，美妆店再跟 Coffee Box 分成，以此降低了运营成本。

用户在哪里，咖啡店就开在哪里

目前 Coffee Box 在上海已经拥有了超过 30 家生产点，每天能卖出 1 万多杯。无店面、无边际、无现金的「三无」概念让 Coffee Box 能够快速的开设生产点，且一个生产点的投资仅有十几万。而对于选址，Coffee Box 会从用户需求和成本结构进行考虑，找到用户最为密集、成本相对较低的地方设点。用户在哪里，咖啡点开在哪里。
