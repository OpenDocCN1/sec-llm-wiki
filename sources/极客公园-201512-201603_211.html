我们盼星星盼月亮终于等来了 Tesla Model 3。

这家电动汽车制造商马上就要接受买家的 $1000 预订款了。但很多消费者依然对于 Tesla 的第一台面向大众市场的量产汽车满怀疑问——顺便一提，这辆车的目标定价约为 $35000。

上周四 Tesla CEO Elon Musk 宣布，Tesla 将会于 3 月 31 日在它的商店接受预定，4 月 1 日接受线上预定。那么问题来了：

消费者什么时候能得到这辆汽车呢？

Tesla 预计将会在「2017 年 晚些时候」开始发货。所以即使你是最早一批预付 $1000 定金的顾客，也必须等待相当长的一段时间。

产能爬坡需要耗费一定的时间，但 2018 年的时候，早一批的买家应该就能上手他们的新车了。

它看上去什么样？

Model 3 应该是一款轿车——就像已经上路的 Model S 一样，但 Tesla 一定会严格为 Model 3 的外观设计保密。可以确定的一点是，它肯定不会有像 Tesla Model X 一样特别的「鹰翼门」。

Model X 的鹰翼门设计给特斯拉找了一个大麻烦，导致产量一直上不去。Model 3 没有鹰翼门，会比 Model X 容易生产很多。

它充一次电能跑多远？

虽然 Model S 基础版的续航至少是 240 英里，但 Model 3 可能没有那么强悍。由于成本的限制，Model 3 的电池将会更小更轻，而电池的体积决定了电动汽车的续航。

引用 Musk 曾经说过的一句话，任何纯电动汽车的续航最少应该是 200 英里。

需要多少钱，我才能入手它？

如前所述，Model 3 的价格大概会是基础版 Model S 的一半——$35000。买家将会有一定程度的所得税宽减额——国家会提供 $7500 的减免，一些州还会提供最多 $2500 的信贷额度。根据凯利蓝皮书，目前新车的平均价格大概在 $34000 左右。

它提供怎样的选项？

Musk 表示 Tesla 不急于在 Model 3 上开发一些新特性，以便于更快速地将它推向市场。这是他在 Model X 上学到的经验教训。「事后看来，其实在第一版的 Model X 上，无需完成太多的事情，可以随着时间的推进，慢慢完成其中的一些……完成一些新技术的迭代，」Musk 说道，「我确实认为 Model X 上，让人自满的地方太多了。」

当然，Tesla 上经常被人谈论的一些特点花费了上千美元才实现，而这对于一辆价格适中的车辆而言，有些不切实际。能让汽车在三秒内从 0 加速到 60 的「搞笑模式」需要花费 $10000，而自动驾驶仪需要再额外花费 $3000。

但定价 $35000 的 Model 3 一定会受到大众的欢迎。当初特斯拉制定的跑车-豪华车-「大众」车这三个阶段的产品战略，将在今年完全实现，到时候不管是在产品层面还是在公司业绩层面，作为样本和榜样形象存在的特斯拉，都会形成一个更加完整的模型。
