五年后，雷电接口总算不再是苹果的「专属玩具」

未来我们会在更多的 PC 上看到雷电（Thunderbolt）接口，但你可能不会意识到它的存在。


2011 年初，英特尔推出了第一代 Thunderbolt （雷电）接口，Thunderbolt 采用了 PCI-E 和 DisplayPort 技术，使用专用接口并兼容 miniDP。这项技术由英特尔和苹果合作开发，苹果随后把 Thunderbolt 接口变成了自家 Mac 产品的标配。

凭借极高的技术规格，自 Thunderbolt 诞生之日起，它的传输速率和同时期的 USB 接口相比一直都有着压倒性的优势，最新的 USB 3.1 协议传输速度为 10 Gbps，和五年前的第一代 Thunderbolt 速度速率相同，而最新的 Thunderbolt 3 最高速率已经达到了 40 Gbps。

不过由于成本高昂同时第三方配件稀缺（相比 USB 方案而言），过去几年中除了 Mac 之外，搭载 Thunderbolt 接口的电脑屈指可数，Thunderbolt 似乎要变成新一代的火线（FireWire）接口——虽然速度更快，但第三方配件的匮乏让它难以成为主流。

当 Thunderbolt 3 遇到 Type-C

转折点出现在 Thunderbolt 3 上。去年中旬，英特尔发布了全新的 Thunderbolt 3 接口标准，除了用 4 条 PCI-E 3.0 通道将数据传输率提高到夸张的 40 Gbps、支持 60 Hz 的双 4K 输出等这些性能提升之外，英特尔还接纳了 USB 的端口定义标准，把 Thunderbolt 3 接口外形做成了USB Type-C 的样子，并可以兼容 USB Type-C 接口的配件。

▲采用 USB Type-C 接口的 MacBook

需要注意的是，Type-C 只是 USB 接口的一种，采用 Type-C 接口的既可以是 USB2.0（目前大部分智能手机上用的 Type-C 都是这种），也可以是 USB 3.0 或者 USB 3.1，比如12 寸 MacBook 上的 Type-C 传输速率则达到了 USB 3.0 的 5 Gbps。凭借丰富的功能、支持多种 USB 规格、体积小、不分正反等优点，采用 Type-C 接口的 USB 设备有望在未来短时间内大量普及。

通过兼容 Type-C 接口，即便用户没有专门为 Thunderbolt 3 设计的配件，也可以把 Thunderbolt 3 接口当做普通的 USB Type-C 接口使用（最高速率为 5 Gbps）；如果用户使用支持 Thunderbolt 3 的外设，则可以获得更快的 40 Gbps 传输速率。

也就是说，Thunderbolt 3 在保证了它领先的传输速率的同时，也将兼容未来市面上最主流的 USB 设备。

不再「曲高和寡」

在兼容 Type-C 之后，很多此前对 Thunderbolt「爱搭不理」的 PC 厂商也突然对这个接口产生了兴趣。

▲ 配备 Thunderbolt 3 接口的戴尔 XPS13

在刚刚结束的 CES 2016 上，几乎所有的主流 PC 厂商都推出了支持 Thunderbolt 3 接口的产品，比如采用「无边框」屏幕的新版戴尔 XPS13 和 XPS15，以及联想 ThinkPad P50 和 P70，惠普、Acer 等其它 PC 品牌也推出了配备 Thunderbolt 3 的笔记本电脑。

虽然 Thunderbolt 3 会不可避免的增加产品的成本，但凭借 Thunderbolt 3 更快的传输速率和兼容 Type-C 带来的额外好处（包括输出视频信号、直接为 PC 充电），Thunderbolt 3 大有在未来成为 PC 产品「标配」的趋势。

更广阔的未来

Thunderbolt 3 的普及还会带来一些额外的好处。

第一个好处是相关配件价格的降低，随着配备 Thunderbolt 3 接口的 PC 越来越多，配件厂商会在未来推出更多支持 Thunderbolt 3 的配件，Thunderbolt 3 相关配件的售价有望在短期内大幅下降。Thunderbolt 3 还会让 USB 拓展坞这种传统配件「重获新生」，由于带宽远高于 USB，Thunderbolt 3 接口可以让用户在拓展坞上同时使用更多的设备而不影响传输速率。

▲ Razer Blade Stealth （左）和 Razer Core （右）

此外，Thunderbolt 3 的高带宽和丰富的功能还可以帮助厂商设计出更加强大的配件，比如前几天我们介绍过的 Razer Blade Stealth 笔记本电脑。通过 Thunderbolt 接口，这款笔记本电脑可以连接 Razer Core 的显卡拓展坞，以实现更强大的游戏性能。如果 Razer Core 的兼容性和稳定性上有所保障，其他 PC 厂商有望很快推出类似的产品。而这可能也是轻薄笔记本电脑的未来形态，它看起来和「正常」的轻薄笔记本电脑没什么区别，在需要更强的性能时，再接入一个外接显卡拓展坞就可以了。

一年前，PC 行业内似乎没有人看好 Thunderbolt 的发展前景，因为当时广泛采用的 USB、DisplayPort 等接口已经足以满足绝大多数用户的需求，Thunderbolt 这种「高大上」的技术只在那些愿意用「一块钱买三分货」的小众圈子里比较流行。

不过兼容 Type-C 接口让 Thunderbolt 重新回到了大众视野中，虽然 Thunderbolt 距离像 USB 那样普及还有很长一段路要走，不过幸运的是，我们未来可以像使用下一代 USB 产品（Type-C）那样使用 Thunderbolt。
