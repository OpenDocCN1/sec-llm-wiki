> 如果有一部怎么摔屏幕都不会碎的手机，它会给我们的生活带来哪些不同？

![](../Images/017b06d2be143ebdc90ad914e88bfdc5.png)每个 iPhone 智能手机用户都有一个「玻璃心」，一不小心正面着地屏幕就碎了。而一旦手机摔碎，除了价格不菲的换屏问题，还可能会引发影响工作、漏接电话等一系列的「连锁反应」。根据KRC Research的一份调研报告的数据显示，全球53%的智能手机用户经历过屏幕碎裂，21% 的用户在使用已经破碎的手机，每1-2秒就有一部智能手机被摔碎。  

很多时候，我们比想象中更担心自己的手机屏幕被摔碎，为了证明这件事，Moto 联手极客公园做了一个有趣的实验挑战：

📹 [https://v.qq.com/iframe/preview.html?vid=h0180la6di4&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=h0180la6di4&width=500&height=375&auto=0)

根据KRC Research的一份调研报告的数据显示，全球53%的智能手机用户经历过屏幕碎裂，21% 的用户在使用已经破碎的手机，每1-2秒就有一部智能手机被摔碎。而视频中，鬼才作家马伯庸最后扔出的那款手机，就是 2015 年底 Moto 新发布的年度旗舰产品——Moto X 极，这款手机最大的特点，就是拥有一块「摔不坏」的屏幕。

相信很多消费者在买来新手机后的第一件事就是给手机「贴膜带套」，这基本上也是目前唯一一种低成本并且相对有效的防止屏幕被摔碎的方法，然而即便是贴了钢化膜，手机屏幕还是有可能被摔碎。

在手机行业已经进入硬件同质化严重、软件应用也大同小异的时代， Moto 花了三年的时间，开发了 Moto ShatterShield™ 极御技术。Moto 表示「这一技术的应用彻底改变了手机屏幕破碎的历史，从根本上解决了手机产品运用玻璃材质作为屏幕而容易碎裂这一设计上的不足，是Moto为手机用户带来的又一突破和创新。」

而极客公园作为国内最大的创新者社区，对Moto这一关乎用户使用体验的创新也非常关注，所以一同打造了此次「极°挑战」实验。

现在，极客公园就为你揭开「摔不碎」的屏幕的秘密：

MotoX 极 最大的卖点就是这块采用了「ShatterShield™极御技术」的防碎屏，这块屏幕采用了 5 层复合结构，其中显示层为柔性 OLED 材质，可以承受一定程度的形变。事实证明，Moto X 极 的这块「摔不碎」的屏幕的确名副其实。在国外媒体的一些极端测试中，即便是冲击力大到足以损害 Moto X 极 的内部组件，这块屏幕也不会碎掉。

📹 [https://v.qq.com/iframe/preview.html?vid=e0180kp699n&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=e0180kp699n&width=500&height=375&auto=0)

值得注意的是，由于要「防摔」，Moto X 极 的最外层并没有采用常见的康宁大猩猩保护玻璃，而是一层特殊的保护层，手指在屏幕上滑动时的感觉非常接近玻璃，不会有手机贴上塑料膜那种涩涩的感觉。  

![](../Images/a561733746001d6dd763ff2cea7ca6d2.png)

可能不是每个人都会喜欢 Moto X 极 硬朗的设计风格，也不是每个人都能接受它 5288 起的售价，不过凭借那块摔不碎的屏幕，Moto X 极 的确有它独特的卖点。在使用 Moto X 极 的一段时间里，我不必担心「手滑」把屏幕摔碎，也不需要担心手机摔落的瞬间所造成的心理惊吓和随之带来的一系列烦恼，这种使用时的「安全感」也是市面上其它智能手机无法提供的。

在极客公园看来，这款摔不碎的手机能解决的，远远不止一个挑战，它将改变手机与用户之间的关系，治愈手机「玻璃心」，让手机成为与使用者的「长情伴侣」。
