那些在 CES「包场刷脸」的中国面孔

占据 CES 展商数量三分之一的国内团队是什么样的存在呢？


一年一度的 CES 就这样迎来了尾声，极客公园对本届活动进行了全面报道。在这个目前全世界最大规模电子设备展会之一的 CES 上，中国展商数目占所有展商的 1/3（1300/4119）。不能否认，今年 CES 上有不少令人眼前一亮的中国团队，但老实说，相对这 1300 家中国展商，好团队实在太少，混脸的实在太多。

刷脸&展示

不论是在 CES 的主会场 LVCC 还是第二会场 Sands，大部分来自国内的参展商都被安置在无人围观的角落或地下，模板化的展台也体现不到任何区别。就更别提最关键的游客了。这些展商的工作人员基本都是三三两两地聚拢一起，刷着手机，聊着天。

「花钱在 CES 上盘一个展位，回去就可以说我在美国这边办展了，万一有人看上了，那岂不是更好？」一位智能硬件领域的参展人员是这么跟我表示他们参加的初衷，当我询问你能否演示一下这个产品时，他却婉言拒绝。

这些充斥着浓浓华强北气息的硬件产品来参加 CES 基本上都是一个目的：刷脸。不得不承认来这里的人都是想借「CES」让自己火一把。然后回去给媒体和投资方说点好消息。可百货店般的布局和商品仿佛给我一种逛中关村中发电子的感觉，但这是给外国人看的。

山寨&创新

前天的 CES 上还发生了一件很有代表性的事：中国一家电动滑板公司展台被美国警方搜查并没收，原因是涉嫌侵犯另一家海外公司的专利。而根据其他人员透露，这种事儿在 CES 上也不是一次两次了。

▲ 案件主角

山寨现在已经成为外国人眼里的中式代名词，「借鉴」设计再二次加工贩卖或许在这里有可行性，可一旦与海外原创团队进行正面碰撞后，冲突自然不能避免。多数厂家（尤其是移动交通和无人机领域）在这里都出现了水土不服的现象。什么来钱做什么，创新仿佛并不是他们关注的事儿。

在做摆渡巴士时，一个参观 CES 的游客向我询问你们国家是不是很喜欢模仿火热的产品，再生产后卖向全世界。我只能无奈地向他解释，这里面有相当一些厂商并不能代表中国。

不否认所有的厂商

当然，并不是所有的国内展商都在做山寨的产品。也有很多国内厂商在向海外传播国内的一些创新思路。

海尔公司在本次 CES 上发布了一个名叫 Ubot 的智能机器人。它除了可以进行语音对话，控制智能家居设备外，还可以监控室内环境，如有突发事件可以立即报警。海尔集团 CTO 赵锋博士向极客公园表示：「目前国内的电器设备从价格到技术已经出于世界前列，在掌握一定数目的用户量后，以物联网为今后的方向进行拓展是一件非常有必要的事情。」将机器人作为信息终端的家用电器或许对产品生态有所延伸。

还有国内的轻客团队也在 CES 上推出了新的折叠版电单车 TF01。它除了能够以折叠形式方便携带外，还能够提供长达 50 公里的电机辅助距离。有趣的是，轻客还与其他传统自行车建立合作关系，提供传统自行车改造为电单车的解决方案。

除了上文所述的团队之外还有大疆，乐视等国内公司通过参展产品吸引了人们眼球。可从 1300 家企业的庞大基数来看，还需要有更多有质量的企业在 CES 上露脸，我们期待在明年的 CES 上能够有更多的国内创新团队将中国的创新带给世界。
