想玩游戏还要轻薄？Razer 给出了「终极解决方案」

轻薄本性能不好，游戏本太笨重，能不能把这两类产品的优点结合起来？Razer 就发布了一款这样的笔记本电脑。


在笔记本电脑中，轻薄和性能一直是一对「矛盾体」，很多优秀的产品也只是能做好其中一个方面。如果非要试图同时在这两个方面做到极致，结果则可能是在散热、续航、价格等更多方面做出牺牲，往往得不偿失。因此，为了满足需求，就出现了很多「双脑党」：玩游戏用一个电脑，出门办公用另一个。

在 CES 2016 上，Razer 推出了 Blade Stealth 笔记本电脑。对于轻薄和性能无法共存的问题，Razer 似乎找到了一个完美的解决方案。

大「瘦身」的 Razer Blade

和之前的 Blade 系列笔记本电脑一样，Razer Blade Stealth 也拥有很高的「颜值」，外壳的材质为铝，采用了 CNC 切削工艺。当然，作为「灯厂」家的产品，键盘灯也马虎不得，Razer Blade Stealth 是第一款拥有独立 RGB 背光键盘的笔记本电脑，用户可以随心所欲地定制键盘背光的颜色。

同时，相比此前 Blade 14「高达」2 公斤的重量，Blade Stealth 的机身重量大幅下降到 1.25 公斤，厚度也仅有 1.3 厘米。不过考虑到 Blade Stealth 的屏幕尺寸仅有 12.5 寸（Blade 14 为 14 英寸），它的重量其实并不能算很轻。

配置方面，Blade Stealth 的所有版本都会配备 Intel 最新的 i7-6500U（Skylake 架构，双核四线程），虽然是没有使用「H」结尾的高性能版本，但低电压 i7 在面对绝大多数游戏时应该不会成为瓶颈。不过在 GPU 方面，Blade Stealth 仅仅使用了处理器中集成的 Intel HD 520 显卡，虽然 HD 520 比起前代的 HD 5300 性能上有了很大的进步，但对于游戏玩家而言，再好的「集显」显然也都是不够的，不过 Razer Blade Stealth 通过一个非常巧妙的办法解决了显卡性能不够的问题。

Razer Blade Stealth 上有两个 USB 接口以及一个兼容 Thunderbolt 的 USB Type-C 接口，这个接口就是解决问题的关键。

「聪明」的显卡拓展坞

Razer 为 Blade Stealth 设计了一个叫做 Razer Core 的显卡拓展坞，这个拓展坞看起来很想一个迷你桌面 PC 主机，把它从侧面「拉」开后，用户可以自行安装 PCI-E 接口的独立显卡（需要用户额外购买），Razer 表示这个显卡拓展坞可以支持 NVIDIA 和 AMD 的绝对多数显卡。除了插独立显卡，这个拓展坞背面还拥有四个 USB 接口和一个网线插口。

在给拓展坞接上电源后，就可以通过上面提到的 USB Type-C 接口把 Blade Stealth 和显卡拓展坞连起来了。连接显卡拓展坞后，用户在玩游戏时就可以利用拓展坞里的独立显卡，从而大幅度提高性能。此外，用户还可以给 Blade Stealth 配上外接显示器和键鼠，以进一步提高游戏体验。

类似的解决方案其他厂商也用过，比如说在去年九月份的 IFA 上，华硕就推出了一款支持「水冷」独立显卡底座的 GX700 游戏笔记本，不过 Razer 更进一步，把这个独立显卡底座换成了用户可以自行更换显卡的「容器」。

对于预算有限、无法「一步到位」买齐所有装备的用户，Razer Blade Stealth 也提供了一种「分步来」的方案，用户可以先购买「基础」的 Blade Stealth 笔记本电脑，之后再购买 Razer Core 显卡拓展坞和独立显卡，而且由于采用了显卡可拆卸的设计，如果感觉显卡性能不够，用户还可以继续升级独立显卡。

不「Razer」的定价

值得注意的是，配备 2K 分辨率屏幕的 Blade Stealth 低频版售价「仅有」999 美元，4K 屏的高配版则为 1599 美元（国行版售价分别为 7999 和 12499 ），虽然这个价格依然和「高性价比」没多少关系，但已经大大低于此前 Blade 系列笔记本电脑的售价，Blade Stealth 将于本月内在美国上市。不过对于关注度更高的 Razer Core 显卡拓展坞，Razer 尚未公布它的具体售价和上市时间。
