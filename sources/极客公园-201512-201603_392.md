# 微软的 2015 年：度过「中年危机」的科技巨头重焕青春

> 微软在 2015 年做了很多事。它进行了史无前例的收购、变革了保守的作风、推出了多款有竞争力的硬件产品。这可能是微软这十年来最有战略意义的一年。

![](../Images/dbcf83c7e48d159c5702f3b0506af6aa.png)  
2015 年，微软很忙。

虽然 Windows 操作系统帮助微软在 PC 端获得了数十年的领头地位，但随着移动互联网的兴起，微软的脚步变得沉重起来。在移动领域反应的迟缓让这个科技巨头不断遭受外界质疑，这个但随着新任 CEO 萨蒂亚·纳德拉（Satya Nadella）的上任，微软在这一年、在一些领域进行了颠覆性的突破，而纳德拉所提出的**「移动为先，云为先」**的战略也象征着微软正在移动互联网的道路上努力追赶着那几个对手。

在这一年，苹果一如既往地吸引着众人的眼球，Google 也在按照自己既定的路线稳步前进，而 Facebook 更是在这一年为向一家综合性科技巨头转型做好了准备。「步入中年」的微软虽然一度在移动互联的浪潮有些「掉队」，但随着新任 CEO 萨蒂亚·纳德拉（Satya Nadella）上任，以及「移动为先，云为先」战略的提出，微软开始大踏步向移动化转型，并且空前对云服务和技术层面加以重视。

![](../Images/4079a8e5c3e183f87f39e36210f0033f.png)

## **收购！收购！**

根据微软自己公布的信息，他们在 2015 年里完成了惊人的** 20 次收购**！这是微软公司在其 40 年历史上的最高记录（下表是 2015 年微软的收购动作）。

![](../Images/56f4dbdc83c5c85143fc7ea76f2401f6.png)

在这些收购中，我们能够看出微软的收购主要集中在两个方面：**1\. 在某项技术上有优势的中小型公司；2. 已经取得初步成功的应用。**

其中引起比较大反响的是 Sunrise、Datazen、Wunderlist、FieldOne、Adallom、Havok、Metanautix。从中，我们既能看出微软在技术领域继续保持深耕的决心，又能看到它在移动端应用领域加紧追赶的步伐。

以其中最被普通用户熟知的 Sunrise 来说，首先，微软在 2014 年年底收购了新兴的邮件应用 Acompli，这个邮件应用因为它可以支持微软 Exchange Server 服务器、整合了日历等功能，吸引了微软的注意力，因此，这个在 iOS 平台上颇受好评的邮件应用被纳入了微软的阵营。而不久之后 Acompli 就被微软打造成了新版的 Outlook。接着，微软在去年年初花了 1 亿美元收购了可能是「移动端最好的日历应用」的 Sunrise。最后，在去年年底，微软将 Outlook 和 Sunrise 这两个很受欢迎的应用整合在一起。虽然很多用户对这两个优质应用的消失感到很不满，但这确实是微软在移动端做出的一个令人称道的努力。

![](../Images/028330b3be835683fee7f5a5db3f80a4.png)

微软在新的一年还会保持这样的大规模收购行动吗？这点很令人好奇。据传言称，微软很有可能要在新年收购近期最耀眼的企业级产品 Slack，如果成真的话，那又会是微软在企业级办公领域的又一大助手。不过可以肯定的是，微软对于技术型创业公司的兴趣绝对不会降低，事实上这也是他们和 Google 等其他巨头争夺的焦点。基本可以肯定的是，2016 年我们还会看到不少微软和那些中小型技术公司的「绯闻」。

## **张开怀抱**

收购固然是微软加速转型的一个策略，但在 2015 年，微软更令人惊喜的是它对自身进行的改造——

*   推出 iOS 版 Outlook；
    
*   推出「牛津计划」，牛津计划是在微软一系列机器学习 API 组合的基础上扩展而来，藉由牛津计划，开发人员能够在他们的应用中轻松添加智能功能，其中提供了许多基于 REST 架构的 API 和 SDK 扩展包，这些扩展包将帮助开发者创建智能应用程序；
    
*   为 Mac 上的 Office 2016 增加了很多新功能，并可以为 Office 365 用户提供使用权限；
    
*   对旗下数字笔记应用 OneNote 的 Android 版和 iOS 版进行了大量改进，并将 iPad 版和 iPhone 版 OneNote 将整合为 iOS 系统通用版；
    
*   为 iOS 平台推出 Invite 会议组织应用；
    
*   将分布式机器学习工具包 (DMTK）通过 Github 开源；
    
*   正式向 iOS 和 Android 平台推出 Cortana 数字助理服务。
    

......

看着以上这一系列的动作，在两年前，你也许会怀疑：这是微软会做的事吗？但事实证明，微软在 2015 年向更广阔的互联网世界张开了自己的怀抱。

在 2015 年，微软为 iOS 和 Android 平台量身打造了多款应用，还在年底的时候向 iOS 和 Android 平台重磅推出了自己非常看重的虚拟助手 Cortana。事实证明效果也不错，至少用户能在移动端的不同平台上都能看到微软的身影了，像 Skype 这样的老牌应用也重焕生机，重返了 App Store 排行榜的前 50。

与此同时，在走出自家领地，拥抱不同的平台之外，微软也在向外寻求更开放的合作与发展的机会。其中最令人感到惊喜的就是**牛津计划**。在年中的时候，相信很多用户都玩过通过面部识别来判断年龄的应用 How-Old，这就是牛津计划的作品。在这个项目中，微软展现了很久未曾在他们身上出现过的「有趣」和「开放」。一系列有关人脸识别、语音识别、计算机视觉等前沿科技的 API 都向用户免费开放，而这种开放性的思路似乎才是微软带给用户的最大惊喜。

![](../Images/2a4ce3ad06fb94d45fd0be9dfa38f4dd.png)

在 2016 年，我想我们会继续看到这样一个开放的微软，像牛津计划这样合作共赢的项目也会继续出现，而用户只需期待微软在这种全新的思路下带来更多更好的产品。

## **硬件****进击**

在 2015 年，微软在整体的战略思路及软件应用方面有了很大的突破，而近几年一直致力于「两只脚走路」的微软自然也不会在硬件方面有所懈怠。事实上，微软去年在硬件方面的表现甚至可以用**「进击的微软」**来形容。

在上周，极客公园已经为大家做过[微软去年在硬件方面的盘点](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=403137103&idx=1&sn=0b7681d83938a9a46afaaa6a7492bc89&scene=21#wechat_redirect)了。我们在这里为您整理了一下这方面的内容。配合以上微软整体布局的变化，也许我们能对微软的 2015 年有一个更全面的理解。

Windows 10 可能是微软在 2015 年最重要的产品，它统一了微软的桌面平台，是微软的「Windows 无处不在」愿景的重要一步。不过重要归重要，Windows 10 并不是微软 2015 年最有趣的产品，微软今年推出的最有趣的反而是两款硬件产品：**HoloLens AR（增强现实）头盔和 Surface Book 可变形笔记本电脑。**

HoloLens 展示了微软宏大的愿景——一种将 3D 视觉技术和真实世界融合的人机交互方式。现在没人清楚地知道 HoloLens 未来能做什么、基于这项技术会出现什么样的应用场景，但即便是如此，大家对 HoloLens 似乎还是异常的兴奋，这种兴奋从 HoloLens 刚开始出现一直持续到现在，人们相信微软做了一个全新而且充满冒险性的东西，有很多人愿意和微软一同探索 HoloLens 的未来。

![](../Images/7b301a1866935e663ac8f9b61e4adc88.png)

和 HoloLens 相比，**Surface Book** 是一个更加现实的产品。精致优雅的转轴，内置的支持热插拔的 NVIDEA 独立显卡，再配合优秀的屏幕、手感出色的键盘和触摸板，Surface Book 是一款非常均衡，并且可以适用于多种场景的笔记本电脑。Surface Book 不是第一款「变形本」，但微软把它做得比之前任何一款「变形本」都要出色。

相比各种「黑科技」加持的 Surface Book，**Surface Pro 4** 显得要低调很多。但相比 Surface Pro 3，Surface Pro 4 在屏幕、散热、性能、键盘底座等诸多方面都有了一定的进步，或许单看一个方面不会显得特别明显，但把这些细节的进步加在一起，让 Surface Pro 4 的用户体验有了明显的进步。在作为笔记本电脑使用时，Surface Pro 4 也完全有实力 PK 同级别轻薄笔记本。

相比在笔记本市场的成功，微软在手机市场由于战略性的失误，的确呈现出一种大厦将倾的趋势。**Lumia 950/950XL **推出后，不少诺粉（Lumia 粉）还在盼着 Lumia 950/950XL 能不能拯救 Windows 手机。但没过了多久，我们就意识到是自己想多了。「媲美」国产千元机设计和做工以及「比肩」iPhone 的售价让 Lumia 950/950XL 毫无性价比可言；虽然「披」上了 Windows 10 的外衣，但软件体验和 Windows Phone 8.1 并没有多大变化，第三方 App 依然是那个永远的痛；至于「革命性」的 Continuum，除了几个微软自家的 App，几乎没有第三方 App 支持。

展望明年，即将推出的 HoloLens 开发者版将会至关重要，如果顺利的话，微软将会证明他们的确可以设计出大胆、创新的产品，他们有能力重塑我们的未来世界。

## **结语**

2015年是对微软意义重大的一年。在这一年，他们在战略上进行了多笔重要收购；在技术开发上变得更加开放；在硬件方面进击式地前进；在软件方面稳步拓展。

而在新的一年，更加开放的微软还会有 HoloLens 这样重磅的产品将要推出。我们有什么理由不对这样的微软抱有更多期待呢？
