# CES 观察｜消费级无人机：烫手的还是概念

> 火爆的概念背后是疲软的消费市场，无人机领域亟需新玩法和新玩家的加入。

![](../Images/9661b9597534ff7f35065f36def93ef6.png)  
豪不夸张地说，今年的 CES 的无人机展区几乎成为了「中国队」的主场。大疆、零度的展区人头涌动，亿航新发布的载人无人机吸引了一圈拍照的人群。除此之外，你还能看到很多来自深圳的新面孔。

![](../Images/4d92c223d65ae018f89851aa1d175bff.png)

*▲ 亿航的载人无人机*  

在无人机展区逛上一圈，一定会让你觉得这个市场异常繁荣。但崛起的中国力量和异常火爆的概念背后，有着一个残酷的现实：消费级无人机市场并没有发展起来，目前无人机的火爆依靠的仍旧是是专业市场的支撑。

![](../Images/bd1383d056c6202af9a9fac19531b301.png)

*▲ CES 大疆展区*

除了专业的视频拍摄团队和小部分尝鲜的极客，现阶段无人机还不会出现在大多数人的购买清单上。除了大家讨论更多的价格因素，我认为消费无人机也面临着「如何带出去」和「如何更好玩」两个问题。

在今年的 CES 上我看到了消费级无人机的一些新变化，这也正式 CES 最吸引人的地方——这个每年年初召开的展会可能会预测未来一整年的技术趋势，甚至还会更久。

## **折叠，然后放进背包**

我们都会感叹于无人机在「上帝视角」所拍摄的美景，但除了影视剧的拍摄团队等专业团体，几乎没有普通人喜欢在出游时带上无人机。背后的原因不外乎是重量和尺寸牺牲了便携性。

举个身边的例子。极客公园的团队驱车从旧金山前往拉斯维加斯参加 CES 时，5 号公路上的一路上美景让我们产生了航拍的冲动，可惜当初我们在国内准备装备时，因为装无人机的箱子太占地方而被迫放弃。

虽然现在市面上已经可以看到很多超小型的无人机，但若想获得一个可接受的续航时间和拍照质量，机身的尺寸并不可能无限制缩小，250mm 轴距是一个分水岭，这时候可折叠的设计就变得有意义了。

![](../Images/07d18f8a9eedd3c1309020c3cb595d7e.png)

*▲ 不同轴距对比*

在今年的 CES 上，已经能看到了好几款可以折叠的无人机，这个现象在去年是没有出现的。这些产品里有来自零度的 XPLORER Mini，它折叠起来后可以放进一个杂志般的盒子中；而 ProDrone 的 Byrd 系列无人机有着「全尺寸」的机身，但能够以一个非常优美的姿态折叠起来；Yuneec Typhoon H 拥有向下折叠的机翼等等……

![](../Images/fd4e87439f7a0ecf59fbd15ca17a7cff.png)*▲ XPLORER Mini*  

***![](../Images/3ecbb7fad1886fbb77a688e77e733983.png)****▲  ProDrone Byrd *

***![](../Images/2881a776b2b1ee7a587ef772641d3b23.png)****▲ Yuneec Typhoon H（本图取自网络）*

来自上海的九鹰无人机展示了一款名为「Mola X 1.0」的概念无人机，它通过旋转的方式把无人机折叠起来，体积也会缩小很多。  

***![](../Images/71dd597742618f5693ed8bbbecebe0fd.png)***

*▲ Mola X 1.0*

一位无人机的创业者在跟我聊天时谈到，之所以现在能够折叠的无人机很少，主要是折叠的连接部分会影响整个无人机的强度，而且制造工艺也会更加复杂，但可折叠设计所带来的便携性确实是很吸引人的。

大疆 Inspire 1 可升降起落架的「变形」设计是现阶段比较可靠的「便携方案」，但未来会出现更多的可以放进我们背包的可折叠无人机——解决「如何带出去」的问题将是消费级无人机真正走向大众的必经之路。

## **新玩家的加入，来自内容和芯片领域**

目前无论是 VR还是无人机都无一例外地遇到了内容的瓶颈。如果说 VR还是 属于「无内容可用」，无人机则是「内容没法输出」。

如果你编辑过航拍视频，一定会清楚下载飞机里的视频到手机上有多费时费劲。更多地时候，我们需要收回飞机，取出存储卡，然后连接电脑。但很多时候我们只是想在社交网络上告诉大家我们用无人机拍了一个好看的视频而已。

![](../Images/8c634f476145d6208d1bb0c68790aade.png)

据极客公园了解，在今年的 CES 上，腾讯互娱将和零度无人机进行合作，未来无人机拍摄的视频可以通过流媒体直接分享到 QQ 或微信上。想象一下，未来的某个黄金周，你的朋友圈被无人机航拍视频刷屏的场景吧。

去年秋天，高通发布了「骁龙飞行平台」(Qualcomm Snapdragon Flight) ，它基于骁龙 801 芯片，集成有 4K 高分辨率相机支持、图像增强和视频处里能力。今年 CES 上，搭载这个平台的无人机也进行了亮相。

![](../Images/62764f9d457197550182a51f557d084c.png)

就像高通的处理器之于智能手机一样，高通也希望骁龙飞行平台将成为无人机运转的最核心部件。高通可以为无人机带来更快的充电速度和更长电池续航时间，当然更重要的是成熟的平台可以大幅降低消费级无人机的开发成本。

去年 CES 上，英特儿分享了无人机应用的实感技术（RealSence），它可以帮助无人机自动避障。在今年 CES 上，CEO 科再奇展示了采用英特尔实感技术的 Yuneec Typhoon H，它将于今年上半年正式面世。

拥有了完备的内容分享平台和设计制造环节，随着芯片厂商的加入，无人机的「生态圈」也将变得更加完善。

## **除了航拍，好玩也很重要**

我也经常使用无人机，但都是出于工作的原因。至少从目前操作无人机对我来说不是一件有趣的事情——我要集中注意在操纵和拍摄上，同时起飞和降落过程也让我不得不变得小心翼翼。

在让无人机变得好玩这件事情上，Parrot 可以说一直走在前列。在今年的 CES 上，Parrot 发布了固定翼的无人机 Disco。这款飞机的速度可以达到 80 公里每小时，前置的摄像头配合 FPV 设备可以获得一个「临场感」极强的飞行体验，更为关键的是，可拆卸的机翼让你不用担心机翼损坏的问题。

![](../Images/730a0680a84591b2047d69626b24c145.png)

在采访中，Parrot 的 CMO 直接明了地告诉我，Disco 就是想让大家像玩游戏一样去飞无人机，45 分钟的续航时间也超过了市面上大多数无人机。好玩也应该是无人机的属性之一。

CES 上还有一架名叫 Fleye 的无人机非常有趣。它前不久登录了众筹网站 Kickstarter。不要看它的长相「略萌」，但是隐藏的旋翼设计和自动避障功能让它可以跟人更为亲密地互动，甚至把遥控器交道小朋友的手中。

![](../Images/22ed89cae915891c6cb0ca58b5877058.png)

*▲ Fleye*  

说实话，对于现在的消费级无人机确实有点审美疲劳了。四周旋翼，或方或圆的机身加上航拍相机就构成了我们「印象中的无人机」。

如果消费级的无人机可以出现更加多元的形态，同时可以不只是一个航拍的工具，那一定会吸引更多的人群，尤其是那些具有一定购买力的「大男孩」，他们可能只是单纯地追求一个操纵感。

## **除了提升像素，航拍相机还能怎样进步？**

事实上，今年几乎所有的旗舰无人机都能拍摄 4K 视频了，不过我关注的并不是分辨率的提升。红外摄像机的加入将会给航拍内容带来一些新鲜的东西。

去年年底，大疆宣布与红外热成像仪厂商菲力尔（FLIR Systems）合作，打造一款名为 Zenmuse XT 的红外航拍相机。今年在 CES 上，也出现了好几款搭载红外航拍相机的无人机。

![](../Images/cabceac8c9d6d966171f09a247208a55.png)*▲ 红外航拍相机*

红外技术对于消防、农业领域意义非凡，同时也会吸引一些喜欢猎奇（拍摄夜晚的动物等）的潜在消费者。要知道，现在已经有人愿意为 iPhone 去购买一个红外摄像头配件了。

![](../Images/c19f656d3757d470e1d0c6cde0de5ec0.png)

现阶段专业的无人机在农业、测绘甚至是军事领域早已经很成熟了，但消费无人机目前仍处于一个技术平台期，相信这些 CES 上展示的新玩法和新玩家将会带来变数。

能够方便的将它们带出去，能够变得更好玩，未来再加上内容的助推，芯片厂商的支持，相信那时候消费级的无人机一定会进入一个全新的阶段。
