![](../Images/9661b9597534ff7f35065f36def93ef6.png)  
乐视在 CES 期间发布了首款搭载骁龙 820 的手机乐 Max Pro ，极客公园也是在第一时间拍摄了上手体验。

不得不说，骁龙 820 抢走了这部手机不少风头。但在我们看来，还没有普及的 Sense ID 指纹识别和 802.11 ad WiFi 才是真正属于未来的技术，我们也会在之后的评测中为大家带来更丰富的信息。

下面是极客公园在拉斯维加斯拍摄的上手视频，让我们先对乐 Max Pro 有一个全面的了解：

📹 [https://v.qq.com/iframe/preview.html?vid=l01798c97sx&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=l01798c97sx&width=500&height=375&auto=0)

究竟哪家厂商能够取得骁龙 820 的首发机会，已经成为最近手机圈的一个热点话题。高通想要尽快翻过骁龙 810 这一页，各家手机厂商也在为下一代旗舰手机寻找一颗更为强大的「心脏」。  

最后，还是乐视抢占了先机。

虽然 CES 并不是智能手机的「主战场」，但从中国远道而来的乐视还是带来了这款重磅的产品：首款搭载骁龙 820 处理器的手机乐 Max Pro。

![](../Images/ddd7eab23e949c36a8c8466a7450baa4.png)

乐 Max Pro 延续了乐视超级手机的设计语言，全金属机身加上背部的弧线让它拿在手里还是很有质感的。乐 Max 的超窄边框也得以保留，整体来说，这是一款让人有把玩冲动的手机。

![](../Images/7841a7adb990e0ea756f00e820266683.png)

14 纳米制程的 Kryo CPU+ Adreno 530 GPU+ Hexagon 680 DSP 构成了骁龙 820 计算架构的「铁三角」，我们在现场用安兔兔跑了下分，达到了比较夸张的 11 万分。现场简单的体验来看，整体都很流畅、「丝滑」，完全不用担心性能上的问题。  

![](../Images/b6ddecf7d78c485eadb33b9c4bbdfb12.png)

除了这颗自带「主角光环」的处理器，乐 Max Pro 整体的配置也十分强悍，它已经为 2016 年的旗舰手机树立了第一个标杆。下面是乐 Max Pro 的配置：

*   6.33 寸 2K 屏幕（2560x1440）
    
*   4GB LPDDR4 RAM+64GB ROM
    
*   2100 万像素后置摄像头（支持 OIS ），400 万前置摄像头
    
*   3400 毫安时电池
    
*   双卡双待全网通
    
*   USB Type-C、QC 3.0 快充、MHL……
    

除了上面这些强悍的配置，乐 Max Pro 也成为了首款搭载高通 Sense ID 超声波指纹识别以及 802.11 ad WiFi 协议的手机。这两项技术或许现在还不普及，但相信 2016 年会有越来越多的旗舰手机使用它们。

![](../Images/c09b7954e62394df7b6a9145ab2989f2.png)

超声波指纹识别拥有更精确的识别能力，而且在扫描时可以忽略油污和汗水的影响。更重要的是，超声波可以穿透由玻璃、塑料等材质，这意味着指纹识别模块可以隐藏到屏幕里了。不过这次乐 Max Pro 还是选择了更加成熟的背部识别方案，但是识别真得速度很快。

![](../Images/bd69a2678f7b8e3b201ecfaad6c3e35d.png)

或许你的设备还没用上 802.11 ac，但 802.11 ad 就快来了。这是最新的 Wi-Fi 网络传输标准协议，它抛弃了已经「非常拥挤」的 2.4GHz 和 5GHz 频段，转而使用 60GHz 频段，速度可达 4.6Gbps。

强悍的配置、博人眼球的新技术，让乐 Max Pro 注定成为这个新年最为「耀眼」的一部手机。不过，现场并没有公布乐 Max Pro 的具体售价和上市时间，这部搭载骁龙 820 处理器的手机还需要过段时间才能来到你的手上。
