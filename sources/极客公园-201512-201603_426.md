# CES｜未来一年的 ThinkPad 新品全在这里

> 在 CES 2016 上，联想似乎要把本年度所有的 ThinkPad 新品展示一遍，包括全新的 X1 Tablet、X1 Yoga，以及经典的 X 和 T 系列产品。

![](../Images/017b06d2be143ebdc90ad914e88bfdc5.png)  
联想向来喜欢在每年年初的 CES 上展示 ThinkPad 新品，今年更是如此，联想似乎想把未来一年所有的新品都摆到 CES 的站台上，下面我们就来盘点下在 CES 2016 可以看到的 Think 系列新品。

## **变革——ThinkPad X1 Tablet、X1 Yoga**

过去一段时间，联想一直在将旗下的 Think 和 Yoga 两大产品线进行融合，而在今年的 CES 上，我们将看到两款融合 Yoga 基因的 ThinkPad 新品：ThinkPad X1 Tablet 以及配备「360 度」可翻转屏幕的 X1 Yoga。

![](../Images/1a1dd1f7a7c8b105d4abb4fea310849c.png)

*▲ThinkPad X1 Tablet*

从外形上看，X1 Tablet「取材于」Yoga Tab 3 Pro，对比 Surface 系列产品，X1 Tablet 的背部支架要小巧不少。X1 Tablet 的屏幕尺寸为 12 英寸，分辨率 2140x1440（屏幕长宽比为 3：2），处理器则为「低耗低能」的 Intel Core M，最大支持 16GB 内存以及 1TB、支持 NVMe 技术的固态硬盘。X1 Table 最特别的是众多的扩展模块，用户可以额外购买 WiGig 底座、Intel 的 RealSense 3D 摄像头、外接电池、外接键盘以及采用 ThinkPad 经典红黑配色的触控笔，最夸张的是，X1 Table 还可以选配类似 Yoga Tab 3 Pro 的投影模块（售价 279 美元）。X1 Tablet 将于下个月上市，起始售价 899 美元。

![](../Images/02b08c21ad28e7c0aaa3d04d92079bd9.png)

*▲ThinkPad X1 Yoga*

至于 X1 Yoga，联想显然从 Yoga 4 Pro 上「汲取」了灵感，不过想比起 Yoga 4 Pro 上亮闪闪的表链式转轴，X1 Yoga 的转轴更接近 ThinkPad S1 Yoga 或者联想 Flex3。和联想旗下的一众可翻转屏笔记本电脑类似，X1 Yoga 也可以「360 度」自由旋转。除此之外，X1 Yoga 还配备了支持 NVMe 的企业级固态硬盘，并可以选配 OLED 屏幕。价格方面，非 OLED 屏幕的 X1 Yoga 起售价为 1449 美元，将于本月上市，采用 OLED 屏幕版本则要等到四月份，具体价格还没有公布。

![](../Images/817a74f48af3b421b78392ad5af7a249.png)

*▲ThinkPad X1 Carbon*

除了 X1 Tablet 和 X1 Yoga 这两款堪称「变革」的产品，联想还会在 CES 上展示 X1 Carbon 的升级版，与上一代产品相比，今年的 X1 Carbon 在外形上没有变化，不过内部更换了最新的 Intel Skylake 架构处理器，并可选配 LTE-A 蜂窝数据模块以及 WiGig 无线底座，新 X1 Carbon 的厚度也仅有 16.51 毫米，重量为 1.17kg，内置电池容量达到了 52Whr。X1 Carbon 将于下月正式上市，起售价为 1299 美元。

## **传承——ThinkPad T 系列、X 系列**

除了「大变样」的 ThinkPad X1 系列，ThinkPad 经典的 T 系列和 X 系列也将获得升级，具体的升级型号包括 X260、T460、T460s、T460p、T560 以及 L460、L560，这几款产品都将于下个月上市。

![](../Images/18d62874c9ac0af389d0a42503008c6a.png)

*▲ThinkPad X260*

X260 最高可以配备 Skylake 架构的低电压 Core i7 处理器、16GB DDR4 内存、512GB 的 SATA 或者 PCIe 接口硬盘，并可选配 WiGIg 无线模块以及蜂窝数据模块。接口方面，X260 也延续了经典 ThinkPad 的传统，包含了 3 个 USB 3.0 接口、mini-DP、HDMI、SD 读卡器以及一个现在已经十分罕见的 RJ-45 网线插口，X260 的厚度约为 0.79 英寸（约为 2 厘米），重量为 2.9lbs（约为 1.31kg）。此外，联想还表示 X260 的电池续航最高可达 21 小时，不过根据以往的经验，实际使用时间会比这个数据短不少，X260 的起售价为 929 美元。

![](../Images/c0b8fe047efb01ab5fa7ab8f583bb5f9.png)

*▲ThinkPad T460s*

此外 T 系列也将获得全面的升级，T460s 是 2015 年推出的 T450s 的升级版，配置方面，T460s 也不出意外的使用了支持 vPro 技术的 Core i7 处理器（Skylake 架构），最大支持 24GB DDR4 内存和 512GB PCIe 接口的固态硬盘，并且可以选配支持 LTE-A 网络的蜂窝数据模块。T460s 的屏幕依然为 14 英寸，最高分辨率 2560x1440，标配 Intel HD 520 显卡，用户也可以选配 NVIDIA GT 930M 独立显卡。和 X260 类似，T460s 配备 3 个 USB 3.0、HDMI、mini-DP 以及 RJ-45 网线接口。除此之外，用户还可以选择加配拥有智能读卡器和指纹识别模块（不知道还是不是划擦式？）的 WiGig 无线底座，T460s 底部也配备了一个连接传统底座的接口。在厚度和重量方面，T460s 相比 T450s 也有所降低，T460s 的厚度只有 0.74 寸（约为 1.88 厘米），重量也只有 3lbs（约为 1.36 kg ）。ThinkPad T460s 将于下个月上市，起售价 1059 美元。

![](../Images/929dae52199baa99ec31942520a9a35f.png)

*▲ThinkPad T460*

除了偏重轻薄设计的 T460s，传统的 T460 和 T560 也将最高配备 Core i7-U 系列处理器，用户可以选配 NVIDIA GT940MX 显卡以及最高 32GB 的内存，T460 将配备 14 英寸、1080p 分辨率的屏幕，T560 的屏幕尺寸为 15.6 寸，最高可以选配 2K 分辨率（2560x1440）的 IPS 屏幕，T460 的重量为 3.8lbs （约为 1.72 kg ），T560 的重量为 5lbs （2.27 kg）。价格方面，T460 的起售价为 909 美元，T560 则为 959 美元。

![](../Images/05d0884aab766d908cc5fb882c3de067.png)

*▲ThinkPad T460p*

如果你对上面几款产品的性能不满意的话，联想还将推出性能更强的 T460p，采用了最大功耗 45W 的 Intel Core H 四核处理器，性能比其他产品采用的最大功耗 15W 的双核 Core U 处理器强上不少。此外，T460p 还将采用 2K 分辨率的 IPS 屏幕，并配备 72 Whr 容量的电池，联想表示其电池续航可以达到 12 小时，T460p 的起售价将达到 1249 美元。

最后，联想还更新了定位更低的 L 系列产品，最新的型号为 L460 和 L560，屏幕尺寸分辨为 14 寸和 15.6 寸，可选最高分辨率均为 1080p，此外 L460 还可以选配 AMD Exo Pro Radeon R5 独立显卡，L460 的起售价为 749 美元，L560 则为 779 美元。

## **升级——ThinkVison 显示器、ThinkCentre 一体机**

除了笔记本电脑产品，联想还会在 CES 2016 上展示旗下的 ThinkVison 显示器和 ThinkCentre 一体机新品。其中，ThinkVison 将至少有 X24 Pro 和 X1 两款新品，这两款产品显示器都采用了超窄边框设计。

![](../Images/eac97b0bd3dc3fe8838cd1b915b65a5b.png)

*▲ThinkVison X24 Pro*

X24 Pro 配备了分辨率为 1080p（1920x1080）、24 英寸的屏幕，可以直接使用内置的 USB Type-C 接口传输数据，并可以选配支持 Intel RealSense 技术的摄像头，理论上可以支持 Windows Hello「刷脸登陆」，很特别的是，X24 Pro 提供了一个无线充电底座（推测应该是 Qi 无线充电标准），用户可以直接把直接无线充电的手机放在底座上充电。此外 X24 Pro 还提供了一个 WiGig 模块，配合最新的 ThinkPad 产品，用户可以把 X24 Pro 当做笔记本电脑的无线扩展屏幕使用。

相比之下，ThinkVision X1 更加偏重于对画质要求较高的用户群体，X1 采用了一块 27 英寸、4K 分辨率（3840x2160）的屏幕，拥有 99% 的 sRGB 色域，1300：1 的对比度和 300 尼特的屏幕亮度，不过这块「Think」牌的 4K 显示器价格可不低，X1 的售价达到了 799 美元。

![](../Images/02d65a56107b47ddaa7dd1cb2297bccf.png)

*▲ ThinkCentre X1 AIO*  

除此之外，联想还将在 CES 2016 上展示一款厚度仅有 11 毫米的一体机——ThinkCentre X1 AIO，这款产品采用了特殊的防尘设计，可以在正常的办公室中使用十年而不必担心进灰，配置方面，X1 AIO 配备了一块 23.8 英寸的 1080p 屏幕以及 Intel i7 Pro 处理器。X1 AIO 将于今年三月份上市，起售价 1029 美元。

## **值得期待 Think 产品**

![](../Images/821eff1d376e8eeea1039a2a2e73f755.png)

从产品上看，联想基本上是要在 CES 2016 上把本年度所有的 Think 新品都要展示一遍。除了 ThinkPad 经典的 T 和 X 系列的延续之外，在 ThinkPad 的高端 X1 产品线中，联想还通过 X1 Tablet 和 X1 Yoga 产品来试图有所创新，WiGig、NVMe、USB Type-C 等技术的广泛采用也表明了联想拥抱新技术的态度。此外，联想也没有「忘记」ThinkVison 和 ThinkCentre 这些相对小众的产品。

最后，希望这些产品在「漂洋过海」来到中国后，价格不要「涨」得太离谱。
