> 杭州是否会再造一个阿里？在这风云变幻的「双创之年」又诞生了什么样新的优秀企业？

![](../Images/dbcf83c7e48d159c5702f3b0506af6aa.png)  
杭州的未来科技城常常被人誉为是「下一个硅谷」，从这里走出了蘑菇街、挖财、Acfun 等优秀的产品。这里是否能再孕育出另一个阿里呢？而在这风云变幻的「双创之年」又诞生了什么样新的优秀企业呢？

在这次的 2015 中国互联网创新产品评选巡演 · 杭州站活动当中，让我们跟随极客君的脚步，一起来看看 WPS、什么值得买、bong、LeanCloud、物联传感、及搜狗等互联网科技企业又给大家带来了哪些有关创新的分享吧。

## **办公也能很活泼**

![](../Images/d092dd05f6d52103f6d0a33c4a2e43ee.png)

*▲金山 WPS 助理总裁 庄湧*

在我们一般人的脑海中，办公都是一件比较严肃的事情，对于金山这家公司来说则更是如此。很多人对金山的印象也比较严肃，因为自从他们创立以来，主要的业务对象就是企业。因此，对于金山来说，在这个移动互联网的时代，他们能做哪些改变呢？

*   他们首先想到的是办公场所的改变。毕竟多了手机这个新的办公工具，出现了多屏办公的要求；
    
*   而也正是由于上面这个原因，协同办公的要求也出现了；
    
*   第三，在移动化的办公过程中，如何将重要信息快速提取出来也成为了用户新的需求。
    

因此，根据这些新的变化，WPS 对自己提出了三个新的要求：

1\. 帮助用户提高办公效率；2. 更有乐趣地办公；3. 呈现方式更加「高大上」。

面对这三个挑战，金山做出了自己的改变。

首先，在多屏办公这个方面，金山给我们举出了一个改变的例子。

现在智能电视已经比较普及了，那么我们能不能利用智能电视这个平台办公呢？金山想出了办法。「打开手机，用这个二维码扫一下，立马就可以把我所要讲的内容，投影到他的智能电视上。」这就是多屏办公的新体验。

而在协同办公方面，金山也给出了自己的解决方案。

> 「我们在想，我们现在手头上都有一块这个屏幕，能不能借这个机会，让用户随时随地可以在一个团队中召开一个讨论会呢？」金山公司 WPS 项目副总裁庄湧说道，「我觉得现在是可以的，就是我们在手机、平板，甚至 PC 上，现在都能够同时分享这个文档，同时有一个主讲人。所以我们的产品经理一发现这种没有投影仪的会议室，我们立马就能变出一个空闲的会议室。然后团队里面几个人马上就可以开一个分享会，或者是讨论会，就可以把这个方案给定了。所以这里效率立马得到了提高。」

第三，在碎片化时间的利用上，金山也在移动办公方面进行了很大的提升，「只要你有这个思路，我就能让你做出一个相对满意的效果。」金山很自豪地给出了这个承诺。

围绕着移动化办公，围绕着分享式办公，金山做出了很大的改变。而这也让 WPS 获得了荣获了苹果 App store 2015 年度精选应用的荣誉。而这也体现了创新的价值。

## **坚持品质消费**

![](../Images/837924838d183429e5594330d43e5390.png)*▲ 什么值得买公关总监 刘雅楠*

双十一、双十二刚过去不久，相信大家都在这一段时间经历了紧张的购物季，那么如何才能更有诀窍地「剁手」呢？让我们来看看导购网站什么值得买给出的答案吧。

很多人觉得导购这个领域门槛不高，但刘雅楠不这么觉得，作为什么值得买的公关总监，在她看来，导购领域的门槛主要体现在三个方面：自由度、信任感和超前量。

自由度可以从三个角度来解释。1. 它意味着你不能过度依靠电商而存活，那样的话，你的内容会受到很大的限制；2. 它代表了内容与用户之间的对应关系，你必须尽量做到内容与用户需求相对应；3. 它代表提高整个购物方式的多元化，比如什么值得买率先引领的海淘潮流。

信任感则是整个导购及购物网站的生存之本。它包含了你推荐产品的质量、价格等多方面因素，同时，还涉及到品类是否广泛、渠道是否多元等问题。总之，没有信任，导购网站也就失去了生存之本。

第三个就是超前量了。所有人都会有喜新厌旧的特点，重点在于你必须要了解更多的东西，一定要做这个行业的领先者，这样才能比别人更早知道，而这才是导购的意义所在。所以第一就是要增加多种品类的单品，第二个就是要在渠道方面做更多的拓展。

关于这些门槛，什么值得买给出的答案就是强调「品质消费」。什么是品质消费？刘雅楠给出的回答是：「第一个是说这个东西本身品质过硬，第二个是说它在当时的这个环境下面，可能处于一个比较划算的价格。符合这两个条件，我们认为它是值得买的。」

当然，在发展了 5 年之后，同类型的产品也越来越多，这也让什么值得买开始考虑自己的多元化发展。

*   他们推出了「商品百科」这个新板块，这是一个类似于消费领域的维基百科的新功能，主要就是为用户提供有关商品的信息；
    
*   推出每日推荐的概念，就有一点像游戏升级，每天只要阅读这十篇百科，我今天的内容就完成了，而这也是什么值得买每天给用户的一份小礼物；
    
*   设立发现频道，发现频道由用户自己提交内容，基本上是用户提交来是什么样，它就以什么样的方式展示出来，短、平、快，内容非常简单。
    

在经历了 5 年的发展之后，什么值得买走到了今天这个「购物门户网站」的地位，这也是他们不断寻求突破、寻求创新的结果。

## **拉近人和信息之间的距离**

![](../Images/0836fd4d8f260cb27eb4b684bab335f6.png)*▲ bong 联合创始人&产品总监 许皓玥*

智能手表作为智能可穿戴设备的代表，已经逐渐走进了普通老百姓的家庭中。而 bong 作为创新智能手表的代表，也来到了杭州跟大家分享他们的心得。

到今天为止，bong 已经经过了 4 代的发展历程。从 2013 年发布第一款产品，到提出「智能操作」的概念，再到最新的 X2，他们一直走在创新的行列中。

「对我们有一些了解的一些用户，或者是朋友，对我们的印象，应该认为我们是一个非常敢冒险，比较有创造力这样一个团队。」这是 bong 的联合创始人许皓玥给自己的团队给出的评价。在他们看来，创造力可以分为两个部分，一个部分叫做把握本质；一个部分叫做打破常规。然后这个东西现在也是 bong 团队基本的一个团队文化。

> 把握本质，我认为它是一种，首先它是一种态度。然后接着它是一种能力，你要给我能够把握本质的这种一种态度。能够知道还有更真实的真相掩藏在背后，同时你还要有能力去甄别这种真相。然后打破常规呢，它其实更像是一种勇气。当我们真正地知道了这个东西，它的真相是怎么样的，我们就有可能能够想到一些，不被经验所束缚的方式去打破。

上面是 bong 对于自己所理解的创新的解释，而他们也用 X2 这个作品阐释了他们对创新的理解。

首先，他们就智能手表的本质展开了头脑风暴，最终，他们得出的结论就是：智能手表就是一个拉近人和信息之间的距离的设备。这个是所有的科技产品，或者是先进系统在做一个很根本的事情。所以，从这个角度出发，bong 重新思考了产品的设计思路，首先它是一个操作系统，它需要被操作。所以，他们将 X2 设计成为用单手就能操作的手表。比如说通过旋转手腕就可以切换 APP；抬一下，就可以测心律，压下去又能测血压，等等。

然后，他们又在设计中放弃了触摸屏的设计。使用全手势操作，并增加了对信息的处理，使用场景推送功能，让可穿戴式设备知道你在干什么、知道你在哪里、知道你现在是什么状态，让那些繁杂的信息变成对用户最有力的信息，使用户不会太累。

所以呢，他们打通了 App 的信息架构。把整个 App 的信息架构全部击碎，变成一张卡片上面去。这就是 bong 的新思路。

## **将质量与效率完美平衡**

![](../Images/025c89ffd8de4499c8caccd3eda2898b.png)*▲ LeanCloud CEO 江宏*

相比于上面 3 款主要面向消费者的产品，Lean cloud 似乎不太一样。作为主要为开发者等专业人士服务的企业，Lean cloud 为应用开发者们提供一站式的后端云服务。当 Uber 在去年准备进入中国市场的时候，他们就是利用 Lean cloud 做的开发工作。

而他们这次带来的演讲主题是《破解高效开发的章程》。

就高效来讲，很多人觉得把一件事做得尽量快，那就是高效，然而 Lean cloud 并不这么觉得。在他们看来，在无法保证产品质量的情况下单纯地提高开发速度，这不能称之为「高效」。在速度、成本与质量中，你很难三者都能达到，因此，Lean cloud 选择的方式是去尽可能好地去兼顾这三方面。

在 Lean cloud 看来，许多创业团队为了在一开始加快开发速度，选择了看上去很「高效」的开发方法，然而随着时间的变化，结果不一定是最好的。

> 一开始，你可能在开发的阶段，手机上面会有一个应用，然后有一个 API 服务，再后面有一个数据库，就完了，这样相对比较简单。可能当用户到了 10 万、100 万，上千万的时候，最终它的后端就变得越来越复杂。所以这样造成的结果就是，你在开发的阶段，或者在你用户太多的阶段。你增加一个功能，就是两倍的时间。

因此，Lean cloud 根据用户最根本的需求，结合自己的技术，为用户提供了在效率与质量之间最为平衡的解决方案。

> 我们想要去做的就是把典型的应用的后端需求抽象成一个通用的云端服务，叫做 Lean cloud。让用户来使用服务，而不是用服务器来开发应用。在传统的开发里面，你可能会到用户提供商那里去，租一些服务器，然后自己在上面开发获取你的 API 服务，配置你的数据库，然后自己去运营。而对于 Lean cloud 来说，它的绝大部分精力可以放在开发前端的移动应用上面，而不需要去管、不需要租两台服务器，然后两台服务器下面跑一些什么东西。

这个就是 Lean cloud 所说的，不在品质上面做任何妥协，而同时能够提高效率。

## **从生活智能化到智能生活化**

![](../Images/be9634644038d9e2ee50acd891dbcf0c.png)*▲ Wulian 物联传感结构设计部副总监 尹德青*

《从生活智能化到智能生活化》，这是南京物联传感公司结构设计部副总监尹德青带来的演讲主题。从题目也可以看出，他们的主要思路还是围绕着生活和智能这两个关键词展开。

从互联网的出现，我们能看到我们的生活正在逐步走向智能化。比如智能健康、智能控制、智能传感等各种各样的智能技术都如雨后春笋一般冒了出来。而为了实现这样一个智能化的生活，我们需要各种各样的一些智能化的设备。而物联传感就是这样一家物联网设备和解决方案的提供商。

但是对很多人来说，这些设备中有一个问题，那就是：它虽然有用，但是它只是设备，只是冰冷的机器。而什么样的产品会更符合我们的需求呢？尹德青给了我们 4 个方面的答案：第一，它的外观要来源于生活，第二，它要体现美感和质感；第三，它使用的时候呢融入生活、融入环境；第四，它要具备智慧的功能，并且这些功能能服务到我们的家庭生活。

而通过他们推出的一款名为「梦想之花」的智能花瓶，物联传感认为他们做到了自己对产品的要求。

*   首先，从花瓶的造型来说，它既代表圆圆满满的生活意义，而「S」型曲线又体现出了艺术的内涵，体现出了「美」。
    
*   其次，由于花瓶的功能，它可以在使用中为我们带来生活的气息，插上鲜花，我们会感到心情放松了一些，这就是它具备的生命力。
    
*   再来，作为一款智能产品，它带有路由器的作用，具有 2.4G 和 5G 型号的一个路由器装置。
    

此外，它同时还提供一个非常有趣的、跟大家交流、互动的一个方式。比如说手掌挥一挥，功能就会切换；你手指在花瓶上弹一弹，里面的功能就可以发生变化，等等。

「对于互联网这个行业来讲，我们公司认为任何实现智能家居功能的不仅仅是某一个单品，或者是单品的组合。它是需要建立这样一个系统，因为只有建立这样的系统，才能让所有互联互通的信息、数据联通起来，这样才有意义，才有价值。」这是物联传感自己的体会，也是他们送给我们所有互联网从业人员的金玉良言。

## **优秀的互联网产品如何进一步前进？**

![](../Images/7dc94f6b11c4dee15bf06c603851808a.png)*▲ 搜狗输入法产品总监 徐萌*  

相信大家一定不会对搜狗输入法感到陌生。作为一个已经发展了 10 年以上的优质互联网产品，他们在发展的过程中也经历了不少的风风雨雨。这次，搜狗输入法产品总监徐萌为大家介绍了他们在产品的发展过程中遇到的一些问题、以及他们的解决办法。

在徐萌看来，他们在产品的发展过程中遇到了 3 个问题：

*   在产品版本更新的过程中，有很多可以继续增加的功能，到底应该加哪个？不加哪个？这是一个问题。
    
*   在做产品的过程中，肯定会收到很多的用户反馈，这时不同用户反馈的不同问题，到底应该首先解决哪个？
    
*   在产品功能已经完备的情况下，如何寻找新的突破口让自己在与对手的竞争中体现出差异性，这又是一个问题。
    

面对这三个问题，搜狗输入法给出了几点方法论方面的思考。

第一个就是产品规划。他们用了一个金字塔模式去构建自己的产品规划。基座就是你产品的核心功能，对于搜狗来说，他们在自己的核心功能——输入上做了很多的努力；而继续往上就是根据用户的反馈继续完善自己的产品；同时，往下你还需要去对自己的产品进行深度挖掘。

其次，在产品价值方面，搜狗觉得单单满足用户的需求是不够的，这样你也只是一个功能性的产品而已，他们选择向前走，去主动推测用户的需求，帮助用户做更多的事，这时，它就不仅仅只是一款输入法了，而能为用户带去更多的价值。

第三，在移动互联网这块，搜狗首先为不同的设备设计了最适合他们屏幕的输入设计；而且结合设备，他们在输入法中也添加了一些多样性的功能。结合移动生态，搜狗将自己的输入法变成了整个设备系统中的一部分。

第四就是借势。有句话说「站在风口上，猪也能飞起来。」搜狗充分体现了自己抓机会的能力。举个例子，在 iOS 8 刚开放给第三方应用的时候，搜狗就开始着手进行准备，然后得到了很好的结果。

最后一个就是品牌。之前都会对输入法这种产品有一个定性的认识，它就是一个工具。但在最近，搜狗推出了一个新的吉祥物的形象，这个形象想表达的东西就是一种年轻、活泼的感觉。有了这个形象之后，用户对你的认知就不仅仅停留在工具层面，它会有一个助手外延的这种感觉，而这也方便了他们之后去做一些外延的功能。

在这几点方法论的带领下，搜狗一直稳步前进，而这也是他们坚持创新的结果。
