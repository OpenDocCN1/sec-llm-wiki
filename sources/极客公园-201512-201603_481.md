# 揭秘朝鲜「红星」操作系统：你要做的事「老大哥」都知道

> 虽然可能是全世界最与世隔绝的国家，但朝鲜也逐渐受到国外网络信息的侵扰。如何屏蔽这些不必要的麻烦呢？他们觉得自己开发一款操作系统也许是个好主意。

![](../Images/dbcf83c7e48d159c5702f3b0506af6aa.png)  
作为与世界格格不入的国家，朝鲜一直对外界呈现的是一副神秘的形象，即使是在科技领域也不例外。虽然全世界都知道他们推出了自己开发的操作系统**红星 OS（Red Star OS）**，但大家都对这个系统不太了解。

不过近日，有欧美研究者借机深入了解了这个系统，他们发现果不其然，这是一个专为其专制统治所开发的系统。

## **别做「坏事」，「老大哥」都能知道**

**红星 OS 是朝鲜根据 Linux 系统开发的一款 PC 端操作系统，它主要基于 Linux 在 2009 年推出的更新版本 Fedora 11 开发，并在 2011 年正式推出。而目前使用的红星 OS 是其在 2013 年更新后的第三个版本。最初，它的外观类似于 windows 的样子，而更新后的红星 OS 看上去更像苹果的 Mac OSX。**

![](../Images/c648ac299fc230724cc592a9a684e172.png)

不过，虽然这套系统已经开发了很多年，但由于朝鲜「特殊」的国情，**它并没有连接到万维网上，只能连接他们自己国内的网络，去一些他们的政府网站及被朝鲜官方认可的网站上逛逛。**而且外部世界的人们也不了解这个系统本身的情况。不过这次，有两个德国学者对这个系统进行了深入的调查，并将它们的研究公布到了世界上，为我们揭开了其一部分的神秘面纱。

总的来说，这个系统如大家所预料的那样，有许多为了控制国民而设计的功能。

**「我们发现红星 OS 的特点就体现了一个国家独裁者对国民实施监视的梦想。」**Florian Grunow 与 Niklaus Schiess 这两位研究人员说道，**「它其中带有很多监视的特性，比如它能够对系统中不同类型的文件添加水印，这样他们就能够追踪不同文件的走向。」**

这使得这个系统解决了一个很棘手的问题，那就是它能够打击在朝鲜日益泛滥的外国电影、音乐和书籍。在朝鲜，人们通常使用 USB 设备或是 Micro SD 卡来传递这些非法内容，而红星 OS 能够在用户不知情的情况下在这些文件上做手脚。以此，朝鲜政府就能发现是谁在传播这些内容。

![](../Images/a7a9a56311bfc9f8e0b02b17572592ee.png)

除此之外，**这个系统对于自身的保护有很强的警觉性，一旦有用户想要修改其中的关键文件，比如防火墙之类的，那它就会自动重启。**

## **朝鲜不是第一个这样做的国家**

不同于很多人的设想，这不是一个仅仅模仿西方的系统，「这个系统是由金正恩和朝鲜官方自己开发的」，Grunow 在昨天的会议上如此说道。其中很多的技术是他们独有的，比如他们自己的加密文件，**「这是一个完全成熟的操作系统，他们掌握了大部分的代码。」**很显然，朝鲜不想让其他「别有用心」的人破坏他们的代码。他们在使用了一些类似于 AES 这样已有的加密算法，但在上面进行了许多改动。

不过，如果我们从外表上看，这真的像是一个完全为朝鲜人民设计的系统，里面有朝鲜文的处理器、日历、以及音乐处理应用等等。而根据去朝鲜旅游的游客的反馈，目前朝鲜的个人电脑数量正在上升，但它们大多数使用的仍然是 Windows XP 系统。

![](../Images/729e5b33f9442a44f1a708ad733dd345.png)

不过，朝鲜肯定不是第一个这样做的国家。在 2009 年的时候，因为将 Windows 系统视为威胁，以及美国的贸易禁令使得他们无法获得合法的软件来源，**古巴政府宣布他们在 Linux 系统的基础上开发了一款新的操作系统，名为 Nova**。而他们也认为这种系统更符合古巴人民的思想。

**而我国也基于 Linux 系统自己开发了我们自己的红旗操作系统与 COS 操作系统（China Operating System）。不过影响力都不大**。

## **结语**

不过，这件事有趣的地方在于，Linux 系统一向以开放性著称，任何人都可以对其进行自定义开发。而朝鲜这次却在 Linux 系统的基础上开发出了一个完全封闭、甚至是用来监视用户的系统，真是可悲可叹。
