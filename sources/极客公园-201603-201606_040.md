# 堕胎前收到劝说广告，孕妇的隐私就不重要吗？

**** 堕胎隐私 ****

****![](../Images/dbcf83c7e48d159c5702f3b0506af6aa.png)  
************************************************************“**************************************************************想堕胎？你需要先听听劝告**

站在美国任意一家堕胎诊所里，你都能看到外面举着抗议标牌的反对者们，这些抗议者大都来自那些反堕胎非营利组织。当然，大家如果对这方面有所了解的话，就会明白，因为宗教等方面的因素，「堕胎」在欧美社会一直是一个比较有争议的话题。虽然大多数国家和地区都批准了堕胎的合法化，但有许多的 NGO 组织一直致力于反对堕胎。其中 Planned Parenthood（计划生育）就是美国在这方面最重要的组织之一，它每年大约能接待 270 万女性进行各种身体检查、避孕与堕胎等服务。

![](../Images/046b284d8abc0c836aeedf1438a22e1e.png)

然而，这种「亲力亲为」的抗议宣传方式非常费心费力，效率也非常低。

去年，美国波士顿的一家广告公司的高管有一天突发奇想：我们每天都要用复杂的移动监测技术去找出那些有某些购物需求的人们，然后给他们发送广告，那为什么我们不把它用到堕胎上呢？以那些反堕胎组织的名义给那些有堕胎想法的女性发送反堕胎的广告，不是很好的一个主意吗？

![](../Images/2dc70756be7ad96380a8534823e192f7.png)*「我为我曾经的堕胎行为感到悔恨」*

这位高管的名字叫 John Flynn，他很快就将自己的想法发送给了一些他觉得可能对这个事儿有兴趣的组织，然后不久，他就被几个这个领域的组织聘为了顾问；紧接着，他还得到了在今年的家庭研究理事会的数字峰会上演讲的机会。总之，他的这个想法让他成为了这个反堕胎领域的名人。

他的具体计划是：当那些想要堕胎的女性进入 Planned Parenthood 的诊所中时，Flynn 将会替他的客户向这些女性的手机中发送相关广告。

而要做到这一点，他要使用一种名为「mobile geo-fencing（地理围栏）」的技术。这种技术运用全球定位系统（GPS）或射频识别（RFID）规定地理边界，当设备越过地理栅栏进出管理员规定的边界时，就会有相关的信息发出。

于是，现在，当一位女性走进被他们覆盖的 Planned Parenthood 的诊所中时，她们就会看到像下面这样的广告推送：

![](../Images/9754250818bc1c4e1627d846bc60454c.png)*「怀孕？这是你的选择，你有时间想清楚这个问题的」*

目前，这个上线不久的项目非常受到这类组织的欢迎，已经覆盖了美国的 5 个城市，根据他们自己提供的数据，这个项目已经覆盖了从 18-24 岁的 80 万名女性。而他们也计划将这个项目推广到更多地区。

**********************************************************“**********************************************************在这样的环境下，你还敢去堕胎吗？

然而，对于很多有堕胎想法的女性来说，这个项目可能会对他们的隐私和数据安全造成很大的威胁。

设想一下吧：当你进入美国任意一家的堕胎诊所，你的手机上就会收到相关的宣传信息；此外，他们还有能获取你姓名和地址的能力。如果你是一位有堕胎想法的女性，当你身陷这种氛围的时候，你不会觉得有些害怕吗？

「这非常没有道德，也很令人抓狂。」说话的人是 Brian Solis，他是一位数字营销领域的专家，他表示他的这个观点得到了数字安全、法律和在线营销等领域专家们的一致赞同。

![](../Images/7e9ea4b083deb7feef0b4c21bf4ae292.png)*Geo-Fencing技术示意图*

但事实上，这就是我们所面对的现实状况。当你在网上查看了某方面的信息之后，你很快就能在之后收到相关的广告推送了。对于数字广告商们来说，这意味着他们实现了更精准的广告推送。而这也就是启发了 Flynn 的地方，他在给客户的 PPT 里写道：「我们可以触及美国的每一家 Planned Parenthood 诊所」，「我们能从智能手机的 ID 中收集大量的信息，很多暴露出来的信息包括了：性别、年龄、种族、甚至是你养的宠物和你开的车。」

然而，我们目前却很难界定这些数字宣传手段的正当性。虽然我们的生活中的移动数字广告已经无处不在了，但事实上它还是一个新出现的现象，在智能手机兴起之后，它才开始出现，而这导致的结果就是相关的法律法规还没能及时跟上这个潮流，不管是在中国还是美国。

就拿在这方面比我们要发达不少的美国来说，他们在这个领域也还处在一个比较模糊的阶段。在加州大学伯克利分校法学院的教授 Chris Hoofnagle 看来，堕胎的这件事就处在这样一个灰色地带。

> 「在美国，隐私权需要依靠技术和具体的情境来判断。举个例子，你和你的医生之间的医疗信息是被绝对保护的；然而，如果你点进了一家医疗网站或是搜索了一个有关艾滋病及堕胎的信息，那这些信息就不被保护了。」

在这种情况下，当你想要堕胎的信息暴露出去之后，在面临许多反堕胎极端分子的恐吓下，你还有足够的勇气去堕胎吗？更令人感到担忧的是，这种线上「恐吓」式的推广有变成实质威胁的可能。

**********************************************************“**********************************************************我的信息我能做主吗？

虽然还没有证据表明 Flynn 和他的客户有利用地理围栏技术获取去用户的真实身份，但有专家表明，这项技术有被他人滥用的风险。下面是 Rewire 给出的技术解释：

> 理论上说，当企业从用户的智能手机上通过 GPS 这样的技术收集信息的时候，这些数据是匿名的，这意味着没人能知道这些数据是谁的，但是他们会知道一系列名为「advertising ID」的数字。这些数字与每一个人手机里操作系统的特定副本有关，比如你使用的是一个 Google 的手机，那你的操作系统就是 Android；你使用的是 iPhone，那你的就是 iOS，而你在手机上做的很多事都与你的 advertising ID 有关。

哈佛大学商学院教授 John Deighton 在采访中表示：「这个故事吸引我的地方在于这些相似的监控技术可以在一个非常微观的尺度下被使用，你能完全能想象自己的地理位置被非法使用，比如获取一个有钱人的家，当他离开房子的时候给你发送提醒。」

![](../Images/dc375e1b483d63f38a8754f8936cf7da.png)

看到了吗？你以为这只是一次「简简单单」的堕胎检查，但你很可能会在接下来遇到一系列的麻烦。而且目前我们还没太好的办法去解决这个问题，像 Planned Parenthood 这样的堕胎诊所能给他们的用户提供的建议就是别带着手机到诊所来，如果做不到的话，至少也要在进入诊所之前关掉 GPS 并且登出所有的 App。

然而我们都明白这样只是治标不治本，我们必须想办法弄清楚个人信息的使用权限问题，虽然这并不容易。但无论如何，我们要搞清楚一件事，那就是当我想要堕胎的时候，我只听从我自己的声音。
