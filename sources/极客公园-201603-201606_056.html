谷歌终胜甲骨文，6年的版权拉锯告一段落

来源：arstechnica、cnBeta

据今日美国报报道，美国旧金山联邦法庭陪审团今日做出裁决，认定谷歌安卓操作系统并未侵犯甲骨文版权，因此驳回甲骨文索赔90亿美元的诉讼请求。此项裁决 结束了谷歌与甲骨文长达6年的版权诉讼大战，甲骨文表示将会就此上诉。谷歌依靠的证人包括谷歌前首席执行官、现任谷歌母公司 Alphabet 执行董事长 Eric Schmidt，他们说服陪审团相信，谷歌使用Java 去创新，而非简单地抄袭其代码。在加入谷歌之前，施密特曾为 IT 及互联网技术服务公司 Sun Microsystems 工作，参与研发和推销 Java。


甲骨文2010年收购Sun Microsystems时，施密特正参与谷歌授权谈判。施密特称，根据他研发Java的多年经验来看，他认为谷歌无需通过谈判就应该被允许使用Java应用程序接口（API），Sun Microsystems以开源和免费方式推广它们，而非通过授权或出售方式。

2010年，甲骨文将谷歌告上法庭，称谷歌安卓系统有37个应用程序接口（API）侵犯了其编程语言Java的版权。甲骨文认为，谷歌只有获得许可才能使用Java API研发安卓系统，并据此要求高达90亿美元的赔偿。而谷歌认为，他们遵循版权法，并合法使用Java软件代码，为此无需支付版权费。


如今甲骨文首席律师 Dorian Daley 表示：「我们坚信谷歌在开发安卓系统过程中非法复制了 Java 的核心技术，借此进入移动设备市场。甲骨文提起诉讼的目的是阻止谷歌的非法行为。我们认为有无数理由支持上诉。」但有法律专家认为，推翻这一裁决将会很难。

Facebook和微软联手埋跨海电缆，追赶Google

来源：Wired

目前Facebook和微软正在铺设一条横跨大西洋的海底通讯电缆，该电缆被称为MAREA，是西班牙语中「潮」的意思。这个巨大的水下电缆将会从美国的弗吉尼亚州一直连接到西班牙的毕尔巴鄂。跨越6600公里，用于传输数据。

为两个地区每个家庭大约16万次数据传输提供高达160tbps的带宽，同时它将会使得这两家科技巨头能够更有效地通过海底传输进行利用，更好发挥他们各种流行的网络在线服务，将计算机数据中心、网络集线器之间更好地关联。


在之前Google早已投资了从美国西海岸到日本和美国到巴西的两条海底电缆，在漂洋过海建设自己的网络基础设施这件事上Google、Facebook、微软都在加快步伐。

自动驾驶的特斯拉Model S撞上了高速公路上停泊的货车

来源：腾讯科技

在特斯拉面向大众推出 Autopilot（自动驾驶）功能的一周内，我们已看到了一个骇人的事实：特斯拉汽车的车主太相信这个功能了。这不，他们最终还是出事了。 一名欧洲车主 Chris Thomann 正驾驶着他的特斯拉 Model S 汽车在瑞士的高速公路上行驶。他开启了特斯拉的自适应巡航控制系统（简称 ACC 系统）。特斯拉的 ACC 系统和 Autopilot 功能使用摄像头和感应器来监测周围的车流，并可以动态地调整车速，甚至可以让行驶中的汽车紧急完全制动。


 Model S 汽车前面有一辆汽车变道，避让一辆停在高速公路上的货车，这辆货车几乎占据了半个车道。Model S 似乎已意识到了它前面的车辆开始变道，但是它并没有发现停在路上的货车。结果，Model S 轻微加速地撞向了货车。托曼称，此次撞车事故「导致他的汽车前端需要整体更换，包括停车感应器和防撞钢梁。」

点评：虽然这是 Model S 使用手册上标明的注意事项，但能够动起来的车却撞上停着车，听起来还是太不智能……

微软禁止用户使用愚蠢和容易猜测的密码

来源：cnBeta

微软正在积极地禁止用户使用弱口令。微软采用“动态禁止”的方式，这意味着，如果你的帐户使用的密码出现在微软内部最常用/被盗密码的列表当中，那么微软将迫使你创建一个更复杂的密码，这种做法将适用于微软帐户，以及Azure的AD服务。


此外，当用户记不得自己的密码，重复尝试次数过多，微软将继续使用其锁定模式，以防止黑客进行猜测密码攻击。据该公司介绍，这种方法可以将黑客攻击时间减少54%。微软为此还专门写了一篇研究论文。但是，如果你没有时间阅读，请记住这一点：微软要求用户设置至少8个字符长的密码，在其中使用符号和/或者数字，最好有大小写字母在其中，不要再在密码当中使用宠物名字。对于严重没有安全感的用户，微软建议使用双因素身份验证。

点评：一边是Google要消除密码，一边是微软要让密码更复杂，有时候消费者也很难做的……

索尼PS4全球销量突破4000万部 超以往所有机型

来源：腾讯科技

据《华尔街日报》报道，索尼周四宣布，其旗舰游戏主机PS4全球销量突破4000万部。这凸显出索尼电子游戏部门的强劲增长势头。索尼电子游戏和网络服务部门索尼互动娱乐（SIE）称，PS4是在上周日突破4000万大关的，其销量超过了以往所有的机型，包括最畅销的第二代机型。索尼在2013年11月发售PS4，该主机销量超过了微软Xbox One和任天堂Wii U。索尼计划在本财年再出货2000万部PS4。


除PS4外，利润可观的网络服务业务也是索尼的创收大户之一，这类业务包括在线电子游戏订阅、基于云端的流媒体电视服务。分析师称，在今年10月虚拟现实头戴设备PlayStation VR发售之后，索尼电子游戏部门的增长势头可能会加速。
