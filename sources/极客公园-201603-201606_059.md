# 三星发布 C 系列「中国特供机」，会有更多「路人转粉」吗？

**** 三星 C 系列新品** **

**![](../Images/9661b9597534ff7f35065f36def93ef6.png)  
**

两个月前，我把「主力机」从 iPhone 6 换成了 S7 edge。较高的辨识度、出色的拍照和强大的 Samsung Pay 是我购买这部三星旗舰手机的原因。  

经过一段时间的使用，我认为这一代的旗舰手机三星是要比苹果「技高一筹」的。但是，S7 edge 高昂的价格和过剩的性能显然不是所有人都愿意为之「掏腰包」的。三星显然也深谙其道，把触角伸向了更低的价格区间。

![](../Images/8c6d2050c78830ffc2085702bc113a73.png)

就在今天，三星更新了自己的产品线，带来了针对中国市场的全新 C 系列手机（C for China？）。首先跟大家见面的是 Galaxy C5 和 Galaxy C7 两款，区别在于屏幕大小和处理器略有不同，售价 2199 元起。

********************************************************“********************************************************并不常见的三星「全金属」手机

外观方面，C 系列正面延续了三星「家族式」的风格：「额头」上印着「SAMSUNG」的标志，椭圆的 Home 键支持指纹识别。然而背面却「风格大变」，C 系列采用了全金属材质和三段式设计，同时摄像头有一定凸起。

![](../Images/e987a421a5e853a23c66e85cc0f98cdd.png)

纤薄的金属机身（6.7mm 厚），加上 2.5D 弧面玻璃，让 C 系列的手感非常棒，这个感觉在小屏幕的 C5 上更为强烈。随之而来的问题是，手机整体的辨识度下降了很多，遮住 logo 的话你很难注意到这是一款三星的手机。

![](../Images/5e5edeedef4cf4030d9dd6678313c8a2.png)

在外观上，C 系列还是很有诚意的，全金属机身也符合现在手机的主流审美。但配置上，C 系列可能要让那些「参数党」失望了。以下就是它们的详细参数信息：

*   处理器：C5 为骁龙 617，C7 为骁龙 625
    
*   内存： 4GB RAM+32GB/64GB ROM 组合
    
*   屏幕：C5 为 5.2 英寸；C7 为 5.7 英寸。两者均为 1080p 分辨率的 Super AMOLED 屏幕
    
*   摄像头：800 万前置+1600 万后置，F1.9 光圈
    
*   电池：C5 为 2600mAh；C7 为 3300mAh
    

其中有几点值得注意。C7 所采用的骁龙 625 ，是高通最新的 14nm 制程处理器。它拥有 8 个 A53 核心（主频 2.0 GHz），集成了Adreno 506 GPU。纸面参数上 625 算不上出色，但功耗控制应该会不错，具体信息待日后评测过真机后再与大家分享。P.S.目前搭载骁龙 625 的手机包括 努比亚 Z11 mini、 HTC One A9 等；而使用骁龙 625 的手机据我所知除了 vivo 外几乎没有。

同时 C5、C7 均搭载了 Samsung Pay （三星智付）服务，它除了支持 MST （磁力安全传输）、NFC（银联闪付通道），最近还加入了支付宝二维码付款，可以说是目前最全面的移动支付方案了。

售价方面：C5：32GB 版本 2199 元， 64GB 版本为 2399 元；C7：32GB 版本 2599 元， 64GB 版本为 2799 元。在颜色上，C 系列拥有「枫叶金」、「蔷薇粉」、「皓洁银」和「烟雨灰」四个颜色。

![](../Images/33efcc50fbd5c4e9cb5857093f283802.png)********************************************************“********************************************************「刚刚好」的手机？

需要注意的是，C 系列并不是此前传闻中的「廉价机」。不同版本的 C 系列价格覆盖了 2199 元至 2799 元，这和三星「次旗舰」A 系列 2398 至 3499 的价格区间其实是有重叠的。因此也让大家对于产品的定位产生了一些疑问。

![](../Images/832b82916d5a41c9b09fcc358212e35b.png)*三星还为 C 系列带来了专属保护壳*

作为一款针对中国市场推出的手机，三星在 C 系列的发布会上花了很大的篇幅去介绍诸如「社交相机」、「红包助手」、「防伪基站诈骗」「游戏中心」等极具「中国特色」的功能，甚至还找来了游戏圈的网红「苍天哥」进行现场试玩。在 C5 或 C7 上确实能看到三星对于中国市场的理解。

![](../Images/f30a0710b5ebcae636721b9eeac480ad.png)

![](../Images/a276e098404043e6af40912678199bd5.png)*与 C 系列一起发布的游戏手柄，暂未公布上市计划*

这次新品发布，三星选择了「刚刚好」作为 C 系列的宣传标语。不论是 C5 还是 C7 确实给人一种比较平淡的感觉：没有特别突出的地方，也没有明显的短板。相比之下，一些系统层面本土化的功能和优化反而成了本次发布会的主角。

![](../Images/74d25013acad1d32acb7daca69db4f01.png)

问题来了，这样一部「刚刚好」的三星手机，足够吸引大家去购买吗？
