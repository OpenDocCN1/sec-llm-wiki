# Twitter 又有了四个新改进，但这些「小修小补」能止住用户流失吗？

在这两年，有关 Twitter 陷入困境、尝试改变、努力转型的消息已经像一个循环一样遍布媒体圈，而具体地查看每一条新闻，其实我们都会发现 Twitter 都是在对自己的功能进行小修小补。虽然在今年年初的时候，Jack Dorsey 就表示他们可能会将 Twitter 140 个字符的限制增加至 10000，但这个可能伤筋动骨的措施还未正式实施。

在去年 10 月的时候，Twitter 增加了投票功能，能让你直接在推文中发送一个投票；而在今年 2 月，他们又添加了 GIF 图搜索的功能，通过和 GIPHY 的合作，用户现在可以在发推的时候直接在下面通过分类搜索自己想要的 GIF 图。通过这些 Twitter 近期的改变，我们也能发现一个趋势，那就是它想让自己的用户界面变得更加多样化、更能与 Facebook、Instagram 这样形式丰富的媒体平台展开竞争。

![](../Images/1393acdc53063a23e2ead00b34bb9f16.png)

而今天，Twitter 又发布了声明，宣布了好几项新的改变。然而，虽然这几个小的改动确实能提升一部分的用户体验，但它能挽回 Twitter 的颓势吗？

********************************************************“********************************************************四个改变能否吸引新用户？

首先，我们先来看看这次 Twitter 的新动作都有哪些：

第一，多媒体内容不再被计入 140 字。熟悉 Twitter 的朋友应该都知道，虽然 Twitter 可以在一般的推文中发送投票、图片、GIF 图等多媒体内容，但它们会占用你 4 个字符的空间，让本来就「捉襟见肘」的 140 字空间更加不够用。所以，Twitter 这次将会在未来让这些内容都不计入 140 字，让用户能发送更多的内容。

![](../Images/295468c75222aeadd7c9a4883f997bb1.png)

第二，在此之前，当你在 Twitter 中回复某条推文的时候，就像新浪微博一样，它将会以 @XXX（你回复的那个 ID）的形式作为开头。这样做的后果就像第一点一样，那就是它会占用你不少的空间。比如碰到了 @KimKardashian 这个 ID 时，一下你就少了 14 个字符的空间。所以，Twitter 将会在之后将你回复的用户 ID 嵌在元数据之中，这样当你回复的时候，用户 ID 就不会再占用你 140 字的空间了。

![](../Images/489dfd5d80c81822ed3db09f314cfbf3.png)

*                               （新的改变能帮你省掉前面那十几个字符）*

第三，你不会再见到「.@」这个功能了。「.@」是 Twitter 自创的一个非常奇怪的功能，它只会出现在推文的开头位置，因为当你要在推文的开头位置「艾特 @」某个 ID 时，如果你不加那个英文的句号，那就只有同时关注了你和那个 ID 的用户能看到这条推文，因为它看起来就像回复功能一样。所以 Twitter 在「@」前面加了一个「.」，只有这样你的这条以 @ 开头的推文才能让每个人都能看到。不过这次 Twitter 终于改变了这个奇葩功能，只要正常使用这个 @ 功能，你的推文也能被所有人看见。

第四，你现在可以转发（Retweet）你自己发的推文了。不知为何，这个功能 Twitter 一直没有设置，这次终于将它增加了上去。

不过，这几项新的措施并没有立刻实施，而是在未来的几个月之中才会推行。

********************************************************“********************************************************新功能的表现不难预期

虽然这些新措施还未实施，但由于这几项功能都不复杂，甚至有些我们在新浪微博这些产品中都早已见识过了，因此我们其实已经能预想它的表现了。

![](../Images/59e40c0d7c79835e84ba5870c6f96e9d.png)

首先，将多媒体内容和回复的 ID 不计入字数，这样做的意图当然是想在不破坏这 140 字的限制下增加用户发表的内容容量。在之前传出的要将 140 字的限制扩充至 10000 字的消息下，很多 Twitter 的忠实用户都表达了强烈的不满，他们觉得这会让 Twitter 变得不再像是 Twitter。Twitter 想在众多讲故事的平台中同时赢得简洁和丰富这两个战场的意图我们都能理解，然而，这是一个完全违背了用户意愿的行为，并且极具风险：简洁才是这个社交平台区别于他人不多的特点之一。所以，Twitter 这次通过这两个小改变让用户能发送更多的内容；而更重要的是，由于像图片和 GIF 图这样的内容不再被计入字数，用户就能放心大胆地发出更多这类更多元化的内容出去，这也能让 Twitter 上的内容更加丰富。

其次，去掉了回复中的「@ID」和开头的「.@」之后，Twitter 的界面会更加简洁，用户之间的互动也能以更加自然的方式呈现出来。

********************************************************“********************************************************但这些能让 Twitter 重新振作吗？

但是，我们还是要问一句：这些能够让 Twitter 重振雄风吗？答案似乎不能确定。

下图是 Twitter 在过去一年当中的股价走势，向下走的曲线一目了然。在上个月他们公布的今年第一季度财报中，其利润也低于市场预期。

![](../Images/c3b77b46efa78dfb6fc3e6fc07ce549f.png)

所以，正如我们之前为大家[在文章中介绍的那样](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=404069204&idx=1&sn=7c0f15f65b960073bafab82b70fd5c82&scene=21#wechat_redirect)：Twitter 最大的问题似乎还是它究竟如何理解自己？

对于 Twitter 来说，它的特点与实力仍然存在，即：能让你迅速了解多重思想的短期信息爆炸力。而这也是他们最重要的资产。然而随着移动化时代的到来和社交平台的不断演进，用户已经可以在许多其他的应用中得到类似的服务，体验甚至更好。面对这些冲击，他们一直没能给出足够好的回应，类似今天的这些小修小补都只是治标不治本。看看 Facebook 这几年的改变你就能知道它为什么能成为全球最受欢迎的社交应用了。

根据相关的财报显示，Twitter 在去年的第四季度中，活跃用户数不尽没有增长，还出现了下降。这次的新功能也许会让 Twitter 的使用体验好那么一点，但是，恐怕 Jack Dorsey 自己也没指望凭这些就能拯救 Twitter，我们应该还能期待 Twitter 在之后会有后续更多的动作。
