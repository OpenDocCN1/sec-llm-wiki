** **Pebble** **

作为智能手表的「鼻祖」，Pebble 近期可谓动作不断。

既两周前在新版的固件更新中大幅升级了 Pebble Health 的功能之后，就在几个小时前，Pebble 第三次上线 Kickstarter，推出了 Pebble 2 和 Pebble Time 2 两款智能手表以及一款叫做 Pebble Core 的神秘可穿戴设备。

********************************************************“********************************************************Pebble 2——多彩机身，售价低廉

2012 年，Pebble 在 Kickstarter 上成功众筹了第一款智能手表，而这也被认为是现代智能手表的始祖，而刚刚发布得 Pebble 2 就是这款「祖宗级」智能手表的升级版本。

![](../Images/7d12f4e6e6d8ae36ff64fec451965a95.png)

Pebble 2 沿用了 Pebble 上的塑料机身和方便户外阅读的黑白屏幕，不过保护玻璃换成了康宁大猩猩玻璃。另外，Pebble 2 还内置了麦克风，可以实现语音回复短信等功能。

![](../Images/351d93f539c2e90fafec4e9d232644c6.png)

运动记步是 Pebble 2 的另一大主打功能，Pebble 2 上加入了心率传感器，配合新版的手表和手机软件，可以实现较为完善的运动计步和健康监测功能。

此外，Pebble 2 的电池续航时间长达一周，并且拥有 30 米的防水等级，官方的宣传片中直接展示了带着 Pebble 2 游泳的场景。

![](../Images/cbf643d2a49199c32d07fcc721cdd0b0.png)

Pebble 2 拥有黑、白、绿、红、青柠五种配色，目前的售价为 99 美元（约合 649 元），预计今年 9 月发货。

********************************************************“********************************************************Pebble Time 2——总算「不丑」了

从命名上也可以看出，Pebble Time 2 是 Pebble Time 的升级版，而且这次 Pebble 还去掉了 Pebble Time Steel 的版本，直接在 Pebble Time 2 上采用了不锈钢材质。

在功能上，Pebble Time 2 相比 Pebble 2 没有太大区别，同样内置了心率传感器并拥有完善的运动计步功能。

*![](../Images/0ec4df58cef458285b91be1d5e200288.png)  
Pebble Time 和 Pebble Time 2*

Pebble Time 2 最大的卖点是它的屏幕。Pebble 表示，Time 2 的屏幕比上一代大了 53%（依然是彩色电子纸屏幕），原来屏幕四周的可以「跑飞机」的边框也大大地收窄。如果说之前的 Pebble 智能手表看起来或多或少都像个玩具的话，Pebble Time 2 总算在设计上跟上了 Apple Watch 等主流智能手表的趋势。

Pebble Time 2 同样拥有 30 米的防水等级，并且电池续航高达 10 天。

![](../Images/2097f78d0db4d31abe5d4604ae94f6b9.png)

Pebble Time 2 拥有金、银、黑三种配色，售价为 169 美元（约合 1108 元），预计今年 11 月发货。

********************************************************“********************************************************Pebble Core——一款全新的可穿戴产品

第一眼看上去，Pebble Core 像一个变厚的 iPod Shuffle。和 Shuffle 一样，Pebble Core 的佩戴方式也是通过背后的小夹子夹在衣领上。这两款设备的顶部也都有一个耳机插孔，不过 Pebble Core 内置了蓝牙模块，还可以搭配蓝牙耳机使用。

![](../Images/d1a7afb80f0fac9566eba2ea20d2c3ef.png)

不过在功能上，Pebble Core 和 iPod Shuffle 可就完全不一样了。除了蓝牙，Pebble Core 还内置了 WiFi 模块、3G 通讯模块、GPS 以及 4GB 内置存储空间，并且预装了 Android 5.0 操作系统。

![](../Images/eaebeb5fd6b1d8b619133334a22eaf01.png)

由于内置了 GPS，用户在外出运动时，可以直接使用 Pebble Core 准确地记录运动轨迹而无需携带智能手机。回来之后，Pebble Core 可以通过 WiFi 来和手机端的 Runkeeper、Strava 等健身 app 同步数据。

Pebble Core 还内置了 Spotify，并且可以直接把音乐离线保存在 Pebble Core 内置的 4GB 内置存储中（应该需要 Spotify 的会员才能使用这项离线保存功能），出门时可以无需联网直接播放 Spotify 在本地缓存的音乐。

Pebble Core 还有两个实用的功能：一是可以随时通过语音的形式「做笔记」；在遇到紧急情况时，可以使用 Pebble Core 发送紧急求助短信，短信内容会自动包含你的地理位置（通过内置的 GPS 获取）。

![](../Images/ba91f6e2394828607e8986d411995654.png)

除了以上这些功能，Pebble Core 的侧面有两个按键，用户还可以为这两个按键定制更多独一无二的功能，比如一键叫 Uber、打开车库门、开关智能灯泡等等。

Pebble 表示，Pebble Core 虽然采用了 Android 系统，不过其电池续航依然可以达到一周。除了可以使用附送的 Micro USB 数据线充电，用户还可以额外花 20 美元购买专用的无线充电板。

最后，作为 Pebble 自家的产品，Pebble Core 也可以和 Pebble 智能手表「无缝」连接，用户可以使用 Pebble 手表控制 Pebble Core 上的音乐播放，查看 Pebble Core 记录的运动数据。（用一款可穿戴设备控制和查看另一款可穿戴设备，感觉有点怪怪的……）。另外，Pebble 手表上的 app 还可以利用 Pebble Core 的 3G 模块实现上网功能。

Pebble Core 的目前的售价为 69 美元（约合 452 元），预计明年 1 月发货。

********************************************************“**********************************************************全新的产品，激进的定价**

从产品上看，Pebble 2 和 Pebble Time 2 更像是前代产品的平滑升级版，虽然我们并没有看到什么革命性的功能，但好歹让 Pebble 手表跟上 Apple Watch、Android Wear 手表等产品的步伐，不至于在功能上被甩开太远。

![](../Images/1c46a27413291c20defa37145b86663f.png)

相比之下，Pebble Core 是一款经过 Pebble 的开发团队重新思考的全新产品。通过将众多元器件集成到一个小盒子内以及预装 Android 操作系统，Pebble Core 可以实现更为丰富的功能，而 3G 通讯模块的加入，意味着 Pebble Core 在未来有潜力进一步取代部分智能手机的功能。

此外，Pebble 上线众筹的这三款产品在定价上都颇为激进，无论是 99 美元的 Pebble 2、169 美元的 Pebble Time 2 还是 69 美元的 Pebble Core，都算得上是高性价比了。而且和 Kickstarter 上众多「高风险」的项目不同，Pebble 在后续的发货时间和售后都拥有非常不错的口碑，大可不必购买后出现「跑路」的情况。

![](../Images/63680482a4896050173a080f5e7360c7.png)

至于这两款智能手表能否让 Pebble 突破来自 Apple Watch、Android Wear 智能手表以及 Fitbit 等品牌智能手环的里外「围攻」，Pebble Core 又能否像四年前的 Pebble 手表那样开创一个全新的可穿戴产品门类？我们就拭目以待吧。
