Chrome 插件


这个月 2 号 Chrome 以 41.7% 打败 IE（41.4%），正式成为了市场占有率第一的浏览器，于是 Google 又完成了一次实至名归的「制霸」。

Chrome 的好用除了本身的流畅性以外，70% 的功劳更要归于其强大又顺手的扩展插件，这些插件满足了不同人的不同需求，也将该浏览器的使用体验拉升到了一个「曾今沧海难为水」的境界。可以说 Chrome 没了插件，就好像悟空没了金箍棒。

都说一招鲜吃遍天，今天就盘点一下那些 Chrome 扩展程序里的「一招鲜」，给大家推荐几款让你用上就戒不掉的好插件。为了方便对号入座，下面把推荐的类别分为「小白入门」、「技巧进阶」、「折腾狂魔」以及「奇技淫巧」四个部分，请自行按需移步。

“「小白入门」

Chrome 虽然已成为最常用浏览器，但像父母、长辈、女朋友等这类小白用户还是不少，于是这里要推荐的都是实用、上手容易、大幅提升体验、几乎没有学习成本的扩展插件，它们往往会让小白用户初尝便上瘾，从此再也离不开……

 1. 入门新标签页——Infinity

Infinity 是一款还算不错的基于 html5 技术的新标签页扩展程序，它重绘了大量图标，界面不丑。在新标签页提供了天气、待办事项、笔记等功能，并且还可以显示 Gmail 的数量和通知，是让新手喜爱并熟练 Chrome 的工具。

PS：如果你嫌弃 Infinity 太 low，那 Momentum 会是高颜值极简风的最佳选择。

2. 广告屏蔽——Adblock、Adblock Plus

屏蔽页面广告的插件是最受小白用户喜欢的，因为它对于没尝试过的人来说对用户体验的提升是最大的。Chrome 上较好的广告插件没太多争议，Adblock 和 Adblock Plus 二者选一就足够了，两者各有所长，视用户习惯而定即可。

3. 视频广告屏蔽——广告终结者

如今视频前面的广告动辄 90 秒的长度简直让人生无可恋，不过由于屏蔽视频广告比较麻烦，大多数插件都不太稳定，时灵时不灵的，只有「广告终结者」相对稳定（不过也是相对），需要时常更新，大部分情况下优酷、腾讯、爱奇艺等都能搞定。PS：截止发稿前广告终结者对于爱奇艺和优酷的屏蔽效果似乎又挂了…… 但愿能尽快恢复功能。

4. 鼠标悬停预览图片——Imagus

只要将鼠标悬停在图片上就能将图片放大看，甚至预览链接中的内容。一个来自 360 和猎豹浏览器的灵感，对于常常刷微博看图片的人来说是神器，其中还提供了更多自主化的功能设置。从此看图不用一张张点开了，鼠标指上去就行。

5. 视频下载插件——Video Downloader professional

把需要的视屏下载下来是很多人的需求，而对于很多小白用户来说这是一个繁琐的过程，且常常要在电脑上装一些流氓软件。不过 Video Downloader professional 可以帮用户检测页面中的所有视频文件，并提供一键下载，对新手非常友好。

“「技巧进阶」

这里是为那些已经稍熟练使用 Chrome 的用户准备的进阶套餐，这里的这些插件可以让你在平日的使用中掌握一些小技巧，对于很多事情能够事半功倍。

1. 标签页休眠——Tab Snooze

笔者力荐

相信很多人都有一下子打开几十个标签页的毛病，面对 N 多标签往往极大地影响效率，关掉怕稍后要用到，不关又碍眼。Tab Snooze 能把暂时用不着但又不能直接关掉的标签页先「休眠」，到了以后特定时间点后将其重新打开。一旦将标签页休眠以后，该标签页会自动关闭保存到 Tab Snooze 中，并有待打开标签数量显示。

2. 小内存救星——OneTab

上面提到一下子打开 N 多标签的习惯，除了影响效率更会对电脑内存造成巨大负担。因为 Chrome 的标签是独立进程，所以当打开过时浏览器内存占用就会超过 2G 甚至更多，自然会卡，这款插件正好可以解决 Chrome 内存占用过多的问题的。需要减少内存占用时，OneTab 会将当前打开的标签关闭，显示在插件的标签列表中，相当于只打开一个标签，内存占用就会瞬间从几个 G 减少到 100M 左右。

3. 一键切换 IE 内核——IE tab

这绝对是一个非常实用的插件，在如网银支付等等不支持 Chrome 内核的情景下，这个小插件帮你一站式解决，不必再专门去开启那个实在没法用的 IE 浏览器了。

4. 可能是最好用的截图——Awesome screenshot

应该算是最好用的网页截图软件了，支持截取整个网页而不单单只是当前界面，同时还支持对截出来的图进行注释、批注等画面标识功能，非常好用。还有一款名为 Capture Webpage Screenshot 的插件，同样是截图的但没有批注功能，相对简洁。


5.Google 出品的以图搜图——Search by image

这是一款由 Google 出品的图片搜索插件，安装后用户只需右键点击图片便能快速通过「以图搜图」功能找到类似图片了，不过需要注意的是这里用的是 Google 的搜索，所以有梯子这个插件才能用。

6. 还你个干净的微博——眼不见心不烦

不知道还有多少人在用网页版微博，那些八卦消息、星座排名肯定也恶心到你了吧官方提供的 5 个屏蔽名额不够用，又不想交钱开通会员，那这款插件可以帮你。「眼不见心不烦」提供了各种「宏拉黑」、「过滤话唠」等功能，给你一个还值得一刷的微博。


7.二维码生成器——The QR Code Extension

这个不必过多解释，似乎是目前使用人数最多的二维码生成器了。简单快捷，可以直接把当前网页生成一个可供扫面的二维码图片，有类似需求的推荐收了。

“「折腾狂魔」

这里是为那些不介意动手的用户准备的套餐，这些插件大多不是装上就能用的而是一些需要进行一些设定的或进一步操作的，但这部分插件的功能更强大，适用场景也自然更多。

1. 自动填写表单——iMacros for Chrome

在网上填写各种表单是我最讨厌的事，很多不重要、无意义的信息一遍遍地填写真的很让人想撞墙。iMacros for Chrome 正是一款可以减少用户劳动力，自动帮助用户添加表单的插件。安装并启动后，就可以和那些让人心烦的重复劳动 see bye bye 了。


2. 不可说之——Proxy SwitchySharp

对于这个插件懂得人自然懂，前身是 Proxy SwitchyOmega，对于很多 Chrome 老玩家来说这肯定是人手一份的。这里由于相关法律法律我不能说得太细，总之你知道这是一款可以快速切换代理，实现「局域翻」的神器，并且根据 pac 脚本实现自动翻墙就行。设置稍复杂，这里无法细说，可自行 Google。

3. 用鼠标操纵一切——Gestures for Chrome

这是目前 Chrome 上最受欢迎的鼠标手势插件，方便, 快捷, 充分发掘鼠标的所有操作，它可以代替绝大多数键盘的快捷操作。如常用的：向左拖动后台打开；向右拖动新标签页打开；向上拖动复制文字；向下拖动复制链接……等等，N 多手势都可以自由定义，发挥空间很大。

4. 用键盘操纵一切——Vimium

这是很多 Vim 党的必装神器了，算是一款非常有极客范儿的插件了，完全释放鼠标，用键盘取代所有鼠标的操作。功能强大，支持非常高自由度的用户设定，玩好了非常炫酷，但是上手比较难。

5. 浏览器密码管理——LastPass

LastPass 可能算是目前浏览器端目前最好用的密码管理器了，简单、美观，支持密码自动填充、生成密码，并且更重要的是密码填选功能可以在某一个标签页存储多个密码。

“6.全平台听歌——Listen 1 

自从国内的音乐平台开始打版权架，我的歌单就从来没在一个音乐平台上放完过，每个平台都会有这么一两首没版权的，切来切去听歌是很反人类的，Listen 1 是可以从网易云音乐、虾米、QQ音乐三个主流音乐网站搜索歌曲的音乐播放插件，从此听歌不用来回切播放器了。不过由于版权原因 Listen 1 没能在 Chrome 商店上架，需要下载并让 Chrome 以开发者模式加载。

具体步骤如下：

  • 下载源文件

  • 打开 Chrome 扩展程序菜单，勾选右上角「开发者模式」

  • 点选「加载已解压的扩展程序…」，选择 Listen 1 即可

“「奇技淫巧」

这部分介绍的是一些锦上添花的小工具，他们各自奇特或者小众的功能虽然不一定都实用，但总能在某些时候给你带来些小惊喜。

1. 插件好用但不要癫狂——一键管理所有扩展

一直在介绍各自插件，但是要知道插件装太多一样会导致 Chrome 占有内存过大，使得电脑卡顿。「一键管理所有扩展」支持一键管理所有扩展，包括一键禁用所有插件、一键开启/关闭插件、插件的逐个禁用和开启。很多插件不是时时刻刻都在用的，要用时打开，不用时关闭，这样才是一个理性的 Chrome 玩家。

2. 显示 IP 地址——Yet another flags

这是款帮你一秒知道当前网址的 IP 地址的插件，安装后打开每个标签页后都会在其网址后出现相应的地区国旗。可以在翻墙时分清自己使用的是哪个国家代理，简单顺手。

3. 海外同学的福音——Unblock Youku

要知道不仅 YouTube 在国内被墙，youku 等国内的视频网站因为版权等原因在国外也是看不了的。这款插件专为那些身在海外但是想追国内神剧的人设计，满足出国后翻回来看剧的奇葩需求。

4. 学霸专属——Daum Equation Editor

这是一款强大到我都不敢用的神奇插件，在平时遇到复杂的数学公式要输入电脑，各种特殊符号和专业的组合方式一定把你逼疯了吧。Daum Equation Editor 专为复杂公式而生，提供了全面的数学公式符号和组成方式，并可以将设计出的公式导出到自己的学术报告或者工作中使用。

5.没时间解释了，快上车——老司机编码助手

现在的人，一言不合就开始飙车……而这，正是一款由程序员老司机推出的带你飙车的插件，用起来顺畅无比。众多程序员都会感叹：哇，这车还 TM 是自动挡！

Chrome 插件里的学问有很多，这里提到的还只是些皮毛，更多像是 Tampermonkey 等等需要各种脚本来发挥逆天功效的插件这里就不提了，另外像是一些司空见惯的大众插件限于篇幅这里也没有多说。如果大家觉得这样的文章还不错，那么在未来还会带来更多更有趣的关于 Chrome 扩展程序的学问。
