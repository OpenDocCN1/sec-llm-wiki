乐视口中会「变革音频行业」的 CDLA 有哪些不为人知的秘密？

CDLA 

在一周前的乐视新品发布会上，乐视在发布新一代智能手机之前，推出了一个叫做 CDLA 的标准。CDLA 的全称是 Continual Digital Lossless Audio，即「全程数字化无损音频标准」，乐视表示这是一项足以「变革音乐」的技术。

CDLA 究竟指的是什么？它继是「无边框 ID」之后，乐视营销团队的又一个「力作」，还是真有什么「黑科技」？它会不会变革我们在手机上听歌的体验？

在这篇文章中，我们会从 CDLA 的原理、优缺点、实际声音表现、用户体验等方面全方位的为大家呈现一个完整的 CDLA 。

“CDLA 究竟是什么？

回答这个问题之前，我们需要先区分一下音频信号的类型。

音频信号可以分为数字音频信号和模拟音频信号两种，其中数字音频信号由包含众多的 0 和 1 的二进制数字组成，我们手机、播放器、PC 上存储的 mp3、AAC、FLAC、APE 等音乐文件都是这种数字音频信号；但数字音频信号本身是无法直接驱动耳机和音箱等发声设备的，为了让这些设备「出声」，需要先把数码设备中存储的数字信号转换成模拟音频信号。

以在普通手机上使用耳机听歌为例（其它设备类似），这一过程大致可以分为以下四个步骤。

提取：从手机中提取保存的数字音频文件；

解码：通过 Codec（部分「Hi-Fi 手机」会配备独立的 DAC 数码转换器）把数字音频信号转换成模拟音频信号（俗称「解码」）；

放大：使用运放芯片把模拟音频信号放大；

收听：才是把耳机插到 3.5 毫米插孔上听歌。

通常来说，前三个步骤都是在手机内部完成的，3.5 毫米耳机插孔输出的是经过放大后的模拟音频信号，可以直接让耳机「出声」。乐视的 CDLA 方案则是把第一步中提取到的数字音频信号直接通过 USB Type-C 接口传输到耳机中，并把随后的三步（即「解码、放大、听歌」）全部都转移到耳机中。

有没有感觉这种解决方案有些似曾相识？其实这和之前传闻的苹果要在 iPhone 7 砍掉 3.5 毫米耳机插孔、使用 Lightning 接口听歌的原理是完全一样的，只是乐视把 Lightning 接口换成了 USB Type-C 接口。

实际上，iPhone 现有的 Lightning 接口以及大多数手机上使用的 Micro USB 也可以实现 CDLA 标准中的这种「手机输出数字音频，耳机搞定解码和运放」功能。

只是上述这些手机几乎无一例外地保留了 3.5 毫米耳机插孔，而乐视则像传闻中的「iPhone 7」那样，直接在乐 2、乐 2 Pro、乐 Max 2 上砍掉了 3.5 毫米耳机插孔。

“CDLA 标准能不能提高音质？

理论上可以。

在乐视官方对于 CDLA  标准的宣传中，第一条就是可以「彻底告别3.5mm耳机的模拟传输信号易被干扰而带来的耳机噪声」。不过相比起音源、Codec 和运放品质等因素，3.5 毫米耳机插孔传输对音质的影响要小的多得多，单纯的 CDLA 数字传输本身并不会对提高音质带来明显的帮助。

相比之下，将解码和运放集成到耳机中带来的影响会更大。

在传统的手机中，由于 Codec 和运放集成在手机内部，在买来手机之后，手机输出的音质基本就固定了（使用外置耳放可能会带来少许的提升）。而在 CDLA 方案中，由于 Codec 和运放从手机内部转移到了耳机中，因此理论上来说，可以通过在耳机中配备更出色的解码和运放芯片，从而让耳机拥有更好的音质。

不过这里有一个非常重要的前提——需要有采用 USB Type-C接口、且内置高品质 Codec 和运放的耳机产品，而在乐视之前，此类的产品数量是……零。

为了避免出现尴尬的「空有标准没产品」的情况，乐视在发布 CDLA 标准时，还展示了一个类似「公版」的解决方案——一个集成 Codec 和微型运放的 USB Type-C 插头（如上图）。理论上来说，只需要把传统耳机上的 3.5 毫米插头「换成」乐视提供的这个 USB Type-C 插头，就可以在支持 CDLA 的乐视手机上正常听歌了。

基于该方案，乐视发布了一款「乐视数字线控耳机」（如上图），这也是目前唯一能正式买到的支持 CDLA 标准的耳机。此外，乐视发布会现场展示的 Fiil 头戴式耳机也采用了这种方案，相比普通的有线版 Fiil，「乐视版」把原来连接手机的 3.5 毫米插头换成了乐视提供的 USB Type-C 插头，理论上来说，普通版的 Fiil 头戴式耳机可以通过换线来支持 CDLA 标准。

“「隐藏」的 3.5 毫米耳机插孔

如果你不想专门给手机买一个这样的 USB Type-C 耳机，乐视在乐2、乐2 Pro 和乐 Max 2 的包装中，附送了一个下面这样的 USB Type-C 转 3.5 毫米耳机插孔的转换头。

根据上面的分析，由于 USB Type-C 输出的是数字音频，那为了让耳机出声，上面这个转换头中应该会内置 Codec 和运放才对。不过有趣的是，这个转换头并没有内置 Codec 和运放。

这又是怎么一回事呢？我们知道，iPhone 上的 Lightning 接口只能输出数字音频，而乐视等手机上使用的 USB Type-C 接口除了能输出数字音频，还能输出模拟音频。当给乐视手机插上这个转换头之后，乐视手机就和普通手机一样，使用手机内部集成的 Codec 和运放，直接在 USB Type-C 接口输出模拟信号，并通过转换头将这个模拟信号变成 3.5 毫米耳机插孔的形式。

从 EUI 中也可以看出这一点，当插入 USB Type-C 转 3.5 毫米转换头时，在「设置-声音和振动」中，最下面的「数字耳机」选项是无法打开的（如下图右），这时候 USB Type-C 接口只能输出模拟音频。我们还在华为 P9 和魅族 PRO 6 这两款同样使用 USB Type-C 接口的手机上测试了乐视附送的这个音频转换头，结果是华为 P9 同样可以使用这个转换头输出模拟音频，但魅族 PRO 6 不可以。

相对的，如果在给手机插入内置 Codec 的乐视数字线控耳机，可以在「设置-声音和振动」的底部选择是否使用「数字耳机」。打开后，手机会向耳机输出数字音频，耳机插头里的 Codec 和运放会把数字信号转换成模拟信号，并最终被用户听到；而如果不使「数字耳机」，则数字音频就会使用手机内置的 Codec 和运放转换成模拟信号，并直接通过 Type-C 输出模拟信号。

“耳机解码 PK 手机解码

那么问题来了，既然耳机和手机都能对音频进行解码放大，这两种方式的音质表现有多大的区别？

根据乐视的描述，使用耳机对数字信号进行解码放大（也就是 CDLA 标准模式）会拥有更好的音质，但在我们的体验中，同样使用这条乐视数字线控耳机，开不开「数字耳机」对音质的影响非常小，只是声音的风格会略有不同。

分析原因，这可能是由于这条耳机内置 Codec 和运放的品质不够好，也可能是因为这条耳机本身的发声单元素质有限，但起码在这条目前唯一能买到的符合 CDLA 标准的耳机上，CDLA  并没有提高手机的音质表现。

也就是说，虽然理论上 CDLA 标准能够提升手机的音质表现，但在乐视当前提供的解决方案上，CDLA 相比传统的使用手机自身进行解码放大并没有什么优势。

最后，我们有必要说一下乐 2 在使用「转换头+模拟输出」时的音质表现。作为一部主打 CDLA 数字音频的手机，模拟音频输出更像是一个「附加」功能，但有些出乎意料的是，乐 2 的模拟音频输出品质相当不错，在千元机中属于非常优秀的水准（如果你觉得手机的声音不对，建议去「设置-声音」里关掉「杜比全景声」），原因可能是其搭载的 Helio X20 SoC 集成的 Codec 品质较高。

“有潜力，但尚需时日

可以看出，乐视提出的 CDLA 标准只是对已有技术的重新包装，并没有称得上「黑科技」的东西。

不过 CDLA 标准的理念本身是值得称赞的，它可以让普通手机也可以通过使用内置 Codec 和运放的耳机，拥有媲美「Hi-Fi」手机的音质。而且通过砍掉 3.5 毫米耳机插孔，可以为手机内部腾出更多的空间。特别是如果今年下半年发布的「iPhone 7」也砍掉 3.5 毫米耳机插孔，将大大加快数字化音频的普及。

只是在现阶段而言，相比传统手机上使用的手机内集成方案，乐视提供的基于 CDLA 标准的产品并没有明显的优势，也无法和 vivo 等品牌的「Hi-Fi 手机」一战。

对用户而言，砍掉 3.5 毫米耳机、强推 USB Type-C 耳机这种做法，除了单纯地「搞个大新闻」之外，并没有给用户体验带来多少实质性的提升。

不过好在乐视保留了传统的模拟音频输出，除了需要随身带一个转换头，用户在乐视的这三款手机上使用传统的 3.5 毫米接口耳机时并不会有多大的麻烦，只是无法一边听歌一边愉快地给手机充电了（乐视这三款手机均不支持无线充电），除非你再买个蓝牙耳机。
