# 魅蓝 3 上手体验：599 元能买到的「最佳手感」

伴随着 SNH48、王尼玛、张全蛋的相继登场，我们总算迎来了魅族 4 月「巡演」的最后一场。在这场「收官演出」上，魅族发布了拥有 5 吋「小屏」、采用塑料后盖的魅蓝 3。  

在经过数年的屏幕扩张之后，今年的国产厂商在中高端手机上突然集体「回归理性」，无论是魅族 PRO 6、华为 P9 还是刚刚发布的 ZUK Z2 Pro，都不约而同地选择了相对较小的 5.2 吋屏幕。有意思的是，在销量更大的千元机市场，相对较大的 5.5 吋屏幕依然是很多手机的标配，魅蓝 note3、乐视手机 2 就是其中的代表。

如果你想购买一部屏幕稍小的手机，但又不想花上一部「国产旗舰」的钱，除了红米 3 等少数产品，当前市面上的选择并不多。起售价仅为 599 元的魅蓝 3 表现如何呢？我们接着往下看。

****************************************“******************************************塑料后盖，手感有惊喜**

从 2014 年底发布魅蓝系列的首款产品魅蓝 note 以来，除了魅蓝 metal 和魅蓝 note3 之外，魅蓝系列一直在使用聚碳酸脂塑料外壳。因此，这次魅族在定位更低的魅蓝 3 上重新用回塑料外壳，并没有什么值得意外的。

实际体验中，**魅蓝 3 的后盖手感和之前的魅蓝系列、iPhone 5c 非常接近，手感可以用「温润」来形容。**不过由于魅蓝 3 的后盖是光面的，长期使用免不了会出现细小的划痕（使用两个小时后，我们手上这台魅蓝 3 就已经出现了一些小划痕）。

![](../Images/f65b3ccc5054fa4e6d859ff5a453ef25.png)

更加难得是，虽然售价低廉，不过魅蓝 3 正面依然配备了 2.5D 弧面玻璃，屏幕一圈的塑料包面也没有明显高于玻璃边缘，而且和魅蓝 note3 一样，魅蓝 3 的听筒和 Home 键的玻璃开孔也经过了 2.5D 打磨。

手感温润的后盖，2.5D 弧面玻璃，平滑的边缘过渡，再加上 5 吋「小屏」，让魅蓝 3 的握持手感非常舒适。如果说在第一代的魅蓝 note 上，**魅族用四分之一的价格实现了 iPhone 5c 95% 的手感，在魅蓝 3 上，有了 2.5D 弧面玻璃的加入，魅蓝 3 的手感比 iPhone 5c 还要优秀。**

此外，由于采用了塑料外壳，魅蓝 3 也可以更轻松地「调」出来丰富的配色。

![](../Images/c7613779439bb9ce8bbea9aa0e160491.png)*图片来自魅族官方微博*

在发布会上，魅族展示了白、蓝、灰、金、粉五种配色可选，其中**金色为新增配色，粉色则在魅蓝 2 的基础上经过了进一步的调整，**从发布会上展示的图片上看（现场展示区没找到粉色版真机…），魅蓝 3 的「水粉色」和索尼 Z5 尊享版的「樱花粉」比较接近。需要注意的是，无论你买的是什么颜色的后盖，**魅蓝 3 的前面板都是黑色的。**

****************************************“******************************************硬件配置，「够用」就好？**

魅蓝 3 搭载了一块 5 吋、720p 的屏幕，色彩表现尚可，亮度稍微有些偏低。看惯了 1080p 甚至 2K 分辨率的屏幕，魅蓝 3 的这块屏幕还是能明显感觉到颗粒感的，不过毕竟 599 嘛，就不吐槽啥了。

配置方面，魅蓝 3 采用了来自联发科的 MT6750，分为「2GB 运存+32GB 存储」、「3GB 运存+32GB 存储」两个版本，并搭载了基于 YunOS 的 Flyme 5.1 操作系统。

![](../Images/df273bde2befcff296fa88d6f4eb6468.png)*魅蓝 3（左）和魅蓝 note3（右）*

相比魅蓝 note 3 的 MT6755（Helio P10），魅蓝 3 的 MT6750 在 CPU 主频以及 GPU 性能上均有所缩水，但由于屏幕分辨率从魅蓝 note3 的 1080p 降到了 720p。理论上来说，魅蓝 3 和魅蓝 note3 的运行速度应该相差不大。

结合我过去两周使用魅蓝 note3 的经验，这个配置搞定电话、短信、微信、微博这些日常的轻度使用问题不大，但想要「不卡」肯定是不现实的。再加上 Flyme 相对保守的后台策略，后台任务开多了，先前打开的 app 经常会被自动清空。如果你喜欢后台开很多 app，建议直接购买 3GB 运存的版本。

**「诚意」的摄像头**

摄像头方面，从参数上看，魅蓝 3 的前置和后置摄像头都和魅蓝 note3 完全相同，其中前置摄像头为 500 万像素，光圈 ƒ/2.0，后置摄像头为 1300 万像素，光圈ƒ/2.2，支持相位对焦，摄像头不突起机身。

![](../Images/664eb888d903e06d58011c9bd92c3a12.png)

在这个价格段上，魅蓝 3 的摄像头配置已经算是很有「诚意」了，在使用过程中，可能是由于我们手上这台魅蓝 3 是媒体测试机，对焦速度比魅蓝 note3 要稍微慢一些，场景发生变化时，魅蓝 3 的预对焦系统偶尔会失效。

成像质量上，魅蓝 3 的表现和魅蓝 note3 也非常接近，虽然没什么惊喜，但也完全对得起售价了。

![](../Images/c10d7b2cdd70e803b619f68afbedcecf.png)

**魅蓝 3 配备了容量为 2870 毫安时的电池**，配套的电源适配器为 5V、1.5A，比魅蓝 2 的电池容量略有增加，不过相比红米 3 高达 4000 毫安时的电池容量要小不少，但相应的，魅蓝 3 的 132g 的重量也要明显比 144g 的红米 3 轻一些。

值得一提的是，魅蓝 3 保留了**双卡双待、全网通、VoLTE、eMMC 5.0 存储、Micro SD 卡拓展**（和其中一个 SIM 卡共用一个卡槽）等相对「高端」的功能。

不过出于成本原因，魅蓝 3 没有配备正面按压式指纹识别（支持 mBack 触摸返回）。另外，和魅蓝 note3、魅族 PRO 6 一样，魅蓝 3 也没有配备 NFC，毕竟 599 嘛，还要啥自行车。

****************************************“******************************************对比红米 3 **

综合考虑屏幕尺寸和产品定位，魅蓝 3 最大的对手可能就是红米 3 了，我们先来看一下二者的配置表。

![](../Images/2684dd72bd3842f44950d8c7149e9f07.png)

从性能上，魅蓝 3 配备的 MT6750 和红米 3 上的高通骁龙 616 基本处于同一水准，在摄像头、支持的网络制式等方面，二者也非常接近。

相比之下，红米 3 的优势是它的全金属后盖和更大容量的电池容量， 而魅蓝 3 的优势是正面的 2.5D 弧面玻璃和温润的聚碳酸脂后盖，至于金属和塑料的喜好问题，大家就见仁见智了。

售价方面，魅蓝 3 相比红米 3 有 100 元的优势，不过红米 3 还提供了一个增加指纹识别的「高配版」可选。当然，**前提是你可以以官方价格买到，对这两款产品而言，这都是一个大大的「如果」。红**米 3 已经上市 3 个多月了，现在还是得靠人品去「抢」，而根据以往的经验，魅蓝 3 上市初期的供货状况应该也不会多乐观。

**************************************“**************************************599 能买到的「最佳手感」

![](../Images/624395783703c042f8e599896e829f5d.png)

总体来说，在第一时间的使用过程中，魅蓝 3 给我的感受还是相当不错的，并没有因为售价的降低而导致产品更「廉价」。**尤其是在「摸」惯了金属手机后，用回魅蓝 3 这种温润的塑料后盖，会有种非常微妙的满足感**，在同价位的手机中，恐怕也没有那部手机能拥有魅蓝 3 这样优秀的手感了。

对比魅蓝 note3，魅蓝 3 在 SoC、指纹识别、存储速度等方面略有缩水，考虑到二者的差价仅有 200 元，如果你不介意大点的屏幕，我还是更推荐大家购买魅蓝 note3，而如果你喜欢尺寸稍小的屏幕或者不喜欢金属「冷冰冰」的质感，魅蓝 3 也是一个非常不错的选择。

当然，最后还是那句话，前提是你能原价买到。
