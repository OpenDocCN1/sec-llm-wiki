极客头条：为中国而造？Model S 将迎来更新 增加「防雾霾」功能

来源：腾讯科技

特斯拉将对 Model S 车型进行一系列升级，这一升级的目的是「简化车辆生产流程，同时使其更具奢华气息」。同时，这次的升级也将帮助 Model S 更好的迎接的来自包括宝马、奥迪和奔驰这些传统车企电动车型的挑战。

全新 Model S 将配置与 Model X、甚至是最新 Model 3 相似的前脸设计、使用一些新喷漆颜色、经过重新设计的 LED 前大灯以及与 ModelX 相似的豪华通风座椅等。

新款 Model S 还将搭载名为「生物武器防御模式」（Bioweapon Defense Mode）的空气过滤系统，以及最高 100 千瓦时的电池容量选项。

其中，所谓的「生物武器防御模式」其实没有我们想象中那么神乎其神。简单来说就是，用户可以通过一个按钮一键激活车载空气过滤装置，这一装置能有效吸收有害气体、粉尘等污染物，并可以在几秒之内将车内臭味清除干净。

根据国外媒体此前对 Model X「生物武器防御模式」进行的测试结果来看，这一车载空气过滤系统效率高于行业平均水平 10 倍左右。而根据特斯拉的介绍称，这项功能对于细菌的过滤能力也提高了 300 倍。

此外，马斯克也曾在 Twitter 上透露，该功能将给用户带来「医院级的空气质量」。

知情人士表示，这款新车型最早将于本周推出，同时推出的还有 Model X 定制车型。不过由于特斯拉经常会在最后时刻调整计划，因此这些升级配置也依旧有可能会推迟，甚至取消。

事实上，特斯拉并没有像传统汽车厂商一样以年份来命名换代车型，但 Model S 的确在过去几年内迎来了多次升级。其中，最重要的一次升级无疑是在去年增加了半自动驾驶功能。

为那些热爱科学的少年，Google 设立了一个奖

来源：网易科技

Google 全球科学挑战赛到今年已经举办到了第六届，这是一项针对全球 13-18 岁之间的青少年举办的赛事，学生可以以个人或团队的形式参赛，分科学类和工程类两类探索科技，解决身边甚至是全球性的问题。

简单来说，如果学生提交的项目旨在解决工程难题，那么他就有资格获得维珍银河公司或者乐高教育提供的奖项，而如果学生提交的项目是偏向用实验解答科学理论问题，那么他可能获得的奖项就可能是由国家地理学会或者《科学美国人》提供的。

美团点评：猫眼电影 3 月已盈利 将分拆独立运营

来源：凤凰科技

美团大众点评 CEO 王兴通过内部邮件宣布，正式分拆猫眼电影业务，让"新猫眼"成为一家完全独立运营的公司。这是继去年 7 月美团宣布猫眼成为独立子公司后，再一次重大的战略调整。
