微软刚刚在上周召开了自己一年一度的 Build 开发者大会，在这个大会上，微软对自家的主要产品 Windows 10 系统宣布了一系列将要进行的更新和改变，并且他们承诺将会在今年夏天正式推出新版本的 Windows 10。而仅仅几天之后，今天，微软就宣布他们面向微软 Fast ring 项目中的内部成员推出了最新的预览版本 Windows 10 build 14316。

让我们来看看这个新版本的 Windows 10 中都有哪些值得关注的亮点吧。

******************“******************一、Linux 命令行工具来到 Windows

在之前的 Build 大会上，微软就已经宣布他们将会把 Linux 系统上的命令行带到 Windows 10 中，而在这个新版本中，你就可以如同微软之前所说的那样在 Windows 10 中运行本地的 Bash Shell 了。Bash（Bourne Again Shell）是 Linux 系统中使用的一种 Shell。它为用户提供了使用文本命令模式来实现各项功能（和/或使用脚本）。

![](../Images/40a37180b36924461275def916841952.png)

要实现这个功能，你首先需要通过「设置」>「安全和更新」>「针对开发人员」将系统转为开发者模式，之后在其中搜索「Windows Features（Windows 功能）」，然后再选择「Turn Windows features on or off（开启或关闭 Windows 功能）」，即可启用 Windows 的子系统 Linux，然后打开命令提示符输入「Bash」就能安装 Bash Shell 了。

******************“******************二、Cortana 大更新

在新版本的 Windows 10 中，Cortana 得到了非常大的重视，它有几个非常大的改变。而这些改变是覆盖全平台设备的，这也意味着即使你没有 Windows 10 系统的手机，只要你在自己的 Android 机上安装了最新版本的 Cortana，你也能用到这些新功能。

1\. 低电量通知。现在，当你的设备处于电量不足的状态时，Cortana 会提醒你注意这一点，帮助你记得要去充电；

📹 [https://v.qq.com/iframe/preview.html?vid=u0192nuhla6&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=u0192nuhla6&width=500&height=375&auto=0)

2\. 追踪手机。许多人都时常会发现自己一时找不到自己的手机了，这时，你可以用 PC 上的 Cortana 去发现自己的手机，当然你需要先安装设置好；

3\. 跨设备分享地图路径。在新版的 Cortana 中，你不必再为了不同设备之间的地图信息转移而感到头疼，Cortana 可以自动帮你在不同设备之间做到这一点。

******************“******************三、为 Microsoft Edge 浏览器添加新的扩展插件

半个月之前，我们就为你报道过 [Microsoft Edge 浏览器将要添加扩展插件](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=404909036&idx=3&sn=618aa21baa67fd05e899ffaf430f0426&scene=21#wechat_redirect)的消息，而今天，他们终于对这个功能进行了更新，添加了几个新的扩展插件，并对之前的翻译、鼠标手势和 Reddit 增强套件等插件进行了更新。

******************“******************四、操作中心改进

现在，你可以在「设置」>「系统」>「通知和操作」中对不同应用对你的重要性进行分类了，共有「正常（Normal）」、「高（High）」以及「优先（Priority）」三个选项，这样，你就可以对众多应用所带来的消息进行优先级的划分了。

******************“******************五、新的 Emoji 表情

采用了配套的微软设计语言的新版本 Emoji 表情你会喜欢吗？

![](../Images/37ead7505b179604a9102678698811c3.png)

******************“******************六、个性化中颜色改变更贴心

在新版本的 Windows 10 中，如果你将系统的颜色改变成了暗色，那你在 Universal Windows Platform 平台上应用（比如「设置」、「应用商店」等等）的颜色也会随之改变，而如果你不喜欢这个功能，你也能够选择不要它。

![](../Images/e61c6b39053ca3fdab99e6b00641a853.png)

******************“******************七、虚拟桌面的改进

这个功能对喜欢在 Windows 10 中使用多个桌面窗口的用户来说是很有用的改进，因为你现在可以将一个窗口固定在每一个桌面中，比如 Skype，这样不管你切换到哪个桌面上，你都能一致地使用这个应用。

![](../Images/4c6bca0d1929db4eec4367250e2d33d6.png)

******************“******************八、对节电模式的改变

新版本中的「节电模式（Battery Saver）」这个选项将会更名为「电池（Battery）」，这样会给用户一个更加综合的电池管理印象。同时，新版本中你可以更清晰地了解到电脑中不同应用对电源的使用程度，而你也能对每一个应用的运行状况进行选择，当你拒绝让某个应用在某台运行时，那它就无所遁形。让你更好地管理自己电脑中的应用。

![](../Images/8dcaeddef79e850e162bc7f5dae84812.png)

******************“******************结语

当然，这些都只是其中的一部分而已，除此之外，在这个预览版本中，Windows 10 还对不少的 Bug 进行了修复，比如对一些机型的不友好等等，想要查看全部的更新信息，请移步阅读原文。具体的使用体验恐怕还得等真正上手了之后才能得到。
