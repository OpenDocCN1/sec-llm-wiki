比特斯拉更酷炫的，恐怕只有它的生产工厂了

特斯拉    硅谷钢铁侠     Model 3 


上周发布会刚刚结束的时候， Model 3 的预售量就已经突破了 12.5 万。据特斯拉 CEO 埃隆·马斯克透露，截至 4 月 2 日，Model3 的订单数量已经达到 27.6 万辆，超过了特斯拉目前为止的全部销量总和。特斯拉的股价也受此提振不断高涨，创下去年 10 月以来的新高。

Model 3 大热的背后，让人又不免开始担心 Model 3 生产的方方面面自建工厂是否能顶得住产能压力？尚未确定的交付日期是否会遥遥无期？同样，很多人也不理解特斯拉为什么坚持自建工厂，而不是全球制造。

当我们回顾特斯拉的诞生时，曾描述过 Roadster 的量产是怎样一种噩梦——车身面板由法国制造，发动机则由中国台湾制造，在中国大陆购买的单块电池，运到泰国组装成电池组，然后在最短的时间内送到英国去清关，以防它们降解。整车在英国组装好后，经由好望角运至洛杉矶。当时，特斯拉最年轻有活力的一群工程师深陷泰国，督促供应商给生产电池组的厂棚加上一圈墙壁。

从变速齿轮到挡风玻璃，事实一再证明，特斯拉这种硅谷初创公司即使找到了顶级供应商，也得不到他们最好的团队的支持，即使特斯拉再有雄心魄力，也很难调动起外包服务公司的积极性。

“弗里蒙特的「终极工厂」

到了生产 Model S 的时候，马斯克不想重蹈覆辙，他希望特斯拉和 SpaceX 一样，搭建自己的内部生产线，尽可能自主完成生产。

Model S 的原型车是在 SpaceX 工厂里的一个大帐篷里造出来的，特斯拉尽力完成了它的发布会，但关于量产计划却毫无眉目。根据特斯拉商务副总裁迪尔米德·奥康奈的回忆，当时的打算还是找厂家代加工车身部件，完成焊接和喷漆再运送过来，但即使这样也遭受谈判受阻。他只能临危受命，解决建造工厂的资金问题。

好在特斯拉的产品实力让他们在 2010 年和能源部签下 4.65 亿美元的贷款协议。同年 5 月，特斯拉低价收购了加州弗里蒙特（Fremont）的一个旧工厂，这里曾是通用汽车和丰田汽车在硅谷边缘的旧厂址，51.1 万平方米，你能想象到曾经在这里的样子：黑色机器，水泥地板，以及经济衰退的年景散发出来的沉闷的味道。

特斯拉不费分毫地获得了巨型金属冲压机等设备，并把这里变成了十足的硅谷风格，喷在工厂外墙上巨大的「特斯拉」字母，让驾驶经过甚至上空飞过的果壳都能感受到特斯拉的存在。厂房铺上了洁白的树脂地板，墙壁和梁柱也刷成了白色，生产线上紧密协调作业的机械臂阵列则被喷成了红色，员工骑着自行车在工厂内走动，天窗洒满阳光，漂亮的工厂也是吸引人才的一方面，这里看上去就像是圣诞老人工作的地方。

在美国国家地理「终极工厂」系列纪录片《特斯拉》一集，大家可以看到首批量产的 Model S 是如何被生产出来的。在进行量产测试时，距离 Model S 首批交付的日期仅仅只有两个月。在这个工厂的流水线上，铝片被切割、冲压，每个机械臂都能进行不同的任务，冲压、焊接、铆接、胶合，它们反复磨合，聪明又棘手，外壳送到在二楼安装电动感应机马达和由 7000 块小电池组成的电池组，打造出由 14 各段落组成的白色车身，然后车身被悬吊式运输局送到另一栋楼中的喷漆中心，完整最后的步骤。在首批 Model S 交付仪式上，车主直接从这里把车开出工厂大门。

这个庞大的工厂在 2012 年开始 Model S 的生产，其生产线成本约为 1 亿美元，在空间上只占用了 20%，剩下的 80% 称之为「暗面」，虚位以待后续第三阶段的车型，也就是 Model 3，它们量大而物美价优，最终会填满这个工厂。

“Gigafactory：未来最大的锂离子电池制造工厂

Model 3 并不只是新推出的一款车型，而是特斯拉伟大抱负的核心，按照特斯拉的计划，2017 年将实现 Model 3 量产，到 2020 年将电动汽车年产量提高至 50 万辆，长期目标是每年产量达到 100 万辆。

特斯拉已经消耗了全世界很大一部分锂离子电池，它需要一个比目前规模大得多的新电池厂生产 Model 3。为了保证这个酝酿多年的计划顺利完成，2014 年，马斯克宣布建造一个「超级工厂」（Gigafactory）——它将成为世界上最大的锂离子电池工厂。

为什么要自己建造一座电池工厂？埃隆·马斯克说：「汽车公司都认为电池工厂是电池供应商那边的事，但据我所知，所有供应商都不想花几十亿美元来建造一个电池工厂。我知道，除了我们，没人会建造这么一个工厂。」

在选址上，超级工厂必须配备铁路沿线，用来把异常沉重的蓄电池送至加州的制造厂。马斯克的名人光环，加上超级工厂 2020 年最终完工将为当地提供 6500 个就业机会，引起了七个州的疯狂竞标。最终，特斯拉在内华达州里诺市郊外建造这家工厂，并从该州拿到了免税、免费土地等优惠……最终特斯拉从政府手中获得了共计价值达 14 亿美元的奖励，在此之前只有波音、英特尔这样的巨头才能享受到如此优惠。

「超级工厂」占地总面积超过 1000 公顷，建筑面积超过 51 万平方米，到 2020 年，它的总规划面积将达到 126 万平方米，按照体积计算，其完工后将成为世界上第二大建筑。

近期曝光的一组「超级工厂」照片，白色屋顶上还将覆盖太阳能面板

到 2020 年「超级工厂」能够全力运转时，特斯拉与其合作伙伴对超级工厂投入将高达 50 亿美元。

具体有多贵，看看工程价格就知道了：

  • 四个独立的有抗震功能的地基——1600 万美元

  • 钢铁混凝土建筑夹层——1300 万美元

  • 屋顶第一阶段——450 万美元

  • 建筑结构部分——1000 万美元

  • 电气基础设施——30 万美元

  • 周边载运拖车——100 万美元

  • 消防指挥中心和哨岗——几十万美元

  • ……

特斯拉会负责运营工厂和调整运维，预计到 2020 年「超级工厂」生产的电池将比 2013 年所有电池制造商生产的电池总量还多，这些电池每年可供应 50 万辆电动汽车。

根据特斯拉联合创始人斯特劳贝尔的说法，出自超级工厂的电池组会便宜很多，质量也会提高。如果超级工厂真的能够实现在 2017 年末将锂电池组的成本降低 30%，不仅能够让 Model 3 达到售价 3500 万美元的目标，还能为续航超过 500 英里的电动汽车的上市铺路。

这同样会是一座让托尼·史塔克艳羡的工厂，它的完全使用可再生能源，自己生产所需电力，工厂屋顶和周围山顶都将安装太阳能电池板，此外还将利用地热和风力发电，建筑主体的形状像切割后的钻石，也是为了能让其与环境相匹配。

特斯拉官网上的一张「超级工厂」概念图

未来如果有需要的话，马斯克还会建造第二家超级工厂，和内华达州的这一座在技术上相互竞争。

马斯克对特斯拉的未来很乐观，他对传记作者阿什利·万斯透露了一些更加异想天开的计划，比如，重新设计特斯拉在帕洛阿尔托的总部：

「其他公司的大堂里都有滑梯，我在想要不要在我们的大厅里装一个过山车，就像是福利特蒙工厂里的那种功能性过山车，你可以坐进去，然后他会带你绕工厂一圈，还能上升下降。除了咱们，哪家公司还会有过山车呀？」
