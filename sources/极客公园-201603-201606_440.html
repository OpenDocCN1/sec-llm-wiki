Oculus Rift 和 HTC Vive 发售两周之内，VR 已经成了各界关注的热点。对于那些已经开始考虑是否购买一台 VR 设备的玩家而言，在一开始他们需要考虑的问题是：我的电脑能驾驭得住它吗？这里有一份买前指南。

相比于 PC 游戏，VR 游戏所需要的配置更高。简单地来说，是因为它所需要渲染的分辨率（第一代的分辨率是 2560×1200）要比今天广泛采用的 1080p 的电脑屏幕高。更不用说，VR 游戏必须是被渲染成 3D 的，并且第一代的 VR 头盔需要持续不断的输出 90FPS 画面，否则里面的图像就会变得卡顿。

Oculus 和 Valve/SteamVR/HTC 公布过官方的推荐 VR 游戏配置。这给予了开发者一个标准的硬件标准，这样他们才能保证持续不断的 90FPS 图像输出标准能够达到。如果你的硬件达不到推荐配置，还要强行上 VR 头盔，那么设备的帧率可能会低于 90FPS，给你带来的 VR 体验也会非常糟糕。

两者的推荐配置都十分相似，但让我们分别来看看每家公司提供的配置表，你可以对照着检查自己电脑是否已经准备好了接受 VR 的洗礼。

“Oculus Rift 推荐的 VR 配置（2016）

GPU：NVIDIA GTX 970 / AMD 290 等效或更高

CPU：Intel i5-4590 等效或更高

运行内存：8GB+ RAM

视频输出：兼容 HDMI 1.3 视频输出

USB 接口：3 个 USB 3.0 接口外加 1 个 USB 2.0 接口

运行环境：Windows 7 SP1 64 位以上

此外 Oculus 官方提供了 Oculus 兼容性检查的应用，可以自动检查用户电脑是否与官方推荐配置相兼容。

“Valve / SteamVR / HTC Vive 推荐 VR 配置（2016）

GPU：NVIDIA GeForce GTX 970 / AMD Radeon 290 等效或更高

CPU：Intel i5-4590 / AMD FX 8350 等效或更高

运行内存：4 GB RAM

视频输出：HDMI 1.4 或 DisplayPort 1.2 或更新

USB 接口：一个 USB 2.0 或更高接口

运行环境：Windows 7 SP1 64 位以上

Valve 提供了 SteamVR 性能测试应用，这款应用也可以测试用户的电脑是否应对得了 VR 游戏。

因为 Oculus 和 SteamVR 的配置如此相似，在电脑上运行这两款应用，也可以有助于确定电脑能否同时应付得了 Oculus Rift 和 HTC Vive。
