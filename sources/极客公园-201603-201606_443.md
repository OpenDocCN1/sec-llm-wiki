# 为什么对 Tesla 来说，Model 3 才是他们最重要的产品？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=405211571&idx=3&sn=ef26960e67f6e0d0896a93d42b77b529&chksm=f8527405cf25fd13562faf980fb2c88f86b56f1d147674e90c109365a5663b77ad85e0d0eeb3&scene=126&sessionid=1681311563#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=405211571&idx=3&sn=ef26960e67f6e0d0896a93d42b77b529&chksm=f8527405cf25fd13562faf980fb2c88f86b56f1d147674e90c109365a5663b77ad85e0d0eeb3&scene=126&sessionid=1681311563#rd)

埃隆•马斯克（Elon Musk）在今天中午为我们揭晓了 Tesla Model 3——这款也许是对他最重要的产品。作为 Tesla 第一款面向大众人群的轿车系列，**Model 3 的价格「仅仅只有」35000 美元，大约相当于 22.6 万人民币**。相比之前价格平均在 10 万美元之上的 Model S 及 Model X，Model 3 也许能够让 Tesla 真正地走进大众市场。

******************“******************关于 Model 3，除了数据，你还需要知道这些

**「从简单的加速过渡到可持续的交通非常重要」**，这是马斯克在发布会的台上说的话，**「这对我们世界的未来非常重要。」**

马斯克当然对自己的产品非常满意，而我们也有文章为你具体地介绍了有关 Model 3 的数据相关的内容，那我们来看看还有什么其他的内容是你需要知道的。

*   首先，**从价格上看，我们就能明白这台车的定位：面向大众。**35000 美元的售价相比之前相对定位高端的 Roadster、Model S 及 Model X 来说都亲民不少，而这也符合马斯克自己一直以来对 Model 3 的宣传。![](../Images/2138173f8a62295baef3bd28a6cfd757.png)
    
*   其次，**它在这个价位上、在电动汽车这个领域绝不是没有对手**，其中它最大竞争对手就是通用汽车（GM）刚刚在上上个月发布的电动汽车** Chevrolet Bolt**。当 Chevrolet Bolt 当时发布时，大家就已经发现它就是面向 Model 3 而来，让我们来看看 Chevrolet Bolt 的数据吧：续航 200 公里，售价为 30000 美元，也将会在 2017 年正式上市…这一切都显示着它就是 Model 3 的最大对手，《连线》杂志当时就撰文称其是**「世界上第一辆真正面向大众市场的电动汽车」**。而二者间究竟孰高孰低，恐怕都要等他们上市了才好比较。
    
*   第三，虽然竞争不少，尤其是在国内它的价格可能会因为各种税务的原因有所上升，但你也**不太需要为 Model 3 的销售感到担心**。就像很多人都意识到了的那样，Tesla 已经像苹果那样积累了许多忠实的粉丝，就在马斯克刚刚开始将 Model 3 推出到台前时，已经有 11.5 万人交了 1000 美元的订金，等到发布会结束的时候，预售量已经突破了 12.5 万。![](../Images/64a7e54e522bdca5a3365055479c5c47.png)
    
*   第四，在**销售策略**上，Model 3 将会从美国的西海岸开始发售，然后是美国东海岸，再之后是欧洲和亚洲，最后才会是那些开右舵车的国家，当然如果是 Tesla 的老用户会得到一些优惠措施。当然，虽然马斯克说他会在 2017 年正式发车，但有过购买经验的用户应该都知道这个过程会很漫长，你很难会在那个时间点就能开上 Model 3，**毕竟在去年一整年里，Tesla 一共也就卖了 5 万多辆车，这也就是通用汽车一周的销量。**不过，那些经过了漫长的等待之后收到了汽车的用户大都觉得，这段等待是值得的，毕竟开过的都说好！
    
*   第五，**如果你以为 Tesla 推出 Model 3 只是为了推出一个新车型，那就图样了。**他们在这之中还有别的收益呢。因为根据加州的法律，每一家汽车制造商都会被要求生产一些零排放的汽车，而没达标的厂商还可以从有有余力的厂商那里购买「零排放信用值」。显然，Tesla 的这种「信用值」非常多，他们每年都会通过这个渠道获得很多收益，在去年第一季度，他们就通过这个方法获得了 5000 万以上的收入。但随着厂商们纷纷加大在环保上的投入，Tesla 在这方面的收入在逐渐下降。不过随着 Model 3 的推出，Tesla 在销量应该会得到一个较大的提升，这会给他们带来更多的收入。
    
    ******************“******************这就是马斯克的核心计划
    

在此之前，马斯克引进了高端运动跑车 Roadster，然后开发了 Model S 系列，最新的则是 SUV 车型的 Model X 系列，但是**他们的核心计划从未变过，那就是 Model 3。**![](../Images/a0460fb07157d6af06027a6f8d353119.png)

在 10 年前的一篇博文中，马斯克在结尾处这样写道：**「简而言之，我们的总体规划是：先打造跑车，然后用赚到的钱去生产大众消费级汽车，然后再用赚到的钱去生产更多的大众消费级汽车... 别把这个想法告诉任何人。」**在今天的发布会上，马斯克也用我们所熟悉的演讲方式——你总能从他的表现中看出认真排练和磨练脚本的迹象，尽管那些无休止的「嗯、啊」以及那些奇怪的咳嗽和大笑都让他看上去不够自信——表达了这一切，**「Model S 系列和 Model X 系列都为 Model 3 的开发买了单，谢谢它们！」**这也是因为马斯克明白，一年只在高端用户中卖出几万辆车绝对没办法实现他的理想。

而对马斯克来说，Tesla 的未来在某种程度上就要看 Model 3 的表现了。**马斯克在 Model 3 上投注了数十亿美元，他需要从中获得足够的收益。**而从发布会时得到的预售数据来看，情况似乎还不错，在发布会结束的时候，Model 3 的预售数量已经突破了 12.5 万！这个数字在汽车领域可不简单，毕竟现在 Model 3 还只是在预订状态，即使你现在已经交了 1000 美元的订金，你也至少要等到 2017 年年底才能真正收到这辆车。

不过 Tesla 也已经计划在明年将其线下经销商与服务网络的规模翻一番，这可能也是他们在为了走进大众市场所做的提前准备。但他们能否真正取得成功，我们还得至少等 18 个月才能知道。
