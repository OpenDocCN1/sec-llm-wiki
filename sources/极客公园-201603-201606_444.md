# 梦寐以求的 Model 3 发布，剁手预订 2 年后的汽车值吗？

今天我们终于见到了 Tesla Model 3 的真容，之前的各种猜测和曝光也都一一印证，售价 3.5 万美元 （约合人民币 22.61 万元），单次充电续航 215 英里（约 346 公里），拥有 Autopilot 自动驾驶功能，将于 2017 年正式交付。

![](../Images/1b29b09f10912fe3e46007e3562b2bcd.png)

但关于汽车的内部细节却并没有任何介绍，只是摄像机轻轻扫过，与 Model S 和 Model X 在功能上都有哪些差异也都并没有提，总之发布会就是出人意料的就结束了，让我们都还没回过神来，但发布会还是有很多地方值得我们好好体会。

******************“******************消除你的「里程焦虑」

Elon Musk 称，特斯拉推出电动车的初衷就是减少碳排放，缓解大气污染问题。同时 Tesla 今年要建成全世界最大的电池生产工厂。为了让车主能够开着车去更远的地方，不会让车主出现续航焦虑的问题。Elon Musk 还曾呼吁 200 英里是电动汽车的「最低门槛」，所以 215 英里这个数字在入门级的电动汽车里已经是相当不错的表现，它也能够满足大部分城市内的白领需求。

![](../Images/ee75c0172b4c300e4fc870129409647f.png)

同时 Tesla 决定在今年全球 3608 个快速充电点的前提下，在 2017 年实现翻倍的增长达到 7200 个快速充电点，让你不再为充电而忧心忡忡。

![](../Images/8c1d93df75524a88de038800f186601a.png)******************“******************百公里加速缩水？

说到百公里加速时 Elon Musk 是这么说的「0 to 60 in under 6 seconds.」也就是会在 6 秒以内，但这估计也要到汽车量产后，经过调试才能确定准确的加速时间，但总之百公里加速应该会比 Model S 慢 1、2 秒吧，毕竟价格有所差异。Elon Musk 还调侃说这比雪佛兰的 Bolt 还是稍微快一点的。

![](../Images/abac5fac3e038cc0fc8568663d6a1022.png)

说完了速度，同时安全也需要让人放心，Tesla Model 3 已经通过了 5 星安全认证。

******************“******************设计更加「激进」的内饰和外观

Model 3 通过调整前排座椅向前来增加内部空间，而不使汽车外形变得更大，而这也是它的一个关键的优势，因为电动车并不像传统车一样拥有前置发动机。所以从外形中看到车也许是会比 Model S 小，但它车内空间应该会和 Model S 相同，并不会有太大的变化。 

![](../Images/3603912ea8c9d43c3428b6789c890b4a.png)

除此之外，更让人惊艳的则是他的内饰，之前有猜测会因为成本取消车内的 17 寸大屏，现在看来不仅没有取消还变成了横置的，而且车内没有了仪表盘，未来会采用 HUD 的形式？这也说不定吧。虽然整体内饰非常简洁，但好像也让人少些许「安全感」，也许这只是一个工程版本吧。

![](../Images/54e2e8fd9d55243160095de1226cdb95.png)

而外观则没有了天窗，Model 3 的前风挡玻璃和车顶变成了一整块玻璃，传统汽车的前进气格栅也完全消失，汽车整体的线条感更加流畅，只能说它的外观设计更加激进，未来感十足。

![](../Images/73a11051d1e2351a9b6a854e214857d1.png)

******************“******************它的竞争对手将会是雪佛兰 Bolt？

发布会上 Elon Musk 还提到了通用汽车公司推出的雪佛兰 Bolt 很大的原因就是要和特斯拉竞争。

![](../Images/d32d0169d76a269e9c6067b501f0c872.png)

因为其实大多数人根本没有能力购买超过 $ 70,000 的特斯拉。但像日产 Leaf 这样比较实惠车型仍然不能够打消了可怕的「里程焦虑」，但有很多美国的电动车都只有 80 英里。所以通用和 Tesla 推出的这两款车其实都是在抢占这个市场。

![](../Images/4d923f7c3214fe44c7dc44330491442b.png)******************“******************关于购买

而 Model 3 新车在海外起售价为 3.5 万美元，约合 22.6 万元人民币，加上运输装载费、关税和增值税，到国内售价很可能会在 35 万元左右（没有算上可能有的政府补贴），而这在国内这个售价正是与宝马 3 系、奥迪 A4 L、奔驰 C 级等豪华中型车价格差不多，所以「剁手」前要先想好啊。

![](../Images/398243cd5690946ac6f90326461beebf.png)

目前中国大陆地区的预订金数额为 8000 元，每人每次付款限订购 2 台。现在 Model 3 接受两种方式的预订：

*   3 月 31 日起直接前往各地特斯拉线下体验中心进行预订。
    
*   今天上午 10 点 30 分后，登陆特斯拉中国官方网站进行线上预订。
    
    ******************“******************最后
    

这款被称为低配版本的 Model 3 虽然在配置上做了很多的妥协，但更亲民的价格很有可能是对这个中低端的市场产生很大的影响。而外观的设计更加激进，设计感十足，所以要在续航里程、设计以及价格上做到平衡还真不是件容易的事情，但这台两年以后才能见面的车，你准备好开始预订了吗？
