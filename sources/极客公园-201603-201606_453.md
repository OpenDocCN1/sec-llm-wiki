# iPhone SE 体验：3000 元就能买到最快的智能手机？

今天是 iPhone SE 国行首发的日子，不过这次的 iPhone 首发和以往来的都不大一样，没有粉丝的彻夜排队，没有黄牛的满天回收，也没有媒体铺天盖地的报道。

iPhone SE 受到这样的「待遇」似乎也可以理解，从产品上看，iPhone SE 所有的功能和卖点没有一个是我们之前没见过的，上一次出现这样的情况还得追溯到 iPhone 5c，不过 iPhone 5c 好歹还有多彩的塑料后盖，而 iPhone SE 则连一个后盖都没舍得换。

不过就是这样一款可能是史上最「无聊」的 iPhone，却可能是近期最值得购买的智能手机。

********************“**********************外观几乎没有变化**

四四方方的外形、不突出的摄像头、顶部的电源键、「不修边幅」的屏幕黑边…… 这一系列 iPhone 5s 上就有的设计元素在 iPhone SE 上被一个不少地沿用了下来。

![](../Images/f994e42470d2f0e650aa36ab340f1a6c.png)*你能认出来哪一部是 iPhone SE 吗？*

iPhone SE 的重量为 113 克，机身厚度为 7.6 毫米，和 iPhone 5s 几乎完全一致。如果把 iPhone SE 和 iPhone 5s 放在一起，闭上眼睛估计没几个人能摸出来哪个是 iPhone SE。

不过仔细观察的话，iPhone SE 和 iPhone 5s 在细节上还是有些不同的。

![](../Images/7c7039a9689c1b0f98d0459db054abbe.png)*iPhone 5s （黑色）和 iPhone SE（银色）*

iPhone 5s 中框的上下两圈采用的是亮面金属倒角，这也是从 iPhone 5 开始就有的设计，在 iPhone SE 上，苹果把金属倒角换成了和边框部分相同磨砂材质，理论上会更加耐磨。

![](../Images/0625343e4bea7bc25328386611f0fb2a.png)

iPhone SE 背面的苹果 Logo 也使用了和 iPhone 6 / 6s 一样的镶嵌工艺，摸起来会更加立体。此外，iPhone SE 背面下部还多了一个「SE」标志。

![](../Images/a67f38d409a39614700aef718b6f242c.png)

当然，相比 iPhone 5s，iPhone SE 在外观上最直观的变化还是新增的玫瑰金配色，如果你想让自己的 iPhone SE 更容易被认出来，就果断买一台「粉色」的吧。

用惯了大屏手机后，再拿起 iPhone SE 这种 4 英寸的小屏手机，会多了一种久违的掌控感。不过更容易掌握并不代表手感更好，由于 iPhone SE 边缘过渡更加锋利，加上屏幕也没有使用 2.5D 弧面玻璃，**iPhone SE 的握持手感反而不如屏幕更大的 iPhone 6 / 6s**。

![](../Images/266fe4a57cec0f816964146b528f3156.png)

此外，iPhone SE 没有 Reachability 这种全屏下拉功能，如果你的手比较小，在不频繁变化手姿的情况下，iPhone SE 单手可操作的区域可能还不如 iPhone 6s 大。

********************“**********************同价位最优秀的摄像头**

iPhone SE 配备了一颗 1200 万像素的后置摄像头，单个像素尺寸为 1.22 微米，ƒ/2.2 光圈，支持相位对焦，不支持光学防抖。除了没使用圆形的「二合一」双色温闪光灯，**iPhone SE 的相机参数都和 iPhone 6s 完全一致。**

在拍照体验上，**iPhone SE 和比它贵 2000 元的 iPhone 6s 几乎没有区别**，优秀的启动速度，快速可靠的对焦，加上一流的「预对焦」系统，让 iPhone SE 的整体拍照体验非常愉悦。

![](../Images/968ffa046b863ec9bea2f981dbec7673.png)

![](../Images/54d23647d9b8a69aa3dd333daa12d106.png)*从左至右分别由 iPhone SE、iPhone 6s、三星 Galaxy S7 edge 拍摄*

在成像画质上，无论是照片观感还是 Exif 信息，iPhone SE 几乎都和 iPhone 6s 完全一致。相比三星 Galaxy S7 / S7 edge，在光照较为充足的情况下，三者的照片观感差距不大，只是在发色倾向上略有不同。不过在光线较暗时，两款 iPhone 则明显被三星拉开了一截。

在 3000-4000 价格段的手机中，iPhone SE 的拍摄表现可以算得上出类拔萃了。除了松下 CM1 （水货）这种「手机里的照相机」，在相机上能媲美 iPhone SE 的恐怕只有降价后的三星 Galaxy S6 了。

![](../Images/e0e79ad01880245e92450aab2886d252.png)

不过需要注意的是，**iPhone SE 的前置摄像头像素被缩水到了 120 万**（iPhone 6s 为 500万），光圈也仅有 ƒ/2.2（和 iPhone 5s 相同），好在还保留了 Retina Flash （闪光灯）功能。自拍时，屏幕可以通过短时间内大幅提高亮度来充当闪光灯的功能（如上图）。

由于配备了性能更强大的 A9 处理器，**iPhone SE 的前后摄像头都支持拍摄 Live Photos，**只是由于屏幕不支持 3D Touch，查看 Live Photos 的方式从用力点按屏幕变成了长按。

根据一些媒体的报道，有部分商家通过换壳把 iPhone 5s 「冒充」 iPhone SE 卖，大家可以**通过查看手机摄像头是否支持 Live Photos 和 Retina Flash，**来简单地判断自己购买的 iPhone SE 是否「货真价实」。

********************“**********************同价位最快的智能手机**

**iPhone SE 配备了和 iPhone 6s 相同的 A9 处理器**，主频从 iPhone 6s 的 1.85 GHz 小幅下降到 1.79 GHz，运行内存为 2GB。

无论是性能跑分还是实际体验中，iPhone SE 的表现都和 iPhone 6s 几乎完全一致，不仅比同价位的所有手机都快一截，即便是对比 Android 「机皇」三星 Galaxy S7 edge，iPhone SE 在大多数操作中也要更快。

![](../Images/5694e6d239a0abb87cf53c88f7d811ba.png)

略有遗憾的是，**iPhone SE 并没有使用 iPhone 6s 上的新一代指纹识别模块**。但有趣的是，在息屏状态时按下 Home 键后，iPhone SE 和 iPhone 6s 进入桌面所花的时间是几乎完全相同。不过在使用 iPhone 6s 时，按一下 Home 键然后立刻拿开，手机依然可以正常解锁，而在使用 iPhone SE 时，按下 Home 键后就必须要再停留一会才能正常解锁。也就是说，**虽然 iPhone SE 的指纹模组识别速度比 iPhone 6s 慢，但过渡动画将二者的实际解锁时间拉到了同一水准。**

******************“******************「超低价」的取舍

除了优秀的摄像头和出色的运行速度，iPhone SE 也保留了很多「iPhone 式」的优点，比如**靠谱的自动光线调节**（用过锤子 T1 的用户应该会深有感触）、**稳定的续航**、**出色的散热**以及**几乎不耗电的待机**，当然，还有**独此一家的 iOS**。

不过作为一款完善产品线的产品，iPhone SE 也没有解决 iPhone 的那些「顽疾」，比如**依旧不支持快充**（原装充电头依然为 5V、1A），屏幕素质不仅被三星 Galaxy S7 / S7 edge 等顶级 AMOLED 屏幕拉开了差距，对比同价位的国产手机，iPhone SE 的这块屏幕也占不到什么便宜（我们手上这台 iPhone SE 色温还有些偏暖）。

![](../Images/f806f6dab81fa9eb59e07172ea85c240.png)

同时，作为一款「入门级」产品，iPhone SE 在部分细节上也有所缩水，**比如没有气压计**，无法测量海拔，室内的 GPS 定位精度可能也会受到一些影响。iPhone 6s 附送的采用液态金属材质的取卡针，而在 iPhone SE 上直接被换成了一个做工有些粗糙的「曲别针」（如上图）。

![](../Images/a0174980837f3c9b226d79e440c9615c.png)

*在 3000-4000 这个价位上，iPhone SE 拥有最快的速度以及可能是最好的摄像头。**如果你想投入 i**Phone 阵营**但预算有限，iPhone SE 是有史以来性价比最高的选择，而如果你依然对 4 英寸的小屏手机心有执念，iPhone SE 是你唯一能买到的「小屏旗舰」**。*
