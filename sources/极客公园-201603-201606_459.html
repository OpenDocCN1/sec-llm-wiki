极客头条：年度盛会：微软 Build 2016 大会昨夜正式拉开帷幕！

来源：The Verge、腾讯科技

一年一度的微软 Build 大会终于在美国时间 3 月 30 日在旧金山来开了帷幕。作为微软全年最重要的大会之一，甚至没有之一，这场面向开发者的大会将会展示微软这一年在软件方面。这次的 Build 大会根据惯例还是开三天，通常第一天会关注在 Windows 上，另外两天则关注其他开发层面的问题。

在第一天的日程中，微软在 Windows、人工智能助手 Cortana 以及 HoloLens 方面都宣布了一些令人关注的消息。下面我们就为你介绍一下 Build 2016 大会第一天的一些重要新闻。

1. Win 10 将会在今年夏天迎来年度更新

首先，微软宣布 Win 10 中重要的 Microsoft Edge 浏览器将会支持 Windows Hello 功能，这意味着你将来可以使用面部识别技术来登录网站了。

第二，将 Xbox One 打造成为一个开发者的平台，将 Windows 10 中的 App 移植到 Xbox One 中。

第三，手写支持技术 Windows Ink，它将与 Edge 浏览器、地图以及 Office 办公组件一道整合入微软的诸多应用。借助这一技术，用户可以更加便捷地持手写笔在 Win 10 设备上书写、记录并进行便捷分享。

第四，个人语音助手 Cortana 升级，用户可以无须登录，直接在锁屏情况下启用。此外，开发者也可以全面调用 Cortana 的主动智能技术，使其应用可以基于用户使用场景执行操作。并且 Cortana 也将来到 Xbox Box 平台。

第五，通知栏的全新布局和功能，原有的单一通知消息，被更多色块表示的功能模块所代替，常用的软件可以在这里面直接调取对，用户来说这是非常方便的。

2. Linux 命令行工具来到 Windows

「Bash shell 也登陆 Windows 了」Bash（Bourne Again Shell）是 Linux 系统中使用的一种 Shell。它为用户提供了使用文本命令模式来实现各项功能（和/或使用脚本）。如果你不理解这些，你大概可以将其理解为 Windows 也支持 Linux 了，系统本地的 Ubuntu 可执行文件也能在 Windows 上运行了，而微软将会和 Canonical 公司一起来做这件事。

3. HoloLens 正式推出

Build 大会上，微软正式宣布 HoloLens 推出，微软强调「今天是我们正式跨越混合世界的梦想实现的一天，HoloLens 这一天在 Windows 平台上成为现实。」同时微软提供给开发者全套的开发套件，开发者能够利用套件进行应用开发。

在 HoloLens 推出的同时，微软宣布第一款官方发布的配套应用，Galaxy Explorer（星际探索）。在这款应用当中用户可以置身星际，探索与各个星球之间。

同时，微软也宣布 Hololens 将开始正式发货，第一批将只面向开发者和企业合作伙伴，售价为 3000 美元（约合人民币 19451 元）。

4. 新版 Skype 推出，内置 Cortana

早先提到的 Skype 新版本在本次 Build 大会上也得以亮相，新版本可以运行于桌面端/Win10 Moblie 端，且将包括 Skype 的绝大多数常用功能，包括群组聊天、一对一语音以及视频通话等等。同时，内置的 Cortana 能让你在使用 Skype 时更加智能、便利。

5. Universal Windows Platform

Universal Windows Platform（Windows 通用平台），这是一个开放的并且可以在所有不同的设备上运行的系统。微软为开发者们提供了许多便利的工具帮助他们使用这个系统，你将很快能看见一些重要的应用来到 Windows 10。

同时，更新系统后的 Xbox 将支持 UWP 应用，微软还未开发者打造了一套重制工具，可以将之前的一些游戏转制成 UWP 应用上架，在现场微软展示了重置后的《帝国时代 2》和《巫师 3》。未来 Steam 平台的游戏都可以通过该工具转制成 UWP 应用。

当然，这些都只是今天 Build 大会一部分的内容，我们也将在今天为你带来对 Build 2016 大会更详细的报道。

Google 推出 360° VR 内容

来源：TechCrunch

如何才能在 VR 设备中获得更真实的感觉呢？Google 觉得让用户获得 360° 全视角的内容是一个好办法。今天，他们宣布了一项新的举措：VR View，这是一个帮助开发者们轻松将 360° 视角的图片和视频内容嵌入到网站和本地应用中的工具，而用户们可以通过 Cardboard 来进行观看。同时，为了让这个技术更容易地被开发者使用，Google 今天也为 Cardboard SDK 加入了对 iOS 系统的支持。

iPhone SE 正式上市：3288 元 国行两版本

来源：凤凰科技

3 月 31 日，也就是今天，苹果全新 4 英寸新机 iPhone SE 将在苹果官网、京东、天猫等各大渠道正式发售，此前已经预定该机的用户，也将陆续收到这款小屏手机。预计今天极客公园也有可能收到这部新手机，届时我们会为大家带来相关的内容。
