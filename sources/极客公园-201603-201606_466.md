# 三星 S7 edge 体验报告 ：它的软件真有那么不堪？

** 三星 S7 edge 评测 **  ** 软件 **

**![](../Images/9661b9597534ff7f35065f36def93ef6.png)  
**

三星 S7 edge 是最近关注度极高的一款手机，很多科技媒体甚至为它打出了有史以来智能手机的最高评分。相信大家已经看了不少关于 S7 edge 的评测，细心的你应该在不同的文章中找到了相同的结论——「这是一款硬件惊艳但软件拖后腿的手机」。  

在使用了一段时间 S7 edge 后，我也得出了相似的结论。惊艳的曲面屏幕，不影响外观的防水设计和出色的拍照效果都让我很满意；但同时又觉得对于它的软件部分，绝对不能简单地用「拖后腿」几个字来概括，这其中还有很多值得讨论地方——至少要讲清楚是哪里「拖了后腿」。

![](../Images/5cd9417de17402a5546aa5ab6f44b481.png)

这篇文章的目的，就是与大家分享一些 S7 edge 软件层面（系统+app）的使用体验。从开机的设置到日常的使用，争取还原一个比较完整的 S7 edge 软件面貌。

在此之前如果你需要回顾一下 S7 edge 的评测，可以点击查看[极客公园之前的文章](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=404673519&idx=2&sn=131bc732fbc111623c8c0f10c152194b&scene=21#wechat_redirect)。另外还有两个前提需要说明一下：

1.  **我购买的是国行公开版的 S7 edge（SM-G9350），当前 Android 系统版本为 6.0.1，系统已安装最新更新。**
    
2.  **本文不涉及刷机和 Root 工作，尽管我也认可「不刷机玩 Android 有什么意思」的观念，但今天讨论的是更具代表性的「原始体验」。**
    
      
    
    ****************“****************系统：颇具「中国特色」
    

一直以来，大家已经习惯性去吐槽三星 TouchWiz UI 的「颜值」。审美这件事自然是因人而异，但我个人觉得基于 Andrdoid 6.0 的新版 TouchWiz UI 还是不错的（三星在宣传时似乎刻意淡化了 TouchWiz 的存在）。它遵循了不少 Material Design 的设计风格（据说是因为 Google 参与开发），整体色彩颇为鲜艳，设计也趋于扁平化。

国内很多 Andrdoid 用户都被定制系统「惯坏了」，不习惯于抽屉式的桌面排列。S7 Edge 在首次开机时就会引导用户选择不同的桌面排列方式。虽然描述文案有些拗口，但聊胜于无。

![](../Images/bc6fa831103651d2b115e7d5158025c7.png)*首次开机引导界面*

预装应用被大家所深恶痛绝，Marques Brownlee 在评测 Verizon 定制版 S7 edge 时发现它内置了十多个运营商「大礼包」， 甚至出现了两个邮件 app、两个照片 app、两个语音助手、三个音乐 app 同时存在的尴尬局面。

好消息是，「国行公开版」的 S7 edge 预装的只有微信、支付宝、百度地图和微博四款 app，以及一套微软的「办公大礼包」。这些恰巧是我常用的软件，所以并没有给我带来什么苦恼。

![](../Images/d470462de3b0019b49db699d7a717a50.png)*预装应用展示*

这次国行版的 S7 Edge 拥有「微信连 WiFi」和「S 漫游」两个专属功能。经过一次系统更新后，居然还出现了「快速抢红包」的开关。除此之外，还能见到颇具「中国特色」的智能管理器，文件夹显示中文注释和电话黄页等功能。资源类应用上，三星也选择和本土厂商进行合作：视频和爱奇艺合作；新闻与搜狐新闻进行合作等。

![](../Images/7fce7497147aa2ce2cfb8bc34eb82d4b.png)*一些本地化的设计*

这么说吧，但凡用过一段时间的国产定制系统，国行 S7 edge 所搭载的 TouchWiz UI 就不会给你带来任何陌生感。经过这么多年，三星早已深谙中国用户的使用习惯，这次国行系统的本地化工作还是可圈可点的。  

至于系统流畅度，初从 iPhone 换到  S7 Edge 时觉得主页面滑动没那么跟手。禁用了一些不常用的自启 app 后，开机内存只有 1.7 GB。我对于参数不是很敏感，不像很多玩家那样对每 MB 内存「锱铢必较」，考虑到这是一部 Android 手机……流畅度还是不错的。

****************“****************功能：可玩性很高

上面这些功能在其他定制系统上也能找到，但别忘了三星还有诸如提升安全性的 My Knox、[炫酷的 Samsung Pay ](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=404864283&idx=1&sn=388f797ba1a7ebc13863801543f032b8&scene=21#wechat_redirect)这些「独门绝技」。在可玩性上，S7 edge 也提供了很多可供探索的选项，Galaxy Labs 里也会不定时增加一些实验室功能。

![](../Images/b59d6a543204207fbba2981d60bc9c6e.png)*「高级功能」界面*

新增的「游戏工具」可以在游戏界面提供一个浮动按钮，点开可以看到截图、录屏的功能，我虽然不怎么在手机上玩游戏，但相信对于那些手游爱好者来说这个功能还是很受用的。  

![](../Images/0b7399667e6dda5cc1e2ac4fea0f28fd.png)*「游戏启动器」和「游戏工具」*

「浮动信息」和「S 助手」的晚间提醒则是我最喜欢的两个功能。「浮动信息」简单来说就是在收到新消息时不用打开 app 直接进行回复，目前支持微信和系统信息，在浏览网页或刷微博时可以避免频繁切换应用。「S 助手」在零点会推送一条包含明日天气、闹铃和免打扰设置的概览，让你安排好这些细节安心睡觉。

![](../Images/14386fa07f7b3ab41da06bf0121099c9.png)*「S 助手」和*「浮动信息」*界面*

就像你看到的这样，TouchWiz 的 UI 虽然称不上惊艳，但绝对不能再以「丑陋」和「简陋」来形容了。不要忘了它还有那么多「接地气」和「可定制」的功能，经过这么多版本的改进，我认为这次它已经进入定制系统的第一梯队。

下面就是令我不满意的地方了。

****************“****************侧边栏：还是以炫技为主

很多人都对 S7 edge 的曲面屏充满了「不切实际」的期待，但软件层面可能要让大家失望了。

目前曲面屏给 S7 edge 带来的更多是观感和手感的提升，甚至可以说是以炫技为主的，而「侧屏应用」与 S6 edge 相比并没有获得实质性的提升。S7 edge 的侧屏应用主要以快捷方式为主，例如快速打开某一 app、某一网络书签等，最多可以设置 9 条面板进行循环切换。

问题在于，这些快捷方式只能算是「锦上添花」的小功能，并不会让你使用手机的效率获得质的提升。用侧屏看新闻？连标题都被打散成三行显示的体验实在称不上出色。经过这段时间的使用，我能想起来的应用场景只有用侧屏呼出快速工具（尺子、罗盘和手电筒），因为暂时没有找到这些小工具的其他入口。

![](../Images/ed920c4690cd0acf93f70ab3e3644db5.png)*一些侧屏应用*

另外一方面，在三星应用商店里目前只能找到 12 款专属侧屏应用，其中还有 7 款是需要付费的，丰富程度还远远不够。

![](../Images/438fefa9c8adff896547aaf3f7cc42ca.png)*侧屏应用商店*

2014 年面市的 Note Edge 是三星第一款拥有侧屏的手机（第一款曲面屏手机则是 Round），它的侧屏较之 S6 edge /S7 edge 要宽很多，显示内容上也更da丰富和独立。 侧屏可以保持显示快捷方式，甚至拍照的时候需要通过侧屏上的按钮来控制。 Note Edge 是三星的「试水之作」，割裂的显示效果和误触的问题或许是这样的侧屏形态没有延续到 S7 edge 的原因。

![](../Images/45156543fe4bc6a8a4359cd6f1a45ee8.png)*Note Edge 的侧屏更宽*

进入 S6 edge /S7 edge 时代，可以看到三星降低了侧屏在操作和内容显示上的「权重」，它更像是原有屏幕的延伸，并在此基础上添加了一些小功能。因此未来对于侧屏功能的挖掘，最好不要期待过高，还是好好享受它带来的「丝滑」手感吧。

最严重的问题来了。

****************“****************应用市场：阿喀琉斯之踵

三星应用市场基本上是不可用的。

首先 app 数量不够，有些常用的检索不到；其次更新较慢，一些原生 app 的版本号甚至还没有第三方应用市场的高。尽管它接入了腾讯应用宝的部分资源，但安装一个第三方的应用市场仍然是必要的。

![](../Images/e0dc2568cfd07a58112a661913a90201.png)*同样的软件，第三方市场提示有更新*

这段时间我把主力机从 iPhone 换为 Andriod 后，最大的不适来自于它缺少一个规范的应用商店。下载应用时需要格外小心，还要时刻关注「软件权限」和「自启动」选项的状态。同时缺少优质应用的付费渠道也带来了「有钱花不出去」的局面。当 iOS 用户都在讨论 Day One 2 限免的消息，我也只能默默翻出 iPad 领了激活码。

当然这也是所有国行 Android 手机都会遇到的问题，但出现在这样一款旗舰产品上难免有些让人唏嘘。这种感觉就像结识一个外表很满意的姑娘，但接触后她的性格却让你打起了退堂鼓。

![](../Images/31a1dc13ddcfc63a577b1b71fce9a274.png)*到底让不让我用?*

在 Google Play Store 入华遥遥无期的情况下，选择一家靠谱的应用商店进行更加深入的合作或许是更好的选择。总结来说，国行 S7 edge 的软件体验绝对算不上「拖后腿」，大量本地化功能也可以看到三星的「用心良苦」。

如果你对于「墙外的世界」有着比较高的探索欲，还是放弃国行版本的 S7 edge 吧。否则，挑选一个靠谱的第三方应用商店，安装 app 时留个心眼，禁用不必要的软件，还是可以用得很顺手的。
