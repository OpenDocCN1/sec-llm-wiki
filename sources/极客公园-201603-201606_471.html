一加手机    氢 OS    线下活动 


曾经我们都觉得在手机行业不应该一直「小众」和「个性」，但慢慢的我们发现，那样的特别反而是珍贵的。

一加可能是这其中最坚定的品牌之一，在经历了 13 年的懵懂和 15 年的混战之后，他们依然选择了「个性鲜明」。这种态度沁入了他们的每一个产品，除了手机、OS，甚至还包括周边的背包和笔记本。

一加公司的气质往往来源于相似的一个人和一群人的组合。在产品上刘作虎保持着一贯的「龟毛」，而一个无法容忍平庸普通的老板之下的员工们，自然也都是天生乐于和自己较劲的。他们最终体现在了一加产品上的执着，体现在了每一个你看得到或是看不到的细节。

去年的一加完成了两件重要的事，一个经历是国产手机市场极其惨烈的战斗，另一个是发布了自己的氢 OS。前者让他们至今想来仍旧心有余悸，后者却让他们在紧张焦虑中其乐无穷。

氢 OS 完整了一加，但从前的氢 OS 是不完整的。这件事情在过去的大半年里折磨着一加，除了和时间赛跑，却还要时刻依从这家公司对产品偏执的态度。

但只有氢 OS 「成年」了，一加才能接着抬头去直面依然水深火热的 2016。

“氢 OS 的「第一次」

一家手机公司做自己的硬件之前，要先做自己的软件，这是一个被多次验证的道理。但一加在 2013 年进入这个行业的时候，并没有那么强的紧迫感。

首先，一加在当时的几个选择都是不错的。ColorOS 大而全，而且保持着国产定制系统里很高的稳定性，这对于一个新品牌的首款产品来说是很重要的。CM 有些极客范儿，能给用户极其接近原生安卓 AOSP 的体验，这是一加一代在海外市场最终收获巨大成功的重要原因。

同时，当时的国产安卓系统都还保留着通过大量适配抢地盘的幻想。一加最早期和 MIUI、Smartisan OS 都有接触，大家也都有过合作适配的意愿。但奈何市场严酷，大家很快就从 UI 和功能的比拼转战了服务和差异化功能，这让第三方适配反而不那么重要了。

「软硬结合」在一加着手准备自己第二代硬件产品的时候慢慢变成了一种强烈的需要，因为只有那样才能真正做到最优的体验。同时，一加和 CM 也终于和平分手，一个一加自己的 OS 变成了箭在弦上，不得不发。

开始一件新鲜的事是让人头疼的，氢 OS 从无到有的过程自然也无比艰辛。但对一加来说这好似重新生长一对翅膀，是成长的烦恼和甜蜜的负担。经过了大半年的招兵买马和闭关修炼，氢 OS 才终于在去年五月发布了。

有趣的是，在这个过程中刘作虎开始渐渐陷入其中不能自拔，一加的小伙伴形容他「喜欢钻研软件和交互多过硬件了，开始整天沉迷其中。」

“氢 OS 的「下一步」

一加总算是完整了。我们在氢 OS 上见到了那个熟悉的一加，从设计到交互再到功能模块，它是一个让人眼前一亮充满新奇感的安卓定制系统。它是一个颜值很高的 ROM，也包含了「氢视窗」、卡片式短信等创新又有趣的模块。

但氢 OS 还是「太年轻」。很多一加的用户在尝鲜的过程中慢慢发现，它身上还有着作为一款尚不足一年的年轻 OS 的小毛病和不完善。

比如系统应用功能模块的缺失。一加在氢 OS 发布之前主推了自家的天气应用，一个很好看很酷炫很特别的天气应用，它第一次在人们面前展示了一加软件上的功力。但一款应用的甜蜜期是有限的，一个天气应用给人带来的新鲜和愉悦也总有保质期。

再比如氢 OS 的稳定性还依然不够，有的时候你能感觉到一些卡顿，有的时候一些应用会闪退。系统优化是一个细致琐碎的工作，一些「加油」选择了耐心等待，还有一些「加油」开始有一点着急了。

作为一个新系统，这些都是绕不开的坎。而就像「加油」们认识的一样，一加在这个过程中依然时刻在和自己较劲。互联网品牌的标签也让一加从一开始就无处可躲，他们每天都会在自己的论坛接收大量的吐槽、需求和建议。

对一个靠自己执着的态度和追求吸引了大量粉丝的品牌来说，无论粉丝给予的是支持还是埋怨，他们永远是最宝贵的。

氢 OS 这个不够完善的过程，就是一加不断反思的过程。而除了修复用户反应的问题，满足一些普遍的需求之外，他们对一个手机的 OS 也有了自己新的理解。比如中国用户一些特色的需求如何进一步优雅高效的实现，再比如氢 OS 和氧 OS 在今后有没有变幻出新的形态的可能。

有了氢 OS，一加才能真正武装完备地迎接中国市场的挑战。而只有 氢 OS 真正成年，一加才能在今年这个更加激烈的竞争环境里稳步向前。在软硬件装备完全的时候，一加才能更加从容地发挥自己对用户体验的那种「个性」理解。

一加也知道，「加油」等了好久了，所以他们决定要在四月敞开「氢听」了。如果你对氢 OS 有自己的看法，有自己的建议或是有自己的期待，那 4 月 7 日你应该来北京听一听虎哥、氢 OS 主创团队和一些大家熟悉的一加老朋友怎么说，他们应该不会回避来自「加油」的任何一个问题。

「加油」们希望在氢 OS 成年之后一加能在 2016 年的路上走得更稳更快一些，而一加希望即便你「兜兜转转」一圈回来，一加还是你当初热爱的样子。

这一切首先从「氢听」开始。

 NOTICE 

一加科技对于产品细节和美的追求，不仅从他们的硬件产品上可以深刻感受，在他们自主研发的氢 OS 系统上也显露无疑。他们一直想要开创一些行业不一样的东西，于是有了基于 MD 的设计风格、有了拥有 33% 自由度的氢视窗、有了不一样的卡片式短信……而这一切的背后，正是他们为追求细节和美的不断较劲。

从去年 5 月 28 日发布，氢 OS 已在一步步成长，而关于成长背后的那些故事和历程，你又知道多少呢？ 未来它又将如何发展，你是否同样期待呢？听，它的故事即将在这里和你一一道来。
