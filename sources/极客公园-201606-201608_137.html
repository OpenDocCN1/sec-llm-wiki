文艺极客

第一次创业失败，张向东光喝酒就专心喝了半年。2007 年在尼斯海滩，这位陕西文艺中年终于破解了他的人生密码——自行车。那时他不过 30 岁，人生风景正好，还没到变臭的时候。

看照片和台风你就知道了，700bike 联合创始人张向东属于科技圈里身材比较好和穿衣服比较好看的。所以在本次奇点大会的舞台上，我们让他站着并问了好多问题。

如果你现在没有 Wi-Fi 的话，可以先看下水水的脱水版本 (｡･ω･)ﾉﾞ

G : 文艺青年做事太不靠谱了，比如做自行车、开咖啡馆什么的……

张向东 : 直到去年发了车，网上的很多评论都是不看好的。

自行车行业觉得我们想得太简单了；车友以为我们会做公路车、山地车，也会有点失望；更多人觉得，自行车？那不是 80 年代的东西吗！

但我觉得这些都不重要。我创业 3 次，稍微有点智力和总结能力的人，这些问题都该想过了。有了答案才做的。

G : 发车一周年，做车差不多两年，你对自己满意吗？

张向东 : 第一，把时间花在自己喜欢的事情上，是稳赚不赔的，你不会后悔。

第二，我对我们的产品、团队运营能力、模式、审美和品质的要求……哈哈哈非常非常满意。

G : 既然做车这么满意的话，如果不做自行车，你会做什么？A.洗脚店  B.包子铺  C.美甲店  D.陕西肉夹馍

张向东 : （搓手......）

G : 我们推荐陕西肉夹馍。（跟你的德州普通话很配）

张向东 : 长得就像兵马俑一样，还去做肉夹馍？（陕西旅游局出多少代言费我都不会去的）我选包子铺。

目前大量品牌都存在升级的机会。从做公司的角度讲，首先看产品存不存在创新机会点，以及模式能不能更高效，然后能不能长久地建立起品牌。再定义运营团队的衡量标准，针对性地做起来。

G : 所以你打算到底怎么做包子？

张向东 : 哈哈哈我对包子实在没什么研究。首先要做研究，然后在消费升级的趋势里，开辟一个新品类……这些在商业经典中都能找到，并不特别（反正都是套路）。

但是我不会选的，我做一件事是因为喜欢。

G : 如果让包子铺和 700bike 搞一个联合品牌活动呢？

张向东 : 虽然 700bike 现在做自行车，但我们希望它未来成长为一个生活方式品牌。本质来讲，任何好东西都是为生活所用的，包子也一样。

看看我们的 LOGO：早上 7 点骑着自行车出发，吃两个包子，开始简单的一天。

G : 为什么你的朋友圈天天都在发吃喝玩乐照？你不是创业者吗？（不是应该秀加班？）

张向东 : 人有点趣味很正常，没有趣味才让我觉得很纳闷呢。读一点点书，有一点小兴趣，非常平常啊，我不在乎别人叫我文艺不文艺。在消费升级的环境里，创始人没有趣味反而挺危险。

另外……我其实也加班的好吗！

G : 创业时是怎么跟团队说的？

张向东 : 做事情要看趋势，不要局限在事情里，不看大势。

第一，中国消费升级的时间来了，人们对品质感有要求；

第二，城市化过程中出行效率很有问题；

第三，中产阶级起来了，他们有审美趣味和精神层面的要求。

另外，还要看行业。

第一，出行领域，城市自行车这类产品是缺失的；

第二，自行车领域有体验的问题，而且很多年没有创新；

第三，渠道商、层层代理的商业模式很低效，所以这个行业有机会。 

G : 你的自行车太贵了。

张向东 : ......我们的自行车品质那么好。
