# 关于三星 Galaxy Note7，你只需要了解以下 10 点

从 2011 年推出第一代 Galaxy Note 开始，三星就开始在高端产品上使用「上半年 Galaxy S + 下半年 Galaxy Note」的「双旗舰」策略。  

相比 Galaxy S，Note 系列的屏幕会更大，配置也略高，但在刚刚发布的 Note7 上，Note 系列的地位却发生了明显的变化。

按照惯例，极客之选（微信公众号：GeekChoice）先带大家看看三星 Galaxy Note7（以下简称 Note7）有哪些值得关注的地方。

**1\. ****一个更加「对称」的 S7 edge**

从外观上看，三星 Note7 就像是 Note5 和 S7 edge 的结合体。

![](../Images/aa4db8ac7d7468e7c75b13ac83c43c98.png)

在机身整体的轮廓上，三星 Note7 和 Note5 基本保持一致，相比 S7 edge，Note7 的外观要更加方正和硬朗。

![](../Images/5f0be9b41fdc0e947295467fdb0c0461.png)*三星 Note5（左）和 Note7（右），来自 Phone Arena*

不过在屏幕上，Note7 采用了类似 S7 edge 的双曲面屏幕，并进行了进一步的「改良」。

![](../Images/52ac124e228fbf84c568ac78a880e491.png)

在 Note7 上，三星缩小了正面双曲面屏的弯曲程度，并增大了背面 3D 玻璃的弧度。**从侧面上看，Note7 金属边框两侧的两块 3D 玻璃在视觉上是几乎完全对称的（如上图）。**

另外，为了降低双面玻璃摔碎的风险，**Note7 的前后都使用了抗摔性更好的第 5 代康宁大猩猩玻璃**，而 Note7 也是目前唯一一款使用第 5 代大猩猩玻璃的手机。

**2\. ****虹膜识别很酷，但并没有指纹识别实用**

从功能上看，Note7 最大的变化应该就是加入虹膜（Iris）识别了。

它的原理是通过识别眼球的虹膜信息，来进行身份验证。在 Note7 之前，富士通 F-04G、微软 Lumia 950 / 950XL 等手机也搭载了虹膜识别功能，但由于产品销量有限，并没有引起太多的关注。

![](../Images/5e9045f3775c5fbfd9bcd8d754cfb46c.png)

在功能上看，Note7 的虹膜识别和指纹识别基本没什么区别，二者都可以用于解锁手机以及 Samsung Pay 支付。Note7 中还内置了一个叫做 Secure Folder 的功能（如上图），用户可以把不想让他人看见的 App 或者图片等内容放在这个文件夹中，然后选择使用虹膜、指纹或者传统的密码来加密。

![](../Images/53d58d2b12d631f1d4d3c5f6ed26f184.png)

但目前看来，Note7 的虹膜解锁过程有些太复杂。**用户需要先点亮屏幕，然后在锁屏界面上滑，才能进入虹膜识别的界面，没有指纹识别那样来得一气呵成**，此外，目前 Note7 的虹膜识别只能记录一组虹膜信息。  

根据 Mr Mobile 等外媒的测试，虽然 Note7 的虹膜识别速度的确很快，但由于多了几个步骤，虹膜识别并没有指纹识别的效率高，不过在某些特殊场景下，比如手指上沾上了水，指纹识别无法识别，这时候虹膜识别的确会更加方便。

![](../Images/d9dfe77c6402553fcc49f6a6645597b5.png)*图片来自 The Verge*

值得一提的是，三星 Note7 并没与因为增加虹膜识别而让手机「前脸」更加臃肿。**Note7 的正面这次「仅」有 3 个开孔，用于虹膜识别和前置摄像头，光线和距离感应器以及 LED 指示灯都采用了隐藏式设计**。另外，虽然这三个孔的大小依然不一样，不过这次总算放在一条直线上了。

**3\. ****功能更丰富的 S Pen**

和往年一样，不管你用不用，在每年的新款 Galaxy Note 上，三星都会对 S Pen 进行升级。

![](../Images/2f7c61af996d48d368664ca03f601e3f.png)

Note7 的笔尖直径从之前的 0.7 毫米增加到了 1.6 毫米，压感级别提高到了 4096 级。三星表示，「这可以让 Note7 的 S Pen 在使用时更加稳定和流畅。」

在功能上，除了可以像 Note5 那样，直接在熄屏状态下拿出笔来写东西之外，在 Note7 上，写完后还可以直接把内容放在锁屏上，作为「Always-On Display」的一部分。

![](../Images/7a57e487056fba6ff1da5892bf668bd6.png)

这个功能还是有很多的应用场景的，比如说你突然想起来今天下午要去机场接人或者去买某个重要物品，就可以直接随手拿起笔记录下来，每次看手机时都可以看到提醒。

Note7 的 S Pen 还增加了一个制作 GIF 动画的功能，用户可以直接使用 S Pen 在正在播放的视频或者手机录制的视频中截取一段最长 15 秒的内容，Note7 会自动生成一段 GIF 动图。

另外，用户还可以直接使用 S Pen 来选择文本甚至带有文字的图片，Note7 可以进行即时的翻译。

![](../Images/fcf75e19df99039c364a32df36b4fb0f.png)

值得一提的是，和 Note7 一样，Note7 上的这根 S Pen 也支持 IP68 级别的防尘防水。更神奇的是，S Pen 在水下是可以正常工作的，用户可以一边拿着 Note7「潜水」，一般用 S Pen 操作。（实在想不出应用场景……）

![](../Images/b2e0ec3d39d92dea0dcaedff2b2f1f15.png)

对了，Note 7 的 S Pen 倒着插不进去了，不用担心像 Note5 那样，不小心把笔「倒插」进去，然后就拔不出来了……

**4\. ****性能不太够「旗舰」**

照理说，对于 Galaxy Note 这样的旗舰产品，我们通常都可以用一句「旗舰级」来一笔带过，但 Note7 并不完全是这样。

根据地区的不同，Note7 的 SoC 有骁龙 820 或者猎户座 8890 两种可选，和 S7 edge 完全一样。**至于高通的最新旗舰骁龙 821，不出意外的话，会在本月发布的小米 note2 上首发。**

值得注意的是，在存储容量上，Note7 直接标配了 64GB 的内置存储，并且支持最高 256GB 的 Micro SD 卡拓展（会占用一个 SIM 卡槽）。

**但有些意外的是，**作******为三星多年以来真正的「年度旗舰」，Note7「仅」配备了 4GB 的运行内存**。

根据一些爆料，之所以没用上 6GB 运存，是因为猎户座 8890 的设计缺陷导致它无法兼容三星自家的单颗 6GB LPDDR4 内存，虽然高通骁龙 820 是可以兼容这颗内存，但为了保证两种 SoC 的「一致性」，Note7 不得不「委身」4GB 运行内存。

在我们长期使用 S7 edge 过程中，虽然 4GB 运存在多数时候也够用了，但 6GB 的运存还是可以带来更优秀的多任务体验，尤其是对于内存管理上一向不太靠谱的三星，6GB 运存还是有一定意义的。

**5\. ****和 S7 / S7 edge 完全一样的相机**

发布会上，三星明确表示，「Note7 的相机模块和 S7 / S7 edge 完全相同。」

![](../Images/5d43681d04ea394fc6cf09558f98ed7e.png)

从参数上看，Note7 依旧是「前置 500 万像素 + 后置 1300 万像素」，没有前置补光灯。后置摄像头拥有 f/1.7 的大光圈，支持光学防抖，双域像素技术也得到了保留。

**考虑到 S7 / S7 edge 在拍照体验上极为优秀的体验，Note7 照搬下来也没有任何的不妥。**

目前看来，即使在 S7 / S7 edge 发布半年后，依然无法在市场上找到可以在拍照体验和成像画质上优于它们的产品，特别是在对焦表现上，S7 / S7 edge 的表现依旧是「bug」级别，目前还没有任何一款手机可与之媲美。

**6\. ****电池容量比 S7 edge 小**

Note7 的电池容量为 3500 毫安时，虽然这已经是历代 Note 中最大的了，不过依然略小于 S7 edge 的 3600 毫安时。

之所以比 S7 edge 的电池小，一个重要原因是 Note7 的 S Pen 需要占据机身内部的大量空间，加上 Note7 的整机尺寸仅仅略大于 S7 edge，电池容量少一点也就不足为奇了。

不过放在旗舰手机中，Note7 的电池依然算是比较大的，根据我们在 S7 edge 上的经验，Note7 的续航应该足以满足大多数用户一整天的重度使用。

另外，和前几代 Galaxy 旗舰一样，**Note7 也支持高通的 QC 快充以及无线快速充电。**在 Note7 上，三星还把「古老」的 Micro USB 接口换成了 USB Type-C，作为「补偿」，三星会在每一步 Note7 中附送一个 Micro USB 转 USB Type-C 的转接头，以保证用户手里的 Micro USB 线不至于被直接淘汰。

**7\. ****更加「年轻」的 TouchWiz**

Note7 搭载了新版的 TouchWiz，整体的配色变得更加年轻。

![](../Images/680370d97f4f50efc6bb7df109776ad1.png)

在这个版本的 TouchWiz 中，自带的图标都采用「大圆角矩形」外形，第三方的 App 图标也会被「强行」拉成这个形状，至于喜不喜欢这种「强行一致」的图标，大家就见仁见智了。

![](../Images/1cfacff10039603b637c635400b2cc4f.png)

另外，在通知中心、设置菜单等位置，Note7 上的新版 TouchWiz 也发生了明显的变化。比如在设置菜单中，原本很长的选项菜单被归成了几个大类。

其实早在今年 6 月份，三星就在 Note5 用户对这套全新的 UI 进行了内测，大家如果手头上有 Note5，可以先刷上体验一下。

**8\. ****无线防水电池背盖**

在发布会上，三星还发布了一款颇为有趣的配件——Portable Power 电池背盖。

![](../Images/6a2045c9bc9273b08c71847b3532c0d8.png)

它的厚度为 8 毫米，内置了 3100 毫安时的电池，由于 Note7 支持无线充电，这个电池背盖直接可以通过无线的方式来给 Note7 充电。三星表示，Portable Power 电池背盖可以「至少为 Note7 充 50% 的电」。

值得一提的是，由于使用了无线充电方式，这个电池背盖是可以防水的。Note7 没电时，可以直接给它扣上这个电池后盖然后接着下水。（虽然不知道为啥要这样做……）

**9\. ****新版 Gear VR**

除了 Note7，三星还发布了新版的 Gear VR 头盔，配色从之前的黑白换成了全黑色。

![](../Images/8f7c9824e8523bc23d6ee47d792f0154.png)

为了兼容 Note7，新版 Gear VR 换用了 USB Type-C 接口，不过可以通过转换头来向下兼容之前的 Galaxy S / Note 手机。此外，通过调整镜片接口等方式，新版 Gear VR 的视场角（FOV）提高到了 101 度，触控操作区域也进行了一些改良。

关于新版 Gear VR 的详细报道，大家可以查看极客公园的 VR/AR 频道「 90 赫兹」的相关报道。

**10\. ****四种配色，价格未知**

除了常规的黑、银、金，Note7 还增加了一种珊瑚蓝的配色，加上之前已经推出的蓝色版荣耀 8 和有可能推出蓝色 iPhone 7，蓝色大有在今年下半年的智能机上流行起来的势头。

![](../Images/446255b19a5fea9fc0a0fdeb893bea68.png)

Note7 将于 8 月 19 日在美国等部分地区发售，同时上市的还有 Gear VR 和 Gear 360，不过三星并没有公布 Note7 的售价，不过意外的话，Note7 的售价应该会略高于 S7 edge，Note7 上市后，三星有可能会适当调低 S7 edge 的售价。

**![](../Images/e9f3ca07ecda99aa38624cb03e88beb6.png)**

**在去年初推出的 S6 edge 上，三星第一次使用了双曲面屏幕，这本是三星一款「试探性」的产品，但却出乎意料地取得了巨大的成功。**

**一年之后，在 S7 / S7 edge 这代产品上，配备双曲面屏的 S7 edge 受到了更多的重视。而在今年下半年的 Note7 上，「双曲面」终于「修成正果」，取代平面屏幕，成为了三星 Note 系列旗舰的唯一选择。**

**但同时使用双曲面屏幕，也让三星的 Galaxy Note 系列和 Galaxy S 系列变得前所未有的接近，从很多方面看，Galaxy Note7 就像是 Galaxy S7 edge 的「S Pen 版」。**

**而这或许恰恰就是 Note7 的使命，它不是用来取代 S7 edge 的，而是给那些想要双曲面屏但又需要 S Pen 的用户，提供一个更好的选择。**
