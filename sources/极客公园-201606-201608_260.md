提起 Tesla 似乎所有和这个名字相关的东西都会闪着光，即使前段时间因为两次意外事故而让 Tesla 和他的自动驾驶技术蒙上了一层灰，但归根结底 Tesla 还是一家让人一听到就仿佛触碰到未来的公司。

关于 Tesla 人们更多的想起的是埃隆·马斯克，毕竟这是一个太过传奇的人，但正如比尔·盖茨和保罗·艾伦、盛田昭夫和井深大一样，每个伟大公司创办者的身后都会有个忠实而内敛的技术操盘手，马斯克当然也不列外。那位马斯克身后的人就是特斯拉的 CTO——斯特劳贝尔（J.B. Straubel），今天他来到了极客公园 2016 奇点创新者峰会的现场，和我们聊了聊关于电动车革命和人类的未来。

********************************************************************“**********************************************************************马斯克电动车梦的开启者**

作为特斯拉的 CTO，斯特劳贝尔一直负责车辆的技术和工程设计工作，他主要关注电池、发动机、电能系统以及高层级的软件子系统。同时，他还负责 Tesla 所有的新技术的评估、研究、开发、软件、电子系统以及推进装置的相关工作。

马斯克在最初通过把 PayPal 卖给 eBay 成为了千万富翁后，一直藏在心底的电动汽车火种开始不再安分。在宾夕法尼亚大学就读期间，马斯克就曾设想过一种用于电动汽车的「超级电容器」，并完成了相关论文。但直到遇到了斯特劳贝尔，马斯克才真正触摸到这扇通往新世界的大门。

![](../Images/8a9c99fe94e99b527e10467d95abbc81.png)*斯特劳贝尔*

斯特劳贝尔在和极客公园创始人张鹏的对话中说到「彼时看到有这样一位领袖，有如此坚定的决心，要把他的全身心投入到这样一个初创公司，没有别的人可以像他一样做到这一点」，马斯克比任何人都要相信这个技术，哪怕在当时看来成功的几率并没有这么大，但是马斯克和斯特劳贝尔仍然认为这一切值得一试。

********************************************************************“********************************************************************特斯拉的伟大使命

对于特斯拉来说所关注的问题是什么？即：交通和能源的可持续性。找到这样的技术，用科技的方式减少交通能耗对于环境的影响，以及所有的能源使用等对于气侯的影响。这件事意义非凡，这是个大问题，同时也是大的机会。这是把双刃剑，一方面要不断的投钱，伴随而来的它也很有可能会带来巨大的回报。斯特劳贝尔认为技术应该和可持续性进行融合，只有这样才能够创造极佳的创业机会和业务机会。

现在全世界的二氧化碳的浓度已经达到 40 万的单位浓度，而这一切带来的无疑又是全球变暖在近几年来的指数级恶化。所以对于我们未来一百年以后来说，这不仅仅我们要去解决好大气中累计的二氧化碳的存储量，可能需要更长的时间去清理、需要技术的推动，这不可能一夜之间把所有的二氧化碳排放事情解决。特斯拉希望能够用一种更具有可持续性的方式产生能源、消耗能源，同时解决现在二氧化碳的排放问题。

特斯拉希望解决这些问题，能够为人类的未来做些什么。「我们公司的同事深信我们的使命，而且相信我们可以在这样的环境之下能够做出创新，做出好的产品」，当坚信自己所做的一切具有非凡意义的时候，这种信念能帮助你度过那些困难时刻。

********************************************************************“********************************************************************Tesla 对新能源的饥渴

「如果我们要让电动汽车更加普及，那我们要做的最重要的事就是去降低能量存储的成本。加入了可再生能源之后，我可以更加关注整体的经济状况，我们不再需要化石燃料，也不需要再为这些付出更大的代价。」

想要改变世界特斯拉需要更多更便宜的电池，斯特劳贝尔和他的团队需要去将电池组的的成本降低至少 1/3，而最好的办法就是去制造自己的电池，于是特斯拉和松下公司 50 亿美元在内华达的沙漠里建起了一座超级工厂——Gigafactory，并且在未来还要建造 100 个。

![](../Images/a4710262f389a75f3d620c070147ac86.png)*近期曝光的一组「超级工厂」照片，白色屋顶上还将覆盖太阳能面板*  

斯特劳贝尔是一位对于能源生成和储存领域情有独钟的人，他在斯坦福大学获得了能源系统工程的学士学位，并在之后又获得了能源工程的硕士学位。当回到特斯拉的使命，回到能量产生的根源，特斯拉想改变这样的情况。不仅仅给消费者销售电动汽车，而是更多的去利用一些新技术、产生新的可再生能源。所以现在特斯拉在可再生能源领域有着这么多投资，Powerwall 和 Powerpacpk 正是其中的代表。

现在我们对化石能源的需要非常非常大量，但是其实只需要一小块地方的太阳能，就可以解决 100% 的化石燃料需求。

********************************************************************“**********************************************************************不断从零开始，从 Model S 到 Model 3**

特斯拉毫无争议是这个时代最伟大的「颠覆式公司」之一，但这种颠覆性有时候也可能带来是消极、负面的影响，因为颠覆很可能会让人陷入一种打破一切、不顾一切的癫狂。找到正确的方式，提出挑战性的问题，从特定的切入点下手能够让「创新」真正实现其价值。

特斯拉具有这样的企业气质和文化，正如他们的第一个产品——「电动敞蓬跑车」，打破人们对电动车外观太丑、性能不好、储物功能太弱等固有印象。让人们相信新的技术真的会比旧技术要好，不仅仅只是替代了旧技术，更多的是完全颠覆以及性能上的提升。

在之后的 Model S 则又从零开始创新，Model S 之前没有人知道这样的一辆车该怎么去造，但这也是能够让特斯拉完全开放灵活性的关键，Model S 的电池组完全覆盖了传统汽车的底座，整个电池组就像是底盘的一块电池板一样，通过这样的设计让底盘非常低、且重心分配非常好，再之后的 Model X 则又在 SUV 领域带来了前所未有的冲击，而到了今天的 Model 3 则肩负了更多使命。

Model 3 拥有特斯拉的第三代技术，把所有的核心部件和核心技术都结合了起来。特别是电池架构，电池单元、电动机等。非常辛苦地去降低成本，保持它的能源效率，同时保证它的性能。Model 3 所有的技术使得它的价格降到 35000 美元，仍然保持了特斯拉独特的造型设计和续航里程。

![](../Images/d07c8480abc2bfe7ebdbf7497c973577.png)

「让电动车从简单的加速过渡到可持续的交通非常重要，这对世界的未来非常重要。」这是马斯克曾说过的话，而在发布的一系列高端的 Roadster、Model S 及 Model X，Model 3 无异是完成马斯克夙愿的最好契机。

简而言之，特斯拉的总体规划就是：通过先打造跑车，然后用卖跑车赚到的钱去生产大众消费级汽车，然后再用赚到的钱去生产更多的大众消费级汽车。Model S 和 Model X 都为 Model 3 的开发买了单，而对马斯克来说，Tesla 的未来在某种程度上就要看 Model 3 的表现了。马斯克在 Model 3 上投注了数十亿美元，他需要从中看到未来和希望，不过好在 Model 3 的表现以非常成功，全球已经有超过 30 万辆的订单。

********************************************************************“**********************************************************************未来技术和自动驾驶**

在斯特劳贝尔演讲后与极客公园创始人张鹏的对话中，他们也说到了未来十年特斯拉的技术趋势和可能性。斯特劳贝尔表示电池技术仍然是其中之一，这是在成本和性能之间最重要的一个技术。「化学」、「机械工程」，还有「电气工程技术」以及「电机驱动」也是另一个技术，因为现在电动汽车中，能量从电池向电机的转移，以及后来的电池、电能的回收过程，这些部件成本下降的速度都需要比大家预期的更快。

![](../Images/0d7d5e9c8d1980b2236fc9def4c47bf2.png)*极客公园创始人 张鹏 和 特斯拉 CTO 斯特劳贝尔*

而且「汽车电子」将会是下一个特斯拉集中关注的领域，有越来越多的模块控制头灯、控制车门、车窗。汽车的头灯是一个值得去改进的一个部件，通过电脑雷达可以很好的去改进它，特斯拉希望去创造一些新的基础设施改变车上的架构。

而关于自动驾驶斯特劳贝尔也表述了自己的看法，自动驾驶在有些情况下的确是有不可替代的作用，而且现在的电脑系统变得越来越智能，传感器变得越来越敏感。从将来来看，汽车一定会不可避免的变得越来越智能，最后会变得「无人化」、「自动化」。

斯特劳贝尔表示「我们认为竞争是促使创新出现的动力，而不是恐惧和害怕自己『落后了』」，因为有这样的竞争，让大家愿意使用资金把世界变得更有效率、更加的清洁，才把这些新技术更快地带给世界。创新是一种自发的必要需求，而不是因为「恐惧」或「规章制度」的要求。
