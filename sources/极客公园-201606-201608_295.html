 智能聊天机器人


“智能聊天机器人的未来

在今年 3 月份的时候，我们为您报道了微软 Build 2016 开发者大会。虽然纳德拉上台之后提出的「移动为先云为先」的策略已经众人皆知，但对于普通的 C 端用户来说，我们直接感受到的还是 Win 10 这样的产品。

然而，在那次大会上，我们却发现，就 C 端来说，Win 10 是微软的现在，但 AI 机器人才是微软的未来。

事实上，如果大家对此有所关注，那你可能会记得一件事：微软在年初的时候推出了其新版智能聊天机器人 Tay，结果却在 24 小时内被 Twitter 上的用户们给「教坏了」，变成了一个种族主义者。这件事就发生在 Build 大会前几天。但在几天之后，纳德拉仍然站在台上，面对全世界的用户说出了这样的话：「在未来，人类的语言将会成为新的 UI，机器人将会成为新的应用程序，而数字助手将会成为新的『元应用』（Meta Apps）或者就像是新的浏览器。」这意味着，在微软看来，在图像界面之后，我们将会进入一个声音交互的时代。

当时，他们用自己家的产品 Skype 做了一个具体的展示。微软在 Skype 中内置了更聪明的 Cortana，你能在与 Cortana 的对话中让它帮你订机票、计划行程、购物等等，总之，就像 Skype 产品经理 Lilian Rincon 所说，这种感觉就像是「Cortana 在和一个第三方机器人协商一样。」

而上周末，他们对自己的这个平台进行了更新。这不仅是这三个月以来他们第一次对这个平台进行的更新活动，也是继上周 Facebook Messenger 聊天机器人平台更新之后这个领域内的又一大动作。然而，事实证明，微软和 Facebook 不仅在时间点上踩得差不多，连具体产品的内容也变得越来越像了。

“更新的 Skype 机器人平台

首先，Skype 今天在自己的官方博客上公布了自己的机器人平台更新的内容。在具体的更新内容之外，他们透露自从这个平台上线以来，已经有超过 3 万名的开发者们在上面构建了自己的聊天机器人；作为对比，注册了 Facebook Wit.ai 机器人引擎的开发者的数量是 23000 人。应该说，二者基本处于同一水准。

而这次更新的内容主要有以下几个方面：

  • 支持群组聊天：在之前的版本中，你无法在群聊中使用聊天机器人；但现在，如果你暂时不想管这方面的事，那你可以让机器人替你先撑一会儿。


  • 卡片式回复：现在，你在 Skype 中同一些商业服务进行对话时，他们可以用多种卡片形式的内容回复你了，比如下面这几种模式。这样的回复方式可以使用户更明了地进行选择。



  • 使用 Skype 账号登录第三方应用：当你在 Skype 中与第三方应用沟通时，如果你想进行更深层的处理，你经常需要登录那些第三方应用的账号。不过现在，直接使用 Skype 的账号就能完成这一切了。


此外，微软也将自己的 Microsoft Bot Framework（微软机器人框架）与 Skype 的机器人平台放进了同一个环境中去，这样你就可以更轻松地开发自己的 Skype 聊天机器人了。同时，这个机器人框架现在还支持很多 Slack 与 Facebook 的相关功能。正在变得越来越强大。

目前，微软的这个机器人框架可以让开发者们在 Office 365 mail、Skype、Slack、Kik 及 Telegram 等多个应用中开发自己的聊天机器人，而他们在未来将会把这个范围扩展得更大。

“微软和 Facebook 正走在同一条路上

不过，如果你看了上周我们发的有关 Facebook Messenger 的文章，那你可能会注意到一个现象，那就是：在智能聊天机器人这个问题上，微软和 Facebook 正在变得越来越像。事实上，他们也正走在相似的一条道路上。

打开他们两个的界面，你会看到很多相似的界面，比如下面这两个第三方咨询的卡片式回复界面，如果我不说，你很难分辨他们。

而第三方账户的连接也是双方在这次都做了的改进，这意味着他们都意识到，在目前智能化聊天功能还不够完善的情况下，只有为用户提供更好地第三方的服务内容，才能尽可能留下那为数不多的用户。

同时，在目前的这个阶段，他们也都将工作的重心放在了开发者身上。目前 Facebook Messenger 平台上的机器人数量已经达到了 11000 个；微软虽然还没公布，但估计也不会相差很大。对于此类平台来说，只有越来越多、越来越好的服务才能让用户意识到他们需要这种新的交互方式，而开发者们才是完成这个目标的人，而非微软或 Facebook 自己。

因此，我们能看到他们在各种的版本更新中都在持续对开发者们释放利好消息，效果也还不错，至少相比用户，开发者们对这些智能聊天机器人平台的兴趣大多了。

正如 BI 之前一篇采访微软的文章中所提到的这段话一样：

「机器人不只是一个能给你带来新奇的事物，当然它也能满足你这方面的需求；机器人真正的未来是成为你电脑与智能手机的界面，帮助你订机票、发短信、做一切你现在需要用鼠标或是手指才能做到的事。微软相信我们的世界将很快会脱离现在由 Google 和苹果统治的 App 世界，这个世界将会变成与机器人对话的世界。」

而这也是我的想法。
