# 为了「照顾」国内用户，三星的 C 系列手机确实动了些小心思

有这么一种类型的手机，它们的配置在「参数党」眼里不值一提，也绝对不会进入「最具性价比的 X 款手机」这样的榜单。但它们在线下往往有着比较广的受众，销量也非常可观。  

OPPO 和 vivo 的一些产品就极具代表性，这种类型的手机往往有着下面的「气质」：

> *   轻薄的外观
>     
> *   一两个主打的卖点
>     
> *   拿得出手的拍照
>     
> *   够用的性能
>     
> *   适中的价格（2000 ~ 3000 元左右）
>     

几个看似普通的元素组合起来，再加上强大的营销攻势，一款「线下热销」的机型就诞生了。

国内的「互联网手机」早已认识到了线下渠道的潜力，国际手机品牌显然也深谙此道。上个月，三星发布了全新的 C 系列手机就很符合上面说到的「气质」。C 系列包括 C5 和 C7 两款，区别在于屏幕大小和处理器略有不同，售价为 2199 元起。

![](../Images/9d8e40534e3f855787af409f5847ad8c.png)

在最近使用了一段时间的 C5 后，我深刻觉得这是一部「非典型」的三星手机。从 C5 上能够见到很多「照顾」国内用户的小心思，以及一些熟悉的国产手机元素。

****************************************************************“******************************************************************外观：符合「主流审美」**

C5 的屏幕为 5.2 英寸，C7 为 5.7 英寸。两者均采用了 1080p 分辨率的 Super AMOLED 屏幕，覆盖 2.5D 的弧面玻璃。C5 的边框和屏幕内黑边（BM 区域）都很窄，不过三星并没有像国产厂商一样将其作为卖点「大肆宣传」。

从正面看起来，C5 和其他的三星手机并没有太大区别：位于听筒下方的 SAMSUNG 标志、椭圆 Home 键等都是熟悉的元素。不过有一个细节值得注意，C5 将距离传感器和环境光传感器「箍」在了一个开孔内，与前置摄像头沿听筒对称排列，看起来更加简洁——不得不说，国内用户对于手机额头上的开孔有些「过分在意」，C5 的这个改变还是很讨巧的。

![](../Images/0eb5e447ee97f3bd03baddda16311a1b.png)*最右为 C5，注意听筒旁边的开孔*

C5 的背部采用了全金属的设计，为了保证信号强度上下用两条天线带隔开，补光灯和后置摄像头「规矩」地排列在一条水平线上。这样的设计在三星的产品序列里几乎没有，但已经被很多国产手机证明是非常受欢迎的。

![](../Images/742841dd5cfea6bd2ab0296001b67bda.png)

C5 整体的做工还不错，尤其是值得一提的手感。C5 的金属部分并不是完全的弧线过度，而是进行了侧边棱线的处理，加上 6.7mm 的厚度和喷砂处理（0.45μm）让它拿在手里还是非常想「把玩下去」的。

![](../Images/4c9bd6d60a69b3b2847ecddf378c6139.png)*图片来源于 C5 官网，注意边框部分的处理*

可惜的是，C5 正反两面由于材质不同，「金色」呈现起来有一定的色差，强迫症患者可能会比较纠结。  

![](../Images/c215c2f7d9614946515696bea564579b.png)

C5 的设计语言和目前在售的其他三星手机有所区别，但选择这样符合「主流审美」的外观显然是比较务实的，而出色的手感所带来的「第一印象」对于线下渠道来说显然也是非常重要的——对于三星店面的导购来说， 至少外观上 C5 是不难「推销」出去的。

****************************************************************“******************************************************************系统：颇有心意的小改变**

在之前的三星 S7 edge 的软件体验报告中，我认为目前三星国行版系统除了不靠谱的应用商店，整体上还是很「良心」的：预装软件少、易用性很强，还有很多本地化的设计。

好消息是，C5 的系统延续了这些优势。举例来说，C5 的第三方预装软件由四个减少到了只剩微信、支付宝两个，甚至连系统自带的计算器、备忘录等软件都能卸载。

**![](../Images/c279a06141b69a1f73c793f803c323bb.png)***C5 预装应用列表*

在我体验 C5 的这段时间，获得了多次 OTA 升级，最新的系统更新日期为 6 月 22 日，Android 版本号为 6.0.1。以下系统部分的体验都是基于这个环境进行的。

在 C5 的发布会上，三星着重介绍了「智能管理器」、「S 助手」、「红包提醒」、「游戏中心」、「三星安全空间」等本地化的功能。其实这些功能在 S7/S7 edge 时代就有了，C5 很好的承袭了下来，并进行了一些微调。

例如在「智能管理器」内，C5 的版本采用了全新设计的界面，并且提高了「一键优化」的权重，更符合大家对于 XX 管家的使用习惯。

![](../Images/bdd518563cde37099d4b917f6776efa6.png)*相同的「智能管理器」，左为 S7 edge 界面，右为 C5 界面*

除此之外，C5 还带来的一些新特性。首先是一个名为「 U 品原音」的功能，三星官方介绍说「这是一种高清音频还原技术，可对在线及本地音乐进行实时的修复还原。」打开后，能够明显感觉音频的声场扩大了一些，听起来会更有「气势」。如果你不满足于这种「一站式」的解决方案，还可以通过一个名为「Adapt Sound 」的功能单独测试左右耳的听力来定制最合适的音效方案。

![](../Images/2215afebe5d38136999eeb469d3209b0.png)

这次 C5 拥有「枫叶金」、「蔷薇粉」、「皓洁银」和「烟雨灰」四个颜色，随之而来的还有统一配色的定制主题。可惜的是，这种统一的感觉只限于自带的应用，并没有覆盖第三方应用，会带来一些割裂感。

![](../Images/b778b556132d8e332917c5aa5a9f0e49.png)*默认主题下，被「打回原形」的第三方应用*

C5 锁屏界面的通知也发生了一些改变，由之前的「横条」变为更为简洁的「圆形图标」，代价是牺牲了一些所能呈现的信息点。C5 还增加了收音机的功能，需要注意的是它需要连接耳机作为天线，所以并不是常见的「网络收音机」。

![](../Images/e5911d1c587e2bcd6eb89c08cd41afc6.png)*C5 的锁屏通知更为简洁*

C5 还有一个新功能是「社交相机」，可以在拍照时实时加上各种滤镜（节日、时间、旅行等 7 个类别共 50 多款滤镜），省掉了后期的 PS 过程。  

![](../Images/4c59c8086785974272e0fa0727a062bd.png)

还有一个好消息，C5 支持 Samsung Pay 服务，拥有和 Apple Pay 类似的 NFC 支付方案，还增加了支付宝的快捷支付。不过，C5 并不支持 MST（磁力安全传输）方案，因此不能在非 NFC 的 POS 上「耍帅」了。

![](../Images/725876118a136a1a3eead7128a1fa8ed.png)

C5 保留了很多 S7/S7 edge 时代就有的本地化功能，还带来国内用户颇为在意的「音乐」、「相机」和「主题」等方面的新特性。不得不说在系统方面，三星还是深谙国内用户使用习惯的。

****************“******************另一种「秀肌肉」的方式**

最后我们看看 C5 的配置：

> *   处理器：骁龙 617
>     
> *   内存：4GB RAM+32GB/64GB ROM 组合
>     
> *   屏幕：5.2 英寸；Super AMOLED 屏幕（1080p 分辨率）
>     
> *   摄像头：800 万前置+1600 万后置（F1.9 光圈）
>     
> *   电池：2600mAh
>     

如果 C5 能够和 C7 一样用上的 14nm 制程的骁龙 625 处理器就更好了，骁龙 617 确实让人少了几分期待。不过在实际使用过程中，C5 并没有什么卡顿现象的出现，但软件的加载速度、游戏流畅度确实和三星使用骁龙 820 或 Exynos 8890 的旗舰手机有一定差距。

![](../Images/f0fbc421762e47953e058e8576a6a995.png)*Geekbench 3 和安兔兔跑分截图*

S7 edge 和 C5 代表着三星两个截然不同的产品思路。前者更多是为了「秀肌肉」，这也意味着消费者要为它独特的外观和强大的性能买单。后者通过大众化的外观、够用的性能和诸多本地化的功能进一步扩大三星的受众群体。

![](../Images/279f39b269a76965dfcf2c94c5551b36.png)*C5（左）和 S7 edge*

伴随着新品发布，三星选择了「刚刚好」作为 C 系列的宣传标语。在外观和配置上，C5 确实只能用「刚刚好」来形容。不过 C 系列从发布到开卖的速度很快，诸多本地化功能也「踩准了鼓点」，这又何尝不是三星在供应链和软硬件整合上另一种「秀肌肉」的方式呢？

我在体验 C5 的这段时间，相继呆过三个城市（北京、上海、成都）。值得注意的是，每个城市的市中心都能看到三星搭建的展区，这样的营销力度不是所有手机厂商都能做到的。

![](../Images/e3abdda3a09b84e62e4763b7ed10e0e8.png)*三星位于成都春熙路的展区*

因为 C5 才发售不久，现在还无法了解它的售卖情况，一个季度过后我们可以再复盘。不过 C5 已经展现了一些成为线下热销机型的气质，加上三星强大的营销攻势，相信会卖得不错。
