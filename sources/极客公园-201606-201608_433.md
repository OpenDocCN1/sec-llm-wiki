# 又一年，这 3 位前 Google 工程师就是想让 Android 和 Windows 真正的「Remix」在一起

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652841117&idx=2&sn=5a32da7924a85a13a81d24c0d0742c64&chksm=7e6a592b491dd03dee779ecc2aa672011ac1c990ccfb9d67af0129454dde2ec5b5ad1fc39ea3&scene=126&sessionid=1681311502#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652841117&idx=2&sn=5a32da7924a85a13a81d24c0d0742c64&chksm=7e6a592b491dd03dee779ecc2aa672011ac1c990ccfb9d67af0129454dde2ec5b5ad1fc39ea3&scene=126&sessionid=1681311502#rd)

![](../Images/ff90609a080fa9a6cd8059bf814268a6.png)

去年我们用一句话来形容第一款「Remix」平板：[「融合了 Windows 和 iOS 系统特点，拥有类似 Surface 外观的 Android 平板——正如它的名字一样「Remix」」。](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=211496308&idx=3&sn=e5f21f3c13f13c0cec8d312b5eeb8026&scene=21#wechat_redirect)  

除了 Remix OS 的更融合且独特的体验之外，在硬件层面技德科技也好像有别家的「影子」，但一年半后的今天，他们发布了新一代平板电脑——Remix Pro，我们不仅看到了不一样的设计，同时他们好像也找准了 Remix 这种混搭的魅力。

除此之外，他们还想让 Remix OS 真正走近千家万户，去适应更多不同的使用场景，他们还与众多合作伙伴合作推出的硬件产品，包括与 AOC 冠捷合作的 Mars 系列云端一体机、与 Acer 宏基合作的安卓游戏本、以及代号为「Remix+」的安卓迷你电脑解决方案等一系列软硬件产品。

同时还发布了让 Android 和 Windows 真正融合的黑科技「Remix X」。

******************************************************************“******************************************************************** Remix Pro ：不单纯的安卓平板**

Remix Pro 首先带给我们最大的不同就是它特别的外观设计，由 BMW（宝马）旗下设计团队 Design Works 设计，机身采用 Unibody 一体成型工艺、全镁合金制成，整机厚度为 6.9mm，机身重量 640g，非常特别的「腰身曲线」使 Remix Pro 更具辨识度，同时也拥有更棒的握持手感。

![](../Images/f60971b8a52b9432788910d4acfa0ed4.png)

更值得一提的是，在 6.9mm 厚（iPhone 6 的厚度为 6.8mm）的前提下，除了 Type C 接口，还是配备了一个传统的 USB Type A 插孔，非常的良心。

![](../Images/7af35d8de46eb83a8c72087a831ccbca.png)

硬件方面，Remix Pro 搭载了高通骁龙 652 处理器，机身配备的 9000mAh 大容量电池。屏幕方面，Remix Pro 采用 12 英寸 IPS 材质显示屏幕设计，显示分辨率达到 2160\*1440 2K 级别，并采用第三代康宁大猩猩玻璃面板，显示效果也算是比较出众。

![](../Images/8443e8944d607e83bcacc5e5947c9a93.png)

与 Remix Pro 配套的 Smart Cover 采用磁吸可拆卸设计，能够充当保护套、支架以及全尺寸键盘三种不同角色，并拥有三种折叠角度，适用于各类使用场景，也满足了不同人群的多样化使用需求。

![](../Images/63820d864be2247dc5ddf20282b1908c.png)

Remix Pro 平板电脑主要面对机构用户销售，预计于今年 7 月现货发售，但官方并未公布价格。

******************************************************************“********************************************************************让「显示屏」也拥有操作系统**

Mars 系列云端一体机是技德科技与 AOC 冠捷合作推出的一体机产品，该系列共包含两种不同尺寸，屏幕大小分别为 23.8 英寸和 32 英寸。

![](../Images/7621f8875ee492fb754af34ffb55fc21.png)

Mars 系列云端一体机采用 Amlogic S905 四核心 64 位 ARM 处理器，辅以 16GB/64GB 存储空间和 2GB 运行内存，搭配经过深度优化的 Remix OS 操作系统，基本能够满足家庭用机的基本需求，外观非常简洁，同时它同样能够作为一块「显示屏」来搭配其他主机进行使用。

Mars 系列云端一体机将于本月正式在京东及天猫平台进行售卖，23.8 英寸价格为 1699 元。

******************************************************************“********************************************************************「Android-x86 创始人」让安卓游戏本体验升级**

技德科技自从今年 1 月推出基于 Android-x86 项目的 Remix OS PC 版起，就一直在寻找着合适的硬件合作伙伴，如今这一项目终于以笔记本硬件产品形态面世。 Acer 安卓游戏本是技德科技在深度剖析手游行业后，与 Acer 宏基合作推出的一款搭载 Remix OS PC 版操作系统的笔记本电脑，希望打造一款真正适合手游的硬件产品。

这一项目的另一重磅消息是，Android-x86 项目的创始人——来自台湾的黄志伟先生亦宣布加入技德科技，以项目 Leader 的身份继续深度探索 Remix OS PC 版的可能，相信有 Android-x86 创始人的「技术加持」，Remix OS PC 版将会走得更远。

![](../Images/67fc3b62116c517494d1a34b1229ea1d.png)

Acer 安卓游戏本采用 11.6 英寸屏幕设计，在 21.2mm 机身厚度和 1.25kg 机身重量之下，隐藏着一颗英特尔全新平台四核处理器以及 500GB 容量硬盘，保证了游戏时的流畅程度。Acer 安卓游戏本内建了比较丰富的键盘映射功能，并为市面上最为热门的虚荣、梦幻西游、皇室战争以及九阴等十余款手游大作进行了订制优化。用鼠标和键盘来操作安卓手游还是相当奇特的一种体验啊，只能说各有优缺点吧。

Acer 安卓游戏本在技德科技官方淘宝店进行售卖，定价为 2199 元。

 ******************************************************************“********************************************************************让你 Android 和 Windows 随时切换的黑科技「Remix X」**

极具「黑科技」意味的 Remix X，究竟如何赢得大家最高的呼声？

Remix X 是技德科技和美国 Codeweaver 公司合作的一个项目，用户可以在英特尔芯片上的 Remix OS 上运行 Windows 应用。也就是说，Remix OS 不仅支持两百万安卓应用，现在也可以支持 Windows 上的 EXE 程序，这可以称得上是 Android 系统有史以来完成的最大壮举，而在昨天，这件事也许还被人嘲笑为天方夜谭。

![](../Images/d4101ef4e147b2d493d8a15533d1e794.png)

Remix X 的诞生，进一步拉近了 Remix OS 和传统桌面级操作系统的距离，这也让 Remix OS 核心竞争力而不断优化和完善。

不过目前，Remix X 暂且可以运行微软 Office 2007 和一些 Windows 下的小游戏，如接龙，扫雷等。双方的工程师正在努力解决更多兼容性和稳定性的问题，目标是支持更多的程序，如 Office 2010，Firefox 和 Flash，Steam。

值得一提的是，技德科技将优先在 Acer 安卓游戏本发布 Remix X 预览版，想体验黑科技的同学赶紧入一台吧。技德科技 CEO 周哲同时宣布，作为第二代安卓迷你电脑的「Remix+」将从即日起开放解决方案。

**技德科技从一款众筹产品，到融合了多种特点的 Remix 平板，再到今天的 Pro 和多放合作，真正将「Remix」这种融合性的极强的系统级改变发挥到了完美，随着像 Remix X 这样的黑科技出现，相信又为我们未来的移动设备增添了一种独特的新的产品选择。![](../Images/342ca8f5774061894f90123b5c3aa62b.png)
