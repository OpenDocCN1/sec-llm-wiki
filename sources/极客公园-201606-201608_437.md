# 一加手机 3 体验：不妥协的手感，不烫手的快充

有句俗话叫「慢工出细活」，放在手机厂商中，苹果就是一个典型的代表，而如果把范围缩小到国内，一加手机算得上是最「慢工出细活」的厂商之一（另一家是锤子）。  

就在昨天，一加发布了 2016 年的第一部、也是唯一一部智能手机——一加手机 3，这款堵上了一加未来一整年的手机表现如何？它能否背负起一加口中的「极速旗舰」之名？我们一起来看一下吧。

******************************************************************“********************************************************************全金属机身，不妥协的手感**

相比一加 2，一加 3 在外观上发生了明显的变化，一加 2 上的「金属中框+多材质后盖」在一加 3 上被换成了一体化全金属后盖，**机身****厚度从一加 2 的接近 1 厘米大幅缩减到 7.35 毫米，重量也从 175 克降到了 158 克。**

![](../Images/95e4be4acb54b0408c5edfdaad2d1be1.png)

为了保证手机通讯信号的传输，一加 3 在后盖的上下各加了一格塑料条，此外，一加 3 摄像头的上方还加了一条竖着、很短的信号条，用于实现 NFC 功能。由于这种「2+1」的信号条设计，第一眼看上去一加 3，你可能会觉得一加 3 和 HTC One M8/M9，三星 Galaxy C5 等手机有些类似。

不过虽然一加 3 的后盖长了一张大众脸，但在弧度的处理上，一加 3 花了很多的心思。

通常来说，弧面的后盖握起来手感更好，但往往不太好看，而平面的后盖看起来会显得更加漂亮和简洁，但手感又不好。一加 3 则试图在「平面的观感」和「弧面的手感」之间找到一个平衡点。

![](../Images/34bde49f215c52ce221b14656333a585.png)

一加 3 后盖中间的部分仅有很轻微的弧面，**观感上有些类似索尼 Xperia X 那样的平面金属后盖**。不过在后盖两侧的边缘，一加 3 又使用了比较明显的弧线**，从而实现更好的握持手感**。此外，在后盖和边框相交的位置（棱线），一加 3 还特意做了**一道非常小的弧面，从而让握持手机时不容易感到割手。**

通过这种独特的背部线条，再加上出色的做工、细腻的表面喷砂以及大幅瘦身的机身，一加 3 的握感非常不错。

![](../Images/987d76874e88ab6d08c1e608b71e2a3e.png)*一加 3 的凯夫拉保护壳*

由于使用了全金属后盖，一加 3 无法像一加 2 那样自行更换后盖了，作为弥补，一加 3 提供了包括竹子、酸枝、黑杏、芳纶纤维（凯夫拉）以及经典的砂岩黑在内的五种不同颜色和材质的保护壳可选。

******************************************************************“********************************************************************正面指纹识别，不可按压**

一加 3 配备了一块 5.5 吋、1080p 分辨率的 AMOLED 屏幕，ppi 为 401。在常见的 LCD 屏幕中，这个 ppi 已经可以基本保证日常使用看不出像素点了，不过由于 AMOLED 次像素排列的问题，**近距离观看时，一加 3 的屏幕还是可以看到轻微的像素点的。**不是「大果粒」，但的确能看出来。

![](../Images/80de8d92e1aa08a527089c002c9627cd.png)*一加 3 （左）和 PRO 6（右）*

好在一加 3 屏幕的整体观感不错，色彩还原没有明显的问题，最高亮度也足够，大致和魅族 PRO 6、ZUK Z2 Pro 出于同一水准，相比三星 Galaxy S7 还有差距。

需要注意的是，和一加 2 一样，一加 3 的正面底部的指纹识别按键模块是不支持按压的，如果你已经习惯了按压式指纹识别，初次使用一加 3 可能会感觉不太习惯。刘作虎表示，

> **「之所以这样设计，是为了让这颗按键在系统内作为主页键使用时，在触感上和两侧的多任务和返回键保持一致。」**

值得一提的是，**一加 3 指纹解锁的成功率很高，而且速度非常快，非常非常快，几乎是手指稍微碰一下即可完成解锁，和我们之前用过的最快的指纹识别 OPPO R9 不相上下。**

![](../Images/64799481520332b30abfe73a175179d6.png)

和近期推出绝大多数手机一样，一加 3 正面也配备了 2.5D 弧面玻璃，玻璃四周的塑料包边基本和玻璃边缘齐平，屏幕边缘的滑动手感非常顺滑。另外，一加 3 的侧面保留了一加 2 上的「静音-勿扰-响铃」的三段式开关，可以快速切换声音模式，用起来还是很方便的。

![](../Images/911ed7bc1f847fd343d3d05ecec71230.png)

性能方面，一加 3 没有什么值得担心的，「骁龙 820+6GB LPDDR4+64GB UFS2.0 闪充」的组合让一加 3 可以流畅运行 Android 平台的所有 app。国内版的一加 3 预装了基于 Android 6.0.1 的氢 OS，经过了一年多的补全，氢 OS 现在已经完全可用，当然，如果你要追求更丰富的功能，可以考虑买来一加 3 后过阵子再刷个 MIUI。

此外，虽然配置很高并且机身很薄，但一加 3 的散热表现相当不错，日常使用时几乎不会感觉感觉到手机发热，即使连续运行跑分软件，机身也只会稍微有些温。

******************************************************************“********************************************************************「五分钟**充电**，两小时**通话**」**

一加 3 的电池容量为 3000 毫安时，这个容量在现今的旗舰手机中并不算大，配合着 5.5 吋 1080p AMOLED 屏幕和骁龙 820，在日常的中度使用中，一加 3 坚持一天问题不大。不过一加 3 还有一个有些「黑科技」的功能——DASH 闪充。

现在市面上最常见的快充方案有两种：**来自高通的 QC（Quick Charge）方案以及来自联发科的 PE（Pump Express）方案**，这两种方案都是基于 9V 或 12V 的大电压技术，都可以实现最高超过 20W 的充电功率，基本一个小时出头就能充满一块 3000 毫安时的电池。**但这两种方案有个共同的问题：只能在手机熄屏才能「全速工作」，一旦点亮屏幕，为了保证安全，充电电流瞬间就会大幅度下降，快速充电退化成了普通的慢速充电。**

相比之下，一加 3 上搭载的 DASH 闪充在不提高电压（5V）的情况下，使用大电流（4A）的方法来提高充电速度。**即使用户一遍使用手机一遍充电，一加 3 依旧可以保持接近 20W（5V×4A）全功率的状态充电。**此外，由于没有高低电压的转换，一加 3 在充电时（无论是熄屏还是亮屏）机身不会有明显的发烫。

在官方宣传界面中，一加直接晒除了一加 3 和小米 5（QC3.0）、三星 S7 edge（QC2.0）的充电速度对比，可以看出，在熄屏状态下，一加 3 的优势并不大，不过**如果一边玩游戏一边充电，一加 3 的充电速度有着几乎压倒性的优势**。

![](../Images/431c4ab3793ecba87531e2cda1829c6a.png)

如果你正在使用 OPPO R9 等手机的话，应该对一加 3 的 DASH 闪充不会感到陌生。实际上，**DASH 闪充就是 OPPO VOOC 闪充换了个名字，**二者唯一的区别是一加把 VOOC 闪充中那根定制的 Micro USB 线换成了一加 3 中定制的 USB Type-C 线。  

我们把一加 3 标配的 DASH 充电头换成了 R9 标配的 VOOC 闪充头，然后使用一加 3 的原装线，依旧可以正常进行快速充电，反过来，我们把 R9 的 VOOC 闪充头换成了一加 3 的 DASH 闪充头，然后使用 OPPO 的原装线，同样可以使用快速充电。

对了，大家千万要好好保管好一加 3 的原装充电头和线，丢了之后再买需要花上接近两百块。

******************************************************************“********************************************************************摄像头，成像有惊喜**

相机方面，**一加 3 采用的传感器是索尼的 IMX298，1/2.8 吋，1600 万像素，支持相位对焦。**这颗 CMOS 在索尼的产品线中属于中高端的位置，除了一加 3，小米 5、vivo Xplay5、努比亚 Z11 mini 等手机也都使用了这颗 CMOS。此外，一加 3 还集成了光学防抖，光圈为 f/2.0。

从参数上看，一加 3 的摄像头配置堪称豪华，再加上前两代的一加手机的摄像头在同时代竞品中都有比较出色的表现，我们对一加 3 的摄像头有比较高的预期。

在白天光照充足的情况下，目前的中高端手机之间已经很难拉开明显的差距，更多的是成像风格上的微小差异。一加 3 的成像风格偏向艳丽，画面饱和度较高，有刻意讨好眼球的倾向，配合自带照片编辑工具中的 LOFTCam 滤镜，很适合饭前「验毒」。

![](../Images/4b9f27dccf6c787ac1d3ccfd952784b3.png)  
*由一加 3 拍摄*

![](../Images/42abd7555c9e8d8884236b642735659c.png)*由三星 S7 edge 拍摄*

在晚上室内光线较差的情况下，一加 3 的画面饱和度依然较高，噪点的控制也相当不错，对比三星 S7 edge，一加 3 拍的照片要略暗一下，三星 S7 edge 保留了更多的暗部细节，但画面噪点比一加 3 更多。

![](../Images/dba6259202f688b47618a10a49e44692.png)*分别由三星 S7 edge（左）和一加 3 （右）拍摄*

到了光线更差的时候，一加 3 这种「牺牲亮度换纯净度」的风格会体现的更加明显。三星 S7 edge 拍摄的画面亮度明显要比一加 3 高出一档，S7 edge 的这种「夜视仪」的成像风格往往可以让照片的第一观感非常惊艳，副作用是拍出的照片和真实场景不符（太亮了），并且会增加肉眼可见的噪点。

相比之下，一加 3 的在夜间拍摄的照片会更加接近真实场景，看起来更纯净，但画面第一观感的冲击力就要比 S7 edge 少很多。至于两种风格孰好孰坏，大家就见仁见智了。

![](../Images/40d58c1a605c626af8f7be9ddec05ade.png)

拍照体验上，一加 3 的表现也不错。任意界面下双击电源键可以快速启动相机，启动速度和三星 S7 edge 差不多，拍照过程中，一加 3 的对焦和测光表现也都比较靠谱，只是在暗光下对焦速度会有明显的下降。特别晚上光线较差时，三星 S7 edge 依然可以一下子对上焦，一加 3 就得拉上几次「风箱」了。

整体来看，虽然在对焦速度等方面比三星 S7 edge 这个级别的产品还有些差距，但一加 3 的拍照表现已经足够优秀，在两千档的手机中算得上是顶级的水准了。如果你对手机相机的要求较高、同时又能接受背后相机模块那个巨大的凸起的话，一加 3 是同价位最值得购买的手机之一。

******************************************************************“********************************************************************一台找不出什么毛病的手机**

在售价上，一加 3 保持了相对的克制，把「骁龙 820+6GB 运存+64GB 存储」卖到 2499 让一加 3 拥有不错的性价比，不过对比近期发布的一票 2000 元档的国产骁龙 820 手机，一加 3 的定价并没有绝对的优势。

对比竞争对手，一加 3 最大的优势是均衡。如果把手机比作一个木桶的话，除了「只能摸不能按」的指纹识别和相机头部分略显夸张的凸起需要适应下之外，一加 3 的这个木桶几乎没有短板。

![](../Images/ed577edeb3d3304446ad441029ca4535.png)

如果你是一个一加 1 的用户同时正在考虑升级手机的话，一加 3 是一个非常值得考虑的选择，而如果你只是想花两千多块钱买一部优秀的手机，一加 3 是继 ZUK Z2 Pro、魅族 PRO 6 等之后，又一部值得纳入考虑范围选择的手机。  

对了，一加 3 已经于今天 10 点正式开售，然后…… 就缺货了……
