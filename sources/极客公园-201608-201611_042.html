新 MacBook Pro 

上周，苹果发布了新一代的 MacBook Pro 笔记本电脑。这是继 2012 年推出配备 Retina 屏幕的 MacBook Pro 以来，这一产品线四年以来的首次重大变化。

新 MacBook Pro 增加了很多创新性的功能，比如在键盘上方使用一块 OLED 触控屏（Touch Bar）来取代了传统的功能键，除了实现原有功能键的功能，这块屏幕还可以根据 Mac 上打开的 app 来显示不同的功能。与此同时，由于砍掉了所有 Type-A 接口、SD 卡等过于「激进」的设计，新 MacBook Pro 又备受争议。

近日，苹果全球营销高级副总裁 Philip Schiller 在苹果位于加州的「太空飞船」总部（Infinite Loop），接受了英国《独立报》的独家采访，透露了新 MacBook Pro 的更多细节。

为什么要设计 Touch Bar？

我们一直在思考笔记本电脑未来的方向。在这个行业中，有些人试图把笔记本电脑变成平板电脑，不过我们却不那么认为。

新 MacBook Pro 的可贵之处在于它依然是一款笔记本电脑，这种产品形态已经陪伴了我们 25 年了，并且有可能继续在未来的 25 年陪伴着我们。

一个你可以用双手打字的平面，一块正对着你的屏幕，笔记本电脑这种 L 型的形态已经被证明是非常合理且高效的。在这一基础上，我们的团队设计了一块可以进行多点触控的区域，它和键盘、触摸板在同一个平面上，可以带来更加具有互动性的交互体验。

macOS 和 iOS 在未来会不会一直保持不同？

我们坚信，macOS 和 iOS 对应着两类同等重要但又根本上不同的产品。

iPhone 和 iPad 的主体是一整块的玻璃，用户可以通过多点触控直接在屏幕上进行操作，并倾向于用全屏幕的方式使用 app。在 iOS 中，我们努力把这种不一样的体验做到最好。相比之下，Mac 上采用的基于光标、菜单的间接操作方式，我们希望 macOS 可以吧这种体验做到最好。

我来举个为什么 macOS 和 iOS 应该保持不同的例子。

Mac 的顶部就有一行固定的菜单栏，这行菜单栏对 Mac 的用户体验是至关重要的，可如果尝试把这种菜单栏放在 iPhone，就变得非常不合适了。另一方面，如果为 Mac 配备触摸屏，就必须保证手指在触摸屏幕时能拥有优秀的用户体验，我们为此做过很多尝试，但最后都证明在 Mac 上配备触屏是一种糟糕的体验，它远没有使用鼠标和触摸板来得优秀和直接。

为什么新 MacBook Pro 没有 SD 卡插槽？

首先，在电脑上配备 SD 卡插槽本身就很笨拙，插上卡之后，SD 卡会突出机身一截。其次，现在市面上已经有很多速度快且同时兼容 CF 卡和 SD 卡的读卡器，不过我们在 Mac 内置的读卡器上却无法做到这一点，之前的 Mac 配备 SD 卡插槽，是因为更多的消费级相机使用 SD 卡，我们这才选择了在 Mac 上支持 SD 卡。从这个角度看，Mac 上的 SD 卡插槽本身就是一个有些妥协的设计。

现在，随着越来越多的相机开始内置了无线传输功能，用户已经可以通过无线的方式来传输照片了。如果你的相机还没有无线功能，则可以使用转接头来连接外置读卡器。

新款 iPhone 中砍掉了 3.5 毫米插孔，为什么新 MacBook Pro 还要保留它？

如果 3.5 毫米插孔只是用来连接耳机的话，我们认为它是可以砍掉的，因为我们认为无线才是耳机的未来。但新 MacBook 是面向专业人群的产品，很多用户会为它配备监听音箱、音频放大器等其它音频设备，这些专业设备常常还没有无线解决方案，需要 3.5 毫米插孔。

macOS Sierra 中增加了 Siri 功能，为何 Mac 用户却不能像 iPhone 直接说「Hey Siri」去启动？

作为用户，我们希望你可以在房间的任何一个地方，无论电脑处于开机还是休眠状态，都可以通过说「Hey Siri」来唤醒 Mac。为了实现这些，我们需要设计应用在整个系统上、随时处于待用状态的电子元件，不过目前的 Mac 还没有内置这种元件。

如何看待大家对新 MacBook Pro 的评价？

新 MacBook Pro 的很多特性给大家留下了深刻的印象，但也有一些变化带来了一些争议。我希望所有人都可以有机会亲身体验一下新 MacBook Pro，感受一下这是一款多么了不起的产品。

新 MacBook Pro 是 MacBook 产品演进的一大步，它表明了我们依然在持续为 Mac 产品线投入精力。我们热爱 Mac，我们会像过去那样，不断地把它变得更好，无论是台式机（iMac）还是笔记本电脑（MacBook）。

另外，我非常自豪的告诉大家，截至到现在，我们在线商店收到的新 MacBook Pro 订单比我们之前的任何一款「Pro」笔记本电脑都要多。显然，有很多人和我们一样对这款产品同样兴奋。

对新 MacBook Pro 的批评声音感到意外吗？

坦白说，我有些感到意外。

不过任何一款伟大的苹果产品都会在早期受到一些批评，这是因为我们在产品上做了一些大胆的冒险，用户在最初使用时难免需要面对一些新变化，这往往不是件坏事。

1998 年推出的初代 iMac

我们相信，在设计新 MacBook Pro 时，我们做了正确的决定，所以我们才能设计出有史以来最优秀的笔记本电脑。刚开始时候，或许不是所有人都会认同这一点，这没有什么关系，当我们推出第一款 iMac 的时候，也有不少人不认同这款产品，不过之后初代 iMac 被证明了是一款非常优秀和成功的产品。
