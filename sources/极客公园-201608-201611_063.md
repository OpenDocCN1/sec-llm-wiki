# 盘点 Smartisan OS 历代亮点，为什么它是锤粉们内心最深处的骄傲

Smartisan OS 作为锤粉最重要的炫耀资本，一直是锤子手机非常核心的竞争力。  

在很多理性锤粉的心中，当抛开老罗和情怀 Smartisan OS 可能才是锤子手机的灵魂，这款根据 Android 深度定制的手机操作系统一直是 OS 中一个很特别的存在。

一方面，固执的坚持拟物风格、九宫格、十六宫格等等或许看起来都在这个时代稍显格格不入；另一方面，无比重视用户体验、不断堆砌细节、追求完美，让 Smartisan OS 的用户一定程度上成了最幸福的手机用户。无论如何是否喜欢，不能否认的是 Smartisan OS 作为一个操作系统给这个行业带来了太多启发，修缮了无数多年无人理睬的体验细节。

**所以，今天就为大家盘点一下锤粉骄傲的资本，那些 Smartisan OS 中具有启发性的系统层优化，从远到近从大到小，从 Smartisan OS v1.3 到 最新的 Smartisan OS 3.1，这算是一份锤子给智能手机操作系统的独特贡献。**

## 革新用户体验的创造

很多操作和科技革新都具有「不可逆」的特性，一旦用上就很难再回去。Smartisan OS 的历代版本在这方面一直都做的很好，创造了很多让人用了就离不开的功能，从根本上刷新了很多领域的用户体验。

**定时静音**

在开启静音模式后，可设置静音倒计时。你可根据场景需要，设置静音时长，倒计时结束将自动关闭静音模式，以防止你忘记关闭静音模式，而错过重要的来电或通知。

![](../Images/15489847e13760ef5a537269734e07f5.png)

**滚动截屏**

在截屏操作的支持上，Smartisan OS 一直都走在前列。对于这一高频刚需，历代的 Smartisan OS 都很重视。

Smartisan OS 的滚动截屏可自动滚动屏幕连续截屏并自动拼接成一张长图。长按「Home」键 + 电源键可呼出截屏增强选项，点击「滚动截屏」启用该功能。在编辑模式下，还可以通过拖动预览窗上下边缘的手柄来选取想要保存的范围。

![](../Images/6981b52f58488488248cf4d17c2ae6ed.png)

**系统全局快捷短语**

这虽不是锤子的原创，但也正是 Smartisan OS 通过改进 iOS 端一款类似 app 的功能并将它带入 Android 用户的视野。

通过全局短语，在系统内任何文本输入界面长按可呼出「快捷短语」按钮，点击按钮可在弹出的列表中选择预先输入的常用短语，如地址、邮件、账户等日常经常需要输入的长串文字。

![](../Images/260fc03df572a513000c39991a8bf81f.png)

**图标排列**

Smartisan OS 算是最懂强迫症人群的手机系统了，因为在系统设置中直接就有一个「强迫症选项」，在这进入编辑模式，可以选择按照应用使用频率、图标颜色或应用安装时间等方式重新排列桌面图标，这个功能当时切中了无数人的痛点。而除了看起来爽以外，这样的设定也同样实用。

![](../Images/0bd985f0d799c3c1a953b91ba0eb5bcc.png)  
**语音搜索本地化**

锤子是业界很早就开始将语音搜索本地化的，由此带来的变化就是响应速度大大领先同类应用。通过直接说出名称即可搜索手机内的联系人、应用和音乐（包括音乐人、专辑和歌曲）。在搜索结果中可直接呼叫联系人、打开应用程序和播放音乐。

![](../Images/0d9fbb23981a443e6a5d8c5ea60e1818.png)

而在最新的系统中，语音搜索已经直接融入了全局搜索中。

**远程协助**

这是个非常为父母考虑的功能，相信很多人都曾因为用电话指导远方的父母操作手机而感到无力又着急，那一刻恨不得立刻出现在父母身边。

![](../Images/ef63ac0a7585114d960ced020183037c.png)

而 Smartisan OS 的远程协助功能可以通过自己手中的 Smartisan 手机方便地通过网络操作另一台 Smartisan 手机，来帮助对方完成一些复杂操作，并且在操作的过程中的可以进行屏幕勾画和讲解。

![](../Images/ce1220c2f2216ff7946c893bc2d9a682.png)

**One Step 功能**

这是在前些天锤子发布会上和 M1 手机一同公布的 3.1 新功能，一个极大简化多步操作的功能。通过将最近添加 / 使用的图片、文件和剪切板内的文字集合在屏幕顶部，将常用应用和联系人集中于屏幕侧边，用拖拽的方式即可将信息发送至应用或联系人，节省了在不同应用之间切换的诸多步骤，大幅提升了应用间的协作效率。

![](../Images/9b34808491744bec9b9652f57e6a94f0.png)  

特别是在邮件、微信等等，让原本需要 9 步甚至 11 步的操作在 2 步之内完成。

**BigBang**

这是一个立意于段落复制编辑的优化功能，通过简单操作让用户在手机上复制和选取部分文字时效率尽可能的接近电脑。

方式则是用拇指大面积按压屏幕中的文字，「Big Bang」会将按住的那一段文字全部「炸」开，按照语义智能拆分成独立的字和词，可以随意选择文字，来进行搜索、分享和复制的操作。

![](../Images/3061f804d93514e7556559d2b88174b5.png)  

这和一款叫 Pin 的软件很像，之前我们也介绍过[（相关文章）](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=402667062&idx=3&sn=0354afc9bd7f35bc3fef497daa8773aa&scene=21#wechat_redirect)，但由于这是锤子基于系统层面的功能，拥有更多权限，Smartisan OS 也在原有的基础上做了很多优化，像是选取自由文字并能分享，像是识别图片中的文字并「炸」开。

![](../Images/3a18a0f81c5cfc7894d9e48097301934.png)

## **效率提升的极致追求**

老罗和他的团队始终对完美主义有着一定的执念，尤其在手机操作效率的提升上，Smartisan OS 几年来一直在添加很多提升操作效率的细节。简单来说，锤子手机想让能用两步完成的操作避免花 10 步去搞定。  

尽管有些优化学成成本和门槛较高，不太适合一些小白用户，但这些改进确确实实对手机的操作效率有成倍提升的效果。

**·** 在锁屏界面下，四指横划快速切换壁纸。

![](../Images/094b3569401e1ec857fe33713c9500fc.png)

****·** **日历快速拖动，日历中长按任务可以将该任务拖拽到任意一天，右划可以进行分享、删除和加星等操作。

![](../Images/c93f7b1f7a899ec8c9e1ab84107aa5c0.png)

**·** 在联系人列表界面左滑拉出字母轴后长按某字母，会弹出手机通讯录中该字母包含的全部姓氏，可快速检索联系人。  

![](../Images/79ef4dbd29e502a7f2c434f90ec9130f.png)

**·** 正在编辑的邮件可以实现最小化，还可以把其他邮件的附件通过拖拽的方式添加到最小化的邮件中，点击邮件正文中的联系人可查看其发出的邮件。

![](../Images/6fd21524c95560ea6dcba85729ec36bd.png)

**·** 「已发送邮件」中支持筛选「已发出但未被回复」的邮件。

![](../Images/2800742ebdcb7ac10e0fcff369b35a4f.png)

**·** 桌面编辑模式可以批量卸载应用。

![](../Images/39546c302e4ba1c45894126664c05a38.png)

**·** 支持在锁屏验证指定指纹直接打开微信、支付宝的付款界面，这是一个很有启发性的小功能。

**·** 关闭重复闹钟时，询问关闭当次还是关闭全部。

**·** 双击 home 可调出后台，长按后台某个程序可以锁定该后台不被清理，当然点击小图钉后则解除锁定。

![](../Images/61f399692153c89535c696a111d52a97.png)

**·** 任务管理器下部的页面指示器里有音乐控制页面的符号，显示哪一个应用在出声儿。

**·** 在灭屏播放音乐时，音量键对侧的上侧键可切换至上一首，下侧键可切换至下一首。

**·** 双手拇指反方向互搓可激活手势激活横竖屏操作。

![](../Images/5fadad36db88aaf0a8acd9910a02b27c.png)

**·** 输入信息后长按绿色发送按钮可选择定时发送。

**·** 地址栏和搜索框分离。

## 体现人文关怀的小细节

锤子一直是一家文艺且充满人文关怀的公司，这一点可能不会有人否认，而 Smartisan OS 也理所当然的继承着这一基调。在历代版本的很多细节处不止一次的出现在不经意的细节处打动人的小功能，那些充满人文关怀的特性也是锤粉们最可不言表又最骄傲的感动。

这些人文关怀的细节是让 Smartisan OS 与其他 OS 最不显眼却最重要的区别，它让锤子所以锤子。

**·** 在音乐播放器中的唱盘爆豆音开关，可以让音乐听起来就像在听黑胶唱片。

**·** 在音乐播放器中增加了「搓碟」效果，默认开启。在播放唱片的过程中用手搓动唱片，可产生打碟效果。

![](../Images/b707be8284b55c50f3d682733e53b0e7.png)

**·** 用 USB 线将手机连接电脑后，无论是用户控制电脑程序为手机安装应用，还是电脑程序自动为手机安装应用，在手机界面都会有相应的提示，防止连接电脑时，电脑恶意静默地向用户的手机安装应用。

**·** 当通话过程中手机被迫关机时，将自动给对方发送短信：「我的手机因为没电所以被迫关机，稍后跟你联系。」

**·** 闹钟响铃弹窗增加天气显示。

**·** Markdown 功能，可通过便签列表页左上角的「设置」中的「启用 Markdown 模式，在锤子变迁中进行 Markdown 文本操作。

![](../Images/bcf3d554f39a53563c42ab2d916a758d.png)

**·** 联系人详情中的「公司」项，点击可查询该公司的工商信息。

![](../Images/9247b1caec382261542bcf6eb8eb1713.png)

**·** 截屏支持图片「套手机框」功能，支持更换生成图片的背景颜色，支持为滚动截屏生成的长图套上手机框。

**·** 双指上滑可清除桌面应用角标，当然大家熟知的是手掌轻轻一挥。

![](../Images/e3a2ee021196672b8b9542d45ee3e882.png)**·** 下拉悬停可窥探手机内部构造。

![](../Images/d3d234f004467124728458b14008d1a6.png)**·** 相机切换到前置摄像头时，在左上角可以设置成「别人眼中的你」和「镜子中的你」。

![](../Images/87140e93a3ff0dd38c76058ef0579d42.png)以上，就是老罗和他的 Smartisan OS 曾经带给锤子用户们的惊喜。

虽然一直有人说锤子仅仅是在无关紧要的小地方修修补补，但其实作为一款常伴身边的设备，往往就是细节处决定了最根本的使用体验。

一直在堆砌细节的 Smartisan OS 和喜欢死磕完美细节的老罗在最细腻的用户体验提升上总能给人惊喜，而 Smartisan OS 在很多地方完成了「了不起的优化」和「有启发的创新」，从整个行业的角度让用户体验不断堆高。

Smartisan OS 学习并优化过很多功能也被模仿了无数次，作为锤子手机的灵魂，Smartisan OS 或许才是锤粉们更深层更细腻的骄傲。
