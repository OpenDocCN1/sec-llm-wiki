锤子 M1 

昨天晚上，罗老师今年首次「开讲」，发布了锤子 M1 和 M1L 这两款手机，我们也以全网最快的速度发布了 M1 和 M1L 的上手评测。

除了「家族」设计、顶级配置这些大家都已经熟知的东西，锤子 M1 和 M1L 还有哪些不太容易但又有趣的小细节？M1 和 M1L 的拍照和充电真实表现究竟如何？今天，我们接着聊锤子。

外观上那些有趣的小细节

锤子 M1 和 M1L 的指纹识别看起来很像 iPhone，这大家都知道了，不过仔细观察，锤子在细节上又做了一些微小的工作。在白色版本的 M1 和 M1L 上，指纹识别一圈的金属圈并不是 iPhone 那样的银色，而是烤上了一层白色的漆，并在边缘切了一圈很小的亮面金属倒角，看起来更精致了一些。

M1 和 M1L 的都沿用了锤子招牌式的听筒传感器二合一设计，但这个模块摆放的位置并不一样，「大号」的 M1L 位于顶部的额头上部，而「小号」的 M1 的位置则更靠近额头中间。

在昨天的体验文章中，我们提到虽然 M1 和 M1 使用了更占空间的摄像头模组，但摄像头部分并没有明显的突出。从锤子官网的提供的数据中，我们可以计算出这两款手机的摄像头部分具体突出的程度：M1 的摄像头突出机身 0.48 毫米，M1L 则为 0.38 毫米。

经过我们的确认，所有白色版本的 M1 和 M1L（包括不锈钢版本）的后盖材质均为亮面塑料，观感上有些类似玻璃，但耐磨性上就要明显逊色一筹了。再加上 M1 和 M1L 的后盖部分不可更换，大家如果打算购买白色版本的 M1 或 M1L，使用时最好还是小心点。

除了常规的哑光铝制中框，高配版的 M1L 还有一个不锈钢中框的版本，中框的表面经过抛光，看上去有种镜面的效果，和前四代的 iPod Touch 的后盖有些像。但需要说明的是，抛成镜面的金属普遍会不太耐磨，相比普通的亚光版，不锈钢版 M1L 的中框在使用时会更容易出现划痕。

屏幕大了，但却没重多少

相比 T1、T2 上的 4.95 英寸屏幕，M1 和 M1L 的屏幕大了不少，其中 M1 的屏幕尺寸为 5.15 英寸，M1L 为 5.7 英寸。通常来说，屏幕大了，机身会更重，但 M1 和 M1L 却并没有明显的「增重」。

根据锤子官网提供的数据，M1 的重量为 146 克，恰好和去年的 T2 相同。

M1L 的重量为 175 克，考虑到它配备了一块 4080 毫安时的电池，这个重量控制地也是相当不错的。有趣的是，锤子的第一款产品 T1 的重量为 167 克，只比屏幕大了它两圈的 M1L 略轻一点。

拍照这次究竟靠不靠谱？

相机是锤子 M1 和 M1L 硬件上重点的提升点之一。在核心的传感器上，M1 和 M1L 配备了索尼 IMX318，传感器尺寸 1/2.6 英寸，像素 2300 万，单像素尺寸 1 微米，支持光学防抖，并配备了激光对焦。

在这组灯光下的闹钟和花茶中，iPhone 7 的表现最好，白平衡准确，噪点控制出色，观感最为通透。相比之下，索尼 Xperia XZ 的画面则明显噪点偏多。锤子 M1、一加 3、小米 5s 三部国产机的画面观感很接近，一加 3 的噪点控制比另外两部手机稍好一些。

在拍照体验和成像品质上，目前的中高端手机已经越来越难以拉开差距，这次的 M1 和 M1L 也总算已经进入了「拉不开差距」的阵营。在多数时候，你应该感觉不到 M1、M1L 的相机表现和 iPhone、Galaxy 之间有明显的差距。在国产手机中，M1 和 M1L 的相机也达到了 2000-3000 元档的主流水准。

不过要较真的话，和一加 3 这一级别的对手相比，锤子 M1 和 M1L 还是有一段距离的。比如说，和 iPhone 和 Galaxy 一样，一加 3 也配备了实用性很高的自动 HDR 功能，在光线反差较大的场景，可以自动启用 HDR 来提高照片的宽容度，而 M1 和 M1L 还必须得去设置中手动打开 HDR，即便是打开了，在需要 HDR 的场景，M1 和 M1L 合成出来的照片也明显没一加 3 来得自然。

充电真的快？

在 M1 剩余电量 40% 的时候，我们使用锤子原装的 24W 充电头和原装 Type-C 数据线，实测手机端的输入功率可以达到 22—23W 之间。

这几乎是目前市面上用高通的 QuickCharge 方案的手机中充电最快的了，比锤子充电更快的，目前似乎也只有采用 PD 方案的 Moto Z Force 了（不是 Moto Z）。

另外，M1 和 M1L 标配的数据线的 Type-C 端口的两侧内置了灯光，方便用户在睡前关灯后可以找到数据线来给手机充电。当检测到数据线插入手机时，Type-C 端口的灯会自动熄灭，非常体贴。

「黑锤」去哪了？

在昨天的发布会上，老罗花了不少口水来介绍 M1 和 M1L 全新的咖啡金配色，T2 时被砍掉的白色也终于「回归」，不过「最锤子」的黑色却没了踪影，直到锤子 UX 产品总监朱萧木昨天在极客公园的斗鱼直播间（房间号：673484）掏出了黑色版的 M1L……

这位锤子的「0001 号」员工表示，黑色版的 M1 和 M1L 在开发过程中是有的，只是相比白色和咖啡金版本，锤子认为制造黑色版 M1 和 M1L 增加的成本在目前并不划算，因此目前上市的 M1 和 M1L 就没有推出黑色版本。至于以后会不会有，如果 M1 和 M1L 卖得好，还是有戏的。

来自锤子科技官网

如何权衡多种配色和成本的关系一直是手机厂商的一个大问题。我们经常可以看到，手机厂商在发布会上一口气为同一款手机发布了四五个颜色的版本，不过到上市时却发现只能买到一两种配色（通常是银色或金色）。如果这款手机卖得很好，手机厂商可能在后期生产新的配色，如果卖得一般，这些「五颜六色」的配色就永远停留在 PPT 上了。

有了 M1 和 M1L，还会不会有 T3？

在正式推出了 M1 和 M1L 之前，几乎所有人一开始都认为这次的产品应该是传说中的 T3。而 M1 和 M1L 推出之后，大家也就理所当然地认为 M1 是 T3 改了个名字。

不过也是发布会结束当晚，在极客公园直播间中（斗鱼房间号：673484），朱萧木表示，「M1 并不是 T3 改了个名字，而是锤子推出的一个全新的产品线，至于大家关注的 T3，它依旧在研发过程中。相比偏重配置的 M1，T3 将会更加强调工业设计。」

因此，如果 M1 和 M1L 依然无法让你满意，还有 T3 可以期待。只是希望这一次，我们不需要等待太久。
