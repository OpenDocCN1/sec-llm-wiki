GPU 技术 

毫无疑问，GPU（Graphics Processing Unit，图形处理器）对于目前所有的硬件厂商来说都变得越来越重要，因为你需要在很多方面使用到它，尤其对于很多属于未来的前沿领域，比如 VR/AR、计算机视觉等领域，GPU 都是核心部分。

而我们也都知道，苹果公司是少数能自己生产智能手机芯片的手机厂商，其他大部分的手机厂商都需要从高通或联发科这样的芯片厂商购买。但是，苹果在 GPU 方面还没有做到「自给自足」，目前他们使用的是英国芯片厂商 Imagination Technologies 提供的图形处理器。

于是，为了补上自己这一块的缺漏，苹果已经在着手建立自己的 GPU 开发部门。而很不幸，为了找到足够的人才，他们很自然地就把发现人才的眼光放到了自己很熟悉的合作伙伴——Imagination Technologies 的身上。


「苹果挖掘机」：连 COO 都被挖走了

事实上，今年年初的时候，苹果就传要收购 Imagination Technologies，当时这笔交易已经走得很近了。然而之后，苹果又取消了这笔交易，让这笔交易无疾而终。

不过，如果你以为这是苹果对 Imagination Technologies 没兴趣的表现，那你就错了。从那之后，苹果就展开了对 Imagination Technologies 的「挖墙脚大法」，好好的一家英国芯片制造公司已经快被苹果「薅成葛优」了。

其中位阶最高的当属 John Metcalfe，今年 6 月离开 Imagination Technologies 的他，当时在公司的职位已是 COO，并且为这家公司工作了将近 20 年。然而，苹果还是成功挖走了他，并在最近任命其为苹果公司负责硬件工程部分的高级副总裁。

Dave Roberts（高级设计经理）、Jonathan Redshaw（副总裁）、Benjamin Bowman（高级软件设计经理）……打开领英中档案就可以看到，以上这几位都是今年被苹果成功「挖了墙脚」的前 Imagination Technologies 高管。

根据 MacRumors 给出的数据，目前通过搜索工具就能找到至少 25 位从 Imagination Technologies 跳槽到苹果的员工。单单在 9 月一个月期间，就有 6 位高级技术人员被苹果挖走。这种流失对于一家像 Imagination Technologies 这种体量的公司来说其实是一种很大的打击。

不过 Imagination Technologies 自己倒是「不怎么在意」，他们的发言人就这样表示：「这并不奇怪，我们的客户在这里发现了人才，有时他们当然也想雇佣一些优秀人才过去。Imagination Technologies 是一家拥有 1400 人的公司，判定我们人才外流纯属无稽之谈。」

关于 GPU 的竞赛，谁也不想落后

Imagination Technologies 本身是一家总部设立于伦敦的芯片设计公司，他们最著名的产品就要数 PowerVR 图形处理器系列了。从 2007 年开始，苹果 iPhone 中的 A 系列处理器中均使用的是 PowerVR 的 GPU 技术，今年的 iPhone 7 也不例外。事实上，苹果本身还是 Imagination Technologies 的投资方，他们目前拥有 Imagination Technologies 10% 的股份。

然而，即使双方已经有了长达十年的合作，但商业市场不相信感情，该挖角的时候就要挖角。作为一家以硬件产品为核心的公司，苹果总是想将 GPU 的研发工作也放在内部进行，依靠别人总不是那么安稳的一件事。同时，GPU 的研发工作也能为苹果在自动驾驶技术、深度学习技术等更广泛的领域提供支持。

事实上，有关苹果正在开发自己的 GPU 研发工作的传闻由来已久，但苹果自己却从未证实过此事。不过在今年年中的招聘工作中，苹果奥兰多等地的办公室已经在大量招收 GPU 相关的研发人员。同时，也有消息称苹果已经准备在伦敦直接建立一个新的 GPU 开发小组。

如果苹果能够成功建立起自己的 GPU 研发部门，那意味着苹果在芯片部分的实力将到达一个新的台阶。毕竟在可见的未来，GPU 的地位将变得越来越重要，像 IBM、Intel 和 NVIDIA 这样的公司都在大力发展 GPU 技术。而这也能够在目前尚不够出色的深度学习、自动驾驶技术等领域，给苹果提供更大的发展空间。
