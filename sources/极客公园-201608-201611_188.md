# Facebook 推出办公通讯软件，又来一款鸡肋的「企业微信」？

这几年，伴随着智能手机的日益普及，企业对于即时性沟通工具的需求也越来越强，在这个「后 email 时代」，到底什么样的产品才更符合商务人士的需求？近日，全球最大的通讯社交平台 Facebook 交出了属于自己的答案。

周一，Facebook 正式推出了旗下面向企业的移动社交平台，Workplace。该产品的使用场景主要是职场，这也意味着 Facebook 将正式成为硅谷独角兽 Slack 的直接竞争对手。

和 Facebook 不同，Workplace 是针对 B 端的付费应用，新注册企业可以获得 3 个月的免费体验，三个月后，Workplace 会根据企业人数的不同收取每人每月 1-3 美元的费用，相比之下 Slack 的最低收费则是每人每月 7 美元。值得一提的是，学校和非营利机构使用 Workplace 是免费的。

这款产品在发布前已经经历了长达 20 个月的内部测试，其使用面板和 Facebook 非常相似，主要功能包括群聊、视频电话会议、直播、群组和信息流，但为了和 Facebook 做出区别，Workplace 将主色调设成了灰色。

![](../Images/ee8ad38c3b32fca6d0a792041805d054.png)

这几年，因为 Facebook 的普及性和易用性等原因，越来越多的人开始使用 Facebook 进行一些简单快速的日常工作交流，这种感觉就像是微信之于我们一样。但仍有不少企业担心 Facebook 会使员工分心，毕竟 Facebook 每次弹出的消息都会占据员工的工作时间。

而 Workplace 发布的初衷就是让员工方便沟通的同时又不至于影响工作。有鉴于此，Workplace 并不要求用户使用个人账号登陆，并将信息流限制为仅支持企业公告、备忘录和通信，而且 Workplace 中不会出现任何广告。企业员工可以建立自己的个人资料，通过信息流查看其它同事的动态更新。另外 Facebook 也将会引入算法，根据重要性展示其它同事的消息。

除此以外，作为一款企业协同工具，Workplace 还提供一些诸如报表分析、统一身份认证和信息集成的功能。

![](../Images/daa43bf43c229499cb34e3d1ca6dd709.png)

据该项目负责人介绍，Workplace 并不是一款仅仅只针对办公室白领的软件，他们想要吸引的是更广泛的用户，包括工人、船员等一些不常在办公室工作的人群，他们可能会在私下使用 Facebook，但却很少会使用工具来帮助自己进行企业协同，如果能吸引到这批人，那将会是很大的市场。

根据 Facebook 的官方声明介绍，在全球已经有超过 1000 家企业正在使用 Workplace，产品覆盖最多的国家包括印度、美国、挪威、英国和法国。

其实在 Facebook 之前，除了 Slack，类似的软件还有微软的 Yammer，Salesforce 的 Chatter 等等，企业办公领域俨然已经成为一个红海。

在这个领域，Workplace 不是入局最早的，但是他们希望自己能够凭借低价策略和 Facebook 久经验证的用户友好性来抢占高地。

它会成功吗？我不知道，这只能留给时间去回答了。

但唯一能确定的是，现在任何的企业通讯软件都还不能彻底的取代电子邮件的作用，虽然不少国内外的企业协同工具在宣传自己的产品时，都喜欢把电子邮件作为自己的假想敌（Workplace 在声明中也强调了自己的真正对标对象是企业内部邮件），但比起邮件，这些新兴的企业沟通工具还是显得方便有余，严谨不足。用它们来交流一些快速执行的工作事物无可厚非，但如果把整个工作流程交流和确定都用即时通讯软件来完成，还是会给人一种不够安全和严谨的感觉啊。
