# 搜狗输入法推出「快速分享」功能，输入法+搜索是个好主意吗？

如果对各种新应用感兴趣的读者一定在「输入法」这个领域还记得 Google 之前推出了一款新产品，名为「Gboard」。它最引人瞩目的特点就是将「输入法」同「搜索」结合在了一起，使用户不必在不同应用中来回切换。![](../Images/823ccb8c93f3b2e4a0143f6ef6ab537e.png)

通过点击键盘左上方的彩色「G」按钮，你能使用 Google 的搜索功能在输入法的界面内快速获得信息，不必再跳出这个界面专门到 app 或浏览器中去查询某些信息，并且快速将结果分享给自己的好友。不过，出于种种大家都知道的原因，我们在国内还无法轻松使用这款输入法。

不过，搜狗输入法也于近日正式发布了其最新版本，而他们也在这个版本中加入了类似的新功能，它真的能带给你一个全新的体验吗？

## 三大新功能让你在聊天中便捷分享

搜狗这次推出的新功能名叫**「快速分享」**，顾名思义，他们的主要目的就是让用户能够 方便快捷地将内容分享给自己的小伙伴们。在这一点上，搜狗输入法产品经理耿雷表示他们和 Google「在分享上的理念是一致的」。

而他们率先推出了三个功能：**智能唤起**、**主动搜索**和**长按候选词搜索**。

**1\. 智能唤起**

通过情景感知智能呈现，比如当输入如「想吃麦当劳」等字样时，词汇候选区会出现带有「快速分享」符号的关键词。点击关键词后，就会出现和麦当劳相关的信息，比如地理位置，团购优惠券等。

![](../Images/1ba5d1a472574d0bc611c0c5766ac401.png)

**2\. 主动搜索**

点击位于输入法工具栏中点击最右侧的「快速分享」按钮，就会在工具栏上方展开搜索栏。用户可以在搜索栏中输入任何关键字进行搜索，输入法会根据关键字显示最符合的一个类别的结果。

![](../Images/3015eef91886f79a381b67c1f830bc3c.png)

**3\. 长按候选词搜索**

和主动搜索类似，但省去了输入「关键词」的步骤，用户只需要长按候选词就能在主动搜索栏中输入该词进行搜索，结果和主动搜索呈现的结果一样。

![](../Images/58cb52e26184e20334c791a8289013fe.png)

点击具体的这些卡片式内容，他们就会出现在对话框中，点击「发送」按钮就可以将其发送给自己的小伙伴们。

目前，搜狗主要做了餐饮、视频、音乐、地理位置这几种用户使用频率比较高的分类，其中目前接入的也主要是搜狗内部的服务，比如搜索服务提供商当然就是搜狗自己，这也无可厚非。不过，耿雷也表示，他们会在之后接入其他更受用户欢迎的应用和服务。

当内容分享出去了之后，如果对方没有安装相关的应用，那点击内容将会以 Web 的形式呈现；如果安装了，那就会弹出相关 app。

## 不过，你真的会在输入键盘上做这么多事吗？

首先，具体的用户体验我们暂时放到一边，毕竟你究竟需不需要这个功能只有你自己用过之后才知道。同时，为了「尽可能不要打扰用户」（耿雷语），想要找到「智能唤起」功能还不太容易，需要你在设置中自己好好找找。

同时，双方在具体操作上的差别也不是重点，比如 Gboard 会在搜索时向上扩展自己的界面，占据超过屏幕一半的空间；而搜狗则不会改变，只会在原来的那个键盘空间内完成这一切。

然后，我们来讨论一下在输入法中添加「搜索」功能是否是一个好的想法。

让我们先来看看 Google 为 Gboard 拍摄的视频中是如何表述的：

📹 [https://v.qq.com/iframe/preview.html?vid=a0303pilfgq&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=a0303pilfgq&width=500&height=375&auto=0)

根据我自己的操作，Gboard 和搜狗大概能为你减少 5-6 下点击屏幕以及 2-3 次滑动屏幕的动作（以 iPhone 为例），而在时间上大概能减少 2 秒吧。

然而，在我看来，如果你没有办法在搜索体验上做到足够好，那这可能就是一个「鸡肋」功能。道理很简单，因为你的这个举动的主要目的是去获得搜索结果，如果这个目的没办法被满足，那节省的几个点击和几秒钟时间就没有意义。用户不会因为想要节省这一点时间和精力去忍受内容上的巨大损失。

Gboard 暂且不论，搜狗还有很远的路要走。比如电影购票，目前他们在 Android 平台上接入的似乎还只是和他们有合作关系的大众点评。然而大家都知道，在电影票这个领域，大众点评可不是一个有存在感的产品。所以，如果搜狗能将猫眼、格瓦拉、淘票票等多个应用 API 都接入进来，这样用户也许会在合适的聊天情境中使用这个便捷功能。

所以，有兴趣的朋友可以试着去美区 App Store 下载 Gboard 试试看（还不支持中文），然后再试试最新版本的搜狗输入法，看看这种搜索功能是不是对你的胃口。
