# 户外旅行手机没信号？这个「天线」让你照样发短信

十一长假，很多小伙伴可能会结伴出门旅行，一起去些风景宜人不过人烟稀少的地方，感受一下远离城市的宁静氛围。  

不过，出行难免会有分散行动的时候，有时候会遇到信号差手机联系不上的情况。从前的解决方案是对讲机，不过今天，极客之选（微信 GeekChoice）发现了一个能发短信的扩展设备，就算你的手机完全没信号也能做到的——goTenna Mesh。

## 只要手机有电，就能发出消息

goTenna Mesh 外表看起来就像是一个小接力棒，其实它是一个便携式天线，用途简单明了。就是通过内部的无线电波来和范围内的其他使用 goTenna Mesh 小伙伴进行通讯，你能通过手机发送最多 160 字的文字消息（内部闪存空间可以容纳 100 条左右的消息），或使用离线地图发送自己的位置。

![](../Images/d6befcc46bb68685a60793b0e386e27e.png)

它的待机时间能超过 24 小时，所以即使频繁使用也能有不错的续航。下面的视频很好的介绍了它：

📹 [https://v.qq.com/iframe/preview.html?vid=p0332i9bsau&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=p0332i9bsau&width=500&height=375&auto=0)

使用时，你只需要把这根「接力棒」打开，然后通过蓝牙连接到手机上，打开对应的 app 后，它会借助 1 瓦高频无线电波来和其他相同频段的设备进行点对点通讯。不论你的手机有没有信号，也不管周围有没有信号塔，甚至是当你把手机切换到飞行模式，你都可以通过 goTenna Mesh 的特殊频段的无线电来进行短信和位置发送。

![](../Images/72223d636b5b82fe98897451c85bc908.png)

也许会有小伙伴问了，日常见到的对讲机不也可以进行点对点通信吗，那为什么还会需要这个 goTenna Mesh 呢？

首先，我们日常使用的手持对讲机确实可以进行点对点通信，不过那是语音通讯，而 goTenna Mesh 能让你使用的是文字通讯，这意味着，消息能够被保留，能被读取。而且，使用 goTenna Mesh 还可以将好友们拉到一个对话群中，这样能很方便的看到大家各自的位置并通过短信交流，这一点是对讲机不能做到的，对于团体出外远行非常有帮助。

![](../Images/a6656b29a2c3208fbdcbd654ffd9c0e5.png)

而且，用过对讲机的人都知道，其实一般情况下，距离大约就是 3-5 公里，不过要是站的越高、地理环境越开阔那距离就越远。但是 goTenna Mesh 就不一样了，使用的人越多，就能形成信号成倍放大的效果，每个用户都相当于增加了它的传输距离，所以当大家连在一起的时候，你甚至可以将信息发送特别远的另一个人手机上！每个使用 goTenna Mesh 的人就好像是接力棒一样，让连接的距离更远，这是它区别于传统对讲机最大的地方。

![](../Images/810e13ddcc4b862ded0756624afe0a4c.png)

## 不止是旅行，它能有很多想象空间

我们说 goTenna Mesh 区别于对讲机的最大不同就是它是通过发送短消息和位置信息来进行交流，所以这种情况下，它不光可以为外出旅行的人提供方便，其实在人群拥挤但是信号很差的地方，尤其是在遇到突发灾难（比如地震泥石流等）的时候，都可以用到这样一个设备来进行位置确定和信息交流。和传统的对讲机来比，这是它的一个天然优势。

![](../Images/d9ab1d2b5d5d7407c605401e03d302fd.png)

所以，本质上来说，传统对讲机存在了这么多年，没有人去想在这种情况下发明一种能发送短信的「对讲机」真的是不科学的。现在终于有人能把这种东西做出来了，这确实是一件好事情。

goTenna Mesh 产品实际上是这只年轻的队伍做出的第二代产品。相比起第一代，这一代的价格更亲民，而且外形也更好看了，想必能够吸引到更多人的目光。

![](../Images/ab235bac06097b16302bfc504e1fc7e4.png)

就好像最早的手机只能打电话，之后才慢慢添加上了发短信、拍照、录音的功能一样，goTenna Mesh 和语音对讲机之间如果能够结合起来，在中短距离通过高频无线电进行交流，那么想必会是非常有应用场景的设备。所以，虽然现在的 goTenna Mesh 只能发送短信和地理位置，但说不定将来就能发语音了呢？

## 价格&购买方式

goTenna Mesh 目前正在众筹（点击阅读原文），价格 129 美元一对（约合人民币 860 元，单个就是 430 元）。说实话，这个价格要去买一个好一点的对讲机还是比较困难的，所以看起来，还是比较值得的。

不过需要注意的是，购买了 goTenna Mesh 的硬件之后，官方配套的手机 app 是需要额外收费的，价格为一年 9.99 美金（约合人民币 67 元）。如果你正好想要在假期和小伙伴一起出游，想要买一个对讲机，那么不妨试试这个能发短信的「对讲机」，说不定会更适合你呢？
