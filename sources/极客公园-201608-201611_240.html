乐Pro 3 

每一个手机「新品牌」面临的最大的难题都是「产品」，乐视就是在那样的质疑声中一路走到乐Pro 3 的。然而中国手机市场有它自己的特色，「性价比」向「质价比」过渡的阶段里，乐视已经卖出了超过 1700 万台手机。

当然，乐Pro 3 依然是一部「很乐视」的手机，光看硬件配置和定价就有了足够充分的购买理由。似乎在乐视身上，「价格屠夫」这个词已经被用烂了，但它真的依然是很多人购买冲动的来源。

所以，在看到乐Pro 3 时候我是很意外的，因为我想当然地预期乐视什么都不会变，但它除了坚持「ID 无边框」之外，居然真的在很多地方改掉了用户不太喜欢的东西。

一点点开始讲究细节

乐Pro 3 无疑是乐视做过最好看的手机，外观、工艺和尺寸都是以往所有成功经验的集合。虽然乐视把 乐Pro 3 定为了一个新的系列，但还是一眼就能看出很多乐视特别的元素。

比如，乐Pro 3 依然是一台坚持了「无边框 ID」的乐视手机，关于这一点已经有了太多的讨论，息屏美学和边框跑马大家都已经耳熟能详了。不过，需要指出的是，如果不论每个人看着的感受如何不同，乐Pro 3 上的「黑边」已经是乐视最好的水平了，横向对比其它品牌同价位的机型也算不上过分「宽」。

不过这一次乐视终于在乐Pro 3 上增加了 2.5D 玻璃，这在乐视手机上是头一回。乐视极致的「无边框 ID」在之前的产品上都有些刮手，而这一次终于在屏幕边缘顺滑了起来。

虽然乐Pro 3 的 2.5D 弧度并不是很深，手感上比 iPhone 还是要差一些，但乐视没有固执还是让人欣慰的。

乐Pro 3 是一台金属占比很高的全金属手机，机身背面没有延续乐 2 系列的三段式结构，而是一体金属加注塑天线条的工艺方案。乐Pro 3 上下各有一条天线条，并且做成了和机身接近的颜色。这个从 HTC M7 开始出现的方案现在似乎成了手机产业的新宠儿。

因为加入了全功能的 NFC，所以乐Pro 3 在机身背后上面的部分还增加了一条竖着着的短短的注塑天线条。这个我们之前在一加 3 上已经见过也比较熟悉了，在我们的调研中绝大多数用户还是愿意牺牲一些外观的简洁度而换来 NFC 的。

我更愿意把乐Pro 3 上的这些细节形容成「开始讲究」，或者，可以拟人地说成改掉了一些臭毛病。乐Pro 3 上还是有不少其它的部分是乐视用户都很熟悉的，比如背面的「乐镜指纹」、略有些突起的摄像头。所以，乐视还是在坚持一些东西，不过至少剩下的「坚持」不太会让人困扰了。

更温柔的拉丝抛光

2016 年手机圈流行趋势之一，是拉丝抛光，它成功贯穿了各大品牌从高端机到千元机的全线产品。虽然大家的方案都差不多，但仔细感受还是有些区别的。

乐Pro 3 是乐视第一次尝试拉丝抛光，乐视把它叫做「金丝蜡抛」。这种工艺看上去比金属更亮，摸上去比金属更润，算是目前金属上一种比较「高级」的处理方式。

在我们拿到的四种颜色乐Pro 3 里，反而是原力金的版本在拉丝抛光之后最为好看，这也几乎成了大家经常吐槽的土豪金在手机上最好的样子了。乐视从上一代产品开始使用的多巴胺红也依然存在，不过，拉丝抛光之后似乎并没有为它加分太多。

当然，同样是在金属上做新的加工，乐Pro 3 和 iPhone 的亮黑还是有差距的，苹果的磁流变抛光工艺几乎完全改造了金属。

值得一提的是，乐Pro 3 的金属机身侧面也是有拉丝抛光效果的。不过，侧面的拉丝效果和背面一致，但抛光并不像背面那样精致。手指滑过机身侧面能保证和背面一样的顺滑，这种连贯的感觉还是很加分的。

另外，乐Pro 3 在背面弧度和侧面的连接处也有一道 CNC 亮边，厂商们总说这会增加金属感，但其实大多数用户会觉得这样的处理「有点俗」。不过乐Pro 3 的亮边是顺着背面弧度切的，握持的时候并不会感觉太突兀。

我是一个接触过所有乐视手机的用户，所以当我正面看着乐Pro 3 的时候，感觉是十分熟悉的。但当我把乐Pro 3 拿在手上，背后拉丝金属的质感和正面 2.5D 玻璃的手感会给我一种很强烈的暗示，这是乐视做过最好看的手机。

这个时候其实我已经忘记了它在 1999 价位实现了骁龙 821 和 6+64 的顶配，这种情况在乐视的手机上还是第一次。
