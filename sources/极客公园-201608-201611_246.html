图片处理 

距离当时 Prisma 的火爆已经过去了 2 个月，这期间出现过无数款山寨 Prisma 的应用，但基本上都拾人牙慧毫无新意。直到前两天一个叫「Ostagram」的工具出现，挖屁屁君我真的被惊艳到了。老实说，要是 Ostagram 早 2 个月出现根本不会有人理 Prisma。

简单来说，Ostagram 相当于一个开源的 Prisma，你可以玩得更炫更炸裂。

相比 Prisma 用给定的模板制作图片，Ostagram 采用的则是 Deepmind 的算法，用一张图片的风格去重绘另一张图。说直白一点就是把两张图片融合起来，用前一张的风格加上后一张的构图。

不过「Ostagram」并不是一个 App，而是一个网站，注册就能使用。

网址见文末

开源版 Prisma，更炸裂的效果

说到图片加工处理，这款 Ostagram 和想象力更配。

Ostagram 其实本质上还是和 Prisma 一样的东西，但就巧妙在它把画面重绘风格的选择权交给了用户，你可以用任意两张照片进行合成，不必再用给定的模板。直接来说就是：这下就厉害了，只要你有想象力又有合适的图，一张图够你吹一辈子。

废话不多，看几个网友吊炸天的作品：

就像上面介绍的，这个工具是通过风格识别两张图的内容，然后用一张的画面风格作为背景，另一站的画面内容来构图，所以这里的诀窍就在于选择背景，背景图片的风格直接决定了图片生成的效果，所以找到合适的背景图可以瞬间让作出的图片效果逆天。

玩好 Ostagram 的诀窍

除了选择合适的照片之外，要想用 Ostagram 做出「一张吹一辈子」的图片另一个关键的地方就在于两张图片的权重调整。Ostagram 比 Prisma 的制作过程要稍复杂一些，多了对两张图片不同权重的调节，直白说就是调整两张图在最后生成的画面中风格的明显程度。

这两个选项需要在图片生成之前选定，分别是 Style scale 和 Style weight，在调节界面中也有直观的效果解释，让你一眼就知道调节当前数值会如何影响最后图片的生成效果。

注册和使用小贴士

因为 Ostagram 不是 app 而是个网站，所以使用 Ostagram 需要事先注册，过程倒是很简便，通过邮箱或者 Facebook 都行，或者你也可以通过俄罗斯最大的社交网站 VKontakte（如果你有账号的话）来登录。

有了自己的账号 ID 后就可以开始创作了。创作流程相对有一点复杂，一次添加两张照片并选择效果强度，然后就可以等着出效果了（时间可能稍有点久）。不过做图片也不是全都要自己准备，Ostagram 也提供了的一些通用的模板，这些模板有的是官方的有的则是某些用户自己创作的。

另外要说的就是 Ostagram 最基础的做图功能是免费的，但要是想制作高清图，想有更多可调节的效果那么则需要付费。

普通制作分为三阶——Free、Premium 和 HD，功能更多的效果收费也更多。

Premium 是 1 张 1 刀！（对，没看错，一张一美元），不过账户充值有一定优惠。而 HD 则更是根据图片重绘的工序复杂程度来收费，更不知道要多少钱了，搞不好做张图就弄得卖房卖地的……

其实话也不用说太多，相信想用的人看完最上面的效果展示就已经忍不住想要试试了。这款工具的效果确实很棒，同时给了用户更大自由度和更多的可能。

比起 Prisma 的傻瓜式操作 Ostagram 有一点麻烦，如果你很想试试做一张能吹一辈子的图的话，不妨试试。
