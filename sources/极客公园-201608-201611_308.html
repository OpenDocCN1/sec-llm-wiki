乐 Pro3 

提起智能手机「堆料」，可能不少人会先想到是小米。

在成立之初的几年，凭借着远超同价位竞品的硬件配置以及独特的在线销售模式，小米几乎把「堆料」这件事做到了极致，让小米手机成为超高性价比的代名词。

但「小米模式」也是有它的底线的：手机虽然便宜，但在整个的产品销售周期中，是必须要赚钱的（初期赔的要在中后期赚回来）。这也符合基本的商业逻辑，毕竟在增值服务无法带来足够多利润的情况下，靠卖手机硬件赚钱是理所当然的。不过有一家公司却不怎么想，它就是乐视。

或许你不太认同乐视的商业模式，或许你依然搞不明白「生态化反」究竟是什么东西，不过依仗着背后丰富的视频资源，乐视几乎是国产手机中唯一一家敢赔钱卖手机的厂商。而在刚刚发布的乐 Pro3 上，乐视又把「堆料」这件事做到了「极致」。

先说重点，我们来看看乐 Pro3 的配置（大家注意标黑的地方）：

· 屏幕：5.5 英寸、1080p LCD，In-Cell，80% NTSC 色域，2.5D 玻璃；

· 机身尺寸：151.4 x 73.9 x 7.5 毫米；

· 重量：175 克 ；

· 处理器：高通骁龙 821（最高主频 2.35 GHz）；

· 运行内存：4GB、6GB 可选（均为 LPDDR4）；

· 内置存储：32GB、64GB、128GB 可选（均为 UFS2.0），不支持 Micro SD 卡；

· 前置摄像头：800 万像素，单位像素 1.4 微米，76.5 度广角；

· 后置摄像头：IMX298 CMOS，1600 万像素，f/2.0 光圈，无光学防抖；

· 电池：4070 毫安时（典型值），标配充电头最大功率 24W，支持 QC3.0；

· 操作系统：EUI 5.8，基于 Android；

· 其它：有 NFC，有红外，双卡双待全网通，USB Type-C 接口，无 3.5 毫米耳机插孔，立体声双扬声器（其中一个扬声器集成在听筒中）；

第一款能买到的骁龙 821

大家对骁龙 820 这颗 SoC 应该已经熟悉得不能再熟悉了。

继在去年的骁龙810 上栽了个大跟头之后，高通通过骁龙 820 在今年强势回归。

在目前市售上的旗舰手机中，除了采用自家处理器的苹果、华为以及三星 Galaxy S/Note 的部分版本（采用猎户座 8890），几乎都清一色地使用了骁龙 820。

骁龙 821 是 820 的小幅迭代版本，二者之间的关系类似两年前的骁龙 805 和 801。CPU 方面，骁龙 821 沿用了 820 上采用的高通定制Kryo 架构，主频上有所提高，GPU也同样是和 820 一样的 Adreno 530，但性能有所提高。高通表示，「骁龙821的CPU速度提升可高达10%，功耗可以进一步节省高达5%，GPU速度也提高5%。」此外，骁龙 821 还进一步提高了内置的ISP （图形信号处理器），可以实现更大范围的激光对焦，支持双相位对焦，并进一步提高了对双摄像头甚至多摄像头的支持。

除了性能上的升级，高通表示，「骁龙820和骁龙821是一个完全兼容的软硬件设计。」市面上正在销售的骁龙 820 手机可以直接换成骁龙 821，无需重新开发。 可预见的是，近期会有大批采用骁龙 821 的新手机或者「新瓶装旧酒」的「旗舰机」推出市场。

回到今天的主角，在乐 Pro3 之前，华硕已经推出了搭载骁龙 821 的 ZenFone 3，不过在华硕昨天召开的国行版发布上，第一批上市的 ZenFone 3 并没有采用骁龙 821 的版本（售价高达 4999 元的 ZenFone 3 尊爵版用的是骁龙 820）。不出意外，乐 Pro3 应该是第一款可以在市场上买到的骁龙 821 手机。

「堆料」不止于骁龙 821

除了骁龙 821，乐 Pro3 的硬件配置还有其它几个地方同样值得关注。

乐 Pro3 的电池容量达到了 4070 毫安时（典型值），不过它的机身厚度仅有 7.5 毫米，机身重量也控制在了 175 克，在这个电池容量下算得上「轻量级」选手了。

值得一提的是，乐 Pro3 并没有因为「薄机身 + 大电池」而影响充电速度。乐 Pro3 标配的充电头最大功率为 24W，支持 QC3.0。经过我们的实测，在手机没电关机的状态下，乐 Pro3 的充电功率可以达到 19-20W。

另外，乐 Pro3 的后置相机的 CMOS 为 IMX298，这颗 CMOS 已经广泛使用在国产的中高端手机中，成像素质优秀。遗憾的是，乐 Pro3 的相机没有配备光学防抖（乐 Max2 是有光学防抖的）。实际体验中，乐 Pro3 的相机表现不错，达到了 IMX298 应有的水准，不过相比一加 3 还有一定的差距，在国产手机中算得上是准一流水准了。

需要说明的是，乐 Pro3 依旧没有 3.5 毫米耳机插孔。想用耳机听歌的话，要么使用标配的 Type-C 转 3.5 毫米转接头，从 Type-C 接口接入模拟音频信号，要么就是购买乐视的 Type-C 耳机，从 Type-C 接口中输出数字音频信号，使用耳机中的 Codec 转换成模拟音频信号（也就是乐视所谓的 CDLA 无损数字音频）。

外观很「华为 P9」

用一句话概括乐 Pro3 的外观：它就像是「乐视 + 红米 Pro + 华为 P9」的结合体。

这样形容乐 Pro3 并不是贬义，手机外观演化到这份上，除了三星的双曲面屏，很难做出明显的区分度。在这种背景下，使用相对成熟的工艺、集合多家之长，不失为一种稳重、聪明的做法。

红米 Pro（左）和乐 Pro3（右）

乐 Pro3 的正面很「乐视」，听筒旁边的前置摄像头和传感器对称分布，底部依然是三颗实体触摸按键，不点亮背光的情况下完全看不出来。乐 Pro3 的屏幕选择了主流的 5.5 英寸 LCD，虽然依旧是「ID无边框」设计，不过边框宽度控制得相当不错（这次是真的窄），比同尺寸的红米 Pro 窄了一大圈（如上图）。

乐 Pro3（左）和乐 Max2（右）

乐 Pro3 采用了一体全金属后盖，上下两头都是金属的，天线条为纳米注塑处理，工艺水准明显比「中间金属、两头塑料」的乐 Max2 高出一个档次。

拉丝（左）和喷砂（右）处理的乐 Pro3

在背部处理上，乐 Pro3 提供了两种不同的方案，「4GB + 32GB」所有三个颜色以及「4GB + 64GB」的「爵士银」采用的是喷砂处理，而「4GB + 64GB」的其它配色以及「6GB + 128GB」的所有版本采用的是金属拉丝抛光处理。

iPhone 7 Plus（左）和乐 Pro3（右）

喷砂处理的我们就不多说了，市面上大多数全金属手机用的都是这种方案（包括亮黑配色之外的 iPhone）。拉丝抛光处理目前用的机型还不错，剩下两款采用该工艺的是红米 Pro 以及华为 P9（金色高配版）。由于机身尺寸和背面弧度比较接近，拉丝处理的乐 Pro3 看起来和红米 Pro 颇有几分相似，不过在细节打磨上，乐 Pro3 要更加精致。

乐 Pro3（上）和红米 Pro（下）

在红米 Pro 的体验中我们提到过，虽然它背面的拉丝抛光处理得不错，但没有任何弧度的边框和生硬的亮面倒角让它的握持手感比较一般。乐 Pro 3 似乎从红米 Pro 中汲取了经验，虽然依旧使用了 CNC 切割的亮面倒角，不过乐 Pro3 倒角的是和后盖边缘的弧度接在一起的，摸上去基本不会有刮手的感觉。另外，Pro3 的边框部分还采用了弧面设计，并且和后盖一样进行了拉丝抛光处理。

经过了这些改良之后，虽然乐 Pro3 看起来很像红米 Pro，不过握持感要明显好一些。拿在手里，乐 Pro3 的手感其实要更加接近华为 P9（金色高配版），而 P9 也是我们用过的手感最好的国产机之一。

把骁龙 821 卖联发科 X25 的价？

售价方面，乐 Pro3「4GB 运存 + 32GB 存储」的版本为 1799 元，「6GB 运存 + 64GB 存储」版本为 1999 元。

乐视还推出了两款乐 Pro3 生态定制版，「4GB 运存 + 64GB 存储」售价 2499 元，「6GB + 128GB 存储」售价 2999 元，除了手机之外，生态定制版包含了签名、独家资源、免费观影等额外「福利」。

其中最值得关注的是 1999 元的版本，「骁龙 821 + 6GB + 64GB」的配置让乐 Pro3 拥有极高的性价比，也几乎让目前市面上所有以高性价比为卖点的「国产旗舰」手机变得不再那么超值。

这也恰恰是乐视最擅长的，没有 3.5 毫米耳机插孔？缺乏品牌积淀？当把手机卖到这个价格后，这些似乎都不是事。
