# 「电动剃须刀」？零度智控又曝光新品，疑似手持云台+运动相机

小型化无人机开始逐渐风靡，大疆都按耐不住爆出即将推出一款折叠小型无人机产品 DJI Mavic，而作为第一批发货的小型无人机产品，零度智控的这款 DOBBY 也已经开始入侵人们的生活，目前 2 万台左右的出货量也证明了它在这一市场的热度，也让我们重新认识了零度智控这家公司。  

但同时，零度智控也好像找到了一些节奏感，从谈论技术到将技术快速落地为新品，速度也是越来越快，因为就在 DOBBY 还在开卖的时候，他们最近又曝光了一款即将发布的新品。

**1\. 外形酷似一个「电动剃须刀」或者是一个「甜筒」，这是他们最近流出的宣传海报。**

![](../Images/ab6421213471f72178416db206cc4bd4.png)

**2\. 而零度智控创始人杨建军朋友圈发布一张图片，并附上了:**

> 你可能有运动相机，但是没增稳；你可能有手持云台，但是没运动。没关系，零度智控来了，放心游泳吧。

此前零度智控官方并未透露过相关信息，应该是该公司新品提前曝光。

![](../Images/040ec66327c2e81a891c2223622119a9.png)

3\. 从照片来看，看产品外形类似于灯泡，但由于无参照物，所以无法计算尺寸，不过根据杨建军文字描述，是与运动相机和手持云台相近的产品，预计该产品体积不会太大。同时今天我还收到了「邀请函」：

![](../Images/5b17d14e3c5d09212104e3ab9b26a5f6.png)*基本表达了它能够装进口袋，同时给我一个「wen」应该是稳定的「稳」吧，很有意思。*

所以，基本上综合上面的三个信息，基本上能够大致判断这款产品：手持稳定 + 运动摄影 +「口袋级」体积。同时为了稳定，照片内透明半球内很有可能是「藏」有一个「三轴云台」，虽然体积很小，但以零度智控的能力应该能够做到。  

**从最小可以挂载 Panasonic GH3/4 的 Z1400，以及最大可以挂载 RED EPIC 摄影机的 Z6000 云台，将无人机使用的云台的核心技术产品化也应该是非常轻松的，大疆的 Osmo 也同样是一个很好的例子，而零度智控可能只是换了一个「路径」而已。**

##  智能拍摄？又是高通骁龙芯片？

假设我的猜测对，那么我可以接着猜一下：

如果是拍摄装备，从唯一一张真机图来看，半球形透明罩 + 不可更换的内置摄像头，如果该产品也和 DOBBY 口袋无人机一样使用索尼的传感器，加上机械增稳的话，画质可能为 4K，而且应该会比 DOBBY 好很多，毕竟主打拍摄。

![](../Images/66aed2afe686f0b00f07f132471778c4.png)

另一边，大疆将自己很成熟的无人机视觉技术、云台增稳技术放到了 OSMO 上。而零度智控在 DOBBY 上的自动跟随、多张连拍、定时拍摄等等功能，相信也同样会出现在这款新产品上，所以我认为它也许同样会沿用高通骁龙芯片的解决方案。

**高通骁龙芯片大幅压缩硬件体积的好处，让零度智控在该硬件架构上获得了一些优势和量产的验证，所以他们延续这套架构继续衍生更多产品应该也不意外。**

## 防水的「三轴增稳相机产品」

杨建军在朋友圈中的描述特别强调了「放心游泳」，**所以猜测这应该是一款可以防水的产品。这个设计应该会受到很多「游泳爱好者」的喜爱，因为此前的运动相机虽可以防水，但因缺少机械增稳功能而抖动。**而目前多数手持云台也是不防水的，所以这一独特的需求应该能够切合很多人的应用场景。

图片上的产品没有以往手持云台的长手柄。除了手持拍摄，按照小蚁、GoPro 等运动相机的惯例，这款新产品应该也会与运动相机一样，会有更多配件能够结合使用。

虽然只是根据目前已知的消息和零度智控历来的技术和产品的推断，但这个「电动剃须刀」的外形和可能的应用场景还是很有特点，如果感兴趣，大家可以期待极客之选（微信：geekchoice）之后的测评和试用。
