# 小鹏汽车 Beta 版发布，看叛逆而又务实的「南派造车」力量

提到小鹏汽车，也许很多人都会感到陌生，但熟悉极客公园的朋友们应该还记得，去年我们的这篇报道：[《这家造出接近 Tesla 的国产电动车公司为何能引起互联新贵的关注？》](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=214552960&idx=1&sn=7331d68bf22e1e28aac83b9a9ddd789d&scene=21#wechat_redirect)，大家感兴趣可以点击看看他们去年的情况，这也是去年我们极客加速计划股权众筹的第三期项目。

简单来说，拥有众多互联网大佬的投资，包括 UC 创始人何小鹏、 YY 创始人李学凌等数十位互联网界大咖。而且作为 Tesla 开源技术的第一个中国受益者，这家电动汽车公司去年就已经完成了 SUV「骡车」（MULE CAR）5000km 道路测试。

![](../Images/3cbcdb6b1d32a2d222c951f2ef3f06eb.png)*基于雷克萨斯的原型车，骡车：名为 MULE CAR，是汽车研发阶段的测试车，通常为了测试最关键的动力系统，会将车身部分零件借用其他车型然后拼接起来，好像骡子是马和驴的杂交，所以圈内人通常叫「骡车」。*

其实这些依旧不能让很多人信服，诸多的疑问、猜测也给了小鹏汽车团队很多的压力，毕竟互联网行业有太多的不确定性。但直到昨日小鹏汽车 Beta 版新车亮相，大家心中那「模糊的信任」终于清晰了许多。

![](../Images/13330ded4aabba97f9461181df9cf7d2.png)

## 新造车时代的「南派」风格

也许在去年，蔚来汽车、乐视汽车、和谐汽车、车和家等等这些新兴的互联网汽车公司的出现，让「互联网造车」成为了热门的讨论话题，但即便是互联网造车，依旧需要时间，所以从去年开始更多的公司都是在获取资金和打造产品。但也许游侠汽车饱受争议的 PPT 发布会，无疑是为互联网造车泼了一盆冷水。

在概念炒得火热的互联网汽车圈，小鹏汽车一开始是最少露脸的那一个，在创业前两年里，小鹏汽车团队研究了特斯拉的开源技术，Tesla 的开源让小鹏从底盘设计、电机选型和电池控制系统的开发上都有了非常好的借鉴模板。

于是他们最开始是专注于互联网汽车核心零部件——电池、电机、电控系统及中控大屏的研发，并将这「三电一屏」作为探索技术与供应链布局的切入点。

![](../Images/ebc0ae3dfbc0428b66b9431b5fc42625.png)

所以也许之前的「骡车」还并不能使人信服，但今天发布的 Beta 版新车展示出更多的功能点、细节、造型设计等等都能够体现出这家有互联网基因的公司对于汽车的思考，也算是终于翻过了「PPT 造车」的这一页。

今天看来，他们居然是最早造出实实在在的样车来的那一个。这种「不鸣则已，一鸣惊人」的务实做派，颇具南方广东人的特点，这也算是展现出现在新造车时代的「南派」风格。

小鹏汽车的三位创始人均是车辆工程科班出身：

**·** 创始人兼总裁夏珩，毕业于清华大学汽车工程系，原广汽新能源中心控制科科长，主导广汽新能源汽车及智能汽车控制系统技术开发。

**·** 联合创始人何涛，清华大学汽车工程系硕士，十年新能源汽车研发经验，主导了广汽智能汽车 Witstar 的开发和无人驾驶样车开发。

**·** 联合创始人杨春雷，哈尔滨工业大学自动化专业硕士，曾担任一汽大众电动车项目经理及广汽丰田电动车开发项目经理，大学时代曾夺得亚太区大学生机器人大赛第一名。

会后采访中，夏珩也详细解释了小鹏汽车「务实、开放、叛逆」的「南派造车」理念：

「小鹏汽车一开始就专注于做事、解决问题，不讲概念，也没有提理念、文化和愿景，只踏踏实实做事，每一步都踩实，像没有发酵的馒头。技术学习方面，擅用开源专利，多多博采众长，尤其多学国外先进技术，该学就学。

作为互联网汽车企业，我们骨子里有叛逆的基因。对于百年汽车工业存在的积弊，我们是新的力量，我们会从零开始，打破反对创新的壁垒。作为新的公司，我们有新的灵魂和血液，不要新瓶装老酒，小鹏汽车的企业架构、产品、商业模式都会互联网化，作为这样的新企业，去和体制僵硬、创新乏力的企业相竞争。」

## 更有诚意的 Beta 版新车

如果说去年的「骡车」，更多的是实现汽车功能的样子，哪怕是绘声绘色的语言也并不能描绘出汽车的形态，也并不能让你感受到这家新造车公司的实力，那么这次的 Beta 版本可以说是将他们脑海里的样子真正展现在你面前，将那些对于车的思考放进了汽车中。

![](../Images/6e17d50a72d0cb0f17d774364d84365c.png)

目前，小鹏汽车自主开发的高阻燃液冷电池包，能量密度高达152Wh/kg，电机功率密度达到 14.5kW/L，续航里程可达 300km，并且开发了拥有自主知识产权的控制器。这对于电动汽车行业来说也是一份非常漂亮的「成绩单」。

而关于如何在这么快的时间内做到比较高的电池容量密度，小鹏团队的方案是通过多轮迭代，第一个迭代是电池的冷却，电池的控制本身的迭代，第二个迭代是轻量化技术的迭代。

同时夏珩也表示「实际上我们的技术方案有很多的团队都在做，但是根据我们跟合作伙伴的交流也发现很多团队做了两三轮就有的做不下去了，有的拿着半成熟的东西去赚块钱了，我们一直持续不断的直到现在还在优化我们整个电池包的技术，而且很重要的一点就是我们的合作伙伴给了我们巨大的支持，我们的技术也依赖了很多合作伙伴共同完成。」

此次公布的 Beta 版新车是紧凑型的 SUV，分为两驱和四驱两个版本，0-100km/h 加速性能方面官方给出的数据分别为 7.9 秒（两驱版）和 5.8 秒（四驱版）。

![](../Images/e7ccf4da6aeb5ce6223b091220267ddc.png)

有趣的是发布的时候，这款汽车是从后台自己开到前台又退回去，并没有人驾驶，非常惊艳。但夏珩介绍其实这并不是无人驾驶，也不是遥控的，是事前规划好路线，通过一键启动的功能实现的。在智能功能方面，这款车将会拥有低速跟随、自动泊车、远程召唤等智能功能。

![](../Images/f15aa6ad0e250aadefaaaea09b5ce150.png)

中控台上，搭载了 15.6 寸智能中控大屏和 12.3 寸全液晶仪表，并有全触摸车辆控制、实时路况地图导航、在线音乐、语音交互、仪表信息自主定制等功能。

![](../Images/3cc8f0d49cff7af6a120930a9b00cd2b.png)

除此之外，小鹏汽车还有一个非常特别的摄像头系统，拥有可升降的车顶摄像头、 360 度全景影像及车内高清摄像，搭载的这七个摄像头实时的记录了大量的行车过程中的视频，有一些会用于自动驾驶的开发，还有一些将用于娱乐系统的开发，具体信息将会在量产版本中介绍。

![](../Images/42da0e3da93a54aa41394e3ebe099b6a.png)

## 关于量产和价格

而关于量产，小鹏汽车已与某民营车企达成合作意向，是计划约在 2017 年底实现小批量的生产并且推向市场。同时，夏珩也在接受采访的时候补充说道：

「量产这块我们会跟整车厂合作，跟其他的团队会有一些不同，虽然小鹏汽车整个团队大概有两百人，其中有 70% 到 80% 都是汽车行业的团队，我们跟普通的汽车行业的团队不尽相同的，就是说我们把控很多核心的功能，包括工艺包括质量包括生产前期制造，但是我们会利用很多外包的人与我们合作伙伴的人来做这样的事情。」

而关于大家最关注的价格问题，此次并没有透露，但接受采访时夏珩表示，如果非要找一辆对标车的话，我们整车的性能包括各方面的功能是想跟 Tesla Model 3 对标的，但是我们的成本控制一定会好很多，我现在只能说到这个程度，但是真正的售价毕竟要考虑到多方面的因素，下次活动才会公布。

![](../Images/4b5b68b9369cb03cd73d98ada63a63ad.png)

但结合 Model 3 在美国卖 35000 美元 (人民币 22.6 万)，国内虽然还没有官方定价，但加上各种关税 Model 3 最多也就卖 35 万左右，所以相信小鹏汽车的价格还是会有相当大的想象空间的。

## 更多互联网化的玩法

而除了汽车本身的性能、智能功能之外，在未来的运营模式和商业模式上，小鹏汽车在这次发布会上也透出了一些非常有趣的想法。

**租售结合的共享经济**

未来小鹏汽车除了普通的售卖之外，为了能更好的让更多的人接受这个新品牌，他们呢将会采用租售结合的方式来做，同时为长距离出行提供「换车出游」等服务。

但租售结合则需要大量的资金来做支持，夏珩也表示推出相应的方案前也一定会做相应的金融上的支持工作，未来的汽车一定会跟共享经济进行某种的结合，我们现在做的事情更多的是怎样在产品层次为共享经济做好准备。

**硬件迭代，每六个月进行一次硬件迭代**

目前小鹏汽车很多开发过程中做到了模块化的设计，因为每个产品的生命周期不一样，比如说一些电子产品，像大屏可能过了一两年就会过时，所以小鹏汽车想通过一些模块化的设计，让这个车即使没有整体的报废也可以部分的升级。这在互联网产品里面非常稀疏平常，但是汽车这个产品怎么做到升级也是小鹏汽车该思考的关键。

最后，也许你是力挺 Tesla，或者是不太看好国内的这些新造车力量，不过我都相信小鹏汽车 Beta 版新车的发布不仅仅是体现「南派造车」的力量，同时也能够为期待互联网造车或者期于互联网改变汽车行业的那些人吃下一个「定心丸」。
