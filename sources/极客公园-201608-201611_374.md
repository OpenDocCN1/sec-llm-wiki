# 宅男们的福利：Google 开始在大学校园测试无人机送外卖

所有大学宿舍里的宅男们除了梦想着能将心目中的女神拥入怀中，他们还有一个梦想，那就是不用动弹就有人能将饭送到嘴边，不影响自己 LOL 的进程。

当然，你可以选择叫外卖，不过很多学校的宿舍楼都不允许外卖小哥上楼，你必须自己下楼取；即使送上楼了，你还得打开门去取，也蛮累的。当然，靠室友来做这件事也不是不可以，不过这要考验寝室中的感情是否牢固。所以说，如果有人能开发一种直接就能送到手边的送餐业务，那至少在校园里还是有市场的。

而最近，真的有公司要做这件事了，而它的名字你可能想不到，它就是 Google。

![](../Images/517d81a7a5a37a1f239aada349d4c150.png)

## 以后可以边 LOL 边吃墨西哥卷饼了

这项即将于本月上线的测试性服务属于 Google 旗下的 Project Wing 项目。Project Wing 出自于 Google 大名鼎鼎的 Google X 实验室，它的目的就是去开发出能运送各种货物商品的无人机服务。

他们将会和墨西哥快餐连锁店 Chipotle Mexican Grill 合作，为弗吉尼亚理工学院（Virginia Tech）的学生们提供相关服务。目前美国联邦航空管理局已经批准了这个项目，而这也将是 Project Wing 所要进行的首次商业化尝试。

「这将会是我们第一次为那些真正需要这些东西的人做快递服务」，Project Wing 的项目负责人 Dave Vos 说道。

Project Wing 这次将会使用带有自动导航功能的混合动力无人机，它能像直升机一样升降和悬停。而它将会在停在弗吉尼亚理工学院校园里的 Chipotle 餐车上取餐，再送到具体的学生那里。无人机将会盘旋在半空，并利用绞盘缓缓放下 Chipotle 的外卖食品。

![](../Images/92a5f690ef9afac2330d4146425a7712.png)*正在测试中的 Project Wing 无人机，下面挂着一个包裹*

不过出于安全考虑，并不是所有的学生都能享受这次服务。那些获得了参与测试资格的学生将会在一个被隔离开的空白地点等待无人机给他送餐。

选择食物做首次实验是因为这是一个很有挑战性的事，包装能否经得住飞行的考验？食物在空中飞行过后是否还是热的？这些都要靠这次实地测试来看看。而且 Project Wing 也已经在开发第二代更加精密的无人机了，不过还不会应用到这次测试中。

同时，据了解，为了符合美国政府的规定，虽然无人机将会完全依靠自己飞行，但人类驾驶员将全程在旁边准备接管操作，这样将会把危险性降到最低。

## 众多巨头都想插一脚，Amazon 动作最大

事实上，与大疆主打无人机拍摄不同，众多的科技巨头们都将目光对准了「无人机送货」这个领域。

Amazon 理所当然对这个领域非常重视，他们早在 2013 年就推出了 Prime Air 无人机快递计划。最近，在 7 月的时候，为了测试自己的无人机送快递服务，他们专门和英国政府达成了协议，将会在飞行员可视航线之外的地方测试自己的无人机。不过由于他们没能获得美国联邦航空管理局的许可，所以他们没办法在美国做相关测试。

![](../Images/3bd0b8d081554c4b9ccfcc732c8e5d46.png)

据金融研究公司 ARKInvest 的一项研究显示，Amazon 无人机送快递每件成本约 1 美元，只相当于其当日达快递服务 7.99 美元的一个零头。所以，相信 Amazon 在这个领域会投入更大的财力和精力。

去年 10 月，Google 也开始在澳大利亚开始测试自己的 Project Wing，不过当时他们主要的目标集中在救灾时的紧急输送任务。不过他们显然有更多想要做的事。数据才是他们在这次测试中最想得到的东西。

事实上，Google 已经和 NASA 展开了合作，他们将会和其他相关的组织一起来制定空中交通管制的相关规定。而美国联邦航空管理局也将会从中获得相关法规的制定标准。

![](../Images/46345e345e8eae25497c94bb442d19d8.png)

当然，也不是所有的大公司都想做这件事。上个月月底，百度公司就宣布砍掉了目前外界一致看好的无人机项目，理由是对他们来说「市场价值不够大」。

所以，根据目前的形势看，我们也许在 5 年内就能收到由无人机送来的快递了。你觉得呢？
