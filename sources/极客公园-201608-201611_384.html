Super Mario Run


昨天 iPhone7 的发布会上所有关于手机的一切都在预料之中，过度曝光下没有了任何惊喜。反而是突然出现在发布会现场站台的宫本茂和他的马里奥成了最大惊喜。

在苹果 2016 秋季发布会上任天堂却第一个发布了自己旗下首款国宝级别 IP 的 iOS 游戏，据悉，在宣布任天堂的经典游戏「超级马里奥」将进入 App Store 应用商店后，任天堂美国存托股涨幅超过了 28%。今天凌晨的发布会，或许任天堂成了最大「赢家」。

「SUPER MARIO RUN」还未推出就成功了一半，这款看起来像款跑酷的游戏到底怎么样？不如先来一起简单了解一下：


跑酷吃金币，没想到你是这样的马里奥


从昨晚发布会现场演示的游戏画面看来，SUPER MARIO RUN 的确只是一款简单的跑酷游戏，是的，并且还类似「天天某跑」的横屏边跑边吃金币的设定。其实看到这样的游戏模式我始终是拒绝的，好好的马里奥 IP 竟然被做成了这样的游戏……



并且看着流出的这些游戏截图，我真的不信这是游戏大厂任天堂的手笔，这样的画面感觉似乎连我 5 岁的弟弟都不愿意玩。



So，任天堂你们真的只是来站个台，让股价往上飘一飘的吗?


任天堂要进军手游？


这款「SUPER MARIO RUN」或许是任天堂正式进军手游的一个信号，要知道在此之前任天堂是很少在其他设备上推出自己的游戏的，更何况是马里奥这样的国民 IP。iOS 平台上在此之前也只有过一款叫「Miitomo」的交友软件（相关文章），都不能勉强算是游戏。



相信今年以来大红大紫的精灵宝可梦让人掉下巴一样的成功给了任天堂信号，当这些经典 IP 在端游平台越来越不受待见的时候，迁移到手游端或许是让它们再度发光发热的好方法。


什么时候能玩


只可惜昨晚 SUPER MARIO RUN 只是预发布，真正能玩还要过几个月才行，不过通过 App Store 里面的预约通知功能，你可以先行预约，当正式发布的时候会有推送通知你。

同时 Android 版也是会有的，不过入驻 Google Play 的日期尚未公布，但任天堂方面表示一定是会有 Android 版，所以众多安卓党们的马里奥粉丝们不必太担心。

但要注意中区 App Store 没有，是的，没有！

最后，上面吐槽的这游戏画面不忍直视也的确是事实，好在还有时间给任天堂认识到这一错误并及时改正，但愿正式发布的时候能好一些吧。
