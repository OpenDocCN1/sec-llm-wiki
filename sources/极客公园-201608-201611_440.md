## 因电池事故频发，三星决定推迟 Note7 发货时间  

**来源：网易科技**

三星电子今天表示，由于要对 Galaxy Note 7 手机进行额外的品控测试，因此将推迟该手机的发货。

在声明中三星称：「由于要对产品质量进行额外测试，Galaxy Note 7 的出货时间将被推迟。」据韩国当地媒体报道，本月早些时候韩国用户和其他市场用户已经拿到 Galaxy Note 7，有部分用户声称他们的手机电池发生爆炸。

品控问题如果被证实，将对这家世界最大智能手机制造商造成很大打击，因为该公司指望这款新产品能在下半年维持移动业务的销售势头。

此前三星表示 Galaxy Note 7 的需求远超预期，造成供应短缺并推迟在部分市场的发布。该公司称，将利用一切手段提高产量。去年 Galaxy S6 Edge 的生产问题导致销售令人失望，部分投资者害怕，如果三星不迅速满足 Galaxy Note 7 的需求，同样的情况将再次上演。

在韩国，不计补贴Galaxy Note 7的零售价为98.89万韩元（约合5927元人民币）。今年3月三星还推出了Galaxy S7和S7 edge旗舰手机，取得巨大成功，提高了上半年的利润。  

  

点评：防水加爆炸，放进水里岂不就是深水炸弹？坐等机皇品控归来，最后友情提醒， 充电请尽量使用原装充电器。

## 苹果这个专利很好玩，让 iPhone 配置安全气囊

**来源：cnBeta**

美国专利商标局今天正式宣布了苹果又获得 59 项新的专利。而在这份名单中，一个专利号为 9430077 的专利或许会吸引一部分人的注意力。我们都知道几乎所有的汽车都有装配安全气囊，当发生车祸时，这些安全气囊将会弹出，这可是一项救人一命的发明。在这九年时间里，iPhone 的设计以及功能都取得了长足的进步，但是其屏幕易碎一直都被许多消费者所诟病，那么，iPhone 是否需要一个安全气囊「救自己一命」呢？

![](../Images/ee9e18ac2f1c267a3c6bb6cc4c24eee7.png)![](../Images/881ee780439a0ea87243ef5e1768cff1.png)

这个专利简单点说，就是为我们的 iPhone 配置一个类似于汽车安全气囊的工具。iPhone 内置的加速计届时将会识别我们的手机是否正在跌落，从而在瞬间打开一个气囊，保护 iPhone 免受损伤。当然，这个专利早在 2011 年就已经申请了，不过从目前的情况来看，这个专利要应用到 iPhone 上，还是有不少的难关需要突破。

在 2014 年，美国人在换碎屏智能手机上花费了 235 亿美元，而这其中很大一部分都是 iPhone 用户所「贡献」的，如果我们的 iPhone 真的能在跌落的时候弹出一个安全气囊，相信许多消费者都会拍手叫好，即使没有安全气囊，大家也希望 iPhone，特别是它的屏幕能更加坚固一些。

  

点评：这东西看起来很有用啊，但苹果连耳机孔都不想要了你还指望它加安全气囊吗。。。

  

## 滴滴联手近 50 家出租车企业，未来出租车也可跑专快车

**来源：腾讯科技**

![](../Images/918b65019fa482f852e5745971a3d5e9.png)8 月 31 日消息，滴滴出行宣布已同北京、上海、广州、深圳、杭州、成都、重庆、南京、三亚等十余个城市的近五十家出租车企业达成战略合作，将在智能派单、流量融合等方面展开探索，以提升出租车行业运营管理模式和提高司机收入和运营效率。

据滴滴出租车负责人曹放详细介绍，在技术、服务融合方面，依托于平台的大数据挖掘和计算能力，目前滴滴正在和合作出租车企业探索，在原有「抢单模式」的基础上推出「智能派单」，优先向与滴滴合作的出租车企业开放。系统会综合考虑距离、拥堵情况、运力供需、司机服务评价等因素，自动将乘客订单定向匹配给一位最合适的出租车司机。

值得注意的是，在流量融合方面，目前滴滴出行平台已经可以实现出租车网约车订单和后台系统的打通，可以让出租车司机在承接出租车单基础上，承接网约车订单。不过目前此功能还在测试阶段，具体落地和运营会根据各个企业与地方政府沟通后再确定。

除此之外，滴滴还将与出租车企业在升级企业信息化系统、提升管理效率、探索出租车行业业务创新等方面积极全面合作，未来还将在合适的时机，围绕新能源汽车销售及牌照、汽车后市场、定制巴士、企业用车、政务用车等方面进行更加深入的战略合作。

  

点评：兜兜转转，从出租车起家的滴滴，终于还是和的哥们来了一次世纪大和解。

## 华为 Pay 手机支付服务上线，支持 25 家银行可绑公交卡

**来源：腾讯科技**

继 Apple pay、Samsung pay 之后，国内的「pay」也陆续推出。今日，中国银联宣布，即日起银联云闪付将全面支持 Huawei Pay。Huawei Pay 也是国内首家同时支持银行卡和公交卡的手机刷卡服务。

![](../Images/d6b5c0d0f91b966664d34005e273049d.png)

Huawei Pay 是基于手机内置安全芯片+NFC+指纹识别+TEE 功能的 NFC 全终端解决方案。只要在支持 Huawei Pay 的华为手机上添加银联卡，使用时，无须亮屏、无须解锁，拿着手机靠近具有「银联云闪付」标识的 POS 机，识别指纹，即可轻松快捷完成支付。

目前，Huawei Pay 适配的机型有：HUAWEI Mate S，荣耀 V8（全网通）、荣耀 8。据悉，今年华为将会陆续发布多款适配机型，预计年底会有千万数量级的华为终端支持 Huawei Pay。中国银联助理总裁胡莹表示，华为是银联第一家合作的国内厂商。

截至 2016 年 8 月 31 日，Huawei Pay 合作银行已达 25 家，包括中国银行、中国工商银行、交通银行、招商银行、中国建设银行、中信银行、中国光大银行、华夏银行、浦发银行、兴业银行、广发银行、中国民生银行、平安银行、北京银行、上海银行、江苏银行、包商银行、徽商银行、江西银行、兰州银行、广州农商银行、顺德农商银行、南京银行、长沙银行、东亚银行。华为表示，更多银行也将逐步接入。

  

点评：对银联来说，用户使用第三方支付会为其带来数百亿的手续费损失，而与手机厂商合作，在扩大支付规模的同时，还可以掌握用户消费数据，何乐而不为。

  

## 华硕德国柏林展示 ZENBOOK 3 笔电，神似 MacBook

**来源：cnBeta**

华硕今天在德国柏林举行的 IFA 2016 上展示了今年早些时候发布的 ZENBOOK 3 笔电，并且将它和苹果新款 MacBook 对比，宣称 ZENBOOK 3 更薄更轻。无论是 MacBook，还是 ZENBOOK 3 都采用单 USB C 型接口和一个耳机插孔，没有其他的端口，连键盘的手感都差不多。

![](../Images/99757683cc4dd8b38bbd37a3a81984aa.png)![](../Images/3469056ab73ac3f0c53710e8ff10d0b6.png)

华硕 ZENBOOK 3 选择了最新的第 7 代酷睿 i7 芯片，的 ZENBOOK 3，这意味着它的性能和功耗要好于苹果最新款 MacBook 当中采用的 Core M7 处理器。华硕还没有公布 ZENBOOK 3 确切的规格，但是演示样机采用 1920x1080 分辨，而苹果 MacBook 屏幕分辨率达到 2304x1440，这方面 MacBook 肯定在纸面上击败 ZENBOOK 3。在纸面上。除此之外，ZENBOOK 3 内存高达 16GB，它的重量只有两磅，机身厚度 11.7 毫米。

![](../Images/3069c220f97181fe2c6f7d9913bc7382.png)

华硕还为 ZENBOOK 3 推出了全新触控板，集成了指纹识别器，支持 Windows Hello。这意味着用户可以用指纹登录到 Windows 10，网站和应用程序。华硕今天奉献了大量的时间，将 ZENBOOK 3 对比 MacBook 和 MacBook Air，指出 ZENBOOK 3 比这两款机型更薄，更轻。

华硕 ZENBOOK 3 上市在即，其中顶级 Core i7 机型售价为 1999 欧元（约 2220.99 美元）。

  

点评：在更轻性能更好的情况下，大家愿意买一款 Windows 内核的 「MacBook」吗，留言区告诉我呀。
