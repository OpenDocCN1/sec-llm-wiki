# 正看着直播就能把外卖点了，美国最大直播平台已经这么干了

深夜看直播，总觉得缺点什么，这个时候手边要是有 pizza，啤酒和小龙虾，那该有多好。

近日，为了满足吃货们的这点小小愿望，美国著名的游戏直播平台 Twitch 悄悄上线了一项新功能，Hungrybot。

该功能允许主播在自己的直播间里和 pizza 外卖商合作上线外卖功能，用户如果在观看直播时想定外卖，直接在聊天栏就能搞定一切，从此就再也不用退出直播去找外卖官网了。

Hungrybot 的具体操作也很傻瓜，用户想定外卖时只需在聊天栏键入「!pizza」，就会收到系统自动回复的可供选择的口味清单，并且该清单通常都伴有折扣。一旦用户选择完毕，系统就会自动跳出支付页面，随后支付，完成！整个过程无需跳往任何外部网站，完完全全的懒人操作。

![](../Images/7198ec8cf4ad8aacee5ba4b68f1371ef.png)*用 Hungrybot 定外卖的过程*

除了让用户更方便地订外卖，该功能还支持主播与外卖商进行分成。用户每订购一次外卖，主播都能获得 1 美元的分成，这使大部分主播都更乐于在自己的直播间加入这项功能。

## 从直播衍生服务向外看去

在中国，直播+电商早就不是一件稀奇的事情，极客公园不久前才深入介绍过[这门生意的产生和发展](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652842754&idx=1&sn=99fe0f64ef7949c0021afa4028e117df&scene=21#wechat_redirect)。

然而现在大部分的直播电商，都是电商为主，直播只是一种辅助渠道。正如淘宝和蘑菇街所做的那样。

![](../Images/c2b5ea9b7e79f32317342682359141a0.png)*蘑菇街直播画面*

但 Twitch 本身就是一个纯粹的内容直播平台，在这样一个纯粹的内容平台上添加外卖或电商功能，国内还很少见。

事实上，有不少的直播场景和电商都是有高度藕合性的。除了现在大家很熟悉的穿衣、彩妆与科技导购。图书，体育和美食也都天然具备导流电商的基因。

而 Twitch 的做法则是将直播与服务结合。除了外卖，**在直播衍生服务这条线上其实还有很多机会可以挖掘，例如赛事直播完全可以和赛事竞猜与体彩服务结合起来，一场线下活动直播如果引入了网约车的 API ，就完全可以边直播边吸引用户完成线上到线下的深度互动。游戏直播平台则可以从单纯的内容输出发展到和手游联运，提高用户参与感。**

在这个家家都在试水直播的年代，用户的注意力早就被大幅分散了，越是这种时候才越要站在用户的角度去思考问题，怎样才能让直播的内容更具可看性，怎样才能占据用户最长的时间，给用户最好的体验？

Twitch 在做的事情其实很简单，不过就是用户在观看直播的时候，想要什么，就给他什么，而且是尽可能方便地去给到他，此举不仅取悦了用户，也为平台和主播提供了一种新的盈利方式，何乐而不为？

现阶段所有直播平台面临的最大的问题就是单一的盈利模式和同质化的竞争，虽然粉丝打赏的确是一种较为成熟的盈利模式，但仅凭这一项还是很难达到收支平衡。

而在这样一个百播大战的环境中，谁率先尝试多样化的盈利模式，更早的达到收支平衡，谁才更有可能走到最后。

从这个维度向外看去，直播衍生服务或许真是一个不错的发展方向。
