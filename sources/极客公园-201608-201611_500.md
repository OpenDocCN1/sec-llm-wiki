前段时间，极客早知道报道过特斯拉将要在之后的新车上装配新型的 100kWh 电池上路。就在今天，特斯拉汽车公司终于宣布了两款新产品——Model S P100D 和 Model X P100D。  

## 新电池组让 Model 系列更加强大，但价格也高了

23 日，马斯克在其推特上发文称特斯拉新产品将会很快宣布，在大家的密切关注中，经过改进的 Model S 和 Model X 对外公布，特斯拉股价随之上涨。

![](../Images/fe9110d94378e343c4d88678481edb64.png)

![](../Images/d5f0e3cf2299dfba09a8c9d09ad1c6ad.png)

*马斯克预热推文不久新产品便对外公布*

![](../Images/88555669b7bc3737116bfe48416fe115.png)

*特斯拉股价受新品影响上涨*

两款新车型都搭载了全新的 100kWh 电池组，这是电动汽车首次搭载如此大续航和动力的电池组。

![](../Images/f269c6a583b39590d727c261165f95e3.png)

更新之后，装配 100kWh 电池的 Model S 在极速模式 （Ludicrous Mode）下，从 0 加速到时速 60 英里（约合 96.56 公里）只需要 2.5 秒！Model X 需要 2.9 秒时间。

![](../Images/a3e780c2559ec6006486cc22ebee3f26.png)*Model S 和 Model X 各代速度及价格数据对比*

要知道，在目前市售车辆中，能达到这个数值的汽油车辆有法拉利和保时捷 918 Spyder，但这两款车价格分别为 140 万美元和 84.5 万美元，和特斯拉比较起来价格昂贵，并且它们都不是新款车辆。

同时，搭载新型电池的两款车型续航都得到了进一步提升，达到了 315 英里（约合 508 公里），如此长的续航成绩足以让特斯拉电动车吸引到很多消费者的目光。

售价上，Model S P100D 的售价将为 13.45 万美元，而 Model X P100D 售价将为 13.55 万美元。对于已经预定 P90D Ludicrous 车型、但尚未交货的客户，升级至 P100D Ludicrous 需要花费 1 万美元，已拥有该车的客户则需要 2 万美元。

## 产品升级命名早有准备

其实早在今年三月，一位黑客就从特斯拉系统固件中找到了相关线索，随后特斯拉贴出了一张停在红色 100 分 EMOJI 涂鸦背景墙前的 Model S 照片。但是官方并没有正面回应关于 Model S 新车的任何报道。

![](../Images/e777e6363ff36674a90a8d30192198cd.png)*今年早些时候的 P100D 泄露图*

马斯克希望新型 Model S 能够吸引到更多喜欢传统超级跑车的消费者来购买特斯拉。但他同时指出新型号汽车的产能将会非常低，因为制造这些复杂的汽车挑战很大。

此次新车型公布说明了特斯拉在按照计划完善自己的产品，而按照特斯拉的规划来看，也许我们能在晚些时候看到特斯拉电动皮卡和公交车也说不定！

![](../Images/1014bd391c7e9c313fa255e5ebf1f103.png)*特斯拉电动皮卡假想图*

关于 P100D 的命名，实际上是有其含义的。「P」是指 Performance，意味着车款性能的提升，代表特斯拉的高运动性能版本，类似于奔驰的 AMG、奥迪 RS、宝马的 M 等系列。搭载极速模式 （Ludicrous Mode）的新车 P100D 即在此列。

「D」是 指 Dual Motor （双电机） 四轮驱动，没有「D」就代表车款是后轮驱动。特斯拉上次发布的车款就只有四轮驱动的选择，只有 90D、P90D，没有了 90 的后轮驱动的配置。本次的车型 P100D 就是指采用四轮驱动配置的电动汽车。

## 新型电池组和电气化的进一步来临

![](../Images/1e4a53f46326125090bab24efb1b1d00.png)

虽然投资人对于特斯拉新品反应不够强烈，但搭载新型 100kWh 的电池对于能源结构的推动却无疑让人兴奋。

在我们之前介绍的特斯拉产品线上能将电能储存并且按需使用的 PowerWall 使用的是 7kWh 电池，考虑到美国家庭每天大约 30kWh 的用电需求，那么如果搭载新型 100kWh 电池就意味着，这些家庭可以存储更多电量，足够他们使用 3 天之久，看上去非常可观。

![](../Images/7e16faf17867c8b6c409fb389bcaca85.png)*特斯拉充电墙 PowerWall*

再说回特斯拉电动车，能将电动车续航成绩推进到 315 英里（约合 506 公里）的成绩意味着司机可以从旧金山开到洛杉矶而不需要中途充电。或者说在国内，从北京到天津（单程距离约 139 公里）开一个往返都能有剩余电量。对于很多喜欢电动车尤其是特斯拉电动车的人来说会是一个非常好的消息。

![](../Images/d88dee192a3d1d7a6d06b16f595b6835.png)

*新型号特斯拉续航将能达到 500 多公里*

按照马斯克的说法，电池存储技术的更新是「非线性的」，虽然目前已经将其推进到了三位数（即 100kWh），但想要继续推进还有很多难度，并且产能上还需要依靠超级工厂 Gigafactory 的不断增加（目前每周只能生产 200 块新型电池），但是新型电池真的非常鼓舞人心，我们有理由相信未来电能技术的进一步进化。

**用马斯克自己的话说：「这是非常深远的里程碑，它会帮助全球各地的用户意识到，未来的时代是电气化的」。**
