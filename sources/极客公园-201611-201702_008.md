# 视频 | 红米 Note 4X 上手：多彩金属下的均衡长续航

情人节当天，小米正式发售了千元机新品——红米 Note 4X，我们第一时间拿到了这款产品。

![](../Images/2b07b65345549e766683267d793cd30d.png)

红米 Note 4X 采用了白色的包装盒，盒子正面隐约可以看到印着「4X」，右上角印着存储规格，我们拿到的是 3GB 运存、32GB 存储的版本，这也是目前红米 Note 4X 唯一发售的版本（后续会推出「4GB + 64GB」的版本），售价 999 元，和红米 4 高配版相同。

![](../Images/72dad3348a04f3f56f18c189c7db4077.png)

除了手机，红米 Note 4X 的包装中还附送了充电头、数据线、取卡针等必要附件，没有保护壳。

其中充电头的规格为 5V 2A，实测功率可以达到 10W 左右，我们尝试使用支持高通 QC 协议的快充头进行测试，发现红米 Note 4X 的充电速度并没有提升。

![](../Images/f0a5d7e341507db7ae895231a9370438.png)

红米 Note 4X 采用了一块 5.5 英寸的 LCD 屏幕，分辨为1080P。

![](../Images/7dcf1ac8e58d88c60fd272900cbaa59f.png)

正面的玻璃盖板采用了 2.5D 玻璃，玻璃四周采用了常见的一圈塑料包边，塑料包边略微高出玻璃边缘一点点，摸上去几乎没有硌手的感觉。这种工艺水准在千元机中还是比较少见的，值得称赞。

![](../Images/deae0ee7134eb61be7493751e0a96ba2.png)

不过受限于成本，红米 Note 4X 的边框比较宽，比已经不算窄的红米 4 还要再宽上一点点。

![](../Images/ff9c300f169785f3a4ea92f760fbf3f1.png)

屏幕下方为小米手机常见的三颗实体触摸按键。

![](../Images/8e716a9a8878ac71173180a66d4c737f.png)

底部采用了 Micro USB 接口，没有用上 USB-C。

![](../Images/8e1604d1949366b80ffe35a9f74e2229.png)

红米 Note 4X 采用了千元机中常见的三段式设计，中间部分为金属，上下两块为塑料。虽然没有红米 Note 4 等产品上采用的金属一体化机身上档次，不过在机身细节的处理上，红米 Note 4X 做得还挺用心的。

![](../Images/89456374837f2eede150a248faa8a257.png)

无论是塑料和金属之间的高光槽，还是塑料和金属部分的衔接，红米 Note 4X 都处理得相当不错，没有明显的割裂感，整体的工艺水准优于采用类似设计的魅蓝 Note3。

![](../Images/103a8b7c2e42d594a10d18b7ef4bb802.png)

红米 Note 4X 背面的摄像头和指纹识别模块对称放在闪光灯上下，其中摄像头为 1300 万像素，有相位对焦，无光学对焦，千元机的主流水准。

![](../Images/df717024db742abb036bed155e53d845.png)

配置上，红米 Note 4X 和红米 4 高配版基本完全一样。

二者均配备了骁龙 625 SoC、3GB 运存、32GB 存储以及4100 毫安时电池，这个配置满足日常应用问题不大，但不适合游戏控。另外，得益于骁龙 625 极为出色的能效比以及大容量电池，红米 Note 4X 的续航非常优秀，正常用两天基本没问题。

![](../Images/b791350b980380a1d619551ea6c2acdb.png)

最后，除了常规的金银黑粉，红米 Note 4X 还推出了蓝绿色（初音绿）配色，我们也会在拿到产品后第一时间和大家分享。
