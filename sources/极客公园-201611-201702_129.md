# 看似无聊的耳机行业，今年还能有什么新花样？

相比日新月异的手机行业，耳机领域产品「革新」的速度显然要慢了不少。不过作为一个必不可少的、和我们身体直接接触的产品类别，耳机上的每一个细微改变都将深深影响我们的使用体验。  

买耳机=听歌，这似乎就像数学中的定理一样不能被改变。但在前不久举办的 CES （国际消费电子展）上看到的一些耳机产品，让我真的忽略了它们的音质表现。对于看似无聊的耳机行业，2017 年会有哪些值得期待的变化呢？  

## 完全无线耳机会越来越多

时下我们谈论「无线耳机」时，几乎就把它等同于「蓝牙耳机」的概念。但严格来说，传统的蓝牙耳机只是实现了和手机连接的「无线化」，左右耳机之间仍然被一根耳机线所束缚。

如果把这跟线材也取消了，把电池、蓝牙芯片、麦克风等组件内置在耳机腔体内，真正的无线耳机就出现了。为了区别现在的无线耳机概念，编辑部的小伙伴们习惯把它称为「完全无线耳机」。

![](../Images/5398b9cd8c4cd8144e5783fdd0dac3f6.png)  
苹果 AirPods

随着苹果 AirPods 的推出，越来越多的人开始了解到完全无线耳机的形态。虽然在此之前，三星（Gear Icon X）、摩托罗拉（Verve Ones）等厂商早已推出过类似的产品，功能也不相上下——德国初创团队 Bragi 推出的 Dash 无线耳机甚至可以通过敲击脸颊来「召唤」Siri。但作为业界的「风向标」，苹果 AirPods 「教育市场」的价值显然会更大一些。

作为全年科技圈的「风向标」，通过 CES 展会来判断全年的产品走向是相当可靠的。

在今年的 CES 上，索尼带来了一款完全无线耳机的原型机、LG 展示了最新款的颈带耳机 TONE Free，除此之外还有大量并不知名的产品也使用了相似完全无线方案。相比去年零零星星的展示，完全无线耳机在今年的 CES 上已经有了相当高的「存在感」。

![](../Images/68b1fa10a2ed792a98cbbb636d895cbc.png)索尼的完全无线耳机原型机

而根据一家参加 CES 的深圳 ODM 厂商介绍，他们已经拥有了一套成熟的完全无线耳机方案，只要根据客户的要求增加不同的产品外观（腔体外壳、保护盒）就能造出一款新品了。相信随着各大厂商加入「战局」，上游产业链不断成熟，完全无线耳机在 2017 年将会更多地走进我们视野内。

![](../Images/444591a36c640edf8d97db701b84d09e.png)LIZN 完全无线耳机

就目前的产品表现来看，完全无线耳机的优点和缺点都很明显。

彻底摆脱了线材的束缚，完全无线耳机戴起来会更加自如、轻松，尤其是在运动中可以避免线材摩擦衣服带来的「听诊器效应」。可以预见的是，运动耳机将成为最先拥抱「完全无线」概念的细分类别。

与此同时，完全无线耳机非常容易丢。值得一提的是，今年在 CES 现场展示的完全无线耳机要么被放在了玻璃柜内，要么会安排专人看护，看来「防丢」确实是一个令人头疼的问题啊。

![](../Images/18f174aa73af6a517a17c467cdd768a4.png)LG TONE Free

另外完全无线耳机把电池移到了狭小的耳机腔体内，待机时间往往要比普通的蓝牙耳机要短——这也解释了为什么这类耳机往往会配备一个保护盒，同时兼有充电的功能。

## 听歌只是耳机的「技能」之一

在每年参加 CES 的音频厂商中，声海（森海塞尔）就像是无人机领域的大疆一样，绝对是同展区内最为火爆的那个。本次 CES 声海带来了一款能够录制「人头录音」的耳机 Ambeo Smart Surround。

「人头录音」的效果虽然听起来很惊艳（相信你看过那个理发师的视频吧？），但是录制起来却相当麻烦：首先需要一个仿真人头，然后在它的左右两侧装上录音设备，最后通过后期合成才能获得最大程度上还原「临场感」。这样一套设备不但造价高昂，而且不可能随身携带。

![](../Images/46b3fc1b1383194d47c6b998468e809b.png)声海 Ambeo Smart Surround

Ambeo Smart Surround 巧妙的地方在于，耳机的左右外壳上各有一个麦克风，当你戴在头上时自然形成了一个「人头录音」的环境。你可以借助手机（目前仅支持 iPhone）录制非常具有临场感的音频，而且使用普通的耳机收听也能获得同样的效果。  

![](../Images/993ae9e288cf7ce0abf44ed59d92c698.png)声海 Ambeo Smart Surround

虽然它的效果不可能比专业的设备更好（例如 3DIO 公司的录音产品），但是已经把手机、耳机麦克风的录音效果甩在了后面。在去年的 CES 上，声海首次公布了旗下的 AMBEO 3D 音频技术，一年后声海把它带来了更加「平易近人」的消费级耳机上。  

![](../Images/1f61ac2492fc6ae9d872639f29641ccb.png)声海 Ambeo 在 CES 的体验区

此前，极客之选（微信号：geekchoice）曾经向大家介绍过一款类似的耳机[ Lifelike](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652844949&idx=3&sn=358a44e962eb62ea2f4786d5fd9dce86&chksm=7e6a4e23491dc735c6ef17b79755a51c7dd76c858d503d1a2c1559d6e9b8dce6cfba794b3159&scene=21#wechat_redirect)，它来自于深圳的厂商森声（SCENES）。值得一提的是，这次森声也来到了 CES 的现场，他们的工作人员在听过声海的产品后表示：「效果没有想象中那么好，但是大厂商推出这样的产品对于教育市场是很有帮助的。」

本次 CES 上，我还看到了一款非常有新意的耳机 Tilde，它来自于法国的初创团队 Orosound。与一般的降噪耳机不同，Tilde 可以自由调节降噪的强度，而且可以打开「指向模式」仅收听佩戴者正前方的人声。

![](../Images/2983c3451d7163e33120288378b77058.png)Orosound Tilde

根据 Orosound 的介绍，他们认为传统的降噪耳机功能过于单一，有时候还会因为降噪而影响跟同事的正常交流，所以才带来了这款「可定制化」的产品。Orosound 已经曾登陆了 Kickstarter 众筹平台（159 美元起），预计在今年 5 月份就能发货了。

除了上面提到的这些，在本届 CES 上还能看到很多「不务正业」的耳机产品。

例如以生产制造平板平面振膜耳机见长的 Audeze 推出了一款适配主流 VR 头显的入耳式平板振膜耳机 iSINE VR，它可以提供更加「丝毫毕现」的虚拟声音体验。而英国的老牌贝斯音箱厂商 Ashdown 带来数款内嵌音量计的耳机，看起来非常拉风。

![](../Images/9774f8a1934820e7106ce8b9911a2ad4.png)Audeze iSINE VR 耳机

***![](../Images/7aba1ff83c918890f921af6983aca82a.png)***

Meters Music OV-1 by Ashdown

最近我把自己的 Bose QC35 卖给了同事，进而把 BEOPLAY H9 作为主力的降噪耳机使用。Bose 的降噪效果毋庸置疑，但是后者触摸调节、滑动开关等功能确实非常方便。

在音质上不能拉开太大的差距（或者到达了一定的水平）的情况下，相信更加丰富的功能对于大众来说是很有吸引力的——如果体积能再小一点，能够完全无线话那自然更棒了。

今年在 CES 音频展区「徘徊」后我的感觉是，相比头戴式耳机，入耳式耳机/耳塞反而会更有趣一些，功能上的亮点也更多。耳机的小型化、无线化趋势势不可挡，未来我们再挑选耳机时一定会更多地关注到这些音质之外的属性。

当耳机满足了基本的聆听需求后，我们对于它功能性、外观个性化程度的要求自然也会越来越高。可以预见的是，今年也会看到更多「不务正业」的耳机产品，而它们也会频繁地「跨界」出现在可穿戴、VR/AR 等领域。
