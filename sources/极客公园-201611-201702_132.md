# Roli Blocks 体验：拿着这个小方块，开始你的表演吧

最早的人类是怎样创造出音乐来的？这问题似乎不好回答，但我脑海中时常会浮现起一群原始人拿着木棍敲击石块的样子。也许，当不经意的敲击伴随周围的声音互相悦动，就成为了最早的音乐。  

即便你完全不懂五线谱，没有任何乐理知识，只要你喜欢音乐，都能创造出全新的，属于自己的音乐出来，这就是今天和大家分享的——Roli Blocks。  

今年的 CES 展会上，我们看到了让人眼前一亮的智能音乐硬件——Roli Blocks。通过赋予「敲击」、「触摸」这些古老的音乐演奏形式以新的含义，这家来自英国的公司，用拼凑乐高积木般的魔法可以让你创造出独一无二的音乐。

极客之选在第一时间拿到了这款产品，下面为大家分享一下它的实际使用体验。

## **「如果你是 DJ」**

用手去触摸，发出不同的声音，借着不同的按压力度，音乐就会有不同的表现，当你去滑动，声音变得有动感。这听上去好像是在说 DJ，但其实，这是 Roli Blocks 的使用方法，通过一小块触摸板+一部手机，它为所有喜欢音乐的人打开了新的舞台。

![](../Images/4761257b99d3e1b59a4cd32382b7bb06.png)

不像手机、电脑这样的实用硬件，乐器本身其实是很小众的存在，它甚至没有玩具那样的吸引力让各个年龄段的消费者都能接受。但 Roli 创造出来的这个东西不太一样，第一次拿到它的时候，我还不能确定我这样的音乐小白能不能玩转它，但当它和手机 app 连上，我开始尝试它的时候，才发现它比我想象当中要好玩。

![](../Images/4dba59a25ddd4ca0beea98036328a41b.png)

Roli Blocks 一共包含三个组件，最主要的部分是眼前这个小小的黑色方块，它是一块音乐触摸板，名叫 Lightpad Block，另外两个分别叫 Live Block 和 Loop Block。三者之间都可以通过磁力接口随意吸附组合，而且，如果你买了很多块，也都可以组合起来，就像乐高积木一样。

![](../Images/6b07f6270bcf7c6c97dc6759c57c8426.png)

作为主角，Lightpad Block 的作用就是充当「音乐键盘」，它的大小和手掌差不多，尺寸 94×94×20mm，重量只有 250g。打开开关，连上手机后，你会发现上面有不同颜色的 LED 灯在 5×5 的网格中不规则点亮，每一个色块都代表着一个音阶。在手机 app 上，你可以在一百多种不同的乐器或者伴奏中选择自己最需要的那种（关于 app 的使用我接下来会讲到）。

![](../Images/e69d09822705a03b94249f4fe31a7069.png)

由于这块触摸板支持压感操作，所以当你的手用不同力度按压的时候，它表面灯光会产生不同变化，同时声音也会产生变化，通过重压和轻按得到的声音是不同的，而手指在上面来回滑动的时候，也会对声音产生潜移默化的影响，创造出与众不同的效果。即便你是一个完全不懂音乐的人，在触摸和按压的过程当中，你也能慢慢摸索出来它的音乐变化。下面这段视频就是简单的演奏示范。

📹 [https://v.qq.com/iframe/preview.html?vid=m0358e0y01o&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=m0358e0y01o&width=500&height=375&auto=0)

![](../Images/d960796c7f831ced41e64a3a5e0eac47.png)

Loop Block 则是对创作进行帮助的功能模块，上面配有专门测录音按钮和演奏切换按钮（就是+和-号）。

![](../Images/f68c18a6562bf36ed9cdd77c8263000e.png)

值得注意的是，只有作为主要部分的 Lightpad 配备了一个 Type-C 充电接口，而另外两个模块是不能直接充电的，它们需要通过磁力吸附在 Lightpad 上进行充电。Lightpad 模块充电两个小时，可以持续工作 4 小时，这样的续航能够满足音乐创作者的需求。

## 用「乐高」的方法创造音乐

![](../Images/c5ce45ebf5ca5eb178495d722da89129.png)

Roli Blocks 的所有音乐创作方式，都结合在了这个叫「NOISE」的 app 中，假如你是第一次打开它，应该会有点搞不清状况，不过慢慢摸索，你就会发现它的功能非常多。

首先，这个 app 是可以单独使用的，所以即便你没有购买 Roli Blocks，你仍然可以在上面玩音乐，但是在小屏幕和大触摸板上面创作音乐，体验是不同的。

其次，这个 app 打开会有两个主要界面，它们之间可以互相切换。在主界面中，你会看到颜色接近的小色块整整齐齐的排列在 4×4 的 16 宫格当中，这里每个格子代表着一段旋律，它们都是你录制好的一段旋律。

![](../Images/6ce6f5d5f9e56a268f67e10c4aac85d5.png)

假如你第一次使用了「钢琴」录制了一段，之后又录制了一段「架子鼓」，那么第一个和第二个格子对应的就是钢琴的和架子鼓的乐曲。也就是说，当你将各种练习曲点按的时候，它们能结合在一起，成为一段复杂的音乐。

上方的「Play」「Click」「Snap」和「Volume」代表的含义分别是播放、打节拍、中断以及音量。尤其是选择了「Click」之后，你可以决定拍子的节奏快或者慢，这可以让你的音乐是舒缓还是激烈。

主界面向上滑动，你会看到「表演」界面，这里可以选择各种各样不同的乐器，Roli 内置了包括钢琴、长笛、架子鼓以及萨克斯等一百多种乐器。而界面中的「Play」「Record」「Learn」「Back」按键分别代表着播放、录制、教学和返回，简单尝试几次就能学会如何使用了。

![](../Images/33ba68af3eea0117abd4c5c1eeeb89fc.png)可以选择多种不同的乐器

所有的音乐创作，都像是拼凑乐高积木一样，当你尝试先用架子鼓录下一段音乐之后，再给它添上吉他的旋律，再加上一点萨克斯的声音，当这些不同的音乐融合在一起的时候，你就会发现，原来创作音乐也不是一件很难的事情。

在这款 app 当中，你可以创作音乐，也可以将创作之后的音乐通过 Roli 的平台分享出去，但遗憾的是，目前还不可以分享到国内的社交网络当中。而且，目前也不可以将自己创作的音乐导出，暂时只能够打开 NOISE 的 app 进行收听，官方称会将 app 进一步完善，而且后续也会有更过的乐器加入，希望能够解决这个不大不小的问题吧。

## 一次音乐小白的启蒙之旅

「触摸」这个动作，在第一代 iPhone 发布以后，让人们打开了新的视界。通过「触摸」的不同方式，Roli 让音乐创作又扩展出了新的方向。作为一款面向大众的乐器，Roli 在尝试用尽量简单的方法，让你不但听音乐，还能「玩」音乐，这就是为什么，在 Apple Store，你能看到它出现在展柜上，它是面向所有人的，即便是一个不认识五线谱，没学过任何乐器乐理的人，都能玩起来的乐器。

![](../Images/fe06cabf93f0bb5967576df9b69c4f87.png)在 Apple Store 会有音乐人士进行现场指导

不过，尽管 Roli Blocks 是一款非常好玩，能让人很方便创造出音乐的产品，但它并非完美。首要问题是，与之配套的 app 只有 iOS 而缺失 Android 平台，这让众多安卓用户只能望洋兴叹，Roli 官方上一款产品电子钢琴也是如此，官方表示后续很快会推出 Android 版本的配套软件，目前，你只能通过 iPhone 或者 iPad 来体验它。

![](../Images/bc788ef2145de0d59c9b9e262377e279.png)Roli Blocks 兼容性列表

其次，在 iOS 上，打开 app 后的新手指导做的并不那么通俗易懂。只有在第一次打开 app 的时候告诉你一些最基本的操作方法，当你开始上手尝试的时候，你或许会对界面上各种各样的功能感到困惑，这并不单单是语言是英文的问题，而是缺少足够的新手教程，对于普通用户来讲，这无形中增加了学习成本，尽管一部分用户会通过摸索逐渐学会它的使用，但这让一些原本兴冲冲想要痛快玩一下的人受挫。

![](../Images/e87efd99bbe94597c8d74f097e37be4c.png)新手引导做的还不够丰富

最后，作为一款乐器，Roli Blocks 三件套创作出来的音乐现在只能保存在 NOISE 的 app 中，不能导出，分享则被限制在了 Facebook 等国内无法使用的社交软件上面，这对于大部分喜欢创作音乐和喜欢分享的人来说，是很让人难过的事情，希望在手机 app 上，这些本地化功能会越来越完善吧。

![](../Images/745e1aa93ebc317d5cc426313acf5fb0.png)分享功能还不够完善

如果你完全不懂音乐，但偶尔也有冲动，想要创造点充满个性的音乐，那我非常建议你先试一试官方的这个配套应用「NOISE」，它在功能上几乎就是一个虚拟版的 Roli Blocks，只不过没有那么「真切」的触觉反馈。而如果你就是一个痴迷音乐，同时又在创作音乐的人，那么相信 Roli 能带给你更全新的体验，丰富你的创作，这恐怕是其他乐器所不能有的新感受。

目前，Roli Blocks 套件在 Apple Store 有售，Lightpad 模块售价 1548 元，Live 和 Loop 模块售价 698 元，当然，你也可以在线下商店体验。

所以各位，拿起 Roli Blocks，开始你的表演吧。
