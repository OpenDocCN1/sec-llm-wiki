# VUE 邝飞：给视频加滤镜这件小事背后，有着你想不到的产品逻辑

在图片之外，短视频已经成为社交网络中的下一个分享热点。但是和那些经过用心调色和滤镜加持的图片比起来，社交网络里的那些小视频大部分还粗糙地像在「裸奔」。  

晒图片和晒视频之间的差距难道真的不能弥补么？在 VUE 联合创始人兼 CEO 邝飞看来，要给视频加上精美滤镜这件小事，背后的产品逻辑也许并没有你想象的那么简单：「视频是比照片更加灵活的表达形式，但是从一段视频到一段精致的影片，这又是另外一个维度的事情。」

**滤镜是否越多越好？拍摄功能是否越专业越好？对这些关键问题的选择和取舍，也许恰好构成了一个视频滤镜产品能否成功吸引用户的关键。邝飞为 VUE 选择的是一条「精致」、「简约」的产品路线，在他看来，VUE 的秘诀是「少」和「好」。所以这款产品最大亮点就是能让用户以最「傻瓜」的方式拍摄一段精美短视频，这也让它成功登上了超过 120 个国家地区 App Store 的编辑推荐。**

下面是邝飞在 GIF2017 大会上对于 VUE 产品逻辑的解读，读完它，也许你能更加理解是什么让这款专注滤镜的产品得以「意外走红」。

* * *

大家下午好！我是邝飞。我们是一个今年新成立的一个团队，我们的产品 VUE 也刚刚面世不久，它的功能是帮助没有创作基础的用户，拍出一段自己觉得很精致的视频。

也许大家还不熟悉 VUE。我们的产品是 6 月份才发布的，到现在也得到了一些用户的认可，我们非常容幸。

为什么要做 VUE 这个产品呢？一个很大的原因是我自己是一个很资深的摄影爱好者，照片对我来讲非常重要。但有的时候我还是会想，能不能有更好的形式来把我们平常看到的、想到的东西表达出来？照片是一个大家非常熟知的表达形式，而视频可以带来更加生动的表现，但是我想做到的是视频的下一个阶段：那就是影片。

影片是比视频更加精致的表达方式，可是就算是我这样非常有创作经验的人，要做出精致的影片也不是那么容易的。创作一段影片的成本非常高，它要制作出来需要一些很复杂的工具，这些工具对普通的用户来说门槛是非常高的。

所以我们在想，有没有可能让大家能够在手机上拍摄精致视频或者小影片，就像现在大家处理照片一样，让它成为一种记录和分享的基本形式。这就是我们做这件事情的初衷。

不过我当时也会疑惑，这是很多人都想做的事情，大家之前都没有很好的解决方案，我们这样的小团队，到底能不能做到。

![](../Images/28140c5a7512cd1ee047b8fee6e9093f.png)VUE 联合创始人兼 CEO 邝飞

但是现在，我们的产品在世界范围内有好几百万的用户，每天也有数十万的视频被分享出去，他们把影片传到 Instagram、Facebook，或者微博、朋友圈。所以现在我想和大家分享，我们 VUE 是怎么把这件事情做到的，怎么样让没有创作基础的用户用简单的方式生产出非常好的片子。

**出于这样的出发点，我们对产品定的原则就是要用最简单的方式，来创作出最好的片子。要做到这样的目标，其实就要做好两个事情：一个是少，一个是好。**

很多人对少的理解，是我们选择最关键、最有效的事情来做。而我对少的理解，它必须是通用的，比如说我们做一个杯子，它也许既可以喝水，也可以喝酒，也可以用来点蜡烛，甚至还可以用来插花。所以我们认为只做一个杯子就可以了，这样通用的东西就可以做到「少」，这可能是之前很多人忽略的一点。

而「好」这个原则其实很容易理解，要把一个事情做得非常的好，就要对这个事情想的很深入，然后把它做到彻底，把每个点做到最优化。

而我们是怎么在视频滤镜这件小事上做到「少」和「好」的呢？我们的产品仅仅只有 11 款滤镜，这比很多 APP 宣称的几十种、甚至上千种滤镜要少的多。为什么我们的滤镜这么少？因为我们觉得，滤镜越少，面对视频这样一个陌生的创作领域时，用户才能够逐一地试用我们的滤镜，知道每一个滤镜的特点，在他的创作过程中，才能够选择一个合适的路径给自己用，把自己的心思聚焦在自己创作这件事情上。

**最初我们大概设计了有 25 款滤镜，后来经过精简，减到了 18 款，但是我们还是觉得太多了，后来只发布了 11 款。每一次，要把滤镜从一个大的数量减到小的数量，其实滤镜的难度大幅度提升的。因为不同的视频可能需要不同的处理方式。我们拍摄的东西包罗万象，每个人的口味也不一样。要做到「少」又满足需求非常不容易，我们在这里就引入了一个思路：我们的每一款滤镜，都要要求它把不同的物体、不同的场景都能够渲染好。因此我们在调试每一款滤镜的时候都引入了近 200 个真实的调试素材，素材包罗万象。每个进去我们都要根据它的 COA 的状况调整，确保每个东西进来都是非常完整的。**

我们再看看「好」这个层面：一个照片的滤镜直接套在视频上，可能会得到一个非常不好的表现。因为照片是个静态的画面，跟视频还是非常不一样的，视频有延续性，其中也有一些动态的变化。所以我们要根据这个画面的变化和场景的变化改变对颜色的计算。一个专门为视频设计的滤镜，它的复杂程度和考量，是跟照片非常不一样的。

另外我们滤镜的设计还会考虑到颜色上的处理。我们在这里会强调两个词：**清洁**以及**符合人的视觉审美**。所以，我们在处理每个滤镜的时候，都会把它先变成黑白的，确保它非常干净。在这样的情况下，我们要把一些用户在日常审美中不是那么喜欢的颜色转化成用户喜欢的颜色，最后提升这种审美的喜好。

![](../Images/6f2f515a0cae1960d7815aae1e5ff9ce.png)

其实，少和好的考量，除了在滤镜上的设计上，在 VUE 的产品设计细节中都会有所体现。比如，我们的产品仅仅只有 4 项功能，这 4 项功能还有 2 项是必选功能、2 项是可选功能。必选功能是滤镜、分段拍摄。在这种情况下，我们完成一段视频，只需要 4 次点击。在这中间一个小小的改变，带来的差异还是非常巨大的。

所以 VUE 跟传统视频处理 app 的最大区别就在于，用户在创作影片过程中感知不到自己使用了哪些专业视频处理技术，只是觉得最后通过很简单的操作就能得到很好的片子，而不是陷入选择焦虑。

**VUE 想通过非常简单的手段传递给用户的到底是什么呢？那就是打造一个影片是非常生动、真实和有美感的事情。很多人常常会想到，生动和美感是一段好视频应该具备的点，但常常会忽略掉真实这个点。但真实感的好处在于很多年以后，当你看到某个片子时，你可以很快地回到当时的感受中，当你把这段视频分享给你的朋友时，也很容易让别人能够进入你的世界。**

VUE 的愿景就是希望通过这些努力，让更多人加入到拍摄视频这个行业里面来，打造生动、真实、有美感的东西，来记录自己的生活，把这些东西分享给你的朋友。我们希望在我们的帮助下，影片创作能够成为一种新的生活方式。这是我们想要做到的。
