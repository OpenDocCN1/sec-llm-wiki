为什么 CES 上的社交机器人都长成一个模样？

 机器人 

编者按：原文来自于 IEEE，作者 Evan Ackerman，极客公园进行编译。

今年的 CES 展会，如此多的新产品让我们眼花缭乱。我们看到了越来越多的厂商参与到自动驾驶技术的商用中，看到更加轻薄，显示更出色的电视，以及通过各式各样的方法来尽可能监测你活动的社交机器人，它们大多被设计为与家庭成员进行日常互动交流。

有很多人在我们的内容中留言，关于 CES 2017，他们提到了一点，这些不同的，白色社交家庭机器人们，它们长得都很像，而且也让人想起了在 2014 年通过 Indiegogo 平台众筹成功（一共募集了 370 万美金）的机器人：Jibo。

所以如果你也注意到了这一点，我们会试着从新出现的社交家庭机器人 Kuri、Mykie 和 Hub 三款产品与 2014 年出现的 Jibo 做出比较，并从中找到问题的答案：为什么这些社交、家庭机器人会长得相似？

颜色洁白，表面光滑，整体圆弧形设计，大大的头和小小的身体。一只眼睛或者一对眼睛，但没有耳朵和嘴，也没有双臂。大量相似的设计语言可以说几乎代表了社交家庭机器人这一分类的「最终形态」。

那么问题来了，既然这些机器人都长相类似，而我们又能看到时间追溯回 2014 年的 Jibo 也是如此，那么它们究竟是如何成为现在这样子的？

「我们设计了一个非常简洁、现代化的机器人外观，这让它看起来非常友好。」来自 Jibo 的营销负责人 Nancy Dussault-Smith 昨天告诉我，「你要先明白人们为什么会把它们（机器人）买回家。」

2014 年推出的 Jibo 机器人

这个回答和 Mayfield 机器人公司 Kaijen Hsiao（COO）、Sarah Osentoski（CTO）告诉我的内容意思相同，是他们公司制造了 Kuri 机器人。「人们对于要天天放在家里的产品非常挑剔」Hsiao 说，「我们很难去打造让所有人都喜欢的装饰品，而最接近大众的选择，就是极简主义的风格加上简单的白色。而且，如果你想要在产品上隐藏起那些传感器、那么自然会将面板设置成黑色，这样的话，机器人就都有一个黑色的部分。」

刚刚在 CES 亮相的 Kuri 机器人

机器人被设计成表面光滑并且充满圆弧形不仅仅是为了讨好人们的眼睛（还有柔软的材料和匀称的造型），还因为这样做是安全的，尤其是你可能每天都会通过触摸的方式与它进行人机互动。举例来说，圆型头部最容易上下移动和旋转，同时也隐藏了机械部分和电子元器件。

在所有家庭社交机器人当中，头部和身体之间有一个特定的比例。Jibo 的 Dussault-Smith 说，这些都是经过精心考虑的。Jibo 之所以会有一个比身体还大的头，是因为这容易让人们联想到可爱的婴儿，或者动物宝宝。

而对 Kuri 来说，考虑的则是另一个实际情况：机器人需要有特定的高度保证能够通过它眼部安装的摄像头看到家里的情况，为了保证稳定性，头部的尺寸就不能过大。

Jibo 和 Kuri 在机器人的「眼睛」设计也有不同的出发点，「我们的初衷是有一个小小的屏幕上面有眼睛，不过我们做了些疯狂的事情，比如试着隐藏屏幕。」Kuri 的 Osentoski 说，「我们很早就想好了如果你要在屏幕上出现一对眼睛，那当你展示给它看什么东西的时候，你就破坏了这个机器人的脸部，脸不再是脸了。」Hsiao 接着告诉我，「最终，我说如果我们想要给大家看的是一双眼睛，为何我们不做一双实体的眼睛？」

另一家公司不这样想。「Jibo 机器人上面只有一只眼睛的设计是不错的选择。」Dussault-Smith 说，「两只眼睛看起来过于真实，它会给人不可思议的感觉，设计一只眼睛可以让人感觉它是可交流的，而又不至于因为太像人而产生威胁的感觉。」而且，Jibo 自身也有一块能展示各种信息的显示屏。

一边是要努力避免机器人被无意识地拟人化，另一边是我们目前还造不出完全满足期待的机器人，这就成为了一直以来推动社交机器人设计的动力。这也是「极简主义」设计的重要根源——尽可能避免拥有人的属性，尤其是在机器人脸部，但同时要让用户能感觉出机器人是可以进行互动的，可交流的。所以说，把机器人做的越像人，可能不是特别好的主意。

所以你能明白为什么人们喜欢机器人设计成这样的原因，因为这些特点会让人感觉舒适。「白色」能让机器人适合各种装饰，表面「光滑」、「圆润」能让人更加安全，脸部「极简」风格可以更方便人检查和交流，圆圆的头更利于整体构建。假如 Kuri、Mykie、Hub 和 Jibo 这些产品获得成功，我们将见到更多拥有这样特点的机器人。

而我思考的不仅仅是它们在外形上如何相似，比这更有趣的是，它们在外形上为什么还有一系列区别。这些区别意味着它们将会通过各自不同的特点，来和我们产生互动。

从根本上说，Jibo 的 Nancy Dussault-Smith 指出了一点重要信息，「机器人之间真正的区别在于内部。」即便所有社交机器人真的都长得完全一样，它们也做的是不同方面的不同事情。或许其中有些会比另一些更成功，或许它们最终都会找到各自最合适的位置，谁知道呢？这些机器人都还没进入寻常百姓家，所以也许假以时日，我们才能找到问题的最终答案。
