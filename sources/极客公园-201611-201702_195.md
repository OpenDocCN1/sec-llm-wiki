# i-rocks IM6，黑白双色齐飞的平民电竞鼠标

对于游戏迷们来说，艾芮克 i-rocks 这个品牌并不陌生，因为和 WE 战队的合作，所以在众多电竞赛事中，艾芮克一直保持着较高的曝光度，熟悉 WE 的玩家都应该在电竞比赛中听说过它。  

而作为电竞外设厂商，艾芮克旗下的电竞产品价格非常亲民、设计也有个性之处。这一次我们收到的是 i-rocks IM6 幻彩翼游戏鼠标，有「黑红版」和「白色透光版」两个版本，黑色版本的黑红组合以及白色透光版本的银白组合都具有挺高的辨识度。黑色版本的磨砂类肤材质触感不错，而白色透光版的银色亮面+斑点的塑料材质则让人担心长时间使用是否会掉色。

![](../Images/12cf62080a7dd693c66c3986c70dcca0.png)

配置上，两款产品并没有区别，但细节上略有不同。这两款鼠标在线材上也采用了不同的材质，黑色版线材为尼龙，白色透光版线材则是橡胶。对于个人来说，黑红版明显更具有吸引力。

![](../Images/0fa40ac0dd097df9950a4e47df10640d.png)

![](../Images/6cbeae37f5dec65980a4e2dc7b404d98.png)

除了左侧的「前进」、「后退」键外，IM6 的左右几乎完全对称，这种设计与其「幻彩翼」的名称相得益彰，正面除了鼠标滚轮之外没有多余的按键，加上 100g 的重量，让鼠标整体给人的感觉更加「轻盈」，这点在白色透光版上表现的更加明显。

![](../Images/73989e913237057754875196d599839f.png)

游戏鼠标最重要的自然是手感舒适，灯光酷炫。IM6 的整体对称设计和底部三片式脚垫令它的稳定性保持的不错，如果你是一个「趴卧型」、手掌不是很小的玩家，那正面的低弧度会让你在操作时感到舒服。而它的滚轮以及两个侧边的多彩灯光则会让喜欢灯光的玩家感觉到足够酷炫。

![](../Images/1fea7254c025356b9713f50fa943e1c8.png)

和艾芮克之前的游戏鼠标类似，IM6 幻彩翼系列同样在鼠标底部加入了回报率（Polling）和分辨率（DPI）等调节开关。这令玩家每次调整鼠标灵敏度都必须翻转鼠标，而这样的设计在我看来没有将开关放在正面或者侧面来的方便。

![](../Images/7ed461050584f48f2ccddc61a4093670.png)

![](../Images/337cfdbde6a8a213e96882975af2204c.png)

回报率，或者叫做刷新率，就是鼠标在单位时间内向电脑报告的次数，次数越高越灵敏，越少就会出现鼠标跳帧或者丢帧的现象，IM6 可以在 125、500、1000Hz 三挡切换，对于普通玩家来说，最高档 1000Hz 的回报率足够日常游戏中的使用。而分辨率（DPI）就不多说了，IM6 的最高档为 1800，意味着玩家在诸如《守望先锋》这样的竞技游戏里能够做出更快速的反应。

![](../Images/0978cb9ddea0341899f2fc86ea4b4bb3.png)

值得一提的是，IM6 在鼠标底部还拥有背光调整按键，由于鼠标免安装驱动程序，IM6 底部的多彩背光灯就承担起了「开启」「关闭」和「锁定」背光灯的作用。在初次体验中，这个开关很方便。不过还是那个观点，如果能将它设计在鼠标的正面或者侧面，那玩家使用起来会更加方便。  

艾芮克 i-rocks IM6 鼠标一如既往地坚持了其平价、亲民的路线，上市价格为 138 元，目前官方售价则为 99 元。对于一款不足百元的游戏鼠标来说，黑白可选，双色齐飞也算是普通游戏玩家的多一种选择吧。
