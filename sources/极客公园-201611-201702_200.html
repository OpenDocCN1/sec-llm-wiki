 Amazon Alexa 

在本届 CES 上展出的福特汽车、LG 智能冰箱、三星智能扫地机器人、WeMo Mini 智能插座、Airmega  空气净化器、联想智能音箱……

你知道这些不同类别的产品有什么共同特点吗？其实它们都搭载了亚马逊的语音助手 Alexa，可以让我们摆脱双手用语音完成很多设备的操作。

早在 CES 正式开展前的媒体活动上，我们就见到了很多搭载 Alexa 的产品。尤其是音频相关的厂商，会把兼容 Alexa 当做一个特别的卖点。而美国时间 1 月 5 号正式 CES 展会正式开放后，我们更是在各个展馆、各种第三方设备上见到了 Alexa 的标志——大至汽车小到智能手表。

福特汽车和 Alexa 的联动效果

有意思的是，本届亚马逊并没有正式参展，你压根找不到它的展位，但这不并妨碍 Alexa 像空气一样无处不在。

CES 上将出现 700 款 Alexa 设备

本届 CES 到底有多少配备 Alexa 的产品呢？这个答案可能是 700 款。在此前的一个媒体活动上，CTA（ CES 主办方）的首席经济学家 DuBravac 表示亚马逊的 Alexa 目前已经支持 1500 种不同的应用，而接下来的几天会有 700 款搭配该语音助手的设备亮相 CES。

三星的扫地机器人 VR7000 可以用 Alexa 进行控制

另一侧面也可以反应 Alexa 的流行程度：本届 CES 上外媒 CNET 和 The Verge 专门为 Alexa 设置了专题页面，不断更新在今年 CES 上出现的相关设备。

The Verge 网站截图

目前搭载 Alexa 的设备可以分为两类。一种是设备本身配备了扬声器和麦克风，可以直接嵌入 Alexa 的服务。另一种是通过亚马逊的音箱 Echo、Echo Dot 来进行控制，可以实现近似的效果。

Martian 智能手表

其实我们回顾 Alexa 的发展历程，会发现一个从自有设备到兼容第三方设备的转变过程。2014 年底，亚马逊发布了智能音响 Echo，它是首款搭载 Alexa 的设备。

2016 年年初，亚马逊又带来了 Amazon Tap 和 Echo Dot 两款产品，其中 Echo Dot 值得一提。很像去掉了扬声器版的 Echo（虽然 Echo Dot 也有一个小功率的喇叭）。

Echo Dot 的体积比 Echo 要小得多，售价也只有后者的三分之一（49.99 美元），不过它的功能和 Echo 几乎完全一致，保留了通过说出「Alexa」唤醒语音助手的功能。

通过 3.5mm 音频线，Echo Dot 几乎可以让任何传统的音箱变得智能起来，让很多老旧的设备也能享受到亚马逊的新技术。不过真正让 Alexa 变得流行起来，是因为亚马逊把它变成了一个开源式的项目。

语音控制是智能设备的下一波潮流

最近两年，各种各样的设备都通过接入互联网、增加手机远程控制「摇身一变」成为了智能设备。但是环顾我们的四周，真正融入生活的产品恐怕并不多。

问题在于，大多数智能设备只是简单地将一些操作「搬运」到了手机上，或者通过互联网抓取一些公开的信息并分享出来。在使用设备的新鲜期过后，你甚至都懒得再去打开它的 app 了。

远程操作并没有在根本上改变我们与设备交互的方式，只是把点、按的操作从物理世界放到了虚拟的屏幕中。当越来越多的设备接入互联网获得与外部世界的沟通能力后，人机交互反而成为了一个短板。因此各家厂商都在探索更多元的交互方式，而语音就是选项之一。

接入了 Alexa 的智能音响

虽然很多时候你羞于在公众场合使用 Siri 这样的语音助手，但必须要承认的是，语音是人类最为自然的的交流方式。而且盘点 CES 上各种搭载 Alexa 的设备后你会发现，更多的语音应用场景是出现在车内或家庭中，也就是相对私密的空间内。这也就避免了心理和技术（噪音干扰）上的问题。

福特和 Alexa 的合作，请注意左下角的语音标志

更为重要的是，语音交互是当下人工智能技术一个很好的出口。当语音识别和语义理解更加强大后，语音助手能够承担的任务就不只是「控制开关」那么简单了。

为什么 Alexa 能够脱颖而出？

首先，Alexa 找到了一个很好的切入点。虽然从一开始，Alexa 就是亚马逊为了对抗 Siri 和 Cortana 这些对手而研发的，但亚马逊最先将它应用到了自己的音响产品当中，这样反而让用户与 Alexa 之间的交流更方便了。

音箱是一个成熟的产品形态，大家更容易接受；与此同时音箱天然就是一个「输出设备」，只要在增加一个麦克风就能实现人机互动了。

Alexa 现在有成为一个「家庭中枢」的趋势，但它一开始的卖点就是让用户能够用过语音直接控制音乐、电台等多媒体内容的播放。劝说用户购买一个能够「语音点歌」的音箱，显然要比一个能够「控制各种智能设备」的管家机器人要容易多了。

对于手机来说，语音或许没有触摸操作起来更加方便，它更像是一个锦上添花的操作。但对于 Echo 这样的设备来说，语音却是唯一的交互方式——如果你想让一款其貌不扬的音响为你做更复杂的事情的话。

另外，亚马逊对待 Alexa 的态度也更为开放。去年 6 月亚马逊将 Alexa 的 API 都开放给了开发者们，这使得它得以快速地普及，也能帮助 Alexa 更快地成长。

值得一提的是，亚马逊还特别设立了 Alexa 基金，计划投资 1 亿美元去帮助那些中小型企业和初创公司开发 Alexa 相关的技术。CES 上一家音频厂商告诉我，为普通的设备接入 Alexa 的芯片成本低到可以接受，而且亚马逊提供了非常详尽的指导，因此可以非常便捷地完成开发工作。

早期利用成熟的产品形态和必要的使用场景吸引普通用户，随后通过不断拉拢开发者让更多「玩家」加入其中，亚马逊为 Alexa 制定了一个循序渐进的「进化」路程。CES 作为每年科技趋势的风向标，Alexa 能在其中获得如此高的关注度足以引起所有人的重视了。

每年 CES 都被称为下一年里行业的风向标，每年 CES 上的新品都让人眼花缭乱。你一定需要个「懂点门道」的人，拨开云山雾绕，帮你看懂所谓的「黑科技」。
