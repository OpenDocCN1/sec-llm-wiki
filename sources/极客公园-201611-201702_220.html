 共享单车的故事 

我们做了一次关于共享单车的小调查。不涉及商业模式、不牵扯资本融资，希望从最接地气的用户体验入手，找到一些，2016 下半年最火没有之一的，共享单车有关的故事。

一共有 13 名共享单车用户跟我们分享了他们与之的故事，这其中或许也是你的故事。

与共享单车的初次接触

有天发现挺多人在晒「小橘车」和「小黄车」，了解后才知道这是个「共享单车」的新兴概念。广告人得紧跟潮流，下了两个 App 都体验了一番，漫不经心拍照发了朋友圈，给外地没有的朋友们显摆一下。

@John / 25 岁 / 上海某广告公司创意策划

我之前一直骑自己的自行车上下班，但停靠和防盗一直是老大难问题。自己两辆车都防不胜防被盗之后，共享单车成了我的最优选择。

@豆豆 / 男 / 24 岁 / 肾内科医生

你眼中的共享单车

花个五毛钱，解决拥堵三公里。找车半小时，骑行十分钟搞定。原来这就是互联网化的现代生活模式啊。

@雨薇 / 女 / 20 岁 / 互联网公司新入职实习生

够环保主义，够健康生活，这波共享经济 2.0，赞。

@阿南 / 男 / 32 岁 / 品牌总监

共享单车改变了......

摆脱成为地铁里早晚高峰的罐头沙丁鱼，成了潇洒如风的单车少年少女。

@晓萌 / 女 / 22 岁 / 国贸写字楼的白领上班族

现在到周末的时候，我跟老公空余就会骑着 ofo 去隔壁的菜市场，感觉像回到了刚毕业小两口谈恋爱的时候。

@DanDan / 女 / 34 岁 / 市场总监 / 现结婚 8 年

省钱没话说。我的日常使用场景是上下班来去地铁站的两公里。上月我共骑了 ofo 13 次，摩拜 4 次，摩拜 lite 8 次，总计花费 21 元。按照之前的话，我一般打个小黑三轮，上下班高峰一趟得花 10 块钱，一个月就得花 250 块。这钱算下来，还是很可观的。

@明伟 / 男 / 26 岁 / 程序员

共享单车的正确使用姿势

我上周见过一特有意思的事。北京 798 里经常有群年纪轻轻的男孩在玩单车特技耍帅，一般都是死飞、山地自行车。那回我又路过见过有男孩玩特技车抬头，用的是摩拜。当时觉得，小伙子技术不错，劲儿挺大。

@猫猫 / 女 / 24 岁 / 设计师

学校图书馆门口我停下 ofo，隔壁一个女生也在停。「原来你今天也骑小黄车来。」一个屡试不爽的新型搭讪开场白。

@张弛 / 男 / 18 岁 / 爱自习的理工科大二学生

一个共享单车的故事

我现在为躲避拥堵每天就骑摩拜上班。但有一个尴尬的事是，路上总会被好几位骑老式 28 自行车的大爷大妈超车，超车后还回头一个迷之嫌弃，说：「年轻人别虚，骑车得使劲啊。」

@陌陌 / 女 / 25 岁 / 软件工程师

现在国外的朋友来北京玩，又能多了一个常规项目：骑共享单车串胡同。这很北京。

@Max / 女 / 27 岁 / 建筑设计师

ofo 刚上线那会，小区门口的大爷大妈见我总骑，问我好几次了：「杏儿，这车看上不错，哪买的？」后来听说他们一群老人家还集体学习了使用方法，如今都换上小黄车出行了。上回他们集体做功课的时候，还是学怎么发微信呢。

@杏儿 / 女 / 26 岁 / 公关经理

 Q： 对共享单车有啥建议吗？

 A： 12 月的天真的太冻了，骑车冷风刮得脸疼。这才是真正，共享单车的「寒冬」到来。不过多穿点捂住脸就还行，该骑还是骑。

@瑶瑶 / 女 / 23 岁 / 科技记者

如你所经历的，共享单车作为即将过去的 2016 年的高潮话题之一，不仅仅改变了我们短途出行的方式，也改变了我们对共享经济的进一步认识和设想。除了商业价值之外，我们也重视由它卷起的风暴，正在改变着这个世界未来我们的生活模式。
