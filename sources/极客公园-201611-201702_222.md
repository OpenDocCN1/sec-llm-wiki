# 当灯泡有了「夜间模式」，睡觉前终于可以安心玩手机了

「夜间模式」、「护眼模式」已经成为了 Andriod 手机的必备功能，苹果也在 iOS 中加入了类似的设置 Night Shift。 它们的原理大同小异，即通过调节手机屏幕的色温，尽可能地减少蓝色光的强度。

这么做的原因在于，各种设备的显示器所发出的蓝光会让身体误以为现在是白天，从而干扰到正常的作息规律**（具体原理极****客公园 (微信号: geekpark) 后台回复「蓝光原理」即可查看**）。结果呢，就是越玩手机越睡不着，相信很多人都有这样的经历。

对于喜欢在睡前玩手机的「夜猫子」来说，「夜间模式」是一个非常棒的功能。但是相信很多人和我一样，不喜欢在全黑的环境下玩手机（亮度最低眼睛也不舒服），这时候就需要开个夜灯了。  

![](../Images/b25fbbb098a949cb8a03df5fa7eb298b.png)

那么问题来了，我们家中的灯泡也能拥有「夜间模式」吗？

在 CES 2017 媒体日的第一天，美国的 LED 灯具公司 Soraa 带来了旗下首款智能灯泡 Helia，它的特点是能够根据科学的作息规律提供更加健康的灯光方案。

![](../Images/7dfbfcbb1e8f58c382f157c8846c2c03.png)

举例来说，Helia 在晚上会尽可能地降低蓝光不让「夜猫子」在盯久了屏幕后睡不着觉，早上又会通模拟白天的光线提醒我们身体该起床了。

Soraa 的联合创始人中村修二（Shuji Nakamura）曾因对蓝光 LED 实用化做出的贡献而获得了 2014 年的诺贝尔物理学奖。但这一次，Helia 却勇敢地和蓝光说了拜拜。

Helia 使用紫罗兰光 LED 替代了蓝光 LED，可以实现蓝光的「零排放」。根据 Soraa 官方介绍，即使 Helia 灯泡发散淡白色（soft white）光时，蓝光的数值也几乎为 0，这是普通 LED 无法实现的。

![](../Images/16d036f88af54b2963d31195178a2dc6.png)Helia 和普通 LED 灯泡对比

尽管 Helia 听起来只是简单地完成了 LED 灯泡「去蓝光」的工作，但真正挑战的地方或许在于如何调整灯泡处在最舒服的色温下，同时为它赋予更多的功能。

「当你去除了太多的蓝光时，灯泡就非常接近蜡烛的表现了。或许一两次你会很喜欢这样的光亮，但我相信你不会想要永远都生活在黄色的光线下。」Soraa 的首席科学家向媒体介绍道。

Helia 可以按照时间规律控制 LED 的效果，当然你也可以在 app 内手动调节，让它匹配你的作息规律。

![](../Images/ef0969ff552539c5d2282e295ef39f27.png)

Helia 还支持拓展模块（Smart Snap），例如你可以为它配备一个人体监测传感器，当它检测到有人来到房间时会自动开灯。  

需要注意的是，当你购买多个 Helia 后，它并不是利用 Wi-Fi、蓝牙或其他传输协议进行联动，而是通过现有的电力网络进行通信，因此它也具备未来与更多 IoT 设备联动的能力。

![](../Images/8a7710b998d5f64e9294df3bce03cc8f.png)

Helia 的售价为 49.95 美元每只, 智能套件（用于灯泡之间的联动）售价为 29.95 美元，今年春天发售。对了，Helia 支持接入 Echo 和 IFTTT 服务，不过你要额外再花费 50 美元……
