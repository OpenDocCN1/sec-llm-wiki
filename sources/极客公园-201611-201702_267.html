 CES 2017 

智能手机可能是大家最熟悉、关注度最高的产品门类，不过在年初的 CES 上，智能手机的存在感往往不是很强。除了向来不去展会「搅和」的苹果，相比 CES，三星、LG、索尼、HTC 等国际品牌通常更喜欢在二三月份的 MWC 或者九月初的 IFA 上发布旗舰新品。

但这并不意味着 CES 上缺乏值得关注的手机新品。作为一个强调技术和未来趋势的展会，我们时常会在 CES 见到一些「脑洞大开」的产品，比如 CES 2014 上 LG 发布的「弯弯」手机 G Flex。通过这些不太「常规」的产品，我们往往可以洞悉智能手机在未来一段时间的发展趋势。

下面，我们就来盘点一下在即将到来的 CES 2017 上有哪些值得关注的手机新品。

华硕：AR 和双摄像头

近期，华硕发布了一段 CES 2017 的预热短片，视频中暗示了华硕至少准备了两款智能手机新品。

其中最重头的产品应该就是传闻了许久的 ZenFone AR 了。在上个月接受外媒 Digitimes 采访时，华硕 CEO 沈振来（Jerry Shen）就已经确认了这款产品的存在，他表示「ZenFone AR 将会兼具先进的功能和优异的性能，同时价格也会有竞争力」。

从名字上可以看出，这款产品的核心卖点是 AR（增强现实）功能，和早些时候上市的联想 PHAB2 Pro 类似，ZenFone AR 也将支持 Google Tango 平台。通过在背后配备多颗功能各异的摄像头，配合对应的软件，实现一些简单的增强现实（AR）应用。 

除了 ZenFone AR，ZenFone 3 Zoom 也很有可能会同时发布。

ZenFone Zoom

ZenFone 3 Zoom 将会是我们之前报道过的 ZenFone Zoom 的升级版本，预计会搭载骁龙 625 以及 4850 毫安时的电池，续航表现值得期待。

此外，ZenFone 3 Zoom 还会配备双摄像头，可以像 iPhone 7 Plus、华为 Mate 9 那样一定范围的变焦（Zoom）效果。有趣的是，上一代产品 ZenFone Zoom 采用的是 Hoya 定制的移动镜组来实现了真正的 3 倍光学变焦，但这款产品在实现变焦的同时，在成像品质上做了比较大的妥协，ZenFone 3 Zoom 更换成双摄方案，意味着华硕放弃了 ZenFone Zoom 的这种「光学变焦」方案。

至于预计将会搭载高通下一代旗舰 SoC 的 ZenFone 4，由于台积电和三星在 10 纳米工艺上都遇到了比较大的麻烦，至少得等到明年第二季度了，CES 2017 上应该不会出现。

LG：这都是些啥手机？

虽然不会推出下一代的旗舰产品 LG G6，但 LG 在 CES 2017 上会发布一大批新手机，其中 LG 已经公开了五款新品的详细信息。

首先是四款 K 系列新机，具体信息如下。

LG K3：4.5 英寸屏幕，分辨率 854 x 480，骁龙 210（四核，主频 1.1GHz），1GB 运存，前置 200 万，后置 500 万，2100 毫安时可拆卸电池。

LG K4：4.7 英寸屏幕，分辨率 854 x 480，骁龙 210（四核，主频 1.1GHz），1GB 运存，前置 500 万，后置 800 万，2500 毫安时可拆卸电池。

LG K8：4.7 英寸屏幕，分辨率 1280 x 720，骁龙 425（四核，主频 1.4GHz），1.5GB 运存，前置 500 万，后置 1300 万，2500 毫安时可拆卸电池，内置 NFC。

LG K10：5.3 英寸屏幕，分辨率 1280 x 720，联发科 MT6750（八核，主频 1.5GHz），2GB 运存，前置 500 万（120 度广角），后置 1300 万，2800 毫安时可拆卸电池，2.5D 玻璃，金属中框，后置指纹识别，内置 NFC。

除此之外，LG 还会发布内置手写笔的 Stylus 3。

LG Stylus 3 会配备一块 5.7 英寸的大屏，分辨率为「感人」的 720p，联发科 MT6750（八核，主频 1.5GHz），3GB 运存，16GB 存储，支持 Micro SD 卡，前置 800 万，后置 1300 万，3200 毫安时可拆卸电池，后置指纹识别，FM 收音机，内置 NFC。另外，LG Stylus 3 手写笔的笔尖只有 1.8 毫米，可以实现更精确的定位，Stylus 3 还会内置 Pen Pop 2.0 笔记应用，可以更方便的记录信息。

目前还不清楚这些新品具体的售价和上市信息，但定位肯定不会太高。另外，考虑到 LG 在中国手机市场基本没有存在感，品牌溢价也非常有限，LG 的这一票「上个时代」的新机在中国上市的概率不大。

虽然 LG 的手机新品吸引力有限，不过在传统家电上，LG 还是有很多值得关注的地方。

除了新款顶级 OLED 电视之外，LG 预计还会发布一系列全新的智能家电产品，包括扫地机器人、冰箱、空调和洗衣机。据悉，这些智能家电产品可以通过「深度学习」，给用户带来更加优秀的体验，并且会更加省电。

现在厂商发新品时，不提两句「深度学习」和「人工智能」似乎都说不过去了，至于 LG 这次的智能家电到底怎么样，我们会继续保持关注。

黑莓归来，但早已变了味道

由于手机业务迟迟没有起色，三个月前，黑莓 CEO 程守宗表示「黑莓计划停止所有公司内部的硬件研发，转而将其外包给合作伙伴」。而就在近日，TCL 正式成为了除印度、斯里兰拉、印尼、斯里兰卡、孟加拉国等少数国家之外，黑莓在全球范围内唯一的手机制造和分销商。

这件事本身没啥奇怪的，在这之前，黑莓推出的两款 Android 手机 DTEK50 和 DTEK60 就是 Alcatel（TCL 旗下的移动设备部门）的 Idol 4 和 Idol 4S（TCL 950）的「换 logo + 软件定制」版。值得一提的是，这并不是 TCL 第一次购买没落的「贵族」品牌，2015 年初，TCL 买下了 Palm 品牌的使用权，不过后来就没有然后了。

在 CES 2017 上，TCL 官方已经确认会发布印着「BlackBerry」logo 的新机，其中至少会有一款配备全键盘的机型。这款产品将搭载最新的 Android 7.0 操作系统，会预装黑莓的安全软件和服务套件。在硬件方面，关于这部新机的爆料目前存在多个版本：一种说法是这是一部中端定位的产品，配置为骁龙 625 / 3GB 运存 / 4.5 英寸 720p 屏幕 / 3400 毫安时，另一种说法是这会是一款旗舰产品，型号为 DTEK70，采用骁龙 821 并配备双曲面屏，空格键上还会集成指纹识别模块。

DTEK60

可以确定的是，有了 TCL 的接盘，至少在未来一段时间内，我们还可以在市场上看到印有「BlackBerry」logo 的产品。只不过当「莓友」们看到预装 Android 系统、完全由 TCL 设计的黑莓手机，内心会是什么感受？

除了「Blackberry」标的 TCL 手机，不出意外，在明年的晚些时候，我们还会看到「Nokia」标的富士康手机。不同的是，TCL 推出的黑莓手机好歹还会预装黑莓的安全软件和服务套件，这个打着诺基亚前员工旗号的 HMD 搞的诺基亚手机将由富智康（富士康的上市子公司）全权负责手机的设计和生产，和那个「科技以人为本」、回想起来如同初恋般美好的诺基亚没有半点关系。

三星：手机不是重点

在 CES 2016 上，三星发布了采用 AMOLED 屏幕并预装 Windows 系统的 Galaxy TabPro S、新版 Gear S2 Classic 智能手表、智能家居设备以及数款电视新品，不过一款智能手机新品都没有。

Gear S2 Classic

在 CES 2017 上，目前可以确定的是三星依旧也不会发布啥重磅的手机新品。根据 PhoneArena 等外媒的消息，CES 2017 上三星唯一可能推出的是采用新款 Exynos SoC 的 A 系列（A3、A5、A7）产品，但可能性并没有很大。对于国内用户来说，由于三星已经用 C 系列全面取代了 A 系列，即使三星推出 A 系列新品，应该也和我们没啥关系。

稍微跑个题，每年的 CES 上，电视机新品都会占据很大的篇幅，CES 2017 应该也是如此，具体的「味道」应该也差不多：LG 展示最新最贵最好的 OLED 电视，索尼可能也会推出 OLED 电视新品，海信展示一票低价高质电视，而三星……则会继续改名大法（据说会推出采用了量子点技术、更优秀 HDR 效果的「QLED」产品线，当然了，这个「QLED」用的 99.9% 还是 LCD 面板）。

索尼、HTC 以及「中国手机军团」

除了上面这几家，索尼也依旧会在 CES 2017 上召开新品发布会，但推出 Xperia 的新品的可能性不大。

另外，CES 之后，HTC 会在 1 月 12 日召开一场新品发布会，预计会发布一款定位中低端的 HTC One X10，U 系列新品也有可能推出。

华为、荣耀、小米等多家国内品牌也会参加 CES，其中华为消费者业务集团 CEO 余承东将发表主题演讲，而小米将是第一次参加 CES。具体到产品上，荣耀 Magic、小米 MIX 等手机应该会吸引不少外媒的关注，不过对于中国消费者来说，新鲜感应该非常有限。

最后再预告下，今年极客公园依旧会前往 Las Vegas，第一时间为大家报道 CES 2017 上那些值得大家关注的点点滴滴。

CES 2017，我们不见不散！
