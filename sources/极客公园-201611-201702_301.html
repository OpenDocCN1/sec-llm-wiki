联想 ZUK Edge

在过去的一两年里，智能手机在外观上变化最大的部分应该就是屏幕了。

具体来说，屏幕的变化有两个方向：第一是基于柔性 OLED 面板的双曲面屏幕，代表产品有三星 S7 edge、荣耀 Magic、小米 Note 2；第二是提高屏占比，从而在体积一定的情况下「塞」进更大尺寸的屏幕，代表产品是小米 MIX 以及刚刚发布的联想 ZUK Edge。

5.5 英寸屏幕，5 英寸的机身

在 Android 阵营中，以窄边框、高屏占比为卖点的产品并不少，不过像联想 ZUK Edge 这样把一部 5.5 英寸屏幕的手机做得这么小还是极为少见的。

可以看出，在同样配备了 5.5 英寸屏幕的情况下，左边的联想 ZUK Edge 看上去和 iPhone 7 Plus 完全不像是一个尺寸的产品。实际上，联想 ZUK Edge 的「三围」和采用 5.0 英寸的 Google Pixel 几乎完全相同。

其实在左右边框上，联想 ZUK Edge 并没有做得像努比亚 Z11 等产品那样极致，不过在上下「额头」部分，ZUK Edge 在保留了听筒、传感器、前置摄像头以及正面指纹识别的情况下，大大缩减了宽度，这让联想 ZUK Edge 的屏占比达到了 86.4 %。

从设计上看，要做出这样的高屏占比是很困难的，需要在内部堆叠上做出很多的调整，从而在体积缩小导致内部空间明显减少的前提下保证手机的功能。比如说，在前置摄像头部分，联想特意为 ZUK Edge 找 OV 定制了一颗前置摄像头，比传统的模组薄了一毫米。

高屏占比带来的好处是显而易见的，它让那些喜欢大屏幕但不喜欢「大手机」的用户不再纠结屏幕和尺寸。在日常使用中，高屏占比也可以获得更加优秀的视觉体验。

提到高屏占比，另外一款不得不提的产品是屏占比高达 91.3% 的小米 MIX。相比将手机上下额头收窄的联想 ZUK Edge，几乎砍掉了上额头的小米 MIX 做得要更加极致一些，在设计和制造难度上理论上要更高。

从产品上看，小米 MIX 的屏占比更高，视觉上的冲击力更强，而联想 ZUK Edge 传统的听筒设计和正面指纹识别更符合多数用户日常的使用习惯。可能更重要的是，即使小米 MIX 的屏占比极高，但 6.4 英寸的屏幕尺寸还是让不少用户感觉太大了，而 5.5 英寸屏幕的联想 ZUK Edge 会更加符合主流用户对手机尺寸的预期。

真正的隐藏式指纹识别

除了超高的屏占比，联想 ZUK Edge 的另一大特点是它的隐藏式指纹识别模块。

在小米 5s 上，小米就通过超声波指纹识别方案，把指纹识别成功地放在了正面屏幕玻璃盖板的下面，不过为了保证识别成功率，小米 5s 在指纹识别模块的位置挖了一个凹槽，这导致了小米 5s 的这个「无孔式」指纹识别看起来和传统的「打孔式」指纹识别差不多。

联想 ZUK Edge 则更进一步，直接把指纹识别模块放在了一整块平整的玻璃盖板下面，这种隐藏式指纹识别 ZUK Edge 应该还是第一个做到的。此外，屏幕下方可以看到一个「腰圆键」形状的轮廓，用于帮助用户找到指纹识别模块。值得肯定的是，在指纹识别的速度和成功率上，联想 ZUK Edge 也做得非常优秀，熄屏下手指碰一下即可进入桌面。

此外，联想 ZUK Edge 的指纹识别模块也具备了 U Touch 功能。默认设置中，轻触返回，长按返回主页，左滑或右滑进入多任务界面。在设置中，可以把左右滑动设置成切换后台 app 或者打开某个特定的 app。

「全平衡」设计

聊完了屏幕和指纹识别，我们再来看一下联想 ZUK Edge 其它部分的设计。

联想 ZUK Edge 采用了类似荣耀 8、魅蓝 X、Xperia Z 系列的「金属中框 + 双面玻璃」设计，前后玻璃盖板都进行了 2.5D 打磨，金属中框用 CNC 切了两圈金属倒角，做工也很精致。相比上一代产品 Z2 Pro 采用的 3D 玻璃后盖，联想 ZUK Edge 的这种 ID 应该更符合「大众审美」。

拍照方面，和 Z2 Pro 一样，联想 ZUK Edge 也采用三星的 CMOS（型号为 2M8），f/2.2 光圈，5P 镜头，支持相位对焦，不支持光学防抖。值得一提的是，三星的这颗 CMOS 的单像素尺寸达到了 1.34 微米，这应该是除了索尼的 IMX377/378 之外，主流 CMOS 中最大的，大像素有助于弱光成像，可以在一定程度上弥补光学防抖的缺失和相对较小的光圈。

在实际体验中，在光线较为充足的情况下，联想 ZUK Edge 的对焦速度出色，大像素带来了优秀的照片宽容度。不过在暗光下，ZUK Edge 的对焦速度和成像质量都会有比较明显的下降，相比 iPhone 7、Google Pixel、华为 Mate 9 等产品还有一定的差距。另外，由于北京这两天毒气太重，暂时就不放实拍样张了，后续再补充。

旗舰配置，即将到来的 Android 7.0

作为一款旗舰产品，联想 ZUK Edge 的硬件配置也没啥好说的了。

5.5 英寸、1080p LCD 屏幕，「满血版」骁龙 821（最高主频 2.35 GHz），6GB/4GB LPDDR4 运行内存，64GB UFS 2.0 内置存储，USB Type-C 接口且支持 USB 3.1 传输，3100 毫安时电池。除了因为手机体积较小导致电池容量无法做到很大以及没有 NFC 之外，基本是 Android 手机中目前能买到的最顶级配置了。

在硬件资源的调用上，联想 ZUK Edge 也没什么问题，可以流畅运行包括 NBA 2K17 在内的所有大型游戏，日常使用中几乎没有任何的卡顿感。不过由于采用了不利于散热的双面玻璃设计，玩大型游戏时会感觉有些一些发热。

系统方面，联想 ZUK Edge 出厂是搭载的是基于 Android 6.0 的 ZUI 2.3，ZUK 表示将在春节之前推送基于 Android 7.0 的 ZUI 2.5。

在经过了长时间快速的迭代之后，现在的 ZUI 在功能上已经非常完善，位置穿越、自启管理、分屏、录屏等该有的功能一个不少，层级明确的设置菜单、类似 iOS 的底部上拉快捷菜单可以让 iOS 用户快速上手。

均衡中又有惊喜的手机

在目前售价两千档及以上的国产手机中，「均衡」和「没有明显短板」已经逐渐成为了一个基本的要求。在这个基础上，如果可以在某些方面再有所突破就更好了。

联想 ZUK Edge 就是一款这样的产品，出色的软硬件让 ZUK Edge 拥有优秀且均衡的使用体验。在这个基础上，ZUK Edge 还拥有 86.5% 的超高屏占比和正面隐藏式指纹识别。

有了这样一款产品，加上 2299元（4GB + 64GB）和 2499 元（6GB + 64GB）的低价，辅以恰当的营销，联想 ZUK Edge 应该可以取得不错的销量。而对于处在变革期的联想移动部门来说，联想 ZUK Edge 将有可能成为他们亟需的「主流爆款」。
