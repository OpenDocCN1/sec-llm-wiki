爆炸原因浮出水面，激进设计导致 Note7 自燃

来源：腾讯科技

知名独立硬件工程师团队「Instrumental」最近对 Note 7 进行了拆解分析，他们得出的结论是，Note 7 电池设计过于激进，导致锂聚合物电池在正常膨胀后没有空间伸展，受到挤压，引起爆炸。

Note 7 的设计导致正常操作手机的时候电池也会受到挤压。（注：锂聚合物电池在充电和放电过程中，锂离子会移位，电池会膨胀。任何电池工程师都会告诉你，电池周围应该留有一定的空间，根据经验，大概是 10%。电池使用一段时间后会膨胀变大，占用这些空间。）被拆解的手机只用了两个月，电池就已经把电池仓全占满了：电池的厚度为 5.2 毫米，电池仓深度也是 5.2 毫米。

Note 7 的锂聚合物电池就像一个被压扁的瑞士卷，由锂钴氧化物制成的正极层、石墨制成的负极层以及聚合物制成的吸满电解液的分隔层组成。分隔层让离子（和电量）在正极层和负极层之间流动，并同时将这这两层隔开。一旦正极层跟负极层接触，能量就会直接流入电解液，使之发热，这又会引起更多的能量流动以及更严重的发热，最后结果就是电池发生爆炸。三星表示，由于激进的制造参数，这些隔离层一开始就可能做得很薄。因此，本身就很薄的聚合物层受到电池正常机械膨胀的挤压，正极层和负极层就有可能会接触，引发电池爆炸。压迫电池后盖也会引起类似的挤压效果，这就是 Note 7 经常在用户屁股口袋爆炸的原因。

点评：不管怎么样，激进和创新的成本不应该由消费者承担，尤其是当成本这么大时。

谷歌前高级副总裁：AI 将在未来 5 年内成为医生助手

来源： Recode 中文站

谷歌 (微博) 前高级副总裁维克·冈多特拉（Vic Gundotra）于 2014 年从谷歌离职。当时他以为，自己将选择退休。然而，由于对可穿戴技术和机器学习的兴趣，他创立了 AliveCor。该公司的产品帮助用户通过智能手机跟踪心脏健康。

冈多特拉认为，可穿戴技术和机器学习的潜力才刚刚开始得到展现。AliveCor 的便携式心电传感器 Kardia 能在用户心脏跳动不规律时发出提示。目前，AliveCor 的投资方梅约诊所已开始研究心电图中可能被人们忽视的其他信号。

不可能有人类医生能根据心电图信息告诉你，血液中准确的钾含量。然而机器能做到这一点。

人工智能将逐渐接管医生的部分工作，但患者总是会希望有医生「来告诉他们，情况到底是什么样」。冈多特预计，在不久的未来，医生们将会寻求机器的帮助，而找到一种适当的方式将非常重要。

点评：的确，在某些方面，机器会比人更少出错。不过在中国，这会不会加剧医闹啊……

iPhone 6S 意外关机原因曝光 电量计算芯片惹的祸

来源：快科技

iPhone 6S 意外关机事件以苹果免费换电池而告终，但究竟为何关机，苹果也是含糊其辞。甚至还有消息称，即便换了电池，iPhone 6S 也有关机的情况发生。日前，微信公众号摩卡工社透露了 iPhone 6S 关机的真正原因，其表示这件事情的「罪魁祸首」其实是德州仪器，也就是 iPhone 6S 那颗型号为 SN27546 的芯片，这是 Ti 给苹果定制的电量计算芯片。

具体来说，电量计的作用是能够精确显示电池的剩余电量状态，对于用户的续航预期管理很重要。很遗憾很多国产机并没有加独立电量计，而是简单的通过电池的电性能曲线来粗略判断。

所以很多手机一旦显示到了 10%，甚至 20% 电量的时候随时会关机，而正常情况苹果可以到了 1% 再关机。不过一旦电量计本身出现问题，自然全部乱套：电池明明还有电，电量计已经「矫诏」通知主控关机休息。

所以，苹果的官方声明其实应该是：「少数于 2015 年 9-10 月期间生产的 iPhone 6S 设备中，Ti 电量计装进电池包之前在受控环境空气中暴露时间过长，使电池电量消耗速度快于正常水平，导致意外关机，这并不是安全问题。」

苹果没有把 Ti 供出来，可能是因为 Ti 打死不承认... 那么问题来了，如果真的是电量计算芯片出了问题，换电池到底有没有用？

点评：连着两条苹果的黑新闻，真的不是三星请来的救兵。

朝鲜「超级安全」红星操作系统可以被黑

来源：cnBeta

朝鲜国内电脑统一采用朝鲜自己开发的操作系统 Red Star 红星，朝鲜认为微软 Windows 等国外操作系统当中包括后门和恶意代码。朝鲜红星 Red Star 操作系统是一个基于 Linux 的操作系统，朝鲜声称其可以完全阻止黑客攻击。但事实证明，红星操作系统并不像朝鲜领导人金正恩想要的那样安全，因为一群安全研究人员设法使用一个网页连接进入了这套操作系统。

安全公司 Hacker House 在红星操作系统中发现了一个漏洞，通过诱使用户打开恶意链接，潜在攻击者可以远程访问运行 Red Star 操作系统的电脑。研究人员解释说，这种安全漏洞可用于安装恶意软件或利用运行红星操作系统的电脑。安全人员表示，Red Star 红星操作系统之所以被黑，主要原因在于其内建的浏览器 Naenara（基于 Mozilla Firefox）存在安全漏洞。

安全研究人员在探测漏洞时，注意到注册的 URL 处理程序被传递到命令行实用程序/ usr / bin / nnrurlshow 当中，这个应用程序处理这些 URI 参数请求时不会清除命令行，因此可以通过将格式错误的链接传递到 nnrurlshow 二进制文件来轻松获取代码执行。

红星操作系统是一个本土操作系统，使朝鲜当局可以控制有红星操作系统的电脑，红星操作系统不仅提供他们所描述的不妥协的安全性，而且还有工具，帮助跟踪正在使用红星操作系统电脑上的文件。例如，红星操作系统能够对连接到电脑的文档，文件，甚至 USB 闪存驱动器打水印，因此朝鲜政府可以轻松跟踪每一位数据。

点评：各位段子手，这是一道送分题啊……
