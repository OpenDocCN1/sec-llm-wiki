微软 Home Hub

智能语音硬件因为亚马逊 Echo 的「意外」成功而变成了众多大公司都不能放过的一条产品线，Google 不久之前才正式推出了其相似的产品 Google Home，而苹果据传也在开发基于 Siri 的智能语音硬件。

微软自然也不能缺席这个领域的争夺。此前有消息称，微软将发布一款名为「Home Hub」的产品，在十月的时候，大家都推断该产品也是类似亚马逊 Echo 这样的硬件设备。不过，最近 Windows Central 发表了最新消息，他们爆料称 Home Hub 并不是一款硬件产品，而是一个基于 Windows 10 系统的软件产品。

根据现有的信息，微软的这个产品也许能让你的 PC 就直接替代 Echo 和 Google Home 为你服务，让你不用再多花钱购买一个新硬件，但这真的可行吗？

一款智能语音软件服务

Home Hub 是什么？

简而言之，它就是一个几乎能做所有 Echo 和 Google Home 能做的事的软件产品，只不过它要在 PC 上运行，这意味着你还得到了一块 Echo 所没有的屏幕。

根据相关信息，Home Hub 的使用方式也很简单，无需登录 Windows 账户，你可以在锁屏的情况下就唤起相关服务，比如日历、提醒事项以及使用一些特定的应用。

这里的重点在于微软强调了这里的「家庭账户」概念，一个家庭可以通过不同的账户公用一台 PC，而在这个「家庭桌面」上，家庭成员们可以通过日历、待办事项、办公软件等相关服务进行信息的共享。这会比 Windows 10 之前的 Guest 账户要更符合「共享」这个概念。

同时，除了这个家庭共享桌面之外，Home Hub 还配备了「Welcome Screen」的功能，Welcome Screen 就像一个公共展示窗口一样，将日历、笔记、待办事项等信息都放在桌面上。而这个 Welcome Screen 也将运行在家庭账户上。同时，Cortana 在 Welcome Screen 上也将会随时处于准备状态，你可以像现在使用 Cortana 一样用语音让它帮你做许多信息处理的工作。

图片来自 Windows Central

此外，Home Hub 还能作为一个控制台帮你操控家中的智能硬件，这一点也很顺理成章，同时也能帮助它在很大程度上对抗 Echo。据了解，他们正在开发这款叫做「Connected Home」的应用来做这件事。

助力 Cortana，真正实现共享 PC

当然，作为一款可以实现语音操作的服务，Cortana 绝对是 Home Hub 的中心所在。

它不仅仅在 Welcome Screen 上变成了橙色，更重要的是在微软正在让它变得更以「家庭」为导向、更理解家庭账户的概念。这意味着 Cortana 可以在你使用家庭账户时理解其中的信息，还能在你以个人账户登录时做同样的事。而这种结合之后的理解能给你提供更综合的服务，而这也是 Google Home 这种只支持单一账户的服务所不能提供的。当然，没有你的授权，它也不会随便分享你的个人信息。

图片来自 Windows Central

同时，虽然微软自己貌似不会推出 Home Hub 的硬件，但这不意味着你不会见到类似的产品。根据微软相关人士透露的信息，他们已经与联想和惠普这种第三方硬件提供商展开了合作，一起开发基于 Home Hub 优化的一体机，可能会在明年年底推出。

而这款软件产品将会从明年开始，通过 Windows 10 的几次大的更新（Redstone 2、3、4）逐渐推出。时间可能是明年下半年或者 2018 年。

通过此举，微软可以让他们现在就在大力推广的 Cortana 服务拥有更多的使用场景、更聪明；同时，也可以通过「家庭账户」的服务让「共享 PC」的概念真正变得可行。

在亚马逊、Google 和苹果都选择了一条同样的道路时，微软却剑走偏锋，从自己拿手的 PC 业务出发来实践家庭智能语音服务这条路。他们能否在 Echo 之外真正取得不一样的成功，我们留待明年重点观察。
