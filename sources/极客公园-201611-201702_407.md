虽然今年还没过完，但对于国产手机来说，2016 年算得上是「大丰收」的一年，华为、OPPO、vivo 三大手机品牌的出货量都在不断创出新高，而在销量激增的背后，是国产手机品牌在供应链上越来越高的话语权以及一款款优秀的产品。  

作为一个以折腾手机为工作的用户，我今年用过的国产手机前前后后差不多有 30 部，其中有至少 10 款产品在我认为是非常出色，它们有的在工艺上有所突破，比如琥珀金配色的华为 P9，有的在设计上带来了惊喜，比如小米 MIX，还有的在系统功能上有精妙的创意，比如搭载了 Smartisan OS 3.1 的锤子 M1 / M1L。然而，如果让我挑出一部今年最喜欢的国产机，我会选择一加 3。

一部优秀的手机应该拥有不错的设计和做工、出色的屏幕、优秀的性能、一流的拍照、够用的续航、足够快的充电以及好用的系统。乍一看每一点似乎都没啥困难的，但要同时兼顾所有这些点并不容易。而在我看来，虽然一加 3 也没有做到完美，但在综合考虑上面这些所有因素后，一加 3 却是最让我感到满意的一部国产手机。

不过一加自己却似乎不那么认为，在一加 3 发布后不到半年，一加 3 的备货刚刚恢复正常的时候，一加就发布它的升级产品——一加 3T。

## 硬件上的小幅升级

![](../Images/49dfa419ada1c9b83c8e9f872eedd00a.png)

作为一加 3 的小幅改进版，一加 3T 在硬件规格上的变化并不大，具体可以概括成以下六点。

*   SoC 从一加 3 的高通骁龙 820 变成了 821
    
*   内置存储从一加 3 的 64GB 变成了 64GB、128GB 两种可选
    
*   前置摄像头像素从一加 3 的 800 万提高到 1600 万，后置镜头换用了蓝宝石保护玻璃
    
*   电池容量从一加 3 的 3000 毫安时提高到 3400 毫安时
    
*   砍掉冰川灰配色，更换为枪灰色，薄荷金配色不变（只提供 128GB 版）
    
*   价格从一加 3 的 2499 元提高到 2699 元（64GB），2999 元（128GB）
    

不过在过去一周的使用中，在这些小变化背后，一加 3T 还是有很多参数之外的地方值得大家注意的。  

## 外观：换了颜色的「大众脸」

在一加 3 的体验中，我们提到虽然它在机身的细节处理和工艺上非常出色，不过在设计上，一加 3 选择了一种非常稳妥的路线，优点是不至于让大多数用户在看到它之后「生厌」，缺点是长了一张「大众脸」，缺乏辨识度。

![](../Images/3d0a228cdab6d45b77851576867e544b.png)一加 3T（左）和一加 3（右）

**一加 3T 的 采用了和一加 3 完全一样的 ID，唯一的变化用枪灰色取代了原有的冰川灰配色。**真机看起来，相比一加 3 的冰川灰，一加 3T 的枪灰色要稍微深一些，有些偏向棕铜，但其实这两个颜色的差别并不大，都属于比较浅的那种。

![](../Images/94408b624dcf5d22db6eff0cf6b647e6.png)

此外，一加还推出了一种黑檀材质的后盖，触感挺不错，售价为 149 元，和除砂岩黑之外的其他后盖相同。

## 屏幕：依旧 AMOLED，依旧「浓妆艳抹」

是的，一加 3T 并没有像早期某些传闻那样改用 LCD 屏幕，而是沿用了在一加 3 上备受争议的 AMOLED 屏幕。

这里需要说明的是，**一加 3 上的这块三星 AMOLED 屏幕本身素质是挺不错的。**它的最高亮度超过了 400 尼特（在 OLED 屏幕中属于相当高的），色域也非常广，只是由于屏幕次像素依然是非标准 RGB 的 Pentile 排列，在 5.5 英寸 1080p 这个规格下，仔细看会有些颗粒感。之所以在屏幕上倍受争议，一加 3 的问题是出在对这块屏幕的调教上。

![](../Images/49dfa419ada1c9b83c8e9f872eedd00a.png)

**如何平衡屏幕显示的「准确」和「好看」一直是手机厂商在屏幕调教上的重要「课题」之一**，如果颜色太准确了就可能看起来不够吸引眼球，但如果追求第一时间的抓眼球，又会导致色彩失真。在一加 3 上，一加明显偏向了后者。

一加 3 的这块屏幕调教有两个特点：**第一是色温比较冷**，大概在 8500K 上下，**第二是颜色非常艳**，色彩和灰阶偏离都比较大。这种屏幕调教的方向是没啥问题的，**大部分用户都喜欢稍微偏冷一些并且颜色更艳丽的屏幕，只是一加 3 的程度有些大，超出了部分用户的接受范围，这才有了屏幕「辣眼睛」的说法。**

作为一个之前多年使用 iPhone 的用户，一加 3 这块屏幕默认的风格我也不太喜欢。在使用一加 3 时，我通常会在「设置」的「色温调节」中，把色温拉到最暖。

![](../Images/5073fa56b92286df28686d953a259f04.png)

需要说明的是，虽然一加 3T 采用的是和一加 3 完全相同 AMOLED 面板，色彩风格同样是偏向「浓艳」，**不过在色温方面，我们拿到的这台一加 3T 比一加 3 要明显暖了一些，第一眼看上去没有一加 3 那么蓝了，算是稍微「正常」点。**当然这是相对而言的，和 iPhone 7 比的话，一加 3T 的屏幕默认色温还是要冷不少的。

在一加 3 上，除了正常的显示模式，在设置的「开发者选项」中还有一个「使用 sRGB」的选项，打开之后屏幕的色温会降到 6500K 左右，色彩和灰阶偏离也会大有改善，但屏幕的观感又会变得过于「素雅」。一加 3T 同样提供了 sRGB 的选项，不过选项名称在氢 OS 2.5 被改成了「基本」，位置也移到了「显示—屏幕色彩模式」中，更方便查找。

## 为什么旗舰机还要谈性能？

大概是在高通骁龙 600 那个时代开始，就逐渐出现了类似「手机硬件性能过剩」、「旗舰机性能不用测」这样的说法。从「日常使用不卡」这维度上看，这种说法是有一定道理的。到了 2016 年，即使是大多数的千元机产品，都可已经可以做到「日常使用不卡」。

**即便如此，在目前搭载了顶级硬件的旗舰手机之间，手机的流畅度依然是有明显差别的。**这种差别体现在很多细小的方面，比如 app 的载入速度、多任务切换速度、app 运行时的帧率等等。这种流畅度的差别在单纯使用一部手机时感知可能并不明显，但如果从一部快的手机换到一部不那么快的手机，差距就会非常明显了。

**在流畅度这方面，一加 3 是今年推出的国产手机中做得最好的。**实际上，在我今年使用过的所有手机中，除了使用 NVMe 存储的 iPhone 7 和 iPhone 6s，唯一可以在流畅度上和一加 3 媲美的只有 Google Pixel。这背后的原因有很多，除了最顶级的硬件，更快的过渡动画、接近原生 Android 的操作系统、对 SoC 性能的大胆调用都有助于让手机用起来更加流畅。

![](../Images/15a7e0a196c62ee0448b7e66c72b5f88.png)

**一加 3T 的 SoC 从一加 3 的高通骁龙 820 升级到了 821，配套的是 6GB LPDDR4 运存以及 64GB / 128GB UFS 2.0 存储。另外，和刚刚发布的华为 Mate 9 一样，一加 3T 也使用了 F2FS 文件管理系统，有助于在长期使用中保持流畅度。**

从 CPU-Z 检测出的信息可以看出，一加 3T 采用的骁龙 821 中两个「大核」主频为 2.34 GHz，两个「小核」为 2.19 GHz，是市面上少有的真正可以算得上绝对「满血」821 的机型之一。从 CpuFloat 监测的数据来看，在日常使用中，这两个频率数据是可以达到的，并没有出现强制限频的情况。

我们使用相对靠谱的 Geekbench 4 和 GFXBench 对一加 3T 的性能进行了测试，对比机型是一加 3 和 Google Pixel。

![](../Images/3565722712b3a5a94fb6676b7b5d7658.png)一加 3T

![](../Images/31bc09634836d48078f2311ebc9066a6.png)一加 3

![](../Images/164c0ca9813d25907cd4c53565271927.png)Google Pixel

从跑分数据看，一加 3T 的确比一加 3 有了一定的提升。不过在实际使用中，我基本感受不到一加 3T 的运行速度有多少变化。应用切换时，一加 3T 偶尔快那么一丢丢，但这也有可能是因为我的一加 3 使用时间相对较长导致的差异。  

**在发热控制上，一加 3T 也和一加 3 没多少区别，日常使用基本感觉不到发热。**即使玩 NBA 2K17 这样的游戏，机身也不会有烫手的感觉，也没有像部分品牌的骁龙 820 / 821 手机那样，出现因为机身过热导致 SoC 大幅度降频进而导致卡顿的现象。

不过在比较极端的测试中，搭载了高频「满血」821 的一加 3T 的确比一加 3 更热。在 24 度左右的室内，经过 GFXBench 的高强度测试后，一加 3T 的最高温度达到了 40.5 度，在背部摄像头附近，一加 3 的最高温度为 38 度。作为对比，采用了降频版 821 的 Google Pixel 为 38.5 度。

## 氢 OS 2.5：这是原生 Android？

如果你是一个氢 OS 粉丝的话，应该留意到或者已经在一加 3、一加 2 上刷了氢 OS 2.5 的测试版固件。在一加 3T 上，出厂时就预装了氢 OS 2.5。

简单来说，**相比目前一加 3 上的氢 OS 2.0（之后会正式升级 2.5），氢 OS 2.5 变得更加接近一加在海外产品中预装的氧 OS，而氧 OS 非常接近于原生 Android。**

![](../Images/7c00d07c63915503a9e9422676207fbd.png)

很多氢 OS 中特色的功能，比如那个占据屏幕一大半空间并且可以直接左右滑动来切换的文件夹、类似 iOS 的控制中心以及刘作虎解释了半天的没有重启按钮，**在氢 OS 2.5 中，或是让位于原生 Android，亦或是直接砍掉。**

![](../Images/8196c37aaa2458cfa6e44ec237fadca8.png)

**在 UI 上，顶部状态栏、下拉通知、设置菜单等等位置通通换成了原生 Android 样式。**氢 OS 中招牌式的氢视窗从第一屏上部挪到了负一屏，变得更像氧 OS 的 Shelf。**除了依旧每行只能摆三个图标、最多摆五行以及没有 dock 栏之外，氢 OS 2.5 基本和氧 OS、原生 Android 没多少区别了。**

作为一个氢 OS 的粉丝，之前我非常喜欢氢 OS，是因为氢 OS 在原生 Android 的基础上，变得更加精致和易用，这和国内其他喜欢把 Android 改得「面目全非」的定制 ROM 有本质的区别。**氢 OS 2.5 中在变得更像原生 Android 的同时，也丢掉了不少之前氢 OS 独特的个性。**

不过对于一加来说，氢 OS 2.5 还是有很多积极意义的。作为一家海外市场比国内市场还要重要的手机厂商，「氢氧合并」意味着一加可以把精力专注在更接近原生 Android 的 氧 OS 上，而不需要花掉很大的精力为折腾国内「专供」的氢 OS，可以大大减少系统开发的成本，后续对 Android 版本升级的跟进也可以更快。

## 相机：依旧优秀，但领先优势不再明显

随着 CMOS、光学防抖、ISP 等相关硬件的进步，智能手机拍出好照片的成本变得越来越低。更重要的是，有了新一代硬件的加持，智能手机的成像品质之争已经不再是苹果和三星的「双城记」，越来越多的国产厂商正在逐渐接近、甚至在部分领域超越这两家。

但与此同时，想把智能手机的相机真正做好，单纯的堆硬件是不够的，比如今年上半年发布的很多国产旗舰手机都是用了索尼的 IMX 298 CMOS，不过在拍照体验和成像品质上，各家产品却存在着明显的差距。

**一款优秀的拍照手机应该拥有足够快的对焦、准确的测光、快速的成像速度、稳定靠谱的白平衡、较高的成片率以及优秀的画质，而把这些综合考虑进来，一加 3 的后置相机就是国产中当之无愧的「旗舰」水准了。**

![](../Images/b63a851561a6c62b5a75405eb7bfdc29.png)

或许是一加自己也对一加 3 的拍照部分比较满意，**一加 3T 的后置相机部分并没有进行升级，只是把相机镜头上的保护玻璃升级到了蓝宝石材质，日常使用更加不易刮花。**在拍照体验和成像品质上，一加 3T 和一加 3 并没有什么区别。

当然了，即使放在 2016 年底，一加 3 /3T 上使用的这套「IMX298 + f/2.0 光圈 + 光学防抖」硬件依旧属于比较高的档次，整体的拍照体验在国产手机中仍然处于一流水准，只是优势已经不再像一加 3 发布之初那样明显了。

为了「验证」一加 3T 的拍照，我们也找来了 Google Pixel、华为 Mate9 两款手机做了夜景下的样张对比，其中 Google Pixel 是法国影像实验室 DxOMark 测出来的目前拍照最好的智能手机，而有了光学防抖和更高像素的辅摄像头，Mate 9 的拍照水准在已经很优秀的 P9 上又有了进步。

画质上我们就不多做评价了，**这三部手机的成像品质已经可以代表目前 Android 手机中最顶级的水准了**，没多少可以挑剔的。在多数情况下，打开相机中的 HQ 模式画质会有进一步的提升（尤其是解析力），但需要注意的是，HQ 和 HDR 是不能同时使用，如果在光线反差较大的情况下打开，照片的亮出可能会因为宽容度不够而出现明显的过曝。在使用一加 3 / 3T 时，我个人更倾向于打开自动 HDR 功能（HDRA），在部分需要更好解析力的情况下再打开 HQ。

另外，一加 3T 把前置摄像头从一加 3 的 800 万像素升级到了 1600 万像素（一加表示 CMOS 型号为三星 3P8SP），不过由于传感器面积没有多少增加，单个像素尺寸从一加 3 的 1.4 微米降低到了 1 微米。反映在成像中，虽然一加 3T 前置摄像头的解析力好于一加 3，但噪点控制却似乎还没后者来得好，再考虑到自拍的使用场景，一加 3T 的前置摄像头难以算得上一个明显的升级。

## 续航和充电

一加 3T 的电池容量从一加 3 的 3000 毫安时提高到了 3400 毫安时，考虑到一加 3T 的体积和重量都没有发生任何变化，电池容量可以提高 400 毫安时还是值得肯定的。

大电池为一加 3T 带来了更好的续航表现。**在我自己强度相对稳定的日常使用中，一加 3T 的电池基本可以足够一天用了，而一加 3 必须要可以「省着用」才能撑到一天。**

![](../Images/d0d55912fc94289da0e26042bb9f77bd.png)

充电方面，一加 3T 采用的是和一加 3 相同的 DASH 闪充方案（VOOC 闪充的 Type-C 版），最大功率同样是 20W（5V 4A）。我们在关机状态下，记录了一加 3 和一加 3T 的充电百分比。（注：由于系统对电量百分比的计算方式不同，实际充进去的电量和这个数据会有少许的偏差。）

*   **一加 3：**15 分钟 32%，30 分钟 64%，45 分钟 88%，1 小时 96%
    
*   **一加 3T：**15 分钟 29%，30 分钟 56%，45 分钟 80%，1 小时 92%
    

随着越来越多的手机开始标配 24W 快充头，在绝对速度上，一加 3 / 3T 已经没有多少优势了，不过一加 3 / 3T 这种「低压大电流」方案的优势是在点亮屏幕甚至正常使用手机时，依旧可以维持几乎最快的充电功率，不像现有的高通 QC、联发科 PE 方案那样会出现明显的下降，另外快充时的发热也会相对更小一些。

有趣的是，在「高压低电流」这条路上折腾了好几年后的高通和联发科，在下一代的 QC4.0、PE3.0 上，都不约而同的选择了类似 OPPO VOOC（DASH）闪充、华为 SuperCharge 这样的「低压大电流」方案。

## 一个更「完善」的一加 3

整体来说，一加 3T 是一加 3 的小幅迭代版本。

相比一加 3，一加 3T 在 SoC、内置存储、电池容量等方面有了一定的提升，不过反映在日常使用中，**除了续航好了那么一点点，一加 3T 相比一加 3 并没有多少容易察觉的进步。**或许这也是一加在发布 3T 后，直接停售一加 3 的原因。价格方面，一加 3T 64GB 版为 2699 元，128GB 为 2999 元。考虑到汇率变化、成本上升等因素，这个价格变化还是比较合理的。

![](../Images/3045c722ee70e545da41390cf33e1670.png)

最后谈一下购买建议。首先，对于已经买了一加 3 的用户，一加 3T 是完全没有必要升级的。不过如果你考虑近期花 3000 元左右买一部国产手机，同时又不介意浓艳的 AMOLED 屏幕，更「完善」的一加 3T 是目前最值得购买的手机之一，而如果你最看重的是手机的拍照和系统流畅度，一加 3T 则是目前最好的选择，没有之一。
