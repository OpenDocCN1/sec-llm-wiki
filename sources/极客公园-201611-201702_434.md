# 大厂又打情怀牌，微软把经典纸牌游戏带到了 iOS 和 Android

有多少人在拥有了自己的第一台 PC 电脑时不知道拿它来干点什么？反正对我来说，年少时面对着那样一个既没连网又没软件的崭新机器，我是无所适从的，然而我又深深的觉得自己必须马上做点什么来测试一下这个充满魅力的高科技盒子，于是，经过几番尝试，年轻的我掌握的第一项电脑技能竟然是——打游戏，括号，纸牌游戏。

那个时候我觉得蜘蛛纸牌真的太好玩了，当然，即使是以现在的眼光来看，空当接龙和蜘蛛纸牌也仍然是非常有魅力的，而且，相信不仅是我，大多人的电脑游戏初体验应该都奉献给了这套微软自带的纸牌小游戏了吧，虽然这么说喜欢扫雷的朋友可能会有意见，但个人觉得纸牌确实比扫雷容易上瘾，尤其是那种赢得游戏后看到纸牌在屏幕上来回飞舞的感觉，真是太愉悦了。

![](../Images/51f3f792b95db8832eb497d42f529029.png)

据微软称，在其 20 多年的运营时间里，纸牌游戏一直保持着在 Windows 系统自带游戏中的高人气——用户们平均每天会进行共计 5500 万次纸牌游戏，这相当于每年此游戏会进行 200 亿次，每小时 229 万次，每分钟 3 万 8194 次。

看来这个世界上无聊的人真的是很多，不过以我为例，纸牌游戏确实陪伴我经历了无数个无聊的等人时光和办公室摸鱼时光，以至于，在我换了 Mac 电脑之后，也曾特意寻找过有没有这样一款游戏可以替代它，可惜，一直没有找到太好的。

然而就在昨天，这款游戏竟然可以在 Apple Store 和 各大安卓应用平台上下载到了，并且是微软官方推出，名称是 Microsoft Solitaire Collection (微软纸牌合集)，它包含了 5 个免费的游戏：Klondike（纸牌）、FreeCell（空当接龙）、Spider（蜘蛛纸牌）、TriPeaks 和 Pyramid。

![](../Images/1250a25b4df630fff59ae1fdc8f5c539.png)

游戏设置了每日任务环节，并设置了不同的游戏难度，用户完成任务就可获得积分奖励和成就徽章，并且，这款游戏还集成了 Xbox Live，用户可以登录 Live 帐号，这样游戏积分就会转化为 Xbox 成就，除此以外，用户使用 Xbox live 账户还可以实现游戏数据云端存储和好友竞技等高级功能。

![](../Images/8e8afeaca0c6e4b97d5272914a28e1b4.png)

目前游戏下载完全免费，不过用户花费 1.99 美元，就可以免去所有广告，并获得特权，在完成每日任务时获得双倍积分。

虽然现在的手游已经变得越来越复杂，越来越精美，但很多时候，在一些碎片化的时间里，我们还是需要一些不需要动脑的小游戏来帮助我们没有负担的消磨时间，在这种情景下，纸牌游戏无疑就是那个兼备了情怀和趣味性的最佳选择。

而且，想想看啊朋友们，在即将到来的春节，在陪着家里人走亲访友，听着七大姑八大姨唠家常的时候，你一定会需要这样一款无负担杀时小游戏的。
