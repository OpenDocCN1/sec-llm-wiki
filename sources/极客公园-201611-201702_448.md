## 全新 MacBook Pro 安装 Windows 可能会损坏扬声器

**来源：威锋网**

![](../Images/60a921f2e6d82e5f69994563985d01b2.png)

购买 Mac 产品的人并不一定全部都使用苹果的操作系统，有些用户会在自己的 Mac 上安装 Windows。新一代 MacBook Pro 上市之后，这一系列新产品也会成为 Windows 的安装机器。不过记者通过苹果的技术支持社区了解到，目前已经有部分用户反映新款 MacBook Pro 安装 Windows 之后可能会导致扬声器出问题。

这些用户表示，通过 Boot Camp 在新款 MacBook Pro 安装 WIndows 10，并且使用一段时间之后，设备的扬声器就开始出现杂音和走音的现象，重启之后也没有恢复正常。据了解，面临这一问题的设备在重新回到 macOS 之后，扬声器的问题依然存在。有用户认为，这很有可能是 Windows 的音频驱动太过时而导致，而且可能已经对扬声器造成实际损坏。

到目前为止，已经有多名用户向苹果的客服反映了这一情况，他们得到的回应是：最好是去 Apple Care 部门进行联系，然后前往 Apple Store 零售店寻找天才吧工作人员解决。话说回来，新一代 MacBook Pro 才上市短短几天就已经出现了三指拖移间歇性失灵和扬声器等问题，不知道随着时间推移，还会不会有更多问题出现。

点评：苹果说，给 MacBook Pro 装上 macOS，就好像把帅气西装穿成大人模样，装上 Windows 像什么话。

## 捷豹路虎人脸识别技术让你「刷脸」开车门

**来源：网易科技**

![](../Images/ef03e049acb6c1d8dfa73832811cf691.png)

据国外媒体每日邮报（Daily Mail) 报道，捷豹路虎有望让车主实现「刷脸开车门」。在车钥匙被遗忘的情况下，驾驶者只需走到他的车旁，来一张自拍照，便可以迅速打开车门。捷豹路虎正在开发利用面部识别及步态分析来检测车主的技术。以期实现当车主接近时，车辆能够自动为他们打开车门的目标。该技术的细节已经在 Jaguar Land Rover 的最近公布的专利申请书中被披露，但这项技术何时可用于实际目前尚不清楚。

安装在车门窗户下方的摄像机可以捕获他人行走经过时的视频和他人站在车旁时的静止图像，并将其与预先保存在内部计算机上的图像进行对比。如果二者匹配的汽车将解锁并自动打开车门。这项技术可以帮助司机省去他们一路上掏车钥匙的麻烦，如果这时他们手里还提满了购物袋，这项技术就变得更有意义了。

该技术的细节已经在捷豹路虎（Jaguar Land Rover）的最近公布的专利申请书中被公开。

点评：好是好，不过被人揍一顿之后再刷脸，会不会不起作用呢？

## 空客自动驾驶飞行的士或于 2017 年底前起飞

**来源：网易科技**

![](../Images/7491d5a4864878fa5b1d88f59708a674.png)

据英国媒体报道，空客公司对无人驾驶「飞行的士」的愿景朝现实又迈进了一步。MTSI 和 SOAR Oregon 联合提供了「试飞和场地」合同，以测试可同时运输人员和货物的单座自动驾驶飞行汽车。空客公司的创新部门今年早些时候推出了 Project Vahana 计划，希望在 2017 年底前让全尺寸的原型机上天，并在 2020 年推出上市型号。

这种飞机可垂直起飞和降落，有类似直升机的支柱和 2 个各安装了四台电动螺旋桨发动机的倾斜机翼，乘客位置的机舱盖小得如同摩托车头盔的面罩。空客公司去年曾表示，Vahana 首批项目之一将与 Uber 合作，为直升机运营商建立新的商业模式。

该计划首席执行官罗丁·莱索夫称：「需要解决很多技术问题，如电池、发动机和航空电子设备等问题。」自动驾驶还刚引入汽车领域，自动驾驶的飞机还没出现过。他表示：「只需 10 年，我们就能让革命化城市出行的产品上市。」

点评：我猜实际产品一定和概念图有差别，但是人类想换个姿势上天还是很有可能的。

## 英特尔研发 Project Alloy VR 头显，获微软支持

**来源：cnbeta**

![](../Images/f29ff6c50f8f235d3ebae739dc4fd54e.png)

今年 8 月，英特尔首席执行官 Brian Krzanich 在公司开发者大会上展示了笨重的 VR 头显原型，这款头显研发代号是 Project Alloy（合金项目），并且获得微软支持，将为用户提供一个「合并现实」的体验。具体来说，英特尔已经找到了一种方法来提供类似 PC 的 VR 体验，而无需将头显连接到高性能 PC。该参考设计有两个处理器，英特尔的 RealSense 3D 摄像头和一个可拆卸的可充电电池，并且采用微软的 Windows Holographic 桌面软件。这意味着你可以通过 Project Alloy 头显看到现实世界，头显上的 RealSense 摄像头捕获你眼前的现实世界画面，并以毫秒为单位将它们投影回虚拟环境中。

戴上 Project Alloy 头显时，你仍然可以看到现实世界当中的人和物体，并且可以使用物理笔作为虚拟游戏中的工具，但是如果这时有人给你一张纸和一支钢笔，你仍然可以通过 Project Alloy 头显提供的画面进行笔记。

总之，这种类型的虚拟世界和真实世界的互动是更安全的，因为你能够看到人和物体在你面前，即使你的头被包围在一个巨大的虚拟显示屏当中。Project Alloy 还省去了额外的传感器或手柄，以获得互动体验。产品计划在 2017 年下半年推出。

点评：听上去感觉 amazing，但估计价格也是非常 exciting。

## 新鲜事简单报

*   **8 代酷睿遭曝光 传言依然采用 14nm 工艺**
    

虽然前不久曝光的 AMD 的 ZEN 处理器性能强大，但英特尔似乎并没有放在心上，这从近期爆出的 8 代酷睿 Coffee Lake 中能够看到端倪。传言 Coffee Lake 将于 2018 年登场，并推出 6 核心产品，制程工艺依然采用 14nm 工艺。据悉，Coffee Lake 平台中的 U 系列也将推出 4+GT 3e 版本处理器。基本上，Coffee Lake 的 Intel HD Graphics 可以视为 Kaby Lake 架构的延伸，同为 Gen9.5 代产品。

*   **地球轨道已出现 1 亿块垃圾 威胁未来太空旅行**
    

在太空中，即使是微小的碎片颗粒也可能造成危害。英国一位专家表示，在地球轨道上存在大量金属和塑料垃圾，它们以超过 20 倍音速的速度围绕地球运转，这是人类面临的最大环境挑战之一。据估计，目前大约有 1 亿块太空垃圾围绕地球运转，其中有 2.7 万块直径大于 10 厘米，受到美国宇航局和美国国防部的跟踪监控。专家表示：太空垃圾不仅可能会毁掉卫星，而且可能会影响未来人类在太空中工作和生活的梦想和野心。

*   **甲骨文收购 DNS 提供商 Dyn**
    

甲骨文宣布，它已经收购流行的 DNS 提供商 Dyn，后者在 10 月份遭遇大规模 DDos 分布式拒绝服务攻击，导致一些世界上最大和最受欢迎的网站无法访问。甲骨文计划将 Dyn 的 DNS 解决方案添加到其更大的云计算平台，该平台已经销售/提供各种基础架构即服务（IaaS）和平台即服务（PaaS）产品。甲骨文和 Dyn 没有透露交易的价格。但是 Dan Primack 报告说，双方交易价格大约 6 亿美元。

*   **新的 Google 搜索工具可帮助用户实时避免购物人潮**
    

就在黑色星期五假日购物狂潮来临之际，Google 推出一个工具，让用户知道某一地点是否挤满了购物人潮。该技术会搜集用户信息数据，来给出某一地点或者商店当中实时用户数量。这些数据可以确定特定区域一小时内的拥挤程度。这可能会帮助用户决定是否在黑色星期五出门去商店抢购，或选择留在家里进行网购。
