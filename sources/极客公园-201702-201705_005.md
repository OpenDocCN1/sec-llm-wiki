# 这个三星出的聊天工具，可以让人用 emoji 表情交流

你在什么时候会发表情？通常是不想打字，或者没有合适的文字可以表达情绪。但有这么一群人，他们无法使用语言进行正常交流。

在美国，大约一百万人中就有一位失语症患者，他们在说话、阅读，或书写上，有语言表达的障碍。失语症也会影响视觉语言，如手语，但失语症不会影响智力。失语症剥夺了患者与外界交流的权利，无法日常生活，还会对情绪造成影响。

![](../Images/48d5f00b84dc9b9f284c968fb432b263.png)

> 下载地址见文末

这款叫做「Wemogee」的应用由三星意大利推出，是为了让失语症患者与朋友和家人恢复交流而做的。Wemogee 与一个语言治疗团队合作，把非正式聊天中常见的基本需求、情绪表达做了个短语列表，然后把这些短语转换成按顺序排列的 emoji 表情。

Wemogee 语言库中的预定义短语分为六大类，共 140 多个词组，包括日常生活，饮食，感觉，求助，娱乐，节日庆祝。通过将文本翻译成表情，Wemogee 可以让失语症患者通过图像与他人进行交流。

![](../Images/6da99980f0a510cabe761d3a266e914a.png)

Wemogee 按照最终接收者的需求设计了两种显示模式。简单直观的界面能够避免大脑过度紧张，通过点击按钮，患者就可以与好友聊天。

失语症患者通过一组特定的图像选择来识别他们想要沟通的内容，将所选择的表情序列发送给普通用户。普通用户将以文本形式接收消息，然后使用文字进行回复。

![](../Images/6c56c19dc202c967adf3766555c7e593.png)

失语症患者的痛苦不仅来源于疾病本身，表达能力障碍也会使身边的朋友、家人越来越疏远，周围环境带给患者的无助、压力会对精神造成极大影响。

在仔细研究各短语之间的逻辑关系后，Wemogee 提供了一个建议回答的系统。Wemogee 可以作为练习工具，提高失语症康复治疗的可能性。

![](../Images/dbfcf2fa2c62a1027f2e5091b9c8d1a1.png)

任何人都有交流的权利，体系成熟的 emoji 表情会让失语症患者的沟通变得简单，直观和有效。
