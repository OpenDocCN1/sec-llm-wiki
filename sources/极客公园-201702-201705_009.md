谷歌 Chrome Experiment 自从 2009 年建立以来吸引了大量具有创新意志的人加入，它的数量还在不断的增加，而有十款是我们不容错过的。

  

无论你喜欢还是讨厌谷歌浏览器，它都改变了我们浏览网页的方式。而对于它的「好」，业界是有目共睹的。 正如 Firefox （火狐浏览器） 采用了许多与谷歌浏览器相同的特征，而微软在发行 Windows 10 新一代 Spartan 浏览器时也借鉴了谷歌浏览器的部分特点。

之前，谷歌推广了与 Web 相关联的编程语言，并鼓励那些具有丰富创意的程序员使用 HTML5 和 JavaScript 去打造独特且优雅的网页体验 。根据统计，现在已经有超过 1200 个 Chrome 实验项目在网上发布了。

##  Chrome Experiment

谷歌 Chrome Experiment 是 2009 年谷歌支持用户使用 Chrome 系统进行网页实验的项目。该项目鼓励用户提交网页实验，最开始只是为了检测 JavaScript 的潜力与 Chrome 浏览器的性能。但随着用户增多，各种新奇的网页也相继涌现。现在它们甚至成为了科研教学的网页工具。

到 2015 年， Chrome Experiment 网站上的实验数目达到了 999 个，当时谷歌工程师还专门设计了 Chrome Experiment #1000 （http://1000.chromeexperiments.com/）网页来帮助用户更快更方便查找和探索其他的 999 个实验。

Chrome Experiment #1000 实际上成为了第一千个网页实验项目，而现在的实验项目数量已经超过了 1200 个，谷歌 Chrome Experiment 网站就成为了一个名副其实的开源网页技术的集中营。

通过筛选，我们找出了其中最有趣的十个，希望大家如果有机会可以亲身体验一下这些实验。虽然它们绝大多数是游戏，但是也能告诉我们在今天这个时代一个浏览器到底能干啥。

## Video Puzzle

![](../Images/85cec9d89159abc526d5fe979285fd71.png)

Video Puzzle （（http://1000.chromeexperiments.com/#/experiment/video-puzzle））虽然在技术上是一种游戏，但它的价值来自于其迷人的视觉效果。 实验会在视频播放时将一个完整的视频画面自动的分割成很多小块从而形成一个谜题，其布局就像拼图游戏一样。它主要考验用户随时跟踪视频中发生情况的能力。这个谜题对于孩子来说特别具有吸引力，它不是很难，但是和常规的拼图比较又多了些挑战。

## Multiplayer Piano

![](../Images/10b4c3a8e9e835a5b6faefb4d5ea25fd.png)

Multiplayer Piano （http://1000.chromeexperiments.com/#/experiment/multiplayer-piano）可以让用户和其小伙伴同时在线使用虚拟键盘演奏音乐，这听起来感觉还不错。此外，如果大家心情好的话，也可以独奏。

## X-Type

![](../Images/d1adfbeef441192e907f1e96fdfbeb66.png)

如果你对比较传统的游戏着迷，X-Type （http://1000.chromeexperiments.com/#/experiment/x-type）会是一个不错的选择。X-Type 就像是一个老练的小型宇宙飞船射手，为了不被消灭获得胜利，在面对比自己大好几倍的敌舰时，进行精准射击。设计师主要从 R-Type （一款横版射击游戏）上获得了名字的灵感。

## Mecabricks

![](../Images/f4cdd371ce5913af59a39066e12673c2.png)

Mecabrics （http://1000.chromeexperiments.com/#/experiment/mecabricks）是一款类似 Lego 的游戏。在这款游戏中，用户可以挑选很多的模块把它们放到模型板上来创作一款属于用户自己的 3D 模型。这些模型也可以模仿现实世界的艺术作品。Mecabricks 和 Minecraft 并不相同，但对那些想要大开脑洞，自我挑战的用户来说是一款不容错过的游戏。

## Silk

![](../Images/3338abf8be4428ae64e17870fd54a42c.png)

Silk （http://1000.chromeexperiments.com/#/experiment/silk）虽然只是一款时间非常短的游戏，但是同样不容错过。在这款游戏中，用户只需要用鼠标或是用手指简单的绘制出一个图案，程序则会自动的完成剩下的部分。这款游戏的最大的意义可能是不管用户有没有艺术天赋，只要动一下手，尽情发挥自己的想象力，就可以完成属于自己的艺术创作。

## Cube

![](../Images/bac07572b02b69e886f67b6e6c57d7ca.png)

Cube （http://1000.chromeexperiments.com/#/experiment/cube）是一款基于 WebGL 技术的游戏，基于 Google Maps 的数据运行。 虽然它在很大程度上是在为谷歌地图打广告，但用户却能在瞬间被它迷住。这款游戏还设有奖金，除非你是一个游戏「老手」，不然奖金可没那么容易进你的腰包。

## GeoGuessr

![](../Images/7b50c9c2e053f17d621300fdf11e668e.png)

GeoGuessr （http://1000.chromeexperiments.com/#/experiment/geoguessr）也是一款让人爱不释手的小游戏，但地理知识丰富的人可能会玩的更得心应手一些。 游戏首先会使用先进的定位技术将用户随机放到任何地方（通过谷歌街景视图），用户需要通过部分街景来推理自己所处的位置。 这看起来好像很简单，但实际是有难度的，毕竟世界上很多地方都看起来很相似。

## Racer

![](../Images/83ebfe27125e9da666ef5c1ef25480a0.png)

在所有的 Chrome Experiment 游戏当中，Racer （http://1000.chromeexperiments.com/#/experiment/racer）是最具创新特色的一款。这款游戏可以在 Chrome 兼容的移动设备上使用，用户只需要找到几个小伙伴就可以一起玩了。在游戏中，每人都有一条跑道，玩家需要同时在手机上完成相应里程的赛跑并避免撞车，用户还可以通过移动手机屏幕进行加速。这看起来很简单，但实际上要赢得比赛却很难。

## X-Wing

![](../Images/d810e827ab02b2d137b56cb1f4bdf37e.png)

在 X-Wing （http://1000.chromeexperiments.com/#/experiment/x-wing）这款游戏中，用户可能会产生一种错觉，感觉自己成为电影《星球大战》中的某位英雄正驾驶着 X-Wing 飞船横穿「死星」的战壕。这看起来很虚幻，但相信这样的设计能让那些科技控心潮澎湃。

## Inspirograph

![](../Images/53d913fccfcfdc3631125d021e5e8526.png)

在没有点进这个网页之前，大家可能对 Spirograph （http://1000.chromeexperiments.com/#/experiment/inspirograph）一点头绪也没有。实际上，Spirograph 可以理解为我们童年玩过的那种画图玩具的虚拟版本，而它在绘制精美复杂的几何图案时一点也不亚于现实版。

## 结语

其实在 Chrome Experiment 中还有很多其他的游戏值得一试。

比如 Land Lines，只要你随便划出一缕线，它会自动匹配卫星地图中相近的自然地貌、建筑、街道形态；比如 The WebGL Globe，一个使数据地理可视化的平台——利用这个项目提供的开源代码，我们可以制作属于自己的数据地球；还有 BioDigital Human，一个高度完成的人体解剖项目，值得医学生和从业者人手一份……

当我们越了解这些网页，我们似乎就越了解谷歌，越能发现它的不一样。在谷歌的价值观里，除了创新、个性的骨骼外，情感、幽默、人情味等也在公司文化的血液里流淌。

谷歌一直通过这样的方式来创造自己的产品，其中 Google Doodle 就是一个典型，它时尚、呆萌并具有鲜明特征的设计一经发布就给人一股暖意，而且它毫不吝啬的和全世界分享。

Chrome Experimen 的 1000 多个网页也是各具特色，异彩纷呈。某种意义上来说，谷歌就是一个舞台，将人性化和富有创意的想法聚集在一起然后分享给全世界，而在无形之中，它的魅力已经深深的把我们折服。
