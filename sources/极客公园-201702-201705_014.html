要闻：Win 10 秋季迎来更新，苹果 iTunes 将登陆 Windows Store

来源：The Verge、新浪科技

在西雅图举办的 Build 2017 开发者大会来到第二天，今天的重磅内容是微软公司公布了 Windows 下一个重要更新——Windows 10 Fall Creators Update 的更多细节。

Windows 10 Fall Creators Update 将在今年下半年为超过 5 亿台运行 Windows 10 的设备带来创新体验，其中包括：

一套全新的设计体系。Windows 10 秋季创作者更新最大的改变在于引入了全新的视觉风格设计元素 Fluent Design System，也就是我们之前所说的开发代号 NEON 和毛玻璃特效。该设计语言的核心就是在美观的前提下，应用程序的使用更加自然和流畅。它将带来直观、和谐、响应迅速、兼容广泛的跨设备体验与互动操作。对于开发者来说，流畅设计能帮助他们设计出更具表现力和吸引力的应用程序，并且广泛支持各种类型的设备和多样化的输入方式。

贯穿 Windows、iOS 和 Android 设备的一致的用户体验。通过可视化时间轴功能（Pick Up Were You Left Off），用户可以快捷跳转到任何时间点访问文件、应用和网站，这个功能类似于网络版的苹果时间机器（Time Machine）。借助 Cortana 功能，用户可以在 Windows、iOS 和 Android 设备之间切换和继续之前的操作。剪贴板（Clipboard）功能使得用户可以在电脑和手机之间进行粘贴复制，例如在电脑桌面上复制文件，然后在手机上进行粘贴。借助 OneDrive 文件随用随取（Files On Demand）功能，用户可以便捷访问存储在云端的所有文件，而无需下载和占有设备存储空间。

Windows 应用商店将要迎来包括 iTunes 在内的一批人气应用。iTunes 应用即将在今年年底加入 Windows 应用商店。届时，Windows 用户将能够在任意 Windows 10 或 Windows 10 S 个人电脑上，享受到完整的 iTunes 应用体验，其中包括 Apple Music、iTunes 商店以及对于 iPhone 和其他苹果设备的支持服务。AutoDesk、SAP 等知名软件也将逐渐进驻 Windows 商店。

全新的开发工具将让开发者更轻松地在 Windows 平台工作。NET Standard 2.0 for UWP 和 XAML Standard 将于下半年推出，它们将让网页开发、C++、.NET 和 UWP 开发者更好地用 Windows 编程。有了 Xamarin Live Player，开发者能够通过 Windows 电脑针对 iPhone 应用进行构建、测试和排错。通过这项新的工具，用户仅需要 Visual Studio 和 iPhone，即可上手在数分钟内开发 iOS 原生应用。同时，通过在 Windows 应用商店上线 Ubuntu，微软极大地简化了其安装的过程。

此外，还有全球首款 Windows Mixed Reality（Windows 混合现实）动作控制器——完全无需依赖任何定位标记即可工作。今年圣诞假期期间，宏碁将以 399 美元的价格推出一款 Windows Mixed Reality 头戴设备与运动控制器的套装。

要闻：小米将在印度开始小米之家，未来两年计划开 100 家

来源：腾讯科技

小米科技昨天宣布，在印度的首家小米之家将于 5 月 20 日正式开业。

小米之家是小米独特的线下零售商店，米粉可以到此来体验和购买小米最新的产品，米粉可以在店里买到一系列小米产品，如手机，移动电源，耳机，手环，空气净化器以及在印度发布的生态链产品。

未来两年，小米计划在印度开 100 家小米之家。接下来的小米之家将会开在一些大都市，例如德里，孟买，海德拉巴和金奈。这些小米之家都有单独区域供米粉体验更多的小米产品。

截至目前，小米之家在中国的数量已经有 88 家，在刚刚过去的米粉节（2017 年 4 月），小米之家的进店人数超过了 500,000 人，在北京的一家最新开业的店里创下了单天进店 24,000 人的记录。在米粉节期间的中国小米之家门店总销售额超过 7500 万人民币。

近年来, 小米手机在印度市场销售成绩不错, 市场研究公司 Canalys 最新数据显示，今年一季度小米成为印度智能手机市场上的亚军，仅次于三星。

小米副总裁，小米印度总经理 Manu Jain 在发布会上说：「我们对于在印度首家小米之家即将开业非常激动，这是小米印度征程的又一重要里程碑。我们会将运营线上销售学到的成功经验通过小米之家应用到线下零售中去。小米之家是在小米互联网+和新零售理念的基础上建立的，会达到与线上销售同样的效率。」

小米公司表示，自从小米于 2015 年 5 月在印度发布了小米线上平台 Mi.com 后，发展迅速，已经成为印度五大电商平台之一。

除了小米之家以外，小米将继续与零售商和分销商的合作来拓展线下零售业务，这种直营模式会去掉线下分销渠道的层层代理，这样小米就可以做到产品线上线下同价。目前，小米的线下零售点已经超过了 10000 个。

  • 微信加强公众号原创保护，未获授权转载将仅显示摘要

来源：凤凰科技

5 月 11 日晚间，微信更新了公众平台原创保护功能，如果公众号推送其他帐号的原创声明文章，未获修改授权的情况下，将变成分享样式，用户需跳转到原创帐号页面阅读文章。

以凤凰科技的公众号举例，如果一个公众号想要转载凤凰科技的原创文章，在未获修改授权的情况下,过去可以直接转载全文，只是转载之后的样式会和凤凰科技的原文保持一致，下方会显示这篇文章来自凤凰科技；


现在更新原创保护之后，将只能显示摘要，并允许转载者写不超 140 字的推荐语，读者如果想要查看原文，需要点击下方「阅读全文」，进入凤凰科技公众号查看。

  • 丁磊：受某些游戏影响，《阴阳师》表现确实有波动

来源：腾讯科技

网易公司周三发布了该公司截至 2017 年 3 月 31 日的第一季度未经审计财报。财报显示，网易第一季度净营收为人民币 136 亿元（约合 20 亿美元），同比增长 72.3%；归属公司股东的净利润为人民币 39 亿元（约合 5.699 亿美元），同比增长 59.4%。

在回答分析师关于《阴阳师》的提问时，丁磊表示：《阴阳师》是一款非常成功的手机游戏，我们这个团队非常出色，当然，近期从业务上看会有一些波动，但我们对未来的发展很有信心，因为在这个类别的游戏中，目前在市场能够真正称得上是精品的，就网易一家。

「当然，由于其他一些游戏的出现，短期内会对《阴阳师》的表现有些影响，我认为这也是很正常的，但《阴阳师》的深度和广度不是其他游戏所可比的。所以，我们对这款游戏的未来很有信心。」

  • Android 之父安迪·鲁宾研发智能安全摄像头用于识别人和宠物

来源：cnBeta

Android 之父安迪·鲁宾投资的初创企业 Lighthouse，拿出了一款智能安全摄像头，Lighthouse 并没有将其新的硬件产品看作家庭安全摄像机。相反，他们认为它是一个「互动助手」产品，帮助 Lighthouse 进入智能相机市场。

该设备今天首次亮相，Lighthouse 可以安装在家中，就像 Nest Cam 一样，可以监控室内发生的情况。Lighthouse 这款产品采用深度学习和 3D 感测技术，以确定谁在家中以及在家中的位置，他们是否处于正常状态。这款产品通过 Wi-Fi 与随机 iOS / Android 应用配对，因此用户可以远程确定入侵者是否在家中。Lighthouse 这款产品还可以侦测家中宠物以及孩子的状态，并且可以判断是否处于危险状态，同时发出警报。

Lighthouse 摄像头包装包括 RGB 相机，3D 传感器，扬声器，麦克风和警笛。相机拍摄 1080p 视频并具有自动夜视功能。这些更强大的硬件组件帮助构建一个更智能的安全摄像头，同时可以作为全天候的家庭助理，它会每天在家中了解谁在家中，包括宠物，以及哪些人不在家中，并且内建类似于 Siri 或 Google Assistant 的语音助手，来提问和发出命令。例如，用户告诉应用程序她的丈夫回家了。然后，当摄像头下一次看到她的丈夫时，应用程序将推送通知告诉用户。

  • 开发者今起可以预购宏碁和惠普的混合现实开发套件

来源：cnBeta

早在三月初，微软表示，宏碁混合现实头显将在当月开始发货，但是这款产品当时并无出货。现在微软在第二天的 Build 2017 开发者大会上宣布，开发者从今起可以预购宏碁和惠普的混合现实开发套件。

这些设备将提供给在美国和加拿大的用户，如果用户现在订购，它们将在今年夏天发货。宏碁版本售价 299 美元，惠普的版本售价 329 美元。他们不会包括今天公布的运动控制器，但是当这些设备普遍可用时，宏碁的版本将包含这种运动控制器，但是价格将上涨到 399 美元。

当然，宏碁和惠普并不是唯一二家正在开发 Windows 混合现实头显的公司。今年晚些时候，我们还应该看到戴尔，联想和 3Glass 公司推出的相关产品。

  • 卡西尼号临终前杰作：史上最清晰 Titan 照片

来源：快科技

在土星轨道服役 13 年之久，随着距离土星越来越近，无人探测器卡西尼号终将冲向土星大气层，结束自己辉煌的考察旅程。但在此之前，NASA 绝不会放过任何机会，让卡西尼号继续施展自己的才华，比如向地球传回令人震撼的天体照片。而这一次的主角，是土星最大的月亮——土卫六 Titan。

据了解，这组照片拍摄于 5 月 7 日，但并未立即被公之于众。照片展示了令人惊叹的细节，那些形似羽毛的条纹，正是 Titan 上的云。不过，与地球上的云不同的是，Titan 上的云并非由水珠或者结晶冰构成，其主要的成分是甲烷。

除了有丰富的气态甲烷之外，Titan 上还有众多有液态甲烷和乙烷组成的海洋和湖泊，这样的组合绝对是不友好的，至少对于人类来说是如此。
