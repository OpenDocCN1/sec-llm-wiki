通过昨晚的 Build 2017 大会，微软用「云」+「AI」重新定义自己

微软在自己的的年度开发者大会上展示了自己的新力量。


也许是黄道吉日吧，科技公司们的大会在近期接踵而至，并且在昨夜今晨来到了一个高潮点，微软与英伟达的年度开发者大会在近乎重叠的时间段同时召开，更别提同时还有 Dell 及 OpenStack 的峰会也在进行中。不过在昨晚，微软在自己一年一度的 Build 大会上还是以多项面对开发者们推出的新技术、新产品、新方案赢得了一众积极的评价，其中颇有不少值得介绍的内容，虽然对普通 C 端用户，这些内容也许会略显「无趣」，但相比于本月初面向教育领域的新品发布会，这也许才是微软更有优势、更有作为的地方。

而通过这次大会，微软已经把他们的主要精力放到了更远的地方。

从云计算到边缘计算

 在今天的主 Keynote 中，云服务 Azure 成为了极为重要的一个角色，它出现的次数几乎覆盖了整个 3 小时左右的演讲。

微软首席执行官萨提亚 ∙ 纳德拉

  • 首先，微软今天宣布推出名为 Azure IoT Edge 的新云服务。这项技术能够将云计算的智能和更多优势扩展到物联网边缘设备上。它能在代码和服务之间提供编配服务，因此它们可以在云端和边缘设备之间安全地流动，从而在物联网设备之间提供智能服务。

开发人员还可以轻松集成 Microsoft Azure 和其他第三方服务，也能对现有服务进行扩充，以自己的业务逻辑创建自定义 IoT 应用程序。Azure IoT Edge 可以在本地计算设备上进行计算，节省时间，它同时也支持在 Linux 和 Windows 上跨平台运行。

  • 此外，微软也发布了 Microsoft Graph 扩展服务，这项功能可以将工作环境中的业务内在规律、设备数据与对现实世界复杂关联的感知结合在一起。

服务于所有开发者的云平台，面向任何平台和设备的开发工具

在纳德拉对整体情况进行介绍之后，被称为「红衣主教」的微软云服务部门负责人 Scott Guthrie 对 Azure 云服务进行了更为详尽的介绍。事实上，对微软来说，Azure 已经超过了 Windows，成为了其最重要的业务之一。其中，全新的 Microsoft Azure 和 Visual Studio 服务及工具，能够帮助开发者对现有应用进行现代化升级，并针对所有的主流平台构建智能应用。

微软全球执行副总裁兼云计算与企业事业部负责人Scott Guthrie

  • Azure Cosmos DB 发布，它是业界第一个全球分布式的多模型数据库服务，能提供带有运行时间保障、高吞吐、高一致性的水平扩展，并能保证 99% 的个位数毫秒级延迟。主要特点是能一键在多个国家快速布置数据库，这样各地的信息都会同步。作为唯一的模式自由数据库服务，Azure Cosmos DB 在灵活性上也非常出色，它不但支持各种流行的 NoSQL API，而且还提供了五种定义清晰的一致性等级可供选择，同时能够对所有数据自动建立索引。

  • 在 Azure SQL 数据库基础上新增的 MySQL 和 PostgreSQL 托管服务，为开发者提供了更多的选择和灵活性，同时还能确保平台服务的高可用性，尽可能不停机以完成扩展，并可确保数据安全和数据恢复的能力。

  • 微软数据库迁移服务开启早期预览，这将帮助 Oracle 和 SQL Server 的用户更轻松地迁移数据并快速地对自己的应用进行现代化升级。

  • Azure SQL 数据库的改进包括：全新的托管实例开启有限预览，为用户提供 SQL Server 虚机实例层级的兼容性，让企业更轻松地把现有 SQL Server 应用迁移到 Azure SQL 数据库。同时威胁检测服务正式上线，Graph 支持服务开启预览。

  • Visual Studio 2017 for Mac 正式商用，让开发者在 Windows 和 Mac 环境之间实现无缝衔接，全面支持移动、网页和云端工作负载，并提供 Docker 工具、Azure Functions 和 Xamarin.IoT 支持功能的预览。

  • Azure Service Fabric 已正式支持 Windows Server Containers，通过 Visual Studio 作为工具，借助 Docker Compose 将容器化应用部署到 Service Fabric 的功能也已开启预览。微软针对几乎所有类型、所有平台容器所提供的全面支持，让开发者得以交付面向关键业务的、可扩展的应用和服务。

  • DocuSign 的客户群快速扩张，现已覆盖 188 个国家和地区的 30 万家企业和超过 2 亿用户。该公司今天宣布，Microsoft Azure 成为其拓展全球业务的首选云服务，加拿大将是第一站。DocuSign 采用 Azure SQL 数据库来处理海量数字交易。

为开发者打造更好用的 Office 365

 在大家更为熟悉的 Office 方面，微软也有不少新动作，不过内容基本上也都是针对企业级用户推出的。

  • 开发者将可以在 Microsoft Teams 中发布嵌入式应用。Microsoft Teams 是微软去年推出的一个企业协同办公应用，作为 Office 365 的一部分，开发者现在可以在 Microsoft Teams 中加入应用。同时，开发者还将可以为 Teams 应用添加新的功能，例如在信息流中加入第三方推送通知、复合扩展和可以交互信息等。

  • 微软为开发者开放了新的 Microsoft Graph API 接口，包括 SharePoint 和 Planner 的 API。Microsoft Graph 让开发者能够访问 Office 365 数据和智能，并在联系人、对话、项目、日程、流程与内容之间建立联系。这些洞察能帮助开发者打造更智能的应用，构建更聪明的工作方式。

  • 对于已经将生产型 SaaS 应用放在 Microsoft Azure 上运行并在 Azure 网站上注册的开发者和 ISV，现在只要通过标准的 PowerApps 和 Microsoft Flow 接口，就可以将其应用中的数据和工作流自动扩展到经过授权的 Office 365 用户。为了进一步帮助 ISV 拓展业务，微软还为销售团队提供了额外的奖励，以鼓励其向企业客户销售由 ISV 开发的合格的 SaaS 应用及服务。

为每位开发者、每个人服务的人工智能

毫无疑问，在今天，没有科技公司在自己的大会上不会介绍 AI 方面的内容，而作为科研实力强大的微软，他们在 AI 领域本身就有很多值得介绍的内容。作为微软 AI 研究领域的负责人，微软全球执行副总裁沈向阳最后一个登场，为大家介绍了微软在这方面的动作。

微软全球执行副总裁兼人工智能及微软研究事业部负责人沈向洋

  • 微软认知服务将智能 API 接口的数量增加到了 29 个，也是唯一允许对 API 进行定制的。利用这些 API，开发者能够将视觉、语音、语言、知识和搜索等智能应用加入到任何应用场景中，直接利用现成的功能或者通过定制加工，来打造自己的智能应用和机器人体验。新加入的 API 服务包括必应定制搜索、定制视觉服务、定制决策服务和视频索引。

  • 此外还有一个被称为 Presentation Translator 的 PowerPoint 插件，它利用了微软的 Translation API 接口，可以在播放演示文稿的过程中，实时地将其翻译成多种语言。对于很多职场人士来说，这也许是未来的一个福音。

  • 微软聊天机器人框架加入了对新的适应卡（adaptive card）的支持，开发者一次编写卡，即可用于多个应用和平台。利用微软对话机器人框架，开发者现在可以直接对接更多新渠道，包括必应搜索、Cortana 和 Skype for Business，并通过微软的支付请求 API，更快速、便捷地用自己的微软聊天机器人结账。

  • Azure Batch AI Training 是 Azure 的一项新功能，目前只提供有限预览。它允许开发者和数据科学家利用参数配置运行环境，针对多 CPU、多 GPU 或现场可编程门阵列（FPGA）等不同环境运行自己的数据模型。

  • 除了本周和哈曼卡顿合作推出的内置 Cortana 的 Invoke 智能扬声器，微软还分别与惠普和英特尔达成了与设备和参考平台相关的合作伙伴关系，用以打造更多支持 Cortana 的智能设备。

  • Cortana 技能工具包开启公共预览。通过创建一个机器人并将其发布到微软机器人框架新开通 Cortana 渠道中，开发者可以为 Cortana 增添新技能。这项服务支持 Windows 10、Android、iOS，以及内置了 Cortana 的哈曼卡顿 Invoke 扬声器。Cortana 技能工具包目前只在美国可用。

总结一下，在去年微软 Build 2016 大会上，微软将重点放到了 Windows 10 系统、「conversation as a platform（对话即平台）」及 AR 设备 HoloLens 上，相对离普通用户较为贴近。但在今年，微软把目光放到了离开发者们更近的地方，在 Azure、Office 365、以及 Visual Studio 等企业级生产力服务工具方面做了很多工作，云与 AI 也成为了两大主题。从中，我们也可以看到，结合这两年 Build 大会的内容，对于未来几年的微软来说，他们的重点无疑也就是云、AI、VR/AR、以及他们传统的优势领域——Windows 系统及 Office 等生产力工具。
