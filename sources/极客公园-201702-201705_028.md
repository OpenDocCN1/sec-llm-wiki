# 70.6% 市场占比，亚马逊正在主宰美国的智能音箱市场

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652846830&idx=1&sn=73e17b07de951d2cb1482e8f85883e8c&chksm=7e6a4758491dce4e3f2b7c918189d24c7703c254845babf0298295cc86ec2b1c0e9cf9fba7df&scene=126&sessionid=1681311247#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652846830&idx=1&sn=73e17b07de951d2cb1482e8f85883e8c&chksm=7e6a4758491dce4e3f2b7c918189d24c7703c254845babf0298295cc86ec2b1c0e9cf9fba7df&scene=126&sessionid=1681311247#rd)

美国人已经慢慢开始习惯使用智能音箱了，国内恐怕还得等到本土化的产品出现。

  

根据著名市场调查公司 eMarketer 前天公布了一份智能音箱市场的研究报告，亚马逊正在主宰美国的智能音箱市场。

eMarketer 的预测，在美国，今年智能音箱的月活跃用户将会达到 3560 万人，比去年增长 128.9%。其中亚马逊的 Echo 将达到 70.6% 的市场占比，远远领先于第二名 Google Home 的 23.8% 以及联想、LG、Harman Kardon 等其他品牌。

![](../Images/5aa3b04aa3e96de3cfc469bd048d7ab1.png)亚马逊 Echo 占有了 70.6% 的市场份额，图片来源 eMarketer

亚马逊在 2014 年发布了 Echo，它是一款搭载了智能语音助手 Alexa 的智能音箱，一共有入门版、标准版和便携版三个版本，最便宜的仅需 49.99 美元。

Echo 看起来和一个普通蓝牙音箱没什么区别，但它内置的语音助手 Alexa 的功能却相当强大，除了基本的播放音乐以外，它还可以帮助你使用语音控制各种智能家居产品，进行网上购物甚至朗读 kindle 电子书。

在报告中，eMarketer 预测亚马逊的市场份额会因为 Google 的加入而有所下滑，但这并不影响它的主导地位。同时报告也强调了亚马逊在 Alexa 和语音识别技术上取得的成就，对大部分使用者而言，这两者已经成为了他们生活中的一部分。

Echo 拥有更多的用户意味着 Alexa 也将会有更多的机器学习数据，Echo 目前的市场地位对 Alexa 成长为 Windows 那样的顶尖平台有很大的帮助。

![](../Images/3a3b058ec322997623c6698bcf509098.png)

亚马逊并没有透露 Echo 的销量数据，但他们曾表示自己的库存非常紧张。

「用户已经逐渐接受了这个技术，并开始更多地参与进来，」eMarketer 的副总裁 Martin Uteras 说道，「随着价格的下降和功能的增加，消费者对这些产品的接受程度越来越高。」

对于虚拟语音助手的应用，eMarketer 也表示这项技术的前景还比较乐观，包括亚马逊的 Alexa，苹果的 Siri，微软的 Cortana 以及 Google Now 在内的虚拟助手使用率将会在 2017 年增长 23.1%。

今年，将会有 6050 万美国人至少每个月使用一次虚拟语音助手，这大概等于智能手机用户总量的 27.5%，或者美国人口的五分之一。

![](../Images/15740f87116d3519749750cce405eff9.png)红色柱形是千禧一代的用户，图片来源 eMarketer

据 eMarketer 统计，虚拟语音助手的重度用户集中在 25 岁到 34 岁之间，这个年龄段的使用人数占到了虚拟助手总用户量的 26.3%。就年代来说，超过三分之一（33.5%）的千禧一代（84 年到 95 年出生的人群）都将在今年用上虚拟助手。

「30岁左右的使用者是虚拟助手的核心用户，这主要是因为他们对娱乐功能有一定的要求。」Utreras 说道。

对亚马逊来说，这份报告的出炉是一个绝佳的消息。这家公司最近正在大力推广自己的虚拟助手 Alexa，他们向广大开发者开放了权限，现在其他开发者也可以在自己的应用中加入 Alexa 了，这使得亚马逊虽然没有直接参加今年年初的 CES 大会，[却让人觉得他们无处不在](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652845293&idx=2&sn=a7e3f5c92ff219e305b9a7388639a410&chksm=7e6a495b491dc04dccdc4ef90fd1f627ac2b4533160a68a6a823acc7e8259c12e740e017e072&scene=21#wechat_redirect)。

同时，亚马逊在智能音箱领域的成功也折射了其另一重要业务电纸书的成功。据外媒 Quartz 报道，亚马逊占据了电纸书市场 74% 的市场份额，很多人将 Borders 这样的实体书店的倒闭归咎于亚马逊电纸书业务的成功。
