Windows Phone 消亡后，微软靠什么重回手机市场？

Windows Phone 的市场占有率已经不足 1% 了，但是微软还想要回到智能手机的战场上。


微软已经两年没有推出新手机了。

尽管还有其他厂商在生产搭载 Windows 移动操作系统的手机（例如惠普），但微软自家的旗舰机自从 2015 年以后就再也没有更新过了。

在上周，微软发布了全新的 Windows 系统和笔记本电脑，企图在传统笔记本和教育市场正面对抗苹果和 Google。但想必微软自己也很清楚，没有足以与 iPhone 和 Andriod 竞争的智能手机平台，在移动互联网的版图上始终缺少了一块。

我们此前曾经报到过，Windows Phone 已经宣告了「死亡倒计时」，不过微软似乎并没有就此放弃手机市场。

早在去年 11 月，微软现任 CEO 萨特亚·纳德拉在接受澳大利亚一家媒体采访时就表示，微软打算在 2017 年推出一款不一样的手机：「我们还会留在手机市场，但跟现在的行业领头者们不一样，我们打算做一款独一无二的终极移动设备。」

微软 CEO 萨特亚·纳德拉

上周，纳德拉在接受采访时再次提起了他们正在做的手机：「……你说到我们会不会再做手机的，我很确定我们一定会做手机的，但他们看起来并不像今天市面上的手机。」

今天 Windows 手机上的 Windows 10 Mobile 系统有两个最大的亮点：其一是它优秀的交互界面，简约商务，没有 iOS 和安卓上的那些过于繁赘的特效动画。其二是 Continuum 功能，Windows 手机可以当做一台小电脑使用：出门在外你可以把它当成一部手机，回到家里你也可以连上显示屏和键盘，像使用一台传统电脑一样使用它。

Continuum 功能演示

可惜的是现在的 Windows 10 Mobile 仍然是 2015 年微软最后的旗舰 Lumia 950 上搭载的版本。过去几年 Windows 10 Mobile 并没有获得长足的进步。

微软在手机市场上反应的迟钝并不让人意外。2010 年，当最初的 Windows Phone 7「姗姗来迟」时，苹果已经发布了 iPhone 4，Google 的 Andriod 系统也在移动市场上站稳了脚跟。但毫无疑问，微软的移动设备在当时看起来还是非常有竞争力的。

Windows Phone 7

在随后的 Windows 8 上，微软在桌面和移动设备上对交互界面进行了大规模的重新设计，然后 Windows 8.1 中又加入了智能语音助手 Cortana 以对抗苹果的 Siri。在 2015 年，微软推出了被媒体称为杀手级功能的 Continuum，通过这项功能用户可以用手机获得类似于 PC 的使用体验。

但可惜的是，不要说成为智能手机市场的搅局者，号称「世界第三大移动操作系统」的 Windows Phone 恐怕都没有给市场上的前两名竞争者带来一点压力。

就算如此费尽心思地想要挤进核心竞争者的行列，微软还是失败了。一切都和当初不一样了，习惯了制作出畅销全球的操作系统的微软，面对移动市场的失败也无能为力。

在当时，用户已经完全被 Andriod 和 iOS 征服了，第三方开发者也不是很想再为第三个系统费力开发一款应用。当然，微软的 Windows 手机每次的更新迭代看起来还是很不错的，然而除了微软以外其他厂家出品的手机就没那么讨喜了。在同样的价格面前，用户往往会选择更优秀的 iPhone 和更具性价比的安卓手机。这也是上个月安卓超越 Windows 成为世界上安装量最多的系统的原因。

Lumia 950 和 Lumia 950 XL

但愿在离开了高端智能手机市场两年以后，微软会给我们带来一些令人惊喜的东西，因为如果无法做出一款消费者真正想要购买的产品，一款差异化的产品，微软就很难重新回到智能手机的市场分一杯羹。

智能手机发展到现在，产品的更新已经不像几年前那样迅猛，水涨船高的定价也让人们慢慢放弃了两年换机的玩机守则。在这样的情况下，微软不仅要做出一部足够「伟大」的手机，还要做出一部能够「搅局」的手机。

换句话说，微软得要让我们大开眼界。

那么将来的 Windows 手机会是怎样的呢？在微软上周的发布会之前，我们一直都以为那会是一款基于云应用的手机，但当我们以为会推出的云系统 Windows 10 Cloud 只不过是一款轻量级系统 Windows 10 S 时，这个想法就不再可靠了。

Windows 10 S 不是基于云技术的，而是基于计算机和微软荒原般的应用商店。

微软需要很多优秀且稳定的开发者来为他们的应用商店开发应用，只有这样才能将用户吸引回来，然而开发人员也需要有足够大的用户群和足够多的时间和金钱投入才愿意为 Windows 移动系统开发应用。

微软因此而陷入了令人沮丧的周期性僵局，这意味着无论微软为我们准备了怎样的产品，对消费者和开发者来说，在短期内都是无关紧要的。

所以微软新手机的使命并不是要成为一个热卖的产品，而应该是像概念手机一样的一款「终极移动设备」，是一款炫技的产品，是微软表示自己还没出局，在未来 5 到 10 年内还有潜力的证明。
