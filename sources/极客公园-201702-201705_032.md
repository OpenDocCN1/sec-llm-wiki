「锤科」到底什么时候才能推出一款「没毛病」的手机？2017 年 5 月 9 日晚上发布的坚果 Pro 或许就是答案。

  

锤子是一个从诞生之日起就充满了争议的手机品牌，产品也总让人又「爱」又「恨」。

一方面，锤子总能在设计、系统体验等方面带来一些不一样的东西，给看似热闹却愈加乏味的智能手机市场增添新意；但另一方面，锤子手机似乎总踩不到对的时间点，前三款产品 T1、T2、坚果 U1 发布之时硬件配置都落后同时期竞品，M1 / M1L 的配置是赶上了，不过在曾经的强项工业设计上却又做了妥协。

「锤科」到底什么时候才能推出一款「没毛病」的手机？2017 年 5 月 9 日晚上发布的坚果 Pro 或许就是答案。

## 关键词：方正、好看、不「撞脸」

在锤子手机的工业设计中，双面玻璃和对称是两个始终逃不开的词汇，T1 和 T2 都是严格遵循这两点做出的产品。在这个基础上，锤子手机又衍生出了很多独特的细节设计，比如听筒传感器合二为一、左右对称的音量键、无断点金属中框。这些小细节和双面玻璃、对称设计一起，构建起了锤子手机在工业设计上特立独行的风格。

回到这次发布的坚果 Pro 上，虽然锤子把它归到了「坚果」这个相对低端的产品线，但锤子在坚果 Pro 的工业设计上花的心思可一点都不比 T1 和 T2 少。

**坚果 Pro 采用了 T1、T2 类似的双面玻璃设计，不同的是，坚果 Pro 的这两块玻璃不是覆盖整个手机表面的，而是分别在底部切掉了一块，取而代之的是两块金属贴片。**

![](../Images/57805c6b8b245b272ba59eb7ddd170e7.png)

这两块金属贴片的高度相同，颜色、处理工艺则和金属中框保持一致。**第一眼看上去，就像是手机底部多了一个金属材质的「下巴」。**当然了，和 LG G5 不同，坚果 Pro 的这个「下巴」是不能拆卸的。

这里有一点需要特别指出**，坚果 Pro 的前后玻璃都是平面的，没有经过 2.5D 打磨。**至于背后的原因，可能是由于 2.5D 玻璃无法和金属贴片平整的衔接，也可能是锤子就是单纯想把手机做得尽可能的「方正」。

![](../Images/ec6934ae1aea813cb232cc49feb90b2f.png)

这种「方正」还体现在了坚果 Pro 的金属中框上。为了获得更好的握持手感，大部分采用金属中框 + 双面玻璃方案的手机都会将中框部分「打磨」得尽可能圆润，**坚果 Pro 则反其道而行之，它的中框部分几乎做没有任何圆润的处理，中框两圈各切了一圈亮面金属倒角，具体效果大家可以参考 iPhone 5。**

**![](../Images/a5ac5ed1b94a328bbd94aa14ac26c174.png)**

这个「方方正正」的中框带来的好处是可以让手机看上去更加「规整」，还可以轻松把手机立在桌子上。当然了，坏处就是影响握持手感。

虽然坚果 Pro 的机身足够轻薄（6.98 毫米，158 克），但当平面玻璃遇上没有弧度的金属中框，再加上不算窄的机身（5.5 英寸屏幕、屏幕边框控制得中规中矩），**坚果 Pro 握在手里不免会有些硌手，而手感也是坚果 Pro 在工业设计最大的妥协之处。**

锤子显然也意识到了这个问题，为此，锤子准备了一个坚果 Pro 钢化玻璃手感膜（售价 49 元）以提高坚果 Pro 的手感，当然，贴钢化膜的副作用是手机会变得更厚一些。

![](../Images/4b2a16748d84613c411482db69f6451a.png)

**配色上，坚果 Pro 提供了**炭黑色、酒红色（只提供 64GB、128GB 版）、细红线特别版（仅限 128GB 版）三种颜色可选，具体大家就看图吧。****  

**![](../Images/aa01b28eae815251641eaad88c3c528c.png)**

**![](../Images/2011219cf280db2536d377fea295263b.png)**

**![](../Images/8df85a2c1743be21293cf7da12b586d6.png)**

除了整体外观的变化，坚果 Pro 身上还有几个小细节值得留意。

**第一是金属中框并没有采用无断点设计，而是加入了常见的注塑信号条。**作为锤子过去两代旗舰产品的标志性设计之一，无断点金属中框的缺席免不了有些遗憾，不过考虑到坚果 Pro 的定价比 T2、M1 / M1L 低得多，这个妥协也就很容易接受了。

**第二是去掉了双音量键，只保留了右侧的音量键，不过在右侧音量键的下方增加了一个 M1 / M1L 所没有的电源键。**这个变化的好坏就因人而异了，我从来不觉得双音量键在功能上有多大的必要性，去掉了也没感觉损失什么，顺便还解决了锤子之前的几代产品普遍存在的左右音量键手感不一致的问题。

**第三是去掉了 3.5 毫米耳机插孔。**对于手机厂商来说，去掉 3.5 毫米耳机插孔可以为机身内部腾出更多的空间，有助于放下更大容量的电池，并且可以让手机外观更加简洁，不过对于用户来说，这往往意味着额外的麻烦。

坚果 Pro 随机附送了一个 USB-C 转 3.5 毫米的转接头，不过转接头终究不是一个多好的解决办法。在发布会上，锤子还展示了一款 USB-C 接口的 S-101 半入耳式线控耳机，售价 99 元。它的原理和 JBL Reflect Aware C、乐视 CDLA 数字耳机类似，都是通过 USB-C 接口从手机中获取数字音频信号，然后经过耳机内部的 codec 进行数模转换和放大（通过手机的 USB-C 来供电），然后驱动耳机单元发声。关于这个耳机的具体表现，我们会在收到后第一时间进行测试。

![](../Images/8cd824fad67602fbc9791f7348fe3109.png)

此外，在指纹识别方案上，坚果 Pro 则延续了 M1 / M1L 的正面可按压实体按键设计。操作逻辑也和 M1 / M1L 无异，轻触返回，长按回主页，双击呼出多任务。

总体来说，坚果 Pro 在锤子经典工业设计的基础上做了一定的改进，整机的外观变得更加硬朗和方正，并且在色彩上做了进一步的探索。对于一款定价在 1500——2000 元档的产品，锤子敢于大胆地使用新设计，并且做出这样一款足够精致、又有高辨识度的产品还是非常值得称赞的，我们也愿意给坚果 Pro 的工业设计一个好评，即使它握起来有点硌手。

## 配置：该有的一个都不少  

在去年年底发布的 M1 和 M1L 上，锤子总算是想明白了「手机想要卖好，配置不能落后」这个道理，第一次在配置上没有落后同时期竞品，而这也让帮助 M1 和 M1L 取得了比 T1、T2 更好的销售数据。在这次的坚果 Pro 上，锤子也延续了这个路子，配置上「紧跟潮流」。

我们来看一下坚果 Pro 的配置清单：

> SoC：高通骁龙 625（MSM8953）/ 626（MSM8953 Pro）
> 
> 屏幕：5.5 英寸 incell LCD，分辨率 1080p，ppi 401
> 
> 运行内存：4GB LPDDR3
> 
> 内置闪存：32GB / 64GB / 128GB eMMC
> 
> 后置摄像头：双 1300 万像素（一个彩色 + 一个黑白），f/2.0 光圈，有相位对焦，无光学防抖，RGBW 白平衡传感器
> 
> 前置摄像头：800 万像素（32GB），1600 万像素（64GB、128GB），f/2.0 光圈
> 
> 电池容量：3500 毫安时
> 
> 充电：18W，高通 QC3.0
> 
> 机身尺寸：155 毫米 \* 73.4 毫米 \* 6.98 毫米
> 
> 重量：158 克
> 
> 操作系统：Smartisan OS 3.6，基于 Android 7.1
> 
> 其它：前置按压式指纹识别（支持轻触返回），双卡双待全网通，USB-C，无红外，无 NFC，无 3.5 毫米耳机插孔，128 GB 版本支持 NFC（其他版本没有）
> 
> 售价：1499 元（32GB，炭黑色）、1799 元（64GB，炭黑色、酒红色）、 2299 元（128GB，炭黑色、酒红色、细红线特别版）

这里我们挑出其中的几个重点来说。

## 骁龙 625 / 626、长续航、双摄、Smartisan OS 3.5 / 3.6

在核心的 SoC 上，坚果 Pro 提供了高通骁龙 625（型号 MSM8953）和骁龙 626（型号 MSM8953 Pro）两个版本可选，32GB 版本用的是骁龙 625，64GB 和 128GB 版本用的是骁龙 626。

**![](../Images/5f23c44c02c532ba3e5c08cb246eb900.png)**

关于骁龙 625，大家应该已经非常熟悉了，而骁龙 626 就是骁龙 625 的高频版本，CPU 的最高主频从 625 的 2.0 GHz 提高到了 2.2 GHz，架构依旧是定位低功耗的 ARM 公版 Cortex A53，其他主要参数（Adreno 506 GPU、X9 LTE 基带、14 纳米制程），骁龙 626 也基本和骁龙 625 保持一致。由于二者的规格相差不大。骁龙 625 / 626 的优点是功耗和发热极低，性能上则是「够用就好」。

具体到日常使用中，骁龙 625 / 626 可以无压力流畅运行在微信、微博、网易云音乐、Chrome、摩拜单车等日常使用频率较高的 app，标配的 4GB 的运存也足以让用户在坚果 Pro 的后台放五六个常用 app 而不卡顿。和锤子 M1 / M1L 这种「骁龙 821 + UFS 闪存」的手机相比，除了 app 载入时会慢那么一丢丢，整体的流畅度上差别不大。

在王者荣耀这样的热门手游中，骁龙 625 / 626 也基本可以跑满 30 帧率，只是没法开高帧率模式（也不建议大家强制开高帧率），并且由于骁龙 626 的制程先进（14 纳米工艺），发热量较小，游戏过程中几乎不会出现因为手机过热而强制降频进而导致游戏卡顿的情况，这其实比骁龙 652 / 653 等理论性能更高但容易因为发热而出现降频的 SoC 表现还要好点。当然了，对于 NBA 2K17 这样的大型游戏，受限于最高性能，骁龙 625 / 626 就完全不能指望了，基本就是看幻灯片。

存储上，坚果 Pro 标配了 4GB 的 LPDDR3 运行内存，内置存储则提供了 32GB、64GB、128GB eMMC 可选。

![](../Images/8a037c6a6f1105e06fb86db9b22870df.png)

至于为什么是「LPDDR3 + eMMC」而不是「LPDDR4 + UFS」，除了成本这个显而易见的原因，根本原因是 SoC 本身不支持。事实上，现在只有骁龙 8XX、麒麟 9XX 等定位高端的 SoC 才支持更先进的 UFS 闪存，骁龙 4XX、6XX、麒麟 6XX 以及目前所有的联发科 SoC 都只能支持 eMMC，LPDDR4 和 LPDDR3 运存的情况也大抵如此（支持 LPDDR 4 但不支持 UFS 的联发科 P20 / P25 是个特例）。

综合来看，**骁龙 626 的性能属于「够用但不优秀」的水准，用在坚果 Pro 这个价位的产品上「没毛病」。**如果你经常拿手机完大型游戏，购买坚果 Pro 需要慎重一下了，不过除此之外，坚果 Pro 用的这颗骁龙 626 应该已经足够用了。

同样「没毛病」的是坚果 Pro 的续航。

![](../Images/fbc40823ba571f82093911608ddf7091.png)

坚果 Pro 的配备了 3500 毫安时的电池，算是勉强跻身「大电池」的行列，考虑到坚果 Pro 的机身厚度只有 6.98 毫米，这个数据还是比较可观的，此外，坚果 Pro 还支持高通 QC3.0 快充，充电头最大输出功率为 18W。

配合低功耗低发热的骁龙 626，**坚果 Pro 的续航搞定一整天的重度使用是完全没问题，省着用可以勉强撑上两天。**

值得一提的是，虽然只是一款「坚果」，不过**坚果 Pro 却成为了锤子推出的第一部搭载后置双摄像头的手机。**

**![](../Images/18ba5f1174ca454bc8b9b1a03edd3ef5.png)**

坚果 Pro 采用的是「一个彩色 + 一个黑白」的平行双摄方案，两颗 sensor 的像素均为 1300 万像素，具体型号尚不清楚（推测可能是索尼 IMX258），支持相位对焦，但没有集成光学防抖模块，不过集成了 RGBW 白平衡传感器。

从功能上看，坚果 Pro 的双摄也和同类产品无异。这颗多出的黑白 sensor 可以和另外一颗 sensor 配合，用于记录景深数据，实现模拟背景虚化效果，也可以单独使用，「原生」拍摄黑白照片。相比于 iPhone 7 Plus、小米 6、华为 Mate 9 / P10 等机型，坚果 Pro 这套双摄方案的主要差距是不具备更优秀的变焦能力，也就是俗称的「光学变焦」（这种说法非常不严谨）。当然了，考虑到坚果 Pro 的产品定位和售价，我们也不能奢求太多，毕竟用上双摄已经算是小惊喜了。

关于坚果 Pro 具体的拍照体验、成像品质（老罗在发布会上表示坚果 Pro 的夜拍有了很大的改进）以及双摄的背景虚化效果，我们还需要做进一步的测试，并在近期推出的坚果 Pro 详细评测中和大家分享。

**系统上，坚果 Pro 搭载了最新的 Smartisan OS 3.6，基于 Android 7.1。**

在 UI 上，Smartisan OS 3.6 变化不大，拟物化和扁平化共存的 UI（用老罗的话说是「该拟物的地方拟物，该扁平的地方扁平」）、精美的的过渡动画让 Smartisan OS 3.X 在一大片的国产 Android 定制 ROM 中有着很高的辨识度。

相比 Smartisan 3.1，Smartisan 3.6 增加了几个实用的小功能，包括智能退订广告和垃圾短信、模拟来电通话、将当前常用的 app「钉」在锁屏界面上等等。此外，锤子自家的文件管理软件 HandShaker 也得到了升级，在电脑和手机配对后，可以实现无线传输文件，复制文本等操作。

另外，Smartisan OS 3.1 的两个重要功能 One Step 和 Big Bang 也获得了明显的升级。

![](../Images/a3e438c8b6a77d8d7af10631e6adc180.png)

其中 One Step 从 1.0 升级到了 1.5，主要的变化有两个。第一个是侧边栏上增加了一个图片搜索的快捷方式，长按图片然后拖拽到这个图标上就可以在浏览器中搜索图片，快速完成「以图搜图」操作；第二是提升了语义分析能力。在收到有地址的信息时，可以直接把这条信息拽到地图 app 中，系统可以自动识别信息中的地址信息，省去了之前需要首先用「大爆炸」炸开文字、选出来地址信息的步骤。如果收到的信息中同时包含了地址、快递单号、航班信息等众多信息，把这条信息拽到地图、快递查询、航班查询等不同的 app 中，可以智能地提取出对应的有效信息。

![](../Images/d6b73d4eb63492ab642903a643fc3de4.png)

Big Bang（大爆炸）也升级到了 2.0 版本，升级的功能包括选择图片区域进行 OCR 识别，在大爆炸界面上下滑动切换文字的上 / 下一段，将所有的文字全部切开然后对文字进行编辑和处理。

![](../Images/cea511054dc8b3c5d32af88c670cdd44.png)

值得一提的是，在 Smartisan OS 3.6 中，还增加了一个叫做闪念胶囊的新功能，用户可以用语音输入的方式随时记录自己的念头、灵感，并且能够不打断自己手中原本的工作。  

至于 Smartisan OS 这些功能的效果如何，大家可以关注我们正在斗鱼进行直播的坚果 Pro 上手评测（房间号：673484）以及后续的更详细的产品评测。

## 第一部同时取悦了罗永浩和用户的锤子手机

坚果 Pro 是一款典型的打着罗永浩和「锤子」烙印的手机。

配置上，坚果 Pro 和锤子 M1 / M1L 一样，该有的一个都不少。外观上，坚果 Pro 像锤子 T1、T2、坚果 U1 那样，在这个「千机一面」的手机市场成功做出来了「锤子式」的差异性，对于一款售价在 1499 —2299 元之间的产品，这显得尤为难得。而这种不惜以牺牲手感为代价来换取设计美感的做法，现在恐怕也就只有罗永浩的锤子会这么做了。

![](../Images/7857beb8c27d3dc8092fe8756fa67670.png)

回到文章开头提到的问题，坚果 Pro 能不能算是第一款「没毛病」的锤子手机？

对于挑剔的用户和媒体来说，这个答案永远都是否定的。不过对即将年满 5 岁的「锤科」来说，坚果 Pro 应该是它们有史以来最接近「没毛病」的作品。
