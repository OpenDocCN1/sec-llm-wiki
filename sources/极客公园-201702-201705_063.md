# 抢占 Google 教育市场的大杀招，微软推出轻量级系统 Windows 10 S

为了与 Google 的 Chromebook 在教育市场上对抗，微软推出了所谓的「廉价笔记本」Surface Laptop，并且作为与 Chrome OS 对位的产品，微软同时发布了全新的 Windows 版本：Windows 10 S。

  

在昨天的微软春季发布会上，微软在软件和硬件上各推出了一款新品：Windows 10 S 和 Surface Laptop。

在发布之前，有传闻说这个系统的名字是「Windows 10 Cloud」，是微软针对 Chrome OS 蚕食教育市场的应对方案。但微软发布的却是一款后缀名为 S 的轻量级 Windows 10 系统，它保留了 Windows 10 的大部分功能，只是在应用程序的安装上限制了用户。

微软只允许用户在这个新系统里使用两种应用程序：使用微软新的通用 Windows 程序（Universal Windows Program，简称 UMP）框架构建的应用程序，以及通过桌面桥（Desktop Bridge）移植到应用商店的 Win32 程序。

## 「S」的含义

对于这个「S」，微软并没有给出官方解释，所以你可以认为它代表了学校（School）、商店（Store）或者灵魂（Soul）……当然，你也可以认为它只是单纯的加了一个 S。

![](../Images/9d57d4daede7d369b65c9fd49a447295.png)

不过笔者认为，「S」其实就代表着 Student 或者 School 这样教育相关的词，但由于微软同时希望非学生的用户也来购买使用这个系统，所以并没有直接点明。

## 只能从应用商店安装程序

在最近更新的创意者更新中，Windows 10 新增了一个只允许系统安装来自官方应用商店的功能，在 Win10 家庭版、专业版和企业版中，用户可以在设置中选择是否允许来源非应用商店的程序安装运行。而新出的 Windows 10 S 系统使用的就是这个功能。

只允许从官方平台安装应用，可以更好地保证系统的性能，电池寿命和安全性。UWP 商店的应用审核非常严苛，系统可以根据设备的需要暂停甚至终止程序的运行，以此节约运行内存、处理器和电池等硬件资源的使用。桌面移植的应用受到的限制要少很多，不过也不可以像普通桌面程序一样安装后台服务和其他自动运行的程序。

在新的系统中，这两个程序都只能通过一种固定的机制进行自动升级，这是为了简化程序的维护和补丁的安装。

## 学生要怎么用？

据了解，在美国，除了一些条件好的学校会给每个学生都配备学习用的电脑外，条件稍差的学校会提供公用电脑供学生学习使用。

在上课时，学生们先领取并登陆一台公用电脑，然后在下课时退出登录并将设备交还给学校。这种多用户使用的情况需要 Windows 系统提供更高的安全性能，同时也要保证登录设置等操作足够高效迅速。

![](../Images/9366a4efd745ecf43720c4ba521ad622.png)协作程序 Microsoft Teams 可以帮助老师更高效地教学

在这种目标情况下，微软需要设备能够提供一整天校园生活的电池续航。当然想让所有学校都用上自家的新笔记本肯定是不现实的，因此微软提供了软件上的解决方案：限制应用的后台运行。

在今年秋季即将发布的下一个 Windows 10 重要更新「Restone 3」中，微软将进一步限制后台应用程序的资源消耗。就像 Google 使用云系统 Chrome OS 的笔记本一样，使用 Windows 10 S 的设备将支持微软基于云设备的管理系统 Intune。

![](../Images/9ba406dfa1da1553472d6e2a22f230c1.png)

如果学生老师不喜欢这种应用安装的限制，或者想要安装其他桌面程序，他们也可以花费 49 美元将 Windows 10 S 升级到专业版 Windows 10。

不过，虽然这次发布会的主题是教育与科技，但微软并没有完全把 Windows 10 S 定位成一款完全针对教育市场的低端产品，普通消费者也可是购买使用这款系统。像 Google 的 Chrome OS 一样，这款新系统的封闭环境使得它非常适合低端一些的 PC 设备。

不过这并不是微软第一次尝试这种高度限制的轻量级系统。早前，在 Windows 8 的时代，微软就推出过一款名叫 Windows RT 的基于 ARM 处理器的系统。然而，当时的 Windows 8 应用商店里的应用质量较低，数量较少等原因使得这个系统并没有打开较大的市场，Windows RT 系统也在微软推出 Windows 10 后不久被微软抛弃。

## 默认浏览器不能改

有趣的是，虽然新系统很明显是同 Google 在竞争市场份额，但微软仍然允许用户在系统中安装来自 UMP 商店的 Chrome 浏览器。

**「你可以在 Windows 商店里下载其他的浏览器，但在打开.htm 文件等情况到时候，Microsoft Edge 仍然是系统默认的浏览器。」**微软官方解释道。这意味着就像 iPhone 上的 Safari 一样，当你在非微软官方应用里打开一个链接，或者点开一个邮件里的链接时，不论你是否想用其他浏览器打开，Microsoft Edge 会直接弹出来。

![](../Images/2ea5cdee482fba035c455656667a5d40.png)

## 美国教育市场已是 Chrome OS 的天下

微软官方宣称，安装这款教育版系统的 PC 设备最低只需要 189 美元，将从今年夏天开始推向市场。这个价格确实可以和 Google 的 Chromebook 竞争。在美国的教育市场上，Chrome OS 目前占据着最大的市场份额，曾经的霸主苹果已经渐渐淡出了这场竞争。

根据英国未来咨询公司（Futuresource Consulting）的分析，在美国本土，K-12 年龄段（幼儿园到 12 年级，相当于国内的高三），Chrome OS 保有绝对的优势，并且这个优势一直在增长。

![](../Images/f281f5c96886ae4951566f8e92d3514c.png)图片来自 Futuresource Consulting

从上图可以看出，Chrome OS 的市场份额从 14 年的 38% 一路涨到了 16 年的 58%，在这期间微软 Windows 的市场份额有少许减少，但苹果的损失要大许多，Mac OS 和 iOS 的市场份额在 2014-2016 年期间从 34% 到 19% 下降了接近一半。

不过反观美国以外的地区，Windows 倒是一路高歌猛进，拿下了大部分的小朋友用户。今年，在经历了 Windows RT 的失败后，带着更优秀的系统，更丰富的应用商店，微软强势杀回了美国教育市场，究竟这套轻量级 Win10 系统能不能为微软扳回一城，我们还是拭目以待吧。
