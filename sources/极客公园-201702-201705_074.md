# Windows Phone 死亡倒计时，这副牌微软彻底打不下去了

为什么经过多年「努力」，微软要把 Windows 手机玩死了？

  

手机业务原本是一把不错的牌，不过微软没有玩好，而且似乎也不准备继续玩下去了。  

在国内厂商延续着去年的节奏，接连发布新品的时候，不知道大家注意到没有，以微软 Lumia 为代表的 Windows 手机已经「很久」没有新品推出了。微软观察人士 Paul Thurrott 在推特上发帖称，微软计划在本财年结束前彻底告别手机业务（今年 6 月底）。

4 月 28 日，微软公布了 2017 年第三财季财报，资料显示该季度微软共计营收 221 亿美元，净利润 48 亿美元，营收额和净利润较去年同期均有增长。Office 和云计算业务继续推动微软业绩增长，分别贡献 79 亿美元以及 67 亿美元的收入。

但硬件表现并不令人满意。Surface 本季度营收下滑 26%，为 8.31 亿美元，至于手机产品，微软没有公布太多，只表示手机业务收入本季度下滑了 7.3 亿美元。随后有外媒详细查阅了他们的财报后发现，智能手机业务的收入，只有「可怜的」500 万美元。

![](../Images/4ca81d54298c6e6654f9237c30738637.png)

而从市场研究机构 Kantar 发布的数据来看，截至今年 1 月份的 3 个月内，Windows 手机市场份额在德国下降到 2.9%，而在英国和法国，下降幅度更大，只占 1.9% 和 2.8%。国内市场方面，Windows 更是只剩下 0.1% 市场份额，即使在微软的主要市场美国，Windows 手机也只获得了 1.3% 的市场份额……

微软手机业务的失败已成定局，至于何时官宣放弃手机业务，从财报上看或许近在眼前了。那么为什么微软会把一手好牌打臭了呢？

美国时间 2013 年 9 月 2 日，微软宣布将以 37.9 亿欧元 (约合 50 亿美元) 的价格收购诺基亚旗下的大部分手机业务。虽然就结果来看，微软与诺基亚的结合，远没有联想与 ThinkPad 成功，但即使放在现在来看，当年微软的这笔买卖依旧是极其正确且划算的。

![](../Images/a9959b58039b87b1f00d64a4ddc1863b.png)

要知道，即使当时诺基亚的统治力与之前几年下滑明显，但瘦死的骆驼比马大，显然并非一些后进入市场的新兴品牌所能比拟的，加之微软在 PC 端操作系统领域的深厚技术累积，重新将诺基亚做起来，应该并不特别难。可以说，收购诺基亚，微软已经在硬件以及市场积累方面省去了不少事情。所以说，WP 失败的原因，更多的还是出在软件层面上。

系统更新，是非常致命的问题。事实上，早期 Windows 系统的更新频率并不算低，但很多时候只是做一些边边角角小地方的完善，每次更新的内容完全忽略了用户的反馈。很简单的例子，很长一段时间，你都无法理解为什么 WP 居然没有重力感应屏幕锁定开关。

习惯性的「主动」放弃用户。系统更新对于每个平台来讲，无疑是非常重要的一项内容。由此来实现新功能加入，以及对现有功能的完善，从而为用户提供愈加出色的使用体验。但令人无法想象的是，微软在这件事情上貌似从未给予足够的重视。

微软在对待用户的态度上，仿佛永远处于一种令人无法理解的傲慢上。为了实现用一个统一的 Windows 8 操作系统覆盖手机和 PC，在停止更新很久之后，2012 年 6 月 21 日，微软正式发布 Windows Phone 8。

微软骄傲地宣布，Windows Phone 8 是一个全新的开始，放弃了 Windows CE 核心，使用和 Windows 8 一样的 Windows NT，原本大家对于它拥有极高的热情，然而却被撒了一头冷水。由于内核的改变，所有 WP7.5 系统的手机都将无法升级至 WP8，意思就是说在此之前所有 WP7.5 用户正式被抛弃了。

2015 年 1 月 22 日，微软召开发布会，正式发布 Windows 10。微软指出，Windows 10 将是一个跨平台的系统，无论手机、平板、笔记本、二合一设备、PC，全部通吃。不过由于 WP7.5 升级到 WP7.8 就到头了，这部分用户无法享受到 Windows 10 所带来的诸多新功能。

![](../Images/15aa076b3de47b8a260dddfed96122bd.png)

之前和很多使用 WP 手机的朋友聊到使用体验，得到最多的回复是：流畅性很高，但很多软件用上，没人开发。就应用开发少这件事，实际上它与平台用户量是成正比的，但起决定作用的，个人而言，还是后者。

当然，这些应该是微软关心的事情。作为用户，我们更多的以结果为导向，选择综合表现更出色的产品。而相比其它两个平台，在软件的应用开发丰富程度上，Windows 平台显然还有着相当明显的差距。不佳的用户体验，也让很多人对 WP 手机并不感冒。

这就陷入了一个死循环：体验越差，用户数量越来越少；用户越来越少，微软越不作为，一步步走到了 Windows Phone 基本被整个行业所淘汰的下场。

其实大家对于 Windows 手机当前的状态心中肚明，此次财报的结果只是做了更直观的反映。回顾 Windows 手机的失败，问题还是出在微软本身。如果说微软能够及时去解决这些问题，可能大家依旧会对其抱有期望。然而长期的不作为，也慢慢的消磨掉了很多老用户的耐性，改投其它平台也就成了顺理成章的事情。

至于前几天传闻的 Surface 手机，在如今手机行业足够成熟，并且大致格局已经形成的情况下，如果想要推倒之前的一些东西，重新来做，难度太大，而且你也无法保证结果会比目前市场上成熟的解决方案要出色很多。当然，从微软对于手机业务的态度，想要大力去做，可能性也并不大。
