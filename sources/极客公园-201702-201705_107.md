# 亚马逊研也在研发自动驾驶技术，但并不打算现在就组建「无人车队」

互联网「巨头」涉足自动驾驶领域已经不是什么新鲜事了，但是对于亚马逊来说，在自动驾驶技术上的投资显然是「另有所图」。

  

**编者注：**互联网「巨头」涉足自动驾驶领域已经不是什么新鲜事了，但是对于亚马逊来说，在自动驾驶技术上的投资显然是「另有所图」。

本文编译自 **USA TODAY **（https://www.usatoday.com/tech/），原文标题为**「Amazon team is researching self-driving tech but no plans for autonomous fleet: report」。**

* * *

Amazon 这家电商巨头并不打算建立自动化的车队，但它确实正在研发自动驾驶相关的技术，目的当然是用来解决物流上可能会遇到的问题。

根据《华尔街日报》（https://www.wsj.com/articles/amazon-team-focuses-on-exploiting-driverless-technology-1493035203）的报道，Amazon 的自动驾驶团队成立于一年前，规模不大只有十几个人。目前它主要充当智囊团的作用，同时会研究自动驾驶领域最先进的技术，用于满足 Amazon 庞大的物流需求。

但目前 Amazon 还没有对这一报道做出回应。

Amazon CEO 杰夫·贝索斯，同时也是一家火箭公司 Blue Origin 的负责人，为了商品的物流方式更加多样化，他带领团队做出了很多的努力，其中就包括不断地开发用无人机送快递的技术。实际上，在这一方面 Amazon 的进展很快，未来用无人机送快递很有可能成为 Amazon 作为主要的物流方式。

![](../Images/32440a8075fe72a581bc723143695db1.png)

一年前，这家电子商务公司的中国分公司——亚马逊中国在美联邦海事委员会进行了注册，成为一家合法的海运运输公司。

Amazon 之所以想在自动驾驶领域有所作为，原因是互联网领域有大量专注研究自动驾驶卡车技术的公司，而自然也引起了 Amazon 的「眼红」及思考，它是否也应该涉猎这一「风风火火」领域。

就在去年秋天，Uber 旗下的 Otto 公司使用一辆无人驾驶的半牵引车，在美国科罗拉多州高速公路上成功的完成了一车啤酒的运输工作。这家公司的创始人 Anthony Levandowski 曾是 Google 汽车部门（Waymo）的员工，他被怀疑创建 Otto 之前窃取了 Google 的自动驾驶技术——现在他也卷入了一场法律诉讼之中。这更加坚定了 Amazon 研究自动驾驶技术的决心。

毫无疑问，自动驾驶技术将成为 Amazon 物流「锦上添花」的存在，特别是考虑到它更加节省成本也更加的灵活。

「自动驾驶汽车可以二十四小时工作，但是一般的驾驶员一天只能工作十小时。」Spend Management 是一家位于亚特兰大的供应链和物流咨询公司，它的 CEO John Haber 这样说道。

![](../Images/1623cde6bbebe75d4c0894fe0fc27044.png)

另外，对于 Amazon 来说，它不打算自己建造自动驾驶车队，而是采取和其他公司合作的方式，Haber 一点也不感到奇怪。「这是典型的 Amazon 风格，他们知道什么行，什么不行，然后就找一个能做事的人出来。」

比如，Amazon 最开始找一些快递员来处理快件，之后，一旦了解了他们工作的方式和细节，Amazon 就能够建立自己的递送网络。「Amazon 会把生意从他们的手中抢过来，」Haber 说。

在自动驾驶车队方面，他猜想 Amazon 会先做更多的自我评估，「如果依靠这种技术可以使公司更具竞争力，Amazon 会回到这一领域开创自己的天地，不再依赖其他公司。」

Amazon 使用无人驾驶技术带来的好处也将超过预期，此外该公司庞大的仓库网络也可以协助自动车辆将商品从货架上运到普通的车辆上。

根据华尔街日报的报道，上周 Amazon 还举办了一个名叫「快速运输沙龙」的活动。组织者是 Amazon 的员工 H.B. Siegel，他主要负责创新想法的收集和管理自动技术领域的专家。让我们期待 Amazon 接下来的动作。
