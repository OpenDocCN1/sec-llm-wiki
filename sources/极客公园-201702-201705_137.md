# ThinkPad Stack 投影机体验：除了几乎和 iPhone 6 Plus 一样大小，还能模块化堆栈

ThinkPad Stack 智能投影模块。

  

提到 ThinkPad，可能大家平时了解更多的是其笔记本产品，比如说前几天刚刚发布的全新一代 X1 Carbon。不过，作为商用 PC 领域的老牌厂商，ThinkPad 也从未停止过对其它设备品类探索的脚步，就比如今天要说的 ThinkPad Stack 商务办公投影机。

早在 2015 年，ThinkPad 就推出了 Stack 套件，简单来讲，它是一套简单、有趣的外设模块化外设堆栈。面世之初，Stack 由蓝牙音箱模块、移动电源模块、移动硬盘模块、无线路由器模块四部分组成，之后又陆续新增了无线充电模块以及投影模块。

这次我们拿到手的，是 Stack 套件中的蓝牙音箱模块、移动电源模块、移动硬盘模块、无线路由器模块以及投影模块。接下来一起了解下这套看似「很简单」的模块，同时和大家分享一些我对于 ThinkPad Stack 投影机的体验心得。

## 通过模块化堆栈，它可以拥有更多功能

![](../Images/a2a99e97da37f4a01ee4b1ee490f97a5.png)

ThinkPad Stack 投影机在整体设计语言上和早先面世的其它模块保持一致，同时保留了 ThinkPad 一贯红黑两色的经典元素。另外在表面处理上，按照 ThinkPad 的说法，它采用了「类肤质涂层」。

不过，ThinkPad Stack 投影机的这层类肤质涂层与笔记本所采用的类肤质涂层有所不同。直观视觉上，在不了解的情况下，很容易「经验主义」的认为是磨砂工艺，但实际触感，要更细腻一些。

对比两种工艺处理，典型的类肤质涂层表面，触感要比磨砂工艺细腻不少，但这种工艺为大家所诟病的一点在于，它无异于「指纹收集器」，并且很难擦拭干净。而在使用 ThinkPad Stack 投影机的过程中，并没有出现这种情况，这对于经常需要拿着它进行投影演示，又很爱干净的用户，是个不错的消息。

![](../Images/a192a2f81003484cd829c93c2cfdf3da.png)

作为一台模块化投影仪，移动便携是 ThinkPad Stack 投影机的核心竞争力。官方给出的三围参数分别为 136mm×76mm×32mm，对比 iPhone 6 Plus 的 158.2mm×77.9mm×7.3mm，它只是在厚度上要更厚一些，搭配 357g 的重量，很方便携带。

软/硬件配置部分，ThinkPad Stack 投影机搭载了安卓 6.0.1 操作系统，内置 Intel 4 核处理器、2GB 内存、16GB 机身存储。在播放视频以及 PPT 这些应用场景下，流畅度表现不错。

ThinkPad Stack 投影机的触控板操控上，三个图标按键与其它安卓设备一样，这里不做赘述。值得一提的是，它支持最多两指操作，包括上下翻页以及放大缩小。

![](../Images/8925ffa28a0d8c4c8701286386494d3e.png)

通常来讲，便携型微投普遍在 200ANSI 流明~500ANSI 流明之间，家用型微投普遍在 500ANSI 流明~1000ANSI 流明之间，高端的家庭影院投影机，亮度在 1000ANSI 流明左右。另外，出于对客厅使用需求的考量，现在市面上一些入门级的家用投影亮度为 2000ANSI 流明~3000ANSI 流明。

官方给出的参数，ThinkPad Stack 投影机的这颗投影灯为 150ANSI 流明，相对略低一些，后边的实际投影效果方面，我们也会对它的投影亮度进行展示说明。

![](../Images/3fad1cc419f795b25b8c47f17cacac73.png)

位于机身背部的开/关机按键。

![](../Images/24faceb9534a7f90b566ced185a8297d.png)

右侧提供 1 个 USB 2.0 接口、音频接口、HDMI 接口、方口电源接口（支持正反插拔）以及安全锁孔。值得一提的是，使用外接 U 盘或者硬盘的时候，ThinkPad Stack 投影机可以直接读取内部文件。

![](../Images/f62ddcf5498c6977a7f0d8e2ea2220dc.png)

底部除了可调节投放角度的支架，中央部位是一个标准的三脚架快拆版接口。虽然在大多数情况下，这个接口并不一定会用到，不过在某些小型会议需要用到三脚架的场合下，这个接口的存在，可以方便很多。

![](../Images/6db67d93c880f540ec678af6307dd9c4.png)

除了 ThinkPad Stack 投影机底部自带的支架，它的包装盒里，附带一个支持更大调节角度的支架模块，该模块拥有两级可调选项，你可以根据实际使用需要，来选择合适的高度。

![](../Images/a58118061be21515e6949e1d96826a46.png)

 ThinkPad Stack 投影机的 65W 电源适配器。

![](../Images/801b2fe8afd3761c8b489c72363a8e39.png)

随 ThinkPad Stack 投影机一起的，还有一个起到保护作用的包，手感很柔顺。

![](../Images/a26c6b461af9d1d84f52efb65a43460f.png)

无线路由模块内置 802.11ac 双频 WiFi，机身左侧配备两个 USB 接口，背部设置有 100 兆有线接口。需要注意的是，该模块没有内置电源，独立使用情况下，它的供电是通过 Micro USB 接口来完成的。

![](../Images/94fd73c9d58f03daa4cfaba3b47dbf71.png)

![](../Images/02157d84493d9e9fec9736ecb7b89def.png)

蓝牙音箱模块采用蓝牙 4.0 标准，前面板设置有音量调节按键、播放/暂停按键，另外配备有 Micro USB 接口、3.5mm 音频接口。不同于的无线模块，它有内置电源，支持单独使用。

![](../Images/b302ea275b7d17b114d7ed1246beeb0d.png)

移动电源模块容量为 10000mAh。它拥有两个标准 USB 接口和一个 Micro USB 接口，输出功率分别为 5V/2A 和 5V/4A。另外有关它的充电问题，我的建议是，虽然利用投影仪模块同样可以为它充电，不过效率相比自带电源适配器，要低很多。

移动硬盘模块是一块容量为 1TB 的机械硬盘，数据连接接口为 Micro USB 3.0 接口。

![](../Images/70c9222057667279280ee7fc3ee900a4.png)

说下不同模块之间连接以及顺序。ThinkPad Stack 的模块之间由顶部的圆孔与底部的凸起扣合实现，彼此之间通过磁吸的方式来「加固」，找准不同磁极可以很方便完成组合。

另外在组合顺序方面，有两种方式可选。一种是：ThinkPad Stack 投影机模块、移动硬盘模块、无线路由器模块、移动电源模块、蓝牙音箱模块。

![](../Images/826cdb3adc3f7b7cf6da1d176e82704c.png)

另一种组合方式是：ThinkPad Stack 投影机模块、蓝牙音箱模块、移动电源模块、移动硬盘模块、无线路由器模块。如果两块移动硬盘模块，则上下各一块，中间为无线路由器模块。总结来讲，无论哪种组合方式，一定要让移动硬盘模块与无线路由器模块相邻。

![](../Images/12b6fc90dfd0e90f3c6cdc5374b823bc.png)

## 如何用手机操控 ThinkPad Stack 投影机

ThinkPad Stack 投影机除了可以与其它模块组合使用，支持与手机连接同样是一大亮点。连接之前，首先需要下载「lenovo Stack Assistant」应用软件，两种下载途径，一种是扫描二维码，另外一种是登录 http://www.lenovo.com/stack 下载（iOS 与安卓平台均支持）。

在上一步基础上，ThinkPad Stack 投影机提供两种与手机连接途径。有 WiFi 情况下，分别将二者连接至同一局域网下即可完成接下来的「配对」操作；如果没有 WiFi，连接的时候要多一些步骤，你需要通过 ThinkPad Stack 投影机自建热点，然后将手机连接到建立的局域网下，后续步骤同理。

![](../Images/5e01489085c57b889124d8ca480e3cb5.png)

与 ThinkPad Stack 投影机连接成功后，手机界面会显示目前已连接模块的相关信息，比如可以直接读取出目前投影机的电量剩余以及充电状态等。点击选择投影仪这一项，即可进入投影仪控制界面，此时手机与投影机均可进行操作控制。

你可以通过右上角的「文件夹」图标来读取手机内图片、视频以及文档。手机屏中央的操控区操作方式与 ThinkPad Stack 投影机触控板一样，同样支持两指操作。

![](../Images/67694cb80706421d89d696657d9ee1f3.png)

## 便携与显示效果，它更看重前者

重点说下 ThinkPad Stack 投影机的投影效果。它的分辨率为 720P，支持 1080P 片源，支持自动梯形校正，投影范围可调节 35-120 英寸画面。不过不支持自动对焦，只能通过手动对焦的方式来实现，刚入手不适应情况下，进行微调有些困难，需要反复进行几次调节才能达到最佳效果，适应之后，调节起来要轻松很多。

![](../Images/65e5abde81303dc917c1226a7e052e9c.png)

亮度问题在前边介绍投影灯的时候留下了一个「梗」，这里来解答下。前边讲到 ThinkPad Stack 投影机配备的这颗投影灯为 150ANSI 流明，从实际的画面展现来看，在暗光条件下，它可以很好完成视频播放任务，拿到光线较亮的地方，表现要差一些。

不过客观来讲，在拥有如此「娇小」机身的条件下，确实无法对 ThinkPad Stack 投影机有太过苛刻的要求。拿它和大型投影仪去对比亮度有失公允，毕竟在便携性方面，它已经足够出色。

![](../Images/ec411d7f6f2edfc8966e7cadd39365c6.png)

 ThinkPad Stack 投影机预装了必备的办公软件 WPS Office，用于方便阅读文档，当然，你也可以进行文字编辑，但实际体验并不算好，用手通过屏幕来操控鼠标指针来进行文字输入，有些费劲，不过应急是可以的。

![](../Images/2bd260a837d6efbf658d41bb2b9460c2.png)

与电脑连接使用是每台投影仪都可以做到的功能，这部分 ThinkPad Stack 投影机没有特别的地方。值得提醒的是，目前它只支持通过 HDMI 线与电脑连接。至于后期是否会像手机一样，可以通过 WiFi 的方式来连接，只能说很有可能。

![](../Images/841276bc9f77c93ee1b944b0ce559f8e.png)

## 写在最后的话

文章到这里差不多接近尾声了。回过头来看 ThinkPad Stack 投影机，模块化和便携性是它吸引人的地方。对于商务办公人群来讲，笔记本也好，投影仪也罢，便携性无疑是他们更为看重的一点。

特别是进行小型会议，随手拿着 ThinkPad Stack 投影机就可以进行内容演示。不过对我而言，可以自由组合的模块化自然更有吸引力。整体来讲，ThinkPad Stack 投影机是一款很有趣的模块化产品，拿来作为移动的电影院，或许也是个不错的选择。

最后来说下售价。联想官方商城给出的 ThinkPad Stack 投影机模块为 3999 元、移动硬盘模块为 799 元、蓝牙音箱模块为 499 元、无线路由器模块同样为 499 元，没有给出移动电源模块价格。

我试着从京东商城上查询 ThinkPad Stack 移动电源模块价格，结果分为 299 元和 399 元两种。计算下来，想要配齐这一套设备，至少需要 6095 元（移动电源模块按照 299 元计算）。当然，你也可以根据自己的需要选择性搭配。
