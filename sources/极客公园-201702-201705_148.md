# 除了更轻更小更快，新 ThinkPad X1 Carbon 还多了三面超窄边框

过去一年里，PC 厂商推出了很多非常优秀的轻薄本，比如说戴尔 XPS 13、惠普 Spectre 13、联想 YOGA 5 Pro，不过在相当长一段时间里，去年的第四代 ThinkPad X1 Carbon 是我们最喜欢的一款 Windows 轻薄本。  

在一款优秀轻薄本应该具备的几个基本点上（包括设计、做工、性能、续航、屏幕），ThinkPad X1 Carbon 基本都没什么可挑剔的，另外，ThinkPad X1 Carbon 还拥有可能是轻薄本中最优秀的键盘和最丰富的接口。

![](../Images/06d9aca4a0b98f9a3890bbf39aff3f7b.png)

在今年年初的 CES 上，联想展示了 2017 年款、也就是第五代 ThinkPad X1 Carbon 以及新一代的 X1 Yoga 和 X1 Tablet，4 月 18 日，联想终于把这三款产品带到了中国市场。

## ThinkPad X1 Carbon 2017：从内到外的全面升级

作为一款 ThinkPad 的「经典系」产品，X1 Carbon 过去几代产品在外观上的变化都不大，直到这一代的 X1 Carbon 2017。

**媲美 XPS 13 的三面超窄边框**

ThinkPad X1 Carbon 2017 在外观上最大的变化就是屏幕部分采用了三面超窄边框设计。

![](../Images/259c1816ca9d98fcbaaefcfc4394dd39.png)

相比三面超窄边框的「鼻祖」戴尔 XPS 13，X1 Carbon 2017 的左右边框宽度相当（5—6 毫米左右），不过上边框要比 XPS 13 略宽一点，但这让 X1 Carbon 2017 可以把摄像头「正常」摆在屏幕上方（摄像头可选配 Windows Hello），避免了 XPS 13 那样由于上边框太窄不得不把摄像头挪到屏幕右下角，进而导致视频时画面角度很奇怪的情况。

![](../Images/09288f35be827b9f3f089d6c22c0c56a.png)

发布会上，联想还特意强调了 X1 Carbon 2017 的超窄边框是在不妥协强度的情况下做出来的。为此，X1 Carbon 2017 在 A 面继续使用碳纤维的情况下，在屏幕边框上加了一圈玻璃纤维加固框，以提高抗跌落性。

![](../Images/3851f22e959df3ae7086b870f38f9147.png)X1 Carbon 2017（左）和 X1 Carbon 2016（右）

除了视觉上的提升，X1 Carbon 2017 的三面超窄边框设计还明显缩小了整机的体积。具体来说，2016 款的 X1 Carbon 的「三围」是 333 mm x 229 mm x 16.45 mm，而 X1 Carbon 2017 为 323.5 mm x 217.1 mm x 15.95 mm，差不多是长宽各少了 1 厘米。

重量上，X1 Carbon 2017 进一步降低到了 1.13 公斤，上一代产品为 1.2 公斤。

![](../Images/191cef630467f6630079ec00888bf708.png)X1 Carbon 2016（上）和 X1 Carbon 2017（下）

另外，X1 Carbon 2017 放弃了上一代产品的铰链式转轴，转而采用了轻薄本中常见的下沉式，转轴的大小也缩小了很多。  

下沉式转轴的设计意味着 X1 Carbon 2017 无法使用上一代产品那样的后置出风口（因为屏幕开合后会挡住），针对这个问题，下沉式转轴轻薄本中常见的方案是把出风口放在 B 面和 C 面相交的位置（也就是 MacBook Pro 用的那种方案），不过 X1 Carbon 2017 并没有这样做，而是把出风口放在了右侧。

这种设计的优点是更方便在小空间内做出更好的散热，缺点是使用鼠标时，右侧出风口的热风可能直接吹到手上，不过考虑到超极本本身的热量就不大，加上 ThinkPad（尤其是高端型号）在散热上的优秀口碑，这个设计应该不是什么大问题。

**新一代硬件平台，更优秀的续航**  

硬件方面，X1 Carbon 2017 并没有太多意外的地方，包括 Intel 第七代 Kaby Lake 架构低电压Core i 系列 CPU（TDP 为 15W），最大支持 16GB 1866MHz LPDDR3 和 1TB PCIe NVMe SSD，14 英寸 IPS LED 屏幕，分辨率为 1080p 或 2K，不支持触摸。  

![](../Images/58baff8759f2931df7e7d4275fb7e2b9.png)

值得注意的是，虽然 X1 Carbon 2017 相比上一代产品在体积上明显缩小，不过它的电池容量依然达到了 57WHr，比上一代 X1 Carbon 的 52WHr 还稍微大了一点。

更大的电池，加上功耗表现更好的 Kaby Lake 处理器，X1 Carbon 2017 的续航表现相比上一代产品应该会有所提升，而[在我们的测试中，上一代 X1 Carbon 在日常使用者可以坚持 6—7 个小时。](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652841165&idx=1&sn=019ac9b717e62640a8c99090757bb694&scene=21#wechat_redirect)

此外，X1 Carbon 2017 也支持快速充电（用的应该是 USB-PD 协议），充电头功率 65W。在电脑完全没电的情况下，一个小时就可以充到 80%。

**一台标准的 ThinkPad**

除此之外，X1 Carbon 2017 也保留了众多 ThinkPad 的经典设计，比如碳纤维材质的 A 面、表面为手感舒适但容易沾油污的类肤质涂层、轻薄本中几乎手感最好的键盘、标志性的小红点等等。

![](../Images/0d7d4b0897b19e81355081cf239562a9.png)

在接口上，新 X1 Carbon 依旧足够「良心」，包括两个 USB-C（支持 Thunderbolt 3，均可以用于充电）、两个传统的 USB-A 母口（左右各一个）、标准 HDMI、mini RJ45（注意是 mini 版，插大部分网线需要转换头）、Micro SD 卡（注意不是标准 SD 卡）、3.5 毫米耳机插孔，并且预留了 SIM 卡卡槽，可以选配 4G 上网模块。

**售价 & 上市时间**

有趣的是，[在 CES 2017 上，除了常规的黑色版本，联想还展示了银色的 ThinkPad X1 Carbon 2017 和 ThinkPad X1 Yoga 2017](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652845283&idx=4&sn=489e171b514b9bdb4b2a2da6c109c99f&chksm=7e6a4955491dc0432bff2429de2d68dd6c98a1e779fb53f396a2550ec557e9e7c138c89a860d&scene=21#wechat_redirect)，不过在这次的发布会上，联想对银色的版本只字未提，上市的产品也只有黑色可选。

![](../Images/017f19939ccc4b81c21f5e0a3005e659.png)

目前联想在官方网站提供了两种规格的 X1 Carbon 2017 可选，i5-7200U / 8GB / 256GB SSD / FHD 售价 9999 元，i7-7500U / 8GB / 256GB SSD / FHD 售价 12999 元，已经在发布会之后第一时间正式开售。

值得注意的是，这次国行版 X1 Carbon 2017 的售价比美国地区还要略低。目前美版 X1 Carbon 2017 的起售价为 1329 美元（i5-7200U / 8GB / 128GB SSD / FHD），把硬盘升级到 256GB 要增加 240 美元，总价为 1569 美元（约 10800 元）。

## ThinkPad X1 Yoga 2017 和 X1 Tablet 2017

除了全新的 X1 Carbon 2017，ThinkPad「X1 家族」的另外两位成员 X1 Yoga 和 X1 Tablet 也得到了升级。

**我们先看一下 X1 Yoga 2017。**

相比 X1 Carbon 2017，X1 Yoga 2017 最大的变化是屏幕支持触摸并且可以进行 360 度旋转，这也是它叫做「Yoga」的原因。

![](../Images/d14f67410ec2e5495fd251bc5ad79ffb.png)

此外，X1 Yoga 2017 还支持 2048 级的压感笔，除了常规的 IPS 屏幕，还可以选配 Adobe RGB 高达 97% 的 OLED 屏幕，获得更加优秀的色彩表现。发布会上，联想还特意强调了 X1 Yoga 2017 的 OLED 屏幕具备优秀的色彩管理能力，适合设计师等对显示品质有高要求的用户。当然了，升级 OLED 屏幕的话，价格自然也要高上不少。

相比上一代 X1 Yoga，X1 Yoga 2017 主要有两个变化：第一是采用了 Intel 新一代 Kaby Lake 平台，第二是全新设计的键盘（联想把它叫做「升降式呼吸键盘」）。

为了提高在平板模式的使用体验，X1 Yoga 的键盘采用了独特的伸缩设计：在屏幕翻转到 180 度以上后，键盘部分会缩进去，这样在作为平板使用时，背面的键盘就不至于这么烦人了。

不同的是，上一代的 X1 Yoga 的键盘在缩进时，是键盘所在的托架（可以理解为电脑 C 面的一部分）缩进去的，这样的问题是托架缩进去之后，C 面并不是一个完整的，作为平板电脑使用时会感觉到有些硌手。

![](../Images/fc8b2b1e9e36d9f492012fb616b40be3.png)

而这一代的 X1 Yoga 2017 在缩进时，键盘所在的托架是不动的，只是单个的键帽往里缩，这样键盘在缩进后，整个 C 面几乎是一整个平面，手感更好。

此外，X1 Yoga 2017 在合上屏幕时，键盘也会往里缩，打开屏幕时键盘又会「浮」出来（联想的说法是「开合翻转呼吸」），看上去很有科技感。

**最后是 ThinkPad X1 Tablet 2017。**  

![](../Images/9f93388b1a5a73066d7e76a2635ab6c3.png)

相比上一代的 X1 Tablet，X1 Tablet 2017 在外观设计上基本保持一致，最大的特色依然是模块化设计，可以外接包括全尺寸键盘、投影仪、拓展电池等众多模块。此外，X1 Tablet 2017 也换用了 Kaby Lake 平台，最高可选用 Core i7-7Y75（上一代 Skylake 架构 Core M7 的升级版本）。

**售价方面，X1 Yoga 2017 的起售价为 10999 元，X1 Tablet 2017 起售价为 8499 元，这两款产品将于今年六月份正式开售。**

**![](../Images/25ecf67e1c683eac07bb6aba7cfa78e6.png)**
