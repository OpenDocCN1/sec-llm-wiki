# 玩了一下午索尼的教育机器人，我真感觉又回到了童年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652846530&idx=1&sn=6a0e35d5a0dd9c1595acbb2089c0ab2d&chksm=7e6a4474491dcd629084746a249b6135b9d3a3abe4f0496f14b00e8a635448a11e60ca26bb5c&scene=126&sessionid=1681311265#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652846530&idx=1&sn=6a0e35d5a0dd9c1595acbb2089c0ab2d&chksm=7e6a4474491dcd629084746a249b6135b9d3a3abe4f0496f14b00e8a635448a11e60ca26bb5c&scene=126&sessionid=1681311265#rd)

![](../Images/da10f78d8e45dd192e1022fdfbd30404.png)

这一次，你可以带上你的小孩，一起守护姨夫的微笑。

  

**作者 |  谁是大英雄**

不得不说现在的小孩儿真的很幸福，他们能玩的东西太多了。对大多数孩子来说，他们生活中不光有各种玩具，还有电脑、平板和其他许许多多的数码产品，相比以前我们童年有啥玩啥的状态，他们是想玩啥都能找得到。  

说起积木，它可能显得过于「传统」，大家能说出来的除了乐高也没有别的。可你知道吗，作为黑科技行家的索尼，最近也出了一款积木——可编程教育机器人 KOOV。这一次，索尼不但想让积木「活」起来，还想打造出具有科技感的百变形态。究竟它长什么样，好不好玩？在花了一下午组装出了一台「消防车」之后，是时候让我来告诉你答案了。

## 不只花花绿绿，动起手来就有「绝技」

![](../Images/f3b23ff86c879772a1ea1727435a91fa.png)

这一次我体验的是 KOOV 豪华版，它是由索尼旗下索尼国际教育（Sony Global Education）推出的产品，在今年 3 月拿到了 IF 产品设计奖。不过，没收到产品之前，我内心里总感觉这只是小孩子玩的东西，因为可编程教育机器人我之前也见过几种，心里感觉这一次也大同小异。

但当我拿到产品开箱后才发现，两个盒子里满满当当全是五颜六色的积木方块，大大小小一共三百多个零件。

![](../Images/5c760815e14aa973ef39668a5b4de19b.png)

值得注意的是，这套积木的产地是日本而非国内，零部件做工很不错，没有那种粗糙的感觉，也没有任何异味。

![](../Images/1bc6886a598894093ea2437d9fac2781.png)

而且，除了各种颜色的积木块之外，还包括了伺服电机、红外线传感器、加速度传感器、光敏传感器这样的非常具有探索性的配件。当时我脑海中的反应是「这真的是给小孩玩的吗？」

![](../Images/9588c292781bd20d4680afbb246d0c57.png)

![](../Images/90c8d35cf8acbdcdf68d57f676b3256d.png)

虽然有点不知所措，我还是按部就班，从指导开始一步步来。在平板（也可以是 Windows 或者 Mac 电脑）上下载 KOOV 的配套程序后，简单注册之后就能使用，这里需要注意的是，KOOV 的账号和套件是一对一的，说明书上的注册码也是唯一的。

![](../Images/c971128d8108e0ad55c506c44224a017.png)KOOV 包含了七种不同类型的基础零件

基础教学之后，其实已经可以撸起袖子开玩了。对于一开始不知道要拼个什么东西的人来说，从官方推荐的模板中学习是快速熟悉的方法（官方目前提供了 22 个模板以供参考），作为一个成年人，我果断选择了难度最高的一个——消防车。

![](../Images/d507ed47390431432a77b3f7a8cf3568.png)

![](../Images/63dc73b7bb71529748bd24acc60bca3d.png)

类似于乐高，所有这些积木都可以通过插槽相连，但相比起来，它的特点是花花绿绿和半透明，颜色更加鲜亮，想必对很多孩子们来说，这种风格会更讨人喜欢。

![](../Images/b27d3d13a08ad9cea7cd921abb3ec48d.png)

我以为最难的模式只是对小朋友很难，其实在真正开始拼的时候才发现，整个过程还是有些挑战的，比如组装这个消防车一共有 77 步，虽然每一步都被分解到最基础的程度，但仍然需要你仔细分辨不同积木以及对应的插槽，不能有任何差错，虽然我在这里说的很轻松，但实际操作起来，还是相当考验手眼协调和空间观察能力的。

索尼在发布这款产品时曾经表示，现在的教育正在转变为 STEM 模式，STEM 是指科学（Science），技术（Technology），工程（Engineering），数学（Mathematics）四门学科的总称，实际上，索尼选择通过 KOOV 在软件和硬件上打造出一套具有特点的 STEM 教育工具，目的是通过这套可编程积木机器人使孩子学会 Think（数学教育）、Make（机器人教育）、Feel（科学教育）三种新的学习方式，虽然概念很高大上，但实际上，通过接地气的编程机器人，孩子们在玩的过程中也能掌握一些科学知识，这一点就是 KOOV 最吸引人的地方。

![](../Images/8c28c2d4cab488c6c603f263acf7f47c.png)

当然，组装过程对于任何一个小孩来说都是循序渐进的过程，如果在教程中他们看的不是很明白，还可以通过「当大/缩小」和「旋转视角」来更好的掌握。

![](../Images/4c6a9f0edb0f240f15d79b2f754e3cb2.png)

![](../Images/2f03eeeb18d2134003ff309c776570f0.png)

由于我中途拼错了一次，导致回去检查耗费了点时间，所以大概用了两个小时才终于把这个「消防车」拼好了。我相信如果熟练的话，能大大提高组装速度。最后，我终于完成了这个「消防车」。

![](../Images/594a2ffe79e740c55ddc35e12b2e4cd2.png)

完成之后，在你的 iPad 上，可以看到获得了相应的成就，你也可以把自己的成果拍下来分享到 KOOV 的官方社区里。还有一点是，实际上作为一个积木套装，你可以用它发挥出你天马行空的想象力，拼出你想要的东西。

![](../Images/b6f573bb5bd6c359109096391231be1d.png)

## 在玩耍中看到更多可能性

获得快乐的方法有很多，小孩子的玩具也有很多，而之所以近年来像 KOOV 这样的可编程教育机器人越来越多，很重要的一点是，它不局限于玩具传统的概念，而是提供了更多玩法上面的突破。

![](../Images/9e0835e983d1ec4b61cd1cc25fb3439c.png)

其实经过上面的介绍大家可能会有疑问，这个积木玩具也就是组装成一个「消防车」或者其他什么物品而已，好像也跟其它积木没有什么两样，作为索尼出品的玩具，总该有一些让人眼前一亮的内容吧？

当然有！如果你注意到我拼好的消防车，会发现上面有很多面条一样的线，还有一个控制器一样的东西。因为它们的连接，我的消防车「活」了，不信你看👇

![](../Images/f61860c2ed94d3934cc8ef786787b24e.png)

而且，按住另一侧开关，还能控制它的消防梯👇

![](../Images/01a70c496269d785edcc779990c5de1e.png)

这可不是简单的遥控器控制，实际上这是通过加速度传感器配合伺服电机来控制的。通过将那些线连接到控制中心面板，再制造一个简单的遥控器，就能控制它做很多很有意思的事情。

比如说，让「挖掘机」动起来~

![](../Images/23e7273250ccd3714416d875c097eea3.png)

或者让小猴子拍手👏

![](../Images/44dde3cb2440af0334192a5e7d02fd75.png)

这些都是在你拼好积木之后，通过程序来控制实现的，而在软件中，你还可以为它添加更多你需要的动作。

![](../Images/fa60462e9eec7102efeb103fe7f69ee9.png)

尽管孩子们可能并不了解如何编程，但通过这样非常直观的引导，他们也能对这件事有更深的认识，会知道，编程能让积木「活」过来，这听起来就很吸引人。这也是为何，在这样的积木套装里，会有红外线传感器、加速度传感器、光敏传感器这样的零部件，通过进一步编程，它们能有丰富的玩法和操作空间。

![](../Images/139e330e439c0a98f399f5ba3902569e.png)

而且实际上，在软件上面有专门的编程入门，配合积木会从最简单的编程开始学起，每完成一课会有相应的成就奖励，如果孩子们真的感兴趣，那么软件能提供非常大的帮助。

另外，索尼官方还在今年进行了线下的课程活动，已经开始将 KOOV 的编程课程「送入」北京、上海等地的小学，这种线上和线下合作的方法，也将有可能对很多孩子起到促进作用。

作为一款儿童可编程教育机器人，索尼 KOOV 应该会是那些喜欢动手，好奇心旺盛的孩子们最好的朋友，基础版 1799 元，豪华版 3999 元，售价可不便宜，但仍然是给孩子最好的礼物。考虑到零部件中自带的各种传感器也有很多可玩空间，我认为这不仅仅是一套孩子们的宝物，对应于一些技术宅们，也可以发挥更多想象空间，说不定将来，还能带着孩子一块儿玩呢。
