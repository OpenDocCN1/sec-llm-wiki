# 红米 Note 4X 初音未来限量套装来了，你喜欢吗

**作者 |  豆腐店店长**

  

在被「左手右手一个慢动作」洗脑之前，更早的「甩葱歌」应该是我单曲循环次数最多的。当然，我口中所说的，并非由芬兰的波尔卡舞曲改编而成的那首，而是「民间」流传的日本虚拟歌姬初音未来翻唱的版本。  

实际上初音未来（初音ミク/Hatsune Miku）并非现实意义的歌手，而是 2007 年 8 月 31 日由 CRYPTON FUTURE MEDIA 以 Yamaha 的 VOCALOID 系列语音合成程序为基础开发的音源库。而包装封面上的那位葱色头发的少女，也被大家广为熟知。

![](../Images/85085454835b29b4d47d6c53952adc86.png)

今年 2 月 14 日情人节当天，小米正式发布了红米 Note 4X，其中就包括今天要为大家介绍的「初音未来限量套装」。时隔 2 个月之后，我们也正式拿到了这台特殊的红米 Note 4X。

外包装盒上显眼的 MiKu 形象以及初音未来字样，让你一眼就能分辨出，它与其它版本红米 Note 4X 的不同之处。

![](../Images/6fe8052c199b7f1f73afd28fc851bea8.png)

打开外包装，在手机盒上可以看到「永远相信美好的事情即将发生」字样。另外，此次「初音未来限量套装」包装盒的颜色，采用了颇具特色的蓝绿色（初音绿）配色。

![](../Images/4ea7e18c1c1fec446a470b93274c2184.png)

![](../Images/3f3f6081b4e679f03b95dd9ab4b2a0e6.png)

之所以称为「初音未来限量套装」，是因为除红米 Note 4X 之外，还包含限量版印有初音未来的移动电源以及手机保护壳。

![](../Images/8da925ff6a1d7bae3c138fa500323fa4.png)

初音未来限量版红米 Note 4X 的正面与其它版本并没有不同的地方，依旧拥有一张「大众脸」。让人有些意外的是，开机之后的主题设置选择上，默认状态下，这台手机依旧提供我们熟悉的几种选项。

与前几天 vivo 推出的 Xplay6 库里定制版有所不同，初音未来主题需要后期自己下载。

![](../Images/0876256f68d9ab70a1cf83080f0b0523.png)

机身配色方面，这台初音未来限量版意料之中地采用了与外包装盒一致的初音未来专属配色。另外，红米 Note 4X 提供香槟金、铂银灰、樱花粉和磨砂黑四种不同选项。

![](../Images/3c044c354c769f74c6c742ec10411a69.png)

红米 Note 4X 依旧是目前常见的三段式机身设计，不过上下两块塑料贴片与后盖的过渡部分采用了亮面凹槽，而并非与后壳相同的蓝绿色（初音绿）配色。

背面的摄像头和指纹识别模块对称放在闪光灯上下，其中摄像头为 1300 万像素，有相位对焦，无光学对焦，属于千元机主流水准。

![](../Images/2c854eceae99046f14f5988a647fd51c.png)

后壳下方同样印有明显的「初音未来」字样。

![](../Images/c40b18ffe2f792d86e45353dfe55aa99.png)

![](../Images/379ca5562cbb0869a625e02895dce0f4.png)

由于红米 Note 4X 采用了圆滑的棱角过渡，并且后壳为略带弧度设计，它的握感不错。

![](../Images/17c6c0eaf061f71317823f2d0ca02d03.png)

接口部分，红米 Note 4X 沿用了 Micro USB 接口，而不是目前颇受推崇的 USB-C 接口。也就是说，它不能满足你方便地进行数据线盲插操作。

![](../Images/f1ff9caca36ce0f9ce94590512bdeaf6.png)

套装内所包含的初音未来保护壳。

![](../Images/6723146308e15c0aed22d4ff33dbfa4e.png)

![](../Images/4afef9fc5445e5eec27925af0999a0aa.png)

套装内的配套的印有初音未来移动电源，配色同样为蓝绿色。它的容量为 10000 mAh。

![](../Images/6a0f7554e2f5a2a4abf7f71833b44873.png)

![](../Images/7fa11519a7893976cd5e942cfa24f151.png)

红米 Note 4X、配套移动电源、初音未来保护壳全家福。

![](../Images/9f52813f219954a03b552cf13d4bc950.png)

硬件配置部分，它和之前的几个版本一样，依旧提供标配以及高配两个版本。其中标配版为 3GB 运存+ 32GB 机身存储（支持额外扩容 128GB），搭载骁龙 625；高配版为 4GB 运存+64GB 机身存储（支持额外扩容 128GB），搭载 MTK Helio X20。

![](../Images/3d4ce8e7b82c8fd6765605244375895a.png)

最后来说下购买及售价。目前「哔哩哔哩」红米 Note 4X 预收页给出的 3GB+32GB 版价格为 1299 元，比其它版本标配版本要多出 300 元，高配版目前并没有给出具体的价格。
