# 小米平板 3 体验：外观不变，内在大不同

大屏手机当道，你是否还需要一部 Android 平板？

  

**作者 |  colorvc**

聊产品前，先说个故事。

今年过年的时候，一个朋友问我，想给父母买一台 Android 平板，预算在 1000—2000 之间，有没有什么推荐的产品。我琢磨了半天，实在是想不出什么太好的选择，最后推荐了一年半以前发布的小米平板 2。  

在过去几年中，由于非 Windows 平板电脑的市场一直在萎缩，导致包括苹果在内的几乎所有主流品牌都明显减少了在新品上的投入，特别是在 1000——2000 元这个价位内，除了华为在通过 ODM 的方式象征性地更新产品线之外，几乎找不出几款像样的新品，以至于小米平板 2 在发布了一年半之久且一直没有降价的情况下，依然是这个价位最值得购买的产品之一，这在两三年前的平板电脑市场是难以想象的。

今年，趁着米粉节这个时候，小米总算发布了小米平板 2 的升级产品——小米平板 3，下面我们就来看看这款姗姗来迟的新品有何特别之处。

## 外观：这不就是小米平板 2？

单看外观，很难看出小米平板 3 相比小米平板 2 有什么变化。

![](../Images/3c65b3756ec84da95cd2c7ecad1b1b98.png)

首先，小米平板 3 采用了和小米平板 2 相同的 7.9 英寸 LCD 屏幕，分辨率 2048 x 1536（长宽比 4：3），ppi 为 326，这三项参数均和 iPad mini（第一代除外）相同。相比常见的 16：9 屏幕，4：3 的显示比例带来了更大的显示区域，更加利于阅读。

![](../Images/32dde93f897f75798575f6d1da675f5a.png)

值得一提的是，小米平板 3 的这块屏幕采用了全贴合工艺，保护玻璃和显示层紧贴在一起，可以让屏幕观感更加通透。实际的显示效果上，小米平板 3 也没啥毛病，整体表现介于采用非全贴合屏幕的 iPad mini 2 / 3 和全贴合屏幕的 iPad mini 4 之间。

![](../Images/b2878ec9b852a7d434b52bc013606652.png)

在机身的设计上，小米平板 3 和小米平板 2 也没什么区别。

![](../Images/4679335b75b662c5b4631651329d3187.png)

二者都采用了一体式的全金属机身，机身表面采用了喷砂工艺，工艺水准距离 iPad 略有差距，但在这个价位的 Android 平板中已经是非常难得了。

![](../Images/0de6ebf6459725552c2194e964df78ef.png)

后置摄像头像素为 1300 万，没有突起。

![](../Images/916c98bb81ebb658e8de258c5f52925e.png)

底部采用了 USB-C 接口，标配了 5V 2A 的充电头。

![](../Images/88b0fbc9786bfb1af54531ffce2fd05b.png)

顶部的 3.5 毫米耳机插孔。

![](../Images/31d7c3f998a1276c42f7ca44aa283e94.png)

屏幕下方依旧保留了小米「招牌式」的三颗实体触摸按键。

![](../Images/ba0e61e90ecadd7eb65d00da247005ed.png)

在厚度和重量上，小米平板 3 控制地同样不错。328 克的重量（iPad mini 4 约为 300 克）和 6.95 毫米（iPad mini 4 为 6.1 毫米）的厚度让小米平板 3 很适合长时间拿着使用。

总体来说，在外观和工艺上，小米平板 3 基本是完全照搬了小米平板 2。不过除了视觉上没啥新意，这并不是什么毛病，即使现在来看，小米平板 2 的外观、尺寸、手感也都非常合适，小米平板 3 也是如此。

## 配置：回归主流

相比起有些「无聊」的外观，小米平板 3 在配置上发生了明显的变化，我们先来看一下它的配置清单。

> 屏幕：7.9 英寸 LCD，分辨率 2048 x 1536，ppi 326，支持黑白显示模式
> 
> SoC：联发科 MT8176（CPU 为 2 \* A72 + 4 \* A53，GPU 为 PowerVR GX6250，28nm HPM 制程）
> 
> 内存：4GB LPDDR3 双通道
> 
> 存储：64GB eMMC5.0
> 
> 后置相机：1300 万像素，f/2.2光圈，支持 1080p 录像
> 
> 前置相机：500 万像素，f/2.0 光圈
> 
> 电池：6400 毫安时（最小值）；6600 毫安时（典型值）
> 
> 电源适配器：5V / 2A
> 
> 机身尺寸：200.4mm \* 132.6mm \* 6.95mm
> 
> 机身重量：328g
> 
> 操作系统：MIUI 8.2，基于 Android 7.0
> 
> 其它：USB-C，蓝牙 4.1，支持 802.11 ac
> 
> 颜色：香槟金
> 
> 售价：1499 元

相比小米平板 2，小米平板 3 在硬件上的变化主要有四点：

*   SoC 从英特尔凌动 X5-Z8500 换成了联发科 MT8176
    
*   运行内存从 2GB LPDDR3 升级到 4GB LPDDR3
    
*   内置存储从 16 / 64GB eMMC 4.5 升级到 64GB eMMC 5.0
    
*   电池容量从 6190 毫安时升级到 6600 毫安时
    

这里我们重点说一下联发科 MT8176。

![](../Images/d8b40d1b50738d846dd803709f5ee20d.png)来自联发科官网

MT8176 是联发科在 2016 年 10 月推出的一款主要为 Android 平板设计的 SoC，也是目前联发科平板 SoC 中定位最高的一款。

CPU 方面，MT8176 拥有 2 个 Cortex A72 核心（最高主频 2.1 GHz）以及 4 个 Cortex A53 核心，GPU 为 ImaginationTechnologies 的 PowerVR GX6250（主频 600 MHz），支持 4K H.265 视频的解码，台积电 28nm HPM 制程。

从规格上看，MT8176 应该比较接近高通的骁龙 650（CPU 略强，GPU 略弱），理论表现应该要优于小米平板 2 上那颗性能本身比较一般且兼容性糟糕的英特尔凌动 X5-Z8500。

![](../Images/1757ad234400577bdae1bedd4779e8f8.png)

在跑分测试中，小米平板 3 在安兔兔中可以跑出 8 万分左右，和骁龙 650 基本相同，略低于骁龙 653。

![](../Images/222b2669d64c58856ed041cf70dc4556.png)

在 Geekbench 4 的 CPU 测试中，Cortex A72 大核让它跑出了超过 1600 分的单核分数，这个数据已经基本和骁龙 820 / 821 处于同一水准了。GPU 跑分（上图三）在 2100 出头，这个数据略低于骁龙 650，和麒麟 950 差不多。

在实际体验中，小米平板 3 可以流畅运行微博、微信等日常 app，王者荣耀这样对性能要求不算高的网游也没啥问题，而 4GB 的运存意味着使用中不需要像小米平板 2 那样时不时地去清理后台了。

更重要的是，由于采用了 ARM 架构的 SoC，使用小米平板 3 时不会出现小米平板 2 上由于使用 Intel 架构 SoC 带来的兼容性问题，不过改用 MTK SoC 也意味着小米平板 3 不能像小米平板 2 那样支持 Windows 系统。

但话说回来，在 7.9 英寸的屏幕上运行 Windows 系统本来就是一件「找虐」的事，再加上缺乏 USB-A 母口、HDMI 等必要的 I/O 接口，对大多数用户来说，Windows 版小米平板 2 的意义并不大，因此这次没了 Windows 版也不算什么多大的遗憾。

## 体验：MIUI + 手机 app

关于小米平板 3 的使用体验，可以基本用一句话来概括「几个好用的 MIUI 自带 app + 无数个手机 app」。

![](../Images/a31cd5fc8ab5b01b92bc9c2f2361e8f7.png)

小米平板 3 预装了基于 Android 7.0 的 MIUI 8.2 操作系统，系统的每一个内置 app 都对平板做了比较周全的优化，包括日历、备忘录、邮件、便签、多看阅读、新闻、视频、音乐、浏览器等等，基本可以涵盖除微信、微博等 app 之外的大多数日常使用场景了。

如果你是一个 MIUI 的粉丝并且习惯使用自带 app，相信小米平板 3 会让你感觉用起来很舒心，如果你不习惯用自带 app，在买来小米平板 3 之后最好也尝试着习惯，因为 Android 平台着实没几个正了八经地为平板电脑优化的 app。

不过好在在换掉了「水土不服」的 Intel 芯片后，小米平板 3 在日常使用中基本不会出现兼容性问题，想运行的 app 都能正常运行，就是用起来可能没那么舒心。  

## 外观不变，内在大不同  

小米平板 3 在延续了小米平板 2 的外观、屏幕的基础上，把 SoC 从「偏门」的 Intel 换成了主流的 ARM，app 兼容性上好了不少，存储规格也干净利落地定在了主流的「4GB + 64GB」。从使用体验这个角度上看，小米平板 3 相比小米平板 2 的提升还是很明显的。

售价上，小米平板 3 比 64GB 版的小米平板 2 贵了 200 快，考虑到前者的内存更大以及上游原材料价格整体上涨的大背景，这个价格还是算得上「厚道」的。另外，由于 iPad mini 2 的停产以及 16GB、64GB 版 iPad mini 4 的停售，目前苹果官方渠道在售的最便宜的「mini」128GB Wi-Fi 版 iPad mini 4 也要 3688 元（电商成交价在 3000 元出头），小米平板 3 和 iPad mini 之间已经拉开了足够的差价。

![](../Images/dd26058cc897d3a2b672620dfb4f7ab3.png)

关于小米平板 3 是否值得买，取决于你是否需要一部 Android 平板。

随着大屏智能手机的普及，包括 iPad 和 Android 平板在内的非 Windows 平板的市场空间越来越少，如果一部智能手机已经足够满足你所有的需求，额外购买一部 Android 平板很可能只会「画蛇添足」，但如果你对智能手机的屏幕尺寸依然不满足，希望有一块更大但又可以拿在手里的屏幕用来阅读或者看视频，或者你打算给父母买一台平板但他们又搞不明白怎么用 App Store，那么小米平板 3 是 2000 元以内最值得你考虑的产品之一。
