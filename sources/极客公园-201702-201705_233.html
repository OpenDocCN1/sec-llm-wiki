同样是想要改变交互习惯，这一次有人思考的方向是声呐。

之前我们曾经介绍过 Sony 的黑科技投影仪——Xperia Touch，它能将任何桌面或者墙面变成可多点触控的安卓操作系统界面，不但看起来酷炫，实际操作时也非常具有未来感。

虽然这台神奇的投影仪准备开售了，但 1799 欧元的售价还是让很多人有心无力，毕竟不是谁都能这样充值信仰的。不过最近，我在 Kickstarter 上发现了一款名叫 Welle 的小东西，有了它，也能把任何物体表面变成智能触控板，究竟怎么做到的呢？先来看看这段介绍：

解放空间，让操控更随心所欲

我们每天都会用到不同的电子设备，大到平板电脑、手机，小到智能手表和音乐播放器，在方寸大小的屏幕上进行操控，不论是增减音量，还是切换歌曲，屏幕既是可触摸的实体，又成了小小的「围城」，有时候限制了我们的动作。

而 Welle 想做的事情，就是突破这一层限制，让你随时都能进行操作而不必拘泥于屏幕，所以你看，通过蓝牙简单连接并设置后，使用起来非常方便，手指在桌上一划，就能控制音量。

看电视灯光太亮，在桌子上划拉一下👇

动一动手指，控制阳台的窗帘👇

要出门了，关掉电视机👇

为什么会这么神奇呢？其实，Welle 利用的是大家熟知的声呐原理。就像潜水艇在深海中航行，通过发射声音和捕捉回声来判断周围的情况一样。Welle 就是一个「声呐发射器」，通过探测到你手的位置变化来做出反馈，当你的手在空间位置上产生变化时，它就能按照预先设定好的程序来调整音量、切幻灯片甚至是做出音乐打碟的效果。

不过，既然 Welle 身材如此小巧（75.4×16.2×35mm），其声呐探测范围必然也不会如同潜水艇那样很大，目前能侦测到的就是在其前方十厘米距离内，A4 纸大小的面积上的手势操作。

除了在桌面或者墙面来操作，通过声呐系统的原理，其实也可以通过这种「隔空手势」来进行操作。

是不是看到这，你会不由自主想到另一款类似的隔空操作设备——Leap Motion？这两者究竟有什么不同呢？

相比于 Leap Motion 这样的基于视觉识别运行的硬件，其高功耗+易受到光线影响的问题始终需要解决，而且成本也比较高，尽管它能够做出许多酷炫的动作，但是毕竟一般人不会买上好几个放在家里。而 Welle 利用声呐原理来制造的产品就避免了这些问题，一方面，造价低廉，而且还能够适用于复杂的场景，便宜的价格也能让玩家进一步开发，所以具有独特的优势。

另外，相比于 Sony Xperia 利用红外感光元件以及电子陀螺仪等元器件来实现动作捕捉，Welle 利用声呐来完成这一目标显得更加方便、小巧。元器件成本也不会那么高，所以你可以看到相比于 Xperia Touch 那样的「大块头」，Welle 显得格外小巧。而且，由于更加简单的结构，实际上 Welle 的续航能达到 30 天之久，因此还是很让人省心的。

不过，利用声呐技术当然暂时只能实现简单的动作捕捉，而不能像 Sony 那样还支持多点触摸，算是它的小小不足吧。

自定义手势，未来变得更加方便

除了最简单的左划右划，你还可以自己对动作进行设置，开放的 API 接口给了这个小东西无限的可能，比如画个圈儿，或者画个问号，都可以对应出不同的操作。

当然，你还可以把 Welle 玩的更花样百出，官方甚至给出了一套有趣的「Welle 字体」，你可以尝试设置用手画出字母「O」来打开台灯，字母「C」变成切换电视频道等等，这时候的 Welle 就是一个只能听懂你的「暗号」的小帮手。

在你习惯了这样的操作之后，你一定会觉得，拿出手机或者用遥控器来操作显得是那样笨拙。

在厨房做饭的时候划拉一下就能免提操作👇

对于已经习惯了在手机、电脑上的各种操作的我们来说，Welle 的学习成本可以说是忽略不计的，而经过简单的联动，你会发现，几个简单的手势居然能给生活带来很多方便，这也正是团队制作它的初衷，一种更加方便的控制方式，一种具有创造力的交互形式，而这种愿望，本质上也类似于亚马逊的语音助手 Alexa 所要完成的事情。

开放的 API 带来的另一个好处是可以用它来与其它物品进行更深一层的联动，不论是利用 IFTTT 来进行不同设备之间的操控响应，还是通过与开源机械臂这样的装置进行二次开发，都能带给人更多的想象空间。

也许有人会问，我家里都是一些老旧家具，不能支持 IOT 怎么办？，Welle 表示，他们正在和 SwitchBot 合作，后者是一个远程机器人，能够控制所有的「老」设备，另外，其实 Welle 支持很多蓝牙设备，所以你不用多么智能的家电也能使用。

在我看来，Welle 带给我们的另一种可能是，从光线传感器、电子陀螺仪到现在的虹膜识别、生物指纹传感器，通过将越来越多的元器件集成在手机或者平板这样的设备上，我们发现它们的功能正变得越来越强大，而假如在未来某一天，能将简单的超声波功能放入手机当中，也许手机会进一步产生变化，我非常期待看到这样的情况发生。

虽然没有 Sony 的 Xperia Touch 那样「全能」，完全变成可触控的安卓系统投影仪。但 Welle 胜在小巧和开放性，我们有机会利用它做出自己想要设定的任务手势，因为有时候你可能并不需要那么多功能，只是想要简单控制音乐音量，或者摸一下桌子就关掉早上的闹钟，那么 Welle 就显得非常好用了，不是吗？
