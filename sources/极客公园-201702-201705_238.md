# 万维网之父获图灵奖，期望互联网重返「去中心化」

作为互联网的构想者，他觉得现在的互联网世界有问题，该治治了。

  

**作者 |  龟途慢慢**

蒂姆·伯纳斯-李（Tim Berners-Lee）——这位在计算机界留名青史的大人物在今天又获得了一项顶级荣誉，他在今天拿下了 2016 年的图灵奖（Turing Award）。

如同很多专项领域的最高奖项一样，图灵奖也被誉为计算机领域的「诺贝尔奖」，这个奖项每年由计算机协会（Association for Computing Machinery (ACM)）颁出，旨在奖励那些「为计算机的发展做出重要贡献」的个人。目前，图灵奖的奖金为 100 万美元，由 Google 提供。

在颁奖词中，图灵奖官方写道：「蒂姆·伯纳斯-李爵士于 1989 年发明了万维网，设想了一个全球信息空间，其中可以用统一的名称区分不同的文件和其他网络资源，可以以标准方式检索文档和资源，并且可以通过超文本链接连接到不同文档的位置。」

> 为此，蒂姆爵士推出了基于 URI 和 URL 的通用资源命名方案；以及用于以可扩展和分散的方式在互联网上发送和接收信息的 HTTP 协议；以及 HTML 标记语言，它提供了以独立于设备的方式创建和显示并链接到其他文档的标准方式。

简而言之，正如图灵奖委员会所说的，「万维网（World Wide Web）的发明者、第一个 Web 浏览器的发明者、以及允许 Web 扩展的基本协议和算法。」这些足以说明伯纳斯-李的重要地位。

![](../Images/0d39182cdba77796c26ea37343fcebf2.png)

事实上，在此之前，他在 2004 年就已经获得了英国王室颁发的大英帝国爵级司令勋章（Knight Commander of the Order of the British Empire），成为了「Sir Tim Berners-Lee」。

不过，随着时代的发展，互联网也早已和当初伯纳斯-李发明它时有了天壤之别。二十多年前，互联网还是一个分散的平台，任何人都可以发布网站并链接到任何其他网站。但今天，当互联网从科学界的研究与共享工具发展成为商业、通信、新闻和娱乐的全球性媒介时，权力已经发生了转移，像 Google 和 Facebook 这样的巨头已经开始掌控互联网。这种情况让伯纳斯-李自己非常忧虑，作为麻省理工学院计算机科学与人工智能实验室（CSAIL）信息分散化小组（Decentralized Information Group）的共同领导者，他正在试图改变这个状况。

下面是他在获奖后接受英国《卫报》的简单采访（略有删改）：

* * *

**Tim，恭喜你**

这确实是一个重要的荣誉，尤其是在计算机科学的领域。能和这个领域内过去的巨人们忝为同列，这真的是巨大的荣誉。

**你的家人们也是计算机科学家吗？**

我父母参与开发了英国第一台计算机，我母亲也被称为全英国第一个商业计算程序员。

**关于信息技术如何彻底改变世界这个问题，你有什么想法吗？我不知道是否有人会想要改变从财务到传媒这所有的东西。**

我的看法是，这场改变是全方位的、没有边界的。我有一种感觉就是，你可以把所有东西和它联系起来。你应该可以和任何东西连接起来，你也可以把任何东西放到互联网上。这就是设计背后的驱动力，也是让人们使用这项工具的动力所在。

你也许记得在 web 之前有电子公告栏（bulletin board），电子公告栏是一种系统，你只需将家中的电脑连接到电话线上，人们就可以通过电脑拨号来交换信息。这些电脑允许人们通过电子邮件交流，并在没有任何中央权力机构或中央系统的情况下进行讨论。所以即使在有网络之前，人们也有这样一个乌托邦的梦想——通过技术连接起来去追求更美好的事物，而且我们可以做到这一点，因为电子通信没有边界。

**这种乌托邦的思想似乎在开源社区仍然存在？**

那些网络团体中的核心人群肯定还在从这个角度来推动发展。不过现在，有些人有些绝望，因为我们每个人都处在同一个社交网络中。这就是他们生活中的一个游戏，它有趣、有用，但并不去中心化。我把这个过程称之为重新分散网络（re-decentralizing the web）。一开始，互联网是分散的、去中心化的；但现在又再次有了中心。我们能做什么去让它重新分散化呢？

**互联网的中心化问题已经到了一个突破点了吗？**

广告和点击诱饵（clickbait）已经到了让人们不能忍的地步了。现在的点击诱饵做得越来越逼真，让用户很难不去点击它。再加上那些弹出式广告，用户很多时候不得不接受它，并且为了不看到广告而付费。

我们或许该有些回应了。人们可以很快地在互联网上获取东西，但他们也可以很快地放下。如果你最喜欢的社交网络突然变得不酷了——你已经看到人们是如何从 Instagram 转移到 Snapchat 上的————我想我们可能会得到一个这样一个世界，那些有钱人家的孩子可以花钱屏蔽掉广告这类东西，获得一个良好的在线学习空间，因此得到更好的教育。

有钱人家的孩子会比那些没钱的获得一个更好的在线学习体验，这会有一点让人感到担心。前者能获得真实的信息，而后者则不得不忍受那些广告的侵袭，他们的生活质量也就不同了。
