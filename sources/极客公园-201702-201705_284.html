如果用一个词形容 IBM 的云计算和 AI 战略那最贴切的也许应该是：实用为王。


作者 |  早优夫斯基


终于，在一年一度的 InterConnect 大会上，IBM CEO Ginni Rometty 亮相会场，一如既往的强大气场，一如既往的自信演讲。作为 IBM 云计算的年度盛会，云计算毫无疑问成了不言自明的主角。

和大部分发力云和人工智能的公司从科研学术角度秀肌肉，或通过 C 端大用户量玩概念的方式不同，Ginni 的整个演讲都围绕着两个字——客户。

万达、AT&T、Salesforce、H&R Block、加拿大皇家银行……通过不同的客户、不同的解决方案，IBM 用各种姿态，一遍遍验证着 IBM Cloud 对于企业未来的价值，以及愿和企业携手并肩、共赢明天的态度。

是的，IBM 在云和人工智能这条路上要走的是纯纯的 toB 流派。

实用派，IBM 的云战略

如果用一个词形容 IBM 的云计算和 AI 战略那最贴切的也许可能是：实用为王。

一切以企业需求为导向，围绕客户打造专有产品，所有的服务和解决方案都不为显示技术实力或炫耀资本，而是踏实解决公司面临的实际问题。

 IBM 公司从 2016 开始正式转型成为一家认知解决方案和云平台公司，也是这样的转变让 IBM 变得更加务实，更懂得如何把前沿科技落地成为能赚钱的产品，这一点从 IBM 一年多来的股价就能看个大概：

自从2016年宣布转型后，IBM股价开始重新攀升

作为一家已经 106 岁的「老牌」科技公司，IBM 给人的印象向来是：稳重、克制、老练，IBM 的云计算业务或许是最好的体现。在同行对手都在忙着抢首席科学家、秀肌肉的时候，IBM 却悄悄在 B 端埋头耕耘，用「与众不同」的思维尝试去把云计算和 AI 这条路跑通。

因为 IBM 在云服务方面最大的特色就是定制化，通过 Watson、Bluemix 为主的产品和服务，根据客户特征来定制云服务。按照 Ginni 的话说「客户不仅是在使用 IBM 的技术，而是 IBM 和客户一起开发了这些专用技术」，这些云服务看起来可能没那么酷，甚至难以被感知道，但却能切实帮助客户优化决策，解决实质问题。

这让 IBM 在众多云服务商和人工智能公司中显得那么独树一帜，显得那么「接地气」。

例如：

与 AT&T 合作，通过 Watson IoT Platform、IBM Watson Data Platform、IBM Machine Learning Service 等技术，支持企业实现有数据洞察的 IOT。

与 Salesforce 合作，将 WatSon 的数据洞察与 salesforce Einstern 的客户深度洞察结合，通过对数据的采集、推理及推荐来加速决策，提升客户满意度。

与 H&R Block 合作，利用 H&R Block 税法文件和 60 年的案例经验，培训 IBM Watson 成为税务专家，询问客户有关生活、收支等它认为需要了解的信息，并给出抵免税、退休金等方面的专用建议……

这几家都是在 InterConnect 大会上被 Ginni 请上台的客户代表，都是典型的通过让 IBM 的产品针对客户需求进行优化，而后根据客户需求开发出相应的定制解决方案。

Ginni 和 AT&T CEO Randall Stephenson

对于客户需求，相比于同时给出三个解决方案来秀肌肉，IBM 的做法更倾向于把技术隐藏在方案背后，然后给出一个最优解。诚然，这才是一个成熟的方案解决商该做的事。

对于现在的 IBM Cloud 来说，客户用起来顺手是第一位的考虑。

区块链、混合云、Watson、Bluemix……

区块链、混合云、Watson、Bluemix，这是这次 InterConnect 大会上 IBM 的所有大招，无一例外，这些都是非常典型的商业化云服务方案，也是把前沿技术落地成为变现产品的好例子。

其中像是首次推向商用的区块链，是典型的交易机构专用方案。IBM 基于 Linux 基金会的 Hyperledger Fabric 1.0 打造了第一个面向企业的区块链服务 IBM Blockchain。这项技术可以允许任何私人公司或政府机构建立一个安全可信的网络，且在这个网络中的内部成员能够高度自由的共享信息。更重要的是，信息只能被内部用户所查看且信息一旦录入就无法再次更改。

还有这次大会上 IBM Cloud 的核心产品混合云，作为公有云和私有云的结合体，混合云既有私有云的安全性，又有公有云的性价比和云体系。它可以让客户把核心应用放在私有云，安全级别较低的放在公有云，协调了使用云服务的顾虑和便捷性。

IBM 和 Redhat 共同打造混合云

而 Watson 作为 IBM 认知计算领域最核心的技术，早已成为 IBM Cloud 众多服务的基石，也是 IBM 多年来憋的大招，通过从金融、医疗、建筑、教育等等市场中的专家培训，Watson 能更好地理解大量的私有的数据，而这些数据通常是公共的搜索引擎无法访问的。

这次 Watson 更是将自己对「非结构化数据」挖掘整合并分析的能力，由此带来的新时代数据的商业价值正式 IBM 务实的最好体现。

最后，值得一提的是，Bluemix 作为 IBM 重要的云服务平台，这次大会上更是因为压轴位置被 Ginni 请上台的 Reshma (CEO of Girls Who Code) 而强势露出。

因为 IT 行业就业性别比例差异，主修 IT 的女生仅占 18%。为帮助更多女性提升经济实力和自立能力，IBM 资助了暑期培训，课程中指导学生学习使用 Waston API 和 Bluemix，在 Bluemix 上中学生可以利用语调分析、对话等服务。一个女生甚至编写出帮助自闭症儿童与人交流的应用。

IBM 成功的商业化转型无疑是成功的，在这样商业化的大规模建设中，IBM 在医疗、教育、建筑等领域做出了不容易被感知但实打实的贡献，像是肿瘤诊断。

大数据、云计算、人工智能，作为三位一体的未来科技核心，有人仰望星空就需要有人脚踏实地。
