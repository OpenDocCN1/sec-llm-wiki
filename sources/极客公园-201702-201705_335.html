有的时候体验和听说还是区别很大。


作者 |  无脑


埃隆·马斯克在去年曾向投资者和超过 37 万订车客户表示，他有意从 2017 年 7 月开始启动 Model 3 的量产计划，而现在距离这个时间就只有 4 个月了。

前一段时间 Tesla 也是首次宣布计划在 Model 3 量产之前从出售普通股，募集 2.5 亿美元加上 7.5 亿美元的可转换票据，但最后募集了约 12 亿美元。这些钱也是为了保证 Model 3 的顺利量产，降低一些风险以避免跳票。

「单次充电能够行驶 345 公里以上，0-100 km/h 加速时间将在 6 秒以内。」这款 Tesla 即将量产的新一代产品 Model 3 的数据在现在看起来并不亮眼，但它除了延续实用的电池续航、动力性能，它还将拥有 Tesla 成熟的安全配置和自动驾驶功能。

而最重要的是 Model 3 作为即将成为特斯拉家族中价格最亲民的车型，起售价仅为 35,000 美元（美国地区），虽然还没公布但据推测在中国应该会在 30 万上下。

在去年 3 月发布的时候，我还并没有觉得这台车极具竞争力，因为那时正是「新造车运动」刚刚初显成效的时候，大家都在「画饼」谈论着未来的量产车，而除了新兴的电动汽车，30 万左右的燃油车更是选择多多。

但直到最近我试驾了一台 Tesla Model S 90D 一周左右之后，我才变得突然开始期待 Tesla Model 3 量产，而这不仅仅是因为这辆车的驾驶感受。

不断「升级」的期待

先拿之前的例子来说，电池容量为 60kWh 入门版车型 Model S，它内部的电池包其实是 75kWh 版本的，也就是其实你买到的是更好的「硬件」，只是需要花钱来软件解锁，就能升级自己的汽车性能，就像突然告诉你花钱软件升级，你的 iPhone 就能增加一天的续航了一样。

特斯拉其实有大约 20000 美元的「软件升级」供用户选择，除了电池包的升级之外，另一个颇具代表性的选项就是著名的 Autopilot，2016 年 10 月特斯拉推出了完全自动驾驶硬件（Full Self-Driving Hardware），之后这也成为了标配搭载在之后生产的每一款汽车上，而是否要体验自动驾驶这项功能就需要你自己来权衡了，当然这需要支付 8 万元左右来选配「增强版自动辅助驾驶」和「全自动驾驶能力」。

但不定期的小更新也是不断，汽车通过 OTA 空中升级逐步推送各种小功能的更新，包括碰撞预警和自动紧急制动等功能，还有自动泊车、泊车召唤等功能，我试驾这辆车的时候还更新了一个关于优化空调系统的更新，所以只能说这台车的体验只会越来越好，而且这会体现在各个细节方面。

而且目前特斯拉的「增强自动驾驶」只使用了新硬件套件的 8 个摄像头中的一个，所以当特斯拉开始使用更多的摄像机时，他们还会有更多的新功能开发出来，同样能为你带来这种「未知的期待」。

不过最让人期待的还是最终的「全自动驾驶能力」。

找到「自动辅助驾驶」的边界

而说到自动驾驶，我们一直再期待，但 Tesla 称之为「自动辅助驾驶」的这个功能早已经被玩坏了，各路大神已经开始拿它当自动驾驶测评了，但我使用了几天之后不得不说它确实不足以强大到完全掌控，但却已经是辅助驾驶中最聪明的了。

给我感悟最深的就是「找到它的边界」，只有正真使用辅助驾驶一段时间之后，你才知道它在什么时间可以足够信任，但在什么时间你需要去「关心」它，关于这个要保持手握方向盘这个要求，我体会到了另一处不同，方向盘的轻微转动能够给你一个反馈，让你去注意可能发生的变化，这样种种之后，你才能体会开这辆车会有多省心，即使还没实现自动驾驶。

哪怕是堵车，这个辅助驾驶相信已经能够超越很多还在研发的「低速自动驾驶」了，而且它既有高性能跑车的驾驶体验，又不至于在堵车时摧毁你对于高性能跑车灵敏操控的喜爱。

所以这些软件上的变化无疑让我对于这台可能买得起的 Tesla Model 3 拥有了更多想象。

虽然为了节约成本 Model 3 使用了传统的钢结构车体，同时为了抵消重量加大带来的能耗增加，Model 3 的尺寸比 Model S 也缩减了很多，但这依旧不影响我对于这台车软件层面的期待。

外媒猜测没有仪表盘的 Model 3 可能会用 HUD 显示

而到今年年底，已经有超过 40 万个预订的人和我一样在期待了，（题外话：预订可以全额退款）所以 Tesla 也制定了未来每周 5000 辆汽车的生产计划。而上周五，有一台 Model 3 的原型在 SpaceX 的测试轨道附近的道路上进行测试，而且作为 Tesla 这样已经相对成熟的产品，对比初创公司的第一代产品相信也会更具竞争力 ，再不行预约一个试驾，让车来说服你。
