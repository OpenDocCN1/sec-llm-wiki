# 重新打造无人机入门之选？大疆突然发布 Phantom 3 SE

**作者 | 无脑**

大疆，除了在高端无人机市场极具竞争力，它的经典「精灵系列」也一直在售卖，精灵 3 Standard 版本在现在也被不少人称之为「入门之选」，最低版本降价到 2999 元的价格对于想要去了解无人机的初学者来说是再适合不过了，2.7K 视频、1KM WiFi 图传、25 分钟续航也已经满足了人们基本的航拍入门需求。  

但今天下午大疆悄无声息的在官网发布了一款「新品」Phantom 3 SE，同样售价 2999 元（预售价），但已经支持 4k 视频录制，图像传输和控制距离远达 4 公里，而且配备视觉定位系统，让它能在无 GPS 信号的环境下也能精准悬停。

![](../Images/67b51e473ebeecbf93cacf83584accd0.png)

但这款「重新」打造的 Phantom 3 SE 配置和配色和之前的 Phantom 3 Professional 几乎一样，但 Professional 版本现在已经下架了，官网现在也只能买到两款精灵系列了，同样是 2999 选那个就毋庸置疑了。

![](../Images/63667b7f991667b16a7abe10f91771f0.png)Phantom 3 Professional

不能不说这可能是大疆的又一次完美的降价营销。同时，对于大疆的同行来说，每次降价都是一次打击。比如同样作为「性价比」的入门之选小米无人机的 4K 版本，也售价 2999 元，而且于 3 月 3 号 0 点开始首次售卖，配置同样是 4K 视频拍摄，4km 远程传输距离，26 分钟续航，光流定位辅助，大体看配置是几乎一样了，所以大疆这次的「降价」动作也就不用多说了。

![](../Images/27ff8adcd718194b51c77e04e6b3fc7c.png)

之前可能不太推荐再花 3000 元钱买精灵的 Standard 版本了，因为配置是略低于其他无人机了，但现在对于各位喜欢无人机又迟迟没有下手的时候这个入门之选可能又要加入你的购物车对比了，而要下手快了，预计开始发货时间是 3 月 31 日，而正式售卖的时候也会贵上 500 元。

需要注意的是 Phantom 3 SE 目前还不会在大疆旗舰店或中国大陆以及其他地区的授权店销售，Phantom 3 SE 现在只在 DJI 线上商城以及天猫、京东上针对中国大陆地区的客户销售。

看来对于入门级别无人机来说，大疆依旧不想放弃，而且关于 Phantom 3 SE 这个名字和动作，不得不让我们联想到同样的「重生经典」的 iPhone SE，只能说大疆你会玩。
