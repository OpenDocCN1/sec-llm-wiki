Firefox 开发商 Mozilla 完成了成立以来的第一笔收购，买下著名的稍后阅读应用 Pocket。收购后，Pocket 将作为独立的子公司继续运营。

一家浏览器开发商买一个稍后阅读应用做什么？虽说 Firefox 已经在右上角默认嵌入 Pocket 部件，但仅仅「稍后阅读」一个功能值得专门收购吗？Mozilla 想通过 Pocket 实现的，或许不止「稍后阅读」。

## Mozilla 的移动之殇

Mozilla 旗下的 Firefox 以「开放」、「开源」著称，并吸引了不少用户。2011 年时，它是世界最流行的桌面浏览器之一，拥有 4.5 亿装机量，是微软 IE 最有力的挑战者。

来到 Android 和 iOS 割据的移动时代，Firefox 出现了水土不服的状况。

Google 和苹果通过原生应用、封闭平台、私有的软件商店和开发者规则，将用户和开发者圈在了自己的系统上。比如，非 WebKit 内核的浏览器不让进苹果的 App Store。Mozilla 的 Firefox 就不是 WebKit 内核，因此它无法将自己复杂的渲染、javascript 引擎移植到 iOS 平台。Mozilla 曾在 2013 年明确表示不会开发 iOS 版 Firefox。

最终，「开放」的 Mozilla 忍受不了当时移动 OS 的封闭性，在 2013 年 1 月推出了基于 Firefox OS 的入门级 Firefox Phone，主打发展中市场。Firefox OS 是一个基于 web 的手机操作系统，希望利用网页无所不在的特点提供一个不受厂商设备限制的开放平台。

![](../Images/d257b96069a19d771618dffea2357ccc.png)

非常不巧的是，Google 在 2014 年正式开卖 Android One 智能手机。低价、入门级，同样主打发展中市场。web OS 阵营的 Firefox Phone 与 native OS 阵营的 Android 正面碰撞，前者不幸落败。Firefox Phone 最终只活了不到 3 年，Mozilla 于 2015 年 12 月终止了这一项目。

究其原因，还是 web OS 当时所能提供的体验不及 Android。并且，Mozilla 最终也向苹果低了头，于 2015 年 11 月推出了基于 WebKit 的 Firefox iOS 版本。

可以说，「开放」的 Mozilla 在「封闭」的移动时代基本毫无建树。

## Pocket 仅仅是稍后阅读应用吗？

Pocket 与「开放」却没有多大关系。

这个诞生于 2007 年的稍后阅读软件最早只是 Firefox 上的一个插件，名叫 Read It Later。2012 年改名为 Pocket，发展至今已有 1000 万月活跃用户。

Pocket 能让用户把互联网上的内容（文字、图片、视频）统统保存在一个应用里，待有空时再翻出来阅读。将内容「封闭」在自己 应用里面的做法，与 Mozilla 所倡导的「开放」背道而驰。

Mozilla 收购 Pocket 的答案可能并不在「开放」，而在于前者的新项目「Context Graph」（情景图谱）。这是一个基于互联网内容的推荐系统，能够根据用户当前的上下文情境发现新的东西。

![](../Images/d5571d0bc2ec94aeb7820b1ee5d8641f.png)

体现在移动端，可以根据用户当时的地理位置推送附近旅游景点的信息，而不需要主动搜索。Mozilla 的团队已经把这个主意做成了一个 iOS app，名为 Project Prox。

![](../Images/2524bc3bcf30fd5870494e99fe8e0a8d.png)

Pocket 也在做类似的事情。2015 年起，Pocket 就尝试基于用户保存的内容、辅以机器算法技术推荐相关的文章。2016 年底，Pocket 正式在应用里新增「推荐」一栏。

![](../Images/fa5cbf529e9133809d21e9b6fe1c5f02.png)

听起来是不是很熟悉？正是今日头条们正在做的事。相较而言，Pocket 的优势是用户已经在 app 里保存了自己想读的内容，不像今日头条们需要烦恼用户第一次使用应该推荐什么内容。

Mozilla 在宣布收购消息的 Blog 里说：「Pocket 将会和 Firefox 一起专注促进互联网高质量内容的发现和获得。」言下之意，「Context Graph」项目必定会与 Pocket 的内容推荐机制相互融合。

推荐阅读说不定会变成 Pocket 又一个主要功能，这个产品也有可能在移动资讯分发格局中突围。不那么纠结开放与否的 Mozilla，这次或许找对了路子。
