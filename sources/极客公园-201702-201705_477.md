# 手机恐怕要做今年 315 晚会的主角了，品质是否已经成了伪命题？

手机厂商们在逃离同质化的道路上拼命狂奔，但却又永远摆脱不了套在头顶越勒越紧的品质紧箍。

  

**作者 | 小猴子sunny**

  

很多人觉得越是成熟的产业越是无聊，其实呢，反而劲爆精彩。  

掐指一算，距离 315 晚会又很近了。三年前，成熟的汽车行业里大众被爆出变速箱质量问题，一下子全国的大众车友群情激愤，大众最终损失不小。而今年，成熟的手机产业里三星恐怕很难在那一天全身而退，「爆炸」的惊悚程度显然更高一些。

于是我们听到了来自业内大佬这样的感慨：「现在比的不是谁更领先，而是谁不犯错。」独自莫凭栏，高处不胜寒，手机产业发展至此，技术突破的尖锐和消费电子需要的稳定体验之间终要平衡，品质可靠性重回用户视野，厂商只会更加如履薄冰。

 手机厂商们在逃离同质化的道路上拼命狂奔，但却又永远摆脱不了套在头顶越勒越紧的品质紧箍。

## 品质「要命」

硬件本身越来越复杂，这种因为精尖而造成的「失控」其实已经一定程度上超过了行业整体的成熟度，这并非完全是激进与保守的区别，还要看投入的诚意和耐心。

三星 Note7 事件是这种不稳态的一个里程碑式释放，Note7 是我们很多人心中 2016 年最好的手机，却因为可靠性的意外使得自己无法被任何一个消费者使用。三星离战胜苹果可能就差不到一毫米的距离，但电池安全差之毫厘的失控最终让三星召回了 250 万台手机，也丢掉了自己最好的机会。

销毁零售版手机这事其实是不常发生的，上一次应该要追溯到 2015 年荣耀将 17000 多台总价值超过 2000 万的手机当众销毁了。不过和三星不同的是，荣耀是在「天灾」之后主动销毁的，运输手机的货车中途遭遇了火灾，荣耀认为这给手机可靠性造成了无法预估的不确定因素，于是忍痛把原本要被卖出的手机付之一炬了。

「和平年代」尚有余地，在这国产厂商和国际厂商背水一战的年代里，大家都要榨干自己的研发能力和产业链最前沿的成果，这件事在如今的智能机上就太过复杂了。加之行业进入集中分布的阶段，核心玩家肩上的担子越来越重，客观的稍不留神和主观的倦怠也就越来越频繁了。

任何一个资深果粉都会觉得苹果的「品质控制」远不及当年了，iPhone 越来越守旧却依然越来越不稳定，6s 的电池问题里一大半是吹毛求疵，一小半是真实的糟糕体验，终于「三防」的 iPhone 7 果不其然在初版的固件里发热严重，一天要按压上百次的 Home 键也经常出现 Bug 而无法唤醒。

都这个年月了怎么还会出这样的问题呢？很多人因此感慨现在的苹果远不及当年的诺基亚。

最终传递给消费者的直观体验确实如此，但实际情况并不能那样总结。各家的品质部门依然在，QA（Quality Assurance）品质保证和 QC（Quality Control）品质控制本身是没有谁敢偷懒的，每一家也都比五年、十年前升级迭代了很多次了，只是如今拧上的发条大家各有松紧。

三星在 Note7 事件之后临时组建的大型调查实验室和公布爆炸原因时宣布的「8 重电池安全检查措施」如果出现在 Note7 上市之前，三星至少可以少损失一百亿美金。

品质控制的一边对应着真金白银，而为了保障动辄几千万甚至上亿的出货，这部分基础投入和能力也面临着巨大的挑战，苹果、三星如是，华为、荣耀、OPPO、vivo、金立们亦如是。

品质控制的另一边对应着行业地位，比如华为和荣耀在过去一年里快速增长成为国产厂商的第一，「变态级」品控功不可没。各家的品控标准不尽相同，而荣耀是国产厂商里最经常公开讨论的那个，他们甚至把自己的品控过程在中央电视台彻底揭秘了一番。去年央视 2 套《寻找顶级制造》栏目里真实记录了荣耀 7 品质检测的各种「变态」环节和指标要求，而从去年到即将发布的荣耀 V9，这个变态指标在荣耀总裁赵明的公开宣布里又升级了两次。

距离智能手机行业混沌初开已经有十年了，存量市场里的一切会更透明，是好是坏都彻底没有秘密了。

## 用什么挑战苹果？

如果苹果并非不可战胜的，那 2017 年它的挑战者们就一定要做出比硬件、软件和服务更高维度的一致体验。这件事，很难。

硬件负利在手机行业喧闹了不到两年，终于被公开证伪了。其实这件事在运营商时代早就发生过，当时的场面就不是很好看了。虽然有可观的补贴，即便以一个夸张的招投标报价出货也能赚到钱，但「负利」还是体现在了品质和用户体验上。

一位深圳某小厂商的采购人员告诉我们，运营商补贴的年代低于 Bom 成本出货也很常见，但小厂商一般会在后期偷换劣质元器件，在品控的环节放松标准，「实际上」亏本出货的很少很少。他们甚至在一些产品上用过「高仿 IC」，那是品质完全没有保障的东西。

可就是这个简单的道理在 2011-2016 的智能手机时代却是很难让人接受的，「性价比」在不少人心里留下了太深的印记，如今他们已经几乎买不到手机了。

外观工艺上的突破让人激动，但它们实在很难在高品控要求下被驾驭好。盲目的山寨式复刻和概念包装让人忍俊不禁，也会给实际体验造成很大的破坏，比如，悬浮式无边框 ID 超出常规的碎屏率。

从 ID 设计到结构堆叠，从元器件的选择到来料品质控制，从组装到品质检测，每一个环节都在高度成熟的现状下失去了投机取巧的可能，或者说，一次次被证明投机取巧也没用。

我们每年都能看到中国手机的质量报告，有趣的是，返修率最低的三个品牌就是现如今中国手机市场的三巨头。

ODM 供应商闻泰分享过这样一段往事：某互联网手机厂商 A 和荣耀同时找到他们做代工，他们的工程师看了两份图纸后给出了一些优化建议。但 A 厂商得知后非常不满，要求维持原本的图纸，按照制造成本出货就行。而荣耀的工程师则要求闻泰提供完整的理由和评估报告，结果闻泰反馈了厚厚一本报告后，那个细小的修改得以通过。

不论是硬件配置参数、软件优化、本地化服务，还是最新的场景化人工智能服务，这一切都有意义，但又只有在一个「最高品质」的牵引下才能成为可持续感知的好体验。这虽称不上是智能手机的最终形态，但也是十年来全球几十亿用户真实行为所得的深厚积淀。

所以，对产业成熟更好的诠释其实是有了足够的耐心和投入就可以在现在和曾经神一般的苹果站在一个高度了。从全面追赶到局部超越再到全方面的决战，硬件、软件和服务都达到了相当的高度之后，今年国产厂商终于要挑战 iPhone 那般高品质的一致体验了。

用户离不开它，所以国产厂商必须挑战它。赵明在 V9 发布前给出的答案是「最高品质」和「不卡顿」，其实也就是 2017 年大家对「软硬结合」和「用户体验」的一种更加高阶的思考和结论。

2017 年将是国产三巨头和苹果三星决战的一年，此时的苹果在准备十周年的献礼绝招，三星痛定思痛后成了全行业最懂电池的厂商，输赢一半在创新突破，另一半就是赵明口中的「最高品质」。
