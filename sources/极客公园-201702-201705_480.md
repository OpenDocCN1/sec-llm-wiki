VR 一体机嘛，得轻，得不晕，效果得好，还得便宜——暴风魔镜 Matrix 大概就是来满足这种「无理要求」的。

近日，暴风魔镜 Matrix 进行了一次了街头采访，在随机地点、随机人群的随机采访后，参与体验的吃瓜群众们总结除了 Matrix 的三大特点：效果特别有感觉，又轻又不晕，根本不像是暴风做出来的。

那么暴风魔镜 Matrix 到底是什么呢？

它是暴风魔镜在去年 12 月发布的一款拥有「3K 概念屏」的最新 VR 一体机，有超轻、超清、不晕等特点，其野心也很大，对标的正是世界级的 Oculus Rift，HTC Vive，PS VR 三大头显。

前不久，《连线（Wired）》杂志创始主编凯文·凯利成为暴风魔镜 Matrix 的全球第一名用户。而在之前的极客公园创新大会上，来自世界各地数千名的资深极客，暴风展台上抢先体验到了暴风魔镜 Matrix。对于这款有实力超越 Oculus Rift，HTC Vive，PS VR 这「三大头显」的国产 VR 一体机，他们表现出了极大的热情和关注。在一轮体验之后，认为 Matrix 更轻的占 92%，认为 Matrix 更加舒适的占 85%，而当场表示愿意购买的则高达 62%，这对于一款尚在测试期的国产 VR 一体机来说，已经是不小的褒扬。《黑客帝国》视觉创意总监 John Gaeta

在现场体验完暴风魔镜 Matrix 之后评价：「从未体验过这么轻的 VR 设备。

 据悉，Matrix 将在不久后正式发售，而暴风魔镜也希望通过跟更多样化的用户群进行提前沟通，而在这次街头采访之后，相信无论是暴风魔镜还是资深 VR 用户，都将对 Matrix 形成一个初步判断。
