如果你讨厌 AirPods 的话，可以看看这款 Beats X。

  

**作者 | 极客之选的小伙伴们**

  

Beats X 可以说是最近关注度最高的耳机之一，因为采用了和 AirPods 相同的 W1 芯片，让它非常适合搭配 iPhone 使用。如果你不喜欢 AirPods 那种被「截掉一截」的外观，或许 Beats X 可以吸引到你的注意。

![](../Images/69f51a4c69800b7299ae30858c70df83.png)

Beats X 的包装采用了透明的设计，可以一窥耳机的整体外观。包装左上角可以看到「8 HR」，代表这款耳机的续航时间为 8 小时。

![](../Images/00c289c9776f63400b8d4882cdb1a718.png)

Beats X 的所有配件，包括不同尺寸的耳塞、贴合翼尖（鲨鱼鳍）、Lightning 充电线和保护壳。没错，它的充电接口是 Lightning 接口，毕竟现在 Beats 是苹果公司的一份子。

![](../Images/b26a2797d8ef088cc57fa73eb9eb80ba.png)

Beats X 支持快充，在电量不足时，充电 5 分钟即可持续播放 2 小时。如果运动前才想起来耳机忘了充电，这个功能还是能够派上用场的。

![](../Images/153fb13f7874e6d797f7458544429a99.png)

和 AirPods 一样，Beats X 也采用苹果最新的 W1 芯片，除了能够提供更加长时间的续航，和苹果设备连接时也会更加方便。当手机打开蓝牙时，在控制中心能够看到图形化的连接界面。

![](../Images/652a4a389451e713063fe2ad33c24336.png)

Beats X 的耳塞部分采用了磁性设计，在不使用时可以吸附在一起防止脱落。现在很多便携无线耳机都采用了类似的设计。

![](../Images/6d4cb1a8d6f5900ed750b028ad75ece0.png)

Beats X 的线控采用了传统的按键布局，按键的反馈非常清脆。线控中包含麦克风，可以用于接打电话和操控 Siri。

![](../Images/0dec962189ffaaad0ab0a37810b51e5e.png)

Beats X 使用了 Beats 招牌的「面条线」，收纳时不易缠绕在一起。需要注意的是，Beats X 的线材上有两个突出来的「电源盒」，应该是为了绕在脖子上时保持平衡。

Beats X 的国行售价为 1188 元，比 AirPods 便宜 100 块钱。我们在 Beats X 的包装中还发现了一张兑换卡，可以通过注册产品获得3 个月的 Apple Music 会员。关于 Beats X 的详细使用体验，我们会在之后的评测中与大家分享。
