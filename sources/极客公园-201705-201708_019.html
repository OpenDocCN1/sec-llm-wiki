摘要：遗憾的是这 30 位拿到车的都是内部员工。


等了这么久，看过这么多谍照，从去年 4 月等到现在，终于有 30 人真正拿到了首批量产的 Tesla Model 3，而且是在超过 50 万的预订者之前。

今天，Tesla 在弗里蒙特工厂举办了首批交付活动，活动的发布只有短短半个小时左右的时间，但却公布了一些关键性的信息：

  • Model 3 目前有两个版本：

3.5 万美元的标配版本：续航 220 英里（354 公里），百公里加速 5.8 秒，130 英里/小时的最高速度

4.4万美元的升级版本：续航 310 英里（498公里），百公里加速 5.1 秒，140 英里/小时的最高速度

  • 选配 Autopilot（自动驾驶软件）要多花 5000 美元。

  • 今年要达到每周 5000 辆车的量产速度，明年要达到每周 1 万辆。

  • 这 30 位早期的拿到车的都是内部员工，原因是他们更能容忍早期量产出现的错误，以便及时修复。

  • 现在全球有 6000 + 个超级充电桩，两年之后翻 3 倍，到达 18000+ 个，Musk 说这样基本你就可以开着 Model 3 任意的远途旅行了。

看完这些信息不知道你的感受如何，当然大部分人以为会标配的 Autopilot 需要多加 5000 美元，这让很多媒体都惊呼失望。但毕竟像 iPhone 一样，「软件」也许才是这辆车真正赚钱的地方。

和往常的发布会一样，Elon Musk 还是再次介绍了 Model 3 的一些亮点，而 Musk 第一个亮出的牌就是安全，他们对 Model 3 也做了很多安全方面的升级，依旧是超五星的安全标准，对比测试的时候，也不忘拿出以安全著称的沃尔沃做对比，还黑了一下他们所谓的「五星」安全。

除此之外，还强调了虽然车长比 Model S 短，但 Model 3 的车内空间却不输 Model S，Model 3 的前风挡玻璃和车顶变成了一整块玻璃，拥有和 Model X 一样的「直升机视角」，最后就是车内的交互了，真的就是只有这样一个非常简洁的大屏幕。而关于更详细的交互却没有做过多的介绍，我们就期待这 30 位车主真正开回家做「深度测评」了。

简洁的内饰很好理解，就是为了能够实现快速生产，Elon Musk 也解释说，在 Model 3 中只有 10,000 个左右的零件。这相比现在的汽车动辄 3-4 万的零件，已经是跨越了非常大的一步。

Musk 还说喜欢特斯拉的可以现在买 Model S 一两个月内就可以提车，而现在预订 Model 3 要等到 2018 年中之后，甚至更晚。

最后 Musk 说我们把在 Model S 和 X 上赚到的钱全部投入到了 Model 3 的生产之中。不禁让我想到在 10 年前的一篇博文中，马斯克在结尾处这样写道：「简而言之，我们的总体规划是：先打造跑车，然后用赚到的钱去生产大众消费级汽车，然后再用赚到的钱去生产更多的大众消费级汽车... 别把这个想法告诉任何人。」
