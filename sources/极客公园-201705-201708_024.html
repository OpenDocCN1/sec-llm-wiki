无风扇 + 超窄边框，你是否会考虑这样的华为 MateBook X？

摘要：华为 MateBook X 是否值得入手？我们为你做了详细的评测。


华为 MateBook X 发布已经有段时间了（6 月 7 日正式进入中国市场），不过有关它的一些讨论依旧在进行中。

身边不少想要入手新本的朋友经常会问：华为 MateBook X 好不好？和戴尔 XPS 13 或者苹果 12 英寸 MacBook 相比，是否值得入手?

前不久我们也拿到了这款关注度颇高的新品，经过半个月的试用体验，这里来和大家分享一些我的看法，希望能够对正在犹豫是否应该入手华为 MateBook X 的朋友有所帮助。


方方正正的外观初印象

由于目前大多数笔记本产品在沿用 16:9 的屏幕比例，这也使得当你看到拥有 3:2 屏幕比例的华为 MateBook X 时，会感觉它看起来要显得「方方正正」一些。

整体风格上，MateBook X 并没有做太多个性化的设计（比如华硕钟爱的「同心圆」以及戴尔 XPS 系列的暗纹），整体来看还是走了类似于 MacBook 的简约路线。

至于哪样的方案更好，只能说从品牌打造的角度来讲，前两者更具辨识度，可能不需要看到 logo，就知道是谁家的产品。不过这样做的风险在于，可能有相当一部分用户并不买账。相对而言，MateBook X 们所选择的简约设计，要更容易被大众所接受一些。

手感方面，MateBook X 要比 MacBook 来的细腻一些（后者会有轻微的颗粒感）。但在清洁问题上，相对而言它的表面更容易留下指纹，不过好在由于采用了全金属机身，擦拭起来很方便。

相比一眼能够看到的外观，细节部分的把控或许才更能体现出一款产品是否足够优秀。MateBook 侧边曲线收弧同时采用了 CNC 钻石切切割工艺处理，尤其在光线照射的条件下，会显得很精致。

不过 B 面与 C 面的贴合度这一点上，它做的相比 MacBook 还是要略微差一些。从整体观感上，这部分实际上并不会带来太多影响，或者说没有影响。但就使用角度来讲，可能你清洁 C 面的频率要相对更高一些。

来说下外接扩展能力。不出意外地，为了更好的控制机身厚度，MateBook X 同样砍掉了传统 USB 接口，机身左右两侧均设置有一个 Type-C 接口。就现阶段而言，在使用过程中，可能你还是需要外接扩展坞。

由于 MateBook X 并没有做散热风扇，所以它的机身底部并没有像传统笔记本一样设置很多开孔。另外有关四个垫脚，上方两个要比下方的两个做的高一些，来尽可能提升使用键盘操作时候的舒适度。


除了 88% 的超高屏占比，在操控方面也下了功夫

在戴尔 XPS 系列大获成功之后，各家 PC 厂商也迅速进行跟进，越来越多以窄边框作为卖点的笔记本产品开始陆续出现。

回顾过去一年上市的诸多号称拥有「窄边框」的笔记本新品，实际上相比 XPS 系列还是有很大的差距，大多数属于「伪窄边框」。这次 MateBook 的到来，确实给 XPS 系列带来了很大的压力。

官方宣称，拥有 13.3 英寸屏幕的 MateBook，边框宽度仅为 4.4mm（最窄处），可以达到 88% 的超高屏占比。从数据对比来看，MateBook X 的边框宽度要比戴尔 XPS13（最窄 5.2mm）更激进一些，从而实现了将「13 寸屏幕装进 11 寸机身」。

另外，MateBook X 显示屏的分辨率为 2K 级别的 2160×1440，sRGB 色域可达 100%，对比度为 1000:1。从实际显示效果来看，确实很棒。另外值得一提的是，虽然配备了镜面屏，但在反光的控制上，做的非常出色。

屏幕底部中央位置显眼的亮面 HUAWEI 标志，也是除了 A 面之外，为数不多的品牌露出。

C 面布局同样极尽简约，键盘+触控板依旧占据了大部分区域，一排与转轴等长的扬声器开孔位于位于键盘区上方中央位置。这部分重点关注的是操控以及集成了指纹识别器的电源按键。

简单来讲下音效，MateBook X 搭载了 Dolby Atmos（杜比全景声），官方宣称能够提供流动音效。不过由于机身厚度所限，就实际展现出的音效来看，只能说还可以，但不要对它抱有太高的期望。

电源键是这次 MateBook X 很有特色的一点。它采用了和 2016 款 MacBook Pro 一样的做法，将指纹识别器与电源键合二为一。好处在于开机的时候，只需要一步操作就能进入到桌面。

就这段时间我的使用体验来看，它的指纹识别成功率非常高，并未出现无法解锁或者二次解锁的情况。另外，我也在手指潮湿情况下进行了解锁测试，结果同样令人满意。

实际上，虽然第一代 MateBook 是一款二合一设备，但就键盘部分的操控性而言，华为确实做得非常棒，此次的 MateBook X 同样如此。其采用了全尺寸巧克力键盘，同样延续了之前的防泼溅设计，这一点是很多同类产品所不具备的。

但轻薄本一贯为人所诟病的键程问题，MateBook X 依旧并没有给予很好的解决。不过它的键程表现要比大多数同类产品来的出色，即便是采用了第二代蝶式键盘的全新 MacBook Pro，在键盘的调校上，也并没有比 MateBook X 做的更好。

这次 MateBook 选择了目前轻薄本产品常见的二级背光设置。实际使用过程中，你可以根据自己的需要，来选择合适的背光亮度。

可能理念不同，Mac 一贯推崇的触控操作，Windows 向来并不重视。由于键盘占据了大部分区域，MateBook 的触控板面积并不算大。另外就实际使用体验而言，它所配备的这块触控板略硬。

作为轻薄本，便携性是不得不提的一项重要指标。即使采用全金属机身，MateBook X 重量也刚 1.05kg，三围为 286 x 211 x 125mm（最厚处）。也就是说，它要比 A4 纸（297mm × 210mm）的面积还小一些。

从数据对比来看，MateBook X 1.05kg 的重量要比 2016 款 13.3 英寸全新 MacBook 的 1.37kg 轻 0.35kg。放在包里可能感觉不到二者在重量方面的差距，不过要是同时将二者拿在手里，还是能够感觉到前者要更轻一些。


除了办公，我们还测试了它的游戏性能

谈性能之前，先来说下 MateBook X 的硬件配置参数。处理器提供第七代酷睿 i5 和 i7 两个可选项，而发热量更低的酷睿 M 并没有出现。其它方面，内存容量最高为 8GB，硬盘部分酷睿 i5 版本提供 256GB PCIe SSD 以及 512GB PCIe SSD 两种规格，i7 版本则为 512GB SSD。

具体到我手里这台机器，硬件配置为 Intel Core i5-7200U 处理器、8GB 内存、256GB SSD 固态硬盘，其中显卡为英特尔 HD Graphics 620。性能测试部分，这次我们选择通过跑分软件结合实际使用体验的方式来进行。跑分软件选择了 CINBENCH R15 以及 3DMark。

CINEBENCH 测试项分别针对处理器以及显卡的性能。处理器部分的测试纯粹使用 CPU 渲染一张高精度的 3D 场景画面，第一次只使用一个线程，第二次运行使用全部处理器核心和线程。

从最后的测试结果来看，MateBook 搭载的第七代酷睿 i5-7200U 处理器，单核得分为 121 cb，多核为 312 cb。对比上代 i5-6200U 处理器，其在性能方面要略强一些，不过二者之间的差距并不大。

3DMark 部分，我们分别在 Fire Strike 以及 Cloud Gate 两档下进行了测试。两项的测试成绩分别为 546 和 3853 分，属于正常测试水平。

这里多提一句，即使对比前段时间，受到很多轻薄本产品推崇的那块性能并不算出色的 NVIDIA 940MX 独显，它依旧有着不小的差距。

通常来讲，这样一款定位于轻薄便携的笔记本产品，它设计的初衷以及预期，更多的倾向于娱乐办公人群。但在 MateBook X 的潜在购买用户中，并不排除对游戏性能有一定要求的朋友。本着全面性的原则，我们也对它的实际游戏表现进行了测试，测试游戏为《英雄联盟》。

办公部分的测试，我们直接忽略诸如文字编辑之类对性能要求并不高的任务，选择了常用的图片处理软件 Adobe Photoshop，用其同时打开 10 张大小均为 9M 的图片，来看 MateBook X 的表现。

和预期的结果一样，在整个图片打开过程中并没有出现读取进度条，10 张图片打开速度很快。也就是说，MateBook X 这套 i5 处理器 + 8GB 内存 + 256GB SSD 的硬件组合，在面对大多数办公任务的时候，都能轻松应付。

游戏测试部分之所以选择《英雄联盟》，首先一点是考虑到其庞大的玩家基数，另外一点也和大家常说的一样，它对于硬件配置方面的要求并不算太过严苛。

画质方面，首先设置为高画质。可以看到，Fraps 测试软件给出的实时帧数为 53 帧。在整个过程中，MateBook X 的帧数基本保持在 40 帧 到 60 帧区间内。随后我们尝试将画质调节到最高画质，这时候会发现它的帧数下降幅度很明显，基本在 30 帧左右。

如果你是一名游戏玩家，那么对于这样的帧数表现应该有一个大致的了解。简单来讲，高画质下，利用 MateBook X 来玩《英雄联盟》这款游戏可以获得还不错的游戏体验，但如果切换到最高画质下，那么你只能看「动画片」了。

就游戏体验这部分可以得出的结论是，MateBook X 基本可以应付一些对硬件配置要求不算太高的游戏。但如果你对于游戏体验有较高的要求，或者平时玩一些大型单机游戏（比如 GTA5），那么它显然无法胜任。

需要说明的是，由于接口部分 MateBook X 只提供 Type-C 接口，目前大部分有线或者带连接器的无线鼠标是无法直接使用的。所以，你只能使用蓝牙无线鼠标或者通过外接扩展坞来连接以上提到的两种类型鼠标设备。


续航还不错，散热表现意料之中

对于笔记本产品而言，续航表现如何是评价其是否足够优秀的重要标准之一。尤其是轻薄本往往需要适用于移动办公场景，这也意味着，它在续航方面需要给予更好的支持。华为 MateBook X 的电池容量为 40Wh，在同类产品中处于中等水平。

实话来讲，其实笔记本续航能力的强弱，除了取决于其内置电池容量大小，很多时候用户使用习惯的不同，续航表现也有着较大差异。

续航这部分的测试，我选择以观看一集完整《我的前半生》电视剧的方式来进行。在此之前，关闭键盘背光，同时屏幕亮度调节至 100%，电池状态为满电。

《我的前半生》一集时长按照进度条显示为 48 分钟，加之片头以及剧中广告大概 2 分钟，也就是说，整个连续播放时长为 50 分钟。而播放完成之后，华为 MateBook X 的电池容量显示剩余 84%。

也就是说，从满电状态开始看一部大概 50 分钟的视频，它消耗了 16% 的电量。这样的成绩在和以上我们说到的其 40Wh 电池容量应该有的表现基本吻合。总结来看，作为一款轻薄本，MateBook X 在续航方面的表现还算不错。

接下来说下 MateBook X 的散热表现。通常来讲，处理器部分一旦上了酷睿 i，为了压制其带来的发热量，厂商会在机身内部做散热风扇。但 MateBook X 并没有采用这样的设计方案。

官方说法：此次其使用了空间智冷技术，首次将航天领域广泛应用的 PCM 相变温控胶囊材质应用到 PC 领域，从而带来了无风扇的 13 英寸笔记本电脑。整机无散热开孔，可以有效避免积尘带来的使用故障以及风扇高速运转时产生的噪声等问题。

需要承认的是，华为所说的可以避免积尘带来的使用故障以及风扇高速运转时产生的噪声，这两项是没有问题的。但在实际使用过程中，我们发现，它的散热表现只能说应付轻应用散热还不错，但在稍高负载时，并不尽如人意。


总结

到这里文章也基本接近尾声了，回过头来看 MateBook X。综合而言，作为一款定位于高端的轻薄本产品，从外观到性能，它都表现出了不错的竞争力。但在测试过程中我们也发现了其所存在的一些不足之处。为了能够让大家更好了解 MateBook X 的优缺点，我们做了如下汇总。

售价方面，按照硬件配置不同，MateBook X 提供了四种可选项：i5 + 4GB 内存 + 256GB SSD 售价 6988 元，i5 + 8GB 内存 + 256GB SSD 售价 7988 元，i5 + 8GB + 512GB SSD 售价为 8988 元，i7 + 8GB 内存 + 512GB SSD 售价 9988 元。 ■
