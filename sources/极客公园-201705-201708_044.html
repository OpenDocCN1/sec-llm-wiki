一切为了变现？乐视手机在美国降价 40% 甩卖

摘要：在美国亚马逊上，Le Pro 3 的售价已经降到了 238 美元，Le S3 为 139 美元，相比上市价分别跌掉了 39.8% 和 44.2%。


去年的 10 月 20 日，当时状况还不错的乐视在美国召开了一场颇为盛大的战略和新品发布会，在那场发布会上，乐视宣布 Le Pro 3 和 Le S3 两款智能手机进入美国市场。

其中 Le Pro 3 和国内销售的乐 Pro 3 保持一致，采用了 5.5 英寸 1080p 屏幕、全金属机身、高通骁龙 821、4070 毫安时电池、QC3.0 快充（最高 24W），配置在当时算得上旗舰，售价为 399 美元。至于 Le S3，它更像是国内销售的骁龙版乐 2，骁龙 652、5.5 英寸 1080p 屏幕、全金属机身在中端机中也堪称主流，售价为 249 美元。


「然并卵」的高性价比

相比起国内，Le Pro 3 和 Le S3 在美国的售价基本保持一致。放在 iPhone、Galaxy 占主导地位、但相对缺乏优秀高性价比手机的美国智能手机市场，Le Pro 3 的 Le S3 本应是性价比实足的「大杀器」。

在乐视之前，一加甚至中兴（主要是天机 7 这部产品）就通过「将旗舰配置卖到中端价位」的方式，取得了不错的销量和用户口碑。不过相比起一加和中兴，无论在产品、营销还是渠道上，在美国初来乍到的乐视都有不少问题。

从产品上看，Le Pro 3 和 Le S3 虽然硬件规格很高，但其搭载的系统和国内的 EUI 基本没什么区别，除了预装几个美国流行的视频 app，基本没有任何针对性的本土化可言。

对于更加崇尚原生 Android、更加依赖 Google 全家桶的美国用户来说，乐视手机上预装的这套 EUI 不可避免地会出现水土不服。在美国众多科技媒体的报道中，EUI 也不出意外的获得了众多「差评」。

系统上的硬伤，加上营销和渠道的匮乏，让 Le Pro 3 和 Le S3 没有像一加那样在美国「火」起来。


降价找出路

虽然在乐视的美国官网上，Le Pro 3 和 Le S3 的售价还分别为 349 美元和 199 美元。不过在美国亚马逊上，Le Pro 3 的售价已经降到了 238 美元，Le S3 为 139 美元，相比 399 美元和 249 美元的上市价，分别跌掉了 39.8% 和 44.2%。

这还不算完，在前几天美亚的促销中，Le Pro 3 的售价一度降到了 214 美元，折合人民币 1444 元，这基本已经是「卖一台赔一台」的清仓价了。

在国内，乐视手机的日子也不太好过。

除了在 4 月发布了一款基本找不到什么亮点的乐 Pro 3 双摄 AI 版，乐视手机在过去半年多的时间里没有任何新品推出。更夸张的是，受困于供应链，近期乐视手机的售后部门居然没有备用零件来维修手机。

对于现在的乐视手机来说，或许唯一能做的就是把现有的产品「清仓大甩卖」了。 ■
