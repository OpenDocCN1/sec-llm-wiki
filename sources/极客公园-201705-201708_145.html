软件电脑搁一边，微软重组销售团队专注推广云服务

摘要：微软接下来很长一段时间的工作原则：移动为先、云为先。


本周一，微软重组了全球销售团队，并将市场部门的工作重心转移到了云服务上，从外媒《华尔街日报》获得的消息来看，微软可能会因此裁掉数千名员工。

从微软执行副总裁 Judson Althoff 发给员工的内部邮件来看，微软将会将大部分的销售力量转移到两个重点用户群体上：大型企业用户和中小型企业。在此之前，微软主要针对的是商业部门，比如公共部门，创业公司以及某些具体行业。

据《华尔街日报》得到的消息，这封邮件并没有提到裁员的事，员工们也没有收到任何形式的通知，并且，具体的裁员人数还不清楚，但根据《华尔街日报》的报道，即将被裁的员工覆盖了微软在全球各地的员工团队，据微软最新披露的数据，到今年 3 月底，微软员工总数为 121000 人。

上月末，有几家外媒就报道了微软加大云服务方面人力资源投入的计划，彭博社指出微软这次裁员的对象将包括一些非常重要的销售员工。

但也有些外媒持有不一样的看法，ZDNet 就认为这次的裁员并没有其他人说得那么严重，微软可能只会将一些受到重组调整影响的员工分配到其他的业务部门。对此，微软还没有给出官方的说法。

微软现任 CEO 纳德拉和诺基亚 CEO Stephen Elop，图源：TechCrunch


业务重心不停换，裁员不能断

这已经不是微软第一次进行大规模的人员清理了，去年 5 月，在一个礼拜内进行了两次大规模的人员变动，起初它将之前收购的诺基亚手机业务以 3.5 亿美元的价格卖给了富士康集团，这其中就包含 4500 名手机业务的员工，随后它又裁掉了智能手机业务相关的 1850 名员工。两个月后，微软又宣布裁掉 2850 名员工，其中 900 多人来自销售团队。更早一些，2015 年 7 月的时候，微软宣布裁掉 7800 名员工，其中大多数人来自诺基亚的手机业务。

Kevin Turner，图源：TechCrunch

这次的人员重组应该是过去一年里领导层的变化导致的，在上任首席运营官，服务微软 11 年的老忠臣 Kevin Turner 离开微软之后，Judson Althoff 和 Jean-Philippe Courtois 接管了公司的销售和市场部门，其中，Althoff 曾经公开批评了微软之前的销售手段，并表示将把 Azure 作为销售部门的核心业务产品。

在一份声明邮件中，微软的发言人表示，「微软将坚持变革，以便更好地服务于我们的客户及合作伙伴。」


收购云监控软件，加注云服务

另一方面，上周微软刚刚证实了他们收购以色列的云监控软件即服务（SaaS）供应商 Cloudyn 的消息，虽然他们没有披露具体的收购条款，但据外媒 TechCrunch 报道，收购价格大概在 5000 万到 7000 万美元之间。

Cloudyn，图源：Enimbos.com

Cloudyn 是一家针对多平台云服务产品的成本及服务表现进行监控和分析的公司，该公司的服务可以帮助像微软的 Azure、亚马逊的 AWS 及 Google Cloud 等云服务商改善自家的云服务，管理用户、分析成本并监控资源部署情况。

从这个角度来看，微软现在对云平台领域的业务可以说是非常重视了，普通消费者可能并没有太多的感知。实际上，自从微软现任 CEO 纳德拉接替史蒂芬·鲍尔默上任以来，微软就一直在主张「移动为先、云为先」的战略，在公司内部进行了大刀阔斧的改革，业绩和股价也相应地有了明显的提高。


Azure vs AWS

对标目前云计算市场最具竞争力的玩家，亚马逊推出的 AWS 云服务，后起之秀 Microsoft Azure 已经逐渐拥有了与 AWS 分庭抗礼的实力，甚至此前有美国的分析公司预测，2017 年下半年，微软将在云服务的收入上超越亚马逊，成为新的市场领导者。

Microsoft Azure vs AWS

根据分析公司 Pacific Crest 的说法，云计算市场将在 5 年之内达到 2300 亿美元，是目前市场的 3 倍，从亚马逊 4 月发布的财报来看，AWS 最近一年财务成绩同比增长 43%，涨幅首次低于 50%，这证明 AWS 的财务成绩确实出现了增速下降的情况，很大程度上这也是因为微软 Azure 对市场的蚕食。

放眼国内，阿里云一马当先，腾讯云后起猛追——根据国际著名调研机构 IDC 发布的调查研究报告，2016 年阿里云占据了约 41% 的市场份额，超过了第 2 到第 10 名的市场份额总和，这与国外前两年的情况多少有点类似，除了各种前沿科技领域的你争我夺，巨头公司们在基础服务领域的竞争也是未来市场的一大热点。
