摘要：超过 40 万的预订者看到了曙光。


特斯拉刚刚确认了 Model 3 车型生产的正式启动日期，这也许让很多 Model 3 预订者欣喜不已，而这些人可能超过 40 万人。

Tesla CEO Elon Musk 刚刚在 Twitter 表示，特斯拉 Model 3「已经通过了所有监管法规」，他们现在预计将在周五启动正式的生产。

这也意味着这辆高预期的车辆好像并没有跳票，一切还是都按照 Tesla 去年七月份所承诺的量产计划准时开始：「2017 年末开始在北美地区交付，随后是欧洲和亚太地区。」

 Elon Musk 的 Twitter 确认消息：

「SN1」可能是指「序列号 1」，这将是生产线上首批生产的车辆，将在 7 月 28 日举行交车仪式。

 Elon Musk 公布了 7 月 1 日的内部团队和外部供应商零件的最后期限，以开始 Model 3 生产。量产的产能也会逐渐增加， 8 月份交付 100 辆，9 月份交付 1500 辆车，产能提升之后预计计划订单量为每周 1000 台，到年底时每周可达 5000 台。

其实最近就已经有了即将 Model 3 车型即将开启生产的提示，Tesla CTO JB Straubel 上个月披露，特斯拉已经开始在美国内华达州的超级工厂 Gigafactory 为新款电动汽车 Model 3 生产电池，这意味着 Model 3 的投产日期也已经不远了。

和之前的报道一样，Tesla 预计会先向员工提供早期生产的 Model 3 车辆，然后交付给加利福尼亚州地区的特斯拉预订车主。而随着产能的提高，特斯拉将开始向东移动，并提供更多的车辆到早期预订者。

据 Musk 介绍，在 7 月 28 日举行的发布活动中更好地了解具体的计划。类似于过去的两款车型，Model S 和 Model X，特斯拉将在弗里蒙特工厂举办交货活动，以推出车辆的生产版本，并将其交付给最初几个客户，一般是 Tesla 的投资者或董事会成员。

但在之前 Elon Musk 曾证实，与 Model S 超过1500 种不同配置相比，他们计划将 Model 3 配置数量限制在 100 种以下。不过也许会有几个小惊喜在发布活动中， Elon Musk 应该会公布车辆的加速参数，「 6 秒以内」也许会有惊喜，因为最近Tesla 刚刚升级了已有车型的零至百公里加速时间的参数，让 Model S 75 从 5.5 秒下降到 4.3 秒，让 Model X 75D 从 6.0 秒下降 4.9 秒。会不会比原本公布的 5.6 秒更快一些？

除此之外颜色应该也许会有惊喜。

而关于中国区这些花了 8000 元预订的朋友们，照这个交付过程，可能你们还要再等等了，据 Tesla 内部员工表示，中国第一批预订车主预计在 2018 年第一季度收到自己的 Model 3 。而且最近关于 Tesla 在华建厂的新闻也是多次反转，贵点就贵点，先体验看看？还是会再等等，靠「时间」来换高额的进口关税？

最后我们只能期待 Musk 会在发布会上公布其他地区的实际售价了，你的一年前投资的 8000 元会不会升值就看它了。
