# 三星 Galaxy S8/S8+ 图赏：不只有让人「中毒」的「全视曲面屏」

![](../Images/c4a895eb0b603ee31e042cb33f7b997f.png)

除了惊艳的双曲面全面屏，还有出色的手感。

  

在手机硬件趋于同质化，外观「撞脸」越来越频繁的今天，三星 Galaxy S8/S8+ 的到来，让我们看到了一些不一样的东西。

它的这套设计语言是否能够博得所有人的喜欢，也许永远不会有一个确切的答案，但就目前而言，的确足够「惊艳」。

S8/S8+ 最大的两点莫过于其所配备的曲面「全面屏」，三星称之为「Infinite Display」（全视曲面屏）。相比上一代产品，手机上下「额头」的宽度大幅缩小，屏占比达到了 84%。

![](../Images/2d64b1fb1eba25df36b70946abe0af29.png)

具体来看，两款产品均采用了柔性 AMOLED 面板，其中S8 的屏幕尺寸为 5.8 英寸，分辨率为 2960 × 1440，ppi 为 570，长宽比为并 18.5：9，相比常见的 16：9 明显长了一截（纵向多出了 400 个像素点）；S8+ 的屏幕尺寸增加到了 6.2 英寸，分辨率同样为 2960 × 1440，ppi 降低到了 529。

![](../Images/2c7f257588f25c9eff1c69596c344e1e.png)

至于为什么此次三星将 S8 / S8+ 的屏幕做得这么长，其中一个原因是上下「额头」太窄，沿用 16：9 的话会让整机显得很「胖」，除了看起来不太「和谐」，也不利于实现单手操作。

![](../Images/1a7dac897ac2aebb397d00e973881ae6.png)

此外，屏幕拉长后，还可以有效避免屏幕内虚拟按键挤占显示区域的问题，在看 21：9 比例的电影、进行分屏多任务等操作时，长屏幕也可以获得更加优秀的使用体验。

值得一提的是，S8 / S8+ 前置相机的像素从 S7 edge 的 500 万升级到了 800 万，镜头光圈达到了 f/1.7，并且支持自动对焦。

![](../Images/4a9bbd64bbb6cf2d076edc0eb2b2a76d.png)

S8 / S8+ 延续了从 Galaxy S7 edge 的「金属中框 + 双面 3D 玻璃」的设计。机身左侧除了音量键，三星为 Bixby 人工智能语音专门做了实体唤醒按键，而电源键则单独放到了机身右侧。

![](../Images/06d0ce8c5452df42a3c7001d64629424.png)

值得一提的是，S8/S8+ 均支持 IP68 级别的防水防尘。

![](../Images/0b3f2c7434b6bfda57131b96ae959e49.png)

背面同样为曲面玻璃，加之机身略窄，即便你的手掌不大，依旧可以获得不错的握感。

![](../Images/cf61686775ebb1dc207c517fdaa9589c.png)

S8 / S8+ 的后置摄像头像素依旧为 1200 万，支持全像素对焦，光圈 f/1.7，支持 OIS（光学防抖）。

![](../Images/8f20e4a1d8170a8d2f5e1bd827db90bf.png)

另外有关指纹识别模块，由于为了实现高屏占比，它不得不作出妥协放到了机身后方。就实际体验而言，还是需要花一段时间去适应，刚上手很容易出现误触摄像头的情况。

![](../Images/295b70f014804633ea344a6a8f0a750a.png)

S8 后置摄像头拍照展示。

![](../Images/54dafe8d01e8b1cb2b226fac46dc611a.png)

硬件配置部分，国行 S8 采用骁龙 835 处理器、4GB 运行内存、64GB 机身存储，支持扩展卡存储；S8+ 同样为骁龙 835 处理器，运行内存为 4GB/6GB、机身存储为 64GB/128GB。

![](../Images/d3f43c16306b98ef84201cdee55d991a.png)

价格方面，三星 S8（4GB+64GB）售价 5688 元，S8+（4GB+64GB）售价 6188 元。而 6GB+128GB 皇帝版 S8 Plus 售价 6988 元。另外，三星和移动推出运营商定制版 S8 售价 5688 元。
