iOS 11 增加了 NFC 的「读卡功能」，可能会有哪些应用场景出现？


随着 Apple Pay、银联云闪付等支付服务的普及，以及越来越多的手机厂商把 NFC 公交卡作为产品的卖点，「NFC 技术」和「移动支付」两个概念牢牢地绑定在了一起。实际上，除了帮助我们更加方便地「刷手机购物」，一套完整的 NFC 方案应具备读卡、写卡、卡模拟和 P2P 传输等功能，而移动支付只是其中的应用之一。

想必 iPhone 的用户都清楚，虽然 Apple Pay 是基于 NFC 技术实现的，但是苹果在 NFC 上还是比较保守的，并没有开放其他的「触碰」功能。不过，在刚刚那过去的 WWDC 上，苹果宣布 iOS 11 将增加名为「Core NFC」 的框架，允许第三方 app 读取 NFC 标签的 NDEF 信息，这意味着 iPhone 未来将有可能实现 NFC 的读卡功能。

苹果的这项举措在 NFC 领域引起了不小的波澜，甚至连 NFC 论坛（全球 NFC 规范的制定者）都专门发文表示欢迎。因为像苹果这样的巨头能够用更加开放的心态对待 NFC 技术，对于它在各个领域的普及是有很大帮助的。

今天这篇文章就跟大家聊聊在移动支付之外，NFC 技术在「读卡」上还有哪些有趣的应用，以及未来哪些功能 iPhone 用户可能也会享受到。

NFC 标签：打开 IFTTT 大门的钥匙

NFC 标签可以说是 NFC 技术最为简易、普遍的一个应用了，但因为它并没有解决什么刚需，所以我相信很多人并不知道它的存在。早年一些手机厂商（例如小米、魅族）在推广 NFC 技术时，曾经推出过一些精致的 NFC 标签，但后来基本上都销声匿迹了。

NFC 标签就像是一把打开 IFTTT（if this then that）大门的钥匙，通过「触碰」这个动作可以实现各种各样的功能。例如触碰一下打开飞行模式（放在会议室），触碰一下打开勿扰模式（放在床头），触碰一下发送电子名片等（放在钱包里）。

没有写入信息的 NFC 标签被称为「白卡」，利用手机的 NFC 写卡功能（读写卡功能通常是成对存在的）可以将自己需要的功能写入其中，这就带来的无限的可能性。几个荷兰的大学生曾经用 NFC 标签制作了一个自行车的 GPS 定位系统 WheelReveal，停完车后可以碰一碰标签就能自动在手机里记录它的具体停放位置。

如果你的手机支持 NFC 功能，不妨购买一些 NFC 标签去试试看（注意留意不同的标签类型），说不定真的就能解决一些问题。至于 iPhone 用户，可以再耐心等待一下，iOS 11 正式版发布后我们便能更加清晰地了解到苹果在 NFC 上的进展。 

Amiibo：包含 NFC 芯片的可交互手办

仅从外观上来看，Amiibo 和其他的手办似乎没有什么区别，但其实它的秘密隐藏在圆形的底座之中。

Amiibo 的底座中内置有 NFC 芯片，可以和任天堂的 3DS、Wii U 和 Switch 游戏机进行联动，在对应的游戏内解锁特别的人物角色，提供一些特殊奖励等。

和其他 NFC 的应用一样，Amiibo 的使用方式也非常简单。在游戏内启用此功能后，将 Amiibo 放在游戏机的识别区域内即可自动连接（例如 Switch 在右手柄的摇杆上）。

值得一提的是，Amiibo 使用的是恩智浦的 NTAG215 标签，现在市面上已经出现了一些利用同款标签制作的仿制品。也有玩家专门购买标签版本 Amiibo 只是为了获得游戏中的道具。

在 2014 年 6 月的 E3 游戏展上，这种互动型的手办首次亮相，随后任天堂不断推陈出新，现在 Amiibo 几乎覆盖了任天堂所有的热门 IP。在本届 E3 游戏展上，任天堂还带来了多款全新的 Amiibo 形象。

根据报道，Amiibo 每年能够为任天堂带来上百亿日元的收益。Amiibo 吸引人的地方在于，它在收藏属性之外，又为手办赋予了一些实用的价值，而且这种物理世界和虚拟世界交互的感觉真得很棒。

目前 Amiibo 仅能在任天堂游戏机中实现，但是理论上只要配备 NFC 天线的手机都可以读取它的信息。按照去年任天堂对于移动平台的重视程度，以及最近和苹果的「眉来眼去」，未来开放移动平台版的 Amiibo 也不是完全没有可能的。

NFC 还能帮助打假？

酒类、油类一直都是假货的重灾区，各种防伪手段也在不断升级进化。现在已经有一些红酒酒庄（例如 Domaine Geantet-Pansiot、Remy Martin 等）已经开始利用 NFC 技术去解决防伪的问题——通过在产品包装内预置 NFC 标签，再结合配备 NFC 的手机就可以快速进行真伪验验证。

与传统的防伪手段相比，NFC 防伪标签有以下优势：可以提供更加丰富的产品信息，方便追根溯源；可以在不破坏产品包装的情况下用 NFC 技术「隔空读取」；可以对防伪信息进行加密。

当然，NFC 防伪标签也有一些弊端。首先验证需要下载特定的 app，而传统的标签并不需要。另外，NFC 防伪标签的成本会更高一些——根据报道，NFC 标签的成本在 15-30 美分左右，相比之下 RFID 标签成本只需 1 美分，差距还是比较明显的。

因此 NFC 防伪标签更适合应用在一些高价物品，甚至是奢侈品之上，这时候就不需要考虑它的成本问题了。

值得一提的是，现在一些 NFC 防伪标签还采用了「一芯双频」技术，一方面消费者可以用来查询产品的真伪，另外一方面仓储物流中也可以进行远距离读取，便于进行库存的管理。

NFC 论坛的安全技术小组主席 Tony Rosati 曾表示：「如果有更多的制造商愿意使用 NFC 防伪标签，假货可能就会彻底消失了。」目前 NFC 防伪标签还是相对小众的，它的普及不但依赖于成产商的重视，也需要手机厂商的跟进。

除了上面提到的这些，NFC 的读写卡功能还能实现蓝牙设备的快速配对，查询公交卡、银行卡的交易流水等功能，至于卡模拟和 P2P 传输功能更是可以单独写一篇文章了。

NFC 技术不是什么新鲜的产物，也不是为了支付而生，但是种种因素的促进下让它更多地成为了移动支付的手段。苹果对于 NFC 技术的开放显然释放了一个积极的信号，相信未来 NFC 会有更多的功能应用「重出江湖」。
