# 坚果 Pro 新配色图赏：这样的「浅金」和「巧克力」还挺招人喜欢

继碳黑色、酒红色以及细红线特别版之后，这次坚果 Pro 又带来了巧克力色以及浅金色两种新配色。

  

5 月 9 日晚上，在一场「超长」发布会之后，锤子终于带来了今年的第一款新机—坚果 Pro。极客公园也在[第一时间做了上手文章](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652846823&idx=1&sn=9b6ca05e347ea2f482293890a1755f8f&chksm=7e6a4751491dce4770386db75f6ee98b33f5288faf010ab28a301eda2f9f22b9796995c097a7&scene=21#wechat_redirect)和[产品评测](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652847002&idx=1&sn=440ae290281b9d3fe253fc829b9dc9f3&chksm=7e6a462c491dcf3aeba1d2704c1a44d7f6612790fd403c9f61d11bb56c4b4ca0855d1e81c4f4&scene=21#wechat_redirect)。

首批上市的坚果 Pro 有三种配色，分别是碳黑色、酒红色以及细红线特别版。时隔一个月之后，坚果 Pro 又迎来了两种全新的配色：巧克力色以及白色前面板的浅金色。

![](../Images/72d7ed8925fb0bf30b62c24e47f12731.png)

和很多手机厂商的做法不同，此次坚果 Pro 正面的玻璃并没有覆盖整个前面板，而是在下方做了一个金属贴片。另外，它前面的玻璃并没有经过 2.5D 打磨，所以给人的直观视觉感受是「方方正正」。

![](../Images/c148b81bf97a44ea4e7952c2e5bfbbb2.png)

前置摄像头部分，根据版本不同，其像素也有所差别，32GB 机身存储版本为 800 万像素，64GB 以及 128GB 机身存储版本为 1600 万像素。

![](../Images/fa84e68dd26a798f2c7170b9203ed36d.png)

位于机身下方居中的可按压实体圆形 Home 按键，集成了指纹识别模块，支持轻触返回，按下回主页，双击呼出多任务。

![](../Images/1e914ee7a49ce9066b3cbc312f6c0fe7.png)

在指纹识别的速度和准确率上，坚果 Pro 的表现值得肯定，系统设置中可以设置成轻触 Home 键（不用按下去）完成指纹解锁。

![](../Images/140f09fa0dba0cac262d91bd2a377776.png)

坚果 Pro 的金属中框并没有采用无断点设计，而是加入了注塑信号条。虽说少了一份「偏执」，不过坚果 Pro 这个小小的妥协换来的是明显更好的信号，并且可以更有效地控制成本。

![](../Images/e9bf4805b44b1050b7565b6e4bc7f6eb.png)

此次坚果 Pro 去掉了双音量键，只保留了右侧的音量键，音量键下方增加了一个 M1 / M1L 所没有的电源键。

为了获得更好的握持手感，大部分采用金属中框 + 双面玻璃方案的手机都会将中框部分「打磨」得尽可能圆润，坚果 Pro 则反其道而行之，它的中框部分几乎做没有任何圆润的处理，中框两圈各切了一圈亮面金属倒角，看上去非常「方正」。

![](../Images/4044541d94e313fc64a0987c317b9481.png)

坚果 Pro 去掉了 3.5 毫米耳机插孔，不过随机附送了一个 USB-C 转 3.5 毫米的转接头，当然，你也可以直接买一副 USB-C 接口的耳机（不附送）。

![](../Images/b3f84b0271764a28a4e4f12e7ba0657e.png)

和正面的做法一致，机身背后同样采用了一块未经 2.5D 打磨的平面玻璃，玻璃下方是一块塑料贴片，不过表面做了磨砂处理，无论是视觉还是触觉，都很接近正面的金属「下巴」。

![](../Images/2784dd34f9e2338ce8e598023b4ba909.png)

坚果 Pro 同样采用了目前流行的后置双摄设计，两颗 sensor 的像素都是 1300 万，一个是常规的 RGB 彩色 sensor，另外一个是去掉了拜耳滤镜的黑白 sensor（可以提高进光量），镜头光圈为 f/2.0，不支持光学防抖。

![](../Images/c6181a75c8fbf7e944b180d207774f46.png)

根据机身颜色和版本的不同，坚果 Pro 背面 logo 的处理方式是有所区别的。黑色（32GB 版除外）、细红线特别版的 logo 是通过雕刻的方式，镶嵌在玻璃背板上的（工艺和黑色 T1 相同），而黑色（32GB 版）、酒红色以及新增的巧克力色、淡金色的 logo 都是印在玻璃盖板下方的。

![](../Images/5cbc47acf505412838d7714d8e8808d3.png)

背部下方的塑料贴片上印有「smartisan」字样，不过由于字体颜色与机身颜色相近，浅金色版本看上去并不明显。

![](../Images/584a31e5a28bf19d979cb713797c08ae.png)

另外，这次锤子还推出了 Smartisan 笔记本，有黑色以及咖啡色两种配色可选。其中小尺寸（105×150 mm，192 页） 版本售价为 49 元，大尺寸（135×195 mm，240 页）版本为 69 元。

![](../Images/1b2fb81cd8f13073e62e8b3557cc69d0.png)

和酒红色一样，巧克力色和浅金色坚果 Pro 只有 64GB、128GB 两个版本可选，没有 32GB。

配置上，这两个新配色和其它版本保持一致，SoC 为骁龙 626，运行内存 4GB LPDDR3，双卡双待全网通，支持 Micro SD 卡，电池容量为 3500 毫安时，18W 快充（高通 QC3.0），128GB 版多了一个 NFC 模块。

![](../Images/deb1d27eb787ca7dc1b5376397d85e61.png)

售价方面，巧克力色和淡金色坚果 Pro 和其它颜色保持一致，64GB 版售价 1799 元，128GB 版售价 2299 元，目前已经在包括锤子官方商城、京东商城以及部分线下零售店开始销售。
