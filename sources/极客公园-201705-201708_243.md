# 碰撞测试满分，特斯拉 Model X 真的是最安全的 SUV？

安不安全，撞撞就知道了。

  

周末外科医生布拉曼开车与家人出去玩，被一辆闯红灯的大型 GMC 卡车从侧面撞上，这辆卡车时速超过 72 千米/小时，布拉曼甚至没有时间闪躲，幸运的是 5 名乘客和他的一条狗都逃过一劫甚至没有受伤。  

![](../Images/13f05019eedff2cb20910b7b7421b2c7.png)

再看下面这个在加利福尼亚的车祸现场，虽然几乎已经看不出来这是一辆车了，但还好驾驶员除了扭到了脖子之外并没有受伤。

![](../Images/9fa076725215b4fa85bdb637777b7250.png)

巧合的是他们都驾驶了一辆电动车——特斯拉 Model X，车祸之后他们都在社交媒体上晒出了车祸现场，同时对特斯拉的安全性表示了感谢。

也许你会说这些都只是偶然事件，**但最近，NHTSA 证实 Tesla Model X 在经过碰撞测试后，在每个安全类别中都获得了 5 星级的评级，成为最高安全级别的 SUV。**

![](../Images/a3d777b5b99ec3f26776631a547ae6e0.png)

同时它的总体碰撞伤害概率仅次于 Model S。如果再举个例子，你可能就你理解这台 SUV 的优势所在了：与所有类别也同样是五星级的沃尔沃 S60 相比，侧面碰撞测试 Model S 保留了 63.5％ 的驾驶员剩余空间，而沃尔沃只有 7.8％。所以作为一个 SUV 来说这个安全级别可以说是少有了。

## NHTSA 的「五星」碰撞测试

要想成为「最」，当然需要一个足够公正的裁判。这就不得不提这个 NHTSA，它的全称是美国国家公路交通安全管理局（National Highway Traffic Safety Administration），这是美国运输部下的一个执行机构，成立于美国华盛顿特区。

> NHTSA 的工作包括编写和执行机动车辆相关的安全性、防盗、燃油经济标准相关标准，关于燃油经济业务是依照统合平均燃料效能标准（Corporate Average Fuel Economy, CAFE）来制定。汽车制造商和进口商的授权也是由 NHTSA 发放，管理允许或栏截进口车辆、汽车安全性零件，也掌管车辆识别号码，开发用于安全测试的仿真人偶，和进行安全测试。

1978 年开始，NHTSA 成立了新车安全评鉴计划，开始使用来自碰撞测试虚拟人物的数据，测试和评估车辆的前方碰撞保护，最开始只有正面碰撞。而之后为了让更多的消费者看懂这些复杂的数据，推出了「五星评价」，为消费者买车提供参考。

![](../Images/0da16f9beb33b778d02bbd9bb699020d.png)

之后，渐渐的增加了侧面碰撞，抗翻滚测试等等，同时要求「五星评级」必须出现在汽车的介绍标签上，为消费者提供参考。不过 NHTSA 也承认自己的五星级评估计划的预算有限，所以将其评级集中在造成死亡人数和重伤人数最多的前方和侧面碰撞事件。

目前 NHTSA 还是主要正面碰撞测试、侧面碰撞测试、侧杆碰撞测试、侧翻测试这几块。而要获得 5 星级的评估，车辆需要达到 10％ 以下的伤害概率，而特斯拉预计 X 只有 6.5％ 左右。

![](../Images/3e605d097e145920f7a531a812b9c365.png)

## Model X 经历了什么 ？

其实在最开始，马斯克在新车发布的时候，其实就已经自称 Model X 为「最安全的 SUV」，而这个结果得益于特斯拉自己内部的车辆测试，内部说在测试侧翻的时候，在规定测试方式下甚至没有办法让 Model X 发生侧翻。

![](../Images/73985a8a1c002e66fdaa48c9be9e8e2c.png)

因为特斯拉对于电动架构和动力总成设计，强化过的电池组安置在地盘，以达到非常低的重心，而这也使得 Model X 在道路上具有最小的翻车概率，甚至没有其他的 SUV 接近甚至超出这个概率。NTHSA 给了 X 型的滚动阻力为 9.30％，并且确实像特斯拉说的在动态测试中并不能让这辆车侧翻。  

另外，像 Model S 和将电池放在地盘的构造的其他所有电动车一样，车的前面没有发动机缸体，这样就拥有了一个非常大的吸能压缩区域。

而这里是 2017 特斯拉 X 型正面碰撞测试的动图：

![](../Images/3c2398c898937708c212dee237ce7212.png)

> 前方碰撞试验评估驾驶员和前排乘客头部，颈部，胸部和腿部的伤害。分别代表平均大小的成年男性和小型成年女性的碰撞测试虚拟人物分别被放置在驾驶员和前排乘客座椅中，并用安全带固定。车辆以 35 英里每小时（56.3 公里/小时）的速度撞上固定的障碍物，相当于以每小时 35 公里的速度移动的两辆相似车辆的正面碰撞。

而值得一提的是正面碰撞过后，车门依旧可以非常轻松的打开，电动系统依旧可以工作。

![](../Images/932e7b102eb776fcf4354a3a3d9972b2.png)

侧杆碰撞测试：

![](../Images/e3f6f447431ca520c01da4299be835d8.png)

关于侧面碰撞的挤压空间数据，除了和 Model S 做对比之外，还有奥迪 Q5 和沃尔沃 XC60，大家可以自己参考。

![](../Images/9b292273ba0a2e2266c4f56f38491996.png)

但作为一台电动汽车，电池的安全也同样不容忽视，国内也曾多次出现过电动汽车事故之后起火的惨案，而 Model X 的锂离子电池组在 NHTSA 测试之前，之中或之后的任何时候都没有发生火灾。

其实电动汽车的事故中，锂电池之所以会发生燃烧，是由于严重的外力破坏，导致防护失效，金属锂与空气接触所造成的。而为了防止空气进入，锂电池都被封装在密闭容器中，而且为了防止外力破坏通常配以不锈钢外壳和铝合金外壳。

而特斯拉更为重视，为电池装配了三层防护板，其中还包括一层坚固的钛合金防护板。

所以总得来说，「最高安全等级的 SUV」确实是实至名归，但这也是特斯拉产品不断改进之后的结果，例如上面的钛合金防护板最初的时候就没有配备。而更重要的一点是虽然重心底防侧翻，吸能空间大，更多的得益于电动汽车的构造优势，但这也同样考验这辆汽车的地盘、电动架构和动力总成等等方面的设计，所以大家也不要进入误区，这次获选也并不能够代表说电动汽车普遍都比较安全。

大家也可以上 NTHSA 官网搜索一下其他电动汽车的车辆安全评级，当然如果你要买车也不仿多多关注这个网站，毕竟相比外观、动力等等，安全因素往往会被我们轻视。
