下面进入今天的「限免精选」。

## iOS 限免

*   **dB meter（￥12→免费）**
    

这是一款可以用来测试音量的应用，利用它可以随时知道周围噪声的分贝数。噪声的高低变化会以直方图的形式展现，用不同颜色显示量级变化，60 分贝以下为绿色，60-105 分贝为黄色，105 分贝以上为红色。通常办公区域绿色为正常，户外街道一般为黄色，如果看到声音到了红色，那就意味着噪声比较明显了，你应该考虑戴上耳机或者换个安静的区域。

画面上除了有实时的分贝数变化，还可以显示当前平均水平（ave）、平均最高水平（ave.max）、最高水平（max），测量数据可以保存。

*   **高铁管家 PRO（￥6→免费）**
    

高铁管家 PRO 是一个自动抢票的软件，就是那种平时用不上，用的时候到处找的工具。各种假期尤其是春节期间的票十分难买，不同车次的放票时间不一样，而且一出来基本是秒没，其实发车前一两天总会有退票的，只是谁也不可能一直盯着 12306。有了这个高铁管家，利用手机就可以 24 小时云端抢票，如果需要提高成功率还可以加钱买抢票套餐。

绑定 12306 账号后可以进行基本的订票、改签、退票等操作。而高铁管家还能在线选座，出发提醒。虽然叫高铁管家，但它也能订机票、酒店等，基本算是一个出行管家了。

*   **Launcher Pro（￥3→免费）**
    

这是一个快捷启动应用，把它添加到 Widget 或者直接放到 Dock 栏中，就可以快捷启动一些 iPhone 的功能，如 Wi-Fi，蓝牙，蜂窝数据，通知，定位服务，后台应用刷新等。不同于其他快捷启动器，Launcher Pro 只能用来打开 iPhone 本身的功能。因为 iOS 的某些选项在设置中隐藏很深，利用这个软件可以快速打开常用的选项，也为那些不熟悉 iOS 的用户提供方便。

*   **Beat Stomper（￥12→免费）**
    

这是一个非常带劲的音乐节奏类游戏，类似以前游戏机上的打砖块，玩家操控一个方块向上跃起再重重落下，从而不断往高处跳去，每次落下必须保证落到移动的挡板上，不要让方块落空就好。随着节奏的加快，挡板下降的速度会变快，你需要快速跃起，然后稳稳落下。方块在跃起后会以不同的角度下降，所以你要预判方块的下落位置。

除了有极具节奏感的电子音乐，迷幻的画面特效也让这个游戏变得酷酷的。不用像其他音乐游戏一样保持精神紧张，掌握节奏感就可以轻松过关。

*   **File Manager Pro（￥25→免费）**
    

这是一个 iOS 平台的文件管理器，可以查看 iPhone 或 iPad 的所有文件，就像 Windows 上的资源管理器，Mac 上的 Finder 一样。File Manager Pro 连接了多个云服务，如 Dropbox、Google Drive 等。常用的新建文件夹，复制移动文件，还有解压都可以在这里完成。File Manager Pro 也能识别各种文件。

iOS 11 会推出自带的 Files，不过从开发者版本看功能还很简陋，可以先收下这款 File Manager Pro。
