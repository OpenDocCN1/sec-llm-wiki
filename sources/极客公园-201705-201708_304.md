# 佳明 vivosmart 3 体验：能够「全天候」使用的运动手环

作为佳明最新的一款运动手环，vivosmart 3 究竟有何特别之处？

  

极客公园最近与天猫成立了「什么都能测」的极客测评团，评测产品从智能手表到空气净化器……涵盖了我们工作、生活的方方面面。我们更关心产品本身的体验是否出色，然后再是「锦上添花」的智能化功能，希望它们能够点亮你我的智能化生活。更多「无微不智」的产品评测，请持续关注极客公园和天猫 app。

* * *

在可穿戴领域，智能手环大概可以分为两个阵营。一类是是由手机厂商所推出的配件，主打和手机之间的联动以及一些智能化的功能；另一种则来来自于可穿戴/运动设备厂商，主打更加专业的数据监测和分析。两类产品的定位不同，也有着不同的受众。  

今天要跟大家分享的佳明 vivosmart 3 显然属于后者。早在 2014 年，佳明带来了全新的 vivosmart 系列运动手环，随后又更迭了 vivosmart HR、vivosmart HR+ 等产品，在运动爱好者中有着较高的关注度。vivosmart 3 则是该系列最新款的产品，那么相比几位「老前辈」，它究竟有何独特的地方呢？

## 隐藏式屏幕、50 米防水  

首先要说的是，vivosmart 3 采用了隐藏式的触控 OLED 屏幕，好处是不显示时能够和手环融为一体，一体成型的机身整体上看起来更加协调，就像是一个普通的运动腕带；不过由于隔了一层橡胶，屏幕的亮度会受到一定的影响，室内使用是没问题的，户外强光下就稍显费力了。

![](../Images/d1a700b03b48ff5ed71e0c3c1a17e118.png)

当抬起手腕或双击屏幕时，就能点亮屏幕，上下滑动可以在不同的页面中切换，长按则可以进入耳机菜单。vivosmart 3 在整体操作上比较流畅、灵敏，系统的层级也很清楚。

![](../Images/0c4d0f48e2abd3f443f171379ffaf4a0.png)

vivosmart 3 的屏幕支持更换显示样式，而且还支持横向显示，可以更好地满足不同人的喜好。

![](../Images/54b20df7ed76f67400260bcff5f7eaea.png)

![](../Images/c2dacdd141925b6a672be03e554475f3.png)

在手环的背面，可以看到心率传感器的监测窗口和用于充电的金属触点。值得一提的是，vivosmart 3 的心率传感器还是比较平整的，戴在手腕上不会有特别突兀的感觉。  

![](../Images/8bfa299b4faf053fec0130f6b34ca66d.png)

这里特别特别要夸赞一下 vivosmart 3 的腕带，它的材质非常柔软、亲肤，长时间戴在手腕上也没有什么负担，可以说是我们测试过的所有智能手环中佩戴最舒服的之一。  

![](../Images/49413382a04161d7cb1b97bc8e96e137.png)

很多智能手环只具备「生活防水」的能力，vivosmart 3 直接支持 50 米的防水，这意味着戴着它洗澡、游泳完全没有任何问题，使用时少了很多麻烦。  

相比智能手表，智能手环往往拥有更长的待机时间，这也是它的优势之一。在开启心率功能的情况下，vivosmart 3 的待机时间为 5 天，我们实际测试的数据也差不多，中等强度的使用下撑一周不是什么问题。

## 满足「数据控」的各种需求  

目前 vivosmart 3 支持 5 中运动模式：走路、跑步、力量训练、有氧运动和其他，不同运动状态下监测的数据重点会有所不同，可以根据具体的运动进行选择。例如在跑步下会着重记录距离、时间、配速等信息；力量训练时则会记录训练组数、休息时间等信息。

另外，vivosmart 3 也能够自动对一些运动进行监测——Move IQ 功能可以自动识别出符合骑车、跑步以及使用椭圆机等熟悉模式的动作。需要注意的是，Move IQ 记录的运动不会出现在活动列表里，仅用于了解全天的运动情况。

![](../Images/65e42d485dc4aae3030c9b6af6fae99f.png)

因为 vivosmart 3 没有内置 GPS，无法记录运动的轨迹信息，所以我们着重测试了它的心率监测准确度。目前监测运动中的心率大概有两种方式，一种是精确度更高的心率带，一种则是更加方便的光电检测。我们戴着心率带和 vivosmart 3 跑了 3 公里后得到了下面的数据：

![](../Images/decd0c1652dbc3e724373e38b9e51545.png)

首先可以看到 vivosmart 3 的心率曲线（下图）和心率带的曲线（上图）走向非常接近，vivosmart 3 的最大心率和平均心率分别是 167bpmb、139bpm，心率带则是 168bpm、139bpm，两者几乎一致，由此可见 vivosmart 3 的心率监测还是非常准确的。而且 vivosmart 3 的心率是支持 24 小时不间断监测的，持续佩戴可以更加宏观地了解每天的心率情况。

![](../Images/e9207e5c3775e4602a925c71a051333d.png)

除此之外，Vivosmart 3 还新增了最大摄氧量（VO2 Max）、全天压力水平（Stress Score）等监测功能。最大摄氧量指的是每分钟每千克体重可以消耗的最大摄氧量（单位为毫升），是一项反映心血管健康的指标。全天压力水平则是结合压力与休息的信息，通过心率变异性（HRV）来判断我们现在的压力大小。  

![](../Images/87111b3637beaed86e7dc204fecb2634.png)

这两项功能的加入，将原本枯燥的数据进一步挖掘后以更加直观的方式呈现给我们，增加了 vivosmart 3 的实用性。

值得一提的是，由于内置了气压计，vivosmart 3 还可以监测上下楼层数量。另外 vivosmart 3 还支持作为监测配件，将心率数据传输给其他佳明的设备（心率推送）。这些功能对于那些「数据控」来说都是非常实用的。

![](../Images/8d0b9434fb2a5c52af14eba1e695713d.png)

vivosmart 3 还会自动记录一些日常生活的数据，包括步数、移动距离、卡路里消耗、睡眠监测和久坐提醒等。如果你有佳明的 VIRB 运动相机，还可以把 vivosmart 3 作为一个控制设备。

![](../Images/41f4689fb7f1d3528e4f7fff87ce3b2a.png)

总结来说，vivosmart 3 的佩戴感非常舒适，支持全天的心率和多种运动模式的监测，再加上 5 天的续航时间，让它非常适合作为一款 7X24 小时佩戴的运动手环。而最大摄氧量、全天压力水平等数据的加入，可以让我们拥有更多的纬度去了解身体的健康信息。

如果你是一个「数据控」，相信 vivosmart 3 可以满足你的所有需求。如果你是一个运动爱好者，vivosmart 3 能够帮助你更好地「上山下海」。目前 vivosmart 3 在天猫的售价为 1080 元，感兴趣的话不妨多多关注。
