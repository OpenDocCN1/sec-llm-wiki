《我的世界》迎来迄今最大更新：全新图像表现、跨平台统一版本

此番更新主要包括「超级无敌图像包」和「团结力量大」两项内容，可玩性将得到大幅提升。


不出所料，《我的世界（Minecraft）》仍为此次 Xbox 在 E3 官方发布会的重头戏之一。作为微软的一棵巨大的摇钱树，《我的世界》也将随着 Xbox One X 的问世迎来迄今为止最重要的两项更新：一是对其图像表现的全盘调整，二是跨平台统一其游戏版本。

视觉效果大升级

玩家将在今年秋季迎来此次重大图像更新。届时，玩家可免费下载「超级无敌图像包（Super-Duper Graphics Pack）」来对游戏进行升级。

上图是游戏的预告截图，我们可以看出，游戏保留了其于视觉表达方面招牌性的「方块元素」，对物品材质的表现处理也未见改变。但与以往不同的是，现在游戏中的某些「方块元素」会被多个更小的「方块元素」刻画出来，因此图像表现也会更为细腻。

更为重要的是，《我的世界》的图像传输方式将会迎来近乎「翻天覆地」的改变。这意味着如果你在 4K 电视上玩《我的世界》，游戏的视觉效果将会令人「叹为观止」。此次升级完全重制了整个光源系统，使得游戏的阴影表现更为丰富。不但如此，游戏同样引入了物理光源系统，这意味着当游戏角色接近屏幕时，他将会以「一种神奇的方式」反射场景中的些许光线。

相互连通，合众为一

于此同时，Mojang 团队同样宣称游戏将会通过 Xbox Live 服务来统一《我的世界》在所有平台上的全部版本。这些版本（包括不在微软平台上的版本），将会通过 Xbox Live 来彼此连通。Mojang 团队品牌总监 Lydia Winters 宣布游戏会统一其在「移动、VR、PC 和控制台端」的所有版本。目前还没有消息表明微软将会如何在其竞争平台上加入 Xbox Live 的连接功能，我们将会进一步期待微软官方的阐释。

此次针对统一所有版本的更新名为「团结力量大（Better Together）」，预计会在今年夏天和大家见面。该更新同样会让玩家得以使用「服务器浏览器」来选择不同的服务器进行游戏，从而将玩法多样化。Lifeboat，InPvP，Mineplex 和 CubeCraft 将会是四个最先加入此次更新范围的服务器，其他服务器将会被陆续加入进来。

《我的世界》针对其在 Windows 10 PC，Apple TV，Oculus Rift，Gear VR 和苹果 iOS 以及 Google 的安卓版的游戏开发了「基床（Bedrock）」版本。随着这次夏季更新的到来，Xbox One 和 Nintendo Switch 游戏控制台版本也将同样成为「基床」版本。这意味着所有使用「基床」版本的玩家只要以同一个 Xbox 账号登录，都可以进入同样的市场，并拥有同样的服务器浏览选项。玩家在某个「基床」版本下的购买内容也可在其他「基床」版本下使用。

两个版本，分而治之？

值得注意的是，以 Java 语言设计的 Xbox 360、Wii U、以及 Windows 和 Mac 的原版游戏目前都不在「基床」版本的范围中。现在，所有「基床」版本的游戏都叫做《我的世界（Minecraft）》，而以 Java 语言设计的版本目前都叫做《我的世界 Java 版（Minecraft Java Edition）》。

尽管《我的世界》迎来了重大更新，Mojang 工作室目前仍在于此同时继续开发着《我的世界 Java 版》。其媒体部主管 Aubrey Norris 表示「我们没有强迫玩家转变的意愿。」他们同样表示，《超级无敌图像包》将会在 Xbox One X 和 Windows 10 平台上登陆，但并未说明玩家是否也可在其他平台上下载此更新包。
