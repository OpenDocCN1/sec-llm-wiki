# Android 之父做了个「全面屏」手机，但他的野心远不止于此

在昨天 Code 大会上面对莫博士咄咄逼人的提问时，理科出身的 Andy 显得有些无力招架，这让人不禁疑问，他想清楚了自己在做什么吗？

  

美国时间 5 月 30 号，「Android 之父」Andy Rubin 创办并担任 CEO 的公司 Essential 发布了两款新品：一款售价 699 美元的智能手机和一台配备了全新操作系统的智能音箱。

这两款新品的名字也很有特点，手机叫「Phone」，智能音箱则叫做「Home」，Andy 在莫博士的 Code 大会上说他希望这款手机是完全属于用户的，因此机身连个 logo 都没有。

Essential Phone 采取与小米 Mix 类似的全面屏方案，不同的是它将前置摄像头置于显示屏顶端，融入了触摸屏中。并且，虽然说是「全面屏」，但和小米 Mix 一样，它也有着一层「下巴」。

机身的背面是指纹识别模块、摄像头、传感器，以及用于外接设备的两个磁力触点。

配置上，Essential Phone 配备了最新的骁龙 835 处理器，4GB 运存，128GB 内存，5.71 英寸 19:10 的显示屏，分辨率高达 2560\*1312，同时配有康宁第五代大猩猩玻璃，边框材料为钛金属，具有超强的耐用性。

![](../Images/f0a438c9f534ec37f658b16bce52e38e.png)手机跌落测试，从上到下分别是 Essential Phone、三星和 iPhone

800 万像素前置摄像头，1300 万像素的后置双摄，3040mAh 电池容量，充电接口为 USB Type-C，没有 3.5mm 的耳机接口。内置系统为原生安卓 7.1.1。

![](../Images/fee351f51720a2494a17f13e2e131a88.png)外媒 The Verge 的上手体验

除了基本的配置之外，Essential Phone 还有一个亮眼的**模块化功能**。在机身背面的顶端有两个磁力触点，可以吸附外界的设备，目前 Essential 已经推出了两款外接设备——一个 360° 的摄像头，还有一个充电底座。

![](../Images/67e488628283a6a536f8cff5a0e8661a.png)Andy Rubin 和 Code 大会

Andy Rubin 在 Code 大会上表示，这样的做法意在迎合移动设备「无线」的趋势，和 iPhone 一样，Essential Phone 也没有配备 3.5 毫米的耳机孔，用户还可以另外购买外接底座来代替充电线。

*![](../Images/36720f72105ed505db25c8fb815efeab.png)*Essential Phone 和充电底座

Essential Phone 最快将于六月开售，目前已经能在官网上开始预订，官方提供了四种颜色供消费者选择：黑色、灰色、白色和绿色。

## 从一开始就没打算做成爆款

对国内用户来说，有了小米 Mix 的铺垫，这款手机确实算不上惊艳，尤其它将前置摄像头融入屏幕顶端的做法，更是会让许多「强迫症」网友抓狂不已。但事实上，外观并不是 Andy Rubin 和他的 Essential 团队最看重的东西。

现在很多用户都开始抱怨手机厂商的创新乏力，他们觉得手机产业已经没有什么可以创新的点了。

但 Andy 不这么想，他认为那些大公司推出的产品之所以看起来没有太多创新的科技元素，是因为它们体量太大了，就比如拿苹果来说，苹果从制造商那里拿到了最新的科技成果，它会直接张口向制造商索要 5000 万份产品，制造商当然做不到，他们才刚刚发明出这样的科技。

![](../Images/d3a692ecf4cf89f348722702974dc792.png)

因此，Essential 手机从一开始就没打算做成爆款，全面屏，钛金属边框，模块化。「我们使用的技术和制造方法师完全无法供应 5000 万台设备。」Essential 公司的首席架构师 Jason Keats 说道。

然而从配置上来看，Essential 并没有打算改变手机行业，它只是尽力达到了行业标准的配置水准。

可以说，尽管 Andy Rubin 和他的 Essential 团队非常想要改变现在的手机行业状况，但他们的力量还太小，对此 Andy 也心知肚明，他也公开表示目前无法打造出完全符合他心理预期的产品，但他们会不断努力，慢慢做出改变。

![](../Images/ea440f9673fc846ea135fd67f7ba7be7.png)

## 智能音箱的背后是庞大的物联网系统

当然，想要弄明白 Essential 到底要做什么，你还得仔细瞧一瞧他们与手机同时发布的智能音箱 Home。

Essential Home 是一款带有屏幕的智能音箱产品，搭载着定制的 Ambient OS 操作系统，用户可以使用它来控制智能家居产品，播放音乐，设置倒计时等，除此以外，Andy 在 Code 大会上表示，Essential Home 希望能够支持一切设备，他们将会尽可能的与所有智能家居的厂家合作，通过 Ambient OS 建立一个通用的物联网系统，这其中甚至包括 Siri 和 Alexa 等其他厂家的智能语音助手。

同时，Essential Home 大多数任务都在本地完成处理，不需要传输到云端，这有助于保护用户的个人隐私。

![](../Images/00183d335d64b1f4bcf22ff73c7b8d51.png)

这台智能音箱设备于 Essential Phone 一样将于今年夏天正式发售，目前官网还没有披露具体的售价。

从 Essential Home 的功能来看，Andy Rubin 是想要将现在杂乱的智能家居市场统一起来，或者说超越智能家居，Andy 想要建立一个庞大而系统的物联网，所有智能设备都将能够连接起来，最初是通过 Essential Home，后续他们还会推出其他产品来达到这一目的。

## 五十多岁还想改变世界

其实，在 2014 年离开 Google 之后，Andy Rubin 本可以选择退休，功成身退，安享天年，但他却没有这么做。

认识他的人都说，Andy Rubin 能看见未来，而且他不想坐等那一天的到来。

早些年，Andy 是苹果公司旗下的 General Magic 的工程师，他参与开发了世界上第一台联网便携设备。后来他联合创办了 Danger 公司，并担任 CEO，这家公司开发了红极一时的 Sidekick 手机，在 iPhone 发布之前提出了「智能手机」的概念。

![](../Images/f47a2a9dbf5b2d839978e69e26a10cbb.png)Sidekick 手机

随后，Andy 创办了真正成就了他的 Android 公司，开发出了当今市场占有率第一的 Android 操作系统，这家公司在 2005 年被 Google 收购，他也就随着公司一起加入 Google，先是担任 Android 部门的主管随后又转到了 Google X Lab 负责智能机器人的开发工作。2014 年，Andy Rubin 离开 Google 创立了风险投资机构 Playground。

Andy Rubin 今年已经 54 岁了，但他不想退居二线，在过去几年里，Andy 一直看着苹果、Google 和其他大公司们企图在高墙内统治世界，但是他认为这条路是走不通，只有开放的平台才能赢得市场。

所以 Andy 回来了，作为 Essential Products 的 CEO。这是他在 Android 之后创办的第一个公司，他想把 Essential 打造成苹果之后最伟大的硬件公司，一个可以支撑数十亿手机、手表、电灯甚至智能烤箱的开放平台。

在 Essential 的官网上刊登着 Andy 的一篇文章《我为什么创办 Essential》（https://www.essential.com/blog/why-I-started-essential）。在文章中，他表示对现在科技行业的状态很不满意：用户的选择越来越少，不必要的功能越来越多，电子消费品越来越多却彼此隔绝，没有协作的能力。

Andy 就这个问题思考了很久，最终他决定和朋友一起创办 Essential 公司——用 21 世纪的方法来打造新时代人们想要的科技产品。

他们将打造一个开放的生态系统，摒弃分裂而过时的封闭环境，在电子设备上使用最优质的材料和工艺，追求简单高效的使用体验。

Essential 将把这些信条应用在每一个产品上，但 Andy 本人也很清楚，想要改变一个行业不在一朝一夕，但他会从这一部手机开始，重新打造他脑海里的未来。
