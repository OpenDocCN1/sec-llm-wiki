# Elon Musk 隐藏在 Model 3 背后的「杀手锏」

从「第一原理」到「机器制造机器」，Elon Musk 要用制造的方式来「杀死」汽车行业？

  

在手工生产时代，每装配一辆汽车要 728 个人工小时，而到了 1913 年，福特发明的流水线使得这一切都改变了，从此之后装配标准部件的 T 型车把这缩短为 12.5 个小时。  

巨大的效率提升，让福特的市场份额从 1908 年的 9.4％ 一路飙升到 1914 年达到 48％。同时因为减少了大量的人工费用，汽车的价格也急剧下降，T 型车在 1910 年销售为＄780 美元，降到 1914 年的每辆＄360，几乎是一半左右。

![](../Images/a26bf66bcf9d22e8e2a8a662d7a84cd1.png)

这个我们现在早习以为常，甚至用于娱乐的「流水线」和张全蛋，在当时却带动了一个产业的发展。

而新一轮的自动驾驶很有可能在未来的几年让汽车产业再次发生巨变，各大汽车厂商面对这个即将到来的变革正在摩拳擦掌的时候，在自动驾驶领域相当「激进」却又被人看好的 Tesla CEO Elon Musk 最近却又希望将汽车制造商的重点重新转回到制造业，又提出了一个相当犀利的观点，**他说工厂本身可能比它所生产的产品更重要。**

Musk 的另一家太空探索公司 Space X 的 CTO 汤姆·米勒（Tom Mueller）曝出，除了长续航的电动汽车和自动驾驶，Musk 还有一个「杀手锏」，而这几乎能够「杀死」这个行业中的竞争对手。

## Musk 的「第一原理」

汤姆·米勒（Tom Mueller）是一名火箭科学家，他研发出了 Space X 的 Merlin 火箭发动机，并在过去 15 年间一直与 Musk 工作。

![](../Images/b87e04b264c7d33536818186a7d84943.png)

在本月早些时候，Mueller 与纽约大学天文学协会的一些天文学家进行了 Skype 电话时，他比较了在特斯拉和 Space X 的制造方面之间的相似之处。不经意间透露了 Musk 希望运用他本人一直推崇的运用物理学设计和制造产品的「第一原理」方法运用到 Tesla 弗里蒙特工厂的生产制造中，而且 Mueller 认为这有可能才是真正打败对手的地方。

**我们先来聊聊什么是「第一原理」？Musk 其实不止一次的提到过，他之所以能够在多个领域取得成功，来自于他对「第一原理」（First Principles）的思考。**

下面是他在一次公开访谈中的表述：

> **我们运用「第一原理思维」而不是「比较思维」去思考问题是非常重要的。**我们在生活中总是倾向于比较——别人已经做过了或者正在做这件事情，我们就也去做。这样的结果是只能产生细小的迭代发展。**「第一原理」的思考方式是用物理学的角度看待世界的方法，也就是说一层层剥开事物的表象，看到里面的本质，然后再从本质一层层往上走。这要消耗大量的脑力。**

简单来说，举个例子，最开始电动汽车的电池组非常昂贵，大概是 600 美元／千瓦时。但我们用第一原理角度进行思考：电池组到底是由什么材料组成的？这些电池原料的市场价格是多少？电池的组成包括碳、镍、铝和一些聚合物。如果我们从伦敦金属交易所购买这些原材料然后组合成电池，需要多少钱？你会发现只要 80 美元／千瓦时。

所以 Musk 的想法总是「这件事情在物理层面上是行得通的，我为什么做不成？」。

当他们试图找出如何降低 Merlin 火箭发动机的成本时，Mueller 与 Musk 进行了一次有趣的对话：

*   **Elon Musk：你认为制造一辆 Model S 需要花多少钱？**
    
*   Tom Mueller：我不知道。大约五万美元？
    
*   **Elon Musk：不，约 3 万美元是生产这辆车的边际成本。你认为它有多重？**
    
*   Tom Mueller：约 5000 磅？
    
*   **Elon Musk：对，约 5000 磅，Merlin 火箭发动机重量是多少？**
    
*   Tom Mueller：约 1000 磅
    
*   **Elon Musk：那么为什么要花费一百万美元来制造 Merlin 引擎呢？它既不是由铝制成的，它没有又没有进行高昂的冲压制造。那为什么他们之间的成本相差 20 倍呢？**
    

这是其实是 Musk 想要说明的一个问题。**材料本身才是主要的限制因素，制造过程中的一切都是公平竞争的，而制造过程中的这些可以完全重新发明。**

火箭科学家 Mueller 说，这只是一个例子，Musk 总是告诉我们说需要推动物理学的极限。它的设想就是把它运用到特斯拉的弗里蒙特工厂，以加快生产速度。

一辆汽车的生产速度，如在丰田或雪佛兰工厂，汽车组装移动的速度大约是英寸/秒来计算的，这远远低于步行速度。他的想法是，完全的机械化，没有人的参与，同时以最快的速度运行。**这就是 Musk 一直在思考的问题：「制造汽车的速度到底能有多快？」**

## 「机器制造机器」

这是 Musk 在特斯拉 2016 年股东大会提到的它所关注的新焦点，**利用物理学「第一原理」它把制造业变成了一个方程式「输出 = 体积 x 密度 x 速度」。**而有趣的是 Mueller 还透露，Musk 也正在研究可口可乐的无人化的制造视频，研究制造速度更快的潜力。

为什么说 Musk 的这个「杀手锏」真的可能变革汽车制造业？

**如果按「第一原理」的思维来看：汽车的主要成本并不在于汽车的原材料成本，而是建造汽车的工厂的效率问题。**

**![](../Images/f3d571113e261621cc519dde936d3b0d.png)**

Mueller 认为，只有 Musk 尝试改造汽车制造业，没有人会这么做，没有人会放弃现有的成果，这就是业内其他整机厂可能被「杀死」的原因。

虽然还有很多证据可以证明生产制造速度的提升所带来的巨大影响，但目前来看，其他几家汽车制造商在一个月内制造的车辆，比特斯拉自 14 年前成立以来累计生产的还要多。

所以这一转变我们还没有看到真正的影响，但这也许要靠 Model 3 来实现，相信大家也听到过「特斯拉计划以每年约 40 万辆的速度生产 Model 3」。而这其实也是特斯拉一直在努力的事情，Musk 认为特斯拉的团队可以将生产线上的速度提高 20 倍。

![](../Images/9190c84f01c819f31fb0db4e832823f9.png)

特斯拉目前每周生产约 2000 多辆车，先按 20 倍的速度推算 2018 年，他们每周都要达到生产约 1 万辆车的水平，除了进一步提高效率外，达到这一速度也将有助于特斯拉赶上大众对于 Model 3 的疯狂需求。

这和通用和丰田运营弗里蒙特工厂时，每年最多可生产 50 万辆汽车的目标类似。但是 Musk 去年表示，他看到了特斯拉弗里蒙特工厂每年生产高达 100 万辆汽车的方式。

**Musk 也在自己的 Twitter 上将特斯拉工厂未来的生产线形容为「Alien Dreadnought（外星人战舰）」，他表示 Model 3 的生产线只是他迈向终极目标中第一步的第一步，而未来生产 Model Y 的工厂才是「Alien Dreadnought」的第一个真实版本。**

**![](../Images/4affc57b495a68b7e39447602ac35e7d.png)**

**而且更重要的一点是，Musk 提到在他未来的生产线上不仅仅是一味的提高自动化的程度，而是将反过来对于生产速度的需求直接构建到汽车的设计中来，例如通过减少车内布线的长度。**他说，Model S 的全车身线束总长大约有 3 公里，而 Model 3 的线束总长仅为 1.5 公里，而他的目标是在新平台的 Model Y 上将布线总长度降至夸张的 100 米。这些改变同样可以大幅度提升生产速度。

![](../Images/bf17a97c3c6e47cdf5bffc3792aaca52.png)同样价格最亲民的 SUV 车型 Model Y，Autocar 的非官方渲染图  

**所以 Model 3 带来的不仅仅是低成本的电动汽车和自动驾驶的广泛应用，他的背后还藏着 Musk 的变革汽车行业的另一大「杀手锏」，也许这才是所谓的「智能制造」的真正奥义所在。**但这同样这也已经被各大汽车厂商所窥视，未来真的是从零打造一艘新战舰更快呢还是改造已有的巨大飞船更快？

**从「第一原理」到「机器制造机器」，再到 Space X 屡战屡败后的成功，Musk 证明自己的言论从「激进」到「靠谱」的时间越来越短，而这一次我同样希望它能够像 1913 年福特发明生产线那样为这个行业再次带来一次「版本更新」。**
