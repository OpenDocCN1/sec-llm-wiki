在文字编辑方面，手机距离「生产力工具」还有多远？

  

前不久的坚果 Pro 手机发布会，可能是罗永浩所有「相声」中我看得最仔细的一场。  

或许在不少人看来，这场发布会在系统层面「事无巨细」般的讲解、demo 占用了过多的时间，让整场发布会显得有些冗长了。不过作为一名科技媒体的文字工作者，发布会上对于信息获取和处理的关注却非常吸引我。

「现在手机上也能完整编辑、处理一篇文章了。」老罗在介绍完大爆炸的编辑功能后说道。实际上，正是老罗的这句话，成为了我购买一部的坚果 Pro 的动机。因为对于我的工作来说，拥有更加丰富的写作手段不亚于为一名战士配发了最新式的步枪。

我打算亲自测试一下，在坚果 Pro 写出一篇文章是不是能够比之前「优雅」。

## 为什么要关注「用手机写文章」？

我们私底下常常开玩笑说，那些跟朋友吃饭还带着电脑的人，不是运营就是「小编」。科技媒体的内容非常强调时效性，很多时候需要我们见缝插针地进行一些文字处理的工作，但是目前这个事情只有电脑能够胜任。

我有一部 9.7 英寸的 iPad Pro，还给它配了键盘和触控笔，曾经幻想着把它作为更加便携的写作工具。但是 iPad 输入效率始终无法让我无法满意，键盘手感太差，触摸屏打字又太慢，更为重要的是**它的体积和电脑并没有产生足够的差距**，最终还是沦为了床头的娱乐工具。

![](../Images/665d83f888524b46d4841b96fb41e521.png)这样打字简直是灾难，图片来源：Tools and Toys（http://t.cn/Ra18crR）

我也尝试过用手机上写一些东西，但是只言片语还行，搞定几千字的文章还是非常麻烦、低效率的——我的容忍度是 140 字的微博。在我看来，手机的输入速度现在已经不是太大的问题，我们的拇指已经习惯了在屏幕上指指点点（估计不少人手机打字比电脑都快）。但是在文字编辑、排版方面，手机还远远不能称为一个「生产力工具」。

举例来说，电脑的鼠标/触控板可以快速定位文字的位置，和快捷键配合还能快速完成复制、粘贴和剪切等操作；而由于「桌面」的存在，电脑上信息间的交互会非常流畅（窗口切换、拖拽文件等）。**这些工作在手机上要么精确度不够，要么非常繁琐，导致整体的效率下降。**

这次 Smartisan OS 3.6 带来了「大爆炸 2.0」、「一步 1.5」和「闪念胶囊」等改进，老罗对于用手机写文章这件事情非常自信，发布会现场甚至还让朱萧木同学亲自做了 demo。不过坦率地讲，我们实际的工作远比现场的 demo 要复杂，写文章除了「敲字」本身，其实是一个包含信息获取和处理——设置大纲——撰写——修改校对——排版发布等过程的「系统工作」。

![](../Images/8f43a5ce40795909b4315ba499cbce82.png)

我需要把这个过程完整放到手机上去进行，最后才能得到我想要的答案。

## 从敲下第一个字开始

我给这次的测试增加了一些难度，就是不借助第三方 app 的帮助，从写作到查资料都在坚果 Pro 的 app 内完成，具体涉及到的有：

*   查资料：自带浏览器、锤子阅读
    
*   大纲：闪念胶囊
    
*   写作：锤子标签（大爆炸编辑模式）
    
*   图片处理：截图（套手机框）
    
*   BGM：自带音乐
    

查资料在我看来就像是一个信息分拣的过程，把信息分为有用、可能有用和无用等纬度进行分类处理。在电脑上我会使用 Reeder、Ulysses 和 Omnifocus 等工具配合使用。在坚果 Pro 上我用自带浏览器和锤子阅读获取信息，用闪念胶囊处理信息。另外，查资料也是一个思维不断完善的过程，在这过程中的一些想法也可以丢进闪念胶囊内。

![](../Images/0587e3eed4e9eff9f2a8c81686b35c30.png)

接下来就要把零散的想法用一个大纲去结构化。大纲不使用锤子标签的原因是避免写作时在同一个 app 内频繁切换。因为闪念胶囊是全局有效的，把大纲记到闪念胶囊里可以随时呼出查看。

![](../Images/9809ef13027bf91ffa25a0fbf5469e85.png)

接下来大部分的工作都会在锤子便签内完成。不得不说，锤子便签对于写作者来说非常友好。它的界面没有什么干扰的元素，支持 Markdown 语言也符合我们的写作习惯，这次还增加了大爆炸的入口。这里要特别说一下大爆炸的编辑模式，**它将段落拆解成最基本的元素，并通过常驻、易于拖动的指针实现了媲美鼠标的定位。**

![](../Images/a101ed61e9cd1894820b221ec9083857.png)

我在文章初步完成后开始使用大爆炸的编辑模式进行修改，刚开始确实需要适应一下它的交互模式，但渐渐熟悉后有一种给文字做「整容手术」的感觉，能够比较畅快地完成局部修改的工作（是的，畅快感很重要）。

文字部分完成后，就需要排版并发布了。因为极客公园的后台同样支持 Markdown 语言，所以我直接把文字复制过去就可以自动匹配格式了。接下来需要一些系统的截图，Smartisan OS 的截图功能支持套手机框，这是一个锦上添花的功能。把自带的浏览器切换到桌面模式，进入网站后台进行图文排版并发布，一篇文章就搞定了。

**没错，你现在看到的这篇文章就是我用坚果 Pro 完成的，它大概花了我 2 个小时的时间。**现在熟悉了操作，可能还会更快一些。目前来看，整个过程还是很顺利的，不过在这过程中我也遇到了一些麻烦。

## 还有什么可以改进的地方？

事先声明，这只是我个人的实际情况，并不适用于所有的文字工作者。

首先遇到的问题就是排版。实际上，这篇文章发布后我又打开电脑调整了一下配图。手机截图的分辨率不适合直接放在网站上，需要经过等比例的压缩；而文章的头图也需要我手动调整一下比例。另外，我还需要用 PS 把一些截图改成了拼图的形式，因为单张截图插在文章内既占用空间也不美观。这些工作目前在手机上还无法完成（用第三方图片编辑工具或许可以，但是也很麻烦）。

另外，在手机上写文章对于文章篇幅和字数的感知要差一些。**在电脑上可以很方便地对文章进行全局审查（例如 Markdown 编辑器的预览功能），也可以很方便地统计字数。**虽然锤子标签也提供了计数功能，但在文字的「所见即所得」方面还是不去电脑来得直接。可以说直到这篇文章发表后，我才知道它在网站上完整的样子什么。

![](../Images/e7c73c639d9bd7ecf68212a5e4911f27.png)通过分享功能「曲线救国」去预览文章

还有一个输入法上的小问题。在电脑端，我可以通过 MacOS 自带的快捷短语或 aText 等软件完成高频词汇的快速输入，例如设置 jgp=坚果 Pro，设置 smo=Smartisan OS 等，这样就不用每次重复打一遍了。坚果 Pro 预装有 3 款定制的输入法（讯飞、搜狗和触宝），但似乎没有一款提供了快捷输入的功能，**Smartisan OS 全局提供了「快捷短语」的功能，但和用输入法打字触发短语还是略有不同的。**

总结来说，目前用坚果 Pro 去写一篇文章在我可以接受的范围内，如果把第三方的 app 加进来效率还会更高一些。除了最后用电脑处理了下图片，剩下的工作全部都是用手机搞定的，整个过程中没有遇到想让我「砸手机」的困惑情况，所以我愿意之后再继续挖掘它的潜力。其中，大爆炸的编辑功能让我印象最为深刻，可以说是我见过比较完美的解决方案了。相比之下，在写文章时一步和大爆炸 OCR 功能我用的并不多。

![](../Images/8b95bf6efc08f007ae9e992f39451885.png)

不过个人觉得，虽然目前 Smartisan OS 在文字处理方面属于移动设备中的佼佼者，但若想真的变成文字工作者（尤其是采编一体）的生产力工具，恐怕在**配套服务（输入法、图片编辑）**上还需要做得更多——当然，这不只需要锤子一家的努力。另外还有一个比较遗憾的地方，因为我没有用语音输入的习惯，所以不确定多「动动嘴」文章完成的效率会不会更高，以后有机会可以单独再做一次测试。
