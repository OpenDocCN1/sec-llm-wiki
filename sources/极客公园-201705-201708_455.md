坚果 Pro 在性能、续航、拍照等方面的具体表现如何？

  

5 月 9 日晚上，锤子发布了今年的第一款新机——坚果 Pro。  

关于这部手机的外观、参数、功能特点，[我们已经在第一时间的坚果 Pro 上手中做了详细的整理](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652846823&idx=1&sn=9b6ca05e347ea2f482293890a1755f8f&chksm=7e6a4751491dce4770386db75f6ee98b33f5288faf010ab28a301eda2f9f22b9796995c097a7&scene=21#wechat_redirect)，大家感兴趣的话可以点击链接阅读，在这篇文章，我们想聊一聊坚果 Pro 外观上一些值得关注的细节以及它在性能、拍照、系统等方面的具体表现。

## 从「圆滑」到「锐利」

过去的几年中，智能手机的主流屏幕尺寸整体上是一直在变大的，大屏幕在带来优秀观感的同时，也让手机变得越来越不好拿，以至于「单手操控」这个乔布斯时代还经常被提及的词汇，现在基本已经没人说了。

面对屏幕尺寸和握持手感这个「鱼和熊掌不能兼得」的问题，绝大多数手机厂商的选择是在收窄屏幕边框的基础上，尽可能地把手机做得更「圆滑」，让大屏幕手机拿起来更舒适，这就有了手机在工业设计上的「圆滑当道」。

不过作为手机圈的「异类」，锤子手机对「圆滑」向来就不是多感冒。相反，锤子手机反而对 iPhone 4、iPhone 5 那种对称和方正的设计情有独钟，这种审美的倾向在坚果 Pro 上表现得尤为明显。

![](../Images/82db23b331003e0a1f891f62df6572ff.png)坚果 Pro 和白锤

如果说在 T2 和 M1 / M1L 上，锤子还试图在「方正」的基础上，在部分细节上做一些「圆滑」的打磨，那么在坚果 Pro 上，锤子则抛开了所有「矜持」，直接做出了一部可能是过去好多年以来外观最为「方正」的手机。第一看上去，坚果 Pro 就像是一部材质上略有调整、多了个金属「下巴」的 iPhone 5。

锤子的这种做法，让坚果 Pro 的工业设计在拥有独特的美感和超高辨识度的同时，也导致了坚果 Pro 的握持手感着实是不怎么样。

![](../Images/39080c3609686b2d160de9e47acb3aa4.png)

对于坚果 Pro 这种「牺牲手感换取美感」的做法是否值得，大家在上手坚果 Pro 后，应该都会有自己的判断。我们的观点是，在手机外观同质化严重的背景下，手上资源有限并且背负着生存压力的锤子能做出来这样一款特别的产品，我们愿意给坚果 Pro 的工业设计一个好评，即使它握起来有点硌手。

## 外观上的几个小细节

坚果 Pro 的机身上看不到任何一颗螺丝，机身背面的玻璃盖板和下面的塑料贴片（观感和触感都很接近金属）是通过不粘胶粘在手机框架上的。拆机时，需要用热风枪对后盖部分进行加热，然后就可以把玻璃背盖和塑料贴片给揭下来了。

![](../Images/3155562c9c854511c12b50faac4af236.png)

无论是正面的玻璃和金属相接，还是背面的玻璃和塑料相接，在量产过程中想要做得比较平整，都是有一定的难度，所幸坚果 Pro 这方面做得还不错，前后的两种材质相连接的地方都没有出现明显的段差。

![](../Images/4286d87199192f7e648a443888f4b11a.png)

坚果 Pro 正面的指纹识别模块也很有意思。通常来说，在非 Under Glass 方案的指纹识别模块上，指纹识别区域的四周都会有一圈金属圈，功能是在检测到手指触碰金属圈时启动指纹识别功能。不过坚果 Pro 是没有这一圈金属的，指纹识别按键一圈的倒角是在周围的金属「下巴」上切出来的，这样可以让指纹识别模块看上去会更简洁一些。

在指纹识别的速度和准确率上，坚果 Pro 也没有任何毛病，基本碰一下就可以完成解锁，在系统设置中可以设置成轻触 Home 键（不用按下去）完成指纹解锁。在 Smartisan OS 设置的「指纹和安全」选项中，还可以设置使用某一个特定指纹直接打开微信或者支付宝的支付界面，非常方便。

![](../Images/7c17447869e044591b96f63b6ebdecbb.png)

另外，根据颜色不同，坚果 Pro 背面的 logo 处理的方式有所区别，黑色和细红线版的 logo 是镶嵌在玻璃背板中的（和黑色的 T1 一致），而红色的 logo 是印在玻璃背板下面的（和白色 T1 一致）。

## 关于「手感膜」

为了防止玻璃磨花，同时提高手机的握持感，锤子在发布坚果 Pro 的同时，还发布了两种均采用了 2.5D 玻璃的「手感膜」（坚果 Pro 前后用的都是 2D 玻璃），一种是钢化玻璃手感膜（售价 49 元），一种叫做「足迹系列」手感膜（售价 99 元）。

![](../Images/c458f4d2d3d2e781f62035d7fa6b5d45.png)

其中第一种钢化玻璃手感膜又分为无孔和有孔两种，前者只能用于 logo 印在玻璃下方的酒红色版本，logo 刻在玻璃中的碳黑色和细红线特别版需要买有孔的版本，否则贴上膜之后 logo 那里会空隙。

在玻璃膜的表面处理（有疏油涂层）、2.5D 打磨、开孔的处理等细节上，这个钢化玻璃手感膜表现的中规中矩，没啥毛病，但也算不上做得多么精致。

![](../Images/462d3aa94e1c87206fd4b96f1a470959.png)

相比之下，「足迹系列」手感膜的打磨和开孔要明显更精致一些，再加上有众多丰富的图案可选，因此相比起 49 元的钢化玻璃手感膜，我们更推荐大家花 99 元买这个「足迹系列」手感膜。

![](../Images/caa024a632e64b8eea96bc9d8af75b1f.png)

需要说明的是，虽然这两种贴膜的边缘都有 2.5D 打磨，但毕竟只是薄薄的一层贴膜，边缘弧度相比采用 2.5D 玻璃手机普遍要小得多，因此大家不要指望这两种贴膜会对坚果 Pro 的手感有多么大的改善，贴膜更大的意义还是保护手机和装饰作用。

![](../Images/d0a15d3cf70a869c09c4423269e12617.png)

如果你希望坚果 Pro 有更好的手感，或者希望可以更好地保护手机，可以考虑一下锤子官方的软胶保护套。这个保护套采用了 TPU 材质，质地柔软，戴上后手感会好很多（代价是把手机原有的设计给遮住了），49 元的定价在原厂保护套中堪称「良心」。

![](../Images/a0b4da5dce41e542d6f667a3c4fc90e1.png)

发布会上，锤子还推出了一款型号为 S-100 的 USB-C 半入耳式耳机，方便没有 3.5 毫米耳机插孔的坚果 Pro 使用，售价仅为 99 元。

这款耳机采用了哑光塑料材质，有黑色、红色、灰色三种颜色可选，做工不错，并且支持线控和通话。不过在音质上，这款耳机的表现一般，在百元国产耳塞中音质也算不上多好，也明显比不上锤子之前和威索尼克合作推出的 S-1000 耳机（售价 199 元），这款耳机价值主要在 USB-C 接口以及方便的线控操作上。

## 性能、续航、「反向充电」

坚果 Pro 的 SoC 分为骁龙 625（32GB 版）和骁龙 626（64GB、128GB 版）两种，骁龙 625 和 626 在核心参数上基本一样，只是在 CPU 最高主频上有细微的差别，实际使用中的差距可以忽略不计。

存储方面，坚果 Pro 标配了 4GB 的运行内存（LPDDR3），内置闪存有 32GB、64GB、128GB 三种可选（eMMC 5.1），支持 Micro SD 卡（需要占用一个 SIM 卡槽）。之所以没有 LPDDR4 和 UFS，是因为骁龙 625 和 626 都只能支持到 LPDDR3 和 eMMC 5.1。事实上，目前同时支持 LPDDR4 和 UFS 的只有骁龙 820 / 821 / 835、骁龙 630 / 660、麒麟 960 以及三星 Exynos 7420 / 8890 / 8895 等少数中高端 SoC。

![](../Images/ee3f5b13bce05b269495bf01fe9b5cab.png)

从 AndroBench 跑分上看，坚果 Pro 用的依然是 EXT4 文件系统，没有用 F2FS。

至于日常的使用，在绝大多数日常 app，骁龙 625 和 626 完全足够流畅运行了，不过在打开 app 以及多任务切换时的流畅度上，骁龙 625 和 626 距离骁龙 820 / 821 /835、麒麟 960 等高端 SoC 还是有一定的差距。另外，或许是为了控制功耗，坚果 Pro 对 SoC 的调度有些保守，我手上这部搭载骁龙 626 的版本，在玩王者荣耀时 CPU 的最高主频只能稳定在 1.8GHz（普通模式可以稳定在 30 帧，高帧率模式帧率跳的会比较厉害）。

由于骁龙 625 和 626 的功耗很低，在 3500 毫安时大电池的帮助下，坚果 Pro 的续航表现非常出色，一天撑下来妥妥的。  

充电方面，配合原装的 18W 高通 QC3.0 快充头，完全没电后，坚果 Pro 差不多半小时能充 40%，一小时接近 80%，实测充电头最高输入功率在 17W—18W 之间。

在发布会上，锤子还提到了坚果 Pro 的「iPhone 陪护」功能，可以反向 iPhone 反向充电。

其实这个功能并没有什么稀奇的，它的原理是利用手机的 OTG 功能来对外接设备供电，理论上支持 OTG 的手机都能反向充电，在坚果 Pro 之前，金立、360 等手机品牌都曾使用「反向充电」作为卖点。

![](../Images/dddad6ae3f2b03561b4bee9840dccc9c.png)

不过反向充电的问题是充电速度通常都很慢，坚果 Pro 也不例外。我们在测试中发现，无论是用 OTG 转接头转接数据线，还是直接用双头 USB-C（C to C）数据线，无论是 iPhone 还是 Android 手机，使用坚果 Pro 反向充电时实际功率都只能达到 2.3W 左右，这意味着即使是给 iPhone 7 这样的电池容量不足 2000 毫安时的手机冲带你，完全充满一次也得花上 5 个小时了。所以这个功能偶尔来应个急还可以，但大家可不要真想着买个手机当充电宝来使。

## 双摄有了，但仍需努力  

在后置相机上，坚果 Pro 这次「赶时髦」地配备了双摄像头。

![](../Images/b0945e6814b3316475e90958968d0e71.png)

这两颗 sensor 的像素都是 1300 万，一个是常规的 RGB 彩色 sensor，另外一个是去掉了拜耳滤镜的黑白 sensor（可以提高进光量），锤子没有公布具体的 sensor 型号，不出意外，这两颗 sensor 应该都是索尼 IMX258。此外，坚果 Pro 的镜头光圈为 f/2.0，不支持光学防抖。

如果你关注手机的双摄方案，应该对坚果 Pro 的这套方案并不陌生，在这之前，小米 5s Plus、努比亚 M2、努比亚 Z17mini 用的也都是类似的黑白 IMX258 方案。从硬件上看，这套方案算不上多么优秀，相比 iPhone 7 Plus、华为 P10、Mate 9、小米 6 上的双摄方案少了变焦功能，但优化得当的话，应该也能获得不错的表现。

![](../Images/55bc5b1d4970afd1ec72c59bd491c5f9.png)

不过在实际使用中，我们发现坚果 Pro 的双摄在体验中还有一些小问题。

![](../Images/350cf0588951e05adc913bdd5daa1a17.png)

![](../Images/37062cd209dc122dcfa9bbfa62612c04.png)

模拟大光圈虚化是双摄的一个重要功能，不过坚果 Pro 的大光圈模式下拍摄时画面无法实时预览，按下拍照后还需要 3 秒左右的时间进行处理，这些都让坚果 Pro 的大光圈功能用起来不太「爽快」。至于虚化的效果，坚果 Pro 还在朝「能用」的标准前进，距离优秀的双摄机型差距明显。

另外，让我们有些不解的是，坚果 Pro 虽然有一个黑白 sensor，但这颗 sensor 并不能单独工作，来拍出专门的黑白照片，而这个功能其他采用「彩色 + 黑白」方案的机型基本都有。

![](../Images/b622288173dabb592cb6ecd35da1b192.png)

![](../Images/49f0de239b185ecae4c5600d2c72e223.png)

![](../Images/7b3aa839f4a39382d71fb3558e8da6bc.png)

![](../Images/c307af630db7bdafa73c8cae21953045.png)坚果 Pro 拍摄（自动测光）

![](../Images/4634ed918dacd9068876a80d97618795.png)坚果 Pro 拍摄（手动测光）

![](../Images/2a28e3cf446cfdbbdd2ab41f0350673d.png)小米 6 拍摄（自动测光）  

成像效果上，坚果 Pro 在白天光照充足时表现还可以，对焦速度、色彩还原、解析力什么的都没什么大毛病，相比旗舰机的差距主要在画面的宽容度上。  

不过在光照不太充足的时候，坚果 Pro 默认的测光有些过于保守，照片拍出来常常会感觉很暗，照片的宽容度一般。手动提高曝光后，照片的整体观感会有所改进，但幅度有限。坚果 Pro 提供了一个夜景模式，不过实际体验中，夜景模式对提高成像品质的加成非常有限，意义不大。

按一部定价 1500 元左右的手机来要求，坚果 Pro 的相机成像品质虽算不上优秀，但也能说得过去。相比起来，坚果 Pro 在大光圈模式、HDR（光线稍差很容易糊掉）等功能上的问题更加影响体验，希望在坚果 Pro 之后的软件更新中可以有所改善。

## 「闪念胶囊」是个「大杀器」

目前坚果 Pro 的最新系统是 Smartisan OS 是 3.6，虽然「图钉」（将频繁使用的应用通过图钉功能钉在锁屏上）功能得等到一个月后的 Smartisan OS 3.7 中才能上线，但 Smartisan OS 3.6 依旧有不少亮点。

在 Smartisan OS 3.6 中，默认桌面增加了文件夹功能（终于等到了），「大爆炸（Big Bang）」的版本号从 1.0 升级到了 2.0，增加了编辑模式、炸了又炸等功能，进一步提升在手机这样的小屏幕上处理文本的效率，「一步（One Step）」的版本号从 1.0 升级到 1.5，增加了以图搜图、智能识别文字信息等功能。

这些功能上的优化进一步完善了 Smartisan OS 的用户体验，让系统更加好用，不过 Smartisan OS 3.6 最大的亮点是新增的「闪念胶囊（Idea Pills）」。

在目前的系统版本中，「闪念胶囊」还是一个测试功能，需要在系统的【设置】—【全局高级设置】中打开。

![](../Images/47f7fceaa757e31e7848c3cd69afa1ca.png)

打开后，在任意界面下，只需要按住 Home 键，就可以通过语音的方式输入内容，语音会自动转成文字，松开 Home 键就可以生成「胶囊」，生成后可以给「胶囊」标上不同的颜色，方便后期管理，也直接设置成待办事项。

任意界面下在「闪念胶囊」的小角标那里向屏幕内滑动，就可以呼出所有的「胶囊」，在这里除了可以修改、删除每个「胶囊」，也可以结合「一步（One Step）」功能，把「胶囊」发送到微信、锤子便签等第三方 app 中。

![](../Images/4b0ed75095b34cd1d2df86202c83c2ca.png)

另外，「闪念胶囊」本身还具备一定的搜索功能，如果语音输入的是手机中存储的一首音乐、某个联系人或者某个已经安装的 app，在文本框下还会出现对应的提示（音乐的话会自动播放）。

如果你像我这样因为工作原因（主要是自己记性不太好）需要经常把某些想法和待办事项记录下来，Smartisan OS 的这个「闪念胶囊」可谓是一个革命性的功能，它将原来那种「解锁手机—找 app—添加备忘录—文字输入」简化成了按住 Home 键说话，这种方便的体验，可以说是用上了就回不去了。

![](../Images/e3d588212747014ff9b541fb00489d6e.png)

Smartisan 3.6 还有一个颇有「情怀」的小细节。亮屏后，按一下音量加或者减可以呼出系统的音量 / 亮度调节界面，正常情况下这个界面是白底，不过如果周围的环境比较暗，这个界面会自动改成黑底的，降低对眼睛的刺激。

![](../Images/79bfb9187caf50e45b092468f0b05ddd.png)

最后，虽然 Smartisan OS 3.6 并没有集成 Google 服务框架，不过可以在自带的应用市场中直接安装「谷歌服务下载器」，更新后（需科学上网）就可以正常使用 Google「全家桶」了。

## 购买建议

坚果 Pro 有 32GB（黑色）、64GB（黑色、红色）、128GB（黑色、红色、细红线）三个闪存容量版本，运行内存均为 4GB，三个版本的售价分别是 1499 元、1799 元、2299 元。

除了存储容量，这三个版本在配置上还有所区别，32GB 用的是骁龙 625，64GB、128GB 是骁龙 626，32GB 的前置摄像头像素 800 万，64GB、128GB 为 1600 万，32GB、64GB 没有 NFC，128GB 有 NFC（但目前还没有适配刷公交卡、支付等功能）。

虽然区别不少，不过在实际使用中，这些硬件上的细微不同几乎不会对日常体验有什么影响。大家在选购坚果 Pro 时，基本只需要考虑下自己需要的存储容量有没有喜欢的颜色就可以了。

![](../Images/1bef1fc22e367d38326030f29608f96a.png)

回到手机本身，在 1500——2000 元这个价格档，坚果 Pro 的外观设计和工艺水准都达到了比较高的水准，配置在这个价位算不上惊艳，但也没有太大的硬伤，Smartisan OS 则是个额外的加分项。只要你不介意握起来有点硌手，坚果 Pro 是近期这个价格档值得考虑的一个选择。
