整合三大系统，从 Windows 10 秋季更新看微软的野心

虽然错过了移动市场很遗憾，但微软并没有彻底放弃，它正打算开着自己的潜水艇偷偷赶上 iOS 和安卓这两艘巨轮。


最近微软似乎很不安分，撇开满屏的 WannaCry 不谈，Windows 在过去一个月里经历了三次大事件：

4 月 11 号，「创作者更新（Creator Update）」开始推送给用户；

5 月 2 日，召开教育主题的发布会，发布了全新的笔记本和轻量级系统 Windows 10 S；

5 月 12 日，在一年一度的开发者大会上，微软又郑重宣布他们即将在秋季发布下一次 Windows 10 的重要系统更新：秋季创作者更新（Fall Creator Update）。

那么微软到底想做什么？我们先从这次的更新的主要内容说起。

除了全新的设计语言 Fluent Design 以外，Windows 10 Fall Creator Update 至少会有以下七个功能的更新。

Story Remix（故事混剪）

Story Remix 类似于 iOS 上的照片 APP 中的回忆功能，它是一个视频制作应用。它可以收集你的照片和视频，并把它们合并成一个有着背景音乐、主题和转场特效的视频。论功能来说，它更像是体量较大的 iMovie，或者 Google 相册的故事功能和 Snapchat 特效的合体。

这个应用是支持云端同步的，这意味着你可以在 Windows、iOS 和安卓上同步操作，在一台设备上开始制作，并在另一台设备上完成它。

iTunes 登陆 Windows Store

本月初，微软表示其新发布的系统 Windows 10 S 上只能安装来自官方应用商店的应用，这意味着像连 iTunes 都不能用，但是微软已经解决这个问题了。在大会上，微软宣布苹果正在开发 iTunes 的 Windows 应用商店的版本，在今年秋天之后，你将可以在 Windows 10 S 的设备上同步你的 iPhone 和 iPad 了。

Microsoft Graph

「如果你不能击败你的对手，那就加入他们。」微软已经意识到了这点，它知道自己无法在手机市场上打败苹果和安卓，于是在上周的开发者大会上，微软推出了 Microsoft Graph 功能，它可以通过微软的云端来同步用户在多平台上对某个应用程序的操作，支持的平台包括 Windows、iOS 和安卓。

Timeline（时间线）

有外媒将 Timeline 比作时间机器，它能让你随时回到你在个人电脑上处理过的文件、使用过的应用以及浏览过的网页，然后再跳转回到你刚刚正在做的事情。这就像一个功能扩展了的任务管理器，你不仅可以管理现在正在执行的任务，还可以回到更久之前，管理之前执行的任务。

Pick Up Where You Left Off

这个功能好比跨平台的苹果 Continuity 功能，Pick Up Where You Left Off 能够帮助 Windows 的用户在 iPhone 和安卓设备上打开他们刚刚在 Windows 10 设备上打开的文档、网页及其他文件。比如说，你可以在安装 Windows 10 系统的个人电脑上打开一个 Word 文档，输入一段文字后保存它，然后你可以直接通过 iPhone 上的 Cortana 应用在手机上打开这个文件继续编辑。

Continuity 是苹果平台上的最棒的功能之一，它可以同步 Mac、iPhone 和 iPad 三种个人设备上的内容。如果微软能够让 Windows 上的内容在 iOS 和安卓上同步，那这将成为 Windows 10 的一个杀手级功能。

Clipboard（剪贴板）

Windows 系统上的剪贴板将会升级成一个云端支持的功能。你在 Windows 电脑上复制一段内容，可以在安卓、iOS 和各种平板上粘贴出来。这个功能苹果已经有了，不过和 Pick Up Where You Left Off 一样，苹果只支持自家的设备，而 Windows 将支持全平台的操作。

OneDrive 文件随用随取（OneDrive Files On-Demand）

OneDrive 是微软的云端储存系统，除了 Windows 以外，它在 iOS 和安卓设备上也有客户端，但在这次更新之前，OneDrive 都只是一个同步文件的系统，它把本地文件拷贝到云端，再去另一个设备从云端下载。但有了「文件随用随取」功能，OneDrive 可以只保存本地文件的路径地址，让用户在需要时再让云端获取文件然后下载。

这意味着用户不需要将所有 OneDrive 里的文件都同步到本地，只要保持在线，云端的文件都可以随用随取。这对储存空间不足的电脑来说是一件好事，不过考虑到 OneDrive 的免费空间只有 5Gb，想要不花钱解决储存空间的事还没那么容易。

以上这些就是微软在 Build 大会上透露的即将在 Fall Creator Update 中亮相的一些新功能，从中我们可以看出微软对未来的一些打算。

与其说 Windows 10 是一个系统，倒不如说它是一种服务，与微软以往推出的桌面系统不同，Windows 10 会经常更新，而且不像是以前那样修修补补，更重要的是功能上的更新。从最开始的 November Update 到「周年更新」再到「创作者更新」，Windows 10 已经比最初的版本进化了许多——毫无疑问，这是微软有史以来最优秀的系统。

微软深知在移动市场上无力回天

到底 Windows Phone 消亡与否，微软似乎已经不是很在意了，从它最近的动作来看，它根本没有再给 Windows Phone 来一剂肾上腺素的打算。

虽然错过了移动市场很遗憾，但微软并没有彻底放弃，它正打算开着自己的潜水艇偷偷赶上 iOS 和安卓这两艘巨轮。

打开 App Store 或者安卓市场，点进开发人员 Microsoft Corporation 的页面，你会惊讶于微软为 iOS 和安卓开发了多少应用。以中国区的 App Store 为例，微软有 70 个应用，Google 有 57 个，而苹果自家的应用也只有 45 个。

微软在 App Store 中国区上的部分应用

微软正悄悄地在 iOS 和安卓平台上建立起自己的生态系统，这一次，在西雅图的开发者大会上，我们可以确定，微软重新找到了自己的定位。

重新开始专注软件

曾经微软的目标是让每个人的桌面上都有一台个人电脑，这个目标可以说已经基本实现，或者说已经到了收尾期了——现在只要人民币两千元就可以购买到一台能够流畅使用的 Windows 10 S 笔记本。

Windows 曾经是世界上最广泛使用的操作系统，那时微软认为自己同样可以征服移动市场，然而当时它已经比苹果和谷歌慢了好几拍。后来的事实证明微软错了，它在移动市场上以惨败收场，但微软现在似乎很坦然地接受了这个结果，并重新明确了自己的定位：一家软件公司。

像很久以前那样，微软又开始专注软件了，这对微软自己来说也是一个很大的赌注。

现任 CEO 塞特亚·纳德拉预测到在不远的未来，人们平均会使用 6 台左右的个人设备，而且很显然大多数设备都不会运行 Windows 系统。所以与其费尽心思劳力地抢占市场份额，微软选择另辟蹊径，从软件层面提高 Windows 的使用体验，这不仅仅包括 Windows 本身的系统更新，还有 Windows 系列应用在其他平台上的使用体验。

将优秀的 Windows 应用移植到用户群庞大的 iOS 和安卓平台上，一方面能更好地留住目前使用 PC 的用户，另一方面也能吸引移动端的用户使用 Windows。「不管 Windows 用户平时使用的是什么设备，我们都在努力满足他们所有的需求。」微软操作系统部门副总裁乔北峰（Joe Belfiore）这么说道，「我们会尽力让已经做出选择的用户获得最好的体验。」

微软未来的目标是什么？

目前来看，微软打算成为平台的整合者。凭借着自己在多平台上的应用和出色的软件能力，加上目前对云端的重视，微软打算让多平台的用户获得像苹果自家产品那样的流畅零过渡的高效率体验。

作为消费者，苹果越来越令人失望的创新能力很难一直留住用户，越来越优秀的安卓和 Windows 设备可能会在将来提供给我们更好的选择。微软能做成这样一件事对消费者当然是有利的，我们也希望可以使用不同平台上最棒的设备，还可以高效地在不同设备间同步与切换。

这样的体验应该是一个趋势，但曾有乔帮主坐镇的苹果毫无疑问是一只拦路虎。

就苹果来说，iOS 上严苛的限制让微软很难自由发挥，如果微软想要做成这样一件事，那势必会打破苹果自身的封闭性。从最近苹果对微信采取的一些动作可以看出，苹果并不打算容忍自家平台上出现搅局者，未来微软也很有可能会面临同样的问题。

微软的软件实力是无需置疑的，它想在云端统一目前稍显凌乱的系统和硬件市场，从技术和经验上来看微软是完全做得到的，但苹果和谷歌肯定不会坐视不管，放任微软在自家的领土上撒野。究竟微软能否成功为横跨 iOS、安卓和 Windows 的消费者提供一个完整有序的数字生活体验，他们给出的答案很明确：「我们会尽力而为。」
