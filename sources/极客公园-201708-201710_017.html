将 iPhone 8 Plus 拉下「最强拍照手机」的位置后，Pixel 2 其实还留了一手

摘要：谷歌在 Pixel 2 中内置了一块图像处理芯片，而这可能也将使得其在拍照方面，获得更大的领先。


前不久 iPhone 8 Plus 以 94 分的成绩夺得了知名摄像器材评测机构 DxOMark 测试榜单的第一名，不过这个荣誉可能还没有「捂热」，就已经易主了。

本月早些时候，谷歌在美国旧金山召开了秋季发布会，带来了包括 Google Home Mini/Max、Pixel 2/2 XL、Pixelbook、Pixel Buds 以及 Google Clips 在内的多款硬件产品。 

不出意外地，在此前 Pixel 凭借 90 分的成绩长期霸榜之后，Pixel 2 再次延续了这一「传统」。在相关的测试报告中，DxOMark 为 Pixel 2 打出了 98 分，这也力压 iPhone 8 Plus 和三星 Galaxy S8 Note 的 94 分，成为目前的最高分。


Pixel 2 的那颗单摄像头拍照效果如何？

和上代 Pixel 一样，这次 Pixel 2 依旧配备了一颗后置摄像头，而非现在流行的双摄解决方案。规格参数方面，像素为 1220 万，单位像素尺寸 1.4μm，支持激光对焦+双像素对焦，支持 OIS 光学防抖和数字防抖，f/1.8 光圈。 

在 Pixel 2 的测试文章中，DxOMark 对它的评价是：「虽然『仅』有一颗摄像头，但 Google Pixel 2 的摄像头是我们测试过的移动设备中，表现最好的，98 分创下了新的评分记录，令人印象深刻。」

DxOMark 的测试报告显示，在强光下，Pixel 2 可显示良好的细节、出色的色彩渲染和非常棒的动态环境。同时，高光和阴影区域的细节保留做的很好，噪点控制以及自动对焦性能也十分出色。 

Pixel 2 亮光测试样张

暗光环境以及需要利用闪光灯来进行拍摄的条件下，Pixel 2 会出现色彩不均匀的情况，但色彩还原度、动态范围和自动对焦表现不错。 

不过，由于其仅配备了一颗摄像头，缩放、景深效果、肖像模式，背景虚化都要通过它来完成，而事实上，虽然其在软件层面上做出了一定努力，但依旧略显不足。 

尤其是在「背景虚化」这一项测试中，Pixel 2 的实际表现要比采用了双摄解决方案的 iPhone 8 Plus 来的差一些。从对比图中可以看到，后者显得更加自然。 

左/Pixel 2   右/iPhone 8 Plus

另外，对于 Pixel 2 的自动对焦性能，DxOMark 给出了用「具有我们见过的最好的自动对焦，而且比我们测试过的任何其他智能手机相机好得多」来形容，足以见得其这部分性能的出色性。

最后有关视频拍摄，Pixel 2 在移动设备中得分最高，并且比上代产品提高了 5 个点，以 96 分排在视频分类之首。在几乎所有照明条件下，Pixel 2 的曝光表现都令人满意，并且自动对焦非常快速、平稳。当然，在平衡细节保留和降噪方面，它也做得很棒。


有关拍照，谷歌还为 Pixel 2 设计了一枚隐藏的芯片

如果按照 DxOMark 的测试评分体系来看，Pixel 2 已经成为迄今为止所有智能手机产品中拍照性能最为出色的。但在拍照这件事情上，谷歌对 Pixel 2 期待远不止如此，而是希望其能够在未来的一段时间内，相对其它手机产品，都将保持领先地位。 

根据 TechCrunch 的报道，此次谷歌为 Pixel 2 设计了一块名为「Pixel Visual Core」的芯片，来对图像处理进行优化，它也是谷歌首款自主设计的消费类芯片，不过其尚未被激活。

Pixel Visual Core 具有八个定制设计的图像处理单元（IPU）核心和 512 个算术逻辑单元，其中 IPU使用两种特定领域的语言：Halide 和 TensorFlow。前者用于图像处理，而后者则用于机器学习。

Google 表示，Pixel Visual Core 芯片支持 Pixel 2 拍摄 HDR+ 算法图像，并且不会出现 HDR 图像延迟的情况。同时能够帮助 Pixel 2 将 HDR+ 的处理速度提升 5 倍，但相比利用 CPU 来进行处理，它的能耗仅仅相当于之前的十分之一。

另外，值得一提的是，Pixel Visual Core 是一个可编程芯片。Google 在今天的公告中指出：「HDR+ 是第一个在 Pixel Visual Core 上运行的应用程序，我们正在准备下一组应用程序，随后也将陆续推出更多的 Pixel Visual Core 的应用。」

当然，激活 Pixel Visual Core 芯片这件事情可能也不会拖太久。按照谷歌的说法，该芯片将作为 Android 8.1 预览中的开发者选项，而该版本的更新大概将在几周后到来，感兴趣的朋友不妨关注下。
