# 英伟达推出的这个新功能，让低配电脑和 Mac 也能顺利吃鸡

**摘要：随着 5G 高速网络的普及，GPU 和 CPU 要承载的高强度运算将移至云端，而 GeForce Now 也将成为基础服务。**

  

在《王者荣耀》让「小学生」和「开黑」流行后，PC 游戏《绝地求生》则让「吃鸡」成为当下潮流。不过，从硬件方面来说，「吃鸡」还是有一定门槛的，如果屏幕前的你只有一台低端 PC 或者是苹果的 Mac 电脑，十有八九不能玩《绝地求生》这款游戏。

不过，显卡大厂英伟达近日在北美推出一项业务 GeForce Now，让用户可以使用云端的 GeForce 显卡运行大型 PC 游戏。Mac 用户只要下载相应版本的 Steam 客户端，就可以和小伙伴们开始愉快的「吃鸡」了。

从短期来看，英伟达的这项服务似乎要革自家显卡的命；从长期来看，在 5G 等高速网络推广之后，我们目前的硬件设备将必然「屏幕化」，并将运算「上交」至云端计算平台，而英伟达目前的「云显卡」GeForce Now，在未来则有可能成为重要的云图形计算平台。

  

## 大吉大利 Mac 吃鸡

白领最爱的苹果电脑可能是职场的工作利器，虽然配备了 AMD 的强力显卡，但是 Mac 电脑无论是专业级还是普通版，在游戏方面的表现都差强人意。而此次英伟达推出的 GeForce Now 瞄准的正是欲玩游戏而不得的用户。

据悉，GeForce Now服务让玩家可以使用云端的 GeForce GTX 显卡，运行大型 PC 游戏。即使 Mac 电脑的配置不适合玩游戏也不要紧，因为虚拟游戏 PC 会负责所有的 CPU 和 GPU 运算需求。同时，GeForce Now 服务已经集成到知名游戏平台 Steam 中，只要 Mac 用户下载相应的客户端，连接自己的 Steam 账户就可以开始玩游戏了。

不过，在「吃鸡」之前，还是要先确定一件事，就是带宽是否足够。根据英伟达的解释，GeForce NOW 完全依靠高速的互联网连接，因为游戏实际上是在远程的服务器上运行，然后通过互联网传输到 Mac 上。GeForce NOW 要求 25Mb/s 的速度，以及 5G 无线路由器。英伟达推荐 50Mb/s 带宽。所以，如果网络不够快的话，用户还是没法「吃鸡」。

## 计算云端化 终端显示化

虽然英伟达的 GeForce Now 服务目前只在北美提供服务，但是可以推测其后是完全可能推向全球的。有意思的是，如果英伟达这个「云显卡」技术成功的话，意味着买顶级显卡玩游戏将成为历史。而用 GeForce Now 来革自家高端 GPU 的命，其背后的逻辑在于，英伟达已经看清未来像大型游戏这种高强度实时的图形运算将最终移至云端，而非继续以本地的笨重的机箱形式存在。而届时，用户手中的手机或者桌上的笔记本，都将成为纯粹的显示和输入设备。

其实终端硬件的简化早已有之，其中最有代表性的就是商用的瘦客户机（thin client）。顾名思义，这些瘦客户机就是精简版的 PC，去掉软驱、硬驱、硬盘等等硬件，所有运算和存储都在中央服务器上进行，而终端的机器只负责输入和显示。从本质上看，英伟达推出的 GeFroce Now 有类似的功能，就是将对 GPU 高依赖的图形运算放到了云端，而用户的 Mac 电脑只负责输入和显示。

而在英伟达之前，对于 CG 内容渲染的云端化早已经开始。现在的动画公司和特效公司早已习惯将做出的文件放到「渲染农场」等云端平台进行渲染，因为后者的渲染速度更快，且成本要比在本地架设服务器低。不同的是，「渲染农场」是 To B 业务，而 GeForce Now 则是完全面向消费者的。

![](../Images/884dc8ea7d82a00a991dbf378ba0f542.png)  

## 「云」需要高速网络支持

省下买 GPU「核弹」的钱，把图形计算上交到云端是个绝好构想，但要实现这个梦想，还相关行业的助力。根据英伟达 GeForce Now 服务要求来看，最重要的就是需要用户有 25Mb/s 的带宽，而推荐配置则是恐怖的 50Mb/s，可见实现云端服务的重要一点，就是需要高速网络的支持。虽然国内外的一些城市已经实现了光纤网络覆盖，但是要达到 50Mb/s 的网速也并不容易。

好消息是，随着 5G 技术逐渐成熟，未来的移动和 Wi-fi 网络提供的速度将能够达到 10Gb/s。从历史角度来看，每次通信技术的迭代，都会带动新一批应用的流行。2G 时代是文字、3G 是图片、4G 则让视频和摄像头成为手机最重要的功能。随着 5G 高速网络的普及，届时手机等设备或许不再需要强劲的 GPU 和 CPU，因为全部运算可轻松放到云端，真正实现终端的显示化。

届时，英伟达目前看起来颇为前沿的 GeForce Now 服务，在未来可能成为最基础的网络服务之一。
