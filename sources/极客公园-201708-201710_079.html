蚂蚁金服发布首个科技平台「蚂蚁佐罗」，它对你使用支付宝有什么影响？

摘要：生物识别技术的发展，正在进一步改变数字世界的样子。


如今，出门不带现金，使用手机支付成为很多人享受现代生活的方式之一。而作为大家主要支付工具的支付宝，除了提供密码、指纹登陆之外，越来越多的人也渐渐习惯于使用刷脸登陆，甚至于在线下，你还可以使用刷脸方式进行支付。

从密码到指纹，再到如今的刷脸支付，技术上的进步不仅提升了人们使用产品的体验，也在更多元地融合进入我们的生活当中。10 月 11 日下午，作为阿里巴巴云栖大会重要部分，蚂蚁金服在其 ATEC 大会论坛上，宣布成立旗下首个独立科技平台 ZOLOZ（蚂蚁佐罗），并将面部识别技术进一步向前，推动生物识别技术能力的普及，这其中还有眼纹识别的踪影。

「我们每一天都被设备不断确认身份，不断被设备问起『你是谁』，而我们的生物特征就可以回答这些问题。」作为 ZOLOZ CEO 的 Toby Rush 认为，在现实世界，我们能通过面对面的情绪反应、声音、动作传递来表现自己，而在数字世界，这件事也存在可能。

什么是眼纹识别？通俗理解就是我们的眼白区域纹理，因为每个人眼白区域血管排布不同，所以和虹膜一样，眼纹也具有唯一性，即便出现同卵双胞胎验证，也具有独特性，所以眼纹识别的精准率相比其它维度的生物识别更高，误识率更低。 

而说到利用人眼进行生物识别，你也许会联想到虹膜识别。这项技术同样拥有精准度、误识率等房买你的优势，但近两年，只有部分智能手机上搭载了虹膜识别技术，因为使用虹膜识别技术就要专门的硬件——远红外摄像头支持，对手机改造和规模化商用是一个挑战。相比之下，眼纹识别对摄像头没有特殊需求，所以用普通智能手机的前置摄像头就能满足，更有利于规模化使用和用户普及。

所以三年前，支付宝就上线了人脸识别技术，人们不需要借助密码，使用人脸就能方便快速验证身份。随后，这项技术不断进步，蚂蚁金服 CTO 程立表示，如今每天有三分之一的用户使用刷脸登录支付宝，而在过去这两年的迭代中，人脸识别技术已经可以从线上来到线下，我们甚至能通过刷脸支付体验肯德基餐厅，这也展现了未来世界的一角。

借助眼纹识别在身份识别独特性和安全性，蚂蚁金服叠加之前的人脸识别技术，在不增加用户负担的情况下，可以对每个人进行多维度的交叉验证，提高了识别的准确度和安全性。所以，当我们每天都在使用支付工具时，它无疑更加便利和安全。

从繁琐、安全性不高的指纹识别，到如今迭代升级的面部识别，生物识别技术的变化之大令人难以想象，不但让我们使用更加方便，也扩展出更广阔的使用场景。

在 Toby Rush 看来，这种身份验证方式的变化让我们的数字世界和现实世界产生了更多关联。正如之前蚂蚁金服生物识别技术负责人陈继东所说，面部识别技术的发展会经历五个阶段，每一阶段的变化都伴随着技术与场景的进一步结合：

  1. 辅助核身，用于非金融场景中的身份验证。如我们在手机上刷脸解锁，或者打开某个应用，需要人工干预；

  2. 实人认证，在非金融场景下，识别和匹配个人身份信息。如火车站刷脸进站或酒店刷脸入住，需要人工干预；

  3. 智能核身，在个人设备的金融支付场景中，不需要人工干预，就可以完成用户的刷脸支付，刷脸转账等业务，但需要用户配合，比如支付宝刷脸转账，同时结合人脸、眼纹、虹膜等多重生物特征；

  4. 支付核身，在公用设备上完成金融支付场景。不用人工干预，就可以完成支付业务，但需要用户配合，比如肯德基 KPRO 餐厅的刷脸点餐；

  5. 万物互联，在公用设备上，无需人工干预，也无需用户配合，完成刷脸支付过程，比如无人超市自动抓取你的面部信息。

生物识别技术进化是多方面的，它不仅仅意味着识别准确率或者安全性，这种进化本身还能结合进其它技术。看看苹果公司就更能体会到这一点，从 iPhone 5s 上体验出色的指纹识别起步，到今年秋季的 iPhone X 发布会，带来 Face ID 面部识别的同时，取消原来的 Touch ID 指纹识别。这项技术通过手机内置的 TrueDepth 相机可以投射并分析面部 30000 多个不可见的点，构建出准确的面部深度信息，这意味着它不会被照片所欺骗。另一方面，泛光感应元件又能够在黑暗中识别出你的脸，这让人脸识别的适用范围更广。

Face ID 不仅仅是识别你的面部信息那么简单，搭载 A11 仿生芯片以后，Face ID 也具有「学习」的可能，它会自动适应每个人的面部变化，所以无论你是化妆或者长出头发，或者剃掉胡子戴上帽子，它都可以认清「你是谁」，尽管目前它仍然没有解决同卵双胞胎的面部相似问题，但这种生物识别技术的进化也足够让我们惊讶。

所以，说到 ZOLOZ 成立，我们看到的，其实不仅是蚂蚁金服在生物识别技术上的成熟，也意味着在我们的现实生活中，生物特征验证开始让更多生活场景变得方便和高效，并进一步展现出更多可能。在为期四天的云栖大会上，我们会更进一步为大家带来关于 ZOLOZ 的详细信息。
