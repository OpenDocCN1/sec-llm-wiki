2018 款 iPad Pro 将加入 TrueDepth 相机系统，但何时发布还得看 iPhone X 的「脸色」

摘要：将 TrueDepth 相机系统引入 2018 款 iPad Pro 值得期待，但何时能发布，却还是未知数。


坦率来讲，最近几年平板电脑市场整体表现并不令人满意。根据 IDC 之前给出的数据显示，2017 年第一季度，全球平板电脑出货量同比下降 8.5%，为 3620 万台。 

排名前五的分别是苹果、三星、华为、亚马逊和联想。其中第一季度苹果出货量约 890 万台，市场占比为 24.6%，虽然同比下滑 13%，但依旧占据榜首位置。 

实际上从最近几年 iPad 的发展轨迹可以看到，在提出「iPad Pro 足以取代 PC」之后，库克掌舵下的苹果公司一直在努力，希望将 iPad 打造为功能更加强大的设备。


2018 款 iPad Pro 或许也将配备 TrueDepth 相机系统

虽然随着最新一代 iPhone 8/8 Plus 开始陆续出货，不少喜欢「尝鲜儿」的用户已经拿到手，但依旧有很多人在等待 iPhone X。

除了拥有目前 iPhone 家族中独一无二的「全面屏」设计，iPhone X 值得被等待的理由还有很多，比如它所配备的 TrueDepth 相机系统。

而最近根据凯基证券分析师郭明錤预测，将于明年发布的全新 iPad Pro，也将引入 TrueDepth 相机系统，并让 iPad Pro 的体验与 iPhone X 保持一致。

在郭明錤看来，加入 TrueDepth 相机系统，不仅将提升产品的竞争力，当所有高端 iOS 设备都支持 TrueDepth 相机系统后，整个生态系统的开发也将受益。 


TrueDepth 相机系统有哪些特点

The TrueDepth camera system（原深感摄像头系统）由点阵投影器、泛光感应元件、红外镜头、700 万像素摄像头、环境光传感器、距离感应器几个元器件组成。而它除了能够实现 Face ID 功能，也用来驱动 Animoji 3D 表情和其他 AR 相关的内容。

按照郭明錤的说法，由于 2018 款 iPad Pro 的体验将向 iPhone X 看齐，这里我们以 iPhone X 的 TrueDepth 相机系统特性，来对其 Face ID 做一个简单的介绍。

相比现在我们熟悉的 Touch ID，Face ID 在解锁要更加便捷。除此之外，人脸也代替了以往指纹的身份验证作用。

实际上，将人脸作为身份识别的背后，苹果运用了 3D 结构光技术，通过前置的 Infrared Camera 和 Dot Project 组件，能够快速扫描人的面部并在人脸表面形成 3 万个看不见的 IR Dot（类似于 3D 建模）。 

它可以支持设备在用户发型发生变化、带/摘了眼镜等等情况下，依旧能够正确识别你的脸并完成解锁。这也就解决了之前三星 S8 系列遇到的通过诸如照片之类的 2D 手段，就能够被攻破的尴尬，更加安全。

需要注意的是，为了更好的将收集到的数据进行分析，苹果在 A11 芯片中构建了神经网络，来为人脸识别提供了足够强大的计算能力，从而让面部录入和解锁的过程足够顺畅。

而不出意外的话，除了常规的配置升级，为了能够更好的支持 Face ID，全新 iPad Pro 也将搭载 A11 处理器（今年 6 月份推出的 10.5 英寸搭载的处理器为 A10X）。


想要在 iPad Pro 上体验 Face ID，或许还得等些日子

首先需要提醒的是，按照郭明錤的说法，只有高端的 iPad Pro 系列会新增 TrueDepth 相机系统。也就是说，你想要在平板电脑上体验到 Face ID，需要花更多的钱，来入手 iPad Pro。

另外，如果苹果决定将 TrueDepth 相机系统引入 iPad Pro，目前不确定的因素是相关元器件是否能够保证足够的供应量。早些时候郭明錤曾透漏，TrueDepth 相机可能是 iPhone X 提升产量的主要生产瓶颈。

考虑到 iPhone 之于苹果的重要性，如果出现相关元器件供货不足的情况，iPad Pro 为 iPhone X 让路的可能性极大。所以，可能最终下一代 iPad Pro 何时能够发布，还是要看 iPhone X 的「脸色」。
