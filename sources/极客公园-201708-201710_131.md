# 小米 Note 3 体验：不仅仅是一个「大号」小米 6

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652849430&idx=2&sn=937d39e503f72bafef32c9b380d219cb&chksm=7e6a38a0491db1b6fa121a314f682e35b9509698bf3c47a78605070cf670bee963bea6be54e5&scene=126&sessionid=1681311134#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652849430&idx=2&sn=937d39e503f72bafef32c9b380d219cb&chksm=7e6a38a0491db1b6fa121a314f682e35b9509698bf3c47a78605070cf670bee963bea6be54e5&scene=126&sessionid=1681311134#rd)

**摘要：更大但更轻薄的机身，颇为惊艳的人脸解锁，让小米 Note 3 不简单是一个「大号」的小米 6。**

9 月 11 日，在发布小米 MIX 2 的同时，小米还发布了一款由吴亦凡代言、主打线下的新品——小米 Note 3。

和采用新一代「全面屏」设计小米 MIX 2 相比，第一眼看上去，小米 Note 3 的亮点似乎不多。它的外观像是一个大一号的小米 6，不过骁龙 660 的配置要比小米 6 的骁龙 835 差了一个档次，售价上二者完全相同（6GB + 64GB 版定价 2499 元）。不考虑代言人的影响，似乎小半年以前发布的小米 6 要比 Note 3 更值得买。

不过很多时候，纸面参数是无法和体验划等号的。在真正使用了一段时间之后，小米 Note 3 却给了我不少惊喜。

  

## 手机大了，却更舒服

小米 Note 3 的设计语言和小米 6 没有太多区别，都是「正面 2.5D 玻璃 + 弧形金属中框 + 背部四曲面玻璃」，小米 Note 3 的变化主要有两处。

![](../Images/0ea481a5d644ec59e4e09efea41119f2.png)

第一是屏幕尺寸。

小米 6 的屏幕尺寸为 5.15 英寸，而 Note 3 为 5.5 英寸，这是一个目前市面上众多 2000—3000 档热门手机（尤其是在线下渠道）选择的屏幕尺寸。作为一款主打线下的产品，小米 Note 3 选择这个尺寸自然是合情合理的，至于和小米 6 的 5.15 英寸应该哪个好，就完全取决于用户的个人喜好了。显示效果上，小米 6 和 Note 3 也没太多区别，二者采用的都是 JDI 的 LCD 面板，分辨率均为 1080p，放在同价格档都是足够主流。

![](../Images/8f8b9884b4172fa4e0c5c910e309a383.png)

第二是中框。

小米 6 的中框为亮面不锈钢，而 Note 3 改成了喷砂处理的 7000 系铝合金，这有效降低了小米 Note 3 的机身重量。作为对比，小米 6 玻璃版的重量为 168 克，而小米 Note 3 在屏幕更大的情况下，整机重量却只有 163 克。

这两点加在一起，让小米 Note 3 在屏幕更大的情况下，反而拥有比小米 6 更加轻薄和舒适的手感。相比市面上大多数同价格档采用全金属机身或者双面 2.5D 玻璃的产品，小米 Note 3 的背面四曲面 3D 玻璃则让它多了几分圆润和精致。

  

## 骁龙 660：可能是第一个拥有「旗舰体验」的中端芯片

虽然在官方的产品介绍中，小米把骁龙 660 称作「高端处理器」，但大家也知道，在高通的移动 SoC 体系中，6 系列的定位最多可以说是「中高端」，即使是 6 系中最强的骁龙 660。

放在之前，这意味着搭载骁龙 660 的小米 Note 3 的性能评价会是「足够满足日常使用，但距离旗舰机尚有差距」，不过骁龙 660 是一个例外，事实上，这可能是第一款真正拥有「旗舰体验」的中端 SoC。

![](../Images/b472ace6691501951f40ba8d0ab71eca.png)

先来简单看看参数，骁龙 660 采用了 14 纳米 FinFET 工艺，CPU 部分为 8 核心设计，Kryo 260 架构，最高主频 2.2GHz，GPU 为 Adreno 512，Spectra 160 ISP，Hexagon 680 DSP，X12 LTE 基带。

从跑分上看，骁龙 660 的 CPU 性能介于骁龙 820/821 和骁龙 835 之间，GPU 性能逊色于骁龙 820/821，不过在功耗和发热上，采用全新架构的骁龙 660 相比骁龙 820/821 有一定优势。另外，在 ISP、DSP 等经常不被重视不过和手机体验相关很大的几个方面，骁龙 660 也达到或者接近了骁龙 820/821 的档次。至于闪存的问题，虽然骁龙 660 的确是支持 UFS，但似乎是设计上有一定的难度，目前为止，包括小米 Note 3 在内的所有用骁龙 660 的手机用的都是 eMMC。

综合来看，非要拍个名次的话，骁龙 660 虽说比不上骁龙 835，但整体水准已经不比上一代旗舰骁龙 820/821 逊色多少，特别是极限性能不太重要的日常使用中，功耗发热控制更好的骁龙 660 的表现甚至要更胜一筹。

在使用小米 Note 3 的过程中（MIUI 9，基于 Android 7.1.1），除了 NBA 2K17 这样的游戏画面还差点意思，我基本感觉不到小米 Note 3 和采用骁龙 835 的 MIX 2 的差距，至于王者荣耀这样的游戏，OPPO R11 已经证明了特殊优化后的骁龙 660 帧率可以比骁龙 835 更高更稳定，同款 SoC 的小米 Note 3 自然也没什么问题。

  

## 惊艳的人脸识别

可能和很多人一样，在得知小米 Note 3 支持人脸解锁功能后，我的第一个反应是不屑：没啥特殊传感器，完全指望前置摄像头的小米 Note 3 的人脸解锁成功率该能有多好？怎么可能来保证安全性？

不过在亲自体验了小米 Note 3 的人脸解锁功能之后，我第一个想到的形容词是惊艳。

![](../Images/902cdd3e2c6b797b34cdefd0fe611e7a.png)

小米 Note 3 的人脸录入非常简单，把脸对着手机一两秒就可以成功录入，不需要做任何动作。

在人脸解锁的速度上，小米 Note 3 表现得非常理想，按电源键点亮手机后，手机几乎立刻就能进入桌面，考虑到点亮屏幕后手机还需要一定的时间来打开前置摄像头，能实现这个解锁速度还是很不错的。

![](../Images/7b1890cc05c1c1206839bd0929668282.png)

更加难得是，小米 Note 3 对解锁时的角度要求比较低，即使解锁时人脸和手机的角度和录入时有一定的不同，只要角度差的不是很大，小米 Note 3 绝大多数时候依然可以实现「秒解」，这也是在我的体验过程中感觉到的小米 Note 3 相比三星 S8 的人脸解锁最大的优势。

值得一提的是，即使在弱光情况下，小米 Note 3 可以通过屏幕补光来进行人脸解锁，不至于到了弱光情况下就直接「抓瞎」，当然，受限于硬件限制，小米 Note 3 在弱光下解锁的速度和成功率都会有所下降。

在安全性上，虽然小米 Note 3 依然是基于 2D 的图像数据，但通过算法上的调整，小米 Note 3 可以对解锁对象进行判断，比如说在录入人脸数据时，使用手机屏幕上的自拍以及普通的照片是无法进行录入的，解锁时自然也无法用自拍照或照片来破解。此外，小米 Note 3 还可以识别眼睛的状态，只有睁开眼的时候才可以解锁，在闭眼时是无法解锁。

这些改进叠加在一起，让小米 Note 3 人脸识别的可用性有了明显的提升。对于那些安全性上没有特别高要求的用户，无论是识别速度还是识别的成功率，小米 Note 3 上人脸识别解锁手机的体验在大部分场景下已经可以媲美前置指纹了。在使用小米 Note 3 的过程中，我尝试不录入指纹完全依赖人脸解锁使用了一段时间，几乎没有感觉有什么不便。

当然，对于小米 Note 3 这样已经拥有了体验优秀的前置指纹的手机，人脸解锁的意义可能并没有很大，这个方案更大的意义是用在那些由于手机上下「额头」太窄导致没有位置使用前置指纹的手机上。

![](../Images/2b54348be4e68017f9c95be343cc1e49.png)

小米 Note 3 的人脸解锁体验之所以可以做得这么优秀，背后是旷视科技旗下的 Face++ 视觉服务平台，是基于深度学习的计算机视觉领域的发展为人脸识别算法带来的提升（又是一个被人工智能所影响和改变的领域）。

更加令人兴奋的是，由于小米 Note 3 的人脸解锁不需要任何额外的硬件成本（只需要一个传统的前置摄像头），只是需要在算法上进行接入和优化，理论上大部分现有机型也是可以通过软件升级来增加这种体验优秀的人脸解锁功能的。

除了小米 Note 3，在近期的开发版固件更新中，小米已经为小米 6 增加了人脸解锁功能，未来很可能会用到更多的机型中。

  

## AI 自拍、内置 NFC 模块

除了人脸解锁，小米 Note 3 还把相关的数据用在了自拍上。通过对人脸更加精确的分析，小米 Note 3 可以针对不同的性别和脸形，对人脸的不同部位进行针对性的美颜，实现更加优秀的自拍效果（小米把这个功能叫做「AI 自拍」）。至于具体的效果，根据来自女同事的反馈，似乎效果不错……

![](../Images/a5f2020f821f535b4771c54cd79aeb8a.png)

后置摄像头方面，小米 Note 3 采用了和小米 6 完全相同的硬件模组，主摄索尼 IMX 386，1200 万像素，f/1.8 光圈，四轴光学防抖，等效焦距 27 毫米，而副摄为等效焦距 52 毫米的「长焦」，1200 万像素，f/2.6 光圈，无光学防抖。

关于小米 Note 3 的后置相机，大家可以参考我们对[小米 6 的评测](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652846719&idx=1&sn=8f4c2c9bb8b581ee2ff2bb66b6d0a666&chksm=7e6a47c9491dcedf3c53d028278d1fc6508ab4993cc288d218838745228fe34c47111c0a4eed&scene=21#wechat_redirect)。简单来说是，主摄成像品质中规中矩，2500 档的主流水准，相比竞争对手的主要优势在于 52 毫米「长焦头」（准确来说应该是「标头」）带来的额外拍摄视角以及优秀的人像背景虚化效果。

除此之外，和很多小米手机一样，小米 Note 3 内置了红外，并且有 NFC 模块，可以在国内多个城市直接刷公交地铁卡。

![](../Images/99b857954990114519cc2dc4925fcd42.png)

另外，由于相比小米 6 的整机尺寸更大，小米 Note 3 的电池容量也达到了 3500 毫安时，支持高通 QC3.0 快速充电（USB-C 接口）。  

  

## 线下产品中的高性价比

小米 Note 3 提供了 6GB + 64GB 以及 6GB +128GB 两个存储版本可选，售价从 2499 元到 2999 元不等，考虑到购买难度、赠品以及促销（目前小米官网 Note 3 全线减 100 元）等因素，小米 Note 3 的实际价格要低于小米 6。

![](../Images/162c2d9d15ebece8560eaf52d83a110a.png)

不过相比起小米 6 主打的线上市场，作为一款拥有明星代言、主打拍照功能的产品，小米 Note 3 更大的市场是在线下。这样看的话，小米 Note 3 的定价还是颇有竞争力的。
