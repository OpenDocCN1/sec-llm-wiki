# 担心数据泄露？Google 计划用实体钥匙来保障你的账号安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652849430&idx=3&sn=54d2b05f2d880c122f997daf216541fe&chksm=7e6a38a0491db1b6c5bc3375d3067cc6e4f526fa7c526f73ab38c4d81e60da42ca405c463213&scene=126&sessionid=1681311134#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652849430&idx=3&sn=54d2b05f2d880c122f997daf216541fe&chksm=7e6a38a0491db1b6c5bc3375d3067cc6e4f526fa7c526f73ab38c4d81e60da42ca405c463213&scene=126&sessionid=1681311134#rd)

![](../Images/3c94bd931bf5d92af5e4a3a2ba85a101.png)

  

**摘要：Google 将在十月提供一项高级账号保护服务，用实体钥匙来改进原有的双重认证，这项服务将推广给政客、企业高管和其他重视账号安全的用户。**

在使用互联网服务时，保护账号安全绝对是最重要的一环，尤其是一些与财产、隐私相关的个人账号，这些信息如果被黑客盗取，后果不堪设想。对一些政客、企业高管来说，如何保证账号安全更是件头疼的事情，这些数据安全甚至能影响他们的整个职业生涯。

有消息称 Google 将在十月提供一项高级账号保护服务，将一些新的保护措施加到电子邮件等帐户上，也包括授权给第三方应用程序的访问数据。新的服务会用实体钥匙来改进原有的双重认证，Google 可能会将这项服务推广给政客、企业高管和其他重视账号安全的用户。

在去年的总统竞选中，希拉里的竞选主席 John Podesta 的 Gmail 邮件就曾遭到黑客入侵，民主党全国委员会的数据库信息也被泄露。上周美国国土安全部门通知 21 个州，他们的选举制度可能是黑客的攻击目标。这一系列的入侵都被认为是俄罗斯黑客进行的针对性攻击。

![](../Images/96093f2ce6aacff24e73df8abe2e466e.png)

为了防止账号被入侵，Google 开始研究新的账号安全措施，来保护这些敏感的数据。在 2014 年，Google 发布了一个 USB 安全密钥的协议，利用 USB 密钥来提高账号的安全性。它能够提升现有的安全措施，比如双重认证，让用户登录账户时使用 USB 设备来进行身份认证。当把 USB 设备插入到电脑后，密钥可以保护用户的 Gmail 和其他 Google 帐户。

![](../Images/f97cc639abc4246c7060ee4d19feec30.png)

除了实体的 USB 密钥，新的服务将增加一个新的实体钥匙，以提供更强大的保护。这项新服务将可以远程控制用户的 Gmail 和存储在 Google 云端硬盘中的文件，防止第三方程序访问其中的数据。

![](../Images/67ca08480868ae270c78aea1dff6d561.png)

虽然这项新的账号保护服务是面向一些特殊人群，但其实每个普通用户都应该对账号安全提起重视。从有针对性的黑客行为来讲，攻破大批普通账户要比攻破一个高级账户简单得多，不管是 Google、Twitter 还是 Facebook，普通账户也是黑客的攻击目标之一。在所有的网络行为都已经实名化的今天，在网络上泄露数据，就像生活中被偷窥一样可怕。

账号保护并没有完美的解决方案，对于普通用户来说，起码 Google 和 Apple 的账号都可以开启两步验证、双重验证，这已经可以防范大部分入侵。
