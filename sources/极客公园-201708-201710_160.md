# 一口气连发多款新品，亚马逊这是在展示智能语音助手的正确打开方式？

**摘要：从智能音箱找到语音助手正确打开方式的亚马逊，一定看到了更广阔的未来。**

北京时间今天凌晨，大洋彼岸的西雅图，一如既往如同家庭聚会般的发布会现场，亚马逊一口气带来多款新品，不仅仅是智能音箱产品线的进一步完善，更将其智能语音助手带到汽车上，扩展其更多可能性。

在这场不算盛大的发布会上，亚马逊却通过新品为我们展示出基于 Alexa 语音助手更酷的生活场景，有放在床头的「音箱闹钟」，也有可以进行游戏互动的「音箱游戏按钮」，当关联更多生活场景之后，亚马逊究竟下一步究竟想要做些什么？接下来，我们不妨来一起了解一下。

  

## Echo Plus：更强大的新一代 Echo 主力

Echo Plus 是之前的 Echo 进一步升级，尽管从外观看起来没有多大变化，但 Echo Plus 的升级类似于从 iPhone 7 到 iPhone 8，更多改变在于内部结构和全新的功能。

![](../Images/07bce1e2d6c74b97fffe19eda160a35d.png)Echo Plus 拥有新的扬声器架构，采用杜比音效，加入专用的 0.8 英寸高音单元和 2.5 英寸低音单元，这意味着它在客厅这样的大环境中拥有更好的声音表现。

如之前一样，Echo Plus 支持亚马逊在线音乐、Spotify 和 Pandora 等服务。在此之上，升级之后的系统还允许你通过搜索歌词/时间段的方式来搜索喜欢的歌曲。

Echo Plus 最大的变化，也是它最能代表未来趋势的升级在于全新的智能家居控制中心（Smart Home Hub），这是它最重要的升级。

当你拥有很多智能产品需要和 Echo Plus 联动时，只需要简单说一声：「Alexa, discover my devices」就能非常快速的进行连接配对，而之前的操作方法则是需要手动进行配对。简化流程之后，这项功能可以自动查看包括蓝牙、Wi-Fi 以及 ZigBee 网络在内的三种连接方式并与产品连接，这对于智能家居的接入更加方便。

不过，这项功能需要厂商介入到 Echo Plus 的 API 中，因为这项功能目前只有 Echo Plus 可以做到，所以重点在于开发者的配合。Echo Plus 售价 149.99 美元，相较于上一代产品发售时 179.99 美元的售价有所下降，作为亚马逊旗舰产品，Echo Plus 在功能上的扩展体现出对于智能家居方向的新思路。

  

## 新一代 Echo：更有质感的家庭控制中心

售价 99.99 美金起的新 Echo 是本次发布会上最「多变」的产品。亚马逊为这款产品赋予五种不同风格的设计，包括木制/织物/金属在内的不同材质，以及黑色/白色/灰色在内的不同颜色的，都给不同喜好的用户提供了更多选择。

![](../Images/993cda8e4eba215532918410aa50c74a.png)

但这一举动很「反亚马逊」，按照其过去风格，很少会在外观设计和颜色上花费这样的心思，在低价产品+会员服务的组合拳之下，我们过去看到的亚马逊畅销产品，如 Kindle、Echo 等，都尽量避免风格多样化，一方面，这更便于产品生产和销售，另一方面，也更利于产品的升级与维护。但这一不同寻常的举动预示着亚马逊要开拓更多家庭的决心。

Echo 的大小介于 Echo Dot 和 Echo Plus 之间，价格也介于二者之间，尽管风格多变，但顶部仍然有 LED 灯以及传统按键的设计，所以将它看作微缩版 Echo 也不为过。加入 0.6 英寸高音单元和 2.5 英寸低音单元，同样的双扬声器配置，在客厅内能够保证其声音品质。

值得注意的是，不同外壳材质的 Echo 售价也不相同，织物材质的 Echo 售价 99.99 美金，木材以及金属版本的售价增加到 119.99 美金，但外媒上周之后称木材手感并没有织物那样舒服。

  

## Echo Spot：像闹钟的 Echo Show

本次发布会上最可爱的产品，非 Echo Spot 莫属，这不但是因为它圆润迷你的造型，更是因为它是本次发布中唯一带屏幕的智能音箱。

![](../Images/8f3a018dc8e02b4118c3b29fcdf63fb5.png)

说起带屏幕的智能音箱，大家能想到的是在今年早些时候发布的 Echo Show 产品，但 Echo Show 过高的价格（229.99 美金），以及稍大的体积并非在所有场合都适合，因此 Echo Spot 可以看成对于 Echo Show 的补充。

体积变小之后，相应的屏幕也从 Echo Show 的 7 寸矩形变为 2.5 英寸圆形，但屏幕在功能上依然和 Echo Show 保持一致，不但支持触控板交互，也能通过语音交互方式搜索喜欢的视频内容，不过由于尺寸变小，加上顶部的前置摄像头，因此更适合进行视频通话。

机身顶部依然有音量控制按键和静音键。419g 的机身重量也显得非常方便小巧。由于内置不同风格的时钟表盘，因此把它放在床头当作闹钟也非常好用。

从外媒现场上手看，Echo Spot 屏幕虽然较小，但可视角度不错。发布会现场还演示了用这个小屏幕连接到第三方智能摄像头，用来监控家庭情况的功能。设想一下，在家里宝宝睡觉的时候，用这样一个小小的智能音箱，远程就可以看到宝宝的情况，的确非常方便。

Echo Spot 是一款与众不同的智能音箱，它延续了 Echo Show 屏幕交互的扩展性，也加入了便携性，说它是带屏幕的 Echo Dot 也不为过，129.99 美元的售价看起来似乎有点贵，但从众多媒体的上手和现场使用来看，大家还是很喜欢这台设备的。

  

## Fire TV：更高清更智能

支持 4K Ultra HD 和 HDR 的全新 Fire TV 显然想要在视频领域进一步扩展，所以为它加入 Alexa 语音控制功能算得上如虎添翼。

![](../Images/e587ab8b55c4622d4cea08b0f7e89fc2.png)

利用语音控制功能，用户可以搜索包含 Netflix、Prime Video、YouTube、Hulu、HBO、SHOWTIME 灯在内的数以百万计的视频内容。杜比音效加入之后，你还可以用来直接播放喜欢的音乐。当然，一切的操作会通过遥控器实现，按下遥控器上的语音按钮，就能点播喜欢的资源。  

加入 Alexa 之后，你还可以通过 Fire TV 控制家里的各种智能家居，这意味着 Echo 产品上的功能也被搬到电视上，Alexa 变得无处不在，并可以做更多事情，69.99 美元的售价显然也会吸引不少用户

  

## Echo Connnect 和 Echo Button：智能音箱的周边配件

![](../Images/1549c16ab86412e6db8af9fff9ce485b.png)

Echo Nonnect 这款硬件能帮助用户在 Echo 上拨打电话，这一功能可以配合所有在售的 Echo 智能音箱产品，帮助用户进行网络通话服务，从通讯功能切入来满足用户的刚性需求，对于增加用户使用粘性会有更重要的作用，显然亚马逊也希望进一步增加产品的通讯属性，34.99 美金的价格也让其具有性价比。

![](../Images/c1197de83f3ce7d97afce5e18a80cf87.png)

外形看起来像曲棍球一般的 Echo Button 是配合 Echo 智能音箱系列出品的小玩具，这个会发光的设备可以玩一些小游戏，它的交互方式就是按下之后会亮起，在 Alexa 自带的益智游戏中，可以充当交互工具，20 美金一对的价格看起来会是给孩子们准备的道具。

  

## Alexa：进入车内和你交互

作为发布会上讲的不多但却让人憧憬的一点是，Alexa 会在明年开始出现在宝马汽车当中，它可以被加入到仪表盘当中，并且在开车时直接使用。

![](../Images/63f7de752f912c1172d0d70292c3f380.png)

想象一下，在车内的语音交互场景将像在家里一样智能并且方便，你喜欢收听的音乐会从室内延伸到车内，更重要的是，以后在车内，就能连接家里的智能设备，比如直接开空调，打开窗帘或者关闭微波炉等一系列操作，不必局限在家里，这将 Alexa 助手的应用延伸到更广的维度，而且在车内，语音交互比触控显得更自然。

联想到之前国内包括出门问问、奇虎 360 等公司推出搭载车内智能语音助手的智能后视镜，以及搭载百度度秘的智能汽车，Alexa 进入汽车领域并不让人吃惊，但它或许会像 Echo 一样改变人们驾驶方式。毕竟，在经验积累足够长时间之后，亚马逊这一举动会带来的影响可能远超我们想象。  

  

## 无处不在的语音助手，展示出亚马逊的野心

从客厅到卧室，从家中到车内，显然亚马逊的野心不单单是一款智能音箱那样简单，这家公司正在把语音助手的能力应用于更复杂场景的体验上，并进一步增强这种交互方式的粘性。

![](../Images/7ab29a43dd3dd7fe9107b8d6b725aed0.png)

如同触控交互从智能手机、平板电脑扩展到更广的大屏智能设备上一样，从智能音箱出手，以智能语音助手 Alexa 为载体的设备正在培养用户习以为常的交互习惯，亚马逊最终要实现的目标，是让语音交互变得像触控交互一样自然，一样多元，在不同环境中都能给人提供帮助的交互形式。

经过几年的沉淀和积累，Alexa 平台上上万种技能已经能够帮助亚马逊扩展其场景，而在不同智能设备生产商的推动下，亚马逊也有能力将身边的一切都集合在一起，用语音方式连接一切，这种能力如同手机上通过触控操作一切一样，正在变得更自然，也更平常。

当然，摆在亚马逊面前的路仍然具有挑战。在发布会前一天，亚马逊 Echo Show 官方表示因为不知道的原因，Google 停止向 Echo Show 提供 YouTube 视频服务，而亚马逊 Echo Show 的视频功能一直被视为 Google Chromecast 的竞争对手，失去 YouTube 上海量的资源，亚马逊要怎样在 Echo Spot 这样的产品上巩固优势，又会是未知数。

喜欢《星际迷航》的贝索斯，想要将 Alexa 训练成电影中那个随叫随到的、善良、博识的助手，这一切在 3 年多的时间里似乎越来越成为现实。我们在大洋彼岸见证了这个不起眼的音箱从不被看好到逆袭称霸的故事，现在，亚马逊的野心更进一步，更显其战略的宏大，但苹果、Google 这些老对手也开始奋起直追，究竟鹿死谁手，也许战争号角才刚刚吹响。
