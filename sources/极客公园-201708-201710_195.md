# 亚马逊入局，眼镜会成为语音助手的必争之地吗？

**摘要：亚马逊的智能眼镜本质是可移动的智能音箱/耳机，不过眼镜是不是语音助手的好载体还有待检验。**

近日，金融时报援引一位业内人士，称亚马逊目前正在研发一款智能眼镜产品，这款可穿戴产品配备骨传导技术，内置亚马逊语音助手 Alexa，可以在不用耳机的情况下让用户与 Alexa 进行交互。

说到智能眼镜，谷歌在几年前推出的 Google Glass 的失败依然让硅谷十分警醒，苹果和微软虽然有计划但均未向外界公布。而亚马逊此次涉足智能眼镜，显然不是想重蹈谷歌的覆辙，其本质还是想借助眼镜来推广自己的 Alexa。对于没有移动设备的亚马逊来说，眼镜能否成为其语音助手的合适载体，还需要市场进行检验。

  

## 没有摄像头的谷歌眼镜？

根据消息人士透露，亚马逊正在研发的智能眼镜会采用骨传导技术，在不用耳机的情况下，将声音传送给用户，究竟是什么声音，答案是来自 Alexa 的声音。据悉，亚马逊希望将其智能助手 Alexa 内置到智能眼镜产品中。

根据报道，亚马逊研发中的这款智能眼镜产品，可能不会走先行者谷歌眼镜的路数，也就是说不会含有显示和摄像头模块，后者也是当年的谷歌眼镜栽跟头的原因，摄像头的加入让注重隐私的欧美人士认为谷歌眼镜是一个偷拍设备。据悉，由于不含有摄像头等元件，亚马逊的智能眼镜会更像普通眼镜，同时可能会有更大的电池。

在使用上层面上，亚马逊的智能眼镜依然需要通过无线连接到移动设备，也就是手机上进行使用。从这个意义上来说，亚马逊的智能眼镜的功效可能更像耳机，而非眼镜。而智能耳机，则可能是智能音箱之后，另一个「被智能」的设备。

  

## 眼镜是语音助手的新载体？

近日，国内耳机厂商 FIIL 发布新品耳机，后者与百度的语音系统 Duer OS 合作，能够实现智能搜索等功能。上个月底，有开发者在谷歌手机应用代码中发现神秘项目 Project Bisto，其代码的说明明确显示「你的耳机内置 Google Assistant」，这也使得谷歌的智能耳机项目因此被曝光。苹果公司的无线耳机 AirPods，已经能够使用 Siri 功能，未来也完全有希望成为内置选项。

相对于拥有安卓的谷歌和拥有 iOS 的苹果，亚马逊目前在硬件端仅有 Echo 可以说有些竞争力，公司也围绕 Echo 推出了 dot、show 等一系列音箱类产品。即便卖上 2000 万台，相对于竞争对手的手机数量仍属小众。而搭载了 Alexa 的智能眼镜，其本质上仍属于 Echo 的分支产品。至于亚马逊的智能眼镜未来会不会成为苹果和微软的 AR 眼镜的竞品，目前我们还不清楚，但有一点可以肯定的是，亚马逊智能眼镜的重心仍是推广 Alexa。不过，眼镜是否是语音助手的合适形式，还有待检验。 ■
