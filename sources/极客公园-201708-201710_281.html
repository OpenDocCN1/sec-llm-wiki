摘要：文末有 iOS 11 最新壁纸打包福利。


美国当地时间 8 日晚上，本该在下周发布会之后推送给开发者的 iOS 11 最终测试（GM）版固件遭到了泄露，曝光了不少之前版本中没有的功能和信息，其中包括新加入的 Face ID 功能、LTE 版新款 Apple Watch 以及 AirPods 升级等等。

话不多说，下面是极客公园整理出的爆料信息。


Face ID 功能坐实

之前极客公园对苹果是否会在 iPhone 8 上取消 home 键进行了报道，而 iOS 11 GM 固件中的信息也证实了我们的推论：苹果希望使用被称为 Face ID 的面部识别功能来代替原先的指纹识别 Touch ID。

据拿到泄露固件的外媒 9to5Mac 爆料，Face ID 的设置过程与 Touch ID 非常相似，用户同样需要设置密码以防 Face ID 出现不可用的情况，一旦创建成功，iOS 就会引导用户识别其面部信息并加载到系统中。

最初，用户需要轻缓地移动头部，「用绕圈的方式，眼睛看着屏幕」，「如果您的面部全角度都被捕捉，Face ID 的表现会更好」。不同于 Touch ID，就算 Face ID 暂时不能完成全角度的扫描，用户也可以退出稍后继续。两次扫描之后，整个过程才算完成。

扫描时头部操作示范图

在设置 Face ID 时，iPhone 会提供诸如「保持您的 iPhone 距离您的面部 10-20 英寸」或者「头部向上/下/左/右倾斜」等文字提示，同样它还能检测到用户的面部被遮挡、不在摄像范围内、或者在设置过程中出现了另一张脸。

另外，Face ID 的设置界面会与 Touch ID 类似，被苹果命名为「Face ID 与密码」。同时 9to5Mac 在研究该固件的字符串时发现有名为「局部捕捉」的选项，也就是说，用户可以在没有完成「全角度」扫描的时候使用 Face ID。

当前设置中的 Touch ID 与密码

更加有趣的是，Face ID 还可以检测出用户是否在看手机，「您在浏览屏幕时注意力是可检测到的。当注意力被检测到时，iPhone 不会息屏」。

由此看来这是一个相对比较「智能」的功能，在新 iPhone 上也许再也不会出现好端端看着屏幕时手机息屏的现象了。


LTE 版 Apple Watch Series 3 曝光

Apple Watch 与 iPhone 相连接时需要使用手机中的 Watch 应用，而外媒发现在 iOS 11 GM 版中，Watch 应用里滚动切换的 Apple Watch 预览图中有一个比较特别的 Apple Watch。 这张图上显示的 Apple Watch 颜色为深空灰，表冠为红色，具有较高的辨识度。爆料截图

在这款从未现身过的 Apple Watch 上，我们可以看到表盘中间有一个 iPhone 上的信号格标志，同时 9to5Mac 表示此前曝光的新 Apple Watch 控制界面中也有同样的标志，据此，有猜测称这款手表吸引人眼球的红色表冠其实是嵌入了 LTE 天线，两年前 Tim Cook 就被抓拍到使用带有红色表冠的 Apple Watch，但是一直没有推出同样的产品，其原因可能是这在当时只是一款试验品。

此前的设置中心爆料图

同时截图上还能看到与手机连接和导航的标识，进一步增加了这块手表具有通话功能的可能性。

📹 https://v.qq.com/iframe/preview.html?vid=s05488fw9dw&width=500&height=375&auto=0

另外，9to5Mac 称他们在分析泄露固件包的代码时发现，新 Apple Watch 可以在离开 iPhone 的情况下接打电话，但这需要从运营商层面对 iPhone 和 Apple Watch 进行绑定，二者共享同一号码，用户则需要每月多支付一定的费用。

不过一些字符串表明，苹果为这款手表准备了促销计划，这意味着绑定套餐在短时间内会比较「便宜」，另外还有信息显示手表在订购时就可以直接绑定运营商，但手表是否会因此而被「上锁」则不得而知。

可惜的是，这项功能需要与运营商达成合作，但在国内，此前具有 LTE 功能的国际品牌手表都是采取直接屏蔽掉该功能的做法，而我们也尚未了解到三大运营商有与苹果协商的动作，所以，大家保持期待但也别抱有太大的希望吧。


AirPods 小幅升级

泄露文件还曝出了 AirPods 会有小幅升级的信息。

从下面的动图可以看到，虽然 AirPods 耳机本身外观上并没有什么变化，但是耳机盒上出现了类似于充电指示灯的图案，苹果这么做可能是想方便用户不打开盖子就能够看到充电状态。

爆料图

不过从版本号来看，这款耳机可能被命名为 AirPods1,2，因此并不会有较大幅度的升级。


16 款全新静态壁纸

从外媒安装在 iPhone 7 Plus 上的版本来看，这次 iOS 11 上会新增 16 款新壁纸，包括 6 个苹果 6 色复古标志 logo 的壁纸，6 个花朵图案壁纸和三个太空壁纸，最后，还有一款特别为 OLED 屏幕准备的全黑壁纸。

遗憾的是，动态壁纸并没有得到更新。

六色 logo 壁纸和纯黑壁纸


相机新增人像照明（Portrait Lighting）功能

据报道，这项新功能是通过模拟不同的照明效果，来增强 iPhone 的人像模式，从而达到类似数码单反相机的拍照效果。

从爆料文件来看，人像照明功能支持轮廓光、自然光、舞台灯光 、摄影室灯光等等，简单地判断下，这个功能应该与拍照时的闪光灯有关。


True Tone

OLED 版 iPhone 将会和 iPad Pro 一样装备 True Tone 功能，它可以根据设备所处的光线环境调整屏幕白平衡，以减少人眼在长时间浏览屏幕时的不适感。iPad Pro 上的 True Tone 设置

至于屏幕分辨率，从这份固件的资料来看周年纪念版 iPhone 应该是 1125*2436 的分辨率。


Home 键的替代品

此前有爆料称周年纪念版的 iPhone 会取消 home 键使用手势操作顶替，这次的固件泄露也让这则消息坐实。爆料图，注意底部横条

另外，还有线索表明电源键将会新增一些代替 home 键的功能，比如双击打开 Apple Pay，长按唤醒 Siri 等等，同时在辅助功能的设置界面，用户还可以调整电源键（文件中称边缘键 Side button）的按键速度，用以打开「键入以使用 Siri」的功能，或者用在 Face ID 上，「在息屏前检查你是否在浏览 iPhone，解锁、限制警报音量」等。

除了以上这些新功能和信息的爆料以外，这套固件中还确认了周年纪念版 iPhone 的「刘海」外形。

刘海状态下，时间显示移至屏幕左端

包括一个 SOS 功能的介绍图。

同时按住屏幕两边的案件激活 SOS 功能

还有一些 3D 的动态 emoji，他们可以跟踪用户的表情，并根据声音变换表现形态。
