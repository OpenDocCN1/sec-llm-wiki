摘要：微软推出一款名叫 Mixer Create 的视频直播应用，支持联合直播，最多支持 4 人。


移动直播，尤其是手机直播已经成为一种新的时尚，各类直播平台都在大力的发展、完善手机直播功能，但目前国内外的直播平台很少能够支持多人同时直播，同时直播多数以连麦的形式进行。而在近日，微软推出了一款名叫 Mixer Create 的应用很好的解决了这个问题，实现了多人在线的同时直播。

下载地址见文末


支持 4 人同时直播

与其他移动端的游戏直播应用不用的是，Mixer Create 支持联合直播，最多支持 4 人，Mixer Create 可将自四位主播的游戏内容整合至同一画面。但是目前，邀请共同直播这一功能仅向部分使用者开放，而微软也已经承诺将会在未来的 App 更新中向所有用户开放此功能，也就意味着用户可以邀请他人加入直播，同时也可以接受或者拒绝别人发起的共同直播邀请。

图片来源：GIPHY（http://t.cn/RNWidcC）

在直播当中，Mixer Create 的传讯功能使得直播可以通过频道的聊天界面与观众进行互动。而除了直播手游之外，使用 Mixer Create 也可进行非游戏内容的直播。

微软 Mixer 直播平台不仅可以提供手机用户通过 Mixer Create App 来进行直播，也可整合来自电脑、Xbox 的直播画面，这在适用性上很具弹性。

目前，Mixer Create 在 iOS 和 Android 平台都可进行下载，但需要注意的一点是，Mixer Create 适用于 Android 平台的所有游戏，但在 iOS 平台上功能有限，微软表示，「在 iPhone 上，只有激活苹果 ReplayKit 功能的游戏才支持使用 Mixer Create。」


视频直播仍可分得一杯羹

虽然微软在游戏方面拥有着其他公司所羡慕的优势，但其在视频直播市场的吸引力依然落后于 Twitch 和 YouTube。根据 Streamlabs 最近的一项研究，目前 Twitch 占据着最大的视频直播市场，领先于排在第二位的 YouTube。而微软的 Mixer、Periscope 和 Facebook Live 只占据视频直播市场份额的一小部分。

图片来源：网络（http://t.cn/RNW6Zq4）

而在前段时间，Mixer 最大的竞争对手 Twitch 对其直播应用进行了升级，支持主播通过移动设备进行直播，且 Twitch 也试图开拓非游戏领域的直播，加入更多的其他内容。作为行业领头羊的 Twitch 都在不断地升级，想要在视频直播市场多分得一杯羹的 Mixer 没有理由不进行改变，这是微软推出 Mixer Create App 的原因之一。

此外在视频直播兴起的过程中，「游戏+直播」的模式为游戏行业注入了新鲜的血液。而在视频直播的类别中，游戏直播无疑能够带来忠诚度较高的用户，也在一定程度上成为手游宣传的新方式。游戏与直播是互助的关系，游戏借助于直播宣传，直播依赖游戏吸粉，「游戏+直播」这种形式，可能带动游戏和视频直播的同时增长，这一方面也使得微软对 Mixer Create 进行了升级。
