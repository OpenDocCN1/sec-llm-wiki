# Magic Leap 被泄露专利图片，产品年内很可能对外公开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652848690&idx=1&sn=b13948a19743ca117f28877c33cb9d63&chksm=7e6a3f84491db692f3c83f6cd1c545dfaecf1b9064e85af7298358df8082e2cac7cefe51e122&scene=126&sessionid=1681311159#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652848690&idx=1&sn=b13948a19743ca117f28877c33cb9d63&chksm=7e6a3f84491db692f3c83f6cd1c545dfaecf1b9064e85af7298358df8082e2cac7cefe51e122&scene=126&sessionid=1681311159#rd)

**摘要：消息人士透露，曝光的图片和实际机器接近，但不完全一致。而 Magic Leap 的产品则可能于年底对外公开。**

  

作为创业公司，在没有拿出产品的情况下融资达 45 亿美元，全硅谷甚至全世界大概只有 Magic Leap 公司才办得到。而这种神秘感也让很多人质疑这个公司的技术是不是「骗人的」。

不过，有外国媒体近日在网络曝光了来自 Magic Leap 公司于 2015 年提交的专利申请图片，其上展示的是一个看起来颇为复杂的眼镜设备。消息人士称 Magic Leap 或将于年底展示公司的真正产品，对于那些质疑过 Magic Leap 的从业者则有「被打脸」的危险。

从曝光的图片来看，这款眼镜的景框两边各有两个摄像头类似的传感器。眼镜分为两层镜片，一个外层镜片，和一个更小巧一些的内层镜片。内容镜片下方可以看到两个感应器，看起来颇像眼球追踪传感器。在两个镜腿下方各有一个接口，通过线缆和其他设备连接在一起。

![](../Images/e2d05f3a535690d60da0f8687af9cae8.png)

对于媒体曝光的专利图片，Magic Leap 公司的发言人 Julia Gaynor 否认这是公司的产品。「我们提交了很多专利，而专利的审核需要很长时间，所以这个并非我们的产品。」Julia 说道。

一些体验过 Magic Leap 设备的人士也提供信息，表示其公司的设备要比图片中的眼镜更大更厚重一些。另外，Magic Leap 的设备两边各有 1 个摄像头，而非图片显示的两个，同时在鼻夹的位置有深度感知传感器。「虽然 Magic Leap 的设备比现在的 VR 头显小一些，但是要比普通眼镜笨重得多。」消息人士透露道，相对来说，Magic Leap 公司的设备更像一个泳镜，不过镜片要大很多，镜腿也更粗大。

作为国内极少数体验过 Magic Leap 在研产品的人，极客公园创始人兼总裁张鹏，曾经于今年 4 月受到 Magic leap 创始人 Rony Abovitz 的邀请，在 Magic Leap 总部体验了其最新的原型机。张鹏表示不能透露具体产品细节，他确认此次曝光的专利图和 Magic Leap 的原型机并不完全一致，但大致方向接近。

在体验方面，张鹏根据自己的体验认为 Magic Leap 产品要比目前市面上的 VR 和 AR 设备要「好很多」。他透露，如果进展顺利，Magic Leap 可能将在年底公开其产品。而此前一直质疑 Magic Leap 是「骗子公司」的人士，很可能「被打脸」。

![](../Images/301675655d2d1012ecd0fea76518a389.png)  

另外，外媒信息透露 Magic Leap 的眼镜设备只是起到显示的作用，数据处理和电源都需要连接额外的设备。一台包含 GPU 和 CPU 的迷你主机，大小类似一台 CD 播放器，用来处理数据和提供电源，而迷你主机则可以挂在腰带上。这些信息也得到了极客公园创始人张鹏的确认。

从 2015 年曝光视频，在科技行业引发激烈讨论的 Magic Leap 公司，近两年并没有透露太多和产品相关的信息，这也使得媒体和业内人士对其公司的技术水平和诚信产生质疑。

不少业内人士认为，公司展示的混合现实视频，更多来自 CG 特效而非实际产品体验。而在 Magic Leap 缺席时，微软的 HoloLens、Meta 公司的 Meta 2 头盔相继面市，凭借光波导和自由曲面等技术，为用户展现混合现实的初级状态。

![](../Images/33a4a57a43fd43996e3cfc640ad213aa.png)

从技术层面来说，Magic Leap 的光场技术要比 HoloLens 和 Meta 的方案更先进，其创始人 Rony Abovitz 研发的「光场芯片」也十分神秘。和其他公司的AR或者 MR 方案不同，Magic Leap 公司的产品除了电子和光学元素，同时还和神经科学相关，其产品终极目标是将人脑变成渲染图像的「GPU」。

从 2011 年创立至今，Magic Leap 已经拿到来自谷歌、阿里巴巴等科技巨头和顶级风投的 45 亿美元融资。从巨量资本押注的层面来看，Magic Leap 公司正在研发的技术必然有可能带来混合现实显示和人机交互的重大变革。当然，Magic Leap 是否能实现这样一个宏大的愿景，也十分值得人们关注。
