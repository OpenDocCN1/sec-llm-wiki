# 红米 Note 5A 图赏：面向线下渠道的多彩「百元机」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652848633&idx=2&sn=49ad8d1e9d54fff140ec3a76d1bffe24&chksm=7e6a3c4f491db559c2cc3fa312b32a79584cf16cb6596c619ebcc99cde4de567ab98aa1b293b&scene=126&sessionid=1681311159#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652848633&idx=2&sn=49ad8d1e9d54fff140ec3a76d1bffe24&chksm=7e6a3c4f491db559c2cc3fa312b32a79584cf16cb6596c619ebcc99cde4de567ab98aa1b293b&scene=126&sessionid=1681311159#rd)

![](../Images/1e1f2ed165fe23634f2d52dbb58e98e2.png)

  

**摘要：作为一台定位于中低端的机型，红米 Note 5A 不算出彩，但 699 元的起步价，确实颇具吸引力。**

  

8 月 21 日，小米发布了一款手机新品——红米 Note 5A。和小米之前推出的小米手机 5X 类似，红米 Note 5A 同样偏重线下渠道，起售价只有 699 元。

![](../Images/0f00dad9fbfd7731ba11bbf3b04f8a23.png)

这次红米 Note 5A 分为标准版以及高配版两个不同的版本，其中标准版搭载了骁龙 425 处理器、2GB 运行内存、16GB 机身存储；高配版搭载骁龙 435 处理器、提供 3GB + 32GB 以及 4GB + 64GB 两种存储规格，电池容量均为 3080mAh。

![](../Images/0c4cbfb6c31032965f8597747db8d867.png)

机身配色部分，红米 Note 5A 提供了香槟金、铂银灰以及玫瑰金三种可选项，我们拿到的这台为铂银灰版本。

![](../Images/df2df05cb236be470a7f4271f3df6305.png)

铂银灰版本机身正面面板为黑色，而其它两种版本则采用了白色前面板。

![](../Images/e7984ce4b13adbaa297312361b2e2c70.png)

红米 Note 5A 采用了一块 5.5 英寸的 LCD 屏幕，分辨率为 1280 x 720。

![](../Images/df986561b489456331510f99735b9486.png)

需要提醒的是，标准版与高配版的前置摄像头规格有所不同。其中标准版本采用了一颗 500 万像素的前置摄像头；高配版本前置摄像头为 1300 万像素，同时多了一颗柔光灯。

![](../Images/61d04380cd7501115e9c29ba12974577.png)

另外，红米 Note5A 的标准版没有配备指纹识别模块，而高配版采用了后置指纹。

![](../Images/2c5244c6438c28d417e13c4dbe22d8d7.png)

支持双 Nano-SIM 卡以及 Micro SD 卡，三张卡可以同时使用。

![](../Images/ada0de0a5bcfe5e91e903f21da5342ff.png)

3.5mm 耳机接口位于机身顶部，另外保留了红外功能。

![](../Images/279058577e630fb382107cac87f70eb0.png)

红米 Note 5A 的底部为 Micro USB 接口。

![](../Images/51cc700e38659cfe8a460129622baaab.png)

音量键以及电源键均位于机身右侧。

![](../Images/364e5f5f4547b8c7e078fc4a2a33e7ba.png)

红米 Note 5A 机身背部做成了类似金属机身的三段式设计，不过其实它的表面材质是塑料，只是做了仿金属材质的处理，表面的工艺处理得不错。

![](../Images/12f51105ff409079bee7cdb9786d5801.png)

红米 Note 5A 机身三围为 153 × 76.2 × 7.7mm，标准版重量为 150g，高配版为 153g。对于一款 5.5 英寸屏幕的手机，红米 Note 5A 的重量算是很轻了，作为对比，小米 5X 的重量为 165g。

![](../Images/b78396f9c4e0916fd2d5fef973958a3e.png)

另外，由于它的背部做了一定的弧度处理，所以整体握持感表现还不错。

![](../Images/10836df0ef8680c45f5c9e89755ab569.png)

标准版与高配版后置摄像头一致，均为 1300 万像素，f/2.2 光圈，支持 PDAF 相位对焦。

![](../Images/81805f69d6d27ace3ee04de63696c2a6.png)

最后来说下售价。标准版 2GB + 16GB 售价 699 元；高配版 3GB + 32GB 售价 899 元，4GB + 64GB 售价 1199 元。

![](../Images/59d876a954f7836f63e84b1fe9663136.png)

总体来说，作为一款定位入门的「百元机」，红米 Note 5A 自身的亮点不多，但最低 699 元定价让红米 Note 5A 在线下渠道拥有不错的性价比。
