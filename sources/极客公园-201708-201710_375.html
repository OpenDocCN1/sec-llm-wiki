Tesla 的「共享」野心，挑起了人们和 Uber 之间的战争

摘要：硬件上透露出的只是「共享」的野心，Tesla 更希望实现的也许是新一代消费观念的转变。


「你买了辆汽车，当你不用车的时候，你可以「共享」这辆车为你去赚钱。」

去年 10 月，Tesla CEO Musk 曾公布，特斯拉将会推出自己名为「Tesla Network」的打车服务，类似 Uber 和 Lyft 的汽车共享计划。

Musk 称，该计划基于 Tesla 网络运作，可使车主根据需要分享自己爱车。另外，该项计划不仅可以为 Tesla 带来收入，更可以为车主带来更大利润。但 Tesla 同时强调，使用 Tesla 自动驾驶功能可以为家人和朋友提供共乘或叫车服务，但出于营利目的的类似做法则必须通过「Tesla Network」。

对于 Tesla 在抢夺 Uber 市场、不务正业、攻击 Uber 这样的批评言论，Musk 也给予了反击：「这看起来像是 Tesla 和 Uber 之间的斗争，但实际是人们和 Uber 之间的斗争。」

这一句话，深藏功与名。为什么这么说，我们接着往下看。

大半年之后，2017 年 7 月，Tesla 在弗里蒙特工厂举办了首批的 Model 3 交付活动，活动上 Musk 依旧只是简单的介绍了 Model 3 的一些硬件亮点，电池版本信息、安全性、简洁的中控大屏、「直升机视角天窗」等等。

但其实，Model 3 的身上有非常多的小亮点并没有被 Musk 公布，而是在之后的体验才被大家所了解，而这些却是让 Model 3 更具想像力非常关键的因素。


「完全自动驾驶硬件」之后的「完全共享汽车硬件」？

最先爆出的就是车辆的解锁方式，Model 3 已经准备抛弃「车钥匙」这样的东西，转而使用手机通过蓝牙来解锁汽车。

其实打开 Tesla 的 iPhone 和 Android 应用程序已经可以用来解锁和启动 Model S 和 X 型，但是「车钥匙」一直被认为是解锁汽车最方便的主要装置。

而现在 Model 3 用 App 解锁，它希望这和你的之前「车钥匙」体验一样，蓝牙连接到手机，在你接近时自动解锁门，而不是打开手机、打开 App、点击开锁，这样的繁琐。所以常说「细节决定成败」，而这就是那些细节。

当然我们难免会遇到手机没电或者死机，所以备用方案 Tesla 提供了带有 NFC 芯片的钥匙卡，只需要在 B 柱上滑动卡片，就可以解锁车门。

除了细节的体验好，这个更重要的一个「应用场景」就是「共享」，这意味着你可以分享你的「电子车钥匙」给别人，方便其他用户使用。

而这只是第一步，发布 Model 3 量产版两天后，一位 Tesla 爱好者 Jason Hughes 发现了后视镜上这个面向驾驶员的摄像头。官方的内饰图片上也同样拥有这个摄像头，Tesla 也向 Electrek 网站证实，Model 3 配备了这个相机，但目前尚未启用。

有专家曾表示，L3 级自主驾驶需要一个面向驾驶员的摄像头来监控驾驶员的参与度。目前在搭载 Super Cruise 自动驾驶技术的凯迪拉克 CT6 上已经有这样的应用。

同时，像大陆集团、博世也在研发这样的技术，英伟达的「黄教主」也在 CES 开幕主题演讲中推出了 NVIDIA AI Co-Pilot，在视觉上，Co-pilot 能够通过车载摄像头监测驾驶员与其行为。

这虽然只是说明了 Tesla 安装这个新硬件的合理，而更重要的一点是，在「共享」功能的时候，这项功能还可以帮助 Tesla 来确认驾驶者的身份。

而接下里说的这个功能，是最近 Elon Musk 自己爆料的，一个「基于云的驱动程序配置系统」，翻译过来就是「你的云端账户」。以前座椅调整、后视镜调整、甚至是一些驾驶习惯，都是存储在你的本地的账户内，而现在他们将存储在云端，这意味着你之后开任何一辆 Model 3 的时候都是「一键」甚至是自动变成「你的 Tesla」，一切都会变成你熟悉的设置和配置，几乎没有体验上的差异。而这和 Faraday Future 在今年 CES 发布的「FF 账户」功能是一个道理。

当面对「共享」这件事来说，这个功能无疑是体验上的革新，省去了开「共享汽车」前的那些繁琐设置，同时也省去了「陌生感」。而这样的例子还很多，例如在需要人驾驶阶段的共享，车身周围的摄像头也能够让现在「汽车分时租赁」头疼的事故的责任判定迎刃而解。

最后，对于实现「共享」最大的「助攻」当然是 Tesla 说了很久的自动驾驶。

「当真正的自驾驾驶得到监管机构的批准时，这意味着你将能够从几乎任何地方召唤你的特斯拉，在途中你可以睡觉，游戏或做任何其他事情。」Musk 这么说到，而当你的 Tesla 成为共享汽车的时候，拥有自动驾驶的它也许就更像是一辆 Uber 了。


「共享」是为自己赚钱！

「这看起来像是 Tesla 和 Uber 之间的斗争，但实际是人们和 Uber 之间的斗争。」再回到之前 Musk 这句深藏功与名的话。

因为当 Elon Musk 公布关于「共享」的总体计划时说「这不是特斯拉的重要新收入来源。」

相反，「你可以通过点击特斯拉手机应用程序将车添加到特斯拉共享车队，让它在你上班或度假时为你创造收入，这可以大大抵消甚至超过每月贷款或租赁成本，这真正降低了所有权的真实成本。这让几乎任何人都可以拥有特斯拉，因为大多数汽车的使用率只有 5％到 10％，所以这辆车能为你创造的经济性很可能是这辆车的几倍之多。」这么说是在表明 Tesla 的态度，不是我与 Uber 争利，这是人民的力量。

而这也就是「共享汽车」的核心。一方面降低汽车保有量的增长，同时提升汽车目前较低的平均使用率。甚至是在无人驾驶到来时，成功地刨去网约车中最贵的成本——司机。

最后 Musk 说到未来「在用车需求超过客户拥有的汽车供应的城市，Tesla 将经营自己的车队，确保用户随时可以随时使用共享汽车。」这句话细思极恐。

因为到这个时候，也许拥有一辆 Tesla 和使用 Tesla 的共享服务好像就没有什么区别了，而 Musk 也悄然实现了你新一代消费观念的转变，从拥有全部所有权到接受只拥有使用权的变化。

汽车因为产品价值高但更新速度慢和可延展性差，就在新一代消费者的兴奋点中逐渐弱化。当它不再是关注的焦点和话题的中心，而逐渐沦为单纯的交通工具时，所有权就不重要了，「共享汽车」则会因为效率提升而改变这个行业。而 Tesla 也从一家生产汽车硬件的公司，转变为一家提供「服务」公司。

所以随着 Model 3 的几乎是「完全共享汽车硬件」的配置，加上即将要大批量的量产，「共享」这件事甚至能在 Tesla 实现自动驾驶之前先落地。而从 Tesla 这一系列的「完全硬件」，我们也能真正感受到「汽车 OTA 升级」对于汽车未来能力提升的重要性。

说到这里，我准备去买点 Tesla 的股票屯着。
