# 魅族 Flow 耳机评测：一款值回票价的 500 元档「流行塞」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652848473&idx=3&sn=dd00ff9190c7e3f65e45a6a19fbecf3f&chksm=7e6a3cef491db5f9e7d16297c0f4dd0f65cc077e9ac3005e688c2b8e25a995e5416dd08b0fde&scene=126&sessionid=1681311165#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652848473&idx=3&sn=dd00ff9190c7e3f65e45a6a19fbecf3f&chksm=7e6a3cef491db5f9e7d16297c0f4dd0f65cc077e9ac3005e688c2b8e25a995e5416dd08b0fde&scene=126&sessionid=1681311165#rd)

![](../Images/1e1f2ed165fe23634f2d52dbb58e98e2.png)

  

**摘要：从一款 500 元档「流行塞」的角度看，魅族 Flow 是明显可以值回票价的。**

  

在 PRO 7 的发布会上，魅族还发布了一款叫做 Flow 的三单元耳机，售价 599 元（和 PRO 7 一起买是 499 元）。

这款耳机的销售状况貌似不错，发布后一直处于「基本无货、偶尔抢购」的状态，我们最后通过万能的淘宝购买了银色的版本。  

![](../Images/54477d02c2bbb3f30949f1928f19eb9c.png)

Flow 的整体设计和和魅族去年出的入门级耳塞 EP2X 有些类似（应该都是出自同一位日本设计师之手），是一种不太规则的流线型设计，好不好看就看个人喜好了，我个人觉得还 OK，但也没有很惊艳的感觉。

![](../Images/4e9e1e62101ccda5c72f81ca890c6998.png)

当然，作为一款 599 元的耳机，Flow 的材料和工艺要比 EP2X 高端很多，耳机的外壳、线控、插头部分都大量采用了拉丝金属材质。特别是外壳部分，Flow 耳机用了一块外形并不规则的金属件，工艺上应该是有一定的难度，这种处理在传统音频厂商的产品很少能看到。

![](../Images/243d8cc069bbddbfc7017c86b7200f07.png)

在工艺上，Flow 也达到了非常优秀的水准，没有遇到部分媒体老师试听的评测版耳机的边缘毛刺问题。

**单看外观工艺，魅族 Flow 其实要比一大票 2000 档甚至更高的大牌音频厂商的高端入耳式耳机还要好。**这也是手机厂商相比音频大厂的普遍优势：音质做得好不好另说（通常不太靠谱），但外观工艺可以轻松干掉音频大厂的数倍售价的产品。

在官方的产品介绍中，魅族用「好的佩戴，是忘记佩戴」来描述 Flow 耳机的佩戴，在实际的体验中，虽然没那么夸张，但 Flow 耳机的佩戴的确非常舒服，比我之前曾长期使用、佩戴上有出色口碑的威士顿 UM10 还要舒服一些。不过需要提醒的是，Flow 的导管比较粗，如果你的耳道比较小，可能会有不适的感觉。

![](../Images/2d4a27f836b14801da9b7faade470113.png)

说完了设计、工艺、佩戴，下面到了音质的部分。

硬件上，魅族 Flow 采用了「一个动圈 + 两个动铁」，也就是俗称的「圈铁耳机」，动圈负责低频，两个动铁分别负责中频和高频。

![](../Images/83fc5c82bf36ec1d0fdd3ff28f816deb.png)根据微博网友 \_\_\_archon

根据微博网友 \_\_\_archon（http://t.cn/RCJ0IzA）的拆解，FLow 的动铁单元来自 Knowles（娄氏），并不是之前一些网友猜测的国产「山寨」单元。除了索尼自家的不外卖高端动铁单元，娄氏的动铁单元品质是目前能找到的品质最好的动铁单元了，也是威士顿、AKG 等索尼之外的国际音频大厂普遍采用的动铁单元。  

**（更新：魅族官方没有宣传 Flow 的单元型号，据说部分零售版 Flow 采用的不是娄氏单元，具体情况尚待确定）**

从硬件上看，Flow 堆的「料」算得上是很足的，这不能保证它的声音一定好听，但至少可以保证它的「硬素质」不会差。

声音方面，魅族 Flow 是一款「流行塞」，低频的质感优秀，量感足够但又不至于「轰头」，人声位置稍微往前拉了点，但感觉不够细腻，高频部分有些「提亮」的处理，刚听起来感觉会很刺激，但也更容易产生听觉疲劳。

魅族 Flow 的阻抗为 32Ω，灵敏 105dB。实际体验中，魅族 Flow 对前段的要求不算高，用 PRO 7 已经能出来不错的声音了，换个推力大的前端整体表现还可以更好，但毕竟是一款手机厂商的塞子，应该也不会有太多用户会把 Flow 搭上「国砖」听吧。

如果纯粹看音质的话，我认为，基本同一价位的威索尼克 GR07 Classic 有着比魅族 Flow 更加均衡和优秀的声音，虽然 GR07 Classic 只有一个动圈单元。如果你对音质的诉求更高并且不怎么看外观，GR07 Classic 依然是 500 元档的标杆产品。

![](../Images/3f3d729331e94b2b737d103e1978b152.png)

不过，从一款 500 元档「流行塞」的角度看，魅族 Flow 是明显可以值回票价的。

**相比这一价位的大多数产品，魅族 Flow 耳机有着更好的工艺，更优秀的佩戴体验以及不算最好但足够出色的音质。**如果你不打算折腾「Hi-Fi」，只是打算花 500 块钱给自己的手机买个戴起来舒服并且音质不错的入耳式耳机，魅族 Flow 是这一价位值得考虑的一款产品。 ■
