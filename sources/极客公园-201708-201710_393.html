马斯克等 26 国 AI 技术领袖上书 要求联合国禁止「杀人机器人」的研发与使用

「杀人机器人」，似乎已被公认是下一轮军用技术的制高点。全球中美俄英法韩等主要军事大国，纷纷加大研发投入，争相打造无需人类驾驶员、操纵者的「钢铁雄师」。但同时，这引发的伦理争议与安全担忧日渐升温。一批机器人和 AI 领域的专家、企业家以及技术领袖，正呼吁联合国禁止「杀人机器人」的开发和使用。今日，来自 26 个国家的 116 名专家，由马斯克和 DeepMind 联合创始人 Mustafa Suleyman 领头，发布公开信正号召全面禁止自主武器。

在公开信中，这批技术领袖们对将主持该讨论的联合国常规武器会议警告称，这轮军备竞赛极有可能导致「人类战争形式发生第三次革命」，前两次分别由火药和核武器引发。信中写道：致命自主武器将使未来战争扩大到前所未有的规模，战争进展的速度也将超过人类对时间的理解。

该公开信在今天 IJCAI 的开幕致辞上公布，得到了机器人以及 AI 领袖不少知名专家学者的支持。AI 顶会 IJCAI 被专家们用作讨论致命自主武器系统的论坛，已经不是第一次了。两年前，包括马斯克和霍金在内的数千名 AI、机器人专家以及行业领袖在该大会上签署了另一封公开信，呼吁与今天相似的武器禁令。这推动了联合国对致命自主武器开启正式讨论。（the Guardian、雷锋网）

天津出新规！共享单车交通违法将「禁驾」并记入信用记录

共享单车的出现，为人们日常出行带来了极大的便利，但同时也存在着乱停、乱放、违反交通规则等诸多问题。

对此，天津市日前正式启用了共享单车交通违法信息交互平台，不少网友拍手称快。

新规规定一年内发生一次违法行为的用户，将被禁用共享单车一周，违法第二次的禁用两周，第三次及以上的，每违法骑行一次将被禁用一个月。

对于弃车逃避处罚的现象，通过信息平台的共享，各共享单车企业会对逃避处罚的用户进行核实，确定后对该用户进行禁用共享单车的处罚，并提示他到当地交警大队缴纳罚款。用户接受处罚后，各企业还会继续对其实施禁用单车两个月的处罚措施。（央视财经）

甲骨文考虑将 Java EE 送给开源基金会

甲骨文想要结束它在 Java 平台企业版 Java EE 上的主导开发角色，寻找开源基金会接手这一角色。甲骨文称，即将发布的 Java EE 8 提供了一个机会重新思考 Java 的开发。虽然目前 Java 的开发是在开源社区的参与下进行的，但甲骨文主导的开发流程被认为并不敏捷，灵活或足够开放。

甲骨文同时表示，它会继续参与 Java EE 的开发。Red Hat 和 Eclipse 基金会都对此表示欢迎，认为转移到一个供应商中立的开源基金会对平台和社区都有益。Eclipse 基金会表示愿意接手。（solidot）

微软未来 Surface 的 3D 相机系统？凌空手势输入

根据 Patently Apple 今日消息，美国专利商标局发布了一项微软的专利申请，该专利涉及到了微软 Surface 设备的 3D 深度摄像系统，通过凌空解读手势来控制设备的一些功能，另外 3D 深度照相机还可以捕捉来自手写笔的输入，以便通过把其他平面上的绘制内容可以输入到 Surface 设备之中。

德国将建设首条电气化高速公路「一键」解决电动车续航问题

近日，西门子公司宣布已经与德国黑森州达成协议，为德国 A5 联邦公路铺设总长 10 公里的空中接触网，建设德国首个电气化公路 eHighway。

根据设计思路，卡车安装有智能受电弓，同时结合混合动力系统，最高可承受的卡车速度为 90 公里/时。当卡车在电气化公路上行驶时，可通过受电弓与接触网连接，使用电力；当行驶在普通路段时，卡车也可自动切换至混合动力引擎。

官网介绍，eHighway 能效是内燃机的 2 倍。不仅能耗减半，还因为使用电力，减少了空气污染，特别适合港口、工业中心和货物枢纽。Quartz 网站曾引用 IDTechEx 报告指出，西门子提出的这个系统在未来 30 年可节省高达 2000 亿欧元。（华尔街见闻）

NASA 将为 2017 超级日全食推流媒体直播服务

当地时间 8 月 21 日，周一，美国所有人都将有机会看到日食现象，根据人们所在的位置，有些人甚至可以看到整个过程。日全食将从俄勒冈州开始，在南卡罗来纳州结束，任何身处这条路线上的人都将见证日偏食。
