# 揭秘 Sand Hill Program：谷歌的技术私教和超级创业加速器

**摘要：谷歌隐秘存在的这个超级创业「加速器」，让你知道走向国际化市场「还有这种开挂模式」。**

  

从 2000 年至今，中国互联网行业在发展到快到第二个 10 年时，这项已经改变了各个行业的「革命」已经到了下半场。就在不久前的「上半场」，创业公司在和投资人谈 BP 时，通常要找一个对标的硅谷公司，例如「中国版的 eBay」，就比较好懂也容易让后者掏钱。然而，当国内互联网人口红利基本吃尽的「下半场」时，如何在本土之外的国际市场打开局面似乎成了所有公司都要面临的问题。  

印度、泰国、菲律宾、马来西亚这些中国近邻国家早已成为国内互联网公司和资本争斗的第二战场。不过，对于很多已经向邻国成功输出互联网经验的公司来说，在面对欧美及全球市场时依然心有余而力不足。这时候，如果有一个能在用户和市场上非常有积累的公司帮忙，一定事半功倍。

美国打车应用 Lyft、家居装修网站 Houzz、中国音乐短视频社交网站 Musical.ly 这几家看起来不太有关联的创业公司，其实背后有一个共同之处——Google Sand Hill Program，这个谷歌内部的神秘项目组汇集全球最有潜力的初创公司，并且已经助力孵化了数个创业公司变身「独角兽」。这个谷歌朋友圈发布的内容，相信很多心怀全球市场的国内创业公司都会十分感兴趣。

近日，极客公园与 Sand Hill Program 创始人 Suman Prasad 进行对话，后者也分享了谷歌这个神秘的创业公司加速项目。

![](../Images/aa445707df7f19936ede7b61703a30e2.png)

  

## Google 原厂创业公司加速器

美国艺术家安迪·沃霍曾经预言每个人都能成名 15 分钟，当然他没有算到互联网技术在 21 世纪的巨大成功。一涉及到互联网，甚至连时间概念都被改变，上一批巨头公司如谷歌、阿里巴巴、百度等发展 10 年时间取得的成就，在当下可能仅仅 2 年就被创业公司超过。创业公司出现的速度越来越快，当然淘汰的速度也越来越快，如何在更短的时间内从头角峥嵘到成为真正的「Player」，是每一个有野心的创业公司都要面对的难题。

如何让这些全球具有独角兽气质和潜力的创业公司快速壮大，则是 Google Sand Hill Program 的重要任务。

2013 年，已经在谷歌新兴业务发展部门担任战略和运营主管两年时间的 Suman Prasad 正式成立 Sand Hill Program。在成为谷歌全球创业公司合作总监之前，Suman 有十年以上的投资和管理经验。凭借在投资和互联网科技领域的深厚积累，Suman 创立的 Sand Hill Program 从一开始朋友圈就包含了顶级投资公司和极具潜力的创业公司。

当然，想要进入谷歌超级朋友圈，还是需要符合比较严苛的标准的。首先，作为 Sand Hill Program 的合作伙伴如红杉、KPCB 这样的硅谷顶级投资公司会给前者推荐拿到 A/B 轮融资的创业团队——能被这些投资公司选中的团队，其潜力自然不小。过了专业创投这关，Google 还会考察公司的产品是否切中市场痛点，是否足够吸引用户进行深度互动, 是否能和谷歌的产品生态体系很好的契合。

「重要的一点，是要看谷歌能否帮助这些公司，通过谷歌的产品和服务创造为其更多价值。」Suman 如此解释道。

![](../Images/54e3293f4b8a1a17dae4f28db73cac74.png)谷歌旗下多种技术和产品

  

## 谷歌生态产品的「私人教练」

对于很多创业公司来说，开始的时候可能只有两个人和一个非常棒的想法，而在好想法和真正实现之间大概隔着一万光年的距离，这其中最大的两个障碍，一个是技术，一个就是市场。而这两个难题，正是 Google 这个 IT 巨头最擅长的两个领域。

在技术层面，谷歌的云平台、SDK、各种功能 API 可以说是一个丰富的生态系统，涵盖了从建站到应用推广的方方面面。而对很多团队来说，即便有使用说明，想要将谷歌的技术和产品熟练的使用起来，依然不容易。

Sand Hill Program 一个重要价值，就是能够联系到谷歌所有产品的相关人员，为创业公司讲解谷歌各个产品和应用的使用技巧，为开发者提供技术支持。例如，一个想要开发 VR 应用的团队，有可能得到来自 Google Daydream 团队技术人员的指导，则要为团队在 VR 开发少走很多弯路。而一个团队如果想知道如何制作安卓系统的应用，还有什么人选会比谷歌安卓团队的技术专家更合适？

除了有专门的技术专家指导你如何更好的使用谷歌生态系统中的工具和服务，Sand Hill Program 中的创业公司还有机会提前测试谷歌尚未推出的新功能和产品，这些新品包括 Google Assistant、Daydream VR 以及 TensorFlow 等大热的新技术平台。通过内测，谷歌获得创业公司的反馈，而创业公司则能提前尝试谷歌的新技术。试想一个团队提前开始使用 TensorFlow 技术，那么他在人工智能赛道上的起点已经绝非其他竞争对手能比。

可以说，Sand Hill Program 为创业公司提供了一个「私人教练」，指导团队如何更好的使用谷歌的产品和服务。

  

## 助力创业公司开拓海外市场

在全球成千上万的创业团队中，有相当多的创始人本身就是技术高手，所以如何制作产品不难，难的是如何让产品被更多的用户使用，这也是为什么很多国内公司的出海之路异常艰辛，因为这些创业公司对海外市场的了解太少。而由于谷歌在全球市场的积累，使得 Sand Hill Program 能够为团队提供目标市场的丰富知识和指导。

如果不说，一般人可能猜不出在欧美年轻人中蹿红的音乐短视频应用 Musical.ly 的背后，其实是一支来自上海的团队。从 2014 年 7 月上线，到 2015 年 7 月登顶苹果应用商店榜首，Musical.ly 只用了 1 年时间。Musical.ly 初露头角后，Google Sand Hill Program 也找到团队，将其加入到合作伙伴名单中。而进入了 Google 的朋友圈，Musical.ly 在欧美市场的开发也得到了很大帮助。

![](../Images/13801db2a1987aa2e5922cb330967345.png)Musical.ly已有2亿用户（图片来自公司官网）

Musical.ly 联合创始人朱骏透露，公司在早期产品基础架构、开发者 SDK、用户验证和用户数据分析上都使用过 Google 的技术，这些服务对于创业团队来说节省下大量精力和成本。而在技术之外，和谷歌旗下视频网站 YouTube 的合作，才是对 Musical.ly 吸引海外用户，打开欧美市场帮助最大的。

从用户层面来说，YouTube 和 Musical.ly 的目标群体都是欧美年轻人，受众基本一致，很多用户在两个平台都有账号。而为了打通两个平台，Musical.ly 在用户的页面上加入链接，可以直接进入到用户的 YouTube 页面。同时，Musical.ly 也支持用户把 YouTube 上的视频导入到前者的页面中点击观看。而很多 Musical.ly 的用户也会将自己的合集视频上传到 YouTube 平台，供后者的用户观看。

通过和 YouTube 的联动，Musical.ly 成功将大量 YouTube 用户迁移到自己的平台上进行内容创作，同时很多 YouTube 播主的粉丝也随之来到 Musical.ly。目前，Musical.ly 平台已经有 2 亿用户。朱骏表示，对于一个想要进入欧美市场，谋求快速增长的初创公司来说，和 Youtube 的合作对 Musical.ly 的品牌和用户增长都起到了关键作用。

  

## **是朋友圈更是社区**

除了为创业团队提供技术支持和市场帮助，每个季度 Sand Hill Program 团队还会举行聚会，将合作伙伴召集到一起，让这些创业者分享自己项目的成功经验和发展历程。同时，也可以让这些创业公司从同行者身上获得灵感，碰撞出更多火花。Suman 透露，此前一期 Sand Hill Program 的分享会上的主角正是已经在香港上市的美图公司。

「虽然大家来自美国、中国、以色列，讲的语言都不一样，但是创业者说的事情是同一件。」Suman 说道。从这个角度来说，Sand Hill Program 不仅是一个谷歌的超级朋友圈，同时更是一个创业公司的社区。

Suman 认为，由于中国本土市场非常巨大，所以国内创业公司往往发展出不同于别处的特点。几年前国内互联网流行的是「山寨硅谷」。而现在，中国互联网公司渐渐强大，很多国内流行的特色已经逆袭海外，例如二维码、共享单车等。「现在印度的创业公司会标榜自己是『印度的阿里巴巴』。」Suman 笑着说道，他认为中国创业公司应该坚持自己的想法和特色，同时 Sand Hill Program 的国内团队同样期待和更多的中国团队紧密合作。

今年谷歌开发者大会上，Google 公司 CEO Sundar Pichai 确立了「AI First」的战略。Suman 透露，已经有相当多的团队开始使用谷歌的机器视觉、语音识别和机器学习工具来为自己的产品赋能。

正如互联网时代造就了一批成功的公司，新崛起的人工智能时代，同样会有一批新兴的创业公司成为下一代独角兽。而 Sand Hill Program 要做的就是为这些有潜力的创业公司提供技术支持和市场帮助，为其成长加速。
