Android 系统将升级新技能，让你没有网络也能联机打游戏

摘要：这项名为 Nearby Connection 的新功能不仅仅能帮手机省流量，它还能做的更多。


我记得很多年以前，黑莓手机曾在 9·11 事件中「一夜成名」，原因是当灾难袭来，网络信号大面积瘫痪时，黑莓手机用户仍然能够通过黑莓手机配合自有的网络服务来发送图片和文字，仅此一项功能，就让很多人对黑莓路转粉。

不过，今天我想说的倒不是那个已经成为「渐行渐远」的黑莓，而是 Google 和它的「亲儿子」Android 系统。在最近更新的 API 2.0 当中，Google 为开发者带来了第二代 Nearby Connection 功能，这将让 Android 设备变得更加好用，而究竟这个功能有什么特别？它在未来还有哪些想象空间？接下来我们不妨聊聊看。


后知后觉的「新功能」

要说起来，Nearby Connection 不算是非常新的功能，简单讲它能让 Android 设备通过蓝牙或 Wi-Fi 找到附近的其他设备，连接在一起，不用网络就能够传输数据及信息。

这并不算是新功能，对于 iOS 用户来说，Airdrop 就能够做到这样，而即便是对于 Android 用户，很多年前就有的各种「XX 快传」应用也能够做到类似的效果。

看起来，官方这一次在 Android 上更新这项功能有些「后知后觉」，你可能也会疑惑，为什么这种很早就应该有的功能，到现在才正式出现在官方版本中？

要理解这一点，我们似乎应该从 Google 对于 Android 系统功能的进一步挖掘说起。实际上，Nearby Connection 在今年 Google I/O 大会上就已经提到了，并且给这项功能做出了一些示例用法：

  1. 协同白板：让附近的参与者共享虚拟白板以记录自己的想法；

  2. 本地多人游戏：设置多人游戏，并邀请其他用户加入；

  3. 多屏游戏：将手机作为游戏控制器，从而在 Android 电视上使用；

  4. 脱机文件传输：快速且不需要网络分享照片、视频及其他任何类型的数据。

上面这些，其实只是官方给出的一些关于 Nearby Connection 的主要功能，在官方给出的开发者文档里，提到了 Nearby Connection 的特点是高带宽，低延迟和完全加密，以此为基础，Android 设备之间能够快速、安全的进行数据传输，这会对开发者的应用开发起到不少帮助。 

比如说在娱乐方面，通过这项 API，开发者能够让你的 Android 手机变身成为游戏手柄，直接连接到电视机玩游戏，又或者可以充当体感游戏的道具，不需要网络就能够让手机变成「乒乓球拍」和「高尔夫球杆」。

或者再想象一下，我们生活中的很多场景都非常需要这样好用的功能，比如说利用这项功能开发出适合线下聚会的「狼人杀」或者「王者荣耀」，一方面能够方便大家在一起玩游戏，免去了网络拥堵，另一方面即便是没有网络的状况下，人们依然能够使用它。

当然，如果你认为现在网络这么发达，流量也很便宜，开发一个不用流量的游戏应用并没有多少价值的话，那么也许通讯以及办公场景会更适合它。回想一下当年黑莓辉煌的时光，曾经备受大家喜爱的就是通讯功能，而当这种能力被赋予到 Android 设备上面，自然会更进一步让手机变得便捷和全面。至于办公方面，Nearby Connection 将会让多人协作变得更加方便，同步更加迅速。这是协同办公方面最看重的能力之一，想必也会让人们惊喜。


在巨人的肩膀上前进

其实一直以来，不论是 Android 还是 iOS，主流手机操作系统的功能更新在渐渐走向个性化，细致化，许多从前开发者们的奇思妙想都变成了如今官方的正式功能，不仅极大促进了系统的进一步完善，同样也反映了众多开发者的深入洞察。

比如不论是 Android 还是 iOS，护眼模式都在很早以前就被开发者开发出来，后来才加入了官方更新。再比如 Android 系统的分屏应用，以及 iOS 上面的中文输入法等等功能，这些都是在开发者带给大家，收到市场正面反馈之后，不断加入到官方功能更新当中，从而成为整个生态体验中的一部分，从这一点上来说，这些开发者们就是先行者，让这些操作系统看到了更多新的可能。

今年 3 月，苹果以不为人知的价格收购了大名鼎鼎的效率应用 Workflow，意味着对于工具类应用的整合迈入一个新台阶。而早在 2014 年，一款上架 App Store 的通讯应用 「FireChat」就利用了 Wi-Fi 或蓝牙形成点对点（peer-to-peer） 模式进行消息传输，在没有网络信号的条件下，依然能够让特定距离内的用户保持联系，因此在通讯不佳或人流密集的地区体现出价值。

不论是 iOS 还是 Android 生态，它们之所以能够留住如此多的用户，原因就在于相比孱弱的 Windows Phone 系统，这两个系统更具生命力。我们有理由相信，随着硬件的进一步革新，手机操作系统的功能进化还将持续下去。

所以，尽管这一次的功能更新看似「后知后觉」，但说不定以后，越来越多基于这项能力开发的应用会让你的生活更方便呢~
