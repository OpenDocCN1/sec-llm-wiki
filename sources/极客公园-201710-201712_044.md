# 英伟达最新 AI 研究让晴天变雪天，人工智能如何欺骗视觉？

> **在未来，人工智能会给更多领域带来惊喜。**  

  

英伟达公布了一个新的研究，这个研究可以让电脑去想象，外面阳光明媚的时候，下雨、下雪是什么样子的。

![](../Images/a183d2906ce4b9c7398d1f4ee0a5e867.png)图 | NVIDIA GitHub  

当然，这个技术不只用来让街景变换，研究人员还用这个技术改变了动物的斑纹，变换了猫和狗的品种，甚至改变人的装扮。

![](../Images/a5cdfc931f69612ca9067d632d55f936.png)

![](../Images/878479d6d5b91d3811f593f9c5af7f83.png)

![](../Images/aff1aa6a888ff6ddd780578267a1bd79.png)图 | NVIDIA GitHub  

这个研究有很多用处，它能帮助自动驾驶汽车的训练。如我们想让自动驾驶汽车在下雨天也能正常行驶，可以通过这个技术，把晴天的视频转换成雨天，以此帮助训练。

英伟达的这项研究背后采用了人工智能方法，这是一种生成式对抗网络（GAN），它特别擅长生成视觉数据。GAN 通过结合连个独立的神经网络来工作，一个是产生数据的，另外一个是判断的，能够拒绝看起来不准确的样本。利用这种方式，随着时间的推移逐渐教会人工智能，产生更好的效果。

通常这种方法需要标记的数据集来生成数据。所谓的标记数据集，就像做练习题一样，告诉你题目和答案，最终让你去考试。在传统方法中，标记数据集需要很大的工作量，研究人员告诉外媒说，如果你要制作一个把白天变成夜晚的场景，需要在同一个地方拍摄图像，然后研究两者的差异，才能实现。

而英伟达的研究和现有的技术相比有很大的优势。这个研究不需要上文中的准备工作，它不需要标记数据集，就能产生类似的结果。这能让研究人员空出很多时间，否则不得不花大力气整理训练数据。

此前，Adobe 也开始了人工智能+视频领域的布局。它通过名为 Adobe Sensei 的这款应用于各款产品的底层人工智能工具，提供多种令人惊叹的功能。在 2016 年，Adobe 在 MAX 2017 创新大会上发布了一系列黑科技，Project Cloak 能够将视频中的部分图案移除。如图所示，用户可以通过 Cloak 使视频中的两个人凭空消失。

![](../Images/01febffe374811ddca4397bd4310fc71.png)图 | Adobe官方  

除了巨头，创企也做出了大量产品，提供了很多有意思的场景。Philm 这款就能让天空变成动态。

![](../Images/62d8df778033fea25a1f9f4cd9e2a7a7.png)该图为极客公园实拍静态图，由 Philm 生成动态天空  

这些 App 是怎样将照片变成油画的呢？这也是「深度学习」模型中神经网络的功劳。它先获取梵高等绘画大师的艺术风格，让人工智能系统成为画家，再让它对你的图像进行创作。

视觉创作 APP Versa 的创始人告诉极客公园，有很多很有意思的场景，都可以通过一些基础的神经网络模型来实现。这两年不断有新技术、新研究出现。但这些新技术或许不都是革命性的突破，可能是因为我们最近才开始关注。

据极客公园了解，科学家早在上个世纪 70 年代便开始研究，有两个德国的医生和生物学家，解剖猫大脑时总结了神经元的状态，他们发展了一套理论，从他们的角度来讲非常切合人脑的识别模式，于是提出了这个架构。随着深度学习的不断发展，理论模型逐步完善。

但神经网络技术逐渐走红也是必然，Philm 的专家认为，随着 GPU 的不断发展，处理速度越来越快，另一方面是大数据时代的到来，此前的数据量不够大，限制了技术的发展。

![](../Images/cd87ba83d859cd950a7dd66599db5624.png)图 | 北大 AI 公开课

据英伟达自动驾驶业务中国区负责人董方亮在北大 AI 公开课上介绍，深度神经网络的每一个节点都可以模拟成一个计算核，GPU 承担了每一个节点的计算，这是 GPU 符合深度学习架构的原因，它带来了深度学习创造力全新计算时代。

但这或许只是一个开始，在未来，人工智能会给更多领域带来惊喜。
