# 探访三星电子韩国总部：消费电子的过去、现在和未来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652851344&idx=3&sn=0db2c19b26eb10b6837603fddfe10d66&chksm=7e6a3126491db830774ab7644ee2c33dcf493e5e836dc2df04279e111a406f12e344229ebe0d&scene=126&sessionid=1681311077#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652851344&idx=3&sn=0db2c19b26eb10b6837603fddfe10d66&chksm=7e6a3126491db830774ab7644ee2c33dcf493e5e836dc2df04279e111a406f12e344229ebe0d&scene=126&sessionid=1681311077#rd)

> **当「电子产品」变成了大众消费品，一个市场份额最高最大众的品牌如何选择自己的产品路径，如何面对用户的成熟习惯时保持自己的先进性。**

  

走在深冬的首尔街头，出于职业病，我仔细打量着行人手中的手机。沿路走完一条街，S8/S8+ 和 Note8 占了绝大多数，这并不让人意外，毕竟这里本就是三星的主场。

这是一趟参观三星韩国总部的旅程，三星电子向中国媒体开放了他们韩国总部的一部分，似乎也是第一次邀请中国媒体深入走进他们的核心区域。

三星是全球最大的家电品牌，也是全球最大的手机厂商，而对我们来说，它是观察消费电子行业一个极好的切入点。在走进三星韩国总部，和三星的工程师们深入交流了几天之后，我们近距离看到了消费电子的过去、现在和未来。

在三星电子水原总部里有一个叫做「SiM」的博物馆，里面完整展示了消费电子过去几十年的历程。

![](../Images/5b9cf230715f09a1d6730b6d78a6951c.png)

解决消费体验的时代难题，就一定伴随着爆款的诞生，在 SiM 博物馆里我们见到了全球第一款销量破百万的电冰箱，它出自通用电气，成为爆款的原因是它领先地解决了压缩机噪音的问题，让电冰箱不那么吵了。

我们在 SiM 博物馆里也见到了三星在韩国市场的第一个爆款彩电和很多经典的「Anycall」手机产品，消费电子的上一个时代属于技术突破和技术下放，那是一个产品形态百花齐放、产品功能十分多样的年代，三星从那时一路走到现在，便有了极为宝贵的时代积累。

![](../Images/12eac65694ec9e0bf2b3b7772ae98dc8.png)

从那个时代走来，在消费电子的当下，我们都有同样的感受，这是一个很矛盾的业态，以三星电子为例，它的全产业链布局和整个行业同质化的严重程度对照着看，大家做到「水桶型」已经不够了。

在与 Note 8 相机团队的工程师们交流的时候，我们能很明显的感觉到一种做到行业领先之后更高维的追求。从 CMOS 到 OIS 镜头再到软件算法，三星每一个部分都在朝极限推进。熟悉手机行业的朋友都知道，S 系列和 Note 系列这么多年以来在影像上的优势，一直都是很「综合」的。

当然，我们也提出了一个现在手机拍照方向的关键问题，超强的算法能颠覆这个行业吗？而三星的工程师告诉我们：「三星坚持在硬件和软件上都投入巨大的精力，目的是让用户在任何时间、任何地点、任何环境下都能拍出好照片。大数据、AI 和算法确实是一个很好的新突破，但目前有些场景下还是很难拍好的。」

再比如，三星是在生物识别上布局最早也最激进的手机厂商，把指纹识别、虹膜识别、人脸识别一个个放进了小小的手机里，这背后除了对前沿技术的追求，也是三星当下思维方式最好的体现，它和过去几十年的经历有关，也受如今行业地位的影响。

三星的工程师告诉我们：「三星选择给用户所有的选择，所以除了现在看到的指纹、虹膜和人脸，将来可能还会有声纹等等。」

![](../Images/4bc0195c276243c242e21464e8b2cdff.png)

消费电子的时代脉搏，严格来说已经并不掌握在任何一家公司的手里了，而是受全球几十亿用户的左右，被每一个渐渐成熟的消费习惯、使用场景决定着。

我们在水原总部的会议室里跟三星的工程师讨论了很多 Icon X 2018 无线耳机的技术细节，其中的很多思路也是一脉相承的。Icon X 2018 用了「inner」的设计，可以在跑步的时候用，可以防止汗水侵蚀，还有内置存储空间可以独立当 MP3，听歌续航也提升到了 5 小时，这全都是朝着综合好用的方向进行的升级。

当「电子产品」变成了大众消费品，一个市场份额最高最大众的品牌如何选择自己的产品路径，如何面对用户的成熟习惯时保持自己的先进性，便是消费电子品的「现在」。

![](../Images/0ec5a92d4239912ad73d39752a77a566.png)

当然，我们还是在水原总部的地下三层见到了一系列全世界最严苛的测试环境，仅仅是对手机的射频性能测试三星都定制了全世界目前规格最高（8X8 MIMO）的测试仪器。这原本就是三星的传统强项，三星也在为「未来」布局。

三星并不经常展示自己的黑科技，可每次当它真正将自己的能力呈现给消费者时，随之而来的往往是惊呼。在消费电子的未来时代，设备如何突破界限，和人们的生活用新的方式融合，是三星正在思考的问题。

Bixby 是三星电子在下一个阶段最重要的战略布局之一，现在也已经有了比较成熟的产品形态。我们在水原总部体验了用 Bixby 和冰箱进行语音交互，还能基于智能传感器和影像系统对冰箱进行检查和操控。最近中文版的 Bixby 也已经正式发布，它很快会渗透到三星电子的全部产品和系统里。

![](../Images/9c13ee6a7c8c4d57b28d3f64edbda29e.png)

探访三星总部的行程里我们去了三星的 C-Lab 创新加速器，其中一个基于 Gear VR 开发的帮助视觉缺陷人士看清事物的系统给了我们很大的启发。VR 和 AI 在医疗健康领域的应用看上去路途艰难，但一点点的小突破意义重大，用 Gear VR 这样的设备就已经可以给残障人士带来不少快乐和轻松了。

关于「未来」，所有的公司都会比较慎重，我们在水原总部窥探到的部分也有限。不过，从这些新项目的战略思路上看，在消费电子的下一个时代，大家都在思考它将如何成为人们的一种基础能力，我们也看到了三星的野望。 ■
