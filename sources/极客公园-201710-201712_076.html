在 iPhone X 中存「两张脸」？短时间内别想了

Face ID 短时期内不会改变支持一个人脸信息的设定。


iPhone X 的到来，重新对生物识别功能进行了定义。之前 iPhone 沿用的指纹识别被 Face ID（面容 ID）所取代。 

通过原深感摄像头来实现，它会投射超过 30,000 个肉眼不可见的光点，并对它们进行分析，为你的脸部绘制精确细致的深度图。根据官方信息，相较于 Touch ID 1/50000 的解锁概率，Face ID 的解锁概率是 1/1000000，在安全性上要更进一步。

早些时候极客公园曾经对 iPhone X 的 Face ID 功能进行了识别准确度测试，结果显示，戴近视镜、墨镜、围脖等条件下，其均能够成功完成解锁任务。

同时，得益于 Face ID 足够高的安全性，在解锁手机之外，其也成为目前唯一可以支持「刷脸支付」的解决方案。

今年 11 月份，微信率先针对 iPhone X 进行了适配，开始支持 Face ID 支付，用户可以通过面部识别来验证付款。随后，支付宝带来了 10.1.8 版本更新，在支付设置中新增了「面容 ID 支付」。

这也意味着，目前国内两大移动支付平台均已经对 Face ID 的付款能力给予了支持。在具体的使用场景上，Face ID 可以完全替代指纹解锁的所有功能。

不过存在争议的一点是，Face ID 只能存储一张人脸，并不能像 Touch ID 那样可以存储多个甚至不同人的身份信息，在日常使用过程中，这或多或少会带来一些不便。

有关 Face 为什么只支持一个人脸信息录入的问题，苹果软件工程高级副总裁克雷格-费德里吉（Craig Federighi）最近通过电子邮件的方式，回复了大家的质疑。 

「目前我们的重心就是让 Face ID 成为单一用户的验证方式，从前大家用的不亦乐乎的 Touch ID 也是针对单个用户设计的。之所以 Touch ID 支持多手指录入是为了让用户双手食指、拇指同时使用，苹果从来都不建议大家将其用在多用户认证上。当然我们也十分关注大家的反馈，并会在未来继续改善 Face ID。」

从克雷格-费德里吉的回应中，我们可以得到的结论是，从指纹识别到如今的面部识别，其实苹果的设计思路一直是采用单一用户验证，只不过由于手指在数量上要更多一些，大家「钻了空子」，才出现了可以录入不同用户指纹信息的情况。

另外，按照克雷格-费德里吉的说法，一个重要的信息是，短时期内 Face ID 并没有要支持多个人脸信息的想法。

但如果未来用户对于此事有更广泛的诉求，也并不排除其会在之后的更新中，做出相应的改变。

不过考虑到苹果向来在用户隐私安全上的「坚持」，在技术层面没有达到其要求之前，想要同时在一部 iPhone X 中存储两个或者更多信息，或许还得等上一些时日。
