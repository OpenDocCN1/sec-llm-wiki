# 为了帮助你记住手机密码，三星带来了「掌纹识别」技术

![](../Images/0cc08bf66f16e8c62fdff680ac4a9575.png)

  

> **在看手相之外，掌纹现在可以用来帮助你记住手机密码了。**

  

多样化的解决生物识别方式，意味着你可以在更多的使用场景中来完成解锁或者支付等操作。在实际使用体验过程中，这样的选择是最稳妥的一种做法。

在众多的手机厂商中，三星就采用了这样的策略，将能给出的生物识别方案均予以落地。因此，在 Galaxy S8/Note 8 系列身上，同时配备了人脸识别、指纹识别以及虹膜识别三种不同的生物识别方案。

![](../Images/ebc6a1580ffcf48e2dbbb285382d01dd.png)

但即便已经拥有了目前行业里足够多种类的生物识别方案，这家公司似乎并不满足于此。据 SamMobile 报道，三星在韩国又提交了一项新的专利技术——掌纹识别。

援引 The Verge 的说法，该专利推出的目的是帮助用户记住密码。

![](../Images/b78e3c63c7ec369d20516479164d2310.png)

具体来看，你首先需要使用后置摄像头对手掌进行拍照，来验证身份。如果掌纹与早先录入成功的记录相匹配，手机便会在屏幕上显示出密码提示，来帮助你解锁自己的设备。

![](../Images/a44485ea9ba844e9625d516076e23297.png)

其实有关掌纹识别技术，很早之前就已经出现并且得以落地到产品上了。

2014 年 3 月份，在日本 PC 制造商富士通发布的 Lifebook E741/C 及 Celsius H730 笔记本电脑中，便加入了掌纹识别。其在 C 面设置有掌纹识别传感器，使用时将手掌悬浮在传感器上方就能解锁电脑。

安全性方面，与指纹一样，掌纹同样具有独特性，同时血液需要流经手掌附近才能完成匹配。根据富士通官方测试，当初其识别错误率仅为 0.0008%，而识别失败率也只有 0.01%，准确度非常高。

![](../Images/aaf6b151cd633853418e65ebf9bb2f06.png)

不过此次从相关的报道中，我们可以得到的信息是，目前三星只是将其用于密码提示，并没有涉及到解锁等功能。在这项技术的应用上，其是否能够达到富士通的水平，还是个未知数。
