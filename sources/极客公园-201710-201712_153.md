# 中兴 Blade A3 上手：可以人脸识别和前置虚化的百元机

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850997&idx=3&sn=3968fd1ca6c6950ca796f7db1e2c51aa&chksm=7e6a3683491dbf95cdaaba404ff436c2aa7f7f13ccab097fcfc1f596dc21f23fc8743d901c8a&scene=126&sessionid=1681311086#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850997&idx=3&sn=3968fd1ca6c6950ca796f7db1e2c51aa&chksm=7e6a3683491dbf95cdaaba404ff436c2aa7f7f13ccab097fcfc1f596dc21f23fc8743d901c8a&scene=126&sessionid=1681311086#rd)

![](../Images/1e1f2ed165fe23634f2d52dbb58e98e2.png)

  

**摘要：虽然配置和外观上亮点不多，不过 Blade A3 却拥有人脸识别和前置双摄功能，在同类产品中并不多见。**

  

Blade A3 是中兴近期发布的一款入门款手机，目前「3GB + 32GB」版售价为 799 元。

通常来说，对于这类售价低廉的百元机，受限于成本，产品本身很难有多少亮点，不过 Blade A3 却有两个有些特别的地方——人脸识别和前置双摄虚化，我们一起来看一下。

![](../Images/b131b1b49e16963788c05ecd1d6a6269.png)

Blade V3 的包装没有什么特别之处，白色盒子上印着 ZTE Blade V3。

![](../Images/eb63fb922398433b8f9270c1768fb833.png)

躺在盒子里的 Blade V3。

![](../Images/42cf9bb0af6bfef5ace71b9f0ff6a8ee.png)

充电头规格为 5V 1.5A，Micro USB 数据线。

![](../Images/a1ea8e3607e7b8083282ec9f7b8126f9.png)

Blade V3 采用了一块 5.5 英寸的 LCD 屏幕，表面覆盖着 2.5D 玻璃，分辨率 720p，显示效果在同价位说得过去，不过 720p 意味着日常使用难免会感到一些颗粒感。

![](../Images/ffa9b1b50af57e66ba2213b8f6bfc8b3.png)

Blade V3 的一大亮点是前置，它的前置采用了百元机中难得一见的双摄设计，主摄 500 万，副摄 200 万（用于记录景深数据做虚化），同时配备了前置闪光灯。

![](../Images/a0ac58f1fc609f74ffa37657accef986.png)

此外，Blade V3 的前置摄像头还可以用来进行人脸解锁，识别速度中规中矩，比小米 Note3、vivo X20、坚果 Pro 2 等 2000 档采用了国内 AI 公司算法的产品有差距。

![](../Images/6c4df74f4122e60a044d682f70a7ed0f.png)

Blade V3 的后盖为塑料材质，不过表面做了一些仿金属的处理，手机上方可以看到两条塑料「信号条」。

![](../Images/0614db88522bad230d8c7a1dc58c77c4.png)

Blade V3 的后置为 1300 万像素，背面的 ZTE 标志上方可以看到后置指纹识别模块。

![](../Images/f6d465da48c226810b43e884911a3cc4.png)

后盖下方可以看到扬声器的开孔。

![](../Images/841a48247d50f78e5e0622240dd53c1b.png)

有趣的是，Blade V3 的塑料后盖是可以拆卸的，不过电池不可更换，打开后盖主要是为了更换 SIM 卡，Blade V3 支持同时插两张 SIM 卡和一张 Micro SD 拓展存储卡。

![](../Images/27a56e0ff88ea0ee066428163a327532.png)

配置上，Blade V3 大致是同价位的主流配置，包括 5.5 英寸 720p 屏幕、联发科 MT6737T、4000 毫安时大电池。

目前 Blade V3 只提供了 3GB + 32GB 一个存储版本可选，除了我们体验的曜石黑，还有前面板为白色的冰川蓝配色可选，售价均为 799 元。 ■
