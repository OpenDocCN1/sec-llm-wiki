特斯拉发布会开得这么嗨，股价为什么反而跌了？

摘要：Model 3 的难产问题是特斯拉如今处境的罪魁祸首。


特斯拉半挂卡车和新款跑车的发布会已经过去快一个星期了。

回想这场激动人心的发布会，「史上最高载重和长距离续航」的重型 Tesla Semi 与百公里加速 1.9 秒的 Tesla Roadster 2 无不让观众为之尖叫，那一天，马斯克重新定义了「电动卡车」和超跑。

对外界而言，大家对这两款新车的关注度堪称「汽车界的 iPhone」，一时间马斯克本人与两款新车的图片刷爆了全球的社交网络。但兴奋之余，也有人为特斯拉敲响了警钟：虽然新品惊喜不断，但特斯拉实际上还存在着今年早些时候发布的 Model 3 的量产问题。

极客公园创始人张鹏就在发布会后表示，「看着虽然兴奋，但我的担心是，如果股市对于 Model 3 这种『前置刺激』越来越不敏感，而生产问题又突破缓慢，Tesla 难免有失速的可能。所有的『前置刺激』都是难以重复的危险游戏，特别是硬件领域。」

目前的情况确实佐证了这一观点，特斯拉在发布会结束后接到了几个大公司的订单，这让股价得到了短暂的上涨，但之后迅速回落，现已回复到发布之前的股价水平。事实上，特斯拉自从今年九月股价达到峰值以后一路下跌，到现在已经跌了 20% 左右。


Model 3 的难产

导致特斯拉股价下跌的罪魁祸首就是今年 4 月发布的 Model 3 的量产问题。早先有报道称 Model 3 的电池在生产过程中遇到了困难，这一问题严重阻碍了特斯拉正常的生产计划。

来自摩根士丹利的分析师 Adam Jonas 就此指出，特斯拉的股价会因为电池量产问题的解决而上涨，但到明年晚些时候，随着竞争对手越来越多，实力差距越来越小，特斯拉投资人的信心会受到不小的打击。

「从短线交易的角度来看，我们认为特斯拉的股价会在接下来几个月里触及 400 美元甚至更高，随后将面临一系列较为严重的阻力。」Adam Jonas 在报告中写道，他认为特斯拉 2018 年的股价会在 400 美元到 200 美元之间波动。

短期内，依靠 Model 3 电池生产问题的改善，特斯拉目前的困境将会得到一定程度的缓解，他们在弗里蒙特的工厂和内华达州的 Gigafactory 电池工厂投入的巨额生产研发资金将会在接下来的时间里得到回报。

有部分人认为特斯拉上周召开的发布会其实是特斯拉希望大家将注意力从 Model 3 的量产问题上转移开来，但很显然，电动卡车和跑车虽然炫酷，但 2019 年才能开始量产的消息让大家感到有些失望。


燃烧的资金

雪上加霜的是，今天彭博社发表了一篇文章（http://t.cn/RY2nDIo），称特斯拉在过去的 12 个月里烧钱无度，每小时花费 48 万美元，这样计算下来，大约到明年 8 月 6 日，特斯拉的现金资源就会耗尽。

这一数据对特斯拉来说非常不利，彭博社也向特斯拉反映了这一数据，特斯拉官方则回应称他们有足够的资金来完成生产目标。

的确，除了基本的融资以外，特斯拉还有一些额外的收入。

上周发布的半挂卡车 Tesla Semi 和跑车 Tesla Roadster 2 虽然要到 2019 和 2020 年才能量产，但也已经开放了预订，每辆 2 万美元的定金几乎可以算是特斯拉的一笔免息长期贷款，Tesla Semi 已经得到了沃尔玛等大公司的批量预订，而单凭观众对 Tesla Roadster 2 的反应来看，这款跑车的预订量也不会让特斯拉失望。

除此以外，马斯克本人也在经营一些小本生意。此前我们就报道过特斯拉推出的充电宝，外形与特斯拉充电桩相似的移动电源刚在官网上线就宣告售罄，足以让特斯拉小赚一笔。更早之前，马斯克旗下另一公司 The Boring Company 推出了一款周边鸭舌帽，日前马斯克在推特上宣布，这款鸭舌帽已经带来了 200 万美元的营收。

然而比起 Model 3 生产所需的资金，这些充其量都只算是「零用钱」，对特斯拉来说，真正能帮助到它的，还是资本市场的直接支持，一旦特斯拉和马斯克无法自圆其说，资本「翻脸不认人」，这对特斯拉来说将是毁灭性的打击。

在 11 月初的致股东信中，特斯拉表示他们仍有充足的资金，足以完成明年 3 月前生产 5000 量 Model 3 的目标，但这对于 Model 3 超 40 万的订单来说，当然远远不够。当少数供应商恢复了零部件的供应，松下部分电池的自动化生产线准备就绪之后，挺过 Model 3 的难产期，相信 Tesla 才会有更多的现金流涌入，摆脱目前的「消耗」状态。

股价的趋于冷静，也许只能说明人们对于马斯克带来的这些「前置刺激」已经逐渐麻木，相反反而是会更理性且冷静的看待，而发布会上马斯克展现给我们的那般美好，只有马斯克真正将他的上一个宏图 Model 3 落地之后，也许才能再次点燃我们的期待。

虽然特斯拉在过去几个月里勉强撑了下来，但它和马斯克的挑战才刚刚开始。
