**摘要：16 年后，又见微软 IE3.0。**

  

出生于 2001 年，微软的 IntelliMouse Explorer 3.0（IE3.0）可能是鼠标历史中最经典的一款产品之一。

凭借和意法半导体合作研发的 IntelliEye2.0，IE3.0 拥有当时几乎独步天下的 400DPI、6000 FPS 的超高规格。更神奇的是，虽然 IE3.0 最初并不是定位于一款游戏鼠标，但顶级的参数、舒适的设计让 IE3.0 成为了当时 CS 玩家手中的「神器」。

之后，在 2006 年，微软推出了 IE3.0 的复刻版，DPI 不变，FPS 提高到 9000。

2017 年，在距离 IE3.0 发布 16 年后，微软又推出了一款 IE3.0 的「复刻再复刻版」——微软 IE3.0 蓝影增强版，我们一起来看一下这款产品。

![](../Images/8b34179285bb62d230fb372e302841b6.png)

包装盒上情怀满满的 Classic IntelliMouse。

![](../Images/5a285409f9f27b0e71f3deefa7140eef.png)

![](../Images/52a35a9031c48060683882379497f4be.png)

宽大舒适的右手造型、侧面的橡胶，都让 IE3.0 蓝影增强版很有些当年 IE3.0 的感觉。

![](../Images/4e861870475fe880c9d3e7645d7f5d5b.png)

IE3.0 蓝影增强版的体积较大，两个按键的微动做得比较硬。

![](../Images/338eac5b68ea40e8c8a279e589442ba7.png)

在 IE3.0 蓝影增强版的侧面，可以看到一大一小两颗拇指键。

![](../Images/2c387926ea5ea690ef341ccda00ac092.png)

使用 Microsoft 鼠标和键盘中心，可以对大小拇指键、滚轮键等功能进行调节，不过仅限于 Windows 系统。

![](../Images/6b92251ab1768d97306ec21e9fa8e422.png)

IE3.0 蓝影增强版采用了枪灰配色，比苹果 MacBook、小米笔记本 Pro 等产品上用的深空灰颜色略深，这也和当前 Surface 系列的整体风格相符合。在鼠标底部，IE3.0 蓝影增强版改成了淡雅的白色，使用时会一直点亮，鼠标从桌面拿起后会慢慢熄灭。

![](../Images/b9dd47f10ac39035a314954aaf0256d3.png)

鼠标内部，微软 IE3.0 蓝影增强版采用了自家的蓝影追踪技术传感器，可以在包括玻璃在内的各种材质表面无障碍使用。另外，IE3.0 蓝影增强版的 DPI 最高可以到 3200，鼠标报告率也达到了 1000Hz，不过 FPS 仅有 3000，这意味着 IE3.0 蓝影增强版无法像曾经的 IE3.0 那样，「顺便」成为一款优秀的游戏鼠标。

![](../Images/87cb5b6f7078bf007df1d439d45b1a48.png)

最后，IE 3.0 蓝影增强版的售价为 349 元，大家愿意为这款情怀满满的鼠标「充值」吗？ ■
