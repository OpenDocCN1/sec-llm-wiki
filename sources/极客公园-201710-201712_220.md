# 特斯拉推出充电宝，终于能买得起特斯拉的产品了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850730&idx=4&sn=44f3a79ff0fb3045f88254fb62696cac&chksm=7e6a379c491dbe8ad2c7d83fd273573de2e0724df53e0c4b0f6bda43dd6c6b7b32f28430d3cc&scene=126&sessionid=1681311092#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850730&idx=4&sn=44f3a79ff0fb3045f88254fb62696cac&chksm=7e6a379c491dbe8ad2c7d83fd273573de2e0724df53e0c4b0f6bda43dd6c6b7b32f28430d3cc&scene=126&sessionid=1681311092#rd)

![](../Images/0cc08bf66f16e8c62fdff680ac4a9575.png)

  

**摘要：据悉，该充电宝的设计灵感来源于特斯拉的「超级充电桩」。**

  

上周五，特斯拉发布了全新的电动卡车和电动跑车。除此之外，特斯拉还推出了一款比较有意思的产品：特斯拉充电桩主题的移动电源。

![](../Images/93a8e9ec4cf9d1b340bbf0cd53beebe9.png)

这款移动电源采用了特斯拉充电桩的外形设计，一眼看上去，就如同一个「迷你」型的「超级充电桩」。移动电源使用了银、黑、红三种配色，移动电源的主体为黑色，中间的特斯拉标志为银色，两边的数据线为红色。据悉，这款移动电源的外形设计是特斯拉在设计「超级充电桩」时突然想到的。

移动电源的左右两侧集成了苹果 Lighting 接口和可拆卸的 Micro USB 接口，但是较为遗憾的是并没有 Type-C 接口。而当数据线不使用时，可放入移动电源主体内部。此外，这款移动电源的尺寸为 108 x 30.5 x 23.3mm，如此小巧，可以直接装进口袋。

特斯拉移动电源技术规格：

*   单节 18650 电池，容量 3350mAh
    

*   输入：1800±200mA
    

*   输出：5V/1.5A 最大
    

这款移动电源售价为 45 美元，折合人民币约 300 元。不过根据特斯拉官网的信息，目前这款移动电源已经售馨。如此看来，这款移动电源还是很受欢迎的。

虽然能够买得起特斯拉的产品了，但不得不承认这款移动电源比目前市场上其他的移动电源要贵不少。
