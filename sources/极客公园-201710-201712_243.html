摘要：「这样做的关键是要给燃油汽车一个『巨大的打击』」马斯克指着新「Tesla Roadster」说。


这个世界真的需要一辆「Tesla 电动卡车」吗？

Musk 的回答当然是肯定。自从 Musk 扬言要推出一款大型的电动卡车，业界的各种猜测不断，Tesla 这辆卡车的受关注程度并不亚于未发布的 iPhone 手机。

今天又是一场「闪电」般的发布会，Musk 不仅兑现了之前的诺言，诸如：「卡车的规格比目前媒体预期的还好」、「史上最高的载重和长距离续航」、「感觉像一辆跑车」等等。

他更是难得为我们带来一个「One More Thing」，一辆百公里加速时间突破 2 秒的超跑——全新的「Tesla Roadster」。



如何重新定义「电动卡车」？

1、「增强版」自动驾驶卡车

很多人没有意识到的是，相比家用汽车，具备完全自动驾驶功能的卡车会更快来到我们身边。

这主要是因为固定场景和固定路线，已经降低了复杂度，同时特别是高速公路相比针对复杂城市道路而言更加可控，出现突发情况的几率大大降低。所以卡车就成为了自动驾驶研究的「前线」。

这一次 Tesla Semi 为我们带来了「增强」的自动驾驶功能：

  • 自动紧急制动

  • 自动车道保持

  • 前方碰撞警告

而在「电动卡车」这个领域中 Tesla 也一定希望自己成为少数的自动驾驶「引领者」之一，虽然这次 Musk 并没有一度强调「无人驾驶」，但却是为卡车司机更方便的驾驶辅助功能。

取消了大型的传统卡车后视镜，Tesla Semi  将通过安装在车外的摄像头显示卡车侧面的图像。Musk 说，这些也是自动驾驶系统的一部分（也有安装在挡风玻璃底部的面向前方的摄像头等一系列传感器），期待未来的自动驾驶软件「升级」。

值得注意的是，Tesla Semi  除了将搭载自动驾驶功能之外，还会拥有一个全新的「排队功能」，简单来说就是第一辆车还是会有司机，但之后的整个车队都是以排队的功能进行自动驾驶，感觉像通过自动驾驶来实现「高速公路上的火车」，相比于物理连接，这样的车队更加灵活，同时这项功能也更可靠，而且可能很快就能真正落地。

2、突破预期的「长距离续航」和「快充」

「这是一个重型、远程、半挂牵引卡车，它具有最高的载重和长距离续航。所以这是之前从来没有过的汽车，但在今天是可能的。一辆电动卡车实际上输出的扭矩可以胜过任何柴油卡车，如果有一场拔河比赛，Tesla Semi 甚至能拖拽柴油卡车上坡。」Musk 在没发布 Semi 时曾说。

结果确实突破了我们的预期。

Musk 承诺 Tesla Semi 的重型版本可以提供 300 英里（约 482 公里）或 500 英里（约 800 公里）的两个续航范围，同时空载情况下，百公里加速时间只需要 5 秒，即便是 80000 磅的载重下也只需要 20 秒。

同时 Tesla Semi 可以在 30 分钟内增加 400 英里的续航，Musk 说「你只需要休息一会，卡车就充电完成，你不需要一直等待你的卡车充电。」

他之后还补充说到，Tesla Semi 将使用 4 个 Model 3 的电动机，在试驾原型车的时候这辆卡车「感觉像一辆跑车」。

3、变革卡车行业？

「电动卡车」可以显著降低卡车公司的燃油和维护成本。所以即便由于大型电池组的价格较贵，虽然导致车的单价上涨，但却可以快速收回成本，更快的实现投资回报，而这只是改变物流行业的一小步。

传统柴油卡车的平均成本为每英里 1.51 美元，而 Tesla Semi  则只需要每英里 1.26 美元。

同时，Musk 保证说，Tesla Semi  将有 100 万英里的保修，而刹车片将有「准无限」「quasi-infinite」的使用寿命，惊喜之余，不得不说真的和罗老师一样严谨。

4、设计和安全

从 Model S 「自动弹出」的门把手，到 Model X 自动开启的鸥翼门、标志性的 17 吋触控屏幕等，特斯拉早已经用独特的设计潜移默化影响我们对现代汽车的审美了。

这一次 Tesla Semi  带来了全新的设计，也沿用了 Model  3 的很多设计。

首先就是取消了传统的卡车座位布局，车内变为了单独的座位，同样没有仪表盘，取而代之的是两个 Model  3 一样的中控大屏。Tesla 接下来需要做的可能是让卡车司机养成习惯坐在驾驶室的中间。

左侧的屏幕用于控制车辆功能和特定于主要设置，而右侧的屏幕具有更典型的导航和无线控制功能。特斯拉也表示，未来这些都可以自由配置。

同时，在安全性方面，Tesla 提供了更加坚硬的前挡风玻璃「Tesla armor glass」，来保护驾驶员的安全。

5、价格

虽然没有公布价格，但和 Model 3 一样，你可以花 5000 美元来预订这款卡车，预计 2019 年量产。

这个还未出生的「卡车选手」早已经有了很多虎视眈眈的对手。在 Semi 发布之前，康明斯（Cummins）抢先推出了首款电动卡车原型 AEOS， 大众宣布将斥资 17 亿美元将电动卡车和电动公交车快速推向市场。 就在前几周，戴姆勒也推出了一款续航达 220 英里的全电动卡车概念车。

但从数据来看，Tesla Semi 为我们带来了更多的亮点，这能够更有利的去说服「货运行业」去做出改变，产品总会带来惊喜，但未来的量产却是 Tesla 需要解决的困难。

Tesla 也许想用这款「电动卡车」重新定义另一个细分市场，而不是仅仅为了帮助货运行业遵守更严格的排放法规。


有史以来最快的量产汽车？

作为「One More Thing」，Musk 带来了一辆百公里加速时间突破 2 秒的全新「Tesla Roadster」。

这辆 Tesla Roadster 2，能够在 1.9 秒内完成百公里加速，这几乎是燃油汽车无法企及的加速度。

它还拥有一个 200KWH 的电池组，能够实现 620 英里（ 997 公里）续航范围，并且这辆车最高时速超过 250 英里每小时（400公里每小时）。

「这样做的关键是要给燃油汽车一个巨大的打击『hardcore smackdown』」 Musk 说。

这辆车拥有四个座位，并将在 2020 年量产。

这次发布会，Musk 仿佛是想再一次掀动「电动汽车」的革命，变革更多的细分领域，同时用全新的「Tesla Roadster」给燃油汽车行业再一次敲响警钟。

当然，Musk 也可能是不想再看到已经持续了几个月的 Model 3 难产的报道了。
