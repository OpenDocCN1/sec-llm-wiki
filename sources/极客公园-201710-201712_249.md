# iPhone X 又被破解了？这并不是 Face ID 的重点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850649&idx=1&sn=90ea6580009b8aeb7c5d1a41a08f6f35&chksm=7e6a346f491dbd79ecfcb2d7bf80f92dac9b8bc8f04ee3335349dd1fd4fd44f426683b7dd484&scene=126&sessionid=1681311095#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850649&idx=1&sn=90ea6580009b8aeb7c5d1a41a08f6f35&chksm=7e6a346f491dbd79ecfcb2d7bf80f92dac9b8bc8f04ee3335349dd1fd4fd44f426683b7dd484&scene=126&sessionid=1681311095#rd)

**摘要：全世界都在尝试破解 iPhone X 的人脸解锁，但 Face ID 给手机交互带来的革新或许更值得我们关注。**

  

自从苹果发布会之后，iPhone X 所搭载的 Face ID 人脸识别功能就在科技圈引发了广泛讨论，围绕它背后的原理、安全性已经衍生出诸多的话题。  

人脸解锁此前在 Android 领域已经有不少应用了，但对于苹果来说还是第一次，而且作为 iPhone X 上完全替代指纹解锁（Touch ID）的安全方案，各种破解 Face ID 的新闻想必很容易挑逗到大众的神经。

近日，一家越南的安全公司利用 3D 面具模型成功「欺骗」了 Face ID，让人们对于 Face ID 安全的关注再次达到了一个高潮。在此之前，双胞胎解锁同一部手机，亲兄弟「骗过」Face ID 的新闻也屡见不鲜。

这些破解操作中不乏一些故意「刁难」Face ID 的情况，更何况其中有一些新闻并不能确定真假，其实很难和大众的真实使用场景产生关联。回想指纹识别刚普及的时代，是不是也出现过很多类似的「破解」新闻呢？

在大家的注意力被「带跑偏」的情况下，Face ID 给手机体验带来的革新反而容易被我们忽略。

  

## 用了就回不去的「无感体验」

在具体的使用场景上，Face ID 可以替代 Touch ID 的所有功能，包括解锁屏幕、Apple Pay 和 App Store 消费等。不过各位 iPhone X 用户稍加留心的话，应该会发现 Face ID 其实新增了一个 Safari 的自动密码填充的选项。

![](../Images/0fb99149050048c5e6fb58b41b2b5323.png)

iCloud 钥匙串并不是一个新鲜的功能，它最早出现在 iOS 7.0.3 系统中。在打开钥匙串功能后，我们并不能直观感受到它的存在，因为苹果非常完美地将它融合进了 Safari 浏览器内，只有在网页进行登录注册操作时才会看到它。

在 Face ID 出现之前，用户登录网站时，钥匙串会在键盘上方出现「自动填充密码」按钮，点击才可自动填充密码。而 Face ID 的出现进一步简化了这个过程——iPhone X 用户只要看着屏幕，Safari 就可以自动输入存储的信用卡或密码信息，整个过程中手指与屏幕不需要接触。

![](../Images/585313ed4229d3fca75c7565d1bbde64.png)

像 iCloud 钥匙串这类密码管理软件的出现，帮助我们简化了「逐个输入密码」的过程，而 Face ID 直接连触摸的操作都省了。这种自然、无感的交互体验在锁屏查看通知界面也能体现。

单从解锁速度的角度衡量，Face ID 和指纹识别相比并没有优势。主要原因有两个：当我们从兜里掏出手机时，指纹识别可以进行「预操作」，但使用 Face ID 时必须把手机「完整掏出来」才行。另外 Face ID 解锁后并不会直接进入桌面，仍然需要一步上滑的操作（避免只想看时间时解锁手机）。

Face ID 关注的重点并不是「解锁」本身，而是解锁之后的信息呈现。

当开启「显示预览：解锁时」这项功能后，诸如短信、邮件这些通知在手机解锁前都不会显示详情，起到保护隐私的作用。iPhone X 一旦「发现」是你本人在看它的时候，就会自动显示通知详情，点击既可进入对应的 app 内。

不论是 Face ID 解锁 iCloud 钥匙串，还是 Face ID 解锁查看通知详情，免除的是手指与屏幕之间的交互，进一步简化了操作手机的流程。为了实现这种建立在眼镜和屏幕间的交互，苹果宁愿在屏幕的上方留出了一块「刘海」的空间。

  

## 更加主动的安全验证方式

此前在 Android 领域，一些手机厂商已经基于普通摄像头做出了 2D 人脸识别的方案。而 Face ID 有所不同，它识别的是用户整张脸的 3D 模型，正是更多维度的信息把人脸识别的安全性和可拓展性提升到了更高的级别。

Face ID 所使用的红外结构光可以追溯到微软的体感设备 Kinect 上。不过 Face ID 更专注于脸部轮廓，利用镜头和感应器扫描出面部的 3D 深度图，借此达到验证身份的效果。

此前 Face ID 一度被认为是苹果在屏下指纹难产的情况下妥协的产物，但回顾苹果这几年的收购情况便可以看到，苹果很早便开始了人脸识别的技术布局。

苹果在 2013 年收购了为 Kinect 提供技术支持的 PrimeSense 公司；而为了在「识别」之外更加准确地捕捉用户的状态，苹果还曾收购了一家名叫 SensoMotoric Instruments 的眼动追踪技术公司。

![](../Images/440dc9898cfea367e0f35accbc9ceddb.png)

iPhone X  常被吐槽的「刘海」中共有八个传感器，包括：距离感应器、环境光传感器、扬声器、麦克风、700 万像素摄像头、点阵投影器、泛光感应元件、红外镜头。其中和 Face ID 相关的至少有四个传感器。

如果再加上「抬腕唤醒」所使用的运动传感器（重力、陀螺），以及学习人脸变化所使用的 A11 仿生处理器，Face ID 或许是 iPhone 中可调用硬件、算法资源最多的功能之一。

更进一步来说，Face ID 为手机赋予了更加主动验证身份的方式。当我们拿起手机时便自然构建了一个实时检测的环境，手机可以主动地去执行一些操作，人机交互融入到了基础的操作中。

如果说指纹解锁是当下安全验证最为成熟的方案，那 Face ID 所代表的是一种实时、无感的未来交互方式，也是比「解锁」更值得我们去关注的地方。
