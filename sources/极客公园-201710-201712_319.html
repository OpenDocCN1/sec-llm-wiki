入口、用户问题逐渐解决后，微信开始给开发者谋福利了

摘要：小程序开放三个新能力：公众号底部广告位向小程序开放、「小程序开发助手」发布、开发者工具支持 PHP 语言。


腾讯在成都举办了全球合作伙伴大会，微信生态自然是最受关注的领域之一，而作为微信今年主推的新产品，小程序的动态备受瞩目。就在昨天，大会上承诺的三个小程序新能力已经正式推出：公众号底部广告位向小程序开放、「小程序开发助手」发布、开发者工具支持 PHP 语言。


公众号底部广告位开放

对于急需推广的小程序来讲，这次最重要的新功能自然是公众号底部广告位的开放。微信公众号的生态已经较为成熟，文章底部的广告位可以为品牌、公众号、移动应用等进行推广，广告主借力公众号资源大量获客，公众号运营者也多了一种变现的方法，而现在这个资源终于也向小程序开放。

根据不同的投放需求，小程序广告可以以图文、图片或优雅大图的形式显示在文章底部（目前电商推广暂只支持图片形式），用户点击广告可直接跳转至相应小程序。

图片来源：微信公众平台

此前小程序已经可以通过嵌入文中的形式「借力」公众号，而这次底部广告位的开放则给了小程序更直接的推广渠道，公众号依然是小程序最重要的入口。


发布「小程序开发助手」

「小程序开发助手」主要是方便了开发者，通过它可以更直接地预览小程序。小程序在公开上线，也就是推出正式版本前，还要经过开发者测试用的开发版、小规模内测的体验版，此前它们都散落在小程序列表中，只能通过标签识别，而现在开发者可以在「小程序开发助手」中看到。

此前想要预览开发中的小程序，只能通过扫描特殊的二维码进入，而现在，每个开发人员都可以直接在「小程序开发助手」直接打开，这里还会显示小程序的版本状态、上传日期、大小等信息。

对于每天要测试各种小程序的开发者来说，开发助手提供了一个更为直观的管理工具。


新增 PHP 语言支持

开发者的另一个福音就是，开发者工具新增了 PHP 语言的支持。程序员终于可以用「世界上最好的语言」来开发小程序了。

此前开发者工具已经支持 NodeJS 环境，开发者可以在腾讯云提供的框架中方便地搭建后台，此次 PHP 语言的加入对小程序开发者来说，无疑提供了更大的便利。

腾讯在全球合作伙伴大会上开放小程序三大功能，明显是在给开发者打强心剂，在入口、用户逐渐解决之后，小程序需要更多开发者的加入来壮大整个生态。
