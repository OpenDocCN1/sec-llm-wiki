# 屏下指纹彻底没戏，三星 S9 拿什么对抗 Face ID？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850428&idx=3&sn=cbe325039e686f8abecee1ad7096f5de&chksm=7e6a354a491dbc5c116c3398d58fccc82948820526fb6586e737883cb2cf947ddd480f2215e4&scene=126&sessionid=1681311101#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850428&idx=3&sn=cbe325039e686f8abecee1ad7096f5de&chksm=7e6a354a491dbc5c116c3398d58fccc82948820526fb6586e737883cb2cf947ddd480f2215e4&scene=126&sessionid=1681311101#rd)

![](../Images/f54f649965952b92132c53407dc19cea.png)

  

**摘要：明年夏天之前，安卓手机的用户还是只能把手绕到全面屏的后方进行指纹解锁，或者严丝合缝的将双眼放到虹膜识别的两个圈圈里。**

  

拿到 iPhone X 的同学，现在应该已经习惯了举起手机，往自己脸上射数千个 Mark 点的解锁方式了吧。凭借新的深度摄像头方案，苹果的 Face ID 成功挤下 Touch ID 成为新一代解锁技术。另一边，安卓阵营目前依然看重指纹识别方案，而随着全面屏成为标配，「屏下指纹识别」技术也成为未来安卓旗舰机型的首选。但是，这个升级过程可能没那么简单。

近日，外媒曝光称三星明年的旗舰机 Galaxy S9 系列手机，已经正式放弃屏下指纹方案，将继续采用背后指纹解锁方案。而即便是目前凭借 Face ID 先胜一筹的苹果，也曾经挑战屏下指纹技术并不幸失败。所以，屏下指纹技术到底有多难，竟然让这么多科技巨头折腰？

目前，指纹识别解锁已经成为大部分智能手机的默认方案。从技术角度来说，目前指纹识别有电容、光学和超声波等几种解决方案。而从 iPhone 5S 开始，电容指纹识别方案成为主流，目前几乎所有手机的指纹识别都是电容方案。其工作原理是，利用手机 Home 键或机身背部的电容传感器，来采集使用者手指纹路信息。在电容方案中加入热敏传感器，就能实现活体检测功能。

体积小、成本低廉且解锁迅速，电容方案因此成为智能机的首选解锁方式。不过，自从三星的 Galaxy S8 开始普及「全面屏」概念，前置电容指纹识别方案就遇到了问题：很难在屏幕下放置电容指纹识别传感器来识别用户指纹。

![](../Images/5b8f4efdb25d4689456664b2fe89d732.png)图片来自苹果官网

电容方案折戟，很多公司只能将精力放在其他穿透力更强的解决方案上，例如超声波和光学方案。光学方案指的是，在屏幕下方设置光学传感器，通过发出近红外光来识别用户的指纹纹路，其思路和苹果的结构光方案类似。而超声波方案，顾名思义，就是在屏幕下方设置超声波传感器，通过超声波完成指纹识别工作。

在手机业内，两种解决方案都有追随者。今年 2 月的 MWC 大会上，深圳的汇顶科技就展示了搭载光学指纹识别方案的三星 S7 Edge 等机器，不过这个方案尚不能量产。

超声波方案的践行者，是目前正在风口浪尖的高通公司。根据高通提供的数据，其研发的超声波屏下指纹识别技术可以穿透 1200 微米厚的 OLED 屏幕、800 微米的玻璃和 650 微米的铝合金。今年 6 月底，vivo 公司曾经展示了搭载高通超声波指纹方案的原型机，不过现场体验并不尽如人意。据高通的说法，超声波方案依然存在体积大、识别率和识别速度低的问题。

汇顶科技董事长张帆近日在媒体采访时曾经表示，公司的屏下指纹技术依然在研发中，而此前团队在这项技术上的投入已有三四年时间。不过，张帆并未透露其屏下指纹技术的真正量产时间。有媒体透露，高通的超声波指纹识别方案可能在明年年初成熟，最早量产也要等到二三季度。这就意味着明年年初发布的三星 Galaxy S9 注定无缘屏下指纹方案，而可能在秋季发布的 Galaxy Note 9 则有机会率先采用新的解决方案。

![](../Images/521b9f083a35a777c6b2d7b99f9ba8fe.png)图片来自苹果官网

在屏下指纹方案之外，不少行业内领先公司也已经开始研发类似 iPhone X 的 Face ID 的 3D 面部识别方案。高通和奇景光电（Himax）、Orbbec、Mantis Vision 都在尝试 3D 识别技术。台湾 KGI 分析师郭明池预测，未来两年内搭载 3D 识别技术的安卓机出货量是使用屏下指纹手机的 2 到 3 倍，其中一个重要的原因是屏下指纹必须配 OLED 屏幕，而 3D 技术则可以搭载 OLED 或者 LCD 屏幕。但是，郭同时也透露，安卓手机要想复刻 iPhone X 的面部识别水平，还需要两年半时间。

所以，明年夏天之前，安卓手机的用户还是只能把手绕到全面屏的后方进行指纹解锁，或者严丝合缝的将双眼放到虹膜识别的两个圈圈里。
