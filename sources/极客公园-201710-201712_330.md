# CES 2018 临近！那些科技大咖和未来变量都将在「极客之夜」闪耀

**摘要：CES 2018 将在明年 1 月 9 日如期到来，极客公园将继续派出报道团队亲临现场进行报道，同时我们也希望能够和前往 CES 的国内厂商和从业者们建立更为深入的联系。**

  

如果说每年秋季的苹果发布会是科技爱好者的「春晚」，那对于科技领域的从业者来说，能匹配这个称号的恐怕只有每年 1 月初在美国拉斯维加斯举办的 CES 展会了。![](../Images/ad374e2390e4def34bbaa73bb53b9e4f.png)

相比 MWC、IFA 等国际型展会，CES（国际消费电子展）所涉及的科技品类要更加丰富，「技术型驱动」的特点也更为明显。每年年初在 CES 上亮相的新产品和新技术往往会左右未来一年甚至多年科技产品的走向，可以说是全球科技发展的风向标。

![](../Images/bafec0899c103983baa5f3ef875f92e6.png)

CES 2018 将在明年 1 月 9 日如期到来，极客公园将继续派出报道团队亲临现场，为大家带来第一手的高质量报道。除此之外，我们也希望能够和前往 CES 的国内厂商和从业者们建立更为深入的联系。

CES 2018 依然包含 Tech East、Tech West 和 Tech South 三大场馆，而根据 CES 官方公布的数据，CES 2018 将会迎来超过 3900 家参展商，参展人数预计将达到 17 万人。

对于参展者来说，如何能够从众多参展商中脱颖而出，对外释放出更大的商业价值，是每年参加 CES 都需要额外关注的地方。而对于观展者来说，更高效地看展，更准确地捕捉产业脉搏，意味着展前需要做足充分的功课。

![](../Images/8d348deccc54695a7dc87b04c3a1fa14.png)

作为国内对于 CES 展会关注程度、投入资源最高的内容团队之一，极客公园一方面将 CES 上的最新的科技产品介绍给国内的读者，一方面也在帮助国内优秀的从业者和参展商在 CES 上更高效地完成「信息交换」。

目前极客公园已经开始了 CES 2018 的筹备活动，我们将在明年 1 月 CES 期间进行两项特别的活动：发布 **CES 2018 极客版观展指南**和举办**「极客之夜」**活动。

  

## CES 2018 极客版观展指南：让你不只看热闹

在 CES 开展前，极客公园将制作并发布 「CES 2018 极客版观展指南」，除了提供展会看点、技术趋势等基础信息，我们还计划收录最值得关注的 50 家技术创新参展企业的信息和具体看点，希望通过我们的努力能够打破参展商和观展者、媒体之间的信息壁垒。不让大家只是看热闹，进而迷失在巨头的酷炫展区，而真正找到那些代表未来的「新可能性」。

极客公园会根据参展产品和技术的重磅程度、行业影响力等多个角度进行评判，从 CES 的所有参展商中筛选出最值得关注的 50 家科技创新公司，并会特别关注来自中国的企业。当然，我们也很欢迎你进行推荐和自荐，让我们不错过每一个优秀的力量（点击**「阅读原文」**或扫描下方二维码报名）。

![](../Images/5210bd5f239c01bbd65b304fcfd0fcdc.png)  

## 在「极客之夜」，科技领袖带你看未来

在展会之外，每年 CES 期间还会举办数百场的场外活动，而很多合作的达成、灵感的迸发往往是在这些场外活动上诞生的。极客公园已经连续两年在 CES 期间举办了晚宴活动，而今年我们将升级为「极客之夜」，迎来众多科技大咖的参与。

「极客之夜」作为国内外科技精英闭门交流论坛， 将是国内科技圈每年最被期待的极客公园创新大会的一个「预告片」和 CES 分会场，这个仅限受邀参与的闭门交流，是 CES 上数一数二的全球科技创新企业的 CEO、CTO 的聚会。

![](../Images/fcf2d89a42616f581cca6d6ef45d3985.png)

在「极客之夜」活动上，极客公园将邀请多位全球科技行业的领袖，解读过去一年科技互联网领域的关键节点，也分享他们从 CES 感受到的趋势。毕竟你懂的，CES 上全球很多科技大神都会去，但在极客之夜你才有机会看到「他们看到的未来」。

对了，「极客之夜」也将为 CES 2018 观展指南中收录的 50 家参展商提供与世界级巨头和合作伙伴线下「面基」的宝贵机会，我们也会邀请最优秀的国内外科技媒体旁听「极客之夜」那些火花四溅的碰撞和预言。

*   **时间：**2018 年 1 月 9 日，19:30  
    
*   **地点：**拉斯维加斯凯撒宫酒店 Caesars Palace, Las Vegas （3570 Las Vegas Boulevard, South, Las Vegas, NV 89109）
