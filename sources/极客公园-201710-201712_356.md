# 101 分，iPhone X 拿下 DxOMark 拍照单项最高分

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850316&idx=5&sn=8d6893e3d2eeb7e741e2302f45e655a3&chksm=7e6a353a491dbc2c391a32cb8559ba53533dac61f11351ea0693ac17673b41d48058852588e2&scene=126&sessionid=1681311104#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850316&idx=5&sn=8d6893e3d2eeb7e741e2302f45e655a3&chksm=7e6a353a491dbc2c391a32cb8559ba53533dac61f11351ea0693ac17673b41d48058852588e2&scene=126&sessionid=1681311104#rd)

**摘要：iPhone X DxOMark 拍照成绩新鲜出炉，101 高分使得苹果手机再度超越安卓旗舰，成为手机拍照霸主。**

  

手机的拍照表现一直是人们选购手机时的重要指标，在这一方面，苹果手机似乎一直是业界的标杆，但随着安卓阵营的崛起，苹果手机在拍照方面的地位一直受到安卓旗舰机的挑战——近年来 DxOMark 手机拍照排行榜前列更多是安卓手机的身影。前不久谷歌 Pixel 2 更是以拍照成绩 99 的高分「霸榜」，这让其他品牌的手机望尘莫及，要超越它岂不是要拿下 100 的高分？  

然而，现在有款手机真的做到了, 那就是开售不久的 iPhone X。根据专业相机评测机构 DxOMark（http://t.cn/RlK9aki）日前公布的最新智能手机分类的排行榜单，iPhone X 在拍照部分以 101 分的成绩超过了 Pixel 2（99 分），在综合成绩方面，iPhone X 得分与 Pixel 2（98 分）极为接近，为 97 分，和华为的 Mate 10 Pro 并列。

![](../Images/9c7ccc49b5471dd9bc86ccb52e39cb5d.png)

![](../Images/d866613f5ddbed514f0a903e615e666d.png)

从上图中可以看出，iPhone X 在拍照方面取得 101 高分是手机拍照各项指标综合表现优秀的结果。对比来看，各项指标中，Pixel 2 在曝光、对比度，色彩和自动对焦方面要优于iPhone X。而 iPhone X 在噪点控制、缩放变焦以及景深方面更有优势。不过，从图中也不难发现 iPhone X 在拍摄视频方面的表现要逊于 Pixel 2。

毫无疑问 iPhone X 这次为苹果手机的拍照体验赢回了「面子」。如果你有购机换机的打算并且对手机拍照性能要求较高，那么当下 iPhone X 就是你的不二之选了。■
