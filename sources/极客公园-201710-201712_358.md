# 为了特斯拉有更多「机器人员工」，马斯克又收购了工厂自动化公司 Perbix

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850316&idx=3&sn=1385484e348668e5d7937e1df1cc960b&chksm=7e6a353a491dbc2c1bbba50624b268faac72acbe2201f10caa7894192a2c96ec5e8655ba2c35&scene=126&sessionid=1681311104#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850316&idx=3&sn=1385484e348668e5d7937e1df1cc960b&chksm=7e6a353a491dbc2c1bbba50624b268faac72acbe2201f10caa7894192a2c96ec5e8655ba2c35&scene=126&sessionid=1681311104#rd)

**摘要：对于想要实现到 2020 年每年生产 100 万辆汽车计划的 Tesla，现在的这笔收购确实非常「超值」和「解渴」。**

  

特斯拉今天证实，他们收购了工厂自动化设备制造商明尼苏达州的 Perbix 公司，试图通过在工厂实现更多自动化来提高产能。  

这是特斯拉在工厂自动化领域的第二次收购，去年特斯拉 1.35 亿美元收购了 Grohmann 工程公司。这次收购也导致了「特斯拉高级自动化事业群」的成立。

特斯拉在今天的声明中（来源：明尼苏达州的明星论坛报 Star Tribune）确认了这项新收购：

> 近三年来一直是特斯拉供应商的 Perbix 公司已经完全集成到 Tesla 中，并且在一系列极其复杂的自动化项目中完美地完成了工作。展望未来，我们将继续扩大我们在两个城市地区的业务并招募人员，继续建造机器。

![](../Images/6a08721b7024edc5c2c5ae7a801bc041.png)

Perbix 于 1976 年由 Tom Perbix 创立，成为加工零件和组装设备制造商「Perbix Machine Co.」。Perbix 在 2001 年把公司卖给了现在的所有者 Jim Dudley。自那时起，该公司就开始专注为工厂自动化设备进行研发。

  

## 机器制造机器

「建立制造机器的机器」是特斯拉 CEO 伊隆·马斯克（Elon Musk）一直喜欢表达的一个观点，有趣的是，其实早在在特斯拉 2016 年股东大会，Musk 的另一家太空探索公司 SpaceX 的 CTO 汤姆·米勒（Tom Mueller）就曝出，Musk 关注的新焦点，除了利用物理学的「第一原理」应用于制造，它也正在研究可口可乐的无人化的制造视频，研究制造速度更快的潜力。

![](../Images/a754ff422cad457f34672c5ca0be008d.png)

特斯拉一直在内部建立这个团队，专注于工厂自动化，而且为了加快进程特斯拉还聘请了一系列外部公司来「帮忙」。其实在收购前，Perbix 已经在特斯拉工厂合作工作三年了。特斯拉公司表示，Gigafactory 电池制造工厂内也早就有 Perbix 的设备了。

Perbix 公司雇用了 150 多名员工，「它提供了定制自动化系统和印刷系统的完整设计和制造」。特斯拉并未透露收购条款，但表示「不会对其财务业绩产生重大影响」。

特斯拉目前正在通过位于加利福尼亚州的「Fremont」和内华达州的「Sparks」的两个工厂扩大生产。

![](../Images/52f3fc725571d73f222676ee1a559ab5.png)

特斯拉最近因为 Model 3 的「难产问题」而受到质疑，说 Tesla 生产线的自动化水平不够。特斯拉回应说，他们在所有生产线上都有「手动和自动化流程」，就像任何一家其他汽车制造商一样，他们预计整个 Model 3 的生产将成为有史以来最为自动化的汽车生产项目之一。

Musk 也在自己的 Twitter 上将特斯拉工厂未来的生产线形容为「Alien Dreadnought（外星人无畏战舰）」，因为它看起来更像是一个来自另一个世界而不是工厂，现在看来 Musk 又离他的这个愿望更近一步了。

去年，Musk 将 Model 3 生产线称为「外星人无畏战舰 0.5」版本，并表示未来在特斯拉的「Fremont」工厂生产速度提高 20 倍。

而 Musk 的另一个关注点在于，工厂机器人能够将产线的「移动速度」提升到多快，在上周与分析师的电话会议上，他说：「如果你能看到他们移动，那说明他们的动作就不够快。」

![](../Images/97873c8605011901cc69dde9734d91ec.png)

Musk 表示 Model 3 的生产线只是他迈向终极目标中第一步的第一步，而未来生产 Model Y 的工厂才是「Alien Dreadnought」的第一个真实版本。

而更值得关注的一点是，Musk 提到在他未来的生产线上不仅仅是一味的提高自动化的程度，而是将反过来对于生产速度的需求直接构建到汽车的设计中来，例如通过减少车内布线的长度。这两点相互配合，也许才是 Musk 变革汽车行业的另一大「杀手锏」，这也是所谓的「智能制造」的真正奥义所在。  

虽然现在看起来特斯拉还远远没有达到预期的生产目标，但如果对于想要实现到 2020 年每年生产 100 万辆汽车的计划，特斯拉现在这笔收购是非常「超值」和「解渴」。

从「第一原理」到「机器制造机器」，再到 SpaceX 屡战屡败后的成功，Musk 证明自己的言论从「激进」到「靠谱」的时间越来越短，当未来迈过 Model 3「产能危机」这道坎，特斯拉该有多可怕？
