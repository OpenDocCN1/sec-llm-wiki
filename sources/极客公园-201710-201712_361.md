# 只要你还活着，戴着的这块智能手表就能「永不充电」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850295&idx=3&sn=b87146c7488d478647b52517c9ed83c4&chksm=7e6a35c1491dbcd7835fc66ccb90f0ebb95c79ca8420ad8d4a15275615c84189c7f292858a9e&scene=126&sessionid=1681311104#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850295&idx=3&sn=b87146c7488d478647b52517c9ed83c4&chksm=7e6a35c1491dbcd7835fc66ccb90f0ebb95c79ca8420ad8d4a15275615c84189c7f292858a9e&scene=126&sessionid=1681311104#rd)

**摘要：热电技术被运用得越来越广泛，也许能让我们摆脱智能设备续航差的尴尬。**

  

续航不给力一直以来都是智能手表的痛点，这也是人们更多使用手环的原因之一。而最近，一家名为 Matrix 的公司开发出的智能手表 PowerWatch 也许能解决这一问题，因为这一次，你可以用自己的热量为它供电。  

📹 [https://v.qq.com/iframe/preview.html?vid=d037482lg8d&width=500&height=375&auto=0](https://v.qq.com/iframe/preview.html?vid=d037482lg8d&width=500&height=375&auto=0)

不像一般的智能手表那样要一天或两天一充电，当你戴上 PowerWatch 之后，你将永远不用为它充电，因为它的能量来源于你体内的热量。  

![](../Images/fe2f36a1311e7179d372c8b16e18cce4.png)热电效应原理  

这一技术基于热电效应，在两种不同金属构成的回路中，如果金属结点处温度不同，该回路中就会产生一个温差电动势，从而产生电能。简单来说，就是由于温度差可以产生电能。所以当你戴上手表，体内的热量能够为手表提供发电所需的条件。

这不是热电效应的第一次应用，早在 NASA 的火星探测器好奇号（Curiosity）上就被使用。而在 PowerWatch 之前，日本钟表制造商精工（SEIKO）也发布过一款基于热电原理由体温供电的石英表。

![](../Images/8d066411e47aac468be6b59fb3c3d890.png)PowerWatch 有三种款式

PowerWatch 拥有一个黑白点阵显示屏，能够显示时间，监测热量消耗以及追踪睡眠，并且支持 50 米防水。由于是配合体热发电，所以在监测热量消耗方面具有一定优势，并且当没有佩戴时手表会自动休眠以保存电量。

![](../Images/4dc37abb6651d9202e814b77043fd8d4.png)

PowerWatch 官方表示手表不但改进了热电模块，并且使用了功耗更低的 AMBIQ 处理器，不过尽管不用充电，手表却显得有些笨重，它也许会成为一些极客爱好者的专属。目前 PowerWatch 仍在众筹，售价 99.99 美元起（约合人民币 663.3 元），如果你感兴趣，不妨去官方网站进一步了解 。
