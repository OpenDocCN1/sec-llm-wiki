摘要：摔过之后的 iPhone X 产生的结果可能会超乎你的想象，你的 iPhone X 真的摔不起。


从网上各路果粉发来的捷报来看，已经有很多人在上个月 27 日成功预订了 iPhone X，并成功在这个月 3 日首发当天拿到了心仪已久的新手机。心潮澎湃的同时，你也要把手机拿稳了，因为摔过之后的 iPhone X 产生的结果可能会超乎你的想象，你的 iPhone X 真的摔不起！


易受损坏的 Face ID

Face ID 是这代 iPhone 独一无二的优势，但却也可能成为最脆弱的「命门」。因为在手机摔落之后，即使屏幕后盖没有碎裂，也不能保证你的 iPhone X 完全没有问题，过于激烈的跌落可能会使手机的 Face ID 功能无法正常工作。

今年，iPhone X 在其内部设计上进行了很多的改动，尤其是在特别留出的那个「刘海」区域。这个区域中共有 8 个传感器，在这其中的点阵投影器、泛光感应元件、红外镜头、700 万像素摄像头、环境光传感器、距离感应器几个元件组成了原深感摄像头系统，而 Face ID 功能的实现就是依靠这个系统。

过于激烈的跌落特别容易让 iPhone X 的前置景深镜头出现问题，从而导致 Face ID 无法正常工作。而作为 iPhone X 上唯一的解锁技术，如果 Face ID 有了问题，那么你这部手机就真的要给你舔不小的麻烦了。


价格超出想象的玻璃面板

虽然号称 iPhone 上有史以来最坚固耐用的前后玻璃面板，但玻璃毕竟是玻璃，掉地上该碎还是要碎。

iPhone X 首次采用了 OLED 屏幕，如果这块被定义为「超视网膜」的屏幕摔碎了，那结果也不言而喻。根据苹果官方网站上的 iPhone 维修定价页面上的信息显示，仅屏幕的保外维修费用就为 2288 元人民币。

而对于后面的玻璃背板而言，iPhone X 的背板如同 iPhone 8 一样，在后盖的内侧多出了无线充电所需的感应线圈，且无线充电板与后盖是通过强力胶粘在一起的。如果背板一但破碎，那么无线充电模块很有可能受到影响。


建议购买 Apple Care+

综合来讲，如果你是使用 iPhone X 的用户，那么在日常使用过程中，务必保护好你的手机，因为一旦发生意外，导致屏幕、后盖破碎，或者 Face ID 功能受损，那么你就需要花费一笔不小的支出维修你的 iPhone X。

当然你也可以选择购买 Apple Care+，之后可以支付较少的费用来维修 iPhone X。根据苹果中国官网资料，Apple Care+ 用户拥有两次意外损坏保修服务，在 2 年有效期内，碎屏维修仅需要额外支付 188 元的维修费用，而对于 iPhone X 其他问题的损坏，也仅需支付 628 元的维修费用。

所以，你是使用 iPhone X 的用户，Apple Care+ 的这份保险建议购买，尽管其价格达到了 1688 元，堪比一台中端安卓机，但为你节省的可是一台安卓旗舰的钱呀。
