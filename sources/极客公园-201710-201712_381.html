俄公司欲打造飞行出租车，用不了多久就可以打「飞的」了

摘要：打造世界首辆飞行摩托车的俄罗斯制造商 Hoversurf 推出了一项计划，将打造五座飞行出租车 Formula Project。


描写未来世界的电影中，经常出现那些在城市上空往来穿梭又秩序井然的飞车，现在这已逐渐变为现实。

近日，打造世界首辆飞行摩托车的俄罗斯制造商 Hoversurf 推出了一项计划，将打造五座飞行出租车 Formula Project。

他们研发的这款飞行出租车体型较小，且可以在车位上实现垂直起降，如常规汽车一样停在车位上或者进入车库当中。Hoversurf 公司称，他们的目标是为业余爱好者和职业驾驶创造一个「极限运动设备」，他们希望这种交通方式有一天能够充分发挥其潜力，取代汽车成为日常交通工具。

这款飞行出租车将配备 52 个小型电动涡轮和折叠式机翼。而这种结构可提高安全性能，如果发现负责滑行的发电机部分发生故障，Formula Project 可像直升机一样着陆。如果负责垂直降落的发动机出现问题，Formula Project 则可像普通飞机一样着陆。

此外，Formula Project 搭载有计算机、安全系统、城市数字地图、GPS 以及无人机信号感应，可以监测到地面情况与其它飞行汽车。

这个「极限运动设备」充满电，一次可飞行 450 公里，最大航速为 320 公里每小时。据统计，Formula Project 飞行汽车造价约达 97000 美元。而研制人员称，这款飞行汽车将于明年升空。
