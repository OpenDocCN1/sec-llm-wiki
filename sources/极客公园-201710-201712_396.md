# 特斯拉又亏了 6 亿美金不算事，但马斯克真的需要人帮他一把

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652850184&idx=2&sn=655ca98189bcdae2348035d022b8a61c&chksm=7e6a35be491dbca88994b48a7916a4c33069957753fe6105d32873ab87a28c45a0f5e61a6496&scene=126&sessionid=1681311107#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652850184&idx=2&sn=655ca98189bcdae2348035d022b8a61c&chksm=7e6a35be491dbca88994b48a7916a4c33069957753fe6105d32873ab87a28c45a0f5e61a6496&scene=126&sessionid=1681311107#rd)

**摘要：****在 Model 3 持续难产这个影响股价的问题上，马斯克需要更专业的帮手了。**

  

特斯拉今天公布了 2017 财年第三季度财报。报告显示，相比去年同期的净利润为 2200 万美元，本季度特斯拉净亏损达 6.71 亿美元，此前第二季度特斯拉的财报显示净亏损达 3.36 亿美元，财报发布后，特斯拉股价应声下跌近 5%。  

  

## 一份亏损但不算难看的财报

![](../Images/ce7a56fa4bdcb66bfd8d60face8bfc72.png)马斯克在一场发布会活动中  图 | 视觉中国  

事实上，根据第三季财报内容来看，特斯拉汽车第三季度营收为 29.85 亿美元，高于去年同期的 22.98 亿美元；总营收成本为 25.36 亿美元，高于去年同期的 16.62 亿美元。

从具体的成本支出来看，特斯拉主要亏损问题出现在持续投入的基础设施建设和 Model 3 的配套生产设施方面。而在汽车、太阳能主业务上营收同比去年和上季度基本持平甚至增长，在发电和储能业务上盈利表现有所提升。

在充电桩建设和服务站点等基础设施建设方面，第三季度中，特斯拉在全球新开了 18 家店铺和服务站点，总数达到了 318 家。服务站点的数量同比增长 6%，每服务中心的技师容量提高了 10%。汽车业务的整体运营成本为 19.31 亿美元，高于去年同期的 15.71 亿美元。这也是特斯拉第三季度支出中的大头。

而为了尽快实现 Model 3 的量产问题，特斯拉将部分 Model X 和 Model S 的生产线转让出来，投入大量研发成本解决 Model 3 生产中存在的零部件供应问题，也影响到了特斯拉汽车在财报中的表现。

虽然特斯拉在财报上处于亏损状态，但从财报内容来看，其在汽车市场上继续保持良好发展势头。特斯拉汽车本季度新车出货量为 26137 辆，其中 Model S 和 Model X 车型的总出货量为 25915 辆，占总比例的 99.15%。Model S 和 Model X 车型的第三季度全球总出货量环比增长 18%，同比增长 4.5%，在美国豪华车市场上占据的份额进一步上升。此外，特斯拉汽车的二手车销售量也环比增长了一倍以上。

![](../Images/f7a387b6ea85d978be6498e777e374ab.png)特斯拉掌握的现金流变化表  图 | 新浪科技

另外值得一提的则是，特斯拉能够掌握的现金流并未受亏损影响，反而进一步增加，目前特斯拉的「口袋」里持有总现金余额上升到 35 亿美元。

  

## 又是电池供应链坑坏了马斯克

Model 3 的产能问题是特斯拉股价下跌的重要原因，瑞银分析师 Colin Langan 在一份报告中称，Model 3 难以达到预期量产会破坏 Model 3 目标实现的可信度，增加短期风险，Model 3 盈利能力备受质疑。

根据马斯克此前的计划，在经历最初的生产调试期之后，Model 3 的产量应当进入一个稳定快速的增长期，到九月将生产超过 1600 辆汽车，但当月实际交付用户的只有 222 辆。在本季财报内容中，特斯拉将把量产 5000 辆 Model 3 的时间期限推迟到 2018 年 3 月份，这比预期推迟了接近 3 个月。

![](../Images/5a1de2fc407fe2aad280d0cede02884e.png)此前特斯拉中国官网透露的 Model 3 预期量产图  图 | 特斯拉

Oppenheimer 分析师 Colin Rusch 称，还是有少数供应商无法及时保证零部件的供应，导致 Model 3 的难以大规模量产。而日前松下在 11 月 1 日公布的财报中「自首」，松下 CEO 津贺一宏透露，其部分电池的自动化生产线还未准备就绪，导致电池产量低，进而限制了三季度 Model 3 的产量。

而据公开信息透露，消费者对 Model 3 的需求仍然坚挺，截至今年 8 月订单量已经突破了 45.5 万。显然，在市场需求旺盛的情况下，供应链端频出问题是特斯拉的一大困扰。

与此同时，马斯克近日在美国范围内裁掉了 700 余名员工也引发了和劳工之间的纠纷。据外媒报道，这次裁员行为引起了其在加州弗里蒙特工厂等地工人的抗议。同时美国汽车工人联合会也已经提交了一份联邦起诉书，抗议一些工人因支持工会的决定而遭到解雇，部分工人甚至表示将停止为特斯拉继续生产汽车。

另外，马斯克本人也遭到传统车厂管理层的批评和抨击。大众首席执行官马蒂亚斯·穆勒（Matthias Muller）批评特斯拉纯粹在烧钱，解雇员工的行为缺乏社会责任感；而通用自动驾驶集成总监斯考特·米勒（Scott Miller）则认为马斯克对于自动驾驶功能的承诺「满嘴废话」。

马斯克使特斯拉成为一款「明星」车的贡献有目共睹，但在如何将特斯拉管理好供应链、提升生产效率和避免过多争议方面，马斯克真得专门找人管管了。
