消息称苹果 Face ID 的硬件很「稳定」，明年将不会升级

摘要：今年 iPhone X 搭载的 Face ID 人脸识别技术相当惊艳，成为很多人「剁手」也要买 iPhone X 的重要原因，但苹果明年或许并不会对它进行升级。


iPhone X 前两天刚刚正式开售，不知道各位有没有抢到手呢？相信很多人「剁手」也要买 iPhone X 的原因之一便是 Face ID 人脸识别功能。

苹果表示 Face ID 在识别速度和安全性方面都优于 Touch ID，而且使用起来也很便利。那么明年苹果会不会对其进行升级呢？ 根据最新的消息来看，苹果可能并不会这样做。

近日，凯基证券分析师郭明錤在其发布的投资者报告中透露，协助驱动 Face ID 人脸技术的原深感摄像头将不会进行「重大配置更新」，未来一段时间苹果将使用相同的点阵投影器和红外摄像头等配置。

郭表示，对于明年发布的新款 iPhone，苹果将确保不会再出现类似 iPhone X 产能不足，供应延期的问题。新款 iPhone 将会按时上市，并在第三季度末实现稳定供应。 

而对于有人预测 2018 年的 iPhone 将采用新的「混合镜头」——采用玻璃和塑料 (glass and plastics)，郭并不认同，他认为这么做会造成更多供应链问题，而 2018 年 iPhone 机型「必须按时上市」。 

此外，郭还表示随着 2018 年所有 iPhone 机型（包括 iPad Pro）都将转用 Face ID，Touch ID 技术基本将退出舞台。3D 感应也将是新 iPhone 的「重要卖点」。

现在我们仍不知道苹果明年在 iPhone X 系列上会有什么新动作，有趣的是，有小道消息称苹果明年将会发布 6.4 英寸的新款 iPhone。消息的真假我们尚且无法考证，不过更准确的信息应该到明年才能知晓。 ■
