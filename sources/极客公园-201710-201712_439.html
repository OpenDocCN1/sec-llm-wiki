我参观了腾讯 QQ 智能主题酒店，想不到除了 QQ 还看到了它的朋友们

摘要：作为最大的年轻人社交平台，QQ 已经成为了一个文化符号，这个符号的背后，已经蕴含着社交、文化、科技等更多的元素。


在今天全世界华人的心目中，谁是辨识度最高的卡通形象？

如果带着这个问题走上街头，我猜想排第一位的答案会是孙悟空。因为无论国内国外，男女老幼，都深受这个从传统形象的影响，而这种影响如同流水，直到今天还在滋养中国人的丰富想象，实至名归深入人心。

图片来自《西游记之大圣归来》官方微博

那么第二位呢？这次也许要好好想想，可选择答案也许异常丰富，很多卡通形象都很有潜质，但在国人生活中，如果说各年龄层都听过的，叫得上名字的，似乎有只企鹅也可以竞争一下，你可能猜到了，就是这只 QQ 企鹅。

图片来自视觉中国

根据腾讯公布的 2017 年第二季度及中期业绩报告显示，截止今年 6 月 30 日，QQ 月活跃用户数为 8.5 亿，这还不包括腾讯其它产品对 QQ 形象的传播，这意味着全世界每 10 个人当中，就有一个人认识这只企鹅（全球总人数大约为 75 亿）。

如此有辨识度的卡通形象，自然有进一步成为「明星」的潜质，既然在互联网上人见人爱，就有向线下试探的更多可能。就在 10 月 27 日下午，珠海长隆企鹅酒店，腾讯 QQ 与长隆集团达成战略合作，成立了全球首家 QQ 智能主题酒店，在这里，我们见到了 QQ 企鹅这一形象的进一步扩展。

当天天气相当不错，和北京比起来，这里天更蓝一些。长隆企鹅酒店在原本以企鹅作为主题元素的基础上，这一次和 QQ 合作，将酒店其中一层的部分房间升级为 QQfamily 智能主题房，一到这一层，我们就看到了不一样的元素内容。

说好的 QQ 企鹅呢？怎么会是只北极熊在走廊旁边？

这只北极熊名叫多福（Dov），是 QQ 企鹅的朋友，嗯，你问我怎么知道的，看看走廊另一边呗~

走廊另一边

如果你是腾讯 QQ 重度用户，也许很早就注意到，QQ 企鹅已经不再是孤独的「一只鹅」了，它还有很多朋友，包括另一只小企鹅 babyQ、卡纳（Qana）、奥斯卡（Oscar）和安子（Anko），这些新形象和最被人熟知的 QQ 一起，组成了现在的 QQfamily。这一次的主题酒店，就是以 QQfamily 作为主角的。

进入房间，就看到让人非常惊喜的各种 QQfamily 主题，无论是墙上的挂画，沙发靠垫，窗边的窗帘，地上的地毯，甚至电视机上的装饰，全部都是不同的卡通角色，不但很到位，而且也很适合家庭旅行的氛围。

细心的朋友应该看到桌子上还有一个像掰弯的管子一样的物品，这其实是一个机器人，官方称作小 Q 机器人。你可以在沙发上说一声：小 Q 小 Q，帮我开灯/关灯，它就立即帮你完成。或者说：小 Q 小 Q，帮我关上/打开窗帘，它也同样可以做到。不过目前智能操控的功能暂时就这两种，据介绍，目前小 Q 机器人的技能 API 已经开放给第三方合作伙伴，之后会有更多硬件接入。

除了一些操控功能外，小 Q 机器人还可以听音乐、讲故事、视频通话。据介绍，这款机器人是腾讯 QQ 和腾讯云小微合作开发完成，作为 QQfamily 智能主题房元素的一部分，它承担了让人解放双手的任务，诸如查询天气，设定闹钟提醒这样的常用事项，都会提升用户旅行体验。按照计划，小 Q 机器人会在年底量产并发布，届时我们也会为大家带来更详细的内容。

再说回房间，除了客厅之外，卧室的布置也延续 QQfamily 的元素，墙上有一些卡通符号（似乎也是 QQ 聊天中的气泡图案），包括大床和被子这些，也设计的很可爱。

卫生间里，最吸引我的是洗漱用品包装，也全部都变成了 QQfamily，包括洗漱用的杯子也是这样，不得不说，这里真的被打造成了一个 QQfamily 的二次元空间。

参观完房间，我们仅仅只看到了腾讯 QQ 和企鹅酒店合作的一部分。在随后的发布会上，长隆集团常务副总裁龚良庆先生进一步介绍了本次合作的细节内容：接下来，双方还将在 QQ-AR、QQ 钱包、QQ 会员等产品技术上全面合作。龚良庆称，之所以选择 QQ 平台，一方面在于这是当下年轻人交流的最大社交平台，另一方面也在于腾讯 QQ 能给游客提供更有趣，更具社交性的旅游产品。

实际上，从 QQ 这个形象到 QQfamily，腾讯早已发现了这只企鹅背后的价值。按照腾讯公司副总裁殷宇的说法，「当大家看到这个形象知道是 QQ，不会叫企鹅，这就是一个现象。」这说明它不仅仅是一个 LOGO，因此围绕它从形象，到故事，再到内涵，就可以尝试更多方向，和长隆合作，可以尝试去把这些东西落地。

腾讯公司副总裁殷宇

「我们分几步走，一个是我们为这些 IP 的形象创造更多接触的可能，你会看到有很多的表情，很多气泡出现，这是线上。线下，会有一些跨界合作的方式，让线下认知能够更多。」腾讯公司社交网络事业群市场部总经理李丹表示，腾讯在对整个 QQfamily 创造相应的故事、内容，目前有漫画，未来可能有动画，包括教育、旅游这样的业务结合。

通过这种方式，李丹表示，可以创造更多人物之间的知名度，以及让它们之间创造更多故事，这一部分创造足够多的接触点后，整个 IP 将会夯实，会有更好的创作平台和更好的内容创作。因此，从某种意义上来说，这一部分的 IP 将会被输送到腾讯影业、腾讯动漫、腾讯游戏、阅文集团这些环节，并产生出更大价值。

事实上，腾讯一直在 QQ 上不断增加用户和这些形象接触的可能，如果你打开 QQ 钱包，能看到作为二次元周边窗口的「鹅漫U品」，这里包含了众多 IP 形象，通过销售关于这些形象的周边产品，用户（很大一部分是年轻人）正在不断喜欢上这些角色，并有进一步在线下接触它们的愿望。

IP 形象的力量真的有这么大？如果你有这个疑问，不妨看看同样作为社交软件的 LINE 在线下的实体店 LINE FRIENDS 是有多么受欢迎，作为一款在国内用户数量并不多的聊天 App，LINE 在线下开的商店和咖啡馆顾客却一直络绎不绝，几乎每到一个城市开店，都会立刻有人排起长队。

图片来自网络

凭借自家的卡通形象，生产出有品质感的产品，LINE 不但在线下找到了曲线救国的思路，也让自身拥有了不局限于互联网的生命力。

谁看到不会想要拍张照呢？

一个具有生命力的 IP 往往需要经年累月的经营和打磨，一旦它深入人心，就能够引发足够的冲动。这种冲动可以超越时间，给予不同时代、不同地区、不同肤色的人以相似的情感体验，这恰恰是那些直到今天还活跃在人们视线中的角色们的特质，作为从社交软件起步的腾讯，想让 QQfamily 继续前行，正需要在线下持续输出，给人们这样的情感体验。

这就是经典 IP 能够超越时间的价值，也正是 QQfamily 这一形象这在努力的目标。据了解，在未来的一年内，企鹅酒店第 11 层的 166 间房都将变成这样的主题房，如果你未来恰好有机会来到长隆，不妨也来尝试一下充满卡通元素的 QQfamily 主题房吧~
