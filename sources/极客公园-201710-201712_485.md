# 为了不再吃土，他给这辆推土机装上了自动驾驶系统

「你为什么要努力？」

「因为不想吃土。」

来自宾夕法尼亚大学的 Noah Ready-Campbell 一定没有想到，自己居然还会回到工地上工作。

他的父亲是工程承包商，也就是我们说的「包工头」，上学那会儿，Campbell 每年暑假都会到工地帮忙开挖掘机，整理施工现场，倒垃圾。这样的环境他并不喜欢，Campbell 当时说：「我很讨厌这个工作，将来再也不回工地上了。」

而现在，工地帐篷却成了他的新办公室。

![](../Images/8f7df0b7b35ceac92686f2aa62f5fcf6.png)Built Robotics 创始人 Noah Ready-Campbell  

  

## 从 Google 到工地，从无人车到推土机

Campbell 大学毕业后的第一份工作是在 Google，那年 Google 宣布要做自动驾驶汽车，在当时似乎是一个遥远的梦想。现在，已经毕业 7 年的 Campbell 成了另一家公司的 CEO，而 Google 的无人车梦想依旧在测试阶段。

Campbell 的公司名叫「Built Robotics」，这家初创公司刚刚完成了 1500 万美元的融资，他们的主营业务是把自驾技术应用到工程设备上，让自动驾驶车辆完成工地上的工作。最近，首次亮相的 Built Robotics 展示了他们的第一项成果：自动驾驶推土机。

## 用自动驾驶技术武装推土机

虽然自动驾驶汽车现在还不成熟，但在美国加州，已经有 40 多家公司拥有测试自驾技术的许可证。雷达和传感器可以帮助汽车「看清」路况，并进行一些自动化操作，但想要在复杂的交通运输系统中正常行驶，对技术的要求很高。而且，自动驾驶汽车运输的终究是人，关于安全、道德的问题都有严格的标准。

和这些自驾车一样，自动驾驶推土机也用激光雷达、GPS 等传感器来「看」外面的世界，但不同的是，这些传感器还要针对施工现场进行特殊设计，以适应高幅度、高频率的震动。另外，激光雷达还可以测挖土的数量。

在同等条件下，要挖出一块 30×40 英尺大小、深度在 2-3 英尺的空地，需要专业工人 1-3 天完成。Built Robotics 表示他们的自动驾驶推土机可以达到相同的施工速度，而且它不会发生危险，也不会感到疲劳，可以 24 小时不停歇工作。

![](../Images/92e1223f4c0b392844362e3f43b8d96f.png)

自动驾驶汽车的定位要精确到厘米，但对于在施工现场工作的推土机来说，并不需要那么精确。它的工作环境相对固定，也没有来往的车辆、行人阻挡行驶。但 Built Robotics 依然使用了增强型 GPS 技术，结合基站和卫星定位，可以获得厘米以内的位置数据。毕竟，推土机这样的庞然大物撞到什么都是个麻烦。

  

## 我们的目标是——「没有蓝翔」

Built Robotics 所做的事当然不是造个推土机那么简单，Campbell 提到：「我们做的其实更难，自动驾驶汽车是在适应环境，而我们是在改变环境。」他们想用自动驾驶技术来提高生产力，解决劳动力短缺的问题。据美国劳动部统计数据显示，2015 年以来，建筑业和采矿业发生的致命事故上升了 2%，达到了 1244 起，另一个现实的问题是，70% 的建筑公司都缺少熟练的劳工。对于挖土这样重复性、同时又比较危险的工作来说，用自动化设备完成是个不错的选择。

![](../Images/3884ee7b24fe482ee8932422c89d95bf.png)

对于 Built Robotics 的盈利模式，Campbell 持乐观态度，认为可以将传感器组件出售给卡特彼勒、约翰迪尔这样的农机公司，也可以向承包商提供技术支持，或收取改造设备的费用。

除了招收更多的人才，最新的资金会用来购买更多的挖掘机和推土机。「挖掘机技术哪家强？」答案可能没那么简单了。
