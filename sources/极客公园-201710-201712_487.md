# 你的 Tesla 可能在悄悄测试全新的 Autopilot 2.0 软件，只是你还并不知道

**摘要：全新的软件已经开始在你的车上做「影子测试」了，特斯拉 Autopilot 2.0 软件的更新终于要来了。**

特斯拉已经在 Autopilot 2.0 软件上研发了一年，甚至很多车主认为他们根本没有什么进展。但也许你可能不知道的是，这个全新的软件也许已经在你的车上用「影子模式」在进行测试了。  

而特斯拉的销售与服务总裁 Jon McNeill 并不吃惊大家的疑问，它在最近关于自动驾驶仪 2.0 的问答环节中回答说，目前行政部门正在谨慎地处理和测试的即将到来的更新。

![](../Images/4bb7d1e3bd13d2e506d48b17920c177a.png)

在欧洲总部举行的「特斯拉车主交流」活动上，Jon McNeill 在演讲中发表了一些有趣的观点，比如说爆料了特斯拉明年将要推出的基于 Model S 和 X 型的全新的全电动车辆。

![](../Images/f02fdda19815ee1dbcb8e509c50ebed6.png)

演讲结束后，他也回答了一些问题，第一个问题就是「搭载 Autopilot 2.0 车型何时能够配备第一代 Autopilot 汽车内的所有功能？」

虽然特斯拉将自动驾驶作为主要功能，将 Autosteer、TACC、AEB 和 Summon 引入到 Autopilot 2.0 车型内，但「尴尬」的是有一些依靠 Autopilot 的传感器功能不可用，也就是说缺少装有一代 Autopilot 早就有的功能，如自动雨刮器等等，而这些功能迟迟不更新，让有些车主认为全新的 Autopilot 2.0 可能还并没有进展，同时遇到了很多困难。

![](../Images/3bc2b25ad8cbb5d3d45169662dafacc7.png)

Jon McNeill 回答说：「为新的 \[Autopilot 2.0\] 硬件堆栈编写软件一直都非常具有挑战性，但是我们在本季度其实已经有了一些非常好的进展。」他透露，他自己已经测试了自己的新软件，并且印象深刻。只不过他认为特斯拉对于向所有客户推送更新的情况持谨慎态度，测试将在一部分客户车型中以「影子模式」运行「数百万英里」测试之后才能被激活。

当然，特斯拉的整个「舰队」每天都能行驶数百万英里，所以他们应该可以快速的积累好的模拟英里数，这无疑成为了 Tesla 又一个独一无二的优势所在。

Jon McNeill 同时还暗示，更新将会有一些特别的「功能」，意味着「增强的 Autopilot 功能」将在「几个星期或几个月」被更新到所有车型内。

特斯拉官方发言人也表示，「Tesla 正在努力测试新功能，已经取得进展。我们正在继续改进我们现有的功能，并将在验证后立即推出新功能。」

特斯拉 CEO Elon Musk 在今年夏天的时候就评论过了一些未公布的 Autopilot 2.0 软件：「我们内部在 Autopilot 软件方面也取得了很大进展，越来越好。我真的很激动，我刚刚测试了驱动最新的开发版本，我很喜欢，这真的是一件特别的事情。因为我认为在自动驾驶技术方面这将会加速让我们成为世界级的技术。」

![](../Images/3a9f5229820e060a79d20c0020221a93.png)

几个月前，特斯拉还增加了 Autopilot 的数据收集工作，Musk 表示，他们正在专注于使用神经网络和计算机视觉技术来改进 Autopilot 2.0，我们希望这个出于「蛰伏」状态的 Autopilot 2.0 能够早一点给我们带来真正超越 1.0 的巨大改变。
