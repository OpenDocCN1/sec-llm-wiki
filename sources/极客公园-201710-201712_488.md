# 「谷歌气球」投入实战，除了能救灾，也是飞在高空的 AI 平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652849891&idx=1&sn=48ed03f86b73db8aaed55989d8dd7d68&chksm=7e6a3b55491db2434232601c2ef5a8ca062ec4d10962a0ff46757696d33f330c1fd7f3f37fe3&scene=126&sessionid=1681311119#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652849891&idx=1&sn=48ed03f86b73db8aaed55989d8dd7d68&chksm=7e6a3b55491db2434232601c2ef5a8ca062ec4d10962a0ff46757696d33f330c1fd7f3f37fe3&scene=126&sessionid=1681311119#rd)

![](../Images/f54f649965952b92132c53407dc19cea.png)

  

**摘要：在飓风袭击之后，Project Loon 已经前往波多黎各完成了部署，目前开始能够提供一些基本的通信服务。**

就在一个月前，岛国波多黎各遭遇了四级飓风「玛丽亚」的袭击。飓风过后，这个位于中美洲的岛国一度有 80% 以上的家庭失去了电力供应，全岛断水情况也非常严重。

作为美国的一个自由邦，联邦政府迅速展开了救援，而美国的科技公司也纷纷[参与](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652849581&idx=2&sn=42f815cbf3b65bc0a15a777e916657cd&chksm=7e6a381b491db10d01d26deccdeb555cb7781c7f98fa0b07a16193f52d02116a3114b2311deb&scene=21#wechat_redirect)到了这次救灾当中。特斯拉向受灾地区提供了 Powerwall 电池储能产品，Facebook 利用 AI 技术协助查找失踪人口，而由 X 公司（前身为 Google X 部门）研发的高空气球 Project Loon 也飞往波多黎各的上空，开始提供紧急的通信服务。

![](../Images/c617fec92f5da729edcea988f094e8da.png)从美国内华达州出发的气球  

美国时间 10 月 21 日，Project Loon 项目负责人 Alastair Westgarth 在 Medium 上发表了官方声明（http://t.cn/RWUBqWD），他表示 Project Loon已经在波多黎各完成了部署，目前已经能够提供一些基本的通信服务（包括信息、邮件和查询救灾信息等）。  

  

## 各方合作的成果

Project Loon 能够快速完成部署，实际上也是多方合作的成果。在救灾期间，美国联邦通信委员会（FCC）特别给 Project Loon 颁布了一张临时许可证，以便它可以「名正言顺」地提供通信服务。

而苹果和运营商 AT&T 合作激活了 LTE Band 8 频段（此前未商用）供气球使用，该频段工作在 900MHz 下，在信号的传播距离上有一定的优势。波多黎各的 iPhone 用户通过更新运营商文件即可完成适配，其他支持该频段的 Andriod 手机也可以直接使用。

![](../Images/7ad43b65b1236fac6fa2778ba2c4552d.png)

除此之外，一些机构还帮助 Project Loon 建立了必要的地面设施，正是在这样的合作下，Project Loon 才得以在 20 公里的同温层中构建出一个临时的通信网络。

  

## 飞行在同温层的 AI 平台

虽然高空气球在我们的印象中并不算是一个科技感很强的产品，但实际上 Project Loon 使用了大量的 AI 技术。在上面提到的声明中，Alastair Westgarth 特意强调了这是他们首次使用机器学习技术让气球编队可以更好地完成信号覆盖。

对于 Project Loon 来说，最难的地方莫过于让它保持在某一区域的上空。因为氦气球只能控制上下，只能通过进入不同层面的气流来调整前后方向。对于复杂的高空环境来说，控制气球滞空显然不是一件容易的事情。

![](../Images/eb3a43e373b1844742737552faa9553e.png)

根据 Wired 此前的报道（http://t.cn/RcF8UPW），Project Loon 最早使用的是传统的高空气球控制方式，即气球按照既定的路线飞行并微调。后来，Google 团队将机器学习引入到了气球的控制系统中，让它可以对周围的环境适时作出反馈，并且随着飞行时间的累积会变得更加「聪明」。

把飞行权交给气球本身带来最直接好处是，同等覆盖面积下，大大减少了所需气球的数量，而且气球可以更快的响应地面的动作。因此，称 Project Loon 为「飞行在同温层的 AI 平台」一点也不夸张。

Project Loon 的理念可以追溯到 2008 年，那时 Google 希望能够成立一家提供「空间数据服务」的公司。自从 2013 年在新西兰完成了首次测试以后，Project Loon 已经在全球累计飞行了超过 2600 公里。由于气球针对耐久性进行了特别设计，它的持续滞空时间达到了 100 天（最长纪录为 190 天。）

值得一提的是，虽然 Project Loon 已经从 Google 剥离了出来，但大家还是习惯称之为「谷歌气球」。

![](../Images/83e118184c0ceedee2df4ba9d9372126.png)

进入到 2017 年，Project Loon 项目的进展速度明显加快。今年 3 月份，秘鲁遭遇了严重的洪水灾害，Project Loon 第一次参与到了实际的应用中，在 72 小时内为 4 万平方公里的区域提供了基础的互联网连接，这也为之后的波多黎各就在积累了经验。

而就在不久前，外媒还报道了 Project Loon 将要「独立」的[消息](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652849653&idx=3&sn=1a27a1e1e5df445a063965d787472c28&chksm=7e6a3843491db155f0dd409f6f16b114f4200c25ed7d289c8766489c0289ec17f0f41dd26a93&scene=21#wechat_redirect)。在 FCC 的一份申请文件中，出现了 Loon Inc. 的名称，代表着 Project Loon 已经在向企业化转变。此前很多从 X 实验室毕业的项目，最后都走上了独立发展的道路。不出意外的话，Project Loon 将成为了 Alphabet 旗下独立的公司，将和我们熟知的 Google 成为兄弟公司。未来 Project Loon 将如何开展商业化业务，将有哪些应用场景，这些都值得我们持续关注。
