# ICO 要革了 VC 的命？听听投资人怎么说

> **还不清楚现在区块链要革谁的命。**

  

2017 年的人工智能一定很憋屈，在本来属于自己的「元年」，风头却被加密货币和区块链一把掳走。随着真格基金徐小平的振臂一呼，投资人、币圈大佬和高晓松在凌晨三点坐而论道，谋划区块链如何变革未来。比特币和各种加密货币浇灌了新的「韭菜」，而区块链项目 ICO 则培育了 VC 们新的焦虑——项目方通过「众筹」的方式融到了项目资金，投资人被疏远成了外围人士。

在区块链的发源地美国，情况反倒显得克制很多。中国农历春节前一周，硅谷区块链创业团队 String Labs 获得来自知名风投 A16Z 和 Polychain 的 6100 万美元投资。作为 String Labs 的早期投资人，丰元创投 Amino Capital 的联合创始人李强近日和极客公园分享了四年来投资区块链的经验，和 ICO 给投资人带来的挑战与机遇。

  

## 谁识区块链

2014 年 7 月，后来被人们称为「V 神」的 19 岁俄罗斯小伙 Vitalik Buterin 成功举行了以太坊项目的 ICO，共筹得价值约 1800 万美元的比特币。而在当时，区块链依然只在电脑极客中流行，即便嗅觉灵敏的硅谷投资人也没能意识到这个新兴技术背后蕴藏的潜力。丰元创投的工作人员在一个场合偶然遇到 String Labs 的创始人 Tom Ding，后者 14 岁就拿到大学学位的故事吸引了人们的好奇。

在丰元创投的办公室，李强和 Ding 第一次聊起了加密货币和区块链。「最开始，Tom 想的是发币。」李强说到。在 2014 年，虽然区块链还没兴盛起来，但是模仿比特币来进行 ICO 发售代币已经蔚然成风。Tom Ding 最初的项目 Coinify 也是想要发售加密货币，并且已经有团队使用 Coinify 的架构成功通过 ICO 融到了 60 万美元。

不过在丰元创投，Tom 花了很多时间和李强探讨发币在金融法规上的合规问题，李强后来将 Tom 的这种行为称作「谨慎认真」。「谨慎」的 Tom 并没有走上 ICO 发币融钱的「捷径」，而是效仿 Vitalik Buterin，开始研究更易用的区块链网络，团队将其命名为 Dfinity。

![](../Images/5d0068c333f24c617420e44cb35f88a7.png)（左起）Tom Ding、李强、Dominic Williams   

「投了 String Labs 几个月后，Vitalik 的以太坊项目就 ICO 了。」李强说到。

当时的硅谷，区块链项目并没有像接下来两年红透半边天的 VR 和 AR 一样吸引人，很多团队的项目并没有像现在的区块链创业一样和物联网、金融等行业挂上关系。「当时很多团队做的是产品溯源。」由 Nike 和阿迪达斯带动起来的球鞋文化，让青少年对复古运动鞋产生极大兴趣，很多人开始囤积名牌运动鞋来进行售卖，但是运动鞋的真假较难辨认，有团队就想在鞋子里加入芯片，使用区块链技术来鉴别运动鞋的真伪。同样的思路，也有团队的计划是用区块链辨别奢侈品的真伪。

用区块链技术来鉴别球鞋自然没问题，但是，是不是可以做更大的事？Tom Ding 和其他区块链同行办起了公益组织 Blockchain University，在硅谷向投资人和科技人士宣传区块链技术。「有几次活动 Vitalik 也出现了，因为当时专门给大家普及区块链知识的场合太少了。」李强说到。

  

## ICO 在革谁的命

2018 年 2 月，俄罗斯通信应用 Telegram 的母公司进行了史上最大规模的 ICO，首次发售代币就获得了 8.5 亿美元融资。币圈人士笑称 Telegram 是「自己下海摸鱼了」，因为各国监管政策不同，大部分币圈人士都习惯使用加密性能更好的 Telegram，而不是微信来进行沟通，这也是为什么很多 ICO 项目都组建了「电报群」。

与以往创业公司融资不同，ICO 项目不需要有成型的产品，只需要一个使用区块链的构想以及技术解决方案即可。同时，ICO 项目是针对全球的，一般通过比特币来进行代币购买，这意味着创业团队可以直接面向 C 端受众进行资金募集。程序员们发现，自己的技术能够直接变现了，而且「没有中间商赚差价」，这让作为「中间商」的投资人们心生恐惧。

在之前，投资人对一个创业项目的投资，从天使到 A、B、C、D、E 轮下来，至少需要三到五年时间。而在区块链领域，项目立项到 ICO 成功可能不到一年时间，在时间上颠覆了投资人培养项目的节奏。另外，区块链项目发售的代币（Token）并不是公司的股权，即便团队拿了投资人的钱，前者也没有义务将 ICO 项目的代币分给投资人。

不过从目前来看，大部分创业团队还是会和投资人站在一起，在 ICO 项目发售时，为投资人预留部分代币。「String Labs 的股权我们也有，同时他们发的代币也会给到丰元创投。」李强说，不过他也承认，ICO 这种形式确实给 VC 带来了很大的挑战，但更有可能别颠覆的，则是叱咤华尔街的金融巨头。

虽然 ICO 让有实力的技术人员，能直接融到钱，但在监管缺失的情况下，更多鱼目混珠没有任何意义的项目，通过 ICO 发售「山寨币」，狠狠的收割了一把「韭菜」。李强认为，这种混乱的现象很像中国之前的「千团大战」，最后只有美团等几个公司最终活了下来。「最优秀的人才融资会越来越容易，不靠谱的项目随便骗钱会越来越难。」

## 再见 BAT

当项目成立，ICO 成功拿到钱后，一个区块链项目的征程才刚刚开始。有了底层协议，团队需要的是寻找并说服开发者，让后者在自己的区块链上开发应用。「如何建立一个健康的社区，让更多的人加入自己的生态，非常有挑战性。」李强认为，就像 2000 年左右互联网浪潮开始时，很多网站出现又消亡了，最后留下的是 Google 和 Facebook 等巨头。「每个垂直领域能活下来两三家就算不错了。」

在谈到区块链未来的潜力时，经常出现的是说法是「颠覆 BAT」。李强认为，使用区块链技术来做电商或者社交，未来是有可能颠覆阿里或者腾讯的。但这个起到颠覆的并不是一个公司，而是一个很大的公链，公链的使用权和拥有权是完全分散的，使用者和掌控者分布在公链中。「一个电商的公链要比阿里的价值更大，但是不存在一个类似阿里的公司来做中心化管理。」李强说到。

在未来，一个蕴含巨大价值的区块链项目，可能只是一个小组织开发出来的，但是会有更多大公司作为合作伙伴加入到公链之中，成为该区块链的成员之一。和比特币类似，要想对区块链进行改变，需要大部分成员达成共识。

目前区块链项目的创业团队还是一些嗅觉灵敏的「草根」，更多受过专业训练的人并没有入场。「这些人不仅有更好的技能水平，同时也有大量的资源，这些『正规军』研发的区块链项目，具有更大的潜力。」李强说。
