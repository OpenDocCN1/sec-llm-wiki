# 7.68 亿人发红包、28 亿条朋友圈、2297 亿条消息，微信的春节数据你贡献了多少？

张小龙一直说「微信是一种生活方式」，当中国人的这种现代生活方式撞上传统的春节，总会有很多有意思的地方。哪的人最爱发红包、不同年纪的人都用什么表情斗图、春节的钱都花在哪了？

作为中国最不可替代的移动应用，微信的春节也勾勒出了现代中国人生活的轮廓，当假期结束，这些带着年味的数据或许能帮我们更好的回味一下这个刚刚过去的春节。

不知不觉中，每年春节人们送祝福的阵地开始从短信迁移到了微信，而依托微信，新年祝福的形式也悄悄发生着变化。文字、图片、音视频通话……这个春节你都收到了些什么样的祝福？

![](../Images/5d2263fa065de53ae3c8f585b57f9807.png)

在这些祝福大军中，90 后以绝对的优势成为了当下这个时代的移动互联网祝福中坚力量，而近来动静颇大的 00 后却意外垫底。

![](../Images/fe711478329668cd6f85c1e08041294f.png)

从 2014 年开始，微信红包几乎成为了一种中国人的新年俗，不管钱多钱少，抢的着抢不着，大过年的看着满天的红包横飞，所有人都乐在其中。

![](../Images/d444b062b69ffed6affea8b60ce85dd0.png)

如果非要分个高低胜负，那么广东、山东和江苏三地的朋友则是手速之王。而除此之外，还有发出最多红包和收到最多红包的全国之最。

![](../Images/eaa3c6bd80c6090f59ae10a06ff31d9b.png)

每当过年过节微信热闹起来时，表情总是不输文字的表达方式之一，而表情对于不同年纪的人也有着不一样意义。

![](../Images/594308756adcb1e542ed96111facf547.png)

小游戏成了今年微信上的春节里最亮眼的新势力，保持着年前小游戏的强劲势头，在这个春节里，小游戏也成长为了一个新年俗。

![](../Images/f0d6401d058b5f972b7246780e33ea9b.png)

春节总是动静结合的，除了在家和家人相聚吃饭之外，外出串门走亲戚同依旧是中国人的沿袭的传统，今年的春节你又走了多少步呢？  

![](../Images/f039a9bd8d4ba284c8f6aef626c7d541.png)

春节里除了收发红包，我们的钱都去了哪呢？微信支付的数据或许从某个角度给了我们一些线索。
