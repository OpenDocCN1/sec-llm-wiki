# Facebook 的用户时长减少了，扎克伯格为什么还挺骄傲？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652853048&idx=2&sn=83322e53649b4977fc74a8dc8a8fe274&chksm=7e6a2e8e491da798aa1ef4ffdba331fcdcbf9600046aa0aae94fbabdfc6ef43882a9eea92a61&scene=126&sessionid=1681311025#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652853048&idx=2&sn=83322e53649b4977fc74a8dc8a8fe274&chksm=7e6a2e8e491da798aa1ef4ffdba331fcdcbf9600046aa0aae94fbabdfc6ef43882a9eea92a61&scene=126&sessionid=1681311025#rd)

![](../Images/9a7faf56f7649e9cafe24e0f2424727f.png)

> **重视用户粘性，是 Facebook 和微信在增长近乎触顶后作出的决定，也是在普通用户开始反思科技和互联网的弊端之后，科技公司们必须作出的回应。**

  

过去一年对 Facebook 而言非常特殊。通俄门、直播自杀和假新闻等等事件让年初就准备好游历全美 50 个州的公司 CEO 马克·扎克伯格忙到了焦头烂额。他也许从没想过，Facebook 会惹上这么多的麻烦，更不要提这些麻烦事恰恰是与他对 Facebook 平台的美好设想完全相悖。

正因如此，2017 年 Facebook 的财务表现才更加让人关心。在财报发布之前，就有不少媒体和分析师唱衰的声音，在财报发布之后没多久，Facebook 的股价就因为一些不太好看的数据而应声下跌 4.5%。

是哪里出现了问题呢？

从财报数据来看，Facebook 2017 年第四季度和全年的总营收同比涨幅均达 47%，超过华尔街分析师的预期，即使在特朗普去年年底的税改之后上交了 22.7 亿美元税款，Facebook 也仍然保持着利润的大幅增长。

但如我们过去多次提起过的，Facebook 在 2017 年里经历了不少的波折，这也是财报发布之前许多人唱衰 Facebook 的原因。在财报中，扎克伯格自己也说道，「2017 年对 Facebook 而言是强劲的一年，但也是艰难的一年。」虽然股东和分析师们仍然盯着营收和利润的数据，但 Facebook 眼下却有着更加复杂而棘手的问题需要解决。

我们首先来看一下财报里比较重要的一些数据：

*   #### 总营收：第四季度同比增长 47%，年度同比增长 47%；
    
*   #### 净收入：税改原因导致第四季度同比增长 20%，全年同比增长 56%；
    
*   #### 稀释每股收益：第四季度同比增长 19%，年度同比增长 54%；
    
*   #### 日活：日活跃用户 14 亿，同比增长 14%；
    
*   #### 月活：月活跃用户 21.3 亿，比去年增长 14%；
    
*   #### 移动广告营收占比：移动广告营收在广告总营收中占比 89%，高于去年同期的 84%。
    

单从这些数据来看，Facebook 的总体情况似乎一片大好，排除税改增加的成本，公司在营收和用户增长方面仍然保持着傲人的成绩。但如果要与去年的增长情况相比，似乎就没有那么乐观了。

2016 年，Facebook 日活跃用户和月活跃用户相比 2015 年分别增长了 18% 和 17%，远高于今年的 14%。在那一年的年终报告上，扎克伯格曾表示：「我们连接世界的使命变得前所未有的重要。」可在 2017 年，扎克伯格似乎并没有集中所有的精力去吸引新的用户。

  

## 

大好形势下的两个小「隐患」

不仅仅是活跃用户的增长速度减缓，在 Facebook 亮眼的财报数据中，还有两个更让股东和分析师们担心的「小数据」：用户平均每日使用时长减少了 2.14 分钟，美国和加拿大的月活跃用户从 1.85 亿下降到 1.84 亿。

「在过去的一个季度里，我们对病毒传播的视频做出了一些调整，以便于人们更好地使用他们的时间。总的来说，我们削减了用户在 Facebook 上消耗的时间，大约每天 5000 万个小时。」扎克伯格在财报中说道，他不仅没有回避这一数据，反而表现出非常满意的态度。

5000 万个小时平均到每个月活跃用户身上，也仅仅只有 2.14 分钟，大约占据每个用户日平均使用时长的 5%。在许多分析师眼中，这 2.14 分钟代表着一个非常危险的趋势。Facebook 最主要的营收来源于广告收入，而广告收入恰恰取决于平台上用户的活跃度。因此，用户使用时长的减少，通常意义而言，会对 Facebook 的广告收入造成直接的打击。

另一个不大好看的数字——美国和加拿大日活跃用户的减少，同样加深了分析师们的焦虑。长期以来，Facebook 在主战场北美一直保持着稳定的增长趋势，虽然近几年的增幅不比亚洲等尚未饱和的市场，却也从未出现过下降的趋势。

![](../Images/942db778b49d4f0948e05c3bbed61aed.png)Facebook 财报中日活跃用户的部分数据；图源：TechCrunch  

在 2017 年，Facebook 因为平台上假新闻泛滥和政治广告等问题遭受了社会各界的诸多批评，同样遭遇的还有 Twitter 等社交媒体。这一年里社交媒体的公信度大大降低，很多人不仅开始质疑这些平台上信息的真实度，更对社交媒体本身的弊端有了许多反思。

Facebook 和扎克伯格本人当然也意识到了这点。「在 2018 年，我们将重点确保 Facebook 不仅有趣，还要对人们的生活和社会有益。」在个人的 Facebook 主页上，扎克伯格如此写道，「我们正鼓励人们彼此之间更有意义地连接，而不是被动地消费内容。」

![](../Images/5e57333be5345d5b3ef67951c95f7403.png)扎克伯格在个人 Facebook 主页上对财报的评价  

  

## 

Facebook 的「自救」

不同于去年的「连接更多人」，Facebook 今年的想法发生了改变，用很多外媒的话说，Facebook 正在「自救」。

从去年年底算起，Facebook 首先调整了信息流的算法，将信息流中媒体内容的占比从 5% 削减到 4%，增加好友动态的比重，让平台属性回归社交。

随后 Facebook 推出平台上的媒体评级系统，将综合主观评分和用户评价来为媒体划分等级，以便于为优质的媒体和内容提供更多的展示机会。

前两天，Facebook 又宣布封禁所有虚拟货币和 ICO 相关的广告，以防止用户在平台上受到欺骗，造成经济损失。

总体上看，虽然仍有不少的争议声，但我们能从这些大刀阔斧的改变中看到 Facebook 和扎克伯格的思考与决心。「短期内，我们想做一个重新的平衡，但是长期来看，用户会觉得在这个平台上找到了很多有意义的东西，而不是完全被动地去消耗一些内容。当你找到有意义的东西时，你会愿意回来。」这是 Facebook 工程总监范鹏在接受极客公园采访时表达的观点。

![](../Images/b53afe1dfbf4df788ae93fdb58a549ca.png)Facebook 工程总监范鹏接受极客公园采访  

表面上看，海外地区越来越成为 Facebook 内部的「增长黑客」们重点发力的市场，他们仍有能力让产品的用户数量保持稳定增长。在这样的条件下，Facebook 也开始有了余力，来思考如何弥补「野蛮增长」可能会带来的一些问题。

  

## 

第三个指标

前面谈到用户 Facebook 的营收主要来源于广告，而广告又依托于用户在平台上的表现，用户越活跃，广告展示的机会和吸引到的注意力越多，Facebook 的营收增长也会越明显。

![](../Images/108eb0a1ccc0955ead38d661a6a9aaf6.png)

但在这里，用户的活跃并不仅仅体现在人数和使用时间上，Facebook 已经成为世界范围内一家独大的社交平台，用户数量的增长迟早会见顶。而如上面所说，恶性追求用户使用时长会引发各种各样的社会问题，这时第三个因素就显得格外重要：用户粘性。

如产品经理张小龙所说，「用完即走，走了还会回来。」扎克伯格的想法其实也是一样，留住用户不一定意味着要让用户无休止地使用自己的产品，只要用户喜欢上产品，即使离开，也会回来再次使用。这种对用户粘性的重视，是微信和 Facebook 两者在增长近乎触顶后产生的思考结果，也是过去这一年中，普通用户开始反思科技和互联网的弊端之后，科技公司们必须要作出的回应。

「如果你把核心的事情做好，用户的增加、销售收入的增长应该会随之而来。」范鹏如此解释道。

反观 Facebook 的财报数据，即使用户增长速度有所放缓，使用时长略微减少，但 Facebook 日活跃用户占据月活跃用户的比重却没有发生任何改变，与前几年一样，同样保持在 66% 左右的高位。

也就是说，即使用户花的时间没那么多了，也没有任何趋势显示他们会离开 Facebook，从这一数据来看，它将让 Facebook 在文化和政治问题上变得更轻，更多去承担客观的工具身份，但对广告营收却没有明显的影响。

当然，去年的财报数据只能看出 Facebook 在遭受一系列打击之后紧急调整的结果，在今年扎克伯格卯足了劲「改革」之后，更多重视用户粘性的产品思维最终会收获怎样的结果，还要看未来 Facebook 的表现。

但至少，在短暂的下跌之后，Facebook 的股票开始反弹，目前，盘后已高于财报发布前股价。
