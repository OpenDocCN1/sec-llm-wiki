# 马力欧要和「小黄人」制作公司合作，新电影 2020 年上映你期待吗？

> **这个蹦蹦跳跳的大叔，如今也能在电影院给大家带来快乐了。**

  

有没有想过有一天，我们在 FC 红白机上玩过的「超级玛丽」会和「小黄人」合作，而且是出现在银幕上？  

今天上午（２月１日），任天堂官方发布公告，宣布开始和「小黄人」制作公司照明娱乐（ILLUMINATION）合作，开发「马力欧」动画电影。根据介绍，这部电影将由「马力欧之父」宫本茂和照明影业创始人克里斯·梅勒丹德利（Chris Meledandri）共同执导，由环球影业与任天堂联合出资打造。任天堂官方推特也同时对外宣布了这次消息。

![](../Images/4406f21f5241edcbbf1aae3153d51038.png)

本次合作双方都算是拥有相当知名 IP 的团队，任天堂自不必多说，自 1981 年首次出现在由宫本茂制作的《大金刚》游戏开始，马力欧这一形象借助任天堂游戏进入无数人的童年时代，可谓是家喻户晓的「水管工人」。而照明娱乐团队在 2010 年《神偷奶爸》上映后，作为片中配角的小黄人（Minions）也迅速走红并受到全世界影迷的热捧，可以说，双方在创造令人印象深刻的 IP 方面有着不少经验。

![](../Images/02bc8fdb1f66f99c01eaeafd1783057e.png)

实际上在 2015 年，任天堂就与环球影城达成协议，将建造包括马力欧在内的任天堂 IP 游乐景点，此次选择联手登上大银幕，我们很有可能见到一部非常特别的马力欧，影片中或许还会有「小黄人」出镜也未尝不可能。

![](../Images/ad13604e268bc7c55b2b5d17689e1713.png)马力欧+疯兔的 IP 合作  

而对任天堂来说，此前曾经与育碧合作推出马力欧+疯兔的 IP 组合就很能吸引大家目光，在动画电影上选择和照明娱乐合作也可以说是双赢的方式，无论游戏迷或是电影迷都能找到喜欢的点，我们也会持续对这次合作保持关注。
