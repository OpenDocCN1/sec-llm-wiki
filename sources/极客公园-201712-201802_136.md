# 荣耀 V10 魅丽红图赏：前置指纹和全面屏之外，还有雕刻工艺的金属后盖

> **伴随着新年的临近，越来越多的手机厂商推出了大红色的手机，不过荣耀 V10 的魅丽红依然显得与众不同。**

  

V10 是荣耀手机去年年底发布的一款旗舰手机，它在采用了高屏占比的 18：9 全面屏的同时，还保留了前置指纹设计，在同类产品中非常少见。

![](../Images/000d7cb7d19b297283f79aea1a8cc7ce.png)

配色上，除了相对「常规」的黑色（幻夜黑）和金色（沙滩金），荣耀 V10 还提供了蓝色（极光蓝）和红色（魅丽红）两种更加大胆的配色。

伴随着新年的临近，近期越来越多的手机厂商推出了大红色的手机，而各家对红色的处理方式又各不相同，下面我们就来看一下荣耀 V10 的魅丽红。

![](../Images/535b1e2819c7db71d6903e24e0138270.png)

荣耀 V10 魅丽红最大的不同是它表面的工艺。在金属后盖的手机中，金属表面大多会采用喷砂工艺，不过荣耀 V10 魅丽红采用的是一种特别的金属雕刻工艺。

![](../Images/15a785a5f2ce364004a841a68ef8522b.png)

金属表面使用精密的刀具切割出了无数条非常细致的纹路，摸上去有点像是指甲锉的感觉，当然了，V10 魅丽红表面的纹路要精细地多。

![](../Images/13cb52d731114597c9036cfd5f5dd151.png)

相比起常见的喷砂，荣耀 V10 魅丽红的这种工艺有两个好处：第一个是增加摩擦力，让手机更加不易滑手，第二是几乎不会沾染上指纹。

![](../Images/2841d42f522313a9659519c4f64c8195.png)

此外，在光线的照射下，荣耀 V10 魅丽红的表面还会呈现出类似玻璃的那种有些流动感的光泽，观感不错。

![](../Images/dd706eed9fd6bf7971e972d66fca1b54.png)

荣耀 V10 的中框和后盖部分是一体式的金属，不过中框部分采用的是喷砂工艺，中框的两侧各切了一圈亮面的金属倒角。

![](../Images/cef9db2b5edd62496e7bf8eea72a257b.png)

翻到正面，荣耀 V10 采用了一块 5.99 英寸的 18：9 全面屏，屏幕材质为 LCD，屏幕下方是前置指纹识别模块。

![](../Images/04c2cad3bc3b71303710601d757fcc2e.png)

硬件方面，荣耀 V10 采用了麒麟 970 平台，性能上足够有保证，独有的 NPU 还可以帮助内置相机、翻译等针对性优化的 app 提供更好的体验。

荣耀 V10 魅丽红的售价和其他颜色没有区别，4GB + 64GB 版售价 2699 元，6GB + 64GB 版售价 2999 元，6GB + 128GB 版售价 3499 元。 ■
