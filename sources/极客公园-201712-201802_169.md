# 智能时代下的「新保险」服务，会是怎样一种体验？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652852765&idx=2&sn=07bf4cc6e3c86268a747443576450ba1&chksm=7e6a2fab491da6bd44f67305a9594da37e388f973cd89a139c89f85cf5b13cdda69bb7521aaf&scene=126&sessionid=1681311034#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652852765&idx=2&sn=07bf4cc6e3c86268a747443576450ba1&chksm=7e6a2fab491da6bd44f67305a9594da37e388f973cd89a139c89f85cf5b13cdda69bb7521aaf&scene=126&sessionid=1681311034#rd)

> **「大象在 2018 年还是一家互联网公司，同时也是一家保险科技公司。我们的愿景还是希望通过保险服务帮助我们的用户去加强他的安全感，这也是我们做业务的初衷。」**

  

在互联网技术的推动下，各行各业都在发生着改变和进化。而互联网和金融的结合，也在催生着行形态保险服务的出现。

作为互联网时代的保险新力量，大象保险从诞生之初就充分运用大数据和云计算技术，通过重塑保险服务流程，打造创新的保险服务价值链，迅速成长为互联网保险领域的佼佼者，同时实现了「智能化保险服务平台」到「以大数据与人工智能科技驱动的智能保险顾问平台」的升级。

在去年八月的极客公园 Rebuild 2017 大会上，大象保险创始人 & CEO 杨喆为我们展示了大数据之上保险的新可能。半年之后，大象又给我们带来了什么新的思考呢？

**以下内容根据大象保险杨喆在极客公园创新大会（IF 2018）上的演讲整理而成。**

![](../Images/f8e767a677cdae6353d257dbcc86763c.png)

大家好，我是大象保险的杨喆，很高兴再一次来到极客公园的舞台，跟大家分享一下我们在保险领域最新思考。

我跟在座的各位一样，很久之前就是一个极客迷，这三天的大会也非常精彩，我们不仅看到了很多黑科技、很多前沿的东西，最重要的是，极客公园能给大家带来的是极客的精神，大家能够去感受到我们作为一个极客，去做很多创新的业务，去探索不同的领域。我们在两年多以前做大象保险，也是怀揣着一个极客的精神去做这样的事情。

回顾来看，互联网保险在 2017 年是一个非常火爆的 IP，我相信 2017 年以前很多人都没有太在意互联网保险，大家都觉得离得非常远。但是从 2017 年年初到现在，我看到身边越来越多做互联网业务的朋友、前同事，都纷纷加入了互联网保险这个「创业大坑」里面去。他们过去有做电商的、做 O2O 的，现在有的加入了创业公司，也有加入了大的保险公司或者是 BAT 这样的大的互联网公司的保险部门。

甚至最近也发现，很多的 VC 投资机构也有自己专门关注互联网保险的投资部门，或者说专门关注互联网保险领域的研究部门。

我们可以看到，整个 2017 年互联网保险是一个非常火的状态，为什么突然保险这个事情从无到有走到了大家身边？但是仔细发现，还是能看到一些端倪或者是一些线索的。因为保险这个事情，跟其他业务有很大的不同，**它不是独立存在的一个特别业务，而是作为金融非常重要的组成部分。**在我们生活的方方面面各处都可以看到保险，比如说我们出游，肯定会有一份意外险，我们去买飞机票、火车票，甚至去买一些公交票或者长途大巴票，留意的朋友都能看到，一般售货员给你票的同时还给你一张纸质的保单，这也是保险。

![](../Images/830f8f3826215e836762211a14a8064e.png)

**互联网保险正是能够把我们传统保险的生产模式和生活场景很好地带给大家**。今天我们说到保险，讨论的重点可能不是保险本身，我们更关注的是我们这帮人，为什么去做保险这样的事情。我跟在座的大家一样，是非常典型的 80 后互联网人，我们一直怀揣着不安分的心，总想做一件能够改变行业或者说对用户非常有价值的产品，我们其实做任何产品的初衷都会想到，我们首先要帮用户解决很多的问题，在解决用户问题的前提，看看有没有这样的产品能帮我们自己解决一些问题。

像我这样一批 80 后，大多来自于小城市，来北上广打拼，可能受过比较好的教育，有比较好的互联网行为习惯，但是我发现最近讨论的很多的话题都聚焦于买房、房贷、小孩上学和父母医疗等问题。而过去很多年，我们聊的是你玩的是什么游戏，今天有什么球，昨天中超的比赛是什么样的。

我突然发现时代远离了我。甚至前段时间有朋友问我你「吃鸡」了吗？我说是肯德基吗？那一刻我发现了，虽然自己还是一个年轻人，但是受生活所迫，受社会压力所迫，离我们原始想要的生活越来越远了，这也是我们这一群人安全感缺失的问题，我们想要改变它。大象团队里有很多的同学，之前都在做互联网金融的业务，我们看到金融是一个非常好的、能够加强安全感的手段，但是随着我们深入的跟用户去调研，去思考用户原本的需求和社会的现状，**我们发现目前大多数人对于金融还是在聚焦在如何去做资产的保值升值，如何去做投资，反而忽视了金融原本应该带给我们资产管理的平衡和安全感的保障。**

之前在做互联网业务、互联网金融的的时候，会去做很多的投资类产品，会去关注证券行业，会帮用户做资产管理，但总觉得对于用户整体的安全感来说，像一个大圆缺一角，我们一直在找寻是什么样的产品，能够完整地补全这么一个角。

回归本质我们发现，保险就是我们一直在寻找的，能够帮我们去解决和完善安全感缺失问题的最好的一个产品。正基于此，我们有了大象保险这个业务，虽然说我和几个核心小伙伴都是大概十年左右的朋友、同事，之前都从事于互联网行业，对于保险真的是完全陌生的领域。但是我们一直坚持着做大象的初衷：让每一份安全感触手可得。随着过去两年对业务的不断深入和思考，我们发现线上产品很牛，可以做很好的体验。

![](../Images/7563807f27bac7b42f7f23a678b75f43.png)

但我们做任何传统业务的优化和改造时，还是需要回归业务的本质。在过去的一年，我们有了更多的基于用户微观数据的思考，更多地在意用户在线上和线下交互体验感知的到达。我们是希望通过我们的技术能力，帮助用户去改变他安全感缺失的这么一个现状和问题。

说到改变，大家首先想到的一般都是大数据，极客的会也很高端，大家很多都谈论如何通过大数据去改变很多的细分场景、很多的产品，我们看到保险跟大数据，有很多的结合，最初我们想到的更多都是在业务端，我们如何通过大数据做精准营销，在服务端我们如何通过大数据做风控，我看到这样的思考，更多只是聚焦于业务的本身，相当于把保险作为一个生意，如何通过技术手段去改变这样的生意。

![](../Images/7ccf4f2870f109f5ba142219067acc14.png)

对于大象来说，从一开始我们做互联网保险的时候，我们就没有把它当成一个生意或者一个事业来做，更多想要通过我们自己原有在行业里的积累，帮助用户解决问题。正是因为这种思考和原生力的变化，去看我们通过大数据来转成对用户「小数据」的细致观察。这也是 PPT 里展示的大象「小数据」，我们会更多聚焦于用户微观的行为数据，跟平台所产生的交互的行为，用户的在线偏好和他主观、客观对于任何场景上的需求。

刚才我提到互联网保险是一个很好的产品，因为它可以跟任意的互联网产品去做深度的融合和合作。互联网保险，尤其是保险业，可能在中国未来经济发展中起到比传统的银行和金融更弹性、更丰富的作用，因为它除了具备原有金融的财富增值和稳定的作用以外，还具备补足我们广大中产阶级安全感缺失的问题，保障未来和社会经济稳定的杠杆问题。

基于我们对「小数据」的观察，我们在过去两年做了很多的苦力活、人工活，我们认为做基础的保险数据整理是非常苦的。对用户在保险侧的需求画像进行整合，用户数据收集是一部分，更重要的是我们在过去两年不断地通过数据和业务流程，去验证我们对于用户标签、用户多维画像的准确度。

同时，我们耗费了很多的人工+计算能力，做了全网的互联网保险产品，我说的保险产品可以聚焦到每个保险的险种及其相关的责任，把它数据化、结构化，让我们能够方便地通过智能的手段，能够去了解产品。

在过去我们的认识中，保险产品都是一个个冰冷的纸质文件，它是线下的，没有办法进行数据分析的。我们在过去的一年，真的是费了很大的人力做这样的整理，我也希望在 2018 年有一个场合，跟大家去分享一下我们如何去做保险数据的整理、分析，如何去做保险数据的建模。

过去以为保险就是意外险、健康险、养老、投资这几类，用户可以按年龄、性别、收入给他做一个细分，就可以完成用户跟保险产品的关联。

随着业务深入做下去，我们发现远比想象的要难很多，我们自己基于用户对于保险侧不同的需求，整合了非常多的场景，同时我们有很多的底层模型，去应用于不同情景下的用户保险需求。现在看到，保险是一个离我们生活非常近又非常远的产品，如何通过多种情景把用户带入到保险的思维中，同时又可以通过我们的计算能力和我们对于海量产品的储备能力，带给他符合需求的定制的解决方案，这点是最难的。

同时在做的过程中，也很容易跑偏。像在 2016 年很多的时候，我们会更关注于场景本身（因为场景很多），而忽视了用户原有保险的本质需求。回到新年我们又一次回归，我们大家也在思考最终想要做什么，想要带给用户的是什么。

最后发现，不是通过各种场景做业务，而是通过各种场景去看到用户的本质需求。通过这种多场景的串联，把用户及他家庭背后的保险解决方案给构建完成，同时基于他不断变化的生活方式、社交状态、收入、职业、地域很多的维度，帮他不断地做风险解决方案的迭代。这才是我们重点要做的。

有了基础的数据能力我们会去希望有一个比较好的工具去呈现它，去让用户可以很方便地使用我们的产品，我们在 2017 年的年中开始准备了阿尔法象的产品，这个产品可以帮助我们的用户完全通过线上的方式，去了解他自己的保险需求，同时可以把基础的保险服务，通过线上的手段带给他。中间用到了人工也用到了智能，我们所需要做到的是人工和智能的无缝对接，让用户感知是一致的，这是最重要的。

现在人工智能这两年非常火，但它不是一个特别新的名词或者是技术，我印象中，大概十几年前在国外上学的时候，当时是完全可以通过一些程序去控制简单地机器人，按照我们的路线进行行走、探索或者是简单地拟人的行动，当时还做了全英最大的电子辞典，这一切都是基于人工智能。  

在保险上希望通过智能的手段带给用户。基于对用户标签的捕获，可以智能的帮他推出家庭保险的推荐书，用户可以在线去浏览全部的家庭解决方案，同时用户还能看到我们每一款险种的细节，以及我为什么会给他推荐这样的产品。

![](../Images/9e38c28dd03c342424625431db93a299.png)

最后可以看到每一款产品是来自于海量的产品信息库带来了，这个背后是我们过去一年两年大家共同努力进行的行业整合。这个产品现在是既可以通过 app 的方式进行展示，我们还把它开放给行业的合作伙伴，可以 SDK 或者是 API 的形式接入我们的产品，如果说任何平台希望为他的用户提供更深度的保险服务，去补强用户的安全感问题，完全可以通过我们「阿尔法象」的产品进行对接，可以方便地展示给用户。  

最后回到大象的初衷，我们认为大象在 2018 年还是一家互联网公司，同时也是一家保险科技公司。我们的愿景还是希望通过保险服务帮助我们的用户去加强他的安全感，这也是我们做业务的初衷。

现在可以看到**，所有的金融行业包括我们重点关注银行业、证券业，都开始往保险行业做横向的延伸，我认为这是社会升级发展的需要，也是国家资源、行业和未来产业稳定性的需要。**

同时我们也可以看到，在国家层面也更多的政策，过去只是以公务员保险、社会保险为主，这是国家主要的底层社会保障和稳定体系，现在从整个国家层面来看，商业保险将在未来增强国民安全感上起到越来越重要的作用。

![](../Images/cde25ba111b7b6da89c4cabab8ecb4aa.png)

我们都说新的技术发展，可以让我们放开手去做很多的创新，大象保险也希望通过新的科技发展，同时结合我们对于智能保险、大数据的研究，能够把互联网保险的思维带给我们每一个用户，同时让「发现身边遇到危险和遇到恶性事件才想起保险」这样的事情不再发生，让每一份安全感和保险的思维存在于大家身边。 ■
