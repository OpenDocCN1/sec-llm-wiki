# 一加刘作虎：为什么说国际化是个伪概念？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652852731&idx=1&sn=ad6c235f599664734212dfbc0597d2c9&chksm=7e6a2c4d491da55b61301cf98d2b30ba8cc96c7e9badbef4542294635b0788ebec2137a6c892&scene=126&sessionid=1681311037#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652852731&idx=1&sn=ad6c235f599664734212dfbc0597d2c9&chksm=7e6a2c4d491da55b61301cf98d2b30ba8cc96c7e9badbef4542294635b0788ebec2137a6c892&scene=126&sessionid=1681311037#rd)

> **刘作虎分享了四年间一加在海外市场拓展中所遇到的难题，也谈到了一些它们所收获到的东西。**

  

刚刚过了四周岁生日的一加科技，迎来了自成立以来的第五个年头。

过去的 2017 年，公司完成了接近 100 亿元的营收。与国内大多数厂商的「机海战术」不同的地方在于，一加采取的是只做旗舰的精品策略。

这也意味着，近百亿营收基本上依靠单款旗舰产品来完成。按照 CES 2018 展会期间一加手机创始人刘作虎在媒体采访时披露的数据，其每部手机平均售价达到 3200 元。

另外，值得关注的是这 100 亿元背后的分布。官方数据显示，国内市场仅仅占据了其中的 30%，而海外市场营收占据了 70% 的比重，后者的贡献率甚至要比前者的两倍还要多。

![](../Images/20f0b121cf38060e745baf71b7b9a2d2.png)

从 0 到 100 亿，一加用了四年的时间，在这个过程中，他们走的并非一帆风顺，有过高光，也经历过挫折。   

2015 年刘作虎曾经在极客公园创新大会上发表了主题为「如何改变中国制造」的演讲，至今三年的时间过去了，外界发生了翻天覆地的变化，人们所关注的话题也由中国制造，更多的转变成了中国创造。

1 月 20 日的极客公园创新大会上，时隔三年之后，刘作虎再一次登上了这个舞台，聊了聊**一**加成立四年的一些感悟，同时也分享了他对于中国品牌「出海」这件事情的看法。

**以下是一加科技创始人&CEO 刘作虎在极客公园创新大会上的演讲实录（经过极客公园编辑）**

## 

当极客成为产品的首批用户……

2014 年第一款产品发布之后，我们很快进入了欧美主流市场，尤其是美国，如果不跟运营商合作，意味着没有机会，但我们作为一个新品牌在美国公开市场找到了一席之地，我们也做了一些之前很少有人做到的事情：

海外最挑剔的极客和开发者是我们的首批用户，我们在美国首先获得认可是在智商密度最高的硅谷，通过邀请码被科技精英们互相推荐。从购买地址我们可以看到有几千个 Google 的员工都是我们的用户，Google 的人每次见到我就会很好奇的问，「为什么我们的手机都可以免费领取，但是他们还要花几百美金买一加手机？」

![](../Images/8c9621312782914d250fa5b8ceba1418.png)

但是，当极客成为产品的首批用户，其实是一件非常具有挑战性的事。

我可以给大家分享一个我们很真实的故事，一加手机 2 代的时候，我们率先在业内使用 USB Type C 充电线。忽然某一天，有一个来自谷歌 Pixel 团队的硬件工程师经过一系列测试，告诉我们：一加手机的 USB Type-C 数据线和适配器在本机上是可以完美使用的，但是有些非标准的电阻器可能会损伤 USB 配件。

我在网上看到之后立马就转给我们的开发同事，但我们开发同事第一反应是给我说不可能，认为这个人不太懂。后来，又过了一周，我看网上还在讨论这件事，我就又问他，人家说的究竟对不对？这个时候开发同事才「很不好意思」地告诉我，是我们自己错了。于是我们赶紧做了弥补调整。

为什么举这个例子？这是我们的品牌属性决定的。我们的用户很多都是来自全球各个领域的专家，可能很多人比我们工程师还专业。但他们都喜欢我们的产品，并会给身边朋友推荐。

要做到口碑的传播，其实是非常困难的。当然，这也是一加比较自豪的事情，能够让这群用户满意，我相信没有其他用户是我们服务不好的。   

## 

「国际化」其实是个伪概念

在一定程度上我们被贴上了「最会做海外市场的中国品牌」的标签，不少朋友让我分享「一加国际化」的秘诀。

但说到国际化，我个人觉得这其实是一个伪概念。

你做一个品牌或者一个产品，并不是专门为某个国家或者某个区域的人生产的，它应该从来就是面向整个世界的，比如 Google 或者 Facebook 这样的公司，从来不会说自己很国际化。

一加也从来没有刻意追求国际化，从一开始我们就是想要做一个给世界的产品，对于我们来说，没有先国内后海外这个问题。

当然，我们必须承认和看到的一个事实是，之所以会有这样的一个标签和探讨，是因为目前大部分的中国品牌在出海的时候仍然会遇到两大难题：第一是遭遇信任壁垒，第二是品牌影响力获得认知还是比较艰难。

![](../Images/1211fbb37af4afca38f93c0297ce2624.png)

  

## 

在海外市场赢得尊重的三个关键

要解决以上两大难题，其实也不难。

**首先，坚持打造世界级产品。**从成立开始，一加一直在坚持用统一的国际标准打造世界级产品。统一的国际标准是什么？换句话说就是好的产品可以跨越地域、种族、文化。

![](../Images/7dba9cd7c8804f734a5a7a080df46772.png)

比如很多人会认为，设计会有很强的地域差异。我告诉大家，我们在做一加 3 的时候也带着这个问题去纽约和上海调研设计模型，结果是，我们在两个地区的调研结果是完全一致的。

只关乎好的产品，不关乎国界。这就是我经常跟团队说你们要用国际水准去要求自己。用户的需求大部分都是共通的，不管你来自哪里，比如每个人都喜欢精致的产品，喜欢简洁高效的用户体验等等。

但光有好的产品还不够。做出一个有国际水准的产品是改变的第一步，**第二步是成为一个有影响力和价值观输出的企业。**

![](../Images/9de9b3938c070d94e03a4f93191c4ce6.png)

就像上个世纪 90 年代的索尼、丰田，他们不仅改变了世界对日本制造的印象，更是把日本的匠心和匠人工艺带到了世界，直到今天依然发挥着影响力。

尽管，已经越来越多的中国制造销售到了海外，但中国企业出海，大部分还没走到第二步，有一点很重要的是在获取影响力的同时保持诚信。

一加的海外排队曾被质疑是请了水军，我想告诉大家的是在海外不存在请水军，也不能请。因为一旦有人发现，你的品牌基本就不会再有任何机会。

**最后，我想讲讲自信。**其实自信是一种信仰，是你对自己坚持的东西的一种信念。如果你坚信做好产品就会成功，那你就会自信，就不会急功近利。

相信自己的判断，相信客观真理，时间会给出答案。并且，也唯有自信做自己，中国企业才能真正带给世界梦想，而不是一味围观世界。

  

## 任何选择和坚持都要回到初心

我知道今天台下也来了很多创业者，做企业其实经常会有很多面临抉择的时候。

其实我们也并不是好像一开始就看透了一样，也是慢慢摸索的。一加之前在国内虽然没有做过千元以下的机器，但是也尝试过千元以上的中端旗舰，那就是一次我们被外界的诱惑影响的结果。

包括在去年，团队看到我们在印度高端市场第二位，那么好的机会和品牌影响力又蠢蠢欲动想做中端旗舰，结果就快立项了被我否定了，他们不解，但是就是被我否定了。

作为一个公司的 CEO，很多时候并没有人替你做这个决定，或者一开始就有人告诉你，怎样选择就一定是对的。

![](../Images/c43271e8a76d7776647ed0f1c73c3365.png)

**很多时候可能是符合客观规律的的理性判断，加上你的直觉灵感，而直觉灵感往往就是你的初心，我当时否定的初心就是因为我们要做最好的安卓旗舰，很简单，很专注。**

最后一句话总结，不管你行不行，真理就在那。什么是真理？就是做好产品，保持初心，坚守诚信，很朴素的价值观。 ■
