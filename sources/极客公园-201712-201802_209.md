> **智能汽车的进化之路，也许是网友和马斯克一起选出来的。**

  

毕竟是新年伊始，大家总要有些目标和规划要去实现，「钢铁侠」伊隆·马斯克也不例外。这位「推特达人」喜欢在网络上和人分享自己的种种观点，而最近，在和网友的交流中，他又有了特斯拉未来的六个功能规划，它们分别是：  

**1，可自动加热的汽车方向盘**

![](../Images/5dec40640da38c6d7ad2b51708ed1644.png)  

**2，几乎无所不能的语音控制**

![](../Images/160eb92dc2b6945e4d8850ddc5b2200f.png)

**3，为户外充电桩站点增加虚拟奖励，并让它看起来更像别具一格的目的地**

![](../Images/fc85b4d417e2aad85e7bfb754cf12f3d.png)

**4，当用户进入车内，再开启雨刮器**

![](../Images/369c157943d684ad728541c658f5eeda.png)

**5，根据下雨量自动调节雨刮器速度**

![](../Images/1b989f8bba6d0a773c16f15003909918.png)

**6，有人闯入车内时自动打开摄像功能**

![](../Images/7b1f7fb95f5b6ecb06ac66bd6abb1e80.png)

你可能会发现，这些想法有些看似很快就能实现，有些似乎又需要很长时间，原因在于，这些都是网友在推特上提出的建议，但马斯克对他们给出了明确的回复，从这似乎我们能够看到人们对于汽车智能化的更进一步的期待。

但毕竟是网友问答，到底这些功能什么时候出现，到时候会实现成什么样，马斯克没有给出具体的信息。所以，在回复时，他有时说「很快到来（Coming very soon）」，有的则是「我们会做的（Will do）」，他回答最多的是关于语音控制汽车的那条留言，在回复中他谈到工程师们正在让 Model 3 上的语音功能覆盖到核心能力，并慢慢增加更多的新功能。

作为 2018 年的开始，我们当然有理由期待，这些接地气的功能会在这一年陆续来到我们身边，毕竟，让汽车像智能手机一样，通过网络升级获得新功能正是特斯拉最初吸引人的地方。不过，马斯克的当务之急是解决特斯拉 Model 3 的产能问题，就在前不久，特斯拉 Model 3 交付未达预期的消息就让不少老牌汽车厂商打开了话匣子，更别说特斯拉还带来了电动卡车这一新品类，要想让大家都感受酷炫的新能力，多造车才是重点。
