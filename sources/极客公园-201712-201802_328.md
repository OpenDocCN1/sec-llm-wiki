# 图赏：在 CHERRY BOARD MX 8.0 之后，又带来了 RGB 黑色侧刻版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652852249&idx=2&sn=5fde07284f8ebe40c2fc21d2587d7fd1&chksm=7e6a2daf491da4b9dde76d65f8b2b507ce5724a9b10647e56dcc162fe4cb1a8907257456a7ba&scene=126&sessionid=1681311052#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652852249&idx=2&sn=5fde07284f8ebe40c2fc21d2587d7fd1&chksm=7e6a2daf491da4b9dde76d65f8b2b507ce5724a9b10647e56dcc162fe4cb1a8907257456a7ba&scene=126&sessionid=1681311052#rd)

![](../Images/1e1f2ed165fe23634f2d52dbb58e98e2.png)

> **依旧标配了「军火箱」，但 CHERRY BOARD MX 8.0 RGB 黑色侧刻版采用了侧刻键帽的设定。**  

  

在键盘领域，有一些很有想法的公司，比如 CHERRY。2016 年 9 月份，他们推出了两款和以往风格完全不同的产品，一款是拥有「奇特」外观设计的 MX BOARD 9.0，另外一款则是首次采用 87 键布局的 MX BOARD 8.0。

对于 CHERRY MX BOARD 8.0，之前我们也曾做过详细的[评测文章](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652844940&idx=3&sn=a8004e6c9ddbf4445ae5852cdef1f527&chksm=7e6a4e3a491dc72cfcfbbdc0f98635ccbad744c343bae904cbe6f729a1c3b096e740049d2553&scene=21#wechat_redirect)。而在它发布之后，CHERRY 又带来了非常特别的 CHERRY BOARD MX 8.0 RGB 黑色侧刻版，一起来了解下。

![](../Images/c1eb2431ba45d6f3310803ae431cf7a2.png)

提及 CHERRY MX BOARD 8.0，除了键盘本身，其所配备的「军火箱」同样令人印象深刻。此次 CHERRY BOARD MX 8.0 RGB 黑色侧刻版依旧选择了这样的做法，不过整体选择了黑色的涂装。

![](../Images/f29a32cd06801f5221998b0abd13d5b8.png)

和之前 CHERRY MX BOARD 8.0 的那款「军火箱」一样，它整体采用了铝制外壳，三围分别为 480×225×85mm。不同的是，此次其提手配色改为了红色，表面同样印有 CHERRY 字样和 logo，十分显眼。

![](../Images/d5cf04afe1327648c81675c7d9fde441.png)

打开 CHERRY BOARD MX 8.0 RGB 黑色侧刻版的「军火箱」，呈现在眼前的是键盘本体。另外，除了使用说明书，没有其它太多的配件。

![](../Images/64cebfd21f4b10f5416d337e39c682b6.png)

就整体外观而言，CHERRY BOARD MX 8.0 RGB 黑色侧刻版延续了 CHERRY BOARD MX 8.0 的风格，依旧为之前的 87 键配列以及悬浮键帽设计。

![](../Images/8963189520a6fb1e2ebe8e40cc055bc2.png)

当然，从命名上也可以看出，CHERRY BOARD MX 8.0 RGB 黑色侧刻版最大的特点在于，其采用了侧刻键帽的设定，你可以一眼就分辨出它和标准版之间的区别。

![](../Images/cf9dce6a9d52b338d26f8b3f0083723e.png)

键帽材质的选择上，这次 CHERRY BOARD MX 8.0 RGB 黑色侧刻版依旧为 ABS 材质，手感十分细腻。另外，有关「打油」的问题上，由于没有进行长时间体验，这里很难给出一个相对准确的答案，不过根据之前 CHERRY BOARD MX 8.0 的体验结论，CHERRY 处理的还不错。

![](../Images/383ad3c65a5c3e58a9898f7830299eb8.png)

这次 CHERRY BOARD MX 8.0 RGB 黑色侧刻版采用了 CHERRY MX RGB 轴，轴体上下盖为半透明设计，来保证其透光的均匀性。

![](../Images/4b72a3ef8c591be451ecb770cb1bf847.png)

另外，除了我们手里拿到的这款 CHERRY MX RGB 青轴版本，CHERRY BOARD MX 8.0 RGB 黑色侧刻版还提供红轴、黑轴和茶轴版本。

![](../Images/a7d4cb134c902233397178dbf2837465.png)

灯效方面，CHERRY BOARD MX 8.0 RGB 黑色侧刻版共有 10 种灯效，包括波浪、呼吸、曲线、折返、激光、扩散、常亮、霓虹、单点亮以及自定义。比较特别的一点是，其 USB 刷新率提高到了 1000Hz。

![](../Images/d46762e1a919c33b7b4e196ebec148f5.png)

机身材质依旧为阳极氧化铝，侧面为一体式设计，同时做了带有高光 CD 纹的装饰。

![](../Images/76a5abf55662e572682579df97274d0a.png)

脚撑和以往我们经常看到的键盘不太一样，其使用了「卷轴」式的直通设计，以旋转的方式打开，支持两档高度调节。

![](../Images/63625417556fbd5ab7d21ce4d0b2aad0.png)

不过，可能也正是由于 CHERRY BOARD MX 8.0 RGB 黑色侧刻版特殊的「卷轴」式脚撑，也导致它很难像 MX Board 5.0 一样，去做更多的导线槽。

![](../Images/a53b2178ef10cebec30bc24bf68f1d69.png)

售价方面，目前官方正在搞促天猫商城搞促销活动，CHERRY BOARD MX 8.0 RGB 黑色侧刻版青轴版本为 1689 元，黑轴为 1649 元，茶轴为 1709 元，红轴为 1749 元。

![](../Images/540f002342f045d13ff1a1d5e54be691.png)
