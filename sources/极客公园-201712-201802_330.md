# 比 Model S 85D 更快，Model 3 创造了一项新的纪录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652852227&idx=2&sn=b12571a3a6d629d04b56d333b8519c20&chksm=7e6a2db5491da4a3b98c3b39b1c9f42f2adb3974b49e97529614d23840d44e34d000a9d432d4&scene=126&sessionid=1681311052#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652852227&idx=2&sn=b12571a3a6d629d04b56d333b8519c20&chksm=7e6a2db5491da4a3b98c3b39b1c9f42f2adb3974b49e97529614d23840d44e34d000a9d432d4&scene=126&sessionid=1681311052#rd)

> **在 50 小时 16 分 32 秒内，特斯拉 Model 3 完成了从洛杉矶到纽约的行程。**

  

尽管需在交 8000 元定金之后，可能依旧需要等待两年的时间才会正式交付新车，但 Model 3 依旧吸引了超过 50 万的预订者。毫无疑问，外界对于这款特斯拉旗下的入门级车型，抱有极高的期待。   

相比之前的 Model S，虽然 Model 3 的车身要更短一些，但按照官方的说法，其车内空间却不输 Model S。另外，Model 3 的前风挡玻璃和车顶变成了一整块玻璃，拥有和 Model X 一样的「直升机视角」。   

特别的地方在于，Model 3 的内饰极其简洁，甚至它的人机交互方式只有位于中控部分的一块面积很大的触控屏。而恰恰得益于此，Model 3 只有 10000 个左右的零件，这也使得在实现量产的过程中，要来的更加容易一些。

![](../Images/239ca095180ca790776d3eb7d39f7a33.png)图片来自视觉中国  

坦率来讲，Model 3 从正式发布到宣布开始交付给用户，一路走来并不平坦。不过好在这款被备受关注的车型，确实也没有让大家失望。 

援引 The Verge 的报道，最近《The Drive》主编 Alex Roy 驾驶着朋友的特斯拉 Model 3，于 12 月 28 日离开加利福尼亚州的雷东多沙滩，驾车前往离帝国大厦不远的曼哈顿停车场，在 50 小时 16 分 32 秒内完成了从洛杉矶到纽约的行程，创造了一项电动汽车的新纪录。

对比之前 Alex Roy 的朋友 Jordan Hart 和 Bradly D'Souza 利用一辆 Model S 85D 跑出的成绩，此次他所用的时间足足缩短了一个多小时，是迄今为止，相同路程情况下，电动车最快的速度。 

值得一提的是，此次 Alex Roy 的测试环境是冬季。所以在整个途中，为了保持车内温度，空调是一直保持工作状态的。显而易见的是，这对于 Model 3 本身的续航，是一个不小的挑战。 

当然，这样的条件下，除了可以更加直观的测试出 Model 3 在低温环境中的表现，也同时反应出过去这几年里，特斯拉在超级充电站的网络布局上，是否能够满足长途旅行的需要。 

严格来讲，由于尚未有更加专业的机构对 Model 3 进行全面的测试，所以其实际表现到底如何，目前尚未有一个定论。但以 Alex Roy 此次的路试结果作为参照，至少可以说明，Model 3 的确值得大家去期待。 

![](../Images/33432f1f7795a6314d7111935f5cedba.png)图片来自视觉中国  

其实早在 2017 年 2 月份，Model 3 就已经开始了「试量产」。但根据早先的报道，由于 Model 3 的电池在生产过程中遇到了困难，严重阻碍了特斯拉正常的生产计划。 

终于，时隔 5 个月之后，去年 7 月份，Tesla 在弗里蒙特工厂举办了首批交付活动，有 30 人真正拿到了首批量产的 Tesla Model 3，这 30 位早期的拿到车的都是内部员工，原因是他们更能容忍早期量产出现的错误，以便及时修复。

![](../Images/175e21b2eaeda2f6d74f098f409b2b41.png)图片来自 The Verge  

按照当时公布的信息，Model 3 目前有两个版本，其中 3.5 万美元的标配版本续航为 220 英里（354 公里），百公里加速 5.8 秒，最高速度 130 英里/小时。 

而 4.4 万美元的升级版本续航为 310 英里（498 公里），百公里加速 5.1 秒，最高速度 140 英里/小时，选配 Autopilot（自动驾驶软件）要多花 5000 美元。 

另外，在当天的发布会上，特斯拉宣布 2017 年要达到每周 5000 辆车的量产速度，到 2018 年这个数字将达到每周 1 万辆。现在全球有 6000 + 个超级充电桩，两年之后翻 3 倍，到达 18000+ 个，Musk 说，这样基本你就可以开着 Model 3 任意的远途旅行了。
