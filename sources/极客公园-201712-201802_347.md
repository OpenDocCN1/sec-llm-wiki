> **过去一段时间极客之选已经体验了多款完全无线耳机，最近我们又收到了来自罗技子公司 Jaybird 的一款新品——Jaybird Run，它究竟有何特别之处呢？**

  

通常来说，音频设备的更迭频率远不如手机，各家厂商一般会按照既定的节奏更迭产品。不过 2017 年可以说是一个例外，几乎在一夜之间主流音频厂商（包括拥有音频产品线的手机厂商）都推出了自己的完全无线耳机。  

以往我们谈论「无线耳机」时，概念上几乎等同于「蓝牙耳机」。但传统的蓝牙耳机只实现了和手机连接的「无线化」，左右耳机之间仍然被一条耳机线所束缚，直到完全无线耳机的出现才彻底解决了这个问题

随着苹果 AirPods 的推出，越来越多的人开始了解到完全无线耳机的形态。而对于其他厂商来说，如何能和 AirPods 形成差异化的竞争，带来更多的特色体验就变得很重要了。

过去一段时间极客之选已经体验了多款完全无线耳机，最近我们又收到了来自罗技子公司 Jaybird 的一款新品——Jaybird Run，它究竟有何特别之处呢？」

![](../Images/e956d168e11bcf1a6bf87f0678286131.png)

![](../Images/febc4d633813baeea3c64d4604ea1804.png)

  

## 想要「甩掉」几乎不可能

从定位上来说，AirPods 是一款能够「全天候」佩戴的完全无线耳机，适合日常通勤使用，但是由于耳机本身设计的原因，在运动场景下（尤其是大幅度的运动）确实有一些力不从心，这也为其他竞争者提供了发挥的空间。

由于 Jaybird 本身就以生产蓝牙运动耳机见长，这次进入完全无线耳机领域依然发挥了这个优势。

![](../Images/368d8cc3e8b9cba5552a48603772ba29.png)

和此前极客之选介绍过的 Jaybird X3 一样，Jaybird Run 的配件也非常丰富，包括四对大小不同的耳套和四对大小不同的耳翼，以匹配不同的耳型。尤其是装上耳翼之后，想要「甩掉」Jaybird Run 几乎是不可能了。

![](../Images/9d91ed349d426e09db6b10d950cff23f.png)

Jaybird Run 的外壳涂有一层防水涂层，不用担心汗水中的酸性物质对耳机造成伤害。不过 Jaybird 官方并没有明确提到它的防水能力，应该仅限「防泼溅」。 

![](../Images/db9e14a5f9f718d7705795d3b40720fb.png)

另外，Jaybird Run 单个耳机仅重 6.8g，对于耳朵的负担比较小，适于长时间佩戴。我们试了在跑步、打篮球等场景下佩戴，耳机固定都比较牢靠，而且完全无线的设计彻底告别了听诊器效应。  

![](../Images/1656f06eba1b528b7d715b653b41352a.png)

由于去掉了线材，完全无线耳机可供交互的区域就只剩耳机罩部分，目前市面上有两种方案：一种是像 AirPods 那样的触碰方案，可以识别单机、双击等操作。另一种就是 Jaybird Run 这样耳机罩上集成按键，通过按下进行操作。

![](../Images/f1e61f13bb288b3128ea0fff889a1374.png)

两种方案各有优劣，其中按键方案符合传统的使用习惯，操作反馈明显，但是按下时会挤压耳朵（缺少支撑点），不适合频繁操作。Jaybird Run 也是一样，两只耳机操作略有不同，具体情况可以查看下图：

![](../Images/a121a9995fbde31e86651c603cf56a55.png)

Jaybird Run 区分主副耳机，其中右耳为主机，可以单独用来单独打电话（左耳不行）。

  

## 被动隔音效果出色

可充电的电池盒已经成为了完全无线耳机的标配，Jaybird Run 也是如此，它的电池盒看起来像是一个大号的胶囊，开关两侧为提示充电状态的 LED 灯。

![](../Images/656f4e31381b232607e90a03e4ec835a.png)

Jaybird Run 本体的续航时间为 4 小时，电源盒能实现两次额外充电，所以总续航时间可以达到 12 个小时，这个成绩在完全无线耳机里还是不错的。另外它还支持「快充」：充电 5 分钟可播放约 1 小时（正常充电时间为 2 小时）。

![](../Images/05301ff5b6681d025dbfc852ed9476db.png)

![](../Images/e4035b94f49ebe5f04f122e613a129e3.png)

最后说说它的音质。上面说过佩戴牢靠是 Jaybird Run 的一个特点，不过还好它的声场比较开阔，听起来不会有明显发闷的感觉。三频表现中规中矩，没有特别突出的部分（风格上很接近 AirPods 的「白开水」），不过好在你可以通过 app 自行调节 EQ 音效，低音控可以自己 DIY 下。  

![](../Images/267bda46f0b7d09841885b6c977269de.png)

得益于牢固的佩戴，Jaybird Run 拥有非常好的被动隔音效果，这其实也有利于声音的表现。不过极客之选要提醒大家的是，健身房使用时没有任何问题，但公共道路上使用时要往外注意安全问题。

Jaybird Run 的售价为 1699 元，有黑白两种外壳可供选择。这个价格比 AirPods 更贵，但是换来了更好的佩戴效果——如果你正在挑选一款适合运动场景下使用的完全无线耳机， Jaybird Run 或许是一个不错的选择。
