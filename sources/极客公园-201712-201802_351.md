# CHERRY MX BOARD 5.0 图赏：依旧全尺寸布局，但引入了樱桃游戏字体

> **不仅带来了超大的掌托，还首次采用了 CHERRY 樱桃游戏字体。**

  

对于机械键盘，不同用户群都有着各自的偏好，有人喜欢多彩背光，也有人更倾向于打击手感。但作为工具，是否能够带来不错的舒适度，无疑是大家都在关注的焦点。

今年 8 月份，Cherry 樱桃发布了以「舒适性」作为主打的  MX Board 5.0 机械键盘，我们也于近日拿到了这款产品，一起来了解下。

![](../Images/f462b65d1c6f9df829029d18386bda64.png)

对比之前的 MX BOARD 9.0，就整体外观设计而言，MX Board 5.0 并没有采用太过个性化的设计，看起来要更加符合大众口味一些。

![](../Images/056882086dd23332b59a637e167653a3.png)

与 MX BOARD 6.0，MX Board 5.0 同样为 108 键全尺寸布局，同时选择了 PBT 双色键帽，提供红轴、黑轴、茶轴、青轴等不同版本可选。另外值得一提的是，它首次采用了与德国 Typemates 共同研发的 CHERRY 樱桃游戏字体。

![](../Images/2657f940334ae509888e722fd39a1c25.png)

位于右上角的 4 枚多媒体按键。

![](../Images/f8b29ca8dd1707617daeb935489ac387.png)

和 MX Board 6.0 以及 MX Board 1.0 一样，MX Board 5.0 的方向键区域同样做了钻石面切割设计，多多少少起到了一些点缀的效果，看起来还不错。

![](../Images/a7acc4bf6be8bf92a1afc3e55b9011ae.png)

MX Board 5.0 为全尺寸白色背光，可以实现常亮、呼吸、心跳等三种不同的灯光效果，你可以根据自己的喜好，通过 Fn 与快捷键组合来自行调节。

![](../Images/b29f34f1f451b350fa7e218836a2f3d8.png)

![](../Images/ec694a4593d93187e49856e91a1c5c7e.png)

由于其采用了 PBT 双色注塑键帽，点亮之后灯光的均匀性表现令人满意。

![](../Images/a177fafb254fe4edb33a6d829521f868.png)

细节处理部分，MX Board 5.0 键盘区外围做了一圈磨砂铝合金装饰条来作为点缀。

![](../Images/1891e7fe14a9c8f421e303cd73c5209e.png)

同时，在其右上角边框与 4 枚功能按键对应位置，设计有 4 颗指示灯。

![](../Images/c30b47a542897a2ce0ad63ac3e37f139.png)

来看键盘背部。在 MX Board 5.0 底部上方，其做了三向导线槽。使用过程中，你可以根据自己的习惯，来选择合适的出线方向。

![](../Images/47ce261d866b5be2218ae40b4fd386b2.png)

键盘底部左右各有一个红色支架。另外，除了其本身自带的支架之外，MX Board 5.0 还提供了一个非常大并且支持调节的掌托，按照官方的描述，其与独特的支脚搭配，可以实现 9 种不同的姿势状态。

![](../Images/df8d303a221696f5d11712ac9732a68a.png)

由于这次寄过来的产品没有包含其掌托部分，所以这里无法为大家进行展示。不过官方标配是有这部分的，所以不必担心。

有关售价，目前 MX Board 5.0 正在搞活动，其中黑轴版本为 1139 元，青轴版本为 1169 元，茶轴版本为 1199 元，红轴版本为 1239 元，均比原价便宜了 41 元。

![](../Images/cc05550e3c8b42f67a76f54b59e3890f.png)
