# 被微软「逼」了两年，你的电脑升 Windows 10 了吗？

> **最后一个免费升级 Windows 10 的机会在 2017 年 12 月 31 日关闭。**

  

从两年前正式推出 Windows 10 开始，微软就一直努力推动用户升级，刚开始甚至还用力过猛，出现了「强制升级」的情况。到现在，微软几乎是在「求」着用户抛弃旧系统。而今天，最后一个免费升级 Windows 10 的机会也在 2017 年 12 月 31 日关闭，Windows 用户们，你们升级了吗？

  

## **Windows 10 推行之初，用力过猛**

2015 年 7 月 29 日，微软正式发布 Windows 10 系统，并允许 Windows 7/8 及 8.1 设备免费升级，据估计有将近十亿的用户受惠。在中国，微软联合腾讯和 360 为用户提供升级计划，盗版系统也可以享受免费升级。

有了 Windows 8 的前车之鉴，很多用户还没打算接受这份「好意」，微软的做法是不停推送升级通知，用各种方法来强制升级，比如把更新按钮放在任务栏，无法关闭，甚至还有很多用户遇到了自动升级的情况。

![](../Images/95c7f5e405d9d64f32f694a7e6eadd69.png)

在用户的声讨下，微软不得不给出了屏蔽 Windows 10 升级的方法。这些举措在当时看来很激进，不过联想到微软当时所处的环境也就不难理解了。

  

## **减少碎片化，推行新技术**

微软是以软件服务起家的，Windows OEM 授权是最主要的营收来源之一。但随着手机市场崛起，PC 市场开始出现疲软，根据微软 2015 年第二季度的财报，Windows OEM 的营收下滑了 22%。靠系统授权的盈利模式已经不适应新的市场，再加上苹果 2013 年将 macOS 免费提供，不管是考虑现实因素还是未来战略，微软在操作系统市场的定位都急需转型。

Windows 7 及之前版本是单纯的电脑系统，直到 Windows 8 才开始针对平板和手机设计，但微软操之过急，Windows 8 将沿用多年的开始按钮取消，变为了偏向平板操作的开始屏幕。由于操作习惯变化太大，用户并不买账，Windows 8 的市场占有率仅有 2.8%，微软在 2016 年就停止了 Windows 8 的支持，成为最短命的操作系统。

![](../Images/f50c38cfa59cbac50b90821fc72864e7.png)

用户不用新系统，很多新技术就无法推行，比如微软小娜智能助理，没有大量的数据就不能持续优化。和 Android 的碎片化一样，对操作系统管控不足影响了很多业务的发展，像搜索引擎、浏览器，这些服务本可以随着 Windows 系统深入到千家万户，但由于盗版盛行，很多电脑运行的甚至还是 2011 年发售的 Windows XP。各种捆绑软件影响了用户的体验，也在破坏整个 Windows 生态。微软想要重新整顿市场，免费好用、跨平台的 Windows 10 就成了一剂良药。

## **由卖软件转向卖服务**

在移动互联网这个新战场，系统收费已经过时，更多平台靠提供互联网服务来盈利。免费的 Android 席卷整个市场，在 2017 年 3 月份，Android 已经超过 Windows 成为第一大操作系统。为了适应移动市场变化，微软在 Windows 7 时代就开始尝试推出 Windows Phone，2014 年纳德拉接任微软 CEO 后，更是喊出了「移动为先，云为先」的口号。他在一次采访中提到，推行免费 Windows 10 的一个重要目的就是为了挽救手机业务。因为 Windows 10 是跨平台的，壮大整个 Windows 10 生态可以吸引更多开发者，自然也是在给手机业务铺路。

![](../Images/297c3815c1672a145db62c39973db3f4.png)

其实不管是手机还是电脑，系统（软件）盈利的方式都在从一次性收费到向服务收费转变。像腾讯以通讯软件起家，但它的互联网服务已经渗透到了多个场景。微软自己也推出了 Office 365 这种「软件 + 服务」的解决方案。总之一个大的趋势就是，未来系统免费会成为主流，但与之相关的服务收费只增不减。微软的 Windows 系统不论是不是正版，在市场上的普及度是很高的，这时候推行免费的 Windows 10，自然是收获大量用户的最快方法。有了一个跨平台、海量用户的生态，盈利方式就太多了。

## **更大的野心：用 Windows 10 统一全平台**

微软还有一个比统一系统更大的野心，那就是硬件业务。从 2012 年的 Surface 平板电脑开始，微软陆续推出了平板电脑、笔记本电脑和一体机等设备，最近更是传出了 Surface 手机的消息，这都是微软加强 Windows 生态管控的举措，Windows 10 更大的意义就在于串联各个平台。

![](../Images/02a1f3066d2e5a45b0be9bc191e1ca30.png)

微软曾经提到，Windows 10 是有史以来最全面的操作系统，同时也将是 Windows 操作系统的最后一版产品，之后将不会再有新版本，只在 Windows 10 基础上更新。为了让不同尺寸、不同交互方式的设备都能在体验上统一，Windows 10 引入了 UWP 通用应用平台，在 Windows 10 平台开发的软件无需重新编写就能在各种设备流畅运行。现在虽然 Windows Phone 已经失败，但 UWP 应用依然在电脑和平板间发挥着作用。

## **最后的免费船票**

微软对 Windows 10 寄予厚望，但需要注意的是，Windows 10 并不是永久免费，实际上在 2016 年 7 月，历时一年的免费升级期限就已经结束，只是微软还开放了一个特殊通道给使用辅助技术的用户。在 2017 年 12 月 31 日，这最后一个通道也将关闭，而激活一个正版 Windows 10 的价格最低为 888 元。

如果你还在使用 Windows 7/8 及 8.1 版本，不管你是否决定要用 Windows 10，都应该升一下级，因为这是最后一个「永久免费激活」的机会。只要升级一次，之后再重装 Windows 10，都会联网自动激活。

Windows 10 更新到现在，已经基本不存在兼容问题了，也不会像苹果一样给旧设备降速，这个免费的船票，你应该拿好。
