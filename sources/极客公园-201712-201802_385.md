# 马斯克确认「电动皮卡车」发布计划，这一刻已经等了 5 年

> **马斯克曾经驾驶福特皮卡 F-250 ，他说在卡车上可以改进的地方太多了。**

  

在上个月 Tesla Semi 活动上，Tesla 计划建造「电动皮卡车」的计划被爆料后，首席执行官伊隆·马斯克（Elon Musk）在最新的 Twitter 的Tweetstorm（连续多条功能）中和粉丝讨论了即将推出的 Tesla 更新和功能，同时也证实，Tesla 电动皮卡车将会在「Model Y」亮相之后。

Musk 先前已经证实，一旦 Model 3 产量大幅增加，Model Y 将作为特斯拉的重点车型来打造，它是基于 Model 3 平台打造的小型 SUV 或跨界车。

Tesla Semi 发布会上，Musk 还发布了特斯拉电动皮卡车的第一个「官方谍照」形象，但有些人一直认为这是一个玩笑。现场他说这是 Tesla Semi 的一个较小的版本和「可以运载皮卡车的卡车」。

今天，Musk 证实了自己已经拥有了皮卡车的「核心设计」，并希望在 Model Y 之后将这款「电动皮卡车」推向市场。

![](../Images/dfbee8d8e43adbf78465e43f98454de1.png)

「我保证我们将在 Model Y 之后打造一款皮卡。我在脑海里规划它的核心设计及工程原件有差不多 5 年了。我非常渴望制造它。」马斯克确实一直在谈论打造一个「电动皮卡车」。在 2013 年的特斯拉车主聚会上，马斯克讨论了关于打造皮卡车的想法。

「我非常喜欢建造卡车，我认为卡车的技术有很多。我认为卡车可以拥有一个很好的空气悬架，它可以动态调整负载，使卡车的角度保持正确，行驶高度平稳，并实时调整阻尼。」

他曾经驾驶福特皮卡 F-250 在 405 公路上行驶的时候，非常颠簸，如果有载重的话可能会好些，没有载重实在是够呛。他认为应该降低卡车重量和提升操控性。

Musk 后来还补充说，这款「特斯拉皮卡」将会和福特 F150 拥有「相似的尺寸」或比它「稍大一点」。虽然还不知道具体何时发布，但 Musk 仿佛已经找到了一个自己发布产品的节奏，接下来就等 Model 3 度过量产危机了。
