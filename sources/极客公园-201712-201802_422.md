# 王者荣耀元素 + 6GB 运行内存，这款定制版 vivo X20 是你的菜吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652851900&idx=2&sn=37869448a62a7d1828daef8edf14ec17&chksm=7e6a330a491dba1cb0c94821ef389e0d1ba304f820f9dd7362ba4a4b1d090ca48a49bd0c7f85&scene=126&sessionid=1681311061#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652851900&idx=2&sn=37869448a62a7d1828daef8edf14ec17&chksm=7e6a330a491dba1cb0c94821ef389e0d1ba304f820f9dd7362ba4a4b1d090ca48a49bd0c7f85&scene=126&sessionid=1681311061#rd)

![](../Images/1e1f2ed165fe23634f2d52dbb58e98e2.png)

> **从系统 UI 到整体外观，vivo X20 王者荣耀周年庆限量版引入了大量王者荣耀元素。**

  

作为今年的国民手游，《王者荣耀》吸引了为数众多的游戏玩家。继今年早些时候，vivo 宣布成为国内移动电竞职业赛事 KPL 的赞助商之后，前不久，vivo 正式带来了 X20 王者荣耀周年庆限量版。一起来了解下。 

![](../Images/839400923a2dd32369ac03722d604c23.png)

与其它版本有所不同的是，此次 vivo X20 王者荣耀周年庆限量版的外包装盒整体采用了黑色涂装，同时正面也更加突出了「王者荣耀」元素。

![](../Images/a5d5a23c73322e9e1c5140e2606be26d.png)

包装清单与其它版本一样，除了使用说明书、保修卡等常规配件，还附赠有 XE680 线控耳机以及透明手机套（TPU 材质）。 

![](../Images/4b55ad4646835c45f151c0cb38833622.png)

和之前的磨砂黑、黑金旗舰版以及 vivo 蓝版本一样，王者荣耀周年庆限量版同样采用了黑色前面板，而玫瑰金与金色版本的前面板则为白色。另外，机身周身的金属切边，也涂成了金色。

![](../Images/34c4c796c1898ff755c41ab95f14ed08.png)

前置摄像头为 2×1200 万像素，2400 万个感光单元两两组合成一个双核像素 ，f/2.0 光圈，全像素双核对焦，保留了前置柔光灯。

![](../Images/b1ae694c3d41e954a4aa7424c7b275c1.png)

vivo X20 配备了一块 6.01 英寸的 Super AMOLED 屏，分辨率为 2160x1080，屏幕比例为 18:9。由于采用了「全面屏」设计，上下「额头」得以大幅收窄，官方宣称它的屏占比达到了 85.3%。

![](../Images/a326215ff6af14266f9823654258057c.png)

值得一提的是，除了整体外观方面，此次 vivo X20 王者荣耀周年庆限量版的系统 UI 以及壁纸部分，同样引入了王者荣耀元素。

![](../Images/2c8990d4cdeb287f449c198949a77097.png)

按照官方给出的数据，vivo X20 的机身三围分别为 155.85 × 75.15 ×7.2mm，机身重量为 159g。当然，由于背部做了一定的弧度处理，所以看起来要更薄一些，整体握感不错。

![](../Images/94327c7f5d5769d9b10c7db0b0c6f59d.png)

机身背部是 vivo X20 王者荣耀周年庆限量版最大的亮点所在，同样也是其明显区别于其它版本的地方。除了配色方面，其采用了红黑撞色设计，背部中央还印有金色的王者荣耀 logo。

![](../Images/06b1e77fc31184217ab1df099b4e86ed.png)

后置摄像头采用了 2x1200 万像素（2400 万感光单元）+ 500 万像素的双摄解决方案，主摄像头光圈为 f/1.8，支持全像素双核对焦，不过不支持光学防抖。

![](../Images/a5c3af7ad37734c57942f7e95b5fd62d.png)

耳机接口和 USB 接口依旧位于机身底部。另外有关续航，vivo X20 的电池容量为 3245mAh，充电头最大功率 18W（Micro USB 接口）。

![](../Images/ce1ead8075d3af1fafaf13a72281089f.png)

硬件配置方面，vivo X20 王者荣耀周年庆限量版依旧搭载了骁龙 660 平台以及 64GB 机身存储，不同的是，运行内存容量增加到了 6GB 。特别的是，由于特别优化过，所以在运行《王者荣耀》这款游戏的时候，vivo X20 的表现很出色。

![](../Images/5e8bb17d6f1598e144bf5e07719d045f.png)

目前 vivo X20 王者荣耀周年庆限量版已经在 vivo 官方商城以及京东商城等第三方电商平台开售，价格为 3498 元，比其它版本 4GB + 128GB 的顶配版贵出 100 元。 ■
