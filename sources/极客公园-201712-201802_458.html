在未来的一个月，极客之选将陆续揭晓 15 款年度获奖产品。在梳理过去一年优秀产品的同时，也希望能给大家年底的「败家清单」提供一些参考。

本次公布的是年度智能家居：Amazon Key In-Home Kit。


相比于智能音箱的火爆，「智能家居」的概念在 2017 年反而黯淡了许多。当「联网」已经成为智能家居的必备技能后，硬件产品和软件、服务产生更为紧密的结合，成为过去一年智能家居行业的主旋律。

具体来说，智能家居仅仅依靠在控制方式上的创新，已经很难继续和消费者产生共鸣。只有完美融入日常的生活服务中，才能发挥更大的价值。在这条演进方向上，亚马逊在美国 37 个城市提供的 Amazon Key 服务可以说是其中最为激进的一个。

相信每个人都遇到过快递送货上门但人不在家的尴尬情况，Amazon Key 服务的出现就是为了解决这个问题。简而言之，它通过继续手段让快递员可以「送货到家」。

Amazon Key In-Home Kit 并不是一款单独的硬件，它包括智能摄像头、智能门锁和手机 app，通过设备联动工作自动为快递员开门，并且监督整个过程。

便利和隐私往往处于天平的两端，Amazon Key 对于便利的「加码」自然会引发一些争议，自上线以来，关于它隐私安全的质疑就从来没有停止过——Amazon Key 甚至被一些人评为「年度失望产品」。

但不可否认的是，Amazon Key 完美解决了物流运输中「最后一公里」的问题，极大地提升了配送效率。尽管现在还不完美，但这种对于智能家居应用边界的探索，一定是值得鼓励的。 ■
