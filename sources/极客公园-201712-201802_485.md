# 全新车内娱乐系统？奔驰在下月 CES 又要用黑科技「剑走偏锋」

> **在车内我们究竟要怎么娱乐？**

  

最近，梅赛德斯宣布，公司将在明年 1 月的 CES 上发布一套全新的信息娱乐系统--梅赛德斯-奔驰用户体验（以下简称 MBUX），这也是梅赛德斯的首歌全新信息娱乐系统的发布。

基于人工智能和直观操作系统的创新技术，MBUX 将迎来信息娱乐和梅赛德斯连接的「新时代」。

![](../Images/042362fe50531b29c76b108bb400759b.png)

为了确保开创性的科技感车载体验，这款产品预计最高 2018 年就会跟消费者见面，该技术将作为下一代新款紧凑型汽车的标准设备引入。梅赛德斯表示，MBUX 将为用户带来一个开创性的车内体验。

除了 MBUX 之外，梅赛德斯还计划在下个月 CES 上带来 3 款重要的新车--EQA 电动掀背概念车、Smart Vision EQ Fortwo 城市概念车、梅赛德斯-AMG Project One 跑车。

此外，拉斯维加斯也是「智能世界大道」的最后一站，梅赛德斯 - 奔驰已经在所有五大洲测试了自动驾驶功能。以便使未来的自动化和自主驾驶功能适应特定国家的用户和交通状况。自动驾驶汽车道路测试在洛杉矶地区以及随后在拉斯维加斯的 CES 上进行，主要集中在密集城市交通和高速公路上的驾驶行为评估。基于 S 级轿车的「Intelligent World Drive」智能测试车也将在 CES 展出。
