# 坐着看球累吗？或许你可以试试这把世界杯主题款电竞椅

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652855819&idx=2&sn=124cd4bac140cf8e1ad9a1c86746ae0c&chksm=7e6a23bd491daaabbff9535e56635ca44f823cea32fc85884752957e5b26343d6729582519a1&scene=126&sessionid=1681310900#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652855819&idx=2&sn=124cd4bac140cf8e1ad9a1c86746ae0c&chksm=7e6a23bd491daaabbff9535e56635ca44f823cea32fc85884752957e5b26343d6729582519a1&scene=126&sessionid=1681310900#rd)

![](../Images/1052436e0296176d4f7a796ec556d661.png)

> **采用了「加大」包裹设计，AutoFull 傲风的这款电竞椅坐起来确实很舒服。**

  

作为体育界最具影响力的赛事之一，世界杯已经成为了一个超级 IP。每逢世界杯赛事到来，我们总能看到各种各样与之相关的产品到来。比如前不久，FIFA 电竞世界杯官方指定电竞椅品牌 AutoFull 傲风就带来了一款世界杯主题款电竞椅——AutoFull 傲风足球先生电竞椅。

![](../Images/15282da027482696a04e118ea991b27e.png)

与 AutoFull 傲风以往其它产品有着明显不同的地方在于，这次其在椅子的靠背上增加了足球刺绣，搭配颜色鲜艳的彩带，颇有些运动的感觉。

![](../Images/27bf196f3b71c89e5425e3c0127e788d.png)

当然，作为一款电竞椅，产品本身的舒适度如何，可能是大家最为关注的地方。AutoFull 傲风足球先生在舒适度上，也同样下了不少功夫。

![](../Images/dde293c9bea0bb6c8e7c7da17fcfb774.png)

从下图中可以看到，它在靠背上方做了两个对称的三角形透气口，来保证透气性。就实际效果而言，效果还是比较令人满意的。

![](../Images/80e2c3cd7d5c7f7329416ba068285535.png)

为了进一步提升椅子的舒适度，AutoFull 傲风足球先生电竞椅附赠有一个同样绣有彩色飘带的靠枕。

![](../Images/c643e4ae451487177b37c5ac31090c4f.png)

值得一提的是，它的头枕既可以插在透气孔里，也可以直接套在椅背上，你可以根据实际需要，来自主调节其上下位置，十分方便。

![](../Images/094b419c2ec95a9c7ea283a8d3196441.png)

另外，根据官方给出的数据，它的椅背高度达到了 83cm，可以为绝大多数使用者提供非常好的支撑。

![](../Images/bcdb8dd685a114c8c3f28d68cf4def30.png)

和 AutoFull 傲风以往的很多一样，AutoFull 傲风足球先生电竞椅的椅座和椅背也做了包裹设计，不过这次它做了加大处理，整体包裹性表现还是不错的。

![](../Images/c8516933ac0a2d84845add1bd2c0c83a.png)

了解电竞椅的朋友应该知道，它的一大特色在于可以将椅背放下来，你可以后躺在上边休息，AutoFull 傲风足球先生电竞椅也不例外。

![](../Images/42edf9916507b978f9f06e2df5cd93d5.png)

它的椅背最大打开角度为 160°，由于底部采用了高承重的「五爪」式设计，稳定性非常高。当你躺在上边的时候，完全不必担心会出现后翻的情况。

![](../Images/1e65f461c81a386208cd2c29c6464f46.png)

除了以上我们提到的这些，AutoFull 傲风足球先生电竞椅在椅子两侧扶手的设计上，做了带有弧度的凹槽，手臂放在上边的舒适度是相当不错的。

![](../Images/5622a77c442006212adc4f6feb0dc0ae.png)

总体来讲，作为一款世界杯定制款电竞椅，AutoFull 傲风足球先生电竞椅在舒适度上的表现是比较令人满意的。同时 1099 元的定价，在同类产品中也属于比较合理的价位，最近有想要入手电竞椅的朋友，不妨关注下。 ■
