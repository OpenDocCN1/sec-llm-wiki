# 亚马逊第二家 Amazon Go 秋季开业，无人便利店技术准备好了吗？ | Global 24/7

> **第二家 Amazon Go 距离第一家只有一英里，占地面积却翻倍。**

  

2016 年，亚马逊提出的无人便利店概念吸引了不少人的关注。2018 年初，第一家无人便利店 Amazon Go 首次向公众露面就获得了外界的认可和好评。日前，据外媒 GeekWire 报道，亚马逊有意乘胜追击，开设第二家无人便利实体店。

据悉，第二家店仍将开在亚马逊总部所在的西雅图市，距离第一家 Amazon Go 仅仅一英里的距离。

其实第二家开店早已有迹可循。有人发现了「亚马逊零售」项目的许可证，透过装修店铺的玻璃，街边过客也可以看到 Amazon Go「NO LINES.NO CHECKOUT.」（无须排队，无须结账）的标语。

亚马逊也在声明中证实了这一消息：「我们很高兴把 Amazon Go 带到西雅图第五大道 920 号，新店将于 2018 年秋天营业。」

![](../Images/6f2aa8cfe586a2c0e35fb6594d9742bb.png)         

## 第二家店面积翻倍

2016 年底，坐落在总部大楼底层的第一家 Amazon Go 只对员工内测开放，直到今年一月，才正式对外营业。有报道称，Amazon Go「千呼万唤」都不肯露面的原因是店内技术遇到困难，但亚马逊却坚称并非如此。

在亚马逊在宣布无人便利店概念之后，有关于 Amazon Go 扩张的消息就不胫而走。Recode 曾在二月报道称，亚马逊计划在年底之前再开六家新店。五月份亚马逊证实将继续在旧金山和芝加哥开设 Amazon Go 无人便利店，但是当时没有说明具体的开业时间和地点。然而，从亚马逊的目前动作来看，显然已经转移了重心。目前还不清楚，亚马逊为什么要在同一座城市开设两家店，也许是出于想快速抢占西雅图零售市场的「野心」。

根据西雅图政府签发的许可文件，新店规模比第一家店更大，占地 3000 平方英尺（279 平方米），而第一家店只有 1800 平方英尺（167 平方米）。由于店内面积不大，第一家 Amazon Go 同时能接待的顾客上限是 97 人。一旦超过这个数量限制，就只能采取限流措施。店里是不用排队结账，但是想要进入 Amazon Go，却得排队等待。

亚马逊表示目前没有计划将耗时四年时间开发的无人便利店「Just Walk Out」系统扩展应用到其收购的全食超市中。因为全食超市平均面积为四万平方英尺，这样后勤方面的挑战将会大大增加，即便第一家 Amazon Go 得到外界的褒奖，亚马逊方面表示仍在努力改进服务，更多的人流和更频繁的商品交易将为亚马逊的算法技术带来更大的考验。

![](../Images/0a5822ae010798d37d85317f6f4f4ea9.png)

  

## 「无人便利店」技术受追捧

Forrester Research 首席分析师乔治·劳里（George Lawrie）表示，数字技术几乎改变了零售业的方方面面，赋予了顾客权利，同样也给他们更多的期待。劳里称，亚马逊一直在线上努力创造「亚马逊风格」的客户体验，现在它正在将这种独特的体验扩展到实体零售。「Amazon Go 的好处是：速度和方便，而这对于顾客来说太重要了。理想的购物体验应该是非常顺畅的。」

根据 451Research 数据，在过去的一年里，86% 的美国消费者会因为排队太长而换了另一家或者直接放弃购物。451 Research 的研究总监 Jordan McKee 说:「这导致潜在销售损失约 377 亿美元。」此外，75% 的购物者表示，他们会在亚马逊这样的支付体验良好的商店里购物。

风险投资公司 Loup Ventures 的研究主管吉恩·蒙斯特说:「Amazon Go 正在做的事情是零售业的未来」。该公司估计，美国自动收银市场价值 500 亿美元，收银员是美国最常见的工作之一。显然，亚马逊也并不是唯一一个想要抓住机遇的公司。

Amazon Go 推出几个月后，Tesco（全球三大零售企业之一）在英国测试自动结账技术，并开发了 Scan Pay 应用程序，先在内部员工中试点，测试一旦成功将会广泛推行。根据路透社的报道，微软雇用了 Amazon Go 前计算机视觉专家，正在尝试在购物车上安装摄像头来跟踪物品，已经有零售业合作伙伴在微软云服务的基础上建立了自动结账系统。微软已经跟沃尔玛进行合作沟通，希望以此来「制衡」亚马逊。

## Amazon Go 是零售业的未来吗？

「Just Walk Out」系统，集合了计算机视觉、传感器融合、深度学习等技术。用户通过扫描二维码进入超市的玻璃门，就如同进入办公大楼的门禁一样简单。头顶上的摄像头和货架上的重量传感器可以自动追踪用户购买的商品。顾客离开时不需要结账，系统会自动扣款，然后将账单发到顾客手机中，从而告别传统耗时的结账流程。         

但从目前来看，Amazon Go 只实现了自动收银，便利店运营仍然需要员工支持，比如门店限流、货架补货、在顾客买酒时检查 ID。虽然 Amazon Go 的模式受到竞相追捧，但不能证明其就决定了未来零售行业的走向。

Constellation Research 的首席分析师兼创始人 Ray Wang 认为，在任何交易下，人为因素和交易背景都需要被考虑进去并举例「有时候顾客在酒店登记时，不想和礼宾员交谈。但是如果换在五星级酒店内，他们可能需要迎宾员提供高质量和个性化的服务。还有在瑞典和荷兰，人们更喜欢现金的结算方式。」在未来，无人零售领域的用户体验始终是核心竞争力所在。目前来看，技术明显是不成熟的。

使用人工智能「简化」零售流程就意味着前期更「复杂」地捕获数据，公司更「详细」地了解客户。Wang 表示，公司如果能确定「顾客在决定购买时处于什么样的位置、感觉如何、外面是什么天气、顾客的心率怎样」等数据，将会对于理解购买前后的状况非常有用。而随着技术的成熟和扩张，这些数据的搜集会涉及到个人隐私，未来无人零售的成功与否还取决顾客是否愿意用隐私交换方便。

![](../Images/615953d01f441fb31bb8903e334ca3f4.png)

亚马逊副总裁狄利普·库马尔（Dilip Kumar）今年早些时候接受采访时表示，亚马逊正在改进技术，争取以尽可能少的信息识别商品和顾客行为，这也表明了也许现在谈 Amazon Go 代表零售业的未来还为时尚早。但是从亚马逊的一系列动作来看，收购全食超市、推出实体书店、设立亚马逊生鲜自提点，Amazon Go 同样是亚马逊实体零售开拓战略的一部分，其在零售行业的布局也足以窥见这家公司的野心和信心。
