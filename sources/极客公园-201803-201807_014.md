> **Google Cloud 丢失用户数据，损失数百万美元，谷歌如何才能突破桎梏实现「后来居上」？**

  

六月底，一篇名为《为什么你不该使用 Google Cloud》的文章在国外互联网上引爆。

作者是 Google Cloud Platform（GCP）的一名用户，他在文章中抱怨称，Google Cloud 在毫无预警的情况下关闭了它们跑在云端的一个项目。

更令他们愤怒的是，Google 没有留给他们解释的机会，便将其项目关停了数个小时，虽然经过沟通和努力「抢救」回几个小时的数据，但还是造成了近一个小时数据的损失。

  

## 一小时数据凭空消失

![](../Images/48e2141c37be476ec3eb45f0a05af06c.png)

文章提到，公司利用 Google Cloud 构建服务，用于监控遍及 8 个国家、数百个风力发电机以及太阳能发电厂的状态，并通过监控仪表盘告知管理人员风力发电机以及太阳能发电板的健康状况，同时在需要维护时实时请求服务。另外一边，文章作者的团队还使用 Google Cloud 提供的 BigQuery 服务，通过算法来控制电力的生产情况，这些都直接与营收息息相关。

并且，由于风能与太阳能都属于易消耗资源，无法存储与销售，因此需要 24 小时不间断地监控，依照电网的需求以及用户的购电量进行实时调整。如果产能不足的话，就会被处以罚款。

当地时间 6 月 28 日凌晨，该团队收到监控服务 Uptime Robot 的通知，警告他们整个网站的服务已陷入停滞。与此同时，公司收到了 Google 的邮件，Google 表示因他们的服务存在一些可以的行为，因此将他们的所有活动全部停止，包括数据库、网站停用以及 Firebase 权限降级。

在事件发生后，该团队表示没有直接联系 Google 的渠道，在线服务系统也被关闭。只收到一封电子邮件，要求负责人填写修正表格以修正可疑行为，并上传信用卡、身份证明照片，否则将在 3 天内删除整个项目。所幸在负责人紧急填写完表格后，Google 在 20 分钟后为他们恢复了服务，但还是造成了几乎一个小时的数据空白。

这件事在论坛上引起了用户的激烈讨论，多数网友认为 Google 没有事先预警就强行关闭服务的做法太过强硬，也有用户表示即使付给 Google 高额的服务费用但是获得的服务质量仍然堪忧。

  

## 火上浇油：COO 离职

无独有偶，7月4日 Google 被爆云服务 COO 黛安娜·布赖恩特（Diane Bryant）在入职不满一年的情况下就辞去了工作，对此 Google 发言人在一份声明中说：「我们感谢她在 Google 期间为公司做的贡献，并祝她未来一切顺利。」

![](../Images/4dc8bb9ee45b200b2eca0c611b3dca16.png)

在加入 Google 之前，黛安娜在英特尔公司工作了长达 25 年，主要负责数据中心团队，后因为「家庭问题」离开英特尔，加入了 Google。

而聘用黛安娜也被看做是 Google 进入云计算领域的一个重大胜利。在业界看来，Google 作为排名第三的云计算服务供应商，相对亚马逊的 AWS 和微软 Azure 来说还只是一个「后来者」，因此 Google 更需要招揽行业领军人物扩充实力，并向各公司证明自身。

今年 5 月，Google 收购以色列云计算公司 Velostrata。该公司致力于帮助企业将运营数据迁移至互联网云服务供应商，亚马逊 AWS 和微软 Azure 都曾是它的服务对象，不过，在被 Google 收购后，Velostrata 可能会停止帮助企业将数据迁移到 Google 竞争对手的云计算平台上，并且整个团队将会加入 Google。

  

## 云计算之争谁是大赢家？

尽管 Google 在努力推动 Google Cloud 服务于更多的企业和更深的业务层面，但当涉及到企业的信任程度和使用频率上，Google 仍然落后于亚马逊 AWS 以及微软 Azure。日前，Google Cloud 负责人在接受采访时表示，Google 正在准备在合适的情况下开展各项收购业务，以此来追赶亚马逊和微软在云服务方面的行业领导地位。

在过去的两年里，Google 压缩了许多成本高昂的研究项目，但对云服务项目，却持续大力地投入资金，这无疑表现了 Google 对云计算领域的重视。在 2018 年 1 月，Google 推出了新的数字商店，面向企业和其他机构销售云计算软件，借此机会追赶亚马逊、微软等行业领头羊。

![](../Images/faff84ede4d39022c459edc939f377c0.png)

面对 Google 等「后来者」的追赶，作为最先进入行业、用户接受度最高评价最好的亚马逊 AWS 也没有放慢脚步，依然力求创新，保持自己的行业领先地位。AWS 首席执行官表示：在时机成熟时，AWS 有望成为亚马逊内部最大的业务。并且，亚马逊还力求与各个行业巨头开展合作（如西门子），这也使得在口碑上得到了强力的保障。

作为近年来的热门，各大科技巨头对云计算重视有加。在激烈的行业竞争中，不论国内国外，众科技巨头争相「不惜血本」发展云服务，努力提高自身的竞争力和口碑。到头来，也许云服务的赢家是谁似乎并没有那么重要，作为服务受益者的企业和用户，能获得更优质的服务和使用体验，才是云服务本身的意义所在。
