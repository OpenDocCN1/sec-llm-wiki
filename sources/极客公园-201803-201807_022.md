# 小米生态链的又一诚意之作：工作娱乐性价比兼顾的游戏鼠标

> **除了无线/有线双模式切换，还有特殊灯效，小米的第一款游戏鼠标有亮点，不过也有需要加强的地方。**

游戏外设领域从来都不乏竞争者，我们熟知的罗技（Logitech）、雷蛇（RAZER）、赛睿（Steelseries）、海盗船（CORSAIR）、樱桃（Cherry）等都是深受玩家群体喜爱的品牌。  

不过说起来，这些国际品牌在价格上并不十分亲民，所以大家更希望有更多走性价比路线的厂商出现。最近，小米生态链公司米物科技就带来了一款双模游戏鼠标，这款 249 元的产品的确给我们带来了一些惊喜，简单体验之后，今天极客之选（微信号 GeekChoice）就来和大家分享一下这款产品的使用感受。

![](../Images/df8a6c779a027bdbdc88e8101900d7d7.png)

![](../Images/ccc13353e360bd45aff0c7c318c424f2.png)

游戏鼠标和游戏键盘一样，都是相当具有标签化的电子产品，很多人即便不使用这类产品，但当它们和日常使用产品摆在一起时，差异一看便知。

小米游戏鼠标在外观方面也下了一番功夫。机身整体选择黑色+深灰色的色彩搭配，外观采用略带棱角的设计，对男生来说更有吸引力，但对女生来说可能不是很带感。另外，棱角设计在外观上呈现硬朗和凌厉的风格，在手感上相比更圆润的产品会稍显逊色。

![](../Images/c8668ea553ef9e83123a8bf1cc8d1040.png)

虽然并非左右完全对称，但小米游戏鼠标整体的给人的观感比较讨好。从正面看，除了左右按键、滚轮之外，在滚轮下方的两颗按键代表的是 DPI 加/减按键，官方提供了从 50-7200DPI 的调整范围，方便玩家在工作和娱乐时的不同选择，调整过程中，鼠标左侧还会通过指示灯提示当前 DPI 档位，做到心中有数。  

![](../Images/9a4a058fbf4231c14a98902265e33ba6.png)

本次小米游戏鼠标采用的是有线/2.4G 无线双模切换，所以有线部分采用可拆卸的 Micro-USB 连接线，这个开口两侧有导轨设计，连接处设计上也有外观上的防呆设计，因此不会造成正反误插，另外，鼠标线材材质使用编织材料，不论从收纳或者长时间使用都要比一般橡胶材质好上不少。

![](../Images/09e9db6a5319580c273959657c60b447.png)

既然是双模鼠标，那么接收器在哪呢？在小米游戏鼠标上，这个 2.4G 接收器被巧妙藏在了鼠标前盖内，前盖采用磁吸式设计，因此无论拆卸或是安装都要方便不少，也不用担心不小心扣坏的问题。  

![](../Images/9a9aed42edb80108309667066ecde21e.png)

鼠标左侧共有三个不同按键，有两个是常见的前进/后退按键，但位于偏下方的单独按键则不太常见，这是一颗快速瞄准键，用于游戏中的快速瞄准。当你在瞄准的同时按下按键，DPI 会被调整到预先设定的较低数值，从而让你迅速确定目标并开枪，这个差异化设计自然是针对当下流行的 FPS 游戏。

![](../Images/da889dcc2655e02b7bf72506071c71f6.png)

鼠标右侧没有多余的按键，不过细心的你可能发现了，在鼠标两侧都有这种带有纹路的橡胶贴合，作用自然是在使用时避免手汗导致鼠标脱手，实际上握持时这样的摩擦力也恰到好处。

![](../Images/4b08da2b58708891e55e902c57392957.png)

最后是鼠标底部，除了防滑贴外，这一次小米选择将自己的 Logo 低调放在底部的圆形脚垫上，脚垫部分的一个重要作用是增加鼠标配重，熟悉游戏鼠标的朋友大概知道，在玩一些竞技游戏时，鼠标重量如果太轻反而会有飘忽忽的感觉，保持一个合适的重量会让操作更稳，另外，切换无线模式之后的开机按键也在底部。

![](../Images/648b574255271ba4e53426490701fe39.png)

![](../Images/76c893e925ae227f971d1e2278f6a398.png)

鼠标产品上，小米并非第一次尝试，但是在游戏鼠标这件事上，小米游戏鼠标的确算是「新人」，相信很多人除了对价格感到意外之外，最希望知道这款鼠标究竟在使用上有哪些不一样的地方，所以在看完外观后，我们不妨看看它的使用特色，首先看看小米游戏鼠标的基础配置：  

*   产品尺寸：126mm \* 68mm \* 41mm  
    
*   产品重量：139g（含电池）  
    
*   分辨率：50 - 7200DPI  
    
*   输入参数：5V 500mA  
    
*   工作温度：0℃ ~ 40℃  
    
*   工作距离：＜10m  
    
*   最大加速度：30G  
    
*   USB 报告速率最大：1000Hz  
    
*   无线报告速率最大：1000Hz  
    
*   适用系统： Windows7 或 macOS 10.10 及以上版本  
    
*   其它：支持可编程按键、支持 RGB 灯光自定义  
    

作为有线/2.4G 无线的双模游戏鼠标，我们在使用上最关注的有两方面，日常生活和游戏。无线模式配合日常办公生活，有线模式针对游戏。

![](../Images/b7577a8f692b3dfc2c5185a7f79749d5.png)针对鼠标的精细化设置，小米游戏鼠标专门推出了 Windows 和 macOS 系统的控制软件，在官方页面即可下载  

首先说说无线模式，小米游戏鼠标的 2.4G 接收器体积小巧可以随时吸纳，即便你是经常外出也可以随身携带并且不用担心丢失。

无线模式最大工作距离能到 10 米，日常无论是台式机或者笔记本都能发挥很好的作用。尤其需要说明的是，本次小米游戏鼠标支持 Windows7 或 macOS 10.10 的软件设定，这意味着一些自定义按键（包括组合键）在 macOS 上同样支持，可以说是 macOS 玩家的福音。续航方面，鼠标内置 900mAh 电池，日常无线使用时长最大 10 小时，连接有线模式会持续充电。

![](../Images/a723362c8c20f2c5be83a0d3498e925c.png)

说到有线模式，我们自然是试试看游戏体验，本次小米采用的是来自原相的 PMW-3330DM 传感器，打开《绝地求生》进入到单人模式下，7200DPI 带来的操作体验很流畅，支持 125、250、500、1000 四个挡位报告率设定。最大加速度 30G 带来的直观感受是鼠标滑动时距离更小，操作更快。1000Hz 的回报率也让鼠标的响应时间更加迅速。

![](../Images/ffd30f731494f2c0d38ee5a28de32447.png)

这里要说到鼠标侧面的这颗快速瞄准键，虽然在日常使用时它几乎起不到作用。但在游戏中，尤其是 FPS 游戏中的瞄准+射击过程，当你在打开瞄准镜射击时，按下这颗按键带来的画面稳定的确让操作更加方便，鼠标两侧的橡胶材质也让操作时摩擦力更大，稳定性更好。

![](../Images/9f58d2793c4683b85fd992d5bd685408.png)

另外，作为游戏鼠标的产品怎么能没有灯效？在软件中，你不但可以自定义滚轮以及底部的 RGB 灯光颜色，还能选择常亮或者呼吸的灯效，好玩的是，你可以单独为鼠标滚轮以及底部设定不同颜色的灯光，看起来还是很酷的，不过目前灯效还太少，我们希望在这方面能看到小米发挥更多想象力，毕竟玩家对于外设的「光污染」还是很在意的。

![](../Images/e33e4e4dfb4cd3d69e79e7654f5f6975.png)

![](../Images/4fbff3f7cf2d5fe83b22ac3f07f0f9bd.png)

作为游戏鼠标方向上的初次尝试，我们很欣喜地看到，小米游戏鼠标这一次不但有一个令人惊喜的价格，在产品体验上也同样充满亮点。不论是额外的快速瞄准按键，还是鼠标整体可自定义按键甚至组合键的功能，都让人觉得考虑细致，外观设计上充满棱角也有小米自己的特色。

虽然在手感上还会和一些大厂有差距，灯效也还可以更大胆一些，但在 249 元的价位上，这款双模鼠标会是游戏玩家一个新的选择，而对于工作/游戏两不误的用户来说，或许这款产品也会让你感兴趣。
