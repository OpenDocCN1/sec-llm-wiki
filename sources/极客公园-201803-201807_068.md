从全行业最高的 93.8% 超高屏占比，到内置了 3D 结构光的可升降全隐藏式 3D 摄像头，再到前后玻璃盖板无任何开孔的极简设计，过去的三天里，OPPO 时隔四年推出的 FIND 系列新旗舰 Find X 占据了几乎所有海内外科技媒体的头条。  

这场在卢浮宫举办的 Find X 的发布会上，除了发布手机，OPPO 还宣布了一个重要消息：进入欧洲市场。

不过在聊这件事之前，我们有必要先说说兰博基尼。

  

## 和「正宗」的 Automobili Lamborghini 合作

对于羽翼逐渐丰满、志在进军欧洲市场的国产手机品牌来说，和历史悠久的高端品牌跨界合作不失为一种提高品牌知名度、拉高品牌定位的有效方法。

所以，当 OPPO 在 Find X 的发布会上宣布和兰博基尼跑车的制造商 Automobili Lamborghini 达成战略合作的时候，在现场掌声的背后，其实并没有让太多的「场外观众」感到意外。

不过在和兰博基尼汽车达成合作这件事的背后，其实还有一段值得玩味的故事。

![](../Images/7aeda483fc375dd935f2f3d550e850c0.png)

OPPO 和兰博基尼的合作并不是一个筹划很久做出来的决定。直到今年 3 月份，距离 Find X 发布只有不到 4 个月的时候，经过熟人的牵线，OPPO 才和兰博基尼进行了接触。  

彼时，兰博基尼正在做一些品牌延伸的工作，在全球寻找合适的合作伙伴，在 3 月份第一次接触后，两家公司发现彼此在产品设计、技术研发上高度契合，于是迅速达成了合作共识。

4 月份的时候，OPPO 副总裁、现任 OPPO 海外市场业务负责人吴强专程前往意大利的兰博基尼总部，敲定了最终的合作细节。

一同前往意大利的还有 OPPO 设计总监范晓宇带领的设计团队，在那一次的行程中，OPPO 和兰博基尼的设计师进行了多次的交流，敲定了 Find X 兰博基尼版上的一些设计元素，包括后盖的碳纤纹理、LOGO 的设计、包装盒的风格、超级闪充头和数据线的细节。

OPPO 很快将这些双方设计师共同碰撞出来的元素变成了最终的产品，并在 Find X 的发布会上作为最后的「One More Thing」呈现给了全球观众。

  

## 从内到外全面定制的 Find X 兰博基尼版

相比普通版 Find X，兰博基尼版在外观上的主要变化有两处。

![](../Images/2646d0297ec24dca9ffa34e380ad9862.png)

Find X 兰博基尼版的后盖同样采用了渐变处理，不过边缘增加的是碳纤维纹理，相比普通版 Find X 的红黑渐变或者蓝黑渐变多了一些「阳刚」的感觉。  

其次，兰博基尼版在后盖的下方增加了立体印刷的兰博基尼标志，替换了「Find X」标志。

![](../Images/4ff7761fc6363c12b229dd20614eca19.png)

除了手机本身，OPPO 还为 Find X 兰博基尼版定制了一套专属的包装盒。  

这套包装要比普通版的 Find X 大了不少，包装盒大范围采用了兰博基尼标志性的橙色，附送的充电头上增加了兰博基尼的标志，充电线采用了编制设计，灵感来自兰博基尼的 V12 发动机进气口。

这还不算完，Find X 兰博基尼版还首发了 OPPO 全新的 SuperVOOC 超级闪充技术，充电头功率达到了惊人的 50W（10V 5A）。根据 OPPO 提供的数据，只需要 35 分钟就可以将 Find X 兰博基尼版内置的 3400 毫安时电池（标准版 Find X 电池容为 3730 毫安时）完全充满。

  

## 全方位的战略合作

对于 OPPO 和兰博基尼汽车来说，Find X 兰博基尼版还只是一个开始。

在接受极客公园在内的媒体采访时，吴强表示，「OPPO 和兰博基尼汽车之间的合作，不仅仅只是一个授权、合作共同推一个定制产品，我们的合作是在全球全方位的战略合作。」

在具体的合作方式上，吴强强调了三点。

第一是共同设计。

未来兰博基尼的设计师和 OPPO 的设计师会一起工作，对未来的产品共同碰撞，联合打造产品。

吴强还透露，OPPO 和兰博基尼的合作将不限于旗舰的 Find 系列，未来根据市场需求也有可能推出「时尚爆款」R 系列的兰博基尼版。

第二是技术上的打通。

![](../Images/656a02c71333120cdbb0b0bcb7656cc1.png)Urus

据吴强介绍，OPPO 一开始希望将快速充电技术应用在兰博基尼刚推出的 SUV Urus 上，不过兰博基尼认为，这项可以大幅提高充电体验的技术不应该仅限于这款车型，应该推广到更多的车型中。

目前，OPPO 和兰博基尼汽车已经启动了相关的技术评估，不出意外，未来我们将在兰博基尼的多款车型上看到 OPPO 的快速充电技术。

第三是推广资源的共享。

未来，OPPO 和兰博基尼将在市场推广上进行很多的联动，OPPO 将参与到兰博基尼组织的赛事中，兰博基尼也将支持 OPPO 在多个国家的市场推广工作。

OPPO 还将和兰博基尼汽车分享部分销售渠道，未来消费者将有机会在兰博基尼汽车的销售点购买到 OPPO 的兰博基尼版手机。

  

## 以「循序渐进」的方式在欧洲市场「小步快跑」

对于志在欧洲市场的 OPPO 来说，和兰博基尼汽车的合作有助于快速提高其在欧洲地区的品牌知名度，再加上 Find X 这款在产品形态上进行了众多创新、在欧美科技媒体中获得很多好评的旗舰手机，OPPO 就有了两块分量十足的「敲门砖」。

当然了，想要在这个智能手机年销量超过 1 亿的成熟市场站稳脚跟，OPPO 还需做更多脚踏实地的工作。

![](../Images/65ba140d94b4c92ca64f53a6ec62bc1a.png)

「循序渐进」是 OPPO 在谈及欧洲战略时经常用到的一个词，作为一家已经在手机行业摸爬滚打了 10 个年头、市场份额稳居行业 TOP5 手机巨头，OPPO 希望以一种尽可能健康合理的方式逐步深入潜力巨大的欧洲市场。

OPPO 将率先进入法国、意大利、西班牙、荷兰 4 个国家，之后再逐步拓展到更多的国家。

销售渠道上，OPPO 将重点放在了线下公开卖场以及运营商渠道上，这两种渠道占据了欧洲地区超过七成的出货量。

基于印度、东南亚、澳洲、非洲、日本等超过 30 个海外市场的经验，OPPO 格外看中本地化运营，OPPO 将在进入的欧洲国家招募当地国家的员工，组建本土的运营团队，计划将有超过 90% 的员工来自欧洲本土。

此外，OPPO 还将和欧洲当地的艺术院校合作，吸引当地的人才，位于欧洲的全球设计中心也在积极推进中。

OPPO 的「循序渐进」还体现在前期精心的准备上。

早在两三年之前，OPPO 就已经在欧洲开始了专利布局，比如将在欧洲注册部分核心专利、进行相关的收购。在 Find X 的发布会上，OPPO 透露目前已经积累了超过 22000 项专利。

![](../Images/1ca718c90892d633fc838476e94db1be.png)

除了自身的积累，OPPO 还在积极和高通等合作伙伴合作，让专利问题不会成为 OPPO 进入欧洲市场的障碍。  

  

## 「未来旗舰」Find X 和水到渠成的欧洲市场

在经过了智能手机普及、4G 时代、消费升级的红利之后，从去年年底开始，国内智能手机市场逐渐进入了 5G 之前的红利真空期，反映在数据上就是智能手机销售增量放缓，部分区域甚至出现了明显的同比下滑。

对于消费者来说，这并不见得是件坏事，因为更加激烈的市场竞争意味着手机厂商必须要全力以赴，拿出自己「压箱底」的技术，这才有了今年上半年头部品牌「大招」频出的局面。

与此同时，实力明显更强的国产 TOP 4 也不约而同地将眼光放在了成长空间更大的海外市场，除了已经站稳脚跟的东南亚、印度市场，销量巨大、消费水平更高的欧美市场也正在成为更多手机品牌的下一站。

对于低调地在「时尚爆款」上耕耘了多年 OPPO 来说，过去的三天则是其自身实力的集中释放。

![](../Images/e42cf3889efca66a00e10a42aad6a7fe.png)

「未来旗舰」Find X 的推出证明了 OPPO 并没有因为过去四年旗舰手机的缺席而放松对未来技术边界的探索，水到渠成的欧洲战略则体现了 OPPO 多年来在品牌、渠道、专利上的长期积累。  

不景气的大环境让行业里不少小品牌的生存难度变得越来越大，不过当 OPPO 等厂商纷纷祭出自己王牌的时候，手机行业也正在变得前所未有的有趣。 ■
