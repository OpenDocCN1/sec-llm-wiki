移动、高通、顺丰洽谈投资小米 IPO，移动拟投 1 亿美元

据知情人士透露，在洽谈以基石投资者身份参与小米香港 IPO 的公司中，有中国移动和高通。知情人士称，中国移动可能投资约 1 亿美元；知情人士还称，中国快递公司顺丰控股的一家附属公司也在磋商成为基石投资者一事。小米拟于周三敲定基石投资者名单。

中国移动回应称消息属实，已签署协议。澎湃新闻从顺丰方面获悉，顺丰确认投资小米，不过顺丰方面表示暂时不便公开具体的投资金额。

彭博社此前报道，小米为规模至多 61 亿美元香港 IPO 设定条款，IPO 定价区间在 17 至 22 港元。小米投资人据悉计划在 IPO 中发行 21.8 亿股股票。（来源：新浪科技、澎湃新闻）


微信官方回应改版争议：会提高阅读效率，所有困惑都有解决方案

微信 iOS 版昨日发布 6.7.0 版本，更新完成后，订阅号将不再以列表形式展示，而是以 feed 流形式展示。在 feed 流中，如果一个账号推送多篇文章，2 篇以外的文章将会被折叠，需要用户手动点击才能展示。改版后，订阅号的群发消息将以「标题 + 封面图」的形式直接展示在消息列表里，用户进入订阅号消息列表后可直接阅读。同时优化了对视频、图片、语音等消息的展示。

微信公关总监张军就争议作出回应：大家说的关于第三条以后的阅读率会下降，这个完全不存在，实际测试效率会提升；原来置顶的公号，会被削弱这个问题在后续版本会解决；菜单栏会和置顶功能一样，会在后续的迭代中呈现出来；品牌我认为不会削弱，相反，不好的公号会迅速被用户取关。（来源：快科技、营销新榜样）


百度诉前员工违反竞业协议，要求赔偿违约金 100 万元

昨日消息，据知情人士透露，百度前员工李成刚因涉嫌违反竞业协议，被百度诉上劳动仲裁部门，将面临共计 100 万余元的竞业限制补偿金退还及违约赔偿。竞业限制的目的在于保护企业的商业秘密，如果李成刚因违反竞业限制义务而侵犯了百度的商业秘密，则其新东家今日头条亦可能被牵涉其中。目前此案已经进入审理阶段。

百度方面称，李成刚在离职后不久，仍处于竞业限制期内的情况下，一边继续拿着百度给的竞业补偿金，一边入职今日头条，并涉嫌将前东家百度公司的商业机密透露给新东家今日头条。（来源：品途商业评论、新浪科技）

微软员工发公开信，抗议公司与移民监管机构合作

据外媒综合报道，微软 100 多名员工日前向首席执行官萨蒂亚·纳德拉发公开信，抗议微软与美国移民和海关执法局（ICE）合作。

这些员工要求微软立即停止与该机构的合作，该机构正在墨西哥边境将非法移民与他们的孩子隔离。这封信指出：「我们认为，微软必须站在道德立场上，把儿童和家庭置于比利润更高的位置。」

此前，微软与 ICE 签订了价值 1940 万美元的合同，帮助后者处理数据和提供人工智能方面的帮助。（来源：网易科技）


欧盟法律委员会支持更严版权法，谷歌 Facebook 将遭打击

欧洲议会下属的法律事务委员会今日投票赞成在欧盟境内实施更严格的版权法，这可能导致谷歌、Facebook 和微软等科技巨头的市场影响力受到进一步的限制。新版权法提案由欧盟委员会于两年前提出，主要是针对谷歌和 Facebook 等在线平台影响力日益提升而制定，旨在迫使这些互联网公司与出版商共享营收，同时还要承担网络著作权侵权责任。（来源：新浪科技）


GitHub Education 现面向所有学校开放

测试、注释和记录、适当的源代码管理等等都是合格程序员必备的基础技能，而这些技能通常不会在课堂上学到。但 GitHub 希望改变这种情况，此前 GitHub Education 仅面向少量具备学位或证书授予的教育机构，而现在该项目扩展提供给所有学校。

GitHub Education 是一系列工具和培训项目。能够免费使用 GitHub Enterprise 或者 Business Hosted，并能通过 GitHub Campus Advisors 为平台培训教师。自然 GitHub 并非唯一针对教育市场的源代码管理公司。本月早些时候，竞争对手 GitLab 宣布面向教育客户免费开放 Ultimate 和 Gold 套装。（来源：cnBeta）


谷歌、Uber 等组建联盟，研究无人驾驶汽车对人影响

据美国汽车协会 (AAA) 的调查显示，多达 73% 的美国人表示他们害怕乘坐无人驾驶汽车，而无人驾驶汽车预计将导致 100 多万司机失业，包括出租车司机、校车司机和 Uber 司机。

在这些令人担忧的趋势推动下，多家正在研究、设计和测试无人驾驶汽车的公司组成了「交通创新与机遇伙伴关系」(PTIO) 联盟，这是个新的以 501(c)(6) 非盈利政策组织，旨在赢得决策者和公众的青睐。创始成员包括福特、丰田、戴姆勒等老牌汽车制造商，Waymo、Uber、Lyft 样的科技巨头，以及 FedEx 和美国卡车运输协会等物流供应商。501(c)(6) 非盈利政策组织意味着，它可以像非营利组织那样接受捐赠，并像商会那样游说政府。（来源：网易科技）

全球 77 个机场支持微信扫码实时退税

腾讯退税通（We Tax Refund）是基于微信小程序推出的海外实时退税服务。用户可以通过微信扫码，轻松将退税款存入自己的微信钱包。截至目前，腾讯退税通已覆盖韩国、德国、意大利、希腊、芬兰等 26 个国家和地区，并且支持在全球 77 个机场实时退税。腾讯退税通作为平台方将不收取任何费用（退税公司手续费与平台无关）。

在机场办理退税时，用户只需填好退税单并在机场海关完成盖章后，前往机场的退税柜台扫「腾讯退税通」小程序，出示退税二维码，退税款便会以人民币形式存入微信钱包的零钱中。（来源：腾讯互联网金融）
