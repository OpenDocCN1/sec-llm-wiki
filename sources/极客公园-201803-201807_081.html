Find X 来了，除了史上最高屏占比，OPPO 还想用全隐藏式 3D 摄像头重新定义未来手机

史上最高屏占比，全隐藏式 3D 摄像头，前后玻璃盖板无开孔，Find X 将重新定义未来手机的产品形态。


对于 OPPO 来说，Find 是一个始终绕不开的名字。

Find 是 OPPO 的旗舰产品线，它有着同时期最旗舰的配置，更重要的是，Find 代表了 OPPO 在工业设计和技术创新上最新的探索。

从 2011 年莱昂纳多手上那台采用侧滑全键盘设计的第一代 Find，到 2012 年发布的 6.65 毫米全球最薄手机 Finder，再到终成销量「爆款」的 Find 5 和 2014 年首发 VOOC 闪充的 Find 7，OPPO 推出的每一款打上了 Find 标签的产品可以找到国产手机中不多见的「探索精神」。

这种精神也延续到了今天刚刚发布的 Find X 上。


史上屏占比最高的智能手机

收窄屏幕四周的边框、提高屏占比是过去一段时间手机行业的大趋势。从 18：9 屏幕，到今年最流行的「刘海屏」，「真全面屏」这个看似很遥远的目标，正在一步步变成现实。

在 Find X 上，OPPO 又向前迈进了一大步。

Find X 采用了双曲面设计，在这个基础上，Find X 又大大收窄了屏幕上下的「额头」和「下巴」宽度，做出了四面超窄边框的视觉效果，OPPO 把 Find X 的这块屏幕叫做「曲面全景屏」。

根据 OPPO 官方的数据，Find X 的上边框宽度为 1.91 毫米，左右边框宽度为 1.65 毫米，下边框则为 3.4 毫米。按照业界常用的「显示区域投影面积/盖板玻璃投影面积」来算，Find X 的屏占比达到了夸张的 93.8%，这也是手机史上最高的屏占比。

为了做出这样的屏占比，Find X 的屏幕面板采用了 COP 封装工艺，原理是利用柔性 OLED 屏幕的特性，将屏幕下方无法去除的排线连同显示区域直接翻折进来，从而避免屏幕排线对「下巴」空间的挤占。

值得一提的是，Find X 是安卓阵营中第一款采用这种昂贵的屏幕封装工艺的手机。

回到屏幕本身，Find X 采用了一块对角线 6.42 英寸的三星 OLED 柔性屏，分辨率 2340X1080（长宽比 19.5：9），ppi 为 401。

至于为什么分辨率没有上 1440p，我们从 OPPO 的工程师口中得知，主要是基于续航的考虑。OPPO 希望 Find X 在采用 6.42 英寸大屏的情况下，同时拥有旗舰机中优秀的续航，于是在屏幕清晰度「达标」的情况下，定制了一块这样分辨率的屏幕。

需要提醒大家的是，虽然 6.42 英寸看上去比较大，但由于 Find X 的屏幕比例更长，并且四个边框都很窄，所以 Find X 的整机尺寸还是比较适中的，配上前后 4 曲面带来的良好手感，Find X 单手掌握起来问题不大。


「曲面全景屏」背后的一堆小创新和一个大创新

对于手机厂商来说，做出超高屏占比只是第一步，更大的挑战是，在选择了这个突破性的屏幕方案之后，前置摄像头、听筒、距离传感器、光线感应器、生物识别模块等不可或缺的元器件应该如何处理。

为了解决这些问题，Find X 做了很多小创新以及一个堪称行业突破的大创新。

我们先从小的地方说起。

通常来说，手机的光线传感器位于屏幕上方的边框上，不过由于 Find X 的上边框太窄，没有足够的空间来摆放光线传感器，这条路走不通。Find X 的做法是将光线传感器放在了手机顶部的「月牙弯」凹槽内，传感器略微突出表面一点点，保证能够收集到充足的光线。

至于传统的距离感应器的功能，Find X 根据场景将它拆成了两个部分。

通话时，距离感应器的功能是在检测到人脸靠近屏幕后关闭屏幕，从而防止通话时误触屏幕，Find X 的做法是利用屏幕触摸，根据在通话时人脸接触屏幕的面积来智能地开关屏幕。此外，Find X 还额外加了一个红外传感器，功能是检测手机状态，让手机在放在包里、口袋里的时候不会出现误唤醒。

听筒方面，Find X 采用了体验更有保证的传统振膜式听筒，手机的上边框上可以看到一些不明显的开孔。

看完了这些小创新，我们来重点看看 Find X 最重要的一个创新：全隐藏式 3D 摄像头。


兼顾设计和功能的全隐藏式 3D 摄像头

在解决掉听筒、距离传感器、光线传感器之后，剩下的问题就是如何处理摄像头了。

虽然目前已经有了一些将摄像头隐藏在屏幕显示面板下方的研究，但在现有的技术条件下，为了保证正常的拍照体验，手机就必须要为前后摄像头保留开孔。

这种情况下，Find X 选择了采用整个顶部区域都可以升降的模块来「收纳」摄像头等元器件。这块区域除了包含了前置摄像头，还集成了一套完整的包含了红外镜头、泛光感应元件以及点阵投影器等元器件的 3D 结构光模组，OPPO 把它叫做 O-Face，这也让 Find X 称为安卓阵营中最早用上 3D 结构光模组的手机之一。

这还不算完，除了前置摄像头和 3D 结构光，这个升降式模块的背后还集成了后置双摄像头模组。

双摄模组只有升起时才可以看到，下降后，后置双摄会像前面的 3D 结构光模组那样隐藏到手机当中，只留下一条神似 Find 7 天际线呼吸灯的弧线和 4 曲面 3D 玻璃后盖连接。

通过这个独特的升降式模块，OPPO 不仅去掉了刘海，保留了前置摄像头、3D 结构光和后置双摄，保持了功能上的完整性，还成功地把这三个部件全部隐藏在了手机当中，让 Find X 的前后玻璃盖板上没有任何一个开孔，从而实现了设计和功能上的完美兼顾。


全隐藏式 3D 摄像头的体验如何？

在兼顾了极简的设计和完善的功能后，Find X 的这个可升降全隐藏式 3D 摄像头的体验如何呢？相信这也是很多消费者心中对 Find X 最大的疑问之一。

在经过了简短的体验后，我们的感受是：比想象中好不少。

首先，为了驱动让这个包含了众多元器件、体积可观的区域实现高灵敏度的自动升降，OPPO 为 Find X 定制了一套由马达和螺纹丝杆组成的「双轨潜望结构」。我们从 OPPO 的工程师口中得知，这套模块只需要 0.6 秒就可以完成上升或下降，为 Find X 快速启动 3D 结构光模组提供了必要的硬件支撑。

在 3D 结构光的人脸识别的速度上，Find X 的 O-Face 的表现也不错，直观的感受和 Face ID 差别不大，即便是算上结构光模块自动升起的时间，从按下电源键开始到进入完成解锁后进入桌面，Find X 也只需要 1 秒不到的时间。

横向对比的话，这个速度和目前的屏幕指纹方案比较接近，相比传统的电容式指纹、Face ID 以及普通的 2D 人脸解锁稍微慢一点，但差别并不算大。

至于大家关心的机械升降模块寿命问题，OPPO 表示，Find X 可以持续使用 30 万次，即便是按照一天 100 次这样比较重度的使用来算，Find X 也可以正常使用 3000 天，也就是 8 年出头，正常用基本不用担心寿命问题。

除了 3D 人脸解锁，OPPO 还为 O-Face 赋予了更多颇具实用性的功能。

首先是支付，OPPO 已经和支付宝一起完成了在人脸支付上的适配，国行上市时就可以使用支付宝进行人脸支付。此外，OPPO 也正在和微信进行调试，很快也会支持微信的人脸识别支付。

O-Face 3D 结构光的数据还可以和前置的 2500 万摄像头进行结合，从而获得更加立体、精度更高的 3D 人脸数据，从而叠加更加精细的 3D 立体美颜和 3D 光效处理。

此外，Find X 还利用传感器来实时检测用户面部数据，并替换成动画表情的功能，OPPO 把它叫做 Omoji。

OPPO 还正在探索 3D 结构光和 AR 游戏、5G 等功能的结合，未来 O-Face 会衍生出更多有价值的功能出来。


意料之中的旗舰配置

Find X 的硬件配置没有太多值得意外的地方。

和之前的 Find 产品一样，Find X 也用上了同时期最强的硬件，包括高通骁龙 845 SoC、8GB 运行内存、电池容量为 3730 毫安时，支持 VOOC 闪充，以及 USB Type-C 接口。

后置相机方面，Find X 采用 1600 万+2000 万后置双摄组合、并带来 RAW HDR 功能，足以保证优秀的相机表现，AI 场景识别的加持也有助于用户随手拍出更好看的照片。

Find X 将提供波尔多红和冰珀蓝两个配色，两个颜色均采用了「3D 叠层流光点彩」工艺，后盖的左、右、下三个边有明显的渐变处理。

需要说明的是，大家不要被 Find X 官方的 9.4 毫米厚度所「迷惑」。由于 Find 的前后采用的都是 4 曲面 3D 玻璃，手掌直接接触的中框部分其实很窄，拿在手上感觉其实是很薄的。

系统方面，Find X 将搭载基于 Android 8.1 的 ColorOS 5.1，重点强调的是 AI 功能的加持。

根据 OPPO 的说法，通过基于 AI 算法学习学习用户使用习惯，ColorOS 5.1 可以将 APP 启动速度平均提升 44%。此外，OPPO Find X 还将内置语音助手，并通过使用低功耗的智能 MIC 和 NXP 降噪方案，在安静环境下的唤醒率可以达到了 95%。


Find X 兰博基尼版，SuperVOOC 闪充，35 分钟充满

发布会上，OPPO 还发布了 Find X 的兰博基尼版，机身设计增加了碳纤维纹理机身，内置存储提升到了 512GB，不过 Find X 兰博基尼版还有一个大招：充电。

Find X 兰博基尼版采用了 SuperVOOC 闪充功能，同时，标配的充电头功率达到了惊人的 50W（10V 5A），根据 OPPO 提供的数据，只需要 35 分钟就可以将 Find X 兰博基尼版内置的 3400 毫安时电池（标准版 Find X 电池容为 3730 毫安时）完全充满。

这个速度…… 除了「吓人」，我们实在找不到其它的形容词了。


Find 归来，它仍是 4 年前的模样

OPPO 将 Find X 定义为「未来旗舰」，从这次的产品上看，「未来旗舰」可能也是对 Find X 最好的诠释了。

Find X 拿出了领先行业至少一个身为的屏占比，配备了安卓阵营最早量产的 3D 结构光，并通过突破性的隐藏式 3D 摄像头设计，完成了智能手机时代第一个正反无开孔的一体式设计，广被用户所期待的 SuperVOOC ，也终于在这代产品上正式开始了商用。

在这款时隔 4 年的 Find 新品上，OPPO 展现了自己在工业设计和技术创新探索的最高水准，并没有因为公司体量的增加变得有任何的保守，一如之前的 Find 那样。

发布会上，OPPO 公布了 Find X 在欧洲地区的售价，Find X 的「8GB + 256GB」普通版售价为 999 欧元（约合人民币 7500 元），兰博基尼版的售价为 1699 欧元（约合 12758 元）。需要说明的是，以上只是欧洲地区的售价，不代表国行。

不出意外的话，OPPO 将在本月 29 日的国内发布会上公布 Find X 的国内售价，我们也期待着在那场发布会上，OPPO 可以继续带来更多的惊喜。 ■
