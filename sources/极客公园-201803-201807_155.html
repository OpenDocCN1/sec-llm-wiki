在可穿戴领域，小米手环绝对称得上是一条教科书级别的产品线。一代产品在功能上高度克制，制换取了「夸张」的续航时间；二代产品加入屏幕和触控按钮，软硬件交互体验升级的同时，依旧保证了持久的续航。

市场的销售数据也反映了小米手环的成功，去年 4 月小米手环的总出货量就已经突破了 3000 万只，最近每个季度还保持着 300 万只以上的出货量，这也让小米（以及手环背后的制造商华米科技）顺利进入了全球可穿戴厂商的第一梯队。

距离小米手环 2 发售已经过去了近两年时间，国内的可穿戴行业基本上完成了洗牌。不论是业界还是粉丝群体，都期待着小米手环的新品能早日亮相。直到今天（5 月 31 日）小米 8 的发布会上，小米手环 3 才终于和大家见面了。

开门见山，这一次小米手环 3 共有两个版本：标准版和 NFC 版本，其中标准版售价为 169 元，目前已经发售。NFC 版本为 199 元，将在后续发售。这次极客之选拿到的是标准版，以下统一用小米手环 3 指代。


屏幕素质提高，支持触摸操作

一代小米手环只有一个简单的点阵显示，小米手环 2 首次加入了 OLED 显示屏，小米手环 3 在此基础上再次进行了升级。

首先小米手环 3 给人的第一感觉就是「珠圆玉润」，原因在于其显示屏采用了一体式纯黑面板，四周进行了圆滑过渡，面板上覆盖有防指纹镀膜。这样的设计无疑提升了小米手环 3 的精致程度，屏幕不点亮的时候有一种「浑然一体」的感觉。

显示屏的升级不仅仅体现在「颜值」方面。小米手环 3 的 OLED 显示屏尺寸增大至 0.78 英寸，分辨率 128 X 80（PPI 为 193）。尺寸和精细度的提升带来了更好的显示效果——小米手环 3 一屏最多可以显示 24 个汉字，可以更加直观、高效地获取通知信息。

更关键的是，这次屏幕终于支持触摸操控了，操作起来比之前要直接许多。上下滑动可以在时间、步数、心率、天气预报（这次新加入的功能）、更多和关于界面切换，左右切换则可以查看界面的详情。在「更多」界面下可以看到小米手环 3 增加了计时器的功能，而且手环也支持更换表盘了（鼓掌）。

除此之外，小米手环 3 还增加了名为「运动副屏」的功能，其实这也是很多运动腕表必备的功能。在户外跑、室内跑、户外骑行和健走四种运动模式下（打开小米运动 app），手环屏幕会显示出运动中的关键数据，抬手即可查看。

在体验小米手环 3 时，我们还发现了一个新加入的功能「事件提醒」非常有意思。通常情况下手环收到的都是手机推送的提醒，而「事件提醒」也需要主动进行设置，它储存在手环本体中，可以脱离手机使用。这样只要你戴着手环，就不会错过重要的提醒，还节省了一个提醒类 app 的空间。


防水能力提升，续航依旧给力

长续航一直是小米手环产品的优势之一，这一次小米手环 3 在屏幕素质提高的情况下依然保留了这个「优良传统」。根据官方介绍，小米手环的日常使用续航时间能够达到 20 天。由于我们拿到手环的时间比较短，无法验证完整的续航时间，不过从目前的掉电速度来看，续航绝对是令人「放心」的。

在防水能力上，小米手环 3 也获得了提升。上代产品为 IP67 防水，这一次升级为运动腕表上常见的 5ATM 防水（50 米水压），可以在淋浴、泳池游泳及浅滩游泳时佩戴。作为一款适合长时间佩戴的产品，防水能力的提升显然进一步强化了这个能力。需要注意的是，5ATM 不适用于桑拿和潜水场景。

小米手环 3 支持自动心率监测（可选 1 分钟、10 分钟和 30 分钟监测频率）和辅助睡眠监测，根据官方介绍小米手环 3 还优化了心率检测和抬腕检测的精准度。在 app 内，可以非常直观地看到全天心率的变化曲线。基础的运动检测、睡眠监测这些功能和上代产品保持一致，这里就不赘言了。

小米手环 3 的重量为 8.5g，比上代产品略重一些，不过佩戴起来依然非常轻便。另外能够明显感觉到，小米手环 3 的「米粒」的牢靠程度要好了很多（官方表示采用双色咬合成型工艺），相信剧烈运动中也不会脱落。

最后说说 NFC 的版本。在小米手环 3 发布前，极客之选曾在微博上进行了一个小调查：「大家对小米手环 3 有什么期待？」其中呼声最高的便是希望它能增加移动支付的功能，例如用 NFC 模拟公交卡。小米手环官微也做过类似的调查，很多人也提到了 NFC 功能。

作为和身体距离最近的电子设备，智能手环在 NFC 应用上确实有着独到的优势，现在也有不少可穿戴产品加上了这项功能。小米显然也捕捉到了这个趋势，即将到来的小米手环 3 NFC 版就是这样一款能够满足大家需求的产品，不过雷军表示可能要到今年 8、9 月才能发售，还需要大家耐心等待。

其实对于标准版来说，虽然功能上相比上代产品没有大的革新，但不论是屏幕素质的提高，防水能力的提升，还是诸如「事件提醒」这类功能的加入，在产品体验上带来的都是实打实的提升。

实际上「无感佩戴」和长续航是小米手环从诞生以来就确立的产品属性，而过去的几年的市场表现已经验证了它的成功。小米手环 3 功能取舍的背后，内核仍是想要更长时间停留在用户的手腕上，产品形态上呈现的是「平易近人」的可穿戴设备。从这个角度上来说，小米手环 3 可以视为是前两代产品的「究极形态版」。

总结来说，169 元的小米手环 3 标准版依然是那些没有接触过可穿戴设备人的入门最佳选择；对于那些小米手环的老用户来说，标准版的升级也绝对值得「换机」，如果真想要体验一些移动支付方面的功能，可以再等等 NFC 版本的发售。
