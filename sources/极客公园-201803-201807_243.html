微软不再迎合消费者了吗？

没有人关心微软开发者大会。

月初 Facebook F8 的余热尚在，有关信息泄露的讨论仍然不绝于耳；即将开始的 Google I/O 热度更是水涨船高，各色预测文章早已占据了媒体的显眼版面。微软夹在它们中间，低调得不像是一个市值同级别的巨头。

论市值，微软的表现要比 Google 和 Facebook 好得多。受困于信息泄露丑闻，Facebook 的市值已经掉队，而微软和亚马逊则追上并超越了原本仅次于苹果的 Google。没错，还有亚马逊，华尔街上，人人都在讨论亚马逊，他们说亚马逊会先于苹果触达一万亿美元的市值巅峰，业务涉及生活方方面面的贝佐斯让美国人尤其感到放心不下。

在人们眼里，当下最热门的科技公司是「GAFA」：Google、Apple、Facebook 和 Amazon，作为五大科技巨头之一的微软似乎已经渐渐淡出了人们的视野。


「开发者」大会

美国当地时间 5 月 7 日，微软开发者大会（Microsoft Build）在西雅图举办，这或许是一场真正意义上的开发者大会——在第一天的展示演讲中，几乎很少出现与消费者有关的产品发布。

在大会最重要的 Keynote 环节，第三任 CEO 萨提亚·纳德拉与多位演讲者一起发布了微软在人工智能、云计算和虚拟现实等领域取得的最新进展。

从头到尾，不说硬件，甚至 Windows 都很少出现。在接近结束的环节里，微软发布了一款 Windows 10 应用「Your Phone（你的手机）」，用户可以通过这款应用在搭载 Windows 10 的电脑里完成查看手机文件、收发短信等任务。此外，微软表示刚刚加入 Windows 10 的 Timeline（时间线）功能将通过 Edge 浏览器的 app 登陆 iOS 平台，安卓平台上的 Microsoft Launcher 也将加入同样的功能。

这些就是第一天的 Keynote 里，有关 Windows 的全部内容，在第一天上午的议程结束后，也只有这些简单的新产品发布受到了最为广泛的关注。

在 Keynote 环节将要结束的时候，一位科技记者忍不住在推特上发问：「Windows 商店没做起来，Groove Music 彻底死了，Windows 笔记本还不如键盘有问题的 MacBook，微软现在和消费者还有什么关系呢？」

消费者渴望惊喜

Facebook、微软、Google 和苹果这些科技大公司们每年春天都会召开一次长达两到三天的开发者大会，他们从全世界召集与之合作密切的开发者伙伴们，一起探讨今后的平台和产品的方向以及细节。

单纯的技术讨论以外，产品发布也是这类大会的重要一环——事实上，大会首日的演讲发布环节才是媒体和普通用户关注的重点。Google I/O 每年都会发布旗下各种应用和安卓系统的更新，有时甚至会带来一些硬件的惊喜。苹果的 WWDC 也是一样。

在刚刚结束的 Facebook F8 上，有不少人感到失望。他们认为 Facebook「没有以前那么酷了」，整场发布会最拿得出手的新品发布居然是很难说是 Facebook 原创的「约会」功能。

相比之下，从用户角度来看，这次微软的 Build 大会则更令人失望。除了上面提到的 Windows 应用的部分更新，只有语音助手 Cortana 与亚马逊 Alexa 的合作与普通消费者有一点关联。至于常被用以炫技的混合现实（MR）技术，在今年仅仅更新了两款企业级应用，消费者端的体验则完全没有提及。

针对消费者群体的产品发布和功能更新的缺失是这次微软 Build 大会与往年差别最大的地方。


Windows 去哪了？

在去年的 Build 大会上，有关 Windows 的发布内容几乎占据了微软全公司新品发布的一半，不仅仅是平台上软件的更新，Windows 全新的设计风格 Fluent Design 也是那场发布会的主角之一。微软在当天表示，Windows 将在秋季迎来「创意者更新」，自此，Windows 不再是一个独立的系统，而是一个服务，它将以升级补丁的方式不断更新下去。

每年两次重大更新的承诺让许多 Windows 的粉丝兴奋不已，但这样的改变也意味着 Windows 在微软公司内部的地位发生了变化。今年三月底，微软宣布部门重组，Windows 部门被一分为二，分别纳入「体验与设备」和「云计算与人工智能平台」两大部门，这次重组被视为微软内部里程碑式的调整，外界普遍认为这是纳德拉领导下，微软抛开 Windows，重塑帝国的重要一步，但纳德拉本人的看法却有所不同。

「说到底，微软就是一家 Windows 公司。」在接受 The Verge 的采访时，纳德拉说道，口吻像极了在他之前的两任 CEO。在纳德拉的计划里，Windows 是微软的基础，它应该像一种底层服务一样深深扎根在微软的各条业务线上。「Windows 究竟是什么：它总是要管理着一堆硬件资源，不论在服务器上还是在客户端里。我们想让用户明白，对微软来说，最重要的就是我们在所有的设备上都能够很好地服务我们的用户。」纳德拉说。跨设备的体验是微软在意识到 Windows 不再能够成为用户唯一的选择后，转而追求的新目标。


是老了，还是成熟了？

通过对云计算领域的不断投入，微软打造出了不逊于亚马逊的云服务产品，得以在云计算服务的市场上分一杯羹；而将公司各种软件打造成订阅式的 Microsoft 365 服务，让微软有了留住客户的能力。对现在的微软而言，推动它市值增长的，早已不是 Windows 和 Office 套件的销量，而是云服务和订阅服务带来的收益。

与其他爱好炫技的科技公司不同，微软在今年不再展示迎合媒体和普通消费者的产品，即便是最为花俏的 MR 技术，微软也将其利用起来开发出可以投入实际操作使用的企业级应用。

现在的微软有了自己的选择，人工智能、云计算和混合现实，这些是纳德拉给微软未来的定义，比起指责微软「不再年轻」，不如说微软经历了几年前的低谷后，真正「成熟」了起来。
