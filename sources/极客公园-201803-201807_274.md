# 腾讯「新文创」，和这之中的「头号玩家」们

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652854433&idx=1&sn=3da2ff743d435d44ce78dd06a0a77488&chksm=7e6a2517491dac01894b8325526d76d12ef4ce28f47a4f02ca67d88b8aefcbd4e36189e9079a&scene=126&sessionid=1681310955#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652854433&idx=1&sn=3da2ff743d435d44ce78dd06a0a77488&chksm=7e6a2517491dac01894b8325526d76d12ef4ce28f47a4f02ca67d88b8aefcbd4e36189e9079a&scene=126&sessionid=1681310955#rd)

![](../Images/92726223121ac1d0b535fc0b352deca8.png)

> **如果说中国也会出现好莱坞一样的「黄金时代」，那么在那个时代里，这些朝气不减的「大孩子」们一定不会缺席。**

  

灯光聚拢处，站着方文山、《纸牌屋》原著作者、还有 LOL 设计师……在这个舞台之上，腾讯将之命名为「新文创」；在这个舞台之下，是腾讯忠实的「头号玩家」们。

《纸牌屋》小说原作者 Michael Dobbs、《阿凡达》的特效动画师 Andrew Jones、台湾作词人方文山，还有近来大热的网游《绝地求生》的创始人 Brendan Greene 等十一位文创领域的大师齐聚一堂，这不仅是互联网行业难得一见的盛会，就演讲嘉宾而言，国内除了腾讯以外几乎没有人能够同时在一场活动中召集如此众多且大牌的创作者。

台下的我，时而瞠目结舌，时而满面傻笑，近乎「朝圣」地体验了大会全程。

  

## 热爱同梦想

对我而言，这次参会经历有着一些私人的因素。我得以采访到「黑暗骑士三部曲」的编剧 David Goyer 以及被称为「蝙蝠侠之父」的电影制作人 Michael Uslan，对一个超级英雄的漫画迷而言，这同时也像是一次粉丝的见面会。

![](../Images/bd8dfab37a189645ff2473ffccfad20c.png)

主会场里，David Goyer 在演讲中聊起了在创作过程中将角色带入生活的主题。漫画人物，尤其是超级英雄，距离普通人的生活往往非常遥远，这种情况下想让观众与电影产生情感共鸣就非常困难，但 David Goyer 和诺兰导演一起，将「黑暗骑士三部曲」打造成了蝙蝠侠探索自我的三个过程，在这三部影片中，观众能够找到许多蝙蝠侠更靠近普通人的一面，他有自己害怕的东西，有局限，有报复心。「不管是超级英雄还是反派人物，必须要与人共鸣，哪怕人类的瑕疵体现在角色上。因为瑕疵，我们才成为人类。」Goyer 说道，他笔下蝙蝠侠和超人的起源故事都有着一个影响深刻的父亲角色：「黑暗骑士三部曲」中忍者大师之于蝙蝠侠，《超人：钢铁之躯》中超人养父之于超人。这些角色的创作与他本人的亲身经历有着密不可分的关系，对于家庭关系有着非常深刻的体验与理解，帮助他创作出了这些让超级英雄拥有人性一面的故事。

![](../Images/0cb753e67f8c033f144178d4dfd3d6a5.png)

随后登场的 Michael Uslan 以电影制作人的身份讨论了全球化下数字内容生产的话题。他是美国第一位在大学开设漫画课程的讲师，年近七旬，Uslan 的头发已经花白，却系着一条印满超级英雄形象的花领带。「在所有的国家，不同的文化，或者童话故事和历史里，都有很好的素材。美国有 240 年的历史，我们能把这个历史展现给全球，而中国有五千年的灿烂文化，我们也可以从中汲取素材，展现给世界。」Uslan 说道，「世界需要中国的超级英雄角色，以及它们的完美故事，而这绝不仅仅是《西游记》。」  

在随后的采访中，我问起从事漫画研究教学的他如何看待中国漫画的研究。Uslan 颇为神秘地透露道，他正与一些中国企业合作，但目前还不能公开，在中国进行这一领域的研究令他感到非常兴奋，「你应该在生活中追求自己的梦想，让你的热爱成为工作的一部分。漫画和电影是我热爱的东西，能从事这一领域的工作是我的荣幸。」

Uslan 的话在当天颇为应景，来到现场的观众大多从事着「新文创」相关的行业。

  

## 内容与连接

七年前，在中国动画电影高峰论坛上，，时任腾讯集团副总裁的程武炒热了两个概念：「IP」和「泛娱乐」。「IP」是「知识产权」的英文缩写，大多指文化作品的核心创意，比如角色、故事等；「泛娱乐」则是围绕 IP 产业的一种商业模式。

![](../Images/f26f795f321a188b15d18ba1f7a671c8.png)

在不久后的 2012 年腾讯互娱的 UP 大会上，程武宣布腾讯正式发布泛娱乐的战略，提出以 IP 授权为轴心、以游戏运营和网络平台为基础的跨领域、多平台的商业拓展模式。

在吴晓波撰写的《腾讯传》中，程武谈起了发起泛娱乐战略的原因：「在当前网络化、数字化、多媒体化等趋势的带动下，游戏、电影、动漫已经不再孤立，而是形成了一个紧密联系的有机整体，一个跨越这三大行业的跨界产业链已经形成，并不断整合和向前发展。」

这之后，每一年的 UP 大会，腾讯都会对其泛娱乐的战略进行更深更广的布局，并且分享在这个领域更加深入的思考。直到 2014 年，「泛娱乐」一词被文化部、新闻出版广电总局等国家机构的行业报告收录并重点提及，这个由腾讯最先提出的名词才开始走进主流的视野。

![](../Images/6e5ff256a49f81ae2fd68be8b00f2c55.png)

在这次的 UP 大会上，兼任腾讯影业首席执行官的程武提出腾讯将从「泛娱乐」的战略升级为「新文创」。他提出有两个核心的升级点：第一，「新文创」将更系统地关注 IP 的文化价值构建，第二，「新文创」对 IP 塑造的方式方法有所升级。「因为只有把各种协作主体、文化资源以及创意形式广泛的连接起来，才能实现更高效的数字文化生产。」

在腾讯的推动下，IP 的概念从流行到普及，如今已深入人心，整个行业对 IP 的重视程度比起七年前早已不可同日而语。六年的泛娱乐实践后，腾讯认为，泛娱乐的各个领域不仅不再孤立发展，而且已经拥有了更大的发展空间。

腾讯的业务覆盖了游戏、文学、动漫、电影和电竞五大领域，如马化腾说的，「腾讯只做两件事，连接与内容，就这么简单。」

新文创是内容，更是连接。

  

## 作品和底气

UP 大会的第二天，腾讯分别在「新文创」各个领域发布了密集的新品。

首先程武领导的腾讯影业成立了全资的影视发行子公司「腾影发行」，并推出了覆盖主旋律、中国风、二次元改编、国产科幻以及国际合作五个分类的影视作品，经典如《王者荣耀》、《剑网 3》和《圣斗士星矢》等作品都将首次改编为真人剧集。

随后，腾讯动漫表示将把金庸作品漫画化，今年就会上线「射雕三部曲」等经典的金庸作品。同时电竞题材、网游 IP 的漫画作品，如《王者荣耀》等都将很快上线。

![](../Images/c838d8411fc27640823aa3d89b3bb86b.png)

已于去年上市的「网文第一股」阅文集团联席 CEO 吴文辉登台表示，2018 年将是阅文 IP 爆发的一年，在过去的 2017 年里阅文共有 100 余部作品进行了 IP 授权改编，其中《斗破苍穹》和《全职高手》的动画作品分别在 3D 和 2D 动画领域获得了全网播放量第一。2018 年阅文将进行 IP 国际化，将已有的重要 IP 推向国际。  

从「泛娱乐」过渡到「新文创」，腾讯首次将电竞作为独立单元在 UP 大会上亮相。腾讯认为，「体育化」是 2018 年电竞运动的关键词，随着「中国电竞进入黄金时代」的论调提出，腾讯电竞将对旗下「王者荣耀」和「英雄联盟」等赛事体系进行体育化的升级，力求更加专业的赛事和人才培养体系。

真正重磅的发布在游戏领域。腾讯是全球最大的游戏公司，旗下拥有数家享誉全球的游戏工作室，以行业领头人的身份，总体上，腾讯希望能把游戏行业推向一个新的高度。打造出能够给玩家更加综合的精神体验的游戏，让游戏与现实生活的方方面面产生连接与互动，让游戏成为文化交流的载体，实现文化的保育、传承和输出。

![](../Images/aa7d09bca78cef56827e152b1732cc8c.png)

大局上的深刻思考来源于腾讯旗下丰富的游戏作品，这一点在下午一连串紧凑密集的游戏发布中得到了印证。腾讯共计发布了 20 款全新的游戏，发布过程中，每款游戏的主创仅有三至五分钟的时间上台发布，超快的发布节奏，应接不暇的预告视频，让在场的观众大饱眼福又兴奋不已。发布最后，登顶多个国家手游下载榜的竞技游戏《堡垒之夜》国服代理的消息将会场的气氛带向了高潮。  

比起第一天干货满满的主题演讲，第二天会场的气氛更加热烈，尤其在腾讯游戏的发布环节，每逢重磅新品的出现，观众席上便爆发出一阵喝彩和掌声，现场的氛围与数天前我在北影节展映影厅的体验极为相似。用以观众身份参会的科幻作家韩松的话说，这次腾讯的 UP 大会「很浪漫很朝气很未来」。

  

## 「大孩子」们的黄金时代

今年三月初，佛罗里达州校园枪击案事发半个多月后，美国总统特朗普把一众游戏行业的高管和创作者召集起来，讨论游戏中血腥暴力的问题。会议开场时，他指着一段剪辑过后的游戏视频问到：「这就是暴力，不对吗？」（This is violent, isn't it?）

这场闭门会议被《华盛顿邮报》的记者曝光，特朗普随之成为了众矢之的，而批评者更多是与游戏行业关系不大的普通人，在美国公众看来，特朗普是在借电子游戏转移枪支暴力事件中政府的责任。

在娱乐行业更加成熟的美国，人们把漫画、游戏和影视作品视为稀松平常的消遣方式，它们早已成为了美国文化输出的核心，在文娱行业的黄金时期，圣贤古书不再是唯一的经典，通过游戏、漫画和电影，他们一样可以学到自己国家的文化精髓。

而这样的「黄金时代」，对目前国内的文娱行业来说还非常遥远，但对处在行业最前沿的腾讯而言，那是它最希望触及的未来，而反复强调的「新文创」，正是腾讯迈向那个未来的重要一步。

与传统的刻板印象不同，现场几乎没有多少稚嫩的面孔，但韩松所说的「朝气」却随处可见。很多年前，那些在家长的训斥揍骂中坚持钻进网吧和被窝里打游戏、看小说的孩子们已经长大，他们对游戏，对文艺作品中那些耳熟能详的故事和人物有着极高的认可，在 UP 大会观众席上神情严肃地听着干货十足的演讲的，为期待已久的新品欢呼鼓掌的，正是那些长大了的孩子。

每一代人都有他们独有的消遣文化的方式。如果说中国也会有出现像好莱坞一样文娱的黄金时代，那么在那样的时代里，一定会有这些朝气不减的「大孩子」们的身影。

腾讯在 UP2018 上呈现给我们的，就是这未来的惊鸿一暼。■
