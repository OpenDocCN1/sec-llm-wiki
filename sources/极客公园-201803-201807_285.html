特斯拉 Model 3 首次亮相亚洲，你们才是马斯克的「中国信心」

「新造车势力」粉墨登场，传统汽车制造商也开始展示「新成果」，这届北京车展「杀气腾腾」。


超过 50 万人的集体等待，「2017 年末开始在北美地区交付，随后是欧洲和亚太地区」，特斯拉 Model 3 去年七月份所承诺的量产计划虽然准时开始，但交付过程可谓一路荆棘，直到最近仿佛才刚刚找回节奏。

这 50 多万人中，更是饱含了中国预订者的期待。但他们能做的更多的只是时刻关注外媒网站，关注生产进度，也有人直接通过各种渠道去国外体验。今年，Model 3 第一季度交付 8180 辆，这也足矣让它成为了第一季度美国最畅销电动汽车。

更重要的是，即便是越来越多的电动汽车出现，这一群人的心依旧难以动摇。之前有外媒爆出说，即便现金储备陷入危机，但马斯克的信心来自中国，除了量产，这一群人的「信任」功不可没。

于是，特斯拉 Model 3 终于第一次以来到了亚洲，第一次来到了中国。除了北京车展，Model 3 将在接下来几个月将展开「中国巡游」，广州、深圳、杭州、天津、青岛、西安等等城市都将见到它的身影。

这次亮相北京车展对 Tesla 「意义重大」。「新造车势力」拿出了产品粉墨登场，传统汽车制造商也开始展示自己即将量产的「新成果」，使得这届车展杀气腾腾。所有的看客们有了挑选的余地。这也正是今年北京车展的最大看点之一。


依然特斯拉

Model 3，一个让特斯拉陷入舆论的旋涡，却又让人止不住期待的名字。

北京车展拉开帷幕，特斯拉携旗下 3 款车型——Model S、Model X以及Model 3亮相。这让许多喜欢这款车型的人，有了近距离接触它的机会。Model 3是特斯拉旗下尺寸稍小、更为简洁，但价格也更亲民的电动车。

提及 Model 3，我们总会不经意将其与 Model S 联系到一起。确实，二者在整体设计风格上有着太多相似的地方，但「前脸」除外。具体来讲，Model 3 的前脸采用了区别于特斯拉其它车型的一体化设计，看起来更具科技感。

同时，特斯拉在 Model 3 的前大灯上也做了改动。相比之前我们熟悉的特斯拉式前大灯，其全新的矩阵式 LED 大灯在直观视觉上会给人一种更加犀利的感觉，运动感十足。

和以往特斯拉的做法保持一致，它同样保留了可以放入一个标准登机箱的前备箱。这也很好的保证了车身尺寸相对较小的 Model 3，依旧能够提供比较不错的载物空间。独特的「前备箱」还可在发生碰撞时形成缓冲，吸收撞击能量，保护驾驶舱人员安全。

相信对于很多看到过特斯拉 Model X/S 的人来讲，一定会对其中控台中央那块「超大」触控屏印象深刻。

得益于对科技的独到理解，特斯拉在Model 3车型上呈现了清新的内饰设计——车内的物理按键以及功能全部整合到了15寸中央触控屏上。

Model 3的车身尺寸更为紧凑，但智能化的设计得以将Model 3内部空间最大化，使其能够舒适地容纳五名成年人及他们的全部物品。

与此同时，Model 3 也拥有同 Model S 和 Model X 一脉相承的特斯拉「基因」——安全与科技。平铺于底盘的动力电池组，使车辆拥有更高的抗扭刚度和更低的重心，有效提升车辆刚度并降低车辆侧翻的可能性。

自动辅助驾驶以及 OTA 空中升级则是特斯拉科技的最好体现。除了车身周围的传感器部署，特斯拉车型通过空中升级不仅可以增加新功能，更能提升车辆性能，让车主的车辆「常开常新」。

截至目前，特斯拉在中国大陆地区的充电网络已经覆盖 170 座城市，拥有超过 1100 个超级充电桩。2017 年，特斯拉还专为中国市场研发了「新国标」充电接口，让驾驶员在为车辆充电时拥有更多选择。

众所周知，特斯拉不生产「慢车」，与 Model X、Model S 相同，Model 3 也拥有优异的性能表现。Model 3 标准里程电池车型 0-96 公里/小时加速时间仅为 5.6 秒，长续航电池车型则仅为 5.1 秒。

同时 Model 3 完美的配重比，配合低重心的底盘布局，为车辆带来了与 Model S 相近的绝佳操控性。

「给汽车一个太阳」

特斯拉一直以「加速世界向可持续能源的转变」为更重要的使命，致力于推动全球范围内可持续能源的利用和循环。如今，依靠 Solar Roof 和 Powerwall 2 将转变能源生成和贮存的方式，特斯拉已经变成全球唯一一家综合型可持续能源公司，以「垂直整合能源解决方案」实现了可持续能源从生产、储存到应用这一整体过程的无缝衔接。

2017 年特斯拉已累计交付 30 万辆电动汽车。

但就在 4 月 22 日「世界地球日」，特斯拉还公布了一组数据向地球致敬——特斯拉能源产品累计生产电量超过 103 亿千瓦时；特斯拉旗下电动车累计行驶超过 115 亿公里、节约燃油超过 11 亿升；通过能源和电动车产品，特斯拉已为地球减排二氧化碳超过 737 万吨。

属于特斯拉 Model 3 的中国故事才刚刚开始。■
