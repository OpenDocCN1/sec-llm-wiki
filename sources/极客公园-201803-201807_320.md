# 华为 MateBook X Pro「全面屏」笔记本评测：它能否成为华为笔电的 Mate 7？

2016 年 2 月，华为发布了旗下的第一款笔记本电脑 MateBook。次年 5 月，华为发布了第二代的 MateBook 产品线，产品从单一的二合一形态扩展到了 X、E、D 三个系列，分别对应轻便本、二合一、大屏。  

在今年 2 月底的 MWC 大会上，华为发布了它们新一代的笔记本电脑产品，型号是 MateBook X Pro。除了搭载英特尔新一代硬件平台等「常规」升级，MateBook X Pro 最大的特点是号称采用了「全面屏」设计。

![](../Images/5129c84962ce3745626e9d950f899961.png)

这款全新的 MateBook X Pro 的表现如何？我们今天就来聊一聊。  

  

## 这个「全面屏」真的很「全面」

当我第一次在巴展上看到 MateBook X Pro 的真机时，当时就对这块 4 面超窄边框的屏幕留下了很深的印象。现在，在将 MateBook X Pro 作为主力笔记本电脑使用了一周多以后，我依然会忍不住感叹这块屏幕的「全面」程度。

![](../Images/3f9b09d27e3c9ea67be170135833dfd6.png)戴尔 XPS 13

其实在笔记本电脑中搭载超窄边框早就不是什么新鲜事。戴尔在 2015 年初就推出第一款拥有三面超窄边框设计的 XPS 13，虽说刚开始普及的速度有点慢，不过大概到去年年中，超窄边框设计已经大量出现在主流轻薄本乃至是游戏本当中。

不过无论是 XPS 13 还是其它采用超窄边框设计的笔记本电脑，目前都只能做到左、右两面或者是上、左、右三面超窄，「下巴」部分通常会比较宽。

![](../Images/08163ce79551f0f46c4ab5058985c2e9.png)

在 MateBook X Pro 上，华为在将上、左、右三边控制得极其窄的同时（实际宽度应该和戴尔新 XPS 13 相当），还大大收窄了「下巴」部分的宽度，这让 MateBook X Pro 的屏占比达到了夸张的 91%，而 91% 也是目前笔记本电脑中最高的屏占比。  

把笔记本电脑的屏占比做的这么高并不是一件简单的任务。由于屏幕尺寸大，笔记本电脑无法像很多全面屏手机那样用 COF 封装来缩小「下巴」，为了在 COG 封装的情况下将「下巴」收到最窄，华为将 MateBook X Pro 屏幕下方的一部分 PCB 板移到了键盘下面。

![](../Images/4b5728a75b6d38f71e3fdf5178e527ce.png)

华为把 MateBook X Pro 的屏幕叫做「全面屏」，这里头有一些营销的成分。不过如果真要为「全面屏笔记本」设定一个标准的话，MateBook X Pro 肯定是目前笔记本电脑的标杆。  

除了超窄的边框，MateBook X Pro 的这块屏幕本身也是下了「血本」的。

![](../Images/5a6ccb1d530fb718d077dc6df8d7662c.png)

MateBook X Pro 的屏幕面板来自 JDI，屏幕对角线尺寸为 13.9 英寸，长宽比 3:2（比常见的 16：9、16:10 更宽，和 Surface 系列相同），分辨率为 3000X2000（和 13 英寸 Surface Book 相同），ppi 达到了 260（13 英寸 Retina MacBook Pro 为 227），最高亮度 450 尼特，拥有 100% 的 sRGB 色域以及 1500:1 的对比度，**支持 10 点触摸**。  

此外，为了控制功耗，MateBook X Pro 的液晶基板还采用了成本更高的 LTPS（低温多晶硅），根据华为工程师的说法，由于采用了 LTPS，MateBook X Pro 这块高分屏的功耗和普通笔记本的 a-Si 1080p 屏幕相当。

从客观参数上看，这无疑是一块行业顶级水准的屏幕，实际体验也是如此。

无论是色彩、亮度、通透性，还是对屏幕反光的控制，MateBook X Pro 都足以媲美行业顶级的 Surface Book 和 MacBook Pro，特别是亮度，MateBook X Pro 可以达到 450 尼特左右，已经非常接近 MacBook Pro 的 500 尼特，比大多数的万元档轻薄本还要更亮一些。

优秀的屏幕素质，加上 91% 的超高屏占比和更加适合阅读的 3:2 显示比例，MateBook X Pro 可能是目前视觉效果最优秀的轻薄本（之一），而这也是 MateBook X Pro 身上最大的卖点。

  

## MacBook 级别的工艺，不过更圆润

第一眼看到 MateBook X Pro，你可能会自然的联想到 MacBook Pro，二者都采用了银色或深空灰配色的全金属机身，设计上走的都是极简风格。

这些「相似」并不见得是一件坏事，毕竟市面上长得像 MacBook 的轻薄本数不胜数，更重要的是，MateBook X Pro 在部分细节的处理甚至要比 MacBook 更加优秀。

金属机身早已成为了中高端轻薄本的标配，而 MateBook 用的是金属机身中比较「高级」的方案，它的整机均采用了 CNC 切割（和 MacBook 一样），和常见的冲压相比，CNC 可以把机身的细节打磨地更加精致。

这里有一个值得关注的小细节。

![](../Images/d202293aff96a918af3e0cbb55ab63e6.png)

笔记本电脑屏幕的边缘通常会有一圈橡胶或者塑料材质的突起，在电脑屏幕闭合时可以起到一定的缓冲作用，不过 MateBook X Pro 的屏幕边缘几乎是平的，这样手指在触摸到屏幕边缘时会更加舒适，当然这样处理的前提是外壳的精度要非常高。  

在机身强度上，MateBook X Pro 做得也很优秀。虽然屏幕 4 个边框都很窄，不过用力在 A 面上按压，屏幕上依然不会出现水波纹。

最后，MateBook X Pro 还有一个图片上很难展现的地方：手感。

![](../Images/c3cc2ff368de229832a958a73878f987.png)

MateBook X Pro 的金属表面采用了喷砂处理，不过和同样采用喷砂工艺的 MacBook 相比，MateBook X Pro 的表面「打磨」地要更细，摸上去会感觉更加顺滑。  

此外，在屏幕转轴附近金属边缘的处理上，MateBook X Pro 做得明显比我之前的主力笔记本电脑新款 15 英寸 MacBook Pro 来得更圆润，拿在手上不会有 MacBook Pro 边缘那种硌手的感觉。

![](../Images/365cc8a248e725aceb82bd9afb60f781.png)

接口方面，MateBook X Pro 最令人印象深刻的是右侧的全尺寸 USB 3.0 口（USB-A 母口），考虑到它的整机厚度只有 14.6 毫米，能把这个接口放进去还是挺难得。

![](../Images/b9b63541e939f00d7ff9132cf137a76f.png)

此外，MateBook X Pro 左侧还有一个 3.5 毫米耳机插孔以及两个 USB-C 口，两个 USB-C 口都可以用来充电，靠下的一个支持 Thunderbolt 3（PCIeX2）。  

MateBook X Pro 的机身重量为 1.33 公斤，和 1.37 公斤的 13 英寸新款 MacBook Pro 处于一个水准。鉴于 MateBook X Pro 的屏幕显示区域、电池容量都要更大并且多了一个 MX150 独显，MateBook X Pro 能把重量控制到这个水准依然是可圈可点的。

  

## 弹出式摄像头，独具匠心的指纹识别

要说 MateBook X Pro 最特别的地方，那肯定非这个弹出式摄像头莫属了。

由于屏幕边框太窄，MateBook X Pro 实在没法在 B 面上找个地方「塞」摄像头了，只能把它挪到了键盘所在的 C 面，然后为它在 F6 和 F7 之间新增加了一个按键，按一下弹出，再按一下藏起来。

![](../Images/11ce41a4d3ea805bbae7e3f0bc0a2172.png)

不过呢，大家应该也能猜到，这个独具匠心的弹出式摄像头恰恰也是 MateBook X Pro 最难用的地方。  

首先，靠下的位置意味着你的下巴和鼻孔在 MateBook X Pro 的前置摄像头中会大上很多，影响颜值。此外，如果喜欢一边打字一边用前置摄像头视频的话，你的手指还会以更粗大的方式出现在视频画面中。

如果前置摄像头的画质对你很重要，同时你又不愿意给电脑外接一个摄像头的话，MateBook X Pro 的弹出式摄像头显然不是一个靠谱的选择。

不过问题是，对于绝大多数用消费者来说，上面这个条件是不适用的。

随着智能手机的发展，笔记本电脑摄像头的必要性已经有了明显的下降。另外，为了保护隐私，越来越多的用户会选择手动把摄像头开孔盖住。在这种情况下，MateBook X Pro 这个独特的摄像头反而还成了一个加分项。

除了弹出式摄像头，MateBook X Pro 另外一个特别的地方是集成在电源键中的指纹识别。  

![](../Images/50ecf389b91bb4df59de6d40f51d69fc.png)

这个设计是华为在去年的 MateBook X 上第一个采用的，之后戴尔、LG 等传统 PC 厂商也开始进行了「借鉴」。除了常规的录入和解锁，MateBook X Pro 的电源键指纹还延续了 MateBook X 上的一个非常「匠心」的功能。  

当用户使用录入指纹的手指按下电源键时，MateBook X Pro 会直接记录指纹信息并存在安全芯片中，等到 Windows 弹出需要指纹验证的界面时，MateBook X Pro 会自动填充指纹然后进入系统。整个过程中，没有任何需要「手动」验证指纹的步骤，用户按一下电源键过上几秒就进入桌面了，非常方便，值得其他传统 PC 大厂「学习」下。

  

## 键盘、触摸板、外放

键盘手感好坏是一个非常主观的问题，就我自己来说，我会把 MateBook X Pro 的键盘归到「好用」但不「极致」这一类。

![](../Images/e114570419c1ae301277d2b8bad4618c.png)

相比去年的 MateBook X，MateBook X Pro 的键盘有了明显的改进，键程更长（1.2 毫米），回弹更舒适，键帽大小也很合适（如果键帽上能稍微加点弧度就更好了），敲击的感觉和惠普的 Spectre X360 有些类似。  

和 ThinkPad X1 Carbon、Surface Laptop 比，MateBook X Pro 的键盘在敲击的感受上还差那么一丢丢，依然还有进一步提升的空间。当然了，比起 MacBook 上「硬邦邦」的蝶式键盘，MateBook X Pro 的键盘手感要好上太多了。

触摸板是 MateBook X Pro 上的另外一个亮点。

![](../Images/3f86e4459f1fc1e322bcb449605709ad.png)

MateBook X Pro 的触摸板面积足够大，表面是类似 MacBook 的磨砂玻璃触感，使用了 Windows Precision 驱动，滑动流畅，定位准确不漂移，多指手势灵敏，在 Windows 阵营中属于绝对一流的水准，优于多数同价位传统 PC 品牌的机型。  

在相当长时间里，MacBook 的外放一直是同类产品的「标杆」，而 MateBook X Pro 是目前少有的几款外放可以达到这个「标杆」水准的产品。

![](../Images/75f3469f4188db2623568e714c3ee734.png)

MateBook X Pro 在机身中「塞」了 4 个扬声器，键盘两侧的开孔下各有一个，两个侧面的开孔（这个开孔同时也是电脑的进风口）中还各有一个。另外，MateBook X Pro 还和杜比在调音上进行了合作，支持杜比全景声（DOLBY ATMOS）。

![](../Images/c3cc2ff368de229832a958a73878f987.png)

在这样堪称豪华的软硬件配合下，MateBook X Pro 的外放有一种大多数笔记本电脑所没有的「空间感」，声场较大，人声部分的表现尤为突出，已经可以当一个几百块的蓝牙音箱来使了。在我们体验过的众多 13 英寸笔记本电脑中，MateBook X Pro 的外放表现属于数一数二的水准。  

  

## 八代酷睿 + MX150，独特的散热

MateBook X Pro 的配置没有太多意外的，CPU 当然是英特尔的第八代酷睿 U 系列，有 i5-8250U 和 i7-8550U 两个型号。

大家对这两颗 CPU 的表现可能也都比较熟了，二者均为 4 核 8 线程，TDP 均为 15W，i7-8550U 的缓存、主频和睿频比 i5-8250U 略高，性能上相比第七代同级别的 U 系列 CPU 优势明显，接近第七代 TDP 为 45W 的 HQ 系列 CPU。

![](../Images/cb9d5a4e135211ba836026b681b30a7a.png)

考虑到 MateBook X Pro 这类轻薄本的使用场景，无论是 i5-8250U 还是 i7-8550U，应该都完全足够用了，甚至即使你使用 Thunderbolt 3 外接高性能显卡，CPU 也基本不会成为影响整体性能的「瓶颈」。  

需要说明的是，MateBook X Pro 的 TDP 锁在了 15W，并没有像新 XPS 13、新 X1 Carbon 那样通过解锁 TDP 来拉升短时间的性能峰值。相比这点性能提升，MateBook X Pro 更倾向于降低风扇的参与，让电脑长时间保持在相对静音的状态。

MateBook X Pro 的显卡有两种规格可选，入门的版本是集显，其他的型号均搭载了 NVIDIA GeForce MX150（2GB GDDR5 显存，低功耗版本）。

不过即使是低功耗版，MX150 也要明显强于曾经的入门独显 940MX，比集成的 Intel UHD Graphics 620 更是强到不知道哪里去了很多，可以在中低画质搞定《英雄联盟》、《守望先锋》。至于「吃鸡」，MX150 就有些「Hold」不住了，建议考虑 1050Ti 以上的显卡或者使用外置显卡。

大家可能还记得，华为的上一代产品 MateBook X 虽然采用了 TDP 为 15W 的英特尔第七代 U 系列 CPU，不过无论是 i5 版还是 i7 版，都是没有配备散热风扇的，完全依靠被动散热，这个设计在当时应该是独一无二的（第五代 Surface Pro 的 i5 版无风扇，不过 i7 版有）。

在 MateBook X Pro 上，华为为它增加了一颗由华为 2012 实验室定制的主动散热风扇。不过在日常使用中，这颗主动风扇的参与程度并不高，低负载的时候只会以极低的转速运行甚至是不转的，这让 MateBook X Pro 在进行打字、浏览网页等低负载操作时可以做到非常地安静。

![](../Images/dbaf144cf82a274092b682384b871aaa.png)

在打游戏等高负载场景运行时，MateBook X Pro 的风扇噪音会有明显的增加，同时 C 面靠上接近出风口的位置会有些发热，但 CPU 和显卡依然能维持比较好的性能输出（「烤机」时 CPU 主频能保持在 2.1GHz 左右），综合散热表现在同价位中属于主流的水准，明显优于去年的 MateBook X。  

MateBook X Pro 的电池容量为 57.4 Wh，这个容量要略大于新款 13 英寸 MacBook Pro 的 54.5 Wh、新款戴尔 XPS 13（9370）的 52 WHr，和 2018 款 ThinkPad X1 Carbon 相当。

在我日常的打字、浏览网页、在线视频、修图等操作中，MateBook X Pro 差不多能坚持 8 小时左右，在高端轻薄本中属于中上的水准。

MateBook X Pro 标配了 65W 的充电头，充电速度速度非常理想，在剩余电量 10% 的情况下，半小时可以充到 50%，1 小时接近 90%。

此外，由于 MateBook X Pro 充电走的是 USB PD 协议，可以直接给华为 P20 系列、三星 Galaxy S9、iPhone X（需要换 C to L 线）等支持 PD 的手机进行快速充电。

  

## 华为笔记本的 Mate 7？

作为一款全球前三的手机厂商推出的笔记本电脑，在 MateBook X Pro 上我们可以看到不少来自手机的「灵感」，比如全面屏设计、集成在电源键当中的指纹识别、金属表面工艺的处理。

这种「用做手机的思路做电脑」的思路帮助 MateBook X Pro 在强手如林的万元轻薄本产品中拥有了自己的差异化元素，同时也正是由于来自手机业务的丰富经验，让华为这个在 PC 市场的「新人」可以跑得比其他人更快。

回到 MateBook X Pro 上，经过了之前产品的探索，华为已经完全抹平了在产品层面上和传统 PC 大厂的差距，在某些方面甚至已经实现了反超。

在定价上，华为依然保持了一个「后来者」的「低调」，具体的配置和售价大家参考下图。

![](../Images/c2d5aaa91cbac66ab2cbd51f3326c9ea.png)

以对个人消费者可能最有吸引力的 7988 元、8688 元两个入门版本为例，在这个价位，MateBook X Pro 可以提供最好的屏幕、数一数二的工艺以及和传统 PC 厂商的竞品同样全面均衡的体验。

![](../Images/5129c84962ce3745626e9d950f899961.png)

在 MateBook X Pro 发布后，有媒体把它比作华为笔记本电脑的 Mate 7。

我们认为，单从产品上看，MateBook X Pro 配得上这个评价。不过当年的 Mate 7 之所以能取得巨大的成功，产品做得好只是基础，产品之外的营销和渠道也起到了巨大的作用。MateBook X Pro 也是如此，它是否能成为华为笔记本电脑的 Mate 7，可能就取决于这些产品之外的因素了。 ■
