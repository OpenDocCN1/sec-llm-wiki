# 华为 MateBook X Pro 图赏： 当笔记本电脑也遇到「全面屏」

> **华为发布新一代 MateBook X Pro 笔记本电脑，最大的特点是「全面屏」设计。**

在今年 2 月底的 MWC 上，华为发布了全新的 MateBook X Pro 笔记本电脑，这是继 2016 年 2 月的第一代 MateBook 和 2017 年 5 月的 MateBook X、D、E 之后，华为发布的第三代笔记本电脑。  

一个半之后，4 月 12 日，在发布新一代 P20 系列旗舰手机的同时，华为宣布了 MateBook X Pro 在国内上市的消息，起售价为 7988 元。

这款号称拥有「全面屏」设计的笔记本电脑有何特别之处？我们一起来看一下。

![](../Images/606420ecae7ecf4ae732b594742ec57a.png)

MateBook X Pro 的机身为全金属材质，A 面、C 面、D 面均为金属，并且全部采用了精度和成本更高的 CNC 工艺。

![](../Images/f5096d53e9fb93e8fea3c42ad4bd0d5d.png)

和同样采用 CNC 工艺的 MacBook 相比，MateBook X Pro 的金属表面做得更加光滑，并且机身边缘处的处理要更加圆润。这些不同通过图片很难表现出来，不过上手后很容易感知出来。

![](../Images/e77df066ac53a590dd388e4371757a2d.png)

MateBook X Pro 的机身厚度为 14.6 毫米，重量 1.33 公斤，两项数据都和苹果的新款 13 英寸 MacBook Pro 相当，考虑到 MateBook X Pro 的屏幕面积和电池容量都要更大，配置也要更高，这个表现还是很不错的。

![](../Images/ef2f2ef092146d8bdd54ade23698e007.png)

更加难得的是，MateBook X Pro 在这样超薄的情况下，依然塞进去了一个标准的 USB Type-A 母口。

![](../Images/ec59b5bd3ab99dcc264b8b17872bdcfa.png)

在 MateBook X Pro 机身的左侧，还可以看到一个 3.5 毫米耳机插孔和两个 USB Type-C 接口（有一个支持 Thunderbolt 3）。  

打开电脑，可以看到 MateBook X Pro 最与众不同的地方——「全面屏」。

![](../Images/cd7689e7b86e0bff45a829fc5ed22a77.png)

超窄边框在笔记本电脑中并不算什么新鲜事物，戴尔在 2015 年初发布的 XPS 13 上就采用了三面超窄边框的高屏占比设计。不过受限于工艺等原因，目前的笔记本电脑基本只能做到左右两边或者上、左、右三边超窄，「下巴」普遍比较宽。

![](../Images/bbd32bd9ba94d19050cf4e0a2f9b97ec.png)

不过在 MateBook X Pro 上，华为通过将部分线路板翻转到键盘下方等方式，在上、左、右三个边收的极窄的基础上，还大大收窄了下边框的宽度，从而让它的屏占比达到了夸张的 91%。 

![](../Images/8e6959053872b4247069504c6f25dfe9.png)

华为将 MateBook X Pro 的屏幕称为「全面屏」，从视觉效果上看，这个「全面屏」非常地货真价实。  

除了超高的屏占比，MateBook X Pro 这块屏幕本身的素质也相当不错。它的对角线尺寸为 13.9 英寸，长宽比为 3:2（和 Surface、Pixel Book 等产品相同），分辨率高达 3000X2000，ppi 为 260，最高亮度 450 尼特，拥有 100% 的 sRGB 色域以及 1500:1 的高对比度，支持 10 点触摸。另外，为了在高分屏的同时控制住功耗，MateBook X Pro 这块屏幕的液晶基板还采用了成本更高的 LTPS 低温多晶硅工艺。

![](../Images/e7fb8af6fe290df1af702de5fd8c1f05.png)

由于屏占比太高，MateBook X Pro 的 B 面没有额外的空间安装前置摄像头，华为把 MateBook X Pro 的前置摄像头「藏」在了键帽下面，位于 F6、F7 之间，按一下即可弹出。

![](../Images/deffc802b6a0b389a1fb73cc41ef399b.png)

上一代 MateBook X 采用的电源键解锁在 MateBook X Pro 上也得到了保留。

![](../Images/a7701271c31f084b95f11ddda9b1e12f.png)

配置方面，MateBook X Pro 搭载了轻薄本中常见的英特尔第八代 U 系列 CPU，TDP 为 15W（没有进一步解锁功耗墙），具体型号为 i5-8250U 或者 i7-8550U。  

除了集成显卡，MateBook X Pro 还提供了搭载 MX150 独显的版本，虽然低功耗设计让 MX150 性能定位比较入门，不过实际性能至少还是比集显好得多。此外，由于 MateBook X Pro 配备了 Thunderbolt 3，用户可以使用外置显卡来进一步提升它的游戏性能。

![](../Images/4b8b70a102430138ce78472a25e5131f.png)

MateBook X Pro 提供了 4 种配置可选，其中 i5 + 8GB + 256GB、无独立显卡的版本售价 7988 元，剩下的 3 个版本均搭载了 MX150 独显，i5 + 8GB + 256GB 售价 8688 元，i7+ 8GB + 256GB 售价 9988 元，i7 + 16GB + 512GB 售价 12988 元。 ■
