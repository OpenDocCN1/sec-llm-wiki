对于锤子科技来说，2017 年是一个成熟后高速成长的一年。

随着吴德周等得力干将的加入以及资本问题的解决，锤子科技终于解决了多年的供应链问题。在大家最关注的产品层面上，在经历了 T1、T2、坚果 U1、M1 的「学习」后，2017 年，锤子用坚果 Pro、坚果 Pro 2 两款非常有竞争力的产品在销量、用户口碑上都完成大幅度的提升。

特别值得一提的是坚果 Pro 2，在去年下半年同质化严重的全面屏手机市场，坚果 Pro 2 在符合大众审美的情况下又做出了足够的差异化，同时在性能、拍照、续航等基础的体验点上做的足够出色和均衡。

进入 2018 后，锤子科技拿出来的第一款新机依然是坚果——坚果 3，它延续了坚果 Pro 2 身上很多优秀的特征，售价更低，不过在外观上有一个明显的变化。

  

## **从上下窄边框到三边窄边框**

在全面屏手机时代，手机厂商最常见的处理方式是 18:9 比例屏幕（通常在 6 英寸左右）加上下窄边框，这种设计在屏占比、视觉效果、成本上取得了一个比较好的平衡，坚果 Pro 2 用的也是这个方案。

![](../Images/cff75fcea56f5df419485d0d3bdb5718.png)

不过有些意外的是，在坚果 3 这款定位比坚果 Pro 2 低一档的产品上，锤子却为它「升级」到了上、左、右三个边都比较窄的三面窄边框设计。  

在这之前，大家最熟悉的采用这种三面窄边框的机型应该就是小米 MIX 系列了，当然，再往前推，类似设计可以追到夏普 Crystal 的部分机型。

相比起常见的上下窄边框，三面窄边框可以在竖向使用时带来更好的视觉体验、更强的沉浸感，不过在横向看视频时会少了一些对称的美感。

考虑到坚果 3 仅仅 1299 元起的定价，这种三面窄边框设计无疑是一个加分项。

屏幕方面，坚果 3 也没有什么意外的地方，5.99 英寸 LCD 屏幕，长宽比 18:9，分辨率 2160X1080（FHD+），显示品质没太多可以挑剔的，同价位中的优秀水准。

![](../Images/7ea36ecce07a47316b2f18a23e5b80d0.png)

  

## 「下巴」中的前置指纹和前置摄像头

选择了三面窄边框之后，剩下的问题是听筒、传感器、前置摄像头等必要的元器件应该往哪里了，在这方面，坚果 3 参考了 MIX 等产品的处理，并且做了一些自己的「定制」。

听筒方面，坚果 3 的处理和坚果 Pro 2 没有太多区别，都是位于屏幕上方的边框边缘，在深色机身上基本看不出来，白色面板上可以看到一条不明显的缝隙。

坚果 3 比较特别的是它的「下巴」部分。

![](../Images/ce6f841d0852545365a6d89969bf51b9.png)

由于需要为屏幕排线和天线净空区留下空间，坚果 3 的屏幕下方保留了一个「下巴」，而且受限于成本，这个「宽度」控制得只能说是中规中矩。  

不过好在锤子并没有浪费这块区域，坚果 3 在这个「下巴」塞了一个已经越来越少见的前置指纹，识别的速度、准确率都比较理想。

至于另外一个必要的元器件——前置摄像头，坚果 3 把前置摄像头放在了指纹识别的左侧。从自拍体验上来说，这个位置要比小米 MIX 的右下角稍微好那么一点点，取景时画面好歹基本是「正」的，不过显然，靠下的摄像头位置意味着你的鼻孔和下巴会变得比平时更明显，自拍时还是得老老实实把手机反过来。

不过作为一个经常能在交互上带来惊喜的公司，锤子给坚果 3 这个本来很尴尬的前置摄像头位置加入了一个看上去颇为「杀手」的功能。

只要点亮手机，在任意状态下（包括锁屏状态）只要把手机翻转过来，就可以直接启动自拍功能，非常方便。此外，坚果 3 的前置摄像头规格也不错，像素 800 万，采用了 ArcSoft 的美颜虚化算法。

  

## **方正的机身，坚果 Pro 2 相同的后盖**

除了正面的改变，坚果 3 其他地方和坚果 Pro 2 基本保持了一致。

![](../Images/f8d794bfb81d92099a68563a47e65255.png)

中框依然为铝材质，风格依然偏方正，中框的中间是一条贯穿机身的「金线」，按键中间也像坚果 Pro 2 那样加了一些纹理，很有辨识度。  

后盖部分，坚果 3 也依然是和坚果 Pro 2 一样的玻璃材质，后盖中间靠上是锤子的「T」字 logo，当然了，由于坚果 3 采用了前置指纹，所以这个指纹识别 logo 是没有集成后置指纹的。

![](../Images/383b547f3dbc05e2eb15e99182cf45af.png)

在后盖的左上角，可以看到目前已经成为标配的双摄像头，两个摄像头像素均为 1300 万，一颗黑白，一颗彩色，规格和第一代坚果 Pro 相同。关于坚果 3 具体的拍照表现，我们会在之后的产品评测中细聊，大家可以持续关注极客之选（微信号：GeekChoice）。  

![](../Images/db268b50dc57ece19e43248a759449b4.png)

需要说明的是，由于整机的风格比较方正，坚果 3 看上去没有那些采用弧面后盖的机型薄，不过其实坚果 3 的厚度仅有 7.16 毫米，所以拿在手里也完全不会有任何厚重的感觉。  

  

## **骁龙 625，4000 毫安时超大电池**

作为一款定位千元出头的手机，坚果 3 在硬件上显得就有些普通了，SoC 为一代「神 U」骁龙 625，运行内存为 4GB。

即使现在看，骁龙 625 在功耗、发热上也是足够出色的，不过没有高性能 CPU 大核和相对一般的 GPU 意味着坚果 3 不太适合玩大点的游戏，如果你喜欢玩《王者荣耀》或者「吃鸡」，采用骁龙 660 的坚果 Pro 2 或者其他采用骁龙 8 系列的机型会是更好的选择。

虽然 SoC 亮点不多，不过坚果 3 的电池容量达到了 4000 毫安时，考虑坚果 3 很薄的机身，这个容量还是很可观的，再配合非常省电的骁龙 625，坚果 3 的续航表现应该足够大多数用户撑上两天。

![](../Images/c250a004871da4875e3732ab5602367e.png)

充电上，坚果 3 也标配了 18W 的快速充电，在这个价位的产品中依然算得上是个亮点。
