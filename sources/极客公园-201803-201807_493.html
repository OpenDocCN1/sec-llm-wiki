三月终于来了，到西南偏南去，追逐这些问题

在这个顶级创新舞台上，中国公司开始被期待着解答那些世界的难题。

从中国北京市 798 艺术区的「大蓝罐」到美国奥斯汀的 SXSW（西南偏南大会）主会场，Google 地图给出的距离是 11441.83 公里。冬未去，春已来，跨过了一个好似漫长的农历春节，这也是 GeekPark IF（极客公园创新大会）走过的距离。

无论北京还是奥斯汀，城市因为那些跳脱的、鲜活的、孑然独立的灵魂而被赋予美好的价值；响彻这些灵魂之间的每一阵集结号角，就是这种美好一次又一次的集中爆发。

冬天的告别刚刚过去并不久远，GeekPark IF 大会在烟花三月南下德州。这是极客公园同西南偏南大会的连续第二年协作，如约而至。2017 年的 3 月，极客公园召集了摩拜、知乎等中国最为有趣鲜活的科技公司来到奥斯汀，实现了中国创新商业势力在 SXSW 的首次集体亮相。一年之后，年轻的 GeekPark IF 与刚刚而立的 SXSW 又将再一次地交融碰撞。

一年之间，一些公司做到了一些事情，都藏于水面的波澜之下。这些事情甚至称不上新闻，无法点燃这个时代人们饥渴的狂躁；但在我们看来，却是如此美好，而又弥足珍贵。

一家名叫 VIPKID 的公司「填平」了太平洋，激活出两个世界主流语种的教育链接，从看似一块铁板的传统行业破壁而出；通身亮黄色的 ofo 告别了「野蛮」扩张，通过算法避免了溢出的单车资源沦为城市垃圾；呢喃的荔枝则让声音成为了陪伴每一个孤独灵魂的亲密伴侣。看似不可思议的事情，仍然绽开在这个移动互联网时代。

小鹏汽车静悄悄地打造了新车，将自动驾驶和中国道路真实地又拉近了一步；Sugr 在智能音箱跌宕的涨潮和退潮之间，缓解了人们对于人机语音对话的担忧和忌惮；眼擎科技则在为忽明忽暗的 AI 技术点亮双眸。那些看似远在未来的憧憬，已经将我们的交互方式点滴改变。

快手跳出了短视频和直播的吵闹喧嚣，成为了新一代记录人生和城市必要载体；腾讯公益聚集起那些看似支离破碎的资源与善意，一度一度地温热着每一处城市乡村。正是科技，而不是别的，再让我们的社会每天进步一点点。

极米把电视的趣味从屏幕框下的牢笼中解放出来，成就了年轻人的观影习惯；还有一个孩子们的心头之好，Makeblock，搭建起了「积木」的新时代。制造人见人爱的硬件，本就不该拘泥于什么章法条例。

这些有趣和美好的发生，既是问题，也是答案——为何是此时？为何是此地？他们又是如何付诸实现？

历史已经蹦蹦跳跳地告别了那个中国公司出海卖弄猎奇、或承受苛责的门槛。在西南偏南，科技商业与人文艺术互相拥抱；来自全世界超过十万的参与者，都期待着又一次从这些中国公司的活力中，获得那些全球性问题新的思考线索和观察维度。

于是，在 GeekPark IF 与 SXSW 每年一度的交集当中，世界创新者的不再单单凝视于「了解中国」，更多的则是期盼从中国势力中窥见线索、碰撞思维、共享趣味与价值。

在这个交集中，你可以扮演求索者，兢兢业业；也可以扮演布道者，解惑渡人；更可以只是扮作一个鲜衣怒马的玩耍者，享受这其中碰撞与交融所得的一切——最终，你必须做一个独立思考者，这是此时此地的入场通行证。

在冬天的北京，几千枚好奇的心灵，收获了几万轮次开怀畅快的思考；在春天的奥斯汀，十万颗好奇的心灵，又在期盼着多少问题和永无止境的回答？

三月终于来了，互道一声春天快乐，在这个被「正确答案」充斥得密不透风的时代，我们更愿意做那个追逐问题的人。

让特立之人不再独行。烟花三月，德州再会。
