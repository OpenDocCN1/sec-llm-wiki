「移动解忧站」或许是人类对于汽车最终形态的愿望，显然福特新蒙迪欧智控版插电混动车型正在为这一点努力着。

极客之选之所以将目光聚集在一辆插电式混合动力的车型上，更多的是因为用户对于出行方式以及车辆的选择上都非常矛盾，无论是传统的燃油车型还是新晋的新能源车型，它们身上总一些能够引起用户焦虑的地方。这也是为什么我们在直播当中提出了「移动解忧站」这个概念，极客之选更希望车是作为一个能为用户解决忧虑的点，而不是制造更多。

通过标题相信大家也能看出，福特新蒙迪欧智控版插电混动车型在多方面都拥有着亮眼甚至是领先同级的表现，这三点也恰恰体现了福特在官方所宣传的智擎、智行以及智联三个关键点，所以本篇文章极客之选也将会从这三个方面来分享试驾感受。  


整体 ID 设计不变 多处小改

在外观上 福特新蒙迪欧智控版插电混动车型的整体设计与老款相比变动不大，依旧保持了流畅的车身线条，标志性的「大嘴」也在，不过进气格栅稍稍发生了一些变化，看起来稍稍有点「中国风」，多出了几分典雅的感觉。

雾灯也采用了全新的造型设计，雾灯下方的镀铬装饰给车头部分一个视觉上的横向拉伸，而雾灯本身搭配了更加凌厉的线条和纵向的延伸，相比以往也变得更加有设计感，正面的整体感和层次感也更强。另外尾灯部分采用了全新样式的镀铬设计，融入在尾灯组当中，使用曲线让整个车尾看起来更加动感，轮毂也采用了全新的样式，10 幅双色轮毂很贴合插电混动版自身的定位，在沉稳当中透露一丝张扬的个性，但又不会给人太过躁动的感觉，尺度拿捏的非常到位。  

如果想要区分福特新蒙迪欧智控版插电混动车型和汽油版的车型，其实在尾标上就能看出，在「MONDEO」标志的下方会多出一个象征插电混动的「Energi」logo 出现，假如是顶配车辆的话，独有的「TITAMIUM」标识则会出现在右侧。

除了标识以外，福特新蒙迪欧智控版插电混动车型在前翼子板的位置会多出一个充电口。外面看起来和加油口差不多，但打开之后是电枪的接口，这部分体验我们会在后续的内容中提及。以上这些便是福特新蒙迪欧智控版插电混动车型在外观方面的改动以及和汽油版车型的不同之处。


智擎，插电混动解决里程焦虑

在混动车型中分为免插电混动和插电混动，前者的出现较早，不过插电混动作为后来者也有着非常明显的优势，具体优势有哪些，咱们慢慢说。

福特新蒙迪欧智控版插电混动车型最核心的部分便是这套插电混动系统，它采用了电动机+2.0L 阿特金森循环发动机+eCVT 电控无极变速器和容量为 9kW·h 的锂离子电池组，整车的百公里综合工况油耗仅为 2.0L。

其中 2.0L 的阿特金森循环发动机也就是汽油机的 最大输出功率可达 105Kw，最大扭矩 174.9 牛米 ，而 eCVT 电控无极变速器则是能够高效率的将有发动机驱动、电动机驱动和混合驱动以及能量回收等等都结合在一起。同时也保证了动力切换平顺，具有结构简单、可靠性高的特点。

因为拥有 9kW·h 的锂离子电池组，所以福特新蒙迪欧智控版插电混动车型能够在纯电动模式下提供最高 52KM 的续航里程。福特新蒙迪欧智控版插电混动车型一共拥有「自动 EV」「立即 EV」「随后 EV」三种驾驶模式，通过扶手箱前方的「EV」按钮便可切换。

「自动 EV」很好理解，就是由车辆本身的中控单元对驾驶者的操作进行判断，依照目前的工况决定是混合输出或者是电力、燃油单独驱动。「立即 EV」是指使用纯电动模式进行驱动，而「随后 EV」则是优先使用发动机进行驱动。

经过极客之选的实际体验，在往返 30KM 左右的路程中，有小部分的拥堵，改行程下的百公里油耗仅为 1.1L。在全程 90% 的情况下都使用纯电行驶的情况下，电量剩余 40% 左右，所以不难看出 52KM 的续航非常贴近用户真实的使用情况。

通过这点也不能看出，福特新蒙迪欧智控版插电混动车型其独特的优势在于如果路程较短的情况下，比如说上下班通勤，如果您的往返路程小于 40KM，您甚至可以把这台福特新蒙迪欧智控版插电混动车型看作是纯电动车来对待。

与此同时，因为是插电混动版本的缘故，福特新蒙迪欧智控版插电混动车型也能提供非常理想的续航里程。对于传统燃油车主所顾虑的堵车油耗高，它能够在纯电驱动下更好的完成这个任务；而新能源车主总担心电量不够，它能够提供超长的续航里程的同时，还能作为纯燃油车使用，车主只要去加油站 1 分钟便能「满血」复活。

如果说作为「纯电车」来使用的话，充电肯定是必不可少的，在这一点的体验上福特新蒙迪欧智控版插电混动车型确实和新能源车型没有太大的区别。

它支持两种充电方式，充电桩的高功率快充，这需要车主办理国家电网的电卡或者是一些充电桩支持手机支付等，使用快充充电的情况下充满大约需要 2.5 小时左右。同时，它也支持普通的 220V 家用电源进行充电，在后备箱内富有国标三头插孔的充点枪，这种情况下充满大约需要 5 小时左右。

福特新蒙迪欧智控版插电混动车型的充电插口在车辆的左侧前翼子板上，在接口旁边还有提示电量的四个 LED 提示灯，车主也能通过它来快速知晓目前的电量情况。当然，作为一台强调互联功能的车型，车主还能通过福特派来远程查看车辆的充电情况。

有一个细节引起了极客之选的注意，仪表右侧的液晶显示屏上，可以调节到「节能绿叶」的选项，画面中会显示一个树叶，它枝叶的茂盛与否是由驾驶员的驾驶习惯来决定的，虽然很多车型都有瞬时油耗或者用颜色来提醒当前的驾驶表现，但这种近似于游戏的方式能够更好培养或者是改正驾驶员的不好习惯。  

因为支持纯电行驶的缘故，福特新蒙迪欧智控版插电混动车型在很多有限牌政策的城市可以获得一块牌照，这对于消费者来说也同样是一个非常有竞争力的部分，同时这也算是解决了消费者的一个烦恼，毕竟在很多城市一个车牌就代表是十万元左右的成本增加。


智行，高级辅助驾驶配合主动安全防护

车有了，既能当「电车」用也能当「油车」用，解决了第一个阶段的焦虑我们就开始思考出行问题了。福特新蒙迪欧智控版插电混动车型在行车上也展现出了智能的一面，这也为很多车主解决了出行的烦恼。

福特新蒙迪欧智控版插电混动车型拥有丰富的主动安全科技配置，比如像是 ACC 全速智能自适应巡航控制系统、LKA 车道保持辅助系统，智能感应制动保护系统（带行人识别功能）、盲区监测以及主动泊车辅助系统功能。

对于 ACC 全速智能自适应巡航控制系统（简称为 ACC 自适应巡航）来说，熟悉汽车的网友应该不会感到陌生，相比普通的定速巡航，ACC 自适应巡航更加安全也减少了驾驶员的负担。

因为名称中的「全速」二字，也就说明了该系统是可以在任意速度时开启实现巡航，福特新蒙迪欧智控版插电混动车型的多功能方向盘，左下方是控制巡航功能的区域，点击「ON」键开启之后，可以按下「RES」键开启巡航，同时还能设定与前车的安全距离，设定完成后车辆会按照驾驶员设定的速度与车距进行巡航。

与此同时车辆也会监测前车的距离，如果与前车距离小于设定的安全距离便开始减速，一直保持设定的距离，如果前车加速或者变道，车辆则会恢复到设定的巡航速度。车辆与前车的距离同样是可以调整的，通过巡航区域箭头的按键便可以增加或减小距离设定，目前一共有四个距离档位可供选择。

福特新蒙迪欧智控版插电混动车型也支持 Stop&Go 功能，通俗点说车辆在巡航速度小于 30KM/H 的时候，如果监测的前方车辆减速甚至停车，车辆也会完成停车的动作，前车如果继续行驶，驾驶员方向盘的按键或者是轻踩油门踏板都能够使车辆继续恢复巡航状态。这在很多堵车严重或者需要频繁跟车的情况下，对驾驶员来说绝对是一个非常实用的功能。

LKA 车道保持辅助系统同样是一个减少驾驶员负担的功能，福特新蒙迪欧智控版插电混动车型在 65KM/H 的速度以上可以开启，点击转向灯杆顶部的按键就会看到仪表上车辆出现虚线，如果颜色变绿说明成功识别了当前行驶车道的标识线。这是假如车辆的方向逐渐偏离车道的话，方向盘会进行小幅度的修正，并提示驾驶员。

值得一提的是，ACC 全速智能自适应巡航控制系统和 LKA 车道保持辅助系统同时开启的话，其实车主就相当拥有了一套高级辅助驾驶功能，比如像是环路或者是没有急转弯的高速公路上，开启这两个功能就一直能够保持在当前车道行车的同时，还能保证监测前方车辆并保持安全距离。

智能感应制动保护系统（带行人识别功能）则相当于对车主以及行人都提供了一份更加安全的保障，这个功能相信也不用极客之选详细介绍了，从名字就就能看出车辆能够识别即将发生的碰撞，仪表台前风挡下方会有红灯亮起，并伴随警示声来提示驾驶员，并会进行预制动，假如驾驶员仍没有反应便立即刹停。

至于盲区监测和主动泊车辅助系统，这一定是新手司机喜闻乐见的功能，盲区监测可以提示驾驶员车辆左右两侧盲区内是否有车辆，这对于驾驶员需要变道时提供了一个良好的提示作用。而这套自动系统如果能够成功识别车位便可以根据提示，驾驶员只需进行档位的切换，其他的则交由车负责。

福特新蒙迪欧智控版插电混动车型这里有一点想提醒大家，新蒙迪欧智控版（汽油版）除了顶配以外，中低配的智控豪华版车型会升级包括 ACC 全速智能自适应巡航控制系统、LKA 车道保持辅助系统，智能感应制动保护系统（带行人识别功能）和主动泊车辅助系统这几项主动安全功能，可以说是非常让人心动的配置下探，加量不加价。  


智联，改变你对传统车机的印象

在很多车企都大喊「互联网座驾」时，到底应该如何理解这几个字呢，在极客之选看来只要车辆本身具备互联网功能的同时车机系统足够智能化，能与其他智能设备联动，就能算是互联网座驾，显然福特新蒙迪欧智控版插电混动车型就是这样一款车型。

在这方面首先要提到的就是 FordPass，它的中文名字是福特派，这是一款集远程控制、状态查询、导航联动、车主服务等于一身的车主必备 APP，想要使用它也非常简单，车主只需要下载福特派应用（Android 和 iOS），然后通过 VIN 号也就是我们俗称的车架号就能添加车辆，之后车辆的中控屏幕上确认便可以完成绑定。

绑定后车主可以远程锁定/解锁车辆，还能远程启动，在冬季这相当于帮车辆提前进行热车，利用软件还能查看车辆位置、续航里程、燃油剩余、电量剩余、胎压等等。

除此之外，车主还能通过福特派进行维修保养的在线预约、福特大使、福特金融等服务，可以说是为车主提供了全面的汽车使用服务。

假如您是非福特车主，这款福特派对于您的用车体验其实也非常有帮助，比如可以使用福特派来查询附近的停车场，看看哪里有加油站，最近的商圈在哪里。这些功能即使没有绑定车辆，也能够正常使用，算是福特给车主的一个小福利吧。  

进入福特新蒙迪欧智控版插电混动车型之后，与车主「长期相处」的则是 Sync 3 系统，如果您熟悉福特这个品牌的话，相信 Sync 系统对您来说并不陌生。Sync 3 系统给极客之选留下了非常不错的第一印象，它本身拥有非常出色的色彩显示，足够细腻的分辨率，屏幕尺寸也够大，并且对于触控操作的响应也足够灵敏，这完全摆脱了大多数人对于车机系统的传统认知。

Sync 3 这套车机系统在功能逻辑上的划分非常清晰，底部的页签可以让车主比较容易的上手，像是音频、空调、电话、导航这些功能一目了然，而应用程序也是 Sync 3 系统 APP LINK 独有对于第三方应用的支持，设置则是为车机系统进行了丰富的功能调节。

福特新蒙迪欧智控版插电混动车型的 Sync 3 系统本身支持数据连接功能，车主在第一次使用的时候进行激活后，便能够使用车辆本身的数据网络，同时 Sync 3 本身还能为乘客提供热点，这一点显得非常人性化。

Sync 3 本身拥有强大的语音识别功能，用户点击多功能方向盘上的语音按键便可以进行语音控制，搜索地点、调节空调、音量等都没问题，系统本身也为用户提供了一些例句参考。

通过近期的体验，极客之选认为 Sync 3 目前是一套完成度和匹配度非常高的车机系统，完成度高是因为在众多细节体验上 Sync 3 都表现很出色，比如车机拥有类似于 Android 的音频音量和系统音量，如果车主使用的是 Sync 3 的导航功能，那么音频的音量和导航音量是互相分离的，这一点细节确实给了极客之选不小的惊喜。

之所以说匹配度高是因为用户能够通过之 Sync 3 完成很多车内的设定，比如像是氛围灯的颜色选择以及座椅的调节和按摩功能，同时也能控制车辆内的多种设定，这也是车机本身作为原厂配件的最大优势，Sync 3 很好的保持了传统优势的同时，也让车机的使用体验更加符合用户预期。

Sync 3 系统也支持手机映射功能，如果是 Android 设备来说它能够支持百度 CarLife，如果是 iOS 设备则可以使用 CarPlay 功能，本身两者的功能都比较类似，就拿 CarPlay 来举例。

连接数据线后，手机端就会收到 CarPlay 的提示，允许后 Sync 3 就会进入 CarPlay 的界面，相信对于 CarPlay 大家都已经很熟悉了，常用的电话、短信就不再多介绍了，Siri 也算是 CarPlay 的主打功能，识别准确率和功能都有不错的表现。

苹果也开放了第三方的音乐应用，像是 QQ 音乐、网易云音乐、喜马拉雅等等，用户可以按照喜好自行选择。在用户将 iPhone 更新到最新的 iOS 12 并且更新最新版本的百度、高德导航后，用户也能够使用了除了自带地图以外的第三方导航应用，语音控制、音乐和导航，这三项车机最为核心的功能都给了用户相当高的自由度。


写在最后

尽管福特新蒙迪欧智控版插电混动车型是一辆改款车型，它并没有很大的外观变化，但细节的改动让它根据辨识度。随着智擎、智行和智联这三个核心卖点的体验不断提升，福特新蒙迪欧智控版插电混动车型的产品力变得更加出色。

通过这篇文章，相信网友对于「移动解忧站」这个概念也有了更深的理解。福特新蒙迪欧智控版插电混动车型在这样一个强调新出行的时代下，既拥抱了新技术，同时也解决了令消费者迟疑的选择焦虑，同时整车的科技配置配合互联互通的理念，让用户无论在驾乘安全还是全周期的使用体验方面都得到了全方位的保证。与此同时，这些体验不仅仅出现顶配车型上，中低配车型也同样能够享受到了科技带来的安全保证以及智联体验，对于 B 级车市场，福特新蒙迪欧智控版插电混动车型无疑是一颗重磅炸弹。
