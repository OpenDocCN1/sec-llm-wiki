寒冬里爱奇艺开了一场动漫盛典，只有好内容才能安全「过冬」

「不可能大家都能活下去，行业洗牌是一定的。」


王洁雯走上台，她的语速很快，显得有些紧张。「我刚刚入行三年，很高兴有这个机会站在这里跟前辈和老师们分享。」

王洁雯是六十一分漫画工作室的创始人，她的工作室去年刚刚成立，是动漫行业里不折不扣的新人。「六十一分的理念是在一小时的基础上多创造一分钟，多努力一分钟。」2017 年王洁雯组建起了一支清一色平台编辑出身的团队，打算「制作一些完全不一样的市场内容」。

一年多，六十一分完成了十五部作品，其中成功出现了一些爆款漫画。《在座的都是废物》自三个月前正式上线后，多次进入平台人气周榜的前十名，目前跻身人气总榜的第十一名，人气值高达 11.9 亿。

作为成功的初创团队，王洁雯受平台方爱奇艺邀请来到「FUN 盛典」的行业峰会，代表漫画领域做主题演讲。当晚《在座的都是废物》拿下了爱奇艺颁发的「年度最佳漫画黑马奖」。

台上的王洁雯说着团队创办之初的故事，她说最重要的就是剧本。组建团队时她还创办了一支编剧团队，成员包括小说家、网络写手以及影视剧的编剧，形形色色讲故事的人。「始终要走在市场、读者的前面。经常有人告诉我们，市场需要什么样的题材，市场需要什么样的内容。应该是我们引导读者，引导市场的走向，只有优秀的作品才能做到这一点。」王洁雯语速依然很快，但聊起行业，她的语气坚定了许多。

「斗胆分析一些行业的现状和未来。」她有种初生牛犊不怕虎的韧劲。


「寒冬来了」之后

王洁雯登台的前一天晚上，动漫行业正在哀嚎。

「寒冬来了！」一篇篇行业媒体的深度报道在朋友圈刷屏，偶有动漫从业者转发时不忘戏谑：「这行业什么时候有过春天？」

哀嚎背后的罪魁祸首，是频频爆出的多家动漫行业公司拖欠员工、作者薪酬的新闻。风波中的主角小到漫画作坊，大到平台型动漫公司，甚至是市场上主流玩家之一的腾讯动漫，也被传出了计划削减低劣签约作品的消息。

腾讯动漫的传闻是压死骆驼的那最后一根稻草，一时间动漫从业者的圈子里山呼海啸。可是「行业新人」王洁雯却不以为然，她认为所谓的寒冬不过是一次洗牌。

2015 年王洁雯刚刚入行时，动漫行业形势一片大好，各类作品百花齐放，资本也是有求必应。三年下来，平台、创作者和读者三方都经历了一次洗牌。付费的用户习惯逐渐养成，读者对优质内容的需求觉醒，加上特殊的资本环境，行业里的泡沫渐渐消散开来。王洁雯觉得现在的行业比三年前更加冷静，「所谓的洗牌对头部作品影响很小，现在行业寒冬的喊话，是对末位作品的淘汰，头部作品则有了更多的机会。在这个行业，内容始终是核心竞争力。」

从创业之初就瞄准了精品内容的六十一分显然非常适应目前的「寒冬」。谈起工作室未来的发展计划，王洁雯说六十一分在 2019 年会围绕 IP 展开，全面开发已有 IP，打造更多的精品 IP。《在座的都是废物》与平台方爱奇艺达成了影视改编的合作，加入了后者「苍穹计划」的第二期。


逃离寒冬

「苍穹计划」是爱奇艺作为国内头部的二次元平台孵化动漫 IP 的诸多计划之一。目前计划已启动两期，一期 10 部，二期 15 部。二期在去年漫画改编计划的基础上加入了动画和轻小说的内容。改编方向除了网络大电影和网剧以外，爱奇艺动漫事业部总经理李菲还表示，爱奇艺正在针对「苍穹计划」的 IP 做动画和院线电影的布局。

漫画是爱奇艺直到去年才开始发力的领域，年底就能够推出「苍穹计划」进行优秀漫画 IP 的网大改编，其实得益于爱奇艺在漫画项目挑选上做出的思考。「我们是后来者，做得比较晚，但我们的优势是影视化加持，所以我们更多地开发能够快速影视化、IP 化的漫画项目，而不是一些在前项付费上比较火的『霸总』一类的作品。」爱奇艺高级副总裁耿聃皓在采访中说道，「所以我们在做漫画项目最开始和创作团队沟通时，都会把未来影视化的整个链条想清楚。现在我们有很多项目能够很快地改编成网大或者网剧，因为作品和我们的方向是契合的。」

「苍穹计划」的部分 IP 内容上线仅仅半年就有不止一家的影视公司主动竞标改编，「在院线电影选择我们的 IP 时，特别明显地发现，真正的好故事、好内容是一个长线的发挥，一定是受所有人认可的。」李菲对极客公园的记者说道。

某种程度上，如王洁雯所说，对内容的高要求帮助爱奇艺巧妙地躲开了这次的「寒冬」。「目前来看，爱奇艺没有受到一点影响。」面对记者的诘问，李菲十分肯定地回答。

对于「寒冬」，耿聃皓有着更多的感慨。他与爱奇艺都经历过视频行业从大热到洗牌的过程，最终行业里只有头部几个平台活了下来，耿聃皓认为时下发生在动漫领域的也是同样的情况。

「不可能大家都能活下去，行业洗牌是一定的。」他把过去两三年称为一段「快速的、不太理性的发展」，这之后就要遵循互联网行业的规则，每个平台都要找到自己的定位和发展方向。对爱奇艺而言，这是耿聃皓很早就想到的结果，爱奇艺动漫需要的是爱奇艺平台的影视化能力，也就是如今「寒冬」里爱奇艺仍在做的 IP 孵化。「爱奇艺一直有自己比较稳定的目标和方法论，有自己的打法，所以一直到现在我们还是在按照既定的打法在做。」


新的尝试

「轻小说」是爱奇艺今年才开始发力的业务。在刚开始接触时，耿聃皓面临着一个非常棘手的问题：「轻小说」应该归类到文学版块还是动漫版块？

「最后让我下定决心的是用户群，」耿聃皓回忆道，出于对「轻小说」用户群体的考虑，爱奇艺把它归类到了动漫频道，「我们认为轻小说是更年轻的用户感兴趣的题材、故事，它在校园里非常受欢迎，有很多校园的作者和读者，这和二次元的用户群是非常匹配的。」最终，轻小说和动画、漫画一起，加入到了爱奇艺专为动漫用户人群所做的「爱奇艺动漫」app 里。

年初，爱奇艺单独发布了爱奇艺动漫 app，产品内覆盖动画、漫画、轻小说和二次元直播等内容，配以二次元社区。独立 app 上线之后，爱奇艺还特别推出了二次元内容的会员服务「FUN 会员」。

和爱奇艺的体育会员一样，FUN 会员是专门针对泛二次元群体的会员服务，在二次元内容方面有着比爱奇艺 VIP 更多的权益，但耿聃皓也坦言两款会员服务其实有着内容上的重合。

在刚刚过去的第三季度，爱奇艺的会员收入首次超过广告收入，会员数达到了 8070 万。「二次元的用户群体可能没有影视综艺的用户群体大，但他们对网上付费的形式有着天然的接受，」耿聃皓说道，他说从新 app 上线之后的成长来看，「未来还是可以期许的。」

爱奇艺希望通过付费会员和独立社区的形式，借助优质的商业化平台推广内容。「不尝试做新的会员的话，VIP 就要看所有的内容」。在爱奇艺动漫的独立 app 上，FUN 会员可以看到专注视频的爱奇艺 VIP 会员大多不会选择的漫画和轻小说，加上社区里的其他内容，如手办等商品诉求，差异化的 FUN 会员对于专注二次元文化的人群无疑有着更大的吸引力。

「不变的话，可能永远不会前进。只有不断地变，不断地试。当然有时候可能会犯错，没关系，犯错改就是了。」当被问起 FUN 会员这样的尝试有没有必要时，耿聃皓说，「这样的尝试未来还会有很多，还会有其他的（内容、业务）单独剥离出来，具体说有没有必要，只要是能够给用户的价值最大化，让用户满意就可以。」

和去年一样，在行业峰会之后，爱奇艺「FUN 盛典」将如约在海南海口举办超级漫展活动。爱奇艺动漫所瞄准的成千上万的二次元爱好者们，将在周末踏上这座刚刚贴上二次元文化标签的旅游海岛，在动漫名作的主题展、漫画大师的签售会和漂亮小姐姐的 Cosplay 面前，二次元们的世界才不会有冬天。
