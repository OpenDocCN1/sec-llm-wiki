历史性盈利，周产仍没有到 5000 辆的特斯拉，背后的「加速度」究竟是什么？

带着 Model 3 超 20% 毛利率的利刃，特斯拉开启了自我「绝地反击」。


特斯拉杀手还在酝酿的时候，特斯拉反倒是自己开始提速。2018 年第三季度成为了特斯拉历史性的「转折点」——这是继 2013 年和 2016 年之后，特斯拉历史上的第三次盈利季度。

据刚刚发布的特斯拉第三季度财报显示，特斯拉在 2018 年第三季度创造了 68 亿美元的收入，并带来了 3.12 亿美元的净利润，特斯拉目前拥有现金流和现金等价物约 30 亿美元，比第二季度增加了 7.31 亿美元。

摆脱「烧钱」的状态，特斯拉凭借 Model 3 开始走向一个正向的轨道，并且展示了一个惊人的「加速度」。

从亏损到盈利的转变，很大程度上要归因于特斯拉今年第二季度到第三季度的 Model 3 产量几乎翻了一番。Model 3 的每周产量提升到了约为 4300 辆（不包括计划停产），这一季度一共向客户交付了 56065 辆 Model 3。而如果加上 Model S 和 Model X 的交付数量，特斯拉在第三季度交付了令人难以相信的 83775 辆汽车。

而本次盈利不仅仅是因为产量的大幅提升，背后更重要的变化是特斯拉实现了「内部成本效率目标」以及「毛利率」的巨大增长。

由于成本改善和生产效率的提高，每个 Model 3 的工时从第二季度到第三季度下降超过 30％，首次低于 Model S 和 X。这也导致 Model 3（GAAP）本季度的毛利率超过 20％（25.8％），远远超过大多数人的预期，包括特斯拉自己。特斯拉在第二季度的毛利率仅为 5％，第三季度预期的毛利率为 15％，大多数分析师认为这很难实现。

「每周产量约为 4300 辆」、「毛利率超过 20％」以及「工时下降超过 30％」这些关键数据来看，这都表明特斯拉正在关注生产效率而不是数量，并没有因为市场和舆论压力而选择了妥协，并且承担着这一切为我们带来惊喜。

在之前传闻特斯拉的「生产地狱」之外还带来了另一个「交付物流地狱」，而第三季度上的这些数据无疑打破了很多人之前的「臆想」，特斯拉也许只是从「生产地狱」转变到了「交付物流地狱」而已。这也正如马斯克所说「幸运的是，这些挑战比汽车制造更容易解决，我们在整个季度都取得了进步。」

这一季度的表现可以说是特斯拉自己的「绝地反击」战，因为目前特斯拉还根本不需要做出什么「反击」。特斯拉表示，「就收入而言，Model 3 是美国最畅销的汽车，就销量而言，它是第五畅销车型。」

第三季度美国乘用车销量

当特斯拉首次依靠 Model 3 盈利之后，能否「持续盈利」完成这个汽车产业的「J 型曲线」将是接下来所有人的关注点。这除了取决于成本再次改善以及生产效率的提升之外，市场预期以及订单情况就更为重要。

据第三季度财报显示，特斯拉表示对 Model 3 的需求依然不减，约 45 万名预订持有者中只有「不到 20％」的人要求退款。

另一方面，严格意义上来说，Model 3 这样一款成功的车型还并没有走向全球。Musk 和 Ahuja 表示，特斯拉将在今年年底之前开始在欧洲和中国接受 Model 3 的「订单」。「欧洲中型高档轿车市场规模是美国同类产品的两倍多。这就是为什么我们很高兴能够在明年初将 Model 3 带到欧洲。」特斯拉也在最近签署了租赁上海以外土地的计划，计划新建 Gigafactory，并于周三表示「目标是在 2019 年将部分 Model 3 生产带到中国。」

虽然低价的 Model 3 让特斯拉成为了更「大众」的品牌，也带来了更多利益，但目前来看，特斯拉也明确表示不希望销售低价汽车长期影响盈利能力。

也就是说特斯拉虽然仍瞄准 2019 年初推出长期承诺的 35000 美元，220 英里版本的 Model 3。但目前特斯拉推迟了其最实惠的版本落地，以便专注于更高成本，马斯克甚至表示，今年专注于低成本 Model 3 将导致公司「死亡」。

「Twitter」、「大麻」这一系列事件让特斯拉仿佛陷入了一个负面舆论的「漩涡」，好在马斯克利用这个第三季度财报告诉大家自己依旧「理性」，为新造车行业带来了很多值得关注的真正变量，期待未来特斯拉能够将财报中展现的许许多多的正向数据变为一个凶猛的「加速度」。
