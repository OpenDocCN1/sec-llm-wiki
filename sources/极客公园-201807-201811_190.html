小米手环 3 NFC 版售价为 199 元，首批适配了超过 160 个城市的交通卡。

文 | 极客之选


5 月 31 日，在小米手环 2 发布接近 2 年后，小米终于发布了第三代产品。相比小米手环 2，小米手环 3 在外观上更加时尚，采用了更大的触摸屏，并且在防水能力、运动检测等方面均有所升级，169 元的定价依然颇具性价比。

时隔 3 个多月，备受关注的小米手环 3 NFC 版也终于到来，将在 9 月 19 日正式开售，售价为 199 元，下面我们就一起来看一下这款产品。

我们拿到的这款是小米手环 3 NFC 限量纪念版，这是小米为了纪念小米手环全球累计出货突破 5000 万的特别版本。

这个版本限量 666 个，不会公开进行销售。和普通版本相比，限量纪念版在腕扣处增加了镭雕图案并印有一个限量编码（我们这个是 132 号）。

此外，限量纪念版的腕带采用了枫叶红配色，而普通版的腕带则提供了石墨黑、热力橙、深空蓝三种颜色，我们认为这个枫叶红腕带「颜值」还是不错的，希望之后也可以出现在普通版上。

外观和基础功能上，小米手环 3 NFC 版和普通版小米手环 3 并无区别，详细体验大家可以参考我们之前的文章，这里我们只做简单的介绍。         

小米手环 3 NFC 版表面采用了一块边缘弧度很大的玻璃，玻璃表面加了疏油层，在视觉上具有很好的一体性，玻璃下方是一块 0.78 英寸的单色 OLED 屏幕，分辨率 128X80（ppi 为 193），支持触摸。

小米手环 3 NFC 版延续了小米手环一贯的优势，正常使用下可以坚持 20 天。值得一提的是，小米手环 3 NFC 版支持 5ATM 级别的防水，可以在淋浴、泳池游泳及浅滩游泳时佩戴。

操控上，小米手环 3 NFC 版也非常直观，上下滑动切换功能（时间、天气、心率、步数、通知），左右滑动切换对应功能下的不同项目，触碰屏幕下方凹陷的区域返回，长按这里是启动部分功能（比如在秒表计时界面长按开始计时）。

功能特性方面，小米手环 3 NFC 版在同类产品里也是佼佼者了，包括在运动时可以显示运动数据的「运动副屏」、可以脱离手机实用的「事件存储」、自动心率监测、查看微信和 QQ 通知、配合小米手机和笔记本电脑的免密码解锁。

相比起普通版，小米手环 3 NFC 版最大的区别无疑是增加了 NFC 模块，可以以此来实现刷交通卡、模拟门禁卡等功能。

小米手环 3 NFC 版的使用方法很简单，使用小米运动 app 连接手环后，在「我的设备」中找到手环，选择交通卡即可添加。

使用小米手环 3 NFC 版刷卡也非常容易，把手环靠近公交或地铁的刷卡机，听到声音就完成了刷卡，整个过程和使用实体交通卡并无区别。

图片来自小米官方

相比使用二维码乘车，小米手环 3 NFC 版刷卡省去了解锁手机找到二维码的步骤，而且由于手环一直戴在手上，因此在便利性上相比支持 NFC 刷卡的手机也有一定优势。

小米手环 3 NFC 版首批适配了全国 164 个城市，包括京津冀互联互通卡（支持 138 个城市）、广东省岭南通·羊城通、深圳通、合肥通、江苏交通一卡通·苏州、武汉通、吉林通、广西交通一卡通，其它城市交通卡即将陆续支持，具体的城市支持列表大家可以点击链接查看。

由于原理和实体交通卡无异，所以使用小米手环 3 NFC 版刷卡同样可以享受实体卡的优惠折扣。需要提醒大家的是，和大部分支持 NFC 刷交通卡的手机类似，小米手环 3 NFC 版的卡片信息是无法删除的，每个手环最多可以开 4 张交通卡，其中交通联合卡只支持开一张。

除了刷交通卡，小米手环 3 NFC 版还可以模拟门禁卡。

不过这个功能目前还处在测试阶段，需要在小米运动 app 里找到「实验室功能」，打开「门卡模拟」，之后在小米手环 3 NFC 版里才能看到「门卡模拟」的选项。

此外，目前「门卡模拟」只能支持未经加密且频率为 13.56MHz 的门卡，使用范围相对有限。

最后，如果你所在的城市在支持范围内，同时你经常刷交通卡上下班并且正在使用的手机不支持 NFC 刷交通卡功能，功能全面、只要 199 元的小米手环 3 NFC 版无疑非常值得考虑。
