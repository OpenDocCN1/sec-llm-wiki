李飞飞卸任 Google 回归斯坦福，仍将致力连结 AI 学界与业界

担任 Google Cloud 的人工智能团队「掌门人」近两年之后，李飞飞终于决定回归校园，卸下现任 Google 云 AI/ML 首席科学家职位，重返校园任教。


「终究要回归的」李飞飞

早在今年 6 月，外媒就传出了李飞飞或将离开 Google 重返斯坦福任教的消息。当时正值 Google 被爆军事合同之际，Google 超过 4000 名员工在请愿书上签字要求停止与军方的合作，而李飞飞由于几封事关军事合同的秘密邮件泄露也深陷其中而备受质疑，外媒曾猜测李飞飞的离开是受到了军事合同的影响。

而在 6 月底谷歌与清华大学的研讨会上，李飞飞教授在接受极客公园记者采访时表示，学术休假在美国是一件非常正常的事情，学者从大学休息到业界工作两年，然后再回归学校，这种双向的学术和业界的联系非常普遍。尽管学术假期会在今年夏天结束，但未来会在学术和产业间寻找平衡点，并不会如传言所说的彻底离开 Google。

Google 也及时回应说，「李飞飞是一位成就卓著的、受人尊敬的人工智能领导者。未来，她计划长期继续在 Google Cloud 工作，不过当她在斯坦福大学的休假结束后，她花在 Google 的时间将会减少。」


「佳飞猫」助攻 Google Cloud

22 个月前，李飞飞因休「学术假期」而加入 Google，担任 Google Cloud AI 负责人及首席科学家。和李飞飞一同加盟 Google 的还有前 Snapchat 研究主管李佳，「加飞猫」组合的加入，促成了 Google Cloud 项目的长远的发展，两位明星女科学家打造了一支超强队伍，极大地加速了人工智能和机器学习在 Google Cloud 客户及开发者中的接受度。

在 2017 年，李飞飞公布了 Google Cloud 基于神经网路技术新推出的一些 API 和引擎，比如 Video Intelligence API、Cloud Vision API、Cloud Natural Language API、Cloud Jobs API、Cloud ML Engine 等。

同年年底，李飞飞和李佳在北京成立谷歌 AI 中国中心（Google AI China Center），这也是 Google 在亚洲设立的第一个 AI 研究中心，方便在实力日渐强大的中国 AI 圈子里「招兵买马」，同时将 Google  AI 团队的相关工作搬来中国。

2018 年初，经过了漫长的准备和铺垫后，「佳飞猫」组合再一次祭出大招，宣布 Cloud AutoML 诞生。Cloud AutoML 完全符合了李飞飞的宗旨：让 AI 平民化，人人可用。用户无需精通机器学习，每个普通人都可以通过该产品自定义机器学习模型。

今年 7 月的 Google Next 大会上，Google 又发布了 Cloud AutoML 针对图像分类的 Cloud Vision API 正式发布公共测试版，同时上线了新功能：利用 Google 强大的预训练 API 模型从图片中提取信息，准确地检测和识别图片内的各个对象和面孔，并读取图片内的印刷文字。


全职新主帅Andrew Moore

李飞飞的继任者，则是来自卡内基梅隆大学的计算机科学院院长 Andrew Moore 教授。在 2018 年底，Andrew Moore 将会离开卡内基梅隆大学（CMU）计算机科学院院长的职位，全职加入谷歌云，担任 Google Cloud AI 负责人职位。

对于 Google 来说，Andrew Moore 也是一位老相识，此次也可称为某种意义上的「回归」。

2006 年 Moore 也曾在学术假期期间接受谷歌的聘任，建立了匹兹堡办公室，并担任副总裁，负责开发 Google 广告、商务等系统底层的基础技术。2014 年 8 月 Moore 重返 CMU，担任该大学计算机学院的院长一职。


CEO 发博回顾 Google Cloud

就在今日凌晨，Google Cloud CEO Diane Greene 在公司的官方博客上发布文章，证实了李飞飞即将卸下现任 Google 云 AI/ML 首席科学家职位，Andrew Moore 即将接棒的事实。

与此同时，Greene 还在博客中展示了过去在李飞飞带领下 Google Cloud 所取得的成就：「李飞飞加入 Google 后建立了高效的团队，共同创新并加速将 Google 的 AI 技术和机器学习融入于 Google Cloud 服务之中……同时期待李飞飞与 Andrew 团队以及 Google 的进一步合作，紧密的结合学界与业界……尽管李飞飞将重返校园任教，但是 Google 同样期待李飞飞以顾问的形式继续与 Google 合作。」

学界与业界是两种完全不同的环境，但并不矛盾对立。「终究要回归的」李飞飞重新回归校园，也不失为业界与学界合作的一种新模式：回归校园并不意味着从此远离业界、远离最新的技术趋势，反而能够在技术和教育层面上推动人工智能研究的发展，真正打通业界与学界之间的屏障，从而产学联合，真正推动技术的发展与革新。
