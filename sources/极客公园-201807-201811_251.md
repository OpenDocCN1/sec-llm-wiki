2003 年的诺基亚正是它如日中天的时候，那时它还没有到达顶峰，但 Symbian 的出现让我们见识到了一个冉冉升起的手机巨头。与此同时诺基亚发布了一款划时代的手机——N-Gage。作为昔日的王者，诺基亚各种经典机型肯定不会缺席极客博物馆系列，而第一篇诺基亚特辑我们就把目光聚焦在这款游戏手机鼻祖身上。

数码产品的更新迭代几乎都是以人类的需求作为前提不断地进化，手机也是如此。最初只是以随时随地能够打电话作为目的，之后开始追求便携性，再后来不断地为手机加入了各种功能，娱乐和生产力基本上可以将他们概括。即使在诺基亚 3310 上，我们也能看到经典的贪吃蛇，但诺基亚早早的就捕捉到了人类的需求，他们想要一款游戏性能比肩掌机的产品，N-Gage 就是这样一款产品。

  

## 打破传统审美的大胆设计

![](../Images/78d5df07fa377f87820e08e2107a414a.png)

诺基亚 N-Gage（左）与 N-Gage QD（右）

诺基亚 N-Gage 并没有在中国大陆地区发售，不过它的兄弟机型——N-Gage QD 对于大家来说肯定不陌生，他们的造型设计非常相像，只不过在一些细节风格上有着不同的处理。诺基亚 N-Gage 整体更加硬朗，直线条运用的较多；诺基亚 N-Gage QD 则基本以弧线为主，看起来相对「秀气」一些。

![](../Images/d28be516da7802b4ad29b0a6f935ba3e.png)

诺基亚 N-Gage 的外形让人们对手机有了全新的认识，当时的人们很难想象按键横向放置中间有一个屏幕的，是我们常见的手机。显然这一点是针对 N-Gage 在游戏上的特性有意而为之，两代产品都保持了这样的设计语言，也因为这种不走寻常路的风格，让当时的年轻人天生似乎就会对它们产生了好感。

![](../Images/0872e3acf661503729d9e79a86ae3b6a.png)

抛开游戏不谈，诺基亚 N-Gage 可以说在多媒体部分也有着强势的表现，诺基亚甚至在系统菜单里单独放置了一个「Media」文件夹，我们在其中能够看到 RealOne 视频播放软件、图片浏览器、上网服务、截屏、音乐、FM 收音机、录音机以及编曲功能。

![](../Images/425d459571b3a8488f0c9319d7697b98.png)

  

## 媲美 MP3 的多媒体表现

不过熟悉他们的人会明白，这两款机型有着非常明显的功能差距，N-Gage QD 更多是妥协下的产物，说得直白一些就是「阉割版」。N-Gage QD 取消了硬解 MP3、FM 收音机、录音等功能，单说无法支持 MP3 的立体声播放就成为了一件让人遗憾的事情，尽管可以通过安装软件来实现 MP3 格式的支持，但因为是软解所以依然是单声道。

![](../Images/753bca6adca00c2d0ba3a547724e5d24.png)

诺基亚 N-Gage 除了 Symbian S60 机型上常见的菜单、编辑和删除按键以外，还增加了 MP3 播放器和 FM 收音机的快捷按键，并且数字键盘区域里，「5」和「7」两个按键有着更明显的颜色和突起。而 N-Gage QD 因为取消了收音机和 MP3 的支持，所以没有了这两个按键，方向键也取消了「确认」功能，单独增加了一个确定键。

![](../Images/a547fadf66d7d517118ff8056865af72.png)

除了上面提到的几点不同以外，诺基亚 N-Gage 的高规格还体现在其它方面，比如像是机身左侧的 mini USB 接口（DKE-2 数据线），那个时代的诺基亚机型就已经可以通过通用接口将手机作为移动存储的形式与 PC 连接，N-Gage QD 取消了这个功能，自然也没有了数据接口。

![](../Images/8f4578dda2bab82fc778ec39117b6bff.png)

诺基亚 N-Gage 包装内附赠了 HDD-2 立体声耳机（2.5mm 接口）、2.5mm 转 3.5mm 转接线以及 ADE-2 录音线，在当时 N-Gage 拥有非常出色的音质体验，几乎可以媲美 MP3 的表现；而 N-Gage QD 中则只有一个 HS7-N 单声道耳机，因为并不支持录音，也没有立体声自然没必要有转接口。

  

## 特立独行的打电话姿势

![](../Images/e653e3a9b22a5c5ca7fec4aeffe5dbd1.png)

诺基亚 N-Gage 还有一点与 N-Gage QD 有着鲜明的差距，那就是打电话的方式，诺基亚 N-Gage 将听筒设置在了机身顶部右侧，而麦克风在左侧数据接口旁，所以打电话的时候就会出现这样一幅情景。相比之下，诺基亚 N-Gage QD 显然就「收敛」了不少，麦克风依然在左侧的位置，但听筒移动到了机身正面，所以接电话的画面就显得「正常」了不少。

![](../Images/81a6fb8e22c30c5e2d8117cebda9a465.png)

其实 N-Gage QD 最令人头疼的地方就是他的胶圈，和一般手机的中框不同，N-Gage QD 四周有一圈橡胶包裹，好处是多了挂绳孔，各个接口也不会像 N-Gage 那样直接裸露在外。但可能是因为供应商的材质原因，这个胶圈可能会在较短的时间内就出现折断的情况，因此当时也出现了各种第三方胶圈配件。

![](../Images/01235120bf80aed12e937c8802e70305.png)

从综合体验来说，诺基亚 N-Gage 几乎是全方位碾压 N-Gage QD，但对于国内用户来说前者有一个最大的问题——不支持中文。因为 N-Gage 并没有在国内发售，所以系统设置中并没有中文的选项，字库也不支持显示中文，中文输入法更是不用想。

![](../Images/974ef29518d681d6856cc1b80cc70a4a.png)

通过外挂字库/输入法实现中文显示/输入，外挂菜单直接显示中文内容

但国内似乎永远不缺技术大神，为了能够正常使用，外挂字库、外挂输入法甚至是外挂菜单的出现，让 N-Gage 在日常使用中不会受到不支持中文的影响。当然，作为第三方的解决方案，小 bug 或者偶尔崩溃也是常有的事儿，但假如白屏了那就比较尴尬了。因为那个时代的手机如果想要刷机需要专业的刷机盒子，使用普通的数据线，拷贝个 ROM 是行不通的，所以当时 N-Gage 也带火刷机业务。

  

## 碾压级别的游戏体验

诺基亚 N-Gage 和 QD 最为核心的还是游戏方面的支持，在前面之所以说它才是游戏手机鼻祖，并非只是单单的因为造型「唬人」。诺基亚 N-Gage 拥有一整套游戏生态作为支持，诺基亚作为当时手机行业的巨头，Gameloft、育碧、EA 纷纷为诺基亚 N-Gage 推出了独占游戏。

![](../Images/4da9498e6224346afe8a32b00dda9e7a.png)

当时诺基亚 N-Gage 游戏采用了独立「卡带」形式发售，几乎和现如今的掌机或者是次时代家用主机的玩法是一样。当然，这个「卡带」并不是诺基亚定制的规格，而是使用了当时比较流行的 MMC（Multi-Media Card）卡，算是 SD 卡的前身，之所以说独占是因为其他品牌的机型几乎都不支持这一个安装格式，这也算是 Symbian S60 在当时的优势之一吧。

![](../Images/e0019b5901aa00debabb36ecd556abd9.png)

不过因为国内特殊的环境，我们很少能见到支持正版游戏单独购买游戏卡的用户，大部分 N-Gage 用户都是在当时各大塞班论坛上分享破解版的游戏软件，这也让非 N-Gage 的诺基亚 S60 机型也能够玩上独占游戏，不过对于机型 RAM 有着较高的要求。

有了丰富的游戏作支持是一方面，N-Gage 游戏还有杀手锏就是超强的画面表现以及良好的游戏性。就像是刚才说的那样，除了一些大公司出品的 java 游戏，其品质大多数都非常粗糙，画面颗粒感严重而且响应速度也不够快，《火焰之纹章》系列算是 java 游戏中少有的精品。

![](../Images/c7cf99259de085bae2dd80255dbfbfb0.png)

这是在一块 2.4 英寸分辨率仅为 176×208 像素的屏幕上展现的效果

但诺基亚 N-Gage 拥有更强的性能，在画质上有着更加出色的表现，大多数的 N-Gage 游戏都是以 3D 形式展现的，而且不会像 java 那样受到容量限制，在好的 IP 支持下，游戏公司有更多的发挥空间，所以我们看到了诸如《使命召唤》、《古墓丽影》、《地域镇魂歌》等经典游戏。也许当你现在看到这些游戏画面可能马上就想扔掉，但你需要了解的是这是一块 2.4 英寸的 STN 屏幕，分辨率仅为 176×208 像素，PPI 什么的就更不要谈，在这样的屏幕和机能下能展现出这样的画面效果，这在当时绝对是手机游戏的巅峰之作。

![](../Images/cabdb2be09ae08e39075fe9f64167fb4.png)网友 gejiyishr1提供的自己收藏的 N-Gage 游戏卡带照片

除了独占游戏以外，Symbian S60 平台还拥有者丰富的扩展性，所以 N-Gage 还可以通过各类模拟器玩到 FC、SFC、MD 甚至是 GBC 的超多游戏。

有可能是因为诺基亚内部的决策也有可能受到破解软件的影响，还有可能是因为 Symbian S60 家族的不断壮大，硬件性能不断增强。N-Gage 不再作为一个硬件系列延续，转而变成了平台。后期我们看到的较为经典的续作应该就是 N81 了，虽然没有延续 N-Gage 的名称，但拥有了 N-Gage 2.0 的平台，也针对横向游戏进行了特殊按键设计。

![](../Images/f73a4bbe24fc23ba3f79ae3a339c22e3.png)

在 Android、iOS 崛起的时代，性能早已不再是手机游戏的桎梏，不过操作系统的大统一也很难看到独占游戏的身影，作为后来者索尼 Xperia Play 有些生不逢时。可能再也没有像是 N-Gage 这样的机型，能把游戏手机这四个字诠释的如此淋漓尽致。
