# 一家老牌 CG 公司的自我修养：能为 GOT 赢下艾美奖，也能给奔驰车雕琢宣传片

> **身在这个行业里，你必须时刻跟上技术的步伐。**

  

Mackevision 最为大众所熟知的一次，是它为美剧《权力的游戏》做的视觉特效。

在视频网站上可以找到特效分解的视频，雄伟的建筑拔地而起，浩荡的无垢军团攻城略地，还有风景仿佛天堂般的高庭以及异域神秘的布拉佛斯，从第四季开始接手《权游》特效制作的 Mackevision 以假乱真地为观众呈现了《冰与火之歌》里的奇幻世界。

因为《权力的游戏》，Mackevision 拿下了电视行业的「奥斯卡」艾美奖，同时也将电视剧的视觉特效水平拔高到了一个全新的层次。「我们经常被问到，『能不能帮我们按照《权游》标准来做？』它几乎成了一个标准。」Mackevision 总部的团队在德国远程完成了全部的特效工作，剧集制作的时间非常紧张，有时新一季已经开播时，他们仍在完善部分内容的制作。

![](../Images/6a0c8c62bac13d588ccea2df29a8109a.png)

很多人不知道的是，拿下艾美奖最佳视觉效果奖的 Mackevision 并非一家专业的影视特效公司，这家发迹于德国汽车城斯图加特市的全球顶级 CG 公司在《权游》一战成名之后，拒绝了无数影视行业的邀请，对他们而言，《权游》只是一次试手，汽车 CG 才是他们真正专注的领域。

  

## 诞生在汽车城

1994 年，Mackevision 在斯图加特临近的小城辛德尔芬根创办，开始时公司的规模很小，团队只有 12 个人，主要的工作是视频的后期制作。

斯图加特是德国著名的汽车城，几个有名的汽车厂商，保时捷、奔驰和博世公司的总部都在这里，汽车是这座城市的标签，居住在这座工业城市里的人们对汽车有种天生的热爱。

很快，对品牌宣传有需求的戴姆勒-奔驰通过广告公司找到了当时名不见经传的 Mackevision。沟通之后，Mackevision 开始为奔驰制作汽车的宣传照和宣传视频。「但是奔驰汽车的型号太多了，每个都做一张照片很麻烦，」Mackevision 中国区总经理费蓓娅（Beatrix Frisch）说道，迫于产量限制，Mackevision 将眼光投向了当时还算是新兴技术的 CG。

CG（计算机绘图）是九十年代迅速在影视行业里流行开来的一项技术，直接使用电脑作图，艺术家可以自己选择、搭配不同配置的汽车外观，相比 Mackevision 原先拍片、修片的工作方式效率有成倍的提升，随着技术的逐渐进步，CG 的效果也越来越好。在与奔驰公司协商之后，Mackevision 决定使用 CG 技术为奔驰制作宣传片。

![](../Images/c5aff2498b8ec53037955508c1c021e3.png)

「直到现在，奔驰依然是我们全球最大的客户，」费蓓娅说道，其次就是总部同样在斯图加特的保时捷。在当时的法兰克福汽车展上，Mackevision 第一次接触到了保时捷，很快成为这家高端汽车品牌「御用」的视觉特效公司。奔驰和保时捷，这两家最负盛名的德国汽车品牌，在 Mackevision 后期拓展全球业务的时候起到了至关重要的作用。  

  

## 走出德国

2009 年，奔驰美国公司在市场推广时发现，美国消费者对特效图片和视频的需求与德国消费者有不同的需求，但当地又没有能够满足奔驰自己需求的特效制作公司，于是奔驰再次找到 Mackevision，希望后者帮他们制作专为美国市场打造的特效内容。

在制作宣传物料时，大型汽车企业往往偏好于那些与他们有着多次合作经验的公司，一来如 Mackevision 这样的企业在过往的合作经历中证明了自己的可靠性，技术得到了车厂的认可；二来长期合作中特效公司对汽车厂商的需求也更加了解，在设计、内容制作的行业，这是商务中非常重要的一环。

「但也必须要说，大公司的车太多了，」费蓓娅笑着说，「一家公司做不完，所以这些大公司一般会有两到三家视效公司备选。」

沟通之后，奔驰希望 Mackevision 直接在美国当地建立一个分公司，便于了解当地消费者需求的同时，也能够拓展一个新的市场。于是，2009 年 Mackevision 在美国底特律建立了第一个国外的分支公司，从此开始在全球范围内的扩张。

在底特律，Mackevision 接触到越来越多的美国及其他国家的汽车企业，如当时还没被菲亚特收购的美国三大车企之一克莱斯勒，在接触之后也很快成为了 Mackevision 的大客户之一。

美国之后，Mackevision 将全球业务拓展到越来越多的国家，目前在意大利、日本、韩国、新加坡，和中国等国家共有 13 家分公司，拥有近六百人的团队。

2013 年，Mackevision 在上海注册公司，当时在全球范围内而言，中国并不是一个特别大的市场，上海分公司主要从事的也是销售和咨询的工作。但很快，中国的车厂开始意识到高端 CG 对汽车品牌的重要性，越来越多的国产和合资汽车品牌开始寻找汽车 CG 公司制作相关内容。

对当时没有内容团队的 Mackevision 上海分公司而言，最开始的市场竞争遇到了很多的阻力，销售和咨询团队对中国市场不够理解更是为 Mackevision 在中国的业务雪上加霜。

到 2014 年，又一次，戴姆勒-奔驰公司向 Mackevision 发出邀请，建议后者在奔驰中国总部所在的北京建立一支内容生产团队，更好地适应这里的市场。基于之前的成功经验，Mackevision 果断在北京注册分公司，建立起了一支约 40 人左右的团队。也是这时，有着中国求学经历、说着一口流利中文的费蓓娅加入 Mackevision，主导了北京分公司的建立。

## 内容以上

北京分公司选择落户在了与 798 隔街相望的电通创意广场，这里距离 Mackevision 全球最大客户奔驰公司的戴姆勒大厦只有不到两公里，和奥迪中国也仅仅只隔着一条酒仙桥北路。费蓓娅表示当初选址时，他们希望能够距离客户更近一点。电通创意广场旧工厂改造的风格让他们想起德国总部所在的斯图加特，园区内有别于 CBD 的闲逸气氛也给了电脑特效艺术家们更多的灵感和发挥空间。

三年多的时间，费蓓娅带领北京团队拿下了上汽名爵和荣威等国产汽车厂商的订单，甚至车和家、威马、爱驰这样的新能源汽车品牌建立了合作关系，「他们与传统车厂的要求一样，没什么区别」。

![](../Images/c69353ea229f0d3f9927878c6c9766fa.png)

熟悉中国汽车市场的费蓓娅看到，几年下来，市场已经发生了非常大的改变，越来越多的国产汽车品牌意识到高端汽车 CG 的重要性，Mackevision 在国际上积累的影响力也渐渐转化成了更多的客户和订单。  

汽车以外，也有一些其他行业的客户寻求与 Mackevision 的合作，与服装、珠宝甚至手机厂商都有各种类型的合作。对 Mackevision 而言，费蓓娅表示他们也在有意拓展业务线，在汽车以外的领域寻找新的市场，但对一家起步于钟情汽车工业的德国公司而言，迈出这一步并不容易。

在今年 1 月，全球最大的管理咨询 IT 公司之一埃森哲宣布其完成了对 Mackevision 的收购，对这家创办二十多年的 CG 公司而言，这次收购意味着一次全新的开始。

早在两年前，Mackevision 就提出要从内容提供商转型为端到端的解决方案提供商，而这次的收购，正是 Mackevision 主动寻求的结果。

在图像技术领域登顶的 Mackevision 看到了作为内容提供商的局限，它希望能够把业务拓展到一个更加广泛的领域。「我们不仅仅是在做图像，我们在将一切变成数字的形态，」费蓓娅说道，「通过埃森哲的资源和 IT 技术，我们能够走到一个更高的层面，图片、视频内容只是第一层，未来我们会提供一整套数字可视化的服务。」

技术是 Mackevision 能够在 CG 行业里取得今天成就的核心之一。北京制作部主管 Andi Wang 在加入 Mackevision 之前曾供职于国内的汽车 CG 公司，跳槽到 Mackevision 之后，他被这家公司的技术实力所震撼。「差距还是非常大的，」Andi Wang 的话里多少有些遗憾。

  

## 技术主导的变局

Mackevison 在德国总部有一支专门的研发团队，他们会开发自己的图像制作软件，同时关注图像领域新的技术趋势。放在近几年说，Real-time 就是一个好例子。

大约四五年前，Mackevision 就看上了 Real-time 会给汽车 CG 行业带来的改变，当时著名游戏引擎厂商、《堡垒之夜》的开发公司 Epic Games 刚刚发布了第四代虚幻引擎（Unreal Engine 4），Mackevision 看到了这款全新游戏引擎会给图像领域带来的变化。

离线渲染（Offline rendering）和实时渲染（Real-time rendering）是计算机制图在渲染时的两种方式，前者不计时间成本，追求卓越的质量，后者则通常应用于游戏，更追求渲染速度而非质量，以能够达到流畅观看为标准。

传统汽车 CG 行业使用的是离线渲染技术，往往一段简短的视频都需要长达数个小时的时间进行渲染，最终的效果也非常令人满意。

但在第四代虚幻引擎（UE4）发布之后，这个情况发生了改变。Mackevision 的团队注意到，Epic Games 在 2014 年发布的实时渲染引擎 UE4 能够渲染出质量满足汽车 CG 需求的视频，这意味着汽车 CG 可以从一味的离线渲染跨越到实时渲染，效率会有天翻地覆的改变。

他们立刻投入对 UE4 的研究中，同时将自己的研发经验反馈给 Epic Games，反过来助推了 UE4 在非游戏行业的应用。

「Real-time 只是一个开始，它起源于游戏引擎，下一步，我们拿来与自己的技术结合，制作精致的汽车 CG，但这只是起步阶段，我们刚刚打开了 Real-time 的第一扇门。」费蓓娅说道，Mackevision 刚刚与博世公司达成了合作，两家合作开发「虚拟验证平台」，为博世公司的自动驾驶技术制作虚拟训练环境，这是基于 Real-time 的应用。

与多年前汽车 CG 刚刚进入中国市场一样，去年刚刚开始生产 Real-time 实时交互产品的 Mackevision 北京分公司在国内初期的推广也比较困难。为了说服客户，他们把实时渲染和离线渲染的两张图片拿给客户对比，发现客户们几乎看不出来两者之间的优劣，这种几乎同等品质、效率成倍提升的「新产品」很快被市场所接受。

在应对市场的同时，Mackevision 北京团队也在不断追求制作更高水平的 Real-time 内容。在今年四月召开的虚幻引擎技术开放日上，Epic Games 为 Mackevision 北京团队颁发了「最佳行业应用奖」，这是整场大会上唯一一个非游戏类奖项。

![](../Images/af2cf96e165d77912f30028639cfc263.png)

「我们之前也没有做过类似的东西，这次拿奖之后大家对操作的流程和规范有了整体的了解，」Real-time 事业部的 Patrick 说道，他表示在这之前行业里没有类似的产品，这次 Mackevision 的获奖对行业来说具有开拓性，对打开市场有很大的帮助。  

对 Mackevision 北京分公司的团队而言，Real-time 几乎是完全陌生的，不论是部门主管、普通的技术人员还是对技术不甚了解的艺术家们，他们都必须从头学起。

在彼此帮助的学习中，以追求更美的图像为标准的团队摸索出了自己的创作方式，但这其中却也有着一些不为人知的苦涩。

  

## 「You have to」

Patrick 原先在一家展览展示的公司做 CG 制作，一次偶然的机会他接触到了 UE4，这种高画质的实时渲染给他带来了极大的震撼，「当时觉得以前那种单纯设计然后渲染的方式可能会过时」。思前想后，他决定学习 Real-time 这项新的技术。

Patrick 辞掉了之前的工作，在家里待业学习 Real-time 学了半年多。面对记者有点腼腆的 Patrick 回忆起加入 Mackevision 之前的那半年多的日子，苦笑着说，「成本还是蛮高的。」

「很有可能你今天做的东西，明天就已经过时了，每天都面临这种恐慌。技术一旦有进步，你就会发现，拿到新技术的人做出来的东西，比你好，比你快，质量还高得没边。」

之前的经历一直警醒着 Patrick 要时刻留意着行业里的新趋势，入职测试是他做的第一个 Real-time 作品，对比现在的水平，连部门主管都惊讶于他进步的速度。

「他现在已经有很多地方做得比我好了。」Sergiu 说道，他是 Real-time 事业部的负责人，去年部门成立时刚刚加入这家公司，「在这个行业里，如果你不时刻保持着学习的状态，随时都会出现一个年轻人顶替掉你。」

「如果以后又出现了更好的技术，你也要立刻去接触那个陌生的东西吗？」

「必须这样。因为客户会改变他们的需求，公司会调整自己的业务，现在不比二十年前，那种你刚入行就知道自己职业生涯要做哪些事的日子，一去不复返了。很多人不理解这件事，尤其一些年纪比较大的人，他们总是在问，公司为什么总在变？你为什么总换工作？为什么那么努力？因为在这个行业里，你必须保持自己的领先优势，你必须时刻学习，只要你还想保持住自己的优势，你就必须弄明白每一个新软件，每一项新技术」。
