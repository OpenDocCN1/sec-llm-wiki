# 「家庭伴侣」似的人形机器人离我们还有多远？我们和优必选周剑聊了聊

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652856860&idx=1&sn=baf74d2844bc03a85b5063be557b7e06&chksm=7e6a1faa491d96bcdf00b213ee3da8f1e6fd49eb257d0a2f4c2129daa50069f5a05bbeb50ec0&scene=126&sessionid=1681310864#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652856860&idx=1&sn=baf74d2844bc03a85b5063be557b7e06&chksm=7e6a1faa491d96bcdf00b213ee3da8f1e6fd49eb257d0a2f4c2129daa50069f5a05bbeb50ec0&scene=126&sessionid=1681310864#rd)

> **优必选不再只是代表春晚的跳舞机器人，它早已在人工智能机器人教育、商业新零售、文化娱乐、交通、政务、安防等多个领域展开商业化布局，并取得不错的成绩。**

  

今年五月，国内人工智能与人形机器人企业优必选宣布完成由腾讯领投的 8.2 亿美元 C 轮融资。融资后，优必选的估值达 50 亿美金，翻了五倍，成为了全球估值最高的 AI 创企。

但优必选创始人兼 CEO 周剑并不满足于此，他打趣道：「现在的投资人还没真正看懂优必选，有的投资人即使给我们 100 亿、200 亿美金的估值，我觉得他还是低估了这个行业的潜力，要是真正看懂就会以 200 亿、500 亿美金的估值抢着投资我们这样的公司。」

![](../Images/21a5209221ba5a851d9a7caa145826fc.png)

其实周剑这句玩笑话怨的并不是投资人，相反和 C 轮融资一样，优必选的前几轮融资表现也一直亮眼。从 2013 年获得正轩投资、力合华睿投资的 2000 万元天使轮以来，短短五年内，优必选共完成了 5 轮融资，从估值一亿元迈向估值五十亿美元，一路狂飙猛进。

这句话是源于「梦想」和「现实」之间的断层。周剑创立优必选一直有一个从未改变过的目标——让人形机器人进入家庭，成为家庭的伴侣。但现实却是，很多人提到优必选会问一句，「是那个做在春晚跳舞的机器人的公司吗？」得到肯定答案后，要么止于一句「哦，还挺有意思的」，要么会反问「他们还做什么？」

大部分人都不知道优必选已经有 To B 和 To C 两大业务线，更别提二者涵盖哪些产品。实际上，To C 是优必选目前的主营业务，在 To C 业务线上，优必选拥有三大系列产品：消费级人形机器人 Alpha 系列、STEM 教育智能编程机器人 Jimu Robot、IP 机器人。To B 业务线目前除了智能云平台商用服务机器人 Cruzr（克鲁泽），还推出了智能巡检机器人 ATRIS。

![](../Images/575b8f8459ce7bd35dca7d30f27d89cf.png)

智能巡检机器人 ATRIS 现场展示下坡

优必选在今年的世界机器人大会还展示了一款便携式智能机器人悟空，是由优必选和腾讯叮当合作推出的一款有生命感的机器人，定位于用户的第一个智能机器人，在交互能力上添加了更多样的拟人化的互动方式。

![](../Images/561ebeef7ae8a05999055b2353c8eb50.png)优必选悟空机器人首次正式亮相

此外，优必选还在研发双足机器人 Walker，在今年的 CES 上已经展出，全人形的双足机器人计划在明年的 CES 上正式亮相。

即是说，优必选目前的融资情况受制于市场开放度。双足机器人这个新事物还处于创新扩散的早期，真正走入家庭还需要些时日。周剑也深知这一点，但他的归因则是从供给端上找原因，「最大的问题是商业化的难度，商业化要将成本降下来，同时还要保持稳定。虽然做一个 Demo 并不困难，但是花几百万美金做一个 Demo 的意义在哪里？如果只是为了做 Demo，这不会是优必选的方向，我们的目标是让机器人进入家庭。」

机器人走进千家万户是一个漫长的过程，但通过在商业新零售、教育领域的一步步布局，优必选正在让机器人逐渐渗透人们的生活。极客公园和周剑聊了聊这些在不同领域的布局、在实现机器人商业化过程中的种种困难，以及具体落地面临的标准等。（以下对话经极客公园编辑整理）

  

## 布局

![](../Images/aad7b10fb791862bbc9c1034f9b501b5.png)苹果 CEO 蒂姆·库克在苹果门店体验优必选 Jimu 机器人

**Q：怎么看待目前的机器人编程教育市场？**

A：编程教育市场很大，而且是刚需，我觉得编程教育可能是目前 To C 机器人市场里唯一满足刚需场景的一个需求，而且本身市场也挺大。但这个市场的发展基于国人或者家长对编程教育的理解及认可度。目前国家已经意识到这个问题，并把人工智能、机器人还有编程教育列为未来每个人必须掌握的技能。国家在学校推广编程教育，包括让这些课程成为必修课，这些举措迟早会从校内影响到校外，从而形成一个良性的互动。目前这个市场的进一步发展可能需要时间，但是我觉得趋势和方向已经非常清晰和明确了。

**Q：现在优必选在教育方面如何布局？**

A:我们在校内、校外都有布局和合作，同时我们也会成立优必选自己的校外培训机构。我们希望做的不仅是新一代的人工智能和机器人教育，还希望未来能成为中国最大的一个平台，同时我们在校内跟各个学校和地方政府的教育局在合作。优必选在教育领域的布局很明确，包含 To C 和 To B 两方面的教育。我们今年在教育市场已经获得非常大的订单。

**Q：新零售方面又是如何布局？**

A：主要还是以 Cruzr（克鲁泽）机器人为主的完整的商业新零售解决方案。在合作过程中，我们会提前了解市场、对接客户，然后根据客户的需求定制不同的解决方案最后完成交付。因为在新零售的场景里，Cruzr（克鲁泽）需要具备不同的功能，在购物中心的需求是一种，在机场的要求又会不一样，银行的场景也是独特的。

**Q：Jimu Robot、Alpha、Cruzr（克鲁泽）三类机器人对公司而言有无轻重之分？有无不同营销方式？**

A：这三款产品对我们来说没有轻重之分，每一个市场都很重，都很广阔。但我们做任何一款产品都有一个前提，除了让公司有更多的现金流，还要有足够的技术积累，同时也是符合公司未来发展战略的，这样才会选择做一款产品。

营销方式上有一些区别，Alpha 系列和 Jimu Robot 我们会更多的做一些共创，让我们的用户参与到这个产品开发里。我们最新的悟空机器人目前正在开展这样的工作，我们希望更多的粉丝能参与共同打造这款机器人。再比如人工智能机器人教育解决方案和 Cruzr（克鲁泽）机器人这类产品，我们推广销售的渠道会偏向 To B，包括与政府合作等。

**Q：未来想怎样进一步打造护城河？**

A：优必选接下来很重要的一个优势是生态优势。比如苹果的生态，其实苹果手机最出色的并不是屏幕或设计，而是硬件、软件加上服务的生态，苹果的生态吸引了很多的第三方来开发不同应用，共同打造生态。但前提是你的手机、硬件产品要有一定的出货量，没有几百万台、上千万台的销售量，生态是难以形成的。因为没有足够多的用户，就没有那么多需求吸引第三方参与。

我们如何打造生态呢？具体而言，首先我们要自己抛砖引玉的做出一些好的应用。比如接下来推出的悟空机器人，我们首先在悟空上打造一些好的功能和应用点，等具备较高的销售量之后，客户对这个产品的需求就会越来越多了，这时候也有第三方开发者愿意进来。

我可以透露一个数字，目前悟空虽然还没上市但订单就已经达到近 5 亿。对我们来讲这已经初具产业规模优势了，生态优势的建立也因此有了机会。

  

## **野心**

![](../Images/7b93540c47fb9e502040f0e902a71eda.png)2150 台 Cruzr（克鲁泽）机器人在居然之家上岗工作，人类历史上人工智能机器人第一次大规模的进入线下新零售

**Q：怎么看现在的市场？**

A：我觉得这个市场足够大，以我们目前的估值来讲，这只是万里长征的第一步。未来机器人产业应该像苹果一样，诞生一个万亿美金的公司。而现在我们公司才几十亿美金的估值。从这个角度来讲，如果投资者真的认为这个行业很大，看中人形机器人未来进入家庭的潜力的话，公司的融资情况会比现在更乐观。但我认为现在投资者还没有看明白优必选，他即使给我们 100 亿、200 亿美金的估值，我觉得他还是低估了这个行业和优必选的潜力。

**Q：目前有没有更具体的短期目标？**

A：我们最近的一个比较重要的目标是在明年的 CES 展上，加上双臂的 Walker 机器人正式亮相。虽然还不如 ASIMO，但可以看到的是我们机器人的每一个部件的成本都在大幅度下降，Walker 的整体成本也将进一步降低。这样一来，这里不是很完整，加了一句价格：如果运动控制算法能力以及伺服舵机的稳定性能够进一步提高，就意味着这款产品具备了商业化的可能性，初期产品售价预计在 20 万左右。我觉得真正的大型人形机器人，这样的价格是 To B 行业可以接受的。

**Q：怎么判断机器人是真落地了？**

A：真落地的标准，就是这个产品为客户所用，而且对合作伙伴和行业有意义。另外一点，客户为了这个产品或者方案付出一定的代价，也能实现高留存率，而不是不用花钱购买机器人。除此以外，你的产品除了让客户觉得有用之外，还能为客户带来一些增值，在满足他的基本需求之外，还会让客户觉得用这个机器人与不用之间有很大的区别，而不只是单纯地替代人类完成了基本工作。

**Q：如何实现真落地需要？**

A：最重要的还是技术条件，如果技术层面不解决这个问题，真落地可能更多在一些噱头或者其它方面落地。

**Q：优必选的终极目标是什么？**

A：我们的目标就是让人形机器人走进千家万户，成为家庭成员。双足机器人对我来讲意味着未来的人，是身边的伴侣，是未来家庭不可缺少的一员，这可能才是最大意义。对于这一点我很坚定，但我还是在不断地反思公司的战略会不会有一些需要细微调整的地方，这些调整肯定一直存在。但直到今天我依然认为，公司未来这一两年的方向没有问题。

  

## **挑战   
**

![](../Images/c655d9ac4267f3a2e57a224176579fb9.png)

双足机器人 Walker 展示踢足球

**Q：机器人由身体和大脑两部分组成，在您看来哪部分更重要？**

A：坦白说我觉得这两个部分难度都非常高。但如果从 AI 对机器人未来服务场景的体现来看，我认为目前优必选在机器人大脑的部分突破更多。

机器人的身体虽然难度非常大，商业化的难度也非常大，但我觉得总体来讲，至少优必选今天在这个领域有比较清晰的方向，我们需要的只是时间。

与此同时，我也反复强调一点，只有搭建好机器人的身体基础才有机会在它上面赋予运动控制算法。如果这个身体都没有搭好，或者用几百万美金搭建身体，即使在上面做再好的运动算法，比如跳舞、翻跟头，其实是不可持续的，我希望在相对较低的成本之上能做到这些动作。

**Q：未来如何让机器人的大脑和身体实现更好的配合？**

A：其实这是一个非常高的要求，这就是我们所说的「手眼协调」。首先是需要机器人的眼睛看到物体，然后决定做什么，最后手才能做动作。手眼协调包括非常多的技术难点，比如物体识别、机器视觉、舵机灵敏性和耦合等，理论上讲，就连计算在本地还是云端都对机器人的反应带来了影响。

如果手眼协调做不好，服务机器人永远是一个梦。我们接下来的计划会让机器人在手眼协调上实现一些突破。如果这个部分突破了，就意味着可以加快大型人形机器人的商业化。这是个非常复杂的过程，对人类可能只需要几次学习的事情对机器来讲则意味着巨大的工作量。所以，我永远强调一点，今天的 AI 很早期。

**Q：真正能够进入家庭的机器人需要具备哪些品质？**

A：我觉得有几点。第一点是安全。因为家里无论是对老人还是小孩来说，安全是第一位的，如果机器人本身站不稳或者有跌倒的风险，或者运动能力不够强，那家庭就不应该是它服务的地方。

第二点是稳定性。在机器人的运动能力已经不会带来危险的情况下，最重要的一点就是交互时它能听懂你的话，在嘈杂的环境中能够理解对话的含义，这甚至比为你端茶倒水还重要。

第三点是基本能力。这台机器人可能陪我聊天、讲故事，也可能帮我做饭做菜、端茶倒水。无论从成本还是通用性来讲，终极的可能性是一台人形的机器人能够在不同的垂直环境里工作。

**Q：为什么传统的机器人还不够安全？**

A：工业机器人从 A 点到 B 点走过来的时候，如果你在中间阻拦它，很可能会受到伤害。所以工业机器人旁边有很多护栏，为了安全，人不能进入到工业机器人操作的范围。但是如果把这种技术运用到家庭中就会很危险，比如一个机器人正在开门，刚好人从旁边经过，它只会执行开门的动作，不会考虑旁边有没有人。而人机协作意味着，机器人手臂伸过来时，如果一旦碰到阻力，比如碰到一个人的手臂或者碰到一个人的躯干，机器人会主动把这个手抬回去，或者回避，而不是必须从 A 点走到 B 点。未来机器人服务很重要的一点，并不是从 A 点走到 B 点这件事必须要做成，而是安全。 ■
