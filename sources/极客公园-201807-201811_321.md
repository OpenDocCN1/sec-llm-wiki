# 英伟达的新「原力」：十年力作，全新架构 GPU 让「超逼真虚拟现实」更近一步

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652856769&idx=1&sn=c899b4d06227c18a0f739c2fae917d39&chksm=7e6a1c77491d9561683695de3356d94f642f76cfb07ce119cc975d4daa35c9930057f66474a9&scene=126&sessionid=1681310870#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652856769&idx=1&sn=c899b4d06227c18a0f739c2fae917d39&chksm=7e6a1c77491d9561683695de3356d94f642f76cfb07ce119cc975d4daa35c9930057f66474a9&scene=126&sessionid=1681310870#rd)

![](../Images/bd662a02fcf9938a5c0ceb1878239a8b.png)

> **英伟达刚刚发布的全新的第八代 GPU 架构「图灵」，它撬动的不止 2500 亿新市场，更将为我们打开一扇「超逼真虚拟世界」大门。**

  

「这才是原力啊！」NVIDIA 创始人兼 CEO 黄仁勋在台上说到，他手里拿着全新的 GPU，与以往不同的是这款 GPU 外壳足够的「闪」，甚至在台上老黄利用镜面反光和摄影师玩了起来，而在这次发布中更「闪」的还远不止这些。  

在温哥华举行的 SIGGRAPH 2018 专业计算机图形学顶级会议上，黄仁勋在他的主题演讲中公布了 NVIDIA 全新的第八代 GPU 架构图灵（Turing），以及发布了基于图灵架构的「全球首款光线追踪 GPU」- NVIDIA Quadro RTX 8000/6000/5000 系列。

这个全新的图灵（Turing）架构之于英伟达甚至是行业的意义都不容小觑。「Turing 架构是自 2006 年发明 CUDA GPU 以来英伟达的重大飞跃，」黄仁勋不断的强调图灵架构的意义，「Turing 架构是 NVIDIA 十多年来在计算机图形领域最为重要的创新。」

![](../Images/1621d07cccd5d1e81cb9fea1158c3918.png)

「NVIDIA 在一块 GPU 上实现「实时光线追踪」技术，此前我们都认为这可能要到五年之后才能实现。」分析公司 JPR 首席执行官 Jon Peddie 在会后说到。  

作为首先推出的这款基于图灵架构的「专业级」芯片，它首先撬动的是能够满足价值 2500 亿美元的虚拟 3D 特效产业需求。只是在专业技术层面上的亮相背后，这款全新架构更大的「能量」还在未完全展露，在游戏开发、消费级领域等更多细分领域应用之后，我们也许才能窥见英伟达在细分产品性能和生态上的战略布局。

![](../Images/8e4add4fefca16e9f115aeb9045b6ecd.png)

  

## 图灵（Turing）架构究竟意味着什么？

这项技术的第一个实现落地不是为了玩游戏，而是为了制作它们的人。

基于 Turing 架构的 GPU 为五千万电影渲染或为保时捷原型的新产品建模的专业人士打造，除了带来了实时的逼真场景渲染，也为其工作流程增添 AI 能力，使其能够与复杂的模型和场景进行流畅的互动，从而彻底变革以往的工作流程。

![](../Images/a7763b247810904d9afa708714e8c193.png)

「它首先为如今的电影制片厂和制作公司渲染作业量实现更高的吞吐量，从而节省大量时间和成本。」NVIDIA 专业可视化副总裁 Bob Pette 说。  

更重要的是，这也是英伟达对于自己能力边界的超越。作为例子，NVIDIA 展示了一个令人印象深刻的「Reflections」虚幻引擎演示。

![](../Images/2e616fd9b1009433ec8877486302ce6f.png)

黄仁勋也在现场以单个 Quadro RTX 8000 示范了《星际大战》游戏以 Reflections 为主题的光影渲染效果，而在今年 3 月左右，同样的展示是在配备 4 个 Volta GPU、价值 7 万美元的 DGX Station 上展示。可以说 Turing 架构达到了在更小的规模和成本之中，实现 Volta 级别的性能。

![](../Images/bab6923b1ab431aa2936ae2ea40edafb.png)

为此黄仁勋举起实物，再现了文章开头的一幕，「每秒处理高达 10 Giga Rays，有谁之前想过能够用 Giga 做单位？」。

Quadro RTX 专业级 GPU 专为要求最为苛刻的视觉计算工作负载而设计，以下则是他突破性的技术的详细例举，包括： 

● 全新 RT Core 可实现对象和环境的实时光线追踪，并做到物理上精确的阴影、反射和折射以及全局光照

● Turing Tensor Core 可加速深度神经网络训练和推理，这对于赋力 AI 增强型产品和服务至关重要。

● 全新 Turing Streaming Multiprocessor 架构拥有多达 4608 个 CUDA core，可提供高达 16 teraflops 的计算性能，并行运算每秒 16 万亿次整数运算，以加速模拟真实世界的物理模拟。

● 先进的可编程着色技术可提高复杂视效和图形密集型工作体验。

● 首次采用超快速的三星 16Gb GDDR6 内存，支持更复杂的设计、海量建筑数据集、8K 电影内容等。

● NVIDIA NVLink 可通过高速链路联通两个 GPU，将内存容量扩展至 96 GB，并可通过高达 100GB / s 的数据传输提供更高性能。

● 提供对 USB Type-C 和 VirtualLink 的硬件支持。VirtualLink 是一种新的开放式行业标准，旨在通过单一 USB-C 连接器满足下一代 VR 头显的功率、显示和带宽需求。

● 全新增强型技术可提高 VR 应用性能，这些技术包括可变速率着色（Variable Rate Shading）、多视角渲染（Multi-View Rendering）和 VRWorks Audio。

![](../Images/3a72027e8f27d9e4dc63cc845149664a.png)

Quadro RTX GPU 将于第四季度在 nvidia.com 上供货。 而关于定价，「买得越多，省得越多。」黄仁勋又重复了一遍他的经典名言。  

*   Quadro RTX 8000(48 GB 内存):预估零售价为 10,000 美元   
    
*   Quadro RTX 6000(24 GB 内存):预估零售价为 6,300 美元  
    
*   Quadro RTX 5000(16 GB 内存):预估零售价为 2,300 美元 
    

  

## 新架构与新软件生态

而对于英伟达更重要的事情是构建基于图灵（Turing）架构的全新软件生态和配套服务，这才是将这项技术真正落地的必经之路。

英伟达发布了 Quadro RTX Server，为数据中心的按需渲染定义了新标准，可轻松进行批量和交互式渲染。英伟达将 Quadro RTX GPU 与全新 Quadro Infinity 软件（将于 2019 年第一季度推出）相结合，可提供灵活的架构，以满足专业人士。

Quadro RTX Server 也已经预装内容创建和渲染软件，提供了强大且易于部署的渲染解决方案，可从小规模安装扩展到最大型的数据中心，且相较于仅采用 CPU 的渲染农场，成本仅为其四分之一。

![](../Images/5cc41ed8272350a0acab8ce9fe37745d.png)

而另一边，全球最广为采用的设计与创意应用厂商都已经开始在与 NVIDIA 紧密合作。  

开发者可通过全新 NVIDIA RTX，享受 Quadro RTX 的这些功能。NVIDIA RTX 这个图形平台，包含了用于光线追踪、AI、光栅化、仿真的 API，并支持 NVIDIA MDL 材质与 Pixar USD 资产交换。RTX 初步已得到 30 多个 ISV 应用的支持，可满足 5000 多万用户之所需。 

「Autodesk 和 NVIDIA 正在共同致力于将这些进步推向市场，AI 和实时光线追踪正在颠覆设计师和艺术家的工作方式。」Autodesk 设计与创作产品高级副总裁 Amy Bunszel 说。

虽然目前英伟达在用基于图灵（Turing）架构的 GPU 突破新的垂直细分领域，它还并不能为我们的普通用户所明显感知，但它却代表着英伟达正在应用 AI 与深度学习赋能底层技术的战略，它提升的是在摩尔定律之外的绘图技术的效率以及效果。

伴随着这项技术的深入应用，全面 AI 化的 GPU 不只会为专业人士，它同样会为每一个人带来巨大改变和全新的想像，甚至会为你打开一扇「超逼真虚拟世界」的大门。■
