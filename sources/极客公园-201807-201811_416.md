> **不知不觉间，Google Cloud Next 已经变成了一场聚集了 25000 个开发者、不逊于 Google I/O 的科技盛会。**

  

即使是自认为对 Google 非常熟悉的人们，也可能没有听过 Cloud Next 大会的名字。

这是 Google I/O 以外，这家公司又一个吸粉无数的开发者盛会。当地时间 7 月 24 日，在 I/O 结束的一个半月后，25000 名 Google Cloud 开发者再度聚首旧金山。

![](../Images/8574fa313c0688bb5579bd7b454529ba.png)

  

## Q2 财报里的「云」潜力

在发布会召开之前，Google 母公司 Alphabet 于当地时间周一公布了 2018 Q2 的财报，除去流量获取成本的季度收入为 262 亿美元，较去年同期增长 26%；除去欧盟 50 亿美元的罚款，Q2 净利润为 32 亿美元。

数月之前，Google Cloud CEO Diane Greene 就曾经对 CNBC 表示，外界低估了 Google 的云业务发展。除了移动广告业务，云计算业务的扩张为 Q2 带来的营收增长也功不可没。Google 虽然没有公布具体的云业务收入，但涵盖云服务的「other revenues」（其他业务收入）营收达 44.25 亿美元，较同期增长 36.5%。

![](../Images/380535e68e7f8e9c74697a6eeaec384e.png)

Diane Greene

增长的同时，Google 也在不断加大对云计算的投入。截止到 Q2，公司资本支出为 53 亿美元，相当于去年同期的 24.8 亿美元的两倍。此外，Alphabet 共有 89058 名员工，去年同期这个数字是 75606，员工数量增长大部分来源于云计算业务的工程师和销售人员，据 Diane Greene 在发布会上所说，为了提供更好的云服务，Google Cloud 的工程师数量翻了三倍，比销售人员还多。

  

## 「混合云」Google Cloud Platform

Google 凭借着新的 Google Cloud Platform 平台，正在为企业提供一套混合云服务方案，企业可以同时在 Google Cloud Platform 上和企业内部环境中进行部署。

Istio 是一种微服务管理框架，允许运营者对流量管理、安全性、故障排除有更多控制，谷歌即将推出 Istio 1.0 版本。Google Kubernetes Engine 现在可应用于内部基础设施，允许用户无需迁移到云端就可以更新应用程序。Cloud Service Platform 背后的理念是让企业按照自己的速度更新他们的堆栈。此外，Google Cloud Platform 工具与云计算中的其他服务，比如机器学习工具，都有着紧密的集成。

Google 宣布新的 CI/CD（持续集成/持续交付）平台——Cloud Build，允许客户大规模快速构建、测试和部署软件。Cloud Build 可以在多种环境下工作，比如 VMs、serverless、Kubernetes、Firebase。更重要的是，Cloud Build 支持 Docker 容器，并提供给开发人员日益自动化的方式进行构建、测试和部署。

  

## 数据安全和 AI 成为 G Suite 更新的主旋律

整场发布会与普通用户关系最近的环节就是办公套件 G Suite 更新和新品发布了。

![](../Images/b93ddd0efa383bcfea4ca939bf1b5673.png)

出席并发表演讲的 Google CEO Sundar Pichai

G Suite 是 Google 为企业办公准备一整套生产力工具，包括国内用户熟知的邮箱（Gmail）、文档（Docs）和日历（Calender）等等。过去的一年里，Google 为 G Suite 增添了大约 300 个新功能，在今天发布会上，数据安全和 AI 成为了 G Suite 新增功能的主旋律。

安全方面，Google 发布了安全中心的调查工具（investigation tool），管理员可以批量识别、管理用户和文件中存在的恶意分享和攻击；「数据地区」（Data Region）功能，管理员能够将数据和文件设置为仅限于本地区（如美国、欧洲等）使用，帮助管理者更好地控制数据安全。

人工智能方面，最先在 Google I/O 发布的智能回复（Smart Reply）和智能创作（Smart Compose）功能有了更多的应用。

Smart Reply 最早在 Gmail 邮箱中应用，据 Google 现场公布的数据，目前全平台已有超过 10% 的邮件使用这一功能辅助回复。现在，Google 将这一功能拓展到了即使聊天应用 Hangouts Chat 上，AI 将识别出用户聊天的方式和习惯，为用户提供智能可选的快捷回复推荐词。

在提升效率方面，辅助邮件写作的 Smart Compose 或许比简单的聊天回复表现更高，现在，Smart Compose 开始对 G Suite 的客户开放，升级将在接下来的几周内推送给客户。

发布会上 G Suite 最受关注的新功能是文档协作服务 Docs，为了方便写作和阅读，Google Docs 推出了语法建议功能。该功能使用基于机器翻译的方法来识别语法错误并进行更正，从何时使用「a」和「an」，到如何使用从属从句的复杂概念。

此外，Google 还为 Hangout Meet 的硬件用户推出了语音命令功能。

  

## 「以人为本」的 AI

最后登场的李飞飞教授带来了 Google Cloud 在 AI 和机器学习方面的最新进展，这是她本人第二次在 Google Cloud 的大会上亮相。加入 Google Cloud 一年多后，她几乎成了 Google Cloud AI 最权威的代言人。

![](../Images/1c332c6e4b93efa784b2869be4fa907c.png)

李飞飞博士

在这次 Cloud Next 大会上，李飞飞发布了她和团队最新的工作成果，包括 Cloud AutoML、AI 服务中心等等。

预选训练好的特定领域机器学习模型是云服务中最受关注的 AI 功能之一。今年早些时候推出的 Cloud AutoML 正是 Google 在这一领域推出的服务。

今天，Google 推出了公开正式版的 Cloud AutoML Vision，将 Cloud Vision 的 API 打包开放给企业用户。此外，AutoML 还新增了两个功能：AutoML Natural Language 和 AutoML Translation，分别在自定义文本和语言翻译领域为用户提供自定义训练模型的服务。

「至此，AutoML 可以为各行业缺少 AI 经验的企业和开发者提供自动生成图像功能，语言分类功能和翻译功能。AutoML 的注册用户也已经超过 18，000 家，服务行业横跨媒体，零售，金融，保险，能源，医疗，环境等等。产品和创新环环相扣, 合作也带来进步，希望我们能够不断提高，把最好的技术带给大家。」Google Cloud AI 研发主管李佳博士说道。

Google 为开发人员提供了能够打造独特会话接口的工具，但这仅仅是转化服务中心的一个开始。Google 认为企业需要一个更加全面的解决方案，集成自动化和强大的分析能力，为了满足这一需求，Google Cloud 推出了 Contact Center AI（服务中心 AI），一个「集虚拟助助理，智能信息发掘和情感分析等功能于一身，帮助 Contact Center（服务中心）的工作人员更有效地解决问题和用户提升体验的」第一个 Solution Product（行业解决方案产品）。

「比起取代人类的一些基本技能，我们认为人工智能在增强人类技能方面有着更加无限的潜力。」在演讲最后，李飞飞教授说道。

  

## 云时代的 Google Cloud Next

Cloud Next 大会上发布的新品大多距离普通用户比较遥远，它是这个云计算称王的时代里，Google 向开发者们表达态度的方式——I/O 上并非主角的露出远远不够，Google 的云服务需要一个专场。

![](../Images/6c913499fb2cd1c09bd9d5b09c02e100.png)

对于想要了解 Google 的人们来说，Cloud Next 仍然是一个值得关注的科技活动，像 CNET 的科技记者 Stephen Shankland 在推特上所说：「Google Cloud Platform 尤其吸引我的原因在于，它是一款付费的产品：没有广告商和用户之间分裂的特权使用费，不会出现偏袒一方损害另一方的情况。付费的客户意味着 Google 的目的非常一致：把产品做得更好。」

几年前，Google 刚刚开始发力云服务的时候，很多人对此并不看好。那时市场是属于亚马逊和紧随其后的微软的，人们告诉时任 CEO Diane Greene，Google 至少需要十年的时间才能准备好面对企业用户。

「微软就花了这么久，我就说，不，不需要十年。」在接受外媒 TechCrunch 采访时，Greene 说道。当时 Google Cloud 开发者会议的参会规模只有 2000 人左右，顶着压力，Google Cloud 一路走来，他们早已准备好了自己的企业服务。

在接受采访时，Diane Greene 说她很讨厌被人叫作「AWS 和 Azure 之后那个『遥远的第三名』」，Google Cloud 有着更大的野心，也有着远远不止于目前市场份额的实力与潜力。

当亚马逊和微软的云服务都在成为公司最挣钱的业务时，Google 不会甘心做那个「遥远的第三名」。
