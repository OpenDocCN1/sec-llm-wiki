微软四季度财报发布：2018 财年收入破千亿，云服务 Azure 成主要推动力

微软最新一季财报中，云收入达 69 亿美元，较同期增长 53%，Azure 仍是主要推动力，同期增长 89%。


北京时间 7 月 20 日凌晨，微软发布了 2018 财年第四季度的财报，季度营收达 301 亿美元，超出此前分析师预测的 292 亿美元。商业云服务（commercial cloud）获 69 亿美元营收，比上一年同期增长 53%。2018 财年整体收入破千亿。

根据 Forbes 的预测，从科技公司云业务的增长势头和尚未满足的市场需求来看，全球云服务市场排名前几位的公司，微软、亚马逊、IBM、Salesforce、SAP、Oracle 和谷歌，在 2018 年将创造超过 1000 亿美元的云计算收入。根据市场研究机构 Synergy Research 的报告显示，2016 年在公有云市场上，微软超过谷歌，成为仅次于亚马逊的第二大公有云服务提供商，云计算市场上出现「两大巨头」对立的局面。

被认为是全球第一大公有云服务提供商，亚马逊的云计算服务 AWS（Amazon Web Service）在 2017 年营收增长了 43%，达到 175 亿美元。2018 年 Q1，AWS 仍然稳坐第一，营收比去年同期（36.6 亿美元）上涨了 49% 至 54.4 亿美元。资深作者、前甲骨文首席传播官的 Bob Evans 曾在 Forbes 发表文章预测，如果 AWS 能保持 49% 的增长水平，2018 年 Q2 的营收将会达到 60 亿美元（去年同期为 41 亿美元）。


Azure 一路狂奔

根据研究公司 Synergy Research Group 发布的数据，AWS 在 Q1 拿下了 IaaS（基础设施即服务）市场 33% 的份额，包括原始计算和存储、应用程序运营服务和私有云托管等。 

尽管亚马逊在 IaaS 市场处于明显的领先地位，但另外一边，软件巨头微软近年来力推的 Azure 也在持续蚕食着亚马逊的优势，市场份额从去年的 10% 增至 13%，2018 年第三财季营收上涨 93%，第四财季营收上涨 89%。在微软第三财季电话会议上，CEO 萨提亚·纳德拉谈起 Azure 的快速增长时表示，「我们在 Azure 上的投入是正确的，在不断扩张的云计算市场上，微软占据了有影响力的市场份额，并且在不断扩大。」

在今年的 Inspire 大会上，微软发布了不少面向 Azure 的新计划和应用。

微软的 One Commercial Partner （商业合作伙伴）部门宣布了针对合作伙伴推出的 Azure Expert Managed Service Provider（专家托管服务提供商）计划，让具备云解决方案的合作伙伴（MSPs）通过 Azure 的帮助更好地服务客户。而且据 Azure 执行副总裁科里·桑德斯说，MSPs 必须由独立的第三方严格审核，从而确保其可靠性。Azure Data 的 CTO，拉古·罗摩克里希纳谈到 Azure SQL 数据库设置新的基准测试工具，迭代快两倍的查询性能，移动计算更高效，比 Amazon Redshift 数据库至少快 67%，比如查询 30TB 数据，Amazon 需要花费 4803 秒，而 Azure 只需要花费 2830 秒。在除速度外，Azure 提供 128 个并发查询，而 Amazon Redshift 并发查询的上限是 50。除此之外，微软推出新产品 Azure Data Box Disk、Azure Virtual WAN（虚拟广域网）和 Azure Firewall（防火墙），着墨在云服务市场的布局。

虽然入局稍晚，但是 Azure 发展势头强劲，照比 AWS 这两年几乎保持不变的市场份额，Azure 的大步迈进似乎有「迎头赶上」的趋势。


Azure 并不是微软云服务的全部

微软于 7 月 19 日发布的财报显示，微软第四财季营收达 301 亿美元，较同期增长 17%。净利润为88.73亿美元，增长10%。微软副总裁及首席财务官 Amy Hood 表示，这一季度商业云收入增长 53% 至 69 亿美元，占整体营收的 22%。 第三财季，微软云业务营收达到 60 亿美元，比去年同期（38 亿）增长了 58%，云业务收入占微软整体营收的 22%。

图片来源：ZDNet

财报发布前，Bob Evans 曾做出大胆预测，第四财季微软商业云将突破 70 亿美元。其推测依据为，2017 第四财季云业务营收为 45 亿美元，过去四个季度，微软云业务照比上一年同期的增长百分比分别是 56%、56%、56%、58%，如果能保持这一增长水平，微软的云业务营收在 2018 年第四财季将位于 70.2 亿-71.1 亿美元之间。从数字来看，第四财季微软云业务增长势头略有放缓。

文章中也同样预测，如果 AWS 能保持 49% 的增长水平，上一季度营收将会达到 60 亿美元（去年同期为 41 亿美元）。这与 AWS 为云基础设施市场的冠军头衔略有出入，许多研究人员和分析师也「站队」，声称亚马逊是排在全球云计算之首。

事实上，Bob Evans 表示云计算领域分为三个层面——IaaS、PaaS、SaaS，而在 IaaS，AWS 的确做的最大，而微软的云业务横跨了三个层面，在整体云业务收入上处于领先地位。微软的商业云服务（commercial cloud）主要涵盖 Office 365、Dynamics 365 以及 Azure 公有云。纳德拉也曾表示「微软在云业务上的成功过在于对三个领域的积极部署，而微软最终的任务是让用户轻松跨越三个领域，充分使用人工智能的力量，产生有价值的数据。」 

微软目前的业务划分为 Productivity and Business Processes（生产力与业务流程）营收为 97 亿美元，同期增长 13%；Intelligent Cloud（智能云）营收 96 亿美元，同期增长 23%、More Personal Computing（更多个人计算）营收为 108 亿美元，同期增长 17%。

其中推动云业务营收增长的三大功臣 Azure 营收增长 89%；Office 365 商业版营收增长 38%， Office 365 家庭、个人版订阅用户达 3140 万以及 Dynamics 365 营收增长达 61%。

有质疑声称「Office 365 不属于真正的云计算业务。」但是 Office 365 的成功恰巧反映了纳德拉早期萌生并且毫不动摇地希望帮助企业完成数字化转型的理念成为了微软成功的一大关键。

 

走向云端的微软

纳德拉多次表示微软未来的愿景是覆盖企业更多云计算需求，推动企业的数字化转型。德国电梯制造商 Thyssenkrupp Elevator 基于 Azure 打造物联网技术解决方案，对电梯的运营情况实时监控，将销售和订单流程数字化，交货时间缩短了 400%。全球领先的医疗技术公司 Stryker 选择 Office 365 来协同办公，并使用 HoloLens（全息透镜）设计手术室。零售巨头沃尔玛也在近日宣布，与微软签署合作协议，利用 Azure 和 Microsoft 365 等云解决方案，共同狙击对手亚马逊。

从 2014 年，纳德拉接任史蒂夫·鲍尔默成为微软 CEO 以来就提出了「云计算为先、移动为先」的转型口号。

此前，微软一系列大规模的裁员就被指在为转型云计算「铺路」。去年，微软重组全球销售团队，裁掉数千名员工，将重心转移到云计算业务上。今年三月微软宣布对 Windows 工程部门重组，形成「体验和设备」（Experience & Devices）、「云计算和人工智能」（Cloud + AI）以及「人工智能和研究」（AI & Research）三个工程部门，前 Windows 和设备部门执行副总裁 Terry Myerson，在微软任职 21年后因此离开了公司。Atlantic Equities （大西洋证券公司）表示「微软向云业务的过渡为这件软件巨头开辟了有利可图的市场。」大西洋证券公司分析师詹姆斯·考德威尔表示「虽然 Azure 还没有确立曾属于 Windows 的垄断地位，但是 Azure 的未来绝对充满期待。考德威尔对 AWS 和 Azure 建模，预测二者在十年后的营收可达 1850 亿和 1150 亿美元，占据 70% 的市场份额。

近来，微软对云计算领域不断投入，比如耗费 260 亿美元收购的职场社交网络平台 LinkedIn。通过微软也增强向企业用户销售云服务的能力，而 LinkedIn 的作用不容小觑，第四财季营收增长达到了 37%。上个月，以 75 亿美元的价格收购代码开源社区 GitHub，以增强云服务的实力。

未来，微软会从 Windows 上转移，押注到云服务和订阅服务，将传统的一次性商业软件销售逐步转化成订阅模式的云计算。微软的确打造出了成功的云计算产品。通过混合云对客户现有资源进行扩展和增强，纳德拉赋予云计算的终极定义是「为客户带来价值」。

自从纳德拉上任，微软股价上涨两倍多，截至美国东部时间周四 18:32 分，微软股价在盘后交易中上涨 4.01 美元至 108.41 美元，市值超 8000 亿，为全球市值第四大公司仅次于苹果、亚马逊、Alphabet。Evercore ISI 的分析师柯克·马特尼预测微软市值在 2020 年可以达到万亿美元。像数十年前一样，以操作系统入局计算机领域从而大获成功的微软，如今也确立了在云计算领域的巨头地位。
