# 不安分分子的新革命

> **作为企业家、创业者，如何在涌动的变化里找到存在的意义，似乎是个永恒的话题。**

  

2018 过半，这是个被投资圈公认为「没有大风口」的年份。不切实际的疯狂变少了，但属于创新者的勇敢者游戏还在继续。人工智能、区块链、自动驾驶……酝酿许久的技术在扎堆走向落地，在这些产业里翻滚不停的冒险家，也走上了一个充满挑战和机会的节点。作为企业家、创业者，如何在涌动的变化里找到存在的意义，似乎是个永恒的话题。

无论是站上鸟巢大胆亮出 TNT 的罗永浩、推动第一批蔚来汽车和服务体系落地的李斌，还是想要用区块链技术和哲学「重新发明互联网」的李学凌，都是这支队伍中的代表人物。

![](../Images/33bac4ccb80b792fd3a1ac8ccc21a143.png)

李斌的 2018 注定将在兴奋和焦虑中度过。

作为国内第一款将服务和量产车交付给用户的新造车企业，蔚来汽车在接下来的几个月的进展不仅是这家公司至关重要的时刻，也是它的「危险期」。李斌想要交给市场的，不仅是一辆电动汽车，更重要的还是这背后包括换电、销售甚至情感等一系列线上线下的服务体系。用李斌的话说，蔚来更重视「技术和感性」的体验，而 ES8 也是一辆注重情感体验提升的科技产品。

早已有「出行教父头衔」加冕的李斌，当下更关注蔚来迈出的第一步：「我们要怎么熬过狮子刚生下来的危险期，至关重要。」李斌说，「也许等我们交付完一万台创始版，像小朋友百日要过生日一样，那个时候我们才能松一口气。」

有人从李斌身上看到了 Musk 的影子，看到了蔚来对于汽车服务体系的巨大变革，也有人担心变革的艰难之路能否走顺，更有人觉得它是汽车界的小米，它的模式创新很多人要过几年才能看懂。到底该如何解读李斌和蔚来汽车？很大程度上，回答了这个问题，几乎也就能管中窥豹，了解未来一段时间里出行领域的最大看点。

![](../Images/71cf1d9348811739cd79a149d04b5602.png)

挺过了 2016 的艰难，2017 年曾经是锤子科技柳暗花明的的一年，喘过一口气后，罗永浩在 2018 年站上鸟巢的发布会，发布了 R1 和 TNT。  

依然是堂吉诃德式的孤勇形象，罗永浩在生产力工具产品上的创新又展现出了一如既往的坚持和大胆。对于罗永浩带着满头大汗对 TNT 的展示过程和反馈结果来说，无论是使用场景还是价格制定上，外界评论都有一种不知所错的意味。但其实如果冷静下来，考虑到智能手机行业的整体疲软，和市场对于硬件创新产品的渴求，这种从零开始的创新，都不是一种没有意义的尝试。只不过，在市场完全没有准备好的情况下，如何一步步推进产品，成为了这家公司绕不过去的魔咒。

创业五年，锤子科技的逻辑已经初具模型，而 2018 年这种「出位」的尝试，会在这家「小公司」的创业史上带来什么样的注脚呢？手机市场迎来拐点，变化中的锤子和罗永浩，对下一代计算平台和硬件创新的探索上还有哪些思考？也许你所关心的那些话题，罗永浩都带来了答案。

![](../Images/80517f409b310d5037bdce724275cb03.png)

互联网创造了财富，但它是否真的带来了繁荣？

这是李学凌接触区块链时，一直在思考的问题。想想我们现在世界上都有哪些公司是靠着中介的方案成为了巨大的公司？Google 是人与信息的中介，Facebook 是人与人交流的中介，亚马逊是人与商品之间的中介。而区块链精神来自分布式计算和 P2P，从而天然厌恶各种中介。

基于这样的想法，一直致力于社交和娱乐领域的李学凌，想重新捡起多年前就一直想做的通讯产品。在这次的 Rebuild 2018 科技商业峰会上，李学凌将首次公布自己在区块链领域的新布局。

在 Rebuild 2018 科技商业峰会上，极客公园把他们请到了成都，希望通过三场高浓度的演讲和对话，让你了解这些「不安分分子」掀起的新革命。■
