# 在工厂睡了快三个月，马斯克如何帮助特斯拉走出「生产地狱」？ | Global 24/7

> **一部 Model 3，险些拖垮了整个特斯拉。**

  

埃隆·马斯克最初承诺在 2017 年底前生产 20 万辆 Model 3。为了实现这一目标，他计划对工厂的机器人进行史无前例的投资，并把生产线称为「制造机器的机器」。然而，截至去年年底，特斯拉只生产了 2700 辆 Model 3，到今年 6 月底，Model 3 产量也仅有 4.1 万辆。

更糟糕的是，特斯拉已经负债 100 亿美元，而且信用评级在 3 月份遭到信用评级公司穆迪（Moody’s Investors Service）下调。特斯拉平均每个季度要花掉 10 亿美元，超过了过去一年的净得。

今年 4 月，马斯克亲自接管了 Model 3 的制造工程，经常直接在工厂的睡椅上过夜。直到 7 月 1 月，这位 6 月在股东大会上差点流泪的 CEO 才逃出自己口中的「生产地狱」，宣布特斯拉实现了周产 5000 辆 Model 3 的里程碑。

![](../Images/6fc4bb4e17298f0f5f36bc3ebcc736ea.png)

在一篇题为《Model 3 是埃隆·马斯克的地狱：它最终能让特斯拉成为真正的汽车公司吗？》的彭博社报道中，作者为我们揭示了特斯拉如何一步步走入了如今的「生产地狱」之中。

  

## 在实现周产 5000 辆 Model 3 之前

马斯克的过度乐观和特斯拉过于依赖自动化的流程，是主要的原因。

2015 年年初，马斯克召集他手下的 12 名顶尖工程师，包括电池、设计、底盘、内饰、车身、传动系统、安全以及热力学领域的专家，开会讨论 Model 3 到底应该是一款什么样的车。他们要求这款车价格亲民，续航里程至少 200 英里......

可时间并不乐观，特斯拉计划在 2017 年中销售这款车型，也就是说，马斯克手下顶尖的工程师们仅有两年半的时间完成从设计、测试和量产的所有流程，对比而言，传统汽车的制造周期需要五年。加上前面提到的种种苛刻标准，Model 3 项目挑战巨大。在汽车行业，丰田往往被视为是生产能力最强的汽车制造商，一辆新车需要大约 30 个工时。而特斯拉即便用上了工厂里的所有机器人，它在每辆车上耗费的时长也是丰田的三倍之多。

![](../Images/dd4353d5651bc4c8896c10afb1640269.png)

马斯克无视过去 50 年汽车制造丰富经验的勇气，一定程度上来自于买家们的强烈反馈。特斯拉在 2016 年 3 月公开发布 Model 3 一周前，员工们开始打赌，赌有多少潜在买家会支付 1000 美元的可退还订金预订 Model 3。当时，最乐观的预期是 20 万辆，但实际预订量是预期的两倍。在这之前，特斯拉曾表示要在 2020 年生产 50 万辆，但在面对如此强劲的需求后，马斯克宣布 2018 年就要达到这一目标。

马斯克指派设计 Model 3 的工程师开发制造工艺，比如发明一种不需要工人操作，仅需一步就可以把汽车排在一起的设备，尽可能实现汽车组装的自动化。特斯拉还同时收购了德国 Grohmann Engineering 和美国 Perbix 这两家自动化公司。特斯拉称，Model 3 生产线的自动化让工厂更安全，但当机器人需要分解后移走的时候，工人们的工作量也没有减轻，有些工人每天工作 16 个小时，特斯拉有时免费提供红牛饮料。

![](../Images/da50713ea897de2f535194c5bbd09542.png)

在今年六月初的股东大会上，马斯克表示他已经要求员工建立第三条总装配线。一周后，马斯克在 Twitter 上展示了一个在弗里蒙特工厂外的「简陋」生产帐篷，没有机器人系统，没有固定壁，以至于有人讥讽：「除了在战区维修汽车的军人，我觉得没人见过这样的设施。」

特斯拉暂时从过度依赖的自动化流程恢复为人工制造，马斯克称，「许多有关自动化的期望都起到了反作用。所有的机器人都被关闭了，并被恢复为人工站，因为机器人一直在出错。」

彭博社在相关报道中指出，如果马斯克能够在 Model 3 上取得成功，他将会颠覆一个规模达万亿美元的行业，在削减碳排放上所做的工作要超过地球上的任何人。

## 40% 关税下，特斯拉在中国建厂非常必要

马斯克坚信，零排放汽车的市场将空前巨大。而中国政府越来越注重改善空气质量和减少尾气排放，鼓励电动汽车的生产和销售，向汽车厂商提供补贴。这对特斯拉的成本控制很有利。

在过去几个月陆续出台的一系列政策中，中国取消或放宽了汽车企业和许多金融服务集团的外资持股上限，还允许外国汽车制造商在中国全资拥有自己的生产业务，而不再需要找到本土合资伙伴。7 月 10 日，特斯拉与上海政府达成协议，将在临港地区独资建设集研发、制造、销售等功能于一体的特斯拉超级工厂（Gigafactory 3）。

这两个月，特斯拉几款车型在中国的定价经历了一次大起大落。5 月，进口车关税降低政策公布两小时后，特斯拉宣布降价，幅度从 4 万到 9 万元不等。然而受随即而来的贸易战影响，7 月 6 日起美国生产的进口汽车关税税率从 15% 上涨至 40%，特斯拉 Model X 的顶配版本售价暴涨 25 万。

在上海建厂，特斯拉就能本地生产，免去关税，减低运输成本，并让公司接近中国庞大的汽车供应链。特斯拉表示，预计新厂将在两年后完工，并在完工两、三年后达到每年 50 万辆汽车的最高年产量。

除了在上海建厂，特斯拉全球副总裁任宇翔本月 12 日宣布，特斯拉（北京）科技创新中心已设立在北京，主要包括电动汽车及零备件、电池、储能设备及信息技术的研究、开发等。

马斯克在造访中国之前接受过外媒采访，他表示，「过去一年非常艰难，但是我预感接下来的一年将非常美好。」他说，现在还有一只脚仍陷地狱，但庆幸的是，一个月内就能拔出这只脚了，预计在三个月内，周产 5000 辆 Model 3 将非常轻松。
