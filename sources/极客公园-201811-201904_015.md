# 那些年，微软葬送的产品〡清明特辑

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652862022&idx=1&sn=29a3c61a04213c09ff0b3b40e2a5bcc8&chksm=7e6a0bf0491d82e6a3f3ab54b005ae72dcd6afd6b45b3fae9bfcd145d63794ad6283b0a917c9&scene=126&sessionid=1681310691#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652862022&idx=1&sn=29a3c61a04213c09ff0b3b40e2a5bcc8&chksm=7e6a0bf0491d82e6a3f3ab54b005ae72dcd6afd6b45b3fae9bfcd145d63794ad6283b0a917c9&scene=126&sessionid=1681310691#rd)

> 在微软关停的众多产品或服务中，有的满是情怀，有的叫人惋惜，而有的则让人恨得咬牙切齿。

![](../Images/5555bf878c05e0888daf444b178f8b72.png)2011 年的万圣节，时任微软 Office 部门高级总监的 Tom Rizzo 在网上对 Google 大肆调侃，嘲笑 Google 那年关停了十几个产品和服务。Rizzo 甚至还恶趣味地制作了一张名叫「谷歌墓地」（Google Graveyard）的图片：Google Buzz、Google Wave、Google Gears……写着已故名字的墓碑堆满了整张图片。

![](../Images/87a12d468b3ff231b341db8431e304fe.png)谷歌墓地和微软墓地 | liveside

但很快，对 Google「落井下石」的微软就受到了群嘲。网友如法炮制了「微软墓地」，Soapbox、OneCare、Spaces、Expo、Zune Player……被宣告「退休」的服务同样不少。

在微软关停的众多产品或服务中，有的满是情怀，有的叫人惋惜，而有的则让人恨得咬牙切齿。下面，极客公园总结了五款知名度最高的微软「已故」产品，在这个清明假期，一起来缅怀那些死于巨头之手的明星产品吧。

  

## MSN Messenger（1999-2014）

1999 年，微软推出了即时通信软件 MSN Messenger。之后，微软不断在 MSN Messenger上添加各种新功能，包括自定义表情、与好友一起玩挖雷游戏、震动屏幕等等。2005 年，MSN Messenger 改名为 Windows Live Messenger，预装在 Windows 系统中，成为了微软在线服务 Windows Live 中的一部分。

但这个 2005 年强势进入中国市场，并迅速占领白领们电脑桌面的通讯软件，在后来却在与腾讯 QQ、微信、阿里旺旺、飞信等本土即时通信软件的竞争中败下阵来。Windows Live Messenger 没有将产品很好地进行「本地化」，无法登录、频繁掉线以及传输文件速度缓慢等诸多问题导致了它 2011 年在中国内地的市场份额仅剩 4.95%。

![](../Images/e60c65518b399567809b902e514b907f.png)MSN Messenger | Franceinfo

2014 年 10 月 31 日，微软宣布 MSN Messenger 正式退出中国市场。中国是 MSN 的最后一个服务地区，至此 MSN Messenger 停止了在全球的服务，作为一款聊天工具的 MSN 不复存在，而微软在 2011 年收购的 Skype 代替了这对不再亮起的蓝绿小人。

  

## Windows Vista（2006-2012）

2006 年，被微软寄予厚望的 Windows Vista 发布，距离上一版本的 Windows XP 已有超过五年的时间，这是 Windows 历史上间隔时间最久的一次发布。

Windows XP 的成功让外界对 Vista 充满了期待，微软内部也是不计成本了想要打造出一款巅峰的桌面操作系统。但可惜事与愿违，Vista 自推出以来一直受到各种批评，比如对多种硬件和软件不兼容，驱动程序存在问题，以及引入了过于繁琐的安全程序等。也就是在 Windows 7 即将接棒的那年，科技博客 24/7 Wall St. 在《时代》上列出了 1999-2009 年十大失败的科技产品，不幸的是，Windows Vista 排行第一。

根据市场研究公司 Net Applications 的数据，2009 年 4 月，Windows Vista 的全球份额还不到 24%，而 Windows XP 的份额则高达 62%。在 2009 年 Windows 7 正式版推出前，很多人在选购电脑的时候，就会顺便要求店家把系统降至 Windows XP 或升级到 Windows 7 测试版。Windows Vista 似乎成为了「不必要」的系统。

![](../Images/b6b8ab91e5ce228067450d54f2a3f79f.png)Windows Vista 界面 | MSPoweruser

就使用体验而言，Windows 7 可以算是 Windows Vista 的 turbo 版本，但 Windows 7 完全是基于 Windows Vista 编写和开发的，前者充分借鉴 Vista 的各种成果，甚至算是直接套用后者的精华。微软称 Windows Vista 新增了上百种功能，其中，被称为 Windows Aero 的全新 UI 风格让人印象深刻。从这个角度来看，Windows Vista 的过渡是必要的，它是 Windows 7 成为优秀接任者的基础。2012 年，发布短短六年之后，微软停止了对 Windows Vista 的主流主持。

  

## Zune（2006-2015）

2006 年 11 月，[微软正式推出了音乐播放器及相关音乐服务 Zune](http://mp.weixin.qq.com/s?__biz=MzA5MTMyNTYzNA==&mid=2663972284&idx=1&sn=418c8ec4dabb0ea8a1ff1b2d12abff62&chksm=8b424811bc35c107730c28f712c226002abd976550842af46ce68769155d8c864b1213999e3e&scene=21#wechat_redirect)。初代 Zune 比苹果的 iPod 整整晚了五年。在那五年里，iPod 系列已经发展到了第五代，nano / shuffle 系列也更新到了第二代。

![](../Images/1f38f7db023bb4f12fd41cb4c94e895d.png)Zune Player | Windows Central

Zune 一登场，就以区别于 iPod 系列圆润设计的硬朗造型（但也有人认为是笨重）亮相。相比被戏称「白开水」的 iPod，Zune 在音质上的表现要更好。另外，Zune 也有极具风格化的系统 UI（这种风格也延续到了后来微软的移动操作系统 Windows Phone 上）。

![](../Images/28840ccc7912bf41da098abd93636d0f.png)Zune 搭配的软件 | drawne.com

但 Zune 也有不足，比如听上去很美好的 Wi-Fi 同步功能不够稳定，也存在「到了闰年就死机」这种让人哭笑不得的固件 bug。和产品线已经非常丰富的苹果相比，微软的竞品的确乏善可陈。

2011 年，微软宣布 Zune 播放器正式停产。2015 年，Zune 服务也正式关闭。Zune 这个音乐品牌终于还是落幕了。在与 iPod 竞争的九年里，Zune 共推出了四代共七款产品。Zune 在刚发售的「鼎盛时期」也只是拿下了美国便携播放器市场份额 9%，远远低于 iPod 的 63%。

但 Zune 和 iPod 都敌不过日渐强势的流媒体音乐。2017 年，苹果将第六代 iPod nano 6 也列入过时产品名单。

  

## Windows Phone（2010-2017）

2007 年，面对 iPhone 引领的触屏革命，最早是为键盘手机设计的 Android 迅速转向去适配触屏手机。而迟钝的微软直到 2010 年，才发布专为全触控设备设计的 Windows Phone 7。那时，iPhone 4 已经发布，Android 也迭代到了 2.1。

微软从 1996 年的 Windows CE 开始建设 Windows Mobile 生态，与最新的 Windows Phone 7 完全不兼容。这直接造成了新移动操作系统应用程序的严重缺失。

2012 年，微软正式推出了 Windows Phone 8 系统，这同时激怒了用户和开发者。用户想要使用这一系统，必须选择重新购买手机，因为之前的设备都无法更新到 Windows Phone 8。在开发者这边，他们才递交 Windows Phone 7 应用，结果微软的新系统让他们重写应用。

![](../Images/3562076f1c161a293857a0a08db751fa.png)iOS、Windows Phone 8 和 Android UI 对比 | TechRadar

而 Windows Phone 的硬件生态也因为微软的授权战略变得越来越冷清。在 2014 年的 Build 大会之前，微软在智能手机市场也采取和 PC 市场相同的战略——对 OEM 厂商收取授权费用，每台 10-20 美元。但当微软回过神来宣布免费授权给手机厂商的时候，2014 年，Android 已经占据了全球 80% 的市场份额，IDC 的数据显示，Windows Phone 和运行 BlackBerry 等其他手机仅占 3% 左右的份额。

那一年，Windows 10 推出。微软正在做着台式机、笔记本、平板电脑、智能手机都在 Windows 10 达到统一的梦。因为 Windows 10 Mobile 生态发展缓慢，用户量太少，微软最终还是砍掉了移动系统——2017 年，微软官方宣布 Windows 10 Mobile 停止开发，只对系统提供安全支持。

![](../Images/2cd8d26903444c46c5c6131cfbf230b6.png) Lumia 930 | Nokia

只是直到现在，人们还是会为那七年间五彩斑斓的 [Lumia 手机](http://mp.weixin.qq.com/s?__biz=MzA5MTMyNTYzNA==&mid=2663973170&idx=1&sn=4a18c3e871d27b9921f4e178d09e2ffd&chksm=8b43b49fbc343d89c2bf5fe55005f4259beb7d0f9cec39f6b7381f18dc474c10a286c6af905d&scene=21#wechat_redirect)感到惋惜。

  

## Kinect（2010-2017）

2010 年的 E3 游戏展上，微软正式推出了 Kinect，售价 149 美元。Kinect 是一种类似网络摄像机的感应器，它配备了三个构成了 3D 结构光深度感应系统的镜头，具备追焦技术，还内建了麦克风，可以用来识别语音指令。有了它，玩家不需要手持游戏手柄，使用语音指令或手势就能操作 Xbox 360 和 Xbox One 的系统界面。就像微软说的，它提供了一种「免控制器的游戏与娱乐体验」。

![](../Images/0e84fdfe69814ce4a83a7db11d12d67b.png)Kinect | Wikipedia

一上市，Kinect 就迎来了属于它的高光时刻：在 60 天里，这款游戏周边设备卖出了 800 万套，是当时吉尼斯世界纪录上销售速度最快的消费电子产品。

但新鲜感过来，Kinect 最终却没有留住玩家。因为体感交互往往只适合应用于运动类和娱乐类游戏，对于需要瞄准的射击类游戏，玩家还是得靠手柄操控。一方面，玩家最终玩腻了娱乐类游戏；另一方面，开发者不可能放弃手柄控制类游戏转而去做类型受限的体感游戏。就这样，Kinect 的生态陷入了恶循环。另外，Kinect 只有至少在 2×2m（无任何家具遮挡）的空间才能准确识别玩家的身体。这也成为了不少玩家犹豫的因素。

随着 Xbox One S、Xbox One X 新品取消 Kinect 连接端口，Kinect 的命运也可想而知了。2017 年，微软宣布 Kinect 停产。

Kinect 至停产时已出货约 3500 万部。后来，Kinect 的相关技术融入了微软的 HoloLens AR 眼镜、Windows Hello 面部识别系统中。可以说，Kinect 有过辉煌的「前半生」，即便失败了，但它的技术仍在微软的其他产品和服务中得到延续。

* * *

以上就是我们精心挑选出的几款最值得缅怀的微软产品。当然，刚刚度过 44 岁生日的微软仍然有很多值得纪念的产品湮没在了数字时代的历史长河里。

有些产品和服务的死亡是因为它们不够优秀，已经变得不再必要。即便优秀，也不一定能存活，因为市场的力量正在摧枯拉朽，为那些真正代表未来的产品留足位置。有些产品则是因为微软战略出现失误，它们中的一些，变成了警钟，还有一些，继续流淌在微软的血液里。
