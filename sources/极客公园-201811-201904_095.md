# 7 座 Model Y 发布，马斯克的 SEXY 没有「意外」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652861492&idx=1&sn=23627ffdce1815a7bd09d7cb9bab210d&chksm=7e6a0982491d8094699e6b238f585413e7febcf012cf38ba5ec5122470886b05fc620a366393&scene=126&sessionid=1681310709#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652861492&idx=1&sn=23627ffdce1815a7bd09d7cb9bab210d&chksm=7e6a0982491d8094699e6b238f585413e7febcf012cf38ba5ec5122470886b05fc620a366393&scene=126&sessionid=1681310709#rd)

凑齐 SEXY，马斯克拿出了一辆没有「惊喜」的Model Y。

  

![](../Images/5369f949f74401c847022785096920c7.png)马斯克的 SEXY 终于完成了最后一笔。舞台上，Model S/3/X/Y 被故意地摆在了一起。像为一个划时代产品做铺垫，从 Roadster 1 开始讲起，马斯克一上来先回顾了特斯拉发布过的所有车型、工厂、充电部署，甚至包括能源产品和中国工厂。

  

![](../Images/2faf551d8d00f2514729c7b0223162c9.png)特斯拉 Model S/3/X/Y 凑齐，亮相发布会

「傲娇」的马斯克特意贴出了十年前外媒对电动汽车的报道。例如《福布斯》将造电动车描述成「extraordinary bad idea（极其糟糕的主意）」，《每日邮报》认为「电动汽车的存在是对空间的浪费」。但十年后的今天，不管是《连线》杂志还是彭博社，都在讨论的是传统车企在电动汽车产品上加紧布局、应对内外忧患的那种焦灼。

只是从发布会开始到结束，仅仅用了 40 分钟左右，而留给这个「划时代产品」Model Y 的介绍只有短短 10 分钟。早在 2015 年，马斯克就通过 Twitter 放出了消息，表示「Model 3 的衍生车型会被命名为 Model Y」。四年过去，Model Y 能满足你的那些期待吗？

  

## 关于 Model Y 的十分钟

由于是基于 Model 3 打造的车型，Model Y 的设计和性能参数并没有让人意外。马斯克甚至还在发布会现场提醒大家「注意」不要把 Model Y 和 Model 3 混淆了，因为长得实在是太像了。

![](../Images/8a2105aafd364ccaf9e22dc7d50b1db5.png)特斯拉 Model Y 纯电动 SUV  

从发布会现场的图片来看，Model Y 整体要比 Model 3 高，和 Model X 差不多。内部空间 66 立方英尺，其中储物空间有 1.9 立方米。可能算是惊喜吧，你得另加 3000 美金才能升级到 7 座车型，该版车型预计 2021 年交付。

![](../Images/9c66d8c325e25a4d5583464002352f79.png)  

动力表现上来看，Model Y 的续航最高可达 482 公里（300英里），0-60 英里/每小时加速为 3.5 秒，风阻系数为 0.23。当然，特斯拉车型的空气动力学性能一直都很出色，如果购买的是长续航版本，可能车子能够行驶的实际里程会超过 482 公里。

![](../Images/787401e994801447b2a3f64606295dd7.png)

价格的话，从 3.9 万美元起跳，但最便宜的这款车型预计 2021 年春季开始交付。尽管可能不会采用与 Model 3 后驱长续航版一样的电池包，但因为距离交付还有两年的时间，一切都是未知数。其他两款，高性能全轮驱动版和长续航全轮驱动版价格相差 9 千美金，预计 2020 年秋季交付。

![](../Images/0564bd06e58bab22650445fd53092bc4.png)特斯拉 Model Y 纯电动 SUV 全系产品

今天下订单需要预付 2500 美元。更重要的是，Model Y 可以在使用 7 天或行驶 1000 英里内全额退款。

![](../Images/358fa1c38aa1d588089357941a14503a.png)  

  

## Model Y 订单量 ＞ Model 3？

马斯克曾预言，Model Y 的全球销量将到达 50 万~100 万辆/年。但在这个时刻都会发生「产能过剩」的汽车产业，Model Y 还能打破 Model 3 的超 40 万辆的订单神话吗？

全球范围内，紧凑型 SUV 属于品牌走量赚钱的主力车型，换句话说，用乐高制造一辆 SUV 都可以拥有五位数的销量。初始 3.9 万美金的价格意味着 Model Y 会成为几乎所有豪华 SUV 的竞争对手，特别是会对像奔驰、奥迪、捷豹等拥有同类型产品的豪华品牌形成强有力的打击。

根据《华尔街日报》的消息，目前美国市场轿车的销量正逐步被 SUV 赶超。二月份，本田思域的销量下跌 10%，与此同时 CR-V 的销量却上扬了 10%。而每卖出一辆轿车，就同时有两辆 SUV 售出，下面这个表格清晰地表明了 SUV 市场需求不断攀升的变化。  

![](../Images/7031b3fd42b483d630f61f08cadb01bf.png)美国市场 SUV 车型销量表现图，来源：华尔街日报

据 JD Power 称，SUV 目前占美国汽车市场的 49％，购买价格在 3 万至 5 万美元的汽车客户超过一半购买了 SUV。

考虑到这种市场变化会持续很长一段时间，Model Y 对特斯拉而言显然是一款更具战略地位的产品。马斯克在 1 月份第四季度财报中表示，中型 SUV 是全球最受欢迎的车型，市场对 Model Y 的需求可能会超过 Model 3。

而中国市场对于 Model Y 来说则更重要。只要看看蔚来、小鹏、威马这些新造车势力不约而同地在这个细分市场布局产品，大抵也能推断出中型 SUV 对中国车企而言的重要意义。而到 2020 年，随着奥迪 e-tron、捷豹 I-PACE、奔驰 EQC 以及宝马 iX3 等豪华品牌重磅车型的陆续上市，将与 Model Y 形成正面竞争。

从价格上来看，Model Y 的竞争优势十分明显。更先进的电池技术，容量更高，单位成本能效更高，价格上会占上风。

  

## 不再重演「量产地狱」？

在特斯拉最近的一次财报电话会议上，马斯克表示，「Model Y 和 Model 3 在构成上具有 76% 的一致性」。相比来看，Model X 和 Model S 只有 30% 的地方是一样的，这也是导致 Model X 交付延后的主要原因。

到了 Model 3 这里，由于本身采取了全新设计（线束总长比 Model S 降低 50%，但小零件的数量大幅增加），但特斯拉却「自大地」过分追求工艺流程的自动化，斥资近 20 亿美元升级为「Dreadnought 0.5」的全自动生产线，但最终产能远不如预期，酿成了令「钢铁侠」头秃的「量产地狱」事件。不过之后特斯拉对整个生产流程进行了优化，据彭博社的线报，目前 Model 3 的产能每周可以达到 5600 辆的水平。

只是遗憾的是，这次发布会马斯克并没有提到 Model Y 的线束问题。「仅 100 米长度的线束」依旧是一个迷。其实从 Model 3 开始，特斯拉就开始使用半导体器件取代线束。这种改变相当于是为总装以及整条生产线实现全面自动化打下了很好的基础。而产能的扩大和提升显然取决于生产的自动化程度。

![](../Images/b10f4ecfeec2b5d87858a3a1411ccab3.png)特斯拉 Model Y 纯电动 SUV

根据马斯克的说法，Model Y 和 Model 3 的总装线紧邻电池和动力总成产线，可以实现无缝衔接，最大程度降低了零部件的运输成本。因此 Model Y 如果没有「划时代的线束创新」，完全可以和 Model 3 一样实现快速投产。  

从这个角度来看，Model Y 的产能爬坡速度应该会比 Model 3 快得多。如果目前 Model 3 的产能已经趋于稳步提升的状态，那 Model Y 跌入「量产地狱」的可能性不大。而且生产和零部件制造工艺的提升能够实现有效的成本节约，特斯拉凭借 Model Y 这款车型有望实现盈利巨大增幅。

![](../Images/2e257238e594fb385beeddd12db17ad6.png)

据极客公园了解的信息，供货美国本土市场的 Model Y 车型将在位于内华达州的超级工厂生产。马斯克此前还表示上海新建的第四座超级工厂将同时投产 Model 3 和 Model Y，其中 Model Y 只供货中国市场。  

Model Y 的诞生可能意味着特斯拉将要走出亏损与盈利边缘。

过去的 2018 年，对特斯拉而言，绝非顺遂的一年。资金短缺、股价波动剧烈、因 Model 3 迟迟无法交付酿成的「量产灾难」……难怪接受 CBS 电视台采访的马斯克一脸的疲惫。

![](../Images/e961d7985d1c7c706ce0962f66dbab9c.png)特斯拉的关键先生：马斯克

都说特斯拉是智能化电动汽车产品的先行者，很大原因在于它将很大的精力投入到了很多前端基础技术的开发上。但自建工厂已经不断扩大公司现金流的压力，在产能以及销量上扬的初期，即便产品具有很强的竞争力，可能盈利面也不会太好看。再加上马斯克「情绪化」的决策，降价、关店等等一系列举动已经让粉丝们很失望，可能会对特斯拉在消费市场建立的「口碑」毁于一旦。

不过随着时间的推移，特斯拉前期进行的技术投入会对整个产品矩阵进行反哺，提升产品核心竞争力的同时也会进一步提高产能，所以之前花在流水线自动化改造上的 20 亿美金其实没有打水漂。如果在此基础上进一步缩减成本开支，将精力集中于产品和技术创新，特斯拉的产品竞争力对 BBA 等豪华品牌产生的压力只会日益剧增。

![](../Images/641def7e934f308fce9786ef3fea8fd0.png)特斯拉 Model Y 纯电动 SUV  

在投资咨询机构 Gerber Kawasaki CEO Ross Gerber 看来，即使客户对特斯拉官方突然降价以及一系列「匪夷所思」的动作很生气，而且也难以预料到还会有怎样的惊喜等着他们，这基本不会对特斯拉的销量造成太大的影响。  

只是，Model Y 也许是特斯拉体验最完整最成熟的一款车型，但它似乎还没有打动消费者的「新卖点」。而在交付之前的这 18 个月里，蔚来、威马、小鹏等新造车势力还将有多款车型上市交付，奥迪、保时捷、奔驰等豪华品牌的多款重磅纯电动车型的也都将陆续上市，Model Y 能否依旧脱颖而出，也许我们需要再等等马斯克的 Twitter 了。
