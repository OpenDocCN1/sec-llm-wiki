# 马斯克的 SEXY 只差一撇，关于 Model Y 我们在期待什么？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652861485&idx=2&sn=8e3b0dee2177890834f557b8d561f077&chksm=7e6a099b491d808da47dbf7c6c72011dd822d9cbeb929648a073b3881ad85adf3b530595f918&scene=126&sessionid=1681310709#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652861485&idx=2&sn=8e3b0dee2177890834f557b8d561f077&chksm=7e6a099b491d808da47dbf7c6c72011dd822d9cbeb929648a073b3881ad85adf3b530595f918&scene=126&sessionid=1681310709#rd)

在三小时后，让媒体吹爆特斯拉的也许不是极致的性能参数，而是 Model Y 在工程架构上的全新变化。

  

![](../Images/f7e869162314435d2da09115c576392b.png)我们对 Model Y 的期待是 Musk 一手打造的。在特斯拉的年度股东大会上，马斯克曾将 Model Y 描述为「something super special.（非常特别的东西）」。在去年五月的公司财报电话会议期间，他说 Model Y 会创造与 Model 3 相似的「a manufacturing revolution（制造业革命）」。

马斯克甚至预言称，Model Y 的全球销量将到达 50 万~100 万辆/年。跨过年销量 100 万辆的大关，成为真正的「主流」，这款产品对于特斯拉的重要性不言而喻。这也是马斯克关于电动汽车普及第三阶段的重要产品。

关于 Model Y 的参数信息马斯克也早已迫不及待的在推文中挤牙膏式的持续透露：Model Y 看起来与 Model 3 类似，但大约要大 10％，而且要贵 10％。与 Model 3 共享大约 75％ 的相同零件（Model X 与 Model S 共享大约 30％的相同零件）。他还证实，它不会有鹰翼门，并且它的续航里程将略低于具有相同电池容量的 Model 3。将于 2020 年底开始量产。

![](../Images/c1fe563bc7a49ed57a4850eba2b159fd.png)

特斯拉官网 Model Y 预告

综合这些信息看来似乎三小时后要发布的产品 Model Y 显得很无聊，但这一定不是马斯克的风格。因为在 Model Y 上对于技术和工程的创新也许才是真正值得关注的亮点。  

回到 2018 年初，马斯克曾在电话会议上说，「我对我们如何设计 Model Y 感到非常兴奋，我们从 Model 3 的生产中取得了很多经验教训，我们将会设计一些易于制造的、能够避免产能地狱的产品。」

在三小时后，让媒体吹爆特斯拉的也许不是极致的性能参数，更有可能是 Model Y 在工程架构的全新变化。「Model Y 的线束会减少到 100 米。」这句两年前吹过的牛，马斯克会在三小时后兑现吗？

![](../Images/a31a66242b0cd86faf54011692b3329d.png)

  

##  Model Y 发布会如果你听到……

#### **1.「Model Y 的线束只有 100 米。」？**

在 2017 年谈及 Model Y 时，马斯克曾表示将在 Model Y 上进行更优化的线缆设计，减轻车辆重量的同时，也让车辆核心部件之间的联通利用率变得更高。

Musk 曾经在电话会议里提到过，Model 3 的线束只有 1.5KM，相比来说，Model S 的线束有 3KM，这是 Model 3 量产爬坡更容易的一个重要因素，但是 Model Y 的线束将会减少到 100 米，并且有消息称 Model Y 将会用到 Space X 的部分技术。

![](../Images/a4162654d4f48bfcd6eaaaf4455ac183.png)

传统汽车线束

从这个表述来看，Model Y 似乎与 Model 3 的工程定位还是有很大的不同。

但当特斯拉因为「Model 3 的全自动化工厂」Dreadnought 花掉 20 亿美元却打了水漂，依旧没能及时摆脱「产能地狱」，当已经几乎确定 Model Y 与 Model 3 共享大约 75％ 的相同零件的时候，马斯克还会兑现它的这句诺言吗？

  

#### **2.「全新的电池组」？**

2019 年 2 月 5 日，特斯拉宣布以 2.18 亿美元每股溢价 55% 收购 Maxwell。Maxwell 是一家超级电容器储能及输电解决方案开发商和制造商。该公司介绍表示，超级电容器和电池能量结合可以降低反应时间，能够更广的温度范围内工作，并可延长电池寿命两倍。Maxwell 的技术或许能够帮助特斯拉电动车实现更快的充放电能力。

![](../Images/7fd18f1fe91537991c92a27d41eb14eb.png)

特斯拉 Model 3 电池组

早在 2018 年特斯拉的年度股东大会上，马斯克曾经提到特斯拉在电池能量密度和成本方面有一些突破性进展，这些突破性进展将会体现到明年开始量产的 Model Y 上吗？  

  

#### **3.「15 分钟左右充满电。」？**

3 月 7 日，斯拉公司发布了第三代 Supercharger 超级充电桩，全新的「V3 Supercharger」可支持 250kW 的峰值充电功率。在这种充电速度下，Model 3 长续航版在峰值功率环境中，5 分钟所充电量可行驶 75 英里 (约合 120 公里)，等效于高达每小时 1000 英里（约合 1600 公里）的充电速率。

![](../Images/1cd91d932b602639782486312e49ea36.png)

Tesla V3 Supercharger

「结合在途电池预热（On-Route Battery Warmup）的新功能，基于我们的数据测算，V3 超级充电桩将最终减少用户平均充电时间的 50%。」特斯拉表示，第一个测试版的超充站已在旧金山湾区开放，并将于二季度与三季度在全美范围内扩张，第四季度将扩展到欧洲及亚太地区。

![](../Images/eebce959b9e6c636735d71039b4480c0.png)平均充电时间对比

可能会拥有全新架构电池组的 Model Y 也许对「V3 Supercharger」充电桩有着更好的兼容性。2020 年量产之后，V3 充电桩的覆盖度如果足够，「15 分钟左右充满电」也许并不是一个梦想？  

  

#### **4.「拥有完全自动驾驶能力」？**

去年 Q3 财报电话会议中，Elon Musk 提到特斯拉自研的 AutoPilot 3.0 硬件即将在 2019 年一季度量产并部署到新车上，Q4 又确认了这一时间表。

根据官方的说法，AutoPilot 3.0 使用是特斯拉第一次自研的专为自动驾驶设计的芯片，其 AI 性能约是目前 AutoPilot 2.5 版本的 10 倍，每秒可处理的摄像头画面从 200 帧提升至 2000 帧，可以幅度优化自动驾驶的可靠性，号称完全支撑未来「全自动驾驶」所需的计算能力。

![](../Images/2a41606450cd51cc8b634d34a06b09a5.png)特斯拉的感知示意图

搭载了特斯拉自主驾驶芯片的 Model Y 可以说是拥有了「原生」终极版全自动驾驶硬件的一款车型，「完全自动驾驶能力」会是从你提车的那一刻就能享受到的功能吗？

  

#### **5.「Model Y 上有了一个新的设计」？**

在 2008 年发布的 Model S 上我们看到了引领潮流的伸缩式隐藏门把手；在 2012 年发布的 Model X 上我们看到了酷炫又智能的后排「鹰翼门」；在 2016 年发布的 Model 3 上我们看到了极简的大屏和中控设计；难道就因为我们很难在看到特斯拉门店和特斯拉 Model Y 的展车之后，放弃了对 Model Y 有新功能设计的想像？
