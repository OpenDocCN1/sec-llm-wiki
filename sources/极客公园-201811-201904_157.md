# 美国智能家居战事升级，亚马逊和 Google 的下一个战场在哪里？

> eero 像是一管「粘合剂」，它可以让设备之间的协作变得更紧密，也让亚马逊的智能家居生态变得更完整。

  

![](../Images/7c7534a3bd1163c72d0a843d40ce3783.png)智能音箱的发源地，美国的智能家居市场，自大厂入局，竞争日渐激烈以来，一刻都没有停止变化过。

2 月 11 日，电商巨头亚马逊宣布（http://t.cn/EcEyibq）收购了 mesh Wi-Fi 界的领头羊之一，eero。据亚马逊官方发布的文章表示，这一收购动作的目的是寻求将路由器技术和自己已有的智能家居产品进行整合，使用户可以更方便地将自己的智能设备连接到网络并接入语音助手 Alexa。亚马逊的意图很明显，要在 Echo 智能音箱和 Ring 智能门铃之后，继续扩大自己在智能家居领域的布局。

  

## 智能家居的基础设施

eero 的主打产品是 mesh Wi-Fi 路由器，一种「用多个路由器硬件节点，组成一个完整 Wi-Fi 网络」的系统。

这个产品类型对大部分中国人来说可能有些陌生。对住在公寓里的我们来说，一个路由器的信号就能轻松覆盖整个房屋，即使是面积大一点的公寓，用上发射功率更大的路由器也可以轻松解决信号覆盖的问题。但对住在独栋别墅里的西方人来说，事情没有那么简单。发射功率的限制决定了单个路由器的信号很难完美覆盖一整栋别墅，这个时候很多人的做法是「架设多个路由器，将它们分别连上网线，接入互联网」，来解决联网的需求。这是完全可行的，虽然很多时候他们需要手动断开信号差的 Wi-Fi，再去选择距离自己更近，信号更好的 Wi-Fi。

![](../Images/26207e71a1e1f316701003b76659f652.png)

但 Wi-Fi 不只是被用来连接互联网，它还是智能家居系统里最重要基础设施。智能家居需要互相连接、沟通，需要一个统一的「数据集散中心」来接收指令，发送信息，各自为政的多个路由器没法承载智能家居的需要，所以就需要 mesh Wi-Fi 的 帮助。  

用户可以将 mesh Wi-Fi 看作多个独立的路由器，但它们之间「具备某种协调工作的机制」，在设置了 mesh Wi-Fi 的房子里，你只需要将网线插进一个主 Wi-Fi 里，然后副 Wi-Fi 会自动中继、传播主 Wi-Fi 的信号，你也只能搜到一个统一的网络信号。当用户下达一个复杂的场景指令，比如「开电视、空调温度调节，灯光色温调节」时，这个指令会被发送到 mesh 路由器的主路由器，分发至各个副路由器，再发送房屋里的各个设备上。

相比于已经趋近饱和的 PC 和手机，智能家居是一片有着巨大市场潜力且亟待开发的蓝海。智能音箱 Echo 的成功更是增加了亚马逊在「家庭」这个场景下的存在感。这次收购 eero，是它进一步切入消费硬件领域的一个重要契机，只不过它的身边，还有不少对手。

  

## 愈演愈烈的战争

一套完整的智能家居系统，有三个重要的组成部分。首先是智能设备，从最基本的灯和空调，到电动窗帘、恒温器、空气净化器、加湿器。其次是环境传感器，温湿度传感器、门窗传感器、人体运动传感器，以及能够感知声音接受指令的智能音箱。最后，设备和传感器之间需要有一套网络基础设施和系统来将它们协调起来，需要路由器，大的房子需要 mesh 路由器，需要通信协议和系统。

在做路由器，以及整个智能家居系统这件事上，亚马逊最大的对手是苹果和谷歌。

![](../Images/fb823f4519f2a04216a3974a86d0ad35.png)

苹果做路由器的历史比谷歌和亚马逊长得多，早在 21 世纪之前，苹果就发布了自己的 AirPort 路由器。但在 2018 年，苹果最终为自己的路由器产品线画上了一个句号。因为在苹果的 HomeKit 智能家居体系内，路由器并不重要。所有的 HomeKit 设备都听命于一个中枢设备，这个设备可以是 iPad、HomePod 或 Apple TV。苹果所有的指令都是端到端的，在 iPhone 上发送一个「开灯」的指令，这个指令会被加密，经苹果的服务器传到 HomeKit 的中枢设备，最后传到对应的灯上。这种「必须走苹果的服务器」、「必须加密」的设计，保证了 HomeKit 用户可以自己掌控自己的隐私数据，也决定了从路由器上是收集不到任何相关数据的。这也就意味着，虽然苹果和亚马逊在智能家居市场有着激烈的竞争关系，但它们走的其实是完全不同的两条路。  

但谷歌和亚马逊「练」的，几乎是同一本秘籍，它们的系统机制和苹果完全不一样。Alexa 和 Google Assistant 对智能家居接入的管理要宽松很多。比如用户用的是小米的智能灯，他也可以将这个灯接入 Alexa。这个时候当他对 Alexa 说「请开灯」，这条指令会先到达亚马逊的服务器，然后由亚马逊的服务器到达小米的服务器，然后由小米的服务器发送到本地路由器，再发送到小米的智能灯上。Google Assistant 的逻辑也基本类似，在这套系统里，最重要的节点有两个，一个是聆听指令的智能语音助手，另一个就是所有数据进出都必须经过的路由器。其中智能语音助手是「收集指令」的中枢，路由器是「发布指令」的中枢。

![](../Images/ff8e115cb4c1260895af4d4571048da7.png)

这一切系统机制上的高度相似，驱使着谷歌和亚马逊之间的智能家居战争愈演愈烈，最终出现了两家连续几年在 CES 上的「大战」，它们非常迫切地要让自己的语音助手进入更多的第三方设备。两家都试图建立起一套从上到下的完整生态，才有了现在语音助手 Alexa 对上 Google Assistant，智能音箱 Echo 对上 Google Home，智能家居设备 Ring 对上 Nest，电视盒子 Fire TV 对上 Chromecast，到现在，智能路由器 eero 对上 Google Wi-Fi 的激烈战况。  

  

## 最后一招

无论是对亚马逊还是谷歌来说，路由器产品都是「收集数据」的绝佳工具。

据 CNBC 报道（http://t.cn/Efj490z），即使根据谷歌现在的用户隐私条款，它无法获知用户通过这些路由器「具体访问了什么网站」，但大部分路由器的隐私条款都允许制造商获知「有哪些设备连接到了路由器」。所以在收购 eero 之后，亚马逊大概率可以去统计，现在安装了 eero 路由器的家庭里，有多少电脑、多少手机、多少智能家居设备，以及它们的具体品牌、型号。

对作为零售商的亚马逊来说，路由器简直是一个绝佳的市场调研工具。我们完全可以想象，在智能家居高度普及的未来，当 eero 路由器发现你家里还没有智能冰箱，或你家的智能微波炉已经服役多年，这个数据被亚马逊的后台捕捉之后，它就可以在网站上推荐你购买最新款的相关产品。

如果说针对企业的 AWS 云服务让亚马逊能够洞悉企业的需求，那么 eero 路由器则很可能会成为亚马逊感知消费端市场风向的一个「探针」。这是亚马逊这门生意最关键的燃料，了解消费者需要什么，然后把他们需要的东西卖给他们。

![](../Images/619845088dd1ce8b58540f14128e9599.png)

对于已经卖出了几百万台 Echo 智能音箱，已经将 Alexa 植入进大量第三方设备的亚马逊来说，eero 像是一管「粘合剂」，它可以让这些设备之间的协作变得更紧密，也让亚马逊的智能家居生态变得更完整。这一场跟谷歌你来我往的军备竞赛已经持续了几年，随着整个智能家居市场的发展，也将最终进入决胜的阶段。
