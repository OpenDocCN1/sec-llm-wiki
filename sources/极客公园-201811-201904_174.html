苦等三年，特斯拉 Model 3 终于登陆中国

特斯拉在中国市场正努力加速，而 Model 3 的到来无疑是一针强心剂。


特斯拉 Model 3 正式进入了中国市场。2 月 12 日，装载着首批交付 Model 3 的滚装船抵达天津港，十天后，首次踏上中国土地的 Model 3 在北京开启交付，6 位消费者成为中国市场第一批 Model 3 车主。

其中一位杭州车主称，他订车的日期正是 2016 年 3 月 31 日 Model 3 的发布当天，距今已接近三年，这也是最早一批预订 Model 3 的人。另一位车主上午取到车后，表示下午要开着这辆 Model 3 回到上海，以便路上体验 Model 3 的续航等性能。

现场交付的五台车中有两台为高性能全轮驱动版，三台为长续航全轮驱动版。第六辆 Model 3 则使用了特斯拉的最新交付服务，特意到家。

首批 Model 3 车主

没错，和之前特斯拉其他车型交付情况不同的是，没时间去提车的车主可以享受到一项新服务：特意到家。特斯拉全球副总裁任宇翔称，在满足条件、双方同意的情况下，特斯拉员工可将新车直接送到消费者指定的接车地点。自今日起，中国车主便可以选择「特意到家」交付模式来接收自己的 Model 3。

除了服务意识的提高，这种交付模式也提供了新的思路，在大规模交付车辆的情况下，使用何种形式能够更好让消费者和车企双方得到最优的解决方案是需要车企重新思考的问题。然而，对于人员没有增长的特斯拉中国区而言，这项服务也带来一定的人工方面压力。

特斯拉全球副总裁任宇翔

目前，中国在售的 Model 3 车型有三款：Model 3 长续航后驱版、Model 3 长续航全轮驱动版和 Model 3 高性能全轮驱动版。售价分别为 43.3 万、49.9 万和 56 万元。

特斯拉从 2017 年中开始在北美地区交付 Model 3，并计划于 2018 年下半年进入欧洲市场。由于产能问题，直到 2019 年 2 月初，第一批 Model 3 才抵达欧洲，与亚洲同步进行交付。中国也成为了亚洲首个交付 Model 3 的国家。

接下来几个月内，特斯拉将在两地进行大规模交付。据悉，截至 2019 年 1 月，Model 3 在欧洲的订单已达到 1.4 万台，而特斯拉预计每周将有 3000 辆 Model 3 到达。

相比之下，中国的情况就没有那么确定。2019 年 3 月 1 日之后，中美的关税问题尚未明确，这也是特斯拉需要面对的大问题。因此，很大一批特斯拉 Model 3 需要赶在 3 月 1 日征收关税的最后期限之前抵达中国。

据悉，由美国生产的 Model 3 分为三批运往中国，第二艘船已于今日凌晨抵达上海港。最后一艘正驶向天津港，预计 2 月 24 日凌晨抵达。

「我们的汽车进入中国市场的成本很高，有进口税、运输费等等。我们在美国国内的劳动力成本已经偏高，而且我们也未曾获得任何电动汽车的税收减免，」特斯拉 CEO 伊隆马斯克在一月份的时候说道。

根据特斯拉 2018 年年报显示，特斯拉全年在中国地区的收入为 17.57 亿美元，同比下降 15.4%。根据全国乘用车市场信息联席会的数据显示，第三季度特斯拉在华销量下滑 37%，10 月份暴跌 70%，销量跌至仅 211 辆。面对订单需求的持续问题，特斯拉 CEO 伊隆马斯克在特斯拉 2018 年第四季度财报发布时说，「人们对于 Model3 的需求是非常高的，主要的问题在于价格是否具有优势，因为人们真是没有钱买这个车，这跟需求无关，只跟价格有关。如果价格能进一步降低，需求会极大。」

针对 Model 3 在中国的交付，特斯拉也拿出了较大的诚意。先是一再降价，后期还推出「春节大礼包」将汽车上搭载最重要的功能之一——辅助驾驶 Autopilot 改为免费，相当于为车主节省了 4.6 万元。一系列迹象说明，特斯拉在中国市场正努力加速，而 Model 3 的到来无疑是一针强心剂。

不过，特斯拉的优势在于对产能的把控已基本稳定，在产量上可以保证消费者的需求。像 iPhone 对中国手机产业的深远影响一样，这个被频频定义为「iPhone 4」那样影响深远的 Model 3 也才刚刚完成中国的第一步，未来中国工厂建成之后，Model 3 的杀手锏也许才会真正释放，从这个角度来看，「围剿」特斯拉的国产新能源车企们已经开始面临着强劲的竞争了。
