极客博物馆 vol.27：如果用生命力来衡量一款手机的经典程度，那么 HTC HD2 一定能挤进前十。有着「刷机神器」称号的它，不仅仅拥有超多 Android ROM 可选，跨系统刷机才是它真正的魅力。

有那么一些已经老去的产品，它们也许早已淡出人们的视线，但每每想到却令我们充满回忆。作为极客之选（微信号 GeekChoice）怀旧栏目，《极客博物馆》希望找到这些曾经带给我们惊喜和感动的产品，带你重拾它们迷人的特质。



极客博物馆栏目两个月前曾经写过一期「硬核」智能手表 Moto ACTV 的文章，一位网友留言希望能看到有关 HTC HD2 的内容。本期极客博物馆我们就满足这位网友的愿望，让我们来聊一聊「刷机神器」——HTC HD2。

HTC HD2 的完整型号是 HTC Touch HD2，研发代号为 LEO，在某些论坛大家也习惯用这个代号。这款 HTC 在 2009 年发布的机型，本身预装的是 Windows Mobile 6.5 操作系统，因为各种机缘巧合，它成为传奇一般的刷机神器。实际上关于这篇文章，我个人有相当多跟 HD2 有关的故事，但碍于篇幅还是决定以回顾的形式，来全面了解一下这款颇具传奇色彩的手机。


为什么 HD2 能刷这么多系统？

想要了解这款手机，就必须从它最大的特点——刷机开始。在前文中已经提到了 HTC HD2 官方预装的系统是 Windows Mobile 6.5，但在各路大神的努力下它成功运行了 WindowsPhone 7、Ubuntu（Touch）、Linux、Firefox、MeeGo、Sailfish 等，不过最受欢迎的系统肯定还是 Android，这其中叫得上的名字的就有 CyanogenMod、MIUI、HTC Sense、Flyme 等等，剩下大大小小各种魔改版、自制版更是数不数胜。

为什么一款 2009 年发布的 Windows Mobile 机型能刷入这么多系统？这个事儿就要从 HTC 泄露了 HD2 的底层驱动说起，这也为运行其他系统提供了基础。其实这和厂商适配新系统是一个道理，之所以 Google 每次发布 Android 新版系统后，厂商们都要过一段时间才会推送升级，就是因为厂商要做驱动适配、兼容性以及稳定性测试，这也是 Project Treble 出现的原因。

简单点说，这个原理就像是 PC 上的「黑苹果」一样，假如能够找到对应的驱动程序，任何 PC 或者笔记本电脑都可以基本完美地运行 mac OS。

除了底层驱动以外，HTC HD2 的硬件规格在当时绝对是实打实的旗舰机，高通 QSD8250 芯片的 CPU 主频能够达到 1GHz，同时它还拥有 448MB RAM。这样的规格对于 Andriod 系统来说绰绰有余，强大的硬件配置也是能够移植系统的基础之一。

有了底层驱动和强力硬件两个先决条件，一位来自俄罗斯 ID 为 Cotulla 的技术大神则编写了 MAGLDR 引导程序，随后 Recovery 则成功移植到 HD2 上。在有了底层驱动和 Recovery 的基础上，安装 Android 系统的难度就降低了很多，因为 MAGLDR 的存在也让 WP7 和其他系统移植提供了先决条件。

在后期 NativeSD 技术出现后，HTC HD2 甚至可以完成多系统共存，在不用刷机的情况下，切换 ROM。当然这一切，除了技术大神的无私奉献以外，对于用户来讲也有一定的门槛，起码要有一定的理论知识基础，好在 HD2 并不是那么容易「变砖」，只要能够进到三色屏，HTC HD2 基本上都能通过重新注入引导程序和 Recovery 成功「救砖」。


「T 版」的 HTC HD2 最受欢迎

之所以有人如此热衷于为 HTC HD2 写引导、做 ROM，其实还是源自于对 HTC HD2 的不甘心，2009 年的 Android 已经积累了一定的人气，但远没有现在和 iOS 平分天下的气势，HTC 仅仅为 HD2 这样一款硬件给力的手机预装了 Windows Mobile 6.5 系统着实有些可惜，虽然当时也有不少人折腾 Windows Mobile 系统，但可玩性远不如 Android。所以不少人是因为觉得这个硬件放在 WM 6.5 上太过「浪费」，才不断地研究能否用上其他系统，而 HTC 泄露底层驱动甚至被看作是有意而为之。

这次极客之选淘到的 HTC HD2 虽然没有全套包装，但整体成色非常不错，而且身为 HTC HD2 老用户的我可以看出这款 HD2 绝非是翻新机，这一点着实难能可贵。因为 HD2 在当时水货市场中非常受欢迎，出货量也不小，同时也因为刷机 ROM 非常丰富，生命周期也相当的长，所以当时不少无良商家就做起了翻新的勾当。

HTC HD2 拥有一块 4.3 英寸 WVGA（480*800 像素）电容屏，之所以特别注明电容屏幕是因为 2009 年前后仍然有一些厂商还会推出搭载电阻屏的产品。Wi-Fi、蓝牙、GPS、支持 MicroSD 卡扩展这些也算是保证了配置上不落伍，唯一有些遗憾的可能就是没有前置摄像头，不过在那个 3G 还没有普及的年代，前置摄像头并不算在标配的行列。

尽管那时还没有「全面屏」的概念，但 HTC HD2 的边框控制非常不错，正面屏占比在当时算是非常高的。事实上，「HD」这个名字也正是因为它拥有 4.3 英寸的巨屏，在那个 iPhone 还是 3.5 英寸，Android 机型 3.7 英寸屏幕是主流的时代，用巨屏这个词并不显得过分。当时我作为用户都在思考「这个屏幕这么大，这应该是手机屏幕尺寸的极限了吧？」但现在的事儿不用我多说你们也都知道了。

HTC HD2 背面采用了三段式的设计，上下两部分采用了类肤质涂层，手感摸起来非常不错，但如果不带壳「裸奔」的话，时间长了表面的涂层很容易磨损脱落。

因为 HTC HD2 采用了可更换电池的设计，所以其背面中间部分的后盖是可以拆卸，后盖为金属材质，一些奸商翻新过的 HD2 采用的都不是原厂后盖，所以经过一段时间的使用掉漆情况也同样明显。


很多用户在选购 HTC HD2 时会犹豫版本的选择，在当时市面上一共有 3 个版本，中国行货使用的是「多普达」的品牌，型号为 T8585；另外两个版本都使用的是 HTC 品牌，所谓的「HTC 版」同现在的公开版是一个概念；另外还有一个「T 版」，该版本是美国运营商 T-Mobile 的定制版本，这也是相对更受欢迎的一个版本。

在外观上，多普达 T8585 和 HTC HD2 除了 logo 标识不同以外并没有什么差别。T 版的 HTC HD2 则在机身长度上稍稍长了 1.5mm，接听和挂断键分别采用了绿色和红色（HTC 版按键均为白色），听筒下方也多了「T-Mobile」的 logo。


CM、MIUI 和 HTC Sense 最受欢迎  

在前文中就已经说过了，HTC HD2 最大的魅力就是拥有非常多的系统可选，Android 的 ROM 数量占据了 90%，剩下的 WindowsPhone 系统也有一些，其他的就相对小众，大多数基本上是体验一下，或者抱着尝试的态度刷一刷。

之前所说的 T 版 HD2 最受欢迎是因为这个版本在刷机上有天然的优势。公开版本的 HTC HD2 采用了 448MB RAM+512MB ROM 的内存组合，而 T 版的 HTC HD2 则采用了 576MB RAM+1GB ROM 的内存组合。

RAM 上多出 100 多兆也许以现在的眼光来看不算什么，但 20% 的提升在当时也不容忽视。最重要的是，拥有 1GB ROM 的 T 版 HD2 拥有更多 ROM 选择，不依靠「A2SD+」技术就能直接刷入完整的 ROM，公开版的 HD2 则经常需要精简一些系统组件或者是挂载在 MicroSD 卡上，这不仅仅增加了刷机的复杂程度，也同时对存储卡的速度有一定要求。

对于大多数用户来说，MIUI 和 CM7 是相对稳妥的选择，稳定性、流畅度都是 ok 的。极客之选手中这台就是 T 版的 HTC HD2，刷入的是 CM7 系统，事实上直到 CM10 系统，HD2 也是拥有 CyanogenMod 官方支持的，Android 6.0 下 HTC HD2 的流畅度依旧不错。至于技术大神的移植版，直到 Android 7.0 都是有 ROM 发布的，但体验比较一般。

对于我个人来讲，MIUI 是最为喜欢的 ROM，因为 Android 2.X 的时代，Android 系统虽然大部分功能性应用已经补全，但原生系统的体验确实还有很大不足，并且几乎没有本地化可言。相比之下，MIUI 无论是在 UI 交互、功能性、稳定性以及本地化上都有着相当不错的口碑，更新速度以及新功能的添加也非常及时。实际上，那段时间也是 MIUI 迅速积累口碑和用户的关键期。

对于 HTC Sense UI 青睐有加的用户，他们也会选择选择刷 HTC 风格的 ROM，因为硬件的相似性，HTC HD2 的体验和 HTC G7(Desire) 并没有太大差别，但在价格上却有着较大的优势。

对于 WindowsPhone 系统而言，大多数用户其实是为了尝鲜，但 WP 系统对于硬件的需求很低，即使到了后期的 WP7.5 和 WP8 系统，HTC HD2 都能非常流畅的运行，而且远胜于 Android 系统。不过因为省电优化以及软件资源的问题，如果想用 HD2 当做主力机使用，大多数人还是会选择 Android 系统。


有缺陷，但无可替代

和众多产品一样，HTC HD2 并非完美，而且通病还不少。在这其中最被熟知的可能就是「虚焊门」，和所有虚焊机型一样，在高温情况下主板上某些芯片会出现虚焊情况，会直接导致手机关机，在降温之后才能正常开机。

真正解决这个问题则需要将手机拆机，把虚焊的芯片取下之后再重新焊在主板上，虚焊问题在当时的「中标」率非常的高，无论是 T 版还是公开版的 HD2 都会出现这个问题。这个问题其实很容易分辨，假如使用手机录制视频能够连续录制 15 分钟以上视频不死机，基本上就证明这款手机没有虚焊问题。在 HTC HD2 火爆的那几年，市场上很多二手货都有这个问题，并且这个问题对于 HTC 本身来说也造成了一定的信任危机。

另外，HTC HD2 的电池触点因为设计上的缺陷，也容易出现问题，用户如果发现突然某一天无法开机，那么很可能不是手机坏了，也不是刷成砖了，而是电池的触点没有连接到电池上。

HTC HD2 的屏幕触控以及按键也都是问题高发地带，如果说触控问题是因为底层驱动或者其他一些原因造成的，但按键就要归咎于厂商的设计问题了，因为 HTC HD2 使用的是常规的物理按键，又没有独立的电源键，所以锁屏和解锁都要通过挂机键实现，长时间的使用之后按键非常容易失灵，这也是用户很常见的问题之一。

尽管 HTC HD2 有很多的不足甚至是缺陷，但由于机缘巧合它成为了独一无二的存在。在 Android 2.X 的时代，刷机是非常多用户的选择，通过刷机能够获得更出色的体验、更酷炫的功能。

HTC HD2 不仅仅拥有超多的 Android ROM 可选，原生的 Windows Mobile、Windows Phone、Ubuntu、Firefox 等超多系统的选择更是让它成为了当时极客精神的代表之一。HTC HD2 不仅见证了 Android 阵营的迅速崛起，更见证了其他系统的没落，它更像是一个时代的代名词。
