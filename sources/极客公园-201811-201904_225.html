极客公园 InnoAwards 2018 年度产品设计奖：OPPO Find X


2010 年 9 月，极客公园发布了第一期「中国互联网创新产品评选（InnoAwards）」。

设立这个评选的原因是，我们坚持以科技、商业与人为关注核心，从创新、技术、用户体验和效率提高等方面进行评选，找出过去一年里中国互联网最优秀的产品和团队。

今年，当我们尝试选择一款产品来代表 2018 年的最佳设计的过程中，有一款产品成为了显而易见的选择，这就是最终得到极客公园 InnoAwards 2018 年度产品设计奖的 OPPO Find X。

本文我们就一起聊聊关于这款手机设计背后的一些故事。


始于全面屏，高于全面屏

2018 年是智能手机在设计上百花齐放的一年。

面对全面屏设计和功能性（主要是前置摄像头）之间的矛盾，手机厂商在过去的一年里尝试了众多解决方案，推出了多种形态各异的全面屏手机，而 Find X 就是其中视觉效果最惊艳的。

在 Find X 上，OPPO 首创了双轨潜望结构，将前置摄像头隐藏在了位于手机顶部的机械结构内，需要时自动弹出，用完后自动归位。一升一降之间，Find X 实现了显示区域没有任何缺口的「真·全面屏」，而 93.8% 的屏占比也是同期最高。

在此基础上，Find X 还将后置双摄模组同样置于升降式机械结构中，从而做到了正反玻璃盖板均没有开孔。

配合手机前后的 3D 曲面玻璃和 3D 叠层流光点彩工艺实现的渐变配色，Find X 实现了宛如「概念机」的一体化极简设计。


3D 结构光和 SuperVOOC 为代表的技术创新

除了设计上的突破，Find X 还是一款在技术上站在巅峰的产品。

Find X 搭载了安卓阵营中第一个真正实现量产的 3D 结构光，在实现安全级别更高的人脸解锁、支付功能的同时，还可以利用 3D 数据完成更加精确和个性的人像美颜。

此外，OPPO 还在 Find X 首发了新一代的闪充技术——最高功率接近 50W 的 SuperVOOC 超级闪充。

SuperVOOC 最早的展示是 2016 年 2 月底的 MWC 上，OPPO 首次对外公开了搭载这一技术的原型机。在之后两年多的时间里，OPPO 对 SuperVOOC 做了大量的改进，最终在 Find X 上拿出了基于串联双电芯方案和电荷泵降压等领先技术的量产版 SuperVOOC。

实际测试中，搭载 SuperVOOC 的 Find X ，35 分左右即可完全充满。

Find X 身上包含的技术创新还有很多。

为了在突破性设计的同时保证体验，在量产 Find X 的过程中，OPPO 的工程师们从内部堆叠、天线设计、供应商选择、生产制造到质量测试，进行了一次全面的重新思考。


创新引领下的 OPPO 手机

站在 2019 年的开头再回看 Find X，除了再次为 OPPO 在这款产品的上付出的努力鼓掌，值得反思的还有创新对于手机行业的价值。

过去的一年对于手机行业来说有些艰难，经过接近 10 年的增长之后，手机行业在 2018 年进入了销量衰退期。不过也正是在这种情况下，创新的价值才会更加凸现。

从 Find X 突破性的设计和首发的 3D 结构光、SuperVOOC 超级闪充，到 R17 Pro 的雾光渐变玻璃和可变光圈，再到打造 VOOC 闪充开放生态、全新的 ColorOS 6 和 Breeno 智能语音助理，在 2018 年，OPPO 用一次次的技术创新提升着产品的竞争力，同时也引领着行业前进。

在这些创新中，Find X 是最亮眼的那一个。不过可以预见的是，随着 OPPO 持续对外传递出强大的创新能力，Find X 很可能只是 OPPO「未来旗舰」的一个开始。
