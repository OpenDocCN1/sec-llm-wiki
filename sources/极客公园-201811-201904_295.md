**小鹏汽车**  

年轻人的第一台智能汽车到底是什么样子？拥有互联网基因的纯电 SUV 小鹏 G3 将在现场为你解答！

**VPhoto**

科技创新如何赋能影像行业？全球即时影像共享服务平台 VPhoto，携最新的影像黑科技——即时影像协作解决方案终端 VBox 6 亮相 IF Stage，观众还有机会上手体验拍摄！

**Dexta Robotics**

致力于创造虚拟现实中全新交互方式的 Dexta Robotics，将 Dexmo 力反馈手套带到现场，提供自然、直觉的触感，让人亲密地触碰真正的沉浸式虚拟世界。

**科幻科普作家 陈楸帆**

如果你是一位科幻迷，一定不能错过这场关于未来科普教育的思想碰撞，科幻科普作家、传茂文化创始人陈楸帆携手创新企业及全国重点中学提倡科普教育的特级教师带来不同维度的见解。

**站酷**

深耕设计领域十二年、聚集 820 多万设计创意人的站酷，邀请七位站酷推荐设计师、独立创意机构创始人，打造两场「站酷时间」，带来「创业×创新×创作」的背后逻辑和深度思考；开启脑波触动，聊一聊「独立创意机构的生存法则」。

**极客之选**

作为极客公园的内容品牌之一，极客之选聚焦消费电子产品、游戏、科幻影视剧作等方面的内容创作。在 IF Stage 上，极客之选「年度产品评选」如约而至，从「娱乐至上」到「生产力万岁」，2018 年最有料的极客装备即将揭晓。

**Libratone 小鸟音响**

源于丹麦的 Libratone 小鸟音响秉承北欧简约设计及丹麦优质声学基因，现已开发多种创新产品，涵盖了 Wi-Fi 家用无线音响、便携蓝牙音箱、降噪耳机等，自上市以来屡获世界级设计大奖，为当下注重生活品质和精神自由的年轻人带来各式各样优质的音频产品。小鸟音响此次来到 IF19 现场，阐释其如何为用户带来真正的听觉自由主义！

**梦想加**

带你了解未来智能办公场景，体验一个 ID 掌握所有办公资源的高效办公方式。梦想加智效方案总监左梦菲将带来现场宣讲：基于「Single ID」理念，梦想加空间智效体系如何实现办公资源一体化调用管理？智能办公场景如何提升办公与管理效率？梦想加将在现场为你解答。还有两轮锦鲤大奖等你来抽！

**未来事务管理局**

如果你有一台时光机，你要穿越到哪里？时间是神奇的东西，它能带走的似乎永远无法被追赶回来。这次，在 IF Stage 上，和未来事务管理局来一场「回到未来」之旅吧！

**轻芒**

通过轻芒小程序+2.0 内容创作者自助即可制作答题小程序，上午出题、下午发布。有多好玩？来 IF Stage 参加答题擂台赛吧。
