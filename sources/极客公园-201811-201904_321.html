红米 Redmi Note 7 体验：999 元起售，4800 万像素能否重新定义千元机拍照？

目前最强的千元机，没有之一。


2013 年 7 月，在第一款小米手机发布两年后，小米正式推出了主打性价比、定价更加低廉的红米手机，第一款产品的售价为 799 元。截止到去年第三季度，红米手机的累计销量达到了 2.78 亿台，成为了国产智能手机里最成功的高性价比手机产品线之一。

今年年初，红米手机从之前小米手机的一个产品序列升级到了独立品牌 Redmi，继续强调性价比，主打线上渠道。

我们今天体验的红米 Redmi Note 7（以下称为红米 Note 7）就是红米手机品牌独立后的第一款产品，除了熟悉的「便宜量又足」，在这款起售价仅为 999 元的产品上，红米手机还首发了 4800 万像素的新一代相机传感器，并且直接提供了 18 个月的超长质保。

下面我们一起来看一下这款新机。


水滴屏，渐变色玻璃，USB-C

红米 Note 7 采用了 6.3 英寸的「水滴屏」，相比同价位更常见的「刘海屏」，「水滴屏」对视觉的干扰要小一些（当然这个因人而异）。

在屏幕四周边框的控制上，红米 Note 7 做得也不错，虽然算不上同价位最窄，不过也已经很窄了，特别是左右边框。

屏幕素质上，红米 Note 7 的这块 19.5:9 分辨率 2340×1080 的 LCD 面板表现也还不错，亮度（后续的系统更新中会加入强光下「鸡血」亮度模式）足够，色彩还原稍偏冷艳，系统设置中提供了标准、屏幕增强、智能环境适应三种模式可选，智能环境适应模式下可以额外手动调节色温。

后盖部分，和前几天发布的小米 Play 不同，红米 Note 7 的后盖不仅用上了渐变色（亮黑配色除外），而且用的是实打实的康宁大猩猩五代，和正面玻璃盖板相同。

我们这台是暮光金版本，真机有点像小米 8 青春版，上方偏紫，底部则偏红一些，很有辨识度。

在后盖的下方，可以看到全新的 Redmi 标志，和之前红米手机后盖上的 MI 标志形成了明显的区分。


红米 Note 7 的中框部分是塑料材质，不过表面做了亮面处理，只要你不是像我这样特意盯着开孔处看，视觉上甚至是手感上都不太能感知到「塑料味」。

在屏幕和中框的衔接处，红米 Note 7 采用了「悬浮屏」设计，屏幕四周有一圈较厚的塑料框包边，塑料框高出中框大概 1 毫米，这种设计可以在视觉上降低红米 Note 7 的厚度。

在红米 Note 7 顶部的边框上，可以看到一个久违的 3.5 毫米耳机插孔（此处应该有掌声）以及一个千元机里少见的红外发射器，可以用来遥控家电。

在底部，可以看到一个千元机里也不那么常见的 USB-C 口，USB-C 口的右侧开孔里是扬声器。值得一提的是，虽然是底部单扬声器，但红米 Note 7 的外放表现还不错，音量大，人声清晰，比同价位不少连响都听不出来的外放要好不少，差不多是两千三千元机型的单扬声器水准。

红米 Note 7 的机身厚度为 8.1 毫米，机身重量为 186 克，在电池容量堆到 4000 毫安时的情况下，这个重量控制得还算不错。在当前动不动就飙到 200 克的智能手机里，红米 Note 7 已经算得上「轻巧」了。


骁龙 660，4000 毫安时，「快充」

红米 Note 7 采用的 SoC 是骁龙 660，最高主频 2.2 GHz 的「满血版」。


骁龙 660 的规格这里我们就不重复了（之前已经重复太多遍了），虽然「年纪」有点大，不过放到现在，骁龙 660 的性能满足日常使用还是没啥压力的，王者荣耀还可以基本满帧跑，「吃鸡」的话则要把画质调低点来保证流畅度了。


配合 4000 毫安时的大电池，红米 Note 7 有着非常出色的续航，足够坚持一整天甚至是更久的重度使用。

此外，红米 Note 7 还支持 18W 的快充，不过出于成本考虑，红米 Note 7 标配的充电头是 5V 2A，用户购买手机时可以选择加 10 块钱得到一个零售价 29 元的小米 18W 快充头。


4800 万像素

相机可能是红米 Note 7 的最大卖点，下面我们就重点说说。

红米 Note 7 的前置部分比较常规，1300 万像素，场景识别、HDR、模拟背景虚化、影棚光效等功能一应俱全。

后置部分，红米 Note 7 采用了竖排双摄方案，副摄为 500 万像素的景深头，主摄的像素达到了有点夸张的 4800 万，镜头为 6P 设计，光圈 F1.8。

红米 Note 7 采用的这颗传感器型号是三星的 ISOCELL Bright GM1（以下简称 GM1），它的传感器面积达到了 1/2.0 英寸。不过这是按照 1 英寸等于 16 毫米来算的，按之前手机传感器常见的 1 英寸等于 18 毫米算，GM1 的传感器面积是 1/2.25 英寸，略大于之前常见的「大底」索尼 IMX380（1/2.3 英寸）。

GM1 的物理像素数达到了 4800 万个，每个像素的尺寸为 0.8 微米，不过 GM1 采用的并不是传统的 RGGB Bayer 阵列，而是采用了 Quad Bayer 阵列，好处是可以直接将四颗像素合成一个输出感光能力更好的「大像素」照片，这时候 GM1 就相当于 1200 万像素、单像素 1.6 微米的传感器。如果想要获得更好的解析力，GM1 也可以输出 4800 万的照片，不过由于 GM1 不像索尼 IMX586 那样具备片上重排的能力，无法直接输出 4800 万像素的 RGGB 信息，因此需要在后期进行软件处理才能输出 4800 万像素照片。

从传感器上分析，红米 Note 7 的 4800 万像素最大的意义可能并不是一些用户期待的细节更清晰（虽然 4800 万像素模式下的解析力的确会比 1200 万像素好一点），而是 1200 万像素模式下，可以通过像素四合一提供比 IMX363（1.4 微米）、IMX380（1.55 微米）更大的 1.6 微米的单像素尺寸，带来更好的感光能力。

回到手机上，和荣耀 V20、华为 nova 4 两款采用 IMX586 的机型一样，红米 Note 7 默认模式也是 1200 万像素，4800 万像素需要在专业模式下手动启用。在 4800 万像素模式下，AI 场景识别、HDR 等功能都是不可叠加的，不过红米 Note 7 倒是可以在 4800 万像素模式下进行数码变焦。

除非是某些特别需要解析力的场景（比如需要进行大画幅打印），为了获得最好的成像品质，我们建议大家使用默认的 1200 万像素拍摄，以下样张也均使用输出 1200 万像素照片的自动模式拍摄（打开 AI 和自动 HDR）。

胜负结果并不重要，毕竟 iPhone XS Max、Pixel 3 都是售价数倍于红米 Note 7、成像品质顶级的旗舰机。不过可以看出，在新一代传感器的加成下，红米 Note 7 这款千元机并没有被两款旗舰机甩开太多差距，这在一两年前是很难想象的。

要挑毛病的话，由于骁龙 660 在 ISP 上的限制，红米 Note 7 在 HDR 时可能要多花点时间。此外，由于这毕竟是小米第一次用 GM1 传感器，白平衡偶尔会不太稳定，当然这可以通过之后的更新来优化。

之后，红米 Note 7 还会通过系统更新加入类似小米 8、MIX 3 的手持夜景模式，可以进一步提升夜拍表现，具体更新时间大家可以关注 MIUI 论坛。


999 元起售，18 个月质保

目前智能手机行业普遍的质保期基本都是 12 个月，从千元机到旗舰机都是如此，不过红米 Note 7 打破了这个行业惯例，直接原厂提供了 18 个月质保。


发布会上，小米 CEO 雷军介绍了红米 Note 7 在提升品质上做的一些努力， 包括全接口的放泼溅处理、防护性更好的前后康宁大猩猩 5 玻璃盖板、四角的防跌落处理。雷军表示，正是这些品质上的提升，才让红米敢于在红米 Note 7 上提供更长的 18 个月质保。

红米 Note 7 提供了 3GB+32GB、4GB+64GB、6GB+64GB 三种存储规格可选，支持 Micro SD 卡拓展，售价分别为 999 元、1199 元、1399 元，1 月 15 日开售。

考虑到红米 Note 7 在屏幕、外观、性能、续航等方面全面的表现，再加上成像素质提升明显的新一代 4800 万像素传感器和目前独一份的 18 个月质保，这个定价我们实在没啥可以说的了。红米 Note 7 是目前最强的千元机，没有之一。

最后，雷军还在发布会上透露，红米将会在春节后发布一款定位稍高的红米 Note 7 Pro。这款产品将采用索尼 IMX586 传感器，SoC 等配置应该也会有些升级。如果红米 Note 7 还没让你完全满意，可以继续期待下这款产品。
