# 皮克斯，Ed Catmull，和每个人的童年┃IF 2019 封面故事

> 所有关于皮克斯的故事，都会追溯到一个原点，Ed Catmull。  

  

![](../Images/7c7534a3bd1163c72d0a843d40ce3783.png)「还有这个，巴斯光年，这是最酷的玩具。」出发上大学之前，安迪把一整箱的玩具都送给了邦尼。可当他从箱子里掏出牛仔胡迪的时候，他犹豫了。

「打我记事开始，胡迪就是我的好伙伴。它勇敢，就像牛仔一样，善良，聪明，但它真正特别的地方，是它从来不会放弃你。不论如何，它永远都会那儿支持着你。」

《玩具总动员 3》上映时，影院里的观众哭得像群孩子，他们已经分不清这话说的究竟是胡迪，还是皮克斯自己。

从《玩具总动员》上映开始，皮克斯已经收获了十九座奥斯卡奖杯。除此以外，还有二百多个奖项，二百多个提名，每每人们聊起当下最成功的动画工作室时，皮克斯不仅是一个绕不开的名字，很大程度上，它就是「最成功」本身。

我们同样也绕不开那些皮克斯讲过的故事。超人一家的家长里短，麦昆和板牙的风驰电掣，尼莫和多莉的海底世界，瓦力和伊娃的太空漫游……哦，对了，你一定记得，《怪兽电力公司》里，头号吓人怪兽萨利文面对人类孩子时笨拙的温柔与善良，《飞屋环游记》里，没来得及和老伴儿一起去世界尽头的卡尔，还有《寻梦环游记》里，最终在冥界相遇的白发老人可可，和她尚未被遗忘的黑发爸爸埃克托。

你一定记得这些故事，你一定忘不了过去这么些年里，皮克斯在银幕前带给你的无数感动。

可你又是否知道，为了让怪物萨利文的 2320413 根毛发看起来栩栩如生，皮克斯如何突破了数量的限制和阴影的投射技术？你是否知道，为了让卡尔的房子飞起来，皮克斯如何完美解决了 CG 世界的重力问题？你是否知道，换了导演的皮克斯如何把《玩具总动员》的故事讲得一个比一个精彩？你是否知道，技术公司出身的皮克斯，如何变成了一家动画工作室，又是如何在引领行业技术革新的二十多年后，成为了一家因欢乐和感动为人们所铭记的创新公司？

所有关于皮克斯的故事，都会追溯到一个原点，Ed Catmull，改变动画行业的技术先驱，创新组织皮克斯和迪士尼动画的掌门人，陪伴皮克斯最久的创始人。

2019 年，Ed Catmull 将正式从皮克斯和迪士尼退休。在那之前，他将来到极客公园创新大会的舞台，首次和中国观众分享他和皮克斯近三十年的创新故事。

在 IF2019，你将从这个站在技术和艺术交叉口的人那里，听到你想知道的，有关皮克斯的一切。
