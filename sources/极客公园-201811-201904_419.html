科技行动派们，你有一封来自拉斯维加斯的邀请函

这是每一年你必须关注的科技盛会，我们想邀请你共同见证。

如果说每年九月的苹果发布会以精巧、细致和个性化内容成为「科技春晚」，那么年初举办的 CES 则像是科技界的盛大运动会。

每年，这场拉斯维加斯举办的盛会都聚集着全球最知名的科技企业、创业团队、极客人群，这里从不缺少让人兴奋的技术创想。从 50 多年前的盒式磁带，40 多年前的电子计算机，到 30 多年前的无线电话，20 多年前的电视机......这里为科技历史打上了重要注脚。

但和柏林的 IFA、巴塞罗那的 MWC 不同，拉斯维加斯举办的 CES 从来不止于单一领域，在即将到来的 2019 年这一变化更加明显：5G 网络到来、AI 场景纵深化、混合现实技术继续延伸、自动驾驶加速向前...... 令人兴奋的技术点一个接着一个，但事实上，让人尖叫的远不止如此。

极客公园从很早开始就关注 CES 展会，并且连续几年奔赴前线，因为我们明白，当科技浪潮到来，只是站在岸上旁观远远不够，没人愿意错过科技的变革。

2018 年开始，极客公园开始举办极客之夜活动，「极客之夜」是 GeekPark IF 海外专场。在这里，科技圈最具代表的科技领袖、精英极客将展开一场高密度的思维碰撞，共同解读全球科技局势，预测产业方向。我们希望在每年 IF 大会到来之前，在拉斯维加斯寻找最具潜力的行业变革者，寻找最有可能的科技推动力量，同时，我们也希望为世界传递更多中国力量的声音。

在极客之夜的舞台，极客间的交流从来没有局限，从计算机技术到物联网，从人工智能到自动驾驶，从大数据到虚拟现实，关注社会各个角落的科技企业汇聚于此，中国科技的声音也因此传递，东西方思想在这里碰撞出火花，进而释放出更大价值，在这里我们关注所有最前沿的话题：

- 除了网速更快，5G 时代的变革还会如何？

- 当「流量信仰」转向「数据信仰」，互联网下半场的战场聚焦在哪里？

- 独角兽企业在 2018 年纷纷融资上市，资本与技术的结合该如何更有效率的发挥作用？

- 当人们对无人驾驶技术的期待趋于理性，哪些场景的应用会率先成熟？

关于这些问题，我们请到了优秀的科技精英代表，包括科大讯飞执行总裁胡郁、顺为资本投资合伙人周航、美团无人配送部总经理夏华夏等，请他们来聊聊这些问题的答案。此外，众多 CES 2019 参展厂商和国内外最优秀科技媒体也将参与其中，这会是你和他们面对面线下交流的最佳时刻。

除此之外，极客之夜上我们会公布「焦点 30：CES 上最不容错过的科技创新公司」，帮助你高效捕捉 CES 最值得关注的科技企业，及时洞察最前沿的行业趋势。对于将要前往拉斯维加斯的你来说，极客之夜绝对会是行程中不可错过的重要内容。开年第一站，我们在拉斯维加斯等你。

目前极客公园已经开始了 GeekPark IF@CES 2019 极客之夜筹备，扫描下方二维码或点击「阅读原文」即可参与报名，我们期待能在世界级舞台上见到更多中国科技力量，倾听中国创新思想的声音。
