# 十年前，它是国产智能机的骄傲 | 极客博物馆

> 极客博物馆 vol.45：精致的外观，简洁好用的系统以及对产品不妥协的坚持，为十年前初出茅庐的魅族 M8 赢得了「国产机皇」、「国产智能机最强」的名号，也为魅族打下了手机领域的一片江山。

有那么一些已经老去的产品，它们也许早已淡出人们的视线，但每每想到却令我们充满回忆。作为极客之选（微信号 GeekChoice）怀旧栏目，《极客博物馆》希望找到这些曾经带给我们惊喜和感动的产品，带你重拾它们迷人的特质。

* * *

  
![](../Images/a45f456d57e3f0ae02ac1da88b6de497.png)「打磨」、「梦想」、「工匠精神」，提到这些你会想到哪个品牌？  

在国内手机江湖，能把它们放在一起形成独特气质的，或许非魅族莫属。这个诞生在珠海，以 MP3 起家的小厂商，用短短四年时间登顶国内 MP3 播放器第一的宝座，之后毅然转型手机领域并迅速获得成功堪称传奇，本期极客博物馆，我们就和大家回顾魅族手机迈出的第一步 —— 魅族 M8。

魅族 M8 是黄章「打磨」的第一台智能手机，也是魅族首次试水手机产品，在 M8 之前，魅族被用户熟知的是其经典的 MP3 系列，而当大洋彼岸的乔帮主带着 iPhone 打开变革时代的大门时，黄章敏感察觉到功能机遍地的洪荒时代即将结束，于是在 2009 年带着魅族 M8 登场，这成为国内第一款大屏幕全触控智能机，无论是在硬件设计还是软件系统上，这台机器都对之后的国产品牌产生了不小影响。

  

## 魅族设计的开端

熟悉魅族的人，或多或少都曾被其独特的工业设计所吸引，早在 MP3 时代，魅族就带来了不少令人难忘的设计，无论是可自助更换多彩外壳的魅族 ME，还是触摸屏外加无螺丝设计的魅族 miniPlayer，都采用了当时极为少见的设计，也曾引领一时风潮。

![](../Images/8b8c771f6d49632017136adda132f9cc.png)

这种对设计的追求延续到了魅族 M8 这款手机上，形成了最早的魅族手机设计语言。需要注意的是，早期 M8 在电路设计上出现问题，造成过触摸失灵的情况，之后推出了优化电路设计的版本 M8SE，外观和 M8 基本无异，极客之选本次拿到的就是魅族 M8SE，为了方便说明，我们简称其为 M8.

拿起 M8，首先映入眼帘的是它 3.4 英寸的 TFT 电容触控屏，有着 480×720 的分辨率，PPI 达到 255，虽然现在看显得小巧可爱，不过在当时，无论是尺寸还是分辨率，这块屏幕在市面上都可以算得上是顶级，即便一年之后的 iPhone 3G，3.5 英寸屏幕分辨率还只有 320×480，可以说魅族在手机屏幕这个「面子工程」上就下了很大功夫。

屏幕上方，听筒部位被设计成三个小点，下方的 Home 键则被设计成了腰圆按键，内嵌有魅族 M 型 Logo，这两个独特元素加上围绕在正面的金属边框，形成了属于 M8 的独特设计语言，很有辨识度。

![](../Images/6e62d7d538a0878a00e79abb286c4396.png)

产品背面，M8 采用了钢琴烤漆工艺的塑料材质，容易粘指纹但是手感顺滑。正中偏上位置 MEIZU Logo 再次表明这是一台魅族产品，Logo 下则是可拆卸的电池后盖，只要轻轻滑动就能打开更换电池，M8 的电池电量有 1300mAh，在当时可不算小。

不止是外观，魅族 M8 的整体配置在当时也是数一数二，处理器上采用了来自三星的 CPU，频率为 667Mhz，在当时算得上是很强了，机身内存 256MB，内置存储有 8GB 和 16GB，这些配置对于当时的用户来说也非常有吸引力。

另外，作为以 MP3 起家的品牌，魅族 M8 的音乐效果也很值得一提，它的外放在如今的智能手机中也算的上优秀，而且由于内部扬声器设计的很合理，所以无论正面还是背面放在桌上，M8 的外放效果都很好。

  

## 国产定制系统的原点

简洁好看的外观为魅族 M8 赚到了大量人气，在 iPhone 还未正式进入国内的 2009 年，这款手机颇有先见之明地预见了智能手机的未来，但不仅是外观设计，魅族 M8 在系统上的出色真正让国内手机厂商看到了智能手机的新时代。

![](../Images/fed9db90938c296f568bcd8a64ecd0a9.png)

打开 M8 上手把玩，如果不告诉你，或许你很容易把它当作一台安卓系统手机，无论是锁屏界面还是系统 UI 设计，都透出浓浓的国产安卓定制系统的感觉。但其实在产品研发的 2006 年，安卓还未登场，彼时可供魅族选择的系统并不多，市面上最主流，有一定生态基础的就是微软的 Windows CE 和 Windows Mobile 系统，魅族最终选择了 Windows CE 为内核。

走出 Windows CE 的一步对魅族非常重要，因为同样来自微软，Windows CE 系统不仅授权费用更低，同时可定制化程度也更高，这意味着魅族一开始上手并不容易，但一旦有针对性进行了全方位的改造，打造出有自身特色的实用系统，对之后的迭代将会积累大量经验，M8 上诞生的这套兼具设计美感和实用性的系统，也能看出黄章当年在 M8 上耗费的心血。

比如锁屏界面，通过在电话、解锁、短信三个部位向上滑动，能够快速进入对应的模块，类似的快捷操作直到 iOS 7 时代的 iPhone 才加入支持。再比如打开锁屏，能看到主要的电话和短信放在最下方，如果按住中间或者向上滑，就能够呼出页面编辑功能，快速调整、删除 App，或者加入桌面插件。

![](../Images/6335cee0eb6bf8de39a7b4be2fcfec4a.png)

再比如多任务系统，对于 QQ、MSN 这样的联网应用，按下 Home 键后不会退出，而是会在后台继续运行，而不联网的词典、电子书等，按下 Home 键则会被关闭，在当时，M8 后台可以同时运行多个程序依然流畅，也可以看出对系统优化下了不少功夫。

尽管同样采用拟物化设计，但 M8 在 App 图标设计上并没有 iOS 那样的统一外壳，而是尽量展现出不同 App 各自的特色。得益于对系统的重新设计，这些精心设计的图标并不杂乱，反而很方便寻找想要的内容，而诸如音乐播放器中的滑动查看歌词，锁屏界面双击 Home 调整音乐播放等功能，都做的实用且有趣。

  

## 它曾是国产机骄傲

从细节上把复杂的功能隐藏起来，但又能随时取用，这种关于系统平衡的思考贯穿在 M8 这套 Windows CE 定制系统的每一个环节，也因此一面世便获得了不少好评，微软总部橱窗内至今展示着魅族 M8，凭借这款机器，魅族也实现了两个月销量十万部的记录，对于初出茅庐的手机界新人，这样的成绩算是开了个好头。

![](../Images/78d542ad96108d4594522db3670dce58.png)图自百度百科

不过 M8 的故事到这里没有结束，因为外观问题，乔布斯认为魅族的设计窃取了苹果的创意和知识产权，因此发售一年后，黄章表示 M8 将停止生产。这件事也为魅族敲响了警钟，在此后从 Windows CE 平台转到 Android 平台的基础上，在传承自己系统交互核心之后，魅族更改外观推出了魅族 M9，这为魅族之后多年在安卓阵营的地位打下了基础。

魅族 M8 的定制化系统不但为自身转战 Android 平台奠定了基础，也在很大程度上影响到之后一众国产智能手机的系统设计，大家熟悉的雷军，在创办小米之前就曾向黄章取经，之后发布的小米手机，其成功的重要原因就在于定制化的 MIUI 系统。可以说，在智能手机起步早期，魅族就是国内智能手机的老师。

精致的外观，简洁好用的系统以及对产品不妥协的坚持，为十年前初出茅庐的魅族 M8 赢得了「国产机皇」、「国产智能机最强」的名号，也为其打下了手机领域的一片江山。如今十年过去，竞争激烈的手机市场，作为老兵的魅族却已不似当年神勇，有人说前人栽树后人乘凉，当系统方面优势不再，老兵也许就该退场，但回想曾经的 M8，不正是靠着魅族的不妥协才化不可能为可能吗？江东子弟多才俊，卷土重来未可知。也许等待合适的机会，魅族依然会带来意想不到的产品。
