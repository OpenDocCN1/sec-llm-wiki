## 万达体育正式登陆美国纳斯达克

7 月 26 日，万达体育正式登陆美国纳斯达克。本次 IPO 发行价为 8 美元，将发售 2380 万股 ADS，低于原计划的 2,800 万股，筹资金额为 1.904 亿美元。作为体育运动推广商，万达体育总部位于北京，此次上市资产主要包括盈方体育传媒集团、世界铁人公司 (WEH) 以及万达体育中国公司 (WSC)。

![](../Images/b68f621d74c1321d92faabe096436d8f.png)         

据公开信息，2016 年至 2018 年，万达体育营收分别为 8.77 亿欧元、9.55 亿欧元和 11.29 亿欧元。2016 年，万达体育亏损 2920 万欧元，2017 年利润为 7880 万欧元，2018 年利润为 5400 万欧元，今年一季度亏损 863.6 万欧元。（来源：界面）

  

## 搜狗成立新融资担保公司

7 月 26 日，据启信宝消息，一家名为「汕头市赢众百富融资担保有限公司」（以下简称「赢众百富」）的公司于 24 日注册，该公司由北京搜狗科技发展有限公司（以下简称「搜狗科技发展」）全资持有。

搜狗科技发展旗下并非一家金融公司，启信宝显示还包括全资持有的搜狗（汕头）保险经纪公司和搜狗（汕头）小额贷款有限公司。由搜狗汕头开发的「一点分期」应用于 2018 年年度上线。对于为何成立这家新公司，搜狗方面并未回复。（来源：钛媒体）

## 沃尔玛牵手 Gatik 推行自动驾驶试点项目，为客户配送订单

近日，沃尔玛宣布和 Gatik 建立合作试点项目，Gatik 是一家 B2B 短途物流无人驾驶技术创企，成立时间已达两年，沃尔玛将选择阿肯色州本顿维市的几家商店，让其通过无人驾驶面包车为客户配送订单。几个月前，阿肯色州立法机构已经通过了沃尔玛的提议，这将使得企业能在公路和高速公路上测试自己的无人驾驶汽车。（来源：猎云网）

  

## 滴滴与日本航空 JAL 联合提供跨境出行服务

7 月 26 日，滴滴宣布携手日本航空株式会社（JAL）展开高品质商旅出行服务合作。此次合作由滴滴旗下高端出行品牌滴滴豪华车、以及滴滴日本，共同与 JAL 展开跨界尝试，整合各自网约车、航空资源，实现跨境出行、空地联运的无缝衔接。

滴滴在去年 6 月与软银公司成立了合资公司滴滴日本，旅客可在日本打开滴滴出行大中华版 App 直接呼叫出租车，现已开通东京、大阪、京都、兵库县、北海道、福冈和广岛等主要地区。（来源：techweb）

  

## SpaceX 星际飞船成功进行首次自由悬浮测试

特斯拉 CEO 埃隆·马斯克（Elon Musk）旗下太空探索技术公司 SpaceX 7 月 26 日对其未来的星际飞船原型 StarHopper（「星虫」）进行了首次自由悬浮测试。

![](../Images/793d3be18c02fa0ede4bb1aed9020043.png)         

StarHopper 是 SpaceX 建造的大型客运火箭，旨在测试 SpaceX 计划中的星际飞船（Starship）和超重型航天器的关键技术，包括 SpaceX 为未来的深空火箭开发的新型 Raptor 引擎。据马斯克称，星际飞船被设计为一次最多可搭载 100 人，将成为 SpaceX 最终前往月球和火星旅行的首选航天器。（来源：虎嗅）

## 腾讯云进军日本市场，今年国际化目标收入增 5 倍

7 月 26 日，腾讯云宣布正式进入日本市场，为日本企业提供一站式云服务。腾讯云副总裁答治茜表示，国际化是腾讯云的重要战略，2019 年腾讯云国际化业务的目标是收入同比增长 4~5 倍。

答治茜指出，日本市场的成熟度很高、游戏产业全球领先，而腾讯在海外的服务经历了多个爆款游戏的检验，包括《PUBG Mobile》、《热血江湖》等，如今，腾讯云已经与日本市场的部分客户达成合作意向，其合作伙伴包括日本游戏公司 Pitaya、日本 IT 公司 E-business 等。（来源：环球网）

## Python 之父考虑重构 Python 解释器

7 月 26 日，Python 之父吉多·范罗苏姆发表一篇名为《PEG Parser》的文章，范罗苏姆表示，他正考虑使用 PEG Parser 代替现有的类 LL(1) Parser（名为 pgen），来重构 Python 解释器。

![](../Images/9e2e3e6d376cb57471a1fc3db6ea423c.png)         

范罗苏姆称现在的 pgen 限制了 Python 语法的自由度，使得一些语法难以实现，也让当前的语法树不够整洁，一定程度上影响了语法树的表意，不能最好地体现设计者的意图。范罗苏姆表示，用 PEG Parser 重构 Python 解释器不会造成语法上的影响，因为底层重构不会影响 Python 语法。（来源：IT 之家）

## 香港联交所将收紧借壳上市规定，上市公司易手后 3 年內不得出售业务

7 月 26 日，港交所发布公告称，将修订有关借壳上市活动的规定，新规将于 10 月 1 日生效。有关借壳上市、持续上市准则及其他《上市规则》条文修订的谘询文件刊发谘询总结。依据谘询总结，修订后，将限制发行人不得在控制权变动之时或其后 36 个月內，建议将其全部或大部分原有业务出售或作实物配发。联交所也可限制发行人不得在实际控制权转手之时或其后 36 个月內，进行有关出售或作实物配发。（来源：全天候科技）

## 因美国对克里米亚的制裁，GitHub 当地账号被限制

GameHub 项目的维护者 Anatoliy Kashkin 发出警告，因美国对克里米亚的制裁，GitHub 限制了他这位生活在克里米亚的居民的账号，他可能无法继续维护 GameHub。在俄罗斯与乌克兰交战以及克里米亚脱离乌克兰之后，国际社会对克里米亚进行了制裁。

Kashkin 称他收到通知，「由于美国贸易管制法律，你的 GitHub 账号已被限制。对于个人账号，你被限制只能访问免费的公开库用于个人通过。」

![](../Images/9638cbd3ea8817758a11dff36ae37cc1.png)         

Kashkin 解释说，GitHub 限制他创建私有库，关闭了现有的私有库，可以创建公开的库但不能删除。他表示自行托管单一的 git 库的意义不大，毕竟很多人是在 GitHub 上发现 GameHub 的，GameHub 提供了很多有用的社交功能。 （来源：solidot）
