Facebook 终于揭开了他们期待已久的数字货币平台 Libra 的神秘面纱。

他们发布了一份白皮书，一个测试网以及阐述了他们的数字钱包 Calibra。这一消息在加密货币领域和主流媒体上引起了轩然大波，记者们争相报道相关细节。

几乎加密货币领域的每一位杰出人士都在消息公布后立即发表了意见。人们最初的反应是谨慎乐观的态度。

大多数人，包括我在内，一开始都认为 Libra 对于加密货币领域来说有利，尽管 Libra 与开放的、无需许可的加密货币 (比如 Ethereum、Radix、Monero、Zcash 和 Bitcoin 等) 毫无关系。几乎所有人都觉得 Libra 将会提高人们的加密货币意识，让普通人习惯于使用无国界的货币，并提升糟糕的用户体验。

立法者们的反应与他们对其他任何不了解的新兴技术的反应一样，充满了恐惧。众议院金融服务委员会 (House Financial Services Committee) 主席、众议员 Maxine Waters 呼吁 Facebook 停止 Libra 项目的开发。政府想要确保的是没有任何一家科技初创企业敢于威胁他们随意贬值货币的权力。

甚至专注于加密货币的律师也加入了进来，质疑 Libra 的合法性。

但随着下意识反应的到来，更详细、更细致的分析开始出现。一开始，我以为自己可以置身事外。大家都在评论，还有什么可说的呢？有很多媒体都在进行报道，我来得太晚了。

但是，我越深入研究这些评论和热门话题，就越意识到有多少人忽略了这一重大声明所带来的真正威胁和可能性。人们可能已经记下了该项目的技术细节，但却没能从整个全局进行看待。

毫无疑问，不管你喜不喜欢 Libra，它的宣布都是影响力巨大的。

几年前，大公司发行加密货币的想法是会让人觉得忍俊不禁的，更不用说由大型跨国公司 (包括 Visa 和 MasterCard 等旧世界金融体系的中坚力量) 组成的财团发行加密货币了。

但 Libra 要做的比发行加密货币更宏大。这是货币史上的一个转折点。

Libra 是一场旧金融世界秩序的灭顶之灾。当历史学家回顾历史时，他们可能会把这一时刻视为这场变革的催化剂。

但是未来是什么样子的呢？它将带来怎样的影响呢？

我们是在奔向金融复兴，还是在奔向 William Gibson 在其著作中描述的由寡头巨型企业带来的赛博朋克噩梦?

为了找到答案，我做了我一直在做的事情，首先一头扎进去，开始阅读资料和倾听他人的看法。我联系了社区里所有的人，请他们把能找到的最好的文章发给我，我阅读了 Facebook 的白皮书和该公司宣传材料。

我发现了什么呢？

跟我来，我要向你们展示一个崭新的数字货币世界，以及一场在行业巨头和现代世界庞大的民族国家之间的全面战争。


睁大双眼，迎接明日的帝国

首先，虽然我会直言不讳地表达出我对 Libra 的厌恶，但我也绝对不会避重就轻。

仅仅因为我讨厌 Libra 的很多方面，并不意味着它没有很多值得去喜欢的地方。

通过密切关注 Facebook 想要做什么，加密货币社区可以从中学到很多东西。

Facebook 提供了加密货币发展所需的 5 个关键要素中的 3 个，即规模、分布和杀手级应用。仅这一点就足以征服这个已知的世界。

他们还从一些最好的项目中提取了更多的创新。

我们将从用户体验开始。让我们面对现实吧，加密货币的用户体验是非常糟糕的。加密货币应用程序几乎普遍不佳，普通人无法使用。即便对于工程师们来说，它们也很难使用。相比之下，Netscape (美国网景公司) 浏览器的早期版本都看起来更好。

未来的加密货币 App 绝不是像当前这样的情况：你前往一家交易所，注册，然后登入，验证你的账户，进行 KYC 审查，进行法币电汇，购买一些加密货币，下载安全一个钱包...

对普通人来说，这是行不通的。试试说服你的妈妈进入加密货币领域，如果你能在两周内完成，你就是个天才。这绝不是推动加密货币得以全球采用的途径。

如果没有更好的用户体验，加密货币甚至无法使用。

2017 年，我指出微信 (WeChat) 及其无处不在的移动消息传递平台将是未来的界面。许多大型加密项目的构建者都得出了相同的结论。我们看到 Status 筹集了 1 亿美元；Telegram 私下筹集了 17 亿美元，用于打造下一代区块链通讯和移动货币平台；Kik 团队也看到了移动端 P2P 资金和聊天应用的相同愿景。

但 Facebook 凭借其巨大的全球影响力、雄厚的财力和一个由企业巨头组成的财团抢先了一步。一些企业巨头都是 Libra 协会的创始成员，其中包括 Visa、万事达 (MasterCard)、Stripe、Paypal、Lyft、Ebay、Uber、Vodaphone，还有 Andreessen Horowitz 等风投巨头。

正如亚马逊有能力借助其资本、技术和与大大小小的书商的联系，成就了他们的 Kindle 电子书阅读器平台，Facebook 联合金融&技术领域的巨头们也有能力创建一个可以推向数十亿用户的平台。

在应用界面层面，Facebook 知道如何建立受欢迎的社交媒体平台，他们的 WhatsApp 聊天客户端是世界上使用最广泛的应用之一，Instagram 也是千禧世代的标准社交媒体应用。

Facebook 的 Calibra 钱包将会很轻易地整合到 WhatsApp、Messenger 以及 Facebook 应用中。从下图可以看出，该钱包已经看起来非常简单易用，其用户界面也设计得简洁美观。

Calibra 钱包界面

加密货币领域的每个项目都应该从 ICO 筹得的资金中抽出一部分来聘用个优秀的 UI/UX 开发团队。否则 Libra 将成为你们平台的灭顶之灾。如果你们的应用不易使用，那就会见光死。

Libra 的杀手级应用已经有了。

让我们继续讨论 Libra 的规模、商业模式，以及这场由诸多跨国公司带来的权力游戏。

很多作者指出，Libra 的共识系统看起来很像权益证明 (PoS)。但更准确地说，它的功能更类似于代理权益证明 (DPoS)，DPoS 因 EOS 等平台而被推广开来。Libra 的共识系统是一个基于 HotStuff 的拜占庭容错系统，而 HotStuff 是一个由 VMware Research、康奈尔大学 (Cornell University) 和北卡罗来纳大学教堂山分校 (UNC Chapel Hill) 的研究人员开发的共识系统。基本上，Lirba 系统将拥有一群大型的验证者节点，这些节点在 Libra 区块链网络中处理交易；如果有节点试图欺骗系统，那就面临损失资金的风险。

代理权益证明 (DPoS) 是当前最快的共识系统之一，可以扩展到每秒处理上千笔交易，而当前比特币每秒只能处理 7 笔左右，以太坊也只能处理约 15 笔。

当然，这些大型的 Libra 协会成员企业 (比如 Visa 和 Mastercard 等) 都需要各支付 1,000 万美元才能拥有成为 Libra 区块链网络中的验证者特权。

他们为什么支付这笔巨额资金呢？

因为他们将会赚很多钱。

这就是 Libra 项目的商业计划的重点。Facebook 为 Libra 网络的验证者建立了一个杀手级的商业模型。在其他企业为 Libra 生态系统开发一款应用程序之前，他们会先把钱赚个盆满钵满。

与其他有着固定的货币供应且随着时间推移而慢慢发行的加密货币不同，Libra 币会随着资金进入到该系统中而得以创建或销毁。如果你使用 50 美元兑换成 Libra 币，那等值的一定量 Libra 币就会被铸造出来。如果你从系统中取走美元，那相应的 Libra 币也会被销毁。

一些作者指出，这与 IMF 的特别提款权 (SDR) 相类似，但 Libra 的这种方式比 SDR 更具优势，而且能走得更远。实际上，Libra 是一种跨越国界的天才设计。

它是这样工作的。Libra 拥有法定货币储备。这将为验证者提供一个很好的 ROI (投资回报率)。随着人们将法币换成 Libra 币，法币将从世界各地流入该储备中。这些验证者可以使用这些钱进行投资、交换和用于交易。如果他们在传统的银行系统中持有这些钱，那么仅仅产生的利息就足以使他们最初投入的 1,000 万美元看起来九牛一毛。

换句话说，Libra 网络的验证者 (节点) 将独占这些利息，而你什么也得不到。

你持有的 Libra 币也不会像其他加密货币那样升值，因此你不会得到收益或者获取新的价值。这是因为 Libra 币是旨在保持价格稳定的，它不会像比特币或者其他通货紧缩的币那样波动，因为 Libra 与一篮子法定货币 (比如日元、欧元、英镑等) 相挂钩，这意味着 Libra 币继承了央行的通胀货币政策。

不仅如此，Libra 并不是一个带有稳定币的区块链平台这么简单。实际上，Libra 甚至不是一个区块链平台，尽管他们在白皮书中反复使用这个术语。Libra 就是一个打着区块链旗帜的联邦数据库(federated database)。

白皮书中阐述道：

「Libra 区块链是一个使用 Libra 协议进行维护的加密认证数据库。该数据库存储着一个可编程资源 (比如 Libra 币) 的账本。资源遵循其声明模块指定的自定义规则，该模块也存储在该数据库中。」

Libra 还有自己的智能合同语言 Move，该语言看起来很强大，旨在避免早期智能合约系统面临的安全问题。但即便是第一种智能合约实现语言 Rust 也是一个很好的选择，因为 Rust 非常强调代码的安全，不会像其他的语言那样面临很多安全问题。

「凭借其『安全的代码』，该编程语言 (即 Rust) 将从头至尾地管理其对象。开发者不需要像在 C 或 C++ 程序中那样进行指针运算 (pointer arithmetic) 或管理内存。」

但不管 Libra 是不是区块链，不管其是否使用新的智能合约语言，Libar 所要构建的都是一个完整的平台，这才是最重要的，这也是加密货币社区在零碎地构建未来时所缺少的。

这里的「平台 (platform)」是一个关键词。Libra 平台能够像一个排练良好的管弦乐队那样十分和谐地运行。

除了依靠大量的法币储备来获取利息，Libra 网络的验证者还将开发运行在该系统上的 App 和程序，以及提供商品和服务。换句话说，该网络也是一个买卖东西的地方。

这使得 Libra 成为一个集稳定币、安全的智能合约可编程资源管理者、消息传递系统和电子商务平台于一体的平台。

电子商务是其中不可或缺的组成部分。如果没有电子商务，Libra 就只拥有垄断的货币，却无处可花；这就是为什么大多数加密货币仍然是投机者的宠儿，但几乎没有人使用加密货币购买咖啡或者 Playstations 游戏机的原因。

如果加密项目想要获取真正的吸引力，并与这个大型平台相竞争，那这些项目就需要明智地建立一个真正的商业模式，就像 Facebook 所做的那样。如果你没有地方花钱，凭空赚钱 (投机) 是不够的。

你需要一个界面、治理模式、货币以及能够买卖的东西，所有这些需要融入了一个盛大的生态系统中。


荷兰东印度公司的回归

这将我们带向了 Libra 币产生的一个最有趣的附带影响。

凭借一个完整的生态系统及其拥有的快速推动 Facebook 数十亿用户采用的能力，Libra 将成为第一个真正挑战由国家支持的货币主权、传统的银行体系、以及国家在印制和分配货币的权利。

那些没有加入 Libra 财团的实体将会如同那些已经加入其中的实体一样有趣。

当前没有银行加入了该财团。

如果任何银行与该协会存在后台交易，那将会很有趣。该协会的成员将会在银行存储大量的资金，而银行将想要知道这些资金流的来源。

将 Libra 与一篮子货币相挂钩也饶是有趣。通过将 Libra 币与其他一些法币相挂钩，他们其实已经开始了让我们的世界走向抛弃美元作为默认的世界货币的道路。

与这种观点相对立的是，有些人认为 Libra 实际上可能一劳永逸地巩固美元作为世界货币的地位。

也许这就是为什么很多监管机构正在密切关注 Libra 的原因。货币是巩固中央权威的终极手段，政府是不会不战而降地将这种权利让渡出去的，即便是让渡给那些支持这种全新货币的大量企业。

这是一场加密货币社区一直都认为会到来，但至今从未真正有能力赢得胜利的战争。到目前为止，所有的加密货币项目都是一场下层社会的反叛，使用游击战术，保持匿名并不断扩散，但如果国家把索伦之眼转向他们，他们就没有多少机会能够对抗国家的真正力量。[备注：索伦之眼出自英国作家托尔金的奇幻小说《魔界》中，是黑暗魔君索伦的标志。]

在某种程度上，Facebook 帮了加密货币社区一个大忙。

他们将会把战斗从较小的项目和比特币转移到一个更传统的敌人 (即 Libra 协会)，这个敌人有着自上而下的分级结构，政府对这个敌人非常了解，没有什么比砍掉「蛇头」更让各个国家喜欢的了。

但这不是一场容易的战斗。

它是一个资金充足、实力强大的对手。世界各国政府面对的不是 eGold，而是现代版的荷兰和英国东印度公司 (the Dutch and British East India companies)。唯一缺少的是他们没有自己的公司军队。Libra 协会并不是一个秘密运作的、试图保持自己的 GitHub 在线并使自己的交易所不被敌对的政府关闭的小团体项目，而是一个联盟，一个拥有战争基金的联盟。

Libra 背后的协会有足够的资金和影响力来影响和修改法律。当该平台启动时，随着越来越多的法定货币流入他们的金库，这种力量将随着时间的推移而增长。任何阻挡他们前进道路的国家都将面临一群说客和非政府组织，他们与监管机构对峙，改写法律以对自身有利，或者当其他国家繁荣的时候，让政府损失新的财富。

这就是赛博朋克 (cyberpunk) 活跃起来时候。大型的跨国公司对抗政府的权利。

如果赛博朋克会告诉我们什么，那就是公司最终会赢。

港口天空的颜色，就像调不到频道的电视机屏幕

多年来，我一直警告说，如果加密货币社区不迅速采取行动，大公司和政府就会接受他们的想法，并加以扭曲以适应现状。

现在就是这一时刻。现在参与 Libra 的大公司就在扭曲着加密货币社区坚持的理念。

如果你想要破坏加密货币引发的「货币自由」运动，很简单 [备注：作者是在讽刺 Libra]：

首先，你需要做一些面向大众的企业营销，比如为没有银行账户的人提供银行服务：

「重新发明货币。转变全球经济。这样各地的人们都能过上更好的生活」

——来自 Libra 官网

就像之前百事可乐公司 (Pepsi) 借着过去抗议者的努力的一则广告来让你喝更多含糖的甜可乐一样，Libra 也牵动了我们的心弦，因为所有那些贫穷的第三世界国家的人都没有银行账户，买不到东西。

接下来，你要拉拢旧世界的金融巨头，他们一直在为区块链领域最基本、最明显的理念申请专利，用以起诉他们的全球霸权的任何竞争对手。

之后，使 Libra 币简单易用，这样对于那些不关心隐私保护等细节的人就会对之欣然接受。最后，对用户的密钥进行托管。

这样你就安全地终止了这场加密货币革命了。

Facebook 会帮助你来保管你的私钥，这样你对自己的资金就灭有任何控制权了，就像普通的银行体系一样！

当然，根据其白皮书，他们不会把将你的资金与你的 ID 绑定在一起：

「Libra 区块链遵循匿名原则，允许用户持有一个或多个与他们真实身份无关的地址。」

但我们知道事实并非如此，因为「Calibra 将要求用户在登录时经历透彻的反洗钱 (AML) 和 KYC 过程」。

如果你仔细观察，从字里行间就会发现，这只是白皮书中众多矛盾中的一个。

Libra 最初将是一个许可型系统，之后会「过渡到一个非许可型系统」，但有关他们将如何实现这一小小的壮举并没有给出任何解释。Libra 币不会与我们的 ID 绑定，而是与透彻的「反洗钱」流程相关联。

就像印度「自愿参加的」Aadhaar 身份识别系统，政府接着让 Aadhaar ID 成为开银行账户或持有你的银行账户的必要条件，突然间自愿成为强制性的。很快，公司和政府就会知道你做的每件事，你去的每一个地方，你花的每一笔钱，因为他们会用先进的 AI/ML 算法跟踪你。

如果加密货币爱好者们的梦想是恢复货币的自我主权，那 Libra 可能带来的就是这种梦想的失败。

Libra 协会的各企业采纳了加密货币社区中最好的想法，并通过已知的瓶颈将这些想法安全地反推了回去。

当你进入加密货币领域的时候，也许你认为自己是在为了加密货币未来的希望而贡献一份力？Libra 所需要做的就是花一些耐心和时间，就可以让你从面临的困境中走出来。但你并没有意识到，你只是进入了由这个协会赞助的另一个牢笼。

但希望依然存在。

专有平台往往会走在前面，因为它们可以像 Facebook 那样设计极好的界面，很快扩大规模并投入大量资金。

但最终，开放的平台会迎头赶上。在过去十年里，开源的软件吞噬了专有软件。现在，无论是大数据、云计算还是人工智能，每一项重大创新都始于开源。

开放的项目往往进展缓慢，由反抗「银河帝国」的反叛者和与社会格格不入的人发起。这些项目一开始可能很蹩脚，但最终通过缓慢的演化找到出路，最终战胜专有系统的定向演化。

至少我一直是这样告诉自己的。

虽然事情并不总会这样。

比如 Apple 搭建起来的封闭式花园也出奇地运作良好，使之成为世界上最强大的公司之一。

有时反叛者联盟会在最后一刻撤离，就像电影里一样，有时帝国会赢。

我越看 Libra，就越难以不让自己沮丧。

Libra 包含了加密货币社区想要的一切，包括扩展性、可用性以及由商户和企业借助自身的资金支撑起来的稳健生态系统。他们甚至还会为 Libra 协会的成员企业创建一种Investment Token，这种代币不同于面向普通大众的 Libra 稳定币，而是面向 Libra 协会成员企业的一种通货紧缩式的「管理币」，用于奖励这些企业带来的「寡头治理」。

而这就是我们应该憎恨和恐惧的地方。

通过 Libra，他们能将我们所做的一切活动与我们的身份绑在一起，这样这些公司就知道我们在哪里生活，在哪里购物，和谁是朋友等等，他们可以追踪我们的数字和现实生活，精确到纳秒。他们可以像超人看透墙壁一样看穿我们的钱包，并通过预测分析来看穿我们的过去、现在甚至未来。他们将控制货币的流动并决定其他企业、社区甚至地区的成败。

这对世界来说是一场灾难。

但我们仍然有机会真正摆脱旧世界的金融体系。

Facebook 给了我们一个机会。

让他们的律师来对付惊恐万状的旧世界金融巨头的势力，让他们的游说者制定新法律，让支持或反对他们的国家去建立或破坏这些法律。

现在就是我们的机会。

如果你还没有聘请到你能找到的每一个开发人员和 UX 设计师，没有找到每一个架构师和业务策划者来帮助你制定一个全面的平台和业务计划，那么你需要快速行动。

我们没时间了。

很快就没有市场了，Facebook 就会把你的梦想从你眼前偷走，使之变成一面黑色的镜子。

如果 Libra 是这个领域的最终赢家，并且能够迅速占领世界市场，那么加密货币就辜负了它所倡导的货币自由，未来就会像是调不到频道的电视机屏幕一样。
