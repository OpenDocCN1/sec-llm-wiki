有那么一些已经老去的产品，它们也许早已淡出人们的视线，但每每想到却令我们充满回忆。作为极客之选（微信号 GeekChoice）怀旧栏目，《极客博物馆》希望找到这些曾经带给我们惊喜和感动的产品，带你重拾它们迷人的特质。



本文授权转载自公众号极客之选


2019 年 5 月 10 号，HTC 官方发布了一则简短声明，宣布将关闭京东、天猫网店，消息一出便勾起了很多肠粉的美好回忆，一代枭雄走到今天难免让人唏嘘，但曾几何时，这个品牌也带来过无数经典产品，本期博物馆我们就来聊聊这个你或许再也买不到的品牌 HTC 的一款经典机型 HTC Desire。


手感出色的安卓旗舰

HTC Desire 是 HTC 2010 年推出的旗舰，也是 Desire 系列开篇，在当年有三星 Galaxy S 和 iPhone 4 两个对手竞争的同时，它依然成为一款倍受好评的产品，甚至在背后还有一个大家所不了解的一机双版本的秘密，可以算得上是有故事的手机。


极客之选（公众号 GeekChoice）拿到的是一台美版机器，虽然包装早已不见，但手机整体保存良好，它的金属边框已经掉色，但正面听筒部位以及背部的 Logo 依旧表明了独特身份。


点亮屏幕的一瞬间，通过一块 3.7 英寸，480×800 分辨率的 AMOLED 显示屏，这款手机展现出今天看来都算不错的观感，再加上主频 1GHz 的高通 QSD8250 处理器，它的配置在当时可谓豪华。而且，即便屏幕尺寸比同一年的 iPhone 4 更大，但重量控制上却很出色，只有 135 克，和 iPhone 4 相差无几。

对金属的巧妙运用是 HTC 在这一时期颇为成功的设计，不同于当年另一款旗舰 Galaxy S，HTC Desire 既通过金属+塑料的结合平衡了品质感和手感，在众多机型中，它的手感绝对是一个重要加分项。

实体按键是它的另一特点，包括主页、菜单、导航、返回、搜索等按键都是实体按键，这种「你要什么就给什么」的设计其实代表着安卓在大而全方向上的尝试。


关于 HTC Desire 双版本的秘密其实并不复杂。起初采用三星 AMOLED 显示屏，更好对比度和不错的功耗为其赢得了不错的评价，但由于面板供应不足，产品发售一段时间后转而采用了 S-LCD 面板，这才出现了两种不同屏幕的机器。


对于当时的 HTC 来说，显示面板更换也许算不上什么，毕竟还能找到其它材料来代替，但这在一定程度上让三星看到了机会，加快了在 AMOLED 技术上的探索和运用，看看如今三星在 AMOLED 材料领域呼风唤雨的力量，HTC 无形中成了三星走向成功的引路人。


让人着迷的 HTC Sense UI

除了一流的手感和显示屏之外，HTC Desire 还配备了一颗 500 万像素后置镜头、Micro-USB 充电接口以及可扩展的 SD 卡槽，这些都算是当年安卓的标配，但它其实有一个独门秘技，那就是 HTC Sense。

图自 Android Forums

2009 年，基于在 Windows Mobile 系统上的尝试，HTC 开始对安卓进行改造，通过精简系统，改变主屏幕和键盘设计，添加桌面小部件等方式让安卓系统变得更加流畅好用，于是推出了一款搭载这一全新 UI 的机型 HTC Hero，新界面的出现颇受用户青睐，也由此成为 HTC 手机的标志，这便是 HTC Sense。

HTC Sense UI 在 HTC Hero 上初次登场，图自 HTC

HTC Desire 同样搭载了 HTC Sense，它的整体 UI 在今天看来颇为简单，主页是一个大大的时钟插件，不但可以展示时间还能看到天气，官方甚至精心设计了动画效果，让你一眼就能知道今天要穿什么，所以一下子让手机变得很有逼格，当年身边的小伙伴曾经以它作为一种炫耀，后来国内的墨迹天气等天气类 App 也用了类似的方式表现天气，可见其影响力之大。

另外，通过双指缩放，Sense UI 还可以一步预览所有页面的内容。你既可以为每一页添加不同的小插件展现出个性的使用习惯，也能直接把常用联系人放在桌面。经过 2009、2010 年对 Sense UI 的不断打磨，这个风格独特的系统让安卓系统散发出与众不同的魅力，也推动 HTC 走上了智能手机行业的巅峰。

人们选择 HTC，很大程度上也离不开其美观、易用的 Sense UI，这套系统也通过 HTC 的机海战术，在早期安卓市场大放异彩。可以想见，假如没有 HTC 的努力，安卓系统走到今天或许需要更长时间。

另外，相较于 iOS 的封闭，Sense UI 在当时无疑是强大的，因为它更能让用户感受到个性、自由，HTC Sense 在不断更新中带来了很多出色的创意，比如拿起手机时自动降低铃声音量，再比如将手机翻面朝下时自动静音，这些功能虽然在今天看来已经不再特别，但放到 2010 年的手机市场，它绝对是吸引人投靠安卓阵营的亮点。


廉颇已老

不错的硬件设计，再配上方便好用的软件系统，让 HTC Desire 成为 2010 年安卓阵营的标兵。这款手机让很多人投入安卓怀抱，也由此成为一名「肠粉」，在 HTC 的诸多产品中，它也有着自己独特的意义，而 Desire 这条产品线也由此成为 HTC 一条重要产品线。

如今，当我们回望 2010 年，HTC Desire 这样一款内外兼修的机型依然颇具亮点，在百花齐放、多姿多彩的手机市场，它的表现并不输给 iPhone 4、Galaxy S，只是花开不再，廉颇老矣，激烈的市场竞争下，这个没有及时调整策略的品牌败下阵来，也让这场演出到了谢幕时刻，但曾经的点点滴滴并不会被遗忘，这也许才是它对我们的最大价值。
