> 曾经的垄断者 IE，如今的边缘者 Edge。

![](../Images/0da79c93bc235d7726b099113f9351bb.png)当地时间 5 月 6 日，微软在谷歌的前一天举办了年度 Build 2019 开发者大会，除了微软最最重视的云服务 Azure 以外，外界关注度最高的就是微软翻新的浏览器：Edge。

微软 CEO 萨提亚·纳德拉在会上宣布，基于谷歌 Chromium 开源架构的 Edge 浏览器很快登陆 Android、iOS 和 macOS 等平台，甚至在 Build 2019「Moving the web forward with Microsoft Edge」的会议议程中，还出现了一张疑似微软正在评估 Edge 有望登陆的平台的图片，其中还包含 Linux。￼

![](../Images/da69a467ca76b862e67c6458450f9748.png)

Build 2019 会议议程中展示的图片 | Neowin

同时，微软也演示了许多 Edge 的新功能和新服务，以及 Mac 版 Edge 的首秀。

  

## Edge 的目标

微软这次打造新版 Edge 的目标，简单说，就是把 Edge 翻新打造成为一款多平台、开源、功能齐全的「现代」浏览器。

发布会上主要宣传了新版 Edge 中的三大新功能，其中最值得关注的，就是微软曾经最重要的产品——IE 浏览器，将通过在 Edge 上增加 IE 模式来被间接「复活」。

IE 模式的加入，使得从 2018 年底宣布基于开源的 Chromium 开发的 Edge 融合了原本微软在 IE 软件上几十年来的技术积累，转型为开源，也打破了其开发和兼容上的封闭性。在接受 在 The Verge 的采访中，Edge 开发负责人 Joe Belfiore 表示，Edge 的 IE 模式目标就是做到无缝连接，在 Edge 里，没看到 IE 的经典 e 标的话，用户根本察觉不出用的是 IE 还是 Edge。

尽管互联网与日俱进，但在世界各地的办公企业和社会基本服务中，IE 仍是唯一的选择。Edge 这次推出的「IE 模式」就是把 IE 作为一个「功能」融入到 Edge 里，那些仅仅兼容 IE 浏览器的网页可以在 Edge 中直接打开，同时 Edge 还有更多的功能、更好的官方支持以及更人性化的设计，在「非 IE 打不开」问题解决后，用户便没有理由再选择 IE 这个落伍的浏览器了。

第二个重点功能关注在近年来备受关注的互联网隐私。微软在新版 Edge 上提供了三种隐私模式供用户选择，分别是：不受限模式，网站和浏览器插件可以追踪用户并推送算法给出的广告；平衡模式，用户未访问过的网页，不允许追踪用户数据；严格模式，所有网站、插件和广告都不允许追踪用户。

![](../Images/a09e98d1014c84df689e72b815cc6043.png)三种隐私模式 | Edge 宣传视频截图

此外，新版 Edge 中还加入了一个如同官方插件的功能，Collections。Collections 旨在让用户在信息爆炸的互联网上，通过浏览器的内置功能来收藏、整理、组织、分享信息，Collections 功能还将支持和 Office 联动，比如直接把收藏的文件用 Office 套件打开，收藏的比价数据一键在 Excel 中生成表格，收藏的网页内容直接导入到 Word 中……

![](../Images/8b5b5dd524b31fb0ce8bcc0d67e93b1c.png)Collections 和 Office 联动功能演示 | Edge 宣传视频截图

采用 Chromium 内核的 Edge 也将同 Chrome 一样，支持丰富的扩展插件，目前 Chrome Web Store 中的所有插件都可以安装到 Edge 上，而微软也在推出 Edge 扩展商店。

![](../Images/87c45f9408213fdbb5c63d511a46f206.png)Edge 全面支持 Chrome 插件 | Edge 宣传视频截图

Mac 版的 Edge 也将分为两个版本，面向开发者的 Dev 版和面向普通用户的 Canary 版，尽管还未宣布具体发布时间，但在 Build 2019 大会上微软已经放出了演示动画。

![](../Images/3bf782888e292a01a2eadf523e723848.png)

macOS 版 Edge 预览 | 微软

在 Build 2019 召开前一个月，微软就发布了改用 Chromium 内核后的首个 Edge 大改进版本。在那个 Public Beta 版里，Edge 不仅展现出了类似 Chrome 的设计语言，还改进了对 4K 视频的支持、浏览器安全性、界面布局等多项浏览器产品上的重点功能。

就今天微软发布的新版 Edge 宣传视频而言，多平台、开源内核、功能齐全的 Edge 已经些许展露出一款极具竞争性的浏览器产品的潜力。

  

## 延续 IE，救活 Edge

自从 2015 年 3 月 30 日公开发布第一个预览版以来，Edge 就在 Windows 10 和 Windows 10 Mobile 中正式取代 IE 默认浏览器的地位。曾经一度垄断行业的 IE 也因此走向了历史舞台的边缘。然而此次，微软在 Edge 中不仅仅复活了 IE，同样也救活了 Edge。

Edge 在 2015 年推出后一直不温不火，谷歌的 Chrome 靠着丰富的功能和多年来跨平台的用户积累占据着浏览器的主导，苹果原生的 Safari 则因完美融入苹果系统生态中自得其乐，Firefox 以「中立性」和「可操作性」也保有一席之地，IE 则早就沦为徒有其安装量，但能不用就不用的产品。Edge 推出后也并没有砸出什么水花。在移动互联网环境下，这两款浏览器都「没有姓名」。

![](../Images/8d1024b19cd36a4adfb713f63a87c541.png)Statcounter 2019 年 4 月的全球浏览器使用市场占比 | Statcounter 官网截屏

然而「转芯」后的 Edge 同样也面临着行业领头羊的压力，正如十几年前的浏览器大战中，谷歌对抗 IE 的垄断而推出 Chrome，苹果也曾在面对微软时，为了让微软开发 Mac 版的 Office 套件，不得不把 IE 设置为预设浏览器，而从 2003 年苹果推出 Safari 后，微软和苹果再无浏览器上的开发交集，直至 Edge for Mac 的推出。

在 The Verge 的采访中，Joe Belfiore 提到了 Edge 在去年测试 Chromium 时遇到的困境，尽管在改用内核的过程中，谷歌和微软的工程师们都合力协作，以至于大改版后的 Edge 和 Chrome 非常类似，站在 Chromium 作为一个开源项目和相关社区的角度，谷歌欢迎微软，但站在竞争对手的角度，Chrome 也不得不防着 Edge。在桌面系统上， Chrome OS 和 Windows 的份额占比的差距，要远远大于浏览器市场上，Chrome 超过 IE 的占有率。在未来，Edge 有 Windows 做靠山，Safari 也有 macOS 的全面支持，但 Chrome OS 就像微软曾经挣扎过的 WindowsPhone 一样，看不到抢占市场的希望。

![](../Images/890e88ac41349cc5863956cde736f515.png)Net Marketshare 统计的 2018 年 5 月至 2019 年 4 月全球浏览器使用市场占比 | Net Marketshare 网站截图

在新版 Edge 发布公开预览版后不久，有不少用户反馈称许多谷歌的产品，如 Google Docs、Google Meet、Google Earth 在 Edge 中访问都出现了问题。在 Google Docs 中直接显示「不支持的浏览器」通知，在 Google Earth 中则是网页拒绝访问的状态。对此，谷歌回应称是因新版 Edge 暂为开发预览版，还未添加进 Google 相关网页的白名单，正式版将会被加入到白名单中。

在上个月，在 Firefox 团队曾工作过八年的 Mozilla 前高管也在推特上抨击谷歌，称 Chrome 的广告会出现在「Firefox」的 Google 搜索结果中，谷歌相关网页则把 Firefox 标记为「不兼容」的浏览器。而每次被用户发现后，谷歌都称是意外，会尽快修复，但错误总是会重演。

![](../Images/7e2205790437325d0cdcc17a42916ff9.png)Mozilla 前高管连发数十条「吐槽」谷歌 | Johnathan Nightingale 部分推特截屏

从曾经占据了 90% 的浏览器市场的 Netscape 的垄断，到 IE 作为行业规则的制定者，再到如今的一超多强，浏览器市场竞争随着互联网的普及和使用方式风云变幻。如今的浏览器市场，既离不开巨头，又舍不掉开放。这一互联网基础服务的承载工具，在一次次应用程序的冲击下依旧坚挺，谷歌和苹果都抓住了应用，而微软这个曾经浏览器中的垄断者，早已沦为边缘者，能否再次重回主流赛道，就要看换了芯也不忘旧的 Edge 了。
