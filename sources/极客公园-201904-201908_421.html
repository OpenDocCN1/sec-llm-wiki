微软 Build 大会前瞻：市值万亿的微软有什么新打算？

数字化生活的基础，是无数开发者创造入口。随着技术平台的不断迭代，技术应用带给我们的便利与能力也在不断提升。现在，位于数字时代前沿的美国西海岸，正迎接一年一度的开发者新浪潮——Facebook F8、微软 Build、Google I/O 三大开发者大会先后登场。极客公园将在现场为大家带来最新报道与解读，让我们一起，抢先一步看到未来。


在过去这一年里，股价突破万亿美元、重新登顶全球市值第一的微软为自己的未来准备了哪些宏远的计划？

和 Facebook F8、Google I/O 相比，微软一年一度的开发者大会 Build 就没那么多普通消费者关注了。一方面，Build 大会通常不发布消费级硬件；另一方面，微软近年侧重云和 AI 的业务线，让距离普通用户最近的 Windows 的露出变得更少了。同时，搭上云服务的办公软件 Office 365 也越来越侧重企业端的用户了。

「在萨蒂亚发给员工的第一封邮件里，通篇一千个字，没有提及 Windows。」一位近期离任的资深高管这样评价公司的 CEO，「萨蒂亚的眼里只有云！」太平洋时间 5 月 6 日到 8 日，微软将在西雅图为开发者举行一年一度的 Build 大会，今年依然以萨蒂亚·纳德拉的 Vision Keynote 开场。

Azure 指挥中心 | Bloomberg

会上，微软如何打好云服务这张「新王牌」，又将为 Windows 和 Office 等「翻新业务」讲出怎样的新故事，以及在过去这一年里，股价突破万亿美元、重新登顶全球市值第一的微软又为自己的未来准备了哪些宏远的计划？在北京时间明晚 11 点开始的 Build 大会上，我们或许能找到这些问题的答案。

针对开发者大会可能会发布的内容，极客公园做出了如下的预测，在纳德拉的主题演讲开场前，让我们先来一睹为快吧。


云业务，内容多到要先「剧透」

在微软那份喜人的 2019 Q3 财报（截至 3 月 31 日）中，云业务的季度收入比重已经能和 Office 和 Windows「分庭抗礼」。Q3 微软收入为 306 亿美元，同比增长 14%。和 102 亿美元的 Office 和 107 亿美元的个人计算机（Windows、Xbox、Surface）相比，包括 Azure 在内的智能云业务当季增长 41%，至 96 亿美元。其中，公有云 Azure 表现亮眼，收入飙升了 73%。

根据数据研究机构 Canalys 给出的数据，在 2018 年第四季度，Azure 在云基础设施市场占有 17% 的份额，同比增长 3%。在这个市场拿着最大蛋糕的 AWS 则还是 32%。Stifel Financial 分析师指出，Azure 的增长速度比同样规模时期的 AWS 快。

Azure | Microsoft

Azure 的优势在于是全球唯一覆盖 IaaS、PaaS、SaaS 三大云服务模式的厂商，同时还有为企业服务的四十多年的经验。现在，微软正在通过增强覆盖多领域的 Azure 实力，来不断提升云服务的竞争力。

5 月 2 日，在临近年度开发者大会 Build 开场的时候，微软还率先「剧透」了关于 Azure 的一系列更新，涵盖了 AI、IoT、混合现实、区块链等领域。比如，为 Azure 认知服务新增「决策」（Decision）服务，将 AI 引入 Azure 搜索，简化机器学习过程，发布了 Azure SQL Database Edge 优化低运算需求的场景，还宣布 J. P. 摩根的以太坊（Ethereum）平台 Quorum 成为 Azure 区块链服务中的第一个账本。

当然，这些更新只是微软放出的预告。关于 Azure，微软表示还将在会上带来更多混合云与边缘计算的新特性，在微软将 AI 技术融入各条产品线之后，我们当然也能在这次大会上看到许多 AI 与云计算交叉的新产品和服务。


物联网，从「云端」到「边缘」

2018 年 4 月 4 日，微软宣布在未来的 4 年投入 50 亿美元在物联网领域。2018 年开始，微软发布了包括 Azure Sphere、Azure Digital Twins、Azure IoT Edge 在内的多款产品，其中，Azure Sphere 是专门设计给物联网应用的操作系统。今年 4 月，微软宣布收购物联网实时操作系统（RTOS）和微控制器单元公司 Express Logic。通过这次收购，微软希望将数十亿个物联网终端产品和应用连接到其 Azure 中，同时将 ThreadX RTOS 的实时处理系统整合到 Azure Sphere。

收购 Express Logic | Le Diligent

在会前「剧透」里，微软同样宣布了物联网方面的更新。微软将推出 IoT Plug and Play——一种新的开放式建模语言，开发人员无需编写任何代码。原理是用户可以将几乎任何外围设备插入 Windows PC，而不必担心驱动程序和物联网设备兼容问题，即插即用，无缝接上物联网。可以看出，物联网是微软在云时代加码的重要技术之一。

根据 Gartner 发布的物联网预测报告，到 2021 年智能手机用户只有 38 亿，而物联网设备到 2020 年却将会有 200 亿台，错过智能手机之后，微软显然跟紧了物联网技术普及的脚步。


Windows 和 Office，老产品新应用

从微软公布的会议主题来看，今年的 Build 大会将会涉及 Fluent Design System 的改进、为多种设备创建 UWP 应用程序、Chromium 版 Microsoft Edge 的新进展等内容。

关于 Edge 浏览器，由于微软在上个月发布了测试版的 Chromium 内核版本，因此该浏览器具有一些 Chrome 特性功能，比如平滑滚动、触摸优化、4K 流视频等等。

还有对标 Chrome OS 的 Windows Lite，The Verge 编辑 Tom Warren 称这款轻系统短期内不会公开。

Windows Lite | The Verge

从 2011 年微软发布 Office 365 开始，Office 成为了用户按需订阅的 SaaS 模式。Gartner 的数据显示，在 2016 年，微软的 Office 占了生产力软件市场接近 90% 的市场份额。根据 Visual Capitalist 的估计，微软 Office 以及其云服务收入在 2018 年达到 283 亿美元，占微软总收入的 25.7%。本次 Build 大会，微软也将展现更多关于 Office 365 和 Dynamics 365 的更新。

而在语音助手领域，微软不再把亚马逊和 Google 的语音助手作为直接竞争对手，展现了偏向 B 端用户的倾向。在 CES 2019，微软公布了 Virtual Assistant Solution Accelerator（虚拟助手方案加速器）服务。客户可以根据需要打造属于自己的虚拟助理，比如修改助理的名字、声音、性格等。这个助理自带一些语音交互技能，还能连接微软生产力服务。据 ZDNet 报道，微软承诺在今年的 Build 大会上公布更多关于这位虚拟助手技术的细节和演示。另外，我们还可能在会上看到 Cortana 和 Alexa 集成的最新进展。


其他可能的发布

开源：自纳德拉上任以来，微软逐步走向开源。比如，让 Windows 10 支持 Ubuntu，并且为 Azure 发布了 Linux 和 FreeBSD 版本，通过收购 Xamarin 来帮助开源 .NET 项目等。去年，微软更是以 75 亿美元收购 GitHub。本次 Build 大会，微软或许将公布公司开源的战略和布局。

游戏：Build 是开发者大会，不是消费者硬件发布大会，所以微软不大可能推出无光驱主机 Xbox One S All-Digital Edition。但此前 Google Stadia 和 Apple Arcade 等游戏服务引发热议，兼具游戏和云计算实力的微软可能会因此透露自家云游戏服务 Project xCloud 的相关消息。在今年 3 月的 GDC 大会上，微软展示了开发人员如何为该平台构建游戏等细节。Project xCloud 目前主要面向游戏开发者。在此之前，微软宣布这个服务将支持所有的数字版 Xbox One 游戏。

Project xCloud | Microsoft

混合现实：在今年 2 月的 MWC 2019 上，时隔四年，微软正式发布了新一代 MR 头显 HoloLens 2。会前，微软宣布将推出价值 3500 美元的 HoloLens 2 开发版（约合人民币 23560 元），但目前还没有公布具体发售日期。开发人员购买开发版后，将获得 HoloLens 2、500 美元 Azure 信用额度和与 Azure 关联的混合现实服务。随着 Epic 创始人 Tim Sweeney 宣布支持 HoloLens 2，5 月底之前，虚幻引擎 4 将正式支持 HoloLens 2 的流播放和原生平台集成，开发者可以创建高质量逼真的渲染和沉浸式体验，覆盖建筑、产品设计、制造等行业。关于混合现实的未来，微软或许还有话没说完。

由此可见，今年的 Build 大会依然聚焦在云服务领域，倾向于企业端用户。从会前「剧透」来看，微软想强调 Azure 是为 AI、IoT、混合现实、区块链而生的最强云服务。Stifel Financial 分析师 Brad Reback 表示：「我们仍然认为，向云计算的转变将对微软有利，因为微软拥有更广泛的产品组合，功能更强大，而且微软有能力进入新领域。」同时，微软在物联网方面技术创新和收购都有动作，不难看出它希望在物联网领导称霸的野心。而微软又将为 Windows 和 Office 这些低调的业务讲出什么新故事呢？

今年，极客公园特别针对 Facebook F8、微软 Build 和 Google I/O 策划了 #西海岸新浪潮# 的专题报道。极客公园已经对 F8 的主题做了详细的报道，北京时间 5 月 7 日早间，我们将为你第一时间报道 Build 2019 Vision Keynote 相关内容。
