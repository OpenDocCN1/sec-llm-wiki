极客博物馆 vol.35：几经沉浮的 RAZR 系列是 MOTO 品牌中相对耀眼的那一个，也是极客博物馆栏目网友留言提到最多的系列之一，本期栏目极客之选挑选了 RAZR 系列第一款也是「战绩」最辉煌的——RAZR V3。

有那么一些已经老去的产品，它们也许早已淡出人们的视线，但每每想到却令我们充满回忆。作为极客之选（微信号 GeekChoice）怀旧栏目，《极客博物馆》希望找到这些曾经带给我们惊喜和感动的产品，带你重拾它们迷人的特质。



能和巅峰时期的诺基亚正面硬刚的品牌并不多，摩托罗拉算是其中最有资历的一位，两家也算得上是死对头。本期极客博物馆极客之选选择了在网友评论中呼声很高的刀锋系列的开山之作——RAZR V3。

对于极客博物馆的读者来说，可能更多人对于 Droid RAZR 记忆更深刻，但 RAZR 最辉煌的时刻还是属于 RAZR V3 的。不过大家也不必伤心，在未来 Droid RAZR 肯定会呈现给观众。

摩托罗拉 RAZR V3（后文中简称为 MOTO V3）是一款 2004 年就发布的机型，更是 RAZR 系列的第一款机型，至于为什么要叫「V3」而不是「V1」这个就无法得知了。「RAZR」一词很明显是由「razor」变形而来，相近的变形词还有游戏玩家们所熟知的「灯厂」雷蛇（Razer），razor 本身就是剃刀的意思，MOTO 希望通过这个词来表现出这个系列薄和金属质感两个特点，其中文译名「刀锋」也显得足够信达雅。

与其说是「系列」，RAZR 对于 MOTO 来说更像是一个分支品牌或者说子品牌，毕竟在 RAZR 系列中还会分为 V、L、K、Z、E 共 5 个小系列。也许 RAZR 系列并不是第一个将超薄的概念引入到手机产品之中的，但绝对是第一个让人印象深刻的超薄手机，并掀起了一股超薄手机的风潮。

极客之选手中这台 MOTO V3 是一款中国移动定制机，除了机身 A 面和 D 面的 MOTO logo 以外，背面还有中国移动的 logo，在后期中国移动的定制机型还有一个专门的名字——心机。MOTO V3 绝大部分机身外壳都采用了铝合金材质，磨砂处理让手感得到了较好的保证。

最早一批 MOTO V3 大部分以银色为主，这款机型从 2004 年推出之后直到 2007 年停产，按照时间顺序各个时期版本的主打色也有不同，在银色之后黑色机身成为了主打，在之后冰蓝色也就是浅蓝色，最后一个版本就是粉红色。对于大部分网友来说，银色和粉色可能是记忆最深刻的。

MOTO V3 整个机身厚度为 13.9mm，这在如今看来并不是什么值得炫耀的数字，但在当时这个机身厚度不要说翻盖机型，比当时很多直板机型都要薄。我相信很多人第一次被 MOTO V3 的震撼程度，不亚于乔布斯从牛皮纸袋中拿出 MacBook Air。

因为采用了翻盖的设计，MOTO V3 还有一个尺寸较小的外屏，为了方便查看来电或短信等通知，翻盖手机大多数都采用了这个设计。但 MOTO V3 在如此薄的部分，放下两块屏幕，这在当时还是少见的。

MOTO V3 的摄像头就在 A 面外屏的上方，30 万像素的摄像头在当年并不算高，要知道同年诺基亚 7610 可是 100 万像素的摄像头。不过，对于 MOTO V3 来说，整个屏幕部分的厚度已经非常薄了，能把摄像头放在这个部分，就已经说明了 MOTO 在工程设计上强大的实力。

而且，MOTO V3 的侧边按键也放在了屏幕这部分，扬声器也放在了机身的 A 面外屏下方的位置，单单从位置上来说，MOTO V3 甚至会让人觉得听筒和扬声器共用了一个元件。尽管这样的设计令人惊叹，但 MOTO V3 必须要面对的一个问题就是更高的返修率，翻盖手机的返修率本身就要比直板手机高上不少，再加上 MOTO 这样的设计，也让 MOTO V3 成为了当时维修率很高的机型。

MOTO V3 除了薄以外，键盘也相当有特点，当年 MOTO 官方的宣传语是「镭射激光键盘」，从造型和视觉效果来看，MOTO V3 的键盘确实很有未来感，尤其是按键之间光带在点亮之后非常酷炫。

但为了控制整机的厚度，MOTO V3 的键程非常短，输入体验单单用一个差字已经不能形容了。对于我来说，第一次使用 MacBook （12英寸，第一代蝶式键盘）打字时，我内心的感受与刚接触 MOTO V3 时是大抵相同的。

MOTO V3 的翻盖设计比较「非主流」，键盘底部凸出来一个很明显的「下巴」，麦克风也很巧妙的被放在键盘和「下巴」之间的过渡部分。

MOTO V3 使用了 mini USB 作为数据传输和充电接口，和当时其他品牌相比，MOTO 使用这种通用标准的接口显得相当厚道。

MOTO V3 在转轴的右侧设计了一个挂绳孔，这也是相当具有年代感的设计，在当时贴膜和手机壳远没有现在这么流行，最火热的手机周边就是挂饰。在当时，为新买的手机挑选一个足够个性的挂饰绝对是要紧的大事。

屏幕、30 万像素摄像头、24 和弦/MP3 铃声、5MB 机身内存，MOTO V3 的硬件配置在当时并不领先，但出色的工业设计以及惊艳的机身厚度让它成为了当时颜值最高的手机，持续热销了很长一段时间。

在最疯狂的时候，MOTO V3 曾经被商家炒作到了近万元的价格，尽管这是个别现象，但这也足以说明 MOTO V3 在当时的受欢迎程度。另外自 MOTO V3 之后，众多竞争对手纷纷推出了自家的超薄翻盖机型，但在那 3、4 年中，MOTO V3 始终是最受追捧的那一个。

MOTO V3 是 RAZR 系列的首款机型，更是最辉煌的一款，RAZR 的再次「复兴」就要追溯到 MOTO「投靠」Android 的智能时代。当然，极客博物馆也会在以后的栏目中继续回顾 RAZR 系列的经典产品。
