大剧透之后，上海车展还有哪些惊喜期待？

电动智能化驱动的汽车产业会孕育出怎样的惊喜，相信在今年的上海车展上就能略窥一二吧。

今年上海车展的主题蛮有意思。「共创·美好生活」一语双关，既点出了「创新」在其中扮演的重要角色，同时也回归了汽车「作为交通工具，使人类生活更美好」设计的初衷。

在下周即将拉开帷幕的 2019 上海车展上，我们依旧能够看到各个品牌展示的最新概念作品，但更重要的是我们可以从越来越多「买得到，买得起」的汽车产品上感受到先进制造、信息通信、互联网、大数据以及人工智能等技术带来的新体验。

上个月刚刚结束的日内瓦车展，新能源汽车集体爆发式的亮相已经让人深感电动时代的到来，AI 技术的展现则让这些曾经笨重的机器有了更高的智能。比如先进的人机交互 HMI，可以大幅提升行车安全的驾驶辅助功能等等。正是这股内外的合力将全球汽车工业的发展推向了新的竞争维度，也为车展提供了更多的「看点」。

电气智能化，毫不夸张地说，带来了不亚于福特 T 型车出现产生的裂变效应。


电动化催生「设计」原力

对普通消费者而言，燃油车和电动车外观来看区别并不大。这在传统车企的产品上尤其更甚。可能很大一部分原因在于这些公司仍处于转型期，针对电动汽车打造的新平台尚未有量产车推出，而基于燃油车平台改造的产品没有足够的设计亮点。

不过这种情况随着大众 I.D.、奥迪 e-tron、奔驰 EQC、保时捷 Taycan 等车型的上市将会有大幅改观。它们诞生于全新的电动产品平台，具备更高的灵活性。从某种意义上说，电动化的趋势为汽车设计的重塑提供了原动力，为汽车设计打开了一个新的创造空间。

以大众的 MEB 为例。作为专为电动汽车设计的模块化平台，后驱或四驱、平整的后排地台、理想的重量分配、可扩展的车身、智能互联等均是设计的「新领地」。

保时捷首款纯电动跑车 Taycan / Porsche 

这种电动化技术驱动产生的效果，我们在大众目前发布的六款 ID. 系列概念车上看得非常清楚。以即将亮相上海车展的 ID.ROOMZZ 为例。从命名上来看，它应该会在交互设计上做不少文章。根据官方透露的信息，这台概念车会采用全新的座椅设计理念以及定制化的氛围灯设计，搭载 IQ.DRIVE 智能驾驶辅助系统。

大众汽车品牌最新概念车型ID. ROOMZZ / 大众

大众汽车品牌首席设计师 Klaus Bischoff 介绍称，ID.ROOMZZ 定位是一款全尺寸电动 SUV，外观设计突出功能性，目的是进一步提升用户的驾乘体验。在此前的各大车展上，大众已经相继展示了包括 ID.、ID. CROZZ、ID. BUZZ、ID. VIZZION 和 ID. BUGGY 在内的五款 ID. 家族车型，这些车型的量产版都将基于大众的模块化电驱平台 MEB 打造。

其实从 ID 这个产品系列的悉数亮相，也不难发现 MEB 的可延展性其实非常强。而且电动车设计可发挥的空间很大，外观在空气动力学上考虑很多，内饰则注重互联性和智能化的交互，和燃油车的产品诉求有很大差别。

奥迪在上海车展也会推出一款纯电动概念车—AI:me。从车型的命名和设计草稿来看，这款概念车主打 AI 功能，重点突出的是电动汽车在未来出行服务中扮演的智能角色。整辆车的尺寸类似 MPV，仪表台一体化的设计也为实现更丰富的交互体验提供了可能。因为同属于 e-tron 系列车型，所以不出意外应该是在 MEB 平台上进行开发的。

奥迪 AI:me 纯电动概念车 / 奥迪

相比大众系电动化产品的概念和前卫，奔驰首款纯电动 SUV—EQC 已经基本接近量产水平，这次参加上海车展属于中国首秀。这台车子是基于奔驰 MEA 纯电模块化平台打造的，类似于大众集团的 MEB，车身宽度、轴距、动力等都是可以根据不同车系车型的需求进行定制化配置的。

不过 EQC 在内饰和外观设计上的中规中矩，很大程度上延续了奔驰 GLC 车型的特点，可能奔驰的粉丝会很喜欢它带来的稳重、精致的感觉，但对于追求刺激和新奇的年轻消费者而言，EQC 的吸引力恐怕不及其他同级别的纯电 SUV。不过据说奔驰将在上海车展公布针对中国市场推出的电动车出行相关的全方位无忧服务。而这种「软硬」一体的配套攻略，显然给了奔驰更多制胜的机会。

第 89 届日内瓦车展现场展示的奔驰纯电动 SUV EQC / 视觉中国


新造车势力的弯道比拼

和传统车企相比，新造车公司虽然没有百年的硬实力撑腰，但通过借鉴成熟的互联网经验，在输出高科技设计体验的同时还提供响应及时的售后服务，这种软件与服务上的优势是值得传统玩家学习的。

比如蔚来在本届上海车展上，将现场展示蔚来能源（NIO Power）补能解决方案与企业技术研发的最新成果。此前，极客公园在报道中回溯了蔚来经历的第一个春节，对其在互联网充电服务上遇到的挑战以及提出的应对措施进行了追踪。无疑，很多消费者购买电动车最担心的还是充电问题，如果主机厂提供了相对完善和及时的解决方案，拿下客户就相当于有了多半的胜算。

蔚来的应急充电救援车 / 视觉中国

另一家新造车公司——小鹏汽车则会带来一款四门中型轿跑车 P7，计划第三季度末试生产并有望年底上市。小鹏第一款量产车 G3 的市场表现蛮不错的，这次选择「轿跑车」这个新造车势力鲜有踏足的细分领域，还是挺有想法的。不过目前还不知道 P7 的内饰设计如何，是否会延续 G3 科技感十足的风格，又是否会效仿特斯拉推出类似 Autopilot 的驾驶辅助功能？一切静待车展现场揭晓。

小鹏四门中型轿跑车 P7 概念渲染图 / 小鹏汽车

零跑的路数则似乎和小鹏相左。去年发布 S01 这款小众的跑车后，今年上海车展将带来首款 SUV 车型—C-more。这款纯电 SUV 基于 C 平台打造，前脸采用封闭式格栅，矩阵 LED 大灯辨识度倒是蛮高的，上下双腰线，车尾飞翼式尾灯搭配流线型车顶，运动风十足。

零跑汽车首款 SUV 车型 C-more / 零跑

从官方公布的续航来看，500 公里+的表现不俗。目前尚不知零跑在充电、维修保养等售后服务方面是否有独特之处，毕竟同级别 SUV 中，蔚来、威马、小鹏都有相对成熟的产品和服务，要想吸引到更多用户，零跑恐怕得拿出更大的卖点才行。

威马 EX5 PRO 纯电动 SUV / 威马汽车

至于威马 EX5 Pro，可以说是上一代车型的升级版，官方将其定义为 2.0 智行版，会在 4 月 12 日车展前夕上市，届时大家可以关注下极客公园的报道。

相比以上的造车新势力，车和家是一家「另辟蹊径」的新造车公司。 他们的首款产品理想 ONE 选择了增程式电动车这个方向，主打「没有里程焦虑」的概念。整体来看，理想 ONE 属于豪华中大型 SUV，六座或七座的设计，专为奶爸奶妈设计，四屏互动的仪表台看起来很酷炫。续航依靠三种能源补给方式最高可以达到 800 公里。理想 ONE 还提供了 L2 级高级驾驶辅助系统，可实现全速域自适应巡航，全自动泊车，自动紧急制动功能。

理想ONE 增程式电动车 / 理想

目前理想 ONE 已经开放预订，最终补贴后的售价为 32.8 万，预计 2019 年第四季度批量交付。不过用户购车权益相对常规，家用充电桩免费安装，免费道路救援以及三年每月 20GB 免费流量，5 月 31 日前预定可享受终身质保。感兴趣的话，大家可以趁着上海车展的机会去现场摸摸看 Baby Blue 限量版珍珠漆的质感。


持续闯入的供应商和科技公司

广义上的车展，我们可以把它理解为各种新车或重磅车型的集中展示。不过随着汽车电动化、智能化趋势的发展，各大车展的现场出现了越来越多零部件供应商和科技公司的身影。

今年上海车展就单独特设了一个「未来出行 (Future Mobility)」展区。包括大陆、博世、采埃孚、伟世通、法雷奥、地平线、禾多科技、Velodyne、亮道智能在内的众多知名软硬件供应商将集中展示在车联网、芯片、无人驾驶解决方案、高精定位和地图、激光雷达等细分领域的前沿技术和产品。

大陆集团今年将从「自动驾驶、蓝天计划和万物互联」这三方面展示创新技术。而作为另一家重要的 Tier 1，博世将在国内首次展示代表全新出行模式的无人驾驶电动巴士概念车以及一系列最新的电气化、互联化、自动化智能交通解决方案。理想 ONE 上的 L2 级辅助驾驶系统即使用了博世的毫米波雷达和电子助力制动系统 iBooster2.0。

采埃孚电驱动样车，集其在自主驾驶、电驱动、集成式安全系统和车辆运动控制四大重点领域先进技术 / ZF

采埃孚这次也带着众多创新科技产品亮相上海车展。届时，具备人工智能的中央域控制器——采埃孚 ProAI RoboThink 将完成亚洲首秀。而为了支持自动驾驶技术在量产车市场的落地，采埃孚会在上海车展发布一款有关自动驾驶的重要新品。

值得一提的是，三月底刚刚宣布将其 nuScenes 自动驾驶汽车数据集全部开源的安波福这次也加入了上海车展。它将展示其最新的 L4 级自动驾驶概念车，并将详细介绍其在智能汽车架构、主动安全、车内驾乘体验、互联网数据服务等主要细分领域的模块化解决方案。

当然，除了重量级的 Tier 1 供应商外，科技公司地平线将在上海车展发布 Matrix 计算平台以及一系列高级别自动驾驶方案的升级版本。同时 10 款地平线合作产品（激光雷达、ADAS、DMS 等智能驾驶方案）将悉数亮相。而自然多模态人车交互方案也将首次展出，听起来充满了黑科技般的神秘感。

而作为提供全栈式自动驾驶方案的初创公司，小马智行 ( Pony.ai ) 将在车展期间推出第三代 L4 级自动驾驶软硬件集成式系统配置。禾多科技则将展示面向高速公路的自动驾驶解决方案 HoloPilot。

小马智行 Pony.ai 第一支城区运营白天黑夜全场景无人驾驶车队在广州南沙上路 / Pony.ai

激光雷达方面，硅谷巨头 Velodyne，国内头部初创公司速腾聚创、禾赛、北科天绘、镭神将带着各自最新的解决方案亮相。自动驾驶量产项目感知功能开发和验证供应商—亮道智能将展示基于激光雷达的感知信息采集与分析，算法开发与验证，驾驶决策与底盘线控的整体解决方案。

作为自动驾驶研发中另一个重要范畴，宽凳科技厘米级别的高精度前装地图方案、高精度定位以及众包地图云解决方案将现身上海车展。宽凳此前曾表示将在 2019 年完成百城百万公里高精度地图商业落地。中电昆辰作为高精定位方案供应商，也将展示其最新产品。

本届车展还有一个亮点是，通讯业巨头华为和 LG 将首次以汽车零部件供应商的身份参展，此前这两家公司在汽车领域的动作似乎都有些扑朔迷离，官方也鲜有回应，而这次阵仗搞得这么大，到时会有哪些亮眼的成果秀出，相信大家一定很期待。


黑科技与暖科技的距离

一边是拥有百年基业的硬实力，一边是主打互联网体验的软服务，新旧造车势力的角逐依然是本届上海车展的一大看点。同时初创科技公司和供应链侧传统玩家的对峙也愈加明显，双方都试图从智能化的小切口入手，希望能在出行市场巨大的利益池中分得一杯羹。

从 PPT 里的酷炫冷峻的「黑科技」到真正「买的到，买得起」的「暖科技」，新旧势力的竞争与角逐让它们的差距不断缩小。

不过，最终的受益者是消费者。产品朝着电动智能化发展的目的，除环保上的考虑外，最重要的是进一步提升用户的驾乘体验和道路安全。不论是主机厂，Tier 1 供应商还是科技公司，任何创新导向的产品思维都不应该本末倒置。而电动智能化驱动的汽车产业会孕育出的「暖科技」，相信在今年的上海车展上就能略窥一二。
