# 极客之选年度评选丨年度手机系统设计：ColorOS

**从「娱乐至上」到「生产力万岁」，极客之选希望能够通过不同维度和视角，盘点 2019 年最有料的极客装备。**

回顾 2019，极客之选（微信号 GeekChoice）给大家带来了上百款科技新品的上手体验内容，也通过《极客博物馆》栏目带着大家进行了一趟「经典产品巡礼」。「年度产品评选」是极客之选每年年底的保留栏目，从 11 月 25 日开始，我们将会逐一揭晓获奖产品，本次评选将涉及到三个大类近 20 个奖项。从「娱乐至上」到「生产力万岁」，极客之选希望能够通过不同维度和视角，和大家一起聊聊那些 2019 年最有料的科技产品。  

最近几年国产手机的发展，可以用「迅猛」来形容。手机硬件从比拼配置，到开始注重手感、相机体验。手机系统也从功能补足，到开始重视易用性和设计美感。OPPO ColorOS 算是变化最大的手机系统之一，在最新的 ColorOS 7 中，不少的细节设计都充满了人文关怀。

ColorOS 7 的核心是「轻快无边界」，体现在设计上，就是更加注重人的感官体验。从整体来看，系统的色彩饱和度、对比度统一降低，图标变得更简约、淡雅，能给人最舒适的视觉体验。

![](../Images/9ddd6c202bcee97658a9a1e8ca5981bd.png)

紧随高帧率屏幕的步伐，ColorOS 7 的动画也进行了专门的优化。量子动画引擎让动效更加细腻，应用返回时，图标的运动轨迹更符合物理规律。  

![](../Images/b707fb936426e6364c2e8c4c7891ff00.png)

具体体验上，ColorOS 7 对用户需求的挖掘要更深。在一些需要跳转页面、填写信息的界面，ColorOS 直接用「半屏交互」快速展示，上滑可以展示完整信息，不需要的话下滑取消。从逻辑上来讲，这样的展示方式避免了重复跳转，不会让人觉得体验割裂。

![](../Images/76ea355e291080c1b0234a99b930bec6.png)

除了设计上充满亮点外，在功能体验上 ColorOS 7 也带来了惊喜——「闪回键」。闪回键功能可以将地图、打车等应用缩小为悬浮窗，在其它界面只显示重要信息，实际场景下避免了重复切换，提升使用效率。

![](../Images/a3b8a63f0f0ef00600cd0a65cabf2121.png)

在底层优化上，ColorOS 7 提出了 UI FIRST 技术，从启动速度、运行效率、游戏流畅度三方面提升「轻快」体验。  

由内而外，国产手机的体验正在快步向前，成为全球智能手机市场的一个标杆。走过了功能堆叠、性能比拼，手机系统向更美、更具人文关怀的方向努力，OPPO ColorOS 算是其中的一个典型代表。
