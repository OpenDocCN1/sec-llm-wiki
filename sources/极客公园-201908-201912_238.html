坚果 Pro 3 评测：改换门庭之后，它还是「内个味儿」吗？

骁龙 855 Plus、4800 万主摄、4000mAh 大电池，出色的硬件配置外，还带来了全新的 Smartisan OS 7.0 系统。


2019 年，对于手机行业而言是一个充满机遇和挑战的年份。

从大的方面来说，在市场增长曲线开始趋向平稳甚至开始下滑的大环境下，迫于出货量压力，硬件利润被进一步压缩，厂商们所面临的资金压力要比前几年大了不少。5G 的到来对于大厂是一个新的增长点，但放在小厂身上却是另一番景象。

巨大的研发投入是一道很难在短时间内跨越的门槛。在 5G 尚未在手机行业得以普及的情况下，小厂所面临的压力是显而易见的。综合多方面因素，今年国内手机市场开始进行新一轮「洗牌」，不少曾经我们熟悉的品牌已经消失在了大众视野里，用户开始向几家头部企业聚拢。

在这次行业格局重塑的过程中，锤子科技也并没有「独善其身」，之后的事情大家也都知道，今日头条母公司字节跳动成为了坚果手机最终的接盘者。

坚果 Pro 3 是坚果手机改换门庭以来推出的首款产品，最近一段时间，网上也有不少相关爆料信息。相信关注它的人都会有同一个关注点：坚果 Pro 3 身上还有之前「内个味儿」吗？带着这个疑问，下面一起来了解下。

         

方方正正，依旧熟悉的「锤子式」设计

从我们一眼就能看到的整体外观说起。

了解坚果手机的朋友应该知道，无论是之前的坚果 Pro 2 还是坚果 R1，其都遵循了居中对称的产品理念，不过到了坚果 Pro 3 这里有所改变，其后置相机采用了「浴霸」设计，第一眼看上去多多少少显得有些突兀。

后盖的工艺处理上，它并没有采用目前行业比较流行的渐变色以及看起来比较炫的纹理效果，而是和之前一样，拥有三种纯色配色。除了我们手里拿到的墨绿色版本，还有黑色和白色两种版本可选。

不同的配色不只是单纯视觉效果上有所区别。具体来讲，这次其墨绿色只有顶配机型才会提供，与此同时，考虑到实际观感问题，坚果 Pro 3 在后置相机的摄像头以及闪光灯排列组合方式上也做了差异化，来和机身主体配色风格尽可能保持一致。

中框部分，坚果 Pro 3 也和之前一样，延续了方方正正的设计，在如今手机产品普遍采用弧度处理的时代，这样的做法并不多见，这也让它看起来很有辨识度。不过垂直的中框切割方式在视觉效果上是有些吃亏的，虽然其厚度只有 7.8 毫米，但看上去却比较厚。

当然，实际上手之后你会发现，虽然其在机身内部塞进了一块 4000mAh 大电池，但由于重量相对比较克制，只有 185 克，并且中框和前后玻璃之间的衔接处也做了一定的弧度处理，握起来的手感表现还是比较令人满意的，不会出现「割手」的情况，对于手腕所带来的负担也比较小。


6.39 英寸「美人尖」屏，全新的屏幕指纹

说机身正面之前，先来回顾下去年五月份发布的坚果 R1。在这款产品上，锤子引入了类似 Essential Phone 以及夏普 S2 的「美人尖」设计，提升屏占比的同时，相比当时的刘海屏，其「切」掉的显示区域更小，对于画面显示的影响也要更低一些。

如果遮住下巴只看上半部分，坚果 Pro 3 和坚果 R1 非常相似。但仔细观察对比，这两款产品的「美人尖」还是有些许的不同，虽然没有一加 7T 那么明显，但前者切割区域两侧还是稍稍做了一些弧度，看起来要更小，过渡也要更自然。

而在边框宽度的控制上，坚果 Pro 3 的上、左、右三个边框都做的很窄，相对来讲下边框稍宽一些，但以坚果 R1 作为参照，它的下巴要进一步收窄。虽然在目前看来，这样的表现算不上最窄，但也非常靠前了。

规格参数方面，坚果 Pro 3 的屏幕尺寸为 6.3 英寸，AMOLED 材质，分辨率为 2340 × 1080，403 ppi，100000:1 对比度，拥有 103.8% NTSC 色域 和 DCI - P3 广色域。另外，其也支持近来大家比较关注的类 DC 调光功能。

值得一提的是，今年比较流行的屏幕指纹也出现在了它的身上，采用了汇顶最新的 G3 屏幕指纹方案，官方给出的解锁速度为 0.2s，实际识别准确率以及解锁速度都比较理想。有些可惜的是，之前坚果手机经典的指纹 logo 二合一设计，也随之退出了历史舞台。


引入头条系拍照算法，有趣的前后同屏录像功能

坚果 Pro 3 的前置摄像头为 2000 万像素，值得一提的是，这次其引入了轻颜相机的美颜算法，可以通过识别的你的面部信息，实现分⼈美颜、记忆美颜等效果。同时，它的相机也和抖音共享特效（没有时间和数量的限制）。

后置相机部分，其主摄像头为 4800 万像素，索尼 IMX586 传感器，F1.75 光圈，长焦镜头为 800 万像素，支持两倍光学变焦，超广角镜头为 1300 万像素，视角度 123°，微距镜头为 500 万像素，支持最小 2cm 对焦。

另外有关拍照部分这里需要说明的是，由于我们拿到机器的时间要稍早一些，系统尚处于 Beta 版，一些功能应用表现还不算稳定。之后随着系统版本陆续更新，实际成像效果应该也会进一步提升，我们也会对这部分保持关注。 

相机之外，这次坚果 Pro 3 在录像方面也带来了一个非常有趣的功能。它可以⽀持利用前后摄像头同时拍两个画⾯，画面效果可以在相机取景框上实时看到，对于很多经常喜欢拍 vlog 的用户来说还是很实用的。同时，其也预装剪映 app，拍摄完成之后，可以方便地进行简单的视频剪辑。


骁龙 855 Plus，UFS3.0，4000mAh 电池

核心硬件配置方面，坚果 Pro 3 搭载了目前顶级的骁龙 855 Plus 平台，提供 8GB+128GB、8GB+256GB、12GB+256GB 三种存储选项。这里需要注意的是，8GB+128GB 版本闪存为 UFS 2.1，其它两个版本闪存为 UFS 3.0。

有关骁龙 855 Plus 这颗芯片大家也比较熟悉，之前我们在多篇评测文章中都做过介绍，这里就不再赘述了。性能表现上，属于目前顶级的水准，应付日常游戏娱乐等应用场景完全没有问题。

至于续航表现部分，前边在介绍握感的时候我们也提到过，它的电池容量为 4000mAh，足够应付一天的正常使用。另外，其也支持 18W 快充，半个小时可以从 0 电量充至 51%，完全充满需要 77 分钟。

其它方面，坚果 Pro 3 配备了 Z 轴线性马达，有些遗憾的是，其并不支持 NFC 功能，如果你平时习惯乘坐公共交通工具出行，多多少少还是会有些不便，不过要是自己开车的话，其实也还好，对于使用体验的影响没有那么大。


全新的 Smartisan OS 7.0 系统，多项功能升级

除了硬件部分之外，Smartisan OS 也是不少人喜欢锤子手机的一大原因。系统方面，这次坚果 Pro 3 带来了全新的 Smartisan OS 7.0，系统 UI 界面上，其依旧延续了之前简洁的风格，不过对 app 图标进行了重新绘制。

功能应用方面，Smartisan OS 7.0 比较有特色的大爆炸、闪念胶囊以及一步也得以更新，分为升级到了大爆炸 3.0、闪念胶囊 3.0 以及一步 3.0 版本，下面重点来说下这次其分别都带来了哪些新的尝试。

首先来看一步 3.0。你可以通过点击 app 图标、从屏幕左上角 / 右上角滑动以及功能键 + 音量减按键的方式启动该功能，现在它同时支持四个应用分屏运行，你可以根据自己的需要去点击想要打开的应用程序，而且支持将主应⽤的文字或者图⽚内容直接拖到小应⽤中，来方便地完成发送或者保存等任务。

闪念胶囊 3.0 最大的改进之处在于，坚果在坚果 Pro 3 的闪念胶囊功能里边加入了语音助手，其除了支持语⾳转⽂字，还能够让语⾳助⼿回答的问题，从我们的实际体验来看，识别准确率以及翻译正确率都有着不错的表现，使用便捷性方面要比之前更好。

有关大爆炸 3.0，这次在提升基础的识别准确率之外，坚果 Pro 3 还新增了语音功能和炸录屏功能，这也使得其能够面对更多样化的使用场景。

除了以上我们提到的这些，TNT 带来了无线投屏功能以及分享模式，现在其支持手机与大部分智能电视进行无线投屏（⽀持 Miracast 投屏和乐播投屏），在 TNT 投屏模式下，坚果⼿机可以充当虚拟触控板的功能，操作便捷度很高。

至于 TNT 分享模式，其没有 dock 状态栏以及通知栏等相对复杂的交互，能够更好地避免在进行内容分享的同时，被他人看到个人的一些隐私信息，更加适合在诸如会议等公众场合下使⽤来进行使用。

简单总结 Smartisan OS 7.0 系统，其在依旧延续 Smartisan OS 一贯风格的同时，进一步强调了交互效率以及操作便捷性。尤其是对于一些办公人士而言，它所带来的体验提升还是很有吸引力的。


缺席「很久」，但并没有令人失望的准旗舰机

由于众所周知的原因，去年八月份发布完坚果 Pro 2S 之后，坚果在接下来一年多的时间里都没有新品推出，而在其缺席的这段时间里，其它手机厂商却在全力往前奔跑。其实拿到坚果 Pro 3 之前，我们对于它是否能够赶上行业普遍水准是抱有一丝怀疑的。

实际上手体验之后，我们很快打消了这个怀疑。核心硬件配置上，骁龙 855 Plus、UFS 3.0、4000mAh 大电池等等诸多特性的到来，让其在与同级别产品竞争中并不会落得下风。与此同时，系统层面上的进一步完善，对于体验所带来的提升也是实实在在的。

不过坚果手机这次在产品策略上显然是比较谨慎的，虽然用上了目前顶级的骁龙 855 Plus SoC，但他们并没有将坚果 Pro 3 定义为旗舰机，而是想要以更具诱惑力的价格来重新获得市场的青睐。

具体定价方面，坚果 Pro 3 8GB+128GB、8GB+256GB、12GB+256GB 版本分别为 2899 元、3199 元和 3599 元，目前已经正式开售。在 5G 尚未正式到来，4G 依旧占据主流的大环境下，买来作为过渡用机还是不错的。
