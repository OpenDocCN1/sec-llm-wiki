## 亚马逊消费业务彻底弃用 Oracle 数据库

北京时间 10 月 16 日，AWS 首席布道者 Jeff Barr 在其博客上透露，亚马逊消费者业务正式完成了对 Oracle（甲骨文）数据库的迁移工作，永久关闭 Oracle 数据库。甲骨文当日股价剧烈波动，收盘时股价下跌0.19%，并在盘后交易中继续下滑。

对于 AWS 来说，这个任务显然是提前完成了的。亚马逊 AWS CEO Andy Jassy 曾在 AWS re：Invent 2018 中曾表示：到 2019 年底，亚马逊将全面放弃使用 Oracle 数据库，97％的「关键任务数据库」将运行在亚马逊自己的服务上。

目前，Amazon 将近 7500 个 Oracle 数据库、75 PB 的数据已经全部迁移到 AWS 数据库服务。亚马逊消费者业务的 100 多个团队参与了迁移工作。包括 Alexa、Amazon Prime、Kindle等产品，涉及消费者付款、客户退货、目录系统、提供体验、数字设备、外部付款、财务、信息安全、市场、订购和零售系统。

  

![](../Images/7dfe490857501062a453c989b5683277.png)

互联网云计算厂商的崛起一直都在对传统的企业服务厂商造成严重冲击，但数据库领域的竞争激烈状况仍然超出想象。

甲骨文创始人Larry Ellison 曾一度忽视来自云计算厂商的进攻，认为这些后来者无法超越自己。但事实并不如他所愿。  

2014 年 AWS 推出了原生企业级数据库 Aurora，并在 2018 年宣布内下线了 88% 的甲骨文数据库并代以自研的数据库。在中国，阿里云从 2012 年就开始强调去 IOE并在 2014 年成功 ，今年还成功推出了云原生数据库 POLARDB。现在，基本各家云计算厂商都有自己的数据库产品，比如腾讯云有 CynosDB，华为有 GaussDB。

对于云计算厂商来说，自建数据库系统的好处是明显的，可以改变过去对上游硬件和基础软件厂商的依赖。云计算虽然是「线上」的生意，但传统 IT 时代中的服务器、数据库、存储介质仍然是云计算生意中最重要的组成部分。

据AWS 首席布道者 Jeff介绍，此次迁移可以帮助AWS数据库成本降低 60％以上，面向消费者的应用程序的延迟减少了 40％，切换到托管服务可将数据库管理开销减少 70％。

对于甲骨文来说，则算得上又一记警钟。据Gartner分析师称，预计到2021年，目前年产值296亿美元的商业数据库市场会收缩20%至30%，甲骨文将会因此遭受更严重的挑战。因为来自数据库软件的收入长期占Oracle 占其营业利润超过50%。对于甲骨文来说，面向云计算转型刻不容缓。

## 阿里云全资收购长亭科技，将独立运营

10 月 11 日午间消息，长亭科技宣布，阿里云拟全资收购长亭科技，收购完成后，长亭科技品牌及团队均保持独立，继续保持独立运营，并在阿里云的技术、资金、业务的全方面支持下拓展市场，持续为企业级用户提供网络安全解决方案。阿里云向新浪科技确认该消息。

据介绍，长亭科技是一家创新安全公司，其最早的四个联合创始人都来自知名的蓝莲花战队，2014 年、2015 年，蓝莲花几乎包揽了全球所有重量级网络安全大赛的前三名，也是中国首支入围 DEFCON CTF 的团队。此外，在 2016 年「315」晚会上，长亭还是智能摄像头、POS 机破解的技术支持方。（来源：新浪科技）

  

## 腾讯云全资收购扣钉科技，将独立运营

据《财经涂鸦》报道，腾讯云不久之前完成了对一站式云端软件服务平台 CODING 的全资收购。收购完成后，CODING 作为腾讯全资子公司，将以深圳市腾云扣钉科技有限公司的主体继续独立运营。与此同时，CODING和腾讯云开发者平台各自的官网信息也显示两者已全面打通。

据公司官网介绍， CODING 是国内首个一站式云端软件服务平台，目前已累积 100 万公有云用户量，15000 多家企业，170 万个项目，交付超过 30 家私有云头部客户（含腾讯内部 OA 版），获得 IDG 资本、光速资本和腾讯云三轮投资共计 2500 多万美元。(来源)

  

## 亚马逊云服务仅占中国市场 6.4%，欲抢夺中国云计算市场

10 月 16 日晚间消息，据台湾地区媒体《电子时报》（digitimes）网站报道，在快速发展的中国云计算市场，亚马逊正在拓展团队，希望从阿里巴巴和腾讯手中赢得更多市场份额。

![](../Images/059ff31ad619e101694411c41ac1b55d.png)图 |视觉中国

尽管亚马逊云计算服务 AWS 在全球拥有逾 40% 的份额，但在中国，该市场却由阿里巴巴和腾讯主导。对此，亚马逊 AWS 企业及云计算顾问张侠（Xia Zhang）日前表示，AWS 一直在扩大其在中国的团队，希望实现与其人力增加成比例的业务增长。

张侠称，中国的云计算市场每年都在稳步增长。IDC 数据显示，中国的公共云基础设施即服务（IaaS）市场主要由阿里巴巴的云子公司主导，2019 年第一季度的份额为 43.2%。此外，腾讯的市场份额为 12.2%，中国电信为 8.4%，而亚马逊 AWS 为 6.4%。位居 AWS 之后的是金山云、华为和百度，其市场份额均约为 5.2%。（来源：新浪科技）

  

## 2019 年上海市产业转型升级发展专项资金（人工智能）拟支持单位公示

10 月 17 日，上海市经济和信息化委员会发布《2019 年上海市产业转型升级发展专项资金（人工智能）拟支持单位公示》，平头哥（上海）半导体技术有限公司、澜起科技股份有限公司、上海商汤智能科技有限公司、上海流利说信息技术有限公司、口碑（上海）信息技术有限公司、云知声（上海）智能科技有限公司等公司在列。公告称，本次拟支持总金额为 6.029 亿元。（来源：36 氪）

  

## 微软推出基于人工智能的「数字营销中心」项目

10 月 16 日，微软推出了一个名为「数字营销中心」的新 Garage 项目。该工具由人工智能提供支持，旨在实现中小型企业（SMB）的数字营销自动化。它的主要重点是使这些业务的整个流程显著提高效率。

## 中国 X86 市场二季度继续下滑

![](../Images/24039fd59de3a3fb7492459fc1ee1c48.png)

近日，IDC发布《2019年第二季度中国X86服务器市场跟踪报告》，报告显示：

  

*   2019年第二季度，中国X86服务器市场出货量 715,054台，同比下滑14.6%；市场规模为38.01亿美元（约合261.28亿元人民币），同比下滑9.4%。
    
*   2019年第一季度，中国X86服务器市场出货量662,504台，同比下滑0.7%；市场规模35.90亿美元（约合240.90亿元人民币），同比增长13.5%。由于均价持续攀升，销售额仍达到两位数增长。
    
*   2019年上半年，中国X86服务器市场出货量为1,377,558台，同比下滑8.4%；市场规模为73.90亿美元（约合502.18亿元人民币），同比增长0.5%。
