# 特斯拉拿「爆品」突袭中国，谁的末日？

特斯拉升级中国工厂，Model 3 的全系国产在「吓」谁？

特斯拉的老用户们又酸了，准车主们又笑了。

4 月 10 日，中国制造的特斯拉 Model 3 又上线了两个「爆款」版本。国产 Model 3 长续航后轮驱动版正式开启预订，续航 668 公里，补贴后售价 339050 元起。同时，Model 3 高性能全轮驱动版也将国产，售价人民币 419800 元起。

![](../Images/5c47ec6df800ccf8ef20e44ed9cada23.png)特斯拉在微博上公布中国制造的新版本 Model ｜微博截图

比起之前的国产的 Model 3 标准续航升级版，这个新的长续航后驱版只贵了 4 万左右的价格，但却多了超过 200 公里的续航，以及一些内饰配置与高配版相同，性价比再次升级。而之前买了进口 Performance 高性能全轮驱动版的用户更是没想到它会国产，价格大幅下探。

这两个「爆款」配置的国产化，背后其实是特斯拉对于中国超级工厂的原有策略的大调整。

2019 年 1 月，特斯拉上海工厂刚刚宣布动工建设时，马斯克还在呼吁「Model 3 的高配款价格明年会跟今年一样，我希望人们不要观望，或者说等着降价。」甚至还明确，中国上海超级工厂将只生产低配版 Model 3，用以供应中国和亚洲其他地区市场。

但疫情的到来，对供应链和特斯拉的全球策略产生了很大影响。刚刚建成不到一年，特斯拉就迅速提升了中国工厂的作用，以 Model 3 全系车型国产化，进一步扩大国内需求，在面对疫情这个长久战的时期，将中国工厂的产能提升到满负荷，以降低成本带来更多的产品力。

但特斯拉国产化的提升以及价格的不断下探，很多网友不禁为国内刚刚成长起来的新造车而担忧。

  

## 搅动的「鲶鱼」

特斯拉其实一直是中国新造车们的「盟友」。

特斯拉依靠更广泛的知名度和新造车们一起，推动消费者对于电动汽车以及「智能」电动汽车的认知理解。「特斯拉更像一条鲶鱼，它倒逼国内的企业认真做 C 端的用户，认真做产品。」李想前两天在对话雪球方三文的时候说，「对于认真的从业者而言，短期看是有压力，但长期看绝对是好事。」

![](../Images/53d29f30d3f2e67d0737292109ec3e0d.png)马斯克发布推文：「祝贺特斯拉团队制造了我们第 100 万辆汽车！」｜Twitter  

以国内蔚来的明星爆款产品 ES6 来说，很多人认为它会受到 Model 3 这次国产化的影响。但它和 Model 3 其实是完全不同的两款产品。产品层面上，一个是偏紧凑型的轿车，一个是中型 SUV，从空间和豪华感上面就很容易把两车区分开。

甚至还有人说，特斯拉为蔚来的销量做了不少贡献。「特斯拉和马斯克的知名度扩大了关注电动车的人，很多人开始对特斯拉感兴趣了，但是他发现 Model 3 比较小，我想买辆 SUV，于是很多人就去买了蔚来 ES6 了。」一位汽车行业从业者说。

而从产品力来看，蔚来即将上市的 100 千瓦时电池包也帮助 ES6 车型 NEDC 续航全系超过 600 公里。这也在数据上不断缩小与特斯拉的续航差距。

同时，蔚来依靠独特的「用户企业」定位，以及换电和电池灵活租赁政策，包括「可充可换可升级」这种全新的独有的电池升级策略，都与特斯拉保持了很强的差异化体验。

![](../Images/0106684c6dfe7486570f3f9c0ef59b93.png)蔚来 ES6 在换电站中进行换电｜蔚来官网

可以说是差异显著的两款产品，但不妨碍的是，他们一起在强化电动汽车的加速性能、NVH、用车成本上的品类优势。

特斯拉这次公布「补贴后」价格也是打击对手的一个小手段。而蔚来的「电池服务化」和「按需升级」策略也可以看做是在「价格体系」上冲击对手的法宝。

只是这个「对手」并不是特斯拉与蔚来，而是传统的燃油汽车。

「我们很快就会看到电池成本降低带来的一个边界，那就是燃油车节省一两年的油费就能完全 cover 纯电动汽车整个电池的成本。」李斌在去年接受极客公园采访的时候说，「到明年，没有补贴的情况下，我相信电动汽车对比传统汽油车，基本在价格优势上就已经能够形成很强的驱动力。」

  

## 「一身冷汗」的 BBA？

这一次真正「一身冷汗」的车企其实是 BBA（宝马、奔驰、奥迪）。

根据中国乘联会的数据，特斯拉 3 月中国汽车销量为 10160 辆。而对比 2019 年的数据，2019 年 3 月奔驰 C 级 14015 辆、宝马 3 系 15820 辆、奥迪 A4L 14351 辆。

特斯拉作为电动汽车领域的头部力量，它已经在开始动摇同级别燃油汽车的市场份额了，而这一次是在这个全球最大的「中国市场」里发生的。Model 3 全系车型国产化的实现，对于电动汽车市场来说一定会加速为 2020 年的中国市场带来不同的格局。

![](../Images/181c20095f36cc2043c72f3b9b741de6.png)在美国市场也同样已经展现出 Model 3 这款爆品的实力 | Clean Technica

对于 BBA 来说，它们的电动产品也都刚刚亮相，这更是对电动汽车市场的一种推动。对于这个百年汽车产业来说，2019 年它的「地基」首次开始了动摇，电动化产品逐一落地。对于这个不寻常的 2020 年来说，也许是时候用「销量」来替电动和智能做一次实在的背书了。
