# 在寻求答案之前，先寻求一个好问题吧

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652869814&idx=2&sn=fb63f02487688ab7a1c8a159f0b2d6d6&chksm=7e6ae900491d6016da6311aa9c5a8f155a978aeaa72b857d84ed57b910f73c1f4aa886dec8eb&scene=126&sessionid=1681310407#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652869814&idx=2&sn=fb63f02487688ab7a1c8a159f0b2d6d6&chksm=7e6ae900491d6016da6311aa9c5a8f155a978aeaa72b857d84ed57b910f73c1f4aa886dec8eb&scene=126&sessionid=1681310407#rd)

去年下半年，我和顺为资本投资合伙人周航牵头发起了一个「未来前沿」创始人工坊，后来前优酷联席总裁魏明也加入进来，我们三个作为常驻教练，每次邀请一些企业家朋友作为飞行教练，给早期创业者们做孵化，也对优秀的创业者直接开支票做投资。

  

创始人工坊做了两期，墙上始终贴着一张海报，「从看见到看穿」。我们为什么会选这句话呢？因为这其实就是创始人工坊最想帮创业者实现的。

  

很多我们接触的创业者，都处于「看见」的阶段，比如看到机会，看到一些方法，也能迅速看到一些问题。很有意思的是，这个阶段的创业者有个共性，那就是特别希望问教练：「你觉得怎么办？」「你觉得这个行吗？」

  

但创始人工坊一直以来都特别强调不给答案，只提问题——提更真的问题。为了这个原则，每次我面对学员忍不住要出主意、说观点时，都会被周航使眼色。那意思是你别说了，提问，让他们多想和多说。

  

我觉得周航是对的，因为这样对创业者可能才是更有效的。

  

我给大家举个真实的例子。

  

前两周，创始人工坊组织了一次线上交流，邀请学员们分享最近在项目推进中遇到的阻碍。其中有一位学员，自身的 B 端业务基本停摆了，客户那边恐怕下个季度也缓不过来，同时有一些 to C 的机会找过来，所以很纠结要不要借此调整产品、团队等等，打开 C 端市场获客，问大家怎么办比较好。

  

同样还有几位学员也表达了类似的纠结，B 端的业务停滞，要不要转型 to C（或者反过来）。那创始人工坊教练们是如何「回答」的呢？

  

 

  

所谓的机会，跟你到底什么关系？

 

先是魏明提供了一个很好的视角，他说世界上之所有有 to B 和 to C 的两种声音，可能也是因为有两类不同的创始人。

  

一类喜欢和大众互动，或者说他更擅长做把握大众心里的事情，知道怎么去拿捏火候，通过产品或者品牌让一群人去 follow。还有一类人擅长和关键人物打交道，把决策者搞定，就能一把来个大的。

  

之前在工坊第二期，G7 创始人翟学魂分享里也提过这一点，他曾经有一项业务，产品做的没什么问题，但就是打不赢另一家公司。

  

后来老翟明白过来了，这件事儿跟他这个人没对味上，自己和团队都是不是强地推、搞铁军那一套的，但他这个业务拓展想往大了做，可能就得用这套打法。于是这项业务他就战略性放弃了，回过头踏踏实实做产品，做自己骨子里适合干的事儿，现在一年也有几百亿收入。

  

所以说，**创业不能反人性，不能逆着用户来，但也很难反天性，逆着自己的脾性搞机会主义。**

  

别光看哪里有机会，还得从自己的角度做一些主动思考。问问对自我的认知，问问对团队的认知。

 

  

  

别浮于概念，回到事情本质思考

  

后来，周航也抛出了一个特别好的问题：这位同学，你能先说说to B 与 to C 之间本质区别到底是什么吗？如果是结合你的行业，具体做法上会有什么差别？ 

  

你还别说，这种从概念里跳出来、回到事情本质思考的方式对创业者很有帮助。这也是周航一向的风格，抛弃掉各种名词的包装和概念，咱就回归到最简单朴素的商业逻辑：**你要做的这件事儿给用户提供了什么价值？谁可能会为它的实现而买单？你准备怎么做？**

  

这么一问就会发现，如果本质的东西没想明白，那些用来表面装饰的定义、概念，往往也禁不住刨根问底。

  

如果很多问题本身其实是个伪问题，那么别人给的和自己写的答案，也就肯定是个伪答案。

  

 

  

别纠结眼前，找到那个真正的问题

 

而我当时问的问题，是另一个视角：纠结要不要 to C 转型背后，什么才是你真正纠结的问题？

  

是由于这段时间的停滞、对现金流和未来发展有着根本性影响，所以需要迅速找到新的变现方式，支撑自己往前走？

  

还是这个时机令自己看到了一些新的机会，可能原来认为不 ready 的事情，好像现在也能够试一试了？

  

如果是前者，那就是一个必须解决的困难，转型才能活下去，那咱别犹豫。

  

如果是后者，你相当于看到了新机会，可能从此要转换赛道，那就必须还是回到基本面做一些思考，努力去看穿：你对技术、产品、用户需求的判断，为什么这个时候不一样了……这些是不是真的支持你的赛道的切换。

  

这些思考能帮助我们产生一些动力或者定力，不轻易被外界的变化迅速动摇。不至于因为有人找来做几笔生意，你就把根本性的产品和技术判断扔掉了。

  

创业的常态，就是那个被一些短期问题考验着的长期判断。有时候应该多问自己的不是「这钱我为什么不赚」，而是「这钱我为什么要赚」？

  

 

  

问题永远在答案的前面

 

为什么创始人工坊的习惯，不是给创业者一个选 A 还是选 B 的答案，而是尽力去帮他梳理这个问题背后的真问题是什么。

  

因为重新把问题定义得更清晰一些，然后一步步拆解问题到更小的颗粒度，你的答案和行动才会更有效。

  

所以我们相信优秀的创业者，需要的不是别人给的答案，而是别人帮他看到了更真的问题。

  

更何况创业本身就没有标准答案，靠二手思考怎么可能做成一手的成功呢。

  

每一个来到创始人工坊分享的成功企业家，几乎都会说这么一句话：「我当年创业的时候要是有这么个场子，能帮我挑错，陪我思考问题，我会少走很多坑。」

  

我觉得他们不是给我面子说漂亮话，因为这种有人站在正方、反方，甚至拿出自己的经验，作为思考伙伴去帮你把问题看得更清楚，一起和你从「看见」到「看穿」的感觉，确实挺难得的。

  

这相当于在创业者早期最脆弱，只有一条命的时候，身边有了一群经验丰富的合伙人可以共同思考。

  

创业这件事，面对的是时间长河中的无数选择题，有自己的思考伙伴，就算是夜路，也会更有机会走到天明。
