「未来前沿」创始人工坊是由极客公园前沿社发起，面向早期创业者的孵化训练营。疫情带来的冲击还在持续，当原本的 B 端业务出现瓶颈，是否要转型打开 C 端市场？面对这种开放性的选择，我们需要回到基本面做思考。
两周前，「未来前沿」创始人工坊组织了一次线上互动，邀请学员们一起交流各自在项目推进中遇到的阻碍、解决的思路，并与工坊教练们共同讨论，获得意见和建议。

在交流中，不止一位同学提到，疫情期间自己原本的 B 端业务停滞、增长出现瓶颈，于是考虑是否要打开 C 端市场。又或者，原本是面向 C 端用户的产品，因为疫情发现了 to B 的潜在机会，但纠结原有的品牌会半途而废：

  • 创业者 A：因为疫情，B 端客户没法推进，客户自身下季度的预算也成了问题。我比较纠结要不要拓展一些 C 端用户，不至于业务卡在这里做不下去。但也意味着团队的变化，产品的调整等等。

  • 创业者 B：我们是做 to B 产品，但始终在想怎么能更规模化，比如通过 C 端获客、自下而上推动企业买单？

  • 创业者 C：我们的产品说不上 to B 还是 to C，因为终端使用者就是一个个的 C 端用户，只是获取用户的途径方式区别，目前还是和大厂合作为主。但如果真的转向 to C 获客，可能就要打造一个服务 C 端的团队，没有想好怎么判断这个时机。

  • 创业者 D：最近投资人提醒我考虑一下 to B 市场，对我们产品来说，现在里面确实有比较好的赚钱机会。但我之前的战略是 to C，先做品牌，长期积累后再考虑 to B。现在就 to B 是能赚钱，但可能就变成了一个供应商。


疫情带来了一些变化，也带来了一些机会。作为从 B 端市场起步一家初创公司，该如何有效地思考业务进程？to B 还是 to C 的业务模式，该如何去选择？

创始人工坊的三位教练张鹏、魏明、周航给出了他们的看法，希望他们的分享能够推动你做出进一步思考，收获一些不同视角的启发。



不是 to B 和 to C ，而是你的路线选择

张鹏：听了大家的叙述，我想先问几个问题：首先，业务受疫情影响，造成现在停滞，你判断它会延续多长时间？

其次，你现在所面临的真正问题，是由于这段时间的停滞、对你的现金流和未来发展有着根本性影响，所以你需要迅速找到新的变现方式，支撑自己往前走？还是这个时机令你看到了一些新的机会，可能原来认为不 ready 的事情，好像现在也能够试一试，所以纠结的是还按不按原来的节奏走？这是两种截然不同的情况。

所以刚才大家所描述的，我感觉核心不是 to B 和 to C 的问题，而是你的路线选择问题。尤其是现今这样一个动态变化的市场，再加上疫情造成的意外，你们实际的问题的是要不要修改路线，以及一个路线的调整可能意味着整个体系的对应调整，自己这个早期阶段能不能 hold 住。

面对这种开放性的选择，很难有谁能帮你做出判断，还是要回到基本面做思考：你对技术的判断、产品的判断、需求的判断等等，这些思考会帮助你产生一些结构化的结果和定力，不轻易被外界的变化迅速动摇。

看上去是选择 to B 还是 to C 的问题，是机会来了我抓不抓的问题，是「这钱我为什么不赚」vs.「这钱我为什么要赚」的问题……其实都是在被一些短期问题考验着对长期的判断。



你作为创始人更擅长做什么？

魏明：我想提醒大家思考一个问题，为什么是世界上有 to B 和 to C 的两种声音？ 

本质上来讲，是因为有两类人。一类人是跟大多数人打交道很愉快，他掌握大众心态，愿意跟大众互动，然后他创立了一个所谓的 to C 的品牌，可以和更多的人打交道。

还有一类人，可能懒得跟大众互动，更喜欢的是跟几个关键人物打交道、一把就来个大的，然后再由大的去把它分销到小的个体。这两类人之间有本质的心理区别，也会形成不同的生意模式。

我讲这些，是希望大家从自己事业的本质去思考问题，你作为一个创始人更擅长做什么。如果这个逻辑成立的话，其实考虑 to B 和 to C 的问题根本，也是先问你自己、你的团队，以及你能控制的那些能量，适合做什么？如果你们适合做 to B，就安安心心的在 to B 里面找可能性，不要骑墙，觉得自己可以做所有的事情。你一定有现在擅长和不擅长的。

当然，你也可能说你愿意跟大众打交道，但很清楚自己的能量得先跟小众打交道。既然已经形成了这样的判断，那直接去做就好了。

等你的资源足够多、能量足够大了，能挪腾过来了，再去尝试另一种。但是大概率是不可能完成的任务，除非你的团队 DNA 起了本质的变化，或者你变成了一个投资人，自己原来做 to B，投了一个做 to C 的伙伴。

我跟一些做 to B 生意的大企业老板打过交道，他们的生意已经做得非常大，但就是能按捺住自己的心，就跟那几十年下来的老伙伴们做生意，把自己该挣的钱挣到，不贪恋对方拥有的品牌和名气，也不谋求那些 to C 市场中看起来的「光环」。

其实我想用这个逻辑提醒大家，就是在问这个问题的时候，不要说因为我 to B 做不下去了，或者是暂时就有些困难，所以去试试 to C 。

 

思考题：to B/to C之间的本质区别是什么？

周航：大家分享了很多自己的个案，我可能没法一一回答具体情况。你们不妨去深度思考一下，to B/to C 之间本质区别到底是什么？特别是结合大家自己的行业，具体做法上会有什么差别？ 

所谓的 toB toC，其实都是一些说法，类似的还有什么 2B2C、S2B2C……说法太多了，有的甚至还把它们二元对立起来。别被这些概念搞晕。

概念是什么其实都不重要，重要的是这些概念背后，回归到你对自己要做的这件事儿的理解。你到底提供了什么价值？对 B 也好、C 也好，本质区别是什么？我们先把底层的问题想清楚，再去看表层的问题怎么解。思考得太浅，就容易围绕一些说法做讨论，对我们的创业也不会有什么帮助。
