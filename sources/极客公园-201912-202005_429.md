# 这只会后空翻的机器狗，可能是你的第一只机器宠物

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652868197&idx=2&sn=1554889ad6695d7e793dd8cacf21dd12&chksm=7e6af3d3491d7ac5c5f8a50a8bb2b46b34b567735abd0640e267a9072e1b8d9c264ce997eda0&scene=126&sessionid=1681310459#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652868197&idx=2&sn=1554889ad6695d7e793dd8cacf21dd12&chksm=7e6af3d3491d7ac5c5f8a50a8bb2b46b34b567735abd0640e267a9072e1b8d9c264ce997eda0&scene=126&sessionid=1681310459#rd)

> 家有一「狗」，如有一宝。

![](../Images/f7e869162314435d2da09115c576392b.png)远在玛丽·雪莱的《弗兰肯斯坦》之前，人类已经默默将「机器人」的定义和人挂上了钩，毕竟，《圣经》中上帝也是按照自己的形象创造了人类。好在后世的科学家另辟蹊径，从自然界获得灵感，不然我们现在乘坐的飞机不会张开双翅，而会像一个双臂前伸飞行的奥特曼。

  

几年前，波士顿动力无所不能的机器狗 Spot 在 YouTube 上走红，让人们看到了非人形机器人的广阔未来。事实上，远在 Spot 成名之前，国内已经有高材生研发出了类似的四足机器人。

2013 年，还在读硕士的王兴兴就已经在研发 xDog 四足机器人。七年后，经过四次迭代，宇树科技携最新型号机器狗 Unitree A1 来到了 2020 年的 CES 消费电子展，而这只能连续作出「后空翻」动作的机器狗，也成功吸引了人们的视线。

2018 年 6 月，宇树科技获得了来自极客公园旗下的变量资本以及安创中国的投资，在 2019 年初，又获得了德讯投资的加持。

2019 年底，在 A1 亮相 CES 之前，宇树科技完成了数千万元人民币 Pre-A 轮融资，本轮融资由红杉中国种子基金投资，原投资方德讯投资追加投资。

![](../Images/85144deeeb4506a1afd325aa9140f3cc.png)

2019 年淘宝的造物节上，极客公园（ID：geekpark）就曾经报道过宇树科技的机器狗产品，当时公司展示的 AlienGo 平台产品，体型较大，通体高反光的黑色材质，看起来很像从美剧《黑镜》中走出来的超级武器。王兴兴告诉极客公园，AlienGo 是宇树科技开发的一个四足移动平台，相关产品可能会用在安防巡检等实际落地场景中，所以看起来都比较「彪悍」。

相比之下，在今年 CES 大展上亮相的 Unitree A1，比起 AlienGo 等前辈，仅有不到 12 公斤的体型看起来「可爱」多了，同样是全黑机身，磨砂材质的表面比 AlienGo 更容易让人产生「撸一把」的欲望。

体型小了，更加灵活，虽然形态发生变化，但是背后的技术一脉相承。从七年前的 xDog 开始，宇树科技开创性的使用了外转子无刷电机直驱的传动方式，并使用直接力控技术，实现了较好的运动能力。在全球范围内开创了较低成本高运动性能全自由度四足的先河。有了无刷电机技术，小巧的 A1 能够作出连续后空翻这样的高难度动作，看到 A1 的精彩表现，CES 大展上不少观众表示想当场把小机器狗带回家。

![](../Images/62ce41fa4641af72317a7b956dbf9287.png)

如果说 AlienGo 平台的「彪悍」产品更适合公司或者园区的安防等 B 端场景，小巧的 A1 产品无疑离 C 端更近一些。王兴兴介绍说，A1 更轻巧，定位为教育酷玩产品，集成高清图传、自动跟随、建图壁障、开放编程接口等功能，是高性能四足机器人走进普通人生活的第一步。

从 2016 年 8 月成立至今，宇树科技已经开发了 Laikago、Laikago Pro、AlienGo、Unitree A1 四款机器人。其中 Laikago Pro 在 18 年上半年开始正式接订单、生产及发货。基于公开检索，Laikago Pro 可能是全球最早开始公开零售的高运动性能四足机器人。据宇树透露其海内外订单大概为 6：4，国际顶级互联网相关公司基本都采购了宇树的机器人。

而随着 A1 的问世，宇树科技也将四足机器人产品的市场扩大到了更加广阔的 C 端，为机器人走进普通家庭奉上了一块敲门砖。

「希望 A1 能够走进家庭，成为人们未来的家庭伙伴。」王兴兴说到。
