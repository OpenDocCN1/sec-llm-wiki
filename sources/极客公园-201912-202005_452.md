# 2019 年度创投市场盘点：国内创投的黄金十年在全面暴跌中结束

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652868069&idx=3&sn=0f28d6a72bd9a6cb510e03f845f8dd81&chksm=7e6af053491d794549e84700bcaeab85f350c0bec94a49e31e6b5c84cd076fc7d16e3f69e2a9&scene=126&sessionid=1681310465#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652868069&idx=3&sn=0f28d6a72bd9a6cb510e03f845f8dd81&chksm=7e6af053491d794549e84700bcaeab85f350c0bec94a49e31e6b5c84cd076fc7d16e3f69e2a9&scene=126&sessionid=1681310465#rd)

风口难觅，寒冬难熬，2019年中国创投市场**融资数量与金额全面暴跌**。  

据烯牛数据统计，2019年国内创投市场共计披露**7,405起**投融资事件，较2018年**减少31.41%**，披露的融资金额共计**5,650亿元**，较2018年减少**60.30%**。国内创投市场**融资数量降至2014年水平**，披露的**融资金额**也到达**近五年最低点**。

![](../Images/a377d24769c358816d4274baf758de89.png)

烯牛数据统计发现，资本寒冬中初创企业处境更加艰难。早期融资占比降至历史最低点，种子轮融资占比2.35%，天使轮占比18.63%；成长期融资（A轮/B轮）数量占比从2014年的38.84%升至2019年的56.78%；后期融资（C轮/D轮及以后）数量占比从2014年的3.62%升至2019年的6.44%；战略投资数量占比从2014年的7.77%升至2019年的15.80% 。

![](../Images/8adaee1e531fff6dd92138c159763183.png)2019年，国内创投市场各阶段融资事件数量全面暴跌，其中早期融资**跌幅超50%**。**B轮是创业公司死亡率最高的轮次**，拿A轮易，获B轮难，活过C轮的越来越少。![](../Images/c490665dbfb8aaaf1e61387fa368b1f7.png)![](../Images/4f48f159939b0a18abd4b57976a6dc0c.png)2019年最受创投市场关注的领域主要有**企业服务、医疗、传统行业、先进制造、文娱传媒、教育、消费**等。**传统行业披露的融资数量逆势上涨****，****实体经济在寒冬中更受资本青睐**，其他各主要领域的融资数量均出现不同幅度的下降。其中**文娱传媒**延续了2018年的趋势，**同比降幅达到56.63%**，而先进制造领域投资数量则仅轻微下降，其在全部融资中的占比有所提升，**国内创投市场脱虚向实趋势明显**。

![](../Images/8d6ecc37e13d33a5a7cceada78f927bb.png)

烯牛数据显示，2019年国内创投市场**退出数量依旧增长**，但是**增速下滑至9.68%**。得益于科创板开板，**A股IPO数量大幅度上升，2019年科创板挂牌数量达到70支，而港股和美股IPO数量则出现了明显的下滑**。

![](../Images/5ff4247a5ad5e5cc0086bccb85662649.png)

2019年**国内创投市场活跃机构数量**较2018年**减幅超过30%**。主流投资机构在2019年的**投资次数均少于往年**，关注早期投资的机构出手更加谨慎。
