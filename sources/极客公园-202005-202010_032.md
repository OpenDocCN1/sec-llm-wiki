# 特斯拉一降再降，真的是在「割韭菜」吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652884784&idx=1&sn=560bd1ae8656d0e35576f3930c0c45e2&chksm=7e6ab286491d3b9065da915d74e0cd1b2a3aba92e130319dc7569976c9c021ab898e9e338be1&scene=126&sessionid=1681310246#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652884784&idx=1&sn=560bd1ae8656d0e35576f3930c0c45e2&chksm=7e6ab286491d3b9065da915d74e0cd1b2a3aba92e130319dc7569976c9c021ab898e9e338be1&scene=126&sessionid=1681310246#rd)

![](../Images/f88a1fe6cb7ce16ac370e42d428811df.png)  

特斯拉在过去几年获得的优势是产能上的积累，技术体系的完整度，加上品牌的影响力，特斯拉出于对市场的急迫性正在疯狂抢占市场份额。

论汽车降价引起的轰动，没有一家公司比得过特斯拉。  

就在特斯拉宣布降价的前三天，刘阳提车了。得知同款车型比自己买的时候价格低了 3 万元，他头一回深刻理解了什么叫「割韭菜」。

刘阳立马找销售人员理论，得到的补偿措施是获得 5 万元的充电额度，这才让他得到一点安慰。「毕竟我是刚刚提了车，」刘阳说。

一般来说，特斯拉官方给出的补偿是退车，或者三年时间的免费超充。但这仅限于降价前 7 天内的车主，因为特斯拉此前发布的「信心保障计划」显示，如果用户对新车不满意，可以在 7 天内无理由退货。在特斯拉车友群里，既无法享受降价，又没办法拿到优惠政策的人统一管自己叫「老韭菜」。

特斯拉降价并不是一件新鲜事。从特斯拉推出新车以来，价格的变化飘忽不定，甚至给人一种「马斯克自己在定价」的感觉。

但实际上，如果真的从特斯拉或者马斯克本人的角度去考虑，特斯拉这么做，也有自己的一套逻辑在里面。

  

## 一降再降，为什么？

如果把特斯拉发售以来的价格画成一个曲线图，会发现明显的下滑趋势。

以国产 model 3 为例，除了正式预售比低价预售时涨价，不到一年半的时间里，标准续航升级版 Model 3 已经历过 4 次降价，降价幅度一次比一次大。

![](../Images/d1db87059fc17b25137c5283f31bc8ed.png)

国产特斯拉 Model 3 价格升降趋势，过去一年多次降价｜极客公园制图

如果按照正式发售的价格来看，一年时间 model 3 降价 10 万余元，这可能也是全球降价速度最快的车型。

实际上，在国产 Model 3 刚交付时，就有不少人提到：这款车型的降价空间可能会非常大。

根据东吴证券当时发布的报告显示，model 3 零部件约 30% 国产化，预计 2020 年中达到 80%，2020 年底实现 100% 国产，预计国产 model 3 生产成本较美版低 20% 左右。现在，就是特斯拉零部件国产化的结果体现。

另外，有知情人士透露，本次特斯拉降价的主要原因是车内电池由三元锂换成了磷酸铁锂，成本进一步降低。「预料到了特斯拉降价，但是没想到可以这么快，没有给消费者反应的时间。」一位业内人士向极客公园（ID：geekpark）表示。         

![](../Images/c07818543c28ac1f553d79a5fec511da.png)特斯拉降价，人们也更加关注。一说本次降价的主要原因是电池更换为成本更低的磷酸铁锂｜人民视觉

不过，相对于一降再降，让潜在用户喊「真香」的售价，特斯拉一贯被吐槽的车身工艺，却没有得到快速更新。时至今日，关于特斯拉车门对不齐、焊接工艺明显不如其他车企，甚至不如同样作为智能电动汽车的蔚来、小鹏等的讨论，仍在微博等社交媒体上被人时不时提起。

在外人看来，这算不算是「丢了西瓜捡芝麻」？

答案是否定的。

在至关重要的中国市场，不仅是马斯克个人，特斯拉作为一个大的整体，在对自身的优劣势把握和商业决策上，有着自己独特的一条路线。

  

## 唯快不破的商业策略

如果要解答这一系列的问题，第一个答案肯定是：快。

在中国，特斯拉用不到一年时间在上海建立了一座工厂，并在几个月时间内达到了周产 3000 辆的产能，以及零部件快速国产化，新车型 model Y 正在有条不紊地推进……起码有一点可以确信，特斯拉国产带来的「鲶鱼效应」比以往任何一家电动汽车公司都要更加有效，同时也让这条赛道的竞争也变得更加残酷。

但是特斯拉并没有掉以轻心，降价策略就是特斯拉在中国的一次「冲刺」，因为在抢夺市场份额的过程中，容不得半点闪失。

理想汽车创始人李想曾在一个微信群里发过一张北京、上海和深圳三座中国一线城市的汽车销量表，2020 年 6 月，特斯拉 model 3 已经是包括燃油车在内的所有车型销量冠军。「灭顶之灾」，李想这么形容。

![](../Images/300102d5c4f8c9b04940a3e67f3f598b.png)

特斯拉成为一线城市的销量冠军，李想称其为「灭顶之灾」｜网络

在欧洲，特斯拉同样开始发力，根据外媒报道，model 3 是 2020 年 8 月欧洲地区最畅销的电动汽车，销量达 7020 台，特斯拉以一己之力建立了全球的电动汽车标杆产品。

这并不是突然之间发生的事。

特斯拉把汽车产品做成了大型的高智能玩具、这家公司本身具备的「颠覆者」气质以及马斯克本人在全世界范围内建立的影响力，都在缓缓累积势能，最终得以爆发。

有人评论道，人们不在乎马斯克做了什么，他本人自带明星光环，很多人都称自己是「马斯克教」的信徒，这足以证明他的影响力。新能源汽车、航天飞船、脑机接口等商业项目，让很多人成了他的死忠粉。

用马斯克个人的影响力来带动企业的增长，虽然是一出险招，但也异常有效。人们对马斯克和特斯拉的认知优势，已经完全建立起来。当特斯拉正式进入中国市场，第一批「极客」们会去尝鲜，甘愿成为「自来水」。

当然，特斯拉也并不是单纯为了快而快，对特斯拉而言，跑在前面是一件十分有必要的事。

![](../Images/c4e3f31aae73deaa8e64ed0e878ea93a.png)特斯拉必须保持速度，尤其在中国这样巨大潜力的市场｜人民视觉

在行业发展初期，购买电动汽车，用户会获得大量补贴，乘着补贴的势头，特斯拉也正在逐渐扩大市场规模。另外，在特定国家，特斯拉还会享受特定的待遇。比如在中国，特斯拉享受 4 年的免税政策，2023 年起每年向中国缴纳 22 亿税款，这使得特斯拉在中国市场初期可以放开手脚，也必须向前奔跑。

电动汽车毫无疑问是一个大趋势，为了避免竞争也好，为了吃到红利也好，特斯拉似乎都存在着一种危机意识。当然，这也和马斯克的思考，以及特斯拉在产业当中对自己的认知有很大联系。

  

## 不做销量惨淡的「艺术品」

每一家车企的终极目标都是尽可能多销售车辆，现在看来，特斯拉做到了。

现在是特斯拉的「高光时刻」。不仅销量上一骑绝尘，从行业关注的资产负债率来看，最近 12 个月特斯拉的平均资产负债率为 71.9%，为历史最低。

资产负债率此前代表着特斯拉最大的经营风险，也是汽车产业中衡量企业经营是否良好的重要指标。资产负债率越小，说明股东出资多，行业对其看好。因此，为了让现金流更稳固，特斯拉必须将市场放在最优先级。

「特斯拉在过去几年获得的优势是产能上的积累，技术体系的完整度，加上品牌的影响力，特斯拉出于对市场的急迫性正在疯狂抢占市场份额。」一位关注汽车行业的分析师这样告诉极客公园。

马斯克不需要公关，马斯克需要的是企业赶在竞争越来越激烈之前牢牢站稳头号座椅。至于制造工艺的优先级，反而没有那么急迫。因为即便改进工艺，也不会比降价等策略对销量提振更有效果。

对于一家经历过生死的企业来说，当下的商业策略也许是最能体现创始人内心所想。

很明显，属于弱势的工艺并不是马斯克希望改进的，反而加强供应链、降低成本、效率的提升和怎样将车型覆盖到更广的人群，怎么样利用固有的优势「降维打击」，也许正是马斯克作为企业运转的核心，最关心也正在努力往前推进的事情。
