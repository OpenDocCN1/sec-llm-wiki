# 看《信条》之前，这个视频揭露了诺兰的秘密

![](../Images/5d96b3daf599cb973f3e78edeb0afb85.png)看完视频，再看《信条》感觉完全不一样。今天，克里斯托弗·诺兰的新片《信条》（Tenet）正式登陆国内院线。相信有些迫不及待的同学已经在昨晚的午夜场先睹为快了。  
和导演之前的作品类似，《信条》同样玩的是诺兰最擅长的时间游戏。从《记忆碎片》到《盗梦空间》再到《敦刻尔克》，不管类型如何而变化，不变的是诺兰对于「时间」这个元素的执著。机核 GAMECORES 的「开开开开」、「yhhh」和「Alanbread」三位同学用两个月时间，将诺兰过去的影片掰开揉碎分析，制作了一期《诺兰的时间秘密》视频。该视频深入浅出的分析了，诺兰如何利用故事架构和拍摄手法，将时间和记忆这个永恒母体玩出花样的。以及更重要的，时间是如何成为导演作品最核心的元素的。在「烧脑」、「大制作」和「爽」之外，相信这段视频会让你在看了《信条》之后，有一些不同的感受。**视频内容经原作者「机核网」授权发布**![](../Images/db7a680cfca6e2af042c6a77a7974edb.png)![](../Images/114b4215ab55b9799902bb977f723ebe.png)
