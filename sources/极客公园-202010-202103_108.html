任正非：华为公司永远不会出售终端业务

2 月 9 日，华为创始人、CEO 任正非在接受记者采访时表示，不要理解终端就是手机，只要和人、物连接的都是终端。比如说用于汽车无人驾驶的激光雷达，家庭应用的煤气表、水表、电视机，都是终端，手机只是终端中的一个部分。

所以，华为公司永远不会出售终端业务。我们可以转让 5G 技术，但绝不会出售终端手机业务。（来源：新华视点）

微软、谷歌、华为等公司合力组建新 Rust 基金会

Rust 是一门流行的编程语言，尽管语法上类似于 C++，但在提升性能的同时，它还着力于保障内存安全性。今日，Rust Core 团队宣布了新成立的 Rust 基金会，创始成员中包括了微软、谷歌、华为、亚马逊云服务（AWS）等科技巨头，以及原发起方兼 Firefox 浏览器开发商 Mozilla。

新的 Rust 基金会创始成员承诺，将在未来两年时间里提供超过百万美元的预算，用以开发相关服务、计划和活动，以支撑 Rust 项目维护者们构建最佳的 Rust 案例，而现在只是一个新的开始。（来源：cnBeta）

科学家研发氧敏变色绷带，可预防慢性伤口

据外媒报道，压迫性溃疡等慢性皮肤伤口如果不及时治疗，会变得非常严重，甚至有可能导致截肢。一种新的「智能」绷带可能会有所帮助，它能在这种伤口发生之前改变颜色。

这种绷带由密苏里科技大学 Chang-Soo Kim 博士领导的团队研发。它由一种柔性的一次性伤口敷料组成，并在其上喷墨打印出一种专有的氧敏墨水。其原理是，将绷带贴在身体已经受到过度压力的区域，如果底层区域的皮肤血液循环开始受限墨水会随着皮肤氧气水平的降低而改变颜色。

专门的应用程序可以客观分析智能手机照片中绷带的「发光强度」并提供警告，说明需要采取预防措施。此外，该应用还可以用来向通过互联网远程监控病人的医生发送信息。

研究人员希望一旦该技术最终实现商业化，每条绷带的材料总价可以低于 1 美元。（来源：cnBeta）
