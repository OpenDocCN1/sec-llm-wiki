# 2020 抖音娱乐白皮书：揭秘娱乐产业最隐秘的角落

抖音正成为娱乐产业的「大脑」与「神经中枢」。

四年时间，抖音憋了一个大招。  

1 月 18 日，抖音官方正式发布其成立四年以来的首个娱乐白皮书。2020 抖音娱乐白皮书基于抖音官方数据资源，横跨用户、内容、影视、综艺、创作者、营销等多个维度分析，在文娱产业变革的关键节点上，试图全方位勾勒出国内文娱产业在抖音上的重要版图与生态。

刚刚过去的 2020 年对整个文娱市场影响至深。疫情期间，用户线下娱乐停滞，纷纷涌向移动互联网平台，移动互联网平台成为大众情感交流、情绪宣泄、彼此打气的「链接器」与「输出通道」。由此，也诞生了特殊时期的巨大线上文娱需求。

同时，线下业务展开受限，文娱产业开始集体「自救」，主动上「云」。不但内容展现形式从线下迁移至线上，还带动了一系列以「云」上娱乐为场景的创新型新消费模式，如直播、短视频带货。尤其是，短视频平台先天具备音乐、娱乐、社区等流行性元素，在都市快节奏生活下，充分利用碎片化时间，很好地契合了大众娱乐、消费升级的潜在需求。

所以，阵位的变化是双向的。

一方面，用户海量汇聚使得短视频平台 DAU（日活）、MAU（月活）屡创新高，抖音 2020 年 8 月公布，抖音（含火山）DAU 破 6 亿，这意味着每三个中国网民中有两个人使用抖音，每天产生超 3 亿次搜索。据艾瑞咨询数据统计，2020 年 2 月，抖音以 4.9 亿 MAU、2.3 万年日均有效使用时长，成为国内规模体量最大的短视频平台与流量池。

另一方面，明星作为文娱产业的核心，活跃阵地全面转向短视频平台。相较于 2019 年，2020 年抖音平台上明星投稿视频增长近两倍，入驻明星艺人投稿内容总获赞量达 80 亿+，较 2019 年增长 31%，娱乐产业头部明星几乎尽入抖音「彀中」。

抖音作为国内文娱产业风暴眼的中心，正在通过多维度、多角度的海量数据，为大众揭示了疫情时代文娱产业最为隐秘的角落。如今，后疫情时代到来，明星+短视频 、 明星+直播成为文娱产业的常态，2020 抖音娱乐白皮书又将为文娱产业未来的发展走向带来新的科学、优质化视角。

## 当代文娱产业行动指南

回顾 2020 年，国内文娱产业稳中有变。

从平台明星内容消费品类的受众群画像来看，用户呈现年轻化、地理位置上升与下沉并行、深夜消费、男女性别比例差异扩大等特点。

展开来看，在用户地理、年龄层分布方面，三四线及以下城市用户占据近半比例，新一线城市用户领跑，占比最高达 22%。80-95 后是内容消费绝对主力，90 后用户占据抖音娱乐内容的 C 位。

不管性别、年龄层、空间地理位置的差异如何，抖音用户明星内容消费集中在夜间，18-22 点是超活跃时间，用户占比均超 40%。体现出娱乐产业繁荣的新夜经济消费趋势。

在男女用户性别、喜好差异方面，2020 年，女性用户是娱乐内容消费的主力军，如女性用户数量在明星内容消费中占据主导位置，较 2019 年比例增加，占比高达 68%。

除此之外，男女用户的喜好大不相同。

在综艺内容消费中，女性占比从 59% 增加至 63%，而在电影兴趣用户中，男性用户占比则从 56% 变化至 64%，女用户对综艺更感兴趣，男用户则在电影内容消费上胜于女性用户。

在电视剧内容消费中，女性用户更喜欢在短视频中追剧，且以小成本的「甜宠」题材为主；男性用户关注的题材以红色、悬疑推理、乡村喜剧居多。尽管男女用户喜好差异巨大，总体而言，用户喜好集中在影像化、剧情化等休闲内容。

除了受众层面的新波动，娱乐内容行业大环境也发生了不小的变化。

受疫情影响，剧集市场较往年较低迷。尽管如此，依然挡不住优质影视剧集在短视频平台上迅速蹿红、现象级传播，以及用户对影视剧集的热情。2020 年，出现一批爆款影视剧 IP，如《传闻中的陈芊芊》、《三十而已》、《隐秘的角落》等。

一边是，5G 时代下，用户消费场景的转变，从电视、PC 传统通路转向手机移动端设备，低时延、高速率又进一步助推短视频的大面积普及。此外，短视频式传播，内容紧凑、清晰明了，节奏快，符合 Z 世代的消费心理需求，又成为大众高效率追剧的最佳移动平台。

另一边，影视剧集也出现精品化、类型化、轻量化、短剧化等特性。通过精品化、类型化精准覆盖高需求垂类用户，产生较好口碑，进而扩大传播圈层。同时，影视剧集亦有 IP「二次」利用的强大需求，短视频无疑是优质影视剧 IP 二次创作、二次消费最佳选择。以短带长，促进内容消费快速增长已成为娱乐内容行业的主流趋势。

2020 年，受疫情影响，1-11 月电视剧备案较 2019 年同期减少 22%；线下影院停摆，电影撤档，在拍电影项目暂停；综艺节目现场摄制受阻。在后疫情阶段，随着影视剧、综艺市场逐步回归正常。

2020 抖音娱乐白皮书构建出娱乐产业的参照系，为娱乐产业寻找下一个新风向。更重要的变化是，从 2020 抖音娱乐白皮书可以看到，抖音的价值与功能演进在四年间发生转变，从第三方的观察者成为娱乐产业的深度参与者、推动者，甚至是共创者。

## 娱乐产业爆款「助推器」

2020 年抖音和超 200 部、超 90% 的剧集合作；接近 90% 综艺节目与抖音建立合作；电影数据更为亮眼，票房排名前 20 的华语电影全部开设官方抖音帐号，抖音参与宣发合作的电影票房占过亿影片总票房 99.4%。换句话说，大众在市场上看到的绝大部分影视剧集、综艺从开机、预热、到宣发、完结，都可能有抖音的身影。

当然，抖音的参与是多维度、多角度的。

明星引发的「蝴蝶效应」，对热点话题、流行趋势引领、推波助澜，以及社区活跃度的作用不可小视。抖音在新明星引入、存量明星用户话题引导上，引进更多新鲜玩法。这其中，既包括抖音自身产品功能的完善，又包括内外部 IP 联动，各类内容、流量扶持与营销策略。

比如，产品功能、形态方面，仅在 2020 年一年，抖音就上线多达 2.3 万个趣味魔法道具，这些道具成为明星乃至草根用户创作爆款原创不可或缺的元素。同时，抖音作为流行爆款音乐制造机器，不但促成音乐新人、独立音乐制作人崭露头角，更带动老的音乐 IP 重回大众视野。

仅从短视频视觉体验、海量 BGM 两项，抖音就收割、留存住大量用户的创作热情与注意力时长。而挑战赛、直播功能的补充，则为优质内容二次传播、破圈，增强互动、挖掘商业价值提供更多的可能性。

此外，在综合利用影视、剧集、综艺、活动 IP，实现 IP 联动方面，抖音制造出一系列爆款。比如，李雪琴喊话吴亦凡；邓紫棋喊话暴躁老韩头；陈赫花式打嗝挑战玲爷跨次元互动。除了 IP 联动，更有独家 IP 合作，2020 年年底，抖音成为德云社全网独家直播平台，并将「德云男团」纳新进行全程直播。

在影视剧集、综艺 IP 合作、联动方面，抖音也可圈可点。

抖音根据影视剧、综艺剧情、展现情节，适时推出互动，活跃用户的同时，又能以流量反哺影视综艺。举例来说，在电影《我和我的家乡》宣传期间，抖音从省份、明星创作者、导演独家短片几个维度，助推电影宣发。

在《三十而已》热播、关键剧情发酵期间，抖音结合剧情场景，联动湖南烟花厂策划了一场烟火表演。爆款综艺《乘风破浪的姐姐》热播期间，抖音通过 # 姐姐舞挑战话题，联动明星姐姐与用户，还开启综艺直播带货模式。

抖音已深度参与到文娱产业的各个关节环节、流程中，带来的是文娱产业营销、分发、运营模式，以及文娱产业从内容、用户、到达人、明星生态的变化。

## 掌舵娱乐下一个「风口」

正如，初代抖音只是移动互联网众多工具的一种，2.0 阶段，抖音也只是短视频营销分发的渠道之一，如今抖音正走向娱乐产业的「大脑」与「神经中枢」。

抖音不再是娱乐产业简单地物料剪辑、加工、分发的输出渠道，而是将触角伸向娱乐产业的上游，将策划、运营能力渗透至娱乐产业全链条、全环节中。

抖音从 1.0 到 2.0 的进阶、演变之路，本质上是由平台去中心化推荐机制、IPGC=IP（知识产权）+UGC（用户生成内容）+OGC（职业生产内容）+PGC（专业生产内容）营销模式所推动。去中心化算法推荐机制决定了内容为王，优质内容促进平台生态良性发展，持续汇聚优秀创作者与庞大粉丝群体。而 IPGC 模式则将内容创新的权力赋予 UGC 用户。

同时，针对创作者、头部的顶级流量、95 后高潜力新生代艺人等，抖音有不同的扶持策略。

萤火计划面向优质内容创作者，给予流量、变现扶持，品牌加持等资源；针对头部的顶级流量，通过巨量引擎全系营销解决方案，如营销数据系统、营销产品体系、用户沉淀转化体系，以及各类合作模式，包括活动、微代言、定制等，提升顶流商业化运营能力；对于新生代艺人，给予创意支持与流量扶持。

通过独有的营销模式，完善的产品设计，精准的内容审核和分发机制，抖音充分调动起 UGC、PGC、OGC 在内的创新热情、创作自主性与粘性，让平台内容的深度和广度得以极大丰富。在助推影视综艺更好地传播，粘合新旧娱乐阵地的同时，抖音反向输出「智力」，为娱乐产业运营、营销探索新思路。

2016 年，抖音作为新生代内容载体刚刚上线时，谁也无法预料短视频强大的用户影响力，并给娱乐产业带来「鲇鱼效应」。2020 抖音娱乐白皮书既是抖音对过去四年国内娱乐产业观察、经验积累的总结、复盘，又将为娱乐产业未来发展趋势提供更多可能性参考。
