华为 HMS（华为终端云服务）已经成为全球移动应用生态的「第三极」。

2020 年已经翻篇，回顾这一年，中国科技产业在疫情、各种外力的裹挟、逼迫下向前奔跑，不断迭代与升级。尽管困难重重，但中国科技圈并没有因此按下暂停键，在这特别的一年，依然留下许多星光闪闪，值得铭记的优秀创新产品。

自 2010 年第一届 InnoAwards 开始，十年过去，极客公园发现优秀创新产品评选愈发困难，因为每一年都有大量、眼花缭乱的优质创新产品涌现。因此，我们评选的维度、标准也在逐年增加。今年，极客公园从产品力、技术创新力、用户体验，到对全球科技生态贡献深层次挖掘后，华为 HMS Core 精准地进入了我们的「射程」之内。

华为 HMS Core（华为移动核心服务）获得极客公园 InnoAwards2020 中国创新产品评选「年度创新应用服务奖」。华为 HMS Core 之所以令人印象深刻，除必备的产品创新能力，更在于其成长性、可塑性与未来发展潜力。



「光速」生长

华为 HMS（华为终端云服务）已经成为继谷歌 GMS、苹果 iOS 之外，全球移动应用生态的「第三极」。

据最新数据统计，目前，华为 HMS 已在全球 170 多个国家和地区服务超过 7 亿用户，汇聚超 200 万开发者，超 10 万个 APP 集成 HMS Core，应用累计分发量超 2940 亿。

华为 HMS 生态的成长性是惊人的，而成长性是一款创新产品最重要的「安全边际」。

正如 2020 年 9 月，华为消费者业务 CEO 余承东所说，鸿蒙操作系统每天每周每月都在改进，华为开始构建自己的生态，把生态干起来。相比于 2020 年 9 月华为开发者大会 2020 公布的数据，华为 HMS 服务生态的各项数字依然在每时每刻不断跳动增长。相比于 2019 年开发者大会，全球开发者数量已经增长了一倍多。

事实上，华为正式全面开放 HMS 生态仅有一年多的时间。

2011 年，华为帐号上线。五年后，华为 HMS Core2.4.0 版本上线，当时仅整合了帐号、应用内支付、推送服务。2019 年 8 月，在不可抗外力推动下，华为宣布全面开放 HMS 生态，并启动 10 亿美元的「耀星计划」。同一时间，华为 HMS Core3.0.0 版本上线，新增位置服务、云空间服务、游戏服务等核心服务。

华为 HMS Core 作为华为 HMS 软硬件开放能力的合集，构建在操作系统之上，是最能体现 HMS 生态能力的根基。华为 HMS Core 为应用开发者提供一整套应用开发基础服务，帮助开发者以快速、高效、低成本、简易方式建立应用，在华为设备生态内，精准、灵活地实现高收益。

从 2019 年 10 月至今，华为 HMS Core 版本已经迭代三次，每一次迭代都增加各类新功能与服务，最新华为 HMS Core5.0 版本全面开放了包括应用服务、图形、媒体、智能终端、人工智能、安全、连接与通信在内的七大领域能力与开发工具。

至此，华为 HMS Core 已经具备了构建全球应用服务生态网络的全套底层架构与能力赋能。凭借在 ICT 领域多年的积累，华为 HMS Core 拥有一系列差异化的软硬件核心能力。



技术溢出

操作系统的核心在于生态的打造。

为吸引更多开发者，构建更广泛的「朋友圈」。华为 HMS Core 简化了开发者接入流程，支持用户在手机、PC、电视、车机多个终端一键登录，覆盖电商、出行、社交、工具等各类垂直领域应用的开发服务。

同时，为了让开发者获得更好的商业化，华为 HMS Core 在保护用户个人隐私安全、合法合规的前提下，为开发者提供分析服务、动态标签管理器服务等多个用户数据分析功能。

比如，分析服务可以让开发者通过多端数据，更精准地了解用户行为，驱动开发者产品、营销策略优化。 

此外，HMS Core 向开发者提供丰富的基础应用开发服务，帮助开发者高效构建应用，如情景感知服务提供用户地理位置、情感状态等数据，可让开发者为用户提供更智慧、个性化的服务。

定位服务，即用户在应用中的地理位置信息定位，与互联网厂商不同，华为凭借在通信设备领域技术积累，综合运用 GNSS、WiFi、基站等多途径定位模式，能根据用户地理位置，提供更准确的服务体验。

在其他领域华为 HMS Core 的开放能力同样可圈可点。

在图形领域中，图形计算服务将计算机图形学、计算机视觉和深度学习等技术结合，加强图形的渲染能力，让用户视觉体验、游戏体感更加逼真。AR Engine、VR Engine 面向未来 5G 主要应用场景，帮助开发者领先一步探索 5G 时代的爆款应用。

连接与通信方面，华为 HMS Core 提供一系列网络、通信服务技术，如线性马达能力、双网聚合能力、近距离通信服务、无线传输服务等，为用户快连接、低时延、大带宽、高可靠的网络连接体验。

此外，AI 方面，从底层芯片能力挖掘 AI 最佳性能；媒体领域提供图像、音频、全景等一整套能力；智能终端领域，提供多屏协同、人-车-家全场景智慧互联解决方案等。

尤其在安全领域，华为 HMS Core 提供可靠的本地生物特征认证，以及用户数据、设备安全能力，保障开发者、用户开发与使用环境安全。华为 HMS Core 已通过欧洲 GDPR（通用数据保护条例）、EuroPrise（隐私认证）、CSA STAR（云安全联盟认证）等二十多个严苛的国际、国内合规认证。



未来可期：IoT 的星辰大海

2020 年底，华为鸿蒙 Harmony OS 2.0 Beta（测试）手机版发布，未来鸿蒙将拓展到手表、车机、智慧屏等更多终端，实现跨越发展。

随着鸿蒙边界的拓展，华为 HMS Core 生态能力也必将从手机跨越到车机、智慧屏等多类型终端。

2019 年初，华为提出 1+8+N 战略，即以手机为核心，从 PC、平板、智慧屏、音箱、眼镜、手表、车机、耳机八大终端，延伸到外围的摄像头、扫地机、智能秤、移动办公、智能家居、智慧出行等智能硬件、智能场景。

IoT 是下一个战略「高地」，华为 HMS Core 作为华为端到云能力的集合体，不但驱动华为手机业务生态的丰富，随着开发者数量增多，华为 HMS Core 也必定在 IoT 领域挖掘出一个更大的生态。
