# 极客之选年度评选丨年度智能家居：如影智能 AIO BOX 全屋智能套装

种种细节共同造就了自然舒适的智能家居体验。

**在 2020 这魔幻的一年，极客之选（微信号 GeekChoice）与大家一起经历了太多「活久见」的奇异事件，很开心我们能够一直陪在你们身边，并且一直努力为大家奉上更出色的数码产品内容。「年度产品评选」是极客之选每年年底的保留栏目，从 12 月 1 日开始，我们将会逐一揭晓获奖产品，本次评选将涉及三个大类近 20 个细分奖项。从「娱乐至上」到「生产力万岁」，极客之选希望能够通过不同维度和视角，和大家一起聊聊那些 2020 年最有料的科技产品。**  

人们对未来智能家居的畅想，从来都不是局限于几个单品，而是一整套设备能够连接在一起，在合适的场景发挥它们的作用。为此很多厂商都建立了自己的 IoT 生态，控制中枢或是手机，或是智能音箱，无论哪种交互，最终目的都是让体验更自然。

如影智能正是将「全屋智能」这一理念，落实到所有产品细节的一家公司。他们提供了市面上少有的套装式解决方案，推出将智能音箱、全能网关、智能门禁结合在一起的 inSight 智慧中控，配合智能窗帘、智能开关、灯带等设备，能够带给用户最舒适的智能家居体验。而感受它们最直接的方式，就是这套 AIO BOX 全屋智能套装。

![](../Images/466afac1efd03ec0f8d8180a45ca9c4c.png)

AIO BOX 套装的核心是 inSight 智慧中控，它有一块 13 英寸的大屏（Pro 版本），内置专属管家「爱迪生」，除了被动接受指令，他还能在学习你的日常习惯后，结合场景变化给出主动的智能服务。你还能将其与社区门禁系统连接，为访客远程开门。inSight 智慧中控共支持旋钮、触控、语音、App 四种交互方式，六种网关协议覆盖了绝大多数连接场景，配网、控制都变得极其简单。生态方面它支持米家、京鱼座等 IoT 体系，为你的家提供硬件、软件、服务三位一体的全屋智能系统。

![](../Images/a5afff2ab486d8fe6481b9e10629681c.png)

套装中的灯带系统、智能窗帘、智能开关、人体传感器等设备，为用户提供了一整套照明体验。当处于入睡、起夜、观影等场景中时，整套系统像「活起来」一样，调整各自状态，无极调光提供了最接近自然状态的光线变化。

![](../Images/1e44a6e8009b8967b99c7e93a4fe8e26.png)

从很多细节都能看到如影智能产品不一样的地方：智能管家「爱迪生」有日间夜间两种音色；inSight 智慧中控的旋钮用 AMOLED 屏显示参数；智能开关采用手机上常用的 AG 玻璃工艺。更贴心的是，他们让用户买回去的不是一个个智能单品，而是产品+装修服务的一整套智能生活解决方案。即使是小白也不用担心安装调试的问题，全屋智能生活一步到位。

如影智能是一家有技术又有想法的公司，核心团队曾经打造过小米小爱音箱等热门智能产品，他们对「全屋智能」概念有自己的理解，这也是为什么如影智能的产品如此特别的原因。总结来看，如影智能解决了目前智能家居的几个核心痛点，能提供更加主动的智能服务，将产品 + 装维服务结合做打包解决方案，还从全屋智能拓展到了智慧社区安防。种种细节共同造就了自然舒适的智能家居体验，这也是我们将「AIO BOX 全屋智能套装」评为年度智能家居的主要原因。
