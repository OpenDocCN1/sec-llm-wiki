# 2020 年的互联网，有哪些值得被铭记的闪光？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652891482&idx=2&sn=e84bc43537edfa024709d507667b2e06&chksm=7e6a94ec491d1dfa10a2f64bfcf80e2368d26ac3b769518cd8b937d71d69acd3431c6edf2748&scene=126&sessionid=1681310189#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652891482&idx=2&sn=e84bc43537edfa024709d507667b2e06&chksm=7e6a94ec491d1dfa10a2f64bfcf80e2368d26ac3b769518cd8b937d71d69acd3431c6edf2748&scene=126&sessionid=1681310189#rd)

在艰难的岁月里，铭记那些珍贵而勇敢的创新和改变。

没有哪一个年份，能让我们拥有如此繁多且强烈的共同记忆。  

2020 年，社会情绪几乎被新冠疫情、远程办公、实体名单、直播电商、社区团购、大数据杀熟、困在系统里的外卖小哥等事件占据。整个行业似乎一整年都忙于与病毒、系统算法、商业伦理等问题做斗争。

在每一年的岁尾，极客公园都会发掘、评选过去一年科技互联网领域涌现出的最优秀的、最值得关注的产品和团队。通过 InnoAwards「中国创新产品评选」，给信仰创新精神的产品人和创业者一些鼓励，授予好产品以荣耀。

在今年这样特殊的环境里，想要寻找 2020 年里值得被铭记的创新之光，难度也陡然增加。但也正因此，挖掘的过程也变得更值得期待：谁会在 2020 年里，依旧敢于探索、仰望星空？

回看过去，十年前开始的 InnoAwards「中国创新产品评选」，见证了每一年科技互联网的变迁，持续迭代至今。

极客公园始终关注人、商业和科技之间的交错发展。在 InnoAwards，冷静地记录这个时代，以年为单位，为科技创新的历史，写下注脚。透过这份奖项榜单，我们希望你可以从上面获得启发并洞察企业高速成长的「源代码」，看见更清晰的未来与更多可能性。

小米、美团、微信、知乎、字节跳动、大疆……如今的科技互联网巨兽，都曾在诞生之初登上过 InnoAwards「中国创新产品评选」的领奖台。

2012 年的时候，刚刚诞生不久的微信、知乎、雪球、陌陌们作为那一年的创新产品，登上 InnoAwards 的领奖台。

2015 年年初刚上线的 keep，获得当年的「年度产品设计」大奖。我们认为真正好的产品设计能够帮助用户完成那些原本很难坚持的事，比如减肥、健身。

2018 年是微信小程序的第二年，那时候的小程序生态还没有让人看到「商业化」的路径。但我们看到了微信小程序背后所蕴藏的对于生活方式从底层进行重塑的势力与效能，一定程度上已经远远超出了时下互联网产业的探讨语境。最后，将「年度创新产品」的殊荣颁给了它。

而今，这些产品已经深入到上亿人的生活，甚至成为了我们生活的基础设施。

凭借 InnoAwards 奖项输出的价值判断，极客公园聚集了一大批，像雷军、周鸿祎、周源、张一鸣等等，国内优秀的创业者。这群人每年用自己的智慧和卓见创造了新的用户体验，创造了新的技术突破，甚至推动社会高效率的发展。他们是未来生活方式的设计者。

今年，我们将继续为你发掘出那些「闪光」，抛开纷扰，站在时代的洪流上方，去点亮那些真正地定义了技术、玩法、交互，影响到我们生活方式的团队，为创新的个体与组织，集一束更亮的光。

在 InnoAwards 2020，我们设置了年度创新大奖和年度创新榜单，来聚焦那群通过科技和创造力打破时代瓶颈的创新者。奖项结果将于 2021 年一月初揭晓。

无论你在哪座城市，在这个冬天，与我们一起，见证 2020 年中国科技互联网的骄傲和希望。让我们一起，与未来的精彩主动相遇，向足以和时代共舞的产品致敬。
