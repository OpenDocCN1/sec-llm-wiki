# 机器人爆发，能从「潮玩」开始吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652891161&idx=1&sn=8e32259d038cb2783a04e6f0cc61405e&chksm=7e6a95af491d1cb91a0b9f83c500e6cf2b0d7226e7f7e7e0fe2f0803affbf7d988ab9f14d3f0&scene=126&sessionid=1681310195#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652891161&idx=1&sn=8e32259d038cb2783a04e6f0cc61405e&chksm=7e6a95af491d1cb91a0b9f83c500e6cf2b0d7226e7f7e7e0fe2f0803affbf7d988ab9f14d3f0&scene=126&sessionid=1681310195#rd)

机器人技术不断进步后，很可能降维到看起来「无用」的娱乐机器人领域。

今年机器人赛道正成为香饽饽。

包括大量头部投资机构涌进，更包括一些互联网、硬件厂商布局。一位行业人士告诉极客公园，「今年机器人领域投资情况，与往年相比，事件数量变少了，但实际上热度在上升。因为今年头部机构都进来了，整个机器人市场估值抬得很高，包括头部项目有很多重合。」

从公开披露的信息可以看出，与往年不同，今年一线资本机构、互联网巨头、明星创业企业纷纷加码。比如，红杉资本、高瓴创投、创新工场、字节跳动、美团、商汤科技、联想、百度风投等。

「投资人把创始人堵在办公室一定要签署投资协议，所以，今年无论是 To B 还是 To C 机器人都很火。」前述行业人士说。

三个月前，阿里巴巴发布物流机器人小蛮驴，并发布机器人平台，正式入局机器人赛道。另据行业人士透露，行业硬件巨头小米明年也将大力进军机器人领域，有可能面向 C 端推出四足机器人的产品。

值得注意的是，小米的入局可以看作机器人行业的大变量，以往通过生态链布局，小米在硬件「新物种」领域的销量达到了百万甚至千万量级，哪怕这次是几十万量级的销量，也足以改变机器人领域里的热点走向。

## 机器人进入社会的提速，会怎么到来？

前述行业人士表示，「机器人无论是 To B 还是 To C，现在都远远不够完美。但更关键的是场景和成本的不匹配。」

「机器人领域很多技术高度密集。」九号机器人联合创始人兼总裁王野曾在极客公园内部分享活动上说。这也造成其成本一直较高，如果没有在一些场景里大规模的应用，成本就难以降低，往往只能像工业机器人那样，被限制在有限的领域，走少量、高价的路线。

但是机器人技术近年来确实有很大的发展，特别是与 AI、传感器、自动驾驶等技术进步的融合，让机器人领域的场景实际上在扩展。

比如，服务机器人在几年前还是不存在的场景，疫情带来的无人化需求，已经让服务机器人的赛道真正出现。而这个赛道的机器人技术和传统工业机器人赛道的技术，有着较大区别，很多技术的创新点并不在传统机器人的技术上，而是与酒店送餐、商场导购、安全监控等场景需求匹配的技术融合、甚至软件能力上。

机器人的场景是不是能变多，取决于它到底有用还是无用，但是否有用的这件事似乎也不是绝对的，其除了技术能力相关，也和其成本高低相关。

今年完成上市的九号机器人在 2017 年至 2019 年三年间，在双轮电动平衡车、智能电动滑板车累计全球销量突破 547 万台。而是双轮的平衡车和滑板车在中国并没有上路行驶的权力，「路权」的缺乏，让其在中国实质上是一个在交通维度看起来无用的「车」，但有意思的是，这些传统看起来「无用的」产品，到现在依旧保持着稳定的销量。

「我们后来分析，一个很酷的产品，上手难度又低，是不是能开始规模化，核心往往是价格问题，不是决对有没有用的问题。」

九号机器人最早推出过 3 万元、45kg 平衡车，比当时业界知名平衡车厂赛格威价格低 62%；2013 年，九号机器人又将产品价格降至 1 万元，产品重量减少至 23kg。2013 年后，九号机器人再次考虑将产品价格降低三分之一至 3000 元。但这个一直没有改变这是个从几千到几万台的「迷你市场」产品的局面。

九号平衡车真正的突破来自于 2014 年小米带来的思路：「一定要做到 1999，这样才能到达有意义的规模化，也就是至少百万台的量。」小米在投资九号机器人的时候，提出了这个目标。

正是在这个目标下，突破关键技术、供应链瓶颈，再以极低价格、足够酷的产品，推动九号平衡车全球市场销量突破百万台。

那么这样的故事，会不会在机器人领域上演？特别是之前一直引人注目的四足机器人领域，有没有可能出现这种「够酷、易用」，但不一定「有用」的娱乐型产品？

毕竟，市场上四足机器人价格普遍「高冷」。比如，波士顿动力 Spot 月租金数万元人民币，售价上万美金。国内四足机器人产品本身不多，且技术成熟度与其大多有差距，售价也多在 1 万人民币以上。这几乎就是和当年赛格威双轮平衡车，九号平衡车一样的就局面。

而另一边，优必选等公司在运用机器人技术的「玩具机器人」，「教育机器人」等领域也一直颇有发展，这似乎也验证了机器人技术不断进步后，降维到看起来「无用」的娱乐机器人领域的可能性。

## 四足机器人：会是下一个「爆点」吗？

目前，全球工业机器人安装量级在几十万台，历年累计 270 万台套。餐饮机器人在数万级别，扫地清洁机器人则在几百万台量级，未来都将继续呈持续增长的态势。

但除了除扫地机器人破百万量级之外，在销售数量上，下一个撞线、突破百万量级或许有可能是偏向娱乐、消遣型的 C 端机器人。

红杉中国投资合伙人吴茗认为，「B 端的机器人兴起关键逻辑是效率改造，通过机器替换重复的、繁重的工作，使人类的工作可以向更高价值链条的工作去转移，本质是一笔经济账。随着机器人技术的不断进化，逐渐辅助越来越多的工种。」

她认为，C 端娱乐型机器人更偏向科技酷玩和陪伴。比如，红杉中国投资的宇树科技 Unitree A1 在尝试的方向，有机会应用于家居陪伴、亲子娱乐、家居安防、宠物陪玩等场景，也能完成一些竞技炫酷的功能，更偏娱乐性，会更有趣和有温度。

今年包括小米、华为、腾讯等科技巨头都看上四足机器人的价值，在四足机器人领域有所布局。四足机器人兼具 To B 和 To C 双向价值，或许最有可能成为机器人下半场的「黑马」。

四足动物是一个种类极其庞大的群体，意味着四足机器人可以模仿很多动物，有很多的应用场景可挖，仿生科技是机器人技术发展最快的领域之一。四足机器人具有运动灵活、复杂环境适应性强等优势，具有高动态性、高适应性、高稳定性、高负载能力，目前有机会能做的应用场景，如安防巡逻、监控服务、反恐应急、巡检采集、数据勘测、短途送货、教育培训、家居陪伴、仿生和军用采购等都属于很大的市场。

虽然在这些潜力领域四足机器人的技术、成本，还没有突破到普及应用的状态，也没有出现被印证足够高效的场景。但是四足技术走向「潮玩」领域或许已经够用，特别是当机械相关的技术相对稳定，后期又可以通过软件升级，来不断提升扩展能力的时侯。

而更关键的是，谁能够率先推动规模化，谁就有机会通过规模降低成本，当成本突破一定基准线后，技术的领先也会随着市场的领先而不断「正循环」。

从这个逻辑来看，掌握着品牌和用户群优势的小米，确实有在四足机器人领域，复刻 9 号平衡车当年思路的逻辑存在。

![](../Images/d06ce9cd516d5d0181ac928edfb9d57f.png)

杰夫·贝佐斯遛「狗」｜视觉中国  

当然，这可能只是四足机器人加速进入社会的一个特殊阶段，最终其价值肯定不止于「潮玩」。

「当下，大众仍然认为行动灵活的四足机器人是一个很炫酷的黑科技。无论是 B 端还是 C 端，目前四足形态的机器人都还在尝试阶段，类似一个炫酷新物种。但伴随着技术的发展，以及生产能力的提升，四足机器人会和我们投资的泡泡玛特一样，从潮流前沿回归到大众更底层的需求，被纳入到更广泛人群的消费菜单。」红杉中国投资合伙人吴茗说。

不管怎么说，原来都是在网络视频里做网红的四足机器狗，明年可能真的要在你家小区出现了，就像那些看起来很帅的平衡车一样。
