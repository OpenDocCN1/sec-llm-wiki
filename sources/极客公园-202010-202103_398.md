# 定了！极客公园创新大会一月见

今年，我们想要试试把「大会」这件事给彻底创新一下。

各位亲，极客公园又忍不住想创新一下了。

眼看又到了一年的年底，而每年冬天极客公园创新大会（GeekPark IF）都是一个科技圈和极客们期待的大聚会，这件事我们已经干了十年。

每一年，我们都看到拖着箱子从外地来的观众；每一年，也都看到很多优秀的创新者来投入地分享自己看到的未来，和走心的「年终总结」；当然每一年，这也意味着是极客公园同学们长达几个月的加班和「鸡飞狗跳」的忙碌。

极客公园内部经常挂在嘴边的一句话是 Geek Things Up！说白了就是和「自己再较较劲儿，努力再好一点」。

如果你是通过我们的公众号认识极客公园，你可能会觉得我们是一家科技媒体。但其实，我们是一个创新者社区。我们希望生生不息地发现科技创新者，成为他们的思考伙伴，一起创造更大的价值。

不过这个时代，你自己是什么，有时候是被大家定义的。即便在科技圈内，大家对我们的第一印象也是「最会搞大会的」。

那好吧，不解释了。虽然我们想做的事远不止于此，但至少我们不能辜负大家的期待。

每年冬天，极客公园年度大会 IF 会准时上演，如今已走过十个年头。上一个十年间，从早期只能容纳两百多人的阶梯教室，到连开三天，吸引几万人到场的科技盛会，IF 已经成为中国品质最高的科技大会 IP。

📹 [https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=z3206hf62cg](https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=z3206hf62cg)

十年，这个舞台伴随中国的移动互联网从方兴未艾来到黄金时代，见证了众多科技创新者的诞生，记录了新一代创业者和企业家的成长。

更重要的是，我们一直认为我们在做「沟通」。我们想要把科技带来的希望与机遇，把我们所兴奋的与所思考的，把那些值得用科技实践和创造的，在年底做一次集中的总结与展望。每年一次，坚持做下去。

今年，是极客公园创新大会的第十一个年头，我们要 Geek Things Up！不能光喊口号，开动之前，我们问了自己几个问题。

**我们能不能让这些思考与火花不只被几万人感受到，而是被几千万人看到？  
  
过去企业家们轮流上台演讲的方式，是不是最好的沟通方式？我们能不能将演讲创新，让沟通更好？  
  
那些坐而论道的企业家访谈，能不能更接地气？在我们的舞台上，能不能让大家看到更真实的他们？  
  
那些写在 PPT 上的科技，能不能来到现实，让大家看到、感受到，甚至能买到？**

「念念不忘，必有回响。」一切都是有可能的，只要你敢去试一试，敢再鸡飞狗跳地和自己较较劲儿。

每年冬天，IF 都准时抵达。它之所以有趣，是因为它不只是一台简单拼凑大佬明星的晚会，不是一个用科技装酷的工具，而是融合了极客公园社区那些创新者的思想，也带着极客公园独立思考的「贺岁片」。

那么今年我们想聊聊什么呢？

我们想挖一挖，科技领域那些用自己的产品改变了人们生活的企业家们，他们的脑子里都在想些什么？什么是他们认为接下来最重要的事情，什么是他们眼中的未来？更重要的是，如果你想加入一家有潜力带着你或奋斗或躺赢的优秀公司，你要怎么「面试老板」，「看懂赛道」？

我们想聊一聊，未来中国将会出现哪些领先全球的技术和科技产品？三维交通、芯片、以人为中心的 AI、数字孪生……哪些中国世界领先的技术会带给我们更多的世界级产品？什么是在下一个 3650 天里最值得我们期待的新变化？

我们想盘一盘，为什么马斯克曾经被看做疯子，如今却被看作是最大的英雄。蔚来、小鹏、理想为啥去年还是步履蹒跚的「小弟」，今年就变成了「乘风破浪的哥哥」？新造车的突破为什么还只是个起点？下一个十年，数字化带来的新交通，将会怎样改变我们的社会？

我们也想观察一下那些因为科技和互联网，正在迅速改变的「传统领域」。疫情让教育行业快速发展，在这个关于几乎中国所有家庭的大事上，有些东西已经发生了永久的改变。为什么教育领域 20 年来迭代出了三代巨头？科技会让教育的未来通向哪儿？未来的孩子到底会更轻松还是更紧张？

另外，当元气森林、完美日记、三顿半、喜茶………在过去的几年间突然就成为了我们眼里的新品牌、新选择，到底是什么让品牌迭代？为什么现在越来越多的创业者不去抢 App Store 的位置，而是开始去争夺超市货架、电商首页的位置了？这种和每个人相关的变化，其实都和科技商业的创新相关。

**1 月的最后一周，这部科技大片即将上演。不同以往的是，这一次，你只需要坐在家中，就能够与千万极客一同品鉴，享受数字化和互联网带给我们的更大的便利、更好的体验。**

极客公园想试一试，能不能让这次 IF 大会超越过去十年的成绩，让这次大会本身也真正地成为一个「创新的」大会。

要怎么做？我们打算先卖个关子。BTW，这次我们会有一个非常令人期待的创新伙伴加入进来，我们会一起努力给大家一个惊喜。

关于本届 IF 大会的进展与更多信息，我们会逐步放出。请大家关注公众号极客公园公众号（ID：geekpark）。

愿我们「十年如初见」，2021 年 1 月末，不见不散！
