# 字节跳动的 To B 新故事

解放创造力，让一部分企业先「飞」起来。

谁会成为中国版的 Slack？这个争论一直存在于中国的企服市场，最早被寄予厚望的是钉钉，之后是企业微信，就像击鼓传花一般，如今业界目光又都投向了字节跳动的飞书。  

问世三年多，飞书才于近期举办首场发布会。飞书最初仅在字节跳动内部使用，是员工对内沟通协同的工具，之后，这款产品逐渐对外，变成可销售的服务，2019 年飞书正式推向市场，以先进工作方式为卖点，成为字节入局企服市场的头排兵。

这个头排兵的首秀办得很热闹，推出飞书的全新版本「π」，独立 App「飞书文档」，还邀请了罗永浩、Papi 酱、李诞等一众红人站台。发布会聊未来企业、智慧办公，谈先进组织，创新文化。关于飞书，字节跳动究竟想讲一个怎样的故事？

  

## 「数字化原生」的工作方法

飞书是什么？负责这款产品半年多，这是飞书总裁张楠被问到最多的问题。

飞书是 OA？是企业 IM？还是云文档工具？这些答案可能都不太准确。发布会上，张楠给飞书的定义是「一站式的企业协作平台」。

张楠强调，所谓「一站式」，「不是简单地把各种功能堆砌在一起，而是用统一的界面和交互，实现不同系统的有机打通」。

打开飞书，产品主页面是消息栏。与微信、QQ 等通信工具以对话为主的消息栏相比，飞书的消息栏更加丰富，集合了对话、日历提醒、文件、会议审批等诸多内容。

这正是飞书一站式协作办公的关键，**将会议、文档、审批等诸多办公场景与通讯整合打通，用户可以通过中心化的信息流来处理工作，而不需要在各个工具之间来回切换**。

![](../Images/c9784edddf6fa5fb9b9527a759c66cce.png)

飞书产品页展示｜飞书

举个例子，使用飞书文档时，你可以针对表格里的一项数据添加评论，涉及到与相关同事讨论时，还可以直接 @ 对方。此时，同事立刻会在飞书的消息栏收到通知提醒，而他只需要在这个界面里就能完成文档查阅并回复。

除此之外，当同事提交了一条审批，你也可以直接在消息栏里批复，无需切换到公司的审批平台。当同事填写 OKR 时 @ 了你，你也可以直接在消息栏里查看对方的 OKR 详情。

**为什么强调「信息流」？张楠有个笃定的预判是「信息流未来将逐渐代替工作流主导企业的运作。」**

张楠进一步解释，伴随着制造业兴起，市面上出现了很多 ERP 系统帮助企业把生产要素数字化，可以定义清楚并有效管理每个环节的工作流程，进而降本增效。

只是新时代的企业，智力劳动的密集程度越来越高，企业的工作流很难再通过单一的 ERP 系统实现流程化。「因为知识型工作者的成果很难通过计件衡量。企业的运作不再是基于工作流，而是信息流。」

**因此，信息流动的效率成为了企业业务发展的核心，这也是飞书产品设计的底层逻辑**。**「重视信息，无论是信息的创建、信息的流动，还是信息的沉淀」。**

过去一年，字节跳动近 10 万员工在飞书上创建了超过 2000 万篇文档，如果打印成 A4 纸，堆叠起来的高度将接近珠穆朗玛峰。如何让这些文档信息能更有效地在公司内流动，方便同事调用查找？为此，飞书开发了多维表格功能、双向链接等多种文档功能。

![](../Images/a69d91ef87ec3acf5b5512dab2fd911d.png)飞书多维表格功能展示｜飞书

不同于传统表格，飞书多维表格可以把信息更加结构化地组织起来，并且有多种视图，能够更清晰地表达数据之间的关联关系。如果引用了多个其他文档，系统会自动建立文档间的双向链接关系，通过生成网状关系图，帮助用户更好地找到相关文档。 

此外，为了让员工更有效率地撰写文档创造信息，飞书还开发了思维笔记功能。思维笔记在撰写时只是一个简单的大纲模式，没有复杂的格式和排版，用户可以一键把大纲转化为思维导图，这样就能清晰看到各个层级的关系。

一位业内人士表示，**飞书发布的这一系列新功能，本质上是希望在数字化的环境下，创造一套「数字化原生」的工作方法。**

## 解放组织生产力的操作系统

在打造飞书的过程中，字节跳动是飞书的第一个客户。飞书有个话题圈功能，这是基于员工的交流社区。字节跳动内部专门创建了飞书产品吐槽圈，曾经的圈主正是字节跳动创始人张一鸣。

接受包括极客公园在内数家媒体采访，张楠提到，张一鸣对飞书的关注非常全面，从产品细节到整体架构，比如，进入到某个界面为什么英文字体变了？翻译的入口怎么找不到了？遇到这些问题，他都会顺手转给飞书团队。

**实际上，很少有公司像字节跳动，对生产工具的选取有着近乎强迫症般的执着。极客公园此前报道，字节跳动曾在公司层面进行过四次全员的生产工具迭代。**

![](../Images/cac43136e5f84a9e0119a0bd9be40df2.png)

字节跳动的工具变迁图｜字节跳动

最早是 Skype，紧接着是微信企业号，Slack，钉钉，最后才是飞书。对字节跳动而言，最适合才是最重要的。Skype 有多人通话功能，能够满足团队早期线上沟通的需求。只是，随着团队规模扩大，成员沟通就不仅限于通话，还涉及文档传输、工作流程安排等诸多问题。

Slack 功能相对全面。然而，作为一款国外软件，它甚至无法将群组名称修改为中文。字节跳动的产品经理和工程师们倒是挺喜欢，可其他部门的同事却难以适应它的产品界面，考虑到公司运转的整体效率，Slack 于是被替换掉。

不同的发展阶段，企业对于生产工具的需求侧重也是变化的。小型公司做好沟通即可，中型大型公司的业务线更复杂，团队协同部门管理的难度更大。**因此，字节跳动非常生产工具的扩展性与适配性。这也是他们决定自主开发飞书的缘由。**

![](../Images/54480f24c2bbd54f7ddf5f9fc5824a16.png)飞书最新产品功能汇总｜飞书

此次发布会，张楠宣布，「飞书核心功能已经开放了 167 个 API，是行业其他产品的两倍以上。到明年 2 月份，我们会继续增加 50% 以上的 API 数量。」这意味着，飞书不仅仅是一个协作工具，也是一个开放平台，企业可以根据自身需求配置相应功能。

张楠举例，飞书企业用户货拉拉把审批、行政、HR 等多个第三方应用系统都和飞书做了集成，还基于飞书的开放平台，自建了将近 100 个应用，实现了办公平台体验的一站式整合。

一位业内人士分析，**未来飞书可能不只是一个工具，而是在满足企业沟通协作这类基础的需求上，不断开放 API 拓展应用边界，成为一套面向企业内部解放生产力的操作系统。**

字节跳动副总裁谢欣曾提到：「当前大家看到的飞书更多是一个提升效率的产品，但我们发现它一定程度上在帮助组织变革。人和信息已经成为了企业构建竞争力的核心。所以飞书会特地围绕这两点去强化。」

发布会上张楠也曾提到，企业组织会从物理形态进化成生物形态。意思是，未来组织是能够自我进化的，是能够激发每个员工成为生态里的一个单元，进而实现公司整体性发展。

相应地，组织的生产工具需要有可扩展和自适应的能力，也应该具备释放员工创造力和自驱力的能力，因此，对「未来」企业的思考，正是字节跳动在飞书上希望讲述的故事。
