## 传软银将暂停对中国投资，官方回应：不予置评

![](../Images/ecede5c5caf0afdcd499953db052ae13.png)

8 月 11 日晚，软银中国资本声明称，软银中国资本有注意到相关的媒体报道，对于日本软银集团在中国的投资策略我们不予置评，软银中国资本将一如既往地致力于在中国投资优秀的高科技、高成长性企业。  

截止发稿前，该声明又被官方删除。此前，据媒体报道，软银集团股份有限公司表示，将暂停在中国开展新的投资，同时观察相关部门对国内科技行业的整顿走向将如何发展。（来源：第一财经）

  

## 黑客窃取 6 亿美元加密货币，或成史上最大的加密货币盗窃案之一

区块链网站 Poly Network 本周二表示，黑客利用了其系统中的一个漏洞，偷走了数千枚数字代币，包括以太坊等，总计价值约 6.1 亿美元。这可能是有史以来最大的加密货币盗窃案之一。

在 Poly Network 向黑客发出通牒，要求他们「建立联系并归还被窃取的资产」后，并警告他们否则将会被各国执法部门追捕后，黑客们开始返还他们窃取的部分加密货币。截至本周三晚 23 点，价值约 2.58 亿美元的加密货币已被退还到 Poly Network 的地址。（来源：新浪财经）

## 马斯克：SpaceX 可以为 NASA 生产宇航服

![](../Images/0bf27a0b4ea06287a370a8c84bbf638d.png)

据报道，埃隆·马斯克近日提出，SpaceX 公司或可以帮助 NASA 制作下一代宇航服。因为本周二一份报道称，NASA 当前的项目落后于原计划，并将花费超过 10 亿美元。  

此外，NASA 发言人莫妮卡·维特在之前的一份声明中表示，该机构上个月曾要求航天行业内的企业就「购买商业宇航服、硬件和服务」提供反馈。据了解，马斯克的提议也是为了回应这个声明。（来源：新浪科技）

  

## B 站日活突破 6500 万，用户使用时长超 80 分钟

《晚点 LatePost》获悉，视频网站 Bilibili（B 站）日活跃用户在近日已突破 6500 万，超越优酷成为仅次于爱奇艺与腾讯视频的第三大长视频平台。在用户使用时长上，B 站已经稳定在 80 分钟以上，低于抖音的超 100 分钟。（来源：晚点）

## 深圳试点首席数据官制度

根据深圳市人民政府办公厅印发的《深圳市推行首席数据官制度试点实施方案》，深圳将在市本级政府，福田等 4 个区政府，市公安局等 8 个市直单位试点设立首席数据官，首要职责为推进智慧城市建设。

深圳首席数据官职责主要为推进智慧城市和数字政府建设、完善数据标准化管理、推进数据融合创新应用、实施常态化指导监督、加强人才队伍建设和开展特色数据应用探索六大方面。（来源：36kr）

  

## 瑞幸咖啡筹划新一轮融资，官方回应：近期公司没有任何融资安排

## Impossible 推出新版植物肉香肠，主要用于食材准备

![](../Images/41e57dfcd6067743718e2cf652f2fbea.png)

Impossible食品公司近日宣布了其第二款香肠产品，以替代2020年6月推出的针对早餐的 "Impossible植物香肠"。新款 Impossible 香肠采用散装方式，有咸味或辣味版本。  

Impossible 公司表示，新款 Impossible 香肠 2 盎司中含有 7 克蛋白质，并且没有胆固醇。与肉类同类产品相比，总脂肪和饱和脂肪分别减少 47% 和 43%。新款建议价格为 5.99 美元。（来源：cnbeta）

## MIT 新算法：可训练无人机避开障碍，从而飞得更快

![](../Images/5e53863a0170f9d22f77cfc69f5b8e1c.png)

据了解，近日麻省理工学院工程师已开发出一种算法，使无人机能够选择最快路线，绕过障碍物。该算法结合了无人机飞过虚拟障碍物的模拟，以及无人机在现实世界中飞过相同路线的实验。  

当无人机使用新算法进行训练时，它们穿过障碍物的速度可以比传统算法规划飞行路线的无人机快 20%。项目研究人员认为，他们开发的算法未来可以使得无人机迅速浏览高度复杂的环境。（来源：cnbeta）

  

## 中国首座训练风洞投入使用，最大风速相当于 14 级强台风

十多年前，美国宇航局利用风洞技术帮助美国国家游泳队寻找阻力最小的泳衣材料，引起不小的轰动。目前，中国首座专门应用于体育综合训练的风洞已经投入使用，运动员正在为明年的冬奥会作准备。

据报道，这座为冬奥会量身打造的体育综合训练风洞，最大风速可以达到** 42 **米每秒，相当于** 14 **级的强台风，基本上涵盖了所有冰雪运动所涉及到的风速范围。（来源：快科技）

  

## OpenAI 推出 Codex：一款可将自然语言翻译成代码的 API

![](../Images/086fc484f2caa4221b73400b6981f856.png)

为 GitHub Copilot 辅助编程工具提供技术支持的 OpenAI 组织，现又推出了可将自然语言转译成代码的私有测试版 Codex API 。这套应用程序接口能够理解十多种编程语言，允许开发者以简单的英语词汇来阐述相关命令并执行，从而轻松为当前的应用程序开发流程引入自然语言编程体验。  

据 OpenAI 所述，该 API 模型最擅长于 Python，但也「精通」JavaScript、Go、Perl、PHP、Ruby、Swift、TypeScript、Shell 等编程语言。得益于 Python 编程时的 14KB 内存，Codex 还能够在执行包括转译、解释和重构代码等在内的任务时，充分考虑到上下文信息。（来源：cnbeta）

## NASA发「模拟火星生活」召集令：管吃管住发工资，与世隔绝过一年

![](../Images/e033be1f99f4901bf3ab436a4da9f1c4.png)

近日，NASA在官网发布了一项模拟火星生活志愿者招募计划，第一次面向全社会公开募集对火星生活感兴趣的人才。选中的人员将在 3D 打印的仿真火星栖息地居住一年，为未来的火星探索任务提供观测数据。  

NASA 此项火星生活模拟计划将进行三次，每次由 4 名入驻成员和 2 名候补成员参加。第一项实验将于明年秋季开始实施，此后两次实验分别计划在 2024 年和 2025 年展开。目前，明年秋季项目的招募通道已经在NASA官网上正式开启。（来源：品玩）
