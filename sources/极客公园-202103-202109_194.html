微软发布 Windows 11 

大概很多人自己也不会想到，有一天会为微软发布新系统而兴奋。

本周，微软正式发布了 Windows 11 系统，全球超过 13 亿的 Windows 10 用户将有机会感受新系统的魅力。

首先，Windows 11 在系统 UI 上进行了新的设计，不仅抛弃了 Windows 8 时代的磁贴设计，甚至直接将开始菜单，从左下方移到了屏幕中间；常用项目和开机选项也一并放到了任务栏的中间位置，再加上圆形边角，有那么一瞬间，还真让人产生一种苹果系统的错觉。看来，操作系统的美学终点是苹果，确实是真理。

抛开 UI 设计，Windows 11 最大的亮点，是可以原生使用 Android 应用。发布会上，微软演示了如何利用亚马逊应用商店，下载美国大热应用 TikTok。为了保证 Android 应用的顺利运行，微软的老搭档英特尔特地开发了一个 Intel Bridge，后者是一个编译器，能让移动端应用跑在 Windows 上。

经过重新设计的微软应用商店｜微软

其实，让 Windows 跑 Android 应用是微软下一步发展的重要一步。正如苹果在推出 M1 芯片的 Mac 系列电脑后，iOS/iPad OS 和 Mac OS 的融合的野心已经昭然若揭。微软的尴尬在于，一方面不会像苹果一样造「芯」，另一方面移动设备和系统（手机）的缺失，使其丧失了成为「大一统」系统的机会。

从 Windows 8「坑死」了诺基亚，再到现在依然难产的Surface Duo 折叠屏手机，微软在「补齐」移动端的路上走得无比艰难。去年 Surface Duo 折叠屏设备曝光后，专门为其打造的 Windows X 系统成了内部和外部都寄予厚望的项目，从目前来看虽然新的 Windows 11「吸收」了不少 Windows X 的精华，但毕竟少了一个移动系统冒头的机会。

没有自己的系统，就会受制于人，例如打通 Android 应用这一块，微软的演示需要「借道」亚马逊的应用商店，而微软明明已经重新设计了自己的应用商店。同时，虽然可以用上 TikTok，但是使用了 Google 核心服务的应用如 Gmail、YouTube、谷歌地图还不能进入微软应用商店——美国「卡」华为高端机在欧美销售的时候，用的也是类似的路数。

有乌云也会有金线，在欧美反垄断愈演愈烈的情况下，相对于被指责「抽税」过高的苹果、颠覆政权的 Facebook 和让中小商家无路可走的亚马逊，微软反而是最安全的巨头，没有之一。

就在 Windows 11 系统发布前一天，微软市值突破 2 万亿美元。

大小周风云

中国人有个习惯，婚礼需要领导作为证婚人讲话。有一年阿里公司员工的集体婚礼上，马云老师作为领导在台上教育新人们，白天干活要「996」，晚上回家要「669」。996 大家都知道，669 到底是啥很多人也没敢问，当然也有老司机吐槽，说 996 之后再 669，身体不允许。

当然，对于中国互联网人来说，即便没有洞房 669，但是在公司 996 却是必须的。

但是现在，情况可能终于有点了变化。

近日，已经上市的快手公司发布公告，除非必要，不再实行全员大小周制度。快手在两年前左右开始实行大小周制度，也就是一周休息一天，一周休息两天。中国在 1995 年开始实行双休制，当时的人们估计没想过自己的孩子未来会在工作福利上开起倒车。

好像也不能怪快手，毕竟此前快手向来以「佛系」著称于中国互联网行业。自从字节系的短视频平台抖音崛起，用户增长以「亿」计之后，快手也不得不「狼性」起来。实行了大小周之后，当年快手就砸钱拿下春晚，把用户做到了 3 亿以上，虽然事后团队认为春晚「K3 战役」并不成功，但是在那个时间点上，除了迎着对手向前冲，好像也没有别的办法。

无独有偶，刺激快手的字节最近发起了一个内部调研，想看看员工对于大小周制度的看法，结果出人意料——居然有三分之一的员工并不赞同取消大小周制度。原因并不是「热爱工作」，而是加班有双倍工资，如果取消了大小周，有些人甚至一年少赚了 10 万元。

似乎为了多赚加班费而主动要求加班的，和想多保持工作和生活平衡的，两群人形成了一对矛盾。其实，字节和快手属于明码标价的 996，加班费给的并不少，不过最大的 bug 在于这是个全公司执行的制度，似乎缺少自由的选择权。

但反过来，如果有劳动者想奋斗、成长、想有更多成就感，想多挣钱，是不是公司也必须拒绝掉这个劳动权利？这真是个令人迷惑，也难以解决的问题。

中国互联网发展二十多年后，网民数量已经超过 10 亿，增量市场转为存量市场，巨头之间的竞争出现越来越多的零合博弈。这种情况下，亦步亦趋紧跟对手，很容易造成「内卷」。一家开始「大小周」，竞争对手不敢「996」，感觉就输了一阵。

但即便是在字节和快手这样的新锐公司，也一样会有员工「带薪拉屎」、「带薪摸鱼」，对没有选择的加班进行消极抵抗。毕竟每个人追求不同，在一个几万人的公司做到全员精神高度统一，只靠明码标价买勤奋，是不可能的。

不管大公司里的大小周是不是会从此终结，为什么总还是会有大公司里优秀的人，会流向还在「996」的创业公司？甚至大公司还会有很优秀的人，出来变成自己要求自己「007」的创业者？

也许因为他们不想只是要明码标价的加班费，而是寻求参与创造一些新东西的成就感，当然，还有比加班费获得更高回报的可能性。

归根结底，这个世界对于「变大」天然是有约束的，你看，世界竟然在用奇特的方式，对大公司的生命力进行「反垄断」——利用资金实力明码标价购买集体勤奋，将会越来越难。

小鹏汽车拟在香港上市融资 19.7 亿美元

在纽约上市的小鹏汽车正寻求在香港上市融资不超过 19.7 亿美元，有望成为第一家回归上市的中国电动汽车生产商。

根据提交给美国证券交易委员会的文件，小鹏汽车将在此次发行中出售 8，500 万股，面向香港投资者的部分最高定价每股 180 港元。这比其美国存托凭证周三收盘价 41.61 美元溢价约 11%。小鹏汽车 1 份 ADR 相当于 2 股普通股。

此前有报道称，蔚来汽车和理想汽车也有意赴香港上市。此次提交上市文件意味着小鹏汽车已经先行一步。（来源：新浪财经）

世卫：德尔塔变异株是迄今最易传播的新冠变异株

当地时间 25 日，世卫组织举行新冠肺炎例行发布会，世卫组织总干事谭德塞表示，德尔塔 (Delta) 变异株是迄今为止发现的最易传播的新冠病毒变异株，该变异株正在未接种疫苗的人群中迅速传播。随着一些国家放松公共卫生措施，全球范围内的病毒传播增多。

谭德塞强调，未来还会出现新的变异株，病毒会进化，但可以通过遏制病毒传播来防止新变异株的出现。（来源：央视新闻）
