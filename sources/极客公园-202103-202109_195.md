# Windows 11：面子仿苹果，里子反苹果

Windows 能跑 Android 难称革命，但微软显然也不依赖 Windows 赚钱了，这样做还能赢得「开放」的好名声。时隔 6 年，微软带来了新一代操作系统 Windows 11。新系统无处不在的圆角设计，以及对毛玻璃材质的模拟等细节都让人联想到 macOS。而最让人惊讶的是，Windows 11 还开始支持原生运行 Android 应用。有网友戏称，这是「苹果风，安卓心，微软生。」![](../Images/01ddbb4cd42ed3051ca899fae3fa6e1b.png)除此，微软还宣布，开发者在微软商城上架应用时，如使用第三方收费渠道不会遭到拒绝，微软甚至完全不从中抽成。这和苹果「围墙花园」的策略形成鲜明对比，后者禁止从应用商城外下载应用，必须使用其应用内支付系统，并支付 30% 佣金。这让 Windows 11 看起来像是：面子在仿苹果，里子在反苹果。支持 UWP、PWA（网页 app）、Android 应用，同时声明在一些前提下不收开发者一分钱，微软是想靠「开放」重整失败的应用商城吗？Windows 求变，我们又能否从中窥见微软的未来？  

## Windows 怎么跑安卓？

Windows 这次支持原生运行 Android 应用的新特性，和之前推出的「Your Phone」实现原理完全不同。虽说「Your Phone」也能让用户在 PC 桌面上和 Android 应用交互，但它本质上是「手机投屏」。由于这个功能是微软和三星深度合作开发，所以其他品牌的手机并不支持这项功能。**而在 Windows 11 上，用户无需连接手机就能跑 Android 应用，比如在 PC 本地上运行不提供 web 端的移动端应用，比如抖音、外卖、打车应用。**![](../Images/2593bde4e814a592cec76b398d59963f.png)**但就目前，用户能在微软商城上搜索并下载的 Android 应用，仅限亚马逊 Appstore 现存的应用。这就像是微软多开了一个「柜台」，在帮亚马逊平台做应用分发。**大部分 Android 应用基于 ARM 架构开发，而 PC 多为传统 x86 架构。那么，Windows 跑安卓是如何实现的？微软找来了又一位盟友英特尔，英特尔提供了一项名为「Bridge」的技术。这是一个运行时后编译器（Runtime Post-compiler） ，可以把 Android app 转换为 x86 指令，让面向 ARM 架构开发打包的移动 app 可以在 x86 架构的 PC 上运行。但在 Windows 上运行 Android 应用，用户接入不了 Google 服务。因为完整的 Android 系统包含 AOSP 和 Google 移动服务（GMS），前者为开源部分，后者可以理解为 Google「全家桶」和云服务，而 GMS 闭源。另外在中国，亚马逊并不提供 Appstore 服务，那微软具体又会通过何种渠道上架 Android 应用，甚至能否开放该功能目前都还不得而知。此前，「Your Phone」就由于 GMS 等问题未在中国提供服务。另外，在 PC 上运行 Android 应用会不会更多是用户一厢情愿的「伪需求」？就目前，大部分 Android 应用仍是与小尺寸的手机高度绑定的，开发和操作的逻辑和桌面系统的交互存在很多不相容的地方。![](../Images/33c969f7514a5518ab7ffa561e176be4.png)**单就目前看，「能跑安卓」难称革命。**在科技领域，人们会要求弱者开放，而微软商城无疑就是弱者。**同时支持 UWP、PWA、Android 应用，微软在试图靠「开放」重整过往对开发者和用户吸引力不足的应用商城。**  

## 谁动了王者的蛋糕

智能手机早已取代 PC，成为人们的网络入口和控制中枢。Google Analytics 的流量数据显示，去年全球互联网来自移动设备的流量占比已经接近七成，桌面端数据继续下滑。**桌面端市场，就是存量市场，谁增长，就意味着有其他人被动了蛋糕。**macOS 开始增长，还靠自研芯片将 iOS app 带到 macOS 上，这进一步加强了苹果生态的粘性。微软除了要警惕苹果，还得提防 Google。Windows 11 不是第一个能够原生搜索、下载、安装和运行 Android 应用的桌面操作系统，Google 的 Chrome OS 才是。另外，Canalys 数据显示，Chromebook 在今年第一季度出货量相比去年同期增长 275%，是 PC 品类中增长最快的系统。据 IDC 数据，Chromebook 在 2020 年的市场份额获得大幅增长，首次突破 10%，**超过了苹果的 Mac，它所搭载的 Chrome OS 也顺势成为第二大流行的操作系统 ，仅次于 Windows。**但 macOS 占有率并没有下滑，也就是说，Google 这个跑 web 和 Android 应用的系统，从 Windows 手里抢走了肉。![](../Images/a4271fa41156aac1c308917c571cb191.png)在 K-12（中小学教育）市场，Chromebook 靠低价占据了接近七成的市场份额，微软旗下游戏《我的世界》甚至已经支持 Chromebook。**这些未来的消费者第一个接触桌面操作系统是 Chrome OS，买的第一部手机也不是「微软」牌。**虽然 Windows 目前在桌面系统的市场份额高达 73.5%，但在移动互联网时代，很多用户在拥有电脑之前，就会先拥有手机。虽然微软还是桌面的王者，但 PC 却不是时代主角了。微软错过了移动平台，也就等于错过了智能家居、可穿戴等基于移动设备衍生出来的消费市场机遇。比如，没有智能家居生态，微软的语音助手 Cortana 也就没有太多用武之地。  

## 「开放」和「云」，让微软改变了游戏规则

在移动系统 Windows Phone 败北后，微软就再也移动这个战场赢过，但它却用「开放」和「云」改变了游戏规则。微软 CEO 萨提亚·纳德拉表达了他对 Windows 11 的愿景，他希望它能成为「平台创造者的平台」。**具体来说，微软不会让自己的应用商城成为唯一的应用下载渠道。它欢迎第三方商城渠道登陆 Windows 11，为消费者提供更加多元化的应用分发体验。****另外，微软承诺「开发者可以保留 100% 收益」，但这需要满足两个前提，一是应用是非游戏类别，游戏，仍会有固定的 12% 抽成；二是不使用微软内建支付结算系统，如果想要使用则仍须抽成，抽成比例为 12%。**这似乎一下子让苹果的 Apple Store 陷入「公关危机」。眼下，苹果正卷入针对应用商城收取高额「苹果税」的诉讼，微软支持原告、热门游戏《堡垒之夜》开发商 Epic Games。虽然新 Windows 被指形似 macOS 的外观，但它在开放性上，却是「反苹果」的。![](../Images/6ecfc72d7441cf31231abd518637c8f6.png)如果说微软的前 CEO 们的执念是「想让所有操作都在 Windows 上执行」，那纳德拉则是「想让所有操作都能在 Windows 上执行」。之后，微软开始做「平台的平台」，这是在移动战场上失利的无奈，也是它的未来｜视觉中国在 2014 年纳德拉上任后，「开放」就成了微软的关键词。2015 年，微软贡献了 16419 个开源项目，成为 GitHub 上公开代码最多的组织。这让开源世界有些吃惊。因为微软是 2014 年才开始在 GitHub 上建立账户的。2018 年，微软以 75 亿美元高价收购 GitHub，是微软在 2018 年架构调整后进行的最大收购项目。「移动为先」是纳德拉上任后的战略重点。**但对于移动市场，他有自己的思考：把以 Office 为代表的微软生产力全家桶移动化，「开放」给 iOS 和 Android 平台。**2014 年 3 月，微软宣布将 Office 套件带入 iOS 平台。几天后，微软又发布了 iPad 版 Office。在 2015 年 Salesforce 的年度营销会议上，纳德拉带着一部 iPhone 就上了舞台，这引发了现场观众「不怀好意」的笑声。在此之前，没人见过微软 CEO 在公开场合展示 iPhone。对此，他应对自如，笑着说，「这虽然是一部 iPhone，但它却安装了微软所有的软件和应用」。这打破过往微软生产力应用拘泥于自己平台的桎梏，再让其触及到更多移动用户的同时，也让微软生产力应用在移动互联网市场不被用户抛弃。让用户在移动端使用生产力软件可以无缝衔接到桌面系统的保障，是微软的云服务。「云为先」是纳德拉提出另一个战略重点。2014 年上任后，纳德拉发布了一份公开备忘录，在里面提到了自己对微软未来的看法和计划。「在这篇文章中，纳德拉提了 10 次 Windows，但还没到第 21 段的时候，已经说了 21 次 cloud（云服务）了。」彭博社如此评价。随后，纳德拉正式确定了云战略的业务步骤：微软将围绕 Office、Azure 大力发展云业务，通过云端平台重塑生产力和流程，建立以云计算为核心的生态系统。也正因如此，云业务目前已经成为微软营收增长的核心驱动力。自 2020 财年 Q3 季度开始，「智能云」业务收入连续 3 个季度成为微软最大的营收来源。**当年，纳德拉坚持关停 Windows Phone 操作系统时说他实在想不明白用户为什么需要第三个操作系统，客户并不需要，除非能改变游戏规则。「开放」和「云」，让微软改变了游戏规则。**在 Windows 11 发布的前两天，微软市值正式突破了两万亿美元，成为仅次于苹果的全球市值第二大科技公司。在纳德拉执掌微软的过去六年里，微软股价飙升了五倍，过去两年增长了一倍，这种疯狂的涨势显然与 Windows 没有太大关系。![](../Images/c0c111c50bb8f0330ef0cf7918709e5e.png)
