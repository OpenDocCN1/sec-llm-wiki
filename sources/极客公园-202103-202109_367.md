# 一个娃娃卖出十几万，被热议的「娃圈」究竟是个啥？

一起来聊聊这个小众的圈子。

「13 岁女孩花 70 万约稿」，这个话题前段时间冲上了微博热搜。小女孩挪用了爸妈银行卡里的存款，找多位设计师约稿。  

后来，这个小女孩又被爆出在「娃圈」做代理，有 300 多人向她支付了定金买娃娃。于是，「娃圈」这个小众圈子出圈了。

关于「娃圈」的争议，你可能听说过一些。像是有人花十几万买娃娃，每年花大几万「养」娃娃。可是，一个娃娃为什么如此值钱？「养娃」又费钱在哪些地方？

听说「娃圈」还有很多讲究，很多规则，比如出售娃娃的厂家被圈内称为「娃社」，每个娃娃都有自己的「身份证」，「买娃」叫「接娃」。这个小圈子究竟是如何运转的？

外界对「娃圈」有好奇，也有质疑，但多数人其实并不了解这个圈子。
