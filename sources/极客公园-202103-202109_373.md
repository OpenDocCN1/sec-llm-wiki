# 全球「缺芯」，背后的真相到底是什么？

从汽车、手机蔓延至家电：揭秘全球「缺芯」行业真相。

如果说，2019 年以来的全球商业大变局，给大众科普了一次，芯片设计与芯片代工的差异。今年年初，全球汽车行业、手机行业，乃至近期家电行业的缺芯潮，既让大众、福特、本田、戴姆勒等全球知名车企部分车型生产线已经或面临停产，也让想购买汽车、手机、家电的消费者第一次近距离感受到，芯片对我们日常生活的影响如此之大。  

芯片行业涉及的链条太多，产业上下游不同环节过于复杂，各种专业术语让人一头雾水，结合历史、地理等因素，全球芯片行业分布又有一些鲜明的特色。如果不是在芯片行业浸淫已久的专业人士，很难用一两句话把全球芯片产业这个话题讲清楚、讲明白，也难以对整个芯片行业的现在和未来有一个客观的趋势判断。

关于芯片行业，我们的疑问很多，比如，汽车、手机等芯片为什么突然之间就成了全球「紧缺货」？芯片设计与芯片代工之间到底是什么关系？芯片行业的发展的核心究竟是什么？一家芯片企业怎么从小成长到行业巨擘，大鱼吃小鱼，各种并购是后来者居上的唯一路径吗？
