国际空间站 SpaceX 龙飞船成功换位停靠 为第二艘升空做准备

根据 NASA 消息，今日国际空间站的 SpaceX 龙飞船（Crew Dragon）成功完成位移操作，从原有停泊位分离，并转移至另一个对接位置停靠。本次任务持续时间为 38 分钟，此前俄罗斯的「联盟 MS-17」飞船也进行了相同操作。
官方表示，这次位移的目的是为即将发射的 SpaceX CRS-22 货运飞船，以及第二艘载人飞船提供空间，便于将用于替换的新太阳能电池板转移出来。在进行对接时，宇航员需要手动对齐接口内的指示图形，使得网格与图形的中心点重合，然后可以将接口靠近并对接成功。
据悉，SpaceX Crew-2 第二次载人航天任务将于本月进行发射，四名宇航员将搭载型号相同的龙飞船前往国际空间站。本次任务定于北京时间 4 月 22 日下午 6:11 分，于美国佛罗里达州肯尼迪中心发射。在这之后，目前停留在国际空间站的 4 名宇航员将返回地球，完成交接任务。（来源：NASA）

苹果 CEO 蒂姆·库克「可能在未来十年内离开苹果公司」

苹果 CEO 蒂姆·库克在接受《纽约时报》作者 Kara Swisher 的播客采访时谈到了他的接班人问题。

谷歌在美国最高法院赢得了价值 90 亿美元的甲骨文 Android API 版权案

甲骨文在要求谷歌承担侵权责任的挑战中败诉，最高法院结束了十多年来关于 Android 一些关键组件的法律缠斗。此案可以追溯到 2010 年，甲骨文认为，谷歌在开发 Android 系统时抄袭了属于 Sun Microsystems的 Java API，因此应承担 88 亿美元的赔偿责任。
谷歌并没有否认它在最初开发 Android 时使用了这些 API。不过，它认为，它们的实现算作合理使用，因此并没有理由让公司面临侵权处罚。此后，安卓系统发生了转变，现在已经不再依赖这些有争议的组件。尽管如此，谷歌诉甲骨文一案还是受到了整个科技行业的密切关注，因为它围绕着如何控制 API 以及如何开发软件和硬件互操作性的潜在影响。
据悉，此次判决很可能会在科技界受到欢迎，行业内曾有人表示担心，围绕 API 授予开发者的不当控制可能会给软件开发带来新的重大障碍。（来源：cnBeta）

美国工程师打造世界上最大的 Switch 长 1.77 米

一名美国工程师成功打造了「世界上最大的」任天堂 Switch，并把它捐给了当地一家儿童医院。这个超大尺寸 Switch 长 1.77 米，宽 0.76 米，重量接近 60 斤，由「休闲工程师」Michael Pick 打造。
这个巨型 Switch 木质 Joy-Con 手柄的每个按键都正常工作，包括摇杆在内，但玩家也可以使用外部手柄游玩。
这个巨型 Switch 设计原理是将一个插入底座的 Switch 和电视内置其中，正常尺寸的 Joy-Con 手柄被安置在 3D 打印底座内部，当与巨型 Switch 互动时，底座使用物理杠杆按下按键。同时，大的摇杆安装在真实 Joy-Con 摇杆上面，通过移动实际输入来工作。Pick 指出，他在 Joy-Con 底座中加入了充电器，这样它们就不会在巨型外壳内耗尽电池电量。（来源：3DMGame）
