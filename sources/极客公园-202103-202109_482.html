100 亿美元，微软收购了一个有 3 亿人口的「互联网社会」

对微软来说，收购 Discord，一方面意味着能接触到 1 亿多粘性用户，另一方面也意味着，它能从一个新的角度，尝试构建未来的「互联网社会」。

又一家「中型创业公司」顶不住了。

据彭博社报道，微软正考虑收购 Discord，价格超百亿美元。后者去年夏天刚获得 1 亿美元投资，估值 35 亿美元。如果收购最终成立，意味着 Discord 的价值在一年内翻了三倍。

Discord 最初只是一个单纯的「语音聊天软件」，以游戏连麦作为切入点，逐渐汇聚成一个玩家社区。之后，越来越多「非玩家」来到这里，建立起「学习小组」、「球鞋讨论群」等频道，让 Discord 变成了一个基于兴趣的综合性互联网社区。

过去一年，受疫情影响，Discord 增长强劲，目前已经有 3 亿注册用户，1.4 亿月活。但它并没有良好的变现模式。视频通话、直播等功能，带来了巨大的运营成本。这可能是创始团队考虑委身巨头的主要原因。

微软并购过不少近百亿美元规模的公司。从 Github 到游戏工作室贝塞斯达，更早的例子还有 Skype 和 LinkedIn。在投资风格上，微软倾向于选择那些业务成熟，产品逻辑已经被验证有效的公司。被收购后，这些公司也大多保持着独立运营，目指更长远的未来。

2015 年，微软曾考虑斥资 80 亿美元收购办公协作软件 Slack，但双方没有谈拢。之后微软自主开发了定位类似的产品 Teams，成功对 Slack「降维打击」。

Discord 的产品功能和逻辑与 Slack 十分相似，只不过一个基于「兴趣爱好」，一个聚焦「办公场景」。Discord 在 to C 的语音通话赛道「战胜」了微软的自家的 Skype。这可能是微软想要收购它的原因之一。


需求的延伸与裂变

Discord 已经火了很久了。

早在 2018 年，它就已经席卷游戏圈，成了最受游戏玩家亲睐的「语音聊天工具」。在《英雄联盟》美服，几乎每局游戏开始前，都会有人发送 Discord 频道链接，邀请队友通过 Discord 沟通。

它的联合创始人、CEO Jason Citron 是一个狂热的游戏玩家。大学期间，他因为沉迷网游《魔兽世界》，差点没能毕业。但也正是出于对游戏的热爱，Citron 学习了编程，并在大学毕业之后投身游戏开发行业。

2012 年，尝试开发了多款游戏缺屡屡受挫的 Citron，意识到自己开发的游戏都不怎么样，反而是一款游戏中的聊天系统，相对最有价值。他将聊天系统从游戏中剥离出来，决定全身心投入开发这款聊天软件。就这样，Discord 诞生了。

Discord 花了很多力气优化通话质量和网络延迟。在 reddit 上，很多玩家表示，他们之所以愿意用 Discord，主要是因为 Discord 的通话质量、体验更好，功能更完善。

Discord 从「游戏连麦」这个强需求场景切入，完成了冷启动｜Unsplash

优秀、稳定的通话质量，只是语音软件的入门基础课。在此之上，Discord 取胜的关键在于：它让一个简单的「游戏连麦」需求，延伸裂变为了更复杂的网络社交关系。

当时市面上最主流的语音聊天软件是 Skype。Skype 的核心逻辑是将「打电话」的体验搬到线上，产品设计是围绕着「拨打」这个行为展开的。这种逻辑并不适合游戏玩家，因为游戏玩家的核心需求是「临时、多人语音」，最好能快速加入，不需要先「互加好友」或「创建群组」。

所以 Discord 很早就确立了「以频道为中心」的逻辑。这和国内的 YY 语音很像，一切的交流围绕「频道」展开，每个频道都像一个房间。你只需要发出邀请链接，其他人就可以一键进入房间，开始语音聊天。

基于通话逻辑的语音软件，如果一方挂断通话，这个「连接」就断了。Discord 不一样，它创造了一个「空间」，无论谁加入，谁退出，这个空间一直都在这里。

这样的机制留住了用户，鼓励他们进行更多后续交流。你加入其他玩家的频道，如果聊得来，你可以永久加入这个频道，用手机和大家文字聊天，下次一起玩。你可以看到频道里其他人正在玩什么游戏，观看其他玩家分享的游戏实况直播。

很多 Discord 用户，都会在无聊的时候，跳到一个没人的语音频道，相当于告诉其他人「我在这里，想聊聊吗？」。其他人如果有兴趣，就可以加入进来。对那些想要聊天，却又「羞于」主动打给朋友的人来说，Discord 提供了一种更简单的发起交流的方式，用户不会有太多社交压力。

包括 Facebook、Snapchat 在内，大部分社交媒体都设计了一套游戏化系统，试图驱动，甚至控制用户行为。点赞、关注，和好友连续聊天超过一周就能「点亮一搜友谊的小船」，这些东西促使用户不断使用社交媒体分享内容，评论互动，但它们给用户带来的压力也越来越大。

Discord 则完全不一样，它几乎没有任何游戏化的设计。在这里，没有「粉丝」的概念，也没有算法推荐的消息流。它就像一栋房子，你打开 Discord，就好像是「放学之后躺在家里的懒人沙发上，等朋友来一起玩点什么」。

有玩家将他和朋友共同创建的频道称作「基地」。


给用户更多「可能性」

因为骨子里带着游戏的基因，Discord 给了用户最大的自由。

就像很多游戏允许玩家通过 mod 修改游戏内容，Discord 在保证核心体验和安全的基础上，开放了大量接口，让开发者能轻松将各种服务接入到 Discord 的平台上。同时，Discord 还做了很多相对「复杂」的功能，为了满足用户多样化的需求。

Discord 绝不是最「简单易用」的语音软件。它的产品形态更接近 Slack，有着更高的学习门槛、更复杂的功能。Discord 认为游戏玩家大多有「钻研」精神，你给到更多的功能、更大的自由，他们会自己探索出合适的使用方式。

事实的确如此。在 Discord 里，有些人数众多的大频道，设计非常复杂。

这些频道有各自的「迎新流程」，能将新用户引导至不同的子频道。不同的频道有不同的发言规则、权限，能在人数众多的情况下维持发言秩序，展示恰当的信息。一些频道的管理者还设计开发了聊天机器人和一些自动化工具，能对用户的问题进行自动回复，实现一些聊天应用，比如身份验证、投票、小游戏……

疫情期间，同类软件比如 Zoom、微软 Teams 大多在用「从需求出发」的思路做产品，专注于提供一些很具体的功能。Zoom 针对网课场景的小测验功能、针对居家办公场景开发的「自定义视频通话背景」功能。

但 Discord 却在思考如何从最底层优化产品，给到用户更多「可能性」。

联合创始人 Vishnevskiy 表示，他们最近主要在钻研技术，尝试让 1000 个人同时进行语音通话，提供给用户更强大的工具。

尽管同属一个平台，但每一个 Discord 频道都有自己独特的组织结构｜Discord

Discord 是那种典型的「非产品经理主导」的产品，它不会主动去设计用户的行为路径，而是尽可能让用户自己做决定。它会提供一个「空间」让用户交流，至于用户具体是在里面聊天还是「挂机」，是大家一起七嘴八舌，还是一群人听一个人讲话，这都不重要。

如果说 Discord 频道是一栋房子，它的诸多延伸功能，相当于给了用户按自己想法「装修」房子的可能。一栋栋形态各异的房子，逐渐连成一片社区。

从 2017 年开始，越来越多基于兴趣标签的频道开始涌现。包括 F1 赛车、机械键盘、球鞋装备、折纸、同人动画、虚拟偶像……

也有很多人开始通过 Discrod 来运营粉丝社群，包括一些 YouTuber 视频博主和消费品牌。数码视频博主 Linus Tech Tips 的频道就拥有接近 90000 个成员，它们每晚的平均在线率可以达到 40%。英伟达也运营着一个接近 40000 人规模的频道。


「社区自治」文化

随着社区规模不断扩大，Discord 在内容管理上压力也与日俱增。

传统通讯软件大多是私密的，用户在通讯过程中的言论属于隐私，不具有传播性，也不需要管理。但 Discord 不一样，频道在创建的时候是默认公开，任何人都可以通过链接加入，具有自然的裂变传播属性。至于那些聚集了数万人的大频道，则更像是一种「公共场所」，用户之间的交流，极易产生分歧甚至争论。

当你把一定规模的用户放到一个空间里，交流就会变成争论，最终演变为混乱，滋生仇恨。Discord 的用户群中有大量低龄的游戏玩家，更是让相关风险成倍增长。

2017 年前后，有不少来自匿名论坛 4chan 的种族主义者，在 Discord 上建立了一系列推崇极端种族主义的频道。他们会用「Kool Kids Klub」这样的名字来伪装自己。这个名字字面上读作「酷小孩俱乐部」，但实际上是在暗示美国 60 年代推崇种族隔离、白人至上的 3K 党。

早期，Discord 不愿意对用户言论进行过多管理。毕竟这是一个带有半私密属性的通讯工具，只要你不主动加入那些服务器，就不会看到那些言论。但从 2017 年起，Discord 开始将自己更多视为一个公共平台。它组建了一个专门的「信任和安全团队」，划定了一系列更明确的发言规则，也加大了在内容安全管理上的投入力度。

该团队负责人 Sean Li 表示，「Discord 就像一个有一亿居民的国家，下面会有不同的州和城镇。我们所做的事主要是在大的规模上制定规则，管理这个社会。同时也要给频道的管理员提供更多工具，帮助他们建立更具体的规则，并且保证能够执行。」

对大部分创业团队来说，这类问题都不太好解决。他们往往没有专业的法务团队，也负担不起大规模的人工审核。反应速度太慢，甚至会被合规问题拖垮，典型例子如 Tumblr。

很多频道都建立起了自己的频道发言规则｜Discord

但 Discord 反应很快，管理制度被迅速建立起来。今天，大部分 Discord 频道都会在显著位置展示详细的发言规则，其中一般包括「不能发布引战、仇恨言论」、「不能发垃圾广告」。有些频道甚至会声明这里主要使用什么语言，防止大量异国语言用户涌入，破坏原有的正常讨论。

Discord 也给频道管理者提供了很多反制负面信息的工具。比如 Discord 允许匿名注册，但频道管理者可以设置，验证手机后才能发言。Discord 还开发了一些自动化的管理工具，可以自动筛选带有可疑关键词的发言，接受用户举报，然后将这些信息汇集在一起供管理员审核，处理违规用户。管理员可以禁言他们一段时间，或彻底从频道中踢出去。

Discord 给了用户很多自由，频道的创建、管理者也往往投入了大量精力去把社区构建成理想中的样子。他们与 Discord 之间的关系不止是「发布、消费内容」这么简单，而是形成了一种更特殊的纽带，产生了「社区自治」的文化。


变现难题和更大的理想

Discord 解决了一个创业项目会面临的大部分问题：底层技术、用户增长、社区治理……最后一个问题是，如何变现？

这是 Discord 目前最大的压力，也是它考虑卖身微软的核心因素。为 3 亿用户提供高质量的语音、视频通话，游戏直播，并不便宜。

此前，两名联合创始人都表示，他们不会出售用户数据和广告牟利。Discord 目前的主要收入来源是会员增值服务 Nitro。用户支付 10 美元月费，就可以获得一系列「特权」：包括支持动图头像、使用更多 emoji 表情包、1080P 直播、上传更大尺寸的文件。但这些功能对大部分普通用户的吸引力相对有限。

之前，Discord 还尝试过游戏发行。2018 年，它推出了一个游戏商店 Discord Store，销售 PC 游戏，但反响平平，几个月后就关闭了。之后 Discord 也尝试过采用订阅制的 Nitro Games，像 Netflix 一样，用户付一笔固定月费就可以玩整个游戏库里的游戏，也没有持续多久。

Discord 的付费增值服务，对大部分普通用户没有太多吸引力。｜Discord

尽管 Discord 自身的变现之路充满艰辛，一部分用户却已经在 Discord 上赚到了一桶金。

Discord 上出现了一些付费内容社群，涵盖的领域非常广泛，包括游戏攻略、投资理财策略、学校课程，也有社交媒体衍生的付费粉丝群。

很多内容创作者选择在 YouTube、Twitch 上发展观众，扩大影响力，然后在 Discord 进行变现。Discord 具备一切他们需要的产品特性：这是一个半私密的社区，可以很方便地管理付费用户的会籍；可以针对不同会员设置不同的自频道；支持几乎一切媒体形式：文字、语音、共享文件、直播……

因为 Discord 功能足够全面、开放，很多人选择利用它建立粉丝社群、俱乐部。但也正因为这种开放性，Discord 很难介入这些生意，大部分人都是通过 Paypal 收款。Discord 和付费内容平台 Patreon 有功能整合，创作者可以将自己在 Patreon 上的会员接入到 Discord，但这并不能给 Discord 带来任何收入。

去年，Discord 进行了一次品牌转型，不再将自己的定位局限在游戏这一领域，而是希望创造一种新的「互联网社会形态」，它现在的口号是「你聊天的地方，玩的地方。」（Your place to talk and hang out.）

两名创始人在一篇对外的公开文章中表示，「显然，人们花费在网上的时间越来越多，他们希望在网络空间里找到归属感，和真正的人性。」

这是一个更大的理想。从 Facebook 创立早期开始，社交媒体创业者们就在想象一种「人们完全生活在线上」的未来。但随着社交媒体的流行，副作用也开始显现，大家越是沉迷手机社交，就愈发感到焦虑、失落，各种批评声也越来越多。

Discord 构筑了一种新的互联网社区形态。这个社区已经有了超过 3 亿居民，如果按人口算，它已经是世界第四大国家，完全算得上是一个「互联网社会」。理想正在孕育，但 Discord 难以驾驭变现的难题，毕竟这是一个创业不到十年的年轻团队。

对微软来说，收购 Discord，一方面意味着能接触到 1 亿多粘性用户，另一方面也意味着，它能从一个新的角度，尝试构建未来的「互联网社会」。

这是一个比百亿估值还要长远得多的未来。
