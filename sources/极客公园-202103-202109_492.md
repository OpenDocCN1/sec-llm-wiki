# 谁「偷」走了你的脸？

深扒人脸识别技术。

今年央视 315 晚会的第一枪，对准了人脸识别技术滥用问题。

央视记者调查发现，全国多家知名品牌门店都安装了人脸识别摄像头，这些摄像头在顾客毫不知情的情况下偷偷抓取人脸数据。

摄像头可以识别消费者的性别、年龄、步态，甚至是心情，这些数据会在系统里形成一个个人脸 ID，顾客去了哪家门店，去过几次，商家们都能一清二楚。

人脸识别技术被滥用已经不算新闻，但每次被曝光后都会引发一阵对技术的恐慌。

此前，全国多家售楼处被曝安装有人脸识别摄像头，于是有人看房担心被抓取人脸数据，带上了墨镜、口罩、甚至是头盔。

刷脸，已经成为你我日常生活中习以为常的动作，从刷脸支付、门禁考勤，到智慧社区，人脸识别技术正在密集且迅速地渗透到我们的生活场景中。

刷脸，一方面带来便利，一方面又带来了隐忧。你了解了我那么多信息，要用来做什么？会被滥用吗？这些信息存储是安全的？如果被人盗取了该怎么办？

**人们对这项技术的焦虑实际源于信息的不对称。**

因此，了解这项技术的原理、技术发展的阶段、应用场景，以及在刷脸时代该如何正确护脸，非常必要。
