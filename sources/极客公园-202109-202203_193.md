# 关于下一个十年，我们在深圳发现了些答案

Stay Calm and Keep Innovating.

  

  

**出品 | 极客公园  
**

  

  

12 年来 ，极客公园创新大会（GeekPark IF）第一次离开北京，在 OPPO（IF 2022 独家冠名赞助合作伙伴）与深圳福田区的协力支持下，南下深圳。

这一年，**中国的互联网行业经历了增长放缓、监管、裁员，国际关系进入新阶段，科技发展也开始不可避免地受到地缘政治的影响**，人们焦虑、疑惑，需要思考科技会不会停下来？科技创业又将往哪里去？带着这些问题，极客公园创新大会 2022 邀约了传奇极客、科学家、用户领袖，以及众多或资深或新锐的创业者，尝试一起探讨答案。

  

**01**

**从工程师精神出发，**

**向创业者能力迈进**

  

  

深圳孕育着超 200 万家的中小企业，在这里有许多「科技个体户」，他们沉迷于创造，对新技术充满好奇心，他们构成了科技创新的最小单元。这个群体的丰富，就意味着通向未来的活力。  

潘昊（柴火创客空间创始人）久居深圳，对中国科技的未来充满乐观。2012 年，潘昊成立柴火创客空间，汇集起一批希望在微小领域应用技术解决实际问题的人。在疫情期间，创客们曾发起一场集体自救：有人利用 3D 打印机，加上一个塑料薄膜，自制防护面罩。有人从身边的机器设备入手，自制呼吸机。有人用自制的简易设备给新冠患者供氧……

  

![](../Images/7955a9fc592c74a936fdf6759f0990e2.png)

柴火创客空间创始人潘昊在 IF 大会演讲。

  

从纯粹的工程师精神出发，致力于打造有用、或者仅仅是有趣的东西，似乎是一切伟大产品创新的起点。三十多年前，苹果联合创始人沃兹尼亚克在家中制造出了属于自己的第一台计算机，也开启了个人计算机的革命。后来，他「勉为其难」地与乔布斯一同创立苹果，「直到我确定自己能继续当个单纯的工程师，我才答应他。」作为一个典型的极客，沃兹在极客公园创新大会上与我们进行了隔空长谈，最让人印象深刻的，是他一生践行了纯粹的工程师精神——他不在意金钱，只会、也只想做产品。如今已经 71 岁的他，觉得这一生无比充实。

![](../Images/196bb8598133aa100dd5e634fce04586.png)

苹果联创沃兹尼亚克在 IF 大会对谈极客公园创始人张鹏，他表示十分看好中国深圳，这里孕育着新一代创新的希望。

  

或许，当下就是一个更加需要致敬工程师精神，回归工程师之伟大使命的时代：**Keep building. Keep inventing**。而沃兹也说，他看好和期待中国和深圳的工程师们，接过当年硅谷创新的火炬，去创造更多影响世界的伟大产品。

的确，中国工业制造在经历了代工时代、山寨时代和转型时代，开始迈入了真正的创新时代。这一代创业者们第一次能够平视西方，而当下的中国产品不止追求性价比，更需要对世界有影响力的产品，这需要真正的创新。

推动了大疆、云鲸等优秀创业公司的李泽湘教授十分赞同沃兹看好深圳和中国的观点。但他觉得，**创新不仅需要从工程师精神出发，更要坚定地向创业者的能力迈进。**

  

![](../Images/54c22de37636d824571ca2c49ef0c78e.png)

极客公园创始人张鹏对谈 XbotPark 创始人李泽湘，中国要面向未来打造工程师红利。

  

2014 年，李泽湘创办了松山湖国际机器人产业基地（XbotPark 机器人部落），面向高校招募年轻创业人才，推动着一波「学院派创业」的新范式。

在人口红利将尽的今天，李泽湘提出，要面向未来打造中国的工程师红利——还是要相信年轻人，新一代的科技创业者将从大学毕业生中诞生，他们没有历史思维惯性的束缚，而「创业的能力，是可以被激发的。」

看重年轻人创业，这听起来很「非共识」。但在过去 12 年，极客公园确实目睹了生生不息的一代代创新者「把非共识变成了共识」，把很多的「经验」变成了「历史」。作为中国科技创新者的社区，从移动互联网、智能硬件、到AI、新造车，每一波新的技术趋势里，我们都很荣幸成为了那些优秀创业者的伙伴。

帮助他们与世界更好地沟通和对话，就是在帮助他们集结更好的人才，赢得更多资本的支持，以及创造更大的市场与价值。

这让人兴奋，也令人焦虑。因为科技创新的更迭、世界变革的速度如此之快，似乎没有人能永立潮头。

但人们总能找到对抗焦虑的方法。比如面对手机市场必然的萎缩，「你焦虑不焦虑？」当这个问题被抛给 OPPO 的 CPO 刘作虎时，他的回答带来了另一个思考角度：「危机感和焦虑是两回事，把做好每一个产品作为关注的核心，这是应该有的危机感，但焦虑是种不解决问题的负面情绪——真正把产品做好，你自然就没有焦虑了。」

  

![](../Images/8c1f05bb5a676d3f71f5da567511d814.png)

OPPO CPO 刘作虎携新款折叠屏手机 FindN 来到 IF 大会。

  

从一加回归 OPPO 后，刘作虎带领团队打造的 Find N 折叠手机在大会前刚刚发布，第一批预售就被抢购一空。在极客公园创新大会的访谈中，他在谈论产品时的兴奋与投入，思考未来时逻辑的「简单平和」，都传递着一种乐观情绪——**科技可以不那么「卷」，向上探索和创新就好；心情可以不那么焦虑，把产品做好就没有「危机」，更能享受快乐。

**02**

**「更深」、「更广」、「更耐心」**

  

在深圳福田，以沈向洋为代表的一群科学家创业者正形成另一股重要力量。  

由沈向洋创院的  IDEA（粤港澳大湾区数字经济研究院）坐标深圳市福田区，定位为面向人工智能、数字经济产业和前沿科技的国际化创新型研究机构，一批科学家致力于推动从学术研究向商业落地的转变。在极客公园创新大会的「前沿社冬季会晤」中，沈向洋说：「把科研的氛围和社会商业应用场景更紧密地连接起来，把价值流动起来，是科技创新生态里值得探索的。」

  

![](../Images/e2fbfd82246d573599b0c5b0aa412ac0.png)

极客公园创始人张鹏与 IDEA 讲席科学家王嘉平跨洋对谈。

  

IDEA 讲席科学家王嘉平在极客公园创新大会上说：「做研究会塑造一个人的价值观。」他认为，**卓越的研究不跟风，而是提出新的问题，从而引发更多人的研究。这种思路迁移到创业中来，就是「不想内卷」，与其衡量商业模式，不如从技术上寻找解决问题的独特路径。**

在微软做过分布式计算研究的他，从技术角度思考：作为一种全新的计算架构，「区块链」从「共识」出发，能够让计算过程真实可信，从而在链上运行的应用就能自证业务逻辑清白——这和之前的计算架构目标不同，但符合数字化社会进一步的需求。由他创立的「墨群区块链」便致力于解决区块链的性能问题，并为之寻找有意义的应用场景。

另一位科学家创业者——三迭纪的创始人成森平博士，在医药领域也在推动技术的升维。中国制药走过了漫长的仿制药时代，始终少有自己的专利，在未来，这个历史终将改变。她与合伙人正致力于原创性底层制药技术的开发，运用 3D 打印技术生产药剂，通过创造一种可以数字化精准设计的药物释放方式，让药物更加精准地发挥作用——这项技术的创新目前只有中美两家公司在推动。

  

![](../Images/240c5f9a8749a72ebd7410855dc40d73.png)

三迭纪创始人成森平博士在极客公园 IF2022，她说，3D 打印制药正在建造一条现代化的制药高速公路。

  

极客公园不仅关注科技本身的升维，在很多领域看起来也许不那么炫酷的科技，其实也有机会释放巨大的商业和社会意义。

农业科技在上一个十年似乎是个并不存在的概念。但从事农业植保无人机的极飞、做智能温室大棚的小雨农智，在这次大会上都谈到了一个观点：「科技并不只在星辰大海，也在田间地头」，回归到第一产业亟待解决和优化的产业问题，去推动「粮食自由」，用技术去提升农民的效率和收益，是对世界意义重大的创新方向，也值得创业者们投身其中。

  

![](../Images/418b7d98c290772fce14601044eb5825.png)

极客公园执行总编卫诗婕对谈谷歌安卓无障碍设计主管夏冰莹：《关于无障碍设计，我们想错了什么》。

  

谷歌安卓无障碍设计主管夏冰莹，则提出了另一个科技盲区的问题：我们应该更加深入地关注和探讨无障碍设计对于每个人的意义——为障碍人士做出的无障碍设计，终将惠及所有人。**这不应该只是一项政治任务，要像做产品一样去定义真正的问题，给出更认真的答案。**

![](../Images/416add68baa111dc980d7d958c7130ee.png)

一同科技 CEO、盲人工程师蔡勇斌在极客公园 IF 2022 分享他的程序员之路。

  

而视障程序员蔡勇斌和他的视障程序员创业团队，也用平和自信的演讲，展示了在科技创造的条件下，「身体障碍」并不意味着「无能」，我们需要让社会意识到这个问题，降低乃至消除健全人社会所强行赋予残障人群的「社会性残疾」，让每个人享受科技带来的进步，并让每个人都能更好地创造价值。

![](../Images/c59e3177bb87183c5d694e816291da3e.png)

极客公园创始人张鹏发表开场致辞。

  

在极客公园看来，或许上一个时代的科技创新，就像荷马史诗里描述征服和英雄主义的《伊利亚特》，但下一个十年，也终将有探讨回归和人性光辉的《奥德赛》。一位大会观众参会后在自己撰写的文章里写道：能够感受到「社会责任」是今年的大主题。是的，科技需要「等一下」，伴随着其能量越大，对于社会和大众的责任也越大，我们需要思考，科技将去往何处。

越来越多与上一个时代不同的思考正在出现。比如今天，**在中国双循环的大背景下，创业者也有了更多的选择。**中国有快速崛起的高端消费群体，他们拥有独立、自信的判断能力。不少与会的创业者提出，要敢于在垂直领域做极致产品，立足中国，放眼世界。

前魅蓝总裁李楠创立了 AngryMiao（怒喵），推出了一款售价 1600 美金的键盘曾经引发巨大争议。面对许多人质疑其「收智商税」，他表现得毫不在乎。

  

![](../Images/8ab4810250b061288f7b37d145ffa4b8.png)

前魅蓝总裁、AngryMiao 创始人李楠在极客公园 IF 2022。

  

他说，**在高端市场，中国品牌从未发生过严肃的战斗**，99% 的中国企业家低估了中国品牌的价格上限。「资本是份额的朋友，但时间是品牌的朋友」，在细分的高端市场做最好的产品，用最大的耐心，一样可以创造很大的价值。中国创业者抛弃性价比、挑战品牌力和产品力的时刻到了。

如果说李楠在商业的本质上提出了关于「决心」的思考，那么从互联网时代转战机器人领域的傅盛则在科技创新的层面提出了「耐心」的价值。

创业本身就是一种态度——坦诚地面对现实，科学地思考世界。转战机器人赛道后，傅盛再也感受不到互联网创业时那种「坐火箭一样」的成功速度。在今年的大会上，他回顾了给猎豹「换引擎」的历程，形容是「满纸血泪」。「我们讲创新时，太容易忽略试错、小步快跑这些过程了。」新领域创业的「水土不服」让他认识到，**科技大爆炸不是常态，日拱一卒才是。**

  

![](../Images/e201a0603e9c707f21aa206d38c5b18a.png)

傅盛在极客公园 IF 2022 发表演讲《小步试错，才是科技发展的硬道理》。

  

人们总是容易忽略一个伟大产品的背后，漫长的试错与迭代过程。确实，面对下一个时代，在鼓励创新的同时，更需要建设一个包容创新的社会氛围——科技不能只看商业的辉煌。像李泽湘在大会说的，我们应当更少关注市值（估值），更多关注创新——**「你不能等到 Tesla 一万亿市值的时候才去欢呼，你要在他入不敷出、九死一生时为他欢呼。」**

如果创新需要耐心，需要试错，需要迭代。那考验的就不只是创业者本身，也是他创造的组织。

  

![](../Images/3a9e346b191c6ba26873f27e3fe146e3.png)

前奈飞首席人才官 Patty Mccord 在极客公园 IF 2022 与张鹏探讨当今时代，企业需要怎样的人才与组织。

  

缔造过顶尖组织文化的奈飞前首席人才官 Patty McCord 告诉我们，**什么是好的组织和文化，这没有标准答案。**要向前看，建设奈飞文化花费了 10 年，这并非一蹴而就的灵感，而是不断持续的过程。伴随着公司从初创走向大公司，从信息分发公司到技术公司再到原创公司，奈飞文化重写了六次。只有不断拥抱变化，才可能做出正确的决策。

但有一点，她觉得创新者们应该记住，对于组织和文化，唯一可以拷贝和搬运的，是一种思想——**未必在于你创造了多少新的方法，而在于你停止了多少组织内无意义的事。**

极客公园从 2010 年开始筹办 IF 大会，它在诞生之初就吸引着一批科技主义者，12 年来，一代一代创新者在这里谈论创新，对技术的认知与理解，反思科技可能引发的问题。在每一次「非共识」的提出，和每一次共识的建立之中，都让我们看到新的希望，和通向未来的「导航点」。

感谢数百万线上的观众，数千名到深圳现场一起探讨的朋友，感谢每一位莅临现场的创新者，感谢每一个勇敢的非共识。

这最终让我们大会的主题——**「科技，不要停下来！」**变成了一个有意义的呼唤，也最终找到了值得践行的答案。
