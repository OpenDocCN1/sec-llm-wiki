PLG 不是一种条件，而是一种哲学


来源：极客公园前沿社（ID：GeekParkFrontier）
作者：余不昧 & flaash
原标题：PLG风靡，我们该怎么去定义这种SaaS的新模式？丨HyperTech



如今，一家公司采用某个软件，情形已经和以前大不一样，故事通常是：J 从朋友那里听说了某软件，所以她注册并开始与她的团队一起使用它，很快整个公司都在使用它。



而以前公司采用一款新软件比现在麻烦很多：漫长的销售流程、复杂的实施、正式的培训和认证，不胜枚举，而这一切都花费了大量时间。

很多 SaaS 企业已经认识到这一市场变化，并已经把增长终端用户作为自己的核心业务：

Slack 在招股书中表示，「最初许多组织采用 Slack 是我们自助服务 GTM（go-to-market）方法的一部分。当用户意识到 Slack 的好处时，自然增长就会产生。」

不仅仅是 Slack。Atlassian 也在招股书中表示：「我们认识到用户推动了我们产品的采用和扩散。」你会在 Zoom、Shopify、Twilio、Dropbox 和其他最近的招股书中找到类似的说法。

以上这些产品都可以被当下很火的一个概念 PLG（Product-led Growth）囊括进来，这些产品都依赖于产品本身作为用户获取、转换和扩展的主要驱动力，而这种以产品为导向的增长是一种以终端用户为中心的增长模式。



在今年福布斯 Cloud 100 的名单中，超过 65-70% 的公司都是 PLG 公司，2016 年这个数据是 30%-35%。而 PLG 公司创造的上市市值也在短短 5 年时间里从 210 亿美元增长到 6870 亿美元。


01

终端用户时代来临



PLG 这个概念是由美国风投公司 OpenView 首次提出的，他们认为：「软件市场在不断发展，我们正处于一个拐点，正在见证终端用户的崛起。」

他们认为，推动软件市场发展的四个基本要素有：

☁️ 基础设施：软件在哪里安装和使用？
💰 成本：构建和购买软件的成本是多少？
👩‍💻 买家：谁来评估和选择软件产品？
🛒 分销：软件产品如何走在买家面前？

这些因素都相互关联和促进：随着基础设施的发展，软件的开发和购买变得更加便宜。这些节省的成本会转嫁给用户，他们的购买价格也会变低。软件更容易买到且更实惠的特点导致了用户购买力的分散化，买方角色也因此在组织结构图中向下移动。分销方式也随之不断调整以适应新的的市场格局。

当考虑到这些驱动因素来审视软件行业的历史时，我们会看到软件的三个主要时代：CIO（首席信息官，Chief Information Officer）时代、Exec（操作系统）时代和终端用户时代。



CIO 时代：1980 年代 – 1990 年代

早在 80 年代和 90 年代，软件是用户从实际的「物理盒子」中安装的东西。构建和购买大规模、单一的内部部署软件程序的成本很高。

「以销售为导向的增长」是由现场销售代表推动的，这个时代的关键决策标准是简单的 IT 兼容性。

Exec 时代：2000 年代初

这时一些公司颠覆了旧的做事方式，将软件从数据中心转移到云中。

这为也用户带来了巨大的经济转变，用户只需支付一小部分费用即可租用它。这个时代为我们带来了作为分销模式的「营销主导增长」，很多上一代 SaaS 公司建立在搜索引擎营销（SEM） 之上。通过向平台方付费以向相关用户群展示广告来拉新。

终端用户时代：2010 年代及以后

这时，基础设施比以往任何时候都更具弹性和可扩展性。得益于 API 和模块化工具，开发人员不再需要从头开始对每个程序进行硬编码。

传递给用户的效率收益意味着试用新产品比以往任何时候都便宜（通常是免费的）。只需点击几下或轻点几下，即可获得数以千计的新产品。

软件的可负担性和可访问性使终端用户的购买完全民主化。吸引和转化大量个人终端用户需要一个可扩展的、自下而上的分销模式，一种利用用户体验使终端用户能够自行查找、评估和采用产品的模式。

这就是 OpenView 的 Blake Bartlett 在 2016 年首次所说的「以产品为主导的增长」——这也是诸如 Atlassian、LogMeIn、Wix、Zendesk 和 Slack 等终端用户时代公司成功背后的秘诀。



02

PLG 是一种哲学，

而不是一种条件



SaaS 公司大体上都在一个非常简单的 GTM 漏斗上运作。顶部是所有「用户」，底部是所有「付费用户」。

简单地说，PLG 就是在这个 GTM 漏斗的每一部分都把产品铸成主角的哲学。无论是通过病毒式传播创建漏斗顶部 (ToFu)，引导用户完成激活和参与，还是在辅助销售中迈出第一步，产品都是主角，而销售、营销和工程是支持。

但是 PLG 的典型构建方式存在两个问题。首先，人们引用这个概念的方式会让人觉得它是一种条件或状态，例如会说 Figma 和 Notion 是 PLG 公司，而其他公司不是。

其次，作为「PLG 公司」被广泛宣传的往往是极端成功的例子。这导致人们认为以产品为主导意味着必须像那些公司一样。

实际上，PLG 不应被视为一种条件，而应视为一种哲学。它不是一个固定的公式，而是一种方法，创始人可以通过这种方法查看 GTM 的每个组成部分，并找出如何最好地利用产品来更好地实现获取、发展和留住客户的目标。

要以产品为主导，问题不应该是「如何像 Slack 一样？」，而是「如何更好地进入市场和优化用户体验？」


03

PLG 框架



来自澳大利亚的风投公司 Blackbird 提出了一个「PLG 框架」，该框架确定了九个可以拉动的 GTM 产品杠杆，确定要拉动哪个杠杆以及力度最终取决于产品的市场和客户。



1. 主要目标：谁是你的目标关键人物？


非 PLG 将重点放在企业买家上，不完全的 PLG 放在团队或中小企业客户上，而 PLG 放在个人买家上。

以 Zoom 和 Cisco 的 Webex 为例。Webex 是企业视频会议市场的主导者。Zoom 有更好的产品，但意识到这是一个拥挤的市场，逐个账户说服他们改用 Zoom 将是一个缓慢的过程。

相反，他们推出了免费增值模式（任何人都可以免费使用 Zoom，会议时长为 40 分钟——区分个人和专业使用的逻辑门槛）和目标个人。赌注是，随着越来越多的用户尝试 Zoom，员工和企业会看到它的效果如何，并切换到付费版本。赌注得到了回报，Zoom 现在在美国拥有 59% 的市场份额和超过 3 亿的每日会议用户。

2. 获客方式：吸引和获取客户的主要渠道是什么？

非 PLG 侧重于付费营销渠道，不完全的 PLG 侧重于有机营销（word of mouth, PR, content, referrals, market places, etc），完全的 PLG 侧重于病毒式传播。

3. 漏斗顶部：转化外围用户的关键动作是什么？

非 PLG 将重点放在销售人员的传统客户演示上，不完全的 PLG 侧重于免费试用，完全的 PLG 侧重于免费增值产品体验。

关于免费增值的一项有趣的举措是「Canva for Education」计划，该计划于 2020 年初启动，向所有 K-12 学区免费提供 Canva。该计划是一项了不起的慷慨行为，也是建立大量超级用户的绝妙方式，这些超级用户将成长为未来的拥护者和付费用户。



4. 销售模式：主要销售模式是什么？

非 PLG 侧重于传统的企业销售，不完全的 PLG 侧重于内部销售，而完全的 PLG 则侧重于自助服务（产品引导买家完成整个购买过程）。5. 能见度：如何与客户沟通产品和定价？非 PLG 在网站上隐藏了有关产品和定价的大部分信息，并促使买家点击「联系我们」按钮，不完全的 PLG 开放了产品功能和细分，而完全的 PLG 则使产品功能和定价简单透明。



6. 定价模式：定价模型是什么？

非 PLG 定价是更传统的订阅许可模式，不完全的 PLG 是基于用户的定价（例如 25 元/用户/月），完全的 PLG 是基于使用的定价。

7. 价值实现时间：让用户到达「有价值」感受的速度是多少？

非 PLG 涉及更繁重的实施过程，需要时间，也可能需要客户、公司和潜在顾问的支持；不完全的 PLG 的设置过程更短、更轻松，通常只能由客户单独处理；而完整的 PLG 涉及产品的简单激活和客户体验「第 0 天价值」。

「第 0 天价值」基于这样一种理念，即越快、越容易让用户获得价值，效果就越好。这是通过拥有易于理解、评估、采用和集成到现有工作流程中的产品来实现的，理想情况下几乎不需要帮助。

8. 参与：与客户互动的核心驱动力是什么？

非 PLG 意味着您依靠销售接触客户并与他们进行追加销售和产品体验对话。半 PLG 依靠以产品为主导的方法来吸引客户，但个性化有限。

完全的 PLG 监控使用数据并提出高度定制化的建议，以适应用户行为并提供更多价值。这些通信是通过电子邮件、推送通知等自动和全渠道进行的，旨在将用户带回产品、增强他们的体验并推动更多购买。最终目标是「及时」提示用户在完美的时刻采取行动或追加销售到付费版本。


9. 连通性：客户通过产品的联系有多紧密？

非 PLG 为客户提供孤立的产品体验，不完全的 PLG 提供基于社区的体验，完全的 PLG 提供网络化体验。

对于大多数产品，客户都相当孤立，因为他们拥有自己的实例并且不与其他客户和外部用户交互。在过去几年中，围绕产品建立社区的想法大受欢迎。社区已从可有可无转变为关键的业务优先事项。

PLG 这种策略除了商业价值之外，在改善人们的工作生活方面也比传统软件企业做得更好。

Postman 首席执行官兼联合创始人 Abhinav 提过一个观点：「PLG 会从根本上带来更好的产品。它们是为最终用户设计的，而不是为买方设计的，所以创始团队真正关心的是谁在使用它，人们如何使用它，以及以及对人们帮助有多大。」

Doja Cat 推出首个「可编程」MV


Girls Who Code 是一个 2012 年成立的非营利组织，他们的核心宗旨是希望可以鼓励以及引起更多年轻女性对于编程的兴趣。最近他们与美国歌手 Doja Cat 合作，推出了第一个可以通过编程互动的 MV。



可以在 Dojacode.com 上体验这只 MV，按下开始后，会看到三颗不同颜色的星星，每颗星都代表一种不同的程式语言：黄色代表 CSS；蓝色是 Javascript；而粉红色则代表 Python。

单击音乐视频后，MV 就开始了。它的播放方式就像 Doja Cat 的原始音乐视频一样，用户可以在整个过程中用输入短语的方式完成代码进而作出剧情选择，有点像选择自己的冒险游戏。屏幕底部的时间线包含四颗颜色编码的星星，显示视频暂停的时间以及将展示的编程语言。



当视频停止时，除了代码行之外，您还可以填补空白。例如，第一次让您使用 CSS 更改 Doja Cat 指甲的颜色；您输入的颜色会实时改变 Doja Cat 指甲的颜色。在另一个场景中，输入城市名称会改变视频中的时间，它甚至会保持该位置的当前时间。

例如在北京上午 11:00 左右输入「北京」后，画面中就可以看到太阳正好在画面正中央。但若输入「纽约」，画面就会变暗，而且不只看的到满天星斗，甚至还可以看到一个象征女性的星座。
