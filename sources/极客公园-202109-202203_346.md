# 3D 视觉赛道如何破局？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MTMwNDMwODQ0MQ==&mid=2652933630&idx=2&sn=213d913ff846a186298e398c6869b17d&chksm=7e55f0484922795e2329ed01f088a89f2222d2de4dd4e06d15354f8f7234cf860679fb27b06b&scene=126&sessionid=1681309851#rd](http://mp.weixin.qq.com/s?__biz=MTMwNDMwODQ0MQ==&mid=2652933630&idx=2&sn=213d913ff846a186298e398c6869b17d&chksm=7e55f0484922795e2329ed01f088a89f2222d2de4dd4e06d15354f8f7234cf860679fb27b06b&scene=126&sessionid=1681309851#rd)

「我们是一家为客户提供 3D 视觉全栈式解决方案的创新公司。」光鉴科技创始人兼 CEO 朱力说道。  

2017 年苹果发布了 iPhoneX，让 Face ID 成为潮流，也让 3D 视觉技术备受业界关注。但由于苹果公司在技术专利和供应链上的双重壁垒，很多公司难以拓展市场。面对这种情况，光鉴科技给出了自己的破局之道。

基于自主研发的纳米光子芯片，光鉴科技提出了不同于苹果「VCSEL+DOE」的全新 3D 视觉感知方案。

朱力相信，能实现软件和硬件结合 的 3D 视觉感知方案将成为未来 3D 视觉市场中新一轮的博弈重点。在他看来，技术的迭代与创新，产品的成本与量产都将成为不可忽略的问题。

如今，光鉴科技已经走过了 多轮融资， 成为了国内 3D 视觉领域具有代表性的黑马创企之一。

成立仅三年，光鉴科技是如何绕过苹果的重重专利封锁，成长为 3D 视觉领域领先 的科技公司？
