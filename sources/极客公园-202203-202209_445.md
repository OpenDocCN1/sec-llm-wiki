# 折叠屏手机之局：要从更新，到更好

新技术吸引人，成熟的产品留住人。

  

**作者 | 豆腐店店长**

  

  

3 月 28 日，vivo 官方正式公布了旗下首款折叠屏手机 vivo X Fold 的发布日期，这也意味着，目前手机行业的几家头部厂商基本都加入到了折叠屏手机的生产行列。

不过在国产品牌 Top5 中，vivo 是入局最晚的一个。如果按照产品发布时间线来进行排序，比较早推出折叠屏手机的品牌是华为，接下来依次为小米、OPPO、荣耀以及 vivo。

事实上，vivo 跟进折叠屏手机的时间并不晚，早在 2018 年接受媒体采访时 vivo 执行副总裁胡柏山就曾表示，公司已经在着手折叠屏手机的相关研发工作。

这不禁令人心生疑问：既然做折叠屏手机这件事情并非仓促上马，那么为什么之前 vivo 没有推出量产机型而是一直等到现在，这背后又有着哪些不一样的思考？

  

**01**

**折叠屏手机，**

**由「动人」到「留人」**

  

  

2007 年，史蒂夫·乔布斯发表了他人生中极为重要的一次演讲，初代 iPhone 的到来，让人们意识到原来「黑莓们」所推崇的键盘和手写笔并不是手机的必须品，而苹果公司所倡导的触控交互方式，成为了行业迈入下一个时代的标志。  

  

![](../Images/24b3c0d021c6fd0f2de661cae665c0b1.png)

  

革命性的创新成果，为苹果公司赢得了长达数年的主动权。但最近几年创新的魔力正在日渐消退，即便是苹果，也没能再次打造出像初代 iPhone 那样，能够真正引领行业跨入新时代的产品，似乎刺激用户消费变成了某些创新出现更为重要的原因。

全面屏的演进，便是一个很好的例子。从刘海屏、水滴屏、弹出式摄像头、滑盖到现在安卓阵营主流的打孔屏，过去的几年里厂商们尝试了各种各样不同的方案。

伴随全面屏方案的不断优化，如今手机产品的观感的确更好，但却并没有让使用体验获得质的飞跃，正在使用挖孔屏手机的人很多，选择刘海屏 iPhone 的用户也未见因此减少。

  

![](../Images/7fab6188b6bf8a85da23a9053ed3b65f.png)

iPhone 13 Pro/图片来自官方

  

事实上，如今手机行业面临的难题并非个例，包括 PC 在内，几乎所有步入成熟期的行业，都存在类似的创新困局。当已知用户痛点被逐一解决之后，寻找未知用户痛点的创新之路愈发艰难。

在这样的大背景下，厂商们想要保持持续竞争力的路径其实有两条，一条是不断进行技术预演，尝试更有突破性的创新；另外一条便是打磨出综合体验更成熟的产品，以此来留下用户。

从 vivo X Fold 的发布时间来看，vivo 做折叠屏手机的态度其实和苹果不谋而合，两家都没有走追求更快、更新的产品路径，而是倾向于稳扎稳打，交付出一台更成熟的手机。

以进入量产阶段开始算起，到现在折叠屏手机已经走过了差不多三个年头，尽管这类产品的出货量曲线一直呈上扬趋势，但一个比较现实的情况，是它依旧没有成为大多数的选择。

折叠屏手机没能很快真正进入普及阶段，一方面是因为产品定价普遍高于常规手机，另外一方面，目前市面在售的很多折叠屏手机并不完美，导致感兴趣的那部分用户选择观望。

由于内屏具备可折叠特性，折叠屏手机能够突破物理限制，很好满足人们对于大屏体验的要求，结合外屏一起使用，相当于将手机的便捷性和平板电脑的大屏显示特性做到了一台设备上，是非常天才的一套产品思路。或许不一定会取代直板手机，却足以成为一条独立的细分产品线。

![](../Images/30095180168509ce6d683026e466b74e.png)

图片来自官方

  

不过折叠屏产品量产至今，有些问题一直伴随其左右。首先一点，便是反复开合手机所产生的内屏折痕，这会直接影响手机展开之后的整体观感，也是之前被大家吐槽比较多的地方。

另外，由于需要满足可多次折叠这一特性，折叠屏手机的内屏结构设计以及材料选择要经过特别处理，没办法直接套用成熟方案，屏幕显示效果相对顶级旗舰也有提升空间。

以上这两点之外，折叠屏手机还有很多地方处于追赶状态。比如生物识别方案，屏幕指纹基本已经成为常规直板旗舰标配，但目前为止，在售的折叠屏手机还并没有跟进。

所以先入局的厂商，在获得市场布局先机的同时，也需要承担起「探路者」的角色；而后入局的优势，则是站在前人的肩膀上相对容易让用户获得更成熟的使用体验。诸如折叠屏手机这类拥有全新形态的产品，终究要经历由「动人」到「留人」这两个阶段，才会有后续普及阶段。

  

**02**

**更好，是上探高端**

**市场的「钥匙」**

  

  

少数人拥有，倒是为扩展市场提供了新契机。从去年开始，目前依旧活跃在舞台中央的几家头部国产手机厂商基本都明确了要进军高端市场，这和华为让出一定市场空间不无关系，但长远来看，高端化其实是手机厂商们必然要走的一条路。  

据统计机构 IDC 公布的数据显示，2021 年全球智能手机出货量为 13.548 亿台，同比增长 5.7%，出货量排名前五名的品牌依次为三星、苹果、小米、OPPO 以及 vivo。其中，三星市场占比 20.1%、苹果为 17.4%、 小米为 14.1%、OPPO 为 9.9%、vivo 为 9.5%。

如果按照出货量多少来评估品牌利润，理论上三星应该是最赚钱的手机公司，但事实却是，出货量从没有登上过榜首的苹果公司，已经连续多年成为利润最高的手机品牌，去年第二季度他们拿走了全球手机市场运营利润的 75%，此前还曾一度超过 90%。

从 Counterpoint 发布的一份报告中，可以发现背后原因。虽然 2021 年三星的整体出货量更高，但高端智能手机市场占比只有 17%，苹果则高达 60%。换言之，随着行业增长曲线趋于平稳，销量优势很难进一步扩大的情况下，已经无法弥补单品利润之间所存在的差距。

当「薄利多销」这条路很难维持的大背景下，上探高端市场就变成了必然。这一根本原因之外，iPhone 卖得好，同时也从另外一个角度说明，如今市场对于高端产品的承载能力变得越来越强，用户有能力、也有意愿为高端产品买单，外部环境已经具备。

几家国产手机大厂中，vivo 的高端化策略初见成效。Counterpoint 数据显示，2021 年底，vivo 在国内市场 4000-5000 元价位段的市占率达到 24.1%，位居第一。不过全球范围来看，想要追赶上苹果或者三星，目前看来还有很长一段路要走。

  

![](../Images/149cccde04605da53a70c41e745d7aa2.png)

  

安卓手机品牌想要以直板手机这种形态去冲击高端手机市场，所面临的难题主要问题是产业链高度成熟的时代，大厂的旗舰产品都很好，却很难从根本上做出差异化。而 iPhone 能够长期占据高端市场榜首位置很重要的一个原因，则恰恰是从硬件到软件，都区别于安卓手机。

按照目前的行业现状，或许国产品牌能抢占一部分高端市场份额，想要实现突破难度非常大。折叠屏手机的出现，为跻身高端市场提供了一扇门，而将产品做到更好，则是打开这扇门的「钥匙」。

一方面，折叠屏手机尚未进入普及阶段，尽管入局的厂商很多，不过市场格局未定，可以提供足够大的争夺空间，尽可以施展才华；另外一方面，大众用户对于这类产品的认可度正在不断提升，而且其自带科技潮品属性，更有利于破开被 iPhone 这类直板手机所垄断的高端市场。

为了用好这把「钥匙」，其实 vivo 在品牌端做了一个目前看来最为合理的决定。按照官方说法，NEX 系列不再更新，其所强调的创新精神则由 X 系列来承载，同时将自家的首款折叠屏手机 vivo X Fold 划到 X 系列中。

对于 vivo 的这一决定，大致可以从三个方面来解读：首先，取消 NEX 系列之后，Fold 将毫无争议成为 vivo 最高端的手机产品系列，内部不会出现打架的情况，方便进行用户心理建设；其次，并入 X 系列，vivo X Fold 更容易借助 X 系列多年积攒下来的良好形象快速进入市场；最后，如果未来折叠屏手机成功突破，将反哺 X 系列，让其整体向高端化再迈进一步。

  

**03**

**在成熟中创造惊喜**

  

  

当然，vivo 能否凭借折叠屏手机在高端市场实现突破，最为关键的一点是能否掏出一款具有说服力的产品。对于 vivo X Fold，官方将其描述为「开启折叠屏 2.0 时代」，比较容易猜到的是，它将搭载全新一代骁龙 8 平台，更多详细资料还是要等到发布会结束才能知道。  

  

![](../Images/2d11c8c8ec18759036929218786975da.png)

  

不过近期 vivo 产品副总裁黄韬在公开发表的文章中列举了包括屏幕折痕、内外屏切换顿挫、色差、铰链、屏幕指纹等在内，一系列折叠屏手机应该解决的难题，同时官方宣布 vivo X Fold 将成为博鳌亚洲论坛官方指定手机，这倒是让我们对于 vivo 首款折叠屏手机及其高端化之路又多了一些期待。

回到文章开头我们所提出的那个话题，其实行业的可持续性发展，需要敢于先人一步的探索者，也要有 vivo 这样厚积薄发的成熟派。毕竟，成熟的产品体验才能留住用户，反证创新的价值所在。探索新技术没有问题，追求更好也未必不是一个好的选择。
