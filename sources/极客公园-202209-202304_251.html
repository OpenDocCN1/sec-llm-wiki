折叠屏的「破冰口」在哪？

瞄准商务用户，vivo X Fold+ 想实现一次市场上的「破冰」。


作者 | Jesse
编辑 | 靖宇


如果把 2019 年三星 Galaxy Fold 发布，看作是折叠屏手机「量产落地」的标志，到今天，折叠屏手机已经走过了近四年历史。

四年后，公众对折叠屏这一概念早已不再陌生，但真正出手购买的消费者仍是少数。所有折叠屏手机的销量加起来，也不过百万量级，还停留在「实验」层面。

想要取得更大成功，折叠屏不仅需要改进技术，还需要在市场层面实现一次「破冰」。所以，各家研发技术、产品的同时，也都在寻找市场的「破冰点」。

过程中，vivo 一直伺机未动，直到今年 4 月，他们才发布了旗下第一款折叠屏手机，vivo X Fold，几乎是主流厂商里最后一个出手的。

但 vivo 精确瞄准了「商务」这一垂直细分市场，面向这部分用户的需求，对产品进行了针对性优化。半年后，他们又推出了改进款产品，vivo X Fold+。

这一次，他们是否走得更远？又能否实现「破冰」呢？


01

用屏幕、铰链

定义「质感」



折叠屏手机最核心的部件，自然是它的两块屏幕。

屏幕决定了折叠屏手机的使用方式。过去不少折叠屏产品，或多或少都存在「偏科」的情况。特别是外屏，常出现尺寸过小、过窄，可用度相对较低的问题。又或者内外屏幕采用了不同的参数，使用体验并不一致、连贯。

这是 vivo X Fold+ 下功夫最多的地方，它配备了一块 6.53 英寸的外屏，单纯从正面看过去，这几乎就和一台普通的智能手机没有区别。当然，折叠屏会不可避免地有厚度的问题，但对于习惯双手使用手机的用户来说，X Fold+ 的外屏体验已经非常接近一台正常的 6.5 英寸手机。

至于内屏，则是一块 8 英寸、4:3.55 的大屏，与很多同类产品相比会稍宽一些，更适合双手握持、操作，更适合并排显示两个应用。



关键在于，这两块屏幕的体验几乎一致。vivo X Fold+ 的内外屏幕都采用了 AMOLED E5 屏，均实现了 120Hz 可变刷新率，且都配备了 3D 超声波屏幕指纹，配置上留足了余量，保证用户无论使用哪块屏幕，体验都不会被打断。

在屏幕配置上，vivo X Fold+ 没有刻意规避折叠屏手机「厚重」的特性，而是将大屏的优势放大，最大程度提升双手操作时的体验感。对于那些习惯双手操作手机，操作方式更「稳重」的商务用户来说，这两块屏幕会更具实用价值。

除了屏幕本身的配置，很多人容易忽视的一个点还在于铰链。毕竟对折叠屏来说，柔性屏幕本身的材质、抗折叠性能，其实大同小异。真正决定这块屏幕折叠寿命、影响折痕观感、开合手感的部件，是铰链。

从这个角度来说，铰链才是折叠屏手机真正的「灵魂部件」。

vivo 为 X Fold+ 专门设计了「航天级无忧铰链」，顶着一块浮动中板，来构成整个折叠屏的机械机构。这套铰链由 174 个零部件组成，为最大程度减轻重量、增加强度，铰链部件采用了液体金属锆合金、航空高强度钢、碳纤维等多种航空材料。

单纯从折叠寿命上看，vivo X Fold+ 可以实现 30 万次弯折，也通过了 TüV 的折叠认证。但更重要的是上手手感：X Fold+ 在开合时能给人很强的信心，稳定且有恰当的阻尼，不会有机械结构运动时「松散」的感觉。这种「质感」对折叠屏来说至关重要，直接影响着产品在用户手上的价值传递，特别是对商务用户来说，这种质感尤为重要。



基于「航天级无忧铰链」的设计，vivo X Fold+ 也实现了多角度的悬停，配合软件适配，能把手机变成一台类似于「小笔记本」的交互方式，拓展了折叠屏的产品形态，也让它多了一点与众不同的特质。


02

更「稳重」的硬件配置



相比前代，vivo X Fold+ 最大的升级点，是芯片和充电。

一方面它升级到了采用台积电 4nm 工艺的骁龙 8+，综合整体功耗降低了 15%，能效比显著提升。与此同时，它还增大了电池容量，让整个手机的续航有了 20% 以上的提升。

对商务用户来说，这是非常关键的升级。毕竟商务用户不像发烧友，更关注峰值性能，商务用户需要的是稳定、可靠、持续的性能释放，不掉链子。

围绕这颗能效更强的 SoC，vivo 还把能给的性能配置，几乎全都塞进了 vivo X Fold+ 里，包括超频版的 UFS 3.1 闪存，通过 Solvit 控制器，实现了更快的缓存、读写；定制的 SPU 芯片，提供更安全的数据保护；升级到 80W 双电池闪充，带来更极致的快充体验。

这些升级从纸面上看，或许并不算一次彻底的革新换代，但对那些惜时如金的商务用户来说，每一分的效率提升，节省出的每一点时间，都会有意义，有价值。

包括 vivo X Fold+ 还提供了一个比较容易忽略的配置：行业内首发「双 5G 双卡双通」。



这意味着用户可以同时用两张 5G 卡进行通信、联网，特别是在一些信号较弱、不稳定的场景下，双卡并发通信，如果分属两家不同运营商，就意味着网络多了一道「保险」，掉线的几率更低。这对于一些路上打视频会议、传输文件的使用场景，都很有用，保证了手机体验稳定、顺畅。

包括相机，vivo X Fold+ 依然给到了旗舰级的「蔡司全焦段四摄」配置，搭载蔡司 T* 镀膜，能够最大程度提升镜头透光度，抵抗眩光。总体的拍摄能力上，X Fold+ 达到了一台旗舰手机应有的水准。在此基础上，X Fold+ 通过折叠屏的设计，提供了不少「新玩法」，比如利用主摄+外屏进行自拍，或在悬停模式下，用一半屏幕取景，一半屏幕操作相机。


03

软件体验的「增量」



对折叠屏产品来说，一个长期的难题是，它到底能带来什么「体验增量」？

几年来，不少折叠屏产品之所以没能切中消费者的需求，还是在于它们没有将屏幕尺寸的增量，转化为软件体验的优势。屏幕大了之后，软件好像只是「拉伸」了一下，并没有显示更多信息，催生新的交互。

当然，这口锅也不能扣在各家厂商的软件部门头上，毕竟移动软件市场发展了这么多年，生态丰富且复杂，很难用几个适配场景，就打动全体用户。

所以 vivo X Fold+ 提出了一套更有针对性的「优化方案」。针对商务用户重点关注的场景，进行更深度的优化。对办公、金融类 App 进行重点适配，尝试进行穿透。

具体到体验上，最容易发现的一个变化就是：用 X Fold+ 看股票 K 线是真的很方便。vivo 与同花顺、富途牛牛、老虎证券等多个金融 App 都进行了合作适配，在几乎每个界面上，都能显示一根舒展得更开的线，方便用户用手指拖动光标，浏览股价变化的细节。

更复杂的变化则发生在办公软件上。光是针对「悬停模式」，vivo 就通过自研 + 协助第三方适配等方式，为 X Fold+ 开发了一系列新功能，比如悬停阅读、书写、通话等等。以及，vivo 与 WPS 合作，推出了悬停演讲者模式，可以用手机 WPS 进行投屏，并利用折叠屏的上半显示 PPT 预览，下半显示 PPT 的注视、操作界面，在讲 PPT 时非常直观、方便。



除了悬停模式，vivo 还针对自家的琥珀扫描、量子套件、原子笔记等功能，都进行了针对性的交互适配，提高了「生产力」。用户可以利用这些软件记录想法、扫描文档、并与电脑进行跨设备协同，只需要「拖拽」一下，就可以完成交互。

当然，X Fold+ 不是要在生产层面取代电脑，它真正的核心目标是做得比普通手机更好，发挥出折叠屏「大屏」的优势，

从这个角度来看，它的确已经取得了不错的成绩。

回到开头的问题。

作为一台上市不久的产品，vivo X Fold+ 能否实现折叠屏市场的「破冰」，或许还难以下结论。但在产品层面，它的确已经做到了，将折叠屏的尺寸优势，转化为体验的增量。特别是在它主打的商务领域。

而如果未来有一天，折叠屏真正攻克了市场，我们会记住，一切都是从这些小的产品积累开始的。
