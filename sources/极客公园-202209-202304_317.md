# 奥斯卡影后+奥普拉，投出一只女性健康独角兽

细分赛道正在成为互联网冬日里的一抹暖阳。

近日，美国女性线上医疗健康平台 Maven Clinic 宣布拿到 9000 万美元巨额融资，这是继其去年 1.1 亿美元融资后的又一轮新融资。

作为一家成立于 2014 年的互联网创业公司，Maven Clinic 是近两年间崛起的老牌创业公司。目前，公司投资人包括红杉、CVC 等知名投资机构和好莱坞明星娜塔丽·波特曼、主持人奥普拉等名人。

**Maven Clinic 最新估值高达 13.5 亿美元，是美国女性医疗健康领域的第一家独角兽。**

为女性和家庭提供全方位的生育健康服务，Maven Clinic 如何理解医疗互联网赛道，并成为 Femtech 领域的明日之星？

  

  

**01**

**女性线上医疗平台**

  

  

Maven Clinic 主要为女性提供包括生育咨询、母乳配送、重返职场训练、领养代孕、卵子冷冻等超过四十多种服务。

它支持个人订阅和企业采购两种付费模式：

*   前者由个人下载 App 后按需使用，类似国内的丁香医生、和缓医疗等产品
    
*   后者则是和企业福利部门合作定制，由企业付费采购员工免费使用。企业员工享受的福利更多，比如可以获得专门的「咨询师」，获取医疗服务、教学课程，制定健康计划。
    

  

在简单的体验背后，Maven 在 Clinic 产品打造上充满着极致的互联网思维。

雷军曾将互联网创业总结为 7 个字：专注、极致、口碑、快。在 Maven clinic 身上也有如此身影。

专注。**从 2014 年起，Maven clinic 的产品定位就是为女性提供线上医疗健康咨询和服务，其中「生育」是其服务的核心关键词。**

平台上既有母乳配送、生育咨询、处方开药等相对刚需的服务，也有助产士、睡眠教练、哺乳顾问等相对小众的服务。

**Maven clinc 提供的每一项服务使用频次都不高，但当这些服务彼此连接，用户使用产品因此变得相对高频。**这既全方位地满足了客户的需求，也延长了产品使用生命周期。

极致。在产品能力拓展中，做到极致是 Maven Clinic 的另一大特点。到目前公司服务已可以满足从怀孕到生育、产后护理等四十多个环节超 350 项服务。

目前 Maven 还在野心勃勃的朝着代孕领养、生育财务管理等领域进行延伸，帮助处理复杂的女性及同性家庭生育、健康需求。

快。Maven Clinic 全职员工不到 400 人，**其服务均依靠合作的三十多家供应商为用户提供服务，这让平台功能更新可以做到快速高效。**

  

![](../Images/185e0cd9d66de743cc5159e23a1decf3.png)

Maven Clinic 提供用户专属护理团队｜Maven Clinic

  

2017 年，美国时任总统特朗普宣布要废除「Affordable Care Act」（平价医疗法案）后，Maven Clinic 立刻宣布将免费提供生育管理咨询服务直到年底，以满足用户对政策不了解的需求，平台用户数量和活跃度迅速提升。

口碑。Maven clinc 发展至今，主要依靠用户口耳相传，并收获了不少名人用户。比如影星波特曼既是其用户，其后更成为了它的投资人。

另外，Maven 的数据显示，其约超过 30% 的用户表示产品曾帮助他们控制抑郁和焦虑。另外，接受过 Maven 生育指导的女性剖腹产降低 27%，减少不必要的急诊比例超过 31%。

**美国市场相对旺盛的生育需求，同时，大企业较完善的福利制度，为 Maven Clinic 的市场需求提供了更高的确定性。**

数据显示，美国 2021 年总和生育率（一名女性一生中所生育的平均婴儿数量）为 1.66，意味着每个女性至少会生育一个孩子。在美国企业中，为女性员工提供生育福利支持也被舆论大力倡导。

此外，新冠大流行和美国国内「堕胎」政策的改变（最高法院推翻罗诉韦德案，又称堕胎法案）的变化更为其提供了教育市场的窗口，让女性开始更关注自己的健康。数据显示，罗诉韦德案后，前往 Maven Clinic 咨询的企业与消费者环比增加了 67%。

新冠大流行期间，出行不便使用户大大增加对线上医疗的需求。

从 2014 年成立到 2018 年，Maven Clinic 的用户仅为 15 万。近三年，这个数字迅速突破至 1500 万，增长达到 100 倍。

  

**02**

**健康即平权**

  

  

Maven Clinic 能在创业长跑中将一个小生意熬成了大赛道，离不开创始人 Kate Ryder 的经营。

Ryder 有丰富的职场经历和社会观察经历。

在创业之前，她曾在《经济学人》和《华尔街日报》等媒体当过记者，还是美国前财政部长汉克保尔森回忆录《濒临崩溃》的作者。在 30 岁时她又切换赛道，成为投资机构 index ventures 的投资经理，开始关注科技互联网。

但 VC 并不是 Ryder 职业生涯的终点。

2014 年，移动互联网崛起，过往的经历驱使她加入了创业大潮，创立了 Maven Clinic。

创业的源头，是她从身边友人和自己身上发现的女性生育困境，「孕产妇健康是个复杂的问题，从生育到怀孕到流产再到产后抑郁症，各类问题无处不在」。

在她看来**，生孩子是一件具有里程碑意义的事件，但也会影响女性的身体、个人生活和职业生涯，进而关联到一个家庭的健康，一家企业员工的留存。**

在现象背后，Ryder 进一步关注到了女性抱怨背后的医疗市场空缺，「在一个 50% 的县没有妇产科，并且孕产妇死亡率超过所有其他发达国家的国家（指美国），包括罗诉韦德法案被推翻，证明美国医疗系统中充斥着不平等。」Ryder 表示。

  

![](../Images/2f1e6dc7903500a9b53ca938ecef6a23.png)

Maven Clinic 创始人 Kate Ryder｜greatplacetowork.com

  

线下资源的不均衡、不充分，很难在短时间改变，但互联网线上医疗可以打破时空局限，解决部分资源不均衡的问题。

目标用户和广阔的市场证明了这个生意是可行的，但如何找到正确的进入路径？

**在 to B 还是 to C 这个问题上，Ryder 走过一段弯路。**

创业之初，Maven Clinic 将普通消费者当作的重要客户来源。早年在接受媒体采访时，Ryder 曾强调 Maven Clinic 的目标是，「帮助女性与从医生、营养师到心理健康专家的医疗保健专业人士建立联系」。

基于此定位，在经过一番数据调研后，Maven Clinc 还一度将目标客群定为大学生。公司曾经推出大学生专门订阅功能 Maven Campus，每月 45 美元或每年 300 美元，以取得定制化的医生服务。

面向个人用户方面的尝试显然不算成功。

2018 年后，Maven Clinic 公司主要的客户已经变成企业员工。那一年，Ryder 表示，产品能力上，加倍投入 Maven  Clinic 的家庭福利计划，**其中包括运送母乳和为新妈妈提供重返工作岗位的指导，后者正是 Maven Clinic 的杀手级功能。**Ryder 此后转而强调，Maven  Clinic 能够帮助企业实现留住在职父母，并降低成本的期望。

随着 to C 向 to B 的转向，Maven Clinic 也迎来了自己规模化成长的机会。

官方数据显示，其已与 450 多家客户合作，包括欧莱雅、微软等，用户覆盖超过 175 个国家/地区。

  

  

**03**

**Femtech 正在崛起**

  

  

不只 Maven Clinic 在受到投资者热捧，一种被定义为「Femtech」的互联网创业赛道正在海外 VC 圈变得热闹起来。

Femtech，顾名思义是 Female tech 的简称，由女性月经跟踪应用程序 Clue 的创始人 Ida Tin 于 2016 年在一场媒体演讲上提出。

根据海外金融数据咨询机构 Pitchbook 的定义，FemTech 发展至今已变成涵盖一系列以技术为依托、以消费者为中心的产品和解决方案，目前数量超过 763 家，其提供的服务主要分为四类：

*   女性健康和保健
    
*   女性医疗
    
*   生殖健康
    
*   生育和家庭护理
    

  

数据显示，**2021 年是 femtech 尤其是风险投资的突破年，全球风险投资首次超过 19 亿美元**，并呈持续增长态势。其中的创业领域包括 AI 医疗识别、互联网线上医疗、女性健康管理软件、生育解决方案等多种类型。

  

![](../Images/5d0d82c015ce943e1c779298304a10e3.png)

  

![](../Images/474dcc25c2a5b9c731c1ff016e626a6f.png)

femtech 创业公司和融资额呈现高速增长趋势 | 来源：Pitchbook

  

Pitchbook 在趋势说明中指出，未来 FemTech 公司可能会以多种方式带来女性医疗保健突破性进展，包括女性医疗服务改善、可穿戴健康管理、女性诊断技术突破、LGBT 亚人群需求定制等。

Female 近几年在欧美受到欢迎，无疑与这些地区女性平权运动、同工同酬法律制度等的改善有关。Femtech 的出现可以说是女性用户用脚投票闯出来的。

主打女性生育的互联网医疗公司 Progyny 市值也已超过 31 亿美元，较 2019 年上市以来价值翻了一倍。其今年一季度财报显示，收入同比增长 41%，企业客户同比增加超过 32%。

在中国，主流的互联网电商都曾将医疗视作万亿大产业，但却一直苦于「无门而入」。Maven Clinic 和 Femtech 用自己的快速崛起证明，切准用户痛点面向精准人群的细分赛道，可能是接下来更受用户和投资者青睐的创业方向。
