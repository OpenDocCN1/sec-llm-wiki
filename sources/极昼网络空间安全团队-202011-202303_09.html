01

带音乐家

 下载附件得到一个decode文件和一个压缩包。

用winhex查看文件头为：4D 54 68 64，查询后为mid文件。所给的mid文件和Velato这个编程语言有关：

Velato是一种使用MIDI文件编写的语言。在这种情况下，MIDI文件既可以构成音乐，也可以构成软件。每个指令基于音符本身的音高和音符之间的间隔。


使用该工具进行编译：

http://velato.net/Content/Velato/Velato_0_1.zip

编译完运行decode.exe，得到Hello，World！（压缩包密码）

打开压缩包查看注释信息，里面有一堆空格和制表符。

利用密码解压压缩包，得到Doc1.docx，打开后得到一串字符串。

三种类型的空白字符，替换成摩斯密码可得aeskey9219232322：

01/0/000/101/0/1011/11110/00111/01111/11110/00111/00011/00111/00011/00111/00111

然后AES解密就可以了。

到点了

【1.docx】提示密码由八位组成。【2.docx】是加密的文档。

因此考虑使用office2john.py脚本获取【2.docx】的哈希值。得到：

2.docx:$office$*2007*20*128*16*d2ba0951ae9b22901f90afd753835952*0bae33c42ddc6d84ff0fac39c83a264c*1899936793713d5355f5c5173b5ab1f55540e232

使用john破解该哈希值，利用8位纯数字字典爆破可得：20201024。

【2.docx】文档打开后，在尾部有白色字符，更换颜色后得到培根密码：

AABBAABBBAABBBAAAABBABBABABAAAAABBAAABBBBAABBBAABABABBAAABAAAABAABAABBABAAAAABAA

利用在线培根解密网址对其解密后得到明文为goodnightsweetie。

将【3.docx】的后缀改为zip，得到4.zip，解压后得到一张图片。


因为它是bmp格式，exiftool、stegsolve等工具均无任何发现后考虑使用wbs43open。密码就为处理【2.docx】后得到的内容goodnightsweetie，我又将解密后的文件命名为12345。

查看该文件可得到flag。

01

re1

 利用file命令发现文件是64位elf文件，先直接执行查看程序执行流程，发现输入测试字符后程序直接退出。

将文件放入ida64分析，发现无法使用f5查看为代码，因此查看调用exit的代码位置，找到下图关键位置。

使用gdb调试

$ gdb main

gdb-peda$ r

# ctrl + c 中断

gdb-peda$ ni

flag{11111111}

一路狂按回车到这个位置：

这里开始进行‘flag{’比对，记录一下地址，0x55555555469c

再看在上面ida里的地址，0x69c

可以计算一下基址：0x555555554000

继续往下执行

到这里可以看到，rsp+0x25，那么可以确定flag的长度为38。

在ida继续分析代码，看到0x18096处有可疑代码，与flag内容进行比对：

用基址加上0x18096，下断点，然后输入38位的flag：flag{11111111111111111111111111111111}

$ gdb main

gdb-peda$ b*0x55555556C096

gdb-peda$ r

flag{11111111111111111111111111111111}

可以看到，输入的1被加密成0xe9，并与0xeb进行比对。

1的ascii为0x31，0xe9-0x31=0xb8，那么反推回去，0xeb-0xb8=0x33，也就是3，那么flag第一位应该是3。

将ida中的数值全部复制出来

0xeb,0xf1,0x19,0xe8,0x1e,0x1e,0xf0,0xec,0xef,0x1e,0xe9,0x1e,0xec,0xec,0xe8,0xec,0x19,0x19,0xee,0x1b,0xef,0xef,0xec,0xea,0x1c,0xea,0xe8,0xeb,0xee,0xeb,0x1d,0xf1

可以看到，有些数值是小于0xb8的，因此，需要生成无符号数值，附上本题python脚本，运行脚本即可得到flag。

c = [0xeb,0xf1,0x19,0xe8,0x1e,0x1e,0xf0,0xec,0xef,0x1e,0xe9,0x1e,0xec,0xec,0xe8,0xec,0x19,0x19,0xee,0x1b,0xef,0xef,0xec,0xea,0x1c,0xea,0xe8,0xeb,0xee,0xeb,0x1d,0xf1]
p = 0xb8
flag = ''
for i in c:    m = i - p    a = format(2**32 + m, 'x')[-2:]    flag += chr(int(a,16))
print 'flag{' + flag + '}'
