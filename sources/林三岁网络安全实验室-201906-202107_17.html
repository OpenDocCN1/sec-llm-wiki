开发当前项目过程（利用sqlmapapi接口实现批量URL注入安全检测

1创建新任务记录任务ID @get（“ / task / new”）
2设置任务ID扫描信息@post（“ / option / <taskid> / set”）
3开始扫描对应ID任务@post（“ / scan / <taskid> / start”）
4读取扫描状态判断结果@get（“ / scan / <taskid> / status”）
5如果结束删除ID并获取结果@get（“ / task / <taskid> / delete”）
6扫描结果查看@get（“ / scan / <taskid> / data）
