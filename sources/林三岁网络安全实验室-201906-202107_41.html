OSPF介绍：
OSPF（开放式最短路径优先）

  • 两表一库一颗树

  • LSA介绍

LSA（链路状态通告）一共有11类，IPv4环境中常用的是1、2、3、4、5、7这6类，这些LSA都会放在LSDB中
LSDB以区域为单位存放的，其中5类的LSA会单独存放在特殊的AS外部链路状态数据库中，对于同区域的设备他们应该拥有相同的LSDB信息
SPF算法只会对LSDB中的1、2、4类LSA执行计算，SPF只会在首次进行计算，后期使用I-SPF算法进行增量计算

  • 路由计算流程：

1、寻找邻居
2、交互各自LSA，同步LSDB
3、通过SPF算法对LSDB中相应的LSA执行计算
4、根据计算得到的带权的有向图，以自己为根寻找去往所有节点的最短路径
5、将生成的OSPF协议路由放入OSPF路由表
6、将协议路由表中的路由追加至IP路由表

  • 区域类型：

1、骨干区域
2、非骨干区域

  • 路由器类型：

1、IR
2、BR
3、ABR（区域边界路由器）
  3.1同时属于多个区域
  3.2且有一个区域属于区域0
4、ASBR（自制系统边界路由）
  4.1执行了路由引入行为的OSPF路由器

  • Router ID（身份证编号）

1、以IPv4地址形式标识
2、可以手工配置或自动生成，建议手工配

  • 网络类型:

*根据当前的数据链路层协议判断工作在哪一种网络类型下，其中P2MP属于特例
1、Broadcast(广播-以太网)
2、NBMA（非广播多点可达-FR）
3、P2MP（点到多点）
4、P2P（点到点-PPP）
*其中广播和非广播多点可达的网络类型下需要选举DR、BDR；P2P和P2MP网络类型下不需要选举
*OSPF提出了邻居和邻接的关系
邻居关系：不交互LSA（DRother-DRother）
邻接关系：交互LSA（DR-BDR、DR、BDR-DRother）

  • DR、BDR选举

1、比较优先级，以高为优
2、优先级相同，比较Router ID，以高为优
伪节点的RID有DR设备的接口IP地址标识

  • LSA类型

1类LSA - Router LSA 每台路由器都会产生，只能在产生区域泛洪，作用是用来描述直连链路状态，而OSPF认为直连链路状态分为4种类型（Stubnet、P2P、Transnet、Virtual-Link）：
Link State ID                生成者router id
Adv Router                        生成者router id
*4中链路类型：
Stubnet：用于描述路由器直连网络号--------路由信息
Link id        直连网络号
Data                直连接口掩码
Cost                该直连网络的开销，取决于链路带宽大小
P-2-P：用于描述P2P邻居---------拓扑信息
Link id        邻居的router id
Data                与邻居相连的接口IP地址
Cost                去往邻居的接口开销
Transnet：用于描述MA网络中邻居，伪节点（本质上代表路由器某个接口属于广播型或NBMA型网络）----------拓扑信息
Link id        伪节点的router id，由此链路上的DR设备接口地址充当
Data                连接伪节点的接口地址
Cost                去往伪节点的接口开销
Virtual-Link：用于描述虚链路上的邻居--------拓扑信息
Link id        虚链路对端路由器router id
Data                与对端路由器相连的接口IP地址
Cost                虚链路的开销
2类LSA – Network LSA DR设备产生，只能在产生的区域泛洪，作用1描述伪节点连接哪些节点；作用2描述所处网段的掩码信息，用于计算这条链路的网络号
Link state id                DR接口IP地址
Adv Router                        DR的router id
Net Mask                        DR的接口掩码
Atatched router        该MA网络中的所有邻居router id

2、DD（主从选举、描述LSDB中的LSA摘要信息）

*LSA摘要信息，由如下三部分组成：
LS type：
此字段标识了LSA的格式和功能。常用的LSA类型有六种（123457）
Link State ID：
此字段是该LSA所描述的哪部分链路的标识。不同类型LSA取值不同
Advertising Router：
此字段是产生此LSA的路由器的Router ID
*lsa老化时间3600s，每隔1800s会重新泛洪
3类LSA – Network Summary LSA 由ABR设备产生，传播的范围为除产生区域的其它区域，作用是通告域间路由
Link state id                由域间路由前缀充当
Adv Router                        ABR的router id
Net mask                        域间路由的子网掩码
*Adv router每经过一个ABR转发都会修改为当前ABR的router id
OSPF路由传递，区域内（链路状态），区域间（距离矢量）

*邻居RID是否可以相同？                NO，邻居关系会无法建立
*同区域RID是否可以相同？                NO，两个原因:

  • 分类：

1、stub
过滤4、5类LSA，ABR自动通过3LSA产生缺省路由
不允许存在ASBR，如果是stub区域的ABR则可以执行引入行为，但是不注入stub
2、totally stub
过滤3、4、5类LSA，ABR自动通过3LSA产生缺省路由
不允许存在ASBR，如果是stub区域的ABR则可以执行引入行为，但是不注入stub
3、nssa
过滤4、5类LSA，ABR手工通过7LSA产生缺省路由
允许存在ASBR存在，如果是nssa区域的ABR执行引入行为，即产生5类也产生7类分别通告
4、totally nssa
过滤3、4、5类LSA，ABR自动通过3LSA产生缺省路由
允许存在ASBR存在，如果是nssa区域的ABR执行引入行为，即产生5类也产生7类分别通告
*5、7类LSA都是填充外部路由，但是5类LSA单独存放在AS外部LSDB，7类是存放在所属区域的LSDB

配置方法：OSPF进程视图、OSPF区域视图
进程视图
export方向：只在ASBR上引入的路由起效果，而不是指对发出的路由信息执行过滤；（LSA）
import方向：OSPF路由表中学习的路由加入IP路由表时执行过滤；（ABR上会影响3类LSA产生）
区域视图
export方向：对本区域向其它区域发布的3类LSA执行过滤（LSA）
import方向：对向本区域发布的3类LSA执行过滤（LSA）
认证和加密的区别？
认证：主要实现保证报文来源的可靠性，确保报文是一个合法邻居发送的，以及防范报文传递过程中被篡改和被他人伪造；认证不会实现对报文信息的加密，报文内容还是明文；
加密：主要实现信息的私密性，只能被能够解密的设备所读取并处理，通过嗅探无法实现对报文内容的获取；加密机制能被破解，但认证机制理论角度来说是不可逆的；
