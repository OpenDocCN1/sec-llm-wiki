**配置步骤：**

(1) 配置 MSR36-20\_1

\# 配置各接口的 IP 地址，具体略。

\# 配置 ACL 3101，定义要保护由子网 10.1.1.0/24 去子网 10.1.2.0/24的数据流。

<H3C>system-view

\[H3C\] aclnumber 3101

\[H3C-acl-adv-3101\]rule permit ip source 10.1.1.0 0.0.0.255 destination 10.1.2.0 0.0.0.255

\[H3C-acl-adv-3101\] quit

\# 创建 IPsec 安全提议 lzc。

\[H3C\] ipsec transform-set lzc

\# 配置安全协议对 IP 报文的封装形式为隧道模式。

\[H3C-ipsec-transform-set-lzc\]encapsulation-mode tunnel

\# 配置采用的安全协议为 ESP。

\[H3C-ipsec-transform-set-lzc\] protocolesp

\# 配置 ESP 协议采用的加密算法为 128比特的 AES，认证算法为 HMAC-SHA1。

\[H3C-ipsec-transform-set-lzc\]esp encryption-algorithm aes-cbc-128

\[H3C-ipsec-transform-set-lzc\]esp authentication-algorithm sha1

\[H3C-ipsec-transform-set-lzc\]quit

\# 创建 IKE keychain，名称为 lzc1。

\[H3C\] ike keychain lzc1

\# 配置与 IP 地址为 2.2.2.1 的对端使用的预共享密钥为明文 123456TESTplat&!。

\[H3C-ike-keychain-lzc1\] pre-shared-keyaddress 2.2.2.1 255.255.255.0 key simple

123456TESTplat&!

\[H3C-ike-keychain-lzc1\] quit #创建 IKEprofile，名称为 LZC1。

\[H3C\] ike profile LZC1

\# 指定引用的 IKE keychain 为 lzc1。

\[H3C-ike-profile-LZC1\] keychain lzc1

\# 配置本端的身份信息为 IP地址 1.1.1.1。

\[H3C-ike-profile-LZC1\] local-identityaddress 1.1.1.1

\# 配置匹配对端身份的规则为 IP地址 2.2.2.1/24。

\[H3C-ike-profile-LZC1\]match remote identity address 2.2.2.1 255.255.255.0

\[H3C-ike-profile-LZC1\] quit

\# 创建一条 IKE 协商方式的 IPsec 安全策略，名称为 LZC，顺序号为 10。

\[H3C\] ipsec policy LZC 10 isakmp

\# 配置 IPsec 隧道的对端 IP 地址为 2.2.2.1。

\[H3C-ipsec-policy-isakmp-LZC-10\]remote-address 2.2.2.1

\# 指定引用 ACL 3101。

\[H3C-ipsec-policy-isakmp-LZC-10\] securityacl 3101

\# 指定引用的安全提议为 lzc。

\[H3C-ipsec-policy-isakmp-LZC-10\]transform-set lzc \# 指定引用的 IKE profile 为 LZC1。

\[H3C-ipsec-policy-isakmp-LZC-10\]ike-profile LZC1

\[H3C-ipsec-policy-isakmp-LZC-10\] quit

\# 在接口 GigabitEthernet2/1/1 上应用 IPsec 安全策略 LZC。

\[H3C-GigabitEthernet2/1/1\]ipsec apply policy LZC

\[H3C-GigabitEthernet2/1/1\] quit

 (2) 配置 MSR36-20\_3

\# 配置各接口的 IP 地址，具体略。

\# 配置 ACL 3101，定义要保护由子网 10.1.2.0/24 去往子网 10.1.1.0/24的数据流。

<H3C>system-view

\[H3C\] acl number 3101

\[H3C-acl-adv-3101\] rulepermit ip source 10.1.2.0 0.0.0.255 destination10.1.1.0 0.0.0.255

\[H3C-acl-adv-3101\] quit

\# 创建 IPsec 安全提议 lzc。

\[H3C\] ipsec transform-set lzc

\# 配置安全协议对 IP 报文的封装形式为隧道模式。

\[H3C-ipsec-transform-set-lzc\]encapsulation-mode tunnel

\# 配置采用的安全协议为 ESP。

\[H3C-ipsec-transform-set-lzc\] protocolesp

\# 配置 ESP 协议采用的加密算法为 128比特的 AES，认证算法为 HMAC-SHA1。

\[H3C-ipsec-transform-set-lzc\]esp encryption-algorithm aes-cbc-128 \[H3C-ipsec-transform-set-lzc\] espauthentication-algorithm sha1 \[H3C-ipsec-transform-set-lzc\] quit #创建 IKEkeychain，名称为 lzc1。

\[H3C\]ike keychain lzc1

\# 配置与 IP 地址为 1.1.1.1 的对端使用的预共享密钥为明文 123456TESTplat&!。

\[H3C-ike-keychain-lzc1\] pre-shared-keyaddress 1.1.1.1 255.255.255.0 key simple

123456TESTplat&!

\[H3C-ike-keychain-lzc1\] quit #创建 IKEprofile，名称为 LZC1。

\[H3C\] ike profile LZC1

\# 指定引用的 IKE keychain 为 lzc1。

\[H3C-ike-profile-LZC1\] keychain lzc1

\# 配置本端的身份信息为 IP地址 2.2.2.1。

\[H3C-ike-profile-LZC1\] local-identityaddress 2.2.2.1

\# 配置匹配对端身份的规则为 IP地址 1.1.1.1/24。

\[H3C-ike-profile-LZC1\]match remote identity address 1.1.1.1 255.255.255.0

\[H3C-ike-profile-LZC1\] quit

\# 创建一条 IKE 协商方式的 IPsec 安全策略，名称为 LZC0，顺序号为 10。

\[H3C\] ipsec policy LZC0 10 isakmp

\# 配置 IPsec 隧道的对端 IP 地址为 1.1.1.1。

\[H3C-ipsec-policy-isakmp-LZC0-10\] remote-address1.1.1.1

\# 指定引用 ACL 3101。

\[H3C-ipsec-policy-isakmp-LZC0-10\]security acl 3101

\# 指定引用的安全提议为 lzc。

\[H3C-ipsec-policy-isakmp-LZC0-10\]transform-set lzc \# 指定引用的 IKE profile 为 LZC1。

\[H3C-ipsec-policy-isakmp-LZC0-10\]ike-profile LZC1

\[H3C-ipsec-policy-isakmp-LZC0-10\] quit

\# 在接口 GigabitEthernet2/1/1 上应用 IPsec 安全策略 LZC0。

\[H3C-GigabitEthernet2/1/1\] ipsec applypolicy LZC0
