MSTP介绍：  

*   MSTP版本  
    

STP RSTP PVST MSTP

*   RSTP 跟端口快速切换（前提是有阻塞端口）  
    

跟乔每隔2秒发送一次BPDU报告状态，超过BPDU老化时间以后自动切换阻塞端口（STP RSTP)

*   STP 保护机制  
    
    1、BPDU保护机制
    
    启动了BPDU保护功能后，如果边缘端口收到了配置消息，MSTP就将这些端口关闭
    
    2、根桥保护
    
    对于设置了根保护功能的端口，一旦该端口收到某实例优先级更高的配置消息，立即将该实例端口设置为侦听状态，不再转发报文
    
    3、环路保护
    
    配置了环路保护的端口，当接收不到上游设备发送的BPDU报文时，环路保护生效。如果该端口参与了STP计算，则不论其角色如何，该端口在所有实例都将处于Discarding状态
    
    4、TC保护机制
    
    设置设备在收到TC-BPDU报文后的10秒内，进行地址表项删除操作的最多次数，监控在该时间段内收到的TC-BPDU报文数是否大于门限值。

9.  #  
    
10.  interface GigabitEthernet1/0/2  
     
11.  port link-type trunk  
     
12.  port trunk permit vlan 1 10 20  
     
13.  #  
     
14.  stp region-configuration             配置MSTP域配置  
     
15.  region-name test                    配置MSTP域名称（同一个MSTP域的所有设备名称要相同）  
     
16.  instance 10 vlan 10                 配置MSTP生成树实例  
     
17.  instance 20 vlan 20  
     
18.  active region-configuration         激活域配置  
     
19.  #  
     
20.  stp instance 0  root primary        设置实例跟桥  
     
21.  stp instance 10  root primary  
     
22.  stp instance 20 root secondary      设置实例备跟
