实验需求：  
ssh测试机在一个局域网内，RT1作为该局域网的网关，具体要求如下：  

*   外网主机可以通过 Router 访问内网 ssh测试机；
    
*   内网主机在访问 ssh测试机时，需要通过外网地址访问，从而有效的避免内网服务器受到来自内部网络的攻击。  
    

配置思路：  

*   通过定义 ACL 规则，并将其与 NAT 配置关联，实现只对内网匹配指定的 ACL 规则的报文进行地址转换。
    
*   为使外网主机可以通过外网地址访问内网 ssh测试机，需要在外网侧接口配置 NAT 内部服务器功能。
    
*   为使内网主机通过外网地址访问内网 ssh测试机，需要在内网侧接口使能 NAT hairpin 功能  
    

配置步骤：  

*   ssh测试机配置  
    

1.  #  
    
2.  vlan 2  
    
3.  #  
    
4.  interface Vlan-interface2  
    
5.  ip address 192.168.0.2 255.255.255.0  
    
6.  #  
    
7.  interface GigabitEthernet1/0/1  
    
8.  port access vlan 2  
    
9.  #  
    
10.  ssh server enable  
     
11.  #  
     
12.  line vty 0 4  
     
13.  authentication-mode scheme  
     
14.  user-role network-admin  
     
15.  user-role network-operator  
     
16.  #  
     
17.  local-user admin class manage  
     
18.  password simple 123456  
     
19.  service-type ssh  
     
20.  authorization-attribute user-role network-admin  
     
21.  authorization-attribute user-role network-operator  
     
22.  #
     

复制代码

*   RT1配置  
    

1.  #  
    
2.  acl basic 2000  
    
3.  rule 0 permit source 192.168.0.0 0.0.0.255  
    
4.  #  
    
5.  interface GigabitEthernet0/1  
    
6.  ip address 192.168.0.1 255.255.255.0  
    
7.  #  
    
8.  interface GigabitEthernet0/2  
    
9.  ip address 10.0.0.1 255.255.255.0  
    
10.  nat outbound 2000  
     
11.  nat server global 10.0.0.1 inside 192.168.0.2  
     
12.  nat hairpin enable  
     
13.  #  
     
14.  ip route-static 0.0.0.0 0 10.0.0.2  
     
15.  #
     

复制代码

*   ISP配置  
    

1.  #  
    
2.  interface GigabitEthernet0/0  
    
3.  ip address 10.0.0.2 255.255.255.0  
    
4.  #  
    
5.  interface GigabitEthernet0/1  
    
6.  ip address 172.16.1.1 255.255.255.0  
    
7.  #
    

复制代码

*   公网配置  
    

1.  #  
    
2.  interface GigabitEthernet0/0  
    
3.  ip address 192.16.1.1 255.255.255.0  
    
4.  #  
    
5.  interface GigabitEthernet0/1  
    
6.  ip address 172.16.1.2 255.255.255.0  
    
7.  #  
    
8.  ip route-static 0.0.0.0 0 172.16.1.1  
    
9.  #
