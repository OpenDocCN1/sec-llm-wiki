一、实验环境

FTP服务器：CentOS 192.168.1.108

FTP客户端：CentOS 192.168.1.110

中间人：    Kali Linux 192.168.1.107

二、实验环境搭建

传送门：https://www.cnblogs.com/lei0213/p/8657039.html

本人的物理机上已经安装了FTP服务器软件所以就不一一演示了，大家可以参照传送门的文章进行搭建。

三、操作步骤

1、初始化ettercap

ettercap -G

2、选择sniff进行嗅探抓包

3、开始抓包

选择Unified sniffing选项

4、选择网卡，一般虚拟机里面选择eth0就行，物理机按照实际使用网卡选择

5、点击Hosts然后选择Scan for hosts开始扫描主机

6、点击Hosts然后选择Hosts list打开主机列表

7、查看扫描到的主机

8、在FTP客户机上登录FTP服务器，客户机需要安装FTP服务，不然会报错

 yum -y install ftp 

登录服务器

9、查看结果

10、获取这些信息后停止嗅探，在菜单栏中依次单击Start然后选择Stop sniffing选项即可。

最后提醒大家再上传隐私文件的时候尽量选择Https协议，不然的话很容易被人通过中间人攻击获取密码，然后自行YY.........
