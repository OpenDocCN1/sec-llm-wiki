kali Linux环境配置

1、 设置更新源

leafpad /etc/apt/sources.list 设置更新源（更新源可以百度，我个人觉得kali官方的更新源比较好用）

![](../Images/fcb2abb6fd0c4e6e87a15f061927a863.png)

   

![](../Images/2a48da26a02967e5b20fced863d75818.png)

2、设置签名

wget archive.kali.org/archive-key.asc   //下载签名

![](../Images/99a7302035a4d6ccbfa28dac8ac8e829.png)

apt-key add archive-key.asc   //安装签名  执行完成以后显示ok即可

3、设置更新

apt-get install linux-headers-$(uname -r) 更新内核  

 apt-get update 执行即可更新源

![](../Images/a4047e8992e004fcc15b9a51e70ee6db.png)

 apt-get upgrade 更新软件 然后会出现一个选项 输入y

![](../Images/b287685fde30de675c9d480fffc0c363.png)

![](../Images/8993cfdfe9284a29a10256e5d7c7b939.png)

apt-get dist-upgrade 安装更新  然后会出现一个选项 输入y

![](../Images/420a2525670ada0dbf8f6f9989b76a86.png)
