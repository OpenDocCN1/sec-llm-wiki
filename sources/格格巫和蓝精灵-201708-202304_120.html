0x00 明文攻击介绍

简单地来讲，就是当我们知道一个加密压缩包内某个文件的内容的时候，我们就可以利用明文攻击迅速有效找出 keys（可以理解为 password 的内部表示形式），从而破解这个压缩包。（password 不一定能成功还原，不过解压文件有 keys 就够了）

0x01 常见攻击方式

1.1 基础知识

通常我们见到的明文攻击，一般有几个先决条件：

1、必须是zip的压缩包2、必须有压缩包内某个完整的原文文件（即压缩完后crc32值必须相同）3、明文文件需要被相同的压缩算法标准压缩4、明文对应文件的加密算法需要是 ZipCrypto Store

注：AES256-Deflate/AES256-Store加密的文件不适用于明文攻击。

1.2 实际利用

例题：2019年山东省大学生网络安全竞赛取证题-磁盘取证

使用cmdscan发现压缩包

filescan获取文件列表，发现zip压缩包

使用foremost分离压缩包

打开压缩包发现又个jpeg文件，猜想是明文攻击

使用dumpfiles分离那个图片

压缩完以后发现大小不一样，使用16进制编辑器查看文件

发现末尾跟了一堆0，删掉 进行明文攻击获取压缩包密码

解密即可获取flag

0x02 深入利用方式

2.1 基础知识

最近在比赛中碰到过好多遍明文攻击的深入利用方式，相比于传统的利用方式，深入利用需要的明文文件的内容更少，仅需要小部分内容即可对文件进行明文攻击。由于各类文件都有各自的文件格式，这更加扩大了明文攻击的攻击面，具体要求是：

1、至少已知明文的12个字节及偏移，其中至少8字节需要连续。2、明文对应的文件加密方式为ZipCrypto Store

如果要固定使用ZipCrypto Store算法加密，可以在压缩的时候指定压缩方式为“存储”。

2.2 工具介绍

工具项目地址：https://github.com/kimci86/bkcrack

直接下载打包好的程序，省的自己编译了。
bkcrack常用参数    -c 提取的密文部分    -p 提取的明文部分    -x 压缩包内目标文件的偏移地址  部分已知明文值    -C 加密压缩包    -o offset 指定的连续明文在压缩包内目标文件的偏移量（若使用文件头，则该参数指定0）

2.3 实际利用

例题：2021湖湘杯-某取证

首先内存取证，扫描iehistory，发现有个 target.zip

下载下来以后发现是加密的，打开发现一个store一个deflate，且未知文件内容

猜测是明文攻击的深入利用方法，类似钓鱼城杯的量子加密那个题
所以取出jpg图片的文件头，进行爆破
echo FFD8FFE000104A4649460001 | xxd -r -ps > jpg_plainbkcrack -C target.zip -c t.jpg -p jpg_plain -o 0

爆破一段时间后，获得秘钥b0a90b36 14dd97b9 f5d648cf 使用秘钥进行解密，因为t.jpg是store格式的，可以直接解密

bkcrack -C target.zip -c t.jpg -k b0a90b36 14dd97b9 f5d648cf -d t.jpg

a.jpg是经过deflate压缩的，提取出来的内容需要进行解压缩，使用bkcrack自带的infalte.py进行解压

bkcrack -C target.zip -c a.jpg -k b0a90b36 14dd97b9 f5d648cf -d a.deflatepython3 inflate.py < ~/Desktop/a.deflate > a.jpg

注：1、inflate.py在bkcrack项目里自带，去项目文件夹里找找 2、只有store算法打包的文件，解密出来才可以直接打开，deflate算法压缩的解密出来是乱码的是正常的，需要解码才能恢复原来的文件的样子。

最后获得a.jpg

后半段去找壁纸文件 filescan找到文件并提取获得后半段
volatility -f PC11.raw --profile=Win7SP1x64 dumpfiles -Q 0x000000007dfb7e90 -D ./


0x03 总结

1、已知的明文长度越长，破解速度越快。

2、图片、文本格式文件、压缩包是最容易以store算法被加密打包的。

3、有时会出现攻击得到了秘钥，却无法解密正确文件的情况。

4、传统的明文攻击利用方式大部分情况下可以破解出压缩包的密码来，直接解压压缩包即可。小部分情况下和深入利用一样，只能获得秘钥，无法直接获得压缩包密码。
