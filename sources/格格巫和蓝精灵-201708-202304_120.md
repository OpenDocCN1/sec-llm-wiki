## 0x00 明文攻击介绍

简单地来讲，就是当我们知道一个加密压缩包内某个文件的内容的时候，我们就可以利用明文攻击迅速有效找出 `keys`（可以理解为 `password` 的内部表示形式），从而破解这个压缩包。（`password` 不一定能成功还原，不过解压文件有 `keys` 就够了）

## 0x01 常见攻击方式

### 1.1 基础知识

通常我们见到的明文攻击，一般有几个先决条件：

*   
*   
*   
*   

```
1、必须是zip的压缩包2、必须有压缩包内某个完整的原文文件（即压缩完后crc32值必须相同）3、明文文件需要被相同的压缩算法标准压缩4、明文对应文件的加密算法需要是 ZipCrypto Store
```

**注：`AES256-Deflate/AES256-Store`加密的文件不适用于明文攻击。**

### 1.2 实际利用

**例题：2019年山东省大学生网络安全竞赛取证题-磁盘取证**

使用`cmdscan`发现压缩包

![](../Images/571762980a6ac3543274e8b729a545bb.png)

`filescan`获取文件列表，发现`zip`压缩包

使用`foremost`分离压缩包

打开压缩包发现又个`jpeg`文件，猜想是明文攻击

使用`dumpfiles`分离那个图片

![](../Images/ab1bb0fa19a954799b64b776a29f30b2.png)

压缩完以后发现大小不一样，使用`16`进制编辑器查看文件

![](../Images/7d70d674e8d7b0550296d41c639e7b07.png)

发现末尾跟了一堆`0`，删掉 进行明文攻击获取压缩包密码

![](../Images/10f0c3a70bba14d9a13c4eecf39eca98.png)

解密即可获取`flag`

## 0x02 深入利用方式

### 2.1 基础知识

最近在比赛中碰到过好多遍明文攻击的深入利用方式，相比于传统的利用方式，深入利用需要的明文文件的内容更少，仅需要小部分内容即可对文件进行明文攻击。由于各类文件都有各自的文件格式，这更加扩大了明文攻击的攻击面，具体要求是：

*   
*   

```
1、至少已知明文的12个字节及偏移，其中至少8字节需要连续。2、明文对应的文件加密方式为ZipCrypto Store
```

如果要固定使用`ZipCrypto Store`算法加密，可以在压缩的时候指定压缩方式为“存储”。


## 0x03 总结

1、已知的明文长度越长，破解速度越快。

2、图片、文本格式文件、压缩包是最容易以`store`算法被加密打包的。

3、有时会出现攻击得到了秘钥，却无法解密正确文件的情况。

4、传统的明文攻击利用方式大部分情况下可以破解出压缩包的密码来，直接解压压缩包即可。小部分情况下和深入利用一样，只能获得秘钥，无法直接获得压缩包密码。
