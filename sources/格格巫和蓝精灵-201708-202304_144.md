**\## 正题**  

      RSA是一种非对称式的加密算法，广泛用于保密通信。RSA算法涉及三个参数,n,e,d，其中私钥是n,d，公钥是n,e,n是两个素数的乘积，一般这两个素数在RSA中用字母p,q表示，e是一个素数d是e模 varphi(n) 的逆元，CTF的角度看就是，d由e,p,q可以求解出的。

      一般CTF就是把我们想要获得的flag作为明文，RSA中表示为m,然后通过RSA加密，得到密文，RSA中表示为C。

        **加密过程**

        **c=m^e mod n ，python里面可以通过 c=pow(m,e,n)进行加密。**

       ** 解密过程**

        **m=c^d mod n，python里面可以通过 m=pow(c,d,n)进行解密****。**

       题目中一般会给出n、e、c，需要求解d，**d = gmpy2.invert(e, (p-1)\*(q-1))**也是现成的公式，所以就需要将n分解成p和q，这也是rsa加密的核心所在，基于大质数分解难题，但在实际过程中会存在有很多些“问题”让你直接或者间接的分解出p和q。那来看下我们今天要看的简单题目。

![](../Images/015516a67d10d8650744392a13579327.png)

题目中给出了p+q以及p-q，那么通过我们小学学习的知识可以知道p=(a+b)/2,q=(a-b)/2,至此问题解决

![](../Images/98ab5c5542919461caaecd3b1c1dabcd.png)

直接套用公式即可解决这个问题

  

import gmpy2

from Crypto.Util.number import \*

a=3203986......

b=9554090.....

c=2288601.....

  

p=(a+b)/2

q=(a-b)/2

n=p\*q

e = 65537

phi = (p-1)\*(q-1)

d = gmpy2.invert(e,phi)

flag = pow(c,d,n)

flag = long\_to\_bytes(flag)

print flag

运行脚本即可得到flag![](../Images/c3999bd152073162ef18bd2b2887c2cd.png)
