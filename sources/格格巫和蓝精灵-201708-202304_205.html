0x01 第一页

Q:

什么是？

为什么要？

怎么做？

A:

一种必要的防守反击的手段。

查清攻击来源，最终目的找到攻击者。

通过信息收集和漏洞利用，收集攻击者信息，反制攻击者服务器。

与常规应急响应中的溯源，存在区别。

1.1 分析类型

当我们收到设备告警信息之后，首先要做的就是根据完整的数据包进行判断。

判断此次攻击是正常业务还是批量扫描还是针对性的攻击。

有些业务系统本身的代码逻辑有问题，会引发设备告警，比如：

如果攻击事件是比较离谱的，并且次数很多，可能就是扫描器了，比如：

如果有明显网站特征或者是利用系统中间件或者框架漏洞的，可能就是针对性攻击了，比如：

判断完事件类型之后，如果是正常业务，那自然皆大欢喜，如果是扫描或者针对性攻击，就要继续下一步。

1.2 收集ip信息

首先可通过威胁情报进行分析，比如：
https://x.threatbook.cn/ https://ti.360.cn/ https://ti.qianxin.com/ https://ti.dbappsecurity.com.cn/

需要注意的是：

同C段，不代表是同组织，尤其是vps。

历史解析域名，不一定是现在绑定域名。

之后进行端口探测，主要以常见服务端口为主，比如：

80，81，88，443，1433，1521，3306，5432，6379，8080，8081

可利用goby或者nmap或者其他工具。

综合以上信息之后，对ip进行判断。

代理ip大部分为家庭宽带，肉鸡大部分为云上vps。

代理ip基本上无开放服务，肉鸡绝大部分存在服务端口。

代理ip：本次溯源到此结束。

肉鸡ip：冲冲冲！

拿到服务器权限之后，就是下一步了。

0x03 第三页

拿到权限之后，需要尽可能多的收集攻击者遗留的信息。

可类比于现场应急响应。

下面以linux为例，如果肉鸡是windows，恭喜你中奖了。

（1）ps -aux 查看当前进程

检查反弹shell的进程(除了自己)，交互式shell的进程,执行脚本的进程

（2）netstat -ano 显示当前网络状态（端口）

检查是否存在大量对外端口扫描,是否存在访问外部ip的奇怪端口（1234,2333,8888,6666,50050）

（3）查看是否存在提权程序或脚本或文本信息

主要检查当前目录以及/tmp目录

（4）查看history历史命令

大概率没有发现

（5）查看是否存在ssh私钥

一般目录是/home/xxxx/.ssh/和/root/.ssh/

（6）查看是否存在计划任务

可通过crontab -l 命令或者查看/var/spool/cron和/etc/cron.d目录

需要排除黑产挖矿

（7）查看是否存在其他 webshell

主要为当前目录或者upload目录或者其他同级目录

（8）查看 web 日志中是否存在其他攻击记录

主要为/var/logs目录和./runtime/log目录

（9）可查看数据库中是否有反弹 shell 或者 ssh 私钥的信息

主要针对于redis

（10）查看数据库中是否有连接记录

主要是postgresql数据库，语句为：

select client_addr,backend_start,query from pg_stat_activity;

以上所有操作,均为了获取攻击者的服务器ip

或者真实ip,以及攻击者的详细信息（id，常用密码，设备信息等）。

以上信息整合后，翻到第一页，如果发现ip为肉鸡，请翻到第二页。

如果ip不是肉鸡，继续下一步。

0x04 第四页

假设我们在以上过程中，得到了攻击者的ip，提权exp，常用id。

（1）对于ip，可重复第一步

ip反查域名

域名查whois注册信息

域名查备案信息

域名反查邮箱

邮箱反查下属域名

域名反查注册人

注册人反查下属域名

（2）对于提权程序

如果生成了调试信息，没有勾选否，那么就可能会造成PDB信息泄露。

通过C32看到程序尾部的信息，找到生成木马的主机用户名。

大多数人的主机名就是自己的常用id。

（3）对于常用id

动用一切手段获取id其他信息

各大搜索引擎（百度,谷歌等）

各大社交平台（微信，QQ，github，微博，豆瓣，知乎，贴吧，脉脉等）

各大漏洞平台（补天，漏洞银行，教育src等）

小技巧：

支付宝转账

github反查邮箱

在综合所有攻击者信息之后，可对其进行画像。之后，输出成果报告。溯源到此结束。

0xFF 结尾

总结一下：

• 收到设备告警
• 分析数据包 （正常业务，批量扫描，针对性攻击）
• 收集ip信息 （域名，情报，whois）
• 端口探测 （nmap，goby）
• 分析ip （代理ip，肉鸡ip）
• 漏洞探测
• 利用漏洞 （拿到权限）
• 在服务器收集证据/信息
• 综合信息，进行画像
• 生成报告
