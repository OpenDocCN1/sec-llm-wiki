## 0x00 靶场介绍以及环境搭建

引用一下迪总给的拓扑图，非常清晰：

![](../Images/afba8a39ffb123c5d07cbaa1e6ea49c5.png "null")

`Target1 / 2 / 3`分别对应`CentOS7 / Ubuntu / Windows7`，其中`Target1`也就是`Web`服务器需要启动一下宝塔（注意看靶机描述信息）：

```

/etc/init.d/bt start
```

**注意：不要勾选这一选项，否则后面代理就就没有意义了。建议导入后打开虚拟机，使用`root/teamssix.com`登录主机，通过`ifconfig`检查网络情况是否正常。**

![](../Images/e988758ed9785dec1fa7271dc5cd9e49.png "null")

另外，我使用的是`2022`版的`kali`，部分命令可能与往前有些许出入，请读者自行斟酌。
