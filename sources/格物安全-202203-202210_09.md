### simple\_re

这个题算是比较正常的难度，Windows下的程序，程序有几个反调试，去掉就好，另外程序是用c++写的，用了虚表，比较麻烦，伪代码如下：

![](../Images/e6b465a323ea2608505d44f1844aa004.png "null")

输入错误的验证码，程序运行到第三个函数就异常退出，动态调试看一下：

*   • 函数一
    

```


sub_7FF7A6F84160(__int64 a1)
```

这部分主要是对输入的`flag`进行一个变换。

*   • 函数二
    

```
BOOL __fastcall 
```

函数先申请了一片空间，然后将`flag`的取前 4 个，然后循环与`ArgList[i]`进行异或，然后写进空间，这个地方推测可能是使用`smc`。

*   • 函数三
    

```
__int64 __fastcall 
```

很明显调用了`lpAddress`，因此只要函数二的结果不对，函数三执行的指令就错误，由于只是取`flag`前 4 位，因此可以很容易突破函数二，动态跟踪一下函数三，看看最终做了什么验证。

![](../Images/1a3a6762ad820b85819574a8700944ab.png "null")
