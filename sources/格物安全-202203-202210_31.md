**![](../Images/aa3becf7505faf64723ca93c9292e7b9.png)**探测局域网内存活主机确定目标**  
nmap -sP 10.131.1.208/24

![](../Images/5dda8143e453353d5b0d92e47e808896.png)

因为扫描结果中返回了vmware虚拟地址所以可以确定目标的IP为：10.131.1.145  

![](../Images/aa3becf7505faf64723ca93c9292e7b9.png)**使用nmap探测目标主机开放的端口  
**nmap -T4 -A -v 10.131.1.145                                                        

![](../Images/ee77644346342b3e080e68be7f057843.png)

  
开放了22和80端口对应的服务为ssh,http，并且可以看到使用了Apache 2.4.29(ubuntu),运行在 linux 4x|5x  

![](../Images/aa3becf7505faf64723ca93c9292e7b9.png)**使用九头蛇对目标22好端口进行爆破  
**hydra -l root -P /usr/share/wordlists/rockyou.txt -f -vV -t 4 ssh://10.131.1.145                                                                            

![](../Images/347c82fe59bf9ef37de19ad02c02777c.png)

  
![](../Images/aa3becf7505faf64723ca93c9292e7b9.png)**使用浏览器查看http提供的服务  
**

![](../Images/f35338bfa60839bb4b0a970b951fc4af.png)

  

在网页源代码中发现了一个注释：bassam.ctf   
尝试访问该文件：

![](../Images/0df68e83afb189c240e99a6e1c374954.png)

发现没有找到该文件，说明这个注释并不是一个文件，除了文件之外，猜测可能是一个域名，将其添加到hosts文件中进行域名访问 ：

vim etc/hosts

![](../Images/bc807ba688985aa65511be82525602d7.png)

![](../Images/c0f248f35bf6c2f749b663e20b0bd66f.png)

发现一个简单的页面并没有提供什么功能服务，尝试进行子域名挖掘以及目录爆破：

子域名挖掘

gobuster vhost -w dic.txt -u http://bassam.ctf/ |grep "200"

![](../Images/09159ce5a04c64bd52fee252abb4039d.png)

  

找到了一个子域名：welcome.bassam.ctf

进行目录爆破

python3 dirsearch.py -u http://bassam.ctf  

![](../Images/d394350656a18f05972eb0941d64b44b.png)

  
只扫出来一个index.html，尝试访问：  

![](../Images/492a95ed923f9b6f4610fe33ff31b6ae.png)

  

并没有出现什么新的东西。  
  

![](../Images/aa3becf7505faf64723ca93c9292e7b9.png)**对子域名个进行探测，寻找更多有用的信息  
**

  

将刚刚找到的子域名添加到hosts文件中

![](../Images/495c3c164a833e928e2ebc49997d18f5.png)

  

使用浏览器就行访问

![](../Images/1699f884dc43ea3228c1d24c913730e5.png)

  

发现这里也有一个注释：open your eyes   
对该域名进行目录爆破

  

python3 dirsearch.py -u http://welcome.bassam.ctf

  

![](../Images/1707d0c3b8ae8a0708022641f8263c62.png)

  

爆破出来四个目录，逐个访问，看看网页中有没有什么线索

config.php

![](../Images/95f452bd1cba194555a942c56fd1c544.png)

index.html

![](../Images/9efb9f4691bd4c7697f30c303f2e98d8.png)

index.php

![](../Images/244cea82025b18e7291646c84864ad8e.png)

index.php/login  

![](../Images/776b05b4ff72dcb98d05ecd8c040995b.png)

  

在这几个目录中发现index.php提供了一个下载的功能，让提供一个url，猜测可能存在任意文件下载漏洞，在输入框中输入index.php

![](../Images/4765d75cc9b8d4701328289b9897ee78.png)

发现可以下载，将刚刚扫到的几个文件全部下载下来，看看里面有没有什么有用的信息

发现config.php中

![](../Images/f3aaaa2feacc6347f3d317a2f833dbd7.png)

  

发现这里存在用户名和密码，但是网页中没有找到登录框，但是服务器开放了ssh服务，尝试使用该用户名密码进行ssh登录：  
ssh test@10.131.1.145  

![](../Images/01cc33d42bef2956895524a97da9b1b7.png)

  
发现可以成功的登录，看看该用户能不能使用 sudo命令：  
sudo -l  

![](../Images/cd78219b800bd178523eb4b477abbc95.png)

发现不可以使用，但是说了kira用户可以使用，看看能不能找到该用户的登录密码，查看一下历史命令：  

![](../Images/6e88fad3b1aa521e1977199ffee580da.png)

发现该用户曾经执行的几条历史命令中查看了一个文件MySecretPassword   
经过对该用户能查看的目录进行查找，发现了几个有用的文件：  
/PassProgram/decoder;/PassProgram/encoder;/var/www/ctf/MySecretPassword  
通过查看文件类型  
file decoder  

![](../Images/8daba15d12b14770927289b2d53225b4.png)

  
发现前两个文件应该是加解密的可执行程序  
file /var/www/ctf/MySecretPassword  

![](../Images/316946c38d9b40ed4763a0b0f219a336.png)

发现MySecretPassword是一个ASCII类型的文件，可能是使用了上面的加密程序进行的加密，尝试使用解密程序进行解密：  
./decoder /var/www/ctf/MySecretPassword  

![](../Images/19c3457a4d42cff6343f62a03512baf3.png)

  
可以得到kira的密码尝试登陆  

![](../Images/02d053ef3b2b55c8b2fba42853e7f047.png)

成功的登录到该用户，执行sudo命令看看能否执行：  
sudo -l  

![](../Images/50978b79316dfdb4a4b859fcd0eac211.png)

发现可以执行，并且有提示，让尝试执行/home/kira/test.sh这个文件  
尝试执行  
./test.sh  

![](../Images/e017640af31fa45e26f503ab51412b7f.png)

发现报错了，看一下这个文件里面有什么  
cat test.sh  

![](../Images/dedb1f7ef796572975c75a57992a933e.png)

  
发现并没有什么，但是刚刚的提示中包括了bassam，尝试使用该用户执行test.sh  
sudo -u bassam ./test.sh bash  

![](../Images/43253262fbd95425ca7ecda7624a3444.png)

发现用该用户执行之后可以直接拿到bassam用户的权限  
查看bassam家目录中有什么  

![](../Images/795a4cb61a7c540d520298ab7c857f17.png)

发现里面有一个down.sh，查看里面的内容  

![](../Images/923445c137f0f073c6364e4c9c435b1b.png)

使用了curl命令访问访问http://mywebsite.test/script.sh并直接执行，通过修改hosts文件，让其访问我们的攻击机，并直接执行反弹shell  
修改hosts文件  

![](../Images/95e2c21ccd160c24873444aa8ac89fcd.png)

使用攻击机开启80端口并创建script.sh  

![](../Images/bbd18155f505a0ed8e326ff45320a695.png)

script.sh  

![](../Images/2a07013656aafeb0831a376a46f2e5ed.png)

监听本地7777端口，并回到ssh执行down.sh  

![](../Images/4d56865278dadab160836ae74ffca464.png)
