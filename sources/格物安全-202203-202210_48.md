## 基础知识

默认有16个数据库，默认使用第一个，`set+num`可以切换数据库

![](../Images/bda0020209b50182de3c3b464b943c43.png)

`dbsize`:数据库大小

`flushall`：清除所有数据库数据

`flushdb`:清除本数据库数据

`select + num`:选择操作哪个数据库

redis是基于单线程的，性能瓶颈是机器的内存和网络带宽，和cpu无关

**qps：每秒查询率（QPS，Queries-per-second）是对一个特定的查询服务器在规定时间内所处理流量多少的衡量标准。**

![](../Images/ae5196dca75d4324f4b35a912e6bdbb4.png)

上下文切换指的是内核（操作系统的核心）在CPU上对进程或者线程进行切换。上下文切换过程中的信息被保存在进程控制块（PCB-Process Control Block）中。PCB又被称作切换帧（SwitchFrame）。上下文切换的信息会一直被保存在CPU的内存中，直到被再次使用。

### String（字符串）

`append + key + string`:追加字符串，如果字符串不存在，就相当于set

![](../Images/de46628924c039a0d5ab4ad83f379d4b.png)

`STRLEN + KEY`:截取字符串长度

![](../Images/3a1253c28db9d049d1bd101fa589a405.png)

`incr + key`:自动加一

`decr + key`:自减一

```
127.0.0.1:6379> incr num
(integer) 1
127.0.0.1:6379> get num
"1"
127.0.0.1:6379> incr num
(integer) 2
127.0.0.1:6379> get num
"2"
```

`INCRBY + KEY + NUM`:设置步长

`GETRANGE + KEY + X1 X`:截取x1到x长度    0 -1：获取全部字符串

`SETRANGE + key + x`:替换某长度字符串

```
127.0.0.1:6379> set xx zxcvbnm,.
OK
127.0.0.1:6379> SETRANGE xx 2 44444
(integer) 9
127.0.0.1:6379> GET xx
"zx44444,."
```

`setex + key + time + value`：设置一个值，以及存活时间

`setnx`:不存在再设置（在分布式锁中常常使用）

```
mset:批量设置

(integer) 1

(integer) 0
```

## 事物

ACID：隔离性、持久性、原子性（要么同时成功、要么同时失败）、一致性

redis事物本质：一组命令的集合

一个事物中的所有命令都会被序列化，在事务执行的过程中，会按照顺序执行

**一次性、顺序性、排他性**

redis单条命令是保证原子性的，但是事物不保证原子性

redis事物没有隔离级别的概念

### redis事物

*   开启事务（multi）
    
*   命令入队
    
*   执行事物（exec）
    

```
127.0.0.1:6379> MULTI
OK
127.0.0.1:6379> set b 4
QUEUED
127.0.0.1:6379> get b
QUEUED
127.0.0.1:6379> set b 4rrr
QUEUED
127.0.0.1:6379> get b
QUEUED
127.0.0.1:6379> EXEC
1) OK
2) "4"
3) OK
4) "4rrr"
```

discard:放弃事物，一旦放弃，之前写的事物都不会再执行

```
127.0.0.1:6379> set a 1
QUEUED
127.0.0.1:6379> set aa 11
QUEUED
127.0.0.1:6379> set aaa 111
QUEUED
127.0.0.1:6379> set aaaa 1111
QUEUED
127.0.0.1:6379> MGET a aa aaa aaaa
QUEUED
127.0.0.1:6379> set aaaaa qqqqq
QUEUED
127.0.0.1:6379> DISCARD
OK
127.0.0.1:6379> mget aa aaa aaaa aaaaa
1) (nil)
2) (nil)
3) (nil)
4) (nil)
127.0.0.1:6379> EXEC
(error) ERR EXEC without MULTI
```

**编译信型异常，事物中的命令都不会执行**

**运行时异常，错误命令显示异常，正确命令正常执行**
