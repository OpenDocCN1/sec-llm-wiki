# 新型“舌尖病毒”瞄准“吃货”专“吃”手机流量

舌尖上的中国》第二季火热开播，让期待已久的“吃货”们再一次大饱眼福，也掀起了和《舌尖上的中国》相关ＡＰＰ下载热潮。提醒广大“吃货”，小心“舌尖病毒”借机占领手机，“吃”掉手机流量。

  

每周五《舌尖上的中国>》都会播出最新一集，在剧集更新的同时，木马病毒也随之涌现。日前拦截到一款最新伪装成“舌尖上的中国”ＡＰＰ的手机病毒━━“舌尖病毒”（Ａｄｗａｒｅ．Ａｎｄｒｏｉｄ．Ｔｇｐｕｓｈ．Ａ），该病毒捆绑了恶意广告插件，并进行强制联网，造成流量资费的大量损耗。

最新拦截到的病毒伪装成“舌尖上的中国”“舌尖上的中国鲁菜篇”“舌尖上的中国沪菜篇”，使用与软件本身属性不符的风险权限。另外，“舌尖上的中国”内含的恶意广告插件能够在后台无提示下载推广软件，造成用户流量损失。此外，“舌尖病毒”推送的广告堆积后还会造成手机卡顿，影响手机正常使用。“舌尖病毒”伪装成正常软件，提供美食和菜谱介绍，手机用户很难从表面上看出异常，隐蔽性很强。

手机安全专家提醒：如果用户下载《舌尖上的中国》相关App后发现手机莫名多出了许多软件，通知栏广告越来越多，流量迅速减少，很有可能是手机感染了“舌尖病毒”，建议尽量通过安全的应用市场下载App，防止个人隐私被窃取、流量被无辜消耗造成更大的损失。
