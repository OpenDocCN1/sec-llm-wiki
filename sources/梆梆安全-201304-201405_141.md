# 九大被严重低估的科技创业企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&appmsgid=10000382&itemidx=1&sign=9a87a2a7640effb5757ec6ab5835e9f9&scene=126&sessionid=1681369285#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&appmsgid=10000382&itemidx=1&sign=9a87a2a7640effb5757ec6ab5835e9f9&scene=126&sessionid=1681369285#wechat_redirect)

　　“人人都以为我们是一夜成名的公司，但实际上在此之前，我们经历了十年的苦熬。”在一次谈及皮克斯一夜成名的时候，乔布斯这样感慨苹果和皮克斯的成功。

  

　　最近几天，随着58同城、去哪儿网登陆纽交所，并且首日分别迎来了41.88%和89.33%的涨幅之后，中国垂直类汽车网站汽车之家也正式向SEC提交上市申请，计划赴纽交所融资1.2亿美元。如果计划成行，汽车之家估值将达到10亿美元，持股5.3%、年仅32岁的创始人李想个人财富将达到5300万美元。

  

　　10亿美元，是科技创业者的一个梦想，或者说情节。在科技媒体上，也常会出现“寻找下一个10亿美元公司”的说法(虽然苹果一年的纯利润就有370亿美元)。不久前，91助手以19亿美元的价格被百度收购;而另一家10亿美元级的大众点评网也出现收购传言。

  

　　本期盐科技试图寻找到目前在各自领域已经有一定建树，但尚未走入大众视野的十家被严重低估的创业公司，他们将成为下一个10亿美元量级的创业公司，而目前，他们的估值都远远低于他们未来应该有的市值——虽然我们已经无法投资他们，但至少可以引起我们的思考，创业者应该如何选择自己的道路，又该如何把握稍纵即逝的机会。

  

　　这些企业，有些盐科技的读者或许听说过，也有些可能通过盐科技才知道，这些都没关系，我们可以看看他们的成长经历，也可以看看他们未来的发展路径。无论成功还是失败，都会给我们最大的启示。

  

　　No.9【手游】乐动卓越

  

　　“现在的乐动卓越，行业老大腾讯都主动跟他们合作，估值起码超过10亿元，你投钱过去人家都不要。我们就是要找下一个乐动，创造一个传奇。”

  

　　手游行业一般都很难获得小盐的关注。因为游戏虽然是最赚钱的领域之一。触控科技CEO陈昊芝认为，2015年国内移动游戏市场规模将达到240亿元。

  

　　但这个领域通常也是“江山代有才人出，各领风骚一两年”。你肯定不大清楚“割绳子”的游戏开发方的第二款游戏是什么，也很少有人能准确说出“愤怒的小鸟”开发商的另外一款游戏。这是一个市场很大、但常青树很少的行业。选出一家游戏公司来说，确实有些冒险。但创业从来就是冒险的事，盐科技喜欢冒险，并希望能够越来越准确，成为冒险的行家。那么，就选乐动卓越吧。

  

　　该公司目前的成功也具有一定的偶然因素，《我叫MT》是一款最初研发仅6个月的卡牌游戏，目的是帮助已经减薪裁员的公司渡过难关。该游戏今年创下了手游最高游戏记录。考虑到其创始人是游戏界的元老，而且对于驾驭成功的技巧，我们相信，乐动卓越会有不错的未来。

  

　　No.8【金融】人人贷

  

　　P2P 借贷(Peer-to-Peer)，指的是有资金持有者通过网络信贷平台将资金贷给其他资金需求者的一种民间借贷方式。

  

　　在过去6年间，全国可统计的P2P平台已达到800家，但仅刚刚过去的10月份，全国已陆续有20家P2P平台倒闭或出现提现困难。

  

　　野蛮生长的行业也意味着洗牌和就会。在这期间，人人贷、人人聚财等P2P网站已然成势。据了解，人人贷今年网贷成交量将达到15亿元，每个客户的借款平均金额5万元人民币，只有一种还款方式——等额本息，只有网上提交材料一种申请方式，纯信用贷款无抵押担保，70-80%的贷款用途是小微企业个体商户的经营周转。该公司贷款人的平均融资成本在20%左右(年化)，今年上半年的平均投标利率(资金出借方的年化收益率)是13.09%。这中间的差额包括向贷款人收取的平均3%的服务费和0.3%的账户管理费等。该公司表示，服务费不列入公司收入，而是放入风险备用金中。截止6月末人人贷坏账率1.2%。

  

　　盐科技分析认为，互联网金融已经初具模样，但距离成熟尚早。在这样的野蛮生长中，能够成功也就意味着拿到了成熟期的入场券。如果人人贷的成交量在未来几年超过100亿元——这不是很难达成的目标，就意味着他们将会成为下一个10亿美元的企业。

  

　　No.7【工具】PP助手

  

　　就在盐科技写这篇稿子的时候，网络上已经有关UC以1亿美元洽购PP助手的流言，正在广泛传播。当你知道这家被隐藏公司的实力后，相信你会跟我一样，觉得这家公司是明显被低估的。

  

　　PP助手是一款同时支持iPhone、iPad、iTouch等iOS及android设备的软件、游戏、壁纸、铃声资源的下载安装和管理工具。在国内IOS市场做同类事情的产品也就5、6家左右。

  

　　PP助手的最主要的功能，就是将App Store上的软件破解后提供给越狱的苹果用户。而现在他们已经做到，将自己的应用商店直接建在苹果产品上面，基本上苹果每推出新版操作系统一周左右，他们就能可以做到上述功能。

  

　　由于其产品推出的时间不仅快，而且在用户体验上可谓极致，PP助手在国内iOS市场拥有极为强劲的应用分发能力，唯一能与其竞争的就只有91助手。

  

　　此外，在今年8月PP助手刚推出了安卓版，市场反响依旧强烈。尽管安卓应用市场这样的产品已多达上百家，但是由于绝对垄断的产品依旧没有产生，纷争割据非常激烈，因为谁都有可能崛起，PP助手势必能在此分得一杯羹。

  

　　该公司现金流应该十分充裕，据说目前每月收入早已突破千万元。同时，因为应用分发渠道对抢占移动互联网入口的重要性越来越被重视，以及91助手被百度以19亿美元收购，相信pp助手的价格势必还将因此而提升。

  

　　No.6【开发工具】Share SDK

  

　　顾名思义，这是一个SDK包，是为开发者服务的。开发者如果不愿意劳神费力的亲自去开发应用里的分享模块，就可以免费使用shareSDK来实现，为开发者省下了时间人力成本。

  

　　ShareSDK应该是目前国内最强大的APP分享工具，集成 ShareSDK 的 app用户可以用各种社交账号登录、分享。尽管友盟等也做类似的事情，但操作起来并不方便，而可以分享的社交平台也很有限，只能包括国内几个大型社交平台，而ShareSDK 不仅几乎涵盖国内所有社交平台，更是将facebook、Twitter等国外主流社交平台涵盖在内。

  

　　不仅如此，该产品还有强大的统计分析管理后台，可以实时了解用户、信息流、回流率、传播效应等数据，有效的指导日常运营与推广，同时为APP引入更多的社会化流量。

  

　　作为国内目前最大的APP内分享服务提供商，该产品已经拥有14471个APP用户，预计年末将达到3万个。若加上这些app涵盖的使用者外，他们的间接用户将会更多。shareSDK的大数据业务会是非常有想象力的一个环节，也会是他们主要的商业模式出发点。

  

　　目前其同类产品友盟已被阿里收购，相传价格为8000万美元。

  

　　No.5【服务】加速宝

  

　　如果你开了家餐厅，但餐厅的门不好，消费者怎么推也推不进来，结果会怎样?即便你的大厨做得菜有多么美味，你也必死无疑!那么，如果我们把餐厅换成APP呢?再牛叉的APP，用户怎么都点不进去，结果又会如何呢?同理!

  

　　根据Compuware的统计数据，多数移动用户可等待网站或应用的最长加载时间是5秒，有74%用户表示如果移动网站无法在5秒内加载完毕他们就会退出，若应用无法在5秒内加载完毕则有50%用户会离开。

  

　　很多开发者在产品端的能力很强，但是服务器端却很弱。加速宝是做什么的?就是帮开发者做产品访问加速，提高移动APP的联网速度。加上另一款可以压缩手机上网流量的移动APP——“飞速流量压缩仪”，目前该公司的两款产品用户量已超过550万。

  

　　该公司的创始人给未来设想了许多种可能的商业模式(主要是B2B2C)：比如提供大数据，将用户数据提供给合作伙伴挖掘从中抽成;或者购买运营商流量，吸引用户，再与游戏联运合作，提供免费下载和使用的流量，变成游戏分发渠道。这些都为改公司的未来提供了充分的想象空间。更为重要的人，目前在这个领域，它还没有真正的竞争对手。

  

　　No.4【移动游戏平台】触控科技

  

　　触控科技很可能已经接近10亿美元这个数量级。10月19日，触控科技再次获得了5000万美元D轮融资，此轮融资由中国私募股权基金新天域资本 (New Horizon Capital) 领投，北极光、迪士尼思伟创投、红杉创投以及纪源资本(GGV)等跟投。

  

　　此次融资之后，将使其融资金额超过8200万美元。

  

　　移动游戏平台的打造离不开其产品的运营能力。在产品研发方面，触控科技拥有《捕鱼达人》休闲游戏系列产品，该产品在中国拥有2亿激活用户。

  

　　另一方面，触控科技投资并支持的2D 游戏引擎 Cocos2D-X在中国拥有70%的开发者认可和使用比例，在全球199个国家地区有40万开发者使用。

  

　　此外，在中国市场，迪士尼、NEXON、Gameloft、育碧、KONAMI、Gamevil等众多一线厂商的产品的代理商。触控科技并不总站在最前沿，但在助力创业企业成长的过程中，触控科技也将水涨船高。

  

　　No.3【安全】梆梆

  

　　毋庸置疑的是，移动安全(盐科技称之为云安全)是未来移动设备的核心入口。原因有二：一是它提供的云安全保护将会是一个生态系统，只有完整的能够实现从云到端不间断保护的云安全厂商才有机会;二是由于提供了生态系统的保护，云安全同时等于也对设备持有人的信用进行了保护。

  

　　换言之，云安全等于保护了设备持有人，进而为用户提供信用服务。这将是下一波智能信息时代的核心。没有了安全和个人信用体系(该信用体系将和手机、安全捆绑在一起，而只有云安全的彻底保护，这一点才能实现)，下一代智能网络就无法实现。

  

　　从这一点来看，云安全就是下一个时代的船票。目前的信息安全公司，大都还没有认识到这一点。因此，目前的争夺，还在争夺在手机内的一个APP的位置。这样的争夺，在盐科技看来，是低效而无益的。搭建自己的生态系统，彻底保护用户的云安全，进而保护好用户的信用，就等于拥有了用户的信用。

  

　　在这个方面，梆梆有未雨绸缪的迹象。虽然他们的口号还是“保护你的app”，但从有限的信息来看，他们还是希望通过这个切口，进而保护手机，进而保护云中安全。保护app，是从app开始就进行安全加固。

  

　　梆梆要在今年年底完成3万个APP的加固，这些APP在移动设备上的总安装量将达到几亿台。这些隐形的服务，现在还无法发挥价值，但如果能够形成云安全的生态系统，那么其价值将不可小觑。这样的一个安全公司在腾讯、360等安全大佬的环伺下并不引人注目，但他们的思路与盐科技对移动安全的定义颇有相似之处，因此，盐科技看好梆梆脱颖而出的能力。此前，据传他们融资超过1500万美元，他们也有能力快速布局，实现他们的构想。因此，盐科技认为，作为云安全生态系统的必然一环，梆梆有可能成长为下一个10亿美元级的企业。

  

　　No.2【O2O】大众点评网

  

　　和美团相比，小盐更看好大众点评。

  

　　这是因为大众点评更“在你身边”。由于对你身边数据的掌握，以及优惠信息的即时提供，这家号称已经估值10亿美元的企业，仍旧有向上生长的空间。因此，小盐将之列为被低估的创业企业——尽管10年时间，点评网已经不可同日而语了。

  

　　大众点评是一家慢公司。和豆瓣一样，他们发展缓慢但是也相对比较踏实。

  

　　但对于大众点评而言，问题也不是没有。一来，他们进军团购有些快速，而忽略了其核心“点评”功能。如果这个核心被忽略了，被其他应用突袭，不是不可能的;二则，点评的质量和互动性欠缺。我就曾经为了店家的一盘菜的诱惑，给该店一个好评。因此，盐科技认为，大众点评的估值仍旧是被低估的，但其未来的潜力是否能够夯实，还有待于上述两个问题的解决。

  

　　No.1【物流】顺丰快递

  

　　什么?选择了一家快递公司?!

  

　　是的，小盐君很严肃的说。

  

　　顺丰快递一贯低调，不融资不上市。早在2010年，顺丰的销售额已有130亿元，仅次于中国邮政，占全国18%市场份额;2012年，其年营业收入达到200多亿。据业内传说，顺丰在多个一线城市核心区有整层整层的写字楼，都是王卫真金白银买了产权的，与其它网络空壳快递公司相比，顺丰凭物业升值的收益已相当可观。

  

　　但今年秋天，它打破惯例，以不超过25%的股份，招来了元禾控股、招商局、中信资本及古玉资本等多个国资背景的“小伙伴”。据说，其估值超过了400亿元，融资超过90亿元。

  

　　但是，在小盐看来，这个估值还是被低估了。

  

　　首先，2011年，淘宝一年的快递数量是30亿单;而根据顺丰的200多亿营业额，我们粗略估计其一年的订单超过10亿。

  

　　其次，顺丰有完备的网络。目前，顺丰旗下拥有30架全货机;5000多个营业网点;150余个一二级中转场和1万多台营运车辆，是仅次于国家队EMS的中国最大民营快递公司。

  

　　再次，顺丰快递员除固定的红黑工装、大背包、自行车外，几乎人手一部“巴枪”——— 这个由顺丰和一家供应商共同研制的产品外观像PDA，可直接与顺丰4008呼叫中心对接，帮助完成快件的现场跟踪。这样一来，电脑里的查询系统就能够跟踪快件的所有去向。

  

　　其实这些，以及未来快递业的高发展都不能算做低估了顺丰快递。小盐认为，顺丰快速最大的优势在于：它通过每年10亿单的快递，长达20年的数据积累，已经获得了数亿用户的大数据系统，这些数据的价值若得到开发，对于其公司的升值应该以千亿计算!

  

　　而这，只取决于对这些数据的加工处理。如果数据处理得当，再对订单和物流进行统筹，窃以为其被低估的程度会更加超出想象。从这个角度来看，顺丰早已经不是一家简单的物流公司，它已经成为一家科技公司，而且其大数据一旦被开发，将会发挥巨大的作用。它唯一需要的，就是如何利用好这个线下平台，完成线上的优化使用。但无论它是否完成，它被低估的价值都远远高于其目前的估值。

  

　　在筹划这个专题之前，盐科技非常希望做成10大严重被低估的创业企业。但最后，还是只做了9个。原因有二：一是社交领域空缺。移动社交应该诞生出非常优秀的创业公司，这一点虚位以待。第二点，也是小盐君的私心：说不定这样空缺几年，盐科技自己也可以挑战一下这个空位呢?

  

　　当然，这个路途太遥远了。各位盐铁君(盐科技的铁哥们儿们)看看一笑即可。不过，小盐君倒真的希望，有一天，从盐科技报道的对象，或者我们的读者中，诞生下一个10亿美元的创业企业。那时候，盐科技一定做一篇优秀的报道，为你们喝彩。

  

　　其实，每一个创业者，只要在路上，就是赢家。

  

　　所以，一起加油。
