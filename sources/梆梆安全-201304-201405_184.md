# 手机病毒伪装红娘相亲 诱骗单身少男少女

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&appmsgid=10000268&itemidx=1&sign=41dc9bf81b3df704c9cfe88f09a512fd&scene=126&sessionid=1681369306#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&appmsgid=10000268&itemidx=1&sign=41dc9bf81b3df704c9cfe88f09a512fd&scene=126&sessionid=1681369306#wechat_redirect)

        安卓手机病毒层出不穷，借助热门手机应用传播更是惯用伎俩。近日，再次截获一款名为a.fraud.fksoftupdate的安卓手机病毒，该病毒感染了包括6款红娘相亲类应用以及德州扑克、将爆三国、召唤世界、时尚美眉、老虎爆点、汽车报价查询、手机电视播放器等在内的700多款应用。

  

        病毒特征：

  

        该恶意病毒运行后，偷偷访问指定网址下载第三方应用安装文件，优先打开伪装的应用程序新版更新提醒界面，进一步诱导用户升级安装，耗费用户流量资费甚至是连环中毒。由于该病毒感染手机应用的数量范围非常广泛，因此危害性极大，用户要特别小心。

        特征一：伪装性。该病毒会预置在红娘相亲、德州扑克等700多款被二次篡改的手机应用中，通过各种热门游戏应用的伪装，欺骗用户下载安装。

  

        特征二：流氓性。一旦这些感染了病毒的应用被安装激活，手机病毒会以应用有更新为理由提醒用户下载更新，而这些更新其实是其他手机应用，此恶意推广行为十分流氓。

  

        特征三：恶意传播。由于该病毒感染的手机应用众多，这些应用被散布在各大手机论坛供用户下载，目前正在疯狂传播，用户可谓是防不胜防。

        专家支招：

  

        由于安卓类手机应用大多以免费提供，加之系统的开放性，导致手机应用开发者绝大多数都没有盈利，因此涉足病毒赚黑心钱成为他们的主要收入途径。很多病毒作者、应用开发者纷纷通过将恶意推广代码植入手机应用，从而赚取推广费。这种恶意行为会在安卓手机上愈演愈烈。

  

        对此，安全专家建议用户不要轻易在手机论坛、不安全电子市场下载应用和游戏，最好去官方网站下载。
