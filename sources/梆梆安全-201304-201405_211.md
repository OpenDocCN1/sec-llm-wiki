# 梆梆：绕开金山们 专注APP安保

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&appmsgid=10000173&itemidx=1&sign=b72e63e087124cd78ef694bf68988670&scene=126&sessionid=1681369316#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&appmsgid=10000173&itemidx=1&sign=b72e63e087124cd78ef694bf68988670&scene=126&sessionid=1681369316#wechat_redirect)

　　电影《中国合伙人》中王阳说了这么一句话：“不要和最好的朋友合伙开公司。”看完电影后，梆梆副总裁赵宇发了一条微博：“我一直都是和最好的朋友合伙开公司，没问题。”他说的这位“最好的朋友”便是梆梆的C E O阚志刚。这一伙人趁着互联网巨头抢夺用户正火热之时，悄悄绕开了“巨头们”，瞄准了移动A P P安全保护的空白市场，专为安卓应用开发者提供移动A P P安全保护服务，这一定位让梆梆获得了红点领投、ID G跟投的千万美元级别B轮融资。梆梆的目标很明确，就是为安卓开发者降低应用盗版率，保护应用安全。再加之较为清晰的“B 2D”盈利模式，梆梆合伙人认定，经历了困惑和新生的循环往复后，这次，这条路走对了。

　　这片市场竟然是空白

　　阚志刚是典型的“技术男”，北京航空航天大学计算机专业博士毕业后，在诺基亚研发中心和赛门铁克研发中心都从事过与“移动安全”相关的工作。但“出身名门”的他心中一直都在酝酿着创业的想法，2010年阚志刚迈出了创业的第一步，组建了现在的梆梆团队。

　　第一年，梆梆的服务主要包括两个方面，第一是保护用户的移动安全，第二是为企业提供B2B服务。但当辛辛苦苦做了上百万的用户后，却发现为用户提供安全保护却难以直接收费，盈利模式非常模糊，同时面对的竞争对手都是360、腾讯等大公司，这无异于以卵击石。而B 2B的模式让阚志刚觉得，虽然现金流有所提升，但根据企业要求为其提供定制式服务并非一个创业公司应该走的路。

　　阚志刚不得不艰难地做出调整。此时，移动互联网领域出现的打包党越来越多，他们把开发者的A PP当成赚钱载体，不劳而获，同时还出现了恶意扣费、隐私窃取、银行账号盗用等问题。越来越多的A PP开发者寻求保护。

　　这样的环境下，梆梆团队开始由B2B转向B 2D (D evelopers)的模式，准备专为安卓开发者提供移动A P P安全保护服务。梆梆团队惊喜地发现，目前国内几乎没有针对开发者提供应用保护的公司，这让他们看到巨大的潜力。曾在大公司供职多年的阚志刚向南都记者分析：“往往在大的公司，因为其体制、机制局限很难在一些垂直的细分行业做出成绩。而小公司因为财力与技术的限制也很难搞定，所以目前只有梆梆这种几十人的技术团队是最有机会来做这一细分、垂直的领域。”

　　阚志刚认为，这次方向选对了，那接下来的路又该怎么走？

　　一群“匠工”看准B 2D

　　自称为“匠工”的阚志刚认为，没有过硬的技术在这条路上不可能行得通，“必须在技术上狠下工夫”。首先从人员配备开始，目前梆梆团队有50人左右规模，其中有70%的技术人员，大多都曾在赛门铁克、诺基亚供职。有了技术团队，就要着手打造领先性的产品。可技术上的优势永远都是相对的，难道不怕有“后来者居上”的情况发生？产品永远不会被破解？

　　阚志刚告诉南都记者：“梆梆已经抢先在技术方面发力，而且从产品形态到服务都在不断更新进步。同时，梆梆正在尝试从普遍性技术到一些具体的行业，为行业提供一些专业的解决方案。”同时，为防破解，梆梆还设计了三套方案，提供三重保护。即使一套方案被破解，还有其他两套方案进行防护。

　　除了技术过硬，服务也是梆梆的另外一张王牌。

　　目前梆梆的主要业务包括对应用的加固保护和渠道监测。在对应用加固保护的业务上，开发者只需要在梆梆的网站上提供A PK(A ndroidPackage安卓安装包)，不需要额外的SD K (Softw are D evelopm ent K it软件开发工具包)配合就可达到加固目的。加固保护后的应用，就可以防止A PP被篡改，防止A PP反编译、被动态注入、A PP数据被窃取等常见的盗版现象。同时先后推出了网页版、PC客户端及“黑盒子”硬件的产品形态来加固保护A PP。

　　梆梆的商业模式选择了B 2D，即向以开发者为服务对象，比如对V IP客户提供SaaS(软件运营服务模式)的服务，同时为中小企业开发者提供按次收费的A PP加固服务。目前，基本属于免费提供保护的状态，阚志刚透露今年第四季度或将根据客户的级别和服务进行收费。

　　梆梆C M O李建华告诉南都记者：“收费对象主要有四类：一是移动金融应用，二是一些电商企业，三是大型游戏的开发者，四是中小企业开发者。”例如V IP客户所获得的服务将更全面且差异化，收费以年费为主，而免费客户就只能获得基础保护服务。

　　年中目标尚未完成十分一

　　南都记者了解到，目前梆梆服务的开发者数量刚超过1000家，加固的A P P数量接近4000个，包括了墨迹天气、神庙逃亡2、致命空袭、天天动听等。但梆梆希望今年年底能将开发者数量提升到10 0 0 0家，加固的A PP超过30000个。而眼下已进6月底，还未完成目标的十分之一。对此，阚志刚却没有太多的担心。他说：“这并不是一个匀速增加的过程。一般来说，前期的推广相对较难，现在会较多地跟渠道商、代理商合作，同时今年8月还将积极争取海外市场，预计未来会成倍增长。”

　　南都记者了解到，随着手游市场的指数型增长，目前在受保护的A P P中一半以上是手游，这是梆梆最看好的重要客户之一。除此以外，移动金融应用对“破解”的持零容忍态度，让阚志刚看到了这一行业的巨大市场，他希望能尽快进入这一领域，阚志刚坦言：“比起手游市场，难度大了很多，但早点下手可能还有希望。” 采写：浩子
