# 58%开发者选为移动设备做游戏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&appmsgid=10000088&itemidx=1&scene=126&sessionid=1681369331#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&appmsgid=10000088&itemidx=1&scene=126&sessionid=1681369331#wechat_redirect)

　　据国外媒体报道，游戏开发者越来越多地选择为移动设备，而非游戏机开发游戏。在最近的游戏开发者大会上进行的一项调查显示，58%的开发者计划为移动设备开发新游戏，38%的受访者称上一款游戏针对移动设备。

  
　　逾50%的受访者自称是独立开发者，这意味着他们可能偏爱移动设备，因为移动游戏的开发成本远低于游戏机游戏。

  
　　在图像质量和身临其境的感觉方面，短期内移动游戏不会超过桌面游戏和游戏机游戏。但游戏掌机受到了日趋复杂的iOS和Android游戏的直接威胁，对开发者的吸引力越来越低。  

　　移动游戏是应用商店时代的主要受益者。有资料显示，在苹果iOS App Store应用商店中下载量最大的200款应用中，70%是游戏；Google Play的这一比例为75%。  

　　在开发移动游戏的开发者中，90%为iOS开发游戏，75%为Android开发游戏，15%为Windows Phone开发游戏。
