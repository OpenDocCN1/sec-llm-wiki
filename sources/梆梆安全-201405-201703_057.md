# 梆梆安全阚志刚：创业是一个过程，过程比结果更重要

创业，似乎是时下最热门的词语之一。谈到创业，脑海里总会不断浮现出创新、突破、坚韧、果断这些关键词。无数的创业企业如雨后春笋般拔地而出，后又因资金、技术等各种难题批批倒下。资本寒冬令新兴的创业公司动荡不已，但与其他创业公司相比，梆梆安全却如同一缕清风“波澜不惊、静若止水”。对于创业、产品、市场，梆梆安全都有着深刻体会。而作为全球安全服务领跑者，梆梆安全对于中国安全市场的未来又有哪些独到见解？对此，我们有幸与梆梆安全董事长兼首席执行官阚志刚博士进行了深入交流。

  

  

  

![](../Images/59eb8721939ac26dfe86a7e665477871.png)  
  
  

**新一代的安全公司**

传不科技对话梆梆安全阚志刚

  

  

**Q**

您好，阚总，今天非常高兴能够有机会跟您近距离接触。对于梆梆安全，我们的了解可能仅限于移动安全服务厂商，并已经完成了4轮融资。对于您以及梆梆安全成功的企业模式我们都非常好奇，首先可以先聊聊您在创建公司之前的一些经历吗？

  

**阚志刚博士**：感谢您的夸奖。其实我创业之前的经历非常简单。2001年从北京航空航天大学计算机科学专业博士毕业后，就加入到诺基亚研发中心工作。2005年又进入赛门铁克并专注移动安全工作了5年，**2010年10月创立了梆梆安全**。

  

**Q**

梆梆安全在创始之初的理念是什么呢？

  

**阚志刚博士**：梆梆安全创立之初，我们希望它成为“全球安全服务领跑者”——一家诚信、受人尊敬的互联网公司。我们认为一家创业公司只有找到差异化，才能生存、发展、壮大。所以在创业之初，我们便非常注重公司在技术、模式、销售、组织等多方面的创新。在技术方面，梆梆安全开创了移动应用安全的先河，成为**世界首家提供移动应用安全保护的高科技公司**；在商业模式方面，则采用SaaS模式为客户提供安全服务，所以，梆梆安全也被称为“新一代的安全公司”。

  

**Q**

您对企业品牌的理解是什么？您在最开始运营的时候又是如何定义品牌的?

****阚志刚博士****：我认为品牌是企业最重要的资产，是企业文化的具体表现，是企业实现百年文化传承的基石。我们处在一个极具变革的时代，技术、市场环境、客户、员工都在不断变化。唯有塑造强有力的企业品牌，才能使公司立于行业不败之地。

  

从运营之初，我们便一直在讨论如何将梆梆安全打造成为像IBM、Intel、诺基亚、可口可乐那样的伟大品牌，让用户肃然起敬并强烈信任。

  

我们把培养一个企业品牌当作提高个人修养一样来实现。**首先，需要有正确的价值观。**其实，企业和人一样，有的人有修养，受到人们和社会的尊敬和认可；有的人却让人厌恶和唾弃，这些都是因为拥有不同的价值观。梆梆安全的价值观是“诚信、简单、包容、善良”，即对公司要忠诚，对客户、伙伴、同事要真诚，秉承简单的同事关系，包容他人、包容自己，善良地对待每件事情。把这些价值观融入到每位员工的血液中，企业品牌也就“立”起来了。

**其次，就是需要有判断事情的准则。**对于安全企业更是如此，不能一味地只向“钱”看，更应该看看这件事对于用户、对于社会是否拥有深刻的意义。如果企业做的事情敢于给自己的孩子说，小朋友很骄傲并自豪地分享给同学们，这种事情我们就可以干。

**第三，就是理想和愿景。**创业公司必须要有远大的理想、愿景和信仰，否则就会束缚企业的发展和格局。企业在追求利润的同时，还应有更加美好的愿景，这将永远指引着企业向前进。所以梆梆安全在创立之初，便立志成为“全球安全服务领跑者”。当然这个愿景是逐步完善的过程，不能一蹴而就。

  

![](../Images/fabd021921f791cc0d1be8018c676ee4.png)  

  

**Q**

梆梆安全在运营过程中经历了哪些比较重大的改变？

****阚志刚博士****：企业就像自己的孩子，每天都在不断改变、成长。有时改变是悄无声息的，只有当你回头看时，才能发现他的惊人巨变！

  

对于我和梆梆安全来说，**最大的改变应该是心路历程**。经历的事情多了，心变得越来越强大，团队也越来越成熟！在梆梆安全创立的前三年，我们将精力主要集中在产品、技术和服务。在2014-2016年，我们则重点优化销售、品牌、企业文化，让公司每年都能上一个台阶。企业发展不能强求，应该顺其自然、尊重客观发展规律，有些事情就是在一点一滴的积累中自然发生的。

  

我们的发展相对比较保守，不会轻易地发生改变。我们只有在新一轮融资到位的情况下，才会发生改变，否则任何改变都是草率的。截止2016年初，我们总共拿到了**四轮投资**，每一轮投资都会发生一次改变，当然这种改变不是革命，而是演进！比如拿到第四轮融资后，我们才决定进入物联网安全领域。运营公司就像打仗，两国交战，最后决定胜利的都源于丰富的经济基础。

  

**Q**

您之前在很多大公司担任要职，您觉得创业型公司跟大公司最大的不同是什么呢？

  

******阚志刚博士******：博士毕业后我在跨国公司工作过10年。这10年对我个人成长起到了很大的作用，期间我经常到国外总部工作和学习，让我深刻体会到大公司的优点和缺点，学习到了人家是如何工作、思考、研发、做市场的。我一直在思考，为什么他们可以成为世界级的跨国公司？除了品牌间的差异，最大的差异就是企业的“正规化和专业化”。所以今年我们将精力主要集中在“三化”建设上，即**正规化**、**专业化**和**国际化**，重点围绕“八字方针”来开展日常工作，即“**目标**、**流程**、**计划**、**培训**”，争取做到目标清晰，流程简洁，计划缜密，培训到位。

  

**Q**

我们再来谈一谈企业人才的问题，您觉得在创业过程中，合格的人才应该具备哪些特质呢？

******阚志刚博士******：一个公司只想通过招人来成功，是不可能的。应该发挥不同人员的优势，培养他们为了实现目标而百折不挠的特质。

  

当然企业在发展的每个阶段对于人才都有不同的需求。在创立之初，人才是求不来的，不是需要什么样的人就能招来什么样的人。记得梆梆安全刚成立的时候，连本科生都招不到。所以，我们更加注重发挥现有人员的优势，让每个人都成为工作中的人才，把每个人的价值发挥到最大。**我们的理念是，相信并发挥每位员工的价值，要200%地相信我们的员工！**

![](../Images/bab689db475f3909cfbda63360b421bd.png)  

  

  

**Q**

未来梆梆安全会涉足资本市场吗？

  

******阚志刚博士******：对于现代企业，必须学会灵活、有效地借助资本的力量，发展、壮大自身，所以**未来我们肯定会涉足资本市场**。企业涉足资本市场共分三个阶段：第一阶段是获得风险投资，助力企业成长。第二阶段是上市重组，助力公司壮大；第三阶段是通过并购投资，助力公司腾飞。

  

**Q**

除了创立梆梆安全，我们看到阚总您的个人成就也非常高！那么，您觉得在创业过程中，您自己最大的收获和体验是什么？

  

********阚志刚博士********：谢谢您的夸奖。其实我自己真没什么成就，只多读了几年书而已。我非常相信知识可以改变命运，所以在公司，我也非常鼓励大家学习、多读书。读书可以使人淡定，可以使人变得坚强。

  

我认为，一个人在40岁之前必须找到一个事情值得你用后半辈子去全身心投入，甚至付出生命，这样的人生才会幸福和精彩！我很幸运，在40岁时找到了喜欢做的事情，这也许就是“四十不惑”的道理吧！

  

大家都称我“大叔创业”，其实我认为创业什么时间开始都不晚，哪怕是70岁。因为创业是一种人生态度和追求。**创业是一个过程，但这个过程比结果更重要**。创业的成功与否完全取决于自己的看法，而非有个标准，就像幸福一样，与自己的体验有关，完全由自己来决定。

  

创业之后，我的生活改变了很多，虽然几乎没有时间陪家人，自己的身体也在经受着劳累地侵蚀，但我并不后悔。创业六年时间中的人生积淀，比前四十年的人生积淀还要多。有人追求的是人生的长度，或许创业追求的就是人生的厚度吧！
