2017 Mobile App Security International Market Growth Predictions

_Jayson Li, VP of International Business

 

Hybrid app security tools will become standard request in 2017


Standard mobile Hybrid app security tools combine Static Application Security Testing (SAST), Dynamic Application Security Testing (DAST) ，and App shielding (wrapping) to effectively against attack.

App shielding technology is based on binary code level encryption and source code obfuscation.  There are a few vendors in the market include Arxan, SecNeo, Whitecryption.   However, not all players can provide full products include Interactive Application Security Testing（IAST）service. 

A key technology in this new hybrid approach to application security will be RASP — Runtime Application Self-Protection. RASP was created to protect App under attack in real time, but, when combined with dynamic testing, it has proven to be useful in helping developers prioritize vulnerability findings. That not only reduces the risk of an app making it to market with a major security defect but it accelerates the time it takes to put a secure app in a user’s hands.

The growth, maturation and adoption of RASP, along with the creation of platforms that combine SAST and DAST into unified hybrid testing solutions will contribute to the explosive growth of the app security market in the coming years — from $2.24 billion in 2016 to $6.77 billion in 2021, according to one estimate.

The General Data Protection Regulation (GDPR) was signed into law in May 2016, leaving a scant fifteen months for businesses to evaluate their security gaps and fix them in time to be compliant and avoid some extremely hefty fines.  Thousands of multinational companies, include USA, China, are waking up to comply before May 25, 2017.

The storm clouds are gathering. Read on so you can prepare sufficiently and come out the other side stronger — and more trusted by your customers — than ever.

Cyber insurance is coming to a requirement in USA and EU market.  In China, a mobile App security company called Bangcle already purchased security product insurance to protect business and clients from cybercrime in 2015.

In that regard, hybrid security testing can be useful, too, because it identifies the really important vulnerabilities and doesn’t waste a developer’s time with minor problems or problems that aren’t problems at all, a/k/a false negatives.

As Hybrid app security tools takes hold in the coming year, expect its development to go hand in hand with increased automation which is critical to solve onerous and time-consuming problem.
