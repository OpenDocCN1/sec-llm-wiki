# 第五次网络变革，你准备好了吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651091049&idx=1&sn=d4e94b541e3c5b7a5a7596226a55c0fe&chksm=bd2eaf7a8a59266c1c9984f4a9318c379b22c2dafffb258fcc98be1264d908eacc4f69736f69&scene=126&sessionid=1681369124#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651091049&idx=1&sn=d4e94b541e3c5b7a5a7596226a55c0fe&chksm=bd2eaf7a8a59266c1c9984f4a9318c379b22c2dafffb258fcc98be1264d908eacc4f69736f69&scene=126&sessionid=1681369124#rd)

**区块链技术**是继因特网、互联网、云计算、移动/物联网之后的**第五次网络变革**，它使得参与方在一种新的可信和安全网络进行透明传输并对数据访问进行审计和认证，将信息互联网变成价值互联网。

  
![](../Images/e99be4ea3596a48615c022a169099604.png)  

**网络技术革命**

区块链是**比特币**的底层核心技术，是一种**难以篡改、可追溯的分布式账本**，提供了各种各样的资产追踪可能，包括所有权，身份断言和证明，加密密钥，或设备属性。分布式账本依次分成块，每块链接上块，使用加密的信任和保证机制在一个对等网络中相互记录，这种记录的方式不是由中心化的机构所控制，而是由社区共同控制，在不可信环境中增加信任的机制，解决效率低下和社会结构的信任问题；区块链中的记录不可更改，重要数据和事件如货币交易、财产登记或其它有价资产应用区块链技术后还具有透明、数据完整等特点，从而减少人为的干预，缩短交易时间和业务流程。

**区块链作为Gartner 预测的2017年10大技术趋势之一**，将创造许多新的价值创造途径，开启新的商业模式，各行各业大大小小组织、机构以前所未有的热情投入到了区块链技术的创新大潮之中，大到全球大型银行（如**中国工商银行、德意志银行**）、跨国集团（如**跨国保险集团MetLife**），小到中小企业机构投资者、市级政府部门。

# **金融市场“拥抱”区块链技术**

信任和对履行义务承诺的信任是任何金融交易的基石。金融市场的实质是通过风险管理基础设施来解决金融交易中的信任和不对称问题。区块链技术的特点及应用将为金融市场带来显著的近期效益：**不仅能使清算和结算速度加快，还能减少金融机构需要维护的账目数量，确保审计跟踪更加精确。**

传统的证券交易，需要经过中央结算机构、银行、证券公司和交易所这四大机构的协调工作，才能完成证券的交易，效率低、成本高，且这样的模式造就了强势中介，金融消费者的权利往往得不到保障，而区块链系统就可以独立地完成一条龙式服务。    

全球大型银行都在以各种方式积极介入区块链技术应用创新，包括组建各种区块链联盟，其中最为著名的**R3联盟**集结了包括**美国银行、花旗、汇丰、瑞士信贷银行**等国外银行以及**国内招商银行、平安银行**等在内的**全球40多家重要银行**，共同致力于金融领域区块链的开发应用及制定**全球清算一体化行业标准**。

国内31家企业组建了金融区块链联盟（简称“**金链盟**”），联盟成员单位70%是金融机构，其余是金融科技企业和互联网企业，这种成员结构将使得应用更快落地。

随着区块链技术的兴起，各国央行正在积极探索研究法定的数字货币，英国、加拿大等多国央行都表示将涉足该领域，并提出了自己方案。本月，日本央行将与欧洲央行启动一个联合项目，研究能够作为市场基础的数字货币支持技术——分布式账本技术的潜在应用。

年初，中国央行召开数字货币研讨会，进一步明确央行发行数字货币的战略目标，并表示争取早日推出央行发行的数字货币。最近，央行相关人士表示，央行发行法定数字货币的原型方案已完成两轮修订，未来有望在**票据市场**等相对封闭的应用场景**先行先试**。

非金融市场区块链技术研究如火如荼

  

区块链账本的可追溯性、高可靠和不可篡改性有利于审计工作的开展，可解决物品的溯源防伪问题，可广泛应用于供应链管理、文化娱乐、智能制造、社会公益等非金融行业。在这些行业的应用，将优化其业务流程、降低运营成本、提升协同效率，进而为经济社会转型升级提供系统化的支撑及积极的推动作用。

在供应链管理上，可以利用区块链技术解决供应链中的**假货问题**，打击供应链上的假货，重构供应链体系。从生产开始，就把商品信息制成二维码或芯片，印刷在包装盒上或装在商品里，所有商品都有唯一的身份，并且它的公私钥也是唯一的，再将信息登记在区块链平台上，让每个运输环节都有相关负责方。藉此利用每个商品的唯一标识，就可以知道商品是谁生产的，谁提供的原材料，经过了哪些环节，在整个供应链当中的过程都是可以被追溯的，如果出现假货，商家可以在区块链上查到商品的来处与去处。**利用区块链技术形成的“透明供应链”能自证清白，让消费者、分销商相信你。**

# **梆梆安全全面布局、探索区块链技术**

**作为最早为支持比特币形成和流通而推出的一项技术，区块链如今已被视为下一代价值互联网的基本协议之一**。然而，今年发生的以太坊DAO智能合约安全漏洞攻击事件，以及最近风险投资公司Fenbushi Capital（分布式资本）的创始人沈波价值约三十万美金数字货币失窃等安全事件，却为**区块链技术敲响了安全警钟。**  

2016年是区块链技术元年，在这一年里，**梆梆安全**看到了区块链技术的应用价值以及存在的安全问题**，**紧跟时代潮流，**对区块链进行全面布局**：

*   研究区块链技术，结合多年对程序代码安全及白盒密码技术的研究，对区块链中私钥保护、智能合约等自身安全形成了一套有效的产品方案。
    
*   与国内多家名校以及金融、能源等行业的大型公司联合申请科技部重大课题，致力于区块链技术的理论研究，将进一步加速区块链技术的成熟与系统化。
    
*   与国内业界领先的区块链公司进行合作交流，共同推动区块链技术的落地。
    
      
    

区块链正在扰动着第五次网络变革，在机遇与风险面前，其自身的安全防护能力需要尽早的予以提升，**不能再让安全漏洞成为千里之堤毁于一旦的那个“蚁穴”**！
