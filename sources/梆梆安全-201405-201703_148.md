# 强强联合 引爆SMB安全市场新格局

近日，梆梆安全与Sophos共同宣布双方将在中国达成战略合作伙伴关系，共同推广面向SMB市场的企业级安全解决方案。一中一西，一“内”一“外”的两家公司将在SMB市场擦出怎样的火花呢？

**当移动安全遇到传统安全**

随着大数据和云的发展，IT架构正在发生巨大的变化。内外网、安全边界的差距越来越小，越来越模糊，传统基于已知漏洞的被动威胁策略，已让企业很难再及时应对未知的安全威胁。同时，随着手机App的爆发式发展，传统安全也很难去保证App中源码、通讯协议等方面的安全。当今的企业正在面对着来自“内”、“外”的双重威胁。

而本次双方的战略合作，则可以解决上述问题。

Sophos——一家拥有三十多年历史，总部位于英国的老牌安全企业——可通过安全侦测与响应服务、数据保护、在网络出口进行网页过滤等安全手段。Sophos中国区总经理钟明辉表示，Sophos是AWS的全球合作伙伴，有较强的技术储备。在端点安全、UTM、下一代防火墙、数据加密四类产品，均同时处于Gartner领导者象限。而有此实力，业内应该不超过两家。

![](../Images/005767f72a2b00fe634a8c3051b57770.png)  

  

而其首创的 “Heart Beat心跳同步”功能，可在网关和端两部分进行协调工作。当终端被攻击后，防火墙可实时感知，并同步下发策略对攻击进行拦截，帮助用户实现对“内部”的安全防护。

面对未知的“外部”威胁，则可通过梆梆安全的“APP全生命周期”安全服务核心产品，以及“渗透测试、安全加固、通讯协议保护、应用市场监测、业务威胁感知”五项行业应用解决方案实现对未知威胁的防御。作为初创企业，梆梆安全虽为安全圈的新生力量，但一直在突飞猛进。成立六年，今年年初其估值已达5亿美元，并成功获得5亿元的D轮融资，年销售额接近3亿元。梆梆安全俨然已成为国内移动安全领域的第一品牌。其研发的安全产品已累计为7万家注册企业及开发者的超过70万个移动应用提供移动应用安全服务帮助。

**创新安全服务体系，突显合作伙伴价值**

随着BYOD的普及和中小企业对于自身资产保护的需求，使得他们越来越重视自身安全。中小企业增长速度快、IT状况评估难等客观情况则让传统部署策略变得难以应对。同时，中国目前拥有2300万家SMB企业，以其中400万家需要安全服务，每项服务费用按10000元计算，行业产值将达400亿元，市场潜力巨大！

同时，对于众多尚处于起步阶段的P2P企业来说，创新安全服务体系也可帮助他们在成立之初，便获得安全的保障。众所周知，初创企业在成立之初，往往要承受资金、生存等多方压力，此时很难再投入大笔资金处理安全问题。而本次Sophos与梆梆安全的战略合作，恰巧迎合了此部分用户的需求，让P2P行业的客户可以以更灵活、性价比更高、更符合自身发展的方式解决安全问题。

![](../Images/aa689ca08f5533ea5c1fc7df6aec0026.png)  

在梆梆安全与Sophos建立战略合作伙伴关系之初，双方便设定了两年内覆盖10万家SMB客户的目标。而依托合作伙伴、通过公有云模式，为用户提供全方位安全防护的服务模式应运而生。但这似乎有一个问题，以卖服务为主的公司，合作伙伴的价值在哪里？

对此，梆梆安全创始人兼CEO阚志刚博士表示，梆梆安全非常重视合作伙伴的价值。合作伙伴可通过销售梆梆安全的产品获得销售分成，也鼓励合作伙伴与原有服务相融合，将自身产品集成到现有安全方案中，为用户提供基于安全平台的更多安全增值服务。同时，用户可在没有任何负担、更为灵活的情况下购买服务，通过登录云平台进行自助式操作完成部署。通过创新的安全服务体系，进一步彰显合作伙伴在SMB群体中的价值！

![](../Images/e2b0139b73d8bbbc7c14d92a1e492d87.png)  

安全之于金融、政企等行业，就像水源之于植物，不仅关乎到自身发展前景，更是性命攸关的大事！一旦数据遭到泄露，一个行业巨头可能瞬间在行业中灰飞烟灭。而本次梆梆安全与Sophos的强强联手，则恰好通过企业之间的优势互补，实现了技术的联合、安全的全防卫。未来，还有更多领域在等着行业好手们去进行联合，为了解决用户之难而不断努力！
