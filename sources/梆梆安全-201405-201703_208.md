# 请Root你的手机！

让你的 Android 手机断开锁链！

无论是把 Android 手机拿来 root， 或是把 iPhone 拿来越狱，网友们都有这样的一个疑问：这样做是否“安全”。事实上， 如果你高度重视信息安全、 隐私与自主权， 那么你会有更高的动机去选择承受 root/JB/刷机过程的风险， 以及成功之后的损失。然后如果你没有信息安全经验，那么请不要去盲目的尝试，否则会给您的设备带来不可逆的损坏。

  

![](../Images/2fb7c02e6675333455f59556bbc52fbd.png)  

**对此小梆特邀梆梆安全研究院高级研究员李泉解答关于手机root的相关问题****。**

1** 为什么大部分安卓玩家拒绝对自己的手机root？**

  

答：这个问题我以前问过我周围的朋友，他们大多数确实选择的拒绝root，主要原因有这么几种：

**1、没有时间去研究root**

**2、不太在乎当前流行的安全课题，**比如“手机root是否被国外势力监听？root是否对手机性能造成影响”，手机用户考虑的更多是“反正大部分的手机用户都跟我一样曝露在相同的风险之中， 就像所有的 Windows 用户都曝露在 NSA 监听的风险之中一样， 我又不是少数的特别高风险者！”

**3、很多手机的使用者合约规定：** root之后就失去了保修服务。这种情况应该是较少。

**4、变砖块的风险。** root不成功的时候通常没什么风险； 万一真的开不了机， 就一不作而不休直接刷机。 刷机的过程如果失误， 手机的确有机会变成砖块。

5、手机root之后，原先的**官方软件的注册功能可能会失效，进而失去软件服务的权益。**

6、root成功之后， 如果任意将 root 权限开放给任何 App， 那么被恶意软件入侵时， 损害会大于未 root的设备。

  

2** 如果应用开发商或手机系统出卖你的信息安全 ，你该怎么做？**

答：我个人认为，要不要root取决于是否在乎信息安全与隐私安全。比如说，如果你希望在未加密的无线网络中安全上网，你必须要利用SSH通道。但是你的手机必须root才能使用这项技术。

再举个iOS系统的例子：如果你想要绕过苹果在 iMessage 当中所留下的后门，那么你必须越狱（类似root）。

还有这样的一个例子，不知道大家是否听说过Carrier IQ，Carrier IQ 是一个隐藏在手机中的木马程序,它会收集用户的拨号、搜索和短信等数据，如果你想要删除Android 的 Carrier IQ程序模块，最好的方式就是刷机、改用非官方的操作系统。

在 Motorola X2窃取用户资料事件中， 如果你想让手机与 Moto 总部断开连接，那么你必须 root。

  

![](../Images/bb690bd1c52660348f1d85b9ff641ff1.png)  

  

听说过Cydia吗，Cydia 是一个专为手机提供越狱服务的软件客户端。据UCSB安全专家分析， AppStore 上面经过苹果官方认证过的 App，其中高达21%的设备会回传你的uuid信息；而在Cydia商店，却只有4%的这种情况。

  

3** 还有其他root手机的理由吗，对于你个人来说。**

  

我才刚开始学 root/刷机， 所知不多； 不过已经看到一个很实用的好处： root 之后， 你可以在旧机型上面刷上新版的 ROM，延长旧机器的寿命 -- 就像Linux 可以延长计算机寿命一样。 例如我在 （出厂时跑 Android 2.3 的） Nexus S 上面刷上CM 10.2.1（相当于 Android 4.3.1），就和操作在新机器一样。

对我个人而言， 好玩和研究也都是很重要的因素。

  

**小编总结**：本文的目的不在于说服大家要root自己的手机。而是要在你看清事实、 评估过可能的风险与必然的损失之后，可以从理论知识出发， 取回你的手机的自主权。 或者你也可能觉得这些麻烦与风险有点不值得、 决定继续信任原厂所提供的资安与隐私保障。 那也没什么不对。 不论如何，至少你做了一个“informed decision”。 那么本文也就达成目的了。
