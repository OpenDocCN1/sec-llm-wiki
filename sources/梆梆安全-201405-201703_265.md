# 【梆梆驾到】梆梆安全献力G20，荣掀移动安全保护新篇章

近日，举世瞩目的二十国领导人峰会（G20）在中国杭州圆满落幕，本次峰会以“构建创新、活力、联动、包容的世界经济”为主题，二十国集团成员和嘉宾国领导人及有关国际组织负责人受邀参会。

  

梆梆安全作为全球安全服务领跑者，与浙江移动信安部通力合作，全力配合浙江移动G20峰会期间的APP安全保障工作。梆梆安全丰富的安全领域服务经验以及全球领先的安全防护技术，为与浙江移动携手保驾护航G20提供了坚实的后盾！

  

为保障G20峰会安全质量，梆梆安全与浙江移动项目组先期便召开保障落实会议，确保从前端驻厂到后端研发、从前端协调到后端测试的各部门人员落实并通力合作。经过坚持不懈的努力，在封网前顺利完成浙江移动信安部所要求对移动应用的加固和渗透测试任务：加固移动应用32个，累计加固次数超过80次；渗透服务完成超过90次，发现漏洞威胁总计超过1万例。提前确保G20峰会安全万无一失。

  

G20峰会期间，浙江移动25个业务服务APP全部采用了梆梆安全独有、业内最先进的第五代移动应用安全加固技术，全新VMP虚拟机与Native代码转换技术极大提高了APP被破译的难度，为峰会期间的APP安全提供了最高强度防护。

  

每当国际重大会议召开之时，往往也是移动安全事件频发阶段。梆梆安全移动威胁感知系统对G20峰会期间的各类移动应用恶意威胁做出了全面而精准地检测，成功防御移动应用安全事件8128例，其中终端威胁事件7814例，信息欺诈事件136例，恶意攻击事件178例。真正做到了移动安全防御无懈可击。
