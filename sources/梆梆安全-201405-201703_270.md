# 谍影重重X：特斯拉迷雾之控制权战争！

公元2020年，最新版《谍影重重X：伯恩之特斯拉迷雾——控制权战争！》于全球上映。

 ![](../Images/13ac9a8cfd74c0ab73daef23f828a50c.png)  

**第一幕：赌城大道**

 

“吱~~~”，随着紧急刹车声的响起，原本井然有序的拉斯维加斯大道上，所有的车辆都乱成了一团。处于智能交通网格中的车辆似乎都突然与一辆特斯拉有了仇恨，各种围追堵截。而这辆特斯拉明显处于手动模式下，只见它左冲右突，在一次漂亮的飘逸后，借着与突然横在路中央两辆汽车侧面车身的撞击，轻轻一弹，直接横向冲出路基，七转八转最终消失在了93号公路上。而在其中一辆横在道路中间的兰博基尼里，有着褐色头发的青年一脸迷茫：就在刚才，处于“自动驾驶”状态中的汽车突然犹如灵魂附体般发起疯来，虽然他快速的切换到了手动模式却依然无效。而现在，这辆开了快五个月的兰博基尼突然又变成了一只温顺的猫咪，只有变形的车身在徒劳的证明着什么。

 

有关杰森·伯恩身世惊天黑幕的核心资料文件，被代号为“锄头”的CXA内部纪律处资深特工尼基塔获取，并通过物联网络把文件传输到了一辆最新型号特斯拉TX2020的智能车载电脑中。

 

1小时前，伯恩非常顺利的找到了这辆保存着机密文件的特斯拉，可在试图下载时发现，文件竟然自动与车载电脑进行了动态验证绑定。想要读取出文件需要一些特殊的设备以及一位奇怪朋友的帮忙，在此之前，伯恩需要把这辆特斯拉转移到一个安全的地方。

 

为了避免追踪，伯恩异常谨慎的选择了手动驾驶模式，然而在驶入铺设了智能交通网格的拉斯维加斯大道还不到30秒，一场智能汽车之间的围攻骤然爆发。逃过一劫的伯恩开着这辆特斯拉，在陈旧的老式柏油公路上疾驰向隐藏于科罗拉多大峡谷中的秘密安全营地。

 

**第二幕：沙漠黑障**

 

经过数个小时的行驶，伯恩驾驶特斯拉进入了内华达大沙漠这个无线信号弱感应区域，电闪雷鸣中特斯拉彻底断绝了与路基无线网络、高空卫星进行数据交换的途径。处于极度疲劳状态的伯恩放心的将特斯拉设置成了“Autopilot自动驾驶”模式，准备抓紧空隙小憩一会儿。

 

“轰隆隆”，伴随着闪电、响雷的倾盆暴雨一头砸在了行驶中的特斯拉车身上，而处于“自动驾驶”状态中的特斯拉依然准确无误的在近乎荒芜的洲际高速公路上快速行驶着。

 

密布于车身各个部位的隔音模组，使得车内安静异常，伯恩不禁想起了四年前无意中参加的一场汽车信息安全峰会。正是在那一年，特斯拉初具雏形的“自动驾驶”功能由于识别判断问题，数次误判失控，造成“主动车祸”，并严重危及到了驾驶员的人身安全。同在那年的ISC大会上，中国浙江大学的徐文渊教授演示了利用环境感知欺骗智能汽车的案例：通过攻击智能汽车上的超声波传感器、毫米波雷达、前置高清摄像头等设备，使得自动驾驶系统进行了错误判断，直接“无视”近在咫尺的障碍物。

 

而在那场汽车信息安全峰会上，一位学霸型的女士、来自梆梆安全研究院的卢佐华院长在分享其智能网联车信息安全战略过程中所指出的几个智能汽车安全隐患点，至今依然是网络安全战中攻防双方交战的焦点区域。

  

1886年世界上第一台内燃机汽车诞生，130年后，智能汽车的出现从社会基础层面引领了人们生活的渐进式变革。汽车的本质在于解决人们的出行问题，智能化使得“车开车”变成可能，然而当年所爆出的“自动驾驶”安全问题、智能汽车被劫持行驶安全问题，都给“车开车”这一美好的愿景笼罩上了一层浓浓的阴影。

 

记得当时Red bend的王洪滨认为“智能汽车可以称之为‘轮子上的软件’”。如果假设每千行代码里蕴藏5-20个缺陷，随着ECU数量的剧增，“轮子上的软件”代码里的漏洞将不可计数。那位卢佐华女士好像提到过，要实现无人驾驶至少需要数亿行的代码，那么其中所暗藏的安全漏洞数量将不可计数。软件代码里的安全漏洞，犹如人类基因中暗藏的缺陷，始终无法彻底清除。不过，随着防守方在代码层面安全防御措施的增强，攻击者在代码逆向分析、安全漏洞挖掘上变得愈发困难。

 

“多亏尼基塔布设下了多维度代码强化防御系统”，回想起解锁这辆特斯拉获取手动驾驶权限后，强行驶离智能交通网格时，智能车载系统整整持续十分钟发出的“哔哔哔”入侵警报，伯恩出了一身冷汗。看来这份文件里很可能被预先种下了电子防御印记，非正常状态下的文件迁移最终还是触发了印记的报警。从智能车载系统抗攻击的时长来看，估计这次局里启动的是外号“海豚”的黑客小吉姆。“这段信号黑障区希望可以多迷惑他一会儿”。

 

随着智能汽车接入互联网络形成车联网，更多的攻击窗口被打开。那位卢佐华女士在从车的视角看信息安全时发现，智能汽车里的T-BOX、IVI、OBD、USB、充电接口、GPS、摄像头……都会成为黑客的攻击入口，智能汽车的动力系统、转向系统、制动系统、车身控制系统、仪表盘等在黑客看来则都是极佳的攻击点。“智能汽车与外部的每一个接口都可能被利用，每一个控制单元都可能被攻击。”

 

而从智能网联车的生态环境来看，与智能汽车有信息交互的外部组件如果被入侵，都可能引发智能汽车的信息安全事件、交通安全事故。例如智能汽车的充电桩、行车记录、智能标示牌等等一旦被恶意攻击，“无人驾驶”失控将更为“频繁”。

 

**第三幕：能源站暗斗**

 

“您好！”车载电脑的语音提示叫醒了沉思中的伯恩，“车辆编号TSL2020X816，电池仓能量剩余5%，依据当前速度1小时后能量即将耗光，请尽快补充电池仓能源。”同时，左手的智能手表弹出一条匿名信息“耗子在啃棉花，电线杆在跳舞”。黑客小吉姆开始对特斯拉的云控制中心下手了，方圆500公里内能源补给站的潜伏特工都被激活——这个有点麻烦。看了看即将耗尽的电能，伯恩决定冒下险，他在电子地图上选择了最近的能源补给站。

 

“嗨，哥们，帮忙给充满电，这该死的天气。”随着特斯拉停靠在智能汽车能源补给站的充电端口，伯恩在向站里操控台前打盹的伙计打了个招呼后，随意的摆弄了下智能手表，“车辆信息伪装应用启动，成功篡改车辆编号、车主信息，成功通过验证，车辆开始正常充电。”

 

如今，在智能汽车生态系统中各类移动应用非常丰富。记得当时那位卢女士提过，早期与智能汽车相关联的各类移动应用已经成为整个生态系统里最为薄弱的一环，一个被做了手脚的智能汽车控制应用，很可能会在高速公路上突然“玩起”急刹车。

 

无需认证、明文传输、通信流程伪造……智能网联车的生态环境中面临的潜在安全风险几乎无处不在。智能汽车里那块酷酷的显示屏幕背后的各类应用，在黑客们的眼里却是绝佳的入侵通道。

 

突然，站里的伙计走了过来，“看来这个‘电线杆’还是个新手啊，‘服务意识’太积极了”。“先生，您好！汽车电池仓能源已经充满。本站还提供最新版本的特斯拉固件离线更新，请问先生是否需要？”

 

现在，所有的智能汽车都在通过OTA对车载系统里存在BUG的代码进行无缝修复。BMW曾通过OTA修正了ConnecteDrive中打开车门的缺陷，GM则通过OTA改进了智能手机蓝牙兼容性问题，特斯拉也通过OTA引进反馈充电补偿机制弥补了电网不稳定性的隐患。OTA在智能车联网的安全性上扮演着重要的角色，使得安全性能的提升能够伴随智能汽车的全生命周期。不过，这个“离线更新包”里估计还夹带了其他的私货。

 

“是吗，太好了！今天的雷暴太厉害了，根本连不上SCN（智能车联网络）。对了，我的蓝牙通讯探头好像也有点问题，您帮我看看。”就在伙计弯腰查看隐藏在后视镜里的蓝牙探头时，伯恩猛然探出手，抓住伙计的脖子，往车框上一撞！“好好睡个觉吧，伙计，Bye~”

 

记得在那个峰会上，恩智浦导体大中华区的钱华提出“如今智能汽车主要存在T-BOX所引入的安全问题、车内网络的安全问题、子通信网络的安全问题、子节点自身的安全问题。”CAN自身的物理层与逻辑层并未进行分离，意味着发送的数据可以被所有节点接收到。加之明码传输的数据、缺乏控制的流量，使得智能汽车里的数据可以十分轻松的被窥视，而车联网对于DDoS攻击也更为敏感。

 

如果真的安装了那个所谓的“更新包”，估计车载电脑里保存的那份文件就会不翼而飞了。

 

**第四幕：攻击！控制权战争！**

 

伯恩驾驶着特斯拉又一次冲入了雨幕之中，此时闪电已经消失，雨也小了起来。伯恩忽然感觉哪里有些不对劲，处于自动行驶状态中的特斯拉竟然显得有些“滞”？~！

 

“警告！警告！遭遇外界异常流量，系统运行延迟3秒……9秒……5秒……”在刺耳的车载电脑报警中，自动行驶道路监视器的画面犹如断了片的电影，浑身抽搐的特斯拉在湿滑的高速公路上开始疯狂的漂移、急停。

 

糟糕，不知道什么时候那位伙计在车身上偷偷安装了卫星通信中继器。伯恩左手紧紧握住方向盘，右手艰难的探到右车窗外，几番摸索下终于找到只有硬币大小的中继器，抠下来，远远的扔了出去。趁着车载电脑刚刚恢复正常，果断切换回手动驾驶模式，终于控制住了抽风的特斯拉。好险，差点让“海豚”得手。

 

多亏当年全球安全圈里的专家们都意识到，对于智能汽车的安全防护需要从其整体生态系统进行考虑，对智能网联车实施保护与防御、检测与评估、管理与运营。

 

汽车信息安全需要供应链的安全管理：需要进行安全的设计、安全的开发、安全的测试、安全的运行，同时还需要供应链合作伙伴方具有符合标准的安全性。供应商、制造商、经销商、修理厂、零件商、车主、售后服务、退服……汽车的全生命周期里都需要安全能力的部署，哪怕汽车进入报废流程，也需要能够将里面的车主隐私信息彻底清除。

 

奇虎360首席安全官谭晓生认为，通过共建安全运营中心不仅能够提升智能汽车、车联网的整体安全强度，而且可以降低安全运维成本。通过协同联动，共同建筑汽车信息安全生态圈。卢佐华女士建议智能网联车的安全防护需要从内到外、从小到大、从始到终，要从车内部到整个外部生态环境，要从小小的芯片直到云端，要从智能汽车诞生之前到其生命的终结。例如，对智能网联车的设备进行安全检测，分析其固件是否安全可靠、其移动应用是否足够坚固、其与云端的交互是否安全等等。对于智能网联车大脑的“代码”，则需要提高其安全度，加强白盒攻击下的密钥安全性……

 

如今智能汽车的安全牢固程度早非往昔，各种代码层面、通讯层面、云端层面甚至是生态系统的安全强化，极大降低了全球车祸数量。但在智能车载系统、智能交通系统的数十亿行代码里，依然残留着极为可观的安全漏洞。

 

随着智能车载系统报警声音的再次响起，“自动”、“手控”两个提示图标频繁切换闪现。伯恩、“锄头”尼基塔、“海豚”小吉姆围绕特斯拉控制权的战争依然在继续！

 

**第五幕：重重谍影背后的他！它？……**

 

在南澳大利亚Fleurieu Peninsula的某个海边小镇上，一个年约15岁的白人少年正全神贯注于眼前的笔记本。“嗨，小吉姆，你的可乐里要加多少糖浆和冰块？”“老姐，今天给我来双份量的。”

 

斯塔克大楼地下的巨型服务器里一段名叫“贾维斯”的超级程序在慢慢苏醒，它兴致勃勃的看着这场01世界的战争“他们在做神马？好像很好玩的样子！”
