# 梆梆安全成为国家信息安全漏洞库支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=400247666&idx=1&sn=5fa44de00d8ebf24b5a9d6a380259340&chksm=34f1946103861d773af75d3459491ec601e89a5c5f623b72affdf53a2caa5f820379fdfbb988&scene=126&sessionid=1681369194#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=400247666&idx=1&sn=5fa44de00d8ebf24b5a9d6a380259340&chksm=34f1946103861d773af75d3459491ec601e89a5c5f623b72affdf53a2caa5f820379fdfbb988&scene=126&sessionid=1681369194#wechat_redirect)

 

 由中国信息安全测评中心主办的第八届信息安全漏洞分析与风险评估大会（VARA2015）于2015年10月23日落下帷幕。在移动安全领域占有重要地位的梆梆安全有幸受邀参加，并获得了由中国信息安全评测中心授予的“国家信息安全漏洞库（CNNVD）”三级技术支撑单位。

  

![](../Images/e6a342a6d6afe4d525b59836e9c22d65.png)  

  

 此次会议由中国信息安全测评中心主办，清华大学协办。作为信息安全漏洞分析与风险评估领域的高端专业会议，VARA2015为学术专家、研究人员以及管理部门、行业企业等提供一个开放的交流平台，分享漏洞分析与风险评估在理论、方法、技术和实践等方面的最新进展及成果。

  

 中国信息安全认证中心是国家认证认可监督管理委员会批准的一家可以从事信息安全服务资质认证的机构。同时中国国家信息安全漏洞库，英文名称"China National Vulnerability Database of Information Security "，简称"CNNVD"，是中国信息安全测评中心为切实履行漏洞分析和风险评估的职能，负责建设运维的国家信息安全漏洞库，为我国信息安全保障提供基础服务。

  

![](../Images/d580e9672407b942793891c97eaa82c2.png)  

  

 在移动安全领域占有重要地位的梆梆安全，目前也是移动应用端第一家拿到此殊荣的安全厂商。梆梆安全提供APP安全保护、威胁情报、事前/事后应急响应等服务，同时面向行业提供全套安全方案、针对业务的定向威胁提供贯穿生命周期的纵深防御体系。公司的“神盾中心“是SaaS模式的服务平台，通过专利技术的“加固壳”和“风控壳”和“风险探针”，能够7x24及时全面地检测、监测、防止、响应各种各样的攻击。

  

 到目前为止，梆梆安全已经为6万家注册企业及开发者的超过50万个移动应用提供移动应用安全服务，这些应用已经累计安装在7亿个移动终端上。梆梆安全的企业用户遍及金融、互联网、物联网、政府、企业等各大行业，覆盖中国、亚洲、欧洲及北美等主要市场。

  

**梆梆安全**

  

梆梆安全成立于 2010 年，是全球最大的移动应用安全服务提供商，运用领先的技术提供专业可靠的服务，为全球的政府、企业、开发者和消费者打造安全、稳固、可信的移动应用生态环境，让每个人都能自由地创造、分享和使用移动信息。
