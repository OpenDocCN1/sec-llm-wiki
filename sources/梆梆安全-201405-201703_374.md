# 中国泛在网快速发展 梆梆安全打造安全环境

 6月19日，艾媒咨询发布了《中国泛在网络安全报告》。报告显示，目前泛在网行业发展快速，应用领域逐步拓宽，相关的技术也得到政府大力支持。但泛在网下的企业面临着严重的企业安全问题，包括终端设备、感知网络、核心网络、业务应用、数据存储等。尤其在泛在网、云计算以及大数据的环境下，中国企业面临的安全问题主要为数据存储、网络攻击以及数据丢失。

  

　　如今，时有发生的APP安全攻击问题反映出安全问题的严峻，而随着各大移动开发者对安全问题的重视，未来全球APP安全市场在整个移动安全市场中的比例将会不断提高。iiMedia Research(艾媒咨询)数据显示，预计2015年全球移动安全市场规模将达到940亿美元，同比增长76.8%，未来移动安全市场仍将保持50%以上的增长率;全球移动安全市场在整个安全市场的占比也不断提高，预计2017年，全球移动安全市场将占安全市场份额的25.3%。

![](../Images/e7bd49dd04a790b52bff5afb808fd1fb.png)  

 

 针对泛在网行业所面临的企业和个人信息泄露等安全问题，各大安全厂商也推出了安全保障业务，包括基于数据的防御分析，大数据主动防御，精准化、个性化的安全策略，以及全面的安全解决方案、安全设备提供、基础服务等。而在目前安全市场的核心参与企业中，主要有梆梆安全、腾讯安全、绿盟科技和安恒信息这四家。以梆梆安全为例，它是一个面向开发者的移动应用安全平台，主要帮助开发者对其移动应用进行安全检测、安全加固、渠道监测。

  

　　目前，梆梆安全通过技术领先的专业产品与服务，为政府、企业、开发者和消费者打造了一个可信的移动应用生态环境。作为全球最大的移动应用安全服务提供商，梆梆安全的主要服务是基于大数据的安全风险控制服务，包括移动应用上线前的安全测评，确保其不会由于逻辑漏洞、代码漏洞，而导致应用本身出现漏洞问题;其次是上线后的应用保护服务，不但为移动应用提供加固服务，还阻止其被反编译、二次打包、注入恶意代码和恶意软件侵扰;最后是移动应用的监测服务，对于移动应用上线后会被删改或者山寨，梆梆安全推出了一个基于大数据的风险防控主动式防御系统，为企业提供一个主动式的移动安全服务平台，提前预知风险，避免问题发生。

  

　　泛在网、云计算以及大数据技术的成熟和推广应用，一方面，给企业和个人用户带来了更大的实惠方便;另一方面，安全问题日益成为技术应用下的重要挑战。随着泛在网络技术的不断推广和应用，加之企业和个人对安全问题的重视，泛在网络的安全市场需要更多像梆梆安全的安全服务提供商。
