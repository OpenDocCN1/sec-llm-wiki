# GMGDC专访梆梆安全COO赵宇:今年四季度正式对外开放大数据平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=200988679&idx=1&sn=24fd5aefd63bd392539a102df71d231e&chksm=28d007141fa78e0277c56392dc2e4d473a6e6bc4865beff95000faf8c280e6f780b2a64e84e6&scene=126&sessionid=1681369220#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=200988679&idx=1&sn=24fd5aefd63bd392539a102df71d231e&chksm=28d007141fa78e0277c56392dc2e4d473a6e6bc4865beff95000faf8c280e6f780b2a64e84e6&scene=126&sessionid=1681369220#rd)

在第三届全球移动游戏开发者大会上，梆梆安全COO赵宇在GMGDC官方采访中心接受游戏之音和其他行业媒体采访时表示，梆梆安全的大数据平台会在今年第四个季度正式对外开放，本着互联网的分享和共赢的精神，希望该平台能让所有的移动开发者使用。

  

以下为专访内容：

 游戏之音提问：关于梆梆安全和其他手机游戏安全服务商的区别，请您介绍一下？

  

赵宇：我们面向游戏开发者是提供一站式的安全服务，我们是整个游戏安全的奠基人。我们从11年提出游戏需要安全加固这样一个概念。到现在为止，国内绝大部分的游戏都在使用我们的安全服务。

  

谈到区别的话，主要是一站式的，我们会给游戏提供加固的同时，也会给游戏提供大数据的监测服务，今天有几次讲到我们其实是安全加固加上大数据平台，全面保障游戏开发者的安全性，以及增加他们运营效率，现在我们整个大数据平台会在今年的第四个季度正式对外开放，本着互联网的分享精神，希望这样一个平台能让我们所有的移动开发者看到这就是我们和其他公司的区别。

  

 游戏之音提问：您是如何看待手游领域的盗版问题，如何能够实现手游行业整个生态系统的健康发展？

  

赵宇：刚才论坛上，很多都提到了14年中国移动游戏的火爆，看了他的繁荣。我看到很多隐患：中国的移动游戏的盗版情况非常严重，检测显示历史数据，几乎很多知名游戏都曾经受到过盗版，外挂，加速，文件被窃取等的风险，这些行为其实可以从根本上会来摧毁一个产业，或者改变游戏健康有序的发展。

  

梆梆作为一家致力于安全服务的服务商，会从几个方面来帮助解决这些问题。第一是提高安全加固的云平台，所有的游戏开发这都可以简单的使用这个云平台，不需要原代码，把游戏上传到这个平台去，平台会有自动化加固的服务，之后再下载，就变成一个安全游戏，这样的游戏就可以避免被二次打包，被驻入，或者被各种工具破解。

  

另外，我刚才提到我们的大数据部分，我们提供了一个版权认证功能，任何一个游戏只要他是认证的游戏，通过我们的大数据平台，以及我们的系统帮助开发者确定游戏的授权，通过加固的方式，从源头来保护开发者的利益，确定版权所有权和开发者代码的安全性。

**梆梆安全** 是全球最大的移动应用安全服务提供商，通过技术领先的专业产品与服务，为政府、企业、开发者和消费者打造可信的移动应用生态环境。

  

梆梆安全 一直专注于移动应用安全方面的技术研究，为移动应用提供“一站式”的安全解决方案，包括事前的风险评估，事中的安全加固，事后的渠道监测。截止2014年8月份，梆梆安全保护的APP数量已超过25万个，覆盖全球4亿手机用户。
