# 梆梆安全鼎力赞助GMGDC CEO阚志刚将出席大会并参与巅峰对话及主题演讲

最新消息，梆梆安全确认成为9月24日至25日全球移动游戏开发者大会（GMGDC）的金牌赞助商。届时，梆梆安全CEO阚志刚将出席大会并参与高峰对话及开发者训练营主题演讲。

![](../Images/cf4611b4c462c6b7c95c8d80bf27a6a5.png)

**嘉宾简介**

阚志刚：梆梆安全CEO，博士。他于2010年创建了梆梆安全，一直致力于为用户打造安全的移动应用生态环境。  

  

阚志刚博士作为创始人，带领团队使梆梆安全成为全球最大的移动应用安全服务提供商，所保护的移动应用市场占有率位居全球第一。同时，作为移动领域的安全专家，他积极参与国内移动应用安全领域的标准制定。

  

阚志刚博士在移动通信和移动安全领域拥有10余年技术管理经验，曾任职于赛门铁克、诺基亚、索尼爱立信等公司，担任技术总监和首席软件架构师等职务。

  

阚志刚博士担任多个社会职务，包括中国公安部移动安全专家和中国移动电子商务安全专家，北京民营科技实业家协会副会长，中国电子商务协会移动商务专家等，并荣获2012年度"北京中关村高新工程 - 科技创新人才"，位列IEEE协会高级会员。同时，他带领梆梆安全成功入选国家“千人计划”项目。

  

阚志刚博士毕业于北京航空航天大学，获得计算机科学专业的博士学位，并拥有北京交通大学的经济管理专业博士后学位。他拥有8项自主知识产权发明专利，14项软件著作权；发表学术论文60多篇，著有5本移动通信领域的著作。

  

**公司简介**  

梆梆安全是全球最大的移动应用安全服务提供商，通过技术领先的专业产品与服务，为政府、企业、开发者和消费者打造可信的移动应用生态环境。  

  

梆梆安全一直专注于移动应用安全方面的技术研究，为移动应用提供“一站式”的安全解决方案，包括事前的风险评估，事中的安全加固，事后的渠道监测。截止2014年8月份，梆梆安全已保护APP数量达到25万多个，使中国4亿的手机用户免遭病毒的威胁。

  

**关于全球移动游戏开发者大会（GMGDC）**  

  

全球移动游戏开发者大会（GMGDC），中国最具影响力的移动游戏开发者B2B大会，将于9月24日至9月25日在成都世纪城国际会议中心举行。此次大会以“助力开发者成功”为主题，将致力于推动移动游戏开发者与国内外渠道之间的合作与接轨，为促进移动游戏业务的投资及增长提供一个开放的商务对接平台。  

  

大会将在中国开发者之城和高科技产业集聚中心–成都举行。今年的大会将吸引超过5000名移动游戏开发者和相关专业人士、300多家国内外媒体、来自25个国家的100多名演讲嘉宾到场。在此次盛会上，参会嘉宾不仅可以领略行业顶尖高手之间的观点碰撞，还可以在首次举办的“独立游戏开发者大赛”版块展现自己最有价值的游戏创意，并可能获得注资或并购的机会。

  

开发者训练营和开发者日为大家提供了一个学习交流的舞台，同时与会嘉宾也将在VIP欢迎晚宴及其他线下活动中与业内人士进行深入探讨。
