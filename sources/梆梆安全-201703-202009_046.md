# 教育App须在6月30日前完成教育移动应用备案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651095941&idx=1&sn=10b0b8f52d7203909be468e80dbc1660&chksm=bd2e5c968a59d580f997738c3fa4a711f98a9e61ca359db53b61d7a76d02f3c237083a7479dc&scene=126&sessionid=1681368905#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651095941&idx=1&sn=10b0b8f52d7203909be468e80dbc1660&chksm=bd2e5c968a59d580f997738c3fa4a711f98a9e61ca359db53b61d7a76d02f3c237083a7479dc&scene=126&sessionid=1681368905#rd)

——稳如泰山·值得托付——

  

5月27日，教育部科技司发布通知，教育应用必须在6月30日前完成备案。教育移动应用是以教职工、学生、家长为主要用户，以教育、学习为主要应用场景，服务于学校教学与管理、学生学习与生活以及家校互动等方面的互联网移动应用程序。

**梆梆安全依据过往教育应用备案的实施经验总结了以下应用备案的要点，供大家参考。**

#   

## 备案责任人与备案工作

**教育移动应用提供者（运营方）**

**3个备案：**

等级保护定级备案——公安部负责

ICP备案——工信部负责

教育移动应用提供者备案——单位属地

# 

  

**教育移动应用使用者（教育部门、学校）**

**1个备案：**

教育移动应用使用者备案——主管教育行政部门

#   

## 备案申请网址

http://app.eduyun.cn

#   

## 教育部通知主要内容

1\. 教育移动应用提供者（运营方）应在完成互联网信息服务（ICP）备案和网络安全等级保护定级备案后，进行移动应用提供者备案。（依据《教育移动互联网应用程序备案管理办法》第9条）；

2\. 教育移动应用提供者（运营方）开展提供者备案；

3\. 教育移动应用使用者（教育部门、学校）做好移动应用使用者备案（依据《教育移动互联网应用程序备案管理办法》第6条）。

#   

## 重要提示

1、时间紧迫！此次教育移动应用前置条件是具备等级保护备案编号、ICP备案编号。**需要的时间如下：****等级保护备案——大约3周，ICP备案——大约2周；**

2、提供者备案实行**“一省备案，全国有效”；**

3、自主开发、自主选用和上级部门要求使用的教育移动应用**均应进行使用者备案**；

4、**2020年7月1日起**，未完成上述等级保护备案、ICP备案的教育移动应用备案将被**撤销**，并予以**通报**。
