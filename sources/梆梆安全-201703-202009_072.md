# 党建和创聚合力，廉洁同行谱新篇

2020年4月21日，梆梆安全党支部与中国移动投资公司第三党支部、中国移动杭州研发中心企业发展党支部和海天瑞声党支部联合开展“反腐倡廉教育”活动，共同签署“党建和创”、“廉洁共建”倡议书，同时举办廉洁党课，以党建促共建，以共建促发展，共同构建党业融合发展、资源互补共享的新生态。

![](../Images/a5207dc334b7842157df603518866ec8.png)

四个党支部在线开展反腐倡廉教育活动

本次活动特邀中国移动投资公司党委纪委书记王玲同志、党委办公室（党风廉政办公室）和纪委办公室负责同志出席。王玲同志在讲话中指出，投资公司以资本为纽带，为四个党支部创新开展反腐倡廉教育活动搭建平台，进一步深化“党建和创”和“廉洁共建”，为被投企业发展赋能，加深研发与投资协同，促进党建和党业融合。

中移投资第三党支部书记郭湫君同志指出，中移投资公司入股梆梆安全和海天瑞声后，持续积极推动被投企业与中国移动体系内单位的业务协同，以实现发展共赢。中移投资公司希望以党建为牵引，在落实与被投企业的业务协同发展上积极作为，以高质量的党建引领，来保障高质量的发展。

中移投资第三党支部和杭研企业发展党支部分别围绕投资工作和智慧家庭生态建设工作分享了廉洁党课。梆梆安全党支部书记田晓宁同志表示，公司把党风廉政建设作为一项重点工作，创建了反腐倡廉制度体系，建立了公司、部门的反腐红线制度，并持续健全公司内控制度，将廉洁从业贯彻到每一位员工的实际工作中去。

![](../Images/97553a7f9b8bdf211c061b011848c60b.png)

在线签署“党建和创”和“廉洁共建”倡议书

在会议期间，梆梆安全党支部和中移投资公司第三党支部签署了《“党建和创”倡议书》和《“廉洁共建”倡议书》。未来，双方将以签署的“党建和创”、“廉洁共建”倡议为基础，共同开展理论同学、组织同建、品牌同筑、服务同行、成效同享等共建活动。同时，在合作过程中，严守诚实信用原则，遵循商业道德，认真践行廉洁从业各项要求，共同营造风清气正、廉洁和谐的工作氛围。

![](../Images/edd655b347eaaa98c03327fd8945f8e6.png)

梆梆安全党支部

本次党建和创反腐倡廉教育活动，梆梆安全作为被投企业，与中移投资集团以互助共享为基础，以互促共赢为目标，相互交流党建经验、探讨廉洁共建、建立健康生态，为后续深入开展党建和创实践活动及业务合作奠定了坚实基础。
