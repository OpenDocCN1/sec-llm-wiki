# 梆梆安全从软件维度构筑物联网安全纵深防御体系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651094782&idx=1&sn=90469a75556e9b649ef2725f0e7fb820&chksm=bd2ea1ed8a5928fb26bd7c9bd03d51013650a16893e63cec4050e80d216bdc9a834258d1df63&scene=126&sessionid=1681368937#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651094782&idx=1&sn=90469a75556e9b649ef2725f0e7fb820&chksm=bd2ea1ed8a5928fb26bd7c9bd03d51013650a16893e63cec4050e80d216bdc9a834258d1df63&scene=126&sessionid=1681368937#rd)

2019年12月5日，北京梆梆安全科技有限公司（以下简称梆梆安全）受邀参加由泰尔实验室主办的2019移动安全和个人信息保护论坛，并发表“构建物联网软件的防御纵深体系”的主题演讲。本次会议大咖云集，主要参会嘉宾由中国信息通信研究院、360、阿里、百度、梆梆安全等国内知名互联网企业、网络安全企业的专家组成，在会上共同讨论了移动安全的未来发展趋势。物联网作为数字转型时代最热门的技术之一，也是智能家居、无人驾驶汽车、智能仪表和智能城市的核心技术。伴随着物联网市场的迅速发展，终端数量剧增，安全隐患也在同步增加。

![](../Images/c09c51eff740f0c7fd50d8ccf73bb5d7.png)

会上，梆梆安全专家刘舒骐介绍了梆梆安全现有的物联网软件防护技术，主要包括Rich环境应用保护、Poor环境应用保护、构造软沙箱以及提供安全区安全功能部署四个方面，并建议将隐藏式安全作为第一道防线，构建物联网软件的纵深防御体系。  
针对Rich环境软件，梆梆安全提供了四重保护方案，包括源码层的源对源保护、IR层的IR混淆以及IR虚拟化、二进制加壳，确保层层保护、层层安全。对Poor环境的软件保护则是以保护其完整性为主，梆梆安全通过CFI技术规定软件执行必须遵循提前确定的控制流图路径，并在运行过程中，核对间接转移指令的目标是否在白名单中，判断程序的函数执行过程是否符合预期，从而判断程序是否被篡改。在不安全环境下，梆梆安全通过构造软沙箱保护密码算法、密钥存储、加解密过程的安全性；在TEE或其他硬件安全区部署安全代码作为安全硬件的有效补充。梆梆安全致力于提供安全咨询和安全产品，为IoT安全开发提供源码层、IR层、二进制层的全面防逆向、防破解、防调试、防Hook保护能力。建立源代码态+IR态+汇编态的一体化保护体系，层层设防，为IoT应用程序提供从静态防逆向到动态防调试的无死角保护，有效防止针对物联网终端设备应用程序的各类攻击、破解行为。目前，梆梆安全物联网安全方案已经在Momenta等多家IoT企业上成功应用。未来，梆梆安全将致力于在智能汽车、智能家居、智慧运营商等物联网相关领域，构建物联网软件纵深防御体系，全面守护物联网安全。
