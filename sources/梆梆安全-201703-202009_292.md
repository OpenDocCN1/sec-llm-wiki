# 新锐力量 | 梆梆安全强势入选Future Power 50

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651093199&idx=1&sn=dccf3999be8f0257ea3c3dc250d0312c&chksm=bd2ea7dc8a592ecad556fcbea64d6f33a010f131eda9b0b6f81194cbd8922387a75fe3ee1672&scene=126&sessionid=1681369002#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651093199&idx=1&sn=dccf3999be8f0257ea3c3dc250d0312c&chksm=bd2ea7dc8a592ecad556fcbea64d6f33a010f131eda9b0b6f81194cbd8922387a75fe3ee1672&scene=126&sessionid=1681369002#rd)

2018年8月27日，以“安全强驱动，数字新生态”为主题的第四届中国互联网安全领袖峰会(Cyber Security Summit 2018 )在京召开。本次峰会聚焦数字时代安全技术新趋势、安全产业发展机遇及挑战、新时期国际安全格局、安全人才培养等热点议题，力邀具有全球影响力的领袖破解安全谜题。![](../Images/87ad2978f4365e90dd71cd32427cc0ac.png)

其中，九大分论坛之一的Future Power 50安全新锐力量分论坛备受关注。FP50安全新锐力量分论坛汇集了权威网络安全专家、权威媒体、创投界意见领袖等重要行业领域权威专家，共同探求新兴安全行业的崛起之道，并现场揭晓了入围“FP50俱乐部”的首批成员企业。梆梆安全作为全球安全服务领跑者，凭借创新技术能力以及市场影响力成功入选，梆梆安全COO赵宇发表了以“万物互联网时代安全新突破”为主题的演讲。

![](../Images/ca11efb751d0038943370ddc8b766058.png)

![](../Images/138a4fbb161037af66cb79ea620e9e29.png)

“科技革命加速了万物互联新业态的诞生，产业新模式、新业态的背后则是新型信息化系统的支撑，正是新型信息化系统在建设过程中所面临的新攻击威胁，促使新的网络安全防护需求不断产生。”梆梆安全COO赵宇表示，黑客攻击、用户安全新需求、政府监管、新安全思维形成以及新技术的应用，这些内外部因素正在加速中国网络安全产业的结构化变革进程，万物互联时代需要重新探寻网络安全新本质，重新诠释网络安全的新定义。

![](../Images/f204f03ad2d1d9edd44db417f22d4706.png)

对此，赵宇详细阐述了梆梆安全的新型网络安全观：黑产已经联手，恶意攻击在变得愈加组织化、国家化，网络安全企业更需要摒弃单打独斗，政产学研企相联合，以安全共同体的方式，进行网络安全的顶层设计，构筑最为广泛的网络安全生态系统，实现对恶意攻击的全面围剿。

![](../Images/2a28afa3af776ed3320b2125d3df9a6c.png)

![](../Images/610da77de579970bfd96720966df101a.png)

如今，梆梆安全正在将安全防护能力向物联网领域延伸，连续发布4部物联网安全系列白皮书，并与北航等国内高等院校科研机构联合成立了物联网安全、车联网安全实验室。面向未来，梆梆安全已经开始区块链安全、人工智能安全的研究工作，并发布《认知安全白皮书》等前瞻性研究资料。据赵宇介绍，梆梆安全在持续展开针对物联网领域安全防护技术、安全产品、安全解决方案的研究与研发，并推出全球首款物联网终端安全产品“智能终端安全威胁预警系统”，从代码安全维度实现了对物联网安全的突破，通过打入探针的方式，及时发现物联网终端设备的异常。全面的移动安全建设主体，加之严密的物联网安全防护，结合全方位的安全服务，梆梆安全“一体两翼“战略所构筑的坚固网络安全防线，让万物安全互联。

![](../Images/f529106e4be84ff686b1add3d653ff07.png)

据悉，Future Power 50的评选需要通过网络投票广泛收集业界意见，并由专家评委组进行综合评判，旨在挖掘出极有潜力、有希望带动未来行业新一轮快速发展的“Future Power”。一直以来， 梆梆安全以保护智能生活为使命，致力于为政府、企业、开发者和消费者打造安全、稳固、可信的安全生态环境，让每个人都能自由地创造、分享和使用信息。从G20杭州峰会、金砖国家领导人厦门会晤、上海合作组织青岛峰会到十九大、两会、国家网络安全周，梆梆安全一直在为国际、国内诸多重大活动提供安全保障服务，此次入选正是业界对梆梆安全的肯定与鼓励，梆梆安全会继续在网络安全的世界里砥砺前行，努力成为全球安全服务领跑者。
