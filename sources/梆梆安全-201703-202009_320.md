# 鹰击长空，飞梆在天

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651092958&idx=1&sn=f1e0573b028f591f15fa499be520ca1b&chksm=bd2ea8cd8a5921db851c009bd7891a273bd0cb6c2731594c52b151c88d217690a7ae67ee1019&scene=126&sessionid=1681369018#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651092958&idx=1&sn=f1e0573b028f591f15fa499be520ca1b&chksm=bd2ea8cd8a5921db851c009bd7891a273bd0cb6c2731594c52b151c88d217690a7ae67ee1019&scene=126&sessionid=1681369018#rd)

劲健雄鹰巡群谷，横击猎物如神助；

何畏狂风骤雨至，长空万里展鸿图。

——摘自盛林诗文选集《心旅沐歌》

  

鹰，是敏锐的、独立的、坚强的。

鹰，是不畏任何艰难困苦，不屈不挠、茁壮成长的。

同时，鹰也是苦难的，是艰辛的。

正是这样成长起来的鹰，才有勇气明知有危险，仍然去尝试、去冒险。在它的眼里，没有懦弱、没有屈服、没有胆怯，没有放弃。挑战是一种本性，冒险是一种享受。也正是这样成长起来的鹰，才有凌云之志，王者之风，才有资格为王为霸，才有能力统治天空、傲视群雄。

那天，酷日炎炎，在烈火的炙烤中，鲜亮地看到了这么一群神鹰，他们身着蓝橙羽翼，在顽强地向上飞翔，他们不仅拥抱了天空，也拥有了全世界，成为名副其实的天空之王。他们的名字叫——**梆梆安全**。

为满足迅速增长的市场需求，在公司技术、产品和方案升级的过程中，实现销售人员能力的配套升级，梆梆安全销售中心计划开展飞鹰小组培养二期项目：在销售部内部甄选具有高潜能的销售精英加以重点培养，以实现业绩的大幅提高，并为公司下一个阶段的发展，培养储备销售管理人才。

**他们有鹰容**——一抹蓝一抹橙，整齐划一的训练服，用他们锐利的眼神，强壮的臂膀，振奋的口号，对外表明傲人坚定的决心，**“对客户服务，我们是认真的。”**

![](../Images/4c95c6a2194eabdc99575a8033f9533f.png)

**他们有鹰姿**——烈日炎烤，他们不怕；持久站立，他们不怕；汗如雨下，他们不怕；他们只怕自己的尽力得不到客户的认可，只怕自己做的还不够完美，他们追求极致，只为客户的一句“满意！”

![](../Images/01b6330214961cec00f055e8af7c9283.png)

**他们有鹰魂**——一根木棍易折断，十根木棍抱成团。一个人的力量是有限的，但是兄弟的团结之力是无限的。群鹰齐心协力完成目标，任何的缺陷或不足都会导致最终的失败，他们坚毅，他们齐力，他们能够化十为一，让自己的小宇宙在集体中无限爆发，他们是最勇猛无畏的“鹰”雄！

![](../Images/6afda80b7eae629d41a46e4100dc8987.png)

**他们有鹰智**——除了体能，还有业务学习、演练及考核，他们探讨，他们学习，他们较量，在一次次的学习考验中，让自己的大脑储备好为客户服务的丰富“智”能，睿智是他们鲜亮的标签，他们是独一无二的智勇飞鹰。![](../Images/963c8988668d845b6d9df1f880aa9e79.png)  

梆梆安全作为全球安全服务领跑者，从2010年成立至今，运用领先技术提供专业可靠的服务，为全球政府、企业、开发者和消费者打造安全、稳固、可信的安全环境。为8万家以上的企业及开发者用户尽心服务。今天，梆梆安全再次明志，请大家见证——梆梆安全，稳如泰山，值得托付，倾力保护万物互联时代下的智能生活！  

**后记**

梆梆安全飞鹰训练营是为了选拔及培养有潜力的销售人才，培养计划着重于培养学员的销售能力，开发个人潜力，为了确保公司业绩的提升，以及甄选销售部储备干部。目前已完成两期，从第一期到第二期，梆梆安全的飞鹰们用坚持到底的决心与心魔较量。一个成功的企业就会如同一支强大的军队，既然是军队必定有着崇高的信仰和超强的执行力。梆梆安全的精英们在一次次集训中用实力验证了他们诚信、责任、专注、激情的精神。他们坚信，无论你是谁，无论你正在经历什么，坚持住，你定会看见最坚强的自己！
