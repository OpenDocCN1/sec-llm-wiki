# AI助力IoT设备更智能、更安全

**作者：梆梆安全研究院  彭建芬**

**一、AI“热爱”物联网**

市场研究机构Gartner调查显示，2017年全球物联网(IoT)设备数量将达84亿——比2016年的64亿增长31%，目前全球人口数量为75亿，物联网设备数量超过全球人口数量已是必然。而预计到2020年物联网设备数量将达到惊人的204亿。

国际数据公司IDC在2017年12月份预估2018年全球物联网(IoT)支出将达7,725亿美元，比2017年花费的6,740亿美元增长14.6%。IDC在《全球半年物联网支出指南》预测中指出全球物联网支出将在2017-2021年预测期内保持14.4%的年复合增长率(CAGR)，2020年将超过1万亿美元大关，并在2021年达到1.1万亿美元，充分体现了物联网强劲的发展势头。  

随着IoT技术的发展和设备数量的增加，物联网智能系统会持续产生大量数据，这些数据无法由传统的数据处理算法和应用程序处理，因此物联网系统所产生的大量数据将难以存储、处理和可视化。然而，在这些数据中隐藏着大量非常有用的高价值信息，物联网传感器数据已经引起了医疗保健、生物信息学、信息科学、政府和企业决策者们的重视。如今，人工智能正在商业监测、医疗保健应用、生产开发、研发、股票市场预测、业务流程、工业应用、社交网络分析、天气分析和环境监测等各种领域中发挥着重要作用。

在可以预期的未来，物联网和人工智能(AI)必将以多种方式发挥重要作用。如今，多种力量也正在推动这两种技术需求的不断增长，越来越多的行业、政府、工程师、科学家和技术人员已经开始在各种各样的环境中应用物联网和人工智能技术。无论是在设备端还是在服务器端，人们在愈加频繁地感受到AI与IoT结合的潜在机会和好处。例如，人工智能与机器学习相结合可以从数据中进行研究，以提前分析和预测未来的行动；企业可以在出现任何影响业务的故障之前，预测出哪些设备需要维修，以及应该在什么时候进行维修。此外，在智能家居中人工智能可以与机器学习一起使用，以实现真正的智能家居体验。如，IoT借助AI技术可以利用蓝牙信号、运动传感器、人脸识别等设备获取的数据分析人类行为，对照明和室温进行宜居性调整等。

**二、物联网安全“拥抱”AI技术**

物联网发展过程中有一个问题是大家都很关心的，那就是如此大量使用互连设备，物联网是否会因之而导致严重的安全问题。因为即使是在现在，网络攻击也相当频繁，所以在实施现实生活中的所有创新计划之前，首先要考虑可能存在的安全漏洞，确保数据安全。

随着物联网在我们生活中的不断渗透，几乎每天都会有新漏洞出现，这将会全方位威胁我们的人身财产安全。例如，家里的智能锁和安全系统可能会反被窃贼“禁用”；内置扬声器和存储器的智能电视可被恶意程序利用变成监控器；智能汽车存在被恶意操控打开车门或启动发动机的危险；植入式心脏起搏器和胰岛素泵也容易受到黑客的攻击。

CNCERT所发布的《2017年我国联网智能设备安全情况报告》指出，我国联网智能设备在安全漏洞、恶意代码及攻击活动等方面主要表现出如下特点：

**1）智能设备漏洞数量大幅增加**

国家信息安全漏洞共享平台(CNVD)2017年公开收录智能设备通用型漏洞2440个，同比增长118%。按漏洞类型统计，占比排在前三位的类型分别是是权限绕过（27%）、信息泄露（15%）、命令执行（13%）。路由器及网关、摄像头及视频系统、机顶盒等类型设备漏洞数量多，是漏洞攻击的重要目标，利用漏洞入侵打印机等办公设备正在成为黑客窃取重要单位内部文件和数据的途径。

**2）恶意代码攻击活动频繁，境外控制服务器控制我国境内大批量智能设备。**

CNCERT抽样监测发现2017年下半年我国境内感染恶意代码的受控智能设备IP地址数量约129.8*万*。目前活跃在智能设备上的恶意代码主要包括Ddosf、Dofloo、Gafgyt、MrBlack、Persirai、Sotdas、Tsunami、Triddy、Mirai、Moose、Satori，这些恶意代码及其变种可通过Telnet、SSH等远程管理服务弱口令漏洞、操作系统漏洞、Web及其他应用漏洞、密码暴力破解等途径入侵和控制智能设备。    

2017年出现的恶意软件BrickerBot黑进物联网设备后，不会将联网设备变成僵尸肉鸡，而是经由命令进行远程操控，破坏存储、中断连接导致设备无法正常运作，即使恢复了出厂设置也无济于事。目前，已有超过1000万的物联网设备被其变成了“砖头”。 

面对黑客对物联网设备的攻击，Forrester Research警告说“没有单一的魔术安全子弹可以轻松解决所有物联网安全问题”。2017年，Forrester Research讨论了13种最相关和最重要的物联网安全技术前景，分析出6项最热门技术，分别是IoT的网络安全、认证、加密、PKI、安全分析及API安全。IoT安全分析作为热门技术之一，通过收集物联网设备的数据，并汇总、监测、范式化，当超出既定策略时，提供执行报告，发出报警。这项技术将集成机器学习、人工智能和大数据技术，提供更多的模型，发现攻击，减少误报。目前思科、Indegy、卡巴斯基实验室、SAP和Senrio等厂家均投入了对该项技术的研究。

![](../Images/454c64d5df951cd84f8aa0f70962b93d.png)

无独有偶，梆梆安全研究院从2016年就选定了IoT安全分析技术方向，并进行了研究。通过对大量IoT终端设备的调研与分析后，发现：

   1）物联网终端设备的计算和存储资源有限，需要设计轻量级的监测机制。

   2）物联网终端与物理场景的操作有关，面向业务逻辑的攻击隐蔽性强。

   3）针对物联网智能终端攻击的恶意代码变种数量多、更新升级快。

根据以上的分析结果，梆梆安全利用微分域的终端检测技术，针对特定活动或活动超出既定策略等异常行为进行快速捕捉，并提供可操作的报告和警报。   

梆梆安全是最早认识到机器智能安全风险并展开认知安全研究的公司之一，“认知安全”作为梆梆安全继“物联网安全”的又一研究方向，正在从AI技术的物联网安全应用研究出发，对物联网设备收集数据进行汇总、整理，利用大数据技术、复杂的多种聚类算法发现未知攻击，并利用机器学习技术分类算法形成攻击模型，提炼攻击的行为特征并下发策略，保障物联网设备的安全运行。未来，梆梆安全将进一步研究AI算法自身安全，保证知识和智慧的安全。
