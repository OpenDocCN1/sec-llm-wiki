# Android P开发者预览版首发 梆梆安全率先兼容

今天，Android P的首个开发者预览版正式发布，梆梆安全也率先实现了兼容支持。

在该版Android P里有一个功能会非常让“商场迷路者”们所欢迎，它就是“使用WiFi RTT进行室内定位”。Android P为IEEE 802.11mc WiFi协议添加了平台支持，这可以让应用拥有室内定位的能力，而且定位精度几乎能够达到1-2米。

另外，Android P的多摄像头 API能实现单摄像头无法实现的创新功能：如无缝变焦、散景和立体视觉，还能有效减少初始捕捉时的延迟。

同时，Android P还提供了对凹口屏幕的支持，改进了消息通知，增加了对HDR VP9 Profile 2的内置支持，以及用于NFC支付和安全交易的Open Mobile API等。

为了进一步提高应用安全性，Android P正在转向更一致的用户界面(UI)，以便跨应用和设备进行指纹验证。Android现在可以通过标准系统对话框提示用户触摸指纹传感器，并在文案和位置管理方面根据不同设备做出相应匹配。

在用户隐私保护方面，Android P对所有处于空闲状态的应用访问话筒、摄像头和SensorManager传感器进行了限制。当应用的UID空闲时，麦克风将会报告系统“无音频信号”，传感器则会停止报告事件，应用使用的摄像头也会断开连接。如果应用尝试使用它们，则会生成错误。

梆梆安全自2011年提出移动应用加固概念以来，一直在为用户提供最为专业的移动应用安全防护。梆梆安全还与谷歌紧密合作，保证对最新版Android的第一时间兼容性支撑，本次也无例外。

随着物联网的逐渐落地，万物互联时代正在离人们越来越近。愈加繁琐的恶意攻击，促使人们必须探寻发现网络安全新本质，形成新的网络安全思想，建立全新网络安全观。在梆梆安全看来，从PC时代到万物互联，应用程序是整个IT世界的灵魂，正是程序在驱动着整个IT世界不断前行。万物互联时代下，繁杂的IT系统架构，需要人们考虑从程序层面重新定义安全，以程序安全为核心，建设全新网络安全防御体系。
