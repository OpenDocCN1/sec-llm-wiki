# 北航&梆梆安全牵手共建首家车联网安全研究院

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651092575&idx=1&sn=b2f1e8de869563cc9c35ac4f2f80d95c&chksm=bd2ea94c8a59205a8869c6f18c43d7155ad0d423d596a6b3d786989160cb9d6d544e83ab8e9a&scene=126&sessionid=1681369038#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651092575&idx=1&sn=b2f1e8de869563cc9c35ac4f2f80d95c&chksm=bd2ea94c8a59205a8869c6f18c43d7155ad0d423d596a6b3d786989160cb9d6d544e83ab8e9a&scene=126&sessionid=1681369038#rd)

2018年1月12日，由梆梆安全举办的**“革故·鼎新·安全——2018梆梆安全媒体交流会”**在京召开。来自网络安全、物联网、IT、党政媒体、电视媒体、门户等领域的29家核心媒体记者，以及行业专家、用户代表共同见证了**梆梆安全&北航首家车联网安全研究院**成立的荣耀时刻。

![](../Images/b177d1769e5b12c942aa73278ea370af.png)

**革故·鼎新·安全——2018梆梆安全媒体交流会会议现场**  

梆梆安全是国内领先的网络信息安全软件和服务提供商，北航是国内交通行业最具影响力的科研和人才培养机构，在交通信息化和智能化领域有着雄厚的研究实力和丰硕的前瞻研究成果。双方希望借助各自的资源和技术优势，在汽车及车联网安全领域开展深入的全面合作，**通过建立车联网安全研究院，****探讨产学研深度合作新模式，挖掘车联网信息安全产业空间和学术空间****。**

![](../Images/4c900d12ec1e395cbbd28a87dd2c428b.png)

**（左）梆梆安全创始人&CEO阚志刚博士 （右）北京航空航天大学余贵珍教授**

此外，**双方共同成立车联网安全研究院，将推进车联网信息安全领域的相关工作，展开科学研究、人才培养、行业咨询、产业转化、标准与规范等方面的合作。**研究院立志成为中国最权威的车联网信息安全技术咨询机构、法规标准制定参与者、车联网信息安全解决方案的领导者。

研究院宗旨是为高速发展的中国车联网信息安全产业提供服务，协助各汽车整车制造厂、零部件供应商完善内部车联网信息安全管理机制，并建立车联网信息安全管理系统，推动中国车联网信息安全的健康发展。

同时，本次交流会围绕**“万物互联时代安全”、“洞见物联 敏见安全”、“基于AI的下一代应用安全技术”**三大主题展开了精彩的演讲和激烈的讨论。

![](../Images/8951fa75f3d86233a41a88729d1e92ed.png)

**梆梆安全创始人&CEO阚志刚博士做主题演讲**

梆梆安全创始人&CEO阚志刚博士在演讲中提到：由于智能终端多样化，网络安全行业面临来自黑产、灰产等领域里更多复合型的攻击手段和更灵活的攻击挑战，用户的信息系统也在暴露出更多的可攻击面，面对狡猾的恶意攻击用户越来越难以有效应对。同时，更多IT巨头、互联网巨头也在通过并购、联盟、合作等方式为其用户提供更多的网络安全服务。来自多方的压力，正在促使中国网络安全产业发生结构化变革，万物互联时代下安全需当重新定义。

![](../Images/aecc6cbc74aa218d08a8e2b449542600.png)

**梆梆安全研究院院长卢佐华做主题演讲**

梆梆安全研究院院长卢佐华在演讲中提到：研究院成立的初衷源于对安全本质的思考。卢佐华从代码之殇、联网之疫、攻防之悖3个维度分析了万物互联网时代的安全特征，提出微边界、微分域来保障程序安全，并展示了先后联合中国电子技术标准化研究院、交通运输部科学研究院、北京航空航天大学、《信息安全与通信保密》杂志社等机构，编撰发布的四部物联网安全系列白皮书。

![](../Images/e7bcab2f1e5aa7d360fa05a54615fedf.png)

**梆梆安全高级副总裁付杰做主题演讲**

梆梆安全高级副总裁付杰从传统安全手段在实际业务保障中遇到的困难出发，借助于海量数据及日趋成熟的机器学习、深度学习，提出构建第三代安全保护体系：基于AI的下一代应用安全技术。

**梆梆安全&北航首家车联网安全研究院的正式成立，标志梆梆安全对于车联网领域的研究之路更加标准化、规范化、国际化，愿双方共同携手成为全球车联网安全领导者！同时，首届媒体交流会的成功召开，也让梆梆安全人更加充满信心，站在巨人的肩膀上，梆梆安全可以看得更高、走**得**更远！**
