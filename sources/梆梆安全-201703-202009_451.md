# 移动互联时代安全的新格局与新引擎

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651091717&idx=1&sn=7730a36f7af6acd8895e26b61913c7b8&chksm=bd2eac168a592500104d603fde4418e96c343bf17d216395aa9de9c32e2d281dfbd5d9a1887a&scene=126&sessionid=1681369073#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651091717&idx=1&sn=7730a36f7af6acd8895e26b61913c7b8&chksm=bd2eac168a592500104d603fde4418e96c343bf17d216395aa9de9c32e2d281dfbd5d9a1887a&scene=126&sessionid=1681369073#rd)

第二十届中国北京科博会“中关村创新论坛”6月11日在北京举行，论坛以“创新：新突破、新格局、新引擎”为主题。从论坛可以发现大家演讲有这样一些热词，比如创新发展、开放共享、移动互联网等，都是一些非常热的话题和大家所关注的新领域。今天我想从一个安全从业者角度谈谈我对移动互联网安全一些思考。

![](../Images/3b1e2e0a8b52f67aa759313215df7e3e.png)

**活动现场**

当前，全球新一轮科技革命和产业变革正孕育兴起，跨行业、跨领域的融合创新不断深入，产生了大量新应用、新业态、新模式。例如随着第五代移动通信(5G)技术的发展，除了能够提升移动互联网用户业务体验的基础，还将进一步满足未来物联网应用的海量需求，与工业、医疗、交通等行业深度融合，实现真正的“万物互联”。**如今我们已经处在“移动互联网的巅峰时刻”，移动互联网正在将我们引入一个新格局，即万物互联的物联网时代。  **

**移动互联时代安全面临全新挑战**

  

现在中国上网用户中，90%的用户都是通过手机上网，仅仅两年不到的时间，中国的4G用户数就已经接近4亿人，移动互联网的进步可见一斑。而就整个互联网发展而言，在最初的15年间我们基本是处于有线互联网，互联网在全球的终端数不到10亿个，而现在全球已经有近50亿个终端设备连入了互联网，在今后的10-15年时间内全球连入互联网的终端数有望达到500亿甚至是千亿规模。海量的联网设备包括物联网终端、RFID标签、近距离无线通信终端、移动通信终端、摄像头以及传感器网络网关等，将带来严峻的安全挑战。  

一方面，“万物互联”时代，安全不再局限于病毒、黑客等单一威胁，**万物互联的复杂性催生一系列交替衍生的安全问题**。由于大部分物联网终端具有资源受限、拓扑动态变化、网络环境复杂、以数据为中心以及与应用密切相关等特点，与传统的无线网络相比，更容易受到威胁和攻击。

另一方面，当所有的设备都变成智能化，都接入网络以后，**边界的概念将会进一步被削弱，所有接入点都将成为风险引入点**，换而言之接入点越多，可以被攻破的入口就会越多。过去，我们安全防护更多采取隔离策略，但如今越来越多的设备都支持WIFI和蓝牙等连接。设备只要联网了，就会有很多攻击点，而且攻击点越多，从防守来说挑战就越大。

  

**边界防护即将成为过去，微边界安全防护策略将成为中流砥柱**

  

随着物联网应用的迅速普及，更多的联网设备、更智能的产品在不断接入网络，但这也让网络空间安全风险随之渗透到每个角落。面对边界概念逐渐弱化、甚至消失，边界防护将成为过去，微边界防护将成为中流砥柱。微边界防护是指物联网世界中无数具备个体智能的互联实体之间的边界，这些实体具备过去宏观网络主机的处理和编程能力，同时又广泛分布于无处不在的大千世界中，因而同时具备了传统边界网络和无边界网络的特点，给传统边界安全防御的理念和手段带来了新的挑战。针对微边界安全时代，安全防护需要遵守以下原则：**（1）安全需泛在化于每个微边界点上，使每个微点都具备安全防护及抗攻击能力。（2）安全部署和运维要能够适应海量并且多样化、多元化的感知设备。（3）安全威胁发现、监测与响应要能细粒度到每个微边界点上。**

在微边界安全防护指导思想之下，梆梆安全提出了泛在安全云服务（USC）全方位安全保护服务策略，在这里笔者对USC做一个简单介绍：

**1**

****U-即Ubiquitous，单词中文意思是普遍存在无所不在，这里强调“泛在网络，安全泛在”****

物联网发展趋势是连接所有尚未连接的，面对这种联网的泛在性，梆梆安全提供的保护能面向每一个联网的端点，加强端点抗攻击能力，实现了安全保护的泛在化。

2

******S- Security ，这里强调是端管云全方位安全保障******

梆梆安全端管云安全保护架构，防范物联网新的接入设备、新的应用、新的场景、新的技术应用等各层面引入的安全风险。

3

******C- Cloud 这里强调是以云服务的方式提供安全保护******

面对物联网连接了百万、千万数量级的联网设备特点，梆梆安全采用云架构以云服务的方式实现安全的保护与管理。

  

**“万物互联”亟需深度整合，建立命运共同体成为安全新引擎**

  

目前，安全企业各个环节各自为政，缺乏开放性和行业责任意识。新威胁也钻起了相关法律法规不完善的空子，我国针对移动互联网威胁的政策监管尚未成熟；另外，行业内也缺乏统一的行业标准对相关各方进行规范和制约，同样给新威胁提供了可乘之机。

同时，移动互联网的复杂性决定了任何一家企业都无法单独承担安全的所有责任，安全产业链协同成为必然趋势。想要构建全民参与的网络安全防御体系，需要移动互联产业链各方、政府、监管机构进行深度整合，建立统一的安全体系。作为安全命运共同体坚实拥护者，梆梆安全在今年5月联合国内八大互联网金融单位，共同成立了国内首个 “金融科技技术安全共同体”，这必将成为金融科技安全技术发展新引擎。

**安全是连接一切的基石，建立命运共同体将成为安全新引擎**。笔者在这里迫切希望能看到更大范围、更深层次产业链协同出现，建立更全面安全命运共同体，让大家能够安全享受“万物互联”带去便利的同时创造各自价值！
