# 梆梆安全入选第七届CNCERT网络安全应急服务支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651091656&idx=1&sn=2430015e9d724f094d36346dc134cc26&chksm=bd2eaddb8a5924cd8d5bfa5c08b52409e19f634f704fcf1bd46bc57fd8aa4b37c63b9846c128&scene=126&sessionid=1681369073#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651091656&idx=1&sn=2430015e9d724f094d36346dc134cc26&chksm=bd2eaddb8a5924cd8d5bfa5c08b52409e19f634f704fcf1bd46bc57fd8aa4b37c63b9846c128&scene=126&sessionid=1681369073#rd)

2017年5月22日，第七届CNCERT网络安全应急服务支撑单位选拔会在青岛召开。经过严格的选拔与答辩，梆梆安全凭借在移动互联网安全领域多年的深耕与技术积累，最终从77家安全服务厂商中脱颖而出，成功入选CNCERT网络安全应急服务支撑单位。

![](../Images/a8597864454e330dace2997670d401d0.png)

**CNCERT为荣获网络安全应急服务支撑单位资质的企业颁奖**

本次“CNCERT网络安全应急服务支撑单位”选拔工作旨在为适应网络安全形势变化和工作需要，发掘一批在网络安全领域拥有较强实力、较强社会责任感的优秀网络安全技术队伍，进一步增强重大突发网络安全事件应对能力，加强公共互联网网络安全应急技术体系建设。自2004年启动以来，在国家计算机网络应急技术处理协调中心统一指导和协调下开展选拔工作。

近年来，随着梆梆安全在移动安全领域的不断发力，其对移动终端的安全保障能力也在持续增强，得到来自国家、政府主管单位、行业、用户的高度认可。先后参加了杭州G20峰会、第三届世界互联网大会、国家网络安全周等多起国家级重大活动、会议的网络安全保障与应急响应工作，为国家的网络安全建设贡献了自己的力量。

![](../Images/425405c335fad20d80d8ca2dc1e3c1ee.png)

**大会现场**  

未来，梆梆安全将继续扎根移动端及物联网安全，为国家计算机网络应急技术处理协调中心在移动安全数据分析、移动应用监测、移动威胁态势感知等方面，不断贡献自己的力量。同时，也将继续为用户提供安全、可靠、易用的安全服务与产品，为保护用户的智能生活而不断努力！

  

**【关于CNCERT】**

国家计算机网络应急技术处理协调中心（简称 CNCERT/CC ）是在信息产业部互联网应急处理协调办公室的直接领导下，负责协调我国各计算机网络安全事件应急小组（ CERT ），共同处理国家公共互联网上的安全紧急事件，为国家公共互联网、国家主要网络信息应用系统以及关键部门提供计算机网络安全的监测、预警、应急、防范等安全服务和技术支持，及时收集、核实、汇总、发布有关互联网安全的权威性信息，组织国内计算机网络安全应急组织进行国际合作和交流的组织。
