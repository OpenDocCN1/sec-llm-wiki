# 公安移动警务平台建设：针对移动应用的安全管理机制

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651091524&idx=1&sn=86bede21adf9317d1ec5b30856b2717b&chksm=bd2ead578a592441ee1d79851b43a0f10d0734b6685c279d74ccb22791958befbac7cd8d0e88&scene=126&sessionid=1681369083#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651091524&idx=1&sn=86bede21adf9317d1ec5b30856b2717b&chksm=bd2ead578a592441ee1d79851b43a0f10d0734b6685c279d74ccb22791958befbac7cd8d0e88&scene=126&sessionid=1681369083#rd)

为贯彻落实公安“十三五”发展规划以及公安部关于推进公安信息化发展的系列文件精神，支持各地公安机关根据《全国公安移动警务平台建设总体技术方案（2016版）》开展新一代移动警务建设，由国家移动信息产业技术创新战略联盟于4月14日在北京举办了“全国公安移动警务平台建设总体技术方案（2016版）”培训会。**北京洋浦伟业科技发展有限公司（梆梆安全）作为联盟理事成员参加会议，并做了主题为《公安移动警务平台建设 - 针对移动应用的安全管理机制》的演讲。**

会议邀请中国工程院院士、NMT联盟专家委员会主任沈昌祥，中国人民公安大学信息技术与网络安全学院院长、NMT联盟专家委员会副主任李欣就公安移动信息化总体架构进行讲解，并由联盟专业技术组组长从网络、安全、应用、终端、视频等方面进行细致的解读与答疑，增进联盟会员对总体技术方案的理解，为移动警务建设提供有力技术支持与服务支撑。

以下是梆梆安全解决方案的相关内容：

**场景篇**

  

互联网+关键基础设施的安全需求现状，需要政府具备**安保措施向移动端前置的管理和技术支撑能力**。

![](../Images/e8b363e4920c087ce9305e50c3f71360.png)

梆梆安全的解决方案主要**针对警务通系统建设中所涉及的移动应用**以及**应****用接入系统的安全管理机制**。

![](../Images/6306da0a91ac11f03d6e20c299e1277c.png)

**移动应用（含I、 II、III类应用）安全防护篇**

针对警务通系统划分的I、II、III类系统配套的I、II、III类应用，梆梆安全提供相关移动应用安全防护方案。通过梆梆安全**移动应用测评云平台**，**自动化识别移动应用中存在的恶意代码、安全风险和安全漏洞**，甲方或集成商对检测平台所发现的问题实施整改。之后，借助梆梆安全第五代VMP加固技术实施自动防御，进行相关加固，全面防范各种恶意攻击。

![](../Images/236aad609fb2f149948181cd0d470afa.png)

**系统（含I、 II类系统）安全防护篇**  

针对警务通系统规范提出的**“边界安全措施”**，梆梆安全的**第二个场景**是**防应用侧入侵服务器**。通过通信协议保护机制可以确保移动应用到后台服务器的通信安全，通过移动威胁感知平台可以对应用的被使用情况和被攻击情况进行全面的威胁预警，并实施动态防御。

![](../Images/6b99a33d59e7adcdfba3e18a3cf0019d.png)

**移动应用（含I类应用）安全运营篇**  

警务通系统中I类系统/应用是面向社会服务的业务域，为协防员与公众提供信息服务。梆梆安全解决方案的**第三个场景**——**钓鱼和盗版监测针对I类应用在分发渠道/应用商店上线后可能遭遇的钓鱼和盗版现象**，这类问题会对公安甚至整个社会造成巨大负面影响。梆梆安全通过对超过410家分发渠道的实时监测，可以及时发现钓鱼应用和盗版应用，并生成详细的监测报告。

![](../Images/41551111d436f12cc9fb4bf1e271d96d.png)

**梆梆安全系统应急管理预案**  

梆梆安全作为安全服务提供商，支持事前/事中/事后应急响应等服务。

**事前：**包括针对具体移动应用设计开发阶段的安全检测和安全设计咨询服务、渗透测试服务；

**事中：**提供针对具体移动应用安全策略的定制加固服务，以及移动端与服务器之间的通信协议保护机制，涵盖应用发布阶段、应用运维阶段和业务运营阶段，能够实现实时预警；

**事后：**梆梆安全提供商务和技术多重支持，包括电话、E-Mail、远程支持和现场服务在内的四种售后服务方式，由梆梆安全各省的区域服务中心和总部技术团队共同提供多重应急管理预案。

**关于梆梆安全**

 梆梆安全成立于 2010 年，是全球专业的移动应用安全服务提供商。梆梆安全不仅提供App安全保护、移动威胁情报、事前/事中/事后应急响应等服务，同时面向行业提供全套安全方案，针对业务定向威胁提供贯穿生命周期的纵深防御体系。如今，梆梆安全的使命是“保护智能生活”，并已推出公安行业、车联网、智能家居等相关解决方案。在将安全能力渗透到各类终端的同时，梆梆安全还打造出把安全能力延伸至传输端以及云端的泛在安全云防护系统。面对快速发展的人工智能，梆梆安全更是前瞻性的提出认知安全理念。

到目前为止，梆梆安全已经为7万家注册企业及开发者的超过70万个移动应用提供移动应用安全服务，这些应用已经累计安装在7亿个移动终端上。梆梆安全的用户遍及公安、金融、互联网、物联网、政府、企业等各大行业领域，覆盖亚洲、欧洲及北美等主要市场。
