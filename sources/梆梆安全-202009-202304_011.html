3月24日，全国首例全链条打击“非法获取公民车辆位置信息”案，在南京市鼓楼区人民法院公开庭审并宣判。被告人黄某伦、李某因侵犯公民个人信息罪分别被判处有期徒刑四年十一个月和三年三个月。

法院经审理查明，2020年6月起，被告人黄某伦、李某帮非法寻车业务经营者，在未经车主授权的情况下，制作提供黑客软件，绕过停车平台系统的安全防护机制，非法获取车辆实时位置信息，或安装 GPS 设备，非法跟踪车辆行踪轨迹，并将其传输给不法分子，从中获利超百万元。

本案被告人与另案被告人谢某等围绕“寻车”业务，分别负责程序开发、数据查询、联系客户、安装定位跟踪设备等，上下游之间环环相扣，形成了一条完整的产业链条，谢某等13人均以侵犯公民个人信息罪判处，判决均已生效。

为进一步加强公民对车辆位置信息的风险意识，梆梆安全车联网安全专家从 GNSS 数据入手，详细梳理车辆位置信息泄露会给车主带来哪些安全风险，并给出相应的解决方案。

概念解析：GNSS 和 GPS

GPS定位设备示例（图源网络）
上文中提到要从 GNSS 数据的角度分析，那么什么是 GNSS？和我们经常提到的 GPS 有什么关系？

GPS是全球定位系统（Global Positioning System）的缩写，是美国国防部开发的一种卫星导航系统，用于确定地球上的位置、速度和时间。GPS 是一种特定的卫星导航系统，由美国政府控制和维护。

GNSS是全球导航卫星系统（Global Navigation Satellite System）的缩写，是一种涵盖多个卫星导航系统的术语。除了 GPS 之外，还有俄罗斯的格洛纳斯（GLONASS）、欧盟的伽利略（Galileo）、中国的北斗导航系统（BeiDou Navigation Satellite System）等。

因此，GPS 是 GNSS 的一个子系统，是 GNSS 中的卫星导航系统之一。GNSS是一个更加广泛的术语，包括多个卫星导航系统，而 GPS 只是其中之一。
所以，如果拿到了车辆 GNSS 数据或 GPS 等卫星导航系统的数据，就能分析车辆的实时位置信息。

风险分析：GNSS 和 GPS 数据泄露引发车辆位置信息泄露

梆梆安全车联网安全研究团队在测试过程中，从多个车机的导航系统中分别提取到 GPS 数据和 GNSS 数据：

图：GNSS数据示例

经过多方数据对比分析，车辆的位置信息主要包括经纬度、海拔高度、车辆速度和方向等数据。以某智能汽车的位置数据信息为例，主要由起始地址和行车地址、行驶里程数、驾驶时间、海拔、温度等数据组成。

图：车辆行驶数据示例

当数据量足够大时，能够根据车辆的常用时间、常去地点、停留时间绘制车辆的行驶轨迹图。根据该图，甚至可以分析车主的家庭地址、公司地址、作息时间等非常敏感的个人信息。

图：车辆行驶轨迹示例
由于“非法寻车”行业的不规范发展，车辆位置信息泄露可能带来的安全风险：

1. 个人隐私泄露：
车辆的常去地点、停留时间等信息如果落入不法分子手中，可能被用于进行追踪、监视、跟踪或实施其他形式的侵犯个人隐私的活动。

2. 车辆盗窃：
不法分子可以通过跟踪车辆的位置、行踪和停留时间等信息，了解车主的行踪规律，从而选择合适的时间和地点实施盗窃行为。

3. GPS 欺骗：
GPS 信息还可用于制造假定位。不法分子掌握 GPS 数据信息之后，可以通过发送假的 GPS 数据，欺骗车主，从而对车主实施敲诈勒索以及其他形式的攻击。

安全建议：加强治理，保障数据流通交易安全

随着汽车电动化、网联化、智能化交融发展，车辆数据安全形势更加复杂严峻，亟须加快建立健全车联网数据安全保障体系，为车联网产业安全健康发展提供支撑。

监管部门作为数据安全治理的首要主体，要统筹安全与发展，构筑起维护数据安全和促进数字经济持续健康发展的法律制度保障。

1. 建立监管机制：从守住国家、企业、个人数据的安全底线出发，加强数据交易市场安全监督和保障的同时，提出数据流通监管的创新思路。

2. 强化多元协同：建立并完善由政府部门、企业、社会组织、网民多元参与、有效协同的数据安全多元共治格局，发挥社会力量协同治理。

车企作为车辆位置信息的收集者和管理者，既要履行数据安全保护责任义务，也要促进数据资源的开发和利用。

 
1. 加强内部管理：制定严格的信息安全制度和流程，明确数据管理的责任和权限，对内部员工进行培训和管理，加强数据监控和审计。

2. 强化数据加密：采用强密码和加密技术，确保车辆信息的安全性和机密性。

3. 防范外部攻击：加强系统安全和网络安全，监测并防范外部攻击，及时处置安全漏洞。

车主作为车辆位置信息的所有者和主要使用者，应该加强个人信息保护。

1. 不轻易透露个人信息：不要将个人信息随意透露给陌生人，尤其是涉及到GPS信息的敏感信息。

2. 安装防盗设备：安装防盗器、安全锁等设备，防止车辆被盗。

3. 防范网络攻击：保持警惕，不点击陌生邮件、不随意下载软件等，避免受到网络攻击。


梆梆安全—安全研究院成立于2016年，一直致力于车联网领域的前沿技术研究，为客户提供全面的车联网渗透测试服务，包括威胁分析风险评估、渗透测试、漏洞验证和修复建议等。未来，梆梆安全将积极参与行业技术攻关，深度洞察网络安全威胁，实现攻击和检测技术的相互赋能，保障交通数据安全和移动应用安全，助力数字交通产业高质量发展。
