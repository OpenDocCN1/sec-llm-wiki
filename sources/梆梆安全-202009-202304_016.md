# 学院路街道党工委领导莅临梆梆安全调研座谈

3月22日，**学院路街道党工委副书记兼党群工作办公室主任梁丽容，调研员虞毅，党群工作办公室科长吴锦峰、综合办公室相关负责人**一行莅临梆梆安全调研指导工作。梆梆安全党支部书记田晓宁陪同调研。

  

代表团一行在梆梆安全党支部书记田晓宁的陪同下参观了梆梆安全技术展厅、企业荣誉墙和党建文化角等，全面听取了梆梆安全整体发展情况汇报，详细了解了公司的核心技术优势、移动安全和物联网安全技术创新的具体情况以及赋能百行百业移动安全体系建设取得的成绩。

  

  

  

  

![](../Images/a63b9bb1df3883d165727888ca2f5a01.png)![](../Images/346789647bb06dba799db3a1645b4e40.png)

座谈会上，**梆梆安全党支部书记田晓宁**汇报了公司党支部自成立以来，始终以“党建树品牌，业务促发展”为主要目标，在深入开展党史学习教育、积极履行企业社会责任、推动基层党建工作发展等方面取得的工作成效，并对学院路街道为企业党建事业发展提供的优质资源表示感谢。

技术展示环节，**梆梆安全技术专家董学飞**针对梆梆安全移动应用安全产品服务体系和配套解决方案进行了详细的总结汇报。近年来，建设数字中国已成为数字时代推进中国式现代化的重要引擎，移动应用运用成果遍地开花，梆梆安全以移动安全为核心，为金融、互联网、物联网、政府、运营商、企业、医疗、能源、教育等行业客户提供了一站式的移动产品及服务支撑解决方案，**为移动应用安全、个人隐私合规和数据安全提供了值得信赖的安全保障。**

![](../Images/7415750fd40b01346d199f1fefaed1b5.png)

  

  

  

![](../Images/d55a96d517a6953522dcd475c43964bd.png)

在交流过程中，**学院路街道党工委副书记兼党群工作办公室主任梁丽容**对梆梆安全的党建工作给予了肯定，并由衷感谢梆梆安全为街道经济社会发展做出的贡献。梁丽容表示，街道会继续做好党建服务和经济服务，不断优化营商环境，进一步增强街道与企业的粘性，为企业发展注入更多活力要素。

**调研员虞毅**表示，此次座谈交流会企业讲党建、说诉求，促进了企业与街道间的党建工作交流，街道将充分发挥基层统筹协调职能，协调相关部门、科室帮助地区企业解决发展困难，为企业发展创造良好营商环境，推动企业更好发展。

  

![](../Images/36c79957e3b6ba23d479848ac6ca0ef2.png)

  

![](../Images/0e983bcb4694d851d5e06bdbc745d5d5.png)

面向未来，梆梆安全将牢记使命与担当，继续深化开展数字安全技术支撑工作，坚定不渝地守护在国家网络安全最前线，以更大的技术投入、更专业的安全实践，**助力构建数字中国安全基石，为网络空间安全保驾护航！**
