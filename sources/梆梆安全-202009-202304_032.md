近日，梆梆安全专家整理发布2月安全漏洞报告，主要涉及以下产品/组件：**Apache Kafka 、****F5 BIG-IP****、****OpenSSH、VMware Workstation 、大华摄像机、Apache Commons FileUpload、Django 、Fortinet、Joomla 、VMware Carbon Black App Control**，**建议相关用户及时采取措施做好资产自查与预防工作。**

**Apache Kafka 远程代码执行漏洞 **

**CVE-2023-25914  
**

  

**组件介绍**

Apache Kafka是一个开源消息系统项目，由Scala写成。该项目的目标是为处理实时数据提供一个统一、高通量、低等待的平台。  

  

![](../Images/99e62f08784c598f54d0f9df4721e231.png)

**漏洞描述**

2023年2月8日，Apache 发布安全公告，修复了 Apache Kafka Connect 远程代码执行漏洞，漏洞编号：CVE-2023-25194，CVSSv3评分：8.5，漏洞等级为高危。**攻击者成功利用该漏洞可以远程执行任意代码。**

  

**影响范围**

目前受影响的 Apache Kafk 版本：

2.3.0 <= Apache Kafka <= 3.3.2

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可及时升级到Apache Kafka 版本3.4.0。下载链接如下：

https://kafka.apache.org/downloads

  

**F5 BIG-IP 任意代码执行漏洞**

**CVE-2023-22374**

  

**组件介绍**

F5 是全球领先的应用交付网络（ADN）领域的厂商，创建于1996年，总部位于美国西雅图市， F5 为全球大型企业、运营商、政府与消费品牌提供更加快速、安全以及智能的应用。  

![](../Images/90f322d2e0214fa4d2be37ad29012dcf.png)

**漏洞描述**

2023年2月1日，F5 发布安全公告，修复了BIG-IP 任意代码执行漏洞，漏洞编号：CVE-2023-22374，CVSSv3 评分：8.5，漏洞等级：高危。  

  

F5 BIG-IP iControl SOAP 中存在格式化字符串漏洞，**经过身份验证的用户攻击者通过 BIG-IP 管理端口或自身 IP 地址对 iControl SOAP 进行网络访问，从而在 iControl SOAP CGI 进程上造成拒绝服务 (DoS) 或可能执行任意系统命令或代码；在BIG-IP设备模式下，攻击者成功利用该漏洞可能导致跨越安全边界。**

  

**影响范围**

目前受影响的 F5 BIG-IP 版本：

F5 BIG-IP 17.x：17.0.0

F5 BIG-IP 16.x：16.1.2.2 - 16.1.3F5 BIG-IP 15.x：15.1.5.1 - 15.1.8F5 BIG-IP 14.x：14.1.4.6 - 14.1.5F5 BIG-IP 13.x：13.1.5  

**官方修复建议**

官方目前尚未发布补丁来修复该漏洞，临时修复建议如下：

对于BIG-IP 系统，将对系统 iControl SOAP API 的访问限制为仅受信任的用户。

如果不使用iControl SOAP API，则可以通过将 iControl SOAP API 允许列表设置为空列表来禁用所有访问，具体操作为如下：

*   
*   
*   
*   
*   
*   

```
通过输入以下命令 登录到 TMOS Shell：tmsh通过输入以下命令从允许的地址列表中删除所有 IP 地址或 IP 地址范围：modify /sys icontrol-soap allowreplace-all-with { }通过输入以下命令保存更改：save /sys config
```

**OpenSSH 拒绝服务漏洞**

**CVE-2023-0286**

  

**组件介绍**

OpenSSH 是使用 SSH 协议进行远程登录的首要连接工具。它对所有流量进行加密，以消除窃听、连接劫持和其他攻击。此外，OpenSSH 提供了一整套安全隧道功能、多种身份验证方法和复杂的配置选项。

![](../Images/e4c37d1eb57d2faf19d0f2ca2be6678b.png)  

**漏洞描述**

2023年2月7日，OpenSSL 项目发布安全公告，修复了 OpenSSL 中的一个类型混淆漏洞，漏洞编号：CVE-2023-0286，CVSSv3评分：7.4，漏洞等级：高危。

  

X.509 GeneralName 在处理 X.400 地址时存在类型混淆漏洞。当启用 CRL 检查时（即应用程序设置 X509\_V\_FLAG\_CRL\_CHECK 标志），**攻击者可利用该漏洞将任意指针传递给 memcmp 调用，从而导致读取内存内容或拒绝服务。**

  

**影响范围**

目前受影响的 OpenSSL 版本：

OpenSSL  3.0

OpenSSL  1.1.1 

OpenSSL  1.0.2

  

**官方修复建议**

目前这些漏洞已经修复，受影响用户可升级到最新版本：  

OpenSSL 3.0用户：升级到 3.0.8

OpenSSL 1.1.1用户：升级到 1.1.1t

OpenSSL 1.0.2 用户：升级到 1.0.2zg（仅限高级支持客户）

下载链接：https://www.openssl.org/source/

  

**OpenSSH 双重释放漏洞**

**CVE-2023-25136**

  

**组件介绍**

OpenSSH 是使用 SSH 协议进行远程登录的首要连接工具。它对所有流量进行加密，以消除窃听、连接劫持和其他攻击。此外，OpenSSH 提供了一整套安全隧道功能、多种身份验证方法和复杂的配置选项。  

![](../Images/e4c37d1eb57d2faf19d0f2ca2be6678b.png)  

**漏洞描述**

2023年2月3日， OpenSSH Server版本9.1中被披露存在一个双重释放漏洞，漏洞编号为CVE-2023-25136，CVSSv3评分为9.8，漏洞等级为严重。

  

OpenSSH server (sshd) 9.1在options.kex\_algorithms处理过程中错误地引入了一个双重释放漏洞，可能导致在未经身份验证的情况下在OpenSSH server (sshd)的默认配置中触发双重释放。

  

**影响范围**

目前受影响的 OpenSSH 版本：

OpenSSH   9.1

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可升级到 OpenSSH 9.2。下载链接如下：

https://www.openssh.com/openbsd.html

VMware Workstation（中文名“威睿工作站”）是一款功能强大的桌面虚拟计算机软件，提供用户可在单一的桌面上同时运行不同的操作系统，和进行开发、测试 、部署新的应用程序的最佳解决方案。

VMware Workstation 版本17.x存在文件删除漏洞，**攻击者可在拥有本地用户权限的情况下利用该漏洞从安装了Workstation 的主机的系统中删除任意文件。**

某些大华嵌入式产品存在未授权操作漏洞，该漏洞是由于处理时间戳变化的API未经过验证，**了解API支持的参数的威胁者可以通过向易受攻击的接口发送特制的数据包来修改设备的系统时间，成功利用该漏洞将导致大华摄像机时间戳发生变化。**

https://www.dahuasecurity.com/support/downloadCenter

  

**Apache Commons FileUpload 拒绝服务漏洞**

**CVE-2023-24998**

  

**组件介绍**

Apache Commons是Apache软件基金会的项目，曾隶属于Jakarta项目。Commons的目的是提供可重用的、开源的Java代码。

![](../Images/732a21f27d3a0a75b48954adaf5d5442.png)  

**漏洞描述**

2023年2月20日，Apache 发布安全公告，修复了 Apache Commons FileUpload中的拒绝服务漏洞。漏洞编号：CVE-2023-24998，CVSSv3评分：6.5，漏洞等级：中危。

  

由于 Apache Commons FileUpload 版本1.5之前未限制要处理的请求部分的数量，导致**攻击者可以通过恶意上传或一系列上传来触发拒绝服务。**

  

**影响范围**

目前受影响的 Apache Commons FileUpload 版本：

Apache Commons FileUpload 1.0-beta-1 - 1.4

  

目前受影响的 Apache Tomcat版本：

Apache Tomcat  11.0.0-M1

Apache Tomcat  10.1.0-M1 - 10.1.4

Apache Tomcat  9.0.0-M1 - 9.0.70

Apache Tomcat  8.5.0 - 8.5.84

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可及时升级到以下版本：

Apache Commons FileUpload：版本 >= 1.5

下载链接：

https://commons.apache.org/proper/commons-fileupload/download\_fileupload.cgi

  

Apache Tomcat：

Apache Tomcat 版本 >= 11.0.0-M3

Apache Tomcat 版本 >= 10.1.5

Apache Tomcat 版本 >= 9.0.71

Apache Tomcat 版本 >= 8.5.85

下载链接：https://tomcat.apache.org/index.html

  

**Django 拒绝服务漏洞**

**CVE-2023-24580**

  

**组件介绍**

Django 是一个开放源代码的Web应用框架，由Python写成。

![](../Images/d043c7f3ce788121428f6b819d826192.png)

  

**漏洞描述**

2023年2月14日，Django 项目发布更新公告，修复了Django文件上传中的一个拒绝服务漏洞。漏洞编号：CVE-2023-24580，CVSSv3评分：7.5，漏洞等级：高危。

  

该漏洞存在于多部分请求解析器（Multipart Request Parser）中，**攻击者将某些输入传递给多部分表单可能会导致打开的文件过多或内存耗尽，并可能导致拒绝服务。**

  

**影响范围**

目前受影响的 Django 版本：

4.1 <= Django < 4.1.7

4.0 <= Django < 4.0.10

3.2 <= Django < 3.2.18

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可升级到安全版本。下载链接如下：https://github.com/django/django/tags

  

**Fortinet 多个产品安全漏洞**

FortiNAC 是一种网络访问控制解决方案，可帮助企业获得实时网络可见性、执行安全策略，并检测和缓解威胁。

CVE-2022-39952：FortiNAC 网络服务器中存在文件名或路径的外部控制漏洞，**攻击者可能导致在未经身份验证的情况下在系统上写入任意内容，**该漏洞的CVSSv3评分为 9.8，漏洞等级为严重。
