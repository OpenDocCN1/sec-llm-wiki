近日，梆梆安全专家整理发布12月12日--12月18日安全漏洞报告，主要涉及以下产品/组件：**Spring Boot Admin**、**Fortinet SSL-VPN**、**Citrix ADC & Gateway**、**Microsoft**、**Apple**，**建议相关用户及时采取措施做好资产自查与预防工作。**

**Spring Boot Admin 代码注入漏洞**

**CVE-2022-46166**

  

**组件介绍**

Spring Boot Admin 是一个用于管理 Spring Boot 应用程序的开源管理用户界面。

![](../Images/bb5ab0262d3af04e574eab80aa94869a.png)

  

**漏洞描述**

2022年12月9日，Spring Boot Admin 项目发布安全公告，修复了Spring Boot Admin 代码注入漏洞CVE-2022-46166，漏洞 CVSSv3评分：8.0，漏洞危害等级：高危。

  

Spring Boot Admin 集成的 Notifier 通知程序容易受到代码注入攻击，**攻击者可利用此漏洞通过向 Spring Boot Admin Server 的 /env 执行器端点发送恶意 POST 请求来远程执行代码。**

  

**影响范围**

目前受影响的 Spring Boot Admin 版本：

Spring  Boot  Admin < 2.6.10

Spring  Boot  Admin < 2.7.8

Spring  Boot  Admin < 3.0.0-M6

  

**注：所有运行 Spring Boot Admin Server、启用通知程序（例如 Teams-Notifier）并通过 UI 写入环境变量的用户都容易受到该漏洞影响。**  

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可升级到 Spring-Boot-Admin 版本2.6.10、2.7.8、3.0.0-M6或更高版本。下载链接如下：

https://github.com/codecentric/spring-boot-admin/releases

  

**Fortinet SSL-VPN 缓冲区溢出漏洞**

**CVE-2022-42475**

  

**组件介绍**

Fortinet（飞塔）是一家全球知名的网络安全产品和安全解决方案提供商，其产品包括防火墙和VPN、防病毒软件、入侵防御系统和终端安全组件等。

![](../Images/789d623ccc5e67bc2744f8b66ade6b5e.png)

  

**漏洞描述**

2022年12月12日，Fortinet发布安全公告，修复了FortiOS SSL-VPN 缓冲区溢出漏洞CVE-2022-42475，漏洞 CVSSv3：9.3，漏洞危害等级：严重，目前已检测到漏洞利用。

  

FortiOS sslvpnd 中存在基于堆的缓冲区溢出漏洞，**攻击者可利用该漏洞在未经身份验证的情况下通过特制请求远程执行任意命令或代码。**

**影响范围**

目前受影响的 FortiOS  版本：

7.2.0 <= FortiOS <= 7.2.2

7.0.0 <= FortiOS <= 7.0.8

6.4.0 <= FortiOS <= 6.4.10

6.2.0 <= FortiOS <= 6.2.11

7.0.0 <= FortiOS-6K7K <= 7.0.7

6.4.0 <= FortiOS-6K7K <= 6.4.9

6.2.0 <= FortiOS-6K7K <= 6.2.11

6.0.0 <= FortiOS-6K7K <= 6.0.14

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可参考影响范围中的修复版本去升级。下载链接如下：

https://fortiguard.fortinet.com/

  

**Citrix ADC & Gateway 远程代码执行漏洞**

**CVE-2022-27518**

  

**组件介绍**

Citrix ADC和Gateway 是美国思杰（Citrix）公司的产品。

  

Citrix Gateway 是一套安全的远程接入解决方案，可提供应用级和数据级管控功能，以实现用户从任何地点远程访问应用和数据；Citrix ADC 是一个全面的应用程序交付和负载平衡解决方案，用于实现应用程序安全性、整体可见性和可用性。

  

![](../Images/d2a7f1245458ebe394472ac1c56d74c7.png)

  

**漏洞描述**

2022年12月13日，Citrix 发布安全公告，修复了 Citrix ADC 和 Citrix Gateway中的一个远程代码执行漏洞（CVE-2022-27518），漏洞 CVSSv3评分：9.8，漏洞危害等级：严重，目前已检测到漏洞利用。

  

Citrix ADC和Citrix Gateway多个受影响版本在配置为SAML SP（SAML服务提供商）或SAML IdP（SAML身份提供商）时，**存在资源在其生命周期内的控制不当问题，可能导致未经身份验证的远程主机在设备上执行任意代码。**

  

**影响范围**

目前受影响的 Citrix ADC and Citrix Gateway 版本：

13.0-x < Citrix ADC and Citrix Gateway  < 13.0-58.32

12.1-x < Citrix ADC and Citrix Gateway  < 12.1-65.25

Citrix ADC 12.1-FIPS < 12.1-55.291

Citrix ADC 12.1-NDcPP < 12.1-55.291

注：Citrix ADC 和 Citrix Gateway 版本 13.1 不受影响。

  

**官方修复建议**

目前该漏洞已经修复，受影响用户可升级到安全版本。

Citrix ADC更新下载链接如下：

https://www.citrix.com/downloads/citrix-adc/  

Citrix Gateway更新下载链接如下：

https://www.citrix.com/downloads/citrix-gateway/

  

**微软 12月补丁公告**

  

**组件介绍**

微软（Microsoft）是一家美国跨国科技企业，由比尔·盖茨和保罗·艾伦于 1975 年 4 月 4 日创立。公司总部设立在华盛顿州雷德蒙德（Redmond，邻近西雅图），以研发、制造、授权和提供广泛的电脑软件服务业务为主。

![](../Images/f8383a68263b4ca1bb6f3a690a4165d4.png)

  

**漏洞描述**

2022年12月13日，微软发布了12月安全更新，本次更新修复了包括2个0 day漏洞在内的49个安全漏洞（不包括之前修复的Microsoft Edge 漏洞），其中有6个漏洞评级为“严重”。

  

本次修复的漏洞（不包括Microsoft Edge 漏洞）中，19个为提取漏洞，23个为远程代码执行漏洞，3个为信息泄露漏洞，3个为拒绝服务漏洞，2个为安全功能绕过漏洞，以及1个欺骗漏洞。

  

**影响范围**

用户可在微软官方选择对应漏洞编号查看漏洞详情。链接如下：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Dec

  

**官方修复建议**

目前微软已发布相关安全更新，建议受影响的用户尽快修复。

  

**（一） Windows update更新**

自动更新：

Microsoft Update默认启用，当系统检测到可用更新时，将会自动下载更新并在下一次启动时安装。

手动更新：

1、点击“开始菜单”或按Windows快捷键，点击进入“设置”

2、选择“更新和安全”，进入“Windows更新”（Windows 8、Windows 8.1、Windows Server 2012以及Windows Server 2012 R2可通过控制面板进入“Windows更新”，具体步骤为“控制面板”->“系统和安全”->“Windows更新”）

3、选择“检查更新”，等待系统将自动检查并下载可用更新。

4、更新完成后重启计算机，可通过进入“Windows更新”->“查看更新历史记录”查看是否成功安装了更新。对于没有成功安装的更新，可以点击该更新名称进入微软官方更新描述链接，点击最新的SSU名称并在新链接中点击“Microsoft 更新目录”，然后在新链接中选择适用于目标系统的补丁进行下载并安装。

  

**（二） 手动安装更新**

Microsoft官方下载相应补丁进行更新。

12月安全更新下载链接：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Dec
