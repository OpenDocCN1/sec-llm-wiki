近日，梆梆安全专家整理发布10月安全漏洞报告，主要涉及以下产品/组件：Apache Shiro、Composer、Fortinet、Microsoft Exchange Server、Apache Geode、Apache Linkis、Samba、SQLite、VMware vCenterServer PSC、Apache Dubbo Hession、Microsoft Edge、OpenSSL、Oracle WebLogic Server ，建议相关用户做好资产自查与预防工作。


Apache Shiro

存在身份认证绕过漏洞

01
漏洞描述
Apache Shiro是一个功能强大且易于使用的Java 安全框架，为开发人员提供了一个直观而全面的解决方案，用于身份验证、授权、加密和会话管理。
2022年10月12日，Apache发布安全公告，修复了Apache Shiro中的一个身份验证绕过漏洞，漏洞编号为CVE-2022-40664，CVSS评分为9.8，漏洞等级为严重。

在Apache Shiro 1.10.0之前，当通过 RequestDispatcher 接口进行请求转发或请求包含时存在身份验证绕过漏洞。

02
影响范围

Apache Shiro 版本 < 1.10.0

03
修复建议
目前该漏洞已经修复，受影响用户可以升级到Apache Shiro 1.10.0或更高版本。

下载链接：https://shiro.apache.org/download.html


Composer

存在命令注入漏洞

01
漏洞描述

Composer 是 PHP5.3以上 的一个依赖管理工具。它允许你声明项目所依赖的代码库，它会在你的项目中为你安装他们。


2022年4月，Composer修复了一个参数注入漏洞（CVE-2022-24828），该漏洞的CVSS评分为8.8，漏洞等级为高危。

带有用户控制的$file或$identifier参数的Composer方法VcsDriver::getFileContent()容易受到参数注入漏洞的影响，如果使用Mercurial或Git驱动，则可利用该漏洞执行任意命令。此外，该漏洞也影响了Packagist.org和Private Packagist，并可能导致供应链攻击。
02
影响范围
Composer 版本 < 1.10.26
2.0 <= Composer 版本 < 2.2.12
2.3 <= Composer 版本 < 2.3.5
03
修复建议

目前该漏洞已经修复，受影响用户可以升级到Composer 1.10.26、2.2.12、2.3.5或更高版本。

下载链接：https://github.com/composer/composer



Fortinet多个产品

存在身份验证绕过漏洞

01
漏洞描述
Fortinet（飞塔）是一家全球知名的网络安全产品和安全解决方案提供商，其产品包括防火墙、防病毒软件、入侵防御系统和终端安全组件等。



2022年10月10日，Fortinet官方发布安全公告，修复了其多个产品中的一个身份验证绕过漏洞（CVE-2022-40684），其CVSS评分为9.6，漏洞等级为严重，目前已发现被利用。

在受影响的FortiOS、FortiProxy 和 FortiSwitchManager产品的管理界面中，可以通过使用备用路径或通道绕过身份验证，并在未经认证的情况下通过特制的HTTP或HTTPS请求对管理界面进行操作。
02
影响范围
FortiOS 版本 7.2.0 - 7.2.1
FortiOS 版本 7.0.0 - 7.0.6
FortiProxy 版本 7.2.0
FortiProxy 版本 7.0.0 - 7.0.6
FortiSwitchManager 版本 7.2.0
FortiSwitchManager 版本 7.0.0
03
修复建议
目前该漏洞已经修复，受影响用户可以升级到如下版本：
  • FortiOS版本 >= 7.2.2
  • FortiOS版本 >= 7.0.7
  • FortiProxy版本 >= 7.2.1
  • FortiProxy版本 >= 7.0.7
  • FortiSwitchManager版本 >= 7.2.1

下载链接：https://github.com/composer/composer



Microsoft Exchange Server

存在远程代码执行漏洞

01
漏洞描述
Microsoft Exchange Server 是个消息与协作系统。Exchange server可以被用来构架应用于企业、学校的邮件系统或免费邮件系统。它还是一个协作平台。你可以在此基础上开发工作流，知识管理系统，Web系统或者是其他消息系统。


9月29日，微软安全响应中心发布安全公告，公开了Microsoft Exchange Server中已被利用的2个0 day漏洞（ProxyNotShell），可在经过Exchange Server身份验证并且具有 PowerShell 操作权限的情况下利用这些漏洞（组合利用）远程执行恶意代码。

CVE-2022-41040：Microsoft Exchange Server服务器提权漏洞，CVSS评分为8.8，漏洞危害等级高。

CVE-2022-41082：Microsoft Exchange Server远程代码执行（RCE）漏洞，CVSS评分为8.8，漏洞危害等级高。
02
影响范围
Microsoft Exchange Server 2013
Microsoft Exchange Server 2016
Microsoft Exchange Server 2019
03
修复建议
微软已经发布了相关漏洞的客户指南，受影响客户可参考实施指南中的缓解措施：

https://msrc-blog.microsoft.com/2022/09/29/customer-guidance-for-reported-zero-day-vulnerabilities-in-microsoft-exchange-server/


VMware vCenter Server PSC

存在反序列化漏洞

01
漏洞描述
VMware vCenterServer 提供了一个可伸缩、可扩展的平台，为 虚拟化管理奠定了基础。VMware vCenter Server（以前称为VMware VirtualCenter），可集中管理 VMware vSphere 环境，与其他管理平台相比，极大地提高了 IT 管理员对虚拟环境的控制。

10月6日，VMware发布安全公告，修复了VMware vCenter Server PSC中的一个反序列化漏洞（CVE-2022-31680），CVSS评分为9.1，漏洞等级为严重。

该漏洞存在于vCenter Server 的PSC（平台服务控制器）中，可在vCenter Server 上具有管理员访问权限的情况下利用该漏洞在托管 vCenter Server 的底层系统上执行任意代码。

此外，VMware还修复了VMware ESXi 中的空指针取消引用漏洞 (CVE-2022-31681)，该漏洞的CVSS评分为6.5，漏洞等级为中，在 VMX 进程中具有特权的恶意用户可以利用该漏洞导致拒绝服务。
02
影响范围

  •  VMware vCenter Server 6.5


CVE-2022-31681影响范围
  • VMware ESXi 7.0
  • VMware ESXi 6.7
  • VMware ESXi 6.5
  • VMware Cloud Foundation (ESXi) 4.x
  • VMware Cloud Foundation (ESXi) 3.x
03
修复建议

Apache Linkis是一个开源的上层应用与底层引擎之间的计算中间件，提供了强大的连接、复用、编排、扩展和处理能力。

2022年10月26日，Apache发布安全公告，修复了Linkis中的一个反序列化漏洞，漏洞编号为CVE-2022-39944。

Apache Linkis版本<=1.2.0并与MySQL Connector/J一起使用时，当对数据库具有写入权限并使用MySQL数据源和恶意参数配置JDBC EC时存在反序列化漏洞，可能导致远程代码执行。

Samba

存在缓冲区溢出漏洞

01
漏洞描述
Samba是用于Linux和Unix的标准Windows互操作性程序套件，旨在提供安全、稳定和快速的文件和打印服务。


2022年10月25日，Samba团队发布安全公告，修复了Samba软件中的一个缓冲区溢出漏洞，漏洞编号为CVE-2022-3437，CVSS评分为5.9。

该漏洞存在于Heimdal（包含在Samba中）GSSAPI 库中的unwrap_des（）和unwrap_des3（）例程中，影响了自Samba 4.0编译以来的所有Samba版本。在默认情况下，当Samba被编译为使用内部Heimdal Kerberos库时，会使用易受攻击的unwrap_des3（），因此该漏洞会影响以默认构建选项构建的文件服务器部署。

此外，Samba团队还修复了一个符号链接漏洞（CVE-2022-3592），该漏洞的CVSS评分为5.4，影响了自 4.17.0 以来的所有 Samba 版本。由于Samba 4.17以来在用户空间中引入的符号链接没有正确覆盖，导致恶意用户可以通过创建符号链接，使smbd摆脱配置的共享路径，并利用该漏洞访问服务器的所有文件系统。
02
影响范围
CVE-2022-3437：4.0 <= Samba 版本 < 4.15.11、4.16.6 或 4.17.2
CVE-2022-3592：4.17.0 <= Samba 版本 < Samba 4.17.2
03
修复建议
目前这些漏洞已经修复，受影响用户可以升级到以下版本：
CVE-2022-3437：升级到Samba 4.15.11、4.16.6 或 4.17.2。
CVE-2022-3592：升级到Samba 4.17.2。
下载链接：https://www.samba.org/samba/history/security.html



SQLite

存在数组边界溢出漏洞

01
漏洞描述
SQLite，是一款轻型的数据库，是遵守ACID的关系型数据库管理系统，它包含在一个相对小的C库中。它是D.RichardHipp建立的公有领域项目。


2022年10月25日，研究人员披露了SQLite中的一个数组边界溢出漏洞，漏洞编号为CVE-2022-35737，该漏洞的CVSSv3评分为7.5，并已存在了22年，目前漏洞细节和PoC已公开。
SQLite 1.0.12到3.39.2之前的版本中存在漏洞，当向某些函数传递大量字符串输入且格式字符串中含%Q、%q或%w格式替换类型或特殊字符!时，某些情况下可能导致拒绝服务或任意代码执行。
02
影响范围

1.0.12 <= SQLite版本 < 3.39.2

03
修复建议
目前该漏洞已经修复，受影响用户可以升级到SQLite 3.39.2或更高版本。
下载链接：https://www.sqlite.org/chronology.html

OpenSSL

存在取消引用NULL指针漏洞


01
漏洞描述
OpenSSL是一个开放源代码的软件库包，应用程序可以使用这个包来进行安全通信，避免窃听，同时确认另一端连接者的身份。这个包广泛被应用在互联网的网页服务器上。

10月11日，OpenSSL项目发布安全公告，修复了OpenSSL中的一个取消引用NULL指针漏洞，OpenSSL 3.0.0至3.0.5版本中，使用带有NID_undef的自定义密码可能会导致OpenSSL加密/解密初始化函数将 NULL 密码匹配为等效密码，这意味着明文将作为密文发出。该漏洞被分配的漏洞编号为CVE-2022-3358，CVSS评分为7.5，危害等级为中。
02
影响范围

OpenSSL 版本 3.0.0 - 3.0.5

03
修复建议
目前该漏洞已经修复，受影响用户可以升级到以下版本：
OpenSSL 3.0 用户：升级到OpenSSL 3.0.6，下载链接：
https://www.openssl.org/source/

注：OpenSSL 1.1.1 和1.0.2 不受此漏洞影响。
