# 梆梆安全顺利通过软件能力成熟度模型集成CMMI L3认证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651122169&idx=1&sn=83b71c12836cf718f3e30766713eef52&chksm=bd2e36ea8a59bffcb00325c11699b09f165da3d45d4608637900dd9346ad390b76d112dca788&scene=126&sessionid=1681368759#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651122169&idx=1&sn=83b71c12836cf718f3e30766713eef52&chksm=bd2e36ea8a59bffcb00325c11699b09f165da3d45d4608637900dd9346ad390b76d112dca788&scene=126&sessionid=1681368759#rd)

近日，CMMI认证评估小组对北京梆梆安全科技有限公司（以下简称“梆梆安全”）软件开发能力成熟度进行评估，经过为期5天严密的审核评估，梆梆安全凭借专业实力，顺利获得CMMI L3认证证书，进一步彰显了梆梆安全在软件安全领域的重要地位。CMMI：Capability Maturity Model Integration，即软件能力成熟度模型集成，代表着国际先进和科学的软件工程管理方法，是国际公认的衡量软件开发过程成熟度和规范性的评估标准。![](../Images/cea8fb8473e3ea2b368f23b2fbc82e0e.png)

梆梆安全研发中心CMMI L3证书  

自认证启动以来，梆梆安全软件开发团队积极配合评估工作，在各环节表现优异，使得评估工作圆满完成。近年来梆梆安全不断提高自身业务水平，此次认证评估顺利通过，标志着公司软件开发能力成熟度和项目管理水平与国际主流模式接轨，在软件产品的研发、管理、服务能力上达到了规范化的水平，在质量管理和过程改进能力上有了显著的提升。  

梆梆安全基于在移动安全领域多年的技术支撑与行业经验，拥有多项安全产品与解决方案。作为软件安全引领者的梆梆安全，开创、繁荣了移动应用安全蓝海市场，并在业务上形成以安全服务为主体，联动移动安全和物联网安全的“一体两翼”业务体系。同时，梆梆安全还建立了由技术、产品、解决方案和咨询服务构成的“四位一体”产研体系。目前，梆梆安全拥有10万家以上的企业及开发者用户，安全技术覆盖的移动应用软件超过100万，这些应用已经累计安装在10亿个移动终端上，用户遍及金融、互联网、物联网、政府、运营商、企业、医疗、能源、教育等各大行业。

本次通过CMMI L3认证不仅是对公司的肯定，更是对公司实现自我突破的激励。梆梆安全将以此为新起点，进一步提升技术能力，深耕钻研，规范过程管理，提高研发标准水平和产品品质，增强软件研发综合实力，为企业业务与管理不断创新变革提供充足动力。
