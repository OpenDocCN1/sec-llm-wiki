# 谷歌发布Android13首个开发者预览版，梆梆安全率先实现兼容适配

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651117863&idx=1&sn=e39cec5c867a6d4cfc1dabfa9790cac2&chksm=bd2e06348a598f220436579f468d0a901182dba5a55f8ab6b048533fc0d7396497a56343f08c&scene=126&sessionid=1681368789#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651117863&idx=1&sn=e39cec5c867a6d4cfc1dabfa9790cac2&chksm=bd2e06348a598f220436579f468d0a901182dba5a55f8ab6b048533fc0d7396497a56343f08c&scene=126&sessionid=1681368789#rd)

虎年伊始，谷歌发布了Android13的首个开发者预览版（Android13 Developer Preview 1），代号为“Tiramisu”，中文名为“提拉米苏”。  

梆梆安全作为Android应用保护领导品牌，率先开展和完成Android13 DP1版本的兼容适配工作，以梆梆安全预兼容加固框架技术为基础，实现了Android13DP1版本的**“零修改”**的完美兼容适配。

**Android13将继续强化系统的隐私和安全，提升开发者生产力****1）以隐私和安全为核心**Android 13 着重于在设备上提供更安全的环境，以及为用户提供更多的控制权，从而为所有人打造一个负责任、高质量的平台。

*   照片选择器和API - 为了保护用户的照片和视频隐私，Android 13 增加了一个系统照片选择器，这是一种标准和优化的方式，让用户可以安全地分享本地和云端照片。
*   用于Wi-Fi的附近设备权限 - Android 13为管理设备与周围Wi-Fi 热点连接的应用添加了运行时权限，这将有助于促进隐私友好的应用设计，同时减少开发者们面临的阻碍。

**2）开发者生产力与工具**Android 13提供了新的功能和工具以提升开发者生产力。帮助开发者们创建可以在数十亿台设备上运行的精美应用。

*   快捷设置放置API - 通知栏中的快捷设置 (Quick Settings) 让用户可以在不离开应用的情况下更改设置或快速进行相关操作。
    
*   主题应用图标 - 在Android 13中，谷歌将Material You动态颜色扩展到Google应用之外的所有应用图标，让用户可以基于其壁纸和其他主题偏好来选择图标色调。
    
*   单个应用的语言偏好 - 一些应用允许用户选择与系统语言不同的语言，以满足多语言用户的需求。
    
*   更快的连字符 - 连字符使折行文本更容易阅读，也让您的界面更具适应性。
    
*   可编程着色器 (shader) - Android 13 添加了对可编程 RuntimeShader 对象的支持，其行为使用 Android 图形着色语言 (Android Graphics Shading Language, AGSL) 定义。
    
*   OpenJDK 11 更新 -在 Android 13 中，谷歌已经开始更新 Android 核心库，以便与 OpenJDK 11 LTS 版本保持一致，为应用和平台开发人员提供代码库更新和 Java 11 编程语言支持。
    

**3）应用兼容性**Android 13针对折叠屏、平板电脑等大屏设备进行了适配优化，让更多应用程序可以无缝适配不同尺寸的Android设备，让应用体验更佳。**梆梆安全移动应用预兼容加固框架技术**梆梆安全，作为移动应用加固概念首倡者，始终坚持以客户为中心，以技术为导向，基于多年移动应用安全技术的积累，建立了高效的Android系统预兼容、自适应的安全加固框架技术，可以第一时间完成对Android系统新版本的兼容适配支持，做好客户安全服务的基础保障工作。梆梆安全与谷歌、华为等建立了技术层面的深度协同合作，密切关注谷歌安卓系统和各厂商ROM、硬件新技术新版本的演化，及时对相关新技术、新版本的兼容性进行验证，以期不断提升产品服务质量，确保应用安全服务和谷歌安卓系统以及各厂商定制化ROM的完美兼容。
