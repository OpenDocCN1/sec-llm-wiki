# 护航数字政务发展 ｜ 梆梆安全亮相第三届中国电子政务安全大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651107460&idx=1&sn=71d84cd98b605be445408cf4306a1667&chksm=bd2e6f978a59e681cfef45ddec8b09cf925fcba008da4dddde6fca06188c66cd883696e89ac3&scene=126&sessionid=1681368815#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651107460&idx=1&sn=71d84cd98b605be445408cf4306a1667&chksm=bd2e6f978a59e681cfef45ddec8b09cf925fcba008da4dddde6fca06188c66cd883696e89ac3&scene=126&sessionid=1681368815#rd)

![](../Images/a4e06fea1e6a49576708ec3f7057b743.png)

9月24日，由中国信息协会主办，信息化观察网、国润互联信息技术研究院、中国信息协会传媒中心承办的2021第三届中国电子政务安全大会在北京成功召开。本届大会围绕“激发数据潜能 共襄安全治理”主题，汇聚国内网络安全领域的众多专家、学者、业内人士等多方力量，探寻数据安全治理之道。![](../Images/e18746f0ed14ce9fe7c9a12e46095f19.png)会上，梆梆安全解决安全售前总监张晋发表题为**“以安全促生态  护航数字政务健康发展”**的主旨演讲。![](../Images/e416854f9687dee2831b65d4b95a2b83.png)

“十四五”时期是加快数字化发展、建设网络强国和数字中国的重要战略机遇期。“十四五”规划和2035远景目标纲要中明确提出，“加强数字社会、数字政府建设，提升公共服务、社会治理等数字化智能化水平”，将进一步推动我国数字政府的建设步伐。随着数字政府建设的持续推进，移动端（APP+小程序）因其简单快捷的使用方式成为政府服务的主要抓手和主要业务载体，移动端海量个人信息数字化带来便利的同时，也面临着前所未有的安全风险，这些都使得**移动端业务数据安全成为不可忽视的重中之重。**

![](../Images/83a74b88380bfe591fd809feebb49eeb.png)

张晋指出，近年来，越来越多的政府职能机构开放了线上业务接口，涉及社保、公积金、税务、工商等多类民生数据，政务数据的整合、开放和共享必然导致了网络安全防护难度的提升。移动政务安全问题主要集中在**安全保障能力不足、个人隐私信息泄露和缺乏应用监管手段**三个方面，其直接关系到国家安全。

在展览展示区，梆梆安全围绕电子政务移动安全进行集中展示，助力电子政务高质量发展。

![](../Images/4d8ce7e7da40734425d152e849a52833.png)大会同期发布了2021数据安全优秀解决方案，梆梆安全**电子政务移动安全解决方案**凭着优秀的安全防护实践获得**2021数据安全优秀解决方案**。

![](../Images/1a238889c7acbe5afff1ae5ca228bb91.png)

  
![](../Images/66cfc6fe34e13863e6f2a0b3cdefbecb.png)

赋能电子政务移动安全

![](../Images/716a5b5f50cf8bc323b3e7bf4d16e557.png)  
面向移动电子政务，梆梆安全深刻理解客户的安全建设痛点，针对性地提出了**移动政务安全一体化解决方案**，全面覆盖了政务APP安全防护的各个安全维度。安全体系落地方案抽象为四个层次，可以根据各地数字政务平台建设不同阶段或需求进行整体规划或分期建设。![](../Images/0be6cc93360462803b21d69b6696b781.png)移动政务安全一体化解决方案

*   **一个中心**

移动安全运营中心，通过封装底层安全功能组件，并以池化方式部署，能够快速构建常态化、可调度、资源可共享的通用安全能力。

*   **两类对象**

目前移动电子政务主要是公众服务类移动应用，但也可能存在内部办公类政务移动应用机会。

*   **三层保障**

全面覆盖了政务APP安全防护的各个安全维度：应用安全、数据安全、传输安全。

*   **四重服务**

以业界顶尖技术提供稳定持续的安全服务，安全防护体系不仅仅是建出来的，更是运营出来的。

梆梆安全提出的**“一个中心、两类对象、三层保障、四重服务”**移动政务安全一体化建设方案，充分考虑数字政务建设过程的不同阶段，因地制宜，根据其特点进行整体规划或分期建设，更好地契合移动政务安全发展，防范隐私泄露、信息混乱等网络安全风险。

未来，梆梆安全将依托公司10年来为APP开发者、运营者提供的安全防护经验，以及业界顶尖的技术提供稳定持续的安全产品服务及解决方案，致力于实现**阳光政务、公信政务、安全政务**。
