# 积极响应监管号召 助力App个人信息保护工作 梆梆安全获工信部通管局感谢表彰

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzE0NTIxMg==&mid=2651102179&idx=1&sn=bbfade4d2b58a59ec470dfca6f442cfc&chksm=bd2e44f08a59cde6a372c6c1f56ae1edceeb696bdb36f7396f77033cbf288a2ee103b085b2f2&scene=126&sessionid=1681368850#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzE0NTIxMg==&mid=2651102179&idx=1&sn=bbfade4d2b58a59ec470dfca6f442cfc&chksm=bd2e44f08a59cde6a372c6c1f56ae1edceeb696bdb36f7396f77033cbf288a2ee103b085b2f2&scene=126&sessionid=1681368850#rd)

——稳如泰山·值得托付——

  

近日工业和信息化部信息通信管理局向梆梆安全发来**感谢信**，就**梆梆安全在全国APP技术检测平台建设与APP侵害用户权益专项整理工作**中所作出的贡献和支持表示感谢。感谢信中指出梆梆安全积极响应工信部号召，发挥自身技术优势助力工信部技术手段建设以及专项整治工作，体现了梆梆安全积极响应监管要求的态度以及自身技术服务能力的专业性。

  

![](../Images/cd3371a4a636e6c8589dc11ca8af337b.png)

图：工业和信息化部信息通信管理局感谢信

  

全国App技术检测平台是在工业和信息化部的统筹指导下，由中国信息通信研究院聚集产业力量组织建设的。在2020年11月的全国APP个人信息保护监管会上，中国信息通信研究院的刘多院长介绍了全国APP技术检测平台相关情况，全国APP技术检测平台由包括梆梆安全在内的多家技术支撑单位提供检测技术及引擎支持，平台可对全国APP的个人隐私保护情况进行大规模合规检查。梆梆安全会不断提升自身技术能力，更好的为工信部等监管部分提供支撑，更好的为企业开发者提供服务。

个人信息保护，梆梆安全一直在关注

  

  

自2017年《个人信息安全规范》发布，梆梆安全即组织内部力量在App个人隐私数据治理领域开展研究，并且积极响应监管号召，基于移动应用合规平台产品以及专业安全团队参与工信部等部门组织的专项治理行动，梆梆合规平台自动化的检测app个人信息保护及数据安全合规情况，为国家网络安全、个人信息保护工作添砖加瓦。随着监管动作不断加码，梆梆安全的产品、服务矩阵也日臻完善，在支撑监管、服务企业方面均已形成解决方案。

  

**专业工具助力合规检查**

梆梆安全的移动应用合规平台，助力监管机构、测评机构、企业开发者对app进行合规检查，透视应用行为安全，最大程度的发现合规问题。为了更好的支持合规检测，移动应用合规平台现可搭载在岱睿合规工具箱上，合规工具箱内置测试终端（手机），并提供双Wi-Fi网卡环境，为测试人员提供即插即用、即拎即走的体验。

  

![](../Images/f67d6127ecf81b00d191207fd6c14c64.png)

图：岱睿合规工具箱外观

  

**专业服务发现问题提供修复咨询**

梆梆安全旗下安全服务团队联合安全服务顾问、资深安全专家，可以根据国家监管单位安全标准、行业安全标准等内容对App进行合规性测试后出具清晰详实的测试报告及解决方案，并协助客户进行合规整改，有效规避安全合规检查风险。同时，梆梆安全可以帮助企业梳理App检测流程及检测点解读，提供app安全认证咨询、金融科技产品认证咨询，为企业提供安全合规问题修复咨询服务及复查服务。

  

**梆梆安全提供一站式合规方案**

梆梆安全从移动App安全、数据保护、隐私合规等多方面为客户提供一站式解决方案，覆盖App的设计、开发、检测、发布、运营等环节，真正为客户提供App全生命周期安全解决方案。梆梆安全将始终致力于保护App的用户隐私数据安全，协助企业、监管机构解决App安全及合规问题。梆梆安全未来一定坚守专业操守，不负重托，与工信部等监管部门加强合作共创安全网络环境。
