# 梆梆安全与望安科技达成战略合作 推进形式化验证在安全关键领域落地

# ——稳如泰山·值得托付——

2021年新年伊始，梆梆安全科技有限公司与望安科技有限公司达成战略合作。双方将强强联合，优势互补，共同推进形式化验证技术在安全关键系统、软件、嵌入式实时操作系统等领域的成熟落地。

![](../Images/0b92bb71765d3ab34679892f53903f26.png)

  

**浙江望安科技有限公司**是国内第一家以"形式化验证"为核心技术的安全服务及产品提供商。公司由主**创始人现浙江大学、原北京航空航天大学赵永望教授**依托十多年的相关研发成果而创办，致力于为国家重大项目、核心软件及重点领域客户提供安全认证保障。业务覆盖航空航天、国防、轨道交通、区块链、物联网、工业控制、芯片设计制造等重大领域。

**北京梆梆安全科技有限公司**成立于2010年，是国内移动应用安全、物联网安全**领军企业**。公司以**“本质安全”**的思维发展和探索相关核心技术，围绕基于硬件的虚拟保护层、软件定义安全芯片、物联网安全操控系统、程序质量保障、程序安全可信，倡导IN-APP Protection安全理念，针对企业数字化转型提供全系列解决方案。业务广泛覆盖金融、政府、运营商、互联网、能源、交通、车联网、智能制造等领域。

![](../Images/0b92bb71765d3ab34679892f53903f26.png)

  

计算机科学的发展主要涉及硬件和软件两个方面，而软、硬件发展的核心问题之一是如何保证它们是可靠的、安全的。传统的模拟和测试方法不能保证软件和硬件的可靠性。形式化验证的主要思路是使用数学的公式、定理和系统对计算机软件或硬件进行正确性验证，从而保证从软件需求到软件编码全过程的逻辑一致性。目前，形式化验证方法成功应用于商业、航空业、通信业和芯片制造业，INTEL，ARM和NIVIDA等大公司已经把形式化方法应用到芯片的制造和验证环节中。形式化验证通过清晰无歧义的形式化语言，进行穷举形式验证，最大限度地理解和分析系统，尽可能地发现其中不一致性、模糊性、不完备性等错误，是改善和确保计算程序、计算系统质量的重要方法。随着我国自主可控的推进，对安全、自主、可靠性的要求不断提高，智能终端系统和软件程序的安全可靠性验证愈发受到重视。形式化验证将在确保产品的安全可信层面发挥越来越重要的价值。

![](../Images/0b92bb71765d3ab34679892f53903f26.png)

  

![](../Images/e4f9eb71cae5df2abb551b76301f1e4d.png)

此次战略合作协议签署后，双方将在技术、产品和市场等层面全面合作，共同推进形式化验证技术在物联网终端固件、嵌入式设备代码、物联网程序等领域的落地。未来，双方将进一步以国家在新基建、5G+等领域的发展战略为引导，充分整合优势资源，创新模式，共同探索安全关键领域新生态。
