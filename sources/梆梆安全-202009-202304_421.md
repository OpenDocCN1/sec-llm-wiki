# 融合发展 ｜“党建和创”助推业务升级

# ——稳如泰山·值得托付——

12月22日，中国移动投资公司（以下简称“中移投资”）党委书记、董事长、总经理范冰，中国移动信息技术公司（以下简称“中移信息”）党委委员、副总经理陈国一行对我司“党建和创”及业务发展进行调研，中移资本，中移信息有关同志陪同调研。梆梆安全董事长兼CEO阚志刚、党支部书记田晓宁等出席。

![](../Images/1481c4d15e7d7503e3104883cafd7d3d.png)

首先，梆梆安全党支部、中移资本党支部及中移信息党支部，分别介绍各自党建工作及业务相关情况。自“党建和创”活动启动以来，基层党组织间的交流不断得到提升，进一步增强基层党组织的战斗力和创造力，做到以党建引领创新发展，以党建和创实践为平台，把党建工作成效转化为发展活力和业务实力，以党建引领推动业务发展行稳致远。

![](../Images/e860895e5308f96e9fe3efd925c07e73.png)

随后，与会人员以“党建和创 产投合力”为主题进行座谈交流。

中移投资党委书记、董事长、总经理范冰对梆梆安全党建及业务发展给予肯定并谈了三点感受。一是，基于三方长期共同的经营发展理念，在党的统一领导下，相互扶持共同发展，共谱国家网络安全新篇章。二是，中移投资要积极发挥纽带作用，为被投企业与中国移动内部党建及业务工作沟通建立桥梁，将各方能力聚拢，加大人才培养及基础研发的投入，将被投企业的研发能力与中国移动内部能力相融合，建立一支以党员作为核心骨干力量的联合突击队，共同攻破技术难点、研发新产品，进一步深化合作。三是，共同探讨民营企业如何通过党建工作加强公司内部管理，使参股企业真正做到通过党建工作带动公司管理及业务发展。

![](../Images/c14a187c27f677abc1ea3bf30da0bd24.png)

中移信息党委委员、副总经理陈国表示前期已与梆梆安全建立友好地合作关系，希望通过“党建和创”双方有所提升、有所拓展、有所收获，共同在安全领域创新突破。陈国表示，希望中移信息、中移资本和梆梆安全，发挥三方优势，结合三方工作特色，建立统一奋斗目标，开展顶层设计，共同投入资源，输出党建及科技成果，探索打造“党建和创”促产投协同发展的新标杆。

![](../Images/dcc47f1505e5402a1163a79ed95d5626.png)

梆梆安全董事长兼CEO阚志刚指出，与中国移动合作分为“融资、融魂、融治、融和”四个重要阶段，梆梆安全始终坚持学习贯彻习近平新时代中国特色社会主义思想和党的十九大精神，紧密围绕新时代党的建设总要求和党的组织路线，将党建工作与企业发展紧密结合，不断为中国移动赋能，努力成为中国移动力量大厦的安全底座。

![](../Images/5ed8cd9693ece82080f31885c35d8fa7.png)

最后，进行“党建和创”示范单位授牌及“数字星火·星焰”党员联合突击队授旗仪式，并颁发《攻坚任务书》。“数字星火·星焰”党员联合突击队正式成立。党员联合突击队由中移信息党支部、中移投资第三党支部、梆梆安全党支部联合组建，旨在以党建带动实践，推动业务快速发展，实现共同战略目标。同时，明确了“智慧中台安全能力运营”、“数字化时代个人信息保护”及“数字化支撑系统安全防御”三项攻坚任务。

![](../Images/e05701c4a1c6cdaf660cd85f13ff8545.png)

范冰同志代表中移投资向梆梆安全颁发“党建和创”示范党组织奖牌。

![](../Images/86ef19a020beeb8d48d04936bfc08d4c.png)

中移资本党委书记范冰、中移信息党委委员陈国、梆梆安全董事长兼CEO阚志刚为突击队授旗并颁发《攻坚任务书》。

未来，梆梆安全作为被投企业，将与中移投资一同实现战略协同，相互赋能、共同赋能，不断打造并扩大双方5G”亲戚圈“，把握时代的势时，依托行业的身位，肩负历史的使命，不忘初心，砥砺前行。
