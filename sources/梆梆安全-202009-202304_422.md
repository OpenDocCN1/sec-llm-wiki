# 创新协同，共筑新基建网络安全——梆梆安全参加“2020年（第十届）电信和互联网行业网络安全年会”

# ——稳如泰山·值得托付——

为加快推进新时代网络强国建设，贯彻落实习近平总书记关于网络安全的系列重要讲话精神，准确把握当前网络安全发展态势，推动网络安全先进技术手段建设，协助推进完善电信和互联网行业网络安全保障体系建设，助力加快新基建网络安全建设，12月22日-23日，“2020年（第十届）电信和互联网行业网络安全年会”（以下简称“年会”）在广东省广州市隆重举行。

![](../Images/38a7a0068cdce44a67e43e3db1e75f61.png)

本届年会由中国通信企业协会和中国信息通信研究院主办，中国通信企业协会通信网络安全专业委员会负责承办，涵盖2020年全国网络安全管理职业技能竞赛闭幕仪式，新基建网络安全防护论坛，5G安全网络论坛，先进网络安全技术实践论坛等内容。工业和信息化部相关领导做重要致辞，表明在新基建形势下安全防护的趋势以及国家在安全领域做出的政策以及重视程度。同时，广东省通信管理局、中国通信企业协会、中国信息通信研究院、中国国防邮电工会全国委员会相关领导也分别做了发言。

![](../Images/1391858be9d74e149c4c87b0503db5b3.png)

在本届年会上，梆梆安全作为基础电信运营商信息安全合作伙伴，在大会上推出并展示了包含“移动&物联网安全”、“安全服务”、“安全咨询”、“安全集成”在内的“四位一体服务体系”，做到全面赋能5G数字化业务能力，受到参会嘉宾的广泛关注，各行业领导及全国龙头企业负责人在参观梆梆安全展位时都表示出对网络安全的重视，并期望与梆梆安全进行更深一步的合作。

![](../Images/540af79e767ce71d8b2ac6417fbd17ea.png)

本届年会以“创新 协同 推动-共筑新基建网络安全“为主题，设有主论坛和新基建安全防护论坛、5G安全论坛、先进网络安全技术实践论坛等三个分论坛。12月23日，在“5G安全论坛”上，梆梆安全的安全专家陈忠，发表了《5G智能终端安全治理体系建设》主题演讲，与现场嘉宾一起分享了5G时代下智能终端的安全治理体系要点和建设思路。

![](../Images/83c54aaff231b34c54e80127ce078f25.png)

随着5G技术的不断发展，物联网智能终端涉及到各个行业和生活当中，预计在今年将会有200亿物联网智能终端接入网络，这其中有大批的原来与网络隔离的又存在风险漏洞的终端，将导致智能终端的安全问题成倍爆发、快速增长。

![](../Images/00ebf8a0eb4c80ea032b7a8a9564884c.png)

梆梆安全认为，在5G环境下的智能终端安全治理及防护建设需从“建立检测准入控制体系”和“建立生命周期监管体系”两方面入手，主要包括：

*   5G智能终端安全基线标准体系建设
    
*   5G智能终端安全检测能力建设-静态检测
    
*   5G智能终端安全检测能力建设-动态检测
    
*   注册跟踪入网终端固件
    
*   追踪固件安全风险
    
*   以漏洞为核心进行风险管理
    

![](../Images/03c23525c7808cf257502345eb148310.png)

未来，梆梆安全将继续行业深耕，不断推进完善电信和互联网行业网络安全保障体系建设，为客户带来更好的产品和更优质的服务。
