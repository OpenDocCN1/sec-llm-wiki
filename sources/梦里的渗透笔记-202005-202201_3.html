前言

我觉得大部分的渗透测试人员都会遇到这样一个情况(大佬除外)，好不容易从外网打入目标内网，摸来摸去还是在当前的网段里，即使偶然获取到目标的拓扑图，明确知道当前网段存在三两台跳板机可以通往别的网段，但也不知道这三两台跳板机在哪，到底是哪一台，整段的渗透挨个去看又不太现实费时又费力，还增加暴露自己的风险。


其实关于如何快速获取内网主机的网卡信息这件事，搞了那么多内网和打了那么多次 HW ，深知其重要性，之前打 HW 的时候，就经常遇到这个问题，但苦于没法快速确定多网卡主机从而渗透更核心的网段，而错过了很多目标，后面和其他队的小伙伴交流的时候才知道原来那个网段还可以通某某段、某某域里面有某某目标。


我最开始的解决方案是对比主机名，但是效果很不理想。后面查了一些资料，也发现国外大佬们写的一些脚本，遇到了几个脚本能达到预期的部分效果，一直也在将就着用着，直到前段时间忘记是哪位群友发了国外的一个链接（原文链接在末尾，感谢群友分享），我看过后发现这就能达到我想要的效果激动的要死 :)，然后自己改了改就有了现在这个脚本。


脚本

Python3 环境运行，需要安装 eventlet 和 impacket 库

 usage: GetIPinfo.py [-h] [-i IP] [-t TIME] [-f FILE] [-o OUT]
 
 optional arguments:
   -h, --help            show this help message and exit
   -i IP, --ip IP        IP
   -t TIME, --time TIME  interval time default 3s
   -f FILE, --file FILE  IP List
   -o OUT, --out OUT     Save File

扫描单个IP

 python3 GetIPinfo.py -i 192.168.0.1

扫描整个 C 段

 python3 GetIPinfo.py -i 192.168.0.1/24

读取指定文本扫描（文本一个 IP 一行，不带端口）

 python3 GetIPinfo.py -f ip.txt

其他

 -t 每个 IP 连接的时长，默认三秒，网络不好的情况下建议调高
 -o 保存文件
    每次扫描后都会将结果到当前文件夹，文件名为: 年月日时分秒_scan.log
