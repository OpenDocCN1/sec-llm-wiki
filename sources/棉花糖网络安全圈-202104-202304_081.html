burpsuite_pro_v2022.11

    1.首先运行reset_license.bat

然后运行ja-netfilter.jar的包，我的java环境是java11的版本

java15也行，其他未测试

java --add-opens=java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED --add-opens=java.base/jdk.internal.org.objectweb.asm.tree=ALL-UNNAMED -jar ja-netfilter.jar -r

2.运行burp的包

java --add-opens=java.base/jdk.internal.org.objectweb.asm=ALL-UNNAMED --add-opens=java.base/jdk.internal.org.objectweb.asm.tree=ALL-UNNAMED -javaagent:ja-netfilter.jar -jar burpsuite_pro_v2022.11.jar

复制左边这段内容进这个框框然后下一步

3.这里点击红框内的选项


4.点击（1）按钮，黏贴到(2)框里

5.复制下图（3）全部内容到（4）里面，然后next


6.然后出现success就搞定啦，之后的使用都要使用上述启动burp的命令才能是破解版哦
