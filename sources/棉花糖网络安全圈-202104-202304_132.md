## Linux更新

1.  停止Nessus服务

```
systemctl stop nessusd  #停止Nessus服务

```

> 注意：如果您之前按照《关于Nessus\_Pro插件202205112225食用方法》升级，切记执行以下命令取消`plugins`目录下所有文件只读权限

```
find /opt/nessus/lib/nessus/plugins/ -name "*.*"
 | xargs -i chattr -i {}##执行时间稍微有点长，因为插件数达14W+

```

否则会提示文件没权限操作，如下图所示

![](../Images/7b3e74413f61b97d3423f1e9c8e7f077.png)

提示操作不允许

2.  接下来就跟上次步骤一样，不啰嗦了

```
/opt/nessus/sbin/nessuscli update all-2.0_202206011352.tar.gz #升级

#取消之前设置的只读

#替换新的inc

#设置只读

"*.*" | xargs -i chattr +i {} #设置plugins全文件只读

#取消该文件的只读


```

## Windows更新

Window类似，就是换了个命令

```
net stop "Tenable Nessus"

 "C:\ProgramData\Tenable\Nessus\nessus\plugin_feed_info.inc"  #取消之前设置的只读

"C:\ProgramData\Tenable\Nessus\nessus\plugins\*.*"   #取消之前设置的只读

"C:\Program Files\Tenable\Nessus\nessuscli.exe" update "{your_path}\all-2.0_202206011352.tar.gz"  #升级

"{your_path}\plugin_feed_info.inc" "C:\ProgramData\Tenable\Nessus\nessus\plugins\" "C:\ProgramData\Tenable\Nessus\nessus\"   #替换新的inc

"C:\ProgramData\Tenable\Nessus\nessus\plugin_feed_info.inc"   #设置只读

"C:\ProgramData\Tenable\Nessus\nessus\plugins\*.*"   #设置plugins全文件只读

"C:\ProgramData\Tenable\Nessus\nessus\plugins\plugin_feed_info.inc"   #取消该文件的只读

"Tenable Nessus"
 
```
