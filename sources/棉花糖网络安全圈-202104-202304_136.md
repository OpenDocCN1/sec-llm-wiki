## Linux更新

1.  停止Nessus服务

```
systemctl stop nessusd  #停止Nessus服务

```

> 注意：如果您按照上一篇《关于Nessus\_Pro插件202205112225食用方法》升级，切记执行以下命令取消`plugins`目录下所有文件只读权限

```
find /opt/nessus/lib/nessus/plugins/ -name "*.*"
 | xargs -i chattr -i {}##执行时间稍微有点长，因为插件数达14W+

```

否则会提示文件没权限操作，如下图所示

![](../Images/01f96da8e9ad2e703498636d448af960.png)

提示操作不允许

2.  接下来就跟上次步骤一样，不啰嗦了

```
/opt/nessus/sbin/nessuscli update all-2.0_202205202157.tar.gz #升级

#替换

#设置只读

"*.*" | xargs -i chattr +i {} #设置plugins全文件只读

#取消该文件的只读


```
