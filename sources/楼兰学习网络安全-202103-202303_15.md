2、CodeQL 标准库

包含了必须的一些标准库(内置库)和一些查询样例。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

https://github.com/github/codeql

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

三、编写第一个查询

![](../Images/7a449fe6e137819055c850de745f83c3.png)

1、下载WebGoat

因为我本地的Java环境是1.8的，WebGoat在新版本中已经不支持Java 1.8，所以通过如下命令下载一个支持Java 1.8的旧版本的WebGoat

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

git clone --branch v8.0.0 https://github.com/WebGoat/WebGoat.git

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

![](../Images/7a449fe6e137819055c850de745f83c3.png)

2、创建CodeQL数据库

备注：需要已经安装Maven，因为WebGoat项目是基于Maven构建的，CodeQL在创建数据库时，会自动探测并使用对应的编译方式。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

在WebGoat根目录下面执行如下命令，会自动编译并且为该项目创建一个名为webgoat-qldb的QL数据库。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

codeql database create webgoat-qldb -l java

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/c0e7a2aca50c32af0b2391557f51c2e8.png)

创建完该项目的数据库后，该项目的源码文件在后面几乎就用不到了(除非像更新QL数据库这种需求)，CodeQL查询时主要使用的便是该项目的数据库文件。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/f2858fe06ab7378a42f4d8c4e696387e.png)

![](../Images/7a449fe6e137819055c850de745f83c3.png)

3、创建你的第一个QL包

你需要创建一个文件夹，用来存放后续你编写的CodeQL脚本，CodeQL官方称这个文件夹为QL Pack。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

例如名为example-query的文件夹，并在里面创建1个QL Pack的配置文件，名称固定为\`qlpack.yml\`;再创建一个ql后缀的文件，名称随意。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/f42ed185ed74e090fb4ee4ab9a6e7cc9.png)

在VSCode中打开这个文件夹

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/6d9706fa75dbc7b42db2c088a64afceb.png)

![](../Images/7a449fe6e137819055c850de745f83c3.png)

4、编写QL包的配置文件

将如下信息填入qlpack.yml文件

name: example-query

version: 0.0.0

libraryPathDependencies: codeql-java

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

第一行表示这个QL包的名称为example-query，必选，如果你在VSCode中同时打开多个QL包时，要保证这个name的值唯一不重复;

第二行表示这个QL包的版本号，必选;

第三行表示这个QL包的依赖，必选，codeql-java表示需要Java语言的QL标准库依赖。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/4d5b06107e289ae7b056bdbf1d67e4f0.png)

![](../Images/7a449fe6e137819055c850de745f83c3.png)

5、VSCode工作区增加CodeQL标准库

为了让CodeQL解释器能够访问标准库，我们需要将标准库所在文件夹也加入到加入工作区中。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

VSCode - 文件 - 将文件夹加入工作区 - 选择在【环境准备 - CodeQL标准库】章节中存放CodeQL标准库的文件夹。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/51c23574bf7077bd03d4d4943d32b92c.png)

![](../Images/7a449fe6e137819055c850de745f83c3.png)

6、VSCode添加CodeQL数据库

在VSCode的CodeQL插件中添加之前用CodeQL创建的WebGoat的数据库。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/c02a47e6113dd111eb01d1f70211d5a5.png)

选择webgoat-qldb那个文件夹。如下是添加成功后的页面。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/8b532e3bd781593e6082479422ddc93d.png)

![](../Images/7a449fe6e137819055c850de745f83c3.png)

7、编写第一个查询

在webgoat-queyr.ql文件中编写如下代码，用来查找WebGoat项目中所有声明的方法。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

import java

  

from Method m

select m

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)

然后右键点击【CodeQL: Run Query 】来执行本次查询，执行完成后在右边可以看到多出一列用来显示查询结果。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/2b45886d4e591887803e3c257ac763f8.png)

点击结果里面的任意条目，可以跳到对应的文件中。

![](../Images/cff1ea77aea016c678b28ff84a2d0c06.png)![](../Images/8840cfd18f67286cb8fc9596adb87e3c.png)
