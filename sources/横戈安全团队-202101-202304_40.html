0x02 任意用户登录

文件：stylei/MainPage.jsp

代码：

String token=request.getParameter("token");YxrSingleObjectAuthorUser curUser=YxrPlateSystemLogin.getCurrentLoginUser(token);


逻辑应该是获取token，然后带入YxrPlateSystemLogin.getCurrentLoginUser方法校验，跟踪过去

 public static final YxrSingleObjectAuthorUser getCurrentLoginUser(String token) {        YxrModelUserToken userToken = (YxrModelUserToken)TOKEN_USER_MAP.get(token);        return userToken != null ? userToken.sysUser : null;    }


获取token，如果token存在返回userToken.sysUser否则返回null，而token他定义在了静态代码块里面
