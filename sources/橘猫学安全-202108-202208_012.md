*   更新工具：
    
    ```
    npm 更新 -g infoooze
    ```
    
*   要获取所有基本选项的列表，请使用 -h ：
    
    ```
    infoooze -h
    ```
    
*   获取 Instagram 用户信息：
    
    ```
    infoooze -i instagam
    ```
    
*   获取域的 Whois 信息：
    
    ```
    infoooze -w google.com
    ```
    
*   要获取网站的子域：
    
    ```
    infoooze -s google.com
    ```
    
*   获取 IP 信息：
    
    ```
    infoooze -p 8.8.8.8
    ```
