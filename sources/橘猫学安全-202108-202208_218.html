一款SRC密码生成工具，尝试top字典无果后，可以根据域名、公司名等因素来生成特定的字典

0x01

PwdBUD仅需三个参数，以域名或公司名为索引生成字典。

0x02

-d --domain    #域名

-c --company   #公司名

-o --outfile   #必须，输出文件
python pwdbud.py -d jd -c jingdong -o res.txt
