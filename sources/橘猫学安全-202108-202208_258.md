# **外围打点**

  

最近想练一波内网渗透，于是就fofa批量了一波weblogic，挑了一个国外的机子

这里用工具发现存在漏洞CVE-2017-10271和CVE-2019-2725

![](../Images/2699d8af8ef9ac6604f4f26e19e0618b.png)  

这里我选择了用CVE-2017-10271，先命令执行一波，发现是台Windows的机子

![](../Images/1065c117252b4771083344ecfdb371c2.png)  

先传个冰蝎shell上去吧

![](../Images/86584d8e1a9e14434e4008a99e5ae561.png)  

冰蝎连接成功，先内网信息收集一波

![](../Images/94dc992f19348d8351f0f0f5efd255ab.png)  

一台winserver2008的机子，我们可以抓到明文密码，并且存在域，打了303个补丁(丧心病狂)

  
查看一下有无杀软

![](../Images/3c156bdf35a4227ceed8c51d0b4780f2.png)  

不存在杀软，那么Beacon就不需要免杀处理，我们可以直接上线CS(这里上线的Beacon配置了云函数，所以外网ip是一直变的)

![](../Images/869a0e643684bd805fc030f7ced6d460.png)

# 内网信息收集

  

上线首先做个进程迁移，选择一个常见的进程注入  
、![](../Images/27d578f3f98afb4dd0d861ebc2c917b9.png)  
![](../Images/4e18875c35e81f7db963f16ce81bcd9d.png)  

这里我们进行内网信息收集

  
内网首先目标是打域控

![](../Images/a4e917b85ed800ae8077eaf11b20daf2.png)  
好家伙，6个域控，之后查看域管  
![](../Images/68daebf0c2bfc8f0ef8360e90a150384.png)  

这么多域管，意味着我们只要能拿到一个域管的权限，这个内网就能漫游了  
首先来看看能不能在当前机子进行提权，因为前面303个补丁，我感觉都提不动了

  
经过提权尝试后，发现常规的提权洞都打了补丁，没办法，当前机子是管理员权限，并且没有杀软，先来抓一波hash

![](../Images/b651e260167dfd629f98ec02c6610591.png)  
![](../Images/f4126c3e8020c992b5248d0ed8fba8be.png)  

接下来，使用CS自带的扫下内网存活

![](../Images/a8c75646df657ef3dd447abe6ade74b4.png)  

出现了两个域控，目标非常明确了，那么下面尝试用抓取到的hash进行psexec横向移动

  
经过多次尝试后，发现两个域控均不能横向，且其他机子无果

下面直接上内网大杀器MS17010!

使用Ladon快速探测存在MS17010的主机

![](../Images/227d1760bf879ec491a835f9bacd0997.png)  
![](../Images/a52c2d84f64d797f672260099f24f265.png)  

初步探测两个域控均存在MS17010,这里使用Landon自带的exp,发现利用失败。既然这样，那么上线MSF吧

# MSF和CS联动

  

首先看了下，目标是出网机器

![](../Images/12c0cf879b326ac9a9d790a852ab6b6c.png)  

之后尝试使用frp，nps等常规代理想把流量代理出来，发现无果，猜测目标做了限制，那么我们直接用公网的msf吧。

  
CS4.3版本移除了foreign/reverse\_tcp

所以我建立了一个foreign/reverse\_http的listener，msf监听后，

CSspwan，成功获得一个meterpreter

![](../Images/027701bb2f9be802a360a2465666e3ca.png)  

下面我们添加路由

```
1.  `run get_local_subnets`
    
2.  `run autoroute -s 10.0.10.0/24`
    
3.  `run autoroute -p`
    
```

![](../Images/e38612e39824979306b81619b2a17349.png)  

那么对ip为10.0.10.1的域控用MS17010打一波

这里使用ms17\_010\_eternalblue这个exp一直打不成功

那么我们换个exp打  
![](../Images/60b16da10b8bf3b9356a71431a346a71.png)

成功获得一个session！  

![](../Images/8b006aa76ea93f4d5be08120231a6a95.png)  

下面我们把这个刚刚获得的session转发回CS

![](../Images/62d0e94a9529c27cca9b5311cf22a172.png)  

成功反弹

  

  

![](../Images/057e4afccb1a8bcc243b2fd09c36f33f.png)

  

# 横向其他域控

  

我们已经拿下一台域控了，那么其他5台就可以都拿了

  
我们先对这一台做个信息收集

  
老样子先进程迁移一下

![](../Images/7d91fa3cbc4eaf9e449aa3c9e8b3ded3.png)  

抓下hash吧

  

![](../Images/469ef2a4db7fc0049d606b70d5f14854.png)  

  

好家伙，为空！！！！

  
那么直接试下横向呢

![](../Images/10253f7a5d9d7dd05f01fcd9868eecbe.png)  

也不行！

  
回想在和MSF联动的时候，本地路由还有个26网段，那我们在基于当前域控再做一波内网探测

![](../Images/63dec179e35a21d8dda28c8da193cd31.png)  

又发现一个DC

  
再试试横向一下，仍旧失败

![](../Images/3691d262dbdd840477c569c9bf9a68c5.png)  

后来尝试了ipc，wmi也不行

  
这时，我突然想到，既然已经拿到域控了，那么我自己创建个域管不就可以了吗

![](../Images/94eb30b4f8fbc848f3872eda5e076384.png)  
![](../Images/64ce18305e2ce8e8b9c213db1f3a8a8d.png)

  
那么换域管登录，这里我尝试在拿到的域控切换，但是不行，那么我们就换那个跳板机吧

![](../Images/c21cd92998b6dfc117293af58b79cfa6.png)  
成功切换

  
那我们以域管身份的session进行横向

![](../Images/219b86cfd3d4361bf579b9957dee025d.png)  
![](../Images/585e5b122acf855db309f0ebff5397ce.png)  

同样另一台域控

![](../Images/a4a6ec9c9ebba5bb1273db9989067718.png)  

在第三台域控可以抓取全部hash

![](../Images/e40126ed431ba5291a3c9566463ebe22.png)  
![](../Images/2f00d9f0d8a1ea4ece5364dcd2d4de81.png)  

后面三台域控发现ping不到且探测不到，那么对已有的机子做个简单的权限维持后，本次内网渗透结束。
