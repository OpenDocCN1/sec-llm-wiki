![](../Images/bf7358faee83121de64fcafe93bd59ce.png)  
  
二、实施步骤  
  

1.Hacker 克隆钓鱼网站，以 139 邮箱登录网站为例：http://mail.10086.cn，在用户 A 上进行测试目标网站是否克隆成功，查看 hacker 和用户 A 的 IP 配置。

  
（1）用户 A（windows server 2003）的 IP 配置  
  
![](../Images/e69bc0f05e337a7219369d76a324af17.png)  
  
（2）Hacker（kali）的 IP 配置  
  
![](../Images/356409813c1aea86b6f65196cac5df3d.png)  
  
2.在 KALI 终端 输入 setoolkit 打开 kali 自带的社会工程学工具集

![](../Images/6e64d9a400a669ced91ab81b9a599003.png)  
  
3\. 输入 1，选择社会工程攻击

![](../Images/cdda4d5fb81843bc21169030365e7f6d.png)  
  
4\. 输入 2，选择网站攻击  
  
![](../Images/a4eaefc1c6fa5527e99a161c7f6199a2.png)  
  
5\. 输入 3  
  
![](../Images/42c75523e3e9f5facc1c35d2a397cfa0.png)  
  
6\. 输入 2，克隆网站和域名  
  
![](../Images/c3e5eece5b6271e2c9025d2fd06478df.png)  
  
7\. 在 kali 的浏览器上用 IP 登录克隆的网站,表示克隆成功

  

![](../Images/2c36e6b904718c97ef9c7b7de1012083.png)  
  
8\. 开启 kali 的数据包转发功能  
  
![](../Images/2450228a336950fd8ee35034b26635ac.png)  
  
9．启动 ettercap

![](../Images/55c93bd4bce88d01bac655946b309a14.png)  
  
10．编辑 Ettercap 的文件(vim /etc/ettercap/etter.dns)，

  

使得用户 A 访问 http://mail.10086.cn 时，域名解析为 Hacker 的 IP  
![](../Images/ed70e419fde40b27d12466fb684497b5.png)  
  
11．我们使用抓包的方式实现中间人攻击。

  

选择 sniff|unified sniffing|选择嗅探网卡，默认 eth0，点击确定，见下图：  
  
![](../Images/452b0e1b6ddf1acdfedd544d50ccca3e.png)  
  
12．启动接口之后，菜单栏选择 hosts | scan for hosts，就可以  
扫描所有主机了。见下图：  
  
![](../Images/67c2d688c8c0381415ffcc289abb88c9.png)  
  
13.选择 Hosts| host list，查看扫描到的主机信息。

  

该界面显示了用户 A 的 IP 和 MAC 地址。

  

见下图：  
  
![](../Images/5b471a08906ef90735cf52fb1aab1d18.png)  
  
14．从中选择 192.168.100.129 作为目标机，单击“Add Target 1”按钮

![](../Images/33498b0c003990d0ca0b249702a98de0.png)  
  
15．启动 ARP 欺骗攻击，在菜单栏中依次选择 Mitm|Arp poisoning..，然后出现弹出框选择攻击的选项，我们使用“Sniffer remote connections”，然后点击“确定”按钮。  
![](../Images/e5c6a18e10537b5387e95de3a5f81790.png)  
  
16．在 windows server 2003 上访问 mail.10086.cn，并查看 arp 缓存表

  
![](../Images/e01b9e56ef01b3ed0b4509d321b0dc38.png)  
  
![](../Images/9ddf3eb57cf6425231aedb4bf94f4395.png)  
  
17．在菜单栏中依次选择 Plugins|Manage the Plugins, 双击启用DNS\_Spoof（DNS 欺骗）  
![](../Images/bf376386d6bf2511c2a07255b4ecdd86.png)  
  
![](../Images/8cf6878e1bd9d53c0739c283873e45d0.png)  
  
18．在 windows server 2003 上访问 mail.10086.cn 时，现在已经解析为 hacker 主机的 IP  
![](../Images/c1384c012a34f251dbdb2c5e23cb9418.png)  
  
19．在 windows server 2003 用浏览器访问 mail.10086.cn，并输入用户名和密码登录 139 邮箱  
  
![](../Images/ec80b4f731237cdd45b56cf8bc21abfa.png)  
  
20．在 kali 的 Ettercap 上可以截获到用户 A 输入的用户名和密码信息  
  
![](../Images/4a7a68dec56da1c44ce814fb26fe9299.png)

  

**注:**

**ettercap**是一个基于ARP地址欺骗方式的网络嗅探工具，主要适用于局域网。ettercap是一款现有流行的网络抓包软件，它利用计算机在局域网内进行通信的ARP协议的缺陷进行攻击，在目标与服务器之间充当中间人，嗅探两者之间的数据流量，从中窃取用户的数据资料。
