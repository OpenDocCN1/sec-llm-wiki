你用 Chrome 浏览器，都都喜欢用什么插件呢？

给大家看看我的：

![](../Images/c1f35d856d696ba40c93f57915e5bcc9.png)

今天，推荐一些常用的 Chrome 的插件，还是非常不错的，大家可以用起来看看。

## 前言

相信很多人都在使用 Chrome 浏览器，其流畅的浏览体验得到了不少用户的偏爱，但流畅只是一方面， Chrome 最大的优势还是其支持众多强大好用的扩展程序（Extensions）。

下面的很多插件都是工具插件，看完保证你工作效率、心情提高 1 倍。

### 1、OneTab：一键合并 tab

Tab 过多的时候，要关闭浏览器的时候OneTab可以帮助你快速的保存、整理浏览器。

![](../Images/f1b191464eb438932ca3f06ffc571f54.png)

### 2、Adblock Plus：免除广告困扰

各种网站都有广告，看烦了，不妨试试 Adblock。

![](../Images/17b79ee2dabc2436eb6bf57d5cd49380.png)

我最常用的插件，没有之一！

### 3、markdown here

超好用的 MD 编辑器，任何地方都可以把 MD 轻松的转换为富文本，我们可以把简书写好的文章（带md语法）直接复制到微信公众号啦。

![](../Images/13b664984d7eb6b01f4b64f3a5e229a7.png)

### 4、LastPass：密码管理软件

LastPass，全球知名在线密码管理工具之一，采用军事级加密算法，支持自动填充网站用户名和密码，与朋友分享登录信息等实用功能，且在全平台同步免费，无需订阅 Premium，即可在手机、网页、电脑端同步你的所有 LastPass 信息。

![](../Images/a228714da57e5681f03421e619cc4e2c.png)

### 5、二维码(QR码)生成器

在线的二维码生成器。最方便的用法是把当前的页面生成二维码，方便手机扫码快速访问。

![](../Images/4047543a3b8d5d3d7af9851b966d580e.png)

### 6、下载+

Chrome的下载管理在二级菜单里，进去很不方便。装了这个插件就可以直接看和管理，很好用。

![](../Images/e349f9556f3ca3b7628cb7648de5afbb.png)

### 7、Github 加速器

一键加速 Github 访问速度，当 Github 访问慢的时候点击右键直加速，同时支持多个加速镜像。

![](../Images/83281851a0ccb687ece2947af95cec23.png)

### 8、购物党

在线的比价工具，剁手党们赶紧装起来。

![](../Images/3334fe38b10ab77bdec4243672f5cf4e.png)

### 9、crxMouse Chrome Gestures

对于国产浏览器自带鼠标手势的功能，真觉得很方便！有了这款插件，也足够让你装B了。

![](../Images/4b61f77f538660260a6e0ec6e9cd6709.png)

### 10、Imagus

图片放大镜的功能，在浏览新闻和博客的时候想右键看一下高清图，有了这个插件完全不用，鼠标悬浮就能看高清图片。

![](../Images/32afac4695d9f37d88a2a580b35edcd5.png)

### 11、Save to Pocket

看到感兴趣的先收藏着，然后走哪儿都能看，并且它由各个平台的版本支持，同时可以自动去广告，只把关键的内容保存，这样非常方便各个平台阅读。

![](../Images/142d4c1b38f77dfac7333a3c954d54fc.png)

### 12、网页截图:注释&批注

网页截图，批注工具。

![](../Images/0c45f05e3fa858801ee9661053ef0b23.png)

### 13、Image Downloader Chrome

想下载某个页面的图片，不用再去资源里面一个一个看了，直接安装这个插件，一键就可以下载。

![](../Images/7cae5bc71b0b1e1acca4c49a384ab27d.png)

### 14、Google翻译

Google翻译是一款由谷歌公司提供的网页划词翻译插件，它支持动态的划词翻译功能，也支持网页翻译，真是阅读外文网站的好帮手啊。

![](../Images/b875c4d49d47444c5b36eabd68dc824b.png)

### 15、Lucidchart Diagrams

绘制各种流程图手头没有趁手的工具，直接试试这个工具哈。

![](../Images/fcc0efce0118c83d0b418e54fbad0f2d.png)

### 16、New Tab Startup Quotes

学习成功人士的格言

每次打开新的 tab 都会有一个名人名言，不过是英文的，得思考一下才能理解其中的奥妙，如果你能做一个中文版就好了。

![](../Images/e8e5c2913963a12b649411f5ebd66c21.png)

### 17、Search by Image

强大的以图搜图

发现了一个图片，但是不知道他是什么，或者想搜索一些类似的，那么就用这个插件。

![](../Images/67fb51e354e03d6463cd3982086b3cfc.png)

### 18、为什么你们就是不能加个空格呢

自动把网页中所有中文、英文、数字、符号之间插入一个空格

![](../Images/924610d6961ce1cfec42c4bab4eadf4e.png)

### 19、Clear Cache

点击图标即可清除缓存、cookie等，开发必备！

![](../Images/08996eedc4e950fb6a13cf0c289f3bb7.png)

### 20、JSON Viewer

JSONView 是一个方便查看 Json 结构的插件，展开，折叠，可以非常方便的查看接口返回数据。

![](../Images/4b2333ec169de729c5680c1dbfbb9a44.png)

### 21、Postman

相信开发者朋友一定知道这款插件，非常方便的调用和调试 API 接口。

![](../Images/8afee809ff754912ff091d41cbc6dfa8.png)

### 22、Octotree

github上查看代码的时候总是一层层进入再出来，有点麻烦，有了这个插件，你可以想浏览本地 IDE 一样浏览 Github。

![](../Images/2a7f5a3b4f7af70addd6d5176a90faea.png)

### 23、Table of contents sidebar

Table of contents sidebar 可以让你在阅读很长篇幅的文章时候清晰的看到文章轮廓。

![](../Images/fcd20573b2fb4c404ee26260448fcf9c.png)

### 24、Tampermonkey

俗称‘油猴子’，方便的管理插件的插件，你试试就知道如何的优秀。

![](../Images/36be6813bd64a8238d80941eaaf425d9.png)

### 25、Code Cola

Code Cola是一个可视化编辑在线页面css样式的chrome插件。

![](../Images/f90042eb7f8459240535187f3596a798.png)

### 26、WEB前端助手

FE助手：包括字符串编解码、图片base64编码、代码压缩、美化、JSON格式化、正则表达式、时间转换工具、二维码生成器、编码规范检测、页面性能检测、栅格检测、JS运行效率分析等等你日常生活中不可缺少的插件。

![](../Images/336c852653a87f4713ffb4d89aa256d8.png)
