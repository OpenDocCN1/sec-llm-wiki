# 神兵利器 | 日常渗透批量刷洞Tools

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTY2NjUxMw==&mid=2247506264&idx=1&sn=7ef5c18a53dc574a36ad9dac3644e957&chksm=c04d5e66f73ad7703ac49aff69b79b6def69194be3bac140c88fd205f8d819adfb1acad2e734&scene=126&sessionid=1681662819#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTY2NjUxMw==&mid=2247506264&idx=1&sn=7ef5c18a53dc574a36ad9dac3644e957&chksm=c04d5e66f73ad7703ac49aff69b79b6def69194be3bac140c88fd205f8d819adfb1acad2e734&scene=126&sessionid=1681662819#rd)

一、工具介绍  

一个既可以满足安服仔日常渗透工作也可以批量刷洞的工具盒子。集合了常见的域名收集、目录扫描、ip扫描、指纹扫描、PoC验证等常用工具，方便安服仔快速展开渗透测试。

  

二、运行界面

1、基于Win环境下运行cmd /k 即可新开cmd窗口，除collect\_subdomain之外，其余工具均可无需等待当前命令执行结束直接执行下一条命令。且支持TAB键关键字自动补全。

![](../Images/479d573e69d82aaa33977a40506f5a54.png)

  

2、命令执行结束后，在results文件夹下可查看输出的报告(Finger扫描的结果在tools/collect/finger/output文件夹内)

![](../Images/5bfa5162d44ad544c218ee0a39a85b50.png)
