最近一直在打攻防，很多时候都需要用到免杀，那么怎么能快速做免杀和权限维持就是一个问题，于是就想起来**利用白加黑快速做免杀或权限维持**，俗称有手就行，废话不多说直接开干！

## **寻找合适文件**

文章主题是白加黑，肯定是需要寻找一些合法的程序，我们这里利用dll劫持去做白加黑免杀或权限维持，所以尝试是否存在有可以劫持dll的exe文件。平时大家应该都会用到网抑云音乐，所以就想着拿它做一个例子，文件夹内共发现这么三个exe。  
![](../Images/da09312a78e977722ab437407a89141e.png)  
在尝试的过程中发现cloudmusic\_reporter.exe(并发现是32位程序)单独复制出来运行会产生报错缺少dll文件。  
![](../Images/46f50b6e21d83442544d5192dd3f7b18.png)将缺失的dll文件复制到相同文件夹后即可成功运行，而且他并没有对dll文件做签名校验。  
![](../Images/a4cd71dd64b1d937f559d25fa6efd4f7.png)

## **分析生成**

打开Visual Studio创建C++win32动态链接库项目。  
![](../Images/ec8b7d2015c3a817b3875549ea45d2dd.png)将之前生成的三个文件复制到项目文件夹后手动拖入到解决方案，并在入口处引用头文件。  
![](../Images/ec45f23ad5ff5d2bcd2e70008a71a919.png)接下来看一下具体这些文件都有什么作用。libcurl.c这个文件运行的时候会获取dll内的函数并将其保存到指针内。指针会去改变原本的函数地址进行链接，使用汇编的方式进行跳转，也就是libcurl\_jump.asm这个文件。  
![](../Images/46d706447b1a6eb00d6f9e0038711cdc.png)由于不需要用到跳转所以采用最笨的方法，去汇编文件内手动删除跳转。  
![](../Images/4bee9167d83c89d55d819a038b04fd91.png)汇编文件需要手动配置，具体怎么配置在文件最开始处已经标明了。  
![](../Images/23ce69dfa61bd59001e9bd07877525f1.png)尝试生成，发现可以成功生成就可以了。![](../Images/d453acbbf1e6cfa9a1e25366b832e36b.png)

## **shellcode加载**

  
直接百度找一个傀儡进程注入源码复制进去即可。  
![](../Images/c0bdb0808d005c405217f5bba4fb4551.png)随后打开CS生成一段32位的shellcode保存。并复制到源码内，根据粘贴进来的shellcode对源码进行修改完善。这里将修改好的源代码贴出来方便大家复制。

```


// dllmain.cpp : 定义 DLL 应用程序的入口点。
```

生成dll文件，并将其重命名为libcurl.dll，与cloudmusic\_reporter.exe放在同一文件夹内，双击运行查看是否上线成功。  
![](../Images/336efe8acc6d7d4539ef8a2a05de4707.png)这样还是不够的，因为没有加密处于裸奔的状态，写个加密算法又很麻烦，这就想到了把shellcode存放在图片内进行隐写。这里需要用到开源的工具  
github:https://github.com/Mr-Un1k0d3r/DKMC利用工具配合shellcode生成图片。  
![](../Images/ccad6026d37ac7484089bcd32d0ca72b.png)随后继续更改源代码，从图片文件读取shellcode。源代码如下：

```


// dllmain.cpp : 定义 DLL 应用程序的入口点。
```

生成dll文件，在将exe，dll及图片放在一起再次运行查看是否可以成功上线。  
![](../Images/1981da09bb24780e1619c30416eac2f5.png)免杀效果在VT上查杀dll和图片分别是4、5，这是没做任何加密的情况下，总体来看效果还算不错。
