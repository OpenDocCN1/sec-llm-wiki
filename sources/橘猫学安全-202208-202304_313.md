# 渗透测试实战分享—从app到网站沦陷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTY2NjUxMw==&mid=2247500300&idx=1&sn=5205324a697af3aeae4b021c0ef6da83&chksm=c04d4532f73acc249c42fba33f1864bcdce7f15cf3f480253b5c725a61bc16a28efecdba66c7&scene=126&sessionid=1681662885#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTY2NjUxMw==&mid=2247500300&idx=1&sn=5205324a697af3aeae4b021c0ef6da83&chksm=c04d4532f73acc249c42fba33f1864bcdce7f15cf3f480253b5c725a61bc16a28efecdba66c7&scene=126&sessionid=1681662885#rd)

分享一下今天对某 app 进行渗透测试，从基础的信息收集到拿到网站的 shell。总体来是还是很简单的

  

1.使用模拟器挂上代理并对 app 进行抓包，我们把其域名给拿出来

  

![](../Images/1005ce9cae4ef0ee7c6d6ae434c93752.png "null")

  

1.使用工具对主域名进行敏感目录扫描，发现存在一个 admin 的目录

  

![](../Images/ebace07c05e1a3f11e98268b3ff88cbb.png "null")

对该目录进行访问，发现存在管理后台，且目前看没有验证码，可以尝试爆破

![](../Images/535d1ba8b3127bf1f19a79f3fce8301d.png "null")

输入不同的账号，看是否存在用户名枚举，如下输如 admin 显示账号或者密码错误

![](../Images/a722825ef775c9ea9f72cfbf87d2f6e2.png "null")

输入 admin2 显示账号未注册，所以此处存在账号枚举漏洞

![](../Images/131c2f3711b65962dcc629f5f0f58b23.png "null")

  

1.进行表单爆破

  

使用 burpsuite 先进行枚举存在的账号，测试发现存在 admin 和 wangjie 两个账号

![](../Images/4a9144e1909d2eac8dcf64fdc6281ebb.png "null")

使用这两个账号然后对密码进行爆破。因为该密码进行了 md5 加密，所以爆破前进行 md5 加密就行。如下成功爆破出来了

![](../Images/80e68b954acba89f9a82d33af4753328.png "null")

对 md5 进行解密，发现密码就是 123456，这密码也够 nice

![](../Images/041a056ef3febf2ae69fc3e491f6b913.png "null")

  

1.使用该账号密码成功登陆后台

  

![](../Images/3d50618ae6233db334056926efcb341f.png "null")

接着寻找可以利用的漏洞点，然后发现存在文件上传的地方，随便传了个后缀的文件过去，发现能上传成功

![](../Images/84ee7613cbc7d37b5114781f4457a4b9.png "null")

  

1.辨别网站使用的脚本语言

  

由于在 http 请求数据及浏览器插件中都没找到该网站使用的什么脚本语言。于是我搜索该 app 对应的公司，然后看他们公司的招聘岗位。发现正在招聘安卓开发，好家伙，那不就是 java 吗

![](../Images/a0a048e55245e0ec958dc77c27de4b0e.png "null")

  

1.上传 jsp 冰蝎🐴

  

![](../Images/2ece199bccf1ae73f9f0be6b005d1a9a.png "null")

访问马子，没啥反应，估计行了吧

![](../Images/11821525d11729dc556a1f63c38207a8.png "null")
