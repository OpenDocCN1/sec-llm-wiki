#### 1、帝国CMS 后台GETSHELL

图书馆的一个系统，为开源CMS修改的，然后通过版本探测与其他的信息收集，发现那个版本好像有一个getshell，不过是后台的，尝试一下，账号admin密码123456发现对了之后GetShell了//这个是当时的payload![](../Images/ee3930087760181cb54264351cd0d150.png)![](../Images/4efbdbbbc85d3832f2023cb78402d17b.png)点击提交后访问

*   

```
`http://xxxxx:port/e/admin/R3inSecurity\_Team.php`
```

然后使用菜刀连接就可以了![](../Images/03b04da5398ddd21408c8621c5ba2264.png)不过需要注意的是，这里执行cmd命令会发现其实不是administrator，需要提权，因为当时除了这里其他地方已经获取到了administrator权限， 所以这个shell就没有提权
