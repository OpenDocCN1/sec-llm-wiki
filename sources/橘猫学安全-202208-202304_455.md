> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTY2NjUxMw==&mid=2247497720&idx=1&sn=4d8d6bd6e8feb67be4298b9bb8214528&chksm=c04d70c6f73af9d072fbdb5199e0e9ff9553b4ea54b24005c27b5457c1a17127e1e5dffd2d70&scene=126&sessionid=1681662920#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTY2NjUxMw==&mid=2247497720&idx=1&sn=4d8d6bd6e8feb67be4298b9bb8214528&chksm=c04d70c6f73af9d072fbdb5199e0e9ff9553b4ea54b24005c27b5457c1a17127e1e5dffd2d70&scene=126&sessionid=1681662920#rd)

EDRHunt 扫描 Windows 服务、驱动程序、进程、注册表以查找已安装的 EDR（端点检测和响应）。  

  

![](../Images/3bed6868982eb454b101b70c7c6c306f.png)

## 安装

*   从发布部分下载最新版本。发行版是为 windows/amd64 构建的。
    

*   GO安装
    

*   需要在系统上安装 Go1.17+ 。
    
*   `go install github.com/FourCoreLabs/EDRHunt/cmd/EDRHunt@master`
