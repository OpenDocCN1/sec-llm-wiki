# 漏洞挖掘工具——afrog

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5OTY2NjUxMw==&mid=2247496478&idx=1&sn=f5157256f496e3667e6a7400d7dfaa7a&chksm=c04d7420f73afd360d16ae3f4c457d8411f5d05b58c16d2d6805df40f9d0c62a285bc96b8a0f&scene=126&sessionid=1681662925#rd](http://mp.weixin.qq.com/s?__biz=Mzg5OTY2NjUxMw==&mid=2247496478&idx=1&sn=f5157256f496e3667e6a7400d7dfaa7a&chksm=c04d7420f73afd360d16ae3f4c457d8411f5d05b58c16d2d6805df40f9d0c62a285bc96b8a0f&scene=126&sessionid=1681662925#rd)

一、什么是afrog：afrog 是一款性能卓越、快速稳定、PoC 可定制的漏洞扫描（挖洞）工具，PoC 涉及 CVE、CNVD、默认口令、信息泄露、指纹识别、未授权访问、任意文件读取、命令执行等多种漏洞类型，帮助网络安全从业者快速验证并及时修复漏洞。二、afrog的特点：

*   基于 xray 内核，又不像 xray
    
*   性能卓越，最少请求，最佳结果
    
*   实时显示，扫描进度
    
*   输出 html 报告，方便查看 request 和 response
    
*   启动程序，自动更新本地 PoC 库
    
*   长期维护、更新 PoC（afrog-pocs）
    
*   API 接口，轻松接入其他项目
    

三、使用方法：

1、扫描单个目标

afrog -t http://example.com -o result.html

![](../Images/3818ffc37701ec5efdda87d67abf5352.png)

2、扫描多个目标

afrog -T urls.txt -o result.html例如：urls.txthttp://example.comhttp://test.comhttp://github.com

![](../Images/5ea30061cc140d34cebd333a267868a5.png)

3、测试单个 PoC 文件  

afrog -t http://example.com -P ./testing/poc-test.yaml -o result.html

![](../Images/eb94066d0b44e24cb53c7f105afdb1dd.png)

4、测试多个 PoC 文件  

afrog -t http://example.com -P ./testing/ -o result.html

![](../Images/5c3011f3f157cf7593e9fb8cb2d2da9f.png)

5、输出 html 报告

![](../Images/43d04d6a21cf4bb33efaf2551e2ed34b.png)
