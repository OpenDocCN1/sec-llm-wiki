# 1.感知行业变化

近几年，金融领域发生了很多大事：不论是消费金融所向披靡，还是P2P昙花一现，亦或是小微信贷钝兵挫锐后整装待发，中国普惠金融总体上取得了不小的进步；再加上金融科技和监管科技的有效加持，这个行业在创新和规范上都有了方向的指引和文件的落地。

在行业退潮整顿之际，存活的机构便在紧锣密鼓做着下一步规划，银行消金、金融科技、监管科技等各领域下的各链条之间，既存在竞争，也不乏配合，当然也有猫腻；这个系统注定是复杂的，大家都在跑马圈地，力争上游。

与此同时，业内人士应该也在不断提升自己的认知和能力，扩充自己的人脉和资源，丰富自己的学识和修养。适者生存，不进则退！毕竟后浪才是方向，90后、00后马上就成为互联网的主力军了！

只要市场存在，就一定有生生不息的需求，只是玩法在变化。十年饮冰，难凉热血！在此，我们大胆做几个预测：

**①关于行业**：P2P整改之后，在没有新的商业模式出现之前，短期不会再有大的风浪，域内资源导向由外部争夺转为内部挖掘。

**②关于风控**：产品、风控、运营成为用户增长的三驾马车；风控由经验驱动转为模型驱动再转为综合驱动。

**③关于人才**：人力缺口收缩，人才缺口却增大，贵精贵专不再贵多，懂业务的技术型复合人才和懂技术的业务型复合人才会备受青睐。

# 2.分建知识体系

就未来信贷风控的整体性打法而言，结合互联网金融行业发展趋势，用江湖口吻可以将其分为五大派系，即：市场、产品、策略、模型、运营。

**市场系**：政策解读、行业研报、前沿动态、营销获客等。

**产品系**：产品设计、审批系统、决策引擎、交互体验等。

**策略系**：风控策略、定价方案、规则设计、决策科学等。

**模型系**：数据理解、特征工程、算法选择、模型部署等。

**运营系**：运营监控、客户提醒、交叉营销、用户画像等。

我们在之前的全面了解系列【风控筑基手册】中，已经按照这个体系布局行文，那么在接下来各版块内容精进的过程中，也会继续依照这个框架不断上下钻研，生成不同颗粒度的知识晶体，使业内新人学习时有所根据，老人复习时有所进步。

# 3.重塑社区结构

在智能风控领域，不乏各类知识分享平台。除了像知乎梅子行、求是汪、周立锋、黄姐姐等几位术业专攻的老师在向这个行业传道授业之外，还有像蚂蚁、同盾、平安、百融、京东等科技公司在技术和方案方面定向提升银行业整体风控水平；泥鸽靶五年匠心生产干货内容，FAL两年精心打磨培训产品，你方未罢我登场，弄潮儿向涛头立。即使略感小众，些许凉薄，这个行业内依然有一股力量在向上迸发。

正阳不才，选择专注做好这个不大的风控圈子和社群。经过1年6个月风刀霜剑的洗礼，风控版块初步重塑了社区的结构框架，大致为：普惠金融、风控圈子、风控学院、风控中心四层关系，如下图所示：

初学者**乐学**，则可以加入风控圈子，聆听前辈经验，感受风控魅力；

借助集体的力量，层层筛选，层层递进，不断聚拢，持续精专，使体系化的风控知识得以有效共享并且有序更迭，从整体上提升普惠金融风控人才的认知和实力。至于圈内个体，找准定位，快速融入，积极参与，主动贡献，方可有所成长。知识很奇妙，付出越多，收获就越多。

# 4.加入风控圈子

金融信贷领域包括非常多的关键词，如：行业、市场、业务、监管、政策、数据、风控、运营、画像、坏账、资产、图谱、供应链等，而风控圈子的主要定位，就在于包容这一切。加入圈子，可以享受圈子的所有权利，同时也意味着承担圈内的相应责任。为了有序规范社群行为，初步拟定群内成员权责明细：

【权】

1.  参与日常知识问答交流；
2.  阅读各类干货知识文章；
3.  参加风控圈子举办的活动。

【责】

1.  不分享站外广告；
2.  不诱导添加微信；
3.  不传播不良言论。

社群类型包括：**模型策略 & 业务市场 **& **外部数据 **& **职场发展 **& **企业资源**

# 5.加入风控学院

风控学院有别于风控圈子，最明显的特点就在于将圈内人群进一步做了细分和聚合，即模型系全部为模型人员，策略系全部为策略人员。以一种学院的形式管理社群，能够让其定位更加精准，知识更加专业。关于权责方面，在风控圈子的基础上，新增如下几点：

【权】

1.  参与系统知识体系的搭建；
2.  参与各类版块内容的研讨；
3.  参加风控学院举办的活动。

【责】

1.  不讨论系外知识；
2.  高质量问答；
3.  文人不相轻；
4.  对话中保护企业隐私。

社群类型包括：**风控业****务 **& **风控****产品 **& **风控****策略 **& **风控****模型 **& **风控****运营**

# 6.加入风控中心

好的知识，需要凝结成晶体，并且能够结合业务、动态更新、删繁就简、去伪存真。如果把五大派系比喻为风控学院下的五个专业，那么这五个专业就需要五个研发中心，就需要为其配备五套对应的师资。为此，特发起**【五派召仙令】**，此令一发，即日起风控学院公开长期招募五大派系知识中心主任及成员，圈内伙伴可自荐或者推荐侠客英才、能人志士且德高望重者，担此重任，共筑基石。我们需要：

**市场系**：分管市场系知识的生产、整理和输出，如行研报告的整理，监管政策的解读，时事热点的追踪等；

**产品系**：分管产品系知识的生产、整理和输出，如决策引擎技术和逻辑上的解析，风控中台的理解与搭建，用户交互、惩罚机制等；

**策略系**：分管策略系知识的生产、整理和输出，如消费贷、小微贷、现金贷、信用卡等风控策略方法论的整理，定价系统与额度系统的设计等；

**模型系**：分管模型系知识的生产、整理和输出，如模型开发方法论，个性化建模问题的梳理等；

**运营系**：分管运营系知识的生产、整理和输出，如用户画像方法论，用户运营方法论，用户数据运营监测体系等。

加入风控中心，就意味着享有更多权利，同时需要承担更多责任。权责方面主要表现为：

【权】

1.  围炉夜话，极致体验。  
    
2.  成员可以第一时间享有系内所有核心资料、人脉、招聘、知识、内容等资源；
3.  部分特殊资源，享有优先权；
4.  正阳系\-风控极客荣誉；
5.  一个不大但志同道合配合默契的风控知识社区。

【责】

1.  搭建知识体系；
2.  组织社区活动；
3.  系统思维；
4.  担当意识。

该令有赏，长期有效，小伙伴可举荐心中最佳或合适人选，一旦选中，当奖则奖。这个行业需要一些人先站出来带个头，然后才能是人才系统的整体进步。
