# 通过技术手段不进入系统重置root用户密码

****0x01 前言****

     有时候大家会拿到一台虚拟机，但是不知道账号密码。或者虚拟机中有重要东西，但是忘记了密码。这时候就可以理利用此技术在不进入系统的前提下修改密码

****0x02 实验环境****实验环境centos7

进入CentOS7 紧急模式恢复root密码

1、开机之后在内核上按↑↓键，选择第一项按下 e键，然后编辑选项

![](../Images/d640241bf4df6ac89fa860a1e5a82719.png)2、按↑↓在此位置添加：rw init=/sysroot/bin/sh

![](../Images/0241348bc8f13d87e6c45d878dc2a3b9.png)

如下图  

![](../Images/7017046ec6448bef3caa45794beeadbf.png)

不同系统这里页面可能不一样，有的人可能会是这样，将红框内的内容改成 ：rw init=/sysroot/bin/sh

![](../Images/39537c59f94887a1f1779779af02ed27.png)

如下图  

![](../Images/3593917f4a5a92e762df54a6e14f7da8.png)

3、改完之后，按下 Ctrl+X 进入紧急求援模式，依次输入以下的命令

*   
*   
*   
*   
*   

```
# chroot /sysroot   //进入系统的根目录# passwd            //重置密码# touch /.autorelabel     //创建文件,让系统重新启动时能够识别修改# exit              //退出chroot模式# reboot            //重启系统
```

![](../Images/b8953b38e8b57ffc615c7f16258b262f.png)

 重启之后，就ok，我这里selinux是关闭的。

      注意：执行passwd命令修改密码，如果系统的selinux开启着，则需要执行命令：touch   /.autorelabel 以更新系统信息，否则重启之后密码修改不会生效。如果没有开启，则不需要执行 touch命令。
