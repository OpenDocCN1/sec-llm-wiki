**0x03- kali客户端的配置  
**

  

我这里使用的是kali2022版本，此版本默认的python版本时python39

![](../Images/8b39edfd9192a9df545c2a813aad99c8.png)

  

首先需要安装venv库，kali默认没有这个库，但是直接安装也是不行的，具体步骤如下

*   
*   

```
apt-get updateapt install python3.9-venv
```

![](../Images/e121e0b76055d8f8aa609551e079fa1e.png)

  

![](../Images/2533cf09bc69f9836c6ffd36384f3468.png)

  

而后进入到http目录下，安装步骤如下

*   
*   
*   

```
python -m venv .venvsource .venv/bin/activatepip3 install -r requirements.txt
```

![](../Images/e160576ae6f1c52dab7baa63ad28900e.png)

  

安装完毕后，即可开始**mitmproxy**本地代理，**mitmproxy**工具kali是自带的，使用此工具的目的是为了能够安装CA证书，否则无法抓取https流量

**0x05- **burpsuite联动，解决乱码  
****

  

首先当然是安装bp证书，这里怎么安装就不演示了，请大家移步本人的博客

https://blog.csdn.net/weixin\_48421613/article/details/109151966

  

首先将浏览器代理设置为8080端口，为burp默认代理端口

![](../Images/a24eb470a788ee29218c2027efcf3441.png)

  

而后，进入burpsuite，点击user options，笔者这里设置的云函数代理池的端口是8081，请根据实际情况来修改

![](../Images/a47ba868d5ded6509a5b906d5b46772a.png)

  

设置完成后，重新访问浏览器，不再乱码，并且代理生效
