## 

### 新的漏洞检查

*   测试主机 CMS 主题预览 XSS ( CVE-2021-29484 )
    

### 更新

*   UI 中的引擎页面现在显示绑定到扫描引擎的目标数量
    
*   UI 中的漏洞页面在漏洞发送到问题跟踪器时显示目标跟踪器问题 ID
    
*   将 Chromium 升级到 v99.0.4844.0
    
*   现在对 GET / POST 参数进行 JWT 审计检查
    

### 修复

*   修复了几个扫描仪崩溃
    
*   许多 UI 更新/修复
    
*   修复了配置 GitHub 问题跟踪器时的错误
    
*   与 CSRF 令牌管理相关的许多修复
    
*   更好地处理 LSR 中排除的导入 URL
    
*   修复了导致预请求脚本被重命名，导致导入脚本加载失败的问题
