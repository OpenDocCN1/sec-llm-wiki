2021 年 20 大最受欢迎的黑客工具

原文：http://mp.weixin.qq.com/s?__biz=Mzg2MzYzNjEyMg==&mid=2247484711&idx=2&sn=7ad41d3974903c13df1a2b0fe593fd30&chksm=ce74dad2f90353c4dc4a801736b2660936d80a0b18da904aa0cc764d2c0b5b6e02d44387f548&scene=126&sessionid=1681666120#rd



与去年一样，今年我们对 2021 年 1 月至 12 月期间最受欢迎的工具进行了排名。

这些工具的主题集中在 网络钓鱼、 信息收集、自动化工具等。

在不详述的情况下，我们准备了 Kitploit 2021 中最受欢迎的工具的有用列表：

1、Zphisher - 自动化网络钓鱼工具




2、Dockerized-Android - 基于容器的框架，可在安全培训平台中集成移动组件



3、Emp3R0R - Linux 用户制作的 Linux 后开发框架



4、MurMurHash - 计算网站图标的 MurmurHash 值的工具，以在 Shodan 平台上搜寻网络钓鱼网站



5、CiLocks - Android 锁屏绕过



6、Viper - 带有 Webui 的内网渗透测试工具



7、禁止 - 绕过 4Xx HTTP 响应状态代码



8、AzureHunter - 一个云取证 Powershell 模块，用于对来自 Azure 和 O365 的数据运行威胁狩猎剧本



9、403Bypasser - 自动化用于规避目标页面访问控制限制的技术


10、Smuggler - HTTP 请求走私/去同步测试工具

11、Nginxpwner - 查找常见 Nginx 错误配置和漏洞的工具


12、SharpML - 机器学习网络共享密码搜索工具包


13、PeTeReport - 开源应用程序漏洞报告工具



14、Byp4Xx - 使用#Bugbountytips 中讨论的众所周知的方法绕过“403 Forbidden”消息的简单 Bash 脚本


15、SillyRAT - 跨平台多功能（Windows/Linux/Mac）RAT


16、Qu1cksc0pe - 多合一静态恶意软件分析工具


17、Android-PIN-Bruteforce - 通过暴力破解锁屏 PIN 解锁 Android 手机（或设备）


18、Arbitrium-RAT - 一种跨平台、完全无法检测的远程访问木马，用于控制 Android、Windows 和 Linuxt


19、AdvPhishing - 这是高级网络钓鱼工具！OTP 网络钓鱼

20、MOSINT - 用于电子邮件的 OSINT 工具
