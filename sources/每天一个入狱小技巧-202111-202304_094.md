与去年一样，今年我们对 2021 年 1 月至 12 月期间最受欢迎的工具进行了排名。

这些工具的主题集中在 网络钓鱼、 **信息收集**、**自动化工具**等。

在不详述的情况下，我们准备了 Kitploit 2021 中最受欢迎的工具的有用列表：

1、Zphisher - 自动化网络钓鱼工具

  

  

![](../Images/5360a68bc66acbce3cd69f2ee12e916e.png)

  

2、Dockerized-Android - 基于容器的框架，可在安全培训平台中集成移动组件

  

![](../Images/7e4b1f0d6de5ab7ca397bf7b2eff25c2.png)

  

3、Emp3R0R - Linux 用户制作的 Linux 后开发框架

  

![](../Images/9cd2eb31d3b00ebbf7d615542610248f.png)

  

4、MurMurHash - 计算网站图标的 MurmurHash 值的工具，以在 Shodan 平台上搜寻网络钓鱼网站

  

![](../Images/fdcf12a084a1d38891e5843f8d325df7.png)

  

5、CiLocks - Android 锁屏绕过

  

![](../Images/d95a3f2b3845a174dafbf8edbdfb68fa.png)

  

6、Viper - 带有 Webui 的内网渗透测试工具

  

![](../Images/6a0cb9c83582c8d755802402c91ff362.png)

  

7、禁止 - 绕过 4Xx HTTP 响应状态代码

  

![](../Images/4a638669d63c8d02d9e96297ede261df.png)

  

8、AzureHunter - 一个云取证 Powershell 模块，用于对来自 Azure 和 O365 的数据运行威胁狩猎剧本

  

![](../Images/52520fc5415aa59ee0be5fd7b59c4783.png)

  

9、403Bypasser - 自动化用于规避目标页面访问控制限制的技术

  

![](../Images/fdcd83643df14f112f02b86008c44830.png)

10、Smuggler - HTTP 请求走私/去同步测试工具

![](../Images/7c0a199d17e0b4ff360b7326b319dae6.png)

11、Nginxpwner - 查找常见 Nginx 错误配置和漏洞的工具

  

![](../Images/d2aa0d55a31d8af6899b31ecc966ff6c.png)

12、SharpML - 机器学习网络共享密码搜索工具包

  

![](../Images/e21ad7b039feae9fbccea8dd28b13602.png)

13、PeTeReport - 开源应用程序漏洞报告工具

  

  

![](../Images/ecaf55f3df6334316bad95febc2b8008.png)

14、Byp4Xx - 使用#Bugbountytips 中讨论的众所周知的方法绕过“403 Forbidden”消息的简单 Bash 脚本

  

![](../Images/171c83db42e32f2093283f5072e5eaee.png)

15、SillyRAT - 跨平台多功能（Windows/Linux/Mac）RAT

  

![](../Images/c1c1ec7e762fd37216a119f590575d8d.png)

16、Qu1cksc0pe - 多合一静态恶意软件分析工具

  

![](../Images/d07d424eef55ed5709d7c3518a917c98.png)
