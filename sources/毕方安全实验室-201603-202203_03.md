## **CodeQL介绍：**

CodeQL 是一个语义代码分析引擎，它可以扫描发现代码库中的漏洞。使用 CodeQL，可以像对待数据一样查询代码。用户可以使用 ql 语言编写自定义规则识别软件中的漏洞，也可以使用ql自带的规则进行扫描。GitHub已免费提供CodeQL ,我们可以在GitHub项目中的Action功能来使用CodeQL

## **Github CodeQL使用：**

登录github之后，先Fork一个项目，然后选择Security-Code scanning alerts-Set up code scanning:

![](../Images/a7055364bba06d4d4631692fa8376f46.png)

然后选择CodeQL Analysis，如图：

![](../Images/6cf7b3cc8b78fe9a5df93cad441a2897.png)

支持的语言：C, C++, C#, Go, Java, JavaScript, TypeScript, Python, and Ruby developers。然后会创建一个Action的模板，一般不用改动，github会自动识别项目的开发语言。

![](../Images/daeb0fdb8de08047b4802f66cb827cc2.png)![](../Images/b8a075235f3a1b4ddd2a0e2b6f1c162f.png)

提交commit即可,然后就可以在Action中看见任务了，等待扫描完成会发送邮件。

![](../Images/e646feb660f6aabb431aab6cc2d52249.png)

扫描完成之后在Security-Code scanning alerts就可以看到结果：![](../Images/beaf212f1eac9a6957fe4d38f0c0ec98.png)

查看详情，查看路径：![](../Images/daeb0fdb8de08047b4802f66cb827cc2.png)

也提供了漏洞示例，如图：![](../Images/9bc3fdac9137f6b070082225951db7df.png)

## ** 案例：**

在github找到个项目，扫描后发现一个任意文件读取：

![](../Images/2e2e668f892e9ea8b82bcfd6bbd4db37.png)  
![](../Images/0737e9f6b21397c5d589764cb1914395.png) 

分析代码，先用node启动一个http服务：![](../Images/3ed4e03df76dbc0ab16401f2b60d5f1f.png)

获取url，用?分割，然后判断最后字符串是否以/结尾,所以只需要不以/结尾的url就不会被加上index.html，这里传入/../../aaa为例![](../Images/9847d8b29856e89bb240d958c044e22f.png)

判断是否为/live\_reload,然后拼接outDistRootDir目录![](../Images/bb782276e8f8eea35fc6cd843e991aeb.png)

这个目录定义为空：![](../Images/09dd5c56bcf40cf4ec7e7dab744d1363.png)

在利用path.normalize方法将路径规范化，查看文档：![](../Images/2bfe6c7615f70c310ec533112d92b970.png)![](../Images/7ebab4be181bd8e9d716bc1d970f987a.png)

结果：/abc，如图：

![](../Images/88e9267544afc897fd2b4fcf341f90e7.png)![](../Images/e732a1274f57d566f17c953d2f0c2891.png)

结果：/aaa/abc，如图：![](../Images/a5c20d8a5a2949c8dc4337dba31d2170.png)

最终的absPath为/aaa，然后调用fs.readFile读取/aaa文件，写入res，最终导 致任意文件读取，如图所示：![](../Images/3d48d616ae9afb1a78211bc35a7564e2.png)![](../Images/e90b96d29127340510645d26a8554d99.png)

  

## **使用体验**

总体感觉不错，比较方便，感觉对javascript支持比较好，测试了一些java和C的项目，经常遇到build错误，项目大了也耗时比较久。可以本地化基础到devsecops流程中，也可以用来批量扫一些开源项目，刷CVE等。
