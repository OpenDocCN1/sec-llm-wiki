**net use**

端口：445\\主要功能是与目标机器建立 ipc 链接，查看共享文件


  

**at**  

端口 : 445\\主要功能是通过 netuse 建立的通道，对目标机器进行计划任务的下发，定时自动执行，无法手动执行

```

```

  

  

**schtasks**

端口：139\\at 在比较新的系统中，已经被淘汰了，慢慢转向了 schtasks。

```

schtasks /s 10.10.10.1 /u admin /p admin /query
```

  

  

**wmic**

端口：135\\使用 wmi 协议在目标机器上执行操作，功能强大，可以查看安装的操作系统基础信息，软件，进程列表，杀软列表，也能执行命令等等，常用命令

```
wmic /node:
```
