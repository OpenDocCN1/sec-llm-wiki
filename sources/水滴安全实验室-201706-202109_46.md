# EversecLab战队获BCTF AI对抗赛漏洞挖掘方向第一名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMDA4NDMzNw==&mid=2247484092&idx=1&sn=0156fa4d0fdb4d7061abdfc21013a363&chksm=fa567a22cd21f334203639eb27acdfa2be92cf758910bf87458ee74f40858ca4be98cdb4a1bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzMDA4NDMzNw==&mid=2247484092&idx=1&sn=0156fa4d0fdb4d7061abdfc21013a363&chksm=fa567a22cd21f334203639eb27acdfa2be92cf758910bf87458ee74f40858ca4be98cdb4a1bd&scene=27#wechat_redirect)

    在Baidu Create 2019百度AI开发者大会李彦宏向在场7000多名开发者和合作伙伴展示百度“AI成绩单”的同时，7月4日BCTF 2019-2020百度人工智能安全对抗赛新赛季开启了新征程。

     新赛季的首场预选赛较量延续了DEF CON CHINA 1.0期间BCTF线下总决赛人工智能攻防赛的“双轨赛制”，由BCTF-RHG漏洞挖掘和BCTF-RHG攻防对抗两场比赛组成。根据规则，除彩蛋题之外，本次BCTF比赛过程中全程不需要人类进行操作和干预，全部由机器人和比赛平台自动完成。

    由水滴安全实验室张红宝带队组成EversecLab战队参与了漏洞挖掘方向的竞赛。BCTF-RHG漏洞挖掘比赛，考察的是机器人在没有人干预的情况下，对于特定二进制文件进行分析，寻找到其中漏洞并利用的能力。

    漏洞挖掘方向，来自恒安嘉新EversecLab战队以斩获8道题目一血的成绩获得一等奖，HALFBIT战队、ChaMD5战队获得二等奖，丁牛科技DigApis战队、中国海洋大学Mech-whale战队获得三等奖。

    在参与比赛期间，EversecLab战队参加了其中关于“人工智能安全对抗赛热点话题”的圆桌论坛，同AI方向技术专家及参赛选手共同对现阶段国内AI攻防赛的赛制设计、考察方向及公众对BCTF新一赛季的期望、对标国际CGC机器人竞赛等话题进行了讨论。
