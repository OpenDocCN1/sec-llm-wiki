1、什么是SDR?

 

软件定义的无线电(Software Defined Radio，SDR) 是一种无线电广播通信技术，它基于软件定义的无线通信协议而非通过硬连线实现。频带、空中接口协议和功能可通过软件下载和更新来升级，而不用完全更换硬件。

 

2、BladeRF介绍：

 

可以看到六款SDR设备的对比，包括HackRF One、USRP B200\USRPB210、BladeRFx40、RTL-SDR、LimeSDR。

    


BladeRFx40是USB3.0的一个全双工28Mhz单通道一个无线电设备，射频范围在300Mhz-3.8Ghz，收发独立的12-bit精度40MSPS正交采样率，板载200Mhz ARM9处理器，搭载了可编程FPGA。

 

不像HackRF、LimeSDR、USRP还需要外部时钟虽说LimeSDR的内部时钟精度高，但是每次运行起来后FPGA发烫严重，甚至我感觉每次使用后都可以去煎一个鸡蛋了。

 

最近小编的LimeSDR已经借给小伙伴了，所以说这次给搭建写一篇关于BladeRF的频谱图成像。

当然了其实也可以利用身边的手台，进行这样的操作。

 

3、原理介绍

 

首先我给大家科普一下SSTV(慢扫描电视Slow Scan Television)，最初只能用来传输黑白图像，现在则主要传输色彩图像，慢扫描电视技术可以通过普通的3KHz话音通道传输画面，所以业余无线电爱好者的这项技术也被运用再其他领域中，称为“静止画面传输”

 

再电视、传真等技术中，自画面左端到右端的一条水平线上的像素称为一行。传送像素的顺序通常采用从画面左上角开始，自左到右、自上到下的，一行一行、逐个像素的传送，称为扫描。这样扫描一次得到的画面称为一帧。

 

本文所介绍的频谱图成像和SSTV的原理类似，只不过是将图像转换成射频信号进行发射出来，先后顺序不同，因为在频谱当中，是向下传输的，所以顺序是从图像的下方然后向上进行发射射频信号，来产生频谱图，而在这里只是能传输黑白的图像罢了。

 

4、动手操作

 

接下来我们就讲解一下，如何利用BladeRF x40进行频谱图成像。

 

（1）如何安装并修改图像


首先git clone 

https://github.com/polygon/spectrum_painter

 在这里下载完毕后直接运行的话会缺少三个依赖，click、numpy、scipy

 首先切换到spectrum_painter

 cd spectrum_painter

 

 然后执行

 pip install --user -e .

 

 再切换到cd spectrum_painter

 执行python img2iqstream.py --help

 

 可以看到选项设置



-s 设置采样-l 每行显示时间-o输出生成的文件名--format是输出的格式这里的话分别有float、bladerf、hackrf、

然后再当前目录执行

python img2iqstream.py -s 1000000 -l 0.004 -o Eversec.bladerf --format bladerf examples/water.png


我这里的话生成的是Eversec.bladerf文件 然后我将logo放入了examples目录下

 

这里要注意 一定要修改一下自己定义的图像，我这里的话使用的是水滴安全实验室的logo图像作为这次实验的对象，原图的话是彩色的，我这里将原来的图像用photoshop修改了一下，将要显示出来的图像填充成白色，然后底部图层填充成黑色，这样的话就可以正常生成文件了。



（2）如何使用BladeRFx40发送射频信号

 

 我这里使用的是BladeRF x40

 首先加载FPGA

 从官网上下载

 https://www.nuand.com/fpga_images/

 我下载的是hostedx40.rbf

 

 执行

 bladeRF-cli -l hostedx40.rbf

 

 这样设备的三个黄色的灯就被点亮了，




 然后进入bladerf

 bladeRF-cli -i

 

 然后输入version

 可以看到固件信息还有fpga的版本信息v0.7.3

 

 输入info




 可以看到fpga已经加载成功了。

 

 如果不知道set如何配置我们可以输入

 help set

 

 当然还有tx的选项配置介绍

 help tx

 

 首先我们设置vga

 Set txvga1 -20



 设置带宽

 set bandwidth tx 1750000



 设置频率为433Mhz

 set frequency tx 433000000



 然后我们配置一下tx

 tx config file=Eversec.bladerf format=bin repeat=1

 

 这里的话就是设置发射的文件为Eversec.bladerf 还有发射次数

 在这里如果不确定自己配置是否正常 可以运行print来查看自己的配置信息

 

 我们要注意一下任何个人和单位不得私自占用，干扰无线电通讯的正常运行


（3）Gqrx查看频谱图

 

 接下来我使用的是rtl2832u来看频谱图

 运行gqrx

 在gqrx的input controls选项中不要选择Swap I/Q ，否则在频谱图上看到的则是翻转的图像了。



 点击左侧那个播放按钮

 然后再bladerf中输入tx start

 这样即可在gqrx中看到我们的logo了。
