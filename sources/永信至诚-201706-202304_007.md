# 推动数据安全建设落地丨永信至诚荣获中国计算机行业协会数据安全专业委员会“优秀成员单位”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454820982&idx=1&sn=ef6d1a981ded4cbfeaeb4baa0d2db235&chksm=8c8faefcbbf827ea8ef29c6badd9f02af61b6990439c1128f55a96b4dadae7a0c30bd8d2003f&scene=126&sessionid=1681375830#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454820982&idx=1&sn=ef6d1a981ded4cbfeaeb4baa0d2db235&chksm=8c8faefcbbf827ea8ef29c6badd9f02af61b6990439c1128f55a96b4dadae7a0c30bd8d2003f&scene=126&sessionid=1681375830#rd)

中国计算机行业协会数据安全专业委员会工作组2022年度工作会议圆满结束。会上，对**在推动数据安全产业发展系列工作中表现突出的单位**进行表彰，永信至诚荣获**“优秀成员单位”**，并凭借在**产业标准构建、****数据安全人才培养**、**数据安全专项活动开展、数据安全产业创新**等方面对数据安全专业委员会工作的大力支持获得**感谢信**。  

  

中国计算机行业协会数据安全专业委员会在**工业和信息化部网络安全管理局**指导下、中国电子信息产业发展研究院支持下，由中国软件评测中心（工业和信息化部软件与集成电路促进中心）牵头成立。

  

![](../Images/ef7f01c472174aa29d3eb8a7cea811a2.png)![](../Images/1af4ee67126229ee108ea66faf69ee05.png)

  

2022年是数据安全产业发展的奠基之年，为推动我国数据安全产业发展，中国计算机行业协会数据安全专业委员会有序开展研究**数据安全产业顶层政策**、**数据安全人才培养**、**推广产业应用优秀案例**、**举办主题沙龙系列活动**等工作，旨在凝聚产业多方力量共同构建数据安全产业生态，推动产业创新，做大产业规模，共享能力资源，护航数字经济高质量发展。

  

作为中国计算机行业协会数据安全专业委员会成员单位之一，永信至诚充分发挥**网络靶场**和**人才建设领军者**优势，支撑**首届数据安全大赛、行业标准研制**等各项数据安全工作开展。同时，依托**“数字风洞”产品体系**，永信至诚以**3×3×3×（产品×服务）****安全感公式**为方法论，已经形成全场景、全要素、全生命周期**数据安全测试评估**标准平台，助力政企用户数据安全要素治理、数据活动处理和数据安全工作成效提升，支撑各行业数字化安全测试保障和专有人才输送，推动产业生态创新，成为助推数据安全产业高质量发展的坚实力量。

  

本次当选中国计算机行业协会数据安全专业委员会**“优秀成员单位”**，是对永信至诚**积极推动数据安全产业发展工作**的充分肯定，也是对永信至诚**数据安全测试评估平台**及**数据安全实践成果**的高度认可。未来，永信至诚将继续围绕数字时代国家及产业需求，与广大产业同仁一起，共同推动网络和数据安全产业创新，夯实网络和数据安全产业基础，为数字中国和网络强国建设保驾护航，致力于**成为中国网络空间与数字时代安全基础设施关键建设者**，实现**“带给世界安全感”**的愿景。
