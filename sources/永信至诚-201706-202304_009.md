# 全国政协委员、香港港专学院校长陈卓禧到访永信至诚，共同推动网络安全教育创新发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454820955&idx=1&sn=b19510fe62cda6a3bba529fc7c8943de&chksm=8c8faed1bbf827c73794a54833a56ce48114931403ce5d16ee16ae334a002f3c007272f591f9&scene=126&sessionid=1681375830#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454820955&idx=1&sn=b19510fe62cda6a3bba529fc7c8943de&chksm=8c8faed1bbf827c73794a54833a56ce48114931403ce5d16ee16ae334a002f3c007272f591f9&scene=126&sessionid=1681375830#rd)

![](../Images/7902d8b92daad584f938df5bf3d71023.png)

  

3月12日，为促进**香港和内地企业关于网络安全教育体系建设**的友好交流，**全国政协委员、香港港专学院**(以下简称“港专”)**校长****陈卓禧**、**港专教授易晨**等一行人到访永信至诚，与永信至诚董事长蔡晶晶、副总裁姚磊、副总裁张丽等人围绕**青少年网络安全课程体系建设**、**网络安全创新培训基地创建**、**网络安全赛事开展**等方向进行深入探讨。

  

![](../Images/20fb18daff94e836f38ec9001f89ea97.png)

  

基于港专与永信至诚落成的**香港首个国产网络靶场项目**，全国政协委员、港专校长陈卓禧首先对永信至诚在疫情期间提供的专业且持续性支撑服务表示感谢，同时对公司**网络靶场深厚技术及运营能力、“产品乘服务”创新理念**表示高度肯定。

  

![](../Images/e6b23587960f90cd8d023077acc6a8fa.png)

全国政协委员、港专校长陈卓禧

  

永信至诚对围绕**“人是安全的核心”理念**构建的整体产品体系、公司经营情况、业务发展、各行业场景应用案例等内容进行了重点汇报，获得了陈卓禧校长的充分肯定。  

  

同时，陈卓禧校长邀请永信至诚参与**港专在香港地区的网络安全高等教育发展及科研活动**，探讨推动香港地区青少年网络安全学科教育、网络安全创新培训基地建设、网络安全赛事，**探索推进香港网络安全人才评估制度建立及香港网络安全行业标准落地**。

  

![](../Images/9e50b0b23e927c108b5b2ed7f16a5fe0.png)

永信至诚董事长蔡晶晶

  

永信至诚董事长蔡晶晶表示，当前，全球数字经济高速发展，数字经济与实体业务高度融合，香港作为全球知名的自由港，一直充当着重要角色，**成为汇聚世界各地数字产业的重要驿站**，面对数字化业务网络安全防护需求的爆发式增长，**网络安全职业岗位需求是一个非常强的刚需，**希望港专与永信至诚能够**充分发挥双方优势，通过港专在香港本土化教育思维及教育资源，结合永信至诚在网络安全人才培养方面全生命周期的运营流程及产品体系**，为香港地区网络安全专业人才教育提供更广阔、更开放、更融合的土壤，**共同形成守护香港地区乃至全国数字化资产的重要支撑力量**。

  

![](../Images/67d1c4f5d9b722a433fbcc0cbe0561d9.png)

  

未来，双方将继续发挥各自基因优势，**围绕香港网络安全专业人才培养，加强业务沟通**。通过香港地区国际化网络安全教育视野，以及永信至诚**在网络靶场、人才建设、“数字风洞”测试评估等领域的实践能力及经验**，为数字中国和网络强国网络安全人才培养提供更鲜活、更开放的视角，**带给世界安全感**。

  

![](../Images/67d1c4f5d9b722a433fbcc0cbe0561d9.png)
