# 永信至诚总裁陈俊受邀参加中国-上海合作组织地方经贸合作示范区工作汇报会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454820802&idx=1&sn=2387493dc3a394f907e9e928896b1cc7&chksm=8c8fa148bbf8285e1f80fdfe8c865152bd8bbd542a359d68597a5c2929d76595c1206568e9b7&scene=126&sessionid=1681375843#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454820802&idx=1&sn=2387493dc3a394f907e9e928896b1cc7&chksm=8c8fa148bbf8285e1f80fdfe8c865152bd8bbd542a359d68597a5c2929d76595c1206568e9b7&scene=126&sessionid=1681375843#rd)

![](../Images/7902d8b92daad584f938df5bf3d71023.png)

  

2月21日，中国—上海合作组织地方经贸合作示范区工作汇报会暨产学研合作洽谈会在北京成功举办。本次会议邀请了上合组织相关国家驻华使节和有关部委、商协会、金融机构和企业代表参加，意在全面展示上合示范区建设发展取得的主要成效，与**在京头部企业****加强产业人才对接**，推动与上合组织国家经贸交流合作，**共同打造“一带一路”国际合作新平台**。**永信至诚总裁陈俊受邀出席本次会议。**  

  

![](../Images/310f8a9c3aef72ca042bf94d7d904b86.png)

  

2018年6月，习近平总书记在上合组织青岛峰会上宣布：“中国政府支持在青岛建设中国—上海合作组织地方经贸合作示范区”。上合示范区深入贯彻落实习近平总书记重要指示要求，主动服务和融入国家开放战略，聚力国际物流、现代贸易、双向投资、商旅文交流发展“四个中心”和上合组织经贸学院建设，加快“搭平台、创模式、聚产业、强主体”，积极探索地方经贸合作新路径，打造上合组织地方间双向投资贸易制度创新的试验区、企业创新创业的聚集区、“一带一路”地方经贸合作的先行区、新时代对外开放新高地，在服务国家对外工作大局中贡献了“上合力量”。

  

![](../Images/4cd2d1c8fee3d2b76d38b70ac90d3c98.png)

  

**永信至诚总裁陈俊**表示，作为聚焦科技创新的网络安全企业，永信至诚将以此次活动为契机，充分发挥**网络靶场**和**人才建设领军者**的技术、资源优势，积极为上合示范区发展及“一带一路”沿线国家经贸合作贡献力量，依托**“数字风洞”**在**数字化体系安全测试评估**的重要价值，不断强化产业创新和专有人才培养，为加快打造新时代对外开放新高地持续护航，向着**“带给世界安全感”**的愿景不断前进。
