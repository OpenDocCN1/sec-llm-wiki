# 夯实安全基座 | 永信至诚圆满支撑“粤盾-2022”数字政府网络安全攻防演练

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454819923&idx=1&sn=d5e56afdb135f71b8b646eb35004a0e4&chksm=8c8fa2d9bbf82bcfdc466e5bcac5a9fdd3a71f9b17ac53d2cf9c3098037962f68cb6b8a62350&scene=126&sessionid=1681375863#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454819923&idx=1&sn=d5e56afdb135f71b8b646eb35004a0e4&chksm=8c8fa2d9bbf82bcfdc466e5bcac5a9fdd3a71f9b17ac53d2cf9c3098037962f68cb6b8a62350&scene=126&sessionid=1681375863#rd)

![](../Images/7499edd6386db4f9c73defe4a163a6a8.png)

  

8月17日，以“**夯实安全基座，筑牢安全防线**”为主题的“粤盾-2022”广东省数字政府网络安全攻防演练圆满闭幕。**永信至诚作为技术支撑单位**，圆满支撑了本次**省级全领域覆盖的特大规模实网攻防演练，**这也是永信至诚**连续三年**助力“粤盾”进行数字政府网络安全深度检测，**打造智慧城市安全测试和数字经济发展安全护航的实践高地**。

  

![](../Images/d02bc840c74177c78aaec11ec89b9e34.png)

  

**深化智慧城市安全测试，夯实数字政府安全基座**

  

**习近平总书记在2022年4月19日召开的中央全面深化改革委员会第二十五次会议上强调**，要全面贯彻网络强国战略，把数字技术广泛应用于政府管理服务。会议指出，要始终绷紧数据安全这根弦，加快构建数字政府全方位安全保障体系，全面强化数字政府安全管理责任。

  

“粤盾-2022”数字政府网络安全攻防演练由广东省人民政府主办，广东省政务服务数据管理局、中共广东省委网络安全和信息化委员会办公室、广东省保密局、广东省公安厅、广东省通信管理局、国家计算机网络应急技术处理协调中心广东分中心、广州市越秀区人民政府共同承办。

  

本次演练以“以练促建、以练促改、以练促管、练建结合”为原则，将**广东省范围50个省级部门和21个地市的120个实际运行的重要政务系统**纳入攻防演练范围，集结了**50支**国内优秀网络安全攻击队伍，运用永信至诚春秋云服安服管控-攻防演练平台，展开**为期5天的实兵、实网、实战攻防演练**，**全面检验全省数字政府安全保障能力**，深入排查重要基础设施存在的突出问题和深层次隐患，督促形成跨地区、跨部门、跨层级的协同联动机制，建立健全动态监控、主动防御、协同响应的数字政府安全保障体系。

  

![](../Images/c4107a78e2b00c8ff346f08ff84d69f8.png)![](../Images/68334fe76b13965f7bbf008d182d94b8.png)

  

值得一提的是，活动现场**特别设立网络安全意识互动展区**。钓鱼邮件体验、意识闯关游戏、弱口令暴力破解、专注关基保障安全、DDOS攻击体验等高度贴近实际业务需求的多元化、互动性展项，吸引众多嘉宾驻足参观了解。**演练与科普竞相呼应，实战与场景相互映射，立体呈现网络安全教育、技术、产业融合发展的生态主题**，全方位宣贯提升网络安全意识和安全防护技能的重要性与迫切性。

  

![](../Images/8687b3a257b5a38ba97b727c39219caa.png)![](../Images/28c3397c87c53763308b1312a6234857.png)

  

**筑牢安全防线，护航数字经济安全发展**

  

2022年6月23日，**国务院发布《关于加强数字政府建设的指导意见》**，指出：  

  

加强数字政府建设是适应新一轮科技革命和产业变革趋势、引领驱动数字经济发展和数字社会建设、营造良好数字生态、加快数字化发展的必然要求，是建设网络强国、数字中国的基础性和先导性工程，是创新政府治理理念和方式、形成数字治理新格局、推进国家治理体系和治理能力现代化的重要举措。

  

近年来，广东在全国率先部署启动数字政府改革建设，并始终将保障网络安全和数据安全作为数字政府建设的生命线，特别是举办“粤盾”数字政府网络安全攻防演练活动，为加强数字政府建设、促进全省经济社会平稳健康发展提供了重要支撑。

  

连续三年的“粤盾”攻防演练，有力检验了全网安全防护能力，并形成了一批务实管用的演练成果，对于**提升数字政府安全防护及应急处置能力**，**筑牢数字政府建设安全防线****，**进一步推动网络强国、数字强国建设具有重大现实意义。

  

![](../Images/243afe51f1273e09295c459510b8371c.png)

  

作为**国家级专精特新“小巨人”企业**和本次“粤盾”数字政府攻防演练的技术支持单位，永信至诚将充分立足数字经济发展现实需求，通过“**产品x服务**”的创新理念和“**攻防兼备、人才济济、平行仿真**”的核心优势，打造场景化解决方案，为数字政府建设和数字经济安全健康发展保驾护航！
