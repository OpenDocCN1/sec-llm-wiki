# 永信至诚入选2021年工业互联网安全人才联合培养计划（第一批）合作伙伴

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454818103&idx=1&sn=7c2a3fa1fe4c852072a4f9d6ca4833eb&chksm=8c8fbbbdbbf832abecbdb1dec6b769bc185c9ea67f3add8a38204f0208a447099a2ae47b8075&scene=126&sessionid=1681375889#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454818103&idx=1&sn=7c2a3fa1fe4c852072a4f9d6ca4833eb&chksm=8c8fbbbdbbf832abecbdb1dec6b769bc185c9ea67f3add8a38204f0208a447099a2ae47b8075&scene=126&sessionid=1681375889#rd)

![](../Images/9a864a56167bd7f57f196a1b698fd16f.png)

  

5月27日，工业互联网安全领航计划启动大会暨第一次全体工作会议成功召开。本次会议上，中国信通院和工业互联网产业联盟联合发布了2021年工业互联网安全人才联合培养计划（第一批）合作伙伴。**永信至诚作为网络靶场和人才培养领域的领军企业以及全国工业互联网安全技术技能大赛的核心技术支持单位成为第一批合作伙伴。**

  

![](../Images/2dbf9ebbc6b3f15cbcefb0ec99fe2b13.png)

  

据了解，由中国信通院联合产业各方发起的**工业互联网安全领航计划**致力于搭建工业互联网安全产业支撑和创新发展的引领性、先导性平台，共同促进工业互联网安全政策落地、标准研用、技术创新、人才培育、产业孵化等体系化建设。领航计划具体包含了工业互联网安全**政策产业、技术标准、检测评估、垂直行业、人才培养以及车联网安全**等各方向重点推进工作。

  

![](../Images/fff144c8509504b6363fdb8c4afac5ee.png)

  

永信至诚作为一家专业的网络安全公司，在工业互联网安全人才培养方面一直耕耘不断。在去年召开的“2020年全国工业互联网安全技术技能大赛”上，**永信至诚作为技术支持单位，为大赛提供了高规格的竞赛模式和高水平的实践平台**，开创了工业互联网安全领域最大规模的网络安全线下赛。近几年来，通过专业的赛事运营服务、春秋云境网络靶场及春秋云实网络安全人才培养等产品、服务及方案，**永信至诚还帮助了更多的用户在高仿真的工业互联网实战场景中实现对网络安全人才的培养、训练、选拔及评价**，为工业互联网产业的人才培育和创新发展积极贡献自己的力量。

  

秉承“人是安全的核心”的主导思想，永信至诚以“攻防兼备、人才济济、平行仿真”为核心技术优势，逐渐形成了互为支撑的人才培养及生态运营、靶场测试验证、安全服务、欺骗式防御、安全态势运营的岛链式产品体系。未来，永信至诚将帮助更多的工业互联网企业用户不断**提升网络安全人才技能水平，加强工业互联网的整体防护能力**，进一步助力我国工业互联网产业的发展，带给世界安全感。
