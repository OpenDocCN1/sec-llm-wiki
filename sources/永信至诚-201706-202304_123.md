# 永信至诚获评国家网络与信息安全信息通报机制2021-2023年技术支持单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454817253&idx=1&sn=49294b13c02224616887a090704382c9&chksm=8c8fbf6fbbf836798485ee47c7d78a38ce8b23fc8451ccc18f7f3cbdb77f3e1ece7c5068f3bd&scene=126&sessionid=1681375894#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454817253&idx=1&sn=49294b13c02224616887a090704382c9&chksm=8c8fbf6fbbf836798485ee47c7d78a38ce8b23fc8451ccc18f7f3cbdb77f3e1ece7c5068f3bd&scene=126&sessionid=1681375894#rd)

![](../Images/702940df12d9b68ca834fc60a95843eb.png)

  

12月15日，由公安部第十一局、国家网络与信息安全信息通报中心主办的“国家网络与信息安全信息通报机制技术支持单位2020年度工作总结暨表彰会议”在京召开。凭借在国家重大活动网络安全保卫技术支持工作中的优异表现，**永信至诚****获评“国家网络与信息安全信息通报机制2021-2023年技术支持单位”，并受到国家网络与信息安全信息通报中心通报表扬**。

  

![](../Images/8cf16af690c4e4920a0f696caa2c7f60.png)![](../Images/f8d8166acb2c6e0f1515fd083cdafcc6.png)

  

当前网络安全威胁和风险日益突出，打造健康、清朗的网络空间环境，是每家网络安全企业义不容辞的责任。**永信至诚基于多年来在网络安全前沿技术和攻防实战方面的研究和实践**，已经形成了完善的安全服务体系和专业的安全服务方法论。依托**春秋云服网络安全服务团队**，圆满完成了全国两会、中共第十九次全国代表大会、“一带一路”国际合作高峰论坛等**数十个国家级网络安全保障工作**，成功支撑广东首届“粤盾”等**大型网络安全实战攻防演习**活动，全力协助国家部门开展网络安全风险隐患排查整治，筑牢网络安全防线，用自己的能力和行动捍卫着国家和企业的网络安全。

  

据了解，本次“国家网络与信息安全信息通报机制技术支持单位”**经过体系化专业化评审，优中选优，且数量大幅精简**。能够获评2021-2023年度技术支持单位称号，并受到国家网络与信息安全信息通报中心通报表扬，充分证明永信至诚**安全技术、实战攻防能力**和**春秋云服**安全服务能力的扎实可靠**。**“没有网络安全就没有国家安全”，未来永信至诚将继续一如既往、毫不懈怠地肩负起网络安全企业的责任，充分发挥自身“**攻防兼备、人才济济、平行仿真**”的核心优势，用专业的技术和服务捍卫国家网络空间安全，为建设网络强国奉献最大力量。
