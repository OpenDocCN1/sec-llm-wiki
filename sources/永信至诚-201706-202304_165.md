# 中国信息安全测评中心：信息安全服务资质申请详解视频课程

为进一步贯彻落实习近平总书记关于新冠肺炎疫情防控和有序恢复生产生活的指示批示精神，切实解决企业申报资质过程中的实际困难，**中国信息安全测评中心特推出国家信息安全服务资质申报网络辅导课程**，主要包括资质发展历程、资质申报流程、一级资质申请书总体结构、安全工程类一级申请书要求解读、安全工程能力证明要点讲解以及维持申请的注意事项等方面。**永信至诚为本次课程录制提供全程支持**。

  

该课程内容结合常见问题和真实案例，对申请书进行逐项讲解，对安全工程资质申报的技术思路进行了梳理，并给出了能力证明的具体方法。**建议申请资质的信息安全企业机构认真观看，按照课程要求正确申报**。
