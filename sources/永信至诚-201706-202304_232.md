# 教育部学校规划建设发展中心与永信至诚签署网络安全战略协议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454814535&idx=1&sn=78939804094549e380195a6dc22e984a&chksm=8c8f49cdbbf8c0db0a4770aed473981efc222eccae2ae589cff2653480cd80ced5b0c7c36943&scene=126&sessionid=1681375949#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454814535&idx=1&sn=78939804094549e380195a6dc22e984a&chksm=8c8f49cdbbf8c0db0a4770aed473981efc222eccae2ae589cff2653480cd80ced5b0c7c36943&scene=126&sessionid=1681375949#rd)

7月29日，由教育部学校规划建设发展中心主办的《智慧学习工场2020建设标准指引》发布会在北京召开。会议宣布，从即日起实施智慧学习工场2020建设标准的指引、认定、咨询和培训等工作。**在网络安全方面，教育部学校规划建设发展中心与北京永信至诚科技股份有限公司签署了战略协议并宣布即时生效。**

因需而智 无限创造——《智慧学习工场2020建设标准指引》重磅发布

  

中央全面深化改革委员会第九次会议上审议通过了《国家产教融合建设试点实施方案》，指出深化产教融合，是推动教育优先发展、人才引领发展、产业创新发展的战略性举措。智慧学习工场，作为产教融合的新载体、科教融合的新设计、未来教育的新探索，推动着产教融合向着试点更广泛、要素更聚集、模式更灵巧、载体更丰富、内涵更兼蓄、创新更协同的方向演化升级。

**教育部学校规划建设发展中心主任陈锋表示，****智慧学习工场是产教融合深化的新平台。****在这里，教育、人才、科技、产业和信息等要素实现更加充分和广泛的聚集、融合、互生、共享，以创新实践引领人才链、教育链、产业链、创新链变革，为高等学校和职业院校培养复合型、应用型和创新型人才提供基础架构，从而加快构建以人才和科技为支撑的、以创新驱动为核心的创新生态系统。**

  

![](../Images/09212b89753a5656990566b3255d2d5d.png)

*会议现场*  

  

智慧学习工场2020建设标准是在总结了多层次、多类型创新实验案例的基础上，借鉴吸收国内外最新理论，对关键问题进行专题调研后形成的。系列文件储备了丰富、详实、前沿和动态的资料库。该标准**在技术上兼容各类相关的国家标准，并填补了现有国家标准体系的空白。**近两年里，智慧学习工场建设标准的内容不断优化升级，其适用性和有效性也持续得到检验和证明，目前已取得阶段性成果，标准将对引领高等学校和职业院校迈向未来具有重要的实验意义和导向作用。

  

强强联手 协同创新——网络安全领域战略协议签署

  

网络安全作为智慧学习工场2020非常重要的一个版块，在现场，**教育部学校规划建设发展中心与北京永信至诚科技股份有限公司签署了战略协议，双方将形成技术创新合作机制，重点研究国家网络安全人才培养中急需解决的战略性安全问题，将在“智能网络安全靶场实验室”共建、网络空间安全学科共建及联合探索、研究及推广网络安全实战型人才培养模式等方面展开深入合作。**

教育部学校规划建设发展中心将会对项目提供政策咨询，顶层设计和理论研究等支持，同时引导和支持全国高校参与合作，协调院校申报、项目遴选、质量监控、论坛组织、经验总结推广以及开放课题的组织和发布等工作。双方将基于可视化内核技术的实验技术，深入研究综合性能力提升培训体系，共同规划全方位的培养目标、课程体系，共建面向高校学生的实践实训基地；组建高水平的专业研发团队，共同承研具有国际先进水平的关键理论研究和技术应用课题；联合培养高素质技术研发与应用人才，满足国家网络安全行业对不同层次创新型人才的需求。

  

**此次合作，双方将充分发挥各自在网络安全领域的技术和人才优势，不断提升网络安全技术的研发能力、网络与网络安全实战型人才的培养能力。**通过合作研发具有自主知识产权的网络安全课程体系、关键技术和实训平台，为网络空间安全一流学科（专业）的建设和发展提供有力保障，为国家网络安全行业人才梯队建设提供核心技术支撑与系统解决方案。

作为专业的网络安全企业，永信至诚一直坚持**“**人是安全的核心”****的理念，结合自身多年来在**安全培训、靶场建设、安全服务**等方面的经验，充分发挥协同创新的能力，与各大高校展开深度合作，以助力网络安全人才的成长，为国家输出更多网络安全实战型人才，为万物互联的世界带来更坚实的安全感。
