# 热血角逐| BCTF 2019-2020百度人工智能安全对抗赛新赛季首战拉开帷幕

"Baidu Create 2019"百度AI开发者大会,于2019年7月3日-7月4日在北京国家会议中心如期召开。来自全球各地的数千名开发者与行业合作伙伴共同见证了百度AI最前沿的人工智能技术、产品，并共同探讨了AI技术落地各行各业及全球产业智能化的趋势。

  

继今年6月，第二届百度网络安全技术对抗赛BCTF线下总决赛在DEF CON CHINA 1.0期间赢得满堂彩后， BCTF 2019-2020全新赛季全面开战。7月4日，由百度安全主办，永信至诚承办的BCTF 2019-2020百度人工智能安全对抗赛新赛季在百度AI开发者大会-公开课中开启了新征程。来自企业、高校、科研机构和传统CTF战队在这里完成了一场没有硝烟的竞技。  

![](../Images/13e9c420164fcc536c30e9779de96552.png)

  

**BCTF****新赛季，持续为AI进化提供肥沃土壤**

▲▲▲

新赛季的首场较量延续了刚刚结束的BCTF线下总决赛人工智能攻防赛的“双轨赛制”，由BCTF-RHG漏洞挖掘和BCTF-RHG攻防对抗两场比赛组成，BCTF-RHG漏洞挖掘比赛，考察的是机器人在没有人干预的情况下，对于特定二进制文件进行分析，寻找到其中漏洞并利用的能力。而BCTF-RHG攻防对抗比赛，则旨在通过特定的规则和环境，实现在具有场景网络的环境中纯机器人程序独立进行安全对抗的尝试。根据规则，除彩蛋题之外，本次BCTF比赛过程中全程不需要人类进行操作和干预，全部由机器人和比赛平台自动完成。

![](../Images/4df1ad4511589a4bf13e039f61d0d73b.png)

比赛现场引入了彩蛋题环节，作为百度安全AI安全技术栈“七种武器”之一的KARMA自适应热修复为战队们加持，在高度碎片化的智能终端生态中，该漏洞无需依赖被修复系统的源码，且一个修复方案可以支持多种不同设备，缩短了智能终端厂商推送系统安全补丁到最终用户的过程，极大减轻了终端厂商的漏洞修复成本。利用该技术强化战队机器人的能力，构建技术交流平台，为孕育功能完善的自动化防御系统提供土壤。

  

**激烈之战响彻云霄，AI高手汇聚云顶巅峰**

▲▲▲

经过六个小时的激烈角逐，以考点为纬度，漏洞挖掘方向题目所有考点被机器人一举拿下，攻防对抗方向题目也被逐一挑战，由现场裁判对战队日志进行最终审核，来自恒安嘉新EversecLab战队获得漏洞挖掘一等奖，国防科技大学HALFBIT战队、ChaMD5战队获得二等奖，丁牛科技DigApis战队、中国海洋大学Mech-whale战队获得三等奖。来自国网山东省电力公司护网先锋战队获得攻防对抗一等奖，FAFA战队、山东科技大学Timekeeper战队获得二等奖，ChaMD5战队、西安电子科技大学L战队获得三等奖。获奖战队分别获得一万元、六千元、四千元奖金，这是对其成绩和能力的肯定。

![](../Images/baca530d08293d3dd10411ebd7057711.png)

**恒安嘉新EversecLab战队在国防科技大学HALFBIT战队堆类题目突破上深受启发，此次，也完成了这一世界级的技术挑战。**赛事的高水准在无形中不断推动着人工智能攻防技术的方向和发展，也正如恒安嘉新EversecLab战队所期：我们的机器人终有一天可以参加真正的CTF比赛。

**极客大咖来袭，爆史上最有料干货**

▲▲▲

同期举办的AI开发者公开课中，百度安全马杰，永信至诚高级副总裁潘柱廷（大潘），国防科技大学HALFBIT战队前队长张斌博士等专家为现场观众奉献了精彩议题， 关于赛事推动AI安全事业的发展，关于AI成长的思辨，关于正在觉醒的自动化漏洞挖掘与利用技术的分享等等，干货满满，共同掀开了人工智能网络安全的新篇章。

![](../Images/bd79dd0a250bcd3b81ed287062945059.png)

BCTF AI攻防赛公开课现场

  

永信至诚高级副总裁潘柱廷（大潘）带来了《AI与智商》的分享，潘总认为**“安全是一个注重结果的领域，专家的意义不大，赢家才是硬核”。**安全里边没有专家，安全只有赢家，不管你的算法多棒，过程、手段多么高深，如果输了就要认，安全是用结果来判断的，只有赢家才是硬核，这样的价值取向对整个人工智能的研究发展非常有用。同时，**他认为****安全再怎么吹、再怎么神秘都要经受对抗的检验，结果是可判定输赢的，效果是可检验的。**  

![](../Images/3e8a0cec692c3ef019456319c8381c5f.png)

永信至诚高级副总裁潘柱廷（大潘）

  

现场，大潘也提了一个有意思的观点，他认为，人类的智能不是高手构建出来的，也不是上帝设计的，人类能有这样高级的智能是因为人类经过了上亿年的生活残杀，在淘汰和死亡的过程中留下来的。我们在做人工智能的对抗，其实也是在做一个加速过程，等不及上亿年的淘汰，通过对抗，程序之间进行淘汰选择，这样留下来的是更智能的，BCTF-RHG赛事则是希望加速了这个演化过程。

  

国防科技大学HALFBIT战队前队长张斌博士为现场观众带来了《软件漏洞自动挖掘与利用》的分享，张斌提到：“自动化分析漏洞的成因是非常艰难且非常重要的一步，漏洞是什么类型的？漏洞是怎么产生的？在做自动化漏洞挖掘与利用时，对漏洞先来个灵魂拷问“你是什么垃圾？”然后才能进一步拿出对策，这对机器人来讲是很难的，相应的分析策略就很重要了。”  

![](../Images/23bd9b48f4a7929c66923688c829dc2c.png)

国防科技大学HALFBIT战队前队长张斌博士

  

张斌认为，现阶段漏洞研究的关键在于实现自动化，漏洞挖掘、分析、利用的自动化，可有效克服当前漏洞研究工作中效率低、周期长等问题，从原来的“工匠模式”转化为“工厂模式”。同时，可有效提升挖掘高质量漏洞的数量，缩短发现、分析与利用的周期，保证漏洞研究工作价值的时效性。

  

作为RHG竞赛的老玩家，张斌为现场观众讲述了CGC和RHG的区别，他通过对机器人硬件平台、编译方式、漏洞缓解技术、竞赛内容、漏洞类型等多方面进行了分析，做了很多对比得出了结论，**“RHG不是缩小版的CGC，这里是更真实的竞赛环境，编译方式的区别等都让RHG变成了一个独立的赛事。”**

  

![](../Images/ecd1eb2f8f29d5b95d4fcb182ca832df.png)

  

最后，张斌总结到，随着人工智能技术的广泛应用，人工智能与网络空间安全紧密结合到了一起，人工智能相关技术在网络空间安全方向主要的内涵与趋势体现在两个方面：AI为安全服务，如何使用人工智能为当前的网络空间对抗技术服务；安全为AI服务，如何发现人工智能的脆弱性，实施新的对抗或安全增强。

  

张斌提到的这两个方面也是百度安全和永信至诚联手打造BCTF的初衷，希望通过搭建一个支持产学研各界交流切磋的平台和演兵场，集结海内外最优秀的战队，在最前沿的AI安全领域碰撞火花，输出实战经验，为AI安全领域的战队成长提供土壤，成为AI时代助力培养中国网络安全人才的“黄埔军校”。

  

下午由R3kapig战队主力丁湛钊担任“圆桌论坛”嘉宾主持，特邀百度安全部高级安全研究员吴乐、恒安嘉新EversecLab战队队长张红宝、国防科技大学HALFBIT战队队长姜植元、国网山东省电力公司护网先锋战队主力王聪等4位嘉宾针对人工智能安全对抗赛的热点话题展开深度讨论，当提到赛事的标准是否对机器人要求过高时，国防科技大学HALFBIT战队队长姜植元表示：**“这更有助于推动技术的方向和技术的发展，对此而言极为有利。”**随后又引出不同观点，话题再次提升高度进入激烈讨论中。  

![](../Images/720cc59e91e7aa656043b635fa8ddaf8.png)

圆桌论坛讨论现场

  

百度安全总经理马杰在最后的颁奖典礼总结到：**“今天的AI比赛，和我们想象中的AI攻防赛还有一段距离，但是只要持续的投入和栽培，可能在仅仅几年的时间里就能产生工程的意义和科学的意义，我们有信心在这个新兴领域做成世界上数一数二的赛事。通过“蓝莲花”战队的这段视频，再次让我回想到当年加入CTF比赛的历程，一个小团队是否有可能挑战世界冠军？事情总要去试试看，做了就有可能实现。今天在座的很多战队比当年的“蓝莲花”名气要大，我相信未来的我们可以成就另一段传奇。”**

  

![](../Images/37acac81deecfdee1af859e298ee1c21.png)

百度安全总经理马杰颁奖典礼总结

  
![](../Images/8136f1050ac43fb4708588b9cffc9358.png)

在新一年的赛季中，再次出征的AI机器人战队不仅在漏洞挖掘、场景攻防等全新赛程中展现了自身不断提高的“战力”，也带来了更多希望。只有保持竞争，我们才能不断进化，怀着对人工智能技术的敬畏之心，我们相信在人工智能网安竞赛的引领下，网络安全行业将迎来前所未有的机遇。

  

未来，永信至诚还将继续深度探索创新竞赛形式，打造更多多样化的网络安全竞赛场景，为推动人才培养事业，推动网络安全人才成长奉献力量。永信至诚竞赛的巨轮将驶向更广阔的赛场，为更多领域、更多行业的网络安全事业保驾护航。
