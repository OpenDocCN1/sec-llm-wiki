# “天府杯”国际网络安全大赛报名通知

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454813460&idx=2&sn=8e1e12bd7f5abbb67510c786ed1d55f3&chksm=8c8f4d9ebbf8c488f8009846a7b35a6f3ac6d3e743387bf81bcf1ac5aa085c6b52f0b57a4e32&scene=126&sessionid=1681375990#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454813460&idx=2&sn=8e1e12bd7f5abbb67510c786ed1d55f3&chksm=8c8f4d9ebbf8c488f8009846a7b35a6f3ac6d3e743387bf81bcf1ac5aa085c6b52f0b57a4e32&scene=126&sessionid=1681375990#rd)

11月16日至17日，首届“天府杯”国际网络安全大赛将在成都天府新区西博城举办。在为期两天的活动中，精彩激烈的“天府杯”国际破解大赛、大咖云集的技术论坛、精彩纷呈的产业成果转化会都将与广大观众见面。  

  

“天府杯”由百度、阿里巴巴、腾讯、360、清华大学、中科院、永信至诚、亚信安全、成都天府新区投资集团有限公司联合主办，启明星辰、天融信、绿盟科技、网御星云、知道创宇、四川大学、电子科技大学、中电10所、科来软件、卫士通、无声信息、卡巴斯基实验室、赛门铁克齐力协办。

  

作为本次活动的重磅环节，“天府杯”国际破解大赛致力成为全球第一的破解比赛，现面向所有安全从业人员公开征集参赛选手与参赛项目。参赛选手根据目标赛项设定来报名参赛项目，“天府杯”国际破解大赛设置冠军、亚军、季军奖、最佳个人奖（个人名义最高积分获得者）、最牛破解奖（获得积分最高的单个挑战项目）、最霸技术奖（裁判根据项目利用目标破解难度、漏洞挖掘难度、漏洞利用技术创新度等因素综合评分评奖）。

  

本次破解大赛共设立100万美元的奖金，包含PC端、移动端与服务器端三大项。

具体赛事如下：

微软Edge浏览器

火狐浏览器

谷歌 Chrome浏览器

苹果Safari浏览器

微软Office系列 ( Word/Excel/PowerPoint)

Adobe PDF Reader

iPhone X

微软远程桌面

Oracle VirtualBox 虚拟机

VMWare Workstation 15虚拟机

 

具体项目、奖金和积分分配详情请见“天府杯”官网（www.tianfucup.com）。目前，官网已开放报名，请及时关注官网动态。

除此之外，“天府杯”还设有破解开放赛，所有对破解有兴趣的选手都可以通过官网注册报名，项目不限，裁判组会根据报名参赛项目概要信息（包括目标、漏洞类型、攻破效果等）进行评分与投票，以确定入选参赛项目。

 

报名方式：

通过大赛官方网站注册报名。

网站地址：www.tianfucup.com
