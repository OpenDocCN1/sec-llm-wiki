# 20支AI战队论剑武汉，“黄鹤杯”RHG机器人网络安全大赛战火重燃！

AI变革传统行业，人工智能的快速发展期正在大踏步走来。近年来，随着信息技术的高速发展，人工智能的应用场景逐渐渗透到自动驾驶、人脸识别、自动分拣等各方面。同时，震网病毒的爆发、WannaCry勒索病毒席卷全球，也为我们敲响了警钟，网络威胁逐渐呈现自动化、智能化的发展趋势，人工智能在网络安全攻防领域的研究迫在眉睫。

  

![](../Images/e73ae33b0481ee50cfd878227fb1f3b3.png)

  

在刚刚结束的2018年国家网络安全宣传周开幕式上，中共中央政治局委员、中宣部部长黄坤明强调，举办国家网络安全宣传周，是以习近平同志为核心的党中央着眼网络安全和信息化发展大势，从推进网络强国建设、提升我国网络安全保障能力全局出发采取的重要举措。要把提高全民网络安全意识、培养网络安全人才作为基础工程，广泛开展网络安全知识宣传教育和技能培训。

  

![](../Images/499c5f8ab5861c1020b51d14c721fca9.png)

  

就在明天，一场旨在培养和选拔网络安全优秀人才，探索网络安全智能化、自动化的盛大赛事——“黄鹤杯”RHG机器人网络安全大赛（RHG2018）即将打响！**大赛由湖北省互联网信息办公室、武汉市互联网信息办公室、武汉临空港经济技术开发区管委会主办，武汉市互联网行业联合会、武汉市软件行业协会、武汉市网络安全协会承办，永信至诚、百度安全协办。作为2018年湖北省暨武汉市国家网络安全宣传周开放日活动的重头戏，大赛被赋予了更多意义。**  

**担当国家网络安全发展重任**

**湖北武汉打造“城市新名片”**

  

在刚刚结束的世界人工智能大会上，《2018中国人工智能发展报告》发布，《报告》指出，近20年来，我国人工智能论文数量和被引数量均排在世界第一，但在人才方面，中国人工智能人才虽拥有量虽居世界第二，但杰出人才占比远低于其他领先国家。

  

武汉地处中华腹地，积极担当起国家网络安全发展战略的重要任务。位于武汉东西湖的“国家网络安全人才与创新基地”是国内首个“网络安全学院+创新产业谷”，未来将成为集网络安全人才学历教育、在职培训、研发中心、孵化平台为一体的人才培养高地。永信至诚作为网络安全人才培养领军企业，于2018年5月17日，在东西湖区临空港大楼内举行了网络空间安全系统研发生产中心项目签约仪式。

![](../Images/4a61e9a5653fa219e943abec91d25266.png)

  

此次，为加速人工智能网络安全人才的培养和选拔，永信至诚再次携手武汉主办方，在国家网络安全宣传周期间，举办“黄鹤杯”RHG机器人网络安全大赛。**“黄鹤杯”RHG机器人网络安全大赛将于9月21日09：00正式开赛，奖项设置为：一等奖奖金十万（1个名额）、二等奖奖金五万（2个名额）、三等奖奖金两万（3个名额）。**

**“黄鹤杯”RHG机器人网络安全大赛也将成为武汉市的“城市新名片，使网络安全优秀人才源源不断地涌流，加速网络安全产业的可持续性发展。**

**RHG竞赛平台全力出击，**

**打造网络安全领域的的“铁甲钢拳”**

  

电影《铁甲钢拳》寓言了未来世界，在数十年后，人与人工智能的关系发生了诸多改变，人类拳击甚至不再被允许，机器人代替人类走上舞台。故事讲的是一位失落的拳击手，用人类智慧指导“废柴”机器人，机器人通过自主学习掌握了扎实本领和正确的价值观，双方回归冠军领奖台，以及惩恶扬善的故事。

  

![](../Images/581581c8aa2ed619d4a364e94231ec8d.png)

  

而在网络安全领域，人与人工智能共同赋能互联网安全的事情也正在发生。2017年4月，永信至诚凭借在网络安全攻防、网络安全竞赛的理解和积淀，推出国内首个人工智能网络安全攻防平台 — 人与机器网络攻防竞赛（简称RHG）平台后。随后，2017年9月，成功举办“首届国际机器人网络安全大赛”（RHG2017）,此次大赛率先点燃了我国网络安全人工智能攻防竞赛的火种，为人工智能网络安全攻防领域培育了新生力量，并使我国AI网络安全技术得到了国际认可。

  

![](../Images/7d236d166f312bff3ab34fd458a5a621.png)

（RHG平台测试动效）

  

在本次大赛中，RHG竞赛平台迎来重大升级，大赛将全面考验人工智能在二进制漏洞的挖掘和利用方面的能力，20支队伍互为竞争，最先完成所有或尽量多赛题的漏洞挖掘、 利用并提交正确flag的战队将获得更高积分。组委会还邀请了在首届RHG大赛名列前茅的HALFBIT、Mech-Whale、pipeline战队、国内外知名的AI战队WHU、Lancet、Redbud、Nu1L、LFHY等，以及来自中科院软件所、丁牛科技、恒安嘉新的企业战队，20支人工智能将同场作战，打造网络安全领域的“铁甲钢拳”！

  

**百度安全，AI力量注入RHG赛场**

百度安全作为百度公司旗下，以AI为核心、大数据为基础打造的领先安全品牌，是百度在互联网安全18年最佳实践的总结与提炼。面对AI时代层出不穷且日益复杂的生态安全问题，百度安全倡导新一代技术研发与开源，迄今已实现多项AI安全核心技术的突破，开源“七种武器”，全面覆盖云管端以及大数据和算法层面的一系列安全风险问题，赋能AI时代的安全生态。基于在AI领域丰富的技术沉淀，百度安全作为本次大赛的协办单位、出题方之一，为本次大赛提供了高质量的赛题保障。

  

  

**“黄鹤杯”系列活动**

**点亮国家网络安全宣传周**

  

“黄鹤杯”RHG机器人网络安全大赛以外，2018年湖北省暨武汉市国家网络安全宣传周还包含“黄鹤杯”网络安全发展高峰论坛、“黄鹤杯”网络安全嘉年华两大主题活动。

  

**“黄鹤杯”网络安全发展高峰论坛。**本次论坛的主题为“共筑网络安全长城，打造数据和谐社会”，开设主论坛、分论坛各1场。**中国科学院院士郑建华，国防科技大学教授、中国计算机学会互联网专委会副主任委员苏金树，国家创新与发展战略研究会副会长郝叶力，东西方研究所全球副总裁迈康纳，华中科技大学计算机学院教授、武汉网络安全战略与发展研究院院长金海等业内知名影响力的院士、专家、行业内国际一流企业家、技术专家汇聚一堂，共同探讨国内外网络安全发展趋势，交流分享国际国内共同关心的网络安全热点话题。**

  

**“黄鹤杯”网络安全嘉年华。**9月21日-23日，国家网络安全人才培养与创新基地以及360企业安全集团等网络安全企业将向市民进行网络安全宣传展示。展示内容以通俗易懂、喜闻乐见的互动体验形式为主，市民可亲身体验“恶意手机充电站”“人脸识别破解”“黑客改号”等生活场景下的网络安全案例互动内容。
