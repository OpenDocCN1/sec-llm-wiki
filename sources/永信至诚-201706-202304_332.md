# 2018年民航网络安全职业技能竞赛（决赛）圆满闭幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454813341&idx=3&sn=a85f7221f361728c2d61d705f0d597cd&chksm=8c8f4c17bbf8c50108aea8c66960a151cd16b450c7c1b5f54fcd664e2df3be4162dbc2409f97&scene=126&sessionid=1681375990#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454813341&idx=3&sn=a85f7221f361728c2d61d705f0d597cd&chksm=8c8f4c17bbf8c50108aea8c66960a151cd16b450c7c1b5f54fcd664e2df3be4162dbc2409f97&scene=126&sessionid=1681375990#rd)

9月18日，由中国民航工会、民航局人事科教司、全国民航团委主办，中国民航大学承办，北京永信至诚科技股份有限公司提供技术支持的“2018年民航网络安全职业技能竞赛决赛”在中国民航大学举行。比赛以落实中央网络安全和信息化部署、开展国家网络安全宣传周活动、提高民航网络安全保障能力为导向，旨在集中展示民航网络安全技术人员的精湛技能，着力推进民航网络安全人才队伍建设。

  

决赛分为**个人赛和团队赛**。汇集了航空公司、机场、空管、服务保障企业、科研院所共27家单位、40支参赛队的120名从事民航信息技术工作的选手。

  

9月18日的决赛上午为个人赛，要求选手线下解答若干题目，考察范围包括民航网络安全政策法规、计算机与网络安全、民航网络安全事件应急处置等方面的理论知识和操作技能。个人赛在线下环境中进行，120名从事民航系统的选手通过3个半小时的激烈的角逐，产生个人一等奖六名、个人二等奖九名和个人三等奖十五名。

  

![](../Images/103e75f26785ff9eafe4068cb5415568.png)

个人赛120名选手角逐现场

 

9月18日下午为团队赛，团队赛采取攻防对抗的形式，各参赛队在线下的网络环境中互相进行攻击和防守。每个队拥有两台防守机，在修复自己防守机漏洞的同时，尽可能地发现其它队伍防守机的漏洞并利用其开展攻击从而得分。40支参赛队通过4个小时激烈的攻防对抗，有三支战队获得团队一等奖的、六支战队获得团队二等奖、六支战队获得团队三等奖。

  

![](../Images/e2fa9b109e268b489489c9129ae87aa2.png)

团队赛40支战队激烈攻防对抗现场

 

竞赛现场**永信至诚讲解专家分别为民航局人教司陈朝霞副司长、中国民航工会黄丽辉主席、全国民航团委陈丽娟书记、中国民航大学吕宗平副校长、民航局人教司张西武处长等领导**，做了竞赛讲解及现场技术支撑情况汇报。

**永信至诚赛事平台研发团队、运维团队、赛题团队以丰富的经验和超强的专业性，确保了此次比赛的顺利进行，**为提高民航网络安全保障能力、推进民航网络安全人才队伍建设提供了重要力量。

  

作为一家网络安全企业，永信至诚凭借深厚的技术积累与大量优秀人才队伍优势，用三年时间，成功承办了**两百余场赛事，十余万人参加，覆盖十余个行业，成为了业内专业的赛事平台研发及运营服务商****。**通过不断创新，持续打造不同竞赛模式的网络安全竞赛，为网络安全爱好者们提供了形式多样的实操演练平台，几乎覆盖了业内所有的顶级赛事：“网鼎杯”网络安全大赛、“巅峰极客”网络安全技能挑战赛、百度杯CTF夺旗大赛、全国大学生信息安全竞赛、企业内网安全实战靶场对抗赛、RHG首届国际机器人网络安全大赛、“企业安全众测”靶场挑战赛、全网TOP白帽挖洞大赛、强网杯全国网络安全挑战赛、BCTF百度国际网络安全技术对抗赛等。

  

未来，永信至诚还将继续深度探索创新竞赛形式，打造更多多样化的网络安全竞赛场景，为民航网络安全人才成长奉献力量。永信至诚竞赛的巨轮将驶向更广阔的赛场，为民航行业的网络安全事业保驾护航。
