# 永信至诚受邀参加中国网络安全产业联盟企业座谈会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454812467&idx=1&sn=4d53c888fa711032e3ed6a7822054389&chksm=8c8f41b9bbf8c8afb2189f02695f19a9dfd9de582d89b621ccfcf33d778315c66320d91ffc7f&scene=126&sessionid=1681376020#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454812467&idx=1&sn=4d53c888fa711032e3ed6a7822054389&chksm=8c8f41b9bbf8c8afb2189f02695f19a9dfd9de582d89b621ccfcf33d778315c66320d91ffc7f&scene=126&sessionid=1681376020#rd)

2018年3月1日上午，中国网络安全产业联盟网络安全企业座谈会在北京隆重召开。中国网络安全产业联盟秘书长杨建军，联盟指导单位相关负责同志以及来自22家会员单位的30名代表参加了本次会议。

  

![](../Images/050a68d1b4f920f3fa40dd4fcbb65b47.png)

  

北京永信至诚科技股份有限公司作为会员单位受邀参加并与参会联盟企业共同围绕企业情况、主营业务、客户群体、主要技术和产品、业务特色等内容进行了深入探讨。

  

![](../Images/021f0f6f9fd25a78a69214c555ddc6d6.png)

  

永信至诚副总裁李炜在此次会议上发表重要讲话，表示作为中国网络安全产业联盟会员单位，永信至诚将凝聚、精炼中国互联网安全十多年的实践经验和理论系统，凭借“攻防第一，人才济济”的优势，以领军网络靶场、高处置态势感知、高能效安全服务的为核心的三大业务，践行聚焦优势、合作共生、有信有诺的价值观，最终实现“ 带给世界安全感”的愿景使命坚持以精湛的技术推动网络安全行业的发展，为我国网络安全整体能力的提升保驾护航。

  

我国网络安全产业日益壮大，永信至诚将积极配合联盟工作，努力为产业发展提供有效能量，全面落实网络安全保护主体责任。
