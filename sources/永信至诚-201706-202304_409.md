# 2017中关村高成长企业TOP100评选活动在京举行 永信至诚入选为高成长企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454812409&idx=1&sn=53fb607486dcae123fba59d38b41d45f&chksm=8c8f4073bbf8c96572f265500139ac92f629772e049a695391473422ec788857d21bdd8159b8&scene=126&sessionid=1681376025#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454812409&idx=1&sn=53fb607486dcae123fba59d38b41d45f&chksm=8c8f4073bbf8c96572f265500139ac92f629772e049a695391473422ec788857d21bdd8159b8&scene=126&sessionid=1681376025#rd)

12月26日，由北京中关村高新技术企业协会（简称高企协）与中关村创业投资和股权投资基金协会（简称创投协会）联合主办的“2017中关村高成长企业TOP100”评选活动颁奖典礼在北京友谊宾馆隆重举行。

  

![](../Images/9c00cc47e66d7a25af52342de468c683.png)

  

TOP100 年度评选活动自2009年创办以来，已成功连续举办了七届。在各级政府及主管单位的关心和指导下，活动得到了社会各界的一致认可与好评，现已成为中关村地区最具权威性和公信力的大型公益性评选活动之一。

  

本届评选活动的举办旨在总结往届活动经验的基础上，秉承公平、公正、公开、公益相结合的“四公”原则，从企业持续成长发展能力与核心竞争，积极承担社会责任等方面着手，甄选并表彰中关村示范区内高成长的优秀企业。永信至诚作为在中关村成长壮大起来的企业新秀和新一代领军企业，通过专家评审，成功入选为2017中关村TOP100高成长企业。

  

![](../Images/1f2b69c49323ac1d547907fa7ddf3885.png)

  

永信至诚副总裁余慧英出席了本次评选活动，并对本次成功入选为2017中关村TOP100高成长企业表示了感谢。

  

2017年，永信至诚始终不忘初心，坚持创新发展的工作态度，深深扎根于网络安全教育领域。2017年里，永信至诚在竞赛体系上不断创新，陆续推出了ISW 2017 内网安全实战演习、RHG首届国际机器人网络安全大赛、X-NUCA “企业安全众测”靶场挑战赛等多场模式新颖的竞赛，创新推动了网络安全竞赛的蓬勃发展。结合高校教学的实践诉求，推出“春秋学堂”立体化网络安全教学平台等，全力为网络安全人才成长保驾护航。

  

![](../Images/42c6607f9af2204836677bcc57f7b8bf.png)

  

本次永信至诚能够成功入选为2017中关村TOP100高成长企业，象征着主办方和各领导单位对永信至诚2017年在人才培养工作上做出的卓越表现以及所取得的杰出成绩的高度认可。未来，永信至诚将继续扎根网络安全教育行业，为社会各界提供优秀的网络安全人才，为推动网络安全行业的发展付出更多努力。
