# 攻自有方，守亦有道——永信至诚网安竞赛中国行之中国银行软件中心

网安江湖风云起，永信至诚再出发。如果说网络安全是一方江湖，那今年便是侠客辈出的一年。2017年，网络安全竞赛在全国百花齐放，永信至诚i春秋、e春秋强强联璧，为全国22个省市自治区、特区呈现了百余场竞赛。ISW企业内网安全靶场挑战赛、RHG机器人网络安全大赛、X-NUCA企业安全众测靶场挑战赛...数十万网络安全爱好者正在通过竞赛磨练武功，探索立足江湖的秘笈。

![](../Images/771db8a7a80ce78cb4145c5d9d295634.png)

  

近日，中国银行软件中心第七届创新及岗位技能大赛—移动互联安全测试决赛在北京圆满收官。本次大赛以信息安全为主题，由中国银行软件中心主办，永信至诚独家技术支撑，旨在为测试人员搭建一个锻炼技能、交流切磋，提高安全防护能力的平台，为软件中心储备安全力量。经历初赛的选拔，共26支队伍，52人挺进决赛，展开巅峰对决。

  

![](../Images/6127db79ed15cd5e7d4416894e2196c5.png)![](../Images/43325975f62f1cdcfa2d6b8ae53c2345.png)

  

安全技能大舞台，彰显你的攻守道。正如本次大赛的主题，网络安全的本质是攻防，只有攻防兼备的人才，才掌握着舞台的主动权。对于测试人员来说，掌握攻防技术、保持漏洞挖掘的敏感度意义非凡。本次大赛模式设置为CTF夺旗赛和AWD红蓝攻防对抗赛，参赛者需要在模拟真实场景的网络环境中解答赛题，或是互相进行攻防对抗来夺旗分数，最终以分数进行排名。永信至诚多年来，积累了深厚的一线攻防及赛事组织经验，其自主研发的e春秋竞赛平台，具备高度贴近实战的比赛场景，在本次大赛中全面考验了参赛人员的安全渗透、安全监测、安全加固等能力。

  

![](../Images/33c40535f4321178d65812c9795464f0.png)

  

随着万物互联序幕的拉开，安全漏洞风险如影相随，安全能力建设不容轻视。网络安全人才被赋予捍卫安全的使命，务必掌握网络安全的“攻守之道”，才能从苍茫的江湖脱颖而出。如今，越来越多的企业已经认识到网络安全竞赛是人才培养和选拔的关键，未来更多人才将从这里出发，成为保障各领域安全的中流砥柱。

 

永信至诚作为国内网络安全教育的先行者，长期践行“以赛促学、以赛代练”的人才培养理念。2014年至今，与政府、高校、金融、交通等领域紧密合作，成功举办了二百余场、十万人次参与的网络安全竞赛。未来永信至诚将创新竞赛形式、打造多样化的竞赛场景，为不同行业、不同职业属性的人才定制竞赛方案，不断推动人才培育事业，为社会实现更高层次的安全保驾护航。欢迎更多企业加入到永信至诚网安竞赛中国行，为捍卫网络安全输送正能量。
