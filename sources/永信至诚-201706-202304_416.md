# 永信至诚再获2017贵阳大数据与网络安全攻防演练安全创新一等奖 扎实攻防技术保障安全服务承诺

11月28日，由贵州省大数据安全领导小组、贵州省委网信办、贵州省公安厅、贵州省经信委、贵州省大数据局、贵州省国安厅、贵阳市人民政府主办的2017贵阳大数据及网络安全攻防演练圆满落幕。本次攻防演练是贵阳市第二次举办以大城市为范围，在真实网络环境中，针对真实目标的一次演练活动，演练活动邀请了众多国内顶级的安全厂商和安全团队参加。永信至诚同样应邀参加了本次攻防演练，最终在演练活动中凭借对安全攻防的理解与强大的技术实力，被主办方授予了安全创新一等奖。  

 

![](../Images/0a3cf3a7abefc9fd85d4422e7107eca5.png)

2017贵阳大数据攻防演练观摩总结大会在演练活动后召开

 

据主办方介绍，为了响应国家网络强国的号召，建立长期有效的网络安全保障机制，自2016年起，贵阳市每年都将举办一次大数据与网络安全攻防演练活动。本次演练活动在2016年成功举办的基础上再进一步，采用了真攻真防的形式展开了一次“瘫痪式”演练。旨在以发现、暴露和解决问题为切入点，真实检验大数据与网络安全的防护水平、应急处置能力，增强全社会的网络安全意识，推动大数据安全发展。通过演练不断摸索与积累科学有效的经验方法，形成常态化的安全能力水平，营造长远的安全产业生态环境。

 

本次攻防演练活动为期七天，邀请了包括中科院信工所、知道创宇、启明星辰、天融信、深信服等等在内的三十余支全国领先的安全厂商和优秀攻防队伍参加。参加演练活动的团队分为“测试”方与“防守”方，在贵阳市公安机关的授权下，对贵阳市行政辖区范围内的网站、在线信息系统、工控系统等关键信息基础设施进行安全检查。参演团队在活动中以不同的任务形式，通过对授权的近10000个目标进行安全检查，发现了部分无效网站与安全隐患，攻防演练活动取得了实质性的成效。

  

永信至诚作为行业内优秀的安全团队，再次以超群的技术实力拿下了安全创新一等奖。并在2017贵阳大数据及网络安全攻防演练观摩总结大会上，应主办方邀请作为获奖的核心队伍代表向观摩本次攻防演练的领导和嘉宾演示了安全检测过程，就在演练中发现的关键基础设施安全隐患做出报告。

 

![](../Images/47379a74f9dfa0b3c1bf213fe1b0944c.png)

永信至诚副总裁余慧英代表永信至诚队伍领奖

 

在观摩总结大会上，贵阳市副市长徐昊与攻防演练活动总评组组长、国家创新与发展战略研究会副会长郝叶力在总结会上肯定了在网络安全领域企业协同参与的力量，同时也对永信至诚队伍在演练活动中表现出来的思路的创新性与突破性，以及卓越的技术能力表示了高度肯定。

 

![](../Images/a5b306fe743917557b9c772bb3ce618a.png)

贵阳市政府副市长徐昊在总结会上致辞发言

 

![](../Images/46a7d76af413188d86b51eb4fe5d384c.png)

郝会长代表攻防演练活动总评组总结发言，对永信至诚队伍表示了高度肯定

 

随着物联网的普及，越来越多智能家电走入我们生活，电视机顶盒作为最普及的物联网设备，其安全性不仅关乎终端用户体验，更与文化传播，舆论导向，乃至社会稳定和政治安全息息相关。作为本次攻防演练的重点，多只队伍对这一目标一筹莫展。来自永信至诚的队伍在对物联网机顶盒的安全检测过程中，率先发现了这一目标中存在的重要安全隐患，打破了众多队伍在物联网方面的空白，率先实现了在物联网机顶盒方面的重大突破。物联网机顶盒安全隐患的发现，真实的向观摩嘉宾和社会各界展示了物联网安全的重要性，极大的提高了观摩攻防演练的领导嘉宾和群众对物联网设备安全性的重视程度。

 

当前，大数据与网络安全形势不容乐观，而攻防能力是保护网络安全的基础，保持网络安全攻防能力与技术的先进性是重中之重。攻防能力是衡量企业安全能力的重要标准，攻防能力是每一个安全企业的基因和核心竞争力。只有具备一流的安全攻防能力，才能够培养出一流的网络安全人才，为企业和客户提供一流的安全服务。永信至诚始终坚持夯实技术能力，养成良好的网络安全基础技术素养，继续精进自身的网络安全技术水平，坚持以技术的进步推动整个网络安全行业的发展。

 

作为一家老牌的安全公司，永信至诚一直坚持磨砺自己敏锐的安全攻防能力，在各种国家重量级演习、比武中都大放光彩。2016年贵阳大数据与网络安全攻防演练中荣获安全突破奖，2017年在某部委举办的演习比武中均以绝对优势获得第一名的成绩。此次再次获得2017贵阳大数据与网络安全攻防演练安全创新一等奖也并非偶然，而是源于对安全深刻的理解和对技术的打磨。

 

永信至诚将继续深耕网络安全教育领域，通过旗下的i春秋网络安全教育平台和e春秋网络安全实验室为众多政府、企业、高校以及大众提供了综合解决方案，为社会各界培养、输送更多拥有实战能力的优秀网络安全人才。以系统、完备的网络安全知识体系为依托，为广大网络安全爱好者提供线上、线下结合的网络安全人才成长平台，为网络安全人才的成长输送养分。
