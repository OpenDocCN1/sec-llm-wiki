# 第三届上海市大学生网络安全大赛预赛圆满落幕 20支战队晋级决赛

11月5日，2017年全国大学生网络安全邀请赛暨第三届上海市大学生网络安全大赛预赛在上海落幕。本次大赛由中国网络空间安全协会人才培养教育工作委员会指导，上海市教育委员会主办，东华大学承办，永信至诚协办。大赛分为网络攻防赛和信息安全作品赛，在备受瞩目的网络攻防赛中，20支战队以优异的成绩挺进决赛,决赛将于18日在东华大学举行。（决赛名单将在文末公布）

  

据悉，本届竞赛吸引了全国123所高校258支战队报名，规模之大、影响力之广、报名之踊跃远超预期。在万物互联时代，信息安全已经上升为国家战略，上海是国际金融之都，国家经济、科技、工业、航运的中心，全面提升网络安全防护能力，助力国家打造网络强国至关重要。高校师生已经达成共识：以竞赛的形式加强网络安全教育，培养和选拔实战型网络安全人才，对于实现更高层次的网络安全大有裨益。本届竞赛是一颗火种，更丰富多样化的竞赛将从上海出发，在全国形成燎原之势。

  

永信至诚i春秋、e春秋平台，以优异的稳定性、友善的可视化界面，国内外诸多顶级赛事的支撑经验，连续三年为上海市大学生网络安全竞赛提供技术支持。未来永信至诚将进一步加强技术研发与人才培养模式创新，与高政企、高校联合，为社会输送更多信息安全人才。

  

11月18日，决赛在即，20支战队将在东华大学展开最终的角逐。在这样一场对安全理论和攻防实战能力结合的考验中，谁能成功问鼎？让我们拭目以待。
