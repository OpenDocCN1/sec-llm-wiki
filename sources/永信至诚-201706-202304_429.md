# 教育部高教司2017年第二批产学合作协同育人项目公布 永信至诚获批成为合作支持企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDUyMjk4MQ==&mid=2454812301&idx=1&sn=e871899acb0d59430bbaaaf08a9f801f&chksm=8c8f4007bbf8c9111c6c790232c32c73905d15783b942fafcb2b6aec90e51e500792e6db98a7&scene=126&sessionid=1681376030#rd](http://mp.weixin.qq.com/s?__biz=MzAwNDUyMjk4MQ==&mid=2454812301&idx=1&sn=e871899acb0d59430bbaaaf08a9f801f&chksm=8c8f4007bbf8c9111c6c790232c32c73905d15783b942fafcb2b6aec90e51e500792e6db98a7&scene=126&sessionid=1681376030#rd)

2017年9月29日，教育部高等教育司公布了《有关企业支持的产学合作协同育人项目申报指南》（2017年第二批）的函，永信至诚通过专家组审议成为2017年度第二批产学合作协同育人项目合作企业，将就网络安全精品课程建设、师资培训、网络安全实验室三个方向共70个项目提供资源与技术支持。

 

为贯彻落实《国务院办公厅关于深化高等学校创新创业教育改革的实施意见》文件精神，教育部高等教育司启动了2017年度第二批产学合作协同育人项目，旨在搭建校企合作的平台，深入推进产学合作协同育人，汇聚企业资源，支持高校开展新工科研究与实践，推进高校教学内容和课程体系改革、师资培训、实践条件建设、校外实践基地建设、创新创业教育改革和大学生创新创业训练，推进各大高校人才培养工作。

  

![](../Images/25e198ad11d273f673d3ca98eafe23a7.png)

永信至诚作为网络安全教育行业的先行者，一直以“培育信息时代的安全感”为己任，致力于网络安全人才培养工作。永信一直坚持产学研结合、校企合作的人才培养方式，积极探索与各大高校间的合作途径，结合自身多年来在安全培训、赛事运营、安全服务方面所积累丰厚经验，与各大高校展开深度合作，助力网络安全人才的成长。  

  

2015年，永信至诚和北京航空航天大学共同建立了“网络安全实用型人才培养联合实验室”，就共建网络空间安全一级学科、实战型网络安全人才培养、探索人才培养模式等，达成深度合作意向。联合实验室成立两年来，组建了高水平的科研队伍，汇聚了网络安全专家，厚植人才培育的土壤，融入创新于教学，为社会输送了大批量的实用型网络安全人才。

 

2017年9月，由永信至诚主编的《网络空间安全导论》正式出版，这是网络空间安全成为一级学科以来，第一部导论性质的教材，内容涵盖了技术、管理、法律、案例等多领域，为网络安全人才提供了学习网络安全技能的知识源泉。

  

![](../Images/dfcd603f42935f999244e2d9f41baacb.png)

  

此次永信至诚获批成为2017年度第二批产学合作协同育人项目合作企业，是永信至诚在产学结合、校企合作的人才培养模式的一次新探索，为永信与各大高校间的深度合作提供了更高的平台。  

 

在本次项目中，永信至诚将立足教学内容和课程体系改革、师资培训、实践条件建设三大板块，与各大高校共同开展计算机科学与技术、软件工程、网络空间安全、网络工程、信息与计算科学等计算机相关专业之间的深度合作。为合作院校开发网络安全课程、为教师开展线上线下技能和授课培训，提供设备及系统技术支持、专业课讲授、实训项目支持、教学管理支持，按照行业用人标准，与校方共同制定专业共建方案，协助高校建设网络安全学科，建设高水平的师资队伍，与学校共同培养企业应用人才。

  

如今，万物互联的时代已经来临，网络安全正在成为最具潜力的高薪行业之一，但网络安全人才的巨大缺口正在制约着这个行业的发展。人才是网络安全的核心，而高校则是网络安全人才供应链上最大的来源。永信至诚将继续深度探索校企合作的人才培养模式，与各大高校展开更广泛的合作，为社会输送更多的网络安全人才，输送信息时代的安全感。
