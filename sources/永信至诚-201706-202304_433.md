# 永信至诚携手北京航空航天大学 共绘一流网络空间安全学院蓝图

9月16日，2017年国家网络宣传周 （以下简称宣传周）在上海开幕，本届宣传周由中央宣传部、中央网信办、教育部、工业和信息化部、公安部、中国人民银行、新闻出版广电总局、全国总工会、共青团中央等九部门共同举办，延续了“网络安全为人民、网络安全靠人民”的主题。本届宣传周突出网络安全人才培养，并首次开展了一流网络安全学院建设示范项目高校评选活动，永信至诚战略合作高校—北京航空航天大学（以下简称北航）被授牌！

  

![](../Images/c7dad21aeb368628dd911aedf855903e.png)

  

万物互联时代，网络安全日益重要。网络安全，人是核心。2015年，永信至诚和北航共同建立“网络安全实用型人才培养联合实验室”（以下简称联合实验室），就共建网络空间安全一级学科、实战型网络安全人才培养、探索人才培养模式等，达成深度合作意向。联合实验成立两年来，组建了高水平的科研队伍，汇聚了网络安全专家，厚植人才培育的土壤，融入创新于教学，在大批网安人才背后默默付出。本次北航获评“一流网络安全学院建设示范项目高校”，是国家对联合实验室的肯定，为校企合作模式更广泛的开展奠定了基础。

![](../Images/09c929870335fa9d56c8cb1037344e06.png)

据悉，联合实验室的建立，是基于2015年8月，永信至诚与北航签订的《战略合作框架协议》，依托北航深厚的专家力量，搭载了永信至诚“i春秋”实训课程和“e春秋”实战平台，充分发挥协同创新作用，在多领域取得了丰富的硕果。  

  

**突破传统教育瓶颈，共建网络空间安全一级学科**

网络安全的竞争，归根结底是人才的竞争。据统计，我国网络安全人才缺口达70万，每年递增1.5万。为了实现网络安全水平的整体跃升，人才缺口的解决迫在眉睫。但由于发展的局限性，我国高校普遍存在学科专业设置不足、教材重理论化、学生缺乏实践等问题。

  

针对传统教育的痛点，双方在网络空间安全学科知识点的梳理，理论实践兼具教材的编写，实践实训基地的共建，学士、硕士、博士的培养等方面达成合作。两年来，双方在网络空间基础理论建设、综合性课程体系的研发方面取得了重大成果。今年9月，由永信至诚主编，北航李舟军老师参与编辑的《网络空间安全导论》正式出版，这是网络空间安全成为一级学科以来，第一部导论性质的教材，该教材内容涵盖技术、管理、法律、案例等多领域，在现今知识量足够大足够宽，能够开启学生成才之大门。

  

**集资源之大成，开启人才培养新模式**

依托联合实验室，双方发挥各自优势，联手发力，深入探索实用型人才培养模式。为提高人才实战水平，实验室创新性引入永信至诚“e春秋”平台，将知识培训、技能训练、仿真演练、竞赛比武融为一体，学生通过实战，对知识梳理更清晰，对自我认知更全面。2015年开始，CTF竞赛在全国蓬勃发展，北航战队在全国大学生竞赛、XMan等取得了优异的成绩。2017年初，经北京市发改委专家评审，永信至诚“网络空间安全智能仿真和众测关键技术与服务北京市工程实验室”正式获批，该实验室以北航李舟军老师作为首席科学家，重点围绕

智能仿真和众测的技术领域，能够向社会提供一系列定制化的应急响应及渗透测试安全服务，输送大批量实用型网络安全人才。

  

在当前网络安全人才稀缺的形式下，永信至诚依托多年来在安全培训、赛事运营、安全服务方面的深厚积累，通过校企合作方式，将企业实践与高校理论紧密结合，无疑是培养和选拔实战型网络安全人才的途径。此次与北航合作，建立了成功的校企合作模式，永信至诚将以此为开端，与加深与政府、高校、企业的合作，为国家输出更多网络安全实战型人才，为信息时代提供坚实的安全感。
