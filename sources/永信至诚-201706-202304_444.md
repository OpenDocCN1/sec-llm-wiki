# i春秋学院2017 年度首届全国高等院校网络空间安全专业师资培训活动圆满落幕

2017年8月7日，i春秋2017年度首届全国高等院校网络空间安全专业师资培训在成都圆满落幕。本届师资培训活动由江苏省计算机学会、电子科技大学信息与软件工程学院主办，永信至诚旗下i 春秋承办。i 春秋教研中心总监、高级安全工程师孙义，高级教研研究员卫子伟等应邀出席本届师资培训活动。

  

![](../Images/921bd72135868882537ca1b22b7929c7.png)

（i 春秋教研中心总监孙义正在对参会教师进行培训）

  

本届师资培训活动的举办，旨在进一步推动全国高等院校网络空间安全相关专业建设及人才培养工作的开展，加强国内各高等院校同行间的交流，培养国内网络空间安全专业的师资力量。对当前网络空间形势下的人才与技能需求进行分析，探讨以 Web 安全与二进制安全为主要方向的网络空间安全课程体系的规划与建设，并对信息安全竞赛人才培养的方向提供指导。

本届培训基于对网络空间安全人才需求与技能需求的深入分析，以建设合理的、专业的、符合目前网络空间安全形势的专业教育体系为目的，着力于对网络空间安全的主要课程内容：Web 应用安全、二进制安全方向进行深入的理论讲解与技术实践，并对信息安全攻防竞赛的人才培养与技能培训进行规划，形成以学、练、赛为基石的系统性、全方位、多维度课程培训体系。

  

![](../Images/da3c8e76335aef0cb5c521fe6ef0f53e.png)

（参会老师与i 春秋教研中心总监孙义探讨人才培养模式）

  

作为国内知名的信息安全在线教育平台，i春秋始终扎根于网络安全人才培养工作。以“培育信息时代的安全感”为使命，通过独创性的技术，凝聚、精炼中国互联网安全十多年的实践经验和理论系统，独创的人才培养模式，为社会精准、高效的输送具备实战能力的网络安全人才，获得了广大网络安全人才和广大高校、企业的认同。

  

![](../Images/4cc3b221410900ee360259f338ea00ae.png)

（参会专家与教师合影）

  

本届师资培训活动的成功举办，是i春秋对网络安全人才培养模式的一次新探索。通过与全国各大计算机学会以及各大高校的联合，加强对师资力量的整合，帮助高校一线教师提升专业技术水平和授课能力，为网络安全人才培养添柴助力。  

未来，i春秋将继续深度探索网络安全人才培养模式，与更多高校与企业加强合作，优势互补，为国家和企业输送更多优秀的网络安全人才。
