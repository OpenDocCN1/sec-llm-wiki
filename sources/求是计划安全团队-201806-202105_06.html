  • 限制:

    • 需要定制dd包.

  1. 开启内置Administrator账户登录(配置自动登陆)..

  2. 开启远程桌面(默认3389端口).

  3. 禁用UAC..

  4. 适当的调整防火墙.(可选)

  • 需要相关的虚拟化驱动.

    • <0041 style="box-sizing: border-box;">VirtIO驱动0041>(备份下载) XEN驱动(备份下载)

  • dd包解压后的体积不能超过机器第一块硬盘的最大容积.

  • 个人Ubuntu18.10安装失败，Debian8 x64无障碍成功

  • 网上公开制作好的DD包：http://arv.asuhu.com/dd/(安装需VNC设置密码)

    • 使用方法:


    wget --no-check-certificate -qO InstallNET.sh 'https://moeclub.org/attachment/LinuxShell/InstallNET.sh' && bash InstallNET.sh -dd '[Windows dd包直连地址]'


    • 使用示例:（下面的包无需VNC,SSH掉了等待几分钟再连接3389）


    wget --no-check-certificate -qO InstallNET.sh 'https://moeclub.org/attachment/LinuxShell/InstallNET.sh' && bash InstallNET.sh -dd 'https://moeclub.org/onedrive/IMAGE/Windows/win7emb_x86.tar.gz'

  • 可能用到的命令:


    • ::以管理员身份运行CMD::

    ::更改用户的密码
    net user [用户名] [密码]
    ::激活 Administrator 账户
    net user Administrator /active:yes
    ::设置 Administrator 账户密码
    net user Administrator [新密码]
    ::添加用户
    net user [用户名] [密码] /add
    ::将用户添加至 Administrator 组
    net localgroup Administrators [用户名] /add
    ::删除用户
    net user [用户名] /del

  • 注意事项:

    1. 远程登陆账号为: Administrator

    2. 远程登陆密码为: Vicer

  • 注册表禁用UAC


    • RegKey="HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" Value="ConsentPromptBehaviorAdmin" Type="REG_DWORD" Data="0" Value="EnableLUA" Type="REG_DWORD" Data="0" Value="PromptOnSecureDesktop" Type="REG_DWORD" Data="0"

  • 开启UAC

    • RegKey="HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" Value="ConsentPromptBehaviorAdmin" Type="REG_DWORD" Data="5" Value="EnableLUA" Type="REG_DWORD" Data="1" Value="PromptOnSecureDesktop" Type="REG_DWORD" Data="1"
