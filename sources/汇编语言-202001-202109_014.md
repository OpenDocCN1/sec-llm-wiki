看下面的例子：

*   
*   

```
GROUPBOX "选项", -1, 55, 5, 120, 100PUSHBUTTON "退出", IDCANCEL, 255, 115, 50, 14
```

这两条语句和下面的语句编译后产生的二进制资源文件是一模一样的：

*   
*   

```
CONTROL "选项", -1, "Button", BS_GROUPBOX | WS_TABSTOP, 55, 5, 120, 100CONTROL "退出", IDCANCEL, "Button", BS_PUSHBUTTON | WS_TABSTOP, 255, 115, 50, 14
```

  

第一种语句的用法比第二种语句不但要直观许多，而且不必书写默认的窗口风格。

当用到的控件没有缩写语法时，那就必须用CONTROL定义了，下面的两句分别定义了一条横线和一个图片框，它们并没有缩写的用法：

*   
*   

```
CONTROL "", -1, "Static", SS_ETCHEDHORZ | WS_CHILD | WS_VISIBLE, 60, 65, 110, 1CONTROL BMP_ID, -1, "Static", SS_BITMAP | WS_CHILD | WS_VISIBLE, 5, 5, 40, 95
```
