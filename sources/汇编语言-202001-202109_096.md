# 对面秒选猪八戒、廉颇怎么办？不用老夫子，出影刃的他完美克制

王者荣耀目前已经上线105位英雄，每个赛季游戏中都没一些比较强势的上分英雄。对抗路是很多玩家用来上分的路线，很多玩家喜欢在对抗路1v1击杀对方，但是当我们选的英雄被对方克制的时候，很难在游戏中打出应该有的水平。现在S23赛季坦克英雄非常受欢迎，比赛中几乎每局都不可缺少开团的坦克英雄，当对面秒选猪八戒、廉颇怎么办？不用老夫子，出影刃的他完美克制！

![](../Images/356b2454bb485fe77273deb7ed5f725b.png)

**猪八戒**

猪八戒在S23赛季惩戒流打法可以说是大放异彩，不仅拥有极高的坦度，伤害也提升了许多。对线时期的河道蟹几乎都被二师兄收入囊中，利用技能迅速推线之后不仅可以对其他路线队友进行支援，还能够入侵敌方野区，打乱对方刷野节奏的同时提升自己的经济。中后期打团找到机会可以直接进场开团，一旦被八戒推到墙上很容易配合队友击杀。

![](../Images/039ae7379d0a0a8ab6f1660156b90bf1.png)

**廉颇**

廉颇在对抗路的对线能力也不俗，特别是前期121技能连招可以打的对方很难还手，廉颇清线速度很快，但是支援能力不足，所以要充分发挥线上有线权的优势，把对方留在边路没有空暇支援。廉颇的战意值决定了其伤害与抗伤能力的高低，所以控制好战意值很重要。前期优势大的时候可以购买暗影战斧提升自身输出能力。

![](../Images/7f8d598cd574aee31cc93631ae120f99.png)

**老夫子**

老夫子在边路有着极高的登场率，特别是对线一些攻击距离比较短的坦克英雄，老夫子凭借二技能的减伤效果能够和对方完美换血。会玩的老夫子喜欢在前期直接扛着兵线清兵抢2，到了4级之后主动支援能力变强，利用大招的捆绑不仅可以留人还能够主动出击，对手一旦被捆到只能接受死亡。后期可以通过深带线给予对方压力，眼里只有防御塔，夫赖行为完全可取。

  

![](../Images/901f48276f64cb4b95bf337d27a5dc38.png)

**吕布**

面对一些坦克英雄的时候吕布可以说很大程度上存在克制，毕竟吕布拥有的100%真伤效果对于出肉装的坦克来说非常致命，但是吕布的强度在这个赛季并不是很强，很多时候吕布都会购买半肉装备，不在一味追求纯输出的装备，不过破军影刃仍然可以购买，否则伤害会显得非常低。中后期打团直接大招跳后排，即使不能秒杀对方c位，也可以很大程度限制其输出空间！你们喜欢用他上分吗？
