# “最弱”法师确定，不是妲己甄姬，而是连续多次登顶T0的她

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247485736&idx=5&sn=bbfc40a6d618905190f7ca60b8012d67&chksm=97a22d8aa0d5a49c6167966a32b8f99280d62a2d61798733751501405d9b998ad77a5d733273&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247485736&idx=5&sn=bbfc40a6d618905190f7ca60b8012d67&chksm=97a22d8aa0d5a49c6167966a32b8f99280d62a2d61798733751501405d9b998ad77a5d733273&scene=27#wechat_redirect)

在王者荣耀中，法师英雄一般拥有强大的控制、远程消耗和瞬间爆发能力，特别是王昭君、甄姬等法师英雄，完美演绎了什么叫做“有控好打团”。法师英雄在团战中的优势尤为明显，只要技能控制敌人，就能轻松打赢团战。不过法师英雄自身也很脆皮，也是刺客英雄击杀的首要目标。随着版本的更新，“最弱”法师确定，不是妲己甄姬，而是连续多次登顶T0的她。  

![](../Images/39eea42c11619a4ada692cd57a868eb7.png)

妲己

妲己是一名拥有强力控制和瞬间爆发的法师英雄，被动技能在技能命中敌人时，能够降低敌人最高216点法术防御。妲己的操作也很简单，23技能都是指向性技能，只要在妲己的施法范围内，技能就能100%命中敌人，属于“有手”就行的那种。

![](../Images/bcdba2dd27978b39168ffea94cb41391.png)

妲己的二技能能够控制敌人长达1.5秒，妲己的大招又是一个爆发伤害很高的技能，再加上1技能的高额伤害，一套技能100%秒杀脆皮。不过妲己的技能空档期较长，容易在没有技能的情况下被敌人击杀。由于操作简单，伤害爆炸又有控制，妲己也是玩家最爱的法师英雄。

  

![](../Images/af386c1fe0db78caab8cf603f767bf99.png)

甄姬

妲己最大的优点就是单体爆发伤害很高，能够瞬间秒杀单个英雄，如果大招的伤害被多名敌人分担之后，输出就会乏力。和妲己相比，甄姬在团战的消耗和控制方面就要优秀得多了。甄姬的二技能可以在多名敌人之间进行弹射，在造成高额伤害的同时，最多每人打上2层冰冻印记。

![](../Images/63bac9e11875117b3d8cd2092e0745f6.png)

甄姬的冰冻印记一旦达到3层之后，就会冰冻敌人1秒。一秒的冰冻对敌人来说十分难受，尤其是在团战前的消耗中，对面的敌人越多，甄姬二技能弹射的威力就越大。特别是一不小心被甄姬冰住一个脆皮的情况下，开团几乎100%能赢。

![](../Images/304bcc3faa8c04d1a09a9f85230846b9.png)

钟馗

钟馗是辅助型法师，在官方最近公布的数据中，拥有超过25%的禁用率，是个十分恶心的英雄。钟馗作为一名辅助法师，和普通法师最大的区别就是血厚。钟馗每击杀或者获得一个助攻，就能够增加180点最大生命值，最多叠加20层，也就是3600点生命值，几乎相当于两件霸者重装。

![](../Images/798c701c569105c1d23d153c2efca006.png)

很多人说钟馗钩子不中的情况下，就是一个对面射手的“回血包”，就是一个只会普攻的超级兵。其实不然，钟馗在被敌人攻击时，会产生自爆效果，可以炸伤敌人，比反甲的效果好上百倍，再加上一技能的控制，配合队友是也能够轻松击杀敌人。

![](../Images/9b792249b76e446657e81283cfb5d588.png)

安琪拉

最近，“最弱”法师确定，不是妲己甄姬，而是连续多次登顶T0的安琪拉。安琪拉是当前版本最热门的法师英雄，有着高达26.8的出场率，不仅操作简单，伤害爆炸，而且还具备很强的控制效果，一旦技能命中敌人，敌人将没有任何的逃跑可能。

![](../Images/c9c683b8c2b08e7e3157abff1ebe389f.png)

安琪拉是草丛三姐妹的代表人物，二技能的火焰术十分暴力，一旦正面命中敌人，能够对敌人造成1秒的眩晕，同时造成1.5秒的减速效果。一般来说，只要二技能命中敌人，再接大招伤害，即使是程咬金也抗不过2秒。不过安琪拉的技能空档期太长，很难适应当前版本的高强度战斗，说是最弱法师也不为过。
