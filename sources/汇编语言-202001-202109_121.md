# 唯一免费的射手，1级打不过伽罗，满级被李元芳欺负，却人气最高

王者荣耀中射手这个职业的英雄是玩家最喜欢的一个职业，射手有着稳定的输出，以及强大的后期翻盘能力。由于现在发育路的出现，让射手职业的英雄，成为了当之无愧的团队C位，一位射手的强弱，完全决定一位队伍的胜负。唯一免费的射手，1级打不过伽罗，满级被李元芳欺负，却人气最高。

**伽罗**

![](../Images/e0732b7850475d43bf27e1b1c5af5862.png)

这位英雄一出场就是巅峰级的射手，毕竟可以增加射程的1技能，让伽罗这位英雄极其有优势。而且普攻的暴击效果，让伽罗这位英雄自带红BUFF，特别是攻速和暴击起来以后，这位英雄相当恐怖。而伽罗这位英雄在前期是比较孱弱的。因为没有位移，很容易被对手击杀，前期是伽罗最大的弱势期。

**李元芳**

![](../Images/0be3a346d7596865cab2be6dd00a6292.png)

这位英雄最近几个赛季还是比较火爆的，因为黄打野刀的出现，让李元芳的打野速度得到了提升，而且黄刀还带有真实伤害效果，配合李元芳的2技能位移和大招的范围减速效果，中前期的李元芳游走能力极强，不过后期李元芳的伤害有限，不速战速决的话，李元芳后期是没有任何优势的。

**蒙犽**

![](../Images/3edb3fa45163bb46ece4cbac5d46f8bf.png)

这位英雄经过了几次削弱后，这位英雄已经成为了冷门射手。不过这位英雄在昨天的更新中，加强了1技能的伤害，这让蒙犽这位英雄的输出能力得到了，特别到了后期，蒙犽的伤害更是爆表。这个加强也让蒙犽的胜率飙升，成为了一位热门射手。

**艾琳**

![](../Images/845583074b8de6ecc613ede9e5e5bdf9.png)

唯一可以免费获得的射手英雄那就是艾琳了。艾琳这位英雄由于是一位内测英雄，之前很多人是没有的。这也让艾琳成为了老玩家的情怀。重做后的艾琳成为了一位AP射手，由于依靠法术伤害，这让艾琳这位英雄的普攻伤害一般，而且攻速较低。使得艾琳在前期对线任何射手不占优势。而后期的艾琳技能伤害更是刮痧。可以说现在的艾琳强度是比较低的。这也让艾琳这位英雄的胜率垫底，但是由于情怀的原因，这位英雄却是人气最高的射手。大家喜欢艾琳这位英雄吗？
