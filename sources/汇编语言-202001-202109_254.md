# 汇编语言ROR（循环右移）指令：将操作数所有位都向右移

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247483925&idx=5&sn=59862454b3aa030247346bd16cdbfe3f&chksm=97a226b7a0d5afa124c3385be7832737e2a516567b2052f9ae41c56528c362f4eea888923aed&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247483925&idx=5&sn=59862454b3aa030247346bd16cdbfe3f&chksm=97a226b7a0d5afa124c3385be7832737e2a516567b2052f9ae41c56528c362f4eea888923aed&scene=27#wechat_redirect)

ROR（循环右移）指令把所有位都向右移，最低位复制到进位标志位和最高位。该指令格式与 SHL 指令相同：  
  

![](../Images/386b841ddcaf51dea8649b1bfd387590.png)

  
在下例中，请注意最低位是如何复制到进位标志位和结果的最高位的：  

*   
*   
*   

```
mov al, 0lh          ; AL = 00000001bror al, 1               ; AL = 10000000b, CF = 1ror al, 1               ; AL = 01000000b, CF = 0
```

#### 循环多次

当循环计数值大于 1 时，进位标志位保存的是最后循环移出 LSB 的位：  

*   
*   

```
mov al, 00000100bror al, 3              ; AL = 10000000b, CF = 1
```
