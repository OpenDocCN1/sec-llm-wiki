# 汇编语言NOT（反码）指令：翻转操作数的所有位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247483894&idx=3&sn=79244fc2d57be5cc890f8ac83ce2bd2a&chksm=97a22554a0d5ac4249c254f37cae8e66b8e0312c916307d679a75d911dff6401454d878728a1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247483894&idx=3&sn=79244fc2d57be5cc890f8ac83ce2bd2a&chksm=97a22554a0d5ac4249c254f37cae8e66b8e0312c916307d679a75d911dff6401454d878728a1&scene=27#wechat_redirect)

NOT 指令触发（翻转）操作数中的所有位。其结果被称为反码。该指令允许的操作数类型如下所示：  

*   
*   

```
NOT regNOT mem
```

例如，F0h 的反码是 0Fh：  

*   
*   

```
mov al,11110000bnot al                          ;AL = 00001111b
```

> 提示：NOT 指令不影响标志位。
