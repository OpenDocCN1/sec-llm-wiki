# 欧盟将在2023年颁布并执行重大反垄断规定

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247492070&idx=4&sn=2f0c8482f9b27e95c13e1c9b2d64928d&chksm=97a1c544a0d64c52146a99d8a66d4ed49bf2f6e3606ccab938eeb6576325dd47143cd817f9fc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247492070&idx=4&sn=2f0c8482f9b27e95c13e1c9b2d64928d&chksm=97a1c544a0d64c52146a99d8a66d4ed49bf2f6e3606ccab938eeb6576325dd47143cd817f9fc&scene=27#wechat_redirect)

据外媒报道，欧盟新的重大反垄断法规很可能将于明年春季生效。这些规定包含在《数字市场法案》（DMA，Digital Markets Act）之中，旨在控制科技巨头的权利。一旦通过，将会迫使各科技巨头对其业务运营进行彻底的改革。 此前欧盟原计划于今年秋季即实施这些规定，如今略有推迟。但欧盟反垄断主管Margrethe Vestager的态度还是一贯的坚定且明确。“DMA将于明年春天生效，一旦收到第一批通知，我们就准备执行。”Margrethe Vestager周四在柏林的一次演讲中如此表示——针对不守规矩的“守门人”的执法很快就会到来。 “守门人”（Gatekeepers）指苹果、谷歌、亚马逊、微软、Meta之类充当企业与用户之间的中介的科技与互联网巨头，它们通常拥有巨额财富，占据市场主导地位，手握关键的数据资源。 近年来，以苹果为例，它不仅在欧盟，还在美国、日本、韩国和荷兰等地都受到越来越多的反垄断审查。对苹果而言，这就可能迫使其商业模式发生重大改变，如允许用户从App Store以外的渠道下载应用程序、使iMessage和FaceTime能与其他通信平台（如WhatsApp）互操作等。 根据DMA，不合规的“守门人”公司将面临罚款，罚款总额可高达其全球年总收入的10%。而对于屡犯不改者，这一罚款比例可以上升到20%。
