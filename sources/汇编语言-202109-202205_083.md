# Conti网络攻击使哥斯达黎加网络瘫痪

近日，因遭受网络攻击，中美洲国家哥斯达黎加政府计算机系统瘫痪近一周。Conti勒索软件团伙声称对此攻击事件负责。

 

攻击发生在上周初，哥斯达黎加财政部首当其冲，它的一些系统从税收到通过海关机构的进出口过程都受到影响，不久后对社会保障机构人力资源系统和劳工部以及其他方面的攻击接踵而至，影响范围涵盖哥斯达黎加多个政府服务。

 

哥斯达黎加出口商会执行主任Christian Rucavado表示，对海关机构的攻击使该国的进出口物流崩溃（哥斯达黎加平均每天出口约3800万美元的商品）。冷藏库中等待转运的易腐物品正与时间赛跑，无法对经济损失有确切的估计。

 

![](../Images/f9ed9cf48097773f0d25352bd6c95396.png)

  

上周五，Conti在其勒索网站上表示，它已经公布了50%的被盗数据，这些数据包括来自财政部和其他机构数据库的超850GB文件。

 

Conti通常将其勒索软件基础架构租给为服务付费的“附属公司”，因此，攻击哥斯达黎加的分支机构可能存在于世界上的任何地方。Conti尚未公布具体的赎金要求，但哥斯达黎加总统已表明不会向这些网络犯罪分子支付任何费用。

 

哥斯达黎加企业担心勒索软件团伙可能已经渗透到他们提供给政府的机密信息中。这些数据的泄漏可能会给这些机构带来严重的风险。而对普通公民来说，他们的财产安全可能会受到严重威胁。
