# 马斯克拟 434 亿美元收购 Twitter

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247490809&idx=6&sn=93b84e54727d5506c7cd1f408cbf99f4&chksm=97a2385ba0d5b14d89ca94ceff5d2af995d888dccc3778bea8d4fa1b0a161678b2313eab7c84&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247490809&idx=6&sn=93b84e54727d5506c7cd1f408cbf99f4&chksm=97a2385ba0d5b14d89ca94ceff5d2af995d888dccc3778bea8d4fa1b0a161678b2313eab7c84&scene=27#wechat_redirect)

Elon Musk近日提出以每股54.20美元、合计434亿美元的价格收购Twitter，声称这家社交媒体公司需要转型、变成私营公司。  
![](../Images/3adffe310fc306feced8d176689fce5e.png)  
Musk在致Twitter董事会主席Bret Taylor的一封信中写道（并在向证券监管部门提交的文件中透露）：“我投资了Twitter，因为我认为它有潜力成为全球言论自由的平台，我认为言论自由是民主体制正常运作的一个必要的社会条件。”  
这是Musk致Twitter董事会主席Bret Taylor的信函，在向证券监管部门提交的文件中予以披露：  

![](../Images/1780acd13e61a42a64adeee010abff9d.png)

  

  

我投资了Twitter，因为我认为它有潜力成为全球言论自由的平台，我认为言论自由是民主体制正常运作的一个必要的社会条件。  
然而，自从我投资Twitter以来，我现在意识到该公司既不会蓬勃发展，也不会以目前的形式成为这个必要的社会条件。Twitter需要转型，成为一家私营公司。  
因此，我提出以每股54.20美元的现金买下Twitter 100%的股份，比我开始投资Twitter前一天溢价54%，比公开宣布我的投资前一天溢价38%。我给出了我能给出的最高也是最终的报价；如果这个报价不被接受，我需要重新考虑我作为股东的地位。  
Twitter具有非凡的潜力。我会发掘这个潜力。  
Elon Musk  
最近几周，Twitter股价因Musk方面的新闻出现了波动，但今年上涨了6%，自本月初以来更是猛涨18.5%。
