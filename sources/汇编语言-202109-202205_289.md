# 34岁高材生发现漏洞，发动全家跑“假单”，一个月非法获利50万！

> **文章来源：****搜狐网**

大家上学的目的都是希望毕业后都能找到一个好工作，通过所学的知识努力挣钱，过上好日子，也的确很多毕业生学以致用，过上了自己想要的生活，然而有些人却利用自己所学的知识非法牟利，实在令人感到惋惜。这不，34岁的高材生发现专车漏洞，一个月非法获利50多万元，最终也为自己的行为买单。  

  

![](../Images/460bf67d90e7f73b676596a029c4739c.png)  
![](../Images/d6c78abf30568498ad1ab5e786b3e31e.png)  
![](../Images/5aa06dbbbad42e9a47f9ab12c5a64ccf.png)

  

34岁的陈某，是四川某高校法律系的本科毕业生，除了自己的专业之外，他对时下热门的IT行业也兴趣颇深，自己学习自己研究，手机、计算机、互联网都玩儿得得心应手。然而，今年5月，自我感觉“技多不压身”的他却站上了法庭的被告席，和他一起接受审判的，还有他的父母双亲。

  

![](../Images/9c5783729ca904becfec63e82da5fd27.png)  
  
  
![](../Images/6ef3461e21f7d7a87543147f2f37274f.png)

  

事情还要从近几年兴起的一个打车软件，18年1月底，他在一次打网约车时发现车费并没有从他的信用卡中扣除，随后的一段时间内，他连续打车都出现相同的情况，他意识到可能是滴滴或银行方面出现了故障，他就动起了歪脑筋，在网上联系司机进行刷单获利，即是让司机跑车，他用自己的账号（总共有一两百个）打车，支付车费后，再跟司机进行分成（20％-50％），为多赚钱，他就给老家的父母打电话让他们也注册账号一起做。

  

![](../Images/3bcf4c5ff327310959f6312bdf370afd.png)

  

据了解，陈某的父亲是个有着20多年驾龄的老司机，平日里开着自己的面包车跑拉客，在儿子的安排和授意下成功，他每天搭载五部手机跑起了空滴滴，给他派单的就是儿子（共获利7万多元）。短短一个月时间，陈家非法获利50多万，而这些钱转眼就被陈某买了车子（20多万宝马）房子（40多万）。

  

![](../Images/311edaf27ec0996bf850ea1b956e9c1a.png)

  

2018年3月，滴滴发现问题后，立即将涉及虚假订单的滴滴账号全部封停，并对部分虚假订单拦截扣款挽回经济损失66万余元，同时向警方报案。公安机关经过侦查发现虚假订单大多从成都市成华区某居民小区发出，并很快锁定了犯罪嫌疑人陈某。

  

![](../Images/6567e97e7f33e2b0550f9a35ce8e1c49.png)  
![](../Images/1314978d5d9319649c00563b45c18739.png)  
![](../Images/faf748062af01de850773fbb7e7137e8.png)  
![](../Images/7b3e6bb3871443db0c52cd1eab2c129a.png)

  

陈某到案后，依仗自己法律专业毕业，避重就轻地交代问题，甚至站上法庭依然企图减轻自己的罪行，他觉得当时他并没有销毁证据而是等待民警上门，属于自首，虽说到案之后的供述前后反复，但是最后他当庭认罪，应当不影响自首的认定，同时他认为父母在法庭上认罪，其实是为了帮自己争取宽大处理。
