JS与Qt对象交互：
JS->Qt:创建一个插件，然后在网页中使用embed标签嵌入Qt控件，它的所有public slots就像普通函数一样被网页中的JavaScript函数访问。
Qt->JS:网页加载JS函数完成后，Qt程序通过evaluateJavaScript函数就可以执行JS函数。

JS->Qt:
1）定义一个插件类，继承于QObject和WebKitPluginInterface：
class EPGPLUGINSHARED_EXPORT EpgPlugin : public QObject, public WebKitPluginInterface  {    Q_OBJECT    Q_INTERFACES(WebKitPluginInterface) //声明WebKitPluginInterface是一个接口public:    EpgPlugin();    ~EpgPlugin();protected:    QList<:plugin> plugins() const;    QObject *create(const QString &mimeType,                            const QUrl &url,                            const QStringList &argumentNames,                            const QStringList &argumentValues) const;    void setWebView(QWebView *webView) {this->webView = webView;}    QWebView *webView;private:    EpgDemo *label;//Qt控件};
2）实现的plugins方法，告诉浏览器插件支持的mimeType：
QList<:plugin> EpgPlugin::plugins()const{
    QWebPluginFactory::MimeType mimeType1;    mimeType1.name="application/x-qt-label";//添加插件支持的mimeType    mimeType1.description=QObject::tr("label");
    QList<:mimetype> mimeTypes;    mimeTypes.append(mimeType1);
    QWebPluginFactory::Plugin plugin;    plugin.name=QObject::tr("epg plugin");    plugin.description=QObject::tr("epg plugin");    plugin.mimeTypes=mimeTypes;
    QList<:plugin> plugins ;    plugins.append(plugin);    return plugins;//返回插件}
3）实现的create方法，给浏览器返回Qt控件：
QObject *EpgPlugin::create(const QString &mimeType,                const QUrl &url,                const QStringList &argumentNames,                const QStringList &argumentValues) const{    qDebug() << "EpgPlugin::create";    Q_UNUSED(argumentNames);    Q_UNUSED(argumentValues);
    label->webView = webView;    label->setPixmap(QPixmap("/opt/test.bmp"));    return label;//返回Qt控件}
4）自定义的控件类：
class EpgDemo : public QLabel{    Q_OBJECTpublic:    EpgDemo();    ~EpgDemo();    void hide();public slots:    void version();    int getId(int id);public:    QWebView *webView;};
5）HTML中，Qt控件使用embed标签创建：
<embed type="application/x-qt-label" id='label' units="pixels" height=200 width=200 />
JS可以使用document.getElementById("label")获取到Qt控件的对象，然后就可以直接调用该对象的public slots方法。
