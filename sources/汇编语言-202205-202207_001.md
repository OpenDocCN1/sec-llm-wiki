JS与Qt对象交互：  
JS->Qt:创建一个插件，然后在网页中使用embed标签嵌入Qt控件，它的所有public slots就像普通函数一样被网页中的JavaScript函数访问。  
Qt->JS:网页加载JS函数完成后，Qt程序通过evaluateJavaScript函数就可以执行JS函数。

    QWebPluginFactory::MimeType mimeType1;    mimeType1.name="application/x-qt-label";//添加插件支持的mimeType    mimeType1.description=QObject::tr("label");
    QList<:mimetype> mimeTypes;    mimeTypes.append(mimeType1);
    QWebPluginFactory::Plugin plugin;    plugin.name=QObject::tr("epg plugin");    plugin.description=QObject::tr("epg plugin");    plugin.mimeTypes=mimeTypes;
    QList<:plugin> plugins ;    plugins.append(plugin);    return plugins;//返回插件}
