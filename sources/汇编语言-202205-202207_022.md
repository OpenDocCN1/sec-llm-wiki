# 在Qt中使用Font Awesome图标

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247493771&idx=1&sn=29e787b1b0b561699e911bcbba15f285&chksm=97a1cc29a0d6453fed404f2dc5e9f776040359b1321f13c0f30cd7f6f1456bb642db2673e640&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247493771&idx=1&sn=29e787b1b0b561699e911bcbba15f285&chksm=97a1cc29a0d6453fed404f2dc5e9f776040359b1321f13c0f30cd7f6f1456bb642db2673e640&scene=27#wechat_redirect)

做过Web前端开发的一定对Font Awesome不会陌生，Font Awesome号称是为Bootstrap设计的完美图标字体，经常出现在各类网页中，非常流行。

这么好的资源，能不能在Qt应用程序中使用呢？答案是肯定的。而且使用起来非常简单。

1\. 先来了解下 Font Awesome 的一些特性：

![](../Images/57a5ce18f75f3c2d4fc4f208e7102dd5.png)

更多关于Font Awesome可以前往其官网【了解详情】。

2\. 下载 Font Awesome（本示例使用的是Font-Awesome-3.2.1版）

![](../Images/0a7127575dbbf95150ee4d98bc546024.png)

解压后得到的文件如下：

![](../Images/592b10ea46708097c1c8bbe555495fbb.png)

【font】目录下的【fontawesome-webfont.ttf】为我们需要的文件，其他文件暂时先忽略。

 3. 创建一个Qt项目，并将字体文件【fontawesome-webfont.ttf】添加到项目资源中

![](../Images/5724418ef1e889c0654bacbea35629e4.png)

4.接下来，先编写一个帮助类，帮助我们更方便的使用FontAwesome

// fontawesomeicons.cpp#include "fontawesomeicons.h"#include 
FontAwesomeIcons &FontAwesomeIcons::Instance(){    static FontAwesomeIcons _instance;    return _instance;}
QFont FontAwesomeIcons::getFont(){    return this->font;}
QChar FontAwesomeIcons::getIconChar(FontAwesomeIcons::IconIdentity code){    return QChar((int)code);}
FontAwesomeIcons::FontAwesomeIcons(){    // add font file    int fontId = QFontDatabase::addApplicationFont(":/font/fontawesome-webfont.ttf");    QStringList fontFamilies = QFontDatabase::applicationFontFamilies(fontId);
    Q_ASSERT_X(fontFamilies.size()==1,"font","font not exist.");
    this->font.setFamily(fontFamilies.at(0));}
