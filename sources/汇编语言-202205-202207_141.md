什么是多线程编程呢，网上很多从计算机组成原理和操作系统深入讲解的多线程的一些文章，这些知识当然很有用也很硬核，掌握理解了有很大的帮助，但是也常常看的我有点头晕。最近在看Qt多线程编程的一些知识，也算是了解了一点点关于Qt多线程的内容，根据个人理解以尽可能通俗易懂（所以也可能会有一些不确切的地方，欢迎批评指正）把一些相关知识记录分享一下，希望能够帮助到一些朋友。

从我个人的理解来解释多线程编程就是把**不同的事情**或者**同一件事情的不同模块**交给**不同的线程**去做，这些线程通常情况下都是能够**并行进行**的（不能并行的话也就不需要开多个线程了，直接一个线程按照顺序来执行就好了），但是在涉及到**公共资源使用**的时候由于互斥锁或者一些其他情况（比如线程的优先级，线程等待等）使得某个线程需要休眠，在互斥锁解开（unlock）后或者一些其它情况下线程被唤醒继续运行。

用一个简单的例子来比喻就是，**小A**和**小B**两个人一起准备一顿饭，小A负责**买菜**和**准备主料**（比如肉菜等）和**炒菜**，但是还有些**辅料**（比如姜蒜葱等）在炒菜的时候也是必须的，但是**时间又有限**，如果买菜准备主料和辅料以及炒菜**全部由小A一个人做**的话时间来不及，所以就把**准备辅料的任务交给了小B**去做，也就是说小B给小A打下手哈哈。

那么整个准备一顿饭的就可以分为 **买菜 准备主料 准备辅料 炒菜** 这四个部分。那么具体的流程就是 小A先去买菜，买完菜后小A开始准备主料，同时小B准备辅料（这里小B在小A准备主料的时候就相当于单独开了一个线程运行了），小A的主料和小B的辅料都准备好后，小A把自己准备好的主料和小B准备好的辅料放在一起炒菜，这样准备一顿饭的整个流程就这样完成了。在准备这顿饭的过程中，我们可以把小A做的事看作主线程，小B做的是看作一个子线程。用一个流程图来理解如下：

![](../Images/448074caca0b29aced8fd98196d7339a.png)

做饭流程示意图

上图就是整个做饭流程的示意，在主线程中小A完成了买菜，准备主料和炒菜，子线程中小B完成了准备辅料。

那么上述的过程在Qt中具体如何实现了，也就是在Qt中如何多线程编程呢，接下来就来实现。

* * *

通常我们编写的新的线程类都是从QThread类中派生出来的，然后重写run()函数在里面定义线程要执行的任务，通过start()函数来调用重写的run()函数。

在左上方的项目文件夹中选择Headers文件夹，右键单击选择添加新文件，在弹出来的新建文件窗口中选择C++ Header File后点击choose，新建的头文件名称就命名为 mythread ，然后完成创建。

```
#ifndef MYTHREAD_H#define MYTHREAD_H#include #include #include "unistd.h"class MyThread : public QThread{protected:  volatile bool m_stop;  //线程退出的标识量  void run(){    qDebug() << "线程开始运行";    while(!m_stop)    {        sleep(1);        ++i;    }    //QThread::exec();    //开启该线程的事件循环，线程不会退出    qDebug() << "线程结束";  }public:  MyThread()  {    m_stop = false;  }  //线程退出的接口函数，用户使用  void stop(){    m_stop = true;  }  qint8 i = 10;};#endif // MYTHREAD_H
```

在上述代码中我们新建了一个名为 MyThread 的类，这个类继承自 QThread 类。

bool型的 m\_stop 变量用于控制后面 run() 函数中的while循环，然后我们重写了 run() 函数，在 run() 函数中我们通过一个while循环来对变量 i （变量i在下面的public中定义，初始值为10）进行加一操作 ，而控制这个while循环的变量就是 m\_stop 。在构造函数中我们将 m\_stop 变量设为 false 这样在run 函数中的 while 循环就可以一直执行下去，同时我们在在类中定义了一个成员函数 stop() ，stop函数中将 m\_stop 变量赋值为 false 这样run 函数中的 while 循环就会停止。

```
#include "widget.h"#include #include "mythread.h"int main(int argc, char *argv[]){    QApplication a(argc, argv);//    Widget w;//    w.show();    MyThread thread1;    thread1.start();    qDebug()<<"子线程运行状态:"<<thread1.isrunning();< span=""></thread1.isrunning();<>    qDebug()<<"子线程结束状态:"<<thread1.isfinished();< span=""></thread1.isfinished();<>    qint8 j = 0;    while(1)    {        qDebug()<<"子线程输出的值："<<thread1.i;< span=""></thread1.i;<>        qDebug()<<"主线程输出的值："<<j<<endl</j<<;        ++j;        sleep(1);//        if(j == 5)  thread1.stop();//        if(j == 8) break;    }    qDebug()<<"子线程运行状态:"<<thread1.isrunning();< span=""></thread1.isrunning();<>    qDebug()<<"子线程结束状态:"<<thread1.isfinished();< span=""></thread1.isfinished();<>    return a.exec();}
```

在主函数中，我们首先实例化一个 MyThread 对象为 thread1，然后调用 thread1 的start() 函数启动线程，也就是 thread1 对象中的 run() 函数，上面有提到通过 start() 函数来调用类中重写的 run() 函数。

isRunning() 函数和 isFinished() 函数是用来查看线程当前的运行状态的，如果线程在运行，则 isRunning() 返回 true， isFinished() 返回 false，没有运行则相反。

5.下面我们来看一下程序的运行结果，右键点击项目，选择运行。运行结果如下图：

![](../Images/71e38444044e0be64470ea95e8878bbf.png)

首先输出子线程的运行状态和结束状态，由于在上面已经调用了 thread1 的 start() 函数，所以运行状态为 true ，结束状态为 false。然后输出子线程变量i和主线程变量j的值，由于两个变量都还未进行加运算，所以都为初始值，然后可以看到，每隔一秒两个变量的值都会加一，但是变量i的值是在子线程进行加操作的，而变量j的值则是在主线程main()函数中进行的加操作。我们可以通过调试界面来查看（下图），变量j在主函数中值为0,变量i在thread1中值为10。

![](../Images/800186cb200de67a1a2f6185c394ad76.png)

随着程序的运行，两个变量每隔一秒中都会加一。那么线程该如何停止呢？还记不记得我们在MyThread类中定义了一个stop()函数来改变，m\_stop变量的值，stop()函数将m\_stop变量值设为ture后 run()函数的while循环就会结束，run()函数就会往下运行直到函数运行结束，此时线程也就不再运行了，我们来运行程序看一下。

6.将main.cpp中主函数while循环中的注释取消

```
` //        if(j == 5)  thread1.stop();`
```

也就是将这两行代码前面的 // 给删除了。第一句的意思是当主函数的变量j的值递增为5时就结束线程thread1，当变量j的值递增为8时就退出while循环。

7.将注释取消掉后我们再来看下运行结果：

![](../Images/be0ba1577b46d33da77739ff86ccbb77.png)

从上图可以看到在 “主线程变量j的值：4” 这句输出后面输出了一句“线程结束”（有人会问不是说的j的值为5的时候结束子线程吗，其实此时j的值已经是5了，只是没有输出出来而已，下面的显示j的值为7的时候就退出循环也是一个道理），因为在那句话输出之后我们调用了 thread1 的 stop() 函数，相应的run()函数里面的while也就退出循环了，然后输出“线程结束”这句话，可以看到后面的输出中，变量i就不再加了，而当我们退出主函数中的while()循环显示子线程的状态时可以看到子线程的运行状态已经为false了，而j结束状态为true。说明线程确实已经结束了。

当然，以上只是线程控制的一种方法，线程的循环和退出也可以调用 QThread类 的 exec() 函数和 exit() 函数等方法。新建线程的方法也有很多，比如继承QObject类等，感兴趣的朋友可以自己找找相关资料学习实践一下。
