## 1.HTTP协议是什么

### 1.1 HTTP协议

**HTTP简介**

HTTP 是 HyperText Transfer Protocol的简称，我们一般称为超文本传输协议，它是客户端与服务端之间进行请求和应答的标准，主要用于从服务器本地的数据传输。

**HTTP的请求响应模型**

一般是客户端发起请求，而服务器端产生响应，一次请求对应一次响应，请求之间相互独立，以下是请求与响应的模型

**会看HTTP响应状态码，判断响应是否正常**

服务器通知客户端，本次请求对应的响应状态，状态码是3位数字组成

![](../Images/c86833422ea845b764681cb88c6daacd.png)

**重定向**

重定向可以理解为客户端发生一个请求，服务端的响应是给这个请求重新定义一个位置，客户端如果想继续访问，需要获取这个位置，然后向这个位置发送请求的过程。

![](../Images/692014f517d199c267258f9848f03ae8.png)

### 1.2 URL是什么

**URL简介**

URL 通常称为统一资源定位符，是Uniform Resource Locator 的简称，专门用于标识Internet 资源位置的一种表示方法，浏览网站输入的地址就是URL

**URL结构**

URL有标准的格式：

> protocol://hostname\[:port\]/path/\[?query\]#fragment

![](../Images/43038cc50a971e11ca70d051c2c19b71.png)

    // <1>判断有没有错误    if (reply->error()){        qDebug()<errorString();        reply->deleteLater();        return;    }
    // <2>检测状态码    int statusCode  = reply->attribute(QNetworkRequest::HttpStatusCodeAttribute).toInt();    qDebug() << "statusCode:" << statusCode;
    // <3>判断是否需要重定向    if (statusCode >= 200 && statusCode <300){        // ok
        // 准备读数据        QTextCodec *codec = QTextCodec::codecForName("utf8");        QString all = codec->toUnicode(reply->readAll());        qDebug() << all;

        QFile file(fileName);        if (!file.open(QIODevice::ReadWrite | QIODevice::Text)){            qDebug() << "file open error!";            return ;        }        QTextStream out(&file);        out.setCodec("UTF-8");        out<        file.close();
        // 数据读取完成之后，清除reply        reply->deleteLater();        reply = nullptr;
    } else if (statusCode >=300 && statusCode <400){        // redirect
        // 获取重定向信息        const QVariant redirectionTarget = reply->attribute(QNetworkRequest::RedirectionTargetAttribute);        // 检测是否需要重定向，如果不需要则读数据        if (!redirectionTarget.isNull()) {            const QUrl redirectedUrl = url.resolved(redirectionTarget.toUrl());
            reply->deleteLater();            reply = nullptr;
            startRequest(redirectedUrl);            qDebug()<< "http redirect to " << redirectedUrl.toString();            return;        }
    }
}
