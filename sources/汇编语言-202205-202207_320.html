在这篇文章中，我们将列出微软在 GitHub 上开源并维护的 Top 10 开源项目，排名根据 GitHub Star 数排序，本文采用倒序的形式呈现（排名由 Neowin 整理提供）。
🥇你心里的第一名是谁？下面就让我们一起来揭晓答案吧！

10：Cascadia


  • 编程语言：Python (100%)

  • Stars：19.9k

  • 描述：Cascadia 是一种有趣的新编码字体，与 Windows Terminal 捆绑在一起，现在也是 Visual Studio 的默认字体。

  • 地址：https://github.com/microsoft/cascadia-code


9：Calculator



  • 编程语言：C++ (71.9%)

  • Stars：24.4k

  • 描述：Calculator 是一个用 C++ 和 C# 编写的现代 Windows 计算器应用程序，预先安装在 Windows 中。该应用程序提供了标准、科学和程序员计算器的功能，以及一组各种测量单位和货币之间的转换器。

  • 地址：https://github.com/microsoft/calculator


8：Monaco Editor



  • 编程语言：JavaScript (81.1%)

  • Stars：29.3k

  • 描述：Monaco Editor 是直接从 VS Code 的源码中生成的。请注意，这个仓库不包含代码编辑器的源代码，它只包含将所有东西打包在一起的脚本，并提供 monaco-editor npm 模块。

  • 地址：https://github.com/microsoft/monaco-editor


7：ML-For-Beginners



  • 主要平台：Jupyter Notebook (99.4%)

  • Stars：35.5k

  • 描述：ML-For-Beginners 是一个面向初学者的机器学习课程，微软提供一个为期 12 周共 26 课时的机器学习课程。每节课都包括课前和课后测验、解决方案、作业等内容。以项目为基础的教学法使你能够边学边做。

  • 地址：https://github.com/microsoft/ML-For-Beginners


6：Playwright



  • 编程语言：TypeScript (85.1%)

  • Stars：37.4k

  • 描述：Playwright 是一个用于 Web 测试和自动化的框架。它允许用一个 API 来测试 Chromium、Firefox 和 WebKit。Playwright 的建立是为了实现跨浏览器的网络自动化，具有功能强大、可靠和快速的特性。

  • 地址：https://github.com/microsoft/playwright


5：Web-Dev-For-Beginners



  • 编程语言：JavaScript (78.5%)

  • Stars：48.2k

  • 描述：Web-Dev-For-Beginners 是微软提供的一个为期 12 周共 24 课时的课程，讲解了所有关于 JavaScript、CSS 和 HTML 的基础知识。每节课都包括课前和课后测验、解决方案和作业等。基于项目的教学法使你能够边学边做。

  • 地址：https://github.com/microsoft/Web-Dev-For-Beginners


4：PowerToys



  • 编程语言：C# (53.6%)

  • Stars：72.8k

  • 描述：PowerToys 是 Windows 系统实用程序，供高级用户调整和简化其 Windows 体验，可最大限度地提高生产力。

  • 地址：https://github.com/microsoft/PowerToys


3：TypeScript



  • 编程语言：TypeScript (100%)

  • Stars：80.4k

  • 描述：TypeScript 为 JavaScript 添加了可选类型，这些类型支持适用于任何浏览器、任何主机、任何操作系统上的大型 JavaScript 应用程序的工具。TypeScript 编译为可读的、基于标准的 JavaScript。

  • 地址：https://github.com/microsoft/TypeScript


2：Terminal



  • 编程语言：C++ (94.6%)

  • Stars：82.9k

  • 描述：这个资源库包含了以下的源代码：

    • Windows Terminal

    • Windows Terminal Preview

    • Windows console host（Windows 控制台主机）

    • 两个项目之间共享的组件

    • ColorTool

    • 展示如何使用 Windows Console API 的示例项目

  • 地址：https://github.com/microsoft/terminal


1：Visual Studio Code



  • 编程语言：TypeScript (93.8%)

  • Stars：131k

  • 描述：Visual Studio Code 将代码编辑器的简单性与开发人员在其核心的编辑、构建，以及调试周期中所需要的东西相结合。它提供全面的代码编辑、导航和理解支持，以及轻量级的调试、丰富的可扩展性模型和与现有工具的轻量级集成。Visual Studio Code 每月都会添加新的功能和错误修复。你可以在 Visual Studio Code 的网站上下载它，支持 Windows、macOS 和 Linux。如果想要每天获得最新版本，请安装 Insiders build。

  • 地址：https://github.com/microsoft/vscode


以上就是微软在 GitHub 上开源和维护的 Top10 开源项目。
