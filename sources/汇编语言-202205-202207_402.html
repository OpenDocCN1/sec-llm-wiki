 sizeof是 C语言的关键字，这个关键字是用来计算传入参数占用的内存字节数。


比如

#include <stdio.h>
int main()
{
    int a = 1;
    printf("%d\n", sizeof(a));
    return 0;
}

好，再回到之前的那个题目，sizeof计算的是指针占用内存的大小，并不是字符串内存的大小，所以正确输出在32位系统中输出是4，在64位系统中输出的是8。


#include <stdio.h>
