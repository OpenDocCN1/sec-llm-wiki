# 10.3 堆栈控件和标签页控件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247493902&idx=2&sn=61ffdd795bf603977d943237e279dcf4&chksm=97a1cdaca0d644ba42c655b14a4cadc87d43a836c18115df2363dcbf34a743c6fc8f8c6d9fe9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247493902&idx=2&sn=61ffdd795bf603977d943237e279dcf4&chksm=97a1cdaca0d644ba42c655b14a4cadc87d43a836c18115df2363dcbf34a743c6fc8f8c6d9fe9&scene=27#wechat_redirect)

本节介绍 Stacked Widget、Tab Widget ，这两个容器也支持多标签页轮流展示，Stacked Widget不带标题栏，需要配合如组合框之类的控件来切换标签页；Tab Widget 功能最为丰富，自带了标题栏，可以通过点击标题栏自由切换各个页面显示。
