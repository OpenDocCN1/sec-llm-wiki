Qt 报 virtual memory exhausted: Cannot allocate memory 错的解决方法

原文：http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247493891&idx=7&sn=9571a89510bb612cc6e566012de8858a&chksm=97a1cda1a0d644b71c433e9de2ed721690fe3501d8f9cebc743834a5b8eb6b4c6ff20c4bf2f4&scene=27#wechat_redirect
解决方法:
如果是使用 qmake 作为编译工具的话，在工程 pro 的文件中添加：
CONFIG += resources_big
这需要 Qt 5.12 和或之后的版本
如果是使用 cmake 作为编译工具的话，在 CMakeLists.txt 文件中添加：
qt5_add_big_resources(SRC_FILES resources.qrc) # big resources
这需要 Qt 5.12 和 CMake 3.9 以及之后的版本
