如果我们事先不知道存在最后的数据对 “c”，除了遍历，有没有什么办法直接获取最后一项呢？

我们可以使用如下方案：

*   
*   
*   
*   

```
    function lastElementValue(object) {        const keys = Object.keys(object);        return object[keys[keys.length - 1]];    }
```
