# 一，前言

43.QT自定义boot工具(上下位机联调)--Apple的学习笔记中描述不支持hex格式，但是MCU编译的时候我们常用的还是此格式文件。那么作为QT的上位机boot工具，必须要支持hex格式文件的解析。

# 二，需求

本人就是做通信协议的，解析处理是我的基本功。但是具体的格式忘记了，所以百度搜索了下，然后就有了设计思路。我做了个c语言的，先在vs2019中调试通过，也便于将来改成动态库。
