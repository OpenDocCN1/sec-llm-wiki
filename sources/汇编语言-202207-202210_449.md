# Qt ‘/‘和‘\\‘转化的方式

在文件路径中，常用的方式有两种：

1.  使用"/";
    
2.  使用"\\’.
    

这两种方式都可以用来表示文件的路径。

一般可以通用，但是在某些情况下（比如比较路径是否相等），’\\‘和’/'就会造成困扰。

今天发现Qt中有两个非常好用的接口：

```
1 \[static\] QString QDir::fromNativeSeparators(const QString &pathName)2 \[static\] QString QDir::toNativeSeparators(const QString &pathName)
```

其中，toNativeSeparators函数可以将以“/”作为分隔符的路径，转化为本机的表示方式，比如说Windows的"\\"。  
fromNativeSeparators则是其逆过程，是将本地的表示方式转化为以’/'作为分隔符的方式。
