最近看到美图秀秀的一些功能，可以手动设置图片的透明度并显示在其它图片上，所以自己动手做了个小Demo，实际效果如下：
（图片仅供参考使用）
可以看到拖动下方进度条，可以控制左上角图片的透明度。
方法如下：
新建一个Qt项目，在UI界面上拖放一个QLabel和一个QSlider，设置QSlider的数值范围为0～255，简单布局下即可。
代码如下：
#ifndef WIDGET_H#define WIDGET_H
#include #include #include #include 
namespace Ui {class Widget;}
class Widget : public QWidget{    Q_OBJECT
public:    explicit Widget(QWidget *parent = 0);    ~Widget();
private slots:    void on_horizontalSlider_sliderMoved(int position);
private:    Ui::Widget *ui;
    QLabel *m_label;    //设置透明度的图片的label};
#endif // WIDGET_H
