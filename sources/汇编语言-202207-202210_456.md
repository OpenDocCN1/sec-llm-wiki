# Qt QString中替换掉指定字符串

首先使用正则表达式QRegExp匹配指定字符串，然后使用QString的replace方法进行替换

*   
*   
*   
*   

```
1 QString originText = "KobeBryantGigiAitch";2 QString searchText = "Bryant";3 QString replaceText = "Gigi";4 QString result = originText.replace(QRegExp(searchText), replaceText);
```

可以使用QRegExp(searchText, Qt::CaseInsensitive)设置为不区分大小写匹配。
