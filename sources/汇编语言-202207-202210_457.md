# Qt QImage修改图片dpi

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247493804&idx=3&sn=f85e68ee71f20a23c914e6546a2108cc&chksm=97a1cc0ea0d6451843cca67a14ff06db5d0b9039f8873cced119df4b83052666d3b7b6fd0499&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247493804&idx=3&sn=f85e68ee71f20a23c914e6546a2108cc&chksm=97a1cc0ea0d6451843cca67a14ff06db5d0b9039f8873cced119df4b83052666d3b7b6fd0499&scene=27#wechat_redirect)

（DPI）Dots Per Inch，每英寸点数，所表示的是每英寸所拥有的像素数量。

QT里QImage设置DPI的方式：

```


*   
*   

```
1 setDotsPerMeterX2 setDotsPerMeterY
```


```

设置每米有多少个像素点进而换算成每英寸有多少个像素点。  
换算：

*   
*   
*   
*   

```
1 1m    = 39.37inch2 1inch = 0.0254m,3 1dots/inch = 1dots/0.0254m = 39.37dots/m4 1dots/inch = 39.37dots/m,
```

故修改90的DPI，则设置的值为：90\*39.37

例子：修改图片dpi为90

*   
*   
*   
*   
*   
*   

```
QImage img("/tmp/3456.jpg"); qDebug()< img.setDotsPerMeterX(90*39.37); img.setDotsPerMeterY(90*39.37); qDebug()< img.save("/tmp/45678.jpg");
```
