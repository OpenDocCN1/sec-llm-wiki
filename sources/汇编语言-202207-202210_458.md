## Qt将按钮变透明的方法

两种方式：  
第一种：flat属性：

![](../Images/c67e6fd1ad6fdbfdcda8349d2adafb63.png)

 此时按钮已经变成透明的  
但是在实际运行时点击会出现按钮的形状；  
若要点击时也透明，则需在stylesheet中输入：  
background:transparent;

![](../Images/0cca5000b6eab857d413d732378cc402.png)

 第二种方式：直接在styleSheet中设置，如：

*   
*   
*   

```
1 QToolButton{2 background-color:rgba(0,0,0,0);3 }
```

即可，这样QToolButton就是透明的了，这是在QToolButton的父窗口设置的，这样在这个父窗口下的QToolButton都是透明的。
