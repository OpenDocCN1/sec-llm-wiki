## 时钟的实现

QLCDNumber的样式与我们过去使用的电子表的很像，所以很自然的就想到去制作这样的一个项目，项目也很简单，主要是用来熟悉这个控件。

```
#include "widget.h"#include "ui_widget.h"#include #include #include 
Widget::Widget(QWidget *parent) :    QWidget(parent),    ui(new Ui::Widget){    ui->setupUi(this);    //防止刚打开这个软件，界面显示的是0，而不是具体的时间    ui->SYSTime->display(dateTime.currentTime().toString("hh:mm:ss"));    time = new QTimer(this);    this->connect(time, SIGNAL(timeout()), this, SLOT(countTime()));    //每隔一秒，计数器触发一次    time->start(1000);}
Widget::~Widget(){    delete ui;}
void Widget::countTime(){    ui->SYSTime->display(dateTime.currentTime().toString("hh:mm:ss"));}
```
