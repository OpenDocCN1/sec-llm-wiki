# 汇编语言LAHF和SAHF指令

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNDcwOTcwOQ==&mid=2247494048&idx=3&sn=19fcfba9a3b2406fa395b7414b7d5413&chksm=97a1cd02a0d64414c89e19db9d877c09b56706dbd6916dec61aa9e1d747ae054a0c34617b73f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxNDcwOTcwOQ==&mid=2247494048&idx=3&sn=19fcfba9a3b2406fa395b7414b7d5413&chksm=97a1cd02a0d64414c89e19db9d877c09b56706dbd6916dec61aa9e1d747ae054a0c34617b73f&scene=27#wechat_redirect)

LAHF（加载状态标志位到 AH）指令将 EFLAGS 寄存器的低字节复制到 AH。被复制的标志位包括：符号标志位、零标志位、辅助进位标志位、奇偶标志位和进位标志位。使用这条指令，可以方便地把标志位副本保管在变量中：

*   
*   
*   
*   
*   

```
.datasaveflags BYTE ?.codelahf                      ;将标志位加载到 AHmov saveflags, ah         ;用变量保存这些标志位
```

SAHF（保存 AH 内容到状态标志位）指令将 AH 内容复制到 EFLAGS（或 RFLAGS）寄存器低字节。例如，可以检索之前保存到变量中的标志位数值：  

```

```

*   
*   

```
mov ah, saveflags  ;加载被保存标志位到 AHsahf                        ;复制到 FLAGS 寄存器
```
