textvariable：改变控件文本，可以动态改变文本，比较常用

value：赋值

text：初始化文本

command:监听命令，主要是监听事件变化


tushare获取股价行情

class Share:    def __init__(self, code, buy, sale):        self.code = code        self.buy = buy        self.sale = sale
    def buy_sale_decision(self):        data_now = ts.get_realtime_quotes(self.code)  # 获取实时分笔数据,参考tushare主页介绍        name = data_now.loc[0][0]  # 股票名字        price = float(data_now.loc[0][3])  # 当前价格        data_date = data_now.loc[0][30]  # 日期        data_time = data_now.loc[0][31]  # 时间        describe = '股票名字: ' + name + '当前价格: ' + str(price) + '日期: '+data_date + '时间: ' + data_time        print(describe)        # print('股票名字：',name,'当前价格：',price,'日期:',data_date,'时间：',data_time)        InitialStockName.set(name)        InitialStockPrice.set(price)        if price <= self.buy:            print('达到买点，买进！')            send_email('达到买点', describe)        elif price >= self.sale:            print('达到卖点，卖出！')            send_email('达到卖点', describe)        else:            print('拿着不动!')

自己封装一个类，获取实时分笔数据,解析出股票的名字，时间，价格，日期，然后实例化之后填入自己买入的价格，与预期的价格，作一下比较，看是否触发报警。

pyinstaller打包成exe

最后就是把运行成功的打包成exe，python脚本的好处就是可以在多个平台上运行，你可以打包后在windows上运行，也可以打包后在mac上运行，也有打包后在Linux运行。

首先要安装pyinstaller模块，安装完之后自己可以设置一份版本信息文件

写入版本信息，然后也是直接采用脚本即可完成打包发包过程

pyinstaller --version-file=version.txt -i 512.ico -F -w OpticalSimulateApp.py
