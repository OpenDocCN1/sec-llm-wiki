遍历QMap容器，一般使用迭代器遍历，但使用迭代器遍历需要写的字太多了，而使用for循环遍历就少写很多字。来看看君君是怎么操作的吧。

  先看下迭代器是怎么遍历的。

QMap<int, QString> map;
map[0] = "000";
map[1] = "111";
map[2] = "222";

// 呜呜，初始化迭代器写得太多内容了，难受。
QMap<int, QString>::const_iterator i = map.constBegin();
while (i != map.constEnd()) {
    qDebug() << "key: " << i.key();
    qDebug() << "value: " << i.value();
    ++i;
}

  我们再看看使用for循环是怎么遍历的。下面介绍三种使用for循环的实现方法，你喜欢那种呢。

QMap<int, QString> map;
map[0] = "000";
map[1] = "111";
map[2] = "222";

  1. 只遍历value值

/* 只遍历value值 */
foreach(QString string, map) {
    qDebug() << string;
};

  1. 遍历key和value

/* 遍历key和value */
foreach(int key, map.keys()) {
    qDebug() << "key: " << key;
    qDebug() << "value: " << map.value(key);
};

  1. 遍历key和value (c++11起)

/* 遍历key和value (c++11起)*/
for(auto each : map.toStdMap()) {
    qDebug() << "key: " << each.first;
    qDebug() << "value: " << each.second;
};
