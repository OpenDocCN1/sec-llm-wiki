1. '#'为将其后面的宏参数进行字符串化操作

1.1 例子

#include <iostream>

#define ToString(s) #s

int main(int argc, char *argv[])
{
    std::cout<<ToString(sssss)<<std::endl;

    return 0;
}

1.2 输出

sssss

2. '##'为连接符，主要用于减少代码密度

2.1 例子

#include <iostream>
#define Concatenator(a, b) a##b

void ab() {
    std::cout<<"This is 'ab' function."<<std::endl;
}

int main(int argc, char *argv[])
{
    Concatenator(a, b)();

    return 0;
}

2.2 输出

Thisis'ab'function.
