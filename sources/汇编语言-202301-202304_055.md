**1.将Qtxlsx添加到项目**

Qtxlsx库存在src里的,所以将QtXlsxWriter-master/src里文件夹

将解压后的src目录拷贝到项目里的子目录Qtxlsx下,在项目pro文件中增加下面这行:

```
include(./Qtxlsx/src/xlsx/qtxlsx.pri)
```

复制

**PS:**和我们之前添加第三方串口库方法类似

**1.输入简单的代码**

```
#include "xlsxdocument.h"
main()
{
QXlsx::Document xlsx;
.write("A1", "Hello Qt!");
.saveAs("Test.xlsx");
return 0;
}

```
