开发环境：win8 编程语言

c++ IDE：Qt Creator

opengl版本：opengl es 3.0（可编程渲染管线，着色器语言）

OpenGL ES (OpenGL for Embedded Systems) 是 OpenGL 三维图形 API 的子集，针对手机、PDA和游戏主机等嵌入式设备而设计。该API由Khronos集团定义推广，Khronos是一个图形软硬件行业协会，该协会主要关注图形和多媒体方面的开放标准。
