类型截断引起的Bug

**背景**

最近遇到了一个Bug，由于崩溃堆栈定位到的是一个第三方的so中，查了许久。最终，定位到了出问题的部分。

**现象原因：**

Model层传给UI层，一个用于描画的Buffer。在使用前，该Buffer被异常释放。导致UI层再调用第三方库，创建纹理时崩溃。

**根本原因：**

C++类型截断导致

// 子类class Child : public Parent{public:std::shared_ptr buf;}
// 由于编译限制，接口层禁止使用C++11。// 所以在Model层，使用智能指针保存buf// 为UI层提供原始指针 bufferstd::map m_bufferMap;void saveBitmap(BitMap* bitmap){Child node;node.buf.reset(bitmap);node.buffer = buf.get();

上面的例子钟，将子类对象赋值给父类类型的对象时，会发生类型截断。子类中多余的部分，将会被抛弃。

问题的原因比较简单，就是C++的一个基本概念。但是该原因导致的问题，以及定位问题的调查过程，还是比较久的。因此，一定要对语言的基本概念会深刻的了解，特别是底层语言，否则很容易自己挖坑。
