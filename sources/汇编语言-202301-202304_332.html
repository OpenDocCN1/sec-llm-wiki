  • 注意方向

GL_BACK: Culls only the back faces.GL_FRONT: Culls only the front faces.GL_FRONT_AND_BACK: Culls both the front and back faces.

  • mode  指明前面多边形的方向。可选的值有GL_CW和GL_CCW。默认值是GL_CCW。

glEnable(GL_CULL_FACE);glCullFace(GL_BACK);glFrontFace(GL_CW);
