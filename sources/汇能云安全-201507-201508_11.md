08月11日，星期二，您好！汇能科技与您一起分享行业快报：

【科技】

1.谷歌重组成立Alphabet,但域名还在宝马手里:虽然谷歌已经重组更名为Alphabet，但Alphabet.com的域名并不属于谷歌，而是归汽车厂商宝马所有。此外，相关社交网络账号也不属于谷歌。

 

2.工信部人事再调整,辛国斌回炉任副部长:工信部副部长毛伟明日前空降江西担任省委常委，辛国斌正好填补毛伟明留下的空缺，“65后”的辛国斌也将成为工信部最年轻的副部长。

 

3.诺基亚招募软件专家，为重返手机市场做准备：国外媒体今日报道称，诺基亚正在招募软件专家，测试新产品，寻找合作伙伴，为重返手机市场积极准备。

 

4.阿里283亿元战略投资苏宁，成第二大股东：阿里巴巴与苏宁云商宣布达成战略合作。阿里巴巴集团将投资约283亿元人民币参与苏宁云商的非公开发行股份，占发行后总股本的19.99%，成为苏宁云商的第二大股东。与此同时，苏宁云商将以140亿元人民币认购不超过2780万股的阿里巴巴新发行股份。

 

5.谷歌重组更名Alphabet,皮查伊接替CEO职位:Alphabet将取代谷歌在纳斯达克上市，谷歌目前所有股份将自动转换为同等数量与权益的Alphabet股份。

 

6.Marvell十亿美元出售手机芯片业务:美国芯片公司Marvell正在考虑出售其手机芯片业务，潜在的买家是大唐电信旗下的联芯科技。

 

7.央视：腾讯举报360云盘存大量淫秽色情内容。不法分子也看上了云盘存储量大、传播迅速、分享方便的优点，把云盘变成了一个淫秽色情信息的“隐蔽”聚集地。

 

【信息安全】

1.韩媒：朝鲜主要机构官网出现瘫痪，原因不明。韩联社观察发现，截至10日上午10时30分许，包括朝鲜劳动党机关报《劳动新闻》、朝中社、金日成综合大学等朝鲜主要机构官网均无法浏览。

 

2.特斯拉屡被黑客操控：智能汽车瓶颈难破。智能汽车本身还处在一个“灰度”空间，传统汽车现阶段可以减少或更稳健地应用智能系统。但特斯拉之所以存在，就是因为它更多地应用了智能系统，所以不可能回头。

 

3.HTC又陷危机：指纹数据被轻易破解。四名来自安全公司“火眼”（FireEye）的专家通过研究发现：HTC One Max这款手机，会将用户的指纹数据存储为图片格式文件，有心人只需通过很简单的方式就可以破解它。

 

4.黑客入侵，电动滑板也存在安全漏洞：黑客发现，只要电动滑板经过蓝牙无线电噪音强烈的地方，它就会停下来。该技术能让他控制电动滑板，是走是停也全看控制者的意愿，同时能让刹车永久失效，甚至能让运行中的电动滑板倒着走。

·

5.安全公司称Windows企业版更新可被黑客拦截：安全公司 Context 在其新公布的一份报告中指出，黑客可以拦截 Windows 更新，使得 Windows 企业版感染恶意软件。报告称黑客可以通过 Windows Server Update Services (WSUS)传输恶意软件。

 

【智能家居】

1.联想发布自有品牌电视：支撑集团智慧家庭战略。此次联想发布六大系列十几款新品电视，与此前推出的联想控股的17TV形成线下线上双品牌。

 

2.张近东：苏宁将定位互联网+转型接口。张近东指出，未来十年将是互联网+的十年，而未来将涌现出更多优秀的企业。而苏宁将在互联网+转型中扮演接口的角色。

 

3.酷开果粉电视体验：用苹果表控制客厅娱乐。从酷开果粉电视上可以看到创维的转型，向简约、功能方向发展的整体UI、三台遥控器三种不同界面以及苹果设备支持的功能，酷开确实有一些自己的想法。

  

4.解读IFA2015家电趋势：智能互联再成热点。2015年柏林国际消费电子展(IFA2015)将于9月4—9日在德国首都柏林举行。全球领先的家电制造商将集中亮相，展示最新产品与创新成果。
