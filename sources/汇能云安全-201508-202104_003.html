勒索软件清理使苏格兰环保局损失110万美元

根据苏格兰广播公司援引信息自由法获得的数据，到目前为止，苏格兰环境保护局在2020年12月袭击事件的清理已花费了将近79万英镑（110万美元），其中有63.5万美元用于稳定该机构的IT平台。该机构表示，攻击者渗透到SEPA的网络，窃取数据并将其恶意软件预先放置在多个系统上之后，随后加密锁定其系统，再泄漏被盗的数据以迫使该组织支付赎金。


Android 加入了对 Rust 语言的支持

Google 官方安全博客宣布，Android 加入了对 Rust 语言的支持。Google 称，七成的 Android 高危漏洞与内存相关，而内存安全语言是解决这一问题的最有效方法。Google 宣布 Android Open Source Project(AOSP)现在支持用 Rust 语言开发操作系统。Rust 语言利用编译时检查和运行时检查确保内存安全，同时它还提供了比拟 C 和 C++ 语言的性能。


澳大利亚政府审计局将网络安全作为广泛应用银行生态系统的重点

澳大利亚政府审计局（APRA）正在“加强”对银行的能力的关注，同时也要关注其技术生态系统和其他合作伙伴在面对日益严峻的网络安全威胁时具有韧性的能力。审计局主席Wayne Byres在2021年AFR银行峰会上表示，尽管还没有APRA监管银行、保险公司或养老金基金遭受重大的网络破坏，但事件发生只是时间问题。

黑客以 SAP 系统为目标进行反向工程

根据 Onapsis 和 SAP 联合发布的一项研究，在安全补丁发布后的 72 小时内，本地 SAP 系统就会成为威胁行为者的目标。黑客对 SAP 补丁进行反向工程，以创建自己的代码来利用最近解决的漏洞，并使用它们针对 SAP 安装。SAP 和 Onapsis 已与网络安全和基础架构安全局（CISA）以及德国网络安全机构 BSI 合作，警告 SAP 客户一旦安装了安全更新，便会对其进行安装并评估其本地安装。


研究人员发现基于WhatsApp的可感染蠕虫的Android恶意软件

Check Point网络安全研究人员发现了另一种可感染蠕虫的Android恶意软件，该恶意软件以“ FlixOnline”的名称伪装成流氓Netflix应用程序，其功能使其可以自动回复受害人传入的WhatsApp消息，以及从命令与控制（C＆C）服务器接收到有效负载。分析报告中说：“该应用程序实际上是为了监视用户的WhatsApp通知而设计，并使用从远程C＆C服务器接收的内容自动回复。”
