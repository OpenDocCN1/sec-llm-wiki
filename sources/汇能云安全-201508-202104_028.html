3月9日，星期二，您好！中科汇能与您分享信息安全快讯：


微软修复Exchange多个高危漏洞

微软发布Exchange Server的紧急安全更新，修复了7个相关漏洞，包括Exchange 服务端请求伪造漏洞（CVE-2021-26855）、Exchange 反序列化漏洞（CVE-2021-26857）、Exchange 任意文件写入漏洞（CVE-2021-26858/CVE-2021-27065）及3个Exchange远程代码执行漏洞（CVE-2021-26412/CVE-2021-26854/CVE-2021-27078）。目前微软已检测到在野利用。


谷歌修复又一枚遭在野利用的Chrome 0day

谷歌修复了 Chrome 89.0.4389.72 版本中已遭活跃利用的 0day （CVE-2021-21166）。用户可到 Settings -> Help -> About Google Chrome 修复该漏洞。Chrome Web 浏览器之后会自动检查新的更新并适时安装。该漏洞由微软浏览器漏洞研究团队的研究员 Alison Huffman 在2021年2月11日提交。


全球近半数企业实行远程工作 面临更大的网络攻击风险

根据LogMeIn与IDG合作的一项新研究，全球接近一半的企业组织担心远程工作将使他们面临更大的网络攻击风险。接近80%的公司承认，他们的一部分员工使用个人电脑在家工作，而40%的公司表示，超过50%的员工需要依靠家里的Wi-Fi网络工作。受访者还强调，支持远程工作最紧迫的挑战是有效的资讯科技/求助台支持、网络安全管理和提供安全的数据访问。


Furucombo遭黑客攻击 造成1400万美元损失

可组合性 DeFi 平台 Furucombo 遭黑客攻击，造成 1400 万美元损失。黑客使用假合约混淆 Furuсombo Proxy，导致部分 Furuсombo 与 Aave 交互合约地址的资金被直接转移至黑客钱包。据 Furucombo 官方表示，已经找到了根本原因并修复了漏洞。用户资金现在已经处于安全状态。团队正在调查被盗的资金并组织后续行动，将保持更新。

荷兰票务平台Ticketcounter190万用户邮箱泄露

荷兰电子票务平台Ticketcounter发生数据泄露事件，由于使用不安全的开发服务器，导致190万条用户邮件信息被盗。据媒体报道，被盗的数据库包括姓名、邮件地址、电话号码、IP地址和哈希密码信息。该公司向媒体证实了这一数据泄露事件。由于Ticketcounter没有支付赎金，攻击者3月1日在黑客论坛上公开了数据库。
