# 中科信息安全快讯 - 黑客侵入佛罗里达州奥尔兹马市水处理设施，企图投毒！

      一名黑客侵入了佛罗里达州奥尔兹马市的水处理系统，企图将氢氧化钠（NaOH）（又叫碱液和苛性钠）的浓度提高到极其危险的水平。  
![](../Images/180f6e9dfefb6fc51962c2a9083f9b33.png)  
      氢氧化钠常见于家用清洁剂中，但是如果高浓度摄入，可能非常危险。然而，少量的氢氧化钠常被水处理设施用来调节酸度（pH），并去除重金属。  

**通过远程桌面软件侵入**

  
针对奥尔兹马市水处理系统计算机系统的攻击发生在周五下午1点半，是通过远程桌面软件进行的，该软件允许授权用户远程解决系统问题。警长Bob Gualtieri在接受路透社采访时表示，黑客远程访问了水处理设施一名员工的计算机上名为TeamViewer的软件程序，以控制其他系统。工厂操作员表示，他们观察到了有人控制了鼠标，进而用来更改控制该市水处理功能的软件。入侵者在系统内部逗留了三到五分钟，将氢氧化钠的含量从万分之1改为万分之111。操作员立即将含量恢复到正常值；由于这名操作员即时干预，奥尔兹马全市的人并没有受到威胁。然后，该操作员切断了远程访问系统的通道。市长Eric Seidel表示，奥尔兹马水处理系统是采用冗余机制构建的，如果水里面的化学成分含量达到危险水平，系统就会发出警报。警长Bob Gualtieri说：“即使工厂操作员没有迅速将调高的氢氧化钠含量恢复到正常值，这些致命的水也要在24到36个小时后才能进入到供水系统；系统部署了冗余机制，对水进行检查后才排放。”Gualtieri补充道，目前还没有逮捕任何人，也没有透露关于这起事件源自美国还是国外的信息。皮尼拉斯县警长办公室、联邦调查局和特勤局正在调查此事。  

**不是针对水处理设施的首次攻击，也不是最后一次攻击**

  
表面上来看，这不是一起高明的入侵。据Mandiant威胁情报团队声称，自去年以来，技能不太娴熟的不法分子企图远程访问工业控制系统的事件数量有所增加。Mandiant告诉IT安全外媒BleepingComputer：“许多受害者似乎是随意选择的，比如服务群体数量有限的小型关键基础设施资产拥有者和运营商。通过与这些系统进行远程交互，不法分子实施影响有限的行动，常常包括操纵来自物理流程的变量。鉴于工业流程通常由专业工程师设计和监控，他们采用了安全机制以防止工作流程被人意外修改，因此，这些行动都没有对人员或基础设施造成危害。”针对水处理设施的攻击在过去二十年间发生过几次。当初备受公众关注的其中一起历史最久远的攻击发生在2000年，受害者是澳大利亚的一家废水处理厂，事后查明系内鬼所为。心怀不满的员工Vitek Boden使用窃取而来的设备闯入了数据采集与监控系统（SCADA）控制器，将80万公升未经处理的污水直接排放到了Maroochy Shire的水道中。2011年，美国国土安全部（DHS）声称伊利诺伊州斯普林菲尔德市的水泵出现故障，一名自称是“教授”的黑客对此做出了回应。该黑客发布的截图显示，他们闯入了南休斯顿的一家污水处理厂。2016年，Verizon在其《数据泄露摘要报告》中声称，黑客活动分子能够闯入IT网络在过时的软硬件设备上运行的水处理公司。
