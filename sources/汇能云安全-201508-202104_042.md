**2月19日，星期五，您好！中科汇能与您分享信息安全快讯：**  

  

**************Android 间谍软件被发现与孔夫子黑客组织有****************************关联**************

      安全公司 Lookout 报告 Android 间谍软件的两种变种 Hornbill 和 SunBird 被发现与孔夫子黑客组织有关联。孔夫子 APT 组织主要攻击东南亚的政府机构、巴基斯坦军方成员，印度选举官员和核机构，被认为与印度政府有关联。新发现的两种 Android 恶意程序主要用于入侵流行的消息应用 Whatsapp，提取聊天内容 。

  

**************T-Mobile称恶劣天气会造成其通信网络****************************故障**************

      近期，T-Mobile的客户——尤其是德克萨斯州的客户经历大多经历了网络问题，一些用户完全没有网络接入，但大多数报告都表示T-Mobile网络上的移动互联网接入无法使用。Down Detector显示，从美国东部时间周一上午8点左右开始，T-Mobile客户的停运报告激增。该运营商的技术总裁内维尔·雷表示美国多地强降雪恶劣天气是罪魁祸首 。

  

**************2020年访问根服务器的DNS查询锐减41****************************%**************

    得益于 Chromium 团队的努力，在2020年DNS社区获得了一个重要的积极因素——解决了大量 DNS 查询被发送到根服务器的问题，从而大幅提高了根服务器的接受度和响应度。据Verisign统计，利用 Chromium内网重定向检测测试结果显示 45.8%的总 DNS 流量是访问根服务器的。此后，Chromium 团队重新设计了代码，在 Android 设备上禁用了重定向测试。  

  

**************疑似遭受黑客攻击，Ant Design源代码仓库被删****************************除**************

       近日，stackoverflow上有用户发现Ant Design（企业级 UI 设计语言和 React 组件库）项目在GitHub上的仓库地址无法访问，疑似被官方删除。经过 Ant Design 官方的初步调查，认定此次事件是受到黑客攻击导致。名为 Jeggy 的社区用户最早发现 Ant Design 的 GitHub 仓库地址返回 404，官网也暂时损坏，但使用 npm 时一切正常。

  

**************法国ANSSI：俄黑客对Centreon服务器展开了持续多年的攻****************************击**************

     法国 ANSSI 在近日的一份报告中指出，名为 Sandworm 的俄方黑客组织，对该国 IT 公司 Centreon 的服务器展开了持续三年的 APT 攻击。由该国情报系统发布的技术报告详情可知，在此期间，黑客破坏了多个运行 Centreon IT 监控软件的法国实体的内部网络。据悉，Sandworm 攻击主要针对信息技术提供商，尤其是 Web 托管服务商。
