1月25日，星期一，您好！中科汇能与您分享信息安全快讯：


FireEye发布审计SolarWinds黑客攻击技术的网络调查工具

在近日发布的一份报告中，网络安全公司 FireEye 详细披露了 SolarWinds 黑客网络攻击事件所使用的相关技术。与此同时，FireEye 还在 GitHub 上分享了一款名为《Azure AD Investigator》的免费工具，以便企业能够确定 SolarWinds 黑客在其网络中部署了哪几道后门。FireEye 已协同微软和 CrowdStrike 对 SolarWinds 的供应链危害展开了全面的调查。


攻击者利用DNSpooq漏洞劫持数以百万计的设备

以色列安全咨询企业 JSOF 在最新报告中披露了七个 Dnsmasq 漏洞（统称 DNSpooq），并指出攻击者借此感染了数以百万计的设备。Dnsmasq能够为运行该软件的网络设备添加 DNS 缓存和 DHCP 服务器功能。受 DNSpooq 影响的设备不仅遭遇 DNS 缓存中毒，还可被用于远程代码执行、以及拒绝服务（DoS）攻击。


Oracle发布2021年1月重要补丁更新

Oracle发布2021年首个重要补丁更新包，本次更新含Oracle产品系列中的329个新安全补丁。其中编号为CVE-2021-2109的Weblogic远程代码执行漏洞值得重点关注，Weblogic相关高危漏洞是网络黑产团伙最钟爱的攻击武器之一，大量勒索病毒、挖矿木马、僵尸网络活动与该组件的高危漏洞利用相关，建议受影响的用户尽快修复。


谷歌宣布将在 Chrome 88 中添加新的密码保护功能

1月20日，谷歌正式发布了 Chrome 88，新版浏览器永久取消了对 Adobe Flash Player、FTP 的支持。同时谷歌宣布将为 Chrome 88 添加新的密码保护功能，其中一项新功能将为用户识别弱密码并支持替换为强密码。首先，在收到 Chrome 88 更新后，用户只需单击个人资料图片下方的钥匙图标，即可检查密码强度。另外，用户可以在地址栏中输入网址直接跳转到该设置区域。


RunMiner挖矿团伙新增漏洞武器：利用Weblogic反序列化漏洞（CVE-2017-10271）攻击主机挖矿

近期RunMiner挖矿木马团伙被检测到使用新增漏洞武器攻击云主机挖矿：利用weblogic反序列化漏洞（CVE-2017-10271）对云主机发起攻击，攻击得手后，会下载、执行恶意脚本尝试对Linux、Windows双平台植入挖矿木马，进行门罗币挖矿操作。RunMiner挖矿木马团伙的攻击活动会严重影响云主机性能，干扰政企机构正常业务运行。
