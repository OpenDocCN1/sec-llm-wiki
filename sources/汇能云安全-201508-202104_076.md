**12月30日，星期三，您好！中科汇能与您分享信息安全快讯：**

  

********************************近期暴雪游戏平台持续受到了一系列大型恶意DDOS攻击********************************据网易暴雪游戏客服团队称，近期，暴雪游戏平台持续受到了一系列大型恶意的“分布式拒绝服务(DDOS)”攻击，严重影响了国服及全球范围内玩家们的正常游戏体验。在此期间，团队一直都与网络服务供应商紧密合作，尽可能地减轻攻击对玩家所造成的影响。同时也在努力提升和采取更多的方式手段，持续不断地尽全力保护各位玩家朋友的游戏体验。  
******************警方提醒：警惕短信内木马病毒链接******************近日，有市民收到内容为“领取大额医疗保险健康金”的短信，这类短信中的链接是木马病毒链接，如果点开会被盗取银行卡账户密码等个人信息。如果收到这样的短信请立即删除，谨防上当受骗。警方提醒：此类诈骗与“积分兑换礼品”“信用卡提额”“车辆违章请查看图片”骗局如出一辙，其本质都是诱导受害人点击短信内木马病毒链接，盗取个人信息并划走资金的诈骗手段。  
****************************2020新危机：DDoS攻击的平均带宽增加，API和应用程序受到攻击****************************

据Link11称，DDoS攻击的数量和复杂性在今年的持续增长。并且在2020年第一季度里，大容量攻击的数量不断增加，50 Gbps以上的攻击数量达到了51种。攻击带宽平均也有所增加，由2019年同一季度的4.3Gbps上升到了5.0 Gbps。在2020年，最大攻击带宽与去年相比几乎翻了一番，根据记录，最大攻击是406 Gbps。在2019年第一季度，最大带宽达到224 Gbps的峰值。

  

**************************日本乐天网店因网络攻击致近150万用户资料被盗**************************日本共同通信社报道称，日本乐天网店因多次遭到网络攻击导致148万用户资料被盗。由于多次未经授权的链接，想在乐天上放置自己商品的各网店经理和代表的名单及其电话号码被泄露。受邀专家最后说，由于商店在储存数据的疏忽造成了这次信息泄露。根据NHK电视台的信息显示，未经授权的国外链接至少连接了600个信息。但是暂时还没有因泄露造成损失的消息。  
************************************CISA发布针对 Microsoft 365的Sparrow 漏洞检测工具************************************

近期大量外媒称黑客一直在利用 Microsoft 365 进行商业和敏感的政府网络监控，美国国土安全部的网络安全和基础结构安全机构（CISA）针对这种情况发布了一项工具 Sparrow.ps1 以帮助用户检测漏洞和可能存在的问题。该工具可以针对性的检测 Microsoft 365 和 Microsoft Azure 环境检测到黑客入侵并帮助管理员尽可能早地进行正确的对策。
