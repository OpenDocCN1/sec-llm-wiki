9月17日，星期四，您好！中科汇能与您分享信息安全快讯：

  

  

****海归男为赌博网站提供源代码，非法获利百万被刑拘****

近日，徐州警方成功打掉一个为赌博网站提供源代码的网站，相关源码共计被下载2万余次，嫌疑人王某非法获利100余万元。该网站共有24000余套网站源码，其中博彩、棋牌类赌博网站源码1500余套，其他用于黑灰产、第四方支付平台等非法网站源码2300余套。据悉，王某留学归来后无正当职业，通过各种手段收集、整理、购买其它网站的代码后，经整合再挂在网上供付费下载。

  

******乔·拜登竞选应用现漏洞：选民敏感信息可被轻易查询******

据外媒TechCrunch报道，一名安全研究人员发现，美民主党总统候选人乔·拜登的官方竞选应用存在隐私漏洞–任何人都可以查询数百万美国人的敏感选民信息。这款名为Vote Joe的竞选应用允许拜登的支持者在即将到来的美国总统大选中鼓励朋友和家人投票，方法是上传他们的手机联系人列表然后看看他们的朋友和家人是否已经注册投票。

  

********Microsoft Exchange Server远程代码执行漏洞（CVE-2020-16875）通告********

近日，绿盟科技监测到网上有安全人员公开了Exchange Server远程代码执行漏洞（CVE-2020-16875）的利用程序，此漏洞为微软在9月的安全更新补丁中披露。利用此漏洞需要具有以某个Exchange角色进行身份验证的用户权限，攻击者可通过向受影响的Exchange服务器发送包含特殊的cmdlet参数的邮件来触发此漏洞，成功利用此漏洞可在受影响的系统上以system权限执行任意代码。

  

**近2000家Magento 1店遭到黑客攻击**

2020年9月12日至13日，全球近2000家Magento 1店遭到黑客攻击，这是迄今为止规模最大的一次有记录的活动。这是一个典型的Magecart攻击：注入的恶意代码将截获不受怀疑的商店客户的付款信息。被检查的商店发现运行Magento版本1，该版本于去年6月宣布停止使用。

  

**Apache ActiveMQ远程代码执行漏洞**

Apache ActiveMQ 是最流行的开源、多协议、基于 Java 的消息传递服务器。Apache 软件基金会公布 ActiveMQ 消息中间件中存在一个安全漏洞（漏洞编号为CVE-2020-13920）。攻击者可利用该漏洞执行任意代码。数据显示，全球范围内（app="Apache-ActiveMQ"）共有 75,339 个相关服务对外开放。目前Apache官方已发布安全更新，建议升级到Apache ActiveMQ 5.15.13版本。
