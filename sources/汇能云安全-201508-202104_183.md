8月4日，星期二，您好！中科汇能与您分享信息安全快讯：

  

**PlusToken案告破超百人被捕涉及金额400亿**

7月30日，“Plus Token平台”网络传销案潜逃境外全部27名主要犯罪嫌疑人和82名骨干成员被抓捕归案。该案系公安机关侦破的首起以比特币等数字货币为交易媒介的网络传销案，涉及参与人员200余万人，层级关系多达3000余层，涉案数字货币总值逾400亿元。专案组民警分赴瓦努阿图、柬埔寨、越南、马来西亚等国家和地区，配合当地警方将嫌犯抓获归案。

  

**研究发现钓鱼攻击平均时间跨度为21小时**

来自Google、PayPal、三星和亚利桑那州立大学的安全研究人员组成的团队花费一年时间，通过分析2000多万名用户对40多万个网络钓鱼页面的访问发现，从首次到最后一次受害者访问，网络钓鱼攻击时间平均跨度为21个小时，而反网络钓鱼机构检测到的每次攻击平均发生在首次受害者访问后的9小时。所有受害者流量中37.73％发生在攻击检测之后。

  

**Tor被曝多个0day漏洞，官方给出回应**

安全研究人员Neal Krawetz 在7月23日和30日分别公布了2个影响Tor网络和浏览器的0 day漏洞技术细节，并称近期会发布其他3个漏洞的细节。有专家确认，利用这些漏洞中的1个可以对Tor服务器进行去匿名，获取真实的IP 地址。研究人员介绍了识别Tor bridge流量的方法，其中包括2个0 day漏洞利用，一个漏洞利用可以检测obfs4，一个漏洞利用可以检测meek。

  

**盘古团队发现苹果Secure Enclave芯片“不可修补”漏洞**

据 9to5mac报道，苹果为设备带来的主要安全增强功能之一就是 Secure Enclave 芯片，该芯片可以加密和保护设备上存储的所有敏感数据。不过中国的盘古团队在 Apple 的 Secure Enclave 芯片上发现了 “无法修补”的漏洞，可能导致私人安全密钥加密被破坏。漏洞 “不可修补”意味着该漏洞存在于硬件而不是软件中，因此已出厂的设备可能无法修复这一问题。

  

**Nexus Repository Manager 远程代码执行漏洞（CVE-2020-15871）**

近日，Sonatype Security Team官方发布了一则关于Nexus Repository Manager 3.x产品的远程代码执行漏洞通告，漏洞编号CVE-2020-15871。根据目前FOFA系统最新数据（一年内），全球范围内（app="Nexus-Repository-Manager"）共有 27,876 个相关服务对外开放。中国、美国、德国、爱尔兰、法国使用数量最多。
