瑞幸自曝造假又添新猜想：董事会成员邮件被黑客攻破？

6月16日，有媒体报道，在遭遇做空前，瑞幸咖啡一位董事会成员及其同事邮件曾收到黑客钓鱼链接，其同事不慎点击邮件系统被攻破。今年2月，做空机构浑水发布匿名报告指控瑞幸咖啡财务造假。但瑞幸官方随后否认了这一指控，2个月后，瑞幸官方发布SEC文件，自曝公司COO刘剑涉嫌财务造假22亿元。前后态度的反差让人意外。


勒索病毒不只攻击电脑，主流 NAS 服务器也成头号目标

近期eCh0raix勒索病毒再度活跃，主要利用 QNAP(威联通)NAS 服务器中QTS 和 Photo Station 上的远程漏洞组合进行传播，对用户隐私数据及财产安全造成极大威胁。据官方介绍，该病毒可成功感染开启 Photo Station 后的 QNAP(威联通)NAS 设备，并在感染后，获取NAS系统和文件的访问权限，加密用户重要数据，从而完成进一步的勒索。


Gamaredon组织使用Outlook宏分发恶意软件分析

Gamaredon组织自2013年起一直活跃至今，且已经发动了多起攻击事件，其中多数是针对乌克兰机构的攻击。在过去的几个月里，该组织的活动有所增加，恶意邮件不断发向目标邮箱。这些邮件的附件是带有恶意宏的文档，当执行这些恶意宏时，会尝试下载多种不同的恶意软件变体。其所使用的编程语言包括C＃、VBScript、batch files和C/C++等。


IBM解决了IBM WebSphere Application Server中两个关键漏洞

一位使用绰号“ tint0”联机的安全研究人员发现了三个严重的反序列化问题，这些问题影响了IBM WebSphere Application Server。其中两个漏洞（CVE-2020-4450 和 CVE-2020-4448）是被评为严重的远程代码执行问题，第三个是被评为高度严重的信息泄露漏洞。这位专家于4月中旬通过趋势科技的零日活动（ZDI）向IBM报告了这些问题，这家IT巨头上周公开披露了这些问题。IBM已经解决了所有漏洞，并确认没有证据表明存在利用野外漏洞进行攻击的攻击。CVE-2020-4450 和 CVE-2020-4448已收到9.8的CVSS分数，它们是由缺乏用户提供的数据的适当的验证的，这可能会导致不可信数据的反序列化。

CVE-2020-4448问题驻留在BroadcastMessageManager 类中，可以利用它来利用SYSTEM特权执行任意代码执行。CVE-2020-4450漏洞存在于IIOP协议的处理中，攻击者可以利用它来允许具有root特权的代码执行，可以通过发送特制的序列化对象序列来利用此漏洞。该缺陷影响 IBM WebSphere Application Server 8.5和9.0，而CVE-2020-4448也 影响 WebSphere Virtual Enterprise Edition。目前，IBM已经解决了所有漏洞，并确认没有证据表明存在利用野外漏洞进行攻击的攻击。
