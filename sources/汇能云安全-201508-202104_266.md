4月9日，星期四，您好！中科汇能与您分享信息安全快讯：

  

****Coinminer恶意软件与Zoom捆绑传播****

由于COVID-19疫情越来越严重，世界各地的公司都已选择远程办公。早在病毒爆发之前，zoom就已经被许多公司和远程工作的人用来召开会议等。与此同时，网络犯罪分子也在利用这些工具传播恶意软件。近期发现Coinminer与Zoom安装程序捆绑在一起，诱骗目标下载安装恶意软件。这些安装软件并不是来自Zoom官方下载中心，都是来自虚假恶意网站，建议用户从应用程序官方网站下载安装程序。

  

**研究员在公网上发现超8千个可直接访问的Redis服务**

趋势科技的安全研究员发现了约8000个不受保护的 Redis 实例，可遭任意互联网用户访问。这些不安全的 Redis 实例遍布全球，它缺少传输层安全 (TLS) 加密机制且不受密码保护。其中某些实例甚至被部署在公有云上。作为开源的内存数据结构存储系统，Redis（远程字典服务器）用于可信环境中。因此，如不受保护且可从互联网访问，那么 Redis 易受所有类型的滥用，包括 SQL 注入、跨站点脚本攻击甚至是远程代码执行。  

****80%Exchange服务器尚未修复高危漏洞****

目前在Internet上暴露的所以Microsoft Exchange服务器中，有超过350,000个尚未针对影响所有受支持Microsoft Exchange服务器版本的CVE-2020-0688后远程代码执行漏洞打补丁。默认情况下，Exchange Control Panel (ECP)组件存在这个安全缺陷，它允许攻击者使用以前窃取的任何有效电子邮件凭证来接管脆弱的Microsoft Exchange服务器。周二，微软在2020年2月的补丁中修补了这个RCE漏洞，并将其标记为“更有可能被利用”的可利用性指数评估，暗示该漏洞对攻击者来说是一个有吸引力的目标。

  

****安全人员发现部分恶意软件通过盗版Zoom安装软件传播****

攻击者正在利用Zoom视频会议服务日益普及的优势来分发安装程序，这些安装程序与恶意软件和广告软件应用程序捆绑在一起。随着人们花更多的时间在室内进行身体/社交活动，许多人开始将Zoom会议用于远程工作、健身课程和虚拟聚会。了解了这一点，威胁行动者已经开始分发与恶意软件捆绑在一起的Zoom客户端安装程序，如Coinminers、远程访问木马和adware包。

  

******黑客恶意注册多个Zoom相关敏感域名用来发动攻击******

自COVID-19爆发以来，攻击者试图利用Zoom不断增长的用户基础，注册了数百个以Zoom为主题的新域名，进行恶意攻击。视频会议软件公司Zoom为其客户提供了一个基于云的通信平台，可以用于音频和视频会议、在线会议，以及通过移动、桌面和电话系统进行聊天和协作。自2020年初以来，该公司每月新增的活跃用户数量急剧增加，因为现在有数百万员工在家工作，仅今年就新增了约222万，而到2019年仅新增了199万。

  

**** Zeus Sphinx木马借病毒趋势大范围传播****

在中断了三年之后，宙斯狮身人面像银行木马最近重新出现，这是一场以冠状病毒为主题的网络钓鱼活动的一部分，这是目前流行的大多数攻击背后最常见的主题。宙斯狮身人面像是一个恶意软件应变,最初发现早在2015年8月,当其运营商用它来攻击几个英国财务目标和它几乎完全是基于宙斯v2木马的泄露源代码。这种恶意软件后来被用于攻击全球各地的银行，从澳大利亚、巴西到北美，试图通过网络注入获取金融数据，利用社会工程说服受感染的用户分发验证码和凭证。
