# **1、Le****vi's****推出智能骑行夹克 碰下袖口即可通话：**该产品将可以让穿戴者只需触碰和滑动夹克的袖口就能完成各种任务，如控制音乐、接电话、获取导航信息等等。谷歌与Levi's的合作最初公布于去年，谷歌启动这一项目的初衷是“希望将一块笔记本触控板，或者手机触控层嵌入到衣服里面，来远程控制智能设备，比如拂一拂衣袖就能打电话”。智能夹克的袖口嵌入了Jacquard标签的传感器，因而带来了上述功能，它可以取出，可通过USB充电。该标签连接了夹克中的LED灯、触觉元件、电池和织入的传感器。在设计上很巧妙的一点是，该技术的连接点利用了夹克的纽扣眼，感应区域就位于袖口，看起来不那么突兀。

**2、这款能测体内酒精的手环拿走了穿戴挑战赛20万美元大奖：**据悉，美国国立健康研究院举办了一次“可穿戴生物传感器挑战大赛”，近日，一款能够测量体内酒精的手环获得了第一名，拿走了20万美元大奖。这款手环名为“BACTrack Skyn”，主要能够通过汗液分析血液中的酒精含量。由于通过皮肤而不是直接通过血液获取数据，因此手环测量到的体内酒精含量，存在一定的滞后性，体内的酒精通过皮肤汗液散发出来，距离饮酒的时间为45分钟左右。

  

# **3、舌尖上的3D美味：美国引进3D打印糖果 只需5分钟：**据外媒报道，美国民众终于可以吃到3D打印的软糖了。坐落在纽约曼哈顿上东区的全球最大糖果店“迪伦棒棒糖”（Dylan‘s Candy Bar），与以独创巧思出名的英国嘉思魔法糖果工厂（Katjjes Magic Candy Factory）合作，将后者全球唯一的安全3D食物打印机引进美国。迪伦棒棒糖”向来专长将艺术、时尚、通俗文化融合为一，如今加上高科技。嘉思则不只拥有全球独家的3D食品打印软件，而且工作速度十分惊人：客制化糖果不用五分钟，让客人满意而去。嘉思魔法糖果工厂以特殊技术将天然蔬果成分加热做成各种形状，将形指令变成密码，以店内方便好用的平板计算机控制打印机，这个阶段大约十分钟完成，互印糖果则如同光速，最快三分钟，最慢不过五分钟。

**4、小米将推无人机 抢占下一个“风口”？：**向喜欢玩跨界的小米，这回又找到了新目标。昨日，小米雷军又一次在微博上爆料小米无人机，并确认将于5月25日晚7点，通过小米直播APP发布小米无人机。从之前小米官方宣传海报看，小米无人机应该是采用了四旋翼设计，摄像头则是圆球造型，或许支持360度全角度旋转，同时支持4K@30fps拍摄以及光流定位。从产品定位来看，小米无人机应该走的是高端路线，但在价格方面或许还将继续扮演“价格屠夫”的角色。小米的优势在于可以让无人机与智能硬件和可穿戴设备的结合，这将会带来更丰富的交互和智能场景。据了解，小米此前申请了一项《无人机的拍摄控制方法及装备、电子设备》的专利。

**【信息安全】**

# **1、互联网金融创业者遭黑客勒索 网贷平台成网络安全重灾区：**互联网金融行业或许正在成为网络攻击的最大的受害者。今年上半年，全国金融行业(含互联网金融)安全漏洞总量同比增长181.9%。全球最大黑客组织匿名者(Anonymous)突袭希腊央行之后，宣称长达30天的DDoS攻击开始。随着塞浦路斯央行、荷兰央行、马尔代夫央行等众多官网站点被DDoS攻击瘫痪，其他各国金融机构纷纷拉响抗DDoS警报。根据该黑客组织公布的攻击名单，中国人民银行也赫然在列。然而，正深受DDoS攻击之扰的金融机构并非仅限于此，互联网金融行业或许正在成为最大的受害者——蚂蚁金融、网贷之家等多家P2P平台或第三方信息服务平台接连遭到黑客攻击。

**2、总交易额近71亿 e速贷涉嫌非法吸存被查：**近日，开业近6年的P2P平台e速贷（运营主体为广东汇融投资股份公司）被警方调查的消息不胫而走，引起行业广泛关注。据网贷之家不完全统计，截至2016年5月13日，至少有24家银行布局资金存管业务，超过82家P2P平台与银行签订了资金存管协议（不含前期谈判、协议签订中）。其中，正式完成银行存/托管系统对接的P2P平台约18家，包括积木盒子（民生银行）、人人贷（民生银行）、爱钱帮（徽商银行）、德众金融（徽商银行）、口贷网（农业银行）、银豆网（江西银行）等。此次涉嫌非法吸收存款的e速贷，其托管机构为广东南粤银行。

**3、加泰罗尼亚警察工会的服务器遭到攻击,警方暴力执法被曝光：**据报道,有一名匿名黑客将加泰罗尼亚警察局官方网站中的机密数据全部泄漏了出来。而他之所以要进行这样的黑客活动,原因就是:警方的暴力行径。在此之前,HackRead曾报道过有关“Phineas Phisher”(菲尼亚斯网络钓鱼者)的攻击事件。根据报道,“@GammaGroupPR”非法窃取了大量的比特币,并且将这些比特币全部捐献给了库尔德组织。没错,这名黑客就是之前入侵了Hacking Team的那名黑客,而他也是FinFisher恶意软件的开发者。

**【智能家居】**

**1、锂电池供电 手持式微波炉售价199美元：**Wayv公司和恩智浦半导体合作，推出了一款名为冒险家的手持微波炉，它是一个电池供电的无线射频烹饪器具，体积足够小，可以轻松放入在一个背包。它的目的是在任何地方加热食物和饮料，设计紧凑，坚固，重量轻。它也可以用在禁止使用明火的地方。这款手持微波炉顶部设有简单的控制，包括启动，停止，背光源和时间调节按钮，以及一个数字显示屏。它使用横向扩散金属氧化物半导体（LDMOS）晶体管，生成250瓦的功率，可以均匀加热食物，无需转盘进行加热。不像在普通微波炉中使用的真空管，冒险家使用用于RF放大器开发的技术在手机信号塔-。这就是使得设计如此紧凑和重量轻，而且它也使食品均匀而不需要一个转盘进行加热。

  

**2、有了这款智能“美图镜镜”女神经秒变女神：**最近，一家名为Simplehuman的家居用品制造商也开始触电物联网了，该公司打造了一台名为SensorMirror Pro的智能化妆镜。虽然看起来奇貌不扬，但这款化妆镜功能十分强大，它可以将图像放大5倍到10倍，以方便你涂抹眼线液、烫睫毛和打粉底。此外，它还搭载了独有的照明系统，显色指数达到90（显色指数越接近100，光线越接近自然光）。同时，一旦化妆镜的内置传感器感应到用户的出现，其内置LED就会自动点亮，不过在试用时它却总是没来由的突然灭掉，让人很苦恼，希望Simplehuman能尽快对其进行改进。除了这些贴心的功能，SensorMirror Pro化妆镜还有一些让人意想不到的功能。对，这款镜子有适配的应用，因此你可以根据自己的喜好为其设定各种使用模式。另外，这款化妆镜还能与Nest的智能家居系统互动，只需一键，就能将NestCam上的灯光设定同步到化妆镜的LED上。
