4月20日，星期三，您好！汇能科技与您一起分享行业快讯：

 

【科技】

 

1.YouTube推出VR直播功能：首先你得有10M网速：北京时间4月19日午间消息，YouTube本周宣布，将推出360度视频的流媒体直播服务。在今年的科契拉音乐节上，将会有部分演唱会利用该技术进行直播。与此同时，YouTube宣布，其视频将可以通过“空间音频”技术去得到增强。这项技术可以模拟来自不同方向和距离的音效。笔记本用户可以通过鼠标来调节视角。而如果在智能手机或虚拟现实头显上播放，那么体验将会更具沉浸感。随着设备的移动，视角也将发生改变。目前，任何人只要拥有兼容的360度摄像头，并可以以10Mbps至20Mbps的网速上传视频，就可以通过YouTube进行360度视频直播。此举将使YouTube领先于竞争对手Facebook，后者支持360视频播放以及流媒体视频直播，但不支持两者的结合。

 

2.苹果获可折叠镜头专利 未来iPhone后置镜头不再突出：北京时间4月20日消息，据科技网站AppleInsider报道，由于苹果发明了全新的紧凑型长焦镜头系统，用户为使用光学变焦功能而忍受智能手机相机突在机身外的日子可能将很快成为过去。苹果获得的这项专利被称作“可折叠长焦相机镜头系统”，描述了一种形状与小写字母“r”相似的长焦镜头——很容易让人想起老式潜望镜。光线进入主镜头，通过镜面反射，然后经过副镜头聚焦到成像传感器。副镜头上下移动很小的幅度——即使只有几分之一毫米，整个系统就可以产生长焦镜头的效果。

 

3.高通与酷派间接子公司达成3G/4G新授权专利协议：4月19日消息，高通宣布，已经与酷派集团间接持有的全资附属子公司宇龙计算机通信科技(深圳)有限公司达成新的3G和4G中国专利授权协议。根据授权协议，高通已授权宇龙开发、制造和销售在中国使用的3G WCDMA、CDMA2000(包括EV-DO)和4G LTE(包括"三模"GSM、TD-SCDMA和LTE-TDD)终端设备。高通方面表示，宇龙应支付的专利费用与高通之前向中国国家发展和改革委员会所提交的整改措施条款相一致。

 

4.苹果更新MacBook 新增玫瑰金色外观：昨日4月19日消息，苹果更新MacBook，配备最新Intel处理器，并增加了一个小时的电池使用时间。此外，MacBook除金色、银色、深空灰色外，新增玫瑰金色。MacBook于起在苹果官网发售，于今日起在Apple Store零售店和部分苹果授权经销商处发售。据介绍，更新后的MacBook配备最高可达1.3 GHz的第六代双核Intel Core M处理器(Turbo Boost 最高可达 3.1 GHz)，以及更快的1866 MHz内存。新的Intel HD Graphics 515图形处理器可提升最高可达25%的图形处理性能，而更快的基于PCIe的闪存使得启动app、打开文件这样的日常任务更加敏捷。


 

【信息安全】

 

1.微信公众号新申请账号不再允许重名：4月19日消息，微信宣布对公众号命名规则进行调整，“命名唯一”原则已经从过去的认证账号，扩大到更多账户。当新注册账户所输入的名字，与平台内已有名称相重复时，就有红色文字提示“基于账号名称唯一原则，请重新提交一个新名称。如果你认为已有名称侵犯了你的合法权益，可以进行侵权投诉。”除了新注册账号，目前有需要申请认证的账号同样要求执行“命名唯一”原则。

 

2.苹果称89%用户使用Touch ID加密设备:4月19日消息，据国外媒体报道，苹果称其iPhone用户平均每天解锁设备80次，其中89%的用户通过TouchID来完成解锁。据悉，美国硅谷咨询公司Creative Strategies分析师本·巴加林(Ben Bajarin)于周一在科技网站Techpinions上发布了该数据。据此前报道，在与FBI的纽约iPhone解锁诉讼中，苹果上周曾向法庭提交了文件，就其设备对用户的安全性保护进行了详细阐述。苹果公司表示，89%的用户通过Touch ID这一功能解锁其iPhone和iPad设备。而据巴加林自己的研究表明，有85%的用户使用Touch ID或密码来保护设备安全。巴加林认为，苹果通过易用的安全加密系统不断加强对消费者隐私权益的保护，其中一个重要考量因素是用户敏感信息的大量数字化。

 

3.苹果证实将弃用Windows版QuickTime：4月19日消息，据国外媒体报道，苹果本周一证实，将停止对Windows版的QuickTime的支持服务。据悉。在上线十一年之后，苹果向华尔街日报明确，将不再发布有关PC版QuickTime的更新或安全补丁程序，这意味着继续使用该软件的用户将需要自主承担风险。上周，安全厂商趋势科技（Trend Micro）披露了Windows版QuickTime的两个新漏洞。公司称去年十一月份就已经告知了苹果相关情况，苹果当时表示并无发布补丁的计划，并补充称“Windows版QuickTime将会被弃用，同时为用户提供卸载说明。” 至于被发现的漏洞，趋势科技称通过QuickTime打开恶意网站或播放受病毒感染文件时会出现此漏洞，其为远程执行代码打开后门，导致恶意用户会在目标计算机上植入木马等恶意软件。

 

4.谷歌安卓年度安全报告：每天为4亿台设备提供安全服务：北京时间4月20日消息，据CNBC报道，近日，世界最大的移动操作系统制造商谷歌表示，安卓系统比之前安全多了。本周二，谷歌发布了第二版安卓年度安全报告，报告中展示了它们是如何保护数十亿设备的。眼下，谷歌越发重视安卓系统的安全，它们正在投入更多的人力和物力来应对潜在威胁。通过谷歌的漏洞寻找计划，安卓部门已经付给技术大牛们20万美元，修复了100多项致命漏洞。“我不觉得黑客实力在变弱，”卢德维格说道。“实际上，他们的攻击变得越来越复杂，但幸运的是，我们的防御能力增长的更快。”

 

【智能家居】

 

1.懂拍摄的小屏努比亚发布nubia Z11 mini手机：4月19日下午消息，努比亚在北京751D PARK第一车间举行Z系列新品发布会，推出了5英寸屏幕nubiaZ11 mini手机。在外观方面，nubia Z11 mini采用了一块5英寸的1080P屏幕，正面下方依旧是经典的“小红圈”设计。中框为金属材质，底部采用对称式设计并配置了Type-C数据接口。前后均为2.5D玻璃材质，后置指纹识别模块。在硬件参数方面，nubia Z11 mini搭载高通骁龙64位8核处理器，辅以3GB RAM + 64GB ROM组合。搭载基于Android 5.1.1系统的nubia UI 3.9.6。支持双卡双待全网通4G+，以及双卡盲插VoLTE技术。采用双频Wi-Fi设计，搭载2800毫安时电池。

 

2.英大学研究全新燃料电池:靠尿液就能发电：4月19日消息，据科技网站TechRadar报道，你是不是也想过凭一己之力驱动全世界？现在这个梦想可以实现了，来自英国巴斯大学的研究人员开发出了一种新的燃料电池，它可以将尿液转化成电能。在这个过程中，燃料电池中用于发电的微生物可将尿液中的有机物质转化成电能并存储在电池中。

 

3.科技又憋新大招 人类皮肤可当显示屏用：虽然现在智能穿戴设备已经在人们生活中普及开来，但智能设备的形态还是过于“传统”。但是在未来，智能穿戴设备将能够很好的和人类的身体很好的结合在一起，皮肤还能当做显示屏来使用！今日研究人员开发出一种超薄显示屏——有机高分子发光二极管材料，这种显示屏只有3微米厚，目前可以利用薄膜把显示屏粘贴到皮肤上，能够像纹身一样呈现出多种图案。虽然目前看来设计还很粗糙，而且只能显示数字和字母，功能也就是检测脉搏和血氧含量，但这种技术能给我提供一个全新的交互方式，让我们的可穿戴设备进行一个质的飞越。
