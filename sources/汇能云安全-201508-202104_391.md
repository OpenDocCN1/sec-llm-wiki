**4****月11日，星期一，您好！汇能科技与您一起分享行业快讯：**

**【科技】**

**1.****开心果机器人公司发布阿U兔智和阿U幻镜儿童机器人：**4月10日消息， 4月9日开心果机器人公司正式推出两款儿童智能产品——阿U兔智和阿U幻镜，并与香港科技大学机器人研究所、北京盛开互动、孩子王、天智通讯、百米生活等单位签署战略合作协议。开心果机器人公司CEO马舒建表示，阿U兔智和阿U幻镜应用了AR增强现实技术、视觉识别技术、情感设定技术，主要面向3岁-10岁儿童，为他们提供教育、互动娱乐，配备语音识别、身份识别、情绪识别、远程监控等功能。

![](../Images/85db160e31e7c09407e56ae853af720d.png)  

**2.****1700Hz刷新率！Nvidia黑科技将消灭VR头晕：** Nvidia 在不久前的 GTC 2016 大会上公布了他们的 VR 头显技术，号称将完全消灭眩晕。Nvidia 向人们宣布：我家的新技术能够达到 1700Hz！如果要进行一个直观的对比—— 90Hz 设备每 11 毫秒显示一张图像，而 1700Hz 设备每 0.58 毫秒就能够显示一张。在 GTC 2016 上，Nvidia 研发部门副总裁 David Luebke 展示了公司最新的技术原型。Nvidia 将显示屏固定在一个轨道系统上让其快速来回移动。凭借着是主流设备 20 倍的刷新率，显示屏在剧烈的运动下图像仍旧能够保持让人惊异的稳定。

 

**3.****Xbox跨平台联机准备就绪 索尼能否不再傲娇****:**对于玩家们来说，微软近期来最让他们震惊的新闻莫过于 Xbox One 即将支持跨平台联机功能了。一直以来各个平台之间在玩家眼中那是壁垒分明，联机当然也就是各玩各的了。现在，微软已经正式公开了这个新特性，而且表示他们已经准备好了。微软如此表态，大家最关心的自然是老冤家索尼了。就在上个月，微软正式宣布将带来 Xbox One 跨平台功能。这意味着 Xbox Live 玩家不再只能独自联机，而是可以和索尼玩家、PC 玩家一起游戏，甚至它和 PC 端的互联都不仅限于 Windows 10。有趣的是，相对于微软的“热情”，索尼一直显得态度十分暧昧。

 

**4****.****更薄机身的Apple Watch 2 两个月后发布****？****：**之前就有传闻称，新款Apple Watch 将会随着 iPhone 7 在今年 9月份推出。但根据分析师 Brian White 在中国供应链的探访，苹果很有可能将会在 6 月份的 WWDC 跟随新版的Watch OS 系统推出全新的 Apple Watch。对于新款 Apple Watch 的曝光还比较少。不过从现在能得到的消息看，新款 AppleWatch 将会保持原有方形表盘、机身薄了 20% 到 40%。而从苹果之前推出多款表带的举动来看，新款 Apple Watch 不出意外还是保持 38mm 和 42mm 两个版本，并且会兼容现有所有表带。

**【信息安全】**

**1.****谷歌光纤宽带免费时代结束:**4月11日消息，据国外媒体Engadget报道，谷歌光纤在最开始推广的时候曾有这样一句广告语：一次支付，终身免费。但如今，谷歌光纤免费时代即将结束。新的付费方案将首先在堪萨斯城实施。新方案包含两部分，首先是选择Fiber 100高速宽带，但用户每月支付50美元；另一种选择是使用小区共享网络，价格仍旧免费.

 

**2.****聊天记录又安全了：iMessage漏洞已被修复****：**上个月在 iOS 9.3 正式版发布之前，国外一个由三位安全专家组成的团队曾曝光iMessage 存在漏洞，可能会导致用户聊天记录泄露，好在现在已经被修复了。上个月苹果已经意识到了这个iMessage 漏洞的存在，并将之标记为“CVE-2016-1764”，该漏洞原本的目标是 OS X 端的 iMessage 应用，但这当然也会影响到 iPhone 用户，不过截止至漏洞被修复前尚未发生与其相关的违法案件。在这里也提醒各位用户，信息中不明来历的网页链接千万不要随意点击打开。

 

**3.****复盘Build 2016:别错过微软给开发者的福利****：**在最近的微软开发者大会（Build 2016）上，微软展示了其最近获得的成就，以及各个产品和平台上针对开发者的更新，还宣布了一系列让开发者们激动不已的消息，比如将在 Windows 上包含能够直接执行 Linux 程序的子系统，Xamarin 将会免费并且开源等。微软已经为非 。NET 开发者和非 Windows 平台提供了大量的工具和产品。比 如发布基于 Linux 操作系统的 Sql Server 数据库，在 Windows 中引入 Linux 子系统并内置 Bash 命令行终端.

 

**4.****电信网络诈骗首发A级通缉令****：**京华时报讯(记者袁国礼)记者昨天从公安部获悉，公安部正式发布A级通缉令，公开通缉十名特大电信网络诈骗犯罪在逃人员。对发现线索的举报人、协助缉捕有功单位或个人，每抓获一名犯罪嫌疑人公安部将给予5万元奖励。公安部刑侦局副巡视员陈士渠表示，这是公安部首次大规模地对电信诈骗在逃人员进行公开通缉。

**【智能家居】**

**1.****首款燃料电池多旋翼无人机发布续航273分钟****：**近两年，无人机已经开始从军事领域向民用市场普及，续航更长、动力更强的无人机产品层出不穷。现在，国内无人机制造商科比特航空正式发布了全球首款氢燃料多旋翼工业级无人机——HYDrone-1800，拥有超长续航时间，主要定位电力、石化、安防、消防等领域。科比特航空介绍称，运用技术成熟、性能稳定的氢燃料电池，HYDrone-1800的续航时间长达273分钟。

 

**2.****CITE2016：海尔发布Ubot家庭智能机器人****：**近日消息，智能机器人是海尔为了解决智能家居、智能家电行业人机交互体验不佳，将可以移动的智能机器人做为家庭中人机交互的中心。这款Ubot家庭智能机器人定位于家庭使用，极具亲和力的外观设计，60厘米高度设计，让他成为孩子的“小伙伴”，仿人类的双臂可以做出各种情感表达的动作。并且Ubot家庭智能机器人还拥有其他的功能，家庭安全卫士:他能够在漏水、漏气、火灾时，发出报警信息，并进行适当的处理，确保损失降到最低；他能在有陌生人非法入侵时，用声音恫吓对方，并拍照、录像发给主人和保安，确保将坏人绳之以法。

**3.****发布前的最后预热 HTC 10真机图再曝光****：**北京时间4月11日消息，据科技网站The Verge报道，HTC新旗舰本月12日就要正式与大家见面了，今天，荷兰网站GSM Helpdesk对其进行了发布前的最后一次精确曝光。据称该机将被命名为HTC10，将在五月中旬开始全面铺货。与此前曝光的渲染图类似，该机的背部边缘设计非常独特，比此前流行的边缘倒角切割要宽的多，而从正面来看，HTC则一改此前被诟病的四下巴设计，用上了One A9的设计元素，最重要的是，该机居然取消了正面的HTC标志，而备受好评的BoomSound双扬声器也悄然消失。
