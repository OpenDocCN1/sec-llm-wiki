**3****月11日，星期五，您好！汇能科技与您一起分享行业快讯：**

**【科技】**

 

# **1.微信确认将推企业版微信工作生活分开说：**3月11日消息，昨日晚间微信官方公布了企业微信的细节。微信方面表示，企业微信将于一两个月内发布，并且会同步发布多个版本，包括在ios、android、mac、windows版。发布上线的初期仍然会采取邀请制的方式。暂时只对腾讯企业邮箱和微信企业号用户开放。

 

# **2.人机大战第二局：李世石认输 AlphaGo再次获胜：**3月10日消息，谷歌旗下人工智能公司DeepMInd开发的智能系统AlphaGo（阿尔法围棋）和韩国职业围棋选手李世石九段的第二局比赛于今日北京时间中午12时在首尔举行，经过4个半小时的对弈，李世石投子认输， AlphaGO再次获胜，2-0领先取得赛点。

 ![](../Images/fd5d8ef10d631454a6f3a6af3105ae16.png)  

# **3.欧盟即将起诉谷歌：利用安卓垄断移动互联网：**安卓已经成为全世界一家独大的智能手机和平板电脑操作系统，份额超过八成五。去年，欧盟在一些公司投诉后，开始对谷歌(微博)安卓进行反垄断调查，据彭博社最新消息，欧盟即将对谷歌发起反垄断诉讼，罪名包括利用安卓优势地位，妄图垄断移动互联网市场。 

# **4.维基百科年内推语音版服务视力不佳者：**维基百科早已超出了一款互联网百科辞典的意义，成为人类文化发展繁衍历史上的一个奇迹，每天全球数以亿计的用户在查阅维基百科。据外媒最新消息，维基百科将开发一个语音引擎和语音版，服务盲人、弱视等视力不佳的群体。![](../Images/6f6dfa6a69ecd79acc62f99a1229cb29.png)  
**5.新政策将出台：无许可网上禁售自制食品：**入网食品经营者不得通过互联网销售散装熟食、无包装的散装食品。未取得食品经营许可的个人，不得通过互联网销售自制的食品。昨天，记者从“加强网络食品经营监管落实企业主体责任宣传动员会”上获悉，北京市食品药品监督管理局本月底将出台《北京市网络食品经营监督管理办法（试行）》，这意味着网络订餐、“朋友圈美食”将面临更为严格的监管。 

**【信息安全】**

## **1.Android N将提供省流量模式 可拦截垃圾信****息：**Android N提供了多种新功能，包括分屏多任务，以及新的通知管理系统。此外还有“省流量”模式，用户可以在系统级拦截来电和消息。 

# **2.4000网友做调查 八成不会改WiFi密码：**75%的网友表示，智能设备在联网时使用更多。然而，在智能设备使用习惯方面的调查显示，82%的网友不会经常更改家中路由器的密码。而实际上路由器是各类智能终端通过Wi-Fi联网的入口和桥梁，其安全性不仅关乎手机、平板、电脑等设备的信息安全，甚至能够通过智能家居带来更严重的威胁。

#  

# **3.生物识别技术未必安全 而且它还带来其它隐忧：**我们都讨厌记忆大量的密码，而生物识别技术提供了一种省心、高效的替代方案。自从苹果在iPhone 上使用指纹识别技术，生物识别在消费领域的步伐明显加快了。但是，生物识别技术未必像我们想象的那么安全，而且，它可能还会带来隐私方面的问题。针对生物识别技术，Wired 网站采访了几位技术和法律方面的专家。

**【智能家居】**

 

# **1.智能家居距离用户仅一步之遥只需巨头相互妥协：**从谷歌用重金收购Nest，苹果推出Homekit智能家居平台，到三星、海尔、美的相继发布智能家居战略和推出智能家居平台，科技大佬和家电大佬们早已用实际行动证明了这个市场的潜力。

**2.苹果申请新专利 让Apple Watch变身医疗设备：**周四公布的一项苹果专利申请显示，苹果正在把Apple Watch打造成为一个全面的医疗设备，一个可以监视用户生命体征，并在他们需要紧急护理的时候，自动发出警告。

# **3.HTC Vive能为开发者带来破冰之旅吗？：**3月9日有消息称，AmazonVideo正在招募高级软件开发经理的职位，以帮助亚马逊创建一个能够进行沉浸式叙述的平台和界面，包括一个能够拍摄和播放虚拟现实的平台，此举被外界认为是亚马逊这家互联网巨头正式进军VR领域的重要一步。
