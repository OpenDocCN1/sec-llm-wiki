【科技】

 

1. 第九城市旗下子公司九城教育在新三板挂牌上市：近日国内游戏开发及运营商第九城市旗下的子公司上海第九城市教育科技股份有限公司，在全国中小企业股份转让系统完成上市工作。教育成立于2012年5月，是第九城市旗下的子公司，并于2015年6月完成股改。第九城市于1999年成立，2004年在纳斯达克上市，是国内资深的网络游戏运营及开发商。

 

2. 饿了么否认与口碑合并 称双方只是外卖业务合作：有传言称饿了么将与口碑合并，将打破饿了么独立运营的承诺。界面新闻记者就此询问饿了么内部人士，对方称消息不实。该人士表示，双方更多的是业务板块的合作，并不是大规模的合并。业务合作模式有可能是口碑的外卖业务并入饿了么，也有可能只是双方的资源整合。

 

3. 索尼在中国召回超1万块笔记本电池 存过热隐患：索尼中国近日向国家质检总局提交了召回计划，因存在过热烧坏隐患，召回10617块进口VAIO笔记本电脑电池组。索尼在官网通知中指出，该批召回产品由松下集团旗下企业提供，生产日期为2013年1月至2013年4月期间，型号为VGP-BPS26。召回范围内的电池组由于在生产过程中混入金属异物，在个别情况下存在过热导致烧坏隐患。

# 4. 东芝拟改制为控股公司以加强企业管制：据共同社报道，出于对长年未能发现财务违规问题的反省，东芝考虑改制为控股公司，以加强企业管治，防止违规操作的发生。同时，东芝希望借改制帮助其可以快速做出经营决断。

#  

# 5. 西数发布一批8TB容量含充氦技术的机械硬盘：西部数据旗下的HGST 2013年首次推出了充氦技术的机械硬盘，希捷也已经跟进，并且都将容量做到了10TB。今天，西数另一个品牌WD终于进入了充氦的时代，并且一口气发布了多款新品，但最高容量仅为8TB。

 

【信息安全】

  

# 1. 台媒：再有大陆留学生因微信聊天内容遭遣返：台媒称，日前一位大陆留学生只因为大半年前在微信聊天中，向朋友透露“我不喜欢这个学校，只是临时挂一下身份”，没想到这段久远的聊天纪录，竟然在入境美国时被海关看到，被盘问三个多小时后，立即就被遣返回中国大陆。

 

# 2. Facebook未遵守法庭命令致其拉美副总裁被捕：Facebook拉美副总裁Diego Dzodan已于巴西圣保罗被捕，当时他正在上班路上。巴西联邦警方逮捕Dzodan的原因是Facebook并未遵守一项旨在帮助调查人员侦查一桩毒品案的法庭命令，该案涉及到一名WhatsApp用户。

 

# 3. 印度4美元手机涉嫌欺诈 已向预订用户退款：曾宣称将提供全球最廉价智能手机的Ringing Bells已开始向预付款消费者退款。该公司的商业模式遭到了调查，并被指控欺诈。

  

4. 快递寄件3月1日开始实行100%实名制：社会治安综合治理基础数据规范》国家标准今日正式施行，今后快递寄件将实行100%实名制。国家质检总局、中央综治办、国家标准委联合发布《社会治安综合治理基础数据规范》国家标准于今年3月1日正式实施。这项规范将推动落实100%先验视后封箱、100%寄递实名制、100%X光机安检等制度保障。

 

【智能家居】

  

1. 日本“机器人出租车”上路供民众试乘：日本“机器人出租车”公司自2月29日开始在神奈川县藤泽市上路供普通民众试乘自动驾驶汽车。该公司由日本著名互联网公司DeNA和自动驾驶风投公司ZEM共同出资成立。在零售商AEON的协助下，购物者在镜头下乘坐这种自动驾驶汽车往返于家门口和AEON的藤泽店之间。
