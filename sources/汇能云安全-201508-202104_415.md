2月29日，星期一，您好！汇能科技与您一起分享行业快报：

 

【信息安全】

 

1. 微信办护照完全秘笈在这里：2月26日，微信近日上线办护照、续签港澳通行证功能，微信官方也于今日公布了“教程”。下面就来一起看下如何利用微信申请出入境业务。打开你的微信，进入我→钱包→城市服务→出入境，就能在线申请出入境业务了。

 

# 2. 五大行联合宣布  手机银行转账汇款将免费：中国工商银行、中国农业银行、中国银行、中国建设银行、交通银行五家银行刚刚联合宣布，今起陆续对客户通过手机银行办理的转账、汇款业务，无论跨行或异地都免收手续费。并承诺，对客户5000元以下的境内人民币网上银行转账汇款免收手续费。

 

# 3. 美团自立门户做支付，欲扩展消费场景却缺乏独特价值：前日，美团支付服务在美团App里悄然上线，与Apple Pay、支付宝、微信支付并列，如果用户使用美团支付付款，还可享受额外的补贴。如此看来，美团是做支付工具可谓已成定势，在移动支付大战已经持续数年的今天，美团作为O2O消费排头兵，仍然没有放弃打造自己的金融服务

 

# 4. YouTube建立专门团队帮助用户减少侵权情况:据国外媒体报道，在过去的几周里，一些知名YouTube用户上传的视频因为侵权而被移除，这也给他们造成了不小的损失。对此，YouTube宣布公司正在筹建一个新的计划来改善平台与用户之间的交流，首先公司将成立一个专门的团队来帮助用户尽量减少犯错即侵权的情况。

 

【科技】

 

1. 鸿海收购夏普谈判延期两周 交易仍可能流产：鸿海（大陆业务称之为富士康）斥资近60亿美元收购日本夏普公司控股权，突然节外生枝，夏普最后关头出现了将近30亿美元潜在债务的信息，迫使鸿海重新考虑是否收购。据外媒最新消息，双方已经决定将收购谈判延期一到两周，鸿海和夏普将会对收购协议进行修改。媒体也指出，此次收购仍然存在流产可能性。

  

2. HTC暗示有意开发手机VR头盔以应对三星的挑战：虚拟现实技术是本届MWC展上的一大热点，而HTC则凭借着自己与Valve联合开发的Vive头盔成为了外界关注的焦点。而眼看着竞争对手（比如三星）在移动VR市场不断发展，HTC似乎也有些跃跃欲试了。

 

3. WhatsApp宣布将停止支持黑莓、S60等操作系统：移动消息应用WhatsApp本周宣布，将于2016年底停止支持黑莓(包括黑莓10)、诺基亚S40和塞班S60系统。而对Android 2.1和2.2，以及Windows Phone 7.1的支持也将结束。Android和iOS是目前领先的移动平台，而微软也在继续发展Windows Phone和Windows 10 Mobile。未来，WhatsApp将专注于这些平台。

 

4. 上海电气将收购苹果供应商Manz 29.9%股权：据外电报道，正在对业务进行重组、寻求募集资金的苹果产品设备供应商Manz周日宣布，该公司将向上海电气出售29.9%的股权。Manz将以“尽可能接近市场价的价格”发行新股，最高价为每股40欧元，从而让上海电气获得公司股权。除去向上海电气出售的新股外，依据德国证券市场的相关规定，此交易最终可能会引发强制要约收购。

 

# 5. 2016深圳IT领袖峰会 聚焦智能时代：2016中国（深圳）IT领袖峰会组委会在深圳市政府新闻发布厅举行新闻发布会，宣布今年峰会将于3月26－27日在深圳市五洲宾馆举行。深圳市委常委、常务副市长张虎、深圳市政府副秘书长蔡文沁、数字中国联合会主席吴鹰、深圳市科技创新委副主任刘锦、数字中国联合会秘书长刘钜波等出席新闻发布会。

 

【智能家居】

 

1. 高通研发新技术，实现电动汽车边行驶边充电：据外媒报道，高通表示他们正在研发一种动态无线充电技术，可以缓解电动汽车行驶一半没电的这种困扰，实现边行驶汽车边充电。

 

2. 青岛产的机器人能看家陪说话 超市网上有销售：作为机器人产业的集聚区，红岛经济区已有60多家企业，甚至机器人四大家族也落户，常说的智能服务机器人、特种机器人、工业机器人，在红岛经济区都能找到。有的机器人能够看家护院 ，让您随时掌握家里状况;有的机器人能够陪读陪说话;有的机器人还能参与打捞救援……

 

# 3. HTC公布VR头盔全球定价 国行版售价最高： 2016年上半年，索尼、Oculus和HTC三大企业的虚拟现实头盔将陆续上市，日前，中国台湾的HTC公布了Vive头盔的全球售价，其中欧洲地区的售价为899欧元，另外中国大陆市场的定价成为全球最高。
