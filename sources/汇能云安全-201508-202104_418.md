**2****月****24****日，星期三，您好！下面与您一起分享行业快报：**

**【信息安全】**

1.  **专骗中国用户 流氓应用伪装成学习助手: **近日安全研究机构Palo Alto发布报告，内容中称在App Store中发现了一款名为“开心日常英语”的App,表面上看它是一款学习类应用，但实际上应用内竟然还隐藏着一款市场App，只要进入“开心日常英语”便会激活隐藏的“XY助手”应用，引诱用户按照引导操作，更危险的是，它已经盗取了大量用户的Apple ID，一旦入侵用户手机可能会造成严重损失。

  

**2. ****北京人均网购去年支出达761元：**昨日，北京市统计局、国家统计局北京调查总队公布专项调查结果显示，去年北京市居民通过互联网购买商品和服务的人均支出为761元，同比增长45%。

  

**3. ****Apple Pay****绑定信用卡遭盗刷？中行：**与ApplePay无关：近日有媒体报道称一用户尝试用银行卡绑定Apple Pay，失败后信用卡被盗刷超过万元的新闻。下午中国银行就此作出回应：该信用卡不可申请Apple Pay服务，该事件是与Apple Pay无关的一起信用卡盗刷事件。

  

**4. ****支付宝安卓版被曝“隐私门” 官方回应称造谣：**近日网友爆料“支付宝Android版涉嫌泄露用户隐私”的消息，支付宝Android版每隔几分钟会在后台启动摄像头进行拍照、录音，并上传到服务器，甚至会扫描通讯录，通话记录，以及附近WiFi等信息。该网友还附上了详细的数据和截图显示爆料的真实性。今日支付宝官方微博做出回应“支付宝客户端使用系统权限的规则是：只申请业务需要的权限，不会做额外的信息采集和后台操作，更不会侵犯、泄露任何用户隐私信息。”

**【科技】**

 

# 1.   **小米5今日发布  高配版售价或破3000元**:经历19个月的磨砺与沉淀，小米2016年开年大作小米5今日终于就要揭开其神秘面纱了。这款让米粉们翘首以盼了多少个日子，肩负着提升小米品牌价值，以重振其往日雄风的扛鼎大作

#  

# 2.   **戴尔670亿美元收购EMC案获美监管机构批准**:  北京时间2月24日消息，据雅虎财经网站报道，戴尔和EMC周二宣布，两家公司的并购交易已经通过了美国联邦贸易委员会（FTC）规定的收购等待期——收购等待期的截止时间点为美东时间2月22日晚23:59），不过该交易还需得到EMC股东和其他地区监管机构的批准，以及符合其他成交惯例条件。

#  

# 3.  **英特尔发新产品与合作 加速推动5G发展**:在近日召开的西班牙巴塞罗那世界移动通信大会上英特尔公司宣布了一系列新的行业合作伙伴关系与产品，并对行业合作、5G原型和无线通信产品三个方面进行了详细的介绍，为实现更快、更智能和更高效的5G无线网络奠定基础。

#  

# 4.  **我国科学家成功解析MLL家族蛋白复合物结构**：中科院上海生科院生化与细胞所国家蛋白质科学中心（上海）雷鸣、陈勇研究组和中科院大连化学物理研究所李国辉研究组近日成功解析出甲基转移酶MLL家族蛋白复合物的结构，并阐释了其活性调控的分子机制。国际学术期刊《自然》2月18日以长文形式在线发表该成果。

**【智能家居】**

# 1.  **中兴发布智能投影Spro Plus  搭载Android M**：中兴今日再次推出便携式智能投影Spro Plus。Spro Plus是Spro家族的最新产品。该产品配备平板级触摸屏，融合了投影仪与平板电脑的功能，外接USB摄像头还可以通过Skype等应用实现多方视频通信。配置方面，这款产品配备了8.4英寸2K分辨率AMOLED触控屏和12100mAH大容量电池，还可连接Wi-Fi和4G LTE网络，用户可扫描二维码连接并控制投影设备，用户体验方面有较大的提升

  

# 2.  **无人机将融合人工智能 在工业领域大放异彩**：据科技博客VentureBeat报道，在过去的十年中，无人机迎来了自己发展的黄金时期，它们从价值数百万美元的军用无人机中分离了出来，成功变成了民用的娱乐工具，带人们体验“上帝视角”创造的惊喜，现在它们更是成了许多行业生产力革新的排头兵

  

# 3. **内置收视服务 LG三星电视受俄罗斯青睐**：Orion Express是俄罗斯境内第二大付费电视运营商，以卫星电视直播为主要业务，在俄罗斯的市场占有率为16%，排名第一位则是占据76%市场份额的Tricolor TV。最近Orion Express表示，将会与三星和LG达成战略合作协议，在三星与LG这两大品牌的智能电视中，将内置名为“Telekarat”的服务。

  

# 4.**  亚马逊Echo成机器猫  ****说句话就能叫Uber或定披萨**：据ZDNet报道，内置Alexa语音助手的亚马逊Echo音箱和FireTV日前迎来了一次软件升级，这两款设备也摇身一变成为了百宝箱。现在，它们不但整合了Spotify音乐会员，还能召唤Uber司机，预订达美乐披萨。

  

# 5. **“10后”不落后  芭比娃娃也要用上智能家居了**：作为科技界近几年的风潮之一，“智能家居”如今也“入侵”了玩具界。在最近纽约举行的2016 年国际玩具展览会上，Mattel（美国玩具生产商）展出了芭比系列的最新产品：The Hello BarbieDreamhouse（你好芭比的梦想之家）。这个“梦想之家”的最大特点就是加入了声控功能，实现像Siri 控制HomeKit产品的效果。
