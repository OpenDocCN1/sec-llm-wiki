2月22日，星期一，您好！汇能科技祝您元宵节合家欢乐，吉祥如意！下面与您一起分享行业快报：

 

【信息安全】

  

1. TPP的签订将会给互联网行业的发展带来巨大影响：TPP号称是全球最大区域自由贸易协定之一。这一协定涉及美国，澳大利亚，新西兰，日本，马来西亚，越南，新加坡，智利，墨西哥，加拿大，文莱，和秘鲁等12个太平洋沿岸国家，协定成员国涵盖了全球40%的经济产出。 该协定是为了促进各成员国之间自由贸易的发展，它将会成为继欧盟协议之后，又一个更大的区域贸易协议。

 

2. 谷歌宣布将转移搜索结果右边栏广告：北京时间2月22日上午消息，谷歌正在对搜索结果页面的广告展示进行调整。谷歌已确认，正在移除桌面搜索结果的右边栏广告。根据此前SEM Post的报道，谷歌AdWords即将调整广告展示方式，即在搜索结果上方展示4条广告，在搜索结果底部展示3条广告，同时删除搜索结果右边栏的广告。去年12月，已有用户注意到，谷歌正测试在搜索结果上方展示4条广告。

 

3. 联想在美国被起诉\--秘密监控用户活动：联想已在美国旧金山联邦法院遭遇集体诉讼。诉讼称，联想预装的软件Superfish会“秘密监控、窃听及传输用户信息”，从而在网页上向用户展示额外的广告。原告方指控称，Superfish会劫持合法连接，监控用户活动，并向合法网页注入用户并未请求的广告内容，并以弹出广告的形式呈现给用户。联想此举违反了《反计算机欺诈及滥用法》，以及美国联邦关于窃听、欺诈、违反合同及非法侵入的法律。

 

4. 惠普计划用Windows手机与iPhone竞争：这款手机名为HP Elite x3，旨在将它打造成针对企业用户的新型“一体化”手机。周一，在西班牙巴塞罗那举行的全球移动展会上（Mobile World Conference）上，惠普终于推出了它的与苹果iPhone竞争的宏伟计划，兑现了该公司CEO 梅格•惠特曼（Meg Whitman）在2012年承诺的惠普要进军智能手机市场的承诺。 

  

 

【科技】

 

# 1. 印度的IT大计划遭遇限电、拥挤和猴子：印度启动了一项180亿美元的数字化计划让国民分享数字革命成果，但波折不断。但是这项计划遇到了一系列历史遗留问题——电力短缺，城市缺乏规划拥挤不堪，还有猴子。

 

# 2. 诺基亚证实将重回手机市场 但尚无具体时间表：据新闻网站Inquistir报道，曾经统治手机业界近20年的超级巨头诺基亚可能会重新杀回手机市场。据CNET报道，诺基亚新任CEO拉吉夫·苏里（Rajeev Suri）在世界移动通讯大会上暗示该公司计划让诺基亚品牌重新杀回手机圈。不过他并没有透露该计划的详细时间表，称诺基亚并不着急。

 

# 3. 华为发布首款笔记本MateBook：在MWC2016巴塞罗那世界移动大会开幕前夕，华为正式发布了传闻已久的MateBook笔记本电脑。MateBook是华为首款笔记本产品，同时属于二合一电脑产品。MateBook是一款二合一笔记本产品，屏幕部分可以卸下作为平板独立使用。整机非常的轻薄，机身厚度只有6.9毫米，同时机身重量也只有640克。笔记本有白色和灰色两种颜色可选。

 

4. 三星支付拟3月入华 抢滩中国移动支付市场：继美国苹果公司之后，韩国三星公司也将挤入中国移动支付市场。韩联社20日报道，三星打算3月在中国推出三星支付服务。三星去年12月宣布与中国银联达成合作协议，银联卡持卡人将可在有三星支付功能的手机上管理和使用自己的信用卡和借记卡。三星去年在韩国和美国首次推出移动支付服务，有大约500万用户。三星还打算今年在其他多个国家推出这项服务，包括澳大利亚、巴西、西班牙。三星支付功能起初只限于三星高端智能手机，现在正在向低端产品延伸。

 

【智能家居】

  

1. 智能家居入侵玩具界?在最近纽约举行的2016年国际玩具展览会上，Mattel(美国玩具生产商)展出了芭比系列的最新产品：The-Hello-Barbie-Dreamhouse(你好，芭比的梦想之家)。这个“梦想之家”的最大特点就是加入了声控功能，实现像Siri控制HomeKit产品的效果。除了声控，能够连接Wi-Fi，还专门配有一个App。通过口头指令，你能够控制电梯来接送芭比上落、打开虚拟微波炉来做早餐、把房子设置成派对模式(灯光闪起、吊灯旋转、楼梯变成滑梯)等等。

  

2. 苏宁中兴跨界合作，进攻智能家居、云计算领域：苏宁和中兴通讯在北京召开主题为“创新共赢，携手未来”的全球战略合作发布会。双方将在硬件开发、技术共享、内容开放、渠道整合、产品包销定制等方面展开深入的合作，涉及到云计算、大数据、智能手机、通讯设备、智能家居等多个领域。
