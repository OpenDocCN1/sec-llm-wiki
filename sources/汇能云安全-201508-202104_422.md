2月18日，星期四，您好！汇能科技与您一起分享行业快报：

【信息安全】

 

1. 乌克兰电力系统以及矿业和铁路系统均遭到Black Energy的攻击：近日，来自Trend Micro（趋势科技：一家提供网络安全软件及相应服务的公司，也是在该领域的全球领导者，以卓越的前瞻和技术革新能力引领了从桌面防毒到网络服务防毒的潮流，以独特的服务理念向业界证明了趋势科技的前瞻性和领导地位。）的专家研究发现，在最近针对乌克兰矿业，铁路系统的攻击中，有一系列Black Energy（黑暗力量）恶意软件的攻击。

 

2. 木马“盗用”百度签名篡改首页和收藏夹：最近360反病毒团队接到用户反馈，说被莫名奇妙的修改了首页，同时浏览器的收藏夹里也莫名其妙的多出了很多收藏站点。经过360反病毒团队的排查，发现用户是误运行了广告程序导致的首页和收藏夹被篡改——这些年广告程序越来越多，本也不算稀奇，但令我们感到意外的是改首页和添加收藏夹的程序。

 

3. 网络犯罪分子可利用恶意DNS服务器劫持Linux应用程序：据了解，网络犯罪分子现在可利用恶意DNS服务器来进行中间人攻击，并劫持Linux应用程序。安全研究人员在Linux的glibc库中发现了一个缓冲区溢出漏洞，并呼吁相关人员尽快修复这一问题。现在，黑客可以利用网络来劫持Linux软件了，而且受影响的软件数量非常多。这一切都源于glibc中的一个严重的漏洞。

 

4. 攻击VMware工作站可获得pwn2own提供的高额赏金：年度Pwn2Own黑客大赛将于下个月返回CanSecWest安全会议,研究人员将要面对的是最流行的浏览器和操作系统,并且需要在其中发现和揭露可利用的漏洞。在今年的比赛中,参与者将被要求在完全补丁版本的64位Windows 10上利用微软Edge或Google Chrome,以及在OS X El Capitan上利用苹果Safari。利用Google Chrome或微软Edge的黑客将会获得65000美元的奖金,而在Mac上利用苹果Safari将获得40000美元。对Windows实现系统级访问或者在Mac OS X上实现root访问将会额外获得20000美元的奖金。

 

【科技】

 

1. 橡胶谷公司获批国家专利运营试点：青岛橡胶谷知识产权有限公司被国家知识产权局确定为“国家专利运营试点企业”，成为我市第三家“国家专利运营试点企业”。青岛橡胶谷知识产权有限公司被国家知识产权局确定为“国家专利运营试点企业”，成为我市第三家“国家专利运营试点企业”。

 

2. 首次发现  彗星尘埃颗粒埋藏南极冰雪下：　据国外媒体报道，近日，一支由日本和美国科学家组成的联合考察队在从南极提取的冰雪样品中，发现了彗星的尘埃颗粒。这是在地球表面第一次发现彗星尘埃的颗粒。他们的研究论文发表在《地球和行星科学通讯》(Earth and Planetary Science Letters)杂志上，文中研究者描述了发现尘埃颗粒的过程，以及分析的结果

 

3. Apple Pay正式入华：就在春节备受网友吐槽的“敬业福”让支付宝陷入尴尬境地，微信支付即将开始提现收费也引发外界热议之际，移动支付领域迎来重量玩家——苹果Apple Pay今日正式入华。Apple Pay在中国的合作方是银联。银联强项是线下收单，这些年互联网支付，尤其是移动支付起来后，支付公司从线上走到线下，主要是利用二维码扫码支付，占有银联传统的市场。

 

4. IDC-2016年全球IT支出增长将减速：IDC预计2016年全球IT支出预计仅可实现2%的增长。市场研究公司IDC今天公布报告称，在经历了几年的稳定增长后，预计全球信息技术行业将在2016年中遭遇自2010年金融危机以来规模最大的企业和政府支出减速。

 

 

【智能家居】

  

# 1. 科学家研究出新玻璃 将助力智能家居：玻璃是每个家庭都必不可少的材料，可变透光率的窗户玻璃，长久以来都是智能家居重要的一环。不过近日，MIT的科学家在玩弄一个名为polydimethylsiloxane(PDMS)的塑料物质时，发现了如果才能正确的预测它的一个特殊属性。在正常型态下 PDMS有着各种不透光的暗区块，但在受到拉伸形变时，这些暗区块就会变得透明。

 

# 2. 智能家居心机重重--“家贼难防”：根据美国调查与咨询公司Gartner公布的数据，到了2016年，在“智能家居”领域一共有3.391亿件联网设备投入使用，是2015年数量的接近2倍。不过在享受智能设备带来的服务之时，也不能忽略一个非常重要的问题：安全与隐私。

# 3. 全球最薄、最轻、速度最快的2TB容量硬盘发布：希捷今天宣布推出全球首款7毫米厚度的2TB容量硬盘，同时也是业内重量最轻、速度最快、能耗最高的7毫米硬盘。这种新的2.5寸硬盘采用SMR叠瓦式磁记录存储，单碟容量1TB，总容量有2TB(双碟)、1TB(单碟)两种。接口SATA6Gbps，缓存容量128MB，平均寻道时间13ms，最大传输率100MB/s，比此前同类产品提升了25％。
