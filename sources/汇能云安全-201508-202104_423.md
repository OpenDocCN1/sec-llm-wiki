【信息安全】

  

1. 百度糯米发布情人节消费大数据  女性买单更慷慨：情人节结束的第二天，国内领先的本地生活服务平台百度糯米发布了2016情人节消费大数据。依托全国400多个城市的覆盖网络和数据来源，内容涵盖餐饮、电影、酒店、鲜花、KTV、温泉等消费品类，百度糯米准确勾勒出今年的情人节消费画像。其中，西餐、创意菜、烧烤和日料成为情人节消费者的最爱，而令人惊讶的是，女性在情人节买单更为慷慨。

  

2. 攻击者利用情人节专属APP传播恶意软件：每年的二月份,情人节专属APP的下载量都会迅速增长。而攻击者却从中发现了机会,因为攻击者可以利用这些情人节专属APP来传播恶意软件!赛门铁克公司的安全研究人员发现，在每年的二月份，与情人节有关的约会类app的数量和下载量都会激增。

  

3. 伊朗黑客成功进入到前IDF主席的计算机：根据以色列的10台报道,一名伊朗黑客去年已经成功地获得了退休的以色列陆军参谋长计算机数据库的访问权限。安全公司发布的许多报道中都曾对伊朗黑客的威胁发出警告,并且这种威胁正呈上升趋势。这些黑客的目标主要是美国和以色列的组织,去年他们曾使用偷来的IDF女性士兵的私人照片攻入了以色列军方服务器。以色列10台在发表的一份报告中称,数百名以色列现任和前任高级安全官员已经成为伊朗黑客攻击的目标。

  

4. 国家机构可采用硬件漏洞对互联网进行监视：随着互联网的不断壮大，所以关于网络安全的会议也越来越多。每年都会有数十亿的新设备连接到互联网上，导致黑客扩大了他们的入侵范围。所以，人们关注的安全焦点大部分都是在一些硬件之间的连接方式。而且，目前来说，大部分的家庭，个人或者公司对网络安全也不太在乎，这样的观念导致了网络安全问题更加严重。

  

【科技】

  

# 

#    1. 小米自吹笔记本\-现在的都烂透了：今天晚上，小米公司运营总监李明@公民大李 在个人微博上发布了一段吐槽称：“我都不想上电脑刷微博了，太慢太慢，有时候手机很多方面都比电脑方便很多，其实这不是件好现象，说明电脑很多地方不思进取。”随后他列举了当今电脑的一系列槽点，包括分辨率太低、摄像头太差、没有指纹、触摸烂的一塌糊涂、工业设计很多地方不堪入目、系统本地化更差。　很显然，这是小米在为自己的笔记本造势，看得出来小米笔记本会有高分辨率、高像素摄像头、指纹识别、精准触摸、优秀工业设计、本地化系统——据说是Windows 10、MIUI双系统。

  

2. 特斯拉携手玩具厂商推出卡丁车版Model S：据科技网站theverge报道，特斯拉公司本周与玩具厂商Radio Flyer合作推出了一款儿童版的“Model S”型“轿车”。这款卡丁玩具车名为“儿童版Model S”，售价500美元，基本上是特斯拉电动轿车的缩小版本。这款卡丁车适合3到8岁的孩子“驾驶”，车重为81磅，最高时速为6英里(可以用开关将时速限制为3英里)。

  

3. 2016年AWE前方高能 黑电技术将势不可挡：作为今年国内最具影响力的，顶级家电展会，中国家电及消费电子博览会（AWE）2016即将在三月初拉开帷幕。当大家看到这篇文章的时候，当然是还没有开始的。2015年的黑电市场精彩纷呈，围绕着显示屏幕的各种技术、造型设计的各种概念，中外厂商展开了一轮轮的隔空争斗。从量子点VS OLED，到曲面VS平面，以及激光电视和OLED电视又展开了谁才是下一代电视的争论。而这些争斗并不如同我们看到的简单的口水战，每一个争斗背后都牵扯着不同厂商的技术以及技术背后所代表的利益。据DigiTimes报道，知情人士称，为了确保4英寸iPhone 5se顺利上线，苹果计划让纬创科技加入代工阵营。 

  

4. 传苹果扩大供应链 纬创组装iPhone 5se：据DigiTimes报道，知情人士称，为了确保4英寸iPhone 5se顺利上线，苹果计划让纬创科技加入代工阵营。分析认为，苹果正在试图将纬创科技培养成“iPhone装配商”，以便为秋季亮相的5.5英寸“iPhone 7 Plus”组装铺平道路。据了解，富士康和纬创科技都将负责4.7英寸“iPhone 7”的组装工作。

  

5. VAIO/东芝/富士通PC业务将合并：早在2015年，日本就传出三家合并的消息，如今终于得到了确认。据外媒报道，VAIO是这次合并的积极促成者。而三家合并的最主要原因是希望通过合并重新塑造PC业务，并与目前日本领头羊联想NEC进行正面的较量。不过新成立后的公司名称以及其他细节等都尚未可知，但日本投资基金Japan Industrial Partners(拥有VAIO公司)的首席执行官Hidemi Moue称，此次合并协议有望于今年3月底向外界正式公布。

  

【智能家居】

  

1. 智能家居普及调查  中国消费者认知远超日韩：GfK最新研究显示，大多数中国消费者认为在不久的将来，智能家居技术就像移动支付和可穿戴技术一样影响着人们的生活。但在日本，只有五分之一的消费者认为智能家居技术将影响他们的生活，更多的人则倾向于移动支付。在韩国，消费者对智能家居和移动支付的观点却不分伯仲。

  

# 2. 华三通信布局智能家居：目前，智能家居的热度已有些烫手。目前海信电器、美的、青岛海尔、四川长虹等这些叫得响的家电企业都已全面转向智能战略，布局智能家居。据了解，华三通信进军智能家居市场的意愿可谓强烈。在推出“魔术家”智能无线路由产品仅3个月之后，日前，华三通信又向市场推出了一款无线中继器，即魔术家F1(H3C-Magic-F1)。
