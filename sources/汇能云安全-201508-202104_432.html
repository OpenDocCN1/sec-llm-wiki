1月13日，星期三，您好！汇能科技与您一起分享行业快报：

【科技】

1. 阿里云将发布大数据平台：2016云栖大会上海峰会将在上海科技馆召开，峰会上阿里云将重磅开启在混合云领域的战略动作，同时首次推出阿里云开放实验室Workshop。

2. 解密百度、阿里医疗产业布局：百度医疗领域的布局以“连接医患+人工智能”为主线，阿里医疗布局与天猫思路一致，希望整合“医疗+药品”。


3. 新浪创业联合果壳举办科技专场，8项目精彩路演：1月12日晚间消息，新浪创业路演最科技专场今日举行，来自全国各地的8个不同领域创业项目，以及20多家知名投资机构投资人齐聚果壳空间，上演一场精彩创新创意大碰撞。


4. 传富士康将在印度建世界最大代工厂：据悉，富士康已计划将智能手机产能从每月100万部，翻倍增至每月产能达250万部，且员工人数今年将至少再招聘1000人以上。


5. 谷歌成立虚拟现实部门，VR或成下个风口：谷歌刚刚成立了一个虚拟现实部门，希望应对Facebook及其子公司Oculus不断发起的激烈竞争。


6. 奥巴马政府将宣布无人驾驶汽车扶持计划：奥巴马本人还有可能在下周二的最后一次国情咨文演讲中讨论改善交通状况的各种措施。


7. 美国部署最新超级电脑 运算每秒5340万亿次：该电脑将在GPS和其他传感器技术的协助下对极端天气进行预测。

【信息安全】

1. 通用汽车邀请黑客攻击自己的系统：为了赶在黑客之前发现汽车系统中存在的安全漏洞，通用汽车日前推出了一个新的披露项目。在这个项目当中，他们将与安全漏洞赏金平台HackerOne进行合作，并通过白帽黑客来获知潜在的安全问题。

2. 蚂蚁金服上线安全响应中心，提交高质量漏洞有奖励：据悉，该平台旨在集合安全领域的专家、白帽子、社会团体及个人共同发现潜在的漏洞信息，并依此建立漏洞统计分析中心，预知并自查风险，及时修复漏洞。


3. 谷歌应用商店下架13款含毒App：谷歌下架了Google Play应用商店中的13款含有“大脑测试”病毒的App。该病毒会深埋在系统底层，暗地向黑客上传用户信息，且无法通过恢复出厂设置删除。


4. 海量下载者修改系统时间致软件升级失效：上海计算机病毒防范服务中心13日预警:近期出现的"海量下载者20992"病毒会严重破坏用户系统的安全,还会盗取各种账号、密码等私人信息,计算机用户要严加防范。

【智能家居】

1. 惠而浦联手IBM发力互联智能家居产品：惠而浦与IBM共同宣布达成一项全新的合作——惠而浦互联家用电器与包括认知分析在内的IBM华生服务进行连接。

2. 云知声软硬件一体方案助力智能家居落地：在本届CES2016上，云知声的众多合作伙伴携智能新品亮相，采用云知声软硬件一体方案的智能机器人、音响台灯皆能听会说，用户声音直接控制，实现更自然的交互。

3. 海尔推动智慧家庭在美国的本土化：海尔美国分公司首席运营官(COO)Kevin Dexter，2016 CES期间接受《第一财经日报》记者专访时表示，海尔正推动智慧家庭业务在美国市场的本土化。


4. 英特尔进军穿戴和物联网，RealSense技术成标配：英特尔与多家公司合作，准备进发智能穿戴领域和物联网领域。以自家特色技术为基础，展出了多种别具匠心的穿戴产品和物联网产品。
