******************1月11日，星期一，您好！汇能科技与您一起分享行业快报：******************

**【科技】**

1. Windows 8寿终正寝，微软宣布下周正式停止支持：在历经了4年的服务后，微软宣布下周二(1月12日)正式停止位Windwos 8提供技术支持，这也意味着Windows8终于“寿终正寝”了。

2. 这家以色列公司的充电技术让手机30秒充满电：以色列一家创业公司StoreDot研发一套新的手机充电系统，充电速度是普通充电方式的200倍。用户可以在6分钟，或者1分钟甚至30秒内充满手机电源。

3. “我和微信的故事”由微信官方推出，盗号为谣言：“我和微信的2015”是为1月11日微信公开课PRO版准备的官方体验。

4. 670亿美元的豪赌：EMC裁员，戴尔变卖家产。EMC将启动8.5亿美元的成本削减计划，裁员将是该计划的一部分；虽然具体裁员数字未披露，但裁员的预计支出为2.5亿美元。

5. 苹果收购的这家情绪识别公司到底是什么来头：据华尔街日报昨日消息，苹果收购了一家可读解人们的面部表情并预测其情绪的公司，Emotient。

6. 消息应用Peach一夜之间爆红美国科技圈：Peach由Vine创始人推出，用户可以发布有趣的动图。

7. 传超20家中国企业在CES展会被查封：多家中国企业因涉嫌违规参展，受到主办方处罚。据悉，在今年的CES展会上，中国公司的参展数量大幅增长，达到1100余家，是去年的两倍，将近三分之一的参展商来自中国。

8. 消息称北京上海等地暂停互联网金融公司注册：目前北京、上海以及深圳等地均暂停有关互联网金融公司的注册登记。据流传出来的北京方面通知规定：暂停核准跟互联网金融相关的企业和个体户名称。

**【信息安全】**

1. 小米全线下架360软件，称其强制装偷跑流量软件：小米方面称，雷电OS在用户不知情的情况下静默执行Root刷机行为，篡改MIUI系统签名，偷跑流量，甚至手机系统崩溃无法正常启动。

2. 入侵照明系统,黑客窃取信息的另一条途径: 人们现在开始意识到真正的危险；联网的照明系统可以成为入侵整个智能家居或楼宇自动化系统的一个入口。

3. NVIDIA GPU可能暴露用户浏览色情网站的历史画面。

4. 监听门后德美恢复网监合作：据新华社电德国媒体8日报道，德国联邦情报局与美国国家安全局恢复了网络监控合作。

5. 漏洞“黑市”：攻破新版Flash赏金10万美元。漏洞交易平台Zerodium近日在推特上宣布，愿意为攻破最新版Flash“堆隔离”特性的人员支付10万美金。这种内存防御机制可以让利用某些类型的安全漏洞更加困难，也意味着黑客最近几年用于注入恶意软件的手段不再管用。

6. 苹果iPhone自动弹iCloud登录窗?小心已被黑：苹果客服称近期不少126、163邮箱注册Apple ID的用户密码被篡改。

**【智能家居】**

1. Wi-Fi联盟宣布802.11ah HaLow技术连接标准：这个标准名称是HaLow。 HaLow标准的工作频率低于1GHz，提供更长的通讯范围和更低的功率，针对长距离低功耗应用需求，如智能家居，数字医疗保健，零售和汽车连接应用。

2. CES风向：智能家电将迎来爆发.为期三天的CES 2016国际消费电子展即将落下帷幕，作为一名家电、家居频道编辑，在看了三天的展会后深切的感受到了一点，那就是家电、家居产品线的智能化普及之路即将到来。

3. 福特亚马逊联手,将车变成智能家居的一部分: 福特在2016年的CES上表示，他们正在与亚马逊以及物联网平台Wink合作，开发新一代的高级用户体验技术，通过福特SYNC车载系统与亚马逊智能交互设备echo和智能助手Alexa的连接，实现家用智能设备和福特汽车的双向互联。

4. 华为“OpenLife智能家庭应用开发大赛”在深圳落幕：在本次大赛上,华为和超过20家智能家居品牌商等进行了合作,而参赛者在参赛产品中均集成或调用了华为智慧家庭的软件开发工具。
