# 汇能科技行业快讯

**10月12日，星期一，您好！汇能科技与您一起分享行业快报：**

**【科技】**

1.传微软砍掉Lumia：然后Surface Phone接班。据The Verge报道，微软最新发布的Lumia 950/950XL很有可能将会是Lumia系列产品的绝唱。

 

2.科技界最大规模并购：EMC戴尔或于本周达成协议。路透社援引消息人士的说法称，尽管美国数据存储巨头EMC最早将于本周一公布与戴尔的收购协议，但该公司也计划寻找其他可能的收购方。

 

3.清华紫光接近收购同方国芯：清华紫光董事长赵伟国昨日在采访中表示，该公司正在洽购一家本土芯片公司，不过没有透露目标公司的名称。

 

4.中兴史立荣：大数据将比土地更值钱。中兴正站在中国经济转轨的几个关键节点上——首先是中国将成为全球第一批建设5G的国家；其次，“智慧城市”将成为新一轮的信息化浪潮的核心驱动力；再次则是智能手机的全球竞赛正在迎来下半场。

 

5.欧盟或迫使谷歌放松Android应用捆绑政策:美国科技博客Venturebeat今天撰文称，欧盟对Android系统展开的全面调查可能迫使谷歌改变商业模式，迫使其放松应用捆绑政策。

 

6.首届华为开发者大会将于10月19日隆重开幕：10月19日-20日，华为将在深圳龙岗大运中心重磅打造首届开发者大会，与您共同探讨如何基于华为全面开放的ICT能力，共创无限商机！

 

7.神州数码落子互联网棋局,市值10年提升7倍:“分拆并不意味分销业务的完全剥离，而是要做全渠道、全商品，不仅仅是要做IT的商品。要进入新的领域，把互联网的渠道价值最大化。”郭为说。

 

5.马斯克：周四请升级软件，特斯拉马上有自动驾驶。特斯拉计划于本周四向全世界的Model S车主推出软件升级，提供自动驾驶功能。该功能不会带来真正的无人驾驶体验，但车辆可以自动沿着车道行驶，并在无需人工干预的情况下完成转向。

 

**【信息安全】**

1.奥巴马政府想开了：放弃获取公民加密信息。白宫上周六表示，美国总统奥巴马已经放弃一项计划，不再通过立法为美国执法机构赋予获取公民加密信息的权限。

 

2.习近平九论互联网：中国是黑客攻击的受害国。中国是网络安全的坚定维护者。中国也是黑客攻击的受害国。中国政府不会以任何形式参与、鼓励或支持任何人从事窃取商业秘密行为。

 

3.支付宝被指存漏洞回应：因用户个人信息泄露。支付宝官方在微博上回应称，是因为账户持有人存在自身身份证等个人隐私信息泄露，导致被关联认证。

 

4.黑客攻击Samsung Pay，可能追踪个人信息: 三星子公司LoopPay的安全漏洞可能已经被间谍用来收集消费者信息从而获利，三星近日已经承认LoopPay受到了攻击，但受影响的服务器已经被隔离，并没有危及个人信息。

 

5.二手手机销售受欢迎，数据被“复活”恐泄露隐私：业内人士提醒，出售旧手机时应提防删除的数据被“复活”，谨防个人照片、信息泄露。同时建议，市民选择手机时应以自己需求为主，尽量不要频换手机。

 

6.翼支付系统疑存隐患：频遭盗刷被投诉。近日，多位银行卡被盗刷受害者对《中国经营报》记者表示，在持卡人不知情的情况下，银行卡中的资金通过翼支付被盗刷，且翼支付无法查询到被盗刷资金去向。

 

**【智能家居】**

1.Netgear发布夜鹰X8 AC5300无线路由器，布局智能家居：10月10日，在北京马奈草地国际艺术中心静谧舒展的环境中，伴随着悠扬的钢琴声，美国网件开启了“2015路由新趋势发布暨NIGHTHAWK X8媒体鉴赏会”。

 

2.熊猫推阿里云电视，打造互联网+影娱生态：本月初，熊猫电视与世界互联网龙头企业阿里巴巴，强强联手，推出熊猫阿里云系列智能电视，首批推出的熊猫阿里云电视采用熊猫夏普UV2A技术的新一代A+优微屏。

 

3.苏宁沦为阿里的“搬运工” 张近东造吗？日前，苏宁交出了与阿里合体之后的第二份考卷。显然，相对于自己生造的“8.18”电商节，国庆黄金周的成绩并不能让苏宁满意，甚至还有了注水的嫌疑。

 

4.英唐智控布局智能家居、物联网:8月14日，英唐智控（300131，SZ）发布半年报，公司2015年上半年实现净利润375.79万元，同比增长47.67%；实现营收1.11亿元，同比下降45.99%，主要因为公司加强订单管理，继续深化产品差异化所致。

 

5.智能家居体验区亮相“环球资源电子展”：“环球资源电子展”昨日启幕，展会从即日起至21日分两期于香港亚洲国际博览馆举行，是全球规模最大的电子产品采购盛会。来自国内、韩国及亚洲其它国家的供应商将通过5800多个展位，展示市场热销的电子产品。
