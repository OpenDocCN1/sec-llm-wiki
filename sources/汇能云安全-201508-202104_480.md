# 汇能科技行业快讯

09月23日，星期三，您好！汇能科技与您一起分享行业快报：

【科技】

1.习大大抵达西雅图，当地Uber应用都开始欢迎了：西雅图用户在早晨打开打开Uber应用后，会跳出“欢迎习近平主席一行到访”中文、英文讯息。

 

2.Facebook已想好怎么创收：用聊天应用投广告。Facebook高管日前透露，该公司准备利用Messenger聊天服务创收，并透露了几种可能的创收模式。

 

3.云加速服务商CloudFlare获谷歌等1.1亿美元融资：CloudFlare 是一家提供网站加速、内容优化及防 DDoS 攻击防御的云安全初创企业，总部位于旧金山。

 

4.引领无线发展,华为助力开创移动宽带新未来：在中国国际信息通信展览会上，华为以“创新引领无线网络”为主题，展示4.5G(4G持续演进)、5G、室内覆盖数字化等领先技术。

 

5.比特币创业公司Circle首获数字货币许可证：Circle已从纽约州监管机构那里拿到了第一张数字货币许可证BitLicense，这意味着该公司将可在纽约州持证提供数字货币服务。

 

6.Groupon宣布全球裁员1100人 退出多国市场：美国团购网站Groupon周二宣布，作为重组计划的一部分，公司将在全球裁员约1100人。

 

7.小米进军虚拟运营商价格再成杀手锏：昨天，小米正式宣布启动虚拟运营商业务“小米移动”，发布“任我行”和“吃到饱”两种电话卡产品，从价格上看极具市场竞争力，低于三大运营商的同类套餐。

 

8.品友发布大数据管理平台多米诺：定位中小企业。昨日，继发布DSP平台“大算盘”后，品友互动在北京发布了跨屏数据管理平台“多米诺”，目标受众依旧是小企业。\[详细\]

 

【信息安全】

1.习近平：中国是网络安全的坚定维护者。国家主席习近平9月22日接受了美国《华尔街日报》书面采访，习近平强调，中国是网络安全的坚定维护者。中国是黑客攻击的受害国。

 

2.游戏开发引擎被曝染毒，原理与之前苹果App类似：国内越狱团队盘古今日凌晨在微博上爆出，一些游戏开发引擎下载地址也被感染病毒，如例如Unity和Cocos2d-x。

 

3.西数My Cloud个人云存储硬盘被曝含严重安全漏洞：来自VerSprite的安全研究人员近日监测到西数My Cloud个人云存储硬盘设备包含两个安全漏洞，允许使用某个版本Debian Linux的攻击者通过一个Web访问UI和一个RESTful API与硬盘发生联系，从而会给不法分子提供两种攻击方式：通过命令注入，或是通过跨站请求伪造（CSRF）攻击漏洞。

 

4.Flash再补23处漏洞，近半数漏洞由中国安全专家发现：9月21日，全球软件巨头Adobe公司发布安全更新，一举修复了Adobe Flash Player中的23处安全漏洞。Adobe官网同时发布公告，向发现这些漏洞的安全研究人员公开致谢，来自中国的安全专家共获得9个漏洞致谢，分别是360获得4个漏洞致谢、阿里巴巴获得3个漏洞致谢，腾讯和KeenTeam各获得1个漏洞致谢。

 

5.D-link意外泄漏私有代码签名密钥：网络设备制造商D-Link在发布的开源固件包中发现了他们对软件进行签名所使用的私钥。黑客可以用这个密钥对恶意软件进行签名，使它更容易执行攻击。

 

【智能家居】

1.华为发布智能家居战略：将成未来主战略之一。在昨日举办的2015 WiFi联盟智能家居峰会上，华为消费者业务首席战略官邵洋正式对外发布了华为的智能家居战略。

 

2.小米发布虚拟运营商，离智能家居又近一步：在9月22日举行的小米4C媒体沟通会上，雷军“意外”地正式发布了小米虚拟运营商业务——小米移动。

 

3.智能卫浴镜或将成为您的“家庭医生”：当卫浴镜不再只是一面镜子，你会对它有哪些期待？在智能家居的风浪之下，卫浴镜不仅能变身“摄影师”、“化妆师”，更能对人的身体状况进行综合评估，守护家人健康。

 

4.创维数字携智能家居整体解决方案亮相2015IBC：近期，第四十八届荷兰广播电视设备展览会(IBC)在荷兰阿姆斯特丹举行，作为智能家居解决方案的全球供应商，创维数字在IBC上，结合最新的科技与市场走势，创维数字重点展出了支持超高清、集社交、多屏汇聚、家庭物联网及多屏互动等功能于一体的智能机顶盒产品，基于此，全面展示了公司构造的智能家居生活。

 

5.格力或携手航天科工，将航天技术推广到智能家居：中央财经大学财经研究所中国企业研究中心主任刘姝威演讲时披露，她此行来珠海与格力电器董事长董明珠讨论了格力如何与航天科工集团合作，实现航天技术向民用企业转移。

 

6.邓超入职长虹、李健牵手微鲸，明星合伙人盛行：长虹官博今日称邓超将出任长虹CHiQ产品经理一职，参与CHiQ产品的设计与研发，明星跨行进入智能家居行业的举动顿时引起了热议。
