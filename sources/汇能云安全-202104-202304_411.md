**伊朗黑****客以几个以色列组织为目标进行供应链攻击**

以色列的IT和通信公司是伊朗威胁行为者带头的供应链攻击行动的中心，该行动涉及冒充公司及其人力资源人员，以虚假工作机会攻击受害者，企图侵入他们的电脑并接触该公司的客户。对手的感染始于识别潜在受害者，然后通过冒充冒充公司的人力资源部门员工，诱使 ChipPc 和软件股份公司等知名公司提供"诱人"的工作机会，结果将受害者引向一个包含武器化文件的网络钓鱼网站，该网站卸载了称为 Milan 的后门，以便与远程服务器建立连接并下载名为 DanBot 的第二阶段远程访问特洛伊木马程序。除了使用诱饵文档作为初始攻击媒介外，该组织的基础设施还包括建立欺诈网站以模仿被冒充的公司，以及在LinkedIn上创建虚假的个人资料。诱饵文件则采用宏嵌入式 Excel 电子表格的形式，其中详细说明了所谓的工作机会和便携式可执行 （PE） 文件，其中包括冒充组织使用的产品的"目录"。无论受害者下载的文件如何，攻击链最终都安装在位于C++的米兰后门。

  

**FBI警告对食品杂货和食品配送服务的凭据填充攻击**

FBI说，黑客利用凭据填充攻击来劫持杂货店、餐馆和食品配送服务的在线帐户，以便通过欺诈性订单耗尽用户资金，并窃取个人或财务数据。这一警告是通过FBI私人行业通知发出的，该机构的网络部门上周向美国食品和农业部门的公司发出了通知。该机构表示，网络犯罪集团正在利用通过其他公司违规获得的用户名和密码组合登录杂货店和食品配送服务的客户帐户，希望用户能够跨账户重复使用密码。这些入侵称为凭据填充攻击，通常使用自动工具和代理僵尸网络进行，以便将攻击传播到大量 IP 地址并伪装攻击者的位置。

  

************美国人口普查局使用 Citrix 漏洞入侵************

美国人口普查局（OIG）在一份报告中披露，美国人口普查局的服务器在利用未修补的Citrix ADC零日漏洞后被黑客入侵。"这些服务器的目的是为局提供远程访问功能，使其企业员工能够访问生产、开发和实验室网络。据系统人员说，这些服务器没有提供普查网络的访问，"OIG说。"在对远程访问服务器的攻击期间，该局的防火墙早就阻止了攻击者从远程访问服务器通信到其指挥和控制基础设施的尝试。但是，直到2周后，该局才知道服务器遭到破坏。虽然攻击者能够破坏局的服务器并设置流氓管理员帐户，使他们能够远程执行恶意代码，但他们无法部署后门来维护对服务器的访问并实现他们的目标。据OIG称，该局未能缓解攻击中利用的关键漏洞，使其服务器处于脆弱状态。在他们的服务器被破坏后，该局也没有及时发现和报告攻击。它还没有保持足够的系统日志，妨碍了事件调查。  

**日本保险公司 Tokio 海洋披露勒索软件攻击**

日本跨国保险控股公司东芝海洋控股公司本周宣布，其新加坡分公司——新加坡东九海洋保险（TMiS）遭受了勒索软件攻击。公告是在本周初宣布的，除了为处理入侵事件而采取的行动之外，几乎没有关于这一事件的信息。作为日本最大的（收入）财产和意外伤害保险集团，Tokio海洋控股公司是网络罪犯的诱人目标，他们可以利用漏洞来寻找和损害该组织的客户。Tokio 海事公司指出，勒索软件攻击影响了新加坡 Tokio 海事保险公司，集团在该国的其他公司没有受到任何损害。目前还不清楚攻击是如何或何时发生的，以及袭击造成的破坏，但TMIS在发现网络并通知当地政府机构后立即将其隔离。如今，大多数勒索软件攻击也被视为数据泄露事件，因为攻击者在加密文件之前还会从受害者网络窃取文件。但是，已引入第三方来分析系统并评估攻击的影响。该公司在其网站上以日文和英文披露了这一事件，并就由此造成的任何"不便和担忧"向客户道歉。

  

**微软入股鲁布里克打击勒索软件**

微软已经向云数据管理公司 Rubrik 投资了一笔未披露的金额，作为联合开发基于 Azure 云的零信托产品的计划的一部分。据鲁布里克说，鲁布里克和微软计划在Azure上提供微软365、数据保护和云服务。据彭博社消息人士透露，微软的投资"低至数千万美元"，价值约40亿美元。该公司与戴尔 EMC、Commvault 和其他存储和备份公司竞争，2019 年价值为 33 亿美元。Rubrik 提供 Azure、AWS、谷歌云和微软 365 的云备份和恢复服务，以及勒索软件恢复服务。Microsoft 在继续推动组织采用零信任架构的同时进行了投资，该架构较少注重加强网络周界，旨在保护工作和家庭中使用的 BYOD 设备和应用程序。该合作伙伴关系还将帮助客户继续数字化转型项目，并将更多数据推至云中。Rubrik 表示，它与微软云的结合将允许客户保护关键应用程序，如 SAP、SQL、甲骨文和 VMware，以及带有 Azure 的网络连接存储 （NAS） 设备。

  

**思科：安全设备易受 SNIcat 数据渗透技术的影响**

在周三发布的安全公告中，思科表示，由于设备已达到报废状态，因此不会修补多个小型企业 VPN 路由器的通用即插即用 （UPnP） 服务中的严重漏洞。零日错误（跟踪为 CVE-2021-34730，评分为9.8/10 严重性评分）是由对传入的 UPnP 流量进行不当验证造成的，由物联网检查员研究实验室的昆汀·凯撒报告。未经授权的攻击者可以利用它重新启动易受攻击的设备或远程执行任意代码，作为基础操作系统上的根本用户。该公司表示："思科尚未发布，也不会发布软件更新，以解决本公告中描述的漏洞。"思科小型企业 RV110W、RV130、RV130W 和 RV215W 路由器已进入报废过程。

  

**福特汽车专有数据或被泄露**

近日，福特汽车被曝存在一个较为严重的安全漏洞，黑客可通过该漏洞访问其配置错误的Pega Infinity系统，从而获取包括客户数据库、员工记录、内部票证等在内的专有数据信息。黑客还可以借此执行账户接管操作。该漏洞由Robert Willis 和 break3r发现， 并得到了Sakura Samurai组织成员Aubrey Cottle、Jackson Henry和John Jackson的进一步验证和支持 。该问题是由CVE-2021-27653漏洞引起的，它是一个信息泄露漏洞，存在于福特公司配置不当的Pega Infinity客户管理系统中。耗时六个月才被披露早在2021年2月，研究人员就向Pega报告了他们的发现，并尽快地修复了聊天门户中的CVE漏洞。大约在同一时间，这个问题也通过他们的HackerOne漏洞披露计划报告给了福特研究人员等待了六个月后才得到了该漏洞的披露详情。目前，福特的漏洞披露计划不提供金钱激励或漏洞奖励，因此根据公共利益进行协调披露是研究人员希望的唯一“奖励”。目前，福特并没有对本次事件的特定安全相关行为发表评论。虽然福特宣称在接到报告后24小时内关闭了端点，但研究人员指出，他们在福特宣称关闭了端点之后发现此端点仍可访问，并要求福特再次审查并采取缓解措施。

  

**微软365：这个新的一键按钮让企业报告诈骗电子邮件**

微软 365/Office 365 帐户和 Outlook 的新按钮和附加组件允许员工直接向英国国家网络安全中心（NCSC）报告诈骗电子邮件。该按钮是对 NCSC 现有的可疑电子邮件报告服务（SERS）的升级，虽然电子邮件过滤系统可以阻止一些网络钓鱼攻击到达员工收件箱，但骗子总是在寻找绕过过滤器的方法，例如，通过在 Google 云服务上托管诈骗、创建 Office 365 网络钓鱼页面或破坏 SharePoint 网站来诱使受害者输入其工作帐户凭据。NCSC 处理的"典型"网络钓鱼网格包括诱骗员工单击在工作计算机上下载恶意软件的链接、创建克隆登录页面，以及发送有关工作软件（如 Microsoft Teams）的虚假警报的电子邮件。NCSC技术总监伊恩·利维（Ian Levy）表示："大流行期间的机会性骗局已经证明，网络罪犯如何不断找到新的方法来攻击我们。好消息是，您可以通过单击按钮将可疑的诈骗电子邮件从工作电子邮件帐户转发到可疑电子邮件报告服务（SERS）来帮助保护工作场所。  

**安卓恶意软件FlyTrap影响恶劣**

安全公司Zimperium的报告指出，自3月以来，一个名为FlyTrap的新型Android木马已经通过社交媒体劫持、第三方应用程序商店进行广泛传播。攻击了一百多个国家/地区的10,000多名受害者。虽然谷歌验证并从商店中删除了所有相关恶意应用程序，但目前仍有三个恶意软件可在第三方、不安全的应用程序商店中下载到。  

****************《弈剑行》手游开服遭黑客攻击改为单机版****************

近日，TapTap上一款名为《弈剑行》的手游发布公告，称游戏开服便遭到黑客攻击，导致战斗服务器全部瘫痪，面对黑客这种恶意攻击，《弈剑行》用“宁为玉碎，不为瓦全”8个字表达自己的决心，甚至直接将游戏从联机版改为单机版。据《弈剑行》官方透露，在游戏刚正式开服便遭到黑客攻击，因为服务器加强了防御，于是抵挡住了第一波攻击，没想到的是在开服后不到24小时，黑客再次针对防御薄弱的对战服务器，由于技术难点没法立即解决这个问题，于是直接选择暂时停服，来调整服务器设定。
