**8月2日，星期一，您好！中科汇能与您分享信息安全快讯：**

  

**********CVE-2021-34481：Windows Print Spooler再爆安全漏洞**********

Windows Print Spooler再爆安全漏洞，为近期发现的第3个安全漏洞。近日，研究人员又在Windows Print Spooler中发现一个本地权限提升漏洞。近日，微软发布安全公告称，发现一个影响Windows Print Spooler服务的安全漏洞，漏洞CVE编号为CVE-2021-34481，CVSS评分为7.8分。该漏洞是一个本地权限提升漏洞，攻击者利用该漏洞可以在系统中执行未授权的行为。攻击者成功利用该漏洞可以以system权限执行任意代码。然后攻击者可以安装程序、查看、修改和删除数据，或创建具有完全用户权限的新账户。要利用该漏洞，攻击者必须具有受害者系统中的代码执行权限。也就是说，该漏洞可以本地利用来获取设备上的提升权限。  
  
**********黑客利用最多的30个关键安全漏洞**********

澳大利亚、英国和美国的情报机构近日发布了一份联合通报，详细说明了2020年和2021年被利用最多的漏洞，再次表明威胁行为者如何能够迅速将公开披露的缺陷武器化，以利于他们。美国网络安全和基础设施安全局（CISA）、澳大利亚网络安全中心（ACSC）、英国国家网络安全中心（NCSC）和美国联邦调查局（FBI）指出："网络行为者继续利用众所周知的、而且经常过时的软件漏洞，攻击全球广泛的目标集，包括公共和私营部门组织。但是，世界各地的实体可以通过将可用的修补程序应用到其系统并实施集中补丁管理系统来缓解本报告中列出的漏洞。前 30 个漏洞涵盖广泛的软件，包括远程工作、虚拟专用网络 （VPN） 和基于云的技术，涵盖来自微软、VMware、脉冲安全、福蒂尼特、Accellion、Citrix、F5 大 IP、阿特拉斯和德鲁帕尔等众多产品。  

  
**********新的安卓恶意软件使用 VNC 从受害者那里窥探和窃取密码**********以前没有记录的基于 Android 的远程访问特洛伊木马 （RAT） 被发现使用屏幕录制功能窃取设备上的敏感信息，包括银行凭据，并为设备欺诈打开大门。移动恶意软件被称为"Vultur"，因为它使用虚拟网络计算（VNC）的远程屏幕共享技术，以获得目标用户的完全可见性，移动恶意软件通过官方的谷歌Play商店分发，并伪装成名为"保护卫士"的应用程序，吸引了超过5000个安装。来自意大利、澳大利亚和西班牙实体的银行和加密钱包应用程序是主要目标。近日发表的一份报告中，意大利网络安全公司Cleafy发现了UBEL，这是Oscorp的最新变种，它使用WebRTC与受损的Android手机进行实时交互。Vultur 采用了类似的策略，因为它利用辅助功能权限捕获击键，并利用 VNC 的屏幕录制功能秘密记录手机上的所有活动，从而避免了注册新设备的需要，使银行难以发现欺诈行为。更重要的是，恶意软件使用 ngrok，一个跨平台的实用程序，用于通过安全隧道将 NAT 和防火墙后面的本地服务器暴露在公共互联网上，以便远程访问在手机上本地运行的 VNC 服务器。此外，它还与命令和控制 （C2） 服务器建立连接，通过 Firebase 云消息（FCM）接收命令，其结果（包括提取的数据和屏幕捕获）然后传回服务器。  
**********语音呼叫中心诱骗用户安装勒索软件和数据窃取器**********一个持续的恶意活动，使用虚假呼叫中心被发现欺骗受害者下载恶意软件能够数据渗透，以及部署勒索软件在受感染的系统上。这些攻击被称为"BazaCall"——避开了传统的社会工程技术，这些技术依赖于流氓网址和恶意软件带状文档，而采用类似振动的方法，即向目标用户发送电子邮件，告知他们即将收取订阅费，除非他们拨打特定电话号码。通过诱骗收件人拨打该号码，不知情的受害者与欺诈呼叫中心的实际人工接线员有联系，后者随后向他们提供下载 BazaLoader 恶意软件的说明。BazaLoader（又名巴扎后门）是一个基于C++的下载器，能够在受感染的计算机上安装各种类型的恶意程序，包括部署勒索软件和其他恶意软件从受害系统窃取敏感数据。BazaLoader 活动于 2020 年 4 月首次发现，已被多个威胁行为者使用，并经常充当 Ryuk 和 Conti 勒索软件等破坏性恶意软件的加载器。  
**********破坏商业电子邮件泄露 （BEC） 攻击的最佳实践**********商业电子邮件泄露 （BEC） 是指没有有效载荷的所有类型的电子邮件攻击。虽然类型众多，但攻击者基本上有两种主要机制，通过这些机制，攻击者利用 BEC 技术渗透组织、欺骗和帐户接管攻击。在最近的一项研究中，71%的组织承认他们在过去一年里看到了商业电子邮件泄露（BEC）攻击。在过去 12 个月中，43% 的组织经历了安全事件，35% 的组织表示 BEC/网络钓鱼攻击占事件的 50% 以上。FBI的互联网犯罪投诉中心（IC3）报告说，BEC诈骗是2020年网络攻击中最昂贵的，有19，369起投诉和调整后的损失约18亿美元。最近的贝克攻击包括欺骗攻击鲨鱼坦克主持人芭芭拉·科科兰，谁失去了38万美元：波多黎各政府的攻击金额达400万美元，日本媒体巨头日经指数（Nikkei）根据一封欺诈性电子邮件中的指示转移了2900万美元。要阻止 BEC 攻击，组织必须关注金三角：人员、流程和技术的对齐。继续阅读，了解每个组织应遵循的最佳实践，以减轻 BEC 攻击。  
**********专家发现几个与威尔梅斯恶意软件相关的 C&C 服务器**********网络安全研究人员上周五揭开了属于俄罗斯威胁行为者APT29（又名"舒适熊"）的新型指挥控制（C2）基础设施的面纱。微软旗下的网络安全子公司RisqIQ在与《黑客新闻》分享的一份报告中说，俄罗斯外国情报机构运营的30多台C2服务器被发现。APT29是俄罗斯对外情报局（SVR）政府特工的绰号，据信是去年年底曝光的大规模太阳风供应链袭击的幕后主谋，今年4月初，英国和美国政府正式将入侵归咎于俄罗斯。网络安全界正在以各种代号跟踪该活动，包括 UNC2452 （FireEye）、Nobelium （微软）、太阳风暴 （单元 42）、恒星粒子 （人群条纹）、暗光环 （Volexity） 和铁仪式 （安全工程），理由是对手使用的战术、技术和程序 （TTP） 与已知攻击者配置文件 （APT29） 的不同。WellMess（又名 WellMail）于 2018 年首次被日本JPCERT/CC认定，此前曾被部署在威胁行为者进行的间谍活动中，以掠夺参与英国、美国和加拿大 COVID-19 研究和疫苗开发的多个组织的知识产权。  
************针对伊朗铁路瘫痪的网络攻击真相来了************

本月早些时候，一场网络攻击使伊朗交通部及其国家铁路系统的网站脱轨，导致火车服务大面积中断，这是一种前所未有的可重复使用的雨刷器恶意软件"Meteor"的结果。据伊朗防病毒公司Amn Pardaz和SenitinelOne的研究人员称，这场名为"MeteorExpress"的运动与任何先前确定的威胁集团或其他攻击都没有关联，因此这是第一起涉及部署这种恶意软件的事件。流星据信在过去三年中一直在工作。伊朗火车系统在一次重大袭击后陷入瘫痪，黑客们玷污了电子显示屏，指示乘客将投诉直接指向伊朗最高领袖哈梅内伊办公室的电话号码。据报道，这一事件在车站造成了"前所未有的混乱"，数百列火车延误或取消。现在，根据 SentinelOne 的说法，感染链始于滥用集团策略，部署了一个工具包，该工具包由编排不同组件的批次文件组合而成，这些组件从多个 RAR 档案中提取并链接在一起，以方便文件系统的加密、主启动记录（MBR）的损坏以及有关系统的锁定。在攻击期间丢弃的其他批次脚本文件被发现负责断开受感染设备与网络的连接，并为所有组件创建 Windows 防御程序排除，这种策略在威胁参与者中越来越普遍，以隐藏其恶意活动，防止安装在计算机上的反恶意软件解决方案。  

  

**********黑客利用微软浏览器错误在目标 PC 上部署 VBA 恶意软件**********一个身份不明的威胁行为者一直在利用互联网浏览器中一个现已修补的零日缺陷来提供功能齐全的基于 VBA 的远程访问特洛伊木马 （RAT），该特洛伊木马程序能够访问存储在受攻击的 Windows 系统中的文件，并下载和执行恶意有效载荷，作为"异常"活动的一部分。后门通过名为"清单.docx"的诱饵文档分发，该文档从嵌入式模板中加载漏洞的漏洞漏洞代码，而根据网络安全公司恶意软件字节，该模板又执行外壳代码来部署 RAT，该文件近日发现了可疑的 Word 文件。这份带有恶意软件的文件声称是"克里米亚居民宣言"，呼吁公民反对俄罗斯总统弗拉基米尔·普京，"建立一个名为'人民抵抗'的统一纲领"。互联网浏览器缺陷，跟踪为CVE-2021-26411，是值得注意的事实，它被滥用于朝鲜支持的拉撒路集团的目标安全研究人员从事漏洞研究和开发。互联网浏览器漏洞利用是用于部署 RAT 的两种方法之一，另一种方法依赖于一个社会工程组件，该组件涉及下载和执行包含植入物的远程宏武器模板。无论感染链如何，使用双攻击载体都可能试图增加找到进入目标机器的路径的可能性。  
**********AvosLocker团伙入侵Coghlin 电气承包商**********AvosLocker团伙在其位于暗网的数据泄露站点公布入侵了Coghlin 电气承包商，在文中团伙表示已经锁定其网络并且获取了员工和首席执行官苏珊·玛丽的数据文件，包括财务文件、发票、银行对账单、护照扫描和国税局税单。  

  
**********Marketo团伙入侵了实时广告平台ReklamStore**********Marketo团伙在其位于暗网的数据泄露站点公布入侵了ReklamStore，据悉ReklamStore是一个实时广告平台。该公司与全球150家广告商合作。该公司在其网站上的描述称为广告商和出版商提供控制和保护措施，防止非法bot活动、历史上的欺骗性url或特定页面级别的欺诈。
