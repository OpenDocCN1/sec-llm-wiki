******************************Zimbra 软件曝新漏洞，发送恶意邮件即可劫持Zimbra 服务器******************************

网络安全研究员在 Zimbra 邮件协作软件中发现了多个软件漏洞，攻击者可通过发送恶意消息攻陷邮件账户，甚至完全控制托管在云基础设施上邮件服务器。这些缺陷是CVE-2021-35208和CVE-2021-35209位于Zimbra 8.8.15版本中，缓解措施已于 Zimbra 版本8.8.15 Patch 23 和 9.0.0 Patch 16 中发布。CVE-2021-35208 的CVSS 评分为5.4，是位于 ZmMailMsgView.java 中的存储型 XSS 漏洞；CVE-2021-35209 的CVSS 评分为6.1，是一个代理伺服小程序的开放重定向漏洞。未认证攻击者可组合利用这些漏洞攻陷目标组织机构的完整的 Zimbra webmail 服务器，导致攻击者获得对所有员工所发送和接受邮件的无限制访问权限。

  

******新加坡政府漏洞奖励计划年度总结：半数上报漏洞真实有效******

据新加坡智能国家与数字政府办公室（SNDGO）近日发布的年度报告显示，新加坡政府通过漏洞奖励和公开披露计划收到的安全漏洞报告中，有一半已被确认为有效。此外，公共部门过去一年记录在案的数据安全事件也增长了44%，但没有“高严重性”事件。在截止于今年3月31日的2020财年内，新加坡政府共报告108起数据安全事件，远超上一财年的75起。尽管事件数量有所增加，但各违规活动的严重程度均为为低级或中级。安全漏洞的严重程度主要取决于事件对国家安全、国家利益、个人或企业实体的具体影响，由低到非常严重共分为五个等级。报告还指出，所有上报数据安全事件均在48小时内得到解决。漏洞奖励计划卓有成效新加坡于2020年4月成立了政府数据安全联络中心，希望为公众提供上报渠道、随时告知涉及政府数据或政府机构的安全事件。  

  

********************************三大热门开源软件曝出漏洞，或影响数千企业********************************  

日前三大热门开源项目——EspoCRM、Pimcore和Akaunting被曝存在九个安全漏洞。研究人员指出：“这三个项目已被广泛应用于数千家企业用户，是支持其服务和云托管工作的核心应用程序。如果这些漏洞被攻击者成功利用，可能会为更复杂的攻击提供途径。”诺基亚和Trevor的技术人员Wiktor Sędkowski表示，这些漏洞会影响EspoCRM v6.1.6、Pimcore客户数据框架v3.0.0、Pimcore AdminBundle v6.8.0和Akaunting v2.1.12，但已在相关漏洞披露后的一天内进行了修复处理。EspoCRM是一个开源的客户关系管理(CRM) 应用程序，而Pimcore是一个用于客户数据管理、数字资产管理、内容管理和数字商务的开源企业软件平台。另一方面，Akaunting是一款开源在线会计软件，专为发票和费用跟踪而设计。

  

********************************第二季度云交付攻击恶意软件增加了68%********************************

根据网络安全公司Netskope最新发布的云威胁报告，今年第二季度通过云交付进行攻击的恶意软件增加了68%，云存储应用程序占云恶意软件交付的66%以上。在2021年第二季度，所有恶意软件下载中有43%是恶意Office文档，而2020年初这一比例仅为20%。即使在Emotet下架之后，这种增长仍然存在，这表明其他攻击者发现了Emotet使用者的攻击手段并采用了类似的技术。协作应用程序和开发工具占第二大比例，因为攻击者滥用流行的聊天应用程序和代码存储库来传播恶意软件。在2021年上半年，Netskope总共检测到并阻止了来自290个不同云应用程序的恶意软件下载。  

********************************二季度勒索软件受害者增长47%********************************

网络安全公司Digital Shadows近日跟踪分析31个网络泄漏站点信息后发布了一份新的勒索软件研究报告。该报告的数据显示，超过700家企业在2021年第二季度遭到勒索软件攻击，攻击者还将这些数据发布到了数据泄漏站点上。在勒索软件数据泄漏网站上列出的近2,600名受害者中，有740人在2021年第二季度被点名，与第一季度相比增加了47%。该报告记录了本季度的主要勒索软件攻击事件，其中包括DarkSide对燃油输送管道Colonial Pipeline的攻击、对全球肉类加工商JBS的攻击。Digital Shadows的Photon研究团队发现，继Maze勒索软件组织普及了数据泄漏站点的概念后，双重勒索策略在勒索软件攻击中变得流行起来。

  

********************苹果修复WiFi断连漏洞********************

苹果公司本周开始为iOS、macOS、iPadOS、watchOS、tvOS和Safari推出安全更新，以解决数十个漏洞，其中包括一些可能导致任意代码执行的漏洞随着iOS 14.7和iPadOS 14.7的发布，苹果共解决了37个安全漏洞，其中包括最近一个安全业界引发热议的WiFi安全漏洞，攻击者可以利用该漏洞使易受攻击设备的Wi-Fi功能瘫痪，无法再接入WiFi热点。该安全漏洞被追踪为CVE-2021-30800，可以通过创建具有特定名称的恶意Wi-Fi接入点来利用。这些使用特殊字符的定制SSID名称会被部分苹果设备视为命令进行处理，从而使设备的Wi-Fi连接功能瘫痪。Apple已经增发了一个补丁，以防止iOS 14.4中的代码执行。但是，该漏洞仍然可以被利用来使运行iOS 14.0到iOS 14.6设备上的Wi-Fi崩溃。iOS最新版本解决的其他严重漏洞还包括CVE-2021-30774（Crash Reporter中的逻辑问题）和CVE-2021-30780（CVMS中的越界写入），这两个漏洞都可能被恶意应用程序利用获得root权限。

  

********************黑客冒充有氧运动教练多年瞄准航空航天员工********************

一个伊朗网络间谍组织在Facebook上伪装成有氧运动教练，试图用恶意软件感染航空航天国防承包商雇员的机器，作为长达数年的社会工程和有针对性的恶意软件运动的一部分。企业安全公司证明点将秘密行动归因于一个国家对齐的威胁行为者，它跟踪TA456，以及更广泛的网络安全社区的名字龟壳和帝国小猫。"利用社交媒体角色'马塞拉弗洛雷斯'，TA456与航空航天国防承包商的一家小型子公司的员工建立了跨公司和个人沟通平台的关系，"证明点在与黑客新闻分享的一份报告中说。2021 年 6 月初，威胁行为者试图通过持续的电子邮件通信链发送目标恶意软件来利用这种关系。Facebook透露，它已采取措施，拆除了由龟壳黑客发起的"复杂"网络间谍活动，该网络利用其平台上广泛的虚假在线角色网络，针对美国、英国和欧洲国防和航空航天领域的约200名军人员和公司。据信，这名威胁行为者通过与伊朗IT公司马哈克·拉扬·阿夫拉兹（MRA）的联系，与伊斯兰革命卫队（IRGC）松散结盟。TA456威胁行为人创建的这种精心制作的假角色，参与与未命名的航空航天员工的反复交流，可追溯到2019年，最后交付了名为LEMPO的恶意软件，旨在建立持久性，执行侦察和泄露敏感信息。感染链是通过包含 OneDrive URL 的电子邮件触发的，该 URL 自称是饮食调查（一个宏嵌入的 Excel 文档），但仅通过连接到攻击者控制的域域悄悄地检索了侦察工具。Facebook已经暂停了弗洛雷斯帐户从其平台，在协调删除与伊朗黑客活动相关的用户。

  

********************如何缓解微软视窗 10， 11 严重SAM 漏洞********************

微软视窗 10 和 Windows 11 用户面临最近公开披露的新未修补漏洞的风险。正如我们上周所报道的，这个漏洞——严重SAM——允许具有低级别权限的攻击者访问Windows系统文件来执行"通过哈希"（以及潜在的银票）攻击。攻击者可以利用此漏洞获取存储在安全帐户经理 （SAM） 和注册处中的哈希密码，并最终使用系统权限运行任意代码。严重SAM漏洞，跟踪为CVE-2021-36934，存在于Windows 10和Windows 11的默认配置中，特别是由于允许"读取"权限的设置，内置用户组包含所有本地用户。因此，内置的本地用户可以访问阅读 SAM 文件和注册表，在那里他们还可以查看哈希。一旦攻击者获得"用户"访问权限，他们可以使用 Mimikatz 等工具访问注册处或 SAM、窃取哈希并将它们转换为密码。以这种方式入侵域用户将给攻击者在网络上提升特权。由于 Microsoft 尚未提供官方补丁，因此保护您的环境免受严重SAM漏洞的最佳方法是实施强化措施。

  

****************************【安全风险通告】Oracle Weblogic Server远程代码执行漏洞安全风险通告****************************

Oracle WebLogic产品中存在安全漏洞，漏洞编号CVE-2021-2394，受此漏洞影响的版本包括10.3.6.0.0, 12.1.3.0.0, 12.2.1.3.0, 12.2.1.4.0, 14.1.1.0.0，未经身份验证的攻击者可以通过IIOP、T3网络访问WebLogic Server利用此漏洞，成功利用此漏洞的攻击者可以接管当前Oracle WebLogic Server。鉴于危害较大，建议用户及时安装更新Oracle官方于2021年七月份发布的修复补丁。

  

******************UBEL是新的Oscorp-安卓凭据窃取恶意软件活跃在野外******************  

一个Android恶意软件被观察到滥用设备中的辅助服务来劫持欧洲银行应用程序的用户凭据，作为2021年5月开始的新活动的一部分，它已演变成一个全新的僵尸网络。意大利CERT-AGID在1月下旬披露了Oscorp的细节，这是一种移动恶意软件，旨在攻击多个金融目标，目的是从毫无戒备的受害者那里窃取资金。其功能包括能够拦截短信和打电话，并通过使用类似登录屏幕来虹吸有价值的数据，对 150 多个移动应用程序执行覆盖攻击。恶意软件通过恶意短信进行分发，攻击通常通过冒充银行运营商实时进行，通过电话欺骗目标，并通过 WebRTC 协议秘密访问受感染的设备，并最终进行未经授权的银行转账。虽然自那时以来没有新的活动报告，但似乎Oscorp可能以称为UBEL的Android僵尸网络的形式暂时中断后进行了回归。一旦下载到设备上，恶意软件就会尝试将自己安装为服务，并将其存在隐藏在目标之外，从而实现长时间的持久性有趣的是，使用 WebRTC 与受破坏的 Android 手机进行实时交互，无需注册新设备并接管帐户以执行欺诈活动。
