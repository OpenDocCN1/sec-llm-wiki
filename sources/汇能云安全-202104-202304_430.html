Xloader恶意软件开始针对Mac用户

在过去的六个月里，Formbook的新版本（XLoader）一直是最“忙碌”的恶意软件之一，被不法分子频繁地用于攻击Window用户，而且与Formbook相比，Xloader增加了一个令人不安的功能：可以攻击Mac用户。XLoader许可证起价为49美元，这个价格使得即使是最缺乏经验和资金不足的网络攻击者也能获得一种用来获取登录凭据、收集屏幕截图、记录击键和执行恶意文件的高效攻击工具。Check Point跟踪了来自69个国家黑客的XLoader请求。发现大多数目标（53%）都在美国，包括Mac和Windows用户。


知名音频社交应用Clubhouse疑似泄露38亿电话号码

之所以出现如此大的数字，是因为 Clubhouse 讨论应用程序据称秘密地实时同步了所有用户的联系人。一旦在智能手机的通讯录中输入了新的电话号码，它也会被添加到会所数据库中。因此，Clubhouse 有许多从未安装过该应用程序或不知道该应用程序的人的电话号码。Clubhouse 声称拥有超过1000 万用户——远少于泄露的 38 亿电话号码。在欧盟，通用数据保护条例 (GDPR) 禁止收集不使用该服务的个人数据。如果泄漏中的数据是真实的，欧盟将不得不进行干预并追究会所的责任。


关于Windows Print Spooler远程代码执行0day漏洞
近日，一名安全研究人员意外发现了一个名为PrintNightmare的0day漏洞，利用此漏洞，黑客可以在补丁完善的Windows Print Spooler设备上获得完整的远程代码执行能力，此漏洞被微软追踪为CVE-2021-34527。微软发布的安全累积更新中修复了一个类似的Print Spooler漏洞。但是对于已经打过补丁的Windows Server 2019设备，PrintNightmare漏洞依然有效，并允许攻击者远程执行代码。此漏洞如此危险的原因在于，它会影响所有当前版本的Windows，并允许威胁行为者获得对网络的有限访问权限，同时立即在易受攻击的设备上获得SYSTEM权限。使用此访问权限，威胁参与者可以通过网络横向传播，直到他们获得对域控制器的访问权限。

艾叶豹组织：针对巴基斯坦用户的监控活动披露

2021年7月，奇安信病毒响应中心移动安全团队关注到自2020年11月起至今，一个未知的APT组织针对巴基斯坦用户展开了有组织、有计划、针对性的长期监控活动。该组织一般利用钓鱼网站进行载荷投递。其攻击平台主要为Android，攻击目标主要锁定为巴基斯坦用户及巴基斯坦TLP政党。截止目前我们一共捕获到Android平台攻击样本15个，涉及的C&C有2个。目前我们并未有直接的发现指向攻击组织身份，且在已知的APT组织中均未发现到有和该组织出现重叠。故我们选取了主要受害国家国兽（捻角山羊）的其中一种天敌动物名字，按照我们内部的命名规则将该攻击组织归属命名为------艾叶豹组织（Snow leopard）。


Windows 新漏洞可被用于强制服务器以攻击者身份认证，官方缓解措施已发布

法国安全研究员 Gilles Lionel 在 Windows 操作系统中发现一个新的安全缺陷，可被用于强制远程 Windows 服务器以攻击者身份认证并共享 NTLM 认证详情或认证证书。Lionel 将该攻击命名为 “PetitPotam”，已在 GitHub 发布 PoC 代码。Lionel 指出，当攻击者滥用 MS-EFSRPC 协议时就会触发该漏洞。该漏洞可导致 Windows 机器对存储在远程系统上的加密数据执行各种操作。PetitPotam 攻击的 PoC 代码可使攻击者将 SMB 请求发送至远程系统的 MS-EFSRPC 界面并强制受害者计算机发起认证程序并共享认证详情。之后攻击者可收集该数据并滥用它作为 NTLM 中继攻击的一部分获得对在同样内网上远程系统的访问权限。


IDEMIA 修复漏洞，允许威胁行为者远程打开门
IDEMIA是生物识别认证解决方案的最大供应商之一，上周修复了一系列安全漏洞，包括一个重大漏洞，该漏洞可能允许威胁行为者劫持设备并远程打开大门。该漏洞被跟踪为 CVE-2021-35522，影响了 IDEMIA 设备，如VisionPass面部识别设备、SIGMA指纹终端以及MorphoWave和MorphoAcces静脉和指纹身份验证解决方案。IDEMIA上周发布了补丁[PDF]，包括纳扎罗夫的团队发现的另外两个问题的两个修复方案。

苹果发布 ios 和 macos 的修复零日，今年第 13 次

苹果今天发布了iOS、iPadOS和macOS的补丁，以解决该公司说在野外被利用的零日漏洞。被跟踪为CVE-2021-30807，苹果说，零日影响IOMobileFramebuffer，一个内核扩展，允许开发人员控制设备的内存如何处理屏幕显示器——屏幕框架布弗，更确切地说。根据 Apple 的说法，应用程序可能会利用 CVE-2021-30807 在易受攻击且未修补的设备上执行具有内核权限的任意代码。有效访问内核特权使攻击者能够完全控制设备，可能是 iPhone、iPad、macOS 笔记本电脑或台式机。在今天iOS/iPadOS和macOS的安全建议中，苹果表示，它知道有报道说，这个漏洞可能在野外被利用，但苹果没有详细说明。苹果鼓励用户更新到 macOS 大苏尔 11.5.1， iOS 14.7.1， 和 iPadOS 14.7.1， 它今天发布的版本， 以解决 CVE2021-30807 漏洞.更新适用于 macOS 笔记本电脑和台式机、iPhone 6s 及以后、iPad Pro（所有型号）、iPad Air 2 及以后、iPad 第 5 代及以后、iPad 迷你 4 及以后以及 iPod 触摸（第 7 代）。虽然这个"零日"很有可能是iOS越狱社区用来根植iPhone的新漏洞，但目前还不清楚今天的零日是否与向世界各国政府销售iPhone黑客工具的以色列公司NSO Group有关。


研究人员警告未修补的卡赛亚单位备份漏洞
全研究人员警告卡赛亚 Unitrends 服务中出现三个新的零日漏洞，并建议用户不要将服务暴露到互联网上。Kaseya Unitrends 是一个基于云的企业备份和灾难恢复解决方案，作为独立解决方案或 Kaseya VSA 远程管理平台的附加组件提供。上周，荷兰漏洞披露研究所（DIVD） 发布了关于Kaseya Unitrends备份产品中三个未修补漏洞的 TLP：AMBER 公告。近日DIVD发布了一份公共公告，警告在Kaseya Unitrends版本中发现零日漏洞早于10.5.2，并且不会将服务暴露在互联网上。DIVD的咨询中写道："在 Kaseya 修补这些漏洞之前，不要将此服务或客户（在端口 80、443、1743、1745 上运行默认值）直接暴露到互联网上。影响 Kaseya Unitrends 备份服务的漏洞包括经过验证的远程代码执行、身份验证的权限升级和客户端未经授权的远程代码执行的混合。与7 月 2 日 REvil 勒索软件攻击中使用的Kaseya VSA 零日不同，这些漏洞更难利用。

开源容器原生工作流引擎 Argo Workflows 可被用于攻击 K8s 集群
Intezer 团队在技术、金融和物流行业组织机构中找到一系列不受保护的运营中，可导致任何人部署工作流。在某些情况下，这些节点被恶意行动者用于部署密币矿机。Argo Workflows 是运行在 K8s 上的开源的容器原生工作流引擎，可使用户从中心接口运行平行任务，从而降低了部署的复杂度并使出错空间减少。Argo 使用 YAML 文件来定义需执行的工作流行，这些工作流或者从模板执行或者使用 Argo 控制台直接提交。针对配置错误的实例，Intezer 公司表示威胁行动者可访问一个开放的 Argo 仪表盘并部署工作流。在所观察到的一个攻击活动中，攻击者部署了 kannix/门罗币挖矿机，该挖矿机是一种已知的密币挖掘容器，已从 Docker Hub 中删除。

因遭受网络攻击，南非多个重要港口运输系统瘫痪
南非公路货运协会CEO Gavin Kelly表示，他们对南非国家运营公司遭受网络攻击感到痛心并高度关切。“这不仅造成严重延误，也大大影响到一切物流运输形式的可靠性，公路货运可谓首当其冲。”Kelly补充道，港口大门如今紧紧关闭，货运卡车既接不了货、也卸不了货。“由此带来的影响显而易见，排队时间会更长、交货必然延迟、道路拥堵进一步增加。应急状态下，临时上线的手动运营流程也会带来更多问题。更重要的是，面对上周爆发的国内动乱，各陆运服务商已经积压了一大批未能及时运送的货物。”港口方面的瘫痪会进一步加剧问题，让配送业务陷入一不可靠、二不可预测的窘境，大大降低整个供应链的执行效率。他还强调，“必须对这套系统做出调整，确保此类事情不致再度发生。另外，还应建立一套替代系统——哪怕昌手动形式，以确保在紧急状态下货物仍能不断出入港口。”
