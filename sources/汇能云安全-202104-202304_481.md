**5月18日，星期二，您好！中科汇能与您分享信息安全快讯：**  

  

******************Edge 92打通了已保存密码的Windows Hello身份验证******************

据Windows Latest报道，微软正在为Chromium Edge浏览器开发两项新功能，分别是 Automatic HTTPS 和“已保存密码”的 Windows Hello 身份验证。当前，用户会在地址栏输入网址时被自动重定向至不安全的 HTTP 版本。但在启用了 Automatic HTTPS 之后，Edge 将优先尝试连接到可用的 HTTPS 安全连接。

  

********************速修复！21个漏洞影响60%的互联网邮箱服务器********************

Exim邮件服务器软件的维护人员发布更新，共修复21个漏洞，它们本可导致威胁人员通过本地和远程攻击向量接管服务器。这些漏洞被统称为 “21Nails”，由安全公司 Qualys 发现。这些漏洞影响Exim，它是一种邮件传输代理 (MTA) 类型的邮件服务器，帮助邮件流量在互联网流动并到达目的地。4月一项调查显示Exim 在所有MTA解决方案中的市场份额高达近60%。

  

********************Gartner：2021年全球公有云支出将达3323亿美元********************

据市场研究机构Gartner最新发布的报告预测，2021年全球公有云支出将达到3323亿美元，比2020年的2700亿美元增长23.1%。云计算支出的增长可以归因于虚拟化、边缘计算和容器化等技术的普及。在对可组合应用程序需求的推动下，SaaS将占据最大的市场份额，到2021年将达到1226亿美元。基于SaaS的应用程序将有助于各国在自动化和供应链等领域生产和分发新冠疫苗。

  

********************因使用“带毒”盗版软件，研究所遭勒索软件袭击********************

由于售价太过昂贵令人却步，一位学生试图使用某盗版数据可视化软件，却最终令一家欧洲生物研究所遭受Ryuk勒索软件的全面攻击。警惕破解软件的原因除了软件破解本身的非法性质之外，其中还隐藏了恶意软件感染威胁。攻击者往往会创建伪造的破解软件下载站点、YouTube视频及BT种子，借此分发恶意软件。

  

********************苹果早在2016年收购了恶意软件检测公司SourceDNA********************

Apple Insider报道称：早在2016年，苹果就已经收购了恶意软件检测初创企业 SourceDNA 。但直到其被扯进Epic Games诉苹果App Store案件，外界才正式获知这一消息。作为一家初创企业，SourceDNA 打造了一款用于检查应用程序是否存在恶意软件或恶意代码的自动化系统。苹果应用审查流程高级主管表示，XcodeGhost引发的问题让他们对收购SourceDNA产生兴趣。
