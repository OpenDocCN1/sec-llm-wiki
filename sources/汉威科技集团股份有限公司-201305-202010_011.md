# 中国仪器仪表行业协会八届理事会第一次理事长联席会议在汉威成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657657267&idx=1&sn=e191fc02601461899d7e220a43909b72&chksm=bd53681d8a24e10b014d2a4eb74e0f41334ec0e34448b52707e64a3f031ed3f44597951da34a&scene=126&sessionid=1681218539#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657657267&idx=1&sn=e191fc02601461899d7e220a43909b72&chksm=bd53681d8a24e10b014d2a4eb74e0f41334ec0e34448b52707e64a3f031ed3f44597951da34a&scene=126&sessionid=1681218539#rd)

![](../Images/0f39ed0075031fe845159a955a8f5e09.png)

9月18日，中国仪器仪表行业协会八届理事会第一次理事长联席会议在郑州举行，汉威科技集团作为协会副理事长单位承办了本次会议。此次汉威科技集团承办如此高规格的行业理事长会议，是对汉威科技集团综合实力、创新能力、行业地位的充分肯定。

协会正、副理事长及委托代表共19人出席本次会议，会议由协会理事长吴朋主持，汉威科技集团任红军董事长致辞。

![](../Images/3324ad73890c1389f522a244ad9ab746.png)

▲汉威科技集团董事长任红军

任红军董事长在会议上表示，汉威科技集团非常荣幸能够承办此次中仪协理事长会议。一直以来，汉威科技集团高度重视技术创新和行业发展，希望通过本次会议推进仪器仪表行业高质量、稳健发展，预祝本次理事长会议取得圆满成功。

![](../Images/3e240d6079d344fa65c9c29b3d820573.png)![](../Images/e6aafefdf738d0c2fdb7b2156c87374e.png)

会议听取了协会秘书处“工作开展情况”、“2020年产业发展峰会筹备方案”、“关于加强行业宣传设想”以及“仪器仪表行业‘十四五’发展规划建议”等情况汇报，并就以上事项进行充分讨论。

  

会后，参会代表先后参观了汉威科技集团展厅、生产车间，系统全面地了解了汉威近年来所取得的一系列重要成就。

![](../Images/5a4cbbecac95b13c27d222c4c821ea58.png)![](../Images/dddebc583edba740f28113bc18c0ce58.png)

参观过程中，参会代表对汉威科技集团二十二年来的行业贡献以及近年来的发展速度表示肯定，对汉威的传感器、仪器仪表产品，以及智能化的生产设备与产线管理等进行了详细的询问，对汉威的智慧城市、安全生产、环境保护、民生健康等核心领域的整体解决方案给予高度评价，汉威科技集团领导班子成员陪同考察。

![](../Images/3af227ce182ba6ddc8ea557ce3d6bd53.png)

近年来，汉威以传感器技术为核心，形成了“传感器+监测终端+数据采集+空间信息技术+云应用”的系统解决方案，业务应用覆盖智慧城市综合解决方案、工业安全监测解决方案、居家智能与健康等行业领域，在“智慧水务”、“智慧燃气”、“智慧热力”、“智慧环保”、“智慧管廊”、“智慧安监”、“智慧市政”等行业应用案例众多，且已经树立标杆。

  

未来，汉威将继续以“为万物赋灵，让生产和生活不断涌现新价值”为使命，打造“民族的汉威，世界的汉威”，用科技改变世界，用智慧创造未来。
