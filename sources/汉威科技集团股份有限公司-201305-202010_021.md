# 请查收来自汉威科技集团 ISEE 2020 邀请函！

**ISEE2020强势来袭，约吗？**

  

  

**2020国际安全和应急博览会（ISEE2020）**将于**9月9日——9月11日**在杭州国际博览中心召开，这是安全应急领域的一场盛会，包括汉威科技集团在内的多家知名企业应邀参展。

  

本次展会，汉威科技集团将携多款软硬件新品亮相展会，以“用科技助力城市安全、用智慧悦享城市生活”为参展主题，聚焦燃气安全、市政安全、工业安全、消防安全、交通安全等物联网+大安全的核心领域，提升城市安全综合管理水平。

**精彩抢先看**  

  

  
  
  

燃气安全

  
  
  
![](../Images/ec0a4842e9452cb76f9c2832b39c3dbf.png)

▲智慧燃气安全监测系统

**智慧燃气安全监测系统**，将感知传感器、智能终端、通讯技术、地理信息和云计算、大数据等紧密结合，打造汉威云，建立完整的物联网产业链，以客户价值为导向，提供完善的平安家居、智慧运营、智能巡检、SCADA系统、智慧燃气信息化解决方案，实现城市燃气建设和安全管理的科学化、精细化、智能化。

  

  
  
  

**工业安全**

  
  
  
![](../Images/64bcd94a30f0a7e78e117ea71b9a4c9d.png)

▲企业综合信息平台

**企业综合信息平台**，依据行业设计规范，采用先进安全仪表的物联网与云计算融合技术，实现各类传感器、视频等实时数据的采集、处理、存储和管控一体化的企业管理，将企业生产运营、生产安全、消防安全、公共安全、环境保护、职业健康等感知物联网和已有其他相关系统实现无缝集成，实现企业应急救援与分析决策的管理目标。

![](../Images/fbc155aa670d5a59951d9fd8629c7925.png)

▲智慧园区综合信息平台

**智慧园区综合信息平台**，从安全备灾、风险评估、监测预警、应急处置到减灾降损，全程化管理各类型工业园区，为工业园区的安全生产提供强大有力的后台支撑。

![](../Images/b84a895b28313f9c6c461fa31c896872.png)

▲应急管理综合应用平台

**应急管理综合应用平台**，基于汉威“物联网+大安全”的“感·应·云”技术架构，围绕应急管理事前、事发、事中、事后全过程业务，构建了一套“统一指挥、专常兼备、反应灵敏、上下联动、平战结合”的政府应急管理综合应用平台。

  

  
  
  

**消防安全**

  
  
  
![](../Images/cfe70c8b9ed182ae263494a5e61fd1c7.png)

▲小微场所安消一体化系统平台

**小微场所安消一体化系统平台**，能够第一时间发现可疑火警上报，及时调取相关的地点、时间、频次等信息进行确认并处理，多维度的报表呈现，快速定位起火点的位置、保存电话拨打记录、联系人确认处理情况等信息，提供科学防范预警和处理依据；平台接收报警信息，联动警报设备，通知人员疏散。

![](../Images/439c0b39f60930a3111472b6b1f729e7.png)

▲智慧消防管理平台

**智慧消防管理平台**，依托汉威科技集团传感器优势，以物联网技术为核心，通过加装智慧烟感、燃气监控、消防水压监控、电路监控、多点视频联动等设备，采集消防设施数据，实现火警预警、动态监控、智能巡检、智能维保、数据研判分析等功能，立体呈现消防安全状态，全面提升消防安全管理水平和消防监督效能。主要应用于政府监管以及工业园区、大型商超、综合市场、医院、学校、古建筑、小微等场所。

  

  
  
  

**交通安全**

  
  
  
![](../Images/cea5a032f317d810265094139b205925.png)

▲酒精无线网络平台

**酒精无线网络平台**，是基于网络版酒检仪研发的酒精无线网络平台，支持多点远程无线数据自动接收，便于执勤人员调度管理；具备执法数据实时查看，执法数据统计分析等功能，增加对酒精检测仪定期标定提醒功能，为客户提供安全快捷的设备管理服务。

  

除此之外，汉威科技集团还将在现场展示**独立式双光路烟雾火灾探测报警器（YB035）、立式酒精体检机**等重磅新品，期待您莅临参观。
