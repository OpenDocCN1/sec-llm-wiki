# 【产业分析】从资本视角看工业安全产业的发展形势及前景

今年六月，我们迎来了以“消除事故隐患，筑牢安全防线”为主题第19个全国“安全生产月”。安全生产，特别是工业安全，是指通过各种安全防护措施和手段，确保工业生产过程安全及劳动者人身健康安全。工业安全产业包括在工业生产安全防护过程中应用的各类安全技术、设备、体系等，主要应用在能源、化工、电力、热力燃气及水产品供应等诸多行业。**本文尝试从产业及资本的角度对国内工业安全行业做观察与概览。**  

  

  

**01**

**工业安全的产业政策导向**

  

**党的十九大报告**

**强调牢固树立安全发展理念**

  

党的十九大报告强调，“树立安全发展理念，弘扬生命至上、安全第一的思想，健全公共安全体系，完善安全生产责任制，坚决遏制重特大安全事故，提升防灾减灾救灾能力。”近年来，我国安全生产持续向好，事故总量、较大事故、重特大事故逐步下降，重点行业领域、各地区安全生产状况好转。但总体来看，我国安全生产形势依然严峻，仍存在较多安全隐患，工业安全基础还不牢靠。

  

**国家加快完善**

**工业领域安全管理与应急制度**

  

2017年1月，国务院制定《安全生产“十三五” 规划》，明确了我国在新型工业化、城镇化推进过程中面临的安全监管体制不健全、安全生产基础薄弱等挑战，对矿山、危化品、烟花爆竹、工贸行业等重点领域提出加快构建风险等级管控与隐患排查治理制度。此后，国家相关部门又相继颁布了《应急产业培育与发展行动计划（2017— 2019 年）》《关于推进城市安全发展的意见》等政策，进一步加快重点产业的安全改造升级，强化对于重大突发事件的应急处置能力和水平。国家积极完善工业领域安全管理与应急制度，一方面推动了安全生产水平的提升，另一方面也为工业安全产业的发展提供了潜在的发展空间。

  

**国家加速推动**

**高新科技在工业安全领域应用**

  

近年来，我国工业发展水平不断提升，但在工业安全领域的技术产品水平仍然不足，在涉及到安全问题的关键环节、重点部位仍存在用人多、机械化与自动化程度低等问题，重大事故发生的风险较大。2015年6月，国家安全监管总局发布《关于开展“机械化换人、自动化减人”科技强安专项行动的通知》，积极推动重点行业领域机械化、自动化安全产品的应用，大力提高企业安全生产科技保障能力。此后，国家相关部门在《工业控制系统信息安全行动计划（2018-2020）》《关于加快安全产业发展的指导意见》，也提出要积极利用新技术开展工业控制防护能力评估和监测，加快先进安全产品研发和产业化，重点发展用于高危作业场所的工业机器人、人机隔离智能化控制系统、尘毒危害自动处理与自动隔抑爆等安全防护装置或部件。

  

  

**02**

**工业安全的全景产业链**

  

**工业安全产业链主要分为上、中、下游三个环节，上游为基础原材料及器件，中游为工业安全产品及设备，下游为工业安全服务。**

  

上游基础原材料及器件，涉及的原材料及器件范围较广，包括生产环境用的各种耐火材料、防腐蚀材料、防静电材料等，以及用于制造各类工业安全产品设备的电子元器件、金属器件等。该环节相关产品涉及种类较多，布局较为分散，部分特殊场合所需安全产品对原材料及器件的性能要求较高。

  

中游工业安全产品及设备，是工业安全产业的核心，按应用领域主要分为矿山安全产品、制造安全产品、劳动防护产品、电力安全产品及其他。其中，矿山安全产品主要包括矿山环境监测产品、矿山安全基础设施、矿山安全避险设施、自动采矿设备等；制造安全包括安全监测产品、智能安全设备、安全控制设备、辅助安全产品等；劳动防护产品包括头部防护产品、器官防护产品、身体防护产品、高空防护产品等；电力安全包括电力安全仪表、电力安全设备及辅助安全产品等。

  

下游工业安全服务，是工业安全产业延伸拓展的重要环节，传统服务有工业安全工程监理、工业安全标准规范制定、工业安全检测认证、工业安全评估评价、工业安全事故分析鉴定等。未来重点发展方向为工业安全管理与技术咨询、工业安全监测服务、工业安全教育培训与应急演练。

**工业安全上市企业的数量较少**

**行业未来具有较大增长潜力**

  

2019年前三季度，我国工业安全产品及设备上市企业营业收入为1714.74 亿元；2018年全年营业收入为2464.91 亿元，同比增长18.6%。由于我国工业安全产业发展起步较晚，目前工业安全领域的上市企业数量相对较少，企业规模较小，在工业安全创新能力发展方面仍然较慢。随着我国工业安全理念在市场中逐步深入落实，未来整个行业的发展潜力巨大。

**矿山及制造安全所占比例较大**

**电力安全未来发展空间可观**

  

从工业安全上市企业规模来看，矿山安全及制造安全企业收入占比较大，均保持在40%左右，劳动防护和电力安全占比较小。近年来，我国在不断提高采矿业、制造业安全标准之外，也在积极推动电力等公共资源生产部门的安全防护工作，同时我国电力等公共资源覆盖范围巨大，未来电力安全等领域也将具备良好的发展空间。

**我国安全生产的要求不断提高**

**科技创新助力工业安全转型**

  

党的十九大以来，我国高度重视安全生产工作，不断加强安全隐患监测排查、安全设施配备建设、安全管理措施推进等，严格落实安全生产责任制、安全准入制度，确保各类安全管理制度和措施切实有效。安全需求的不断变化，也对工业安全产业的发展形成一定挑战，但同时也推动科技创新的不断发展。

  

环境探测在工业生产中的应用逐步成熟，各类成分传感器技术已有较大进展，能够为工业安全提供良好监测预警功能，也为工业安全监测服务奠定技术及设备基础。

  

智能仪表成为工业生产安全及公共资源生产部门的应用热点，市场供给端已能够提供良好的产品和服务，而市场需求端较为分散，需要有效合理开发。

  

同时，工业安全领域上市企业积极进行科技创新融合，研究开发出适应国家政策需求的、提供更好安全防护功能的产品设备，并加速推动工业安全产业向智能化、信息化、平台化方向转型。

  

  

**04**

**工业安全的市场规模**

  

**2022年，中国工业安全市场规模**

**将达到1.2万亿元**

  

中国工业安全市场受到国家安全生产政策推动以及工业企业安全管理水平不断提高等多方面的影响，2019年整体市场规模突破万亿元，预计2020年将达到1.2 万亿元，工业安全产业在我国工业高质量发展中的影响将进一步提升，持续为工业企业的职工安全和财产安全提供坚实保障。

**2017-2022年中国工业安全市场规模及预测**

![](../Images/fdfe12e95350bc98291bdb2692217d43.png)

▲数据来源：赛迪顾问，2020年2月

  

**华东地区仍将是主要市场**

**工业安全服务将快速增长**

  

从市场区域来看，未来华东地区仍将是我国工业安全产品及服务应用的主要市场，占比可达全国市场的40% 以上，其次是中南地区、华北地区。同时，随着各地区工业企业在安全生产方面投入的增多，其安全运营及管理越来越系统化，单一的工业安全产品及设备将不能充分满足其安全生产的需求，以工业安全产品设备为基础、以系统化的安全设计及监测为提升的一体化工业安全服务将成为热点。

  

  

**05**

**工业安全部分龙头企业动向**

  

2019年，我国工业安全领域的龙头企业以技术创新、产品突破为重点，积极推动企业在矿山安全、制造安全、电力安全等各类工业安全细分领域的发展，同时以企业技术产品体系补充拓展、市场规模壮大等为目的进行并购，不断增强企业自身在行业中的竞争力。

**06**

**工业安全领域资本市场动向**

  

**工业安全领域投融资案例数量下****降**

  

从近三年的投融资案例数量来看，2018年工业安全领域投融资案例数量最多，2019 年数量有所下降。从细分领域来看，工业机器人、工业自动化两大领域的投融资案例最多，电力安全也受到资本市场一定关注。

  

从市场区域来看，未来华东地区仍将是我国工业安全产品及服务应用的主要市场，占比可达全国市场的40% 以上，其次是中南地区、华北地区。同时，随着各地区工业企业在安全生产方面投入的增多，其安全运营及管理越来越系统化，单一的工业安全产品及设备将不能充分满足其安全生产的需求， **以工业安全产品设备为基础、以系统化的安全设计及监测为提升的一体化工业安全服务将成为热点。**

  

**工业安全投融资金额呈现增长趋势**

  

从已透露的投融资案例金额来看，大致呈现出金额逐年增大的趋势，2017 年投融资金额多在5 千万元以内，2018 年、2019 年投融资金额逐步提升，单轮融资金额最高达到5 亿元。

**结语**

  

得益于政策的驱动以及各生产主体安全意识的提高，工业安全行业处于快速发展期，目前正从产品及设备的基础应用，逐步向以系统化的安全设计、监测、防控为一体化、智能化、信息化、平台化的综合工业安全服务方向转型，市场规模稳步提高。

  

汉威科技集团股份有限公司深入贯彻国家安全生产政策，**立足于以传感器为核心，以智能仪表为应用，以物联网数据平台为支撑，构建了“物联网+ 大安全”的发展理念，**大力推广物联网综合解决方案在安全生产领域的应用，参与制定多项工业安全领域国家标准，服务工业安全领域客户超过2000 家，已经成为我国工业安全领域重要引领者，在安全生产、园区安全、市政安全、环境安全、水质安全等领域沉淀了较强的核心竞争力，未来将继续发挥行业优势，推动我国经济社会高质量发展，为全面建成小康社会贡献力量。
