# 汉威科技集团发布第一季度报告，传感器业务高速增长

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657654648&idx=1&sn=f0f68e8cdcdf546e93b4c27acdaa2170&chksm=bd535ed68a24d7c0794fbb5c60021835e81e9aa7273c525eb9a814729f78bedaf041099a0cc8&scene=126&sessionid=1681218554#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657654648&idx=1&sn=f0f68e8cdcdf546e93b4c27acdaa2170&chksm=bd535ed68a24d7c0794fbb5c60021835e81e9aa7273c525eb9a814729f78bedaf041099a0cc8&scene=126&sessionid=1681218554#rd)

![](../Images/2211f0731e4ef33811662c6ccb71449f.png)

4月27日，汉威科技集团发布2020年第一季度业绩报告。2020年第一季度，新冠肺炎疫情的全球化蔓延为全球经济发展带来了前所未有的严峻考验，全球经济面临较大的下行压力。在此形势下，汉威科技集团全体同仁在董事会的领导下，紧紧围绕“成为以传感器为核心的物联网解决方案引领者”的产业愿景，**持续夯实内生增长，**在整体经济下行的环境下积极把握市场机遇，取得了良好的经营成果。

![](../Images/79f8006c50ba45fd54618c30d1ccc6b3.png)

  

**主要财务数据**  

  

报告期内，新型冠状病毒疫情在全球范围迅速扩散，受此影响，各行各业的生产、销售工作受到普遍冲击，整体经济环境面临较大的下行压力，汉威科技集团在危机中坚守主业，稳定发展，整体业绩实现正向增长。

  

报告期内，汉威科技集团实现营业总收入41,034.33万元，较上年同期下降4.84%。

实现归属于母公司所有者的净利润2,989.14万元，较上年同期增长5.88%。

  

**主要业务分析**

  

**厚植优势，持续建设物联网产业生态圈**

  
![](../Images/422bddf3f7387fdea42abd73fd7118d8.png)

**传感器业务**：报告期内，公司传感器业务经营情况良好。受新冠肺炎疫情影响，公司生产的红外热电堆传感器销量增幅明显，为抗击疫情、保证顺利复产复工做出了重要贡献。其中全资子公司炜盛科技实现净利润2,003.91万元，同比增长195.93%。一氧化碳传感器增幅明显，环保类气体传感器业绩稳中有增。应用于热水器、净化器、新风系统的家电类传感器市场状况稳定，市场份额进一步扩大。红外探测传感器产品布局进一步完善，MEMS产品线顺利投产，MEMS封测产线正在筹建中。

**物联网综合解决方案：**报告期内，物联网系统解决方案相关订单的实施、交付、验收工作出现了一定程度的延期。自全面复工以来，公司相关业务已经逐步恢复正常。

**● ****物联网平台解决方案**：业务经营稳定。在GIS、SCADA以及可视化平台项目领域斩获了多个优质订单，在智慧燃气、智慧水务行业持续深耕，同时不断丰富产品线。  

●  **智慧安全系统解决方案**：受新冠肺炎疫情影响，下游企业复工复产延缓，导致公司产品交付调试安装进度放缓，智慧安全系统解决方案业务当期销售收入小幅减少。同时，汉威科技集团在疫情期间积极采取远程办公、线上服务等多种模式降低疫情影响，报告期内新增订单较去年同期仍有所增长，在手订单充足。

●  **智慧环保系统解决方案**：环境监测方面，报告期内，公司不断完善智慧环保云平台，通过云服务的方式支撑环保机构的远程/在线办公业务。环境治理方面，报告期内，受新冠肺炎疫情的影响，汉威科技集团控股子公司嘉园环保有限公司项目类业务整体业绩有所下滑，运营类项目业绩已回归稳步上升通道。

●  **智慧市政系统解决方案**：报告期内，公司扎实推进智慧水务、智慧热力系统建设，充分发挥智慧市政项目的标杆示范效应，实现了智慧市政建设发展和运营实践的良好互动。

**居家智能与健康：**报告期内，市场对防疫产品的需求迅速提高，公司快速响应并开发了相关的软件系统及硬件设备，形成了“智能门磁+防疫隔离管理系统”、“热成像-人脸识别系统”等软硬件结合方案，主要用于社区、酒店、学校、商场等人员聚集的地方，取得了良好的效果。

**创新驱动，进一步提升研发实力**

报告期内，由于下游呼吸机、口罩检测设备需求量的增加，医用流量传感器的订单量出现大幅增长，为保证产品的质量水平，并按时交付客户，公司导入了高精度标定设备和检测设备。在满足订单需求的同时严把质量关，同时，公司针对于不同客户的需求定制开发了多种传感器应用方案，重新对软硬件接口及通讯协议模式进行定义，使之符合市场主流厂家产品的无缝接入。

**加强管理，不断完善集团管控体系**

报告期内，在经济下行压力加大，疫情影响较大、民营企业面临的形势更加严峻的大背景下，公司以强化内控为核心，以资金管理、采购管理、人力资源管理、应急管理为核心，加快内部优化调整、提质增效，加强管理改革，深挖内潜、降低运营成本，建立健全了各类风险防控的长效机制，为公司持续健康发展提供了有力保障。
