# 精彩剧透丨汉威科技集团即将亮相北京多国展

一年一度的仪表行业盛会——第30届中国国际测量控制与仪器仪表展览会（简称多国展）将于11月25日-27日在北京国家会议中心隆重举行。

届时，汉威科技集团将携带**一系列高端传感器产品及城市安全物联网解决方案**精彩亮相。期待您莅临汉威展台**（展位号：B132）**，共赏智能测控新风采。

多国展是由中国仪器仪表学会主办的亚洲最具影响力的测量控制、仪器仪表及自动化权威展览会。本届展会展出总面积超过30000平米，将有来自全球20多个国家和地区近500家中外企业参展。

**传感器系列产品**

![](../Images/85f39362ca263baf8cf5a62dc134453e.png)

本次多国展，汉威科技集团将重点展示**气体、压力、流量、热释电、水质、MEMS**等门类传感器产品，可广泛应用于智能家居、智能家电、车载电子、智慧消防、石油化工、煤矿安全、大气监测和智慧城市等领域。

**智慧燃气物联网系统**

![](../Images/d552932567e0c0bcc31d669be8c1a6fe.png)

**▲智慧燃气物联网系统**，搭乘汉威云，实现设备工况总览及大数据采集、分析。为企业提供高效、便捷的管理与服务体系，助力政府安全监管，保障燃气管网安全运营，实现城市建设和管理的规范化、精准化、智能化。

![](../Images/28c68e5e37e8817980c07e78c2b95f4c.png)

**▲燃气调压设施预测维修系统**，适用于燃气管道各种等级压力的监测、预警和相关数据的管理。

**▲阀井室安全监测系统**，适用于燃气井、污水井、电力井、供水井、通信井等阀井内，对危险气体、液位、温度、井盖异动等信息不间断监测和预警。

![](../Images/89e865876e71ce8225396b1cc3e41f3e.png)

**▲工商业燃气安全监测系统**，适用于城市工商业、综合体、九小场所等燃气场所安全监测预警。通过区域内智能监测终端实时感知数据变化，管理平台进行数据存储和分析，实时监测气体泄漏、阀位信息、烟雾报警等状况，如有异常，提前预警。

**工业安全物联网系统**

![](../Images/d27ae4828e32c3ae9de8c13807e55f03.png)

**▲工业火气报警控制系统**，是具有完全冗余结构的智能火灾报警和气体探测一体化系统，通过趋势设定技术达到最大的安全性和最小的损失风险，满足功能安全性要求。

![](../Images/c5f32117ae3147a038e48a060ef5052b.png)![](../Images/672e0b33d13da8890e95457e8fd0d496.png)

**▲可编程安全控制系统**，具有模块化、双安全CPU设计，支持表决功能、冗余容错设计的功能安全控制系统，具备支持IEC1131-3的LD、FBD、ST和SFC四种语言。适用于石油化工、精细化工、食品制药、危险化学品储运等工业领域，可满足可燃/有毒气体监测系统（GDS）等关键性安全系统应用，能够提供优良的安全生产售后服务，共同提升企业安全生产水平。

![](../Images/962da9a32dda437525268f6c718c0ec6.png)

**▲安全风险管控与应急管理平台**，依据行业设计规范，采用先进安全仪表的物联网与云计算融合技术，实现各类传感、视频等实时数据的采集、处理、存储和管控一体化的企业管理，将企业生产运营、生产安全、消防安全、公共安全、环境保护、职业健康等感知物联网和已有其他相关系统实现无缝集成，实现企业应急救援及分析决策的管理目标，助力企业践行“安全第一、环保优先、身心健康、严细恒实”的管理理念。

**祥云物联网平台**

![](../Images/6414bfef639d5362d3e4e04e331ff8fe.png)

**▲祥云物联网平台**，包括边缘采集层、pass服务层和业务赋能层，聚集智能仪表终端价值挖掘，整合产业链上下游生态资源，打通物联网感知、传输、平台、应用完整链路，形成资源共享、合作共赢的物联网生态体系。
