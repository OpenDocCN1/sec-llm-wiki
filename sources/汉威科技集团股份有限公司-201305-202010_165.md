# 第四届中国传感器创新创业大赛华中赛区决赛顺利举行

2018年9月28日，第四届中国（国际）传感器创新创业大赛（华中赛区）决赛在河南工业大学顺利举行。来自国内高校和国内知名企业的8位专家组成大赛的专家评委，汉威科技集团股份有限公司总工程师张小水作为创新组评委参与评审工作。

![](../Images/0b3732408a8b56d000f73ce00c4b2cff.png)

  

  

  

**第四届中国传感器创新创业大赛**

  

华中赛区决赛

  

  

主办：中国仪器仪表学会    河南省仪器仪表学会

  

承办：河南工业大学    汉威科技集团股份有限公司

  

协办：河南省仪器类教学指导委员会

           郑州高新区管委会梧桐园区运营中心

  

  

  

![](../Images/d2449a3b72c44fbb0132e2a041e1ffe3.png)

经过3个月的精心制作，共收到30件参赛作品。经过匿名网络初评，来自华中科技大学、武汉理工大学、河南工业大学、企业设计院等10个单位、20支队伍进入决赛。决赛作品通过现场展示、答辩两个环节共产生一等奖4名、二等奖7名，三等奖7名，优秀指导教师4名。

  

  

  

开幕式

河南省仪器仪表学会副理事长兼秘书长、河南工业大学电气工程学院院长刘楠嶓致辞：

“

  

  

  

此次创新创业大赛一方面搭建了华中赛区进入决赛的作品进行展示和竞赛的平台，另一方面要选拔更优秀的队伍代表华中四省（河南、湖南、湖北、江西）参加全国决赛，取得更好的成绩，并预祝大赛圆满成功。

  

  

  

  

”  

![](../Images/f673fbfb2aa082335398d8a007174bc2.png)

  

  

  

**协同创新创业**

![](../Images/119c69f10eb5ce57a78f1a300ed653e7.png)

**携手做大做强**

  

汉威科技集团股份有限公司作为承办单位之一，发掘创新科技项目的独特平台，对接活动发挥大赛的创新孵化平台作用，同时集团公司针对“传感器+”领域，构建专业孵化器——漫威众创空间，实现精准孵化，选择具有创新性的、能够补全汉威产业生态圈的项目进行孵化。通过需求对接，集聚集团创新创业资源，发现创新创业的价值，促进优秀项目协同创新创业，携手做大做强。

  

  

![](../Images/3a7fa5982706afd3a75aea05afb07015.png)
