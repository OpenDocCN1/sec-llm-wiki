# 汉威科技集团与郑州大学共建物联网研究院

2018年9月14日，汉威科技集团与郑州大学签署共建“郑州大学汉威物联网研究院”合作协议，汉威科技集团董事长任红军、郑州大学校长刘炯天出席签约仪式。

![](../Images/4473f4f3a06d046128c3df5fc7f003b8.png)  

  

  

  

**☆****☆****☆****☆☆☆☆****☆****☆**

合作亮点

  

双方本着共建、共管、共赢的基本原则，探索以企业为主导，将研究院建在大学的新路子，创新产学研合作新模式和学校办学新方式，为汉威科技集团的行业经验和产业优势与郑州大学的学科优势和科研优势进行深度结合提供新的平台。

  

![](../Images/aecf089cba50a9daedaacc79c9a42e88.png)

  

  

物联网研究院  培育物联网生态

物联网研究院的建设和发展，将充分发挥郑州大学的学科优势和汉威科技集团的产业优势，通过产教融合，产学研合作，形成合力，实现共赢，培育物联网生态环境，为物联网的研究及应用提供技术保证和智力支持。

  

![](../Images/a9e71480998f784b90e7b56a43afd1a8.png)

  

**汉威科技集团**

汉威科技集团将充分发挥郑州大学的学科优势和科研优势，开展物联网基础研究、应用基础研究，研发战略性、前瞻性技术，强化企业创新能力，提升企业核心竞争力，增强企业获利能力。郑州大学则发挥汉威科技集团的行业经验和产业优势，通过产教融合，移植企业文化，以一流学科建设为指引，打造物联网优势特色学科平台，提升人才培养条件，服务国家一流大学建设。
