正式发布

2018年7月25日上午，2018郑州“智慧化时代企业组织文化建设”高峰论坛暨《汉威文化法典》发布会在郑州高新区顺利召开。

  
  
  

  

  

  

![](../Images/0bbf7aa850d13de1abd00be4bb2ffdfb.png)

河南省工商联副主席赵纯武出席论坛并致辞。

  

  

![](../Images/c58384c8985a04cc744c546a6d570b16.png)

郑州高新区党工委副书记管委会常务副主任李金勇出席论坛并致辞。

  

  

![](../Images/11c2dfb5ee90b3e0abe6d04eadac8288.png)

华夏基石管理咨询集团创始人、董事长，中国人民大学教授、博士生导师，中国著名管理咨询专家彭剑锋教授在此次论坛上作《数字化与智能时代：战略、组织、人才管理新思维》的主题演讲，并与汉威科技集团董事长任红军共同为《汉威文化法典》揭幕。  

  

  

![](../Images/4ee4d81ae73df3fc7f5054385162a9d3.png)汉威文化法典![](../Images/95de61d4bd4104b8b27f2e5e25c518b7.png)

Han Wei cultural code

企业是社会的细胞，优秀的企业文化是新时代中国特色社会主义文化的重要组成部分。党的十九大为民营企业的发展、民营企业文化建设提出了新要求，省工商联将继续坚决贯彻习近平新时代中国特色社会主义经济思想和党的十九大精神，引导广大民营企业树立新发展理念，实现高质量发展，为中原更加出彩作出积极贡献。

                                       ——赵纯武

  

  

  

Han Wei cultural code

高新区管委会近年来全面贯彻落实党的十九大精神，围绕千亿级世界一流高科技园区奋斗目标，给辖区内企业的发展提供更有力的支持和服务。相信通过本次论坛的交流，推动企业在智慧化时代的浪潮中不断的变革和发展，与高新区一道在国家自主创新示范区的建设过程中，担当高新责任，奉献高新智慧，做出高新贡献。                                          

  ——李金勇

  

  

  

Han Wei cultural code

文化是企业面对未来的追求和使命。《汉威文化法典》的推出，也是要确立汉威人在面对错综复杂的矛盾关系的时候，我们要坚守什么样的价值观？她是汉威人对未来的顶层设计和系统思考。意味着汉威真正从机会导向转向战略导向。                                                                                                ——彭剑锋

  

  

  

  

Han Wei cultural code

《汉威文化法典》是汉威科技集团在成立20周年之际，携手国内顶尖的管理咨询集团北京华夏基石，对汉威的企业文化进行梳理与重塑形成的纲领性文件。它将促成汉威人不忘初心，持续奋斗，厉行价值创造，为万物赋灵，铸造基业长青的汉威。                                                                           ——任红军

  

  

  

  

  

![](../Images/b32d6033848a018af07eb25055bfed8e.png)

华夏基石高级合伙人、项目总监葛晶面向来自集团公司的400余名中高层干部和骨干人员，全面、深入的解读了汉威过去的成功之道、面临的现实挑战，以及《汉威文化法典》的主要内容。  

  

  

  

  

汉威文化法典

  

  

《汉威文化法典》是汉威及各成员企业自创业之始，从各自不同的领域、不同的角度，以各种不同的方式创新发展的精神，形成的共同文化的认知和共识，她是汉威人共同的纲领和信仰。

  

  

  

  

  

为万物赋灵，让生产和生活不断涌现新价值

  

  

  

![](../Images/b1c9ddfc408415f170e5becd35c0a336.png)

  

    纵观商业历史，能实现基业长青的企业寥若晨星。

    技术、产品的不断创新和夯实，有效的管理，是企业保持竞争优势并获得成长的要素。而大量的现代工商业实践证明，由企业愿景、使命、价值观和行为准则等核心要素构筑的企业文化，才是基业长青的基石。

    回望过去，尽责、创新支持勤奋的汉威人走过卓有成效、快乐的二十年；展望未来，《汉威文化法典》必将促成汉威人不忘初心、持续奋斗，厉行价值创造，为万物赋灵，铸就基业长青的汉威。

  

——汉威科技集团创始人、董事长任红军
