# 重庆市自动化与仪器仪表协会组团考察汉威科技集团

**{  11月14日-15日 }**  

地点：河南汉威科技集团股份有限公司

  

为增进重庆市自动化与仪器仪表协会成员交流、促进成员单位发展、打造协会品牌。河南汉威科技集团股份有限公司迎来了重庆市自动化与仪器仪表协会领导班子及核心企业组团考察交流。

![](../Images/252b04a51ae5525ff05ab872a186de29.png)

汉威科技集团  

是国内最大的气体传感器及仪表制造商，创业板首批上市公司，我们围绕物联网产业，将感知传感器、智能终端、通讯技术、云计算和地理信息等物联网技术紧密结合，打造汉威云，建立完整的物联网产业链，结合环保治理、节能技术，以客户价值为导向，为智慧城市、安全生产、环境保护、民生健康提供完善的解决方案。

  

![](../Images/54716b6ebaee3b92af83cec29d2970ea.png)

  

此次访问交流由协会秘书长张新国带队，前往企业包括理事长单位重庆川仪自动化股份有限公司、秘书处及副理事长单位重庆科技发展战略研究院、副理事长单位重庆中智联仪表集团、重庆耐德工业股份有限公司、重庆材料研究院相关领导及技术骨干。

  

![](../Images/76e420eab2258d93c528fdf5e779075c.png)

  

汉威科技集团董事长任红军、研究院院长李志刚等陪同参观，汉威科技旗下畅威物联网科技有限公司副总经理高延明、炜盛电子科技有限公司电子事业部总经理祁泽刚，对汉威核心产品传感器、智慧城市等作了全面细致的讲解。

  

![](../Images/161d35a4db96e28677c742ee117a19ea.png)

  

参观交流期间，双方开展了技术问诊、技术对接、项目合作，并举行了座谈交流，围绕传感器前沿技术，物联网智慧城市技术方案及产品、平台、服务，作了深入交流与探讨。汉威科技集团董事长任红军表示，为进一步推动重庆和西部智慧城市建设，将加强与重庆市自动化与仪器仪表协会及相关企业的互动、合作；南阳防爆所副所长张刚就生产防爆安全等问题与大家作了深入交流，结合自身业务方向和重点发展领域，各单位分别就物联网云平台、智慧安检、防爆安全、产品定制化、生产大数据等方面提出了思路与需求，双方达成了初步合作意向。

  

![](../Images/d3ccf3fef83c842251914e75982df956.png)

   此次考察一方面是为了进一步推动“十三五”规划中的智能制造战略布局，同时也是协会开展服务、搭建交流平台、聚合企业资源、实现技术服务、成果转化工作的一次有力实践。
