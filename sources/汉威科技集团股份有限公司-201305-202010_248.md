# 郑州华润燃气副总经理陈豫一行莅临汉威参观交流

2017年9月6日上午![](../Images/26d15826136dc277513b52ebec5f8f29.png)

郑州华润燃气副总经理陈豫一行到汉威科技集团参观交流。汉威科技集团董事长任红军、副总裁尚剑红、副总裁焦桂东等领导对陈总一行的来访表示热烈欢迎，并带领大家一起参观展厅，介绍汉威近19年的发展历程，以及目前的业务板块、产业布局、产品和解决方案。

  

![](../Images/9e85fdb3a69a194ccc22665f27693baf.png)

  

  

从传感器材料、模块到智能仪器仪表，再到整个行业应用的完整解决方案，汉威不同业务板块的布局构建了完整的物联网生态闭环，生动、真实、丰富的案例呈现，给来访嘉宾留下了深刻印象。

  

![](../Images/bdfaaea5215a83b23c2130995edde017.png)

![](../Images/6dc1ca3a559cc218f0d10e3672f027dc.png)

  

  

在汉威集团会议室，双方就目前汉威博士后工作站的建设经验进行了对标交流，同时陈豫总向汉威介绍了郑州华润燃气的发展历史及对未来的展望,双方对共同关注的科技合作、智慧燃气建设等内容进行了深入的探讨。

  

![](../Images/66d7a87e809014b288d27ef67f4ffa6b.png)

![](../Images/474775162bed584169c7d2db6032ebdc.png)

  

随后，集团副总裁尚剑红、副总裁焦桂东等领导一起陪同陈总一行参观了郑州高新自来水公司。高新水司是汉威的控股公司，作为智慧水务应用的标杆企业，目前已全面实现了智能化管理，是互联网+、工业4.0的典型代表。

  

![](../Images/03bf377c0693b4e0308b537fd51c1518.png)

  

强强联手

郑州华润燃气和汉威科技集团同时作为郑州本地化优秀企业的代表，通过此次的沟通交流，双方加深了彼此的了解。未来双方将进一步深化互信、积极互动、加强沟通合作，为社会创造更多价值。
