# 清华大学五道口金融学院专家莅临汉威电子

      5月6日，清华大学五道口金融大咖们齐聚郑州，在汉威电子董事长任红军校友的盛情邀请下参观了汉威电子。

![](../Images/7ea22161e439d483f37fcd7345c45c2d.png)  

![](../Images/444dc04610150acc5b85fcea9f2611ba.png)  

      在汉威电子展厅，任红军董事长介绍了汉威的发展历程，并着重讲述了汉威目前的创新创业发展情况。随后，金融大咖们还参观了漫威众创空间（以汉威电子为依托的传感器国家专业化众创空间），并在漫威咖啡厅进行了座谈。

![](../Images/d90a331dfaf9689872f0f873d905e516.png)

      此次活动，为汉威电子汇集了更加深厚的金融资源，为日后加速发展提供了强大的支持与动力。
