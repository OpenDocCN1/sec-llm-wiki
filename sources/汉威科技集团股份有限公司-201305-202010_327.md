# 依托大数据服务网格化监管

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657650771&idx=1&sn=5177cf7fafbbe74695f03e676d173ab9&chksm=bd5341fd8a24c8eb30dd9916aabf0d113219cf0676b331758120676873f86c24490610d58ce5&scene=126&sessionid=1681218609#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657650771&idx=1&sn=5177cf7fafbbe74695f03e676d173ab9&chksm=bd5341fd8a24c8eb30dd9916aabf0d113219cf0676b331758120676873f86c24490610d58ce5&scene=126&sessionid=1681218609#rd)

![](../Images/1ad2e6fa11875de35c938210a459ccad.png)

  

近几年，随着雾霾频发，大气污染问题成为社会关注的热点话题，雪城软件（汉威智慧环保事业群成员企业之一）匠心研发的网格化环境监测平台在汇集高密度分布式监测设备的基础上，依托大数据，实现精准分析，使大气污染防治工作量化可控，为环境监管部门制定方针决策提供科学的数据支撑。

![](../Images/47aeed1b3cbed3526d6c3306d712cecd.png)  

** 雪城软件开创环境监测领域新高度，网格化大气环境监测平台可以实现：**

智能监测

  

运用智能化传感器实现城市区域环境空气质量、工业废气、汽车尾气、工地扬尘、餐饮油烟、装修喷漆等溶剂类污染的精准化监测。  

![](../Images/4e5b98b14af8ca7118d7255edd171187.png)

精准分析

# 

# 

  

基于高斯模型的污染源动态趋势分析，将污染区域、污染程度以动态的形式直观的展现出来。基于统计模型的预警预报模型分析，将气象场、监测、源清单等数据导入统计模型，可以科学预测污染变化趋势。

![](../Images/9d02f1a5fef5efc9b4517a9749756df6.png)  

基于小时数据的大气质量对比分析，将一天内不同时段的大气污染AQI和单因子的数据进行对比分析，从中挖掘规律，并制定对策。

![](../Images/9d007ae7e5a83e75b6eb7c126b2ac2e8.png)  
  基于连续监测数据的大气质量对比分析，将一段时间内相同时段的大气污染AQI和单因子的数据进行对比分析，从中挖掘规律，并制定对策。  

![](../Images/9d20ed8ba89a12a8ff130551dd77d26e.png)

科学防治

# 

# 

  

实时展示县区办事处空气质量日排名、月度排名等，协助建立大气污染防治考核与评价体系，合理制定县、区、办事处绩效考核责任目标。

![](../Images/0bfa82a7babfc3471bff168c2ff9a67f.png)  
![](../Images/292e2950a6018abe68230c44ba3f5e12.png)  
  集中对工业源监控、干洗店、建筑工地、餐饮企业、混凝土搅拌站较难管控的污染散源进行有效监管。  

  

![](../Images/aba012463098dd31a345d35d9fcd0ac1.png)  
  
![](../Images/e7b31b76ca024dab4a2df6ad41043f41.png)

![](../Images/319453c735b9dceeec94445c5b8d78fd.png)  
![](../Images/c8eb99a0b111ab29f72120d31d14da61.png)![](../Images/d995ceeda3245b4f3e36127f226ad055.png)  
   

  针对大气污染情况制定科学合理的防治方案，并根据分析模型进行模拟推演，方案执行后，进行污染防治效果的后验证。
