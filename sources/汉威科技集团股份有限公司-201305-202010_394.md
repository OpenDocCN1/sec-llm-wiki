# 汉威安防卫士为“上合峰会”保驾护航

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=406296828&idx=1&sn=368a2cf90f4118c4bed23d79823d9cf7&chksm=3b0c51520c7bd844848798ddeb756c9c46335ecfd2b9a243357222ed2940bee9b174f33fce6c&scene=126&sessionid=1681218624#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=406296828&idx=1&sn=368a2cf90f4118c4bed23d79823d9cf7&chksm=3b0c51520c7bd844848798ddeb756c9c46335ecfd2b9a243357222ed2940bee9b174f33fce6c&scene=126&sessionid=1681218624#rd)

2015年12月14日-15日，上海合作组织成员国政府首脑（总理）会议理事会第十四次会议在郑州胜利召开，中国、俄罗斯、哈萨克斯坦等十二个国家的领导人出席了峰会。这是郑州第一次举办如此高规格的国际会议，全市安防工作也升级至有史以来的最高级别。在本次峰会期间，河南汉威电子股份有限公司承接了重点路段及重要区域的视频监控工作，为确保峰会的顺利进行发挥了重大作用。

**“壹号任务”光荣而艰巨**

 近期恐怖袭击事件喧嚣尘上，地区冲突风险升温，要保证“上合峰会”的顺利进行，安防工作无疑是最重要的环节，被视为“壹号任务”，而视频监控作为安防的重要手段尤为重要。作为“壹号任务”的参与者，汉威感到这项任务光荣而艰巨，此项目时间紧、任务重、责任大，但汉威人齐心协力，投入了全部的热情与力量，圆满完成了峰会期间所承接的重点路段及重要区域的视频监控工作。

![](../Images/2a934be53d5da3c2cd7b7b901cd02970.png)

汉威任务区域示意图

据悉，河南省黄河迎宾馆是本次峰会的主会场之一，负责接待国务院总理李克强及中方代表全体人员，黄河迎宾馆门口监控及其内部监控管理平台接入公安局监控管理平台的任务是由汉威承接和完成的。除此之外，汉威承接的任务区域还包括机场高速下口、整个中州大道、迎宾路、柳林站所有沿线的监控项目以及公安厅、公安局、绿地、新郑机场等多处高点监控等等。“我们负责的路段在安保任务中属于非常重要的路段”， 汉威智能交通事业部总经理李卫红介绍说，“汉威历来就是市政交通工程的首选承建单位，不论设计方案还是工程质量，都多次获得郑州市公安局、郑州市交警支队的好评，正是凭借多年积累下来的好口碑才能担起此次峰会期间的安防重任。”

![](../Images/580b2b5530d3460f4d9440e1dbf7975d.png)

任务区域中的150处高清路面监控设备均由汉威负责安装，同时这些监控设备拍摄到的画面还要上传添加到郑州市公安局的监控平台上。由于该区域存在桥梁修建、道路改造等情况，造成了电力、网络资源少，给施工造成了非常大的难度，不但要通过各辖区公安分局协调就近的设备供电问题，还要协调移动、联通的网络资源，同时不能直接上传到市局平台的还需通过交警支队的监控平台中转到市局监控平台。就是在这样的情况下，汉威团队全体动员、加班加点，仅仅用了不到两周的时间就保质保量地完成了任务区域内的视频监控工作，为上合峰会的安全、顺利召开出了一份力。

**“上合”安防，汉威在行动**

“壹号任务”中所包含的视频监控，是峰会期间安保方案的重要组成部分，而对于提供这些监控设备的单位，不论是设备质量、技术资质，还是单位背景、综合实力等方面都有更加严格的要求。汉威是国内首批、河南首家创业板上市公司，自1998年成立起就坚持走“持续创新、自主发展”的道路，并将“产业报国、民族复兴”作为汉威的使命和理想。从信息城市、数字城市到智慧城市，汉威在智能交通管理领域走得又好又快，应用更落地，也更接近政府的商务、公共设施和民生建设。不仅如此，汉威之前所承接的市政智能交通工程项目均未出现过任何问题，这也是郑州市公安局、郑州市交警支队对汉威倍感信任、青睐有加的重要原因。

汉威城市交通监控系统采用先进的视频成像技术、计算机网络与通信技术、数据库管理技术等高新技术手段，通过安装在重点路段、重要区域的视频监控设备，将各个监控点的车辆交通状况、区域实时视频、快速地传回后台指挥中心系统，在指挥中心系统集成平台上可直观地了解和掌握各监控点的车辆、人员等状况，可以对现场突发事件等录像取证并及时处理，从而确保了重点路段、重要区域的安全防卫及智能调度目标的实现。

汉威将领先的传感器技术、电子控制技术、数据通信技术等高新技术有效地综合运用于交通运输、服务控制和车辆制造，加强车辆、道路、使用者三者之间的联系，从而形成一种保障安全、提高效率、改善环境、节约能源的综合运输系统。据样本地区应用数据显示，汉威智能交通系统的实施可以减少交通阻塞10%～50%，节省能源5%～15%，减少空气污染25%以上。

**“有条件要上，没有条件创造条件也要上”**

“壹号任务”时间紧、困难多、压力大，从下达通知到峰会召开仅有半个月的时间，汉威智能交通事业部全体总动员，在李卫红总经理的带领下，合理统筹、科学安排，大家各司其职、团结协作、夜以继日地开始了紧张地施工工作。“当时我们的目标很明确——一切为了上合峰会，能够为上合峰会的安全出力，我们都感到很自豪”，李总骄傲地说道，“那几天大家以工地为家，吃住都在工地上，条件很差，环境也十分恶劣，却没有任何怨言，这种不怕苦不怕累的工作热忱着实令人感动，特别是最后几天，因为连轴转很多人都累病了，却没有一个人请假休息的，而是把药带在身上，吃了药继续工作。”  
时间紧迫只是“壹号任务”最好解决的一个问题，技术难题及外联沟通方面的问题才是最难攻克的关卡。每个监控设备安装完毕后，都需要接电联网才能正常上传画面，但是由于这些监控设备所安装的位置都比较特殊，既不准飞线又不准破路，根本没有现成的电源、网络可用，必须通过公安机关或市政部门协调好从第三方获取电源，通过移动、联通公司协调网络，还要保证这些电网的稳定性和安全性。除此之外，前端设备由于网络线路复杂，一部分设备还需先接入交警支队监控平台，再通过支队平台上传到市局监控平台，因为市局是专网专线，对技术设备、施工都有特殊要求。面对这些重重困难，李卫红总经理只有一个要求，那就是——“有条件要上，没有条件创造条件也要上！”她既是整个项目的指挥官，又在施工现场解决最困难、最关键的一线问题，在她的带领下，汉威团队终于排除万难圆满完成了自己的“壹号任务”。

**“上合一役，我们收获的不仅是口碑”**

 随着上合峰会的结束，汉威团队终于可以松一口气，谈到这次“战役”，李卫红总经理说，他们收获的绝不仅仅是好口碑，她说：“在这个项目中，大家遇到问题不逃避、不推脱，而是积极主动解决，充分体现了我们汉威人‘尽责’的精神，同时，通过这个项目，整个团队的紧密性、协调性得到了加强，做应急项目的能力也得到了大大提高，还传帮带了一批新人，这些都是我们的收获。能够圆满完成这项任务，还要感谢集团领导、采购部、行政部等其他部门的大力支持，汉威大家庭就是我们最坚强的后盾。能为上合峰会出力固然骄傲，但更令我们自豪的是，我们身后有一批勇于担当、尽职尽责的汉威人！”  
上合峰会的成功举办，体现了郑州承接国际会议的能力得到了有力认可，这对郑州、河南乃至中部地区都具有重大意义。而汉威作为“上合峰会”的安防卫士，圆满完成了自己承接的光荣而艰巨的“壹号任务”，这也标志着汉威承接大型市政智能交通工程项目的能力得到了有力认可，必将为汉威的发展带来新的发展机遇。
