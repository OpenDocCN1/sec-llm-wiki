# 城市燃气无线监测系统解决方案

**系统概述  
**城市燃气无线监测系统基于无线网络传感技术开发的自组网、自适应、维护简单的城市燃气安全的在线监测管理系统。广泛应用于居民社区、学校及企事业单位食堂、宾馆、工厂等使用燃气的场合，对燃气泄露等重大安全事故防患于未然。系统主要由燃气报警器/探测器、无线网络设备、监控中心组成。

![](../Images/4e4cfa3bb3060ecd4683bdb5e8cc4a43.png)

**系统特点**  
★无线联网、统一监控。以无线联网的方式代替传统单点监控，实现区域联防。  
★可靠安全、多级报警。采用现场监控与数据远程相结合的多级监控模式。现场发出报警的信息提醒现场人员的同时，通过Internet和GPRS网络等多种网络将数据传送到更高一级监控中心。  
★安装简单。只需在现场安装相应燃气报警器，信息自动上传至监控主机和监控中心。  
★升级维护方便。采用C/S与B/S相结合的系统框架，通信与前台相对独立，维护升级方便。  
★适应大规模的城市燃气用户的监控需求。有效整合包括各种居民社区、学校、酒店、宾馆等城市燃气各个用户的燃气使用情况，对各个监控点作统一监控，及时发现安全隐患。  
★支持短信提醒功能。
