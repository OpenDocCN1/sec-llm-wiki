# 微博泄露公司机密小伙被辞退

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&appmsgid=10014182&itemidx=4&sign=9ce265a70808d2738f7dd64cf0983180&scene=126&sessionid=1681218641#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&appmsgid=10014182&itemidx=4&sign=9ce265a70808d2738f7dd64cf0983180&scene=126&sessionid=1681218641#wechat_redirect)

眼下，微博已经成为不少年轻人日常生活的一部分，常被用来记录生活、表达情绪，苏州90后小伙小周也是一样。可没想到，自己不经意发的一条微博，竟泄露了公司机密。小周不仅被辞退，还被公司告上了法庭。  

  

作为一名“90后”，小周和所有同龄人一样，平时只要一有空，就会刷微博，自己也常发一些微博，记录生活中的点点滴滴。一段时间下来， 小周也拥有不少的粉丝。这给他的生活增添了不少乐趣。

  

去年9月，小周参加了工作，在苏州一家公司担任设计师助理，负责产品的研发工作。因为工作性质特殊，刚一入职，公司便对其进行了商业保密方面的培训，同时在劳动合同中约定，一旦泄露公司商业机密，公司就有权解除劳动关系并要求相应的赔偿。

  

今年6月，小周新买了一盆小植物装扮办公桌。瞧着新鲜，小周于是拍下一张照片发到了微博上。可就是这条微博给小周惹上了麻烦。原来，在照片的背景中，小周的电脑开着，上面有一张公司新产品的成稿图，这个新产品公司花了大量的时间与精力研发，原定于一周后发布。但因为小周的微博被大量转发，产品提前曝光，从而影响了公司的原定计划。为此，公司将小周辞退，并通过诉讼程序向小周索要相应赔偿。目前，姑苏法院还在进一步审理中。

  

现代快报记者 何洁
