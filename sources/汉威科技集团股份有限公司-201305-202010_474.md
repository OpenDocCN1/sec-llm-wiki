# 微博实验：半小时就查到你的详细信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&appmsgid=10014182&itemidx=3&sign=101ddd558e2493be8121362b248f236d&scene=126&sessionid=1681218641#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&appmsgid=10014182&itemidx=3&sign=101ddd558e2493be8121362b248f236d&scene=126&sessionid=1681218641#wechat_redirect)

昨日，网友“和菜头”发微博称，“无数网友不断上传自己或家人孩子的照片，以及自己的社会关系。随便翻翻就可以知道——有多少人把自己置于绑架、诈骗的可能性之中。”  

  

“和菜头”的微博引发网友热议。有网友立即删除了关于孩子的微博，也有不少家长持怀疑态度。面对怀疑，“和菜头”仅用半个小时，就知晓了其中一名网友以及其孩子的详细信息。

  

![](../Images/444d8e4688a3ead83d0965dac668e533.png)

  

**实验：半小时就查到孩子的详细信息**

  

网友“和菜头”称，有家长不相信微博会泄露隐私。作为回应，“刚才，一位XX妈对我的言论很不满。于是，我花半小时过了一遍她晒儿子的700多条微博。得到了居住地，孩子的真实姓名，生日。知道了她的家庭状况，老公几天回家一次。通过她的制服照和手机签到信息得到了她的单位。通过照片，知道了每周固定带孩子要去玩的地方。晒娃，真不是什么好事。”结果如何？“和菜头”说：“XX妈吓了一跳，道歉，并立即删微博，嘿嘿。”

  

记者昨日联系网友“和菜头”，他并不太愿意接受采访。但他还是说“微博上晒孩子，真的有泄露信息的可能。我只是一个善意的提醒而已。”

  

“和菜头”的提醒或许并不是危言耸听。记者昨日下午，随意浏览30余个地址栏上标明“长沙”的微博。在查看了这些博主的近期微博后，发现有七成博主有在微博上“晒幸福”的习惯。除了晒孩子的照片，一些博主还透露了孩子的学校以及其他家庭成员等重要信息。而这些博主中，很多是经过微博认证的。也就是说，通过博主的微博，可以轻易得知博主、孩子甚至其他家庭成员的姓名，甚至孩子所在的学校。

  

**警方：发微博时不要随意泄露个人信息**

  

“总看到家长们自豪地将孩子的图片作为微博头像，微博里面总会提到自己孩子的名字，提到幼儿园或学校名字，图片经常会暴露自己居住的小区。其实很容易以此汇总出来孩子的名字、家庭住址、学校、相貌、家长从事的工作等。希望家长们能意识到这些是孩子的重要隐私，要掂量后再发帖。”南京市公安局栖霞分局女刑警温秀荣提醒说。

  

温秀荣告诉记者：根据拐卖儿童案件作案手段，犯罪嫌疑人与儿童套近乎的手段，除了糖果、玩具外，还有“我是你妈妈的同事”“你爸爸让我来接你”这类的话。对此，警方提醒：家长将孩子信息发上网将增加泄露孩子隐私的风险，为确保个人生命财产安全，不要随意泄露个人隐私。

  

公安部打拐办主任陈士渠，也转发了“和菜头”的微博提醒网友要注意保护孩子的隐私，发布微博时确需增强防范意识，提防居心不良之人获得隐私信息。

  

**\[提醒\]**

  

**孩子相册，要对陌生人加密**

  

“我给孩子建了一个微博，里面都是孩子的照片，还有就读的小学，日常琐事。”长沙家长张悦（化名）说。当记者告诉她这样做容易泄露孩子的重要隐私时，她表示回去马上把相册加密，并删除有可能泄露关键信息的图片。

  

专家提醒，父母将信息上传至微博，千万要谨慎！如果一个陌生人有意无意找到你的微博相册，而你的孩子照片又赫然在上，那你孩子的照片他就唾手可得了。为防止有人用你孩子的照片做“后续文章”，你应该对个人尤其是孩子的相册加密，杜绝陌生人“偷窥”。

  

更重要的是，不要在微博里留自己的住址和电话号码。

  

记者发现，很多微博都带地理信息功能，这样在微博上容易泄露自己的行踪、家庭住址、单位地址等。

  

**\[案例\]**

  

**照片泄底，儿子遭绑架**

  

根据四川媒体报道，小磊（化名）家住成都市青白江大湾镇，就读小学。小磊在校表现好，2009年底，获得了小红花作为奖励，小磊的妈妈让他胸戴小红花，在教室门口拍了一张照，并将照片发到了网上“晒幸福”。

  

结果，照片被同一社区的小混混张立（化名）看到，张立根据照片中教室门口的表扬榜上的内容，得知了小磊的班级信息。随后，张立多次到小磊就读的学校门口蹲守，每当看到家长接小磊回家，他就上去打招呼，混个脸熟。直到有一天小磊的妈妈有事来晚了，张立就上去把小磊骗走，并向其家长勒索10万元。

  

小磊的家长向大湾派出所报警，警方抓获张立并成功解救小磊。经过审讯，张立交代，他没有固定工作，想挣点“外快”，从网上得知小磊的信息便起了歹心，多次蹲守摸清情况后，就对小磊下手了。
