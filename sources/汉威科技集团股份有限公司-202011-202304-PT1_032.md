# 誓师大会丨2023汉威科技集团营销培训暨营销队伍誓师大会顺利举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657694111&idx=1&sn=28b0973af2f0dda16a319a47cabafaf7&chksm=bd52f8318a25712707e2c9b0891f7e0aadb2e6ad958e993aa5cf85b9d0fe63b1340c80a4724f&scene=126&sessionid=1681218439#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657694111&idx=1&sn=28b0973af2f0dda16a319a47cabafaf7&chksm=bd52f8318a25712707e2c9b0891f7e0aadb2e6ad958e993aa5cf85b9d0fe63b1340c80a4724f&scene=126&sessionid=1681218439#rd)

1月31日~2月2日，2023汉威科技集团营销培训暨营销队伍誓师大会隆重举行。

  

  

  

**Part1  营销培训**

**1**

**营销培训**

![](../Images/3d4a357277c40cb93804854b7d999a98.png)

实战派营销专家

**曾子亮**

![](../Images/6d9900ffcf019e45a782e572971cddaf.png)

工业品实战营销专家

**诸强华**

1月31日~2月1日，知名实战派营销专家曾子亮、工业品实战营销专家诸强华，分别为汉威全体营销人员进行了为期两天的解决方案、工业品营销培训。

![](../Images/601506ef2e44ecafbc96606f4019276f.png)![](../Images/3ab449429549bc5f4ba4ff4aa79cb59b.png)

2月2日上午，汉威内部讲师为大家进行了营销标准化、合同管理与风险管控等相关培训。

  

  

**Part2  董事长战略解读**

**1**

**董事长战略解读**

![](../Images/dde41c068a05ab4859067150ec42d610.png)

汉威科技集团董事长

**任红军**

2月2日下午，汉威科技集团董事长任红军进行《创佳绩 赴山海》主题分享，为来自全国各地的营销精英讲述了集团成长历程和关键节点，分析了集团发展的底层逻辑，解读了未来战略布局，并鼓舞大家勇争潮头，再创佳绩，共赴山海。  

  

  

**Part3  营销队伍誓师大会**

**1**

**主持人开场**

![](../Images/0a72c5aba7b291febb0188825bade664.png)

汉威科技子公司上海英吉森总经理

**张绪文**

2月2日下午，汉威科技集团2023年度营销队伍誓师大会在庄严的国歌声中正式开始。  

**2**

**总裁发布战前总动员令**

![](../Images/2e39acef058d1b8b537550cccf0b5f0f.png)

汉威科技集团总裁

**李志刚**

汉威科技集团总裁李志刚发布战前总动员令，号召全体营销人员紧盯目标，奋力拼搏，不辱使命，在2023年打一场漂亮的攻坚战，为集团争取新的荣光。  

**3**

**年度先进单位表态发言**

![](../Images/20735ced6b9048204f027f66c858f869.png)![](../Images/186cc228b05f36a3e67386340b2355da.png)

畅威物联网、汉威智慧安全年度先进单位代表表态发言，将为实现年度新目标而勠力同心，高歌猛进。  

**4**

**副总裁动员讲话**

![](../Images/84ee10aa10d78e284cd8d912437c92fe.png)

汉威科技集团副总裁

**杨昌再**

![](../Images/18674c66c13d5b89f057ad3176eca543.png)

汉威科技集团副总裁

**尚中锋**

汉威科技集团副总裁杨昌再、尚中锋发表讲话，进一步动员各单位领导团队和一线营销人员，紧抓机遇，敢拼敢干，结果导向，使命必达。  

**5**

**授旗宣誓仪式**

![](../Images/a6960aa6022aacfead5a0c271525b243.png)![](../Images/151cb32b60dd94551d0a71a731558834.png)![](../Images/6e6d1d7c59a1ddf217b299254bdb38d8.png)![](../Images/724257a3e762a36d3068bd5326c701a8.png)![](../Images/05721b9b8281a0b19bf061d7c32b3ccd.png)![](../Images/d1ff10b65b0c2a575c6f117908222264.png)![](../Images/57087b6357f2f45ac20bfc990c33a45e.png)![](../Images/3a6f0b69d0faf032de9122721dd9ca87.png)![](../Images/b7c99ada4cad005b1a7ee8df5e15647d.png)![](../Images/25224e9e9bfc083fcc2a99b870f1e01d.png)![](../Images/d648f00560b843da765c4e9d6c014e26.png)![](../Images/41deb3025b9632b5ee0c62543566c6a1.png)![](../Images/d02d048ca5a4973b5c6a61c8b60767aa.png)

向下滑动查看所有内容

随后，大会进行授旗宣誓仪式。各单位营销团队代表们依次登台，从董事长任红军手中接过大旗并郑重宣誓。这标志着各单位将坚持战略引领，紧盯目标责任，为汉威持续高质量发展奋勇前行。

**6**

**全体大合唱**

  

![](../Images/429d5f25d2730656d614f2f49c066737.png)

全体营销人员齐声高唱，嘹亮的歌声在整个大厅回荡，无不彰显着汉威营销人员们的充沛活力和高昂士气。  

**7**

**大会晚宴**

![](../Images/7eed19ef75fe80be08c80467a2023030.png)

会后，集团为大家准备了丰盛的晚宴，全体营销精英欢聚一堂，举杯同庆，共飨佳肴。  

  

首战即决战，开局即冲刺。2023年已经过去一个月，征程已起，时不我待。在未来的日子里，全体营销人员将奔赴全国各地及海外市场开疆拓土。与此同时，全体汉威人也将保持战略定力，固本拓新高效协同，助力汉威持续开创高质量发展新格局。
