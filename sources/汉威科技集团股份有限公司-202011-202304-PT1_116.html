2022世界传感器大会进入第2天！8月22日的郑州国际会展中心依然人头攒动、热度不减。根据安排，今日进行了多场行业主题报告活动，干货满满。


总

览

备受瞩目


虽然已经是开展的第2天，但汉威科技集团1008展位前的热度依然不减，前来参观、交流的与会者络绎不绝，从了解新品到问询采购，从洽谈代理到商务合作，现场真的是热闹非凡！



万物互联，传感先行。传感器是数据采集的源头，2022世界传感器大会期间，汉威科技集团也展示了众多自主研发的传感器科技、产业和应用的最新成果，营造了优质的交流氛围。



研

讨

高峰论坛


8月22日上午，汉威科技集团总裁李志刚发表了《点线面结合，全域保障油气管网安全》主题演讲，详细阐述了汉威油气管网安全的解决方案，与参会嘉宾共同探讨油气管网安全解决之道，锚定新技术、展望新趋势，描绘产业新蓝图。


//  汉威科技集团总裁-李志刚 //


22日下午，汉威科技集团董事长任红军发表了《传感器生态建设实践》主题演讲，并与参会嘉宾展开深入交流与探讨。报告中有关“传感器生态”的一些新观点、新思路引发了与会人员的热烈讨论，一些事关大众安全的内容也引起了与会者的强烈共鸣，任红军董事长的发言亮点多多，期间观众掌声不断。


//  汉威科技集团董事长-任红军 //


作为国内气体传感的龙头企业，汉威科技集团是“城市生命线”解决方案的实践者和倡导者，汉威凭借在智慧燃气、供排水、智慧热力、智能交通、危化品监管、综合管廊等城市生命线领域强大的产品、技术实力及二十多年的行业经验积累，已经为多个省市公共管理部门提供了完善的城市生命线感知、预警、应急指挥等产品和服务。帮助他们实现了由“以治为主”向“以防为主”转变、“被动应付”向“主动监管”转变，提高了管理部门对城市应急事件的快速反应和协同指挥能力，让科技创新为人民群众的切身安全需求服务。


聚

焦

重磅新品


除了带来了最新研究成果，汉威科技集团发布的新品也是本届传感器大会的重要看点。这次，多款传感器新品重磅亮相。


传感器作为汽车内外环境感知的核心部件，是不可或缺的重要技术品种。汉威科技集团在气体传感器领域深耕多年，在汽车传感器板块也不断突破，为适应市场需求，相继推出多款新品。



此外，汉威科技集团“管网地听”系列新品—WG360智能监测终端也在此次大会亮相。


//  汉威子公司畅威物联网副总、高工-常磊 //


该产品主要适用于城市地下管网可燃气体泄漏监测和预警，采用泵吸式采样方式，内含TDLAS激光检测技术，GPS/北斗定位技术，具有精度高，可靠性强，耐腐蚀，电池用量大等优势；当检测到异常事件时，设备报警，并通过4G/NB-IoT等方式将报警信息上传到平台。平台给就近巡检人员下达现场排查指令，巡检人员到疑似泄漏点排查，将结果上报平台，平台分析判断给出应急预案，实现闭环管理，全面守护城市管网安全。

播

亮点多多


线上直播这也是本次大会的特色之一。


考虑到疫情的原因，很多朋友无法来到郑州参会。为了满足无法到场的朋友们的需求，此次大会仍然设立了数字化展会平台，实现“云预约、云展示、云直播、云论坛”等功能，面向参展企业、观众、嘉宾、媒体及工作人员提供全周期的服务。



除了大会官方直播，汉威科技集团的直播间内也是气氛活跃，互动频频。我们的技术人员从专业角度到应用领域，为线上用户答疑解惑，全方位介绍了汉威科技集团的产品优势与发展前景。同时，大会周边的各种短视频也受到了粉丝们的欢迎，观看量屡创新高。
