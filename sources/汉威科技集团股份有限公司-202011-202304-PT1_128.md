# 消火栓无水=生命无保障！科技如何推进行业发展？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657689022&idx=2&sn=af53b6c76a57857d6316f828de836835&chksm=bd52d4108a255d062ccff136a4bb7e064e0417529f9e9cb51b737f6d5f902cd0de69723e6ee3&scene=126&sessionid=1681218461#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657689022&idx=2&sn=af53b6c76a57857d6316f828de836835&chksm=bd52d4108a255d062ccff136a4bb7e064e0417529f9e9cb51b737f6d5f902cd0de69723e6ee3&scene=126&sessionid=1681218461#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

消火栓是现代居住小区必须配备的消防设施，遭遇火灾时，它是保护居民生命财产的“救命箱”。然而在现实生活中，楼内消火栓无水已是“常态”，火灾隐患令人担忧！

  

**案例一：**

**家中起火消防救援，消火栓却“滴水不漏”**

  

![](../Images/30053064ba3db475df86ec5d138af04e.png)

//  图源：湖南都市 //

  

据湖南都市报道，7月30日早上8点，长沙某小区一居民家中发生火灾，随后消防人员火速到达现场，救援时却发现楼道里的消火栓竟然没水，无奈之下消防员只好从水箱消防车里引水施救。事后居民发现，每层楼的消火栓都没有水，这么多年来原来小区消火栓只是“装饰品”。

  

**案例二：**

**小区消火栓无水，业主担忧消防安全隐患**

  

![](../Images/9937689f4bf41c89e10fd06fa15b44d5.png)

//  图源：十堰广播电视台 //

  

据十堰广播电视台8月6日报道，十堰一小区消火栓长达20年无水，无奈业主向新闻热线反映。更令人不解的是，箱上贴着的检查记录却标注有“消火栓一切正常”的字样。

  

**关于消防救援的误区：**

人们普遍认为，只要消防车到达火场，就可以立即出水把火扑灭。其实不然，小区高层住户发生火灾时，消防人员首先会用小区楼层内的消火栓进行灭火，如果消防栓无水，就只能用消防车上的水。由于消防车内还要装灭火泡沫，消防车自备水不多，这时，消火栓就发挥出巨大的供水功能。

  

消火栓是现代消防设备中最重要的一环，如何有效解决消防用水因压力不足造成的“建而无水”、“建而少水”，无法有效支撑现场救援用水等现象，以及消防部门对消防用水基础设施“坏而不知”等的现象？

  

**汉威智慧消防给水监测系统**

  

![](../Images/8a6f2f3426848a297398dc77e50514c5.png)

  

汉威智慧消防给水监测系统通过在关键部位，如：消防水池、消防水箱、最不利点消火栓、喷淋末端试水装置安装自主研发的液位或压力传感器，利用物联网技术实时监测，实现对消防供水设施关键参数连续收集。针对出异常情况实时推送警示提醒信息，定期形成运行报告，主管单位、维护单位、监管部门可以通过授权实时掌控消防供水系统的状态。

  

![](../Images/8d24b392b8db232129b034f87f7e4c9c.png)

// 系统架构图 //

  

**主要功能**

  

1

**实时监控**

  

24小时监测消防末端（如消火栓、喷淋装置）水压、水箱液位实时状态信息。

  

2

**报警提醒**

  

发生液位不达标、压力不达标等情况时，将预警故障信息以APP/短信/平台等方式推送至相关值班及负责人员，提醒及时采取相应措施消除隐患。

  

3

**GIS定位**

  

对智能消防用水监测系统的智能设备的进行地图定位，可快速查找安装位置以及设备信息。

  

4

**历史记录**

  

所有告警信息及平台操作记录均被写入日志，并可供用户查询调阅。

  

5

**数据分析**

  

对设备采集、巡查、维修等数据进行综合性的分析，生成报表，方便综合分析和处理。
