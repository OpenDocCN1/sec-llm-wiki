近日，人民日报发布了题为《多措并举确保燃气安全》的文章，从多个方面阐述了燃气安全现状及解决方案，其中提到：“要有序推动全面安装燃气报警器，充分发挥燃气报警器的安全预警作用。”




//  图源：应急管理部官网 //


近年来，燃气事故屡见不鲜，绝大部分的燃气事故都发生在燃气的使用端，如居民家庭、餐饮店等，这些事故造成了不同程度的人员伤亡和财产损失，使得燃气安全成为社会高度关注的话题。随着燃气安全整治力度的加大，强制性或推广性要求安装燃气报警器已成为政府保护人民生命财产安全的一些强有力的措施，地方政府立法将是一种趋势。


燃气报警器是重要的燃气安全设备，其预防爆炸危险的原理主要有三点：提前感知、及时提醒、应急措施，其核心便是气体传感器，俗称“电子鼻"。当"闻"到泄漏的燃气时，传感器电阻随燃气浓度而变化，达到一定浓度时，报警器就会发出报警信号来提醒用户及时处理燃气泄漏，同时将信号传输至紧急自动切断装置，切断燃气供给，大大降低燃气事故发生率，保障用户的人身和财产安全。燃气报警器种类繁多，应用领域广泛，针对不同的使用场景，我们要如何选择燃气报警器呢？



家

庭

诸如小型餐厅或家庭可以选择独立的可燃气体探测器，既可以大大降低安装成本又能有效避免由于气体泄漏而引发的火灾、爆炸、中毒等恶性事故的发生。


//  家庭型燃气报警器安装示意图 //


在燃气或一氧化碳存在的场所，一旦燃气浓度或一氧化碳浓度达到报警设定值，家用探测器将发出声光报警信号，迅即采取有效措施。同时启动联动装置，通风或关闭气源，排除险情，有效避免由于气体泄漏而引发的火灾、爆炸、中毒等恶性事故的发生。




餐

饮

● ●


和家用场景的燃气泄漏报警系统一样，餐饮领域应用的报警系统也能够在刚发生泄漏的时候发出警报提醒和切断燃气阀。不同的是，餐饮燃气泄漏报警系统还可以根据使用需求，联动安装防爆风机，用于发生泄漏时及时抽掉泄漏的天然气。



针对餐饮企业燃气安全防范问题，汉威餐饮系列燃气安全监管解决方案，通过信息化手段对接入的物联网设备进行监管和预警提醒，具备现场报警、短信通知、微信推送、电话通知等多种预警方式。健全的燃气报警管理体制为居民用户、餐饮企业、工商业用户、大型综合体等应用场所提供7*24小时不间断监测服务，帮助减少燃气爆燃、爆炸事故。


然而，即使安装了燃气报警器也并非就意味着高枕无忧。


目前燃气报警器市场上假冒伪劣产品鱼目混珠。据统计，全国约有150余家专业燃气报警器生产厂商取得计量器具型式批准证书，但仍有不少厂家无证生产燃气报警器，产品质量得不到保障，这类产品在厨房高温、潮湿、油污等环境下，其内在的气体传感器在短期内就容易损坏，会出现误报警或不报警的问题，这就意味着家中燃气报警装置无法有效感应泄漏的燃气。因此，我们在购买相关燃气报警器产品时，还要注意筛选相关生产资质。
