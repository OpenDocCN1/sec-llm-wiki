# 宁波国际照明展第1天，炜盛科技看点来了！

7月18日，宁波国际照明展盛大开幕，作为汉威科技集团旗下专业的传感器制造商——**炜盛科技****2A08**展位有哪些精彩瞬间不容错过？带你到现场看看！

  

  //  

**传感器解决方案**

**1、智能灯具**

![](../Images/3ae43b30ae528ceebbfaa35b07eb1f58.png)

**热释电**

传感器

![](../Images/e5a84ab6e37f44a18e635697635317dc.png)![](../Images/0e91c61b52cab50115ca9648382fca6b.png)![](../Images/c6972b67a4562dde5ae0bd7d38587654.png)

炜盛科技自主研发的模拟热释电、数字热释电产品广泛应用于小夜灯、吸顶灯、太阳能壁灯、庭院灯等各类智能灯具中。

  

本次宁波照明展中，除了原有的模拟热释电热销产品RD-623/624/626W和数字热释电产品RDB/RDA-F系列，还重点展出了新推出的四元热释电RPTA-646/RPTD-646系列产品，同时提供热释电芯片、透镜及解决方案。

![](../Images/04ee075b33fd2130146c3c98b93b6996.png)![](../Images/9d1fe39cc916468dc5d3d1b5b049d994.png)

**展会**

**现场**

![](../Images/5ef06134d684a8fd59a8a1926056b6cb.png)

**2、智能家居**

  

展会现场还展出了综合红外热释电、热电堆及环境监测类传感器的智能家居解决方案。重点展出在净化器、宠物用品、智能门铃、智能门锁、微波炉、烟机等产品中应用的各类传感器，为观展人员展示介绍传感器在智能控制及节能方面的作用。  

  

![](../Images/8ea7e726cebd3d91105f6dafc30b25a3.png)![](../Images/1a54e849f6639fd95d66a1aa30cb679c.png)

**盛**

**3、智慧生产**

  

基于20多年的传感器研发、生产经验，汉威科技集团也在展会现场带来了应用于智慧消防、智慧农业、智慧工业各领域的传感器产品及解决方案，充分展示了作为国内传感器龙头企业的综合实力。  

  

![](../Images/bb971f859ca16b23477ea5d47e90ed2b.png)![](../Images/32e877c1529afa2a05ac50c99bb0a84e.png)
