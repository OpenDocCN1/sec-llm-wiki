# 【行业关注】北京市率先完成危化品企业双重预防机制数字化建设工作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657686910&idx=2&sn=b3419a018741b7d7d8f729e1b5c791ac&chksm=bd52dcd08a2555c6144e64d0be0cf2d9e686c1703261f6e64308ba58fb1762335cdf4182ddb0&scene=126&sessionid=1681218465#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657686910&idx=2&sn=b3419a018741b7d7d8f729e1b5c791ac&chksm=bd52dcd08a2555c6144e64d0be0cf2d9e686c1703261f6e64308ba58fb1762335cdf4182ddb0&scene=126&sessionid=1681218465#rd)

文章来源： 北京应急

![](../Images/5bb328177c4eb6d8b3823ea1fd7fd2e5.png)

  

为贯彻落实《全国危险化学品安全风险集中治理方案》（安委〔2021〕12号）和本市实施方案，扎实做好本市危险化学品安全风险集中治理，提升危险化学品企业数字化、信息化管控水平，市应急局在全市范围内开展危险化学品重大危险源企业双重预防机制数字化建设工作。目前，全市38家重大危险源企业双重预防机制数字化建设工作已经全部完成，运行效果实现优良，在全国率先完成建设运行任务。

  

![](../Images/1b37df08aef4999f0305942c94a0f3ad.png)![](../Images/32af0f1ce802373d794ef43647c21dab.png)

// 图源：北京应急管理部 //

  

**01**

**总体情况**

  

2022年3月至6月，市应急局组织全市38家危险化学品重大危险源企业开展双重预防机制数字化建设工作，并于6月19日全面完成系统部署，实现风险清单全部制定、清单内容全部录入、系统建设全部完成、数据对接全部成功，在全国率先完成建设任务，同时实现运行效果优良。

  

**02**

**主要做法**

  

**高度重视**

**01**

加强领导。成立工作专班，推进工作开展。明确专人负责，划定工作片区，对每个区，市应急局安排1名工作人员实时跟踪掌握各区工作开展情况，协调解决各区工作推进中出现的问题。

**02**

明确任务。按照应急管理部工作要求，结合本市实际，制定并印发了实施方案，将全市38家重大危险源企业纳入建设范围，明确双预防数字化建设工作流程、时间节点和重点要求。

**03**

强化考核。将双预防数字化建设工作纳入对本市各区政府安全生产年度综合考核，要求各区、各企业将双预防数字化建设作为深入开展风险集中治理、落实企业主体责任、提升安全管理水平的重要举措。

**定期调度**

**01**

建立月报机制。强化工作统筹，4月起，要求各区每月报送整体工作进展，每周梳理企业工作进度，市应急局汇总后，对工作推进不力的区和企业进行通报。

**02**

严把顶层设计。在5月20日和24日，用两天时间对38家企业的工作方案进行逐家调度，提出建议，现场进行指导帮扶。

**03**

实施高频调度。为加快推进工作进度，从6月起，坚持每日调度、总结，实施高频通报。6月份，全市共调度总结25次，通报工作进展14次，对工作进展快、质量高的企业进行点名表扬；对进展慢、态度消极的企业，进行通报批评、约谈教育乃至行政处罚。

**强化指导**

**01**

开展专题培训。邀请应急管理部化学品登记中心的相关专家，对本市建设企业开展集中专题培训，指导企业科学编制风险清单，同时对企业建设工作方案以及工作中存在的问题进行指导、点评和答疑。

**02**

组建专家队伍。组织成立了北京市双重预防机制数字化建设专家组，通过包片分工，指导各区、各企业开展双预防数字化建设工作。

**03**

强化现场指导。6月以来，积极开展现场指导帮扶，赴各区重点建设企业开展指导服务工作9天，现场指导企业19家，有效促进各企业建设问题解决与工作落实。

**04**

开展试点帮扶。去年本市有6家企业开展了双预防数字化试点建设，今年采取结对子的方式，安排这6家试点企业与其他企业对接，开展指导和帮扶，重点指导风险清单编制和清单录入信息化系统。

**突出重点**

**01**

关注自建系统进度。对自建系统的燕山石化公司进行实地调研，了解企业在建设、运行过程中遇到的难点问题。疫情期间，通过视频调度的方式，线上跟踪全市7家自建系统企业的建设进展。6月以来，逐家开展现场指导服务，指导企业风险清单编制、数据对接等工作。

**02**

压实企业主体责任。今年以来，共组织召开7次双预防数字化建设调度和培训会议，均要求企业主要负责人参加，切实落实“一把手”工程的要求，提高企业主要负责人的重视程度。

**03**

指导清单系统录入。积极联系应急管理部化学品登记中心的相关负责人员，编制风险清单线上录入指导手册，同时通过视频会议的形式，现场教学风险清单录入系统的详细操作流程，将录制的教学视频发送给各企业进一步深化学习。

**典型引路**

**01**

对在双预防数字化建设过程中，工作质量高、工作进展快、运行效果好的燕山石化公司、中航油（北京）机场航空油料有限责任公司等企业，通过官微、媒体等途径进行广泛宣传，发挥典型带动作用，及时推广双预防数字化建设工作的典型做法。同时，结合本市实际，进一步拓宽建设范围，鼓励中石化催化剂北京奥达分公司、北京八亿时空液晶科技股份有限公司等非重大危险源重点化工企业，结合企业风险，向前一步，提前谋划，积极开展双预防数字化建设工作，提升企业安全管理水平。

**02**

下一步，市应急局将加大工作力度，严格工作标准，持续开展定期调度和现场指导服务，及时解决企业问题，优化风险清单编制质量，督促企业扎实开展隐患排查任务，严格做好隐患整改闭环管理，保持系统运行效果优良，充分发挥双重预防机制数字化建设在危险化学品安全监管工作中的作用，有效防范化解危化品安全事故发生，为党的“二十大”召开营造良好的安全环境。
