# 汉威燃气安全解决方案，为“城市生命线”打造看得见的安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657686830&idx=2&sn=0f472fbb51ad91d971e6d1efc3041c79&chksm=bd52dc808a255596c82238e2d0c8741226a2e9d31214b98562f0a303074c6ba86951a89e50b7&scene=126&sessionid=1681218465#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657686830&idx=2&sn=0f472fbb51ad91d971e6d1efc3041c79&chksm=bd52dc808a255596c82238e2d0c8741226a2e9d31214b98562f0a303074c6ba86951a89e50b7&scene=126&sessionid=1681218465#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

作为现代“柴火”，燃气管网犹如城市的大动脉，遍布整个城市的地下，成为城市名副其实的“生命线”。由于燃气管道输气压力较大，所处环境受温湿热变化和地面道路车辆碾压等影响，管线破损、腐蚀、泄漏等事故易于发生。一旦发生事故，其后果不堪设想，还容易衍生引发大面积停水积水、停电停气等问题，严重影响人民群众的生活保障。

  

![](../Images/295df2cf4c15c8f67fb5d0af8e1bb960.png)

//  图源：网络 //

  

据统计，百分之七十的燃气管网事故都是微小泄漏长期积累而引起的，这些微小的燃气管道泄漏，其“不安全状态”依靠传统的人工检测手段难以做到快速、精准的发现，容易让“小患”积成“大祸”。作为城市生命线工程的一部分，燃气监管平台应运而生，从前端感知、风险预警到专业评估，为城市生命线燃气安全提供强有力的守护。

  

  

**汉威城市生命线  **

**燃气安全解决方案**

  

![](../Images/9ed6d9480a3b67f486a8a4fc7b0c09e3.png)

  

汉威城市生命线-燃气安全解决方案本着“预防为主，综合治理”的原则，通过**建设城市燃气地理信息系统（GIS政府版）、城市燃气安全生产监督管理系统、城市燃气应急管理系统、移动管理平台**4个业务子系统来实现燃气行业的安全监管。

  

**城****市燃气地理信息系统（GIS政府****版）**

  

城市燃气地理信息系统（GIS政府版）包括：燃气管网设施GIS数据、场站GIS 数据、燃气设施工程建设GIS数据、安全隐患GIS数据、燃气事故发生点GIS 数据、抢险抢修中心GIS数据等能够反映行业基础设施、管理资源状况的静态或动态GIS数据，**实现燃气行业管理事件和事务型业务信息的“一张图”管理和整合模式**。在提高燃气日常运行信息化管理水平的基础上，提升应对各类突发事件响应处置效能，从而实现城市燃气智慧管理和科学决策。

  

  

  

  

![](../Images/f20068ecc08e4305cbc57b415538591e.png)

**城****市燃气安全生产监督管理系统**

  

以辨识、管控安全风险为重点，实施企业分级分类管理，以安全隐患排查标准清单为依据，以开展企业自查自改自报、行业管理机构指导、考核、执法为核心，通过系统可全过程记录报告安全隐患排查和治理情况，建立燃气行业安全生产差异化监管工作体系，全过程记录报告安全隐患排查和治理情况。

  

  

  

  

![](../Images/686fae82ced05488db49497dc74b4bd3.png)

**管****网安全监测系统**

  

管网安全监测系统是针对燃气公司管网安全的辅助监测方式，通过监测密闭空间如：燃气阀门井的气体浓度，大用户调压柜、调压箱的进出口压力值，工商业用户、公福用户、民用户的流量值等参数，来实现燃气泄漏、设备故障、漏气盗气的分析预警功能，从而最大程度上减少安全隐患，降低经济损失，提高经济效益。

  

  

  

  

![](../Images/c513b57c61ae5966540120f9531b1dae.png)

// GIS一张图总览功能 //

  

![](../Images/7d8903df4b14f023ce573d2822a0e70d.png)

//  管网物联网安全监测设备应用场景 //

**用****户燃气泄漏安全云报警系统**

  

燃气安全云报警系统由燃气报警器、监控软件平台、服务器、切断阀等组成。综合利用GIS技术、通讯技术、数据库技术、互联网技术等最新成果，针对燃气泄漏的监管需求，打造了**具备燃气泄漏数据即时上传、数据统计分析研判、短信通知**等功能。应用现场报警、手机短信、自动拨打电话、微信、APP推送等多种方式保障用户燃气安全。

  

  

  

  

![](../Images/80626e8188b7ce9e708cfc8a2236e67c.png)

//  基于GIS的展示 //

  

![](../Images/409590ff2bce86d1d7c8f5e5e6540206.png)

//  工商业安全监测设备应用场景 //

目前，该系统方案已经成功应用于厦门、杭州、南京、长春、呼和浩特等多个城市，有效地加强对城市燃气安全的管理，防范事故于未然，保障管网的安全和稳定供气，为“城市生命线”打造“看得见”的安全。
