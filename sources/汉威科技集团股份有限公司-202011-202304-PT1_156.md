# 汉威科技与汉威传感基金合作伙伴开展传感器产业对话交流活动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657686625&idx=2&sn=b609f90ec3a7d52c39109d2634c06818&chksm=bd52ddcf8a2554d9bda3f0d5af2a878d1921e561b20a07799494b21ca52688ee645904b35dc9&scene=126&sessionid=1681218465#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657686625&idx=2&sn=b609f90ec3a7d52c39109d2634c06818&chksm=bd52ddcf8a2554d9bda3f0d5af2a878d1921e561b20a07799494b21ca52688ee645904b35dc9&scene=126&sessionid=1681218465#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

7月5日，河南高科技创业投资股份有限公司（简称“河南高创”）总经理李贞和、副总经理倪政委及投资部门的相关人员，与郑州高新产业投资集团有限公司（简称“高新产投”）产业规划部经理张柯、合规风控负责人宋俊丽及相关人员一行莅临汉威科技集团参加传感器产业对话交流活动。汉威科技集团董事长任红军、首席专家张小水、副总裁兼董事会秘书肖锋、副总裁金贵新、投资总监巩超、集团研究院副院长刘建钢以及北京威拓私募基金管理有限公司的基金团队成员参与了此次活动。

活动伊始，董事长任红军详细介绍了传感器的概念及应用、行业发展现状、面临的挑战和机遇，并分享了汉威科技集团在传感器产业二十余年的发展经验。随后，各方就各自对传感器产业发展的理解、相关领域的投资经验、资源优势以及如何围绕传感器上下游产业链寻找与汉威产业发展契合的优质投资标的进行了深入的对话交流。

  

![](../Images/bae160f12eb99ef6fe427acb2fccadf6.png)

//  汉威科技集团董事长 任红军 //

  

此次交流活动，不仅加深了各方对传感器行业及汉威传感器产业发展的理解和认知，同时也凝聚了各方在正式开展投资合作前的业务共识。新形势下，各方将释放专业能量，形成资源互补，共同围绕汉威传感器核心产业进行延链补链强链，全面提升产业发展能力，带动智能传感器全产业链高质量发展。

  

![](../Images/3b54abfc366fd24e5ffb4ea91c8d0a70.png)

  

不久前，公司与高新产投、郑州产投股权投资引导基金合伙企业（有限合伙）（简称“郑州产投引导基金”）、河南省农开创业投资引导基金合伙企业（有限合伙）（简称“农开创投引导基金”）共同投资设立郑州汉威传感创业投资基金合伙企业（有限合伙）（简称“汉威传感基金”）。公司作为汉威传感基金有限合伙人之一，使用自有资金认缴出资29,500万元，认缴出资比例59%。农开创投引导基金、郑州产投引导基金分别为河南高创、高新产投受托管理的基金合伙企业。
