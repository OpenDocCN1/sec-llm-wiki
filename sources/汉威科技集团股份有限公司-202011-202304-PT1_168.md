# 燃气管道改造方案印发，城市燃气安全发展路在何方？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657685087&idx=1&sn=7a978706f0cbef2e1e529cbd0751e29d&chksm=bd52c7f18a254ee701c82ff76092a6d96886453f413250dd80b9c2acd12ee652a92407ff199e&scene=126&sessionid=1681218469#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657685087&idx=1&sn=7a978706f0cbef2e1e529cbd0751e29d&chksm=bd52c7f18a254ee701c82ff76092a6d96886453f413250dd80b9c2acd12ee652a92407ff199e&scene=126&sessionid=1681218469#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

国务院办公厅近日印发《城市燃气管道等老化更新改造实施方案（2022－2025年）》。在新改造标准的制定上，《实施方案》强调要结合更新改造同步**在****燃气管道重要节点****安装智能化感知设备**，完善智能监控系统，实现智慧运行，完善消防设施设备，增强防范火灾等事故能力。

  

![](../Images/026d482a9a8a345c435f2cdc70ed9050.png)

  

截至2020年，我国城市燃气管道长度累计86.44万公里。近10年，城市燃气管道长度复合增速达到 10.85%。应急管理部安全协调司司长苏洁曾表示，“初步统计，现在全国已有近10万公里管道出现不同程度老化，再加上当时建设标准比较低，日常维护、保养、更新不及时，现在这方面的风险挑战非常大。”

  

众所周知，城市燃气是通过地下管网输送到用户端。随着埋地管线的数量激增，地下管网的管理和维护难度升级，管线隐患风险也随之增多。在燃气行业快速的发展过程中，**以“可视化”为主线，****通过****在市政燃气井布局相关气体监测终端**，连接从前端感知到数据分析，有效聚焦地下管道的实时监测，提高燃气管网安全、改善管理手段是发展智慧燃气的命脉所在。

  

![](../Images/1a6e1d51617688804c517e1658961acd.png)

// 汉威气体监测终端系列产品 //

  

除此之外，《实施方案》还提出**推进数字化、网络化、智能化建设，完善燃气监管系统**，将城市燃气管道老化更新改造信息及时纳入，实现城市燃气管道和设施动态监管、互联互通、数据共享。

  

![](../Images/67cfb3b950f0e26908f37f5490b743f8.png)

  

在夯实安全基底、提升燃气管理水平的大背景下，传统的燃气巡检模式正向智慧化信息化方式靠拢。通过各类智能巡检终端的应用，结合GIS管网信息，**实现管网巡检的可视化、数字化、可量化**，从而有效保证管网设施的日常安全，提升输气可靠率，确保燃气管网安全运行。

  

![](../Images/485fb8cee19ebddf2bbaba19c175392c.png)

// 汉威燃气管网巡检系列产品 //

  

燃气安全涉及建设、经营、输送、使用等各个环节，除了提高家庭、单位燃气用户的燃气安全意识外，相关企业、部门建设燃气管网数字地图和风险监测预警平台，加强对燃气常态化安全监管也是燃气安全监管中不可或缺的一环。

  

![](../Images/abf80c7254187068fbcbd38ef6cba5c3.png)

//  汉威智慧管网安全监测系统 //

  

智慧化燃气管网安全监测系统通过增加智能传感器，利用物联网技术，可提供7\*24小时不间断监测服务，实现对燃气管网的位置、分布和燃气浓度等信息进行监管和预警提醒，帮助减少燃气爆燃、爆炸事故。

![](../Images/33309e4f489a2c0ffabc4b0158f1b13b.png)

燃气监管、信息更新都离不开传感器的连接作用。作为国内知名的气体传感器及仪器仪表制造商、物联网解决方案提供商，汉威科技集团深耕燃气行业20余年，完善的智慧燃气信息化解决方案已成功应用于厦门、杭州、南京、长春、呼和浩特等多个城市。未来，也将积极响应国家号召，配合燃气安全隐患排查整治工作，用优质的产品和服务为用气安全再上一道“阀”。
