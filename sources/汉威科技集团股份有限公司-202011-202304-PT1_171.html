汛期来临，如何让城市不再“看海”?

原文：http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657684971&idx=1&sn=aeefc45a9d18a39799c8347bfc64b5c6&chksm=bd52c4458a254d5361f9b274b4a3de716ba8449e6ea41297eb85e8d635d5a8bb659e33ba90af&scene=126&sessionid=1681218469#rd


近日，住房和城乡建设部、国家发展改革委、水利部3部委印发《“十四五”城市排水防涝体系建设行动计划》，从全面排查城市防洪排涝设施薄弱环节、系统建设城市排水防涝工程体系、加快构建城市防洪和排涝统筹体系、着力完善城市内涝应急处置体系、强化实施保障5个方面，提出20项工作任务，并明确相关部门责任分工。



随着夏季到来，“下雨就看海”成为很多城市面临的共同话题。相关统计数据显示，2010年以来，我国平均每年有185座城市受到城市内涝的威胁，济南“7·18”特大暴雨、北京“7·21”特大暴雨、郑州“7·20”特大暴雨造成了不同程度的环境破坏、经济损失和人员伤亡，而这样的痛感实在不该被我们淡忘。



统计显示，当积水深度达到20厘米时，行人步行困难；超过30厘米时，机动车难以行驶；超过80厘米时，交通完全瘫痪。城市内涝使轨道交通等地下设施积水倒灌浸泡的隐患空前增大，不仅造成财产损失，甚至会威胁生命安全，严重影响“城市生命线”正常运行，所以加强城市内涝事件应急管理迫在眉睫。


汉威城市内涝监测预警系统 system 

打造“城市内涝监测预警”一体化解决方案，通过加强“家底摸查清晰、数据汇聚融合、智能分析算法”等手段，辅以物联感知网、大数据、AI智能技术，形成“1网、1图、1脑、N应用”的总体架构，构建全面覆盖的“平时监测、战时指挥、平战结合”的内涝预警预报系统。


一网 / 城市内涝物联感知网



根据城市内涝防治需求及排查统计出的历史积水点、内涝隐患点的相关信息，在现有物联感知设备基础上补充点位，增加液位、电子水尺、积水点监控视频等监测设备，完善城市内涝监测感知体系。


一图 / 城市内涝监测预警要素一张图



基于地理空间资源、防汛应急预案、救援力量等数据，以地理信息技术为基础，整合内外部资源，形成包括管网设施GIS数据、积水区域GIS数据、救援物资管理GIS数据、安全隐患GIS数据等能够反映基础设施、管理资源状况的静态或动态GIS数据，实现管理事件和事务型业务信息的“一张图”管理和整合模式。


一脑 / 城市内涝态势感知



根据城市现有管网数据、高程数据，对汛期中排水能力进行分析，为城市内涝预警的推送、出行研判提供数据支撑。通过模拟各种工况下排水系统的运行状况，可以分析评估排水系统运行现状，预测区域内过流能力以及排水能力。并且在水力模型平台上实时推算、展示区域内的未来积水情况。


N项 / 综合应用



通过气象六要素、实时雨量、天气预报、水文信息、桥涵洞监测、危险区域分析、地面地下预警等模块，将城市内涝预警平台产生的预警预报信息与应急救灾机制、网格化基层工作体系相结合，做到预警预报事件及时推送至相关行业主管部门，实时处理预警信息并跟踪事件处理状态，最终通过通行研判模块形成城市道路积水情况一张图，及时掌握城市道路通行情况，足不出户即可全面掌握城市内涝积水信息。



治理城市内涝事关人民群众生命财产安全，既是重大民生工程，又是关乎“城市生命线”重大发展工程。城市内涝治理问题并非一朝一夕之事，是持久战而非速决战。需要伴随城镇化发展持续推动，除了加强城市基础设施的建设与完善外，在这个基础之上，还要久久为功，持续加强城市建设的系统性、整体性和协调性，不断提升城市防洪排涝能力和预警能力，让城市不再“看海”。
