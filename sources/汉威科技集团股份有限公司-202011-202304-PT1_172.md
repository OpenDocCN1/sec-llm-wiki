# 【专业贴】住在高层的朋友，二次供水的真相你需要知道！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657684790&idx=2&sn=414f7a3fd6eff89007b50ec1867cc088&chksm=bd52c4988a254d8ed91bd4c7dd7cc25562c30b54288b5820aa6b5a6d37128615d7318fc8ebfd&scene=126&sessionid=1681218469#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657684790&idx=2&sn=414f7a3fd6eff89007b50ec1867cc088&chksm=bd52c4988a254d8ed91bd4c7dd7cc25562c30b54288b5820aa6b5a6d37128615d7318fc8ebfd&scene=126&sessionid=1681218469#rd)

供水是城市居民生活的重要保障，当城市人口越来越多、建筑越来越高，市政管网供水压力不足，无法满足高层居民用水需求的问题也日益突出。

  

![](../Images/b0ce099f31d154eeaf00e31213c61924.png)

  

目前，二次供水是解决高层建筑供水的唯一方法。二次供水是指单位或个人通过存储、加压，然后通过管道重新提供给用户使用的形式。通常来说，**建筑的第一层至第6层是市政直接供水区域，第7层至第15层是二次供水加压中间区域，15层以上则被称为高压供水区域**。  

  

二次供水设施直接关系到二次供水水质、水压和供水安全，与人们生活质量直接相关。目前，为了不影响城市居民用水，国家不允许在市政管网上直接安装生活和生产水泵，那该如何将供水设备串联到市政供水管网，既能够充分利用原有压力，同时又不产生负压呢？  

  

这就离不开无负压供水系统了。无负压供水设备是一种加压供水机组，直接与市政供水管网联接、在市政管网剩余压力基础上串联叠压供水来确保市政管网压力不小于设定保护压力（设定压力必须高于小区直供区压力需求，一般不低于1.2Kg）的二次加压供水设备。它是为解决由于压力不足，无法到达用户用水的高度或流量，而专门研发设计的新型环保节能的专业设备。

  

![](../Images/dbc0774d9bf74ce48c70c9e798ce908c.png)

//  图源：网络  //

  

无负压供水系统主要由无负压稳流罐、压力罐（隔膜式或气囊式膨胀罐）、无负压控制柜、水泵、电机、过滤器、倒流防止器、压力传感器、电接点压力表、管路组件、底座等组成。通过安装在供水管网上的高灵敏度压力开关或压力传感器等，来检测供水管网在用水量变化时的压力变化，不断的向微电脑传输变化的信号。

  

可以看出，**压力传感器是无负压供水设备的重要组成部分之一**。当用水量发生变化时，压力传感器检测到供水管网的压力变化，并将变化信号连续输出给控制系统，系统根据不同的运行工况，动态控制补偿量，实现动态压力平衡，保证供水管网压力恒定，来满足用户用水需求。相对于需要经常更换的远程压力表来说，**使用压力传感器不仅可以解决供水不稳定的问题，还可以降低售后维护成本**。
