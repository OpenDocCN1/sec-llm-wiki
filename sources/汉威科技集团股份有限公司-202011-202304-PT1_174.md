# 新国标发布，危化品企业气体检测传感器如何选型？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657684696&idx=2&sn=bffeb178c669010f974857d9f281f937&chksm=bd52c5768a254c602dadcf8bd9e9d4eb19f02e0a55f076566c8757cb9262381d7cb94e086ea9&scene=126&sessionid=1681218469#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657684696&idx=2&sn=bffeb178c669010f974857d9f281f937&chksm=bd52c5768a254c602dadcf8bd9e9d4eb19f02e0a55f076566c8757cb9262381d7cb94e086ea9&scene=126&sessionid=1681218469#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

应急管理部组织修订的国家标准《危险化学品企业特殊作业安全规范》（GB 30871-2022）已正式发布，将于2022年10月1日实施。修订后的新标中，多次提及**生产、经营（带储存）危险化学品的企业和化工及医药企业**，在作业中需**配备移动式气体检测报警仪等设备****对可燃气体、有毒气体及氧气进行浓度监测。**

  

![](../Images/73e3e09e98300bccd892f51bc4e94be5.png)![](../Images/20f87ccbb921ceca56c0af10845ae12e.png)![](../Images/efedac645f7595b74037da924af2148e.png)![](../Images/712ed2990449787c1e716b836f7e0ae5.png)

//  图片截取自：国家标准全文公开系统网站 //

  

对于危化品企业来说，安全生产的风险和安全工作的重要性就更甚于其他一般的企业，安全生产的重要性是不言而喻的。那么，我们如何才能抓好安全生产工作，精准检测气体浓度呢？

  

✦

**危险化学气体检测**

✦

  

**可燃气体**

  

**红外可燃气体传感器**具有量程范围宽、选择性好、抗干扰能力强等特点，适用于碳氢化合物的检测，可用于便携式检测仪和在线探测器等设备。

  

**载体催化元件**则适用于石油、化工等多种工业领域爆炸下限阀内内的易燃易爆气体或有机蒸汽的检测。可检测烷烃类气体、稀缺类气体、醇、醚、醛、酮等有机蒸汽以及苯、甲苯、二甲苯、汽油、柴油等有机蒸汽。

**可燃气体传感器**

  

**毒性气体检测**

  

毒性气体检测推荐使用**ME系列工业级电化学气体传感器**和**MQ系列工业级半导体气体传感器**。其中，ME3系列适用于便携式仪表，ME4系列适用于便携式仪表和在线探测器，MQ系列适用于硫化氢、氨气、有机蒸汽、卤素等有毒气体的检测。
