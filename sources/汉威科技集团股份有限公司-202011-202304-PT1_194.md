# 盘点丨智能家居中常用的传感器有哪些？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657683533&idx=2&sn=303e5e3999490825d11f9b7388edbe22&chksm=bd52c1e38a2548f5c40a2232b88b4faf6da3d07ab89f6dd78b8182e783f458682106bf714472&scene=126&sessionid=1681218473#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657683533&idx=2&sn=303e5e3999490825d11f9b7388edbe22&chksm=bd52c1e38a2548f5c40a2232b88b4faf6da3d07ab89f6dd78b8182e783f458682106bf714472&scene=126&sessionid=1681218473#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

智能家居是个系统的产品概念，而传感器是把传统家居设备如门窗、灯光等连接起来的“桥梁”。通过各式各样的传感器设备，实现了智能家居的场景化，也让用户真正享受到智能家居带来的乐趣。

  

那智能家居常用的传感器都有哪些？一起来看一下吧！

  

  

**01**

**气体传感器**

  

在居家生活中，可燃气体以及污染气体是影响人们身体健康的重要因素。

  

在智能家居中，通过气体浓度传感器，可以实现对危险气体的分析，从而可以采取针对性的控制策略，这也是维护家庭生命安全，将危险消灭在未发生时期的重要环节。

  

![](../Images/191f8e42c5c3406d4db04608100935d1.png)

**图丨一氧化碳传感器/MQ-4**

  

![](../Images/7e821e6c2ac5b4cd7fe69d44f197179b.png)

**图丨甲醛传感器/ZE08-CH₂O**

  

  

**02**

**温湿度传感器**

  

家庭环境中的温湿度条件，不仅关系到家庭环境的质量，更与人体健康紧密相连，可以说是智能家居中至关重要的一环。

  

在智能家居中，通过对温湿度的实时监测与调节，可以营造舒适的居住环境，带来良好的居家体验。

  

![](../Images/957558b06ce834f86435de012969f6d6.png)

**图丨温湿度模组/ZS03**

  

  

**03**

**气体传感器**

  

在智能家居领域，很多场景都可以通过人体感应来识别和控制，无论是人体感应的门、灯、窗帘，还是带红外开关的电器设备的开启与关闭，这些功能的实现离不开红外传感器技术的支持。

![](../Images/861d8edb824ade38f1cafb714be8e1b4.png)

**图丨红外热释电传感器/RDA226**

  

  

**04**

**PM2.5传感器**

  

近些年来，人们对雾霾的关注度越来越高，室内PM2.5含量也成为影响室内空气质量的重要指标。随着人们环保健康意识的增强，智能家居系统中对PM2.5的监测也成为不可缺少的一项重要工作。

![](../Images/26f765c562bacc283cb0815af4394e15.png)

**图丨激光粉尘传感器（ZH07）**

  

传感器技术的发展，使智能家居行业常用的传感器更加微型化、集成化、高精度和智能化。多种传感器的集成融合，以及传感器与其他学科的不断交叉融合，更细微、更精准、更智能化的传感器必将对智能家居的未来感知层起到至关重要的作用！
