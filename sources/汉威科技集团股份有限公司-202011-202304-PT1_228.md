# 【服务案例】汉威智慧消防监管体系为长垣人民医院筑牢“防火墙”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657681415&idx=1&sn=0a848232e5beba8354c774e40922d3d6&chksm=bd52c9a98a2540bf0f7d23a9f2a9856e754bc68f4d2c978ad987eff1051d75347f087912ee78&scene=126&sessionid=1681218480#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657681415&idx=1&sn=0a848232e5beba8354c774e40922d3d6&chksm=bd52c9a98a2540bf0f7d23a9f2a9856e754bc68f4d2c978ad987eff1051d75347f087912ee78&scene=126&sessionid=1681218480#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

消防工作关系国计民生，传统消防安全管理模式缺乏数字化管理理念，对于风险隐患动态掌握不足，火灾处置存在滞后性。随着近几年城市化进程的不断加快，消防管理水平与消防安全需求不匹配的矛盾日益突出，而科技的发展为解决这一难题提供了新的思路和策略。

  

![](../Images/2eea19ce196ce72239fdeb93f33fc4b5.png)

  

长垣市人民医院作为当地知名的综合医院，为全市人民健康提供了有力保障。随着医院规模的不断扩大、人流量不断增加，以及消防设施建设的不足和特殊医疗活动的需要，大大增加了医院消防安全管理的难度。为解决和改善医院消防安全管理漏洞，从2021年10月份开始，医院陆续部署了汉威智慧消防管理平台，实现对消防设施（管物）在线管控、消防工作（管人）在线处理的智慧消防管理新模式，筑牢安全“防火墙”。

  

![](../Images/a87df512c1e1af2c2abb8ca20882b9bb.png)

  

  

**PART 01**  

**24小时实时监测**

  

通过在消防重点区域加装独立智能探测器、电气火灾监控探测器、安装用户信息传输装置等，以实现原有消防系统的信息接入，全面构建医院消防物联网监测感知脉络，实现设备实时在线监测、在用数量统计、运行维护监测、自动预警等。

  

![](../Images/2ace758e82bcf3c5218cc3b19dcefae0.png)

  

汉威智慧消防管理系统可以规范医院的消防管理，对消防维保、消防巡查、消防培训等任务进行在线管理，自动记录管理过程，并通过数据挖掘分析技术，对多种因素进行分析，并进行综合预警。通过数据汇聚与共享，可获取各消防系统的实时数据、建筑安全管理的数据，当出现火警或异常报警时可第一时间推送相关信息和处置方案。

  

  

**PART 02**  

**消防管理可视化**

  

![](../Images/6cadf0ad82222776573845f739cf1625.png)

  

汉威运用数字孪生技术，完成了应用级、基础技术级、数据级的架构支撑，在系统中提供实景数据与多种地理基础数据的自动汇聚、关联与融合。通过物联网信息传感和通信技术，实时采集点位、空间数据以实景3D地图构建方式，还原医院的真实场景，保证重点场所点位数据、视频点位数据精准，实现在实景三维数据中的“数据”决策。

  

![](../Images/9e41e38ee7b04cf824c3879c1efd89b6.png)

  

  

  

**PART 03**  

**消防监管更方便**

  

为方便开展消防安全工作，智慧消防管理系统也有移动端应用。在日常消防监督管理中，消防巡检人员可随时随地监控该医院各消防系统的运行状态，使用移动终端进行现场巡检作业，当发现隐患或隐患整改时，可直接拍照录入系统，规范消防管理工作，确保消防安全第一道“防火墙”的管理责任。

  

![](../Images/b14f7c5dbc2cd8bb4a9e6261805e9086.png)

  

汉威以传感器为核心，以物联网技术为支撑，以专业的技术、高质的服务，为长垣市人民医院打造了以数据驱动为核心的智慧消防监管体系，全面提升长垣市人民医院的安全防范和应急处置能力，构筑消防安全防线。

  

![](../Images/4f26da86fe3c1240e1aa398068acc20e.png)![](../Images/379b1a103a91deb59b60c44cca930ccb.png)

// 汉威智慧消防监管体系汇报现场 //

  

统筹运行、多项互通，深化数据价值，汉威智慧消防监管体系，打破原先的信息孤岛，实现了设备维护可视化、监督管理智能化的目标，有效提升了消防日常检查和灭火处置工作的效能，是一种让“消”与“防”更“智慧”的创新监管模式。
