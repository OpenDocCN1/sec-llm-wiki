# 为防疫加把“科技锁” ！汉威“小门神”已上岗！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657681288&idx=2&sn=8bb3afac9b08282a1a4104d030b5a45d&chksm=bd5336268a24bf302a6a9385a17fcde542f2878fa1a9e7ddbb60f1ef0c78cf0f916827962258&scene=126&sessionid=1681218480#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657681288&idx=2&sn=8bb3afac9b08282a1a4104d030b5a45d&chksm=bd5336268a24bf302a6a9385a17fcde542f2878fa1a9e7ddbb60f1ef0c78cf0f916827962258&scene=126&sessionid=1681218480#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

“倒春寒”的疫情突如其来，且波及地区范围不断扩大，疫情防控形势严峻复杂。3月以来，全国本土疫情累计报告感染者超过15000例，已波及34个省份。

  

![](../Images/9cf7623a344c8a1769c5a025d1005ac5.png)

// 图片来源：网络 //

  

当前疫情防控工作形势严峻，有效遏制疫情扩散蔓延，对居家隔离、健康监测人员的有效管控是关键。做好居家隔离人群管控存在着动态管理难、管理成本高、人手短缺等问题。为了高效管控居家医学观察人员，筑牢疫情防控线，汉威科技集团子公司威果科技再出新招——“小门神”NB-IOT智能门磁探测器。

  

  

** 隔离防疫，智能门磁精准管控** 

  

![](../Images/515ab0c25db1658c2cfc4636ceccf34a.png)![](../Images/2d51f7983ef5f450231bd6c26a63ba50.png)

  

  

威果科技新一代NB-IOT智能门磁探测器采用NB-IoT物联网通讯技术，具有**低成本、低功耗、广覆盖等特点，通讯稳定、响应快捷**。使用隔离门磁报警器不仅能节约大量人力、物力，还能大幅度降低疫情传播风险。将隔离门磁报警器安装在入户门外，**仅感应是否有人进出，不涉及用户隐私信息，观察期满以后可以立即拆除回收**，不会影响用户正常生活。

  

![](../Images/eb928d19218fc6ec4b247ba13042cdbc.png)![](../Images/ed55690c25328f8c63a7e510d88ae2ac.png)

// 威果智能门磁在各隔离点实际应用 //

  

**居家隔离人员的出入情况实时监控：**

![](../Images/203be10af5e621b341efd91a8ab8a75e.png)

  

NB-IOT智能门磁探测器由无线发射器和磁块两部分组成，24 小时实时监测门开启和关闭的状态，适合安装在入户大门、窗户上。一旦监测到**磁块与发射器分开超过或靠近低于****1.5CM**时，疫情隔离防控检测中心平台便会**自动弹窗报警**，使用地图就能精准定位到隔离人员具体安装位置。

**三级权限管理，实现多级报警：**

分级管理，管理人员、基层巡检人员、督察员，**按级别划分管理权限**，做到管理有序，提升工作效率。

**多处站点同时接收报警信息：**

同一个社区**可设置多账号同时接收报警信息**，不仅填补了人工监管的漏洞，还让疫情防控更精准，更高效。除了防疫隔离外，还广泛应用于社区、家庭、公寓、养老院、酒店、企业园区、商铺等场所。

**隔离人员开门记录查询功能：**

数据采集终端**7\*24小时不间断连续采集**，出门即报警。对于居家隔离人员开门次数及开门情况有记录可查，做到防控有据。

**社区网格人员管理高效：**

![](../Images/b31a1e44def49773fb6067fb2cb1d30d.png)

  

平台设有**巡跟记录登记表格**，统计数据通过NB-IOT网络上传到管理后台，实现实时预警，达到实时监测隔离场所人员动态的目的，让社区工作人员上门监测做到有迹可循，方便快捷的保存每一次巡查记录，提高工作效率。

  

“小门神”将原来单一的“人防”转变为“人防+技防”，不仅有效填补了人工监管的漏洞，还让疫情防控更精准，更高效。

  

  

  

  

从最开始对新冠疫情的猝不及防，到全民抗疫的众志成城，再到科技抗疫助力疫情防控常态化中的动态清零，面对疫情，我们不再恐慌。同心抗疫，共克时艰，汉威科技通过物联网赋能，抗击疫情的肆虐蔓延，用新技术、新方法、新方案，站在抗疫第一线，用科技的手段构建防疫第一道防线，用责任和担当筑起了一座防疫高墙。
