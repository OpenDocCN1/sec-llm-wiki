# 落实消防责任，筑牢安全防线！汉威科技开展2022年消防演练

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657680854&idx=1&sn=3f054fba8b7ad8160c7c5015e6d5fb05&chksm=bd5334788a24bd6e7b4371b18edb4ff9eb878a548d579cf40df14f72a153d409070ebef9744b&scene=126&sessionid=1681218483#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657680854&idx=1&sn=3f054fba8b7ad8160c7c5015e6d5fb05&chksm=bd5334788a24bd6e7b4371b18edb4ff9eb878a548d579cf40df14f72a153d409070ebef9744b&scene=126&sessionid=1681218483#rd)

为了提高公司员工的火灾防范意识，掌握火灾逃生自救知识和技能，增强全体职工面对突发事件与自然灾害发生时的应变、自救、以及迅速有序撤离现场的自护能力，汉威科技集团在3月9日组织了一场消防及紧急突发事件疏散演练，公司全体职工参加，各部门按照紧急预案有序开展救援、避险等工作，共筑安全防火墙。

  

  

**壹**

01

全员参与  防治火灾

![](../Images/3cbb16bd2f57a32f189bc9f819ce25e6.png)

  

一阵急促的警报声拉开了消防安全演练活动的帷幕。在消防广播和各消防应急疏散队的指引下，全体职工迅速用毛巾捂住口鼻，低头弯腰伏身，紧张有序地撤离疏散至各指定空旷区域集合点并清点人数。

  

![](../Images/b1d5b4b1bc494e7dacbaad9a54b9e665.png)![](../Images/ea035fa69024343149537b64a479d795.png)

  

职工们快速有序地疏散

  

此次演习设置了疏散逃生、火情处置、现场讲解实操等多个环节。演习过程中，十五个消防应急疏散队伍皆能遵守应急预案，反应敏捷、行动迅速、配合默契，各部门员工能听从相关人员指挥协调，有序疏散。

  

  

**贰**

02

消防演练  防患未“燃”

![](../Images/3cbb16bd2f57a32f189bc9f819ce25e6.png)

  

为了让职工们进一步学习消防安全及应急救生知识，汉威科技集团还邀请到“蓝朋友”为职工们展示消防设备，进行了一场直观的消防科普。此外，职工们还现场实践了使用高压水枪的灭火方式。

  

![](../Images/0ab80b68510959e39c38aa6ad89597a7.png)![](../Images/00faeacb2f25c8efa629bfeac50255ed.png)![](../Images/14e10c743917c5854d93f1331a26fd88.png)

高压水枪灭余火除隐患 

  

在此次消防及紧急突发事件疏散演练中，职工们通过对消防知识的学习掌握了火灾自救的方法，增强了安全防范意识，提高了防灾避灾和自救互救能力，为自己与身边人担起安全责任防患于未“燃”！

  

  

**叁**

03

上下联动  共筑平安

![](../Images/3cbb16bd2f57a32f189bc9f819ce25e6.png)

  

在汉威科技集团董事长助理刘凤军的主持下，消防演练总结正式开始。

  

![](../Images/ca092b6672dbe40a617f6537a30ace22.png)

//  董事长助理刘凤军  主持活动 //

  

首先，汉威科技集团总裁李志刚对专程到场指导的高新区有关领导表示感谢，对各单位有序不乱的疏散表示肯定，并对本次消防疏散演习进行总结梳理。

  

![](../Images/3ed207eb23003f3fc7869ffe779d41e3.png)

//  总裁李志刚  作总结讲话 //

  

他表示，此次演练，我们既延续了以往的“实战”标准，突出随机性和突发性，使演练更具真实感。通过各单位的精心组织和通力配合，圆满完成了预定流程，基本达到了预期效果。总体上过程紧张有序、安排合理，有效积累了实战经验。希望大家共同努力，进一步提高安全管理整体水平，为公司发展创造更加良好的环境，以优异的成绩迎接党的二十大胜利召开。

  

![](../Images/82adef369f7076b6d5c5a3edf634cc99.png)

//  高新区枫杨办事处魏主任  作出点评 //

  

最后，高新区枫杨办事处魏主任对此次演练作出点评。一方面，充分肯定了汉威科技集团在火灾防控管理水平和应急疏散组织的能力，另一方面，又一次重申和强调了消防安全的重要性，提醒大家“安全常记心中”。

  

![](../Images/53f12994eb935f0e6a368105ca0462b3.png)

  

演习我们是认真的，准备我们是充分的！一直以来，汉威科技集团高度重视消防安全建设工作，始终坚持“安全生产和应急管理两手抓”，安全管理水平不断提升，为公司持续创新发展创造了良好的环境。不仅完善了消防制度，还组建了消防应急疏散队伍，定期开展消防培训学习和消防演练活动，定期对园区内办公场所、生产车间展开消防安全检查工作，将消防安全工作常态化，真正做到防患于未“燃”，极大地保障了企业财产和员工生命健康安全。
