# 郑州航空港兴港公用事业有限公司总经理谢新鸽一行莅临汉威参观交流

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657680512&idx=1&sn=36804557d4463bd326f94469909994fd&chksm=bd53352e8a24bc38a325ecc2dfd439d3453e430a0c3f0fc17ba5dcb1ae4a91f98864860b2ab5&scene=126&sessionid=1681218483#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657680512&idx=1&sn=36804557d4463bd326f94469909994fd&chksm=bd53352e8a24bc38a325ecc2dfd439d3453e430a0c3f0fc17ba5dcb1ae4a91f98864860b2ab5&scene=126&sessionid=1681218483#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

3月1日，郑州航空港兴港公用事业有限公司总经理谢新鸽一行深入汉威科技集团参观交流。汉威科技集团总裁李志刚、副总裁尚中锋、研究院院长武传伟、智慧城市事业群副总经理闵行政等集团公司领导陪同调研，随后进行座谈交流。

  

![](../Images/d3ded8ec595570696474c5fe1537c614.png)![](../Images/40999f3f6c7b8b51e7798ef5a1b77034.png)

//  谢新鸽总经理一行参观汉威智慧展厅 //

  

郑州航空港兴港公用事业有限公司总经理谢新鸽一行先后参观了汉威智慧展厅、制造车间、传感器实验室等，详细了解汉威生产经营、科技研发和转型升级情况。结合产品实物、平台系统及项目案例，对汉威科技集团的产业发展、科技创新能力和智能制造水平等给予高度评价。

  

![](../Images/4ff0f625b86592190e0e034f8379a8ca.png)![](../Images/c05ea1eb560167f9d27619951ae578ba.png)

  

总裁李志刚介绍道， 汉威科技集团作为国内知名的气体传感器及仪器仪表制造商，围绕物联网产业，将感知传感器、智能终端、通讯技术、云计算和地理信息等物联网技术紧密结合，打造汉威云，建立完整的物联网产业链，致力于智慧市政、智慧燃气、智慧水务、智慧热力、综合管廊等城市智慧化建设，实现城市燃气建设和管理的科学化、精细化、智能化，提升城市公共服务水平，构建完整的智慧城市生态圈。

  

![](../Images/563a3c20e351028bf56b7a9c88fe1dc9.png)

//  会议室交流  //

  

在交流会上，汉威科技集团总裁李志刚对郑州航空港兴港公用事业有限公司各位领导的到来表示热烈欢迎。郑州航空港兴港公用事业有限公司总经理谢新鸽对汉威科技集团在传感器领域的突出贡献以及物联网行业的领先地位给予了高度肯定，赞赏了汉威在企业高质量发展上的不断创新和坚持。

  

  

郑州航空港兴港公用事业有限公司和汉威科技集团同时作为郑州本地化优秀企业的代表，通过此次的沟通交流，双方加深了对彼此的了解。未来，双方将各自发挥所长，进一步深化互信、积极互动、加强沟通合作，在物联网、云计算、大数据、人工智能上深度融合，共同推动中原经济区建设和航空港经济综合实验区建设的发展，打造“智慧城市”新时代，为社会创造更多价值。
