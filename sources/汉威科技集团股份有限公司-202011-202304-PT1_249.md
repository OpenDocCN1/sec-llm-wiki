# 汉威视角 | 郑州市区将全面开展燃气用户加装安全装置工作，意味着什么？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657680317&idx=1&sn=e00c27b875cdcfba70b2159a7ddc16e0&chksm=bd5332138a24bb05afc8a339c813695d57eb04aced7aeeab6ce2fbb3870d85074ee5493781b5&scene=126&sessionid=1681218483#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657680317&idx=1&sn=e00c27b875cdcfba70b2159a7ddc16e0&chksm=bd5332138a24bb05afc8a339c813695d57eb04aced7aeeab6ce2fbb3870d85074ee5493781b5&scene=126&sessionid=1681218483#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

据郑州市城镇燃气安全领导小组办公室发布消息，

自2022年3月起，**郑州市区（中原区、二七区、金水区、管城回族区、惠济区、郑东新区、高新区、经开区）将全面开展燃气用户加装安全装置工作。**依据相关法规规范，结合郑州市城镇燃气使用实际情况，制定了郑州市城镇燃气用户加装安全装置工作实施方案。

  

  

**方案要求：**

01

新建住宅管道天然气工程在建设环节**全部安装自闭阀**，燃气具连接管必须使用金属软管；

02

既有管道天然气居民用户**加装自闭阀**，非金属软管更换为金属软管；

03

瓶装液化石油气居民用户非金属软管更换为金属软管；

04

非居民燃气用户（包括管道天然气和瓶装液化石油气）**全部安装符合相关技术规范要求的燃气泄漏报警器及联动切断装置**，非金属软管更换为金属软管，并确保正常使用。

//  资料来源：郑州交通广播 //

  

  

**为何要加装燃气安全装置？**

  

据中国城市燃气协会安全管理委员会发布的《全国燃气事故分析报告》统计：仅2021年上半年度，国内（不含港澳台）燃气事故544起，其中重大事故1起；造成71人死亡，412人受伤；事故分布在全国31个省份、215个城市。

  

![](../Images/ba1220249e8fa87a009b830445247226.png)

//  图源：燃气安全与服务 //

  

***1***

**按事故气源种类统计：**

  

2021年上半年，共计发生天然气事故191起，死亡38人，受伤201人；液化石油气事故326起，死亡33人，受伤190人；气源待核实事故27起，受伤21人。

  

***2***

**按事故类型统计：**

  

2021年上半年，居民用户事故305起，死亡25人，受伤189人；工商用户事故89起，死亡13人，受伤53人；管网事故146起，死亡31人，受伤170人；场站事故4起，死亡2人。

  

  

通过2021年上半年燃气事故情况分析，可以看出，**用户端事故风险依然是燃气行业的最主要安全风险之一**。用户在使用天然气及液化气的过程中，缺乏一定的安全意识，对气体的性质及预防事故发生的措施不了解，对本质安全型产品更是知之甚少，故而致使燃气事故频发。

  

  

**加强燃气安全监管已成必然趋势**

  

早在去年，应急管理部就联合住建部等部门推动各地区全面摸排，切实解决影响燃气安全突出问题，要求紧急部署开展燃气行业专项整治，进行安全生产大检查。相关部门单位也多次印发关于加强燃气等行业领域事故防范力度要求，这也意味着各行各业加强燃气安全监管已成必然趋势，城市燃气行业将迎来新的发展机遇。

  

**新版《中华人民共和国安全生产法》**

  

于2021年9月1日开始施行，新规规定**餐饮等行业的生产经营单位必须安装防止燃气泄漏的可燃气体报警装置**，不按规定安装的，触犯法律，最高可以处以二十万元罚款。

  

**《燃气工程规则》**

  

于2022年1月1日开始实施，新规规定**建筑高度大于100m的高层家庭用气场所以及商业用户使用的商业燃具、用气设备等需设置燃气泄漏报警装置和切断等安全装置**。

  

**《“十四五”国家应急体系规划》**

  

国务院日前印发《“十四五”国家应急体系规划》，对“十四五”时期安全生产、防灾减灾救灾等工作进行全面部署，要求**重点深化城镇燃气及燃气设施安全管理等安全生产治本攻坚**。

  

  

**如何安全使用燃气？**

  

![](../Images/795682d59a3ea1f0c382db6d3e9452c2.png)

// 图源：应急管理部官微 //

  

  

今年以来，无论是政策新规还是地方政府单位均高度重视燃气安全工作。绷紧燃气“安全弦”，织密燃气“安全网”，拧紧燃气“安全阀”，以“人防+技防+物防”，确保群众用气安全已成为当下民生之要事。

  

![](../Images/2a84358ab0cd1768d90a15d86bb8a5cd.png)

  

燃气安全涉及千家万户，事关人民群众生命财产安全，容不得丝毫马虎。不论是家庭还是各燃气企业，都应该提前防范、遏制事故，以实际行动和实际效果建设燃气安全新环境。
