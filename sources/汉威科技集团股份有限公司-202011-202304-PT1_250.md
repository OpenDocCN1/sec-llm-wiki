# “黑气瓶”再出整治新规，如何让瓶装液化气安全治理“快、准、狠” ？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657680240&idx=2&sn=d73ff5f4bc884c8232d0251e08d2b6b7&chksm=bd5332de8a24bbc8ac8ebdd14a2e1ecc7a8a0328b28bb2b716ea0293d1d707b9295bf7c5688d&scene=126&sessionid=1681218487#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657680240&idx=2&sn=d73ff5f4bc884c8232d0251e08d2b6b7&chksm=bd5332de8a24bbc8ac8ebdd14a2e1ecc7a8a0328b28bb2b716ea0293d1d707b9295bf7c5688d&scene=126&sessionid=1681218487#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

为巩固2021年总局“铁拳”行动暨翻新“黑气瓶”违法违规案件查办成果，推动燃气气瓶充装追溯体系建设，提升用气瓶质量安全水平，国家市场监督管理总局近期印发了《特种设备超期未检专项整治行动方案》《“黑气瓶”整治巩固提升行动方案》。

  

![](../Images/45f43e49d4771781be5c168082a37d9e.png)

//  图片来源：国家市场监督管理总局 //

  

**重点任务**

The key task /

  

**（一）确保气瓶产品质量和可追溯性**

  

**（二）充装安全追溯平台建设和报废气瓶去功能化**

  

燃气气瓶充装单位应在2021年年底完成气瓶充装安全追溯平台建设，实现充装出厂的气瓶手机扫描查询充装数据信息。**对仍未建立气瓶安全追溯平台或无法通过手机扫描查询充装数据信息的充装单位，应限期整改，逾期不整改的，按照不再具备许可条件收回充装许可。**对安全评估合格的燃气气瓶，负责评估的检验机构应逐只将评估结果上传到气瓶充装安全追溯平台，否则不得进行充装。

  

**（三）加大执法力度严格监管**

  

**（四）推动气瓶保险和定检改革试点**

  

  

**汉威科技集团**

**瓶装液化气智慧解决方案**

  

  

![](../Images/f897a25a403829b16efe1b58ad24af19.png)

  

汉威科技集团瓶装液化气安全云管理整体解决方案 ，**通过现场可燃气体探测器实时监控、建设24小时在线监测平台及钢瓶追溯信息化平台，**实时监测企业生产运营情况，完善企业钢瓶追溯工作、提升企业本质安全工作、加强企业客户安检责任意识，建立一整套从终端用户到燃气企业到政府监管三方合一的液化气领域安全监管长效机制。**使每只气瓶都拥有了一张“身份证”，**确保气瓶使用更加安全，实现气瓶充装、检验、配送等数据可追溯。

  

  

**平台优势**

  

  

![](../Images/00fbc8ff8bf81dcc053f6f97bc692d0b.png)

  

![](../Images/a073073152fecc075d758e3becaf8286.png)

**气瓶安全追溯管理系统**

气瓶追溯管理涉及气瓶的生产制造、充装、检验、配送、报废等多个环节，结合物联网技术、通讯技术实现一瓶一码，气瓶流转的全过程追溯和安全监管。

![](../Images/a073073152fecc075d758e3becaf8286.png)

**危险源视频监控**

接入液化气储配站、供应站监控区域内的视频源，通过网络实时传输视频信号，实现危险源远程可视化监管。

![](../Images/a073073152fecc075d758e3becaf8286.png)

**数据监控大屏**

融合大数据分析、GIS地图、3D等技术，实现数据可视化展示，分析数据关系，挖掘数据价值，带给客户更加清晰、准确、和震撼的体验。

![](../Images/a073073152fecc075d758e3becaf8286.png)

**企业入户安检**

利用移动终端对液化气用户进行安全检查，对不合格、存在安全隐患的问题进行记录，要求定期整改，验收通过方能继续使用。

![](../Images/a073073152fecc075d758e3becaf8286.png)

**数据电子档案**

建立燃气企业信息、站点信息（储配站、供应站等）、从业人员、危化车、终端用户、钢瓶等信息的电子档案，实现整个行业的信息化管理。

![](../Images/a073073152fecc075d758e3becaf8286.png)

**服务一体化**

建立统一服务平台，实现政府、企业、用户各级综合管理。

  

  

  

**成功案例**

  

  

目前，该平台已在杭州市、厦门市、吉林市、乌鲁木齐等城市成功应用。

  

![](../Images/63f41d5e131dc96520ff93873a11c432.png)

  

瓶装燃气的安全管理一直是城市安全的重中之重，也是难点所在。因其数量多、分布广、流动性强的特点，一旦发生事故，将造成生命财产损失和重大社会影响。气体安全已成为民生之要事，采用“技防”即物联网技术来防范气体爆炸已经成为必然趋势！
