# 应急管理部：“十四五”时期将加强燃气等行业领域事故防范力度

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657680240&idx=1&sn=aedf98723a11746aac77f5cb95b43e75&chksm=bd5332de8a24bbc80a0b3d9ca5302290d76585fa5b01e4e009c5a680e13f45fc348edb1487e5&scene=126&sessionid=1681218487#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657680240&idx=1&sn=aedf98723a11746aac77f5cb95b43e75&chksm=bd5332de8a24bbc80a0b3d9ca5302290d76585fa5b01e4e009c5a680e13f45fc348edb1487e5&scene=126&sessionid=1681218487#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

国务院日前印发《“十四五”国家应急体系规划》，对“十四五”时期安全生产、防灾减灾救灾等工作进行全面部署，要求重点深化城镇燃气及燃气设施安全管理等安全生产治本攻坚。

  

![](../Images/37de50be2efe7207409aa46525d5e444.png)

  

应急管理部安全协调司司长、新闻发言人苏洁日前在国新办举行的吹风会上透露，“十四五”期间，**一是要加大投入，改造老旧管道**，**二是加强对燃气等城市生命线的监测预警能力建设，特别是要督促餐饮等行业生产经营单位**，要让所有单位在“十四五”期间力争安装燃气泄漏报警装置。同时，也指导**全国重点城市加快推进城市安全风险综合监测预警平台的建设**，使各地对燃气以及相关各类城市生命线的风险能够做到“能监测、会预警、快处置”。三是加大安全宣传教育。

  

![](../Images/bae4934afb47f9c483ebcfaa49dfd872.png)

//  图源：网络 //

  

汉威科技集团作为国内知名的气体传感器及仪器仪表制造商、物联网解决方案提供商，深耕燃气行业20余年，以客户价值为导向，将感知传感器、智能终端、通讯技术、地理信息和云计算、大数据等技术紧密结合，打造汉威云，提供完善的智慧燃气信息化解决方案。

![](../Images/aec0a5d2b8dc0a823c0f832b22ae19d3.png)

  

  

**01**

**燃气安全监管物联网云平台**

  

![](../Images/af21708c3bd5c3aa914f03d6d8f40faf.png)

   ——————

汉威燃气安全监管物联网云平台解决方案，是一套集物联网+互联网技术于一体的综合监控解决方案。平台通过信息化手段对接入的物联网设备进行监管和预警提醒，具备**现场报警、短信通知、微信推送、电话通知**等多种预警方式。提供**7\*24小时不间断监测服务**，帮助减少燃气爆燃、爆炸事故。

////    

  

**02**

**餐饮系列燃气监管方案**

  

![](../Images/3f997057684c6d849c0f86a719850d4e.png)![](../Images/c32526e4d977a80340d2f6aeec592d50.png)![](../Images/91621eb36710605d4630c0ddbb4d3f06.png)

   ——————

针对餐饮企业燃气安全防范问题，汉威餐饮系列燃气安全监管解决方案，通过信息化手段对接入的物联网设备进行监管和预警提醒，具备现场报警、短信通知、微信推送、电话通知等多种预警方式。健全的燃气报警管理体制为**居民用户、餐饮企业、工商业用户、大型综合体**等应用场所提供7\*24小时不间断监测服务，帮助减少燃气爆燃、爆炸事故。

////    

  

**03**

**燃气巡检方案**

  

![](../Images/3c444cd2b658f16e338d833b6a1a766f.png)

   ——————

汉威燃气管网巡检系统融合了GIS、蓝牙、GPS及物联网等先进技术，通过各类智能巡检终端的应用，结合GIS管网信息，**实现管网巡检的可视化、数字化、可量化****，**从而有效保证管网设施的日常安全，提升输气可靠率，确保燃气管网安全运行。

////    

  

近年来，因燃气泄漏引发的重特大火灾事故数不胜数，每一次惊心动魄的救援，每一个生命的消失，都在提醒着我们提前防范，以实际行动和实际效果维护个人燃气使用安全，将燃气事故扼杀在摇篮里。汉威科技也将积极响应国家号召，配合燃气安全隐患排查整治工作，用优质的产品和服务为用气安全再上一道“阀”。
