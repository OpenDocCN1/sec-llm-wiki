# 应急管理部：将重点从管住增量、治理存量、提升园区三个方面把好安全关

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657680060&idx=1&sn=945c438ca0d5e0afa2322d835f8bc2cc&chksm=bd5333128a24ba04dce4fa6ad21e90d4b6a8cbb418afffff2e82c78dd8f20650f9c2092370dc&scene=126&sessionid=1681218487#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657680060&idx=1&sn=945c438ca0d5e0afa2322d835f8bc2cc&chksm=bd5333128a24ba04dce4fa6ad21e90d4b6a8cbb418afffff2e82c78dd8f20650f9c2092370dc&scene=126&sessionid=1681218487#rd)

![](../Images/e6d53a31c4490b25abf77ca5f10f6dd8.png)

  

2月15日，应急管理部2月份例行发布会上，应急管理部危化监管一司司长孙广宇介绍，近年来，危险化学品项目正由江苏、浙江等东部沿海地区，加速向中西部和东北地区转移，特别是江苏响水“3•21”事故发生后，转移进程进一步加快。与此同时，产业转移承接地区事故呈上升趋势。经报国务院领导同意，**在承接转移项目的中西部和东北地区21个省份，开展为期一年的专项整治，将重点从管住增量、治理存量、提升园区三个方面把好安全关**。

  

![](../Images/8532fc214fe377f8ba71b00481d81b54.png)

  

随着化工园区的规模化发展，安全管控体系逐渐规范，涉及方面也愈加宽泛。企业深化改革、新的生产力和生产关系的大调整，企业的安全管理如何适应新形势的要求，如何提高安全管理水平，这些都是摆在我们面前的一项重要课题。

  

  

**01**

![](../Images/e6b9ebcfb0942f18c6d0a936ff8fd347.png)

**Production safety**  

**一网通管和一手齐抓**

  

  

![](../Images/9315f4ec4d8f5421cfcac307442f3095.png)

//  智慧园区一体化管理平台的系统模式 //

  

汉威科技集团结合化工企业安全发展需求，以数据分析工具、物联网技术为依托，将园区的**安全环保、消防应急、能源物流、综合服务、产业运行**等业务管理信息整合为一，建设智慧园区一体化管理平台，通过打通不同业务场景及系统之间的数据壁垒，为化工企业用户提供智能化管控平台，实现运行状态一网通管，安全要素一手齐抓，促进园区产业安全生产转型升级和高质量发展。

  

  

**02**

![](../Images/e6b9ebcfb0942f18c6d0a936ff8fd347.png)

**Production safety**  

**运行状态一网通管**

  

  

**一网通管**

  

构建互联互通、高效协同的园区运行系统，仅利用“一键、一屏、一网”即可统筹管理园区运行指标。

  

**一网调度**

  

打造园区统一应急管理一张网，建立协同指挥调动联动模式，实现紧急突发事件的应急处理。

  

**一网预警**

  

建设园区全域覆盖的感知网络和预警体系，实现园区的集约化管理。

**Production safety**  

**安全要素一手齐抓**

**安全生产监管系统**

  

安全生产监管系统是风险辨识与管控信息的整合工具，为用户提供可视化的风险评估结果，并帮助其进行分级管控的动态化管理。

  

![](../Images/747214ad664c3725c970e0df54a68374.png)

  

**应急救援指挥系统**

  

建立应急值守、应急数字预案、应急资源保障、应急演练、辅助决策、指挥调度、事故管理等的防控体系，提高应急救援能力，降低事故造成损失。

  

![](../Images/6bcd660a03902d6958d4674fe9b8e962.png)

  

**环境监控综合管理系统**

  

在线监测污染物排放治理情况及项目施工现场的环保整治情况，建立环境质量的综合性评价，促进园区的安全与环保并行发展。

  

![](../Images/482964185b015950e6f6befc451c76b9.png)

  

**园区运营管理系统**

  

建设企业运营服务管理平台，提高园区经济运行管理能力及生产运行管控力，促进园区规范化发展和智能化管理，有效提升园区的综合竞争力。

  

![](../Images/6b47d39261ce8367f3c6f2844715c23c.png)

  

**园区封闭化管理系统**

  

利用GIS二三维+AI行为分析+卫星定位等技术，实现园区全域封闭化管理的实时监管和重点监控对象的全面监管。

  

  

  

  

针对化工园区危险源集中化、园区规模化等特点，如何对产业园区进行合理规划、识别潜在的风险，减少并控制重特大事故的发生，已成为各级政府、园区建设者与管理者日益关心、关注和需要解决的核心问题。

  

![](../Images/d5f471e9eb5d2d4ccd1a71636167afba.png)

  

如今，用数字化改革的成果，结合安全生产物联网数字化监管系统来提高检查效率、精准度已成为企业安全生产密不可分的一部分。在企业现有安全管理手段的基础上，充分利用信息化优势，将企业安全管理进行系统化梳理，最终才能实现企业本质安全管理。
