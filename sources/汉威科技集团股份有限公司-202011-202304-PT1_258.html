汉威视角 | 2022年北京冬奥会上有哪些值得一提的“黑科技”？

要说最近最火的是什么，那当然是我们的2022年北京冰雪盛会啦。既有开幕式霸屏、又有冰墩墩出圈、更有运动健儿们频频传来的好消息。


//  图源：北京冬奥组委官微 //


2022年北京冬奥会，除了火出圈的“冬奥顶流”冰墩墩和雪容融，智能科技大规模使用，也让世界重新认识中国。“科技” 、“低碳”是本届冬奥会的一大亮点，围绕冬奥会上的“黑科技”在场馆建设、赛事转播、运动员备战训练等领域中的运用都有哪些呢，一起来看~




奥运史上“零的突破”


“双碳”大目标下，本届冬奥会成为首个真正实现碳中和的奥运赛事，这届冬奥的“绿”不仅出现在赛区场馆，绿色交通也为实现冬奥“碳中和”助力。


//  图源：北京冬奥组委官微 //


据北京冬奥组委介绍，2022年北京冬奥会共有3大赛区、39个场馆，全部实现了城市绿色电网全覆盖，赛期内全部使用绿色电能，这是奥运史上首次实现全部场馆100%绿色电能供应，是奥运史上“零的突破”。


//  图源：北京冬奥组委官微 //


赛事所使用的交通服务车辆包括氢燃料车、纯电动车、天然气车、混合动力车及传统能源车。其中，节能与清洁能源车辆在小客车中占比达100%，在全部车辆中占比达85.84%，氢能源汽车成为赛事服务用车的主力。这也意味着北京冬奥会就此开创了全球首次大批量使用氢燃料电池客车服务体育赛事的先河。


//  图源：网络 //


同时，北京市还建设了“冬奥绿色低碳公共交通网”，北京赛区所有冬奥场馆都实现了地铁线路全覆盖。



“水立方”变“冰立方”


2022年北京冬奥会，“水立方”变身“冰立方”，承接冬奥会和冬残奥会的冰壶和轮椅冰壶比赛项目。“水立方”改造成“冰立方”并非机械性的转换，而是在保有“水立方”水上功能的基础上，新增冰上功能，在比赛大厅中部通过搭建可转换结构及安装可拆装制冰系统，铺设4条标准赛道的冰壶场地。


//  图源：水立方官微 //


为了保障“冰立方”的室内环境条件符合冰壶比赛的要求，场馆设置了由4000多个传感器领衔的楼宇设备管理系统，可以监测和控制场馆内的温度、湿度、PM2.5浓度等的变化。



VR观赛“亲临其境”


无法到现场观赛？没关系，北京冬奥会的“智能观赛”模式也给观众带来非同一般的观赛体验。在5G网络的“高速通道”上，人工智能、虚拟现实等先进技术将得到综合运用，为观众呈现一场视听盛宴。


//  图源：网络 //


通过人工智能和虚拟现实技术，观众可以“亲临其境”，甚至从运动员视角观看比赛，比观众席上更具感染力。



冬奥“战袍”内含玄机


内置传感器的高科技“冬奥战袍”也是北京冬奥会的热点之一。“传感器能感应和追踪肌肉纤维内部活动，通过应用程序报告各部分肌肉的运动状态。”科研人员说，这可以帮助运动员有针对性提升训练水平。


//  图源：网络 //


利用运动捕捉穿戴传感器、激光雷达等设备，收集运动的运动数据，针对短道速滑和速度滑冰的个人比赛项目的减阻节能和提高成绩，充分考虑运动员的个性化生理特征、装备特征和环境特征，包括体形、骨骼肌肉、生理生化等，建立数字运动员模型。



传感助力科学防疫


智能科技的大规模投入使用，不仅仅是向世界展示中国先进的科技，背后还有防疫的需要。当前全球新冠疫情形势依然严峻，变异毒株传染性更强、传播范围更广。


//  图源：网络 //


而在冬奥会赛场，多样防疫机器人、可穿戴式测温设备、移动的核酸检测PCR实验室、气溶胶检测系统等抗疫“黑科技”随处可见，搭配严密的防控政策，全方位保障疫情防控工作精细化。



冬奥村的小传感大智慧


除了冬奥会现场，冬奥村的“黑科技”也令人连连称赞。在运动员公寓中，每套房间靠窗的墙上均装有智能安防系统，当有人靠近窗户时，红外感应器就会报警。独立空调系统跟新风系统、智能环境检测仪的运用，即使是在不开窗的情况下，也可为室内提供新鲜空气。


//  图源：网络 //


同时，智能床还搭载精密的传感器，能够精准捕捉人体体征数据，监测运动员心率和呼吸信号，管理运动员睡眠数据，形成健康预测报告，帮助教练实时关注运动员状态；还可通过大数据进行预警，防止紧急情况发生。



北京2022年冬奥会在传感器、物联网等一系列高科技技术应用下吸引了全世界的目光，给奥运历史立下绿色标杆，我们或许可以从冬奥会上得到一些启示。



毋庸置疑的是，科技越发展，传感器越进步。而“碳中和”的新玩法，少不了传感器的支撑。推动碳排放有序“达峰”、“中和”，既是支撑落实国家“双碳”目标的必然要求，也是推动实现经济社会发展全面绿色转型的客观需要，这其中便需要大量的气体传感器进行监测，而这正是汉威科技重要的业务领域，其中的核心便是气体传感器及相关的仪器仪表设备。



传感器存在于生活的方方面面，带领人们进入全新人工智能时代，传感器重要性不言而喻。未来，汉威科技将根据实现“碳中和”的阶段性要求，积极关注氢能产业的发展，随着公司在以传感器为核心的技术、业务领域的不断拓展，持续探索，通过自身的产品和技术为包括储能在内的国家各项战略规划积极发挥企业的价值与责任。
