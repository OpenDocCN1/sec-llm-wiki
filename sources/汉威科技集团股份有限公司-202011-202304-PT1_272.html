ANNUAL  SUMMARY REPORT 

汉威科技集团股份有限公司

-2022年度工作会议隆重举行-

为切实做好疫情防控工作，巩固来之不易的防控成果，有效控制和降低疫情传播风险，1月22日，汉威科技集团2022年度工作会议隆重举行，汉威人“在云端”汇聚一堂，回望过去，面向未来。伴着庄严高亢的国歌，会议正式开始。



PART.01

总裁年度工作概述


“2021年，集团公司主要经营指标实现了良性发展，企业整体延续了稳步发展、总体良好的态势，并呈现出‘底盘稳、韧性强、动力足、潜力大’的新特点。”总裁李志刚在年会上发表致辞，就“2021年主要成绩和亮点”、“当前的形势分析”以及“2022年总目标和总体工作思路”作重要部署。


//  汉威科技集团总裁 李志刚 //



PART.02

子公司代表签订目标责任书


总裁李志刚与各子公司代表签订2022年目标责任书，鞭策和激励各子公司在2022年持续创新、向新而战 ，继续开创“高质量百亿汉威”新局面。



同时，各子公司代表分享了自己2021年的沉淀与思考，并就2022年的工作目标作出发言。




PART.03

现场表彰仪式


党委书记张潇君宣读《表彰决定》。充分肯定了获奖单位及个人在2021年度各项工作中取得的巨大进步与为集团做出的突出贡献。2021年汉威取得的成绩可圈可点，感谢大家过去一年的辛苦劳作。


// 汉威科技集团党委书记 张潇君 //


// 优秀员工、单位表彰颁奖 //



PART.04

董事长作重要讲话


2021年是汉威“高质量执行年”，提出了“战略引领、创新驱动、平台支撑、协同发力”四个着力点。一年来，在以总裁为核心的管理团队领导下，汉威顺利驶入快车道。站在新形势下的新起点上，2022年汉威要怎么做？


//  汉威科技集团董事长 任红军 //


汉威科技集团董事长任红军就2022年的各项工作发表重要讲话。他表示，2022年是一个乘势而上，实现“高质量快速发展年”。2022年对汉威的发展很关键，我们必须要抓机遇、抓落实，全面突破，使命必达。同时，2022年汉威将继续坚定不移地贯彻既定策略，以“战略牵引、创新驱动、平台支撑、协同发力”为着力点，实现人才辈出，高质量可持续发展局面，打造具有核心竞争力的百亿企业。


2022年是机遇与挑战并存的一年，汉威将重整行装，从传感器这颗“芯”出发，继续以高质量发展为主题，持续推动行业改革创新步伐，以定力保动力、以动力促发展，在2022年再创佳绩！





END
