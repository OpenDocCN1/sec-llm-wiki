# 乘《科学技术进步法》东风，为国产仪表科技创新活力注入新动能！

时序更替，万象更新。伴随着2022年钟声的敲响，修订后的《中华人民共和国科学技术进步法》于2022年1月1日正式施行。

  

![](../Images/ac2b8b465c072b0ce5687cbdcb171d94.png)

  

《科学技术进步法》

相关内容

**其中，第九十一条指出：**

对境内自然人、法人和非法人组织的科技创新产品、服务，在功能、质量等指标能够满足政府采购需求的条件下，政府采购应当购买；

**第四十一条指出：**

国家鼓励企业加强原始创新，开展技术合作与交流，增加研究开发和技术创新的投入，自主确立研究开发课题，开展技术创新活动。

  

在《科学技术进步法》中，科学仪器被多次提及。时隔14年后《科学技术进步法》再度修订，**全方位鼓励支持国产高端仪器发展，大力推进采购国产仪器，**这也悄然唤醒了国产仪器仪表制造业的新的生机。

  

  

**《科技进步法》出台**

**为国产仪表科技创新活力注入新动能**

  

汉威科技集团作为国内知名的气体传感器及仪器仪表制造商、物联网解决方案提供商，高科技型企业，响应国家号召，**始终坚持技术创新发展战略，加强智能传感器的自主可控技术研发，投入大量的资源进行技术攻关，不断突破技术壁垒，助力传感器及智能仪器仪表国产化。**

  

![](../Images/648cd8e50ba204068a90eb1b937c8176.png)

//  汉威科技集团业务领域 //

  

一方面，汉威坚持沿产业链构建传感器生态，实现市场导向和资源循环。**拥有众多自主知识产权，并不断塑造属于自己的核心关键技术，**汉威围绕物联网产业，将感知传感器、智能终端、通讯技术、地理信息和云计算、大数据等技术紧密结合，打造汉威云，为智慧城市、安全生产、环境保护、民生健康提供完善的物联网解决方案，**现已形成“以传感器为核心，涵盖智能仪器仪表、云端技术、软件”的完整物联网产业链。**

  

![](../Images/e3017ef1a97aeabfb3df05d35b06b172.png)

  

另一方面，汉威建设了汉威研究院、智能传感器创新中心等专业研发中心，充分发挥团队积累的传感器、智能仪器仪表技术和经验，通过对具体行业的分析，结合部分核心技术和实际项目经验，不断扩充技术品类，打造供应链核心技术，构建传感器生态。

![](../Images/a153e30169a9c6d36b0926698cbadb74.png)

//  汉威研发中心 //

  

汉威科技集团**崇尚创新和研发，拥有自主知识产权，掌握核心关键技术。**建设了以汉威研究院为核心，涵盖北京、上海、深圳国内研发中心和美国、德国、新加坡海外研发中心在内的全球研发创新体系，不断围绕传感器、智能仪表、地理信息、云计算、大数据、移动互联等互联网技术，水、气、固废净化处理技术，节能技术等方面全面创新，并在智慧城市、安全防护、测量控制、环境保护、家居健康舒适领域开展应用模式创新，为客户提供安全、可靠、经济、便捷的产品和服务。

  

![](../Images/dfb64cb70110fe8663e18964f2375344.png)

  

汉威通过产学研合作模式的探索，已与中国科学院上海微系统与信息技术研究所、中国科学院苏州纳米技术与纳米仿生研究所等十余家科研院校建立了合作，不仅促进了公司科学技术水平的快速提高，同时也推动了国内科研院所和高等院校科技成果的产业化进程，建立了全面互动的科技创新生态圈，对增强行业产业链供应链自主可控能力起到很好的促进作用。

  

![](../Images/79c983f7a8e9b86eb181e16601e83e7a.png)

  

汉威科技集团作为中国仪器仪表学会的常务理事单位，国内知名的气体传感器及仪器仪表制造商，将进一步聚焦国产仪表系统的研发，以科技创新引领仪器仪表行业高质量发展，加强产业集群资源共享，构建完整的产业链，不断创新，突破国际技术限制，为我国的仪器仪表科技创新发展贡献力量。
