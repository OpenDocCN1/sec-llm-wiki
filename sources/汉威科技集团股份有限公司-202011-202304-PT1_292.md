# 携手中国铁塔，汉威助力江苏淮安工业园建设“智慧大脑”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657678262&idx=1&sn=06686676847d2e2edeb396a9a949b261&chksm=bd533a188a24b30ebcdbdffd27c27ff1d5e7d995e20136360d60416b067f78fbe395e35fbd3a&scene=126&sessionid=1681218493#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657678262&idx=1&sn=06686676847d2e2edeb396a9a949b261&chksm=bd533a188a24b30ebcdbdffd27c27ff1d5e7d995e20136360d60416b067f78fbe395e35fbd3a&scene=126&sessionid=1681218493#rd)

![](../Images/59178cb1e21ce2c8d10b1a0b78dc758a.png)

  

江苏淮安，一座覆盖面积约24.58平方千米的工业园区化工片区，正在精心织就的“隐形安全网”下平稳地运行。在园区的统筹指导关怀下，**汉威科技集团**与**中国铁塔**强强联合打造了“智慧大脑”，使其借势创新载体，顺利转型升级为数字化的特色园区，并成为智慧安全“5+1”工程的样板案例。

  

![](../Images/09b1714578bf86225ef13881c4226b71.png)

//  淮安工业园区综合指挥中心 //

  

  

**数字赋能**

**迎来化工园区2.0时代**

  

淮安工业园区化学矿产资源条件优异，从盐卤开采、制盐制碱，到后道吃氯耗氢、再向下游延伸，该园区逐渐摸清了发展道路，完善了产业链条，凭借着迅猛势头先后获批国家火炬淮安盐化工特色基地、省新型工业化示范基地、省级先进制造业基地等荣誉称号，快速迎来了自身的1.0时代。

  

![](../Images/cc0195651abc2ad1cb4d350e125e892f.png)

  

随着产业发展向智能化、信息化转型，数字赋能安全生产的思路逐渐清晰，在认识到数字赋能安全生产的新思路后，中国铁塔联手汉威科技集团，共同布局智慧安全“5+1”工程，以**封闭化管理**、**应急指挥中心**、**危化品停车场**、**特勤消防站**及**隔离防护带**“五个工程”为基础依托，以**综合信息控制系统**为“一个中心”，构建配套安全生产管理、综合服务、应急救援指挥为一体的支持体系，为工业园区搭建“智慧大脑”，加速标准化创建和信息化改造，推动化工园区进入2.0发展时代。

  

![](../Images/19d7eb33f9d01795c0e33c301e816d6b.png)

// 智慧园区一体化管理平台成功验收 //

  

  

**智慧互联**

**建立工业园区综合信息化平台**

  

为了使“智慧大脑”可以充分调动安全环保、消防应急、能源物流、综合服务、产业运行等相关业务模块，汉威科技集团运用**“工业互联网+”**思维，协助中国铁塔建立一网通管的**工业园区综合信息化平台**，提升园区规范化、智能化管理服务水平，促进产业高质量发展。

  

![](../Images/9f9cdcecff3ed087f38d2b0fa6a331dc.png)

  

![](../Images/ff0f0f0590ed7008951dee26ce3af2f4.png)

**一网统管**

“一张网”实现人、物、网高度融合，将园区安全监管、环境监测、应急救援、封闭管理、公共服务等各类管理要素统一采集、传输、存储和应用，掌握园区运行状态，实现管理整体联动。

  

![](../Images/ff0f0f0590ed7008951dee26ce3af2f4.png)

**一网调度**

构建以指挥中心为龙头的统一调度、统一指挥，环保消防等单位协同合作的工作新机制，打造全区统一应急一张网，做到快速响应，快速处理。

  

![](../Images/ff0f0f0590ed7008951dee26ce3af2f4.png)

**一网预警**

建立从企业数据监测——系统分析预警——指挥中心确认——预警指令发送——企业/执法人员处置——预警处置反馈——预警闭环完毕的数字化监管业务协同流程，可第一时间发送信息至企业管理人员，确保隐患风险及时处置。

  

![](../Images/ff0f0f0590ed7008951dee26ce3af2f4.png)

**一网采集**

自动识别不同类型的安全监测设备及系统的多源异构数据，企业与园区智慧安全“5+1”工程融合连接，全面采集业务管理信息或相关系统数据，打通不同业务场景及系统之间信息孤岛和数据壁垒。

  

  

**护航生产**

**打造汉威安全云生态**

  

此次为江苏淮安化工片区搭建智慧园区一体化管理平台，是汉威科技集团为工业企业托底安全生产的又一次成功案例，且有望推动淮安化工智慧园区成为江苏省的标杆项目。

  

汉威人对工作的悉心严谨、尽责创新也深深打动着用户。一封表扬信，无不述说着那段酷寒冬季里抢工期、拼速度的施工故事。

  

![](../Images/c6a3a45cd2a5faf930c6a2a0fcdd3698.png)

  

在扎根物联网产业的二十余年里，从感知传感器到智能终端，从传统产品到整体解决方案，汉威在广度上拓宽应用领域，在深度上挖掘技术成果，从而形成了“感•应•云”的业务生态。同时，利用物联网、云计算、移动互联网、大数据挖掘等先进信息技术及手段，全面整合企业、园区、政府应急职能管理部门的信息资源，强化企业主体责任和政府监管，建立从安全备灾、风险评估、监测预警、应急处置到减灾降损的全过程管理体系，为企业的健康稳定发展保驾护航。
