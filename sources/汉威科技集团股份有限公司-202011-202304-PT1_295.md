# 冬奥会日益临近，京津冀及周边地区大气污染如何治理？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODEzMzk1Mw==&mid=2657677879&idx=2&sn=cb69c48605ecffde6b96c4f8691f15aa&chksm=bd533b998a24b28fbdc58cfbc7eab0342f229d8f89f7f1393f55bc37e59d600cdcbf5eb66f9e&scene=126&sessionid=1681218496#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODEzMzk1Mw==&mid=2657677879&idx=2&sn=cb69c48605ecffde6b96c4f8691f15aa&chksm=bd533b998a24b28fbdc58cfbc7eab0342f229d8f89f7f1393f55bc37e59d600cdcbf5eb66f9e&scene=126&sessionid=1681218496#rd)

![](../Images/59178cb1e21ce2c8d10b1a0b78dc758a.png)

  

  

2022年北京冬奥会迎来倒计时，京津冀及周边地区将因北京冬奥会举办大面积关停企业？此消息一出，让很多企业陷入恐慌之中。

  

![](../Images/d6667755439b9de1eaedc428597bf282.png)

//  图片来源于网络 //

  

对此，北京冬奥组委新闻发布负责人严家蓉在12月16日上午举行的新闻吹风会上回应称：“这一情况并不属实。”严家蓉表示：“据我们了解没有大面积停工的计划，京津冀及周边的区域在秋冬季实行一些大气污染的防治措施，这些措施已经连续几年执行，并取得了积极成效，和举办北京冬奥会和冬残奥会没有关系。”

  

  

![](../Images/2f8a6c982a62eb71ce84c78a44bfb25d.png)

**秋冬季大气污染治理攻坚任重道远**

  

秋冬季攻坚虽取得积极成效，但空气质量改善成果还不稳固。京津冀及周边地区、汾渭平原仍是全国PM[2.5]浓度最高的区域，秋冬季PM[2.5]平均浓度是其他季节的2倍左右，重污染天数占全年95%以上。今年10月下旬以来，京津冀及周边地区已经发生三次区域性空气污染过程。

  

![](../Images/0d420f33215b448dc7d2d5265e7eccf0.png)

  

秋冬季是污染物排放相对较大，且气象条件不利的时段，秋冬季大气污染防治形势依然严峻。京津冀及周边区域产业结构、能源结构、运输结构没有根本改变，整体污染排放水平仍然处于高位，空气质量改善成果还不稳固，一旦气象条件不利，容易发生重污染过程。当下，营造良好外围环境，加强大气污染联合治理，确保实现“冬奥蓝”至关重要。

  

  

![](../Images/2f8a6c982a62eb71ce84c78a44bfb25d.png)

**汉威大气精准监管解决方案**

  

汉威大气精准监管解决方案以助力政府落实**“减污降碳”**总要求为主要目标，以先进的物联网技术为基础，组合运用自主研发的多种类型物联感知终端，实现区域污染源在线连续监测；深入开展雷达精准走航监测服务，实现特定地理空间移动监测；结合大气环境综合监管软件平台，实现数据智能分析。

  

![](../Images/366813948d273f1f7621a03cb9307c21.png)

全方位多维度建立完善的环境质量监测监控体系，对**秋冬季颗粒物**、**PM[2.5]**等重点污染源企业监测数据质量的监控更有效，实现大气污染的精准化监测，及时准确地把握城市空气质量变化状况，精准定位城市重污染区域和污染排放源头，为大气污染防治工作提供科学有效的决策支持。

  

  

**组合监测**

  

组合运用多种物联网监测设备、雷达走航车，适应不同场景需求，通过科学布点、组网监测，为用户提供定制化监测方案。

  

**智能预警**

  

通过预警规则，对污染物超标排放、污染天气、污染散源排放等多种场景进行智能侦测与智能预警，辅助管理部门对环境事件快速响应和快速处置。

  

**科学研判**

  

通过对重点对象、重点数据进行专题分析、大数据关联挖掘分析，结合第三方生态环境专家团队专业分析和解决方案，提高分析研判的科学性和准确度。

  

**精准溯源**

  

以大数据、物联网、云计算、机器学习、区块链等技术为引导，突破环境污染精准溯源与治理难题，服务城市大气污染防治与监管决策支持。

  

![](../Images/e1984a545d5e555ef299436cceab7887.png)

  

北京冬奥会的举办将加快推动北京大气污染治理、水环境生态修复、城区景观环境提升等工作。时下，在坚决打好污染防治攻坚战、减污降碳的同时，依靠科技转型升级，创新发展，加快推动生态环境治理体系和治理能力现代化将是实现污染难题治理的重要路径。
