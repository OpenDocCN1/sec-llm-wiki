# 强化产学研，融入长三角丨《河南日报》关注汉威在“长三角”的科技创新战略

随着长三角区域一体化发展正式上升为国家战略，长三角正成为全国经济发展最活跃的地区之一。深度对接长三角一体化和长江经济带国家战略，学习借鉴沿海先进地区发展经验，正成为河南企业贯彻新发展理念、融入新发展格局的重要战略思路。

  

11月21日，《河南日报》要闻版刊登“对接长三角 中原新起航”专题报道，文章重点聚焦**汉威科技集团在长三角地区通过建立优势互补的产学研合作机制**，不仅推动公司科学技术水平的快速提高，同时也推动了国内科研院所和高等院校科技成果的产业化进程，建立了全面互动的科技创新生态圈，为河南企业深度融入长三角一体化，建设现代化河南提供了更多思路。

![](../Images/2079b0b991b635ba50ee70834efc601d.png)

以下为报道原文：

**建立优势互补的产学研合作机制**

  

长三角地区在人才、技术、资讯等方面具有很多独特的优势。**公司通过多年产学研合作模式的探索，已与中国科学院上海微系统与信息技术研究所、中国科学院苏州纳米技术与纳米仿生研究所等十余家科研院校建立了合作**。这种“优势互补、互利互惠”的产学研合作机制促进了公司科学技术水平的快速提高，同时也推动了国内科研院所和高等院校科技成果的产业化进程，建立了全面互动的科技创新生态圈。

![](../Images/37d0b8eb842cdc6ab66f34e98dae5f39.png)

▲汉威科技集团上海第二总部

“十四五”期间，公司将在长三角地区**重点围绕MEMS、光电技术等先进传感器、数字经济云平台及应用**方面，加大研发创新、市场营销、投资培育平台建设，在上海打造第二总部。同时把一些**适合在中原地区产业化的项目导入到河南**，**发挥两地资源互补优势，**让汉威的传感器和物联网事业有更好的发展。
