# 升级：SuperRDP2.1，解除限制，更多同步源

最近太多朋友催我了，说SuperRDP2.1该升级了。  

![](../Images/53444863cce1ac75f7231bdfa91f8738.png)

没想到更新自动分析支持后，还是这么多问题。

见文章：[SuperRDP2：自适应支持Windows家庭版最新远程桌面](http://mp.weixin.qq.com/s?__biz=MzI1NTUzMjUzMQ==&mid=2247484620&idx=1&sn=5c775c4c57e3b37d67b551c1ff10eeb6&chksm=ea35c850dd4241469b892ed2b757c46bfff573d1215ec8d048bd08011bf3a1aacda308d983e8&scene=21#wechat_redirect)  

我分析了下原因：

1.   可能是自动分析对某些版本支持不够。这个需要单独分析，但是由于github交流不够及时，我没法快速跟进。
    
2.  可能是之前加入的使用限制，导致自动分析支持功能失效。
    
3.  可能是某些朋友不知道怎么使用。
    
4.  ...
    

  

所以，这次更新想解决这些问题：  

1.  解除了使用限制（code和次数限制），大家可以放心大胆使用了。
    
2.  加入了更多线上同步的配置信息源，以量取胜，补充自动分析失败后的备用方案。
    
3.  更新superrdp.ini支持到目前最新的win11版本。  
    
4.  修复了一些bug
