# 我用微信远程控制了家里电脑

视频文字版：  

有一天外出，需要微信扫码，但突然忘了微信密码，密码存在家里电脑的一个文件里。

怎么办？幸好我早有准备，没有关家里的电脑，并且登录着电脑微信，还给微信加了微小秘的辅助功能，现在终于派上了用场，不枉花了这么多电费。

我给微信发了cmd，开启微小秘，远程dos管理电脑。

cd到密码文件目录，type查看文件，找到密码。

YES！

登录微信，终于可以扫码了，感谢微小秘。

（请问剧本有什么问题？）

继《关机大师》之后，又继续给微信增加了一个DOS远程控制功能（专业名叫做给微信开启了cmdshell），通过这个功能，基本上能完成电脑所有的常规操作（不包括界面交互式的）。  

比如文件管理、注册表配置、启动软件、关闭软件、用户管理、服务管理、ftp、telnet等等。  

也就是windows原生cmd支持的功能几乎都能够正常使用（非阻塞的）。  

搞这个呢，其实就是好玩，很早之前就有这个想法，只是弄《关机大师》之后顺便加上了。  

后续有时间还会继续完善，大家可以期待一下。

另外也寻求大家帮助，看看能不能给我提一些比较好玩的想法，如果能够实现，可以一一加上。

比如之前有朋友说到锁屏，这个就挺有用的。  

好的，到这，下次见。  

（完）
