# 魔法电脑第一个插件-win11升级助手

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NTUzMjUzMQ==&mid=2247484326&idx=1&sn=35f266c4d6dd995d192aaddaa213426b&chksm=ea35cf3add42462cb5af96cb675a6d6bc590b609cb50880de7cf3306139dba7c3d57f8af62d6&scene=126&sessionid=1681666035#rd](http://mp.weixin.qq.com/s?__biz=MzI1NTUzMjUzMQ==&mid=2247484326&idx=1&sn=35f266c4d6dd995d192aaddaa213426b&chksm=ea35cf3add42462cb5af96cb675a6d6bc590b609cb50880de7cf3306139dba7c3d57f8af62d6&scene=126&sessionid=1681666035#rd)

windows11正式版已经发布快1一个月了，很多朋友都应该已经升级了。

但是windows11对硬件的强制要求，导致很多老电脑（或者硬件不支持的新电脑）无法正常升级。

关键是前几天微软在beta版中通告了安卓子系统发布，这应该让很多小伙伴心痒痒，据说性能不错，虽然bug不少。

所以，为了让某些无法升级windows11的朋友能够尝鲜一下。

经过差不多两周多业余时间，我终于在10月快结束的时候，测试好发布魔法电脑的第一个插件：win11升级助手。

win升级插件功能：

1.  检查系统版本是否到win10 2004以上，提供升级win10最新版接口
    
2.  绕过兼容性检查工具检测，不用安装兼容性检查工具
    
3.  绕过win11对cpu（Intel、amd、高通）、内存、硬盘、tpm、uefi的检查
    
4.  提供win11升级接口，下载原生官方升级工具，能够保留原始数据和应用（不需要升级U盘之类的）。
    
5.  **支持win11 dev降级到beta升级**，保留原始数据和应用（降级后可能存在bug，大家自行选择是否使用）。
    

使用方法：

1.  下载魔法电脑最新版1.1.1.0（也可以自动升级，如果升级失败，从官网下载最新版）。
    
2.  运行魔法电脑，点击工具箱，会自动下载win11升级插件（如果下载失败，请从官网手工下载，放入plugins目录）。
    
3.  在工具箱点击win11升级助手，根据提示操作。
    
4.  如果win10版本低于2004，点击升级Windows10，根据提示下载官网工具进行升级，升级成功重启后，重新打开魔法电脑升级win11。
    
5.  如果win10版本已经最新，点击升级Windows11，根据提示下载官网win11升级工具进行正常升级。
    
6.  **注意：升级过程中，****请不要关闭魔法电脑或者退出升级助手插件****，否则升级会失败。**
    
7.  **注意：升级前，先关闭杀毒软件，否则可能导致软件无法正常工作，无法升级。**
