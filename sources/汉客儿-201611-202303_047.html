远程桌面

远程桌面是 Windows 系统下原生、跨平台的的远程控制功能，拥有微软官方提供的各平台客户端，就可以让你在远程轻松帮助别人或者控制自己的电脑。

我是远程桌面重度用户，家中电脑常年开启远程桌面服务，以便我能随时访问家中电脑。

在组装机年代，天天用着破解版的windows专业版并没有什么感觉，现在用着正版“Windows 家庭版”系统，才发现家庭版远程桌面服务被阉割了。

从 Windows 7 以来家庭版都不支持桌面功能，但是市面上整机预装的操作系统几乎都是家庭版。

用不了，怎么办？有人说换软件，是的，市面上也有类似软件：如VNC、Teamviewr，QQ远程协助等等。

但综合体验之后，依然还是觉得Windows自带的远程桌面强大，最主要是流畅不卡顿，跟本地使用几乎没有差别。

并且Windows也提供了移动版的客户端，就算在地铁上，也能用手机通过远程桌面移动版在快速的5G网络访问家中电脑。

非常棒，这多次帮我搞定了在地铁突然需要用电脑的突发事件。

~远程桌面是真的好，5G也是真的快！哈哈~

那么windows家庭版用户有没有什么方法使用远程桌面呢？

往下看，当然是可以的！

启用远程桌面

通过百度或者其他搜索引擎简单一查，已经有很多网友遇到了跟我们一样的问题，所以很容易找到一个软件可以解决这个难题。

RDP Wrapper Library by Stas’M。

一个叫做Stanislav Motylkov的老外开发的一个工具，可以让Windows家庭版正常启用远程桌面服务。

并且从Windows Vista开始一直支持到Windows10，还支持多用户同时远程连接同一个电脑，非常哇塞。

另外还提供了方便的安装器、桌面服务检测、配置工具等等。

真的是非常良心的开源作者了，可惜的是，不知道什么原因，两年了，Stanislav Motylkov没有继续更新该工具，导致第一次接触工具的我懵逼了，无法在最新Windows10家庭版中使用。

一顿各种折腾之后，搞明白工具原理，才知道针对不同系统版本，该工具需要进行不同的破解。

破解信息保存在rdpwarp.ini的配置中，作者虽然没有继续更新，但是保留了更新方法。

不过更新方法对比普通用户来说，那门槛是相当高了。

经过一番搜索，并没有找到代替或者继续帮助作者更新的项目。

如此没办法，只好自己动手，丰衣足食。

SuperRDP

经过我重新开发安装器，优化核心模块之后，整理成了SuperRDP项目。

项目开源在github，供需要的朋友使用。

前面说到，我是远程桌面重度用户，所以系统版本一更新，为了我自己，我也会第一时间马上更新。

所以，有需要的朋友可以放心大量的使用。

目前，我已经更新支持3个新系统版本，在最新Windwos10家庭版中稳定运行了几周，完美。
