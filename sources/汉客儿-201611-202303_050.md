# 小技能： Windows10突然不能复制粘贴谁搞鬼

最近连续遇到几次，电脑突然不能复制粘贴了，非常影响工作。

**(如果不想听我扯，就直接跳到最后看结果啊，我真贴心。)**

你们都懂得，程序员嘛，用的最多的就是ctrl+c，ctrl+v。

![](../Images/851a73637c159a990f9cf664574f6d81.png)

这不能用了，不是让我技能减半吗，痛苦无助。

有问题找度娘，经过一番搜索，找到很多方法，但都不是我想要的。

比如：

```



1. C:\Windows\System32\rdpclip.exe，dwm.exe用管理员启动，重启电脑
```

五花八门的，其实**重启电脑一般都能搞定的**。

但是有些时候，打开的东西多了，不想重启电脑。

所以应该怎么办呢？

继续搜索，终于在知乎看到点有用的东西了。毕竟是程序员，感觉这个靠谱。

![](../Images/78215cbd31e49a1bcea347eea9f5f175.png)

经过搜索，找到关键函数：

```
GetOpenClipboardWindow();
```

### 重点来了

几分钟搞定一个**ClipLock**的小程序，运行找到了占用剪切板的程序。

居然是最近装的**小米妙享**的一个进程。

![](../Images/a61b0a377fcbd64a326c9f5299a4c673.png)

![](../Images/b5317843d7e6e8a0f1b17e4ae3b902a6.png)

通过任务管理器结束进程，剪切板果然恢复正常，bingo！
