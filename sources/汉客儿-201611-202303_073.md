# 金庸：一个时代的落幕文

吃过晚饭，一个消息震惊得我久久无法消化。一代武侠大师金庸走完了他灿烂的一生，我不由想到了乔峰跳下悬崖的那一幕，怎么都无法相信。

  

我对金庸的生平事迹并没有太多关注，除了知道著名的关于他和他的表哥一个八卦外，其他基本一无所知。但这并不妨碍我喜欢老爷子的作品，以及对他的无法诉说的崇敬。

  

我爱好小说这件事真的是受到金庸作品的影响，因为我的启蒙读物就是老爷子的《飞狐外传》，那年我才10岁。那本黄旧的书依然让我记忆清晰，胡斐、金面佛苗人凤、苗若兰......其实我一直想不通当时家里怎么会有这么一本书，可能这就是我和小说不解的宿命吧。后来也一直游离在小说左右，十多年间断断续续，从来没有真正离开过，也从来没有真正停下来过。

  

在这个网络文学盛开的时代，涌现了太多太多优秀的作家，不管他们稿费如何高昂，粉丝如何庞大，但是无论如何都无法超越金庸先生的高度。因为他就是这些作家的偶像，是他们写作的起源。他代表着一个时代，他就是一个时代。

  

金庸小说翻拍的作品，代表了八零后整个青春的记忆。红了多少明星，火了多少作品，已经记忆不清。但无论如何他们背后都逃不开金庸的印记。无论多少大明星，多少大导演，他们都只是凡人，而金庸是大师。

  

作为同时代的武侠大家古龙、梁羽生，虽不乏经典作品，享誉文坛。但在我心里，只有一个金庸，无可替代。

  

金庸这个名字仿佛天生就带有武侠气质。说武侠不金庸，说金庸不武侠。两个名字紧紧融合在一起，无法分离。这就是金庸的魅力，武侠的魅力！

  

2018年10月30日(戊戌年 壬戌月 乙未日)，金庸走了，武侠走了。江湖不再，传说余怀！

  

再见，金庸！再见，武侠！

  

飞雪连天射白鹿，笑书神侠倚碧鸳。

金庸先生羽化仙，从此江湖武侠湮。
