无论在渗透测试还是src挖掘过程中，信息搜集阶段都是必不可少的，甚至有时可以说是最重要的环节之一，在此以本文总结一下我对于信息搜集的一些思路。

  

  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

基于搜索引擎的信息搜集

![](../Images/495745cee0d192e006179ddcb075fda3.png)

**google**

全球通用的搜索引擎，上面能找到的信息非常多。

附上一些常用的google语法

*   
*   
*   
*   
*   

```
 intext：把网页中的正文内容中的某个字符作为搜索的条件  intitle：把网页标题中的某个字符作为搜索的条件 filetype：指定一个格式类型的文件作为搜索对象  inurl：搜索包含指定字符的URL site：在指定的站点搜索相关内容
```

  

  

**fofa**

fofa是白帽汇推出的一款网络空间搜索引擎，确实好用，可以很方便的进行资产收集并通过高级语法筛选，美中不足的是不开会员只能看一页数据  

查询语法在官网https://fofa.so中，十分易于上手。

  

除此之外Shodan和Zoomeye等也是信息搜集的常用搜索引擎，不过平时笔者个人使用较少，这里就不再赘述。

  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

whois查询

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

查询whois信息可以获取关键注册人的信息，网站注册人有时身份就是管理员，后续可以采取社工，钓鱼等手段进行利用，还可以根据whois信息进一步收集资产，扩大攻击范围。

**方法**

网上在线whois查询，Linux whois命令等。

  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

子域名收集  

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

可以通过子域名收集的方法更加广泛的收集目标资产，一般主站的安全防护等级较高，而其之下的二级域名，三级域名等对应的网站则更容易作为渗透的切入点。![](../Images/495745cee0d192e006179ddcb075fda3.png)

**方法/工具**

1.Layer子域名挖掘机:支持图形化界面，对新手十分友好  

2.在线子域名查询

3.通过搜索引擎高级语法实现

  

Github上还有很多开源的子域名爆破软件，这里因为笔者个人使用较少就不再赘述，感兴趣的小伙伴可以自行探索。

  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

目录扫描

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

当确定了目标站点时，仅仅根据功能点去发现漏洞是不够的，目录扫描的作用是帮助白帽子在渗透过程中探测目标目录，可以通过目录结构判断目标站点使用的框架和模板等，同时还可以发现因源码泄露等导致的安全风险。

**工具**  

1.7kbscan：支持图形化界面，十分容易上手

2.dirsearch：基于python的一款目录扫描，基础用法

*   
*   
*   

```
python dirsearch.py -u xxx.compython dirsearch.py -u xxx.com -e * (指定所有语言)python dirsearch.py -u xxx.com -s 1（扫一下间隔一秒）
```

端口扫描

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

通过端口扫描可以获取目标开放的端口，并通过端口号了解目标服务器提供的服务类型从而进行针对性攻击，是渗透测试中的常见手段。  

附上网上师傅整理的常见端口及可能存在的漏洞

![](../Images/c3db8d6671c49330a9419b8219196754.png)

**工具**  

端口扫描的工具一般选用nmap，官网提供的windows版本支持图形化界面，易于上手的同时可以根据不同需求更改命令中的参数。

  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

指纹识别  

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

网站指纹识别是指根据网站中的关键字、url中的特定内容和目录中的特定文件等判断其使用的cdn、waf、容器和cms等信息，从而更好地进行针对性的渗透测试。

**工具/方法**

1.通过云悉，微步等平台在线识别

2.使用whatweb、wapplyzer等插件进行指纹识别

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

旁站查询

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

旁站是指同ip地址的其他站点，有时目标站打不进去可以从旁站下手，有概率旁站与目标站点在一台服务器上，此时拿下旁站即拿下目标站。  

**方法**

一般通过在线查询的方式获取旁站  

![](../Images/8d042090b045af84392f3cbd773cf3c2.png)

C段扫描

![](../Images/495745cee0d192e006179ddcb075fda3.png)

  

C段扫描是指扫描与目标IP处于同一个IP段的机器，进行渗透测试没有思路时可能会在同C段机器上发现突破点或发现同属于目标的其他资产，不过该方法容易误伤，慎用。
