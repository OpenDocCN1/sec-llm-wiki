# 造车新势力2019年终大盘点之：年度“最”......

**2019年就接近尾声了，在即将过去的2019年，相信每个人都遇到了很多的人和事。****或许有的你还没有来得及总结，或许有些人和事你根本就就不屑一顾。****按照惯例，今年四哥继续总结一下造车新势力们在2019年的表现，以飨诸君。****当然，纯属四哥一家之言，欢迎文明拍砖！**

  

**1、年度“没落”最快的新势力——知豆**去年还销量抢眼的知豆，今年销量比自由落体还快的速度跌至“销声匿迹”。曾经出身“寒门”（没有资质，以低速车起家），后来“加入豪门”（被吉利收购），继而获得资质，或许被很多人在“城市代步车”的细分领域寄予了颇高的期望，如今经营惨淡的结局，恐怕不在很多人的预期之中。

  

**2、年度“最尴尬”的新势力——云度汽车**云度汽车曾经很有网红的潜质，属于最早一批获得资质的造车新势力，更是最早量产的新势力之一。然而，网红的潜质终究也没有让云度成为网红。π1和π3两款车型，1~10月份累计上牌量分别为336和219辆，恐怕经营性亏损不是一个小数。而最近更是鲜少在媒体上见到云度汽车的报道，或许没有消息就是最好的消息吧，毕竟很多新势力在过去的几个月都是以负面消息居多，这也许是云度汽车不得不接受的“尴尬”局面。

![](../Images/c28ab54aaea9b909746047ed594f1566.png)

**3、年度最“乡情”新势力——零跑**由安防领军企业大华集团投资的零跑汽车，借道濒临死亡的“长江汽车”资质，推出了电动跑车——零跑S01。或许是其“亲民跑车”的缘故，网络上不少播放量挺高的视频中，零跑S01都是乡村婚礼的婚车。从销量上看，全年预计能达到千辆规模，如果是超跑，这个量就很可观了，但由于是售价十余万的“乡情跑车”，这个量还远远没法收回研发成本。就不知道2020年，零跑S01是否会在“乡村爱情故事”中有更大的斩获。  

  

**4、年度最“土豪”新势力——国能新能源（恒大新能源汽车）**“土豪”要拆分开来，首要条件是“土”，国能新能源采用了N年前SAAB Vector93的平台，甚至连外观都几乎没有啥改动，推出了一款EV，和现在新势力们各种炫酷造型以及多重叠加的电子网联设备相比，确实是最“土”，没有之一。国能新能源的“豪”恐怕还是体现在其股东恒大。

![](../Images/64c8e0e0d934c5aa2e6760d71d64c2b7.png)

大、大、大、大......，买、买、买......

  

**5、年度最悲催新势力——敏安汽车**出师未捷身先死，空有资质难变现。跻身最早获得资质的新势力，却在首款产品即将上市前夕，公司不得不“阶段性放假”！这悲催有谁能比？

![](../Images/4efa4c76e85bfcc2ec02d317cc7da00f.png)

  

**6、年度最局气新势力—— 国机智骏汽车**够不够“局气”要看有没有国字开头，在新势力中国机智骏绝对能算得上。背靠大树不差钱，一口气同时发三款车，这在造车新势力中，几乎是独一份。

![](../Images/664d80d7b47110c93e2cc814110553ca.png)

  

**7、年度最吸金新势力——小鹏汽车**11月13日，小鹏汽车官方宣布成功签署C轮融资，总金额为4亿美金。

![](../Images/4fee077ec0bc5d0f27e96f772c506b1e.png)

**8、跨年度“孕期最长”新势力——拜腾汽车**从FMC到和谐富腾，再到拜腾，如果将公司的产品比作“baby”的话，拜腾无疑是“孕期最长”的新势力。

![](../Images/7720e214692bdf84c4daf88f3ed92031.png)

到底是因为“屏”太大了还是因为别的呢？

  

**9、年度“最逆袭”的新势力——合众汽车**合众汽车也属于第一批获得资质的造车新势力，可在2018年之前一直没有太受关注。尤其是2018年最大股东华夏幸福退出之后，很多人都以为合众汽车或将夭折，然而，随着江西宜春的入主，合众汽车堪称年度“逆袭”的新势力典范。

  

![](../Images/06101f965d1f298dfa5aa06b630ad295.png "点击查看源网页")

其一是控股股东退出后，很短时间内找到了金主；其二，在产品投放上，也有看似合理的节奏，尤其是品牌改名“哪吒”之后，蹭了电影的热度。而终端实际销量，一款N01预计今年会接近万辆的销量，虽然还不足以支撑企业的正常运营，但是实际销量也能跻身新势力No.4。

  

**10、年度最“坑”的新势力——蔚来汽车**无论是创始人被调侃为年度最惨的人、亦或是新势力中年度销量榜首，都不足以掩盖企业巨亏的“瑕疵”。这个最“坑”评给蔚来应该不冤。
