# 一招怼破造车新势力掌门人吹的牛逼

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMzM3NTM3MA==&mid=2247484632&idx=1&sn=8cc60818a07e0b69424e26f5af581c84&chksm=e887d73ddff05e2b95c704f772dbde98afd3ac12e2cbb78d9d4bdc0d018ddcdb7be140d27217&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIzMzM3NTM3MA==&mid=2247484632&idx=1&sn=8cc60818a07e0b69424e26f5af581c84&chksm=e887d73ddff05e2b95c704f772dbde98afd3ac12e2cbb78d9d4bdc0d018ddcdb7be140d27217&scene=27#wechat_redirect)

  

入夏以来，多起新能源汽车（纯电动）自燃事件引发了普通消费者对新能源汽车的极度担忧。一方面，工信部作为主管部门，也终于官宣要有所行动了，要求全国排查新能源汽车安全隐患，并对涉事企业提出了事故上报的具体要求和隐瞒不报的处罚规则。而另一方面，在短短两个月时间，涉及多起（2起或以上）自燃事故的某造车新势力掌门人的惊人言论，让行业内人感到既忧心又可笑。

  

该“明星”掌门人的观点包括：**汽车自燃都有概率，燃油车是爆燃，电动好一些“， ”自燃有一定比例，但是从数量上看，燃油车比电动车多多了，也很少会看到电动车在行驶过程中出现问题“，进一步解释其观点”汽油是爆燃的，但电动车从冒烟到最后烧起来，一般有几分钟的时间，这个角度看，电动车会好一点“**。

  

除去咬文嚼字的挑剔之外，这位掌门人恐怕连最基本的一个汽车质量术语PPM都没有搞清楚（当然，四哥相信事实上他是应该清楚的，不知何故，要故意混淆或者弱化这个重要的汽车质量管控概念），这对应他观点中的“自燃有一定比例，但是从数量上看，燃油车比电动车多多了”这句话。从累计的绝对数量上来看，燃油车的自燃事件肯定比电动车多，但是从PPM值（每一百万辆中发生事故的比例）来看，这位同学创办的企业累计销售了一万多台车，发生自燃好几起（西安烧一台、安亭烧一台、武汉烧1台......还有在试验场烧的不统计），简单算数你这自燃的PPM值就几百了嘛，难道这烧电动真车还非得搞的和清明节“烧纸车”一样任性？

![](../Images/1a0050a7afe975934bab66c12eb931dd.png)

  

其实出现问题并不可怕，踏踏实实查明原因，解决问题，本来大家对电池包被“刮擦”变形导致的起火原因就持怀疑（当然，在专业人士的眼里，这种原因看起来似乎过于牵强），为啥就没有及时帮助用户全面排查呢？反而接二连三滴烧了起来。

  

要四哥说，其实没有必要高调解释说什么自燃的比例、什么从冒烟到烧起来的时间等等，这些绝对都不是任何一个你的客户愿意自己遇到的，你这里说的是一个比例，任何遇到此事的客户，对当事人来说就是100%。**其实要四哥给你们出个招包管用，让你们的PR也不必如此难受，只要安排每天直播你们自家的车子天天接送你家孩子的实况视频，保管比找什么媒体专访都管用！**对了，这个创意要是采用了，给不给创意费呢？用车抵俺可不敢开哈~~~
