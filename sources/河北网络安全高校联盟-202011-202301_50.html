0x00漏洞原理



命令执行是指对于代码中调用了命令执行函数，且对传入参数过滤不严使得可以执行用户输入的系统命令。
命令执行函数:
1.system()        执行外部程序，并且显示输出 2.exec()          执行一个外部程序  3.shell_exec()    通过 shell 环境执行命令，并且将完整的输出以字符串的方式返回。 4.passthru()      执行外部程序并且显示原始输出  5.pcntl_exec()    在当前进程空间执行指定程序 6.popen()          打开进程文件指针 7.proc_open()     执行一个命令，并且打开用来输入/输出的文件指针。



0x01 LOW




<?phpif( isset( $_POST[ 'Submit' ]  ) ) {    // Get input    $target = $_REQUEST[ 'ip' ];    //没有任何过滤，可以用 ; | & && || 等拼接    // 根据系统执行ping命令    if( stristr( php_uname( 's' ), 'Windows NT' ) ) {       // Windows        $cmd = shell_exec( 'ping  ' . $target );    //命令执行    }    else {        // *nix        $cmd = shell_exec( 'ping  -c 4 ' . $target );    }    // Feedback for the end user    $html .= "<pre>{$cmd}</pre>";}?>
可以看到有一个危险函数shell_exec ;然后有一个可控变量$target ;并且没有任何过滤，可以利用管道符或分隔符进行拼接，使其在执行完ping命令后执行任意命令。
函数解释:
sstristr(string,search)stristr() 函数查找字符串在另一个字符串中第一次出现的位置。如果成功，则返回字符串的其余部分（从匹配点）。如果没有找到该字符串，则返回 false
php_uname ([ string $mode = "a" ] ) : string返回运行 PHP 的系统的有关信息mode 是单个字符，用于定义要返回什么信息：'a'：此为默认。包含序列 "s n r v m" 里的所有模式。's'：操作系统名称。例如：FreeBSD。'n'：主机名。例如：localhost.example.com。'r'：版本名称，例如：5.1.2-RELEASE。'v'：版本信息。操作系统之间有很大的不同。'm'：机器类型。例如：i386。
shell_exec ( string $cmd )通过 shell 环境执行命令，并且将完整的输出以字符串的方式返回。

<?phpif( isset( $_POST[ 'Submit' ]  ) ) {    // Get input    $target = $_REQUEST[ 'ip' ];    // 设置黑名单，过滤了'&&'和';'仍然可用其他方式突破；如：| & ||      $substitutions = array(        '&&' => '',        ';'  => '',    );    // 将黑名单中的字符过滤    $target = str_replace( array_keys( $substitutions ), $substitutions, $target );    // Determine OS and execute the ping command.    if( stristr( php_uname( 's' ), 'Windows NT' ) ) {        // Windows        $cmd = shell_exec( 'ping  ' . $target );    }    else {        // *nix        $cmd = shell_exec( 'ping  -c 4 ' . $target );    }    // Feedback for the end user    $html .= "<pre>{$cmd}</pre>";}?>
如上面注释所言，虽然设置了黑名单，对部分符号进行了过滤，但是仍然没有完全控制输入的参数，因此还是可以突破。
函数解释:
str_replace ( mixed $search , mixed $replace , mixed $subject [, int &$count ] )将$subject中的$search替换为$replace
array_keys()返回数组中部分的或所有的键名

此时我再对其黑名单增加一些参数
修改如下：
<?php    // Get input    $target = $_REQUEST[ 'ip' ];     $substitutions = array(        '&'  => '',        ';'  => '',        '| ' => '',        '-'  => '',        '$'  => '',        '('  => '',        ')'  => '',        '`'  => '',        '||' => '',        '|'  => '',        'cat' =>'',        'ls' => '',        ' ' => '',     );    // Remove any of the charactars in the array (blacklist).    $target = str_replace( array_keys( $substitutions ), $substitutions, $target );    // Determine OS and execute the ping command.    if( stristr( php_uname( 's' ), 'Windows NT' ) ) {        // Windows        $cmd = shell_exec(  $target );    }    else {        // *nix        $cmd = shell_exec(  $target );    }?>

此刻过滤了空格和部分敏感参数，但是还有部分可用的参数；比如用l\s代替ls；用%d0%a0代替分隔符；用${IFS}代替空格。

<?phpif( isset( $_POST[ 'Submit' ]  ) ) {    // 检查token    checkToken( $_REQUEST[ 'user_token' ], $_SESSION[ 'session_token' ], 'index.php' );    // Get input    $target = $_REQUEST[ 'ip' ];    $target = stripslashes( $target );    //过滤反斜线    // Split the IP into 4 octects    $octet = explode( ".", $target );    // 判断输入是否为ip地址    if( ( is_numeric( $octet[0] ) ) && ( is_numeric( $octet[1] ) ) && ( is_numeric( $octet[2] ) ) && ( is_numeric( $octet[3] ) ) && ( sizeof( $octet ) == 4 ) ) {        // If all 4 octets are int's put the IP back together.        $target = $octet[0] . EXP1:c''at flag.txt
EXP2:c""at flag.txt
EXP3:ca$@t flag.txt
(5)反引号绕过：
EXP1:cat `ls`
(6)liunx工具绕过：
