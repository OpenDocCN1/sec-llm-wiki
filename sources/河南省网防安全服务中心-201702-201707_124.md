# 网防G01的网页木马检测及防护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247484564&idx=1&sn=27af1f5c47df6a765223198468665609&chksm=97884cf5a0ffc5e340221c8b2fe0068c232b88e1b7295b2c2318b0d8cb2f27964f28a42ad33f&scene=126&sessionid=1681668082#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247484564&idx=1&sn=27af1f5c47df6a765223198468665609&chksm=97884cf5a0ffc5e340221c8b2fe0068c232b88e1b7295b2c2318b0d8cb2f27964f28a42ad33f&scene=126&sessionid=1681668082#rd)

网页木马（也称作webshell）是政府网站、Web业务系统面临的最大安全威胁，攻击者通过漏洞攻击侵入系统后，植入网页木马可以长期控守网站，甚至进行系统提权，层层突破，进而控制整个网络，实现长期潜伏的目标，

  

近年来，网页木马的存在形式和攻击模式也随着防护手段的提高在不断发展，通过伪装、变形、加密等手段，致使查杀与发现难度越来越大。传统的单一的网页木马检测方法具有误报率高、严重滞后等缺陷，网防G01通过基于特征和行为两种模式，利用沙箱技术，可有效发现和隔离木马。

  

网防G01具有的针对webshell的防护功能：

![](../Images/20c8126f03d2ee0799c9cd9530817a30.png)

图-1 网防G01的webshell防护相关功能

  

**1、webshell扫描**：网防G01的巡检优化功能里面自带webshell木马扫描就是针对已知特征的网页木马进行扫描，通过修复功能能够隔离webshell木马文件，详情里可查看webshell木马的详细内容。

  

![](../Images/6a5b78ca9f3a3132a484fe16dd5a6448.png)

图-2 webshell一键巡检及巡检目录自定义

    

![](../Images/a6f15af340a17ade128651adf5bed7e2.png)

图-3 感染文件修复及隔离（手动）

  

![](../Images/3e3d8cc533ef503ed4bcab67bd3365b8.png)

图-4 木马样本详情

  

**2、已知Webshell自动隔离**：webshell自动隔离功能是网防G01监测到新创建的文件（包括上传图片、文档等）具有webshell特征时，会自动将此webshell隔离，阻止木马文件创建到服务器的web目录当中。

  

![](../Images/156c778ac1016dc043833b4d15bdb6b6.png)

图-5 已知webshell自动隔离

  

**3、未知Webshell拦截**：网防G01的未知webshell防护不同于WAF，网防G01基于RASP（Runtime Application SelfProtect）技术和云端沙箱检测的技术，从而能够实时刻画攻击事件现场，阻断恶意攻击行为。

  

![](../Images/6a9481dff1867a54005642ddfd4f1313.png)

图-6  未知webshell防护机制

  

**4、webshell攻击事件及溯源**：webshell攻击事件能够实时描述webshell攻击的场景，通过上下文关联检测，对webshell的攻击指征和攻击路径进行详细的刻画。  

  

![](../Images/8abb26bcf28111c816c46787e2a7f2c9.png)

图-7webshell攻击事件回溯  

  

  

政府网站综合防护系统（简称网防G01），具有操作系统加固、网站防护、webshell防护、防篡改、威胁情报等全面的服务内容。
