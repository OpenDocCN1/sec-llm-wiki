# 研究人员将永恒之蓝EternalBlue移植到Windows10

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247484529&idx=5&sn=288a402f4340f0bff4e4a8eb84e0cb05&chksm=97884c10a0ffc506e2e23818964e6bf78a5e2885cb8cfd4aa5b867641b309d8347b902a5a5f9&scene=126&sessionid=1681668087#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247484529&idx=5&sn=288a402f4340f0bff4e4a8eb84e0cb05&chksm=97884c10a0ffc506e2e23818964e6bf78a5e2885cb8cfd4aa5b867641b309d8347b902a5a5f9&scene=126&sessionid=1681668087#rd)

勒索软件 WannaCry 上个月引发了全球的关注，它利用 Shadow Brokers 泄漏的 NSA 漏洞利用代码 EternalBlue 进行传播。EternalBlue 主要针对的是 Windows XP 和Windows 7。

现在，RiskSense 的研究人员宣布他们已经将 EternalBlue 移植到 Windows 10，但短时间他们不会公开 Windows 10 版本的源代码。研究人员在一份报告（PDF）中解释说，开发 Windows 10 版本是必要的，此举旨在帮助防御者更好的理解利用链，为漏洞利用构建防御机制。研究人员称，**安装微软释出的补丁 MS17-010 仍然是目前防御 EternalBlue 的最佳方法**。
