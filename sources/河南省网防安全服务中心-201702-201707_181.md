# 信大天瑞助力"《网络安全法》宣传活动启动仪式"

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247484505&idx=1&sn=cba805700dff09e27ad3bad12a37f4e2&chksm=97884c38a0ffc52e866046a5be0e1b855f87fb38f56a98f5e8a8f11de0f6d462481165861ee8&scene=126&sessionid=1681668087#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247484505&idx=1&sn=cba805700dff09e27ad3bad12a37f4e2&chksm=97884c38a0ffc52e866046a5be0e1b855f87fb38f56a98f5e8a8f11de0f6d462481165861ee8&scene=126&sessionid=1681668087#rd)

2017年 6月1日起，《中华人民共和国网络安全法》将正式施行，这是我国第一部关于网络安全的基础性法律，也是我国网络空间法治化建设的重要里程碑。为了让广大网友和公民全面了解《网络安全法》的具体内容，掌握化解网络风险的法律武器，合理、合法地维护个人网络权益， 5月31日上午，由河南省公安厅、郑州市公安局主办的“《中华人民共和国网络安全法》宣传活动启动仪式”在郑州市紫荆山广场隆重举行。

  

![](../Images/bac8a8338932ab2d2166f325d9b1bc03.png)

  

郑州信大天瑞信息技术有限公司作为河南省网安总队、郑州市网安支队应急服务支撑单位，应邀参与启动仪式，并就《网络安全法》的普及开展现场宣传，受到与会领导的好评！
