4月28日CNNVD共发布安全漏洞67个，更新安全漏洞4个。主要影响厂商为美国Google（6个）、美国Linux（6个）、美国CloudBees（4个），主要影响产品为Google Chrome（5个）、Linux kernel（3个）、CloudBees Jenkins（3个）。

今日需关注的典型漏洞如下：

【漏洞名称】Google Chrome FFmpeg 数字错误漏洞

【漏洞编号】CNNVD-201704-1379（CVE-2017-5047）

【漏洞详情】Google Chrome是美国谷歌（Google）公司开发的一款Web浏览器。FFmpeg是FFmpeg团队的一套可录制、转换以及流化音视频的完整解决方案。

Google Chrome中的FFmpeg存在整数溢出漏洞。远程攻击者可借助特制的视频文件利用该漏洞造成越边界内存写入。以下版本受到影响：基于Mac、Windows和Linux平台的Google Chrome 57.0.2987.98之前的版本，基于Android平台的Google Chrome 57.0.2987.108之前的版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://chromereleases.googleblog.com/2017/03/stable-channel-update-for-desktop.html

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017041379

【漏洞名称】Linux kernel 信息泄露漏洞

【漏洞编号】CNNVD-201704-1374（CVE-2007-6761）

【漏洞详情】Linux kernel是美国Linux基金会发布的操作系统Linux所使用的内核。

Linux kernel 2.6.24之前的版本中的drivers/media/video/videobuf-vmalloc.c文件存在安全漏洞，该漏洞源于程序没有初始化videobuf_mapping数据结构。本地攻击者可利用该漏洞获取敏感信息。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=0b29669c065f60501e7289e1950fa2a618962358

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017041374

【漏洞名称】CloudBees Jenkins 跨站请求伪造漏洞

【漏洞编号】CNNVD-201704-1517（CVE-2017-1000356）

【漏洞详情】CloudBees Jenkins是美国CloudBees公司的一款基于Java开发的开源的、可持续集成的自动化服务器，它主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。LTS（Long-Term Support）是CloudBees Jenkins的一个长期支持版本。

CloudBees Jenkins 2.56及之前的版本和LTS 2.46.1及之前的版本中存在跨站请求伪造漏洞。远程攻击者可通过诱使用户打开Web页面利用该漏洞执行未授权的操作。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://jenkins.io/security/advisory/2017-04-26/

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017041517


【漏洞名称】Apache FOP 安全漏洞

【漏洞编号】CNNVD-201704-877（CVE-2017-5661）

【漏洞详情】Apache FOP（格式化对象处理器）是美国阿帕奇（Apache）软件基金会的一个由XSL格式化对象（XSL-FO）和输出独立格式化程序驱动的打印格式化程序。它能够读取格式化对象（FO）树，并将生成的页面呈现给指定的输出。

Apache FOP 2.2之前的版本中存在XML外部实体注入漏洞。攻击者可通过发送恶意的SVG文件利用该漏洞获取文件系统上的文件。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://issues.apache.org/jira/browse/AMQ-6470

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017040877


【漏洞名称】Oracle JD Edwards EnterpriseOne Tools 安全漏洞

【漏洞编号】CNNVD-201704-1264（CVE-2017-3517）

【漏洞详情】Oracle JD Edwards Products是美国甲骨文（Oracle）公司的一款全面集成的企业资源计划管理软件套件（ERP），它提供财务管理、项目管理和资产生命周期管理等应用模块。JD Edwards EnterpriseOne Tools是其中的一个工具组件。

Oracle JD Edwards Products中的JD Edwards EnterpriseOne Tools组件9.2版本的Web Runtime SEC子组件存在安全漏洞。攻击者可利用该漏洞未授权读取数据，造成拒绝服务，影响数据的保密性和可用性。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpuapr2017-3236618.html

【漏洞链接】

http://www.cnnvd.org.cn/vulnerability/show/cv_id/2017041264
