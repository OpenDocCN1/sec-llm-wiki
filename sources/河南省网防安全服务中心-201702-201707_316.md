# CNNVD最新漏洞（2017-04-20）

今日CNNVD共发布安全漏洞47个，更新安全漏洞9个。主要影响厂商为美国Oracle（8个）、美国VMware（7个）、美国Adobe（5个），主要影响产品为（VMware Workstation和Horizon View Client（6个）、Oracle Fusion Middleware（4个）、Adobe Acrobat和Reader（2个）。

**今日需关注的典型漏洞如下：**

**【漏洞名称】****VMware Workstation和Horizon View Client 缓冲区错误漏洞**

**【漏洞编号】****CNNVD-201704-956（CVE-2017-4908）**

**【漏洞详情】**VMWare Workstation和Horizon View Client都是美国威睿（VMware）公司的产品。前者是一套桌面虚拟计算机软件；后者是一款可以从任何位置对VMware Horizon桌面进行访问的客户端设备。

VMware Workstation和Horizon View Client中存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞在主机上执行任意代码或造成拒绝服务。以下产品和版本受到影响：VMware Horizon View Client 6.2.x版本，7.x版本；VMware Workstation 12.x版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.vmware.com/security/advisories/VMSA-2017-0008.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040956

  

**【漏洞名称】****Oracle Primavera Products Suite 安全漏洞**

**【漏洞编号】****CNNVD-201704-891（CVE-2017-3503）**

**【漏洞详情】**Oracle Primavera Products Suite是美国甲骨文（Oracle）公司的一款项目组合管理解决方案套件产品。Primavera P6 Enterprise Project Portfolio Management（P6 EPPM）是其中的一个用于项目的规划、管理和执行的组件。

Oracle Primavera Products Suite中的Primavera P6 EPPM组件的Web Access (Apache Commons BeanUtils)子组件存在安全漏洞。攻击者可利用该漏洞控制组件，影响数据的可用性。以下版本受到影响：Oracle Primavera Products Suite 8.3版本，8.4, 15.1版本，15.2版本，16.1版本，16.2版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpuapr2017-3236618.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040891

  

**【漏洞名称】****Apache CXF JAX-RS XML Security streaming客户端安全漏洞**

**【漏洞编号】****CNNVD-201704-874（CVE-2017-5653）**

**【漏洞详情】**Apache CXF是美国阿帕奇（Apache）软件基金会的一个开源的Web服务框架。该框架支持多种Web服务标准、多种前端编程API等。JAX-RS XML Security streaming clients是其中的一个使用XML签名和XML加密来保护JAX-RS客户端和端点的客户端。

Apache CXF 3.1.11之前的版本和3.0.13之前的版本中的JAX-RS XML Security streaming客户端存在安全漏洞，该漏洞源于程序没有验证服务响应是否签名或加密。远程攻击者可利用该漏洞欺骗服务器。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

http://cxf.apache.org/security-advisories.data/CVE-2017-5653.txt.asc?version=1&modificationDate=1492515074710&api=v2

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040874

  

**【漏洞名称】****Adobe Acrobat和Reader 安全漏洞**

**【漏洞编号】****CNNVD-201704-667（CVE-2017-3022）**

**【漏洞详情】**Adobe Acrobat和Reader都是美国奥多比（Adobe）公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。

Adobe Acrobat和Reader中存在内存损坏漏洞。攻击者可利用该漏洞泄露内存地址。基于Windows和Macintosh平台的以下产品和版本受到影响：Adobe Acrobat DC和Acrobat Reader DC Continuous 15.023.20070及之前的版本；Acrobat DC和Acrobat Reader DC 15.006.30280及之前的版本；Acrobat和Reader Desktop 11.0.19及之前的版本。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://helpx.adobe.com/security/products/acrobat/apsb17-11.html

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040667

  

**【漏洞名称】****Android Qualcomm SPCom驱动程序权限许可和访问控制漏洞**

**【漏洞编号】****CNNVD-201704-613（CVE-2016-5856）**

**【漏洞详情】**Android是美国谷歌（Google）公司和开放手持设备联盟（简称OHA）共同开发的一套以Linux为基础的开源操作系统。Qualcomm SPCom Driver是其中的一个串口通信驱动组件。

Android 7.0之前的版本中的Qualcomm SPCom驱动程序存在提权漏洞。攻击者可借助本地恶意的应用程序利用该漏洞执行任意代码。

目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：

https://source.android.com/security/bulletin/2017-03-01

**【漏洞链接】**

http://www.cnnvd.org.cn/vulnerability/show/cv\_id/2017040613
