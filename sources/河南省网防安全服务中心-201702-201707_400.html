【漏洞预警】IIS 6.0 远程代码执行0day

2017年3月27日网络中公开了关于Windows Server 2003 R2系统下的IIS6.0 远程代码执行0day漏洞。该0day漏洞早在2016年8月份被人在外利用。该0Day漏洞可远程执执行任意代码，危害程度高。影响严重。目前FOFA系统中共有约373万Windows系统上的IIS6.0对外开放（仅为分布情况，非受影响情况），中国共有约60万对外开放。

漏洞原理与危害

在Windows Server 2003 R2的操作系统中，开启了WebDav服务的IIS 6.0 存在缓冲区溢出漏洞，导致任意代码执行。WebDav服务中的ScStoragePathFromUrl 函数通过一个以"If: <http://"开头的的超长header 的PROPFIND请求中，该函数被调用了两次。最终导致缓冲区溢出漏洞，执行任意代码。执行代码权限为IIS的Network组权限。该漏洞而使远程攻击者提升权限，控制系统。 WebDav（Web-based Distributed Authoring and Versioning） 一种基于 HTTP 1.1协议的通信协议。它扩展了HTTP 1.1，在GET、POST、HEAD等几个HTTP标准方法以外添加了一些新的方法，使应用程序可对Web Server直接读写，并支持写文件锁定(Locking)及解锁(Unlock)，还可以支持文件的版本控制。在Windows Server 2003的系统中WebDav服务器在IIS中内置但默认不开启。

漏洞影响

Microsoft Windows Server 2003 R2 开启WebDAV服务的IIS6.0。目前漏洞代码已经在网络中公开，任何攻击者都可能修改该利用代码，并进行恶意破坏。 目前白帽汇安全研究人员在Windows Server 2003 R2系统中测试成功复现，其他系统还在测试当中(请持续关注)。
