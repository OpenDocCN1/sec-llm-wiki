# 许昌市公安局与信大天瑞签署战略合作协议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247484116&idx=1&sn=ef078515fb0c92b115388d40ae8aab2b&chksm=97884ab5a0ffc3a3009e469730166aecb61d82e7ef09c4dab8dfce902ca09623360f0b6e80dc&scene=126&sessionid=1681668154#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247484116&idx=1&sn=ef078515fb0c92b115388d40ae8aab2b&chksm=97884ab5a0ffc3a3009e469730166aecb61d82e7ef09c4dab8dfce902ca09623360f0b6e80dc&scene=126&sessionid=1681668154#rd)

**2017年3月3日，许昌市公安局网络安全保卫支队与郑州信大天瑞信息技术有限公司在许昌市公安局共同签署了战略合作协议，将围绕网络安全及关键信息基础设施防护等领域展开合作。**

  

![](../Images/c595c144cfcd703132910eb248a33c64.png)

  

网络安全保卫支队长朱建军，副支队长苏博，信大天瑞负责人郭梦非以及相关业务人员出席签约仪式。

  

![](../Images/a023123807c80183a332105bb70de717.png)

  

战略合作协议的签署，实现了信大天瑞与许昌市公安局的优势互补。

  

根据协议，后续双方将开展全方位、深层次的战略合作。其中，信大天瑞作为公安部第一研究所授权的G01河南服务站，将充分利用公司技术优势、人才优势，和许昌市公安局的业务优势、资源优势，通过合作互补、协同创新，将共赢发展，为许昌市在网络安全保障、关键信息基础设施防护，网安大数据、威胁情报、应急响应服务等方面展开充分合作。

  

![](../Images/231ea69509d1d95e1caaa682a8f46c21.png)

  

签约仪式的完成，标志着许昌公安警企战略合作又迈进了坚实的一步，对于推动信息化与警务工作融合发展，提升许昌公安“打防管控”一体化综合实战能力具有十分重大的战略意义。

  

![](../Images/f71133a385bc78c7d271b4a181b14338.png)

  

未来，双方将发挥各自优势，在围绕网络安全、关键信息基础设施防护、网络空间探测、威胁情报等相关领域的技术研究、交流培训和推广应用等方面加强合作，显著增强许昌市公安网络安全保障与实战能力，满足实战需求，进一步提升技术水平，确保关键信息基础设施防护，为许昌市网络安全提供强大科技守护之盾!
