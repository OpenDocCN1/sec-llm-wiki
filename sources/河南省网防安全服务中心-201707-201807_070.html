去年，邻居是个小MM，闲来无聊，就想看看她在干嘛，于是一条清晰的思路浮现在脑海~


通过wifi万能钥匙探测她家的wifi网络信号，确认好ssid名称之后，发现万能钥匙居然有密码，果断连接上去。使用密码查看器获得密码后，我就伪造了一个跟她相同的wifi网络，并使用deauth攻击，使其被迫下线，接入自己的钓鱼wifi。

这样能干的事情就很多了。通过js注入，提示她更新flash，并在这边利用远控，远程截屏，发现她在看电视，并在C:\**\Documents\Tencent Files下发现QQ号。当时就加了她的QQ号，告诉妹子她在干嘛，家在哪里，当时可把妹子吓坏了，果断邀请美女出去吃饭，后面的事情不可描述~

当然这种事情我是不可能干嘀~

本文通过测试环境重现整个过程，附有视频教程。

纯干货走起


测试环境：树莓派3b（X东有售）

系统环境：kali linux2018.2-rpi3

利用工具：fruitywifi、chaos、winrar等


一、环境搭建

1.1 系统安装

下载kali linux 2018.2-rpi3镜像，解压并安装，使用dd或者win32diskimager烧录至sd卡中（Kali下载地址：https://images.offensive-security.com/arm-images/kali-linux-2018.2-rpi3-nexmon.img.xz）。

 首次启动时不要连接外置无线网卡，这样可以通过名称有效的区分板载网卡和外置网卡。

登录账号：root 密码：toor

修改更新源。这里采用清华大学的debian9的更新源。

nano /etc/apt/sources.list

注释原有更新源，添加以下代码：

deb http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ stretch main non-freecontrib

deb-src http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ stretch main non-freecontrib

1.2 更新系统

apt-get update

apt-get upgrade

apt-get disk-upgrade

1.3 异常处理

更新时会提示公钥异常

gpg --keyserver  keyserver.ubuntu.com --recv-keys9165938D90FDDD2E

gpg --export --armor  9165938D90FDDD2E | sudo apt-key add -


开机时你会发现字体中文乱码，安装中文字体

apt-get install ttf-wqy-zenhei

更改系统配置

dpkg-reconfigure locales

这里使用空格键选中，回车下一步。配置完后reboot重启即可解决。

更换更新源，这里采用kali linux 2018的更新源

nano /etc/apt/sources.list

注释原有更新源

添加以下代码：

#清华大学

debhttp://mirrors.tuna.tsinghua.edu.cn/kali kali-rolling main contrib non-free

deb-srchttps://mirrors.tuna.tsinghua.edu.cn/kali kali-rolling main contrib non-free

1.4 安装fruitywifi

apt-get installfruitywifi-module-fruityporxy

1.5 安装chaos

安装依赖

apt install golang xterm git upx-ucl -y

下载chaos源码

git clonehttps://github.com/tiagorlampert/CHAOS.git

安装截屏套件

go get github.com/kbinani/screenshot&& go get github.com/lxn/win

go install github.com/kbinani/screenshot&& go install github.com/lxn/win

至于如何让别人连接你的wifi：

1、使用wifi万能钥匙破解密码后，使用路由器做桥接，将自己的路由器设置有上游设备，或将ssid设置与目标wifi一致，密码一致，使用deauth攻击，迫使对方下线，接入自己的wifi。

2、如何无法使用万能钥匙破解，使用Wifiphisher，迫使对方下线，通过固件升级的方式欺骗对方输入密码。或者可以直接设置个公开的wifi，不过这个办法不太好用。
