# 麦肯锡公司报告预测 2018年人工智能领域十大发展趋势

“ 

人工智能是各国政府和企业竞相抢占的新技术领域，鉴于世界上一些大型企业都在加大投资力度推动人工智能的发展，该技术必定会在2018年取得重大进展。

”

  

**一、人工智能将成为政治问题**

![](../Images/8c80ec8b7077e91c1caa2e917c550347.png)

人工智能在创造就业机会的同时，也会导致一部分人失业。比如，无人驾驶车辆导致每月25000名工人失业，如果大型仓库只有几十人就可以运作，那么目前在美国仓库工作的100万名装卸工人将面临失业。

  

**二、后勤工作将变得更加高效**

![](../Images/d6cf60002c3e4caf2f71daffbb3c7b16.png)

 未来，一个约2万平方米的物流中心仅需要一名管理人员，其他运行工作都由人工智能完成。未来的仓库将更加智能和自动化，采用可提供全天时服务的机器人设计。2012年，亚马逊公司以7.75亿美元的价格收购了Kiva系统公司，该公司研发的可学习性机器人能够在亚马逊仓库高效地寻找和运输货物。该技术现已投入使用，未来将在亚马逊高效、低成本的物流系统中扮演更加重要的角色。

  

**三、无人****驾驶汽车**

![](../Images/e43f3fc777898d5fea2b95cf4da073e1.png)

特斯拉公司是推出无人驾驶汽车的首批汽车制造商，其他传统汽车制造商也将在2018年研发先进无人驾驶技术。

  

**四、先进机器人战士**

![](../Images/3899d5d795a610f5c6d358fd01035d58.png)

DARPA已率先在人工智能领域取得技术突破，将在互联网和GPS导航方面发挥重要作用。目前，DARPA正在与波士顿动力公司合作研发一系列可用于“救灾”和作战的机器人，其中具有代表性的是Atlas后空翻机器人。

  

**五、机器学习将能辅助知识工作者**

![](../Images/c2a7a9a3ee1ed5177b22fc0c4a3f5fe0.png)

基于人工智能的Gong、Chorus和Jog等工具，可以帮助销售代表完成电话记录，指导客服人员提高表达效率。人工智能有望在2018年及以后为“白领”阶层的工作提供支持。

  

**六、人工智能将完成内容创造**

![](../Images/fb2633f6eec601aaf6c4234057367b86.png)

《今日美国》、CBS广播公司和赫斯特杂志国际集团正在寻求应用人工智能技术进行内容创造。比如，Wibbitz软件能够提供一种软件即服务的交付平台，允许出版商将文字内容转换成视频形式。美联社正在使用由Automated Insights科技公司研发的Wordsmith工具，该工具能基于收集到的数据，采用自然语言生成技术，撰写新闻故事。2018年，将有更多媒体公司应用自然语言生成和视频技术。

  

**七、P2P网络会提高透明度**

![](../Images/f9aac69add7148ee77b01cb5b3d22e4b.png)

机器学习是人工智能的一种形式，脸书等公司已经使用统计建模帮助计算机决定接下来向用户展示的内容，为了使建模正常运行，需要大量数据和强大计算能力维持运行。随着P2P网络的兴起，私人电脑通过互相联结形成强大的集体网络力量，从而使小型组织也能直接运行最先进的人工智能项目。

  

**八、消费者将习惯于与技术交流**

![](../Images/f2ffd032c18af6b0d8a0c0ce557da212.png)

2017年亚马逊智能对讲机销售量达2000万套，谷歌Home和苹果Airpod等智能设备销量持续增加，这表明，很多人正习惯于通过语音指令来与技术设备进行沟通。2018年，随着智能助理与计算机、智能手机和电视融为一体，消费者将会更加习惯于基于语音的交互。

  

**九、数据科学家的需求提升**

![](../Images/bb5dbdab0fe29a4dbe2aeeb1426b23c5.png)

IBM公司数据显示，对数据科学家的需求在2020年前会增加至270万人。随着机器学习平台数据量的增加、各类型企业致力于收集并进行高效数据分析，未来机器平台必然会需要大量大数据分析人员。

  

**十、人工智能将战胜疾病**

![](../Images/e59b5e5499e09bc248cd230483ce1617.png)

计算机对等网络能够通过收集和分析人类分子数据来解决健康问题，该技术的形成受到了区块链和人工智能两大技术的启发。机器学习技术对疾病进行识别和分析，以快速和低成本方式获得新型药物和治疗方法。
