“网防G01”应对Microsoft Windows SMB远程代码执行漏洞(CVE-2017-11780)

SMB协议是基于TCP－NETBIOS下的，一般端口使用为139，445。


端口封闭是网防G01“应用防护”的一项基本功能，网防G01能自动识别服务器上的服务及其对应的端口，主要是帮助用户检测并防护对外暴露的危险端口，除了445端口外，默认情况下135、139等端口也会暴露在公网外，成为易受黑客攻击的目标，用户可以充分利用封闭端口功能，减少危险端口暴露，降低被攻击的风险。


在Windows服务器上部署“网防G01”服务器安全防护软件，在网防G01的“应用防护”列表中找到445端口，点击“封闭端口”一键封闭445端口，禁止外网访问，即可有效防御Microsoft Windows SMB远程代码攻击。



用户可以基于网防G01的服务器漏洞修复功能，远程检测并为所有服务器一键修复包含“Microsoft Windows SMB远程代码执行”的所有安全漏洞。
