# 国家互联网应急中心（CNCERT）开通“魔鼬”木马感染数据免费查询服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247484727&idx=1&sn=946d5330efa755b611f50d6f31a252f2&chksm=97884d56a0ffc4408c161df0a10b31c1e1bc1607b914d1caf3094800ce2a6ed60bdb212e3ab6&scene=126&sessionid=1681668067#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247484727&idx=1&sn=946d5330efa755b611f50d6f31a252f2&chksm=97884d56a0ffc4408c161df0a10b31c1e1bc1607b914d1caf3094800ce2a6ed60bdb212e3ab6&scene=126&sessionid=1681668067#rd)

2017年8月2日开始，一款名为“魔鼬”的木马在互联网大规模传播。“魔鼬”木马可控制感染电脑对外发动拒绝服务攻击，具有潜在危害大、传播范围广等特点。8月3日至今，国家互联网应急中心监测发现我国境内有9余万台电脑感染了此木马。为此，国家互联网应急中心开通了“魔鼬”木马感染数据免费查询服务，点击网址http://d.cert.org.cn/moyou即可查询您使用的IP地址是否受到木马感染。如果您有意见或建议，欢迎通过电话 010-82990999或邮箱cncert@cert.org.cn与国家互联网应急中心联系。

![](../Images/f89dd924af2d6bc215e1cbf0494e2398.png)

说明：

1、“魔鼬”木马暂只能感染Windows系统，请您在Windows电脑浏览器中打开查询页面进行查询，地址：http://d.cert.org.cn/moyou。

 2、如果您使用宽带拨号上网或手机上网，由于IP地址经常变化，会导致查询结果不准确，仅供参考。
