网防 G01 针对网站防护采用先进的 **RASP**（**运行时应用程序自我防护**），基于 IIS 网站和Apache 的网站，网防 G01 的安装包中集成了 RASP 模块，安装完成后则 RASP 模块生效，基于JAVA平台的，需要手动部署 jsagent，如下所示： 

  

![](../Images/2c52eaff30021fe63d45977a38838b1e.png)

针对 JAVA 平台网防 G01 提供两种模式供用户选择：RASP 模式和 Web 过滤防护，网防G01 针对 JAVA 平台的两种防护模式默认安装后是没有开启的（后续将更改为默认开启），需要用户去应用防护下面去针对每一个应用进行设置。JAVA 平台的 RASP 防护必须要安装Jsagent 模块，防护作用才能生效。安装完成效果如图所示 IIS、Apache 和 Java 平台的设置完成效果界面：

传统的 WAF 是通过过滤用户的输入进行网站应用的防护，攻击者能够通过各种方法进行绕过，而 RASP 不再关注用户数输入数据，而是监控应用程序本身，使攻击者无法绕过。 RASP 与 WAF 的对比图如下所示： 

  

![](../Images/a127e9c8f4bba99cf31eaa7565e229fe.png)
