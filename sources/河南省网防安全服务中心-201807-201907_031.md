# 在Kali Linux中使用SET工具包进行网站克隆

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247488021&idx=1&sn=be5a97afbd7c99af8a719f6d4560ed22&chksm=97885a74a0ffd36265454445485266d9bd5afb7fd6f93b154506e7beac514f5c74b93040f994&scene=126&sessionid=1681667839#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247488021&idx=1&sn=be5a97afbd7c99af8a719f6d4560ed22&chksm=97885a74a0ffd36265454445485266d9bd5afb7fd6f93b154506e7beac514f5c74b93040f994&scene=126&sessionid=1681667839#rd)

SET工具包：Social-Engineer Toolkit专门用于社会工程的高级攻击包。SET通过https://www.social-engineer.org/ 发布更新，并迅速成为渗透测试人员库中的标准工具。SET由David Kennedy（ReL1K）编写，并在社区人员的大量帮助下，它包含了以前从未见过的攻击工具集。渗透测试期间，工具包中内置的攻击工具可以进行有针对性地集中攻击。  
**第1步：检查您的IP地址（Kali Linux）**

![](../Images/206f883e78ceaf7c0e71818f31cb4eb4.png)  
**步骤2：检查网络中的所有计算机**  
命令：Netdiscover -r 192.168.243.0/2  
![](../Images/9c18fef440a6f503021122c8649dd61f.png)  
我们得到了N / w ip  
默认网关  
广播ip  
Ping IP（未知）检查主机是否存在：

```
Ping 192.168.243.129
```

![](../Images/3c4a865cf1300d29dfb2a919c8d0f10c.png)  
现在Kali Linux中利用SET  
命令：**Setoolkit**

![](../Images/5a484ef70a27fa4b3547b07f4f89a7f3.png)

**利用第一个选项：**  
1.社会工程攻击  
现在，因为我们要执行网站克隆，所以我们必须选择该选项  
2.网站攻击向量  
5.Web Jacking攻击方法  
2.网站克隆  
在此之后，它将要求您提供一个IP地址(Kali Linux计算机的IP地址)

![](../Images/80128aed080d6d7c3de2e91437f7b336.png)  
在此之后，它将要求您输入您想要克隆的网站的URL。  
在这里，让我们克隆Facebook网站

![](../Images/e2a3acceda52913ea9f98f46c93d6d7a.png)  
将url粘贴到SET工具包终端中，开始克隆

![](../Images/c1124976044dd03bf4dd9120aec222e3.png)  
现在url已被克隆。您可以将克隆的网站发送给受害者，他单击链接，您就能在kali linux中获得他的凭证。

![](../Images/470baacd84b327360164e6a9dda88b2b.png)  
一旦受害者单击链接，受害者将被重定向到登录页面。

![](../Images/e871dd03855e6d599f422f974f12c99a.png)  
我在这里输入详细信息：

用户名：xxxxxxxxxx @ gmail.com

密码：123456

![](../Images/4cfd338446ae8c2b8f430a964325c863.png)  
现在转到您的Kali Linux并转到位置：

```
root/.set//reports/2018–12–27 08:03:52.640607.html
```

在此文件中，您将以明文形式获取所有凭据。  
![](../Images/a6ec15a532bbdf5a97f90fb04c56f8df.png)  
这样你就能拿到受害者的凭证了!
