## Reverie

今天给大家介绍的这款工具名叫reverie，它是一款专门针对Parrot Linux的自动化渗透测试工具。该工具可以帮助我们对目标进行类似信息收集、安全审计和安全报告生成等渗透测试工作，而且所有任务都是自动化完成的。

![](../Images/775a6094e7a20dcd672ece6602809940.png)

## 工具使用指南

使用下列命令将项目代码克隆至本地：

```
~
```

进入项目目录：

```
~
```

提供完整权限：

```
~
```

无需安装即可运行reverie：

```
~
```

如需安装，可直接运行install.sh文件：

```
~
```
