# ISeeYou：一款基于Bash和Javascript开发的社会工程学&网络钓鱼工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNjQ0MTEwMg==&mid=2247487918&idx=3&sn=c43b80986f35ccc2e13acbb9221d9073&chksm=978859cfa0ffd0d9ea00b1efc3e61007e96a436ab3d007de8e476f6c1d2a5fe51b126ced006e&scene=126&sessionid=1681667854#rd](http://mp.weixin.qq.com/s?__biz=MzIxNjQ0MTEwMg==&mid=2247487918&idx=3&sn=c43b80986f35ccc2e13acbb9221d9073&chksm=978859cfa0ffd0d9ea00b1efc3e61007e96a436ab3d007de8e476f6c1d2a5fe51b126ced006e&scene=126&sessionid=1681667854#rd)

今天给大家介绍的是一款名叫ISeeYou的强大社工工具，该工具基于Bash和JavaScript开发，可帮助研究人员在进行社工技术测试或网络钓鱼培训过程中快速定位目标用户的确切地理位置。在拿到目标用户的地理位置坐标之后，研究人员就可以对目标用户展开基础的网络侦察活动，并执行进一步的测试。

![](../Images/368e499d7ca2eca0f9223abe70656943.png)

### 注意

1、 在进行网络钓鱼测试时，该工具不需要任何其他的软件辅助。

2、 用户可以通过查看日志文件来解码地理位置坐标。

## 工具截图

运行ISeeYou.sh文件后，用户将看到如下图所示的界面：

![](../Images/74626b0e803fc71686b5f3bdb1b090a0.png)

输入图中框出来的URL地址之后，按下回车键：

![](../Images/396ae2afdee2715e35386affe821a5c0.png)

需要注意的是，这个URL地址是根据不同的用户随机生成的，所有生成的地址都为serveo.net域名下的子域名。我们可以在网络钓鱼活动中通过电子邮件或其他方式把这个URL地址发给你的目标用户，用户点击访问后将看到如下图所示的界面：

![](../Images/5c5bbb48649ec7e6b4c6bbdfd4b29b0c.png)

当然了，你也可以根据自己的需要来修改这个Web页面。

当目标用户允许页面拥有地理位置访问权限后（需要想办法隐藏请求），我们将会收到目标用户的实际地理位置信息，其中的数字即为目标用户的经纬度数据。

![](../Images/617d869a60cdaec02084f76364baa548.png)

大家可以访问https://maps.google.com或其他地图服务来将经纬度数据转码为地理位置。

![](../Images/8471d52d6273c88f15f6d72dc9aea268.png)

## Xterm使用方法

Xterm允许我们选择需要从剪贴板拷贝过来的数据数量：

1、 添加或创建~/.Xresources文件；

2、 设置如下参数：

```
XTerm*selectToClipboard:
```

3、 运行下列命令：

```
xrdb-
```

4、 重启xterm
