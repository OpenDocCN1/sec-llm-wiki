Mad-Metasploit是一款针对Metasploit的多功能框架，该框架提供了多种自定义模块、插件和资源脚本。

## 如何将Mad-Metasploit添加到Metasploit框架？

1\. 配置你的metasploit-framework目录：

```

$ vim config/config.rb
```

2-A、交互模式：  

```
$./mad-metasploit
```

2-B、命令行模式：

```
$.
```
