## 工具功能

1、 管理栈内存；

2、 轻量级模拟：枚举全部路径（寄存器、栈和某些指令）；

3、 完整模拟：仅跟踪代码路径（性能慢）；

4、 模拟TEB&PEB结构；

5、 显示引用内存地址的字符串；

6、 使用FLIRT风格签名；

7、 识别偏移量地址中的函数引用。

### rust安装-Windows

rust工具集下载地址：【https://www.rust-lang.org/en-US/other-installers.html#other-ways-to-install-rustup】

![](../Images/5bcfc615e84ace6c4d54b9ead1e8e397.png)

该工具将会安装rust的编译器-rustc，rust包管理器-cargo，以及其他用于rut环境下的实用工具。

### 安装rust依赖组件

如果大家遇到了下图所示的情况，是因为没有安装Build Tools for Visual Studio【解决方案 https://github.com/endgameinc/xori#install-rust-toolchain】：

![](../Images/4005a62880cd3771bde1b7081860a0f4.png)

1、 按照提示要求，点击上述链接，或直接点击【https://github.com/endgameinc/xori#install-rust-toolchain】；

2、 取消rustup-init.exe；

3、 回到浏览器，往下滑，点开“Tools forVisual Studio 2017”标签页，下载“Build Tools for Visual Studio2017”；

![](../Images/93fcc38088efd3c444b24fc56cd1b195.png)

4、 运行下载好的可执行文件；

选择“Visual C++ build tools”并点击安装，安装完成后关闭安装程序：

![](../Images/f0b8fb853a1b8e7019808dd2152dbcac.png)

### 安装rust工具链

运行rustup.exe，你将会看到如下所示的输出：

![](../Images/c817081e1efe3e7023e4df48aaa4750b.png)

成功安装后，你将会看到rust编译器-rustc、rust包管理器-cargo和其他实用工具已经全部安装完成了。路径分别为“C:\\Users\\%username%\\.cargo“和”C:\\Users\\%username%\\.rustu”。
