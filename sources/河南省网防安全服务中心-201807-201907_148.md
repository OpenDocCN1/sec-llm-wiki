# 2019净网行动都有哪些看点？

公安部7日在京召开新闻发布会，通报全国公安机关开展“净网2018”专项行动相关情况。公安部新闻发言人郭林主持发布会，公安部网络安全保卫局党委书记王瑛玮、副局长张宏业和山东济宁市公安局网安支队支队长刘建、四川达州市公安局网安支队副支队长沈黎明出席发布会，并回答了记者提问。

在通报“净网2019”专项行动重点举措时，王瑛玮介绍，在今年的中央政法工作会议上，习近平总书记强调，要加快推进社会治理现代化，努力建设更高水平的平安中国。声琨书记和克志部长就贯彻落实工作提出了明确要求，要求继续深化“净网”行动，着力营造清朗的网络空间。对此，公安部党委决定今年继续在全国范围内开展“净网2019”专项行动。各地公安机关要紧紧围绕新中国成立70周年大庆安保维稳工作这条主线，从严从实从细抓好打击整治各项措施，努力建设更高层次、更高水平的平安网络，以优异成绩迎接新中国成立70周年大庆。

一是进一步深化打击破案。坚持攻小案、破大案，抓住网上突出问题和群众反映热点，以打团伙、断链条为重点，快侦快破快诉涉网违法犯罪案件。要加强国际警务执法合作，特别是对藏匿在东南亚地区的黑客攻击、网络赌博等突出网络犯罪团伙、窝点开展集中打击。

二是进一步强化企业整治。健全完善“一案双查”制度，督促联网单位落实安全管理责任制度及应急响应措施，对拒不履行单位要依法从严查处。要以防范网络诈骗、侵犯公民信息等犯罪为重点，全面整治网络运营秩序，打击网络黑产黑市，净化网络环境。

三是进一步加强信息治理。坚持边清边打，将信息清理工作与打击同谋划、同推进、同落实，全力遏制“黄赌毒”、“枪爆盗”等违法信息滋生蔓延。

四是进一步深化体系建设。建立健全网络综合治理体系，以专项行动为抓手，坚持打击与整治相结合，坚持以打促管、以打促建，全面提升社会治理、网络治理能力，推动提升国家治理体系和治理能力的现代化水平。
