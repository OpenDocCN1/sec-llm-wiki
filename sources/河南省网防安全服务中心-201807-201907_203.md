# **总结**

在版本低于5.0.13的版本中，破坏性还是很强的，因为无需开启debug模式即可造成代码执行  
![](../Images/f9367b6b3d2fde696d70bb39fdf27d96.png)  
![](../Images/b09bee80ff156191e6eb4c9ad4d05bcf.png)  
在版本高于5.0.20的版本中，破坏性还是一般的，需开启debug模式才可造成代码执行  
![](../Images/d6c36988baffa2eead8c24cd88f7ea0e.png)  
![](../Images/09425dc77cb2a4582bcfd67d848f82e5.png)  
关于为什么5.0.7及以下版本不能执行，笔者对比了thinkphp\\library\\think\\Route.php，发现5.0.8相对于5.0.7在获取当前请求类型的路由规则处增加了一个三目运算符导致$rules数组被置空  
![](../Images/adde7663fdf64bc9abfc6eb7afce56fc.png)  
这也解释了为什么5.0.7执行时会爆出如下错误  
![](../Images/2e01bc03af52e78a71bc57e86b845db4.png)
