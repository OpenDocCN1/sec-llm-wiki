# 17 个用于攻击网闸的恶意框架

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247484493&idx=1&sn=bd0201baf50444d732b07d70b83e080e&chksm=ce4622baf931abac284bfb7a4895b434f3cf2031d9f04e082b45a81d1dfd39485e3afcafafd1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247484493&idx=1&sn=bd0201baf50444d732b07d70b83e080e&chksm=ce4622baf931abac284bfb7a4895b434f3cf2031d9f04e082b45a81d1dfd39485e3afcafafd1&scene=27#wechat_redirect)

![](../Images/0e9b506bd493001b65d4eee5d3dc8a11.png)

  

在 2020 年上半年检测到四种不同的旨在攻击隔离网络的恶意框架，使此类工具包的总数达到 17 个，并为攻击者提供了进行网络间谍活动和泄露机密信息的途径。ESET 研究人员 AlexisDorais-Joncas 和 Facundo Muñoz在对框架的全面研究中说：“所有框架都旨在执行某种形式的间谍活动，所有框架都使用 USB 驱动器作为物理传输介质，将数据传入和传出目标网闸网络。网闸是一种网络安全措施，旨在通过将系统与其他不安全网络（包括局域网和公共互联网）进行物理隔离来防止对系统的未授权访问。这也意味着传输数据的唯一方法是将物理设备连接到它，例如 USB 驱动器或外部硬盘。

 

*   所有框架都旨在执行某种形式的间谍活动。
*   所有框架都使用 USB 驱动器作为物理传输介质，将数据传入和传出目标网闸网络。
*   我们没有发现任何实际或怀疑使用隐蔽物理传输的案例。
*   超过 75% 的框架使用恶意 LNK 或 USB 驱动器上的自动运行文件来执行初始的网闸系统入侵或在网闸网络中横向移动。
*   在过去的 10 年中，在 Windows 中发现了 10 多个严重程度与 LNK 相关的远程代码执行漏洞，然后由 Microsoft 修补。
*   所有框架都是为了攻击 Windows 系统而构建的。我们没有发现任何针对其他操作系统构建的实际或可疑恶意软件组件的证据。

 

鉴于该机制是保护SCADA和工业控制系统 (ICS)的最常见方式之一，通常受赞助或参与民族国家努力的 APT 团体越来越多地将目光投向关键基础设施，希望通过恶意软件渗透带有网闸的网络，以监视感兴趣的目标。

![](../Images/93ab391ae48c6498668077853ba215b3.png)

一些被归因于知名威胁行为者的框架如下——

*   Retro （DarkHotel又名 APT-C-06 或 Dubnium）
    
*   Ramsay（黑暗旅馆）
    
*   USBStealer（APT28又名 Sednit、Sofacy 或 Fancy Bear）
    
*   USBFerry（Tropic Trooper aka APT23 或 Pirate Panda）
    
*   Fanny （方程组）
    
*   USBCulprit（Goblin Panda aka Hellsing 或 Cycldek）
    
*   PlugX（野马熊猫）
    
*   Agent.BTZ（图拉集团）
    

所有框架都设计了自己的方法，它们都有一个共同点：无一例外，都使用武器化的 USB 驱动器。连接和离线框架之间的主要区别在于驱动器首先是如何武器化的。连接框架的工作原理是在连接的系统上部署恶意组件，监控新 USB 驱动器的插入并自动放置破坏网闸系统所需的攻击代码，而像 Brutal Kangaroo、EZCheese 和 ProjectSauron 这样的离线框架则依赖于攻击者故意感染他们自己的 USB 驱动器以后门目标机器。

![](../Images/b9d86063c6f1d81cd1d1fd207a587fba.png)

作为预防措施，建议拥有关键信息系统和敏感信息的组织防止在连接的系统上直接访问电子邮件、禁用 USB 端口并清理 USB 驱动器、限制在可移动驱动器上执行文件，并对网闸系统进行定期分析以找出任何迹象的可疑活动。维护一个完全网闸的系统会带来额外保护的好处，但就像所有其他安全机制一样，网闸绝不是灵丹妙药，不能阻止恶意行为者利用过时的系统或不良的员工习惯。网络安全没有绝对，因为他是一种非常复杂的系统性工作，所以很容易出现挂一漏万的现象，但在攻击与防护之间都有个攻击成本问题，在非国家支持的黑客最愿意攻击性价比高的网络，但是对于有国家支持的黑客，他们的目标和任务则不然。所以在判定自己系统在维护国家安全、公共利益、社会秩序中的作用，以及其价值。只有充分进行评估后，或者能够对攻击可能性有个合理判断，而不是盲目乐观。**参考：https://www.welivesecurity.com/**[开启等级保护之路：GB 17859网络安全等级保护上位标准](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247484486&idx=1&sn=63d2db24b93b9373f5d27e94470cd114&chksm=ce4622b1f931aba76058d181a609315e348fcf0db30c0bdf18ca5b39e318a9bb115771d8330c&scene=21#wechat_redirect)
