为 IT 管理员提供有关 Web 浏览器安全设置管理的建议

近年来，浏览器的安全性稳步提高。今天，它们在默认状态下通常是安全的。因此，NCSC不再为每个主要浏览器提供详细的配置指南。相反，此高级指南将帮助您开发一种适用于您的组织的安全 Web 浏览方法。

为什么要管理 Web 浏览器安全性？

Web 浏览器在组织内广泛用于访问各种在线内容，包括企业 Web 服务和 Intranet 站点中保存的公司数据。这种对敏感数据的广泛访问和另一方面对公共互联网站点的公开，使浏览器成为攻击者的一个有吸引力的目标。此外，浏览器具有高度的可配置性和可扩展性，因此确保它们使用的配置能够最大限度地减少您的组织面临的风险，这一点很重要。

好消息是最流行的浏览器在默认情况下基本上是安全的。因此，您作为企业管理员的工作是防止他们变得不安全。这需要将它们保持最新和管理少量设置的组合。如果使用插件或扩展，您还需要管理它们的配置。

浏览器管理准备

在许多方面，浏览器的管理方式应与任何其他第三方应用程序大致相同。这包括使用您的审批流程来选择 Web 浏览器，确保通过安全的应用程序分发安装合法版本的浏览器，并确保及时安装更新。

但是，还有一些额外的因素：

选择网络浏览器

首先，您需要决定要使用的网络浏览器。

在决定时，您应该考虑：

  • 兼容性：虽然不像以前那么受关注，但您的一些公司工具可能只支持一部分浏览器。但是，如果您的一个 Web 应用程序需要一个旧的、不受支持的浏览器，并且您无法从该应用程序迁移，那么您应该研究使用单独的浏览器访问该 Web 应用程序并使用现代、安全的 Web 浏览器访问所有内容的方法别的。

  • 性能，包括对移动设备电池寿命的影响。

  • 安全功能：大多数流行的 Web 浏览器都具有类似的安全功能，但您可能需要专门寻找：

    • 与安全浏览列表服务集成，阻止已知恶意或欺诈站点（包括已知钓鱼站点）

    • 沙盒，包括基于虚拟化的安全性（例如 Windows Defender Application Guard）

  • 您使用的设备和操作系统的平台支持。如果您在组织中使用多个操作系统，您可能希望使用跨平台浏览器来简化管理。同样，如果您使用过时的平台，您可能需要使用支持该平台的更新的第三方浏览器。

  • 企业管理功能，包括集成到您使用的移动设备管理服务中。

  • 支持日期：一些浏览器开发人员支持他们的产品的时间更长，或者有扩展的支持版本。如果您打算在一段时间内使用相同的浏览器，请确保您选择在整个期间都受支持的浏览器。

管理网络浏览器

我们建议您调查您在设备上使用的浏览器的安全性并配置设置以降低以下方面的风险：

  • 企业管理具有以下特点：

    • 与任何第三方软件一样，您应该考虑应用程序恶意或易受攻击的可能性和影响。这是考虑在您的设备上允许哪些第三方应用程序的类似方法。

    • 扩展程序通常有权读取或更改用户访问的任何网站上的数据。这可能包括敏感或个人数据。

    • 扩展程序会增加您的网络浏览器的潜在攻击面，因为该软件也可能包含安全漏洞。您应该考虑如何使用户的扩展程序保持最新。

    • 更新：用户可能没有最新版本的浏览器。如果您的浏览器未更新，则它可能存在可被攻击者利用的已知漏洞，从而导致设备受到威胁。您可能希望考虑一种方法来监控您的用户在其设备上使用的浏览器版本。

    • 恶意软件保护：浏览器是抵御恶意软件的第一道防线。根据您的平台配置，用户可能能够下载和运行恶意可执行文件。您应该考虑如何通过使用配置为扫描下载的防病毒软件或通过实施应用程序允许列表策略来缓解这种情况。

    • 关键安全功能：例如防止用户绕过证书警告。

    • 登录云同步账号：与设备内置云账号一样，第三方浏览器往往也有用户可以登录的云账号。如果您担心将工作数据同步到个人帐户会带来风险，您可能希望限制从设备浏览器登录这些帐户的能力。

    • 浏览器插件，例如 Java、Flash 和 Silverlight，是用户设备受到威胁的主要方式之一。在现代网络上也很少需要它们，因此您应该考虑它们对您的组织的必要性。

    • 第三方扩展：浏览器有很多第三方插件/扩展可用，但你应该允许它们使用吗？一个常见的例子是广告拦截器扩展。虽然此类软件可能有用，但您应该考虑以下安全风险：

  • 许多用户希望使用浏览器的内置密码管理器来保存密码和凭据，从而轻松使用强身份验证策略。有关更多信息，请参阅有关使用密码管理器的更广泛指南。

  • 配置与隐私相关的设置（包括 cookie、不跟踪和弹出窗口阻止）可能对您的组织有用，但从安全角度来看不是必需的。

  • JavaScript 控制台等开发人员功能可能对某些用户有用，但可用于促进社会工程攻击。您可能希望为不需要它们的用户禁用它们。

  • 某些组织可能有法律或政策需要配置用户的浏览器以启用流量检查。如果这适用于您，您可能还需要为浏览器配置受信任的证书和/或代理设置。

如何管理浏览器

在选择和使用网络浏览器时，基于上述考虑，我们建议执行以下步骤：

  • 使用上述注意事项选择满足您组织需求的浏览器。这可能是内置于您的操作系统（例如 Edge 或 Safari）中的，也可能是单独安装的第三方产品。

  • 查看第三方应用程序指南，并将有关查看和分发第三方软件的建议应用于您的浏览器部署

  • 查看开发人员针对您选择使用的浏览器提供的任何企业管理指南。

  • 制定您认为足够重要以在用户设备上强制执行的设置和策略。具体来说，围绕在浏览器上安装第三方扩展制定政策。

  • 在可能的情况下，使用移动设备管理 (MDM)来实施这些策略。

  • 确保为浏览器及其扩展程序打开自动更新。

  • 您可能希望在用户指南中包含一些安全浏览网页的安全提示。这些应包括“以管理员身份登录时不要浏览网页”和“出现提示时安装更新”。

我们建议不要禁用关键的可用性功能，如 JavaScript 和密码自动填充。虽然过去这些功能存在安全漏洞，但如果不启用这些功能，可靠且安全地使用网络可能会非常困难。
