# 设备安全指南-过期的产品

降低使用过时智能手机、平板电脑、笔记本电脑、台式电脑、电器或软件应用程序的风险

所有软件，包括设备操作系统，最终都会过时。理想情况下，一旦过时，不应使用技术。

本指南为无法在支持日期结束前完全从过时产品迁移的组织提供建议。

### 笔记

本指南 *并未* 提供继续使用过时产品的无风险方式，但将有助于降低这样做的风险。

降低这种风险的唯一完全有效的方法是停止使用过时的产品。

* * *

## 为什么要管理过时产品的风险？

使用过时的产品会导致两个相关的问题：

1.  1
    
    #### 该产品将不再接收安全更新
    
    如果开发人员不再提供安全更新，这会增加攻击者发现可利用漏洞的可能性。
    
      
    
      
    
2.  2
    
    #### 不存在最新的安全缓解措施
    
    较旧的产品可能缺乏最新的安全措施，这会增加漏洞的影响，使漏洞利用更有可能成功，并且更难检测任何漏洞利用。
    
      
    
      
    

综合起来，这些问题使高影响安全事件更有可能发生。这将包括利用远程访问漏洞的恶意软件，这可能会对整个组织产生灾难性的影响。

当开发人员不再支持产品时，有效防止新威胁的措施就会受到限制。随着时间的推移，将会发现新的漏洞，这些漏洞可以被相对低技能的攻击者利用。

## 准备保护过期产品  

当产品过时时，您需要权衡继续使用它们的风险与更换或升级它们的成本。

建议升级而不是继续冒风险，但应认识到这并不总是可行的。如果您决定在短期内继续面临风险，您应该定期重新审视此决定，考虑可能出现的新威胁和漏洞，并重新评估您的风险偏好。

如果您决定是时候升级您的应用程序，请在可能的情况下考虑转向软件即服务产品。利用云产品意味着您可以管理过时软件的大部分安全风险。如果您决定接受使用过时系统和软件的风险，以下建议将帮助您将风险降至最低。

### 产品支持

在 选择新硬件或许可新软件时，请始终考虑产品的支持寿命。这将帮助您确保您的系统尽可能长时间地得到支持。

* * *

## 如何管理过时产品的风险

  

以下步骤适用于支持期即将结束的任何软件。

应用短期缓解措施

在不受支持的产品中发现的弱点将保持未修补状态，并且会被技能相对较低的攻击者利用。

有两种方法可以降低风险：

*   通过防止过时的设备访问不受信任的内容来降低被入侵的*可能性*（有效地使恶意内容难以到达设备并加以利用）
    
*   通过阻止从易受攻击的设备访问敏感数据或服务来减少危害的*影响*（因此即使设备受到危害，损害也会最小化）
    

您应该实现这两种方法的组合。从长远来看，远离过时的系统应该是目标。

* * *

## 降低妥协的可能性

只有当攻击者能够接触到易受攻击的产品时，漏洞利用才能成功。如果不受信任的数据无法到达设备，则不可能通过此路线进行利用。要实现这一点，您可以采取几个步骤。

限制攻击者对过时产品的访问

恶意数据可能到达过时产品的途径包括电子邮件、网页浏览、文件共享、网络端口和可移动媒体。我们建议尽可能禁用这些路由。如果可以，请使用网络气隙来实现此目的。应仔细考虑并减少流向过时服务器的数据流，尽可能使用离散网络防火墙。

来自 Internet 的数据和文件应被视为不受信任，即使来自已知的第三方也是如此。如果从企业存储服务中检索的数据来源最初是外部的，则也应视为不受信任。

#### 防止从过时的设备访问不受信任的服务

使用技术控制来防止从过时的设备访问外部、不受信任的服务。这应该包括阻止访问外部电子邮件和通过本地网络浏览器浏览互联网（间接访问，例如通过瘦客户端是可能的）。如果没有在技术上强制执行，这些控制将不会有效。

如果您无法完全阻止对不受信任的服务的访问，您可以通过确保禁用对外部内容的访问或需要手动确认来稍微降低受损风险。对于活动内容或媒体尤其如此，例如宏和浏览器插件。这可以降低“偷渡式下载”攻击的风险。

除了完全阻止对 Internet 的访问之外，没有任何方法可以完全减轻未打补丁的 Web 浏览器暴露于恶意 Web 内容的风险。但是，可以通过阻止访问丰富的 Web 内容和运行脚本来降低风险。扫描所有传入数据以查找恶意内容的网关是另一种明智的预防措施。

#### 防止访问可移动媒体

应防止访问可移动媒体，因为它可用于传输不受信任的内容。同样重要的是要注意，智能手机和平板电脑等设备可用于将媒体传输到过时的设备，如果受到威胁，可能会对它们所连接的设备发起攻击。

可以通过众多第三方产品和一些固件配置选项来控制对可移动媒体和任何连接设备的访问。

#### 将过时的客户端设备转换为瘦客户端

如果您的智能手机、平板电脑、笔记本电脑或台式 PC 无法升级到最新软件，您可能希望将它们转换为“瘦客户端”设备，并仅将它们用作对可信内部服务（例如远程桌面环境）的访问机制。通过将过时的系统用作瘦客户端，可以避免设备直接处理不受信任的内容的需要。

例如，Web 浏览可以通过远程桌面环境执行，运行打补丁的现代浏览器。可以以类似的方式访问业务生产力应用程序。这允许远程会话运行支持的、打过补丁的软件，即使用于访问服务的客户端设备不能。远程系统应配置为防止通过剪贴板共享和文件传输等功能将数据传输回客户端设备。

通过确保过时的 Windows 客户端设备位于与远程桌面服务和其他企业服务不同的 Active Directory 林中，可以加强这种缓解措施。

#### 从过时的服务器中删除不需要的服务

应检查过时的服务器以确保它们提供的服务最小化。不重要的服务应该被禁用。

在可能的情况下，将所需的服务从过时的服务器转移到现代的、受支持的服务器或云服务。过时的服务器不应用于提供远程应用程序服务或其他远程桌面设施。也不应依赖于在网络内用户之间有任何分离预期或远程桌面解决方案提供安全分离的地方。

## 应用缓解措施以减少妥协的影响

直接暴露于恶意内容的未打补丁的最终用户设备最终可能会受到损害。通过控制对托管敏感数据的企业服务的访问并提高检测攻击的能力，可以减少入侵的影响。

#### 定期重新映像/擦除设备以尝试删除任何常驻恶意软件

过时的平台更有可能包含来自先前入侵的恶意软件，因此应定期擦除它们并重新映像，以删除可能存在的任何恶意软件。但是，请务必记住，这只会暂时消毒设备。恶意软件用于在平台上出现的漏洞将在设备重新映像后继续提供攻击途径。换句话说，设备仍然容易受到攻击。

#### 将过时的系统视为不受管理或不受信任

如果组织内继续使用过时的设备，我们建议将它们视为不受信任的设备并给予限制访问。更广泛的企业应将过时的服务器视为不受信任，并应相应地处理它们提供的数据和服务。这可能类似于采用自带设备 (BYOD) 方法。

#### 网络分区

通过对网络进行分区，可以降低恶意软件在企业中横向传播的能力。应明确定义区域之间的流量，提供阻止和防止未经授权的通信的能力，例如恶意软件试图访问其命令和控制系统的通信。您不能假设受感染设备上的软件防火墙会继续有效工作。

#### 改进对过时组件的保护性监控、日志记录和审计

当使用过时的产品时，确保有效和主动的保护监控能力到位尤为重要。许多组织通常能够记录安全事件，但不会根据这些事件主动发出警报或采取行动。

#### 反恶意软件和入侵检测产品

可以使用防病毒、基于主机和基于网络的入侵检测系统等产品，并将继续在检测恶意代码方面提供一些好处。它们的有效性可能会降低，因为产品在不受支持的操作系统上运行时可能不会更新，并且签名可能不会被调整以检测针对过时系统的攻击。

#### 事件响应

如果企业环境中存在过时和易受攻击的软件，则对安全关键事件的及时响应变得越来越重要。应迅速采取行动遏制和消除妥协，以尝试减少任何妥协的蔓延。

## 了解第三方连接

如果第三方组织在您的环境中使用他们自己的设备或连接到它，您应该知道他们是否运行过时和易受攻击的软件 - 并采取措施解决相关风险。例如，您的企业环境中有供应商管理服务的情况可能是这种情况。

### Microsoft 产品的特定缓解措施

Microsoft 发布了 Windows 和 Office 等产品的“支持终止”日期。您应该使用这些日期来制定有效的计划以迁移到替代的受支持产品。

#### 办公文件类型

如果您需要在少量设备上保留安装过时版本的 Office，请考虑应用控制以防止 Office 可以打开的文件类型通过网关传输。或者，在浏览器中使用 Office 365 等在线生产力套件，并将电子邮件附件配置为自动在线打开，可以降低被利用的风险。

#### 部署 EMET

一些较旧的 Microsoft 平台仍有可用的增强型缓解体验工具包 (EMET)版本。EMET 使平台中的某些漏洞更难被利用，但不会完全阻止攻击。

#### 考虑自定义支持协议 (CSA)

CSA 是一项付费服务，可供拥有 Microsoft 首要支持协议的客户使用。根据此类协议，Microsoft 将提供*关键*和*重要的*安全更新（重要更新需额外付费）。

通过 CSA 提供的更新类型将类似于“扩展支持”中的产品可用的更新类型，但需要手动安装，因为它们不会通过 Windows 更新提供。

一旦产品获得扩展支持，就不能保证所有未来的安全漏洞都会得到解决，因此不应将其视为完全迁移到现代支持的操作系统的长期替代方案。
