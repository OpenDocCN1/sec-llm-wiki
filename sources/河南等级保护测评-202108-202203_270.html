Chrome操作系统在日常工作中见到的不是太多，本人也只是在上海工作中见到过一些安装Chrome的设备，但基本上没有通过它做过任何工作相关事情，本篇大家了解有Chrome操作系统这么回事即可，不必苛责理解或深入了解。

Chrome 操作系统

Chrome OS 是 Chrome 设备上的默认操作系统。

虽然本指南不适用于任何特定版本的 Chrome OS，以最后一次在运行 Chrome OS 80 的设备上进行了测试，该设备于 2020 年 4 月使用 Google 管理控制台进行管理。

一般建议

对于 Chrome 操作系统设备的企业部署，应该：

  • 决定组织将使用哪些 Chrome 操作系统设备。一旦设备达到其自动更新到期 (AUE)日期，它将不再接收更新，策略可能无法按预期工作，并且技术支持将停止。到达 AUE 日期后，应购买新设备。不同供应商和型号的 Chrome 操作系统设备的 AUE 的确切日期已在线发布。

  • 确保设备更新到最新的稳定渠道 Chrome 操作系统版本并应用任何 TPM 更新。应在设备配置阶段安装任何可用的 TPM 固件更新。在预配设备后安装未来的 TPM 更新时，请确保正确备份用户数据。

  • 使用推荐的一种网络架构来实现对企业服务的远程访问。

  • 使用移动设备管理 (MDM)服务确保设备由组织管理。这将确保可以最大程度地控制在设备上执行哪些策略。

  • 根据组织情况，配置MDM的日志记录和监控功能。

  • 如果需要虚拟专用网络 (VPN)，请考虑使用第三方应用程序来保护通信，因为 Chrome OS 80 仅支持推荐的VPN 配置文件的子集。使用第三方 Android VPN 解决方案时，应该测试 Chrome 操作系统和 Android 流量是否都受 VPN 保护，并且 VPN 已自动启动。

  • 将用于工作的第三方应用程序（托管应用程序）集中批准到企业应用程序目录中。要么在安装过程中自动安装它们，要么在Managed Google Play Store 中提供它们。

  • 请勿部署防病毒软件和其他安全软件，因为 Chrome 操作系统不建议这样做。

工作申请

  • 大多数组织都希望为其用户提供一系列生产力和业务应用程序，以便他们可以远程工作和协作。建议尽可能使用内置应用程序或云基础架构提供的功能，因为它们可提供更高的可信度和安全性。这可能有助于通过MDM管理帐户，最大限度地减少管理开销。

  • 小心使用高权限应用程序，例如第三方键盘应用程序和网络扩展。这些类型的应用程序可能能够访问大量工作数据，因此会给组织带来更高的风险。

  • 渐进式 Web 应用程序(PWA) 由内置的Chrome 网络浏览器支持，并具有浏览器的许多保护。安装恶意PWA可能对用户数据和设备完整性的影响有限。但是，管理员目前无法通过MDM服务以与 Chrome和Android应用程序相同的方式控制用户安装哪些PWA。

设备配置

一旦选择了 MDM 服务、架构和应用程序方法，应该开发一个设备配置，可以应用该配置来实施技术控制。

特别是，应该包括管理以下各项的策略：

  • 外部接口，包括有线和无线外围设备 （例如，在设备锁定时禁用 USB 附件）

  • 使用 生物识别技术 （如果可用），以及配置 密码和身份验证策略

  • 要允许的 Google Cloud 服务 

  • 设备操作系统和应用程序更新，包括自动更新

  • 应禁用开发人员和测试版功能，例如 Linux 子系统和 Google 助理，以防止通过 MDM 绕过强制技术控制。
