微软云Azure AD 新的漏洞让黑客可以暴力破解密码

MicrosoftAzure 是其中发展最快的云之一。Azure 是在 AWS 和谷歌云发布多年后推出的，但仍在敲开成为顶级云服务提供商的大门。
Secureworks 网络安全研究人员在 Microsoft Azure Active Directory 使用的协议中披露了一个未修补的安全漏洞，潜在的攻击者可以利用该漏洞进行不被发现的暴力攻击。
Secureworks Counter Threat Unit (CTU) 的研究人员在星期三发布的一份报告中说： “这个缺陷允许威胁行为者对 Azure Active Directory ( Azure AD )执行单因素暴力攻击，而不会在目标组织的租户中生成登录事件。”
Azure Active Directory 是 Microsoft 的基于企业云的身份和访问管理 (IAM) 解决方案，专为单点登录 (SSO) 和多重身份验证而设计。它也是 Microsoft 365（以前称为 Office 365）的核心组件，具有通过 OAuth 向其他应用程序提供身份验证的功能。
弱点在于无缝单点登录功能，该功能允许员工在使用连接到企业网络的公司设备时自动签名，而无需输入任何密码。无缝 SSO 也是一种“机会主义功能，如果该过程失败，登录会退回到默认行为，即用户需要在登录页面输入密码。
该机制依赖Kerberos协议在 Azure AD 中查找相应的用户对象并发出票证授予票证 (TGT)，允许用户访问相关资源。但对于Office 客户端早于 Office 2013 更新的 Exchange Online 用户，身份验证通过名为“UserNameMixed”的基于密码的终结点进行，终结点根据凭据是否有效生成访问令牌或错误代码。
正是这些错误代码导致了缺陷。虽然成功的身份验证事件会在发送访问令牌时创建登录日志，但不会记录Auto logon对 Azure AD 的身份验证，从而允许通过 UserNameMixed 端点利用遗漏进行未检测到的暴力攻击。Secureworks 表示于 6 月 29 日将问题通知微软。
微软公司是一家美国跨国技术公司，生产计算机软件、消费电子产品、个人计算机和相关服务。最著名的软件产品是Microsoft Windows系列操作系统、Microsoft Office套件以及Internet Explorer和Edge Web浏览器。是美国信息技术行业的五大公司之一。
Microsoft Azure在AWS之后位居第二，提供广泛的以企业为中心的服务，是按需即时配置计算资源混合云产品服务的佼佼者。在IaaS云提供商中的市场份额为20%。Microsoft Azure拥有600多项服务，提供VM作为其IaaS产品的一部分，Active Directory用于同步本地目录，并支持单点登录。该公司还提供具有实时分析和跟踪用户行为和存储服务的移动参与，以及数据管理工具，如Azure数据资源管理器、AzureSQL数据库、无服务器、CDN、Azure AI、Azure Blocka hung Work bench、Azure IoT和其他服务。Azure有54个区域，每个Azure区域至少有三个可用区。
