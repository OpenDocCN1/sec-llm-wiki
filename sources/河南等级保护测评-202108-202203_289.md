# 密码管理器：如何保护密码

需要帮助记住所有在线密码？密码管理器。

**什么是密码管理器？**

密码管理器是手机、平板电脑或计算机上的一个应用程序，可以安全地 存储用户密码，因此用户无需记住所有密码。一些密码管理器可以在用户不同设备上同步密码，让用户无论身在何处都可以更轻松地登录。当用户需要创建新密码（或更改现有密码）时，有些还可以为用户创建随机、唯一的密码。

**为什么需要密码管理器？**

跨不同账户重复使用相同的密码可能很危险。网络犯罪分子可能会窃取用户的一个密码，然后使用它来尝试访问其他账户。意味着即使他们只知道一个密码，也可以迅速闯入用户多个账户。

我们应该为所有的在线账户创建一个唯一的、难以猜测的密码，以防止同密码攻击这种情况发生。当然，仅凭我们大脑记忆，几乎不可能完成。密码管理器提供了这种帮助。旨在使使用和生成密码更容易、更安全。许多还可以代表用户自动在网站和应用程序中输入适当的密码，因此用户甚至不必在每次登录时都输入密码。

**哪些类型的密码管理器可用？**

我们可能在不知情的情况下已经使用密码管理器。许多内置于用户的互联网浏览器（例如 Google Chrome、Microsoft Edge 或 Firefox），或者是用户的智能手机或平板电脑上操作系统的一部分。此时，用户可能已经注意到，当用户登录账户时，会出现一个框，询问是否希望浏览器（或设备）记住密码。如果不与其他任何人共享设备，则勾选此框是安全的。

也可以下载独立的密码管理器应用程序，其中许多应用程序可以安装在不同类型的设备上，并具有额外的功能，例如能够为用户创建好的密码。在选择适合密码管理器之前，确定密码管理器能够满足所需功能。 

**如何保护密码管理器？**

无论使用的是独立密码管理器还是内置密码管理器，确保密码管理器账户的安全非常重要，因为如果犯罪分子访问它， 他们可能会访问用户所有密码和关联账户。还需要采取措施确保用户始终可以自己进入，这样就不会失去对所有密码的访问权限。

**英国NCSC 的建议：**

 在密码管理器账户上设置双因素身份验证。如果选择请设置不止一种类型的第二个因素，以便有一个备份计划来进入密码管理器账户。 

系统提示更新时，请立即为密码管理器应用安装更新。如果使用的是浏览器，请始终确保使用的是最新版本并保持最新版本。

  

为密码管理器账户选择一个强密码（例如使用三个随机单词）。
