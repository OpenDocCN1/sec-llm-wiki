# 西门子的网络安全保护的三个阶段

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247483705&idx=1&sn=f18167e012aea3dce3c25ed049e53e7c&chksm=ce4627cef931aed8759d693cd33d50a87f5a17567cff372ebda327f31e963d8145eaa89f1ad4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247483705&idx=1&sn=f18167e012aea3dce3c25ed049e53e7c&chksm=ce4627cef931aed8759d693cd33d50a87f5a17567cff372ebda327f31e963d8145eaa89f1ad4&scene=27#wechat_redirect)

西门子于 2018 年与国际公司和研究合作伙伴共同推出的《信任宪章》也得出了这一结论。该倡议制定了一个分 三个阶段的措施目录。旨在准确解决这些领域。

### 第一阶段：建立网络安全文化  

网络安全涉及所有员工。首先是管理层，他们更愿意通过委派 IT 部门提出必要措施来解决问题。相反，管理人员应该宣布这个主题为重中之重并承担责任。第一项措施：风险评估。公司自己的员工构成的风险最高。据安全软件提供商卡巴斯基称，超过 80% 的安全事件是人为错误的结果。典型的例子是欺诈性电子邮件和弱口令。唯一的补救方法是定期培训课程。这些培训课程也很重要，因为它们让公司证明他们已经采取了《通用数据保护条例》中概述的所有必要措施。 

![](../Images/51ebdee1bcca5127b11dffcae7d21f8b.png)

  

### 第二阶段：实施和纳入措施

威胁是众所周知的，现在是具体的组织措施问题。中小企业应认真研究和优化数据保护、安全政策、物理安全和访问管理，并开始实施培训措施。西门子已将其添加到其供应商条款和条件中的《信任宪章》也推荐了这些措施。但这还不是全部：特别是提供数字和互联产品和服务的公司必须将网络安全作为这些产品的一部分。这就是关键概念发挥作用的地方：设计安全——从开发到产品操作再到服务。这与默认的安全性密切相关：所有保护措施都应在交付时生效，例如更强的密码，而不是仍然经常使用的“0000”。 

  

![](../Images/62fad1a96d5708399216c18a831edc26.png)

  

  

### 第三阶段：沟通措施并发挥榜样作用

做好工作并告诉人们。该建议也适用于旨在网络安全的措施。这不仅意味着“公共关系”，还意味着通过 IEC 62443 或 ISO 27001 等认证措施对安全状态的个人证明。树立良好榜样的公司鼓励其他公司采取相同的方法。这很重要，因为网络攻击不仅仅停留在公司或国家边界。这就是为什么必须始终在上下文中看待网络安全措施的原因，例如在整个供应链中或例如与稍后负责产品维护的服务提供商。

 

如果一家公司完成了这三个阶段，那么它就可以很好地免受黑客攻击，但不会永远如此，因为犯罪分子会不断开发新的恶意攻击方法。因此，网络保护不是您只需投资一次就可以忘记所有的产品。这是一个持续的过程，需要不断地关注，但这也正是为什么它是一种更可持续的保护形式。

 

但机会就在于此：良好的网络安全是变革和新数字商业模式的基础。这些在家具行业已经存在，其中一个例子就是定制家具的在线配置。然而，Homag 的 Ernst Esslinger 指出，许多其他行业仍处于起步阶段。他认为这种情况必须改变：我只建议做一件事，以确保您不会错过数字世界提供的众多机会——为网络安全做更多的事情。

![](../Images/46bb23aec27f8c6f7aa8a8f31004b9e4.png)

  

**网络保护不是一劳永逸一次性投资的产品，而是一个持续的过程。**
