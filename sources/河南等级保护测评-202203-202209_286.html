研究人员演示了针对 IT 和 OT 网络的物联网设备的勒索软件

随着勒索软件感染已经从纯粹的数据加密演变为双重和三重勒索等方案，新的攻击媒介可能会为未来的活动奠定基础。

Forescout 将其称为物联网勒索软件或R4IoT，它是一种“新颖的概念验证勒索软件，它利用物联网设备获取访问权限并在 IT [信息技术] 网络中横向移动并影响 OT [运营技术] 网络。”

这种潜在的支点基于物联网设备数量的快速增长以及组织中 IT 和 OT 网络的融合。R4IoT 的最终目标是利用暴露和易受攻击的物联网设备（例如 IP 摄像头）获得初步立足点，然后在 IT 网络中部署勒索软件，并利用糟糕的运营安全实践来控制关键任务流程。

研究人员说：“通过破坏物联网、IT 和 OT 资产，R4IoT 超越了通常的加密和数据泄露，导致业务运营的物理中断，”从而为传统的勒索软件攻击增加了额外的勒索层。

换句话说，R4IoT 是一种新型恶意软件，它在 IT 网络上将 IoT 入口点和与勒索软件相关的横向移动和加密结合在一起，从而对 IT 和 OT 网络造成广泛影响。

在假设的情况下，这可能需要破坏公司网络中的一台机器，不仅可以释放勒索软件，还可以从远程服务器检索额外的有效负载，以部署加密货币矿工并对 OT 资产发起拒绝服务 (DoS) 攻击。为了降低潜在 R4IoT 事件的可能性和影响，建议组织识别和修补易受攻击的设备，实施网络分段，实施强密码策略，并监控 HTTPS 连接、FTP 会话和网络流量。

研究人员总结说：“勒索软件一直是过去几年最普遍的威胁，到目前为止，它主要利用传统 IT 设备中的漏洞来削弱组织。但新的连接趋势增加了数量和多样性的 OT 和 IoT 设备，几乎增加了每项业务的风险。”
