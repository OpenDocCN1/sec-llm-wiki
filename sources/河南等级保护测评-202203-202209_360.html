五眼联盟发布2021年被利用最高的15个漏洞

美国、澳大利亚、加拿大、英国和新西兰的五眼联盟安全机构发布了一份 2021 年最常被利用的漏洞的最终清单，其中 Log4Shell 位居榜首。

除了臭名昭著的 Log4j 漏洞之外， 该列表还包括著名的ProxyLogon和ProxyShell漏洞以及其他 Microsoft 漏洞 ZeroLogon，以及另一个 Microsoft Exchange Server 漏洞 ( CVE-2020-0688 )。

前 15 名中的其他错误是 Atlassian ( CVE-2021-26084 )、VMware vSphere  CVE-2021-21972  Pulse Secure ( CVE-2019-11510 ) 和 Fortinet FortiOS ( CVE-2018-13379 ) 中的错误。

国家网络安全中心 (NCSC) 首席执行官 Lindy Cameron 说：“NCSC 和我们的盟友致力于提高对漏洞的认识，并提出可行的解决方案来缓解这些漏洞，该公告将权力交到网络防御者手中，以解决公共和私营部门生态系统中最常见的网络弱点。”


除了 前 15 名列表之外，五眼联盟构还提供了一个额外的漏洞列表来修补，包括值得注意的系统，例如 Accellion 文件传输设备 (FTA)，该系统被一个网络犯罪组织作为目标，并链接到 FIN11 和 Clop 勒索软件。

其他易受攻击的产品包括 Windows Print Spooler 和 VPN 产品 Pulse Connect Secure 和 SonicWall SSLVPN SMA100。

Dynatrace的应用程序安全首席产品工程师 Andreas Berger 认为，应用程序越来越多地充满了缺陷，因为它们建立在具有开源组件的云原生架构上，使得漏洞更难清除。

即使采用强大的分层网络安全方法，许多组织仍然缺乏能够看到容器化应用程序内部的解决方案，或者了解区分潜在漏洞和严重风险所需的上下文，安全团队很难有效地确定其工作负载的优先级，因此即使是记录最充分的漏洞，例如 Log4j 库漏洞，也可能几个月甚至几年都得不到检查。看到 Log4Shell 在 2021 年最常被利用的漏洞列表中名列前茅尤为相关，因为它是在今年最后一个月才被发现的——突显了它的严重性。

Berger 总结说，为了降低风险敞口，组织需要将全栈可观察性与人工智能和自动化相结合，以消除盲点，以揭示漏洞的确切原因、类型和严重性。
