# 安全通报-海康威视部分混合SAN/集群存储产品存在安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247489780&idx=2&sn=395af6490433221712cb427613376cc4&chksm=d2179599d7b257df2ffce1662605b57d0a89cc5c29560445639e1bd31541d187796d49f944dd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247489780&idx=2&sn=395af6490433221712cb427613376cc4&chksm=d2179599d7b257df2ffce1662605b57d0a89cc5c29560445639e1bd31541d187796d49f944dd&scene=27#wechat_redirect)

**SN号**HSRC-202304-01

**编辑：**海康威视安全响应中心（HSRC）

**首次发布日期：** 2023-04-10

 

**概括**

海康威视部分Hybrid SAN/Cluster Storage产品存在访问控制漏洞，可利用该漏洞获取管理员权限。攻击者可以通过向受影响的设备发送精心制作的消息来利用此漏洞。

海康威视已发布修复该漏洞的版本。

 

**漏洞编号**

CVE-2023-28808

 

**计分**

本次漏洞评分采用CVSS v3。 

( http://www.first.org/cvss/specification-document )

CVE-2023-28808

基本分数：9.1(AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N)

时间得分：8.2 (E:P/RL:O/RC:C)。

**前提**

攻击者可以访问设备的网络。

 

**攻击步骤**

发送特制的恶意消息。

 

**获取固定版本**

用户可以在海康威视官网下载补丁/更新。

 

**漏洞信息来源**

此漏洞由印度 Redinent 创新团队的 Souvik Kandar 和 Arko Dhar 报告给 HSRC，我们还要感谢印度国家计算机应急响应小组 (CERT-In) 与我们协调处理此漏洞的合作.
