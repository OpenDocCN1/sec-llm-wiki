# 微软2023年4月份于周二补丁日针对97个漏洞发布安全补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247489718&idx=3&sn=0788aff70b991546d73d1671f7240775&chksm=d21795dbd3b65f953fec538dfe15cb1aed5f77870222aa0198c423e34715254ee54d92a9bf3d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247489718&idx=3&sn=0788aff70b991546d73d1671f7240775&chksm=d21795dbd3b65f953fec538dfe15cb1aed5f77870222aa0198c423e34715254ee54d92a9bf3d&scene=27#wechat_redirect)

这是本月的第二个星期二， Adobe 和 Microsoft（以及其他公司）已经发布了最新的安全补丁。跟随祺印说信安一起了解 Microsoft 和 Adobe 最新产品的详细信息。

**2023 年 4 月的 Adobe 补丁**

4 月份，Adobe 发布了六个公告，解决了 Acrobat 和 Reader、Adobe Digital Editions、InCopy、Substance 3D Designer、Substance 3D Stager 和 Adobe Dimension 中的 56 个 CVE。Reader的更新可能是最重要的。纠正了 16 个不同的 CVE，如果威胁行为者可以让用户使用受影响的 Reader 版本打开特制的 PDF，其中 14 个可能会导致任意代码执行。此更新还包括来自 Haboob SA 的 Abdul-Aziz Hariri 的四个 CVE，这是他在最近的 Pwn2Own Vancouver 上成功演示的一部分。

Adobe Digital Edition的补丁纠正了一个严重级别的代码执行错误。InCopy的修复还解决了一个单独的关键级代码执行问题。其他更新明显更大。Substance 3D Designer的更新解决了九个错误，所有这些错误都被评为严重。Substance 3D Stager的修复修复了 14 个漏洞，其中 10 个被评为严重，可能导致任意代码执行。Adobe 的最终补丁涵盖了Adobe Dimension并纠正了 15 个独特的错误。这些错误中共有 14 个可能导致任意代码执行，另一个是内存泄漏。

Adobe 本月修复的错误在发布时均未被列为众所周知或受到积极攻击。Adobe 将这些更新归类为 3 级部署优先级。

**2023 年 4 月的 Apple 补丁**

Apple 上周和昨天修补了几个 CVE，涵盖了两个受到主动攻击的漏洞。CVE-2023-28205 是 WebKit 中的一个 UAF，可以在 Safari、macOS 和 iOS 中找到。它可以导致在登录用户级别执行代码。需要与特权升级相结合才能接管系统。Apple 修补的第二个漏洞就是这样做的。CVE-2023-28206 是 macOS 和 iOS 中 IOSurfaceAccelerator 组件中的权限升级。Apple 没有明确说明这些是结合使用的，但它们是由同一研究人员同时报告的，因此它们的结合使用是有道理的。

**微软 2023 年 4 月补丁**

本月，微软发布了 97 个新补丁，解决了 Microsoft Windows 和 Windows 组件中的 CVE；办公室和办公室组件；Windows Defender的; 共享服务器；Windows 超级 V；PostScript 打印机；和微软动态。这是对先前发布并在今天记录的三个 Edge（基于 Chromium）CVE 的补充。这使今天的 CVE 总数达到了 100 个。

在今天发布的补丁中，有 7 个被评为严重，90 个被评为重要。虽然这一卷似乎确实与过去几年持平，但远程代码执行 (RCE) 错误的数量几乎占了发行版的一半。在一个月内看到如此多的 RCE 修复是不寻常的。另外请注意，微软本月没有解决在 Pwn2Own Vancouver 期间通过 Teams 披露的任何错误。

其中一个新的 CVE 在发布时被列为受到主动攻击。让我们仔细看看本月的一些更有趣的更新，从受到主动攻击的漏洞开始：

 -        **CVE-2023-28252**** – Windows 通用日志文件系统驱动程序特权提升漏洞  
**这是本月受到积极攻击的一个错误，如果它看起来很眼熟，那是因为在同一组件中有一个类似的0-day 补丁，只有两个几个月前。对我来说，这意味着原始修复是不够的，攻击者已经找到了绕过该修复的方法。与 2 月份一样，没有关于这些攻击可能有多广泛的信息。这种类型的利用通常与代码执行错误配对以传播恶意软件或勒索软件。一定要快速测试和部署这个补丁。

\-        **CVE-2023-21554**** – Microsoft 消息队列远程代码执行漏洞  
**这是一个 CVSS 9.8 错误，获得了 Microsoft 最高的可利用性评级。它允许未经身份验证的远程攻击者在启用消息队列服务的受影响服务器上以提升的权限运行他们的代码。默认情况下禁用此服务，但许多联络中心应用程序通常使用此服务。它默认侦听 TCP 端口 1801，因此在外围阻止它可以防止外部攻击。但是，尚不清楚这可能会对运营产生什么影响。您最好的选择是测试和部署更新。

\-        **CVE-2023-23384**** – Microsoft SQL Server 远程代码执行漏洞  
**这是 Microsoft 在 2 月份发布的静默补丁，目前正在记录中。silent patching 的问题已经被详细记录，所以我不会在这里重复它。该补丁修复了 SQLcmd 工具中的 OOB Write 错误，该错误可能允许未经身份验证的远程攻击者以提升的权限利用代码。虽然未在 CVSS 中列出，但攻击的复杂性似乎很高，因为攻击者一次只能控制几个字节。服务器崩溃的可能性更大。如果您正在运行 SQL 服务器，请阅读累积更新表以确保您同时安装了二月和四月的更新。

\-        **CVE-2013-3900**** – WinVerifyTrust 签名验证漏洞  
**CVE 编号没有错误——这是一个 10 年前重新发布的补丁。如果这个 bug 听起来很熟悉，那是因为它在最近的 3CX 攻击中被威胁者使用过。这是过去的“选择加入”修复，这意味着管理员必须选择加入才能获得此修复。通过此修订，添加了针对其他平台的修复程序并添加了针对企业的进一步建议。一定要花时间查看所有建议，包括有关Microsoft Trusted Root Program 的信息，并采取必要的措施来保护环境。

查看剩余的 Critical-rated 补丁，在 Pragmatic General Multicast (PGM) 中还有另一个 CVSS 9.8 错误，类似于已经讨论过的 MSMQ 错误。但是，此错误被列为不可利用的消息队列漏洞。DHCP 服务器中存在错误，但可能没有最初看起来那么严重。它需要网络相邻攻击者向受影响的 DHCP 服务器发送特制的 RPC 调用。DHCP 不是可路由协议（或安全协议），因此外部威胁参与者无法利用此漏洞。第 2 层隧道协议和点对点隧道协议中存在几个严重级别的错误。在过去的几个月里，我们已经看到很多类似的错误得到了修复，但没有一个被报告为在野被利用。最后一个严重级别的错误会影响原始图像扩展。查看巧尽心思构建的文件可能会允许代码执行。

转到其他代码执行错误，首先跳出的是 PostScript 和 PCL6 类打印机驱动程序的 11 个不同补丁。在未来一段时间内，打印机似乎仍将是微软的安全问题。除了已经提到的补丁之外，还有八个 DNS 服务器补丁。这些不太严重，因为它们要求攻击者拥有更高的权限。有一个针对 RPC 运行时的修复程序，但描述令人困惑。虽然需要 CVSS 状态低权限，但描述指出未经身份验证的攻击者可以利用此错误。有一个针对 Internet 密钥交换 (IKE) 协议的补丁，但它需要运行 IKE 和 AuthIP IPsec 键控模块。请注意，禁用其中任何一个都会对 IPSec 功能产生不利影响，因此如果您正在运行这些，修补而不是禁用服务。Network Load Balancer 中存在一个 RCE 错误，使其对网络相邻的攻击者开放。在这种情况下，建议升级到较新的软件负载平衡服务，该服务被列为不受影响。蓝牙组件收到一个补丁，要求攻击者在物理上靠近目标。其余大部分补丁修复了 open-and-own 错误，包括罕见的 Windows 内核 RCE。大多数内核错误都是权限提升，因此在组件中看到 RCE 错误很有趣。蓝牙组件收到一个补丁，要求攻击者在物理上靠近目标。其余大部分补丁修复了 open-and-own 错误，包括罕见的 Windows 内核 RCE。大多数内核错误都是权限提升，因此在组件中看到 RCE 错误很有趣。蓝牙组件收到一个补丁，要求攻击者在物理上靠近目标。其余大部分补丁修复了 open-and-own 错误，包括罕见的 Windows 内核 RCE。大多数内核错误都是权限提升，因此在组件中看到 RCE 错误很有趣。

特权提升 (EoP) 补丁的数量大约是 RCE 补丁的一半，其中绝大多数需要经过身份验证的用户运行特制代码才能提升到 SYSTEM。有几个例外值得注意。Kerberos 和 Netlogon RPC 错误都需要中间人 (MiTM) 攻击者。Kerberos 错误可能导致客户端加密降级为 RC4-md4 密码。攻击者可以使用它来破坏用户的 Kerberos 会话密钥以提升权限。同样，MiTM 攻击者可以拦截 Netlogon RPC 消息来修改 Netlogon 协议流量以提升他们的特权。  

七种不同的安全功能绕过 (SFB) 错误在本月收到补丁，这延续了每个版本中 SFB 错误增加的趋势。Azure 服务连接器中的第一个可能允许攻击者绕过内部防火墙限制。锁定屏幕中有两个不同的错误可以允许它被绕过，但这两个都需要物理访问。Windows 启动管理器中的两个错误也是如此。组策略中的错误很有趣，因为它会阻止管理员在某些情况下更新组策略。Windows 注册引擎的补丁修复了一个错误，该错误可能会在帐户注册过程中绕过证书验证。最后一个 SFB 错误在驱动程序吊销列表中。
