# 红帽宣布全面推出恶意软件检测服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247489060&idx=3&sn=990e16836d2dcd6cd3cb09d817500cf4&chksm=ce4630d3f931b9c5a2efa09b97984e0399459477b73be06f2ded66658e2a54ee08a42728cee6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247489060&idx=3&sn=990e16836d2dcd6cd3cb09d817500cf4&chksm=ce4630d3f931b9c5a2efa09b97984e0399459477b73be06f2ded66658e2a54ee08a42728cee6&scene=27#wechat_redirect)

**Red Hat 周二宣布全面推出针对 Red Hat Enterprise Linux (RHEL) 系统的恶意软件检测服务。**

Insights 服务是与 IBM X-Force 合作创建的，它使用包含 180 多个与已知 Linux 恶意软件相关联的签名的数据库来扫描 RHEL 系统中的恶意软件。用户可以获得所有系统的汇总结果或单个系统扫描的结果。

支持 RHEL 8 和 9 主机。扫描可以手动运行，但也可以安排或自动运行。

Red Hat 告诉客户，在大多数情况下，扫描很可能无法检测到。当在系统上检测到恶意软件时，会向用户提供有关威胁类型的信息以及指向 IBM X-Force 分析报告的链接以获取更多详细信息。

Red Hat Insights恶意软件检测服务的测试版现已推出。恶意软件检测服务是一种监控和评估工具，可扫描Red Hat Enterprise Linux (RHEL) 系统是否存在恶意软件，利用与 IBM X-Force 威胁情报团队合作提供的超过 175 个已知 Linux 恶意软件签名。Red Hat Insights 分析提供：

*   针对 RHEL 系统扫描的签名列表，以及指向参考信息和分析报告的链接
    
*   单个系统扫描的结果和所有 RHEL 系统的汇总结果
    

要扫描您的 Red Hat Insights 系统以查找潜在的恶意软件，请按照我们的入门指南进行操作。第一次全面扫描后，您可以在Insights malware detection 测试版中查看结果。 

请注意：由于此信息具有潜在的敏感性，因此只有组织管理员才能默认访问结果。如第 2.2 节所述，必须首先授予所有其他用户访问该服务的权限Insights 恶意软件检测指南。

我们希望您不会看到如下所示的屏幕，但是如果在您的系统上找到了签名匹配项，您将看到有关签名的详细信息、匹配的系统数量以及在系统中找到匹配项的详细信息。

![](../Images/b80c4ffa7cb4d579127d7df56825770f.png)

与其他 Insights 服务一样，恶意软件检测包含在您的 RHEL 订阅中。恶意软件检测支持 RHEL 7 服务器/工作站以及 RHEL 8 和 9 主机。

有关新恶意软件检测服务的任何反馈都可以使用 Insights 中的“反馈”按钮发送给我们——可以在页面右下角的上面的屏幕截图中看到它。请尽快试用 Insights 恶意软件检测服务！
