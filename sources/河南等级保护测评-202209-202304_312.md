# 黑客工具Kali Linux发布新版本2022.4

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247488664&idx=3&sn=604d081f30605a4aa666f831cf6d71e0&chksm=ce46326ff931bb79582c867bcd87d1c258e0691555d8c93802ccd4eac314d292cf6a1c9bbdcd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247488664&idx=3&sn=604d081f30605a4aa666f831cf6d71e0&chksm=ce46326ff931bb79582c867bcd87d1c258e0691555d8c93802ccd4eac314d292cf6a1c9bbdcd&scene=27#wechat_redirect)

Offensive Security 发布了Kali Linux 2022.4，这是其流行的渗透测试和数字取证平台的最新版本。

![](../Images/2037e400da90d92ea045ced3cf09d633.png)

Kali Linux 2022.4 中的新工具

除了对现有工具的更新之外，新的 Kali 版本始终会提供新工具。这次是：

*   bloodhound.py – 用于BloodHound的基于 Python 的摄取器
*   certipy – 用于 Active Directory 证书服务枚举和滥用的工具
*   hak5-wifi-coconut – USB Wi-Fi NIC 和 Hak5 Wi-Fi Coconut 嗅探器的用户空间驱动程序
*   ldapdomaindump – 通过 LDAP 的 Active Directory 信息转储器
*   peass-ng – 适用于 Windows 和 Linux/Unix\* 和 MacOS 的权限升级工具
*   rizin-cutter – 一个由rizin框架驱动的逆向工程平台

Kali NetHunter 新闻

  

该发行版的移动 (Android) 渗透测试平台 Kali NetHunter 现在具有内部蓝牙支持并增加了对某些设备的支持，以及其他改进。

还有新的Kali NetHunter Pro——“手机上‘真正的’Kali Linux”——支持 Pine64 PinePhone 和 PinePhone Pro 开源智能手机，允许用户完全控制设备。

开发人员分享说：“首先，我们为PinePhonePinePhonePro提供了可用的SD卡映像，以便与主操作系统一起双启动。很快我们将发布带有PlasmaMobile的替代版本以及安装程序，这样您就可以将KaliNetHunterPro安装到内部闪存上。”**其他变化**Kali Linux 2022.4 附带了新版本的 GNOME 桌面环境（带有 shell 更新、新文本编辑器和新主题）和新版本的 KDE Plasma 桌面环境（带有经过调整的小部件）。Kali (for) ARM、一些新平台（通用云、QEMU VM）的 Kali镜像也有一些更新，并且 Kali 已添加到 Microsoft Azure 商店。**官方下载地址：https://www.kali.org/get-kali/**
