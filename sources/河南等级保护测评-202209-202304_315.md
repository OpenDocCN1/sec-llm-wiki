# 2022年顶级网络安全博客和网站

国内的安全网站，其实也非常多。特别是微信推出公众号、百度推出百家号、头条推出头条号后，安全网站和自媒体成为网络安全知识传播的两大主力，而在国外则以安全网站和博客为主。大部分网络安全公司，都有自己网站和博客，而国外还有推特这个阵地。在国内，我们知道freebuf、安全牛、E安全、安全内参等，当然你也看到了“**河南等级保护测评**”公众号，期待一天咱们共建一个有影响力的宣传平台，共同为我国的网络安全尽一份绵薄之力。本公众号的成长，离不开您的支持，请多多转发，共同进步。今天我们结合国外的网站信息，谈谈国外比较有影响力的安全网站和博客。![](../Images/1c212a8c108523e147d4a0ddf97defe4.png)

### 1.DanielMiessler

作为一名经验丰富的网络安全专家、顾问和作家，米斯勒在他的博客上采用了一种个人化的方式——用这样的话来问候访问者：“我的名字是丹尼尔·米斯勒……我在安全、技术和人类的交汇处探索有趣和美丽的事物。” 他的产品包括精选的时事通讯、散文、播客和高质量的写作。

### 2.gcluley

### 

在 2013 年决定开始“为自己工作”之前，Graham Cluley 是一位长期在 Sophos 和 McAfee 担任高级职位的行业专家，可以说 Graham Cluley 完全熟悉网络安全领域——以开放、易于访问的风格运行博客，同时继续他的工作。担任会议发言人、媒体专家、播客和顾问。

### 3. IT 安全大师

IT Security 是 IT 安全行业突发新闻的每日新闻摘要。他们提供文章、视频、网络研讨会、分析、案例研究，甚至还有一个专门介绍最新网络安全骗局的部分，重点介绍最近的黑客攻击。

### 4.安全周刊

该博客以行业资深人士 Paul Asadoorian的作品为特色，以网络广播和大量 IT 安全视频节目为特色，您可以在包括 iTunes、YouTube、Google Play 等在内的多个频道上收听或观看这些节目。

### 5.黑客新闻

黑客新闻以最新的网络安全新闻为特色，深入报道“信息安全的当前和未来趋势以及它们如何塑造网络世界”。重点关注领域包括数据泄露、网络攻击、漏洞和恶意软件。它声称每月有 800 万读者，其中包括“领先的安全研究人员、极客、技术人员、商业毕业生、CISO 以及数千名安全专业人员”。

### 6.信息安全杂志

Infosecurity Magazine 在过去十年中一直通过印刷版和在线版向读者提供前沿的网络安全内容。除了众多文章外，Infosecurity Magazine 还提供定期（免费）网络研讨会、白皮书和虚拟会议。

### 7. CSO在线

#### CSO 提供有关广泛的安全和风险管理主题的新闻、分析和研究。顾名思义，它面向企业安全决策者和 CSO（首席安全官）以及对信息安全、身份和访问管理、损失预防等感兴趣的任何人。它专注于提供“ \[需要\] 的关键信息，以领先于不断变化的威胁并防御犯罪网络攻击。”

### 8.Tripwire 

State of Security 提供有关行业状况的新闻和观点，由定期撰稿人以及来自整个网络安全行业的客座作者撰写。它曾荣获“最佳企业博客”和“最具娱乐性的安全博客”称号。以下是 2018 年的十大帖子。

### 9.troyhunt

Troy Hunt是一位网络安全思想领袖，他在世界各地演讲和培训技术专业人员，  是 Microsoft 区域总监和最有价值专家 (MVP)，专门从事在线安全和云开发。他还撰写了一个博客，其中包含冗长、全面且发人深省的帖子。

### 10.  byronaco‍hido

最后的看门狗由 普利策奖获奖记者、教师和受人尊敬的网络安全和隐私专家拜伦·阿希多 ( Byron Acohido ) 撰写。他的博客以视频为主，包括许多采访风格的帖子以及客座博客帖子。

#### 

### 11. Schneier论安全

Bruce Schneier 自 2004 年以来一直在他的博客 Schneier on Security 上撰写有关安全性的文章。他被经济学人称为“安全大师”，是 IBM Security 的特别顾问和 IBM Resilient 的首席技术官，哈佛研究员和13 本书。Bruce Schneier 了解安全性——他的博客证明了这一点。如果您对安全行业感兴趣，这绝对是一本值得收藏的书。

### 12. Akamai 博客

#### 

Akamai 是一家内容交付网络服务公司，发布了 Akamai 博客 — 汇集了大量技术和安全专业人士的新闻和观点。Akamai 将自己描述为“讨论、分享和反思推动当今在线业务发展趋势的论坛”。

### 13.briankrebs 

前华盛顿邮报记者 Brian Krebs 撰写了这个涵盖安全新闻和调查的深度博客。他是《垃圾邮件国度》一书的作者，曾在《纽约时报》、《商业周刊》和 Poynter.org 上发表过专题报道。

### 14.Naked Security 

Naked Security 博客由 Sophos 发布，赢得了最佳企业博客和最佳 IT 安全博客等多项奖项。该博客每天都有多个故事，涵盖了计算机安全的各个方面。

### 15.taosecurity  

TaoSecurity由 Richard Bejtlich撰写，内容涵盖“数字安全、战略思想和军事历史”，专门针对中国网络犯罪分子。Bejtlich 撰写了多本关于安全的书籍。他是 Corelight Inc. 的首席安全策略师和 FireEye 的前首席安全策略师。

### 16.Dark Reading

如果您从事网络安全工作或对该领域有任何兴趣，您可能已经访问过 Dark Reading 网站。作为网络安全专业人士中最受欢迎的网站之一，Dark Reading 提供从分析和应用程序安全到移动和云安全、物联网等各种主题的见解。根据 Dark Reading 的说法，“这是企业安全人员和决策者了解新的网络威胁、漏洞和技术趋势的地方。”

### 17.电脑世界 

PC World 是一份著名的在线计算机和技术杂志，提供新闻、评论和操作方法，以及大量视频，主题不仅包括与 PC 相关的问题，还包括商业和 网络安全 。

### 18.Wired 

Wired 是另一个广受欢迎的网站，涵盖了从商业和文化到设计、装备、科学、安全和交通等一系列主题。Wired 不仅受到网络安全领域的人的欢迎，而且受到任何对技术如何影响当今文化感兴趣的人的欢迎。该网站 2018 年最有趣的故事之一是“ NotPetya 的不为人知的故事，历史上最具破坏性的网络攻击”。

### 19.首席信息官 

CIO 是一本面向技术和安全领导角色的在线杂志。其编辑重点包括旨在帮助高级管理人员应对其组织面临的网络安全挑战的内容。

### 20. CNET

CNET 是技术评论、“操作方法”技术内容和最新技术新闻的首选网站。他们的网站上还有一个购物区，列出了从电视到笔记本电脑再到网络托管等各种商品的最优惠价格。它们还涵盖网络安全问题，例如数据泄露和防御，以及政府为建立 美国网络学说所做的努力。

### 21.WeLiveSecurity.com

WeLiveSecurity.com 是 IT 安全公司 ESET 发布的屡获殊荣的博客，其中包含来自世界各地的研究人员和安全专家的安全新闻和见解。 它是 InfoSecurity 杂志欧洲安全博客奖的 2018 年最佳企业安全博客奖得主，是新闻工作者和行业专家信赖的突发网络新闻来源。它还作为论坛发布了一些 ESET 最引人注目的网络安全发现。

### 22.signalmag

### 

Signal Magazine 是真正适合网络安全专业人士的杂志。它是 AFCEA 的官方出版物，AFCEA 是一个专业协会，自 1946 年以来一直专注于为政府和军队服务。Signal 出版印刷和在线杂志、博客、时事通讯、网络研讨会、电子书等。内容主要围绕网络、国防、国土安全、情报和技术——基本上是所有与安全相关的事物。

### 23.threatpost 

ThreatPost 是一个独立的新闻站点，涵盖各个角度的安全性。除了数字文章（这里是其 2019 年网络安全预测），他们还不断发布视频和播客。

### 24.计算机世界

Computerworld 于 1967 年作为印刷杂志成立，并于 2014 年“走向数字化”，现在是在 47 个国家/地区拥有品牌的全球出版物，是科技界任何人的首选。该在线杂志涵盖云计算、新兴技术 网络安全 等内容。
