IBM Cloud Databases for PostgreSQL 的供应链缺陷

原文：http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247488570&idx=4&sn=e0faa5e0a84183b9924a92692452fb55&chksm=ce4632cdf931bbdb6d00bb29ac3a95708fa783cb0cdb8f8bf2974142ff48f902878040d373e4&scene=27#wechat_redirect


IBM 修复了影响其云数据库 (ICD) for PostgreSQL 产品的高危安全漏洞，该漏洞可能被利用来篡改内部存储库并运行未经授权的代码。

特权升级漏洞（CVSS 得分：8.8）被云安全公司 Wiz 称为“ Hell's Keychain ”，被描述为“影响云提供商基础设施的首创供应链攻击向量”。

成功利用该漏洞可能使恶意行为者能够在客户环境中远程执行代码，甚至读取或修改存储在 PostgreSQL 数据库中的数据。

Wiz 研究人员 Ronen Shustin 和 Shir Tamari表示： “该漏洞由三个暴露的秘密链组成（Kubernetes 服务帐户令牌、私有容器注册表密码、CI/CD 服务器凭据）以及对内部构建服务器的过于宽松的网络访问。”

Hell's Keychain 始于 ICD 中的 SQL 注入漏洞，该漏洞授予攻击者超级用户（又名“ibm”）特权，然后用于在托管数据库实例的底层虚拟机上执行任意命令。

此功能被武器化以访问 Kubernetes API 令牌文件，从而允许进行更广泛的后期开发工作，包括从 IBM 的私有容器注册表中提取容器映像，该注册表存储与 ICD for PostgreSQL 相关的图像，并扫描这些图像以获取其他秘密。


“容器镜像通常包含专有源代码和二进制工件，这些都是公司的知识产权，”研究人员解释说。“它们还可以包含攻击者可以利用的信息来查找其他漏洞并在服务的内部环境中执行横向移动。”

Wiz 表示，它能够从图像清单文件中提取内部工件存储库和 FTP 凭据，从而有效地允许对受信任的存储库和 IBM 构建服务器进行不受限制的读写访问。

这种攻击可能会产生严重的后果，因为它使对手能够覆盖在 PostgreSQL 映像的构建过程中使用的任意文件，然后这些文件将安装在每个数据库实例上。

这家美国科技巨头在一份独立公告中表示，所有 IBM Cloud Databases for PostgreSQL 实例都可能受到该漏洞的影响，但指出它没有发现恶意活动的证据。

它进一步表示，修复程序已自动应用于客户实例，无需采取进一步行动。这些缓解措施分别于 2022 年 8 月 22 日和 9 月 3 日推出。

研究人员表示：“这些漏洞可能已被恶意行为者利用，作为广泛利用链的一部分，最终导致对平台的供应链攻击。”

为了减轻此类威胁，建议组织监控其云环境以查找分散的凭据，实施网络控制以防止访问生产服务器，并防止容器注册表被抓取。
