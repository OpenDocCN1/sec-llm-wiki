# Hive 勒索软件团伙攻击1,300 家企业，赚取 1亿美元

**美国政府机构表示，Hive 勒索软件团伙已使 1,300 多家企业受害，在过去一年半中收到了超过 1 亿美元的赎金。**

**![](../Images/0be1f2f8ff802acc80fc3a299afba1b8.png)**

Hive自 2021 年 6 月起活跃并作为勒索软件即服务 (RaaS) 提供，已被用于攻击企业和关键基础设施实体，包括通信、政府、医疗保健、IT 和关键制造组织。

为了提高对 Hive 勒索软件的认识，网络安全和基础设施安全局 (CISA)、联邦调查局 (FBI) 和卫生与公共服务部 (HHS) 发布了一份联合警报，详细说明观察到的危害指标(IoC) 和战术、技术和程序 (TTP)。

![](../Images/59826fa2d46f10714151e8f9dc7d0a6e.png)

根据传播 Hive 的分支机构，可以通过远程桌面协议 (RDP)、虚拟专用网络 (VPN) 和其他未通过多因素身份验证 (MFA) 保护的远程连接协议获得对受害者网络的初始访问权限。

联合警报显示，在一些 Hive 勒索软件攻击中，观察到威胁行为者绕过 MFA 并利用 CVE-2020-12812 访问 FortiOS 服务器。Hive 分支机构还被发现发送带有恶意附件的网络钓鱼电子邮件，并针对已知的 Microsoft Exchange Server 漏洞（CVE-2021-31207、CVE-2021-34473 和 CVE-2021-34523）。

在获得对受害者网络的访问权限后，Hive 勒索软件会尝试识别和终止与反恶意软件、备份和文件复制相关的进程，停止卷影复制服务并删除现有副本，并删除 Windows 事件日志。

在加密之前，网络犯罪分子还会从受感染的 Windows、Linux、VMware ESXi 和 FreeBSD 系统中窃取感兴趣的数据。

Hive 在根目录中创建一个扩展名为 .key 的文件——这个文件对于创建它的系统是唯一的，需要解密。在每个受影响的目录中都会放入勒索字条，警告受害者不要篡改 .key 文件，因为那样会阻止数据恢复，并指示受害者通过 Tor 浏览器访问的网站上的实时聊天与攻击者联系。

赎金票据还威胁受害者，如果不支付赎金，数据将在 Tor 网站“HiveLeaks”上公开。Hive 威胁行为者还被发现使用匿名文件共享站点来泄露被盗数据。

“一旦受害组织在实时聊天面板上联系 Hive 参与者，Hive 参与者就会传达赎金金额和付款期限。Hive 参与者以美元协商赎金要求，初始金额从几千美元到数百万美元不等。Hive 参与者要求用比特币付款，”CISA、FBI 和 HHS 说。

这三个机构还警告说，已经观察到 Hive 攻击者重新感染（使用 Hive 或其他勒索软件变体）受害者，这些受害者在不支付赎金的情况下恢复了他们的环境。
