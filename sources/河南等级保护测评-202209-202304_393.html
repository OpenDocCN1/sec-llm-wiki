已经又到一年的收尾，微软周二补丁如期而至。以ZDI的网站整理的讯息看，这次微软是面对64个漏洞进行了补丁发布，而Adobe则0报告，着实有点让人吃惊。

2022 年 11 月的 Microsoft 补丁

本月，微软发布了 64 个新补丁，解决了 Microsoft Windows 和 Windows 组件中的 CVE；Azure 和 Azure 实时操作系统；微软动态；交换服务器；办公和办公组件；系统内部；视觉工作室; 共享服务器；网络策略服务器（NPS）；视窗位锁；和 Linux 内核和开源软件。此外，来自第三方的 5 个其他 CVE 被集成到 Microsoft 产品中，使修复总数达到 69 个。

在今天发布的 64 个新补丁中，11 个被评为严重，53 个被评为重要。本卷与之前 11 月的版本类似，还推动了微软在 2021 年发布的修复数量，并使今年成为有史以来第二个最繁忙的补丁。

本月发布的新 CVE 之一被列为公开已知，另外六个在发布时被列为在野外，其中包括自 9 月以来被列为受到积极攻击的两个 Exchange 漏洞。让我们仔细看看这个月的一些更有趣的更新，从我们一直在等待的那些 Exchange 修复开始：

-        CVE-2022-41028 - Microsoft Exchange Server 远程代码执行漏洞
-        CVE-2022-41040 - Microsoft Exchange Server 特权提升漏洞
这些补丁解决了当前用于主动攻击的最新 Exchange 漏洞。上个月预计它们会出现，但它们终于出现了（以及其他几个 Exchange 修复程序）。这些 bug 是 ZDI 在 9 月初购买的，当时向微软报告。在某个时候，它们在野外被发现。Microsoft 发布了几种不同的缓解建议，但最好的建议是测试和部署这些修复程序。有些人怀疑这些补丁会在本月发布，所以很高兴在这里看到它们。

-        CVE-2022-41128 - Windows 脚本语言远程代码执行漏洞
JScript 中的这个错误也被列为在野外被利用。攻击需要引诱用户访问特制网站或服务器共享。这样做时，他们将让他们的代码在受影响的系统上以登录用户的级别执行。微软没有提供关于这可能有多普遍的信息，但考虑到它是一种浏览和拥有类型的场景，我预计这将是一个包含在漏洞利用工具包中的流行错误。

-        CVE-2022-41091 - Windows Mark of the Web Security Feature Bypass Vulnerability
Mark of the Web ( MoW ) 旨在应用于从 Internet 下载的文件。这些文件应区别对待，并在访问它们时收到安全警告对话框。此漏洞也被列为受到主动攻击，但同样，Microsoft 没有提供有关这些攻击可能有多广泛的信息。

-        CVE-2022-41073 - Windows Print Spooler 特权提升漏洞
PrintNightmare的遗留问题仍在继续，因为威胁参与者继续挖掘巨大的攻击面，即 Windows Print Spooler。虽然自 PrintNightmare 以来我们已经看到了许多其他补丁，但这个补丁被列为狂野。虽然没有特别指出，但禁用打印后台处理程序应该是一种有效的解决方法。当然，这会破坏打印，但如果您处于无法进行修补的情况，这是一种选择。

-        CVE-2022-41125 - Windows CNG 密钥隔离服务特权提升漏洞
11 月活动攻击中列出的最后一个错误是“加密应用程序编程接口 - 下一代”(CNG) 密钥隔离服务中的特权提升。攻击者可以滥用这个漏洞在 SYSTEM 上运行他们的代码。它们需要经过身份验证，这就是为什么像这样的错误通常与某种形式的远程代码执行漏洞配对。与所有其他野外攻击一样，没有迹象表明它的使用范围有多广，但在这一点上它可能有点针对性。尽管如此，还是要快速测试和部署更新。
