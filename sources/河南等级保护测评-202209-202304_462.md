# 美国国家安全局NSA发布VPN安全指南

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjY2MTI3Mg==&mid=2247487571&idx=2&sn=cefb863c68b69fada36e07ddfd18155c&chksm=ce4636a4f931bfb294f466707ead99db7467a720d4e79df049687e0617177ec2e46914d4c715&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247487571&idx=2&sn=cefb863c68b69fada36e07ddfd18155c&chksm=ce4636a4f931bfb294f466707ead99db7467a720d4e79df049687e0617177ec2e46914d4c715&scene=27#wechat_redirect)

美国国家安全局（National Security Agency）近期发布了有关保护IPsec虚拟专用网络（VPN）安全的指南，在冠状病毒大流行之后，美国各地的公司继续努力应对远程工作。指南建议包括警告不要依赖供应商提供的默认配置。

该文档有两种形式：安全VPN 指南和详细的配置示例版本。许多VPN供应商提供了为其设备预先配置的加密套件和IPsec策略，以及用于兼容性的其他套件。Internet安全关联和密钥管理协议（ISAKMP）和IPsec策略定义了VPN如何相互认证，管理其安全关联以及如何在VPN连接的不同阶段生成其密钥。

![](../Images/edab2ee2ff1e0e1aaafa222acb0d02d4.png)

指南警告称如果将这两个阶段中的任何一个配置为允许过时的加密，则整个VPN都将面临风险，并且可能会丧失数据机密性。

美国国家安全局（NSA）建议管理员确保政策符合国家安全系统政策委员会（CNSSP）-15标准，该标准定义了在国家安全系统之间安全共享信息的参数。甚至配置符合CNSSP-15的默认策略可能还不够，许多VPN被配置为在默认策略不可用时退回到备用策略。如果管理员将供应商的预配置替代产品留在其设备上，则可能会使用不合规的安全策略。

![](../Images/382ed5a00a988acec0d8c5a217981095.png)

IPsec于1990年代引入，是VPN相互通信的传统协议。可以用于远程访问或VPN间通信。是SSL / TLS VPN的替代方法，后者提供完全基于浏览器的访问，而无需在客户端使用专用的软件应用程序。

NSA建议管理员减少其VPN网关攻击暴露面。由于这些设备倾向于可以通过互联网访问，很容易受到网络扫描、暴力攻击和零日漏洞攻击。降低此风险的一种方法是，如果使用对等VPN，则将接受的流量限制为已知IP地址。

远程访问VPN时远程对等IP地址是未知的，因此无法将其添加到静态过滤规则中。管理员仍可以限制对可通过UDP访问的特定端口和协议（例如端口500和4500）的访问。
