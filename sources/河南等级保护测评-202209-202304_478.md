# 在 Linux 中恢复丢失和删除的数据的步骤

丢失文件通常是一种痛苦的经历，尤其是当涉及到大量重要信息并且 Linux 用户也不能幸免时。通常，当这些文件被删除时，它们无法恢复，因为人们没有处理它们的技术知识。但是，可以恢复文件。要恢复已删除或丢失的文件。例如， Linux 系统** (/media/dnyce/117137A85FFD287C) **分区上的可移动媒体 (/dev/sdb5) 上的文件 'linuxshelltips' 已被删除，需要恢复。可以使用** TestDisk **数据恢复工具在 Linux 中恢复已删除的文件。该工具不仅可以有效地恢复丢失的数据，还可以用于在 Linux 环境中恢复损坏的文件系统。TestDisk 数据恢复工具可以安装在主要的 Linux 发行版上。安装后，切换到 root 用户帐户并启动 TestDisk 并在突出显示的“创建新日志文件”选项上按 \[Enter\] 非常重要。采取行动后，用户将收到系统上所有硬盘设备的列表。然后，他们可以导航到要从中恢复丢失数据的设备。下一步是使用键盘箭头键并导航到驱动器列表底部的 \[Proceed\] 菜单选项。尽管TestDisk倾向于突出最实用的选项，但建议用户通过按键盘上的\[Enter\]选择分区表的默认选项，然后单击\[Advanced\]选项并按键盘上的\[Enter\]。之后，用户可以导航到分区选项，在终端窗口底部显示 \[Undelete\] 选项，然后按键盘上的 \[Enter\]。动作完成后，被删除的 linuxshelltips 文件被恢复。建议希望恢复多个文件的用户使用键盘键 \[a\] 选择/取消选择它们。要复制多个选定的文件，建议使用键盘键 \[c\]。
