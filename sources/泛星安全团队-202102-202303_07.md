# 0x01 环境搭建

ofcms是一个java 版CMS系统、基于java技术研发的内容管理系统、功能：栏目模板自定义、内容模型自定义、多个站点管理、在线模板页面编辑等功能、代码完全开源，技术选型：jfinal DB+Record mysql freemarker Encache spring 等 layui zTree bootstrap。
