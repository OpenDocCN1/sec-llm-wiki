### DIVA简介：

        DIVA（该死的不安全和易受攻击的应用程序）是故意设计的存在很多漏洞的Android app。

源代码链接：https://github.com/payatu/diva-android

apk文件链接：http://payatu.com/wp-content/uploads/2016/01/diva-beta.tar.gz

### 闯关工具：

 Java JDK 1.8

夜神模拟器

Android SDK Tools

Apktool

dex2jar、jd-gui

AXMLPrinter2.jar

### 开始闯关：

#### 第一关 不安全的日志输出

        产生原因：由于app代码中将敏感信息（如凭据，会话ID，财务详细信息等）通过log.e输出，所以在app的表单中输入的内容，可以在相关的日志中输出。

1.  提交数据后，输入命令adb logcat查看日志
    
    ![](../Images/10bf433fce16ffed6217fa85adb83875.png)
    
      
    
    也可以进入交互式shell，输入ps | grep -i diva先找到diva的pid值(2732)，再通过logcat | grep \[pid\]获取日志信息。
    
    ![](../Images/f7f8c6263f89d2eeabd29f99a942ca46.png)
    
      
    
    ![](../Images/eb2d9252f942e4bd5657068fe77ff946.png)
    
      
    
2.  可以通过反编译在logActivity.class中看到代码中使用了log.e输出。
    
    ![](../Images/0cc0e9bf90245e0f88deb1dc45e29e1e.png)
    
      
    

#### 第二关 硬编码—第一部分

硬编码

*   某些需要比较字符串的值为硬编码，如：激活码
*   加密的key或者salt为硬编码，如MD5的salt

1.  直接查看源码，发现vendor key的值![](../Images/a052f2982eeef4e514c1e16f6f744d75.png)
    
    ![](../Images/dfe7264a08392e04a4d9d0090cad99aa.png)
    
      
    

#### 第三关 不安全的数据存储—第一部分

        产生原因：使用了SharedPreferences类，该类是Android平台上一个轻量级的存储类，主要是用来保存一些常用的配置，本例中是用该类存储了用户名和密码，因此是具有风险的。SharedPreferences类存储的数据会以.xml的形式存储在/data/data/app的包名/shared\_prefs目录下。

1.  首先随意输入用户名和密码 admin/admin 点击保存
    
    ![](../Images/cc4ca1c83f4694a5c6e1699a2338d110.png)
    
      
    
2.  进入shell模式，在/data/data/jakhar.aseem.diva/shared\_prefs/目录中查看jakhar.aseem.diva\_preferences.xml文件，也可以输入adb pull /data/data/jakhar.aseem.diva/shared\_prefs ./将文件复制出来查看
    
    ![](../Images/1f089dcaaf04399fea3280b025917506.png)
    
      
    
    ![](../Images/49c63f7a65948046a60dbf810744eae1.png)
    
      
    
3.  在InsecureDataStorage1Activity.class中可以看到产生风险的地方
    
    ![](../Images/dada0ce184499439095274ad39597d41.png)
    
      
    

#### 第四关 不安全的数据存储—第二部分

        产生原因：将敏感数据保存在本地的sqlite3数据库中，对应的数据库目录: /data/data/app的包名/databases

1.  同样先输入admin/123456
