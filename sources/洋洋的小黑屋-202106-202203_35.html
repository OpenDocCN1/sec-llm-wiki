前言

最近购入了一本《内网安全攻防》，虽然之前也看过很多内网渗透的文章，但都比较细碎，很难串到一起。这次决定跟着这本书来系统学习巩固一下内网渗透的知识。

本机信息收集

拿到一台边界机的shell后，需要知道其所处的内网结构是什么样的，角色是什么样的，使用这台机器的人角色是什么，这台机器上安装了什么杀毒软件等等。手动信息收集需要收集的信息包括：操作系统、权限、内网IP地址段、杀毒软件、端口、服务、补丁、网络连接、共享、会话。如果是域内主机，操作系统、应用软件、补丁服务、杀毒软件一般都是统一安装的。

  1. ipconfig /all        查询网络配置信息
  2. systeminfo        查询系统名称和版本
  3. wmic product get name,version        查看安装的软件、版本、路径
  4. wmic service list brief        查询本机服务信息
  5. tasklist                        查询进程列表
  6. wmic process list brief        查看进程信息
  7. wmic startup get command,caption    查看启动的程序信息
  8. schtasks /query /fo LIST /v        查看计划任务
  9. net statistics workstation        查看主机开机时间
  10. net user                         查看用户列表
  11. net localgroup administrators    查看本地管理员
  12. query user || qwinsta        查看当前在线用户
  13. net session       列出或断开本地计算机和连接的客户端的会话
  14. netstat -ano        查看端口列表、本机开放的端口所对应的服务和应用程序
  15. systeminfo        查看系统详细信息
  16. wmic qfe get Caption,Description,HotFixID,InstalledOn      使用 wmic 识别安装在系统中的补丁情况
  17. net share（wmic share get name,path,status）     查看本机共享列表和可访问的域共享列表（域内共享有很多时候是相同的）
  18. route print（arp -a）     查询路由表及所有可用接口的 ARP
  19. netsh firewall set opmode disable     关闭防火墙（ Windows Server 2003 系统及之前版本）
  20. netsh advfirewall set allprofiles state off      关闭防火墙 （ Windows Server 2003 系统及之后版本）
  21. netsh firewall show config                查看防火墙配置
  22. netsh firewall add allowedprogram c:\xxx.exe "allow nc" enable      修改防火墙配置，允许指定程序全部链接（Win Server 2003 系统及之前版本）
  23. netsh advfirewall firewall add rule name="pass nc" dir=in action=allowprogram="C: \xxx.exe"     修改防火墙配置，允许指定程序全部链接( Win Server 2003 之后系统版本)
  24. netsh advfirewall firewall add rule name="Remote Desktop" protocol=TCP dir=inlocalport=3389 action=allow     防火墙允许3389放行
  25. REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f      开启3389
  26. netsh advfirewall set currentprofile logging filename "C:\windows\temp\fw.log"      设置防火墙日志存储位置

查询当前权限

  1. whoami  查看当前权限
  2. whoami /all  获取域 SID
  3. net user XXX /domain  查询指定账户的详细信息

判断是否有域

内网渗透中，搜集完跳板机的本机信息之后，就需要判断当前跳板机是否所处内网，所处内网中是否有域，如果有域，需要判断当前跳板机是否在域内，以便后面进一步扩大战果。

  1. ipconfig /all      查看网关 IP 地址、DNS 的 IP 地址、本地地址是否和 DNS 服务器为同一网段、域名等
  2. nslookup   （可以通过反向解析查询命令 nslookup 来解析域名的 IP 地址。使用解析出来的 IP 地址进行对比，判断域控制器和 DNS 服务器是否在同一台服务器上）
  3. systeminfo      判断本机是否处于域环境，查看本机信息，回显信息中域信息为域名表示处于域环境，域信息为workgroup表示不在域内。
  4. net config workstation     判断本机是否处于域环境，查询当前登录域及登录用户信息， （回显中的工作站域 DNS 名称显示域名表示处于域环境，如果显示为 WORKGROUP，则表示非域环境，登录域可以判断当前用户是域用户登录还是本地用户登录）
  5. net time /domain      判断主域（一般域服务器都会同时作为时间服务器，如果存在域，且当当前用户为域用户，会成功返回时间信息）

探测域内存活主机

注：在扫描的时候，应尽量避免使用Namp 等工具进行暴力扫描，也不要在目标机器上使用图形化的工具，而要尽量使用目标系统自带的各种工具，推荐使用 PowerShell 脚本。对于 Windows 7 以下版本的系统，可以使用 VBS 脚本。在探测时，可在白天和夜间分别探测，以对比分析存活主机和对应的 IP 地址。

利用 NetBIOS 快速探测内网

NetBIOS 是一种在局域网上的程序可以使用的应用程序编程接口（API），为程序提供了请求低级服务的统一的命令集，作用是给局域网提供网络及其他特殊功能。几乎所有的局域网都是在NetBIOS 协议的基础上工作的。“NetBIOS”也是计算机的标识名，该名字主要用于局域网中计算机之间的相互访问。NetBIOS 的工作流程是正常的机器名解析查询应答过程，推荐优先使用。nbtscan 是一个命令行工具，用于扫描本地或远程 TCP/IP网络上的开放NetBIOS名称服务器。nbtscan 有 Windows 版本和 Linux 版本，体积很小，且不需要特殊的库或 DLL。

  1. nbtscan.exe  ip地址范围
  2. 显示结果的第一列为 IP 地址，第二列是机器名和所在域名，最后一列是关于机器所开启的服务的列表

利用ICMP协议探测内网

依次对内网中的每个 IP 地址执行 ping 命令，可以快速有效地找出内网中所有存活的主机。

  1. for /L %I in (1,1,254) DO @ping -w 1 -n 1 192.168.2.%I | findstr "TTL="

利用ARP协议扫描内网

  1. arp.exe -t  IP地址范围（192.168.2.0/24）

收集域内基础信息

确定了当前内网拥有的域，并且所控制的主机在域里面，就可以进行域内相关信息的收集了。

  1. net view /domain        查询域信息
  2. net view /domain:XXX        查询此域内所有计算机
  3. net group /domain        查询域内所有用户组列表
  4. net group "domain computers" /domain        查询所有域成员计算机列表 
  5. net accounts /domain        获得域密码策略设置、密码长短、错误锁定等信息
  6. nltest /domain_trusts        获取域信任信息

查找域控制器

  1. nltest /DCLIST:XXX        查看域内控制器的机器名(xxx为域名)
  2. Nslookup -type=SRV _ldap._tcp         查看域控制器的主机名
  3. net time /domain        查看当前时间（般时间服务器为主域控制器）
  4. net group "Domain Controllers" /domain        查看域控制器组
  5. netdom query pdc        到域控制器的机器名为 DC

获取域内用户和管理员信息

  1. net user /domain        查询所有域用户列表
  2. wmic useraccount get /all        可以获取域内用户详细信息，常见参数包括用户名、描述信息、SID、域名、状态
  3. dsquery user        查看存在的用户
  4. net localgroup administrators /domain        查询域内置本地管理员组用户

查询域管理员用户组

  1. net group "domain admins" /domain        查询域管理员用户
  2. net group "Enterprise Admins" /domain        查询管理员用户组

定位域管理员

在一个域中，当计算机加入域后，会默认给域管理员组赋予本地系统管理员的权限。也就是说，在计算机添加到域中，成为域的成员主机后，系统会自动将域管理员组添加到本地系统管理员组中。因此，域管理员组的成员均可访问本地计算机，而且具备完全控制权限。渗透测试人员通常会通过搜集域内信息，追踪域内特权用户、域管理组用户的历史登录位置、当前登录位置等。定位域内管理员的常规渠道，一是日志，二是会话。日志是指本地机器的管理员日志，可以使用脚本或 wevtutil 导出查看。会话是指域内每个机器的登录会话，可以匿名查询，无须权限，可以使用 netsess.exe 或 PowerView 等工具查询。

域管理员定位工具

假设已经在 Windows 域中取得了普通用户权限，希望在域内横向移动，想知道域内用户登录的位置、他是否是任何系统中的本地管理员、他所归属的组、他是否有权访问文件共享等。枚举主机、用户和组，有助于我们更好地了解域内布局。常用的工具有 psloggedon.exe、pveFindADUser.exe、netsess.exe、hunter、NetView 等。在PowerShell 中，常用的脚本是 PowerView。

1.psloggedon.exe

psloggedon.exe 可以显示本第 2 章 内网信息的收集 67地登录的用户和通过本地计算机或远程计算机的资源登录的用户。如果指定了用户名而不是计算机，psloggedon.exe 会搜索网络邻居中的计算机，并显示该用户当前是否已登录，其原理是通过检验注册表里 HKEY_USERS 项的 key 值来查询谁登录过机器（同样调用了 NetSessionEnum API），某些功能需要拥有管理员权限才能使用。

  1. psloggedon [-] [-l] [-x] [\\\\computername|username]
  2. -：显示支持的选项和用于输出值的单位。 
  3. -l：仅显示本地登录，不显示本地和网络资源登录。 
  4. -x：不显示登录时间。
  5.  \\computername：指定要列出登录信息的计算机的名称。 
  6. Username：指定用户名，在网络中搜索该用户登录的计算机。

2.pveFindADUser.exe

pveFindADUser.exe用于查找 Active Directory 用户登录的位置，枚举域用户，以及查找在特定计算机上登录的用户，包括本地用户、通过 RDP 登录的用户、用于运行服务和计划任务的用户账户。运行该工具的计算机需要具有.NET Framework 2.0，并且需要具有管理员权限。

  1. 直接运行“pveadfinduser.exe -current”命令

3.netview.exe

netview.exe 是一个枚举工具，使用 WinAPI 枚举系统，利用 NetSessionEnum 找寻登录会话，利用 NetShareEnum 找寻共享，利用 NetWkstaUserEnum 枚举登录的用户。同时，netview.exe 能够查询共享入口和有价值用户。netview.exe 的绝大部分功能不需要管理员权限即可执行。

  1. -h：显示帮助菜单。 
  2. -f filename.txt：指定从中提取主机列表的文件。 
  3. -e filename.txt：指定要排除的主机名文件。 
  4. -o filename.txt：将所有输出重定向到文件。 
  5. -d domain：指定从中提取主机列表的域。如果没有指定，则使用当前域。
  6. -g group：指定用户搜寻的组名。如果没有指定，则使用 Domain Admins。 
  7. -c：检查对已找到共享的访问权限。

查找域管理进程

如果在一个非常复杂的内网环境中，渗透测试人员不能立即在拥有权限的系统上获得域管理员进程，通常采用的方法是在跳板机之间进行跳转，直至获取域管理员权限，并进行一些分析工作，以找到其渗透测试路径。

本机检查

  1. net group "Domain Admins" /domain        获取域管理员列表
  2. Tasklist /v        列出本机所有进程及进程用户

查询域控制器的域用户会话

  1. net group "Domain Controllers" /domain        查询域控制器列表
  2. net group "Domain Admins" /domain        收集域管理员列表
  3. Netsess.exe –h        收集所有活动域会话列表
  4. FOR /F %i in (dcs.txt) do @echo [+] Querying DC %i && @netsess -h %i 2>nul >sessions.txt && FOR /F %a in (admins.txt) DO @type sessions.txt | @findstr/I %a        交叉引用域管理员列表与活动会话列表

扫描远程系统上运行的任务

  1. net group "Domain Admins" /domain        收集域管理员的列表。

扫描远程系统上 NetBIOS 信息

  1. for /F %i in (ips.txt) do @echo [+] Checking %i && nbtstat -A %i2>NUL >nbsessions.txt && FOR /F %n in (admins.txt) DO @type nbsessions.txt |findstr /I %n > NUL && echo [!] %n was found logged into %i
