# wechat-export

Export WeChat chat histories to HTML files.

## Preview

This script generates a HTML file for each contact's chat history.

![](../Images/64929e9fc56244fed529345a6004c688.png)

Currently it supports:  

•Text•Voice•Picture•Video•System message

## How to Use

Tested on macOS 11.5.2 and iOS 14.8, but should work on any recent versions.

1.Back up iPhone with your Mac. 

![](../Images/ec9cd00d38e42ee7f45e5633a2c7938c.png)

2.Use iExplore to export "Documents" to the local system. 

![](../Images/33726bc8890026cf22d96cd13dc2fa34.png)

3.Clone the code.4.Compile the audio decoder: `cd silk/silk && make && cd ../../`5.`npm install`6.`node index.js path_to/Documents/{uid} output_dir` (`path_to/Documents` is what we got from the second step, and `uid` looks like `g3c3814a370neh4dr69uf9f889f6ea7a`).
