明天，一场世界级“极客派对”在这里开启

中国有没有适合极客生长的土壤？


有，没有。谁说了也不算呐。

美国人 Jeff Moss 和中国人马杰决定一起做个“小试验”来验证一下。


于是，2018年，原本只在美国拉斯维加斯举办的世界顶级黑客（极客）大会DEF CON 跨国万水千山漂洋过海来中国办了一次，Beta版（测试版）。


咦？好像有点儿意思……


去年的那场“小试验”挺成功，于是他们打算把试验田继续扩大，这便有了今年的“DEF CON 神州”模式。


明天，它的1.0正式版本将首次亮相。



关注浅黑科技超过一年的浅友可能知道，去年幺哥为了拿到一手信息，大周六的早上六七点从被窝里爬出来，跑到现场拍照片撸稿子，写出了这篇：（我黑进全球最著名的黑客大会，拿到了一手信息。。。 | DEF CON 前戏速递）


为了维持住快男称号，今年我打算再快一点，提前一天就去现场。下面，请跟着我的脚步一起感受极客客派对前一天的宁静。。。




一、选址

今年 DEF CON 地点选在北京751艺术区一个由废弃工厂改造而成的艺术区，从全世界各地赶来的观众不仅能在这里感受到纯正的工厂风，还能顺道领略北京大山子路口的神奇。


工厂、摇滚、极客、涂鸦、机械、黑客、朋克、金属、破解、未来、电子、渴望……不知道为什么，这些词汇从逻辑上没啥关系，摆在一起却很和谐，仿佛有某种内在联系。


或许这就是 DEF CON 选在这里举办的原因，751浓浓的工厂风一下子让人联想到蒸汽朋克、赛博朋克。



二、主会馆



我到 DEF CON 现场时，工人还在布置，现场杂乱，反倒有些朋克感。（那串字符是我手绘的……）


我曾和史中讨论过朋克的外显特征是什么，最后得出的结论是：多,而无用。看来还挺准。



这位大叔正在给集装箱涂鸦，或许他知道自己写的字母 DEF CON 意味着什么，或许不知道。


一辆吊车在场馆外开来开去，竟跟现场的布置风格融为一体毫无违和感，我头一次觉得一辆吊车也可以很朋克，一副吊吊的样子。。。



几个工人们正在运送货物。后面的场馆最初是一个大煤气罐，如今已经成了科技公司们办会的圣地。或许是因为它又大又圆，所以风水比较好，在里面开过会的公司生意都能又长又宽。



三个工人在摆弄一个蜂窝状的装饰物，给明天的活动现场补上一些细节。



一辆吊车正在悬挂展板。


这是挂上之后的样子。



工人正在“做旧”一个现场装饰品。



主会馆门口，一个师傅正在切割金属架，火花从转动的轮盘里飞出。从门口的装饰看出，这次的主要搭建风格也是以金属、机械为主。

 

明天这个罐子里将坐满成百上千位极客、爱好者以及像我这样酱油打手。



一位工人师傅坐在讲台上玩手机，他屁股下的这个台子在接下来的三天会站上几十位世界顶级的极客。



会场后方有一个神秘的集装箱，这是一个名叫“无极之树”的互动装置，据说是为了致敬《银翼杀手》。很可惜我没看过这部作品，有浅友知道这是什么梗吗？



三、VILLAGE（村落）



VILLAGE 直接翻译过来的中文意思是“村落”，这是 DEF CON 大会的一大特色活动。比如这个 LOCK PICKING VILLAGE，开锁村落，专门教人开锁，让你坐着躺着站着用各种姿势开锁（不用钥匙的那种），带你体验最原始的破解快感。




BLACK WINDOW VILLAGE ，黑窗村落？这是一个新的 VILLAGE ，我也不知道是干嘛的，难道是教人跳窗？还是像电影里特工那样，出入防御重地犹如无人之境？


CAR HACKING VILLAGE，汽车破村落。一开始我以为明天黑客会来破解这两辆车金杯车，工作人员告诉我这是工人们的坐骑 … … 明天这里会换成一辆特斯拉或是其他品牌的智能汽车，黑客们在这里尝试破解，并且给在场观众讲解原理。



AI VILLAGE ，这是百度安全的特色环节，他们会在这里讲解内存安全等专业技术内容。


RECON VILLAGE，侦察者村落，教你如何在网上侦查信息以及隐匿自己。


BLOCKCHAIN VILLAGE，区块链村落，教你关于区块链技术、区块链安全的那些事儿。


四、中式极客


我回头一看，几位大哥蹲在地上堆积木，一开始我以为是乐高积木，走近一看并不是。


据说，他们将会在这三天在这个地方拼出一座太和殿，全程不用胶水粘合剂，不用一颗钉子螺丝。

 

这位大哥给我讲解名为“唐块”的积木，他说这种基于中国传统工艺榫卯结构搭建出来积木强度很高。我问小哥，一个积木拼出的玩意能有多结实？他指了指身后。

 

这是一辆由用积木作为主体的电动小车，一言不合就发车的那种。

 

小哥说，整个车体也没有用粘合剂、钉子或螺丝，纯靠自身的榫卯结构，完全可以承受一个成年人的重量。骑着它去买菜，你就是菜市场最靓的仔。还能带着妹子去兜风……


旁边是成箱成箱的积木零件。据说他们要在这里连着拼三天，参会观众可以全程观看搭建过程，有兴趣也可以上手感受一下。


主会场外，几个指路牌堆在路边，今年 DEF CON 有很多个区域，室内和室外都有，所以得靠它们来指路。



五、BCTF（极客夺旗赛）



这是另外一个外场，路过的人都忍不住对着他拍照，不知道明天这里会发生什么。



走进内场，黑客夺旗赛“BCTF”正在做最后的准备工作，服务器嗡嗡作响，仿佛是一台台正在预热的赛车引擎。


运维人员正对比赛环境做最后的调试。


明天这里会上演一场大战，CTF  相当于网络安全领域的“电子竞技”，一群黑客（长得很黑的客人）坐在一起解计算机谜题，或是互相进攻对方的电脑，得分高的队伍获胜。详情可参看史中老湿敷写的：《为解谜痴狂的人》。



比赛会场旁边是金主爸爸区，赞助商们会在这里搞搞小活动，带着小姐姐来这里给观众派发小礼品。



六、WORKSHOP（工作坊）



这是DEF CON 的另一个小场馆，工人正在搭建展板。“WORKSHOP”工作坊是一个涨姿势的地方，观众可以在此学到一些能很快上手的技术。


工人正在搭建内场，这里一共有三间会议室（教室）。


此时里面空无一人，但是从明天开始，可能得早点来才能占到座。


我看了一下“课程表”，每一堂课都很性感。比如，如何黑掉 DEF CON 1.0的胸卡，比如黑掉 WIFI，再比如……



在旁边的咖啡厅休息，我看见一个熟面孔，Jeff Moss，DEF CON 的创始人，也许是全球知名度最高的黑客之一。另一个顶级黑客大会 Blackhat 也是他创办的。

1993年他在美国拉斯维加斯发起第一届 DEF CON，如今已经走过26个年头，今年正式“落户”中国，开启 “DEF CON 神州”的第一个正式版。


关于他的故事，可以参看前几天史中发的《别忘了寂寞的山谷的角落里，“极客”们也有春天》


明天，他会来现场，和所有人一起全程观看这场“极客试验”。
