# 明天，一场世界级“极客派对”在这里开启

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0NDEwMTc1MA==&mid=2247492585&idx=1&sn=7409cdec531967601b9ea426bca6fac2&chksm=fb03e7f0cc746ee6fd83db5dfbdea7b4a50458d0b6195d3693e62e53a78aef5bf484b77497d5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247492585&idx=1&sn=7409cdec531967601b9ea426bca6fac2&chksm=fb03e7f0cc746ee6fd83db5dfbdea7b4a50458d0b6195d3693e62e53a78aef5bf484b77497d5&scene=27#wechat_redirect)

中国有没有适合极客生长的土壤？  

  

有，没有。谁说了也不算呐。

美国人 Jeff Moss 和中国人马杰决定一起做个“小试验”来验证一下。

  

于是，2018年，原本只在美国拉斯维加斯举办的世界顶级黑客（极客）大会DEF CON 跨国万水千山漂洋过海来中国办了一次，Beta版（测试版）。

  

咦？好像有点儿意思……

  

去年的那场“小试验”挺成功，于是他们打算把试验田继续扩大，这便有了今年的**“DEF CON 神州”**模式。

  

明天，它的1.0正式版本将首次亮相。

  

![](../Images/9a77df16fef35929eca8f4831ed070c8.png)

  

关注浅黑科技超过一年的浅友可能知道，去年幺哥为了拿到一手信息，大周六的早上六七点从被窝里爬出来，跑到现场拍照片撸稿子，写出了这篇：（[我黑进全球最著名的黑客大会，拿到了一手信息。。。 | DEF CON 前戏速递](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247487979&idx=1&sn=6425ab98df1c1f21a265f25ef2a17a1a&chksm=fb0015f2cc779ce418fa47a31bc906e801d34d224ffe480edf5546b2c0c2097dd7ce49301741&scene=21#wechat_redirect)）

  

为了维持住**快男**称号，今年我打算再快一点，提前一天就去现场。下面，请跟着我的脚步一起感受极客客派对前一天的宁静。。。

  

  

  

**一、选址**

![](../Images/e9a2bfce5b8d8c5ba0099e546ee54a54.png)![](../Images/49815bfeb1b6aead83fc2d9993dff1fd.png)

今年 DEF CON 地点选在北京751艺术区一个由废弃工厂改造而成的艺术区，从全世界各地赶来的观众不仅能在这里感受到纯正的**工厂风**，还能顺道领略北京**大山子路口的神奇**。

  

![](../Images/dfa3db5b11e63e9814470d6f02de5d22.png)

工厂、摇滚、极客、涂鸦、机械、黑客、朋克、金属、破解、未来、电子、渴望……不知道为什么，这些词汇从逻辑上没啥关系，摆在一起却很和谐，仿佛有某种内在联系。

  

或许这就是 DEF CON 选在这里举办的原因，751浓浓的工厂风一下子让人联想到蒸汽朋克、赛博朋克。

  

  

**二、主会馆**

  

![](../Images/f01a665fb3bbb65f60cfc9c3e0ecc376.png)  

我到 DEF CON 现场时，工人还在布置，现场杂乱，反倒有些朋克感。（那串字符是我手绘的……）

  

我曾和史中讨论过朋克的外显特征是什么，最后得出的结论是：**多,而无用。**看来还挺准。![](../Images/b14ce9464d2c7742bdb65121e4202564.png)  

  

![](../Images/176c2de603340de9b4efc484739fbd45.png)  

这位大叔正在给集装箱涂鸦，或许他知道自己写的字母 DEF CON 意味着什么，或许不知道。  

  

![](../Images/b42a2a768f4762471188ad2d84dc010a.png)

一辆吊车在场馆外开来开去，竟跟现场的布置风格融为一体毫无违和感，我头一次觉得一辆吊车也可以很朋克，一副吊吊的样子。。。

  

![](../Images/8322051313b73bffb527bcf28d973d31.png)  

几个工人们正在运送货物。后面的场馆最初是一个**大煤气罐**，如今已经成了科技公司们办会的圣地。或许是因为它**又大又圆**，所以风水比较好，在里面开过会的公司生意都能**又长又宽**。

  

![](../Images/d11b03c6c66a82f0f2a807e60b9327a1.png)  

三个工人在摆弄一个蜂窝状的装饰物，给明天的活动现场补上一些细节。

  

![](../Images/79bc4014de7115d29329d3db9676dd11.png)  

一辆吊车正在悬挂展板。

  

![](../Images/d31aa4f776e08b0295edabfe99896fb3.png)这是挂上之后的样子。

  

![](../Images/c638110a502c1acf42773f7a6ec16f5d.png)  

工人正在“做旧”一个现场装饰品。

  

![](../Images/927d399a8e93cf1c4909d9fe6b302ae4.png)  

主会馆门口，一个师傅正在切割金属架，火花从转动的轮盘里飞出。从门口的装饰看出，这次的主要搭建风格也是以金属、机械为主。

 ![](../Images/861767bf6c1767aacfa8b2d9da797f0c.png)

明天这个罐子里将坐满成百上千位极客、爱好者以及像我这样**酱油打手**。

  

![](../Images/8105c63d47b7d67bab860b48c13aced0.png)  

一位工人师傅坐在讲台上玩手机，他屁股下的这个台子在接下来的三天会站上几十位世界顶级的极客。

  

![](../Images/24846f2b6823fbe834fd46397ab2a178.png)  

会场后方有一个神秘的集装箱，这是一个名叫“无极之树”的互动装置，据说是为了致敬《银翼杀手》。很可惜我没看过这部作品，有浅友知道这是什么梗吗？

  

  

**三、VILLAGE（村落）**

  

![](../Images/18c34b1d82b588383f3afb3455be3e4e.png)  

VILLAGE 直接翻译过来的中文意思是“村落”，这是 DEF CON 大会的一大特色活动。比如这个 LOCK PICKING VILLAGE，开锁村落，专门教人开锁，让你坐着躺着站着用各种姿势开锁（不用钥匙的那种），带你体验最原始的破解快感。

  

  

![](../Images/12909a35cb00d87e4b3c8629160e94d1.png)  

BLACK WINDOW VILLAGE ，黑窗村落？这是一个新的 VILLAGE ，我也不知道是干嘛的，难道是教人跳窗？还是像电影里特工那样，出入防御重地犹如无人之境？

  

![](../Images/3c3c51baa7f4215a8ead298a23e7881a.png)

CAR HACKING VILLAGE，汽车破村落。一开始我以为明天黑客会来破解这两辆车金杯车，工作人员告诉我这是工人们的坐骑 … … 明天这里会换成一辆特斯拉或是其他品牌的智能汽车，黑客们在这里尝试破解，并且给在场观众讲解原理。

  

![](../Images/87971005e87af0fcfa84555127f3df77.png)  

AI VILLAGE ，这是百度安全的特色环节，他们会在这里讲解内存安全等专业技术内容。

  

![](../Images/767fba10f52cad4b8b44f27c8d037dcb.png)

RECON VILLAGE，侦察者村落，教你如何在网上侦查信息以及隐匿自己。

  

![](../Images/94d3ff666b7eec13698c0440e27da0b2.png)

BLOCKCHAIN VILLAGE，区块链村落，教你关于区块链技术、区块链安全的那些事儿。

  

**四、中式极客**

  

我回头一看，几位大哥蹲在地上堆积木，一开始我以为是乐高积木，走近一看并不是。

  

![](../Images/99fd05feeb094891099fc2162e4acebd.png)

据说，他们将会在这三天在这个地方拼出一座太和殿，全程不用胶水粘合剂，不用一颗钉子螺丝。

 

![](../Images/b9e2ae1fd0bf4c11efbb86309447a65f.png)

这位大哥给我讲解名为“唐块”的积木，他说这种基于中国传统工艺**榫卯结构**搭建出来积木强度很高。我问小哥，一个积木拼出的玩意能有多结实？他指了指身后。

 

![](../Images/5838bfc4bb2b53492420d20ab38754e7.png)

这是一辆由用积木作为主体的电动小车，**一言不合就发车**的那种。

 

![](../Images/325fa3b89831083ecb556e4530b19ff1.png)

小哥说，整个车体也没有用粘合剂、钉子或螺丝，纯靠自身的榫卯结构，完全可以承受一个成年人的重量。骑着它去买菜，你就是菜市场最靓的仔。还能带着妹子去兜风……

  

![](../Images/f9a80529e4753ed61b2eac470b9c083d.png)

旁边是成箱成箱的积木零件。据说他们要在这里连着拼三天，参会观众可以全程观看搭建过程，有兴趣也可以上手感受一下。

  

![](../Images/65c0d9230ad566c35eba914b94759bf7.png)主会场外，几个指路牌堆在路边，今年 DEF CON 有很多个区域，室内和室外都有，所以得靠它们来指路。

  

  

**五、BCTF（极客夺旗赛）**

![](../Images/4d7983e29880a73f340637737538ea21.png)

![](../Images/941edaeeb9d2ac7a4ebccbd98db92cfe.png)  

这是另外一个外场，路过的人都忍不住对着他拍照，不知道明天这里会发生什么。

  

![](../Images/adf212a89b02bd261fcdd8fdda48dc30.png)  

走进内场，黑客夺旗赛“BCTF”正在做最后的准备工作，服务器嗡嗡作响，仿佛是一台台正在预热的赛车引擎。

  

![](../Images/b7b27fa868ddcadab04ffd9317aac9ec.png)运维人员正对比赛环境做最后的调试。

  

明天这里会上演一场大战，**CTF  **相当于网络安全领域的“电子竞技”，一群黑客（长得很黑的客人）坐在一起解计算机谜题，或是互相进攻对方的电脑，得分高的队伍获胜。详情可参看史中老湿敷写的：《[为解谜痴狂的人](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247488417&idx=1&sn=72cc5c444fde3ea287a79eb204856e6e&chksm=fb0017b8cc779eae04c6748c0785c8444815ab62272ab3700f58ab58638e5bc76c49d1338aa2&scene=21#wechat_redirect)》。

  

![](../Images/3b3b2815368d8d97815700379820dcb7.png)  

比赛会场旁边是**金主爸爸区**，赞助商们会在这里搞搞小活动，带着小姐姐来这里给观众派发小礼品。

  

  

**六、WORKSHOP（工作坊）**

  

![](../Images/b74c38003b3bbee300e496a491de45f2.png)  

这是DEF CON 的另一个小场馆，工人正在搭建展板。“WORKSHOP”工作坊是一个涨姿势的地方，观众可以在此学到一些能很快上手的技术。

  

![](../Images/b0a307861c6fa4da6ca65d4b9806abb2.png)

工人正在搭建内场，这里一共有三间会议室（教室）。

  

![](../Images/ff31aa3d3c202b93a12c306b982042a7.png)

此时里面空无一人，但是从明天开始，可能得早点来才能占到座。

  

![](../Images/e41bcf7d6b783ea5ec8b9f6680d1b8fe.png)

![](../Images/5fdb4dc7518b176d0b07db0468355db2.png)

我看了一下“课程表”，每一堂课都很性感。比如，如何黑掉 DEF CON 1.0的胸卡，比如黑掉 WIFI，再比如……

  

![](../Images/5d7a1717588b1cff6ce95277648ccda1.png)  

在旁边的咖啡厅休息，我看见一个熟面孔，Jeff Moss，DEF CON 的创始人，也许是全球知名度最高的黑客之一。另一个顶级黑客大会 Blackhat 也是他创办的。  
  

1993年他在美国拉斯维加斯发起第一届 DEF CON，如今已经走过26个年头，今年正式“落户”中国，开启 “DEF CON 神州”的第一个正式版。

  

关于他的故事，可以参看前几天史中发的《[别忘了寂寞的山谷的角落里，“极客”们也有春天](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247492405&idx=1&sn=25123e5430d7b3ea23bc8a7354aa609f&chksm=fb03e72ccc746e3a3405fa33a24b8114eae38283ed66487e50ec47354ca3c6cca1d441050473&scene=21#wechat_redirect)》

  

明天，他会来现场，和所有人一起全程观看这场“极客试验”。
