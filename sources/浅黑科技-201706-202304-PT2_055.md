**别忘了寂寞的山谷的角落里**

**“极客”们也有春天**

**文 | 史中**

  

  

我们总会为一些画面着迷。

  

可能是这个，

  

![](../Images/ed405dab0c46eb7df5eb5bd785946e38.png)

  

可能是这个，

可能是这个，

也许喜欢的东西并不同，但我们对那种“像电流一样流淌全身”的美好感觉的期待是一样的。

  

  

  

**（一）**

  

  

文人张岱曾说，“人无癖不可与交”。人如果有个爱好，就会显得很有人味儿。

  

我恰好认识一些“有人味儿”的人。

  

比如马杰，在这个忙忙碌碌的世界，他绝对称得上稀有物种。

  

在工作中，马杰是那个兵来将挡水来土掩尽心尽责殚精竭虑的坚硬的百度安全总经理。但在日落之后，他就会变得蓬松而文艺。

  

![](../Images/e75a2aad4fdc204f9379c6a76e57224b.png)

**这是工作时的马杰，文艺时的马杰你还是脑补吧。。。**

  

  

他好酒，喜欢收藏精致的东西。工作之余，他在城市里拥有自己的日料店和居酒屋。

  

我记得，上次在他的居酒屋里，他热情地给我介绍“二割三分”的意思就是用于酿酒的米磨去了外面的77%，只留下核心的23%。当时，他眼睛里闪烁着挚爱的光芒。

  

居酒屋深埋在胡同，里面偶尔坐着一些独饮、对饮的人。马杰为他们创造了一个不大不小的“秘密基地”。

  

和中哥熟悉的人大概都知道，我也有一个小爱好——刷煎蛋。

  

煎蛋网是一个有十多年历史的兴趣社区，人们喜欢在上面分享冷知识、轻松的图片和段子。我喜欢煎蛋，大概是因为人们的话语里总是闪烁着思考和智慧。

  

煎蛋网社区的人们自称蛋友，自嘲煎蛋网是“小破站”，而尊称煎蛋的创始人兼唯一正式员工 Sein 为“方丈”。

  

![](../Images/6c0a232f2a899a738a64f57c46e633ea.png)

  

  

Sein 是一个财务自由的，有点脾气的码农。在煎蛋如日中天的2010年左右，他曾经拒绝了各路风险投资帮助煎蛋做大上市的建议，只是怕煎蛋成为一个为了赚钱什么姿势都能给的网站。

  

如今，蛋友们喜欢在“无聊图”板块的图片下面神吐槽，但头疼的是最近经常有人在吐槽区开车，或者写一段“恶政隐”（恶意的政治隐喻），从而让方丈被有关部门找去喝茶，以至于他一度不得不关闭吐槽功能。

  

包括我在内的蛋友们忧心忡忡，担心有一天 Sein 累了，“小破站”就此关闭，人们四散天涯。不过 Sein 回复蛋友说：我会坚持下去的。

  

我有一位公关盆友，对古典乐如数家珍。他可以听出斯美塔那心中汹涌的伏尔塔瓦河，可以看到贝多芬手中挥向命运的的英雄之剑。

  

前两天，这位盆友却跟我吐槽工作的艰辛：

> 朋友圈里一出现什么“行业爆文”，我就压力大到一身冷汗。因为如果我不去看它，就意味着我被行业落下一大截。我甚至觉得不捏着鼻子把朋友圈没完没了的文章看完，就没办法跟同事和媒体正常对话。
> 
>   
> 
> 每天我都在被各种消息推搡，我的时间被扯碎，和几千年前的奴隶并没什么区别。

  

他每天唯一确定的快乐就是晚上十一点后关掉手机，窝在沙发里享受他的音乐。

  

那些大师们作古百年，却仍在为他撑起一片坚固而美好的角落。

  

于是我明白，马杰的居酒屋，Sein 的煎蛋网，作曲家们的古典音乐，就是那些偶尔卸下生活铠甲的人们的一则“精神栖息地”。

  

![](../Images/40eb6254990a3c9f222a50c1a9590f6c.png)

  

安静的空气里，我们辗转于那些“有人味儿”的人为我们搭建的精神栖息地，能够暂时不用成为自己需要成为的那个人，感受纯粹的美、自由和热爱。

  

这种情景足够让我着迷。

  

  

  

**（二）**

  

  

Jeff Moss 是个有人味儿的美国人。

  

他用了二十几年，为一群特别的人创造了一片精神栖息地。

  

这群人通常被我们称为极客（Geek）。

  

![](../Images/858aeddedb36a7c561e453b296db2c4e.png)

**Jeff Moss**

  

  

极客是什么？能吃吗？怎么吃？好吃吗？其实我觉得，给极客下了最精彩定义的那个人是乔布斯。

  

很多人都知道，在距离破产只有90天时，乔布斯完成了这条苹果公司的广告片：

  

> 他们我行我素，桀骜不驯，惹是生非。他们格格不入，就像方孔中的圆桩。他们用与众不同的眼光看待事物。他们既不墨守成规，也不安于现状。。。有人视他们为疯子，而我们却视他们为天才。因为，只有那些疯狂到认为自己能够改变世界的人，才能真正地改变世界。

  

如果按照这个定义，爱因斯坦、鲍勃迪伦、马丁路德金、默罕默德阿里、希区柯克、毕加索，他们都是超屌的极客（事实上他们也都出现在了乔布斯操刀的这条广告片里）。

  

![](../Images/117e3cff005a0f3112cbb7f1b9df69b0.png)

**鲍勃·迪伦**

  

  

极客大概不信邪，他们信自己，天生喜欢在各种规矩的边缘疯狂地试探。实际上，为了科学地“作死”，极客们总得研究最新的知识，于是在这个科技闪耀的时代，很多极客顺理成章地成为了科技爱好者。

  

![](../Images/53ea5e6e7d4d76934ed264bec76d0098.png)

  

  

这世界上的极客多吗？

  

我不敢说。我只知道，看浅黑科技的文章看到这个地方都没有退出，如果不是逢文必看到底的强迫症，那你多半应该是个极客。

  

说远了，我们回来。

  

Jeff Moss 的故事开始于1985年。

  

那年，十岁的 Jeff 有了自己的第一台电脑，他不太理解为啥子人类的游戏要收费，于是决心寻找破解游戏的方法。

  

到了1988年，十三岁的 Jeff 已经我擦嘞闹不住了，他认识了好多“同道中人”，跟小伙伴成立了黑客小组，居然把美国的电信网络给黑掉了 。少年得志的 Jeff 给自己起了个中二的网名：“黑暗切线”，一直沿用至今。

  

![](../Images/8351df123a8286566e885a946ea8a4c7.png)

  

1992年，Jeff 十七岁。这一年他面对一场离别，一个极客小伙伴因为老豆的工作调动，就要离开美国了。重情重义的 Jeff 决定在拉斯维加斯定一家酒店，为他举行一场告别 Party。

  

结果神奇的事情发生了。。。还没到欢送的日子，这位朋友的老爹提前工作调动，朋友都来不及跟 Jeff 打招呼，就直接被薅走了，从此杳无音信。

  

定酒店的钱都花了，退是不可能退的。Jeff 想想，既然这样，那不如大家多找些各自的极客朋友来，把本来的“欢送 Party”改成“相识 Party”。

  

![](../Images/2c8a8f1d0f611e77784324959f0b3041.png)

  

  

没想到，这群素未谋面的极客盆友们在这场 Party 上交流各自破解游戏的心得，掏出自己做的小玩意儿，玩得敲开心。

  

Jeff 即兴赋诗一首：天下豪杰众，极客聚首难，网络一线牵，珍惜这段缘！

  

和这么多极客朋友在一起聊天，Jeff Moss 像融化在梦境里。他发下宏愿，每年都要把极客朋友们聚到拉斯维加斯，开一场热热闹闹的 Party。朋友们都以为他说着玩，万万没想到，Jeff Moss 就是这么耿直，说每年开 Party，就每年开 Party，一开就开了26年。

  

这个Party 名叫 DEF CON。

  

![](../Images/97a7395ed3eb76cdb0221f3c0b1d4694.png)

![](../Images/db071eca3fecd1526a2a9dc266749265.png)

![](../Images/8d6be946fd300a05b152cece2a144d83.png)

  

  

从第一年的十几个人，到2018年的第26次 DEF CON，参与人数已经达到了30000人。（这人数已经赶上了当年陕北会师的红军了。。。）当然，这么多人的吃喝玩乐，Jeff Moss 自己可掏不起钱了，于是现在的 DEF CON 需要参加者“众筹”，换句话说，其实就是买票入场。

  

  

  

**（三）**

  

  

二十多年了，DEF CON 一直稳居全世界极客们的“精神栖息地”之首。只不过，这片栖息地如今已经太大了，堪比国家公园自然保护区。

  

好几万人参加 DEF CON，他们自然没办法挤在一个屋子里。于是每年 Jeff 都会包下拉斯维加斯像城堡那么大的一整座酒店，分成演讲区、村落、工作坊、黑客大赛等等区域，让极客们随意在各个“分会场”里穿行。

  

由于名声太火，全世界心怀梦想的小白极客们纷纷来朝圣。鉴于大多数人“心气比天高，技术比纸薄”，所以各个区域几乎都采取了“先富带后富共奔富裕路”的极客奔小康模式。

  

比如，如果你进入电路板村落里，“村长”会塞给你一个电烙铁，手把手教你焊一个计算器、电路灯之类的小玩意儿带回家。

  

![](../Images/8d6be946fd300a05b152cece2a144d83.png)

  

  

比如，如果你进入开锁的村子，“村长”就会给你一把锁，然后教你怎么用两根棍捅开一把锁，包教包会包分配。

  

![](../Images/70f1f3ca81d8a72612b10ba7c4c9da97.png)

  

  

比如，如果你进入演讲区，上面可能站着一位大胡子极客，然后给你讲怎样破解一台 iPhone 或者远程让特斯拉汽车来个急刹车。

  

![](../Images/a699054179adeb834f741ab6da317323.png)

  

  

如果你特别小白，建议你不要踏足那一小块神秘的“黑客大赛区域”（当然你要去参观也没人拦着你），因为这个被称为 DEF CON CTF 的黑客大赛已经成为了国际上最著名的黑客赛事，能出现在 DEF CON CTF 决赛现场的，基本相当于世界杯八强的水平。这种水平的比赛，小白是插不上脚的。

  

![](../Images/43e16b42a356dee580f6d40d0fd1f1c6.png)

  

  

在 DEF CON，你可以提着酒瓶子参加各种聚会。想想好有道理，毕竟这是个 Party，不是学校，更不是公司，没有班级辅导员，也没有老板，大家都是江湖上的“同好用户”而已。

  

![](../Images/8e6202299fb61ee3babe7326d8ede2c8.png)

  

  

2016年，中哥曾经代表老东家雷锋网去 DEF CON 浪过一次。现在回想起来，DEF CON 让我反复回味的，就是它的“人味儿”。

> 人们笑容洋溢，几万人相互见面都会点头微笑。人们装束奇特，但没人觉得这有什么不妥。人们对各种手机电脑游戏机“搞破坏”，但大家都知道，这只是一群喜欢突破极限的极客而已，他们并无恶意。他们不想真的破坏这个世界，恰恰相反，从 DEF CON 走出去，很多人的日常工作就是用他们的技术保护这个世界。
> 
>   
> 
> 从 Jeff Moss 到几万参与者，没人想从 DEF CON 中捞钱，也没有极客A想从极客B身上盘剥什么。

  

当时看到这些场景，我莫名有些热泪盈眶。

  

我发现极客们的 DEF CON 和马杰的居酒屋、我的煎蛋网、朋友的抖音没有什么本质区别。就是喜欢，仅此而已。

  

![](../Images/d5944888979131bf1bfaf0e313fc8a25.png)

  

  

说到这里，世界终于要开始展现它强大的玄幻编剧能力了。

  

2018年春天，Jeff Moss 和马杰这两个有趣的人同时出现在北京老舍茶馆，似乎有神马大事要发生。果然，他们宣布了一个超屌的事实——在拉斯维加斯轮回了26年之后，百度安全把 DEF CON 引进了中国，北京。

  

![](../Images/8ee15d4658e63fedb13cbcfa6b46eb9a.png)

**马杰和 Jeff Moss**

  

  

没错，那些梳着朋克头，穿着鼻环，手握啤酒，穿着露脐装或挺着大肚腩，看上去有点虎但是内心却柔软善良的外国极客们，将会和带着黑框眼镜，身穿格子衫，头发像鸡窝一样的中国极客们共处一室三天三夜。

  

想想就让人鸡皮疙瘩掉一地。。。

  

中国的极客会喜欢这种美式 Party 吗？他们会和外国人一起焊冒烟的电路板，一起开锁，一起鼓捣无线电和汽车，一起听各种神奇的破解经历，一起硬核摇滚，一起喝酒吹牛X吗？？

  

上面这些来自灵魂的拷问，在2018年做策划的时候，美国老炮儿 Jeff 和中国老炮儿马杰都拿不准。Jeff 冥思苦想，搞出一个万全之策——要不干脆咱们把 Party 的名字叫做 DEF CON China Beta 版吧。这样即使中国极客不来捧场，咱俩也能“遮个羞脸”：我们做的是 Beta 版，失败也很正常嘛。（原来美国人也有中国老干部的思维嘛。。。）

  

![](../Images/5bbe939f512074a78c928ef3dffdb06b.png)

**看到了么，右上角这个就是万无一失的“Beta”。。。**

  

  

说干就干。接下来 Jeff 团队和马杰的百度安全团队就踏上了生不如死的筹备过程。

  

这个 Party 要在哪里搞呢？马杰第一眼就看中了 798 艺术区里的那个“大罐子”（官方名叫 751 D·Park），赶紧托人去问，这个地方太火爆了，人家的预定恨不得要排到年底了。。。

  

无奈，组委会只好选择了一家稍显朴实的酒店。毕竟是 Beta 版，糙一点儿大家也有个担待。

  

与此同时，Jeff 团队面向全球发布 DEF CON China 的主题演讲、村落和工作坊的征集令。本以为在陌生的中国搞 Party，那些外国极客不会那么积极，没想到全球的投稿像雪片一样塞到组委会的邮箱，各种题目五花八门，以至于 Jeff Moss 每天都发愁怎么礼貌友善不伤人家心地拒绝别人。

  

在中国开一场奇形怪状的 Party，难度有多大，你懂的。各种场地、物料、有关部门关系协调等等奇葩的事情层出不穷，我记得那两个月我在百度安全的朋友们差点没累吐了血。

  

终于，2018年5月，DEF CON China Beta 版如约召开。

**（四）**

  

  

一年很快过去了。

  

就在2019年4月，Jeff Moss 又不远万里来到了中国，他和马杰又把大伙儿神秘兮兮地叫到了一个小黑屋里，宣布了一个天了噜的消息：2019年，第二次 DEF CON China 终于历经磨难修成正果，从 Beta 版升级为 1.0！！！

  

还有个好消息，马杰去年就垂涎的 798 大罐儿，今年终于软磨硬泡东挪西凑如愿订到了。所以，2019年的 DEF CON China 1.0 将会在 751 D·Park 举行。（时间是20190531-20190602）

  

![](../Images/108d6bfd9e06f19510489f25df547d65.png)

**751 D Park 原来是北京煤气厂储存煤气用的大号煤气罐，现在成了最酷的集会场地。**

  

  

看着 Jeff Moss 和马杰认真的眼神，不知为何，我想到了小时候弹玻璃球，小朋友们为了争执一个球到底算不算进洞的那种笃定。

  

Jeff 说，这次 DEF CON China 的画风是酱的：

  

![](../Images/ab0cdf77de6b592373011f35d2f5eb0b.png)

  

这叫复古未来主义。大概就是上世纪七八十年代的艺术家们设想的未来生活。讲真，我对这种复古未来主义的艺术作品没有一点抵抗力。

  

![](../Images/9ca0e1e797e32bc14d0e9c694bc754f3.png)

![](../Images/2d61b67f145c5f8900bdee5a4dd8174d.png)

  

  

你看这个智能手表，居然要插软盘。。。

  

![](../Images/e431f029d1558e468d71b94688072c64.png)

  

  

没错，现在看来是有点不靠谱。但是谁又能说得准，就在另一个平行世界，鸭梨公司也许真的发明了一种插软盘的手表呢？世界越无聊，幻想才显得越有趣。

  

为了这个主题，Jeff 还认真地在 DEF CON 官网上开了个帖子，让大家投票，哪个才是极客心中最屌的复古未来主义画作。

  

![](../Images/90cca591edd1b769c45859e5e2056964.png)

![](../Images/bd0c7133bcfcfc8f02269dd9c7f2d4af.png)

![](../Images/36bf16cf3828c2f0236e3a4aa43bf8f1.png)![](../Images/eee2982da39444c9081814f3a7dcb123.png)

  

虽然 DEF CON 顺利地开到了中国，但马杰心里一直有遗憾：这么多有意思的极客和技术，慢慢的现代主义元素，唯独缺点中国风啊。

  

偶然间，他发现了一个专门用中国传统榫卯结构做拼搭积木的团队，惊呼这不就是中国的极客吗？他赶紧把团队邀请到了 DEF CON China，三天的时间里，这群人将会徒手不用一根钉子，纯粹用榫卯结构搭建起一座仿真的太和殿。

  

你可能会纳闷，说了半天，为啥都是艺术品，积木这些玩意儿呢？

  

Jeff 说，其实这是有意为之的。很多极客，并不知道自己是极客，他们只是对各种新鲜事充满好奇心，但他们也许还没有做好准备，勇敢地去探索。这世界上的好奇心和热爱其实是相通的，你也许先要试着来社区转一转看看积木或者艺术品，才会认识这个社区里面真正有趣的朋友。

  

我们在经历肉眼可见的变迁。

  

过去世界是个大广场，现在很多人已经钻进了各自的“小泡泡”，那些小泡泡就是不同的精神栖息地。而那些迟迟没有选定自己的栖息地，被留在广场上的人，变得越来越孤独。不论你是否愿意，事实就是如此。

  

每个人的精神栖息地都不同，我只是猜想浅友中也许会有人喜欢这场极客 Party，才连夜把 Jeff Moss 和马杰介绍给你。

  

![](../Images/d5523edd8dca04309ea5f034ed78ce32.png)

**Jeff Moss 和马杰，在2019**

  

  

如果你想验证一下自己是不是极客的一份子，欢迎你加入这两个老极客的大聚会——DEF CON China。（如果你因故没办法参加，还有个好消息，幺哥说届时他会在现场发回一手报道，到时候他要不写的话，你们找他去算账。他的微信是：xieyaopro）

  

  

  

**（五）**

  

  

有个不重要的小问题。

  

这些人把 DEF CON 这个美式的极客 Party 千辛万苦费力不讨好地带到中国，Jeff Moss 想要什么？马杰想要什么？百度安全又想要什么？

  

我没有问 Jeff，也没有问马杰，因为我知道，他们的第一反应一定是：“我们希望世界变得更美好”之类正确的废话。

  

但我敢肯定，他们都有私心。

  

Jeff 曾经骄傲地回忆他自己的十三岁：“我在还没到法定喝酒的年级，就和来自俄罗斯、加拿大以及墨西哥的朋友谈笑风生，这感觉超酷。”

  

我突然想到《小王子》，小王子为那朵玫瑰盖过玻璃罩，除过毛毛虫，从此对她有了爱与责任。小王子驯化了狐狸，这只狐狸对他来说便独一无二。

  

![](../Images/d2ea48256f043e8bab3a60777b0da7be.png)

  

  

在忙碌的大人们看来，那朵玫瑰和花园里的五千朵玫瑰没有区别，那只狐狸和森林里的走兽别无二致。但小王子确信，自己需要付出时光和生命，为对方做些什么。

  

2015年，百度收购马杰的创业公司安全宝，他和他的同学们浩浩荡荡从创新工场的加速器搬到了百度大厦。从那一刻，马杰生命的一部分，就已经和百度安全融为一体。

  

百度安全是个在瓜众心里存在感不强的部门，他们并不直接产生利润，主要工作其实是保卫百度赖以生存的人工智能环境和物联网生态。

  

所以，百度安全开发了很多开源的安全项目，也为各路社区贡献了很多代码。中哥在过去的节目里，也给浅友们介绍了许多。（比如：**[《MesaLock Linux：能用在黑匣子里的操作系统是什么样？》](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247488967&idx=1&sn=66705655cb215448f3121a7b1d09c189&chksm=fb0011decc7798c840d3bce7366e6aac8136df6a11f6cacd4a14b1201a2885202a9e4e9aea8d&scene=21#wechat_redirect)、[《一把锁的传奇——从 OpenSSL 到 MesaLink》](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247488361&idx=1&sn=ad79db1d06c231ebc9e39c1bf716e976&chksm=fb001770cc779e6642465c415edf553bb82bb5db23d0199b2b10ba25b539702c2ff827d89694&scene=21#wechat_redirect)****、**[**《AI 世界生存指南》**](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247490160&idx=1&sn=9605aba8aeac664d3e82c7ee3125b6ff&chksm=fb001e69cc77977f7f2e1b9cf3be3c0986f0ed77d425eabc0b8f699c54a7c3cb41dff6c4db99&scene=21#wechat_redirect)）

  

![](../Images/1de05cec700afb55b80f523f3db04f61.png)

**在同性社交网站 GitHub 上，致力于安全传输的开源项目 Mesalink 已经有1000多颗星了。**

  

  

虽然这些开源项目的美很难被普通人感受到，但他们却在坚定地改变着每台智能设备背后的安全状况。

  

百度需要安全，百度安全也需要极客们的帮助。（可以看中哥之前写的一篇文章[**《人工智能会被黑客攻击吗？我们该恐惧还是拥抱》**](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247486867&idx=1&sn=30f0f369268abfffb130141ea7df841d&chksm=fb00098acc77809c375c23e3edf9d09523630b18a381fd15d18faf0c5c0f3f11a367a3c4f628&scene=21#wechat_redirect)）

  

这恐怕就是他们的私心。

  

在创立安全宝不久，马杰自己也不宽裕的时候，曾经赞助中国第一支极客战队“蓝莲花”奔赴 DEF CON CTF，写下了中国极客在世界上浓重的历史。而在马杰进入百度之后，百度同样继续赞助蓝莲花战队。

  

战队的这些战士们，后来成为了中国网络安全明星创业公司长亭科技的核心人员，他们在用全球顶尖的算法和技术守卫我们的安全。（长亭科技的故事，可以看这篇：[**《福布斯榜上的90后黑客陈宇森：世界终会留给我一条逆袭的路》**](http://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247489269&idx=1&sn=4bd85f0a1f62336dfe982b69596e8fab&chksm=fb0012eccc779bfa8a13e140e1efbb741af89fae20687febdb53596cac4fa7d8e6cbc52ed930&scene=21#wechat_redirect) ）

  

小王子来到地球之前，曾经在一颗星球上遇到了商人。那个商人拥有无数颗星星，他忙着计算自己的星星，从来没有时间抬头。

  

在地球上，也有很多人把科技做成钓钩，乐此不疲地从浩瀚的海洋里把鱼群拉上船，商业即是如此，无可厚非。但偶尔科技也可以被做成一支玫瑰，在微凉的夜晚绽放微笑，让疲惫的夜行人驻足歇脚。

  

于是我猜，那些用心为自己和别人营建精神栖息地的人，他们是善良的，值得我们敬他们一杯。

  

我时常回想起曾经读到的一句话：

**我跋涉千里回到故乡，看到一片破败的荒原，但我依旧相信，有一天花会绽放，鸟会归来。**
