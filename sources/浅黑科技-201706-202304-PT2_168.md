# 我黑进全球最著名的黑客大会，拿到了一手信息。。。 | DEF CON 前戏速递

今天是周五，充满期待的一天。也是世界著名黑客大会 DEF CON China 的**第一天**。（如果还不知道 DEF CON 是什么，请参考：*[《世界黑客大会 DEF CON 来中国了，值得一去吗？》](https://mp.weixin.qq.com/s?__biz=MzU0NDEwMTc1MA==&mid=2247487821&idx=1&sn=0f5ff2e4f91c956dcb61470c9e6022ae&chksm=fb001554cc779c42f00d58d8ab039ae004fbee3e39b6b36417df51082080a3016e7132f5ca5e&scene=21#wechat_redirect)）*

  

**今天由「跑得比西方记者还快」**的谢幺第一时间给大家会场**前戏速递**：

  

  

  

**Let's Rock ！**

**\-----**

  

北京时间 ：6:30

北京望京昆泰酒店

  

你没有看错，为了带来一手现场速递，幺哥**五点多就出发****，**跨越了大半个北京城来到酒店。

  

6:32 ![](../Images/2cc2fbafb57d74916fa73e8dae11d0f3.png)

这是召开DF CON China 所在的昆泰酒店，楼太大，不用广角镜头还真装不下。

  

6:35

![](../Images/1a589adf3e7c94e3f351f6a1bb268961.png)

由于去的太早，现场安保人员和志愿者都还在集结，这也为我「黑」进会场直接创造了条件。

  

**此时的DEF CON 就像是一台连接网络，还没来得及安装安全软件、也没有打补丁的服务器。**

  

![](../Images/89c9ae59680dfd55e4488b183d6aa7aa.png)

会场摆了一辆红色轿车，看样子「汽车破解村落」（**Car Hacking Village**）的场子就直接在酒店外面，不知道这辆车会不会被拆掉……

  

6:38

![](../Images/16b15c33dd3f2f5c810c2252991bc1db.png)

会场的某个门口，保洁大妈正在做打扫，或许她并不知道两小时以后这里要迎来几千人。

  

6:40

![](../Images/9059388a446adab63e6c72bf7a7842d0.png)

负责签到和售票的工作人员还没完全到位，于是我直接顺着酒店电梯上到了会场所在的楼层。

  

  

6:42

![](../Images/a1d7e8200615adfcd2affdf31fd069a5.png)

  

一上楼，我看到了自动售卖机、拳击游戏和街机……

？？？

两个小哥蹲在地上美滋滋地打着拳皇97风云再起，他们应该是布置会场的工作人员。

  

![](../Images/56e56a7d49c3cef54f2b8c9a3a3293a1.png)

![](../Images/a0cfaa21b72a2f0374cb3fea637adbcd.png)

两个小哥打得太嗨了，以至于画面模糊。绝对不是我手抖/斜眼笑

  

6:47

![](../Images/ada43b45241dec3fffe27166d5e94f53.png)

![](../Images/312ca71c2da71a7e9cb00007d069d178.png)

两边的站台不知道是干啥的，问了一下打游戏的小哥，貌似是**黑客集市，会展示一些跟黑客、极客主题有关的小玩意。**

  

  

6:48

![](../Images/0db5614ddef0b29cf78920f6195770d9.png)

BCTF 分会场，一会儿这里要进行激烈的CTF黑客攻防比赛以及现场破解悬赏赛。

  

![](../Images/1be00e0f5b8e5df7ffa0504ad3d87a82.png)

桌面上摆着某品牌智能门锁，一旁写着「不服来挑战」，据说只要能现场破解它就能瓜分百万奖金。

  

![](../Images/ff6f7ede64c60739ad5c69534c647a80.png)

网友嘉年华，不知道是干嘛用的，不过听名字应该是供参会者把玩的。

  

  

![](../Images/d290f7a557af3b8dd84e3cc5fb60ee29.png)

CTF 现场服务器的硬盘风扇已经嗡嗡作响，让人不禁联想起起跑线前轰鸣着的赛车，一场大战一触即发。

  

6:52

![](../Images/156723bc3dff1cb085b1cd3bf0967fdd.png)

联合主办方百度安全的工作人员正在收拾展位。

下面我们去主会场看看:  

  

6:53

![](../Images/78214174f8e400bbacd0f6c39c48edba.png)

![](../Images/b3bbfd1283489b76011c587d7dc1f781.png)

主会场的视觉是**四个分别朝着不同方向的钥匙**，象征着破解。

和在拉斯维加斯的 DEF CON 一样，他们用**黑色**+**绿色**来营造出黑客&极客感。

  

6:55

![](../Images/ac94f000eef4a6d893b248b4b4f148ac.png)

主会场旁边是三个**「破解部落」**，分别是硬件极客、生物特征破解、和Chip Off Village (谁来帮我翻译一下），可以让参会者亲身体验黑客破解项目。

  

6:56

![](../Images/f0474becd4d6a049a6f6a05561ef770c.png)

为了让参与者更直观得感受，以及更深度的参与，连桌子都像是开三方会谈一样，估计是便于参会者讨论。

  

![](../Images/5aa3390cfa54c31e80b7599d9ca6ea89.png)

![](../Images/bb8590604bcc7d73f35b1c490383fbde.png)

地上齐刷刷摆放着破解用的工具，灯具低着头，仿佛在说：**大爷来玩儿啊~****/斜眼笑**

  

6:58

![](../Images/ea278e6db7298c83a2978e3c6deda794.png)

由于整个会场的节目比较多，所以会有路牌来引导参会者。

顺着路牌，我找到了更多「破解村落」（ Hacking Village ） 。  

  

![](../Images/60605080957edbd944648c8012613ca2.png)

![](../Images/674748a94753352dd67fbc9735026064.png)

有几个工作人员零零星星的在走动。

  

6:59

![](../Images/78482947a4d1ba43cad1c982bd5f4925.png)

**正当我拉开一扇门准备进去的时候，有人问我：你干嘛的？！**  

  

幸好机智的幺哥提前穿了一件之前在DEF CON 010 沙龙活动上蹭的纪念T恤，于是我淡定的告诉他：

  

额……我是这的演讲者的助理，提前来看看环境。

然后就很顺利的进来了……

  

![](../Images/d22aeb651492895eb8f8c66f5c566d16.png)

PS：这招叫做「社会工程学攻击」，人才是最致命的漏洞。

  

7:00

![](../Images/b9edabd1e92f42c583a23e0af4d05e0a.png)

成功进入「机械锁破解村落」（The Lock Village）

  

  

![](../Images/28eb11725d87fb2f42841e285e75101f.png)

桌上已经准备好纸笔，但是工具（演示锁和开锁工具）似乎还没运过来。

  

  

7:02

![](../Images/db18f0f94ebd27d6814b1570b1760fc9.png)

从Village会场出来，外面又多了一些东西：同声传译。

  

由于DEF CON 起源于美国拉斯维加斯，这是第一次来中国办会，会有很多外国演讲者和参会者慕名而来，所以同声传译机是必须的，尤其对于我们这种四六级水平的人。

  

  

7:03

![](../Images/073cf29bc2e1c21fa5fceb98acbc77bf.png)

![](../Images/9388fcc1941845659d40ce7a687185fc.png)  

在商业展区，我看到了很多熟悉的安全品牌。

  

![](../Images/6b092fff035eec9488cb61bdfd284215.png)  

工作人员正在准备展区的物料。

  

这样的展区可以说是非常酷了，锁链加网格，站在里面有种莫名的迷幻感。

  

![](../Images/c3d1365e2cc95a00c29e087ae5ed4b43.png)

展区一共有两个，我们去另一个看看：

  

7:10

![](../Images/eec56afb826b6ec9c912b513fabb5b5f.png)

昏暗的灯光下红蓝交织，象征着攻击和防御，线路结构又让人联想起电路板。

  

![](../Images/52a20f9d5d33a7082332e7d680a457ca.png)

![](../Images/f3cda5fce0c6e4d191c5b5070154b94e.png)

i 春秋的黑客密室活动

  

![](../Images/d3871d6285f7e16a8e93bbbeaf100695.png)

GeekPwn 极棒的全球顶级黑客招募令

  

![](../Images/ccfe722dc016676c0b0873afac267dd7.png)

BOX，貌似是一家区块链公司，他们参加了这次的破解悬赏活动，看样子链圈和币圈的朋友也很关注网络安全。

  

7:14

![](../Images/ea6e436d79388ee9b530fbe3446cd501.png)

楼下，工作人员已经扛着大箱小箱物料入场。

  

![](../Images/84d83c288b97d51c51adc7de7aee2718.png)

志愿者已经大量涌入，开始准备换装、分工。

。。。。。。

  

**我冥冥之中感觉自己就快要被撵出去了**……

  

![](../Images/d08dcc610e41f6329f4d10628fc92ab1.png)

果然，安保人员开始入场，会场开始清场……  

  

  

![](../Images/5527d087889625a673ae2570b08d9672.png)

  

为了保持幺哥的风度（不被保安架出来），我主动下楼了。

此时不到7点办，居然就已经有一些参会者在等着入场。

  

![](../Images/6e0ac11567cccdaf7ae48903fdaa099c.png)

  

工作人员正在吃早饭，一问之下了解到 7:30 才可以开始入场。

我和一个等着入场的**外国小哥**攀谈了一会儿，他说他来自土库曼斯坦，在中国留学，之前没参加过拉斯维加斯的DEF CON ，第一次给了DEF CON China。

  

撰文时，我又遇到一个穿着套头卫衣，背着大书包的Boy，于是我果断拦住了他。

  

  

我：你也是黑客吗？

Boy：对技术感兴趣所以过来看看。

我：你是专门买票过来的吗？

Boy：嗯，不然呢？

我：……（内心OS：对啊不然呢）……额那个……你会黑客技术吗？

Boy：会一点。

我：您今年贵庚？

Boy：13。

我：我能给你拍张照吗？

Boy：额……好吧！

  

![](../Images/12ee908f7f236a2ea3514a650897c31c.png)

  

  

拍完，他就扭头离去，深藏功与名，留我独自凌乱。

13岁,13岁的时候我在干嘛？

  

7:20

![](../Images/9632c14c449c071f7f50f6bf5c3d4925.png)

会场已经排起了队，人群人我看到一个外国姑娘抱着一个不到一岁的小Baby。

  

几小时后，

这里将会开启一场长达三天的黑客派对。

  

8:50

我听到有工作人员一阵惊呼，过去一问，发现有参会者把现场的一台机器给破解了。

  

![](../Images/faf939f9fce50590c600722cc3e76055.png)

  

不过……后来发现……貌似是酒店的机器惨遭误伤 ……/捂脸

  

![](../Images/5d58dfbaca5116f3068ea66c5c29bd70.png)  

  

  

**接下来的三天，DEF CON China 还会有怎样的精彩？**

**他们会把楼拆了吗？**
