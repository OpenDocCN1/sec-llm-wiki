**没听过 DEF CON 和 Blackhat ，就别说自己是**网络安全爱好者了。****

  

这俩黑客大会分别被称之为“黑客奥斯卡”和“黑客世界杯”。—— 网络安全爱好者没听过这两个会，相当于电影爱好者不知道奥斯卡奖，足球迷没看过世界杯。

  

来，跟我一起念：

  

> 不赖客·嗨特！ 
> 
> 呆夫·炕！

**DEF CON **只认现金。****

网上预订门票？不好意思没有。刷卡、刷脸一律不行。当然，支付宝和微信扫码支付也是不行的。

  

黑客精神的一个重要的气质就是平等、匿名。所以这个盛大的 Party 只接受一手交钱一手交货的现场购票，想要预约，网上购票或者想刷卡购票？请求一律会被组委会拒绝。

  

同时，刷脸也不行。DEF CON 从没有为政府官员、行业大咖或明星开过不收钱的先例。当年好莱坞巨星威尔·史密斯为了出演一个黑客而去 DEF CON 体验生活，组委会表示：对不起，请买票。

  

![](../Images/936060e2dbd2d6beba19075fca934fa4.png)

  

  

  

  

3

  

**DEF CON  和 Blackhat 是“亲兄弟”，而且 DEF CON “出生”更早。**

  

BlackHat 和 DEFCON 的创始人是同一个人——被媒体誉为“全球身价最高黑客” 的Jeff Moss 。（我能叫你一声姐夫吗？@Jeff ）

  

1993年，世界互联网初具雏形， Jeff Moss 就创建了 DEFCON。4年后他又创立了 BlackHat 。如今这两个会并列世界上最牛X的黑客聚会。

![](../Images/14e32efe7b83cb0cffe8db4968ae9191.png)

Jeff Moss 

  

不过，Jeff 明显更宠爱 DEF CON。因为 Blackhat  就被他以1400万美元的价格卖掉了。而 DEF CON 则在他手里举办至今。

  

问 Jeff 为啥卖掉 Blackhat，他曾在一次采访中弱弱透露：“感觉每天都要花很多精力来运营它，那种耗神，你应该明白……”。

  

或许……姐夫是想留出点时间陪姐姐。

## **除了屌屌的奇特画风，奇葩破解也是 DEF CON 的标志。**

黑客聚会，少不了破解。顶级黑客的聚会，怎么少得了各种奇葩的破解。

  

软件破解、硬件破解、电话破解、汽车破解、无人机破解、一切可以被破解的东西的破解。在往年的聚会中，黑客们曾经试着创造链接距离最长的 Wi-Fi；比赛在拉斯维加斯的烈日下谁能最快地把一杯啤酒变成冰啤。

  

![](../Images/3f221f18fe7531c6a3801f7d7dabcd0a.png)

  

另外，虽然画风有点夸张，但技术全都是实打实的。DEF CON 对议题质量的把控有口皆碑。

  

  

6

  

    

**关于 DEF CON 名字的由来，有个彩蛋就隐藏在你的手机里。**

  

很多人都不知道 DEFCON 的来历。在英语中“CON”一般代表了会议，但是“DEF”是什么鬼？

  

很多人百度之后，都会言之凿凿地告诉别人，DEFCON是防御戒备状态（Defense condition）的简称，它象征了一种黑客精神。但是 Jeff Moss 却会告诉你，你只猜对了一半。

  

拿出手机，打开虚拟拨号键盘（如果你还在用 Nokia 直板功能机，直接看按键也行）看一下“3”下面的英文字母。你会惊奇地发现，正是“DEF”。这代表了 DEF CON 开趴的第一年“1993”。

  

![](../Images/cc5702fd581f8b040583d81d1764b606.png)

**DEF CON 的灵感来自一次温暖却并不成功的告别**

  

1993年，18岁的 Jeff Moss 面对一次离别。他的一位黑客朋友因为爸爸工作调动 ，马上要离开美国了。“此去经年，山高水长，他日相见，不止何岁何年。”Jeff 决定为他的朋友举行一个盛大的告别 Party。

  

经过了很长时间的策划，一切安排妥当，然而事情发生了一点小变故：他的朋友提前离开了美国，杳无音信。

  

“独守空房”的 Jeff 决定，把自己其他的黑客朋友邀请过来，把这次“送别 Party”改成一个“相识 Party”，当时的 Jeff 估计不会预料到，24年后，这个 Party 俨然成为了全世界黑客的“圣地”。

![](../Images/948dceec88a3e61d5cb2c3ac2f130ed8.png)

## **DEFCON 上，黑客也被黑。**

老虎也有打盹的时候。2009年，有一部 ATM 机被放置在会议中心的赌场里，很多黑客都选择在这里取现金。殊不知这是一个钓鱼 ATM 机，无数黑客的信息就这样被盗取了。

  

看来黑客之间的互相伤害，也是毫不留情的。

  

![](../Images/f64f9720515110966ecb4ee0a0678659.png)

**DEF CON 今年要来中国了！**

打开 DEFCON 官网，你会发现了这么一张图上写着：“CH 神州 NA” ，很明显，他们要走出从美国拉斯维加斯，来到北京。

![](../Images/01ef9f18286b48da36816323780bf8e9.png)

  

**以往，DEF CON 只在美国拉斯维加斯举办，中国北京是这个世界第一黑客Party 出海的第一站。**

  

这次 DEF CON 是由百度安全引进的，计划在2018年5月份正式举办，算是中外极客交流合作模式的一次探索和尝试。  

  

为什么是和百度联合举办？

  

**Jeff Moss 在签约发布会上聊起一段往事：**  

  

两年前，他在一次黑客会议上遇到马杰（百度安全的老大），彼时百度安全赞助了两支安全战队。

  

比赛时，他们在一个咖啡厅聊起网络安全技术和极客文化，第一次见面就聊了两个多小时。当时他们就开始思考 DEF CON 跟百度能否尝试一些合作。两年后，Jeff 决定让 DEF CON 走出拉斯维加斯，第一站就选在中国。

  

Jeff 说：

  

> DEFCON 强调对前沿科技和边界的探索精神；百度则崇尚开源共享、追求极致的理念」双方的一些精神内核不谋而合，所以，**DEFCON 和百度联合办会一点也不奇怪。**

  

百度安全专门把这次签约发布会的地点挑在北京前门的老舍茶馆。我在门里门外走了几圈，一股浓浓的中国风扑面而来。

![](../Images/f22cae132cc5457df49d3337517e9ce9.png)

![](../Images/4c193f05d17118f97b6cdc93ae5d9140.png)

  

所以，【百度安全 × DEF CON 】，他们会让黑客精神和中国风碰出怎样的火花？

5月，拭目以待！
