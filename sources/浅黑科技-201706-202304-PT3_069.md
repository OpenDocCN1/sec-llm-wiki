# 黄健翔为什么会主持“黑客秀”？

**黄健翔主持了中国最大的黑客秀“极棒”。**

**这让我嗅到了一种别样的气息。**

  

![](../Images/185a242e8d81fe7bce37ec8a229cb602.png)

  

**黄健翔为什么会主持“极棒”黑客秀？**

  

**文 | 史中**

  

很多人对黑客的了解几乎为零。

  

十一回家，各路叔叔阿姨拉着我阐释他们的赚钱心法。他们对赚钱和花钱的深刻理解让我惊为天人，敬佩有加。但我说到我在写一些黑客文章的时候。他们马上眉头紧锁，如临大敌，苦口婆心劝我“从良”。

  

劝我的这些人，大抵都年老。

  

我曾经写过一篇文章，讲了百度安全的黑客“小灰灰”是如何破解 ofo 单车的。文末有人留言说：ofo 花一块钱骑一个月，你们还要破解真是闲得蛋疼；还有人说：脏话我就不多说了，ofo 人红是非多，（你们）连机器都不放过。

  

留言的这些人，大多都年轻。

  

于是我仔细思考，为什么在对待“黑客”的态度上，年轻人和老年人达成了难得的共识？

  

类似的误读还有很多。

  

> 1986年，崔健在北京工体第一次喊出了一无所有，但之后漫长的时间里，摇滚被视为反叛、危险和异类。
> 
>   
> 
> 2006年，黄健翔喊出“伟大的意大利的左后卫”的时候，他身上也突然多了一个标签——反叛。

  

在我眼里，他们虽然不是黑客，但身上都具有黑客精神。

  

所以黄健翔主持黑客秀，似乎很合适。

  

**![](../Images/25194f1ab6a430410c407055c20f057f.png)**

  

为了给这种黑客精神正名，我更愿意把它形容为：拥有为世界寻找伤口的冲动。

  

**1、黄健翔，极棒和王琦 **

  

和黄健翔握手的这个人是王琦，“极棒”黑客秀的创始人。

  

![](../Images/22d36d2fdd5895a61b1a15d66dda6e55.png)

  

平时如果我有机会给圈外的朋友介绍一个黑客，我一般会选择他。

  

王琦曾经作为网络安全专家出现在 3·15 晚会上。出现在 3·15 晚会上的人，应该不是坏蛋，这让我省掉很多口舌。

  

![](../Images/b5eabfc4aec4b2af65c6ac6d6c56dc35.png)

王琦是中国比较早的一批黑客。

  

他原来是微软中国的安全专家，然后创业拉起了自己的队伍，名字叫做 KEEN。创业的初衷大概是用团队的黑客技术保卫网络安全，当然顺便赚大钱（鉴于人们对黑客的误解，他们更习惯于自称白帽黑客）。但是情况不太尽如人意，从大背景上来说，那个时候连很多企业都觉得安全是个可有可无的事情，遑论个人。

  

王琦经历了中国黑客最暗淡的岁月，用他的话来说，**很多黑客都悲剧地“死于丈母娘”。**

  

> 在你刚刚热爱技术的时候，你邋里邋遢，不仅不修边幅而且赚不来钱，说话不漂亮，还没有任何的荣誉和回报。就算好不容易找到了喜欢的姑娘，也会被丈母娘的“房”和“车”逼死。

  

他讲过一些身边黑客的故事：

  

> 1998年，中国有一位天才黑客，他曾经黑掉了摩托罗拉的大哥大。这在当时的世界范围内都算是创举，但是他的成果无人问津，从那之后，再也没有人能找到他。
> 
>   
> 
> 那时还有一位黑客，在上海证券公司工作。他在 CIH 病毒爆发的第二天，就完整地逆向出了病毒的代码。不仅如此，当时的他以一己之力，可以把 Windows 系统全部逆向出来。就是这样个牛人，仍在证券公司朝九晚五。

  

这些人，被王琦称为**“走散的”黑客。**

  

每次提到这些往事，他都沉默很久，一字一顿。他不明白到底是谁规定了人们对黑客的评价标准，给他们压上了难以承受的条条框框。

  

终于，他决定换一种方式和公众对话。

  

> *   2014年，KEEN 走出中国，去加拿大参加世界顶级破解大赛 Pwn2Own，拿到了非常棒的成绩。很有趣，在国外大赛取得成绩，反而让他们在国内声名鹊起。
>     
>       
>     
> *   同一年，KEEN 举办了第一届“极棒”黑客破解秀，一口气破解了70部手机。普通人第一次感觉到原来每天握在手上的设备竟然这么不安全。而那些被丈母娘看不起的“屌丝”黑客，也第一次在新闻里电视上“耀武扬威”。
>     
>       
>     
> *   2016年，王琦登上央视 3·15 晚会，面对亿万观众黑掉大疆无人机，并且讲述硬件设备和互联网的安全漏洞。
>     
> *   2017年，央视新闻调查用《我是黑客》的题目大篇幅报道了极棒和与之相关的黑客们。
>     
> 
>   
> 
> *   就在 KEEN 平地惊雷的 2014 年，互联网巨头腾讯注意到了他们。这才引出后来腾讯投资 KEEN，同时建立顶级安全研究团队“科恩实验室”。
>     

  

![](../Images/429cabd5b5c0315bcb1c3f3dbbb6f5b4.png)

  

“3·15”、”秀“、”腾讯“，这些字眼对于大众来说没有认知门槛。短短两三年，所有的事情“都对了”。

  

**”要用正确的方式让普通人感受到网络安全的重要和黑客的良善“**，可能是王琦最大的感悟。

  

这样看来，一切都顺理成章：邀请黄健翔做第四届极棒的主持人，正是因为他有能力和公众能更好地对话。**“黄健翔”三个字足以说明：喜爱网络安全的极客并不是怪兽，他们更像一个运动员，就像足球运动员、拳击手一样。**

![](../Images/bf04f4e8ee5c43e7447095030a9943a2.png)

***极棒 2017 现场***

  

**2、黄健翔，“鹅厂”和网络安全 **

  

这次极棒上，黑客们用一个二维码就盗走了 iPhone8 中的相片，他们破解了手机人脸识别、声纹识别，他们用机械臂抓着毛笔伪造了人的签名，甚至用人工智能合成了以假乱真的黄健翔的声音。

  

借助“解说一哥”的人气，网络安全这种冷门的技术刷爆了社交媒体。

  

但不知道你注意到没有，我之前提到了腾讯投资 KEEN。这绝不是一笔带过。极棒作为一个小众的黑客秀，投入很大却并没有很强的盈利能力。所以，它需要某个甘愿长期付出不求短期回报的主体来支持。它的成功从某种程度上说，有赖于腾讯的庇佑。

  

所以，从商业角度来推测，极棒黑客秀一定对腾讯有好处。

  

你可能会问，“鹅厂”和黑客有什么渊源吗？

  

太有了。这里把“黑客”代换成“网络安全”，你就更容易理解了。**黄健翔所能触达的大众认知，同样是腾讯安全所需要的。**

  

![](../Images/8c3ed0c184d4356b8139a1c761fcc868.png)

  

**1）腾讯安全需要公众认知**

  

2010年，腾讯把“电脑管家”像钉子一样插入用户的认知，打了 360 一个措手不及，这才引出后来的 3Q 大战。从这一刻开始，腾讯就没有在网络安全领域“松口”。

  

2015年，腾讯陆续建立了“七大安全实验室”，在反诈骗、移动安全、反病毒、漏洞研究等等方面死磕 以 360 为首的一众竞争对手，其中就包括以 KEEN 诸多大牛为班底的科恩实验室。马化腾也在很多场合“爆料”，腾讯在安全上的投入，每年达到几十亿。

  

腾讯这样投入安全的理由很简单：

  

作为一个动辄就圈住十亿用户的互联网巨头，腾讯产品几乎要服务所有中国人。可以这么说：**用户可以不在乎安全，甚至完全不考虑安全；但是在腾讯的角度，它不仅要考虑安全，而且要保证万无一失。**十亿用户如果发生了信息泄露或者黑客袭击，连社会的基础都可能被动摇。

  

所以，腾讯实际上有巨大的动力，把自己对于安全的态度传递给普通人。极棒就是最好的出口之一。

  

事实上，每年腾讯都会为极棒不遗余力地做背书，把自家顶尖的网络安全研究员 TK、袁哥都贡献出来做评委；腾讯还利用自己的 IP 和媒体资源大力推广极棒破解秀。

  

实际上，这次极棒全程通过七家直播平台对外直播。利用黄健翔的 IP，通过极棒让普通人感受到“腾讯安全”的存在，对鹅厂来说是一件非常划算的事情。

  

![](../Images/f4ccbee70a60f371b551710a79d0ca50.png)

***黄健翔和挑战人脸识别破解的女黑客 Tyy***  

  

**2）腾讯安全需要人才**

  

在互联网巨头里，腾讯是最早注意到网络安全重要性的。

  

作为巨头，它比其他公司更早感受到网络安全在未来生活中会处于怎样的地位（这也是腾讯投资 KEEN 的原因）。所以从现在开始就要一刻不停地为未来储备黑客人才。

  

所以，招揽人才也是极棒的目标之一。

  

专家说，中国网络安全人才缺口大概是100万左右。因为之前说到的文化原因，很多研究网络安全的年轻人被家人视为不务正业。但实际上，未来我们的网络安全，都要仰仗他们。

  

通过黄健翔主持的极棒黑客秀，没准会让看台上或屏幕那头的观众爱上这门技术。他们也许因此想要加入 KEEN，或者立志进入科恩实验室。这对腾讯来说，才是真正沉甸甸的财富。

  

今年的极棒，依然和往年一样燃。我突然觉得很欣慰：无论被多少人误解，那些黑客依然全心投入，腾讯和 KEEN 依然在不遗余力地给他们舞台。这可能就足够了。

  

我想起来了，十一劝我“从良”的一位叔叔，恰好是黄健翔的粉丝。我很期待黄健翔主持的极棒能够告诉他，我们黑客所做的事情，是多么伟大、光荣和正确。

  

至此，我明白：极棒邀请黄健翔，不是一种消费，而是相互成全。就像黄健翔曾经说的：

  

> **他不是一个人在战斗！**
