# 十一长假结束真恐怖，然而更恐怖的是这部“黑剧”

![](../Images/d8244c1a0bfa7709d5f572f7ca76648e.png)

你有没有想过，当键盘侠惹恼一个黑客时会发生什么？

英剧《黑镜》作为披着科技外衣，旨在对人性进行探讨的“黑剧”，以细思极恐和反转的结局被人所熟知。

![](../Images/1a42937dd6adefe8c1fff0b5965222a2.png)

铁柱前两天追完了整个第三季，其中印象最深的第六集是一个**黑客屠杀键盘侠**的故事，看完后让铁柱陷入了沉思……

![](../Images/a1061788fd694429c9e509b3797a160f.png)

▲ 全网公敌

***注意：本文涉及严重剧透，想看整个第三季的老铁在后台回复关键词「黑剧」自取资源……***

未来世界，气候改变使许多动植物灭绝，其中包括蜜蜂。然而科技在进步，人类发明出了可自主行动的智能蜜蜂机器人传播花粉。

![](../Images/8298fe571cdbab026cf2d136538f3a4d.png)

翠花是一个毒舌的专栏作家，由于写了一篇抨击“轮椅烈士”的文章受到了网友的口诛笔伐。

有街上路人热情的问候：

![](../Images/b48173cc06e6614be57f22ded70634c5.png)

有的在社交软件下“亲切”留言：

![](../Images/73cc27ac472e2d6a99caa78d729227c8.png)

甚至还有狂热一些的“粉丝”为她送去了好吃的蛋糕……

![](../Images/03e0f86caa20f233954c89b73cbe4381.png)

但是让所有厌恶她的人没有预料到的是：**翠花是个乐观的好作家。**

**面对骂街，她微笑面对；面对美食，她选择享受。**

然后，她把自己喉咙割了……

![](../Images/cce23b8b7cf4f4a04600f91c96954e6e.png)

女警官阿冷与跟班招弟开始着手调查女作家的死，找到了送蛋糕的小学老师。

![](../Images/53afbfec78ae356d00c77a73847c57d6.png)

老师表示，蛋糕是跟网友一起众筹买的，同时社交软件下的诅咒留言只是个玩笑。

![](../Images/efd178931702263eceed80307de49d4a.png)

黑哥是一个艺人，由于在某节目中公开喷了一个小朋友同样遭到了网友的口诛笔伐，不久后也倒下了。

![](../Images/11e203a004f48e4f5399bdd56ea5e21f.png)

医生在给他做核磁共振的时候不小心从他脑袋里吸出来一只机械蜂，虽然此时黑哥才算真正凉透，不过大家也终于搞明白原来是机械蜜蜂在杀人。

![](../Images/38e7a53198302405ce13dd4670414cc2.png)

阿冷与跟班招弟继续追寻真相。功夫不负有心人，招弟运用其高超的电脑技巧发现，原来前面死的两位是被网友“喷”死的。

网上出现了一个名叫后果游戏的投票游戏：**任何网民极度讨厌某人时，只需要在该人的社交网站留言中打上 #「去死」 的标签，机械蜂会在每日下午5点除掉得票最多的人……**

![](../Images/3d826ba1636af9bdf54cc1a121415125.png)

**原来机械蜂是通过人脸识别确定目标，****作家翠花和艺人黑哥显然都是当日的榜首才会被机械蜂钻进脑袋**，真相似乎就在眼前……

阿冷与招弟怀疑有黑客黑进了机械蜂的系统，于是跑到制造机械蜂的公司进行询问，没想到技术打脸男告诉她们：我们的系统最安全，谁都不可能黑进来。

![](../Images/3f4af7f8d98780dabaf7b0c60aacccca.png)

然后系统就被黑了……

![](../Images/275e52e6b8eee0d3cf0e82dc45cd8a72.png)

此时的榜首是一个对英雄纪念碑作不敬的尿急女，阿冷和招弟与上面派下来的莽汉男想要阻止尿急女遇害，然而遮天蔽日的蜂群却告诉她们一切都是徒劳，第三位遇害者诞生。

![](../Images/1cd53136b17c88a287e23c645f34b154.png)

看到这里，铁柱不禁想到，既然是人脸识别，为什么不给受害人头上套个丝袜？莫非未来丝袜很贵？

![](../Images/a530c55c991b14d5a9abf72d287d1a05.png)

▲ 这人脸识别还能认出来？

第四位上榜的是腐国财政大臣。

![](../Images/e83a52d91e51a87b528eb42ebeb579bf.png)

**他感到十分委屈：连排第四位的都是个恋童癖，为啥我排第一啊？**

![](../Images/df4153c28b652ca0bf4e20cee84abd29.png)

然而莽汉男对BOSS表示：大哥你放心，你很安全，不会有事儿的，我们用炸弹把机械蜂的老巢炸掉就稳了……

然后……

![](../Images/104d8319b7a55134f6d03e4dd89a9b75.png)

▲ 财政大臣：“我有句MMP不知当讲不当讲”

于此同时，阿冷和招弟通过一张照片的位置信息终于知晓了控制机械蜂杀人的幕后黑客：机械蜂公司前员工黑无敌。

![](../Images/267fa470273dcefacc265ebd00eb6f3a.png)

并得到了控制机械蜂的工具包，同时她们还发现那些文件中有着所有参与后果游戏的人员名单。

**此时阿冷隐约意识到这一切也许只是一个圈套，黑无敌一开始的目标就是键盘侠们。**

**然而急于拯救财政大臣的莽汉男却十分果断，毅然决然的按下了控制键。**

![](../Images/a5539d317a500ab25f513fb33cb765da.png)

于是，键盘侠们的末日来临了，所有参加过后果游戏的人都将受到审判……

![](../Images/78bd585ebeb60efd3206601775e66ab4.png)

![](../Images/1e9553348679a0d988ce578f7644c5cf.png)

![](../Images/6cf61e175717ac04b9f6da46662ca557.png)

![](../Images/867f65ca0499ceffcbd8c55014413fc6.png)

最后影片结尾也没有抓到幕后黑手黑无敌，只是留给了观众自由想象的空间，全片结束。

**\---**

**当道德审判变成集体行为时，往往伴随着盲目，人们会用自己认为正确的道德观批判他人，而在网络上声讨却是一种看似不用负责的有效手段。**

片中为别人打上 **#去死 **标签的人被询问在网上的言行是否当真时，他们都会回答：**这只是个玩笑。**

![](../Images/896802d3c321c7d2b380bdda5ba649f6.png)

**然而正是因为这种看似无形的施暴手段却可以对当事人造成实打实的伤害。**

然而铁柱认为这部剧真正恐怖的地方并不在于黑客的强大力量，甚至也不在于失控的杀人智能蜂。

而是**当你看到大批键盘侠们被杀死，并终于为自己言行承担生命的后果时，也许同样会产生大快人心的感觉。**

这何尝不是站在自己的道德制高点上对键盘侠进行审判？我们真的可以保证自己不会成为片中键盘侠中的一员吗？

也许隐藏在网络后的人性才是真正需要反思的……
