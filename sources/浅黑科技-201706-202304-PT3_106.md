# 我来科普一下，腾讯的“TUSI”是什么？

**密码的最高形态是什么？  
**

**那就是没有密码！！**

  

别着急退出文章，这句话看上去有点扯的话，其实蕴含了一个**真理**。

  

我给你举几个例子体会一下：

  

> 你和女票交流的最高虐狗境界是什么？是“你不用说，我懂。”
> 
>   
> 
> 你在饭店点菜的最高境界是什么？是一努嘴伙计就知道老主顾你一荤三素多放蒜少放盐。
> 
>   
> 
> 街头打架的最高境界是什么？是一个眼神，对方已经落荒而逃。

  

没错，这些经验告诉我们的真理就是：

  

**在所有需要人与人之间交换信息（也就是交流）的场合，达到同样效果的情况下，所需要占用的精力越少，这次交流就越成功。**

  

这是个朴素的道理，但却可以推导出一系列非常有趣的事情。

  

今天我们就来聊聊。

  

  

**为什么实体密码是未来？**

  

我们先来做一个思想实验：

  

> 每个人的财富各有不同，相差悬殊，但是每个人的注意力和时间却是平等的。每次交流所需要的精力越少，就留给人越多的时间去做下一件事。如果你每一次交流都比别人节省了时间，那么你就相当于获得了额外的生命。

  

![](../Images/bfd9874c3c40f318f096eb333b2b05d6.png)

  

额外的生命，还有另一个名字，叫做“自由”。

  

你可能没有想过，所有的科技进步方向，本质上都是让人更自由。

  

> 高铁大大节省了你从北京到上海的时间，所以你获得了额外的时间，获得了自由。
> 
>   
> 
> 计算机大大节省了你计算卷帙浩繁的数据的事件，所以你获得了额外的时间，获得了自由。
> 
>   
> 
> 电商大大节省了你逛商场挑选衣服的事件，所以你获得了额外的时间，获得了自由。

  

说到这里，终于要开始涉及今天的主题。

  

![](../Images/35efa9b1729bcd0bbfc89862a6ed8c70.png)

  

如果能够把你登录某个网站、使用某个服务时输入密码的时间大幅缩减，那么这会是一个不错的生意。

  

一个实体的“硬件密码”就是一种方法。

  

其实，这种“硬件密码”我们都见过，比如我们网银转账时用过的U盾。不过，没人觉得那个东西节省时间。这是因为，早期U盾的认证，是需要用USB插口进行物理连接，并且还要用密码进行二次验证。所以耗费了更多时间。

  

但是，物联网技术发展了这么多年，这件事情开始变得可能了。

  

  

**一把万能钥匙会是什么样？**

  

想象一把这样的钥匙：

  

![](../Images/17bf38e845329cf8a919c0d94f78e8c1.png)

  

> 你只需要把它装在兜里，它就可以通过无线信号，自动和周围的一切智能硬件建立联系。
> 
>   
> 
> 当你走到家门口，钥匙就和智能门锁建立了连接，瞬间认证了你的身份，锁簧弹开，你只需要轻轻一转门把手，就可以进去。
> 
>   
> 
> 当你回到家里，智能照明系统和智能音响系统又和你的钥匙建立了连接，于是灯光马上变成了你之前设定好的颜色，背景音乐响起，正是你昨天选好的歌曲。
> 
>   
> 
> 当你走上公交车，这把钥匙和刷卡系统建立连接，直接从你的账户里扣除车票。
> 
>   
> 
> 当你走进餐厅，这把钥匙和管理系统建立连接，自动把你喜欢的菜肴列出来供你选择。
> 
>   
> 
> 当你住进宾馆，这把钥匙自动和酒店系统连接，走进来一个漂亮的妹子，说，你做梦呢吧。。。

  

![](../Images/60a9388e930b59d2449cbe2a2c4d863a.png)

  

没错，这就是在物联网技术加持下的“万能钥匙”能给你带来的帝王般的感觉。

现在该醒醒了，现实是这样的：门锁、灯光、音响、餐厅、宾馆、公交车上的物联网身份认证协议，并没有一个全国统一的标准。

  

![](../Images/ef13813cf2539df44cc25d4c140845da.png)

  

这就好像，门锁会说汉语，灯光只能说日语，而餐厅系统又只能说鸟语。。。

  

所以，即便你的住宅和城市的公共设施都是智能的，但由于他们之间不互相理解，所以你需要针对每一个设施都带一个“钥匙”，这就和我们的钥匙串一样。

  

而你每天要经过无数扇门，去无数个地方，做无数件事，这个世界越智能，你要随身携带的钥匙越多，到最后你身上很可能要携带好几百个钥匙。

  

![](../Images/c0e93f0a8db4b784c8c0a0a639c73729.png)

  

这简直是坑爹。

  

  

**有人想试试解决这个问题**

  

如果能把所有的钥匙压缩成一把，那么刚才我想象的“天上人间”就能实现。

  

很多人都在朝思暮想解决这个问题。不过因为统一众多硬件传输标准的事情非常复杂， 还没有人做出一统天下的成果。在不同领域比较有名的是：FIDO、IFAA、EID等。

  

最近，一个来自南方的小公司也跃跃欲试，这就是腾讯。

  

![](../Images/1968c7c9a23756a9304ab0558d009ed2.png)

  

他们打算在哪里解决呢？在无锡。

  

这两天，腾讯和无锡市政府就联合成立了一个叫做“TUSI”的联合实验室，这个实验室就要推广一个名为“TUSI”的物联网安全标准。

  

![](../Images/f1ef986a4021bcb5051257755c2a2919.png)

  

其实，这件事腾讯想做，我们很容易理解。而且它早就应该做。

  

为什么呢？

  

“密码”从根本上来说，就是对身份的认证。所以，只要一家公司掌握的资源，有助于认证你的身份，就更容易把这件事情做成。所以如果说优势，腾讯应该有四个：

  

1、腾讯手里有一个得天独厚资源，就是QQ、微信，将近10亿人的登录认证信息。

  

![](../Images/ac41f56f264d1eed6ce060115181c79f.png)

  

估计每个人用手机的时候，都经历过这样的场景：一个新的 App，提示你可以用微信号登录，你点击一下，就跳转到微信自动认证，整个过程很块。

  

如果腾讯可以把庞大的基础用户导入方便的硬件里，用户会觉得很自然。这样，其他硬件厂商自然愿意加入“TUSI”生态。

  

2、腾讯有个智能硬件开放平台。

  

![](../Images/651713dfa6bfd4f4b2e46e230367b4f7.png)

  

在最近两年，腾讯开发了一些列物联网平台，包括QQ物联智能硬件开放平台和微信物联，这些平台可以快速把一个普通硬件开发成物联网硬件。接下来也可以顺理成章地导入“TUSI”身份认证联盟。

  

3、腾讯有腾讯云。

![](../Images/82e14528f3587e82a36429ea4b95949c.png)

  

腾讯云在中国的市场份额位居第二，今年开始，腾讯云主打“AI”这个概念。在早些时候，腾讯云刚刚发布了一个叫“小微”的平台，就是帮智能硬件附加人工智能的平台。这个平台也可以把合作伙伴导入“TUSI”身份认证联盟。

  

4、腾讯有一个叫Qkey的东西。

  

![](../Images/8f4cbf5895b330234367e7620c29e55f.png)

  

这是一个腾讯自己开发的身份认证手环，可以成为我们刚才一直说的“万能钥匙”的实体。

  

  

**腾讯的“万能钥匙”还用到区块链技术**

  

当然，成立联盟，制定标准，输出技术，只是腾讯的美好希望，面对阿里巴巴等等强大的对手，他们还是想把功课做足。

  

他们找到一个让“TUSI”更加独特的亮点——区块链技术。

  

那么，区块链技术怎么用在身份认证中呢？

  

TUSI 只是众多安全支付联盟里的一个有力竞争者，离一统天下还远，甚至可能永远没办法一统天下。所以，和其他联盟合作的胸怀，就非常必要了。

  

腾讯无线安全产品部副总经理申子熹说，区块链技术，一个主要的应用场景就是在和其他联盟的合作中。

  

> 如果你有一个手环、一块手表、一张蓝牙卡、还有自己的指纹认证等等生物技术，这些分别属于不同的硬件厂商，你分别注册了五家服务，五家分别提供认证功能。那么怎么把它们整合在一起呢？
> 
>   
> 
> 当然，厂商之间交换用户信息是最直接的办法。但是用户信息是厂家的核心资产，不太可能直接交换。所以联盟区块链的技术就能把用户信息脱敏之后放在区块链上，任何一个厂商需要的时候，只要从链上读取表单信息，就可以进行鉴权。

  

这个区块链的安全技术，主要是和 Intel 合作的。听起来还蛮靠谱的。

  

![](../Images/c2f925b9d44f87ca27394197b07eddd9.png)

  

实体密码，万能钥匙，这些酷炫的想象，正在太湖旁的无锡变成现实。根据无锡市政府领导的介绍，腾讯会逐渐和无锡中小企业、市政工程合作，推出例如虚拟就诊卡、智能校园卡等类似的身份认证硬件，如果效果不错，这些硬件就会在联盟里进一步整合，没准以后无锡的童鞋，只要带一个手环出门，就可以上山下海、求学看病了。

  

这件事情还是挺酷的。
