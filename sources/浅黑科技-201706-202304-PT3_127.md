**Let's Rock !**

  

先来举个例子，五月天的《知足》，在QQ音乐和网易云音乐都是没有版权的。

![](../Images/3355a0184e6229481baa2240531ed966.png)

![](../Images/78b7de931840efa302498f813126f55e.png)

  

现在来看看在 Listen 1 里搜索这首歌，它的表现如何？

  

![](../Images/faa63d070a96a666e77f0bf66a67fe71.png)

细心的浅友可能已经看出来了**，这个播放器能在同一个搜索界面用标签页的形式一键切换网易、虾米、QQ音乐三家的音乐源。**

也就是说，只要这三家的任何一家有你要听的歌的版权，你都能在 Listen1 里直接听。

同时，你还可以为自己添加一些歌单，可以把分布在三个平台的歌曲放在同一个歌单里，无缝收听。

![](../Images/ea69b5eda94136eaa66f292bcafba388.png)

同时，Listen1还继承了三个音乐软件里的精选歌单，可以随意切换三个软件里的推荐歌单。

![](../Images/d07cc899ed3dfb8b88e521498b90cf67.png)

Listen 1 的功能大概就是这些了，如果你觉得对你有用就可以直接去下载试用了，免费的。

不过，如果你还有些好奇它是如何做到“三合一”的，直接绕过音乐版权限制的，那就不妨继续看下去。

事情是这样的。

从前有一个不停音乐就写不出代码的程序员，他也遇到了同样的问题，需要下载很多音乐软件，他觉得特烦。

但是没什么事能难道一个程序员的。

他发现这几个音乐软件都有网页版，于是他经常开着三个网页来听音乐。

![](../Images/efada4f5d06d6ba1405c1cf05d29dcc2.png)

后来他就想：既然开三个网页就能解决问题，为什么不能直接写个程序，把三个网页播放器的API接口接到同一个网页里，然后做一个统一的歌单呢？

于是 Listen 1 的想法雏形就出来了，他在代码托管网站 Github 上创建了一个开源项目，开始进行开发，结果得到了不少程序员的支持，一起来完善和优化这个项目。

一开始 Listen 1 只是一个网页，但经过开发者们一年多的努力，如今不仅支持各种浏览器插件，直接在浏览器里就能启动。

  

![](../Images/92ee5975998b715d8ee55a25d62e55f4.png)

  

后来，他们还开发了各个系统的桌面版。

![](../Images/5a7b3d671155a0fcff63750f15de7c79.png)

  

那么这个软件涉及侵犯音乐版权吗？

  

我认为没有。

  

从原理上来看，Listen 1 只是调用了三个音乐程序的 API 接口，相当于把三个程序简化之后塞进了一个程序里，替代了用户原本手动三个程序（网页）的动作。

  

本质上，用户还是同时用了三个音乐平台的服务，但是不需要安装多个软件了。

  

所以应该不存在什么“被封杀”的危险，它的首页也表示细化大家推荐给身边喜欢音乐的朋友

  

![](../Images/01c38672d12f3cb38f60223f197036f8.png)

  

最关键的，这个程序是开源的，如果你身边也有对这个项目感兴趣的程序员朋友，不妨一起加入进来让它变得更好用~
