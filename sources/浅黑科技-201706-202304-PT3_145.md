**4**

  

**在作案手法上，这次的 **Petya 确实独树一帜了**。![](../Images/136ad61f9b01d5603c6d4e04ff965997.png)**

  

传统的勒索软件作案手法是直接逐个加密你的文件，Petya 不逐个加密单个文件，而是加密磁盘的MFT，并且破坏MBR，使得用户无法进入系统。

  

MFT是啥？MBR是啥？

  

注意，幺哥要**正经地讲知识点了。**。

  

**MBR** 全称是 Main Boot Record（主引导记录）是位于磁盘最前边的一段引导（Loader）代码，电脑读取磁盘会先读取那一段。你可以理解为**在村口玩耍，兼职带路的小屁孩。**（据说上了年纪的都会脑补出放牛的王二小）

**MFT** 全称是 Main File Table （主文件表），大概包含文件大小、时间、位置等等数据。你可以简单理解为**村里的地图****。**

坏蛋 **Petya** 改掉了地图，用糖买通了村口带路的小孩，然后一切就尽在掌握中了……

当电脑重启时，病毒代码会在 Windows 操作系统之前接管电脑，然后执行加密等恶意操作，想干嘛就干嘛。

**5**

  

**Petya  迅速在多个地区爆发，最初的传播方式可能还是个谜**。

  

有种说法是 Petya 的传播方式和 WannaCry 一样，利用的是永恒之蓝漏洞，黑客用专门的漏洞扫描器在网上批量扫描存在该漏洞的电脑，然后进行植入勒索病毒，随后勒索病毒还会自行在内网利用该漏洞或其他方式横向传播，“传染”同一内网里的其他机器。

也有一种说法是，黑客首先攻击了乌克兰的一家叫M.E.Doc 的 **会计软件 **公司。然后通过 M.E.Doc 的更新服务器把一个恶意软件推送给用户。

用户只要一更新软件就立刻感染病毒。**（简直相当于往河里投毒啊！）**

这种推测大概就可以解释为什么 Petya 能迅速占据银行、商场、公司、政府等多个行业了。

  

而且 **M.E.Doc 公司今天早晨承认更新服务器遭到攻击，但否认传播了病毒。**

![](../Images/06de88350a9ffda42faa50717fafd585.png)

  

还有一种说法是，Petya 利用了2017年4月份报告的一个 Windows 漏洞（代号：CVE-20170199）

  

黑客做一个带有恶意链接的 RTF 文档，用邮件发给别人，只要打开就立刻中招。  

  

说 RTF 文档你可能不明白是什么，说写字板你应该就知道了。就是这种文档▼

![](../Images/27da1e66f6a14bfef6e4ee7b66215fc9.png)
