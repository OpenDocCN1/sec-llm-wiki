# 会议回顾 | 数字科技国际治理会议成功召开

2022年6月30日，浙江大学网络空间国际治理研究基地、浙江大学网络空间安全学院、浙江大学计算机科学与技术学院、浙江大学国际战略与法律研究院、浙江大学杭州国际科创中心、浙江大学嘉兴研究院、浙江省区块链与网络空间治理重点实验室、移动终端安全技术浙江省工程研究中心联合主办的**“数字科技国际治理会议”**顺利举行。本次会议由浙江大学程乐教授担任大会主席，诚邀海内外知名专家学者齐聚线上，共商**“构建网络空间命运共同体 加强数字科技发展国际合作”**的全球时代议题。

随着数字经济在市场经济中占比不断攀升，数字产业已经跃升为世界新兴产业。全新数字科技构建了新的产业关系，激发了新的市场与合作。本次会议紧扣时代主题，回应社会关切，就数字基础设施建设或数字科技发展的社会影响等问题展开国际对话，积极探索国际合作机制，数百名业内人士线上参会，十三位国际知名专家学者依次进行了主旨发言。  

浙江大学国际战略与法律研究院常务副院长、网络空间安全学院兼聘教授、光华法学院光华特聘教授程乐代表主办方致辞。程乐教授首先对各位嘉宾表示热烈欢迎和衷心感谢，并指出后疫情时代如何刺激经济复苏以保证社会恢复到疫情爆发前的水平，是全世界面临的共同问题，而数字经济发展和数字技术的创新可能是最行之有效的答案。程教授立足全球视野，提出了国际合作框架下数字技术治理有关的八点建议。同时，程教授也期待这次研讨会能够融合学术领域与实践领域的智慧，为数字科技国际治理提供助益。

主旨发言环节，加拿大滑铁卢大学N. Asokan教授首先对人工智能系统的可信度问题进行了深入探讨，分析了在人工智能系统存在被攻击可能的情况下，如何评估、提高这些系统的可信度，详细阐述了人工智能系统中有关安全与隐私的注意事项。

韩国首尔大学丁相祚教授指出技术标准化将普惠于消费者，并会对相关市场产生较大影响。韩国政府为技术标准化进行了大量投资和法律改革，尤其是信息和通信技术领域。并提出对技术标准的法律响应可以分为行政法规、专利保护和反垄断三方面：随着国内国际标准的协调越来越重要，行政法规也在寻求国内标准与国际标准的协调平衡；在专利保护方面，在禁令和损害赔偿计算之间需要一种新的方法；由于各国的产业结构不同，所以各国在反垄断法的适用方面也存在显著差异。

韩国韩世大学赵容珣教授从战略技术的角度出发，概括了全球主要国家包括中国、美国、英国、日本等国的高科技发展趋势，并主要对韩国技术保护相关法律的发展趋势、韩国先进战略技术保护有关的先进技术、国家先进战略产业法的制定和主要内容、战略技术和标准化等问题进行了详细阐述。

日本东京大学渡部俊也教授以数据权属和数据保护为主题展开研讨，提出为了保证数据的顺利访问，促进对数据的投资，保护数据访问权有其必要。然而，数据是一个无形的对象，无法应用知识产权或民法中所有权的一般概念。渡部俊也教授介绍了日本对数据所有权和数据保护概念的界定，以及相关的法律发展。

美国伊利诺伊大学芝加哥分校Venkat Venkatakrishnan教授提出了应对网络安全威胁的两种方法，讨论了这两种方法如何在追求更广泛的安全保障方面进行协同工作。第一种是反应式方法，重点是在网络安全威胁发生时检测和缓解威胁。另一种是积极主动方法，帮助识别和解决网络安全威胁的根本原因。

韩国汉阳大学尹宣熙教授提出有必要对人工智能自动集成的数据库进行类型化分类，并重点讨论了当前人工智能未保护的类型。依据韩国现行法律，虚拟现实游戏产品没有清晰的法律定义，因此虚拟现实内容游戏产品的激活受到限制。这些问题需要韩国专利局的政策和各国的立法实践予以回答。

韩国东亚大学孙判道教授论述了加密货币市场的经济学在资本市场经济功能中的关键作用。提出了PoW加密货币系统相关的低交易费用和低挖掘成本的主要驱动因素是挖掘的分散化和技术的改进。进一步提出有限的费用和较低的挖掘难度创造了在长期范围内实现加密货币可持续性的激励机制。

香港大学赵云教授指出传统的纠纷解决机制已不能满足电子商务的需求。2019年新型冠状病毒对世界产生了重大影响，在线争议解决（ODR）提供了高效的方案，具有较大优势，对中小微企业来说极具吸引力。监管制度对ODR的可持续发展至关重要。2019年，亚太经合组织继续努力缔结合作框架，该框架成功地为跨境贸易中的中小企业提供了必要的指导。预计在不久的将来会为监管做出更多的努力，以促进ODR的应用，这将有助于增加所有人真正诉诸司法的机会。

英国诺丁汉大学Paul Torremans教授指出，自20世纪60年代以来，欧洲法律的数量、范围以及知识产权领域的决策呈指数级增长。Paul Torremans教授对欧盟知识产权法的每个主要领域进行了明确而详细的阐述，提出国际私法对“定义明确或定位明确”的实质性概念的需求，并讨论了全球禁令在欧盟和其他国际司法管辖区的影响。

新加坡国立大学Massimo Alioto教授从原始设计的角度探讨了实现网络硬件安全的道路，打破了传统系统分区的界限，并进一步讨论了硬件配线的新概念，引入了电路灵活性，使硅芯片能够随着时间的推移而进化，并通过基于学习的物理保护机制抵消新发现的漏洞。为了举例说明上述概念和由此产生的技术进步，Massimo Alioto教授展示了几种硅演示，以量化传统技术的优势和局限性，并确定未来十年面临的机遇和挑战。

意大利国家研究委员会法律信息学和司法研究所研究主任Enrico Francesconi提出，机器可读、可操作的规则是开发具有自动推理功能系统的先决条件，以用于法律领域的高级信息服务，并提出了一种在语义框架内进行法律知识表示和推理的方法。这种方法基于条款和规范概念之间的区别，能够为高级法律信息检索和法律合规性审查提供帮助。

韩国国立庆尚大学李軒喜教授提出，随着第四次工业革命的发展，数据保护的重要性与日俱增，与此同时，跨境数据保护的重要性正在显现。韩国正在各个国际领域发挥谈判力量，例如努力加入数字经济伙伴关系协议（DEPA）。李教授重点介绍了韩国的数据保护法规和跨境数据保护规范。

英国华威大学Feng Hao教授指出，密码认证密钥交换（PAKE）是密码协议研究和实践的一个主要领域。Feng Hao教授对该领域近30年的研究进行了系统回顾，总结了当前最先进的技术，对现有密码协议进行分类并总结出经验教训。

至此，数字科技国际治理会议圆满落下帷幕。大会举办期间，与会专家学者及各主办单位对“构建网络空间命运共同体 加强数字科技发展国际合作”这一议题达成八项共识，开辟了新的科技和产业领域合作空间，为数字科技以及网络空间国际治理发展提供智识贡献。
