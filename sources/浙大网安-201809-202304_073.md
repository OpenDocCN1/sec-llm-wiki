# 浙大网安参与制定的安全多方计算IEEE国际标准正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NDczNDc4NA==&mid=2247490535&idx=1&sn=c87c8bdde6adfcbf4299483260975d3d&chksm=c01a4348f76dca5e31f1de8b957fead92e395f1446fb5e91369de71f6b998fa1b9ab1033d1fe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NDczNDc4NA==&mid=2247490535&idx=1&sn=c87c8bdde6adfcbf4299483260975d3d&chksm=c01a4348f76dca5e31f1de8b957fead92e395f1446fb5e91369de71f6b998fa1b9ab1033d1fe&scene=27#wechat_redirect)

近日，国际标准组织电气与电子工程师协会（IEEE-SA）正式发布了浙江大学作为秘书单位制定的安全多方计算IEEE国际标准——《IEEE 2842-2021 - IEEE Recommended Practice for Secure Multi-Party Computation》。该标准有助于推动安全多方计算技术规范发展，加速隐私计算技术实际落地。

  

![](../Images/a5e1bcaec0af51e1a71498581aa77737.png)

  

学术界和产业界都在致力于研究如何在利用数据共享发挥数据价值的同时，规避个人隐私泄露与数据滥用等巨大风险。在理想状态下，可以通过一个可信的第三方实现多方数据的安全计算，但在现实中，这样的理想第三方并不存在。目前，主要研究隐私计算技术，通过安全多方计算（MPC）、联邦学习（FL）与可信执行环境（TEE）等技术，在保证数据安全的同时对数据价值进行挖掘。对于这些新兴的应用技术，相关的国际、国内标准亟待建立完善。

该标准于2019年9月在IEEE牵头立项并设立安全多方计算工作组（Secure Multi-Party Computation Working Group），浙江大学网络空间安全学院张秉晟教授担任工作组秘书。历时2年标准制修订，经过多轮研讨、沟通、起草、编写等大量研究和推动工作，该标准于2021年11月8日正式发布。该标准规范了安全多方计算的定义，以及安全多方计算的基本要求、可选要求和安全模型、系统角色以及工作流程、部署模式等，并给出了安全多方计算的具体实现案例。

浙江大学作为双一流建设高校，在网络空间安全学科建设和隐私计算技术探索方面一直走在前列。浙江大学网络空间安全学院自开办以来始终致力于高水平科研和国际化办学，产出了大量高水平科研成果，并主导和参与了多项相关行业标准制定。
