# 喜报 | 苑子琦等同学自主设计的amipsel处理器荣获“龙芯杯”一等奖

2021年8月20日，备受关注的**“第五届全国大学生计算机系统能力培养大赛”**决赛落下帷幕。全国大学生计算机系统能力大赛是由教育部高等学校计算机类专业教学指导委员会和系统能力培养研究专家组共同发起，面向高校大学生举办的全国性大赛。**目前，该赛事为国内计算机体系结构和操作系统领域最硬核、参赛人数最多、业界与学界最认可的比赛。**浙江大学网络空间安全研究中心的**常瑞、吴磊和申文博老师带领的队伍获得一等奖1项和三等奖2项。**

  

在**处理器设计赛道（“龙芯杯”）**中，两支参赛队伍分别以预赛第一名和第十七名的优秀成绩突出重围，获得决赛29张入场券中的2张。在决赛中，由**苑子琦、沈栩捷、石昊洋、李鸿屹**4位同学组成的浙江大学二队脱颖而出，凭借**全场综合性能最佳的amipsel处理器荣获一等奖**；**贺思睿、张行健、潘子曰共同设计的芯仪处理器获得了三等奖的佳绩。**

  

在**操作系统赛道**中，首次参赛的**陈宇、梁洵、李子航****组成“浙江大学长城队”，他们设计的“基于 Rust 语言的TEE OS”获得比赛三等奖。**

  

**处理器设计赛道**

“龙芯杯”处理器设计大赛已连续举办四届，本届赛程尤为紧张。参赛队伍需要在4个月的时间内完成处理器核的设计，包括功能、性能测试、移植操作系统等开发工作。4月至8月期间完成初赛作品，并在8月5日提交。进入决赛的队伍于8月18日至19日参加决赛。决赛分数由综合性能、龙芯自定义指令、系统启动与在线答辩四部分组成，综合考虑了处理器的功能和性能，以及参赛队伍的应变能力、表达能力和创新性。

  

有了去年参加“龙芯杯”的经验和“一生一芯”计划的基础，本次比赛的老师和队员都做了充分准备。队伍在4月份就开启了“龙芯杯”启动会，确立了适合FPGA上硬件资源的5段流水线的基本设计，提出了重点优化分支预测和高速缓存的比赛策略，同时规定了敏捷开发、可配置处理器、每完成一个小功能就单独提交一次的三大工程要求。  

  

队员们从5月份开始开发处理器，历时近一个月，两支队伍都于6月前通过了预赛中89个测试点。此后，我们在89个点的基础上，完成了10个性能测试和系统测试，并针对主频和性能测试的样例（包括一些著名的嵌入式benchmark，包括但不限于dhrystone、coremark、crc32、quick sort等）进行优化。其中，amipsel处理器重点优化了多发射下的分支预测，成功解决了板上RAM读口较少和发射数量较多的矛盾，并实现了多段分支预测和提早恢复预测错误的机制；芯仪则另辟蹊径，提出了branch cache这种不预测，但是能够几乎无代价跳转的机制。在高速缓存方面，amipsel根据实际情况，设计实现了简单的非阻塞数据缓存，明显提高了2个性能测试点的分数。

8月18日决赛当天，在自定义指令答题中，官方给出的filter指令是一个难度较往届比赛更大的、和历史记录相关的硬件加速器，而时间仅给了3个小时。对于多发射设计，该指令有更高的实现难度。但是，两队队员秉承着不到最后一刻永不言弃的精神，都正确实现了该指令，其中一队压线通过，有惊无险。在此后的系统展示与在线答辩环节中，两支队伍都势如破竹：一队的branch cache成功吸引了评委们的注意；**二队的dtqemu、可配置性处理器设计成为了比性能第一的amipsel处理器本身更加引人注目的亮点****。**

**操作系统赛道**

操作系统赛道为今年首次增加的赛道，参赛队伍需历时4个月完成一个操作系统项目。“浙江大学长城队”的选题为蚂蚁金服公司的**“基于 Rust 语言为 TEE（可信执行环境）设计 TEE OS”**。

  

题目的目标是设计出适配Intel SGX、AMD SEV、RISC-V Keystone共 3 种TEE 环境的TEE OS，这对项目设计的要求颇高。因此，参赛队员在比赛前期经历了漫长的调研过程，包括阅读 Keystone 的源代码、研究 Linux 操作系统的架构、研究 Rust 语言的模块机制和条件编译等。在获得了一定的知识积累后，队员们最终决定以 HAL 的方式设计一套平台无关的 API来最大程度降低每个架构的适配成本。最终**成功适配了 Intel SGX、RISC-V Keystone 和通用 x86 VM 三个架构**（其中 AMD SEV 由于技术原因，采用通用 x86 VM 代替）。

  

除此之外，**项目还需利用 Rust 语言的内存安全特性来尽可能地提升内核的安全性。**由于 Rust 编译器的检查非常严格，用 Rust 语言编写操作系统对参赛队员而言也是一个新鲜的挑战。在项目设计和开发的过程中，队员们常常遇到难以用传统操作系统编程思路解决的技术问题，所幸老师提供的关于 Theseus 操作系统的论文以及来自企业技术指导的建议都给予了很大的启发。比赛结束时，3名参赛队员成功完成了一个小型操作系统的设计任务，Rust 语言及操作系统编程水平也得到极大提升。

  

最终，**“浙江大学长城队”完成了一个 TEE OS 命令行管理工具和一套跨平台的内存 API，并获得全国三等奖**。

  

凭借着优异表现，**浙江大学的作品获得了组委会专家的一致好评。**从历史统计数据来看，本届系统能力大赛的作品，无论是排名靠前的作品还是整体水平都创造了新的高度。一位龙芯的专家认为，比赛队员们的表现着实在专家们的“意料之外”。

  

本次比赛，参赛队员们都付出了大量的时间，同时也获益良多。在老师的指导下参加如此硬核的比赛，**队员们和计算机系统有了最真实的接触，增强了对真实系统的认识、理解和实践能力，也挑战了自我，超出预期地完成了作品。**
