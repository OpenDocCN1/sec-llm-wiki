# 浙大网安物联网安全团队基于RFID的人脸认证研究获得2021年IEEE INFOCOM最佳论文提名奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NDczNDc4NA==&mid=2247490513&idx=1&sn=31336d6d5f4d3b19930482b96569faec&chksm=c01a437ef76dca6891e3cab0d1c23272805ab5673173d6663581b4eb93719347f935ad2312fa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NDczNDc4NA==&mid=2247490513&idx=1&sn=31336d6d5f4d3b19930482b96569faec&chksm=c01a437ef76dca6891e3cab0d1c23272805ab5673173d6663581b4eb93719347f935ad2312fa&scene=27#wechat_redirect)

近期，浙江大学网络空间安全学院物联网安全研究团队利用无线射频识别技术，实现了可抗欺骗攻击的人脸识别认证系统。该研究工作“RFace: Anti-Spoofing Facial Authentication Using COTS RFID”已被网络领域的一流国际会议IEEE INFOCOM 2021收录，同时获得大会最佳论文提名奖（Best Paper Candidate）。INFOCOM是IEEE组织在通信网络领域的旗舰性会议，也是中国计算机学会推荐的A类国际会议。该研究工作在INFOCOM 2021收录的251篇论文中脱颖而出，入围最佳论文的候选名单，获得了广泛的关注和好评。INFOCOM 2021程序委员会同时邀请该研究成果以Fast Tracking Paper的形式发表到国际一流期刊IEEE Transactions on Mobile Computing（TMC，CCF A类期刊）。该研究聚焦当前基于图像的人脸认证系统隐私泄露和易受欺骗攻击的安全性问题。虽然面部几何特征能够在一定程度上抵抗欺骗攻击，但基于图像的认证方式仍然饱受DeepFake、特征合成等方式的攻击（例如3D打印的人脸）。浙大网安的硕士生徐炜烨、博士生刘建伟和本科生张诗敏在林峰教授、韩劲松教授和任奎教授的指导下，提出了一种新颖的保护隐私的防欺骗攻击的人脸识别系统，名为RFace。该系统使用商用低成本RFID标签构成阵列提取面部的3D几何形状和内部生物材料特征。这些特征很难捕获和伪造，因此可以抵抗欺骗攻击。RFace仅要求用户将面部摆放在标签阵列前几秒钟，并且不会泄漏他们的面部隐私。研究团队建立了一个理论模型来严格证明特征捕获的可行性以及面部特征与射频信号之间的对应关系。在实用性方面，设计了一种有效的算法来缓解面部和标签阵列之间距离和偏转角度不稳定的影响。通过对30位参与者进行的大量识别实验和三种类型的主流欺骗攻击实验，表明RFace的平均身份验证成功率超过95.5％，EER达到4.4％。更重要的是，实验发现现有的攻击无法欺骗RFace。该研究也得到了香港理工大学郑元庆教授的精心指导和帮助。
