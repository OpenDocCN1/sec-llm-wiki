# 任奎教授当选2020国际计算机学会会士（ACM Fellow）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NDczNDc4NA==&mid=2247490489&idx=1&sn=1eb4f4e33c62ff97a98c62b4b12cee04&chksm=c01a4316f76dca003566d6966b0cfd74829eccf80455b6af35db3fca813c05de3ef8b7e54824&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NDczNDc4NA==&mid=2247490489&idx=1&sn=1eb4f4e33c62ff97a98c62b4b12cee04&chksm=c01a4316f76dca003566d6966b0cfd74829eccf80455b6af35db3fca813c05de3ef8b7e54824&scene=27#wechat_redirect)

近日，国际计算机学会 (Association for Computing Machinery , 简称 ACM)正式公布了2020年ACM Fellow名单，**浙江大学网络空间安全学院院长、计算机科学与技术学院副院长任奎教授**因其在“无线系统安全和云数据安全方面的贡献”（For contributions to wireless system security and cloud data security）当选ACM Fellow。ACM创立于1947年，是全世界计算机领域影响力最大的专业学术组织，同时也是世界 “计算机领域的诺贝尔奖”——图灵奖（A.M. Turing Award）的评选机构，目前在全世界130多个国家和地区拥有超过10万名会员。ACM Fellow是ACM授予资深会员的最高荣誉，表彰对于计算机相关领域有杰出贡献的学者，审查过程十分严格，每年遴选一次。当选ACM Fellow也就意味着进入了“计算机领域世界顶尖的1%”，是极高的专业荣誉。2020年新当选 ACM Fellow 名单，共有95位科学家当选，12位华人学者中的4位在内地大学全职工作。

  

**人物简介**

![](../Images/2e5ecb9fc9e1286ca469e928eb64fa2c.png)

  

  

任奎现任浙江大学求是讲席教授，是无线系统安全和云数据安全等相关领域的国际著名学者；他发表了300余篇同行评议的期刊与会议文章，获得了多篇最佳论文和时间考验论文奖。他的H-index为75，文章总引用次数超过34000次，并入选科睿唯安高被引科学家。任奎教授诸多开创性的学术贡献包括：

在无线系统安全方面，任奎教授在包括智能移动设备安全、物理层通信安全、智能3D打印设备安全等领域提出并实现了一系列被广泛认可的创新理论方法、技术与系统。他率先发现及揭露了一系列因智能移动设备中传感器的使用所导致的安全问题，包括基于深度学习及加速度传感器的零权限手机窃听攻击、基于计算机视觉技术的新型远程触摸屏输入获取攻击、基于智能手机内置传感器的3D打印窃取攻击等。这一系列工作引起了广泛关注，多次被包括新华社、科技日报、科学美国人、美国国家科学基金新闻、ACM新闻、每日科学等在内的国内外主流媒体报道。相关研究成果整体推动了学界与业界对物联网和智能移动设备安全威胁的广泛重视，并已然成为该新兴安全领域研究的重要参考；其最新成果已被业界采纳用于提高相关智能手机的隐私保护及安全性。同时，任奎教授在面向智能设备的身份认证安全方面亦做出了具有广泛影响的工作。他曾提出了首个基于相机指纹的抗伪造设备认证系统，在图像篡改检测，数字版权管理等方面具有广泛的应用，目前已被成功应用于业界的版权检测系统中。任奎教授亦曾设计实现了首个利用设备物理特性以抵抗语音模仿攻击的安全认证系统，并对生物识别技术开创革新，比如提出了心脏三维运动模式和指纹音等新型生物特征。这些卓越的研究成果曾获相关领域顶级国际会议最佳论文奖。

在云数据安全研究方面，任奎教授是国际学术界的先行者之一，在包括安全云数据存储、云数据内容访问控制、加密数据库和加密计算等多个研究热点方向做出了大量奠基性的创新贡献。任奎教授曾提出了首个隐私保护的云存储完整性公开审计系统以及提出了首个支持动态数据更新的审计技术，开创了云存储完整性审计研究领域的全新方向，在学界引起了广泛的关注，相关论文工作取得了超过6400次的引用。任奎教授曾提出了首个支持在大规模动态系统中实现数据所有者控制的细粒度云数据安全共享技术，创新性地解决了加密云数据共享所面临的如何在撤销数据用户访问权限后进行安全高效的密文更新这一关键挑战。该项工作对云数据安全共享领域产生了深远的影响，取得了超过2000次的引用，并获得了相关领域顶级国际会议的时间考验论文奖。除了在云数据存储安全方面的一系列卓越工作之外，任奎教授在加密数据库的前沿领域亦做了大量开创性的工作，首次提出了包括安全排序搜索、加密模糊搜索、加密多关键字搜索、软硬件协同的加密范围搜索等一系列创新理论与技术。这些基础性成果极大地推动了相关领域的发展，产生了深远的影响，相关论文工作取得了5000多次引用，并荣获相关领域顶级国际会议最佳论文奖。任奎教授亦曾提出基于前沿的差分隐私技术，并利用时空数据相关性以及多阶段架构，以实现理论最优的隐私保护的云数据分析框架。这些成果已集成到业界数据分析平台中，用以保护百万计的用户数据隐私。

任奎教授获得的其他奖项和荣誉包括国际电气电子工程师学会会士（IEEE Fellow 2016），因其在“云计算和无线网络的安全和隐私方面的贡献”（for contributions to security and privacy in cloud computing and wireless networks），浙江大学首届国华杰出学者奖、IEEE通信分会安全技术委员会技术成就奖、纽约州立大学校长杰出研究奖、纽约州立大学布法罗分校资深学者奖、美国国家自然科学基金青年职业奖 (NSF Career Award) 等。任奎教授同时还担任多个国际权威期刊编委、国际一流会议主席或共同主席、教育部科技委员会委员、高等学校教学指导委员会委员、ACM亚洲计算机与通信安全会议（AsiaCCS）指导委员会委员、ACM中国安全分会主席以及浙江省海高会青年分会首任会长。
