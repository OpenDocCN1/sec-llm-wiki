# 【转发】浙大计算机学院任奎、周昆双双入选2020 ACM Fellow，中国大陆仅4席

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NDczNDc4NA==&mid=2247490487&idx=1&sn=c8ee60b42493fb0df828c8d0da144c2d&chksm=c01a4318f76dca0ee8b84b94b789c46eb977a320613f2f25d602f3a30dcd91641c0ddbab3ae7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NDczNDc4NA==&mid=2247490487&idx=1&sn=c8ee60b42493fb0df828c8d0da144c2d&chksm=c01a4318f76dca0ee8b84b94b789c46eb977a320613f2f25d602f3a30dcd91641c0ddbab3ae7&scene=27#wechat_redirect)

1月14日，国际计算机学会（Association for Computing Machinery， ACM）公布了2020年新选会士名单（ACM Fellow），**浙江大学网络空间安全学院院长、计算机科学与技术学院副院长任奎教授**因其在无线系统安全和云数据安全上的卓越贡献当选。**浙江大学计算机辅助设计与图形学国家重点实验室主任周昆教授**因其在计算机图形学上的杰出成就当选。2020年， 全球一共评选出7位图灵奖得主在内的95名ACM Fellow，**中国大陆仅入选4位，浙江大学即占两席**。
