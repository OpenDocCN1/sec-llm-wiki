SVF: Static Value-Flow Analysis For Source Code

Abstract

Static analysis is an enabling technique that paves the way for a wide range of client applications, such as program understanding, software vulnerability detection, and compiler optimisation. I will share our past experience in developing precise and scalable static program analysis techniques for analysing large-scale software. The talk will start with the background knowledge of program analysis, and then move to our ongoing project (https://github.com/SVF-tools/SVF), an open-source static analysis framework based on a years-long effort. Next, I will introduce SVF's design, setup, internal working and applications. Finally, I will discuss some future research opportunities.

  

BIO

Dr. Yulei Sui is currently a Senior Lecturer at University of Technology Sydney (UTS), Australia. He is broadly interested in Programming Analysis, Compilers, and Software Engineering. In particular, his research focuses on building fundamental static and dynamic analysis techniques and tools to improve the reliability and security of modern software systems. His recent interest lies in bug detection, program repair and software security analysis through data mining and machine learning. His papers have been published in the competitive conferences and journals, such as ICSE, FSE, OOPSLA, ECOOP, SAS, ASE, ISSTA,  USENIX Security, ACSAC, ISSRE,  CGO, CC, LCTES, TSE and TIFS. He was a plenary talk speaker at EuroLLVM 2016, and has been awarded a SAS 2019 Best Paper, an ICSE 2018 Distinguished Paper, a CGO 2013 Best Paper, and a 2017 ARC Discovery Early Career Researcher Award.
