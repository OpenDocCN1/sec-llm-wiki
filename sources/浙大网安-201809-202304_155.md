# 2020 年浙大网安年会圆满成功

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NDczNDc4NA==&mid=2247490434&idx=1&sn=85e8ce3e0f4edc621ed474403e82e118&chksm=c01a432df76dca3bd5561e41be103f2c734f6098a2b78add6e26d147c8d378805cf13c26871d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg5NDczNDc4NA==&mid=2247490434&idx=1&sn=85e8ce3e0f4edc621ed474403e82e118&chksm=c01a432df76dca3bd5561e41be103f2c734f6098a2b78add6e26d147c8d378805cf13c26871d&scene=27#wechat_redirect)

豪情欢歌辞旧岁，喜气开篇迎新年，2020年1月12日傍晚，浙江大学网络空间安全学院2020年年会在杭州旅行者酒吧隆重举行，浙江大学网络空间安全学院师生80余人欢聚一堂，共度联欢。

  

![](../Images/a3f8c4c01a35478bc3f11a7ef2af543b.png)

  

网安院长任奎教授进行了讲话，他以幽默的方式开场，肯定了常老师的主持，使得现场氛围更加活跃，而后他真切地表达了自己对各位老师的感谢，同时许下了对学院未来的期待。  

  

![](../Images/7c17502698962d83c6bb6ed693e23512.png)

  

随后，进行了颁奖环节。王飞同学获得了2019 IEEE GLOBECOM CONFERENCE Best Paper Award；王超同学获得了第二届中国研究生创“芯”大赛华为专项奖二等奖以及全国决赛一等奖；张义然，董晓飞，杨博麟，徐国瑞四人获得了Asian Hardware Oriented Security and Trust Symposium 2019 (AsianHOST 2019) Best Student Poster Award；徐金焱获得了全国信安大赛一等奖；陈元，徐金焱，李嘉奇，孟泉润四人获得了iDash安全基因大赛一等奖；张义然，邵彬，王超“华为杯”第二届中国研究生创“芯”大赛全国决赛一等奖。任奎教授分别给获奖同学颁发了奖状。

  

![](../Images/6d8164ca335a8d72dc1aba6a17f31ca2.png)

  

颁奖结束后，进行了聚餐和游戏环节。游戏环节分为三轮，每轮以击鼓传花的形式选出四名参赛选手，完成switch上的五个小游戏，吸引了众多老师和同学围观。整个游戏环节跌宕起伏，高潮连连。每轮游戏后的抽奖环节更是万众期待，今年的头奖又花落在了闫同学身上，让人羡慕不已，没中奖的同学就把好运气攒到明年吧。

  

![](../Images/92a136d43411cda99d8873a09b58cc23.png)

  

2020年浙大网安年会最终在一片片欢声笑语中落下帷幕。相信正是因为我们在过去一年的倾力付出，才会在年末时绽放出最绚烂的笑容。展望2020，亲如一家的网安人将继续紧密团结，续写新篇。
