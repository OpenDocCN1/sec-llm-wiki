How to Use Abstract Information to Improve The Efficiency of Vulnerability Mining

Abstract

In the field of binary program analysis, vulnerability mining is a key issue that lasts for a long time. The existing automated vulnerability mining techniques are various, but many technologies have various deficiencies, which is mainly reflected in the following three aspects: slow analysis speed, low coverage of program state space, and poor automation. These shortcomings have limited the widespread application of automated vulnerability mining technology in reality. Therefore, in the foreseeable future, vulnerability mining will remain the focus and difficulty in the field of binary program analysis.

Most current binary analysis techniques focus on the underlying code. We believe that a potential research direction is to use abstract information to guide the underlying code analysis to improve the analysis speed and state space coverage. Some of these abstract information can be obtained through automated program analysis, and some can be provided by analysts using prior knowledge of experts. This report will first introduce the main deficiencies of current automated vulnerability mining technologies and explore the main difficulties and challenges of applying these technologies to real-world goals. Subsequently, this report looks forward to future research directions and explores how to combine automatic analysis results, abstract information and prior knowledge provided by humans to improve the efficiency of vulnerability mining. Finally, this report will showcase the latest progress in angr development.


  Bio 

Ruoyu Wang is an assistant professor at Arizona State University. His main research interests are binary program analysis, including vulnerability mining, exploits, and program patching. He is one of the co-founders and core developers of the binary analysis platform angr. His papers have been published in Security and Privacy, USENIX Security, CCS, NDSS and other conferences, and won two best paper awards. He is a non-famous CTF competitor who used to be a member of Blue-lotus and is now a core member of Shellphish, specializing in reverse engineering. He is also a member of the Shellphish CGC team and won the third place in the 2016 DARPA Cyber Grand Challenge final.
