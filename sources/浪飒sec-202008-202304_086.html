介绍

chafofa一款命令行fofa查询工具，可快速将查询结果导出到表格中。

程序源码中自带了普通会员，如果自己有高级会员自行替换。

使用

查fofa命令行工具 author:浪飒 Options:   -f TEXT     请输入fofa查询语法   -s INTEGER 请输入所要查询的条数，默认100条   --help     Show this message and exit
