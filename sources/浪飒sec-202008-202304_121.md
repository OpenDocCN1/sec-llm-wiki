## 前言

本文阐述解决MarsCTF配置docker API时会出现API无效的问题，其实主要解决Docker开放2375端口。

实验环境：Kali2022.2

## 开始

在配置docker API时会出现API无效

![](../Images/26d2a6c051791f8ccd64fe5da8c6d705.png)

image-20221124010117031

我找了半天是因为docker没有开启2375端口，实现远程访问

查看docker服务信息

```

systemctl status docker.service
```

![](../Images/892fd9a52a9720eb224816faf555bde2.png)

image-20221124010657263

找到docker.service文件存放在`/lib/systemd/system/`

编辑docker.service

```

vim /lib/systemd/system/docker.service
```

在ExecStart行后面追加以下内容

```

-H tcp://0.0.0.0:2375 -H unix://var/run/docker.sock
```

如下图所示：

![](../Images/c17cc989c33bf78edcb29a079414584b.png)

image-20221124010459869

保存并退出

重新载入服务信息

```

systemctl daemon-reload
```

重启docker服务

```

systemctl restart docker
```

再次查看docker服务信息

![](../Images/b66bd97a5357af2c300314898a054f44.png)

image-20221124011345584

查看端口是否开启

```

netstat -nlpt
```

![](../Images/4853ba03f41d8ca518930ad99a07dacf.png)

image-20221124011552926

docker api配置有效，大功告成！

![](../Images/e44f769da9bfdac3db12dfc485aa58e7.png)

image-20221124011630288

![](../Images/8afb79a3a98c9f76ecaab3882919a6ea.png)
