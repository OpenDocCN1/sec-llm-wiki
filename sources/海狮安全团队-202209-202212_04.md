在项目中总会遇到一些不出网的机器，或者有些跑在 127.0.0.1 上的服务。这时候就需要把端口或者网断代理出来进行下一步操作。

# 0x01 ssh

## 本地转发 

```


ssh -NL 本地端口:目标IP:目标端口 跳板user@跳板机IP
```

## 远程转发 

```


ssh -NR 端口:目标IP:目标端口 跳板机用户名@跳板机IP
```

## 动态转发 

```


ssh -ND 本地端口 跳板机用户名@跳板机ip
```

ssh 代理一般常用于链接目标开在 127.0.0.1 上的数据库或者站库分离的使用，php 站的话可以使用 adminer.php 来操作数据库，但是库比较大的话还是还是把端口代理出来使用 Navicat 操作。

# 0x02 sshuttle

```


sshuttle -vr root@10.10.10.10.1 192.168.1.0/24 --ssh-cmd "ssh -i id_rsa"
```

当拿下边界 web 服务器时可以用这个工具代理流量去访问内网的机器。

限制：你必须有本机的 root 权限但是你可以在服务端有普通账户即可。服务器要支持 python2.3 或者更高版本。

github 链接

```

https://github.com/apenwarr/sshuttle
```

# 0x05 EW

EarthWorm 是一款用于开启 SOCKS v5 代理服务的工具，基于标准 C 开发，可提供多平台间的转接通讯，用于复杂网络环境下的数据转发。专有主页：http://rootkiter.com/EarthWorm/

普通内网环境：

1、目标有公网 ip 且拥有权限。

```


./ew -s ssocksd -l 8888  
```

2、目标无公网 ip

```


./ew -s rcsocks -l 1080 -e 8888  //vps运行
```

二重内网环境：

1、A有公网ip（边界机器 dmz 区） B内部机器（数据区可以链接 A 但不出网）

```


./ew -s ssocksd -l 9999    //B机器运行
```

2、A 无公网 ip 可出网 ，B 可访问 A 但不出网

```


./ew -s lcx_listen -l 1080 -e 8888 //vps运行
```
