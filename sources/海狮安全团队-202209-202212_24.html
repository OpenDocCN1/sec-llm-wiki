0x01 SMB协议介绍

先来简单介绍下 SMB 协议，在 Windows 操作系统中出现 NetBIOS 后，使用 NetBIOS 实现了一个网络文件/打印服务系统，这个系统基于 NetBIOS 设定了一套文件共享协议，用于实现不同计算机之间共享打印机、串行口和通讯抽象等功能，这个协议就被称之为 SMB（Server Message Block） 协议。SMB 协议典型应用就是众所周知的“网上邻居”功能。

除此之外，那么大家肯定还会听说过 Samba 吧？Samba 是 SMB 协议的一个开源实现，用于在类 Unix 系统中来实现 SMB 功能，是可以使得 Windows 主机和 Linux 主机之间实现了资源共享的软件。

另外 Windows 主机还有 CIFS（Common Internet File System） 协议，即通用因特网文件系统，CIFS 是 SMB 协议的衍生品，即 CIFS 是 SMB 协议的一种特殊实现，由微软公司开发。具体的内容大家可以去查阅 https://docs.microsoft.com/en-us/windows/win32/fileio/microsoft-smb-protocol-and-cifs-protocol-overview?redirectedfrom=MSDN，里面介绍还是挺详细的，如果对这方面有兴趣的小伙伴可以在公众号留言，人多的话可以出一期关于 CIFS/SMB 协议的详细分析，带你学习不迷茫。

0x02 Windows SMB利用

协议了解后那就开始干活了。最简单的当然是用 windows 连接 windows。

方法一：利用自带文件共享服务

win+r，输入 \\ipaddress

回车连接后，输入用户名密码后即可看到主机共享文件信息

方法二：使用net use命令

使用系统工具 net use 命令连接

相信到这细心的小伙伴发现了，这里没有查看到默认的系统共享 C$ 等目录，接下来，可以映射网络磁盘来进行查看

又有新问题了，如果隐藏共享不是常见的 C$，那该怎么连接？可以直接通过获取权限吗？如果通过文件共享上传了马子又该如何上线呢？接着往下看。

0x03 Linux SMB利用

Linux 中的软件还是挺多的，这里以介绍为主，功能大多比较类似，有喜欢的工具可以自行尝试

方法一：smbclient

smbclient 是 linux 上可存取 SMB/CIFS 服务器的用户端程序，kali 默认安装。

使用 -L 参数可以查看远程主机的所有共享文件信息

接着连接后使用交互式命令查看或者下载文件就可以了，非常类似FTP

方法二：winexe/pth-winexe

winexe/pth-winexe 同样在 kali 中默认安装，除了用于 linux 连接 windows，还可以直接执行系统命令

方法三：crackmapexec

方法四：Smbmap

kali 默认安装软件，可用于执行系统命令，识别共享目录

方法五：Impaclet包工具

安装 impacket 工具

https://github.com/CoreSecurity/impacket.git

利用 pseexec.py、smbexec 文件都可以直接获取权限

方法六：Evil-winrm

evil-winrm 是著名的 PS 远程 shell 黑客框架工具，Windows 远程管理（WinRM） Shell 的终极版本。在 kali 中安装十分简单，gem install evil-winrm，一条命令即可。可以进行命令补全、上传下载文件、加载 powershell 脚本等功能
