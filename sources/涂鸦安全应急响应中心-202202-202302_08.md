# 漏洞综述

在Linux kernel v4.19之后引入的HCI时间解析器包含漏洞。控制HCI事件数据包能够造成安全影响。

1.  CVE-2020-24490 BadVibes 基于堆的缓冲区溢出
2.  CVE-2020-12352 BadChoice 基于堆的信息泄露
3.  cve-2020-12351 BadKarma 基于堆得类型混淆

## 漏洞原理与内核动态调试

### 漏洞原理

此漏洞完成远程内核rce为 内核地址泄露 + 内核krop的组合攻击

### 内核地址泄露原理

cve-2020-12352 badchoice，堆栈信息泄露

在内核源码 net\\bluetooth\\a2mp.c 对于蓝牙的a2mp协议访问控制中，存在返回未初始化变量的问题

hci\_dev\_get() 类似于 hciconfig命令，列出当前设备所有的蓝牙适配器

![](../Images/cf2befd6c8dc99d35b1e917afcce432f.png)

poc使用了lib\_bluetooth库的头文件

