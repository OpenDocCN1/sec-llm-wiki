# TransparentTribe APT组织最新样本分析报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514417&idx=1&sn=224ad304c2d24598c9ec4dcb563769eb&chksm=ce463221f931bb373596eedea986d97fd15495d8774d04c705b5625f27fae7237463319d662e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514417&idx=1&sn=224ad304c2d24598c9ec4dcb563769eb&chksm=ce463221f931bb373596eedea986d97fd15495d8774d04c705b5625f27fae7237463319d662e&scene=27#wechat_redirect)

 

TransparentTribe APT组织，又称ProjectM、C-Major，是一个来自巴基斯坦的APT攻击组织，主要通过鱼叉式钓鱼邮件对特定国家政府、军事目标发起攻击，该组织活动最早可以追溯到2012年，并于2016年被proofpoint首次披露，此前深信服安全团队首发布过一篇《来自TransparentTribe APT组织的窃密》的报告，近期又获取到一例TransparentTribe APT组织的最新变种样本，此样本的诱饵文档为日历型电子表格，通过执行表格中宏代码释放恶意程序，窃取受害者主机的敏感信息。样本执行整体流程图：

  

![](../Images/0eda192cb249cd6068d95b280e6ef0e3.png)

1.打开诱饵表格文档。

  

![](../Images/8da51f060351cfef734172538cf47731.png)

  

2.文档里面包含恶意的宏代码，执行宏代码，表格文档如下：

  

![](../Images/17b89e3fd0d3323c647dd589a7f584a3.png)

  

恶意宏代码会释放恶意程序到相应的目录并执行,进程信息如下所示：

  

![](../Images/31af81f9c8d0ae1b411645c6fb921000.png)

  

释放的恶意程序目录，如下所示：

  

![](../Images/014e1108f444f053f1111210cf7a1494.png)

  

3.表格中包含的恶意宏代码，如下所示：

  

![](../Images/a1ddd5ad27e397f0cf0dc587e15f0731.png)

  

动态调试宏代码，首先会解密出相应的恶意文件路径目录字符串，然后读取窗口中的数据写入生成的恶意文件中，如下所示：

  

![](../Images/38326206c00eff65cf2dc25aa0774299.png)

  

窗体的数据如下所示：

  

![](../Images/09219d9b8e0d0acc74f10bf83358da7a.png)

  

解压相应的数据压缩包文件，并调用生成的恶意文件。

  

![](../Images/30ead9bae5a043d8b27770748335847d.png)

  

解压drivertoolkit.zip文件。

  

![](../Images/35dca152de7f1dc74dbf0b1b8406366d.png)

  

   

**分析drivertoolkit.tmp文件**  

  

1.判断系统是否存在如下进程，如果存在则退出，如下所示：

  

![](../Images/7a1ca564c6fc9ea08f5f4fb97b0dffb0.png)

  

检测的进程列表

python.exe、fiddler.exe、virtualBox.exe、VBoxService.exe、bitcoin-qt.exe、dotPeek.exe、dotPeek64.exe、jetbrains.exe、vmware.exe

  

2.设置系统自启动项快捷方式，如下所示：

  

![](../Images/1c97afeb6b82d2e8bc6daa397d5e9fab.png)

  

快捷方式用于启动C:\\ProgramData\\twainResolver\\twainResolver.scr程序，如下所示：

  

![](../Images/3a9df6585908f24f4e1374fabfca679a.png)

  

3.读取文件中的数据，生成恶意文件C:\\ProgramData\\twainResolver\\twainResolver.scr，如下所示：

  

![](../Images/41bb9d2a081bb4a60722c61afcb90925.png)

  

读取的数据为PE文件。

  

![](../Images/0e2f04081fa0efe3aad54af4f9aad22e.png)

  

4.最后启动恶意程序C:\\ProgramData\\twainResolver\\twainResolver.scr。

  

![](../Images/8812ce3fb63ba0e12c85e8539f41db6b.png)

  

   

**分析twainResolver.scr文件**  

  

1.收集主机上的进程信息，上传到远程服务器，如下所示：

  

![](../Images/0577f87d7df2313bbd5f0f84530f9e7d.png)

  

捕获到如下的流量数据包：

  

![](../Images/5cf95b74ddeb7f5d1b125807b4ee34a6.png)

  

传输的数据如下：

  

![](../Images/cd6338f4ec2c46c401e271cea889036d.png)

  

2.由于远程服务器失效了，上传数据失败，无法返回相应的数据。

  

![](../Images/bbd44ae7bdb3e5150e5c0fb4e8994318.png)

  

3.由于返回的数据为空，所以无法从远程服器下载相应的恶意程序，程序直接退出，如下所示：

  

![](../Images/b0ed0fd324384d1c960e0358619b3d99.png)

  

猜测会下载一个RAT远控类程序，但已失效，无法获取到该RAT程序，进行下一步的分析，大多数的APT攻击组织主要目标是为了窃密，在执行的最后一般会释放一个RAT类的恶意程序控制受害者机器，并从受害者机器上获取有价值的信息。
