微软八月补丁日重点漏洞预警

原文：http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514375&idx=2&sn=69ee0b30c8dc8e08151ce9909fce6bee&chksm=ce463217f931bb01bd1051c921b03daa33752d041a715af5906da1ca3ba793b51d04285f3115&scene=27#wechat_redirect


2019年8月13日，Microsoft发布了八月份安全补丁更新。在官方的安全更新公告中一共披露了93个漏洞的相关信息，其中29个获得了“严重”评级。截至目前为止，尚未发现这93个漏洞的在野利用。


漏洞概述



1 Remote Desktop Protocol远程代码执行漏洞（CVE-2019-1181/1182/1222/1226/）

Microsoft已修补远程桌面服务中的四个不同的严重漏洞：CVE-2019-1181，CVE-2019-1182，CVE-2019-1222，CVE-2019-1226。所有这些都可以被利用而无需身份验证或用户交互。


根据微软的说法，其中至少有两个（CVE-2019-1181和CVE-2019-1182）可以被认为是“可疑的”，并将它们等同于BlueKeep(CVE-2019-0708)。这些漏洞中至少有一个很可能会被快速武器化，并且应该为所有Windows系统优先打补丁。



2 Windows DHCP客户端/服务器远程代码执行漏洞（CVE-2019-1213）

当攻击者将特制数据包发送到DHCP服务器时，Windows Server DHCP服务中存在内存损坏漏洞。成功利用此漏洞的攻击者可以在DHCP服务器上运行任意代码。

要利用此漏洞，攻击者可以将特制数据包发送到DHCP服务器。



3 Windows Hyper-V远程执行代码漏洞（CVE-2019-0965/0720）

CVE-2019-0965:

当主机服务器上的Windows Hyper-V无法正确验证来宾操作系统上经过身份验证的用户的输入时，存在远程执行代码漏洞。


要利用此漏洞，攻击者可以在客户机操作系统上运行可能导致Hyper-V主机操作系统执行任意代码的特制应用程序。


成功利用此漏洞的攻击者可以在主机操作系统上执行任意代码。

CVE-2019-0720:

当主机服务器上的Windows Hyper-V网络交换机无法正确验证来宾操作系统上经过身份验证的用户的输入时，存在远程执行代码漏洞。


要利用此漏洞，攻击者可以在客户机操作系统上运行可能导致Hyper-V主机操作系统执行任意代码的特制应用程序。


成功利用此漏洞的攻击者可以在主机操作系统上执行任意代码。
