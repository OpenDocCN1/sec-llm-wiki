# 【漏洞预警】ProFTPD远程命令执行漏洞(CVE-2019-12815)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514364&idx=1&sn=ccf4f6991d6977f6a19597361ab58544&chksm=ce4633ecf931bafaecf1b9538ba86809739b836b2195c355b39a1e23fa69a3dd328b3a7c0232&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514364&idx=1&sn=ccf4f6991d6977f6a19597361ab58544&chksm=ce4633ecf931bafaecf1b9538ba86809739b836b2195c355b39a1e23fa69a3dd328b3a7c0232&scene=27#wechat_redirect)

2019年07月17日，ProFTPD正式修复了一个任意文件复制漏洞。**通过此漏洞，攻击者向ProFTPD服务器发送SITE CPFR和SITE CPTO这两个命令，可以在未经许可的条件下复制ProFTPD服务器上的任意文件。**

**漏洞名称**：ProFTPD远程命令执行漏洞预警

**威胁等级**：严重

**影响范围**：ProFTPD <= 1.3.5b

**漏洞类型**：远程代码执行漏洞

  

**ProFTPD服务器简介**

  

ProFTPD是一个开源，跨平台的FTP服务器软件，具有良好的平台兼容性，兼容大多数类Unix系统和Microsoft Windows。ProFTPD是目前Unix环境中最受欢迎的FTP服务器软件之一。

  

**漏洞描述**

  

ProFTPD默认安装了mod\_copy模块，并且在大多数Linux发行版系统中默认启用。在这种情况下，攻击者向受该漏洞影响的ProFTPD服务器发出CPFR和CPTO命令，则可在未经授权的情况下复制ProFTPD服务器上的任意文件。

  

**影响范围**

  

目前受影响的ProFTPD版本：  

**ProFTPD <= 1.3.5b  
**

  

**修复建议**

  

1\. 升级ProFTPD至1.3.6版本

2. 禁用ProFTPD的mod\_copy模块
