# 【漏洞预警】Atlassian Crowd远程命令执行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514357&idx=1&sn=3290c20257bce78757381268ae773d72&chksm=ce4633e5f931baf3e7189c8506b65d8b07c0ff09141177b3af57ce377c8067fdd8f624957762&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514357&idx=1&sn=3290c20257bce78757381268ae773d72&chksm=ce4633e5f931baf3e7189c8506b65d8b07c0ff09141177b3af57ce377c8067fdd8f624957762&scene=27#wechat_redirect)

近日，Atlassian Crowd远程命令执行漏洞的利用方式公开。**此漏洞由于Atlassian Crowd的com.atlassian.pdkinstall.PdkInstallFilter允许攻击者在/admin/uploadplugin.action路径下使用Multipart格式上传文件，攻击者可以利用此方式向服务器上传恶意文件,获取服务器权限,实现远程命令执行漏洞的利用。**

**漏洞名称**：Atlassian Crowd远程命令执行漏洞

**漏洞编号**：CVE-2019-11580

**威胁等级**：高危

**利用难度**：中等

  

**Atlassian Crowd介绍**

  

Crowd是一个简单易用的单一登录和用户管理软件，为用户提供一组用户名和密码来登录需要访问的所有应用。无缝集成 Jira、Confluence 和 Bitbucket 等所有 Atlassian 产品，为用户提供单一登录 (SSO) 体验。集中多个目录，将任意目录组合映射到单个应用，然后在同一位置管理身份验证权限。适用于 AD、LDAP、Microsoft Azure AD、Novell eDirectory 等的连接器。  

  

**漏洞分析**

  

此漏洞发生在Atlassian Crowd的com.atlassian.pdkinstall.PdkInstallFilter中，PdkInstallFilter.java中的doFilter()函数会在传入数据为Multipart类型时，执行extractJar()函数。

![](../Images/bd4fe644a35fc294f2916b7010f73e90.png)

extractJar()函数功能是将上传的文件作为临时文件，将生成的文件名传入到tmp参数中，并return回doFilter()函数进行判断。

![](../Images/41fd152b7323f8523221c3636b8bf886.png)

若返回的tmp参数不为null，则以tmp中存储的文件名更新插件，从而实现文件上传。

![](../Images/d46402fe6c96fbb7310ef8da1c461812.png)

  

**漏洞复现**

  

搭建 Atlassian Crowd 3.2.3环境。在/crowd/admin/uploadplugin.action路径下构造Multipart类型请求包，在file\_cdl参数中传入要上传的文件，最终效果如下图所示：

![](../Images/214fe87d2eac2994c56b3379c897bb22.png)
