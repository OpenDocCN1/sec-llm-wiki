# 【漏洞预警】Zimbra 邮件系统远程代码执行漏洞（CVE-2019-9621 CVE-2019-9670）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514291&idx=1&sn=29907d59aeb03c7d02666f551d5d885f&chksm=ce4633a3f931bab530d3a445e34fb79ab09c6d862f2241dfdeb40a7d46aa9b883512c46879db&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514291&idx=1&sn=29907d59aeb03c7d02666f551d5d885f&chksm=ce4633a3f931bab530d3a445e34fb79ab09c6d862f2241dfdeb40a7d46aa9b883512c46879db&scene=27#wechat_redirect)

近日，国外安全研究人员Tint0在博客中披露了一个针对Zimbra 邮件系统进行综合利用来达到远程代码执行效果的漏洞（CVE-2019-9621 CVE-2019-9670）。此漏洞的主要利用手法是通过XXE(XML 外部实体注入)漏洞读取localconfig.xml配置文件来获取Zimbra admin ldap password，接着通过SOAP AuthRequest 认证得到Admin Authtoken，最后使用全局管理令牌通过ClientUploader扩展上传Webshell到Zimbra服务器，从而实现通过Webshell来达到远程代码执行效果。

 

深信服安全团队第一时间响应并发布预警信息，并将持续跟踪事态进展。

  

**漏洞名称**

Zimbra 邮件系统远程代码执行漏洞

**威胁等级**

高危

**影响范围**

Zimbra Collaboration Suite < 8.7.11版本；

Zimbra Collaboration Suite 8.7.11 to 8.8.11 版本可配合Memcached进行利用；

**漏洞类型**

代码执行

**利用难度**

中

  

**千里百科-Zimbra 组件介绍**

  

Zimbra 是一套开源协同办公的套件，Zimbra主要提供Zimbra Collaboration Suite (简称ZCS)协作套件和 Zimbra Desktop 即Zimbra桌面程序。

  

**漏洞描述**

  

对于Zimbra Collaboration Suite 8.7.11版本，可通过XXE(XML 外部实体注入)漏洞读取localconfig.xml配置文件来获取Zimbra admin ldap password，接着通过SOAP AuthRequest 认证得到Admin Authtoken，最后使用全局管理令牌通过ClientUploader扩展上传Webshell到Zimbra服务器，从而实现通过Webshell来达到远程代码执行效果。

  

另外一种漏洞利用方式是通过普通用户的身份认证的特性配合ProxyServlet.doproxy()方法里的SSRF，完成SOAP AuthRequest 认证得到Admin Authtoken，最后使用全局管理令牌通过ClientUploader扩展上传Webshell到Zimbra服务器，从而实现通过Webshell来达到远程代码执行效果。

  

除此之外，在Zimbra Collaboration Suite 8.7.11 to 8.8.11版本使用了Memcached做缓存服务时，也可以利用SSRF 攻击Memcached缓存服务进行反序列化攻击，从而达到远程代码执行的效果。

 

**影响范围**

  

目前据统计，在全球范围内对互联网开放Zimbra的资产数量多达**8.2万**台，此应用受影响范围排前三位的分别是美国、巴西、印度尼西亚，其中归属中国地区的受影响资产数量为**2800台**以上。

  

目前受影响的Zimbra版本：

Zimbra Collaboration Suite < 8.7.11版本；

Zimbra Collaboration Suite 8.7.11 to 8.8.11 版本可通过Memcached配合进行利用；
