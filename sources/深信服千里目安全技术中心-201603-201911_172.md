# 【漏洞预警】Microsoft Exchange 任意用户提权攻击预警

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514271&idx=1&sn=66fc6e70fb87010243476a7785913e01&chksm=ce46338ff931ba99a621b5a77466186985189886947dcb1d2df5f84ace914a93e3d07b2d4b18&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514271&idx=1&sn=66fc6e70fb87010243476a7785913e01&chksm=ce46338ff931ba99a621b5a77466186985189886947dcb1d2df5f84ace914a93e3d07b2d4b18&scene=27#wechat_redirect)

自微软公布了一月份的安全更新不久，国外安全研究员发现了一个Exchange Server任意用户伪造漏洞（CVE-2018-8581），可利用此漏洞获取域服务管理控制权限，进一步获得域服务中的所有账户信息。目前，该漏洞的PoC和相关利用方式已被公布，且微软尚未对此漏洞发布安全补丁，使用了Microsoft Exchange的用户可参考千里目实验室提供的临时防护方案进行有效防护。

  

**千里百科**

 

Microsoft Exchange是一套微软公司的邮件服务器产品，能提供企业所需要的全部邮件服务功能，它不仅支持常规的SMTP/POP协议服务之外，还支持IMAP4、LDAP和NNTP协议，已被广泛应用于企事业单位。

  

当攻击者拥有目标邮件域内的任意邮件账户权限或能控制目标内网中的域成员计算机，并能有效发起Windows Name Resolution Spoofing攻击，则CVE-2018-8581漏洞就可以被利用。虽利用条件比较苛刻，但危害不容小觑。CVE-2018-8581漏洞被成功利用后可导致目标内网中的域控服务器和所有域成员计算机都被控制。

 

**影响版本**

  

Microsoft Exchange Server 2010

Microsoft Exchange Server 2013

Microsoft Exchange Server 2016

Microsoft Exchange Server 2019

  

**修复建议**

  

由于目前微软官方还未对此漏洞提供相关的安全补丁，但微软在安全公告中给出了临时缓解方案，对使用了Microsoft Exchange的用户可自行删除注册表中的“DisableLoopbackCheck”键来实现对该漏洞的防护。

  

具体操作步骤如下：

1、通过“Windows”+“R”，输入“cmd”打开命令解释器。

2、在CMD命令解释器中，输入如下命令来查看注册表中的“DisableLoopbackCheck”键值。若键值是否为1，则说明当前使用的Exchange Server存在安全风险。

1> 注册表查询命令如下：

reg query HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Lsa   

/v DisableLoopbackCheck

2> 注册表查询效果如下：  

![](../Images/63c82f09876b6e571d0377420b69f766.png)

3、在CMD命令解释器中，输入如下命令来删除注册表中的“DisableLoopbackCheck”键，从而实现对该漏洞的防护效果。  

1> 注册表键值删除命令如下：

reg delete HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Lsa   

/v DisableLoopbackCheck /f

2> 注册表键值删除效果如下：  

![](../Images/c0a528edc680ce412f9cc32dd3be2a8c.png)

温馨提示：建议在做修复处置之前，先对注册表做一次完整的备份，以备不时之需。
