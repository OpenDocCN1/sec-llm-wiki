一、本周漏洞总体态势


1. 总体态势跟踪


最近一周，深信服安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞529条。

 

其中Exploit database增长漏洞56条，Security focus增长漏洞113条，Packet Storm增长漏洞66条，CNNVD漏洞增长最多，共增长294条（占比55.6%）。

 

整体漏洞类型与利用情况占比如下。Web应用程序利用占比59%，应重点关注；拒绝服务和概念验证占比27%；远程攻击占比2%；本地特权升级利用占比9%；利用Shellcode存档占比3%；存档的安全文件本周无更新。

 

 

2. 重要厂商漏洞跟踪


最近一周，深信服安全团队所跟踪的50多个重点厂商和组件中，Microsoft和Adobe两家厂商发布安全更新。其中Microsoft发布安全更新1条，共更新漏洞51各；Adobe发布安全更新3条。详细更新信息如下。

 

Microsoft产品安全漏洞

产品介绍：

微软（Microsoft），是一家美国跨国科技公司，以研发、制造、授权和提供广泛的电脑软件服务业务为主。

漏洞更新情况：

2019年1月8日Microsoft发布1月份安全补丁更新。共修复了51个安全漏洞，其中有7个漏洞被标记为关键漏洞。


此次更新涉及产品主要是Microsoft Windows系统 、Microsoft Office、Microsoft Word、Microsoft Outlook 、Windows Jet 数据库、Chakra 脚本引擎、Windows Hyper-V  、Windows DHCP 客户端等微软主流应用软件和组件。


提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

参考链接：

https://www.bleepingcomputer.com/news/microsoft/microsoft-january-2019-patch-tuesday-includes-51-security-updates/


Adobe产品安全漏洞

产品介绍：

Adobe是世界领先的数字媒体和在线营销解决方案供应商。

漏洞更新情况：

1月8日，Adobe发布了适用于Windows，macOS，Linux和Chrome OS的Adobe Flash Player更新。这些更新解决了功能和性能错误，并且不包含安全修复程序。


1月8日，Adobe发布了Adobe Digital Editions的安全更新。此更新解决了一个重要漏洞。成功利用可能会导致当前用户的信息泄露。


1月8日，Adobe发布了Adobe Connect的安全更新。此更新解决了一个重要的会话令牌暴露漏洞。


提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

https://helpx.adobe.com/security.html


二、重要漏洞预警


ThinkPHP 5.0.* 远程代码执行漏洞

漏洞等级：高危

受影响系统：ThinkPHP <5.0.24

漏洞描述：ThinkPHP是一个快速、兼容而且简单的轻量级国产PHP开发框架，可以支持windows/Unix/Linux等服务器环境。该漏洞主要存在于Request (thinkphp/library/think/Request.php)类中，ThinkPHP 5.0.24以下版本由于在此类中未做好安全过滤，导致了一个ThinkPHP 5.0.*远程代码执行漏洞。 

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://github.com/top-think/framework/commit/4a4b5e64fa4c46f851b4004005bff5f3196de003


Discuz!命令执行漏洞

漏洞等级：高危

受影响系统：Discuz! X3.2

漏洞描述：Discuz!是一个以社区为基础的专业建站平台。Discuz!存在命令执行漏洞，攻击者可利用该漏洞获取网站服务器控制权。

解决方案：厂商尚未提供漏洞修补方案，请关注厂商主页及时更新：

http://www.comsenz.com/


Juniper Junos OS 安全漏洞

漏洞等级：中危

受影响系统：Juniper Junos OS

漏洞描述：Juniper Junos OS是一套专用于该公司的硬件系统的网络操作系统。该操作系统提供了安全编程接口和Junos SDK。Juniper Junos OS中存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（崩溃）。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://kb.juniper.net/InfoCenter/index?page=content&id=JSA10913&actp=METADATA


systemd-journald 本地拒绝服务漏洞

漏洞等级：高危

漏洞编号：CVE-2018-16864

受影响系统：Apache CouchDB 2.3.0

漏洞描述：systemd-journald是一个被systemd管理的进型日志管理服务，可以收集来自内核、系统早期启动阶段的日志、系统守护进程在启动和运行中的标准输出和错误信息，还有syslog的日志。systemd容易出现本地拒绝服务漏洞。成功利用此漏洞可能允许远程攻击者在应用程序的上下文中执行任意代码。 尝试失败可能会导致拒绝服务的情况。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.suse.com/support/kb/doc/?id=7023611


SIMATIC S7-300 CPUs 安全漏洞

漏洞等级：高危

漏洞编号：CVE-2018-16561

受影响系统：SIMATIC S7-300 CPUs <V3.X.16

漏洞描述：SIMATIC S7-300 CPUs是一款CPU（中央处理器）模块。SIMATIC S7-300 CPUs V3.X.16之前版本中存在存在安全漏洞，该漏洞源于程序没有正确的验证S7通信数据包。攻击者可通过发送特制的S7通信数据包利用该漏洞造成拒绝服务。 

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://cert-portal.siemens.com/productcert/pdf/ssa-306710.pdf


Microsoft Edge 安全漏洞

漏洞等级：高危

漏洞编号：CVE-2019-0565

受影响系统：Microsoft Windows 10

漏洞描述：Microsoft Windows 10是美国微软公司发布的操作系统。Edge是其中的一个系统附带的浏览器。Microsoft Edge存在远程内存破坏漏洞。攻击者可利用漏洞在当前登录用户的上下文中执行任意代码，损坏内存。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2019-0565


Microsoft Chakra Scripting Engine远程内存破坏漏洞

漏洞等级：高危

漏洞编号：CVE-2019-0539

受影响系统：Microsoft Windows 10

漏洞描述：Microsoft Windows 10是美国微软公司发布的操作系统。Edge是其中的一个系统附带的浏览器。ChakraCore是使用在Edge的一个开源的JavaScript引擎的核心部分，也可作为单独的JavaScript引擎使用。Microsoft Chakra Scripting Engine存在远程内存破坏漏洞。攻击者可利用漏洞在当前登录用户的上下文中执行任意代码。失败的攻击将导致拒绝服务条件。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0539


Microsoft Windows Hyper-V远程代码执行漏洞

漏洞等级：高危

漏洞编号：CVE-2019-0550

受影响系统：Microsoft Windows 10版本1703，Windows 10版本1803，Windows 10版本1809，Windows Server 2019，Windows 10版本1709，Windows 10，Windows 10版本1607，Windows Server 2016

漏洞描述：Microsoft Windows Server 2019等都是美国微软（Microsoft）公司发布的一系列操作系统。Windows Hyper-V是其中的一个虚拟化产品，支持在Windows中创建虚拟机。Microsoft Windows Hyper-V中存在远程代码执行漏洞，该漏洞源于主机服务器上的Hyper-V未能妥当地验证来自访客操作系统上的用户的输入。远程攻击者可利用该漏洞造成Hyper-V主机操作系统执行任意代码。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8489


IBM API Connect 安全漏洞

漏洞等级：中危

受影响系统：IBM API Connect 5.0.0.0-5.0.8.4

漏洞描述：IBM API Connect是一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。IBM API Connect 5.0.0.0版本至5.0.8.4版本中的管理服务器的基于角色的访问控制功能存在安全漏洞。攻击者可利用该漏洞获取高度敏感的信息。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10793601


BlogEngine 3.3 XML外部实体注入漏洞

漏洞等级：中危

受影响系统：BlogEngine 3.3

漏洞描述：BlogEngine.NET（博易） 是一款免费、开源的博客系统。2008年至今，本博基于 BlogEngine.NET 进行中文本地化，并将其努力在中国进行推广和应用。BlogEngine 3.3 存在XML外部实体注入漏洞。攻击者可利用该漏洞加载恶意外部文件实现攻击。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://blogengine.io/
