**一、本周漏洞总体态势**

  

**1. 总体态势跟踪**

  

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞234条。

![](../Images/fe6ffdd12769006a18dedc199170fc09.png)

其中Exploit database增长漏洞11条，Security focus增长漏洞26条，Packet Storm增长漏洞55条，CNNVD漏洞增长最多，共增长142条（占比60.7%）。  

![](../Images/f2d77de2805739043608d6345b57b736.png)

整体漏洞类型与利用情况占比如下。拒绝服务和概念验证占比最多为46%，应重点关注；Web应用程序利用占比27%；远程攻击占比18%；本地特权升级利用占比9%；利用Shellcode存档和存档的安全文件本周无更新。  

![](../Images/2714c8e7cf9b67b78891e8bd540ee3c9.png)

   

**2. 重要厂商漏洞跟踪**

  

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Debian，Adobe和Rad Hat 三家厂商发布安全补丁。其中Debian 发布安全更新1条，Adobe发布安全更新2条，Rad Hat更新漏洞4条。详细更新信息如下。

**Debian产品安全漏洞**

**产品介绍**：

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

**漏洞更新情况：**

2019年1月1日Debian 发布了一条安全更新，影响产品thunderbird。在Thunderbird中发现了多个安全问题，这可能导致执行任意代码或拒绝服务。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://www.debian.org/security/2019/dsa-4362

  

**Adobe产品安全漏洞**

**产品介绍**：

Adobe是世界领先的数字媒体和在线营销解决方案供应商。

**漏洞更新情况：**

1月3日，Adobe发布了适用于Windows和MacOS的Adobe Acrobat和Reader安全更新。影响产品包括Acrobat DC ，Acrobat Reader DC，Acrobat 2017，Acrobat Reader 2017。此次更新共涉及2个漏洞（CVE-2018-16011，CVE-2018-16018）。这些更新解决了严重漏洞。成功利用可能导致在当前用户的上下文中执行任意代码。Adobe建议用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://helpx.adobe.com/security/products/acrobat/apsb19-02.html

  

**Rad Hat 产品安全漏洞**

**产品介绍**：

Rad Hat（红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

**漏洞更新情况：**

本周Rad Hat共更新4条漏洞，其中中危漏洞3条，低危漏洞1条。影响产品包括Enterprise Linux ，Ceph Storage，Software Collections等。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://access.redhat.com/security/security-updates/#/security-advisories

  

**二、重要漏洞预警**

  

**IBM API Connect 权限许可和访问控制漏洞**

**漏洞等级**：中危

**受影响系统**：IBM API Connect 5.0.0.0-.0.8.4

**漏洞描述**：IBM API Connect（又名APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。IBM API Connect 5.0.0.0版本至5.0.8.4版本中存在提权漏洞。攻击者可利用该漏洞提升权限。  

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10792055

  

**Typo3 CMS pw\_highslide\_gallery Extension 0.3.1数据库披露漏洞**

**漏洞等级：**中危

**受影响系统**：Typo3 CMS pw\_highslide\_gallery Extension 0.3.1

**漏洞描述：**Typo3内容管理系统，是基于PHP4/PHP5+MYsql的内容管理系统(框架)(CMS/CMF),兼容PHP4和PHP5.数据库系统除Mysql之外，也能运行于Oracle, MS-SQL, ODBC, LDAP 等其它数据库系统。Typo3 CMS pw\_highslide\_gallery Extension 0.3.1存在数据库披露漏洞。攻击者利用该漏洞可获取数据库信息。

**解决方案：**目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://extensions.typo3.org/extension/download/pw\_highslide\_gallery/0.3.1/zip/

  

**Adobe Acrobat和Reader CVE-2018-19725安全绕过漏洞**

**漏洞等级**：中危

**受影响系统**：Adobe Acrobat和Reader

**漏洞描述**：Adobe Acrobat和Reader都是Adobe公司的产品。前者是一套PDF文件编辑和转换工具，后者是一套PDF文档阅读软件。Adobe Acrobat和Reader存在未指定的安全绕过漏洞。攻击者可以利用这些问题绕过某些安全限制并执行未经授权的操作，这可能会导致获得更高的权限。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://helpx.adobe.com/security/products/acrobat/apsb19-02.html

  

**Apache CouchDB 2.3.0 CSRF漏洞**

**漏洞等级**：高危

**受影响系统**：Apache CouchDB 2.3.0

**漏洞描述**：Apache CoucDB是开源数据库软件，它拥有易于使用和可扩展的体系结构。它有一个面向文档的NoSQL数据库体系结构，并以面向并发的语言Erlang实现; 它使用JSON存储数据，JavaScript使用MapReduce作为查询语言，使用HTTP作为API。Apache CouchDB版本2.3.0存在跨站点请求伪造漏洞。攻击者利用该漏洞在浏览器以CouchDB的Futon管理界面安全环境执行所注入的JavaScript。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://wiki.apache.org/couchdb/Breaking\_changes

  

**FreshRSS 1.11.1 Html注入漏洞**

**漏洞等级**：中危

**受影响系统**：FreshRSS 1.11.1

**漏洞描述**：FreshRSS 是一款自由免费的 RSS 订阅器,界面美观,支持导入/导出为 OPML 文件、过滤、标记、搜索等,有助于轻松查找和阅读文章。FreshRSS 1.11.1存在Html注入漏洞。攻击者利用该漏洞可实现Html注入攻击。

**解决方案**：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://freshrss.org/

  

**MacPaw CleanMyMac X 输入验证漏洞**

**漏洞等级**：高危

**受影响系统**：MacPaw CleanMyMac X 4.04

**漏洞描述**：MacPaw CleanMyMac X是美国MacPaw公司的一款专用于macOS平台的清理工具。该产品能够清除计算机中的垃圾文件、历史缓存和日志等。MacPaw CleanMyMac X 4.04版本中存在输入验证漏洞。本地攻击者可利用该漏洞以root用户身份修改文件系统。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://macpaw.com/cleanmymac

  

**Dell EMC RSA Archer 访问控制错误漏洞**

**漏洞等级**：中危

**受影响系统**：Dell EMC RSA Archer <6.5.0.1

**漏洞描述**：Dell EMC RSA Archer是一款企业IT治理和合规治理产品。该产品可以制定eGRC计划，用于管理企业风险、实现业务流程自动化等。Dell EMC RSA Archer 6.5.0.1之前版本中存在访问控制错误漏洞。远程攻击者可利用该漏洞绕过授权检查并获取被限制的用户信息的读取权限。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.dellemc.com/

  

**FasterXML Jackson-databind 安全漏洞**

**漏洞等级**：高危

**受影响系统**：FasterXML Jackson-databind 2.x<2.9.7

**漏洞描述**：FasterXML Jackson是一款用于Java的数据处理工具。Jackson-databind是其中的一个具有数据绑定功能的组件。FasterXML Jackson-databind 2.9.7之前的2.x版本中存在安全漏洞。远程攻击者可利用该漏洞执行服务器端请求伪造攻击。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://github.com/FasterXML/jackson/wiki/Jackson-Release-2.9.7

  

**libsixel 缓冲区错误漏洞**

**漏洞等级**：中危

**受影响系统**：libsixel 1.8.2

**漏洞描述**：libsixel是一个为DEC SIXEL图形和其他转换器程序提供编码/解码实现的软件包。libsixel 1.8.2版本中的loader.c文件的‘load\_jpeg()’函数存在基于堆的缓冲区越界读取漏洞。

**解决方案**：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://github.com/saitoha/libsixel

  

**Poppler 安全漏洞**

**漏洞等级**：中危

**受影响系统**：Poppler 0.72.0

**漏洞描述**：Poppler是一个用于生成PDF的C++类库，该库是从Xpdf（PDF阅读器）继承而来。Poppler 0.72.0版本中的Object::dictLookup存在安全漏洞，该漏洞源于程序未能检查dict数据类型。攻击者可利用该漏洞造成拒绝服务。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://gitlab.freedesktop.org/poppler/poppler/commit/de0c0b8324e776f0b851485e0fc9622fc35695b7
