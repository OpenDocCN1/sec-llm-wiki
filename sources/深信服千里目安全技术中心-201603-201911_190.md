**一、本周漏洞总体态势**

  

**1. 总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞442条。

![](../Images/9b76cdb3833e939d1a4bb26066934b88.png)

其中Exploit database增长漏洞35条，Security focus增长漏洞52条，Packet Storm增长漏洞61条，CNNVD漏洞增长最多，共增长294条（占比66.5%）。  

![](../Images/6276891cfbf6e304850db989a87bee91.png)

整体漏洞类型与利用情况占比如下。本地特权升级利用，web应用程序利用和拒绝服务概念验证分别占比最多为31%，26%和23%，应重点关注；远程攻击占比11%；利用Shellcode存档占比3%，存档的安全文件均占比6%。  

![](../Images/81aef1b7063b52671a5a1e3b53535de0.png)

   

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Rad Hat和Debian两家厂商发布安全补丁。其中Rad Hat更新漏洞12条（高危2条），Debian 发布安全更新3条。详细更新信息如下。

**Rad Hat 产品安全漏洞**

**产品介绍：**

Rad Hat（红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

**漏洞更新情况：**

本周Rad Hat共更新12条漏洞，其中高危漏洞2条，中危漏洞2条，低危漏洞8条。影响产品包括Enterprise Linux ，Gluster Storage Server，Satellite，Ansible Engine等。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://access.redhat.com/security/security-updates/#/security-advisories

  

**Debian产品安全漏洞**

**产品介绍：**

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

**漏洞更新情况：**

12月19日Debian 发布了一条安全更新，影响产品openssl1.0。此次更新涉及到的漏洞包括CVE-2018-0732, CVE-2018-0734, CVE-2018-0737, CVE-2018-5407。在安全套接字层工具包OpenSSL中发现了几个本地侧通道攻击和通过大的Diffie-Hellman参数拒绝服务。

  

12月20日Debian 发布了一条安全更新，影响产品netatalk。此次更新涉及到的漏洞包括CVE-2018-1160。Jacob Baines在Netatalk中处理DSI Opensession命令时发现了一个缺陷，Netatalk是AppleTalk协议套件的一个实现，允许未经身份验证的用户以root权限执行任意代码。

  

12月20日Debian 发布了一条安全更新，影响产品libapache-mod-jk。此次更新涉及到的漏洞包括CVE-2018-11759。Raphael Arrouas和Jean Lejeune在mod\_jk中发现了一个访问控制绕过漏洞，这是Tomcat Java servlet引擎的Apache连接器。通过将mod\_jk升级到新的上游版本1.2.46（包括其他更改）来解决此漏洞。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.debian.org/security/#DSAS

  

**二、重要漏洞预警**

  

**Cisco Adaptive Security Appliances Software authorization访问控制漏洞**

**漏洞等级**：高危

**受影响系统**：Cisco ASA Software

**漏洞描述**：Cisco Adaptive Security Appliances（ASA，自适应安全设备）Software是一套运行于防火墙中的操作系统。authorization subsystem是其中的一个授权子系统。Cisco ASA Software中的authorization子系统存在提权漏洞，该漏洞源于程序没有正确地验证用户权限。远程攻击者可借助web管理接口利用该漏洞获取提升的权限。  **解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181219-asa-privesc

  

**IBM Notes和Domino 权限许可和访问控制漏洞**

**漏洞等级**：高危

**受影响系统**：IBM Domino 9.0.1版本至9.0.1 FP10 IF4版本，9.0版本至9.0 IF4版本；IBM Notes 9.0.1版本至9.0.1 FP10 IF5版本，9.0版本至9.0 IF4版本

**漏洞描述**：IBM Notes和Domino都是美国IBM公司的协同办公软件。该软件具备电子邮件、日历、日程安排等办公功能。基于Windows平台的IBM Notes和Domino中的Notes System Diagnostic（NSD）服务存在提权漏洞。攻击者可通过共享内存IPC发送特制的命令行利用该漏洞执行恶意的dll文件。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.ibm.com/support/docview.wss?uid=ibm10743405

  

**Apache Hadoop 安全漏洞**

**漏洞等级**：高危

**受影响系统**：Apache Hadoop

**漏洞描述**：Apache Hadoop是一套开源的分布式系统基础架构，它能够对大量数据进行分布式处理，并具有高可靠性、高扩展性、高容错性等特点。Apache Hadoop中存在安全漏洞。本地攻击者可利用该漏洞在系统上获取提升的权限，并以root权限执行任意命令。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.apache.org/

  

**weixin-java-tools 安全漏洞**

**漏洞等级**：高危

**受影响系统**：weixin-java-tools 3.2.0版本

**漏洞描述**：weixin-java-tools是一款基于Java的微信软件开发工具包。该产品用于支持微信支付、开放平台、公众号、企业微信/企业号和小程序等微信功能的后端开发。weixin-java-tools 3.2.0版本中的BaseWxPayResult.java文件的getXmlDoc方法存在XML外部实体注入漏洞。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://github.com/Wechat-Group/weixin-java-tools/commit/6272639f02e397fed40828a2d0da66c30264bc0e

  

**Android Camera子系统缓冲区错误漏洞**

**漏洞等级**：高危

**受影响系统**：Android中的Camera子系统

**漏洞描述**：Android是一套以Linux为基础的开源操作系统。Camera subsystem是其中的一个照相机子系统。Android中的Camera子系统存在缓冲区溢出漏洞。攻击者可利用该漏洞执行任意代码或造成拒绝服务。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.codeaurora.org/security-bulletin/2018/12/03/december-2018-code-aurora-security-bulletin

  

**McAfee Application Control和Change Control 安全漏洞**

**漏洞等级**：中危

**受影响系统**：McAfee Application Control和Change Control 7.0.1及之前版本

**漏洞描述**：McAfee Application Control和Change Control都是美国迈克菲（McAfee）公司的软件。Application Control是一套程序管控软件，可阻止设备运行未经授权的应用程序。Change Control是一套变更管控软件，可拦截对应用程序的未授权变更。McAfee Application Control和Change Control 7.0.1及之前版本中存在安全漏洞。攻击者可借助ASP.NET form利用该漏洞执行被列入黑名单的文件。 

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://kc.mcafee.com/corporate/index?page=content&id=SB10261

  

**OpenSSL CVE-2018-0739拒绝服务漏洞**

**漏洞等级**：中危

**受影响系统**：OpenSSL

**漏洞描述**：OpenSSL 是一个安全套接字层密码库，囊括主要的密码算法、常用的密钥和证书封装管理功能及SSL协议，并提供丰富的应用程序供测试或其它目的使用。OpenSSL存在拒绝服务漏洞。攻击者可以利用此问题导致拒绝服务的情况。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.openssl.org/news/secadv/20180327.txt

  

**NTP CVE-2018-12327堆栈缓冲区溢出漏洞**

**漏洞等级**：中危

**受影响系统**：NTP 4.2.8p11

**漏洞描述**：NTP服务器【Network Time Protocol（NTP）】是用来使计算机时间同步化的一种协议，它可以使计算机对其服务器或时钟源（如石英钟，GPS等等)做同步化。NTP存在基于堆栈的缓冲区溢出漏洞，因为它无法正确绑定 - 检查用户提供的数据，然后再将其复制到不够大的缓冲区中。攻击者可以利用此问题在受影响的应用程序的上下文中执行任意代码。Failedexploit尝试将导致拒绝服务条件

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.ntp.org/
