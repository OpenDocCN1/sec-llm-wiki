# 还在用工具激活系统？小心被当做矿机！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514253&idx=1&sn=ff7295c5def2b3a5a8cff6040fa67c73&chksm=ce46339df931ba8b9c0f843b29a07cab9c470c724c5466dbb7a1b92ca10376f7d692ae6352eb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514253&idx=1&sn=ff7295c5def2b3a5a8cff6040fa67c73&chksm=ce46339df931ba8b9c0f843b29a07cab9c470c724c5466dbb7a1b92ca10376f7d692ae6352eb&scene=27#wechat_redirect)

  

**一、现象描述**

近日，深信服EDR安全团队捕获到一个伪装成激活软件Windows Loader的病毒样本。经分析，该样本并没有激活功能，其主要功能是安装广告软件以及挖矿程序。

挖矿程序会拉起系统进程并在其中注入挖矿代码，并循环监控taskmgr.exe进程，如果检测到taskmgr.exe进程则终止挖矿，使得受害者比较难以察觉。

![](../Images/c842fd927b30112fe6292b89707485a7.png)

**2.1 病毒母体**

**2.4 activation.exe**

首先在Local目录下新建cypjMERAky文件夹并将自己拷贝到下面。

![](../Images/eef082a31e7e40c1c4b384b4d1c6105e.png)

  

添加注册表自启动项。

![](../Images/a1cffdf08bb0288e40158f718dcf6a8e.png)

  

![](../Images/bf3b37e32ca07ddf46c79ee08433c0aa.png)

  

检测是否存在taskmgr.exe进程。

![](../Images/4e625d4b5e71096762e25360ebc9c396.png)

  

如果taskmgr.exe进程不存在则拉起系统进程wuapp.exe，参数为“ -a cryptonight -o stratum+tcp://xmr.pool.minergate.com:45560 -u minepool@gmx.com -p x -t 2”。

![](../Images/8cc25aa24cfd17cd411e92fd13dba09b.png)

  

将挖矿程序注入到wuapp.exe进程。

![](../Images/adee94a06e7bb0e7c29b4178489d3441.png)

  

挖矿程序为开源的cpuminer-multi 1.2-dev。

![](../Images/c9a72212d8dd9ea6891321d1746dcd64.png)

  

进入循环，守护注册表自启动项，并检测taskmgr.exe进程，如果检测到则终止wuapp.exe。

![](../Images/d2944c6e889485a73caf894da1e0ea50.png)

  

**三、解决方案**

（1）不从不明网站下载软件，不要点击来源不明的邮件以及附件；

（2）及时给电脑打补丁，修复漏洞；

（3）尽量关闭不必要的文件共享权限以及关闭不必要的端口，如：445,135,139,3389等；

（4）安装专业的终端/服务器安全防护软件，深信服EDR能够有效查杀该病毒。
