**一、本周漏洞总体态势**

    

  

**1\. 总体态势跟踪**

  

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞209条。

![](../Images/3b2ea68dc00980d75c9185e34b7c7786.png)

其中Exploit database增长漏洞12条，Security focus增长漏洞26条，Packet Storm增长漏洞25条，CNNVD漏洞增长最多，共增长146条（占比69.8%）。  

![](../Images/4aefbf5c505430dc3446de1f566076fd.png)

整体漏洞类型与利用情况占比如下。web应用程序利用占比最多为42%，应重点关注；拒绝服务概念验证和本地特权升级利用均占比25%；存档的安全文件占比8%；远程攻击占比和利用Shellcode存档本周无更新漏洞。  

![](../Images/3255c0a997faeeae1d22ba90910468d7.png)

   

**2. 重要厂商漏洞跟踪**

  

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Adobe和Debian两家厂商发布安全补丁。其中Adobe更新漏洞1条，Debian 发布3条漏洞更新。详细更新信息如下。

**Adobe产品安全漏洞**

 

**产品介绍**：

Adobe是世界领先的数字媒体和在线营销解决方案供应商。11月20日Adobe发布安全更新。

**漏洞更新情况：**

Adobe已发布适用于Windows，macOS，Linux和Chrome OS的Adobe Flash Player安全更新（ CVE-2018-15981）。这些更新解决了Adobe Flash Player 31.0.0.148及更早版本中的严重漏洞。Adobe Flash Player中存在一个漏洞。远程用户可以在目标用户的系统上执行任意代码。远程用户可以创建特制内容，当由目标用户加载时，将触发类型混淆错误并在目标用户的系统上执行任意代码。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://helpx.adobe.com/security/products/flash-player/apsb18-44.html

  

**Debian产品安全漏洞**

 

**产品介绍**：

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

**漏洞更新情况：**

11月19日Debian 发布了一条安全更新，影响产品mariadb-10.1。此次更新涉及到的漏洞包括。CVE-2018-2562, CVE-2018-2612, CVE-2018-2622, CVE-2018-2640, CVE-2018-2665, CVE-2018-2668, CVE-2018-2755, CVE-2018-2761, CVE-2018-2766, CVE-2018-2767, CVE-2018-2771, CVE-2018-2781, CVE-2018-2782, CVE-2018-2784, CVE-2018-2787, CVE-2018-2813, CVE-2018-2817, CVE-2018-2819, CVE-2018-3058, CVE-2018-3063, CVE-2018-3064, CVE-2018-3066, CVE-2018-3081, CVE-2018-3143, CVE-2018-3156, CVE-2018-3174, CVE-2018-3251, CVE-2018-3282。在MariaDB数据库服务器中发现了几个漏洞。 需要通过将MariaDB升级到新的上游版本10.1.37来修复这些漏洞。

  

11月23日Debian 发布了一条安全更新，影响产品liblivemedia。此次更新涉及到的漏洞包括CVE-2018-4013。发现在liveMedia中的缓冲区溢出，一组用于多媒体流的C ++库可能导致在解析格式错误的RTSP流时执行任意代码。

  

11月24日Debian 发布了一条安全更新，影响产品roundcube。此次更新涉及到的漏洞包括CVE-2018-19206。Aidan Marlin发现，用于IMAP服务器的基于AJAX的可上网的webmail解决方案roundcube在处理无效的样式标记内容时容易出现跨站点脚本漏洞。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://www.debian.org/security/#DSAS

   

    

**二、重要漏洞预警**

    

  

**Apache HTTP Server 安全漏洞**

 

**漏洞等级**：中危

**受影响系统**：Apache HTTP Server 2.4.18，2.4.20，2.4.23，2.4.29，2.4.33，2.4.30

**漏洞描述**：Apache HTTP Server是一款开源网页服务器。该服务器具有快速、可靠且可通过简单的API进行扩充的特点。Apache HTTP Server中存在拒绝服务漏洞。远程攻击者可通过发送特制的HTTP/2请求利用该漏洞造成拒绝服务。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://httpd.apache.org/security/vulnerabilities\_24.html

  

**Huawei Emily-AL00A 安全漏洞**

 

**漏洞等级**：中危

**受影响系统**：Huawei Emily-AL00A 8.1.0.167

**漏洞描述**：Huawei Emily-AL00A是华为公司的一款智能手机设备。Huawei Emily-AL00A 8.1.0.167版本中存在安全漏洞，该漏洞源于程序没有正确的处理智能短信验证码。攻击者可通过诱使用户访问恶意网站或恶意App，并进行用户注册利用该漏洞后造成信息泄露。  

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20181121-02-smartphone-cn

  

**Pixman 数字错误漏洞**

 

**漏洞等级**：中危

**受影响系统**：Pixman 0.32.8之前版本

**漏洞描述**：Pixman是一个开源的用于像素操作的软件库，它提供图像合成、图像光栅化等功能。Pixman 0.32.8之前版本中的‘general\_composite\_rect()’函数存在整数溢出漏洞。攻击者可利用该漏洞造成使用pixman的应用程序崩溃或执行任意代码。 

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://bugs.freedesktop.org/show\_bug.cgi?id=92027

  

**Discuz! 跨站脚本漏洞**

 

**漏洞等级**：高危

**受影响系统**：Discuz! X3.4

**漏洞描述**：Discuz!是一款华人地区非常流行的Web论坛程序。Discuz! X3.4版本中存在跨站脚本漏洞，该漏洞源于admincp/admincp\_setting.php和template\\default\\common\\footer.htm文件没有正确的处理statcode字段。远程攻击者可借助admin.php文件利用该漏洞注入任意的Web脚本或HTML。

**解决方案**：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.discuz.net/

  

**IBM WebSphere Application Server 安全漏洞**

 

**漏洞等级**：高危

**受影响系统**：IBM WAS 9.0

**漏洞描述**：IBM WebSphere Application Server（WAS）是美国IBM公司开发并发行的一款应用服务器产品，它是Java EE和Web服务应用程序的平台，也是IBM WebSphere软件平台的基础。IBM WAS 9.0版本中存在XML外部实体注入漏洞。远程攻击者可利用该漏洞泄露敏感信息或消耗内存资源。 

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10738721

  

**Linux kernel 安全漏洞**

 

**漏洞等级**：高危

**受影响系统**：Linux kernel 4.19.2及之前版本

**漏洞描述**：Linux kernel是美国Linux基金会发布的开源操作系统Linux所使用的内核。Linux kernel 4.19.2及之前版本中的arch/x86/kvm/x86.c文件的‘vcpu\_scan\_ioapic’函数存在安全漏洞。本地攻击者可借助特制的系统调用利用该漏洞造成拒绝服务（空指针逆向引用）。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.kernel.org/

  

**PHP 安全漏洞**

 

**漏洞等级**：中危

**受影响系统**：PHP 5.x版本至7.1.24版本

**漏洞描述**：PHP是PHP Group和开放源代码社区共同维护的一种开源的通用计算机脚本语言。该语言主要用于Web开发，支持多种数据库及操作系统。PHP 5.x版本至7.1.24版本中的ext/standard/var\_unserializer.c文件存在安全漏洞。攻击者可利用该漏洞造成拒绝服务（应用程序崩溃）。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://bugs.php.net/bug.php?id=77177

  

**GreenCMS 跨站请求伪造漏洞**

 

**漏洞等级**：中危

**受影响系统**：GreenCMS 2.3.0603

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www.greencms.net/
