**一、本周漏洞总体态势**

    

  

**1.总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞540条。

![](../Images/79b533bd4aeded342b2948a83de1ad82.png)

其中Exploit database增长漏洞75条，Security focus增长漏洞100条，Packet Storm增长漏洞85条，CNNVD漏洞增长最多，共增长280条（占比51.8%）。  

![](../Images/38950cb84334e73429867f2f0b7539d5.png)

整体漏洞类型与利用情况占比如下。web应用程序利用占比最多为73%，应重点关注；拒绝服务概念验证占比15%；本地特权升级利用占比8%；远程攻击占比1%；利用Shellcode存档占比1%；存档的安全文件占比1%。  

![](../Images/1614c6d699f8766aa8a8d7e48d5a7d58.png)

  

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Microsoft，Adobe和Debian三家厂商发布安全补丁。其中Microsoft更新漏洞62条（高危13条），Adobe更新漏洞3条，Debian 发布2条漏洞更新。详细更新信息如下。

**Microsoft产品安全漏洞**

 

**产品介绍：**

微软（Microsoft），是一家美国跨国科技公司，以研发、制造、授权和提供广泛的电脑软件服务业务为主。

**漏洞更新情况：**

2018年11月13日Microsoft发布11月份安全补丁更新。共修复了62个安全漏洞，其中有13个漏洞被标记为关键漏洞。

  

此次更新涉及产品主要是浏览器的脚本引擎和Office软件等微软主流产品。

  

同时修复了黑客可利用10月份更新进行提权的漏洞；

  

修复了之前已被利用的0day漏洞CVE-2018-8589，此漏洞为卡巴斯基实验室发现，据称已被多个APT组织利用，漏洞为提权漏洞，影响系统中的Win32k组件；

  

推特上披露的0day漏洞（任意删除文件的那个）暂时还未修复，近期应重点关注。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.bleepingcomputer.com/news/security/microsoft-november-2018-patch-tuesday-fixes-12-critical-vulnerabilities/

  

**Adobe产品安全漏洞**

 

**产品介绍：**

Adobe是世界领先的数字媒体和在线营销解决方案供应商。11月13日Adobe发布安全更新。

**漏洞更新情况：**

适用于Windows，macOS，Linux和Chrome OS的Adobe Flash Player安全更新。这些更新解决了Adobe Flash Player 31.0.0.122及更早版本中的一个重要漏洞。成功利用可能导致信息披露。

  

适用于Adobe Acrobat和Reader for Windows的安全更新，以解决重要漏洞。成功利用可能会导致无意中泄露用户的哈希NTLM密码。

  

适用于Windows和macOS的Photoshop CC更新。 这些更新解决了Photoshop CC 19.1.6及更早版本19.x版本中的一个重要漏洞。成功利用可能导致信息披露。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://helpx.adobe.com/security/products/flash-player/apsb18-39.html

  

**Debian产品安全漏洞**

 

**产品介绍：**

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

**漏洞更新情况：**

11月13日Debian 发布了一条安全更新，影响产品ceph。此次更新涉及到的漏洞包括CVE-2017-7519, CVE-2018-10861, CVE-2018-1128, CVE-2018-1129。Ceph是一个分布式存储和文件系统，其中发现了多个漏洞：cephx身份验证协议可以重放攻击并且错误地计算签名，“ceph mon”没有验证池操作的功能（导致潜在的损坏或删除快照映像） libradosstriper中的格式字符串漏洞可能导致拒绝服务。

  

11月18日Debian 发布了一条安全更新，影响产品chromium-browser。此次更新涉及到的漏洞包括CVE-2018-17478。cloudfuzzer在chromium的v8 javascript库中发现了越界限制内存访问问题。此更新还修复了先前安全上载引入的两个问题。已经恢复了对arm64的支持，并且gconf-service不再是包依赖。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.debian.org/security/#DSAS

  

**二、重要漏洞预警**

  

**Siemens SIMATIC S7-400 输入验证漏洞**

 

**漏洞等级**：高危

**受影响系统**：Siemens SIMATIC S7-400

**漏洞描述**：Siemens SIMATIC S7-400是一款用于制造和过程自动化领域的可编程逻辑控制器产品。Siemens SIMATIC S7-400中存在输入验证漏洞。攻击者可通过向TCP 102端口发送特制的数据包利用该漏洞造成拒绝服务。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.industry.siemens.com/cs/ww/en/view/109476571  

  

**Cybozu Dezie 路径遍历漏洞**

 

**漏洞等级**：高危

**受影响系统**：Cybozu Dezie 8.0.2版本至8.1.2版本

**漏洞描述**：Cybozu Dezie是一套基于Web的数据库系统。Cybozu Dezie 8.0.2版本至8.1.2版本中存在目录遍历漏洞。远程攻击者可利用该漏洞删除服务器上的任意文件。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://kb.cybozu.support/article/34089/

  

**Microsoft Windows 权限许可和访问控制漏洞**

 

**漏洞等级**：高危

**受影响系统**：Microsoft Windows

**漏洞描述**：Microsoft Windows中存在提权漏洞，该漏洞源于程序没有正确的处理对高级本地过程调用 (ALPC)的调用。本地攻击者可通过登录系统并运行特制的应用程序利用该漏洞在本地系统的安全上下文中执行任意代码。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8584

  

**Microsoft DirectX 权限许可和访问控制漏洞**

 

**漏洞等级**：高危

**受影响系统**：Microsoft Windows Server

**漏洞描述**：Microsoft Windows 是一系列操作系统，DirectX是其中的一个多媒体系统链接库。Microsoft DirectX中存在提权漏洞，该漏洞源于程序没有正确的处理内存中的对象。本地攻击者可通过登录系统并运行特制的应用程序利用该漏洞在内核模式下执行任意代码。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8561

  

**IBM MQ库安全漏洞**

 

**漏洞等级**：高危

**受影响系统**：IBM MQ 8.0.0.0版本8.0.0.10版本

**漏洞描述**：IBM M是一款消息传递中间件产品。该产品主要为面向服务的体系结构（SOA）提供可靠的、经过验证的消息传递主干网。IBM MQ库中存在安全漏洞。攻击者可利用该漏洞在系统上提升权限，并以root的权限执行注入的代码。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10734447

  

**Huawei nova 2 Plus和Mate9 Pro 安全漏洞**

 

**漏洞等级**：中危

**受影响系统**：Huawei nova 2 Plus和Mate9 Pro

**漏洞描述**：Huawei nova 2 Plus和Mate9 Pro都是华为公司的智能手机产品。Huawei nova 2 Plus 8.0.0.350之前版本和Mate9 Pro 8.0.0.363之前版本中存在安全漏洞，该漏洞源于系统对权限校验不充分。攻击者可通过数据线将该手机与另一部手机相连并执行一系列操作利用该漏洞绕过FRP。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.huawei.com/cn/psirt/security-advisories/huawei-sa-20181114-01-smartphone-cn

  

**SwitchVPN for MacOS 权限许可和访问控制漏洞**

 

**漏洞等级**：中危

**受影响系统**：SwitchVPN for MacOS 2.1012.03版本

**漏洞描述**：SwitchVPN for MacOS是一款基于macOS平台的VPN软件。SwitchVPN for MacOS 2.1012.03版本中存在提权漏洞。攻击者可利用该漏洞提升权限至root。

**解决方案**：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://switchvpn.net/

  

**Android 权限许可和访问控制漏洞**

 

**漏洞等级**：中危

**受影响系统**：Android 9版本

**漏洞描述**：Android是一套以Linux为基础的开源操作系统。Android 9版本中的aacdecode.cpp文件的CAacDecoder\_DecodeFrame存在提权漏洞，该漏洞源于程序缺少边界检查。远程攻击者可利用该漏洞获取提升的权限（越界写入）。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://source.android.com/security/bulletin/2018-11-01
