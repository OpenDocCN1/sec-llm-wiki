**一、本周漏洞总体态势**

    

  

**1.总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞323条。

![](../Images/9b855f0e61653e103a431b2657c81327.png)

其中Exploit database增长漏洞32条，Security focus增长漏洞45条，Packet Storm增长漏洞40条，CNNVD漏洞增长最多，共增长206条（占比63.8%）。  

![](../Images/b3aa55443d7ec6803a9ba4cef26d5d64.png)

整体漏洞类型与利用情况占比如下。web应用程序利用占比最多为50%，应重点关注；拒绝服务概念验证占比22%；本地特权升级利用占比19%；远程攻击占比9%；利用Shellcode存档和存档的安全文件本周无更新。  

![](../Images/7a06819da3aba9bd68fb9e1918eb217d.png)

   

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Debian，VMware和Rad Hat三家厂商发布安全补丁。其中Debian 发布4条漏洞更新，VMware更新漏洞2条，Rad Hat更新漏洞25条（高危7条）。详细更新信息如下。

**Debian产品安全漏洞**

 

**产品介绍**：

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

**漏洞更新情况：**

11月8日Debian 发布了一条安全更新，影响产品nginx。此次更新涉及到的漏洞包括CVE-2018-16843, CVE-2018-16844, CVE-2018-16845。在Nginx中发现了三个漏洞，Nginx是一个高性能的Web和反向代理服务器，可能导致在处理HTTP / 2或ngx\_http\_mp4\_module模块中的服务器内存泄露时拒绝服务。

  

11月10日Debian 发布了一条安全更新，影响产品ghostscript。此次更新涉及到的漏洞包括CVE-2018-11645, CVE-2018-17961, CVE-2018-18073, CVE-2018-1828。Ghostscript中存在几个漏洞，可能导致拒绝服务，信息披露，任意大小文件或者处理格式错误的Postscript文件时执行任意代码。

  

11月10日Debian 发布了一条安全更新，影响产品thunderbird。此次更新涉及到的漏洞包括CVE-2018-12389, CVE-2018-12390, CVE-2018-12392, CVE-2018-12393。在Thunderbird中发现了多个安全问题，可能导致执行任意代码或拒绝服务。

  

11月11日Debian 发布了一条安全更新，影响产品qemu。此次更新涉及到的漏洞包括CVE-2018-10839, CVE-2018-17962, CVE-2018-17963。由QEMU（一种快速处理器仿真器）仿真的网卡中的数据包处理中的整数溢出可能导致拒绝服务。

  

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://www.debian.org/security/#DSAS

  

**VMware产品安全漏洞**

 

**产品介绍**：

VMware，是全球云基础架构和移动商务解决方案厂商，提供基于VMware的解决方案， VMWare虚拟机软件是一个“虚拟PC”软件,它使你可以在一台机器上同时运行二个或更多Windows、DOS、LINUX系统。

**漏洞更新情况：**

11月9日，VMware ESXi中报告了两个漏洞，权限升级漏洞（CVE-2018-6981），来宾系统上的远程用户可以在主机系统上获得提升的权限；信息泄露漏洞（CVE-2018-6982）来宾系统上的远程用户可以获取潜在的敏感信息。启用了vmxnet3的系统会受到影响。

  

VMware已发布修复程序。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://securitytracker.com/id/1042055

Rad Hat（红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

**二、重要漏洞预警**

    

**多款Cisco Meraki产品权限许可和访问控制漏洞**

 

**漏洞等级**：高危

**受影响系统**：Cisco Meraki

**漏洞描述**：Cisco Meraki MR等都是无线网络接入点设备。多款Cisco Meraki产品的本地状态页面功能中存在权限许可和访问控制漏洞。远程攻击者可利用该漏洞修改设备配置文件。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181107-meraki

  

**Cisco Stealthwatch Enterprise 访问控制错误漏洞**

 

**漏洞等级**：高危

**受影响系统**：Cisco Stealthwatch Enterprise 6.10.2及之前版本

**漏洞描述**：Cisco Stealthwatch Enterprise是一套企业网络安全防护解决方案。该产品具有安全事件分析、网络分段管理和数据保护等功能。Cisco Stealthwatch Enterprise 6.10.2及之前版本中的Stealthwatch管理控制台（SMC）存在访问控制错误漏洞，该漏洞源于不安全的系统配置。远程攻击者可通过发送特制的HTTP请求利用该漏洞绕过身份验证，进而在受影响的系统上以管理权限执行任意操作。  

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181107-smc-auth-bypass

  

**Cisco Unity Express 安全漏洞**

 

**漏洞等级**：高危

**受影响系统**：Cisco Unity Express

**漏洞描述**：Cisco Unity Express是一套语音通信解决方案。该产品包括语音邮件和交互式语音应答等功能。Cisco CUE 9.0.6之前版本中存在安全漏洞。远程攻击者可利用该漏洞以root用户的权限执行任意shell命令。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181107-cue

  

**IBM DB2 权限许可和访问控制漏洞**

 

**漏洞等级**：中危

**受影响系统**：IBM DB2 9.7

**漏洞描述**：IBM DB2是一套关系型数据库管理系统。该系统的执行环境主要有UNIX、Linux、IBM i、z/OS以及Windows服务器版本。基于Linux和UNIX平台的多个版本的IBM DB2（包括DB2 Connect服务器）的所有修订包中存在提权漏洞。攻击者可通过加载恶意共享库利用该漏洞获取对DB2实例账户的完整访问权限。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

http://www.ibm.com/support/docview.wss?uid=ibm10733122

  

 

**Android System 信息泄露漏洞**

https://source.android.com/security/bulletin/2018-11-01.html

http://www.securityfocus.com/bid/105849

**Dell OpenManage Network Manager 6.2.0.51 SP3权限提升**

 

**漏洞等级**：中危

**受影响系统**：Dell OpenManage Server Administrator

**漏洞描述**：Dell OpenManage Server Administrator是一套系统管理解决方案。该方案支持在线诊断、系统运行情况检测、设备管理等。Dell OpenManage Network Manager公开了一个可以使用默认凭据访问的MySQL侦听器。此MySQL服务以root用户身份运行，因此攻击者可以利用此配置来部署后门并将权限升级到root帐户。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.dell.com/support/article/cn/zh/cndhs1/sln314610/dell-openmanage-network-manager-security-vulnerabilities?lang=en

**受影响系统**：Schneider Electric BMX P34 CPU B

**Microsoft Internet Explorer 11 - 空指针解除引用漏洞**

 

**漏洞等级**：中危

**受影响系统**：Microsoft Internet Explorer 11

**漏洞描述**：Microsoft Windows是一系列操作系统。Internet Explorer是微软公司推出的一款网页浏览器。Microsoft Internet Explorer 11存在空指针解除引用漏洞。崩溃是由于在解析格式错误的DOM元素时'Tree :: Notify\_InvalidateDisplay'函数内的NULL指针取消引用访问冲突引起的。

**解决方案**：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://www.microsoft.com

**参考链接**：

https://www.exploit-db.com/exploits/45778/

  

**IBM API Connect 安全漏洞**

 

**漏洞等级**：高危

**受影响系统**：IBM API Connect 5.0.0.0至5.0.8.4版本和2018.1和2018.3.6版本

**漏洞描述**：IBM API Connect（又名APIConnect）是美国IBM公司的一套用于管理API生命周期的集成解决方案。该方案支持创建、运行、管理和保护API和微服务等。IBM API Connect 5.0.0.0至5.0.8.4版本和2018.1和2018.3.6版本中存在CSV注入漏洞。攻击者可利用该漏洞执行恶意的命令。  

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10737867
