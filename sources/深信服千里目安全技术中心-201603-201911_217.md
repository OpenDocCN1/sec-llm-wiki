**一、本周漏洞总体态势**

    

  

**1. 总体态势跟踪**

最近一周，深信服安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞506条。

![](../Images/fd81fc2c3fe8e8810829aa197dc3aafd.png)

其中Exploit database增长漏洞69条，Security focus增长漏洞35条，Packet Storm增长漏洞58条，CNNVD漏洞增长最多，共增长344条（占比67.9%）。  

![](../Images/c575045e428841b9417a6482831b8362.png)  

整体漏洞类型与利用情况占比如下。web应用程序利用占比最多为61%，应重点关注；拒绝服务概念验证占比25%；本地特权升级利用占比9%；远程攻击占比3%；利用Shellcode存档占比1%；存档的安全文件占比1%。

![](../Images/95ed1d57df404e7833ffd69a8bc795b7.png)

   

**2. 重要厂商漏洞跟踪**

最近一周，深信服安全团队所跟踪的50多个重点厂商和组件中，Debian和Apple两家厂商发布安全补丁。其中Debian 更新漏洞1条，Apple更新漏洞12条。详细更新信息如下。但部分更新漏洞仍处于暂无POC，部分CVE编号搜索为RESERVED状态，暂无详细结果。针对此类漏洞，深信服安全团队将持续跟踪。

**Debian产品安全漏洞**

 

**产品介绍**：

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

**漏洞更新情况：**

11月3日Debian 发布了一条安全更新，影响产品ruby2.3。此次更新涉及到的漏洞包括CVE-2018-16395, CVE-2018-16396。在Ruby语言的解释器中发现了几个漏洞。漏洞源于程序没有正确的执行相等性检测。目前尚无此漏洞的详细信息。

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://www.debian.org/security/2018/dsa-4332

  

**Safari 产品安全漏洞**

 

**产品介绍**：

Safari是苹果计算机的操作系统Mac OS中的浏览器，使用了KDE的KHTML作为浏览器的运算核心。

**漏洞更新情况：**

10月30日，Apple发布安全更新Safari 浏览器 12.0.1。适用于macOS Sierra 10.12.6、macOS High Sierra 10.13.6 和 macOS Mojave 10.14。涉及到的漏洞编号包括CVE-2018-4374，CVE-2018-4377，CVE-2018-4372，CVE-2018-4373，CVE-2018-4375，CVE-2018-4376，CVE-2018-4382，CVE-2018-4386，CVE-2018-4392，CVE-2018-4416，CVE-2018-4409，CVE-2018-4378。主要解决存在的逻辑问题，跨站点脚本处理问题，多个内存损坏问题，资源耗尽问题等。

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

https://support.apple.com/zh-cn/HT209196

  

    

**二、重要漏洞预警**

    

**Schneider Electric Software Update 安全漏洞**

 

**漏洞等级**：高危

**受影响系统**：Schneider Electric SESU 2.2.0之前版本

**漏洞描述**：Schneider Electric Software Update是施耐德电气的一款Schneider软件更新工具。Schneider Electric SESU 2.2.0之前版本中存在安全漏洞，该漏洞源于该产品使用固定的或受控制的搜索路径查找资源。本地攻击者可通过在目标计算机上放置特制的文件利用该漏洞执行任意代码。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.update.schneider-electric.com/download/SystemConsistency/SoftwareUpdate/SESU\_220/SESU\_2.2.0\_setup\_sfx.exe

  

**Schneider Electric InduSoft Web Studio和InTouch Edge HMI 缓冲区错误漏洞**

 

**漏洞等级**：高危

**受影响系统**：Schneider Electric InduSoft Web Studio 8.1 SP2之前版本

**漏洞描述**：Schneider Electric InduSoft Web Studio是施耐德电气的嵌入式HMI软件包。该产品为HMI客户端提供读取、写入标签和事件监控功能。Schneider Electric InduSoft Web Studio 8.1 中的TCP/IP Server Task存在基于栈的缓冲区溢出漏洞。远程攻击者可利用该漏洞执行代码。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://sw.aveva.com/hubfs/assets-2018/pdf/security-bulletin/SecurityBulletin\_LFSec130.pdf

**Mozilla网络安全服务CVE-2018-12384信息泄露漏洞**

 

**漏洞等级**：中危

**受影响系统**：Mozilla Network Security Service

**漏洞描述**：Mozilla Network Security Services是一个函数库（网络安全服务库），它可跨平台提供SSL、S/MIME和其他Internet安全标准支持。Mozilla Network Security Service容易出现信息泄露漏洞。攻击者可以利用此问题执行中间人攻击并获取敏感信息。 成功的攻击将导致其他攻击。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://developer.mozilla.org/en-US/docs/Mozilla/Projects/NSS/NSS\_3.36.5\_release\_notes

**参考链接**：

https://www.securityfocus.com/bid/105218

  

**OpenSSL CVE-2018-0734侧信道攻击信息泄露漏洞**

 

**漏洞等级**：高危

**受影响系统**：Apache Impala 3.0.1之前版本

**漏洞描述**：OpenSSL 是一个安全套接字层密码库，囊括主要的密码算法、常用的密钥和证书封装管理功能及SSL协议，并提供丰富的应用程序供测试或其它目的使用。OpenSSL容易出现本地信息泄露漏洞。本地攻击者可以利用此问题获取敏感信息。 这可能有助于进一步的攻击。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.openssl.org/

**参考链接**：

https://www.securityfocus.com/bid/105758
