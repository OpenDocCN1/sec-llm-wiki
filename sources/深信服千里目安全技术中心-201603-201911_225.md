# 【漏洞预警】win10操作系统任意文件删除漏洞

2018年10月23日，安全研究人员在github上公布了最新的win10x64版的任意文件删除漏洞，在github上的SandboxEscaper上有着完整的漏洞利用程序源码以及release版的demo，并且被其他安全研究专家证实该漏洞可以在最近的win10上复现。

  

    

**千里百科**

    

Windows 10是Microsoft生产的一系列个人计算机操作系统，是Windows NT系列操作系统的一部分。它于2015年7月29日发布。Windows 10持续不断地发布新版本，用户无需支付额外费用。截至2017年11月，该操作系统在超过6亿台设备上运行。

  

    

**漏洞描述**

    

该漏洞的原因在于win10系统的数据共享服务(dssvc.dll)中有alpc的调用接口，该接口导出了RpcDSSMoveFromSharedFile函数，该函数正是本次漏洞利用到的函数。该函数的原型如下：

long Proc8\_RpcDSSMoveFromSharedFile(

  /\* \[in\] \*/ handle\_t IDL\_handle,   //IDL handle

  /\* \[string\]\[in\] \*/ wchar\_t \*arg\_1,//handle string

  /\* \[string\]\[in\] \*/ wchar\_t \*arg\_2)//path string

当任意权限的用户调用该函数时，该函数会将第三个参数所代表的文件进行删除。在这之前，会通过CreateMountPoint函数建立两个文件夹的软链接，如图：  

![](../Images/c540248c7169fa0556dba1a586200b67.png)

并删除该目录下的特定文件，从而将所链接目录下的文件一并删除。

  

    

**漏洞复现**

    

本次复现使用了win10x64版，首先使用github上提供的漏洞利用工具，在本地重新进行编译，将一个test.sys驱动文件放到C:\\Windows\\System32\\Drivers目录下，并修改源代码将e:\\test1目录链接到C:\\Windows\\System32\\Drivers

![](../Images/80809f06dcf0208d5e55043f03533d92.png)

最后尝试删除test.sys驱动文件。

![](../Images/5f5e581fbd239a859ee3b16957ccb383.png)

该函数并非一次性就可以将目标文件删除，需要运行多次，如图：  

![](../Images/2ce8194d51891ec4552862efcbc24c87.png)

查看test.sys文件：  

![](../Images/9d7a066f393281b3cef0acbf8a086b67.png)

通过sysinternals也可以确定是dssvc.dll将test.sys驱动删除，首先通过如下指令查看dssvc服务对应的程序：  

![](../Images/ce51c1778bd5dbed737fe4a196915a26.png)

接着对该进程进行行为监控，输出如下：  

![](../Images/9e78d6dd0a869a555d32425b4ac15bb6.png)

至此漏洞复现成功。利用该漏洞可以同杀毒软件进行对抗并且通过伪造删除后的文件可以用来进行dll劫持。

 

    

**影响版本**

    

win10 x64、win10 x86
