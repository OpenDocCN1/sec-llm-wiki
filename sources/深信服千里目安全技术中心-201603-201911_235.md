# 【漏洞预警】libssh身份验证绕过（cve-2018-10933）

2018-10-16，libssh发布更新，该更新修复了一个身份验证绕过漏洞，漏洞的CVE编号为CVE-2018-10933，目前github上已有可利用的poc。

  

    

**千里百科**

    

Libssh是一个用C编写的库，用于实现SSHv2协议，它可用于实现客户端和服务器应用程序。它可以扩展到数千个用户。

  

    

**漏洞描述**

    

Libssh版本0.6.0及更高版本的服务器端代码中存在身份验证绕过漏洞。通过向服务器发送SSH2\_MSG\_USERAUTH\_SUCCESS消息来代替服务器期望启动身份验证的SSH2\_MSG\_USERAUTH\_REQUEST消息，攻击者可以在没有任何凭据的情况下成功进行身份验证。

  

    

**漏洞复现**

    

本次复现使用了libssh-0.7.4，使用ubuntu 16.04.2 LTS作为测试环境。

使用已经公开的poc脚本进行漏洞复现。

![](../Images/af4181cdf7e8009f758fe7118684e636.png)

   

    

**修复分析**

    

官方发布的patch文件中添加了额外的session状态标志位。用该标志位标注当前session所处的状态，避免客户端通过发送SSH2\_MSG\_USERAUTH\_SUCCESS消息进行绕过。

![](../Images/66f76e0f6f4ca5ee076012f62d2e01be.png)

    

**影响版本**

    

Libssh 0.6.x

Libssh 0.7.x < 0.7.6

Libssh 0.8.x < 0.8.4

  

    

**修复建议**

    

**目前官方已经推出了更新补丁，各版本的下载地址如下**：

https://www.libssh.org/security/patches/stable-0.6\_CVE-2018-10933.jmcd.patch01.txt
