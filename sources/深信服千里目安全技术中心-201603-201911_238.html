一、本周漏洞总体态势

1. 总体态势跟踪

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞820条。


其中Exploit database增长漏洞47条，Security focus增长漏洞105条，Packet Storm增长漏洞89条，CNNVD漏洞增长最多，共增长579条（占比70.6%）。

整体漏洞类型与利用情况占比如下。web应用程序利用占比最多为36%，应重点关注；拒绝服务概念验证占比17%；本地特权升级利用占比19%；利用Shellcode存档占比4%；远程攻击占比9%；存档的安全文件占比15%。

 

2. 重要厂商漏洞跟踪

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Microsoft，Spring和VMware三家家厂商发布安全补丁。其中Microsoft更新漏洞49条（关键漏洞12条），Spring 更新漏洞2条，VMware更新漏洞1条。详细更新信息如下。

Microsoft 产品安全漏洞

产品介绍：

微软（Microsoft），是一家美国跨国科技公司，以研发、制造、授权和提供广泛的电脑软件服务业务为主。

漏洞更新情况：

2018年10月9日Microsoft发布10月份安全补丁更新。共修复了49个安全漏洞，其中有12个漏洞被标记为关键漏洞，35个为重要漏洞，1个为中危漏洞，1个为低危漏洞。此次更新相比上月漏洞数量稍少，其中上月披露的CVE-2018-8423漏洞已修复。


此次更新涉及产品包括Edge，Windows，IE，Office，SQL Server等微软主流产品。其中CVE-2018-8453 Win32k提权漏洞，此漏洞已被其他组织利用于攻击活动，但是该漏洞不能导致远程代码执行，只能用于感染机器后实现提权；CVE-2018-8423 JET引擎远程代码执行漏洞已被披露POC，影响当前受支持的所有Windows版本。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

参考链接：

https://www.bleepingcomputer.com/news/microsoft/microsoft-october-2018-patch-tuesday-fixes-12-critical-vulnerabilities/


Spring产品安全漏洞

产品介绍：

Spring是于2003 年兴起的一个轻量级的Java 开发框架，它解决的是业务逻辑层和其他各层的松耦合问题。

漏洞更新情况：

10月10日，Spring更新两条漏洞CVE-2018-11084和CVE-2018-15755。


Cloud Foundry Garden-runC版本（1.16.1之前的版本）可防止基于文件属性删除某些应用程序环境。 经过远程身份验证的恶意用户可能会创建和删除具有精心设计的文件属性的应用，从而导致新应用实例的拒绝服务或扩展现有应用。


Cloud Foundry CF Networking版本2.11.0到2.15.0，包含一个内部api端点，易受迭代单元和策略服务器之间的SQL注入攻击。 具有mTLS证书的远程经过身份验证的恶意用户可以发出任意SQL查询并获得对策略服务器的访问权限。

提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

参考链接：

https://pivotal.io/security/cve-2018-11084

https://pivotal.io/security/cve-2018-15755


VMware产品安全漏洞

产品介绍：

VMware是全球云基础架构和移动商务解决方案厂商，提供基于VMware的解决方案， VMWare虚拟机软件是一个“虚拟PC”软件,它使你可以在一台机器上同时运行二个或更多Windows、DOS、LINUX系统。

漏洞更新情况：

10月9日，VMware更新了一条漏洞CVE-2018-6977（中危）。由于3D渲染着色器中的无限循环，VMware ESXi，Workstation和Fusion包含拒绝服务漏洞。成功利用此问题可能允许在guest虚拟机中具有普通用户权限的攻击者使VM无响应，并且在某些情况下，可能导致主机上的其他VM或主机本身无响应。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

参考链接：

https://www.vmware.com/security/advisories/VMSA-2018-0025.html


二、重要漏洞预警

Adobe Acrobat和Reader 缓冲区错误漏洞

漏洞等级：高危

受影响系统：Adobe Acrobat和Reader

漏洞描述：Adobe Acrobat是一套PDF文件编辑和转换工具，Reader是一套PDF文档阅读软件。Adobe Acrobat和Reader中存在缓冲区错误漏洞。远程攻击者可利用该漏洞执行任意代码。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://helpx.adobe.com/security/products/acrobat/apsb18-30.html


Microsoft Windows Kernel 权限许可和访问控制漏洞

漏洞等级：高危

受影响系统：Microsoft Windows Server 2019，Windows Server 2016，Windows Server版本1803，Windows Server版本1709，Windows 10版本1809，Windows 10版本1803，Windows 10版本1709，Windows 10版本1703，Windows 10版本1607。

漏洞描述：Microsoft Windows Kernel中对内核内存处理的方式存在提权漏洞。本地攻击者可利用该漏洞以提升的权限执行任意代码。以下系统版本受到影响。

Cisco Prime基础设施 - 未经身份验证的远程执行代码

漏洞等级：高危

受影响系统：暂无

漏洞描述：Cisco Prime Infrastructure（PI）是一套通过Cisco Prime LAN Management Solution（LMS）和Cisco Prime Network Control System（NCS）技术进行无线管理的解决方案。Cisco Prime基础设施（CPI）包含两个漏洞。 第一个漏洞是文件上传漏洞，允许攻击者像Apache Tomcat用户一样上传和执行文件; 第二种是通过绕过SUID二进制文件中的执行限制将权限升级为root。
