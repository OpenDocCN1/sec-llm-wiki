一、本周漏洞总体态势

1.总体态势跟踪

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞521条。

 

其中Exploit database增长漏洞57条，Security focus增长漏洞32条，Packet Storm增长漏洞127条，CNNVD漏洞增长最多，共增长305条（占比58.5%）。

整体漏洞类型与利用情况占比如下。web应用程序利用占比最多为56%，应重点关注；拒绝服务概念验证占比26%；本地特权升级利用占比11%；利用Shellcode存档占比5%；远程攻击占比2%；存档的安全文件本周无更新。

 

2.重要厂商漏洞跟踪

最近一周，深信服科技北研安全团队所跟踪的50多个重点厂商和组件中，Debian和Rad Hat 两家家厂商发布安全补丁。其中Debian更新漏洞3条，Rad Hat更新漏洞23条。详细更新信息如下。

Debian产品安全漏洞

产品介绍：

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

漏洞更新情况：

9月24日Debian 发布了一条安全更新，影响产品strongswan。此次更新涉及到的漏洞包括CVE-2018-16151, CVE-2018-16152。strongSwan的gmp插件中存在安全漏洞，解析和验证RSA签名中的漏洞可能导致在证书和IKE身份验证期间出现Bleichenbacher样式的低指数签名伪造。


9月27日Debian 发布了一条安全更新，影响产品python2.7。此次更新涉及到的漏洞包括CVE-2018-1060, CVE-2018-1061, CVE-2018-14647, CVE-2018-1000802。Python中存在多个安全漏洞，ElementTree无法初始化Expat's hash salt，在difflib和poplib中发现了两个拒绝服务漏洞，并且shutil模块受到命令注入漏洞的影响。


9月28日Debian 发布了一条安全更新，影响产品python3.5。此次更新涉及到的漏洞包括CVE-2017-1000158, CVE-2018-1060, CVE-2018-1061, CVE-2018-14647。Python中存在多个安全漏洞，ElementTree无法初始化Expat's hash salt，在difflib和poplib中发现了两个拒绝服务漏洞，在PyString_DecodeEscape中发现了缓冲区溢出漏洞。


提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

参考链接：

https://www.debian.org/security/2018/dsa-4305

https://www.debian.org/security/2018/dsa-4306

https://www.debian.org/security/2018/dsa-4307

Rad Hat （红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

二、重要漏洞预警

多款Lenovo IdeaPad产品竞争条件漏洞

漏洞等级：高危

受影响系统：Lenovo 310S-14ISK；320-15IKBRA；320-15IKBRN等

漏洞描述：Lenovo 310S-14ISK等都是联想（Lenovo）的笔记本电脑产品。多款Lenovo IdeaPad产品中的BIOS闪存设备锁定机制存在竞争条件漏洞。拥有管理员权限的攻击者可利用该漏洞修改BIOS的内容。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.lenovo.com/us/en/solutions/LEN-20184


多款Lenovo Thinkpad产品安全漏洞

漏洞等级：高危

受影响系统：Lenovo ThinkPad E480/E580；ThinkPad L480/L580等

漏洞描述：Lenovo ThinkPad E480等都是中国联想（Lenovo）公司的不同型号的笔记本电脑产品。多款Lenovo Thinkpad产品中存在安全漏洞。物理位置临近的攻击者可利用该漏洞注入任意代码。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.lenovo.com/us/en/solutions/LEN-20527

受影响系统：Apple iOS 12之前版本；macOS Mojave 10.14之前版本；watchOS 5之前版本；tvOS 12之前版本。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

多款Cisco产品Video Surveillance Manager Software 安全漏洞

漏洞等级：高危

受影响系统：Cisco VSM Software 7.10版本、7.11版本和7.11.1版本

漏洞描述：Video Surveillance Manager Software是一款视频监控管理器。多款Cisco产品上的VSM Software存在安全漏洞，该漏洞源于程序为root账户使用了未记录的默认静态用户凭证。远程攻击者可通过使用该账户登录受影响系统利用该漏洞以root用户身份执行任意命令。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://tools.cisco.com/security/center/conten


Dell EMC Unity Operating Environment 安全漏洞

漏洞等级：高危

受影响系统：Dell EMC Unity OE 4.3.0.x版本和4.3.1.x版本以及Dell EMC UnityVSA OE 4.3.0.x版本和4.3.1.x版本

漏洞描述：Dell EMC Unity Operating Environment 是一套使用在EMC Unity存储系统中的操作环境。UnityVSA是它的另一版本。Dell EMC Unity OE 存在安全漏洞。本地攻击者可利用该漏洞修改服务工具中的库文件，进而以提升的权限执行代码。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://support.emc.com/downloads/39949_Dell-EMC-Unity-Family

IBM Rational Quality Manager 跨站脚本漏洞

漏洞等级：中危

受影响系统：IBM RQM 6.0版本至6.0.6版本

漏洞描述：IBM Rational Quality Manager 是一套协作的、基于Web的质量管理解决方案。该方案在软件开发的整个生命周期之内，提供了测试规划与测试评价管理方法，并能够共享信息、自动化加快项目进度以及报告制定的发布决策。IBM RQM 中存在跨站脚本漏洞。远程攻击者可利用该漏洞在Web UI中注入任意的JavaScript代码。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www-01.ibm.com/support/docview.wss?uid=ibm10733078


Foxit Reader for Windows 安全漏洞

漏洞等级：高危

受影响系统：Foxit Reader 9.2.0.9297及之前版本

漏洞描述：Foxit Reader for Windows是一款基于Windows平台的PDF文档阅读器。Foxit Reader 中‘setInterval()’方法的处理过程存在释放后重用漏洞，该漏洞源于程序在对对象执行操作之前，没有检测该对象是否存在。远程攻击者可借助恶意的文件或页面利用该漏洞在当前进程的上下文中执行任意代码。

解决方案：目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.foxitsoftware.com/support/security-bulletins.php

参考链接：

https://www.zerodayinitiative.com/advisories/ZDI-18-1094/


Fastspot BigTree 安全漏洞

漏洞等级：高危

受影响系统：Fastspot BigTree 4.2.23版本

漏洞描述：Fastspot BigTree是一套基于PHP和MySQL的开源内容管理系统（CMS）。Fastspot BigTree 中存在安全漏洞。远程攻击者可借助..\子字符串利用该漏洞绕过身份验证，读取任意文件。

解决方案： 目前厂商暂未发布修复措施解决此安全漏洞，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

http://www.bigtreecms.org/

参考链接：

https://github.com/bigtreecms/BigTree-CMS/issues/345
