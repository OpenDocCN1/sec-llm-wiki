# 罕见！驱动护体的挖矿病毒ProtectionX

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514204&idx=1&sn=0de61742de4d5b12f01857fee327f25b&chksm=ce46334cf931ba5a9c8ecc526f1bb2270007f87f735e72badb7258cafd2b83a7d870e66ae0fa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514204&idx=1&sn=0de61742de4d5b12f01857fee327f25b&chksm=ce46334cf931ba5a9c8ecc526f1bb2270007f87f735e72badb7258cafd2b83a7d870e66ae0fa&scene=27#wechat_redirect)

    

**事件背景**

    

近日，深信服安全团队追踪到一新型的挖矿病毒，该病毒与普通挖矿病毒有很大差异，普通挖矿没有特殊防护，而该病毒采用了驱动进行防护，十分罕见。

  

与多数挖矿病毒一样，感染主机会出现异常卡顿现象，且CPU占用率过高。该病毒使用了驱动保护，无法通过任务管理器中止病毒进程，很难查杀。深信服已将该病毒命名为ProtectionX。

  

感染ProtectionX病毒后，系统中会存在3个进程：母体1sass.exe及其子进程wuauc1t.exe与win1ogon.exe，注意名称中是“1”而不是“l”。其中win1ogon.exe进程占用大量CPU资源。

![](../Images/6783ba8cabef9fe4ae7742b79c2fe90f.png)

尝试终止1sass.exe进程，提示“拒绝访问”。而终止wuauc1t.exe和win1ogon.exe进程后，又会重新起来！这里，是因为有驱动保护了1sass.exe，而1sass.exe又防护了wuauc1t.exe与win1ogon.exe，环环相扣，多层护体。  

![](../Images/a2698609b7d385c5376c76ab27681984.png)

 

    

**行为分析**

    

病毒执行流程如下：

![](../Images/f7b450094cc3e717dccf9aefea1ded8d.png)

**主要包括3个模块：自保护、持久化以及挖矿模块。**

其中自保护模块用于保护病毒母体进程不被杀掉，持久化模块添加开机自启动，挖矿模块会进行挖矿并杀掉别的挖矿进程以及其他一些CPU占用高的进程。  

**2.1 病毒文件**

病毒母体1sass.exe为一个win32程序，加了VMP壳。

![](../Images/3b3a2d9afc69b065aba5e8948cff2621.png)

**2.2 自保护模块**

释放ProcessExtended.dll模块到本目录并加载。

![](../Images/6c0981c1538f938daa9a8e346e45f965.png)

![](../Images/920058decef531161ba8b9e53b9d7fbb.png)

调用ProcessProtectionX函数。

![](../Images/f676493d6a7383120c30371ecb90c81a.png)

ProcessProtectionX函数首先释放一个驱动文件到%Temp%目录，驱动文件名由7个随机的字母加数字组成。  

![](../Images/ddd425eb7ad201908a123af32359444e.png)

安装驱动，服务名为hy5.5。  

![](../Images/b1c5963544eb7c5e704ebadf05740112.png)

与驱动通信，将自身进程ID发送给驱动。  

![](../Images/ea45404bb6b373f7419039814e6a6b1d.png)

驱动中使用了SSDT HOOK，HOOK掉了NtOpenProcess从而实现进程保护。  

![](../Images/b641d1c87c5c9df164e627c32327d140.png)

![](../Images/18736d87e1eab3af7dce0442fbdf5eed.png)

删除驱动文件。

![](../Images/a6e68c3e12527b7ee737bfa40a9cbcb3.png)

**2.3 持久化模块**

为1sass.exe添加自启动，注册表路径为

“HKLM\\software\\microsoft\\windows\\CurrentVersion\\Run\\Registered font”。

![](../Images/821f8b0cafa23531e44c49be74de3fec.png)

**2.4 挖矿模块**

挖矿模块包含两个进程：wuauc1t.exe和win1ogon.exe。

  

由1sass.exe释放并运行，随后进入循环对这两个进程进程守护。

![](../Images/1c7f282aff5448bea1b6c7377e1cdc01.png)

**2.4.1 抢占资源**

wuauc1t.exe的功能为抢占CPU资源，由1sass.exe释放到同一目录下并运行，运行时传入参数“win1ogon.exe”。

![](../Images/a443f4d47fa636c29995505a4dc6df11.png)

![](../Images/a9ec1d9b346642c2f6bf37f69bcbd057.png)

首先遍历系统进程并获取其CPU占用率。“Process\\ % Processor Time”用于获取过程的所有线程在每个处理器上的处理器时间总和。

![](../Images/4c25e57fa670ed33ea126ebce69c25b0.png)

获取除传入参数“win1ogon.exe”、本进程以及“explorer.exe”以外的CPU占用较高的进程。

![](../Images/030aff96e248996b7e22c4ce06d07b52.png)

![](../Images/3522dc26400ed8f4b69ddce976e6f930.png)

终止掉CPU占用较高的其他进程以及其他挖矿进程。

![](../Images/1387e779f4024ef2aa4425220f0cd1ed.png)

终止的其他挖矿进程列表如下：

![](../Images/91ec79f2e05c7a1dde9c5fcd70a55dbf.png)

**2.4.2 挖矿**

win1ogon.exe为挖矿进程，也是由1sass.exe释放到同一目录下并运行。矿池为pool.minexmr.com:7777。

![](../Images/194e3b304f01cfedbb84c36198182ff6.png)

![](../Images/a4e9c5f6e90dfdac66de1cb93aaa04c5.png)

有了其他两个进程的保驾护航，挖矿进程可以最大限度的利用系统资源进行挖矿。

  

    

**解决方案**

    

**病毒检测查杀**

1、深信服为广大用户免费提供查杀工具，可下载如下工具，进行检测查杀。

 http://edr.sangfor.com.cn/tool/SfabAntiBot.zip

2、深信服EDR产品及防火墙等安全产品均具备病毒检测能力，部署相关产品用户可进行病毒检测。

**病毒防御**

1、及时给电脑打补丁，修复漏洞。

2、对重要的数据文件定期进行非本地备份。

3、更改账户密码，设置强密码，避免使用统一的密码。

4、可以尝试使用PC Hunter强制删除并结束进程1sass.exe、wuauc1t.exe、win1ogon.exe。

5、删除注册表项HKLM\\software\\microsoft

\\windows\\CurrentVersion\\Run\\Registered font。

 

最后，建议企业对全网进行一次安全检查和杀毒扫描，加强防护工作。推荐使用深信服安全感知+防火墙+EDR，对内网进行感知、查杀和防护。
