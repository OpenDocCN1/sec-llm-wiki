**0x01 本周漏洞总体态势**

      

**1. 总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞490条。

 

其中Exploit database增长漏洞34条，Security focus增长漏洞31条，Packet Storm增长漏洞85条，CNNVD漏洞增长最多，共增长340条（占比69.4%）。

![](../Images/a0c0d347142adaea6457e6b9b7b8e249.png)

整体漏洞类型与利用情况占比如下，web应用程序利用占比最高为50%，应重点关注；其次是拒绝服务和概念验证，本地特权升级利用，远程攻击分别为23%，12%和9%；利用Shellcode存档和存档的安全文件均占比3%。  

![](../Images/6b10ea478f6242401817b22dac3ea2ae.png)

   

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点软件厂商中，Mozilla Firefox 、Rad Hat、Debian三家厂商发布安全补丁。其中Mozilla Firefox  更新漏洞9条（高危1条），Rad Hat更新漏洞1条，Debian更新漏洞4条。详细漏洞信息如下。但部分更新漏洞仍处于暂无POC，部分CVE编号搜索为RESERVED状态，暂无详细结果。针对此类漏洞，深信服科技北研安全团队将持续跟踪。

 

**Mozilla Firefox 产品安全漏洞**

**产品介绍**：

Mozilla Firefox，中文俗称“火狐”，是一个自由及开放源代码的网页浏览器，使用Gecko排版引擎，支持多种操作系统，如Windows、Mac OS X及GNU/Linux等。

Mozilla Firefox在9月5日更新了9条漏洞，其中严重漏洞1条，高危漏洞3条，中危漏洞2条，低危漏洞3条。影响产品包括Firefox 62和Firefox ESR 60.2。其中需重点关注的高危漏洞有内存损坏及代码执行漏洞（CVE-2018-12376），内存安全漏洞（CVE-2018-12375），攻击者可利用该漏洞造成内存损坏并可能执行任意代码。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

*https://www.mozilla.org/en-US/security/advisories/mfsa2018-20/*

*https://www.mozilla.org/en-US/security/advisories/mfsa2018-21/*

 

**Rad Hat产品安全漏洞**

**产品介绍**：

Rad Hat（红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

9月4日Rad Hat官方公布了一个高危漏洞（CVE-2018-6555），该漏洞是由于.net/irda/af\_irda中的irda\_setsockopt函数，在Linux内核中，通过4.16，允许本地用户导致拒绝服务(由于ias\_object在没有使用后失效和系统崩溃)，或者通过使用AF\_IRDA套接字可能产生其他未指明的影响。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接**：

*https://access.redhat.com/security/cve/cve-2018-6555*

**Cisco Integrated Management Controller Software 命令注入漏洞**

**漏洞等级**：高危

**受影响系统**：Cisco IMC Software

**漏洞描述**： Cisco Integrated Management Controller（IMC）Software是美国思科（Cisco）公司的一套用于对UCS（统一计算系统）进行管理的软件。该软件支持HTTP、SSH访问等，并可对服务器进行开机、关机和重启等操作。Cisco IMC Software中的基于Web的管理界面存在命令注入漏洞，该漏洞源于受影响的软件没有充分的验证输入的命令。远程攻击者可通过向该接界面发送特制的命令利用该漏洞在受影响的设备上以root权限注入并执行任意系统级别的命令。

**解决方案**： 目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

*https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180905-cimc-injection*

**参考链接**：

*https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180905-cimc-injection*

**Tor Browser CVE-2017-16541信息泄露漏洞**

**漏洞等级**：中危

**受影响系统**：Tor Browser 7.0.8

**漏洞描述**：洋葱浏览器是一款匿名访问网络的的软件。用户通过Tor可以在因特网上进行匿名交流。为了实现匿名目的，Tor把分散在全球的计算机集合起来形成一个加密回路。当你通过它网络访问互联网时，你的网络据会通过多台电脑迂回发送，就像洋葱包裹其核心那样掩饰你的网络活动,信息传输在每一步都被加密，无从得知你所处位置和信息传输目的地。Tor浏览器容易出现信息泄露漏洞。攻击者可以利用此问题获取可能有助于发起进一步攻击的敏感信息.Tor Browser 7.0.8易受攻击; 其它版本也可能受到影响。

**解决方案**：

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

*https://blog.torproject.org/tor-browser-709-released*

**参考链接**：

*http://cve.mitre.org/cgi-bin/cvekey.cgi?keyword=CVE-2018-16541*

 

**DokuWiki 2018-04-22a Greebo任意代码执行**

**漏洞等级**：高危

**受影响系统**：DokuWiki版本2018-04-22a Greebo

**漏洞描述**：DokuWiki是一个开源wiki引擎程序，运行于PHP环境下。DokuWiki程序小巧而功能强大、灵活，适合中小团队和个人网站知识库的管理。DokuWiki可以与多种CMS程序进行整合，例如WordPress、XOOPS、PostNuke等。DokuWiki版本2018-04-22a Greebo受到CSV公式注入漏洞的影响，该漏洞允许任意代码执行。该应用程序的管理面板具有“CSV用户导出”功能，允许将用户数据（用户名，真实姓名，电子邮件地址和用户组）导出为CSV文件。 在注册页面上，攻击者可以在真实姓名字段中设置某些值 - 当使用电子表格应用程序（Microsoft Excel，Open Office等）导出和打开时 - 将被解释为公式。打开这些恶意导出文件的管理员将面临风险。敏感数据的泄漏甚至是受害者本地机器上任意代码的执行都将成为结果。

**解决方案**：目前厂商还未发布升级补丁，请相关用户及时关注相关地址：

*https://github.com/splitbrain/dokuwiki/issues/2450*

**参考链接**：

*https://packetstormsecurity.com/files/149260/DokuWiki-2018-04-22a-Greebo-Arbitrary-Code-Execution.html*

 

**PHPMyAdmin 4.7.x跨站点请求伪造漏洞**

**漏洞等级**：高危

**受影响系统**：phpMyAdmin版本4.7.x 

**漏洞描述**：phpMyAdmin 是一个以PHP为基础，以Web-Base方式架构在网站主机上的MySQL的数据库管理工具，让管理者可用Web接口管理MySQL数据库。phpMyAdmin版本4.7.x（4.7.6.1 / 4.7.7之前的版本）容易受到CSRF弱点的影响。 通过欺骗用户单击精心制作的URL，可以执行有害的数据库操作，例如删除记录，删除/截断表等。

**解决方案**：厂商已发布漏洞更新补丁，请使用此软件的用户及时更新：

*https://www.phpmyadmin.net/downloads/*

**参考链接**：

*https://packetstormsecurity.com/files/149168/phpMyAdmin-4.7.x-Cross-Site-Request-Forgery.html*
