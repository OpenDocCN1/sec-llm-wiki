**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点软件厂商中， Debian、rad hat、Adobe和phpMyAdmin四家厂商发布安全补丁。其中Debian 更新漏洞2条（高危），rad hat更新漏洞1条，Adobe更新漏洞2条，phpMyAdmin更新漏洞1条。详细漏洞信息如下。

 

**Debian 产品安全漏洞**

**产品介绍：**

Debian 是一个自由的操作系统（OS），提供您安装在计算机上使用。操作系统就是能让您的计算机工作的一系列基本程序和实用工具。

  

Debian 8月20日和22日分别更新了影响linux和openssh的漏洞。英特尔处理器设计实施指令的推测性执行以及处理页面错误的方式存在漏洞。该漏洞可能允许攻击者控制非特权进程从任意（非用户控制）地址读取内存，包括从内核和系统上运行的所有其他进程或跨客户/主机边界读取主机内存；OpenSSH容易出现用户枚举漏洞。该漏洞允许远程攻击者检查目标服务器上是否存在特定的用户帐户。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.debian.org/security/2018/dsa-4279

https://www.debian.org/security/2018/dsa-4280

 

**rad hat产品安全漏洞**

**产品介绍：**

rad hat （红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

  

8月21日rad hat 官方公布了一个高危漏洞（CVE-2018-10902），原始midi内核驱动程序不能防止并发访问，导致snd\_rawmidi\_input\_params()和snd\_rawmidi\_output\_status()中的双重realloc（双重释放），它们是rawmidi.c文件中snd\_rawmidi\_ioctl()处理程序的一部分。恶意本地攻击可能会使用此权限进行权限提升。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://access.redhat.com/security/cve/cve-2018-10902

**二、重要漏洞预警**

    

**ThinkPHP 3.2版本框架SQL注入漏洞**

**漏洞等级：**高危

**受影响系统：**ThinkPHP v3版本

**漏洞描述**： ThinkPHP团队对thinkphp 3框架进行了一处安全更新，经过分析，此次更新修正了一处SQL注入漏洞，该问题是由于select(),find(),delete()方法会传入数组类型数据，最终导致的多处SQL注入。

**解决方案**：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/top-think/thinkphp/commit/

9e1db19c1e455450cfebb8b573bb51ab7a1cef04#

diff-c7e3ac519b1260c65bca310cad99050c

**参考链接**：

https://mp.weixin.qq.com/s/Y6aAZZbUEnoaFpvWh9yXsQ

 

**Struts2远程代码执行漏洞(S2-057)**

**漏洞等级**：高危

**受影响系统**：Struts 2.3.34，Struts 2.5.16

**漏洞描述**：定义struts-actionchaining.xml配置时如果没有设置namespace的值，并且上层动作配置中并没有设置或使用通配符namespace时，可能会导致远程代码执行漏洞的发生。同样也可能因为url标签没有设置value和action的值，并且上层动作并没有设置或使用通配符namespace，从而导致远程代码执行漏洞的发生。

**解决方案**：厂商已发布漏洞修复程序，请及时关注更新：

http://archive.apache.org/dist/struts/

**参考链接**：

https://mp.weixin.qq.com/s/v8vgO95o3pyGuRVWZZHZTg

**Cisco Web Security Appliance权限提升漏洞**

**漏洞等级**：高危

**受影响系统**：Cisco Web Security Appliance 10.0.0-959

**漏洞描述**： Cisco Web Security Appliance（WSA）是美国思科（Cisco）公司的一套Web安全设备。该设备提供基于SaaS的访问控制、实时网络报告和追踪、制定安全策略等功能。Cisco Web Security Appliance (WSA)的帐户管理子系统存在权限提升漏洞。该漏洞源于访问控制实现不当。本地认证攻击者可利用该漏洞将权限提升到root，从而可转义CLI subshell并以root身份在底层操作系统上执行系统级命令。

**解决方案**：

厂商已发布漏洞修复程序，请及时关注更新：
