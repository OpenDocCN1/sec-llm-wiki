**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点软件厂商中， Microsoft 、rad hat、Adobe和Samba四家厂商发布安全补丁。其中 Microsoft 更新漏洞54条（高危8条），rad hat更新漏洞1条，Adobe更新漏洞8条，Samba更新漏洞5条。详细漏洞信息如下。但部分更新漏洞仍处于暂无POC，部分CVE编号搜索为RESERVED状态，暂无详细结果。针对此类漏洞，深信服科技北研安全团队将持续跟踪。

 

 

**Microsoft 产品安全漏洞**

**产品介绍：**

微软（Microsoft），是一家美国跨国科技公司，以研发、制造、授权和提供广泛的电脑软件服务业务为主。

2018年8月14日Microsoft发布条安全更新。其中涉及产品包括Internet Explorer、Microsoft Edge、Microsoft Windows、Microsoft Office、Microsoft Office Services 和 Web 应用、ChakraCore、Adobe Flash Player、.NET Framework、Microsoft Exchange Server、Microsoft SQL Serve和Visual Studio。包含多个远程代码执行漏洞如Windows PDF远程执行代码漏洞（CVE-2018-8350），Microsoft Excel远程执行代码漏洞（CVE-2018-8375），Microsoft图形远程执行代码漏洞（CVE-2018-8344）等。利用上述漏洞攻击者可以在目标系统实现如任意代码执行。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://portal.msrc.microsoft.com/zh-cn/security-guidance/releasenotedetail/1c26eff2-573f-e811-a96f-000d3a33c573

 

**rad hat产品安全漏洞**

**产品介绍：**

rad hat （红帽）是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

8月16日rad hat 官方公布了一个高危漏洞（CVE-2018-10873），影响SPICE0.14.1，其中用于在分解消息生成代码缺乏足够的边界检查之前。经过身份验证后，恶意客户端或服务器可能会向其对等方发送特制消息，从而导致崩溃或可能导致其他影响。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://access.redhat.com/security/cve/cve-2018-10873

 

**Adobe产品安全漏洞**

**产品介绍：**

Adobe是世界领先的数字媒体和在线营销解决方案供应商。Adobe Reader(也被称为AcrobatReader)是一款PDF文件阅读软件。

8月14日Adobe发布适用于Windows和MacOS的Adobe Experience Manager、Adobe Acrobat和Reader安全更新。此次更新解决了几个严重漏洞。包括反射的跨站点脚本漏洞（CVE-2018-12806），输入验证旁路漏洞（CVE-2018-12807），Adobe Acrobat和Reader 缓冲区错误漏洞（CVE-2018-12808 ），Adobe Acrobat和Reader远程代码执行漏洞（CVE-2018-12799 ）， 成功利用可能导致在当前用户的上下文中执行任意代码。

**参考链接：**

https://helpx.adobe.com/security/products/acrobat/apsb18-29.html

 

**Samba产品安全漏洞**

**产品介绍：**

Samba是在Linux和UNIX系统上实现SMB协议的一个免费软件，由服务器及客户端程序构成。

8月14日Samba官方发布5条安全补丁更新。涉及版本为Samba4.7.8，Samba4.7.3、Samba4.6.15，使用该产品的用户可以通过下方参考链接进入Samba官方补丁更新页面下载补丁进行更新。但此次更新漏洞仍处于暂无POC，CVE编号搜索为RESERVED状态，暂无详细结果。深信服科技北研安全团队将持续跟踪。

https://www.samba.org/samba/history/security.html

  

 

    

**二、重要漏洞预警**

    

**Microsoft Windows PDF库安全漏洞**

**漏洞等级：**高危

**受影响系统：**Microsoft Windows 10版本1703，Windows 10版本1709，Windows 10版本1803，Windows Server版本1709，Windows Server版本1803

**漏洞描述：**  Microsoft Windows 10等都是美国微软（Microsoft）公司发布的一系列操作系统。Microsoft Windows PDF库中存在远程代码执行漏洞，该漏洞源于程序没有正确地处理内存中的对象。远程攻击者可利用该漏洞在当前用户的上下文中执行任意代码，损坏内存。

**解决方案： ** 

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2018-8350

**参考链接：**

http://www.securityfocus.com/bid/104985

**Apache Ignite任意代码执行漏洞**

**漏洞等级：**高危

**受影响系统：**Apache Ignite <=2.5

**漏洞描述：**Apache Ignite是美国阿帕奇（Apache）软件基金会的一套高性能、集成化和分布式的用于大规模的数据集处理的内存计算和事务管理平台。Apache Ignite 2.5及之前版本中存在任意代码执行漏洞，该漏洞源于序列化机制不含有可允许序列化/反序列化类的列表。攻击者可通过向GridClientJdkMarshaller反序列化端点发送序列化对象表单利用该漏洞执行任意代码。

https://lists.apache.org/thread.html/e0fdf53114a321142ecfa5cfa17658090f0b4e1677de431e329b37ab@%3Cdev.ignite.apache.org%3E
