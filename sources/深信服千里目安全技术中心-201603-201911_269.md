**一、本周漏洞总体态势**

    

**1. 总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞354条。

 

其中Exploit database增长漏洞43条，Security focus增长漏洞22条，Packet Storm增长漏洞77条，CNNVD漏洞增长最多，共增长212条（占比59.8%）。

![](../Images/35fcb35b5d7ef7c525d15967f36df6de.png)

整体漏洞类型与利用情况占比如下，web应用程序开发利用、本地特权升级利用和拒绝服务概念验证三种类型占比最高，分别占比35%、23%和19%，应重点关注。其次是存档的安全文件，占比14%；利用Shellcode存档占比7%；远程攻击最少占比2%。  

![](../Images/02a217411981bce4feed55a44fe77eb9.png)

   

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点软件厂商中，Jenkins、Rad Hat、Drupal三家厂商发布安全补丁。其中Jenkins更新漏洞17条，Rad Hat更新漏洞2条（低危），Drupal更新漏洞1条，详细漏洞信息如下。

 

**Jenkins产品安全漏洞**

**产品介绍：**

Jenkins是一个开源软件项目，是基于Java开发的一种持续集成工具，用于监控持续重复的工作，旨在提供一个开放易用的软件平台。

Jenkins安全公告公布了17个可交付成果中的漏洞，漏洞涉及AccuRev、TestRail、Anchore、Confluence Publishe、Inedo BuildMaster、Inedo ProGet、Kubernetes、Maven Artifact ChoiceListProvider、meliora-testlab、CIFS、资源处理器、SaltStack、Shelve、SSH代理、Tinfoil 、TraceTronic ECU-TEST等插件。此次更新多为中低危信息泄露漏洞，例如Jenkins SSH Agent Plugin 信息泄露漏洞(CVE-2018-1999036)，Jenkins SaltStack Plugin 信息泄露漏洞(CVE-2018-1999027)，Jenkins Accurev Plugin 信息泄露漏洞(CVE-2018-1999028)等。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://jenkins.io/security/advisory/2018-07-30/

 

**Rad hat产品安全漏洞**

**产品介绍：**

Rad Hat (红帽)是世界领先的开源解决方案供应商,依托社区驱动的方式来提供可靠和高性能的云、虚拟化、存储、Linux 和中间件技术。

8月2日，Rad Hat (红帽)官方更新了两个漏洞，分别是ttembed 输入验证漏洞(CVE-2018-10922 )和ttembed输入文件整数溢出漏洞(CVE-2018-10921)。ttembed中存在输入验证缺陷。使用精心设计的输入文件，攻击者可能会因为ttembed信任攻击者控制的值而触发拒绝服务条件。两个均为低危漏洞，提醒用户及时下载补丁更新。

**参考链接：**

https://access.redhat.com/security/cve/cve-2018-10922

https://access.redhat.com/security/cve/cve-2018-10921

 

**Drupal产品安全漏洞**

**产品介绍：**

Drupal是使用PHP语言编写的开源内容管理框架(CMF)，它由内容管理系统(CMS)和PHP开发框架(Framework)共同构成。

8月1日，Drupal项目使用的Symfony库发布了一个影响Drupal的漏洞安全更新（CVE-2018-14773）。它源于对（旧）IIS标头的支持，该标头允许用户通过X-Original-URL或X-Rewrite-URL HTTP请求标头覆盖请求URL中的路径。这会影响\\ Symfony \\ Component \\ HttpFoundation \\ Request :: prepareRequestUri（），其中使用了X-Original-URL和X\_REWRITE\_URL。该漏洞影响Drupal8.5.6之前的Drupal8.x版本，提醒使用Drupal的用户更新版本至Drupal 8.5.6。

**参考链接：**

https://www.drupal.org/SA-CORE-2018-005 

  

    

**二、重要漏洞预警**

    

  

**Samsung SmartThings Hub video-core HTTP服务器缓冲区错误漏洞**

**漏洞等级：**高危

**受影响系统：**Samsung SmartThings Hub

**漏洞描述：**Samsung SmartThings Hub是韩国三星（Samsung）公司的一款智能家居管理设备。video-core HTTP server是其中的一个HTTP服务器。 Samsung SmartThings Hub中的video-core HTTP服务器的数据库字段的检索存在基于栈的缓冲区溢出漏洞，该漏洞源于video-core进程没有安全的在SQLite数据库的‘clips’表中提取字段。攻击者可通过发送HTTP请求利用该漏洞执行任意代码。

**解决方案： **目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.samsung.com/us/smart-home/smartthings/

**参考链接：**

https://www.talosintelligence.com/vulnerability\_reports/TALOS-2018-0548

**Jenkins SSH Agent Plugin 信息泄露漏洞**

**漏洞等级：**高危

**受影响系统：**Jenkins SSH Agent Plugin 1.15

**漏洞描述：**CloudBees Jenkins是美国CloudBees公司的一套基于Java开发的持续集成工具。SSH Agent Plugin是使用在其中的一个用于提供SSH凭据的插件。CloudBees Jenkins SSH Agent Plugin 1.15及之前版本中的SSHAgentStepExecution.java文件存在信息泄露漏洞，该漏洞源于在记录ssh-add命令时，程序也会以明文的形式记录SSH密钥密码。攻击者可利用该漏洞获取SSH私钥密码。

**解决方案：** 目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://jenkins.io/security/advisory/2018-07-30/#SECURITY-704

**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name= CVE-2018-1999036

 

**Cisco Adaptive Security Appliance (ASA)软件拒绝服务漏洞**

**漏洞等级：**高危

**受影响系统：**3000系列工业安全设备(ISA)， ASA 5500系列自适应安全设备，ASA 5500- x系列下一代防火墙，用于Cisco Catalyst 6500系列交换机和Cisco 7600系列路由器的ASA服务模块，适应性安全虚拟设备(ASAv)，火力2100系列安全设备，火力4110安全设备，火力9300 ASA安全模块。

**漏洞描述： **多款Cisco产品中ASA和FTD Software的ingress flow创建功能存在输入验证漏洞，该漏洞源于程序未能正确的处理内部软件的锁定，导致其他的系统进程可以使CPU进入循环。远程攻击者可通过发送恶意的IP数据包流利用该漏洞造成拒绝服务（CPU资源耗尽）。

**解决方案：**目前厂商已经发布了升级补丁以修复这个安全问题，请到厂商的主页下载：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180418-asa2

**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-0228

 

**ShopNx任意文件上传漏洞**

**漏洞等级：**高危

**受影响系统：**ShopNx ShopNx <=2017-11-17

**漏洞描述：**ShopNx是一款用AngularJS、NodeJS和MongoDB创建的购物网站单页应用程序。ShopNx 2017-11-17及之前版本中存在安全漏洞，该漏洞源于程序未能充分过滤用户提交的输入。远程攻击者可利用该漏洞上传带有JavaScript载荷的恶意HTML文件，从而窃取用户的凭证。

**解决方案：**厂商尚未提供漏洞修复方案，请关注厂商主页更新：http://shopnx.in/

**参考链接：**

https://nvd.nist.gov/vuln/detail/CVE-2018-12519

 

**tinyexr缓冲区溢出漏洞**

**漏洞等级：**高危

**受影响系统：**tinyexr tinyexr 0.9.5

**漏洞描述：**tinyexr是一个小型OpenEXR图像加载保存库。tinyexr 0.9.5版本中的tinyexr.h文件的‘tinyexr::DecodePixelData’函数存在缓冲区溢出漏洞。攻击者可利用该漏洞造成缓冲区越界读取。
