**一、本周漏洞总体态势**

    

  

**1. 总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞394条。相比前两周增幅略有下降。

 

其中Exploit database增长漏洞25条，Security focus增长漏洞18条，Packet Storm增长漏洞95条，CNNVD漏洞增长最多，共增长256条（占比64.9%）。

![](../Images/0c21923b5e3a3d5b26f1f7edf7ebab48.png)

整体漏洞类型与利用占比情况如下，web应用程序开发占比最高（36%），应重点关注，其次是拒绝服务概念验证占比28%，本地特权升级利用占比16%，远程攻击和安全文件占比相同均为8%，利用Shellcode存档占比最少（均为4%）。

![](../Images/9c138c9387df1be2ba0328d59401440b.png)

 

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点软件厂商中，Mozilla、Foxit两家厂商发布安全补丁和更新。其中Mozilla更新漏洞20条，Foxit更新漏洞26条，Adobe详细漏洞信息如下。但部分更新漏洞仍处于暂无POC，部分CVE编号搜索为RESERVED状态，暂无详细结果。针对此类漏洞，深信服科技北研安全团队将持续跟踪。

  

**Mozilla产品安全漏洞**

**产品介绍：**

Mozilla Firefox是一款开源Web浏览器；Firefox ESR是Firefox的一个延长支持版本。

本周，Mozilla Firefox产品更新多个漏洞。MozillaThunderbird信息泄露漏洞（CNVD-2018-13663，CNVD-2018-13662，CNVD-2018-14109），MozillaFirefox代码执行漏洞（CNVD-2018-13863，CNVD-2018-13891），MozillaFirefox整数溢出漏洞（CNVD-2018-13885），Mozilla Firefox越权漏洞，MozillaFirefox信息泄露漏洞（CNVD-2018-13964）。其中，“MozillaFirefox代码执行漏洞（CNVD-2018-13863,CNVD-2018-13891），MozillaFirefox越权漏洞”为高危漏洞。目前，厂商已经发布了上述漏洞的修补程序。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.firefox.com.cn/?utm\_medium=referral&utm\_source=mozilla.org

 

**Foxit产品安全漏洞**

**产品介绍：**

Foxit Reader for Windows是一款基于Windows平台的PDF文档阅读器。

本周，Foxit Reader 被披露存在内存错误引用、缓冲区溢出和远程代码执行漏洞，攻击者可利用执行任意代码。Foxit Reader缓冲区溢出漏洞（CNVD-2018-13985），Foxit ReaderExpaseFDF任意文件编写远程代码执行漏洞，Foxit Reader内存错误引用漏洞（CNVD-2018-14146，CNVD-2018-14147，CNVD-2018-14148，CNVD-2018-14149，CNVD-2018-14150，CNVD-2018-14151）。其中，“Foxit Reader缓冲区溢出漏洞（CNVD-2018-13985），Foxit ReaderExpaseFDF任意文件编写远程代码执行漏洞”为高危漏洞。目前，厂商已经发布了上述漏洞的修补程序。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

参考链接：

http://www.cnnvd.org.cn/web/bulletin/bulletinById.tag?mkid=118  

  

    

**二、重要漏洞预警**

    

**Intel Converged Security Management Engine任意代码执行漏洞**

**漏洞等级：**高危

**受影响系统：**Intel Converged Security Management Engine 11.\*

**漏洞描述：**Intel Converged Security Management Engine是美国英特尔（Intel）公司的一款使用在CPU（中央处理器）中的安全管理引擎。Intel Converged Security Management Engine 11.x版本中存在安全漏洞。攻击者可借助本地的特权访问权限利用该漏洞执行任意代码。

**解决方案：**目前厂商已经发布了升级补丁以修复这个安全问题，请到厂商的主页下载：

https://www.intel.com/content/www/us/en/security-center/advisory/intel-sa-00118.html

**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-3627

 

**Network Manager VPNC权限提升漏洞**

**漏洞等级：**高危

**受影响系统：**Network Manager VPNC Network Manager VPNC <1.2.6

**漏洞描述：**Network Manager VPNC plugin（networkmanager-vpnc）是一款支持连接Cisco VPN的虚拟网络管理器。Network Manager VPNC插件1.2.6之前版本中存在安全漏洞，该漏洞源于换行字符可以被用来将Password helper参数注入到配置数据中并传入到VPNC。攻击者可利用该漏洞以root权限执行命令。

**解决方案：**目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://gitlab.gnome.org/GNOME/NetworkManager-vpnc

**参考链接： **  

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-10900

 

**Jenkins未授权用户重置部分全局配置漏洞**

**漏洞等级：**高危

**受影响系统：**Jenkins weekly <=2.132，Jenkins LTS <=2.121.1

**漏洞描述：**Jenkins是一个开源软件项目，是基于Java开发的一种持续集成工具，用于监控持续重复的工作，旨在提供一个开放易用的软件平台，使软件的持续集成变成可能。

Jenkins存在未授权用户重置部分全局配置漏洞,远程且未经授权的攻击者可以通过构造恶意登录凭证，从Jenkins主目录下移除 config.xml 配置文件到其他目录，从而导致 Jenkins 服务下次重启时退回legacy模式，对匿名用户也会开放管理员权限。

**解决方案：**用户可联系供应商获得补丁信息：

https://jenkins.io/download/

**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-1999001

 

**Foxit Reader缓冲区溢出漏洞**

**漏洞等级：**高危

**受影响系统：**Foxit Foxit Reader for Windows <=9.1.0.5096

**漏洞描述：**Foxit Reader for Windows是中国福昕（Foxit）软件公司的一款基于Windows平台的PDF文档阅读器。基于Windows平台的Foxit Reader 9.1.0.5096及之前版本中对PDF文档的解析存在基于堆的缓冲区溢出漏洞，该漏洞源于程序未能正确的验证用户提交数据的长度，导致复制数据的大小超过了堆缓冲区空间。远程攻击者可借助恶意的文件或页面利用该漏洞在当前进程的上下文中执行任意代码。

**解决方案：**目前厂商已发布升级补丁以修复漏洞，补丁获取链接:

https://www.foxitsoftware.com/support/security-bulletins.php

**参考链接：**

http://www.cnvd.org.cn/flaw/show/CNVD-2018-14290

 

**Mozilla Firefox代码执行漏洞**

**漏洞等级：**高危

**受影响系统：**Mozilla Firefox <61，Mozilla Firefox ESR <52.9，Mozilla Firefox ESR <60.1

**漏洞描述：**Mozilla Firefox和Firefox ESR都是美国Mozilla基金会开发的浏览器产品。Firefox是一款开源Web浏览器。基于Windows平台的Mozilla Firefox 61之前版本、Firefox ESR 52.9之前版本和60.1之前版本中存在安全漏洞，该漏洞源于用户在打开带有SettingContent-ms扩展的可执行文件时，程序并没有提醒用户。远程攻击者可利用该漏洞执行任意代码。

**解决方案：**厂商已发布了漏洞修复程序，请及时关注更新：

https://www.mozilla.org/en-US/firefox/

**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-12368

 

**Debian devscripts任意代码执行漏洞**

**漏洞等级：**高危

**受影响系统：**Debian devscripts <=2.18.3

**漏洞描述：**Debian是Debian计划（Debian Project）组织开发维护的一套自由的操作系统。devscripts是其中的一个集合了多个系统维护脚本的软件包。Debian devscripts 2.18.3及之前的版本中的scripts/grep-excuses.pl文件存在安全漏洞，该漏洞源于程序未能安全的使用YAML::Syck。攻击者可利用该漏洞执行任意代码。

解决方案：厂商尚未提供漏洞修复方案，请关注厂商主页更新：

https://packages.debian.org/search?keywords=devscripts

参考链接：

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-13043

 

**QNAP QTS LDAP Server命令注入漏洞**

**漏洞等级：**高危

**受影响系统：**QNAP Systems QTS <=4.2.6 build 20171208

**漏洞描述：**QNAP QTS是中国威联通（QNAP Systems）公司的一套Turbo NAS作业系统。该系统可提供档案储存、管理、备份，多媒体应用及安全监控等功能。LDAP Server是其中的一个轻量级目录访问协议服务器。QNAP QTS 4.2.6 build 20171208及之前版本、4.3.3 build 20171213及之前版本和4.3.4 build 20171223及之前版本中的LDAP Server存在命令注入漏洞。远程攻击者可利用该漏洞在NAS上执行任意命令或安装恶意软件。

**解决方案：**厂商已发布漏洞修复程序，请及时关注更新：

https://www.qnap.com/en/security-advisory/nas-201806-19

**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-0712

 

**Huawei多款产品缓冲区溢出漏洞**

**tinyexr堆缓冲区溢出漏洞**

**漏洞等级：**高危
