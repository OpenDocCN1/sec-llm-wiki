**一、本周漏洞总体态势**

    

  

**1\. 总体态势跟踪**

最近一周，深信服科技北研安全团队跟踪国内外多个漏洞相关平台（CNNVD、CVE、Exploit database、Security focus、Packet Storm等），各平台总计增长漏洞643条。

 

其中Exploit database增长漏洞33条，Security focus增长漏洞103条，Packet Storm增长漏洞69条，CNNVD漏洞增长最多，共增长438条（占比68.1%）。

![](../Images/02f853bed684c5e8b65792bed20960c8.png)

整体漏洞类型与利用占比情况如下，web应用程序开发占比最高（49%），应重点关注，其次是本地特权升级利用占比15%，远程攻击和安全文件占比相同均为26%，拒绝服务概念验证和利用Shellcode存档占比最少（均为6%）。  

![](../Images/a90999f03f8c04cfc7006e0078dcf399.png)

   

**2. 重要厂商漏洞跟踪**

最近一周，深信服科技北研安全团队所跟踪的50多个重点软件厂商中，VMware、Oracle、Adobe三家厂商发布安全补丁和更新。其中VMware更新漏洞2条，Oracle更新漏洞113条，Adobe更新漏洞50条（其中高危漏洞8条），详细漏洞信息如下。

 

**VMware产品安全漏洞**

**产品介绍：**

VMware，是全球云基础架构和移动商务解决方案厂商，提供基于VMware的解决方案， VMWare虚拟机软件是一个“虚拟PC”软件,它使你可以在一台机器上同时运行二个或更多Windows、DOS、LINUX系统。

2018年7月19日，VMware官方发布安全更新，涉及产品及漏洞包括VMware Horizon View Agent本地信息泄露漏洞（CVE-2018-6971），因为在安装期间（包括静默安装）指定了当前登录用户以外的帐户时，vmmsi.log文件中的凭据记录不安全。 成功利用此问题可能允许低权限用户访问Horizon View Agent安装期间指定的凭据；ESXi，Workstation和Fusion拒绝服务漏洞（CVE-2018-6972），由于RPC处理程序中的NULL指针解除引用问题，VMware ESXi，Workstation和Fusion包含拒绝服务漏洞。 成功利用此问题可能允许具有正常用户权限的攻击者崩溃其VM。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.vmware.com/security/advisories/VMSA-2018-0018.html

 

**Oracle产品安全漏洞**

**产品介绍：**

甲骨文公司，全称甲骨文股份有限公司(甲骨文软件系统有限公司)，是全球最大的企业级软件公司。WebLogic是一个applicationserver，是一个基于JAVAEE架构的中间件，WebLogic是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。

本周，Oracle产品被披露存在多个漏洞，攻击者可利用漏洞影响机密性、完整性及可用性。涉及产品包括OracleWebLogic，Oracle Fusion Middleware，Oracle Java SE和Java SEEmbedded。涉及高危漏洞有OracleWebLogic反序列化远程代码执行漏洞、Oracle Fusion Middleware Oracle WebLogic Server组件远程漏洞（CVE-2018-2935 ）、Oracle Java SE存在未明漏洞（CVE-2018-2938 、CVE-2018-2964 ），目前，厂商已经发布了上述漏洞的修补程序。提醒用户及时下载补丁更新，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://www.oracle.com/technetwork/topics/security/public-vuln-to-advisory-mapping-093627.html

 

**Adobe产品安全漏洞**

**产品介绍：**

Adobe是世界领先的数字媒体和在线营销解决方案供应商。Adobe Reader(也被称为AcrobatReader)是一款PDF文件阅读软件。

2018年7月17，Adobe官方发布安全更新。上述产品被披露存在类型混淆和缓冲区溢出漏洞，攻击者可利用漏洞执行任意代码。涉及产品及漏洞包括Adobe FlashPlayer类型混淆漏洞（CVE-2018-5007 ）、Adobe Acrobat和Reader缓冲区溢出漏洞（CVE-2018-5043 、CVE-2018-12784 、  CVE-2018-5034 、CVE-2018-5037 ）、Adobe Acrobat和Reader类型混淆漏洞（CVE-2018-12793 、CVE-2018-12794 、CVE-2018-5057 ）。上述漏洞的综合评级为“高危”。目前，厂商已经发布了上述漏洞的修补程序。Oracle建议客户始终应用最新的重要补丁更新，以防范已知漏洞，避免引发漏洞相关的网络安全事件。

**参考链接：**

https://helpx.adobe.com curity/products/flash-player/apsb18-24.html

  

    

**二、重要漏洞预警**

    

**1.Weblogic反序列化漏洞CVE-2018-2893**

**漏洞等级：**高危

**受影响系统：**Oracle WebLogic Server10.3.6.0，12.2.1.2，12.2.1.3，12.1.3.0

**漏洞描述：**Oracle官方发布了7月份的关键补丁更新CPU（Critical Patch Update）,其中包含一个远程代码执行漏洞，漏洞威胁等级为高危，漏洞对应的CVE编号为CVE-2018-2893。此漏洞产生于Weblogic T3服务，所有开放Weblogic控制台端口的应用，均会默认开启T3服务。攻击者可以利用UnicastRef和远端建立tcp连接，获取RMI registry，再将加载的内容利用readObject解析，从而造成反序列化远程代码执行。

**解决方案：**目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujul2018-4258247.html  
**参考链接：**

http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-2893

 

**2.Weblogic任意文件上传漏洞CVE-2018-2894**

**漏洞等级：**高危

**受影响系统：**Oracle WebLogic Server10.3.6.0，12.2.1.2，12.2.1.3，12.1.3.0   

**漏洞描述：**Oracle官方发布了7月份的关键补丁更新CPU（Critical Patch Update）,其中包含一个任意文件上传漏洞，漏洞威胁等级为高危，漏洞对应的CVE编号为CVE-2018-2894。此漏洞产生于Weblogic中 /ws\_utc/config.do路径下的一个上传点，所有存在此路径的Weblogic用户均有可能受到此漏洞的影响。Weblogic 任意文件上传漏洞是通过ws\_utc/config.do路径进行配置的过程中，在配置界面中会存在一个上传点，我们可以更改当前的工作路径，将路径改变成一个我们无需权限即可访问的路径，目的是我们可以不受限制的去访问我们接下来要上传的shell。

**解决方案：**目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

http://www.oracle.com/technetwork/security-advisory/cpujul2018-4258247.html

**参考链接：**http://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2018-2894

**受影响系统：**Oracle JD Edwards EnterpriseOne Tools 9.2

**漏洞描述：**Oracle JD Edwards EnterpriseOne Tools为Oracle JD Edwards EnterpriseOne应用程序提供基础技术。Oracle JD Edwards EnterpriseOne Tools 9.2中的Web Runtime组件存在安全漏洞。漏洞允许通过HTTP进行网络访问的低权限攻击者破坏JD Edwards EnterpriseOne Tools。 成功攻击此漏洞可能导致未经授权访问关键数据或完全访问所有JD Edwards EnterpriseOne Tools可访问数据。
