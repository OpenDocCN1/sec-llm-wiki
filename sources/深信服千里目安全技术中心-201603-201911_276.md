# 【漏洞预警】Weblogic任意文件上传漏洞CVE-2018-2894

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514174&idx=1&sn=3344839bbda13d2bfb72940818ea8afc&chksm=ce46332ef931ba38135935bbd184b4896247c74bb6ddc0efa23b84c61c7670e22768df6e5d66&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514174&idx=1&sn=3344839bbda13d2bfb72940818ea8afc&chksm=ce46332ef931ba38135935bbd184b4896247c74bb6ddc0efa23b84c61c7670e22768df6e5d66&scene=27#wechat_redirect)

Oracle官方发布了7月份的关键补丁更新CPU（Critical Patch Update）,其中包含一个任意文件上传漏洞，漏洞威胁等级为高危，漏洞对应的CVE编号为CVE-2018-2894。

 

    

**千里百科**

    

  

WebLogic是美国Oracle公司出品的一个application server，确切的说是一个基于JAVAEE架构的中间件，WebLogic是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。

 

将Java的动态功能和Java Enterprise标准的安全性引入大型网络应用的开发、集成、部署和管理之中。Weblogic是商业市场上主要的Java（J2EE）应用服务器软件（application server）之一，是世界上第一个成功商业化的J2EE应用服务器，具有可扩展性，快速开发，灵活，可靠性等优势。

 

    

**漏洞描述**

    

  

此漏洞产生于Weblogic中 /ws\_utc/config.do路径下的一个上传点，所有存在此路径的Weblogic用户均有可能受到此漏洞的影响。据统计，在全球范围内对互联网开放Weblogic服务的资产数量多达35,382台，其中归属中国地区的受影响资产数量为10,562台。具体数据如下图：

![](../Images/6ec8c6a8c9189fe3d0a87dedf35a1ccb.png)

Weblogic 任意文件上传漏洞是通过ws\_utc/config.do路径进行配置的过程中，在配置界面中会存在一个上传点，我们可以更改当前的工作路径，将路径改变成一个我们无需权限即可访问的路径，目的是我们可以不受限制的去访问我们接下来要上传的shell。接下来的步骤就是利用上传点上传shell，并在对应路径进行访问，getshell。  

 

    

**漏洞复现**

    

  

上面描述的可能过于专业化，我们准备了一个案例让各位小伙伴们直观的了解一下。

由于触发此漏洞的前提是：

1.使用Oracle WebLogic Server10.3.6.0；Oracle WebLogic Server12.2.1.2；Oracle WebLogic Server12.2.1.3；Oracle WebLogic Server12.1.3.0中的任何一个版本的weblogic。

2.对外开放weblogic端口。

3.存在/ws\_utc/config.do路径。

据此搭建一套weblogic 12.2.1.3的运行环境。

![](../Images/06d83d2421f84874908bb057f726b563.png)

我们首先访问ws\_utc/config.do路径。

![](../Images/1f9e78306c4af7f56ec420a363a2a8b6.png)

在图中红色框框内，我们可以更改工作目录，将其替换成一个无需权限就可以访问的路径，这里我们替换成  

/u01/oracle/user\_projects/domains/base\_domain/servers/AdminServer/tmp/\_WL\_internal/com.oracle.webservices.wls.ws-testclient-app-wls/4mcj4y/war/css。

![](../Images/b6602ca2979fed59ce2a79efdd086674.png)

接下来我们点击图中的 安全->添加，在弹出的对话框中，我们可以看见上传点，通过这个上传点，我们可以上传任意文件，这里我上传了pwn6.jsp的shell文件。

![](../Images/4f118e639f525a5f38474a5436c68cfb.png)

在这里我们要记录好返回数据包中的时间戳（途中红色框框内的信息），因为最后生成的文件名是“\[时间戳\]\_\[文件名\]”的格式。以图中上传的shell文件为例，最后上传的shell文件名为1532056314098\_pwn6.jsp。  

 

最后我们在之前更改的路径下访问我们的shell文件，成功获得服务器shell，如下图。

![](../Images/aebd905e9dc8554ca620db94ad4c609b.png)
