# 【漏洞预警】git客户端远程代码执行（cve-2018-11235）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514155&idx=1&sn=547df4390522ee77e23e06564d1d1349&chksm=ce46333bf931ba2d9691e6a464a75c36f53cccc70952d434c47f8f1fb4ee243d51a05f30c0bf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514155&idx=1&sn=547df4390522ee77e23e06564d1d1349&chksm=ce46333bf931ba2d9691e6a464a75c36f53cccc70952d434c47f8f1fb4ee243d51a05f30c0bf&scene=27#wechat_redirect)

近日，开源的分布式版本控制系统Git的客户端被发现存在一个远程代码执行漏洞。漏洞的CVE编号为cve-2018-11235。

    

**千里百科**

    

Git是一个开源的分布式版本控制系统，可以有效、高速的处理从很小到非常大的项目版本管理。Git 是 Linus Torvalds 为了帮助管理 Linux 内核开发而开发的一个开放源码的版本控制软件。尽管最初 Git 的开发是为了辅助 Linux 内核开发的过程，但是很多其他自由软件项目中也使用了 Git。由于其脚本配置的简便性，Git也非常方便新手使用。国内外使用Git工作的个人或者团队也在逐渐增加。

    

**漏洞描述**

    

本次的漏洞的主要原因是由于Git在签入项目的子模块时，由于.gitmodules存在恶意伪造的子模块路径，子模块路径中存在../../等允许路径向前回溯的字符，导致Git检测到对应的子模块已经存在于工作目录中，因此未对子模块做签入校验，而是直接采用了子模块的配置文件，当应构造好的hooks文件夹存在post-checkout文件时，会直接执行该文件，导致远程代码执行。

    

**漏洞复现**

    

本次复现分别使用了Git客户端1.9.1以及Git服务端2.14.1两个应用程序，使用ubuntu 14.04.2 LTS作为测试环境。

使用已经公开的poc脚本构造恶意的Git文件以及目录。

![](../Images/b1d523bdf8a2d0788b3e678157ca3dae.png)

  

随后配置好git用户名以及密码，也可以通过配置RSA密钥的方式来省去git clone时需要输入git密码的步骤。

接下来，在Git客户端，通过git clone --recurse-submodules git@remoteip:/remotedir 的方式将远程Git服务器上的项目签入到本地。

![](../Images/6efbb842abec94e3c46fe21292136142.png)

在签入的过程中，由于未对子模块的路径做校验，导致执行了子模块中的post-checkout恶意脚本，在本次实验中构造的子模块路径如下：

![](../Images/629f928f783eaca36e9b0297159bb2d4.png)

该恶意脚本的位置在子模块所属配置文件的hooks文件夹中，hooks文件夹中存放在一些用于项目进行初始化工作的脚本，通常情况下并不会在签入远程项目的时候执行。

![](../Images/fede6af054aa9709dc22d7915a7980af.png)

在Git2.14.1版本的服务端进行本地克隆，同样会执行对应的恶意脚本。

![](../Images/b0bccb10f3a0334eceae770341ad10fd.png)

  

    

**影响版本**

    

Git version < 2.13.7

Git version 2.14.x < 2.14.4

Git version 2.14.x < 2.14.4

Git version 2.14.x < 2.14.4

Git version 2.14.x < 2.14.4

    

**修复建议**

    

目前官方已经推出了更新补丁，个版本的下载地址如下：

Windows:   

https://git-scm.com/downloads

Linux:   

https://git-scm.com/downloads/linux

Mac:   

https://git-scm.com/downloads/mac

    

**缓解措施**

    

如果没法及时下载，也尽量在使用git进行拷贝的时候不用使用--recurse-submodules的参数
