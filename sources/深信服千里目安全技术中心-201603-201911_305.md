近日，Microsoft Windows远程代码执行漏洞攻击代码被披露出来，开启RRAS的用户面临威胁。漏洞的CVE编号为**CVE-2017-11885**。

    

**千里百科**

    

RRAS是Windows提供的一种远程服务，它允许用户从远端通过拨号连接连接到一个本地的计算机网络，一旦建立了连接，就相当于处在了本地的LAN中，从而可以使用各种各样的网络函数以便进行访问。它是专门为已经熟悉路由协议和路由选择服务的系统管理员使用而设计的。通过路由和远程访问服务，管理员可以查看和管理他们网络上的路由器和远程访问服务器。RRAS的主要有开放式最短路径优先(OSPF)、路由信息协议(RIP)、IP网络地址转换(NAT)服务、虚拟专用网络(VPN)等多种功能。

    

**漏洞描述**

    

RASS服务中的MIB\_OPAQUE\_QUERY结构中的dwVarID受指针解引用的影响，当dwVarID作为指针指向功能函数数组时，服务程序并不会检测指针是否指向数组边界以外的区域，这就使得攻击者能够控制指针指向特定的内存区域，从而获得代码执行的能力。攻击者只需向目标服务器发送RASS服务处理请求，就可以在目标服务器上执行任意代码。

    

**漏洞复现**

    

为了直观的展示此漏洞的攻击效果，我们准备了一个演示环境让各位小伙伴们直观的了解一下。

首先我们在Windows Server 2003 SP2配置RRAS服务，配置服务过程中需要服务器有两块以上的网卡。

进入服务器管理、添加新角色

选择自定义配置，

![](../Images/40d322f2acfb3b2422057d8ef1098d52.png)

选择Remote access / VPN server选项，

![](../Images/8a56e73c1b193eecfab8db29e1c88f5a.png)

网络模式选择NAT，

![](../Images/10fe62ac64286449e44c792b5d482e83.png)

RASS服务配置完毕。

攻击首先发起一个DCE-RPC请求到靶机的RRAS服务。

通过msfvenom生成一个绑定4444端口的shell，

**修复建议**

    

微软已在2017年12月发布的官方更新提供了该漏洞的补丁，但微软只针对Windows 10、Windows 8.1、Windows 7、Windows Server 2016、Windows Server 2012、Windows Server 2008系统发布了安全补丁，使用上述版本的用户可以在下面的网址中更新安全补丁或使用Windows的自动更新功能

更新链接：

*https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-11885*

 

    

**缓解措施**

    

由于该漏洞需要开启RRAS服务才能攻击，广大用户也可以通过禁用RRAS服务防御此漏洞攻击。
