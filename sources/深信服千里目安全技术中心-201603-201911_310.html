1.Linux Kernel 可预测随机数生成器缺陷漏洞

漏洞等级：高危
受影响系统： Linux Kernel
CVE编号： CVE-2018-1108
漏洞描述
Linux是一套免费使用和自由传播的类Unix操作系统，是一个基于POSIX和UNIX的多用户、多任务、支持多线程和多CPU的操作系统。

Linux kernel 被证明存在一个本地可预测随机数生成器缺陷漏洞。攻击者能够利用此漏洞绕过限制并执行未授权的操作。Linux kernel 4.15.4之前的版本都受此漏洞的影响。

解决方案
软件开发人员可以通过https://lkml.org/lkml/2018/4/12/711重新编译Linux修复此漏洞。

2.FTPShell Client 6.7 缓冲区溢出漏洞

漏洞等级：高危
受影响系统： FTPShell Client 6.7
CVE编号：CVE-2018-7573
漏洞描述
FTPShell客户端是一个Windows文件传输程序，使用户可以可靠地传输文件，上传到网站，并从互联网下载更新。


在FTPShell Client 6.7中发现了一个问题。远程FTP服务器可以发送400个'F'字符以及FTP 220响应代码以使应用程序崩溃；在溢出之后，可以在受害机器上运行任意代码。这与CVE-2009-3364和CVE-2017-6465类似。

解决方案
    目前厂商还没有提供补丁或者升级程序，我们建议使用此软件的用户随时关注厂商的主页以获取最新版本：http://www.ftpshell.com/index.htm

中文版参考链接
    http://sec.sangfor.com.cn/vulns/351.html

3.Ncomputing vSpace Pro目录穿越漏洞

漏洞等级：高危
受影响系统： Ncomputing vSpace Pro v10-v1
CVE编号： CVE-2018-10201  
漏洞描述
NComputing vSpace是一款强大的桌面虚拟化产品。在NComputing vSpace Pro 10 和 11中发现一个漏洞。


这个漏洞可以通过使用…/ 或 …\ 或 …./ 或 ….\ 这种目录穿越的攻击模式构造的URL被远程利用，而无需用户的凭证。攻击者利用这个漏洞可以突破应用程序根目录的限制，访问文件系统的其他部分。这样可以使攻击者有能力访问受保护的文件，这会为攻击者进一步入侵系统提供更多的有用信息。


解决方案
目前厂商已公布升级程序，我们建议使用NComputing vSpace的用户安装最新版本。更新下载地址为：https://www.ncomputing.com/products/vSpace/vSpace PRO#DOWNLOA

中文版参考链接
    http://sec.sangfor.com.cn/vulns/349.html

4.2345安全卫士3.7拒绝服务漏洞

漏洞等级：高危
受影响系统： 2345安全卫士3.7版本
CVE编号：   CVE-2018-10809
漏洞描述
2345安全卫士是集电脑体检、木马查杀、垃圾清理、修复系统漏洞、系统加速、软件管理等功能为一体的电脑安全管理的软件。


在2345安全卫士3.7中，因为驱动程序文件（2345NetFirewall.sys）未验证来自IOCtl 0x00222040的输入值，导致本地用户造成拒绝服务（BSOD）或可能具有未指定的其他影响。 注意：由于对CVE-2018-8873的修复不完整，因此存在此漏洞。

解决方案
目前厂商还没有提供补丁或者升级程序，我们建议使用此软件的用户随时关注厂商的主页以获取最新版本：http://safe.2345.cc/
