【漏洞预警】Spring Framework多处重要安全漏洞预警

近日，在Pivotal发布的一份报告中，安全研究人员在Spring Framework5.0- 5.0.4、4.3-4.3.14以及不支持的旧版本等多个版本中发现了三个重要漏洞：CVE-2018-1270、CVE-2018-1271、CVE-2018-1272。

 

千里百科

Spring Framework是一个Java/Java EE/.NET的分层应用程序框架。它是一个基于IOC和AOP构架多层J2EE系统的开源框架，模块化好且实现了很优雅的MVC，对不同的数据访问技术提供了统一的接口。此外它采用的IOC可以很容易的实现Bean的装配，提供的AOP简洁易用并据此实现了Transaction Management等功能。Spring Framework 提供简易的开发方式，这种开发方式，将避免那些可能致使底层代码变得繁杂混乱的大量属性文件和帮助类。目前此框架的使用非常活跃。

漏洞描述

CVE-2018-1270漏洞: Spring框架5.0-5.0.4、4.3-4.3.14以及不支持的旧版本等多个版本允许应用程序通过Spring-messaging模块在WebSocket端点上通过一个简单的STOMP代理来公开STOMP客户端。恶意用户(或攻击者)可以利用此模块向代理发送恶意的消息，从而导致远程代码执行攻击(CVE-2018-1270，高危)。

 

CVE-2018-1271漏洞: Spring框架5.0-5.0.4、4.3-4.3.14以及不支持的旧版本等多个版本允许应用程序基于Spring MVC配置静态资源(例如CSS、JS和图像)。当配置为从Windows上的文件系统提供静态资源时，恶意用户(或攻击者)可以使用一个特别制作的URL发送请求，该URL可以引导目录遍历攻击和访问受限目录(CVE-2018-1271，重要)。

 

CVE-2018-1272漏洞: Spring框架5.0-5.0.4、4.3-4.3.14以及不支持的旧版本等多个版本支持客户端侧的Multipart请求。当Spring MVC或Spring WebFlux服务器（服务器A）将从客户端侧接收到的请求用于向另一台服务器（服务器B）做Multipart请求时，此过程容易被攻击者截获并修改，受污染的Multipart请求会导致另一台服务器错误地执行。如果请求中包含用户名或者用户角色等信息，可能会导致攻击者权限提升(CVE-2018-1272,低危)。

 

影响版本

Spring Framework 5.0-5.0.4，

Spring Framework 4.3-4.3.14,

不支持的旧版本（3.2.0以下）。

 

修复建议

目前暂无漏洞POC，请及时关注深信服安全云和千里目安全实验室微信公众号，我们将第一时间推送此漏洞解决方案。

建议使用如下措施避免本次漏洞影响：

(1)修复CVE-2018-1270：

   对消息进行身份验证和授权，比如Spring Security提供的消息，只允许认证用授权的户使用该应用程序。

(2)修复CVE-2018-1271：

   不使用Windows；

   不提供文件系统的文件，即不使用“文件”；

   用带有CVE-2018-1199补丁版本的Spring Security；

   使用Tomcat或WildFly作为服务器。

(3)修复CVE-2018-1271：暂无修复方案。

 

缓解措施

(1)Spring Framework 5.x的用户请尽快更新到Spring Framework 5.0.5版本；

(2)Spring Framework 4.3.x的用户请尽快更新到Spring Framework 4.3.15版本；

(3)使用不支持的Spring Framework旧版本的用户，请尽快更新到Spring Framework 4.3.15或者5.0.5最新版本。

Spring Framework更新到4.3.15或5.0.5最新版本下载链接地址：

http://repo.springsource.org/libs-release-local/org/springframework/spring/

或

https://github.com/spring-projects/spring-framework/releases

 

同时为了兼容上述两个最新版本，建议用户先升级Spring Boot版本：

Spring Framework 4.3.15：对应先升级Spring Boot 1.5.11版本；

Spring Framework 5.0.5：对应先升级Spring Boot 2.0.1版本.

下载地址：https://github.com/spring-projects/spring-boot/releases

信服君总结

    Spring Framework本次被发现的三个漏洞中，漏洞严重程度不一样，其中需要重点关注的是CVE-2018-1270 远程代码执行的高危漏洞。

    据研究指出，Spring框架在全球目前下载已超过百万次，影响面极为广泛。如果本次远程代码漏洞被攻击者广泛利用，可能会对应用程序产生巨大的威胁。这是非常危险的，攻击者可以完全接管一个Web应用程序，并在服务器上运行他们的代码，进而控制大批量用户的Web系统。
