# 内容管理系统二次开发，是谁纵容了篡改

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514095&idx=1&sn=9341b31882f3dea4b019f39a5445e66c&chksm=ce463cfff931b5e9eaa4065e3a60a2881a85dd526844203e3f89927043d173723db32a8964b8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514095&idx=1&sn=9341b31882f3dea4b019f39a5445e66c&chksm=ce463cfff931b5e9eaa4065e3a60a2881a85dd526844203e3f89927043d173723db32a8964b8&scene=27#wechat_redirect)

今天小齐子扔了一批URL给我，说交给我处理，一脸懵0.0.

URL全是EDU的网站，打开几个URL看看，发现都是一些被篡改的网站，里面的内容真是不堪入目，不可描述，大部分受影响网站都是教育网站。

![](../Images/e398a1b6946190705ce200157e998654.png)

  

打开其中一个网站的主页，挺正经的，是某211、985重点大学，不过都已经开始给别家打广告挣零花钱了嘛？不太好啊。

![](../Images/5d905bb19e47614c92a99050660c623a.png)

没有日志，没有信息，无从下手啊....先看看批量找到的URL，大部分URL都有这样的共性：/e/space/UserInfo.php?userid=

![](../Images/f242bd53bc3f1bc583a2a3a0d8e8649a.png)

  

首先确定的条件是网站使用的是 EmpireCMS 二次开发的，URL 看起来应该是一个显示已注册用户信息的地方，推断可能是由于某大学二次开发的时候未删除注册模块，被恶意攻击者借用来实施篡改，哎，安全开发意识不足啊。

本来打算就这样结束的时候又好奇遍历了一下 ID，发现了点有意思的事

![](../Images/17c6c86cd1c3a0ef01b261d841fd8d31.png)

![](../Images/28dbda148cae4bea4ee8c59ad5f2395e.png)

ID 为 43419 的用户和 ID 为 43420 的用户几乎是同时注册的，再观察相近几个用户 ID，注册时间均在同一时段。有点意思啊，看起来像是脚本批量注册，不过这个 EmpireCMS 好像也有点问题啊，怎么可以允许这么注册呢，难道没有保护机制嘛？我决定在本地搭建测试环境看看。

  

本地搭建 EmpireCMS 7.2 版本测试一下注册流程，找到注册页面：

![](../Images/cd5d6d812cde20988e0f1b78414416d0.png)

  

点击下一步就到了真正的注册页面：

![](../Images/d81bf46e06fd97d90fd202d7d445938f.png)

  

果然没有复杂一点的提交验证机制，连验证码都没有，难怪这么容易就可以注册，添加内容看一下数据包，随便 fuzz 一下发现好像没有什么验证机制，感觉自己推断的好像是有点道理的，于是乎写一个批量注册的脚本在本地环境中跑一下，先注册十个用户（用户名六位随机，个人介绍提交篡改内容）试试（脚本就不给了，自己测试吧）：

![](../Images/ac37577d9174d1e5a1649fc37c572c75.png)

  

好像成功了啊，从前台页面找到我提交注册的恶意账号：

![](../Images/9cb4d0ede634f077b572632d333e4241.png)

前台可以看到埋下的篡改，也完全复现了这次刷黑链SEO的场景，除了7.2版本，6.0-7.1版本也可以被利用。

  

**修补方案：**

EmpireCMS 作为比较靠前的内容管理系统，导致很多大型的企业学校都对它进行二次开发，但是在用户模块未关闭或审核未开启的时候存在逻辑缺陷漏洞，由于验证机制不足，导致绕过第一步后直接批量的注册并且上传暗链，这算是黑产刷 SEO 的新方式，其目的是优化自己网站中的一些关键字在搜索引擎中的排名，或是提高自己网站的搜索引擎权重，影响范围很广，建议 EmpireCMS 修补方案如下：

1.增加 referer 验证（最简单方法，但是容易绕过）

2.设计一个单点登录，生成一个 token，放到 cookie 里。

3.服务端设置 session 记录当前到哪一步。

4.可以设置第一步成功之后得到某个值，第二步需要这个值才能操作。

二次开发的企业临时解决方案：

1.关闭会员模块

2.如果需要会员模块，请开启审核注册
