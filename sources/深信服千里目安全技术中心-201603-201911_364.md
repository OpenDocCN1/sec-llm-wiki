据 Struts 官方披露，Struts2 的 showcase 应用中存在远程代码执行漏洞。漏洞编号 S2-048，CVE 编号 CVE-2017-9791。

![](../Images/a415d2c462541feba258a3c708f51779.png)

  

千里百科

Struts2 是一个基于 MVC 设计模式的 Web 应用框架，它本质上相当于一个 servlet，在 MVC 设计模式中，Struts2 作为控制器 (Controller) 来建立模型与视图的数据交互。Struts2 的使用范围及其广泛，国内外均有大量厂商使用该框架。

  

漏洞概述

当 Struts2 中的  Struts1 插件启用的情况下，攻击者通过使用恶意字段值可能造成 RCE。这些不可信的输入数据被带入到 ActionMessage 类中的错误信息中。Struts 2.3.x 系列版本全部受此漏洞影响。

  

官方解决方案

使用resource keys替代将原始消息直接传递给ActionMessage的方式。 如下所示

messages.add("msg", new ActionMessage("struts1.gangsterAdded", gform.getName()));

不要使用如下的方式

messages.add("msg", new ActionMessage("Gangster " + gform.getName() + " was added

  

**根据官方发布的消息，漏洞利用条件比较苛刻（漏洞触发需要非默认插件 struts2-struts1-plugin，且需要手动将客户端参数值添加入 action message 的点），千里目安全实验室将持续关注此次漏洞进展，最快速度给出完整的解决方案。**
