# 【漏洞预警】Node.js 反序列化远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514079&idx=1&sn=baf1be31f9389a801f88a6eea901d7e9&chksm=ce463ccff931b5d93359092f697989bb6fe57cdb1c9f858af1f7397909b321fcaffa7554fdd4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514079&idx=1&sn=baf1be31f9389a801f88a6eea901d7e9&chksm=ce463ccff931b5d93359092f697989bb6fe57cdb1c9f858af1f7397909b321fcaffa7554fdd4&scene=27#wechat_redirect)

2 月 10 日，Node.js 曝存在反序列化远程代码执行漏洞。漏洞 CVE 编号 CVE-2017-5941。攻击者利用此漏洞通过构造 Payload 对服务器进行远程攻击，从而获得服务器权限。

  

千里百科

Node.js 是一个 Javascript 运行环境 (runtime)。实际上它是对 Google V8 引擎进行了封装。V8 引擎执行 Javascript 的速度非常快，性能非常好。Node.js 对一些特殊用例进行了优化，提供了替代的 API，使得 V8 在非浏览器环境下运行得更好。

  

漏洞原理

Node.js 的 node-serialize 库中存在一个漏洞，该漏洞通过传输 JavaScript IIFE，利用恶意代码（未信任数据）达到反序列化远程任意代码执行的效果。

漏洞修复

  

1、厂商尚未发布官方漏洞补丁，请关注厂商主页及时更新：

*https://github.com/luin/serialize*

2、临时修复方案

  

（1）修改 /node\_modules/node-serialize/lib/serialize.js 中的 FUNCFLAG 值为随机值并保证该值不被泄漏。

  

（2）确保 Serialize 字符串仅内部发送。

  

（3）使用公钥（RAS）加密 Serialize 字符串，确保字符串不被篡改。
