# 高危漏洞预警- Linux 内核本地提权"脏牛漏洞" | 千里目安全实验室

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514070&idx=1&sn=a96b31b2a66861f836174a0cde8d5b2c&chksm=ce463cc6f931b5d0d8ea436788279608e7a130ed3b52ba2cc61646407d68496206bbdc90a18c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514070&idx=1&sn=a96b31b2a66861f836174a0cde8d5b2c&chksm=ce463cc6f931b5d0d8ea436788279608e7a130ed3b52ba2cc61646407d68496206bbdc90a18c&scene=27#wechat_redirect)

漏洞描述

10 月 19 日，国外安全研究人员 Phil Oester 在 RedHat 官网的安全公告中发布了一个全版本 Linux 内核本地提权漏洞（CVE-2016-5195），被称为 “脏牛漏洞”（Dirty Cow）。之所以称为 Dirty Cow，是因为Linux内核在进行内存管理时使用的写时复制（Copy on Write）机制存在条件竞争漏洞，从而引起内存破坏，导致权限提升。目前虽然没有公布漏洞细节，但是已经有 PoC 和 Exp 流出，在此呼吁广大用户及时升级自己的 Linux 系统。

漏洞危害

攻击者利用该漏洞可以在全版本 Linux 系统上进行本地权限提升，获得系统 root 权限。

漏洞影响

所有使用 Linux 内核版本 >=2.6.22 的系统，都会受到该漏洞的影响。比如各类 Linux 发行版：RedHat、CentOS、Debian、Ubuntu，OpenSUSE 等，也包括介于 Linux 内核的各类衍生产品，比如 Android 系统的手机和平板电脑、各类基于 Linux 内核的嵌入式设备和智能设备、Docker 镜像等等。

漏洞修复

**Debian/Ubuntu Linux**

这里以 Ubuntu 16.04 LTS (xenial) 系统为例

1.建议使用官方源，必须在 /etc/apt/sources.list 中开启 -security 后缀的源，如下图：

![](../Images/8ee89cc8fbac6bd9ec8f7681548f01c8.png)  

2.执行更新升级命令

> apt-get update
> 
> apt-get -y upgrade
> 
> apt-get -y dist-upgrade

3.重启系统

> shutdown -r 0

4.再次查看 Linux 内核，已经更新至最新

![](../Images/922158d2e9860b3e068e42b79df0f483.png)  

  

**RHEL / CentOS Linux 5.x/6.x/7.x**

> $ sudo yum update
> 
> $ sudo reboot

  

**RHEL / CentOS Linux 4.x**

> $ sudo up2date -u
> 
> $ sudo reboot
