恶意软件感染自检与防护小妙招

网络世界里，看似繁华精彩，实则险象环生，一不小心就可能中了恶意软件的招。你是否曾经无意中发现自己的电脑或手机固定地弹出某一个广告的提示窗？或是浏览器打开某些特定的链接时会跳转到一些毫不相干的网站？也可能自己的浏览器主页莫名其妙地被篡改到一些特定的网页？还可能本来流畅无比的电脑或手机莫名其妙地变得卡顿严重？甚至直接大部分文件、图片都打不开而且桌面被篡改成了勒索赎金的信息？如果这些事情曾经发生在你的电脑或手机上，那么你的电脑、手机很可能——文件被加密而受到勒索则百分百确定——被恶意软件感染了。


有没有一些简单可行的小妙招，能让我们在日常的生活、工作中感染了恶意软件之后进行自检确定，或者未雨绸缪、做一些防护措施以减少自身电脑和手机被感染的几率呢？本文就此给出一些小 Tips 。

如何判断感染了恶意软件？

很多时候，恶意软件的感染过程毫无征兆，感染成功后运行起来像是个隐秘的杀手，没有什么明显的外在症状，也像是所谓的“隐疾”，平时活蹦乱跳能唱能闹，一旦发作起来则“病来如山倒”。如果想知道自己的机器是否感染了恶意软件，首先需要了解恶意软件感染、运行过程中的一些典型现象。


很明显的特征

1.勒索软件

这是症状最明显的一类恶意软件。勒索软件的作者为了让受害者清晰地知道自己被感染了勒索软件，会在醒目的位置弹框、或者在每个目录下放一个明显的加密提示文本文件甚至直接替换电脑桌面壁纸。以此告诉受害者自己的文件被加密了，要在指定的时间之前向黑客交赎金，否则被加密的文件则会永远也无法解密。这便是勒索黑客的“生财之道”。


2.浏览器重定向

假如你在搜索引擎上搜一个东西，随便点击一个搜索结果，然后打开的页面是一个毫不相干的网站（比如充斥着某些“老师”的动图甚至短视频）。你关掉页面回去点击另外一个搜索结果条目，症状如上，重复尝试几次不同的搜索结果，症状都如此——你的机器肯定被植入了恶意软件。


3.浏览器主页被篡改

这也是比较常见的一种情况。不论自己把浏览器主页设置成什么网站，过一段时间打开浏览器总会发现主页被篡改成其他的网站——你肯定中了相关恶意软件。有些恶意软件就靠这种手段推特定网站的流量。


4.广告弹窗

关不完的弹窗，关掉一个另起一个。甚至不联网也会有一些广告的弹窗。这些情况说明你可能中了一些恶意推送广告的恶意软件。不过据说现在有些正常软件也会加入这样的功能……

不太明显的特征

1.系统卡顿

很多正常操作也能导致系统卡顿：同时运行过多程序、硬盘空间不足、空余内存太少、网络带宽过低……如果你机器配置不低、平时运行非常流畅的系统突然有一天打开就非常卡顿。那么可能中了一些恶意软件在消耗你的 CPU 计算资源、或者占用太多内存。如果你懂一些技术，可以进一步用特定工具软件查看一下系统的进程行为，运气好的话可以一下就确定恶意进程。


2.桌面上的陌生图标

如果哪天开机突然发现桌面上多了一个或多个图标，都不是自己安装的程序。一般是一些游戏或者相关联的一系列应用——最好不要点，多半是系统被植入了恶意软件，恶意软件推广的无关应用。（悄悄说一句，现在甚至某些看起来正常无害的软件也会做这种事。）


3.持续崩溃

正常情况下，软硬件兼容性、软件之间的冲突都可能造成软件或系统崩溃，但一些恶意软件比如 Rootkit ，会深入系统底层附着在内核进程上，造成系统不稳定。


4.浏览器冻结或持续无响应

系统中其他程序运行流畅无阻，浏览器开着寥寥几个标签页，网速也没有卡到蜗牛状，但是浏览器一直卡住动弹不得……多半是感染了恶意软件。

没有特征

什么？没有特征不是表明系统运行良好无异常么？如果这样想，未免太天真。其实很多恶意软件包括僵尸木马和窃取信息的木马，运行的时候都没什么动静，甚至很难被安全防护软件检测到。或者鉴于我们自身不够敏感，有一些蛛丝马迹也不一定能发现的了。


手机上的恶意软件

智能手机操作系统发展到今天，跟 PC 操作系统的差别越来越小。移动平台上的恶意软件跟 PC 上的恶意软件外在行为也越来越像。理论上 PC 机上由恶意软件引发的症状，移动平台上的恶意软件也都可能出现。

当然，移动平台上的恶意软件也有自己特有的特征，比如：耗电量。虽然正常地打开游戏、视频播放器、音频播放器等大 APP 能导致电量消耗比较快，但如果某天开始发现自己的手机耗电量比以前快很多，不开启什么 APP 也如此，手机很可能就感染了恶意软件。

如何免遭恶意软件感染？

通过前文的一些简单小 Tips，可以大致判断自己系统是否感染了恶意软件，那平时自己用电脑手机上网时，如何防范恶意软件的感染？这里也有一些小 Tips：

  1. 及时升级系统、应用、插件到最新版本，及时打安全补丁。新版本的系统、程序或者安全补丁里，会包含一些安全漏洞的修复，更新、打补丁以免受到针对这些漏洞的攻击；

  2. 启用「点击加载」插件。这类插件可以控制 Flash 视频或者 Java 应用的自动加载与执行，这样如果访问到包含自动播放的恶意 Flash 动画或者自动运行的 Java 应用的页面，就能免受攻击，而无害的 Flash 动画视频与 Java 应用，手动点击播放或执行即可；

  3. 删除不再使用的程序。多一个程序、多一份风险。很多不再使用的程序自己也想不起来更新，如果哪天爆出了可利用的漏洞，自己再次运行的时候就可能遭受攻击；

  4. 短信、邮件中的不明来源的链接，或者邮件、网页中不明来源的附件、程序，点击时要谨慎，尽量确定无害后再进行下一步操作；

  5. 加强自己密码的复杂性，不要多账户共用同样的密码，不要使用有明显规律的密码；

  6. 对于支持 HTTPS 访问的网站，确保自己用 HTTPS 访问；

  7. 有登陆操作的网站，关闭浏览器之前确保自己已经退出登录；

  8. 使用防护软件，比如防火墙、防病毒软件等，并定期更新病毒库。


平时多注意这些小 Tips，会大大降低感染恶意软件的概率。
