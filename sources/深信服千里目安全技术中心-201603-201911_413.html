AES.DDoS 又名 Dofloo 或 MrBlack，在 2014 年首次被发现，是一种感染基于 ARM 架构路由器的木马程序，大量感染设备被攻击者用来组建发动 DDoS 攻击的僵尸网络。

Incapsula 公司耗时 4 个月深入研究该恶意程序和僵尸网络，分析了世界各地的 1600 个 ISP 提供的流量，整理出来自 40269 个 IP 针对 60 位客户恶意攻击。发现所有发动攻击的路由节点均被 MrBlack 感染。


ARM ，全称 Acorn RISC Machine，是 Acorn 有限公司面向低预算市场设计的一款微处理器。具有体积小、低功耗、低成本、高性能等特点，广泛应用于嵌入式设备中。
传播方式
AES.DDoS 采用传统的 SSH 暴破攻击，攻击者首先会在一段 IP 范围内进行扫描，整理存在 SSH 端口的 IP，针对这些 IP 利用字典直接进行暴破。
样本分析

千里目实验室捕获 AES.DDoS 样本之后，对其进行了详细分析。分析结果显示相比 Xor.DDoS， AES.DDoS 虽然同为 DDoS 攻击木马，但仍然存在很多自身的特点。


从处理器上来说这是一款针对 ARM 处理器的 DDoS 攻击木马。



行为上 AES.DDoS 会首先读取 /proc/self/exe 获得木马程序的绝对路径并将路径写入 /etc/rc.local、/etc/rc.d/rc.local、/etc/init.d/boot.local 中，完成自启动。





AES.DDoS 木马会主动连接 C&C 服务器并发送受控主机的内核版本、CPU 和内存参数，接收 C&C 服务器发送的 DDoS 攻击指令，利用 AES 算法对接收的指令进行解密，根据解密的指令可以执行 4 种不同类型的 Flood 攻击。同时也可随时终止 DDoS 攻击。
命令控制

感染主机连接 C&C 服务器成功后，攻击者向感染主机发送指令 “6”，可以发起 DDoS 攻击，接收指令 “7” 可以杀死 DDoS 进程。



DDOS攻击
SYN_Flood 攻击

 SYN Flood 是一种广为人知的 DDoS（分布式拒绝服务攻击）攻击方式，这是一种利用 TCP 协议缺陷，发送大量伪造的 TCP 连接请求，从而使得被攻击方资源耗尽（CPU 满负荷或内存不足）的攻击方式。


正常情况下客户端与服务器端的连接：
1.客户端通过发送 SYN 同步（synchronize）信息到服务器要求创建连接
2.服务器通过响应客户端 SYN-ACK 以接收（acknowledge）请求

3.客户端答应 ACK，连接随之建立


SYN Flood 攻击目前有两种方法，不过都与服务器端没收到 ACK 有关。一种方法是攻击者不发送最后的 ACK 信息；另一种是在 SYN 里通过欺骗来源 IP 地址，让服务器发送 SYN-ACK 到伪造的 IP 地址，因此服务器永不可能收到客户端发来的 ACK。攻击者利用上述方法发送海量的 SYN 半连接，很快就会将服务器的资源耗尽，当正常用户访问服务器时，服务器已经没有资源可以分配，从而造成拒绝服务攻击。


TCP_Flood 攻击

TCP Flood 是向目标机发送大量 TCP 全连接，耗尽服务器资源，从而造成拒绝服务的一种攻击方式。


UDP_Flood 攻击

攻击者向目标主机发送随机端口号的 UDP 数据包，目标主机会检查这个端口是否存在应用服务，发现端口上不存在服务，主机会向原地址强制发送 ICMP 不可达数据包。当攻击者向目标主机发送大量的 UDP 数据包，目标主机会发送大量 ICMP 不可达报文，导致主机宕机。


DNS_Flood 攻击

DNS Flood 实际上是 UDP Flood 的一种应用变种。攻击者向 DNS 服务器发送大量 DNS 请求，消耗服务器资源。导致正常的 DNS 请求响应变慢。


CC_Flood 攻击
CC 英文全称 Challenge Collapsar，意为“挑战黑洞”。其前身为 Fatboy 攻击，是一种基于页面的分布式拒绝攻击，通过发送消耗性能的 HTTP 请求来消耗服务器资源。攻击者通过多次向目标机上的开销比较大的页面发起访问请求，导致目标主机进行大量计算，最终耗尽计算资源，从而拒绝所有服务的请求。
防御与查杀

AES.DDoS 木马主要由 SSH 端口密码破解入侵，可以通过关闭端口、设置强密码、部署安全设备来进行防御。由于受该病毒感染的主机较多，以下提供病毒的检查与清除方法。


1、检查 /etc/rc.local、/etc/rc.d/rc.local、/etc/init.d/boot.local 文件删除木马启动项


2、删除木马文件并杀死木马进程。
