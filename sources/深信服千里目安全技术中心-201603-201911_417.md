# 拿什么拯救你，我的 Struts2

千里百科

  

Struts2 是全球使用最广泛的 Java Web 服务端框架之一。Struts2 是 Struts 的下一代产品，是在 Struts1 和 WebWork 的技术基础上进行了合并的全新的 Struts2 框架。  
Struts2 官方于今年 4 月 20 日，发布 S2-032 漏洞通告：S2-032 远程代码执行漏洞，该漏洞是继 S2-016 漏洞以来，影响最大的 Struts2 漏洞。漏洞的利用代码一经曝光就在安全圈和互联网引起一场血雨腥风。漏洞披露Struts2 官方 4 月 20 日，发布 S2-032 漏洞通告，如下图：![](../Images/120de5b26d22228e4e77877d4c4bfc69.png)  
自从 S2-016 漏洞以来，虽然 Struts2 出现过多个远程命令执行漏洞，但由于其利用条件十分有限，显得过于鸡肋，导致人们并没有去关注。直到25日下午，具体的说法是 25 日下午 3 点 29 分，故事发生了戏剧性地转变。menmen519 牛在 Wooyun 社区发布的这个 PoC，引发了一场血雨腥风。![](../Images/17f946f5e3782e7e4f3948df59e03a23.png)  
该 PoC 显示利用此漏洞可直接向网站写入 Webshell ，人们终于意识到这是个影响严重、利用简单的 Struts2 高危漏洞。此后的几个小时内，漏洞利用的命令行工具、批量检测脚本、图形化工具、在线检测工具等被迅速开发出来，漏洞得到空前的重视。乌云、补天等漏洞提交平台都被该漏洞刷屏。Wooyun 平台到此时还未确认的 S2-032 漏洞比比皆是，如下图：![](../Images/17d7463e1fe435a7ec40e81f5576ce84.png)  
根据乌云漏洞中心的统计，该漏洞除了会影响银行与互联网企业(网易/多玩等)，还可能影响政府、证券、保险等行业。  
千里目实验室利用百度搜索了 300 个使用 Struts2 框架的网站，使用检测脚本进行检验，发现 16 个网站存在漏洞，存在漏洞的比例在 5% 左右。虽然该漏洞利用存在一定的前提条件，不如 2012 年的 S2-016 漏洞那样命中率高，但是使用 Struts2 框架的网站数量非常庞大，并且逐年增长，漏洞影响范围依然十分广泛。该漏洞会为今年安全行业留下色彩浓重的一笔。漏洞原理漏洞利用前提是开启动态方法调用。如果我们要调用对应的 *login* 方法，可以通过 *http://\[host\]/index!login.action* 来进行动态方法调用。这种动态方法调用的时候 *method* 中的特殊字符都会被替换成空，但是可以通过 *http://localhost:8080/struts241/index.action?method:login* 来绕过无法传入特殊字符的限制。![](../Images/b6f0e50a7ff0fcfce075920d65f6a96b.png)  
接收到的参数会经过处理存入到 *ActionMapping* 的 *method* 属性中。*DefaultActionProxyFactory* 将 *ActionMappping* 的 *method* 属性值设置到 *ActionProxy* 中的 *method* 属性![](../Images/bf02c97630b78cc14d22e6af9e7ed777.png)  
而 *DefaultActionInvocation.java* 会把 *ActionProxy* 中的 *method* 属性取出来放入到 *ognlUtil.getValue()* 方法中执行 *ognl* 表达式，如下图![](../Images/318c8530056991acac1bdd7dbc04f26a.png)  
**关于沙盒绕过:**通过 *ognl* 表达式静态调用获取 *ognl.OgnlContext* 的 *DEFAULT\_MEMBER\_ACCESS* 属性，并将获取的结果覆盖 *\_memberAccess* 属性，这样就可以绕过 *SecurityMemberAccess* 的限制。影响版本Struts 2.3.20 - Struts 2.3.28 (不包括2.3.20.2 和 2.3.24.2)漏洞危害**该漏洞利用简单、粗暴，甚至一个数据包就可以写入 Webshell，使服务器完全沦陷。该漏洞的危害主要有：**1\. 攻击者可以远程获取目标站点的网站、Web 服务器、数据库、操作系统等信息。2\. 攻击者可以远程执行任意系统命令。3\. 攻击者可以远程上传 Webshell ，在目标站点留下后门。4\. 以此漏洞为入侵点，进一步扩大入侵范围，提高获取的权限。修复与防护1、禁用动态方法调用修改 Struts2 的配置文件，将 “*struts.enable.DynamicMethodInvocation*” 的值设置为 *false*，比如：

> <constant name="struts.enable.DynamicMethodInvocation" value="false" />；

2、升级Struts版本至2.3.20.2、2.3.24.2或者2.3.28.1补丁地址：*https://struts.apache.org/download.cgi#struts23281*3、全面检查网站文件，服务器配置等，确保网站不存在 Webshell，没有遭到恶意篡改。4、升级 WAF、IPS 等防护设备的特征库。参考资料*http://struts.apache.org/docs/s2-032.html**http://seclab.dbappsecurity.com.cn/?p=924*
