# 勒索软件变种来袭，你的数据安全防护该升级了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514040&idx=1&sn=0013e0ee7c6fb3f231981320058ceabf&chksm=ce463ca8f931b5be292a739cd275df5f05eb5228db58a59f483a7c4a39612bd81da1dc29da20&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514040&idx=1&sn=0013e0ee7c6fb3f231981320058ceabf&chksm=ce463ca8f931b5be292a739cd275df5f05eb5228db58a59f483a7c4a39612bd81da1dc29da20&scene=27#wechat_redirect)

千里目安全实验室在最近的安全研究中捕获一个名为 TeslaCrypt 的勒索软件恶意样本。经过研究分析发现，TeslaCrypt 勒索软件是最早期的一款臭名昭著的勒索软件 Cryptolocker 变种。

  

变异体 TeslaCrypt 能够巧妙地躲过一些杀毒软件的侦查，并且声称能够对文档进行非对称的 RSA-2048 加密，在恶意软件中占有重要的地位。千里目安全实验室对 TeslaCrypt 勒索软件进行深入研究发现，该软件并非像声称的那样坚不可摧，用户中招后依然可以进行数据恢复。

![](../Images/297720d2b00a3f228c51317ed9c21f54.png)  

  

千里百科

  

勒索软件是黑客用来劫持用户资产或资源并以此为条件向用户勒索钱财的一种恶意软件。其主要通过电子邮件和非法网站传播，当用户点击恶意链接或者打开附件时，将下载执行加密程序对数据进行加密，需按照要求支付一定数目的“赎金”才能恢复数据。  

  

从 2015 年开始，勒索软件在全球疯狂传播，各种种类的勒索软件及变种层出不穷。比较典型的勒索软件有，利用 Flash player 漏洞针对游戏平台玩家的 TeslaCrypt 勒索软件（本文将重点分析该软件），善于伪装成 PDF 文件的 CryptoWall 勒索软件，不交赎金就公布个人信息的 Chimera 勒索软件，托管收取费用的 TOX 勒索软件，攻击移动平台的 Android.Trojan.Koler 勒索软件，今年2月最新出现的可伪装成 word 文档的新型勒索软件，3月份首款针对苹果 MAC 系统的勒索软件 KeRanger 诞生。

  

**勒索软件入侵方式**就入侵方式而言， PC 端的勒索软件一般通过邮件附件和钓鱼网站入侵用户电脑，用户中招后，电脑中的文档会全部被加密，并弹框要求支付赎金才能解锁文件，否则资料将会丢失（如文章第一幅图所示）。针对移动端的勒索软件经常隐藏在色情网站中，或者伪装成成人应用软件等，并会以机主已经“违法”为借口劫持其移动设备。例如源于加拿大的勒索软件 Koler，受害者以为自己安装的是播放成人视频的视频播放软件，实际勒索软件已经悄悄潜入系统。并在屏幕首页弹出“警告：你的手机已因涉及非法色情活动被锁定!”要求支付比特币进行解锁，如下图：![](../Images/9fc039caae1f66c91815a6221cf2d712.png)  

  

如果受害者不支付赎金，勒索软件不仅会将受害者手机锁屏以阻止他们进一步操作，还威胁受害者要将他们浏览成人网站的消息通知给手机中的所有联系人。

  

这种勒索手段不仅仅是体现在安全方面，同时还抓住了受害者的羞耻心理。但受害者碰到这种事情时会感到很尴尬，因为他们访问的是一个色情网站，所以不想告诉任何人。有一些特定类别的用户更容易受到这些网络罪犯的勒索，例如企业高管，他们担心上黄网被他人知晓会影响个人形象，所以最后都会决定支付赎金。

  

目前，针对 PC 端的勒索软件， AES 对称加密方法已经可以进行破解并恢复系统数据，而非对称的 RSA-2048 加密方法还没有成熟的解决方案。针对移动端的勒索软件，大部分软件不会真的发送隐私信息给所有联系人，如果手机中没有重要资料可进行刷机处理。

  

TeslaCrypt行为分析

TeslaCrypt 勒索软件一般通过邮件附件和钓鱼网站进行传播，其攻击流程如下图所示：

![](../Images/fefaa660a680cb26efac4fc1ad40512b.png)  

(1)用户点击恶意链接或打开恶意附件时，将下载恶意程序到目标主机；

(2)恶意程序加载执行，释放核心代码；

(3)为防止用户恢复数据，对用户存储设备上的备份数据进行删除；

(4)为防止用户更改系统配置以及结束恶意进程，将杀死 procexp 等进程；

(5)生成加密 key，对特定拓展名的文件进行加密，加密完成后修改文件拓展名；

(6)收集受害主机信息，与远程 C&C 服务器通信；

所有操作完成后，弹出勒索程序对话框，要求用户按照指示支付一定金额的比特币，否则将无法恢复文件。

  

**以下给出对TeslaCrypt勒索软件的详细分析：**

1、将自身拷贝到 Application Data 目录下，并以 7 位随机的小写字母组成的字符串命名，通过在注册表

>  HKLM\\SOFTWARE\\Microsoft\\Windows\\Currentversion\\Run 

下新增 AVSvc 健，保证自身开机自启动。

2、通过 CreateMutex 创建名为 “safsdfasdfwrtqr15” 的互斥量，保证同一时间内存中只有一个实体运行。

3、判断用户 Application Data 目录下是否存在 key.dat 文件，若不存在，则检查 

> HKCU\\SOFTWARE\\Microsoft\\Windows\\Currentversion\\SET 

下是否存在 data，当两者都不存在时，本地生成比特币地址以及公钥，与系统 hash 一起以加密形式写入 key.dat，并用同样的值设置注册表 SET 下 data 值。

完成上述操作后，创建四个子线程分别负责**网络通信、自保护、文件加密、删除备份**文件功能，以下分析各功能实现：

  

**网络通信**

向 http://ipinfo.io/ip 发送请求获取感染主机公网ip地址：

![](../Images/8984a246748ff7370cd1172bb18a7e61.png)  
生成一个 64 位的 key，并将比特币地址、系统版本、日期、已加密文件数目、加密文件大小、公网 ip 等信息填充到相关字段：

![](../Images/714392b50b1ccfc2e65a0134804a6b16.png)  
对上述信息经过base64编码后向服务器发送GET请求：

![](../Images/93cbe0a3055b80c6d4a6cd8630c55ddc.png)  
目前获取到的服务器域名有：

> dpckd2ftmf7lelsa.jjeyd2u37an30.com
> 
> dpckd2ftmf7lelsa.s24f53mnd7w31.com

当服务器成功接收后将返回200响应，实体中包含 "---!!!FINE!!!---" 字样。

  

**自保护**

Teslacrypt 每隔 200 毫秒将通过 EnumProcesses 枚举系统进程，GetProcessImageFileName 获取每个进程执行体名称，当存在 taskmgr、procexp、regedit、msconfig、cmd.exe 这 5 种进程时，通过 TerminateProcess 将其杀掉，从而防止用户对系统进行修改以及结束加密程序等，实现对自身的保护。

  

**文件加密**

通过 GetLogicalDriveStrings 获取受害主机存储设备信息，然后通过 GetDriveType 判断存储设备类型，对三种类型设备进行加密，包括硬盘、网络存储、移动介质等。

加密函数中，通过 FindFirstFile, FindNextFile 对存储设备上文件进行遍历，对特定拓展名的文件使用 AES 算法加密。下表给出了部分文件拓展名.

![](../Images/363be91f19717b80daa70c96e4ec4061.png)  
向符合以上拓展名的文件中写入加密数据

加密完成后对文件进行重命名，命名方式为原文件名后加.ezz拓展名（如，a.doc加密后为a.doc.ezz），并创建 HELP\_TO\_SAVE\_FILE.txt ，指示用户按照要求支付比特币恢复文件.

![](../Images/4e79b3fb2fa6bef39783cb71d41b6502.png)  

在所有文件加密完成后，在 Application Data 下创建 log.html 文件，记录已经加密的文件列表。在用户 Documents 目录下生成 RECOVERY\_FILE.TXT 文件，保存生成的比特币地址以及密钥。

与其他类型勒索软件不同，teslacrypt 不需要从远程 C&C 服务器上下载加密密钥来对受害主机进行数据加密，因此阻止网络通信并不能阻止加密行为。

  

**删除备份**

为防止用户恢复加密文件，teslacrypt 勒索软件通过调用 vssadmin.exe 删除所有数据备份。

![](../Images/8c7d338683bdfadb225c8b3746213025.png)  

  

防御建议1、谨慎打开来历不明的可疑邮件，不轻易点击可疑链接以及打开相关附件；2、禁用 office 宏功能；3、定期备份重要数据，通过不同的媒介存储；4、安装可信的反病毒软件，及时更新特征库；5、及时更新系统补丁及应用程序，防止勒索软件利用漏洞攻击；

6、TeslaCrypt 虽申称使用 RSA-2048 加密，但经过分析，实际使用 AES 对称加密，因此，理论上在保留公钥的情况下可解密加密文件。思科曾发布了解密工具，在 Application Data 目录下 key.dat 文件保留的情况下可解密已加密文件，用户可从以下地址下载该工具，尝试恢复数据：
