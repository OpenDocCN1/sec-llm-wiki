# 【漏洞通告】Windows DWM组件本地提权漏洞 CVE-2021-33739

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514761&idx=3&sn=785b8df527dd3235dc645ffae1b584da&chksm=ce463199f931b88f468e0fc9a9e616bd79eee7a54cafded3b12448b638c205e1f64b73cc685a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514761&idx=3&sn=785b8df527dd3235dc645ffae1b584da&chksm=ce463199f931b88f468e0fc9a9e616bd79eee7a54cafded3b12448b638c205e1f64b73cc685a&scene=27#wechat_redirect)

**漏洞名称 **:Windows DWM组件本地权限提升漏洞

**组件名称** :dwm.exe/dwmcore.dll

**影响范围** : 

Windows 10 Version 1909, 2004, 20H2，21H1

Windows Server Version 2004, 20H2

**漏洞类型** : 本地提权

**利用条件** :

1、用户认证：需攻击者登录系统并拥有执行权限或需诱导用户执行恶意文件

2、触发方式：本地

**综合评价** :

<综合评定利用难度>：一般，需要用户认证或诱导用户执行恶意文件

<综合评定威胁等级>：高危，能造成本地权限提升

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

dwm.exe 是 windows 下的桌面窗口管理器，提供窗口合成等功能，提供了一些UI 显示效果（例如3D特效、窗口透明），作用是使桌面窗口的图形效果更佳美观、提高使用体验等。

  

**2 漏洞描述**

2021年6月9日，深信服安全团队监测到一则Windows DWM组件存在本地权限提升漏洞的信息，漏洞编号：CVE-2021-33739，漏洞威胁等级：高危。

  

该漏洞是由于内存释放后使用，攻击者可利用该漏洞构造恶意数据执行本地权限提升攻击，最终获取服务器最高权限。

  

    

**影响范围**

    

  

目前受影响的Windows版本：

Windows 10 Version 1909, 2004, 20H2, 21H1

Windows Server, Version 20H2/2004

(Server Core Installation)

  

    

**解决方案**

    

  

**1 修复建议**

在cmd中执行systeminfo | findstr “KB5003635 KB5003637”，在命令行输出中查看是否存在“KB5003635”或者“KB5003637”。  

![](../Images/2e02d690030ff8fb9bf3f84f725721a6.png)

  

**2 官方修复建议**

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。链接如下：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-33739

  

**打补丁方法:**

进入上面的链接页面，下载当前系统版本对应的补丁包进行安装
