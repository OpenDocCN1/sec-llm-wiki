漏洞分析


1 组件介绍

Apache Dubbo是一款高性能、轻量级的开源java RPC分布式服务框架。核心功能有面向接口的远程过程调用、集群容错和负载均衡、服务自动注册与发现。其特点主要在以下几个方面。使用分层的架构模式，使得各个层次之间实现最大限度的解耦。将服务抽象为服务提供者与服务消费者两个角色。


2 漏洞简介

2021年5月28日，深信服安全团队监测到一则Apache Dubbo官方发布安全补丁的通告，共修复了2个安全漏洞。


3 漏洞描述

Apache Dubbo协议绕过漏洞（CVE-2021-25641）

简介：该漏洞由于Dubbo设置的serialization id存在绕过风险，攻击者可利用该漏洞在未授权的情况下，伪造较简单serialization id，可以使攻击者进行进一步攻击利用。


Apache Dubbo 远程代码执行漏洞（CVE-2021-30181）

简介：该漏洞由于Apache Dubbo支持脚本路由功能，攻击者可利用该漏洞在获得权限的情况下，构造恶意配置，插入恶意代码，最终可获取服务器最高权限。


影响范围


Apache Dubbo 作为一款高性能、轻量级的开源 Java 服务框架，当前可能受漏洞影响的资产广泛分布于世界各地，国内主要集中在广东、江苏、河北等省份地区。
