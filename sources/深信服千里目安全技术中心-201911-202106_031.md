# 【漏洞通告】ExifTool代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514746&idx=1&sn=cab710e7a3cd1cdcaee3d961e3effa83&chksm=ce46316af931b87c773b5f6807d68865d260836174b5950e2d81f869406a331c13cfe0ae5d10&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514746&idx=1&sn=cab710e7a3cd1cdcaee3d961e3effa83&chksm=ce46316af931b87c773b5f6807d68865d260836174b5950e2d81f869406a331c13cfe0ae5d10&scene=27#wechat_redirect)

**漏洞名称** : ExifTool代码执行漏洞

**组件名称** : ExifTool

**影响范围** : Exiftool>=7.44 && Exiftool<12.24

**漏洞类型** : 远程代码执行

**利用条件** :

1、前置条件：可远程访问存在漏洞版本的ExifTool库的应用服务器或本地访问存在漏洞版本的exiftool程序

2、触发方式：远程或者本地

**综合评价** :

<综合评定利用难度>：容易。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

   

**漏洞分析**

    

  

**1 ****组件****介绍**

ExifTool是一个独立于平台的Perl库，也有一个命令行应用程序，用于读取，写入和编辑各种文件中的元信息。ExifTool支持许多不同的元数据格式，包括EXIF、GPS、IPTC、XMP、JFIF、GeoTIFF、ICC Profile、Photoshop IRB、FlashPix、AFCP and ID3、Lyrics3等。

  

**2 漏洞描述**

2021年5月15日，深信服安全团队监测到一则ExifTool组件存在ExifTool代码执行漏洞的信息，漏洞编号：CVE-2021-22204，漏洞威胁等级：高危。

  

该漏洞是由于ExifTool版本7.44及更高版本中存在对DjVu文件格式的数据处理不当。攻击者可利用该漏洞在含有漏洞版本的ExifTool库的应用服务器或者应用程序下，构造恶意DjVu文件，服务器或者应用程序远程或本地解析此文件，导致任意代码执行，最终获取服务器最高权限。

  

**3 漏洞复现**

**影响范围**

    

  

ExifTool是一个独立于平台的Perl库，也有一个命令行应用程序，用于读取，写入和编辑各种文件中的元信息。可以运行在几乎所有计算机平台上，可能受漏洞影响的资产广泛分布于世界各地。

  

目前受影响的ExifTool版本：

Exiftool>=7.44 && Exiftool<12.24

  

   

**解决方案**

    

  

**1 如何检测组件系统版本**

访问安装ExifTool库的应用服务器，查看exiftool安装目录的exiftool文件的version字段确定版本。

![](../Images/c7283b04038c6d2e9e91eb042db31636.png)

  

**2 官方修复建议**

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。链接如下：

https://github.com/exiftool/exiftool/commit/cf0f4e7dcd024ca99615bfd1102a841a25dde031#diff-fa0d652d10dbcd246e6b1df16c1e992931d3bb717a7e36157596b76bdadb3800

【**深信服安全感知平台**】结合云端实时热点高危/紧急漏洞信息，可快速检出业务场景下的该漏洞，并可联动【深信服下一代防火墙等产品】实现对攻击者IP的封堵。
