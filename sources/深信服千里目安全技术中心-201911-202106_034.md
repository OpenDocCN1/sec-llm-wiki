# 【漏洞通告】zzzcms远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514744&idx=2&sn=dedbe51429e3b267f6fc182f5f6c6a8f&chksm=ce463168f931b87e71e3489b4fcbed9cedf31d4da08ab842ca0cb8cfedd67a10ec12e41f9e4f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514744&idx=2&sn=dedbe51429e3b267f6fc182f5f6c6a8f&chksm=ce463168f931b87e71e3489b4fcbed9cedf31d4da08ab842ca0cb8cfedd67a10ec12e41f9e4f&scene=27#wechat_redirect)

**漏洞名称** : zzzcms远程代码执行漏洞

**组件名称** : zzzcms

**影响范围** : zzzcms <= 2.0.3

**漏洞类型** : 远程代码执行

**利用条件** :

1、用户认证：不需要用户认证

2、触发方式：远程

**综合评价** :

<综合评定利用难度>：容易，无需授权即可远程代码执行。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

   

**漏洞分析**

    

  

**1 ****组件****介绍**

   zzzcms互联网商务建站系统以下简称zzzcms，自2016年5月立项开始制作，至6月完成V1.0版本，到2016年7月经历了10多个版本的更新。作者力争打造一款最简单、最易用、最舒服的建站系统。

  

**2 漏洞描述**

   2021年5月13日，深信服安全团队监测到一则zzzcms组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2021-32605，漏洞威胁等级：高危。

    该漏洞是由于parserIfLabel模块存在模板注入，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行任意代码，可以获取服务器相关权限。

  

**3 漏洞复现**

    搭建zzzcms组件2.0.3版本环境，复现该漏洞，效果如下：

![](../Images/bcaf9e5b02cd38344ea9c25a433d54c5.png)

  

    

**影响范围**

    

  

    zzzcms作为一款简单、易用的建站系统，主要分布在国内省份山东、云南、上海等地区。

    目前受影响的zzzcms版本：

    zzzcms <= 2.0.3

  

    

**解决方案**

    

  

**1 如何检测组件系统版本**
