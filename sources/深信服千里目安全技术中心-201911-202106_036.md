# 【漏洞通告】Microsoft SharePoint CVE-2021-31181远程命令执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514743&idx=5&sn=3656e8649c5ce9e28031cf35f41b9a15&chksm=ce463167f931b871eb9395714413ea44f01ffd5da9200b06fd3f815a581ba57156fcf8f1a126&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514743&idx=5&sn=3656e8649c5ce9e28031cf35f41b9a15&chksm=ce463167f931b871eb9395714413ea44f01ffd5da9200b06fd3f815a581ba57156fcf8f1a126&scene=27#wechat_redirect)

**漏洞名称** : Microsoft SharePoint CVE-2021-31181远程命令执行漏洞

**组件名称** : Microsoft Sharepoint

**影响范围** : 

Microsoft SharePoint Foundation 2013

Microsoft SharePoint Enterprise Server 2016

Microsoft SharePoint Server 2019

**漏洞类型** : 远程代码执行

**利用条件** :

1、用户认证：需要用户认证

2、触发方式：远程

**综合评价** :

<综合评定利用难度>：复杂，需要用户授权

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

   Microsoft SharePoint Foundation和SharePoint Server都是美国微软（Microsoft）公司的业务协作平台。该平台用于对业务信息进行整合，并能够共享工作、与他人协同工作等。

  

**2 漏洞描述**

    2021年5月12日，深信服安全团队监测到微软官方发布了一则漏洞安全通告，通告披露了Sharepoint组件存在远程命令执行漏洞，漏洞编号：CVE-2021-31181。威胁等级：高危。

     该漏洞CVE-2021-31181是由于服务器未能正确处理用户传入的XML数据，解析时会导致生成恶意控件，攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行远程代码执行攻击，最终可获取服务器权限。

**影响范围**

    

  

    受漏洞影响的资产广泛分布于世界各地，国内主要集中在广东、北京、上海等省市。
