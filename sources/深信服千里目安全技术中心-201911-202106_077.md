# 针对性伪装攻击，终端信息安全的间谍--海莲花 APT

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514719&idx=1&sn=268190c0fe104775d1bf40c6e27fe20c&chksm=ce46314ff931b859e4fb7133fcc3a7f6c6b1b89de253252cccf1387bac8ec157e9214fc4f780&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514719&idx=1&sn=268190c0fe104775d1bf40c6e27fe20c&chksm=ce46314ff931b859e4fb7133fcc3a7f6c6b1b89de253252cccf1387bac8ec157e9214fc4f780&scene=27#wechat_redirect)

背景概述近期，深信服终端安全团队捕获并分析了一个APT样本，经过分析人员确认来自近年来频繁活跃的“**海莲花**”组织。  
![](../Images/a11bec4caa52bb193da0e7901cacafeb.png)\*2012年4月，首次发现某境外黑客组织对中国政府、科研院所、海事机构、海域建设、航运企业等相关重要领域展开了有组织、有计划、有针对性的长时间不间断攻击。该组织主要通过鱼叉攻击和水坑攻等方法，配合多种社会工程学手段进行渗透，利用木马程序入侵并控制特定目标人群的终端系统，窃取相关的机密资料。根据该组织的攻击特点，将其命名为“海莲花”（OceanLotus）。![](../Images/a11bec4caa52bb193da0e7901cacafeb.png)

  

“海莲花”组织自首次发现以来，已被发现先后使用了4种不同形态的木马程序。初期的木马程序并不复杂，比较容易被发现和查杀。但近年来捕获的“海莲花”攻击样本均增加了一系列复杂的攻击技术，防护查杀的难度也呈正比增加。

此次深信服终端安全团队捕获的样本就具备了以下特征：

*   白加黑投递，利用正常软件加载恶意攻击载荷
    
*   精确攻击，只有特定主机才能解密执行远控木马
    
*   多重加密，在生成最终载荷前，执行了四次解密操作

样本分析APT样本包含lenovodrvtray.exe和DgBase.dll两个文件

![](../Images/63b43acbf92ba8e04a13e7e7ac3e7d7f.png)

  
其中lenovodrvtray.exe是带有正规数字签名的联想驱动自动安装软件

![](../Images/affad852e9254cb6bc7a56f1df3df6ce.png)

  

lenovodrvtray启动时会加载恶意文件DgBase.dll

![](../Images/7adfa36cd2161b997fb553394f07e1b4.png)

  
DgBase.dll载入后会从资源段中解密释放一段代码跳转执行

![](../Images/f8a7be9d27a46debd890b1ce46989e69.png)

  

该段代码同样是经过加密的，在执行前会不断异或解密汇编代码

![](../Images/a90ab4d4fb0c28589763a1d17b7c031a.png)

  

经过数次自解密后跳转到该段代码真实入口点

![](../Images/ea0ee052d739237d4577bc1eacfbbb28.png)

  

利用主机名生成哈希值，根据该HashData生成密钥

![](../Images/752c43caeeb4c5a697477714dc8a8cd8.png)

  

将数据拷贝到新的地址并使用密钥解密

![](../Images/5b38596d0b3ed69d160ae2d36f4103fd.png)

  

创建线程执行解密出来的代码

![](../Images/9e26bf9d9c4d8eb04ed27b018c48acd2.png)

  

执行StartServiceDispatchW

![](../Images/accc96cc0c101146038a851a62a197ac.png)

  

执行RegisterServiceCrtlHandle将恶意程序注册为服务

![](../Images/83b3dc5ff2391c4f5412b906028f9504.png)

  

该线程会从自身地址偏移0xB78B处开始搜索提取PE文件

![](../Images/1446e2993b47850ec342e98c8c28ac0c.png)

  

申请新的内存空间用于拷贝新的PE文件

![](../Images/66336bcc3e9668c82dbf9dd8591933e4.png)

  

该PE会执行两次，第一次生成域名、IP等信息，第二次作为远控木马执行

![](../Images/5c4f5be9e16b6e2b70303c1cc51c02ce.png)

  

跳转到PE处执行，该远控木马包含通信和控制模块

![](../Images/2fc7c36ab0de217a04811bec61e7b8be.png)

### **日常防范措施**：

1.  及时给系统和应用打补丁，修复常见高危漏洞；
    
2.  不要点击来源不明的邮件附件，不从不明网站下载软件；
    
3.  避免使用弱密码，定时进行密码修改以及加固；
    
4.  定期查看终端日志，检查终端是否存在异常行为。
