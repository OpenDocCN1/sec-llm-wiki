# 【漏洞通告】GitLab远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514710&idx=2&sn=b157fc43ade387516312ae0b0e807713&chksm=ce463146f931b850fac6656232ce873d1c899eee07b21f72081f73ddaf92777def9e77ab5fe7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514710&idx=2&sn=b157fc43ade387516312ae0b0e807713&chksm=ce463146f931b850fac6656232ce873d1c899eee07b21f72081f73ddaf92777def9e77ab5fe7&scene=27#wechat_redirect)

**漏洞名称** : GitLab远程代码执行漏洞

**组件名称** : GitLab

**威胁等级** : **严重**  

**影响范围** : GitLab >= 13.2  

GitLab < 13.9.4 or 13.8.6 or 13.7.9

**漏洞类型** : 远程代码执行

**利用条件** : 1、用户认证：不需要用户认证

2、触发方式：远程

**造成后果** : 允许未授权经过身份验证攻击者执行任意代码。

  

   

**漏洞分析**

    

  

**1 ****组件****介绍**

GitLab 是一个用于仓库管理系统的开源项目，使用Git作为代码管理工具，并在此基础上搭建起来的web服务。GitLab是由GitLabInc.开发，使用MIT许可证的基于网络的Git仓库管理工具，且具有wiki和issue跟踪功能。

  

**2 漏洞描述**

2021年3月16日，深信服安全团队监测到GitLab官方发布了一则漏洞安全通告，通告披露了GitLab组件存在远程代码执行漏洞，漏洞编号：暂无，官方已提交申请CVE请求。该漏洞通过不安全用户控制的降价渲染选项远程执行代码，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终可获取服务器最高权限。

  

    

**影响范围**

    

  

Gitlab可以运行在多个linux发行版上，由于其便捷性和安全性被广泛使用，成为最流行的版本控制软件之一。全球有近四十万服务器采用 GitLab，可能受漏洞影响的资产广泛分布于世界各地，中国大陆省份中，浙江、广东、山东、北京、上海等省市分布较多，该漏洞比较严重，建议用户及时升级到最新版本。

  

目前受影响的GitLab版本：

GitLab >= 13.2  

GitLab < 13.9.4 or 13.8.6 or 13.7.9
