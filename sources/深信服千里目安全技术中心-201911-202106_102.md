# 【漏洞通告】QNAP Nas Helpdesk未授权远程代码执行漏洞（CVE-2020-2506/ CVE-2020-2507）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514705&idx=3&sn=517f29796dfbc56a9920514cf5eba6c2&chksm=ce463141f931b857620f1d9f50a1d4fd954e1dcd9b745187f7123ba8bc742b4145f05bef0d47&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514705&idx=3&sn=517f29796dfbc56a9920514cf5eba6c2&chksm=ce463141f931b857620f1d9f50a1d4fd954e1dcd9b745187f7123ba8bc742b4145f05bef0d47&scene=27#wechat_redirect)

**漏洞名称** : QNAP Nas Helpdesk未授权远程代码执行漏洞CVE-2020-2506 /CVE-2020-2507

**组件名称** : QNAP Helpdesk

**威胁等级** : **高****危**  

**影响范围** : QNAP Helpdesk < 3.0.3

**漏洞类型** : 远程代码执行

**利用条件** : 1、用户认证：不需要用户认证

2、触发方式：远程

**造成后果** : 攻击者可以在未授权的情况下构造恶意请求实现远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Helpdesk是QNAP公司的一个远程技术支持平台应用。借助Helpdesk，可以轻松获取有关使用QNAP NAS的帮助或其他信息，甚至在发送支持请求时自动附加系统日志。在获得允许的情况下，Helpdesk还允许QNAP支持工程师远程访问NAS，以尝试解决技术问题。

  

**2 漏洞描述**

2021年3月6日，深信服安全团队监测到QNAP Helpdesk官方发布了一则漏洞安全通告，通告披露了Helpdesk组件存在远程代码执行漏洞，漏洞编号：CVE-2020-2506、CVE-2020-2507，漏洞危害：高危。其中CVE-2020-2506允许攻击者绕过访问控制，CVE-2020-2507可能导致远程攻击者执行任意命令。

  

    

**影响范围**

    

  

目前受影响的QNAP Helpdesk版本：

QNAP Helpdesk < 3.0.3

  

    

**解决方案**

    

  

**1 ****官方修复建议**

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://www.qnap.com.cn/zh-tw/security-advisory/qsa-20-08
