# 【漏洞通告】VMware View Planner远程代码执行漏洞（CVE-2021-21978）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514700&idx=2&sn=abb5ef910da97c5df1ad794632a7b31c&chksm=ce46315cf931b84ac6f7a7e125c861fd443c6c49661b33aa35b2b67171fe290c5b6b034467ed&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514700&idx=2&sn=abb5ef910da97c5df1ad794632a7b31c&chksm=ce46315cf931b84ac6f7a7e125c861fd443c6c49661b33aa35b2b67171fe290c5b6b034467ed&scene=27#wechat_redirect)

**漏洞名称** : VMware View Planner远程代码执行漏洞CVE-2021-21978

**组件名称** : VMware View Planner

**威胁等级** : **高****危**  

**影响范围** : VMware View Planner:4.6

**漏洞类型** : 远程代码执行

**利用条件** : 1、用户认证：不需要用户认证

2、触发方式：远程

**造成后果** : 由于不正确的输入验证和缺少授权，导致logupload web应用程序中可以上传任意文件。能够访问View Planner Harness的攻击者可以上传并执行恶意文件，最终在logupload容器内远程执行代码。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

VMware View Planner是用于比较虚拟桌面部署平台的第一种全面的标准方法。View Planner使用专利技术，为在虚拟桌面平台上评估的所有桌面生成了客户端和服务器端性能的实际度量。View Planner使用一组丰富的常用应用程序作为桌面工作负载。

  

View Planner提供了一种一致的方法，该方法可捕获部署平台的总体可扩展性以及给定桌面内每个单独的应用程序操作的性能。工作负载已达到定义的性能阈值的虚拟桌面数量决定了总体基准评分。

  

**2 漏洞描述**

2021年3月2日，深信服安全团队监测到VMware官方发布了一则漏洞安全通告，通告披露了VMware View Planner组件存在远程代码执行漏洞，漏洞编号：CVE-2021-21978。该漏洞由于不正确的输入验证和缺少授权，导致logupload web应用程序中可以上传任意文件。能够访问View Planner Harness的攻击者可以上传并执行恶意文件，最终在logupload容器内远程执行代码。

  

    

**影响范围**

    

  

目前受影响的VMware View Planner版本：4.6
