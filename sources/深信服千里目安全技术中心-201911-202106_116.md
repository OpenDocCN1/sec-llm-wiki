# 【漏洞通告】Apache Tomcat Session 反序列化代码执行漏洞 （CVE-2021-25329）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514699&idx=1&sn=66b83cd075a3aee22bfac67cb410e79b&chksm=ce46315bf931b84dc8012224578894b8de02b07ad3d72eb42f27a99d078dee4a7b5a4687cd0a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514699&idx=1&sn=66b83cd075a3aee22bfac67cb410e79b&chksm=ce46315bf931b84dc8012224578894b8de02b07ad3d72eb42f27a99d078dee4a7b5a4687cd0a&scene=27#wechat_redirect)

**漏洞名称** : Apache Tomcat Session 反序列化代码执行漏洞（CVE-2021-25329）

**组件名称** : Apache Tomcat

**威胁等级** :**中危**

**影响范围** : Apache Tomcat 10.x < 10.0.2

Apache Tomcat 9.x < 9.0.43

Apache Tomcat 8.x < 8.5.63

Apache Tomcat 7.x < 7.0.108

**漏洞类型** : 远程代码执行

**利用条件** : 1、用户认证：不需要用户认证

2、前置条件：

 （1）攻击者能够控制服务器上文件的内容和名称

 （2）服务器PersistenceManager配置中使用了FileStore

 （3）服务器PersistenceManager配置中设置了sessionAttributeValueClassNameFilter为NULL，或者使用了其他较为宽松的过滤器，允许攻击者提供反序列化数据对象

 （4）攻击者知道使用的FileStore存储位置到可控文件的相对文件路径  
3、触发方式：远程

**造成后果** : 攻击者可能可以构造恶意请求，绕过CVE-2020-9484补丁，造成反序列化代码执行漏洞。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Tomcat是Apache 软件基金会（Apache Software Foundation）的Jakarta 项目中的一个核心项目，由Apache、Sun 和其他一些公司及个人共同开发而成。由于有了Sun 的参与和支持，最新的Servlet 和JSP 规范总是能在Tomcat 中得到体现，Tomcat 5支持最新的Servlet 2.4 和JSP 2.0 规范。Tomcat 服务器是一个免费的开放源代码的Web 应用服务器，属于轻量级应用服务器，在中小型系统和并发访问用户不是很多的场合下被普遍使用，是开发和调试JSP 程序的首选。

  

**2 漏洞描述**

2021年3月2日，深信服安全团队监测到Apache Tomcat官方发布了一则漏洞安全通告，通告披露了Tomcat组件存在反序列化代码执行漏洞，漏洞编号：CVE-2021-25329。该漏洞由于官方在CVE-2020-9484漏洞修复上存在不足，攻击者可能可以构造恶意请求，绕过CVE-2020-9484补丁，造成反序列化代码执行漏洞。有关于CVE-2020-9484的分析可以查看相关链接。

  

**3 ****漏洞复现**

搭建Tomcat 9.0.35漏洞环境，配置session持久化功能，启动tomcat，上传恶意war包（包含commons-collections-3.1.jar依赖包），再上传包含恶意序列化数据的session文件到session目录下。

向服务器发送精心构造的恶意HTTP请求，造成远程代码执行：

**影响范围**

    

  

Apache Tomcat 可以运行在几乎所有计算机平台上，由于其跨平台和安全性被广泛使用，成为最流行的 Web 服务器端软件之一。全球有数百万 Web服务器采用 Apache Tomcat，可能受漏洞影响的资产广泛分布于世界各地，中国大陆省份中，浙江、广东、山东、北京、上海等省市接近 20%，此漏洞虽说是中危，但涉及用户量过多，导致漏洞影响力还是很大。

  

目前受影响的Apache Tomcat版本：

Apache Tomcat 10.x < 10.0.2

Apache Tomcat 9.x < 9.0.43

Apache Tomcat 8.x < 8.5.63

Apache Tomcat 7.x < 7.0.108

**1 ****如何检测组件系统版本**

Windows系统：在tomcat的bin目录下，输入catalina version命令即可显示版本信息；

Linux系统：在bin目录下执行如下命令：sh version.sh 可显示版本信息。
