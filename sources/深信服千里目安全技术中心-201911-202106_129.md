# 微软补丁日安全通告|2月份

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514693&idx=2&sn=5f4e03a641902d417ad566f3499851de&chksm=ce463155f931b843af566bb24a6ca5edf0eb522b354de3050f445898bf6c9dabb2244a0ffbca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514693&idx=2&sn=5f4e03a641902d417ad566f3499851de&chksm=ce463155f931b843af566bb24a6ca5edf0eb522b354de3050f445898bf6c9dabb2244a0ffbca&scene=27#wechat_redirect)

    

**漏洞概要**

    

  

2021年2月10日（北京时间），微软发布了安全更新，共发布了56个CVE的补丁程序，同比上月减少了了27个，涵盖了Microsoft的众多组件和软件。

  

在漏洞安全等级方面，有11个漏洞被微软官方标记为“Critical”，43个漏洞被标记为“Important”；在漏洞类型方面，有21个远程代码执行漏洞，11个权限提升漏洞，7个拒绝服务漏洞以及10个信息泄露漏洞。

  

    

**漏洞数据分析**

截至2021年2月，微软在各月修复的漏洞数量如下所示：

![](../Images/69f04571dc07ccba958dca088ac06a93.png)

● 总体上来看，微软本月修复的漏洞数量降低到了56个，相较于上月减少了27个漏洞。

● 千里目安全实验室在综合考虑往年微软公布漏洞数量的数据统计和今年的特殊情况，初步估计微软在今年3月份公布的漏洞数将有小幅度提升。严重类型漏洞数也会维持在10个左右。

● **从漏洞数量来看，今年出现了显著降低。**微软在2021年2月份爆发的漏洞相较于去年有一定的下降，一方面是由于在二月份有一些安全研究员因为节日暂停工作，另一方面是因为一些常用组件漏洞更难进行挖掘，但是最近的具有严重危害的漏洞数量增多。

●** 从漏洞的危险等级来看，“Important”等级漏洞数量显著降低。**单个的重点高可利用漏洞数量相对平衡，但单个具有普通影响力的漏洞明显增多，这加大了严重漏洞对普通用户的危害。这种趋势，对于APT组织或成熟的攻击组织来说是一个利好消息，大幅度增加的单个严重漏洞提供了诸多的攻击路径和攻击手段组合的选择。

● **从漏洞类型来看，权限提升漏洞(EoP)大幅降低。**远程代码执行漏洞(RCE)数量相较于前两年有一定增加，其他漏洞类型的数量与往年相比差别不大。权限提升漏洞(EoP)虽然数量降低，但仍需要引起高度重视，尤其是在配合社工手段的前提下，甚至可以直接接管整个局域网并进行进一步扩展攻击。远程代码执行漏洞(RCE)一定数量的增加，这对于攻击者而言是个好消息。远程代码执行漏洞有利于攻击者更容易的获取受害者机器的执行权限，对于普通用户以及企业来说，远程代码执行类型的漏洞是危害比较大的。

  

    

**2月重要漏洞分析**

    

  

**1 ****漏洞分析**

Windows TCP/IP：CVE-2021-24074、CVE-2021-24086、CVE-2021-24094，Windows TCP/IP是Windows自己实现的 TCP/IP协议族，主要实现在Tcpip.sys驱动文件中。Windows IPv4/IPv6存在缓冲区溢出漏洞，当执行流执行进入漏洞的逻辑中时由于缺少必要的验证，导致内存空间被覆盖，使程序的内存空间被修改。攻击者可以利用漏洞进行远程拒绝服务甚至远程代码执行。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。

  

Microsoft SharePoint：CVE-2021-24072，Microsoft SharePoint可以为个人、信息和公司创建门户页面。Microsoft SharePoint存在一个XML外部实体注入漏洞，该漏洞是由于SharePoint服务器未对用户输入的内容进行校验，并解析未校验的数据。攻击者可以通过创建恶意的XML文件，并通过该XML来触发漏洞实现XML外部实体注入泄露敏感信息，从而造成远程代码执行，进而接管服务器。1月份微软安全更新也曝出了一个Microsoft SharePoint的远程代码执行漏洞，我们建议用户及时更新微软安全补丁。

  

Windows Installer：CVE-2021-1727，Windows Installer是专门用来管理和配置软件服务的工具。Windows Installer不仅仅是一个安装程序，它还是一个可扩展的软件管理系统。该漏洞为Windows Installer的远程代码执行漏洞。Windows Installer在取消安装时会调用以.rbs为后缀的回滚脚本，攻击者可以通过构造恶意程序诱使Windows Installer使用攻击者自己的回滚脚本（\* .rbs文件），而不是安装期间由msiexec.exe创建的回滚脚本。如果本地非管理员攻击者设法用“还原”某些系统注册表值的回滚脚本替换了该回退脚本，从而它将指向攻击者的可执行文件，则Windows Installer将会以SYSTEM权限执行该可执行文件，从而造成权限提升。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。

**该漏洞为之前Windows Installer的0day漏洞，详情见下方链接：**

[【漏洞更新】Windows Installer 权限提升漏洞](http://mp.weixin.qq.com/s?__biz=MzI4NjE2NjgxMQ==&mid=2650249426&idx=2&sn=00c64054a773f7783f9d3cda20d3f6ca&chksm=f3e222a6c495abb0251b23a89aac5c4ecea12b173d202f9c1c77851966a78d4c81e35bec5464&scene=21#wechat_redirect)  

  

Windows Kernel：CVE-2021-1698、CVE-2021-1732，win32k.sys是Windows的多用户管理的sys文件。该漏洞为win32k的本地提权漏洞，win32k某些函数在处理内存对象时存在缓冲区溢出漏洞，当执行流执行进入漏洞的逻辑中时由于缺少必要的验证，导致内存空间被覆盖，使程序的内存空间被修改。攻击者可以通过构造恶意的利用程序，利用该漏洞进行任意地址读写，通过写入指定payload造成本地提权。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。

  

DNS Server：CVE-2021-24078, DNS Server是Windows服务器的一项有关DNS的服务，DNS Server存在一个任意释放内存的漏洞，当执行流执行进入漏洞的逻辑中时由于缺少必要的验证，导致内存空间被任意释放。攻击者可以通过构造恶意的利用程序，利用该漏洞进行远程代码执行。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。
