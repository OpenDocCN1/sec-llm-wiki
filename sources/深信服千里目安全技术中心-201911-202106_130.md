# 【漏洞通告】2021年2月深信服安全蓝军灯火实验室向微软提交并协助修复了4个漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514693&idx=3&sn=631585fd0e81a74eaf98a4b14e74bd48&chksm=ce463155f931b843f555342ff06bea56eaa0729de630f057c41fe3bacb731474a8ebb94d894a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514693&idx=3&sn=631585fd0e81a74eaf98a4b14e74bd48&chksm=ce463155f931b843f555342ff06bea56eaa0729de630f057c41fe3bacb731474a8ebb94d894a&scene=27#wechat_redirect)

近日，深信服安全蓝军灯火实验室向微软提交并协助修复了4个漏洞，这些漏洞都可能导致攻击者实现远程恶意代码执行。

  

北京时间2021年2月10日，微软已经针对上述漏洞发布了安全更新，并公开致谢深信服安全研究员。

![](../Images/98e96a8efb45bb119bb17c2b2ab52fb1.png)

  

    

**漏洞概述**

    

  

● CVE-2021-1722  

Windows的传真服务中存在一个整数溢出的漏洞，攻击者可以构造特殊的数据包发送至远程传真服务器，并在远程服务器中触发该漏洞，利用该漏洞攻击者可以实现远程代码执行。

  

● CVE-2021-24072

Microsoft Sharepoint组件的某个端点在解析XML数据时无法正确处理数据包，存在一个XXE漏洞，通过认证的攻击者可以发送精心构造的请求来读取服务器上的敏感文件，进而造成远程命令执行，获得服务器权限。

  

● CVE-2021-24077   
Windows的传真服务中存在一个整数溢出的漏洞，攻击者可以构造特殊的数据包发送至远程传真服务器，并在远程服务器中触发该漏洞，利用该漏洞攻击者可以实现远程代码执行。

  

● CVE-2021-24088   
Windows的打印机服务中存在一个整数溢出的漏洞，攻击者可以构造特殊的数据包发送至远程打印机服务器，并在远程服务器中触发该漏洞，利用该漏洞攻击者可以实现远程代码执行。
