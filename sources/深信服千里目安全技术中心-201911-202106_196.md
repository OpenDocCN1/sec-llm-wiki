# 【漏洞通告】Apache Airflow 错误的会话验证漏洞 （CVE-2020-17526）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514649&idx=2&sn=f9aa172f6fe3fcd3d90390146ae7b56e&chksm=ce463109f931b81f6be0821956a578b2f9fe3661424ab287fef7487f7bdfcd2d0daf6bc87eb7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514649&idx=2&sn=f9aa172f6fe3fcd3d90390146ae7b56e&chksm=ce463109f931b81f6be0821956a578b2f9fe3661424ab287fef7487f7bdfcd2d0daf6bc87eb7&scene=27#wechat_redirect)

**漏洞名称** : Apache Airflow 错误的会话验证漏洞 CVE-2020-17526

**威胁等级** : **中****危**  

**影响范围** : Apache Airflow Web < 1.10.14

**漏洞类型** : 未授权访问

**利用难度** : 未知

  

    

**漏洞分析**

    

  

**1 ****Apache Airflow 介绍**

Airflow 是 Airbnb 开源的一个用 Python 编写的调度工具。于 2014 年启动，2015 年春季开源，2016 年加入 Apache 软件基金会的孵化计划。Airflow 通过 DAG 也即是有向非循环图来定义整个工作流，因而具有非常强大的表达能力。

  

**2 漏洞描述**

Apache 官方在2020年12月21日发布的邮件中披露Apache Airflow 存在一个由于错误处理会话验证导致的未授权访问漏洞。如果用户使用了默认的秘钥配置，攻击者就可以在其他的一个配置了默认秘钥的站点进行登录，接着以登录后的session信息直接未授权访问受害者站点。 

  

    

**影响范围**

    

  

目前受影响的Apache Airflow版本：

Apache Airflow Web < 1.10.14

  

    

**解决方案**

    

  

**1 临时修复建议**

修改配置中的默认秘钥为自己的秘钥。

  

**2 官方解决方案**

目前厂商已发布升级补丁修复漏洞，请受影响用户及时更新官方补丁。官方链接如下：

https://github.com/apache/airflow
