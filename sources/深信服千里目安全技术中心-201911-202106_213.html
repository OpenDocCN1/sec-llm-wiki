【漏洞通告】深信服安全蓝军灯火实验室向微软提交并协助修复了3个漏洞

近日，深信服安全蓝军灯火实验室向微软提交并协助修复了3个漏洞（CVE-2020-17097，CVE-2020-17092，CVE-2020-17120），其中CVE-2020-17097和CVE-2020-17120可能导致攻击者在受害者主机上以高权限用户身份执行任意代码，CVE-2020-17120可能导致远程恶意代码执行。


北京时间2020年12月9日，微软已经针上述漏洞发布了安全更新，并公开致谢深信服安全研究员。


漏洞概述


1 CVE-2020-17097

Windows Digital Media Receiver是Windows的一个系统组件。攻击者需要一个低权限账户，并利用该漏洞在其他账户会话中创建高权限文件夹并在该文件夹中放入恶意DLL，并通过DLL劫持的方式执行任意代码，最终导致本地权限提升。


2 CVE-2020-17092

Windows Network Connections Service是Windows的一个系统组件。Windows网络服务中存在一个权限提升的漏洞，攻击者可以在高权限进程中利用该漏洞执行恶意代码。


3 CVE-2020-17120

Microsoft Sharepoint上存在一个信息泄露漏洞， 通过身份认证的攻击者可以通过构造一个特殊的页面来泄露用户的敏感信息， 在某些特定的环境中, 攻击者甚至可以执行任意代码。
