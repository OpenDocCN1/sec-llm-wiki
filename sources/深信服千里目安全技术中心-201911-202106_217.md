# 【漏洞通告】Windows NTFS远程代码执行漏洞（CVE-2020-17096）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514639&idx=4&sn=7a5f453c688ec95baf8072019044068f&chksm=ce46311ff931b80995f4c71e88bf04cc394addaeea63382d342c804cbba48bf42d6b523a6229&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514639&idx=4&sn=7a5f453c688ec95baf8072019044068f&chksm=ce46311ff931b80995f4c71e88bf04cc394addaeea63382d342c804cbba48bf42d6b523a6229&scene=27#wechat_redirect)

北京时间2020年12月9日，微软MSRC发布了Windows NTFS远程代码执行漏洞CVE-2020-17096的公告，深信服安全研究团队依据漏洞重要性和影响力进行评估，作出漏洞通告。

**漏洞名称** : Windows NTFS远程代码执行漏洞

**威胁等级** : 高危  

**影响范围** : Windows 10

Windows 10 Version 1607, 1803，1809, 1903, 1909, 2004，20H2

Windows 8.1

Windows Server 2012, 2012 R2, 2016, 2019

Windows Server version 1903, 1909, 2004，20h2

**漏洞类型** : 远程代码执行漏洞

**利用难度** : 一般

  

    

**漏洞分析**

    

  

**1 ****相关组件****介绍**

NTFS（New Technology File System）是Windows NT内核的系列操作系统支持的、一个特别为网络和磁盘配额、文件加密等管理安全特性设计的磁盘格式，提供长文件名、数据保护和恢复，能通过目录和文件许可实现安全性，并支持跨越分区。

  

**2 漏洞描述**

CVE-2020-17096：该漏洞是NTFS的内存错误漏洞，当NTFS对目录句柄执行无效的请求时，则NTFS在处理完成时将会发生内存错误，从而造成内存泄露。攻击者可以在本地利用该漏洞执行任意命令，也可以在远程通过SMB协议传输精心构造的数据交由NTFS处理，从而执行任意代码。

  

    

**影响范围**

    

  

受影响版本：

Windows 10

Windows 10 Version 1607, 1803，1809, 1903, 1909, 2004，20H2

Windows 8.1

Windows Server 2012, 2012 R2, 2016, 2019

Windows Server version 1903, 1909, 2004，20h2
