2020年8月11日，Citrix官方发布的漏洞公告中发布了5个漏洞，分别为CVE-2020-8208、CVE-2020-8209、CVE-2020-8210、CVE-2020-8211、CVE-2020-8212，其中仅CVE-2020-8209公开漏洞细节。

  

   

**漏洞分析**

    

  

**1  Citrix组件介绍**

Citrix美国思杰公司，是一家致力于云计算虚拟化、虚拟桌面和远程接入技术领域的高科技企业。Citrix ADC 是业界领先的应用交付控制器、L4-7 负载均衡器和 GSLB,在各种设备和地点确保百分之百的正常运行时间和无与伦比的安全性。

  

**2 漏洞描述**

2020年8月11日，Citrix官方发布的漏洞公告中发布了5个漏洞，分别为CVE-2020-8208、CVE-2020-8209、CVE-2020-8210、CVE-2020-8211、CVE-2020-8212，其中仅CVE-2020-8209公开漏洞细节。

  

CVE-2020-8208, CVE-2020-8210, CVE-2020-8211, CVE-2020-8212细节尚未公布，其中CVE-2020-8208官方认定为严重漏洞，其余三个漏洞分别被评定为中危和低危漏洞。

  

**CVE-2020-8209：**

Citrix Endpoint Management存在一个未授权任意文件读取漏洞，该漏洞是由于授权验证不足。攻击者通过构造特定的HTTP请求可以读取远程服务器上的文件内容，包括一些账户的配置文件等。

  

    

**影响范围**

    

  

目前受影响的设备：

XenMobile Server < 10.12 RP3

XenMobile Server < 10.11 RP6

XenMobile Server < 10.10 RP6

XenMobile Server < 10.9 RP5

  

    

**修复建议**

    

  

官方已经发布了最新的补丁，用户可以依据不同的版本去下载对应的补丁：  

XenMobile Server 10.12 RP3: https://support.citrix.com/article/CTX277473

XenMobile Server 10.11 RP6: https://support.citrix.com/article/CTX277698

XenMobile Server 10.10 RP6: https://support.citrix.com/article/CTX279101

XenMobile Server 10.9 RP5: https://support.citrix.com/article/CTX279098
