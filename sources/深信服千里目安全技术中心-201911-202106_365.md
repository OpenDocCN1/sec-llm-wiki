# 【流行威胁跟踪】AgentTesla新变种活跃海外，窃密数据或遭多处泄露

样本简介

深信服安全云脑于7月16日拦截到一款AgentTesla的变种，为7月14日用 .net 编译，近期主要活跃在欧美等海外地区。该恶意程序伪装成pdf文件，运行后经过多层解密最终内存中加载窃密木马，盗取用户的系统信息/邮箱账号/浏览器密码/FTP账号等数据，发送到passjones@yandex.com邮箱。深信服安全团队进一步分析发现，该邮箱至少在5月初就开始接收窃密数据，并代理了多个邮箱，全球范围内盗取了至少上百用户的信息。每隔2小时的整点时间就会被来自意大利米兰的固定IP登录该邮箱获取盗取的数据，疑似作者设定的自动接收数据的程序。此外，深信服安全团队还发现有很多来自不同地区的IP通过网页或客户端方式登录该邮箱。由以上信息推测，攻击者至少在5月份就开始了窃密行动，并使用多个邮箱和持续批量生产样本投放攻击，盗取的数据估计已被多人掌握。

  

AgentTesla 作为一款商业窃密软件，在2014年首次出现后就不法分子广泛使用，主要通过钓鱼邮件方式进行传播，近几年持续活跃，其可配置化的方式可让作者轻易地产生变种。本次拦截的变种，执行阶段共4层，每一层均使用.net 编译。和近期6月披露的活跃家族对比，其4层执行阶段的技术手法一致，不同的是6月的样本最后一层的窃密程序为C++编译，通过C&C服务连接方式传输数据；而本次变种最后一层为 .net 编译，通过邮箱STMP协议传输数据。

字符串加密算法：

要想解密一个字符串，需要3部分，秘钥+初始向量+密文，其中密文转化成了base64编码，将这3部分拼接成字节流，每4个组成一个数字，将这些数字保存在数组中，所以一个字符串对应一个数组，所有的字符串都放在一个二维数组中，解密的时候只需要提供一个能找到这个数值的索引便可以成功解密

![](../Images/5bb7c281984b6475e5c73fd4d39aeb3e.png)
