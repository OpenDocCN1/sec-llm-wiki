Nexus Repository Manager 3 远程代码执行漏洞通告（CVE-2020-15871）

2020年7月29日，Sonatype公司发布安全公告，公布了Nexus Repository Manager 3 远程代码执行漏洞（CVE-2020-15871）的相关信息。深信服安全研究团队依据漏洞重要性和影响力进行评估，作出漏洞通告。





漏洞名称：Nexus Repository Manager 3 远程代码执行漏洞（CVE-2020-15871）

威胁等级：高危

影响范围：Nexus Repository Manager 3 OSS / Pro <= 3.25.0

漏洞类型：远程代码执行

利用难度：一般






漏洞分析


1 Nexus Repository Manager介绍

Sonatype Nexus Repository Manager（NXRM）是美国Sonatype公司的一款Maven仓库管理器，它提供了强大的仓库管理、构件搜索等功能，并且可以用来搭建Maven 仓库私服，在代理远程仓库的同时维护本地仓库，以节省带宽和时间。


2 漏洞描述

根据官网对该漏洞的描述有两种攻击场景，第一种攻击场景是攻击者可以像运行Nexus Repository Manager服务器一样运行任意代码，但是在该场景下需要攻击者具备一定的用户权限；第二种攻击场景是攻击者可以利用社工等手段诱使具有一定权限的用户运行Nexus Repository Manager服务器，从而在该过程中运行任意代码，相对而言第二种场景的利用难度较低。


影响范围


【影响版本】

Nexus Repository Manager 3 OSS / Pro <= 3.25.0


解决方案


1检测方案

在Nexus Repository Manager 3服务器Web端左上角可以查看版本号。

如显示的版本号属于受影响的版本，则证明漏洞存在。


2 修复方案

目前官方已更新修复版本，请访问以下链接下载最新版本：

https://help.sonatype.com/repomanager3/download
