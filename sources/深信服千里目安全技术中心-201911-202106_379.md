# 【流行威胁追踪】看到Sodinokibi/REvil蓝屏勒索，我就蓝瘦

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514527&idx=1&sn=c3b29a87505e2f0e2e7cae4b893f796f&chksm=ce46328ff931bb99a39a62a70b08f612b610d20b2c5b814949e5f5cb182ecaf8d42ccc73f713&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514527&idx=1&sn=c3b29a87505e2f0e2e7cae4b893f796f&chksm=ce46328ff931bb99a39a62a70b08f612b610d20b2c5b814949e5f5cb182ecaf8d42ccc73f713&scene=27#wechat_redirect)

**勒索行业背景**

从2019年开始，进入勒索病毒行业的黑产人员越来越多，导致对应的勒索家族以及勒索组织也不断的增多，每天都有很多企业中勒索病毒。并且随着勒索威胁的进一步演进，勒索病毒不仅加密数据，还扩展到了数据勒索和盗窃领域，大部分勒索组织将窃取的数据在地下论坛进行售卖、通过收集的数据完善自己的武器资料库和少部分通过公开窃取的企业数据威胁企业交赎金，通过公开窃取威胁企业的家族主要以Sodinokibi、Maze、Clop、DopplePaymer、Nefilim/Nephilim勒索家族为主导。但是最近，勒索组织又更新了新一轮的玩法，开始对窃取的企业数据在DarkNet上进行公开拍卖，下图为勒索家族Sodinokibi公开的拍卖信息。

![](../Images/a3b9632bc031c56fd89086a80885eb73.png)

 

  

**本期追踪家族**

本期追踪勒索家族为Sodinokibi/REvil（在国内也经常被称呼为蓝屏勒索-会为桌面设置一个蓝色背景的勒索信息提示图）,该勒索家族在2019年初开始进入勒索行业，并且伴随着GandCrab的停止运营，其在接收GandCrab家族的传播与运营渠道后，开始展现它的感染能力，逐渐成为2019年勒索黑产中的新星，并被戏称为“GandCrab接班人”。Sodinokibi的主要运营组织叫做**U****nkown**或者**U****NKN**，该黑产团队一直活跃在少数的俄语地下论坛中，关于其与GandCrab的关系，该组织承认其购买了GandCrab的源码进行修改

“We used to be affiliates of the (GandCrab) affiliate program. We** bought the source code **and started our own business. We developed custom features for our purposes”。

下图为该家族设置的蓝屏勒索背景。

![](../Images/6b3143d035e98f4b9f5ca5e440291909.png)

  

根据emsisoft公开的勒索病毒2020Q1分析数据来看，Sodinokibi勒索家族在Q1季度中排名第四，占据3.5%。

![](../Images/dc2eac5a947b565dae6c8613890b5704.png)

  

  

**Sodinokibi时间线**

通过对之前以及现在的安全报告进行分析，我们可以看出，在2020年，Sodinokibi组织的行为变化比较频繁。

2019年4月，Sodinokibi开始在野外出现，并且利用钓鱼邮件、垃圾邮件、漏洞、RDP攻击进行攻击。

2019年6月，接管GandCrab运营与传播渠道，感染量逐渐增大。

2020年1月，在某个俄罗斯地下论坛赞助文章征稿竞赛，相关人员可能会获得与Sodinokibi组织合作的机会。

![](../Images/2a57e64f4f9b65034963ed06090bb003.png)

  

2020年1月，首次发布被窃取企业数据，进一步威胁企业交赎金。

2020年2月，勒索提示txt文件中decryptor.top更换为decryptor.cc

2020年4月，抛弃比特币，转而使用门罗币作为支付货币，避免被安全人员进行交易追踪。

2020年4月，Travelex（外汇金融交易）由于被攻击，交**230万美元**恢复数据。

2020年5月，艾伦·格鲁布曼律师被勒索，赎金翻倍达4200万美元，并且由于这一泄露，导致，后期更多的名人被勒索。

2020年5月，勒索特朗普，称有相关特朗普黑料，介入政治，后称相关数据被第三方购买。

2020年6月，开始拍卖窃取的企业数据，进一步威胁企业交赎金。

2020年6月，Symantec安全研究员发现使用Cobalt Strike进行推送Sodinokibi勒索，并且会扫描客户网络中的信用卡以及POS相关软件。

2020年7月，从窃取的数据中，筛选出名人进行勒索，比如NBA球星**勒布朗·詹姆斯**

2020年7月，Sodinokibi袭击了巴西电力公司Light S.A，勒索**赎金1400万美元**。

**勒索运营模式**

Sodinokibi背后的主要运营组织名称叫做**U****n****known****或者U****NKN**，该组织一直活跃在几个俄语黑客论坛中，在其中发布运营以及合作的相关信息，Sodinokibi采用的是RAAS（Ransomware as a Service）的运营模式，并且他们对RAAS的会员有着一系列的要求，**不招新手**、至少**5年的黑产经验**，不接受**英语为母语的合作伙伴**，不允许合作会员在**C****IS****（前苏联相关国家）类国家**（包括乌克兰）进行攻击。关于合作收入这一块，在前三次合作会员可以拿到**60%的**赎金占比，在成功完成三次勒索交易后，可以提高到**70%。**

![](../Images/20cab27076ce8d72eeabe90a1bc7acf9.png)

  

在赎金交易这块，初始的时候Unkown组织采用的是BTC交易，由于被安全研究员对BTC地址进行跟踪以分析其资金流向，在2020年4月，该组织全面将赎金交易改为**M****onero**(门罗币，俗称XMR)交易，因为门罗币具有比比特币更好的匿名方式。 

![](../Images/2abd121ee9abe3af5f74add422267e64.png)

  

在赎金收取这块，初始的时候该组织并没有进行主动索要，其表现的和其他的常规家族一样，由被攻击者决定是否需要交赎金。可能是觉得这样收到的赎金太少和太慢，其合作会员后来在进行加密数据之前，会将企业数据进行上传，以**泄露数据**威胁企业进行交易。下图为截至2020年7月5日其Blog上被威胁泄露数据的组织统计占比。

![](../Images/f7842c35d1ad18334129bbb0e327a319.png)

  

从其被攻击公司来看，各行各业都有中招，IT公司、汽车行业、高科技企业、酒店、服装公司、食物提供商等。

![](../Images/3cb3138e143604876f594bb8ccf6c4a9.png)

  

如果企业信息被挂在上面了，他们还会通过联系企业的相关合作伙伴以进行威胁，给竞争对手发送泄露信息进行拍卖等方式进行更恶劣的威胁。

![](../Images/f5d04b8ba839940f85b7fdebc5afce62.png)

  

但是，从被威胁的企业数据分析来看，似乎未支付赎金的企业占据了大部分，但实际上更多的企业是没有被放在该博客上的，迫于生产的压力、声誉的受损以及避免更大的损失，更多的企业交了赎金。

![](../Images/851775ab64440ed15543fb5de0fc55e7.png)

  

通过分析国内某论坛上的数据以及应急响应数据的分析，国内中Sodinokib的个人以及企业是很多的，这还是已知的，未知的还有更多。

![](../Images/77f61bc305024709b74a3cd2e0b50f2c.png)

  

  

**勒索攻击向量**

从国内外安全厂商披露的Sodinokibi/REvil相关报告分析，以及实际案例分析，可以得出该勒索的整个完整的攻击路径，下表为其合作会员曾经使用的各种勒索投递攻击方式。

| 时间 || 攻击方式 |
| --- | --- |
| / || 钓鱼与垃圾邮件 |
| / || RDP(远程桌面)攻击 |
| 2019.04 || Confluence远程代码执行漏洞CVE-2019-3396 |
| 2019.04 || Weblogic远程代码执行漏洞CVE-2019-2725 |
| 2019.06 || RIG kit(恶意广告引流漏洞页面) |
| 2019.06 || Hacked MSP()推送Sodinokibi |
| 2019.06 || 水坑攻击(网站合法文件替换) |
| 2019.07 || Flash漏洞CVE-2018-4878 |
| 2019.10 || 大量伪装office文档的钓鱼邮件 |

**国内变种分析**

在2020年4月份，深信服安全团队发现一起针对国内的[定制Sodinokibi攻击事件](http://mp.weixin.qq.com/s?__biz=MzI4NjE2NjgxMQ==&mid=2650241750&idx=1&sn=24746c98a7a3eb70511b7981e1ad54a9&chksm=f3e2c0a2c49549b4b8d36ee17067bdeba4ba2f50cc2e87dca62676f0fef2a31a2409766ca7e0&scene=21#wechat_redirect)。

![](../Images/d457098b0664be639b228a2cf289ed51.png)

  

Sodinokibi样本会内置一个加密的配置表，其配置表的基本作用如下表。

| 字段 || 字段说明 |
| --- | --- |
| pk || Base64编码的加密公钥 |
| Pid || RAAS购买者标识符(2.0以下版本为一个数字,从2.1开始为Bcrypt hash) |
| Sub || 攻击活动标识符 |
| Dbg || 是否开启调试 |
| Fast || 是否开启快速加密,对大小65535bytes字节以上的文件是否加密 |
| Wipe || 是否擦除数据 |
| Wht->fld || 文件夹白名单 |
| Wht->fls || 文件白名单 |
| Wht->ext || 后缀白名单 |
| Wfld || 擦除数据文件夹 |
| Prc || Kill进程名单 |
| Dmn || C2通信域名 |
| Net || 确定是否将被攻击机器相关信息发送给C2 |
| Nbody || Base64编码的txt勒索提示信息内容 |
| Nname || txt勒索提示文件名 |
| Exp || CVE-2018-8453提权EXP |
| Img || Base64编码的桌面背景文字 |
| arn || 是否开启持久项-（开机自启动） |

  

从该事件的样本分析来看，该定制版本很明显是针对国内用户，通过解密其配置文件，因为其文件夹白名单中明确的排除了“tencent files”和“wechat files”的目录，可以看出该事件幕后的攻击者对国内网络环境有一定了解。 

![](../Images/f3c9d44be2a823662e2e1361e37d626b.png)

 

通过与2019年的国内中毒样本分析与对比，我们可以看到主要针对国内的黑客组织是Hack Group 13，还有一些hack组织是通过大量的钓鱼邮件或者僵尸网络投递针对亚洲地区进行区域性攻击，少部分无差别攻击导致攻击到国内。

![](../Images/82cb6a23dcb5d25249bf0fb4e677b892.png)

  

其中这些工具具有以下的用途

| 名称 || 作用 |
| --- | --- |
| ph.exe || Process Hacker，用于结束一些进程 |
| bro.exe || / |
| sais.exe || / |
| xm64 || 密码抓取工具 |
| xwdef.exe || 防火墙关闭工具 |
| ns.exe || 网络扫描工具 |
| Dudok.exe || 勒索病毒母体 |

 

从多次的安全事件样本分析来看，我们可以称Group13为Dudok Hack Group，因为其很喜欢将其勒索病毒命名为dudok.exe，由于Sodinokibi V2.1版本及以上会将PID字段更改为Bcrypt Hash，但还是可以确认"pid":"$2a$10$SosE00UUiauiFk820KWBX.Ll5a8ec43FclRfjUQltNiz44FfH38GO"为Dudok Hack Group组织。可以看到，从**2019年7月到2020年4月**，其sub已经增长到了1362,说明其攻击活动非常频繁。

 

  

**结束语**

进入勒索黑产的人员越来越多，且越来越猖狂，其攻击方式很大部分还是通过RDP进行爆破攻击成功的，只有少数特殊攻击会使用其他攻击技术。目前的勒索不止只加密数据，还进行数据窃取，一次勒索攻击对于企业来说，可能就是一次决定企业命运的重要事件，所以企业要做好的还是做好自身的安全基础防护，访问控制。
