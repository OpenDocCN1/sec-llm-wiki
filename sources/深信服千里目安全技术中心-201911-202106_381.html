F5 BIG-IP是一系列应用交付平台，具有负载均衡，流量管理，应用程序管理等多种功能。F5 BIG-IP的流量管理用户界面（TMUI）被发现存在远程代码执行漏洞。此漏洞允许未经验证的攻击者通过BIG-IP管理端口对TMUI进行访问并执行任意系统命令。


漏洞信息于2020年7月1号由F5发布，截至2020年7月3日除15.0.0版本外均有对应的修复补丁。2020年7月5日，互联网中出现该漏洞的利用POC。深信服安全研究团队第一时间对出现的POC进行了验证，并给出检测方案。




漏洞名称：CVE-2020-5902: F5 BIG-IP TMUI 远程代码执行漏洞

威胁等级：高危

影响范围：BIG-IP 11.x,12.x,13.x,14.x,15.x

漏洞类型：代码执行

利用难度：简单

临时缓解措施


若目前无法升级，官方提供以下临时缓解措施，在不影响系统情况下避免攻击：


2.1所有网络接口


1）.输入以下内容登录TMOS Shell

tmsh

2）.输入以下内容修改httpd属性

edit /sys httpd all-properties

3）.找到include节，添加以下内容：

include '<LocationMatch ".*\.\.;.*">Redirect 404 /</LocationMatch>'

4）.输入以下内容写入并保存对配置文件的修改

Esc:wq!

5）.输入以下内容保存配置

save /sys config

6）.输入以下内容重启httpd服务

restart sys service httpd
