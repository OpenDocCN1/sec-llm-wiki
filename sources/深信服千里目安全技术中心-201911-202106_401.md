# Punycode 钓鱼？我们看见你了！

深信服通过NTA（网络流量分析）和云脑大数据关联分析，监控到多起使用punycode域名进行钓鱼的高级攻击行为，疑似为有组织的APT团伙活动。

  

    

**1.知攻**

    

Punycode域名攻击对应ATT&CK攻击矩阵中的T1036 Masquerading 和 T1192 Spearphishing Links两个Techniques，是一种APT中常用的高级攻击手法。

  

1.1

**背景**

早期的DNS（Domain Name System）是只支持英文域名解析。域名的编码字符集是ASCII码（参考阅读2）。在IDNs（国际化域名international domain names）（参考阅读4）推出后，为了保证兼容以前的DNS，所以，对IDNs进行punycode转码，转码后的punycode就由26个英文字母+10个数字，还有‘-’组成。

  

1.2

**攻击方式**

也正是因为这种对IDNs进行转码的机制，很多不法分子会利用一些与英文字母相似的非英文字符伪造知名网站的域名，达到欺骗用户的目的，这种技术也被称为“同形异义攻击（Homograph）”。

例如：斯拉夫字母“а”（U+0430）和拉丁字母“a”（U+0041）会被浏览器处理成不同的字符，但是在地址栏当中都显示为“a”；再例如英文字母g（U+0067）和浊软颚塞音ɡ（U+0261）在地址栏里都被显示为“g”。在26个英文字母当中，可能互相相似的情况不多，但是放在IDN里面，这种类似的相似情况太多太多。

Punycode的攻击方式存在两个明显的优势，导致常被攻击者选取用来攻击：

1.  Masquarading：从肉眼上很难区分正常域名和punycode伪装的域名，进行网络钓鱼的成功率很高。
    
2.  Evasion：从安全防护的角度而言，通常会因为避免大范围误报而把含关键词的域名列为白名单，所以可以有效的绕过安全防护产品的威胁情报检测等功能。
    

  

    

**2.知防**

    

这里提供的检测方案不仅覆盖了IDN的异常检测，同样也覆盖了常规的同形异义攻击。例如，英文字母a和o在某种程度上相似，英文字母l和符号|相似。

2.1

**前置准备**

1.收集国际域名中大量相似的字符，并进行了整理。比如：

![](../Images/73f24de92179c18b21e19f68845b23f8.png)

2.收集大量知名网站域名（Alexa Top 2w）。

  

2.2

**检测算法**

检测方案流程如下：

![](../Images/4b43ddcaa72fd0a376a50e1b9db1b28f.png)

  

   

1)IDN域名解码

把域名中带有’xn--’字样认为是IDN域名，这类域名的组成除开正常的英文字母、数字和常规符号外，还参杂了希腊字母、德文字母等等。然后这类型的字母在浏览器和邮件客户端的展现和正常英文字母相差无几。下图是利用一个第三方开源库生成的混淆字符生成的恶意IDN域名：

![](../Images/bda79be19c4db0cca0943c7af7724601.png)

这类域名用正常的域名字符编码为‘xn--fcebooks-16g.com’，‘xn--facbooks-e8g.com’等等。因此，如果‘xn--’字样出现在域名当中，就先用punycode进行解码，使它变成如上图中的Evil url字样。

  

   

2)对混淆字符进行替换

其实在真实环境中，并不是所有的字符都能被替换成易混淆的字符，欺骗用户。举个简单的例子，在通用的英文字符中，i和l就容易被混淆，但是i和z明显就不一样。因此在替换混淆字符时，并不用对每一个字符进行替换，只用按照之前收集的相似字符表里的字符替换即可。

例如‘goagl3’，其中字符‘o’，‘a’，‘l’，‘3’这样的能被替换的字符均会被替换。如下图：

![](../Images/eec7beda94fc508538d95a2bbf9355bb.png)

这样就会发现这样一个被伪装的域名（例子很夸张，真实环境的域名不会像这样）的相似域名集合里就会出现一个知名的网站域名（google）。

  

   

3)计算与知名网址的相似度

此时这个待检测域名被映射成一个它所有可能的相似域名集合，这时候将top2w的知名网址域名集合与这个相似域名集合做一个交集，如果该域名集合是由IDN域名衍生而来的，则只要这个域名集合与知名网站集合有交集则认定这个域名有高度伪造嫌疑，因为常常使用IDN域名的情况通常是有伪造嫌疑的。

如果该域名集合不是由IDN域名衍生而来的，则判断与知名网站域名交集个数是否为1（这里的意义在于伪造的域名具有极强的针对性）而且判断这两个域名之间的编辑距离是否为1。

因为部分知名网站中的域名本身就十分相似，如果这个‘恶意’域名与多个知名网站域名相似，则反映出针对性不强，且更容易误报。

再者，根据统计，90%的域名伪造行为编辑距离都等于1，也就是说，大部分伪造域名只会替换其中的一个字符（毕竟字符替换多了，人就更容易察觉其中的不同）。所以这里做这两个判断。

  

    

**3.知效果**

    

通过punycode攻击的检测，经深信服安全云脑分析后，监控到疑似APT35团队攻击行为。此次APT攻击使用的域名具有较强的迷惑性。使用的域名有131个，例如：

xn--facebook-06k.com

xn--google-yri.com

activity-confirmationservice.info

yahoo-verification.org

accounts-support.services

该批域名使用的是一些正常单词的组合形式，其中包括account，service，verification等一下带有迷惑性的词语，其中也包括一些知名网站的域名，像yahoo，facebook，google等域名单词的组合。该种域名模式以和正常域名模式构造相似来逃避检测。

从这批域名的解析时间来看，大部分域名都在凌晨解析，最早的发现在晚上23：30左右，最晚的发现在05：44左右，其中大部分集中在凌晨1点至2点之间，解析时间十分异常。  

从解析IP来看，大部分域名都解析到40.112.253.185（美国 加利福尼亚州 圣何塞 IDC服务器），从这个IP反查，可以发现大量同样域名模式的APT\_35域名。

![](../Images/9d1fc110cc9ce2a5f8b50c7f9450e62c.png)

  

根据这次事件攻击者使用的域名集合，进行可视化关联分析，初步认为对方是有组织的网络犯罪团伙，并且从2014就开始活动，有较强的攻击工具开发能力，往往为企业造成较大的经济损失。

![](../Images/4252b7c30a3f576613299b0e76f3b2e1.png)

从其中部分的解析IP关联，发现40.112.253.185和204.95.99.250关联出大量的apt\_35形式的域名，这批域名均是有迷惑性单词+连字符组成的，且访问的url和下载的文件在VT上被大量检测引擎报malware和phishing。

通过开源情报源，这次的远控域名属于伊朗的charming kitten团伙，根据互联网上的介绍，该团伙是伊朗的网络间谍组织，主要进行针对人权活动人士、学术研究人员和媒体转载的网络间谍行为。这个组织注册的域名在文法结构上都具有很强的相似性。

  

    

**4.解决方案**

    1.深信服**安全感知平台**以及**安全云脑**能够对使用punycode进行钓鱼的未知威胁攻击和高级威胁攻击进行检测。2.可疑链接可以通过深信服智安全中心进行威胁判定：https://sec.sangfor.com.cn/analysis-platform3.对于可能被用来做为钓鱼域名的知名企业，建议对与自身域名相似的punycode域名进行抢注，防止被攻击者滥用于攻击活动中来。

3.Unicode：随着世界互联网的形成和发展，各国的人们开始有了互相交流的需要。但是这个时候就存在一个问题，每个国家所使用的字符编码表都是不同的。这个时候，人们希望有一个世界统一的字符编码表来存放所有国家所使用的文字和符号，这就是Unicode。Unicode又被称为 统一码、万国码、单一码，它是为了解决传统的字符编码方案的局限性而产生的，它为每种语言中的每个字符设定了统一并且为之一的二进制编码。Unicode规定所有的字符和符号最少由2个字节（16位）来表示，所以Unicode码可以表示的最少字符个数为2\*\*16=65536。4.IDN：国际化域名（英语：Internationalized Domain Name，缩写：IDN）又称特殊字符域名，是指部分或完全使用特殊的文字或字母组成的互联网域名，包括法语、阿拉伯语、中文、斯拉夫语、泰米尔语、希伯来语或拉丁字母等非英文字母，这些文字经多字节万国码编译而成。IDN的域名是使用unicode字符集。
