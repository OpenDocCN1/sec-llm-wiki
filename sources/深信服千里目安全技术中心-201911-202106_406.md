# 汉化远控木马下发挖矿程序，利用“肉鸡”资源捞金

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514499&idx=1&sn=a99cc8018df3f871a40021fed753993e&chksm=ce463293f931bb85baa1e530944c5d39f0a0b711f5c0f45e300fb6b72603f38e354cf708637c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514499&idx=1&sn=a99cc8018df3f871a40021fed753993e&chksm=ce463293f931bb85baa1e530944c5d39f0a0b711f5c0f45e300fb6b72603f38e354cf708637c&scene=27#wechat_redirect)

 近日，深信服安全团队排查定位到一款伪装为Windows系统帮助文件的远控木马，攻击者通过远控木马下发挖矿程序到被害主机，占用主机资源进行挖矿。

  

威胁关联分析

## 

通过威胁分析发现，该木马连接的域名 fuck88.f3322.net和r.nxxxn.ga是已经被开源威胁情报收录的两个恶意域名，同时用于Kryptik木马的控制端：

![](../Images/86afcbd40eb8889c14847b4f39c16f58.png)

  

查询域名fuck88.f3322.net的whois信息，可以看到注册者使用名为“peng yong”，并且该注册者同时注册了多个具有欺骗性的动态域名：

![](../Images/9ac2237b8a763e6576da673dfa7aa319.png)

![](../Images/20feab1294389c915f7c3f8695dc7e75.png)

  

通过深信服安全云脑查询恶意域名相关信息，在最近一个月内攻击次数均较为平稳：

![](../Images/3bdafc3b746110adaadb30b11cab8de5.png)

  

服务DLL文件Remote.hlp是一个伪装成Windows帮助文件的后门程序，仅从字符串分析，就能够得到许多功能信息。而此次事件捕获的域名所关联的后门程序中，均存在一条“TheCodeMadeByZPCCZQ”标识字符串：

![](../Images/616c71aebd612685208afb4c60c38c50.png)

  

可以推断，这些后门程序均来源于同一款远控生成器，并且通过对后门dll的字符串分析，有很多中文描述的控制操作，可以确认是一款汉化的远控程序：

![](../Images/f3274230989002cc687c2612c429e493.png)

  

在此次捕获的安全事件中，除了持久化驻留的后门程序，在被害主机中存在通过后门投放的挖矿程序，伪装成银行图标，占用主机资源进行挖矿：

![](../Images/a6323497418f45b11facd7255980cd59.png)

![](../Images/87f0da44f07905eac5d6fc7859dcf4f9.png)

 

命令行中配置的的恶意域名为o.vollar.ga。

  

后门母体

1\. 检查互斥体“XXNBbin1”，如不存在则创建该互斥体：

![](../Images/5ecb79d910a28dc0a1e0ca42c08c7266.png)

  

2\. 验证路径

“C:\\ProgramData\\Microsoft\\Windows\\GameExplorer”是否存在，如不存在则创建：

![](../Images/d0b24f05d0a0a51d82f2bdc01df989b8.png)

  

3\. 创建注册表值，并设置如下键值：

hKey = HKEY\_CURRENT\_USER

Subkey = "Software\\Microsoft\\Windows\\Windows Error Reporting"

ValueName = "DontshowUI"

Value = 0x01

 

hKey = HKEY\_LOCAL\_MACHINE

Subkey = "software\\microsoft\\remote\\Desktop"

ValueName = ""

Value = "C:\\Documents and Settings\\Administrator\\桌面\\"

 

4\. 释放用于注册后门服务的DLL文件，路径为"C:\\ProgramData\\Microsoft\\Windows\\GameExplorer\\Remote.hlp"，并设置文件属性为HIDDEN|SYSTEM：

![](../Images/e2f39f45baf34a01d9902611f3474cad.png)

  

5\. 注册表里添加服务注册项，不同的母体注册的服务名称会有变化：

![](../Images/5e818d283337f82429df0e928c1049b0.png)

  

该样本中服务名称为".Net CLR"，研究员排查过程中发现有过

“Ias”、“FastUserSwitchingCompatibilty”，

服务指向的DLL程序都是母体释放的Remote.hlp：

![](../Images/993bcd3743b07669e4970ca4e082cf18.png)

  

6\. 创建服务并启动：

![](../Images/c753c206c8cd43cb1a2821d6ba6e633a.png)

  

7\. 释放"C:\\Windows\\System32\\\\Delete00.bat"文件，清除母体，然后退出母体进程：

![](../Images/3eb27b973a2671f2efa2eab13952780e.png)

1\. 使用高强度的主机密码，并避免多台设备使用相同密码，不要对外网直接映射3389等端口，防止暴力破解；
