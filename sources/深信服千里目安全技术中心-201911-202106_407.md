# 微软5月份补丁日重点漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514498&idx=1&sn=0a05c963df41f30876d340fd03c50b15&chksm=ce463292f931bb8413f029d951cbd478ebf6e3a1e0ed4feaeb3a5a7af97a5f3e842a5b1e448c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514498&idx=1&sn=0a05c963df41f30876d340fd03c50b15&chksm=ce463292f931bb8413f029d951cbd478ebf6e3a1e0ed4feaeb3a5a7af97a5f3e842a5b1e448c&scene=27#wechat_redirect)

2020年5月13日(北京时间)，微软发布2020年5月份安全更新，共发布了111个漏洞的补丁程序，涵盖了Microsoft Windows、Internet Explorer（IE）、Office、SharePoint、Win32k等众多组件和软件。111个CVE中共有16个被微软官方标记为Critical。

  
此外，在本月的安全补丁中，有23个针对远程代码执行漏洞，8个针对拒绝服务漏洞，57个针对权限提升漏洞以及9个针对信息泄露漏洞。整体来看，此次补丁日发布的安全补丁基本解决了Windows中被发现的漏洞或Bug。  
深信服安全研究团队依据漏洞重要性和影响力进行筛选，对下述漏洞做重点说明。  
    

**漏洞分析**

   

  

  

  

  

**1.CVE-2020-1153**

  

Microsoft Graphics Components远程代码执行漏洞。

  

该漏洞主要是由于Windows未能成功进行OpenType字体处理出现了一个越界写问题，并最终导致了远程代码执行漏洞。成功利用该漏洞的攻击者可以在目标系统上执行任意代码。要利用此漏洞，攻击者可以诱使用户打开一个特制文件以实现漏洞触发。

  

  

**2.CVE-2020-1023/1024**

  

Microsoft SharePoint远程代码执行漏洞。

  

该漏洞主要是因为软件无法检查应用程序包的源标记。成功利用该漏洞的攻击者可以在 SharePoint应用程序池和SharePoint服务器场帐户的上下文中运行任意代码。利用此漏洞要求用户将特制的 SharePoint应用程序包上传到到受影响的 SharePoint。

  

  

**3.CVE-2020-1165/1166**

  

Windows Clipboard Service权限提升漏洞。

  

Windows在处理对剪贴板服务的调用时，由于方式不恰当导致存在一个特权提升漏洞。成功利用此漏洞的攻击者可以在本地系统的安全上下文中运行任意代码。要利用此漏洞，攻击者首先必须登录到系统。然后，攻击者可以运行一个特制应用程序，该应用程序可以利用此漏洞并控制受影响的系统。

  

  

**4.CVE-2020-1058/1060**

  

VBScript远程代码执行漏洞。

  

VBScript 引擎在处理内存中的对象时可能发生释放后重利用，并最终实现远程代码执行。成功利用该漏洞的攻击者可以获得与当前用户相同的用户权限，在用户的上下文中执行任意代码。在基于 Web 的攻击场景中，攻击者可以托管一个特制网站，然后诱使用户查看网站。攻击者还可能在承载IE呈现引擎的应用程序或Microsoft Office文档中嵌入标记为“safe for initialization”的ActiveX控件。攻击者还可以利用接受或托管用户提供的内容或广告的受攻击网站和网站。这些网站可能包含可能利用漏洞的特制内容。

  

  

**5.CVE-2020-1062**

  

Internet Explorer内存损坏漏洞。

  

Internet Explorer在处理内存中的对象时由于处理方式不当可能发生释放后重利用，并最终可以实现远程代码执行。此漏洞可能会损坏内存。成功利用该漏洞的攻击者可以获得与当前用户相同的用户权限，在用户的上下文中执行任意代码。攻击者可以托管一个特制网站，然后诱使用户查看网站。在攻击场景中，攻击者必须诱使用户采取行动，而不能进行自主触发漏洞。
