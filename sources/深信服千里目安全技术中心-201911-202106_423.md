# 微软4月份补丁日重点漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514484&idx=1&sn=119a385ddc789d1661a6d2ee98349f4a&chksm=ce463264f931bb7286cacbb16d634ba86d2ca0f7b341cbb7f915477710e959cd6291d8ac7637&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514484&idx=1&sn=119a385ddc789d1661a6d2ee98349f4a&chksm=ce463264f931bb7286cacbb16d634ba86d2ca0f7b341cbb7f915477710e959cd6291d8ac7637&scene=27#wechat_redirect)

2020年4月14日，微软发布2020年4月份安全更新，共发布了113个漏洞的补丁程序，涵盖了Microsoft Windows、Microsoft Edge、ChakraCore、Internet Explorer（IE）、Office、Azure DevOps、Web Apps和Microsoft恶意软件保护引擎等众多组件和软件。113个CVE中共有17个被微软官方标记为严重。  
此外，在本月的补丁中，微软公布了39个针对特权提升漏洞的补丁，16个针对信息泄漏漏洞的补丁，1个拒绝服务漏洞的补丁。整体来看，此次补丁日发布的安全补丁基本解决了Windows中被发现的漏洞或Bug。  
深信服安全研究团队依据漏洞重要性和影响力进行筛选，对下述漏洞做重点说明。

  

    

**漏洞分析**

    

  

  

**1.CVE-2020-0938**

OpenType字体解析远程代码执行漏洞。该漏洞主要是因为Windows Adobe类型管理器库不适当地处理特制的多主字体-Adobe Type 1 PostScript格式时会造成任意代码执行。攻击者可以通过多种方式利用该漏洞，例如说服用户打开特制文档或在Windows预览窗格中进行查看。对于Windows 10以外的所有系统，成功利用此漏洞的攻击者可以远程执行代码，权限为当前已登录用户权限。对于运行Windows 10的系统，成功利用此漏洞的攻击者可以以有限的特权和功能在AppContainer沙箱上下文中执行代码。然后，攻击者可能会安装程序。查看，更改或删除数据；或创建具有完全用户权限的新帐户。目前，该漏洞已发现主动利用。

  

  

**2.CVE-2020-0968**

脚本引擎内存损坏漏洞。脚本引擎处理Internet Explorer中内存中的对象的方式中存在一个远程执行代码漏洞，攻击者可以在当前用户的上下文中执行任意代码的方式来破坏内存。成功利用此漏洞的攻击者可以获得与当前用户相同的用户权限。然后，攻击者可能会安装程序。查看，更改或删除数据；或创建具有完全用户权限的新帐户。在基于Web的攻击情形中，攻击者可能拥有一个旨在通过Internet Explorer利用此漏洞的特制网站，然后诱使用户查看该网站。攻击者还可能在承载IE呈现引擎的应用程序或Microsoft Office文档中嵌入标记为“初始化安全”的ActiveX控件。攻击者还可能利用受感染的网站以及接受或托管用户提供的内容或广告的网站。这些网站可能包含可以利用此漏洞的特制内容。目前，该漏洞已发现主动利用。

  

  

**3.CVE-2020-0967**

VBScript远程代码执行漏洞。该漏洞可能以一种攻击者可以在当前用户的上下文中执行任意代码的方式来破坏内存。成功利用此漏洞的攻击者可以获得与当前用户相同的用户权限。然后，攻击者可能会安装程序。查看，更改或删除数据；或创建具有完全用户权限的新帐户。在基于Web的攻击情形中，攻击者可能拥有一个旨在通过Internet Explorer利用此漏洞的特制网站，然后诱使用户查看该网站。攻击者还可能在承载IE呈现引擎的应用程序或Microsoft Office文档中嵌入标记为“初始化安全”的ActiveX控件。攻击者还可能利用受感染的网站以及接受或托管用户提供的内容或广告的网站。这些网站可能包含可以利用此漏洞的特制内容。

  

  

**4.CVE-2020-0965**

Microsoft Windows Codecs库远程代码执行漏洞。攻击者可以诱使目标系统使用程序处理经过特殊设计的图像文件，成功利用此漏洞的攻击者可以执行任意代码。
