# Fastjson AnterosDBCPConfig远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514458&idx=2&sn=0e651fd16abb7dcc5e3fbf39014f660f&chksm=ce46324af931bb5cf256df1280ecbd490d1a10e681036ca41c8d9bf3dd2267a1a798bfa6198a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514458&idx=2&sn=0e651fd16abb7dcc5e3fbf39014f660f&chksm=ce46324af931bb5cf256df1280ecbd490d1a10e681036ca41c8d9bf3dd2267a1a798bfa6198a&scene=27#wechat_redirect)

Fastjson是一个Java语言编写的高性能功能完善的JSON库。Fastjson AnterosDBCPConfig存在远程代码执行漏洞，远程攻击者可以通过构造的攻击代码触发远程代码执行漏洞，最终可以获取到服务器的控制权限。  

  
  
  
  

**漏洞名称**：Fastjson AnterosDBCPConfig远程代码执行漏洞

**威胁等级**：高危

**影响范围**：Fastjson<=1.2.66

**漏洞类型**：代码执行

**利用难度**：简单

  
  
  
  

  

    

**漏洞分析**

    

  

**1 Fastjson组件介绍**

Fastjson是一个Java语言编写的高性能功能完善的JSON库。它采用一种“假定有序快速匹配”的算法，把JSON Parse的性能提升到极致，是目前Java语言中最快的JSON库。Fastjson接口简单易用，已经被广泛使用在缓存序列化、协议交互、Web输出、Android客户端等多种应用场景。  

  

**2 漏洞描述**

Fastjson远程代码执行漏洞是由于使用br.com.anteros.dbcp.AnterosDBCPConfig类，绕过了Fastjson的黑名单而导致。当服务端加载了存在受漏洞影响的Anteros-DBCP依赖，并且开启了Fastjson的autotype时，远程攻击者可以通过构造的攻击代码触发远程代码执行漏洞，最终可以获取到服务器的控制权限。

  

**3 漏洞分析**

以Fastjson1.2.66 + Anteros-DBCP-1.0.1+metrics-healthchecks-3.0.2作为漏洞环境分析。传入构造好的payload，经过JSON类中的parse方法的解析入口，如下图：

![](../Images/eee9632c58d1986f24d51669a399118a.png)

在JSONObject类中进行格式解析和特殊字符检测。继续跟进处理的过程，当获取到@type传入的类名后，会通过checkAutoType方法检查@type传入的类是否在黑名单中，如果黑名单中存在此类名，直接抛出异常退出程序。如下图：

![](../Images/53bd4e0264a03c76cc82589abf247daa.png)

继续跟进，payload中的json格式数据会在JSONScanner类中进行字段名匹配，如果字段名匹配成功，则将对应的参数值传入，为对应属性赋值，如下图：

![](../Images/4e1aba7e40a1774769a9c9949ca72bc0.png)

进入@type指定的br.com.anteros.dbcp.AnterosDBCPConfig类中，通过setHealthCheckRegistry()方法为healthCheckRegistry变量赋值。

![](../Images/bef5cd801906582e86e3c43c7f85ce07.png)

在healthCheckRegistry参数中传入恶意地址，经过lookup方法进行访问，服务器就可以远程加载恶意文件。

![](../Images/0120cf2f1f4da0f3ad5f1d47b68eb8a4.png)

![](../Images/c1e2ef6b2d4cca04e54d8cf153790bda.png)

经过测试metricRegistry参数同样可以完成攻击。

![](../Images/3c14b00d1665dfc3c4a16538b9e699e9.png)

至此漏洞利用过程基本完成。

  

**4 漏洞复现**

搭建Fastjson1.2.66 + Anteros-DBCP-1.0.1 + metrics-healthchecks-3.0.2漏洞环境，传入精心构造的json数据，让目标服务器加载远程主机上的恶意文件，从而在目标主机上执行任意代码。效果如图：
