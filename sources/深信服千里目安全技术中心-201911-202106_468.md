# Apache Dubbo反序列化漏洞 CVE-2019-17564

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514452&idx=1&sn=29ea224a4b7773a93160c61d1ab4b039&chksm=ce463244f931bb52e59ab73f31093c143263b765f849665d96a55dc4dab1fbee58d01e7f31e7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514452&idx=1&sn=29ea224a4b7773a93160c61d1ab4b039&chksm=ce463244f931bb52e59ab73f31093c143263b765f849665d96a55dc4dab1fbee58d01e7f31e7&scene=27#wechat_redirect)

Apache Dubbo是一款高性能、轻量级的开源java Rpc分布式服务框架。**Apache Dubbo HTTP协议处理模块中存在一个反序列化漏洞，攻击者利用此漏洞可以在受影响的Apache Dubbo服务器上执行任意指令。**

  
  
  
  

**漏洞名称**：Apache Dubbo反序列化漏洞 CVE-2019-17564

**威胁等级**：**高危**

**影响范围**： 

Apache Dubbo 2.7.0 - 2.7.4.1

Apache Dubbo 2.6.0 - 2.6.7

Apache Dubbo 2.5.x 

**漏洞类型**：远程代码执行

**利用难度**：容易

  
  
  
  

  

    

**漏洞分析**

    

  

**1 Apache Dubbo组件介绍**

Apache Dubbo是一款高性能、轻量级的开源java Rpc分布式服务框架。

  

核心功能有面向接口的远程过程调用、集群容错和负载均衡、服务自动注册与发现。其特点主要在以下几个方面。使用分层的架构模式，使得各个层次之间实现最大限度的解耦。将服务抽象为服务提供者与服务消费者两个角色。  

  

**2 漏洞描述**

Apache Dubbo HTTP协议处理模块中存在一个反序列化漏洞，此漏洞的利用方式和其他java中间件反序列化漏洞相似。Apache Dubbo对消息体处理不当导致不安全反序列化，当项目包中存在可用的gadgets时，攻击者可以通过HTTP协议发送恶意的反序列化数据，当Apache Dubbo对恶意数据进行序列化操作时，则会触发漏洞。攻击者利用此漏洞可以在受影响的Apache Dubbo服务器上执行任意指令。

  

**3漏洞复现**

搭建Apache Dubbo2.7.3 + zookeeper3.4.9环境，启动zookeeper，并将Apache Dubbo的maven项目导入idea中启动，看到如下图的信息，则环境搭建成功。
