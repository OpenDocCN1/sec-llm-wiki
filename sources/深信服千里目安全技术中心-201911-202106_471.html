漏洞概要


2020年2月11日，微软发布2020年2月份安全更新，共发布了99个漏洞的补丁程序，涵盖了Microsoft Windows、Edge、ChakraCore、Internet Explorer（IE）、SQL Server、Exchange Server、Office、Azure DevOps Server、Team Foundation服务器和Microsoft恶意软件保护引擎等众多组件和软件。99个漏洞中共有12个远程代码执行漏洞被微软官方标记为紧急漏洞，且CVE-2020-0674已被发现用于在野攻击，CVE-2020-0683已发现公开PoC。深信服安全研究团队依据漏洞重要性和影响力进行筛选，对下述漏洞做重点说明。


漏洞分析



1.CVE-2020-0674


IE浏览器远程代码执行漏洞。漏洞触发点位于IE的脚本引擎Jscript.dll中，其处理内存中对象的方式中存在错误。攻击者可以使用IE加载特定的JS代码来触发漏洞，成功利用此漏洞的攻击者可以在当前用户的上下文中执行任意代码。如果当前用户使用管理员权限登陆，攻击者可以完全控制受影响的系统，任意安装程序、查看/更改或删除数据、创建具有完全用户权限的新账户。即使受害者不使用IE，如果在Office文档中嵌入了对象，但仍然可能受到此漏洞的影响。目前已发现在野利用。



2.CVE-2020-0729


LNK远程代码执行漏洞。Microsoft Windows在处理.LNK文件时存在远程代码执行漏洞。攻击者可以诱导用户打开恶意.LNK文件（可位于可移动驱动器或远程共享）来利用此漏洞，成功利用此漏洞的远程攻击者可在受害者的系统上执行任意代码。



3.CVE-2020-0688


Exchange远程代码执行漏洞。Microsoft Exchange在处理内存中的对象时，存在远程代码执行漏洞。攻击者可以通过发送特制电子邮件来在受影响的Exchange服务器上以系统级权限执行代码，过程中不需要其他用户交互。



4.CVE-2020-0689


安全引导的安全功能绕过漏洞。此漏洞可能允许攻击者绕过安全引导功能在受影响系统上加载不信任软件。成功利用此漏洞的攻击者可以绕过安全引导，并加载不受信任的软件。



5.CVE-2020-0660


Windows RDP拒绝服务漏洞。Windows RDP协议在处理连接请求时，存在拒绝服务漏洞。攻击者可通过向受此漏洞影响的RDS发送特制请求包来利用此漏洞，成功利用此漏洞可导致目标系统上的RDS停止响应。



6.CVE-2020-0681、CVE-2020-0734


Windows RDP客户端远程代码执行漏洞。Windows RDP客户端在处理连接请求时存在远程代码执行漏洞，攻击者可通过控制合法服务器并托管恶意代码，然后等待用户连接来利用此漏洞，成功利用此漏洞的远程攻击者可在受害者的系统上执行任意代码。



7.CVE-2020-0655


Windows RDS远程代码执行漏洞。Windows Remote Desktop Services在处理剪贴板重定向时存在远程代码执行漏洞。攻击者需要控制RDS主机并等待用户连接，成功利用此漏洞的远程攻击者可在受害者的系统上执行任意代码。



8.CVE-2020-0662


Windows内存处理远程代码执行漏洞。Windows处理内存中对象的方式中存在一个远程代码执行漏洞。为了利用此漏洞，攻击者首先需要拥有一个域用户账户，然后创建特制请求使Windows执行具有提升权限的任意代码。成功利用此漏洞的攻击者可以在目标系统上以提升的权限执行任意代码。



9.CVE-2020-0683


Windows Installer特权提升漏洞。当 MSI 包处理符号链接时，Windows Installer 中存在特权提升漏洞。为了利用此漏洞，攻击者需要登录系统，并运行经过特殊设计的应用程序，该程序可以利用此漏洞进行文件添加或删除。



10.CVE-2020-0692


Microsoft Exchange权限提升漏洞。Microsoft Exchange在处理Token时存在权限提升漏洞。攻击者通过修改安全访问令牌中的参数并发送给受影响服务器来利用此漏洞。成功利用此漏洞的远程攻击者可获取Exchange服务器上的其他用户权限，访问其他用户邮箱。
