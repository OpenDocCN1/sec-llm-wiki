**漏洞名称**：Windows远程桌面网关（RD Gateway）远程代码执行漏洞(CVE-2020-0609/0610)

**威胁等级**：高危

**影响范围：Windows Server 2012 - Windows Server 2019**

**漏洞类型**：远程代码执行

利用难度：容易  

  
  
  
  
  

  

      

**RD Gateway介绍**

      

    Remote Desktop Gateway服务，通常也被称为RD Gateway（RD网关），是一项角色服务，使经过授权的远程用户能够从任何可以远程桌面连接客户端（ RDC）的Internet连接设备连接到内部公司网络或专用网络上的资源。它可以将RDC流量加密到HTTPS隧道中，以保证连接的安全性。  
    RD网关的三个主要用途是：  
1\.    在最终用户的设备与RD网关服务器之间建立加密的SSL隧道：为了通过任何RD网关服务器进行连接，RD网关服务器必须安装了最终用户的设备可以识别的证书。在概念的测试和证明中，可以使用自签名证书，但是在任何生产环境中都只能使用来自证书颁发机构的公共信任的证书。  
2\.    在环境中对用户进行身份验证：RD网关使用收件箱IIS服务执行身份验证，甚至可以利用RADIUS协议来利用多因素身份验证解决方案，例如Azure MFA。除了创建的默认策略外，您还可以创建其他RD资源授权策略（RD RAP）和RD连接授权策略（RD CAP），以更具体地定义哪些用户应有权访问安全环境中的哪些资源。  
3\.    在最终用户的设备和指定资源之间来回传递流量：只要建立连接，RD网关就会继续执行此任务。您可以在RD网关服务器上指定不同的超时属性，以在用户离开设备时维护环境的安全性。  

  

      

**漏洞描述**

      

    CVE-2020-0609/0610，微软远程桌面网关远程代码执行漏洞。该漏洞主要由于在生产环境中，RD Gateway在配置时会开启支持UDP+SSL。当客户端向服务器发送一个或多个CONNECT\_PKT\_FRAGMENT包以建立连接时，服务器未对该结构中的数据进行严格验证。攻击者可以构造特殊数据以造成服务端的越界读写，最终实现远程代码执行，且研究表明该漏洞不需要用户交互，可以在不需要任何用户干预的情况下远程执行任意代码。  
    目前互联网中已出现可造成目标主机蓝屏的poc，并公开在了GitHub中。经千里目实验室研究员分析，该poc可成功造成受影响主机蓝屏。1月27日已有国外安全研究员在推特上公开了漏洞exploit的演示视频。
