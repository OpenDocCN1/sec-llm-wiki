GitLab多个安全漏洞公告

2019年12月10日，GitLab发布12月份安全更新，共修复了3个漏洞， CVE-2019-19628、CVE-2019-19629、CVE-2019-19604。深信服安全研究团队依据漏洞重要性和影响力进行筛选，作出以下漏洞说明。


千里百科 - GitLab 


GitLab 是一个用于仓库管理系统的开源项目，使用Git作为代码管理工具，并在此基础上搭建起来的web服务。GitLab是由GitLabInc.开发，使用MIT许可证的基于网络的Git仓库管理工具，且具有wiki和issue跟踪功能。


漏洞描述



1.CVE-2019-19628


GitLab存在目录穿越和远程代码执行漏洞，该漏洞产生的原因是由于Maven包注册表的没有做好参数处理，攻击者可利用该漏洞提升权限和远程执行代码。



2.CVE-2019-19629


GitLab存在私有代码泄露漏洞，当用户将公共项目转移到私有群组时，Elasticsearch提供的Group Search API可能导致私有代码泄露。



3.CVE-2019-19604


GitLab Git依赖项存在任意命令执行漏洞，该漏洞产生的原因是由于用户使用git submodule update功能时，会执行攻击者在.gitmodules文件中设置的命令。


影响范围


受影响版本

CVE-2019-19628:  GitLab EE 11.3及更高版本

CVE-2019-19629:  GitLab EE 10.5及更高版本

CVE-2019-19604:  Git 2.20.0-2.20.1

                                Git 2.21.0

                                Git 2.22.0-2.22.1

                                Git 2.23.0

                                Git 2.24.0

                                所有版本的GitLab Omnibus


不受影响版本

GitLab EE 12.3.9

GitLab EE 12.4.6

GitLab EE 12.5.4

Git 2.20.2

Git 2.21.1

Git 2.22.2

Git 2.23.1

Git 2.24.1


检测方式


使用如下命令检测当前GitLab版本：

cat /opt/gitlab/embedded/service/gitlab-rails/VERSION

使用如下命令检测当前Git版本:

git --version

若检测当前版本在受影响范围内，则存在上述安全风险。


修复建议


官方已在最新版本的GitLab修复了上述三个漏洞，用户可从官网下载并升级软件到最新版本。


GitLab升级至：12.5.4、12.4.6、12.3.9

Git升级至：2.20.2、2.21.1、2.22.2、2.23.1、2.24.1
