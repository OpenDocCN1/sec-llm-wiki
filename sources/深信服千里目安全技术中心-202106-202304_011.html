BlackLotus：绕过UEFI安全启动的新型恶意软件

黑莲花（BlackLotus）是一种新型 UEFI Bootkit 恶意软件，最近被安全公司ESET 发现。这种软件可以绕过传统安全防护程序的保护，完全控制受感染计算机的操作系统。与传统的恶意软件相比，黑莲花更加难以检测和清除，因为它可以绕过许多现有的安全防护措施，包括反病毒软件、操作系统内核保护、安全引导流程和系统完整性检查等。


黑莲花的开发者将其作为商业化的恶意软件工具进行出售，用于网络间谍和网络犯罪等活动。然而，该恶意软件的传播方式尚不清楚，因为它的隐蔽性高，不容易被发现。ESET 发现这种恶意软件的方法是使用了名为 Fuzzing 的技术，该技术可以模拟攻击者可能使用的各种场景，并检测漏洞和风险点。


这种恶意软件是一种 UEFI Bootkit 型的恶意软件，它可以在 UEFI 固件中安装一个恶意的代码段，以取代原来的引导程序。由于 UEFI 固件是计算机系统的底层软件，控制着操作系统的启动过程，所以一旦被感染，黑莲花可以控制整个计算机系统并长期存在，而且不会被操作系统和传统反病毒软件检测到。


深信服深瞻情报实验室一直在关注全球攻击者使用的各种新型的攻击手段、攻击武器与全球最新的攻击事件，此前发布过多篇与 RootKit 相关的技术分享文章，现针对这款新型 UEFI BootKit 恶意软件进行了相关分析。

PyTorch遭供应链攻击，云计算平台面临更多供应链威胁

供应链攻击技术是 APT 攻击组织经常使用的一种主要攻击方式之一，这种攻击方式主要针对特定的企业和用户进行定向攻击活动，其中最主流的是软件供应链攻击。


软件供应链攻击可以分为基于软件源代码、开源软件第三方包和软件开发工具相关。其中，基于软件源代码的攻击方式是最为隐蔽、危害最大，技术难度最高的一种攻击方式。而基于开源软件第三方包和基于软件开发工具相关的攻击方式相对容易实现。


2021 年 1 月，深信服深瞻情报实验室披露了 Lazarus APT 组织通过在 VS 项目中设置预构建事件命令，进行基于软件开发工具相关的供应链攻击，当运行受感染的VS软件开发工具的工程项目文件之后，恶意代码会调用 rundll32 执行VS项目中附带的恶意 64 位的 DLL 文件。Lazarus APT 组织通过上述的供应链攻击方式，目的是为了定向盗取安全研究人员的 0day 漏洞等。


近日该攻击方式的 POC 被公开，深信服深瞻情报实验室第一时间进行了跟踪分析，深信服深瞻情报实验室一直致力于研究各种 APT 组织的攻击手法，他们通过一些真实的攻击事件对软件供应链攻击活动进行了深入的研究，特别是基于开源软件第三方包和基于软件开发工具相关的攻击方式。

大型企业级电话管理系统供应商3CX遭受严重供应链攻击，受影响用户超千万

3 月31日，3CX 公司发布了针对 DesktopApp 软件的风险通告（CVE-2023-29059）。3CX 互联网语音协议（VOIP）桌面客户端在通过 Git 进行构建时，被注入了受供应链攻击的恶意代码，并使用了由 Sectigo 颁发和 DigiCert 加盖时间戳的合法 3CX Ltd 证书。


据 3CX 官网显示，该公司成立于 2005 年，是一家总部位于塞浦路斯的软件公司，专门提供企业级VoIP通信解决方案。目前，3CX的产品和服务已经覆盖全球 160 多个国家，并且已经拥有超过 60 万企业用户，日活跃用户超过 1200 万。因此此次供应链攻击事件造成的影响十分巨大。


此次供应链攻击做的非常隐蔽，最早的入侵攻击时间可能是在去年年底左右，影响平台除了 Windows 还有 MAC，攻击者篡改了几个最近 Windows 和 Mac 版本的软件安装程序，以向用户计算机投递额外的信息窃取恶意软件。经过深信服深瞻情报实验室分析，相关木马特征符合 Lazarus 组织的特点。

疑似 Kasablanka 组织针对阿塞拜疆及乌兹别克斯坦地区的攻击行动分析

在 2022 及 2023 年期间，深信服深瞻情报实验室监测到疑似 Kasablanka 组织的多次钓鱼攻击活动，针对目标主要集中在中东、中亚以及东欧地区，其主要目标为乌兹别克斯坦及阿塞拜疆的外交及其他政府部门。


其钓鱼攻击相比其他钓鱼略有不同，通过向目标发送恶意宏文档，宏文档通过命令调用浏览器打开钓鱼页面诱导目标数据输入相关凭证。除了通过钓鱼窃取邮箱凭证外，该组织还投递多种木马对目标进行攻击，其木马组件多使用 python 开发并使用 telegram 通信。


从攻击动机分析，该组织具有强烈的信息收集和间谍活动特征，属于疑似国家级背景支撑的黑客组织。从使用的工具看，攻击行动中大量使用 python 编写及 telegram 通信的木马，telegram 通信类木马在网络犯罪论坛中一直保持着较为活跃的状态，组件开发人员具有强烈的黑产从业人员气息。

BYOVD技术滥用，利用驱动获取最高权限削弱防御

BYOVD 攻击，指攻击者通过滥用带有漏洞的驱动获得内核访问权限并执行恶意代码，这项技术近来广受各大攻击组织的青睐，且源于各类情报的不断公开和工程化的开源项目，此技术正在从仅被类似于方程式这样的高级 APT 组织所使用，演变为一种常见且通用的攻击技术手段。


臭名昭著的朝鲜黑客组织“拉撒路集团 ”(Lazarus group) 一直在利用流行的Windows 防病毒软件 Avast 的 0day 漏洞进行有针对性的攻击。这些攻击主要针对美国和欧洲的金融机构。这个 0day 漏洞是由网络安全公司 ESET 的研究人员发现的，它允许攻击者在具有system特权的目标系统上执行任意代码。据说，拉撒路集团利用该漏洞在受害机器上部署了一种名为 “LZBot” 的自定义恶意软件。Avast 已经针对该漏洞发布了补丁，并敦促所有用户立即更新他们的软件。拉撒路集团被认为是近年来几起备受瞩目的攻击事件的幕后主使，包括 2014 年臭名昭著的索尼影业黑客袭击事件，该组织仍然是全球网络安全的主要威胁。


Scattered Spider团伙通过BYOVD战术在攻击中使用了名为 “TinyPosh”和“TinyNode” 的两种恶意软件，这些恶意软件主要用于窃取机密信息和加密货币挖掘。通过利用 Windows 驱动程序漏洞，这些恶意软件可以在系统中保持持久性，并避开传统的安全监测方法。


最近的一些攻击案例被发现使用了名为 Sliver 的开源渗透测试工具。攻击者在攻击中使用 BYOVD 技术，通过禁用安全产品并安装反向shell实现攻击。在对使用未修补漏洞或配置不当的系统进行攻击的过程中，ASEC 发现了攻击者利用漏洞对 Sunlogin 远程控制程序进行攻击的情况。该软件的远程代码执行漏洞已公开披露并被利用。


微软于 22 年 10 月表示其会修复 Windows 易受攻击的驱动程序黑名单同步问题，目前 Win11 以上系统可在 Windows安全中心->设备安全性->内核隔离详情中查看 Microsoft 易受攻击的驱动程序组织列表打开状态；Win10以上系统可通过以下微软链接手动下载和应用易受攻击的驱动程序阻止列表。


深信服深瞻情报实验室第一时间对 BYOVD 技术进行了跟踪分析，深信服深瞻情报实验室一直致力于研究各种 APT 组织的攻击手法，通过一些真实的攻击事件对BYOVD 技术进行了深入的研究，提出了相应的解决方案与多个产品结合。
