**挖矿病毒活跃家族**

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**1.8220 团伙**

**8220 是一个非常活跃的挖矿团伙，首次发现于 2017 年**，针对 Windows 和 Linux 平台设备发起攻击，早期通过传播恶意 Docker 镜像进行传播，后来演进为利用漏洞入侵受害设备，组件僵尸网络，对抗安全软件，下载并部署挖矿程序，挖取数字货币以谋取利益。  

  

2022 年之前的攻击活动中，该团伙利用了十几种服务漏洞：

Apache Struts远程代码执行漏洞（CVE-2017-5638）

Weblogic WLS 组件（CVE-2017-10271）

Apache solr RCE 漏洞（CVE-2019-0193）

Weblogic 反序列化远程代码执行（CVE-2019-2725）

Confluence 远程代码执行漏洞（CVE-2019-3396）

Nexus Repository Manager 3 远程代码执行漏洞（CVE-2019-7238）

Apache Flink 任意文件上传（CVE-2020-17518）

Weblogic Console HTTP 协议 RCE（CVE-2020-14882）

Confluence 远程代码执行漏洞（CVE-2021-26084)

Apache Log4j2 远程代码执⾏漏洞（CVE2021-44228）

ActiveMQ 未授权访问漏洞

Docker remote api 未授权访问漏洞

Hadoop Yarn 未授权访问漏洞

SSH 未授权访问漏洞

Redis 未授权访问漏洞

  

**在SSH未授权访问方面，开始使用专用的文件来管理暴力破解步骤。**

在 2022 年 7 月，深信服千里目深瞻情报实验室捕获到该团伙利用 Atlassian Confluence OGNL 注入命令执行漏洞（CVE-2022-26134）的攻击活动，通过漏洞下载脚本并执行，关闭安全服务、清除竞品、收集信息、横向移动、部署挖矿程序。

  

![](../Images/21eff7916b07e8ee03a33eea272bbac6.png)![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**2. TeamTNT 团伙**

**TeamTNT 是一个国际挖矿团伙，首次发现于 2020 年 4 月**，主要针对易受攻击的 Docker 和 Kubernetes 设施发起攻击，能够窃取各类登录凭证信息，部署挖矿程序，挖取数字货币以牟取利益。  

  

该团伙通常通过 Docker API 未授权漏洞获取受害主机权限，也会在已经获取权限的 Kubernetes 设施投放恶意镜像，窃取软件配置凭证，服务凭证，CSP 凭证等多种凭证，并且能够使用预加载、LKM Rootkit 等技术隐藏挖矿进程，而且具有增加了针对 GPU 设备挖矿的能力。

  

在成功渗透后，还会部署 IRC Bot，可以查看网络内看到更多易受攻击的设备，进行进一步渗透和控制。在 2021 年末，该组织使用了一种新型的 TNTbotinger IRC Bot，相比之前使用的版本增加了 DDos 功能。

  

2021 年 11 月，TeamTNT 在社交媒体发文表示将会停止攻击活动。

![](../Images/c4763950a39369b70fcd8c87a317a23b.png)

2022 年 9 月，TeamTNT 重新开始活动，并被披露，该团伙劫持了大量伺服器，试图破解比特币。

  

2022 年 11 月，发生了名为“Kiss-a-dog”的挖矿攻击事件。

  

该事件就是针对易受攻击的 Docker 和 Kubernetes 基础设施发起的，从此次攻击所使用的技术栈来看，和 TeamTNT 团伙的所使用的技术栈多处存在重叠。

  

值得注意的是，本次攻击中没有看到 IRC Bot 的影子，而是通过安装 Redis 服务作为后门执行挖矿和渗透脚本。

  

**可以确定的是，针对云和容器集群的攻击仍在阴暗处偷偷发展壮大**。

  

据统计，全球目前有上万个 Docker 实例和几万个 Kubernetes 设备暴露在公网上，随着数字化转型的发展，这个数字一定还会进一步增加，云端安全仍然很大的挑战。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**3. Win10UpdateMiner 挖矿木马**

**Win10UpdateMiner 是一款挖矿木马，最早出现于2022年5月中旬**，通过伪装 Windows 10 系统升级程序进行传播，能够在受害主机进程内注入挖矿代码，占用受害者资源，挖取比特币，谋取利益。

  

2022 年 11 月，Win10UpdateMiner 变种被发现，伪装证书升级程序，并将挖矿载荷的解密过程移动到了第二阶段程序，但总体执行流程没有太大变化。

  

该木马有一个比较明显的特征，就是会利用第三方邮件系统托管加密的挖矿载荷，而没有使用自己的网络资产进行托管。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**4. Kthmimu 团伙**

**Kthmimu 是一个新兴挖矿团伙，首次出现于 2022年3月，针对Windows和Linux两个平台进行攻击，主要通过 Log4j 漏洞传播，能够清除竞品、创建计划任务、部署挖矿程序，挖取虚拟货币以谋取利益。**

在 Windows 版本中，会通过 WMI 创建计划任务，定期从远程下载新的挖矿程序部署脚本。

  

2022 年 6 月，该组织再次进入大众的视野，使用多种漏洞进行传播和渗透:

Spring4Shell 漏洞（CVE-2022-22965）

GitLab CE/EE RCE 漏洞（CVE-2021-22205）

Linux Polkit 权限提升漏洞（CVE-2021-4034）

Linux 内核提权漏洞（CVE-2021-3493)

Sudo 堆缓冲区溢出漏洞（CVE-2021-3156）

Laravel 反序列化 RCE 漏洞（CVE-2018-15133）

脏牛漏洞（dirtycow）（CVE-2016-5195)

  

值得一提的是，该团伙在受害主机上植入 Perl 语言编写的 IRC Bot 以建立自己的挖矿僵尸网络。该僵尸网络存在高达 40 多个命令，包括 DDos，横向移动等功能，并获得了上万台易失陷设备的 IP 地址。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**5. 1337 团伙**

**1337 是一个新的挖矿团伙，首次发现于 2021 年底**，通过对爆破暴露在公网的 SSH 服务进行攻击，成功获取受害主机权限后，会部署挖矿程序，挖取虚拟货币以谋取利益。

  

从技术栈来看，该组织还属于初期阶段，不像老牌挖矿团伙一样具备一定的漏洞利用能力。不过值得注意的是，该组织没有使用 XMRig 挖矿程序作为矿机，而是使用了不常见的开源矿机 Phoenix Miner。

  

Phoenix Miner 是一个模块化、快速、高效的虚拟货币挖矿机，通常用来挖掘 ETH, ETC 等 Ethash 的虚拟货币，支持 Windows 和 Linux 双系统，支持 AMD 和 Nvidia 的显挖矿，包括混合挖矿功能。

  

另外，该团伙还使用了一款名为 XHide 的拥有近 20 年历史的黑客工具，该工具被用于隐藏挖矿进程。值得一提的是，这款工具在 2020 年就被公开被某个不知名的挖矿组织所使用。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**6. Hezb 团伙**

**Hezb 是一个新的挖矿团伙，首次出现于 2022 年 5 月**，针对 Windows 和 Linux 两个平台进行攻击，利用 Confluence 漏洞（CVE-2022-26134）和 WSO2 RCE 漏洞（CVE-2022-29464）进行传播。能够清除竞品、卸载安全软件、部署挖矿程序，挖矿虚拟货币以谋取利益。

  

该木马还通过开源代码平台获取 CVE-2021-4034 漏洞利用程序，该漏洞可以提升本地权限。

**挖矿攻击未来发展趋势**

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**1. 受虚拟货币行业影响--趋于稳定币**

2022 年 5 月，包括比特币在内的三大稳定币价值一夜之间缩水 30%，加密货币的价值发生了较大的变化，包括比特币在内的大量加密货币价值大幅度缩水，不论是散户还是投资机构都受到了较大的打击。  

  

FTX 作为国际大型加密货币交易所，拥有 100 万用户，其 30 岁执行长班克曼佛利德，在 2021 年 11 月财产多达 150 亿美元，但在 2022 年 11 月 11 日 FTX 申请了破产，并且还伴随着高额的债务问题。**一年的时间，公司加密货币的崩溃让一个庞然大物就这样轰然倒塌**。

  

覆巢之下安有完卵，受挖矿团伙青睐的门罗币也同样受到了重创。除了早在 2021 年 11 月就宣布停止活动的 TeamTNT，此期间挖矿团伙的活跃程度也明显受到了影响，一些挖矿组织就这样偃旗息鼓，消退在大众的视野之中。

![](../Images/e680c2f1368d44ea21e5994de15c5021.png)

就像加密货币行业一部分人的想法一样，一些网络黑产团伙似乎也仍对加密货币的前景有着一定的信心，因此一些新兴的挖矿团伙进入了大家的视野，而且随着 9 月份加密货币逐渐回暖，一些老牌挖矿团伙也开始蠢蠢欲动。

  

因此，**黑产挖矿团伙活跃度和加密货币行业有着很强的相关性**。

  

由于金融和加密货币行业的震动，投资者也开始倾向于投资更加安全的资产，而在加密货币行业，以太坊作为一种稳定币，就成为了加密货币投资者的宠儿。

同样，一些新兴挖矿团伙，就抛弃了门罗币的挖取，转而转向更加稳定的以太坊。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**2. 受政策影响--生存空间受限**

2022 年，国内对于整治挖矿的力度进一步加大，贯彻“政治虚拟货币”挖矿活动要从源头抓起的方针，帮助公众认清“挖矿”的国际背景、巨大隐患和现实危害，倡导大众远离“挖矿”活动。  

  

在虚拟货币交易方面，禁止将虚拟货币纳入保险责任范围，不允许虚拟货币的交易炒作活动。

  

社交媒体方面，国家网信办督促主要网站平台切实落实自己的主要责任，保持对虚拟货币操作进行打压，加大对诱导虚拟货币投资的账号，进行打击。

  

在当前的国际经济形势下，对于“挖矿”活动的打击一定会继续加强，挖矿黑产团伙的生存空间也一定会继续缩小。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**3. 攻击平台发展趋势--转向信创环境**

随着全球数字化转型的逐渐加深，公网上易失陷的容器、服务和基础设备在全球的数量已经达到6万台之多，而且这个数据还在继续增长，这给挖矿团伙形成了可乘之机。  

  

近些年，针对云的挖矿活动也日益增多，**即使在虚拟货币行业和各国政策的多重压力下，仍有挖矿团伙在云端活动**。

  

值得一提的是，国内企、事业单位正在大力推广信创环境，可以保障各职能系统在关键时刻仍然可以正常运作，这也一定程度上可以保护关键基础设施不受网络攻击侵害。

  

但同云场景情况相似，在用户不断增多的情况下，难免有黑产团伙铤而走险，很有可能在不久的将来，会出现针对信创环境的挖矿程序。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**4. 攻击方式发展趋势--更加多元**

在挖矿团伙的技战术方面，SSH 或 SQL 等服务的弱口令爆破和 N Day 漏洞利用仍然最常见的入侵手法，这样的方式能够以用最少的成本谋取更多的利益，似乎这也是挖矿团伙的一种行事准则。  

  

挖矿团伙更喜欢使用已于获取的工具或开源项目进行攻击，在扫描阶段使用的工具，例如 Massscan、Portscan、Hxx 等等。包括用于隐藏挖矿进程的Rootkit 工具，也是倾向于使用开源项目进行小幅度修改、甚至不进行修改。

  

一些挖矿团伙正在组建自己的挖矿僵尸网络，这些僵尸网络多数为 Perl 编写的 IRC Bot，由开源项目修改而来，在 DDoS 功能的基础上，扩充了数据获取、和矿机批量管理的功能，使自动化攻击过程更加透明可控。

  

挖矿团伙更多的投入一般是在虚拟货币矿池的搭建和资产轮换方面，主要用于对抗威胁情报产品的检测，这决定着是否能够将非法谋取的利益装进口袋。

  

在当前对挖矿团伙的不利形势下，节约成本的趋势还会进一步加深，未来可能会涌现大量的轻量级挖矿团伙。

  

挖矿团伙并非故步自封，也在尝试新的攻击方式。**2022 年 11 月，研究人员发现某未知名挖矿团伙利用伪造的知名电子厂商网站，将挖矿程序捆绑在该公司的工具上进行传播。这样的方式通常用于窃密木马病毒的传播**。

  

如 8220 团伙，也开始使用 PureCrypter 一类的廉价 MaaS 进行传播。

  

**大多数情况下，挖矿病毒的传播方式和其他类型的，如勒索、木马等类型的病毒一样，可以有多种方式，可以通过渗透植入，也可以通过网页钓鱼，或者软件捆绑，又或者垃圾邮件。因此，可能会出现更多传统或新式的传播方式的挖矿攻击活动**。

***02***

**2022 年黑客工具技术态势分析**

2022 年以来，在网络攻击、红蓝对抗愈演愈烈的趋势下，为达到简化攻击流程、节约攻击资源、精进对抗技术的目的，黑客工具作为一种半自动化的攻击程序，已然成为了 APT 组织和黑产团伙攻击活动中不可或缺的一部分。  

  

**黑客工具的用途广泛，在攻击的各个阶段均扮演着重要的角色，通常使用者会利用其进行窃密、横向移动、获取网络深层权限、留下后门方便后续进攻、下发恶意文件等恶意活动**。

  

黑客工具的使用者有红队的安全研究人员，也有 APT 组织、网络黑产团伙等，黑客工具被用来发起互联网设备攻击的事件也在快速增长。

**2022 年热门黑客工具**

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**Metasploit**

Metasploit，老牌攻击利器，于 2004 年问世那一刻，便引发安全界的强烈地震。从一句犀利标语“The world’s most used penetration testing framework”的背后，就能够感受到其手握寰宇的自信。

  

Metasploit 的宗旨是永久开源，其自身的修改非常频繁，几乎每一次 CVE 被披露后，该工具都会进行一次及时的更新。

  

该工具由渗透攻击、攻击载荷、辅助、空指令、编译器、后渗透、防御规避（免杀）七大模块组成。包括信息收集、指纹识别、漏洞探测、漏洞利用、C2 连接、后渗透处理、文件混淆、木马生成、病毒生成、溢出攻击等强大的攻击功能。

![](../Images/a941635945f1cd1b0c038443ddff16ed.png)

Metasploit Framework 6.2，于 2022 年 9 月 6 更新。

  

新增了扩展加密功能，从 MSF6 开始，所有 Meterpreter 都使用 AES 对通信流量加密，使特征检测变得困难。另外，Metasploit 改进了 SMB 客户端，增加其通信复杂程度，以抵御流量特征的检测。

  

Meterpreter 信道改进。目前 Meterpreter 使用的 DLL 文件现在通过序号解析必要的函数，这意味着反射型加载 DLL 使用的导出表不再作为文本数据存在于生成的二进制文件中。

**Cobalt Strike**

Cobalt Strike，自 2012 年起开始发布第一版，到现在的 4.7.2，成为了安全从业人员和攻击者口中的渗透神器。该神器在构造时也曾参考过 Metasploit，可以说是青出于蓝而胜于蓝。

  

该工具具有端口转发、服务扫描、自动化溢出、多模式端口监听、Win exe 木马生成、Win dll 木马生成、Java 木马生成、office 宏病毒生成、木马捆绑、钓鱼攻击等众多强大功能。

![](../Images/e4ab2eefc61eb298f46c14796d95ae9f.png)

图2.2 Cobalt Strike框架界面

2022 年 8 月，官方推出 4.7 版本，此次更新延续了 Cobalt Strike 一贯的主题：稳定性和灵活性，在稳定使用的同时，增加更多有用有趣的功能。

  

新增支持 socks5 代理，打破原有固化通信手段，使信道传输方式更加多样。

  

新增更灵活的缓冲区溢出（BOF）内存驻留技术，用户可自行调整 BOF 在内存中的方式，增加特征检测难度；

新增 Beacon 休眠方式，可自定义休眠函数，并可调用动态函数（LIBRARY$function）和 Beacon API。并将 Beacon 重新设计，支持在 Beacon 休眠过程中针对 BOF 的所有操作。

  

此外，还有一些使用体验方面的优化，如界面调整、批量有效负载生成、信标存活跟踪等。

  

如此优秀的工具，自然会被各大 APT 组织及恶意黑客组织盯上，并使用其执行攻击行为。

  

2022 年 10 月，安全研究人员发现，Black Basta 勒索团伙在攻击过程中，使用 Cobalt Strike 作为第二阶段的攻击载荷，并完成横向移动。

**Sliver**

前浪苍劲，后浪澎湃。名不见经传的 Sliver 登上历史舞台。该工具由 BishopFox 公司采用 Go 语言编写，于 2020 年初次完整发布，设计之初便以替代 Cobalt Strike 为目标，成为一款优秀的安全测试工具，而其本身代码开源也成为其一大优势。

![](../Images/ea0f78d856dc4d9f66e926b751375440.png)

Sliver 包括许多常见的 C2 框架特性，支持多个同步操作、多种侦听器类型、用户开发的扩展、有效负载生成，支持多种回调协议，拥有多人攻击模式、多通讯协议支持、分阶段与无阶段 Payload 生成、动态编译、编译时混淆、.NET 集内存执行、反取证、Windows 进程迁移等强大功能。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**Brute Ratel C4**

Brute Ratel C4（BRc4）是一款商业化渗透测试工具，于 2021 年首次问世，由 Mandian 和 Crowd Strike 前红队队员 Chetan Nayak 发布的工具包，用以替代被安全公司重点防范的 Cobalt Strike 框架。

  

经历一年时间的磨砺后，该工具的能力已然可与 Cobalt Strike 等知名工具相媲美。

  

BRc4 没有提供漏洞生成特性或漏洞扫描特性，但是使用了众多用于规避和检测对抗技术，其 C2 核心通信逻辑是将有效负载输出隐藏在合法网络流量中。

![](../Images/043a0913f7fd390d9455bd177aff841e.png)

BRc4 拥有基于 HTTPS 的 DNS 通信配置、自定义 C2 通道、间接调用系统 API、检测 EDR 用户空间 HOOK、清晰明显的域环境界面、友好的攻击信息面板等优秀功能。

  

2022 年 9 月，BRc4 v1.2.2 的破解版本开始在地下网络犯罪团体中流传，这预示着该工具很可能会掀起一阵浪潮。

**4. 防御规避技术趋势**

在通讯流量方面，为了增加隐蔽性，降低被安全软件发现的风险，Cobalt Strike、Metasploit、Sliver、Brute Ratel C4、DeimosC2、Nighthawk 等一系列成熟的渗透型框架，都拥有自己的信道传输协议，如加密流量、避免固定特征、将数据混杂在正常业务之中、构建隐蔽隧道传输信息等方法，达到窃取数据、下发隐蔽命令的目的。  

  

Cobalt Strike 在最近的一次更新中，用户可自定义心跳函数，使防御方通过单次难以判断 Cobalt Strike 的入侵。

  

在文件方面，通过分段加密、修改特征码、花指令、加壳等方式进行文件免杀处理，使杀软无法正常匹配现有的文件、行为、内存特征，导致无法检测出对应工具生成的恶意文件。

  

2022 年 5 月，hubtress 公司分享了一种有趣的混淆文件。攻击者部署一种编码、加密和规避防御的噪点，以增加防御的成本。Powershell 脚本可能对防御方来看毫无意义，这种混淆的 Powershell 试图逃避防御者及安全系统来分析它们。

![](../Images/daba55eca4e7a10f759379c3c177b4c1.png)

无文件攻击是另一种避免文件被检测的方式，不需要将恶意文件落地到目标的磁盘，便可执行相关的命令。

  

理想的无文件攻击是只存在于内存中的恶意代码，比如最早的 Powershell downloadstring，远程文件被当成字符串下载到 Powershell 进程内存中执行，而后发展到利用 mshta、rundll32 等系统程序执行脚本的各种奇技淫巧，再到现在流行的各种 .NET assembly 托管代码注入技术，当然还有一些完全脱离操作系统的高端无文件攻击。

  

微软设立了一个攻击模型，按磁盘文件的活动将无文件攻击分成了 3 个类型：

![](../Images/091b3c46308683f8af05adb8629f5a95.png)

1、没有任何的文件活动。简单说就是攻击活动没有任何的磁盘文件落地和磁盘文件的操作行为，一般这种攻击的实施都脱离了操作系统，是由更上层的硬件固件和软件层发起的；

  

2、没有磁盘落地文件，但通过文件间接活动，恶意代码一般通过白文件间接加载到内存中执行。这类攻击恶意代码的载体大多数都是脚本，通过程序命令执行，也有通过磁盘引导记录等特定机制的执行；

  

3、需要操作文件进行活动。比较容易能理解的意思是恶意代码变成了数据，利用文件相关的程序漏洞或功能特性将恶意数据转换为恶意代码执行。

  

除此之外，微软又进一步按感染主机对无文件攻击进行分类。

1、漏洞攻击，基于软件和操作系统安全漏洞的无文件攻击。

2、硬件攻击，脱离操作系统的无文件攻击。

3、执行和注入，无文件攻击执行恶意代码的常见形式。

**2022年感染式病毒态势分析**

现存于网络世界的各类恶意软件中，感染式病毒作为起源最早、影响最为深远的病毒类型之一，其以强大的传播能力、变型能力存活至今。

  

自 2001 年 Windows XP 发布以来，感染式病毒经历了井喷式的发展。早期终端安全防护产品的能力缺失，使得感染式病毒在全网的泛滥屡禁不止。

  

感染式病毒着重于“感染”二字，通过对原有的可执行文件、WORD 文件和 HTML 文件等文件进行修改，在其中附加恶意代码块，使用户在打开文件的过程中不自知的运行了恶意代码。

  

因为感染式病毒直接对文件本体进行操作，因此在感染过程中常会出现对用户的文件造成永久性的损坏的情况。同时，部分感染式病毒家族会出现重复感染的情况，一次次的感染，导致用户的文件臃肿、磁盘空间被占用。

  

感染式病毒通常具备横向传播、持久化、连接 C2 服务器、窃取信息、部署挖矿程序等功能。

**2022年活跃感染式病毒家族**

2022 年感染式病毒总体仍在以百万级别的数量增长，为首的是 Virut、Sality、Neshta 等几大家族。

![](../Images/97f226130ac84570d5375c3aecf7f10e.png)![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**1\. Synaptics**

因其样本含有的攻击者邮箱地址特征，又被称为 Xred，最早发现于 2016 年，其一部分代码与 DarkKmote 远控基本一致。DarkKmote 出现于 2012 年，2018 年停止更新，在此期间该软件的作者一直开放下载。

![](../Images/0494030102cab92600b85cd13b797a5e.png)

Synaptics 运行后通常会，释放病毒本体文件 Synaptics.exe 至 Synaptics 目录下，并且将文件和目录设置为隐藏属性，文件设置为系统文件，然后执行释放的病毒本体。

  

在父进程结束后，子进程随即开始进一步感染。遍历 Desktop、Download 和 Documents 目录下的所有文件，感染所有目标文件。

  

该病毒的功能通常为窃取信息、与 C2 服务器通讯、控制用户机器、从远程拉取文件并执行等。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**2\. Sality**

Sality 最初被发现于 2003 年，经过多年的发展已经变成一个持久的、多变的、拥有多种功能感染性病毒。被 Sality 感染的计算机可能通过 P2P 网络被控制成为“肉鸡”用于欺诈邮件的中继站，或成为流量转发的代理，或被窃取用户个人信息，或被用于进行分布式计算、挖矿等。

  

自 2000 年以来，部分的 Sality 版本还发展出了利用 Rootkit 技术隐藏自身的能力。正因其不断发展的变种及不断丰富的能力，使得 Sality 成为当前网络世界中最复杂、最难以处理的病毒家族之一。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**感染式病毒未来趋势**

随着安全技术的普及，落后的传播方式令感染式病毒所引发的影响越来越小，很多时候，感染式病毒的爆发并不会造成受害者业务停止等糟糕的情况。

  

在研究过程中，偶尔能够见到针对 Linux 的感染式病毒，随着信创系统的逐渐普及，不能排除未来将会出现针对 Linux 操作系统的感染式病毒的可能。届时很有可能会看到使用更易跨平台的 Rust、Go 编写的感染式病毒。

  

虽然相较勒索等高危类型病毒的影响较弱，但感染式病毒其难以去除的性质仍令很多受害者头痛不已。

  

感染式病毒可能会在不久的将来加入 MaaS 用于分发其他恶意软件，可能会成为另一种形势的勒索软件，还可能在几年之后逐渐没落，甚至消亡，但在短期内仍旧是需要警惕的安全隐患。

**2022年恶意脚本技术态势分析**

夜色降临之际，草木皆可为剑。

  

脚本语言是一种计算机程序语言，以简单的方式快速完成某些复杂的事情通常是创造脚本语言的重要原则，能让开发者编写出让计算机系统听命行事的程序。脚本往往意味着灵活多变、接口调用方便、上手容易，且随着其发展、功能方面已完全不逊色于其他编译型语言。也正因如此，脚本也越来越受到不法分子的追捧，在攻击过程中起着不小的作用。

  

近几年，勒索攻击、挖矿攻击、APT 攻击、网络黑产等攻击事件中往往都有脚本的身影。随着安全软件对可执行程序的查杀越来越精确，脚本代替部分功能出现的攻击事件越来越多，实现技术也越来复杂。

  

2022 年以来，新增的恶意脚本数量就占据着所有恶意文件总量很大的比重，其中脚本和 PE 可执行程序的比例约为 1:2。

![](../Images/1a5c41b22040ad21911dff097565848f.png)

目前，在网络攻击中使用最多的脚本语言是 JavaScript、其次是 VBScript 和 PHP，这与脚本语言的流行程度，使用场景和功能有着很大的关系。

  

![](../Images/e62c4ad84ac449da2da5678ae84840c3.png)

**未来趋势  
**

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**1. 语言替代趋势**

近几年，在 Powershell 被各路挖矿、黑产、勒索组织、APT 组织大肆使用，很多安全产品都对 Powershell 做出了针对性的安全解决方案，微软官方也推出了 ASMI 机制来监控脚本的使用情况。

  

因此 Powershell 被恶意利用的空间变得狭窄，攻击方都在寻找 Powershell 的替代品，以至于 JavaScript、 VBScript 和 Python 在攻击事件中出现的频率逐渐升高。

  

继 2020 年出现了 Python 的 .net 加载器之后，2022 年又出现了 JavaScript 和 VBScript 的 .net 加载器。例如一款倾向于个人的勒索程序 Magniber 其运营商主要使用 Chrome 和 Edge 浏览器的安全更新来推送恶意 Windows 应用程序包文件。

  

以往 Magniber传播活动中，背后运营商主要使用 MSI 和 EXE 文件，最近则改用了 JavaScript 加载勒索程序本体，加载器本身经过混淆处理，并使用了 DotNetToJScript 技术变种。

  

该技术的原理在于将脚本的运行环境设置为 .NET，并通过反序列化的方式在内存中执行 .NET 程序，不需要将释放文件保存到物理磁盘上，可以避免被大多数安全产品检测。

  

随着技术发展，还会有更多新型的脚本语言被开发出来，但便利生产工作的同时，也很可能会成为攻击者的助力。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**2. 工具化趋势**

脚本的编程十分灵活、功能强大、生态完善、且拥有比高级语言更低的写学习成本和开发成本，脚本工具化这一趋势在各个攻击领域都有体现：攻防对抗中很耳熟能详的工具都采用脚本语言编写或重写，如知名的 C2 框架 Empire，Nishang 等，除此之外还有一些使用简单方便的工具，如 powercat、impacket 等。

  

同样，在网络黑灰产中，脚本语言也被用于开发病毒程序，如新发现的 RedLine 加载器中集成了 JavaScript 编写的 VJW0rm 远控程序。多个挖矿团伙使用 Perl 语言编写的 IRC Bot。

  

2022 年初，APT35 也被公开使用了名为 PowerLess的新型 Powershell 后门，该后门通过在 .NET 上下文中直接运行而非生成 Powershell 进程来规避 Powershell 安全检测。

  

2022 年 3 月发现的勒索软件的新变体中，也在使用 Powershell 编写加载器，并使用反射加载的技术执行最终的代码。

  

2022 年 9 月，使用 Python 编写的 W4SP 窃密木马采用了 Hyperion 对源码进行混淆，该木马被上传至 PyPI 的多个库进行供应链攻击，导致大量受害者信息失窃。

  

使用脚本语言编写黑客工具可以很好的规避杀软的检测，且Powershell、JavaScript、VBScript这样的脚本语言Windows系统本身就具备解释执行能力，无需其他依赖即可执行。

  

在未来，可能出现更多使用脚本编写的渗透工具或者病毒，这会是对安全产品检测能力的一大挑战。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**3. 专业化趋势**

专用于某一领域的脚本也具有强大的功能，能够被攻击者利用。Flash 时代的 ActionScript3，就曾被大量攻击者使用。

  

2018 年，研究人员发现潜伏多年的 AutoCAD 盗图事件，AutoCAD 为一款专业制图软件，使用者多为设计人员，对知识产权有着极高的保护需求。在该事件中，攻击者利用专业制图工具 AutoCAD 在加载图纸时会自动加载 AutoLisp 脚本这一特性，对 AutoCAD 用户发起攻击。

  

此次事件主要分了三个阶段：第一个阶段会收集主机的一些系统语言、CPU 信息、AutoCAD 版本等信息，通过 GET 请求上传到指定的服务端，然后服务端会对上传的信息进行判断并向受害主机发送。第二阶段会劫持浏览器主页、并查询主机上的安全软件，第三阶段则是收集主机图纸并发送到指定邮箱。

  

如同 Office 、WPS 的宏，AutoCAD 的 AutoLisp 也属于便利某专业领域而产生的专业化脚本，同时也能够做到很多常规脚本能够做到的事情。随着未来技术的进一步发展，会有越来越多的行业向数字化发展，届时也一定会有提升生产力的脚本语言出现，等到利益足够诱人的时候，那些语言将有可能成为攻击者受众的重要武器。

***04***

**2022年Rootkit技术态势分析**

Rootkit 作为一种集高权限、高隐匿性、高持续性一体的计算机软件，多数情况下，在系统的“底层”发挥作用，在网络攻击中，通常用于隐匿恶意代码主体，欺骗安全软件逃避检测，往往能够在“无声无息”间完成窃取数据、更改系统设置等高权限操作。  

  

Rootkit 一直是 APT 组织的常客。APT 组织 Strider 所使用的恶意 Rootkit 软件 Project Sauron 又名 Remsec，持续监控包括我国在内的多个国家至少长达 5 年之久，使用的技术手段之繁杂，令人望而生畏。

  

近些年来，网络黑灰团伙产对 Rootkit 也青睐有加。诸如双枪、BlackAv、麻辣香锅等病毒，都是利用 Rookit 技术劫持浏览器页面引流获取非法收益，还能够窃取受害者重要信息，甚至控制主机。

  

Rootkit 至今已发展出种类繁多、功能各异的病毒软件，但被披露出的 Rootkit 数量却屈指可数，一定程度上意味着其隐匿能力也在暗地里逐渐增强。

  

另一方面，从目前已经跟踪的 Rootkit 病毒来看，其持久化能力也在逐步提升。从 Rootkit 到针对引导驱动的 Bootkit，从单纯的提权需求到行为隐藏，Rootkit 技术仍将在未来逐步进化。

**2022年活跃Rootkit病毒家族**

据 2022 年应急响应数据统计，出现频率最高的为麻辣香锅，后续一次为 fvol、老裁缝、双枪木马、独狼等典型 Rootkit 病毒家族。  

  

![](../Images/bd05b6d12e5e8878c3e46d2837e1a1be.png)![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**双枪木马**

双枪木马，首次出现于 2017 年，至 2022 年，已经迭代了第四个版本，累计感染计算机万余台，经过多次迭代的功能越加繁杂，与杀软对抗的手段逐渐增加，自保护技术也越加丰富。  

  

该病毒能够劫持浏览器主页并篡改为带有推广渠道号的导航网站，也会劫持用户账号以发送广告和垃圾邮件。其使用上传到百度贴吧的隐写图片来为僵尸网络分发配置文件和恶意驱动，也曾利用阿里云存储托管配置文件。

  

双枪 4，即双枪木马的第四代，此版本的病毒伪装成游戏外挂在多个下载站大量的传播。使用 VMP 壳保护自身代码，避免被安全软件检测。能够注册网络回调以阻挡安全软件联网，并劫持了多个购物网站。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**紫狐木马**

该家族的病毒长期致力于网络黑产，通过刷量、推广用户不需要的软件获取利益，同时能控制大量的终端。该病毒基于开源 Rootkit 项目 Hidden 开发而来，并不断保持更新。  

  

紫狐通过伪装成 TG 等热门应用欺骗用户点击运行，也通过社会工程学相关的技巧，如钓鱼等欺骗用户运行该恶意软件。

  

正式挂载其 Rootkit 驱动前检测当前系统环境是否存在终端安全防御软件，若有则注销其 MiniFilter 并关闭其负责防御模块的进程。

  

通过直接向设备驱动发送 IRP 包直接与底层设备通信，避免了对系统API的使用从而绕过安全软件的检测。

  

能够终止国内外多种终端安全防御软件的检测、防御模块，利用 SMB 漏洞、SMB 爆破和网络扫描入侵其他机器。还会劫持受害者的邮箱应用账户向其他机器发送恶意的邮件，收集受害者信息发送至攻击者 C2 服务器上，隐藏恶意文件、隐藏注册表表项，保护应用程序不被终止。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**Lazarus**  

该 APT 组织自 2009 年被发现以来，一直活跃在世界各地。其主导、参与了多起与政府、商业组织有关的窃密活动。

  

2022 年 11 月，在 Lazarus 针对荷兰某航空公司发起的攻击行动中，使用 LinkedIn 向目标的职员发送招聘信息，附带的附件为恶意构造的钓鱼文件，用户打开该文件时攻击即开始。

  

Lazarus 积极使用 Bring Your Own Vulnerable Driver (BYOVD) 技术。该程序仅仅针对 Windows 7.1 到 Windows Server 2022 之间发布的系统版本，释放并加载经过认证的、已签名的 Dell 驱动，利用其访问控制漏洞（CVE-2021-21551）将进程权限提升至内核。并且该病毒通过检测当前进程是否处于被调试状态，阻止安全分析人员调试。能够清理注册表回调、进程创建回调、线程创建回调、映像加载回调，禁用 Windows 事件记录（ETW）、监控文件访问、监控主机流量等。

**Rootkit技术未来发展趋势**

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**1. 两个不同的发展方向**

网络黑产团伙使用 Rootkit 主要侧重于利用其高权限的特性避免被终端安全软件查杀。诸如刷量、流量劫持等都易被用户察觉，这里 Rootkit 被用作为一种持久化方案，即使受害者知晓自己的主机感染了病毒也无法轻易清除。未来，网络黑产团伙也定会在提升病毒的顽固程度上持续发力。

  

高级网络攻击组织则侧重使用 Rootkit 的隐蔽特性和高权限特性。通过对内核数据的修改，达到欺骗操作系统和安全软件，隐藏恶意软件运行的目的。

  

同时，利用的高权限特性在受害主机上肆意妄为。有理由相信，高级网络组织将持续开发更为隐匿的 Rootkit 技术。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**2. Bootkit 也许东山再起**

Rootkit 较普通软件更接近于底层，其与 Bootkit 的结合也更加紧密。国内的安全厂商曾披露过一起针对 UEFI 主板的 Bootkit 木马。该木马通过在系统启动的阶段进行多次 HOOK 最终在 Windows 系统启动时插入工作线程，转而执行 Rootkit 部分的功能。

  

攻击者还可以采用供应链攻击的方式，向受害者购买的 ROM 设备中植入 Bootkit 病毒，从而达到在受害者不知情的情况下监控其行为的目的。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**3. BYOD 技术茁壮发展**

BYOD 技术本质是漏洞利用技术的延展。攻击者通过挖掘系统驱动文件或服务供应商驱动文件的漏洞，利用此漏洞完成任意代码执行或任意地址写等行为，可以在本身不需要额外加载驱动的情况下，以 SYSTEM 权限完成任意行为。

  

因系统驱动文件或服务供应商驱动文件所呈现的暴露面虽然随用户不同而有较大差别，但总体暴露面相对较大且容易利用。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**4. Rookit 不再是难以获取的技术**

开源思想在全球的不断蔓延也促使 Rootkit 向着更多人走去。国内外各大开源平台上有诸多开源的 Rootkit 项目，其中不乏精品。这些开源项目极大的减小了 Rootkit 的开发难度，在此项目上做小幅度的修改即可完成自己的 Rootkit 软件。

  

Rootkit 的商业化也促使着 Rootkit 向着 RkaaS（Rootkit as a Service）发展。暗网平台售卖存在诸多恶意软件售卖的商家，直接将恶意软件包装成一个服务，购买者仅仅只需要点击按钮即可生成定制化的 Rootkit 软件，并能够实现在统一平台上管理各个被感染的 Bot。

  

这极大的降低了攻击者的使用门槛，也在一定程度上促进了各个恶意软件供应商的互相合作。

![](../Images/21ebc4929212857f3732ca510f9d4e02.png)

**5. Linux Rookit**

随着企业单位数字化转型和信创环境推广工作开启，Linux 设备的数量将进会进一步迎来大幅度的提升。容器安全和基于信创环境的办公系统很有可能成为攻击者的目标，由于环境的特殊性，攻防之间的对抗频率将大大提升，同事大大加快攻击技术的复杂化。Rootkit 作为一种辅助技术，是各种类型病毒在用户层进行安全对抗日渐复杂时的必要选择。  

  

早在 2020 年，安全研究人员就发现了一款可以追溯到2016 年的 Rootkit 程序，名为“Snoopy”，用在一次针对攻击亚马逊云服务器的攻击过程中，隐蔽了恶意信道，令当时的安全软件无法检测。

  

由于 Rootkit 技术已经不再难以获取，而且只需要简单编译就可以完成系统兼容，近期更有攻击者将 Rootkit 源码下载到系统本地进行编译，而且这种攻击还有增加的趋势。

  

ebpf 是一种基于 Linux 便于应用观测系统内核及设备状态的技术，即让使用者可以在应用层通过预定的 API 与内核通讯，实现更多的功能。

  

随着这项技术的技术的不断发展，epbf 技术也进入了安全研究人员的视野。在 2021 年的世界黑帽大会上，有一篇名为《With Friends Like eBPF, Who Needs Enemies?》的报告提供了一个利用 ebpf 技术实现的 Rootkit 案例。

  

现今，ebpf 不断发展，甚至 Windows 平台也推出了自己的开源 ebpf 项目，在 ebpf 不断不急的趋势之下，epbf 很可能会成为 Rootkit 技术的下一个战场。

  

***05***

**总结**

2022 年的恶意文件不仅仅以上几种类型，这里所能展现威胁相对于全年的威胁来说也仅仅是冰川一角，例如国内发生多起以 BlackMoon 为首的大规模僵尸网络感染事件，国外利用各种方式传播横行的 Redline 窃密木马，以及卷土重来的典型 MaaS Emotet 僵尸网络在全球范围肆虐。  

  

可以讲述的案例还有很多很多，但回顾过去不是为了判断，而是为了了解过去和现在的事件，以便我们更好地驾驭未来。

  

我国一直以来高度重视网络安全建设，将网络安全提升到国家安全的战略层面。“没有网络安全，就没有国家安全”，网络安全是建设现代中国、平安中国的重要一环。然而随着国际局面的复杂化，网络安全形势日益严峻，网络安全问题日益凸显，各种类型的网络恶意行为频发，大规模、系统性、长时间的网络攻击行为成为常态，破坏力和危害性与日俱增。

  

攻击成功并不一定是攻防技术水平存在差距问题。

  

防御是“面”的问题，而攻击是“点”的问题，资产越多防御越困难，修补漏洞、修复错误配置以及在关键的面向互联网的系统上实施多因素认证等基本步骤可以减少组织的攻击面，并使其不容易成为目标，增加攻击的成本，从而减少攻击者的利润。

  

网络安全需要每个人都保持警惕并不懈努力，以保护我们的互联数字生态系统。我们要“结硬寨，打呆仗”，承认自己的局限性，靠提升总体水位的笨办法，慢办法，走人世间最长的那条捷径。
