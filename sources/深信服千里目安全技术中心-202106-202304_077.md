**漏洞名称：**

Citrix ADC和Citrix Gateway远程代码执行漏洞

**组件名称：**

Citrix ADC、Citrix Gateway

**影响范围：**

Citrix ADC 和Citrix Gateway 13.0-x系列 < 13.0-58.32

Citrix ADC和Citrix Gateway 12.1-x系列 < 12.1-65.25

Citrix ADC 12.1-FIPS系列 < 12.1-55.291

Citrix ADC 12.1-NDcPP系列 < 12.1-55.291

**漏洞类型：**

远程代码执行

**利用条件：**

1、用户认证：不需要用户认证

2、前置条件：默认配置

3、触发方式：远程

**综合评价：**

<综合评定利用难度>：未知

<综合评定威胁等级>：严重，能造成远程代码执行。

**官方解决方案：**

已发布

  

**漏洞分析**

![](../Images/0e50f8ae1d488c25a0a5c15291490d5e.png)

**组件介绍**

Citrix ADC和Citrix Gateway是Citrix公司的应用程序交付控制器和远程接入解决方案。

  

Citrix ADC主要用于分析应用程序特定的流量，以智能地分发和优化 Web 应用程序。其功能可大致分为交换、安全保护、服务器场优化以及全局服务器负载平衡。

  

Citrix Gateway则是一套安全的远程接入解决方案，可提供应用级和数据级管控功能，以实现用户从任何地点远程访问应用和数据。

![](../Images/0e50f8ae1d488c25a0a5c15291490d5e.png)

**漏洞简介**

2022年12月15日，深信服安全团队监测到Citrix官方发布了一则漏洞安全通告，通告披露了Citrix ADC和Citrix Gateway组件存在远程代码执行漏洞，漏洞编号：CVE-2022-27518。

  

该漏洞由于系统未能在生命周期（创建、使用和释放）保持对资源的控制，**攻击者可利用该漏洞在未授权情况下，构造恶意数据进行远程代码执行攻击，最终可获取服务器最高权限**。

**影响范围**

目前受影响的Citrix ADC 和Citrix Gateway版本：

Citrix ADC 和Citrix Gateway 13.0-x系列 < 13.0-58.32

Citrix ADC和Citrix Gateway 12.1-x系列 < 12.1-65.25

Citrix ADC 12.1-FIPS系列 < 12.1-55.291

Citrix ADC 12.1-NDcPP系列 < 12.1-55.291

**如何检查漏洞是否存在**

打开ns.conf文件，确定是否配置为SAML SP或SAML IdP，文件中若出现以下任意一条命令并且版本在受影响版本内，请立即更新：

add authentication samlAction

add authentication samlIdPProfile
