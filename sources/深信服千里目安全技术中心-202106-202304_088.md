# 换汤不换药，Win10UpdateMiner新版本已被捕获

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247515660&idx=1&sn=085df9691cc6429ae6fd31f617b87dc2&chksm=ce46351cf931bc0a5e6a62d57f3d89ae238ae1708a4d77a97b709ed893800e49c7c4d70daa7b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247515660&idx=1&sn=085df9691cc6429ae6fd31f617b87dc2&chksm=ce46351cf931bc0a5e6a62d57f3d89ae238ae1708a4d77a97b709ed893800e49c7c4d70daa7b&scene=27#wechat_redirect)

![](../Images/0a0deb41af49deca995f3218e0cf0072.png)

  

**恶意家族名称：**

Win10UpdateMiner

**威胁类型：**

挖矿木马

**简单描述：**

Win10UpdateMiner 是一款挖矿木马，最早出现于 2022 年 5 月中旬，通过伪装成 Windows 应用程序进行传播，能够在受害主机上注入挖矿代码，占用受害主机资源，挖取比特币，谋取利益。

  

**恶意文件分析**

![](../Images/de0d65af97d196d06d3e55eab9651539.png)

**1.恶意文件描述**

近期，深盾终端实验室接到 XDR 团队基于行为分析捕获到一种未知挖矿木马病毒。经分析，该挖矿木马属于 Win10UpdateMiner 家族的一个新型变种。

  

Win10UpdateMiner 在今年 6 月被首次曝光，通过伪装成 Windows 升级程序诱导受害者点击，当用户点击之后，该病毒会在受害主机上植入挖矿程序，挖取数字货币以谋取利益。

  

本次发现的新版本从手法上并未有新的创意，使用第三方邮件服务托管挖矿组件，下载器伪装成 Windows 证书升级程序，诱导受害者点击，后续会下载挖矿组件，通过注入浏览器进行挖矿。

![](../Images/de0d65af97d196d06d3e55eab9651539.png)

**2.恶意文件分析**

程序本体主要由两个函数组成，主要功能是解密硬编码在程序内的 C Sharp 代码，并通过动态编译执行。  

  

![](../Images/db85cdc4dd09da5f352d9e71ef0cfd18.png)

  

代码的主要包括 4 个类，对应 4 个功能。第一段代码的功能是通过硬编码地址获取秘钥并下载加载器及挖矿程序相关组件。

  

![](../Images/f6a7123c0deaf3b4ecf46585fe1caebd.png)

  

第二个段代码的功能是从文件中读取数据，第三段代码的功能是将数据写入文件。

  

第四段代码是将下载回来的加载器程序加载到内存，并将其他组件的数据作为参数传入，最后执行。

  

![](../Images/5a7d282bb80c1210984153cd8d15798d.png)

  

这里在程序逻辑上有一个判断，如果下载失败，则从本地读取挖矿组件数据，若下载成功，则将下载的数据写入 “C:\\ProgramData\\SoftwareDistribution”。

  

文件名及对应组件的功能和之前版本完全一致。

  

![](../Images/0179bb0bf3c65bebb465a4ab9eae0cca.png)

  

成功读取到挖矿组件数据后，使用从远程获取的秘钥对数据进行解密。解密算法和解密代码段的算法相同。

  

![](../Images/fff3cd8d06e245fd8c5f27fd280720e0.png)

  

相比之前的版本，下载链接地址的解密算法从 RC4 加密算法变成了更简单的 Xor 加密算法。

  

![](../Images/258b9d270f8d81aecf44795ec7fb9ed5.png)

  

LC\_DLL 即加载器，通过 Confuser 混淆工具混淆。

  

![](../Images/d4169df8f1d10dad4b32bdc74d8d76f0.png)

  

通过 Laucher.Start 函数启动。

  

![](../Images/25a402a931a1ea1caf6eefed76b4976c.png)

  

判断主机是否安装 IE，欧朋，火狐，谷歌，Edge 浏览器。

  

![](../Images/c417153f14393384facddf1f1430dd91.png)![](../Images/5874ca9b2fb8990880f5fb596494d216.png)![](../Images/908a9acf7431cba45ac64fa3ac4da959.png)![](../Images/b4e41f09d0694ea2249da77c5b80e640.png)![](../Images/9f6ff75c55c8d2577002700ef776ec0f.png)

  

解压并释放配置文件为临时文件到 Temp 目录，这个解压过程在之前的版本是在主程序中完成的，这个版本移动到了加载器中。

  

![](../Images/7ab15b98142ee934a351f059ddb5d492.png)

  

解压并释放驱动文件，设置隐藏属性、系统属性，修改创建时间、最后访问时间。

  

![](../Images/5fc0f689e362aaad1d921f0fa5d15a97.png)

  

添加防火墙出站规则，放行所有地址和端口。

  

![](../Images/4be8eb7d5b95e0cf13b1608e0b139335.png)

  

启动之前找到的浏览器程序，将矿机程序注入进程内存，开始挖矿。

  

![](../Images/d8ce5d20c3b032244965a00132a1db42.png)

  

通过  -c 指令，将配置文件导入程序。

  

![](../Images/562518bccdc83764b3bade93ac2e22c8.png)

**解决方案**

![](../Images/de0d65af97d196d06d3e55eab9651539.png)

**终端加固建议**

1\. 避免将重要服务在外网开放，若一定要开放，需增加口令复杂度，避免使用弱口令。

2\. 避免打开可疑或来历不明的邮件，尤其是其中的链接和附件等，如一定要打开未知文件，请先使用杀毒软件进行扫描。

3\. 安装信誉良好的防病毒/反间谍软件，定期进行系统全盘扫描，并删除检测到的威胁，按时升级打补丁。

4\. 使用官方和经过验证的下载渠道，使用正版开发人员提供的工具/功能激活和更新产品，不建议使用非法激活工具和第三方下载器，因为它们通常用于分发恶意内容。

![](../Images/de0d65af97d196d06d3e55eab9651539.png)
