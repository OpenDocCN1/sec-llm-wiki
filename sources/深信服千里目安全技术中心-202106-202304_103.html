漏洞名称：

Nginx NJS

影响范围：

Nginx NJS < 0.7.4

漏洞类型：

UAF 漏洞（Use-After-Free）

1、用户认证：未知

2、前置条件：默认配置

3、触发方式：未知

<综合评定威胁等级>：高危，能造成拒绝服务。


漏洞分析

组件介绍

Nginx 是美国 NGINX 公司的一款轻量级 Web 服务器/反向代理服务器及电子邮件代理服务器 。Nginx NJS 是其中的一个支持扩展 Nginx 服务器功能的脚本语言组件。

漏洞简介

2022年10月31日，深信服安全团队监测到一则 Nginx 组件存在 UAF 漏洞的信息，漏洞编号：CVE-2022-43286，漏洞威胁等级：高危。

该漏洞是由于 Nginx NJS 组件存在堆 UAF 漏洞，攻击者可利用该漏洞构造恶意数据对 njs_json_parse_iterator_call 函数进行非法内存复制，最终造成程序拒绝服务。

漏洞影响范围

目前受影响的 Nginx NJS 版本：

Nginx NJS < 0.7.4
