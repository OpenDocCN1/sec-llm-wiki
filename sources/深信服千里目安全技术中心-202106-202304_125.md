# 畅捷通T+文件上传漏洞（官方已出补丁），警惕Tellyouthepass新变种趁虚而入！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247515011&idx=1&sn=2bf821085a1ce584f3db92928c11f4c8&chksm=ce463093f931b9853abc3101070ff7c7f0dd705b53797d02215d508b9fddc736e1095f8742af&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247515011&idx=1&sn=2bf821085a1ce584f3db92928c11f4c8&chksm=ce463093f931b9853abc3101070ff7c7f0dd705b53797d02215d508b9fddc736e1095f8742af&scene=27#wechat_redirect)

![](../Images/566e00147b917684b166567427bc9abe.png)

**事件背景**

8月29日下午6点左右，根据国内知名技术社区消息，疑似用友等管理软件厂商正遭受勒索病毒集中攻击，国内主机遭受到不定向勒索攻击，受害主机上的数据被加密，并被勒索0.2个比特币。

  

千里目安全技术中心监测到**该勒索攻击来自Tellyouthepass家族勒索病毒，并通过畅捷通 T+ 文件上传漏洞进行勒索病毒的传播。攻击完成后，受害主机上的文件被加密，后缀名被修改为.locked。**  

  

8月30日，畅捷通官方发布通告，少量畅捷通T+软件客户遭受勒索病毒攻击说明，并发布安全补丁。

**漏洞分析**

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**漏洞概要**

**漏洞名称：**

畅捷通T+文件上传漏洞

**组件名称：**

畅捷通T+

**影响范围：**

畅捷通T+ ≤ v17.0

**漏洞类型：**

文件上传

**利用条件：**  

1、用户认证：不需要用户认证

2、前置条件：默认配置

3、触发方式：远程  

**综合评价：**

<综合评定利用难度>：容易，无需授权即可上传文件。

<综合评定威胁等级>：高危，能上传恶意文件，并远程执行代码。

  

  

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**组件介绍**

畅捷通 T+ 是一款基于互联网的新型企业管理软件，功能模块包括：财务管理、采购管理、库存管理等。主要针对中小型工贸和商贸企业的财务业务一体化应用，融入了社交化、移动化、物联网、电子商务、互联网信息订阅等元素。

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**漏洞简介**

近日，深信服安全团队监测到一则畅捷通 T+ 存在未授权文件上传漏洞信息，漏洞编号：暂无，漏洞威胁等级：高危。

  

**攻击者利用此漏洞无需授权即可上传恶意文件，从而远程执行任意代码。**

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**漏洞影响范围**

目前受影响的畅捷通 T+ 版本：

畅捷通T+ ≤ v17.0

**恶意文件分析**

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**恶意文件概要**

**恶意文件名称：**

Tellyouthepass

**威胁类型：**

勒索病毒

**简单描述：**

Tellyouthepass 家族勒索病毒自2020年夏季以来一直处于活跃状态，攻击目标多为国内用户。该病毒经常利用漏洞渗透企业内部，加密受害者数据，勒索钱财以谋取利益。

  

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**恶意文件描述**

近期，深信服深盾终端实验室收到来自深信服安全应急响应中心的威胁情报，**国内大量主机正遭受不定向勒索攻击，受害主机上的数据被加密，并被勒索0.2个比特币。溯源后，发现该攻击来自 Tellyouthepass家族勒索病毒。**

![](../Images/ac4f134a01141f04a630ccc2d3af62d9.png)

**恶意文件分析**

经调查，本次攻击事件，攻击者通过文件上传漏洞上传恶意载荷，并获取 Webshell，最后通过 Webshell 执行加密数据的命令进行勒索。

  

Webshell 通过反射加载执行恶意代码，该技术手法和冰蝎马原理类似。

  

![](../Images/a7537f1ea5a2c1a2a41f7b194410781e.png)

  

攻击完成后，受害主机上的大量文件被加密，后缀名被修改为 .locked。

  

![](../Images/35e0d648ca5ac0ba5ac7575b8e6323b6.png)

  

终端日志显示，在攻击过程中，被利用进程会通过 cmd，执行 “vssadmin delete shandow /all” 命令删除卷影。】

加密完成后，会释放勒索信，通过特征判断，本次攻击与Tellyouthepass 家族勒索病毒存在一定关联。

  

![](../Images/337c9b418b2dc2b5e2ab9a1f353345ef.png)
