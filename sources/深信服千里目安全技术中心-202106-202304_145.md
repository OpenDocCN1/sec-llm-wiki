# 【漏洞通告】Apache Spark Shell命令注入漏洞 CVE-2022-33891

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514995&idx=1&sn=83feedc2fa5507b04d28c19c03c6671a&chksm=ce463063f931b975df280ff2164f68aec652378347d998c6d319420cb572084d569015a0f0b2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514995&idx=1&sn=83feedc2fa5507b04d28c19c03c6671a&chksm=ce463063f931b975df280ff2164f68aec652378347d998c6d319420cb572084d569015a0f0b2&scene=27#wechat_redirect)

![](../Images/5616bdd3ed054c4bf72f4708cfb88a34.png)

**漏洞名称：**

Apache Spark Shell 命令注入漏洞

**组件名称：**

Apache Spark

**影响范围：**

Apache Spark ≤ 3.0.3

3.1.1 ≤ Apache Spark ≤ 3.1.2

3.2.0 ≤ Apache Spark ≤3.2.1

**漏洞类型：**

命令注入

**利用条件：**

1、用户认证：不需要用户认证

2、前置条件：启用 ACL

3、触发方式：远程

**综合评价：**

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能造成系统命令执行。

  

  

**漏洞分析**

![](../Images/735e5dc95224d799173cd514fa7e9c5b.png)

**组件介绍**

Apache Spark 是一个开源集群运算框架，最初由加州大学柏克莱分校 AMPLab 开发。相对于 Hadoop 的 MapReduce 会在执行完工作后将中介资料存放到磁盘中，Spark 使用了存储器内运算技术，能在资料尚未写入硬盘时即在存储器内分析运算。

![](../Images/735e5dc95224d799173cd514fa7e9c5b.png)

**漏洞描述**

2022年7月19日，深信服安全团队监测到一则 Apache Spark 组件存在命令注入漏洞的信息，漏洞编号：CVE-2022-33891，漏洞威胁等级：高危。

  

该漏洞源于启用 ACL 时，HttpSecurityFilter 中的代码路径可允许攻击者冒充任意用户。**攻击者可利用该漏洞在未授权的情况下，根据用户输入创建一个 Shell 命令并执行，最终获取服务器最高权限。**

**影响范围**

目前受影响的 Apache Spark 版本：

Apache Spark ≤ 3.0.3

3.1.1 ≤ Apache Spark ≤ 3.1.2

3.2.0 ≤ Apache Spark ≤3.2.1

**解决方案**

![](../Images/735e5dc95224d799173cd514fa7e9c5b.png)

**1.如何检测组件版本**

**方案一**

全盘搜索 spark，如果存在 spark-{version}.jar，则用户可能受漏洞影响。

![](../Images/0805465300cc66ed61a6a87c136b8a31.png)

**方案二**  

如果项目是由 maven 编译的（一般在项目根目录下会有 pom.xml）

![](../Images/e281bf6f7b3abf2d4c34d3c7cd3821b9.png)

打开 pom.xml 文件，如图：  

![](../Images/3693196051e298f8269743510c33bf68.png)

  

在此文件中搜索 spark-core，如果可以搜索到关键字，并且标签内部的字段分别在 Apache Spark ≤ 3.0.3、3.1.1 ≤ Apache Spark ≤ 3.1.2、3.2.0 ≤ Apache Spark ≤3.2.1 之间的版本，则可能受到漏洞的影响。（图中的 spark-core 的版本是 3.2.1，在漏洞影响范围内）

![](../Images/65d3481ba009f3778b90240de3cdb25c.png)![](../Images/735e5dc95224d799173cd514fa7e9c5b.png)

**2.官方修复建议**

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://lists.apache.org/thread/p847l3kopoo5bjtmxrcwk21xp6tjxqlc

![](../Images/735e5dc95224d799173cd514fa7e9c5b.png)
