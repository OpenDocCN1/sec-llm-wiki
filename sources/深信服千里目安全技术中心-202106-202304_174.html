2022年6月15日（北京时间），微软发布了安全更新，共发布了 55 个CVE 的补丁程序，同比上月减少了 20 个。


在漏洞安全等级方面，存在2个标记等级为 “Critical” 的漏洞，51 个漏洞被标记为 “Important”；在漏洞类型方面，主要有 28 个远程代码执行漏洞，12 个权限提升漏洞以及 12 个信息泄露漏洞。

  • 总体上来看，微软本月发布的补丁数量为55个，有2个 critical 漏洞补丁。

  • 千里目安全技术中心在综合考虑往年微软公布漏洞数量的数据统计和今年的特殊情况，初步估计微软在今年七月份公布的漏洞数将比六月略多。漏洞数量将会维持在70个左右。

  • 从漏洞数量来看，今年相较去年略有增加。微软在2022年6月份爆发的漏洞相较于去年有少量的增加。本月出现了55个漏洞补丁，并且有2个 critical 类型的漏洞补丁。


  • 从漏洞的危险等级来看，相较去年“Important”等级漏洞数量有所增加，“Critical” 等级漏洞略有减少，但是近两年相对历史数据而言总体漏洞数量均有降低。从漏洞趋势上看，针对 Windows 系统本身的严重型和高危型漏洞数量降低，针对Windows产品侧的漏洞数量占据大多数。这种趋势，标志着微软系统本身正向着更加安全走去，也符合MSRC成立的期望。


  • 从漏洞类型来看，spoof 类型的漏洞有大幅度的降低，RCE、Info 类型的漏洞有所增加，仍然需要引起高度重视，尤其是 RCE 漏洞在配合社工手段的前提下，甚至可以直接接管整个局域网并进行进一步扩展攻击。

重要漏洞分析

漏洞分析

Windows Installer 本地提权漏洞 CVE-2022-30147

Windows Installer 是 Microsoft Windows 的安装服务，它可以支持安装程序所需的所有功能，包括安装、维护、删除应用软件包。


Windows Installer 中存在本地提权的漏洞，当攻击者安装恶意的应用软件包时，将会触发一个逻辑漏洞。攻击者可以利用该漏洞最终获取计算机的最高权限。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。


Windows ALPC 本地提权漏洞 CVE-2022-30160

Advanced local procedure call，即高级本地过程调用，是一种用于高速、异步的进程间通信机制，历史可以追溯到Windows Vista。其从 Windows 7 开始广泛使用，例如  RPC 会使用 ALPC 来获得更高性能。


Windows ALPC  组件中存在本地提权的漏洞，攻击者可利用该漏洞在获得权限的情况下，构造恶意程序进行权限提升攻击，最终可获取服务器最高权限。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。
