# 【漏洞通告】Windows Installer本地提权漏洞CVE-2022-30147

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514975&idx=2&sn=46a22132da953c69aab0c1c0ccee28f9&chksm=ce46304ff931b959b3f0407b0de5681fe16d47e825af5c87eb0e1d55cff570e9abf9f2a1a5fb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514975&idx=2&sn=46a22132da953c69aab0c1c0ccee28f9&chksm=ce46304ff931b959b3f0407b0de5681fe16d47e825af5c87eb0e1d55cff570e9abf9f2a1a5fb&scene=27#wechat_redirect)

![](../Images/45c61334804473ce03a629361846a337.png)

**漏洞名称：**

Windows Installer 本地提权漏洞

**组件名称：**

msi.dll

**影响范围：**

Windows 7

Windows 8.1

Windows 10 Version 1607, 1809,1909, 2004, 20H2

Windows Server version 2008，2012，2016，2019，2004, 20H2

（详细影响版本见第三章节）

**漏洞类型：**

本地权限提升

**利用条件：**

1、用户认证：需要用户认证

2、前置条件：无  
3、触发方式：本地运行命令行程序，触发漏洞

**综合评价：**

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能造成本地权限提升。

  

  

**漏洞分析**

![](../Images/5162c4fd8728f21af8e9d2876ddd912e.png)

**组件介绍**

Windows Installer 是 Microsoft Windows 的安装服务，它可以支持安装程序所需的所有功能，包括安装、维护、删除应用软件包。

![](../Images/5162c4fd8728f21af8e9d2876ddd912e.png)

**漏洞描述**

2022年06月15日，深信服安全团队监测到一则 msi.dll组件存在本地权限提升漏洞的信息，漏洞编号：CVE-2022-30147，漏洞威胁等级：高危。

  

该漏洞是由于逻辑错误，**攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行本地权限提升攻击，最终获取服务器最高权限。**

**解决方案**

![](../Images/5162c4fd8728f21af8e9d2876ddd912e.png)

**1.如何检测组件系统版本**

使用 cmd.exe 执行 “systeminfo” 命令，可以获取 Windows 操作系统安装的补丁。

  

![](../Images/a7ece526106737ad256deafc7ef4d0cf.png)

  

查看是否存在以下网址安全更新程序一栏中对应的补丁包。

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-30147

  

![](../Images/226c4c37d746462d708a4a24b439cc8c.png)

![](../Images/5162c4fd8728f21af8e9d2876ddd912e.png)

**2.官方修复建议**

当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。链接如下：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-30147

  

**打补丁方法:**

进入上面的链接页面，下载当前系统版本对应的补丁包进行安装。
