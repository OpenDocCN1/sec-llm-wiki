漏洞分析

组件介绍

Apache HTTP Server（简称Apache），是 Apache 软件基金会的一个开放源代码的网页服务器，可以在大多数电脑操作系统中运行。其由于具有的跨平台性和安全性被广泛使用，是流行的Web服务器端软件之一。

漏洞简介

近日，深信服安全团队监测到一则Apache HTTP Server官方发布安全补丁的通告，共修复了8个安全漏洞，其中包含1个中危漏洞、7个低危漏洞的信息。
