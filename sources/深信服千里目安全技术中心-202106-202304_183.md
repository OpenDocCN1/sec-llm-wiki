# 伪装Win10升级程序，Win10UpdateMiner正在悄然传播

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514970&idx=2&sn=816f82ab0ca1f6aac2d09099deb7cad0&chksm=ce46304af931b95c215b7be52edbfb6458bab36a8115e7c904f74ebe8b35b253a1063444a7bb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514970&idx=2&sn=816f82ab0ca1f6aac2d09099deb7cad0&chksm=ce46304af931b95c215b7be52edbfb6458bab36a8115e7c904f74ebe8b35b253a1063444a7bb&scene=27#wechat_redirect)

![](../Images/a51eb00fac249834f3a169fe585fbf49.png)

  

**恶意通告名称：**Win10UpdateMiner（该病毒暂未有官方命名，暂由深信服根据特征命名）

**威胁类型：**挖矿木马

**简单描述：**Win10UpdateMiner 是一款挖矿木马，最早出现于2022年5月中旬，通过伪装 Windows升级程序进行传播，能够在受害主机上注入挖矿代码，占用受害者资源，挖取比特币，谋取利益。

  

  

**恶意文件分析**

![](../Images/64d75cab11e833312686bc7bdba5e6c0.png)

**1.恶意文件描述**

近期，深信服终端安全团队在运营工作中发现，一款未知挖矿木马正在国内范围传播。

  

该挖矿木马通过伪装成 Window10 升级程序的下载器进行传播，下载程序运行后，会从远程服务器下载加载组件、另外一个功能相似的下载器，及相关的配置文件。通过无文件执行，释放加载器程序到隐藏目录，添加隐藏属性并添加到计划任务。

第二阶段下载器下载加载组件和挖矿相关组件后，通过无文件执行，最后将挖矿代码注入其他进程，运行挖矿程序，占用受害者资源，挖取比特币，谋取利益。

  

深信服终端安全团队将其命名为 Win10UpdateMiner。

![](../Images/64d75cab11e833312686bc7bdba5e6c0.png)

**2.恶意文件分析**

1\. 伪装作 Windows 升级程序的下载器在网络路径的域的 NETLOGON 目录下被发现，发现时已经被添加为计划任务。

 

![](../Images/dd03dd1eb9209931111eb2cb95dca6a3.png)

  

2\. 为了对抗分析和检测，该下载程序经过 Confuser 混淆，通过常规的手段很难将其具体恶意行为复原。

 

![](../Images/5ea64c253e1b0927cc3a45daa26645b6.png)

  

3\. 结合之前捕获的历史版本来看，该程序的功能比较简单，就是从预先硬编码的网络地址获取密钥并下载名为 DC\_DLL、TASK 和一个以传入参数为名（此处为 023）的三个文件。

  

使用密钥对三个文件解密后，通过 Assembly.Load 加载 DC\_DLL，调用 Laucher 下的 Start 函数，并将剩下的文件作为参数传入。

  

![](../Images/99150ddd704022ef0bb4d62da81e2943.png)

  

4\. DC\_DLL 是一个可执行程序加载器，执行后，除了执行传入的可执行程序外，还会将其释放到指定目录，并根据传入的 XML 格式数据，将可执行程序添加到计划任务。

 

![](../Images/5f748a28528340e72120c3417bd014b2.png)

  

  

5\. 023 是进行下一阶段攻击要使用的下载器程序，TASK 就是用于添加计划任务的 XML 文件。

 

![](../Images/a09ca7ae2a47a0b2485fb25b153293d8.png)

  

  

6\. 第二阶段下载器程序会被释放到 C:\\Program Files\\Common Files\\microsoft shared\\MSMultimedia\\  隐藏目录下，并赋予隐藏文件属性。

 

 

![](../Images/5f748a28528340e72120c3417bd014b2.png)

  

7\. 第二阶段下载器程序名为 MultimediaAgentMS.exe，其功能和前一阶段下载器相似，只是不再需要外部传参，所有需要的组件名称都是通过硬编码编写的，在下载完成后，同样通过Assembly.Load 进行加载运行。

  

LC\_DLL 是另外一个加载器，CONFIG 是 XMRig 矿机运行所需要的可执行程序，DATA1 和 DATA2 是数字货币矿机和所需要的驱动程序。

  

![](../Images/4da421e821a9c9895278385ec4a32c62.png)

  

8\. LC\_DLL 运行后，会将配置文件释放到临时目录，然后破坏 AMSI 功能，随后创建新的 svchost.exe 进程，并将挖矿代码注入，开始挖矿任务。

  

![](../Images/9b137251f4812b963d28c2b23e16c7f8.png)

  

9\. 完成后，删除相关文件。

  

![](../Images/2c96ca71059527f17d51ee1523ca309b.png)

  

  

**解决方案**

![](../Images/64d75cab11e833312686bc7bdba5e6c0.png)

**1.处置建议**

1\. 避免将重要服务在外网开放，若一定要开放，需增加口令复杂度，避免使用弱口令。

2\. 避免到信誉不明的网站下载应用程序。

3\. 避免打开来历不明的邮件、链接和附件等，如一定要打开未知文件，请先使用杀毒软件进行扫描；

4\. 定期使用杀毒软件进行全盘扫描。

![](../Images/64d75cab11e833312686bc7bdba5e6c0.png)

**2.深信服解决方案**

**【深信服终端安全管理系统EDR】**已支持查杀拦截此次事件使用的病毒文件，请更新软件（如有定制请先咨询售后再更新版本）和病毒库至最新版本，及时查杀新威胁；  
**【深信服下一代防火墙AF】**的安全防护规则更新至最新版本，接入深信服云平台，“云鉴” 服务即可轻松抵御此高危风险。  
**【深信服安全感知管理平台SIP】**建议用户及时更新规则库，接入云图，并联动【深信服下一代防火墙AF】实现对高危风险的入侵防护。  
**【深信服安全托管服务MSS】**以保障用户网络安全“持续有效”为目标，通过将用户安全设备接入安全运营中心，依托于XDR安全能力平台和MSSP安全服务平台实现有效协同的“人机共智”模式，围绕资产、脆弱性、威胁、事件四个要素为用户提供7\*24H的安全运营服务，快速扩展持续有效的安全运营能力，保障可承诺的风险管控效果。
