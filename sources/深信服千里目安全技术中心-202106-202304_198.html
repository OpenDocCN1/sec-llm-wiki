漏洞名称：

Zyxel 远程命令执行漏洞

组件名称：

Zyxel

影响范围：

5.00 ≤ Zyxel ≤ 5.21

漏洞类型：

命令执行

利用条件：

1、用户认证：不需要用户认证
2、前置条件：无

3、触发方式：远程

综合评价：

<综合评定利用难度>：容易，无需认证即可进行攻击。

<综合评定威胁等级>：严重，能造成远程代码执行。


漏洞分析


1 组件介绍

Zyxel USG FLEX 是中国 Zyxel 公司的一款防火墙，可以提供灵活的 VPN 选项，为远程工作和管理提供灵活的安全远程访问。


2 漏洞描述

近日，深信服安全团队监测到一则 Zyxel USG FLEX 组件存在越界访问漏洞的信息，漏洞编号：CVE-2022-30525，漏洞威胁等级：严重。


该漏洞是由于特定路径处理 json 格式的传入数据时存在错误，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行系统命令注入攻击，最终执行任意代码。


影响范围


Zyxel USG FLEX 是一款企业级防火墙产品，通常用于企业网络的出口部分。可能受漏洞影响的资产广泛分布于世界各地，在国内主要应用于浙江、北京、上海等地区。此漏洞危险性高，但是用户数量较广泛，漏洞影响力较大。


目前受影响的 Zyxel USG FLEX 版本：

5.00 ≤ Zyxel ≤ 5.21


解决方案


1 官方修复建议

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://www.zyxel.com/support/Zyxel-security-advisory-for-OS-command-injection-vulnerability-of-firewalls.shtml
