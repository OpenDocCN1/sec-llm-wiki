# 【漏洞通告】Apache APISIX JWT-Auth Plugin 密钥泄露漏洞 CVE-2022-29266

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514950&idx=1&sn=15e3f5580e33ff92d44cea087a39fcac&chksm=ce463056f931b94076b33d5b70d329c2dc02c49f26931629524274ab14a31fe79a3ac8bf1693&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514950&idx=1&sn=15e3f5580e33ff92d44cea087a39fcac&chksm=ce463056f931b94076b33d5b70d329c2dc02c49f26931629524274ab14a31fe79a3ac8bf1693&scene=27#wechat_redirect)

**漏洞名称**：

Apache APISIX JWT-Auth Plugin密钥泄露漏洞

**组件名称**：

Apache APISIX

**影响范围**：  

Apache APISIX < 2.13.1

**漏洞类型**：

信息泄露

**利用条件**：  

1、用户认证：不需要用户认证

2、前置条件：开启 jwt-auth plugin

3、触发方式：远程

**综合评价**：

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能获取用户密钥信息。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Apache APISIX 是 Apache 基金会推出的一款 API 网关管理工具，具有实时、高效的特点，借助它可以非常方便的对 API 进行验证和鉴权并进行监控。

  

**2 漏洞描述**

近日，深信服安全团队监测到一则 Apache APISIX 的 JWT-Auth Plugin 存在密钥泄露漏洞的信息，漏洞编号：CVE-2022-29266，漏洞威胁等级：高危。

  

该漏洞是由于 JWT-Auth Plugin 在接受到一个恶意构造的请求后会返回用户的密钥信息连同错误信息一起返回，**攻击者可利用该漏洞获取用户的密钥信息。**

  

    

**影响范围**

    

  

目前受影响的 Apache APISIX 版本：

Apache APISIX < 2.13.1
