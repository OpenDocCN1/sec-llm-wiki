接下来让我们一起来回顾一下现场议题！

 

议题一 《从0开始编写 Chrome V8 利用脚本》

V8 引擎是 Chrome 使用的 JavaScript 语言的解释器。来自知道创宇404实验室的 HCamael 师傅从 StarCTF 2019 OOB 这道 CTF 题目入手，分享了如何从0开始研究 V8 引擎，让我们学习到了 V8 安全研究的步骤和入手点，掌握了 V8 安全研究的技巧。



议题二 《深入分析 Magnitude exploit kit》

MagnitudeEK 是一个针对基于 Chromium 浏览器的漏洞利用链，其主要利用了两个漏洞：CVE-2021-21224 和 CVE-2021-31956。CVE-2021-21224 是 V8 引擎中的类型混淆漏洞；而 CVE-2021-31956 是 Windows ntfs 驱动中的分页池溢出漏洞。来自深信服千里目安全实验室的 DaJun 和 N0tai1 两位师傅重点介绍了两个漏洞的根本成因以及如何组合这两个漏洞形成完整的攻击链。


 

议题三 《深入解析 WebKit JSC 引擎与漏洞原理》

在浏览器漏洞研究中，JS 引擎已成为最大的一个攻击面，无论是使用模糊测试还是代码审计进行漏洞挖掘，都需要对其代码库与内部设计有足够的了解。来自知道创宇404实验室的 ghost461 师傅结合 WebKit 源码讲解了 JavaScriptCore 引擎的内部设计与对象构造，并针对 js 引擎的特点总结分享了相关漏洞类型。

 


议题四 《Linux Rootkit 事件调查响应之道》

来自深信服千里目安全实验室的马师傅主要介绍 Rootkit 在攻防场景的应用、 Linux 内核态 Rootkit 常见的一些隐藏技术以及如何展开 Linux Rootkit 事件调查响应。通过他的思考和分享，让我们认识到了法证之父的交换定律在数字调查取证领域中同样适用，高隐藏高持久化的 Rootkit 也必须符合系统数据结构，也会留下微量痕迹。
