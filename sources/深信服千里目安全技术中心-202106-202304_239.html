【漏洞通告】Spring Framework 拒绝服务漏洞CVE-2022-22950

漏洞名称：

Spring Framework 拒绝服务漏洞

组件名称：

Spring Framework

影响范围：

5.3.0< = Spring Framework < =5.3.16

5.2.0< = Spring Framework < =5.2.19

Spring Framework <  5.2.0

漏洞类型：拒绝服务

利用条件：

1、用户认证：不需要用户认证
2、前置条件：配置 SPEL 输入执行功能

3、触发方式：远程

综合评价：

<综合评定利用难度>：中等，无需授权即可造成拒绝服务。

<综合评定威胁等级>：中危，能造成拒绝服务。


漏洞分析


1 组件介绍

Spring 是美国威睿（Vmware）公司的一套开源的 Java、JavaEE 应用程序框架。


2 漏洞描述

近日，深信服安全团队监测到一则 Spring Framework 组件存在拒绝服务漏洞的信息，漏洞编号：CVE-2022-22950，漏洞威胁等级：中危。


该漏洞是由于 Spring Framework 对 SPEL 表达式处理不当，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行拒绝服务攻击，最终造成服务器拒绝服务。


影响范围


Spring Framework 作为主流的 Java 开发框架，全球有数百万使用 Spring Framework框架的资产，可能受漏洞影响的资产广泛分布于世界各地，国内主要分布在广东、北京、上海等省市。


目前受影响的 Spring Framework 版本：

5.3.0< = Spring Framework < =5.3.16

5.2.0< = Spring Framework < =5.2.19

注：其他 Spring Framework 旧版本同样会受到影响。

解决方案


1 如何检测组件版本

Windows 系统：

全盘搜索 spring-core，如果存在 spring-core-{version}.jar，则用户可能受漏洞影响。



Linux 系统：

使用 find / -name ‘spring-core*’  命令搜索，如果存在 spring-core-{version}.jar ，则用户可能受漏洞影响。



2 官方修复建议

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://github.com/spring-projects/spring-framework/tags
