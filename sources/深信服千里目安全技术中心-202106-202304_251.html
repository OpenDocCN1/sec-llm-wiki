漏洞分析


1 组件介绍

Veeam Backup&Replication 是一款简单、灵活、可靠、强大的数据保护解决方案，可有效保护云端数据、虚拟及物理工作负载，实现数据保护现代化并避免停机事件的发生。


Veeam Agent for Windows 专为 Microsoft Windows 平台提供保护、迁移和虚拟转换功能，并支持所有的 Veeam 原生保护和恢复功能。同时可以与其它Veeam产品进行联动。


2 漏洞描述

近日，深信服安全团队监测到 Veeam 官方发布安全更新的通告信息，共修复了2个安全漏洞，皆为高危漏洞。



Veeam Backup & Replication远程代码执行漏洞（CVE-2022-26500/CVE-2022-26501）

该漏洞是由于 Veeam 分发服务（默认端口为 TCP 9380）允许未经身份验证的用户访问内部 API 函数。远程攻击者可通过该方式向内部 API 发送恶意输入，并最终导致恶意代码的上传和执行。


Veeam Agent for Windows远程代码执行漏洞（CVE-2022-26503）

该漏洞是由于Veeam Agent for Microsoft Windows （默认端口为 TCP 9395）中存在.NET反序列化漏洞。远程攻击者成功利用该漏洞后可远程代码执行漏洞。

影响范围



Veeam 是备份、恢复及数据管理解决方案领域的领军者，借助简单、灵活、可靠、强大平台成为值得信赖的数据保护提供商，为云端、虚拟、物理、SaaS 和 Kubernetes 环境提供统一平台，在欧洲、中东和非洲地区及全球市场份额占比排行第二。

上述漏洞影响版本较多，影响范围广，受影响用户主要分布在欧美地区。


解决方案


1 官方修复建议

当前官方已发布最新版本，建议受影响的用户根据自身安装的主版本及时更新升级到最新版本。链接如下：
