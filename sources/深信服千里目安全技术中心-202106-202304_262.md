# 【漏洞通告】Apache ShardingSphere  ElasticJob-UI权限提升漏洞CVE-2022-22733

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514907&idx=1&sn=c2f4068ae776f4a8942b8da7d39ec681&chksm=ce46300bf931b91d567fa56c54c77a24f9e3767708b6fe3b528ae07f0890fb92e295720739b5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514907&idx=1&sn=c2f4068ae776f4a8942b8da7d39ec681&chksm=ce46300bf931b91d567fa56c54c77a24f9e3767708b6fe3b528ae07f0890fb92e295720739b5&scene=27#wechat_redirect)

**漏洞名称**：

Apache ShardingSphere ElasticJob-UI 权限提升漏洞

**组件名称**：

Apache ShardingSphere ElasticJob-UI

**影响范围**：

Apache ShardingSphere ElasticJob-UI <=3.0.0

**漏洞类型**：

权限提升

**利用条件**：

1、用户认证：需要用户认证  
2、前置条件：默认配置

3、触发方式：远程

**综合评价**：

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，可通过权限提升登录后台管理端，进而可能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Apache ShardingSphere ElasticJob 是面向互联网生态和海量任务的分布式调度解决方案，由两个相互独立的子项目 ElasticJob-Lite 和 ElasticJob-Cloud 组成。ElasticJob-UI 是 ElasticJob 的管理控制台，包含了动态配置、作业管控等功能。

  

**2 漏洞描述**

2022年1月24日，深信服安全团队监测到一则 Apache ShardingSphere ElasticJob-UI组件存在权限提升漏洞的信息，漏洞编号：CVE-2022-22733，漏洞威胁等级：高危。

  

该漏洞是由于返回 token 中包含了管理员密码，**攻击者可利用该漏洞在授权的情况下，构造恶意数据执行权限绕过攻击，最终获取服务器最高权限。**

  

    

**影响范围**

    

  

ShardingSphere‐UI 由于其简单和易用性被广泛使用，可能受漏洞影响的资产广泛分布于世界各地，今年曝出的漏洞可以直接获取服务器最高权限，涉及用户量多，导致漏洞影响力很大。

  

目前受影响的 Apache ShardingSphere ElasticJob-UI 版本

Apache ShardingSphere ElasticJob-UI <= 3.0.0
