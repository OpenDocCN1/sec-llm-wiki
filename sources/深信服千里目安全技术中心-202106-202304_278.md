# 【安全公告】微软补丁日安全通告|1月份

**漏洞概要**

  

  

2022年1月12日（北京时间），微软发布了安全更新，共发布了 122 个CVE的补丁程序，同比上月增加了 39个，涵盖了针对 Windows 的 98 个补丁以及 Chromium 的24个补丁。

在漏洞安全等级方面，有10个漏洞被微软官方标记为“Critical”，89个漏洞被标记为“Important”； 在漏洞类型方面，主要有30个远程代码执行漏洞，41个权限提升漏洞以及6个信息泄露漏洞。

  

**漏洞数据分析**

**1  ****历史微软补丁日1月漏洞对比**

*   总体上来看，微软本月发布的补丁数量为122个。
    
*   千里目安全实验室在综合考虑往年微软公布漏洞数量的数据统计和今年的特殊情况，初步估计微软在今年2月份公布的漏洞数将有大幅度提升。漏洞数量也会维持在90个左右。

*   ****从漏洞类型来看，RCE 类型的漏洞有降低，EOP 类型的漏洞有较大幅度的提高。****权限提升漏洞(EOP)数量提高，需要引起高度重视，尤其是在配合社工手段的前提下，甚至可以直接接管整个局域网并进行进一步扩展攻击。远程代码执行漏洞(RCE)有虽然数量略有降低，但其危害性仍然很大。远程代码执行漏洞有利于攻击者更容易的获取受害者机器的执行权限，对于普通用户以及企业来说，远程代码执行类型的漏洞是危害比较大的。
    

  

**1月重要漏洞分析**

  

**1 漏洞分析**

**Windows Installer权限提升漏洞****：****CVE-2022-21908**

Windows Installer 是 Windows 上的安装程序服务，它可以支持安装程序所需要的许多功能。

Windows Installer 中存在一个本地提权的漏洞，当攻击者以一定的逻辑步骤来安装组件时，将会触发一个逻辑错误。****攻击者可以利用该漏洞最终获取计算机的最高权限。****该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。

 

**Windows Win32k 权限提升漏洞****：****CVE-2022-21882****、****CVE-2022-21887**

Windows win32k 是 Windows 的子系统，负责图形界面的创建和管理。

**CVE-2022-21882：**win32k 在处理用户请求时存在内存越界读写漏洞, ****攻击者可以利用此漏洞进行本地提权, 获得系统管理员权限, ****漏洞危害性大, 我们建议用户及时更新安全补丁。

**CVE-2022-21887：**win32k 在处理用户请求时出现了内存释放后使用漏洞, ****攻击者可以利用此漏洞进行本地提权, 获得系统管理员权限,**** 漏洞危害性大, 我们建议用户及时更新安全补丁。

 

**Windows Kernel 权限提升漏洞****：****CVE-2022-21881**

Windows Kernel 是 Windows 系统的内核。

Windows 内核在处理用户态请求时, 存在条件竞争漏洞, ****攻击者可以利用此漏洞进行本地提权, 获得系统管理员权限,**** 漏洞危害性大, 我们建议用户及时更新安全补丁。
