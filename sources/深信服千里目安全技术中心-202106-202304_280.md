# 1月深信服蓝军安全研究团队向微软提交并协助修复5个漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514896&idx=5&sn=f57da73eed11b400f487ca03dc69b9c8&chksm=ce463000f931b916db8962a7487bc9101d3894d38369fceda80936826a44f44a6ca440c640bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514896&idx=5&sn=f57da73eed11b400f487ca03dc69b9c8&chksm=ce463000f931b916db8962a7487bc9101d3894d38369fceda80936826a44f44a6ca440c640bd&scene=27#wechat_redirect)

  

近日，深信服安全蓝军安全研究团队向微软提交并协助修复了5个漏洞，其中CVE-2022-21878，CVE-2022-21888，CVE-2022-21837可能导致远程代码执行。CVE-2022-21835，CVE-2022-21881可能导致本地权限提升。  

  

北京时间2022年1月12日，微软已经针上述漏洞发布了安全更新，并公开致谢深信服安全研究员。

**漏洞概述**

 

  

*   CVE-2022-21835
    
    Windows密码学服务在解析用户的输入时存在一个内存破坏的漏洞，若攻击者成功利用该漏洞，则可以实现本地权限提升，最终完全接管受害主机。
    
*   CVE-2022-21878
    
    Windows Geolocation Service解析用户请求的时候存在远程代码执行漏洞，导致攻击者可以通过诱导受害者触发该漏洞，从而在受害主机上执行恶意代码。
    
*   CVE-2022-21888
    
    Windows Modern Execution Server解析用户请求的时候存在远程代码执行漏洞，导致攻击者可以通过诱导受害者触发该漏洞，从而在受害主机上执行恶意代码。
    
*    CVE-2022-21837
    
    有权访问域的经过身份验证的攻击者可以在 Sharepoint 服务器上远程执行任意代码，将自己提升为 Sharepoint 管理员，从而接管Sharepoint服务器。
    
*    CVE-2022-21881
    
    Windows 内核在处理用户态请求时, 存在条件竞争漏洞, 攻击者可以利用此漏洞进行本地提权, 获得系统管理员权限。
