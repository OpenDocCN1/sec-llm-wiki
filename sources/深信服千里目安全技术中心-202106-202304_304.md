***1.** 背景概述***

Apache Log4j2漏洞由于利用方式简单、影响范围广、造成危害大。自曝光以来，短期内已有多个多黑产从业者利用该漏洞进行恶意勒索、挖矿，组件僵尸网络等非法牟利行为。

  

**漏洞影响范围：**

Apache Log4j2.x <= 2.15.0-rc1

  

虽然官方已出具相关的修复方法和补丁，但由于该组件更新升级需要重启并且可能存在更新组件后与原有业务造成冲突等原因，大批量客户都通过更新WAF策略进行该漏洞利用的初步防护，但是由于漏洞利用payload变形较多,WAF存在绕过风险。

***如何帮助客户检测是否已经被攻击？***

***如何帮助客户在不用重启、不需要更新组件的情况下，快速有效“免疫”漏洞利用攻击？***

***深信服针对该漏洞推出******内存检测工具******，及时发现威胁，以及无须重启的******漏洞免疫“热补丁”******，一键安装轻松免疫该漏洞！***

***2.****** 入侵取证***

内存检测工具通过扫描进程内存，匹配特征字符串来判断业务是否曾经受到log4j2漏洞利用，并将字符串去混淆后打印出来，可用于取证、反制。
