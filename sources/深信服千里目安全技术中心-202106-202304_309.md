# 【漏洞通告】Chrome V8 UAF漏洞 CVE-2021-4102

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514877&idx=3&sn=bcdfd666dc84f68814d3c06913f09e16&chksm=ce4631edf931b8fb5f3d9e2710cf76cab2f11bb9bb6dc0af70c00da8be8fa9de3eba6e78ccee&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514877&idx=3&sn=bcdfd666dc84f68814d3c06913f09e16&chksm=ce4631edf931b8fb5f3d9e2710cf76cab2f11bb9bb6dc0af70c00da8be8fa9de3eba6e78ccee&scene=27#wechat_redirect)

**漏洞名称** : Chrome V8 UAF漏洞

**组件名称** : Chrome

**影响范围**：Google Chrome <  96.0.4664.110

**漏洞类型**：远程代码执行

**利用条件**：

1、用户认证：否  
2、前置条件：需要用户访问网页且关闭沙箱  
3、触发方式：远程

**综合评价**：

<综合评定利用难度>：一般，用户访问恶意网页且关闭沙箱可以造成远程代码执行。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Google Chrome 是由 Google 开发的一款设计简单、高效的 Web 浏览工具。Google Chrome 的特点是简洁、快速。Google Chrome 支持多标签浏览，默认情况下，每个标签页面都在独立的“沙箱”内运行，在提高安全性的同时，一个标签页面的崩溃也不会导致其他标签页面被关闭。此外，Google Chrome 基于更强大的 JavaScript V8 引擎，提升浏览器的处理速度。

  

**2 漏洞描述**

2021年12月13日，深信服安全团队监测到一则 Chrome 组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2021-4102，漏洞威胁等级：高危。

  

Chrome V8 中存在UAF漏洞，**攻击****者可利用该漏洞在未授权的情况下，构造恶意数据造成远程代码执行攻击，最终获取服务器最高权限。**

  

    

**影响范围**

    

  

Chrome 可以运行在几乎所有计算机平台上，由于其跨平台和安全性被广泛使用，成为较流行的浏览器软件。Chrome 在中国浏览器市场占有率较高，拥有广泛的用户基础。

  

目前受影响的 Chrome 版本：

Chrome < 96.0.4664.110

  

    

**解决方案**

    

  

**1 ****如何检测组件系统版本**

在 Chrome 中选择设置，在设置界面点击关于 Chrome 即可看到当前版本。
