漏洞概要


2021年12月15日（北京时间），微软发布了安全更新，共发布了83个 CVE 的补丁程序，同比上月增加了28个，涵盖了针对 Windows 的67个补丁以及 Chromium 的16个补丁。
在漏洞安全等级方面，有7个漏洞被微软官方标记为 “Critical” ，60个漏洞被标记为 “Important” ； 在漏洞类型方面，主要有41个远程代码执行漏洞，21个权限提升漏洞以及10个信息泄露漏洞。

  • 千里目安全实验室在综合考虑往年微软公布漏洞数量的数据统计和今年的特殊情况，初步估计微软在明年1月份公布的漏洞数将有大幅度提升。漏洞数量也会维持在90个左右。

  • 从漏洞数量来看，今年出现了小幅度的提升。微软在2021年12月份爆发的漏洞相较于去年有大幅度的提升。今年11月份漏洞修复数量相较于去年11月份大幅降低，导致上月需要修复的漏洞被移动到本月。

  • 从漏洞的危险等级来看，“Important”等级漏洞数量小幅提高，“Critical”等级漏洞数量小幅降低。从漏洞趋势上看，针对Windows系统本身的严重型和高危型漏洞数量大幅降低，针对Windows产品侧的漏洞数量占据大多数。这种趋势，标志着微软系统本身正向着更加安全走去，也符合MSRC成立的期望。

  • 从漏洞类型来看，RCE 类型的漏洞有大幅提高，EOP 类型的漏洞有大幅度的提高。权限提升漏洞(EOP)数量提高，需要引起高度重视，尤其是在配合社工手段的前提下，甚至可以直接接管整个局域网并进行进一步扩展攻击。远程代码执行漏洞(RCE)有大幅度数量的提高，危害性很大。远程代码执行漏洞有利于攻击者更容易的获取受害者机器的执行权限，对于普通用户以及企业来说，远程代码执行类型的漏洞是危害比较大的。



12月重要漏洞分析


1 漏洞分析

Windows Remote Desktop Client：CVE-2021-43233

Windows Remote Desktop Client是微软官方对于RDP远程桌面的实现，默认安装在Windows操作系统中，可以使用户对远程计算机进行对物理计算机能进行的操作。


Windows Remote Desktop Client中存在远程代码执行漏洞，在执行流运行到漏洞处的时候缺少必要的检查，导致内存空间被错误操作，攻击者可以利用该漏洞最终达到远程代码执行。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。


Windows Common Log File System: CVE-2021-43226
Windows Common Log File System是一个通用目的的日志文件系统，它可以从内核模式或用户模式的应用程序访问，用以构建一个高性能的事务日志。它自Windows Server 2003 R2引入，并包含在之后版本的Windows操作系统中。CLFS可以用于数据日志与事件日志。CLFS已被TxF和TxR用于在提交事务前存储事务状态的变更。


Windows Common Log File System 中存在一个本地提权的漏洞，在程序执行流运行到漏洞代码处时缺少对数据必要的检查，导致内存空间被破坏。攻击者可以利用该漏洞最终获取计算机的最高权限。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。


Windows Print Spooler Service: CVE-2021-41333

Windows Print Spooler Service是Windows上默认启用的打印机服务，它通常用来管理Windows系统上的打印机，用户可以通过该服务来添加，删除，或启用打印机作业。


Windows Print Spooler Service中存在一个本地提权的漏洞，当攻击者以一定的逻辑步骤来操作打印机时，将会触发一个逻辑错误。攻击者可以利用该漏洞最终获取计算机的最高权限。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。
