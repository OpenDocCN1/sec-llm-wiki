# 【漏洞通告】Microsoft Excel 安全特征绕过漏洞 CVE-2021-42292

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514851&idx=1&sn=d4c59dd7d55ec3985044e2e98dfc9a27&chksm=ce4631f3f931b8e5ce2faf25d25db621323acb959cc81bd9ee13a32c9e56ad0e011cf9d4266c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514851&idx=1&sn=d4c59dd7d55ec3985044e2e98dfc9a27&chksm=ce4631f3f931b8e5ce2faf25d25db621323acb959cc81bd9ee13a32c9e56ad0e011cf9d4266c&scene=27#wechat_redirect)

**漏洞名称** : Microsoft Excel安全功能绕过漏洞

**组件名称** : Microsoft Excel

**影响范围** : 

Microsoft Office 2013 Service Pack 1(32/64-bit editions)

Microsoft Office 2013 RT Service Pack 1

Microsoft Office 2016 (32/64-bit editions)

Microsoft Office LTSC 2021 for (32/64-bit editions)

Microsoft Office LTSC for Mac 2021

Microsoft 365 Apps for Enterprise for (32/64-bit editions)

Microsoft Office 2019 for Mac

Microsoft Office 2019 for (32/64-bit editions)

**漏洞类型** : 安全功能绕过

**利用条件** :

1、用户认证：否  
2、前置条件：需打开恶意文档  
3、触发方式：远程

**综合评价** : 

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Microsoft Office可以运行在Windows以及MAC平台，由于其便捷性和安全性被广泛使用，成为最流行的办公软件套件之一。全球有大量使用 Office 的用户。Excel组件是Office的一款电子表格软件。

  

**2 漏洞描述**

近日，深信服安全团队监测到一则Microsoft Excel组件存在安全功能绕过漏洞的信息，漏洞编号：CVE-2021-42292，漏洞威胁等级：高危。

  

该漏洞是由于Excel组件存在安全功能绕过漏洞，攻击者可以通过构造恶意文档并诱使用户打开，从而利用该漏洞绕过Excel的安全功能，在用户机器上执行恶意代码。

  

    

**影响范围**

    

  

目前受影响的Office版本：

Microsoft Office 2013 Service Pack 1(32/64-bit editions)

Microsoft Office 2013 RT Service Pack 1

Microsoft Office 2016 (32/64-bit editions)

Microsoft Office LTSC 2021 for (32/64-bit editions)

Microsoft Office LTSC for Mac 2021

Microsoft 365 Apps for Enterprise for (32/64-bit editions)

Microsoft Office 2019 for Mac

Microsoft Office 2019 for (32/64-bit editions)
