# 【漏洞通告】远程桌面连接客户端远程代码执行漏洞 CVE-2021-38666

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514851&idx=2&sn=aec6077c2f93b68b217dec19cb10999a&chksm=ce4631f3f931b8e5ab96bdc0894151849a03a12511c5b7df941cd2ac3136806f2bdd8a11c8b9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514851&idx=2&sn=aec6077c2f93b68b217dec19cb10999a&chksm=ce4631f3f931b8e5ab96bdc0894151849a03a12511c5b7df941cd2ac3136806f2bdd8a11c8b9&scene=27#wechat_redirect)

**漏洞名称** : Windows远程桌面客户端远程命令执行漏洞

**组件名称** : Windows远程桌面客户端

**影响范围** : 

Windows 10 Version 1607/1809/1909/2004/20H2/21H1

Windows Server, version 2004/20H2

(Server Core Installation)

Windows 7 for 32/64-bit Systems Service Pack 1

Windows Server 2008/2012/2016/2019/2022

Windows 11 for ARM64-based Systems

Windows 11 for x64-based Systems

Windows RT 8.1

**漏洞类型** : 远程命令执行

**利用条件** :

1、用户认证：不需要用户认证。  
2、前置条件：需要用户交互。  
3、触发方式：远程。

**综合评价** : 

<综合评定利用难度>：一般，需要用户连接至恶意RDP服务器即可远程代码执行。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

Windows Remote Desktop Client 使用户可以使用并控制一台远程的PC，对远程PC进行一切可以对物理PC进行的操作，如：使用安装在远程PC上的APP；访问在远程PC上的文件和网络资源；在关闭Client的时候保持APP打开。

  

**2 漏洞描述**

2021年11月10日，深信服安全团队监测到微软官方发布了一则漏洞安全通告，通告披露了Windows远程桌面客户端组件存在远程命令执行漏洞，漏洞编号：CVE-2021-38666，漏洞威胁等级：高危。

  

该漏洞由于客户端未对服务端传来的数据进行严格的校验，导致内存破坏，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终可获取系统最高权限。

  

    

**影响范围**

    

  

Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是目前使用Windows系统最多的两个国家。
