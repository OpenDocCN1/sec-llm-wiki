# 【漏洞通告】Windows win32k权限提升漏洞CVE-2021-40449

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514835&idx=2&sn=977e462d57618e1ac1e83160c1d7d76f&chksm=ce4631c3f931b8d5c618eb2518abe8a63d35e61d6f98f370c11a24c1f52d1f340b1f0e2ff2e7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514835&idx=2&sn=977e462d57618e1ac1e83160c1d7d76f&chksm=ce4631c3f931b8d5c618eb2518abe8a63d35e61d6f98f370c11a24c1f52d1f340b1f0e2ff2e7&scene=27#wechat_redirect)

**漏洞名称 **: Windows win32k 权限提升漏洞

CVE-2021-40449

**组件名称** : 

win32kfull.sys、win32kbase.sys、win32k.sys

**影响范围** :

Windows Server, version 2004/20H2(Server Core Installation)

Windows 10 Version 1607/1809/1909/2004/20H2/21H1

Windows 7 for 32/64-bit Systems Service Pack 1

Windows Server 2008/2012/2016/2019/2022

Windows 11 for ARM64-based Systems

Windows 11 for x64-based Systems

Windows 8.1 for 32/64-bit systems

Windows RT 8.1

**漏洞类型 **: 本地权限提升

**利用条件** :

1、用户认证：不需要用户认证  
2、触发方式：本地

**综合评价** :

<综合评定利用难度>：一般，攻击者在拥有低权限的情况下可利用此漏洞获得系统管理员权限。

<综合评定威胁等级>：高危，攻击者利用此漏洞能获得系统管理员权限。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    win32k是Windows内核中提供GUI相关功能的内核模块，例如桌面、窗口的创建和管理，是Windows桌面系统的最重要的内核模块之一。

  

**2 漏洞描述**

    深信服安全团队监测到一则win32k组件存在本地权限提升漏洞的信息，漏洞编号：CVE-2021-40449，漏洞：高危。

    该漏洞是由于UAF导致的任意地址写漏洞，攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行本地权限提升攻击，最终获取服务器最高权限。

  

   

**影响范围**

    

  

    Win32k存在于所有的Windows系统中，Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是使用Windows系统最多的两个国家。

    目前受影响的Windows版本：

Windows Server, version 2004/20H2(Server Core Installation)

Windows 10 Version 1607/1809/1909/2004/20H2/21H1

Windows 7 for 32/64-bit Systems Service Pack 1

Windows Server 2008/2012/2016/2019/2022

Windows 11 for ARM64-based Systems

Windows 11 for x64-based Systems

Windows 8.1 for 32/64-bit systems

Windows RT 8.1
