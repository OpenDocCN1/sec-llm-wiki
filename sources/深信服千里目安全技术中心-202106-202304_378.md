# 【漏洞通告】Windows通用日志文件系统权限提升漏洞CVE-2021-40467

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514835&idx=3&sn=7b2f164a6047cf688f059d477ec8426f&chksm=ce4631c3f931b8d5a445222234c9d1d59d9b9a3868993bf9ac1d31f76e075d0b21d000e5e898&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514835&idx=3&sn=7b2f164a6047cf688f059d477ec8426f&chksm=ce4631c3f931b8d5a445222234c9d1d59d9b9a3868993bf9ac1d31f76e075d0b21d000e5e898&scene=27#wechat_redirect)

**漏洞名称 **: Windows通用日志文件系统权限提升漏洞

CVE-2021-40467

**组件名称** : Clfs.sys

**影响范围** :

Windows 7

Windows 8.1

Windows 10 Version 1607/1809/1909/2004/20H2

Windows Server version 2008/2012/2016/2019/2004/20H2

**漏洞类型** : 本地权限提升

**利用条件** :

1、用户认证：需要用户认证  
2、触发方式：本地

**综合评价** :

<综合评定利用难度>：一般，低权限的攻击者可以利用此漏洞获得管理员权限。

<综合评定威胁等级>：高危，能造成本地权限提升从而获得管理员权限。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    通用日志文件系统是一个通用目的的日志文件系统，它可以从内核模式或用户模式的应用程序访问，用以构建一个高性能的事务日志。它自Windows Server 2003 R2引入，并包含在之后版本的Windows操作系统中。CLFS可以用于数据日志与事件日志。

  

**2 漏洞描述**

    近日，深信服安全团队监测到一则clfs.sys组件存在本地提权漏洞的信息，漏洞编号：CVE-2021-40467，漏洞威胁等级：高危。

    该漏洞是由于堆越界写，攻击者可利用该漏洞在获得权限的情况下，构造恶意数据执行本地权限提升攻击，最终获取服务器最高权限。

  

    

**影响范围**

    

  

    通用日志文件系统存在于目前大部分的Windows系统中，Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是使用Windows系统最多的两个国家。

  

    目前受影响的Windows版本：

Windows 7  
Windows 8.1  
Windows 10 Version 1607/1809/1909/2004/20H2  
Windows Server version 2008/2012/2016/2019/2004/20H2
