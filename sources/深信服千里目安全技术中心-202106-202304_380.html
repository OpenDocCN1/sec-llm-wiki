漏洞概要


    2021年10月13日（北京时间），微软发布了安全更新，共发布了82个CVE的补丁程序，同比上月减少了4个，涵盖了Microsoft发布的71个补丁，Chrome早前发布的8个补丁以及Openssl的3个补丁。

    在漏洞安全等级方面，有2个漏洞被微软官方标记为“Critical”，68个漏洞被标记为“Important”； 在漏洞类型方面，主要有27个远程代码执行漏洞，21个权限提升漏洞以及15个信息泄露漏洞。

1 2021漏洞数量趋势

    截至2021年10月，微软在各月修复的漏洞数量以及各月严重漏洞数量如下所示：

  • 总体上来看，微软本月发布的补丁数量减少到了82个，相较于上月减少了4个漏洞。

  • 千里目安全实验室在综合考虑往年微软公布漏洞数量的数据统计和今年的特殊情况，初步估计微软在今年11月份公布的漏洞数将有大幅度提升。漏洞数量也会维持在110个左右。

    2018-2021年，10月份的漏洞各个类型数量对比如下图：

  • 从漏洞数量来看，今年出现了小幅度的降低。微软在2021年10月份爆发的漏洞相较于去年有大幅度的下降，一方面是由于在软件及系统缓解措施的增加，致使一些组件相较于往年更难利用，另一方面是因为一些常用组件的常见低级漏洞更难进行挖掘，漏洞挖掘的门槛逐渐提升，对相关从业人员的技术要求有较高要求。

  • 从漏洞的危险等级来看，“Important”等级漏洞数量小幅下降，“Critical”等级漏洞数量大幅下降。从漏洞趋势上看，针对Windows系统本身的严重型和高危型漏洞数量大幅降低，针对Windows产品侧的漏洞数量占据大多数。这种趋势，标志着微软系统本身正向着更加安全走去，也符合MSRC成立的期望。

  • 从漏洞类型来看，RCE类型的漏洞有小幅提升，EOP类型的漏洞有大幅度的下降。权限提升漏洞(EOP)数量升高，需要引起高度重视，尤其是在配合社工手段的前提下，甚至可以直接接管整个局域网并进行进一步扩展攻击。远程代码执行漏洞(RCE)有大幅度数量的减少，但其危害性仍然很大。远程代码执行漏洞有利于攻击者更容易的获取受害者机器的执行权限，对于普通用户以及企业来说，远程代码执行类型的漏洞是危害比较大的。


10月重要漏洞分析


1 漏洞分析


Microsoft Sharepoint: CVE-2021-40487, CVE-2021-41344

    Microsoft Sharepoint是可以创建网站来与同事、合作伙伴和客户共享文档和信息, 搭建企业页面等的内容管理系统，可以部署在本地或者云上。CVE-2021-40487:Microsoft SharePoint Server存在远程命令执行漏洞，攻击者可以以低特权的身份发送特定的请求，来使得服务器在解析文件时出现解析错误, 最终可以在服务器上执行任意命令。CVE-2021-41344:Microsoft SharePoint Server存在远程命令执行漏洞，攻击者可以以低特权的身份发送特定的请求，使得服务器在解析文件时出现解析错误, 最终可以在服务器上执行任意命令。经过评估，该漏洞漏洞危害较大，建议用户及时更新微软补丁。


Microsoft Exchange Server: CVE-2021-41348

    Microsoft Exchange Server是当前最流行的邮件服务器之一， 广泛用于国内外的企业和机构。当攻击者处于相邻的网络时，Exchange Server存在远程命令执行和权限提升漏洞，攻击者可以通过相邻的网络，以低特权的身份发送特定的请求，在服务器上执行任意命令，最终接管服务器。经过评估，该漏洞漏洞危害较大，建议用户及时更新微软补丁。

 

Windows Win32k: CVE-2021-40449,CVE-2021-40450,CVE-2021-41357

    win32k是Windows的子系统，负责图形界面的创建和管理。CVE-2021-40449是由于 win32k 在处理重置设备上下文请求时出现了UAF漏洞，攻击者利用此漏洞，可以获得系统管理员权限。CVE-2021-40450：该漏洞是由于win32k在拷贝用户态缓冲区数据到内核缓冲区时，出现了缓冲区溢出，攻击者利用此漏洞，可以获得系统管理员权限。CVE-2021-41357 ：该漏洞是由于win32k在处理窗口对象创建时出现了UAF漏洞，攻击者利用此漏洞，可以获得系统管理员权限。以上漏洞已出现在野利用，建议用户及时更新微软补丁。
