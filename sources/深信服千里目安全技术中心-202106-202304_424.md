# 【漏洞通告】Atlassian Confluence 文件读取漏洞 CVE-2021-26085

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514805&idx=3&sn=6c146d92e8e8cca81d6a6eb56d9d2bb7&chksm=ce4631a5f931b8b3dd6c144bfa9d905d52165a53c8b8cfa202dafea94ec7a1aca21fde07fed1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514805&idx=3&sn=6c146d92e8e8cca81d6a6eb56d9d2bb7&chksm=ce4631a5f931b8b3dd6c144bfa9d905d52165a53c8b8cfa202dafea94ec7a1aca21fde07fed1&scene=27#wechat_redirect)

**漏洞名称 **: Atlassian Confluence文件读取漏洞CVE-2021-26085

**组件名称** : Atlassian Confluence

**影响范围** :

Atlassian Confluence < 7.4.10

7.5.0 ≤ Atlassian Confluence < 7.12.3

**漏洞类型** : 文件读取

**利用条件** :  

1、用户认证：不需要用户认证

2、触发方式：远程

**综合评价** :  

<综合评定利用难度>：未知。

<综合评定威胁等级>：中危，能造成服务器部分文件信息泄露。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    Atlassian Confluence是澳大利亚Atlassian公司的一套专业的企业知识管理与协同软件，也可以用于构建企业WiKi。该软件可实现团队成员之间的协作和知识共享。

  

**2 漏洞描述**

    近日，深信服安全团队监测到一则Atlassian Confluence组件存在文件读取漏洞的信息，漏洞编号：CVE-2021-26085，漏洞威胁等级：中危。

    该漏洞是由于没有对用户输入的内容进行严格的过滤导致，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行文件读取攻击，最终造成服务器部分文件信息泄露。

  

    

**影响范围**

    

    Atlassian Confluence在全世界分布较少，主要集中在在美国、德国和荷兰。

    目前受影响的Atlassian Confluence版本：  

Atlassian Confluence < 7.4.10

7.5.0 ≤ Atlassian Confluence < 7.12.3
