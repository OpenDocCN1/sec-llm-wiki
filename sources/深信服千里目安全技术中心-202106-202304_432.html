全球IT咨询巨头遭LockBit攻击

8月11日，全球IT咨询巨头埃森哲遭受了来自LockBit团伙的攻击。埃森哲事件中LockBit勒索团伙声称窃取了埃森哲超过6TB的数据，要求埃森哲支付5000万美元（3.2亿人民币）作为赎金。埃森哲在第一时间已采取措施控制病毒扩散，并采用备份数据进行业务恢复，他们声明对客户和正常的业务运营不会有任何影响。但不可否认的是被窃取的数据存在泄露的风险。

深信服终端安全团队在此事件发生之后迅速响应，捕获了此次事件中的LockBit2.0变种，进行详细分析并提供相应的勒索防护建议。

BlackMatter新动向：金融行业遭殃

BlackMatter 勒索团伙于2021年8月10日在其泄密网站上更新了最新的受害者名单，其中受影响较严重的是为多家银行和金融机构提供服务的印度商户平台公司Pine Labs。

据海外媒体报道，此次事件中导致多家金融机构和该公司的服务协议、其他私人协议、多份财务报告和超过 500,000 条的客户信息被窃取加密。BlackMatter也在其网站声称窃取了Pine Labs 100G的数据，要求他们在限定的时间内支付赎金。

勒索团伙新武器：PrintNightmare漏洞

PrintNightmare是一类安全漏洞（漏洞编号为CVE-2021-1675、CVE-2021-34527和CVE-2021-36958），影响 Windows Print Spooler 服务、Windows 打印驱动程序和 Windows Point and Print 功能。

Magniber和 Vice Society勒索团伙瞄准这一点，已经将这类漏洞规则纳入攻击使用的武器库。Magniber勒索软件于2017年底在韩国通过恶意邮件入侵加密终端被首次发现，Vice Society 于今年7月出现，是个新的勒索团伙，主要针对公立学区和其他教育机构。

据海外媒体报道，这两个勒索团伙正在积极利用Windows Print Spooler中的漏洞来入侵终端进行数据文件加密，并在受害者的网络中横向传播，以扩大影响范围，增加受害者支付赎金的概率。

在云网端的多层架构下，针对勒索病毒在突破边界、病毒投放、加密勒索、横向传播等各个环节，实现实时拦截、快速查杀、多重监测和有效处置，为用户提供全方位的勒索防护能力。

8个终端勒索防护小Tips

1、企业需要警惕非工作时段勒索病毒/团伙趁机攻击；
2、企业需要警惕“节假日高峰”现象；
3、Windows服务器中勒索病毒概率远大于Linux服务器；
4、有定期冷备份或者异地备份，关键时刻能救命；
5、大量证据表明，人是企业安全最薄弱环节（弱密码、钓鱼等），内部安全意识提升非常重要（也可以考虑零信任方案）；
6、核心数据资产的访问控制需要重点加强，有条件的建议前置堡垒机等方式进行管控；
7、企业内部任何一个漏洞或者僵尸网络主机，都有可能成为入口点，日常打补丁和杀毒是必不可少的；
8、不要迷信专网安全性，各个分支加入专网建议用防火墙等边界控制设备进行隔离管控。
