# 【漏洞通告】SonicWall Analytics 远程代码执行漏洞 CVE-2021-20032

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514800&idx=4&sn=1ad6d6c395156bb128ead9a58017edbe&chksm=ce4631a0f931b8b68a933b24a59c64803610ce53f0cac51eb738df283dc388bdc2c7ad0bd9e1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514800&idx=4&sn=1ad6d6c395156bb128ead9a58017edbe&chksm=ce4631a0f931b8b68a933b24a59c64803610ce53f0cac51eb738df283dc388bdc2c7ad0bd9e1&scene=27#wechat_redirect)

**漏洞名称** : SonicWall Analytics 远程代码执行漏洞

**组件名称** : SonicWall Analytics 

**影响范围** : SonicWall Analytics ≤ 2.5.2518

**漏洞类型** : 远程代码执行

**利****用条****件** : 

1、用户认证：需要用户认证  
2、触发方式：远程

**综合评价** :

<综合评定利用难度>：未知。  

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

SonicWall Analytics是一款高性能的网络管理和报告引擎。

  

**2 漏洞描述**

2021年8月17日，深信服安全团队监测到SonicWall官方发布了一则漏洞安全通告，通告披露了SonicWall Analytics 组件存在远程代码执行漏洞，漏洞编号：CVE-2021-20032，漏洞威胁等级：高危。

  

该漏洞是由于JDWP远程调试接口存在漏洞且该接口默认在9000端口开放，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终可获取服务器最高权限。

  

    

**影响范围**

    

  

该产品主要在内网场景使用，因此搜集到的资产较少，国外主要集中在美国、巴西等地，国内几乎没有暴露资产。

  

目前受影响的SonicWall Analytics版本：

SonicWall Analytics ≤ 2.5.2518

  

    

**解决方案**

    

  

**1 官方修复建议**

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://mysonicwall.com/

  

**2 ****临时修复****建议**

该临时修复建议存在一定风险，建议用户可根据业务系统特性审慎选择采用临时修复方案：

建议SonicWall Analytics的管理员关闭9000端口。
