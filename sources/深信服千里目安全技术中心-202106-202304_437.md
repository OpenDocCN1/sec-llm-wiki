**漏洞名称 **: Node.js远程代码执行漏洞CVE-2021-22931

**组件名称** : Node.js 

**影响范围** : 

Node.js 12.x < 12.22.5 (LTS)

Node.js 14.x < 14.17.5 (LTS)

Node.js 16.x < 16.6.2 (Current)

**漏洞类型** : 远程代码执行

**利用条件** :

1、触发方式：远程

**综合评价** :  

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    Node.js是美国Joyent公司的一套建立在Google V8 JavaScript引擎之上的网络应用平台。该平台主要用于构建高度可伸缩的应用程序，以及编写能够处理数万条且同时连接到一个物理机的连接代码。

  

**2 漏洞描述**

    近日，深信服安全团队监测到一则Node.js组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2021-22931，漏洞威胁等级：高危。

    该漏洞是由于 Node.js 的 DNS 库没有对输入的主机名称进行正确的检查，导致攻击者可以通过该漏洞造成域名劫持和代码注入。攻击者可利用该漏洞构造恶意数据，造成远程代码执行攻击，最终获取服务器控制权。

  

    

**影响范围**

    

  

    可能受漏洞影响的资产广泛分布于世界各地，主要集中在美国、中国、德国等国家。国内主要集中在北京、浙江、上海等地。

    目前受影响的Node.js版本：

Node.js 12.x < 12.22.5 (LTS)

Node.js 14.x < 14.17.5 (LTS)

Node.js 16.x < 16.6.2 (Current)
