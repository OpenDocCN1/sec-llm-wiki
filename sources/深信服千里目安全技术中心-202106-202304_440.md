# 【漏洞通告】Windows NFS ONCRPC XDR Driver 远程代码执行漏洞 CVE-2021-26432

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514797&idx=2&sn=4257a5a49547e53adb310a442772d413&chksm=ce4631bdf931b8abc212bd80d7dda35a1246d23d605bf5c5942e60ff8c80c353f235c1b5cbf9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514797&idx=2&sn=4257a5a49547e53adb310a442772d413&chksm=ce4631bdf931b8abc212bd80d7dda35a1246d23d605bf5c5942e60ff8c80c353f235c1b5cbf9&scene=27#wechat_redirect)

**漏洞名称 **:Windows NFS ONCRPC XDR Driver 远程代码执行漏洞CVE-2021-26432

**组件名称** :Windows NFS ONCRPC XDR Driver

**影响范围** : 

Windows 10 Version 1607/1809/1909/2004/20H2/21H1

Windows Server, version 20H2/2004 (Core installation)

Windows Server 2012 R2/2016/2019

Windows 8.1 for 32/64-bit systems

Windows RT 8.1

**漏洞类型** : 远程代码执行

**利用条件** :

1、用户认证：不需要用户认证  
2、触发方式：远程

**综合评价** :  

<综合评定利用难度>：容易，无需授权即可远程代码执行。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

   网络文件系统（NFS）是一种在网络上的机器间共享文件的方法，文件就如同位于客户的本地硬盘驱动器上一样。其可用于不同类型计算机、操作系统、网络架构和传输协议运行环境中的网络文件远程访问和共享。

  

**2 漏洞描述**

   2021年8月11日，深信服安全团队监测到一则Windows NFS ONCRPC XDR Driver组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2021-26432，漏洞威胁等级：高危。

  该漏洞是由于服务器未能正确处理用户传入的请求，导致产生了缓冲区溢出漏洞。攻击者可利用该漏洞在未授权的情况下，构造恶意数据造成远程代码执行攻击，最终获取服务器最高权限。

  

  
    

**影响范围**

    

  

   Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是使用Windows系统最多的两个国家。

   目前受影响的Windows版本：

Windows 10 Version 1607/1809/1909/2004/20H2/21H1

Windows Server, version 20H2/2004 (Core installation)

Windows Server 2012 R2/2016/2019

Windows 8.1 for 32/64-bit systems

Windows RT 8.1
