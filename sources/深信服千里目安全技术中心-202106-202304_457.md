# 【漏洞通告】Jetty WEB-INF 文件读取漏洞 CVE-2021-34429

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514789&idx=3&sn=220c27f21aabf0db9fbbada393af3a6c&chksm=ce4631b5f931b8a346467058f779b1d4da62395726aef4ad49abea5a4193f215236ae6c33cd4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514789&idx=3&sn=220c27f21aabf0db9fbbada393af3a6c&chksm=ce4631b5f931b8a346467058f779b1d4da62395726aef4ad49abea5a4193f215236ae6c33cd4&scene=27#wechat_redirect)

**漏洞名称 **: Jetty WEB-INF 文件读取漏洞CVE-2021-34429

**组件名称** : Eclipse Jetty

**影响范围** : 

9.4.37 ≤ Eclipse Jetty ≤ 9.4.42

10.0.1 ≤ Eclipse Jetty ≤ 10.0.5

11.0.1 ≤ Eclipse Jetty ≤ 11.0.5

**漏洞类型** : 文件读取

**利用条件** :

1、用户认证：不需要用户认证

2、触发方式：远程

**综合评价** :

<综合评定利用难度>：容易，无需授权即可进行文件读取。

<综合评定威胁等级>：中危，能造成敏感信息泄露。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    Eclipse Jetty是Eclipse基金会的一个开源的、基于Java的Web服务器和Java Servlet容器。

  

**2 漏洞描述**

    近日，深信服安全团队监测到Eclipse Jetty官方发布了一则漏洞安全通告，通告披露了Eclipse Jetty组件存在文件读取漏洞，漏洞编号：CVE-2021-34429。

    该漏洞是由于没有严格控制url输入产生，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行文件读取攻击，最终可造成服务器敏感信息泄露。

  

    

**漏洞复现**

    

  

    搭建Eclipse Jetty组件9.4.37版本环境，复现该漏洞，效果如下：

![](../Images/be8ceced914275b78f72bc421c1149c3.png)![](../Images/33bf3f2fa0cdc68dc6b9f81f7fb81aa1.png)

  

    

**影响范围**

    

  

   Jetty在全球范围内主要分布在美国和中国，在德国和法国也有少量分布，在国内主要分布在浙江。

  

    目前受影响的Eclipse Jetty版本：

9.4.37 ≤ Eclipse Jetty ≤ 9.4.42

10.0.1 ≤ Eclipse Jetty ≤ 10.0.5

11.0.1 ≤ Eclipse Jetty ≤ 11.0.5
