# 【漏洞通告】Windows 本地提权漏洞CVE-2021-36934

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514783&idx=4&sn=136f879c8a3f883cf0508cc961990a86&chksm=ce46318ff931b899cb9b30ddd9ca42252cbbe892c3ad3115007d3cc2c23594b1c186a64645f6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514783&idx=4&sn=136f879c8a3f883cf0508cc961990a86&chksm=ce46318ff931b899cb9b30ddd9ca42252cbbe892c3ad3115007d3cc2c23594b1c186a64645f6&scene=27#wechat_redirect)

**漏洞名称 **: Windows 本地提权漏洞 CVE-2021-36934

**组件名称** : Windows 

**影响范围** : Windows > Windows 10 version 1809

**漏洞类型** : 本地提权

**利用条件** :

1、用户认证：不需要用户认证

2、触发方式：本地

**综合评价** :

<综合评定利用难度>：未知。

<综合评定威胁等级>：未知，能造成本地提权。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    ACL是一个windows中的表示用户（组）权限的列表。ACL分为两类，Discretionary Access Control List (DACL) 自由访问控制列表和System Access Control List (SACL) 系统访问控制列表。

  

**2 漏洞描述**

    2021年7月22日，深信服安全团队监测到一则Windows组件存在权限提升漏洞的信息，漏洞编号：CVE-2021-36934，漏洞威胁等级：未知。

    该漏洞是由于微软对 SAM、SECURITY 等系统文件过于宽松的访问控制，导致攻击者可利用该漏洞在未授权情况下，构造恶意数据执行权限提升攻击，最终获取服务器最高权限。

  

   

**影响范围**

    

  

    Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是使用Windows系统最多的两个国家。

  

    目前已知受影响的Windows版本：

Windows > Windows 10 version 1809
