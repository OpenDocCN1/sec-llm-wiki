漏洞名称 : Windows Print Spooler权限提升漏洞

组件名称 : Windows Print Spooler

影响范围 : 未知

漏洞类型 : 权限提升

利用条件 :

1、用户认证：不需要用户认证

2、触发方式：本地

综合评价 :

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能造成权限提升。


漏洞分析


1 组件介绍

    Print Spooler是打印后台处理服务，即管理所有本地和网络打印队列及控制所有打印工作。如果此服务被停用，本地计算机上的打印将不可用；如果此服务被禁用，任何依赖于它的服务将无法启用。Spooler是为了提高文件打印效率，将多个请求打印的文档统一进行保存和管理，先将要打印的文件拷贝到内存，待打印机空闲后，再将数据送往打印机处理。


2 漏洞描述

   2021年7月21日，深信服安全团队监测到一则Windows Print Spooler组件存在权限提升漏洞的信息，漏洞编号：CVE-2021-34481，漏洞威胁等级：高危。

   当Windows Print Spooler服务不正确地执行特权文件操作时，存在特权提升漏洞，攻击者可利用该漏洞在未授权的情况下，构造恶意数据造成权限提升，最终获取服务器最高权限。

   此漏洞不同于之前的CVE-2021-1675和CVE-2021-34527这两个漏洞。在微软的漏洞通告中指出，该漏洞存在于2021年7月13日之前，不是微软补丁日发布的补丁所引入的漏洞。


影响范围


   Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是使用Windows系统最多的两个国家。


目前受影响的Windows版本：未知。


解决方案


1 官方修复建议

   官方尚未发布补丁，请持续关注官方网站以获得最新解决方案，链接如下：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34481


2 临时修复建议

   首先确定Print Spooler服务是否正在运行。在Windows PowerShell中运行以下命令：

Get-Service -Name Spooler

如果Print Spooler正在运行或未禁用该服务，且停止和禁用Print Spooler服务不影响现有业务，请在Windows PowerShell中运行以下命令：

Stop-Service -Name Spooler -ForceSet-Service -Name Spooler -StartupType Disabled

以上步骤会禁用本地和远程打印功能。
