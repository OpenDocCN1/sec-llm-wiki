# 【漏洞通告】 Apache Airflow CeleryExecutor远程命令执行漏洞 CVE-2020-11981

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514781&idx=4&sn=ed553fb16af050d191351e7dee9251d0&chksm=ce46318df931b89bf9df559a52443ced5e14d5a2ac1549573ddf4f9544a81e01ad7e59b5ed74&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514781&idx=4&sn=ed553fb16af050d191351e7dee9251d0&chksm=ce46318df931b89bf9df559a52443ced5e14d5a2ac1549573ddf4f9544a81e01ad7e59b5ed74&scene=27#wechat_redirect)

**漏洞名称 **: Apache Airflow CeleryExecutor 远程命令执行漏洞 CVE-2020-11981

**组件名称** : Apache Airflow

**影响范围** : Apache Airflow <=1.10.10

**漏洞类型** : 远程命令执行

**利用条件** :

1、用户认证：需要用户认证

2、触发方式：远程

**综合评价** :

<综合评定利用难度>：中等，需要授权才可远程命令执行。

<综合评定威胁等级>：高危，能造成远程命令执行。

  

   

**漏洞分析**

    

  

**1 ****组件****介绍**

   Airflow 是 Airbnb 开源的一个用 Python 编写的调度工具。于 2014 年启动，2015 年春季开源，2016 年加入 Apache 软件基金会的孵化计划。Airflow 通过 DAG 也即是有向非循环图来定义整个工作流，因而具有非常强大的表达能力。

  

**2 漏洞描述**

   近日，深信服安全团队监测到一则Airflow组件存在远程命令注入漏洞的信息，漏洞编号：CVE-2020-11981，漏洞威胁等级：严重。

   该漏洞是由于broker中的信息是可控的，攻击者可利用该漏洞在授权的情况下，构造恶意数据执行远程命令执行攻击，最终获取服务器最高权限。

  

    

**影响范围**

    

  

    目前受影响的Apache Airflow版本：

Apache Airflow<=1.10.10

  

    

**解决方案**

    

  

**1 官方修复建议**

    目前厂商已发布最新版本修复漏洞，请受影响用户及时更新最新版本。官方链接如下：

https://github.com/apache/airflow

  

**2 深信服解决方案**

【**深信服下一代防火墙**】预计2021年7月22日，可防御此漏洞， 建议用户将深信服下一代防火墙开启 IPS 防护策略，并更新最新安全防护规则，即可轻松抵御此高危风险。

  

【**深信服安全感知平台**】预计2021年7月22日，结合云端实时热点高危/紧急漏洞信息，可快速检出业务场景下的该漏洞，并可联动【深信服下一代防火墙等产品】实现对攻击者IP的封堵。
