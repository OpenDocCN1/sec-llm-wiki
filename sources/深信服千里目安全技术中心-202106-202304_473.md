# 【漏洞通告】Linux Netfilter本地权限提升漏洞 CVE-2021-22555

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514780&idx=2&sn=5f68a53274c17878021972a508b04d0a&chksm=ce46318cf931b89acbfd93f2618440b6a64b2ba31031da586030664383439e01e22792333f06&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514780&idx=2&sn=5f68a53274c17878021972a508b04d0a&chksm=ce46318cf931b89acbfd93f2618440b6a64b2ba31031da586030664383439e01e22792333f06&scene=27#wechat_redirect)

  

**漏洞名称 **: Linux NetFilter本地权限提升漏洞

**组件名称** : Linux Netfilter

**影响范围** : 

Linux Kernel >= 2.6.19

Linux Kernel < 5.12 

**漏洞类型** : 本地权限提升

**利用条件** :

1、用户认证：不需要用户认证

2、前置条件：内核选项CONFIG\_USER\_NS、CONFIG\_NET\_NS未关闭

3、触发方式：本地

**综合评价** : 

<综合评定利用难度>：未知

<综合评定威胁等级>：高危，能造成本地权限提升

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

   Netfilter，在Linux内核中的一个软件框架，用于管理网络数据包。不仅具有网络地址转换（NAT）的功能，也具备数据包内容修改、以及数据包过滤等防火墙功能。利用运作于用户空间的应用软件，如iptables、nftables、ebtables和arptables等，来控制Netfilter，系统管理者可以管理通过Linux操作系统的各种网络数据包。

现今许多市面上许多的IP分享器或无线网络路由器（Wireless router），多是嵌入式Linux平台，并利用Netfilter的数据包处理能力，提供NAT以及防火墙的功能。

  

**2 漏洞描述**

   近日，深信服安全团队监测到一则Linux Netfilter组件存在本地权限提升漏洞的信息，漏洞编号：CVE-2021-22555，漏洞威胁等级：高危。

   该漏洞是由于Linux内核模块Netfilter中存在一处本地权限 提升漏洞，在64位系统上为32位进程setsockopt IPT\_SO\_SET\_REPLACE（或IP6T\_SO\_SET\_REPLACE）时，如果内核选项CONFIG\_USER\_NS、CONFIG\_NET\_NS被开启，攻击者可通过该漏洞，实现本地权限提升，以及从docker、k8s容器中实施容器逃逸。

  

    

**影响范围**

    

  

Linux操作系统在全世界范围内应用十分广泛。主要应用于中国、阿根廷、美国等国家及地区。

目前受影响的Linux Kernel版本：

Linux Kernel >= 2.6.19

Linux Kernel < 5.12 

  

  

    

**解决方案**

    

  

**1 ****检测组件系统版本**

   使用hostnamectl命令查看Linux内核版本

![](../Images/bf2372afc51d095f32ea7cb0af2ab2ea.png)

  

**2 官方解决方案**

目前厂商已经升级版本以修复这个安全问题，请到厂商的主页下载：

https://mirrors.edge.kernel.org/pub/linux/kernel/

  

**3 临时修复建议**

根据RedHat的建议，用户可以实施以下操作通过禁用非特权用户执行CLONE\_NEWUSER、CLONE\_NEWNET，以缓解该漏洞带来的影响。
