# 【二次通告】 Kaseya VSA 身份验证绕过漏洞 CVE-2021-30116

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514780&idx=3&sn=43f9e47806088fd7beed250a32bd550b&chksm=ce46318cf931b89addebf2481eca1563ccc1e4dc6ce32e9e8238459f368d472ba57698e550c8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514780&idx=3&sn=43f9e47806088fd7beed250a32bd550b&chksm=ce46318cf931b89addebf2481eca1563ccc1e4dc6ce32e9e8238459f368d472ba57698e550c8&scene=27#wechat_redirect)

 

**漏洞名称 **: Kaseya VSA 身份验证绕过漏洞

**组件名称** : Kaseya VSA

**影响范围** : Kaseya VSA < 9.5.7

**漏洞类型** : 身份验证绕过

**利用条件** :

1、用户认证：不需要用户认证

2、触发方式：远程

**综合评价** : 

<综合评定利用难度>：未知。

<综合评定威胁等级>：高危，能造成服务器敏感信息泄露。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

   Kaseya VSA 是一款企业用于集中IT管理的软件，集终端管理和网络监控为一体，管理端通过控制用户端设备来执行命令，能生成报告并将生产数据可视化，同时也提供访问控制、自动化软件保护。

  

**2 漏洞描述**

   2021年7月6日，深信服安全团队监测到一则 Kaseya VSA 组件存在安全漏洞的信息，漏洞编号：CVE-2021-30116，漏洞威胁等级：高危。

  由于管理程序代码中dl.asp身份验证绕过漏洞，攻击者可利用该漏洞在获得 agentguid 的情况下，构造恶意数据执行身份验证绕过攻击，最终造成服务器敏感信息泄露。

  

    

**影响范围**

    

  

该产品分布于国外，其客户主要为管理服务提供商，在商业零售领域应用、IT领域应用较为广泛。

  

目前受影响的Kaseya VSA版本：

Kaseya VSA < 9.5.7
