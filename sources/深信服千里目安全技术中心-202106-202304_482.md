# 【漏洞通告】Django SQL注入漏洞 CVE-2021-35042

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514778&idx=2&sn=a9947e9b87baf417170b7feb47c9812f&chksm=ce46318af931b89c9162f8712bcdd182b766d14a62e415f6cacdecdaf5af3e818ddf2a05472c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514778&idx=2&sn=a9947e9b87baf417170b7feb47c9812f&chksm=ce46318af931b89c9162f8712bcdd182b766d14a62e415f6cacdecdaf5af3e818ddf2a05472c&scene=27#wechat_redirect)

**漏洞名称 **: Django SQL注入漏洞

**组件名称** : Django

**影响范围** : 

Django 3.2

Django 3.1

**漏洞类型** : SQL注入

**利用条件** :

1、用户认证：不需要用户认证

2、触发方式：远程

**综合评价** : 

<综合评定利用难度>：未知

<综合评定威胁等级>：高危，最终造成服务器敏感信息泄露。

  

    

**漏洞分析**

    

  

**1****组件****介绍**

   Django是一个开放源代码的Web应用框架，由Python写成。采用了MVC的框架模式，即模型M，视图V和控制器C。它最初是被开发来用于管理劳伦斯出版集团旗下的一些以新闻内容为主的网站的，即是CMS（内容管理系统）软件。

  

**2 漏洞描述**

   近日，深信服安全团队监测到一则Django组件存在SQL注入漏洞的信息，漏洞编号：CVE-2021-35042，漏洞威胁等级：高危。

该漏洞是由于对QuerySet.order\_by()中用户提供数据的过滤不足，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行SQL注入攻击，最终造成服务器敏感信息泄露。

  

    

**影响范围**

    

  

   在世界范围内，Django主要分布在美国，在中国、德国、印度等国家也有少量分布

国内主要分布在浙江、北京、上海等地。

    目前受影响的Django版本：

Django 3.2

Django 3.1
