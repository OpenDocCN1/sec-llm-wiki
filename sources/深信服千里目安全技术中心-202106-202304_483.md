# 微软补丁日安全通告|7月份

**漏洞概要**

    

  

    2021年7月14日（北京时间），微软发布了安全更新，共发布了117个CVE的补丁程序，同比上月增加了67个，涵盖了Microsoft的众多组件和软件。

    在漏洞安全等级方面，有13个漏洞被微软官方标记为“Critical”，103个漏洞被标记为“Important”； 在漏洞类型方面，主要有44个远程代码执行漏洞，32个权限提升漏洞以及14个信息泄露漏洞。

\- 千里目安全实验室在综合考虑往年微软公布漏洞数量的数据统计和今年的特殊情况，初步估计微软在今年8月份公布的漏洞数将有大幅度提升。严重类型漏洞数也会维持在110个左右。

**\- 从漏洞数量来看，今年出现了大幅度的提升。**

    微软在2021年7月份爆发的漏洞相较于去年有大幅度的提升，其中很大一部分都是针对Windows 组件的漏洞。

  

**\- ****从漏洞的危险等级来看,“Important”等级漏洞数量大幅提升,“Critical”等级漏洞数量小幅下降。**

    从漏洞趋势上看，针对Windows系统本身的严重型和高危型漏洞数量大幅提升，针对Windows产品侧的漏洞数量占据大部分。这种趋势，标志着微软系统本身正向着更加安全走去，也符合MSRC成立的期望。

  

**\- 从漏洞类型来看，除了跨站脚本请求(XSS)漏洞，其他漏洞数量均大幅提升。**

    权限提升漏洞(EoP)数量提升，需要引起高度重视，尤其是在配合社工手段的前提下，甚至可以直接接管整个局域网并进行进一步扩展攻击。远程代码执行漏洞(RCE)有大幅度的提升，危害性很大。远程代码执行漏洞有利于攻击者更容易的获取受害者机器的执行权限，对于普通用户以及企业来说，远程代码执行类型的漏洞是危害比较大的。

  

    

**7月重要漏洞分析**

    

  

**1  漏洞分析**

**Windows Print Spooler：CVE-2021-33771**  

Print Spooler是打印后台处理服务，管理所有本地和网络打印队列及控制所有打印工作。早前由国内安全研究员披露，当 Windows Print Spooler 服务不正确的执行特权文件操作时，存在远程代码执行的风险。攻击者通过一个低权限账户，利用该漏洞绕过安全检查，从而可以使用 System 权限运行任意代码，进而控制该服务器。该漏洞已公开披露且被在野利用，危害比较大，我们建议用户及时更新微软安全补丁。

  

**Jscript Engine：CVE-2021-34448**

JScript 是由微软公司开发的动态脚本语言，是微软对 ECMAScript 规范的实现。Jscript Engine 存在远程代码执行漏洞，攻击者可以通过构造恶意网页诱使用户进行访问，实施水坑攻击，从而在用户机器上执行任意命令。该漏洞已被在野利用，危害比较大，我们建议用户及时更新微软安全补丁。

  

**ntoskrnl.exe: CVE-2021-33771，CVE-2021-31979。**

ntoskrnl.exe又叫内核映像，为Windows NT内核空间提供内核和执行层，并负责硬件虚拟化、进程和内存管理等多种系统服务，故属于系统最基本的部分它具有缓存管理、执行指令、内核、安全访问监督、内存管理及任务调度等功能。当该组件没有正确处理用户传入的数据时就可能导致内存空间遭到恶意篡改，攻击者可以利用这些漏洞进行本地提权攻击。该漏洞已被在野利用，危害比较大，我们建议用户及时更新微软安全补丁。

  

**Windows DNS Server: CVE-2021-33780。**

DNS Server是Windows服务器的一项有关DNS的服务，一般可以通过Windows Server操作系统通过服务器管理器来安装该服务。DNS Server存在远程代码执行漏洞，当执行流执行进入漏洞的逻辑中时由于缺少必要的验证，导致内存空间被覆盖，使程序的内存空间被修改。攻击者可以利用漏洞进行拒绝服务攻击甚至远程代码执行。该漏洞经过评估，危害比较大，我们建议用户及时更新微软安全补丁。

  

**Microsoft SharePoint：CVE-2021-34467。**

Microsoft SharePoint可以为个人、信息和公司创建门户页面。CVE-2021-34467, Microsoft SharePoint由于未能正确处理用户传入的请求，在解析时存在一个文件解析漏洞，在获得认证权限的情况下攻击者可利用该漏洞，构造恶意数据执行任意命令从而获取服务器权限。CVE-2021-34468和CVE-2021-34520同样被标记为重要，我们建议用户及时更新微软安全补丁。

  

**Microsoft Exchange: CVE-2021-34473。**

Microsoft Exchange是国内外主流的邮箱服务器，应用广泛。CVE-2021-34473由于服务器未能正确处理用户传入的请求信息，在解析请求时存在一个解析错误，使得攻击者可以利用该漏洞构造恶意请求访问服务器内部服务，最终获得服务器的最高权限，同时还有多个标记为重要的安全漏洞如CVE-2021-31196和CVE-2021-31206等，我们建议用户及时更新微软安全补丁。

  

**Windows win32k: CVE-2021-34449。**

Windows win32k 是 windows 的子系统，负责图形界面的创建和管理。CVE-2021-34449 是未能正确处理窗口类型的转换导致了类型混淆，攻击者利用该漏洞，可以获得系统最高权限。漏洞经过评估，危害性较大，我们建议用户及时更新安全补丁。
