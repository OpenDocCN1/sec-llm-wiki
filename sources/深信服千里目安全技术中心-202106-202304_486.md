# 【漏洞通告】Windows Defender 远程代码执行漏洞 CVE-2021-31985

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514776&idx=2&sn=0c00a54d8d7e2c67711a3038ec803715&chksm=ce463188f931b89e6d9e78f0f892d83c1890cc920c5d8db5b158acd8c0f029455f1e6d9d780b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514776&idx=2&sn=0c00a54d8d7e2c67711a3038ec803715&chksm=ce463188f931b89e6d9e78f0f892d83c1890cc920c5d8db5b158acd8c0f029455f1e6d9d780b&scene=27#wechat_redirect)

**漏洞名称 **: Windows Defender 远程代码执行漏洞

**组件名称** : Windows Defender 

**影响范围** : Windows Defender <= 1.1.18200.3 

**漏洞类型** : 远程代码执行

**利用条件** :

1、用户认证：不需要用户认证

2、前置条件：需用户将文件下载到本地

3、触发方式：本地

**综合评价** : 

<综合评定利用难度>：简单，无需授权即可造成代码执行。

<综合评定威胁等级>：高危，能造成代码执行。

  

   

**漏洞分析**

    

  

**1****组件****介绍**

   Windows Defender，曾用名Microsoft Anti Spyware，杀毒程序，可以运行在Windows XP和Windows Server 2003操作系统上，并已内置在Windows Vista、Windows 7、Windows 8、Windows 8.1和Windows10中。

  

**2 漏洞描述**

   2021年7月8日，深信服安全团队监测到一则Windows Defender组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2021-31985 ，漏洞威胁等级：高危。

   该漏洞是由于Windows Defender在检测文件时，如果该文件是恶意构造的则可以导致该文件中代码的执行。攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行代码注入攻击，最终获取服务器最高权限。

  

    

**漏洞复现**

    

  

   搭建Windows组件Win10 1803版本环境，复现该漏洞，效果如下：

   恶意文件未放入 Win10 之前：

![](../Images/8ee99162b23b0c8ae5f7c19200085f4f.png)

   将恶意文件放入系统中，Windows Defender 崩溃。

![](../Images/d589d918adeee7ad5cd7ad58fa5dd26d.png)

  

    

**影响范围**

    

  

    Windows系统作为当下最流行、使用最为广泛的操作系统，在全球各个地区都有相当大的使用量，中美两国是使用Windows系统最多的两个国家。

  

目前受影响的Windows版本：

Windows Defender <= 1.1.18200.3 

  

    

**解决方案**

    

  

**1 如何检测组件系统版本**

    访问Windows安全中心，在设置-关于中查看对应的Windows Defender版本。若Windows Defender 关闭，则不受此漏洞影响。

![](../Images/eab5568f77f0d84f75b874d9e91d401b.png)![](../Images/61a8977623de3de2db226a161083dde6.png)

  

**2 官方修复建议**

   当前官方已发布受影响版本的对应补丁，建议受影响的用户及时更新官方的安全补丁。微软不提供Windows Defender 的离线补丁包，需用户自行连接互联网，Windows Defender会自动进行更新。

  

**3 临时修复建议**

   若用户不连接互联网，则可以在 Windows 安全中心中关闭 Windows Defender 。

注意：若没有使用其它主机侧安全产品，关闭Windows Defender 可能会增加主机遭受攻击的风险。
