# 【漏洞通告】Apache Dubbo 远程代码执行漏洞CVE-2021-25641二次通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NjgzNjA5NQ==&mid=2247514770&idx=1&sn=908130f23addbbc6dec6af1ee20c781f&chksm=ce463182f931b8948cf51cae1124d2943c3f3be22306c77006fde3faa260ba6ae2ab960eaa4b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg2NjgzNjA5NQ==&mid=2247514770&idx=1&sn=908130f23addbbc6dec6af1ee20c781f&chksm=ce463182f931b8948cf51cae1124d2943c3f3be22306c77006fde3faa260ba6ae2ab960eaa4b&scene=27#wechat_redirect)

**漏洞名称 **: Apache Dubbo 远程代码执行漏洞

**组件名称** : Apache Dubbo

**影响范围** : 

Apache Dubbo 2.7.0 - 2.7.8

Apache Dubbo 2.6.0 - 2.6.9

Apache Dubbo 2.5.x

**漏洞类型** : 远程代码执行

**利用条件** :

1、用户认证：不需要用户认证

2、触发方式：远程

**综合评价** :

<综合评定利用难度>：容易，无需授权即可远程代码执行。

<综合评定威胁等级>：高危，能造成远程代码执行。

  

    

**漏洞分析**

    

  

**1 ****组件****介绍**

    Apache Dubbo是一款高性能、轻量级的开源Java RPC框架。核心功能有面向接口的远程过程调用、集群容错和负载均衡、服务自动注册与发现。其特点主要在以下几个方面：使用分层的架构模式，使得各个层次之间实现最大限度的解耦。将服务抽象为服务提供者与服务消费者两个角色。

  

**2 漏洞描述**

    近日，深信服安全团队监测到一则Apache Dubbo组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2021-25641，漏洞威胁等级：高危。

    该漏洞是由于协议绕过，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终获取服务器最高权限。

  

   

**影响范围**

    

  

    Apache Dubbo 作为一款高性能、轻量级的开源 Java 服务框架，当前可能受漏洞影响的资产广泛分布于世界各地，国内主要集中在广东、江苏、河北等省份地区。

目前受影响的Apache Dubbo版本：

Apache Dubbo 2.7.0 - 2.7.8

Apache Dubbo 2.6.0 - 2.6.9

Apache Dubbo 2.5.x

  

    

**解决方案**

    

  

**1 官方解决方案**

    当前Apache Dubbo官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://github.com/apache/dubbo/releases
