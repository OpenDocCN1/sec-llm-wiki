# 2019网民网络安全感满意度调查活动全面启动

日前，**2019网民网络安全感满意度调查活动组委会发出通知，将于8月13日上午9 时正式对外采集信息，**全国各大网络平台将同步开通线上数据样本采集通道。信息采集历时10天，将于8月22日24 时结束。通知要求各发起单位从即日起，全面启动调查活动各项工作。

通知指出，调查活动是落实习近平总书记重要讲话精神的具体行动，是我国开展网络安全综合治理的重要方式之一，各单位要从事关大局、事关民生的高度，切实提高认识，把做好本次调查活动当作网络社会组织履行社会责任的一项重要工作认真落实，精心组织，扎实推进。要充分发挥当地各类媒体资源的优势，采用线上线下活动相结合的方式，进行多层次、多角度、综合性的立体宣传，提升自身在本地的知名度和影响力、号召力，提高社会各界对调查活动的知晓率和认可度。各单位要指派专人负责，明确工作职责，细化目标任务，做到有人员、有措施、有落实。活动期间，各发起单位要与本地区承担活动任务的相关各方保持联络，及时沟通工作进展，确保活动取得实效。

为加强宣传，营造浓烈气氛，保证调查活动各项工作有序开展，组委会秘书处整理并向各发起单位提供了一系列材料，包括调查活动介绍PPT、活动实施方案、组委会第一次会议纪要、活动支持单位邀请函、活动新闻宣传参考材料、活动宣传标语、活动宣传图片及链接样例、调查问卷入口位置推荐示例、调查报告汇编等。各发起单位可根据需要，结合本地实际情况组织实施。
