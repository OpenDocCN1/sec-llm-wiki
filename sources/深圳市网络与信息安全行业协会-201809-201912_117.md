# 讲网络故事，谈安全保险

保险，就是通过将风险转移给保险人，从而把偶然的损失进行分摊，保险人同意为被保险人赔偿损失，在损失发生时提供其他经前方面的援助，或者提供处理风险的服务。  

  

网络安全保险，是一种专业性的保险，用于转移网络安全风险，是一种较好的网络安全风险管控措施。

  

下图，是笔者从《中华人民共和国网络安全法》中，提炼的有关网络安全保险的内容。大家周知，《网络安全法》共分为七章，共计79条款，定义了1）国家网信部门、2）网络安全运营者、3）关键信息基础设施运营者、4）网络安全产品与服务提供者、5）任何组织或个人、6）境外的组织或个人等六类的网络安全责任主体，明确了各自的法律责任。其中，第一至五章是明确法律条款要求，第六章是明确违法责任。

  

笔者，从第六章着手，将17个条款分别分配给了6类责任主体，并给第一至五章的法律条款，做了映射对接。

  

![](../Images/fa11f94d7c1ed83ba2232ac2b640e5a9.png)

  

网络安全保险属于财产险领域，目前平安财产保险、中国人民财产保险、前海人寿财产保险等公司，分别推出了各自的网络安全保险产品。

  

由于网络安全保险的专业特殊性，需要构建一个“网络安全 + 金融保险”相关结合的产业生态，目前，能够将网络安全保险讲清楚的人不多，能够理解接受网络安全保险的人也不多。

  

但是，

1、2017年，中国信息通信研究院联合各大保险公司，在中国保险学会下成立了网络风险与保险专业委员会，组建了产业发展联盟，建成了网络风险与保险创新实验室。

2、2018年，中国信息安全杂志，专门出版了一起网络安全保险专刊。

3、2019年，针对于委内瑞纳电网疑因网络攻击而导致大面积停电事件，笔者联合深圳网络与信息安全行业协会，组织了网络安全保险的专题研讨。

  

等等，网络安全保险，离我们越来越近了。

  

近期，中国保险行业协会，于近期也计划邀请海外学者 汤博士来华，组织一起网络风险与保险的专题培训。培训内容非常丰富，为了规避广告嫌疑，笔者删除了培训时间地点、报名方式等内容（感兴趣者，可访问官方网站）。

  

  

**一、 背景简介**

  

国际保险大视野（海外专家来华）系列培训是 2017 年保险业协会为推动中国保险业与国外相关行业机构交流学习的重要平台。保险业协会邀请国际知名保险及相关企业的核心业务负责人、资深专家到国内授课，致力于把国际先进的保险管理、技术和创新经验引进国内。授课方向将包括保险业务创新、风险管理、保险资金运用、保险科技等热点主题。

**三、培训老师**

  

****汤阳博士 -** 国际网络安全及网络风险管理专家**

  

汤阳博士拥有计算机科学博士学位，微软认证系统工程师（MCSE），北美信息安全专家（CISSP），中国信息安全专家（CISP）等认证。

  

现为北美某保险科技及区块链公司创始人及网络安全总监，北美金融科技领域的信息安全专家和咨询顾问，为各类金融科技公司提供咨询服务，包括IT 网络安全（Network Security）和宏观网络安全及网络风险管理（Cyber Security & Cyber Risk Management）。曾在中国建设银行工作近20年，负责网络安全工作，是为数不多的在传统金融和金融科技领域均具备丰富经验且颇有建树的安全专家。

  

作为信息安全专家，他在企业信息安全的各个专业领域具有丰富的实践经验，包括 IT 内控与合规，数据安全、开发安全、运营安全、网络安全、物理环境安全、风险评估、安全监控和安全事件应急响应等。熟悉美国银行及加拿大主要银行的信息安全管理实践。

  

作为金融科技治理专家，他熟悉国际主流信息科技治理和信息安全标准，曾作为国际信息系统审计协会（ISACA）特邀专家参与 COBIT5 中文版的翻译工作，并参与编写 ISACA 信息科技治理最佳实践。

  

在信息科技风险监管研究方面，他关注各国金融科技风险的监管和评价，对世界主要国家信息安全监管保护要求开展过深入研究，原中国银监会《银行业金融机构信息科技监管研究》编写组成员。
