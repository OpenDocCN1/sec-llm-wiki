# 等级保护2.0正式发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0Mzk0NDQyOA==&mid=2247484756&idx=1&sn=8ca601459561489e606c68cd76d28b3d&chksm=fb02fed7cc7577c1e1850269cf1877aa73e3a3d77b14ee856159c96f852f52ea2c8174e7060c&scene=126&sessionid=1681322800#rd](http://mp.weixin.qq.com/s?__biz=MzU0Mzk0NDQyOA==&mid=2247484756&idx=1&sn=8ca601459561489e606c68cd76d28b3d&chksm=fb02fed7cc7577c1e1850269cf1877aa73e3a3d77b14ee856159c96f852f52ea2c8174e7060c&scene=126&sessionid=1681322800#rd)

2019年5月13日下午，国家市场监督管理总局召开新闻发布会，期待已久的等保2.0正式发布。根据最新的消息，等保2.0将在2019年12月1日正式实施。相比“等保1.0”只针对网络和信息系统的情况，“等保2.0”将云计算、大数据、物联网、工业控制系统等新业态也纳入了监管范畴，覆盖技术更全面，监管范围更广。  

  

  

**01**

**何为等级保护**  

  

等级保护是国家通过制定统一的信息安全等级保护管理规范和技术标准，组织公民、法人和其他组织对信息系统分等级实行安全保护，对等级保护工作的实施进行监督、管理。

  

国家信息安全等级保护将信息系统的安全保护等级由低到高分划为五级，主要依据是危害的范围和严重程度。  

  

![](../Images/1c31af971b8f5911a757902823af144f.png)

  

从广义上来说，信息安全等级保护包含所有依据等级保护思想的信息安全标准、产品、系统；从狭义上来说只是指信息系统安全等级保护，主要包括安全技术和安全管理两个层面。

  

  

  

**02**

**等保1.0到2.0的重大变化**

  

等保2.0的升级可以认为是应对了网络空间环境的变化。从原本的名称《信息安全技术信息系统安全等级保护基本要求》改为《信息安全技术网络安全等级保护基本要求》标志着等保的目标对象不再是单一的信息系统，而是扩展到了整个网络空间。

  

等保2.0另一个传递出的思想，是不能再拘泥于单纯的被动防御，而是需要将被动防御转型成主动防御。

**05 控制点和要求项的变化**

相比较于等保1.0，等保2.0在控制点方面基本持平。但是在等保2.0正式发布的稿件中通用要求部分新增了部分重要要求项。如：强调了入侵防范、安全审计、恶意代码防范、集中管控等要求。

  

  

  

众所周知，信息安全行业两大驱动因素——政策+安全事件。网络安全等级保护制度是我国网络安全保障领域普适性的制度，对国家网络安全保障有着不可替代的作用。综合来看，等保2.0将安全要求的范围扩大的同时，对安全的整体架构提出了要求，并且将安全的观念从被动防御转为了主动防御，将安全要求进行了前置。
