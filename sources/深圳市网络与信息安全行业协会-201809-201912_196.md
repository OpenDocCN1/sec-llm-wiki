# 隐私泄露、虚假广告、恶意软件……互联网成了315晚会重灾区

央视“315晚会”高居企业关注榜榜首，哪些企业会上榜，每年不断有各种预测。但实际上根据曾参与过晚会制作的央视人士透露，上榜企业基本无规律可言，取决于各个曝光节目的制作进度。这个逻辑其实并不复杂：相比起“只要策划，基本出稿”的纸媒和“拍脑袋加搜索加知网”出稿的自媒体，视频内容的制作要复杂很多，现场效果、回应取得、后期制作、呈现结果，哪个环节出问题，都可能导致一个选题被毙。  

所以，正如某位央视人士所言，“315晚会哪些企业会上榜，基本是一种玄学”，与其去预测今年哪些企业会上榜，不如出门买彩票。相对而言，去看看过去历年上榜的企业，当时所反映的问题，获得（或没有获得）的进展，也许更具历史价值。自315晚会将精力投注到互联网、新零售等高科技行业后，我们撷取出三年内上榜的科技企业、行业，看看315晚会的杀伤力到底如何。

**2016年**

1、“饿了么”惊现黑心作坊，知道真相的你还会饿么

![](../Images/1a12209c3cfc89c525eb9fca6efc34aa.png)

*外卖食物 图源/网络*

点名情况：在饿了么店铺“宏伟餐厅”。灶台就在门口露天摆放，上面布满黑黑的油渍；厨师用脏得看不清原色的抹布，将锅里、锅底擦了几遍，然后又将抹布垫在炒勺上；漏勺就放在脚边的脏水桶上，用时拿起来不加清洗直接使用；菜品出锅时，厨师将手指伸进锅里蘸出汤汁，伸进嘴里尝味道，感觉滋味不够好，又将菜品倒回锅里再次翻炒。

回应情况：饿了么官方微信表示，饿了么高度重视今晚央视315晚会报道的问题，紧急成立专项组，下线所有涉事违规餐厅，并连夜部署，核查全国范围的餐厅资质。

事后影响：此后，“饿了么”开展了一系列行动。包括与360合作，以直播形式向全网公开参与明厨亮灶饭店的后厨；建立独立的食品安全部门；委托第三方匿名检验餐厅情况；开展“食品安全月”自查自纠工作等。北京市食品药品监管局对被曝光的无证经营餐馆进行了核查，约谈了“饿了么”北京区域负责人。四川省成都市食品药品监管局取缔了被曝光的无证经营餐馆。并对“饿了么”在进行立案调查。上海市食品药品监督管理局对“饿了么”违反食品安全法的行为处以罚款12万元；对3·15晚会被曝光的涉嫌违反食品安全法的行为，约谈其主要负责人并正式立案调查。

2016年3月17日，北京市食品药品监管局约谈“饿了么”北京区、百度外卖、到家美食会、美团等10家网络餐饮运营商，要求运营商开展自查，并于3周内提供自查报告。中国消费者协会也约谈了“饿了么”电商外卖平台。2017年，饿了么公布3月份“食品安全月”行动的阶段性成果，共查出了违规餐厅5257家，并已将违规餐厅名单同步至各地食药监供进一步处理。

现状：目前，饿了么已经被阿里巴巴收购，去年底至今年初仍在持续招聘员工和骑手，与美团在外卖领域进行竞争。

2、二手车交易骗局：车易拍是这样骗你偷你

![](../Images/1b77523e4ebadfa62bcf53e78539d3b3.png)

*二手车交易 图源/网络*

点名情况：车易拍买家和卖家看到的是两个不同的页面，买家和卖家之间并非像广告宣传的那样不赚中间差价，存在价格欺骗行为。

回应情况：2016年3月15日21点，北京工商部门赶到“车易拍”公司位于朝阳区的办公场所现场取证。2016年3月15日23:55，车易拍通过官方微博发表声明《车易拍致亲爱的卖车人》。2016年3月16日10:19，车易拍再次通过官方微博发表声明，正式向消费者道歉，并连夜将“车易拍”收费明细在网站首页做了公示。2016年3月16日，国家工商行政管理总局要求北京等地工商部门，按照消费者权益保护法和《侵害消费者权益行为处罚办法》等有关法律法规进行查处。

事后影响：受315晚会影响，车易拍在二手车交易行业第一的地位被颠覆。2016年6月车易拍CEO发布内部信，称公司面临裁员与融资问题，9月，车易拍D轮融资获得北汽支持，挺过了资金匮乏阶段。

现状：目前，车易拍已经被大搜车并购，并全面打通平台与大搜车旗下二手车商服务SaaS平台“车牛”的底层数据。

**2017年**

1、互动百科网成虚假广告“垃圾站”

![](../Images/371d18bfd0d4bcb1be1de9a1f94f9ae5.png)

*互动百科 图源/网络*

点名情况：互动百科只需花费4800元就可以开通“百科词条认领”的服务，然后就可以随意以虚假广告堂而皇之地圈钱。一位互动百科的工作人员坦言，经他手开通的保健品百科词条，十个里面有一个有相关资质就不错了。

回应情况：互动百科官方微博在315当晚发表声明称，针对互动百科在词条内容审核以及客户资质审核方面存在的问题表示诚恳道歉，并排查网站词条内容，整改词条内容审核流程，下线不符合百科标准的词条和不合格客户广告。

事后影响：节目播出后不到半小时，北京海淀分局稽查大队雷霆出击，对这次事件进行调查，执法人员介绍，现场发现的技术服务合同，能反映出一些企业是通过付费形式进行的宣传。3月16日，互动百科经向全国股转系统申请，暂停转让。随后，3月20日媒体报道其互动百科产品已经进行下架整改。2017年互动百科业绩大幅下滑，通过大额支出销售费用来吸引客户，当年经营活动现金流为负数，在营收增长19.77%的情况下，净利润却下滑61.45%。2018年10月18日，海淀分局对其出具《行政处罚决定书》，称“公司利用自有网站（www.baike.com）为上海心知元电子商务有限公司、广州蕥生莱贸易有限公司、武汉正德一生物医药科技有限公司、运城市绿色壹佰医药科技有限公司、颈复康药业集团有限公司发布的广告，存在违反《中华人民共和国广告法》规定的情形；利用自有网络为梁田发布广告，存在违反《食品广告发布暂行规定》的情形”。最终决定没收公司广告费2.7万元，罚款24.2万元，合计26.9万元。

现状：2018年，互动百科宣布进行终止挂牌工作，截至目前尚未完成。

2、跨境电商违规引进日本“核污染区”食品

![](../Images/2a96d02345c190edf063e0232c8fed54.png)

*跨境电商 图源/网络*

点名情况：深圳市有棵树旗下的深圳海豚跨境科技有限公司，号称是中国进口母婴用品最大的供应链平台，为国内众多的电商提供货源。在公司的网上商城里有来自日本的核污染地区禁止销售的卡乐比麦片。

另外，在无印良品超市，一些日本食品的外包装上都被贴上了产地为日本的中文标签。但是当揭开中文标签后，露出了这些产品的真实产地为东京都，名列禁止进口名单。

2017年2月21日，深圳市市场稽查局对深圳有棵树公司进行执法检查，在该公司天津的保税区仓库里查获了近二万袋来自日本核污染地区的卡乐比麦片。

回应情况：有棵树公司回应表示，在接到国家质检总局发布的警示通报后，已经在第一时间将日本食品全线下架，并对此前售出的不符合通报的卡乐比麦片进行追回，向客户表达诚挚的歉意，并已在着手进行赔付。

2017年4月26日，媒体报道深圳市有棵树集团公司副总经理杨桦表示，公司一直在积极配合执法部门调查，并积极整改。但深圳市市场稽查局执法人员陈龙却称，事发至今，案件调查处理进展缓慢。“目前调查中遇到了一些阻力和困难，主要是第一个当事人不积极配合案件调查，给我们的办案设置障碍。在案件办理过程当中，办案人员的人身也受到了威胁。”

而颇具人气的小资品牌无印良品的回应，则带有一丝喜剧色彩。无印良品回应称，涉事食品所标示的“东京都”为母公司注册地址，并非食品产地。曝光食品无咖啡因香茅薏仁茶（谷物饮料）原产地为日本福井县，鸡蛋圆松饼（热加工糕点）原产地为日本大阪府。上海出入境检验检疫局回应称，“经核查无印良品（上海）商业有限公司的进口记录，未发现有来自于日本核辐射地区的产品。这也成为央视315晚会最著名的乌龙事件。

事后影响：3月16日，有棵树发布公司股票暂停转让公告，深圳市有棵树集团公司的两个股东汤臣倍健和建研集团在16日早开盘下跌。停牌4个月之后，有棵树股票于7月14日恢复转让。2017年8月与天泽信息签订收购合同，海豚供应链被有棵树剥离，不包括在此次收购中。2017年9月，深圳市市场稽查局发现，国内涉嫌销售日本核污染食品的网上商家初步统计已达13000多家。

现状：2018年10月，天泽信息完成对有棵树的收购。

**2018年**

1、共享单车押金难退

![](../Images/8857073ce65a31c3b0ea1ef9ded951e9.png)

*酷骑单车 图源/网络*

点名情况：晚会引用的中消协数据显示，截止到2018年1月3日，共收到消费者关于共享单车的信件2383封，因有共享单车企业无偿付能力，不能及时退还押金，引发全国性群体投诉。在70多家共享单车中，有34家已经倒闭，其中酷骑单车接受到消费投诉超20万，涉及金额超10亿。经中消协调查，北京酷骑单车总部已人去楼空。中消协认为，酷骑公司的行为严重侵害消费者合法权益，严重扰乱市场经济秩序，已申请公安机关立案侦查。

回应情况：2017年11月20日，酷骑单车通过微信公众号发布了《酷骑单车后续使用及退押金事宜的通知》，称因经营原因由四川拜客公司代运营管理和维护工作（不包括债务），位于北京市通州的办公室暂停办理退押金事务。

2018年315晚会曝光酷奇单车至2019年2月，酷骑单车的CEO才接受媒体采访，“他透露到，曾亲自私下与ofo、摩拜两大巨头创始人分别谈了两三次，想把公司卖给其中一家，但没有人愿意接手。”目前，工商局和用户还在与其联系，但是公司的资金困难，使其避而不见，同时也没有找到转变局面的方法。

事后影响：退押金难的问题并未得到解决，另外，由于公司资金困难，投入到市场上的酷骑单车无人管理，成为城市垃圾。

现状：2018年，共享出行行业面临资本寒冬，在没有进一步资本进入的情况下，纷纷出现资金链断裂的情况，又有一部分共享单车公司破产，生存下来的共享单车公司面临被大公司收购的结局。ofo和途歌等也因为面临退押金难的问题，被消费者投诉。“押金”很可能成为共享单车的负面遗产，在今后很长时间内跟“忽悠”画上等号。
