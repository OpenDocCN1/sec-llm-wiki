# 中国网络社会组织联合会第一届理事会第二次会议在京召开

1月14日上午，全国人大社会建设委员会副主任委员、中国网络社会组织联合会会长任贤良在京主持召开中网联第一届理事会第二次会议。

![](../Images/2073f0402e4fa11b17d24376031923f8.png)

**会议现场     高海涛/摄**

会议审议通过《中国网络社会组织联合会2018年工作总结和2019年工作要点》，通报了《中国网络社会组织联合会2018年度会费收支情况》，表决通过《中国网络社会组织联合会秘书处主要职责、内设机构和岗位设置方案》、《中国网络社会组织联合会分支机构管理办法（试行）》、《中国网络社会组织联合会财务管理制度（试行）》、《中国网络社会组织联合会项目活动管理办法（试行）》等有关规章制度，审议通过设立网络传播专业委员会相关事宜。

![](../Images/6aca629ea1e9982b738af38c6e2de560.png)

**全国人大社会建设委员会副主任委员、中国网络社会组织联合会会长任贤良    高海涛/摄**

任贤良会长指出，中国网络社会组织联合会自去年5月成立以来，坚持以习近平新时代中国特色社会主义思想和党的十九大精神为指导，深入学习贯彻全国网信工作会议和全国宣传思想工作会议精神，以服务网信中心工作为主线，以服务会员发展为根本，以加强自身建设为重点，积极组织开展各项活动，在起步开局中有效提升了影响力和引领力。据统计，中网联成立8个月来，先后主办或参与主办了2018中国网络媒体论坛、中国网络诚信大会等重要活动近20项，取得了可喜成绩，产生了广泛影响，受到各级领导、互联网业界以及广大网民的充分肯定。

任贤良会长强调，2019年是新中国成立70周年，是全面建成小康社会关键之年，做好2019年工作意义重大。为此，中网联今年要围绕以下六个方面来开展工作：一是要旗帜鲜明讲政治，牢固树立“四个意识”；二是要围绕中心、服务大局，全力配合网信中心工作；三是要依法依规抓监管，持续有力加强行业自律；四是要树品牌、展形象，不断提升中网联影响力；五是要强化服务意识，更好为会员提供优质服务；六是要驰而不息加强自身建设，树立中网联良好形象。任贤良会长特别指出，2019年要围绕新中国成立70周年这一重大主线和中国全功能接入互联网25年这一重要节点，提早谋划设计品牌活动，充分展现以互联网为标志的信息革命在国家发展中所发挥的重要而独特的推动作用。

中网联副秘书长和各部门负责人列席会议。
