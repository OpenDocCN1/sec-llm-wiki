# 网络空间安全人才队伍建设框架（研究）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0Mzk0NDQyOA==&mid=2247483706&idx=2&sn=1910e4e9792e1c049fa4a2a7c72992e2&chksm=fb02fab9cc7573af79ef3f2cff09b0de496bbfb826197d443a0a613e52a383ba1e85c3fcebda&scene=126&sessionid=1681322831#rd](http://mp.weixin.qq.com/s?__biz=MzU0Mzk0NDQyOA==&mid=2247483706&idx=2&sn=1910e4e9792e1c049fa4a2a7c72992e2&chksm=fb02fab9cc7573af79ef3f2cff09b0de496bbfb826197d443a0a613e52a383ba1e85c3fcebda&scene=126&sessionid=1681322831#rd)

2015年6月，为实施国家安全战略，加快网络空间安全高层次人才培养，我国国务院学位委员会决定在“工学”门类下增设“网络空间安全”一级学科，授予“工学”学位。随后3年内，众多高校纷纷开设网络空间安全专业，至今年3月，已有20多家高校获批，更多高校正在筹备申请中。可以预见，网络空间安全人才在未来若干年，在各行业、各领域都将炙手可热。下图是美国标准与技术学会发布的“网络空间安全人才需求”，其预测2022年，对此专业人才的需求量将达180万。

  

![](../Images/de5dbc1e26512ec5a3b0d0837edfb6fd.png)

这么多的人才需求如何满足，怎样才能培养出合格的人才，需要哪些知识、技能和能力？占知智库为大家提供的资料《网络空间安全人才队伍框架》可作参考。   

  

《网络空间安全人才队伍框架》由美国商务部下属的美国标准与技术学会发布于2017年8月，全文共144页，其最具价值之处倒不在正文，而是附件，尤其是附件B。其中详尽罗列并描述了网络空间安全的职业分类、专业领域、角色、知识、技能、能力、任务，合计2000多项。大纲如下：

  

1．内容简介

2．框架各部分及相互关系

3．框架的使用

4．扩展信息

附件A：框架要素

附件B：工作职责详情

附加C：人才发展工具

附件D：各文件间的相互对照

附件E：缩略语

附件F：参考文件

 

框架的架构

该框架分为5层，见下图：

 

![](../Images/2ea0c09d56221855a4728423e3cf1612.png)

职业分类（Category）：位于架构顶层，共有7个大类。  

 

![](../Images/087c2059d43b427992a8131a3cb58df0.png)

专业领域（Specialty Areas）：共有32个专业，下图以安全规定（SP）大类为例，列出其专业领域，包括：风险管理、软件开发、系统架构、技术研究与开发、系统需求规划、试验与评价、系统开发。  

 

![](../Images/a99c016cedb616a38cee6ff8877acc36.png)

专业示例

工作角色（Work Roles）：开展一项工作可选择一项或多项“工作角色”，该框架列出了每个大类每个专业领域下的工作角色，并对角色进行了编码和描述。

![](../Images/250649718822d3124754365d0da4d6f1.png)

角色示例

此外，还以工作角色为中心，列出了其下要执行的任务以及所需的知识、技能和能力。 

![](../Images/13824d4ac658d39efc34a557094c7264.png)

 知识、技能和能力（KSA）：是组成工作角色的三项属性，通过相关的经历、教育和培训来体现。该框架列出了630项知识、374项技能和176项能力。

![](../Images/329273dd52adcb498e2ba833568a4d75.png)

 知识描述示例

任务（Tasks）：是在某专业领域或工作角色下，开展工作的最小单元。该框架列出了1007项任务。

 

![](../Images/ed35be992705be57cd931ee95012d54b.png)

任务描述示例

如何使用这个框架？该框架列出4步法（似乎都是这个理）：

1. 确定网络空间安全人才需求

2. 招募优秀的网络空间安全人才

3. 教育和培训人才

4. 保持和发展人才
