# 深圳市首届网络空间安全工程技术专业高级职称评审（2020年度）工作会议圆满结束

**NIS研究院**

**深圳市网络与信息安全行业协会**

——关注SNISA，共享信安事。

  

2021年4月29日，深圳市网络与信息安全行业协会举办的“2020年网络空间安全工程技术专业职称评审会议”在福田高训大厦首次召开并圆满完成。网络空间安全工程职称评审技术共设5个专业，此次参加高、中级职称评审的共31人。会议由协会白健秘书长主持，深圳市人力资源和社会保障局专技处曾烨副处长及11名高级职称评委专家委员会参加。

  

![](../Images/23f0177fd58a06376ee4a5090c5c2455.png)

 深圳市人力资源和社会保障局专技处副处长曾烨致辞

  

深圳市人力资源和社会保障局专技处副处长曾烨对评审工作提出了要求，他强调，网络空间安全工程技术专业是2020年首届评审会议，一定要严格执行评审纪律，按照评审程序，把握评审质量，确保评审工作的公平性、准确性和专业性，共同推进评审工作的圆满完成。

 ![](../Images/ba295017653db6485fdc539283c4441f.png)

深圳市网络与信息安全协会秘书长白健讲解评审工作流程

  

  

会后，深圳市网络与信息安全行业协会白健秘书长表示，感谢曾烨副处长的莅临指导，感谢各位评审委员专家的到来，并且感谢市人社局和有关职能部门的肯定，支持我会承办网络空间安全工程技术专业首届高级职称评审会，作为网络空间安全行业服务的组织，协会将持续加大力度组织好职称评审工作，履行好评审职责，服务好深圳市人力资源市场和人才队伍建设，为网络安全行业储备更多优秀的人才。

  

![](../Images/10c7e3a68e676569bc9d3db4c9cf1b48.png)

深圳市2020年网络空间安全工程技术专业评审及答辩中

  

  

此次评审活动采用网络在线评审模式，旨在提高评专家工作效率，提升评审科学化水平，提倡无纸化办工等。专家评委通过深圳市人才一体化综合服务平台，对所有申报资料进行打分，投票等一系列工作。严谨、认真地履行评审职责，确保评审工作有效性及公平、公正等。持续为网络空间安全行业甄选出具有杰出贡献及在企业管理、学术等方面取得显著成绩的行业精英。为网络空间安全行业专业人才发展做好服务工作。
