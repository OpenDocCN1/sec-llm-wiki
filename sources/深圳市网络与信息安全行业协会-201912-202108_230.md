**简介：**

**北京知道创宇信息技术股份有限公司**成立于2007年，由数位资深的安全专家创办，2015年获得腾讯大范围战略投资，举办业内知名的Kcon白帽黑客大会，研发并部署全球知名的“ZoomEye”网络空间雷达系统及暗网雷达系统对全球约42亿IP及暗网市场进行了资产指纹、漏洞、暗网交易测绘，创办“Seebug”漏洞平台，累计60000+名以上白帽子、57000+个漏洞、45000+个漏洞PoC。

  

北京知道创宇信息技术股份有限公司较早提出基于云与大数据技术的云防御理念作为云防御领导者在业内享有较高的知名度与口碑，同时形成了基于云防御的WEB安全解决方案，基于WEBSOC立体监控与基于流量威胁感知的安全监测预警分析方案，基于资产与威胁的安全管理方案，基于0day、1day、Nday的安全响应方案，基于人工的安全服务方案。

**岗位职责**

```


1.负责公司产品的销售及推广；
```

  

**岗位要求**

```


1.大专及以上学历，计算机、网络、市场营销等相关专业；
```

  

  

**工作地点**

华南事业部  深圳

  

  

  

  

  

  

  

**2.政府行业销售总监**

  

  

 

**岗位职责**

  

1\. 根据公司战略以及政府业务主策略，完善政府业务整体销售策略与团队业务拓展计划。  

2\. 结合政府业务应用场景及公司产品，完善政府业务解决方案，并组织资源落地执行。   

3\. 维护和开拓直销客户与渠道合作伙伴，负责业务谈判及成交，落实回款，创建长期、良好、稳固的客户关系。  

4\. 负责团队搭建及日常管理，带领团队达成KPI目标

  

**岗位要求**

1\. 本科及以上学历。  

2\. 5-8年销售工作经验，3年以上销售团队管理经验。  

3\. 把握安全行业趋势，熟悉地方政府组织架构与决策机制，具备良好的政府业务前瞻性和判断力。  

4\. 有政府单位客户关系或行业客户关系，能够较快速形成业务转化。  

5\. 良好的业务规划能力与全局意识，较强的组织协调能力，坚韧，执行力强，有创业精神。 

6\. 把握安全行业趋势，熟悉地方政府组织架构与决策机制，具备良好的政府业务前瞻性和判断力者优先。 

7\. 具备丰富的网络安全产品及方案销售经验者优先。

  

  

**工作地点**

华南事业部  深圳

  

  

  

  

  

  

  

**3.售前解决方案**

  

  

 

**岗位职责**

1、根据信息安全市场发展，客户业务安全需求，提供行业解决方案； 

2、负责网络安全售前工作，负责分析客户需求、与客户进行交流，编写方案设计报告、实施方案报告和其他技术方案； 

3、深入了解重点行业客户安全体系，为销售团队、售前团队提供成果分享； 

4、配合客户经理完成与用户的需求调研、方案撰写、业务交流等工作。 

5、参加招投标会，进行信息安全技术上的讲解和答疑；

  

**岗位要求**

1、本科以上学历，信息安全背景，3年以上售前工作经验；2、深入了解网络安全各项标准、法规、技术； 

3、熟悉网络安全领域的相关专业技术知识、标准和相关安全产品及安全服务； 

4、具备较强的PPT、Word方案编写能力以及售前标书能力； 

5、具有CISA、CISSP、CISP、CCIE、ISO主任审核员、PMP、ITIL等证书者优先； 

6、熟悉等保或管理咨询以及相关技术要求者优先； 

7、具有金融、央企、教育、医疗行业经验者优先； 

8、具有集成项目经验者优先； 

9、有白帽经历或渗透测试服务经历优先；

  

**工作地点**

华南事业部  深圳

  

  

  

  

  

  

  

  

**4.华南大客户销售**

  

  

 

**岗位职责**

  

 1、负责挖掘云安全的商机，跟进新进客户的销售咨询，完成云安全产品及解决方案的销售； 

2、负责了解客户原始需求，挖掘并引导客户新的需求，根据公司产品挖掘在各行业尤其是互联网、金融、电商、教育行业的销售机会； 

3、负责了解客户招标需求，统筹公司资源，出具投标方案和完成标书，并主导参与整个投标过程； 

4、负责行业大客户开拓，建立稳定的客户关系，并针对特定客户独立完成客户拜访及产品销售； 

5、定期与老客户进行沟通，建立良好的长期合作关系。

  

**岗位要求**

  

  

 1、具有计算机及相关专业专科及以上学历，有安全或云计算销售经验者优先； 

2、具有良好的网络安全行业知识背景，熟悉互联网行业，能够独立开发新客户，完成销售任务，有金融、电商、教育、互联网客户资源者优先； 

3、具有独立开发客户的能力，具备较强的学习能力、人际沟通能力和解决问题能力； 

4、为人坦诚自信，乐观进取，高度的工作热情，有良好的团队合作精神

  

  

**工作地点**

华南事业部  深圳

  

  

  

  

  

  

**5.渗透测试工程师**

  

  

 

**岗位职责**

1\.  驻场工程师，负责完成客户所下发的渗透任务。

2\.  周期性对客户进行攻防实战及CTF方面的培训。 

3\.  能够沟通清楚漏洞挖掘过程，能够解答客户疑问，并提出相应的安全防护方案。

  

  

**岗位要求**

```


1、了解典型漏洞利用方法，具备一定的漏洞分析能力；熟悉业界安全攻防动态，能够独立挖掘、分析、利用漏洞；
```

  

  

**工作地点**

华南事业部  深圳
