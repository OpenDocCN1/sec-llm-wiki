# 微信清粉服务或泄露个人信息！微信账户可能会失控

微信里别人把你删了、拉黑了但是对方依旧在你的好友列表中，对于好友数量上百上千的人来说，手动删除真的是一件非常麻烦的事,也就会有人会选择类似于微博的“清粉”服务，这种服务虽然会省事不少，但是却暗藏被盗号的风险......

  

据国内媒体报道，如今电商平台、微信公众号都有提供“清粉”服务，单价多为1至3元，虽然价格便宜，但是却有不小的风险，使用过“清粉”服务后，你的微信可能会到处发广告、被拉入各种广告群、频频被迫下线、接到众多骚扰电话，骚扰电话甚至还能说出你的具体个人信息......

  

![](../Images/b3cdccc317dc273e2a477f54973ecee1.png)

  

专家介绍，“清粉”的原理是通过应用集群控制软件控制待清理微信账户，**一旦用户同意他人用群控软件“接管”账户，就很可能将自己的个人隐私完全暴露给他人。**

  

  

  

  

01**5.88元可买“清粉”周卡**

近日，据央视报道，为清理微信好友，微信用户何先生在某电商平台上购买了一款「清粉」软件，虽然成功「清粉」，但不久后便收到众多骚扰电话，能够说出他具体个人信息 ...  

  

记者搜索发现，类似案件多有发生。今年5月，据北京警方通报，市民张先生看到朋友圈里清理“僵尸粉”的广告消息，出于好奇添加了一名客服为好友。在一番操作后，微信中长久不联系的“僵尸粉”被删除。

不料，几天后，张先生的朋友给他打来电话，称张先生通过微信让他转账200元帮缴话费，询问张先生何时归还。这时，张先生才发现自己被骗，并及时报警。

据报道，还有使用了“清粉”软件的网友因此被陌生人直接加为好友后拉入各种广告发布微信群，微信被迫下线的情况也频频发生。

  

![](../Images/fe5d03c56bf6149d54fcdd38b6e86191.png)

  

  

南都记者也搜索到一些网站不仅提供“清粉”的单次服务，也会提供“清粉”的App，售价在60到100元左右，大部分只针对安卓手机用户。

![](../Images/bc1b83fc00f293d49d57bbdb290620f2.png)

  

  

  

  

02**案例：某科技公司赔偿200多万**

据此前警方通报**，****不论是链接还是其他形式，“清粉”软件最关键的一步就是登录微信的二维码。****事主一旦完成扫码，陌生人就获得了登录微信权限，个人隐私很容易被不法分子获取，导致各种安全隐患，甚至有可能出现账号被恶意利用、盗号，出现闪退或无法正常登录的情况。**  

  

“清粉”的原理是通过应用集群控制软件控制待清理微信账户，令该账户自动向其所有好友群发消息，再由群控软件根据“信息是否能够成功发送接收”来识别其中哪些是“僵尸粉”并删除。但是，除清粉外，群控软件还能控制微信账户批量点赞朋友圈内容、群发微信消息、自动同意好友添加并回复等。

  

记者发现，对于开发“清粉”服务的不法分子而言，“清粉”只是获利的一方面，利用此项服务获取到的数据信息获利空间更大。

  

据杭州互联网法院官方披露，今年6月2日，该法院就原告腾讯计算机公司、腾讯科技公司诉被告浙江某网络公司、杭州某科技公司不正当竞争纠纷一案进行一审宣判，判令两被告停止涉案不正当竞争行为，赔偿两原告经济损失及合理费用260万元，并为其消除影响。

  

杭州某科技公司开发、运营的“某群控软件”，利用外挂技术将该软件中的“个人号”功能模块嵌套于个人微信产品中运行，为购买该软件服务的微信用户在微信平台中开展商业营销、管理活动提供帮助，主要表现为自动化、批量化操作微信的行为，包括朋友圈内容自动点赞、清理僵尸粉、智能养号等等。

  

同时，该公司还会监测、抓取微信用户账号信息、好友关系链信息以及用户操作信息（含朋友圈点赞评论、支付等）存储于其服务器，攫取数据信息。

  

在审理后，法院认为，两被告通过被控侵权软件擅自收集微信用户数据，存储于自己所控制的服务器内的行为不仅危及微信用户的数据安全，且对两原告既有数据资源竞争权益构成了实质性损害，故属于违反《反不正当竞争法》。

  

  

  

03**微信安全团队提醒**

据微信安全团队介绍，一旦用户同意他人用群控软件“接管”账户，账户就很可能失控，不但会将自己的个人隐私完全暴露给他人，诸如工作、身份、联系方式、社会关系、财务信息等也都可能被他人获得。

  

微信官方数据显示，截至2020年6月底，微信共对上百万个明确使用“清粉”软件等外挂的账号，进行了短期或永久限制处理。

  

![](../Images/178e0836d11e3c2871525d76cec67f45.png)

  

微信安全团队提醒用户，**不要使用破坏微信软件协议或具有外挂功能的插件及软件。如遇安全风险，可通过微信客户端、腾讯110小程序进行投诉。**
