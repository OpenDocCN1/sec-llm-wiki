# 2020一季度公安网安部门违法违规APP专项整治工作成效

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0Mzk0NDQyOA==&mid=2247486448&idx=1&sn=5fa33ab1e9a96202943288f550f583d1&chksm=fb02f073cc757965e88b4fd0d0e46aabf140c82be6c304e91912b075a97c3a9b2a05f272d29a&scene=126&sessionid=1681322733#rd](http://mp.weixin.qq.com/s?__biz=MzU0Mzk0NDQyOA==&mid=2247486448&idx=1&sn=5fa33ab1e9a96202943288f550f583d1&chksm=fb02f073cc757965e88b4fd0d0e46aabf140c82be6c304e91912b075a97c3a9b2a05f272d29a&scene=126&sessionid=1681322733#rd)

**深圳市网络与信息安全行业协会**

今年第一季度，全国公安机关网安部门充分发挥职能作用，加大公民个人信息保护力度，依法查处违法违规收集公民个人信息APP服务单位386个，涉及信息咨询、辅助学习、文学小说、新闻资讯、娱乐播报等多个类型。其中，97个APP服务单位被予以行政处罚，192个APP服务单位被依法责令改正违法行为，51个APP被下架、停运，有效保护了公民个人信息。突出典型案例为：

  

  
  

  

0

**1**

![](../Images/c9384a4905d6e8b7c75da37c09cfb15f.png)

 **▊  ****“猎豹清理大师”APP**

**（版本号：6.13.5.1066）**

该APP的主要功能是提供手机清理优化及安全保护，运营商为北京猎豹网络科技有限公司。

  

经查，该款APP的隐私协议中对于索取用户通讯录、通话记录等权限的行为没有进行详细说明。目前北京市公安局朝阳分局已依法责令该公司改正违法行为。

  

0

**2**

![](../Images/bb0c717f51dad43a39ab948274efc36a.png)

 **▊ ****“印象笔记”APP**

**（版本号：10.5.5）**

该款APP的主要功能是提供多客户端同步的在线云笔记软件及个人效率工具，运营商为北京印象笔记科技有限公司。

  

经查，该款APP隐私协议中未以显著位置、显著字体申明收集用户信息数据项，未明示各数据项收集用途。目前北京市公安局朝阳分局已依法责令该公司改正违法行为，并予以警告处罚。

  

0

**3**

![](../Images/2442350f1d618111b25fabf572ba1ce1.png)

 **▊ ****“好孕帮”APP**

**（版本号：3.4.8）**

该款APP的主要功能是为不孕不育、难孕难育人群提供专业咨询，运营商为明锐思成（北京）信息科技有限公司。

  

经查，该款APP在收集信息时未明示并征得用户同意，用户服务协议及隐私声明中未明示申请权限目的，未告知收集用户个人信息的目的及使用方式。目前北京市公安局西城分局已依法责令该公司改正违法行为，并予以警告处罚。

  

0

**4**

![](../Images/c48c99ae2f7f2fe4b8e30a0970d42930.png)

 **▊ “不背单词”APP**

**（版本号：3.2.2）**

该款APP的主要功能是为用户提供英语单词学习服务，运营商为北京艾斯酷科技有限公司。

  

经查，该款APP在收集信息时未明示取得用户同意。目前北京市公安局大兴公安分局已依法责令该公司改正违法行为，并予以警告处罚。

  

0

**5**

![](../Images/fdbb58f8d1f7eda3061be2521cbee643.png)

 **▊ “哈弗智家”APP**

**（版本号：3.4.7）**

该款APP的主要功能是为哈弗车主、用户提供在线交流和售后服务、维护、咨询等服务，运营商为长城汽车股份有限公司徐水哈弗销售分公司。

  

经查，该款APP无收集信息明示且未取得用户同意，未向用户明示收集、使用个人信息的目的、方式、范围，河北省保定市公安局已依法责令该公司改正违法行为。

  

0

**6**

![](../Images/008f12173619304ff1e9efb208fdcea0.png)

 **▊ “完美校园”APP**

**（版本号：v5.0.6）**

该款APP的主要功能是为用户提供校园卡充值、查询、虚拟校园卡、在线报修、查成绩、课表以及就业等服务，运营商为新开普电子股份有限公司。

  

经查，该款APP在部分第三方SDK组件中存在调用获取任务信息和读取联系人等两项权限的情况。目前河南省郑州市公安局已依法责令该公司改正违法行为。

  

0

**7**

![](../Images/a50f1c8b0f975d9a3e3bc3eb4e9ba485.png)

 **▊ “天然工坊”APP**

**（版本号：3.5.0）**

该款APP的主要功能是提供网络购物服务，运营商为湖南天然工坊电子商务有限公司。

  

经查，该款APP的用户隐私协议中未向用户明示获取用户信息的详细用途及业务关联。目前湖南省长沙市公安局已依法责令该公司改正违法行为，并予以警告处罚。

  

0

**8**

![](../Images/aa3792c36ae23c64cc9a49a0ea4561a1.png)

 **▊ “随手借”APP**

**（版本号：4.11.11）**

该款APP的主要功能是为合作对象“亚联财小额贷款有限公司”开展小额资金贷款业务，帮助用户提交身份信息、授权核查公积金、社保情况，提供用户资质审核筛查业务，运营商为深圳市瑞科麦数据技术有限公司。

  

经查，该款APP 应用隐私政策中未明示第三方 SDK插件，收集使用个人信息的目的、方式和范围。目前广东省深圳市公安局已依法责令该公司改正违法行为。

  

0

**9**

![](../Images/08cd4e9e88b6c12fd71294cd063339e4.png)

 **▊ “每日瑜伽”APP**

**（版本号：7.15.1.1）**

该款APP的主要功能是提供线上瑜伽视频教学等服务，运营商为西安瑜乐文化科技股份有限公司。

  

经查，该款APP未以显著位置、显著字体申明收集用户信息数据项。目前陕西省西安市公安局高新分局已依法责令该公司改正违法行为。

经查，该款APP存在超范围收集用户信息问题。目前陕西省西安市公安局已依法责令该公司改正违法行为。
