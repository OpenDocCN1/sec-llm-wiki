# 疫情对网络安全行业有很大影响

Tor浏览器很多人都用过，暗网浏览主流浏览器，前两天Tor隐私浏览器背后的组织Tor Project宣布，由于冠状病毒（COVID-19）大流行造成的经济负担，将裁员三分之一。

  

声明中说：**“Tor与世界上的许多地方一样，都陷入了COVID-19危机。**与其他许多非营利组织和小型企业一样，这场危机使我们深受打击，我们不得不做出一些艰难的决定。我们不得不放弃了13名出色的人，这些人帮助Tor遍及了全球数百万人。” 

  

![](../Images/7ea47c6fc884c2b71de676f4fa479df4.png)

  

**Tor项目总部位于美国的非营利组织完全依靠捐款生存。**每年，该项目都会开展年终捐赠运动，以期增加下一年的财务状况。由于大多数捐赠者（用户，美国政府和私营部门）大多部捐赠者自己都受到COVID-19疫情影响，捐的非常少。**如果收不到捐款，Tor项目将来生存都会是个大问题。**

  

Tor项目并不是经历艰难时期的唯一组织。其他公司也被迫解雇员工。这份名单包括大牌像Tesla（特斯拉）, BestBuy（百思买）, GAP, Macy's, Yelp, Disney（迪斯尼）, Vox Media。美国企业都在解雇员工。

  

最近几天，19家中国上市网络安全公司披露的2020年Q1 业绩预告**4家盈利，9家亏损，6家未披露。各家盈亏情况与去年Q1对比如下：**

  

![](../Images/dd734714bb52c04a225af54367b8ae87.png)

  

![](../Images/cbc7ba2e5b1708afca04fc9d8d292d3d.png)

  

*   北信源、拓尔思2家企业业绩预计同向上升。
    
*   迪普科技、飞天诚信2家企业业绩预计同向下降。
    
*   深信服、绿盟科技、南洋股份、蓝盾股份、任子行、美亚柏科、卫士通、中孚信息、数字认证9家企业业绩预计亏损。
    
*   三六零、启明星辰、格尔软件、安恒信息、山石网科、安博通6家企业业绩未披露。
    

  

  

对于网络安全创业企业来讲，行业专家建议：一是需要注意自己的现金流，二是需要注意疫情对产品和服务方向会造成的影响。

  

新基建这个词的迅速走红，特别是在有关网络和5G网络建设，成为业内外比较关注的话题。2020年4月20日，国家发改委首次明确新型基础设施的范围，国家发改委相关负责人表示，初步研究认为，新型基础设施是以新发展理念为引领，以技术创新为驱动，**以信息网络为基础，**面向高质量发展需要，提供数字转型、智能升级、融合创新等服务的基础设施体系。

  

总而言之，有影响也有希望。5G的广泛性带来的安全危险是无法预估的，需要投入更多的精力和资源解决安全问题。**“安全是“1”,其他都是“0”。**
