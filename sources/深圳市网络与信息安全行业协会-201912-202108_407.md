# “淘宝内测版本”弹窗是一场营销还是报复性bug？

3月25日消息，据网友爆料，淘宝iOS9.5.7版本罕见出现系统错误，打开APP后，系统弹窗提示“您使用的程序是内测版本，将于当地时间2020-3-28到期，到期后将无法使用，请尽快下载最新版本。”不过，该条消息一闪而过。

  

一开始在朋友圈有人发的时候还以为是p的图呢。

![](../Images/bdc3bba1b37fe468a0b9acd6cbe72ff1.png)

  

  

官方回应之后还牵扯出一个“淘宝特价版”难道这是一场营销？？

  

后来很多人都说自己也有，于是昨天上午顺利上了微博热搜。

  

  

![](../Images/06d74ef5cb0aa23c9793634b96de3cb1.png)

  

**经试验，在此版本下，用户在淘宝上的浏览、领券、下单行为并未受到影响。**

  

不过，当把手机时间调整至2020年3月29日后，淘宝弹窗提示“您使用的程序是测试版本，目前已经过期，请更新到最新版本。”

  

![](../Images/f8a7911125eef35ea5f16fad94de2e39.png)

  

在该弹窗提示后，在淘宝上的正常的浏览、领券、下单等行为均无法完成，app出现闪退，并需要进行app恢复。不过，在点击恢复后仍然无法正常使用，系统提示为“异常退出”。

  

![](../Images/83254125707866608e28f65175ecc3d6.png)

**经测试，将淘宝更新到最新版本9.5.15后该问题得到解决。**

  

目前，网上传的沸沸扬扬的版本如下：  

  

![](../Images/67a70a8384f7794340f6e5e81678b43a.png)

![](../Images/48ae694bbd4b7dc94ed57952dee29bc3.png)

  

在事故发生后，一些比较优秀的人就做出了一系列的分析。  

首先，事故定级，本次事故是阿里S1,这个级别属于阿里非常严重的事故定级，其次称，IOS团队可能被全员打低绩效3.25（在这儿解释一下，第一次打3.25属于警告，第二次会直接开除，3.25是拿不到年终的，意味者四月的年终可能就凉了）  

![](../Images/6b664d0bf9dcbeb0dbd7ed158389db94.png)除此之外，我们优秀的网友也给予了自己的猜测：

  

其中获赞最多的是一个阿里巴巴的员工：他猜测应该小哥已经拿了325，故意在这天搞这么一出戏。这个评论获得293个认同。业界曾说，阿里的员工基本都得过325，所以，这个评论或者可信度也是比较高的。

![](../Images/f157e3bc10697b9acf4d15a76cb504c1.png)

  

  

  
很快，淘宝官方就出来辟谣了！对此，阿里方面表示：谣言！关闭提醒即可。  
![](../Images/58b6976711aebaf95513d0c54d45ad85.png)  
虽然官方出来辟谣了，也不免被网友们调侃：  
![](../Images/1105fe8e66a3623941ca4c6865b8a74d.png)![](../Images/a31cd7e72760c0c1bc1db7db7ebcec12.png)![](../Images/439f62692648362250c0dda325bce0e5.png)微博截图  
  
借用网友的话：你好冷酷，好无情（旺柴）。  
![](../Images/66d260f8f96fa4bbda8bbd6524b60439.png)  
另据淘宝方面介绍，淘宝特价版App将于3月26日正式发布，将以C2M商品为核心供给。目前淘宝特价版在APP Store购物类排行榜已跃居第一。  
不过，特价版亮相后，也有不少网友吐槽设计难看。有人在淘宝官博下举报山寨，淘宝回复称“大水冲了龙王庙，真是我亲兄弟”。这是继钉钉之后，又一个被网友集体吐槽的App。  
![](../Images/0d5b169d98d4422d807987a3a703bf3c.png)

  

![](../Images/16c4dcda9e909984f97d413f39a3eab2.png)

  

网友也积极参与了

![](../Images/5dc5f50333aa849ca89224ba0a836c89.png)

  

话题说回来，官方的回应也没有提及弹窗的具体原因，但是不管是不是报复性的bug，它始终是个事故，这个责任肯定有人背。现在打开淘宝app没有提示了，目前已修复了。

  

不过325和3月25日数字一样，巧合吗？
