# 疫情之下，境外黑客组织扬言近期攻击我国视频监控系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0Mzk0NDQyOA==&mid=2247485870&idx=1&sn=3c32a90d8330e2425b63270193089eae&chksm=fb02f22dcc757b3bc25a9a506cf7e51ef44e008552616e8b005a85b6d716f44cd269c114e2e9&scene=126&sessionid=1681322755#rd](http://mp.weixin.qq.com/s?__biz=MzU0Mzk0NDQyOA==&mid=2247485870&idx=1&sn=3c32a90d8330e2425b63270193089eae&chksm=fb02f22dcc757b3bc25a9a506cf7e51ef44e008552616e8b005a85b6d716f44cd269c114e2e9&scene=126&sessionid=1681322755#rd)

近期有境外黑客组织发布推文扬言将于2020年2月13日对我国视频监控系统实施网络攻击破坏活动。

  

  
  
  
  
  
  
  
  
  
![](../Images/d7c81e5b0ae13ddc56cb5ac653fb17be.png)  
其声称已掌握我境内大量摄像头控制权限，并在某平台公布了70余个视频监控设备信息。  
![](../Images/60feacc373017f65a28a412a27db9b0b.png)  
经核查后，上述的链接均属于某某光电技术有限公司生产的监控设备视频查看地址，通过互联网搜索发现该设备存在大量漏洞且至今仍未修复，黑客可以绕过登录界面直接看到监控内容甚至直接获取控制权限，潜在危害较大。  
全国约78.9万个开放在互联网的相关监控设备。此次黑客公布的视频监控设备信息主要涉及辽宁、山东、河北、河南等地，具体分布如下：  
![](../Images/e417484d60d0658c7d1adc8c0a5dbfe8.png)这些设备大多开放在如下端口：

*   21
*   80
*   81
*   82
*   83
*   443
*   554
*   9001
*   9999
*   8888

通常使用如下协议：

*   http
*   https
*   rstp
*   ftp
*   ipcam
*   sip
*   upnp  
    

网络视频监控设备和传统的家用设备的区别在于，其为了远程控制多数选择直接暴露在公网中，因此存在极大的安全风险隐患。攻击者可以轻易的访问到这些设备并实施远程控制，以及用于从事网络危害活动。  
这些设备往往具有如下特点：

*   其自身不具备防御性
*   固件版本十分老旧
*   不支持OTA自动更新
*   以产品功能为导向而非安全  
    

回顾历史上的僵尸网络攻击，以及针对IoT设备的攻击，主要采取以下几种方式：

*   弱口令及默认密码、内置密码
*   逻辑漏洞
*   公共组件历史漏洞

  

针对以上情况分析，疑似境外黑客组织掌握我国暴露在互联网上的视频监控设备，并利用其漏洞进行攻击控制，建议加强针对视频监控网络的安全监控和防护工作：

  

  
![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

1、梳理暴露在互联网上的视频监控网络设备，如非业务必须，请避免直接暴露在互联网，同时对资产加强安全监控和防护措施。

  

![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

2、对暴漏在互联网上的视频监控设备进行安全监测，对视频监控设备进行扫描，及时发现视频监控设备漏洞、弱口令等问题，并及时针对漏洞进行修复。

  

![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

3、采用流量检测技术手段，对视频监控设备与外部通信行为进行持续监控，尤其是境外通信行为，及时采取阻断措施。

  

![](../Images/ed1e0ee668943c85f5ad753b38803288.png)

4、建议用户自查使用的视频监控产品是否存在安全隐患，若存在隐患需及时隔离公网访问或停用相关设备，防止被黑客利用。
