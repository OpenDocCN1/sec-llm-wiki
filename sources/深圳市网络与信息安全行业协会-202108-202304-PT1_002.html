1. 自主访问控制(DAC:Discretionary Access Control)

自主访问控制(DAC)是一个访问控制服务，其执行一个基于系统实体身份的安全政策和它们的授权来访问系统资源。

2. 双附接集线器(DAC: Dual-attached Concentrator)

双附接集线器(DAC)是FDDI或CDDI集线器有能力接入到一个FDDI或CDDI网络的两个环。它也能够是来自其它FDDI或CDDI集线器的主机端口的双重归属。

3. 数字访问和交叉连接系统(DACS: Digital access and Cross-Connect System)

数字访问和交叉连接系统(DACS)是一个数字系统，在其中访问由T-1硬件结构在专用和公共网络中执行，集中交换和交叉连接由D3/D4成帧为转换数字信号-0信道(DS-0)到其它DS-0信道被执行的。

4. 国防高级研究计划署(DARPA: Defense Advanced Research Projects Agency)

国防高级研究计划署(DARPA)，从ARPA发展而来，是一个美国政府机构，其为有关Internet的实验提供研究基金。

5. 双连接站(DAS: Dual Attachment Station)

双连接站（Dual-Attachment Station)，也叫做一类一站，是一个设备连接到主环和次环两个FDDI环上。双连接为FDDI环提供冗余：如果主环不工作了，这个站能够将主环切换到次环上，使故障孤立，保持环的完整性。

6. 动态分配插槽(DAS: Dynamically Assigned Socket)

动态分配插槽(DAS)是在请求下通过在AppleTalk网络上的一个主机使用数据报传送协议(DDP)自动分配的。在一个AppleTalk网络中，这些分配编号为128到254的插槽作为动态分配插槽。

7. 数据直接VCC(Data Direct VCC)

数据直接VCC(Data Direct VCC)是在一个ATM网络中两个LECs之间的双向的点对点的VCC设置。IT是由Phase 1 LANE定义的三个数据连接中的一个。数据直接VCC不提供任何类型的服务质量（QOS）保证，所以他们典型的被用作UBR和ABR连接。

8. 数据流径(Data Flow)

数据流径（Data flow）是指一条信息（数据）从源地到目的地采用的路径。在IP网络中，数据流径是一组通信，由一个源地址/任务和目的地址/任务的结合来识别，IP下 一个协议域，源和目的端口，那里的协议和端域能够是任何值。结果，所有符合这些值的特殊连接的通信被理论上组成一个数据流径。一个数据流径能够代表在两个主机之间的一个单个TCP连接，或它能代表所有在两个子网络之间的通信。IPSec保护被应用到数据流径中。

9. 数据流控制层(Data Flow Control Layer)

数据流控制层（Data Flow Control Layer）是IBM SNA建筑模型中的第5层（相当于OSI模型中的会话层），其决定和管理会话者的交互，特别是数据流径。

10. 数据链路层(Data Link Layer)

数据链路层（Data Link Layer）是OSI七层模型中的第二层，其提供数据同一个物理层的可靠传输。数据链路层与物理寻址、网络拓扑、行控制、错误通知、安排帧的交付和流控制。

11. 数据包(Data packet)

数据包（Data packet），也叫做呼叫包，是数据通过一个网络传输的一种格式。一个信息包包括数据本身和地址、错误检测和其它必要的信息来保证这个信息包完整地到达它预定的地址。

12. 数据接收器(Data Sink)

数据接收器（Data Sink）是指一个计算机或任何其它的网络设备有能力接收数据。

13. 数据流(Data Stream)

数据流（Data Stream）是指所有数据在一个单个的读或写操作下传输通过一个通信线。一个数据流能够从一个块传递实践中表现卓著，尽管块移动本身被认为是一个“流”（粗糙粒度的）。

14. 数据报(Datagram)

数据报（Datagram）是一个独立自主的数据实体，其运送充分的信息从源地发送到目的地而不依赖于在源和目的计算机的初期交换和传送网络。IP数据报在Internet中是基本的信息单元。用户数据报协议是路由数据报无连接通过IP网络的最流行的协议，当TCP进行可靠的数据传输时。术语单元、帧、信 息、分组和节也用于描述在OSI相关模型的各种层的逻辑信息组和在各种技术环中。

15. Datakit###

Datakit是与RBOCs的X.25广泛配置相似的私有分组转换系统。Datakit支持主机到主机的连接和对终端、打印机和主机的EIA-232连接。

16. 数据链路控制层(Data-link Control Layer)

数据链路控制层（Data-link Control Layer）是在IBM SNA建筑模型中的第2层（大概相当于OSI模型中的数据链路层）。它负责在一个特殊的物理链接上传输数据。

17. Datex###

Datex是在Scandinavia中为了数据通信的一个电路交换网络，是世界上的相似网络的相互连接。由于它在数据传输速度上的限制，大多数交易已经被转换到更有效的媒体,如Internet。

18. 数字音频视频委员会(DAVIC: Digital Audiovisual Council)

数字音频视频委员会(DAVIC)，在2001年解散，是一个通过发布开放平台和协议的最优协作规范来推进交互数字视听应用和服务一个工业组织，不仅仅通过地理边界也通过不同的应用程序、服务和产业。

19. 数据总线连接器(DB Connector: Database Bus connector)

数据总线连接器(DB connector)是一种用于连接串行和平行电缆到数据总线的连接器。数据总线连接器命名格式是DB-x，x代表连接器内电线的数量。每条线被连接到在 连接器中的一个栓上，但是在很多情况下，不是所有的栓都被分配一个功能。数据总线连接器被各种EIA/TIA标准定义。

20. 分贝(DB: Decibels)

分贝(db)是一个根据增益或损失测量相对功率比的单位。Db的单位根据基于10的对数的比率，典型地用瓦特来表示。例如，一个-3dB损失表示一个 50%的功率损失；一个+3dB读数表示一个功率加倍；10dB表示增加（或损失）的因数是10；20dB表示增加（或损失）的因数是100；30dB表示增加（或损失）的因数是1000。

21. 动态带宽分配(DBA: Dynamic Bandwidth Allocation)

动态带宽分配(DBA) 是指实际上自动增加或减少信道带宽而不中断链接来最优化带宽性能的过程。

22. 每毫瓦分贝(dBm: Decibels per milliwatt)

每毫瓦分贝(dbm)是与1毫瓦有关的功率测量单位。它被应用在无线电、微波和光纤上作为一个有效测量绝对功率的标准，因为它的性能来测量非常大和非常小的值是它的短处。dBm（或dBmW)和dBW是独立的电阻。因为它涉及到瓦特，它是一个绝对单位，用在测量绝对功率。它不应该和dB混淆，dB一个无量 纲的单位，其用来测量两个值之间的比率。0 dBm在1kHz频率，600欧姆的电阻下被定义为1mw。

23. dBmV###

dBmv是指在一个75-ohm的系统中1毫伏的分贝。dBmv的量度标准是一个与13.33毫伏特有关的功率比。dBmv在北美是用在有线电视（CATV）行业的射频（RF）功率的单位。

24. dBW###

dBW在分贝中表示对1瓦特的功率比。dBW在分贝中相对1瓦特来测量一个信号的能量。

25. 美国国防通信局(DCA: Defense Communications Agency)

美国国防通信局(DCA)，在SONET/SDH通讯中也叫做国防资讯系统局，是美国国防部负责计划、发展、守备、操作和支持指挥、控制、通信和为总统、 国防部部长，总参谋长，战斗支持官和其它在和平和战争条件下的国防机构的部门的需要服务的信息系统的一个战斗支持机构。

26. 数据通信信道(DCC: Data Communications Channel)

数据通信信道(DCC)在SONET/SDH通讯中是频带内数据通信信道。每个SONET/SDH帧包括两个数据通信信道(DCC)叫做会话DCC和线路 DCC为在NEs和管理系统之间传输管理信息。DCC能够使服务提供商的操作支持系统(OSS)来管理SONET/SDH网络元素(NE)而不需要一个昂 贵的频带外数据通信网络。

27. 数据国家代码(DCC: Data Country Code)

数据国家代码(DCC)是由ATM论坛发展的用于专用网络的两个ATM地址格式中的一个。DCC根据子网络模型寻址改写的，在那里这个ATM层负责网络层地址到ATM地址的映射。

28. 数据通讯设备(DCE: Data Communications Equipment)

数据通讯设备(DCE)是一个与数据终端设备相通信的设备。这个DCE提供一个到网络的物理连接，转发通信，和提供一个时钟信号用于DCE和DTE之间的同步数据传输。调制解调器和接口卡就是DCE的例子。

29. 分布式计算环境(DCE: Distributed Computing Environment)

分布式计算环境(DCE)是由Open Group发展的一组运行在不同平台创建分布式应用的开源技术。DCE设备包括：远程过程调用(RPC) ；安全服务；目录服务；实时服务；线程服务；分布式文件服务。

30. 色散补偿光纤(DCF: Dispersion Compensating Fiber)

色散补偿光纤（Dispersion Compensating Fiber）是一个有着相对色散的光纤，这种光纤被用在一个传输系统中。它通常用来抵消由光纤引起的色散。

31. 数据通信网络(DCN: Data Communications Network)

在电讯中，数据通信网络(DCN)是基于传输数据的目的的通信设备配置的频带外网络，和模拟信号是相对的。DCN提供网络元素和它们各自的操作支持系统 (OSSs)之间的连通性。它的基本功能是能够监督一个telco/PTT网络的状态但它也能够推动网络操作和管理，例如供应、计费、计划和服务保证。

32. 分布式组件对象模型(DCOM: Distributed Component Object Model)

分布式组件对象模型(DCOM)，由Microsoft发展的，先前叫做网络对象链接和嵌入（OLE），使软件组件能过通过一个网络直接通信。DCOM是为应用通过多重网络传输而设计的，包括这样的网络协议如HTTP。

33. 数字交叉连接系统(DCS: Digital Crossconnect System)

数字交叉连接系统(DCS)是一个数字信号或它的权利部分提供自动交叉连接的网络元素。

34. 离散余弦变换(DCT: Discrete Cosine Transform)

离散余弦变换(DCT)是一个与离散傅里叶(DFT)转换相似的傅里叶关系转换，但是仅使用真实的数字。它和一个DFT大致是等价的，而长度是它的两倍， 运行在偶对称的真实数据上（因为这个傅里叶转换是真实的，甚至作用也是真实和对偶的），在那里一些输入和/或输出数据的变量被半采样转换。

35. DVB/DAVIC协作联盟(DDIC: DVB/DAVIC Interoperability Consortium)

DVB/DAVIC协作联盟(DDIC)是一个在开发者成员和DVB-RCCL/DAVIC国际标准之间促进和支持产品协作的工业组织。一个独立的查证过 程允许DDIC成员提供测试和备有证明文件的协作产品，因此允许电缆网络操作者来选择可靠和高协作性的，基于标准的DVB解决方案。

36. 分布式数据管理(DDM: Distributed Data Management)

分布式数据管理(DDM)是在一个IBM SNA环境中3个SNA处理服务中的一个，其提供点对点的通讯和文件共享。

37. 国防数据网(DDN: Defense Data Network)

国防数据网(DDN)是由一个不机密网络和各种机密和顶级机密网络组成的美国军事网络。DDN是由在美国国防部门下的国防资讯系统局(DISA)操作和维持的。四个DDN子网络是：无机密通信的军事网络；1号机密通信国防安全网络；2号顶级机密通信国防安全网络；3号顶级机密/敏感资讯国防安全网络。

38. 动态域名(DDNS: Dynamic DNS)

和DNS相似，动态域名(DDNS)允许任何人占有一个Web或FTP服务器来广告一个公共名称给预期的用户。不像DNS仅仅与静态IP地址一起工作，DDNS与一个动态的IP地址一起工作，例如那些由一个ISP或其它DHCP服务器分配的地址。DDNS在家庭网络中很流行，它从它们的服务提供商那里典型地接收动态的、时刻改变的IP地址。使用DDNS，一个人简单地与一个供应者签约和在他们的主机上安装网络软件来监控它们的IP地址。

39. 拨号路由选择(DDR: Dial-on-demand Routing)

拨号路由选择(DDR)是一种技术，其能够使路由器应传输站点的要求自动开始和关闭一个电路转换对话。这个路由器假装保持活动的以便终端站点把这个会话当做活动的对待。DDR允许路由使用一个外部ISDN 终端适配器或调制解调器来通过ISDN或电话线。

40. 法定标准(De jure standard)

法定标准（de jure standard）是已经被标准团体，专业组织，行业组织，一个政府团体或其它组织认可的标准。

41. 丢弃允许(DE: Discard Eligible)

丢弃允许(DE)是在帧中继头部的一个位，如果帧必须被丢弃，发信号给一个交换机来选择被丢弃的帧来代替另一个帧而不需要丢弃允许(DE)位调整。

42. 失效(De-activation)

失效（De-activation）是指失去网络访问和对一个用户设备特权的能力的过程，回收的设备归属于其它用户设备。失效作为用户帐户移除的一部分出现，或作为用户设备交换激活的一部分。

43. 死锁(Deadlock)

死锁（deadlock）是一种情形，在那里两个或更多相竞争的动作在等待其它的完成，从而都不能完成。在计算机中，死锁是指一个特殊的情形，当时两个或更多进程都等待另一个释放资源，或多于两个的进程在等待一个循环链中的资源。死锁在多重处理中是一个公共的问题，在那里很多进程共享一个特殊类型的相互排外的资源例如软件或soft锁。

44. 数字设备公司(DECnet)

DECnet是由数字设备公司（数字的或DEC，现在是HP的一部分）发展和支持的一个协议组。一些版本的DECnet已经被废除了。原始的DECnet 允许两个直接连接的小型机通信。后来的版本通过增加附加所有权的支持和标准协议来扩展DECnet的功能。当前，两个版本的DECnet在广泛使用：DECnet Phase IV和 DECnet plus (DECnet V)。DECnet现在是HP OpenVMS的一部分。

45. DECnet Plus###

DECnet Plus，也叫做DECnet/OSI或DECnet V，定义一个执行3个协议组的分层的模型：OSI, DECnet, 和TCP/IP。DECnet Plus符合7层OSI相关模型和支持很多标准OSI协议。DECnet Plus提供与DECnet Phase IV 向后兼容和支持多种私有数字协议。DECnet Plus支持应用层，表示层和会话层的功能。DECnet plus的TCP/IP执行支持低层TCP/IP协议和使DECnet通信的传输能够通过TCP运输协议。

46. DECnet路由选择(DECnet Routing)

DECnet路由选择（DECnet Routing）是由数字设备公司在DECnet Phase III中引进的一个私有路由选择方案。在DECnet Phase V中，DECnet完成它到OSI路由选择协议(ES-IS和IS-IS)的转换。

47. 专用LAN(Dedicated LAN)

专用LAN（Dedicated LAN）是分配给一单个设备的网络段，其用在LAN交换网络拓扑中。

48. 专线(Dedicated Line)

专线（Dedicated Line）是一个通信线，其不确定地保存传输，而不转变为必需的传输。

49. 默认网关(Default Gateway)

默认网关(Default Gateway)是在一个网络中的路由器或交换机提供一个接入点到其它的网络。在企业中，这个网关是由这个网页提供的从一个工作站到外部网络路由这个通信的计算机。

50. 默认路由(Default Route)

默认路由（Default Route）是由一个路由器在一个给定的IP分组目的地址没有提供其它的已知路由而使用的网络路由。一个路由器通过寻找“最佳特定匹配”来决定哪个路由能够有效到达一个IP地址。

51. 防御讯息系统(Defense Message System)

防御讯息系统(DMS) 是在美国国防部门配置安全电子邮件和目录服务的部署。DMS通常与DMDS一个目录管理系统联合操作，其接收信息然后转发它，基于信息标准，对政党来说需要在一个信息上采取行动。这个结合已经成功迎合上面的梯形命令，因为政党行动不需要等待信息中心操作员来路由这个信息到恰当的信道。

52. 偏转路由(Deflection routing)

偏转路由(Deflection Routing)是一个基于分组交换的网络路由策略，其不需要分组缓冲。每个分组可以选择跟随哪个输出离开这个路由器，当时可能一个分组随着这些输出中的 一个被送出。但是，两个或更多分组可能想跟随相同的输出（可能是指分组中的一个争用）离开，于是仅其中的一个分组可能随着链接被送出，那时其它的分组随着 适当的输出被送出，尽管其它的链接不被分组选择。

53. 延迟(Delay)

延迟（Delay）是在一个发件者开始一个事务和这个发件者接收到第一个响应之间的时间。它也是一个分组通过一个给定的信道从源地址到目的地址传输的时间。

54. 数字以太网当地网络互连(DELNI : Digital Ethernet Local Network Interconnect)

数字以太网当地网络互连(DELNI)，与集线器相似，是由数字设备公司(DEC)在1980s生产的一个以太网通信产品。虽然它能应用在三种不同的应用中，但是最流行的一个是连接8个DS-200终端服务器到一单个以太网。

55. 需求优先(Demand Priority)

需求优先（Demand Priority）是一个用在100VG-AnyLAN中的多媒体接入方法，其使用一个集线器来处理多重传输需求和能够依照优先权来处理通信，使它能够对 服务时间敏感的通信如多媒体和视频有用。需求优先消除了空中分组碰撞，碰撞恢复和以太网络的典型广播通信。

56. 分界点(Demarc: Demarcation point)

分界点(Demarc)，也叫做划分点（POD），是一个网络点或一个通信公司的公共网络的终点和一个用户专用网络的起点的结合处。例如，在载波设备和用 户终端设备（CPE）之间的点，在那里这个电话公司的本地环网络终结，和电话公司或用户前提的配线连接。一个分界点也指输入最近点(MPOE)。

57. 解调(Demodulation)

解调（Demodulation）是返还一个被调的信号到它的最初形式的过程。调制解调器通过取得模拟信号和返还它到它的最初（数字）形式执行解调。

58. 解调器(Demodulator)

解调器（Demodulator）是在它们已经被天线接收以后聚集信号的一个设备。一个解调器是典型的从一个天线接收系统首先管理设备下行流。在一个系统传输的另一端相应的设备是调节器。

59. 分离器(Demux: Demultiplexer)

分离器(Demux)是一个用于分离两个或先前被一个兼容复用器组合并传输通过一个信号信道的多个信号的设备。

60. 目录驱动网络(DEN: Directory Enabled Networking)

目录驱动网络(DEN)是为网络用户、应用软件和在一个中心目录中怎样建立和存储信息来定义规格的一个创新。DEN定义一个面向对象的基于另一个新近创新标准的信息模型，公共信息模型(CIM)。两个模型被映射到被定义作为轻型目录访问协议一部分的目录中。

61. 密集模式组播(Dense Mode Multicast)

密集模式组播（Dense Mode Multicast）是一个组播能够用于为组播用户建立一个发送组的树的模式。它的对立面是稀疏组播。密集模式对很多节点将预定接收组播分组是完美的，因此大部分的路由器必须接收和转发这些分组（高密集的组）。

62. 拒绝(Deny)

拒绝（Deny）是ACL采取的一个行动，其意味着这个分组被丢弃了。

63. 移除(Deprovisioning)

移除（Deprovisioning）是一个除去现存用户帐户的过程，其包括用户帐户登记和设备失效。

64. 分布式编码规则(DER: Distinguished Encoding Rules)

分布式编码规则(DER)是一个基本编码规则的子集，其提供一个严密的方法来描述任何ASN.1值来作为一个8位字节的字符串。

65. 指定网桥(Designated Bridge)

指定网桥(Designated Bridge )是在每个LAN上的网桥提供最小根路径的成本。一个局域网的指定网桥是唯一允许向或从LAN上转发帧的网桥，因此它是这个指定网桥。

66. 指定端口(Designated Port)

指定端口(designated port）是连接它到指定网桥的端口。这个在网桥或交换机上的指定端口（接口）广告最优生成树hello信息（BPDU）到一个LAN区段。

67. 指定路由器(Designated Router)

指定路由器（Designated Router）是一个运行开放最短路径优先(OSPF)的路由器,其为一个多路接入网络产生LSAs，在运行OSPF时有其它特殊的功能。每个多路接入 OSPF网络最少有两个附加路由器，有一个路由器是被OSPF Hello协议推选的。这个指定路由器能够使多接入网络需要的邻接的数量减少，进而减少路由协议通信的数量和拓扑数据库的大小。

68. 目地地址(Destination Address)

目地地址（Destination Address）是一个接收数据的网络设备的地址。很多协议如IP、TCP和UDP都有为了分组路由选择和运输的目的地址的空间。

69. 目的节点(Destination Node)

目的节点(Destination Node)是一个有网络地址的节点，由相关的节点决定的，到那里一个现有的呼叫应该被发送。目的节点是一个端到端信道的或虚拟波长通道(VWP)的终端。这个目的节点可能或可能不是一个信令系统7个信令点的一个。

70. 决定性负载分配(Deterministic Load Distribution)

决定性负载分配（Deterministic Load Distribution）是在两个网桥通过一个电路组之间的分布式通信技术。它保证分组在源目的地对之间的分类和总是为一个源目的地对在一个电路组中的相同的区段转发通信，在一个给定的电路组配置下。

71. 德国检验试验室联合会(DFN: Deutsches ForschungsNetz e.V.)

德国检验试验室联合会(DFN)是一个德国学术和研究计算机网络。DFN从1984年开始运作。这个当前网络叫做"G-WiN"，它运行在 Gigabit速度下，和被10G链接连接到GEANT。

72. 文档交换体系结构(DIA: Document Interchange Architecture)

文档交换体系结构(DIA)定义了在一个SNA网络中文件的透明交换需要的协议和数据的格式。DIA是3个IBM SNA处理服务中的一个。

73. Diag100###

Diag100是一个诊断软件效用，其测试在一个实验环境中的卡。它伴随NS4/100或者FNIC 10/100。短语“提供Diag100 诊断软件”意味着这个产品伴随有Diag100-一个诊断软件效用，一个程序。

74. 拨接备份(Dial Backup)

拨接备份(Dial backup)是提供相对WAN停工期的保护的特征，通过允许网络管理员来设定一个备份序列线通过一个电路交换连接。

75. 点对点拨号(Dial Peer)

点对点拨号( Dial peer），也叫做可设定地址的呼叫端点，是一个能够发起或接收在一个电话网络中的呼叫的设备。在IP语音(VoIP)网络拨号点中包括VoIP- capable电脑，路由器和网络内的网关。POTS点对点拨号包括传统的电话网络设备例如电话设置，蜂窝电话和传真机。

76. 拨号线路(Dial-up Line)

拨号线路（Dial-up Line）是一个通信电路，其由一个使用电话公司网络的电路交换连接确定。

77. 直接拨入/被叫号码识别服务(DID/DNIS: Direct Inward Dialing/Dialed Number Identification Service)

直接拨入/被叫号码识别服务(DID/DNIS)是指当一个呼叫到达到一个ACD或PBX时的服务，这个载波在长途中继线中发送一个数字编码。特殊地，这个值是用户拨的特殊号码。通过映射每个可能的编码有一个内部分机，这个交换机能够提供直接向内拨号(DID)。ICM使用DID/DNIS值来指定服务， 技能组或特殊代理给应该发送这个呼叫的交换机。这个交换机在呼叫到达时和适当地分配这个呼叫时从长途中继线中读值。

78. 直接向内拨号(DID: Direct-inward-dial)

直接向内拨号(DID)是由电话公司提供的服务，其能够使呼叫者直接拨号到在一个专用分组交换机（PBX）内的一个分机而不使用自动总机。直接向内拨号(DID)是呼叫，在其中网关使用拔号识别服务(DNIS)产生呼叫，和提示拨附加的位的提供是相对的。

79. 差分编码(Differential Encoding)

差分编码（Differential Encoding）是一个数字编码技术，为何一个二元的值用一个信号改变而不用一个特殊信号级别表示。

80. 差分曼彻斯特编码(Differential Manchester Encoding)

差分曼彻斯特编码(Differential Manchester Encoding)是一个数字编码方案，在那里一个中央跳变被用于时钟信号，每个跳变的起始位指示0.这个编码方案被IEEE 802.5和令牌网络应用。

81. 差分服务(Differentiated Service)

差分服务（Differentiated Service）是指在网络中通过雇用一小的，定义明确的，各种服务能够建立的积木式组件在不同的服务质量（QoS）中提供服务。

82. 德国工业标准连接器(DIN Connector: Deutsche Industrie Norm connector)

德国工业标准连接器(DIN Connector)是直径13.2 mm,在从3到15个的插脚规格上都是可用的。德国工业标准连接器被用在一些苹果机和与IBM的个人计算机兼容的计算机上，和在一些网络处理器面板上。

83. 德国工业标准(DIN: Deutsche Industrie Norm)

德国工业标准(DIN)是一个德国国家标准组织。

84. 直接广播地址(Directed Broadcast Address)

直接广播地址（Directed Broadcast Address），与广播地址相同，是一个Internet协议地址，其指定了在一个特定网络中的“所有主机”。一个直接广播的单一拷贝被发送到一个指定的网络，在那里它被广播到在那个网络中的所有终端。

85. 特定搜索(Directed Search)

一个特定搜索（directed search）被用于测定资源的连续存在性和获得特定节点路由信息。

86. 有向树(Directed Tree)

有向树（Directed Tree）是一个用于定义数据流或流程的逻辑结构。数据流的源点是根。数据流是单向分支离开根部到达目标，这个目标就是有向树的叶子。

87. 目录服务(Directory Services)

目录服务（Directory Service）是一种类型的应用，其存储和组织关于一个计算机网络用户和网络共享的信息，其允许网络管理员用户到共享的接入。另外，目录服务作为在用户和共享资源之间的一个提取层。

88. 防御讯息系统局(DISA: Defense Information Systems Agency)

防御讯息系统局(DISA)，以前叫做DCA，是美国国防部负责计划、发展、守备、操作和支持指挥、控制、通信和为总统、国防部部长，总参谋长，战斗支持官和其它在和平和战争条件下的国防机构的部门的需要服务的信息系统的一个战斗支持机构。

89. 发现模式(Discovery Mode)

发现模式（Discovery Mode），也叫做动态配置，是一种方法，通过它一个AppleTalk端口从一个操作节点获得关于附加网络的信息，然后使用这个信息来配置自身。这个发现模式使用appletalk 发现端口次命令发现设置和重置。

90. 退出请求(Disengage Request)

退出请求（Disengage Request）是在H.323协议中的一个信息，由网关设置的这个计费信息令牌（其包括呼叫的持续时间）当一个呼叫结束时给看门人。

91. 距离矢量(Distance Vector)

距离矢量（Distance Vector）是两个路由算法中的一个。另一类是链路状态路由选择。基本上，路由协议基于距离矢量算法根据目的地的远近来决定最好的路径，当链路状态协议是可以使用更高级的方法根据链路的变化，例如带宽，延迟，可靠性和负载。距离矢量协议根据距离的远近来决定最好的路径。距离可能用跳数或一个 metrics运算的组合来代表一个距离值。

92. 距离矢量路由算法(Distance Vector Routing Algorithm)

距离矢量路由算法（Distance Vector Routing Algorithm）是一种类型的路由算法，其在一个路由中重申跳数的个数来寻找一个最短路径生成树。距离矢量路由算法号召每个路由器在每次更新时发送它 的整个路由表，但是仅仅给它的邻居。距离矢量路由算法倾向于路由循环，但是比链路状态路由算法计算更简单。也叫做bellman-ford路由算法。

93. 延迟失真(Distortion Delay)

延迟失真（Distortion Delay），也叫做组延迟，是指在一个传输系统输出时，在一个波形由两个或更多频率波部分组成，由于不同频率部分到达的时间不同而引起的失真。

94. 分布式计算环境(Distributed Computing Environment)

分布式计算环境(DCE)是一个软件系统，是在1990s早期由一个包含阿波罗计算机、IBM、数字设备公司和其它（不是Hewlett-Packard 的一部分）的社团发展的。DCE为发展客户/服务器提供一个框架和工具包。这个框架包括一个远程过程调用(RPC)机制叫做DCE/RPC，一个命名（目 录）服务，一个认证服务和一个分布式文件系统(DFS)。

95. 分布式控制器(Distributed Director)

分布式控制器（Distributed Director）是一个分布式Web通信方法，为了确定一个客户的最佳Web服务器，其有效地引入帐户Web服务器和相关的客户到服务器的拓扑距离。分布式控制器使用控制器响应协议，来为BGP和IGP路由表Metric查询DRP服务器代理。

96. 目录信息树(DIT: Directory Information Tree)

目录信息树(DIT)是一个整体的树的输入，与在OSI X.500目录中的信息对象是相应的。

97. DIX: DEC, Intel,###  ### 和Xerox###

DIX，三个公司名字的缩写：DEC, Intel, 和Xerox，是指以太网版本2或以太网II帧，所谓的DIX帧。以太网版本2是由三个领导性的公司定义的，是当今最普遍使用的以太网。以太网版本2成帧 与IEEE 802.3中的使用的原始的成帧不同在于在目的和源地址之后的它的2个8位字节域的解释。以太网版本2成帧，那个域被当作一个以太类型和立即确定一个上层 协议。例如，一个0x0800信号的以太类型值，一个IP数据报包压缩。同样地，一个以太类型的0x0806指出一个地址解析协议（ARP）帧。由于原始 成帧用在IEEE 802.3中，那个区域被当作一个分组长度，一个IEEE 802.2首部被期待遵循这个长度域。

98. 数据链路连接标识符(DLCI: Data-link Connection Identifier)

数据链路连接标识符(DLCI)是在帧中继网络中指定了一个PVC或SVC值。在基本的帧中继规格中，DLCIs是局部有意义的（连接的设备可能使用不同 的值来指定相同的连接）。在LMI扩展规格中，DLCIs是全球有意义的（DLCIs指定个别终端设备）。

99. 延时锁定回路(DLL: Delay Locked Loop)

延时锁定回路(DLL)支持设备之间的高带宽数据率。这些DLLs是提供电路零传播延迟的电路，在遍及一个设备的输出时钟信号之间是低时钟倾斜，和先进的时钟域控制。这些独立DLLs能够被用作执行一些电路，其提高和简单化了系统标准设计。

100. 数据链路交换Plus(DLSw+: Data-link Switching Plus)

数据链路交换Plus(DLSw+)是指Cisco在SNA和NetBIOS通信传送中执行的DLSw标准。DLSw+超过了包括现有Cisco RSRB执行的高级特征的标准，和提供额外的功能来增加数据链路交换的全部可测量性。

101. 附属逻辑单元(DLU: Dependent LU)

附属逻辑单元(DLU)，一个用在IBM SNA APPN中的术语，是一个依赖于SSCP，为带有其它逻辑单元的会话的确立来提供服务的逻辑单元。

102. 从属逻辑单元请求器节点(DLUR Node)

从属逻辑单元请求器节点（DLUR Node）是一个终端节点(EN)或一个网络节点(NN)，其在APPN网络中执行从属逻辑单元请求器(DLUR)部分。

103. 从属逻辑单元请求器(DLUR: Dependent LU Requester)

从属逻辑单元请求器(DLUR)是客户部分从属逻辑单元请求器/服务器到IBM APPN的增进。这个DLUR部分位于APPN Ens和NNs中，其通过来自DLUS的安全服务支持邻近的DLUs。

104. 从属逻辑单元服务器节点(DLUS Node)

从属逻辑单元服务器节点（DLUS Node）是一个网络节点，其在APPN网络中执行从属逻辑单元服务器成分。

105. 从属逻辑单元服务器(DLUS: Dependent LU Server)

从属逻辑单元服务器(DLUS)是是服务器部分从属逻辑单元请求器/服务器到IBM APPN的增进。这个DLUR部分通过一个APPN网络提供SSCP服务到DLUR节点。

106. 直接存储器存取(DMA: Direct Memory Access)

直接存储器存取(DMA)是指从一个外围设备中传输数据，例如一个硬盘驱动，到内存中而不需要数据通过中央处理器。DMA高速传输数据到内存中而不需要经过处理器。

107. 目的介质存取控制(DMAC: Destination MAC)

目的介质存取控制(DMAC)是在一个分组中指定在目的地址域的MAC地址。

108. 分布式管理任务组(DMTF: Distributed Management Task Force)

分布式管理任务组(DMTF，以前叫做“桌面管理任务组”）是一个发展、支持和维持PC系统和产品的系统管理标准的工业联盟，其目的是为了减少所有权的整体成本。这些包括桌面管理任务组(DMI)，当今最广泛使用的管理标准。

109. 被叫号码(DN: Dialed Number)

被叫号码(DN)是一个呼叫者拨号发起一个呼叫的电话号码。

110. 识别名(DN: Distinguished Name)

识别名（Distinguished Name）在基于X.500协议的OSI目录中是一个全球性的、权威性的一个输入名。

111. 数字网络架构(DNA: Digital Network Architecture)

数字网络架构(DNA)是由数字设备公司发展的网络架构，现在是HP的一部分。这个产品包括DNA（包含通信协议）被共同归诸于DECnet。

112. DNA: DoNotAge###

DoNotAge是LS Age域中最重要的位。LSAs使DoNotAge位设置不是陈旧的，因为它们在OSPF路由器链接状态的数据库中，其意味着这些LSAs不需要每30分钟更新一下。

113. 数据网识别码(DNIC: Data Network Identification Code)

数据网识别码(DNIC)是一个X.121地址的一部分。DNICs被划分为两个部分：第一部分指定了这个定址PSN位于的国家，第二部分指定了PSN本身。

114. 被叫号码识别服务(DNIS: Dialed Number Identification Service)

被叫号码识别服务(DNIS)是主干线的特征，在那里这个被叫号码被识别；这个被叫号码信息被用于路由这个呼叫到适当的服务中。DNIS是一个与免税指定服务一起使用的服务，这是为何呼叫被设置成特定免税服务号码被路由到适当的区域，在内部一个公司来响应。

115. 域名服务器区域(DNS zone: Domain Name Server zone)

域名服务器区域(DNS zone)是在DNS树中的授权点。它包括来自向下的特定点的所有名称，除了那些其它的权威区域。权威的名称服务器能够被其它DNSs要求做名称到地址的 转换。很多域名服务器能够在一个组织之内存在，但是仅那些被根域名所知的能够被通过Internet的用户访问。其它的域名服务器响应仅仅是内部访问。

116. 信息交换中的网络安全（DNSIX: DOD Network Security for Information Exchange）###

信息交换防御智能信息系统网络安全处(DNSIX)是美国防御智能局定义的一个网络安全需求的收集。

117. DOCSIS电缆调制解调器(DOCSIS CM: DOCSIS Cable Modem)

DOCSIS电缆调制解调器(DOCSIS CM)是一个基于DOCSIS标准的电缆调制解调器，其从家庭中通过TV电缆连接到Internet中。

118. DOCSIS有线电缆调制解调器终端系统(DOCSIS CMTS: DOCSIS cable modem termination system)

DOCSIS有线电缆调制解调器终端系统 (DOCSIS CMTS)，也叫做有线电缆调制解调器终端系统(CMTS)，是一个特别设计的路由器或数据网络的一个网桥。CMTS位于服务提供商的头部和用于聚集来自多重电缆调制解调器然后与中枢网络相连接。

119. DOCSIS配置文件(DOCSIS Configuration File)

DOCSIS配置文件（DOCSIS Configuration File）是一个DOCSIS电缆调制解调器中包含配置参数的文件。这个电缆调制解调器在启动时使用TFTP协议获得这个文件。

120. 国防部(DoD: Department Of Defense)

国防部(DOD)是美国负责国家防御的政府机构。DOD经常资助通信协议的发展。

121. 域(Domain)

域(Domain）意味着网络中的很多不同东西：1.在Internet中，域是指一个web站点的URL。2.在虚拟局域网（VLAN）中，它是涉及基 于机构类型或地理的网络分组生成的阶层树的一部分。3.在SNA中，它是一个SSCP和它控制的资源。4.在IS-IS中，它是一个网络的逻辑设置。

122. 域名(Domain Name)

域名(Domain Name）是在Internet定义一个web站点的唯一的名字。域名总是有2个或更多的部分，彼此用点分开。一个特定的机器可能有多于一个的域名但是一 个特定的域名仅指向一台机器。例如，这些域名：javvin.com, www.networkdictionary.com，但是每个域名能够涉及到不止一台机器。

123. Dongle###

在计算机网络中，一个Dongle是一个短的网络电缆，其连接一个PCMCIA适配器到一个网络电缆。Dongle 典型地从属于Ethernet网络上每个RJ-45连接器或拨号网络上的一个RJ-11连接器。Dongles趋向于运行不多于6英寸。这个术语 "dongle"也已经在USB网络中流行，指USB电缆从一个USB外围设备中扩展。

124. 点地址(Dot Address)

点地址（Dot Address），也叫做点符号和四部点符号，是指IP地址中公共的符号，以n.n.n.n的 形式，其中每个数n代表，在十进制中，4字节IP地址中的一位。

125. 十进制点符号(Dot-decimal Notation)

十进制点符号（Dot-decimal notation），也叫做 Dotted decimal notation或dotted quad notation，是一个使用基于10（十进制）而不是十六进制数记下8位位组串的方法。增加点允许个别8位位组值的从容分离。例如， 255.255.255.255是在十进制点符号中。IPv4地址普遍的写成或标示成十进制点符号。

126. 十进制点符号(Dotted Decimal Notation)

十进制点符号（Dotted Decimal Notation），也叫做Dot-decimal notation或dotted quad notation，是32位整数的句法表现，其有4个8位数组成，它们分开写成基于10的周期（点）而不是十六进制数。它通常代表在Internet中的 IP地址，例如在192.67.68.35.中。

127. 下载(Download)

下载（Download）是指从一个远端网络区域移出文件到一个本地计算机的过程。有几种方法可以在Internet中做这个。HTTP, FTP和e-mail附件是最常用的。

128. 下行流(Downstream)

在网络接入中，来自用户的观点，下行流（downstream）是指通信由终端服务提供商操作和到用户终结。换句话说，下行流通信流向是向用户计算机的。另一方面，上行流网络通信是从本地计算机流向远端目的地的。通信在大部分网络流中是上行流和下行流同时进行。

129. 每百万单位的缺点数(DPM: Defect Per Million)

每百万单位的缺点数(DPM)，也叫做DPMO，制定的一个测量标准，在任何处理过程中关联失败的预期规范。每百万单位的一次失败数。

130. 每百万机会的缺点数(DPMO: Defects per million opportunites)

每百万机会的缺点数(DPMO)，也叫做DPM，制定的一个测量标准，在任何处理过程中关联失败的预期规范。每百万单位的一次失败数，标准化的成果指定1 DPMO。

131. 分布式关系型数据库架构(DRDA: Distributed Relational Database Architecture)

分布式关系型数据库架构（Distributed Relational Database Architecture）是一个为IBM所有的关系数据库架构。

132. Drop###

一个Drop是在多点信道中的一个点，在那里一个到网络设备的连接被建立。

133. 引入电缆(Drop Cable)

引入电缆（Drop Cable）是连接一个网络设备（例如计算机）到一个物理媒体的电缆，例如以太网收发器。如果是全规格的最大长度是47米。

134. 插分(Drop-and-Insert)

插分（Drop-and-Insert）是使一单个T1接入线携带数据和语音两者通信的一个特征。MAX使用一个T1接入线预先分配的部分来用于LAN网 络的固定和转换电路。这个线的保留部分用一个T1接口能够到达一个PBX，这个PBX为了语音能够存取固定和转换电路两者。插分也能够用于共享在MAX和 出了PBX之外的设备之间存取线带宽，例如一个信道银行或T1多用器。

135. 目录系统代理(DSA: Directory System Agent)

目录系统代理(DSA)是一个软件，其为一个目录信息基础的一部分提供X.500目录服务。一般地，每个DSA负责一单个机构或机构单元的目录信息。

136. 目的服务存取点(DSAP: Destination Service Access Point)

目的服务存取点(DSAP)是一个到网络协议堆的上层的个人的或组织的地址。DSAP是一个8位的域，其允许LLC层保持通过一个IEEE 802 LAN环境多连接的跟踪。

137. 差分服务代码点(DSCP: Differentiated services code point)

差分服务代码点(DSCP)是一个在一IP分组中的域，其使不同水平的服务分配到不同的网络通信中。DSCP是一个6位的域，其是IP优先（3位）和3位 扩充的结合，就像RFC 2474定义的一样。DSCP能够被在网络中的每个分组标示为一个DSCP码和分配给它适当的服务水平。为了与仅支持IP优先遗留服务器一起工作， DSCP值被使用，因为它们与IP优先域是兼容的。

138. 色散位移光纤(DSF: Dispersion-shifted fiber)

色散位移光纤(DSF)是设计有零点离差近1550 nm的一种单模式光纤。

139. 数字用户线接入复用设备(DSLAM: Digital Subscriber Line Access Multiplexer)

数字用户线接入复用设备(DSLAM)，是在DLS技术架构中的一个系统，链接和聚集很多用户DSL连接到一单个高速率ATM线。为了启动DSL技术，服务提供商必须有一个位于它们网络中的DSLAM与在最终用户位置的用户终端设备交互。

140. 交付状态通知(DSn: Delivery Status notification)

交付状态通知(DSn)是信息返回给发起人指示一个e-mail信息的交付状态。一个寄件人能够要求三种交付状态通知：延迟、成功、失败。

141. 特定域部分(DSP: Domain Specific Part)

特定域部分(DSP)是一个NSAP格式的ATM地址的一部分，其包括一个区域标示符、一个站点标示符和一个选择器字节。

142. DSPU集中(DSPU concentration)

DSPU集中（DSPU concentration）是一个Cisco IOS特征，其能够使一个路由器对SNA PU 2节点起到一个PU集中器的作用。DSPU集中在路由器上在上行流主机上简单化了PU定义的工作，当为下行流PU设备提供额外的适应性和灵活性。

143. 下行流物理单元(DSPU: Downstream Physical Unit)

下行流物理单元(DSPU)，一个在 IBM SNA中的术语，是一个位于来自主机下行流的PU。

144. 数据设备就绪(DSR: Data Set Ready)

数据设备就绪(DSR)是指EIA/TIA-232接口电路被激活，当DCE被通电和准备好使用时。

145. 动态源路由(DSRFLOW)

DSRFLOW，对动态源路由(DSR)的流状态扩展，提供源路由的所有优点，而没有大部分每个分组的与源路由相连接开销。它通过允许大部分分组被发送而 不需要一个源路由标题工作，从而充分地较少开销。确实，DSR的其中一个优点是分组的源路由越长，分组的头部就变的越大。这个技术应用被叫做固有源路由选择。

146. 数据服务单元(DSU: Data Service Unit)

数据服务单元(DSU)，也和CSU一起被提及，记作CSU/DSU，是用在数字传输中的设备，其使在一个DTE设备上的物理接口连到一个传输设备，例如T1或E1。这个DSU也负责例如信号定时的功能。

147. 1阶数字信号交叉连接(DSX-1)

1阶数字信号交叉连接(DSX-1)是一个标准，其定义了电压、脉冲宽度和插头和为连接DS-1(T1)信号的孔。

148. 数据终端设备(DTE: Data Terminal Equipment)

数据终端设备(DTE)是一个在X.25网络中的末端节点。DTE是在一个用户网络接口的设备，其作为一个数据源、目的或两者服务。DTE通过一个DCE 设备和典型地使用由DCE产生的时钟信号连接到一个数据网络。CTE包括设备如计算机、协议转换器和多工器。

149. 指定运输列表(DTL: Designated Transit List)

指定运输列表(DTL)是一个节点列表和可选链接IDs，其完全指定一通过单个PNNI对等组的通道。

150. 双音多频继电器(DTMF relay: Dual-tone Multifrequency Relay)

双音多频继电器(DTMF)是为何一个本地语音通过IP网关被DTMF数字（在一个呼叫中）收听的机制，当时压缩作为或RTP或H.245分组发送它们通过IP网关的远程话音，其重建DTMF数字和预防由于压缩造成的数字丢失。

151. 双音多频(DTMF: Dual Tone Multifrequency)

双音多频(DTMF)，也叫做接触语音或拨号语音，被用于通过在语音频率带到呼叫转换中心的电线的电话信令。DTMF是起源于当电话中一个按键被按下时的音调，基本上用于美国和加拿大。DTMF是多频移位键控系统(MFSK)的一个例子，由ITU-T推荐Q.23标准化的。

152. 数据终端就绪(DTR: Data Terminal Ready)

数据终端就绪(DTR)是指EIA/TIA-232电路被激活而让这个DCE知道什么时候这个DTE已准备好发送和接收数据。

153. 用户代理目录(DUA: Directory User Agent)

用户代理目录(DUA)是一个软件接入X.500目录服务，为了目录用户的利益。这个目录用户能够是一个人或其它软件要素。

154. 双循环计数环(Dual Counter-rotating Rings)

双循环计数环（Dual Counter-rotating Rings）是一个网络拓扑，在其中两个数据通道，它们的目标是彼此相反的，存在于一个标记传送网络。FDDI和CDDI是基于这个概念的。

155. 双归属(Dual Homing)

双归属（Dual Homing）是一个网络拓扑，在其中一个设备以独立接入点（附属点）的方式被连接到网络。一个接入点是主连接，另外一个是备用连接，其在主连接失败的情况下被激活。

156. 双协议栈(Dual Stack)

双协议栈 ( Dual Stack）主机是Internet主机，其提供两个离散的网络层。这里的术语栈是指协议栈或用在计算机网络软件中的协议组。双协议栈主机运行当前的两个协议标准，IPv4和下一代Internet层，IPv6。

157. 扩散更新算法(DUAL: Diffusing Update Algorithm)

扩散更新算法(DUAL)是一个用在增强IGRP中的集中公式，其在每个及时通过一个路由计算时提供冗余功能操作。允许路由器包括在一个拓扑变化中来同时同步，当包括路由器不被改变影响。

158.  双宿工作站(Dual-homed Station)

双宿工作站（Dual-homed Station）是一个附加到多重FDDI环来提供冗余的设备。

159.  数字视频广播(DVB: Digital Video Broadcasting)

数字视频广播(DVB)工程是一个在广播、制造、网络操作相关法规工作为模拟到数字广播的转换确定公共国际标准和领域的行业联盟。

160.  数字视频广播-电缆(DVB-C)

DVB-C代表数字视频广播-电缆，它是DVB的数字电视通过电缆的广播传送的欧洲协会标准。这个系统传送一个MPEG-2家庭数字音频或视频流，使用一个正交幅度调制（QAM）用信道译码调制。

161.  数字视频广播-人造卫星(DVB-S)

DVB-S代表数字视频广播-人造卫星，它是DVB的一个变量。它意味着基本的（大部分用在欧洲）通过卫星完成的数字TV广播方法。

162.  数字视频广播-陆地(DVB-T)

DVB-T代表代表数字视频广播-陆地，它是数字陆地电视广播传输的DVB欧洲联盟标准。这个系统传输是一个MPEG-2家庭数字音频/视频流，使用带有连接通道编码的OFDM调制。

163.  数据语音视频集成(DVVI: Data, Voice, Video Integration)

数据语音视频集成(DVVI)是指通过一个单一网络提供数据语音和视频服务。这个术语通常用于一单一企业网络。根据一个服务提供者的情况，它通常被叫做三合一服务（triple play）。

164.  密集波分复用(DWDM: Dense Wavelength Division Multiplexing)

密集波分复用(DWDM)是一种光学技术，其通常用于通过现有的骨干中枢来增加带宽。DWDM通过在相同光纤中的不同波长的多重信号的自动结合和传输工作。结果，一个光纤被转换成多重虚拟光纤。DWDM的一个重要优点就是它的协议和比特率是独立的。基于DWDM的网络能够在IP, ATM, SONET/SDH, 和Ethernet协议中传输数据，和在100 Mb/s到2.5 Gbps的带宽之间处理比特率。

165.  数据交换接口(DXI: Data Exchange Interface)

数据交换接口(DXI)是在RFC 1483中描述的一个ATM论坛规范，它定义一个网络设备例如一个网桥、路由器或集线器是怎样有效地作为一个FEP通过与一个特殊DSU的接口连接，其执行分组分割和重新组装产生作用到一个ATM的网络。

166.  动态适应路向选择(Dynamic Adaptive Routing)

动态适应路向选择（Dynamic Adaptive Routing）是指基于对当前实际网络的情况的感觉和分析的通信的动态路由选择，不包括路由选择决定被预先确定信息下的情况。

167.  地址解析决议(Dynamic Address Resolution)

地址解析决议（Dynamic Address Resolution）是使用一个地址解析协议来决定和按要求存储地址信息的过程。

168.  动态缓存管理(Dynamic Buffer Management)

动态缓存管理（Dynamic Buffer Management）是使用帧中继和ATM服务模块为分配和缩放通信输入或在VC基础上预先留下一个节点的方案。
这个WAN转换动态分配缓冲器到基于当 前通信数量和服务水平协定的独立虚电路中。这个可用缓冲器的深度挖掘能轻易的适应进入节点的大量爆发的通信。

169.  动态路由选择(Dynamic Routing)

动态路由选择（Dynamic Routing），也叫做自适应路由，是一类根据网络拓扑或通信的变化自动调整的路由选择。

170. 动态转换呼叫(Dynamic Switched Call)

动态转换呼叫(Dynamic Switched Call)是一类VOIP呼叫,动态确定通过一个基于拨号电话号码的分组数据网络。
