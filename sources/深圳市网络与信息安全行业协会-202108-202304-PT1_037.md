# 速来报名！网络空间安全专业职称评审即将截止~

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0Mzk0NDQyOA==&mid=2247505861&idx=1&sn=4630d4e0ea2426b15b5a934978601892&chksm=fb012c46cc76a5502e738bd080c05398c2bbfe8f36b720c1fa13d12c72e9abce1901c73e0dd6&scene=126&sessionid=1681322534#rd](http://mp.weixin.qq.com/s?__biz=MzU0Mzk0NDQyOA==&mid=2247505861&idx=1&sn=4630d4e0ea2426b15b5a934978601892&chksm=fb012c46cc76a5502e738bd080c05398c2bbfe8f36b720c1fa13d12c72e9abce1901c73e0dd6&scene=126&sessionid=1681322534#rd)

**申报时间**  
  

**2022年度网络空间安全专业职称评审将于2月28日截止。**

2月28日24时前，申报单位须在申报系统中将申报记录提交评委会办公室受理，未提交评委会办公室受理的申报记录无法继续申报本年度职称评审。

3月9日17时前，申报单位需在申报系统中将退回修改的申报记录提交至评委会办公室受理，退回修改的申报记录未提交至评委会办公室受理的，无法继续申报本年度职称评审。

  

深圳市网络与信息安全专业高级职称评审委员会受深圳市人力资源和社会保障局指导、管理和监督，由深圳市网络与信息安全行业协会组建，负责深圳市网络空间安全专业职称领域的初级、中级、副高级年度评审工作。自2019年起，协会已承接2020年度、2021年度共两年度的网络空间安全专业职称评审工作。

申报本专业职称有：市不动产登记中心、 市国家气候观象台、北大深圳研究生院、市卫生健康发展研究和数据管理中心、深信服、博通智能、任子行、华为、永达电子、开源网安、网安计算机等企事业单位。
