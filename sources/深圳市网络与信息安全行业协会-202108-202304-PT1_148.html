第4版 · 全!新!改!版!


斯元商业咨询今日正式发布「Emerging Technology Vendor Index · 网安新兴赛道厂商速查指南」（2022年）第4版。



定位：网安新兴赛道及厂商速查

内容：赛道中英文名称，国内、国际厂商索引，代表性厂商

受众：企业安全负责人、渠道合作伙伴、安全营销人群、投资机构、行业咨询分析机构，及其他网络安全行业从业者


此前斯元商业咨询面向国内安全厂商启动了「Emerging Technology Vendor Index · 网安新兴赛道厂商速查指南」（2022年）（如下简称“速查指南”）第4版的公开调研工作，得到了国内厂商的积极参与及反馈。斯元商业咨询梳理优化本次调研数据，并结合网安技术与产品最新的发展动态，正式发布第四版速查指南报告。


本指南属于斯元商业咨询Cyber Security Billboard系列报告之一。


第4版速查指南共收录144个新兴产品赛道，较之第3版新增了17个产品赛道，同时，对厂商收录情况进行了调整优化，共收录国内外厂商1300+家。




关键看点

展示方式保持不变

采用中英文对照目录索引，每个赛道均独立页面展示，厂商名字以文字形式呈现，便于使用者快速检索定位、分析者按图索骥。

优化调整厂商收录

进一步提升厂商收录的技术要求，结合调研填写情况，对厂商收录情况进行了增删调整。新增收录了近100+国内厂商，大幅度优化删减了300+技术赛道聚焦不足的国内厂商，新增收录200+国际创新技术厂商。

关于斯元商业咨询





斯元商业咨询是国内首家专业网安行业加速器机构，辅助网安初创企业提升营销能力，助力业务加速成长。斯元的服务内容包括业务战略梳理、品牌宣传与曝光、GTM策略规划、销售体系与人才梯队搭建、国际国内竞品分析等。此外，斯元还为安全企业的战略协同合作与并购、国内企业业务出海探索、投资机构投后管理与服务及其他安全行业生态拓展提供咨询与服务。




关于深圳市网络与信息安全行业协会






深圳市网络与信息安全行业协会（SNISA），是深圳市网络安全行业的权威组织，是中国网络安全审查技术与认证中心（CCRC）在深圳唯一授权工作站，是经深圳市人力资源和社会保障局核准，开展网络空间安全工程技术专业职称评审工作的社会组织。






「Emerging Technology Vendor Index · 网安新兴赛道厂商速查指南」为斯元商业咨询「Cyber Security Billboard」系列报告之一，并非年度型单次总结报告，而是随着业内赛道和厂商更新情况，1年多次不定期动态更新迭代，为企业安全负责人、渠道合作伙伴和安全从业者提供最实时准确的信息查询检索。
