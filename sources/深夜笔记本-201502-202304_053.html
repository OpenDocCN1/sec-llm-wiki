iP归属地的查询网上存在很多在线网站批量查询，但是这些在线网站一般都有数量限制。如果使用python爬虫可能会被ban ip，而且总体爬取的效率不高。今天在网上发现一个比较好用的python库，可以高速度地完成ip归属地查询的任务。


使用的库：
https://github.com/animalize/qqwry-python3


版本限制：
这个库目前只支持python3.0以上


使用方法：
首先在你的本地python环境中装入一个库qqwry-py3，你可以直接使用下面的命令安装：

pip install qqwry-py3

安装完成后你还需要一个纯真ip数据库：

https://www.cz88.net/

下载完成后是一个setup.zip的压缩文件，解压后安装即可。其实我们能用到的只有安装后生成的qqwyr.dat文件，这个文件存放了很多ip及其对应的归属地。

为了更方便的使用，我只把qqwyr.dat文件从虚拟机拖回了本地，采用下面的代码读取ip并且查询归属地：

from qqwry import QQwryq = QQwry()q.load_file('qqwry.dat')f = open('ip.txt','r',encoding='utf-8')for i in f.readlines():    i = i.strip()    res = q.lookup(i)    #print(i)    print(i+"    "+res[0])

经过测试，发现读取速度很快，5000个ip大概需要10秒
为了更方便使用，对代码进行稍微改进：

from qqwry import QQwryimport argparseparser = argparse.ArgumentParser(description='帮助信息')parser.add_argument('-f','--file',help="输入一个ip文件",default='')args = parser.parse_args()def ipquery(file):    q = QQwry()    q.load_file('qqwry.dat') #载入纯真数据库    f = open(file,'r',encoding='utf-8')    outfile = open('result.xlsx','w+',encoding='utf-8')    for i in f.readlines():        i = i.strip()        res = q.lookup(i) #调用lookup查询ip归属，返回元组类型        outfile.write(i+"        "+res[0]+"\n") if __name__ == '__main__':    if args.file != "":        file1 = args.file        ipquery(file1)    else:        print("You must input a file!")
