    最近一直在忙于工作不太好更新公众号，今天给大家分享一点审计代码的一些个人的小技巧与总结 可能是老生常谈的话，但是对于新手可能存在一些帮助

  

漏洞名称  密码硬编码

    密码明文存储 password 、pass、等，对于这种硬编码类型的漏洞比较好找，当拿到源码以后直接用 Sublime Text 等类似工具打开项目，然后按 Ctrl + Shift + F 进行全局 找关键字password或者pass

    示例 直接暴露密码

![](../Images/3ab540f5ea4fadae01e8111781416fa8.png)

  

漏洞名称 弱加密

    数据弱加密主要看数据传输中的加密方法，一般写在工具类 util 中

内容为 base64 编码方法

![](../Images/94a0c5188599abf0705d8c5ee6f064ba.png)

  

漏洞名称  SQL 注入

  

    手动查找的话 一般直接搜索 select、update、delete、insert 关键词就会有收获如果 sql 语句中存在+ append、 $（） # 等字眼，如果没有配置SQL过滤文件，则判断可能存在SQL 注入漏洞  不过一般都可以直接用工具跑可能效率更高一些 推荐使用sqlmap
