# VMware vRealize Operations Manager SSRF（CVE-2021-21975）漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Nzk3MjMzMA==&mid=2650567808&idx=1&sn=a16d42d82dff1dc633adaa23eaf552f3&chksm=bed9048589ae8d932ddcb3f5934adbacc91e4fb11e1265d99f8459668f5d2a3d733a917e86d3&scene=126&sessionid=1681665254#rd](http://mp.weixin.qq.com/s?__biz=MjM5Nzk3MjMzMA==&mid=2650567808&idx=1&sn=a16d42d82dff1dc633adaa23eaf552f3&chksm=bed9048589ae8d932ddcb3f5934adbacc91e4fb11e1265d99f8459668f5d2a3d733a917e86d3&scene=126&sessionid=1681665254#rd)

一.漏洞背景

vRealize Operations Manager API包含服务器端请求伪造。通过网络访问vRealize Operations Manager API的攻击者可以执行服务器端伪造请求攻击(SSRF)，以窃取管理凭据。

  

漏洞复现  

祭出fofa大法，fofa语法如下

(title="vRealize Operations Manager") && is\_honeypot="false" 

ps:&& is\_honeypot="false" （排除蜜罐）
