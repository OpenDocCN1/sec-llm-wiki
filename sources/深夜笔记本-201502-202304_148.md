# D-Link DCS监控 账号密码信息泄露 CVE-2020-25078

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Nzk3MjMzMA==&mid=2650567789&idx=1&sn=687903d00bc54eb54d12e6845d37ad0f&chksm=bed9046889ae8d7e03107f36d0f82f612a3e94d2ea79f4c6a84147cd59998f312bbb6e17b3bb&scene=126&sessionid=1681665259#rd](http://mp.weixin.qq.com/s?__biz=MjM5Nzk3MjMzMA==&mid=2650567789&idx=1&sn=687903d00bc54eb54d12e6845d37ad0f&chksm=bed9046889ae8d7e03107f36d0f82f612a3e94d2ea79f4c6a84147cd59998f312bbb6e17b3bb&scene=126&sessionid=1681665259#rd)

一.漏洞背景

   D-Link DCS-2200是一款监控摄像机，成像色彩为彩色 是一款网络摄像机，

根据VULDB 所看到的信息原文如下

A vulnerability, which was classified as problematic, was found in D-Link DCS-2530L and DCS-2670L (the affected version unknown). This affects some unknown processing of the file */config/getuser*. The manipulation with an unknown input leads to a information disclosure vulnerability (Password). CWE is classifying the issue as CWE-200. This is going to have an impact on confidentiality. The summary by CVE is:

  

通过原文大概意思可以总结为：  

   D-Link DCS系列 通过访问特定的URL可以得到账号密码信息，攻击方可以  

  

直接进入利用漏洞得到账户密码直接进入后台
