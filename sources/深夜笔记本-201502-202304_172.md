# 火影忍者十五年连载，教会了我们什么

连载15年的《火影忍者》终于要告别了，时光的车辙印刻了岁月的泥潭。十五年，真的是一个成长，看完《火影忍者》我情不自禁对着镜子，面对着自己很多天没剃的胡渣，我也想说青春在此刻就要告别了吗？

十五年，对于人来说都不算是短暂。十五年，足够使单纯的正太变成无趣忙碌的上班族大叔，使叛逆自我的2b青年变成以为人父…… 

十五年是一种见证，见证了午后阳光洒下从幼年稚嫩再到现今沧桑而被拉长的影子。

 十五年可以带走一切，带走很多人的生命。  
人生像一本书，一页又一页地往后翻，直到岁月终被耗尽，但是即便生命的消失，岁月带不走生命曾留下的意义。  
从火影的动漫角色里面，鸣人一点一滴的成长，他们的十五年对于我们的十五年而言，他们则是历史在若干年后的续写和发展。  
我们和他们一样，有着不一样的童年。我们和他们不一样，我们又承载着作为我们这个年代所应该肩负的重任。然而，他们的精神却如同空气，借助历史的风传递给了我们。   
火影的十五年，带给我们的不仅仅是一个漫画所之于我们的快乐和分享。也许更多的是他明示了我们的态度和思想。我们能够透过漫画中的人物去感受他们的人生和境遇，学习他们遇到困难所激发的勇气，面对危机所呈现的乐观，遭逢抉择所表现的坚定，濒临绝望所秉持的态度。

偶尔我们会想，十五年之后，我们会怎样  
有时我们会问，十五年之后，你们会在哪  
在一起的时候，我们会说，我们要永远在一起；十五年后....我们的身边是不是还是曾经约定的那个约定？  
毕业的时候，我们会写：苟富贵，勿相忘 十五年后，街头的照面是否还能够辨认出对方？  
告别的时候，我们会说：我永远不会忘记你 十五年后，你是否会记得一个人曾经和你相遇在人海茫茫。  
十五年，相比于他们，也许对于我们的意义更像是收获，我们生活在纷繁复杂的年代，有着比他们更交联的关系。他们的故事可以用笔无穷无尽的续写。  
而我们的十五年仅仅是弹指一挥间。  
十五年就像是一个容器，我们欣赏了美景，历经的感情，将所有的一切填满这个十五年。而有些人却永远只有一个容器。

《**鸣人的成长，从小被仇视最终得到了别人的认同》**

（一）坚强与泪水

你穿行在马路，孤独的你，徘徊在那街头，人们的眼光依然那样冷漠。你来到校园，孤独的你，荡着那树底下的秋千，孩子们的笑容依然那样灿烂。你回到家中，孤独的你，面对着那镜子，你的目光依然是那样孤单。你哭了，哭得很伤心，你的心，被那人们的眼光所刺痛，被那孩子的笑容所刺痛，也被自己的目光所刺痛。你恨他们，你恨所有人，恨他们的眼光，恨他们的笑容，恨他们的一切，也恨自己的一切。在泪光中，你望着，每个家庭，是那样的温馨，每个孩子，是那样的快乐，而你，只能望着，只能静静地望着。你还想哭，为自己的遭遇而哭，为自己的孤独而哭，可是你已经哭够了。因为你已经懂得了什么是坚强。

![](../Images/0c8886c0520f7c2002760fb1f21dcb1d.png)

  

（二）孤独

世间最大的痛苦是孤独，一个人在世上，没有人认同，好像世界不需要你一样。也许，从出生时，你的命运就以注定，你是这样的一个人，你是这样的一出悲剧。孤独是你的命运吗？是你的一生吗？时刻被人孤立着，在一个人的世界中挣扎。孤单地，无声无息，来到这世上，就是为了等待死亡的到来。你不甘心便尝试着摆脱它，尝试着用恶作剧使人们注意，尝试着用嬉皮笑脸来忘掉痛苦，尝试着用自己的热心去接近同伴，但是，一切都是徒劳的，命运早已决定了一切，这一切，让你觉得更孤单。在那无法摆脱的孤独中，你明白了，人最大的痛苦莫过于此、

 

  
![](../Images/60dc3f4e2c40bf5f7087b0e20c1ee6d8.png)

  

（三）梦想  

  

那好，你们听着，我要成为火影。迟早有一天，我要让你们认同我的存在。别忘了我的名字--旋涡鸣人。

你对着泪水，对着孤独，对着命运，对着那一切宣战。你的命运，会随着你的成长而转变，正因为你有了信念，有了自己的梦想，你相信自己的价值，并尽力地把它付诸实际。达到忍者的颠峰，也许对你而言，这段路还很遥远，但是，你会靠着自己的双手，开拓自己的命运。去开拓自己的梦想。因为从那一刻起，这已经不再是一出悲剧，因为从那一刻起，你已成为忍者，真正的忍者，一名有梦想，有血有肉的忍者。

如今你已得到别人的认可。

人类是渺小的，我们没有宇宙一般千万个岁月。但是我们又何必去苛求能够看遍世间万物，身边的美好，我们若能紧捧双手不让他从指缝溜走，那么十五年，尽管是刹那芳菲，却野能够承载最珍贵无比的记忆。  
十五年《火影忍者》最终告别，再次面对着镜子里长满胡渣的自己，“青春再也回不来了！” 。
