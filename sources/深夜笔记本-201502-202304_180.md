# iPhone的定位追踪功能你用过吗？

没有尾巴的猫（微信号：catnotail）“查找我的iPhone”是苹果为 iPhone 手机提供的一个可以通过网络定位手机位置的功能。除了定位以外，它还可以实现锁定手机和远程删除手机内容的功能。接下来在这里简单介绍下怎么使用它的操作方法。![](../Images/1d0abae8b900992a8ee97fb91296a1d9.png)“查找我的iPhone”是附属在 iCloud 服务里的功能之一，所以要使用它的前提是要打开 iCloud 服务。在“设置-iCloud”里可以用我们的 Apple ID 来激活它。![](../Images/763ac4dcda1c4ad80755548d252b11ea.png)随后可以输入自己的 Apple ID 与密码来激活它，如图所示![](../Images/92c13f0a1f8939dcc1090fe592db6866.png)当我们在 iPhone 上打开了“查找我的iPhone”以后，接下来就可用“查找我的iPhone”来定位手机了。![](../Images/3e0b25a4497be491c4d9c4527752e3f1.png)一般情况下可以直接在电脑网页中打开 iCloud 的页面，登陆自己的 Apple ID 账号。![](../Images/ecb6ed554d74caba443256c69c3bea1f.png)登陆成功以后，可以在页面中看到有一个“查找我的iPhone”功能图标，点击打开继续。![](../Images/e626f361e4115d77231e699c3e498cd1.png)由于苹果网络服务器的不稳定，在这里会经常遇到提示 iCloud载入出错的提示。有时候我们可以多尝试几次，运气好的话可以打开。![](../Images/45129aaa87a93d9aabad4896ad08be9b.png)如果一直处于打不开的情况，个人建议是在 iOS 设备上下载独立的“查找我的iPhone”应用，保证可以正常打开。![](../Images/a6b9181df99d7a2c8007fea726e59542.png)“查找我的iPhone”软件准备好以后，就可以在这里登录我们的 Apple ID 账号，定位与追踪设备的位置了。![](../Images/3f0060a597532a77622375456e87d62a.png)随后等待软件连网并显示与这个 Apple ID 绑定的 iOS 设备了，当找到以后，可以远程执行锁定，删除数据等操作。![](../Images/19640e7b81711070161ecc137e5c9f99.png) |
