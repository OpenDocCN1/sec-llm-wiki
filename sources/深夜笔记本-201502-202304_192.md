# 写给妈妈的诗

文\\没有尾巴的猫

挡不住时光的流逝，扼不住岁月的变迁。当母亲已渐渐老去，你是否曾轻轻地对她说过一句，妈妈，谢谢你，我爱你。  

 “慈母手中线，游子身上衣，临行密密缝，意恐迟迟归。”不是所有的爱都要说出来，母亲的爱体现在一言一行中，需要我们用心去体会。妈妈别哭，人生的路，我会好好走。  

 也许我们并不完美，但在妈妈眼里，我们永远是她无法代替的最爱的孩子。成长在母亲构建的诗情画意里，妈妈，你的幸福，是我最大的心愿。  

 

 门前的柳树又发芽了，桃树又开花了。一眼睛，我们都长大成年了；一瞬间，父母都生白发了。很多时候都会恍惚惊觉，时间都哪去了。

 

 背着妈妈的希望上路，再难再苦的路也要走。小时候妈妈总是把最好的留给我们，现在，我想把最好的都留给她。  

 

 妈妈，我爱你。
