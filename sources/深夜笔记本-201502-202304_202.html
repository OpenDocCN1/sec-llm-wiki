在微软的windows7开始很多人开始知道了Windows Defender这款内置软件，他是一款是一个用来移除、隔离和预防间谍软件的程序，更让人惊喜的是Windows 8中的Windows Defender不仅是反恶意软件，还是一款杀毒软件，可以查杀病毒。

今天给大家带来的计算机教程就是将windows8中的Windows Defender添加到右键中实现木马扫描

1、同时按“Win+R”,在运行中输入regedit回车


2、打开注册表编辑器后，找到“HKEY_CLASSES_ROOT\Folder\Shell”，然后右键点击Shell，选择“新建 - 项”


把该项命名为“WindowsDefender”。然后在右侧窗口中点击右键，选择“新建 - 字符串值”，把新建的字符串值重命名为“Icon”，然后双击“Icon”，打开“编辑字符串”窗口。


把“Icon”的数值数据填写为“%ProgramFiles%\Windows Defender\EppManifest.dll”。



然后相同的设置新建一个名为“MUIVerb”的字符串值，数值数据为“Scan Windows Defender”（随便自定义）。


然后在左侧窗口中的新建的“WindowsDefender”项上点击右键，选择“新建 - 项”，命名为“Command”。然后在右侧窗口中双击“默认”字符串值，在打开的“编辑字符串”窗口中，输入数值数据“"C:\Program Files\Windows Defender\MpCmdRun.exe" -scan-scantype 3 -SignatureUpdate -file %1”（注意 此处路径与你windows8的路路径相同，我这里给出的是一般路径位置。）


最后，关闭注册表编辑器。

重新打开“文件资源管理器”，在磁盘或任意文件夹上点击右键你就可以看到菜单中多了一个“Scan Windows Defender”选项。


注意，以上方法只限于扫描驱动器或文件夹，如果单个文件的扫描，您可以通过以下方式：

1、将以下代码复制粘贴至记事本，并保存为Scan Windows Defender.bat

@echo off

"%ProgramFiles%\WindowsDefender\MpCmdRun.exe" -Scan -ScanType 3 -File %1

pause

另存为文记事本文件 注意下面红色出选项。


2、同时按“Win+R”，在运行中输入shell:sendto回车

将刚保存的bat文件转移到打开的sendto文件夹中即可。
