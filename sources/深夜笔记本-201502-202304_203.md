# 计算机教程（关闭windows8.1的应用自动更新）

　 Windows 8.1系统支持应用自动更新，但是有些朋友也许认为每个应用不用都被Windows 8.1自作主张的自动更新。因为这里涉及到应用可能出现的BUG，或者觉得旧版本比新版本好用，其实我们可以快速的将Windows 8.1系统的自动应用更新关闭，转变成手动更新状态，这样可以更加自主灵活地控制自己的Win8.1应用。下面今天带来的计算机教程就是：关闭windows8.1的应用自动更新

  

　　1.点击Windows 8.1开始屏幕中的应用商店磁贴，打开应用商店，鼠标移动到屏幕右上角或者右下角或者利用快捷键Win+C调出Charm超级菜单栏，从中选择“设置—应用更新”；

![](../Images/76a24c4c300b45fd3d96f287bea2c51c.png)  
进入Windows 8.1系统的应用更新设置界面之后，将“自动更新我的应用”选项更改为“否”即可。

![](../Images/50cb73f047a358bb7f7fcff06e15fac0.png)  
　　这样更改Windows 8.1的应用设置更新之后，Windows 8.1系统中安装的应用就不会自动更新了。但是如果部分应用有新版本可下载更新时，应用商店的磁贴右下角会显示数字，这是当前可更新应用的数量提示，大家可以根据自己的需要灵活选择应用下载更新设置状态。需要应用自动更新，用同样的方法和步骤打开应用更新选项设置即可。

![](../Images/4d91ee84d7c69972e727947158d6ef24.png)
