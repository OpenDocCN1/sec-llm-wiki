# 计算机教程（利用虚拟机安装windows7）

现在大部分的系统装的是Windows7，Windows7的大众口碑还是很好的，所有越来越多的人选择安装windows7系统了，对于Windows7的安装其实有很多方法，微软为了普及Windows7，在Windows7安装的方法方面做足了准备，比如微软推出了一款u盘安装Windows7的程序，很实用很方便。

  

　　当然，如果你不会设置U盘启动，或者没有4G以上大的u盘装载win7系统镜像的话，还有个简单的方法，就是用虚拟光驱来安装。对于虚拟光驱怎么安装Win7系统。今天就给大家带来计算机教程（虚拟光驱安装系统）

你的电脑必须满足以下三个条件

  

　　1.本身系统还能使用 可以安装虚拟光驱

  

　　2.再有，自然就是虚拟光驱了。推荐使用Daemon Tools Lite

  

　　3.最后当然还要有系统安装包，格式为iso。百度上面有很多的 建议下载官方镜像包。

  

开始安装

1.安装虚拟光驱 下载好Daemon Tools Lite并且安装，这里不做图示。基本就是下一步下一步就好了。

![](../Images/4936620b8dfc53beab44b9d38af89994.png)  

2.安装完成后双击桌面小图标

  

.![](../Images/9a7343e18a8b5ada5a4ce155ce00cc0a.png)  
3.运行后就跳出个软件的页面

![](../Images/2d6d714cdc985ba87257342398771a40.png)  
4.接来点击添加文件（红色标记处）。点击添加文件，文件就是ISO镜像包了。

![](../Images/2e2ea3ffc74e38b6db20ab59392d4f47.png)  
![](../Images/20a43391fc90d3ddcb74e3c09caf2970.png)  
5.选择完成以后，接下来选择图中所示进行操作

![](../Images/1ab4a6b98f0d03cbb20a8567dd72c034.png)  
6.软件页面就多了个设备的无媒体，选择设备：无媒体。然后点载入  

![](../Images/7cf03b74391d4f14b40eaf4e17e8cf22.png)  
7.载入成功后，就会出现下图

![](../Images/a02c6f144d4f879f9075119b684a6651.png)  
8.最小化软件，到我的电脑里面查看，多出一个光驱盘，并打开它。（这里提示下有的电脑会弹出自动播放选择，不选择或者直接运行 setup.exe都可以）

![](../Images/a1d2993d859e0483d29afe141c1ad30f.png)  
9.进入后找到 setup.exe 双击运行下面就可以安装系统了。

![](../Images/6d076696a016de84a56b2dafd6e85125.png)  
10.现在安装，选择好你需要安装的盘符就好了一般都是C盘 系统默认盘符

![](../Images/9b11ded2f72f78d82ffb2113c317026d.png)  
11。接下来就是等待电脑几次重启了，不需要你在设置什么了。大多都是中文提示，不需要过多解释

![](../Images/4d91ee84d7c69972e727947158d6ef24.png)
