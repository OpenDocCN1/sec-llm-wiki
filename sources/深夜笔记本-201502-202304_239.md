# 第99封信

 下雨了，我躲在家里睡了一个很长的午觉，醒来，雨依旧没有停歇。我从一堆书中找到穆斯林的葬礼，认真的读着，这本书我看了三五遍，说不上书中的三代人命运的沉浮困惑交错扭结的爱情悲剧是如何吸引了我，其实就是想安静的呆一会。

 这本书有了年纪，8年前从一个朋友手中得来。现在看着它陈旧的样子还是满心欢喜，翻着那泛黄的纸张，低头时闻道一股旧书的味道，藏着一种独特的魅力。这种味道如美酒，愈醇愈香，愈久愈浓。

 我翻到第五页，一张折叠好的纸轻轻地滑落在了地上。迷惑，这是什么？捡起来打开，首行写着“第99封信”，这是我的字迹，我一眼就看了出来，信是我写了。五年前，多青春的年纪，呼吸都是那么轻盈，那时候的我从第1封信写到第98封信，写进了青春和梦想，写满了想念与牵挂。我每一封信都小心翼翼地装好贴上邮票，带着满是期待的心情把它们一封又一封的塞进了邮筒里。

 这是我在不安分的岁月里坚持最长的一件事。我喜欢看纸张上的字，无论是刚劲有力还是稚嫩歪曲的字体，读着信，仿佛看到了写信人低头执笔认真的模样。我喜欢写信，给朋友，给恋人，给亲人还有陌生人。而这第99封信，我写给某人。

 信里有一段说：即使楚雁潮不是穆斯林，即使韩新月有心脏病，即使他们相差许多岁，即使他们是师生关系，他们也要相爱。一个人遇到知音难免有一种高于友情的情感，我始终知道你就是那个人。

 我慢慢地读完这封信，往事历历在目，那种思念的美好，那种期待的幸福，占据了我多长的青春，给它带来多少快乐和喜悦。我写这封信的时候，是我看到了韩新月临死前的等待，让人很是心痛。合上书，我拿出纸笔，写了第99封信，同以上的98封信一样，写给我的某人。

 “岁月一定很温柔，它曾经轻轻的抚摸着世间的爱情，然后时光是残忍的，再坚贞的爱情也敌不过时间，它会夺取你的爱情，你的容颜，甚至是你的生命！”信里的这段话，回想起那个时候的自己对时光的愤怒，也想起自己对命运的不甘心。在信里清楚的表达自己对爱情的坚定和真诚，懵懂的写到面对命运的不公平一定奋战到底。

 信折好夹在了书里，忘了很久。看着这封写满一页纸的信，突然好怀念当年的自己，莽莽撞撞，奋力向前的样子。几年过去了，我很少再写信，那种单纯美好的时光真的被时间偷走了，在这越来越浮躁的社会里生活得越来越复杂。

 我放下书，拿起了笔，在那第99封信上写了“补上曾经的那份单纯与美好”这句话。取出一个带有邮票的信封，然后出门，把它塞进了硕大的邮筒里。

 我想把它寄回给主人，曾经熟悉的陌生人。
