# Windows 7系统利用DOS命令快速修改系统时间

在使用windows7系统过程，发现时间突然不准了，双击右下角时间位置修改时间固然简单，但是今天教大家一个更加快速的办法通过dos命令来修改时间

1、按“Win+R”组合键打开“运行”窗口，输入“CMD”命令后按回车，打开命令提示符窗口；

![](../Images/6e0f8e85181bdb5d76a06a6f4a1ae615.png)  

2、在打开的命令提示符中，输入“time”命令后按回车，会发现显示的是当前的时间；

3、在“输入新时间”命令行中输入“17:20”，想要查询系统时间是否改回来，马上在新的命令行中输入“time”命令，会发现系统时间已经被修改好了，很简单吧。

![](../Images/6c4dd6f0d386d6e5a0de5108e4cd5d49.png)
