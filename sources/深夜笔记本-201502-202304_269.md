# 巧妙找出win7系统后台运行的程序

下面就来教你如何巧妙找出win7系统后台运行的程序：

 　1、按组合键(win键+R)打开运行窗口，在文本框中输入“msinfo32”，按回车键执行命令，如下图所示：![](../Images/a0045f35694f7baa04ac2f1af2266545.png)  
2、随后会弹出一个系统信息窗口，我们依次展开“系统摘要—软件环境—正在运行任务”，便可以在右边框中看到系统中正在运行的所有程序的信息，包括优先顺序、最小工作集等等，如下图所示：

![](../Images/c49cabf49210fd545ed3fb03b31a67c8.png)  
你只需要一个内置的简单命令就可以查看到自己电脑运行了多少程序，是不是很方便，当然也可以使用任务管理器来查看，（快捷键为ctrl+alt+del三个键）。各位不妨在自己电脑上实验下吧。
