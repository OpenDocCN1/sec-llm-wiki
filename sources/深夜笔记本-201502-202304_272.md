# 无线信号太弱？！自制简单的 Wi-Fi 信号增强器吧！

相信大多数人都在家里都已经搞了个无线路由器了吧，毕竟现在使用WIFI的设备越来越多了，但如果你家比较大信号很差，那么我们就来自己DIY一个WIFI信号放大器吧！！管不管用一试就知道～

第一步,取一只用过的啤酒罐,洗净

![](../Images/3be9ea1c1df44a39a884f6a0b82eb1f6.png)

第二步,拔出拉环

![](../Images/2b577242bd295c3bcef91f70f6b1b231.png)

第三步,沿红线所示对罐底进行环切,将整个底部移除

  

![](../Images/3510213f400b5719fac72e7980d25c26.png)

第四步,沿红线对罐顶进行环切(注意不要全切,留下白线部分不切,同时白线必须靠近罐口)

![](../Images/06b4ad9d986fa60db55325366a277e73.png)  

第五步,在所留白线的反面垂直画一条红线,沿红线剪去铁皮  

![](../Images/068cdf69dfe55d30b3a458945bfb8baa.png)

第六步,展开铁皮,使铝罐白线部分依附在底座上,将天线穿过罐口,用兰丁胶固定罐底

![](../Images/4ea40509934b5cd9a1a455acfbc32425.png)

wi-fi信号放大器大功告成!

![](../Images/3d691d00f914eac3869ff14e0a1ab68b.png)

  

感谢各位亲，如果您有时间，请务必自己实验下，信号在那个点弱就把口朝那边放，如果有所改善，请您记得帮助我宣传一下。
