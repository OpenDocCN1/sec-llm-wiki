TeamServer.prop

在 4.4 版本之后，您可能在启动团队服务器时注意到一条警告消息：

丢失的文件是可选的，它的缺失不会破坏团队服务器。它包含许多可选参数，可用于自定义用于验证屏幕截图和键盘日志回调数据的设置，从而允许您调整“HotCobalt”漏洞的修复程序。您可以通过创建一个名为 TeamServer.prop 的空文件并将其保存在 Cobalt Strike 目录中来抑制警告。

一个示例 TeamServer.prop 文件可以从 Cobalt-Strike/TeamServerProp GitHub 存储库下载在这里。我们建议创建一个空的“TeamServer.prop”文件，创建该文件但使用默认设置，或者只是忽略警告。但是，如果您想更改这些设置，现在可以这样做。

默认 TeamServer.prop 文件包含以下内容：

 1#Cobalt Strike Team Server Properties
 2#Fri May 07 12:00:00 CDT 2021
 3# ------------------------------------------------
 4# Validation for screenshot messages from beacons
 5# ------------------------------------------------
 6# limits.screenshot_validated=true
 7# limits.screenshot_data_maxlen=4194304
 8# limits.screenshot_user_maxlen=1024
 9# limits.screenshot_title_maxlen=1024
10# Stop writing screenshot data when Disk Usage reaches XX%
11# Example: Off
12#          "limits.screenshot_diskused_percent=0"
13# Example: Stop writing screenshot data when Disk Usage reaches 95%
14#          "limits.screenshot_diskused_percent=95"
15# Default:
16# limits.screenshot_diskused_percent=95
17# ------------------------------------------------
18# Validation for keystroke messages from beacons
19# ------------------------------------------------
20# limits.keystrokes_validated=true
21# limits.keystrokes_data_maxlen=8192
22# limits.keystrokes_user_maxlen=1024
23# limits.keystrokes_title_maxlen=1024
24# Stop writing keystroke data when Disk Usage reaches XX%
25# Example: Off
26#          "limits.keystrokes_diskused_percent=0"
27# Example: Stop writing keystroke data when Disk Usage reaches 95%
28#          "limits.keystrokes_diskused_percent=95"
29# Default:
30# limits.keystrokes_diskused_percent=95

  • 以“#”开头的行是注释。

  • limit.*_data_maxlen是将被处理的屏幕截图/keylog数据的最大大小。超过此限制的回调将被拒绝。

  • limit.*_validated=false表示忽略以下三个…_maxlen设置
    将任何…_maxlen设置设置为零将禁用该特定设置

  • limit.*_diskused_percent设置回调处理的阈值，当磁盘使用率超过指定百分比时回调被拒绝

  • limit.*_diskused_percent=0（零）禁用此设置

  • 有效值为 0-99
