那天下班前，同事向我展示了他个人开发的扫描器听说还上过新闻呢....

  

“该死的， 又酸了🍋。”

  

“啊？冰箱又是什么东西酸了🤔” 周欣怡疑惑的问道。

  

我悄声的说：“害。同事写的漏洞扫描器, 能扫描到不少漏洞呢！就是命令行有点麻烦。”

  

我盯着周欣怡说：“嘿嘿！可以帮我写个前端嘛，下个月房租我出！”

  

周欣怡是我的合租室友，她在一家金融公司做前端开发。

  

“赵彬彬 ! !  你给我过来，我跟你说件事。”  

我走到她房间门前，愣愣地看着她，心里想着：“完了，她这是要引人犯罪啊。”

  

“你这是要准备干嘛，穿的这么性感。”

  

"要你管,你不想要前端嘛。我可以教你，不过要你自己写不懂的才可以问我哦～”

她一脸认真的对我讲。“愣着干嘛？吹风机拿来给我吹头发啊....”

  

就这样我就走上了前端之旅。

听周欣怡讲完感觉做前端工作其实并不难,就看你如何去做的美观。

  

首先，我们需要在电脑上装载一个必不可少的應用程式叫做 — **“Node.js”**

> Node 版本要求 Vue CLI 需要 Node.js 8.9 或更高版本 (推荐 8.11.0+) 下载安装即可。

![](../Images/e87c040e5fa0f72a0fbf0a509d949f7a.png)

  

现在有了npm，只需要一条命令安装Vue客户端。

> npm install -g @vue/cli

![](../Images/48f75a6ef6826f8f025fa422c4fb8ce5.png)

  

    通过简单运行 vue，看看是否展示出了一份可用命令的帮助报告

看来是成功了。
