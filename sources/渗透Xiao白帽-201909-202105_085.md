**0x08 利用PowerShell收集域内信息**

**一笔带过一下PowerShell。**

PowerShell 常用的执行权限共有四种。

*   
*   
*   
*   

```
 Restricted：默认设置，不允许执行任何脚本。 Allsigned：只能运行经过证书验证的脚本。 Unrestricted：权限最高，可以执行任意脚本。 RemoteSigned：本地脚本无限制，但是对来自网络的脚本必须经过签名。
```

  

在 PowerShell 中输入“**Get-ExecutionPolicy**”，看到为默认 Restricted 权限，

如果想执行一个 PowerShell 脚本，需要修改 PowerShell 的默认权限为执行权限。
