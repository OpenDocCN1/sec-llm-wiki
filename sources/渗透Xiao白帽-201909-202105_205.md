# CVE-2018-2894-任意文件上传漏洞 复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NTM4ODIxMw==&mid=2247483685&idx=1&sn=0009060843e4cd19a6c5cafecda7c854&chksm=ea37fe7fdd40776947a260f06fddccde7996e81dbef660960e9989d1778e56107269a8cf09fb&scene=126&sessionid=1681667484#rd](http://mp.weixin.qq.com/s?__biz=MzI1NTM4ODIxMw==&mid=2247483685&idx=1&sn=0009060843e4cd19a6c5cafecda7c854&chksm=ea37fe7fdd40776947a260f06fddccde7996e81dbef660960e9989d1778e56107269a8cf09fb&scene=126&sessionid=1681667484#rd)

**0x01 漏洞背景**  

    WebLogic管理端未授权的两个页面存在任意上传getshell漏洞，可直接获取权限。两个页面分别为:

http://ip:7001/ws\_utc/begin.do

http://ip:7001/ws\_utc/config.do。

**0x02 漏洞环境**

*   执行如下命令，启动weblogic 12.2.1.3：
    
*   cd /vulhub/weblogic/CVE-2018-2894    // 进入对应漏洞的目录下  
    
*   docker-compose build   // 编译漏洞环境
    
*   docker-compose up -d // 生成环境  
    

![](../Images/3e34e717ea1dc6cfaca5d5fbe791f4de.png)

环境启动后，访问http://192.168.255.145:7001/console，即可看到后台登录页面，192.168.255.145是我本地环境的ip。  

![](../Images/a6f6d15a981121d89a6b8506c0ff6d47.png)

执行命令查看登陆的账号密码：weblogic  ---> LQeb6qju  

docker-compose logs | grep password  

![](../Images/92954a194035987f53f5c25951d1e52c.png)

登录后台页面后点击 base\_domain 的配置，在“高级”中开启“启用 Web 服务测试页”选项：

![](../Images/5a589302a26455f0a83ed80cd1c1dd76.png)

![](../Images/fd6413e660880d5513a9649fd17a4cad.png)

最后保存配置。  

**0x03 漏洞复现**

*   访问`http://192.168.255.145:7001/ws_utc/config.do`，
    
*   设置Work Home Dir为`/u01/oracle/user_projects/domains/base_domain/servers/AdminServer/tmp/_WL_internal/com.oracle.webservices.wls.ws-testclient-app-wls/4mcj4y/war/css`
    
*   ![](../Images/7c8473cf7d8346a2e2b027147d7d9864.png)
    

  

  

*   我将目录设置为`ws_utc`应用的静态文件css目录，访问这个目录是不需权限的，这点比较重要。
    
*   然后点击安全 -> 增加，然后上传webshell：  
    
*   ![](../Images/aef8c1e83008b645a895f62ab209d5e7.png)
    

上传成功页面刷新，审查元素也可以看到时间戳。
