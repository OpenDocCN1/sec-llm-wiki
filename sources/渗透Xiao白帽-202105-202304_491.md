# 什么是快乐星球？资料与工具常年分享

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NTM4ODIxMw==&mid=2247487837&idx=1&sn=ceac1175602ab171a5f807b37c910e7e&chksm=ea37ee07dd4067110e87abe1b5d8143d010afa9a76751ae21b9650ce1f2185d18f24d3d6ad40&scene=126&sessionid=1681667409#rd](http://mp.weixin.qq.com/s?__biz=MzI1NTM4ODIxMw==&mid=2247487837&idx=1&sn=ceac1175602ab171a5f807b37c910e7e&chksm=ea37ee07dd4067110e87abe1b5d8143d010afa9a76751ae21b9650ce1f2185d18f24d3d6ad40&scene=126&sessionid=1681667409#rd)

知识星球已经运营31天，内容大致为：（1）每日分享资料与工具，并进行了分类（2）创办了作业模块，偶尔发布作业与大佬互动，（3）成员可在星球内发布问题，会有大佬及时给与回复。（4）成员可定向提问，星主与其合伙人都会及时给与回复。（5）成员如需要提供特定资料可在星球发布需求，星主与其嘉宾会及时给与回复。

**详细如下：**  

（1）星球中暂时分类为7类，成员可根据自己需求查找资料，我们会每天进行资料更新，成员或有其他需求可以提出。
