## 快速安装

1.  克隆这个 repo 
    

```

git clone https://github.com/yogeshojha/rengine && cd rengine
```

2.  编辑 dotenv 文件， **请务必更改 postgresql POSTGRES\_PASSWORD 的密码！**
    

```

nano .env
```

3.  运行安装脚本，请留意任何提示，您还将被要求输入 reNgine 的用户名和密码。
    

```

sudo ./install.sh
```

如果 `./install.sh`没有安装权限，请更改， `chmod +x install.sh`
