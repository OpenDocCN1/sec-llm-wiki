# Docker可视化管理工具  

Docker常见的几款web工具：

*   docker UI
    
*   shipyard
    
*   portainer
    

本次是在Centos7上安装portainer  
首先搜索一下Docker Hub上的portainer镜像

| 

```
1

```

 || 

```
\[root@localhost ~\]# docker search portainer

```

 |
| --- | --- |

![](../Images/adfbb56d56bcf0b0a1f8c6498fa50956.png)  
然后下载官方portainer镜像

| 

```
1

```

 || 

```
\[root@localhost ~\]# docker pull portainer/portainer

```

 |
| --- | --- |

![](../Images/20a4391e29121062e168712f81a770cd.png)  
在后台运行portainer容器，端口映射成9000，–restart=always表示开机自启动

| 

```
1

```

 || 

```
docker run -d -p 9000:9000 --restart=always --name portainer -v /var/run/docker.sock:/var/run/docker.sock -v /Users/lee/dev/docker\_file/portainer/data:/data docker.io/portainer/portainer

```
