Docker环境信息

1.docker info
显示Docker系统信息，包括镜像和容器数
示例：



info


2.docker version
显示Docker版本信息
示例：




version


容器生命周期管理

1.docker run
创建一个新的容器并运行一个命令



部分常用选项



示例1 运行ubuntu容器，并分配一个伪终端：



run1


示例2 后台运行ubuntu容器，并返回该容器ID：




run2


2.docker start
启动一个或多个已经被停止的容器




示例：



start


3.docker stop
停止一个运行中的容器




示例：



stop


4.docker restart
重启容器




示例：


restart

5.docker rm
删除一个或多少容器


示例：



rm


6.docker kill
kill命令的作用是杀掉一个运行中的容器



示例：



kill


PS.一些常见的rm和kill组合姿势~



rm&kill
