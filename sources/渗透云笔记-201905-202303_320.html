  输出方式

 print_r,var_dump,debag_zval_dump

这个主要是输出变量的数据值，特别是数组合对象数据，一般我们在查看端口的返回值或者不确定的变量可以使用这两个API，debug_zval_dump类似，唯一增加的一个值是refcount,记录一个变量被引用了多少次

代码

 <?php
 $arr = array(
     "key1" => true,
     "key2"=> "test",
     "key3" => "100",
     "key4" => null,);
 print_r($arr)
 ?>
