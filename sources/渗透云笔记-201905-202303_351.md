# 华盟十六周年一路有你！

历经十六载，华盟走过风风雨雨，十六年的发展形象品牌已经发展成在全国具有一定影响力的网络安全品牌。

  

![](../Images/b177d7f8f3be20bbaa49768a9635882d.png)

  

回想我们一起走过的青春，是回忆，是怀念，更是让人回味无穷。致我们一起走过的青春，有欢笑，有悲伤，有艰辛，也有喜悦。

  

“往后余生，风雪是你，平淡是你，清贫是你，荣华是你……”  

  

不管航路多艰险，风浪有多大，我们都将一直陪伴朋友到达美丽的彼岸！愿华盟的以后有我们，有你们，也有新朋友们一起并肩前行！

  

在我们欢庆十六周年的同时，也有华盟学院、360集团、安全牛、游侠安全、四叶草、天億网络安全、OWASP中国、渗透云笔记、安全+等业界精英，技术大牛、安全团队、合作伙伴朋友们一起。谢谢你们的祝福，也祝愿华盟与大家可以共同进步，共同努力。
