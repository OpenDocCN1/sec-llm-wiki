Ubuntu 16.04搭建LAMP开发环境

（这些命令都可以复制粘贴的哈右键，不对的话就自己敲）

打开Ubuntu后，右键，选择open-terminal进入终端命令行![](../Images/e313687e9d886d8e67b0504e6194864d.png)

![](../Images/5e32386c83fa4ca1118aacad709d0343.png)

下面的操作都在这里面输哈

基本设置：

1.设置root密码

sudo passwd

切换到root用户：su 或 su - 或 su root   
切换到普通用户：su 用户名 或 logout

2．更新源

sudo apt-get update

源保存的文件为：/etc/apt/sources.list

![](../Images/da26096a0d86ff8ac822a1293474bee0.png)

（如果出现了让你输入密码的情况，就请输你之前设置的那个，按下回车，密码都是不显示在屏幕上的哈，然后如果出现了E:Invalid operation updata，没关系，重新输入sudo apt-get updata回车就好了，出现了下面那一堆就好了）

 

安装常用软件

1.SSH

sudo apt-get install openssh-server

 

查看状态：service ssh status/start/stop/restart   
或：/etc/init.d/ssh status/start/stop/retsrt   
实际上，service命令就是执行/etc/init.d脚本，二者功能是一样的

![](../Images/5cd63990b5b0ae985378e34a2580268f.png)

（这些工具以后可能会用，现在不晓得也没关系，输入命令后，出现上图，敲个y按回车就好）

 

2.Vim

sudo apt-get install vim

![](../Images/6915f4933099cdd9527a1462d8e21a86.png)

（同样输入命令按回车，按步骤就好，如果已经装了的话，会提示，像上图，这个时候，英语尤其的重要哈哈）

 

3.Tree

sudo apt-get install tree

![](../Images/2c9870ff06a147365ef711408941bc38.png)

 

4.Git

sudo apt-get install git

 

![](../Images/8de0d5a45d99999683aaa1a1b78fd3fe.png)

搭建LAMP【这才是重点】

 

1.安装Apache

sudo apt-get install apache2

![](../Images/d5f7973ec796bcfb194e0faf344bc535.png)

 

测试： 浏览器访问http://Ubuntu的IP（即http://localhost），出现It Works!网页。   
（打开火狐浏览器，在搜索栏中输入网址）

![](../Images/5bd590200fe84f1b3c62db13dff6af48.png)

![](../Images/163e9d66077beda26722853826516bcb.png)

![](../Images/20a5a7cdf7cb8ff9aac9776db467c78a.png)

（出现上图就ok）

查看状态： service apache2 status/start/stop/restart  
Web目录：/var/www   
安装目录： /etc/apache2/   
全局配置： /etc/apache2/apache2.conf   
监听端口： /etc/apache2/ports.conf   
虚拟主机： /etc/apache2/sites-enabled/000-default.conf

（这些以后可能会用，先不管）

2.安装MySQL

sudo apt-get install mysql\-server mysql-client

1![](../Images/a0a920749260d1476387ffae4637ae69.png)

按y

测试：mysql -u root -p 

![](../Images/9ddf8e96d775bee04077e5e88666bdeb.png)

![](../Images/45e0ecde1cea4e71cea2f1d87e355df1.png)

（如果安装成功的话，就会进入mysql命令行，mysql\>这个样子，退出就敲quit；就ok）  
查看状态：service mysql status/start/stop/retart   
查看监听端口的情况：netstat -tunpl或 netstat -tap

 

3.安装PHP

sudo apt-get install php7.0

测试：php7.0 -v

sudo vim /var/www/html/phpinfo.php

进去之后是这样

5.修改权限

sudo chmod 777 /var/www

![](../Images/e5cf8f6cea3376224e5b5bd7ff13b590.png)

 

 

6.安装phpMyAdmin

sudo apt-get install phpmyadmin

![](../Images/dbcbc32a8fb825a68d10afaf5985b483.png)

 

安装：选择apache2，点击确定。下一步选择是要配置数据库，并输入密码。

（中间会让你选择，就选apache2，然后选ok那些，设置个密码，再次输入密码，就好了，记得设置个不会忘的密码哦）   
创建phpMyAdmin快捷方式：sudo ln -s /usr/share/phpmyadmin /var/www/html   
启用Apache mod\_rewrite模块：sudo a2enmod rewrite 

![](../Images/574ff755056493ab4691d7ca859520bf.png)

  
重启服务：   
service php7.0-fpm restart   
service apache2 restart 

![](../Images/d61c3598d22a2dd23ea696a5257040d4.png)

（依然会让你输入密码，输就好了）

 

  
测试：浏览器访问：http://ubuntu地址/phpmyadmin(即http://localhost/phpmyadmin)

![](../Images/b76aec712f34f6a9dce4527dedcbbda0.png)

![](../Images/f74261149ff6c709364f33557e3e747f.png)

 

（出现这个就ok）

7.配置Apache

Sudo vim /etc/apache2/apache2.conf

1![](../Images/0ea79dae4c63d648bbdd5c043288ba10.png)

 

打开文件后

先按下i然后滑到页尾

添加：   
AddType application/x-httpd-php .php .htm .html   
AddDefaultCharset UTF-8 

![](../Images/65c2640056669e9cb601393b9bb88a3b.png)

 

 

再按下Esc 输入：wq回车退出（w是保存q是退出）

![](../Images/48e83b2c3c45d43224b40b68ef6b8968.png)

  
重启Apache服务

service apache2 restart

 

lamp就搭建好了
