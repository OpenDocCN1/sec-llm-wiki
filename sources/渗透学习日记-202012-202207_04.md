# Linux Polkit本地权限提升漏洞(CVE-2021-4034)复现

漏洞描述：Polkit 是用于在类 Unix 操作系统中控制系统范围特权的组件。它为非特权进程提供了与特权进程进行通信的有组织的方式。polkit 的 pkexec 存在本地权限提升漏洞，已获得普通权限的攻击者可通过此漏洞获取root权限。  
CVE编号：CVE-2021-4034  
影响版本：CentOS系列：

*

*   
*

CentOS 6：polkit-0.96-11.el6_10.2CentOS 7：polkit-0.112-26.el7_9.1CentOS 8.0：polkit-0.115-13.el8_5.1CentOS 8.2：polkit-0.115-11.el8_2.2CentOS 8.4：polkit-0.115-11.el8_4.2
```

```

漏洞复现：  
环境（现已获取webshell，apache权限），根据内核版本和polkit版本（可通过命令apt policy policykit-1或rpm -q polkit查看）可知，当前环境存在漏洞。
