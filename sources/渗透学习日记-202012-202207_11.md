**漏洞描述：**  
VMware是一家云基础架构和移动商务解决方案厂商，提供基于VMware的虚拟化解决方案。2021年9月22日，VMware 官方发布安全公告，披露了包括 CVE-2021-22005 VMware vCenter Server 任意文件上传漏洞在内的多个中高危严重漏洞。在CVE-2021-22005中，攻击者可构造恶意请求，通过vCenter中的Analytics服务，可上传恶意文件，从而造成远程代码执行漏洞。  
  
**影响范围：**  
影响版本：VMware vCenter Server：7.0,6.7,6.5,4.x,3.x影响组件：VMware vCenter Server

  

**复现过程：**fofa:app="vmware-VirtualCenter"点击HTML5进行测试![](../Images/8416418f6dfa31774068f62b0e2a59f3.png)  
  
进去之后会出现一个登录界面![](../Images/95fdb001beb9f7656894be76abcda534.png)  
在url中输入analytics/telemetry/ph/api/level?\_c=test如果出现以下情况（只要不是错误代码或者为OFF就存在此漏洞）![](../Images/3ed98de4cc315215e484380bd7814ce1.png)漏洞poc现以公开(poc地址:https://github.com/r0ckysec/CVE-2021-22005),使用命令(cve-2021-22005\_exp\_win.exe -u IP地址 -s),返回一个root权限的shell
