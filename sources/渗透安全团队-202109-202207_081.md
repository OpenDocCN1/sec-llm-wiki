### 过程

![](../Images/385d616e4f807a29d84655857ccccd74.png)

#### 接下来进行接口配置

```

```

#### 付费版

```

官方都有接口，复制接口。
```

##### 数据包如下

```


POST /base64 HTTP/1.1
```

#### 白嫖版

##### 毕竟都喜欢白嫖，上述没有太多的描述。

```


这里选择了本地进行模型训练。
```

##### POST数据包修改host为自己本地即可
