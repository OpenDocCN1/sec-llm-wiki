# 【最新漏洞预警】CVE-2021-45897 全球最大CRM系统SuiteCRM远程命令执行漏洞分析与复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkxNDAyNTY2NA==&mid=2247488361&idx=1&sn=d683daea16415e2bc019ea8aed34459a&chksm=c175eec6f60267d06a92ad61596a3274df9ab6fa8d8256a05b3d39f2fceee66314bc5c15c990&scene=126&sessionid=1681408056#rd](http://mp.weixin.qq.com/s?__biz=MzkxNDAyNTY2NA==&mid=2247488361&idx=1&sn=d683daea16415e2bc019ea8aed34459a&chksm=c175eec6f60267d06a92ad61596a3274df9ab6fa8d8256a05b3d39f2fceee66314bc5c15c990&scene=126&sessionid=1681408056#rd)

  

**漏洞信息**

  

SuiteCRM是全球排名第一的开源CRM系统，自最初发布以来已被下载超过 800,000 次。近日官网爆出SuiteCRM存在多个漏洞，其中一处远程命令执行漏洞编号为CVE-2021-45897，影响版本如下：

  

*   < 7.12.3
    
*   < 8.0.2  
    

  

在CentOS上进行程序安装与数据库配置，完成研究环境搭建：  

  

![](../Images/0daa2aae289814bf7177528efaa0f697.png)

  

下面给大家简要分析一下漏洞触发原理并复现该漏洞。

  

**漏洞分析**

  

  

SuiteCRM软件支持用户定义邮件模板。补丁修复位于\`modules\\EmailTemplates\\EmailTemplate.php\`：

  

![](../Images/f38ad347936731702c887bff08d4799b.png)

  

\`repaireEntryPointImages\`读取\`html页面\`中解析\`<img src=\`标签，提取文件后缀\`fileExtension\`和\`id\`，随后调用\`makePublicImage\`函数将\`upload\`目录文件写入到\`public\`，且没有对后缀名做检查。提取文件的URL格式为：

  

*   

```

```

  

经过身份认证的用户可以通过\`/index.php?entryPoint=download&type=Notes&id=<note-id>\`链接Notes模块中的附件：

  

![](../Images/97dfca572602e827bc651f725d853d58.png)

  

\`repaireEntryPointImages\`由\`retrieve\`函数调用，在用户保存和访问电子邮件模板时都会触发该功能：

  

![](../Images/66d9efa38da43ecfda00473faa7cd2e1.png)

  

SuiteCRM允许用户创建邮件模板，并支持添加附件，实际上以uuid的方式存储在本地文件系统：

  

![](../Images/f202888170dbb701cd43b6aca7c5248c.png)

  

同时用户可以将任意附件添加到邮件模板，但不能被php解析，但是利用\`repaireEntryPointImages\`函数，如果邮件正文中包含类似内容如下：

  

*   

```

```

  

\`Notes\`模块下的附件就可以被复制写入到\`public\`目录。

  

总结漏洞利用过程如下：

  

*   用户通过\`Notes\`上传webshell；
    
*   SuiteCRM系统\`Notes\`模块将webshell以UUID的方式存储在\`upload\`目录；
    
*   验证能否通过\`/index.php?entryPoint=download&type=Notes&id=<note\_id>\`下载附件；
    
*   创建一个电子邮件模板，模板html源码中包含类似于\`#<img src='localhost/index.php?entryPoint=download&type=Notes&id=UUID&filename=poc.php#si\`的匹配项；
    
*   保存或者重新加载邮件模板，SuiteCRM执行\`repaireEntryPointImages\`将webshell复制到\`public\`目录；
    
*   通过\`http://\*\*\*/public/UUID.php\`执行命令。
    

  

**漏洞复现**

  

用户登录，进入\`Notes\`功能上传\`Notes\`附件，返回ID：

  

![](../Images/7d94b1770a4db58422982d9e15bfd536.png)

  

检查附件内容：

  

![](../Images/e92a9220819c26822b37198b4b14afce.png)

  

进入\`Email-Templates\`功能，新建邮件模板并篡改\`body\_html\`参数：

  

![](../Images/0f8bb2d19fb8d89c130413714d396392.png)

  

保存后重新查看该模板，webshell被写入：

  

![](../Images/61503697d38bf58fc5ef46a8e855b4ac.png)
