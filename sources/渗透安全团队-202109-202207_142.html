1、用户安全

查看用户信息文件，检查是否有新增用户

 cat /etc/passwd

查看home目录是否有新增目录

切换到home目录看是否有新的用户目录，如果有新增加的目录，则已被入侵

查看是否还有其他特权用户（默认只有root一个特权用户即uid=0）

awk -F: '$3==0{print $1}' /etc/passwd

查看当前登录用户

who   # tty：本地登录  pts：远程登录

查看系统信息

w  #可以知道某一时刻用户的行为

查看的用户的多少，用户上线了多久，以及负载

uptime

删除用户密码

passwd -d username

查看用户上一次密码修改时间

stat /etc/passwd    #如果近期修改过，可能存在问题

查看不可登录之外的用户

cat /etc/passwd | grep -v nologin  #有无新增用户，有则可能存在问题

查看具有root权限的用户

cat /etc/passwd | grep x:0  # 有新增的就可能存在问题

查看使用shell的用户

cat /etc/passwd | grep /bin/bash

查看可以远程登录的用户

awk '/\$1|\$6/{print $1}' /etc/shadow

查看具有sudo权限的用户

查看登录失败的次数

grep -o "Failed password" /var/log/secure|uniq -c

查看登录失败的用户

lastb 

同一个ip多次登录失败，可能在进行爆破

查看登录使用的用户名 （可以看到出现的次数）

grep "Failed password" /var/log/secure|perl -e 'while($_=<>){ /for(.*?) from/; print "$1\n";}'|uniq -c|sort -nr

查看成功登录的ip

grep "Accepted" /var/log/secure | awk '{print $11}' | sort | uniq -c |sort -nr | more

查看登录成功的用户名、日期以及ip

grep "Accepted" /var/log/secure | awk '{print $1,$2,$3,$9,$11}'

如果出现可疑用户可进行如下操作

1、禁用账号

usermod -L user  #/etc/shadow 第二栏开头为！则表示以禁用

也可修改/etc/passwd文件

修改/bin/bash为/bin/nologin禁止账号登录

2、删除用户

userdel xp  #删除xp用户userdel -r xp   #删除用户 ，并将/home目录下的user目录一并删除

2、历史命令

用户执行操作的历史记录存放在文件.bash_history，登录root可查看其他用户的历史记录信息。

cat /home/lemonlove7/.bash_history  #lemonlove7是要查看的用户

查看当前用户操作命令历史

history

保存历史记录到指定文件

cat /home/lemonlove7/.bash_history >>history.txt  #保存lemonlove7用户的历史记录到当前目录的history.txt文件中

3、检查异常端口

netstat –antp  #显示直接ip所有建立相关链接程序名的tcp的端口情况-a：显示所有选项-t:仅显示tcp相关选项 -u:仅显示udp相关选项 -n：直接使用ip地址，而不通过域名服务器-l：仅列出有在 Listen (监听) 的服務状态-p：显示建立相关链接的程序名-r：显示路由信息，路由表-e：显示扩展信息，例如uid等-s：显示网络工作信息统计表（按各个协议进行统计）-c：每隔一个固定时间，执行该netstat命令

查看对应链接的文件路径

通过ip地址获取程序pid

netstat -antlp | grep 127.0.0.1 | awk '{print $7}' | cut -f1 -d"/"

5、检查进程

ps   -aux -a                - 列出所有运行中/激活进程 -ef |grep      - 列出需要进程 -aux            - 显示进程信息，包括无终端的（x）和针对用户（u）的进程：如USER, PID, %CPU, %MEM等

查看pid对应的程序

ps –aux | grep pid

监控网路客户连接数

netstat -n | grep tcp | grep 监听端口 | wc -l

查看cpu占有率前十的进程

ps aux --sort=pcpu | head -10

6、开机启动项

启动项文件如下

more /etc/rc.local /etc/rc.d/rc[0~6].dls -l /etc/rc.d/rc3.d/

查看是否有异常脚本在开机时启动

7、定时任务

crontab  -l  #如果有不是管理员设置的定时任务很可能是黑客留下的

编辑定时任务

crontab -e

查看root定时任务计划

crontab -u root -l 

查看有哪些用户有定时任务

ls /var/spool/cron

删除定时任务并控制计划任务不能写东西

sed '/gcc.sh/d' /etc/crontab && chmod 0000 /etc/crontab && chattr +i /etc/crontab

常见的定时任务文件如下

/var/spool/cron/*  #centos的/var/spool/cron/crontabs/* #ubuntu的/var/spool/anacron/*/etc/crontab/etc/anacrontab  #异步定时/etc/cron.hourly/* /etc/cron.daily/* /etc/cron.weekly//etc/cron.monthly/*

8、服务

查看开机启动项目

chkconfig

查看服务自启状态

chkconfig --list

9、文件查找

查找指定的文件（find）

查找最近一天修改的文件

find / -mtime -1 > /lemonlove7.txt  #将修改过的文件保存到根目录下的lemonlove7.txt中

查找大文件

find / -size +10000k -print  #查找大于10000k的文件

查看文件的md5值

md5sum -b filename  #filename文件名

10、top命令

top命令类似于Windows的任务管理器，能够实时显示系统中各个进程的资源占用状况

默认top是根据cpu的占用情况进行排序的

可通过b键进行切换，可切换到按照内存使用情况进行排序

监听指定进程

top  -p pid  监控指定进程

free   #查看当前系统内存使用情况

11、hosts文件

有些挖矿的会修改hosts文件

cat /etc/hosts

12、日志分析

默认日志位置

var/log

定位有多少IP在爆破主机的root帐号

grep "Failed password for root" /var/log/secure | awk '{print $11}' | sort | uniq -c | sort -nr | more

可以看到第一个ip爆破了我320次

查看日志配置情况

more /etc/rsyslog.conf


可使用命令 lsat进行查看最近登录的信息

各类日志文件如下图

查看/var/log/wtmp文件查看可疑IP登陆（日志文件查看方式可参考如下命令）

last -f /var/log/wtmp

13、文件清除

遇到无法常看文件权限或是病毒在一直向某个文件写入程序，可尝试如下命令

lsattr 恶意文件  #查看文件属性

查看lemonlove7.txt的文件属性

e：该文件使用extends来映射磁盘块

i：文件不能被删除

解除文件锁定

chattr -i 恶意文件

解除lemonlove7.txt文件的不可写入属性

chattr +i   #不让lib文件被写入删除

结束某进程

Kill -9  pid

kill掉这个pid为13405的py进程

 kill 9 13405
