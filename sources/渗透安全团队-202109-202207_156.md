##   
**漏洞描述**

  

ntopng是监控服务器网络流量的工具，对外提供Web页面。其4.2及以前的版本中存在一处权限绕过漏洞，利用该漏洞可以未授权访问目标任意接口。

  

## **影响范围**

  

ntopng commit < e8b9721479f401f595c5c7bb151819aceb03ad71

  

## **复现过程**

  

使用docker搭建环境 docker-compose up -d

  

搭建完成后我们访问 127.0.0.1:3000  

  

![](../Images/3abf33dc8b9a1cbf3b2db2c7fc5f7084.png)  

  

我们在本地搭建完之后可以使用默认账号密码进去选一个感兴趣的接口  

  

账号密码:admin/admin

  

![](../Images/08515d07f56da73a8013eeb2e1fdfd65.png)  

  

比如 http://127.0.0.1:3000/lua/macs\_stats.lua  

  

首先我们利用poc计算出ntopng lua目录的长度  

  

python poc.py --url http://ip:3000/ baselength

  

![](../Images/a24cd175c41a922d43771d33c866011e.png)  

  

可见长度为36  

  

在使用poc生成越权的url  

  

python poc.py --url http://ip:3000/ generate -l 36 -p macs\_stats.lua  

  

![](../Images/92cfc854d50834b776360166de64a5e4.png)  

  

访问即可

  

![](../Images/8d9f5efc2fc8a067ee1868f8bbcb9c6c.png)  

  

可使攻击者可以在未授权的情况下请求复合漏洞利用条件的接口  

  

相关poc关注公众号回复 **Ntopng**

![](../Images/6ca38a9e9bc0ba07b9309a6cab7c20a7.png)
