# 内网渗透神器Viper（二）连载篇

昨天我们介绍了Viper的安装，不知道大家是否已经安装成功了呢？今天开始就来教大家如何使用这个平台。  

  

我们做渗透最主要的就是防止溯源追踪，而viper非常友好，提供了反溯源配置。

  

VIPER内置一套自签名SSL证书,用于实现前后端Https连接,如果你的PC机所在网络环境存在流量监测设备,建议替换内置的SSL证书,绕过流量监测.

此处生成的证书用于VIPER控制台前端与后台WEB服务通讯的https加密以及Nginx双向认证,与载荷reverse\_https证书无关.

## 操作

*   **安装Viper并启动**
    
*   https://yourvpsip:60000登录Viper确认无异常
    

*   登录Viper所在的服务器执行如下命令
    

cd /root/VIPER/nginxconfig    # /root/VIPER为viper安装目录

  

chmod 755 gencert.sh

  

./gencert.sh                  # 按照提示运行,牢记密码

![](../Images/b767a6d5dee80cacf150669b9dd7d265.png)

  

![](../Images/ce13dde465fdc0b338696946ba699ae8.png)  

  

*   将 `/root/VIPER/nginxconfig/client.pfx` 拷贝到本地,双击导入证书到PC,
    

![](../Images/cf847bddd005e1dad8efb1b3e735aa37.png)

![](../Images/6c7edda3b2d7ff1f9715b2a5f2bab910.png)

![](../Images/dddcc1de02f986ed90dbe36386bb2229.png)

此处输入脚本中指定的密码

![](../Images/a2246404d44320154501dd43398e4d3f.png)

![](../Images/588385c0986f24db00483dadb306d877.png)

![](../Images/d522745e5a5043a9d7c6e1bc45c44ee1.png)

*   **重启浏览器(必须关闭chrome浏览器的所有进程,然后重新打开)**
    
*   访问 https://yourvpsip:newport 登录.
    

![](../Images/dda61dafd401941fb97be86900c9800d.png)

*   用户名: root  密码:自定义密码
    

![](../Images/e26dc55968e95356c77fe19a17c8f5a0.png)

这样你的平台只能你自己登录了，你的队友想要登录需要你提供证书给别人安装才行！

  

  

viper上线

viper是一个可视化的msf，所以基本原理和msf差不多，使用方法类似于CS，我们选择监听载荷新增监听

![](../Images/cdd1e49792f3ee687763ba2d2ac387a8.png)

  

![](../Images/b835ff4155c571596707f29d7c2b0b3e.png)

选择你要生成的监听类型，配置参数，记住，不要勾选虚拟监听哦

![](../Images/34d4cda517019d5da6b61d33b7edf8c6.png)

![](../Images/b38eb6144ea3d7b577dabd1ce9f08882.png)

别名自定义，因为在渗透中我们会创建很多监听模块，为了防止混淆我们可以自定义名称，点击下面的新增监听，我们的监听器就配置好了。

  

接下来生成载荷

![](../Images/0c1f8551f45d7a0be17d2751cedd17c1.png)

平台提供了几十种载荷满足我们的需要，点击自己需要的载荷类型，即可下载到本地  

![](../Images/a599d49f0550baeff9d72f48e2cd5321.png)

但是这儿的载荷不免杀，viper也提供了简单免杀的载荷，我们点击生成载荷  

![](../Images/5187ed15e4fcf184577fdf362aa021af.png)

载荷，监听端口要和监听器一致，否则无法上线

![](../Images/28b6499abbc7e5a570534481b2f671cb.png)

免杀类型提供了源码和分离，选择一个即可，作者亲测，分离免杀可以绕过金山等杀软，但是无法绕过Windows安全中心，而且免杀效果只有一天左右，一天以后，杀软还是能识别  

将生成的载荷发送给目标主机，运行即可上线  

![](../Images/eba6ee585a5e2fcfb1b51b7cc1947d7d.png)

提供了基础功能

![](../Images/ffa328df119fe523dbe6173e76079129.png)

基本操作大家自己去研究一下，后面的文章教大家如何用viper进行内网渗透！
