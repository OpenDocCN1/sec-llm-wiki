Viper(炫彩蛇)是什么

viper是一个图形化的msf平台，让所有的msf可视化操作，减轻小白的命令痛苦。

提供图形化的操作界面,用户使用浏览器即可进行内网渗透.

集成杀软绕过,内网隧道,文件管理,命令行等基础功能.

内置70+个模块,覆盖初始访问/持久化/权限提升/防御绕过/凭证访问/信息收集/横向移动等大类.

可视化的内网网络拓扑展示

msfconsole命令行,支持颜色显示,Tab提示

多用户协同


安装教程

  • 准备一台linux系统的VPS或虚拟机（个人建议使用kali，配置为4核4G最佳，最低为2核2G）

切换到root用户,确认以下操作都在root用户下操作sudo安装会出现未知问题sudo su
安装dockerapt install docker
安装docker-composeapt install docker-compose
如果遇到问题，可百度安装docker和docker-compose
切换到root目录
cd /root

    设置安装目录

    export VIPER_DIR=/root/VIPER


    生成安装目录,并进入安装目录

    mkdir -p $VIPER_DIR && cd $VIPER_DIR


    

    生成docker-compose.yml

    以下代码直接复制粘贴到命令终端回车即可

    

    tee docker-compose.yml <<-'EOF'

    version: "3"

    services:

      viper:

        image: registry.cn-shenzhen.aliyuncs.com/toys/viper:latest

        container_name: viper-c

        network_mode: "host"

        restart: always

        volumes:

          - ${PWD}/loot:/root/.msf4/loot

          - ${PWD}/db:/root/viper/Docker/db

          - ${PWD}/module:/root/viper/Docker/module

         - ${PWD}/log:/root/viper/Docker/log

          - ${PWD}/nginxconfig:/root/viper/Docker/nginxconfig

        command: ["VIPER_PASSWORD"]

    EOF


    设置登录密码

    Viper不允许使用默认密码


    export VIPER_PASSWORD=自定义密码


    

    写入密码到docker-compose.yml

sed -i "s/VIPER_PASSWORD/$VIPER_PASSWORD/g" docker-compose.yml


    

    如果以上执行正确,执行效果如下


  • 启动Viper

cd $VIPER_DIR


docker-compose up -d

所有的docker-compose命令必须在安装目录执行才会有效果


  • 等待15s系统启动,访问 https://yourvpsip:60000 登录. 用户名:root 密码:自定义密码


如果是公网vps部署viper记得关闭防火墙，放行端口哦
