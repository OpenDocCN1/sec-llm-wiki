Ruby非数值类型

Ruby字符串是一个8位字节序列 一个字符就是一个字节 可以使用单引号，双引号进行表示 两者最大的区别在于双引号中的内容可以被变量替换 #{变量名称}

注意:如果在字符串中有\反斜杠以及"双引号'单引号 直接使用 \转义

#!/usr/bin/ruby

Ruby符合数据类型 ----数组

在Ruby中利用数组可以存储更多同类数据到一个变量中，变量就是一个标识符，用来标记数据。

定义数组 数组名=[数据1，数据2，...];

通过下标索引可以访问数组中的具体内容 数组名[index]  index范围0~数组长度-1

puts names[3]
puts '-----------------------------'

复合数据类型----HASH

Ruby哈希是在大括号内防止一系列键值对，键和值之间使用逗号和序列=>分隔。尾部的逗号会被忽略。

使用键可以访问到值 访问方式 hash变量名[键]

#!/usr/bin/ruby
# coding=utf-8

test_hash = {"a"=>1,"b"=>2,"c"="clear","d"=>"def"}  #定义hash
puts test_hash["a"]      # 通过键访问到值
puts test_hash["b"]
puts test_hash["c"]
puts test_hash["d"]
puts '------------------------------------'

# 遍历hash数据
test_hash.each do [key,value]    # 在HASH数据变量使用 each进行遍历，务必赋值两个变量，不然会报错
    puts key,value
end

Ruby中的变量

普通变量: 小写字母开头组成

@开头：实例变量(Instance variable)

@@开头: 类变量(Class variable)

#!/usr/bin/ruby
# coding=utf-8

# 类变量定义 @@变量名称
# 对象变量   @变量名称
class Car
    @@car_sum = 0
    
    def initialize(wheel, color)      # 利用实例变量
        @wheel =wheel
        @color = color
    end
   
    def display_details
        puts "This car wheel #{@wheel}"
        puts "This car color #{@color}"
    end
    
    def sum_car
        @@car_sum = @@car_sum + 1
        puts @@car_sum
end

c1 = Car.new(wheel 4, color "blue")
c1.display_details
puts '-----------------------------'
c1.sum_car

c2 = Car.new(wheel 2, color "black")
c2.display_details
c2.sum_car
    # 在类中定义的类变量 只有在程序结束时 才会释放    所以定义的类变量可以一直来使用

&block调用

&代码块名称 来接受代码块更加常用 通过block或代码名称.block来调用执行

在函数定义中 通过block.call来调用代码块，否则不执行代码块

#!/usr/bin/ruby
# coding=utf-8

def test(&block)		# 在方法传递的参数中 如果具有& 那么这个参数一定是传递的代码块内容，不传递也不会报错
    puts "hello world"   
end
test

def testA(a,b,&block)  # 在进行参数传递时，如果参数当中有 &参数名 那么将其放在最后传递 
    puts 'hello world2'
    block.call
end
test(a 1,b 2){puts "hi"}   # {}代码块 使用block.call就可以调用代码块中的内容

Metasploit中的 Module Tree 分为两种，Primary Module Tree 和 User-Specified Module Tree，前者用于放框架自带的module，后者用于放自己写的module.

Primary Module Tree在目录 /usr/share/metasploit-framework/modules/ 下

User-Specified Module Tree 在 ~/.msf4/modules/

auxiliary：辅助模块，不带有payload的exploit，比如一些扫描模块

payloads：远程运行的代码，比如反弹shell的代码

exploits：带有payload的exploit

encoders：用于对payload进行编码

nops：保持paload大小的一致性

post: 获取权限后，用于后续渗透阶段的模块
