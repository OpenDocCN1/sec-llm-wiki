### JS信息泄露漏洞学习记录

分享一个毫无过滤的RCE获取方法，直接进入主题

分析步骤

#### 1、先随便输入账号和密码抓包，发现密码是某种加密。

![](../Images/103b1b5c6c008143b6e1be20a4729730.png)

#### 2、查看对应的js代码，可以看到有js对应目录

![](../Images/38a4f53fbaf6421dd5e2ab1116a22f7c.png)

#### 3、这里就可以通过403返回和404返回来判断目录是否存在，通过观看源码是可以发现有js的，可以爆破一下js，测试有没有敏感信息，我拿起御剑扫了一波js的字典

> ❝![](../Images/303b09d4196f7049ca293d69fb0c841d.png)❞

#### 4、将其遍历下载保存起来合并成一个文件，暂时设定为set.js

这里利用一个工具，可以快速提取出一些泄露的文件名

```

https://github.com/GerbenJavado/LinkFinder
```

```


multipart/form-data
```

接着我们得到了此信息从中看到了一个`../php/exportrecord.php?downname=`下载的功能，然后查询他对应的js代码

> ❝![](../Images/40266ab2e7e0adf8537f32a81f57a293.png)❞

#### 5、接着进行测试是否能够文件下载，对他自己本身进行测试，发现是可以的`任意文件读取`的，具体原理，可以待看代码，**「估计啥都没过滤」**

```

curl https://127.0.0.1/php/exportrecord.php?downname=exportrecord.php -k
```

#### 6、这时，继续测试的话，我们就得找功能点进行测试，所以再扫一波php目录，这里面大概都是功能模块

> ❝![](../Images/585bfc6946fd7c18d1428c345bdcac3d.png)❞

#### 7、经过目录的爆破我们可以发现，一般ping常见的漏洞点，这种功能很容易出现RCE漏洞，如果过滤不全的话，我们利用任意文件读取，读取一下`ping.php`的源代码，分析，过一过大脑

```

curl https://127.0.0.1/php/exportrecord.php?downname=ping.php -k
```

```


<?php
```

```

jsondata[ip]=|whoami&jsondata[type]=1
```
