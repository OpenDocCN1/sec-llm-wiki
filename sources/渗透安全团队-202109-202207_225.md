## DOMDOM开始 

1、可以用两种方法确认靶场的存在，扫ip

```


netdiscover -i eth0 -r 192.168.56.0/24
```

2、扫目标端口开发情况

```

nmap -p- -T5 -A 192.168.56.106 -oA dom
```

3、访问主页，爆破目录，指定扫描php

```


gobuster dir -u http://192.168.56.106 -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -t 100 -x php
```
