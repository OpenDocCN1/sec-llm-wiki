# CobaltStrike超简单拿域控

由于大部分师傅可能都不知道CobaltStrike是啥，我说一下怎么开teamserver，和启动CobaltStrike，具体原理请百度

## 一、启动CobaltStrike 

**1、先将CobaltStrike放入kali中，然后启动teamserve命令**

```

 ./teamserver 192.168.1.105 123456
```
