# 这里就要用到socat来进行重定向

**工具socat（一款端口重定向工具）我们用它来建立80端口上的连接管理，并且继续在80端口运行那个连接团队服务器的连接。**

```

socat TCP4-LISTEN:80,fork TCP4:team.dj.com:80
```

直接用apt安装socat

```

apt-get install socat
```

接着r1,r2执行这个命令，如果端口被占用可以关掉服务，我这边是关掉apache2

```

/etc/init.d/apache2 stop
```
