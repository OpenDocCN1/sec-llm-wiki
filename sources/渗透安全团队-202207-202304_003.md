*   wmi
    
*   wmihash
    
*   smb
    
*   mssql
    
*   oracle
    
*   mysql
    
*   rdp
    
*   postgres
    
*   redis
    
*   memcached
    
*   mongodb
    

*   多线程bao破，支持进度条
    
*   全部插件测试用例（pkg/crack/plugins/plugins\_test.go）
    
*   API调用，可参考（internal/runner/runner.go）
