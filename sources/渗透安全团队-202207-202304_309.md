# 给某个伙伴展示一次渗透提权

前言  

这是一个某个正在学习安全伙伴告诉我，他老师给他一个靶机让他提权，他不知道怎么下手，让我来试一下，那就试一下

![](../Images/2b95238a1d7fbd2ff87534efed084527.png)

知道网段ip没开机密码，他说这个靶机是这样的。

固定ip是 192.168.3.5

是个win2003r2的系统

那就先把虚拟机配置一下

 ![](../Images/c5460ccfc39a3de3fb6fc524e6694d21.png)

 

加一个192.168.3.0网段的网络

把第一个网络适配器添加上VMnet2这个网络

![](../Images/f36d7ef5429182240d3e6a8bc306fd4b.png)

然后在我的kali虚拟机上也添加VMnet2网卡

开机ifconfig看看

![](../Images/bbb3c8193ca25a9fa82b02af8d72476a.png)

添加上了

然后ping一下看能不能ping通![](../Images/99183a05edaefd00687ad70e25fedbbb.png)

 能通

用nmap简单扫下服务和端口

好多开放端口

有23端口但是没密码

有445端口用msf搞了一波似乎不行，可能打了补丁

![](../Images/e126fc2f2c7696f9dcada689d9204574.png)

上面有好几个站点， 随便选一个默认密码就进后台了

![](../Images/f7e0b6f32c3a75b912e892d5544c8d0b.png)

剩下直接拿shell行了

直接传一张图片马，他后台有个文件改名

![](../Images/021cbf29ff8c8c47e4a8f34dfe92d165.png)

通过抓包把文件类型改了，改成图片里面一句话马的执行类型，这个站是asp站，我传的是asp马，所以改的也是asp

ok

链接了上来

![](../Images/ad91d4f1fee4db0185852db3bf1a9607.png)

传了个msf马上来执行不了，没有权限

![](../Images/ce582feda3733e74bde67ed7638ceb79.png)

**提权**

尝试通过mssql数据库提权方法

在里面的代码文件找出数据库账号密码

 ![](../Images/c22c5a569662e977d6df5ff8ecdf7905.png)

账号:sa

密码：admin

看能不能链接

连上了

 ![](../Images/2a0140f8744186be6d71ddda3eb8644c.png)

 

用 exec xp\_cmdshell 执行命令

exec sp\_configure 'show advanced options',1;

RECONFIGURE;

exec sp\_configure 'xp\_cmdshell',1;

RECONFIGURE;

 ![](../Images/cc7001b65f0c1b588490c1c7b1d6c7f3.png)

 

exec xp\_cmdshell 'netsh advfirewall set allprofiles state off';

关闭防火墙

exec xp\_cmdshell 'net user';

查看用户

![](../Images/ad56adcde20ad32337eda2d3c8e6373c.png)

  

把账户密码改了

 ![](../Images/c5a428d9c2d001fce7422f44d997fd3b.png)

这下能登录进去了

![](../Images/17d336f3daa13b343d50f0c5bd9249a0.png)

只是administration权限，我需要最高的system权限

![](../Images/62a9b64301a604cf215280c3dc32e495.png)

用SC提权方法

sc提权只适合老系统，xp win7 2003这些，其他系统有其他方法

sc Create sys binPath="cmd / c start" type= own type= interact

sc start sys  

虽然提示失败1053 但是最高权限system窗口弹出来了

 ![](../Images/f46c869c3a9fbdb926121ec933461232.png)
