****新功能特性****

  

威睿刚刚推出 VMware Workstation 17.0 Pro 正式版，这是经过几个月测试后最新推出的稳定版，目前威睿也开始面向商业客户销售新版本的许可证。

## VMware Workstation Pro 17 的新功能特性

*   自动启动虚拟机
    
*   现在，您可以将本地虚拟机配置为在主机引导时自动启动。
    
*   支持新的客户机操作系统
    
*   Microsoft Windows 11
    
*   Microsoft Windows Server 2022
    
*   RHEL 9
    
*   Debian 11.x
    
*   Ubuntu 22.04
    
*   全新虚拟可信平台模块 2.0
    
*   Workstation Pro 现在提供虚拟可信平台模块（版本 2.0）设备，以支持 Windows 11 以及需要 TPM 的其他操作系统。
