**0x01 工具介绍**

Python Shellcode 免杀加载器 支持图形化伪装开发。

**0x02 安装与使用**

1、将生成的shellcode放到pickle\_to\_img.py源码文件里。

![](../Images/3cf1cff5c586ad7680f8bdd613bf2230.png)

2、运行pickle\_to\_img.py，会自动生成一个ico文件，将文件上传到服务器

3、修改loader.py 文件，将ico的地址换成服务器的地址

![](../Images/e58ddadd4d2632e9f06e1d93789d2004.png)

4、打包代码，将py文件转为可执行文件

*   
*   
*   
*   

```
Pyinstaller -F loader.py -w
//注意//python版本最好是32位
```
