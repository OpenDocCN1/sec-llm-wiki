我们搭建好测试靶场后开始探测局域网ip

![](../Images/f6308bb73e982490214a4b3608373cc2.png)

一眼看中192.168.36.148就是我们的靶机ip

我们还是nmap扫描一下端口开放情况

![](../Images/320989e3eb9653936f9e04873fbde10a.png)

发现开放了80端口，我们还是老样子，掏出御剑扫一下

在探测的时候我们去识别一下中间件等信息

![](../Images/bd05ee95175b894cb4a08b5e33f57b0d.png)

开始上御剑

![](../Images/e93aeeeef01cafa5343c8243c4c8ce4c.png)

我们发现了robots文件和一个wordpress的文件夹

访问看看

![](../Images/cd6ece4a19df5d3b37d2909c4ee7c9d7.png)

就一个文件夹，打开看看是什么页面

![](../Images/6d1c5c805d0c02cb99cdf5bfa60456c0.png)

有东西，我们先看一下这个页面都有什么吧

![](../Images/0de1300f25032f8e260ed474ad05d5c2.png)

咦，发现了login的超链接，没猜错的话应该是登录点

![](../Images/8117231e8dc98fe7b17efee51eabcaa3.png)

果然，这就是一个wordpress的站点，先来测试一波弱口令

![](../Images/67445b5a0323e9ce2c66aeee7647b2d6.png)

![](../Images/962e50b88c24afc081dcb25658cd12ba.png)

弱口令成功进入

我们找一个能编辑代码的地方尝试写入一句话

![](../Images/e54f819c5fc7adeddc9d90cc2b1623d6.png)

有php的页面代码，我们尝试插入一句话

![](../Images/e0d4000eef0a511b9e539c1f9c80823c.png)

还是老样子，冰蝎马

保存后进行查看

至于404页面的路径，直接百度就好

http://192.168.36.148/wordpress/wp-content/themes/twentyfourteen/404.php

![](../Images/c7b988d0b666ebb1bf6a020a3f62b9f5.png)

白屏的，好情况，直接连接

![](../Images/f460dbe5c5983c9df7d6d70e4ff099ac.png)

连接成功，我们直接上msf

![](../Images/44aa51fb25972d9a82c0f738a7637ce7.png)

设置好后开始监听

然后配置冰蝎那边的ip和端口

![](../Images/71e10bd126895494cd0f5c1dbd652325.png)

配置好后开干

连接成功，我们开始数据库提权拿信息

![](../Images/cd76476578a71776bbcc22fb0b6e37e8.png)

mysql -h localhost -u root -p -D wordpress -e 'select \* from wp\_users'

![](../Images/2ddccc3575bb7d1690bffb735e307be6.png)

md5加密的密码，我们拿到网上去解密一下

![](../Images/abefa1782eb8e5dcbc558194ef5f157f.png)

解密成功，我们去登陆一下试试

![](../Images/79b8392104c7099db214b76189e02445.png)

登陆成功，拿下此站点
