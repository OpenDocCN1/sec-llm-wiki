# 一、网页抓包

## 1\. 火狐浏览器抓包

`环境需求：`

```

火狐浏览器
```

(1) 打开测试工具`BurpSuite`，默认工具拦截功能是开启的，颜色较深，我们点击取消拦截。  

![](../Images/ad69568a96421c0b858bbad6e08a3b5a.png)

  

下图取消拦截状态，数据包可以自由通过：  

![](../Images/687b5357144662c90e0c4aa657b5784a.png)

  

(2) 按下图顺序点击选显卡来到`代理设置`  

![](../Images/e3f784660bb6185f0fafd3e92b95f911.png)

  

(3) 可以看到默认的代理设置情况，本地代理地址：127.0.0.1，代理端口8080。如果前面没有勾选一定要选择勾选。工具代理设置完毕。

![](../Images/fac1a90320a65ba9b46c6a4097ea67d2.png)

  
  

(4) 证书安装，浏览器输输入`http://burp/`,点击图示位置下载证书

![](../Images/2f3a426642d437cdb6a98f23f80eb6d3.png)

  

(5) 配置证书，打开浏览器并导入证书

![](../Images/84120b4de90060ffa43228ac21ab6bd2.png)

  

火狐浏览器开打开证书配置界面  

![](../Images/0060fb59ff1b50f029aca16677aaadd8.png)

  

(6) 导入选中下载的，勾选信任确认

![](../Images/62a4f9cd5b26df668311c3f7de6abbfd.png)

![](../Images/f25ae53133e260f9b01878de7634caf5.png)

  

(7) 火狐设置和Burpsuite一致的代理然后确认。  

![](../Images/7e5567adfc7f5dbd1b2e891bdb94f026.png)

  

![](../Images/a3514d9c2fc7c72007c378cb309b80ae.png)

  

(8) 访问百度查看抓包情况  

![](../Images/f8a0f0bfb2707ee867e4ee9b8abca9d3.png)

  

(9) 不用了记得把代理关了，记住开了`代理和burpsuite`共存亡！  

![](../Images/761d184c4e0fdae21e8669649243e42e.png)

选择证书后打开进入下一步。  

![](../Images/f0236c434f39b5442b169d7f70bb2bd1.png)

  
按下图位置设置进入下一步，完成。

**最后设置证书信任**  

按图示操作找到刚才安装的证书。  

![](../Images/92b52c64f82e50dfd189e33648a59b4f.png)

  
选中证书点高级  

![](../Images/2f83d671de860a433e0c7e7142eadaa0.png)

  

按下图勾选，确认。最后重启浏览器即可。

# 1.测试环境

  

```


MacOS（Windows一致）
```

# 2.设置代理

  

## （1）模拟器代理设置

  

设置-->WLAN-->鼠标长按wifi名称

![](../Images/22051d76b3c1165319d5ec521f37b2be.png)

  

修改网络-->下拉高级选项-->下拉代理选项-->选择手动

![](../Images/bd921bf5b1fb6a096e64852ae8896c84.png)

![](../Images/640f1ed17a46d47f7ac3a260537bfc09.png)

  

## （2）设置代理一致

  

代理服务器填写电脑ip，默认端口8080即可，设置完毕保存！

![](../Images/0de0747fb8851cd1db1c6b817ace6eaf.png)

  

Burpsuite设置代理与模拟器一致并保存。  

![](../Images/440ead8b81db8e72f54de3b54f45acb3.png)

# （3） 下载证书

  

模拟器打开浏览器，并输入http://burp回车，点击CA Certificate下载证书，默认下载的证书是der格式，是无法安装的。

![](../Images/7427d165be860773a8dbaf865271879b.png)

  

通过模拟器自带的系统应用工具“文件管理器”来修改格式。  

![](../Images/aa0bcd5a2b2a53619a3f19ecbec4c278.png)

  

打开文件管理器-->选择$MuMu共享文件夹找到我们刚下载的证书  

![](../Images/1225310f58e78af8bf5311ac041ec1f3.png)

  

长按证书-->选择重命名-->将其证书修改为cer-->确认。

![](../Images/0a6c9b4f687b6eb2efc5f6d028eab280.png)

  
（4）安装证书  

选择设置-->安全-->从SD卡安装-->点击刚才修改的证书-->设置一个名称保存即可

![](../Images/a37519bf89bd050d42c3ea62281d55bd.png)

  

选择设置-->安全-->从SD卡安装-->信任的凭据-->用户 即可看到我们的证书  

![](../Images/5665b4477b64eefe0baccc26d993e9cf.png)

# （5）测试代理是否成功

# 安装xpose

  

xpose和JustTrustme已经打包到公众号 后台回复app抓包即可获取下载地址。

（1）先更换机型，我在测试的时候发现默认机型不匹配，无法安装，更换机型

选择右上角功能选项-->选择系统设置-->属性设置-->选择预设机型-->选择一款机型（我选的vivo）-->重启模拟器

![](../Images/ede4b77479e755e63fe6c8c8aafe7bfb.png)

  
（2）把下载的xpose拖到模拟器安装-->打开xpose-->选择安装（资源在国外，可能失败，多安装几次）

# 五.Burpsuite抓包问题解决  

  

## 1.问题描述

  

有时候按照教程配置之后也无法抓包，有哪些原因呢？

### 原因一 未正确配置

  

那就按照上面教程过一遍再试试

###  原因二 证书无效

  

有的网站对证书做了限制或者黑名单，所以Burpsuite无法抓取

## 2.解决办法

  

### 1. 更换抓包工具

  

换成Fiddler:  
有朋友觉得fidder对数据包进行操作不方便，那么可以将burpsuite作为上层代理，把fiddler抓到的流量转到burpsuite上面，然后进行操作就很方便了。方法见下：

### 2\. Fiddler和Burpsuite联动

  

总体配置不变，首先正确配置这两个工具

  
然后Fiddler开启网关
