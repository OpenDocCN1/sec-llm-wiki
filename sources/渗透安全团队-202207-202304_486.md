# **外围打点**

最近想练一波内网渗透，于是就fofa批量了一波weblogic，挑了一个国外的机子

这里用工具发现存在漏洞CVE-2017-10271和CVE-2019-2725

  
![](../Images/b7897c06edda4fef8420872a835e25d4.png)  
  

这里我选择了用CVE-2017-10271，先命令执行一波，发现是台Windows的机子

  
![](../Images/5449f47a67a67e25e4485c2fe72f8eb4.png)  
  

先传个冰蝎shell上去吧

  
![](../Images/bb9ae30ec1d19aecea2dddaf404bbd25.png)  
  

冰蝎连接成功，先内网信息收集一波

  
![](../Images/fbb9527973385894dc05740260d9b6cb.png)  
  

一台winserver2008的机子，我们可以抓到明文密码，并且存在域，打了303个补丁(丧心病狂)

  
查看一下有无杀软

  
![](../Images/9e97389e29b2548dc4e4cd685d2f7547.png)  
  

不存在杀软，那么Beacon就不需要免杀处理，我们可以直接上线CS(这里上线的Beacon配置了云函数，所以外网ip是一直变的)

  
![](../Images/6aea48ae9bf9d4d1bff549e0295dc511.png)

# 内网信息收集

  

上线首先做个进程迁移，选择一个常见的进程注入  
、![](../Images/832f8bac516fef0497b46c7c47a6e367.png)  
![](../Images/3d2523110636b071f899fdf79f7e49e0.png)  
  

这里我们进行内网信息收集

  
内网首先目标是打域控

  
![](../Images/da95b4a87b272fc0b591937f7b8dd3c3.png)  
好家伙，6个域控，之后查看域管  
![](../Images/c1d85acec743c00de8d3503f797d2e9a.png)  
  

这么多域管，意味着我们只要能拿到一个域管的权限，这个内网就能漫游了  
首先来看看能不能在当前机子进行提权，因为前面303个补丁，我感觉都提不动了

  
经过提权尝试后，发现常规的提权洞都打了补丁，没办法，当前机子是管理员权限，并且没有杀软，先来抓一波hash

  
![](../Images/4f34dd250660eefdd2bddbfecfc813ec.png)  
![](../Images/062bcac983e835a55ab06667425cc5cd.png)  
  

接下来，使用CS自带的扫下内网存活

  
![](../Images/8d12b37d4d0faa715af84e48a8d58570.png)  
  

出现了两个域控，目标非常明确了，那么下面尝试用抓取到的hash进行psexec横向移动

  
经过多次尝试后，发现两个域控均不能横向，且其他机子无果

下面直接上内网大杀器MS17010!

使用Ladon快速探测存在MS17010的主机

![](../Images/14922f1562c27b707634a6fdcd4dbc34.png)  
![](../Images/858d86575df4ef417bcffed60c5b0053.png)  
  

初步探测两个域控均存在MS17010,这里使用Landon自带的exp,发现利用失败。既然这样，那么上线MSF吧

# MSF和CS联动

  

首先看了下，目标是出网机器

  
![](../Images/189a4ddb3905923bf8209f7bceb02536.png)  
  

之后尝试使用frp，nps等常规代理想把流量代理出来，发现无果，猜测目标做了限制，那么我们直接用公网的msf吧。

  
CS4.3版本移除了foreign/reverse\_tcp

所以我建立了一个foreign/reverse\_http的listener，msf监听后，

CSspwan，成功获得一个meterpreter

  
![](../Images/1fcb98f605c5d7729c0b315d47870463.png)  
  

下面我们添加路由

```
1.  `run get_local_subnets`
    
2.  `run autoroute -s 10.0.10.0/24`
    
3.  `run autoroute -p`
    
```

![](../Images/174444df9adf0c2daf09805a32137044.png)  
  

那么对ip为10.0.10.1的域控用MS17010打一波

这里使用ms17\_010\_eternalblue这个exp一直打不成功

那么我们换个exp打  
![](../Images/62606ab478a8552ecb7cd6082bcd3245.png)

成功获得一个session！  

![](../Images/3f298bb9baa8be1186aed900468d5c56.png)  
  

下面我们把这个刚刚获得的session转发回CS

  
![](../Images/bfd2703891c1b77d3e7ecb01ca91ff7a.png)  
  

成功反弹

  

  

![](../Images/faa7f490a896a0c629be027c304a198c.png)

  

# 横向其他域控

  

我们已经拿下一台域控了，那么其他5台就可以都拿了

  
我们先对这一台做个信息收集

  
老样子先进程迁移一下

  
![](../Images/4396299e44706405d99eaf65174e1c4f.png)  
  

抓下hash吧

  

![](../Images/a847755d3d3f9f3677d810331e775ebd.png)  

  

好家伙，为空！！！！

  
那么直接试下横向呢

  
![](../Images/eaaee14a16b82da8a254427aea49b064.png)  
  

也不行！

  
回想在和MSF联动的时候，本地路由还有个26网段，那我们在基于当前域控再做一波内网探测

  
![](../Images/4783153f8077505bb52b04f16e56502e.png)  
  

又发现一个DC

  
再试试横向一下，仍旧失败

  
![](../Images/b7d5eb6ce81cfcc8c59f42fe744e99cc.png)  
  

后来尝试了ipc，wmi也不行

  
这时，我突然想到，既然已经拿到域控了，那么我自己创建个域管不就可以了吗

  
![](../Images/40394912e9e310aaa76d866360329391.png)  
![](../Images/fa2311de8f91229b6d49524c10070691.png)

  
那么换域管登录，这里我尝试在拿到的域控切换，但是不行，那么我们就换那个跳板机吧

  
![](../Images/2df29b9e655fbb32d575ba3ae7932376.png)  
成功切换

  
那我们以域管身份的session进行横向

  
![](../Images/cfa61a51a88ca402570544ff26a6028b.png)  
![](../Images/b34ef83029ebae4200f93fba4e5ec251.png)  
  

同样另一台域控

  
![](../Images/cc0979665c441c9fc01fa500882dce71.png)  
  

在第三台域控可以抓取全部hash

  
![](../Images/7a94d3f0e99a1986b334da5aa54eb02c.png)  
![](../Images/f29cc63cefb0f166c5431876dfbdb0ad.png)  
  

后面三台域控发现ping不到且探测不到，那么对已有的机子做个简单的权限维持后，本次内网渗透结束。
