**创建 UAI-Censor 应用**

获得应用 ID 进行鉴黄 API 调用的时候使用,注册成功以后进入控制台，搜索 UAI，然后点击 AI 内容审核

![](../Images/94a6555da153e3204a70ecd8f5e29638.png)

点击创建应用，输入自定义的应用名称，点击确定

![](../Images/35e26244a74647cd3f621335ba922c05.png)

点击确定以后会显示成功的弹框，高亮部分就是你的应用ID，留着备用

![](../Images/b85a8431270544d3da04bc611a561696.png)  

**获取公钥、私钥，应用ID**

获取了，但是不能所有人都操作吧？

点击进入如下链接  
https://console.ucloud.cn/uapi/apikey
