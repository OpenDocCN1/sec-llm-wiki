# 实战|看我如何干掉果聊APP

某老哥中招了，找到我，发了APP后，我逐步分析，发现该APP没加壳。  

  

![](../Images/51984a44dbba65face7cd9507d257537.png)

  

尝试反编译，好像有混淆，我直接选择模拟器抓包，抓出交互的API地址

  

![](../Images/aa53bbb6a1818a2bdd0073ecc5e2a907.png)  
![](../Images/c84e0f3d61a1de9ae95d0e4faf1ee502.png)  
  

api地址为：http://XXXX:6003/api/uploads/apisms

  
APP主要行为为通过APP获取通讯录权限，短信，相册权限，通过api上传相关信息

  
拿到api地址好办了，扫描服务器端口，发现6002端口，6003端口开放

  

![](../Images/580c9a87ed1ab6296e501c8405fa4462.png)  
  
查找api后台，发现6002端口后台地址为：

  

http://XXXX:6002/admin/common/login.shtml

  

存在弱口令 admin  

  

123456  登录进入后台，

  

![](../Images/f6946bf074b9433d9393e92b2da7b39c.png)  
  

系统设置处可以修改文件上传类型，修改上传类型，添加php类型，上传webshell一条龙

  

![](../Images/ab9843a83e5aa65d6be1d9e9af3f8b78.png)  
  

![](../Images/3cd030be100ad0dd9ee5e099365589c4.png)

  
  
拿下该api webshell  ，查询数据库信息，服务器为127.0.0.1  账号为6002，密码为kkk123

  

![](../Images/9eae90affcb23aedc6e0676bec9b1b7c.png)

  
  
通过密码心理学，端口6003的数据库账号密码应该是6003密码为kkk123 

  

尝试通过HTTP隧道登录数据库，查找管理员登录日志

  

![](../Images/0e441f9976a692d904bd3c7b8bbf6b83.png)

  
发现这些ip多为云南的ip，登录日志已备份。

  

6002和6003用的同一套程序，但是没有弱密码，直接通过数据库修改管理员密码，拿下6003这个后台  

  
好家伙，7000多条数据

![](../Images/b0f46054378ad348eab9751c9518e4a5.png)  
  
至此，该拿的数据库拿了，发现后台存在大量受害人数据，通讯录，相册，短信等，

![](../Images/a238973580679215faebd892c319066e.png)

  
  
如何处理？当然是删除了！

  

利用webshell和数据库权限删除掉网站以及数据库，相册内容存储在阿里云oss（可到阿里云取证）上面，通过配置文件查找到阿里云oss key，进入对象存储删除之。
