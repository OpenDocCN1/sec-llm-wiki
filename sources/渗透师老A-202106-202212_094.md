# 羊了个羊修改通关思路分析

用fiddler抓包，看到点击开始游戏后生成了两个请求文件分析了一下这是请求关卡数据，得到关卡id分别为80001和90015分析了一下确定90015是第二关也就是难度比较高的关卡

![](../Images/8ec112cf06dd098fd7fcae7ab7c57cc0.png)

接下来直接使用FiddlerScript  

直接在OnBeforeRequest类中加入替换关卡id的代码

*   
*   

```
if (oSession.url=="cat-match.easygame2021.com/sheep/v1/game/map_info?map_id=90015") {      oSession.url = "cat-match.easygame2021.com/sheep/v1/game/map_info?map_id=80001";
```

然后重新点击开始游戏之后，你会发现两个关卡都是简单的关卡了

PS：狼人吸血鬼模式也可以用同样的逻辑，只要开发者不更新关卡逻辑这个方法就应该一直可以用，每天的关卡id自己替换一下就好

![](../Images/02babf3849e1cff50aa6b37341685ceb.png)
