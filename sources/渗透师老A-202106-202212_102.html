接下来分析一下upload.ashx 拿出.net神器来分析一波


从这句代码来看

HttpPostedFile httpPostedFile = context.Request.Files["FileData"];

上传的名字应该是FileData。

如果不对那么永远都是返回0从这段代码就可以看出

string s = "0";  context.Response.Write(s);

所以应证了猜想参数不对

从代码里面可以知道,他要调用一个函数来验证上传参数的扩展名是否在这个函数中。

一看函数凉凉了白名单验证

 publicstaticreadonlystring[] allowExtend = newstring[]    {      ".jpg",      ".gif",      ".png",      ".bmp",      ".pdf",      ".xls",      ".xlsx",      ".doc",      ".docx",      ".rar",      ".txt"    };
