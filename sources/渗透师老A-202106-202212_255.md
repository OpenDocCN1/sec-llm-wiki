## 

GeoWiFi是一款功能强大的WiFi定位工具，

通过 BSSID 和 SSID 在不同的公共数据库上搜索 WiFi 地理位置数据。

![](../Images/859f8b2594d341ed77fb0963abd6b29b.png)

  

## **公开数据库**

> Wigle（https://wigle.net/）
> 
> Apple
> 
> OpenWifi（https://openwifi.su/）
> 
> Milnikov（https://www.mylnikov.org/）

## 

## **先决条件**

*   Python3
    
*   为了在Windows上显示表情符号，建议安装新的 Windows 终端。
    
    ⚠️
    
    为了使用 Wigle 服务，需要获取 API 并配置utils/API.yaml文件以替换Wigle 提供的“**编码使用**”数据的“ wigle\_auth ”参数值。 **这是通过 SSID 搜索所必需的。**
