# 俄罗斯：所有网站域名将迁移至.ru

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg5NzU1MzM5Mw==&mid=2247501413&idx=1&sn=fe643fc1c6b0cbb85ab546bf2a5329a4&chksm=c07280fbf70509ed68211dc2118994449fab1d5a6f5be6d06550be0e7a067146ace523568f8c&scene=126&sessionid=1681656464#rd](http://mp.weixin.qq.com/s?__biz=Mzg5NzU1MzM5Mw==&mid=2247501413&idx=1&sn=fe643fc1c6b0cbb85ab546bf2a5329a4&chksm=c07280fbf70509ed68211dc2118994449fab1d5a6f5be6d06550be0e7a067146ace523568f8c&scene=126&sessionid=1681656464#rd)

> 导读：在国际和大背景的形势与实际制裁下，俄罗斯在Runet启动之前，将境内所有网站域名迁移到.ru国家项级域。  

上周，乌克兰副总理米哈伊洛·费多罗夫致信监督互联网域名系统 (DNS) 的非营利组织互联网名称与数字地址分配机构 (ICANN) ，要求将俄罗斯与全球互联网的核心部分切断割开来。

  

ICANN的首席执行官 Göran Marby 明确表示拒绝，声明该组织必须“保持中立并采取行动支持全球互联网”。

  

“我们的使命不包括采取惩罚性行动、发布制裁或限制对互联网部分的访问——无论挑衅如何，”Marby 在回复费多罗夫时写道。“ICANN 始终如一地应用其政策并与记录在案之流程保持一致。单方面进行更改会削弱多方利益相关方模型以及在维持全球互联网互操作性政策的信任。”

  

尽管 ICANN 不会切断俄罗斯网络，也不会关闭 DNS 链接，但这并不意味着俄罗斯可以不受限制地访问互联网。

  

被称为 Anonymous 的黑客组织宣布涉足乌克兰与俄罗斯的冲突，它宣布正在与俄罗斯总统弗拉基米尔·普京与俄罗斯政府进行网络战争。

  

该组织在推特上有一个名为“Anonymous”的账户  （拥有 740 万粉丝和近 190,000 条推文），用于召集世界各地的黑客攻击俄罗斯。

  

上周四，黑客们破坏了俄罗斯空间研究所的网站并泄露了他们声称是从俄罗斯航天局 Roscosmos 窃取来的文件，同时留下言论：“别管乌克兰了，否则Anonymou会让你更上瘾。” 

  

与此同时，一场 DDoS 攻击重创了俄罗斯的 .ru 顶级域名，其目的是从根本上切断对所有以 .ru 结尾的 URL 网址访问。这些是支持乌克兰的黑客活动激增的最新事件。

  

俄罗斯也承认正在与乌克兰进行网络战。2 月 28 日俄罗斯新闻频道RT发表的一篇文章证实，它自己的网站以及克里姆林宫的网站已于上周五被 Anonymous 攻陷。文章还称，该组织周一以其他俄罗斯和白俄罗斯媒体为目标，将其主页替换为“停止战争”的相关内容。

  

据报道，俄罗斯日前已经封锁 Twitter、Facebook、各种新闻网站和主要移动应用商店。另外，总部位于美国的互联网骨干运营商 Cogent Communications 正在切断与俄罗斯的服务，此举将导致一些主流网站中断和性能不佳。

  

3月6日，俄罗斯政府决定最迟将于本月3/11将所有互联网服务切换至.ru俄罗斯国家顶级域名，放弃海外主机托管和流量。
