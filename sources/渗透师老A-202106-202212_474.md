# 中兴F450 F650测试成功

  
准备一个U盘插入光猫的usb口，使用useradmin进入光猫管理界面

  

（192.168.1.1）密码在光猫背后，查看“存储管理”是否识别Ｕ盘。

  

![](../Images/5836a53d40611be4471ae905a34391e6.png)

  
  
随便点击U盘路径，然后使用Burp Suite 进行截包。修改为“path=/”，使其跳转根目录，这样就可以获取光猫的所有配置文件。  

![](../Images/241cf721f8e15e87cb320fa9dac99e63.png)

  
  
将光猫超级密码文件 /userconfig/cfg/db\_user\_cfg.xml 复制到U盘，  

![](../Images/03ef57c7c78a995d8e3010c272bb4edb.png)

  
  
  
使用 52pojie大牛的工具进行解密。  
  

![](../Images/f8b0f03236c3aa6043d679665ba7cc0c.png)

![](../Images/5f9b6ca504968e5b433257cfd95ee685.png)

  
获取超级密码以后，就可以改桥接，删除TR069及其他电信后门程序。
