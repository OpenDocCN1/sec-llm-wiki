## 内网初步信息搜集

尝试使用得到的账号密码登陆 SSH 发现登陆成功：

![](../Images/459ac7ff8c7e33f258ec9c691049c847.png)

通过信息搜集发现当前机器是有两个网卡：

![](../Images/d1366f6a82b50f80634ad3df6e3d3102.png)

其中 `ens33` 是外网的网卡，`ens38` （10.0.1.6）是内网网卡，猜测有内网！  

PS：**在实战的内网渗透中：如果是在 `linux` 环境下的内网渗透尽量形成全部 `bash` 和 `python` 化，因为 `Linux` 都完全自带，而在 `windows` 下的内网渗透则尽量全部形成 `powershell`，`bat`、`vbs` 化，尽量不要过于依赖外部工具。**

所以我们用 `for` 循环 `ping` 一下 `ens38` 的 `C` 段：

```

 for i in 10.0.1.{1..254}; do if ping -c 3 -w 3 $i &>/dev/null; then echo $i Find the target; fi; done
```

![](../Images/07462d0c970f42b51cabbf6cbf0071a5.png)

发现内网还有一台主机存活：`10.0.1.7`

![](../Images/57397441ebcd9af1ea8e0523c11a7025.png)

## 内网渗透之大杀器 - CVE-2021-42287、CVE-2021-42278

通过对当前内网进行信息搜集发现当前 `Win7` 机器还有一个内网网卡：

![](../Images/92f816fa6caa629836aa1816f71d11a6.png)

且定位到域控到域控 `IP` 为 `10.0.0.12` :

![](../Images/0f9464c6600c7f26fb11f78cd9cf3085.png)

由于最近爆出了两个域内核武器漏洞：CVE-2021-42287、CVE-2021-42278，尝试看看能不能直接利用。

具体原理是：假如域内有一台域控名为 DC（域控对应的机器用户为 DC），此时攻击者利用漏洞创建一个机器用户，再把机器用户 saulGoodman的改成。然后利用去申请一个票据。再把的改为。这个时候 KDC 就会判断域内没有 DC 和这个用户，自动去搜索 DC（是域内已经的域控DC 的 sAMAccountName），攻击者利用刚刚申请的 TGT 进行 S4U2self，模拟域内的域管去请求域控 DC 的 ST 票据，最终获得域控制器DC的权限。

具体可以看我发布的文章，这里就不多赘述。

[只需要一个域用户即可拿到 DC 权限（CVE-2021-42287 and CVE-2021-42278）](http://mp.weixin.qq.com/s?__biz=MzkzNzMxNDc5Mg==&mid=2247483681&idx=1&sn=5757667e1a2f812244fe17b50ce46c27&chksm=c29011a6f5e798b089099860b7754babafd39154911a64a53669da882df6dec5118cf7942414&scene=21#wechat_redirect)  

于是直接使用 MSF 添加了一个 Socks：

![](../Images/84e086cf3cdefafe3e0bc3d31550fa8b.png)

然后添加路由：

```

run autoroute -s 10.0.0.7/24
```

![](../Images/5a06588522b37ccc209dc87de266f53f.png)

由于是 socks5 协议，我本地修改了配置文件然后直接利用脚本：

```

python3 sam_the_admin.py "redteam/root:Red12345" -dc-ip 10.0.0.12 -shell
```

![](../Images/00f4d9b1ef7cd8d062785453cd891fc6.png)
