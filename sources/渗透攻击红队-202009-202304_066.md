对于一个攻击者来说，被防守方发现是一件很可耻的事情，更别说被溯源到了个人信息。本篇文章主要写如何隐藏 C2，我这里用 CobaltStrike 来做演示，这种方式是利用成本最少最高效的，毕竟能白嫖域名和CDN，这种方式还能够避免被一些威胁情报平台溯源到真实的 VPS IP，打 hvv 够用了。

  

  

**域名 + CDN = 隐藏 CobaltStrike Server**

## 

**前期准备**

  

首先需要去 freenom.com 注册一个域名，在注册的时候需要挂美国的代理，而且个人账号信息也需要填写为美国的信息！

具体参考这篇文章：https://mp.weixin.qq.com/s/4LDpKKMuOHNSPxWrkv3tFA

注册完成后就可以看到注册的域名了：

![](../Images/e19bf7227cba468d3f34fb7dadeda62b.png)

之后在 cloudflare.com 注册一个账号，然后添加一个域名，就是刚刚组册的域名，然后选择最下面的：  

![](../Images/2b7ef9137f634e9c1baefd08780f29e4.png)

然后来到 DNS 处，找到该 CDN 的 DNS：      

![](../Images/1944b8a1aea456f60a1bbb5698932940.png)

填入到 freenom：  

![](../Images/819227ebdb58aed8c9821d3bc413515e.png)

之后来到 Cloudflare 缓存处开启一下，这样访问免费域名就不会出现访问延迟等情况：

![](../Images/21a746ebac41966488493eaed56f417c.png)

![](../Images/bc4a46375ded8ee09503cd62d89e6dd6.png)

最后添加一个解析 A 记录到自己的 VPS，名称就是域名、内容就是 VPS 的 IP 地址：

![](../Images/43599f601e4a0ec1839cfac6de95d5ed.png)

添加完成后就可以 ping 域名看看是否配置成功：  

![](../Images/21955bb1dcc36cc41916d4807906b36f.png)

超级 Ping 发现 CDN 也配置完毕，没有 VPS 的真实 IP：      

![](../Images/a46e3ea8e8530bdfd3ae4b8c8fc339b4.png)

  

**上线到  CobaltStrike 成功隐藏 IP**

  

之后我们来到 VPS Server，启动一下 teamserver，客户端连接 C2：

![](../Images/3956f786424d29b181254d2be6fd42ad.png)

在这之后新建一个监听器为 http 的，然后 Hosts 和 Beacons 都设置为域名：  

![](../Images/d93993da56fec66bbdd057bd79a8bf74.png)

最后生成一个 exe 上线看看：

![](../Images/52178fc4eacce27725c8450b329db139.png)

![](../Images/dc81e9f831e414361df069b4ef1893c3.png)

最后分析网络连接发现连接的 IP 已经是 CDN 的 IP 地址：

![](../Images/81d8e57fe3011c333c2afe3d8bb09a6c.png)

![](../Images/f9c3675a04f31b1bc4362e0f55c082b7.png)

通过微步在线沙箱分析发现成功隐藏了 C2 的真实 IP:

![](../Images/7be72e45ff6e90b2e28c8749daa36b7e.png)

![](../Images/b24154e07b627a6d8f58a702e6fb5eca.png)

这种方式能够在一定程度上防止被 BT 溯源到真实的 IP 地址，即使溯源到了真实的 VPS 的 IP，毕竟是匿名的 VPS ，除非反制拿到了 ROOT，否则也是无济于事。
