在渗透测试过程中路由器也是一个重要的口子，一旦拿到目标公网上的路由器我们可以做流量分析以及接下来要说的 PPTP 连 V\*N 进内网，废话不说兄弟们看文章。

  

**锐捷路由器设置 PPTP 进目标内网**

## 

**实际操作**

  

今天拿到一台路由器进去后发现有 PPTP 服务，可能有些兄弟对 PPTP 不是很了解，PPTP：(PPTP: Point to Point Tunneling Protocol）点对点隧道协议（PPTP）是一种支持多协议虚拟专用网络的网络技术,它工作在第二层。通过该协议，远程用户能够通过 Microsoft Windows NT 工作站、Windows xp 、 Windows 2000 和windows2003操作系统以及其它装有点对点协议的系统安全访问公司网络，并能拨号连入本地 ISP，通过 Internet 安全链接到公司网络。  

  

说白了就是可以通过 V\*N 来帮助我们直连到内网。

  

首先是拿到了一台路由器的权限发现是锐敏的路由：  

![](../Images/c2448452e4f1d9986c1236a077651161.png)  
来到 VPN 应用这里开启 PPTP 服务（公网ip）并且添加一个 PPTP 账号：  

![](../Images/41c462a1f46f509591726c8377217c0f.png)  
之后通过 Windows 自带的网络适配器添加一个：  

![](../Images/6a9be3ec553771896f9156b7f74f175c.png)

连接到工作区：  

![](../Images/d77bcbf42d81f07d2e5dbb2f50580a18.png)

使用我到 Internet 连接（V\*N）：  

![](../Images/46dde2f76c4e60e08df55eab5253d15d.png)

设置它公网路由器的IP：  

![](../Images/179fc6cdbd9917678c81f6c5c46da79e.png)

输入添加好的 PPTP 的账号密码：  

![](../Images/04f57eff9eea3e9e677f827b0a1a7bd4.png)  
连接的时候点击跳过：  

![](../Images/c66bc8858d1448d47f92dd96696f96c3.png)  
之后来到网络适配器这里会多出一个适配器，我们右键属性打开：  

![](../Images/81b3623b95a0e69c6c10dcebf1a7c6dc.png)

一定要选中点对点隧道协议 PPTP、可选加密（没有加密也可以连接）、以及后面三个选项要打勾：  

![](../Images/a51a2c99df3fc0e78bcfaf6c5d47bc76.png)

之后就可以通过 V\*N 连接到它内网了：  

![](../Images/9f6a8916c72cf3c1e4ec845b4e9ddf19.png)  
这样就到目标到内网了！之后就可以做内网横向、ARP投毒等一系列内网渗透操作了！
