介绍

    使用Python语言开发的一个能在内网中快速开启HTTP文件浏览服务的小工具 ,可执行Webshell，可用于在内网不出网时文件的下载，启动时会根据网卡IPV4地址输出URL(本地回环除外)。

项目地址：

https://github.com/Axx8/HTTPServer




Options：

   -h,        --help           show this help message and exit   -p PORT,   --port=PORT      自定义端口（默认：8080）   -d DIR,    --dir=DIR        自定义目录（默认：当前目录）   -s SHELL,  --shell=SHELL    自定义Shell路径（默认：/?shell=）




使用

默认端口 8080

HTTPServer.exe




执行Webshell

自定义Webshell路径：-s

HTTPServer.exe -p 8888 -d C:\ToolsBox -s Axx8
Get Shell  http://ip:8888/?Axx8=whoami




指定端口 -p
HTTPServer.exe -p 9999




指定目录 -d
HTTPServer.exe -d  C:\ToolsBox
