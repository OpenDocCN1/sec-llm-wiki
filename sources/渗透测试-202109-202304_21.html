解决渗透测试过程中遇到部分APP无法代理抓包等问题。

环境&工具

Windows  10

夜神模拟器 7.0.2.7 (Android 7 32bit)

frida-server-15.1.22 (上传到模拟器中)

Python  3.8.6

pip  22.1

frida   15.1.22

frida-tools  10.6.1 

r0capture


一、模拟器安装frida-server

打开夜神模拟器>进入设置>点击版本号5次>激活开发者模式>进入开发者模式>打开USB调试功能。


打开USB调试


二、查看连接设备

进入夜神模拟器安装目录下的bin目录查看到有adb.exe和nox_adb.exe，用其中一个都可以。

adb.exe devices或nox_adb.exe devices

看到已经有设备了。


三、上传frida-server到模拟器中

adb.exe push frida-server /data/local/tmp

上传到模拟器的/data/local/tmp目录

上传成功。

注:Frida-server的版本必须跟你宿主机的Frida版本一致。


四、进入shell运行Frida-server

adb.exe shellcd /data/local/tmpchmod 777 frida-server./frida-server

查看frida-server是否运行成功

新建一个adb shell

adb.exe shellps | grep frida-server

正在运行的进程，说明frida-server启动成功。


五、本地安装frida-tools

根据模拟器安卓手机的frida版本来安装Windows版的frida(版本必须一致)。

Python  3.8.6

pip 22.1

pip install fridapip install frida-tools

查看是否安装成功

pip list | findstr frida

显示如上内容则安装成功。

注意：版本要与本地Frida一致。


六、转发android TCP端口到本地

adb.exe forward tcp:27042 tcp:27042adb.exe forward tcp:27043 tcp:27043

连接判断

frida-ps -U frida-ps -R   无法使用-R时转发端口27042到本地

如果出现android手机的进程列表说明连接成功。


七、获取APP包名

My APK 工具(公众号后台回复0517获取)或ls /data/data


八、运行脚本抓包（这里测试抓取 "摩范出行 app" 的数据包）


APP包名：com.hxcx.morefun

安装依赖

pip install logurupip install click

抓包

注：运行脚本自动打开摩范出行 app，无需提前启动。

python r0capture.py -U -f com.hxcx.morefun  -p morefun.pcap
