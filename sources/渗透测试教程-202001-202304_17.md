# 渗透测试实战分享—从app到网站沦陷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3OTIwNDkzNQ==&mid=2651837843&idx=1&sn=d5a89b810d8d5057413f6b195ed0c098&chksm=f0b030bbc7c7b9addbf99b889b502cb4c0bf185b5e680adeadb3d7ae58d85cd2504b109017fb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3OTIwNDkzNQ==&mid=2651837843&idx=1&sn=d5a89b810d8d5057413f6b195ed0c098&chksm=f0b030bbc7c7b9addbf99b889b502cb4c0bf185b5e680adeadb3d7ae58d85cd2504b109017fb&scene=27#wechat_redirect)

分享一下今天对某 app 进行渗透测试，从基础的信息收集到拿到网站的 shell。总体来是还是很简单的

1.使用模拟器挂上代理并对 app 进行抓包，我们把其域名给拿出来

![](../Images/ce66234842b95cdf08851afe94daf51f.png "null")

1.使用工具对主域名进行敏感目录扫描，发现存在一个 admin 的目录

![](../Images/e9f77258c9c3e6ef455595db0ab1092d.png "null")

对该目录进行访问，发现存在管理后台，且目前看没有验证码，可以尝试爆破

![](../Images/a614b8dca754aba43eea2210575a5190.png "null")

输入不同的账号，看是否存在用户名枚举，如下输如 admin 显示账号或者密码错误

![](../Images/30c0af8258ba716a97fd9f0b7ab9fce4.png "null")

输入 admin2 显示账号未注册，所以此处存在账号枚举漏洞

![](../Images/16eb2d0092feb6642b2d3a6d219d9d3c.png "null")

1.进行表单爆破

使用 burpsuite 先进行枚举存在的账号，测试发现存在 admin 和 wangjie 两个账号

![](../Images/633fe3025f6bd446cea99e4040979aba.png "null")

使用这两个账号然后对密码进行爆破。因为该密码进行了 md5 加密，所以爆破前进行 md5 加密就行。如下成功爆破出来了

![](../Images/9f86db0808d938555cc8ce0997afe005.png "null")

对 md5 进行解密，发现密码就是 123456，这密码也够 nice

![](../Images/d528660518bd1ba139f2359ceb0db0e9.png "null")

1.使用该账号密码成功登陆后台

![](../Images/d738708fecb00b884decfa4359fa1fdf.png "null")

接着寻找可以利用的漏洞点，然后发现存在文件上传的地方，随便传了个后缀的文件过去，发现能上传成功

![](../Images/cb6e4b8884687540d301a1b247e2d738.png "null")

1.辨别网站使用的脚本语言

由于在 http 请求数据及浏览器插件中都没找到该网站使用的什么脚本语言。于是我搜索该 app 对应的公司，然后看他们公司的招聘岗位。发现正在招聘安卓开发，好家伙，那不就是 java 吗

![](../Images/bfd49d09e0647121e3aaeba8b600ab5e.png "null")

1.上传 jsp 冰蝎🐴

![](../Images/b4b42034c7b6b829403461aa15894143.png "null")

访问马子，没啥反应，估计行了吧

![](../Images/2340cc54abceff26979ed53699299251.png "null")
