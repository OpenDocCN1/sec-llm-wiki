| mimipenguin || linux 读密码，类似于 mimikatz，需要 root 权限 |
| --- | --- |
| Impost3r || Impost3r 是一个利用 C 语言编写，用来窃取 linux 下各类密码（ssh, su, sudo）的工具 |
| swap\_digger || swap\_digger 是一个 bash 脚本，用于自动化 Linux 交换分析以进行后期利用或取证。它自动进行交换提取和搜索 Linux 用户凭据、Web 表单凭据、Web 表单电子邮件、HTTP 基本身份验证、WiFi SSID 和密钥等 |
| tcpdump || 抓取数据包进行分析，获取明文账号密码，比如 ftp、telnet、http |
