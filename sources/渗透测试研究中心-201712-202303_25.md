### 拉取项目

首先从GitHub克隆到服务器上。

```
git clone https://github.com/ki9mu/ARL-plus-docker/
```

![](../Images/7240a705ba45de8e40bead1a05e22d92.png)

### 修改配置文件

因为ARL在配置文件里设置了黑名单，有时候项目为GOV或者EDU之类的时候无法进行扫描，所以在这里修改一下配置文件就可以解除限制。

```

cd ARL-plus-docker/
```

在这里删掉黑名单里的几项就可以了

![](../Images/6896e728fe85234d6d1a0910fe585541.png)

修改后：

![](../Images/e83bfe5f118ac5e436d49aff2ba3dcbb.png)

增加和修改riskiq以及fofa API

  

![](../Images/9b5c3bccabfc78003dfe7ecb7063cf70.png)

  

再增强版里添加了Oneforall的模块，所以在配置文件里需要打开，因为clone下来的代码里默认是Flase，这里将需要想打开的开关替换为Ttue即可。

```
vi oneforall-config/setting.py 
```

![](../Images/3a219602bb6bcf7690632ff89fe5764d.png)

修改后：

![](../Images/19933df56b6341f2d71cc2d5cd7484ca.png)

修改为配置文件之后就开始启动docker，先添加一个volume，然后docker-compose up -d就可以直接启动，拉取镜像的时候如果很慢可以换一下docker源。

```

docker volume create --name=arl\_db
```

![](../Images/b4d930af176ec0fce0373cfacaa32c95.png)

当看到一排done就说明成功了，这时候还需要进容器修改一下python代码，因为在python脚本里也有黑名单。先使用docker ps看一下容器的ID，然后进入这个容器进行修改，使用vi进行编辑。

```


docker ps #查看容器ID
```

修改前：

![](../Images/d27191d562dc8d7465896cf7dfe3ee3c.png)

![](../Images/c5ca6727d503c0417bc7647675ca9acc.png)
