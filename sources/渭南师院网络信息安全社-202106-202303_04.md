**软件逆向工程是什么？**

软件逆向工程（*Software **Reverse** Engineering*），是指从可运行的程序系统出发，运用多种技术手段，对软件的结构和流程进行逆向的拆解分析，从而推出软件产品的源代码、设计原理、系统结构、算法、处理过程、运行方法等的过程。

  

*软件逆向工程能做什么？*

如果想要维护一些设计文档和源代码已经丢失的软件系统，则只能通过逆向的手段逐步探清该软件系统的结构，才能进行维护。此外，为了向一些没有公开相关接口的软件添加功能插件，或向没有公开源代码的软件打补丁以修复漏洞，则必须要进行逆向工程才能做到这些事。

  

    另一个重要的应用方向是对计算机病毒与木马的行为分析，通过逆向工程，安全人员可以知晓这些恶意程序会执行哪些操作、怎样触发、如何传播等内容，甚至能从程序中隐藏的蛛丝马迹找到作者的信息。  

  

    不过，任何技术都有被恶意利用的可能，比如说商业竞争中不法者通过逆向竞争对手的软件产品，获取其中重要的算法和业务逻辑，从而复刻其产品，有时只需要进行一些小小的优化修改，就能胜过竞争对手。

  

*怎样进行软件逆向工程？*

    大多数的软件都需要进行编译才能够执行，通过OllyDBG、IDA等软件逆向工具对其进行反汇编或反编译，进行静态分析或动态调试，并借助软件或人工梳理出程序的执行流程，逆向人员就有可能还原软件的算法与业务逻辑，对于复杂的软件系统，则需要逆向人员具有足够的经验以分析软件系统各个模块之间的关系。很多软件会使用一些保护手段，这需要逆向人员掌握解密、脱壳、Anti反调试等技术与这些保护进行对抗。

*什么是注册机？*  
    注册机是指用于注册激活付费软件的工具，能通过注册机进行激活的软件通常需要一对用户名与激活码，通过在注册机中输入用户名，注册机就能自动生成该用户名对应的激活码。  
  
    本次我们将先逆向分析原需要激活软件的验证方式，然后手动编写一个注册机。  
  
*0x00 获得伪代码*  
    首先用静态逆向分析工具IDA打开原软件，IDA会自动定位到入口点，点击【跳转】→【跳转到伪代码】，即可从反汇编自动生成类C语言代码，大大提高了代码可读性。  

![](../Images/a5a15318352d49ec00ed0cf05e8efd3c.png)

使用IDA打开原软件  

![](../Images/d8a30dfd18cf044e9ebc95bdb141a6cf.png)

生成伪代码  
  
*0x01 分析逻辑*  
    在变量定义和初始化代码下方第一行就是设置随机化种子函数 *srand* ，这表明激活码的生成很可能依靠固定种子的随机数进行计算。  
  
    运行软件可知软件开始就会打印提示并要求用户输入用户名和激活码，随便输入后弹出了激活码格式错误的消息，看来存在验证。  
  

![](../Images/bd70eb7a45677ede677fd940977b2d09.png)

运行软件  
    回到IDA，根据上面得到的信息，很容易分析出 *Str* 变量是用户名，且不能大于8字符，*Str1* 变量是激活码，且长度为32字符。  
  
    接着往下看，*v8* 是用户名的长度，然后进入一个32轮的for循环，我们可以大胆猜测这就是激活码生成的核心逻辑。  
  
    循环的第一句从用户名中取出一个字符值赋给 *v4*，在这里用 *i* 取余 *v8* 使得数组不会越界，并且形成循环，也就是说如果用户名长度为8，那第9次循环取到的就是用户名的第1个字符值。  
  
    接下来生成一个随机数，与刚取出的值进行异或并赋给 *Str2*，可以得知 *Str2* 就是生成的激活码。  
  
    下面处理生成的激活码，如果为负，则取绝对值，然后取余10生成一位数字，并加上48生成 ASCII 字符（48是 ASCII 中 ‘0’ 的值），至此循环结束。  
  
    接下来使用 *strcmp* 对用户输入的激活码和生成的激活码进行比较，如果相等，则打印成功信息，不相等则打印错误信息。  
  
    程序逻辑分析到此就完成了，该软件的注册逻辑非常简单。

#define KEY_LEN 32

int main(){    srand(66);    char account[256],genKey[KEY_LEN+1];    printf("请输入您的用户名：");    scanf("%s",account);    if(strlen(account)>8)    {        printf("输入的用户名过长\n");        return 0;    }    int accountLen=strlen(account);    for (int i = 0; i < KEY_LEN; i++)    {        genKey[i]=account[i%accountLen]^(rand()%256);        if(genKey[i]<0)        {            genKey[i]=-genKey[i];        }        genKey[i]=(genKey[i]%10)+48;    }    printf("您的激活码为：%s\n",genKey);    return 0;}
