# Hook 技术简介

    Hook（挂钩）技术，顾名思义，通过向Windows系统“订阅”某些消息，从而监视软件或硬件的活动，并作出响应。

   Hook技术的核心在于SetWindowsHookEx函数，通过在c语言中引用windows.h，你就可以调用该函数，并获得大量的Windows API支持与宏定义。

SetWindowsHookEx的函数原型如下↓

*   
*   
*   
*   
*   
*   

```
HHOOK SetWindowsHookExA(  int       idHook,  HOOKPROC  lpfn,  HINSTANCE hmod,  DWORD     dwThreadId);
```

   其中，第一个参数为宏定义，表示你所要挂取的消息类型，其中WH\_KEYBOARD、WH\_MOUSE以及相应的低等级挂钩是最常使用的挂钩类型，它们通常用于挂取键盘与鼠标的消息，从而实现快捷键与全局快捷键功能。

    第二个参数为一个回调函数，当接受到所挂取的消息时，回调函数将被调用，从而执行自己的代码，回调函数的参数指示了消息的所有信息，不同的挂钩类型，将以不同的方式解读参数。

    第三与第四个参数指示挂钩模块与窗口进程，对于全局挂取，这两个参数可以为NULL。

   通过调用SetWindowsHookEx，你可以监视、截留、篡改Windows消息，从而实现相应的高级功能。

    Hook作为Windows系统的重要功能，已经被广泛的用于各个应用中，但Hook提供的功能过于强大，以至于常常被有心之人利用。在下期，我将讲解如何发现与反制Hook，敬请期待。
