# 【游戏漏洞】《华夏OL》背包物品属性分析

物品的名字和属性通过不同的遍历进行关联，我们得到了名字库之后还需要得到物品的属性。属性遍历可以顺着名字库继续向上分析，也可以通过物品数量等属性去分析，之后再找到名字相关的ID与名字库进行关联。

首先，扫描药品数量，得到两个结果**(如图)**

![](../Images/61606c448d8266069e0ad3c709e3a925.png)

改写第一个地址里的值后，我们发现游戏内的本地显示也跟着变化，说明这个地址很有可能就是我们要的物品对象下的数量。**(如图)**

![](../Images/db6b7f73b71254b738516d56c4ae0b11.png)

但是当我们改变了这个物品的位置之后，发现这个地址里的值也变了，而第二个地址中的数值是不变的，所以第二个地址才是我们要的。

通过OD对这个地址下访问断点，鼠标放在物品上时游戏断下**(如图)**

![](../Images/9ad2879eb83abf0994db94ee8ef4ec37.png)

这里的访问代码有很多，所以每个人断的位置都可能不同，不过并不影响分析的结果，继续向上分析edx的来源，来源于局部变量\[ebp-8\]，在经过多层局部变量和参数的传递后，得到来源于066C4194 处 call    dword ptr \[eax+70\]的返回值**(如图)**

![](../Images/2064fd9aaae04f884f5bfb1bd0ab96e3.png)

到函数内部进行分析，在00409FE6处  call    0040A560内得到+4偏移，在0040A472  处的call    0040A660内得到了一个数组**(如图)**

![](../Images/2064fd9aaae04f884f5bfb1bd0ab96e3.png)

而数组序号的来源公式是0x135C与0x400做商的余数**(如图)**

![](../Images/b44b9043121d9456da6ffd8f7c641c6d.png)

继续分析数组起始地址的来源，得到两层+4偏移之后来到了基地址所在的函数**(如图)**

![](../Images/c0c8ff8fa95d38b2ccb65c67fcd94b98.png)

接下来继续分析0x135C的来源，经过多层参数传递，得来源于0304E4F4  处的mov     eax, dword ptr \[ecx+eax\*8+958\]**(如图)**

![](../Images/071cc3c61c1572f4fe3dae4ee8527dec.png)

返回后可以得到基地址和偏移+28C**(如图)**

![](../Images/3c338d8fafd5c48de8e189c9dcc44dce.png)

这里的数组序号eax则为物品在背包里的位置，从0开始，最大值为8F，这样我们的背包物品就遍历完全了，只要将公式整理好编写成代码即可。
