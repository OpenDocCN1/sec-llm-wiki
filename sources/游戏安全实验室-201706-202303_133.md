**很多游戏挂机辅助，是需要大量上号的**

**而大量上号又受到机器硬件的影响，导致无法开足够数量的账号**

**其中一个制约条件就是显卡，那么对于显卡最好的优化方式就是黑屏**

**以下是通用型黑屏优化的效果以及实现原理和代码**

**原理:hook Direct3DDevice9::Present  在伪造的 Present  里添加黑屏代码 详情见源代码**

**下边是核心代码**

**DWORD WINAPI ****HookD3d9****(PVOID parg)**

**{**

**BOOL isHook=(BOOL)parg;**

**DbgPrintfA("HookD3d9  isHook=%d \\r\\n",isHook);**

**if (g\_D3DDevice==NULL)**

**{**

**g\_D3DDevice=GetNewD3DDevice(); //此函数必须在单独线程执行 不能在入口函数执行**

**}**

**//**

**PVOID pPresent=(PVOID)GetClassProcAddr(&IDirect3DDevice9::Present); //68 0x44 此pPresent 处可以取得 Present与g\_D3DDevice的偏移0X44**

**if (g\_D3DDevice==NULL)**

**{**

**DbgPrintfA("HookD3d9 369 d3d Null Error  397 ");**

**return -1;**

**}**

**PDWORD poldVcallPresent = (PDWORD)\*((PDWORD)(\*(PDWORD)g\_D3DDevice + 0x44)); //0x44为**

**if (g\_pNew\_Present==NULL)**

**{**

**g\_pNew\_Present=poldVcallPresent;**

**}**

**DbgPrintfA("406 &IDirect3DDevice9::Present=%08X poldVcallPresent=%08X g\_D3DDevice=%08X",\*(DWORD\*)(pPresent),poldVcallPresent,g\_D3DDevice);**

**if (isHook)**

**{**

**DbgPrintfA("安装d3d9Hook Code136815");**

**hookApi(&g\_pNew\_Present, New\_PresentVcall);**

**}   else**

**{**

**DbgPrintfA("卸载d3d9HOOK Code136816  ...");**

**unhookApi(&g\_pNew\_Present, New\_PresentVcall);**

**//Freeg\_D3DDevice();**

**g\_pNew\_Present=NULL;**

**}**

**// Sleep(1000);**

**// MessageBoxA(0,"d3d Hook OK ",0,0);**

**return TRUE;**

**}**
