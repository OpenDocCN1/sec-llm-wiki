分析角色对象我们从角色的血量入手，CE搜索整数型，通过筛选得到了3个数值(如图)

![](../Images/c9dd267dad52e81b6ea688d508ae1cc0.png)

其中的前2个数值是当前血量，第三个是最大血量。我们在数值和最大血量比较接近的当前血量上下访问断点，游戏断下(如图)

![](../Images/1e396c1c8b846bf33f09d5d17e99469d.png)

   

这里得到了两层偏移\[ECX+0D0\]+48，执行到返回继续分析(如图)

![](../Images/93f6b53568fcfa9743becf5db0fb2511.png)

   

ecx来源于eax，为CALL 004d5390的返回值，我们到CALL里分析EAX的来源(如图)

![](../Images/10e6c99cd904e53f7eb7077d5e490329.png)

   

eax又来源于call 004D5190，而CALL内部的代码相对来说比较的复杂(如图)

![](../Images/fcdf2ef0a999a1bcee9490bd1415f042.png)

   

这里是一个循环，分析起来也很简单，但是对于我们来说分析这段代码不如直接内联汇编，或者直接调用函数来的方便，所以我们来到外层调用函数的位置。

 

call 004D5190有2个参数，第一个参数是1FD3，是角色的ID，可以通过CE搜索得到常量，而第二个参数是一个结构体，里面分别存放的1FD3和0两个DWORD型数据。而向上分析ECX的来源，我们发现ECX最终来源如下

mov     ecx, dword ptr fs:\[2C\]

mov     edx, dword ptr \[ecx+eax\*4\]

mov     ecx, dword ptr \[edx+8\]

这里出现了mov     ecx, dword ptr fs:\[2C\]这样一条代码，这里属于线程局部静态变量，我们可以通过TlsGetValue()等函数来对其进行读取。读取方法大家可以去百度，很容易实现。

接下来通过代码注入器做一个测试，我们临时使用下ECX的值，代码如下

push    7010000

push    1FD3

mov   ecx,0B74A2F8

call    004D5190

mov  ecx, 7010010

mov \[ecx\],eax

这样我们就得到了想要的角色对象(如图)

![](../Images/5c3e183bb14d65326b438396ceda8028.png)
