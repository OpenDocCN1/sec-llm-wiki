**一、分析**

最近还在完善\[PlantsVsZombies\]的外挂功能，思考着如果人不在的时候，能有一个外挂帮助挂机，继续游戏就好了，于是有了写一个机器人的想法。

如果需要实现自动游戏，肯定需要从游戏中获得反馈的数据。比如在僵尸吃掉我们的植物的时候，外挂应该怎么样去反击，当一大波僵尸来临的时候，我们又应该怎么样去种植植物防守。

对于植物大战僵尸这款游戏，想要获得反馈数据，可以通过读取内存中的数据的方法，比如判断僵尸是否被制造，攻击植物是否发生，植物生命值是否减少为0……等等逻辑判断。另外一个可行的办法就是从屏幕上读取像素来获得。在通常情况下

> ![](../Images/3c8d9de43aa34a43fd6da1ac60f63177.png)

代表了游戏进度，红色的地方代表这是否为攻击的界点（即一大波僵尸出现的地方）

 

在僵尸攻击植物的时候界面显示为：

> ![](../Images/4a7b196df360d3cbac7056ebe46e4c8a.png)

攻击之后为

> ![](../Images/f0e6aa54b4183b4947ab2ece9d5c29d9.png)

像素明显发生了变化，于是，我们就可以通过像素采集来获得游戏中的信息了。

 

**二、实现方式**

首先我们利用通过代码获得游戏在屏幕中的绝对位置

```
hGameWnd = FindWindow(NULL,szwindow);
	if (hGameWnd == NULL)
	{
		printf("error\\n");
		return 1;
	}
	RECT lrect;
	GetWindowRect(hGameWnd,&lrect);
	p.x = lrect.right;
	p.y = lrect.bottom;
```

> 然后通过按键精灵的抓图功能，算出偏移，并抓取你敢兴趣地方的像素点

> 接下来就是判断像素了（下面是部分判断逻辑）

```
while (true)
	{
		//最后一波攻击
		COLORREF cr2 = GetPixel(hdc,dwx-188,dwy-15);
		if(cr2 != 0)
		{
			
			PostMessage(hthreadwnd,WM\_ATTACKWAVE,ATTACK\_SECOND,0);
			//判断坚果是否没有了，如果遭到攻击，则补充坚果，同事种植炸
			break;
		}
		Sleep(3000);
	
	}
		
		COLORREF dwcr\_nut\[5\];
		DWORD x,y;
		x = dwx-440;
		y = dwy-433;
		for (int i = 0; i < 5; i++)
		{
			dwcr\_nut\[i\] = GetPixel(hdc,x,y+i\*100);
		}
		while (true)
		{
			for (int i = 0; i < 5; i++)
			{
				
				if(dwcr\_nut\[i\] != GetPixel(hdc,x,y+i\*100))
				{
					PostMessage(hthreadwnd,WM\_ATTACKWAVE,ATTACK\_NUT,i);
					continue;
				}
			}
			DWORD buf\_read,br;
			ReadProcessMemory(hProcess, (PVOID)dwAddrbase, &buf\_read, sizeof(buf\_read), &br);
			ReadProcessMemory(hProcess, (PVOID)(buf\_read+dwAddroffset\_money\_first), &buf\_read, sizeof(buf\_read), &br);
			ReadProcessMemory(hProcess, (PVOID)(buf\_read+0xB8), &buf\_read, sizeof(buf\_read), &br);

			//没有僵尸，判定关卡结束，终止线程
			if(buf\_read == 0)
				return 0 ;

			Sleep(3000);
		}
```

**三、结论：**

结合内存和像素判断，可以更精确的知道游戏中的信息，进而采取相应的操作（程序中将自定义了windows消息，将地址和当前状态写入windows消息参数，发送到对应的消息处理过程中进行相应处理，进而实现了自动游戏）。
