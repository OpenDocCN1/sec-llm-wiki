# 【游戏漏洞】《元气骑士》无限钻石破解分析

**首先反编译APK，得出以下结果（如图）**  

![](../Images/9d9dcb2b68c677dee23be989a26222eb.png)

解压缩APK后发现了lib/armeabi-v7a/文件夹中的libil2cpp.so以及assets/bin/data/Managed/Metadata/中的global-metadata.dat，直接用Il2CppDumper对libil2cpp.so进行分析，得出dump文件。

接下来打开虚拟机，通过对比shared\_prefs中的文件得出gems为钻石在存档中的命名（如图）

![](../Images/4a9c30ce94b672be6a151ba262e9dc1a.png)

接下来在dump文件中搜索gems，最终锁定get\_gems()为获取钻石的函数，函数头部为0x5b7e70（如图）

![](../Images/c843bb90222cac09c6073303688b8a12.png)

IDA加载libil2cpp.so，跳到0x5b7e70地址处（如图）

![](../Images/009a7f10f011c28b9b0c6e6409083989.png)

我们有两种办法来修改钻石数量，一种是在函数最后对R0赋值时进行改写代码，另一种是在返回后对R0进行改写，第一种在这里并不适合，所以我们选择第二种，在函数头部查看交叉引用，跳到引用处（如图）

![](../Images/cdbe73c9d8d292a509f0193a5bb1b50f.png)将004502A8     MOV    R1, R0代码修直接修改为MOV    R1, #0x100000即可。

修改后重编译APK，再次打开游戏，钻石修改成功（如图）

![](../Images/825b574ec79ea76181856aa63d197e98.png)
