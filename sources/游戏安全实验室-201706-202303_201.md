# 【游戏漏洞】《流放之路》系列之角色信息

今天我们通过血量来分析下流放之路的角色信息。

首先用CE搜索角色血量，我们得到了不止一个结果（如图）

  

![](../Images/64040f36b2fafaed8b22a015bce9f12e.png)

   

我们需要在这几个地址中找到角色对象下的血地址，分别对这些数值进行改动，我们发现在更改某个地址的数值时，角色血量球上的数值会发生改变（如图）

  

![](../Images/bf094239662cb2e657627182d8872765.png)

   

F9会发现可以断到很多不同的位置，我们选择其中一个位置继续分析（如图）

  

![](../Images/9804056a801778806f2e64b5313ce4a1.png)

   

执行到返回后，得到1C偏移，而0x7723D6处的CALL中有eax的来源（如图）

  

![](../Images/21af7745e7c19e168181df0fc76a1889.png)

进入CALL里继续分析，得到了一个数组和一个+4偏移（如图）

  

![](../Images/d6e26ac16032a47ee4149f7a1c87475d.png)

   

经过下断分析，我们发现这个数组并不是周围对象的数组，而是一个角色对象下的属性数组，而且在这里下F2断点，数组序号ecx大部分时候都是3，所以我们暂且把这个+ecx\*4看成是+0xC。

我们继续分析，发现从这个子程序进行返回，无法得到基地址，因为来源是被临时写入的，所以我们要通过其他方法继续分析。

我们在角色对象的虚表上下访问断点，游戏断下，执行到返回和可以得到三个较大的偏移（如图）

  

![](../Images/47cf597367783ea91b403bb4e6684b1f.png)

![](../Images/60b1b4a785c9a755ec472513f98bdcaa.png)

![](../Images/479a3ce12f78fc1f64d8cbf90d2d09c5.png)

 

然而，如果我们顺着8DC的偏移继续分析，就进了陷阱里，我们要在4414偏移处找其他访问，在这个0x61871b的eax上下断后游戏断下（如图）

  

![](../Images/498135817d5996af3fdbe63925dcbdcb.png)

  

继续顺着+144偏移向上分析，得到了3层很小的偏移（如图）

  

![](../Images/2624181dd916ab8235758646a78280ec.png)

  

继续向上分析，这里要注意跳转会影响代码的执行过程，返回后得到+38偏移和基地址（如图）

  

![](../Images/57c183f3bfd4c3356a9da74a9e93b8bb.png)

  

![](../Images/672662cf075e1833edce5155a4ee81f6.png) 

  

**最终我们得到公式如下**

 \[\[\[\[\[\[\[\[\[129FCD0+38\]+4\]+14\]-8\]+144\]+4414\]+1D8\]+4\]+3\*4\]+1C+10最大血

 \[\[\[\[\[\[\[\[\[129FCD0+38\]+4\]+14\]-8\]+144\]+4414\]+1D8\]+4\]+3\*4\]+1C+14当前血

由于服务器对心跳的验证过于频繁，所以游戏下断最好不要超过5秒钟，否则会小退或者崩溃。
