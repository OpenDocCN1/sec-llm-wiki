l **前言**  

程序分2步验证，第1步验证考验的是二进制bit矩阵乘法运算，第2步验证考验的是Crc32和FNVhash算法的碰撞攻击。

l **逆向分析**

1.首先，通过you lose字符串定位到关键函数，部分函数分析如下：

![](../Images/3cbc41b7c280ce82d1165dccb1d2c978.png)

2.第1步验证需要提供一个名为zapus\_dll的dll，并且需要导出zapus\_get函数。接下来分析关键函数sub\_4011D4

![](../Images/ed939d144bdae0db64e79e3d02aa49ed.png)

3.逻辑是这样的，一个0x80\*0x10的二维数组A，与dll导出函数获取的0x10大小的数组B进行运算，得到一个0x10大小的数组C与结果比较，相同则验证通过。其中上图最长的一行代码相当于把每个字节变成8个bit进行运算，逻辑就变成了 0x80\*0x80bit的矩阵A 乘上 0x80bit的矩阵B，得到0x80bit的矩阵C，也就是 A\*B=C，现在A,C已知，求B。

4.其中B=A^(\-1)\*C，就是先求矩阵A的逆矩阵A^(\-1 )，在求逆矩阵与C相乘的得到的结果B，就是DLL导出函数需要给出的结果。这里要注意的是，bit矩阵运算中的加减（+-）需要转换为并且（&），乘除（\*/）转换为异或（^）。

5.接下来是第二步验证，第二步计算了DLL文件的crc32和FNVhash结果，与特定的结果比较，如果相同则通过验证。

  

![](../Images/2382649e1adea6634c4e6a8a88d40a1f.png)

6.这里先对crc32进行碰撞，主要思路是crc32碰撞可以在文件最后添加4个字节（这4个字节是用结果对结果进行碰撞得出来的），而不改变其crc32的结果，所以先碰撞出符合的crc32结果，再通过添加4个字节对FNVhash算法的碰撞。

（感觉这里没有说明白，可以参考：http://www.pediy.com/kssd/pediy06/pediy6937.htm）

| int main(int argc, char\* argv\[\]){long size;char \*szBuf;fstream fi("zapus\_dll.dll", ios::in | ios::binary); fi.seekg(0, ifstream::end);size = fi.tellg();fi.seekg(0); szBuf = new char\[size\]; int nNewSize = size + 4;char \*szNewFileBuf = new char\[nNewSize\]; fi.read(szBuf, size);fi.close();memcpy(szNewFileBuf, szBuf, size); // 用结果对结果碰撞// 得到的4个字节szAdd加到文件（crc32页为0x614C5347）尾部是不改变其crc的char szAdd\[4\];DWORD dwAdd = rCRC32(~0x614C5347, ~0x614C5347);memcpy(szAdd, &dwAdd, 4); // 碰撞开始for (int nloop = 0; 1; nloop++){char \*a = szBuf; // 碰撞Crc// 这里是指将原文件的crc碰撞成0x614C5347，这样就可以无限增加代码而不改变其crcDWORD x = rCRC32(~0x614C5347, ~CRC((BYTE\*)a, size)); // 将碰撞的结果加到文件后面，组成新文件，对其FNVhash进行碰撞memcpy(szNewFileBuf + size, &x, 4);int nFNVhash = FNVhash(szNewFileBuf, nNewSize); // 这里是循环增加4个字节来碰撞FNV的，大小控制在100MBint nCount = 0;for (nCount = 0; nCount < 100 \* 1024 \* 1024; nCount++){nFNVhash = FNVhash(szAdd, 4, nFNVhash);if (nFNVhash == 0x614C5347){// FNV也碰撞成功，输出文件cout << nCount << endl;cout << nloop << endl; fstream newfile("new.bin", ios::out | ios::binary | ios::app);newfile.write(szNewFileBuf, nNewSize); for (int i = 0; i < nCount+1; i++){newfile.write(szAdd, 4);}newfile.close(); break;}} // 增加100MB大小结果都碰撞失败，修改文件最后的内容（+1）重新进行碰撞\*(int\*)(szBuf + size - 4) = nloop + 1;\*(int\*)(szNewFileBuf + size - 4) = nloop + 1;} system("pause");return 0;} |
