# 数字灵动集团助力2023年长沙市网络安全应急演练

为筑牢网络安全防线，提升网络安全保障水平，4月18日，2023年长沙市网络安全应急演练在国家网络安全产业园（长沙）正式启动，本次应急演练由湖南省委网信办、长沙市委网信办主办，国家网络安全产业园（长沙）测试认证中心等多家单位联合承办。
```

![](../Images/3ebd9d5215ba0d195be83334e8539793.png)​

```


本次演练活动系长沙市举办的第三届城市级大规模网络安全应急演练，由国内一流网络安全企业、信息安全机构、高校等专业力量组成的18支网络安全攻击队伍，对全市党政机关、医疗、教育、金融、交通、工业等重点领域的145家关基单位，进行为期10天的高强度实兵实战攻防演练，这是对全市关基单位网络安全防护水平的一次重大检验。
