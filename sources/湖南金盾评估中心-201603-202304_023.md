# 喜报|湖南金盾荣获湖南省委网信办联合国家计算机网络与信息安全管理中心技术支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662127456&idx=1&sn=1f2594f04c3f3dad2488e1c12943980e&chksm=f35ae3b0c42d6aa6f195b830a275c61baed05aa08cca02fbf53df7d5bd42ffe37929a72afab0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662127456&idx=1&sn=1f2594f04c3f3dad2488e1c12943980e&chksm=f35ae3b0c42d6aa6f195b830a275c61baed05aa08cca02fbf53df7d5bd42ffe37929a72afab0&scene=27#wechat_redirect)

2022年9月，湖南省委网信办联合国家计算机网络与信息安全管理中心湖南分中心，面向社会公开遴选技术支撑单位。此次参与评选的都是行业实力雄厚的领头企业。评审专家组对申报单位的综合能力、技术实力、保障水平、合作情况等方面进行了综合评审。经过评审和认真研究，湖南金盾以实力成功入选！这份荣誉也是对金盾在网络安全行业的突出贡献给予的高度认可。

  

未来，湖南金盾将立足新的起点，迈上新的征程，开创新的辉煌！
