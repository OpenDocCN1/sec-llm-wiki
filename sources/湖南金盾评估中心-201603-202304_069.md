# 【安全风险通告】Apache Log4j任意代码执行漏洞安全风险通告

1

**漏洞概述**

漏洞名称：Apache Log4j任意代码执行漏洞

CVE编号:  CVE编号

风险等级:  **高危**

漏洞类型：代码执行

2

**漏洞详情**

Apache Log4j 是 Apache 的一个开源项目，基于Java的日志记录工具。Apache log4j-2 重写了Log4j框架，是 Log4j 的升级。我们可以控制日志信息输送的目的地为控制台、文件、GUI组件等，通过定义每一条日志信息的级别，能够更加细致地控制日志的生成过程。

Log4j-2中存在JNDI注入漏洞，当程序将用户输入的数据进行日志记录时，即可触发此漏洞，成功利用此漏洞可以在目标服务器上执行任意代码。

3

**影响范围**

**Apache Log4j 2.x <= 2.14.1**

4

**修复建议**

1、JAVA应用检测

排查Java应用是否引入log4j-api,log4j-core两个jar；

  

2、若存在应用使用，极大可能会受到影响，升级所有相关应用到log4j-2.15.0-rc2 版本。

请到如下链接获取修复后的官方版本：

https://github.com/apache/logging-log4j2

https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc2
