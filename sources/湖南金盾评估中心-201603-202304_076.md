# 长沙市市委一级巡视员、市先进计算及信息安全产业链链长张宏益一行调研网络安全测试认证中心

11月9日下午，长沙市市委一级巡视员、市先进计算及信息安全产业链链长张宏益一行莅临湖南金盾，考察调研国家网络安全产业园区（长沙）网络安全测试认证中心运行情况，网络安全测试认证中心负责人、湖南金盾董事长邓庭波进行接待，并现场汇报了中心的运行情况、发展规划及需求。  

  

![](../Images/c959d3f5ad0392f3ef87827f17751da5.png)

*张宏益链长（中）调研网络安全测试认证中心*  

  

网络安全测试认证中心自今年3月成立以来，以“打造全国首创的网络安全领域全方位测试认证公共服务平台”为目标，现已建立覆盖近70位专家的专家库，打造了网络安全前置审查线上平台，率先实现网络安全审查“线上+线下”相结合的模式，完成了43个信息化项目的45次网络安全审查的技术支撑工作，通过前置审查将网络安全风险关口前移，有效提升了信息化建设项目的网络安全水平。目前中心正在开展网络安全审查标准的制定工作，以推动网络安全审查的标准化和规范化。中心不仅网络安全审查工作成果斐然，在打造测试认证全方位服务平台、推动安全检测与认证产业发展、为主管部门监管APP和小程序安全提供技术支撑等方面也有一定成效。

  

![](../Images/6ceb4c0bc7dd4e9fe181d769de40e08e.png)

*张宏益链长听取中心运行情况汇报*

  

![](../Images/0e9399e7d11d9202e0d8a3d3ff397cb7.png)

*董事长邓庭波进行汇报（左一）*

董事长邓庭波介绍，中心未来将着力加大对已建信息化系统定期检测力度，逐步做到全覆盖；研发网络安全测试认证线上平台，打造最具权威性的第三方测试认证机构；在信创领域探索新的检测技术，为信创系统把好第一道关；与“三中心”融合，共同支撑国家网络安全产业园区（长沙）建设。

![](../Images/404b767dd00575cad17ebcc5efdf711c.png)

*张宏益链长指导中心工作开展*

  

调研过程中，张宏益链长充分肯定了中心的运营进展和工作成果，并对中心的发展需求和发展规划给予了亲切指导。他指出，中心是国家级的中心，要争取并充分发挥国家级资质的效用，加强核心人才培养，同时不断加强技术创新能力，提高核心竞争力，进行市场化运作，做大做强，为国家网络安全产业的发展做出更多贡献。
