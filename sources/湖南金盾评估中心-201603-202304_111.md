# 湖南金盾董事长邓庭波受邀出席2021信息技术应用创新论坛并分享网络安全审查实践经验

![](../Images/db234b032dd466bc9d019ff55a7391b9.png)

*2021信息技术应用创新论坛·湖湘特色应用示范创新分论坛现场*

为推动信息技术应用创新产业发展，7月14日下午，由湖南省工业和信息化厅、长沙市人民政府、长沙高新技术开发区联合主办的2021信息技术应用创新论坛·湖湘特色应用示范创新分论坛在湖南国际会展中心举办，国家网络安全产业园区（长沙）网络安全测试认证中心主任、湖南省金盾信息安全等级保护评估中心有限公司董事长邓庭波受邀出席论坛，并分享了网络安全审查技术服务的探索与实践经验。  

 

![](../Images/f5b82843e717edfcad6567b57ff9e59b.png)

*董事长邓庭波作主题演讲*

  

会上，邓庭波从近期重大网络安全审查事件入手，强调了网络安全审查工作的内容和重要意义，介绍了网络安全测试认证中心审查工作进展、成果以及未来的发展展望。

 

![](../Images/96e9d532b5cbc06a0fa48b3887ba0ee0.png)

*董事长邓庭波分享网络安全测试认证中心审查实践经验*

  

作为具有湖湘特色的网络安全产业应用示范创新，由湖南金盾牵头组建的网络安全测试认证中心自今年4月底正式开展审查工作以来，秉承“一个平台、资源共享、多方联动、服务各方”的服务理念，不仅率先构建了“线上+线下”相结合的网络安全审查模式，建立了包含近70位业内资深专家的专家库，规范了信息化项目网络安全设计方案的编写，完成了多个政府项目的网络安全审查，有效提高了政府投资信息化建设项目的网络安全水平，还启动了网络安全审查地方标准起草工作，正不断完善标准建设，为网络安全审查工作提供更权威的审查依据。邓庭波表示，今后，测试认证中心将不断开拓创新，切实加强网络安全审查技术核心优势，为推进网络强国建设贡献力量！
