# 【安全风险通告】Shiro又爆高危漏洞，Apache Shiro身份验证绕过漏洞安全风险通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662124941&idx=2&sn=ea27664b0618d9c72a3763a971112c74&chksm=f35af95dc42d704b661add7dba478209afef08a2113b53730a21e1bb6846787f68d15f8f6370&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662124941&idx=2&sn=ea27664b0618d9c72a3763a971112c74&chksm=f35af95dc42d704b661add7dba478209afef08a2113b53730a21e1bb6846787f68d15f8f6370&scene=27#wechat_redirect)

  
  

2020年8月18日，安全监测中心检测到Apache Shiro官方发布安全通告  Apache Shiro身份验证绕过漏洞（CVE-2020-13933），经过分析，攻击者可以通过构造特殊的HTTP请求实现身份验证绕过。鉴于该漏洞影响较大，建议客户尽快升级到最新版本。

  
  

漏洞详情

1

漏洞描述

Apache Shiro是一个强大且易用的Java安全框架，通过它可以执行身份验证、授权、密码和会话管理。使用Shiro的易用API，您可以快速、轻松地保护任何应用程序——从最小的移动应用程序到最大的WEB和企业应用程序。

  

2

风险等级

风险评级为：高危

风险等级：蓝色（一般事件）

  

3

影响范围

Apache Shiro < 1.6.0

  

4

处置建议

更新至最新版本：http://shiro.apache.org/download.html
