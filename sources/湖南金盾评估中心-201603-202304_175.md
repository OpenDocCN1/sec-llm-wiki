# 湖南金盾获国家信息安全漏洞库三级技术支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662124654&idx=1&sn=6e4bd78ccfe630b45adbb2c12dca4653&chksm=f35af8bec42d71a86a6e405615e5546ff3d73b9b89a726684bacd3d4180803b54bb427c53405&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662124654&idx=1&sn=6e4bd78ccfe630b45adbb2c12dca4653&chksm=f35af8bec42d71a86a6e405615e5546ff3d73b9b89a726684bacd3d4180803b54bb427c53405&scene=27#wechat_redirect)

2020年6月，湖南金盾获中国国家信息安全漏洞库(CNNVD)颁发的**“中国国家信息安全漏洞库三级技术支撑单位”。**

  

![](../Images/cb1d18d1e0cf17dd2ddf61f533b1a35a.png)

  
  
  
关于CNNVD  
  
  

国家信息安全漏洞库，英文名称"China National Vulnerability Database of Information Security "简称"CNNVD"，于2009年10月18日正式成立，是中国信息安全测评中心为切实履行漏洞分析和风险评估的职能，负责建设运维的国家信息安全漏洞库，面向国家、行业和公众提供灵活多样的信息安全数据服务，为我国信息安全保障提供基础服务。

**湖南金盾**作为独立于第三方的安全服务厂商，一直致力于分析和研究各种安全缺陷和安全隐患，积极发现、收集、分析、研究、报送漏洞信息。凭借核心技术团队在网络安全领域多年的攻防渗透经验，不断丰富网络信息安全漏洞库。2019年下半年，湖南金盾已向国家信息安全漏洞库提交多个通用型漏洞。

  

此次湖南金盾被评为国家信息安全漏洞库(CNNVD)“三级技术支撑单位”的称号，标志着对湖南金盾技术实力的信任。湖南金盾肩负重任，定当全力以赴共同维护国家重要行业和关键基础设施的网络空间安全。
