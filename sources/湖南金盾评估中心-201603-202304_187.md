# 415国家安全日 | 维护国家安全，人人有责

       2015年7月1日，新国家安全法实施，规定每年4月15日为全民国家安全教育日，并对我国政治安全、信息安全等11个领域的国家安全任务进行了明确。网络信息安全在国家安全中占据了重要地位，习近平主席曾指出，没有网络安全就没有国家安全。415全民国家安全教育日，一起来聚焦网络安全。公安部网络安全保卫局邀请网络安全教育宣传员黄轩、王珞丹、宋佳，与您一起开展“共同关注网络空间、守护网络清朗空间”互动答题活动。

![](../Images/037c5596b3f0268d601ccacdd58fc8cf.png "微信图片_20200415092854.jpg")![](../Images/9732f0a46474a0db447d1dc31bc14569.png "微信图片_20200415092858.jpg")![](../Images/f14ec31a661420ec4ef76d8a57b138ab.png "微信图片_20200415092850.jpg")

       伴随着互联网的发展，网络安全问题时常发生。湖南金盾成立**应急响应团队**，专注于信息安全领域。积极向客户单位提供**网络安全信息报送、网络安全应急处置、网络安全专项配合、以及其他工作（如交流培训、安全竞赛等）。**为用户制定**网络安全事件应急预案，**及时处置系统漏洞、计算机病毒、网络攻击、网络侵入等安全风险；在发生危害网络安全的事件时，**立即启动应急预案，**采取相应的补救措施。

  

      网络安全不仅事关广大人民群众的工作生活，更关乎国家安全和国家发展。湖南金盾继续用责任和担当守护国家、企业和人民的网络安全，勇担网络安全行业领军企业责任。
