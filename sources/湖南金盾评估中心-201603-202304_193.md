# 【安全风险通告】Apache Shiro＜1.5.2 权限绕过漏洞

## 一、漏洞描述

2020年3月24日，安全应急响应中心检测到Apache Shiro 官方发布安全更新，修复了一个权限绕过漏洞。攻击者利用该漏洞可以绕过验证访问到后台功能。  
Apache Shiro 是一个应用广泛的权限管理的用户认证与授权框架。官方于24日凌晨发布1.5.2版本，该版本修复了一个权限绕过漏洞。在一定条件下，攻击者可以构造恶意请求访问，从而绕过权限验证访问到后台功能。湖南金盾提醒Apache Shiro用户尽快采取安全措施阻止漏洞攻击。

## 二、影响版本

Apache Shiro＜1.5.2

## 三、安全版本

Apache Shiro＞=1.5.2
