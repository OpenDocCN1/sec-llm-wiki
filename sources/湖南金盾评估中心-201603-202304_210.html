【威胁通告】Windows CryptoAPI高危漏洞（CVE-2020-0601）

原文：http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662124020&idx=2&sn=4fe76f90a9728c3a39429b90f9be2077&chksm=f35afd24c42d7432c774c12c1b05ef393847aef2a423e877e297829bcbfab9c90792d701f89b&scene=27#wechat_redirect

概述


      微软发布了2020年1月份的安全更新，其中修复了一个Windows CryptoAPI的验证绕过漏洞(CVE-2020-0601)。该漏洞由NSA报告给微软。



详情


     该漏洞被编码为CVE-2020-0601，影响所有Microsoft Windows版本加密功能。该漏洞将导致Windows证书验证的加密认证的证书信任体系失效，并且被利用执行远程代码。



影响范围


Windows 10

Windows Server 2016

Windows Server 2019



缓解措施


       及时升级补丁是目前唯一已知的缓解措施，湖南金盾建议尽快安装所有2020年1月的补丁程序：(http://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0601)，以有效缓解Windows 10和Windows Server 2016/2019系统上的漏洞。
