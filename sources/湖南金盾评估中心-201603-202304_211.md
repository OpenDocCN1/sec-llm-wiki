# 【威胁通告】Weblogic远程代码执行漏洞（ CVE-2020-2546、CVE-2020-2551）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662124020&idx=1&sn=81badbe2f54400d23f9b731742f85d50&chksm=f35afd24c42d74322f68034edd0a086e5b268441ebbf70ea4ab8b19760e76c101dec3981ce67&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662124020&idx=1&sn=81badbe2f54400d23f9b731742f85d50&chksm=f35afd24c42d74322f68034edd0a086e5b268441ebbf70ea4ab8b19760e76c101dec3981ce67&scene=27#wechat_redirect)

  

**概述**

  

      北京时间2020年1月15日，Oracle发布2020年1月关键补丁更新（Critical Patch Update，简称CPU），此次更新修复了333个危害程度不同的安全漏洞。其中196个漏洞可被远程未经身份认证的攻击者利用。

  

**详情**

  

     此次更新涉及Oracle Database Server、Oracle Weblogic Server、Oracle Java SE、Oracle MySQL等多个产品。Oracle强烈建议客户尽快应用关键补丁更新修复程序，对漏洞进行修复。此次发布的补丁，修复了Weblogic的两个高危漏洞（CVE-2020-2546、CVE-2020-2551）

**缓解措施**

  

       此次 Oracle 官方的 CPU，只发布了 12.2.1.4.0 版本的修复补丁，其他版本补丁将于 2020 年 1 月 31 日发布，请相关用户及时关注，在补丁发布后及时安装修复。
