**【JDICSP小分享第十六期】** 

  

      本次主要介绍怎么自签名nginx可使用的https证书，一般用来配置只能用IP访问的网站，若有域名可使用阿里云、腾讯云或acme.sh的免费https证书。

**自签名RSA证书**

      公司详细信息、电子邮件地址等可留空用默认，也可以按照真实信息来填，影响如下图，下同。

![](../Images/b9f1ae64988b10cdae76c0fca2969039.png)  

生成10年有效期2048位RSA公钥和私钥：

*   
*   

```
openssl genrsa -out rsa.key 2048openssl req -new -sha256 -x509 -key rsa.key -out rsa.cer -days 3650
```

![](../Images/2f9d0081516388442900967d4374c8e9.png)  

**自签名ECC证书**

生成10年有效期256位ECC公钥和密钥：

*   
*   

```
openssl ecparam -out ecc.key -name prime256v1 -genkeyopenssl req -new -sha256 -x509 -key ecc.key -out ecc.cer -days 3650
```

![](../Images/4a265149299a621e98e2c4667cd85733.png)

```
# 监听默认https端口listen 443 ssl http2;listen [::]:443 ssl http2;# 配置RSA、ECC双证书，若不需要可去除4行中的2行配置单证书# RSA证书ssl_certificate /etc/nginx/rsa.cer;ssl_certificate_key /etc/nginx/rsa.key;# ECC证书ssl_certificate /etc/nginx/ecc.cer;ssl_certificate_key /etc/nginx/ecc.key;# 配置支持的TLS协议和算法ssl_protocols TLSv1 TLSv1.1 TLSv1.2 TLSv1.3;  # TLSv1.3需要nginx版本 >= 1.13.0ssl_prefer_server_ciphers on;ssl_dhparam /etc/nginx/dhparam.pem;  # openssl dhparam -out /etc/nginx/dhparam.pem 4096ssl_ciphers EECDH+AESGCM:EDH+AESGCM:ECDHE-RSA-AES128-GCM-SHA256:AES256+EECDH:DHE-RSA-AES128-GCM-SHA256:AES256+EDH:ECDHE-RSA-AES256-GCM-SHA384:DHE-RSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-SHA384:ECDHE-RSA-AES128-SHA256:ECDHE-RSA-AES256-SHA:ECDHE-RSA-AES128-SHA:DHE-RSA-AES256-SHA256:DHE-RSA-AES128-SHA256:DHE-RSA-AES256-SHA:DHE-RSA-AES128-SHA:ECDHE-RSA-DES-CBC3-SHA:EDH-RSA-DES-CBC3-SHA:AES256-GCM-SHA384:AES128-GCM-SHA256:AES256-SHA256:AES128-SHA256:AES256-SHA:AES128-SHA:DES-CBC3-SHA:HIGH:!aNULL:!eNULL:!EXPORT:!DES:!MD5:!PSK:!RC4;ssl_ecdh_curve X25519:P-256:P-384:P-521;  # openssl和nginx版本过低可能会不支持X25519
ssl_session_timeout 10m;ssl_session_cache shared:SSL:10m;ssl_session_tickets off;  # nginx版本 >= 1.5.9
# 开启服务端 OCSP 查询ssl_stapling on;  # nginx版本 >= 1.3.7ssl_stapling_verify on;  # nginx版本 => 1.3.7resolver 114.114.114.114 119.29.29.29 valid=300s;resolver_timeout 5s;
# 添加https安全头# HSTS头add_header Strict-Transport-Security "max-age=63072000; includeSubdomains; preload";# 相同域名的 frame允许嵌套，也可以用Alllow-From uri设置白名单域名add_header X-Frame-Options SAMEORIGIN;# 防止MIME 类型混淆攻击add_header X-Content-Type-Options nosniff;# 阻止XSSadd_header X-Xss-Protection "1; mode=block";# 启用网页安全策略，自动将网页上所有加载外部资源的 http链接换成https协议，禁止 https加载http的资源add_header Content-Security-Policy "upgrade-insecure-requests block-all-mixed-content";
# 强制https访问，加在listen 80;的server块里if ($server_port = 80) {    return 301 https://$server_name$request_uri;}if ($scheme = http) {    return 301 https://$server_name$request_uri;}
```
