# 预警｜Windows再现“永恒之蓝”级漏洞 国内超150万主机受影响

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662123553&idx=1&sn=28f93d2b97ee92505f7b74111ea198fc&chksm=f35afcf1c42d75e7fa6ffa26937b9daf4d46bc9b7b8ad407c3b569d1d70e890366227abecba6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662123553&idx=1&sn=28f93d2b97ee92505f7b74111ea198fc&chksm=f35afcf1c42d75e7fa6ffa26937b9daf4d46bc9b7b8ad407c3b569d1d70e890366227abecba6&scene=27#wechat_redirect)

  

5月15日，微软发布安全补丁修复了CVE编号为CVE-2019-0708的Windows远程桌面服务（RDP）远程代码执行漏洞，该漏洞在不需身份认证的情况下即可远程触发，危害与影响面极大。

  

通过分析发现国内有超过150万台主机对外开放3389端口，可能受到漏洞影响。

  

**漏洞描述**

Windows 远程桌面服务（RDP）主要用于管理人员对 Windows 服务器进行远程管理，使用量极大。

  

近日，微软官方披露Windows中的远程桌面服务中存在远程代码执行漏洞，未经身份认证的攻击者可使用RDP协议连接到目标系统并发送精心构造的请求可触发该漏洞。

  

成功利用此漏洞的攻击者可在目标系统上执行任意代码，可安装应用程序，查看、更改或删除数据，创建完全访问权限的新账户等。

  

**风险等级**

安全监测与响应中心**风险评级**为：高危

**预警等级**：蓝色预警（一般事件）
