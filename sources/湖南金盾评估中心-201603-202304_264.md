# Internet Explorer XXE 漏洞预警

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662123504&idx=1&sn=bda616a20d25c8fcfd39cee8ad389dae&chksm=f35af320c42d7a360322fc7ff37e73da653d451c852a8dbed50d5e01f33b51f77c37e4f724ec&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662123504&idx=1&sn=bda616a20d25c8fcfd39cee8ad389dae&chksm=f35af320c42d7a360322fc7ff37e73da653d451c852a8dbed50d5e01f33b51f77c37e4f724ec&scene=27#wechat_redirect)

**0x00 漏洞背景**

      北京时间4月11日，国外安全研究员 John Page 公开披露 Internet Explorer 11 XXE漏洞，成功利用该漏洞将导致本地文件泄露。

      微软得知漏洞后，给出”暂时不予修复”的处理结果。鉴于漏洞真实存在，且具有一定危害。

**0x01 漏洞详情**

      漏洞源于Internet Explorer 对MHT文件处理不当，如果用户在本地打开特制的.MHT文件，则Internet Explorer易受XML外部实体攻击。

      在Windows上，MHT文件默认由Internet Explorer打开。漏洞触发需要CTRL + K（重复选项卡），“打印预览”或“打印”等用户操作，但是可以通过嵌入<script>window.print();</script>脚本自动触发，无需用户进行交互。

**0x02 漏洞影响**

       漏洞影响win7、win10、server 2012 R2 平台下最新版本的Internet Explorer Browser v11。

漏洞验证视频：https://youtu.be/fbLNbCjgJeY

**0x03 安全建议**

       微软得知漏洞后，给出“暂时不予处理”的决定。

       鉴于漏洞真实存在且具有一定危害，建议广大用户，不要轻易打开MHT文件。包括但不限于电子邮件，即时通讯软件或者其他渠道获得的MHT文件。
