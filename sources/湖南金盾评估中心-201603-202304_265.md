启用了disable\_functions和禁用assert的情况下，寻找 common.php 里面的公共函数搞事情

其中一个函数为cmf\_log:

/\*\*  
 \* 文件日志  
 \* @param        $content 要写入的内容  
 \* @param string $file    日志文件,在web 入口目录  
 \*/  
function cmf\_log($content, $file = "log.txt")  
{  
    file\_put\_contents($file, $content, FILE\_APPEND);  
}

明显的只要控制了 $context 参数就能写入任意内容
