【JDICSP小分享第八期】

简介

     AnyConnect 为思科推出的 VPN 客户端，当前已有 Windows、Android、iOS、OS X、Ubuntu、WebOS 等操作系统的客户端，使用它可以让用户通过互联网访问到企业的内网。

       OpenConnect 最初是作为思科专有的 AnyConnect SSL VPN 客户端的开源替代品，后来OpenConnect 项目还提供与 AnyConnect 兼容的服务端 ocserv，本文主要就是讲 ocserv 如何部署的。

      仅在 centos7 下测试通过，centos6会因为编译工具包和依赖库版本太老的原因而无法编译通过。

安装

步骤

01

安装编译工具包和依赖库

yum groupinstall 'Development Tools'  # 安装编译工具包
yum install gnutls-devel libev-devel tcp_wrappers-devel pam-devel lz4-devel libseccomp-devel readline-devel libnl3-devel krb5-devel radcli-devel protobuf-c-devel gperf nettle-devel gnutls-utils  # 安装依赖库

02

下载编译安装

wget "https://github.com/openconnect/ocserv/archive/ocserv_0_12_2.tar.gz"
tar xzf ocserv_0_12_2.tar.gz
cd ocserv-ocserv_0_12_2
autoreconf -fvi  # 生成 configure 文件

./configure  # 生成 Makefile 文件

make   # 编译，如果是多核cpu可以使用make -j线程+1来提高编译速度，比如4核8线程cpu可以用make -j9

make install  # 安装

03

配置文件处理

mkdir -p /etc/ocserv/cert

         复制默认配置文件

cp doc/sample.config /etc/ocserv/ocserv.conf
cp doc/systemd/standalone/ocserv.service /etc/systemd/system
sed-"s@/usr/sbin/ocserv@/usr/local/sbin/ocserv@" /etc/systemd/system/ocserv.service  # 这一步将默认systemd配置文件里的ocserv修改至正确路径

编辑/etc/ocserv/ocserv.conf配置文件，端口可以自定义

auth = "plain[passwd=/etc/ocserv/ocpasswd]"
tcp-port = 55443
udp-port = 55443
server-cert = /etc/ocserv/cert/server-cert.pem
server-key = /etc/ocserv/cert/server-key.pem
ca-cert = /etc/ocserv/cert/ca-cert.pem
dns = 114.114.114.114
把文件末尾的 [vhost:www.example.com] 之后的内容包括 [vhost:www.example.com] 全部删除

         可能还需要更改的

#tunnel-all-dns = true # 是否接管 DNS 解析请求到 VPN 服务器，true 代表客户端的 DNS 请求全部由服务器处理

max-clients = 16 # VPN 最大链接客户端数量，默认为 16。
max-same-clients = 2 # 同账号链接 VPN 最大客户端数量，默认为 2

# vpn 分配 ip 段，要确保 ip 段不存在冲突
ipv4-network = 192.168.1.0
ipv4-netmask = 255.255.255.0

# 路由表相关，用来分流流量
route = x.x.x.x/255.255.255.0
no-route = x.x.x.x/255.255.255.0

04

生成证书

      创建 CA 模版和服务端证书模版，192.168.155.132 需要替换为服务器的公网 ip

cd /etc/ocserv/cert
echo '''cn = "CA" 
organization = "CA" 
serial = 1 
expiration_days = 3650
ca 
signing_key 
cert_signing_key 
crl_signing_key
''' > ca.tmpl
echo '''cn = "192.168.155.132"
organization = "server"
expiration_days = 3650
signing_key
encryption_key
tls_www_server
''' > server.tmpl

         使用模版生成证书

certtool --generate-privkey --outfile ca-key.pem
certtool --generate-self-signed --load-privkey ca-key.pem --template ca.tmpl --outfile ca-cert.pem
certtool --generate-privkey --outfile server-key.pem
certtool --generate-certificate --load-privkey server-key.pem --load-ca-certificate ca-cert.pem --load-ca-privkey ca-key.pem --template server.tmpl --outfile server-cert.pem


05

防火墙配置

         激活 NAT

iptables -t nat -A POSTROUTING -j MASQUERADE

        打开 ipv4 防火墙转发

echo "net.ipv4.ip_forward=1" > /etc/sysctl.conf

sysctl -p

        centos7自带了iptables规则，若端口无法连接打开防火墙55443端口

iptables -A IN_public_allow -p tcp -m tcp --dport 55443 -m conntrack --ctstate NEW -j ACCEPT

iptables -A IN_public_allow -p udp -m udp --dport 55443 -m conntrack --ctstate NEW -j ACCEPT

06

添加 vpn 用户

ocpasswd -c /etc/ocserv/ocpasswd username

07

启动 ocserv并加入开机自启

systemctl start ocserv.service
systemctl enable ocserv.service

        使用 systemctl status ocserv.service查看服务是否运行，如下图出现 active (running) 则已运行

      安装客户端后点击界面上的齿轮按钮，由于使用的是自签名证书，所以要把“阻止连接到不信任的服务器”取消勾选才能连接
