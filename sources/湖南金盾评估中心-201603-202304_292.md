# 【安全预警】Apache Struts 2 RCE漏洞（CVE-2018-11776/S2-057）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662123140&idx=1&sn=fc51ddbd067473e07212fb686be47651&chksm=f35af254c42d7b42ee2f4b8a8a0a4788ddc13a1d04ab370e98441343518082277077855a7b9e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662123140&idx=1&sn=fc51ddbd067473e07212fb686be47651&chksm=f35af254c42d7b42ee2f4b8a8a0a4788ddc13a1d04ab370e98441343518082277077855a7b9e&scene=27#wechat_redirect)

**一、漏洞概述**

定义XML配置时如果namespace值未设置且上层动作配置（Action Configuration）中未设置或用通配符namespace时可能会导致远程代码执行。url标签未设置value和action值且上层动作未设置或用通配符namespace时可能会导致远程代码执行。

**二、影响版本**

Struts 2.3 – Struts 2.3.34

Struts 2.5 – Struts 2.5.16

其余版本也可能会受到影响

**三、官方解决方案** 

升级至版本2.3.35或2.5.17。这两个版本仅仅只是更新了安全补丁，不存在兼容性问题。

**四、临时解决方案**

推荐用户及时更新，但如果不想更新，可暂时使用官方提供的临时解决方案：当上层动作配置中未设置或使用通配符namespace时，验证所有XML配置中的namespace，同时在JSP中验证所有url标签的value和action。
