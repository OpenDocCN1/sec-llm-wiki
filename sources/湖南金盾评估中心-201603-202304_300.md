# 湖南金盾受邀出席DCCB安全国际峰会， 打造国际网络安全交流平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662123091&idx=1&sn=8238333779979bd1cb031a595fdef9c3&chksm=f35af283c42d7b95990e5489a36b413594e6ab817f687158ef7449562197244e322ec654fcec&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662123091&idx=1&sn=8238333779979bd1cb031a595fdef9c3&chksm=f35af283c42d7b95990e5489a36b413594e6ab817f687158ef7449562197244e322ec654fcec&scene=27#wechat_redirect)

全球网络安全盛会DEF CON 将于今年5月正式登陆中国，DEF CON与百度安全将联合主办“御 ·见未来”2018首届DCCB(DEF CON China Baidu)安全行业国际峰会。湖南金盾受邀出席本次峰会，与全球网络安全人才共话安全。

![](../Images/61f8550bce998b2c56532d2424a345f4.png)

DEF CON是全球安全领域的顶级会议，从发起至今已有25年历史，被誉为安全界的“奥斯卡”，由全球最具影响力也是形象最正面的黑客Jeff Moss于1993年创办。整个大会共包含议题演讲，CTF比赛和Hacking Villages三大板块，每年7月在美国拉斯维加斯举行，汇集全球网络安全研究者进行前沿安全技术交流与课题研究。百度安全推动DEF CON落地中国，旨在通过探讨网络信息安全攻防，发现安全人才，为国家人工智能战略做好坚实的安全基础，为建设网络强国做好技术储备和智力支持。

首届DCCB安全行业国际峰会的召开，将吸引更多来自包括中国在内的亚太地区的网络安全研究者参与其中，集结国际顶尖安全人才同台切磋，分享技术，也给无数东半球怀揣极客梦想的网络安全研究者提供更高层次的展示和发展空间。向全世界展示中国安全领域技术实力，推动整个安全产业的变革。

**湖南金盾是一家专注于网络和信息安全服务的高新技术企业，国内技术领先的安全服务提供商，湖南省内第一家具备资质和能力的等级测评机构。公司致力于帮助重要信息系统提升安全防护能力，为用户提供优质的信息安全服务。**

**此次，湖南金盾受邀参加首届DCCB安全行业国际峰会，湖南金盾期待通过此次峰会对接全世界安全领域内有技术实力、先进思维的安全企业、安全专家以及优质白帽子，不断创新提升自身的核心竞争力，有效推动网络强国战略思想的深入贯彻，为我国网络安全事业的建设发展做出积极贡献。**

同时我们欢迎更多有志之士参与到此次峰会中来，共同预祝2018首届DCCB(DEF CON China Baidu)安全行业国际峰会圆满成功，同时也期待最先进的世界文明成果与最悠久的中华文化在中国这片古老的土地上相遇碰撞出精彩的火花！
