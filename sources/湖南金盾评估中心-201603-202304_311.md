# 2017年“湖湘杯”—湖南雨人、湖南金盾载誉归来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyNTI0ODcwMw==&mid=2662122994&idx=1&sn=a5e54ea8a0a423b640288c3e88ec5c81&chksm=f35af122c42d7834fdc74e4d00a62e26cfecb3138632382119b2634e158c64f215c2bba5c321&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyNTI0ODcwMw==&mid=2662122994&idx=1&sn=a5e54ea8a0a423b640288c3e88ec5c81&chksm=f35af122c42d7834fdc74e4d00a62e26cfecb3138632382119b2634e158c64f215c2bba5c321&scene=27#wechat_redirect)

        2017年9月22日，“湖湘杯—2017年网络安全技能大赛”线上报名通道正式开启。本次大赛是中共湖南省委网络安全和信息化领导小组办公室在中央和国家有关部门的指导下，联合湖南省直相关部门共同举办 。自9月22日线上报名通道开启以来，大赛收到了来自全国29个省1422个队的线上报名，经过初赛、复赛两轮激烈的比赛，最终30个队来到长沙超算中心参与决赛。

       12月7日，进入决赛的30个队在封闭式局域网环境下进行了一整天的比赛。
