# 湖南经视就WannaCry勒索病毒事件来访湖南金盾

    2017年5 月12 日（上周五晚），全球爆发大规模蠕虫勒索软件感染事件，全球超过150个国家，至少20万名用户中招。英国、美国、俄罗斯、德国、土耳其、意大利、中国、菲律宾等国家都受到影响，且攻击仍在蔓延。据报道，勒索攻击导致16家英国医院业务瘫痪，西班牙某电信公司有85%的电脑感染该恶意程序。至少1600家美国组织，11200家俄罗斯组织和6500家中国组织和企业都受到了攻击。国内也有大量教学系统瘫痪，很多毕业生论文被锁。

一、事件概述

    WannaCry勒索病毒主要利用微软Windows操作系统的MS17-010漏洞进行自动传播，3月14 微软已经发布补丁，由于很多受害者没有及时安装补丁，导致被病毒攻击，计算机中的文件被加密。该恶意软件会扫描电脑上的TCP 445端口（Server Message Block/SMB），以类似于蠕虫病毒的方式传播，攻击主机并加密主机上存储的文件，然后要求以比特币的形式支付赎金。

3月1日

![](../Images/9a200e8ef045f6df730ac0fad6abcb83.png)

湖南经视的两位记者就这次事件来到湖南金盾，采访了两位安全专家详细了解了WannaCry勒索病毒以及防范措施，并于15日的经视焦点播出。

二、防范措施

1、立即断网，拔掉网线，防止扩散和蔓延。

2、及时备份数据资料

3、网络管理员在网络防火墙上配置相关策略，限制外部对445端口的访问。

4、打好补丁

湖南金盾简介

湖南金盾，全称湖南省金盾信息安全等级保护评估中心有限公司经湖南省公安厅批准成立（湘公\[2009\]48号），湖南省信息安全等级保护工作协调小组办公室推荐，公安部信息安全等级保护评估中心审批，成为湖南省内首家通过等级测评机构能力评估的第三方测评机构。

    公司的业务由成立初期单纯的等保测评服务，形成目前整个信息安全服务的立体服务模式：信息安全等级保护测评、安全运维、安全应急服务、安全加固、网络安全风险评估、网络安全运维监控、安全咨询、安全培训等，为政府、金融、证券、运营商、医疗、教育等近60家重点单位和机构的300多个信息系统提供网络安全测评、运维、应急、培训、监理及咨询等多种服务，服务质量得到了各级主管机构和广大客户的高度认可。

    公司拥有一流的信息安全专家和专业的安全服务队伍，所有测评人员均通过公安部信息安全等级保护测评师认证，并获得相关资格证书，其中包括高级测评师、中级测评师及初级测评师。
