# 如何制作一个即插即用的Python环境？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2MzE3NzczNQ==&mid=2650620954&idx=1&sn=77d8c80a251c78c64809145dbbbfcc48&chksm=f2b63772c5c1be64cd0304ae4ece01888ccc47f8c46e27c8ad9dac3b83e20b253be9388e37b3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI2MzE3NzczNQ==&mid=2650620954&idx=1&sn=77d8c80a251c78c64809145dbbbfcc48&chksm=f2b63772c5c1be64cd0304ae4ece01888ccc47f8c46e27c8ad9dac3b83e20b253be9388e37b3&scene=27#wechat_redirect)

当你在某个没有Python环境的机器上需要使用Python环境、你可能需要在电脑上运行Python脚本，但是电脑是不能装东西，那怎么办呢？

我的方案是：先绿化Python安装包，然后量产U盘（2个区：CD-ROOM和U盘），再然后把绿色版Python装入U盘的CD-ROOM中，最后通过autotun.inf把U盘中的Python加入到环境变量中。

![](../Images/f4b29312d161ade1bd155073766991d7.png)  
图1 绿色版Python

这样就不需要手动把U盘中的Python加入到环境变量中，既方便又装逼。

实验环境：

*   系统：
    

*   Windows XP Professional SP3 X86
    

*   Python版本：
    

*   Windows xp及以下系统支持：Python 2.6.6
    
*   Windows 7及以上系统支持：Python 2.7.12
    
*   下载地址：https://pan.baidu.com/s/1EgfZuS5\_dOSkfxIhnRVOyw
    

*   U盘：
    

*   Kingston DT SE9H 16GB  
    ![](../Images/7b4d1413cd72b2c4de26ce351681ad3d.png)
    

*   工具：
    

*   检测：ChipGenius芯片精灵V4.18.0203绿色版
    
*   量产：群联UPTool v2.093版(2015.03.12)
    

在量产之前，拔下电脑上所有的USB设备，只保留Kingston DT SE9H。

## 0x01 准备

先下载U盘检测工具ChipGenius，下载地址：http://www.upantool.com/test/xinpian/2011/ChipGenius\_V4.html。

下载完成后，用ChipGenius检测U盘的芯片型号等信息，检测结果如下图：

![](../Images/7515e7b8332f7cee4ae3dcc55cac59a5.png)  
图3 U盘的详细信息

只要看图3中的主控厂商、主控型号两个信息，如下：

*   主控厂商: Phison(群联)
    
*   主控型号: PS2251-68(PS2268) - F/W 02.02.55 \[2015-06-12\]
    

最后，就是下载量产工具。

在http://www.upantool.com/中输入关键字`PS2251-68`搜索，我选择的量产工具是*群联UPTool v2.093版(2015.03.12)*，下载地址：http://www.upantool.com/liangchan/Phison/2016/8872.html。

下载、解压完成后，运行UPTool\_Ver2093.exe，如果出现图4，则说明量产工具选对了。

![](../Images/e693193af44b07cfe75bad8d92ae3348.png)  
图4 UPTool\_Ver2093.exe界面

准备工作完成后，接下来就是量产啦~~~

## 0x02 制作

先对U盘进行量产设置（也叫生产设定），点击生产设定按钮，提示输入密码，默认密码为空。

![](../Images/f7594a16dd32575c9d6aec671e9b393c.png)  
图5 量产设置

量产模式有好几个，我们做的是CD-ROOM+U盘（也就是模式21），则需要启用光碟模拟（也就是设置两个区）（如图6所示）：

*   分区1：分区模式选择光驱（只读模式），再选择Python2-Portable.iso写入。
    
*   分区2：啥也不用管。
    

![](../Images/b729a7319ec471c8a53c54dac23fa2b9.png)  
图6 设置量产模式和分区

这样量产分区就OK了，点击确定即可保存且返回主界面，点击开始即可开始量产，如图7所示：

![](../Images/d173a1ab9b6688203769edfd6aab46f2.png)  
图7 开始量产

开始漫长的等待时间了，也许一根烟、也许两杯茶、也许睡一觉。。。。。

![](../Images/d54f3275c0f634ceb778020ed8d26242.png)  
图8 量产完成

经过快2小时后，出现如图8所示，则说明量产完成~

在这里提醒你，一定要关闭UPTool\_Ver2093.exe，再插拔U盘。

## 0x03 测试

拿个新电脑来测试一下自己成果啦~

插入U盘后，CD-ROOM+可移动磁盘就呈现在你的眼前了，如图9所示：

![](../Images/810e28f11a0fff76138093895f3b5715.png)  
图9 CD-ROOM+可移动磁盘

然后就会自动运行脚本`Python2.bat`，它主要的作用是把`E`盘中的`Python27 (Python26)`文件夹复制到`F`盘，然后把其加入环境变量`PATH`。

运行`python -V`检查是否成功，如图10所示则说明成功：

![](../Images/ea594b35560e85448d2a2f6509b478f4.png)  
图10 检查是否成功

这样，就可以使用U盘中的Python环境啦~~~~
