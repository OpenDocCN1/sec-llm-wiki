Scrapy是一套基于基于`Twisted`的异步处理框架，纯python实现的爬虫框架，只需要定制开发几个模块就可以轻松的实现一个爬虫。Scrapy官网和官方安装文档。

### 安装

直接使用pip安装：

```bash
pip install Scrapy
```

*注意：*

> Scrapy依赖这些python包：
> 
> *   lxml
>     
> *   parsel
>     
> *   w3lib
>     
> *   twisted
>     
> *   cryptography and pyOpenSSL
>     
> 
> 对于Scrapy最小的包版本：
> 
> *   Twisted 14.0
>     
> *   lxml 3.4
>     
> *   pyOpenSSL 0.14
>     

### 创建一个`Scrapy`新项目

使用命令创建一个Scrapy新项目：

```bash
$ scrapy startproject 项目名称
```

例如：创建一个名叫`helloscrapy`的项目：

```bash

$ scrapy startproject helloscrapy
```
