**0x00 ********OPC Server 配置******

![](../Images/4aebcc140e8243a69ef7d30a9ac838ed.png)

我们以Kepware4.0为例讲述OPC Server与OPC Client是如何配置的。

首先我们打开Kepware Server的界面，如下图所示：

![](../Images/099e576f110a6707c28ff077b28d656b.png)

图36 Kepware Server界面

这个界面很像SCADA软件的设备创建界面，Kepware也是通过创建通道，设备之后是设备中的点来完成整个OPC Server的配置。首先我们看下通道的创建。

  

01

*Channel*  

**创建通道**

在设备窗口，我们在树形结构空白处，点击鼠标右键，弹出菜单，我们选择创建通道，如下图所示：

![](../Images/5ce88a11ad2172867e0843985896b85b.png)图37 Channel菜单界面

弹出创建通道对话框，

![](../Images/e4dfe38a730ba0647c384fbb074d51e4.png)图38 Channel名字配置界面

输入一个通道名称，这里我们选择默认，直接点击“下一步”：

![](../Images/68389a636ad975841b5b784a958d21fe.png)图39 Channel驱动配置界面

这里会提示我们，选择创建的设备驱动，我们先看看Kepware支持多少种设备的驱动。

![](../Images/29a1ae2ddb8a7a3b68511302450ebdd0.png)图40 Channel驱动选择界面

下拉菜单中，有很多啊！这里我们仅仅介绍Simulator的（其他的是收费的，如果有兴趣的同学可以自行研究）驱动，选择完驱动，点击“下一步”：

![](../Images/dffe5bf42b2e6b07fe4df50c8d03e064.png)图41 Channel驱动参数配置界面

这类配置一些参数，如操作模式、写操作时间间隔等。点击“下一步”：

![](../Images/a2bc08e49f61cc43f95539714effa11e.png)图42 Channel驱动寄存器参数配置界面

这里是一些特殊寄存器用的配置，我们暂时用不到，点击“下一步”：

![](../Images/2277bd9938512b30468122dcf055feb8.png)图43 Channel驱动参数配置确认界面

完成通道的创建。

  

02

*device*

**创建设备**

创建完通道后，会出现新的界面样式，如下图所示，我们继续创建设备：

![](../Images/c81bebbcefdf889e8616ae251a5ff205.png)图43 Channel创建完成界面

根据提示，我们点击“Click to add a device”来进行创建设备：

![](../Images/9c0efde28d768d5194e971f9d364f37b.png)图44 Device名字创建界面

可以填入自己喜欢的设备名称，我们这里选择默认，点击“下一步”：

![](../Images/646345669d0670d351f711b9b0ea24a5.png)图45 Device模式选择界面

这里是设备模式，模拟驱动这里是简单的数据类型，是16位的数据，还是8位的数据；我们依旧默认选择，选择16位数据设备，点击“下一步”：

![](../Images/232aa6b74a345a5e6d326c1338b3eec3.png)图46 Device参数配置界面

这里是选择设备ID和数据类型的，数据类型有十进制与十六进制区别，我们依旧选择默认选型“十进制”，点击“下一步”：

配置完成后，就接下来配置我们的测点了（Item）。

  

03

*Item*

**创建测点**

在整个窗口的右侧，点击鼠标右键，创建测点（Item），如下图所示：

![](../Images/a6bb226e1acab560593b5a6b17fe8bf5.png)图49 Item菜单界面

创建测点：

![](../Images/54b02fad2bb2f0375762ceddf5284110.png)图50 Item创建属性界面

1、Name：测点的名字，我们随意创建即可（不支持中文，建议使用英文或者拼音加数字的形式）；

2、Address：测点的地址，这里支持如下的形式：

![](../Images/58ff5afcbea2cdecd7eea9a0e227498f.png)图51 Simulation 地址参数界面

其中还可以支持以及函数的方式：

*      RAMP(Rate, Low Limit, High Limit, Increment) 
    

递增/递减函数，

第一个是参数是速率，多久变化一次；单位是ms

第二个参数是底限，递增或者递减的最小值；

第三个参数是高限，递增或者递减的最大值；

第四个参数是变化量，为正值是递增函数，为负值为递减函数。

*      RANDOM(Rate, Low Limit, High Limit)
    

随机函数，

第一个是参数是速率，多久变化一次；单位是ms

第二个参数是底限，递增或者递减的最小值；

第三个参数是高限，递增或者递减的最大值。

*      SINE(Rate, Low Limit, High Limit, Frequency, Phase)
    

正弦函数，

第一个是参数是速率，多久变化一次；单位是ms

第二个参数是底限，递增或者递减的最小值；

第三个参数是高限，递增或者递减的最大值；

第四个参数是频率，频率参数的有效范围是0.001到5赫兹；

第五个参数是相位，可用于抵消特定角度产生的正弦波。

*      USER(Rate, User Value1, User Value2, User Value3,...User ValueN)
    

这个属于用户自定义函数，是按照用户定义的数值依次变化。

这里我们创建一个随机函数，RANDOM (30, -20, 75)；

3、Description 对点的描述，我们这里是模拟的所以不填也是可以的。

数据属性。

4、Data type 数据类型，我们可以根据表中的数据类型进行选择；

5、client 读写属性，有只读和读写两种，Random函数为只读的，所以我们这里只能选择 Read Only。

6、Scan rete 变化速率，这里我们选择默认。

点击“应用”可以继续创建测点，我们点击“确定”完成测点的配置。

![](../Images/d732d5f342c9ec7907c97e1b6610a90a.png)图52 Item创建完成界面

![](../Images/c882958291fa88bd5949b3abbda62701.png)图53 OPC Client配置界面

01

*Group*

创建组

在刚刚创建的连接处，点击鼠标右键，选择创建组，如下图所示：

![](../Images/7e6728b56888dcf40f73f1b6bb97db63.png)图57 OPC Client组创建菜单界面

选择“New Group”，如下图所示：

![](../Images/002d3b406542d39ed157abdb2baaf5ef.png)图58 OPC Client组属性创建界面

我们在这里键入组名字，其他参数如下：

Update Rate：更新速率，在这个组下的测点更新的速率；

Time Bias：时间偏差，这里不做修改

Percent Deadband：数据死区，这里不做修改

Language ID：语言ID；

Update Notification：选择OPC版本，我们默认即可。

         填写完成之后，点击“确定”。完成组的创建；

![](../Images/70c141a0061eb631c8eacb1200778444.png)

图59 OPC Client组创建完成界面

  

02

*Item*

创建测点

在刚刚创建的组下面，点击鼠标右键，创建测点，如下图所示：

![](../Images/6fe03277bc94322598ec030e1050ef2f.png)图60 OPC Client测点菜单界面

选择“New Item”，如下图所示：

![](../Images/715305fe86f82ca4317d81f0cd1fa1bc.png)图61 OPC Client测点选择界面1

在右下侧，连接的OPC Server中选择我们刚刚创建的通道、设备，如下图所示：

![](../Images/be4a7f447d4b2407ad6d5828a5aa8b1c.png)图62 OPC Client测点选择界面2

然后选择，我们刚刚在OPC Server端创建的测点，选择“Add Leaves”，然后点击“OK”。如下图所示：
