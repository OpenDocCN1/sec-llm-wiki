0x00 Clonezilla概述

Clonezilla是一个用于Linux，Free-Net-OpenBSD，Mac OS X，Windows以及Minix的分区和磁盘克隆程序。它支持所有主要的文件系统，包括EXT，NTFS，FAT，XFS，JFS和Btrfs，LVM2，以及VMWare的企业集群文件系统VMFS3和VMFS5。Clonezilla支持32位和64位系统，同时支持旧版BIOS和UEFI BIOS，并且同时支持MBR和GPT分区表。它是一个用于完整备份Windows系统和所有安装于上的应用软件的好工具，而我喜欢用它来为Linux测试系统做备份，以便我可以在其上做疯狂的实验搞坏后，可以快速恢复它们。

Clonezilla也可以使用dd命令来备份不支持的文件系统，该命令可以复制块而非文件，因而不必在意文件系统。简单点说，就是Clonezilla可以复制任何东西。（关于块的快速说明：磁盘扇区是磁盘上最小的可编址存储单元，而块是由单个或者多个扇区组成的逻辑数据结构。）

Clonezilla分为两个版本：Clonezilla Live和Clonezilla Server Edition（SE）。Clonezilla Live对于将单个计算机克隆到本地存储设备或者网络共享来说是一流的。而Clonezilla SE则适合更大的部署，用于一次性快速多点克隆整个网络中的PC。Clonezilla SE是一个神奇的软件，我们将在今后讨论。今天，我们将创建一个Clonezilla Live USB存储棒，克隆某个系统，然后恢复它。

0x02 启动U盘制作

准备材料：

（1）U盘

（2）刚刚下载的Clonezilla的iso文件

（3）老毛桃U盘启动制作软件（我这里使用的老毛桃，因为直接使用UltraISO软件无法启动Clonezilla）

（4）UltraISO软件（虽然它制作的启动盘无法启动Clonezilla，但需要用它来读取下内容）

我们先使用老毛桃给U盘做一个PE，制作好了运行如下图所示

接着我们在U盘的根目录下创建了一个MYEXT文件，将Clonezilla的iso文件复制到里面，我这里用的是clonezilla-live-2.6.4-10-amd64.iso版本。

之后我们使用UltraISO软件将clonezilla-live-2.6.4-10-amd64.iso里面的内容拷贝到U盘的根目录下（网络上的教程是说可以仅仅拷贝live和syslinux就可以，但我全部拷贝了）。

这样我们的启动盘就做好了，下一步就是进行数据盘对拷。

0x03 数据对拷


1、系统采用U盘启动（每个系统的启动项选择都不一样，这里就不介绍了）；

2、加载Clonezilla，如下图所示：

3、选择语言“简体中文”

4、键盘布局，默认不更改

5、选择“使用再生龙”

6、选择第二种模式，“硬盘对拷或者分区对拷”，在这里目的是硬盘对拷

7、选择“初学模式”（也可以在专家模式，自定义一些参数）

8、选择第一项“复制本机硬盘到本机硬盘”

9、选择源磁盘sda（这里就是HdiskA，安装有Windows 2008的系统盘）

10、选择目标磁盘（HdiskB）

11、这一步，选择跳过检查，这样速度会比较快一些

12、选择ok确认后，会再一次提醒按Enter（回车键）确认操作

当Enter确认后，数据对拷程序开始时，会接着再一次警告提醒，输入y接受

输入y。

13、可以看到数据对拷进度、数据拷贝的速度

14、数据对拷成功后，退出此程序，关机。
