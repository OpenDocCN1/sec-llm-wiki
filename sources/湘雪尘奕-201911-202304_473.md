本文档将指导您完成安装Python和Django在Windows操作系统。它还提供了安装virtualenv和virtualenvwrapper指令，使它更容易在Python项目。本文档作为用户在使用Django项目初学者的指南。

本指南中的步骤已经用Windows 7, 8和10进行了测试。在其他版本中，步骤将类似。您需要熟悉使用Windows命令提示符。

![](../Images/96b505dbda36f5f0c55ea0b8be7edade.png)

**0x00 安装Python**

![](../Images/4aebcc140e8243a69ef7d30a9ac838ed.png)

Django是一个Python Web框架，因此需要Python将安装在您的机器。在编写时，Python 3.5是最新版本。

https://python.org/downloads/ 该网站提供最新的Python版本的下载。下载可执行安装程序并运行它。

添加环境变量，计算机->”属性”->“高级系统设置”->“环境变量”->“PATH”里面添加刚刚安装的Python路径。

安装完后，打开命令提示符，并检查Python版本是否与执行安装的版本一致：

```
python –version
```

![](../Images/76cc38ed04dc6a19d232d4f1ea221ee8.png)

0x01 安装PIP

![](../Images/9d2ea7851950bd59e0e2aca67fd3503d.png)

  

PIP是Python的包管理。它使安装和卸载Python软件包（如Django！）很容易。对于安装的其余部分，我们将使用PIP从命令行安装Python包。

在您的机器上安装点，去https://pip.pypa.io/en/latest/installing/，并按照安装说明get-pip.py。

01

*install*

安装

PIP已经安装，如果你使用的是Python 2 > = 2.7.9或Python 3＞＝3.4下载使用或如果你是在一个虚拟环境的创建工作pyvenv virtualenv或。只需升级PIP即可。

安装pip，安装下载https://pypi.python.org/pypi/pip#downloads

下载完成后，解压缩并执行下面命令安装

python setup.py install

执行完毕，添加环境变量如安装python时候类似。之后在命令行窗口执行如下命令：

```
pip list
```

![](../Images/76cc38ed04dc6a19d232d4f1ea221ee8.png)

0x02 安装virtualenv

![](../Images/9d2ea7851950bd59e0e2aca67fd3503d.png)

virtualenv和virtualenvwrapper每个Django项目创建提供一个专门的环境。虽然不是强制性的，但这被认为是一种最佳实践，并且在准备部署项目时将节省您的时间。简单型：

```
pip install virtualenvwrapper-win
```

然后为您的项目创建一个虚拟环境：

```
mkvirtualenv myproject
```

虚拟环境将自动激活，你会看到“（如何）”旁边的命令提示指定。如果您启动一个新的命令提示符，您将需要再次激活环境：

```
wokon myproject
```

![](../Images/76cc38ed04dc6a19d232d4f1ea221ee8.png)

0x03 安装Django

![](../Images/9d2ea7851950bd59e0e2aca67fd3503d.png)

  

Django可以很容易地使用PIP在你的虚拟环境的安装。

在命令提示符中，确保虚拟环境处于活动状态，并执行以下命令：

```
pip install django
```

这将下载并安装最新的Django发布。

在安装完成之后，你可以通过执行Django管理--与命令提示符验证Django。

看得到你的数据库运行在Django数据库安装信息。

![](../Images/76cc38ed04dc6a19d232d4f1ea221ee8.png)

0x04 创建Django项目  

![](../Images/9d2ea7851950bd59e0e2aca67fd3503d.png)

执行如下命令，创建Django项目

```
django-admin startproject helloword
```

![](../Images/76cc38ed04dc6a19d232d4f1ea221ee8.png)

0x05 启动Django项目

![](../Images/9d2ea7851950bd59e0e2aca67fd3503d.png)

执行如下命令，启动Django项目

```
python manage.py runserver 0.0.0.0:8000
```
