**0x00开启Web功能**

![](../Images/4aebcc140e8243a69ef7d30a9ac838ed.png)

01

开启 Web Server

Web 功能在配置界面的硬件组态配置中，如下图所示：

![](../Images/0a7e757d04e378731297e0eaf3a87467.png)

  

选择1200工程中的设备和网络；

选中 CPU 部分; 

之后界面中的下部就会出现CPU信息，选择属性一栏；

  

02

*配置 Web Server*

  

在CPU 属性中的“Web 服务器”，如下图所示：

![](../Images/c8982f94d447348d1c363e89fab031e7.png)

将“启用模块上的Web服务器”前面的方块选中；

之后将自定义的Web界面文件加载到工程当中；

如下图所示：

![](../Images/f8ee208a5066d84937777994513c1b72.png)

HTML目录：将Web文件所在的目录选中，可使用后面的按钮选择；   

默认HTML页面：选择Web的默认页面文件，可使用后面的按钮选择；

03

*编译工程*

编译，如下图所示：

![](../Images/56ee5d4fcae23f945dc12d0bd589e8da.png)

 在左侧的项目树中，选择相应的PLC，右键弹处菜单；

选择“编译”->“软件（重建所有块）”；

进行全部软件编译；

  

下载，如下图所示：

![](../Images/1133630bdbd7dcbc19c360464b02afae.png)

在左侧的项目树中，选择相应的PLC，右键弹处菜单；

选择“下载到设备”->“软件（所有块）”；

进行软件的下载；

如果无法登陆到Web 服务器界面，重新下载，选择下载全部；

![](../Images/96b505dbda36f5f0c55ea0b8be7edade.png)

**0x01 登录Web界面**

![](../Images/4aebcc140e8243a69ef7d30a9ac838ed.png)

  

使用IE浏览器（IE版本在8 以上）直接访问PLC的IP地址即可访问。

![](../Images/96b505dbda36f5f0c55ea0b8be7edade.png)

**0x02 附件**

![](../Images/4aebcc140e8243a69ef7d30a9ac838ed.png)

Web 服务器文件为Webpage\_V1011 文件夹中的内容。

  

![](../Images/96b505dbda36f5f0c55ea0b8be7edade.png)
