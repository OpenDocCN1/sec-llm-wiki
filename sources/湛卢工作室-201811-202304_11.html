    在《劳动节 | 说说代理池》一文中我们介绍了代理池攻防的一些手法，随着攻防对抗的发展，利用云厂商提供的云函数（Serverless Cloud Function，SCF）来搭建代理池的方法越来越常见，也在攻防演习中被攻击方所利用，本文将对云函数（SCF）的原理、构建代理池的方法进行介绍。

0x01 什么是云函数（SCF）

    云函数（Serverless Cloud Function，SCF）是云计算厂商为企业和开发者们提供的无服务器执行环境，可在无需购买和管理服务器的情况下运行代码， 是实时文件处理和数据处理等场景下理想的计算平台。只需使用 SCF 平台支持的语言编写核心代码并设置代码运行的条件，即可在某云基础设施上弹性、安全地运行代码。

    无服务器（Serverless）不是表示没有服务器，而表示在使用 Serverless 时，我们无需关心底层资源，也无需登录服务器和优化服务器，只需关注最核心的代码片段，即可跳过复杂的、繁琐的基本工作。使用云函数（SCF）时，我们只需使用平台支持的语言（Python、Node.js、PHP、Golang、Java 及 Custom Runtime）编写代码，云计算厂商将完全管理底层计算资源，包括服务器 CPU、内存、网络和其他配置/资源维护、代码部署、弹性伸缩、负载均衡、安全升级、资源运行情况监控等。

0x02 云函数代理池构建原理

   云函数（SCF）可通过 API 网关触发器进行触发，接受来自客户端的数据，并将请求转发出去。因此一个 HTTP Proxy 的实现思路如下图所示：



    我们在本地搭建代理客户端，代理客户端拦截数据包，提取 HTTP 报文相关信息，然后将报文发送到API网关，API网关触发部署在云上的云函数（SCF），云函数（SCF）负责解析结构化的数据，组装 HTTP 请求，并发送数据包。数据包发送后，云函数（SCF）再把响应包组装好返回给 API 网关，API网关再将结果返回给用户。


    由于云函数（SCF）会自动地在同一地域内的多个可用区部署，所以云函数（SCF）请求目标网站时，会自动调用不同可用区域的IP地址，利用这一特性，我们变相的达到构建IP代理池的目的。


    此外，由于云函数（SCF）Serverless的特性，我们不需要购买VPS服务器，云函数每月都有免费使用额度，也降低了攻击隐匿成本。需要注意的是，云函数无法长驻，调用的时候创建，执行完之后立即就销毁，所以无法直接保存状态，也正是这一点，让我们无法代理像 SSH 这种需要长连接的服务，只能代理 HTTP(s) 这种无状态的协议。

0x03 云函数代理池实现

    实验环境：

    本地环境：kali、python3>=3.6

    代理客户端：mitmproxy

    云函数（SCF）：某云厂商


    云函数（SCF）配置：

    1、开通云函数服务，在“函数服务“ > 新建 中使用自定义创建，函数名称及地域任选，运行环境选择 Python3.6。

    


    2、在函数中填入实现转发功能的server.py代码。



    触发器配置：

    1、成功创建函数后进入“触发管理“，创建触发器，触发方式选择“API 网关触发“，其他使用默认值。



    2、记录触发器中的访问路径，在代理客户端配置文件中需要使用。



    本地客户端配置：

    本实验使用 mitmproxy 提供本地代理，开启代理开始运行：

mitmdump -s client.py -p 8081 --no-http2


    mitmproxy 代理开启后，可以看到请求已发送至云函数（SCF）处理，在“函数服务”的“日志查询”中可以看到调用记录：

    


    根据日志记录，可以看到请求的IP为云厂商的IP，成功实现代理转发，每一次的请求都会自动切换不同IP：


    简单总结一下，采用云函数（SCF）的方式构建代理池，云函数会自动切换出口IP，对使用者完全透明，十分方便；代理池的IP的个数是海量的，而且很多IP在威胁情报中都是干净的白IP，给防守方的攻击溯源带来更大的难度；不需要购买VPS，云函数的使用量每个月都有免费额度，降低了攻击隐匿的成本；云函数（SCF）代理池仅支持 HTTP 和 HTTPS这种无状态的协议，速度有的时候会比较慢。
