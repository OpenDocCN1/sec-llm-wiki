# 走！去沙漠种下黑客情怀

有人说，有生之年，一定要去一趟大西北。

“塞上江南”宁夏则有着大西北独一无二的风景。

“大漠孤烟直，长河落日圆。”这里是热血男儿向往的胜地，站在沙坡头上，眼前是一望无际、烟波浩渺的大沙漠，英雄气概从脚下油然而生。

![](../Images/0bb271041498d9d1eb5781d9f0f7f4f6.png)

荒漠虽美，沙漠化问题却对黄河走廊的基础设施及农田造成了严重威胁。

![](../Images/211ccac79abf18bfdc594cba612c254e.png "春天 绿叶分割线")

ONE BUG ONE TREE的诞生，正是“互联网安全防护林”12家SRC联盟寄望用实际行动，让网络安全生态与现实环保生态同行。网络安全志愿者们每找到一个漏洞，SRC联盟即以提交者的名义捐赠一棵树，这也大大的激发了网络安全志愿者的公益热情。

![](../Images/499d8a551a93fc0f846c18c01cf501d9.png)

  

仅让植树行动遥远而不可及，显然无法满足网络安全志愿者们的宏愿。你亲手找的漏洞，这个9月，我将带你亲手种植林木回报你对互联网安全生态的付出。

**宁夏远征令**

**响彻云霄**

**远征时间**：9月1日-9月4日

**远征对象**：千名top网络安全志愿者中脱颖而出的两位精英

**远征地**：宁夏

**征途**：沙漠徒步；亲手种树；参加全球公益组织…

**远程行程**：

**远征目标**：互联网安全防护林12家SRC联盟代表中将挑选出网络安全志愿者代表，承载着网络安全志愿者们的托付前往宁夏地区亲手种下树木。为保护宁夏自然保护区的生态环境，当地有着严格的人员出入数量限制，因此此次的宁夏种树之行，我们将挑选出2位网络安全志愿者代表前往。

**选拔方式**：8月11日-8月19日24点，网络安全志愿者们在12家已加入互联网安全防护林SRC/众测平台中，每家提交并确认一个漏洞，不分等级，最先完成12家打卡（即全垒打），按照达标顺序，前2位将代表去宁夏种树。
