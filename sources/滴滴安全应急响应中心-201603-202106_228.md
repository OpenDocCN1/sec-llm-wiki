**币安宣布第一笔收购：移动钱包 Trust Wallet**

![](../Images/8dace7ea4d5ea4d534a55e919bf197cc.png)

全球交易量最大的加密货币交易所币安近期完成了第一笔收购，被收购的是移动钱包公司 Trust Wallet。

这笔交易的金额没有公布，但币安对 TechCrunch 证实，收购价格中包括现金、币安的股票，以及部分 BNB 代币。在这笔收购之后，位于美国的 Trust Wallet 将继续独立运营，而目前总部位于马耳他的币安将协助 TrustWallet 的管理，并承担营销等非技术领域的工作。币安 CEO 赵长鹏在接受 TechCrunch 采访时表示：“Trust Wallet 的团队与我们有着同样的价值观，而产品也非常互补。对于那些喜欢提取资金到钱包的用户，现在我们有了一款他们可以使用的产品。”

**点评**

不仅要你的币在，还要你的钱包在。

**亚马逊计划 2020 年初彻底抛弃甲骨文专有数据库**

![](../Images/46581c9c4eb371c4f1937b694eea8bb7.png)

亚马逊在数据中心技术提供商这条路上的发展日渐将不少自己长期以来的供应商变为了难以共融的竞争对手，甲骨文（Oracle）即其中之一。最近，亚马逊正在考虑对甲骨文的新一轮打击。据知情人士透露，这家电子商务巨头已经将公司大部分内部基础设施转移到亚马逊网络服务（AWS），并计划于 2020 第一季度彻底移除甲骨文的专有数据库软件。

这一转变亦标志着亚马逊在企业计算领域的快速崛起，并进一步显示了在企业不断将工作转至云平台并抛弃传统数据中心这一过程中甲骨文的艰难挣扎。得益于 AWS 的发展（第二季度该业务的营收增长高达 49%），亚马逊在今年初超越 Alphabet 成为全球价值第二大的上市公司。

**点评**

新一轮神仙打架。

**美国囚犯攻破监狱系统，私自充值近 25 万美元**

![](../Images/fdca450e8e15076e7726d6ae3d140c1e.png)

美国爱达荷州的囚犯成功攻破了监狱发放的平板电脑软件系统，给自己充入了近 25 万美元的帐户余额。这些平板电脑由知名监狱设备供应商 JPay 制造，通常是他们与外界的唯一联系途径。囚犯可以使用平板电脑收发电子邮件、听音乐、转账，以及完成基本的计算功能，但某些服务是收费的。

根据 美联社的报道，爱达荷州监狱官员发现，364 名囚犯利用软件漏洞给自己增加了 JPay 账户余额。在爱达荷州，这些设备是 JPay 与 CenturyLink 合作的成果。后者证实了软件漏洞的存在，但拒绝提供更多细节，只是表示问题已得到解决。到目前为止，JPay 已经索回了约 22.5 万美元总金额的 1/4，并停止了囚犯使用的某些功能，直到他们完成赔偿为止。

**点评**

在监狱也不能阻挡一颗挖洞的心！

** 4 **

**Reddit 承认发生信息安全事故，部分用户数据泄露**

![](../Images/49b19e2b42dbcb466847611340af29e7.png)

Reddit宣布，6 月份时的一个信息安全漏洞导致攻击者入侵了该公司内部系统的某些部分，但泄露的数据并非敏感数据。值得注意的是，这次攻击绕开了 Reddit 通过短信实现的双因子认证系统。这也给仍在使用短信来部署双因子认证的互联网服务敲响了警钟。

Reddit 首席技术官克里斯·斯洛维在博客中解释称，该公司于 6 月 19 日发现了这次黑客攻击，估计攻击发生在 6 月 14 日到 18 日之间。他表示，这次攻击“影响了少量我们的员工帐号，以及云计算和代码托管服务提供商”，获得了“访问某些系统的只读权限，这些系统中包含备份数据、源代码和其他日志文件”。

**点评**

短信验证存在着固有的安全缺陷，短时间仍无法改变。

**GitHub 推出 Python 安全警告，识别依赖包的安全漏洞**

![](../Images/204df4af5bed702ec94269caa40e3c57.png)

GitHub 宣布了 Python 安全警告，使 Python 用户可以访问依赖图，并在他们的库所依赖的包存在安全漏洞时收到警告。

GitHub 会根据 MITRE 的公共漏洞列表（CVE）来跟踪 Ruby gems、NPM 和Python 程序包中的公共安全漏洞。CVE 是一个条目列表；每个条目都包含一个标识号、一段描述以及至少一项公共参考。这非常有助于促使管理员快速响应、通过移除易受攻击的依赖或迁移到安全版本来修复漏洞。

当 GitHub 收到新发布的漏洞通知，它就会扫描公共库（已经选择加入的私有库也会被扫描）。当发现漏洞时，就会向受影响的库的所有者和有管理员权限的用户发送安全警告。

**点评**

有了全自动检测Python依赖包，漏洞减减减！

**迪拜将创建世界上第一个区块链法庭**

![](../Images/deb8df080a7577f352cb204f3b303f13.png)

迪拜国际金融中心（DIFC）与智能迪拜（Smart Dubai ）展开合作，将创建世界上第一个区块链法庭。在现有的争端解决服务的基础上，双方将首先探索如何帮助法院核实对跨境执法的判决。该法庭的建立，将简化司法程序，消除文件重复，提高整个法律生态系统的效率。

双方对此的研究将结合专业知识和资源，调查由私链和公链引起的纠纷，以及智能合约的编码规则和合同条款。目前，基于区块链的智能合约交易不可撤销，且没有技术手段来解除交易。

联合工作组将在区块链上建立智能合约，整合逻辑，并允许各种形式的例外和条件，以实现无缝且更有效的争端解决方案。

**点评**

这年头当个法官都要懂个区块链~

**惠普发布bug赏金计划寻找打印机漏洞，最高10万美元**

![](../Images/4672ded436100caf84b661aee40325f7.png)

惠普宣布了第一个专门针对其打印机的bug赏金计划，为能够在其机器上发现漏洞的黑客提供高达1万美元的奖励。Bug赏金是公司发现安全漏洞的常见方式，对于严重漏洞酬金支付可高达10万美元。

HP的bug赏金计划将通过Bugcrowd运行，这是一个促进支付和邀请的平台。该程序目前是私有的，邀请研究人员加入。奥尔布赖特表示惠普有意将其公开，但目前仍在关闭状态以更好地管理发现的漏洞。受邀研究人员可以从他们家里的电脑上远程访问15台打印机，这些打印机在惠普的办公室中被隔离，他们可以窥探这些打印机，找到隐藏的漏洞。如果他们发现并报告任何缺陷，HP将支付他们的发现费用，然后在下次更新时开始修复。
