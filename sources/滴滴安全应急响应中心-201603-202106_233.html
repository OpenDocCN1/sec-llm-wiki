短信不安全，Instagram 正在开发独立的双重认证功能

黑客可以把你的电话号码复制到一张新的 SIM 卡上，从而将你的号码据为己有，用来重置你的密码，窃取你的 Instagram 和其他服务的账号，并拿出去售卖换取比特币。正如 Vice 旗下 Motherboard发布的一篇文章中所详细报道的那样，Instagram 账号特别容易受到攻击，因为该应用仅支持通过短信验证码登录，一旦电话号码被劫持，相关账户的安全性立刻将为零。

不过，现在 Instagram 向 TechCrunch 证实，他们正在开发一套配合 Google Authenticator 或 Duo这类安全应用使用的非短信双重认证系统。这套系统生成的验证码无法在其他手机上显示，这样即使你的手机号码被黑客复制到新的 SIM 卡上也没有关系。

点评

双重验证，双重保险。

 Farfetch 收购 CuriosityChina 奇智睿思，拓展中国社交媒体业务

电商创业公司 Farfetch 与约 900 家高端时尚精品店和品牌合作，通过在线平台展示并销售服装、鞋帽、配件和首饰。有消息称 ，该公司正在筹备规模 60 亿美元的 IPO（首次公开招股）。与此同时，该公司正在通过收购，进一步押注中国市场。中国是全球增长最快的奢侈品市场之一。

Farfetch 将收购 CuriosityChina 奇智睿思 ，后者的优势在于利用社交媒体，尤其是微信，展开营销活动，瞄准用户并销售商品。Farfetch 的计划是，将奇智睿思集成至该公司的“Black & White”白标签 API中。这个 API 让精品店可以将存货加入至 Farfetch 的采购和物流平台，或使用该引擎在自己的网站上销售商品。在这笔收购后，Farfetch 的客户可以选择使用这个 API 在中国开展营销活动。

点评

中国消费者的崛起也带动了社交媒体的兴起。

部分顶级网站的密码策略和十年前一样糟糕

你可能会认为，亚马逊、Reddit、维基百科和其他知名网站会告诉你，“password1”和“hunter2”是糟糕的密码。然而实际上这些网站并未这样做。近期的一个研究项目跟踪了过去 11 年顶级网站的密码设置规则。结果表明，大部分网站只提供最基本的密码限制，没有采取更多措施去帮助用户。

普利茅斯大学的史蒂芬·弗内尔于 2007 年首次对网站的密码设置规则进行了调查。令人失望的是2018 年的总体情况与 2007 年基本相似。在中间的这些年里，关于什么样的密码是失败的密码，以及我们使用密码的正确方式是什么，已经有过很多报道。然而，网站并没有做出太多改进，鼓励或强制用户采取正确的做法。

点评

与其讨论什么样的密码是失败的密码，不如真正的做些什么。

“MoneyTaker”黑客从俄罗斯银行偷走了100万美元

据网络犯罪研究公司Group-IB称，一个被称为MoneyTaker的网络犯罪团体最近设法从PIR Bank（俄罗斯）窃取了近100万美元。

盗窃案于7月3日通过俄罗斯中央银行的自动化工作站客户端进行，这是一个类似于SWIFT的银行间系统。黑客设法将资金转移到俄罗斯主要银行的17个账户，然后将其兑现。安全研究人员证实，对PIR Bank的攻击始于2018年5月下旬，并且该银行区域分支机构之一的受损路由器被用作入口点。“路由器有隧道，允许攻击者直接访问银行的本地网络。这种技术是MoneyTaker的一个特征。研究人员表示，该计划已经被该集团至少三次用于攻击具有区域分支网络的银行。

点评

又又又是以路由器为入手点的攻击。

Microsoft解决了Translator Hub中的严重漏洞

Microsoft Translator Hub该服务允许感兴趣的各方根据组织需求构建自己的机器翻译系统，然后通过Microsoft Translator Text API在应用程序，网站等中使用它。在寻找Hub上的漏洞时，安全研究人员Haider Mahmood 发现删除项目的HTTP请求包含“projectid”参数，该参数是数据库中单个项目的ID。此外，Mahmood还发现该请求也没有跨站请求伪造（CSRF）保护。这意味着攻击者可以利用CSRF漏洞冒充合法的登录用户并代表他们执行操作。事实上，安全研究人员透露，通过迭代从0到13000的项目ID，攻击者可以从数据库中删除所有项目。

点评

删库后就只能跑路了。

美国国安局局长组建特别行动小组 反击俄罗斯的网络威胁

据外媒报道，美国网络司令部司令兼美国国安局局长Paul Nakasone近日确认，他已经成立了一个特别行动小组来解决俄罗斯在网络空间带来的威胁。Nakasone在科罗拉多州举行的阿斯彭安全论坛上表示，俄罗斯“有很强的能力，我们一定会被访问。如果被非法访问，我认为，毫无疑问我们将确保我们采取行动。”

Nakasone还表示，以美国关键基础设施为目标，将构成高于该水平的攻击。2017年1月，Jeh Johnson曾将选举基础设施添加到重要政府设施清单中，包括投票系统，选民登记和投票站 。

点评

终于要反击了。

新的sextortion计划使用受害者的真实密码进行勒索

互联网用户需要警惕新的网络钓鱼骗局，这实际上是一种分销方案，利用用户的旧密码并勒索他们观看色情内容。诈骗者声称在观看色情片时记录了受害者的镜头。他们还声称拥有用于在目标计算机上安装间谍软件的受害者密码，当受害者访问色情网站时，他们激活了网络摄像头以录制镜头。

通常情况下，诈骗者发送的电子邮件中突出显示的密码是合法的，受害者以前曾使用过。安全专家认为，网络犯罪分子很可能利用从各种大规模数据泄露中获取的旧密码，他们只是将旧密码与有用的标识符匹配。成功定位受害者后，他们可以轻松启动勒索活动。
