0x02  第四扩展FS

binwalk windows.jpg之后发现存在一个加密的zip文件。

提取加密 zip 文件，从图片 EXIF 信息中备注字段获得密码Pactera（Windows: 右键 - 属性 - 详细信息）。  

获得一个看上去意义不明的文本文件。

根据提示 日常违规审计中频次有时候非常重要 对文件进行字频统计，按照频率从高到低排序，获得 flag ，代码如下：

import operator
def char_frequency(str1):
    dict = {}
    for n in str1:
        keys = dict.keys()
        if n in keys:
            dict[n] += 1
        else:
            dict[n] = 1
    return dict
f = open("file.txt","r")
sorted_x = sorted(char_frequency(f.read()).items(), key=operator.itemgetter(1),reverse=True)
for c in sorted_x:
    print c[0],

0x04 安全通信

ECB 选择明文攻击。由于 ECB 使用固定长度的明文与固定长度的密钥进行运算，获得固定长度的密文。

因此在密钥不变可以构造明文的情况下，可以进行逐位碰撞来撞出明文。

我在撰写脚本时参考了这篇文章

（https://michael-myers.github.io/blog/post/enigma2017-broken-encryption-writeup/）。

我在学习 ECB 选择明文攻击时参考了这篇文章（https://github.com/EiNSTeiN-/chosen-plaintext）。

在本题中提交用户名时可以构造一个长度任意的字符串。

我们使要猜测的一个字节位于构造字符串 padding 的最后一位，如下图中的逗号：

+--------+--------+--------+--------+
|data=aaa|aaaaaaa,|secret=a|bcdef   |
+--------+--------+--------+--------+

之后对最后一位进行遍历，此时密钥不变，当密文与之前获得的相同时，就爆破出了最后一位字符。

以此类推逐个爆破，即可获得所有明文。

         +--------+
guess 0: |aaaaaaaa|
         +--------+
guess 1: |aaaaaaab|
         +--------+
guess 2: |aaaaaaac|
         +--------+
  ...
         +--------+
guess n: |aaaaaaa,|
         +--------+

爆破脚本如下：

#!/usr/bin/python
# DDCTF, Misc 5
# Origin: https://michael-myers.github.io/blog/post/enigma2017-broken-encryption-writeup/
__author__ = 'michael-myers'
__editor__ = 'henryzhao'
import sys
import time
import socket
# Split encrypted string.
def parse_challenge(challenge):
    challenge = challenge.splitlines()[0]
    challenge = challenge[2:]
    ciphertext_blocks = [challenge[0:32], challenge[32:64], challenge[64:96],
                         challenge[96:128], challenge[128:160], challenge[160:192],
                         challenge[192:224], challenge[224:]]
    return ciphertext_blocks
def main():
    guessed_secret = ""
    mask = " flag is: DDCTF"
    for secret_bytes_to_guess in range(0, 54):
        # Add in a new guessing byte at the appropriate position:
        print 'current pos: ' + str(secret_bytes_to_guess)
        s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        server_address = ('116.85.48.103', 5002)
        s.connect(server_address)
        time.sleep(0.2)
        print s.recv(2048),
        s.sendall("2acba569d223cf7d6e48dee88378288a\n")
        time.sleep(0.2)
        print s.recv(2048),
        # Padding string
        padstr = 'A'*(56-secret_bytes_to_guess)
        print 'padstr: ' + padstr
        s.sendall(padstr+"\n")
        time.sleep(0.2)
        first_data = s.recv(2048),
        # We built a 56-byte padding, so the encrypted block will always be 6st.
        block_to_guess = parse_challenge(str(first_data))[6] 
        print first_data
        print parse_challenge(str(first_data))
        # We choose first 15 as static string.
        current_guess_str_head = mask[-15:] 
        for guessed_byte in range(0x20, 0x7E):
            # And add the current guessing character as the 16st.
            current_guess_str = current_guess_str_head + chr(guessed_byte)
            # Sent to server and get encrypted string.
            s.sendall(current_guess_str+"\n")
            time.sleep(0.15)
            recv_enc_data = s.recv(2048)
            recv_enc_data = recv_enc_data.splitlines()[0]
            print "Currently guessing: " + current_guess_str
            print "Chosen vs. final ciphertext blocks: " + recv_enc_data + " <- ? -> " + block_to_guess
            if recv_enc_data == block_to_guess: # Yeah!!!!
                guessed_secret = guessed_secret + chr(guessed_byte)
                print "Guessed a byte of the secret: " + guessed_secret
                mask = mask + chr(guessed_byte)
                break
        if guessed_secret[-1] == '}':
            break
    print "All guessed bytes: " + guessed_secret
    print("Done")
if __name__ == "__main__":
    main()


0x05 complex stego

易思路（solution_decrypt2.py）：
X(z)实际上这相当于1,z^(-1),z^(-2)...的一个线性组合常向量(input) * 向量(z)。给了X(z)，z可以任取的情况下，以input的视角来看就是f(input) = 常向量(z) * 向量(input) = input[0] + 1/z * input[1] + 1/z^2 * input[2] ... = X(z)，因此在f中，z实际上为参数，实质自变量为input。

在数学世界中，我们可以选取45个z值z0, z1 .. z44，然后得到45个线性方程组input[0] + 1/z0 * input[1] + 1/z0^2 * input[2] .. = X(z0)，input[0] + 1/z1 * input[1] + 1/z1^2 * input[2] .. = X(z1) ...
令行向量V(z) = [1 1/z 1/z^2 ...]， 方程组写成矩阵就是 [V(z0); V(z1); .. ] * 列向量(input) = 列向量([X(z0); X(z1); ...])， 令矩阵A=[V(z0); V(z1); .. ]，向量x = Vec(input)，向量y = [X(z0); X(z1); ...]，那么就是Ax=y，其中A, y已知，那么显然x=A^(-1) * y 。

然而还差一点，这是现实世界，图像中只有256种取值，因此X(z)函数值会有比较大的量化误差，同时还有像素值<0或者>255引起的截断误差。因此，这时z点取值要取合理的点，也就是图像g,b值均>2且<254保证没有截断误差。至于量化误差，可以取最小二乘解来解决。我们取1000个合理点z，得到1000个方程组，也就是1000 * 45的矩阵A， 那么由于量化误差，实际上这时就是Ax ~= y，因此我们取A的伪逆pinv(A)，得x ~= pinv(A) * y即可。

难思路（solution_decrypt.py）：
根据函数名z_encrypt、题目名complex、提示（傅里叶变换视频）、搜索引擎或者数学功底，了解到这是一个z变换，encrypted.png为其函数图象，参照https://en.wikipedia.org/wiki/Z-transform#Inverse_Z-transform 

中的路径积分公式

 计算即可。在单位圆上面选取1000个点计算数值积分即可。

具体代码可参考：https://github.com/garzon/DDCTF_2018/tree/master/complex_stego


0x06 keepassx

keepassx是一个Linux的开源程序。拿到题目我们首先应该安装Linux虚拟机。并且从Github下载keepassx的源代码。
拿到源代码查看并加上百度发现keepassx是基于Qt做的跨平台的移植。所以也应当下载Qt的源代码。

通过阅读源码我们应该理清大体架构和逻辑。KeePass2Writer-writeDatabase是用来储存密码的方法。
