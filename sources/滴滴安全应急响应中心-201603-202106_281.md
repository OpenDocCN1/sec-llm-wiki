# DDCTF校园行成功在成都举办！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3Mzk1MDk1NA==&mid=2651904463&idx=1&sn=e59d9e60841b77d381709f4f67bbd4b4&chksm=84e34a4ab394c35c16e14852539cf47e048fb5ac7ad8f4d7a2a71f800f44b6d0a07fdfb414aa&scene=126&sessionid=1681379516#rd](http://mp.weixin.qq.com/s?__biz=MzA3Mzk1MDk1NA==&mid=2651904463&idx=1&sn=e59d9e60841b77d381709f4f67bbd4b4&chksm=84e34a4ab394c35c16e14852539cf47e048fb5ac7ad8f4d7a2a71f800f44b6d0a07fdfb414aa&scene=126&sessionid=1681379516#rd)

3月22日，滴滴安全校园行在成都电子科技大学清水河校区成功举办，还有数十位成都信息工程大学的小伙伴们前来参加，现场气氛火热~

![](../Images/9e158b115138128ed639d9845fabb2c9.png)

  

同学们认真听讲，积极思考![](../Images/2c65fabf433a73dee2b80da87765c996.png)

  

![](../Images/2243b27c01991ca29d46dcdfda572d69.png)

在本次成都电子科技大学的DDCTF校园行讲座上，滴滴出行安全工程师、DDCTF2017优胜选手张顺先为同学们讲解了去年DDCTF的赛题，与同学一起讨论思路，并透露他也是今年DDCTF出题人之一，欢迎大家赛后交流。此外，在演讲中张顺还向大家介绍了他加入滴滴信息安全部后的一些工作与收获。他提到，目前滴滴不仅有着非常良好的信息安全环境与氛围，更是有许多顶级安全专家，在这里不仅可以随时与他们交流，更是可以从他们身上学到不同的“姿势”，来提升自己的技术水平。最后，他表示希望可以有更多优秀的同学加入滴滴，一起来应对更多的难题与挑战。
