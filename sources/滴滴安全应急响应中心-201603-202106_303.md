# 2017滴滴安全大会暨颁奖典礼全景回顾，感谢所有合作伙伴！

1月12日，2017滴滴安全大会暨颁奖典礼成功举办。来自阿里、腾讯、360、盘古、长亭科技、知道创宇等公司的安全大咖齐聚大会现场，为我们带来众多技术干货议题分享。同时，在大会现场，我们还为在2017年为滴滴做出巨大贡献的白帽颁发了个人与团队奖项。
