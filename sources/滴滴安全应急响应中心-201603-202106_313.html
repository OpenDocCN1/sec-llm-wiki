【职位一】

  安全数据分析工程师 - 内网安全  

职位描述：

1. 负责安全事件的数据分析，输出告警规则；

2. 负责公司内部系统业务数据分析，建设操作关联系统；

3. 负责从海量日志中关联分析异常行为，建设关联分析平台。

任职要求：

1. 有业务安全的数据分析和防护经验，了解复杂业务场景下的异常行为发现方法；

2. 具备日志分析经验，能够海量日志中分析异常行为，能够建立多维度日志的关联分析方法；

3. 具备使用数据分析算法进行数据分析能力，有机器学习在信息安全领域应用经验优先；

4. 本科学历以上，计算机或相关专业；

5. 有较强的代码能力，开发过应急响应相关工具或平台优先。


【职位二】

  安全技术运营工程师 - 生产网  

职位描述：

1、负责入侵检测系统策略设计与运营；

2、参与攻击检测系统/监控系统的开发；

3、针对入侵事件进行分析，总结特定攻击场景的特征，形成可落地的规则/模型。

任职要求：

1、熟悉常见黑客攻防手法、主流漏洞成因及基础安全知识；

2、熟悉Python、Sql、Scala、Java一种或多种语言；

3、了解常见 AI 模型，统计分类算法，熟悉 Hadoop、Spark 等大数据平台框架，了解 Map Reduce 基本原理。

有以下经验优先考虑：

1、对 Python 网站框架Django/Flask 有一定了解，可以独立进行研发者优先；

2、有数据挖掘经验，有攻防对抗经验，有高级别爬虫研发/防爬经验者优先；

3、有薅羊毛、刷数据等黑灰产行为的对抗经验者优先；

4、有项目管理、安全方案推行或者安全策略推行经验者优先。


【职位三】

  应急响应工程师 - 内网安全  

职位描述：

1. 负责安全事件的应急响应，快速定位并处置，溯源并完整复盘事件经过；

2. 负责安全攻防产品的告警运营，并参与整体安全解决方案的建设；

3. 负责从海量日志中发现问题并输出相关运营自动化工具或者系统；

4. 关注国内外安全事件，从安全事件中提炼防护、检测规则。

任职要求：

1. 有应急响应经验，了解多种攻击场景下的应急处置与分析方法，有APT攻击分析实战经验者优先；

2. 具备日志分析经验（如IPS、FW、系统日志、应用日志等），能够从日志中发现异常事件，输出日志关联分析方法；

3. 在web攻防、系统攻防、网络攻防、移动端攻防、常见应用攻防、恶意软件等任一领域有比较深入的认知；

4. 本科学历以上，计算机或相关专业；

5. 有较强的代码能力，开发过应急响应相关工具或平台优先。


【职位四】

  漏洞分析工程师  

职位描述：

1、编写扫描插件，参与扫描器的维护和开发；

2、跟踪业界重大漏洞，参与安全事件应急响应；

3、云平台漏洞安全运营。

任职要求：

1、熟悉各类漏洞原理及修复方案；

2、熟悉互联网系统的常见架构；

3、善于挖掘漏洞，有一定的渗透测试经验和能力；

4、关注业界漏洞动态，对漏洞信息敏感且有一定判断力；

5、至少会使用 python/php/java 中的一种语言开发；

6、本科及以上学历。


【职位五】

  WAF/服务器安全Agent研发工程师  

职位描述：

1、负责或参与WAF/服务器Agent的检测引擎、调度、运营平台等模块开发；

2、负责WAF/服务器Agent在生产环境的稳定运行。

任职要求：

1、 熟练掌握常用数据结构和算法，并能灵活运用；

2、基础扎实, 熟练掌握 C/C++ 语言, 有 2 年以上的 Linux 环境开发经验；

3、能承担较大工作压力，有较强独立分析，解决问题的能力；

4、逻辑思维清晰，良好的文字和语言沟通表达能力；

5、有良好的团队合作精神。

加分项：

1、熟悉 TCP/IP、HTTP、HTTPS、HTTP/2 等网络协议，精通 socket 网络编程；

2、有大访问量高压力程序开发经验；

3、对自动机等理论有过实践或者对 nginx 有深入理解；

4、有研究能力，曾经在某个领域有深入的研究。


【职位六】

  移动端开发工程师  

职位描述：

1、负责移动端Web及Hybrid应用的架构设计与实现，能够对移动应用提供持续的体验与性能优化；

2、与产品、UI和后端进行良好的沟通协作，能够理解产品设计，完成移动应用合理的技术规划；

任职要求：

1、本科或以上学历，计算机相关专业，3年以上工作经验；

2、深入理解W3C标准与ES规范，熟悉Web语义化，理解Web标准，掌握盒模型、常用布局以及浏览器的兼容性；

3、对MVC/MVVM等有深入的理解，能够熟练运用常用设计模式到实际项目中来解决问题；

4、熟练掌握Android/iOS平台混合移动应用的开发过程，能够独自选择技术路线并搭建项目框架；

5、熟练使用React/Vue/AngularJs/RequireJS/Ionic/PhoneGap/Cordova/ReactNative等前端和混合框架中的一种或多种，了解原理者优先；

6、具备iOS/Android原生开发能力，熟练使用Object-C/Java，了解iOS/Android开发中的常用库，熟悉JS与Native代码的交互者优先；


【职位七】

  移动安全专家  

职位描述：

1、负责移动客户端的安全测试及漏洞响应处理；

2、负责移动客户端自动化安全测试平台的开发运营；

3、负责移动安全加固技术研究与开发。

任职要求：

1、熟悉APP漏洞挖掘方法（白盒/黑盒），对漏洞原力有较深入的了解；

2、熟悉x86和ARM汇编，熟练使用IDA等相关逆向和调试工具；

3、熟悉反编译、动态调试、加密、防劫持、脱壳、安全加固等技术；

4、熟悉APP架构、包括部署架构，了解对APP生命周期安全管理；

5、熟悉IOS，Android客户端和服务器端通信机制及防护技术；

6、有客户端自动化检测平台开发或漏洞运营经验者优先。


【职位八】

  安全开发工程师  

职位描述：

对于研发过程产生的漏洞通过工具的方式进行消除，开发部门漏洞管理的平台。

任职要求：

1、有五年以上开发经验；

2、至少精通两门编程语言（python、Java、Golang、nodejs）python优先；

3、有多线程、高并发、分布式架构设计等相关经验；

4、精通HTTP协议，熟练使用HTTP相关的组件库；

5、熟悉MySQL、Redis、MQ等技术；

6、具备良好的沟通能力、学习能力、英文阅读能力。


【职位九】（急招）

  安全运营工程师  

职位描述：

1、负责滴滴云平台安全检测以及安全事件的分析处理；

2、负现监控、扫描等各类安全策略的制定、实施与持续优化；

3、紧跟新的安全威胁。

任职要求：

1、在安全任一领域有突出的能力，熟悉常见的安全漏洞的攻防；

2、具备一定代码能力，能用自动化解决问题；

3、有海量日志分析的能力，对告警事件有理解、分析、判断和优化能力；

4、对技术有浓厚的兴趣；

5、综合素质要求：逻辑能力，责任心，敏锐，主动，沟通能力浪好；

6、本科及以上学历。
