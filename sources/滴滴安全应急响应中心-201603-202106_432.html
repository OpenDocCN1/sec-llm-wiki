Question：
在和开启  OCSP  Stapling 的 Server 端进行 TLS  Handshake 时， OCSP Response Data 中的 This Update 和 Next Update 之间差 7 天, 这个时间是谁决定的？为什么？

Answer：
OCSP  Response Data 中的 This Update 和Next Update 相差 7 天这个是由该证书对应的 CA 决定的。

在 RFC 2560 中 2.5 节，  OCSP Responders (CA) 有个 Response Pre-production 过程，即在特定时刻执行一次 Response Pre-production ，如果 OCSP Status 是 「Good」则这个时间是 This Update , Next Update 的时间，在这个时间的基础上再加上周期, 这个周期在CA 处是可以配置的。
