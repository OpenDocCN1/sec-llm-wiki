# 今天终于把多年来欠的书费还上了！

在网络安全的求学道路上，对我影响比较大的有两本书：《网络渗透技术》和《深入理解计算机系统》。  
最早是先看到网渗的电子书，发现看不懂，但感觉很厉害的样子。于是，上安全焦点找学习指引，原文已搜不到，只记得当时推荐了《深入理解计算机系统》，就去学校图书馆借来学习，从此才算步入计算机技术的大门。  
但学完《深入理解计算机系统》其实是不足以看懂网渗一书，还有很多其它知识，所以又去找其它知识学习，也正是这个过程才认识了看雪论坛，从中获益良多。  
最后，花了好多年才从零基础到看懂《网络渗透技术》一书，引领着我整个安全学习的道路，至少是有个目标在那里的。  
网渗一书很早就绝版了，网上很难买到中间曾从淘宝以双倍价格买了复印版，一直没买过正版。  
后来出版社又搞了绝版复印，但要双倍价格，且封面改变了，因此我也没买。  
现在京东和淘宝上都拿买到此书，可能大多是二手，有兴趣的可以去淘本作纪念。  
今天从淘宝买的一本二手正版的《网络渗透技术》收到了，50几块，把欠了多年的书费给还了！
