# 倚天屠龙荐：Chrome插件推荐

给大家推荐几款比较好用chrome插件，包括日常应用功能以及安全测试用途的，大家各取所需。  

  

**1、****Adblock Plus：广告拦截器**

  

![](../Images/73b5f6000f76831112631776d4e7f4d2.png)

用AdBlock可以直接指定选择相应的div块进行拦截，看哪不爽就拦截哪，非常适合某些个广告繁多色彩斑斓的站点。

  

**2、****Chrono下载管理器**

  

![](../Images/61ee2aad2e9db143de9f83a484767ca6.png)

在收集Fuzz样本，比如图片或者pdf时，通过chrono指定文件后缀即可从当前网页中提取下相应文件后缀的下载地址。

在下载BlackHat等知名安全大会的PPT时，显然要比你写脚本，或者通过迅雷识别更方便高效。

  

**3、****Imagus：图片放大镜**

  

![](../Images/ab9b65339f98a3e67e7d918140ea19bc.png)

有时刷微博时看到的图片都是缩小的图片，想看清晰点的还得再点一下打开，通过Imagus直接将鼠标悬停在图片上，即可放大显示图片，甚为方便。

  

**4、****Google翻译**

  

![](../Images/a5d1e6aad9f1bc77d3661713e59418dd.png)

之前都是用金山词霸作为翻译软件，但实际上也就刚安装的时候可以用，过几天经常就没反应了。

后来发现在浏览器看英文资料的情况比较多，刚好有google翻译这款插件，划词翻译，整句翻译也支持。

  

**5、****FireShot：捕捉网页截图**

  

![](../Images/51684fb76108d8e0e691992f6092bc01.png)

用FireShot可以在网页上截图，也可以直接捕捉整个页面，这个功能比较实用，支持保存为PDF，JPEG，GIF，PNG或BMP等多种格式。

  

**6、****LastPass：密码管理软件**

  

![](../Images/0aefbadb2f2c2be9b5a6befabf166cee.png)

用LastPass可以帮助生成、填充密码，加密云同步，可以手机、电脑等多平台上同步使用，可以防止忘记密码，定期更改密码也方便。

可能更多人担心的还是云同步密码的安全性，虽不能说万无一失，但对于大众的安全保护还是足够的。在便利与安全方面，看你个人的取舍了。

  

**7、****Vimium：快捷键操作插件**

  

![](../Images/2435b1d3e21cffba38afc75c1de1d8a9.png)

我觉得这个非常适合程序员，用惯了vim，再在浏览器上使用vimium会非常顺畅，一旦熟炼使用，操作会非常快，尤其适合键盘控们拿来装逼。

![](../Images/703659da0b3eb603d10594cc970738f6.png)

  

8、Evernote：印象笔记剪藏

  

![](../Images/f58acb3cadb50caa97106c43337fe30b.png)

  

在浏览网页时，看某些觉得不错的文章，可以直接通过该插件保存到印象笔记，各平台上都可以用印象笔记这个app查看保存的笔记，随时随地可查阅。

  

**9、****Wappalyzer：Web技术识别插件**

  

![](../Images/6c29e9b18dc67f85f109cd3c3aa498c0.png)

  

渗透测试中，这个插件非常有用，可以当作收集目标网站信息的工具，再针对这些Web框架作有针对性的渗透测试。

  

**10、****Tampermonkey：流行脚本管理器**

  

![](../Images/0aee4de4618caa001e949aabcf80a383.png)

中文名叫“油猴”，它的强大的之处在于可以下载使用广大网友提供的js脚本，包含各式各样的功能，相当于另一个插件管理器。比如Endless Google可以自动翻页搜索结果，比如Yet Another Weibo Filter可以过滤微博上自己不想看的信息，还有其它更多脚本功能，大家可以自行挖掘。

  

**11、****GitHub Hovercard**

  

![](../Images/14bb9bea11f74b83bc0ae61425d39539.png)

  

通过该插件，当你将鼠标停留在 GitHub 网站的用户头像或者仓库链接地址上时，会自动弹出一个悬浮框，带你提前预览基本信息。插件支持的悬停位置更多，包括用户头像，仓库地址，Issue 链接，个人主页等。

  

**12、****Octotree：GitHub代码目录浏览**

  

![](../Images/5df60adf392373c5fb5500aec461336b.png)

  

在GitHub上查看代码目录不是很方便，每次打开目录就相当于要再重新打开一次网页，效率很低。通过该插件，可以直接浏览整个项目的代码目录树，不同文件格式还自带图标，想看哪个文件直接点击即可。

  

**13、****OneTab：将多个Tab合并到一个页面**

  

![](../Images/7b98f7f7f6e5f9ebd38fbeedc0e057e7.png)

有时开着浏览器，打开的页面越来越多，多得只能显示个网页logo了，找都不方便找了。用OneTab可以直接所有当前标签页全并到一个页面上显示，节约内存，又方便查找。

  

14、**JSON Viewer**

  

![](../Images/7a696895c0b70f24e8f032ad014afc1c.png)

  

JSONView 是一个方便查看 JSON 结构的插件，支持展开、折叠功能，可以方便地查看返回数据。
