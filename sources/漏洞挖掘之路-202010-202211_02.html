hashcat

Hashcat 是世界上最快的密码破解程序，是一个支持多平台、多算法的开源的分布式工具。

项目地址：https://github.com/hashcat/hashcat

hashcat安装

windows使用msys2安装

https://github.com/hashcat/hashcat/blob/master/BUILD_MSYS2.md

1、首先去https://www.msys2.org/ 下载并安装 完成1-7步

下载并安装
安装完成后执行
pacman -S mingw-w64-ucrt-x86_64-gcc
gcc安装后查看版本
gcc --version

2、安装所需依赖项

pacman -S git
pacman -S make
pacman -S gcc
pacman -S libiconv-devel

3、下载最新的hashcat

git clone https://github.com/hashcat/hashcat.git

4、编译

cd hashcat
make

5、执行

./hashcat

注意：虚拟机安装由于虚拟机显卡问题，会造成不适配问题。电脑安装如果电脑缺少显卡驱动的话，去对应的官网下载驱动即可。所用到的Opencl有intel版本，nvida版本和AMD版本。

默认安装目录为

C:\msys64\home\user\hashcat\
例如：
C:\msys64\home\Administrator\hashcat


其他安装方法

https://github.com/hashcat/hashcat/blob/master/BUILD.md
