# 案例4 超时设置

### 为什么需要设置超时？

 默认情况下，socket中没有超时None，如果无法连接到服务端，那么就会一直等下去。

### 设置超时

socket.gettimeout #获取设置的超时的值 

socket.settimeout #设置超时的值

```
 import socket
s=socket.socket()
a=s.gettimeout()#获取设置的超时的值
s.settimeout(0.5)#设置当前超时
b=s.gettimeout()#获取设置的超时的值
print(a,b)
```

  

# 案例5 重用套接字地址

### 为什么需要设置？

 默认情况下，套接字在使用完一个地址之后(ip,port)，这个内容将不能使用。

### 设置重用

获取套接字内容 getsockopt(socket.SOL\_SOCKET,socket.SO\_REUSEADDR)

设置套接字内容 setsockopt(socket.SOL\_SOCKET,socket.SO\_REUSEADDR,1)

相关知识：https://blog.csdn.net/weixin\_30662109/article/details/97018111

假如端口被`socket使用过`，并且利用socket.close()来关闭连接，但此时`端口还没有释放`，要经过一个TIME\_WAIT的过程之后才能使用，这是TNN的相当烦银的，为了`实现端口的马上复用`，可以选择setsockopt（）函数来达到目的。（以下是网上找到的一篇文章的一小段相关例子，试用之后，相当有效果，特此提取出来收藏）

端口复用的实现，我在这里用Python举个TCP端口复用的例子，UDP套接字要做的完全一样。

```
 import socket
tcp1 = socket.socket(socket.AF\_INET, socket.SOCK\_STREAM)
tcp2 = socket.socket(socket.AF\_INET, socket.SOCK\_STREAM)
\# 在绑定前调用setsockopt让套接字允许地址重用
tcp1.setsockopt(socket.SOL\_SOCKET, socket.SO\_REUSEADDR, 1)
tcp2.setsockopt(socket.SOL\_SOCKET, socket.SO\_REUSEADDR, 1)
\# 接下来两个套接字都也可以绑定到同一个端口上
tcp1.bind(('0.0.0.0', 12345))
tcp2.bind(('0.0.0.0', 12345))
```

```
 import socket
s=socket.socket()

a=s.getsockopt(socket.SOL\_SOCKET,socket.SO\_REUSEADDR)#获取套接字内容
s.setsockopt(socket.SOL\_SOCKET,socket.SO\_REUSEADDR,1)#设置套接字 1为重用 0为不可用
b=s.getsockopt(socket.SOL\_SOCKET,socket.SO\_REUSEADDR)
print(a,b)
```

  

# 案例6 获取网络时间

### 原理

 向NTP服务器发送UDP协议的 '\\x1b' + 47\*'\\0' 

                服务器返回时间秒数，从1970开始计算

### 第三方库 ntplib

 ntplib 库可以利用 ntp服务器，获取网络时间

### 实现

import ntplib 

ntp\_client = ntplib.NTPClient() 

response = ntp\_client.request('pool.ntp.org') 

print(response)

```
 import ntplib
import time

ntp\_client=ntplib.NTPClient()
response=ntp\_client.request('pool.ntp.org')
print(response)#返回的是一个对象
print(response.tx\_time)#获取到的时候就从1970年开始的 需要使用time模块进行转换
print(time.ctime(response.tx\_time)) #使用time模块 进行转换
```

也可以直接使用time模块获取

```
 import time
print(time.strftime("%Y-%m-%d %H:%M:%S", time.localtime()))
```
