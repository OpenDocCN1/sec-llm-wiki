案例1 获取设备名和IPv4地址

打印设备名称

使用 socket.gethostname()

获取本地设备的ip地址

使用 socket.gethostbyname()

获取原理：读取hostname对应 hosts文件中的ip映射（不准确）

准确的获取ip地址：

                利用UDP协议来实现的，生成一个UDP包，把自己的IP放到UDP协议头中，然后从UDP包中获取本地IP。

 s = socket.socket(socket.AF_INET,socket.SOCK_DGRAM)
 s.connect(('8.8.8.8',80))
 ip = s.getsockname()[0]

完整案例：

 import socket
 #获取设备名
 print(socket.gethostname())
 #获取本地的IP地址 通过hosts文件中获取一般不准确
 print(socket.gethostbyname('YUAN-1272'))
 #正确的获取IP地址
 s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM)
 s.connect(('8.8.8.8',80))
 ip=s.getsockname()[0]
 print(ip)

案例2 通过指定端口和协议找到服务名称

原理

如果想要指定端口所运行的服务，可以使用socket.getservbyport()函数获得。传入端口，和协议（tcp、udp）

实现

socket.getservbyport(port,protocol)

 import socket
 
 s=socket.getservbyname('http','tcp')#获取指定端口
 a=socket.getservbyport(80,'tcp')#获取指定端口名称
 print(s,a)
 #循环检测端口 可以检测udp tcp端口
 for port in range(0,65536):
    try:
        b = socket.getservbyport(port, 'udp')
        print('udp:'+str(port)+b)
    except:
        pass


案例3 底层相关函数

IPv4地址转换格式

使用底层网络函数时，有时普通字符串形式的IP地址并不有用，需要转换打包32位二进制格式。

函数

inet_aton 转换为二进制

inet_ntoa 转换为字符串格式 例如：127.0.0.1

 import socket
 s=socket.socket()
 ip='192.168.1.106'
 ip_1=socket.inet_aton(ip)#将ip转换为二进制
 print(ip_1)
 ip_2=socket.inet_ntoa(ip_1)#将ip_1转换为字符串格式
 print(ip_2)

拓展

转换16进制import binasciibinascii.hexlify()

 import binascii
 a=binascii.hexlify(ip_1)#将bytes转换成十六进制
 print(a)

主机字节序与网络字节序转换格式

使用底层网络时，需要处理底层数据。需要把主机操作系统发出的数据格式转换为网络格式。或者逆向转换

函数

ntohlhlton其中n代表网络，h代表主机，l代表长整型 32位，s代表短整型16位

 import socket
 s=socket.socket()
 a=socket.htonl(0x01)#主机字节序转网络字节序 0x01为整型
 print(a)
 b=socket.ntohl(a)#网络字节序转主机字节序
 print(b)
