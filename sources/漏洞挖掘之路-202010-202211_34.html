套字节介绍

什么是套接字

    计算机网络数据结构

分类：

套接字地址家族

1 AF_UNIX

2 AF_NETLINK 进行用户级别和内核级别代码之间的IPC

3 AF_INET         基于网络的套接字 ipv4

4 AF_INET6       基于网络的套接字 ipv6

创建TCP服务端

tcp服务端原理

创建服务端套接字(server_socket)绑定套接字地址(ip,port)等待连接,连接成功后,新建与连接相关的套接字(client_socket)

tcp服务端实现

1 新建套接字

socket.socket()

2 绑定地址

server_socket.bind((ip,port))

3 等待连接

server_socket.listen(num)

4 循环等待连接

client_socket,addr=server_socket.accept()

5 通信

接受数据 data=client_socket.recv(1024) 发送数据 client_socket.send('hello')

6 关闭套接字

客户端关闭 client_socket.close()

服务端关闭 server_socket.close()

 import socket
 
 server_socket=socket.socket()
 
 addr='192.168.1.113'
 port=5555
 server_socket.bind((addr,port))
 server_socket.listen(5)
 
 while True:
    client_socket, addr = server_socket.accept()
    print(1)
    while True:
        data = client_socket.recv(1024)
        # a=input('输入:')
        # client_socket.send(bytes(a,encoding='utf-8'))
        print(data)
        # client_socket.close()
 
 
 
 
 
 server_socket.close()

创建UDP服务端

UDP服务端原理

UDP是不需要连接,直接等待发送过来的数据即可.

UDP服务端实现

1 创建UDP套接字

2 绑定服务器套接字

3 服务端无限循环,等待接收,执行发送

4 关闭套接字

 import socket
 
 s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM)
 s.bind(('192.168.1.113',5001))
 
 while True:
    data,addr=s.recvfrom(1024)
    print(data,addr)

创建UDP客户端

UDP客户端原理

直接发送数据包到指定位置

UDP客户端实现

1 创建UDP套接字

2 循环,发送数据(sendto()),接收数据((recvfrom()))

3 关闭套接字

 import socket
 s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM)
 
 while True:
    send_data = input('>')
    s.sendto(bytes(send_data,encoding='utf-8'),('192.168.1.113',5001))
 
 
 
 s.close()
