### 套字节介绍

##### 什么是套接字

    计算机网络数据结构

起源:

分类：

                                AF\_INET

##### 套接字地址家族

1 AF\_UNIX 

2 AF\_NETLINK 进行用户级别和内核级别代码之间的IPC

3 AF\_INET         基于网络的套接字 ipv4 

4 AF\_INET6       基于网络的套接字 ipv6

# 创建TCP服务端

### tcp服务端原理

 创建服务端套接字(server\_socket)绑定套接字地址(ip,port)等待连接,连接成功后,新建与连接相关的套接字(client\_socket)

### tcp服务端实现

##### 1 新建套接字

 socket.socket()

##### 2 绑定地址

 server\_socket.bind((ip,port))

##### 3 等待连接

 server\_socket.listen(num)

##### 4 循环等待连接

 client\_socket,addr=server\_socket.accept()

##### 5 通信

 接受数据 data=client\_socket.recv(1024) 发送数据 client\_socket.send('hello')

##### 6 关闭套接字

客户端关闭 client\_socket.close() 

服务端关闭 server\_socket.close()

```
 import socket

server\_socket=socket.socket()

addr='192.168.1.113'
port=5555
server\_socket.bind((addr,port))
server\_socket.listen(5)

while True:
   client\_socket, addr = server\_socket.accept()
   print(1)
   while True:
       data = client\_socket.recv(1024)
       # a=input('输入:')
       # client\_socket.send(bytes(a,encoding='utf-8'))
       print(data)
       # client\_socket.close()

server\_socket.close()
```

  

# 创建TCP客户端

##### 1 创建tcp套接字

##### 2 连接服务器

##### 3 通信

# TCP端口扫描器编写

### 原理

 TCP客户端连接服端某一端口,如果端口开放,正常返回.如果端口关闭,那么抛出异常.

### 实现

1 创建TCP套接字 

2 遍历端口,发送连接请求 

3 异常判断 输出内容

拓展

 设置超时

```
settimeout(0.5)#设置超时时间为0.5秒
```

  

```
 import socket

ip='192.168.1.113'
for port in range(0,65536):
   try:
       client\_socket = socket.socket()
       client\_socket.connect((ip, port))
       print('连接成功,端口号为:'+str(port))
       client\_socket.close()

   except:
       print('端口不能连接'+str(port))
       client\_socket.close()
       pass
```

# 创建UDP服务端

### UDP服务端原理

 UDP是不需要连接,直接等待发送过来的数据即可.

### UDP服务端实现

1 创建UDP套接字 

2 绑定服务器套接字 

3 服务端无限循环,等待接收,执行发送 

4 关闭套接字

```
 import socket

s=socket.socket(socket.AF\_INET,socket.SOCK\_DGRAM)
s.bind(('192.168.1.113',5001))

while True:
   data,addr=s.recvfrom(1024)
   print(data,addr)
```

# 创建UDP客户端

### UDP客户端原理

 直接发送数据包到指定位置

### UDP客户端实现

1 创建UDP套接字 

2 循环,发送数据(sendto()),接收数据((recvfrom())) 

3 关闭套接字

```
 import socket
s=socket.socket(socket.AF\_INET,socket.SOCK\_DGRAM)

while True:
   send\_data = input('>')
   s.sendto(bytes(send\_data,encoding='utf-8'),('192.168.1.113',5001))

s.close()
```
