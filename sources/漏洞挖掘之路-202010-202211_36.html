多线程介绍

为什么需要多线程？

计算机程序最初是一个顺序序列来执行，但是某些步骤互不影响，从实际上可以同时执行，但是计算机最初不支持同时运行。

什么是多线程？

本质上多线程是异步的，需要多个并发活动，每一个活动的处理顺序都是随机的。每个活动执行特定任务。

### 进程和线程区分

1、通俗地说，进程就是一个运行中的程序。

                2、多线程-进程->主线程->多线程

同一进程下的，进程共享同一个数据空间。

单核CPU同一时间内只能执行一个线程，通过时间片来划分执行的线程。

多线程编程

threading.Thread直接在线程中运行函数

使用方法 threading.Thread(target=func,args=(a,b)                                 使用 start()启动线程

简单的例子：

 import threading
 
 def pr1():
    print('程序启动成功！')
    print('-----------')
    print('--1、新建 --')
    print('-----------')
 
 t1=threading.Thread(target=pr1)
 t1.start()
 
 
 def pr2(x,y):
    print(x+y)
 
 t2=threading.Thread(target=pr2,args=((1,2)))
 t2.start()

线程间通信

通信原理

使用threading模块中的Event对象， Event对象，Event实例管理着一个标志，通过set()方法会将它重置为false,使用wait()方法会使当前线程阻塞至标志位true。

具体实现

event = threading.Event() 线程类继承

在类的run方法中 编写暂停

 import threading
 import time
 
 class MythreadA(threading.Thread):
    def run(self):
        print(self.name + ' : '+ 'hello ')
        time.sleep(1)
        event.set()
        time.sleep(1)
        event.wait()
        print(self.name+'1')
        event.clear()
        time.sleep(1)
        event.set()
 
 
 class MythreadB(threading.Thread):
    def run(self):
        event.wait()
        print(self.name + ' : ' + 'hi ')
        event.clear()
        time.sleep(1)
        event.set()
        time.sleep(1)
        event.wait()
        print(self.name+'2')
        event.clear()
 
 
 event=threading.Event()
 t1=MythreadA()
 t1.name='BO'
 t2=MythreadB()
 t2.name='TT'
 t1.start()
 t2.start()

多线程缺陷

Python 中的多线程原理

Python解释器使用了内部的全局解释器锁定（GIL），在任意指定的时刻只允许单个线程执行，并且现在Python程序只能在一个处理器上运行。而现代CPU都已经是多核，但是Python程序无法使用。

Python中多进程介绍

使用Python的多进程模块可以将工具分配给不受锁定机制现在的单独子进程。

                使用multiprocessing模块 类似于threading


multiprocessing模块使用

多进程创建

1、直接初始化 调用 Process

 import multiprocessing
 
 def test(a,b):
    print(a,b)
 
 
 if __name__ == "__main__":
    m1 = multiprocessing.Process(target=test, args=('hello', 'word'))
    m1.start()


2、直接继承 覆写run

 import multiprocessing
 
 class M1(multiprocessing.Process):
    def run(self):
        print('hello word ')
 
 if __name__ == '__main__':
    m1 = M1()
    m1.start()



高级多进程模块

subprocess模块介绍

用于创建新进程，并获取它的输入、输出及错误信息。

subprocess模块中的创建方法

call()

创建新进程运行程序，输入和输出绑定在父进程，返回新进程的退出码

check_all()

创建新进程运行程序，输入和输出绑定在父进程，退出码0正常返回，否则异常

getstatusoutput()

创建新进程运行程序，返回新进程退出码和输出（元祖）

getoutput()

创建新进程运行程序，返回新进程输出（字符串）

check_output()

创建新进程运行程序，返回新进程输出（bytesarray）
