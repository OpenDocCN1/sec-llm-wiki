正则表达式介绍

什么是正则表达式？

Ragular Expression 简写 regex 或 re 正则表达式是使用单个字符串来描述、匹配一系列 符合某个句法规则的字符串。 案例：目前要删除电子邮箱中 某些包含敏感信息的邮件。 主要用于：快速搜索、替换或验证具有特殊形式或格式的文本。

Python re正则函数

正则搜索函数

1、re.match(pattem,string[,flags])

从字符串第一个字符开始匹配，如果匹配成功返回MatchObject对象实例，否则返回None 案例：

 import re
 
 s='Life is short'
 a=re.match('is',s)
 b=re.match('Life',s)
 print(a)
 print(b)


2、re.search(pattern,string[,flags])

从字符串中搜索符合正则表达式的内容。如果查找到则返回MatchObject对象实例，否则返回None。 案例：

 import re
 
 s='Life is short'
 a=re.search('is',s)
 print(type(a))
 print(a)
3、re.findall(pattern,string[,flags])

从字符串中查找到符合正则表达式的所有内容，并返回结果列表。如果正则表达式中使用了组()，则返回元组。 案例：

 import re
 s='Life is short'
 a=re.findall('\w{1,10}',s)
 print(type(a))
 print(a)
flags参数设定

1、re.I 忽略大小写

 import re
 s='AaBbCcDd dest port no yes I am is'
 a=re.findall('\w{1,10}',s,flags=re.I)
 print(a)

2、re.L 根据本地设置而更改\w.\W.\b.\B.\s 以及 \S 的匹配内容 3、re.M 多行匹配 4、re.S 使"."元字符也匹配换行符 5、re.U 匹配Unicode字符 6、re.X 忽略pattern中的空格，并且可以使用"#"注释 案例： s = "Life is short" re.match('l.+',s,re.l)

正则替换函数

1、re.sub(pattern,rep1,string[,count])
2、re.subn(pattern,rep1,string[,count])

其中pattern为正则表达式，rep1替换成的内容,string进行替换的字符串，count可选参数 最大替换次数。

案例：
 import re
 s='AaBbCcDd dest port no yes I am is dest'
 a=re.sub('dest','is',s)
 print(a)
 b=re.subn('dest','is',s)
 print(b)

正则表达式对象

RegexObject介绍

re模块中有compile函数，可以将正则表达式编译成RegexObject对象实例，然后通过实例对象调用方法，对字符串进行操作。 使用编译好的实例对象，可以提高处理于匹配的速度。

对象方法

注意：用 re.compile(pattern[,flags])生成实例对象。 re.l match(string[,pos[,endpos]]) search(string[,posl[,endpos]]) findall(string[,post[,endpos]]) sub(rep1,string[,count=0]) subn(rep1,string[,count=0]) split(string[,maxsplit=0])

案例演示

s = 'abc bde ddd ie iq ie qi qu'

 import re
 
 s='abc bde ddd ie iq ie qi qu'
 a=re.compile('\w{1,5}')
 b=a.findall(s)
 print(b)


正则分组基础

### 分组概念

在正则表达式中使用组，可以将正则表达式分解成多个不同的组成部分。在完成匹配或者搜索后，可以使用分组编号访问不同部分匹配的内容。 使用一对 圆括号"()" 表示位于其中的内容属于一个分组。 例如：(abc)+ 可以匹配 abc abcabc abcabcabc 等多个abc重复的情况。

分组案例

匹配电话号码（区号+号码） 返回元祖

 import re
 
 s = "Iphone number:010-1234566"
 r=re.compile('(\w{3})-(\w{7})')
 a=r.search(s)
 print(a)
 print(a.group(0))
 print(a.group(1))
 print(a.group(2))
 print(a.groups())


分组名称设置 (?P<分组名称>)

 s = "Iphone number:010-1234566"
 r=re.compile('(?P<aaa111>\w{3})-(?P<aaa110>\w{7})')
 a=r.search(s)
 print(a)
 print(a.group('aaa111'))
 print(a.group('aaa110'))
