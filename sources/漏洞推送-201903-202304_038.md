1.简介

TZ是一个由golang开发跨全平台，集主机发现，漏洞扫描，漏洞利用为一体的内网渗透工具。

配合cs插件生态，目标是为了做到内网渗透 all in one，以及常见漏洞检测利用的all in。

1.2.公共参数介绍：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
 -c string               c  -ip string               ip list  -p string               PlusName  -port string               port  -t int               thread (default 8)
```

  

\-ip 目标ip，Examples：192.168.3.1或者192.168.3.1/24

\-p 调用插件名称

\-t 线程数，默认为8

\-port 目标端口，部分插件无此参数

![](../Images/bc29d1fd46a8a70f253b607527b8ebb0.png)

  

点击frp，点击以后会卡住是正常现象，因为此时在上传frp客户端

![](../Images/1e65eee5ee60ed3a27292307970b0e19.png)

  

填写frp服务端ip，以及端口

![](../Images/fa5a956a48197715b9edfb6e8e370b3c.png)

  

会使用frp启动socks5代理，将内网代理出来。

![](../Images/44b4fd5f63e060dfc6a5eb644469e307.png)

  

通过TZ启动的frp客户端，连接参数使用AES强加密并使用随机密钥，避免服务器连接信息泄露
