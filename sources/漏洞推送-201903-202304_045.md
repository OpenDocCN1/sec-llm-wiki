用一个安卓apk的题目来简单学习一个frida的使用。

反编译一下这个apk，我使用的jadx

我们通过搜索 错误，来定位到逻辑代码

![](../Images/456f0376c37a53c79a98b52b55df77e9.png)

最重要的函数是MainActivity.this.ccc.cc他接受了两个参数，一个是我们输入的文本，一个是内部生成的 ，至于怎么生成的我们不用关心，Frida了面前无秘密。

  

接下来安装一下frida

  

使用pip安装

pip3 install frida

pip3 install frida-tools

安装完成以后验证

  

![](../Images/c4124ed99f083c40a35fa8583c141f8b.png)

  

然后下载frida的服务端

https://github.com/frida/frida/releases

  

  

在adb里面执行getprop ro.product.cpu.abi,然后根据cpu的指令集下载服务端文件

  

![](../Images/422e2dbd6edfa6d63bef043611d08b1d.png)

我是mumu的模拟器，我下载的是

frida-server-14.1.3-android-x86.xz

  

 然后把文件复制到安卓模拟器的/data/local/tmp/ 目录，chmod u+x frida添加执行权限

  

启动服务端

![](../Images/d664c61495813c04e3182e69b246198d.png)

  

测试，如果能正确显示安卓的进程，就是已经安装好了

![](../Images/a85feb9f74e80ecdbfcafaa7f76bc659.png)
