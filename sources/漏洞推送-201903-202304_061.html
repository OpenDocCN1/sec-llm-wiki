安全从业者，最应该学习的第一门开发语言是什么？

最近，有不少粉丝在后台留言问我，有大三大四学生的，还有一些想转型做Java的：
毕业之后，应该找什么工作？
现在是不是该系统学一些编程之类的，听说薪资很高？
号主您是学Java的吗？是自学的吗？我现在学还来得及吗？
 
字里行间，能看出他们深深的焦虑，而且大多数人对今年的就业形势很悲观，觉得：

  • 赶上疫情，很多公司裁员、缩招，找工作肯定很难；

  • 对于学生，竞争人数指数级增加，今年毕业生又增加了40万，达到了874万。

 
我不得不说，越是逆境，越不能自乱阵脚，自我放弃，反而需要明确目标，更加努力学习。不然潮水退去，裸泳的就只有自己，更是悲哀。
 
虽说疫情导致很多公司倒闭、裁员，但像腾讯、抖音、淘宝或者线上教育的互联网公司，在疫情期间用户暴增。公司赚钱了，业务增加了，反而是非常缺人。
 
这不，最近和粉丝聊天的时候，就发现一位读者，从产品经理转行到Java开发，不到6个月的学习，就拿到了快手Offer，薪资直接翻倍，真的是让人羡慕 。
 
就在开头问的，现在学习Java来得及吗？
 
我只能说，选择Java，最好的时机是10年前，其次是现在。我特意在拉勾上搜索了下，在大厂，Java工程师应届生薪资轻松达到 15k-25k，工作经验有 3 年的就能达到 35k-50k，这薪资水平绝对是碾压了身边 90% 的小伙伴。
                      
有人会说，成，我就自学吧。作为过来人，我真心不推荐大家自学，耗时耗力不说，学到的知识还非常不体系化，最主要的是，没有真实项目支撑你把概念和知识点串联起来，更不能去丰富你的简历。说白了，你这一切的努力，都是为了让你的简历更加漂亮。
 
如果你想学Java，并且学完能找到一份10K以上的工作，我这里推荐给你 拉勾教育推出的 【0基础 Java 就业训练营】。很简单的3点：

1、0基础，无门槛，跟着学就对了；
2、拿拉勾作为实战项目，前后端、功能、数据，手把手带你搭建一款真实的在线教育平台；
3、学完，拉勾直接内推公司，跳过HR海选。
