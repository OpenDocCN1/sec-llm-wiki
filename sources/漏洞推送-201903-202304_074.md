漏洞产生的主要原因就是think框架应该是通过/，来分割路由，但是因为没有考虑\\的情况，导致可以通过路由传入think\\App这样的任意类， 然后再反射执行invokeFunction方法实现任意函数的执行。

  

官方的修复方法，也就是对路由里面的特殊字符串进行过滤。

  

漏洞修复方案：

  

Thinkphp v5.0.x补丁:

  

library/think/App.php

$controller = strip\_tags($result\[1\] ?: $config\['default\_controller'\]);后添加

```


```


if (!preg\_match('/^\[A-Za-z\](\\w)\*$/', $controller)) {
```


```

Thinkphp v5.1.x补丁:

library/think/route/dispatch/Module.php

$controller       = strip\_tags($result\[1\] ?: $this->rule->getConfig('default\_controller'));

替换为

```


```


$controller = strip\_tags($result\[1\] ?: $this->rule->getConfig('default\_controller'));
```


```
