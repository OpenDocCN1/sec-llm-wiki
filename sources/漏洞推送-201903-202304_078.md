以php7.2为例

  

1.首先下载安装VS2017，安装C++扩展

![](../Images/95c6fb6be207966c33162cf87c40c950.png)

  

2.下载php源代码

  

https://windows.php.net/download/

![](../Images/158d05c265fd04e22f59b6d94e82e650.png)

  

3.clone php dev sdk

```


```
git clone https://github.com/Microsoft/php-sdk-binary-tools
```


```

  

4.环境配置

![](../Images/c688c2682567a12af656887ffb7a188c.png)

执行命令 phpsdk\_buildtree phpdev 创建目录结构

  

将php源码放入下图目录中

![](../Images/b474fa8877f354b1779e958eb8211c66.png)

 下载依赖包 windows.php.net - /downloads/php-sdk/deps/vc15/x64/

![](../Images/1eebbc7d83de221f1b3a8fd9472c2751.png)

解压放入deps目录中

![](../Images/ca7d63ff9ae5b282f385084a26fed8b4.png)

  

如果你网络环境比较好的话，也可以使用phpsdk\_deps -u 来在线安装

5.编译php

在phpsdk-vc15-x64.bat 中启动cmd

![](../Images/8b57fb29cac3712cb578b275cb8bc9e1.png)

cd 进入phpdev中的php源码目录

执行

buildconf

再执行

configure --help

 继续执行

configure --enable-debug --enable-phpdbg

 编译

nmake

 编译的php文件在源码目录下

![](../Images/17a50cea03cee5a1c20884c55401babe.png)

  

在目录下创建php文件

![](../Images/517668c5dce3c29eb3e232deef5e1d5c.png)

php源文件下断点调试

![](../Images/57356e23d1a0fe17d4950326feb813a7.png)

  

使用编译出来的php.exe 运行 poc.php

![](../Images/0f91db610cf6bce31a8e1d92540112e8.png)

vs-调试-附加到进程，附加到php.exe

  

![](../Images/035b4f5d63091fcb5d3382db8c8fd189.png)

  

附加成功以后，在php的cmd里面按回车，继续执行程序。
