在使用cs的过程中可能需要在某些目标上线以后马上进行持久化或者进行控制,但是我们又不可能时刻在电脑前盯着,这个时候就需要实现一个上线提醒的功能,让cs在有主机上线的时候自动给我们推送一条消息方便,我们进行处理


0x1 安装与配置CS


以ububtu的服务器为例


安装jdk


sudo apt-get install openjdk-8-jdk



java -version 检测是否安装成功



下载cs,上传一份到服务器上

链接: https://pan.baidu.com/s/17GMsIoHNfTI5K3KoYLlRyQ 提取码: nni8


解压以后

vim ./teamserver


vim ./teamserver



修改服务端口,避免被爆破


启动teamserver服务

./teamserver 公网ip password &


启动以后,在本地连接服务器测试


Windows下运行




填上刚才文件里面修改的端口,命令行启动服务的时候填的密码,用户名随意


进入主页面,表示连接成功
