0x1  

    在实际的渗透测试的过程中，攻击者为了隐藏自己，一般会在vps下进行扫描，攻击等等操作。


    但是在linux中软件工具依赖关系比较复杂，以wpscan为例，现在百度搜索Ubuntu安装wpscan也有一大把文章。但是你按照网络上的教程一步一步的安装各种依赖，不仅费时间，而且最后wpscan虽然是安装好了，但是一运行就各种报错，无法正常使用，不要问我是怎么知道的。

    

    这个时候才知道kali下各个工具的方便了，但是一般各种vps的主机商都是不提供kali的镜像的，但是Ubuntu的系统的话，可以通过下面的方式，来安装kali下的各种工具。


0x2


vps：美国 Ubuntu 18.04


添加kali源

apt-key adv --keyserver pool.sks-keyservers.net --recv-keys ED444FF07D8D0BF6echo -e "#Kali linux repositories | Added by Katoolin\ndeb http://http.kali.org/kali kali-rolling main contrib non-free" >> /etc/apt/sources.list


0x3


更新源

apt-get update

    

0x4


添加源成功后，安装wpscan测试


apt-get install wpscan


扫描测试，成功运行
