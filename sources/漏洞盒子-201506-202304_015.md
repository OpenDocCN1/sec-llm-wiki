# 关于「盒子星球白帽大会」延期举办的通知

各位白帽和业内朋友们：

鉴于当前深圳疫情防控形势趋于严峻，以及政策等因素影响，出于参会人员健康安全和以及相关防疫管理部门要求的不可抗力因素，原定于2022年10月22日在深圳举办的「盒子星球白帽大会」将**延期至2022年11月5日**举办。  

![](../Images/beda6cbb71e9115cc0b60189b7a939c9.png "banner_800x400-.png")

感谢各位对「盒子星球白帽大会」的理解与支持！因延期带来的诸多不便，我们深表歉意！

  

我们始终将观众及合作伙伴的身体健康与生命安全置于首位。我们将严格按照国家对疫情防控工作的要求，全力做好会议期间防疫工作，确保所有参与者的健康与安全，竭诚提供更优质的服务和更好的参与体验，坚信在大家的共同努力下，一定能带来一场**安全、高效的白帽盛会**！
