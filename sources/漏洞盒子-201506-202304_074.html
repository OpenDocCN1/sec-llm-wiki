JavaScript在网络安全中的身影

议题嘉宾：斗象科技高级安全研究员 高佳


随着前后端分离技术的发展与广泛应用，前端承担越来越重要的作用。JavaScript作为前端的核心语言，在安全领域的身影也以从起初的仅在XSS中可以看到，变化为如今在api接口泄露、加密绕过、任意登录等一系列漏洞也频频现身。本次议题将结合审核过程中遇到的经典漏洞案例，向大家展示在漏洞挖掘实战过程中如何搜集筛选隐匿各处的js文件中的有效信息，并一举收获高额漏洞赏金。


邮件钓鱼之macro

议题嘉宾：平安集团资深安全研究员 陈栋


红蓝对抗中钓鱼攻击是能最直接获取权限的一种方式，而使用macro来完成命令的执行在钓鱼攻击中是非常常见的一种手段。议题将会介绍在红蓝对抗中关于macro的一些攻防手段。


网络攻防的「基石」-软件逆向

议题嘉宾：三零卫士木星安全实验室 徐智鑫


带领大家了解软件逆向工程在网络安全中的应用，为什么说网络攻防的基石是软件逆向工程，以及如何学习软件逆向工程。


Weblogic IIOP NAT 网络绕过

议题嘉宾：白帽汇安全研究员 r4v3zn


默认使用 Weblogic IIOP 协议进行发起序列化攻击时会出现 NAT 网络问题，本议题主要从多个层面进行分析出现 NAT 网络问题出现的成因；解决 NAT 网络问题的多种方案，如通过 java agent、Hook、动态字节码技术进行解决 NAT 网络以及使用这些技术时出现的问题。以及最后的成品解决方案和利用工具。


猖獗的网络犯罪及相关分析

议题嘉宾：FreeBuf年度作者 辛巴


针对网络犯罪我们要了解他们的犯罪手段，特别是对其中最为猖獗的诈骗，在诈骗嫌疑人日益增多，手段推陈出新的今天，了解他们的诈骗手段，捕捉他们实施犯罪的程序样本。以我们跟进的裸聊诈骗为例，确定了全国的80%相关的裸聊诈骗案件为同一个诈骗团伙所实施，且所使用的木马app程序有专门的人员进行二次开发维护，除了裸聊诈骗，还涉及到虚拟币投资杀猪盘，小额贷款诈骗等多个该团伙运营的诈骗套路。
