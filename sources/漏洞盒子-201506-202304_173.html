1. 漏洞概述

官方公告：

Problem :It is possible to perform a RCE attack with a malicious Content-Type value. If the Content-Type value isn't valid an exception is thrown which is then used to display an error message to a user.改漏洞是利用构造Content-Type出发报错并来实现的任意代码执行。

官方公告中还提到了Jakarta这个Struts2默认的上传组件。

If you are using Jakarta based file upload Multipart parser, upgrade to Apache Struts version 2.3.32 or 2.5.10.1. You can also switch to a different implementation of the Multipart parser.

官方公告网址：https://cwiki.apache.org/confluence/display/WW/S2-045

2.Content-Type中“multipart/form-data”的猫腻

触发该漏洞构造的Content-Type头部必须要存在“multipart/form-data”这个部分，原因是Strus2并没有自己的上传请求解析器，Struts2会调用其他解析器，将HTTP请求中的表单域解析出来。

而默认的解析器就是Jakarta。

4.修复措施

1.受影响用户可升级版本至Apache Struts 2.3.32 或 Apache Struts 2.5.10.1以消除漏洞影响。

2.修改default.properties中的struts.multipart.parser为cos或pell(需相应包支持)。

3.参考官方版本修复方式:

2.5.10.1：https://github.com/apache/struts/commit/b06dd50af2a3319dd896bf5c2f4972d2b772cf2b

2.3.32：https://github.com/apache/struts/commit/352306493971e7d5a756d61780d57a76eb1f519a
