在2014年美国黑帽大会上，柏林SRLabs的安全研究人员JakobLell和独立安全研究人员Karsten Nohl展示了他们称为“BadUSB”(按照BadBIOS命名)的攻击方法，这种攻击方法让USB安全和几乎所有和USB相关的设备(包括具有USB端口的电脑)都陷入相当危险的状态。 

![](../Images/28452e1be95d17a53d243120d5edb8f4.png)

Teensy USB开发板   

Teensy是一个非常小的完整的基于USB接口的单片机开发系统，能够实现多种类型的项目。所有的编程是通过USB端口。在没有特殊的程序要求下，只有一个标准的Mini-B USB电缆和PC或Macintosh电脑的USB端口。

主要特点：

> 可以是任何类型设备的USB
> 
> AVR处理器，16 MHz
> 
> 单个按键编程
> 
> 易于使用的Teensy Loader应用程序
> 
> 免费软件开发工具
> 
> 兼容Mac OS X，Linux和Windows
> 
> 小尺寸,许多项目的完美支持
> 
> 使用标签面包板
> 
> 非常低的成本

所需工具：

> 1.Teensy ++ 2.0 
> 
> 2.Teensyduino插件
> 
> 3.arduino

教程开始

下载安装 ARDUINO 1.6.5    https://www.arduino.cc/en/Main/Software/

![](../Images/5572287f7d7c45fec1cf9108dad8d2b0.png)

 选择对应的平台下载 

![](../Images/b4a604052c3baa0dc5a846ec26f4a360.png)

我使用的是Kali linux 系统 下载Linux 64 压缩包解压 进入arduino目录 运行 

```
./arduino
```

![](../Images/09319f64d12397d90bece4c567418614.png)

终端运行打开之后,但需安装Teensyduino插件  下载地址 http://www.pjrc.com/teensy/td\_download.html

选择下载 Linux installer 64

![](../Images/5d39c8da835c200a9ff7d6f53dd87f6a.png)

下载完成终端打开  teensyduino.64bit 进行安装 

```
./teensyduion.64bit
```

![](../Images/0c26fcfede097d8a4eabc3ee3ee0a3b7.png)

选择 arduino 安装目录> Next 

![](../Images/c9ebbd352eeb8e51e94a87249b50d38d.png)

选中 ALL >Next 

![](../Images/db69ca70c00ff13e5a0de7d8c49df849.png)

切换打开 arduino 

```
          选择菜单栏 Tools\>board:  > Teensy ++ 2.0
```

开发环境已经准备好了！

> ‍‍一旦感染，通过USB外设或其他途径，恶意代码可以隐藏在外设中，避免被系统清除   
> ‍‍只要USB控制器是可重复编程的，USB外设就不应该和他人共享
