# 斗象科技CEO袁劲松受邀出席金融信息安全保障与风险防范论坛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxODIzNzgwMw==&mid=2654056291&idx=1&sn=1e99aa35c492e9b137efd5a7588bc055&chksm=8c289167bb5f187122d58e632d41249f68c38b1e6551ab5fad0bec750dcf9f9484b873931711&scene=126&sessionid=1681312181#rd](http://mp.weixin.qq.com/s?__biz=MzIxODIzNzgwMw==&mid=2654056291&idx=1&sn=1e99aa35c492e9b137efd5a7588bc055&chksm=8c289167bb5f187122d58e632d41249f68c38b1e6551ab5fad0bec750dcf9f9484b873931711&scene=126&sessionid=1681312181#rd)

2017年6月29日，由中国银联和上海金融业联合会金融信息化专委会联合主办的第十一届上海金融服务实体经济论坛之金融信息安全保障与风险防范论坛如期召开。上海市十大“智慧工匠”企业代表，上海斗象科技CEO袁劲松先生受邀参加此次行业盛会，并发表了关于漏洞收集与管理体系的专题演讲。

![](../Images/7e5b2dc1f331c0dd8ecdec7eb9bd8973.png)

面对错综复杂的国内外形势以及经济转型带来的严峻挑战，为了更好地驱动金融服务科技创新，迎接全新的机遇和挑战，并促进业内交流、经验分享，论坛以“互联网+时代的金融信息安全保障与风险防范”为主题，围绕金融业对信息技术高度依赖的条件下，如何保障系统安全和数据中心运营的建设发展、金融行业大数据应用的安全等问题进行了广泛交流。

中国工商银行数据中心（上海）、中国银联、上海市信息安全评测中心及上海市信息安全行业协会的领导、专家们也受邀出席，分享了先进的安全管理方法与宝贵的实践经验。主要内容有：数据中心信息安全管理与实践、多中心高可用的金融数据中心架构设计与实践、自主可控的金融信息安全技术防护体系、金融行业重要信息系统安全评测与检查、“互联网+”时代的网络与金融信息安全等。

![](../Images/837ac8b9786c4a2d5b94d7826c9ea67e.png)上海斗象科技CEO袁劲松先生在论坛上发表了“金融行业如何建立可信赖的漏洞收集与管理体系”的专题演讲，近年来金融机构是网络攻击的重要目标，尤其各种漏洞、信息泄露、黑客攻击呈高发态势，在企业安全体系建设的生态中，如何建立可信的漏洞收集与管理体系，解决企业对于互联网漏洞的处置痛点，是企业需要思考的一个问题。

![](../Images/e7c9f627e5ccbef7490fdb42e62d2fbc.png)纵观国内外，Google、微软、阿里巴巴、腾讯等知名互联网公司都已建立起了各自的应急响应中心（SRC，Security Response Center），并在推出以后取得了良好的效果，对企业安全起到了巨大的协调和推动作用。广大企业可以把安全应急响应中心看成一种安全能力或者产品，由一个SRC服务商来为没有资源建设安全应急响应中心的企业整合资源提供服务。

  

斗象科技旗下的漏洞盒子（www.vulbox.com）既是国内领先的互联网安全众测服务平台，又是中立的企业SRC平台，现已拥有全球3万名安全专家与技术团队，开创了测试过程全透明的管理方式，让企业可以轻松掌握漏洞生命周期管理的主动权。漏洞盒子的安全应急响应小组7\*24监测互联网漏洞，并在威胁发生的第一时刻，向企业报告漏洞类型和危害，减少企业及社会损失。

作为国家互联网应急中心省级支撑单位，斗象科技将继续致力于为企业用户提供优质的网络安全解决方案，携手共迎全新的机遇和挑战。
