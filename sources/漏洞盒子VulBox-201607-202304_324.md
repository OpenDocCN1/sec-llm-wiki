# 漏洞盒子助力上海市中小学「信息安全」主题开放日 | 漏洞盒子进校园

4月15、16日，上海市中小学生“信息安全开放日”成功地在上海市商业会计学校举行。本次开放日活动是今年“网络安全进校园”系列活动的首场，之后将在全市各中小学继续开展，通过对青少年的网络信息安全教育和宣传活动，以丰富多元的活动形式推广网络安全教育，提升广大青少年的网络安全防范意识和能力，培养中国互联网未来健康力量。  

“网络安全进校园”系列活动在市教委、市网信办、市经信委、团市委、通管局共同指导展开，此次活动由上海市商业会计学校主办，上海市信息安全行业协会、首席安全官（CSO）俱乐部、斗象科技、安致信息、易念科技共同协办。

![](../Images/53b4a9f1fcb0e821cfd7de70016da233.png)

本次开放日活动设立了多个环节，信息知识教育与游戏互动相穿插，让家长和孩子在欢乐的环境中学习到信息安全知识：信安专业学生精心编排的情景剧表演《三打白骨精》、漏洞盒子美女工程师的网络安全威胁演示、信息安全知识竞答游戏、免费发放的《网络安全亲子手册》等活动吸引众多家长围观。

![](../Images/1346d4ded469d98a502d00c618d65253.png)![](../Images/49aca707d39ea7f4112d66cacc4ff5ac.png)

在网络安全亲体验活动环节，漏洞盒子安全服务工程师程灿现场为大家演示WiFi劫持技术，直观展示公共WiFi所存在的网络安全隐患，提醒大家在公共场所使用Wifii热点需要谨慎。

![](../Images/a258f2e8b0e39ab8a86e997f40382bbd.png)![](../Images/49aca707d39ea7f4112d66cacc4ff5ac.png)  

现场学生积极参与线上知识竞猜活动赢取漏洞盒子提供的小礼品。

![](../Images/21b4c0f8c66e9c3e427c097c7663ef52.png)

![](../Images/49aca707d39ea7f4112d66cacc4ff5ac.png)  

上海商业会计学校信安专业学生编排信息安全版情景剧《三打白骨精》，巧妙穿插了各类手机信息安全泄漏情节。搞笑、有趣的故事情节让在场的学生和家长捧腹一笑的同时，也警示大家注意手机信息安全的隐患和不良后果。让中小学生了解网络和信息安全基本知识，加强网络安全意识，同时也有助于他们树立正确的信息安全伦理观。同时，也促使家长对孩子信息安全教育的重视度会有所提高，能够引导孩子正确使用网络。

![](../Images/53cc2beae7f4655456b493e7007c207d.png)

![](../Images/49aca707d39ea7f4112d66cacc4ff5ac.png)  

4月15日，是国家安全教育日。除了国土和军事领域，国家安全还包括了经济、文化、社会、科技、生态、网络空间等多个领域。网络信息安全作为网络空间安全的重要部分，也在逐渐被公众所重视。据中国互联网协会的调查报告显示，近一年时间，国内6.88亿网民因垃圾短信、诈骗信息、个人信息泄露等造成的经济损失估算就高达915亿元，诈骗的方式也逐渐从撒网式诈骗向精准诈骗升级，逐渐形成了分工精细、成规模的黑色产业链。而这背后，暴露了网民安全意识不强、上网习惯不佳、个人信息保护不利等问题。青少年作为未来网络空间的中坚和主体，针对他们的网络安全教育刻不容缓。

![](../Images/fbb1e162f08060a2119683a5f69bf63a.png)

【上海市信息安全行业协会秘书长王强为活动总结】

今时今日我们每个人都被互联网连接起来了，或许我们还没有对我们个人的信息安全保护有清楚的概念，可是我们在享受支付的便捷的痛就是我们那不经意之间的信息泄露让我们的信息就不会那么私人化，就有可能导致我们银行卡的余额被清零，信用卡被盗刷而背上巨额债务，因此信息成为社会发展的重要战略资源，信息安全问题也日益突显。对于广大青少年学生来说，他们生在网络时代，一出生便享用了网络带给我们的便捷，同样的他们也面对着相同的信息安全问题。如何引导和教育青少年提高自身信息安全防护的认识和能力，亟需引起关注。

漏洞盒子作为国内领先的互联网安全服务平台，肩负着社会信息安全教育的责任。漏洞盒子是国内首家链结安全专家资源与自有安全团队，通过再现真实环境进行漏洞挖掘，为企业用户提供高效、透明的互联网安全测试服务平台。
