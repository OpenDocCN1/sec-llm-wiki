# 斗象科技与360达成深度合作，承办「漏洞挖掘与源代码安全分论坛」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxODIzNzgwMw==&mid=2654055195&idx=1&sn=4c98ea47ff38d63dedbc0be492f3d735&chksm=8c28951fbb5f1c093a0b5dbcc8d63d7aac0246d9dae5c44f8538b3e2e39e9aed661a9bda0551&scene=126&sessionid=1681312277#rd](http://mp.weixin.qq.com/s?__biz=MzIxODIzNzgwMw==&mid=2654055195&idx=1&sn=4c98ea47ff38d63dedbc0be492f3d735&chksm=8c28951fbb5f1c093a0b5dbcc8d63d7aac0246d9dae5c44f8538b3e2e39e9aed661a9bda0551&scene=126&sessionid=1681312277#rd)

亚太地区最大规模、最专业的信息安全行业年度会议ISC 2016（China Internet Security Conference，中国互联网安全大会）将于2016年8月16日至8月17日在北京国家会议中心举办。

**斗象科技旗下媒体FreeBuf今年再次与360深度合作，承办ISC2016-漏洞挖掘与源代码安全分论坛。论坛探讨安全漏洞的自动挖掘技术与态势感知，探讨源代码安全问题在基础设施建设、企业安全管理等方面的影响及作用。**

**届时来自世界各地及国内的安全行业从业者、政府及企业安全负责人、安全厂商和研究组织的优秀白帽黑客将云集北京，将深入探讨全球信息安全最新发展趋势，分享最前沿安全技术研究成果及实践。

中国互联网安全大会始办于2013年，至今已是第四届。

首届中国互联网大会引发了大众对“互联网安全”前所未有的关注热情；2014 年美国首任国土安全部部长Tom Ridge，计算机病毒之父Fred Cohen等国内外业界顶级专家学者悉数到场。2015 ISC规模空前，总参会人数超过三万人，大会主题“数据驱动安全”已成为业界公认的安全理念和发展趋势。
