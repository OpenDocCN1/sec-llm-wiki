base64大家肯定都知道是什么，我们通常就拿它做一个简单的编码，进行传输等等。标准base64如下：

例如：字符串：aa11~~!!base64编码后：YWExMX5+ISE=

那么除了这样用，还可以进行怎样的操作呢？比如这样：

在这个编码后的base64字符串里添加一些特殊符号

--!@---YW<九月><$>Ex--|$也|MX--<5..%%...+<--|是@I>S-!|E--永-$$$%%远$$$$----的${^^^^^神~~~~....}{%^@^$&=

然后看到这些会不会说一句：这是什么鬼东西！

但是现在，我们知道这一串鬼画符是由上面的base64添加了一些特殊符号生成的，那么我们还能将其解码为字符串吗？

我们用不同的语言来尝试一下：

1、首先是php：

<?php$str='--!@---YW<#九月><$>Ex--|#$也|MX--<5..%%...+<--|是@I>S-!|E--永-$$$%%远$$$$----的${^^^^^神~~~~....}{%#^@#^$&=';echo base64_decode($str);?>

可以看到依然解码成功了，说明我们的PHP包容性极强，那么waf有没有可能是解码不了呢？


2、然后是python：

依旧来测试我们的鬼画符：

import base64leleyyds = base64.b64decode("--!@---YW<#九月><$>Ex--|#$也|MX--<5..%%...+<--|是@I>S-!|E--永-$$$%%远$$$$----的${^^^^^神~~~~....}{%#^@#^$&=")print(leleyyds.decode())

发现报错了。。字符串只能用ASCLL，那我们先把中文去掉：

import base64leleyyds = base64.b64decode("--!@---YW<#><$>Ex--|#$|MX--<5..%%...+<--|@I>S-!|E---$$$%%$$$$----${^^^^^~~~~....}{%#^@#^$&=")print(leleyyds.decode())

然后成功解析了

python的解析能力也是很强的！


3、最后是java：

尝试了下java不可以，但是查了一下java可以通过=来做隔断符,比如下面：

YWExMX5+ISE=YWExMX5+ISE=

解码后就是：

aa11~~!!aa11~~!!

那么比如我们将命令分割为两段或更多段:

命令：phpinfo();分割为两段:cGhwaQ==和bmZvKCk7

那么组合起来：

cGhwaQ==bmZvKCk7

java会将其解析成为phpinfo();命令，但是其他语言就可能解析不了，这在你写jsp免杀马的时候可以进行混淆。

所以当我们在绕waf的时候针对不同语言的站点，可以尝试添加这种混淆方式尝试一下。
