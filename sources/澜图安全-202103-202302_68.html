Docker安装需要python3.*和pip20.*

1、安装docker

sudo apt-get install docker.io


这里说明一下为什么使用docker.io，很多人都说docker.io是旧版本，docker-ce是新版本，其实不然，docker.io其实是由ubuntu团队进行维护的，docker-ce是由docker官方维护的社区版，由于ubuntu以前很长时间没有维护docker,所以停留在古老版本，但2020年6月以后就重新进行了维护，所以我们这里使用的ubuntu环境直接使用docker.io来安装，方便快捷，docker-ce需要好几步骤，很麻烦。


然后安装docker-compose

pip install docker-compose


2、Docker的基础命令：

docker search xxx 搜索docker库里的镜像名，可以关键字docker pull xxx 拉取这个镜像，需要全名docker images 查看所有已经拉取的镜像docker run --name -d -p 8080:80 xxx     这里的--name是给这个镜像取个名字（可以不写，会默认起一个名字）， -d 为后台运行 -p为把物理机端口映射到docker的端口上，左侧为物理机端口，右侧为docker端口。docker ps 查看当前启用的镜像docker stop xxx 关闭镜像，这里xxx为--name的名字。docker exec -it id号 /bin/bash  进入镜像内部，bash交互界面。

比如我们要找一个awvs工具。命令如下：

docker search awvs   寻找镜像docker pull awvs-13   下载这个镜像docker run --name awvs -d -p 10086:3443 awvs-13   因为awvs默认使用3443，所以我们把docker镜像的3443端口映射至物理机的10086端口，这样访问物理机的IP：10086就可以打开awvs的web界面了。

最后还有一个很重要的一点，需要设置开机自启！

systemctl list-unit-files | grep enable 查看是否开启自启systemctl enable docker.service 设置开机自启systemctl disable docker.service 关闭开机自启

docker run时候加上--restart=always是容器镜像开机自启。

如果run的时候没有加上，后面想加就docker container update --restart=always 容器名字或者id

不然的话，需要systemctl start docker来启动容器，而且有的会报错

重启无用，报错。

那么这种怎么解决呢？

是因为没有镜像源。

进入 /etc/docker，没有daemon.json文件就自己新建一个。

然后编辑下文件写上如下内容：

{ "registry-mirrors": ["https://registry.docker-cn.com"]}

如果拉取镜像太慢的话，把这个链接该为国内镜像源就可以了。

然后重启docker就行了：

systemctl restart docker.service
