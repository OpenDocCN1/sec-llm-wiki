前言


寒假期间，火炬木攻防实验室举办了一场面向21级新生的比赛。赛场选用CTFd平台，以下是平台搭建过程记录。


环境

硬件选用升腾C92小主机，其采用赛扬j1800双核双线程cpu，4gb ddr3 1600mhz内存，64gb msata硬盘。该机器多用于软路由方面，性能较差，但用于搭建平台还是足够的，且功耗非常低，日常待机仅十几瓦。


       系统环境为Ubuntu 20.04。


CTFd介绍


CTFd是一个开源的ctf训练平台，它提供了丰富的功能模块，管理者可以自由定制和直观地查看后台数据，最重要的是它可以被搭建在本地环境中。
官网：https://ctfd.io/

本地搭建过程


1、安装git
sudo apt install git


2、安装pip

sudo apt install python3-pip


3、安装Flask

ctfd是基于Flask框架打造的，因此需要先安装Flask框架。

sudo pip3 install Flask


4、下载CTFd

sudo git clone https://github.com/CTFd/CTFd.git


5、安装CTFd

下载完成后，来到CTFd文件夹目录，安装(中途可能会报错，重新执行命令即可)。

sudo ./prepare.sh


6、启动本地环境

sudo python3 serve.py

浏览器访问"http://127.0.0.1:4000/"即可打开平台，进行注册账号以及初始化设置即可正常运行。


内网穿透


由于家用宽带无公网ip，因此只好采取内网穿透的方式让本地环境能在公网访问。网上有很多内网映射工具，请自行尝试，这里采用了NATAPP。

如果是云服务器，只需要将其部署到公网端口就能通过公网对平台进行访问。



小结


在平台搭建的过程中也遇到了不少困难，如内网映射问题、过多请求导致崩溃问题，但最终还是一一克服了。比赛总体来说进行得较为顺利，而且有了这一次的经验，今后的比赛定能越办越好。
