![](../Images/f069e23a0fd6ce76c8051e1e54d51ecc.png)**0x00 Intro to IAST**  
  

交互式应用程序安全测试（IAST，Interactive Application Security Testing）是⼀种新兴的应用安全检测技术，它更关注代码本身存在的安全风险，可以识别如SQL 注入、命令执行、任意文件读取以及其他常见 Web 应用漏洞。

  

灵芝IAST 通过在WEB中间件（Tomcat, Jetty, WebLogic, etc.）上安装Agent，实时地监控和收集 Web 应用运行时的函数执行和数据传输，高效、准确地识别安全缺陷及漏洞，对 Web 应用接收到的请求及其对应的后端逻辑进行污点流分析，检测代码中存在的安全风险。

代码分析： 

1.  第 4  行，通过 request 对象获取 get 参数 cmd 的值，然后通过 URL 解码，转换为字符串 decode；
    
2.  第 9  行，将 decode 后的字符串值存入 HashMap 中；
    
3.  第 12 行，获取 HashMap 中的参数；
    
4.  第 14 行，cmd 转换为字符串数组；
    
5.  第 16 行，调用 Runtime 的 exec 方法传入 cmd 数组，执行系统命令。
