# 【云安全】谷歌云对象存储攻防

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDQ5NTQzOQ==&mid=2247492518&idx=1&sn=7f8f2e3c37a14e2866acf21b64426250&chksm=eaa96b86dddee2904d16f22a1c677d8168d4cb1cd5030066e3733cc08543efe59e65b68581b9&scene=126&sessionid=1681371420#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDQ5NTQzOQ==&mid=2247492518&idx=1&sn=7f8f2e3c37a14e2866acf21b64426250&chksm=eaa96b86dddee2904d16f22a1c677d8168d4cb1cd5030066e3733cc08543efe59e65b68581b9&scene=126&sessionid=1681371420#rd)

本文主要介绍谷歌云对象存储攻防的方式。

  

**01 **

**存储桶配置错误-公开访问**

  

![](../Images/a7b1698f1b3eb4cf47c11f78d0bcefd4.png)

  

当创建的存储桶配置了allUsers拥有GCS对象的读取权限时，该存储桶可以被任何用户公开访问。

  

![](../Images/8d4cf32a68345588c0612c37620edb91.png)

  

**02 **

**Bucket爆破**

  

当不存在时访问会提示NoSuchBucket。  

  

![](../Images/1c717c4848a1de82eb32481ef9a38606.png)

  

当存在时会出在下面情况，公开访问和拒绝访问。  

  

![](../Images/79a0b0227228369a29564f0adf79b745.png)![](../Images/9270f6e554c667bc6cfbec007a495806.png)

  

**03 **

**Bucket Object 遍历**

  

当对allUsers配置了Storage Object Viewer 或者Storage Legacy Bucket Reader权限时就会将存储桶内容遍历出来并且可以读文件内容。

  

![](../Images/05f1bcaf4e0e7ae1aa751c982a25fe20.png)

  

**04 **

**任意文件上传和覆盖**

  

当存储桶配置了allUsers拥有 Storage Legacy Bucket Owner、Storage Object Admin或者Storage Legacy Bucket Writer 权限时，任何用户都可以上传任意文件到存储桶并覆盖已经存在的文件。  

  

![](../Images/177b1e327e62eaf50397cb67970b731b.png)![](../Images/c732b142e61bbb05c8320c98f575ab57.png)

  

**05 **

**SERVICE ACCOUNT泄漏**

  

*   Github代码中泄露
    

*   网站JS代码  
    

  

![](../Images/1f32a9facd34f2459afe6bb7cdca0952.png)

  

**06 **

**Bucket IAM 策略可写**

  

![](../Images/50c8e5a0207f092a8e14ea3d31bd005d.png)

  

访问权限控制为统一时，对象访问权限完全由存储桶级权限 (IAM) 进行控制。  

  

直接访问存储桶发现AccessDenied。

  

![](../Images/2a3ed2ae989d69596413513a02eb9484.png)

  

查看Bucket IAM策略。

  

![](../Images/601763b0c098cf3d60d6a23ada874f75.png)

  

上图标识部分表示所有的谷歌认证用户都有权有权获取和设置任意 IAM 策略，通过gsutil去修改IAM策略。

![](../Images/222f7bf456fa28f3ec63b0b995ad50e8.png)

再次去访问存储桶

![](../Images/d79432f38c005f89b376f87b119b3f4a.png)

  

**07 **

**Object ACL可写**

  

![](../Images/50c8e5a0207f092a8e14ea3d31bd005d.png)

  

访问存储桶对象时提示AccessDenied

  

![](../Images/70b61014869a33df11aadf99c7b47472.png)

  

当访问权限控制为精细控制时，查看Object ACL,发现所有谷歌认证用户都能修改Object ACL。

  

![](../Images/63e80b63f33ace29cd6496f554de84f4.png)

  

gsutil acl ch -u allUsers:R gs://new2\_test/1.txt

![](../Images/10fb806243198ce93beec15763bea196.png)

  

修改ACL后任何用户都可以访问。

![](../Images/7370caebee0bca4051125a974ef44a0d.png)
