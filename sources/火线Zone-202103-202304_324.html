火线Zone社区自2021年4月份开始内测以来，至今已有1500多名优质的白帽子注册申请，社区发帖数超过700+。

因近期有很多新来的朋友们，现用一篇文章带大家了解一下火线Zone社区运营规范。


火线Zone是什么


火线Zone是[火线安全平台]运营的封闭式实战安全攻防社，研究讨论实战攻防技术，平台向顶尖的白帽子提供安全测试的云端基础设施。

社区成员必须在[火线安全平台]提交有效漏洞才能申请免费加入。

我们不希望出现劣币驱逐良币的结果，我们不希望一个技术社区变成一个水区！


如何发表内容


  1. 进入【火线Zone https://zone.huoxian.cn/】-> #发布主题#-> 在文章开头选择#添加标签#

  2. 投稿文章必须添加官方标签#原创文章# 、#翻译文章# ，否则不参与社区奖励。

  3. 文章类型以渗透测试、代码审计、漏洞分析、漏洞挖掘、火器工具实战姿势为主，其余类型可根据文章内容质量酌情考虑。

  4. 发布文章后，社区管理员会对文章进行审核，不满足要求的文章将会被删除，不能获得社区奖励。

  5. 投稿内容必须在火线Zone首发，且发布后不得在其他任何平台进行发布。

  6. 只有[火线安全平台]的实名制白帽子才可获得内容激励，涉及奖励发放。

根据【火线Zone社区运营规则 v0.1】相关要求规定，为鼓励所有社区新用户进行原创文章的分享，实行#首发文章激励#计划。

首次发帖点赞数超过5个

即可获得“火线定制帽子一个”

满足条件后请微信联系火线小助手进行奖励发放，本次#首发文章激励#计划截止到11月30日。



#原创文章激励#计划


根据【火线Zone社区运营规则 v0.1】相关要求规定，为鼓励所有社区用户进行原创文章的分享，实行#原创文章激励#计划，发布的原创文章请添加官方标签#原创文章#，否则不计入奖励。


＋

奖励具体规则如下：


  1. 点赞 >10 的原创文章，将获得#原创文章激励#300查克拉。

  2. 点赞 >10 的原创文章，同时可参与周度计划评选，按照文章Rank值来计算排名，获得对应奖励。


Rank = 评论数 X 3 + 点赞数 X 2 + 阅读量 X 1

第一名：500元现金+500查克拉

第二名：300元现金+300查克拉

第三名：200元现金+200查克拉


符合周度激励的内容将会被设置为社区精华并对外发表在【火线Zone】公众号上。

所有奖励每周一进行结算（即本周奖励结算上周的原创文章），结算完将在火线Zone社区进行结果公示，如有异议请及时联系#火线小助手#。

无异议后将在周二或周三发放奖励至火线安全平台账号内，可进行现金提现或兑换商品。


查克拉是什么


查克拉是火线安全平台推出的查克拉系统，查克拉为火线安全社区可流通可消费的虚拟货币系统，成员可使用它进行：

社区消费：可根据需要使用查克拉兑换火线平台的各种服务（如项目资产监控服务、项目线索服务、商用产品等）

实物兑换：可根据查克拉在火线商城兑换相应奖品。

社区分红：查克拉可作为价值投资货币参与平台年终分红。社区会根据年度运营业绩作为社区分红基金，年底按照成员本年度查克拉占比进行分红。

（如平台年度发放奖励100万元，年度社区结余查克拉10万个，白帽子A本年度查克拉结余为2万个，则白帽子A的年度分红为：100万 X（本年度分红比例，如20%） X （2万/10万）=4万
