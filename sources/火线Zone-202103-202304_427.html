我们从《红蓝对抗之企业对外根域名资产收集》这篇文章可以学习到如下几种根域名的收集方式。本文将对细节再进行补充和扩展。



1

通过PTR记录收集


什么是PTR记录呢？

PTR记录，是电子邮件系统中的邮件交换记录的一种；另一种邮件交换记录是A记录（在IPv4协议中）或AAAA记录（在IPv6协议中）。PTR记录常被用于反向地址解析。


以Facebook为例


1. 收集IP段


https://bgp.he.net/searchsearch%5Bsearch%5D=facebook&commit=Search



2. 正则提取ip段


(\d{1,3}\.){3}\d{1,3}\/\d{1,2}



3. 解析ptr记录


printf("hello world!");cat facebook.txt | mapcidr -silent | dnsx -silent -ptr -resp-only -o output.txt



4. 提取根域名


cat ~/Desktop/output.txt | python extract-root-domain.py -



import clickfrom wsltools.domaintools import domain
def generate(results): for result in results: if domain(result).valid: yield domain(result).main
@click.command()@click.argument('filename', required=True, type=click.File(mode='r'))
def main(filename): results = filename.read().splitlines() for r in set(generate(results)): click.echo(r)
if __name__ == "__main__": main()
