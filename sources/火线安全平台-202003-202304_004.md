# 火线众测、洞态IAST双双斩获网安新兴赛道厂商「速查指南」星标推荐

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4MjEwNzMzMg==&mid=2247492815&idx=2&sn=0c53eab10c83deead036f8ba86ff1b6a&chksm=fdbfcd64cac844729202fa29d4d6e0e81644ed1401cdfc7d22ff866eaf6b956b2658e8476de2&scene=126&sessionid=1681371248#rd](http://mp.weixin.qq.com/s?__biz=MzU4MjEwNzMzMg==&mid=2247492815&idx=2&sn=0c53eab10c83deead036f8ba86ff1b6a&chksm=fdbfcd64cac844729202fa29d4d6e0e81644ed1401cdfc7d22ff866eaf6b956b2658e8476de2&scene=126&sessionid=1681371248#rd)

![](../Images/2bcff19d33eb08d9f9a5a2d9b3305a03.png)

  

近日，斯元商业咨询正式发布2023首版网安新兴赛道厂商「速查指南」，**火线安全在应用安全领域的核心业务火线众测、洞态IAST双双斩获网安新兴赛道厂商「速查指南」星标推荐。**

  

网安新兴赛道厂商「速查指南」为斯元商业咨询Cyber Security Billboard系列报告之一，助力企业安全负责人、渠道合作伙伴和安全从业者及时了解网安行业的新兴赛道及前沿产品，在项目产品选型时，高效检索细分赛道和代表性厂商。自2022年推出以来，已迭代发布了4个版本。相比于2022第4版，**2023首版新增46个新兴赛道，共计190个赛道，新增厂商700+家，共达2000+家。**

  

**洞态IAST**

**最能落地的IAST**

**洞态IAST是火线安全基于应用安全领域多年的技术积累，推出的全球唯一开源IAST产品。**凭借高检出率、低误报率、无脏数据和漏洞检测的完整覆盖度等多重优势，在众多交互式应用安全测试产品中脱颖而出，获得斯元商业咨询的星标推荐。  

  

![](../Images/793066bb298c9ff0fc42fe7748fdf019.png)

  

洞态IAST可完美匹配敏捷开发和DevSecOps流程，在软件开发和测试阶段无缝集成现有开发流程，让开发人员和测试人员在执行功能测试时，实时、动态、同步进行漏洞检测，**可精确确定漏洞所在代码行，在无感知的情况下完成安全测试。**

  

**洞态IAST独创数据采集、扫描引擎分离，多维度熔断降级，深度漏洞检测，跨服务漏洞检测，与黑盒产品交叉验证等功能，帮助企业在应用上线前高效检测漏洞，降低漏洞发现与修复成本。**采用无需采集和重放流量的被动插桩模式，不产生任何脏数据；独特的云端算法在确保高检出率的同时，大量减少误报；同时，还对不同类型的客户业务拥有完整的覆盖度，支持微服务、API 网关、分布式等应用架构。

  

![](../Images/88268c414f1aa90d863ccecf093070da.png)

  

**目前火线安全已帮助200多家大型企业成功部署数十万个节点，并在全球27个国家和地区进行了广泛部署，拥有行业里最多的落地应用，是最能落地的IAST。**此前，火线安全凭借开源洞态 IAST 产品，和用户一起在 DevSecOps 领域积累的大量实践落地经验，特将所做研究和用户实践经验整理成实战型经验手册。

  

本册从甲方视角出发，收录了11家企业如何将IAST落地到 DevSecOps 流程中，共13篇文章。涉及在线旅行服务、互联网医疗平台、SaaS 协同平台、传统零售、移动社交、O2O 生活服务、金融科技等多个行业。

  

![](../Images/170ff44f28bfe03eda07a6011c942295.png)

  

**火线众测**

**效果与产出远高于行业平均水平**

火线众测自网安新兴赛道厂商「速查指南」收录众测赛道以来即入选，**在2023首版「速查指南」中，更是凭借远高于行业平均水平的服务效果与产出，一骑绝尘，成为唯一获得星标推荐的安全众测平台。  
**

  

![](../Images/d31891030bc97b85247c2960a8834db3.png)

  

**火线众测平台不仅是最高质量的白帽子聚集地，更是最受高难度客户欢迎的安全众测平台。**基于优质的全实名制白帽社区，为客户提供专业的众测服务，帮助企业全面发现业务漏洞和风险。

  

![](../Images/ec063c6e1566a76b5d1a999cce81f7f9.png)![](../Images/92f0edac8b0843265789b530881d31f5.png)![](../Images/c65d2f0e889737ada36e4da9933b80ad.png)

  

ChatGPT等AI技术的飞速发展，让应用的开发越来越简单。未来，应用将继续迎来爆发式增长，带来众多新兴的技术与挑战，应用安全也将面临前所未有的风险。

  

无论是技术还是形态，应用永远在变化，但是应用安全的本质与目标从未改变。**未来，火线安全将继续基于自身在应用安全领域的深厚积累，持续为网络安全、应用安全的技术创新与发展贡献火线力量。**
