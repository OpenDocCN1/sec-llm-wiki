自洞态首次发布版本更新日志以来，已经过去一年的时间。从v1.1.0到如今的v1.9.2，我们收到了大量来自社区伙伴反馈的建设性意见，洞态新版本又为大家带来了一些新内容，欢迎社区小伙伴们继续参与到洞态的持续更新与迭代中来。


DongTai-IAST  1.9.2

产品 Bug 修复：

* 修复了 Agent 状态显示异常的问题。

* 修复漏洞一直验证中的 Bug。

* 修复了由社区@wowo233反馈的 Redis 失连导致 Celery 挂起，任务不再消费的 Bug。

产品易用性提升：

* 更新 Agent 管理部分的设计，按时间展示 Agent 数据，默认只展示2天内的 Agent。

* 简化熔断配置设置。

* 增加对 ARM64 架构的支持。

* 添加 Agent 版本响应头配置。

* 优化服务端存储空间，开源版不再存储无漏洞代码调用链信息，节省磁盘空间占用。


DongTai-Agent-Java v1.8.1

Bug修复：

* 修复 Java Agent Attach 后的类转换导致的异常。

* 修复 Java Agent SecureRandom 的弱加密检查。

* 修复解析源自定义模型导致的 IllegalAccessException。

易用性提升：

* 增加调用链大小超过容量的警告级别日志。

* 添加 Fluent-Arm，在使用另一个进程时修复 Fluent 提取。

* 修复 Agent 注册时采集环境变量时的问题。

检测能力提升：

* 添加污点标签以提升漏洞识别准确性。
