**01**

*   HXSecurity/DongTai-engine

*   HXSecurity/DongTai-openapi
    
*   HXSecurity/dongtai-core
    

  

**02**

**DongTai-IAST**

  

1.Agent 管理界面增加 卸载/注册、降级/恢复，在自动降级不满足要求时可手动管理 Agent 状态。  

  

参数详见：系统配置 - Agent 管理

https://doc.dongtai.io/docs/operation/server-configuration#agent-管理

2.Agent支持配置集群标签参数，启动时支持配`cluster_name`集群名称，`cluster_version` 集群版本，方便为不同集群配置不同熔断降级参数。

  

参数详见：系统配置 - Agent 配置熔断降级

https://doc.dongtai.io/docs/operation/server-configuration#agent-管理

  

3.Java Agent 主动熔断降级方案，感谢**58同城**贡献联合共建，贡献 Java Agent 端代码。

  

*   支持根据JVM CPU、内存、线程数、垃圾回收等维度参数降级
    
*   支持限定请求数、单请求hook数，自动应对压测等特殊场景
    
*   支持二次降级卸载、支持降级后主动恢复等功能
    

  

参数详见：系统配置 - Agent 配置熔断降级

https://doc.dongtai.io/docs/operation/server-configuration#agent-管理

4.优化漏洞列表、系统日志等接口响应速度

5.优化了污点流程图的渲染效率

6.统一页面表格格式，美化了页面样式

7.对删除操作增加了预先的询问校验

8.修复若干中英文展示 Bug

9.修复了图标高度切换版本发生变化的 Bug

10.修复了规则删除或增加时，总数未改变的 Bug

11.修复了部分 `I18N` 描述不准确的 Bug

12.修复了无法导出报告的 Bug

  

**03**

**DongTai-agent-java**

  

Java Agent 可配置核心依赖包获取位置，启动参数 :  `dongtai.server.package`

  

**参数设定**

  

*   true：从 Server 端下载核心依赖包，多版本可复用 agent.jar
    
*   false：从本地获取核心依赖包，可优化应用启动速度
    

  

参数详见：Agent 配置安装参数

https://doc.dongtai.io/docs/getting-started/agent/parameter/config-java-agent#配置安装参数

**关于洞态 IAST**

洞态 IAST 是全球首个开源 IAST，于2021年9月1日正式开源发布。洞态 IAST 专注于 DevSecOps，具备高检出率、低误报率、无脏数据的特点，帮助企业在应用上线前发现并解决安全风险。自开源发布以来，洞态 IAST 备受开源社区人员和企业的关注，包括中国移动、去哪儿、知乎、同程旅行、轻松筹等在内的近二百家企业均已成为洞态用户。
