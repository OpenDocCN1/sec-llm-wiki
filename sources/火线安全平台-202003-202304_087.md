# 火线沙龙第23期—云原生&DevSecOps专场

随着虚拟化技术的成熟和分布式框架的普及，在容器技术、可持续交付、编排系统等开源社区的推动下，应用上云已经是不可逆转的趋势，而云原生作为一套构建和运行应用程序的技术体系和方法论，已经在云上环境中发挥着重要优势。

  

它充分利用和发挥云平台的弹性+分布式优势，为企业云上业务加速并提供保障。同时，其组织形式DevOps也为云原生提供着持续交付能力。

  

**本场沙龙，将围绕云原生以及DevOps展开讨论，帮助企业和用户搭建和规划全新的云原生应用，第一时间了解云新鲜技术，为企业安全应用建设保驾护航。**

**沙龙议题**

  

  

**汪照辉**｜某大型国有证券公司高级架构师

**DevOps落地思考**

  

作为甲方的架构设计和研发运维人员，我们期待的DevOps是一套完整的体系，DevOps安全是DevOps建设过程中重要的内容，高效地融合为一体。本次我将分享下重塑DevOps体系和DevOps落地的思考和思路，希望能从思维层面带来一些认知的改变，能促进国内产品化的完善。

  

**马景贺**｜极狐(GitLab)技术布道师

**DevSecOps:让大家都Happy的安全软件构建模式**

  

DevSecOps 被认为是保证软件安全的重要手段，不能简单认为 DevOps + Security = DevSecOps，真正构建高效的 DevSecOps 体系，不仅需要研发、安全、运维等团队的参与，更需要合适的工具，适宜的流程，从而打造适合本团队且能真正落地的 DevSecOps 体系，最终达到团队受益，软件安全交付的目的。

  

**李祥乾**｜探真科技研发副总裁

**DevSecOps****邂逅云原生：云原生时代下的持续安全**

  

随着DevOps文化的兴起，相比于传统架构，云原生具有一系列的特性，使得安全能够更加低摩擦地内生于企业的流程中，内生于DevOps之中，更好地践行DevSecOps。从云原生架构与传统架构的不同之处开始，希望与大家讨论云原生架构下如何在加快的CI/CD中，实践持续安全（Continous Security），碰撞出更亮的火花。

  

**Clare**｜国内某支付机构安全架构师

**云原生安全实践**

  

容器，微服务，弹性分布式网络架构的引入，云原生（Cloud Native）云安全问题已经成为企业防护的重中之重. 针对云原生体系面临安全风险与威胁，从攻击到防御角度的纵深防御探索和实践。
