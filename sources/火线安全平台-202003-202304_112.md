**01**

**环境准备**

  

*   Linux/Mac 机器
    
*   安装 Docker 服务，可通过 docker -v 判断 docker 服务是否安装，如未安装，请先自行安装。
    
*   具有 docker-compose 命令，可通过 docker-compose -v 判断是否存在，如不存在，请先自行安装。
    

  

**02**

**洞态 v1.1.4 一键安装**

  

*   
*   

```
git clone git@github.com:HXSecurity/DongTai.git && \ bash ./DongTai/deploy/docker-compose/dtctl install
```

  

**03**

**旧版本一键升级 v1.1.4**

  

洞态 IAST 版本 >= v1.0.3 时，可一键升级到 v1.1.4，版本 < v1.0.3 不支持自动升级，建议直接部署 v1.1.4 新版本，如需升级可联系洞态小助手协助。

*   
*   
*   
*   
*   

```
# 默认升级到最新版# 需要指定版本升级的用户可以使用-t <版本号>cd DongTai && \git pull && \bash ./deploy/docker-compose/dtctl upgrade
```

  
  
**注意事项：**

*   DongTai-WEB 服务默认端口：80，自动部署时，会询问是否需要修改 DongTai-WEB 服务的默认端口，并检查端口是否被占用。
    
*   由于数据库初始化完成的时间与机器配置有关，build\_with\_docker\_compose.sh 脚本运行完之后，需要等待1-3分钟。
*   部署完成后，访问 DongTai-WEB 服务，如：http://localhost，如图：
    

![](../Images/414bba8bf3faaa3f2c27168ba944aef9.png)

若验证码未加载出，是因为数据库还没有初始化完成，需等待一下。如果超过10分钟，还未出现验证码，请在官方 **微信群 **中反馈。

至此，洞态已完成安装与配置，可通过 **Add Agent **下载并配置探针，检测漏洞。
