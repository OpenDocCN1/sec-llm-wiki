01

环境准备


  • Linux/Mac 机器

  • 安装 Docker 服务，可通过 docker -v 判断 docker 服务是否安装，如未安装，请先自行安装。

  • 具有 docker-compose 命令，可通过 docker-compose -v 判断是否存在，如不存在，请先自行安装。


02

洞态 v1.1.3 一键安装


git clone git@github.com:HXSecurity/DongTai.git && cd ./DongTai/deploy/docker-compose && bash ./dtctl install -v 1.1.3


03

旧版本一键升级 v1.1.3


# 进入之前旧版DongTai的目录后更新# 以1.0.3为例，其他版本需修改为旧版本号cd DongTai && git pull && git checkout release-1.1.3 && cd ./deploy/docker-compose && bash ./dtctl upgrade -f 1.0.3 -t 1.1.3
‍


注意事项：
  • DongTai-WEB 服务默认端口：80，自动部署时，会询问是否需要修改 DongTai-WEB 服务的默认端口，并检查端口是否被占用。
  • 由于数据库初始化完成的时间与机器配置有关，build_with_docker_compose.sh 脚本运行完之后，需要等待1-3分钟。

  • 部署完成后，访问 DongTai-WEB 服务，如：http://localhost，如图：


若验证码未加载出，是因为数据库还没有初始化完成，需等待一下。如果超过10分钟，还没有出现验证码，请在官方 微信群 中反馈。
至此，洞态已完成安装与配置，可通过 Add Agent 下载并配置探针，检测漏洞。
