**03**

**旧版本一键升级 v1.1.3**

*   
*   
*   

```
# 进入之前旧版DongTai的目录后更新# 以1.0.3为例，其他版本需修改为旧版本号cd DongTai && git pull && git checkout release-1.1.3 && cd ./deploy/docker-compose && bash ./dtctl upgrade -f 1.0.3 -t 1.1.3
```

‍  
  
**注意事项：**

*   DongTai-WEB 服务默认端口：80，自动部署时，会询问是否需要修改 DongTai-WEB 服务的默认端口，并检查端口是否被占用。
*   由于数据库初始化完成的时间与机器配置有关，build\_with\_docker\_compose.sh 脚本运行完之后，需要等待1-3分钟。
*   部署完成后，访问 DongTai-WEB 服务，如：http://localhost，如图：
    

![](../Images/414bba8bf3faaa3f2c27168ba944aef9.png)
