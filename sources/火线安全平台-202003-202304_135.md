**Python Agent (v1.0.6)**

  

DongTai-agent-python是洞态IAST针对Python应用开发的数据采集端。在添加iast-agent代理的Python应用中，通过hook内置函数的方式采集所需数据，然后将数据发送至DongTai-openapi服务，再由云端引擎处理数据判断是否存在安全漏洞。

  
洞态IAST Python Agent(v1.0.6) 首次发布GA版本。  

*   Agent 采用和 Server 版本号一致的策略
*   支持 Flask 和 Django 两大主流Web框架

**版本及安装前提**

  

*   最新版本：v1.0.6
    
*   环境准备

        ◇ Linux/Mac机器        ◇ 安装Docker服务，可通过**docker -v**判断**docker**服务服务是否安装，如未安装，请先自行安装        ◇ 具有**docker-compose**命令，可通过**docker-compose -v**判断是否存在，如不存在，请先自行安装

**2.一键部署**

运行自动部署脚本，一键部署洞态服务：

  

*   
*   

```
chmod u+x build_with_docker_compose.sh./build_with_docker_compose.sh
```

  

**注意事项：**

*   **DongTai-WEB**服务默认端口：80
    
*   **DongTai-OpenAPI**服务默认端口：8000
    
*   自动部署时，会询问是否需要修改DongTai-WEB服务、**DongTai-OpenAPI**服务的默认端口，并检查端口是否被占用。
    
*   由于数据库初始化完成的时间与机器配置有关，build\_with\_docker\_compose.sh脚本运行完之后，需要等待1-3分钟。
    

  
  

**3.快速访问**

部署完成后，访问**DongTai-WEB**服务，如：**http://localhost**，页面如下：

  

![](../Images/7c77ca5146f16c4333fc5f386d1f4c7e.png)  
**注意事项：**  

*   若验证码未加载出来，是因为数据库还没有初始化完成，耐心等待一下，如果超过10分钟，还没有出现验证码，请在官方QQ/微信群中反馈

  

*   登陆系统之后，需要先前往 **服务注册** 功能配置 **DongTai-OpenAPI **服务的地址，如图。**若本机部署该地址需填写局域网地址，禁止填写127.0.0.1和localhost。**

  

![](../Images/621bee74a0efe6b7fc6b8bde015c327c.png)

  
至此，**洞态**已完成安装与配置，可通过**Add Agent**下载并配置探针，检测漏洞。
