01

版本及安装前提


最新版本：v1.0.5


环境准备


Linux/Mac机器


安装Docker服务，可通过docker -v判断docker服务服务是否安装，如未安装，请先自行安装


具有docker-compose命令，可通过docker-compose -v判断是否存在，如不存在，请先自行安装


02

快速安装


1. 克隆代码


访问github，搜索DongTai，或直接访问以下github地址然后克隆代码：


https://github.com/HXSecurity/DongTai



在shell中通过以下命令下载仓库并切换至最新版本的分支：


git clone git@github.com:HXSecurity/DongTai.gitcd DongTaigit pull
# 如果需要部署其他版本，切换至相关分支即可git checkout release-1.0.5


如果clone失败请看 《github无法push？看这篇文章就够了》


2.一键部署


运行自动部署脚本，一键部署洞态服务：


chmod u+x build_with_docker_compose.sh./build_with_docker_compose.sh


注意事项：


   1. DongTai-WEB服务默认端口：80


   2. DongTai-OpenAPI服务默认端口：8000


   3. 自动部署时，会询问是否需要修改DongTai-WEB服务、DongTai-OpenAPI服务的默认端口，并检查端口是否被占用。


   4. 由于数据库初始化完成的时间与机器配置有关，build_with_docker_compose.sh脚本运行完之后，需要等待1-3分钟




3.快速访问


部署完成后，访问DongTai-WEB服务，如：http://localhost，页面如下：



注意：


1.若验证码未加载出来，是因为数据库还没有初始化完成，耐心等待一下，如果超过10分钟，还没有出现验证码，请在官方QQ/微信群中反馈


2.登陆系统之后，需要先前往 服务注册 功能配置 DongTai-OpenAPI 服务的地址，如图。若本机部署该地址需填写局域网地址，禁止填写127.0.0.1和localhost。





至此，洞态已完成安装与配置，可通过Add Agent下载并配置探针，检测漏洞。


03

快速升级


注意：本次升级是 v1.0.4 版本升级到 v1.0.5 的教程，如果您的版本是 v1.0.4 之前的版本，则需要先升级到 v1.0.4 版本。


1. 更新代码到1.0.5版本


# 切换代码所在的目录，如：/opt/DongTaigit stashgit pullgit checkout release-1.0.5


2. 一键部署服务


运行自动部署脚本，一键部署洞态服务：


# 停止当前 docker 中所有的的洞态服务docker stop dongtai-iast_dongtai-engine-task_1 dongtai-iast_dongtai-web_1 dongtai-iast_dongtai-engine_1 dongtai-iast_dongtai-webapi_1 dongtai-iast_dongtai-openapi_1 dongtai-iast_dongtai-redis_1 dongtai-iast_dongtai-mysql_1   cd deploy/docker-composechmod u+x install.sh./install.sh



3. 更新数据库文件


3.1 进入dongtai-mysql的容器：


docker exec -it dongtai-iast_dongtai-mysql_1 /bin/bash


3.2 进入/docker-entrypoint-initdb.d目录，下载数据库更新文件：update-20211009.sql


cd /docker-entrypoint-initdb.dmysql -uroot -p"dongtai-iast" -D dongtai_webapi < /docker-entrypoint-initdb.d/update-20211009.sql
