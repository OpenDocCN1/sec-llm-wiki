# 火线安全平台——高效链接企业与白帽，扶持白帽成长

**在金融行业网络安全攻击不断增加、防御难度不断提高的背景下，如何筑牢金融网络安全屏障来应对日益复杂的安全挑战？**

2021年9月10日，由安世加主办，火线安全等企业赞助的金融行业安全实践沙龙成功举办。来自中国人寿养老保险、老虎证券、中国民生银行、火线安全、Imperva和Gigamon等企业的嘉宾，通过结合自身业务分享其安全实践，给出了他们的应对思路。  

  

火线安全创始人邬迪在会上分享了**“众测服务的最新实践”**。（篇幅受限，其余嘉宾的演讲资料获取方式已放在文末哦）

  

众测源于用户对测试覆盖度和深度的要求提高，自2012年产生以来，已经发展为互联网企业的标配。**众测“奖励先到先得”的模式能激起众多白帽安全专家的积极性，测试覆盖度和深度都能得到保证，漏洞挖掘效果极好。**企业业务信息系统能在火线众测的加持下提前检测出漏洞风险，以防止业务受到影响。

  

目前，众测的模式也受到来自需求端和供给端的挑战。从需求端来看，企业对测试过程无法做到充分的信任；从供给端来看，白帽子数量不足以满足企业需求。

  

针对以上二点，火线安全平台自成立以来，一直在**“可信、智能、成长”**上发力，以期通过技术创新、运营策略创新，让企业信赖，帮白帽成长。

  

**可信——提高企业信赖度**

火线安全平台的白帽子们除了需要满足邀请审核、交身份信息验证和人脸识别（平台不保存人脸信息，仅用于注册验证）外，还需要签署严格的保密协议，最大力度来建立企业与白帽子之间的信任桥梁。  
黑客是喜欢匿名的，但火线坚持“强实名认证”，**火线也是业内第一个做强实名认证的白帽子社区**。我们认为实名制使得企业更加放心把业务系统交给白帽子检测，白帽子反而会从中受益。

**智能——提高白帽效率**

目前，国内白帽的数量远不足以满足市场对安全人才的需求。为此，火线安全平台创新开发了一系列的工具，以提高白帽挖掘漏洞的效率。

  

**01 资产检索数据**

![](../Images/368c0776cfc2d333ae96d48450f46ceb.png)  
无论是在众测、渗透测试还是模拟攻防演练中，攻击方在前期都需要在资产信息收集上耗费大量精力。火线认为**信息收集这些基础工作应该是由平台将其标准化、工具化、自动化，进而减轻资产信息收集压力。**  
因此，**火线安全平台将入驻火线的所有企业的信息资产进行了自动化的收集整理**，包括企业的域名、工商数据、服务数据证书、URL和APP等信息。白帽子可以在众测项目开始后便可以直接获取企业的资产信息进行漏洞挖掘，极大地提高了其资产信息收集效率。  

**02 漏洞线索分析**

![](../Images/c13c0e7ac447345eedcc79f368cf6279.png)  
  
火线安全平台会经常提供一些漏洞线索，白帽子可以通过使用平台上的积分去锁定某个资产信息，再进行深度分析。  

**03 策略自定义工具**

![](../Images/7df0b65e7dc226116aab7421673c7123.png)  
  
策略自定义工具是火线为提高白帽子检测效率开发的无代码扫描器，这款扫描器将漏洞扫描工具拆分为一个个的模块，白帽子进行一些拖拽，便可以组成新的检测策略进行使用，简单便利且效果好。  
  

**成长——助力白帽成为技术大拿**

火线安全平台一直都将平台上的白帽子作为自己最最核心的竞争力，为帮助白帽们成长，在火线Zone专门设置了**技术交流版块**。此外，火线会定期举办**“听火”线上技术交流沙龙**。我们也鼓励精英白帽分享自己的“独门技巧”，并奖励获得多数白帽认可的技术分享文。
