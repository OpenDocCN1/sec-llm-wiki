洞态 | 为研发人员打造的安全利器之 IDEA 插件


洞态专注于 DevSecOps，帮助企业发现并解决应用安全风险。洞态 IAST 是全球首家开源的 IAST，支持 SaaS 访问及本地部署，助力企业在上线前解决应用的安全风险。

一、前言

一款合格的产品，安全要成为重中之重。


当组织或公司遇到安全漏洞时，总会造成难以预估的损失。几乎每年，我们都会看到有重大的网络安全事件的发生，这些事件都会伴随着巨大的损失。应用上线后出现安全漏洞，不仅会造成组织或公司的经济损失和名誉损失，也给每一位用户造成无法弥补的损失。应用在测试阶段检测安全漏洞的时间可能并不是很充裕，所以如何在应用开发阶段就可以让每一个研发人员进行漏洞检测，是洞态团队在努力做的。


成为合格的研发人员，难；成为懂网络安全的研发人员，难上加难！


对于大部分研发人员来说，网络安全的概念是比较模糊的。在开发应用的过程中关注到功能、性能，而缺少对安全性的关注，这就会导致开发的应用可能存在安全漏洞，造成损失；在代码中使用的第三方组件，只考虑功能性而不考虑组件是否安全，这对应用本身的危害是非常大的，因为黑客可能利用第三方组件的安全漏洞入侵应用，造成损失。


洞态，帮助研发人员发现安全漏洞。


洞态是一款开源的被动式交互式安全测试 (IAST) 产品，洞态团队开发的 IDEA 插件，专为研发人员在开发过程中使用，实时检测安全漏洞，而且检测的方式也非常简单，正常访问一次应用接口就可以检测有没有漏洞，大大降低了使用的门槛，即便对安全知识知之甚少的同学也可以检测自己所开发的功能是否存在安全漏洞，非常方便。


洞态 IDEA 插件运行在 Intellij IDEA 上，开发者可以使用插件来做：


  • 实时检测正在开发 web 应用的安全漏洞

  • API Sitemap — 对应用所有的 API 接口进行梳理

  • 第三方组件的安全性查看


二、洞态 IDEA 插件功能使用


1. 实时检测正在开发 web 应用的安全漏洞


新建 spirngboot 项目，模拟开发过程，写一个带有“命令执行”漏洞的接口，使用洞态插件启动项目



正常访问项目接口，访问 url ：http://localhost:8080/demo/cmdi?var1=l&var2=s


查看漏洞列表，发现检测到漏洞



选中漏洞，点击查看详情可以到洞态查看漏洞详情




2. API Sitemap


在官网创建项目，可以看到项目里所有的 API，类似 swagger，但无需配置。



查看刚刚访问过的接口，可以看到参数信息和请求信息，功能强大。



3. 第三方组件的安全性查看


在洞态的“组件管理”中，可以看到刚刚启动的项目所依赖的第三方组件和安全性，发现使用第三方组件所造成的安全漏洞



三、如何使用洞态 IDEA 插件


 1. 下载插件


下载地址：https://github.com/HXSecurity/DongTai-Plugin-IDEA/releases/download/v1.0/DongTai-Plugin-IDEA.zip


2. 安装插件


点击 IDEA 设置中的 Plugins，选择 “Install Plugin from Disk...”



选择刚刚下载的 IDEA 插件 zip 包



3. 申请成为洞态用户


申请洞态用户：https://dongtai.io

demo 用户在线体验：https://demo.iast.io


4. 配置插件


在洞态-部署界面: https://iast.io/deploy 获取用户 Token，复制。



在插件内配置 Token即可。
