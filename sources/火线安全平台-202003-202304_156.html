如何向洞态IAST项目提交PR


本文我们将以前端为例，来对洞态IAST社区进行一次PR贡献。


准备工作


node版本 14.16.0

git版本 2.32.0


fork代码到本地


进入仓库：https://github.com/HXSecurity/DongTai


此仓库为洞态IAST主仓（建议star或watch仓库，以便最及时关注项目动态），找到 子模块 DongTai-web点击进入后，点击仓库右上角的fork。


这样在本地的仓库中就多了一个fork的Repository。


点击进入项目，将项目clone到本地


git clone git@github.com:yourname/DongTai-web.git


将仓库与上游仓库同步


git remote add upstream https://github.com/HXSecurity/DongTai-web.git


修改工作分支


git checkout -b develop


然后可以进行你需要修改的代码操作


执行正常的git提交操作（建议commit内容使用英文）


git add .git commit -m "fix:xxxxxx"git push origin master


完成提交工作


发起PR（Pull Request）






进入fork的仓库点击pull requset 选项卡 点击 new pull requset 进入pr界面 左侧选中Dongtai主仓的develop分支，右侧为你刚才提交代码的分支。



选择过后可以看到commit的内容




点击 create pull requset 进入如下界面




输入title和本次pr的描述后（建议使用英文），点击 Create pull requset 按钮即可完成一次pr操作


洞态社区成长体系


贡献者(Contributor)


加入条件：

提交至少一个PR并被合并至仓库


权益：无


组织成员(Member)


加入条件：

必须是Contributor

提交5个以上PR到DongTai及子仓库


权益：

拥有DongTai团队的标识

拥有所有仓库开发分支的写入权限


维护者(Maintainer)


加入条件：

必须是组织成员

经常活跃或对某个仓库有突出贡献


权益：

拥有组织成员的所有权益

批准其他组织成员的贡献

拥有工作组决策的投票权


项目管理委员会(PMC)


加入条件：

必须是维护者

对产品的特定发展方向有独到的见解并被采纳   


权益：

拥有维护者的权益

负责PMC、Maintainer成员的选举与退出

为开源社区提供技术指导和技术决策
