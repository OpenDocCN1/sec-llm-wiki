**01**

**版本及安装前提**

  

   

最新版本：1.0.3

  

   

环境准备

  

Linux/Mac机器

  

安装Docker服务，可通过**docker -v**判断**docker**服务服务是否安装，如未安装，请先自行安装

  

具有**docker-compose**命令，可通过**docker-compose -v**判断是否存在，如不存在，请先自行安装

  

**02**

**快速安装**

  

   

1\. 克隆代码

  

访问github，搜索DongTai，或直接访问以下github地址然后克隆代码：

  

*   

```

```

  

![](../Images/47fc21f00be41a65a3620b266a71f7bb.png)

  

在shell中通过以下命令下载仓库并切换至最新版本的分支：

  

*   
*   
*   
*   
*   
*   
*   

```
git clone git@github.com:HXSecurity/DongTai.git
cd DongTaigit pull
# 如果需要部署其他版本，切换至相关分支即可git checkout release-1.0.3
```

  

   

2.一键部署

  

运行自动部署脚本，一键部署洞态服务：

  

*   
*   

```
chmod u+x build_with_docker_compose.sh./build_with_docker_compose.sh
```

  

**注意事项：**

  

1.洞态服务需要暴露**DongTai-WEB**服务、**DongTai-OpenAPI**服务，默认端口分别为：80、8000，自动部署时，会询问是否需要修改默认端口，并检查端口是否被占用

  

2.由于数据库初始化完成的时间与机器配置有关，build\_with\_docker\_compose.sh脚本运行完之后，需要等待1-3分钟

  

   

3.快速访问

  

部署完成后，访问**DongTai-WEB**服务，如：**http://localhost**，页面如下：

  

![](../Images/9f295004f556b64c5758a3edcd6b7673.png)

  

**注意：**

  

1.若验证码未加载出来，是因为数据库还没有初始化完成，耐心等待一下，如果超过10分钟，还没有出现验证码，请在官方QQ/微信群中反馈

  

2.登陆系统之后，需要先前往 **服务注册** 功能配置 **DongTai-OpenAPI **服务的地址，如图

  

![](../Images/07326b63a8b6109b11c1c6eca6109f3a.png)

  

至此，**洞态**已完成安装与配置，可通过**Add Agent**下载并配置探针，检测漏洞。

  

**03**

**快速升级**

  

如果不需要保存历史数据，已部署的探针也不需要使用，可以重新部署探针到服务商时，直接使用 **快速安装 **的部署方案

  

如果需要保存历史数据，根据如下方案进行升级即可

  

   

1\. 更新代码到**1.0.3**版本

  

*   
*   
*   

```
# 切换代码所在的目录，如：/opt/DongTaigit pullgit checkout release-1.0.3
```

  

   

2\. 一键部署服务

  

运行自动部署脚本，一键部署 **洞态** 服务：

  

*   
*   
*   

```
cd deploy/docker-composechmod u+x install.sh./install.sh
```

  

**注意事项：**

  

由于数据库无法自动升级，部署完成之后需要升级数据库

  

   

3\. 升级数据库

  

3.1 进入**dongtai-mysql**的容器，安装wget：

  

*   

```

```

  

3.2 进入**/docker-entrypoint-initdb.d**目录

  

3.3 下载相关文件

  

*   
*   
*   
*   
*   

```
wget https://raw.githubusercontent.com/HXSecurity/Dongtai-Base-Image/release-1.0.3/mysql/update-20210817.sqlwget https://raw.githubusercontent.com/HXSecurity/Dongtai-Base-Image/release-1.0.3/mysql/update-20210831.sqlwget https://huoqi-public.oss-cn-beijing.aliyuncs.com/iast/rule.sql
```

  

3.4 通过mysql命令按以上顺序执行sql，进行升级

  

*   
*   
*   

```
mysql -u root -p "dongtai-iast" -D dongtai_webapi < /docker-entrypoint-initdb.d/update-20210817.sqlmysql -u root -p "dongtai-iast" -D dongtai_webapi < /docker-entrypoint-initdb.d/update-20210831.sqlmysql -u root -p "dongtai-iast" -D dongtai_webapi < /docker-entrypoint-initdb.d/rule.sql
```

  

如果使用外部独立的mysql，按顺序执行如上3个sql文件即可。
