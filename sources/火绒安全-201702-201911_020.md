# 重要通知：火绒4.0即日起正式升级为5.0版本

亲爱的火绒用户：  

  

从今天开始，火绒4.0将正式升级为5.0版本。整个升级过程为线上分批自动升级，无需您手动操作，升级完成后，则需要您重启电脑（点击系统菜单中“重启”按钮）才能正常使用全部功能。如果您在升级后遇到任何问题，请随时联系我们解决。

  

火绒5.0版在4.0“轻巧、干净”的基础上，经历全新的升级，新增众多重要防御功能，变得更加专业，做到了集“杀、防、管、控”于一身。此外，自年初内测开始，我们时刻在匠心打磨、优化火绒5.0版，时至今日，这款产品已经足够稳定、成熟，请大家放心使用。
