# 清理软件CCleaner遭黑客入侵 数百万用户面临入侵风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NjYzMDM1Mg==&mid=2247484208&idx=1&sn=a609cef81d3183cbb7b3394f248c4ca8&chksm=eb73dd0fdc045419878c2a98f9a11047ec2d2d815dd2f1413cfdd7cb0d7af511364475de1dc1&scene=126&sessionid=1681574919#rd](http://mp.weixin.qq.com/s?__biz=MzI3NjYzMDM1Mg==&mid=2247484208&idx=1&sn=a609cef81d3183cbb7b3394f248c4ca8&chksm=eb73dd0fdc045419878c2a98f9a11047ec2d2d815dd2f1413cfdd7cb0d7af511364475de1dc1&scene=126&sessionid=1681574919#rd)

日前Piriform官方发布消息称，其旗下清理软件CCleaner有两个版本遭到黑客入侵，并且被安装了后门，在用户安装后会窃取其电脑信息。由于CCleaner用户群庞大，目前预计已经感染数百万的终端用户，危害严重。

 

**受影响版本**

> CCleaner v5.33.6162 
> 
> CCleaner Cloud v1.07.3191 

 

**黑客窃取的信息**

> 计算机名称
> 
> 已安装的软件和Windows的更新
> 
> 运行中的进程列表
> 
> IP和MAC地址
> 
> 其他信息。例如运行进程是否具有管理权限，以及它是否是64位系统等。

 

**CCleaner**

最近刚刚被Avast收购的CCleaner是一款著名的系统优化工具。其主要功能为清理Windows系统的垃圾文件和隐私记录，以及软件卸载等。由于其体积小，运行速度快，功能全面等优点，受到大量用户的欢迎，目前已累计有20亿次的下载量。国内也有不少人是CCleaner的忠实用户。

  

![](../Images/fdf5d6f6f8a79e65a9b9f19429b9eb95.png)

火绒安全专家建议CCleaner 产品的用户尽快进行排查，将软件及时更新到CCleaner 5.34或者更高版本（下载地址https://www.piriform.com/ccleaner/download）。目前火绒安全软件已经可以全面检测并查杀。
