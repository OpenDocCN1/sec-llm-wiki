**Ins ****因 API 漏洞遭入侵，600万知名账号信息被窃取并在 DoxaGram 上出售**

**

上周，美国女星 Selena Gomez 的 Instagram 被黑，发布前男友 Justin Bieber 的裸照。随后几天，名为 Doxagram 的网站公开兜售 600 万 Instagram 大 V 账号的邮箱地址和电话号码等私密信息，运动名人、当红明星、政治家、媒体都受到影响。有些外媒表示可能是黑客利用了 Instagram 网站的 API 漏洞，专门入侵知名度高的账号，获取邮箱地址和电话号码等信息。目前Instagram 已经确认公司遭到入侵，正在进一步调查。专家表示这个出售信息的 Doxagram 网站很可能就是由入侵 Instagram 的黑客创建的。

**六年的老漏洞”Loop Bug”重现，几近全部PDF阅读器中招**

**

近日，德国软件开发商HannoBöck称，一个早在2011年就被发现PDF解析库中的“loop”Bug，如今又在主流PDF阅读器中出现。该Bug最初是由德国软件开发商Andreas Bogk发现，会导致Evince应用程序进入死循环，迅速耗尽内存后崩溃。Chrome、Firefox、GitHub的PDF解析库都受到影响。同时，开源PDF解析器（如Ghostscript和QPDF）、在Windows 8或更高版本中默认安装的Windows Runtime PDF Renderer库或WinRT PDF也受影响。Böck已向所有受影响的产品厂商报告了旧的错误信息，他们正准备为此推出补丁程序。

来源：http://www.freebuf.com/news/146633.html

****被指预装恶意软件 联想支付350万美元与FTC和解****

**

联想从2014年开始在数十万台笔记本电脑上预装了软件VisualDiscovery，美国联邦贸易委员会(FTC)认为联想在预装软件时侵犯了消费者的隐私，在没有给出通知或获得用户同意的情况下就访问消费者的敏感信息，称该软件能访问消费者的社会保障号码等敏感信息。

目前，联想已经与FTC达成和解，联想将支付350万美元，并调整销售笔记本电脑的方式，以换取FTC撤销对其销售预装软件的指控。

**主流语音助手都存漏洞 浙江大学发现DolphinAttack攻击手段**

**

最近，浙江大学的一个研究团队发现，如今市场上的智能语音助手或多或少都存在一些安全漏洞，只要运用一个小技巧，就可以轻易控制它们。团队把这个小技巧命名为“海豚攻击”（The DolphinAttack），只要将特殊的语音指令转换为类似海豚的超声波，便可以在人类无法感知的情况下对智能语音助手下指令。这些声音对于人耳来说是无法听见的，但电子设备能听到这些命令。在实验过程中，研究人员成功的入侵了Google Assistant、苹果的Siri、亚马逊的Alexa、三星的S Voice、微软的Cortana以及华为的HiVoice。研究人员不仅能够“静默”激活语音助手，而且还能执行拨打电话、打开网站、关闭飞行模式、通知绑定智能门锁开门解锁等命令。

来源：http://www.sohu.com/a/190500092\_165095

**Struts2 REST ****插件 XStream 远程代码执行漏洞 S2-052(CVE-2017-9805)**

**

2017年9月5日，Apache Struts 发布最新安全公告。Apache Struts2 的 REST 插件存在远程代码执行的漏洞，其编号为 CVE-2017-9805 ，漏洞危害程度为高危（Critical）。当用户使用带有 XStream 程序的 Struts REST 插件来处理 XML payloads 时，可能会遭到远程代码执行攻击。

**受影响版本：**Apache Struts Version：2.3.33； Apache Struts Version：Struts 2.5 – Struts 2.5.12

**解决方法：**1、升级Struts到2.5.13最新版本；2、如果系统没有使用Struts REST插件，那么可以直接删除Struts REST插件，或者在配置文件中加入如下代码，限制服务端文件的扩展名<constant name=”struts.action.extension” value=”xhtml,,json” />
