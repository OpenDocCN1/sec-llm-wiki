# “网银升级”诈骗新伎俩 银行存款瞬间归零

“ 当下，大众对移动支付越来越依赖，犯罪分子发现良机，纷纷以“网银升级”为借口，在手机和电脑端设下连环陷阱诈骗钱财，非常危险，其套路如下：

**一、仿冒短信**  

犯罪分子先用伪基站向用户群发诈骗短信，犯罪分子会使用任意显号软件，将电话号码伪装成银行客服电话，谎称用户网银即将过期，必须到指定网址升级。

  

**二、钓鱼网站**

大众习惯直接使用短信上的网址，但短信上的网址实为钓鱼网站，犯罪分子仿照银行官网制作页面，网址多在官网域名基础上添加字母或修改后缀而成，真假难辨，网站会诱导用户填写银行账户、手机号、身份证号等信息。

  

![](../Images/0046521df72d05f751d50d7dd19565b8.png)

**三、窃取信息**

木马能实时盗取用户输入的信息，用户填写银行账户和密码时，犯罪分子可以同步登陆银行官网，转走余额。部分犯罪分子只需用户填写手机号码，即可在其他网站消费，一旦用户疏忽，将银行发送的消费验证码输入钓鱼网站，犯罪分子就能成功消费。

这种诈骗方式因其获利快、易成功，深受犯罪分子喜爱，在短时间内成爆发趋势。

  

  

**大家可以通过以下4个方法防止被骗：**

1.  拨打官方客服电话咨询  
    
    收到短信后，及时拨打银行官方客服电话或直接到营业厅核实。
    
      
    
2.  手动输入网址
    
    银行所有业务只会通过官网办理，接到短信后，手动输入银行官网地址，最好不要使用搜索得到的或短信提供的地址。
    
      
    
3.  关注账户变动信息
    
    开通账户变动短信通知，一旦发现被骗，立即报警。
    
      
    
4.  养成良好安全习惯
    
    不在公共场所登陆网银。操作结束后先退出网银系统，再关闭浏览器。勿将U盾等安全产品交给他人保管。安装火绒安全软件，火绒安全软件既能拦截木马病毒，也能拦截钓鱼网站，防止大家在不知不觉间遭受损失。
