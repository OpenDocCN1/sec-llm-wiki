PART1:火绒秘籍

  

**1.****免打扰模式——游戏安全两不误**

玩游戏时最怕弹窗，可是把安全软件关闭又让病毒有可趁之机。只需右键火绒安全软件托盘程序，开启**免打扰模式**即可一举两得。  

 

![](../Images/5ffbba691bfa7cdbd690ee6bf54b4a5b.png)

  

**2.设备使用控制——陌生U盘全拦截**

U盘的乱用不光会导致通过U盘传染病毒，更可能在你不经意间泄露信息。火绒的U盘保护功能，可以检测并防御U盘病毒，并且默认开启。

  

同时，用户若想要指定U盘才可以接入电脑，只需在**家长控制——设备使用控制**中设置信任U盘。火绒安全软件将帮助你阻拦陌生U盘接入，将威胁拦截在外。

  

![](../Images/1ae8d5726cd51ea6d9773c325c2ae009.png)

 

**3.流量悬浮窗——流量去向全监控**

 想要随时监控流量去向，了解程序流量情况，右键火绒安全软件托盘程序，开**启流量悬浮窗**即可随时监控流量信息。  

 

![](../Images/d24ce3c35de29444e774c48eac646909.png)

  

**4.网络流量——网络管理不阻塞**

通过流量悬浮窗监控后，到**拓展工具——网络流量**功能管理可以更好地控制上网的程序。设置限制网速或结束进程，防止网络阻塞。  

  

![](../Images/85ea98465585cc765747ce7a9d9c03db.png)

  

![](../Images/5ff28129a0ae274ed2a242a1467c42b5.png)

  

**5.文件粉碎——彻底删除防恢复**

 在使用电脑过程中，有部分不需要的文件，但是通过常规删除，无法删掉。此时打开拓展工具——文件粉碎即可彻底删除，并且防止被技术手段恢复，稳定安全。

PART2：常见问题

**1.火绒剑在哪里安装？**

**答：火绒剑包含在火绒安全软件内。是火绒安全软件得一个扩展工具。**目前没有独立版。也请大家不要搜索和下载所谓得独立版。  

前段时间，火绒就截获了一批伪装成“火绒剑”安全分析工具的病毒样本。此类样本是将“火绒剑”的部分文件“再打包”后生成的，安装后不但无法正常运行，还会被捆绑后门病毒。请大家注意。

 

2\. 虚拟沙盒功能在哪？

  

答： 火绒在检测一个文件是否是病毒的时候，扫描引擎会构造虚拟沙盒，让程序跑在虚拟沙盒跑出解密代码和行为特征。**此功能为火绒扫描引擎自带，无需设置。**

**3.火绒和 Windows Defender 不能共存？**

答：因为火绒是经过微软认证的安全软件。**所以在安装火绒后，微软会自行关闭Windows Defender。**并非火绒自身原因。这个情况微软官方也有所解释：

  

> 如果你安装其他反恶意软件程序来保护你的电脑，WindowsDefender 和 Microsoft Security Essentials 将自行关闭。

 

4\. 软件界面显示“安全服务异常，无法正常启动”怎么办？

  

答：**重启计算机即可解决。**两种情况可能会导致此问题：

       3.0卸载（卸载完未重启电脑）安装火绒4.0

       4.0卸载（卸载完未重启电脑）重新安装4.0。

   

5.为什么火绒扫描时cpu很高？

答：火绒在高速扫描的时候会尽可能的使用CPU资源，所以在高速扫描的时候CPU占用较高是**正常现象。**
