# 犯下超5万起网络犯罪的黑客被逮捕

  
据报道，法国当局新近抓获了一名黑客，名为Julius Kivimäki（化名“Zeekill”），曾犯下五万多起网络犯罪事件。其所在的网络犯罪组织曾对PlayStation和Xbox在线游戏服务发起DDoS攻击，还对载有索尼在线娱乐总裁的飞机发出炸弹威胁。2015年，他因涉嫌犯下超过五万起计算机入侵事件而被定罪，当时17岁的他被判处了两年有期徒刑缓刑。2020年10月，Kivimäki入侵芬兰首都的私人心理治疗中心，盗取了超过两万名患者的相关信息。由于该治疗中心拒绝支付高达六位数的赎金，Kivimäki将所有患者记录的大型压缩文件上传到了暗网，但他不小心附上了一份自己主文件夹的副本，从而被安全专家追踪到。目前，芬兰警方表示已逮捕该黑客，并正在走引渡程序。

# LockBit宣布对英国皇家邮政的攻击负责

  
近日，LockBit勒索软件组织承认对英国最大的邮政企业皇家邮政（Royal Mail）进行网络攻击，导致该公司因“严重服务中断”而停止其国际航运服务。该勒索组织表示只会在皇家邮政支付赎金后提供解密器并删除窃取的数据。2月6日，LockBit数据泄露网站的条目显示，英国皇家邮政的被盗数据将于2月9日在网上公布。目前，皇家邮政仍将这起事件模糊地描述为网络事件，试图淡化勒索攻击带来的影响，并表示已经恢复了部分受影响的服务。

**国内知名金融机构因违规查询个人信息被罚75万**

  
近日，央行长沙中心支行发布的惩罚信息显示，长银五八消费金融因存在未经同意查询个人信息的违法违规行为，被罚款75万元。与此同时，此次罚单实施了“双罚制”，对机构和相关负责人同时进处罚。据了解，这并非长银五八消费金融首次被罚。2021年7月15日，银保监会湖南监管局公布的行政处罚罚单显示，因贷后管理不到位，长银五八消费金融被处以罚款30万元。

Twitter遭遇史上最大规模的宕机

  
据报道，2月8日全球最大的三家社交媒体平台遭遇宕机，Twitter、Instagram和YouTube的部分用户无法访问其账户。据了解，这是Twitter16年历史上最大规模的一次宕机。许多Twitter用户8日收到一条消息提示称“已超过每日推文发送限额，无法发帖。”当天，YouTube和Instagram用户也同样遭遇了宕机。YouTube的宕机时间很短，但规模较大，8点后恢复了正常。

韩国移动运营商29万用户数据遭泄露

  
据报道，韩国移动运营商LG Uplus上个月的数据泄露事件可能影响约29万名用户。1月初，该移动运营商曾透露约有18万条客户信息遭泄露，包括姓名、出生日期和电话号码等，但不涉及财务信息。近日，该公司在其网站上表示，发现了另外11万条已终止订阅的用户的数据也受到了影响。目前，LG Uplus正在积极配合当局的调查。
