CS:GO 皮肤交易网站被黑

微软员工在 GitHub 上意外泄漏登录凭据



据报道称，微软员工意外在GitHub平台上暴露了公司在线基础设施的敏感登录凭据。这些凭证首先由网络安全研究公司 spiderSilk 发现，随后由微软证实。据了解，泄漏的凭据与微软官方 tenant ID 有关，tenant ID 是链接到一组特定 Azure 用户的唯一标识符。
