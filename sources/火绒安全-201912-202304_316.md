# 国产化适配版图再扩大，火绒与联想产品完成兼容互认证

4月8日，火绒终端安全管理系统1.0版（以下简称“火绒企业版1.0”）与联想旗下产品（超融合AIO平台）完成兼容互认证，“火绒企业版1.0”可与联想该产品相互适配、稳定运行。  
  
至此，火绒适配联想产品范围再度拓展，与联想的生态协作伙伴关系稳固加深，这表明了火绒国产化兼容、适配进程再次向前迈进，更标志着火绒正在快速、高效、全面地推进国产化适配战略部署。![](../Images/78fe3c0777bb5be27987ba97fd93ddb0.png)兼容认证书上表示，“火绒企业版1.0”拥有高效的终端管理、防御功能，能够通过“控制中心”派发安全策略，同时具备规范外接设备使用、提供远程桌面服务、进行异地终端管理等功能，将企业网络纳入严密的防控之中，确保安全无死角，充分满足企事业用户在目前互联网环境下的电脑终端防护需求。  
火绒企业版自2018年推出至今，已有数万家机构单位选择使用，覆盖了政府、医疗保健、金融服务等50余类细分行业，火绒用品质赢得了用户的口碑与认可。  
现如今，火绒国产化适配版图持续扩大。火绒企业版产品早已完全适配UOS、鲲鹏、深度、红旗、中标麒麟、优麒麟、银河麒麟、神州网信、联想超融合AIO平台等众多国产化操作系统，吸引了一批诸如联想、天融信、迪普科技、安恒信息、杰思安全、奇安信、安天等同行成为合作伙伴并向其进行引擎赋能。不忘初心、牢记使命，未来，火绒将继续发挥自身独特技术优势，持续赋能国产化生态，将安全服务和防护辐射到更多不同行业的用户终端上，筑牢“国产化”安全防线。
