勒索软件团队ZIGGY宣布关闭

并公布解密密钥

勒索软件开发团队ZIGGY日前宣布公布所有解密密钥 , 该团队提供的数据库共包含 922 个解密密钥分别对应922名受害者。同时开发者还提供解密器指导受害者将解密密钥与主密钥配合使用。随后安全专家进行测试后证实解密器和密钥是真的。据悉，由于最近执法机构抓捕了Emotet和Netwalker勒索软件的开发者, 这引起该开发团队的担心。另外，为继续降低被抓的可能性该勒索软件团队还准备向所有受害者退款，受害者只需要提供截图和电脑编号发送到指定邮箱即可。

玩家对《Apex英雄》服务器进行DDoS攻击

近日，“Apex英雄”游戏工作室Respawn封禁了两名其Xbox 上的玩家，他们被发现为了赢得比赛而对游戏服务器进行 DDoS 攻击。有网友在 Reddit 上称，在一场比赛中，一名玩家被击倒后，服务器突然崩溃了。当该网友重新连接到服务器时，发现自己已经被击倒，而此前被击倒的玩家复活，他的队友就站在自己面前。这两人被其他玩家指控称，对游戏进行 DDoS 攻击，以获得胜利。近来针对主机版《Apex英雄》的 DDoS 攻击愈发普遍，Respawn 表示将会严厉打击这些行为。

注：DDoS 攻击指分布式拒绝服务攻击，是控制多个计算机用海量请求淹没服务器，从而使其他用户无法访问服务器。

微软多项网络服务疑似因DNS系统出现故障


近日，微软发布公告表示，由于DNS 服务系统出现异常，其许多网络服务出现故障。这些服务包括Microsoft 365、Microsoft Teams、Xbox以及必应搜索，其中受影响最严重的是Microsoft Teams服务，据网友反馈该服务几乎无法使用，即不能正常接受和发送消息。目前，报告问题的用户在微软部署缓解措施后已经在逐渐降低，另外如果用户当前访问仍然出现故障请等待片刻，待系统缓解刷新到全球所有节点后即可恢复正常访问。对此，微软表示其正在进行调查，有关相关故障问题企业管理员可在管理中心跟踪此事件调查报告。

黑客入侵 PHP 的 Git 服务器

试图提交后门代码

近日，PHP 团队发现其 git.php.net 服务器被入侵，官方仓库中出现了两个恶意提交，并且这些提交伪造了 PHP 开发者和维护者的签名。目前，PHP 仍然是服务器端主要的编程语言，为互联网上超过 79% 的网站提供支持，如果没有发现该后门代码，后果将非常严重。此外，PHP 团队表示以后所有修改会直接推送到 GitHub 上，不再是 git.php.net 服务器上。因此，今后想为 PHP 做贡献的人需要先通过双重身份认证加入 GitHub 上的 PHP 组织。据悉，PHP 团队正在审查仓库中是否有其他恶意代码。

《使命召唤：战争地带》作弊软件

被发现含恶意软件

近日，动视公司发现了针对《使命召唤：战争地带》作弊者的恶意外挂软件。安全研究人员发现，作弊论坛上宣传的一款Warzone作弊软件器中含有隐藏的后门，这可以使攻击者在受害者的电脑上安装矿机，利用游戏玩家的显卡来开采加密货币。动视指出，大多数作弊器通常会建议用户禁用反病毒软件，以确保在用户在不知情的情况下运行恶意软件。该游戏自推出以来，因作弊问题，动视已在全球范围内封禁了30万人，其中6万人在一天内被封。
