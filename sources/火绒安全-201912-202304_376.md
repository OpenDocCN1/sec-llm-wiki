**CAPCOM 公司内部服务器遭到入侵**

![](../Images/180cd5d7b2be1d7d2f5253c4016c44fa.png)

近日，日本知名的游戏公司CAPCOM发布公告，表示公司内部的邮件和文件服务器遭到了未被授权的第三方访问，事件发生后该公司立刻停止了集团内部部分网络。目前尚未发现用户资料和信息被盗取的证据，据了解，这次网络攻击没有影响该公司旗下游戏的网络功能。但和以往黑客的大规模攻击不同，这一次针对该公司内部服务器的黑客行动显然是冲着内部资料来的，该公司表示将联合警方进行调查。如果此次服务器入侵真的获得了部分CAPCOM内部资料，那么很可能最近就会有《生化危机4重制版》等新作游戏的传闻。

**虚假马斯克账户借特朗普推文行骗 数小时**

**获利逾25万**

![](../Images/2d50056e12b73036594b0939a18c2a49.png)

近日，一名骗子利用名为马斯克的账户，在特朗普的推文下回复称选举基本上大局已定，为了庆祝大选，他将向用户赠送礼品，并给出了指向musk-coins.com的链接。相关人员发现该链接会把用户引流到一个网站，要求用户提供自己的比特币，以获取更高的回报。骗子在骗取价值3.2万美元的比特币和价值6000美元的以太坊（总价值约合人民币25万元）后，修改了他的Twitter账户名称，并删除了网站。据悉，在Twitter采取措施前，4小时内约有300名用户上当受骗，发送给黑客价值111.8万美元的比特币。

**瑞典最大保险公司泄露用户数据 ****近百万客户个人信息流入社交媒体**

![](../Images/bf06e0dd536a8685fed5e043ccbe7aa0.png)

据报道，瑞典最大的保险公司Folksam在新闻稿中证实，近100万客户的个人信息已泄露给Facebook和Google等社交媒体，其中一些被视为敏感的个人数据，例如某人购买了工会保险或怀孕保险，以及特别值得保护的个人数据——个人社会保险号。对此Folksam表示歉意，并要求已收到个人信息的合作伙伴将其删除。据悉，从Folksam接收个人数据的公司有Facebook，Google，Microsoft，Linkedin和Adobe。目前，没有信息表明该信息已被第三方以任何不当方式使用。

**谷歌再次公布Github尚未修复的漏洞**

![](../Images/5cb088c2fa80d35ba3f0742a403d50b6.png)

近日，谷歌旗下安全实验室披露了微软旗下代码托管平台 Github 中存在一个高危漏洞。据谷歌公布的信息表示，攻击者可以利用该漏洞进行注入攻击。该漏洞危害性较高，但修复难度也很大无法及时修复。为此在90天的保留时间里该平台请求谷歌延迟14天披露 ,但该平台试图再次申请延迟时，谷歌认为有违标准的漏洞披露流程，谷歌最终披露了漏洞详情和概念验证代码。目前 Github 已经公布修复程序并要求使用者立即升级封堵漏洞，接下来该公司还将继续发布修复程序解决问题。

**臭名昭著的勒索软件组织Maze宣布“正式关闭”**

![](../Images/29efdf6394a7b17d71455131d839626e.png)

据报道，臭名昭著的勒索软件组织Maze于近日宣布“正式关闭”。在过去一年中，该组织已针对大量目标公司发起了攻击，包括钢铁巨头华森集团，佳能，LG电子等。Maze的做法很激进，他们首先泄漏受害者的部分数据，并威胁他们如果不支付赎金就会公开这些数据。据了解，该组织曾向一家佐治亚州的电线和电缆制造商索要600万美元，并向一个未具名的组织索要 1500 万美元。相关人员表示，Maze 的这次退休是将信将疑的，可能已经赚够了钱，不过更大的可能是他们要重新命名，与另一个团体结盟。
