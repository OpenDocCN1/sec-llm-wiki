# 加速球是否真的优化了内存和结束无用的进程呢？

 一般大家的计算机内存有8G、16G等，这部分内存我们称之为物理内存。但其实程序对内存的需求却远大于这些数值，那么怎么办呢？系统就使用了名为“虚拟内存”的技术， 同时系统还会划出一部分磁盘空间当作“内存”去使用，满足了程序对内存的需求。

  

当程序运行时，常访问的数据会被加载到物理内存中，不常用的数据则会被放到这部分“内存”，也就是磁盘上。同时，系统会根据程序对数据的需要实时做动态调整，这个过程就比较复杂啦。可以简单理解为：“内存不够，磁盘凑”。

  

\# 那么加速球“优化”内存的方法是什么呢？

是将它认为不常用的数据从内存强制调回磁盘。这个方法虽然从视觉角度上看直接有效，但却有点“一刀切”，因为加速球无法判断程序下一时刻需要用到哪些数据。所以很可能加速球“优化”后，程序要用到的数据恰巧被它“腾走了”，还需要重新将数据从磁盘调到内存中。如此频繁的读取磁盘反而会降低程序的执行效率，还会干扰系统对程序的内存管理。

\# 结束“无用”进程就更简单粗暴了

刚才我们提到，程序执行的过程中会调用数据到内存。那直接把程序退出，自然就会减少内存占用了。但是就和刚才说的一样，具体哪个进程属于“无用”，加速球无法准确判断。如果结束的并不是无用的进程的话，当程序再次被打开，那么就又重复了刚才的问题……

\# 那么我的电脑真的卡顿应该怎么解决啊？

如果是因为电脑配置不足导致经常卡顿的情况，使用加速球是可以达到暂时缓解的效果的。但是这也是治标不治本。所以想要加快这类电脑运行速度，还是建议进行扩充内存或升级电脑。

  

如果你电脑配置足够还卡顿，并且出现很多广告弹窗和没见过的程序，可能是因为安装了流氓软件或者使用过下载器。那些没见过的程序和广告弹窗多了，就会占用大量内存，就有可能出现卡顿的情况。“加速球”优化或者关闭这些进程后，是会有一定加速效果的。但是广告弹窗和捆绑安装的程序并不会因为用户点了加速球就束手就擒，很大概率会再次启动。所以解决这类软件仅通过“加速球”其实是搞不定的，这个时候需要用到哪个软件？？你们懂的。
