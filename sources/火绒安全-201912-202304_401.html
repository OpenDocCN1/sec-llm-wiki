加拿大税务网站被攻击 黑客入侵账户给自己发救济金


加拿大联邦官员表示，加拿大税务网站遭黑客攻击，11200个账户被入侵，黑客利用漏洞访问政府网站并给自己重新发放紧急救济金。此次攻击是“凭证填充”的一种形式，黑客通过这种方式欺骗性地获取用户名和密码，并利用了许多人在不同账户上使用相同密码这一点，获得利益。信息显示，2020年共有1.3万多名加拿大人成为欺诈行为的受害者，总金额为5100万加元（约合人民币2.55亿元），共有1729名为涉及新冠肺炎欺诈的受害者，其受骗金额达到555万加元（约合人民币2775万元）。

影像IT巨头柯尼卡美能达遭新型勒索软件攻击


近日，影像IT巨头柯尼卡美能达遭新型勒索软件（RansomEXX）攻击。该勒索软件的扩展后缀为“ .K0N1M1N0”。它以企业为目标，但是和其他勒索软件不同的是，该勒索软件需要人为纠正。黑客入侵企业网络潜藏，并通过时间的流逝，再传播到其他设备以获取管理员位置。一旦获得管理员权限并访问Windows域控制器，他们便可以在网络上部署勒索软件并提供所有设备进行加密。目前柯尼卡美能达表示正在努力解决问题。

新型加密挖矿蠕虫可扫描和窃取AWS凭证


近日，安全研究专家发现了疑似首个新型加密挖矿恶意软件，该组织者TeamTNT（主要针对 Docker 安装的网络犯罪集团）的运作方式是在互联网上扫描那些被错误配置的 Docker 系统，并在没有密码的情况下将其管理 API 暴露在互联网上。报告称，该恶意程序的攻击范围扩大到了 Kubernetes 安装。此外，相关人员发现它的另一个严重功能，即可以扫描底层受感染服务器的任意亚马逊网络服务（AWS）凭证。

Mac恶意软件通过Xcode项目传播 滥用WebKit、Data Vault漏洞


据报道，安全人员在多个 Xcode 项目中发现了 XCSSET 恶意软件系列，以及导致恶意有效荷载的兔子洞（rabbit hole）。该恶意软件能够劫持Mac上的Safari和其他浏览器，以便窃取密码、金融数据和个人信息，部署赎金等。另外，在其中一个开发者项目中“不寻常”感染还发现了两个零日漏洞（WebKit、Data Vault漏洞）。该漏洞允许它绕过MacOS的系统完整性保护(SIP)功能来窃取Safari cookie，解决沙箱问题。到目前为止，这些项目被认为未被其他开发人员广泛使用，从而限制了不良的影响。

FritzFrog僵尸网络正通过SSH感染我国Linux服务器


近日，研究人员发现了一个名为FritzFrog的新型无文件P2P僵尸网络，该僵尸网络一直积极地瞄准全球的SSH服务器，其中，北美、中国、韩国是重灾区。作为一种模块化、多线程、无文件的 SSH Internet 蠕虫，FritzFrog 通过破坏公共 IP 地址来发展 P2P 僵尸网络。相关人员表示：建议选择强密码并使用公共密钥身份验证，这更加安全。路由器和IoT设备通常会暴露SSH，请考虑更改其SSH端口或完全禁用对它们的SSH访问。”
