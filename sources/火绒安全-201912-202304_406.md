# **50多家科技公司源代码泄露：华为海思、联想、高通均在列**

近日，华为海思、联想、高通等50多家公司相关的源代码被泄露在网上。遭泄露的源码被发布在 GitLab 上一个公开存储库中。这些源代码是开发人员兼逆向工程师Tillie Kottmann从各个来源收集的，因为不安全的DevOps应用程序导致公司专有信息暴露。目前，Kottmann 已应部分企业的要求删除了代码。例如梅赛德斯-奔驰的母公司和联想的文件夹。

# **Facebook成功阻止欧盟反垄断数据要求：伤及用户隐私**

据报道，Facebook今日赢得了一项法院命令，要求欧盟暂时停止向Facebook索取更多数据。Facebook认为欧盟在调查时所要的数据过于高度敏感，已经超出了必要的范围，可能伤害用户隐私。欧盟中级法院“综合法院”（General Court）近日裁定，欧盟需在举行全面的听证会之前，暂时停止向Facebook索取更多数据。分析人士称，综合法院的这项裁定，可能会挫败欧盟委员会调查Facebook的相关努力。 原出处：新浪科技、Hackernews相关链接：https://tech.sina.com.cn/i/2020-07-28/doc-iivhvpwx7931051.shtmlhttp://hackernews.cc/archives/31451

# **云计算软件服务商遭勒索软件攻击 众多大学和非盈利组织受影响**

据报道，包括伯明翰大学、伦敦大学在内的超20所英美加大学以及其他非营利组织的云计算软件服务商（Blackbaud）遭到勒索软件的攻击。被窃取的数据包括了电话号码、捐赠记录等，以及寻求经济支持的学生信息。Blackbaud声称在支付赎金之后，攻击者毁掉了窃取的数据拷贝。  原出处：新浪科技相关链接：https://tech.sina.com.cn/roll/2020-07-26/doc-iivhvpwx7561557.shtml

# **科技独角兽Dave承认出现安全漏洞 750万用户受影响**

近日，继黑客在一个公共论坛上公布了应用程序DAVE的750万名用户信息后，该应用证实了自身存在安全漏洞。泄露的数据包括真实姓名、电话号码、电子邮件、出生日期和家庭住址，甚至银行卡信息，DAVE表示这些信息是加密的，安全漏洞源于前业务合作伙伴Waydev的网络，目前未有证据表明黑客利用这些信息对用户账号进行未授权的行为。
