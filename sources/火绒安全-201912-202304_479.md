# 这里有份远程办公风险与防护指南 请查收

疫情之中，远程办公成为目前的主要办公方式，相信不少员工也是初次体验如此长时间的远程办公，甚至设备也是临时借来的，这也导致一些安全风险随之而来。在此，小编也为大家准备了一份远程办公可能存在的风险与相关防护建议，希望帮助大家安全、安心的办公。

 

**一、勤消毒：保持终端安全干净**

使用个人电脑，尤其是借用他人设备接入公司内网（VPN）时，如果携带病毒、木马，将会通过内网横向传播给企业终端。

  

因此，在远程办公时，要先使用安全软件对电脑进行全盘扫描杀毒，确保有一个安全无毒的办公环境。

 

**二、戴口罩：远程工具做好防护**

远程办公少不了使用远程工具，包括Windows系统自带的“远程桌面”（RDP）功能，以及TeamViewer等第三方远程工具。使用这些功能的时候，需要开启3389等远程端口，黑客可以通过暴破、撞库等方式入侵终端。

  

对此，我们需要保存好此类工具的登录凭证，设置高强度的密码，给此类工具带上安全防护口罩，防止病毒出入。

 

**三、多洗手：时刻保持个人安全意识**

远程办公时，缺少专业的安全管理人员维护，个人要时刻保持高度安全意识。不随意点击不明网址、邮件，不下载可疑附件，防止被钓鱼攻击。也不使用陌生的U盘等外接设备，保证公私数据有序分开使用。

 

**四、不聚集：保护其它终端安全**

在远程办公过程中，如果发现终端存在漏洞攻击、重要文件感染病毒，以及其它安全威胁出现时，要及时通知管理人员进行处理，并根据实际情况选择是否更改为线下办公，避免其它终端被攻击、感染的风险，做到不聚集、快上报。

 

最后，愿新型冠状病毒在全国医护人员的奋战下，在所有安静在家参与远程办公员工协同防护中，逐渐消散，也希望大家工作有条不紊，如果遇到任何终端安全问题，欢迎随时联系火绒获得解决。
