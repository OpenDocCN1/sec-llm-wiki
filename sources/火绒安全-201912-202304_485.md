# Windows 7用户请放心 火绒依旧为您提供支持服务

1月14日，微软正式宣布不再为Windows 7（下称Win 7）系统提供技术支持与更新，这也意味着Win7系统将失去官方维护，面临更多的未知风险。根据用户反馈和关心的后续安全防护问题，我们回复如下：

  

1、火绒依旧持续为Win 7系统提供安全防御。

一直以来，火绒与微软提供的补丁更新保持同步状态，用户使用火绒即可获得微软官方补丁。如果将来微软再次给Win 7系统提供特殊紧急补丁时，火绒也会及时跟进更新。  

  

2、对于微软未就Win 7安全问题提供安全方案，火绒也会通过升级增强防御，保护用户终端安全。

  

3、火绒产品（个人版、企业版）的技术、功能升级针对所有目前支持的系统，包括Windows XP与Win 7与在内。

  

目前来看，虽然微软不再维护Win 7系统，但国内依旧有很多用户在使用这一经典系统，特别是对于配备该系统的老旧机器用户，以及对兼容性、稳定性有较高要求的医院、学校、银行与政企等单位。

  

对此，火绒拥有轻量的体积与数次优化后稳定的性能，不占用过多的空间，可以满足老旧设备的运行条件；此外，火绒目前的主防策略中也包含了众多对Win 7等老旧系统防护的实用功能，比如“网络入侵拦截”功能可以在系统无论是否打补丁的情况下都能阻止相关的漏洞攻击。

  

如果您有任何关于Win 7防护问题，或者对火绒使用问题，请随时联系我们解决，感谢您选择火绒。
