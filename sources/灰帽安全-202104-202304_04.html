以下分为两种方案注册OpenAI流程

第一套方案：

1.第一步先获取自己的openAI 的 API key 点击获取:https://platform.openai.com/account/api-keys,如果你之前没注册账号，请先免费注册，如果是大陆用户，需要使用【虚拟手机号关注灰帽安全回复：虚拟手机号码】接受短信验证码

2.第二步，需要一台VPS，低配的足够使用，如果你没有需要购买阿里云、腾讯云、华为云、天翼云等（海外版本建议必须需要支持openai才行咯）， 你可能需要的SSH远程连接软件: Putty 【官方下载】：https://www.putty.org/

3.一键安装 Docker，一键安装命令如下：

curl -fsSL https://get.docker.com -o get-docker.sh sh get-docker.sh

4.使用开源程序进行搭建ChatGPT 【开源项目】安装命令如下：

https://github.com/Chanzhaoyu/chatgpt-web

docker run \        --name chatgpt-web \        -p 3002:3002 \        --env OPENAI_API_KEY=Your key \        --restart always \        -d chenzhaoyu94/chatgpt-web:latest

最后安装好以后，直接访问你VPS的ip: http://xxx.xx.xx.xx:3002 即可
