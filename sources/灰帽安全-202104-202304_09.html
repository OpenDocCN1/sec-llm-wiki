Chatbot UI 是一个高级聊天机器人工具包，适用于 OpenAI 的聊天模型，它使用 Next.js、TypeScript 和 Tailwind CSS 在Chatbot UI Lite之上构建。它旨在模仿 ChatGPT 的界面和功能。所有对话都本地存储在您的设备上。部署也非常方便，结合 Vercel 可以一键部署，小白也能学会

已有的功能(持续更新功能中)：1. 搜索聊天内容 2. 导入/导出聊天 3. 自定义系统提示 4. GPT-4 支持（需要访问权限） 5. 搜索对话 6. 代码语法突出显示 7. 切换侧边栏 8. 对话命名 9. 在应用程序中添加 OpenAI API 密钥 10. Markdown支持
