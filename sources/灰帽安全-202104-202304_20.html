ChatGPT绑定到公众号流程

Github代码

首先，我们需要使用到github上的一份第三方代码，这份代码将 AI模型 接入各类 消息应用，开发者通过轻量配置即可在二者之间选择一条连线，运行起一个智能对话机器人，在一个项目中轻松完成多条链路的切换。该架构扩展性强，每接入一个应用可复用已有的算法能力，同样每接入一个模型也可作用于所有应用之上。

它可以支持：

  • 微信

  • 公众号

  • Telegram

  • QQ

  • Gmail

等等，未来还会支持更多的平台。

项目地址：https://github.com/zhayujie/bot-on-anything

OpenAPI地址

需要一个chatGPT账号并生成一个API Key，这个API secret Key是为了验证你的身份。

这个非常简单，我们打开openai的平台地址：https://platform.openai.com/

项目代码克隆：

第一步下载代码

git clone https://github.com/zhayujie/bot-on-anythingcdbot-on-anything/

第二步进入目录

cd bot-on-anything/

第三步进行复制配置文件

cp config-template.json config.json

第四步进行修改配置文件以下例子只保留微信公众号（里面有各种各样的配置）：

安装依赖

升级pip包管理工具和安装openai

第一升级pip包管理工具

pip3 install --upgrade pip

第二安装安装openai

pip3 install --upgrade openai

安装 werobot 依赖：

pip3 install werobot

运行程序

python3 app.py

3.使用

用户关注订阅号后，发送消息即可。

注：用户发送消息后，微信后台会向配置的URL地址推送，但如果5s内未回复就会断开连接，同时重试3次，但往往请求openai接口不止5s。本项目中通过异步和缓存将5s超时限制优化至15s。所以需要点击继续主动拉取缓存信息。待后续优化。
