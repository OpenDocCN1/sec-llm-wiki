**0x01**  **前言**

  

MS Office docx 文件可能包含作为 HTML 文件的外部 OLE 对象引用。有一个 HTML 场景 ms-msdt: 调用 msdt 诊断工具，它能够执行任意代码（在参数中指定）。  
结果是一个可怕的攻击向量，通过打开恶意 docx 文件（不使用宏）来获取 RCE。  
**通俗来说就是调用远程html文件来执行任意代码。**

**0x03**  **漏洞复现**

  

首先生成一个插入了OLE链接的docx文档。  
新建一个docx后缀的word文档。

![](../Images/7a7db87bfe3af943fd22c21716a69b7b.png)

  

使用office word打开新建的文件，插入OLE链接。

具体插入流程为顶部工具栏 **插入-对象**

![](../Images/9a35065aef83e23bc766ad984f2d6db1.png)

随便插入一个对象后保存，使用解压软件打开。（word文件可以看作是一个压缩包）

![](../Images/8cd22b030cd60ecde065f7e2a76bf48f.png)

打开后首先进入 word/\_rels/document.xml.rels 文件（使用文本编辑器打开）

![](../Images/bf5ae8cd8613432896747db02bb8ab16.png)

全文搜索ole定位到我们该刚刚插入的链接位置。

![](../Images/95c7ac1f5bc4fb14cae69e8b889d565a.png)

注意当前Relationship标签的id值，通常是rid5，接着修改当前标签中**Target**的值，并新增属性**TargetMode**

*   
*   

```
Target="http:///poc.html!" TargetMode="External"
```

![](../Images/405b5474af2728560d6b42d76b5447fd.png)

修改完后保存并更新目录，接着修改 **word/document.xml**文件，全文搜索rid5（上一个文件对应的id值）

![](../Images/1ef5e276d4d93104fd9fbb0c5b54e27b.png)

修改该标签内**Type="Embed"**为**Type="Link"**并新增属性**UpdateMode="OnCall"**

![](../Images/1315bc8295cfb0b4323459bc84f205c4.png)
