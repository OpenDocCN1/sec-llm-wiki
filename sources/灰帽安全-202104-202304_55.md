一、模拟器安装frida-server

打开夜神模拟器>进入设置>点击版本号5次>激活开发者模式>进入开发者模式>打开USB调试功能。

![](../Images/ae022e46af007d3ac48c3488b03f5898.png)

  

![](../Images/b4d8b80266d9bef1c8430de80afc31ff.png)

打开USB调试

![](../Images/7025a1f586325b638a519ee59c9ae925.png)

  

二、查看连接设备

进入夜神模拟器安装目录下的bin目录查看到有adb.exe和nox\_adb.exe，用其中一个都可以。  

*   
*   
*   

```
adb.exe devices或nox_adb.exe devices
```

![](../Images/c2d21476c271f832094c6ffb6a7a9ac0.png)

看到已经有设备了。


注:Frida-server的版本必须跟你宿主机的Frida版本一致。

  

四、进入shell运行Frida-server  

*   
*   
*   
*   

```
adb.exe shellcd /data/local/tmpchmod 777 frida-server./frida-server
```

![](../Images/6487311c02469241801a713d9126b21c.png)

新建一个adb shell

*   

```
adb.exe shellps | grep frida-server
```

![](../Images/5baf0b237943dcdf95f96dce8a1c78be.png)

正在运行的进程，说明frida-server启动成功。

*   
*   

