0x01 前言

利用Python对shellcode进行XOR，然后使用WINAPI来创建进程注入二进制文件，这是总体思路。

我通过CobaltStrike生成shellcode，写一个Python脚本来对shellcode进行XOR处理

raw_shellcode = "Shellcode Payload"
enc_shellcode = []
for opcode in raw_shellcode:
        enc_opcode = (ord(opcode) ^ 0x41)
        enc_shellcode.append(enc_opcode)
        
print ("".join(["\\x{0}".format(hex(abs(i)).replace("0x", "")) for i in enc_shellcode]))

0x03 WINAPI

准备一些WINDAPI来创建进程注入二进制文件

OpenProcess

https://docs.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-openprocess

HANDLE OpenProcess(
  DWORD dwDesiredAccess,
  BOOL  bInheritHandle,
  DWORD dwProcessId
);

使用OpenProcess通过为其提供该进程的 PID 来打开该进程。因为进程注入的主要思想是在本地进程中为 shellcode 创建一个新的分配空间，然后在该分配中写入 shellcode 并执行它

VirtualAllocEx

https://docs.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-virtualallocex

LPVOID VirtualAllocEx(
  HANDLE hProcess,
  LPVOID lpAddress,
  SIZE_T dwSize,
  DWORD  flAllocationType,
  DWORD  flProtect
);

在另一个进程中使用VirtualAllocEx为 shellcode 分配一个新的内存空间

WriteProcessMemory

https://docs.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-writeprocessmemory

BOOL WriteProcessMemory(
  HANDLE  hProcess,
  LPVOID  lpBaseAddress,
  LPCVOID lpBuffer,
  SIZE_T  nSize,
  SIZE_T  *lpNumberOfBytesWritten
);

使用WriteProcessMemory通过VirtualAllocEx在另一个进程中创建的新分配中编写Shellcode

VirtualProtectExhttps://docs.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-virtualprotectex

BOOL VirtualProtectEx(
  HANDLE hProcess,
  LPVOID lpAddress,
  SIZE_T dwSize,
  DWORD  flNewProtect,
  PDWORD lpflOldProtect
);

使用VirtualProtectEx来更改保护权限

CreateRemoteThread

https://docs.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-createremotethread

HANDLE CreateRemoteThread(
  HANDLE                 hProcess,
  LPSECURITY_ATTRIBUTES  lpThreadAttributes,
  SIZE_T                 dwStackSize,
  LPTHREAD_START_ROUTINE lpStartAddress,
  LPVOID                 lpParameter,
  DWORD                  dwCreationFlags,
  LPDWORD                lpThreadId
);

CreateRemoteThread创建一个在另一个进程的虚拟地址空间中运行的线程，并可选择指定扩展属性。

CreateThread和CreateRemoteThread的区别在哪里？

CreateThread 只允许你为当前进程创建一个线程。

CreateRemoteThread 允许你为另一个本地进程创建线程。
