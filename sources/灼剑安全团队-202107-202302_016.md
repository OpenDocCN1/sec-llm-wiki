### **一、背景**

在做攻防项目的时候发现了一个外网的向日葵命令执行

![](../Images/1526b37a0c40ab8f659ca447f7733f90.png)

  

但由于存在杀软，无法执行命令

![](../Images/4e87c4a6625e911466a1b1489e755074.png)

下面就来说一下我是如何绕过杀软拿到shell的

  

### **二、测试**

#### **2.1 本地环境调试**

自己搭了一个虚拟机，也是存在漏洞的向日葵命令执行，环境配置和目标一样，但没装360（后面会说是如何获得目标系统信息的）

  

开始测试，发现

*   `failed,error 5`：表示命令执行失败，其实就是杀软拦了
    

![](../Images/8099e35d48b0ac1d78d8c00b586242ad.png)

*   `failed,error 2`：表示命令不存在
    

![](../Images/099a7644375ca8324f1f9e8c327c3f8d.png)

  

#### **2.2 了解向日葵漏洞**

首先我通过向日葵和杀软允许的`ping`命令判断确认是存在命令执行漏洞的

![](../Images/86f10ffe9618640f28eaf3316e18c7b8.png)

  

#### **2.3 然后尝试绕过杀软**

1.  通过网上搜索各种文章，晓得是利用向日葵不禁止`ping`命令，然后通过`../`进行目录穿越来执行任意命令的。
    
2.  目标机器上的杀软实际上是禁止调用`cmd.exe`和`powershell.exe`等危险的进程，其他exe程序并没有禁止
    
3.  所以我们可以利用`C:/Windows/System32/`或`C:/Windows/SysWOW64/`目录中的exe文件，来进行信息收集
    

![](../Images/276c9c4215e77d25256bc3d0bc22e1d8.png)

  

#### **2.4 目标机器信息收集**

利用`systeminfo.exe`来获得操作系统信息：Windows Server 2008。

![](../Images/9aa6a680de4b58c3e630fc371e3e3496.png)

  

利用`netstat.exe`来获得网络状态信息

![](../Images/f995e081a817a58a4c77f6fb7b8dfc7b.png)

  

利用`tasklist.exe`来获得进程信息，发现存在360全家桶，命令执行就是他拦截的

![](../Images/b79335d2af536c520a0f3af8de4b8e62.png)

  

利用`ipconfig.exe`获得ip信息

![](../Images/da92872c173ab93a384e1099e94dbd08.png)

  

利用`arp.exe`获得内网其他IP

![](../Images/8a6c1b1edbe1dc4db50783016b9a6992.png)

  

  

利用`net.exe`获得用户信息

![](../Images/24d4de2af86b5666ffc45d7c27075ebb.png)

  

#### **2.5 实现文件读取，读取向日葵配置文件**

既然已经可以执行部分命令了，首先我的思路是利用文件读取的命令，直接读取向日葵配置文件，利用配置文件中的fastcode和密码直接连接向日葵。

  

windows机器上查看文件是使用`type`命令，但并不存在`type.exe`

![](../Images/c596ed9258b961950593ab39a856ca70.png)

  

所以如何读取文件内容便是个问题。上网搜索，网上说用`wmic`可以实现列磁盘和文件读取写入等操作

*   
*   

```
# 列磁盘wmic logicaldisk get caption,name
```

![](../Images/a354d8356597c53a5729d32c7ea986a6.png)

  

很明显，`wmic`被拦截了，无法使用

此时我又想到了windows用来进行字符串匹配的`findstr`命令。看了一下说明，发现是支持正则的，那我直接一个`.`岂不是可以匹配所有，变相的进行文件读取。。。

![](../Images/68477e4f2537ebebf8b95fa4e24284b5.png)

  

本地测试了一下，确实可以

![](../Images/5d6c675ceaea60c94e330af9f33cbd89.png)

  

然后就是目标系统上获得向日葵的配置文件了，不同版本向日葵的配置文件位置可能不一样

*   
*   
*   
*   
*


![](../Images/c46dd2399315a3e387a76ff21d3f896f.png)

  

万万没想到的是，目标系统上的向日葵用登陆了个人账号，并且没开fastcode登录，也就不能密码解密后直接连Orz。

  

#### **2.6 计划任务命令执行（当前已拦截）**

既然无法使用fastcode直接远程向日葵了，那只能去找其他路子，我想到了计划任务。

本地尝试使用`at`添加执行计划任务，但发现计划任务添加成功却没有执行

![](../Images/84cef4c22e6498298a3f014c6abed3ac.png)

  

连个最简单的计算器都无法执行。。。

![](../Images/a82a4510622c8bbfb4490a6f6c10b576.png)

  

后面搜索才知道，Windows Server 2008中，已使用`schtasks`命令替换`at`命令

#### **2.7 实战利用**

首先需要找到网站的物理路径，这里利用报错得到了物理路径（网站关了，当时没有截图）

然后就是根据泄露的物理路径，写入计划任务

1.  最先尝试的是直接写phpinfo，可以写入，并且直接显示phpinfo信息；
    
2.  然后尝试写入简单的php一句话木马，发现写入不成功；
    
3.  最后发现可以利用文件包含，先写一个`abc.txt`，里面放入php一句话木马，然后写入一个`abc.php`，直接包含`abc.txt`即可。
    

![](../Images/f306e129233830c960b87307781b0aad.png)

  

  

然后是执行（这里虽然返回的是「failed,error 5」，但实际上等待几分钟后，就会发现已经执行了）

![](../Images/ed6b15e472b6ac401204f314d56f0102.png)

  

  

然后等待几分钟，访问创建的文件，文件成功创建

![](../Images/f369b18c002b41792a069bbc3d784648.png)

  

利用这种方式，成功拿到了shell

![](../Images/71ac68d79b1a4b0bdcf8c5d03185507f.png)
