### 1.1 Less-1

使用语句判断是否能注入

```


?id=1 and 1=1
```

通过以上的语句，发现在id后面加上`'`符号，页面显示不正常，这就有可能存在**SQL字符注入漏洞**

![](../Images/49ec65b70d52ca834d423420a70d9cf2.png)

再输入`-+`符号，将sql后面的语句注释掉，页面就会回显正常，说明这个地方是**单引号字符型注入漏洞**

![](../Images/9866c67b7772331160397edfa03d5782.png)

然后使用`order by`语句判断

```




?id=1' order by 1 --+ 页⾯正常
```

![](../Images/de4b285a3480d6afdd48d50c4bf32c1c.png)
