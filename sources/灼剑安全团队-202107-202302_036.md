```


```

```

```


```

5.\_\_isset()
```

```


```

```
　　方法用于检测私有属性值是否被设定。（当外部使用isset读类内部进行检测对象是否有具有某个私有成员的时候就会被自动调用！）【http://www.cnblogs.com/xishaonian/p/6170459.html】
```

```


```

```
6.\_\_unset()

```



# tp5.0.x

tp5.0.x触发RCE最后都需要调用\_\_call方法

这里我们选择\\thinkphp\\library\\think\\console\\Output.php的\_call方法

![](../Images/96e5b00be6bf8d76f9f6175bc16c0824.png)

 

 

 接下来我们需要找到能调用\_\_call方法的链子

首先我们全局搜索\_\_destruct方法找到\\thinkphp\\library\\think\\process\\pipes\\Windows.php的

![](../Images/c22ddb3c67b80044d11a1cec370a4c20.png)

 

 

 跟进removeFiles方法发现可以触发\_\_tostring 方法

![](../Images/27e291c0840b65b2cf37e31ccfc19638.png)

 

 

 由于这里file\_exists可以触发\_\_toString方法 我们找到\\thinkphp\\library\\think\\Model.php

![](../Images/9a9b8f8c6bc4f98ae40bfb74b9c85925.png)

 

 然后进入toJson

![](../Images/9ad5c994b71fca36d33b23a87a74abba.png)

 

 在toAarry方法里面找到四个地方可以触发\_\_call

![](../Images/2a22eaba3eda7fa036e9eab97f9bac7e.png)

 

 但是由于前面两个方法在初始启动类里面没有dd方法所以报错了

 

 

![](../Images/c7e33e4aaebacee9417328816858ccff.png)

 

 继续更进

![](../Images/3d9b2128aba66b846f11a39af76b5e3b.png)

 现在就是要在当前类里面找到一个存在的无参方法，且该方法的返回值可控

![](../Images/6a0f3a7b51675c689d1c5d300f845f90.png)

 

 

到这里我们就能控制modelRelation了，但是method\_exists($modelRelation, 'getBindAttr')由于先验证方法存在在调用，所以第三个调用\_call的点也没了，只能看value的值是否可控来触发第四个\_call

![](../Images/6d3ce2d30ca39ae7339d7894332dafb0.png)

 

 

 更进getRelationData方法方法发现 必须传入为Relation 的对象且必须存在isSelfRelation 和getModel方法且返回value必须和getModel方法的返回值一样或继承于Relation

![](../Images/fbf92fe999d13bedfb00523c48d95599.png)

 

 

 我们找到\\thinkphp\\library\\think\\model\\relation\\HasOne.php可知其继承于OntoOne又继承于Relation

![](../Images/d6ec80df474c5a1266dcb006af68882f.png)

 

 

 由于parent变量在Model中可控只需HasOne方法里面的getModel()满足==parent即可即为new Output();但是在调试过程中我发现其实可以不用返回值就可以触发\_\_call方法

![](../Images/6f4e40b4b7e38578855c37af84a7a200.png)

 

 

 这是详细调用过程

![](../Images/18eec7c714d8c960f2a56b143fbf5801.png)

 

 

 

 到这里才发现小丑是自己无参传入block会导致报错

![](../Images/6fbd825c6880707f0a37e252da6800b8.png)

 

 所以还是得回到Model继续调用第四条链子，参数为可控的attr

![](../Images/dc46cbaccd76c45dbe547bc9ad349ebd.png)

 

 由于hasOne继承OneToOne所以调用此方法

![](../Images/4275f8064c8c65438a909690f6a10b2d.png)
