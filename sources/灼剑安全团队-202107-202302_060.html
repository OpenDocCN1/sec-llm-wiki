使用 python 来转换为 交互式shell，分为以下两种方法

  • python3 -c 'import pty; pty.spawn("/bin/bash")'

  • python3 -c "__import__('subprocess').call(['/bin/bash'])"

但是不能自动补全，可使用stty进行优化

Ctrl+z挂到后台（任务暂停），echo $TERM 获取 term值，stty raw -echo 关闭输入回显
