## **工具简介**

当按下设定按键时，自动执行系统命令，帮助社工时快速操作上线。

### **1、硬件部分**

此文章使用的键盘全为自己做的。

硬件需要支持QMK。

![](../Images/a7041e7e0f236ddf4258d07f4dc917f8.png)

key

### **2、固件部分**

基于QMK combos的字符串输入，以及模拟人工操作。

### **3、使用介绍**

基于QMK的按键多层特性，此键盘暂为4层

> 第一层 办公层（一个按键代表一个组合键如 curl+c，做一个合格的文档工程师） 第二层 联盟层 （对就是打lol的，支持所有常规操作以及2个装备栏） 第三层 穿越层（全程穿越火线层，支持常规动作以及蹲跳动作）  第四层 渗透层 （还在写，也就是本文的拓展。如社工时的powershell一键输入，常规测试的一键启动工具等）

config.h是配列的配置文件，这里我们需要添加以下代码

```

#define COMBO_COUNT 1 
```

rules.mk是一个开关文件，此处需更开启如下开关

```
COMBO_ENABLE = yes
```
