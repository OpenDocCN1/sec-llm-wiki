## 0x00 前言

 Cobalt Strike是一款基于java的渗透测试神器，常被业界人称为CS。

## 0x01 简介

 Cobalt Strike自3.0以后已经不在使用Metasploit框架而作为一个独立的平台使用，分为客户端与服务端，服务端是一个，客户端可以有多个，非常适合团队协同作战，多个攻击者可以同时连接到一个团队服务器上，共享攻击资源与目标信息和sessions，可模拟APT做模拟对抗，进行内网渗透。

 Cobalt Strike集成了端口转发、服务扫描，自动化溢出，多模式端口监听，win exe木马生成，win dll木马生成，java木马生成，office宏病毒生成，木马捆绑；钓鱼攻击包括：站点克隆，目标信息获取，java执行，浏览器自动攻击等等。

### 4.2 安装步骤

#### 4.2.1 服务端搭建(腾讯云vps)

*   在腾讯云控制台找到服务器，点击右边的登录,再点击立即登录，再输入用户名、登录密码，点击确定，进入服务器
    

![](../Images/81c647d55570dc00e640e9ebacf63a01.png)

![](../Images/37a0e8e8fbb5fb58b39b2c0cd8e4cc2a.png)

![](../Images/983405ee62e9bbbab2318d0f6238fb00.png)

![](../Images/7176c33d541ea6b658c310700170ba8f.png)

*   使用腾讯云服务器yum 安装 \[GNOME Desktop\] \[Graphical Administration Tools\]图像化组件,提示安装大小，回复y
    

```
yum groupinstall "GNOME Desktop" "Graphical Administration Tools"
```

![](../Images/af46cd25d2bbc1f9760e8de0b33e10be.png)

*   更新系统运行级别,重启。关闭窗口，去腾讯云控制台
    

```

ln -sf /lib/systemd/system/runlevel5.target /etc/systemd/system/default.target
```

![](../Images/f72970302c8e0fa6ff11692f90038e1d.png)

*   依然点击登录，输入虚拟MFA设备动态密码确定，使用vnc登录，点击"立即登录"
    

![](../Images/fcb8389dd71e73c7477e7ea6c8a2c6df.png)

![](../Images/cb76335bb88fa448ec15bb3bc7e379b2.png)

*   简单选择时区 / 语言 / 即可开启图形化Linux
    

![](../Images/66e2d1e3bcdd4a035cec772ee3eb6734.png)

![](../Images/23995bdb877736cb4bacaaa6e2572a28.png)

![](../Images/d7e873f429b553c7bf1a0d3f136a4294.png)

*   打开终端，输入命令查看系统是否有java
    

```
java -version
```

![](../Images/8a6d4c9c8df012c61781e4bb9548e905.png)

![](../Images/85a74340eae698e372db669349d80ec0.png)

*   打开浏览器在百度网盘下载工具
    

![](../Images/8cb53b709ff42b1dbb86350d03e4b22c.png)

```







sudo su
```

![](../Images/f11e0eb8123dc8ce40c9e40af965eee2.png)

*   使用终端进入cs文件夹，输入以下命令赋予权限
    

```



cd /urs/local/lswcs4/
```

*   现在关闭这个窗口，去控制台点击"登录"，用标准登录方式登录。(注：因为一些特殊的符号不能在"vnc登录"里运行)
    

![](../Images/981747495fdfac711766f5a87cfd069c.png)

*   运行以下命令，启动cs服务端
    

```


cd /usr/local/lswcs4
```

![](../Images/c92f2b4aefb9d91ac03cad3065b46a8e.png)

注：如果未能连接，那就是因为端口问题，输入以下命令

netstat -lnpt   （查看端口）

#### 4.2.3 后台运行cs服务端

*   使用命令安装screen工具
    

```
yum install screen
```

![](../Images/1f5c159bddba80e266d716bdca71d81d.png)

*   常用screen参数
    

```





screen -S session_name              # 新建一个叫session_name的session
```

*   创建后台程序窗口,在这个窗口启动cs服务端
    

```


screen -S cs
```

![](../Images/9271986d491c92589d19c81102582670.png)

*   使用键盘上的按键，(注意：不是命令,就是键盘上的三个键，长按ctrl ，再按a，然后按d)
    

```
Ctrl+a+d
```

![](../Images/55f08c5e08e8266faadc024e37302022.png)

*   查看当前后台窗口，完成连接。
    

```
screen -ls
```
