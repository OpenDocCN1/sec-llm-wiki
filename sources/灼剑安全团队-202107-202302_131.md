0x00 前言

最近发现python中的 Selenium 模块可以控制浏览器做操作，百度后并没有发现完整的与之相关的脚本。控制浏览器爆破可以在某些环境下使爆破变得更简洁，本文就是讲一个简单的复用脚本的编写

## 0x01 脚本环境及搭建

（1）python3（2）chromeDriver（3）chrome（其他浏览器也可以，只是需要下载对应驱动）（4）演示系统 MetInfo 7.3.0

### 1.1 chromeDriver

python与Chrome的安装就不说了，下面会较详细的讲下chromeDriver的选择。查看chrome的版本安装对应的版本的chromeDriver，并在chrome中浏览器里输入：**chrome://version**

![](../Images/17d44c0cc058225ed8f54ef3a72af933.png)

下载对应版本的chromeDriver，如果没有一样版本的就选择相近的版本

http://chromedriver.storage.googleapis.com/index.html

![](../Images/9a2da70480263be118c51dab7c2475fb.png)

将下载的exe放入python安装目录下的Scripts文件夹，python安装路径，可以在cmd里输入 where python 查看。

### 2.2 更改为无头模式

无头模式可以在初始化selenium的 webdriver时制定，因为无头模式下不需要打开chrome的ui页面，开启后可有效的对速度以及内存占比进行优化。某些页面会对无头模式进行识别，所以需要添加一些绕过，此代码中并没有绕过，读者可独自在网络查找。

```

()options.add\_argument("--headless"
)driver \= webdriver.Chrome(options=options
)
```
