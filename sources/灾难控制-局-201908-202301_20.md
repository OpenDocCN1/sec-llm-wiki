### 1.Hook 介绍

execve的主要作用是用于从文件系统加载程序代码，让进程执行新的代码。

![](../Images/d85395df5abbd3cc9bc2ec377a1ae744.png)

Elkeid Driver Hook Execve 主要是利用Kretprobe Hook实现的，Hook了`execve`,`execveat`以及`call_usermodehelper(现版本还未默认开启，下版本会默认开启)`。

### 3.字段详解

#### uid

Linux User Identifier,Root User UID is 0.

#### data\_type

Elkeid 为了区分数据类型而设置的字段，execve在Elkeid中的data\_type为59。

#### exe

当前进程的executable file path，如我们执行了`/bin/ls`，那么对应进程的exe就是`/bin/ls`。

当出现`(deleted)`的时候，说明该文件已经被删除。

#### pid

Linux Process Identifier

#### ppid

Linux Parent Process Identifier

#### pgid

Linux Process Group Identifier (Process Group Leader)

#### tgid

Linux Process Thread Group Identifier

#### sid

Linux Process Session Identifier (Session Leader)

#### comm

长度为 TASK\_COMM\_LEN (16) 的字符串，用来描述进程，通常来源于 `execve argv`，该参数可以被修改，如通过 `prctl PR_SET_NAME`。

#### nodename

UTS namespace(UNIX Time Sharing) 用来隔离系统的 hostname 以及 NIS domain name。

nodename 是当前进程的 UTS namespace 数据结构中的 nodename，如果是宿主机，往往和宿主机的 `hostname` 一致，如果是容器且存在 UTS 隔离，那么和容器内的 `hostname` 一致。

该值由于依赖 UTS 隔离，因此不能完全根据该值判断是否处于容器内，仅能作为一个数据指标。

#### sessionid

`auditing session id`，依赖 `Kernel CONFIG_AUDITSYSCALL` 配置支持，默认开启。

部分情况下可以根据该值进行行为关联。

#### pns

当前进程的 `pid_for_children` namespace inum。

#### root\_pns

1号进程的 `pid_for_children` namespace inum，通常通过与 pns 对比可以得知是否处在容器中。

#### socket\_exe

Elkeid Driver 会爬去当前进程 fd list 和进程树中的 fd 来寻找是否存在网络连接，寻找到的第一个网络连接所属的进程的 `exe file` 即为该值。

#### argv

当前 `execve` 的传入参数。

#### run\_path

当前进程所属的目录位置，可以简单理解为 `pwd`。

#### pgid\_exe

Linux Process Group Identifier (Process Group Leader) 对应的 `exe file`。

#### stdin

当前进程的 `stdin`。

#### stdout

当前进程的 `stdout`。

#### dip

当前进程所存在的第一个网络连接所属的目的IP。

#### doprt

当前进程所存在的第一个网络连接所属的目的端口。

#### sip

当前进程所存在的第一个网络连接所属的源IP。

#### sport

当前进程所存在的第一个网络连接所属的源端口。

#### sa\_family

当前进程所存在的第一个网络连接所属的 `sa_family`。

#### pid\_tree

当前进程所属的进程树，例如：

```
3413330.rm<3413328.sudo<3402660.bash<3402658.sshd<3402653.sshd<2042788.sshd<1.systemd
```

由 `PID + process comm` 组成。

#### tty

当前进程分配的`tty`。

#### socket\_pid

当前进程所存在的第一个网络连接所属的`pid`。

#### ssh

环境变量中的`SSH_CONNECTION`值，如果该行为是通过SSH登陆操作的，通常可以通过该值判断来源。

如：

```
10.21.15.55 64609 10.217.55.18 22
```

#### ld\_preload

环境变量中的`LD_PRELOAD`值。

#### res

当前的`execve`的返回值。
