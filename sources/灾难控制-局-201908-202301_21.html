Elkeid资产插件及 Go SDK 开源

Elkeid Agent继开源了driver/journal_watcher两个plugin之后，已经具备了d多种行为采集以及ssh登陆事件上报等功能。为了弥补在系统资产/软件包/敏感配置等方面的数据获取能力，我们这次开源了Elkeid资产插件 — collector。


collector 会在定时扫描主机上的相关资产与配置，解析、规范数据之后上报到Server，并可根据需要进一步联动威胁情报，提升主机安全基线水位。另外，值得一提的是：在部分数据采集上，我们支持对主机上的容器内相关资产进行采集，以丰富我的资产数据库。


相比其他同类安全防护软件，具有以下优点：

  • 支持资产及配置种类接近十种，并在持续迭代增加中

  • 高性能，低IO，通过合理设置采集时间段，降低业务感知

  • 无依赖，不调用任何外部脚本/命令

  • 数据详细、整齐，开箱即用

  • 对容器化场景具有良好的兼容性

1. Cron定时任务采集


支持对主机内的所有cron定时任务进行采集，并根据不同发行版做了兼容性适配，确保无数据遗漏。除了定时扫描之外，我们在关键目录上设置了inotify，确保尽可能及时更新定时任务列表。默认每小时采集一次。



字段说明：

minute：定时分钟
hour：定时小时
day_of_month：定时天/月
month：定时月
day_of_week：定时天/周
user：执行用户
command：执行命令
path：定时任务文件路径
target_content：command如果是脚本，那么这个字段会是脚本内容

2. 发行版软件包采集


我们针对Debian与CentOS适配了此项功能，在不调用外部命令的情况下高效搜集宿主机与容器内的软件包信息，支持DPKG与RPM两种格式的数据库。默认每天0-6点采集一次。


字段说明：

name：软件包名称
version：软件包版本
status[dpkg]：软件包状态
release[rpm]：软件包发行版

3. Pypi软件包采集


插件支持宿主机与容器内的Pypi软件包信息采集，自动遍历/usr下的所有目录，并跟随.pth文件内容增加采集索引，同时解析site-packages与dist-packages目录，获取全量.egg-info与.dist-info文件，进而得出软件包信息。相比pip list方式，这种解析速度更快、性能更高，数据更加全面。但目前不支持conda等虚拟环境下的包信息采集。默认每天0-6点采集一次。


字段说明：

name：软件包名称
version：软件包版本
pyversion：python版本

4. Systemd服务采集


因为时常会有恶意后门、挖矿木马等通过systemd服务实现持久化驻留，我们对系统级别的服务进行了周期性扫描与上报。默认每天0-6点采集一次。


字段说明：

name：服务名称
type：服务类型
exe_start：启动命令
restart：重启方式
working_directory：工作目录
target_content：同cron

5. 开放端口采集


为了适配不同版本/环境下的操作系统，我们提供了两套开放端口采集方案，优先使用netlink _inet_diag，如果不支持这种方法，则会降级到纯/proc的方式。默认每小时采集一次。

netlink实现方式类似ss，纯/proc的方式类似netstat。注意：在连接数较大的机器上纯/proc的方式可能会存在性能风险。

字段说明：

dport：目标端口
sport：源端口
dip：目标ip
sip：源ip
interface：网卡
family：ip类型
state：状态
uid：用户id
username：用户名
inode：socket inode
pid：对应进程pid
cmdline：对应进程命令行
name：进程名
type：协议类型

6. 常驻进程采集


插件会周期性的对系统当前进程做快照，记录进程相关信息并传回Server，后续可以根据exe的sha256做进一步威胁情报联动。默认每小时采集一次。


字段说明：

pid：进程pid
ppid：父进程pid
name：进程名
cmdline：进程命令行
exe：进程exe path
sha256：进程exe对应的sha256
uid：用户id
username：用户名
euid
eusername
cwd：工作目录
session：session信息
tty：tty信息
start_time：进程启动时间

7. 用户信息采集


通过inotify与周期扫描两种方式确保用户信息及时更新，同时可以根据自带的弱口令库检测当前主机是否存在弱口令(本地计算，只传输结果)。默认每小时采集一次。


字段说明：

username：用户名
password：口令(x)
uid：用户id
gid：用户组id
group_name：用户组名
info：其他信息
home_dir：家目录路径
shell：shell路径
last_login_time：上次登陆时间
last_login_ip：上次登陆ip
weak_password：是否弱口令

8. sshd配置采集


为避免不安全的sshd配置导致机器被暴力破解，插件会定期采集并解析sshd配置，确保符合ssh登陆安全基线。默认每天0-6点采集一次。


字段说明：

password_authentication：是否开启了密码认证
pubkey_authentication：是否开启了公钥认证

9. 包管理配置采集


大多数包管理都应该符合一定的要求(采用可信的源仓库等)，为避免配置错误导致引入不安全依赖，插件会定期采集包管理软件的配置，目前支持apt/rpm。默认每天0-6点采集一次。


字段说明：

sources 软件源列表

10. 性能


在50W左右不同业务机器上统计观测24h，得到以下性能指标(峰值)：

  • CPU(单核)

    • pct99 < 1%

    • pct999 < 3%

  • RSS

    • pct50 < 15MB

    • pct90  < 18MB

    • pct95 < 19MB

    • pct99 < 21MB

    • pct999 < 36MB

  • Disk IO

    • pct99 < 4KB/30s

    • pct999 < 4MB/30s
