## 1.Elkeid(AgentSmith-HIDS) 预编译 Ko文件

本次更新提供了一些预编译好的 Elkeid 内核模块，这些内核模块适配了 Debian,Centos,Ubuntu 等发行版的不同内核版本，便于相关同学进行测试或部署。

## 2.需要注意

本次提供的预编译ko文件仅基于标准的Linux发行版以及Kernel，若是非标环境请先自行测试稳定性后再使用。

当前版本的 Elkeid 内核模块已经在几十万量级的生产网环境(Debian)上稳定运行半年左右，但这并不保证该内核模块在其他版本的内核中能够完美运行，例如在**小于3.10** 和 **大于 5.4** 的内核版本尚未适配；且Linux发行版本众多，我们仅测试覆盖了部分主流的发行版及版本。因此，不要在不支持的Linux版本且未经测试的情况下，直接 insmod 使用 Elkeid 内核模块。

## 4.获取预编译的 Ko

如果获取失败，则说明预编译的 Ko中，不包含当前系统的内核版本所需的 Ko，需要自行编译

```
wget "http://lf26-elkeid.bytetos.com/obj/elkeid-download/ko/hids\_driver\_1.6.0.0\_$(uname -r).ko"
\#  or
curl -O "http://lf26-elkeid.bytetos.com/obj/elkeid-download/ko/hids\_driver\_1.6.0.0\_$(uname -r).ko"

\#  其他地址
\# http://lf3-elkeid.bytetos.com/obj/elkeid-download/ko/hids\_driver\_1.6.0.0\_$(uname -r).ko
\# http://lf6-elkeid.bytetos.com/obj/elkeid-download/ko/hids\_driver\_1.6.0.0\_$(uname -r).ko
\# http://lf9-elkeid.bytetos.com/obj/elkeid-download/ko/hids\_driver\_1.6.0.0\_$(uname -r).ko
```

## 6.已知问题

*   ###  内核模块 hook 点初始化失败 : do\_init\_module
    

在一些老版本的 ubuntu/centos 内核中出现，dmesg 会有如下输出:

```
do\_init\_module register\_kprobe failed, returned -2.
```

*   ### 内核版本 > 5.4.X 或者 < 3.10.X
    

编译失败 : 这些内核版本尚未适配，下个版本会做支持
