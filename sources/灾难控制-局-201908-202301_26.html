1.项目更名

该项目由 AgentSmith-HIDS 正式更名为 Elkeid

项目地址更新为：https://github.com/bytedance/Elkeid


2.更新说明

此次更新主要涉及 Elkeid Driver 以及对应 Driver Plugin。


2.1 common 字段增加 pns/root_pns

pns为当前进程 pid namespace 的 proc_inum

root_pns为1号进程的 pid namespace 的 proc_inum

通过这两个数据可以判断当前进程是否是存在namespace pid隔离。


2.2 Create File Hook 数据增加一些网络相关信息

602 Create File数据增加dip,dport,sip,sport,sa_family,socket_pid

数据采集来源于创建文件进程的fd list以及父进程，在很多场景下不一定准确，但是具有一定的参考价值。
