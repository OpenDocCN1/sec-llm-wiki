## 1.项目更名

该项目由 **AgentSmith-HIDS **正式更名为 **Elkeid**

项目地址更新为：*https://github.com/bytedance/Elkeid*

  

## 2.更新说明

此次更新主要涉及 Elkeid Driver 以及对应 Driver Plugin。

  

### 2.1 common 字段增加 pns/root\_pns

`pns`为当前进程 pid namespace 的 proc\_inum

`root_pns`为1号进程的 pid namespace 的 proc\_inum

通过这两个数据可以判断当前进程是否是存在namespace pid隔离。

  

### 2.2 **Create** **File** Hook 数据增加一些网络相关信息

602 Create File数据增加`dip`,`dport`,`sip`,`sport`,`sa_family`,`socket_pid`

数据采集来源于创建文件进程的`fd list`以及父进程，在很多场景下不一定准确，但是具有一定的参考价值。

  

### 2.3 增加 call\_usermodehelper\_exec() Hook

我们观察到部分Rootkit会通过调用`call_usermodehelper()`来实现一些行为，因此我们增加了相关Hook针对性采集信息，目前在SandBox模式下开启，格式如下：

### 2.4 新增默认开启的 Hook 点(HIDS 模式下)

经过内部充分的测试，我们开启了之前在HIDS模式下默认关闭的部分Hook，列表如下：

| Hook || 备注 |
| --- | --- |
| rename || 无 |
| --- | --- |
| link || 无 |
| setsid || 无 |
| prctl || 仅会采集PR\_SET\_NAME |

  

### 2.5 稳定性/性能提升

*   Driver 增强了稳定性和兼容性
    
*   Driver 性能小幅提升   
    

*   DNS Hook减少了内存申请，提升了性能
    
*   Execve Hook 减少了内存申请，提升了性能
