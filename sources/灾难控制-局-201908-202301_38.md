# AgentSmith-HIDS更新说明

### 1.使用Kprobe替换Hook Syscall Table

AgentSmith-HIDS本次最大的更新(重构)就是替换了原来的Hook方案，使得兼容性从原来的**Centos6/7 && Kernel && 2.6.32/3.10**提升到了**Kernel > 2.6.25**，主流发行版Linux都支持，兼容。

  

### 2.去除部分功能

为了保证更好的兼容性和轻量化，去除了原先的Hook **sys\_access**功能（沟通下来发现使用的人和场景比较少），并且去除了原先的**Real Time Rootkit Detection**，原因是原先的方案存在误报，并且对性能影响相对较大。

关于**Rootkit Detection**，后续会成为一个重点进行专门的研究和功能迭代，目前只是暂时缺失。

去除了原先的**netlink**数据传输方案，只保留**share mem**方案，毋庸置疑该方案性能更优异。

目前保留的功能有：

**1.execve hook**

**2.connect hook**

**3.process inject hook**

**4.create file hook**

**5.DNS query hook**

**6.load LKM hook**

  

### 3.关于稳定系

并且这次更新引入了**ltp(linux-test-project):https://github.com/linux-test-project/ltp**稳定性测试框架，进一步的保证了稳定性。目前我们在多个Linux发行版和多个Kernel版本上进行了ltp的syscall稳定性测试，均全部稳定通过。

并且由于使用了Kprobe，稳定性会优于老版本的直接Hook Syscall Table的方案。

  

### 4.去除了Golang版本的用户态Agent

同时维护两个版本的用户态Agent(Rust && Golang)对于个人开发者和半业余项目来说，是有一定困难的，由于性能上的考量，决定去除Golang版本的用户态Agent，只保留Rust版本的用户态Agent，Rust可以保证更加的安全可靠和更优异的性能表现。

  

### 5.与老版本的用户态Agent不兼容

由于部分字段的调整，新版本的内核驱动与老版本的用户态Agent并不兼容。

  

### 6.其他更新

由于使用了Kprobe进行Hook，不再拘泥于syscall，因此多个Hook点下移。整体而言更加灵活方便。

  

### 7.BUG修复

如老版本在有些情况下无法获取当前execve的exe file的绝对路径等BUG，还有部分稳定性BUG修复。

  

### 8.性能优化

相较于老版本优化了多处细节，主要为了保证更好的性能表现。

  

### 9.关于文档

我们还更新了**README**和**Quick-Start**，方便大家更方便的进行测试和学习。

请移步：https://github.com/EBWi11/AgentSmith-HIDS

  

**（提示：若有在使用老版本的同学请自行升级，老版本将不在维护）**

  

### 10.后续计划

基础功能计划是到此为止，后续重点将在**Rootkit检测**和**用户态模块**的完善上。

并且有计划剥离我们目前纯自研的\*\*安全流处理引擎(AgentSmith-HUB)部分基础功能进行开源，来弥补AgentSmith-HIDS目前规则引擎和处理引擎缺失的局面，届时会开源全部积累的规则(不限于主机入侵检测)，来形成闭环。如果进展顺利，会在2020年上半年开源，敬请期待。
