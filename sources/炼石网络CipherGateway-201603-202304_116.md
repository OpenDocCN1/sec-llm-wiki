# 炼石荣获“中国网络安全创业公司HOT51”

近日，第三方专业咨询机构安全牛发布《中国网络安全创业公司HOT51》。该报告历时4个多月深入调研中国100余家热门网络安全创业企业（成立六年以内），推选出51家优秀公司，代表着中国网络安全市场的“创势力”和风向标。**炼石凭借“密码技术、数据安全、实战化防护、安全新合规”等方面的优势，成为“中国网络安全创业公司HOT51”数据安全领域上榜企业。**  

  

![](../Images/6a6e9040a672ecad5d99c8ba1fb1382e.png)  

2021年是“十四五”开局之年，迎接数字时代，激活数据要素潜能。数据安全作为数字化和数字经济发展的基石，已成为国家安全战略的重要一环。

  

然而，信息系统中数据体量巨大、浩如烟海，不同类型的数据，其安全策略、数据库适配、开发语言、性能要求、成本运维等，均存在较大的差异，同时海量数据与业务系统纽结缠绕，如何平衡好数据保护和业务处理之间的关系，成为企业数据安全建设的重中之重。

  

目前，企业海量数据高速流转于应用系统中，传统的“城防式数据安全”模型难以满足企业在数据流动过程中的安全防护；同时，业务与安全研发排期不吻合、业务团队技术与响应跟不上等融合负担，严重制约安全建设与业务拓展的高效发展。

  

在实际的应用场景中，企业业务与安全紧密结合，需要具备轻量级改造应用、灵活部署实施且不影响应用正常使用的数据加密方案。**炼石基于****面向切面的加密技术，将安全与业务在技术上解耦、但又在能力上融合交织，以免改造方式，****实现主体到应用内用户、客体到字段级的防护，打造“以密码技术为核心，访问控制、审计等多种安全技术互相融合”的实战化数据安全密码防护体系。**同时，产品支持分布式部署，集中管控，可针对单个应用防护，也可以针对几十个应用的批量保护。

  

**炼石坚持“以数据为中心的新安全理念”，成功研发********CASB业务数据安全平台、CipherSuite密码套件、密钥管理系统、服务器密码机、密评工具箱、敏感数据发现平台****等产品。******同时，密钥管理与数据加密及认证平台、CipherSuite密码算法软件模块、服务器密码机、密码卡、业务数据代理加密网关等相关产品均已通过商用密码产品认证，满足企业实战防护与新合规两类需求。

  

炼石聚焦政府、金融、教育医疗文旅、工业央企商业等行业的个人信息保护、商业秘密保护、国密合规整改三大业务场景，为用户提供安全、易用、高性能的解决方案。目前，炼石已成功参与某民航企业、某省健康码系统、某大型赛事等项目的数据安全保护。通过梳理客户的合规要求与业务需求，以应用侧为抓手，选用具有国家密码管理局认可的商用密码认证产品，有效防范内部业务人员、DBA运维人员越权访问，以及外部黑客入侵拖库等风险。

  

《中国网络安全创业公司HOT51》是网络安全投资者、企业CISO用户、网络安全人才和网络安全企业需要共同关注的热榜。炼石入围《中国网络安全创业公司HOT51》，代表着业界对炼石理念和技术创新的肯定与认可。未来，炼石将建立更具整体性、系统性和针对性的数据安全保障体系，助力企业数字化建设。

  

![](../Images/0975ca17a65a5fe2ba1d028127ce3366.png)

  

炼石网络是一家基于密码与系统安全技术的数据安全创新公司，提倡“以数据为中心的新安全理念”，自主研发了CASB业务数据安全平台和高性能国密产品，开创性的实现免开发改造应用、敏捷实施细粒度数据保护，该产品入选工信部2020年网络安全技术应用试点示范推荐项目，并夺得第七届互联网安全大会(ISC 2019)首届“创新独角兽沙盒大赛”总冠军。基于AOE面向切面数据安全技术，将安全与业务在技术上解耦、但又在能力上融合交织 ，实现主体到应用内用户、客体到字段级的防护，打造“以密码技术为核心，访问控制、审计等多种安全技术互相融合”的实战化数据安全防护体系。炼石为政府、金融、教育医疗文旅、工业央企商业等行业用户，提供个人信息保护、商业秘密保护以及国密合规改造方案，让数据共享更安全、更有价值。
