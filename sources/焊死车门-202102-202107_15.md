**横向移动**  
    横向移动就是当我们打点成功后，以当前被攻陷主机为跳板，通过信息收集，进一步扩大资产范围，获取域控、目标服务器，甚至控制整个系统的内网环境。

第一式 中出ipc$

**简介**  
    Ipc$(Internet Process Connection)是共享”命名管道”的资源，它是为了让进程间通信而开放的命名管道，可以通过验证用户名和密码获得相应的权限,在远程管理计算机和查看计算机的共享资源时使用。利用IPC$,连接者甚至可以与目标主机建立一个连接，利用这个连接，连接者可以得到目标主机上的目录结构、用户列表等信息。  
**使用条件**  
    1.开启139，445端口（基于smb实现共享）  
    2.目标管理员开启默认共享  
    3.知道目标机器的账户及密码  
    为啥都知道用户密码了还要使用ipc$，因为在真实环境中，有很多机器是不开放远程桌面端口（3389）来让你登录；还有就是你不知道当前用户是否是被登录的状态，你登录就有可能把当前用户挤下去，导致攻击被发现。  
**使用方式  
**

`net use \\<目标机IP>\ipc$ "password" /user:"username" # 建立ipc连接``dir \\<目标机IP>\c$  # 查看目标机器文件c盘（类似可以d$、e$等）``copy 本机文件 \\<目标机IP>\c$  # 复制文件到目标机器（上马常用）、反过来可以copy回来``net time \\目标机器IP # 查看目标系统时间`

**简介**

    计划任务windows常用命令为at 和 schtasks  
   at 是 Windows 自带的用于创建计划任务的命令，主要工作在 Windows Server 2008 之前版本。schtasks Windows Vista、Windows Server 2008 之后的版本废弃了 at 命令，采用 schtasks 取代了 at。计划任务的作用非常大了，可以执行系统命令，可以建立计划任务上马等

    ② 使用copy命令，将木马复制到目标机中  
    ③ 目标机上创建计划任务，使其自动触发木马文件

**简介**  

    有时候我们可以不用这么复杂，执行系统命令还可以使用psexec进行，只需要瞧准破绽，一掌过去（老汉推车），即可执行相应的系统命令。

    PsExec 是 windows 下非常好的一款远程命令行工具。PsExec的使用不需要对方主机开方3389端口，只需要对方开启admin$共享 (该共享默认开启)。但是，假如目标主机开启了防火墙，PsExec也是不能使用的，会提示找不到网络路径。由于PsExec是Windows提供的工具，所以杀毒软件将其列在白名单中。

第四式 一套从天而降的掌法（观音坐莲）-wmi  

**简介**

    你见过一套从天而降的掌法吗，观音坐莲-wmi告诉你，利用工具可在windows和linux上对目标机器进行横向渗透。

    Windows管理规范WMI（WindowsManagement Instrumentation），从 Windows 98 开始都支持 WMI，WMI 是由一系列工具集组成的，可以在本地或远程管理计算机系统。  
    自 PsExec 在内网中被严格监控后，越来越多的反病毒厂商将 PsExec 加入了黑名单。在使用 WMIEXEC 进行横向移动时，Windows 操作系统默认不会将 WMI 的操作记录在日志中，恶意行为被发现的可能性有所降低，隐蔽性有所提高。  
    使用WMI是要求目标主机开启135端口和445端口（135 端⼝是 WMIC 默认的管理端⼝，而 wimcexec 使⽤445端⼝传回显）

**使用方式**  

*   
*   
*   
*   
*   


第七式 加藤鹰之手-票据传递攻击（ptt）  
**简介**  
    除了锋利的冈本零点零一外，票据传递攻击也是横向控制域管服务器的重要技巧。

    当我们获取到server hsah或者krbtgt hash时我们就可以随意伪造ST服务票据，进而使用服务票据登陆域控制器。犹如加藤鹰之手爽到无法呼吸。  
    票据传递攻击分为黄金票据和白银票据。

  

**使用方式**

    黄金票据和白银票据的不同  
    1.访问权限不同：  
        ① Golden Ticket：伪造TGT，可以获取任何Kerberos服务权限  
        ② Silver Ticket：伪造TGS，只能访问指定的服务  
    2.加密方式不同：  
        ①Golden Ticket由Kerberos的Hash加密  
        ②Silver Ticket由服务账号（通常为计算机账户）Hash加密  
    3.认证流程不同：

       ①Golden Ticket的利用过程需要访问域控

        ②Silver Ticket不需要

第十一式 天外飞仙-SPN  

**简介**  

    SPN(ServicePrincipal Names)又名服务主体名称，是服务实例的唯一标识符，所谓的服务实例就类似于HTTP、SMB、MySQL等服务。

    SPN分为两种类型：

   一种是注册在活动目录的机器账户(Computers)下，当一个服务的权限为 Local System 或 Network Service，则SPN注册在机器账户(Computers)下。

    一种是注册在活动目录的域用户账户(Users)下，当一个服务的权限为一个域用户，则SPN注册在域用户账户(Users)下。

**利用方法**  

*   
*   
*   

```
Setspn -T <域名> -Q */*  # SPN发现Add-Type -AssemblyName System.IdentityModel New-ObjectSystem.IdentityModel.Tokens.KerberosRequestorSecurityToken -ArgumentList "<服务名称>"  # 请求服务票据mimikatz # kerberos::list /export  # 使用mimikatz导出之前请求的服务票据
```
