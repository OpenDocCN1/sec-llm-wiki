**二、binwalk**

**（1）安装：**

    **安装git工具**

:~$ sudo apt –get update

:~$ sudo apt-get installbuild-essential autoconf git

**下载binwalk**

:~$ sudo git clonehttps://github.com/devttys0/binwalk.git

**安装sasquatch SquashFS提取工具**

:~$ sudo apt-get installzliblg-dev liblzma-dev liblzo2-dev

:~$ sudo git clonehttps://github.com/devttys0/sasquatch

**安装binwalk**

:~$ sudo python setup.py install

**（2）binwalk的使用：**

**获取帮助信息：**

binwalk –h

![](../Images/177bcfae3fcea9fa5185c5ff581899d1.png)

  

**对固件进行扫描：**

binwalk xxx.bin

![](../Images/842fcd53e68a03ab4efa4cb8fec38c79.png)

**提取固件文件：**

binwalk –Me xxx.bin

![](../Images/d19a71c94451bac8982b43f835ed19b6.png)

**四、根文件识别与提取**

固件文件通常以bin、zip、LZMA、arj等文件压缩类型封装，其中，最常见的为bin和zip格式，bin文件是二进制镜像形式，需要使用binwalk提取squashsf文件系统。

二进制镜像提取文件系统界面如下：

![](../Images/d19a71c94451bac8982b43f835ed19b6.png)  

对于bin文件来说，不一定就是二进制镜像文件，也有可能是数据文件，首先要对文件进行识别，可以借助linux下的file命令，如下所示：

![](../Images/0521da9890ab329a9af663d12e7aac08.png)  

通过对bin文件的提取，获得了后缀为squashfs的固件文件，从而获得固件的根文件。以D-Link DIR300路由器为例：

![](../Images/953a70aa9198b494df6dff993bda6007.png)  

还有些经过加密的压缩包，无法直接解压缩，这是厂商对固件做了保护，防止逆向分析。以D-Link DWR-932B路由器为例：

固件地址：

https://media.dlink.eu/ftp/products/dwr/dwr-932/driver\_software/DWR-932\_fw\_revB\_2\_02\_eu\_en\_20150709.zip

      此固件以zip格式进行压缩打包，并经过加密，无法直接解压。

![](../Images/218581a0977166de253822f65ff68e29.png)  

使用binwalk进行解包，生成\_DWR-932\_B1\_FWv.02.02EU.zip.extracted文件夹。文件夹下存在40.zip包。

![](../Images/426ba5e4d929cf1ebd358e22c6721d7a.png)  

继续对40.zip解压，发现需要密码。

![](../Images/c220ef6035773fb8d3cc7333006548f5.png)  

使用frackzip工具可以破解该zip密码，密码为：beUT9Z。解压后获得文件夹与文件。

![](../Images/ce2c51a5aa8c1d7d8cf1f211cf8b7557.png)  

Yaffs2文件就是它的根文件系统，使用binwalk进行解压时发现无法提取出根文件系统。

![](../Images/1bd0d3b8332b10f97af399bd5907abde.png)  

提取后的文件夹中并非根文件系统，百度资料后，了解到932B型号的路由器使用了yaffs的原生态压缩算法，可以使用工具unyaffs提取。

![](../Images/d6ae59d113d8a662728042c641902dd5.png)  

使用unyaffs进行解压。将镜像文件提取到yaffs2-root目录，获得完整的根文件系统。

![](../Images/d0fbf23ec59e2646db3fcd425f287412.png)
