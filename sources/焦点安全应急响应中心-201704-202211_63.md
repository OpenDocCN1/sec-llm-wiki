# 关于使用社工钓鱼等方式提交漏洞的处理说明

FSRC 2018年度活动正在火热进行，截止现在，本次活动接收到的漏洞数已经超过200！感谢白帽子们的热情与大力支持！

  

在审核期间，我们也发现有白帽子使用社工钓鱼等方法，FSRC在此做出如下声明：

  

1.FSRC 仅接收在FSRC官网中列出的对外接收的系统的漏洞。

  

2.对使用社工、钓鱼等方式进而发现的相关漏洞，FSRC将按照公告内容对这些漏洞做忽略处理。

  

3.FSRC 会对本声明发布之前，利用社工钓鱼等方式发现漏洞且无恶意操作的白帽子进行一定程度的奖励，以感谢其贡献。

  

我们再次声明，欢迎各位白帽子踊跃参加我们的年度活动。也希望各位白帽严格按照相关规范和活动须知进行测试，禁止使用扫描器进行大范围扫描或使用DDOS等干扰正常业务，禁止向正常客户发送测试信息，禁止社工钓鱼，禁止大规模导出数据。FSRC也会秉持公平、公正的态度进行漏洞审核，尽全力让每一位遵守规则的白帽得到付出所对应的奖励。

  

年终活动中，我们也新增“年度有爱奖”，对提交漏洞时格式规范、提供 poc 或 exploit 、有详细分析，有助于加快审核处理速度的白帽提供额外奖励。

  

良好的安全行业环境，需要我们共同的努力与守护。
