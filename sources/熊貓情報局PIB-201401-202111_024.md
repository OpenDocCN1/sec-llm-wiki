# 美媒：在外星人眼中 地球人可能就像蚂蚁一样无趣

《科学美国人》月刊网站1月21日发表文章《为什么我们认为外星人可能想访问我们？》，作者是阿维·洛布。全文摘编如下：

认为我们值得来自银河系中先进物种的特别关注是很自以为是的。我们对于他们，或许像蚂蚁对于我们一样无趣。毕竟，当我们走在人行道上时，很少或完全不会查看沿途的每一只蚂蚁。

我们的太阳形成于宇宙恒星形成史的末期。大多数恒星都比太阳古老几十亿年。事实上，许多类似太阳的恒星都太古老了，已经耗尽了它们的核燃料并冷却下来，变成地球大小的致密残余物，称为白矮星。我们最近还了解到，在所有类似太阳的恒星中，约有一半有一颗地球大小的行星位于宜居带，这些行星上可能存在液态水和构成生命的化学元素。

银河系中有数十亿个地方的生命骰子都投出了类似于地球的条件，因此我们所知的生命形式很可能是常见的。如果情况确实如此，那么某些智能物种的技术开发很可能比我们早几十亿年。这些先进文明在权衡与我们这样的欠发达文化互动的风险后，可能会选择避免接触。费米悖论（“大家都在哪里？”）可能意味着，我们不是罐子里最值得关注的饼干。

要知道作为人类外观的“一级近似”看起来什么样，我们有理由先去照照镜子。这种做法是基于一个寻常假设，即我们每个人都拥有相同的遗传血统。但对于其他星球上独立进化的生命来说，情况可能并非如此。例如，比邻星b是距离我们最近的宜居系外行星，那里的动物和植物可能与地球上截然不同。特别是，那里的动物可能长着看起来很奇怪的眼睛，它们的眼睛最适于探测比邻星发出的红外辐射。比邻星是一颗矮星，表面温度只有太阳的一半。

比邻星b与其恒星的距离是地球距太阳的1/20，因此我们预计它会被潮汐锁定，也就是在任何时候都以同一面朝向其恒星，就像月球永远以同一面朝向我们一样。生活在永昼中的物种可能与生活在寒冷夜晚的物种完全不同，表现出不同的强制睡眠模式。比邻星b表面的任何植物都会进化出获取红外光的能力，因此那里的草可能是深红色的，不像地球上是绿色的。

预测已有数十亿年历史的技术会是什么样子，这就更难了。为了搜寻这些技术，我们必须标出通过望远镜看到的异常现象，而不是出于保守主义而忽视意料之外的信号。如果我们的仪器不够灵敏，或者搜寻技术不够完善，我们就不会发现技术标记。如果没有合适的机器学习算法来处理数据，可能就像布设一个徒劳无功的渔网，因为网眼太大而永远捕不到鱼。

我们根据镜子里看到的东西设计搜寻方式。无线电通信和激光发明后，我们开始寻找来自外太空的无线电和激光信号；有了光帆技术后，搜寻工作也取得了相应进展。就在我们想象新技术的同时，可能最终会找到一种技术，让我们能够发现其他许多使用这种技术的物种。

然而，我们应该谨慎对待达不到定量科学证据标准的坊间观察。这些观察包括缺乏证据支持的阴谋论，或有关不明飞行物的报道，它们都经不起可重复验证，而可重复是成为可信科学数据的先决条件。不明飞行物报告提供的线索总是游走在可探测的边缘。随着时间的推移，我们的摄录设备大幅改进，可以预想，一张50年前老旧相机拍摄的模糊照片如今会变成先进相机拍摄的清晰图像，从而提供确凿证据来排除任何合理怀疑。

但已有线索总是微不足道的，这意味着不明飞行物最有可能是仪器伪像或自然现象。为了获得科学上的可信性，在发现一个不同寻常的物体后，必须通过有据可查的科学程序对这一物体或同类的其他物体进行定量研究。科学证据限制了我们的想象力，也让我们免于陷入牵强附会的想法。

费米悖论的自命不凡之处在于，它假设我们人类在宇宙中有一定的重要性。现实可能是，我们是平凡的，就像恐龙那样注定在某场灾难后灭亡。为什么邻近星系会关心我们的草有多绿？鉴于比邻星这样的矮星要比太阳多得多，大多数宜居行星可能都被深红色的草覆盖。对于系外行星上的度假者来说，深红色的草才赏心悦目，就像绿草对我们来说一样。因此，星际旅行社可能会发现，比邻星b是比地球更有吸引力的旅游目的地。我们可能会像费米那样感到奇怪，为什么没有系外行星游客羡慕我们。但更好的做法是，我们可以联系上比邻星b，吸引当地人到我们这里来，与我们共饮水做的饮料。
