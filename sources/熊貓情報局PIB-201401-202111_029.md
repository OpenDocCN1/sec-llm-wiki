# 中科院国家重点实验室与阿里云合作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTU0MDcyMA==&mid=2650565468&idx=5&sn=4b868988541ce7ae446ffc12615930f0&chksm=befe30c38989b9d50d07abdcd475feebeff1f6646731b070e8fcb13e71627402a29bac438dbf&scene=126&sessionid=1681279895#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTU0MDcyMA==&mid=2650565468&idx=5&sn=4b868988541ce7ae446ffc12615930f0&chksm=befe30c38989b9d50d07abdcd475feebeff1f6646731b070e8fcb13e71627402a29bac438dbf&scene=126&sessionid=1681279895#rd)

1月26日，记者采访获悉，中国科学院资源与环境信息系统国家重点实验室与阿里云达成合作，建设国际领先的“陆地表层系统模拟与计算平台”，从而对地球系统、重大地质灾害等进行更深入的研究。通过“陆地表层系统模拟与计算平台”，科学家可以构建地理数据场空间重构模型，重大地质灾害三维动力学过程模型，地球系统科学数据共享平台等等，从而研究系统中的物质和能量循环的关键缘由。
