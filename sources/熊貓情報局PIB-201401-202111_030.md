# 微软宣布支持 Open Web Docs

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTU0MDcyMA==&mid=2650565468&idx=4&sn=7152e5dfe09653dabc05ef8b407cd601&chksm=befe30c38989b9d552a8bc4309948f4dece01a2da41cdf8d4bf2964da0963e8b6ab6fa7baf4f&scene=126&sessionid=1681279895#rd](http://mp.weixin.qq.com/s?__biz=MjM5NTU0MDcyMA==&mid=2650565468&idx=4&sn=7152e5dfe09653dabc05ef8b407cd601&chksm=befe30c38989b9d552a8bc4309948f4dece01a2da41cdf8d4bf2964da0963e8b6ab6fa7baf4f&scene=126&sessionid=1681279895#rd)

IT之家1月26日消息 微软今天宣布支持 Open Web Docs，这是一个集体项目，旨在支持技术写手社区长期维护高质量和与浏览器无关的网络平台技术文档。Open Web Docs 并不是一个新的文档平台，相反，它将与包括 MDN Web Docs 在内的现有平台紧密合作。IT之家获悉，微软将与 Coil 和谷歌一起成为 Open Web Docs 的创始赞助商，此外还有 Mozilla、三星、W3C 和其他一些个人贡献者的支持。

![](../Images/1b66c532531287e372127722b8f28a63.png)

“Open Web Docs 今天启动，进一步的路线图细节即将公布。该集体的初始目标主要集中在支持 MDN 最近的基础架构过渡，并为 MDN Web Docs 上的核心网络技术文档、浏览器兼容性数据和 JavaScript 文档做出贡献。”
