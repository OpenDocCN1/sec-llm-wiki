## 数字银行应用程序  Dave.com 披露了安全漏洞，原因是已知的威胁演员ShinyHunters在犯罪论坛上泄露了700万条用户记录。

  

知名的威胁行动者 ShinyHunters在犯罪论坛上泄露了7,516,625条用户记录后，流行的数字银行应用  Dave.com披露了一项安全漏洞。

  

据*ZDNet称*，该安全漏洞起源于前业务合作伙伴Waydev的网络  。

  

Dave向执法部门报告了该事件，并开始了对该违规行为的内部调查。该公司还意识到威胁者正试图出售地下网络犯罪中的Dave用户记录，因此雇用了安全公司CrowdStrike来调查安全漏洞。

  

戴夫（Dave）会通知客户有关安全漏洞的信息，并针对该事件强制重置密码。

  

作为持续的暗网和深网监控的一部分，Cyble研究团队的研究人员 确定了已知的威胁演员“ ShinyHunters”，该泄露了700万用户记录的Dave.com。演员最初尝试通过拍卖出售大量的收录数据，然后免费发布，

  

Cyble在6月28日意识到了这一事件，并在7月2日通知了Dave。

  

*“该数据库最初是在拍卖中，在黑客论坛漏洞利用别名“ hasway”进行拍卖，后来在拍卖中被删除。Cyble相信别名属于ShinyHunters。” 据报道 Cyble。*

*“ 7月24日，'ShinyHunters'泄露了Dave.com和其他数据库的情况，事情发生了有趣的转变。泄漏的用户记录已免费建立。”*

  

![](../Images/81ff6121abeee011261e79461e32c2e1.png)

  

泄漏的记录包括：

*   用户身份
    
*   电话号码
    
*   电子邮件地址
    
*   全名
    
*   出生日期
    
*   居住地址
    
*   Risepay ID
    
*   Synapsepay ID
    

不幸的是，对于某些用户而言，泄漏的数据还包括加密的支付卡数据和社会保险号。

*“该数据库似乎已通过将Github网络钓鱼电子邮件发送给Dave.com员工而被转储了。威胁演员似乎是通过在LinkedIn / Crunchbase / Angel在线平台上搜索组织中的开发人员来找到员工详细信息的。” 继续Cyble。*

ShinyHunters成为销售许多其他组织（包括）的数据的头条新闻，也是同一个人/团体也泄露并泄露了/出售了许多其他公司的数据。
