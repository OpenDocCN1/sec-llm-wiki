图标字体是一场真真正正的伟大的黑客攻击。它们轻量，可扩展，在那一段SVG仍未充分在主流浏览器上呈现的年代，用巧妙的方式在网络上呈现出矢量图像。尽管，它的起步如同黑客一般到来，但我觉得，图标字体如同守护矢量图形的精灵，它们依旧存在。

Genericons，一种崭新的，专为博客而制作的图标字体，是Joen Asmussen与Sheri Bigelow及Takashi Irie的贡献。

他们在设计时，保持着最简单的想法，保证轻小，通用，使它们能够自由地被用于各种项目。他们仔细认证，设计出小尺寸，只因将图标字体限制在16\*16px的范围内。

![](../Images/f04df2895a4b40944620477673203e79.png)

字体的名称，本身着重于单词“通用(generic)”，但Genericon既是在纽约北部的一场艺术/科幻小说/游戏会议，又是炮灰霸天虎。如果跟着它的名字寻下去，我想，你会知道它很神奇。

Genericons开始于WordPress.com.网站上通知功能的指针。消息从此传出：有关使用字体来作为图标。很快，有人请求他们将其用于WordPress主题的样式，支持的工具，及其他各种项目中。其次，它们成为了100%免费，GPL许可的一种字体。你甚至会在WordPress的最新默认主题中见到它们：Twenty Thirteen，目前正在开发的一个主题（2333333333

*（这里是Twenty Thirteen主题截图，我就不上了）*

制作一个图标，是需要灌注爱的。它涉及到一个细致，注重细节和技巧的方面：让它变成一个小小的符号，如同“旁白”一样。Genericons已经得到了很多的爱。所有的图标都经过精心排列，被分为16\*16格。每一个符号被以Unicode的方式映射到使用的地方，以避免被显示器读取出。很多灵感是来自于Github，及他们光荣的那篇“Octicons制作”的文章。@font-face字体使用的语法是由Font Squirrel优雅地产生出来的（我们爱那些基佬家伙）。内含的OpenType字体文件（.otf），如果你喜欢，你甚至可以把它放入在你的系统字体文件夹，在Photoshop中使用他们！

图标字体真的很棒，因为你可以很容易地改变它们的大小，颜色，透明度，阴影，旋转，轮廓，或添加渐变/纹理（虽然当你做出最后一个时，你就失去了可扩展性）。你能够使用CSS来改变其外观，就像重新着色一样。所有的图标都有一个灵活的简单规则，即优于SVG。它们还适用于所有现代浏览器，甚至可以工作在IE6上！

尝试用Genericons吧，前往http://genericons.com/，并下载这个字体。将其字体文件夹及genericons.css文件复制进你的项目，并使用相关的HTML语句调用CSS：

```

```

| 1 || <span style\="font-size: 12pt;"\><link href\="path/to/genericons.css" rel\="stylesheet"\></span\> |
| --- | --- |

然后试试下面的CSS例子，它们将改变图标字体的颜色，与复选标记图标交换标准的项目符号列表，或用你自己的样式改造它们：

让每一个图标都变成鲑鱼色Salmon：

```

```

| 123 || <span style\="font-size: 12pt;">.genericon { color: #fa8072;}</span> |
| --- | --- |

或把星星图标变成金黄色Gold：

```

```

| 123 || <span style\="font-size: 12pt;">.genericon-star { color: #fa8072;}</span> |
| --- | --- |

使用图标符号列表：

```

```

| 123456 || <span style\="font-size: 12pt;"\><ul class\="my-checklist"\> <li\>One</li\> <li\>Two</li\> <li\>Three</li\> <li\>Four</li\></ul\></span\> |
| --- | --- |

  

```

```

| 123456789101112 || <span style\="font-size: 12pt;">.my-checklist { list-style-type: none; text-indent: \-16px;}.my-checklist li:before { padding-right: 16px; content: 'f418'; display: inline-block; \-webkit-font-smoothing: antialiased; font: normal 16px/1 'Genericons'; vertical-align: text-top;}</span> |
| --- | --- |

使用的图标样式引用文字：

```

```

| 12 || <span style\="font-size: 12pt;"\><blockquote class\="my-blockquote"\>有时候，我相信在早餐前有六件不可能的事。 &mdash;<em\>Lewis Carroll</em\></blockquote\></span\> |
| --- | --- |

  

```

```

| 1234567891011121314 || <span style\="font-size: 12pt;">.my-blockquote { background: #eee; border-left: 32px solid #ddd; padding: 10px;}.my-blockquote:before { margin-left: \-42px; padding-right: 10px; content: 'f106'; display: inline-block; \-webkit-font-smoothing: antialiased; font: normal 32px/20px 'Genericons'; vertical-align: bottom;}</span> |
| --- | --- |
