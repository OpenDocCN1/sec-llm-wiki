“燕云实验室”是河北千诚电子科技有限公司成立的网络安全攻防技术研究实验室。主要研究方向为渗透测试、代码审计、逆向分析、漏洞研究、CTF对抗、威胁情报、应急响应等。


一、漏洞简介


近日，SentinelLabs 研究人员在 OMEN Gaming Hub SDK 包中发现了潜在的一个高严重性安全漏洞CVE-2021-3437，攻击者可以利用该漏洞触发拒绝服务(DoS)条件、提升权限、并禁用安全产品并执行其他恶意活动，例如危害底层操作系统，数以百万计的 HP OMEN 笔记本电脑和台式游戏电脑受到影响。


“An exploitable kernel driver vulnerability can lead an unprivileged user to SYSTEM since the vulnerable driver is locally available to anyone.” reads the analysis published by SentinelLabs.”This high severity flaw, if exploited, could allow any user on the computer, even without privileges, to escalate privileges and run code in kernel mode. Among the obvious abuses of such vulnerabilities are that they could be used to bypass security products.”


HP OMEN Gaming Hub，以前称为 HP OMEN Command Center，是一种预装在 HP OMEN 台式机和笔记本电脑上的软件产品，该软件可用于控制和优化设备 GPU、风扇速度、CPU 超频、内存等设置。

该漏洞源于对 OpenLibSys 开发的 WinRing0.sys 缺陷代码的重用。会影响预装在 HP OMEN 系统上的OMEN Gaming Hub 软件使用的驱动程序，该软件允许控制和优化设置，包括设备 GPU、风扇速度、CPU 超频和内存。


二、影响范围


11.6.3.0版本之前的HPOMEN Gaming Hub


1.0.44版本之前的HPOMEN Gaming Hub SDK Package



三、修复建议


惠普于 9 月 14 日发布了安全公告以解决此漏洞，建议用户查看 HP 安全建议以了解完整的修复详细信息。
