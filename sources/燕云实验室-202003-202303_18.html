工具简介


AppScan是IBMRational公司出的一款Web应用程序安全性测试工具，可以自动进行漏洞评估。根据网站入口自动对网页链接进行安全扫描并检测Web属性中的嵌入式恶意软件，之后会提供扫描报告和修复建议等。

 新增功能

V10.0.4 中的新功能


Web 服务扫描配置向导：

已修改和改进工作流程（包括自动打开和配置 Postman 和 SoapUI。）

外部客户机向导已合并至此向导。

现在支持 HTTP/2。

现在可以从命令行运行增量扫描。

非标准报头：应用程序数据结果列表中新增了“报头”选项卡，其中显示 AppScan 发现的非标准报头，在扫描期间将会对其进行测试。

Angular 支持：提高了 Angular 网站的 Explore 阶段覆盖率。

现在支持 AWS Cognito。

AppScan Connect：除美国数据中心之外，AppScan Standard 现在还无缝连接至 AppScan on Cloud 的新欧盟数据中心。

HTTP 和 TLS：版本设置已移至“高级配置”中，而且现在按照扫描保存。

许可证：云许可证和本地许可证服务器许可证不再需要密码。
