# 燕云论剑共聚石门，论坛首秀实力开讲

“燕云实验室”是河北千诚电子科技有限公司成立的网络安全攻防技术研究实验室。专注于web安全，网络攻防，安全运维，应急溯源方面的研究，开发成果应用于产品核心技术转化，国家重点科技项目攻关。

  

  

前言

Foreword

  

![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)     

![](../Images/f0f0bc1b3474112091b3d3eecc1b9236.png)

  

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   2021年3月27日下午，由河北千诚电子科技有限公司旗下“燕云实验室”联合“OWASP河北”主办，由河北千诚电子科技有限公司、北京神州绿盟科技有限公司提供支持的“燕云论剑·网络安全技术论坛”在石家庄观和国际酒店首秀开讲。论坛秉承“实力至上、技术共享”的理念，坚持以技术为本的原则，旨在汇聚网络安全人才，共享网络安全技术和经验。本次论坛到场近百人，周边省份如山西、山东、河南、内蒙古、北京的小伙伴也来到了现场，同时论坛邀请了知名网安团队以及多位独立网安白帽子到现场交流。本次论坛由省内安全大佬大鹏Aring担纲主持，在论坛开场中大鹏同学介绍了自己的网安从业经历以及论坛的缘起和筹备情况。  

![](../Images/4b4b42dd960c2845a78a29ab39ceafb1.png)

  

  
  

论坛开幕  

THIS IS TITLE

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   

论坛开始，由河北千诚电子科技有限公司技术副总、燕云实验室团队联合创始人kuteng对论坛进行了介绍，他讲到“省内网安人才都有共同的痛点，一是技术氛围不浓厚，二是碰到技术问题缺求助渠道或平台，三是没有线下组织，大家的沟通交流比较少，希望通过本次论坛建立一个交流的平台，大家能在这个平台上形成一个虚拟的团队，大家平时互相交流、互帮互助，通过各种形式的活动提高自身的技能水平，也希望通过论坛的积极发声影响到省内网安人才生态环境的改变和提升”，最后kuteng对燕云实验室的情况进行了简单介绍。

  

![](../Images/f77fe39d19aaffce52e17dce2b95da2f.png)

  

  
  

第一主题

THIS IS TITLE

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   本次论坛第一项主题是由燕云实验室负责人LvY 大佬为大家带来的《新时代下渗透攻防着力点》，他首先回顾了自己十年网安工作的历程，然后通过对比十年来渗透攻击方式和手段的变化，结合当前新形势下互联网的架构变革，寻找新时代下渗透攻防的着力点。

  

![](../Images/cb5c3f0852363b664720d00802a892fb.png)

  

  
  

第二主题

THIS IS TITLE

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   

第二项主题是由燕云实验室的dp 同学为大家带来的《应用指纹识别技术》，分享探讨如何通过结合wappalyzer的识别技术、安全爬虫以及自定义式poc的一套综合识别方案，从而解决web应用指纹识别实践中的各种特殊案例及难点。

  

![](../Images/6ffd9718c9ea42f9a2d05fd82a0ee4d3.png)

  

  
  

第三主题

THIS IS TITLE

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   

第三项主题是由燕云实验室的zhzyker 同学带来的《新兴扫描工具vulmap技术分享》，分享独立开发的web漏洞扫描工具的研发过程和规划思路，展示vulmap如何满足现阶段大家对漏洞扫描工具功能的要求，探讨未来对实用工具的功能期待。

  

![](../Images/4d2340eb275a5535893a4f9fbeb86536.png)

  

  
  

第四主题

THIS IS TITLE

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   

第四项主题是由绿盟的小叮当同学带来的《HW之信息收集技术分享》，本次议题对信息收集的方法和技巧进行总结和分享，信息收集对于渗透测试是非常重要的，只有掌握了目标单位足够多的信息之后，才能更好地对其进行漏洞检测，可以说信息收集的完整性决定了渗透测试的结果。

![](../Images/0bc0d7095a3b42dc5ec67952abc914ad.png)

  

  
  

第五主题

THIS IS TITLE

  
![](../Images/dff844ad368fe7556ab260ffcc2e0e3b.png)   第五项主题是由绿盟的铁血丹心同学为大家带来了的《提权技术实践分享》，本议题分享Windows、Linux以及数据库平台上的多种提权姿势，避免低权限的账号在渗透测试过程中形成的重重阻碍，提高自己在系统中的权限以便控制全局。

  

![](../Images/cb8941f739a018a2e4fdfc01f18224d6.png)

  

  
![](../Images/5dbdda8dce21f0c92047de88ffad9694.png)  
在论坛主题进行过程中，燕云实验室zhzyker现场发布了最新vulmap v0.7内测版，并在论坛的最后一个环节通过抢红包的方式送出了零组文库邀请码，恭喜以下同学获得邀请码。

  

![](../Images/f9c56310af4d2b47ca6964a55cc10bae.png)
