三、修补建议


截止目前仍没有该漏洞的相关补丁，但是微软提供了临时修补建议如下：


1. 使用 command 把 sourceroutingbehavior 设置为 "drop"

netsh int ipv4 set global sourceroutingbehavior=drop

IPv4源路由被认为是不安全的，并且在Windows中默认为阻止状态；但是，系统将处理该请求并返回拒绝该请求的ICMP消息。解决方法将导致系统完全丢弃这些请求，而不进行任何处理。


撤销上述改变需要：

netsh int ipv4 set global sourceroutingbehavior=dontforward


2. 配置防火墙或负载平衡器以禁止源路由请求
