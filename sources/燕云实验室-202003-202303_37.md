一、漏洞概述  

![](../Images/b52b9c65ab15fb17a33517c0a41a6e06.png)

昨天2021年2月9日，微软官方在https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-24074公布了漏洞CVE-2021-24074，该漏洞是在Windows TCP/IP中引发的Remote Code Execution（远程命令执行漏洞），官方漏洞评级为：  

且影响范围及广，漏洞覆盖包括截止最新的Windows10和Windows Server, version 20H2，可见该漏洞严重性甚高

  

但是该Remote Code Execution漏洞若要利用难度极高，过程复杂，因此短期内很成功复现该漏洞
