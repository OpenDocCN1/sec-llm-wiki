一、About Web Brutator 


工具的介绍简单明了，翻译过来叫“快速模块化Web界面Bruteforcer”

我们先来讲一哈 Web Brutator 的功能


可对webapps的web登录界面爆破账号密码，常规工作中可极大程度省去猜解口令时间，且爆破效率与手工测试无法相比，目前支持的webapps种类如下：

axis2coldfusionglassfishhtaccessjbossjenkinsjoomlarailostandardformtomcatweblogicwebsphere

种类基本上很全乎了

实际上这个工具也有些年头了, 两年前是0.1版本

今天逛twitter发现@securisec转特了 Web Brutator 还有炫酷的GIF过去瞄了一眼发现 Web Brutator 前几天更新了，真实小年的小惊喜
