# 《致命愿望》：与魔鬼签订契约

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MjczMjM2NA==&mid=2247495755&idx=3&sn=8801e449390059a428665113f54a9524&chksm=e9756c68de02e57e34d85d03634bf7abf42c9c396e09f3afc4b2aa0ae860a794fcfe8b3322ae&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MjczMjM2NA==&mid=2247495755&idx=3&sn=8801e449390059a428665113f54a9524&chksm=e9756c68de02e57e34d85d03634bf7abf42c9c396e09f3afc4b2aa0ae860a794fcfe8b3322ae&scene=27#wechat_redirect)

爱奇艺迷雾剧场的新剧《致命愿望》已经开播。由冯绍峰，文淇，范丞丞和郭子凡主演，故事主要讲述了一款名为Wisher的APP毫无征兆的出现在一群大学生的手机里。只要向它许下愿望，完成“随机”分配的简单任务，愿望便能实现。一群禁不住诱惑的年轻人深陷其中，前赴后继地组成了欲望控制下的多米诺骨牌。这一切的背后则被一个神秘的组织操纵着。

  

**![](../Images/7c88a2a466d9ec8ce486f09a0988e0d5.png)**

  

《致命愿望》毫无疑问进一步拓宽了迷雾剧场作品题材的广度，作为国产剧集中较为少见的二分之一现实悬疑片，《致命愿望》设定了一个软科幻（即人类的生活方式与现实差别不大）+近未来的绿藤市，取景自著名的立体城市山城重庆，这座自带赛博朋克气质的多雾城市也完美契合了主创想要表达的科技质感和冷冽的整体色调。幽暗的小巷、高耸入云的摩天大楼，霓虹灯映射下的潮气，还有云雾缭绕的盘山公路，组成了一幅高概念科幻背景下的未来生活图景。

  

**![](../Images/60cb91d120dbe6d3f3217bb8231c9cc4.png)**

  

软科幻的魅力即在于，它看上去离我们现实的生活一点都不遥远。第一集中杨蓉饰演的大学老师王美芬有这样一段台词：“七年前的时候，全球产生的数据是32 zetabyte，而现在是175 zetabyte，数据增长来源于什么呢？是你们每天的出行、导航、购物、刷微信、点赞、自拍等等。十年前，这些数据交互行为是218次，而今天已经是每人每天4785次，如果把这些数据全部储存在蓝光碟上，摞起来的高度，足够从地球到月球往返11.5次。”

  

**![](../Images/eff40de52945325c514d1055ddf0ef91.png)**

  

由此，《致命愿望》向我们抛出了一个有些恐怖但又现实的问题：当大数据足够充足，一个人不但过去和现在将是完全透明的，甚至他的未来，他面对各种问题时最终会作出何种选择，也是可以被预测的。在这种情况下，大数据的掌握者便可以透过某种形式引导某人去完成某件事，并通过一种“交换机制”心理暗示这个人，他所作出的决定完完全全属于他自己，并最终将时间的发展导向数据掌握者想要达成的方向。如此这般，“未来”便被操纵了。

  

这就是开头所言的“Wisher” APP的运行机制。套在一层“游戏”的外壳下，其实是剥夺了人自由作出选择的权利。一切的一切，均在大数据的操纵下被整理成了一行行代码，程序延展成的线操纵着每一个人的命运，并最终随着数据量的扩充，操纵一个集体、乃至全人类的未来。在这样的情况下，“自由意志”将会变成一个伪命题。

  

![](../Images/88d35df19ce5bfc6d7eb46bcb7c0b6b5.png)

  

大数据作为近几年最热的科技名词之一，探讨这一概念对人类影响的科幻作品其实不在少数。最典型的例如前几年大火的美剧《西部世界》，除了探讨高智能AI与“灵魂”存在这样科幻作品永恒的经典话题之外，当故事走出剧中的“西部世界”进入“现实世界”，观众发现那是一个被智能AI操纵的病态社会：每一个人从出生起便被精密计算，预测出未来的生活轨迹和命运发展，并最终被打上某种标签，从事某种特定的工作。

  

如此就真的能决定一个人的命运吗？我们知道，一个人的命运，一要靠自我奋斗，二要考虑历史的行程。一个掌握着大数据的人或者程序，是无法影响到这两点的。所以我们看到《西部世界》中德洛瑞丝变成了一个数据所未能预料到的变量，蝴蝶效应里的那只蝴蝶随即开始振动翅膀，带动一大批人摆脱了这种程序强加给他们的“命运枷锁”，走向了真正的自由。

  

![](../Images/323341060c7986cbeaea009b06af2a12.png)

  

《致命愿望》同样拥有一个颇有野心的剧本，它不光试图探讨大数据对人类未来的影响，也同样设计了混沌学里的蝴蝶效应概念。第一集还抛出了一个“人际场”的模型理论。如果以足够充足的大数据为依托，蝴蝶效应的作用过程与结果将变得可以预测，从一个看似与你毫无干系的人出发，遥控他的行为却能直接作用在你的身上，这是多么的可怖！

抛开《致命愿望》之中的科幻元素，我们能看到主创团队一开始将这部剧定义为“二分之一现实悬疑”的原因。除去那二分之一“不现实”的要素，剧中的人物关系以及人物对立带来的视角切换是写实的。冯绍峰、邵兵饰演的中年组和文淇、范丞丞饰演的少年组两个视角一分为二，分别代表当下和未来。文淇、范丞丞作为APP的实际使用者，在从内部探索这个程序运行的方式和底层逻辑。而中年组则从外部视角切入，试图去摸清Wisher背后隐藏的真相。如此带来的戏剧冲突不得不让人期待未来的故事发展。

  

视觉上，《致命愿望》也延续了迷雾剧场一贯的优点，有诸多可圈可点的地方。在开启支持HDR Vivid视频标准的帧绮映画模式下观看，高对比度带来了更加柔和真实的色彩表现，相比蓝光1080P模式下的画面，明暗对比更加强烈。环境光带来的漫射效应更加真实，也更加凸显科技感。

魔幻3D立体城市重庆作为取景地，也在帧绮映画模式下给观众带来了沉浸式的“江城一日游”。在雾气中缓缓驶向对岸的平底船、蜿蜒曲折的盘山公路和雨中霓虹灯光映射下的天空，给剧集增添了一丝赛博朋克的色彩。剧中开头处一段从上至下俯拍的镜头，毫无疑问致敬了雷德利·斯科特的经典科幻作品《银翼杀手》。那种冰冷氛围感下的霓虹灯柱，无疑让人感到熟悉，这种赛博朋克作品最为显眼突出的视觉元素的出现，也暗示着《致命愿望》的故事内核同样落在高科技社会下，人性所面临的艰难抉择之上。
