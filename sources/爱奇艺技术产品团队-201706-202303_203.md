# 《中国新说唱2020》推出“蹦迪模式” 爱奇艺从视觉、听觉到体感升维视听体验

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MjczMjM2NA==&mid=2247487766&idx=2&sn=3eac263f348c7ffb9c6f92d115f24222&chksm=e9768d35de010423a85ff6ab4d8239f60157e642ff1c531ea9afed42bec6c1933969f23b5fc7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MjczMjM2NA==&mid=2247487766&idx=2&sn=3eac263f348c7ffb9c6f92d115f24222&chksm=e9768d35de010423a85ff6ab4d8239f60157e642ff1c531ea9afed42bec6c1933969f23b5fc7&scene=27#wechat_redirect)

近日，由爱奇艺自制的《中国新说唱2020》火热上线。此次，节目播放界面右上角新增了闪电图标，开启后手机将在节目歌曲演唱环节随旋律节奏振动闪烁——这是爱奇艺创新推出的“蹦迪模式”，打通视觉、听觉、体感等多重感官体验，创造沉浸式综艺视听盛宴。继奇观之后，爱奇艺又在丰富用户观看体验方面创新推出“蹦迪模式”，全新的视听体验让用户直呼“眼前一亮”，众多用户发弹幕表示“好酷”。

  

![](../Images/59f4b451fd30a343c0a5a3e37241205c.png)

  

“蹦迪模式”是爱奇艺创新推出的互动功能，通过振动和光效营造现场感，实现了视频内容从听觉、视觉到体感与氛围的升维式跨越，打造立体化的视听体验。不同音乐的音色及旋律不同，“蹦迪模式”基于律动检测算法，可根据音色差异及旋律变化，对歌曲进行音频分型，并匹配合适的振动和光效，让用户仿佛置身演出现场，进而“跟着音乐动起来”。目前，“蹦迪模式”支持开启振动、开启闪光以及全部开启三种模式，用户可以根据自身的观看需求个性化选择。

  

爱奇艺“说唱”IP系列综艺节目不仅在内容布局方面持续深耕说唱产业发展，更持续通过创新技术优化用户视听体验。《中国新说唱》2019创新将互动视频分支剧情能力融入节目内容中，并推出业内首个互动视频广告，为用户带来可选择的综艺内容。今年，基于爱奇艺原创功能奇观，用户可以一键识别画面中嘉宾以及rapper的个人信息；“蹦迪模式”则进一步打破空间界限，为用户营造了个性化、高沉浸感的视听氛围。

  

《中国新说唱2020》是由爱奇艺自制的华语青年说唱音乐节目，每周五晚8点在爱奇艺、随刻、奇异果TV以及爱奇艺海外版同步更新。首期节目播出后，迅速占领爱奇艺站内综艺内容热度榜TOP1，内容热度峰值突破8200，并在开播4小时内斩获全网近200个话题热搜，引发大众热议。
