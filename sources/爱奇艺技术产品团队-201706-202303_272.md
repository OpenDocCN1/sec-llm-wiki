# 爱奇艺知识发起"停课不停学"计划，8500门免费精品课程已备好

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MjczMjM2NA==&mid=2247486220&idx=2&sn=f640b118dcd10c900b1dcf489f29cc90&chksm=e976972fde011e39ebf2f6edcd07e6b738626674ee9d3bc06029b1efbdd51d61c8f1e77e6e94&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MjczMjM2NA==&mid=2247486220&idx=2&sn=f640b118dcd10c900b1dcf489f29cc90&chksm=e976972fde011e39ebf2f6edcd07e6b738626674ee9d3bc06029b1efbdd51d61c8f1e77e6e94&scene=27#wechat_redirect)

近日来，新型冠状病毒感染的肺炎疫情牵动着每个人的心。为积极响应教育部《关于2020年春季学期延期开学的通知》，2月2日起，爱奇艺知识联合40余家头部教育机构发起“停课不停学”计划，为全国各地开学延期的中小学生推出各年级、各学科近2000场共计80,000分钟的免费直播课，并提供超8500门免费精品录播课程。“直播+录播”的免费授课模式，将充分还原线下教学体验，全面帮助中小学生享受优质的教育资源，搭配使用爱奇艺电视果打开爱奇艺知识还可体验大屏学习，线上学习不伤眼！**点击文末“阅读原文”**可了解爱奇艺电视果详情。

  

![](../Images/06291e46478dcb3b240bc0867f61d461.png)

  

爱奇艺知识“停课不停学”计划专区已在爱奇艺教育频道、知识频道、爱奇艺知识APP同步上线。  

  

免费直播网络课程将在2月6日起陆续上线。爱奇艺知识联合了学而思、作业帮、有道精品课等多家教育机构，提供覆盖小学一年级到高中三年级的各类学科直播课，通过科学的课程规划、体系化授课内容及师生互动，帮助全国中小学生按计划保持学习进度，及时为学生们答疑解惑，解决家长后顾之忧。

  

免费录播课程已于今日全面上线。爱奇艺知识在原有8200门免费课程的基础上，联合熊猫博士、ahaschool、义方教育等合作伙伴再新增超300门课程。据了解，总计超8500门的免费录播课覆盖了K12、文史、职场、艺术、运动健身等各类教育内容。其中，K12免费录播课不仅包含语文、数学、英语等学科的中小学课堂同步课程，还涉及少儿科普、医学科普、绘画启蒙、思维训练等多领域素质教育课程，集应试与素质教育为一体，兼顾学习效果提升与兴趣培养。

  

![](../Images/da1d07bdcda073bcd578acf7e4fc5617.png)

  

此外，爱奇艺知识还联合教育机构上线了关于新型冠状病毒的少儿科普免费课程，用通俗易懂的方式让孩子们树立防范意识。   

  

爱奇艺副总裁王学普表示，在这个特殊时刻，爱奇艺知识希望发挥在互联网、技术等领域的优势，联手教育产业优质合作伙伴，全力以赴帮助全国疫情地区的学生们“停课不停学、学习不延期”。同时，爱奇艺知识将不断扩充更多免费课程，保证每堂课的教学质量，让学生们安心学习。

  

![](../Images/55097e64d3772ce3dd01e2738c5e3bde.png)

  

目前，爱奇艺知识已覆盖外语、文史、艺术、亲子、职场等15大品类，与超1800家合作伙伴达成深度合作，在内容深耕优选、塑造伙伴品牌、IP定制课程等方面均实现突破。2019年12月，爱奇艺知识还发起了知识百科“爱知计划”，宣布投入71亿流量补贴，激励、扶持百科短视频创作者，并在现金补贴、多元变现、内容指导、官方荣誉、创作沙龙等方面给予更多资源倾斜。未来，爱奇艺知识将继续开放自身平台能力，全面助力教育产业的发展，让科技助力创作，让学习快乐简单。
