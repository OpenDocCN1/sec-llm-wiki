# 爱奇艺技术沙龙——云架构及AI深度学习平台实践与应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MjczMjM2NA==&mid=2247484720&idx=2&sn=aada6608f19633bb64e278a30619cc8e&chksm=e9769913de011005882735847a132f31c9f0e3743b0ccfc0269708dfdfbfe76ef8acd2251ea7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MjczMjM2NA==&mid=2247484720&idx=2&sn=aada6608f19633bb64e278a30619cc8e&chksm=e9769913de011005882735847a132f31c9f0e3743b0ccfc0269708dfdfbfe76ef8acd2251ea7&scene=27#wechat_redirect)

本期【爱奇艺技术沙龙】邀请了爱奇艺、京东、Intel的技术专家，分享他们在云计算、AI平台建设方向的实践和经验。现场将为听众分享，在用户高速增长、海量用户并发等不同阶段，爱奇艺在云计算基础架构方面的思考和实践经验；面对用户日益多元化、专业化的收看使用需求，通过AI技术为用户提供更加智能化的视频观影体验，同时还将分享爱奇艺是如何通过AI平台的建设，为更好的用户体验提供技术支持。

**活动信息**

  

【时间】2019年03月02日（周六）

【地点】上海市长宁区临虹路365号爱奇艺创新大厦

  

**出品人**

  

![](../Images/699897c7dd700ba28e0711cc5069773e.png)

吴杰珂

爱奇艺高级技术总监，现负责爱奇艺私有云基础架构相关技术研发及运营，包括：分布式计算，分布式存储，网络虚拟化，计算虚拟化，系统性能分析，集群性能优化，智能化运维管理，深度学习平台等，另外，负责并参与了云平台计算云团队的建设，基础服务的落地及推广，帮助和推进爱奇艺公司整个技术方案的云化。在加入爱奇艺之前，服务于英特尔亚太研发中心，从事多媒体框架，图像处理，编解码器，嵌入式操作系统，开源软件等相关的研究工作。研究过程中共申请20多项国内外专利。

  

活动嘉宾

![](../Images/210b6a0e8719ab1ebe6edacdb6e58328.png)

**讲师**：蒋文杰 **爱奇艺网络虚拟化专家  **

**主题：**《高性能负载均衡及IPv6实践之路》

内容简介：随着国内IPv6规模部署的不断推进，给互联网公司进出口网关和负载均衡系统提出了挑战。该分享介绍了爱奇艺自研的高性能4层负载均衡器DPVS,以及如何搭建IPv6的进出口网关和负载均衡系统。

  

![](../Images/13b370de2f6ed93abe690328cb63a953.png)

**讲师**：石雪峰 **京东工程效率专家**

**主题：**《高效DevOps平台建设实践之路》

内容简介：随着DevOps理念的深入人心，行业越发重视工程效能建设，很多公司都在加大投入打造内部DevOps平台，但是面对企业内部业务背景复杂，竖井式的系统泛滥，团队边界模糊缺乏统一规划，如何能在企业内部打造一个可落地的持续交付平台成为了一个现实问题。在本次分享中会跟大家探讨如何打造一个高效的DevOps平台，并以实际案例剖析平台设计的核心思想，技术实践以及落地路径，希望可以帮助大家理清平台建设思路，让DevOps真正发挥价值。

  

![](../Images/2a48bfac1660f22154aac2289822ab6d.png)

**讲师**：张磊 爱奇艺AI优化专家

**主题：**《基于CPU的深度学习推理服务优化方案》

内容简介：随着人工智能技术在多媒体领域的广泛应用， 如何提升深度学习服务性能，提高应用部署效率，充分利用已有的 CPU 集群，成为深度学习应用落地的重要问题。该分享介绍爱奇艺在 CPU 集群上实现深度学习服务部署和优化的云平台架构，以及如何应用 MKL-DNN， OpenVINO，多线程并发等技术，完成深度学习应用在 CPU 上的优化和加速。

  

![](../Images/15cd2918303380ddee8186159d8bdb92.png)

讲师：许莉 Intel资深架构师

**主题：**《高性能视频编解码及推理优化》

内容简介：当今信息膨胀的年代，视频称为主要的信息传播方式之一。作为人工智能的主要领域，实时视频分析被广泛地部署在云端数据中心。英特尔在其高密度硬件平台和软件解决方案(FFMPEG+Openvino)上，为实时视频分析业务提供了完整的解决方案。该解决方案不仅融合了传统视频转码业务平台，同时引入了异构推理软件库Openvino以扩展硬件视频分析能力。本次讲座会以实际的例子，介绍如何在英特尔的硬件平台VCA2上利用FFMPEG链接英特尔异构系统推理库Openvino来实现多相机的实时球赛分析。
