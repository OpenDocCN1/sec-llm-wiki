今天测试时发现没有带串口模块，正好手边有个树莓派，所以将开启串口功能的步骤记录了下来，如有不正之处，万望指正：

  

1 修改APT软件源

  

本来直接用的树莓派自带的apt源，无奈挂代理都不好用，只好更换

  

在命令行输入**sudo nano /etc/apt/sources.list**将原来的内容使用**#**注释掉，并添加如下内容：

*   
*   

```
deb http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ buster main non-free contribdeb-src http://mirrors.tuna.tsinghua.edu.cn/raspbian/raspbian/ buster main non-free contrib
```

安装minicom工具

*   

```

```

  

2 开启raspberrypi的UART串口

  

首先进入树莓派配置**sudo raspi-config**选择接口选项

![](../Images/97177f486e6adb482676d873bc1a5b06.png)

点击确定后，再选择串口

![](../Images/e3ef0db1f5d69158de846185473f3083.png)

提示是否开启串口shell，这里我们因为要将raspberryPI作为串口工具用，所以我们选择否

![](../Images/aad9bb2a519bfdf3d1d93c539cf7c707.png)

提示是否开启硬件串口，选择是

![](../Images/83f2111f8b9df774a957a85f1ed71793.png)

然后重启，我们就不用买USB2TTL了**XD**

![](../Images/940f98948a0995efa9e753a0fcc758ce.png)

我们查看一下**/dev**下的设备文件，可以看到**新增了一个ttyS0**的接口

  

3 测试串口

  

接下来我们就来测试一下raspberryPI的串口，首先将其接到我们需要调试的设备上：

![](../Images/cca6724363862d4ff52fcc634bb302e3.png)

从这个引脚图中可以看出TX和RX分别在8和10脚，将树莓派的TX接到设备上的RX上，将树莓派的RX接到设备上的TX上

  

然后启动**minicom -D /dev/ttyS0**来查看信息

![](../Images/25ac30092c90187cf820f7967afb32ee.png)
