# 物联网与信息安全团队2022级硕士新生系列讲座第八期

2022年11月23日，“物联网与信息安全团队”2022级硕士新生研讨会第八期在人工智能学院泰达西院8号楼207会议室顺利召开，本团队全体2022级研究生共10人参加。

![](../Images/80738190e59d5827848907198a7a5cb3.png "111111.jpg")

本次会议主题为“工作经验分享”，由于文平老师与研一新同学分享了工作经验以及为大家提供科研规划的指导和建议。在报告中，于文平老师由自己在工作过程中面临的问题引入，结合自身工作经历为大家介绍了自己的心得体会，以帮助大家更快地接受和融入工作，规避错误；以及缓解了同学们刚刚进入科研生活的紧张无措。其次，对于工作，于老师告诫大家要不断学习，不断总结，对工作任务及时反馈，知识充盈头脑，面对业务才会得心应手；对于科研，于老师借用“10000小时定律”指导大家结合自身实际情况做好科研规划并严格执行，确保科学研究有条不紊地开展。![](../Images/3ad8e7a267c934cf325f460723982b9c.png)

最后，于老师以“笃行致远、惟实励新”八字箴言与大家共勉。祝愿同学们能够顺利进入科研状态，按照自身规划，追寻心中的目标，早日实现自己的科研成果。
