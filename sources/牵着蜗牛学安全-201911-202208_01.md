# **2、分析HeapDump**

用 heapdump\_tool.jar 工具对 Heapdump 进行分析。

> heapdump\_tool.jar 是基于 jhat，通过 jhat 解析 heapdump 文件，所以建议 jdk 版本为 1.8。  
> 使用方法：  
> *java -jar heapdump\_tool.jar  heapdump*  
> 查询方式：  
> 
> *   `` `关键词：如 password` ``
>     
> *   `` `字符长度：如 len=10 获取长度为 10 的所有 key 或者 value 值` ``
>     
> *   `` `按顺序获取 ：如 num=1-100 获取顺序 1-100 的字符` ``
>     
> *   `` `命令：` ``
>     
> 
> *   `` `geturl`：获取所有字符串中的 url ``
>     
> *   `getfile`：获取所有字符串中的文件路径文件名
>     
> *   `getip`：获取所有字符串中的 ip
>     
> 
> *默认不输出查询结果非 key-value 格式的数据，需要获取所有值，输入*`*all=true*`*、*`*all=false*`*取消显示所有值。*

![](../Images/17df0c5b29cd79727b8f40b8ab5b761c.png)

在分析过程中，发现一对阿里云 ak/sk。

# **3、GetShell**

> AccessKey（即访问密钥）是云平台用户在通过 API 访问云资源时用来确认用户身份的凭证。  
> 主账户/根用户的 AccessKey 具有主账户的完全权限，因此云厂不建议直接使用主账户/根用户的 AccessKey 进行 API 调用。

拿到 ak/sk 后的利用方式：

*   第三方平台，如行云管家
    
*   云厂官方工具
    
*   aksk\_tool.jar
    

用 aksk\_tool.jar 进行访问，命令为`java -jar aksk_tool.jar LT... 4Vg5...`。

![](../Images/6abff071e9a9ccce4aa6037af48d7d4c.png)

共发现 26 台 ecs、3 台 MySQL 和 存储对象 OSS。

![](../Images/12bcdbf01aa2aee4914aecc82675c174.png)

![](../Images/8ef539eca2761631af0631139c9d67ca.png)
