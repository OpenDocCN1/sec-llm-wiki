    ● 发现可被使用的Payload后，使用再使用对应数据库版本的PAYLOAD进行测试（MySQL >=5.5、MySQL >= 5.6 、MySQL >= 5.0.12），获取大致数据库版本  
    ● 尝试联合查询读取1 to 20 列数据
    
6.  打印结果：可注入的参数、可使用的Payload与注入类型、网站使用的中间件版本、DBMS版本

#### 1.首先当我们当使用sqlmap默认命令

```
sqlmap -u 
```

提交请求时默认的UserAgent为：

```
sqlmap/
```

这样就很容易暴露

```

GET /pikachu/vul/sqli/sqli_str.php?name=admin&submit=查询 HTTP/1.1
```

一般黑客会在`SqlMap`添加`--random-agent`参数，来避免被发现。

**可根据上述流量提取攻击特征：**  
若攻击者使用`SqlMap`不添加`--random-agent`参数，则可通过捕获请求包的`USER-AGENT`字段，来判断攻击者是否在使用`SqlMap`进行攻击

### 0x04 Sqlmap特征总结

*   `SqlMap`的关键字特征：`user-agent`、 xss测试语句、随机数的位数
    
*   `SqlMap`的攻击流程具有一定的顺序和规律
    
*   `SqlMap`的一些Payload测试语句具有模板特征
