## 一、收集域内基础信息

1、查询域（需要启动Computer Browser服务）

*   在Win7上操作启用
    

![](../Images/f3ccabe8ba918ca7dc71be926f623a56.png)

*   在Win2012R2上操作启用
    

![](../Images/9221fdcc22103baae36ae41dbe73e6c9.png)

```
net view /domain
```

![](../Images/5497a7ac1a34f6f0cccedffdd55a0dd6.png)

2、查询域内所有计算机（然而只看到预控服务器）

```
net view /domain:HACKBIJI
```

![](../Images/98377017de485521b61350b970baef4d.png)

3、查询域内所有用户组列表（默认13个组）

```
net group /domain
```

![](../Images/255d59ae4f0d3cbe4d14f895424f47df.png)

4、查询所有域成员计算机列表（确实是所有成员的名字）

```
net group "domain computers" /domain
```

![](../Images/b11f0af0e66b1b357bec1bb8c5660b56.png)

5、获取域密码信息（这个是密码设置的要求）

```
net accounts /domain
```

![](../Images/e85ea59a8ec13526f5ffa1997ff367ce.png)

6、获取域信任信息

```
nltest /domain_trusts
```

![](../Images/bf91df51d37237287a4259dadb45e5be.png)

## 二、查找域控制器

1、查看域控制器的机器名

```
nltest /DCLIST:HACKBIJI
```

![](../Images/b685ffec93a78e55f5b591f2a271eed0.png)

2、查看域控制器的主机名

```
nslookup -type=SRV _ldap._tcp
```

![](../Images/fece49d831189079cf00179f6925b3f8.png)

3、查看当前时间

```
net time /domain
```

![](../Images/b8dac87718ec9344ead1e91f1a44c33f.png)

4、查看域控制器组

```
net group "Domain Controllers" /domain
```

![](../Images/8c666b44b17f2ae6e3bc7ceedf2e862b.png)

## 三、查询所有域用户列表

1、向域控制器进行查询（实用命令）

```
net user /domain
```

![](../Images/1ed8bb572aa78deb3f722887dd1930d4.png)

2、获取域内用户的详细信息（用户名、描述、SID、域名、状态）

```
wmic useraccount get /all
```

![](../Images/566af9c9a4ac2ae260155f18349e085f.png)

3、查询本地管理员组用户（2个用户名，1个用户组）

```
net localgroup Administrators
```

![](../Images/ddbf767cbbc5d31f4075fa2b5aac7c7a.png)

生成的结果会保存在文件中。

7、查询远程系统中运行的任务（不怎么灵）

```
FOR /F %i in (ips.txt) DO @echo [+] %i && @tasklist /V /S %i /U user /P password 2>NUL > output.txt && FOR /F %n in (names.txt) DO @type output.txt | findstr %n > NUL && echo [!] %n was found running a process on %i && pause
```

![](../Images/36d34fc08c51842209d54804db3794f2.png)

8、扫描远程系统的NetBIOS信息

```
for /F %i in (ips.txt) do @echo [+] Checking %i && nbtstat -A %i 2>NUL >nbsessions.txt && FOR /F %n in (admins.txt) DO @type nbsessions.txt | findstr /I %n > NUL && echo [!] %n was found logged into %i
```

## 六、利用Powershell收集信息

  

*   检查Powershell状态
    

![](../Images/fbfd74c56a99ae5e47a60e3d1cf032e7.png)

*   将状态修改成Unrestricted（需要管理员权限）
    

![](../Images/db54f9dde9fde28c2c7e15c87ce9e585.png)

*   下载PowerView.ps1^(\[2\])
    
*   导入PowerView.ps1，并运行查询命令
    

```
Get-NetDomain #获取当前用户所在域的名称
```

![](../Images/e3d2eae83ad9a26d80f38c5ad1d9a441.png)

```
Get-NetUser #获取所有用户的详细信息
```

![](../Images/21e214d6372c3ef06532c3860af554c6.png)

```
Get-NetComputer #获取域内所有机器的详细信息
```

![](../Images/7f49ad8658e636e658d437197aaa18a7.png)

```
Get-NetShare #获取当前域内所有的共享信息
```

![](../Images/2ff21e01ac9dc7b48520fddfbd837848.png)

```
Get-ADObject #获取活动目录的对象（内容超级多）
```

![](../Images/52156935f2e86e2ae576aa109cf7073c.png)

```
Invoke-UserHunter #获取域用户登陆的计算机信息，以及该用户是否有本地管理员权限
```

![](../Images/f0c2ce9f9207d0c1ff95c8b5f237ad57.png)

```
Invoke-ProcessHunter #通过查询域内所有的机器进程找到特定用户
```

![](../Images/27245c5f16cc16c78e7f723c6a7e9478.png)

还有很多命令等待你自己去探索～
