kali 2020.02版本，不能连接ssh问题及解决方法

问题点：由于新版本不熟悉，网上资料也少，导致连接不上ssh，苦恼。

解决方法：

配置SSH参数

修改sshd_config文件，命令为：

vim /etc/ssh/sshd_config

1、 

将PermitRootLogin without-password修改为

PermitRootLogin yes

 //202002版的kali linux中是PermitRootLogin prohibit-password（关键点） 

2、PasswordAuthentication yes   //将前面的#去掉


3.然后启动SSH服务，命令如下：
  （1）/etc/init.d/ssh start或者service ssh start


  启动SSH服务以后，通过如下命令来查看启动是否成功：

  （1）/etc/init.d/ssh status或者service ssh status
  如果状态为“active (running)”则表示服务在运行当中。

4. 然后设置开机自动启动

命令：update-rc.d ssh enable
