Metasploitable 2 autopwn

 

最近搭建metasploitable 2 靶场，然后突然发现msf一个好玩的模块，今天来通过metasploitable 2靶场来介绍一下。

 

安装metasploitable2

安装什么的就不用说了，下载完直接是vm虚拟机格式，直接打开即可，设置好网络。

打开后，登录用户名密码都是msfadmin ，

登录后是一个终端页面，咱们看一下ip地址，其他的就不用关了，什么服务什么的都已经自动开启了。


欧克，靶机ip出来了：192.168.134.134

现在就是来配置msf了。

配置metasploit

安装

Apt-get install Metasploit-frameworks -y

安装postgresql

Apt-get install postgresql -y

 

Msf5现在已经没有自动攻击模块了，需要自己下载添加msf文件，有人说找不到下载地址？

下载地址其实msf有，你们看看，很贴心的。


 


See 后面那个就是下载地址，我这个是已经添加完了的，要是没有添加的话你加载这个模块不仅有下载地址，还有需要放置的文件夹地址。

Load db_autopwn //加载模块

 

msf5auxiliary(scanner/portscan/tcp) > load db_autopwn

[-]Failed to load plugin from /usr/share/metasploit-framework/plugins/db_autopwn:cannot load such file -- /usr/share/metasploit-framework/plugins/db_autopwn.rb

msf5auxiliary(scanner/portscan/tcp) >

 

 

这是我删除模块后加载的情况，它告诉你了模块应该放置的目录。

我们现在重新放置一下。



可以看见，添加好了。

 

那咱们就开始干吧！

懒人的福利

（为了给你们截屏，我又重新演示一次，我太难了！先把kali关机了）

 

1.  开启数据库

servicepostgresql start

2.  初始化msf数据库

Msfdbinit

3.  启动msf

Msfconsole



4.  连接数据库

Db_status

5.  加载模块看看情况

Loaddb_autopwn



6.  先扫描目标主机，msf自带了端口扫描模块，咱们先搜索一下，然后用tcp扫描，配置好，就开始扫描了。




 


7.  扫描结果出来了，很多端口开放了，咱们可以查看一下

hosts



8.  扫描完了，我不知道他那个端口存在漏洞，怎么办。就加载自动攻击模块，一个个去匹配尝试（懒人福利）。

9.  咱们先看看autopwn使用方法

Db_autopwn-h   //有请百度翻译



10.         来来来，最简单的配置如下，

Db_autopwn-t -p -r -e

11.         默认对所有端口进行测试，一般可以用这个，我试了一下，这个靶机要测试1400多个，我的破笔记本测试的时候卡死，所以我就不适合这个，我看了一下我的那个shell，php的漏洞，那肯定是web服务的，咱们就指定80端口就好

12.         一条命令就欧克了，剩下的等着shell就好了，喝口水。歇会歇会。

Db_autopwn-t -p -r -e -PI 80


 


13.         自动帮你测试exp，web有611个，看见那个0和那个1没有，sessions代表会话，已经利用成功了一个，咱们等着跑完。说实话，就这一个。哈哈哈。看看是什么漏洞。（这里提一下，msf在测试exp的时候，后台会有设置会话监听，很多的，这个时候电脑就比较卡了，当测试完后，那个没有会话的监听会自己退出，说明什么，说明一台好电脑的重要性，）


14.         已经全部测试完了，就一个会话，php_cgi的漏洞，咱们来看看这个会话怎么样。


15.         经常这个样子，我也不知道是电脑卡了还是会话有问题，咱也不敢问，毕竟4G的内存维持一个win10，两个虚拟机，它也是幸苦。
