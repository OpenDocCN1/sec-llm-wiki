#### 0x00 前言  

生活中很多的事情并不是你都可以控制的，网络中也是，你以为鼠标，键盘在你手里就安全了吗，你的每一次操作都可以让自己陷入深渊。

今天要给大家聊一聊 web 方面的一类漏洞，点击劫持。

0x01 简单点击劫持攻击  

我们首先来看一个例子；

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1077447277909868544](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1077447277909868544)

  

大家可以看到，视频中我点击 Click 弹出了所在地区的天气，有的表哥可能会想Click 是不是个 a 标签，链接了地址。其实大家在视频中可以看到，在同样位置的下方我放了一个 a 标签做对比，a 标签显示的颜色是不同的。

这里我们先来了解几个主要的 CSS 样式的知识，

> position 用来定义标签的位置，当选项为 absolute 时，为绝对定位，元素可以放置到页面上的任何位置。

> z-index 属性设置元素的堆叠顺序。拥有更高堆叠顺序的元素总是会处于堆叠顺序较低的元素的前面。
> 
> Z-index 仅能在定位元素上奏效（例如 position:absolute;）！

> opacity 属性设置元素的不透明级别。

这里我也在想，如何利用点击劫持进行攻击？

其实如果我们将网络钓鱼和点击劫持结合在一起，诱骗受害者下载某些非法文件或者执行某些非法操作，就可以完成某些攻击。

#### 0x03 网络钓鱼+点击劫持+msf

前段时间公众号推过篇钓鱼的文章，这里我们就可以尝试利用钓鱼+点击劫持，诱导受害者下载被改过名或者进行过免杀的木马文件，进而完成攻击。

[社工之网络钓鱼](http://mp.weixin.qq.com/s?__biz=MzI5NTQ1MTI3MQ==&mid=2247483921&idx=1&sn=042d9a94c790d31f063ce1e27cbcb7d9&chksm=ec522df9db25a4efd6e86f15828a01832f3bf42d2010883dc0eaaba8d3b1accc955bf9038d3a&scene=21#wechat_redirect)

这里假设受害者连上了我们构造的钓鱼 WIFI 热点，热点的 DNS 将百度解析到我们自己的服务器地址，而在服务器地址上我们构造了用于钓鱼的浏览器 Flash 升级页面，诱导受害者安装 Flash ，而提示安装的地方利用点击劫持，让用户在不知情的情况下下载安装我们改过名的 msf 木马文件。

0x04 关于点击劫持的预防

网站方面：  

很多网站对用户保留了 <img>  标签，可用于用户信息设定头像等，这里就需要注意，<img> 标签的 style 属性是否可能导致浮出，是否可被攻击者进行网站某些关键信息的修改，或者图片覆盖。

利用专门防御 iframe 嵌套的点击劫持攻击，由微软提出的一个 http 头

`X-FRAME-OPTIONS `在IE8、Firefox3.6、Chrome4以上的版本均能很好的支持。

  

用户方面：  

点击劫持的利用有点类似于钓鱼攻击，一方面需要自己有些安全意识，另一方面要清楚自己所操作的每一步的意义，尤其在软件安装或者下载文件时，检查文件的合法性。
