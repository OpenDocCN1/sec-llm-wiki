IAEA核设施计算机安全建议书简介


IAEA（国际原子能机构）出版了关于核安全的一系列标准及建议指导。在核安全体系中，计算机安全（即网络安全）作为核安全的一个重要内容，IAEA也给出了相关的技术建议，目前并没有正式发布，处于草案阶段。IAEA核设施计算机安全技术指南（草案）（编号NST045和NST047）旨在协助成员国核设施运营商及核设施承包商，供应商实施计算机安全（草案中计算机即网络安全），并提出解决网络安全问题的技术方法。该指南中技术方法对其他工业设施的网络安全防护同样具有指导意义。

IAEA有关计算机安全的建议书有很多，都包含在核安全系列建议书（Nuclear Security Security Series 简写NSS）中。关于安全目标核原则的建议书为NSS20；关于安全概念、策略、一般方法的建议书为NSS13、NSS14和NSS15；关于安全技术应用指南的编号为NSS23-G，NST045；关于计算机安全技术指南的建议书有NSS17、33-T、NST047。

NST045（建议书名称为COMPUTER SECURITY FOR NUCLEAR SECURITY即核设施计算机安全），NST047（建议书名称为COMPUTER SECURITY TECHNIQUES FOR NUCLEAR FACILITIES 即核设施计算机安全技术）。而在两个建议书中计算机安全的概念范畴等同于我们熟知的网络安全概念，为了保持和原建议书的一致性，本文中将沿用计算机安全的说法。本文主要介绍NST047。

NST047（建议书名称为COMPUTER SECURITY TECHNIQUES FOR NUCLEAR FACILITIES 即核设施计算机安全技术）建议书目录如下：

下面对NST047各章内容进行简要介绍。


第一章 介绍



本章对NST047建议书的背景进行了阐述，阐述了网络攻击的严重后果及计算机安全在核安全中的进行计算机安全防护的必要性，以及计算机安全防护的主要目标为防止核敏感信息的泄露和防止对核设施的破坏。计算机安全防护的范畴包括核设施整个生命周期的计算机安全防护和核燃料测量核控制系统。最后阐述了本建议书的主要结构。


第二章 基本概念和关系



本章首先介绍了核安保、核安全核计算机安全的概念。其中，核设施中计算机安全的概念为“计算机安全与基于计算机的系统有关，尤其是那些执行或支持核安全，NMAC和敏感信息管理功能的系统。计算机安全性提供了防御网络攻击的技术和工具。计算机安全性还可以防止可能影响安全性的人为行为或疏漏。”本章还阐述了设施功能，计算机安全级别，系统和域的概念。

设施功能即设施功能是确保核设施安全性所需的活动，过程和操作。包括但不限于对核安全，核保安或NMAC重要的职能，或利用敏感信息的职能。设施功能分配给执行这些功能中一项或多项的系统。

计算机安全级别是一个抽象概念，它定义设施功能以及执行该功能系统所需的安全保护等级。对于每个计算机安全级别，都定义了一组特定的保护和预防措施。

计算机安全域是一种逻辑和/或物理概念，它根据系统组的安全级别定义系统组的边界，以简化计算机安全措施的管理及应用。

（c）每个设施功能都分配给一个或多个系统。

（d）单个系统执行一个或多个设施功能（例如HMI）。从安全性的角度来看，理想的情况是，单个系统执行单个设施功能，但是出于其他考虑，设计人员可以自行决定是否将一个或多个设施功能分配给系统。

（e）单个安全级别应用于一个或多个安全区域。

（f） 每个安全区仅分配一个安全级别。

（g）每个系统都位于一个安全区内。

（h）一个安全域包含一个或多个系统。

典型核设施安全域模型

保护系统的标准方法是使用安全级别和安全区域的概念为所有系统构建设施架构。分配给区域的安全级别基于该区域内系统执行设施功能所需的最高安全保护级别。

域概念要求将相同的安全级别分配给该区域内的所有系统。通常，核设施区模型由许多不同的区组成，其中几个区可能分配了相同的安全级别，如图。
