编者按

  

*最近全球疫情肆虐，美国不断借疫情攻击中国。美国政客的政治手段和攻击手法昭然若揭。而美国的网络安全公司也有“政治”倾向（忘记了，美国本来就是政商一体的）。在这篇美国anomali网络安全公司的技术报告中，安全研究人员仅凭一封钓鱼邮件就将网络战的锅扣在了中国，而且还没有找到直接证据，我想问，这样严谨吗？美国的网络安全公司真的是为了钱，披着技术公司的外衣，给美国政客干脏活。*

  

下面，我们看看这个公司如何利用一封钓鱼邮件的技术分析，甩锅中国网络攻击的。

  

  

概况

  

anomali网络安全公司网络安全研究人员发现一封针对越南岘港市政府雇员的鱼叉式网络钓鱼电子邮件。该电子邮件包含一个恶意的Microsoft Excel 文档，该文档释放了恶意动态链接库文件，该DLL文件通过 HTTP 协议获取主机的反向SHELL。该DLL文件共享代码与Pirate Panda组织使用的exile-RAT相似性很高。  

  

##   

  

钓鱼邮件

  

在下面屏幕截图中，显示的网络钓鱼电子邮件是由一名政府雇员发送给另一个政府雇员的。邮箱后缀为"danang.gov.vn"。  

![](../Images/d4f654c2bedcd86abb6898ab1e046899.png)

主题标题是"C\_p nh\_t l\_ch tr\_c l\_30/4 v\_ 1/5"，谷歌翻译为"更新的时间表30\_4和1\_5.eml"。

*   4月30日是"统一日"，标志着1975年南北越南统一
    
*   5月1日是越南全国的"劳动节"假期
    

![](../Images/9377f7d61cac82e81f3b51aa4ffbd7e8.png)

该钓鱼邮件可能来自真正的内部邮箱，因为 Microsoft Exchange 将其归类为"内部"，电子邮件标头 10.196.132.154 中的 IP 地址来自内部专用网络。如果原始电子邮件帐户与真正的员工相关联，那么该员工很可能以前遭到泄露。

在名为"Cöng vión phón m\_m\_N\_ng"的在线电子表格中，仅找到有关受害者电子邮件地址的信息，谷歌将其翻译成"岘港软件园"。无法确定列出的政府雇员与软件员之间是否存在任何联系。电子表格包含岘港政府员工的电子邮件地址、电话号码和职位，受害者的职称为"专家"。该电子表格于dsp.vn网站（一个政府拥有的网站）托管。

![](../Images/5992ade69fd54236e68d69564dbb40ef.png)

岘港位于西沙群岛对面的海岸。2020年3月，西奥多·罗斯福号访问岘港，纪念越南与美国的关系。据新闻报道，"作为唐纳德·特朗普总统国防战略的一部分，华盛顿最近高度重视改善与越南的防务关系，该战略优先考虑与中国的战略竞争，并打击其在亚洲日益增长的军事能力。

自新冠病毒疫情爆发以来，南海的各国海军活动有所增加，包括中国军舰"辽宁"号和美国海军舰艇在该地区巡逻，区域紧张局势持续的迹象。

##   

  

恶意 Excel 文档

  

网络钓鱼电子邮件包含一个名为"lich truc li"的附件，该附件翻译为"办公室日程安排"。  

![](../Images/492148ce72ee78a8117723b264608020.png)

电子表格包含一个表格，三个标题"b\_ng phón t\_c trung t\_m d\_li\_u"，该表翻译为"数据中心分配表"，"TRUNG T\_M PH\_T TRI\_N H\_TNGA N\_NG\_NGN\_NG\_NG\_NG"，翻译为"多基础设施发展中心"和"ph\_ng h\_tng"，即"系统室"。这可能支持政府雇员在岘港软件园的数据中心工作的假设。此电子表格可能是员工计划。列 B 似乎包含员工姓名，而 C 和D 对应于第 19-24 行中布局的班次模式。开源搜索表明，首字母缩略词"TC1"、"TC2"和"TC3"可能是指技术中心。

打开 Excel 文档时，两个可执行文件（utilman.exe 和mpsvc.dll）将释放到文件夹%AppData%Microsoft\\Corporation中。

Utilman.exe 是 Windows Defender 的合法可执行文件Mpeng.exe。攻击者使用 DLL 侧加载技术使用合法安全产品加载恶意 dll，然后在启动文件夹中创建 utilman.exe 的快捷方式，这样在计算机的下一次重新启动期间执行，并与命令和控制（C2）服务器通信。

![](../Images/e1f961044b068bca2b2c2369c4edaeeb.png)
