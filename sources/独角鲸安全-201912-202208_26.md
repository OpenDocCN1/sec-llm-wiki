**摘要**  

2015 年以来，“蔓灵花”APT组织一直在使用未被曝光的下载器的变体攻击巴基斯坦和中国的相关机构。我们根据样本中发现的 PDB 字符串命名此恶意软件系列为ArtraDownloader。目前，我们发现该下载器存在三个变体，最早时间戳为 2015 年 2 月。“蔓灵花”APT组织使用该恶意程序与其使用远程木马BitterRAT进行通讯。

2018年末至2019年初，“蔓灵花”APT组织发起了一轮针对巴基斯坦和沙特阿拉伯相关机构的网络攻击。这是第一次发现该组织对沙特阿拉伯进行网络攻击。在这次网络攻击中，“蔓灵花”APT组织使用了ArtraDownloader恶意下载器的三个变体，具体技术细节将在如下给出。

**攻击活动**

从获取的恶意文档情况来看，所有样本都与合法且被“蔓灵花”组织入侵成功的巴基斯坦政府相关网站通信，并下载恶意载荷。

2018年9月12日初，如下文件托管在URL：https://wforc\[.\]pk/js/服务器上。

*   Internet Data Traffic Report – August 2018.docx
    
*   PAF Webmail Security Report.doc.exe
    

钓鱼攻击的目标是沙特阿拉伯某组织的员工。恶意文件通信的C2服务器网址为nethosttalk\[.\]com。

大约在同一时间，两个托管在巴基斯坦其他站点的恶意文档被发现。这些文档托管在khurram.com\[.\]pk/js/drvn并与C2服务器nethosttalk\[.\]com通信。文件名称如下：

*   Handling of Logistics.pdf\[.\]com
    
*   Cyber security work shop.pdf\[.\]com
    

从2018年11月6日起，http://rmmun.org\[.\]pk/svch路径下托管ArtraDownloader下载器文件，该文件与域名info.viewworld71\[.\]com或者hewle.kielsoservice\[.\]net通信。

       2018年11月至2019年1月，在一家液压工程公司的网站上发现使用AtraDownloader下载器的文档，网址为almasoodgroup\[.\]com。其中一个名称为Port Details.doc的RTF文档利用CVE-2017-11882漏洞。这个文档还是从hewle.kielsoservice\[.\]net网站下载恶意载荷，另外两个恶意文件从xiovo426\[.\]net网站下载恶意载荷。

       2019年1月2日，文档article\_amy.doc被上传到VirusTotal平台。这个文档托管在almasoodgroup\[.\]com/js/cwqj域名下，并与C2服务器thepandaservices.nsiagenthoster\[.\]net通信。很明显，合法域名almasoodgroup\[.\]com被入侵。

2018年12月17日和18日，一个文件从域名http://fst.gov\[.\]pk/images/winsvc下载。不清楚用户是如何打开的文件，但是这个文件是利用CVE-2017-11882 (EQNEDT)漏洞执行的恶意文件，该文件链接C2服务器hewle.kielsoservice\[.\]net/Engset.php。

  

**变体比较**

   在所有ArtraDownloader恶意软件家族的约80个样本中，2个不同的变体被标识。这些变体之间有微小差异，主要集中在字符串混淆技术和HTTP请求两个方面。最早的ArtraDownloader样本编译时间是2015年2月，由此可知这个恶意软件家族是一个古老家族。3个不同变体编译时间如下图所示：

![](../Images/6388c7f8f73386ff1dafc27fc1c3e78b.png)

总体而言，ArtraDownloader 恶意软件家族技术原理并不复杂，它利用简单的注册表项进行持久性维持和通过 HTTP 请求来下载和执行远程文件。深度技术分析详见附录。

**结论**

迄今为止，“蔓灵花”APT组织继续活跃在全球各个区域。使用ArtraDownloader的自定义下载恶意软件。目前主要目标为巴基斯坦、中国和沙特阿拉伯。此下载程序通过 HTTP 执行 BitterRAT恶意软件。
