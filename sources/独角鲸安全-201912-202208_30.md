# ** 一、事件ID 4688审计**

![](../Images/7a930a4769b309d73e2b424ddc3c7314.png)

  

## 

       Event ID 4688记录进程创建事件。从Event ID 4688提供的信息中我们能够知道创建了什么进程，进程创建时传递了什么参数和父进程信息等。

  

       Event ID 4688系统默认没有开启，需要进行设置。设置一共分为两个步骤。以下是配置方法。

  

## **二、事件ID 4688配置（配置两个组策略）**

#### 1、进程创建组策略配置

**策略路径:** Computer Configuration >Policies > Windows Settings > Security Settings > Advanced AuditConfiguration > Detailed Tracking

**策略名称:** Audit Process Creation

**支持系统:** Windows 7及以上

**描述/****帮助:**

  这个安全策略决定当操作系统中进程创建和执行时，是否生成审计事件，记录进程名称。这些事件能够帮助你跟踪系统中用户的活动。

事件级别: 因系统而已，从低到中

**默认:** 不配置

  

#### 2、额外信息配置

  为了能在4688审计日志中能够包含命令行信息，需要进行额外的配置。

| 策略配置 || 详细 |
| --- | --- |
| 路径 || Administrative  Templates\\System\\Audit Process Creation |
| --- | --- |
| 配置 || Include  command line in process creation events |
| 默认配置 || 未配置(not enabled) |
| 支持系统 || ? |
| 描述 || 这个策略的设置决定当进程被启动时安全日志是否进行日志记录，，仅当审计进程创建策略应用时才可以应用，并且会在日志记录中详细的记录命令行信息。如果未设置此策略，事件ID 4688中不会记录命令行信息。注意:当此策略有效时，任一用户读取安全日志时都能够看到命令行的参数，这可能会泄露敏感信息 |
