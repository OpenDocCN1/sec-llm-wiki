       作为数字取证和事件响应从业者，我们需要离线导入注册表HIVE文件。我们需要从本地系统的所有用户帐户访问NTUSER.DAT文件，访问注册表HIVE文件，特别是访问挂载镜像中的HIVE文件。

       我还没有使用商业命令行工具cafae（作者TZ）处理离线注册表HIVE文件的时候，我使用Powershell模块（作者Chris Redit）ImportRegistryHive.psm1。        

  

1.  下载ImportRegistryHive.psm1模块
    
    链接地址：https://blog.redit.name/posts/2015/powershell-loading-registry-hive-from-file.html
    
2.  解压
    
3.  复制ImportRegistryHive文件夹到C:\\Program Files\\WindowsPowerShell\\Modules文件夹下
    
4.  显示新模块详细信息
    
    *   
    *   
    
    ```
    Get-Help Import-RegistryHive -DetailedGet-Help Remove-RegistryHive -Detailed
    ```
    
5.  使用Arsenal Image Mounter(AIM)挂在镜像

```
# Load SYSTEM hive into HKLM\TEMP_SYSTEM, this can be accessed using PSDrive SystemHiveImport-RegistryHive -File "G:\Windows\System32\config\SYSTEM" -Key "HKLM\TEMP_SYSTEM" -Name SystemHive # Get COMPUTERNAME value from PSDrive SystemHive$CurrentControlSet = Get-ItemPropertyValue "SystemHive:\Select" -Name Current$ComputerName = Get-ItemPropertyValue "SystemHive:\ControlSet00$CurrentControlSet\Control\ComputerName\ComputerName" -Name ComputerName$ComputerName # Remove SystemHive and unload the Registry hive HKLM\TEMP_SYSTEMRemove-RegistryHive -Name SystemHive
```
