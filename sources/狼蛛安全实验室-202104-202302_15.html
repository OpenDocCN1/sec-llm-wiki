Patchwork 组织针对巴基斯坦最新攻击活动分析

组织：疑似 Patchwork（又名白象/摩诃草/APT-Q-36，印度）

攻击目标： 巴基斯坦

攻击手法： 【鱼叉式钓鱼攻击、漏洞利用】

Patchwork 组织善于抓住热点事件及政府工作会议作为诱饵，并采用鱼叉式网络攻击手段投递攻击载荷。本次捕获的样本以“2022年总理赈灾基金”和“跨部门研讨会 - AML/CFT报名表格”为诱饵，释放带有CVE-2017-11882漏洞的恶意RTF文档。打开该恶意文档都会释放mcods.exe和McVsoCfg.dll两个PE文件，最后执行mcods.exe以加载McVsoCfg.dll（加载的McVsoCfg.dll是BADNEWS变种木马），从而执行恶意功能。此外，本次攻击活动主要以巴基斯坦为攻击目标，载荷加入了巴基斯坦时区校验以及更可靠的加密方式，并且ShellCode加入反调试手段。

与以往的攻击相比，该组织的技术有以下变化：

1、本次首次加入了时区校验，使得攻击行动更具针对性。

2、与以往相比，本次样本在URL字段的命名上没有使用易于理解的字符串，而是使用了模糊不明确的命名方式。

3、获取的信息较之前样本略有更新，且本次主要通过Windows命令行进行信息获取，之前部分信息是根据注册表获取信息。

4、攻击者在本次攻击中使用了AES-CBC-256算法对数据进行加密，前期攻击中也使用过AES-CBC-128、RC4等不同算法，可以看到该组织在数据加密算法上一直在下功夫。

【科技安全】台积电在美设立 5nm 晶圆厂，并有可能扩大投资在美设立 3nm 晶圆厂

11月21日，台积电创办人张忠谋在台湾出席记者会时正式证实，台积电在亚利桑那州的5纳米晶圆厂将于12月6日举办首批机台设备进驻典礼，意味着厂房已经部分完工。报道称，张忠谋也首次证实台积电在继5纳米晶圆厂后，还会扩大投资在美设立3纳米晶圆厂。补壹刀认为，此举有可能是“美国正在一步步将台积电收入囊中”，“美国只是将台湾当作遏制中国的“棋子”。美方一直考虑的是都是如何最大程度避免自己的损失，同时把利益最大化，甚至‘趁火打劫’。”专家认为，美国将芯片领域进一步泛安全化，类似台积电这样的企业当前的处境，不可避免会使中国大陆芯片产业承压。

Killnet 声称攻击了 Starlink、Whitehouse.gov 和英国网站

亲俄威胁组织 Killnet 声称对 Starlink 和美国政府网站 whitehouse.gov 发起了 DDoS 攻击。Starlink 是 SpaceX 运营的卫星互联网服务公司，whitehouse.gov 网站是美国白宫的官方网站。在他们的 Telegram 频道上，Killnet 声称对美国政府网站whitehouse.gov发起了“测试”DDoS 攻击，并且Killnet 表示据称针对 Starlink 的 DDoS 攻击发生在 11 月 18 日。而据新闻报道，11 月 18 日，对 Starlink 账户的访问中断了几个小时。为了回应英国对乌克兰的支持，Killnet 声称已于 11 月 22 日对威尔士亲王的网站发起 DDoS 攻击。

01

谷歌发布 YARA 规则以帮助检测并阻止 Cobalt Strike 的恶意使用

谷歌云威胁情报研究人员在野外发现了 34 个破解版本的 Cobalt Strike。这些版本包含 257 个独特的 JAR 文件和 Beacon 组件，它们在执行时可以记录击键、执行代码、提升权限和进行端口扫描，以及其他恶意活动。研究人员还注意到，每个未经授权的 Cobalt Strike 工具包版本都有攻击模板二进制文件，数量在 10 到 100 之间。随后研究人员发布一组开源 YARA 规则以帮助社区标记和识别 Cobalt Strike 的组件及其各自的版本。

原文链接：

https://cloud.google.com/blog/products/identity-security/making-cobalt-strike-harder-for-threat-actors-to-abuse

发布平台： Google Cloud

02

Luna Moth 回调网络钓鱼勒索活动针对多个行业的企业

Luna Moth（又名 Silent Ransom Group）发起的回调网络钓鱼勒索活动针对多个行业的企业，包括法律和零售业。研究人员表示，这种社会工程学攻击留下的数字伪影很少，因为它依赖于合法的技术工具来进行攻击。并且，这种攻击方式比基于脚本的攻击更耗费资源，但更简单，而且它的成功率往往更高。Unit 42 称，与Conti 组织相关的威胁参与者在BazarCall活动中广泛使用了这种攻击方式 。

03

总部位于越南的 Ducktail 网络犯罪活动不断发展、扩大

据研究人员介绍，Ducktail 信息窃取程序已更新为具有新功能，使用它的威胁参与者一直在扩展其操作。威胁行为者以可能有权访问带有信息窃取恶意软件的 Facebook 商业帐户的个人和员工为目标。该恶意软件旨在窃取浏览器 cookie 并利用经过身份验证的 Facebook 会话从受害者的 Facebook 帐户中窃取信息，并最终劫持受害者具有足够访问权限的任何 Facebook Business 帐户。根据分析和收集的数据，研究人员将攻击归因于越南威胁者，并且证据链表明威胁行为者的动机是经济驱动的。

04

攻击者使用网络钓鱼工具包针对北美消费者进行攻击

研究人员发现，自9月中旬以来，攻击者利用一个复杂的网络钓鱼工具包，以北美消费者为目标，利用劳动节、万圣节等节日假期，针对消费者群体进行钓鱼攻击。

研究人员称该工具包中使用了多种规避检测的技术，并结合了多种机制，其中最为独特的功能是能够基于令牌系统，确保每个受害者被重定向到一个唯一的钓鱼页面。钓鱼邮件会假冒多种知名品牌，将受害者重定向至钓鱼页面中，提示受害者在5分钟以内完成调查问卷才能获得名牌奖品，并构造虚假用户评价以增加钓鱼攻击的成功率。

原文链接：

https://www.akamai.com/blog/security-research/sophisticated-phishing-scam-abusing-holiday-sentiment

1500个 APP 暴露 Algolia API 密钥，影响超300万用户

Algolia 是一个面向开发者的搜索功能 API 接口，为网站及APP 的开发者提供搜索功能接口。研究人员发现有1550个移动 APP 会泄露 Algolia API 密钥，威胁行为者可以利用硬编码的 Algolia API 密钥窃取数百万用户的数据，敏感内部服务和存储的用户信息有泄露的风险。暴露密钥最多的 APP 种类为商城 APP，下载次数超过230万次。此外，还有新闻 APP、食品和饮料、教育、健身、医疗和商业 APP，累计下载量超过95万次。
