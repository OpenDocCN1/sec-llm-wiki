**01**

APT 37 使用 Konni RAT 进行攻击

**组织：** 疑似 APT37（又名Hermit/Ricochet Chollima，朝鲜）

**攻击目标：** 俄罗斯政府

**攻击手法：** 【钓鱼攻击】

攻击者伪装成俄罗斯驻中国沈阳总领事馆的地址进行攻击。消息的主题是“Re: Посольство России в Японии”，翻译过来就是“Re: 俄罗斯驻日本大使馆”。这种在电子邮件中包含“Re:”即“回复”的用法通常用于使收件人看起来更可信。电子邮件的正文要求收件人检查附加的详细信息，以执行在发送者和接收者之间转移资金的请求。电子邮件附件是一个 Zip 档案“Donbass.zip”，这是乌克兰地区顿巴斯的英文拼写。Zip 档案中包含两个 Microsoft PowerPoint 文件，“\_Pyongyang in talks with Moscow on access to Donbass.pptx”（译为“\_Pyongyang 与莫斯科就访问顿巴斯进行谈判.pptx”）和“Donbass.ppam”（译为“顿巴斯.ppam”）。其中 PPTX 文件实际上是一个诱饵文件，文件中不存在任何宏或任何可能被视为恶意的内容；而 PPAM 是 Microsoft PowerPoint 使用的加载项文件格式，通常需要应用程序才能打开。通常这种情况，将执行恶意宏。

![](../Images/58fec4178863a88081eaf6c3574b336c.png)

宏最初向用户显示一个消息框（如图所示），然后使用命令提示符将一大块 base 64 编码文本存入名为“oup.dat”的文件中，然后将其存储在用户的“temp”中目录。使用微软“Certutil”工具，将“oup.dat”解码为“oup .vbs”，并存放在 Microsoft Office 目录中。“oup.vbs”有两个用途。首先是创建一个名为“Office Updatev2.2”的计划任务，此任务的是每 5 分钟连续运行一次“oup.vbs”；其次是执行基本 64 位编码的 PowerShell 命令。PowerShell 命令尝试提供一些环境信息（例如，机器名称）并连接到位于 gg1593\[.\]c1\[.\]biz 的 URL。此域指向 IP 地址 185\[.\]176\[.\]43\[.\]106。

**归因分析：** 由于确保持久性和连接到 C2 的活动与之前部署 Konni 的尝试相匹配，因此研究人员将此次攻击归因于 APT37 组织。

**02**

Gamaredon APT 在新活动中针对乌克兰政府机构  

**组织：** 疑似Gamaredon（又名Armageddon/ GammaLoad/UAC-0010/APT-C-53/，俄罗斯FSB）    

**攻击目标：** 乌克兰政府机构

**攻击手法：** 【钓鱼攻击】

攻击者使用网络钓鱼电子邮件传递包含带有恶意 VBScript 宏的远程模板的 Microsoft Office 文档。这些宏下载并打开包含 LNK 文件的 RAR 档案，随后在受感染的端点上下载并激活下一阶段的 PowerShell 脚本。通过执行 PowerShell 脚本，信息窃取恶意软件被部署在目标主机上。该恶意软件是一种双重用途的恶意软件，能够从受感染的机器中提取数据并传播额外的任意有效载荷。信息窃取器还可以从任何附加的可移动存储中提取文件——它搜索具有预定义扩展名的文件。

![](../Images/5b60ed73e550fbbb2343e28ec197b3bd.png)

**归因分析：** 

1、攻击者正在使用包含与俄罗斯入侵乌克兰有关的诱饵的网络钓鱼文件；

2、该活动中使用的策略、技术和程序 (TTP)、恶意软件工件和基础设施与 CERT-UA 最近归咎于 Gamaredon 的一系列攻击中使用的有相当大的重叠，如第一阶段的 PowerShell 脚本使用的 Gamaredon 的域 xsph\[.\]ru；第二阶段使用的 PowerShell 代码“旨在为攻击者提供对受感染端点的持续访问，并能够根据需要部署额外的有效负载”，在 CERT-UA 关于 2022 年上半年使用 GammaLoad 和 GammaSteel 的相关报告中也有披露等。

综上所述，研究人员将此次攻击归因于 Gamaredon 组织。

**03**

Sandworm 冒充乌克兰电信公司投放恶意软件

**组织：** 疑似 Sandworm（又名 Telebots/ Voodoo Bear/Unit 74455，俄罗斯GRU）    

**攻击目标：** 乌克兰

**原文概述：** 【钓鱼攻击】

2022 年 8 月开始，Recorded Future 的研究人员已观察到攻击者使用伪装成乌克兰电信公司的动态 DNS 域，试图将恶意软件传播到乌克兰组织的网络上。所采用的攻击使用与军事行动、管理通知、报告等相关的各种诱饵文档。威胁组织正在利用恶意 ISO 文件，这些文件提供部署 Colibri Loader 和 Warzone RAT（又名 AveMaria）有效负载的可执行文件。

攻击首先引诱受害者访问这些域，通常是通过从这些域发送的电子邮件，使发件人看起来像是乌克兰的电信提供商。这些网站使用的语言是乌克兰语，呈现的主题涉及军事行动、行政通知、报告等。网页的 HTML 包含一个 base64 编码的 ISO 文件，当使用 HTML 走私技术访问网站时会自动下载该文件。图像文件中包含的有效载荷是 Warzone RAT，Sandworm 使用它来替换他们在前几个月部署的 DarkCrystal RAT。Warzone RAT 提供强大的功能，如 UAC 绕过、隐藏的远程桌面、cookie 和密码窃取、实时键盘记录、文件操作、反向代理、远程外壳 (CMD) 和进程管理等等。

**归因分析：** 1、虽然 Sandworm 已显着更新了其 C2 基础设施，但它是逐步更新的，因此 CERT-UA 报告中的历史数据使研究人员能够将当前的基础设施与威胁行为者联系起来；

2、许多域解析为新的 IP 地址，但在某些情况下，与可追溯到 2022 年 5 月的过去 Sandworm 活动有重叠；

3、近期，多个俄罗斯背景的组织多使用 HTML smuggling（译为”HTML 走私“）的手法对乌克兰进行攻击；

综上所述，将此次攻击归因于 Sandworm 组织。

**04**

DarkCasino 行动：深入分析 APT Group Evilnum 的攻击（第 2 部分）

**组织：** 疑似 Evilnum（又名DeathStalker，白俄罗斯）    

**攻击目标：** 欧洲以及亚洲某些国家

**攻击手法：** 绿盟科技的研究人员对 Evilnum 进行了分析，其中提到 Evilnum 的新的定制木马 DarkMe 以及 PikoloRAT。并且分析了在不同的攻击流中是如何运用到两个木马的，并对该组织最新的攻击技术和战术进行了分析。

Operation DarkCasino 是一系列针对在线交易现金流的持续 APT 攻击。Evilnum 集团采用了各种不断改进的攻击技术和工具，显示出其敏锐的对抗意识。为有效防止此类操作，研究人员认为在线金融平台用户应特别注意通过各种渠道传输的 LNK、PIF、SCR、COM 类型的文件，对带有 offer、visa、casino 等关键字的文件更加警惕，避免 Evilnum 攻击，可能造成直接经济损失。

**归因分析：** 

1、在攻击流 A 中，攻击者依然采用了 kernel32 和 ntdll 这两个模块来构建主要的攻击流程，这是之前披露过的 Evilnum 组织的常用攻击手法；

2、基于程序中的特定字符串，研究人员将  PikoloRAT 归因于该组织。

**01**

StrivePhish钓鱼组织大爆发，针对**国内**企业、高校和事业单位

近日，研究人与近期出现大批量针对**国内企业、高校和事业单位**等进行大规模专业的邮件钓鱼事件，经过分析，该事件为典型的国内邮箱窃密的黑灰产组织，微步情报局将之命名为StrivePhish组织，具体分析如下:

1.  该组织使用特定的钓鱼链接进行针对性攻击，钓鱼域名为组合域名，即使用接收邮件人员所在公司的官网加上该组织域名资产，目的是增加钓鱼链接可信度，提高钓鱼成功率；  
    
2.  该组织已将查询目标账户，申请域名，绑定钓鱼服务和发送邮件等一系列攻击链路形成模板化和自动化流程，该组织的钓鱼目标最高增长量在600条以上；
    
3.  关联发现，该组织最早于2022年5月13号开始活跃，且通过其后台数据推断，至少已获取1500多条对应的账户密码，危害十分巨大。
