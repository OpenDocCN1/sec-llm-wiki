美国 NSA 网络武器“饮茶”分析报告

组织： 疑似 APT-C-40（又名方程式/Equation Group/Tilded Team，美国）

攻击目标： 中国

原文概述： 国家计算机病毒应急处理中心在对西北工业大学遭境外网络攻击事件进行调查过程中，在西北工业大学的网络服务器设备上发现了美国国家安全局（NSA）专用的网络武器“饮茶”（NSA命名为“suctionchar”）。国家计算机病毒应急处理中心联合北京奇安盘古实验室对该网络武器进行了技术分析，分析结果表明，该网络武器为“嗅探窃密类武器”，主要针对 Unix/Linux平台，其主要功能是对目标主机上的远程访问账号密码进行窃取。

具体执行过程：

  1. 运行于内核层的 sum 会辅助“饮茶”嗅探木马（Suctionchar_Agent）窃取 passwd、telnet、su 等进程中的账号密码；

  2. 窃取到的账号密码会同步发送给运行于Ring3的“饮茶”嗅探木马（Suctionchar_Agent）;

  3. “饮茶”嗅探木马（Suctionchar_Agent）会将账号密码保存到名为“/var/tmp/.xxxxxxxx”的隐藏目录中；

  4. 美国国家安全局（NSA）的攻击实施者远程发送执行 ish 反弹的触发包到内核层的 BPF 过滤程序；

  5. BPF过滤器捕获到特征包后传送给 Ring3 的 Dewdrop 程序模块；

  6. Dewdrop 进行数据包解密并收到 ish 反弹指令，随即转送给 Incision 程序；

  7. Incision 程序主动回联到 callback 地址，美国国家安全局（NSA）的攻击实施者利用 ish 接受窃取的密码文件；

  8. 美国国家安全局（NSA）的攻击实施者将被 RSA 公钥加密的密码文件进行私钥解密并还原密码文件；

攻击场景

Kimsuky 使用多种攻击武器针对韩国进行定向攻击

组织： 疑似 Kimsuky（又名SharpTongue/ Thallium/SectorA05/APT-C-55，朝鲜）

攻击目标：

攻击手法： 【鱼叉式钓鱼攻击】

近期，在美韩联合演习这一背景下，研究人员监测到大量来自 Kimsuky 组织的攻击，从攻击样本来看，使用 pif、hwp、doc 等文件做为诱饵进行初始攻击，后续载荷包括其常使用的 AppleSeed、PebbleDash 等木马。

此次的攻击活动有如下特点：

1. 使用 PIF 可执行文件格式伪装成 PDF 文件，后续载荷为 PebbleDash 木马；

2. 部分样本诱饵被韩国 DRM 软件加密，疑似由 Kimsuky 组织在其他攻击活动中所窃取，用于实施定向攻击；

3. 样本擅用加解密算法来躲避相关杀软的静态查杀。

攻击链

归因分析： 

1、宏文档样本与 ASEC 在今年5月披露的 Kimsuky 样本攻击流程一致；

2、解密函数以及使用的 Key 与研究人员之前在《Kimsuky 武器库更新：利用新冠疫情为诱饵针对韩国地区的攻击活动分析》一文中披露的相同，使用类似 base64 的映射表来进行解密；

3、执行的Thumbs.db.pif载荷实际为 PebbleDash 木马，该木马是 NukeSped 变种木马之一，去年被发现与 Kimsuky 常用的 AppleSeed 木马一起用于攻击；

4、双扩展名 VBS 样本通过 regsvr32 加载后门DLL 的方式也是 Kimsuky 在启动 AppleSeed 时常用的一种手段；

综上所述，研究人员将攻击归因于 Kimsuky 组织。

伪猎者 APT 组织对瞄准基金会代表和平昌和平论坛政界人士进行定向攻击

组织： 疑似 APT-C-60（又名伪猎者，东亚）

攻击目标： 韩国基金会代表和平昌和平论坛政界人士

攻击手法： 【鱼叉式钓鱼攻击】

攻击事件时间节点包括两个：2022年2月上旬针对2022平昌和平论坛相关人士的攻击；2022年6月中旬对 Bernhard Seliger 博士的定向攻击。均为鱼叉邮件类型的攻击。攻击者用于攻击载荷托管、C&C 通信的网络资产包括公开免费的云端存储站点（如 bitbucket.org、statcounter.com）和攻击者私有 C&C 资产。木马回连地址会涉及这两类的多个 url 地址。

2022年6月20日，攻击者伪装成韩国在校研究生论文答辩事宜，诱导目标人员下载托管在 cloud.mail[.]ru 上的恶意文件。下载文件为 rar 压缩文件，包含诱饵文档和恶意 Lnk 文件。落地载荷可分为三部分：具备恶意下载的 Lnk 文件，具备文件信息收集以及下载执行的下载器木马（mssysmon.db），具备文件窃密、插件加载、 shell 功能的远控木马（TaskControler.dll）。

归因分析： 

1、本次样本与之前发现伪猎者攻击事件中落地载荷执行流程基本一致，第三阶段组件 TaskControler.dll 与历史事件具有相同导出函数、代码行为和通信过程基本一致；

2、在对伪猎者进行历史攻击时间分析时，发现其中DLL载荷导出函数“extension”、“%AppData%\Roaming\Microsoft\”下的伪造payload组件目录以及payload遍历加载逻辑几乎完全一致；

综上所述，研究人员认为将该攻击样本归因到伪猎者较为可信。

Charming Kitten 瞄准核安全和基因组研究中的高价值目标

组织： 疑似 Charming Kitten（又名APT35/ Phosphorous/TunnelVision/TA453，伊朗）

攻击目标： 专门从事中东事务、核安全和基因组研究的个人

攻击手法： 【钓鱼攻击】

攻击者假冒西方外交政策研究组织的合法个人，向受害者发送网络钓鱼电子邮件，该电子邮件最终旨在代表伊朗伊斯兰革命卫队 (IRGC) 收集情报，并且攻击者假冒的的用户包括来自皮尤研究中心、外交政策研究所 (FRPI)、英国查塔姆研究所和科学杂志《自然》的人。并且该组织的 MPI 技术有了变化。在典型的攻击活动中，该组织都会与他们的目标进行一对一的对话，但最近该组织使用了一种称为 Multi-Persona Impersonation (MPI)  的策略，即攻击者在单个电子邮件线程上使用至少两个参与者控制的角色来说服目标该活动的合法性。

在最近的攻击中，该组织控制的“Carroll Doherty”角色联系了一位参与核军备控制的著名学者，讨论可能的美俄冲突。“Carroll”还在电子邮件中抄送了另外三个 Charming Kitten 角色：“Daniel Krcmaric”、“Aaron Stein”和“Sharan Grewal”。这场运动最终代表了该组织的 MPI 技术的演变，因为角色并没有停止只接触一个目标，而是接触同一所大学的两个目标。当其中一个目标回复后，“Carroll”向目标发送带恶意 OneDrive 链接的电子邮件。当目标点击邮件中的恶意链接时，该链接会下载名为“The possible US-Russia clash.docx”（译为”可能的美俄冲突.docx“）的文件。并且,“Carroll”向目标用户单独发送密码，让目标知道文件是安全的，因为没有密码就无法阅读。四天后，抄送的 TA453 角色之一“Aaron Stein”从电子邮件线程中删除了“Carroll”并向目标道歉，且重新发送了相同的 OneDrive 链接和密码。与“Harald”发来的文档类似，该文档也使用了远程模板注入来下载 Korg。Korg 是 Charming Kitten 最新的远程注入模板，具有三个宏：Module1.bas、Module2.bas 和 ThisDocument.cls。宏从 my-ip.io 收集用户名、正在运行的进程列表以及用户的公共 IP 等信息，然后使用 Telegram API 泄露这些信息。 

Charming Kitten 电子邮件活动时间表

归因分析： 研究人员继续评估 Charming Kitten 支持伊斯兰革命卫队 (IRGC)。该评估基于各种证据，包括普华永道确定的组织报告和 IRGC 单位之间的单位编号重叠、美国司法部对 Monica Witt 和 IRGC 附属演员的起诉，以及与报告的 Charming Kitten 目标相比的分析 IRGC-IO 优先事项。研究人员主要通过受害者学、技术和基础设施进行区分该组织的多个子组。在该组织的典型活动中，一些小组会在传递恶意链接之前与目标进行数周的良性对话。相反，另一个子组倾向于立即在初始电子邮件中发送恶意链接。 

研究人员认为虽然仅存在特定指标并不能明确将电子邮件归因于该组织所有，但可能与该组织相关的角色的指标包括：

  1. 使用 Gmail、Outlook、Hotmail 或 AOL 电子邮件地址而不是机构电子邮件；  

  2. 在对话中包括其他“个人电子邮件账户”；

  3. 回复空白电子邮件； 

  4. 要求合作研究与中东有关的问题；

  5. 提供 Zoom 呼叫（通常会导致凭证收集链接）；

  6. 发送未经请求的协作“草稿”附件。

Charming Kitten 网络间谍活动示例

组织： 疑似 Charming Kitten（又名APT35/ Phosphorous/TunnelVision/TA453，伊朗）

攻击目标： 美国、欧洲和中东国家的个人、学者、记者、活动家、智囊团、研究所、组织、军事和政府部门

原文概述： Charming Kitten 持续开展网络间谍活动，对伊朗和外国公民进行广泛监视，对伊斯兰革命卫队(IRGC)具有战略情报价值。虽然近年来的大量技术报告显示，他们针对不同的部门和目标使用了多种漏洞、半先进和独特的工具，但他们在网络间谍活动中主要使用“鱼叉式网络钓鱼”方法。该组织在他们复杂的攻击中结合使用虚构的角色、模仿和滥用知名人士被黑的在线账户提高攻击命中成功率。此外，作为社会工程计划的一部分，他们在初始阶段与潜在目标建立信任，有时他们会尝试与受害者进行长达数天的谈话，然后在预定时间诱骗他们点击恶意链接。“采访”、“会面”、“讨论”、“合作”是他们钓鱼场景中最常见的话题。根据 Certfa Lab 的调查，自 2021 年底以来，Charming Kitten 一直在运行多个网络钓鱼活动，其中一些活动仍在进行中并且仍然活跃。本文主要揭示了其中的一些攻击示例。在这些示例中，Charming Kitten 通过发送视频/音频通话邀请的网络钓鱼操作以获取凭据。

  1. 阿尔法行动：该组织冒充法国国家科学研究中心的研究员 Samuel Valable，创建了一个虚假的 LinkedIn 账户，然后针对其他国家的研究人员和学术界收集情报并破解他们的账户。LinkedIn Messaging 上这次对话的新颖而重要的部分是 Charming Kitten 发送的所有链接都是合法和真实的，他们没有向目标发送任何网络钓鱼链接或恶意文件。在与目标的对话结束时，黑客从 Zoom 向目标发送了一个视频通话链接，并要求该人与他们进行视频通话。在通话中引起目标兴趣之后，通过分享的虚假链接进行信息收集。

  2. 布拉沃行动：该组织冒充中东研究所的主席 Paul Salem，并联系了在中东从事不同主题工作的伊朗和非伊朗活动家，其目标是知名专家的领域进行合作和合作。

  3. 查理行动：该组织冒充大西洋理事会地缘经济中心的非常驻高级研究员之一 Hagar Hajjar Chemali，此人也是美国政治评论员，这次冒充行动的目标群体是政治、媒体、人权捍卫者和中东专家的女权活动家，以收集具体信息，例如居住在伊朗、伊拉克和欧洲国家的正在寻求并有资格获得经济支持的伊朗女权活动人士的姓名。值得一提的是，这类数据对伊朗政权意义重大，在某些情况下可能导致以与外国合作的罪名逮捕和拘留活动人士。

  4. 三角洲行动：该组织冒充华盛顿阿拉伯海湾国家研究所 (AGSIW) 的高级常驻学者 Hussein Ibish。

与 Charming Kitten 子组 Nemesis Kitten 有关的勒索活动策略和技术

组织： 疑似 Nemesis Kitten (又名DEV-0270， Charming Kitten子组，伊朗)

原文概述： 微软的研究人员在发布的博客中详细介绍了 Nemesis Kitten 在其端到端攻击链中的策略和技术。研究人员评估 DEV-0270 是由一家以两个公共别名运作的公司运营的：Secnerd (secnerd[.]ir) 和 Lifeweb (lifeweb[.]ir)。这些组织还与位于伊朗卡拉季的 Najee Technology Hooshmand (ناجی تکنولوژی هوشمند)  有关联。攻击者扫描互联网以查找易受攻击的服务器和设备，使具有易受攻击和可发现的服务器和设备的组织容易受到这些攻击。Nemesis Kitten 以利用高严重性漏洞、特别是最新披露的漏洞来访问设备而闻名。威胁参与者通常通过将其 Web shell 注入易受攻击的 Web 服务器上的特权进程来获得具有管理员或系统级权限的初始访问权限。然后它使用Impacket的 WMIExec 横向移动到网络上的其他系统，并添加或创建新的用户账户以保持持久性。研究人员还发现该组织使用了几种防御性规避技术来避免检测，包括关闭 Microsoft Defender 防病毒软件。该组织还在整个攻击链中广泛使用远程二进制文件 (LOLBIN) 来进行发现和凭据访问，这延伸到它滥用内置的 BitLocker 工具来加密受感染设备上的文件。

微软调查伊朗对阿尔巴尼亚政府的袭击

组织： 疑似伊朗组织

攻击目标： 阿尔巴尼亚政府

原文概述： 微软的研究人员高度自信地评估称，2022 年 7 月 15 日，由伊朗政府赞助的行为者对阿尔巴尼亚政府进行了破坏性网络攻击，扰乱了政府网站和公共服务。与此同时，除了破坏性的网络攻击之外，MSTIC 还评估说，一个独立的伊朗国家支持的演员泄露了几个月前被泄露的敏感信息。各种网站和社交媒体被用来泄露这些信息。这篇博客对此次事件相关的组织、攻击策略等进行了分析。

其中，微软研究人员高度自信地评估了多个伊朗参与者参与了这次攻击——不同的参与者负责不同的阶段：

  • DEV-0842 部署了勒索软件和擦除恶意软件

  • DEV-0861 获得了初始访问权限并窃取了数据

  • DEV-0166 泄露数据

  • DEV-0133 探测受害者基础设施

攻击阿尔巴尼亚政府背后的威胁者

归因分析： 

  1. 观察到袭击者在伊朗境外活动

  2. 负责入侵和泄露数据的攻击者使用了其他已知伊朗攻击者以前使用的工具

  3. 负责入侵和泄露数据的攻击者针对符合伊朗利益的其他部门和国家

  4. 雨刮器木马代码以前曾被一位知名的伊朗攻击者使用

  5. 勒索软件的签名与伊朗攻击者使用的其他工具的数字证书签名相同

【海外利益安全】德国经济部和外交部欲否决中远海运收购德国第一大港汉堡港 Tollerort 集装箱码头35%股份

当地时间9月13日，德国经济部长哈贝克（绿党）接受路透社采访时放言，他不支持中远海运收购 Tollerort 集装箱码头35%股份。他还声称，德国政府正研拟新的对华贸易政策，要降低对中国原材料、电池、半导体的依赖，且在与华贸易往来上“不再天真”。据路透社14日报道，德国政府内部就此问题存在分歧，同时这一消息令德国企业界感到沮丧。Tollerort 集装箱码头地理位置优越，提供便捷的海上通道，其中包括可容纳大型集装箱船只挂靠，完善的公路、海运、铁路、水路网络与腹地联系紧密。预期交易事项将为中远海运公司创造新的增长点，并继续为全球各航运公司提供优质的供应链服务。

9月13日，我外交部发言人毛宁回应称，德国是贸易大国……有责任有义务维护全球产供链的稳定。希望德方能恪守开放市场公平竞争的原则，客观理性地看待中国投资，为中国企业提供公平、开放、非歧视的市场环境，不要将正常的经贸合作政治化，更不要以国家安全为由搞保护主义。

日本政府将针对重要基础设施建立“积极网络防御”体系

日本《读卖新闻》13日报道，多名日本政府相关人士透露，日本政府计划建立所谓“积极网络防御”体系，并将该方针写入将于今年修订的《国家安全保障战略》中，其内容将授予日本政府在非战争状态下实施网络入侵、解析可疑通信内容等权限。报道称，“积极网络防御”体系将常态化网上巡逻，提前发现可能成为日本安全保障威胁的可疑情况，并采取反制措施。报道还称，美国与英国已建立了类似体系。

Google 宣布完成收购 Mandiant，提升网络威胁情报能力

Google宣布，其3月份就首次透露的价值54亿美元的收购网络安全公司Mandiant的交易提议现在已经完成。Google云首席执行官 Thomas Kurian 在一篇博文中写道：”我们将保留 Mandiant 品牌，并继续 Mandiant 的使命，即让每个组织免受网络威胁并对他们的准备工作充满信心。”Kurian 说：”将 Google 云现有的安全组合与 Mandiant 领先的网络威胁情报相结合，将使我们能够提供一个安全运营套件，帮助全球企业在安全生命周期的每个阶段保持保护。凭借 Google 的数据处理规模、人工智能和机器学习的新颖分析方法以及对消除整类威胁的关注， Google Cloud 和 Mandiant 将帮助企业重塑安全，以满足我们快速变化的世界的要求。”

关于“魔盗”窃密木马大规模传播的风险提示

近期，CNCERT和安天联合监测到一批伪装成CorelDraw、Notepad++、IDA Pro、WinHex等多款实用软件进行传播的窃密木马。通过跟踪监测发现其每日上线境内肉鸡数（以IP数计算）最多已超过1.3万，由于该窃密木马会收集浏览器书签、邮箱账户等信息，故我们将命名为“魔盗”。

攻击者利用“cdr[.]jyxwlkj.cn”及“cdrnb[.]jyxwlkj.cn”域名建立多个软件下载页面，用于投放伪装成实用软件的“魔盗”窃密木马。窃密木马运行后会收集受害者主机中已安装的软件列表与多款浏览器的历史记录、书签数据和邮件客户端邮箱账户信息，并加密回传至攻击者服务器。由于部分恶意程序具备在线升级能力，因此攻击者可随时更改攻击载荷（如勒索、挖矿、窃密等不同目的的攻击载荷），给受害者造成更大损失。

飞机 WiFi 设备发现漏洞，会暴露乘客数据

Necrum 安全实验室的 Thomas Knudsen 和 Samy Younsi 发现在据称用于在飞机上提供互联网连接的无线 LAN 设备中发现了两个严重漏洞，这两个漏洞影响了 Contec 制造的 Flexlan FX3000 和 FX2000 系列无线 LAN设备。根据安全专家的说法，这里的问题是设备所有者只能从 Web 管理界面更改用户账户的密码，因为根账户是为 Contec 保留的（可能用于维护目的）。 “这意味着拥有硬编码密码的攻击者可以访问所有 FXA2000 系列和 FXA3000 系列设备，”Knudsen 和 Younsi 解释说。
