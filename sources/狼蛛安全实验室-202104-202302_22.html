360发布关于西北工业大学发现美国 NSA 网络攻击调查报告（之一）

组织： 疑似 APT-C-40（又名方程式/Equation Group/Tilded Team，美国）

攻击目标： （中国）西北工业大学

原文概述： 2022年6月22日，西北工业大学发布《公开声明》称，该校遭受境外网络攻击。中国国家计算机病毒应急处理中心和360公司第一时间成立技术团队开展调查工作，全程参与此案技术分析，初步判明相关攻击活动源自美国国家安全局（NSA）的“特定入侵行动办公室”（Office of Tailored Access Operation，后文简称TAO）。经技术分析与溯源，技术团队现已澄清TAO攻击活动中使用的网络攻击基础设施、专用武器装备及战术，还原了攻击过程和被窃取的文件，掌握了美国 NSA 及其下属 TAO 对中国信息网络实施网络攻击和数据窃密的相关证据，涉及在美国国内对中国直接发起网络攻击的人员13名（NSA对西北工业大学攻击窃密期间的 TAO 负责人是Robert Edward Joyce），以及 NSA 通过掩护公司为构建网络攻击环境而与美国电信运营商签订的合同60余份，电子文件170余份。

02

APT 组织 Evilnum 发起新一轮针对在线交易的网络攻击

组织： 疑似 Evilnum（又名DeathStalker）

攻击目标： 地中海沿岸的西欧诸国，以线上交易现金流为目标

攻击手法： 【钓鱼攻击】

Evilnum将诱饵伪装成账单、清单、发票等常见的交易类文件，以此攻击负责相关事务的人员。部分关键词显示，Evilnum的攻击目标具备使用加密货币收款的能力。

诱饵文件名称

本轮网络攻击活动发生在7月下旬至8月上旬，两次活动的攻击链有一定的相似性。在攻击中最终释放的 ShellRunDllVb.dll 是 Evilnum 组织近期频繁使用的 DarkMe 木马程序，具有文件操作、CMD 命令执行等功能。

7月攻击链：带有双重扩展名的下载者木马被包装在压缩包中投递给受害者，诱使受害者运行该木马。木马运行后下载位于远程的下一阶段 dropper 木马并运行。bCMLm.exe 将内置的三个文件 UI.exe、库文件 E.ocx、隐写图片文件 bump.bmp 释放至系统 %TEMP% 目录中并运行其中的 UI.exe 文件。UI.exe 加载 E.ocx，进而读取并加载执行 bump.bmp中隐藏的数据库文件 ShellRunDllVb.dll。

8月攻击链：初始阶段载荷被伪装成 pif 快捷方式，通过双重扩展名让受害者误认为该文件是 pdf 文件。该载荷是 dropper 木马程序，将内置的三个文件释放至系统 %TEMP% 目录中并运行其中的 lddAw.exe 文件，后续运行流程与7月下旬流程基本一致。

归因分析： 

1、攻击目标与该组织过往目标一致；

2、诱饵特征与Evilnum组织的既往行动类似。Evilnum 通常使用此类诱饵攻击各种线上服务中的交易系统，期望窃取交易双方账户中的现金。Evilnum 此类攻击的目标行业涵盖线上银行、互联网金融、加密货币平台、线上娱乐等行业。

综上所述，将此次攻击归因于 Evilnum 组织。

Mandiant 揭露了庞大、多年的伊朗网络间谍和监视组织 APT42

组织： 疑似 APT42（伊朗）

攻击目标： 西方智库、研究人员、记者、现任西方政府官员、前伊朗政府官员和海外伊朗侨民

原文概述： Mandiant 发布了一份全面的报告，详细介绍了 APT42，这是一个由伊朗国家资助的网络间谍组织，其任务是对伊朗政府具有战略利益的个人和组织进行信息收集和监视行动。研究人员有把握地估计，APT42 代表伊斯兰革命卫队 (IRGC) 的情报组织 (IRGC-IO) 根据与该组织的行动任务和优先事项相一致的目标模式开展行动。

APT42 使用高度针对性的鱼叉式网络钓鱼和社会工程技术，旨在与受害者建立信任和融洽关系，以便访问他们的个人或公司电子邮件账户或在他们的移动设备上安装 Android 恶意软件。此外，APT42 很少使用 Windows 恶意软件来补充其凭据收集和监视工作。APT42 操作大致分为三类：凭据收集、监视行动、恶意软件部署。

Kimsuky 针对与朝鲜有关的特定个人的恶意文件

05

MagicRAT 是 Lazarus 的最新木马

组织： 疑似 Lazarus（又名 APT-C-26/APT38, 朝鲜）

原文概述： Cisco Talos 发现了一种由 Lazarus APT 组织开发和运营的新远程访问木马 (RAT)“MagicRAT”。Lazarus 在成功利用 VMWare Horizon 平台中的漏洞后部署了 MagicRAT。研究人员还发现了 MagicRAT 和另一个被称为“TigerRAT”的 RAT 之间的联系，最近被韩国互联网与安全局 (KISA) 披露并归因于Lazarus。

归因分析：

1、 MagicRAT 提供服务的 C2 服务器与之前披露的 Lazarus 活动使用 Dtrack RAT 系列存在重叠。此外，Talos 还发现了托管和服务于现有 MagicRAT 感染的 TigerRAT 的 C2 服务器。

2、在一些感染中，研究人员观察到攻击者部署了 MagicRAT 一段时间，随后将其移除，随后下载并执行了另一种名为“VSingle”的定制开发恶意软件，这是 JPCERT 披露并归因于 Lazarus 的另一种恶意软件。

01

【科技安全】美政府要求 NVIDIA、AMD 向中国限制出售 AI 芯片

AMD 的发言人称公司已经收到了新的许可证规定，将停止向中国出口 MI250 人工智能芯片。芯片设计公司 NVIDIA 也在提交给 SEC 的一份文件中说，美国官员要求其停止向中国（包括中国香港）出口用于人工智能工作的两种顶级计算芯片 A100 以及 H100；次日，为了不影响 H100 的科研，美政府告知该公司可以继续在中国进行 H100 人工智能芯片的开发工作。NVIDIA 称“美国政府新的授权要求并不完全等同于禁售、断供，而是对相关指定产品增加了多一道许可申请的要求。”

美方举动可能会削弱中国公司进行图像识别等先进技术的能力，对此中方回应称“美方的做法是典型的科技霸权主义”，“美方应立即停止错误做法，公平对待包括中国企业在内的各国企业，多做有利于世界经济稳定的事”。

01

Android 恶意软件伪装成《中国自由陷阱》并窃取信息

Cyber 研究员发现了一条 Twitter 帖子，其中安全研究人员分享了有关据称旨在针对维吾尔社区的 Android 恶意软件的信息。该恶意软件伪装成”The China Freedom Trap“（译《中国自由陷阱》）：该恶意软件的图标类似于Dolkun Isa 所著的《中国自由陷阱》一书的封面，并且在打开应用程序时，会向用户显示该书的几页，包括封面，本书及其作者的介绍，最后附上一封吊唁信。然而实际上恶意 APK 文件的设计目的是：

  1. 隐藏应用程序图标；

  2. 窃取设备和 SIM 信息；

  3. 窃取短信、联系人和通话记录；

  4. 识别相邻小区信息（接收信号强度、小区 ID 位置）；

  5. 代表受害者拨打电话和发送短信；

  6. 删除短信和通话记录；

  7. 从受感染设备的相机中拍照并捕获其屏幕。

02

赛门铁克在 1,800 多个移动应用程序中发现了硬编码的 AWS 凭证

研究人员已经在 Android 和 iOS 上发现了1859个包含硬编码 Amazon Web Services(AWS) 凭证的应用程序，这构成了重大的安全风险。超过四分之三(77%)的应用程序包含有效的 AWS 访问令牌，允许访问私有 AWS 云服务。有趣的是，发现超过50%的应用程序使用了与其他开发人员和公司维护的其他应用程序相同的 AWS 令牌，这凸显了一个具有严重影响的供应链问题。更糟糕的是，47%的已识别应用程序包含有效的 AWS 令牌，这些令牌授予对云中所有私有文件和 Amazon Simple Storage Service (S3) 存储桶的完全访问权限，包括基础设施文件和数据备份等。

原文链接：

https://symantec-enterprise-blogs.security.com/blogs/threat-intelligence/mobile-supply-chain-aws
