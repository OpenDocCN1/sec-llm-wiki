APT-C-23 通过 Microsoft Office 和 PDF 文档部署的 Escanor RAT 恶意软件

**组织：** 疑似 APT-C-23（又名双尾蝎/ AridViper，哈马斯）  

**攻击目标：** 美国、加拿大、阿联酋、沙特阿拉伯、科威特、巴林、埃及、以色列、墨西哥和新加坡、东南亚

**原文概述：** 研究人员在暗网论坛和 Telegram 频道中发现了一种新的远程管理工具 (RAT)，该工具将 Microsoft Office 和 Adobe PDF 文档作为武器来传递恶意代码。威胁行为者提供基于 Android 和基于 PC 的 RAT 版本，以及隐藏的虚拟网络计算 (HVNC) 模块和漏洞利用构建器，以武器化 Microsoft Office和 Adobe PDF 文档以传递恶意代码。网络犯罪分子积极使用 Escanor 的移动版本（也称为“Esca RAT”）通过拦截 OTP 代码来攻击网上银行客户。该工具可用于收集受害者的 GPS 坐标、监控击键、激活隐藏的摄像头以及浏览远程移动设备上的文件以窃取数据。

![](../Images/f5e3eb7aa31aba4b7f74ebf585eac270.png)

**归因分析：** 最近检测到的大多数样本都是使用 Escanor Exploit Builder 交付的。演员们使用诱饵文件模仿流行在线服务的发票和通知。域名“escanor\[.\]live”之前已被识别为与 AridViper (APT-C-23 / GnatSpy) 基础设施有关。并且在之前 360 的安全研究员发布报告之后，Escanor RAT 演员发布了一段视频，详细介绍了如何使用该工具绕过 AV 检测。

俄罗斯 APT29 组织使用 Azure 服务入侵 Microsoft 365 用户

**组织：** 疑似 APT29 (又名NOBELIUM/Cozy Bear/The Dukes，俄罗斯）    

**攻击目标：** Microsoft 365 用户

**原文概述：** 亲俄组织 Cozy Bear（APT29，Nobelium）正在使用新方法积极攻击 Microsoft 365 帐户，其中包括禁用许可证、 MFA 接管休眠账户、专注于运营安全等策略。

1.  禁用许可证：APT29 对受感染的目标帐户禁用 Purview Audit，然后针对目标收件箱收集电子邮件。禁用 Purview Audit 后的日志将不会保留邮件访问记录，以及威胁组织收集邮件账户的信息和时间。
    
2.  lMFA 接管休眠账户：APT29 通过获得的邮箱列表进行了密码猜测攻击，在获取到设置但从未使用过的帐户密码时，威胁组织可以根据 Azure AD 提示注册 MFA 后，便可以使用该帐户访问该组织的 VPN 基础架构（该基础架构使用 Azure AD 进行身份验证和 MFA）。
    
3.  专注于运营安全：APT29 除了使用代理来混淆攻击地址，还使用 Azure 虚拟机，并且将良性管理行为与其恶意行为混合在一起，添加服务证书进行验证以及试图将自己的行动伪装成合法行动，持续专注于运营安全。

Kimsuky 的金龙集群及其 C2 运营

**组织：** 疑似 Kimsuky（又名Thallium/ SharpTongue/SectorA05/APT-C-55，朝鲜）

**攻击目标：**

**攻击手法：** 【钓鱼攻击】

攻击者启动了感染链，发送了包含宏嵌入 Word 文档的鱼叉式网络钓鱼电子邮件。钓鱼文档有多个，但是每个都与朝鲜半岛地缘政治问题相关。如果受害者单击该链接，则会连接到第一阶段的 C2 服务器，并使用电子邮件地址作为参数。

第一阶段 C2 服务器验证传入的电子邮件地址参数是预期的，如果它在目标列表中，则传递恶意文档。第一阶段脚本还将受害者的 IP 地址转发到下一阶段服务器。打开获取的文档时，它会连接到第二个 C2 服务器。

第二个 C2 服务器上的相应脚本检查从第一阶段服务器转发的 IP 地址，以检查它是来自同一受害者的预期请求。使用此 IP 验证方案，参与者可以验证传入请求是否来自受害者。最重要的是，运营商依赖其他几个过程来仔细交付下一个有效负载，例如检查操作系统类型和预定义的用户代理字符串。

**02**

密码长度超过64字节的加密 ZIP 文件可能有两个正确的密码

研究人员发现加密的 ZIP 文件可能可以有两个正确的密码，并且在提取 ZIP 时都产生相同的结果。由于在启用 AES-256 模式生成受密码保护的 ZIP 存档时 ，如果密码超过 64 个字节，ZIP 格式使用PBKDF2算法并对用户提供的密码进行哈希处理。这个新计算的哈希值不是用户选择的密码，而是文件的实际密码。当用户尝试提取文件并输入超过 64 字节的密码时，用户的输入将再次被 ZIP 应用程序散列并与正确的密码进行比较密码（现在它本身就是一个哈希）。但是，现在同一个 ZIP 有两个可能的密码这一事实并不代表安全漏洞，“因为仍然必须知道原始密码才能生成密码的哈希值，”研究人员进一步解释道。

**01**

亚马逊Ring中的漏洞允许黑客通过摄像头进行间谍活动

Amazon Ring 公司开发和供应视频对讲机和视频监控系统，该公司的设备不仅可以广播监视器上发生的所有事情，还可以将记录保存到云端并在移动应用程序中显示图片。

Checkmarx 的一名安全研究人员分析了 Amazon Ring 应用的Android版本并发现其中存在漏洞，允许攻击者访问由Ring应用程序生成的敏感数据，不仅包括地理位置和摄像头记录，还包括全名、电子邮件地址、电话号码和邮政地址。由于 Ring Android 应用程序的下载量超过 1000 万次，并被全世界的人们使用，访问客户保存的摄像头记录的能力可能会导致从敲诈勒索到数据盗窃等各种恶意行为。与此同时，据亚马逊称，没有发现利用该漏洞的案例。此外，值得注意的是，该漏洞已在5月27日更新中修复，但该修复仅在前几天公开宣布。
