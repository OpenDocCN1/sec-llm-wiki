【重要】海莲花组织针对我国关基单位攻击活动分析

组织： 疑似APT32（又名OceanLotus／BISMUTH/海莲花，越南）

攻击目标： 中国关基单位

原文概述： 攻击者针对我国关基单位负责重点课题的研究员发起APT定向攻击，瞄准文档类资料进行窃取，以窃取机密资料和重要文件为目标。通过流量分析，发现国内某核心制造业厂商也同样遭受该组织攻击，并持续处于活跃状态，经过处置，研究人员已成功阻断该组织攻击活动。在此次事件中，APT32组织选择了RemyRAT远程控制木马作为后门程序植入了国家关基单位。

海莲花专用工具 RemyRAT 所使用的TTP

归因分析： RemyRAT在本次关基单位应急事件中作为海莲花组织的专有工具被发现。通过流量还原技术，观察受害者IP与C&C的交互，发现出现单字节传输，通讯协议相似，固定长度心跳，上线交互一致等特征，通过与伏影实验室针对海莲花APT组织工具复盘特征的比对，将此流量定性为海莲花远程控制工具RemyRAT所产生。

02

Lazarus 参与了对  DeBridge Finance 的攻击

组织： 疑似Lazarus（又名 APT-C-26/APT38，朝鲜）    

攻击目标： DeBridge Finance 公司

攻击手法： 【鱼叉式钓鱼攻击】

攻击者针对 deBridge Finance 员工发送了一封声称来自该公司联合创始人 Alex Smirnov 的电子邮件，其中包含一个名为“新薪金调整”的 HTML 文件，该文件伪装成 PDF 文件，以及一个伪装成包含密码的纯文本文件的 Windows 快捷方式文件 (.LNK)。单击打开伪造的 PDF，要求输入密码；当用户打开 “password.txt.lnk” 文件时，整个系统将会被感染。研究人员在深度分析后发现该 .LNK 文件有以下功能：

  1. 显示带有“pdf 密码”的 notepad.exe：Salary2022；

  2. 检查防病毒进程是否处于活动状态（ekrn - Eset、qqpcrtp - 腾讯、bdagent - BitDefender）；

  3. 如果没有找到相应进程：将生成的名为 Box.lnk 的恶意文件保存到 autostart 文件夹中；

  4. 从 var lp 中解码 Base64 编码的后门，将其保存到一个随机名称的文件中；

  5. 向攻击者指挥中心 (C2) 发送重复请求，以便接收指令。接收到的指令收集了大量关于 PC 的信息并将其导出到 C2：用户名、操作系统信息、CPU 信息、网络适配器和正在运行的进程。

疑似Lazarus 的子组 Andariel 部署 DTrack 和 Maui 勒索软件并攻击医疗保健和公共卫生部门

组织： 疑似Lazarus（又名 APT-C-26/APT38，朝鲜）（Andariel 是 Lazarus 的子组）

攻击目标： 美国医疗保健和公共卫生部门

原文概述： 卡巴斯基将Maui勒索软件攻击与朝鲜支持的APT组织Lazarus的子组Andariel联系起来，他们认为此联系有中等可信度。据卡巴斯基所说，在针对日本，俄罗斯等公司的攻击中使用的特定DTrack变体与以前的Andariel业务直接相关的样本具有84%的代码相似性。并且根据受害者的日志分析显示，受害者公司的网络中几个月前就存在“3Proxy”工具，此工具在Andariel过去的各种活动中被观察到使用。

归因分析： 1、代码相似性。来自受害者的 DTrack 恶意软件与先前已知的 DTrack 恶意软件具有高度的代码相似性 (84%)，并且 “DTrack” 恶意软件使用了与“Backdoor.Preft”恶意软件相同的 shellcode 加载程序；

2、攻击者使用了 3Proxy 工具，该工具之前也被 Andariel 使用过。

综上所述，将此次攻击归因于 Lazarus 的子组 Andariel。

Bitter APT 的“Dracarys”Android 间谍软件

组织： 疑似蔓灵花（又名Bitter，印度）

攻击目标： 新西兰、印度、巴基斯坦和英国

原文概述： Bitter APT 积极参与桌面和移动恶意软件活动，并使用鱼叉式网络钓鱼电子邮件等技术，利用已知漏洞传递远程访问木马 (RAT) 和其他恶意软件系列进行攻击。本月 4 日，Meta 发布《Meta 的对抗性威胁报告，2022 年第二季度》，其中研究人员提到Bitter APT 提供了 Android 间谍软件“Dracarys”。值得注意的是，该恶意软件使用了辅助功能服务（这是 Android 操作系统中帮助残疾用户的一项功能，可以自动点击并授予应用程序某些权限）。Dracarys Android 间谍软件冒充正版应用程序，例如 Signal、Telegram、WhatsApp、YouTube 和其他聊天应用程序，并通过网络钓鱼站点进行分发。

在此文发出之时，研究人员观察到其中一个网络钓鱼站点仍然模仿真正的 Signal 站点并提供木马化 Signal 应用程序。本文对木马化 Signal 应用程序进行分析。

Kimsuky 冒充韩国国内大型门户云服务进行攻击

组织： 疑似Kimsuky（又名APT-C-55/ Thallium/SharpTongue/SectorA05/，朝鲜）  

攻击目标： 在朝鲜工作的专家和记者

攻击手法： 【钓鱼攻击】

韩国国内某大型门户公司伪装成云共享邀请服务发起一系列图书链接黑客攻击。此次攻击使用伪装的共享文件“朝鲜核发展历史和美朝关系发展前景”、云共享受邀者冒充上届政府担任负责海外和朝鲜事务的国家情报局第一副局长的名字进行了攻击。在黑客攻击邮件的正文中，为了诱导点击分享邀请接受按钮，正文内容使用了如下语句：“我们将向您发送一份关于朝鲜第八次党代会南部战略路线和政策变化的前景”，“我分享这个文件是因为我认为如果你参考它会对其他人有帮助。” 作为 ESRC 分析的结果，如果收件人单击黑客电子邮件正文中包含的共享邀请上的 [Accept] 按钮，它会连接到网络钓鱼服务器，例如 'share.myboxes.navers[.]tech'以及 ' view.boxfile[.]click' 等，试图窃取用户的密码。虽然攻击者没有使用云服务的实际分享邀请功能，但黑客邮件的正文模仿了实际服务的设计和文本，因此收到分享的收件人很容易点开文档，从而受到攻击。

【疑似APT】TAC-040 利用 Atlassian Confluence 漏洞部署新的“Ljl”后门

组织： 疑似 TAC-040

攻击目标： 在医疗保健、教育、国际发展、环境和农业领域进行研究的组织，以及一些提供技术服务的组织

原文概述： 研究人员发现被跟踪为 TAC-040 的攻击组织可能利用 Atlassian Confluence 服务器中的CVE-2022-26134漏洞部署了一个以前未被检测到的后门 Ljl Backdoor。攻击者利用该漏洞对研究和技术服务部门的一个未具名组织进行攻击。在获得初始访问权限后，被称为 TAC-040 的 TA 将运行各种命令来枚举本地系统、网络和 Active Directory 环境。 此外，Deepwatch 表示 TA 可能使用 RAR 和 7zip 来归档来自多个目录的文件和文件夹，包括注册表配置单元。这次攻击发生在 5 月，持续了 7 天，对网络日志的分析表明 TAC-040 从受害者系统中窃取了大约 700MB 的数据。

就攻击背后的动机而言，Deepwatch 表示它们可能与间谍活动有关，但该公司不能完全排除它们是出于经济动机，因为它表示它还在系统上发现了 XMRig 加密矿工的加载程序。TAC-040 的目标是在医疗保健、教育、国际发展、环境和农业领域进行研究的组织，以及一些提供技术服务的组织。

01

【重要】美国前国安官员成立开源情报基金会，加强社交媒体等公开数据利用

7月29日，一群前美国国家安全官员共同成立了一个专业协会，希望促进开源情报流通，通过对公开数据分析帮助西方大国了解与追踪俄乌战争情况。

研究人员对此基金会进行了初步调研并形成了报告，通过对人员的背景调查发现该组织的高层人员和咨询委员会都曾在政府机构任职，尤其是高层二人，均有30多年的情报行业工作经验，而咨询委员会的工作经历均与国防、国土、国家安全领域相关，最终目的都是保护美国国家安全。因此该组织目前在俄乌问题上给予美国情报方面的支撑，日后说不定也会帮助美国政府，从开源情报方面“研究”中国并给出针对性的指导意见。

全球诈骗行动 “Classiscam” 扩大到新加坡

2022 年 3 月，Classiscam（一种复杂的诈骗即服务业务）已扩展到新加坡。Classiscam 欺诈者，顾名思义，以其中一个的用户为目标，冒充合法买家的诈骗者接近卖家，要求从他们的列表中购买商品，最终目的是窃取付款数据。自从 Classiscam 出现在新加坡以来，研究人员已在本地分类网站上检测到总共 18 个旨在针对买家的域，但据该团队称，实际的钓鱼域应该会更多。

推特确认540万账户数据泄露为零日漏洞引发

Twitter证实，最近暴露540万个帐户数据的数据泄露是由利用零日漏洞引起的。7月底，一名攻击者泄露了540万个Twitter帐户的数据，这些帐户是通过利用流行的社交媒体平台中现已修复的漏洞获得的。这个漏洞是2021年6月更新代码的结果。当安全人员得知此事后立即进行调查并修复了它，当时还没有证据表明有人利用了这个漏洞。
