Gamaredon APT组织使用恶意程序 GammaLoad.PS1_v2对乌克兰进行网络攻击

组织： 疑似Gamaredon（又名Armageddon/GammaLoad/UAC-0010/APT-C-53/，俄罗斯FSB）    

攻击目标： 乌克兰

攻击手法： 【鱼叉式钓鱼攻击】

攻击者使用集体大规模分发有针对性的网络钓鱼电子邮件，利用与战争相关的诱饵作为电子邮件主题，包括“Інформаційний бюлетень（译：信息公告）”、“Бойове розпорядження（译：战斗命令）”的邮件主题，并伪装成乌克兰国家安全局的发件人。这些欺骗性电子邮件包含触发感染链的 HTM dropper。一旦打开，后者会创建一个带有 LNK 快捷方式文件的恶意 RAR 存档，用作诱骗受害者打开它的诱饵。如果打开，上述 LNK 文件会下载并运行包含 VBScript 代码的 HTA 文件，该文件应用 PowerShell 解密并在目标计算机上启动 GammaLoad.PS1_v2 恶意软件。为逃避检测，攻击者使用外部服务来阻止 C2 服务器的 DNS 解析。

02

Securonix观察到新的攻击活动可能与 APT37有关

组织： 疑似APT37（又名Hermit/Ricochet Chollima，朝鲜）    

攻击目标： 捷克共和国、波兰和其他欧洲国家的高价值组织

攻击手法： 【钓鱼攻击】

攻击者使用网络钓鱼电子邮件，这些电子邮件中包含恶意压缩文件作为邮件附件。压缩文件解压后含有文件'missile.docx'以及 '_weapons.doc.lnk'。打开 LNK 文件后，代码运行以在 DOCX 文件中查找 base64 编码的 PowerShell 脚本，以建立 C2 通信并下载两个附加文件，“weapons.doc”和第二阶段加载器“wp.vbs”。下载的文件是一个诱饵，据推测是俄罗斯战地记者奥尔加·博热瓦（Olga Bozheva）的报告。同时，VBS文件在后台静默运行。在第二阶段，恶意 VBscript 文件在宿主机创建了一个名为“Office Update”的新计划任务，计划任务执行以 Base64 编码的 PowerShell 脚本。此时 C2 通信再次建立，为攻击者提供了对系统的访问权限。在第三阶段，从 C2 服务器请求将加载到内存中的 .NET 程序集。在攻击的这个阶段，攻击者已经加载了 RAT 并建立了数据交换链路，并且能够执行以下操作：

  • 使用 Win32 GDI API 捕获屏幕截图并以 GZIP 形式泄露它们。

  • 提取存储在本地状态文件中的状态密钥，用于 cookie 数据库解密，在 MFA 绕过中很有用。

  • 从受害者的网络浏览器中提取保存的凭据。

  • 启动可以每 10 秒执行一次命令的远程交互式 shell。

在第四阶段，攻击者对主机有一定的控制权，并且能够下载和执行命令。为了进一步推进持久性阶段，黑客下载了支持修改后的 Konni 样本功能的附加文件，并将它们提取为压缩的“.cab”压缩文件。该文件包含与恶意软件相关的多个文件，如替换合法 Windows 服务库（如 System32 中的“wpcsvc”）的 DLL，该库用于在具有更高用户权限的操作系统中执行命令。

值得关注的是，此次攻击使用了 Konni 恶意软件，并且这次攻击与研究人员之前从 FancyBear/APT28 中看到的历史数据之间似乎存在 IP 地址、托管服务提供商和主机名之间的直接关联。

攻击链

归因分析： 使用的恶意软件是Konni。Konni 恶意软件被归类为 APT37 大量使用的 RAT（远程访问木马），包含提升权限并在受影响主机上保持持久性的内置功能。这种特殊的恶意软件于 2014 年被发现，并归因于朝鲜 APT37 组织。因此研究人员认为此次攻击可能是 APT37 组织发起的。但是不排除 APT28 支持该活动的可能性。

俄罗斯国家支持的行为者使用 GoMet 后门攻击乌克兰

组织： 疑似俄罗斯国家支持的攻击者

攻击目标： 乌克兰大型软件开发公司

攻击手法： 此次事件针对的是一家大型软件开发公司，该公司的软件被乌克兰境内的各个国家组织使用。而研究人员认为不能忽视攻击者想要获取供应链式攻击来源的可能性。研究人员确认该恶意软件是名为“GoMet”的开源后门的略微修改版本。修改的内容包括：修改了 cronjob 配置（此操作能缩短其连接执行时间，使其在连接失败时能有效防止连接中止，有效连接到C2）、cron 模块中的字符串以及相关受害者和编译器数据等等。

目前网络上能找到的对 GoMet 后门的使用情况，都是攻击者先利用设备上的公共漏洞，然后恶意行为者将 GoMet 作为后门丢弃。值得关注的是，在此次事件中该恶意软件使用了一种有些新颖的持久性方法，即它列举了自动运行的值，而不是创建一个新的值，而是用恶意软件替换了一个现有的好软件自动运行可执行文件，这可能会避免检测或阻碍研究人员分析。

GoMet 后门本身是一个用 Go 编程语言编写的相当简单的软件。它几乎包含攻击者在远程控制代理中可能想要的所有常用功能。代理可以部署在各种操作系统 (OS) 或架构（amd64、arm 等）上。

攻击目标： 印度国防部下属企业

攻击手法： 【钓鱼攻击】

近期安恒信息中央研究院猎影实验室捕获到透明部落组织针对印度国防部下属企业攻击的样本，样本格式为带有恶意宏的pptm文件，可能通过钓鱼邮件投递至印度国防部下属企业，样本中的宏代码会释放并执行CrimsonRAT，执行来自恶意C2的各种命令。诱饵文档冒充为印度国防部下发的指令，大意为通知各个印度国防公共部门企业进行“清洁运动”以减少未决事项。

宏代码的主要执行流程

归因分析： 

1、本次攻击释放的最终载荷被识别为Crimson RAT，而Crimson RAT是透明部落特有的远控软件。并且本次样本的Crimson RAT的执行流程与此前披露的样本存在多处重合，具体如下：

  • 样本中硬编码的版本号格式相近；

  • 功能入口由定时器触发函数回调进入；

3、诱饵文档中说明“DPSUs附属/下属办公室的所有联合秘书级官员将确保并监督清洁工作，相关部门的所有员工都将参与清洁运动。”“DPSUs”是“Defence Public Sector Undertakings”的缩写形式，译为“国防公共部门企业”，归印度国防部国防生产部管控。

【重要】阿里巴巴 OSS Buckets 被盗，被恶意行为者通过隐写术分发恶意 Shell 脚本

OSS是一项服务，允许阿里云客户将Web应用程序图像和备份信息等数据存储在云端。最近，研究人员发现了一个恶意活动，该活动使用阿里云（也称为阿里云）的对象存储服务 (OSS)进行恶意软件分发和非法加密货币挖掘活动。

为了保护 OSS 存储桶，用户必须设置适当的访问策略。如果此操作不正确，恶意用户可以将用户的文件上传或下载到存储桶本身或从存储桶本身下载。恶意行为者还可以通过获取用户的AccessKey ID 和 AccessKey secret或 auth-token 来获取用户的 OSS 存储桶。当研究人员调查此活动的技术细节时，他们发现其中一个 shell 脚本包含对 OSS KeySecret 和 GitHub 的引用。最初，研究人员假设恶意行为者只是搜索无意中推送到 GitHub 公共存储库中的凭据。在分析的一个样本中看到了对恶意脚本的评论证实了他们的初步假设。

图 1. 恶意脚本中的注释表明开发人员不良做法已被利用

经过进一步调查，他们发现恶意行为者使用隐写术将包含嵌入式 shell 脚本的图像上传到受感染的 OSS 存储桶，而用户将能够访问图像本身，却不会看到附加到文件的恶意脚本。恶意Shell 脚本以配置错误的 Redis 实例为目标来挖掘 Monero 矿工。
