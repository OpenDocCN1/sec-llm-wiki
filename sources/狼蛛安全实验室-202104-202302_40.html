透明部落伪装印度国防部邮件攻击的跟踪简报

组织： 疑似透明部落（又名Transparent Tribe／APT-C-56／APT36，南亚）    

攻击目标： 印度国防部

攻击手法： 【鱼叉式钓鱼攻击】

包含宏代码是恶意文档标题伪装成数据表格，文档内容伪装成印度国防部的国防保卫部与秘书处（LS）发出的邮件内容，生成电子邮件更换并需要转发。恶意宏的功能是根据目标机器不同操作系统系统号释放对应的不同二进制PE文件并最终启动RAT后门。释放的RAT后门是透明部落一直维护和使用的CrimsonRAT。该后门支持加载键盘记录器，USB蠕虫等可扩展模块，并且还有主要用于管理受感染机器的Server组件。由于此次捕获的样本与上一次的样本相似程度极高，研究人员暂时尚不能确定是否仅是测试文档，还是上次攻击未被发现披露的IOC。

归因分析： 此次捕获的文档与之前透明部落组织的攻击文档从内容到流程基本相同，最后释放的还是上次的攻击RAT，仅文档发生了一点变化。

02

Kimsuky 近期以多个话题针对韩国的鱼叉

攻击活动分析

组织： 疑似Kimsuky（又名SectorA05/APT-C-55，朝鲜）    

攻击目标： 韩国

攻击手法： 【鱼叉式钓鱼攻击】

攻击使用多个诱饵话题进行攻击，例如“第20届脱北者咨询委员会意见收集“、”文化体育观光部韩国政策广播院节目邀请“等话题。在此攻击活动中，攻击者使用带恶意ole对象的hwp文件进行鱼叉攻击，当受害者点击执行诱饵文件之后，将会展示一个提示内容，诱导用户进行交互，以达到执行恶意载荷的目的。从此次Kimsuky的攻击活动中，研究人员总结出该组织的攻击手段具有以下特点：

1. 通过执行hwp文档中的OLE对象，将hellcode注入正常程序来执行后续操作；

2. Kimsuky组织拓宽武器库，使用MSF生成Shellcode；

3. 后续载荷均未落地，以无文件运行方式躲避杀软查杀。

hwp是韩国hansoft开发的hangul办公软件使用的文档，一般常见于针对韩国的攻击活动中。这种钓鱼攻击主要通过恶意ole内嵌对象、恶意eps及esp配合文档漏洞来进行攻击。钓鱼攻击使用的诱饵话题以半岛地缘政治为主，辅以经济民生、工程项目、加密货币等话题进行攻击。

归因分析： 根据其钓鱼规模、针对目标、技战法（TTP）、C2地域归属 等方面来看，研究人员有中等信心将其归因于Kimsuky组织。

1、在Kimsuky组织以往的攻击活动中，使用电子邮件中嵌入恶意附件的鱼叉式网络钓鱼是获取受害者网络初始访问权限最常见的策略。它在鱼叉式网络钓鱼活动中使用了包含 Word、Excel 或 HWP文档的电子邮件，将带有漏洞的文档或者嵌入ole对象的文档向受害者投递，其诱饵内容往往极具诱惑性和针对性。

2、Kimsuky使用PowerShell来执行各种来自Internet的可执行文件，而无需将后续载荷接触计算机上的物理硬盘，达到无文件运行的目的，以此降低被发现的风险。并且研究人员发现早在今年3月初，韩国某安全厂商就曾披露过类似行动，其中的TTP几乎一模一样，使用“第20届总统选举新闻稿“为诱饵进行攻击

03

Lyceum组织以军事热点事件为诱饵针对中东地区的定向攻击

组织： 疑似Lyceum（又名Hexane/Spilrin，伊朗）

攻击目标： 中东地区能源企业

攻击手法： 【鱼叉式钓鱼攻击】

攻击者诱骗受害者点击下载docm文件或者伪装的SCR屏幕保护程序。初始样本带有伪装为Microsoft的数字签名。将样本文件后缀改为rar，解密打开后发现其中包含两个文件（s563.exe以及s563.exe），自解压脚本运行其中的 s563.exe。s563.exe的主要功能为从同目录下的f1.jpg文件中读取后续待释放文件数据，解密后释放到指定位置，并启动执行。攻击样本被下载执行后，会释放一个诱饵文件来迷惑受害者。释放的诱饵PDF内容为“无人机击中伊朗帕尔钦军事基地”的新闻报道，原始报道发布时间为5月27日。而释放的后门文件与Lyceum组织之前的后门样本相似，获取本机信息并与远程C2连接，接着执行远程命令，达到数据窃取、远程命令执行、远程文件下载等功能。

从此次Lyceum的攻击活动中，研究人员总结出该组织的攻击手段具有以下特点： 

（1）Lyceum组织通过planet-informer[.]me域托管攻击样本； 

（2）SCR攻击样本实际为带有密码保护的SFX文件，SFX解压得到的释放器从伪装的jpg图片文件中提取出后门和诱饵释放器的可执行文件数据；

（3）第一阶段释放器和后门依然沿用了Lyceum组织此前样本中使用的C#代码控制流平坦化手段。

攻击流程

归因分析： 1、释放的后门文件与Lyceum组织之前的后门样本相似；

2、对使用的托管域的进一步分析后发现其存在另一个链接托管了武器化的docm文档，疑似之前国际安全厂商曾披露的活动中使用，且披露的恶意载荷URL与本次捕获的URL链接结构上高度相似；

3、对样本进行调研，发现其与之前披露过的攻击样本同源并且其路径中都包含“u1”这个用户名；

4、在代码层面，也与国外厂商披露的代码相类似，在配置选项中除通讯端口外几乎一模一样；

5、攻击目标与该组织以往攻击目标一致。

综上所述，研究人员将此次攻击归因于Lyceum组织。

APT28 使用 CredoMap 恶意软件发起的网络攻击

组织： 疑似APT28（又名Fancy Bear/UAC-0028，俄罗斯）

攻击目标： 乌克兰

攻击手法： 【钓鱼攻击、漏洞利用】

攻击者利用乌克兰人对潜在核攻击的恐惧，向受害者发送包含名为“Nuclear Terrorism A Very Real Threat.rtf.”的恶意文件的电子邮件。打开该文件会导致下载 HTML 文件并执行 JavaScript 代码 (CVE-2022-30190) ，这将确保下载和启动 CredoMap 恶意软件。

Follina漏洞 (CVE-2022-30190) 是 Microsoft 诊断工具中的一个漏洞，至少从 2022 年 4 月开始就被广泛利用，只需打开文档文件就可以触发恶意下载，如果是 RTF，只需 在 Windows 预览窗格中查看即可。

CredoMap 是Virus Total上的多个 AV 引擎检测到的未知恶意软件株，许多供应商将其归类为密码窃取木马。该恶意软件旨在窃取存储在Chrome、Edge和Firefox网络浏览器中的信息，例如帐户凭据和cookie。
