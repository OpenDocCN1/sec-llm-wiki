伊朗 Lyceum APT黑客组织利用新的DNS后门攻击能源行业

组织： 疑似Lyceum（又名Hexane/Spilrin，伊朗）

攻击目标： 中东能源和电信行业

原文概述：  Zscaler最近的一项分析提出了一个基于DIG.net开源工具的新DNS后门，用于执行“DNS劫持”攻击、执行命令、丢弃更多有效负载和泄露数据。

攻击从一个Word文档开始，该文档包含从伪装成新闻网站的网站下载的恶意宏。该文件被掩盖为带有伊朗军事主题的新闻报道。如果目标在其Microsoft Office上启用宏以查看内容，则 DNS 后门将直接放入Startup文件夹，以在重新启动之间建立持久性。后门使用文件名“DnsSystem.exe”，它是DIG.net的定制版本，攻击者根据需要对其进行了调整。该恶意软件通过获取“cyberclub[.]one”域的IP地址来设置DNS劫持服务器，并根据受害者的用户名生成一个MD5作为唯一的受害者ID。

02

Sandworm 使用恶意程序 CrescentImp 对乌克兰媒体组织进行大规模网络攻击

组织： 疑似Sandworm（又名Telebots/Voodoo Bear/Iron Viking/BlackEnergy/Unit 74455，俄罗斯GRU）    

攻击目标： 乌克兰媒体组织

攻击手法： 【钓鱼攻击、漏洞利用】

Follina，这是Microsoft Windows支持诊断工具 (MSDT)中的一个远程代码执行漏洞，目前被跟踪为CVE-2022-30190，该漏洞可以通过打开或选择特制文档来触发。

攻击者利用Follina漏洞，向乌克兰媒体组织（广播电台、报纸、新闻机构等）超过500名收件人发送主题为“交互式地图链接列表”的钓鱼邮件。邮件带附件，附件包含同名武器化文档“LIST_of_links_interactive_maps.docx”，打开该文件将加载 HTML 文件并执行 JavaScript 代码，进而下载并执行归类为“恶意 CrescentImp”的 EXE 文件“2.txt”。但是，尚不清楚CrescentImp属于哪种类型的恶意软件家族或其功能。来自CERT-UA的哈希显示目前在Virus Total 扫描平台上没有检测到。

原文链接：

https://cert.gov.ua/article/160530

发布平台： CERT-UA

伊朗鱼叉式网络钓鱼行动针对以色列和美国前高级官员

组织： 疑似Charming Kitten（又名Cobalt Mirage/Phosphorous/TunnelVision，伊朗）    

攻击目标： 以色列和美国前高级官员前以色列官员、高级军事人员、研究机构研究员、智囊团和以色列公民

攻击手法： 【鱼叉式钓鱼攻击】

该活动包括通过被劫持的合法和虚假电子邮件帐户进行鱼叉式网络钓鱼、伪造URL缩短器、以凭据收集为主题的以雅虎为主题的网络钓鱼页面，以及使用合法文件验证服务来获取目标的ID或护照扫描。该活动的一部分包括一个窃取证书的页面，该页面被模拟为“滑雪者圆桌会议”的邀请。研究人员指出，这可能只是一种旨在窃取凭据的形式，或者它有可能是伊朗阴谋引诱以色列目标参加海外活动的一个例子。

为了与新目标建立更深的信任，威胁参与者对一些受害者的收件箱进行了帐户接管，然后劫持了现有的电子邮件对话，从目标和受信任方之间现有的电子邮件对话开始攻击，并以这种名义继续对话，并且在许多情况下，对话都提到了伊朗和以色列的安全问题；为了方便他们的鱼叉式网络钓鱼操作，攻击者使用了一个虚假的 URL 缩短器 Litby[.]us来伪装网络钓鱼链接，并利用合法的身份验证服务validation.com来盗取身份证件。

归因分析：

1、以色列官员一直是伊朗国家实体的主要目标；

2、周边的地缘政治事件是伊朗威胁行为者常常使用的诱饵文件话题，事实上，最近有报道称，在以色列安全机构 Shin Bet曝光的另一次类似活动中，以色列官员被邀请参加海外活动，涉嫌绑架他们；

3、Yahoo 网络钓鱼页面源代码中的伊朗 IP 地址以及来自 Phosphorus 活动分析的旧的、已注释掉的代码（存在但未执行或运行的代码）曾在 2020 年被微软披露并归因于

Charming Kitten。

综上，研究人员将此次攻击归因于Charming Kitten组织。

APT组织APT-C-23近期攻击活动分析

组织： 疑似APT-C-23（又名双尾蝎/AridViper，哈马斯）

攻击目标： 中东

攻击手法： 【鱼叉式网络钓鱼攻击】

攻击者注册域名用于攻击活动。初始样本是以《法塔赫运动和巴勒斯坦事业的未来》话题为诱饵的带有恶意宏代码的DOCM文件。宏代码运行后将加载执行恶意代码，与C2相连，执行信息上传、持久化、信息窃取、屏幕截图等功能。

归因分析：

1、此次捕获样本与Cybereason 2020年披露的Molerats活动[1]中的恶意DOC文档以及Pierogi后门的重合之处：宏代码均将有效负载先写入TXT文件再创建PE文件写入；后门均使用WMI SQL查询本机的反病毒软件信息；均在%AppData%\Microsoft\Windows\
Start Menu\Programs\Startup目录创建快捷方式实现持久化；Pierogi后门发送到C2的信息包括：cname计算机名、av反病毒软件、osversion操作系统版本、aname恶意软件在受感染机器上的位置，与此次捕获样本所上传的信息相同；C2下发指令包括：截屏、shell指令以及文件下载，与此次捕获的后门样本C2下发指令完全重合。

2、本次捕获样本的网络流量特征与研究人员于2020年披露的AridViper攻击活动有相似之处，响应包格式均为："key" : ["The key is required."]。“巧合”的是，后门的POST包缺省字段均为反病毒软件查询字段。

3、 此次捕获后门连接到的URL路径与Palo Alto 2020年披露的AridViper新型python后门PyMICROPSIA[2]连接的URL路径结构的风格相似，均为随机字符组成。

4、在代码细节方面，此次捕获后门在算法处与AridViper历史样本中存在一致的部分。

综上所述，研究人员将此次攻击归因于APT-C-23组织。

【重要】二维码（QR码）网络钓鱼成为新威胁

QR（或快速响应）代码是一种特殊的条形码，可以在水平和垂直方向上存储数据，这意味着它们比典型的条形码（最大容量为 4,296 个字母数字字符）可以容纳更多的数据。随着疫苗接种运动在全球范围内受到关注，许多国家开始使用二维码来验证个人的疫苗接种状态。这些代码现在在社会的许多层面无处不在，从公务员到面向客户的企业。二维码为攻击者提供了一种多样化网络钓鱼策略的方法。并且由于电子邮件过滤解决方案在检测电子邮件中的可疑链接方面并未扩展到 QR 码，QR 网络钓鱼提供了绕过高级电子邮件安全工具的途径。常见的利用方式有：通过电子邮件利用；或威胁行为者用恶意代码覆盖餐厅菜单、广告或布告栏上的现有二维码，以利用这些代码的广泛使用引发的隐含信任。二维码网络钓鱼诈骗可能会变得更加普遍，联邦调查局甚至在 2022 年初发布了有关威胁的警告。
