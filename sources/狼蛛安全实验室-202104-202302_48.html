组织： 疑似UNC3524

攻击目标： 企业发展、并购和大型企业交易的员工

原文概述：Mandiant 研究人员发现了一个名为 UNC3524 的新 APT 组，该组主要针对专注于企业发展、并购和大型企业交易的员工的电子邮件，其c2系统主要是LifeSize, Inc的摄像头系统。该组织从入侵到被发现的时间长达 18 个月，而2021 年的平均停留时间为 21 天，其部分原因在于他们选择在不支持防病毒或端点保护等安全工具的受害环境中的设备上安装后门。高水平的操作安全性、低恶意软件足迹、娴熟的规避技能和大型物联网 (IoT) 设备僵尸网络使该组与众不同，并强调高级持续威胁中的“高级”。UNC3524 也非常重视持久性。每次受害者环境删除他们的访问权限时，该组织都会立即使用各种机制重新破坏环境，立即重新启动他们的数据盗窃活动。此博客介绍了该组织的工具（即于开源 Dropbear SSH 客户端-服务器软件开发的新型后门程序 QUIETEXIT）、策略和程序。研究人员观察到的 UNC3524 的 TTP 与与俄罗斯相关的 APT 组织相关的 TTP 重叠，包括 APT28 和 APT29。

APT32与StrikeSuit Gift恶意软件源代码包的联系

组织： 疑似APT32（又称OceanLotus／BISMUTH，越南）

攻击目标： 外国政府、持不同政见者、记者等

原文概述： Stairwell研究人员发现一个2017年末提交VirusTotal的归档文件，这个归档文件包含了恶意软件源代码、shellcode、测试文件、文档、宏脚本、注释等。这个恶意软件的源代码内部命名为StrikeSuit Gift，它似乎是多年前开发的。此外，通过细枝末节的检查，Stairwell研究人员认为这个源代码包是由APT32开发或使用的。APT32，也被称为“OceanLotus”和“BISMUTH”，2017年正是APT32的黄金时代，这个多产的越南APT组织，不断攻击外国政府、持不同政见者、记者等。该组织以创新攻击方式和防御规避而闻名，它使用定制开发的、开源的和商业可用的工具来执行攻击活动。

归因分析：

１、L.dll 外壳代码加载器的hash与之前的研究中提到的相同，且strike suit Gift project web builder/shell code loader 具有作为这个加载器的源代码的所有技术特征；

２、在 VB 宏和 XML 调度任务中与 APT32(或 OceanLotus)有更直接和明显的联系；

综上，研究人员将此次发现的恶意软件源代码包归因于APT32组织。

组织： 疑似Lazarus（又名 APT-C-26，APT38，朝鲜）

原文概述： Andariel 团伙被韩国金融安全研究所（Korean Financial Security Institute）归属为Lazarus APT组织的下属团体。近日，奇安信威胁情报中心红雨滴团队在日常的威胁狩猎中捕获到一批与Andariel相关的攻击样本，均为PE可执行文件。根据这批样本上传VT的时间可知相关攻击活动至少从今年2月份开始发起。攻击样本可以分为两类：一类是内存中解密并加载后续载荷的加载器，加载的内容包括后门和浏览器窃密程序;另一类是用Go语言编写的下载器，向C2服务器回传收集的主机信息然后下载PE文件并执行。大部分Go下载器目前在VT上的检出数量仍然较少，仅为个位数，这可能是攻击者选用Go开发恶意软件的一个原因。

Hive0117针对东欧投递无文件恶意软件DarkWatchman

组织： 疑似Hive0117

攻击目标： 立陶宛、爱沙尼亚和俄罗斯的电信服务提供商和工业公司

攻击手法： 【钓鱼攻击】

攻击者冒充来自俄罗斯政府的联邦执法局给受害者发送邮件。电子邮件的内容具有相同的俄语文本，详细介绍了与莫斯科昆采夫斯基地区法院相关的执法程序相关的几篇文章，这些文章由“执行税务机关决定的跨区法警部门法警”维护。电子邮件包含嵌入恶意软件的．ｚｉｐ文件附件，名为“Исполнительный лист XXXXXXX-22.zip”，其中“X”表示数字值，或“Счет 63711-21 от 30.12.2021.zip”，分别翻译为“Performance”清单”、“执行令”和“发票”。在电子邮件中观察到的唯一变化是与单个电子邮件相关联的名称和“案例编号”以及随附的恶意 ZIP 存档文件附件。每个存档文件都包含一个同名的可执行文件，旨在为键盘记录器提供 DarkWatchman JavaScript 后门和加密源代码，类似于 2021 年 12 月的报告。恶意电子邮件的最终目标是将DarkWatchman恶意软件的副本投放到受害者的计算机上。

DarkWatchman是一种带有C# 键盘记录器的轻量级、隐秘的JavaScript RAT（远程访问工具）。DarkWatchman之前曾与俄罗斯威胁行为者有联系，主要针对他们本国的组织。在某些情况下，攻击者使用加载器文件从在线资源(domtut[.]site|fun|online) 中获取两个经过混淆的有效负载、一个作为后门的JavaScript文件和一个执行键盘记录器的PowerShell 块。DarkWatchman菌株采用域生成算法(DGA)来生成C2域，使其基础设施映射和拆除更加困难。

归因分析： 新恶意软件样本似乎都基于以前与 Hive0117 活动相关的 C2 IP 地址 (103.153.157[.]33)，因此研究人员将此次攻击归因于Hive0117 组织。

TA542投递Emotet 恶意软件开展攻击活动

组织： 疑似TA542（又称Mummy Spider）

攻击手法： 【钓鱼攻击】

攻击者以受损坏的邮箱发送Eｍotet电子邮件，电子邮件标题仅有一个词，正文仅包含托管包含 Microsoft Excel 加载项 (XLL) 文件的 zip 文件的 OneDrive URL，不包含其他内容。zip和XLL文件使用与电子邮件相同的主题，且zip文件包含同一个 XLL 文件的四个副本，XLL 文件在执行时会利用 Epoch 4 僵尸网络删除并运行 Emotet。已识别的活动在以下方面与之前观察到的 Emotet 活动不同：

１、活动的低容量性质。通常，Emotet 会向全球许多客户分发大量电子邮件活动，最近几周的一些活动总共达到了 100 万封邮件。 

２、OneDrive URL 的使用。通常，Emotet 会提供链接到 Office 文件的 Microsoft Office 附件或 URL（托管在受感染的站点上）。 

３、使用 XLL 文件。通常，Emotet 使用包含 VBA 或 XL4 宏的 Microsoft Excel 或 Word 文档。XLL 是一种用于 Excel 的动态链接库 (DLL) 文件，旨在增加应用程序的功能。

值得注意的是，TA542 对不依赖于启用宏的文档的新技术感兴趣，因为微软正在使威胁参与者越来越难以使用宏作为感染媒介。

跟踪 APT29 网络钓鱼活动

攻击目标： 欧洲、美洲和亚洲外交组织

攻击手法： 【钓鱼攻击】

APT29 发送伪装成大使馆管理更新的鱼叉式网络钓鱼电子邮件，这些网络钓鱼电子邮件使用了一个被跟踪为 ROOTSAW 的恶意 HTML 投放器，该投放器利用一种称为HTML 走私的技术将 IMG 或 ISO 文件传送到受害者系统。打开时，ROOTSAW HTML dropper 会将 IMG 或 ISO 文件写入磁盘，该图像文件包含两个附加文件，一个 Windows 快捷方式 (LNK) 文件和一个恶意 DLL。如果用户单击 LNK 文件，“Target”命令将正常执行。这种机制诱使受害者打开 LNK 文件，从而无意中启动了恶意 DLL。DLL执行导致BEATDROP下载器的投递，该下载器在创建暂停线程以将自身注入后在内存中运行，它将枚举系统的用户名、计算机名和 IP 地址并连接到Trello进行C2通信。在成功部署 BEATDROP 以交付和执行有效载荷之后，APT 29通过“Java Update”的注册表项创建持久性，接着 APT29 利用 BOOMMIC 在环境中进一步建立立足点。一旦建立访问权限，APT29 就会迅速升级其在域内的权限。在多种情况下，APT29 能够在初始网络钓鱼负载执行后不到 12 小时内获得域管理员。为了促进横向移动，APT29 依赖于用于模拟特权用户的恶意证书和 SMB BEACON 的组合。

值得注意的是：

1、映像文件中包含的文件（如已安装的 ISO 文件）将不包含 Zone.Identifier Alternate Data Stream (ADS) 标志，该标志指示文件已从 Internet 下载（所谓的“网络标记”），这可以防止从 ISO 或 IMG 图像文件打开的文件出现 Windows 操作系统警告消息。 

2、APT29 使用的一种技术是使用具有与目标应用程序或文档不同的图标的 LNK 文件扩展名，使快捷方式显示为文档而不是要启动的程序。这会诱使受害者打开看似合法的文档。默认情况下，快捷方式文件也隐藏了它们的 LNK 文件扩展名，即使启用了 Windows 资源管理器“显示文件扩展名”，这也进一步降低了打开快捷方式而不是文档的怀疑。

3、APT29 还利用恶意 docx 交付 HTA dropper，从而在一个单独但类似的网络钓鱼活动中在目标系统上交付和执行 BEATDROP。BEATDROP 是一个用 C 语言编写的下载器，创建一个挂起的线程后，BEATDROP 将枚举系统的用户名、计算机名和 IP 地址。

Emotet恶意软件通过PowerShell安装在Windows快捷方式文件中

Emotet 僵尸网络现在使用包含 PowerShell 命令的 Windows 快捷方式文件 (.LNK) 来感染受害者计算机，而不再使用现在默认禁用的 Microsoft Office 宏。.LNK 文件的使用并不新鲜，因为 Emotet 团伙以前将它们与 Visual Basic 脚本 (VBS) 代码结合使用来构建下载有效负载的命令。然而，这是他们第一次使用 Windows 快捷方式直接执行 PowerShell 命令。密切监视 Emotet 活动的 Cryptolaemus 研究小组指出，这项新技术是威胁参与者绕过防御和自动检测的明显尝试。网络安全公司 ESET 的安全研究人员还注意到，在过去 24 小时内，新 Emotet 技术的使用有所增加。ESET 的遥测数据显示，受 Emotet 新技术影响最大的国家是墨西哥、意大利、日本、土耳其和加拿大。

除了在 .LNK 文件中切换到 PowerShell 之外，Emotet 僵尸网络运营商自 11 月将活动恢复到更稳定的水平以来还进行了一些其他更改，例如 迁移到 64 位模块。该恶意软件通常用作其他恶意软件的网关，尤其是像 Conti 这样的勒索软件威胁。

量子勒索软件4小时可完成设备加密

近日，The DFIR Report安全研究人员分析了一款量子勒索软件攻击活动，攻击活动从初始感染到完成加密受害者设备只用了3小时44分钟。量子勒索软件会加密环境中所有主机的文件，然后释放以下勒索信README_TO_DECRYPT.html，勒索信息称数据在攻击活动中被窃取了，如果受害者不支付赎金就公开这些数据。研究人员分析认为攻击活动是通过含有ISO文件附件的钓鱼邮件开始的。量子勒索软件攻击活动使用IcedID恶意软件作为初始的攻击向量。攻击活动会部署Cobalt Strike用于远程访问。初始感染2小时后，攻击者将Cobalt Strike注入C:\Windows\SysWOW64\cmd.exe 进程中来实现检测绕过。然后，攻击者会负责LSASS内存来窃取Windows域凭证信息，以进一步在网络中传播。接下来的1个小时里，攻击者与环境中的其他服务器建立RDP连接。然后通过C$ 共享文件夹的方式复制勒索软件（ttsel.exe）到其他主机的方式来部署勒索软件。最后，攻击者使用WMI和 PsExec来部署量子勒索软件payload——Quantum Locker实现数据窃取和设备加密。

【重要】大数据防疫中个人信息公开与隐私保护的边界浅析

2020年初新冠肺炎疫情在我国爆发后，国内相继启动了一系列的防疫风险应急和防控措施，有效遏制了疫情的蔓延，与此同时在疫情防控的过程中随之出现了许多不容忽视的问题。在新冠肺炎疫情防控过程中，大数据防疫中信息公开的主要内容为“健康码”、“大数据行程码”以及“确诊患者活动轨迹信息”。其中确诊患者的活动轨迹信息主要包括性别、年龄、移动轨迹、社会关系、工作单位等信息。在追踪确诊患者的轨迹排查是否出现接触者时对疫情信息和患者个人信息的处理不当，导致因个人信息泄露对患者产生了不良的社会影响甚至导致确诊患者的“社会性死亡”，那么如何既能有效地控制疫情的蔓延又能保护患者的个人隐私是本文将要讨论的问题。

谷歌强制实施安卓APP隐私保护新政

谷歌将于本周三在安卓（Android）官方应用商店Google Play推出应用隐私政策。用户在下载安装安卓应用时，页面将显示“隐私标签”，让用户一眼就能看到APP收集了哪些个人信息，并决定是否继续安装。当用户在Play商店中查找应用程序时，除了“关于此应用程序”和“评分和评论”等内容条目，将有一个名为“数据隐私和安全”的新条目，开发人员可以在其中解释他们收集了哪些（隐私）数据。值得注意的是，虽然该隐私政策声称用户从本周三开始就能够查看APP所收集的隐私信息，但该政策并不能保证开发人员及时、如实和完全地填写收集了哪些信息。
