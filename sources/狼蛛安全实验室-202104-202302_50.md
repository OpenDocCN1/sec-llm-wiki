**02**

间谍组织Gamaredon继续针对乌克兰的激烈运动

**组织：**疑似Gamaredon(又名Shuckworm/Armageddon，

俄罗斯）

**攻击目标：**乌克兰

**原文概述：**该组织近期活动的标志之一是在目标计算机上部署了多个恶意软件有效负载。这些有效载荷通常是同一恶意软件（Backdoor.Pterodo）的不同变体，旨在执行类似的任务。每个都将与不同的命令和控制 (C&C) 服务器进行通信。这四种不同的 Pterodo 变体都是具有类似功能的 Visual Basic Script (VBS) 释放器。它们将删除一个VBScript文件，使用计划任务（shtasks.exe）来保持持久性，并从 C&C 服务器下载附加代码；所有嵌入的 VBScript 都非常相似；并且都使用了类似的混淆技术。

虽然攻击者在最近几周大量使用了 Pterodo，但也部署了其他工具。其中包括 UltraVNC，一个开源远程管理/远程桌面软件实用程序。研究人员还使用Process Explorer观察到 Shuckworm，这是一种 Microsoft Sysinternals 工具，旨在提供有关哪些句柄和 DLL 进程已打开或加载的信息。

**归因分析：**此次攻击中部署的UltraVNC 之前曾被 Shuckworm 用于多次攻击，且恶意软件变体使用的技术与之前的很相似，因此研究人员将此次攻击归因于Gamaredon组织。

**04**

Lazarus 瞄准化工行业

**组织：**疑似Lazarus（又名APT-C-26，APT38，朝鲜）

**攻击目标：**化工行业以及信息技术（IT）部门

**攻击手法：**【鱼叉式钓鱼攻击】

    受害者收到恶意 HTM 文件，可能是电子邮件中的恶意链接或从 Web 下载的恶意链接。HTM 文件被复制到一个名为 scskapplink.dll 的 DLL 文件中，并注入到合法的系统管理软件 INISAFE Web EX Client 中。接下来，scskapplink.dll 使用 URL 参数键/值“prd\_fld=racket”从命令和控制 (C&C) 服务器下载并执行任意命令，以及其他恶意软件，这些恶意软件通常从添加到 Tukaani 项目 LZMA Utils 库 (XZ Utils) 等木马化工具的恶意导出中执行。攻击者使用 Windows Management Instrumentation (WMI) 在网络上横向移动，并通过 DreamSecurity 在其他机器上注入 MagicLine。在某些情况下，攻击者被发现从注册表中转储凭据，安装 BAT 文件以获取持久性，并使用配置为以特定用户身份运行的计划任务。

    在此次攻击中，攻击者还部署了入侵后工具，包括一种用于以设定的时间间隔截取在受感染机器上查看的网页的工具（SiteShoter）、IP 记录工具（IP Logger）、用于远程打开计算机的协议 （WakeOnLAN）、文件和目录复制器 （FastCopy）以及在 MagicLine 进程下执行的文件传输协议（FTP）。

**原文概述：**AhnLab的ASEC分析团队现已确认受影响公司的INITECH进程 （inisafecrosswebexsvc.exe）产生了恶意行为。  

    首先在受害者系统上检查以下项目是否存在 inisafecrosswebexsvc.exe。确认inisafecross webexsvc.exe文件为正常文件，未被篡改，通过查看进程执行历史和恶意代码SCSKAppLink.dll的代码，发现 SCSKAppLink.dll被注入 inisafecrosswebexsvc.exe，并通过访问https://matric.or.kr/include/main/main\_top\[.\]asp?prd\_fld=racket来下载和执行额外的恶意代码。

    inisafecrosswebexsvc.exe 文件具有以下特征：

    1、它是 INITECH 的安全程序 INISAFE CrossWeb EX V3 的可执行文件。

    2、它具有与普通文件相同的哈希值。(MD5:4541efd1c54b53a3d11532cb885b2202)

    3、它是一个通常由 INITECH 签名的文件。

    4、入侵前系统已安装INISAFE Web EX Client，未发现篡改痕迹。

    5、它由 iniclientsvc\_x64.exe 在系统启动时执行，并在违规当天以相同的方式执行。

**【重要】**研究表明多个应用程序仍然在用户按下静音按钮后监听

    在一项新的研究表明，在流行的视频会议应用程序(VCA)上按静音键可能并不像用户想象的那样管用，因为应用程序仍在监听用户的麦克风。更具体地说，按下静音键并不会阻止音频持续或周期性地传输到应用服务器。作为研究的一部分，研究人员对选定的应用程序进行了全面的运行时二进制分析，以确定每个应用程序收集的数据类型以及这些数据是否构成隐私风险。被选定的应用程序包括 Zoom、Slack、Google Meet、Cisco Webex和Discord等等。研究人员发现，无论静音状态如何，所有应用程序都会偶尔收集音频数据。

**原文链接：**https://wiscprivacy.com/papers/vca\_mute.pdf  

**发布平台：**wiscprivacy

实时语音隐藏算法阻止麦克风间谍活动

      哥伦比亚大学的研究人员开发了一种新算法，可以阻止通过智能手机、语音助手和一般连接设备中的麦克风进行的流氓音频窃听。该算法可以预测性地工作。它会推断用户接下来会说什么，并实时生成阻塞的可听背景噪音（耳语）以覆盖声音。该系统目前仅适用于英语，成功率约为80%。噪音的音量相对较低，最大限度地减少了用户干扰并允许舒适的对话。

**原文链接：**https://arxiv.org/pdf/2112.07076.pdf

**发布平台：**arxiv
