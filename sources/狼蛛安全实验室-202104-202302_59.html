网站：OpenSanctions

该项目收集了不同的名单，例如被列入制裁名单的公司、被政府禁止的人、在通缉名单上的人等等。他们提供 TXT、CSV 和 JSON 格式的数据集。可以用于分析某国被制裁公司的情况以及为何被制裁。


分享者推特：@OSINT_Research

网站链接：https://opensanctions.org/

2

工具：HostSpider

分享了一个新工具，可以收集域名信息。它获取 Whois 信息、抓取子域等，然后生成包含所有相关信息的 HTML 报告。这个工具速度快而且信息量多，较为完整，虽然没有对比其他工具以查看子域列表的完整程度，但通常会使用多个开源工具来进行域名信息搜集。


分享者推特：@cyb_detective

工具链接：https://github.com/h3x0crypt/HostSpider

5、siteliner

功能：Siteliner 是一项免费服务，可让浏览网站，揭示影响您网站质量和搜索引擎排名的关键问题：

重复内容- 重复内容会降低您网站的搜索引擎排名，从而减少您网站的访问量。Siteliner 系统地检查您的网站是否有内部重复内容，在每个页面上突出显示，智能排除菜单和导航等常见内容。

损坏的链接- 损坏的链接会损害您网站的用户体验并降低您网站的搜索引擎排名。Siteliner 检查您网站上的所有内部链接以确保它们正常工作，并突出显示损坏的链接，以便您轻松修复它们。

根据您的页面之间的链接模式，在搜索引擎抓取您的网站时识别对搜索引擎最显眼的页面。

报告- Siteliner 抓取并分析您网站上的页面，揭示每个页面的关键信息。Siteliner 为您的站点提供标准的 XML Sitemap，以及更详细的 Siteliner 报告。

网址：https://www.siteliner.com/
