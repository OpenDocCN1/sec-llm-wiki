工具：Investigator

GitHub 用户“ABHIJITH”创建了一个简单的 HTML 页面，对域名进行了不同的搜索。在顶部填写域名，然后单击下面的众多搜索选项之一以查找子域、IP 地址、证书信息等等。本质是通过点击按钮生成一条google hacking语句进行搜索，方便了我们手动输入要记命令的问题。

  

github链接：https://github.com/abhijithb200/investigator

html页面：https://abhijithb200.github.io/investigator/

技巧：facebook搜索公式

Facebook 搜索矩阵由可用的不同 Facebook 目录、有关 JSON 编码搜索查询的信息以及可供搜索的选项组成。在底部还有一些有用的 Google 搜索。可以很方便的在facebook上搜索想找的人、地点、群组等。

  

原文链接：https://plessas.net/facebookmatrix

twitter分享链接：https://twitter.com/kirbstr/status/1425257151312760832

twitter分享人：@kirbstr

Smat App

社交媒体分析工具包 (SMAT)，可用于调查假新闻或。它提供了对在已知承载假新闻的特定社交媒体网站上讨论的主题的见解。您输入一个搜索词，设置日期范围，选择您感兴趣的平台和信息类型。之后，它会为您提供关于某个主题被讨论的次数、每个用户的活动以及查找与其相关的链接或消息。

工具：Whatsmyname

一个用户名枚举工具，此脚本与大多数工具不同，因为它不仅查询网站，而且在存在搜索的用户名时可以点击前往。在向网站或 API 发出查询之后，可以查看内容。目前已集成300多个网站。

  

工具链接：https://github.com/WebBreacher/WhatsMyName

在线工具网站：https://whatsmyname.app/

分享者推特：@WebBreacher
