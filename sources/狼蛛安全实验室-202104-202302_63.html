疑似来自美国的“顶级”APT组织ProjectSauron

组织：ProjectSauron（美国）

攻击目标：主要为中国和俄罗斯

攻击手法：初始接入：初始感染媒介仍然未知。维持：一旦安装完毕，ProjectSauron的主要模块就会像“休眠细胞”一样开始工作，它们不显示任何活动，并等待进入网络的“唤醒”命令。密码过滤器 DLL：在域控制器上将其持久性模块注册为Windows LSA（本地安全认证）密码过滤器，这样，其被动后门模块在任何网络或本地用户（包括管理员）登录或更改密码时都会启动，并及时以明文形式获取密码。防御规避：使用了一个隐藏的文件系统，该系统作为文件存储在磁盘上；密码过滤器DLL。横向移动：攻击者利用合法的软件分发渠道在受感染的网络内横向移动。发现：使用sinfo工具收集常用的系统信息。信息收集：盗窃文件、键盘记录，以及从受感染的电脑和附加的USB中劫持加密密钥。命令与控制：拥有广泛的网络通信能力，使用最常见的网络协议：ICMP、UDP、TCP、DNS、SMTP和HTTP；将信息编码为BASE64格式；使用具有本地网络和互联网访问权限的本地服务器作为内部代理节点，从没有直接访问互联网的网络其他部分窃取数据。信息渗漏：除了常见的渗漏方法，还使用电子邮件渗漏数据。

归因分析：1.ProjectSauron攻击活动中所有人类撰写的文本均为英文。2."This cruft"的使用。cruft这个词很少被非母语人士使用。3.ProjectSauron的开发人员最初在使用拉丁字符的系统上工作和测试他们的代码。4.大多数ProjectSauron模块包含使用熟练英语的标准嵌入式使用输出。

与土耳其有关的新APT组织EGoManiac

组织：EGoManiac（土耳其，疑似与土耳其警察部门相关）

攻击目标：土耳其国内目标

攻击手法：研究人员发现了一个新的与土耳其有关的组织EGoManiac，该组织是之前披露的Octopus Brain攻击活动的发起者。安全团队Sentine Labs经过深入研究，将Octopus Brain与名为Rad的工具包联系起来，该工具包早在2010年就已开始开发并一直使用到2015年。Rad 是围绕POCO C++跨平台开发库构建的模块化间谍恶意软件工具包。我们发现的所有 Rad 样本都依赖于使用属于 Gmail、Yandex 或 Woxmail（在撰写本文时已失效）的硬编码地址的电子邮件渗漏。Rad 工具包的执行流程很简单。wsms.exe(RadStarter) 是从安装程序设置的注册表项运行的主要模块。反过来，它会将其他模块作为单独的进程运行。每个进程代表不同的功能，包括键盘记录器、热麦克风记录器、浏览器信息提取器、屏幕捕获模块、文件搜索和用于渗漏的通信模块。

归因分析：EGoManiac主要针对土耳其国内目标实施攻击，曾经使用过Hacking Team的RCS工具，疑似与土耳其警察部门相关。从表面上看，EGoManiac 的活动围绕着土耳其关系展开。该恶意软件充斥着土耳其语，诱饵是用土耳其语编写的，受害者是土耳其语并且与当地政治有关。2016年，土耳其网站报道了一项正在进行的起诉土耳其国家警察成员和一家名为“Datalink”的IT公司高管的行动，该公司涉嫌泄露警方活动的信息。据报道，FETO/Gülenist运动的社交媒体账户使用这些泄露的信息来煽动国内正在进行的权力斗争中的阴谋分子。

报告指出，土耳其使用一种名为“HORTUM”(大致翻译为“花园软管”)的间谍软件，从包括安全总局(EGM)情报部门在内的公共机构内受感染的机器中抽取数据。一些报告错误地将HORTUM与黑客小组的RCS混为一谈。这些被窃取的数据被发送到johndown@woxmail.com，然后被Datalink重新分发。HORTUM的功能及其通信方法与EGoManiac的Rad相匹配，包括硬编码的Woxmail地址。

组织：APT-C-36（Blind Eagle，可能位于哥伦比亚）

攻击目标：南美实体

攻击手法：APT-C-36对目标采用了不同的策略，许多欺诈性电子邮件模仿哥伦比亚国家税务和海关局（Dirección de impusestos y Aduanas Nacionales，DIAN），这是攻击者以前使用过的诱饵。这类电子邮件声称“已向银行账户发出扣押令”，电子邮件附件中包含更多详细信息，并且该信息受密码“dian”保护。这些钓鱼邮件中的交付文档是包含链接的PDF文件或DOCX文件。APT-C-36使用URL缩短器，例如cort.as、acortaurl.com和gtly.to。这些URL缩短器能够进行地理定位，因此如果来自威胁行为者未针对的国家/地区的用户点击链接，他们将被重定向到合法网站。如果满足位置条件，用户将被重定向到文件托管服务器并自动下载文件。

归因分析：2019 年，我们写了一篇关于威胁行为者的博客文章，该行为者可能位于哥伦比亚，以垃圾邮件为目标针对哥伦比亚和其他南美国家的实体。该威胁行为者有时被称为 APT-C-36 或 Blind Eagle。从那时起，我们一直在跟踪这个威胁行为者。在此博客条目中，我们分享有关 APT-C-36 在该监控阶段正在进行的垃圾邮件活动的新发现。

Kimsuky使用Metasploit meterpreter的攻击案例

组织：Kimsuky（朝鲜）

攻击目标：/

攻击手法：CobaltStrike和Metasploit都是渗透测试工具，可用于控制受感染的PC和窃取信息。Metasploit也提供了一个负责实际恶意行为的后门，称为Meterpreter。Meterpreter可以像CobaltStrike一样以Staged/Stageless方式创建。

Metasploit的Meterpreter也被Kimsuky小组使用。ASEC分析团队确认，meterpreter在监控metasploit恶意软件的同时运行在rundll32.exe进程中。实际的恶意软件是一个64位DLL，由regsvr32.exe进程加载和执行。之后，随着rundll32.exe的执行和stagershellcode的注入，meterpreter运行在rundll32.exe中，这是一个正常的程序。注入的shellcode从地址79.133.41[.]237:4001下载meterpreter到内存中并执行它。

归因分析：从表面上类似的文件中公开的内容来看，恶意代码的c&c服务器地址都是与Kimsuky集团相关的IP地址。过去的样本目前无法下载计价器，但除了64位DLL形式的DLL或代码的外形特征外，几乎是相同的形式，如在regsvr32.exe上运行正常程序rundll32.exe，并嵌入meta sploit stazer等。他们都使用了米特弗里特的x64 Reverse TCP Stager。

TA551利用BazarLoader进行勒索攻击

组织：TA551

TA551 组织主要利用带有恶意宏文件附件的电子邮件来散布恶意代码。DOC文件本身在允许文档宏删除HTA文件后下载附加恶意代码的操作方法是一样的，改造的重点在于附加下载的恶意代码的类型。ASEC 分析团队继续介绍 TA551 组在攻击中使用的 DOC 宏文档。去年7月介绍的内容和宏文件的操作方法没有变化，但这次确定了宏执行后最后阶段分发BazarLoader的情况。BazarLoader是一种从内存中下载后门并注入正常进程的恶意代码，基于C++语言，主要以x64可执行文件的形式分布。BazarLoader 下载的恶意代码称为“BazarBackdoor”，该后门收集用户PC 信息和企业环境信息，并执行下载器为公司下载其他恶意代码的功能。作为海外感染案例，安装了“Cobalt Strike”以收集横向移动和附加信息，最后安装“Ryuk Ransomware”或“Conti Ransomware”向公司索要钱财。BazarLoader 和 BazarBackdoor 使用名为 *.bazar 的 C2 域命名为“Bazar”。

TeamTNT组织的新工具针对多个操作系统

组织：TeamTNT

攻击目标：针对各种操作系统，包括：Windows、不同的 Linux 发行版，包括 Alpine（用于容器）、AWS、Docker 和 Kubernetes

攻击手法：自 2020 年年中以来，TeamTNT 一直是最活跃的威胁组织之一。他们的活动通常使用开源工具进行恶意活动。部分导入工具列表包含：Masscan 和端口扫描程序以搜索新的感染候选者；libprocesshider 用于直接从内存中执行他们的机器人；7z 解压下载的文件；b374k shell 是一个 php web 管理员，可用于控制受感染的系统；

Lazagne，一种适用于多种 Web 操作系统的开源工具，用于从众多应用程序中收集存储的凭据。2021 年 7 月，TeamTNT 开始使用新工具运行 Chimaera 活动，并首次在其网站上公开发布感染统计数据

归因分析：AT&T Alien Labs 发现了由威胁参与者 TeamTNT 分发的新恶意文件。正如研究人员在较早的活动中观察到的 TeamTNT，他们专注于窃取云系统凭据、使用受感染的系统进行加密货币挖掘，以及滥用受害者的机器来搜索并传播到其他易受攻击的系统。使用像 Lazagne 这样的开源工具可以让 TeamTNT 在一段时间内保持低调，让反病毒公司更难发现。

研究人员发现新型Android银行木马SOVA

2021年8月初，ThreatFabric研究人员发现了一个新的Android银行木马。根据C2服务器的登录面板，可以看到它被攻击者称为S.O.V.A.。该木马目前处于开发和测试阶段，其目标是在其覆盖和键盘记录机制中添加其他高度危险的功能，如DDoS和勒索软件。S.O.V.A.包含当前Android恶意软件中通常可用的功能，包括：覆盖攻击、键盘记录、通知操纵。此外，它还有一个在Android恶意软件中并不常见的功能：窃取会话cookie。此功能允许犯罪分子访问用户的有效登录会话，而无需知道银行凭据。
