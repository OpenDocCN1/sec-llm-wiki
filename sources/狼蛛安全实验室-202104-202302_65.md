**01**

FIN7黑客利用Windows 11主题文档传播后门

**组织：**FIN7（俄罗斯）

**攻击目标：**美国的销售点 (PoS) 服务提供商

**攻击手法：**利用带有 Visual Basic 宏的武器化 Windows 11 Alpha 主题 Word 文档投放恶意负载，包括 JavaScript 植入程序。感染始于 Microsoft Word 恶意文档，其中包含据称“在 Windows 11 Alpha 上制作”的诱饵图像。该图像敦促接收者启用宏以触发下一阶段的活动，这涉及执行高度混淆的 VBA 宏以检索 JavaScript 有效负载。除了采取几个步骤通过用垃圾数据填充代码来阻止分析之外，VB 脚本还会检查它是否在 VirtualBox 和 VMWare 等虚拟化环境下运行，如果是，除了停止感染链外，还会在检测到俄语、乌克兰语或其他几种东欧语言时自行终止。

**归因分析：**对 FIN7 的归因源于威胁行为者采用的受害者学和技术的重叠，包括使用基于 JavaScript 的有效载荷来掠夺有价值的信息，有效负载被发现与 FIN7 使用的其他后门共享类似的功能。

**02**

三边行动：针对南亚、中东多国长达数年的网络间谍活动

**组织：**透明部落（TransparentTribe，巴基斯坦）

**攻击目标：**攻击地域覆盖伊朗、阿富汗、印度和巴基斯坦国家，涉及人权活动家、运输部门、军事、退役军人、极端信仰者和政府部门等

**攻击手法：**涉及 Windows 平台和 Android 平台，Windows 平台使用多种类型恶意样本进行钓鱼和水坑攻击，在木马后门的使用上以开源木马 QuasarRAT 和命名为 PrisrolRAT 的 Delphi 特马为主，Android 平台上样本使用的都是开源 AndroRat 木马，手法则是通过伪造正常的 Android 软件下载商店，诱导受害者目标下载运行。

**归因分析：**关联发现，此次攻击活动背后组织的历史间谍活动至少可以追溯到2013年，早期针对印度地区进行攻击，在2017年"恰巴哈尔港协议"签订三方-印度、阿富汗、伊朗正式开展贸易往来后，伊朗、阿富汗以及伊朗和巴基斯坦交界-俾路支斯坦地区也被纳入攻击范围，主要涉及人权活动家、运输部门、军事、退役军人、极端信仰者和政府部门等多个领域。通过溯源分析，发现近期捕获的移动端后门配置信息，与透明部落(TransparentTribe)组织近期使用的后门具有相同配置，这意味着两个组织或许存在一定的关联，此次攻击活动目的性较强，带有国家战略性目的，疑似具有国家背景支持的 APT 攻击组织所为。

Lnk文件使用了的伪装后缀包括txt、pdf、docx等，运行后打开谷歌云盘的诱饵文件或自释放诱饵文件，并同时加载具有后门功能的恶意js代码，将恶意Lnk文件写入到%startup%文件夹中。

**归因分析：**此次攻击活动与Lazarus组织样本存在高度相似性。该样本与此前的Lazarus组织使用的Jscript代码MD5：9d555c1093ff84ac3d442b1a0617f7ef存在一致性。

**04**

疑似双尾蝎APT组织近期针对巴勒斯坦地区的攻击活动分析

**组织：**双尾蝎（APT-C-23）

**攻击目标：**中东地区

**攻击手法：**伪装成政治热点、教育相关的可执行文件诱饵，以及伪装成微软图像处理设备控制面板程序(ImagingDevices.exe)，此类样本运行后，将会释放展示正常的诱饵以迷惑受害者，同时后门将继续在后台运行以窃取受害者计算机敏感信息。

**归因分析：**此次捕获的攻击样本与双尾蝎APT组织常用攻击手法，恶意代码基本一致。其中Delphi 语言编写的样本较以往样本无较大变化，而VC版本则增加了新的持久化方式，以及丰富了指令内容。

经关联分析，我们从样本库中关联出一些与VC版本后门代码几乎一致的样本，释放的诱饵以及C2均为同一个。以及发现一例与以往捕获Delphi版本后门样本相似的样本，释放与教育相关的诱饵文档。
