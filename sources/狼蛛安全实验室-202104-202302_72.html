Lorec53组织针对乌克兰边防局和国防部的攻击活动分析

组织：Lorec53（俄罗斯具有一定民族主义特点的民间黑客组织，可能是前苏联政治拥护者）

攻击目标：乌克兰边防局和国防部

攻击手法：攻击的初始阶段主要通过钓鱼邮件实施入侵，攻击者以“COVID-19Vaccine”、“向 ATO 退伍军人付款”、“紧急更新！！！”、“乌克兰总统令 №186_2021”等具有高度迷惑性的内容作为邮件标题诱使受害者相信钓鱼邮件的内容。钓鱼邮件中附带含有恶意快捷方式的压缩包，当受害者点击压缩包内的恶意快捷方式时，恶意快捷方式便会从黑客服务器上下载恶意木马从而展开后续的攻击。一旦受害者相信邮件内容并执行黑客精心布置的恶意木马，受害者电脑上的机密文件将会被黑客窃取。特别要警惕的是,该组织也曾经攻入了位于中国的企业服务器并将其作为恶意代码存储点，比如黑客组织曾在3月份利用上海某机电设备有限公司的官网（shca****.com）服务器作为其木马的存储服务器，以此作为其攻击活动中的一环来投递木马。

归因分析：该组织使用的木马和攻击目标十分符合俄罗斯黑客组织的习惯。如其使用的Smoke Loader木马、Raccoon木马极为频繁地出现在俄罗斯黑客论坛里并进行大肆出售。但我们难以将其归属到目前所发现的俄罗斯黑客组织，虽然黑客组织目前的攻击活动带有明显的政治意图。由于该黑客组织并没有一款自己高度定制化的攻击武器，且习惯于从黑市中购买攻击木马，而且攻击所使用基础设施也缺少隐私保护和隐秘保护措施，因此我们认为该黑客组织是一个具有一定民族主义特点的民间黑客组织。来自其他实验室的研究人员根据其攻击组件中的特征信息，将该组织命名为Lorec53。

利用俄乌克里米亚冲突为诱饵的钓鱼攻击活动分析

组织：疑似反对普京在克里米亚半岛上的政策的团体

攻击目标：俄罗斯和亲俄罗斯个人

攻击手法：2021年7月21日，Malwarebytes的安全研究人员发现了一种新型的文档攻击手法。原始的文档文件执行后会尝试注入两个远程模板，其中第一个远程模板的为宏代码利用文档，第二个模板包含了CVE-2021-26411的漏洞利用代码，这是一个IE浏览器漏洞。两个模板最终都会加载同一个VBA RAT，且远程模板加载后，恶意文档会展示一个俄语编写的诱饵文档，该文档的主要内容是克里米亚针对俄罗斯政策的反对声明。

最终加载的VBA RAT包含了完整的远控功能，它可以收集本地的基本信息并上传到C2，可收集的信息包括UUID、操作系统版本、系统架构、CUP信息、内存容量、硬盘空间、计算机名、用户名、域名、管理员标志、手感染计算机上的杀软信息等。同时，该RAT还可以远程执行shell、删除用户文件、上传和下载文件、读取磁盘和文件系统信息。

归因分析：我们无法仅根据技术来确定谁可能是这次攻击的幕后黑手，但向受害者展示的诱饵文件可能会提供一些线索。它包含来自一个与安德烈·谢尔盖耶维奇·波蒂科有联系并反对普京在克里米亚半岛上的政策的团体的声明。随着俄罗斯和乌克兰之间围绕克里米亚的冲突继续，网络攻击也在增加。诱饵文件包含一份宣言，显示了这次袭击背后的可能动机（克里米亚）和目标（俄罗斯和亲俄罗斯个人）。但是，它也可能被用作虚假标志。

思科修复VPN路由器中的严重漏洞

思科于近日在新发布的软件版本中修复了影响多个小型企业 VPN 路由器的认证前安全漏洞 CVE-2021-1609 和 CVE-2021-1602，这两个漏洞允许远程攻击者触发拒绝服务或在脆弱设备上执行命令和任意代码，且无需身份认证就可以远程利用漏洞。CVE-2021-1609(CVSS 9.8)是由于HTTP请求验证不当造成的漏洞，CVE-2021-1602(CVSS 8.2)是由用户输入验证不足造成漏洞的，这两个安全漏洞均存在于 web 管理界面。CVE-2021-1609 漏洞影响 RV340、RV340W、RV345 和 RV345P 双 WAN 千兆 VPN 路由器，CVE-2021-1602 漏洞影响 RV160、RV160W、RV260、RV260P 和 RV260W VPN 路由器。攻击者可以通过向受影响路由器的 Web 的管理界面发送恶意制作的 HTTP 请求来利用这些漏洞。这些漏洞并不互相依赖，受一个漏洞影响的版本可能不受另一个漏洞的影响。思科已于8月4日发布软件更新来解决这些漏洞。

研究人员虽然没有观察到这些针对关键基础设施攻击的初始感染媒介，但对其攻击深入分析后发现攻击者主要目标为在关键机基础设施内部进行凭证窃取和横向移动，且广泛的使用ProcDump、PAExec、Mimikatz 等凭证转储工具。由于这些攻击活动的目标地理位置和部门的相似、不同目标组织几乎都存在下载器和键盘记录器以及使用的相同 IP 地址等迹象表明这些针对多个东南亚基础设施的攻击活动背后是同一个攻击者。
