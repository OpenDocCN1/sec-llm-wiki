# 全方位绕过安全狗2

### 前言

之前写过一篇绕过安全狗的文章后有表哥找我问了一些问题，我发现bypass可能是现在安全表哥们必不可少的一项技能了。

安服过程中也常常能遇到安全狗,在不允许深挖的情况下只要能证明漏洞存在就算交差了，于是就有了今天这样一篇从头到尾绕过安全狗的文章。文章技术点不多，全当给各位表哥做个参考吧。

### Docker搭建安全狗环境

win服务器的安全狗版本没有变化,去官网下了新版的安装包也没变化,就搭建linux版本的吧。

```
docker run -it  -d --name mysql\_dev -p 3307:3306 -e MYSQL\_ROOT\_PASSWORD\=root mysql:5.6 --character-set-server\=utf8mb4 --collation-server\=
utf8mb4\_unicode\_ci\# mysql

80:80 --link mysql\_dev  -v $(pwd)
:/var/www/html centos:7 /bin/bash\# 其实我一直都是用ubuntu的 只是安全狗的环境在ubuntu上起不来 只好换centos啦

#lamp环境

```

随后就是下载安全狗啦，docker使用的是64位，注意位数

下载解压 执行`./install.py`

这里出现错误，你只要按错误日志安装对应的包就好了。

![](../Images/10265ab31700ea5f38dd508cab719dd4.png)

  

执行`yum -y install file mlocate`随后继续`./install.py`  

![](../Images/22f3e1114433f833daea8b14041ab5a6.png)

  

这样安全狗就起来了,在web目录下写一个测试文件

```



cat >/var/www/html/index.php<<EOF
```

访问http://127.0.0.1/?0=readfile&1=file:///etc/passwd 被咬了就对了

![](../Images/8ed5d119ab669e145a1902589d20e92b.png)

### 文件读取
