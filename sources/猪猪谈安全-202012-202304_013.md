# 记一次杀猪盘的渗透之旅

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMDAwMjkzNg==&mid=2247508678&idx=1&sn=4116e8be57e43247e334fca02d4e4af9&chksm=97d04dd1a0a7c4c729bed2a81aae888c7f6e3c18d851e3cc05f671be4093f9b9c350011fbd25&scene=126&sessionid=1681667676#rd](http://mp.weixin.qq.com/s?__biz=MzIyMDAwMjkzNg==&mid=2247508678&idx=1&sn=4116e8be57e43247e334fca02d4e4af9&chksm=97d04dd1a0a7c4c729bed2a81aae888c7f6e3c18d851e3cc05f671be4093f9b9c350011fbd25&scene=126&sessionid=1681667676#rd)

所谓“杀猪盘”，是指诈骗分子利用网络交友通常是“异性”交友，诱导受害人下载诈骗APP并在上面进行各种“投资”，如菠菜、股票、期货甚至虚拟货币的网络诈骗。今年某月某日`小白`就遭遇了这种骗局，他先是被骗子通过QQ添加并下载了一个名为”心动“的APP，在“心动“APP上结识了位名为“xx老师”的美女，`小白`被美色迷了眼打算相约这名网友，但是美女则借口让他下载另一个名为午夜乐园的APP进行投资，果不其然`小白`被成功骗取10余万。

## 0x01 APP测试准备

根据`小白`的描述，我们关注到以下几点信息，分别是 QQ、“心动”APP以及“午夜乐园”APP，但是`小白`因不堪被骗将骗子QQ删除了。所以我们无法从QQ号这点进行入手，但是这两个APP的APK包倒是存在，于是开始渗透分析。

### 安装APP

使用夜神模拟器安装这两个APP，为了方便起见就使用安卓5.0版本，否则无法抓取到 https 数据包

> 小知识：从 Android 7.0 开始，默认的网络安全性配置修改，默认不再信任用户添加的 CA 证书，也就不再信任抓包工具的证书

![](../Images/50b36bf9bd71894771abaf9d23e22724.png)  
因为“午夜乐园”APP需要邀请码才能注册，所以我们先安装“心动”APP  
![](../Images/0bf08d1d6f20dfbce802f3f2fe6ea66c.png)

### 设置抓包

在 BurpSuite 中设置监听地址以及监听端口，其中地址为内网的IP地址  
![](../Images/bbbf98c285387184820db35bca66b461.png)  
设置网络中的 HTTP 代理为 BurpSuite 中的代理地址和端口  
![](../Images/644c23349a16b64582374c8892460057.png)  
访问百度，在 Burp Suite 中成功抓取到数据包  
![](../Images/c58ac19486b36be3dd7956e98768dddc.png)  
现在针对 http 协议的数据包都可以抓取到了

### 安装证书

接下来为了抓取到 https 的数据包，我们需要为其安装 CA 证书  
![](../Images/4b9c19782cf501a52d789863b7ad6011.png)  
访问`https://burp`点击`CA`开始下载证书，下载完成后在`设置`中找到`安全`  
![](../Images/23da13af96ba53123e691f2c0ea56dbf.png)  
选择`从SD卡安装`  
![](../Images/818a50041ccd324fdd89b53266704448.png)  
选择之前下载的证书并为证书命名  
![](../Images/58ca5c32450b1eec6723499098e422f5.png)  
在`用户凭据`中已存在证书  
![](../Images/881f08ed19640704215a15dfd22bda41.png)  
访问`https://www.baidu.com`  
![](../Images/f0b5b50146a0424fced9454ec72ec618.png)  
在 Burp Suite 中成功抓取到 https 数据包  
![](../Images/51e24868644eb802db858b188ebbd798.png)

### IP地址查询

通过简单的sql语句对 admin 登录日志进行查询

```

select distinct ip from yl_admin_log limit 50
```

![](../Images/7e1104db364570fc8c546e024e308301.png)
