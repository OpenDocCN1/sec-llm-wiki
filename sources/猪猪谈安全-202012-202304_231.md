# 特征

*   支持 URL 列表。
    
*   对 10 多个新的 Spring4Shell 有效负载进行模糊测试（以前看到的工具仅使用 1-2 个变体）。
    
*   对 HTTP GET 和 POST 方法进行模糊测试。
    
*   发现漏洞后自动验证漏洞。
    
*   随机和非侵入式有效载荷。
    
*   WAF 绕过有效负载。
