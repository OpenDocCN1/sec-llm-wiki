### 前言

闲着金币在edusrc里面，刚好某学校上架了新礼物，就有了这次的渗透,此文章中所有漏洞均已提交至edusrc并已经修复。

### 0x1信息泄露

在url后面随便输入字符,页面报错得到框架为ThinkPHP3

![](../Images/3f744605fb29f1c5251dc37cf73c5606.png)

然后我们尝试访问默认日志路径

```
Application/Runtime/Logs/控制器/年份_月份_日期.log
```

访问成功,不过每隔几分钟日志就会被自动删除

![](../Images/fe76098fe45cee87ea333885180afb87.png)

### 0x2由日志泄露导致的任意用户注册

用户注册的地方,一定要使用该校的邮箱@xxxxxxxxx.edu.cn进行注册

![](../Images/10e1d38665d9fc67fe90237b1a504276.png)

我们通过GitHub搜索 该校域名+邮箱关键字，成功找到一个可以登入的邮箱

![](../Images/e8b8e054ac94ccb3e2f1e40c4911eb87.png)

然后登入

![](../Images/2d507220f7272c62bf3c731a768826fe.png)

利用得到的邮箱进行注册，查看激活邮件URL构造

```
http://xxxxxxxxx.edu.cn/index.php/activation?accessToken=f6d785fb9470d5fd604fb8897778f740
```

![](../Images/4798d7e52e3fdef3ae66a3f5ff6e5d02.png)

accessToken我们可以通过日志去查看,然后即可构造激活链接实现任意用户注册

edusrclalala@xxxxxxxx.edu.cn

![](../Images/7e79170bfb65e95f01f9c6c716dbfe7b.png)

查看日志得到accessToken

![](../Images/408512ee316de0b619b20fddac7f756b.png)

构造激活链接，访问成功激活

![](../Images/a649ee388d758d73179d35eba6f29072.png)
