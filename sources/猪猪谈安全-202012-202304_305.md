### **ZIPZIP**

  

根据题目描述猜测可能存在 zip 解压的操作，于是可以使用软连接写后门

  

首先生成一个指向 /var/www/html 的软连接文件

ln -s /var/www/html  test

对该文件进行zip压缩

zip --symlinks test.zip ./\*

上传之后，就会自动解压出test链接，并指向服务器的 /var/www/html

这样再解压 test 目录下的文件时就会被解压到 /var/www/html 目录

### **Press**

文件主要流程是打开flag文件，然后进行运算，输出到out文件，out文件的内容是

```


0x60, 0xE1, 0x2F, 0x05, 0x79, 0x80, 0x5E, 0xE1, 0xC5, 0x57, 
```

dword\_6020A0查看交叉引用，得到了密文

```
++++++++++\[->++++++++++++++++<\],\[->-<\]>>\[-\]+++++<\*++.<
```

直接开始调试，文件中的内容会存到byte\_6026A0里

![](../Images/48d3e07618f971f6a85e525268cadd36.png)

s就是那个+-的内容，通过调试，他的核心函数就是这个

sub\_40094B函数是最主要的函数，他在循环到.的时候，会把生成的byte\_6021A0的值附给最后的数组

在遇到，的时候，把flag文件的值附给byte\_6021A0数组，然后开始循环

这个类似于第五空间的brainfuck，把brainfuck对应的操作流程翻译过来，就可以了

![](../Images/9b3140b2dbc5c8d46891bf46feff44f6.png)
