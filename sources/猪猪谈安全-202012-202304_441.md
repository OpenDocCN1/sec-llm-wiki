# 0x00前言

最近是大事没有,小事不断,被调遣到客户单位做HW蓝方,没啥意思，整天盯着防护设备等待告警，正好一王者大佬最近在挖EduSrc，让帮着搞一搞，在50星荣耀王者的诱惑下，我准备开启我的EduSrc之旅。

# 0x01 年轻人不讲武德

通过对某个大学的C段扫描，扫到了一个学生管理系统

![](../Images/4f8668a115ab8db0a156993351c5ea77.png)

简单测试了一下，发现抓包验证码不刷新，而且会提示“用户名不存在”，这里就可以进行账号密码的爆破。

![](../Images/d6a9dc8eef821dfa98a27cc6e8857e98.png)

很显然，我的百万大字典不配爆破，这网站不讲武德，放弃爆破。

![](../Images/ed91b7b4c950a35d2d63823cc420d975.png)

# 0x02 偷袭

通过目录扫描，扫描到未授权页面

http://mabaoguo /admin/manage.asp

![](../Images/0f5e7c3ec5ffe822113e67ec1d1b4178.png)

 

![](../Images/d6a9dc8eef821dfa98a27cc6e8857e98.png)

此未授权页面包含所有的用户ID值，怪不得我的字典没爆破出来，原来账号全是中文汉字，好家伙，以为我不会爆破了吗，反手就是一个偷袭爆破

![](../Images/654d466b09ce01b1aceb2906e114408b.png)

爬取所有id值进行爆破，爆破到大量弱口令，密码均为123456，但是用户都为普通用户。

利用爆破的账户进行登录

![](../Images/8bbab8a20ddb76b5177dcfca98f003a6.png)

发现网站存在两处上传点

![](../Images/293ad786068db3472b77ffa8fdd1a6a2.png)

此处上传为资源分享，因为账号权限问题，此账号不可以上传。

 

另一处上传点为导入数据的功能，只能上传execel文件

![](../Images/6c2f2cf86727f48e0b40fd3de3fc65be.png)

 

# 0x03 接化发 这次我没大意 成功拿下

![](../Images/6aa00570462be266bcc93e0e4076bb76.png)

抓包测试上传

![](../Images/983b448f5e136eef7d48a7277ed67c34.png)

 

上传的文件没有路径回显，此时测试一下是否进行了重命名，再次上传相同文件名文件

![](../Images/b2dca9543731b2bc40c95292a5301fa6.png)

发现文件名变了，说明上传的文件没有进行重命名，下一步测试上传文件的路径，经过fuzz了多个目录，都没有找到文件位置。

![](../Images/d2f1d9942bd126e8753cffd3a603b3c6.png)

再回到上传包，尝试能否跳目录进行上传

![](../Images/125ae5270ef35a10cc12ab54ee3b8ad7.png)

文件名前面加../上传，发现上传成功的文件名又变为了6666.xls

说明上传的文件跳目录了

最后测试发现../../就到网站根目录了

![](../Images/99f2c86849ca8d58efc07bd3414c0497.png)

 

![](../Images/4bc81dd773a917a4574ca7bff7e006e7.png)

找到文件位置后，开始测试上传后缀

![](../Images/e6bd11df34fb5cd53321b2d04a8c16af.png)

![](../Images/87c4cf945f6584ad6a116d600befe769.png)

 

经过多次测试发现为上传白名单，尝试多种方法，最后利用00截断成功getshell
