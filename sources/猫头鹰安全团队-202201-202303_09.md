   前几天在公众号发了文，反响还不错。 谢谢大佬们支持。今天我们框架又迎来新的版本更新。时间问题，本文写简单一些。  

  

更新信息：

*       修复了命令行，空命令仍然执行上一条有效命令问题。  
    
*       修复了Windows平台运行编译问题。
    
*       优化了Spiriter功能问题，并且支持shellcode加载。
    
*       添加了CMAKE NASM构造编译环境模块。
    
*       修复了SpiritCore.Spirit里面的load\_modules函数 异常处理问题。
    
*       添加了search命令 以描述信息与模块名为标准搜索
    
*       添加了exit命令 与退出问题。
    

  

 我们最主要是对Spiriter进行全面更新，通过srdi与spiriter dll payload 配合加载shellcode。  其技术是通过反射注入dll方式进行加载。

**命令：**  

back 返回命令

exploit 运行模块Exploit函数

generate 生成后门文件

help 帮助信息 （没有写全 只要banner）

info 模块信息

session 后门会话信息

set 修改参数

show 查看参数

use 使用模块

  

**用法与配置**

用法与MSF基本一样。

SpiritCore目录下Config为配置文件，里面存放FOFA等配置，但是xray已经做到自动定位，不用填写。

###安装与运行 支持环境：Windows Linux

（建议使用Linux，因为Windows测试并不完善） 运行环境：建议使用Python3（可以使用Python2，但不建议）

安装依赖：impacket 、mingw-w64、 cmake、nasm
