**0x01****简介**

Apache Struts 2最初被称为WebWork 2，它是一个简洁的、可扩展的框架，可用于创建企业级Java web应用程序。它利用并延伸了Java Servlet API，鼓励开发者采用MVC架构。设计这个框架是为了从构建、部署、到应用程序维护方面来简化整个开发周期。

  

**0x02****漏洞描述**

Apache Struts可能允许远程恶意用户在系统上执行任意代码，这是由对标签属性中原始用户输入的强制双重OGNL评估引起的。通过发送特制数据，攻击者可以利用此漏洞在系统上执行任意代码。

 

影响范围：

Apache Struts 2.0.0-2.5.25
