0x01简介

Nexus是Maven仓库管理器，也可以叫Maven的私服。Nexus是一个强大的Maven仓库管理器，它极大地简化了自己内部仓库的维护和外部仓库的访问。利用Nexus你可以只在一个地方就能够完全控制访问和部署在你所维护仓库中的每个Artifact。Nexus是一套“开箱即用”的系统不需要数据库，它使用文件系统加Lucene来组织数据。


0x02漏洞描述

该漏洞存在部署权限默认账号，成功登录后可使用“createrepo”或“mergerepo”自定义配置，触发远程命令执行漏洞。

 

影响版本

Nexus Repository Manager OSS <= 2.14.13

Nexus Repository Manager Pro <= 2.14.13

限制：admin权限才可触发漏洞


0x03环境搭建

作为一个人菜瘾大还懒的我，当场开启docker

docker pull sonatype/nexus:2.14.13

docker run -d -p 8081:8081 --name nexussonatype/nexus:2.14.13

docker exec -it 12604662a723 /bin/bash

cd bin

./nexus start 但是好像不用开启，已经开启了。。。

直接访问8081会显示404，手动输入nexus访问


0x04漏洞复现

管理员admin/admin123登录

然后找到漏洞位置：Capabilities - Yum:Configuration –Settings

点击 Save 抓包，更改mergerepoPath后的value值

Payload

Win：C:\\Windows\\System32\\cmd.exe/k dir&

Linux：/bin/bash -cls -al /createrepo

如果是root部署，作用更大。可惜我偷懒了，nexus的权限。


0x05修复建议

1、  修改弱密码

2、  升级至最新版本
