0x00简介

FusionAuth是一个免费的身份管理平台，安装简单，易于集成。FusionAuth提供登录、注册、MFA、SSO、电子邮件模板、本地化、密码控制、强哈希、网络挂钩、基于角色的访问控制等功能。


0x01漏洞描述

在FusionAuth 1.11.0版本之前的中发现了一个问题。经过身份验证的用户被允许编辑电子邮件模板（主页->设置->电子邮件模板）或主题（主页->设置->主题），可利用freemarker.template.utility.Execute执行任意命令。在处理自定义模板的Apache FreeMarker引擎中。


影响版本：FusionAuth  <= 1.10.0

按需要安装好数据库，安装Postgresql

sudo apt-get upgrade

sudo apt-get install postgresqlpostgresql-client

设置用户名和密码 postgres postgres

sudo -upostgres psql

\passwordpostgres

点击submit，然后提示安装Elasticsearch

安装Elasticsearch7.2.1以上内置java

https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-7.10.2-linux-x86_64.tar.gz
