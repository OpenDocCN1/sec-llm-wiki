# **Cryptopia被盗调查进程更新 被盗原因及客户资产偿还事宜仍无大进展**

新西兰加密交易所Cryptopia发布公告更新被盗事件调查及客户资产赔偿进程。公告显示，Cryptopia仍就确定客户所持股份的法律地位、被盗事件原因调查及客户资产赔偿事宜寻求新西兰法律指导；但其被盗原因及客户资产偿还事宜仍无大进展。Cryptopia将与客户和解进程将分为三个主要阶段：保护资产和公司数据、钱包环境和客户调节以及确定用户和归还。但“确定用户和归还资产”阶段目前尚处于初期阶段。Cryptopia表示，目前仍在进行客户资产持有量的确定，且还需要一定时间才能完成。同时，Cryptopia称其已出售相关厂房和拍卖相关设备，但就被盗资产赔偿仍需得到新西兰法院的指示，以及满足法律要求和义务及反洗钱、了解客户(AML/KYC)要求。而关于被盗资产调查，Cryptopia将继续与新西兰警方和国际当局合作，确定2019年2019年1月黑客攻击来源，但不会将调查攻击根本原因作为目标，相反，Cryptopia的职责在于维护利益相关者的利益以及追讨损失。对此，目前Cryptopia表示已进行相关工作，追查和冻结被盗资产。此外，Cryptopia将于12月初提交下一份报告更新。此前2019年1月13日至14日，Cryptopia遭受黑客攻击，被盗28773枚ETH。1月30日，该交易所再次出现安全漏洞，被盗1675枚ETH。  

# **sodinokibi勒索病毒大量攻击中韩企业，中招用户被勒索0.15个比特币**

腾讯御见威胁情报中心今日发文称，近期腾讯安全御见威胁情报中心检测到大量借助钓鱼邮件传播的sodinokibi勒索病毒攻击中韩两国企业。在一天之内攻击者使用伪造的近1000个邮箱地址针对国内目标发送超过5万封钓鱼邮件。中招用户被勒索0.15个比特币（市值7800元人民币），中招企业主要集中在广东、山东、江苏、上海、北京等地，主要受害企业包括IT公司、科研和技术服务机构，以及传统制造企业。钓鱼邮件伪装成以“偿还债务”、“支付汇款建议”为主题，并在附件中添加包含勒索病毒的压缩文件，中文版为“您的账号.zip”、韩文版为“송장 10.2019.zip”，解压后分别为“付款发票.xls.exe”、“10 월 송장.xls.exe”，都是伪装成表格文件的sodinokibi勒索病毒。从钓鱼邮件内容格式、主题和投递的样本类型来看，此次针对中国和韩国的攻击为同一来源。  

# **荷兰国际集团提出Corda区块链的安全和隐私权衡方案**

据Cointelegraph消息，荷兰国际集团发布了一份名为《Corda安全和隐私权衡的解决方案:吃蛋糕还是吃蛋糕》的白皮书，并宣布该公司已经解决了区块链软件公司R3旗下Corda区块链的安全和隐私问题。白皮书指出，目前，Corda区块链上的每一笔交易的内容都要经过公证才能达成一致。荷兰国际集团的解决方案引入了零知识证明(ZKP)公证服务来验证交易，据称该服务可以在不损害安全性和不泄露任何私人内容的情况下评估交易的有效性。  

# **微软与OpenZeppelin合作推出审计智能合约库**

据AMBcrypto消息，最近，区块链安全审计和开源开发工具提供商OpenZeppelin宣布将启动OpenZeppelin审计智能合约库。此次发布是与跨国技术公司微软合作，作为其Azure区块链开发套件的VSCode插件的一部分。根据该版本，它将使使用Microsoft VSCode的智能合约开发人员能够从OpenZeppelin的合约库中安全地将合约添加到他们的代码库中，该库拥有超过100万次下载和200个贡献者。除了能够基于类别下载合约和库之外，它还具有在导入和部署OpenZeppelin合约时为每个导入的合约创建迁移文件以及针对原始GitHub存储库的哈希进行验证检查的功能。此外，合约将作为只读导入，以防止意外编辑而损害审核代码的安全性。  

# **挖Monero币的加密蠕虫Graboid目前已感染2000多台不安全的Docker引擎**

据freebuf报道，研究人员称，Graboid加密蠕虫旨在挖Monero币，到目前为止，已经感染了2000多台不安全的Docker引擎（社区版）主机，这些主机正在清理中。最初的恶意Docker镜像已被下载了10,000次以上，蠕虫自身已被下载了6500多次。管理员可以通过镜像创建历史记录，查找名为“ gakeaws / nginx”的镜像来发现感染。攻击者通过不安全的Docker daemons获得了最初的立足点，该daemons首先安装了Docker镜像以在受感染的主机上运行。另外，攻击者无需任何身份验证或授权，即可完全控制Docker 引擎和主机。攻击者利用此入口点来部署和传播挖矿木马。  

# **McAfee安全实验室发布对比特币勒索软件Sodinokibi的分析文章**

McAfee Advanced Threat Research（ATR）官方网站，近日发布对Sodinokibi及其与GandGrab之间联系的系列分析文章最后部分。在本系列最后一篇文章，安全研究人员描述了传播Sodinokibi勒索软件的不同会员组织使用的操作、技术和工具。比特币勒索软件Sodinokibi 是2018年和2019年中期影响最严重的勒索软件之一。
