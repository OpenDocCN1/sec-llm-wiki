# 都说六月骄阳似火，在这个六月。小编先给各位hw的大佬们道声辛苦啦。hw任务艰巨，但是身体第一哟~

![](../Images/f6cc900b8832b59fcbd625d6dd6ca32c.png)

  

在这个六月，区块链安全生态BUGX也举办了一次有意义的活动：第二期Hack The Exchanges 活动，相较第一期，本次活动活加大了奖励力度。满满的福利是对守护区块链生态安全的战士最好的嘉奖。

  

下面来看看本次的奖励~

  

![](../Images/6c929aa954091f88319ca6e4b9d7c7f4.png)

 

每一份努力都值得嘉奖，每一个漏洞都值得重视。每一行每一业安全的建设都是从漏洞的挖掘、漏洞造成的影响与危害开始逐步重视起来的。白帽们的每一次挖掘都是为安全生态的建设添砖加瓦。BUGX对白帽们再次表达感谢！

  

最后，没有挖到有效漏洞的小伙伴也不要泄气，继续关注bugx.io 下一个活动，在等着你！
