## **概述**  

  

在区块链世界中，一切的操作都是基于交易，bob给alice转账即发起了一笔交易，bob调用alice部署的合约也是发起了一笔交易...交易在以太坊中无处不在，下面将以以太坊的交易为第一视角，观察一个以太坊交易的生命周期。

  

  

**我的一生**

## 

2019年4月15号，下午3点50分15秒，晴

这必将是值得纪念的一天，因为，我付出了一生，为家族创造了足够的价值，但同时我也永远成为了历史。

  

"我"的名字是0x1c154c1ae248789599aee93b064138e6853683f582438e02785092ad448d4fc3，是我们以太坊家族中第7570190 代家庭中的一个成员，我的家庭叫 0xb16c5502485bd814cc20d90043d9d3521b7ee6fa89c262b21af6c04facd6e9ac，如果没看过我们"家族谱",可能会觉得我们的名字很奇怪。但我相信，从我祖祖祖...爷的"家庭"出生的那一刻起，我们"家族"必将在这个世界上永垂不朽，旭日东升。

  

回顾一生，所看，所见，所想，不过如此。"戎马"一生，终究殊路同归，一切所做都是为我们家族发展贡献力量。

  

**第一张：诞生—咿呀落地**

  

如果你问我的父母是谁，严格来说，我以至于我的同胞们，都没有父母。但是有一句话说的好，顾客是上帝，用户是衣食父母，那么使用以太坊的用户就是我们父母。是他们创造了我。

#### 

#### **"生育"**

用户创建我的方式主要只有两种:web3和eth客户端，不像你们人类有这么多种的姿势，但不管使用多么花哨姿势，最终达到的目的都是一样的：通过祖先遗留下来的基因，用"父母"赋予我们的特有的信息将基因构造成一个完整的个体——我。

  

我猜测我的"父母"使用了web3创建了我。

//特有的信息

var src = "0xac35bb64e8e549d067faa3937d39bd77ab9699aa"

var des = "0xb686f0e01f1c582c574977f08bbcc4495625116f"var 

value = "0.00028691"

  

  

//web3方式

web3.eth.sendTransaction({from: src, to: dst, value: web3.toWei(value, "ether"), data: ""});

  

我想0xac35bb64e8e549d067faa3937d39bd77ab9699aa这个就是我的父母吧，嗯嗯，名字的还是有几分相似的。哦，对了，你好像只知道我的名字，还没见过我长什么样吧？

#### 

#### **美男子？**

我的基因就是下面这样。

//整体基因

type Transaction struct { 

   data txdata

   hash atomic.Value 

   size atomic.Value   

   from atomic.Value

}

  

data可以说就是我身体的大部分了，其中hash就是我未来的名字。和你们不一样，我乃至我整个家族的成员的名字都是在"身体"构建完成之后根据我的"模样"来定夺的，而不是根据"父母"的喜好来的呢。

  

当用户通过不同方式创建了我之后，我便像一颗受精卵一样根据这我们家族的基因来慢慢的构建着自己身体的每个部位，当我的身体(data)构建完之后就可以给我取名字(hash)了。如果看不懂为什么我的基因会被设计成这样也不用感到失望，就好像人类至今都尚未完全对自己的身体每一个基因都探索完成一样，这是个难题。当然了，我肯定是比人类基因简单的。如果你迫不及待，可以看看我的基因谱（https://github.com/ethereum/go-ethereum）

  

当我的一切都构造完成，基因与父母的特有信息便完美的融合在一起后，我便到了这个复杂的以太世界，说实话，当我第一次看见这个世界的时候，我也被吓了一跳。这里实在太过于庞大了，各种“工厂”纵横交错：rlp，txpool,miner,merkel，p2p，共识……一时间我茫然了，我不知道我的组织在哪，我为什么会被缔造成这样，甚至我不知道该去哪...

  

**第二章：成长—经历磨砺**

  

#### **实力派与幸运儿**

我想，每个我的同胞刚到这个世界的时候也是和我一样的迷茫，正当我寻思着该如何打破江局，一名老者扶了扶他的眼镜走了过来，和蔼地和我说:你现在所处的地方其实只是一个平行世界，在整个以太世界中，有许许多多的你自己在不同的地方进行着活动，但是最终的现实世界只有一个，要决定在现实世界中你自己的最终是否会成为一个伟大的"人"，那就要看每一个平行世界的你的造化：通过层层考验，将缔造你的"父母"所赋予你的信息，不被篡改地铭刻在这个以太世界。如果通过考验，那么你将会在这个以太世界中占有一席之地，并且找到属于自己的组织。

  

当我仍在原地苦苦思考着老者的话语的含义时，老者扔下一句"你现在还too young，赶紧去交易池进行考验增长一下知识水平吧"，便一瞬间不见了。

  

我在原地思索了一会儿，将信江疑地前往交易池...

#### 

#### **前往交易池**

当我站在交易池门口前，不禁感到一丝畏惧，因为这里有大量的同胞在接受着严格的检查，不合格的直接就被丢弃掉！残忍至极。而实力强劲通过检查的则在排着两条长长的队伍。

  

当我踏入门口的一瞬间，一个巨大的机械臂马上向我冲来，容不得我一丝反应，我就被放上了检测台。我知道我要接受考验了，但我不知道我是否有足够的能力通过这个考验，只是都到了这里，只能硬着头皮上。但是出乎我意料，检察官并不严肃，冲着我笑了笑就给了我一张试卷，上面只有一道数学题。我看着这道题认真地思索了一下，发现只是简单的代数计算。我飞快地将试卷上所需要的参数从我"脑子"里检索着，一下子我就把题目做完了，拍拍袖子上的灰尘冲着考官也笑了笑，交卷了。考官看着我的试卷满意的露出了神秘的笑容，嘴唇中慢慢的吐出"有个好爹"四个字，便让我去排队了。

  

通过了漫长的等待，我终于通过了后面的两个关卡，这两个关卡比较容易，之后我被分配到了7570190号房间，我当时并不知道这个数字意味着什么，只是觉得有种莫名温暖感。陆陆续续，这个房间进来了24个同胞，在这里我们交谈甚欢，各自聊着一路走来的故事。不一会，房门发出"伊伊..."的声音后便关上了，房子外面也突然热闹了起来，不知道在争吵着什么，但是总感觉正在决定这我们这25个同胞的命运。

  

外面一下子安静了下来，房子里面的我们莫名地紧张了起来，突然之前的老者出现在我们面前，声音响彻了整个房间:跟着0x5a0b54d5dc17e0aadc383d2db43b0a0d3e029c4c，他会指引你们继续发光发热，当时我并不知道老者所指的这个人是谁，默默地等待着这个人的出现。不一会，只见门口又发出了"伊伊..."的声音，不同的是，门外不是之前的漆黑一片，而是耀眼的光慢慢地扩开来，我们每个在房间内的人不得不得眯着眼睛，缩小瞳孔，但仍不足以看清门外那个"指路人"的模样...

#### 

#### **万千世界**

等了好一段时间，待我们看清了这个"引路人"的时候，他意味深长地对我们说:你们刚刚通过了交易池的层层考验，确实值得表扬。这证明你们真实地携带着你们的"缔造者"的信息，没有被篡改，没有丢失，这非常的好。但是这并不是你们的终点，你们下一步，也是最重要的一步就是将这些信息铭刻在我们这个大千的以太世界中。接下来，我会带你们"穿梭"于整个世界，去吧！去奋斗！去为了自己的未来干自己该干的事情！但有一件事必须提醒你们的是：运气也是实力的一部分。

### 

**第三章：奋斗—价值体现**

###   

"引路人"话音刚落，门外亮眼的光闪烁了起来，仿佛有一股强大的吸力迫使我穿过这扇门。我一步一步地迈向光所指的方向，每一步都十分的凝重，因为我并不知道穿过这扇门后会发生什么样的事情。

  

啊！当我穿过门之后，身体有种四分五裂的感觉，房子也在不停地变换着形状，屋内的同胞也和我一样不停的嘶吼着。突然，哐当一声，我们的房子从之前的富丽堂皇变得寒微简陋，巨大的体积一下子变得非常的小但刚好可以容纳我们25个肩负着重任的使者。透过旁边的窗户，我看到我们正在一条光速的隧道中穿梭着...

#### 

#### **做我该做的事**

时间过了不知道多久终于慢慢地，慢慢地，停了下来。房子也变回了本来的模样，和刚刚长得一模一样的老者出现在我们眼前，我想我又有新的任务了。

  

老者仿佛对刚买的高腰裤不是很满意，提了好几次仍然紧凑着眉毛，这使得我们更加紧张了起来。不一会，老者来到我们房子前，仔细审视着我们的房子，他的眼神非常的犀利，先看了看我们房子的编号，然后对比了一下他手上记录的表格，最后从头到尾地检查着每一个角落，严厉程度不比之前在交易池的低，这使得我的手心偷溜地冒出了冷汗。过了一段时间，老者自言自语道：“嗯！很好，属于完整体。这才使得我放下心来，然后他指着我们的房子挥一挥手袖便连同我一起整个房子飞了起来，直接扔到了另外一个小房子里面。

  

通过之前的一系列的经历，我已经对这个以太世界有了一定的认识，回想起刚到这里的时候那位老者所说的话，现在也有了新的领悟：每个"我"生下来的时候就已经决定好了我该做的事情，我的身体的每一部分，每一寸肌肤，甚至名字被设计成这样都是为了完成这个目的。也找到了这个世界中的规律：做任何事情之前，必须检查。

  

现在我身处在以太世界里面只有强者和幸运儿才能到达的地方，虽然这里很简陋只有一个令人畏惧的操作台和对应的机械手臂，但我知道在这里我将完成我这一生最重要的任务，做完这件事之后，我就可以功成名就，垂柳千古。我稳健的一步一步走向操作台，而当我走到中心时，机械手臂也马上行动了起来，按照惯例将我身体的各部分进行检查验证，然后再操作台下面突然冒出了许多的数据，机械手臂把我身体上部分的数据抽取出来整合到下面的数据中。简单出乎我的意料！我以为为了完成这个最后的任务我需要进行大量的操作，忍受难以忍受的痛苦，但只是这么简单，我已经完成了我的使命。突然，房间里面一闪而过未曾出现过的光亮画面，然后很快光慢慢地，慢慢地暗淡了下来，回归最原始的黑暗。

### 

**第四章：落幕—完美谢幕**

  

回顾一生，所看，所见，所想，不过如此。"戎马"一生，终究殊路同归，一切所做都是为我们家族发展贡献力量。一路走来，经历的风风雨雨，重重难关，最终还是化为最原始的0和1。从我诞生到这个世界中来，我的目的只有一个——将我的"缔造者"所赋予我的信息铭刻到我的世界来，即使至今我仍未知缔造我的那个人身处何方...

  

"我"叫0x1c154c1ae248789599aee93b064138e6853683f582438e02785092ad448d4fc3，我是以太坊家族中第7570190 代家庭中的一个成员。2019年4月15号，下午3点50分15秒，我完成了"缔造者"赋予我的使命。
