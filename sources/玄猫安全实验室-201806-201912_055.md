**安全事件**

1

**出现针对安卓手机的新型恶意软件 能仿冒加密App并窃取用户加密货币**

据The Next Web消息，近日，网络安全公司Group-IB发现一款针对安卓手机的恶意软件“Gustuff”，专门针对顶级国际银行和加密货币交易所，窃取客户法币和加密货币。据悉，“Gustuff”还会针对加密应用程序制造大量仿冒品，会窃取用户的敏感数据，如用户名和密码；如Coinbase、BitPay和比特币钱包等加密货币应用程序的用户是其特定攻击目标。

2

**恶意比特币钱包广告伪装后躲过谷歌审查**

据thenextweb报道，Reddit用户发现，谷歌在YouTube上意外地推广了恶意比特币钱包。恶意广告是伪装成Electrum的广告，甚至会在视频中告诉用户在视频中如何找到Electrum真正的链接（electrum.org），但当用户点击广告时，会立即开始下载恶意exe文件。此后，恶意广告会将毫无戒心的用户重定向到假冒网址elecktrum.org。

3

**被标记为“Cryptopia黑客”的钱包地址时隔一个月时间转出逾3万枚ETH**

今年1月，加密货币交易所Cryptopia遭遇黑客攻击，3月29日被标记为“Cryptopia黑客”的地址出现大额ETH转移，经查询发现这一地址标被etherscan标记为“Cryptopia: Hack 2”，它将30789 ETH（市值约428万美元）转移到一个未知的钱包地址（0x3fbaa73a43开头）。经过查询，Cryptopia: Hack 2钱包已经进行27次交易，上一次交易发生在32天前。不过今日这一钱包又发生另一笔交易，将1枚ETH转至另一未知钱包地址（0x30d4bffe开头）。有分析认为，这笔资金也许是补充损失的来源，或者是黑客试图通过多个地址来隐藏他们的踪迹。

4

**报告：黑客通过Tor浏览器进行域名抢注盗取200个比特币**

  

据tecmundo报道，英国公司Digital Shadows发布报告称，黑客通过Tor浏览器进行域名抢注盗取200个比特币。黑客在暗网上发布信息称，他最多会使用800个网站进行域名抢注。根据Digital Shadows的研究，发现了超过500个此类网址。

  

**安全资讯**

  

# **多家数字货币交易平台确认被东北亚黑客组织Lazarus攻击**

昨日，降维安全实验室预警多家交易平台沦为国家级APT组织攻击目标，经确认此次攻击系国家级黑客所为。国家级黑客组织Lazarus针对数字货币交易平台发起连续的攻击行动，多个大型数字货币交易平台均遭到不同程度的渗透攻击，该黑客组织与2014 年索尼影业遭黑客攻击事件以及2016年孟加拉国银行数据泄露事件和2017年席卷全球的“Wannacry”勒索病毒等著名攻击事件有关。

# 

# **Monero等七家公司过去两周向白帽黑客发放奖励以查找和修补了20个软件漏洞**

据thenextweb报道，根据Hard Fork审查HackerOne数据，七家公司在过去两周（3月14日至28日）期间向白帽黑客发放奖励以查找和修补了20个软件漏洞。其中，加密货币OmiseGO的开发者Omise提交了八份漏洞报告；Crypto.com和Augur各提交了三份；Monero向白帽黑客支付了两次修补费用；ICON处理了一个补丁；Stellar也修复了一个漏洞；Robinhood为两个安全修复程序颁发了漏洞奖励。

# 

# **多家交易所被攻击疑似和国家级黑客组织有关，该组织曾被指参与Coincheck等五起盗窃案**

某安全实验室与DrangonEx取得联系，一起分析并确认DrangonEx交易所遭受了黑客组织攻击，并且有证据显示攻击者可能和2014年索尼影业遭黑客等攻击事件有关。对此，360安全大脑表示，进一步的追踪溯源，发现这是一起由国家级黑客组织APT-C-26（Lazarus音译”拉撒路”）针对多家知名数字货币交易所发起的攻击行动。（注：联合国安理会此前报告称，Coincheck等五起加密货币交易所窃案系朝鲜黑客小组Lazarus所为）。360安全大脑在介绍该组织时也提到，2014年，索尼影视娱乐公司遭到黑客袭击，美国政府出面谴责Lazarus的行为。

# 

# **分****析机构公布Stellar 2017年攻击详情 官方称将于年底进行统计和披露细节**

3月27日，加密行业分析机构Messari发布一份调查报告称， Stellar曾在2017年4月份遭遇通胀Bug。有攻击者利用Stellar协议中"MergeOPFrame::doApply"功能漏洞创造了22.5亿枚XLM（当时价值约为1000万美元）。该数量占当时XLM供应量的25%，但并未引起媒体注意。Stellar发展基金会决定销毁同等数量的XLM以抵消此次非法膨胀。Messari表示，当时受影响的地址和Bug相关记录已不能够通过Stellar Expert或其他区块浏览器查询；且非法增发的XLM已被转移到交易所，并很可能已在2017年币市上涨期间卖出。对此，Stellar官方发布声明回应称，2017年4月已注意到此Bug，也做了对应措施，即销毁同等数量代币以平衡市场XLM流通量。且Stellar官方承诺，正如上月发布2019年路线图指出的一样，将在2019年年底对基金会所持XLM进行全面统计，关于该Bug的详细信息也在其中。

# 

# **以太坊基金会：Solidity最新版本0.5.7已修复所有漏洞**  

据ambcrypto报道，以太坊基金会发布了一篇名为“Solidity Optimizer and ABIEncoderV2 Bug”的博文，其中讲述了ABI编码器中发现的一个错误，以及优化器中发现的两个漏洞。该团队进一步透露，这些漏洞具有“低影响”。昨天发布的Solidity最新版本0.5.7包含了对所有漏洞的修复。

# 

# **朝鲜Lazarus黑客集团采用PowerShell新方法进行加密攻击**

据cointelegraph报道，网络安全和反病毒公司卡巴斯基实验室于3月26日发布的一份新报告称，朝鲜Lazarus黑客集团采用新方法继续进行加密攻击。该报告显示，自去年11月以来，黑客组织Lazarus积极开展新业务，使用PowerShell管理和控制Windows和macOS恶意软件。据报道，Lazarus团队开发了自定义PowerShell脚本，可与C2恶意服务器交互并执行来自运营商的命令。

# 

# **Joseph Young：必须建立更好的冷储存系统**

加密货币分析师Joseph Young发推称：新加坡的一个加密货币交易所被黑客入侵。黑客攻击的丑闻损害了加密市场的公众形象，对行业不利。现在必须建立更好的冷储存系统。在安全方面值得称赞的交易所有：Kraken、Binance、Coinbase、Gemini等等。

# 

# **Etbox官方：已追回部分被盗资产，对于因黑客入侵造成的用户损失将负责到底**

Etbox.com公告称，3月24日Etbox平台钱包受黑客入侵，导致平台数字资产被盗，目前已追回部分资产，现已修复漏洞，并处理所有用户的提现，etbox表示有足够的资产供用户提现，对于这次因黑客入侵造成的用户损失，etbox将负责到底。平台将一如既往的按EX蓝图计划进行经营及应用开发。

# 

# **又一家新加坡数字货币交易所BiKi宣布被盗**

据BiKi的公告，今日凌晨0:00-7:30期间，平台内部分用户的账号被修改密码，平台已经停止一切提现和场外交易，初步排查结果是验证码被黑客劫持，具体原因、涉及的用户数量和资金数量在进一步紧急排查，等待排查结果出来后，平台将会对本次用户资产被盗做一个合理的补偿方案。据悉，BiKi与龙网（DragonEx）一样，都是在新加坡。

# 

# **GitHub用户爆料：以太坊钱包MetaMask泄露地址和浏览动态 没切换到隐私模式会中招**

根据MetaMask GitHub上的一条信息，知名的以太坊钱包MetaMask一直在向用户浏览的网站广播他们的以太坊钱包，允许第三方查看他们的以太坊地址，并可能将其与他们的网页浏览动态联系在一起。该钱包有一个内置的“隐私模式”，可以阻止这种情况发生，但这需要用户手动激活。如果没有启用该功能，这个应用还是会将相关信息“同步到”用户浏览过的网站。提交这一信息的用户表示：这牺牲了系统中所有人的隐私，因为亚马逊、谷歌、PayPal等网站可以将你的区块链交易与信用卡支付联系在一起，这样你的身份，以及和你进行交易的用户的身份都会曝光。《币世界》此前报道，2018年11月，降维安全实验室曾发现以太坊钱包MetaMask推出隐私功能来保护用户隐私，但提醒称，加入隐私功能后，未经用户许可，网站将无法获取用户以太坊地址，但是此功能需手动开启，开启方式为Setting--Privacy Mode。

# 

# **Cryptopia：在宣布入侵24小时后存入的资金将无法追回**

据AMBCrypto消息，新西兰的加密货币交易所Cryptopia发布了一份声明，详细介绍了1月14日黑客攻击后发生的存款情况。声明称，所有客户都是在1月15日新西兰时间12点被通知的，因此，在公告后24小时内发生的存款将无法追回。
