# **Electrum伪造升级提示的钓鱼攻击盗窃至少200个BTC**  

据慢雾区消息，Electrum伪造升级提示的钓鱼攻击已盗窃至少 200 枚BTC，此次攻击单靠升级 Electrum无法避免，需要整个生态服务都做对应的改动（因为 Electrum 这个客户端并不是全节点，然后在交易广播上和对应的服务端有消息通讯，攻击者也可以部署恶意服务端）。慢雾区提醒用户，Electrum这类钓鱼攻击需要长期警惕。慢雾区此前发布Electrum钓鱼更新事件预警，对Electrum钱包进行攻击的黑客利用Electrum的软件异常构造恶意的软件更新提示，诱导用户更新下载恶意软件使用。

# **EOS竞猜游戏ggeos再遭交易回滚攻击**

据PeckShield态势感知平台01月03日数据显示：黑客向EOS竞猜类游戏ggeos游戏发起攻击，目前游戏网站已暂停运营。数天前，PeckShield就曾披露了该游戏遭黑客攻击，受影响下游戏网站暂停运营整改，不过1月3日刚部署上线又遭到黑客攻击。安全人员分析认为，目前新部署上线的脆弱合约已成黑客重点攻击对象，简单通过暂停运营整改合约的方式治标不治本。针对此，PeckShield紧急推出DApp安全盾风控解决方案，通过已积累的庞大高危账户库，帮助游戏合约开发者有效检测、阻断和隔离危险源，并可第一时间报警并停止游戏，最大程度减少游戏合约被攻击可能及资产损失额。

  

# **12月共发生20起竞猜类游戏遭攻击事件 总损失超600万元**

据PeckShield态势感知平台数据显示，过去一个月，EOS公链共计发生20起竞猜类游戏遭黑客攻击事件，开发者共计损失348,204个EOS，以当前价格18元估算总价值超600万元。PeckShield安全人员分析数据发现：1、攻击事件损失超过1万个EOS的有7起，大部分攻击损失均在1,000—10,000个EOS之间；2、安全事件开始影响到包含BetDice、ToBet在内的头部竞猜类游戏，其中BetDice一次损失195,531个EOS，较为惨重；3、除个别项目因私钥泄露和假转账通知等造成的漏洞，黑客主要攻击方式为交易回滚攻击，大部分安全事件和随机数问题有关；4、过去半年，12月份受攻击次数最多，损失额度亦最大环比11月份增长6倍。

# **波场某DApp被盗200万TRX，超八成投资者仍看好波场的未来发展**

调研链Insight Chain(INB)发布投资者关于“波场某DApp被盗200万TRX ，孙宇晨称会组织安全培训“的看法的调研结果。本次在Insight DApp内共收集有效问卷375份，其中36.6%的投资者认为在主流数字货币中，波场的安全性较好，只有6.9%的投资者认为其安全性并不理想；遭受此番攻击后，49.6%的投资者表示会受其影响，减少TRX的持有量，但有约5.3%的投资者表示会增持TRX；58.9%的投资者认为在目前的技术水平下，安全培训可以有效解决波场的安全问题；高达85.3%的投资者仍看好波场的未来发展。
