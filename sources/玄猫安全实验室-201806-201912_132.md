ICO 页面是一个dApp。包含了两个在 Rinkeby 测试网络的合约。第一个是 ERC20 token 合约，上面的币叫 HACK 币。你可以进行 token 的相关操作。最终的目标是获得比 31337 多的 HACK 币。另一个合约是一个彩票游戏。

## **Winning the lottery**  

    

![](../Images/ac0de29b2daa5eb311e35944e14e42f3.png)

*robot address :*

*0x3a0c7287b9aac3c71ee8b9048c5dfb989f2a4d54*

查看合约交易的信息，可以看到机器人地址每5个*blocks*提交一个随机数。**这些数是以明文的形式提交的，并且没有seed。**说明代码存在抢占交易问题。在看到后，以更大的*gas*提交发起交易即可。  

  

*< https://rinkeby.etherscan.io/txs?block=1207127>*，看到**攻击者以更高的 gas 发起交易，成功抢占交易。**

  

通过抢占交易我已经成为进入到*desires mapping *，但我仍然不能买*token*。我还需要进入到* whitelist mapping *中。从合约中看到，*owner*才可以做这一步。

  

function addParticipant(address who) onlyController public {

  if (isDesirous(who) && who != controller) {

     whitelist\[who\] = true;

     delete desires\[who\];

     AddParticipant(who);

     RemoveProposal(who);

  }

}

## **Getting to the whitelist**  

  

智能合约没有其它的缺陷能够让我进入到白名单。但是*vue.js*写的*web*应用存在以下的代码，能够显示用户的邮箱地址。 

  

domProps: {

    innerHTML: t. \_s( e. email)

}

  

这说明用户可以控制输入，并且没有通过过滤的情况下显示在页面上——这是一个*XSS*。使用* \`changeEmail\`*方法我可以获取HTML标记注入在页面上。 

  

我们猜测合约的*owner*的*geth*部署在他本地的电脑，监听在*localhost:8545*地址，并且，他的用户是*unlocked*状态的，*owner*访问了这个*XSS*页面，**我们可以试着通过*XSS*调用其本地*geth*节点发起一个交易，让我们加入到白名单里。**

  

![](../Images/edd856511cdb7e2d486b55b9a450adec.png)

 

将上图的 *test.js *代码上传到线上服务器，然后用 *XSS Code* 代码发送请求进行* XSS *攻击，受害者访问了页面后，下载* test.js *代码在浏览器上执行，调用* metamask *的* web3.js *接口，然后指向本地的* 8545 *端口进行攻击操作。惊喜的是，*owner *访问了页面，并且符合我们的猜测，我们进入到白名单里了。

## **Buying tokens**  

  

接下来，我们准备买 31337 个*token*。但是发现* buy() *方法中存在限制条件： 

function buy() public payable {

 if (isWhitelisted(msg.sender)) {

    uint hacks = RATE \* msg.value;

    require(hack.balanceOf(msg.sender) + hacks <= 1000 ether);

    hack.mint(hacks, msg.sender);

 }

}

  

这说明我们最多只能买 1000 个 HACK 币。但是看到*transfer *函数，我们是否能够通过转移 token 来增加呢？ 

function transfer( address \_to, uint256 \_value) public afterICO returns ( bool) { /\* ... \*/}

  

被* afterICO *修饰，但是我们发现，它的判断条件*\`block.timestamp > November15\_2017\`* 没有被* require() *修饰，所以我们直接操作即可。 

  

modifier afterICO() {

    block.timestamp > November15\_2017; \_;

}

  

**通过 32 次****"buy & transfer" ****交易，我们最终达到了目标。**

**Crafting an off-chain transaction**  

  

最后一个任务，是发起一个签名的* off-chain *交易，交易的* msg.data *中需包含"HACK"。此任务关键词是 "交易"。
