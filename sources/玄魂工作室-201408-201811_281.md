# 每周一书-《鸟哥的Linux私房菜》获奖公布

#  

《鸟哥的Linux私房菜》一书的赠书活动时间为2016年10月19日到10月31日， 也就是今天结束。

首先要感谢QQ号为：1084830483（路在远方），来自哈尔滨工程大学的同学赠送给玄魂工作室的读者的。 得到此书的同学请主动联系“路在远方”，表示感谢！

这本书得到了大家的积极响应，到目前为止共有1788人阅读推送的文章， 50人参与留言。

部分留言节选如下：

* * *

## 木易先森

从小接触计算机，从Windows97玩到现在的Win10。小学到高中都是班上的“大神”，别人电脑出了问题也都找我，我也就真的把自己看成了一个“大神”。后来知道了linux，才知道自己不过是个跳梁小丑罢了，后来很想学Linux ，但作业太多没时间，现在有时间学，但网络上的很多容易找到的资源都不系统，看到玄魂分享这本好书，我很希望能够得到它，烦请大家点个赞，谢谢！

## Pui Ching@J.R.smith

第一次接触Linux时，是在北理工大学，学通信工程专业时，一位老师在课上告诉我们:“以后学好Linux系统，出去找工作，1万起”，当时是第一次知道这个操作系统，后来有同学去学了ccna，也是推荐我去学习Linux，不要从事网络工程师，系统工程师比较吃香。就这样，我就参加北京的一个培训机构，深入的学习了Linux，发现原来这个操作系统如此强大，各个互联网公司，国外的公司支持Linux。一开始工作时没有找好工作，进入了一家银行，在国家开发银行里当了一名工程师，进入银行后才发现原来银行大部分是Unix，跟之前的Linux大不一样，HP，IBM，Sun等都不一样，索性，毅然决然辞职，到了一家互联网公司，开始了Linux工程师的职业生涯～

## 木子扬羽

第一次听linux是因为想当hacker，然后了解到hacker精神，过度到linux精神，接着自己折腾乌班图，那时候觉得世界就应该是linux那样，可生活确实windows的样子，也是让人懊恼，跌跌撞撞，还是靠近了linux，玄魂大哥推的书，更像是一种精神上的传递，希望得到此书的人别放弃梦想，就算现实再残酷（书是好书，留给别人，留言是为了回味故事）

## mouse catch cat

這本書做為學習考證入門是最好的，當初學習時，老師推薦我看這個書，下了幾個電子版的，還有鳥哥的網站，也就沒買原著，其實紙質版書比電子版在某些情況下方便很多，查閱方便。學完過了一年忘了好多，現在把電腦的windows幹掉了，只裝了個Ubuntu，感覺挺方便，記起一些東西來了，雖然debian繫列和redhat繫命令、包有些許區別，但基本都相通，強制自己日常用Linux才不會忘。。

## helloximo

看了各位的留言我想说的是大家缺的不是书而是学习的热情和执行力！三分热情的人我估计这本书你连第一章都看不完！所以我希望留言的各位好好想想！你真正缺乏的是什么？我有一本第三版！看了一个多月吧！只要有时间就看！目前也只看了一半！我觉得还缺少练习！而且这本书值得反复看反复练！各位且行且珍惜！

## CORE

正在通过大陆版第三版配合鸟哥的官网学习。以前读书的时候不懂事，不知道好学习，现在出来工作了才发现没有一技之长真的很难过。真心希望能够得到这本书，纸质版的阅读比网页版要好很多。
