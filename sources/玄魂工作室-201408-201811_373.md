## 1.1  安装VS CODE

在Kali系统中打开VS Code网站：https://code.visualstudio.com/。

![](../Images/4305ead4383e5f72997542fa29163719.png)  

图2

下载.deb格式的软件包。

![](../Images/9d63bffbf39f8f57abf8a8fbc596f2dc.png)  

图3

下载完成后，启动终端，到下载目录，查看下载的文件。

![](../Images/8c92b85308b8bba890a9f052700f1a8e.png)  

图4

接下来使用dpkg来安装软件包，输入如下命令：

dpkg - i  \[软件包名称\]

![](../Images/03830ff4d0ca61305b5a69e76ba9b3e2.png)  

图5

安装成功之后，到软件列表页，搜索VS Code。

![](../Images/eaeed15a2f3dbdf078e1cbafedf4ac1a.png)
