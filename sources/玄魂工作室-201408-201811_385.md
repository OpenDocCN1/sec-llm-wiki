## 1.2 如何配置更新源

启动终端输入

vim /etc/apt/sources.list

 

![](../Images/57cb4e223c59a0a724346a7f406e4c7a.png)  

添加如下内容：

 

\# Regular Repositories

deb http://http.kali.org/kali sana main non-free contrib

deb http://security.kali.org/kali-security sana/updates main contrib non-free

\# Source repositories

deb-src http://http.kali.org/kali sana main non-free contrib

deb-src http://security.kali.org/kali-security sana/updates main contrib non-free

 

![](../Images/9f93ead6eea008fbad788c4aa497a2f6.png)

## 1.5  安装vmware tools

1.         安装Vmware Tools前需要安装内核

apt-get install linux-headers-$(uname -r)

![](../Images/4c2e030bb31e018a8466ab23136bf055.png)  

2.    加载vmware-tools镜像。

![](../Images/f981aaa76037afdb35c471a4bb5511f2.png)  

3.     打开光盘所在目录，将Vmware-tools的安装文件（Vmware-tools.\*\*\*.tar.gz这个文件）拷贝到HOME目录。

![](../Images/b6828585430a308bf4f54cdcfcf71b96.png)  

![](../Images/c4e03c4659885a5750bb8d7060f0e5a5.png)  

4.     解压缩（tar）该安装文件，并安装vmware-tools.

tar zxvf VMwareTools-9.9.0-2304977.tar.gz

cd vmware-tools-distrib/

./vmware-install.pl

![](../Images/87bd86173bf0bf0b944e3a2dbc99c05e.png)  

![](../Images/1dc6593c68c191e917fa008946a77308.png)
