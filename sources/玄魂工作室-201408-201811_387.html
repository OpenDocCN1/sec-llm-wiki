匿名者附属组织LulzSec推特账号4月16日发布匿名者暗网IRC频道。
onionirchubx5363 . onion  Port 6667 SSL: Port 6697

今天老夫利用ubuntu 下载 tor messenger进入匿名者暗网IRC频道.你们自己下载Windows版安装，安装完操作都是一样的
首先老夫打开火狐浏览器谷歌搜索tor messenger 或者你们直接输入网址：https://trac.torproject.org/projects/tor/wiki/doc/TorMessenger#Downloads


点击这里


下载好了直接提取此处；


打开messenger文件夹点击tor messenger step


安装成功代理vpn打开connect


链接成功会跳出选择链接IRC还是其他，我们选择第一个IRC，next


然后输入自己用户名和匿名者提供IRC暗网域名

Name 自己用户名
server IRC暗网域名 onionirchubx5363.onion



password 密码输不输入密码，这里直接跳过



Alias这里就是输入自己用户名

端口默认6697修改为6667

取消use ssl 小钩钩符号


我们看到IRC用户名和IRC域名，别名，端口，SSL点击finish

点击connect （连接）


连接成功


连接成功点击tor messenger file （文件） 接着join chat （加入聊天）

account （账号）已经看到用户名和域名

channel （渠道）就是匿名者提供的IRC频道名#main

password （密码）不用输入

接着 Auto-join this chat room（自动加入这个聊天室）打上钩钩符号。




现在已经进入#main频道可以聊天了
