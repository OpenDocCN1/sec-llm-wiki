# 匿名者推出暗网IRC频道，如何进入IRC频道呢？

匿名者附属组织LulzSec推特账号4月16日发布匿名者暗网IRC频道。  
onionirchubx5363 . onion  Port 6667 SSL: Port 6697  
![](../Images/9576aac1b7f5b0fa952d040396337cc5.png)  
今天老夫利用ubuntu 下载 tor messenger进入匿名者暗网IRC频道.你们自己下载Windows版安装，安装完操作都是一样的  
首先老夫打开火狐浏览器谷歌搜索tor messenger 或者你们直接输入网址：https://trac.torproject.org/projects/tor/wiki/doc/TorMessenger#Downloads  
  
![](../Images/cb695c77cbdbebe98dba06c84c15b8cb.png)  
点击这里  
  
![](../Images/a46d8ff37ddab931c3fe12067298697b.png)  
下载好了直接提取此处；  
  
![](../Images/47178d02a4d74e0242acf1de12969f39.png)  
打开messenger文件夹点击tor messenger step  
  
![](../Images/9c490bab7f098aeca044a7e6f527895e.png)  
安装成功代理vpn打开connect  
  
![](../Images/010ffae3fe4ecd38cc3583c526cc4ff1.png)  
链接成功会跳出选择链接IRC还是其他，我们选择第一个IRC，next  
  
![](../Images/c617eb6fede1696482eed4a5505ef50b.png)  
然后输入自己用户名和匿名者提供IRC暗网域名  
  
Name 自己用户名  
server IRC暗网域名 onionirchubx5363.onion  
  
![](../Images/8faf3b257ca5bd086a8f35416cbca324.png)  
  
password 密码输不输入密码，这里直接跳过  
  
  
![](../Images/a78088955a21bb7faa4baa68ff7ba302.png)  
Alias这里就是输入自己用户名  
  
端口默认6697修改为6667  
  
取消use ssl 小钩钩符号  
  
![](../Images/1531383a3ea8ba6b1d1017c8f49a4d92.png)  
我们看到IRC用户名和IRC域名，别名，端口，SSL点击finish  
![](../Images/12e7920a98e455487a36f00ff79845d5.png)  
点击connect （连接）  
  
![](../Images/ae32afc9fbf317cb8c789258b987be52.png)  
连接成功  
  
![](../Images/bd0cc6e8326801d15f2b3cd806de33e1.png)  
连接成功点击tor messenger file （文件） 接着join chat （加入聊天）  
  
account （账号）已经看到用户名和域名  
  
channel （渠道）就是匿名者提供的IRC频道名#main  
  
password （密码）不用输入  
  
接着 Auto-join this chat room（自动加入这个聊天室）打上钩钩符号。  
  
  
![](../Images/dd19e9e898fea28ceb59b4b610ef985c.png)  
  
现在已经进入#main频道可以聊天了  
  
![](../Images/cc388cd88ec2944adfe670dd9da13a9f.png)  
进来看到好多国外匿名者大黑阔，装个逼老夫退出房间了。
