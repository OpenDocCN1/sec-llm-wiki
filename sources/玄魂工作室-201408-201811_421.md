# 从此不再为PPT困扰！斧子演示让文稿“动起来”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NDk5NTYwNw==&mid=402800534&idx=1&sn=f85eb012e35347fa86bd399f4224b6dd&chksm=022824ee355fadf8c91f2a355cef280b0724c317008d6ea3f80c7181f09a60d51558a861c736&scene=126&sessionid=1681656531#rd](http://mp.weixin.qq.com/s?__biz=MzA4NDk5NTYwNw==&mid=402800534&idx=1&sn=f85eb012e35347fa86bd399f4224b6dd&chksm=022824ee355fadf8c91f2a355cef280b0724c317008d6ea3f80c7181f09a60d51558a861c736&scene=126&sessionid=1681656531#rd)

　　【环球科技1月7日报报道】又是一年年末，年终总结恐怕又让不少人头疼了。然而比起年终总结来，更让人头疼的恐怕是年会总结时候的演讲。且不说别的，光演讲时候PPT的制作就够不少人喝一壶的。

　　**让人头疼不已的PPT**

![](../Images/4911a74b311c8535b973891ef2443618.png)

  

传统PPT

  

　　说到PPT，让人不禁想起刚毕业入职的时候，无论是转正演讲、项目报告还是年终总结，一边演讲一边播PPT仿佛成了一种惯例，提到演示文稿第一反应就想到PPT也成了一种思维定式。自几十年前幻灯片发明以来，报告的形式并无多大变化。虽然每天都有很多人在做PPT，然而做的好看的却寥寥无几。为了工作需要，有些公司还高价聘请PPT美化团队来帮助自己完成PPT的美化工作。

　　转眼2016年已经来临，从经济到科技，一切都在飞速发展中，大多数人却还在使用PPT做演讲稿，殊不知PPT早已跟不上时代的步伐了!亚马逊CEO贝佐斯就曾宣布，禁止员工在开会中使用PPT，认为PPT这种固定模式的展示限制和束缚了思维表达，使气氛僵硬，缺少沟通。

　　确实是时候尝试一下更炫酷而且省钱的展示方式了!

　　**一款让文稿“动起来”的软件**

![](../Images/5768979129ef344876e3700cd7d91f37.png)

　　记者无意中接触到了一款名为斧子演示(AxeSlide) 的演示文稿制作工具，看过用它作出的演示文稿后，瞬间觉得文档+图片的简单PPT演示文稿效果简直太业余了!

　　那么斧子演示到底是什么呢？据了解，AxeSlide斧子演示是一款全新的演示文档制作软件，基于Html5 2D/3D技术开发，具有良好的跨平台性(兼容主流的windows和OS X系统)。软件演示方式的灵感来源于Prezi，演示的内容都在一张大画布上，利用平移、旋转和缩放(Zoom)，可以推进、拉出查看详细内容。软件支持插入图片、视音频文件，并提供丰富的模板可供下载使用，快速制作质量优良的演示文档。

![](../Images/04036196d9731c52588deee2627b80c9.png)

　　概括来讲，斧子演示是一款极易上手，操作简单，创意无限，效果炫酷的一款免费可视化演示文稿制作软件。这款软件最大的特点就是打破了传统思维方式，以全新的思路让文稿演示“动起来”。

　　**逻辑清晰界面简洁**

![](../Images/5926f47b53a9b86255712715d5d7ce45.png)

  

斧子演示界面

  

　　不同于传统PPT一页页的线性演示逻辑，斧子演示是在一张画布上展开的面逻辑，用最直观、最形象的表现形式把演讲者的论点展示出来。而斧子演示的逻辑则是通过无缝衔接的一个个平移、缩放的画面充满动感的展示给观众。内容的组织类似思维导图，整体与细节间的平滑过度，观点和逻辑结构让观众更易把握。

![](../Images/9323a8fd61d4a371effc54fe2a3f3a22.png)

  

斧子演示成品示意图

  

　　和传统PPT至少有几百个直观和隐藏的功能键相比，斧子演示的操作界面更简洁，功能键少而直观。不管是插入音频、视频，还是插入矢量图;不管是改变底色，还是调整图片，斧子演示都能轻松完成。选用合适的模板之后，只需输入文字内容，其它的专业效果就都可以交给斧子演示来完成了。

　　**一键导出省去安装烦恼**

　　对于PPT使用者而言，电脑上若未安装PPT软件则无法打开文件。与传统的PPT演示不同，基于HTML5语言设计的斧子演示，无需事先安装软件就可跨平台播放，方便在各操作系统的PC端以及手机端、pad端等进行移动端展示。

![](../Images/84944654b5cfa6dab8116e48378b3769.png)

　　此外，斧子演示文稿还可以一键导出为PDF文件和视频。如果将斧子演示文稿拿到其他电脑上演示，可以一键导出生成一个便携文件，在任何系统中都可以打开并轻松演示。还可以上传到云空间中自己的账号里，随时在线浏览和下载。此外，由于斧子演示的HTML5基因，作品上传到云空间后，可以在手机端随意观看，任意转发。

　　**做颠覆者，让别人去跟随！**

　　斧子演示的产品灵感虽然来源于Prezi，但是从一开始斧子团队就立足中国本土，致力于打造最适合国人使用的、完全颠覆PPT的演示文档制作软件，所以在功能和软件定位上都有别人Prezi。由于软件完全免费，必将在包括学堂课业、商业演示、创意提案、公众演讲等众多领域大显身手。

　　在斧子的产品路线图中，未来的一到两年左右的时间内，斧子也会完成一次自我颠覆，把演示文档带入到全新的纯三维世界中，创造真正的国际大片般的演示体验。未来的路并不平坦，但正如斧子团队的负责人所说：“不论从产品还是技术上，我们都走在了最前沿，前路多坑，但是我们不会绕行，要做就做勇于填坑的人”。

![](../Images/58dbfbcfdac27e454bbf9681c334815b.png)

  

目标客户与使用环境

  

　　斧子演示团队曾于去年获得来自华熙集团的千万级天使投资。作为一个研发为重的团队，在极少宣传曝光的情况下，目前累积用户量已超过10万，并且几乎每月都在以成倍的速度增长。在刚刚过去的12月中， AxeSlide发布了2.1.1版本更新，在优化软件功能的基础上，修复了十多项存在的问题。

　　斧子演示CTO杨文海表示，斧子演示未来将继续在产品打磨上着力，在Prezi基础上不断创新;着重做移动端，完善已有功能，有针对性提升用户体验。
