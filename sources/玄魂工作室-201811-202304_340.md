二：Linux\_awvs安装记录

环境：Ubuntu 16.04.1 LTS

  

安装好依赖:

sudo apt-get install libxdamage1 libgtk-3-0 libasound2 libnss3 libxss1 -y

  

下载官方的脚本：https://www.acunetix.com/thank-you-for-downloading-wvs-onsite-linux/

开始安装:

  

记得：sudo

chmod u+x acunetix\_trial.sh

./acunetix\_trial.sh

成功后会给出地址可以访问看看。

https://Taoing:13443/  # 当然Taoing是你的IP地址  注：你们的不是Taoing哦

  

建议ifconfig看下虚拟机ip：直接在物理机谷歌浏览器中打开，记得是https

  

三：破解

下载破解文件: patch\_awvs  

  

将破解文件解压并拷贝到安装目录中

  

我是直接放在桌面 懒得搞到目录

  

sudo cp patch\_awvs /home/acunetix/.acunetix\_trial/v\_190325161/scanner/

  

进入安装目录：cd /home/acunetix/.acunetix\_trial/v\_190325161/scanner/

  

![](../Images/62d93b0950fcf9a1c157727166b7e967.png)

  

加下权限：sudo chmod +x patch\_awvs

  

运行破解程序：sudo ./patch\_awvs

![](../Images/3eb358ffc32fc1a7fa177a9f13484f89.png)

  

  

显示如上表示成功

  

  

**检测是否成功**：

  

打开awvs面板 登录以后

  

点击Administrator->Profile->License",可以看到99999就说明成功激活

  

![](../Images/1ba15afc3dad15241a67f58c08ec4f76.png)

  

关闭自检更新：

登录系统后,左下角Settings->ProductUpgrades,改为"Do not automaticaly check for update\[Not Recommanded\]"

  

  

![](../Images/8105c844beef2e9abdb600af74c874da.png)

 

  

请开始你的骚操作，建议保存虚拟机快照
