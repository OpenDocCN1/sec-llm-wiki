想到了thinkphp3.x常犯的exp表达式注入，于是在所有action中搜索$_GET/$_POST

App\Lib\Action\Admin\UserAction.class.php

    public function baseinfo(){        $data = array('status' => 0, 'msg' => '未知错误');        $Userinfo = D("userinfo");        $status = $Userinfo->where(array('id' => $_POST['id']))->save($_POST);        if (!$status) {            $data['msg'] = "操作失败";        } else {            $data['status'] = 1;        }        $this->ajaxReturn($data);        exit;
    }

这种构造如下payload会产生注入问题。
