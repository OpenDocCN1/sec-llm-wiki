RSA加密，通过断点查看exponent和modulus的值。

![](../Images/ae2b0f192223da89c978c0c3df7d1c20.png)

  

值是固定的，搜索后发现就存储在config.js中，也就是说RSA公钥为modulus。

但这是一个256位公钥的RSA加密，在其他环境中几乎找不到这种加密项目，而js中有RSA.js/Barrett.js/BigInt.js这么一个早期项目。这种时候就需要用python去调js代码来进行加密。

```
import execjs defrsa(str):    file = 'RSA.js'    ctx = execjs.compile(open(file).read())    js = 'a("'+str+'")'    params = ctx.eval(js)    return paramsprint(rsa("admin"))
```
