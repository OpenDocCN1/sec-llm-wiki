一、    前言


需要提权的用户通常分为两类，一类是计算机普通用户(包括域普通用户)，user，guest，一类是webshell常获取的用户，NETWORK SERVICE，MSSQLSERVER，defaultapppool用户。一般需要提权到SYSTEM或者administrator权限。

提权通常有三种方法，1，exp溢出提权，2，第三方服务提权，3，错误配置提权。
一些常见的提权命令。
systeminfo
net user
net localgroup
net localgroup administrators
whoami /priv
tasklist /svc
netstat -ano
taskkill /IM x64.exe
qwinsta
query user

三、    第三方服务提权


本质上是我们拥有第三方服务的账户/权限，而第三方服务错误的用system权限运行了，那么有可能使用这些第三方服务来执行cmd命令。如果不能直接执行，如果能够写入纯净文件，也有可能使用dll，mof，启动项来提权。
C:/windows/system32/wbme/mof/
C:/ProgramData/Microsoft/Windows/Start Menu/Programs/Startup/
C:/Users/administrator/AppData/Roaming/Microsoft/Windows/Start Menu/Programs/Startup/
常见可能泄露密码的配置文件，web.config，config.php，web.xml，application.properties
windows比linux更加常见这种情况，因为windows的程序往往是高权限运行。

Redis使用save无法写入纯净文件，因此在linux常用的RCE方法无效，只能通过主从复制覆盖文件。

添加java.io.FilePermission权限，利用了DBMS_JVM_EXP_PERMS存储过程对PUBLIC用户开放的漏洞。

(需要CREATE SESSION权限，CPU补丁之后仅限DBA用户可以执行。)

获取了java.io.FilePermission权限之后还可以用DBMS_JAVA.RUNJAVA或者DBMS_JAVA_TEST.FUNCALL调用类，一般是oracle/aurora/util/Wrapper类。

select DBMS_JAVA_TEST.FUNCALL('oracle/aurora/util/Wrapper','main','C:\\windows\\system32\\cmd.exe','/c','calc') from dual;
