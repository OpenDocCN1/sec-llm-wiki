前言

虽然前面几次都有发过一些比较简单的cms的代码审计文章，但是好像从来没有系统的去说一下代码审计的一个思路。接下来就给大家分享一下我代码审计的一个流程。

工具篇

前言 在代码审计的过程中，自动化审计工具起到非常关键的作用，它能帮我们快速定位一些可能出现漏洞的地方，比如定位一些敏感函数，一些比较容易出问题的代码格式，这些工具能读取我们的整个cms代码项目，然后通过正则去匹配，我们也可以通过修改正则去更改规则。

Seay源代码审计系统

前言

  • 这个工具是一个不开源的由国人写的工具，它还有一本配套的叫代码审计的书，如果要想学代码审计，那本书是个很不错的入门读物，建议大家读一下。但是这个软件比较老，而且也很久没有更新了，其中的误报还是比较严重的，但是上手比较容易，如果是一些比较简单的cms是可以用这个软件的。

使用

新建项目

  • 安装的话就不在这说了，安装网上都有很多详细的教程，这里我简单给大家讲一下使用。

  • 当我们打开后，就是这样的一个界面，我们可以新建一个项目，项目选择我们要审计的cms的根目录，记得，是根目录。

自动审计

  • 当我们新建好项目后，我们点击自动审计，然后点击开始。

  • 我们发现这里会有很多条信息，但是这写信息，不都是对的，也可能是误报，所以我们可以通过双击去看当前页面的代码。

全文搜索

  • 当我们想要知道某个函数具体的实现的时候我们可以通过全文搜索去搜索对应的函数或者变量。

审计插件

  • 这里最主要是的mysql的监控插件，我们可以通过这个插件去监控mysql执行的具体流程，这样方便我们在审计sql注入的时候，查看我们注入的语句是否被执行。

RISP代码审计

前言

  • 这个工具是一个用php写的，它的界面如下。这个工具比上面那个工具好，不仅是进行敏感函数的定位，还会把参数的传递过程显示出来，而且误报率是比较低的。

源码的绝对路径

  • 如题，就是传入源码的路径。

扫描级别

  • 这里默认1就好

漏洞类型

  • 这里选择你想专门审计的漏洞类型，或者选全部

代码样式

  • 就是显示的一个主题，对审计结果无影响。

PHPstorm/sublime

前言

  • 这两个软件呢，主要是用来阅读代码，因为代码审计的代码阅读功能比较差，比如一些高亮，而且没有调试功能。这里主要是说phpstorm

调试功能

  • phpstorm是可以外联php的一个debug插件，进行一个调试功能，这在大型的cms审计是非常方便的，这里的话也是不说安装，大家自行去搜索一下。

快捷键

  • phpstorm让我最爱的就是它的快捷键。
  • ctrl+b可以快速找到函数的实现
  • 左键选择函数，右键从文件中搜索，可以查看当前函数在哪里被调用。

多项目

  • 而且phpstorm可以一次性打开很多项目，不用阅读一个就要重新打开。

简介

  • 这是一个比较简单的cms，但是具体名字我忘记叫什么了。

rsia进行自动审计

  • 由于这个cms没有搭建好，所以我就随便挑了一个漏洞。任意文件删除漏洞
//关键代码
  public function del()
 {
    $dirs=in($_GET['fname']);
    $dirs=str_replace(',','/',$dirs);
    $dirs=ROOT_PATH.'upload'.$dirs;
    if(is_dir($dirs)){del_dir($dirs); echo 1;} 
    elseif(file_exists($dirs)){
      if(unlink($dirs)) echo 1;
    }else echo '文件不存在'; 
 }
  • 其实不难看出来，unlink会删除dir是可以通过get传参的，虽然最后破解了ROOT_PATH.'upload'，但是可以通过../来跳出最后进行删除。
