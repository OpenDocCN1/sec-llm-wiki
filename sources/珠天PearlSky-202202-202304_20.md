# 前言

虽然前面几次都有发过一些比较简单的cms的代码审计文章，但是好像从来没有系统的去说一下代码审计的一个思路。接下来就给大家分享一下我代码审计的一个流程。

# 工具篇

前言 在代码审计的过程中，自动化审计工具起到非常关键的作用，它能帮我们快速定位一些可能出现漏洞的地方，比如定位一些敏感函数，一些比较容易出问题的代码格式，这些工具能读取我们的整个cms代码项目，然后通过正则去匹配，我们也可以通过修改正则去更改规则。

# Seay源代码审计系统

## 前言

*   这个工具是一个不开源的由国人写的工具，它还有一本配套的叫代码审计的书，如果要想学代码审计，那本书是个很不错的入门读物，建议大家读一下。但是这个软件比较老，而且也很久没有更新了，其中的误报还是比较严重的，但是上手比较容易，如果是一些比较简单的cms是可以用这个软件的。

## 使用

### 新建项目

![](../Images/e7faa818fb53bbb781e537ca3fb391ad.png)

*   当我们想要知道某个函数具体的实现的时候我们可以通过全文搜索去搜索对应的函数或者变量。

## PHPstorm/sublime

### 前言

*   这两个软件呢，主要是用来阅读代码，因为代码审计的代码阅读功能比较差，比如一些高亮，而且没有调试功能。这里主要是说phpstorm

![](../Images/2be6f15d0aeb3574dd50c3d83dc918da.png)

### 调试功能

*   phpstorm是可以外联php的一个debug插件，进行一个调试功能，这在大型的cms审计是非常方便的，这里的话也是不说安装，大家自行去搜索一下。

### 快捷键

*   phpstorm让我最爱的就是它的快捷键。
*   ctrl+b可以快速找到函数的实现
*   左键选择函数，右键从文件中搜索，可以查看当前函数在哪里被调用。

### 多项目

*   而且phpstorm可以一次性打开很多项目，不用阅读一个就要重新打开。
