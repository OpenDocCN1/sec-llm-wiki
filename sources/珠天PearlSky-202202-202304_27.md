## 分析

*   首先我们得知道java的反射原理，java可以通过反射去获取类的信息，如构造方法，成员方法，和成员属性。我们可以通过反射去获取我们想要的某个类的某个方法并且去执行。

```


//自定义类Stu

()"ok"

;ok

()"ok"

);"Stu"

); //获取类"ok"

);//获取名为ok的方法
```

*   这段代码是在`entry.setValue("test");`执行的时候完成了代码注入，这个test可以是任意值，我们打断点。

TransformedMap类

*   我们发现这里调用了`this.valueTransformer`类的transformer方法。而`this.valueTransformer`的值在构造函数里被赋值。
*   在实例代码种有如下代码

```


Transformer[] transformers = new Transformer[]{"getMethod"

,            //方法名"getRuntime"

,new Class[0]}//参数值"invoke"

,"exec"

,"calc"

}
```

*   这边调用了 TransformedMap的decorate方法，其功能就是返回一个实例化的TransformeedMap对象，其构造函数的值为mp,transformerChain,transformerChain，其中valueTransformer就为transformerChain。

![](../Images/46257cd4b826dbca934f07d5f8694d65.png)

TransformedMap

*   而这里的transformerChain是ChainedTransformer的实例化对象，其构造函数的值为transformers。
    
*   transformers是一个数组，其中的参数为我们要执行的目标类的信息。
    
*   我们继续步入，由于valueTransformer是ChainedTransformer的实例化对象，这里调用了ChainedTransformer的transformer方法。
    

![](../Images/0c694b4ef7630d5bf8d51c005e704365.png)

ChainedTransformer类

*   这里的this.iTransformers为我们传入的transformers素组，循环调用数组里，每个对象的transformer方法，首先是调用ConstantTransformer的transformer方法。

![](../Images/3f59cdc29f4d264e09b283ae40274116.png)

ConstantTransformer

*   可以看到返回了this.iConstant，而this.iConstant的值为我们一开始实例化传入的Runtime.Class。然后赋值给object

![](../Images/84fa2fced26a17983d8a1895b08bc9d0.png)

TransformedMap

*   可以看到object已经被赋值为了Runtime,这时候调用的是InvokerTransformer的transformer方法。

![](../Images/32caededef2ce0a2c10c5b6e3b4bc0b3.png)

InvokerTransformer

*   这里就是整个利用的核心，input是我们传入的runtime类，获取其class值赋值给cls。
*   cls为class.java.lang.Class。接下来获取方法，方法名就是我们传入的getMethod。
*   参数类型为String,Class\[\]。然后通过invok去执行。最后返回一个执行的object对象。
*   以此类推，整体的利用顺序如下

