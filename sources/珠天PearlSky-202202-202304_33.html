ZC_Function.php
function zc_check($string){
  if(!is_array($string)) return addslashes(trim($string));
  foreach($string as $k => $v) $string[$k] = zc_check($v);
  return $string;
 }
  • 发现用到了addslashes和trim函数。
  • addslashes
  • trim
  • 这里的添加反斜杠可以使用宽字节注入来绕过，但是需要数据库的编码是gbk的，寻找一下数据库相关的信息。
ZC_Mysql.php//核心代码
function connect() {
  $link = @mysql_connect(DB_HOST, DB_USER, DB_PASS) or die("数据库配置信息错误：数据库地址，用户名或者密码不正确");
  mysql_query("SET NAMES utf8");

 }

  • 发现这里用的utf8编码，所以无法用宽字节注入。接着看，又因为filter_xss函数对一些符号进行了过滤，所以xss漏洞也是没有的。

  • 跟进 upfile
function __construct($file){
   $this->file_name=$_FILES[$file]['name'];//客户端原文件名
   $this->file_type=$_FILES[$file]['type'];//文件类型
   $this->file_tem=$_FILES[$file]['tmp_name'];//储存的临时文件名，一般是系统默认
   $this->file_size=$_FILES[$file]['size'];//文件大小
  }
  • 发现这里的文件类型是根据file]['type']来获取的，而这里的值跟数据包的Content-Type头有关，我们只需要这样设置Content-Type: image/jpeg就可以绕过。接着看。
  • 跟进upload_file
function upload_file(){
   $f_name=$this->files_name();
   move_uploaded_file($this->file_tem,$f_name);
   return $f_name;
  }
  • 发现把文件上传到了$f_name指定的路径。跟进files_name
function files_name(){
   $name=$this->set_name();
   $folder=$this->creat_mulu();
   return "../../".$folder."/".$name;

  • 跟进set_name
//获得文件后缀名
  function getext(){
   $ext=$this->file_name;
   $extstr=explode('.',$ext);
   $count=count($extstr)-1;
   return $extstr[$count];
  }
  
  //新建文件名
  function set_name(){

  • 发现文件名由time()函数拼接上后缀，后缀的获取是截取文件名小数点后面的字符。
