# xhcms代码审计

## 前言

今天打开先知社区逛了逛，发现了一篇关于xhcms的代码审计文章，看起来挺适合新手的(比如我这样的菜狗),于是就下载了一套进行代码审计，整个cms漏洞很多，而且逻辑简单，确实很适合新手练习，话不多说，我们直接进入主题。

## xhcms

我的这套cms是1.0版本的，在网上随便找个源码网站下载一份就好。然后通过phpstudy搭建环境，这里就不教了，大家自行百度。

## 任意文件读取

#### 漏洞位置 index.php?r=

```


index.php$file=addslashes($_GET['r'
]); //接收文件名$action=$file==''?'index':$file
; //判断为空或者等于index'files/'.$action.'.php'

); //载入相应文件
```

*   从这里可以看到通过GET方法获得参数r的值，经过addslashes函数后，传给。通过一个三元运算符判断file是否为空，然后通过 include直接导入。

```
include('files'.$action.'.php'
);
```

*   这里因为$action是可控的，而且没有做任何过滤，就照成了任意文件读取。 这里我们自己写一个config.php![](../Images/d01ce87486702ad49b2d112a7c53937a.png)
*   访问127.0.0.1/xhcms/?r=../config

![](../Images/33f7f5e6d319015a0918794aea6451d4.png)

### Tip

*   这里因为后缀写死了php,而且想通过00截断绕过也只有在低版本的php下有用，所以如果要利用这个漏洞的话，要么找到一个上传点能上传一个木马，然后通过include包含，或者包含一些其他pph然后利用传参去进行调用，找了很久，这个cms的上传还是写的很死的，没办法上传一个一句话木马。
