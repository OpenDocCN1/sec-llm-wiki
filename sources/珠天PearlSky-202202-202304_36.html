先了解代码中出现的魔法函数：

__invoke(): 以调用方法的形式调用一个对象时，此方法会自动调用。

__construct(): 对象初始化时会调用此方法

__toString(): 对象在需要转换成字符串时会调用此方法

__wakeup(): 当对象被反序列化时会自动调用此方法

__get(): 访问对象不存在的属性时会调用此方法

代码审计

Modifier类

class Modifier {
    protected  $var;
    public function append($value){
        include($value);
    }
    public function __invoke(){
        $this->append($this->var);
    }
}

这个类有变量var，方法append，魔法方法__invoke。

最开始有一行注释，提示flag在flag.php文件中

//flag is in flag.php

需要注意的是，append方法中有include函数，可以利用这个函数来读取flag.php的源码，获取flag。

魔法方法__invoke中调用了append方法。

可以利用Modifier类对象当作普通函数来调用，触发魔法方法__invoke，其内部就触发了append方法，此时append方法接受的是var变量，进而触发include函数获得flag。其触发链如下

// modifier 是 Modifier 实例化后的对象
modifier() => modifier.__invoke() => modifier.append() => include()

这个类有变量source、str，魔法方法__construct、__toString、__wakeup。

__construct：初始化source变量，并打印一个字符串。

__toString：访问变量str的source变量，在Show类对象转换为字符串时调用此函数

__wakeup：在Show类被反序列化时调用，同时过滤source变量，过滤了部分伪协议。

POP链构造

首先看看得到的分析：Modifier类和Test类

要触发Modifier类的链

modifier() => modifier.__invoke() => modifier.append() => include()

就需要Test类的魔法方法__get

test.__get() => modifier() => modifier.__invoke() => modifier.append() => include()

要触发Test类对象的魔法方法__get需要类对象访问一个不存在的属性。

目光回到Show类的魔法方法__toString，它是从str变量中取source。

如果变量str的值是Test类对象，Test类没有成员属性source，会触发Test类对象的魔法方法__get。现在的触发链如下

show.__toString() => test.__get() => modifier() => modifier.__invoke() => modifier.append() => include()

到这一步，需要想如何触发Show类对象的魔法函数__toString。

看到Show类的魔法方法__wakeup，preg_match方法的第二个参数需要str类型的变量，其中$this->source就是作为preg_match方法的第二个参数，令source变量的值为Show类对象，就可以触发魔法方法__toString。现在的触发链如下

show.__wakeup() => show.__toString() => test.__get() => modifier() => modifier.__invoke() => modifier.append() => include()

得到完整的POP触发链就可以开始构造exp了。

PAYLOAD构造

构造exp，从后往回一个一个类的构建，首先是Modifier类。

这个类主要利用的地方是include函数，include函数接受的变量是var，修改var变量的值就行了。

想要得到flag.php的内容，可以利用伪协议，上面过滤了一部分，但还是有未过滤的伪协议可以读取flag.php中的内容。

class Modifier {

    public function __invoke(){
