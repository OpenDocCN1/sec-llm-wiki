  • file_get_contents函数是打开一个文件并返回这个文件的所有字符，当allow_url_open为on的时候可以用来执行伪协议。

  • php伪协议

    • file:// — 访问本地文件系统
    • http:// — 访问 HTTP(s) 网址
    • ftp:// — 访问 FTP(s) URLs
    • php:// — 访问各个输入/输出流（I/O streams）
    • zlib:// — 压缩流
    • data:// — 数据（RFC 2397）
    • glob:// — 查找匹配的文件路径模式
    • phar:// — PHP 归档
    • ssh2:// — Secure Shell 2
    • rar:// — RAR
    • ogg:// — 音频流
    • expect:// — 处理交互式的流

  • 这里我们用到了data这个可以传入数据的伪协议，我们用这个协议传入welcome to the zcctf然后通过file_get_contents返回这个数据，使得判断为true，就能继续下面的代码执行。

  • 我们发现__tostring里面有一个file_get_content函数，把类属性file赋值进去，也就是说会打开file指定的文件并把数据放回。而且对file这个属性没有任何过去，只要让file=flag.php在调用__tostring这个函数，就能拿到flag

  • 那怎么才能去调用这个__tostring函数呢

  • 我们发现这里对传入的参数进行了一次反序列化，然后把反序列化后的对象传给了$password并且输出。那也就是说我们可以传入一个Flag对象的序列化字符串给password，进行反序列化后被输出，这样就调用了__tostirng这个函数了。

include($file);  //useless.php 
        $password = unserialize($password); 
        echo $password;
<?php  

class Flag{  //flag.php

}  
$f = new Flag();//实例化类
$f->file="flag.php";//传参
echo serialize($f);//序列化

?>
  • 再把数据传给password
  • 这里我们在看完了useless.php的数据后，就传useless.php就好，因为我们在进行反序列化创建对象的时候，我们得保证有这个类，所以传入useless.php通过include导入了Flag这个类，我们反序列化后的对象才能正确执行。
