0x00 格式化字符串漏洞简述

格式化字符串Format String漏洞最早是在1999年被Tymm Twillman发现的，他在著名的BugTrag邮件列表中公布了一篇关于proftpd软件漏洞的文章Exploit for proftpd 1.2.0pre6,是最早关于格式化字符串漏洞的公开描述。直到2000年，tf8在BugTrag上公布了一份利用wu-ftpd格式化字符串漏洞实现任意代码执行的漏洞WuFTPD:Providing *remote* root since at least1994，才使格式化字符串这类漏洞被广为人知。

格式化字符串漏洞是一种威力比较大的漏洞，漏洞原因主要是因为使用类似于printf(str)这类语句，里面的str用户可以自己定义。轻则使程序dump，重则造成任意地址写甚至拿到shell

0x01 格式化字符串漏洞原理

格式化字符串漏洞的产生主要源于对用户输入内容未进行过滤，这些输入数据都是作为参数传递给某些执行格式化操作的函数，恶意用户可以使用%s %x等等格式符，从堆栈或其他内存位置输出数据，也可以使用格式符%n向任意地址写入任意数据，可能导致任意代码执行或从程序中读取敏感信息

危险函数

  • printf(const char *format, ...)等同于fprintf，但是它的输出流为stdout

  • fprintf(FILE *stream, const char *format, ...)按照格式化字符串将输出写入流中。三个参数分别是流，格式化字符串和变参列表。

  • dprintf(int fd, const char *format, ...)等同于sprintf，但是它的输出不是写入流，而是一个文件描述符fd

  • sprintf(char *str, const char *format, ...)等同于fprintf，但是它的输出不是写入流，而是写入数组。在写入的字符串末尾必须添加一个空字符

  • snprintf(char *str, size_t size, const char *format, ...)等同于fprintf，但是它制定了可写入字符的最大值size。超过第size - 1的部分会被舍弃，并且会在写入数组的字符串末尾添加一个空字符。

  • vprintf(const char *format, va_list ap)与上面的函数对应，但是将变参列表换成了va_list类型的参数。

  • vfprintf(FILE *stream, const char *format, va_list ap)与上面的函数对应，但是将变参列表换成了va_list类型的参数。

  • vdprintf(int fd, const char *format, va_list ap)与上面的函数对应，但是将变参列表换成了va_list类型的参数。

  • vsprintf(char *str, const char *format, va_list ap)与上面的函数对应，但是将变参列表换成了va_list类型的参数。

  • vsnprintf(char *str, size_t size, const char *format, va_list ap)与上面的函数对应，但是将变参列表换成了va_list类型的参数。

<!--more-->除了printf函数族，scanf函数也会出现格式化字符串的漏洞

格式化字符串基本格式：


%[parameter][flags][field width][.precision][length] type

parameter - 'n$' 用来获取格式化字符串中指定的参数
flags - '+, 空格 , - , # , 0 '
field width - 显示数值的最小宽度
precision - 常指明输出的最大长度
length - 浮点型参数或整形参数的长度(hh,h,l,ll)
type - 转换说明,格式化控制符

常见的格式化控制符
d - 十进制 - 输出十进制整数
s - 字符串 - 从内存中读取字符串
x - 十六进制 - 输出十六进制数
c - 字符 - 输出字符
p - 指针 - 指针地址
n - 到目前为止所写的字符数

原理

printf()类函数，在读取参数的时候，并不知道参数的个数，它会根据format中的打印格式的数目依次打印堆栈中参数format后面地址的内容

格式字符串漏洞发生的条件就是格式字符串要求的参数和实际提供的参数不匹配

恶意用户可以使用%s和%x等格式符，从堆栈或其他位置输出数据

甚至通过%n可以向任意地址中写入任意数据

危害

  • 打印敏感信息

  • 任意代码执行

  • DUMP程序

0x03 pwntools.fmtstr

pwntiils pwnlib.fmtstr模块提供了一些字符串漏洞利用的工具。

该模块中定义了一个类Fmtstr和一个函数fmtstr_payload

其中，Fmtstr提供了自动化的字符串漏洞利用


class pwnlib.fmtstrFmtstr(execute_fmt, offset=None, padlen=0, numbwritten=0)

execute_fmt(function)-与漏洞进程进行交互的函数；
offset(int)-控制的第一个格式化程序的偏移量；
oadlen(int)-在payload之前添加的pad的大小；
numbwritten(int)-已经写入的字节数；

fmtstr_payload则用于自动生成格式化字符串payload


class pwnlib.fmtstr.fmtstr_payload(offset, written, numbwritten=0, write_size='byte')

offset(int)-控制的第一个格式化程序的偏移量；
writes(dict)-格式为{addr: value, addr2: value2},用于往addr里写入value的值；
numbwritten(int)-已经由printf函数写入的字节数；
write_size(str)- 必须是byte,short,int。指定要逐byte写，逐short写还是逐int写
