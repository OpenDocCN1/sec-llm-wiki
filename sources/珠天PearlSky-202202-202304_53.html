0x00前言

当我们去浏览一个网站的时候，我们的电脑会向目标网站的服务器发送一个请求包，请求包里面会附带一些我们主机的一些信息，比如说请求的来源，所使用的浏览器，编码格式和请求的协议等等。而当服务器接收到我们的请求包后，就会返回一个响应包(有时候也叫返回包)，相应包里有当前的响应状态码，响应数据等。接下来，我会详细地给大家讲解，请求包和响应包里每个参数所代表的意思。

0x01请求包


各个参数的解释

HOST
请求的目标url和端口号
Connection
是否需要持久连接
Cache-Control
指定请求和响应遵循的缓存机制
Upgrade-Insecure-Requests
向服务器指定某种传输协议以便服务器进行转换（如果支持）
User-Agent
用户所使用的浏览器
Accept指定客户端能够接收的内容类型
Accept-Encoding指定浏览器可以支持的web服务器返回内容压缩编码类型
Accept-Language所支持的语言编码格式
Cookie所携带的客户本地信息

0x02响应包

HTTP/1.1 200 OK 
协议/协议版本/状态码
Content-Type
所放回的数据类型和编码
Content-Encoding
服务器支持的压缩文件类型
Vary
告诉下游代理是使用缓存响应还是从原始服务器请求
Server
服务器所使用的软件
Date时间信息
Content-Length
请求的内容长度
