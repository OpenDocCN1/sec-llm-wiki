**欢迎来到Misc的世界**

  

Misc，全称 Miscellaneous（杂项）

在 CTF 中扮演最奇特的角色

  

各个分支的 CTFer 也喜欢它，因为它很有趣

**入门的同学很喜欢它，因为它门槛低**

**最重要的是，它在比赛中的题目占比很高，10 道题目，它就能占到 3 题，深受各位 CTFer 的重视**

  

**我认为 Misc，共分为五类**

① 隐写：图片、音频、视频隐写

② 取证：内存取证、磁盘取证

③ 流量分析：web、usb、蓝牙流量

④ 破解：压缩包破解、文档破解

⑤ 其他类型

**隐写（Steganography）**

  

**隐写术是一门关于信息隐藏的技巧**

信息隐藏指的是不让预期接收者之外的任何人知晓信息的传递或者内容 隐写的信息看起来像一些其他的东西, 例如：一张清单，一篇文章，一篇图画或者其他“伪装”的消息。

  

*   图片隐写，通常有：宽高修改、LSB 隐写、数据块隐写等
    
*   音频隐写，通常有：摩尔斯电码、频谱分析与提取、数字信号编码（曼彻斯特编码）等
    
*   视频隐写，通常有：帧隐写、视频轨道、字幕等
    

  

**做题步骤：**

通常我们拿到题目（压缩包解压后），都会先做以下五步（Misc 类的题目基本如此）

  

1\. **首先，查看文件类型**，我们通常在 WSL 或者虚拟机 Kali 中执行以下命令：  

*   
*   
*   
*   

```
# 查看文件类型file flag# 大致阅览一下文件内容cat flag
```

2\. **其次，查看有无特殊信息**，并搜索 CTF、flag、key、password 等关键字：

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# 可以直接右键，查看文件的属性
# 对于单个文件，我们搜索内容是否隐藏了关键词，因为 flag 通常被隐藏在这些信息中# 根据题目和描述，在需要密码时也可以搜索相关的关键字strings flag.png | grep -i -n 'flag'
# 对于文件夹，我们采用遍历式搜索cd 文件夹名字grep -rn 'flag' ./*
# 是否有隐藏文件头，搜索二进制文件头hexdump -C flag.bmp | grep -i -E "89 50 4E 47|FF D8 FF|47 49 46 38|50 4B 03 04|52 61 72 21 1A"
```

3\. **然后，查看文件是否隐藏了二进制文件**，一般我们用 Winhex 或者 010editor 软件查看

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# 下面是常见文件头和文件尾# 其他文件头可以参阅博客：https://iqiqiya.blog.csdn.net/article/details/80156865
# png头：89 50 4E 47尾：AE 42 60 82
# jpg头：FF D8 FF尾：FF D9
# gif头：47 49 46 38尾：00 3B
# zip头：50 4B 03 04
# rar头：52 61 72 21 1A 07 00 CF 90 73（v4）头：52 61 72 21 1A 07 01 00 CF 90 73（v5）
# bmp头：42 4D
# pdf25 50 44 46 2D
# pyc03 F3
# 二进制文件尾部可能会含有隐藏信息（一般发生在 png、jpg 和 gif 文件）# JPG 二进制文件的特征是 FF 很多
```

4\. **最后，分离文件**，同样是在 Linux 中运行：  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
# 下面两个命令都能分离隐藏文件，做题时最后两个都试一下binwalk -e flag.pngforemost flag.png
# 在二进制文件的指定位置分离# 以十进制确定分离位置dd if=phrack.bmp of=out.png bs=1 skip=1143210# 以十进制确定分离位置dd if=phrack.bmp of=out.png bs=1 skip=$((16#1171AA))
```

**取证（Forensics）**

  

其实我也不太清楚内存取证和磁盘取证的具体区别，因为在实际比赛中并不会分得那么细，考的基本都是对取证文件的分析或提取，因此我就简单说下这类题目的考点吧。

  

*   用 volatility 查看镜像（后缀为 vmem、raw 之类的文件），并分析镜像内容，比如登入密码、可疑进程、特定文件、剪贴板历史等
    
*   挂载镜像（例如 VMware 挂载 MS-DOS）
    
*   NTFS 数据流隐写
    
*   注册表分析（例如 RegistryExplorer 提取 Windows 注册表）
    
*   raid 重组、ext 文件恢复、数据恢复 等等  
    

  

需要注意文件系统，比如 Windows 有 FAT12、FAT16、FAT32、NTFS 等，而 Linux 有 EXT2、EXT3、EXT4 等，有时还会考 Macos 的知识。

**流量分析（Traffic Analysis）**

  

这一类题目，几乎都是分析 WireShark 的各种流量包（web、usb、蓝牙），具体分析我也仅是略知一二，还请各位多刷题、多整理属于自己的笔记。

  

需要注意的是，这类题有时也会考察计算机网络的相关知识（比如 TCP 三次握手协议），而且各位也要掌握一些 Web 方面的网络命令（比如 ns、nmap 等），其实多掌握各种方面的知识也挺不错的，说不准在什么时候就会用到，比方 AWD 是大家都会参与的线下比赛，但它基本考的就是 Web，也就是说，即便你其他方向学得再精再厉害，要是不会 Web 那也就只能干坐着了 (ˉ▽ˉ；)...

**破解（Crack）**

  

*   压缩包破解
    
*   文档破解
    

这一类题考得最多的就是压缩包破解了，特别是 ZIP 压缩包，比如有字典暴力破解、伪加密、CRC32 碰撞、损坏压缩包恢复等，因此要特别注重 ZIP 压缩包的二进制，最好看一下别人的博客，记一下笔记，再刷点题。

而文档破解我刷的题太少，只知道一个 PDF 破解，其他的暂时还没遇到过 (lll￢ω￢)

**其他类型**

  

其实 Misc 有趣的地方就在于其不仅限于固定的题目，经常会考各种奇奇怪怪的知识，当然，解法也不唯一。

  

就比方说拼图，题目给你一堆被拆分的图片，你要将其合并，你会怎么做呢？

  

1\. 在 PS 中手动拼图，累死啦 (〃＞目＜)

2\. 会使用命令行，一键完成

*   
*   

```
# 将全部 256 张散图拼成一张大图片，宽为 16 张图片，高也为 16 张图片montage ./puzzle/*.png -tile 16x16 -geometry +0+0 flag.png
```

3\. 按照时间顺序排序，直接显示出拼图

![](../Images/206f980a145374bbce8299beb5da2d8f.png)

  

对于同一道题目，根据每个人的经验不同，自然会给出不同的解法，不存在最好或最差的解法，只有适合你自己的解法

  

或许有人会说，刷题时我也会遇到古典密码这类编码和解码的题目，为什么我没有放在考点里面呢？因为我认为这些属于密码学，亦算是密码学与 Misc 的结合（毕竟各方向知识点的结合也不少），因此没必要细讲。
