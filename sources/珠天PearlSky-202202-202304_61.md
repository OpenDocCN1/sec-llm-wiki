## 0x00 一些碎碎念

目前网络安全还没有普及到我们院校，而且战队也是刚刚起步，绝大部分时间还是要靠自己努力。

  
这里只是给新人的一些经验总结，多多少少给点帮助，不至于走太多弯路。

学习的话当然最好是从打 CTF 开始入门。

  

可以自己找资源学习，推荐的话就是 B 站上涅普科技出的教程，挺照顾新人的。

  

然后一定要多刷题，多总结思路，推荐的刷题网站有：BUUCTF, 攻防世界，ctfshow，BMZCTF，BUGKUctf  

  

先要自己思考，绞尽脑汁也做不出来之后，可以自己去网上搜集一些相关资料，然后可以去群里面询问，最后实在不行再去找 WP（Write Up，指上传的题解）。

  

并且一定要搞清楚每道题的原理，然后跟着 WP 自己动手复现。

  

事后最好将思路以及笔记记录到战队博客上面。

  

战队博客只是用来记录以及督促各位学习的，还希望大家足够重视。

  

参加 CTF 比赛这件事根据个人，最好还是跟着战队一起参加，收获一份体验。

  

刚开始肯定会有点忐忑，比赛打不下来 flag 等等，都是新人必经的一个阶段  

  

CTF 共分为五大分支：Pwn、Crypto、Web、RE、Misc

下面是各个方向的队友给予新人的一些建议：  

  

## 0x01 PWN

****By：**sevenG0**  

  

学习PWN呢，最好要有充足的时间才行，一是你能投入学习钻研的时间，二是你未来走向岗位之前的试错时间。  

  

PWN这个方向时CTFer公认的难搞，大量的基础知识，比如C语言，Python,汇编语言，计算机操作系统，数据结构，静态反汇编（IDA,Radare2），动态调试（GDB,x64dbg），编译原理等等都是需要熟练掌握的。。  

  

所以需要你投入大量的时间去学习，并且初期学习的时候，你能得到的收获是没有期待中那么高的，需要不断坚持下去，当你的知识和经验积累到一定程度时，它才会慢慢反馈给你。  

  

所以要学习PWN之前一定要想清楚，并且给自己留有充分的时间去学习，确定自己是否能够坚持下去，等到自己不感兴趣仍有时间去转型。

  

不过PWN虽然难，但它学成之后获得的收益还是蛮大的，目前CTF战队中,PWN手的地位是极其高的，虽然有些比赛的其他题偶会难一点，但大部分情况还是不影响PWN手的地位的。  

  

总之呢，PWN的学习是一个非常漫长的过程，选择PWN一定要想清楚了。  

  

如果下定决心，或者有兴趣学习PWN的话，可以来私聊我。

  

其他方向比如Web是一个比较容易入门的方向，我刚开始也是从Web入门的。

  

也稍微讲一下关于Web

  

首先呢学习Web需要你熟知各大漏洞的原理以及利用技巧，bypass技巧，还有各种CVE也要去动手复现，学好Web其实讲究的是一个随着时间的推移，你所掌握的知识面越来越宽，利用技巧，bypass技巧越来越多的一个过程，要学会利用好前人所总结的经验

  

剩下的可以看前一篇aka\_zz写的文章（本来要放一起的，不小心提前发了，只能推迟一天

## 0x02 Crypto

**By：Tuanzi**  

Crypto，也叫做密码学，它是 CTF 五大分支中的一支，在 CTF 中一直占有独特的地位，因为玩的人极少，就算在比赛当中，也会经常出现一支队伍解不出一道密码学题目的状况（除了签到题）

### 学密码学需要什么基础呢？

入门的话可能需要懂一些 python2 的知识，当然如果你学过 python3 也可以，本质没啥用区别；

当然，也需要数学方面的知识，但是没有大家想的那样难，至少在入门阶段，只需要基础数论（学起来很快的），但是到了很后期，可能需要了解到线性代数、抽象代数等知识，但是那也是很久之后的事情了；

因此，对数学感兴趣（至少不讨厌）的同学可以来尝尝鲜哦 O(∩\_∩)O ~

不过除了古典密码学，密码学还会考察现代密码学，但是这个就比较难了，也是比赛中常考的压轴题。

举个大家熟悉的例子：MD5，它常常用于验证信息传输是否完整，什么意思呢？比如在数学建模比赛中，大家在最后一天要准时提交参赛文件，但是这个时候提交的人数肯定是非常多的，主办方服务器可能会承受不住，那怎么办呢？主办方可以让大家先提交参赛文件的 MD5 码，再依次慢慢上传自己队伍的参加文件，有人会说，如果有人偷偷修改文件怎么办，这就不用担心了，因为一旦修改了文件内容，哪怕一个标点符号，文件的 MD5 码就会完全不一样，因此这样有效防止了参赛同学在提交时间截至后，拖延时间进行修改文件的情况，下面是我参加比赛时提交的 MD5 码：

![](../Images/cc6abe246975a8dc3f576cf6ed0207b7.png)

那么在 CTF 比赛中一般怎么考察 MD5 呢？因为密码学的比赛较少考察到 MD5，因此下面我们以 Web 类型的题目举例：  

下面是比赛题目的链接，它提示了我们 "please input a"，意思是在题目的网站后面输入`a=?`，也就是`123.206.87.240:9009/md5.php?a=`，但是具体要拼接什么并不知道，但是注意到地址出现了 MD5，也就是本题要考察的内容，很有可能考的是 MD5 Collision（MD5 碰撞）

![](../Images/a2809ff3ac36b1acdbbec4d6250edc14.png)

PS：PHP 在处理哈希字符串时，会把每一个以 "0E" 开头的哈希值都解释为 0，也就是即便是两个完全不同的字符串，只要它们的哈希值前面要是都是 "0E" 开头，那么 PHP 就认为它们是一样的

我们根据这一漏洞，猜测数据库中可能存在以 "0E" 开头的密码，于是百度查一个以 "0E" 开头的字符串，进行拼接（进行 MD5 碰撞），如果碰撞成功，那么本题就解决了  

![](../Images/281f72f5a2765defd9e2f2891ec6c5cb.png)

  

果不其然，我们猜测对了，至此我们得到了 flag，只要我们将它提交给主办方，我们本题就算完成啦 ~

怎么样？是不是感觉很容易呀，通过了本题，我也想告诉大家 CTF 并不是只考察一个方向的比赛，它是一个综合的网络安全比赛，比如这题隶属于 Web，但它也出现密码学的考点，同样 Pwn 也可以和 Web 或 密码学结合，考察大家的综合素质

## 0x03 Misc

**By：Tuanzi**

Misc，全称 Miscellaneous（杂项），从翻译中就可以猜到这个分支就是包含些奇奇怪怪的东西 :D

  

**在 CTF 中，通常会考察隐写、电子取证、流量分析、破解等内容。**  

但是按我的理解，只要是不属于 Web、Crypto、Pwn 或 RE 类型的题目，都叫作 Misc，因为分不了类，所以叫作杂项咯 ~

你可能对 Misc 的第一印象是混乱，或者题目类型种类繁多，没错，还真是这样！但正因如此，Misc 的题目都非常有趣，会涉及各方面的知识、各种花式技巧以及各种各样的工具，使人欲罢不能。所以它还有个作用，就是当学其它方向累了的时候，做几道 Misc 题，能让你思维开阔、让你身心愉悦

### 学 Misc 需要什么基础呢？

无，只要你有兴趣，任何时候都能开始学

唯一的基础就是从你做题的那一刻开始积累的

### Misc 到底是什么？

老规矩，我们以真实题目代替解释。下面这道是我们团队去年参加的 GFCTF（2021）

题目给了我们一个压缩包，我们要做的就是从中找出 flag

![](../Images/e78ecd477fd27e69aaf2ab9d78dd0295.png)

首先解压，得到一张名为 flag.png 的图片，图片里面有很多可爱的皮卡丘，但是可以注意到，有些皮卡丘身上有一些奇怪的英文字母，这代表着什么呢？我们暂且不清楚  

![](../Images/cf8db131dc6909d9194005b831803835.png)

在 Misc 中，题目给出了图片，一般都是考察图片隐写，什么是隐写呢？就是图片中隐含了一些看不到的内容，这些内容往往是出题人通过某种方式加进去的，我们要做的就是将它提取出来。图片隐写的入门通常会学习到很多 Bash 命名，比如 binwalk、foremost 等，这些命令可以将图片中的隐写部分提取出来，让我们试试看吧 ~

![](../Images/ce4ed7b0d6732b23ec26639687b89b10.png)

用 binwalk 命令对图片进行处理，从结果可以发现（Zip archive data，译为压缩包数据），里面含有压缩包！可是，压缩包竟然是加密的，可恶！有什么办法可以提出里面的音频文件吗？  

![](../Images/3a8ce7b6c87c91d8a3f4f8a755d514e3.png)

欸？皮卡丘身上的英文字母会不会就是解压密码呢？让我们再仔细看一下，沃趣，将它们进行连线之后竟然可以得到 I\_want\_a\_p1ka! 这段字符串，赶紧看看是不是解压密码  

![](../Images/10d2e1ee6b308807c17b41a46ad1fc2e.png)

确实是解压密码，里面是个音频文件，放出来听一下。可是听起来很吵，是杂音，说明音乐里面没有隐藏有用的信息，那就有可能隐藏在音频文件里面了，很有可能是音频隐写！  

![](../Images/dfabbbef095b59b8268f1099fa964009.png)

用 Audacity 软件打开音频文件，拉伸音轴，注意到音频呈高高低低的排序，这是什么意思？联想到密码学，有没有一种可能，高的代表 1，低的代表 0，它们组成了 01 字符串？唔，不管了，咱们先试一试吧，把音频文件里的音频按照 0 和 1 的关系提取出来  

![](../Images/50ee888d8d6ce8139ea74cf04510b1fa.png)

提取需要脚本，可以选择从网上下载一个 python 脚本，也可以自己写一个，但是如果自身造诣不足，很难写出来，所以我们从网上下载了一个 python 脚本，具体代码如下：  

![](../Images/49dd29b505fe4e7dd08c532e1095cd0a.png)

运行脚本，把音频信息提取出来到 flag.txt 文件中  

![](../Images/0705ec5063891a1ee5b629474d94ab09.png)

然后查看 flag.txt，哇！全是 0 和 1，  

![](../Images/a16e212dc100d01358b941928d068def.png)

这里再次联想到密码学，01 字符串可能和 ASCII 编码有关系（ASCII 编码是 CTF 中常考的编码），于是再将 01 字符串转换为 ASCII 编码，同理，我们可以在网上找到相应的脚本并运行（过程省略）  

最终，我们得到 ASCII 编码如下：

![](../Images/bda3f8774399d55fe5b295c3a087698a.png)

如果之前做过 base64 编码的题目，这里应该能看出要进行 base64 编码转图片（当然，这里面向新人，我们就假设已经知道了这个编码），在网上找个能够在线将 base64 编码转图片的网站，然后得到了下面这张图片：  

![](../Images/ae1888b3265278274c328a00fae04cdd.png)

居然又是皮卡丘！好耶ヽ(✿ﾟ▽ﾟ)ノ，经过了这么长时间的操作，我相信大家也累了，不要着急，接下来就是最后一步了！这张图片很明显是隐藏了下半部分的，所以它的考点是图片高度隐写，我使用 Winhex 软件调整图片的高度（Winhex 是一个能够直接修改软件二进制文件的神器），图片中的 01 9B（十六进制）代表了图片的高度，我们将它改成 02 9B 也就能直接改变图片的高度  

![](../Images/7f92304d2ef791084b3c3bc61006af06.png)

终于！！！我们得到了完整的图片，图片下方就是 flag，把它提交给主办方就代表完成了这道题，实在是太不容易了 /(ㄒoㄒ)/~~  

![](../Images/719c6355ab5d66781f056bb3b28147c3.png)

怎么样 (●'◡'●)，相信你看完了这道题的全程解法，对于 Misc 一定有了自己的认知了吧，虽然过程比较繁琐，但是总体还是非常有趣的，对不对！而且在比赛中，自己解题得到 flag 的那一刻，无论是谁，一定是非常满足的，所以 CTF 也是能使人充实的一个比赛呀
