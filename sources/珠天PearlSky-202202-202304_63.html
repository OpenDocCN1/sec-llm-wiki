patchelf&glibc-all-in-one

PWN的时候会经常遇到本地与远程libc版本不同问题
需要用这个解决

  1. git clone https://github.com/NixOS/patchelf
  2. sudo apt-get install autoconf automake libtool
  3. sudo apt-get install libffi-dev
  4. ./bootstrap.sh
  5. ./configure
  6. make
  7. make check
  8. sudo make install

  10. git clone https://github.com/matrix1001/glibc-all-in-one
  11. #需要到的`GLIBC`通过`glibc-all-in-one`下载

  13. #生成符号链接
  14. cd 到lib 或 lib64
  15. sudo ln -s ~/glibc-all-in-one/libs/2.23-0ubuntu3_i386/ld-2.23.so ./23_3-linux.so.2
  16. patchelf --set-interpreter /lib/23_3-linux.so.2./pwn
  17. patchelf --replace-needed libc.so.6/home/seveng0/glibc-all-in-one/libs/2.23-0ubuntu3_i386/libc-2.23.so ./pwn
