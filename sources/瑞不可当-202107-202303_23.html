一、网络空间测绘

1.基本概念

网络空间测绘通过搜索引擎技术来提供交互，让人们可以方便的搜索到网络空间上的设备。用主动或被动探测的方法，来绘制网络空间上设备的网络节点和网络连接关系图，及各设备的画像。网络空间测绘的目标是实现对来源众多、类型各异的网络空间资源的全面测绘，是实现网络空间资产摸底、落实“摸清家底”要求的重要手段和方法，是网络空间有效治理的前提条件。通过定期对范围内的网络空间进行持续性扫描，对关注范围内的网络资产设施进行普查，绘制网络空间地图，摸清网络空间各种信息资产（实体和虚拟资产）。

2.技术原理

网络空间测绘技术的主要技术手段和重要功能组成是网络空间资产探测，即测绘技术中的“测”。网络空间资产探测从探测机理上主要分为主动探测和被动探测两种手段。目前网络空间资产探测以主动探测为主，基本技术思路是利用探测扫描引擎，针对网络空间中的IP和域名节点，采取一定的策略进行协议交互，对目标回包进行分析，进而发现目标资产的端口、服务、设备型号、操作系统、应用组件等信息。被动探测目前在网络空间资产探测上处于辅助补充地位，基本技术思路是利用流量分析引擎，处理网络核心路由器和交换机等流量关口的汇聚流量，对其进行协议解析，进而识别资产相关信息。

3.网络空间测绘的作用

3.1 攻防演练

攻防演练通常是在真实网络环境下对参演单位目标系统进行全程可控、可审计的实战攻击，通过演练检验参演单位的安全防护和应急处置能力，提高网络安全的综合防控能力。而网络空间测绘在攻防演练中可以起到以下作用：一是为攻击方提供网络空间侦察手段，绘制作战地图，辅助完成攻击路径选择、攻击战法运用和攻击手段决策。运用主动探测手段，获取目标节点资产信息，对其网络的安全情况进行探测摸底，在此基础上绘制出攻击者视角网络空间地图，帮助攻击团队根据地图决定重点攻击方向、挑选主要攻击目标和采取相应攻击手段；二是为防守方提供网络空间监控手段，绘制防守地图，辅助完成事前摸底排查、事中检测监控和事后响应处置。运用主动探测和被动探测手段，二者结合对所属网络资产和安全情况进行全面摸底，帮助防守团队根据地图进行事前摸底排查，开展暴露面收敛、升级加固等工作，同时提供事中检测监控和事后响应处置的基础数据支撑；三是为导演组织方提供网络靶场态势监控手段，实现网络靶场全景信息掌握。运用主动探测和被动探测手段，二者结合对整个网络靶场的资产和安全情况进行全面摸底，并记录其变化情况，同时融合其他业务系统的数据，为导演组织方提供网络靶场整体全景信息地图。
3.2 应急响应

应急响应是在对网络安全态势、组织的网络系统运行情况和面临安全威胁有清楚的认识下，在管理、技术和人员方面进行计划和准备，当网络安全事件突发时，能够有序应对并妥善处理，降低组织的损失，并能够改进网络安全突发事件的策略和计划。应急响应的第一步就是明确资产的范围。如何最大化的去收集资产范围，尽可能的收集到子域名及相关域名的信息以及一些被遗忘的“资产”，这对后续工作显得尤为重要。通过网络空间探测引擎能够快速进行网络资产匹配，较为全面的收集目标单位的资产范围。通过全面掌握资产范围可以在遭受到攻击时准确快速定位受到攻击的资产，并在后续抑制和根除阶段对目标单位相同相似资产进行整改以确保不会出现类似事件。

3.3 漏洞挖掘

漏洞挖掘技术是指对未知漏洞的探索，综合应用各种技术和工具，尽可能地找出目标中的潜在漏洞，一个多种漏洞挖掘分析技术相互结合、共同使用和优势互补的过程。对一个网站挖掘的深浅来说很大程度取决于信息收集的如何，这说明信息收集在漏洞挖掘中是非常的重要的。而网络空间测绘使得资产搜集、目标信息获取更加全面且高效；不仅如此，网络空间测绘还能够批量收集脆弱资产(0day/1day) 影响内的设备、终端等，使技术人员能够针对某一特定漏洞对多个目标进行漏洞挖掘。

二、FOFA简介

FOFA（网络空间资产检索系统）是白帽汇推出的一款网络空间搜索引擎，它通过网络空间测绘帮助研究人员或企业迅速进行网络资产匹配，实现漏洞影响范围分析、应用分布统计、应用流行度排名统计等目标。其是世界上数据覆盖更完整的IT设备搜索引擎，拥有全球联网IT设备更全的DNA信息。

网络空间测绘指对网络空间中的各类虚实资源及其属性进行探测、分析和绘制的全过程，FOFA的测绘基于端口扫描，底层原理由全网扫描及各种指纹识别的脚本和规则来进行维护，主要基于IP、端口、指纹、部分域名子域名的关系数据库。深入理解FOFA的工作机制有助于对其更好地使用，接下来将对FOFA进行更进一步分析。

FOFA可以从不同维度搜索网络组件，例如地区，端口号，网络服务，操作系统，网络协议等等。目前FOFA支持了多个网络组件的指纹识别，包括建站模块、分享模块、各种开发框架、安全监测平台、项目管理系统、企业管理系统、视频监控系统、站长平台、电商系统、广告联盟、前端库、路由器、SSL证书、服务器管理系统、CDN、Web服务器、WAF、CMS等等。

三、FOFA查询语法

1.搜索页面标题中含有“登录”关键词的网站和IP

title="登录"

2.搜索http响应头中包含thinkphp的网站和IP

header="thinkphp"

3.搜索html正文中包含thinkphp的网站和IP

body="thinkphp"

4.搜索某个IP或IP段

ip="47.107.44.152"

ip="47.107.44.152/24"

5.搜索开启80端口的IP

port="80"

6.搜索根域名带有baidu.com的网站

domain="baidu.com"

7.搜索域名中带有"login"关键词的网站

host="login"

8.搜索IIS 10服务器

server="Microsoft-IIS/10"

9.逻辑运算符

&&    表示逻辑与

||    表示逻辑或

通过逻辑运算符可以将多个搜索条件连接在一起从而提高结果的精准度。

搜索IP位于中国的IIS 10服务器

server="Microsoft-IIS/10"&& country="CN"

四、FOFA与其他网络空间搜索引擎对比
1.FOFA

FOFA是国内安全公司白帽汇推出的网络空间测绘引擎。它的优点比较鲜明，其使用次数较多，对资产的特征收集的比较完善，语法也比较完善。Fofa还支持图标搜索，功能相较于其他的搜素引擎更加完善。值得一提的是，Fofa还新推出了蜜罐识别功能，在攻防演练中对红队比较友好。由于其使用的人数比较多，这样每当有新漏洞出现时，相关的复现文章都喜欢放上一个Fofadork，这样就可以快速的找到符合条件的可能有漏洞资产。由此可见，Fofa的漏洞相关性非常好，符合快速复现漏洞的需求。

当然Fofa也不是十全十美。其最终呈现的资产重复较多。有的时候资产的域名可能不同，但是 ip 地址是一个，容易导致在复现漏洞的时候产生冗余。

2.Zoomeye

Zoomeye 是知道创宇推出的国内最早的空间测绘引擎。其优点在于搜索界面就可以主观显示出IP地址和地理位置；缺点在于其缺少对于域名的相关展示以及对域名的搜索不是很友好。

3.Shodan

Shodan俗称黑谷歌，国外的网络空间搜索引擎。其结果展示的全面，能够直观反应各种信息；缺点在于国内访问受限，且有搜索限额。就算你有谷歌账号、微软账号也是有搜索限额。

4.Sumap

Sumap是雷神众测实验室中的一款空间搜索引擎。优势在于其详情页可以查看某一台主机的详细指纹和信息，还可以免费下载 Json 格式的数据；缺点就是缺少api 查询量，单次只能查看 100 条，搜索数量不多不少。

5.Censys

Censys 是一款免费的搜索引擎，最初由密歇根大学的研究人员在 10 月发行，目前由谷歌提供支持。其结果展示比较友好，ip 和域名，指纹，端口，系统，协议，地理位置等可以有个直观的展示。网站查询结果可以达到 1000 条。只是这一点就超过国内很多的搜索引擎了；缺点在于语法比较复杂，上手难度大。所以说对新手不是很友好。
