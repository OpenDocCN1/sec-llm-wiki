1.当接到某个项目进行渗透测试时，我个人比较偏向小程序，当我打开小程序点击其他功能点的时候发现参数被进行加密了。  

![](../Images/03f29986c77c385156b19f78420a02d8.png)

2.对小程序进行反编译后得到小程序的前端代码，使用小程序开发者工具进行查找搜索encrypt参数,先看app.js成功定位到encrypt。ps(为什么先看APP.js，因为其他那些是引用的库)  

![](../Images/7961abd0f4ba509e8898de35a377d66a.png)

3.跟进 o，o是A6F17FD27F6C38AFC09717D525323F76.js  

![](../Images/e73ba962fddd7efd1a646e23deab9355.png)

4.找到 A6F17FD27F6C38AFC09717D525323F76.js 中的encrypt  

![](../Images/03f1c3452ceca90680588043e64d7dce.png)

5.成功找到加密方法：  

```


   r.encrypt = function(t,e,i) {
```

![](../Images/be435e233e51cb32547f0d674da7735f.png)  

6.现在得到的信息有：

aes加密，cbc模式，pkcs7填充

aes解密函数第一个参数s是明文，第二个参数e是密钥，i是iv

跟进e，发现e是传进来的

那就只能搜一下key试试看看

  

![](../Images/c29900c0b991a61c67b7890f61a0b82b.png)

7.继续 跟进n，看一下1F03AD467F6C38AF7965C541D7123F76.js  

![](../Images/e7d11b5bf9dddc07a44f055f01da2bae.png)

8.成功找到key和iv值

  

![](../Images/1a283b9a3083165ee844d4c0e904481f.png)

9.剩下就是拉出来js文件调试；成功解密出密文。  

![](../Images/b151df1f69806010f6d912477f151d8e.png)

解密成功密文后接下来跟常规渗透测试无区别了。
