**0****7**安装  
  

这里未来方便同学们我将需要的包都打包在-->requirements.txt

```
pip3 install \-r requirements.txt \-i https://pypi.mirrors.ustc.edu.cn/simple/
```

我们需要配置一下config.json文件，需要添加2条Cookie文件,分别是IP138与爱企查的Cookie（无需登陆）

![](../Images/b57015938d578c261ebaddae25694ed7.png)![](../Images/283757ec7bb3e35aa8131346190a0f2a.png)

可以使用浏览器无痕模式访问

```
https://baike.baidu.com/item/企业名称
随便那个企业都行，出现如下图即可
```

![](../Images/6c2ab5c80348c61e43a44e667f1a4c9c.png)

使用F12大法抓到他的流量

![](../Images/073aef9fceb4de2ffe8d07bc9d81ff4f.png)

这里重点要提醒一下，爱企查的Cookie有个坑，就是其中有个数值使用的是"我们需要改成'

![](../Images/3affe95f88a990f64fcddc9100385356.png)

第二个Cookie访问，这里就直接F12进行复制走就行

```
https://www.ip138.com/
```

![](../Images/25da06721d585ecc681904dd9bb0078e.png)

安装成功之后就可以使用

```
python3 Ipconfig-V2.py -h  
```

![](../Images/fe5b7425a25962e24cca1980914d23e9.png)
