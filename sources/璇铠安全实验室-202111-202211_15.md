**1**漏洞描述**0**

Django是一个由Python写成的Web应用框架.

Django 组件存在 SQL 注入漏洞，该漏洞是由于对 QuerySet数据合集的order\_by函数存在SQL注入漏洞.攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行 SQL 注入攻击，最终造成服务器敏感信息泄露.

  

**2**漏洞分析**1**QuerySet与order\_by关系  
Django内置了一个ORM框架，从数据库查询出来的结果是一个合集，这个合集就是QuerySet.  
order\_by,将查询出来的结果按照某字段的值，由小到大或由大到小进行排序

### ![](../Images/2d22548c4e43988c09e620f8af7753a7.png)vul函数获取GET提交默认值ID，然后使用order\_by大到小的排列.使用values()函数将数据合集转化成一个个json的数据格式返回.

![](../Images/bd4e1d9fbbf21373aabb5722c9ed33c9.png)

查看Collection具体做了什么


做了 一些过滤

当用户输入的字段中带了点'id.'，就会跳出循环进入到\_fetch\_all中，这个时候会进行SQL查询造成SQL注入

updatexml报错注入原理  

concat()数用于连接两个字符串，形成一个字符串，因此不会符合XPath\_string的格式，因此会造成格式错误  

  

0x7e ASCII码，实为~，updatexml报错为特殊字符、字母及之后的内容，为了防止前面的字母丢失，开头连接一个特殊字符
