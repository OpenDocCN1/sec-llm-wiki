frida-server安装

首先要下载frida-server，不过我这边在上面链接当中已经存在frida-server


上传frida-server


这边推荐一手adb的上传，下载，安装工具
电脑文件地址使用（C:\frida-server）    手机文件地址使用（/data/local/tmp）手机文件地址建议不要改动，其他可能没有权限
从电脑上传到手机上
adb push C:\frida-server /data/local/tmp/frida-server     *这一步是重要操作

下面都是使用手册科普一下

从手机上传到电脑上
adb pull /data/local/tmp/frida-server C:\frida-server
安装APK到手机上
adb install C:\frida-server.apk
如果手机上已经有了可能会报错，如果还想安装使用这个将会覆盖安装
adb insatll -r C:\frida-server.apk
如果有多台手机同时链接那这边方法是
adb.exe devices      //查看是否有链接的设备  
List of devices attached
HT7BP1A03420    device  //PE1
HT7BP1A03110    device  //PE2

adb -s HT7BP1A03110 insatll -r C:\frida-server.apk   //选择PE2进行安装

启动frida-server


adb shell                            //进入设备
$ su                                 //提升权限
# cd /data/local/tmp/                //进入目录
# chmod +x ./frida-server            //给执行权限
# ./frida-server                     //执行frida-server

frida-server运行监测


adb forward tcp:27043 tcp:27043    //开启监听
adb forward tcp:27042 tcp:27042    //开启监听
frida-ps -U                        //测试PS

7.报错问题解决

7.报错问题解决
1
出现了SyntaxError：invalid syntax问题

答：这种情况可能是python环境不行，建议重新安装python


2
出现了'drozer' 不是内部或外部命令，也不是可运行的程序或批处理文件。

答：这里就是可能安装时候没有在Scripts文件当中建立drozer.bat,我们可以手动建立


@echo off

python2 "%~dp0drozer" %*

3
出现SyntaxError: Missing parentheses in call to 'print'. Did you mean print("usage: drozer [COMMAND]")?

答：你可能没有改东西，他变成了python3了，建议修改Scripts文件当中的drozer.bat
