仅作为安全学习使用切勿到真实国内环境测试！**1**漏洞描述

Aria2是一个命令行下轻量级、多协议、多来源的下载工具（支持 HTTP/HTTPS、FTP、BitTorrent、Metalink），内建XML-RPC和JSON-RPC接口。在有权限的情况下，我们可以使用RPC接口来操作aria2来下载文件，将文件下载至任意目录，造成一个任意文件写入漏洞  

**2**漏洞原理

![](../Images/aa9e7ede4d2dc365347330e862c31329.png)

**3**复现机器版本

靶机：centos7: Docker version 20.10.11

靶机IP：192.168.10.129

攻击机：ubuntu18.04

攻击机IP：192.168.10.128

**4**漏洞复现

打开靶场：

`cd /vulhub/aria2/rce`

run:

`docker-compose up -d`

查看是否开启容器：

`docker ps`

![](../Images/d80278a2caab94b4c53cccc9403e3a54.png)

  

![](../Images/ed1215c4bc0b2297a2befa9612dd0f14.png)**5**漏洞利用

`http://binux.github.io/yaaw/demo/`

打开yaaw，配置，填入运行aria2的目标域名：

`http://192.168.10.129:6800/jsonrpc`

![](../Images/b18d4e7bd756e0f349cb86500366d3f4.png)

在test中写入

`hello hacker`

  

首先需要搭建一个网站

这里可以使用python搭建临时网站

`python3 -m http.server 8000`

![](../Images/c8fdcc382d52f56188ff5a4fac565b67.png)

访问页面，可以正常下载文件

![](../Images/5c5844aa0b252eb61d8a035cd369ec5c.png)

添加一个下载任务，设置好下载链接，这里将反弹文件下载到/etc/cron.d/下，文件名为hacker，/etc/cron.d目录下的所有文件将被作为计划任务配置文件读取

![](../Images/9874e70b8f38ace707c9a1586f58bb59.png)

  

![](../Images/f60f41427599bf69b940c51e0e8c44f2.png)

进入容器查看一下是否写入成功

同理这里可以写反弹shell，拿到服务器的shell

最后关闭靶机

`docker-compose down`
