安装步骤

1
在官网下载需要的版本，这本是拿去一个最新的版本metasploit-framework-6.1.15+20211114112823


本人下载的安装包
https://osx.metasploit.com/metasploit-framework-6.1.15%2B20211114112823-1rapid7-1.pkg
当然你也可以自己选择
https://osx.metasploit.com/

2
下载之后就按照一步步的安装，这里推荐都同意，最好不要修改任何路径地址，修改了后门代码可能也要修改


3
接下来我们执行命令，进入msf的配置文件当中


cd /opt/metasploit-framework/bin/

4
首先最重要的先安装好数据库


./msfdb init
刚开始会出现这个文件，大家别惊慌，我们看到最后

出现了这两条，输入yes就好了
[?] Would you like to init the webservice? (Not Required) [no]: yes
[?] Would you like to delete your existing data and configurations? []: yes
接下来,是输入web端的账号和密码
[?] Initial MSF web service account username? [vul]: msf    //用户名
[?] Initial MSF web service account password? (Leave blank for random password):   //密码这里密码不会显示出来，但是你肯定是输入的
最后可能会安装不成功如下图

这时候我们不用担心，在输入一次
./msfdb reinit
依旧重复上面步骤
[?] Would you like to init the webservice? (Not Required) [no]: yes
[?] Would you like to delete your existing data and configurations? []: yes
接下来,是输入web端的账号和密码
[?] Initial MSF web service account username? [vul]: msf    //用户名
[?] Initial MSF web service account password? (Leave blank for random password):   //密码这里密码不会显示出来，但是你肯定是输入的
最终出现，下图界面就安装成功
