环境配置

4
配置流程


正常安装

安装好Kali系统，在kali系统启动Parallels Tools，点击黄色感叹号，选择挂载


完成挂载

现在开始执行下面内容，基本上容易不成功。
有些机器是需要点击桌面的Parallels Tools从透明的变成白色，即成功挂载
sudu su                         #进入root权限
mkdir /root/pt                  #创建pt目录
cp -r /media/cdrom0/ /root/pt   #将安装复制到pt目录下
cd /root/pt/cdrom0目录下         #进入到安装包目录下
./install                       #执行安装程序


安装不成功

首先看看需要安装的3个包（上面那张图，是2021.2版本）
inux-headers-5.10.0-kali9-arm64
dkms
libelf-dev

Steps1

安装核心依赖（重要）

第一个依赖包需要手动下载三个deb安装包，在链接中下载三个包 http://http.kali.org/kali/pool/main/l/linux/

1.linux-headers-5.10.0-kali9-common_5.10.46-4kali1_all.deb (http://http.kali.org/kali/pool/main/l/linux/linux-headers-5.10.0-kali9-common_5.10.46-4kali1_all.deb)

2.linux-headers-5.10.0-kali9-arm64_5.10.46-4kali1_arm64.deb(http://http.kali.org/kali/pool/main/l/linux/linux-headers-5.10.0-kali9-arm64_5.10.46-4kali1_arm64.deb)

3.linux-kbuild-5.10_5.10.46-4kali1_arm64.deb(http://http.kali.org/kali/pool/main/l/linux/linux-kbuild-5.10_5.10.46-4kali1_arm64.deb)


Steps2

安装依赖包

我建议这样的安装顺序，如果安装没按照这个顺序来可以向下看补救，按照下图出现则安装成功，也可以用命令看是否成功

sudo dpkg -i linux-headers-5.10.0-kali9-common_5.10.46-4kali1_all.deb
sudo dpkg -i linux-kbuild-5.10_5.10.46-4kali1_arm64.deb
sudo dpkg -i linux-headers-5.10.0-kali9-arm64_5.10.46-4kali1_arm64.deb

检验是否成功

apt install linux-headers-$(uname -r) #检验是否成功


Steps3

报错补救

要是出现安装包发送错误不用慌再次执行，进行卸载重装

apt --fix-broken install

在重新进行安装

sudo dpkg -i linux-kbuild-5.10_5.10.46-4kali1_arm64.deb
sudo dpkg -i linux-headers-5.10.0-kali9-arm64_5.10.46-4kali1_arm64.deb

Steps4

安装dkms、依赖包（手动安装）
可以选择自动安装直接跳到第五步骤
apt install dkms
apt install libelf-dev


Steps5

安装Parallels Tools安装包
出现下图画面就是安装成功啦
sudu su                         #进入root权限
mkdir /root/pt                  #创建pt目录
cp -r /media/cdrom0/ /root/pt   #将安装复制到pt目录下
cd /root/pt/cdrom0目录下         #进入到安装包目录下
./install                       #执行安装程序
