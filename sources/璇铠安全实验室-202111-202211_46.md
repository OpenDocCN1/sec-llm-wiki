**4**配置流程  
  
正常安装  
安装好Kali系统，在kali系统启动Parallels Tools，点击黄色感叹号，选择挂载

![](../Images/033b648f6d6405f0b92d4cccbd02e442.png)

  
完成挂载  
现在开始执行下面内容，基本上容易不成功。

```


有些机器是需要点击桌面的Parallels Tools从透明的变成白色，即成功挂载
```

![](../Images/48279598f996a473f62cb57e60b225fe.png)

  
安装不成功  
首先看看需要安装的3个包（上面那张图，是2021.2版本）

```


inux-headers-5.10.0-kali9-arm64
```

  
Steps1  
安装核心依赖（重要）

> 第一个依赖包需要手动下载三个deb安装包，在链接中下载三个包 http://http.kali.org/kali/pool/main/l/linux/
> 
> 1.linux-headers-5.10.0-kali9-common\_5.10.46-4kali1\_all.deb (http://http.kali.org/kali/pool/main/l/linux/linux-headers-5.10.0-kali9-common\_5.10.46-4kali1\_all.deb)
> 
> 2.linux-headers-5.10.0-kali9-arm64\_5.10.46-4kali1\_arm64.deb(http://http.kali.org/kali/pool/main/l/linux/linux-headers-5.10.0-kali9-arm64\_5.10.46-4kali1\_arm64.deb)
> 
> 3.linux-kbuild-5.10\_5.10.46-4kali1\_arm64.deb(http://http.kali.org/kali/pool/main/l/linux/linux-kbuild-5.10\_5.10.46-4kali1\_arm64.deb)

![](../Images/6047e0895cb2bdef193cfa843a2d0c98.png)

![](../Images/44f3379d9fc6eafca560531acb8dc5de.png)

  
Steps2  
安装依赖包

我建议这样的安装顺序，如果安装没按照这个顺序来可以向下看补救，按照下图出现则安装成功，也可以用命令看是否成功

```


sudo dpkg -i linux-headers-5.10.0-kali9-common\_5.10.46-4kali1\_all.deb
```

![](../Images/da75f1996732c23a4a48f26be0085260.png)

![](../Images/94d9f003bbf5ed7e5f8cafc10d489e6c.png)

检验是否成功

```
apt install linux-headers-$(uname -r) #检验是否成功
```

![](../Images/e55ed0d36315dc7625bc43b02da65a94.png)

  
Steps3  
报错补救

要是出现安装包发送错误不用慌再次执行，进行卸载重装

![](../Images/0651e36a68b75f93fdf2d8e9a6e8091b.png)

![](../Images/30dfd05981194be26148967817c5849f.png)

```
apt --fix-broken install
```

![](../Images/3e1ed0afa1fd682758d36d502daf4d49.png)

在重新进行安装

```

sudo dpkg -i linux-kbuild-5.10\_5.10.46-4kali1\_arm64.deb
```

  
Steps4  
安装dkms、依赖包（手动安装）

```
可以选择自动安装直接跳到第五步骤
```
