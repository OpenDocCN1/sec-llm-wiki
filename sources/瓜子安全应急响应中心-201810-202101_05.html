亮点三：资深作者在线直播

2020年7月22日晚20：00，我们邀请到了安全客资深作者lengyi为大家带来主题“WMI攻击与防御”。WMI就是 Windows Management Instrumentation（Windows 管理规范）。它是 Windows 中的一个核心管理技术。WMI 为访问大量的 Windows 管理数据和方法的提供了一个统一的机制。其方便性被攻击者所青睐，直播我们就为大家揭开wmi的面纱。干货满满，不容错过！
