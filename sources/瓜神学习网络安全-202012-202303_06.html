00X00 前言

官方给出的安装方式apt install scrcpy，但是经过各种换源操作啥的依然报错

┌──(root㉿kali)-[~/桌面]
└─# apt install scrcpy           
正在读取软件包列表... 完成
正在分析软件包的依赖关系树... 完成
正在读取状态信息... 完成                 
E: 无法定位软件包 scrcpy

00X01 解决报错并安装

网上找了半天解决方式都没有成功，最终参考链接如下https://unix.stackexchange.com/questions/630757/kali-linux-issue-while-downloading-scrcpy

sudo apt update
sudo apt install snapd
systemctl restart snapd.service
sudo snap install core
sudo systemctl unmask snapd
sudo systemctl enable --now snapd
sudo snap install scrcpy
echo "alias scrcpy='/snap/bin/scrcpy'" >> ~/.zshrc
source ~/.zshrc
scrcpy

00X02 安装ADB

通过apt-get安装adb
命令

sudo apt-get install android-tools-adb

查看adb是否安装成功

adb version

00X02 启动

1、启动adb服务

#启动adb服务
adb start-server
#查看usb
lsusb


2、手机打开开发者模式，打开usb调试

2、启动scrcpy

adb devices
scrcpy
