# 00X00 注册步骤

1、进入官网后，点击注册按钮。  
2、点击创建账号。  
3、输入自己的邮箱账号。  
4、设置密码。  
5、完成后会进入这样的界面。  
6、点击进行邮件验证。  
7、填写名和姓，下方的组织选填。
