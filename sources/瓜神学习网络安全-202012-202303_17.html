00x01卸载nginx

sudo apt-get remove nginx nginx-common # 卸载删除除了配置文件以外的所有文件。

sudo apt-get purge nginx nginx-common # 卸载所有东东，包括删除配置文件。

sudo apt-get autoremove # 在上面命令结束后执行，主要是卸载删除Nginx的不再被使用的依赖包。

sudo apt-get remove nginx-full nginx-common #卸载删除两个主要的包。

sudo service nginx restart  #重启nginx

00x02下载nginx 1.14.1稳定版本

nginx官网1.14.1稳定版本tar.gz包。

http://nginx.org/download/nginx-1.14.1.tar.gz

00x03安装

1、解压安装

tar -zxvf nginx-1.14.1.tar.gz
$ cd nginx-1.14.1
$ ./configure --prefix=/usr/local/nginx --with-http_ssl_module

2、注意：

1、出现下面等一些报错，报错哪个就安装哪个

解决

sudo apt-get install libpcre3 libpcre3-dev

其他可能遇到的

 sudo apt-get install openssl libssl-dev进行安装openssl 依赖包，这只是Ubuntu的安装命令，
 centOS的安装命令是yum -y install openssl openssl-devel

3、make安装

make
make install

4、备份

cp /usr/local/nginx/sbin/nginx /usr/local/nginx/sbin/nginx_bak

5、启动

#启动
/usr/local/nginx/sbin/nginx -c /usr/local/nginx/conf/nginx.conf

6、nginx-V检查

/usr/local/nginx/sbin/nginx -V

成功

nginx 被安装在 /usr/local/nginx 下
启动

/usr/local/nginx/sbin/nginx

停止

/usr/local/nginx/sbin/nginx -s stop

重启

/usr/local/nginx/sbin/nginx -s reload

00x04添加https配置

1、在/usr/local/nginx/conf文件夹下新建一个文件夹cert，放入证书文件。
3、修改/usr/local/nginx/conf/nginx.conf文件，添加80跳转443
3、修改/usr/local/nginx/conf/nginx.conf文件，在文件中加入https配置。

    server {
 
        listen	80;
		server_name www.yourdomain.com;
	    rewrite ^(.*) https://$server_name$1 permanent; #http 跳转 https
    }
server {
        listen 443;
        server_name localhost;
        ssl on;
        ssl_certificate   cert/214070724490639.pem;
        ssl_certificate_key  cert/214070724490639.key;
        ssl_session_timeout 5m;
        location / {
             proxy_redirect off;
             proxy_set_header Host $host;
             proxy_set_header X-Real-IP $remote_addr;
             proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
             proxy_pass http://localhost/;
        }
    }
