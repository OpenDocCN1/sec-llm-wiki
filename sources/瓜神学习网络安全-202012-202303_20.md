说明：

```
MySQL数据库安装目录：C:
```

MySQL数据库备份目录：C:\\MySQLdata\_Bak

实现目的：  
备份MySQL数据库存放目录中的mysql数据库到C:\\MySQLdata\_Bak目录，按照日期存放，

并且只保留最近7天的数据

例如：

```
C:
```

1、把下面的文件保存为：mysql\_bak.bat 放到C:\\MySQLdata\_Bak\\目录中.  
如：`C:\MySQLdata_Bak\mysql_bak.bat`

## 1、mysql\_bak.bat :

```


@echo off
```

## 2、在Windows中打开，开始-设置-控制面板-计划任务，把上面的批处理文件添加到任务计划中，设置每天某时间执行。
