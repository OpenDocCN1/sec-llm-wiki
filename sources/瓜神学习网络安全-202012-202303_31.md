## 一、开启USB调试

\*\*  
在 开发人员选项 打开 USB调试，USB连接手机  
我用的是小米手机  
开启方法是 `“设置”->“我的设备”->“全部参数”->点击7下MIUI版本，开启“开发者选项”。然后在 “设置”->“更多设置”->“开发者选项” 中同时开启 USB调试 和 USB调试(安全设置)。`

![](../Images/48e978c2b708303bc85f6918a7b96777.png)  
![](../Images/495aec919caa9682176c708b1bdea912.png)

## 二、调试连接

\*\*  
1、把下载的文件夹解压到无中文路径下  
2、在空白处`shift+鼠标右键`打开`powershell`窗口

![](../Images/c7fc2089208dbb4edac1488cff640943.png)  
3、手机通过USB连接电脑  
4、运行 `adb usb`  
![](../Images/a63a0454e10e7bd7046b69cbf13c5f80.png)  
4、运行`scrcpy.exe`  
![](../Images/ff7d6ebef7b32e7282707eef106d7ff3.png)  
\*\*

## 三、无线连接

\*\*  
此连接方式更加方便快捷，若宽带速率高，使用效果更佳，使用方法也非常简单。

确保PC和手机在同一Wifi中  
手机先通过USB与PC相连

```

在PC上运行 adb tcpip 服务端口，如端口为8888
```

```

adb tcpip   8888
```

![](../Images/41e8004bafc6cbc28495f4e12b96ea37.png)  
拔下你的设备，断开USB连接  
在PC上运行 adb connect 手机IP:服务端口（手机IP可通过手机的状态信息查看，或者登录路由器查看，一般以192.168开头）

![](../Images/0fafd322bc33b1dea48bf4e53e5231ca.png)

```

adb connect  192.168.1.101
```

![](../Images/781af5b494542b0e7ba0cebba7c257df.png)  
执行`scrcpy.exe`
