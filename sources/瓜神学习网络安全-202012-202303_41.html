Apache Druid 命令执行漏洞（CVE-2021-25646）

原文：http://mp.weixin.qq.com/s?__biz=MzkwODE4ODUzMg==&mid=2247484051&idx=1&sn=5ebe6a2f301905dff144dcd41acadbac&chksm=c0cc8c88f7bb059e43880a451770faf56fa7cbfda94c195871a7089371e52c53452f8e3ee240&scene=126&sessionid=1681664455#rd

漏洞描述

Apache Druid包括执行用户提供的JavaScript的功能嵌入在各种类型请求中的代码。此功能在用于高信任度环境中，默认已被禁用。但是，在Druid 0.20.0及更低版本中，经过身份验证的用户发送恶意请求，利用Apache Druid漏洞可以执行任意代码。攻击者可直接构造恶意请求执行任意代码，控制服务器。


影响版本

Apache Druid < 0.20.1


漏洞环境

Docker环境

docker pull fokkodriesprong/docker-druid


docker run --rm -i -p 8888:8888 fokkodriesprong/docker-druid


访问验证 IP:8888   版本为0.15.1版本
