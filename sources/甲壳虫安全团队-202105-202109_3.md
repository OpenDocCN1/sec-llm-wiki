# PING命令

## 用法

ping \[-t\] 不断向目标发送数据包，直到强迫其停止

ping \[-a\] 将地址解析成主机名

ping \[-n count\] 定义向数据包发送的数据次数，可以判断目标IP是否存在

ping\[-l size\]  定义发送数据包的大小，默认32节，最大65500字节。

## ping ip -a

**ttl=128     windows 系统**

**ttl=64         linx系统**

## ping ip -t

时延低，说明网络状态良好。用了-t 主机会一直发送，直到强制退出。

## ping 网址

例如：ping www.baidu.com

## ping -t 与ping -l 连用      CTRl+C终止发送

# NESTAT

## 用法

**\-a ：查看本地开放端口**

**\-r：列出路由信息**

**\-b：显示创建每个连接或侦听端口时涉及的可执行程序（耗时长，限权不足会失败）**

**\-e：显示以太网统计**

**\-f：显示外部地址的完全域名**

**\-n：以数字形式显示地址和端口号**

**\-o：显示拥有的与每个关联的进程ID**

**\-t：显示连接或卸载状态**

**\-s：显示每个连接的统计**

**\-p proto：显示proto指定协议链接**

# NBTSTAT命令

## 用法

**nbtstat -a 远程主机机器名   得到NETBIOS信息**

**\-n 列出本地———信息**

\-A 需要知道ip 得到----信息

      -A列出为其IP地址提供的远程计算机名字表。  
　　-c列出包括了IP地址的远程名字高速缓存器。  
　　-n列出本地NetBIOS名字。  
　　-r列出通过广播和WINS解析的名字。  
　　-R消除和重新加载远程高速缓存器名字表。  
　　-S列出有目的地IP地址的会话表。  
　　-s列出会话表对话。  
　　NBTSTAT生成的列标题具有以下含义：  
　　Input  
　　接收到的字节数。  
　　Output  
　　发出的字节数。
