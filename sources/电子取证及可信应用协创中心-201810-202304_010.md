# 大数据助推公安工作提质增效

**本文由****湖北****警官学院20级网安孙培博同学编写****，转载请注明。****大数据是当代互联网技术快速发展的产物，对新时代公安工作具有极其重要的“提质增效”作用。自从看到了赵克志部长在全国公安厅局长会议上作出****的****“大力实施公安大数据战略，着力打造数据警务、建设智慧公安”重要指示****后，“大数据对公安工作的影响究竟有多少”的疑问在我头脑中久久萦绕。**

![](../Images/2d9b461902e964595e8cc2398aac16a7.png)

**为此，从我有限的大数据知识和暑假公安见习实践经验，结合上课所学和暑假补学的大数据知识出发，谈一谈我对公安工作结合大数据的浅薄看法。**

**一、****数据必须要融合**

**数据融合是以产生决策智能为目标，将多种数据源中的相关数据提取、融合、梳理整合成一个分析数据集，为接下来的数据挖掘等技术打下坚实基础，因此数据融合是第一关。纵观现实，公安视频网、公安信息网、电子政务网、互联网之间仍存在部分分裂。我认为只有实现更大程度的“四网融合”，才能让“视频监控、AR实景、高清抓拍、人像比对、以图搜图、wifi嗅探”等的子功能更大程度地发挥作用。****    我畅想一下，当数据融合达到一定程度后，大数据平台将实时全面地在线获取本地医疗、住建、交通、民政等社会外源数据，然后融合警务数据、物联感知数据等，进行深度关联，并通过数据汇聚、治理、挖掘后，为上层各类平台应用及模型开发提供数据调用接口。平台将依托强大的数据汇聚和治理能力,实现将人脸、人体、车辆等物联感知数据和警务数据、外源数据有效融合，支撑民警对人、事、物开展全方位、立体化研判分析的任务。**

**二、大数据要接轨实战**

**大数据平台应从打防管控和社会治理等实战出发，实现云端接口的实时访问，以及数据库实时对接功能，确保案件、车辆、驾驶人员、在逃人员等数据的鲜活性。通过完善物联应用模块，将车、人等轨迹数据与各类静态基础数据进行融合式分析，从而深度挖掘在智慧维稳、智慧侦查、智慧交通、智慧监管、智慧管理、智慧服务中的应用潜能。****大数据平台通过对智慧小区业主信息、暂住人口、物联网感知数据、水电煤外源数据等的融合应用，可精准发现未办理居住证的外来务工人员、群租房、涉毒人员聚集等情况。利用标签碰撞功能，对教师职工、公交司机、医疗工作者进行人员背景分析筛查，可快速核查肇事肇祸的精神病人、多次经济债务纠纷、家庭重大矛盾等风险，精准评估个人就职潜在风险因素，预防个人极端事件发生。****大数据平台的模型库也可以为一线实战部门提供强大的工具支撑。模型库提供快速检索、以人搜人、以车搜车、轨迹还原、串并案分析、预警推送等实战服务，在安保维稳、侦查破案、群众求助、风险防控、数据建模、社会治理等方面大有可为，可以在部分工作上实现提质增效。****大数据接轨实战，可以视频分析的应用中得到很多启发，见下图。**

**三、向科技要警力**

**我在见习期间发现，随着经济快速发展，新型犯罪和传统犯罪交织，公安部门，尤其是公安基层的任务日益繁重，警力却鲜有增长，导致警力不足成为困扰公安工作的难题。那么如何实现警力无增长改善呢，向科技要警力便是最优途径之一。****通过对这些有关公安大数据旳经历、学习、思考，我深深地感受到了大数据在公安工作中的巨大作用。在以后的学习和工作中，我要努力学习知识理论和实操技术，自觉将科学技术与具体业务紧密结合起来，立志做科技强警的先行者和实践者。**
