# Win10取证:使用FeatureUsage重构用户活动

我敢肯定，您已经听说过Windows 10中引入的一些功能，而且是对取证友好的功能。一个很好的例子是Windows 10时间轴。最近，我发现了另一个有用的功能，可以帮助法医分析师和事件响应者重建用户活动。它称为FeatureUsage。  

  

那么，它跟踪什么以及取证痕迹在哪里？例如，当用户运行固定到任务栏的应用程序时，它会跟踪与任务栏相关的事件。FeatureUsage位于NTUSER.DAT注册表文件中的以下项下：

  
NTUSER.DAT\\Software\\Microsoft\\Windows\\CurrentVersion\\Explorer\\FeatureUsage  

  

您可以在此键下找到一些子键：

  

![](../Images/82aad14c57f806f6e8481449769a909e.png)

*图1. FeatureUsage子项*  

让我们看一下每个子项：

  
AppBadgeUpdated。此子项跟踪任务栏上应用程序的徽章(用于突出显示新的或未读的项)更新。例如，如果您使用Telegram并收到新消息，则可以在应用程序的徽章上看到带有红色消息的红色图标。因此，在这里我们可以找到应用程序的路径和徽章更新的数量：

  

![](../Images/bbe3015d630391debb7d400224916590.png)

*图2.电报徽章更新的数量*  

AppLaunch。此子项记录应用程序的启动，这些应用程序固定在任务栏上。当然，不是每个用户都固定应用程序，但是如果每个人都固定应用程序，那么您将获得大量的数字证据：

  

![](../Images/cf0de0ca602be04c07c0be1af21aa6af.png)

*图3. Microsoft Edge启动计数*  

AppSwitched。当用户想要从一个切换到另一个时，此子项记录任务栏应用程序上的左键单击。从法医角度来看，此子项最为有趣，因为它可能包含大量记录，这可能是执行证据的来源：

  

![](../Images/b90e4fa38f14d1292f966c745e61aa93.png)

*图4. Mimikatz被执行的证据*  

ShowJumpView。此子项跟踪任务栏应用程序上的右键单击。用户可以这样做，例如，检查或打开最近的文件。这可能是指向最常用应用程序的附加工件：

  

![](../Images/5c5d4233d7654d6a3068b8787577c150.png)

*图5. Microsoft Word的ShowJumpList数据*  

TrayButtonClicked。此子项跟踪以下任务栏项目上的左键单击：ClockButton,StartButton,NotificationCenterButton 和 SearchButton。与前面的示例一样，您可以看到每个项目的点击次数：

  

![](../Images/961faa0f8451563b04a66fccef570304.png)

*图6.任务栏项目的点击次数*  

Windows注册表一直以来都是数字证据的良好来源，拥有另一个可能提供的有用人为痕迹资源始终是一件好事。有许多不同的执行证据来源，但这总是不够的，因为您将永远不知道在下一次法证检查或事件响应参与时在哪里可以找到关键的人为痕迹。
