1. EaseUS Date Recovery Wizard Free （Windows和Mac）

首先，EaseUS Data Recovery Wizard Free仅允许您免费恢复多达2GB的数据。因此，从技术上讲，它不是 免费的数据恢复软件。但是，我想在这里介绍它，因为EaseUS的恢复率是业内最高的，其Windows和Mac版本都在不断更新以支持新设备和数据丢失情况（最新版本是13.2）。
我在MacBook Pro上测试了该程序，试图从偶尔用于打印任务的32GB闪存驱动器中恢复那些丢失的PDF文件，并不时重新格式化设备以实现数据隐私目的。EaseUS表现出色！扫描过程非常快，因为仅用了5分钟左右的时间便显示了文件预览窗口。我可以无限制地预览每个文件的内容，由于重新格式化了驱动器，这可以帮助我快速找到已删除的PDF（经验教训：重新格式化磁盘不会立即擦除数据）。然后，我选择了这些PDF文件并单击“立即恢复”，这些文件已保存到我的桌面。我打开它们，它们的外观与从闪存驱动器中删除它们之前的样子完全相同。
我喜欢什么：
  • 扫描速度快，回收率高。
  • 擅长从格式化的磁盘或存储卡中检索数据。
  • 文件预览功能对于识别要恢复的丢失项目非常有用。
  • 它提供Windows和Mac版本。
我不喜欢的是：
  • 2GB的限制有点低。如今，照片和视频的文件大小越来越大。如果EaseUS将其设置为5GB，那就太好了。

2. PhotoRec（Windows / Mac / Linux）

PhotoRec由Christophe Grenier创建，是一个免费的开源文件恢复程序，几乎可以在所有操作系统上正常运行。PhotoRec不仅是照片恢复工具（不要被其名称所迷惑）。您可以使用此功能强大的软件从硬盘或可移动媒体恢复近500种不同的文件格式。这是有关如何逐步使用PhotoRec 的教程。
我喜欢什么：
  • 可在多种平台（Windows，macOS和Linux）上使用。
  • 由开发人员定期更新。
  • 强大的恢复功能，包括多种文件格式。
  • 它是开源的（已发布源代码）。
我不喜欢的地方：
  • 对用户不太友好，因为它使用命令行工具界面。
  • 您可能想从技术朋友那里获得一些帮助，以使其正常工作。

4. Lazesoft Recovery Suite Home  （Windows）

如果您正在寻找功能强大的Windows抢救解决方案，那么Lazesoft Recovery Suite 就是其中之一。除了从普通磁盘中恢复数据外，Lazesoft还附带了一组实用程序，当您忘记登录密码甚至无法启动时，它们可以挽救Windows系统。
注意：该软件有多个版本，但是只有Home Edition是免费的。
我喜欢什么：
  • 可以选择多种模式（取消删除，取消格式化，深度扫描）。
  • 能够在检索图片之前预览它们。
  • 其中包括许多超级有用的实用程序，包括密码恢复，Windows救援，磁盘克隆等。
我不喜欢的地方：
  • 下载有点慢。

5. Exif Untrasher（macOS）

Exif Untrasher是另一个在Mac（macOS 10.6或更高版本）上运行的完全免费的程序。它主要用于恢复从数码相机中删除的JPEG照片。如果您想从外部驱动器，USB记忆棒，SD卡等找回丢失的JPEG，也可以使用它，只要它是可以安装在Mac上的可移动磁盘即可。
我喜欢什么：
  • 易于下载和安装。
  • 快速准确地从我的相机SD卡中查找和恢复删除的照片。
  • 恢复的照片的质量非常好。
我不喜欢的地方：
  • 它仅适用于JPEG文件。
  • 无法恢复从内部Mac硬盘驱动器中删除的照片（尝试选择该音量时，您会注意到“ Macintosh HD”选项为灰色）。

6. TestDisk（Windows / Mac / Linux）

TestDisk是PhotoRec的姊妹程序，它是一种功能非常强大的分区恢复工具，旨在帮助发现已删除/丢失的分区，使崩溃的磁盘可再次启动以及更多其他功能。TestDisk就像是一位经验丰富的医生，可以解决与计算机硬盘有关的大多数问题。有关如何使用TestDisk的视频教程在这里。
我喜欢什么：
  • 免费，开源，安全。
  • 可以修复分区表并恢复已删除的分区。
  • 从软件故障，某些类型的病毒或人为错误导致的有问题的分区中抢救数据。
我不喜欢的地方：
  • 非GUI程序-即它不适用于计算机新手，因为它需要更多的技术知识才能成功使用。

另一个功能强大但免费的数据恢复实用程序。Puran File Recovery可以很好地从几乎任何存储介质中恢复数据。该软件支持十种不同的语言。Puran的所有实用程序对于私人和非商业用途都是完全免费的。您可以在这里观看来自YouTube的视频教程。
我喜欢什么：

  • 突出显示后即可预览文件。
  • 您可以按文件类型对找到的项目进行分类。例如图片，视频，文档等
  • 恢复后保留文件质量。
我不喜欢的地方：
  • 对于新用户而言不是那么直观，特别是与该列表中的其他一些选项相比。

8.Glary Undelete（Windows）
与Recuva类似的很棒的取消删除工具，Glary Undelete从FAT和NTFS磁盘“ 删除 ”项目。使用简单：只需选择要扫描的驱动器，然后单击“搜索”，然后等待一段时间，具体取决于所选磁盘的容量。您会看到一堆文件。完成后，只需导航到左侧的文件夹，然后使用预览功能找到您要定位的项目，就可以了！从此视频教程（来自Vimeo）中查看更多信息。
我喜欢什么：
  • 快速下载并安装。干净的逻辑软件界面。
  • 完美删除回收站或外部存储设备中的项目。
  • 预览功能有助于查找您要检索的文件。
我不喜欢的地方：
  • 找到并列出了许多垃圾文件，这可能会让您有些不知所措。
  • 恢复格式化或硬盘崩溃丢失的数据的能力较弱。

9. SoftPerfect File Recovery（Windows）

这是另一个使您意外删除的文件恢复活力的好工具。SoftPerfect File Recovery （向下滚动页面以下载程序，跳过EaseUS建议）的主要目的是帮助您挽救从硬盘，USB闪存驱动器，SD和CF卡等意外删除的数据。它支持流行的文件FAT12 / 16/32，NTFS和NTFS5等具有压缩和加密功能的系统。该程序在Windows XP到Windows 10下运行。
我喜欢什么：
  • 便携式，无需安装。
  • 提供33种界面语言。
  • 非常易于使用-无需不必要的设置和屏幕。
  • 能够使用“路径”还原文件。
我不喜欢的地方：
  • 没有文件预览。扫描文件被一一列出，而没有分类在文件夹中。

10. Tokiwa（Windows）

如果您想快速恢复丢失的文件，Tokiwa Data Recovery是一个不错的选择。它是一个独立的应用程序，这意味着安装过程只需要很少的时间。就我而言，Tokiwa在不到一分钟的时间内发现了42,709个文件-非常高效！Tokiwa声称它可以从通用存储介质中检索和擦除文档，档案，图片，视频等。
我喜欢什么：
  • 它是便携式的-无需安装。
  • 快速扫描过程。
  • 简单扫描结束后即可使用深度扫描功能。
  • 能够永久擦除文件。
我不喜欢的地方：
  • 我找不到任何设置或文档-尽管使用起来很简单。
  • 无法预览图像或文件。
  • 擦除功能不允许将已擦除的项目保存在系统驱动器中。

14. Undelete360（Windows）

顾名思义，Undelete360会恢复您从计算机，回收站，闪存驱动器，数码相机，存储卡等意外删除的文件。启动该程序时，您会看到两个标签：“ 恢复文件 ”和“ 清除文件 ” 。要取回已删除的项目，请停留在“ 恢复文件 ”选项卡上，突出显示磁盘驱动器，然后开始搜索。
我喜欢什么：
  • 提供多种语言。
  • 文件树对找到目标项目非常有帮助。
  • 指示文件路径以及文件条件。
  • 包括擦除工具，该工具可安全删除无法恢复的文件。
我不喜欢的地方：
  • 我的计算机在扫描过程中挂起。
  • 与此处列出的其他大多数应用程序相比，非常耗时。
15. FreeUndelete（Windows）
顾名思义，FreeUndelete是一个免费软件工具，可以从任何基于NTFS和FAT的卷中删除文件。FreeUndelete可在Windows 10、8、7，Vista和XP上运行。在测试过程中，我发现该程序非常直观，并且数据扫描过程非常快。但是，令我感到沮丧的是，找到的文件和文件夹组织得不好，这使得实际上很难选择和恢复要恢复的文件和文件夹。
我喜欢什么：
  • 快速下载，安装和扫描。
  • 非常直观–没有复杂的按钮或选项。
我不喜欢的地方：
  • 左侧的面板有点奇怪-我的计算机上没有驱动器D：或E:。
  • 找到的文件组织不良。无论是否恢复，我都找不到想要恢复的照片。

16. WinHex（Windows）

WinHex 的目标更多是取证数据恢复需求。下载存档后，将其解压缩并单击“ WinHex.exe”以运行该程序。第一次打开它可能会有些不知所措。要扫描和恢复数据，请移至 “工具”->“磁盘工具”->“按类型恢复文件”。
我喜欢什么：
  • 用于调查和取证使用的唯一免费软件。
  • 能够编辑/克隆磁盘以及恢复分区。
我不喜欢的地方：
  • 需要某些专业知识来处理该程序。
