# Volatility 3 Public Beta 发布，不再需要 --profile！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODA3NDc3NA==&mid=2247484244&idx=2&sn=f717c0065b9021a781aabfc24756b882&chksm=9bda9eadacad17bb5a64378730fe860eed25f4ffbb7257de7e55f7babd77b5b3db08e90f61d1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODA3NDc3NA==&mid=2247484244&idx=2&sn=f717c0065b9021a781aabfc24756b882&chksm=9bda9eadacad17bb5a64378730fe860eed25f4ffbb7257de7e55f7babd77b5b3db08e90f61d1&scene=27#wechat_redirect)

       第十届年度开源数字取证大会（OSDFCon）于2019年10月15日至17日在美国的Herndon，VA（弗吉尼亚州，赫恩登）举行，在网上看到这届大会上的议程信息，我觉得最令人感到激动的当属Volatility 3的发布！  

![](../Images/f2a4fa356e85b51aa642798630558bd3.png)

        FTW，Volatility 3 Public Beta 最重要的特性便是不在需要 --profile，可以实现自动检测操作系统和应用的支持！另外Volatility 3 Public Beta 由Python3 编写，更好的Wow64的支持！

![](../Images/f3d2480b79a0c035688ed6369b18b7b6.png)

![](../Images/ed440bec1bddbbd5aa33de16e092399d.png)

      自十年前首次公开发行以来，Volatility已吸引了数字取证行业中最大，最活跃的用户和开发者社区之一。由于这些贡献，它已成为世界上最先进且使用最广泛的内存取证平台。在数字取证研究界，Volatility一直是蓬勃发展的生态系统的基础，该生态系统继续推动尖端技术快速过渡到全球数字调查人员的手中。(文字介绍来源于OSDFCon官网)   

![](../Images/a0d126487a28a0b660e9b51dbffa497d.png)

![](../Images/cf0e22320383c7b6ae5409f71d629be0.png)     Volatility是世界上使用最广泛的提取和处理内存信息的工具，包括一些取证产品也是在它的基础上进行二次开发，比较出名的是Magnet，在使用Magnet时，它的内存取证部分，Powered by Volatility。

这次刚刚看到发布的消息，还没来得及体验，改天体验一下Volatility 3的乐趣！
