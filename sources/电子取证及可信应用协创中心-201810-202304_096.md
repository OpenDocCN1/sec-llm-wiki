# 张天长教授带队赴省厅网安总队商讨合作共建事宜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODA3NDc3NA==&mid=2247483735&idx=1&sn=aae7312c43a664d188b26e06f3b9276f&chksm=9bda9caeacad15b83f2f1c8be403e4776d668f1f210e18fe42ccb77281dc7d6240696ced6d85&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODA3NDc3NA==&mid=2247483735&idx=1&sn=aae7312c43a664d188b26e06f3b9276f&chksm=9bda9caeacad15b83f2f1c8be403e4776d668f1f210e18fe42ccb77281dc7d6240696ced6d85&scene=27#wechat_redirect)

  

   为了落实学院领导对信息技术系的工作要求，做好2018电子数据取证高峰论坛会议准备，谋划共同建设电子取证及可信应用协同创新中心，加强双方的长期合作和密切联系，2018年10月16日下午，中心主任张天长教授带领黄学鹏、龚德中、徐伟、张俊等老师，赴省厅网安总队商讨合作共建事宜。邹德文政委，肖波处长等领导热情接待，参与会谈。双方深入探讨，在若干极具操作性的方案、规划，建议等方面取得高度共识，包括构建合作育人模式，共同培养网络安全与执法专业高素质人才；促进教师与实战紧密结合，提高解决实际问题的能力，在实战中发现研究课题，解决应用急需；提升协创中心建设层次，探索高水平科研和电子取证应用能力建设等 。双方还共同拟定了后期的相关工作。

![](../Images/82ea44cf5ebce1fb4841114a8ab67493.png)

       2018年10月15日下午，中心主任张天长教授，信息技术系副主任徐宗海等还与到访的武汉市局网安支队的客人进行了座谈。
