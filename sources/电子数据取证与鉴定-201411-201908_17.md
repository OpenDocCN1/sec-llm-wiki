# 第二十一期 电子数据取证的培训和认证（一）

电子数据取证是一个严谨的过程，因为它需要符合法律诉讼的要求。因此，取证调查机构必须从“人、机、料、法、环”等多个方面规范电子数据取证工作。而排在第一位的“人”更是整个质量管理体系中的重中之重，电子数据取证对于取证人员的经验和专业素养有着极高的要求，这在2010年国家认可委颁布的CNAS-CL27《检测和校准实验室能力认可准则在电子物证检验领域的应用说明》、2012年颁布的GA-T 976-2012《电子数据法庭科学鉴定通用方法》都进行了明确的规定。由于电子数据取证是一门不断发展的新兴学科，因此，如何对相关人员进行培训和考核以维持其持续的能力，也是所有机构面临的一大难题。  
近几年，随着网络犯罪案件的不断增长，对于电子数据取证所涉及的人员、技术、产品和方法的需求也随之增加。目前，国内在该领域的产品研发、标准制定以及实验室建设方面发展迅速，研发实力和技术积累甚至已经走在了国际前列。与此同时，在该领域的系统化、标准化的人才培训以及相关培训认证方面仍处于基本严重滞后状态，与国际上各种相关认证蓬勃发展相差甚远。目前，国际上关于电子数据取证的认证主要分为行业内中立机构的认证和产品供应商关于某个具体产品的认证。根据Tom's IT Pro网站对于国际上几个知名在线招聘网站的统计，电子数据取证岗位对于认证要求排名前列的分别为属于行业内中立机构的认证的CCE、CFCE、CHFI、GCFA、GCFE、CSFA以及属于产品供应商认证的ACE和ENCE。具体数据见下表。![](../Images/2b06abb03ae237a819785ae14cb1d2b4.png)![](../Images/2b06abb03ae237a819785ae14cb1d2b4.png)Tom's IT Pro网站所筛选出的认证很大程度上考虑到了此认证的通过人数，一般低于5000人的认证不计入他们的考量范围。有些认证由于价格因素或者是刚起步，因此在人数上有所欠缺，因此未计入Tom's IT Pro网站的统计。小编通过对电子数据取证领域的各种国际认证进行综合梳理，制作了以下两个表格供有志于参加取证认证的同学作为参考。表1：行业内中立机构的认证![](../Images/56f8469770b394e7989ff90fbaed4656.png)表2：产品供应商关于某个具体产品的认证![](../Images/a874ee45307b8f01dd5764010bd379d3.png)![](../Images/ca6780c1f9bf23285428e9f10b3cfbc2.png) ![](../Images/a3cc49dc2ffc876216ee379178a58e99.png)  
**小编语录**其实早在本公众号的第六期，小编曾经简略介绍过电子数据取证鉴定的培训与认证，当时就想着要将这个模块作为一个专题推出，让大家有的放矢地选择该领域的培训和认证。可惜，小编的拖延症使得小编迟迟没有动笔。最近，好多朋友在向小编询问关于这个领域的培训和认证。终于使小编下定决心，把这方面内容做个梳理。应广大朋友的要求，本期公众号的内容简略介绍了下关于电子数据的培训和认证，在接下来的几期中，小编将就认证介绍、知识体系、认证流程、主要知识资源等展开进行详细介绍。编写过程中得到了诸多好友的帮助，给予了很多信息的补全，在此特别感谢徐志强、孙奕、陈思晶、刘浩阳、郭永健...关于认证的具体介绍将会和获得认证的朋友合作进行编写，具体信息我将在详细介绍中予以标注。
