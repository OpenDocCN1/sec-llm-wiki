来源：电子数据取证与鉴定

  

随着犯罪人员的反侦查意识不断增强，人为破坏电子证据的手法也层出不穷，想要获取有用的电子证据难度越来越大，因为这些电子证据可能已被受调查者删除、加密、格式化，甚至存储介质都遭受到蓄意破坏。能在多大程度上进行数据恢复、证明案件事实也成为司法实践无法回避的首要难题。因此，数据恢复已成为电子数据取证中必不可少的环节。

在国外，数据恢复产业已经成为一个蒸蒸日上的朝阳产业。很多计算机集成商和存储设备生产厂商都有从事数据恢复服务的部门，专业的数据恢复公司也有很多。以美国为例，数据恢复公司有400多家，一年的数据恢复市场营业额为1.5亿美金，且每年以50%的速度递增，如美国著名的专业从事数据恢复的Ontrack公司每年的产值在2亿美元以上。

近期，世界最顶尖最权威的评测网站TopTenREVIEWS对2016年全球知名的数据恢复软件进行了综合测试，并发布获得前10名的榜单，分别为Data Rescue PC3、Ontrack Easy Recovery、Stellar Phoenix Windows Data Recovery Professional、Seagate File Recovery、R-Studio、Data Recovery Wizard、Recover My Files Professional、GetDataBack、Power Data Recovery和Salvage Data Recovery。

![](../Images/0bf30c25e21d8100e368771118cdff11.png)

TopTenREVIEWS依据丢失文件的恢复、格式化系统的文件恢复，数据恢复的速度、数据恢复特性、数据扫描特性、售后支持、支持的操作系统，对这些数据恢复软件进行了综合测评，具体测评结果如表所示。

TopTenREVIEWS除了依据数据恢复软件的数据恢复等功能外，还综合考虑了对操作系产品价格、售后服务等因素。在电子数据取证领域，R-Studio、Recover My Files、Stellar PhoenixWindows Data Recovery Professional、EasyRecovery等专用数据恢复软件正深受取证人员青睐。

 1、R-Studio

R-Studio是加拿大R-TT公司研发的数据恢复工具,为使用FAT12/16/32、NTFS、 NTFS5(Windows 2000/XP/2003/Vista/Windows 8/Windows 10系统)和Ext2FS(Linux系统)分区的磁盘提供最为广泛的数据恢复解决方案。 

为更好地针对非Windows系列的操作系统，R-Studio还开发了R-Studiofor Mac和R-Studio for Linux。R-Studio for Mac是专为Mac操作系统环境设计的。它能从HFS/HFS+（Macintosh）、FAT/NTFS/ReFS（Windows）、UFS1/UFS2（FreeBSD/OpenBSD/NetBSD/ Solaris）和Ext2/Ext3/Ext4FS（Linux)分区中恢复文件。R-Studiofor Linux是专为Linux操作系统环境设计的，它能恢复Windows、FreeBSD/OpenBSD/NetBSD/Solaris和Macintoshi系统中的数据。

![](../Images/bc53d46b26a1a802cf260603874c5ccf.png)

  

 2、Recover My Files

Recover My Files是澳大利亚GetData软件公司研发的数据恢复软件。该软件功能强大，恢复成功率极高，可以很轻松地恢复电脑硬盘、U盘、TF卡、SD卡、记忆棒、相机存储卡、软盘，Zip驱动器等存储设备上的数据。

Recover My Files可以运行在Windows 2003、Windows XP、Windows Vista、Windows 7、Windows 8 和Windows 10中。它支持FAT 12、FAT 16、FAT 32、NTFS、NTFS5、HFS 和HFS+ (MAC)文件系统的数据恢复。

![](../Images/9a0f064890dc797db5411b9188f3f3c6.png)

 3、StellarPhoenix Windows Data Recovery Professional

Stellar Phoenix Windows Data Recovery Professional是印度StellarInformationTechnology公司推出的一款Windows数据恢复软件。

Stellar Information Technology公司是世界上数据恢复软件的领导者，旗下拥有许多知名产品，包括Windows Data Recovery、FAT & NTFS Data Recovery、PhotoRecovery (Win)、CD DVD Recovery、iPod Data Recovery、Linux&Novell Data Recovery、SCOOpenServer Recovery、SCO UnixWare Recovery、Sun Solaris Recovery、BSD Recovery、HP Unix Recovery、MySQL&SQL&Oracle Database Recovery等。目前Stellar的产品已经覆盖了美国、欧洲和亚洲市场等170多个国家，覆盖了企业，政法机关等。

![](../Images/f39f9bbc924c85a626613718859cf446.png)

4、EasyRecovery

EasyRecovery是由全球著名数据厂商美国Kroll Ontrack公司出品的一款数据文件恢复软件。支持硬盘、光盘、U盘、移动硬盘、数码相机、手机以及Raid阵列等不同存储介质中的数据恢复，能恢复包括文档、表格、图片、音频、视频等各种数据文件。

EasyRecovery有适用于Windows及Mac平台两个软件版本，EasyRecoveryWindows版本支持FAT12、FAT16、FAT32、NTFS、HFS/HFS+、EXT2、EXT3、ISO9660等分区格式的文件系统，EasyRecovery Mac OS版本支持FAT12、FAT16、FAT32、NTFS、HFS/HFS+、EXT2、EXT3、SO9660分区的文件系统等。

EasyRecovery面向不同需求的用户，发布了三种版本：EasyRecovery企业版、EasyRecovery专业版和EasyRecovery家庭版。其中EasyRecovery企业版功能最为强大，支持几乎所有类型的文件恢复，还支持RAID数据恢复。
