伪基站的取证鉴定中，经常需要将时间戳转换为普通时间。伪基站服务器一般为ubuntu为代表的linux系统，在Linux系统中，有许多场合都使用时间戳的方式表示时间，即从1970年1月1日起至当前的天数或秒数。如/etc/shadow里的密码更改日期和失效日期，还有代理服务器的访问日志对访问时间的记录等等。伪基站记录短信发送时间也使用时间戳。由于发送短信数据量巨大，需要自动转换脚本的帮助。

我们将伪基站服务器中提取的send.data文件进行转换。文件内容为发送时间和对应的IMSI。


现在需要对其进行批量转换，python脚本如下：

import datetime

import time

f = open("send.data", "r")  #读入文件

s = open("output.txt", "w")  # 转换结果存入的文件

while True: 

    line = f.readline() 

    if line: 

        pass  

       ltime=time.localtime(int(line[0:10]))

       timeStr=time.strftime("%Y-%m-%d %H:%M:%S", ltime)

        s.write(timeStr+'  '+line[11:])

        line=line.strip()

        p=line.rfind('.')

        filename=line[0:p]

        print "create%s"%line

    else: 

        break

f.close()

s.close()
