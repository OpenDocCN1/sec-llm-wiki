一、 基本案情

2008年，林某、王某夫妇以成立生物科技公司为掩护，以DS2010系统及消费增值平台为依托，以销售生物保健产品为幌子，要求参加者购买产品获得会员资格，同时按照一定的顺序组成层级，以发展下线会员的数量作为计酬和返利的依据，引诱参加者继续发展他人参加，骗取财物，在全国各省市大肆发展下线会员，进行网络非法传销,骗取高额会员费。2012年6月至2013年1月，公安机关先后抓获犯罪嫌疑人16名。截止案发，该传销组织已发展会员7.3万人，会员金字塔状安置层级达200层，涉案金额达2.7亿元。鉴于案情特别重大，并涉及大量电子证据，汉寿县检察院迅速指派技术部门干警介入侦查活动，引导并监督侦查取证。2014年3月25日该案一审宣判,以组织、领导传销活动罪，分别判处主犯林某、王某、陈某、董某4人5年至11年不等有期徒刑，并处50万至500万元不等的罚金；除1人免予刑事处罚外，其他11名从犯获刑1年6个月至3年不等，并处5万至40万元不等的罚金。

二 、网络传销案最新特点

（一）作案手段网络化，电子证据获取难。以成立注册公司为掩护，以购买螺旋藻产品为幌子，网上销售、网上付费，涉及定罪量刑的传销人数、传销组织层数、返奖金额等关键数据都存储在数据库中，还原、提取相应电子证据较难。

（二）运用看似合法的网站作掩护，更具欺骗性。公司内部组织严密，网站设立市场部、教育培训部等板块；以健康推广会为名，用网络组织会员集会；将网络返利方式设置得非常复杂，故意让参与者搞不懂。

（三）发展速度快、涉案金额大。以网上注册公司DS2010系统和消费增值平台为依托，以购买新大泽牌螺旋藻商品为名，采取拉人头、交入门费方式在全国发展网络传销会员，4年内网络注册会员遍布湖南、江西等六省，发展会员7.3万多人，非法收取会员交款、培训费2.7亿元。

（四）涉案人员籍贯异地化，学历高。在办理的16名涉案人员中有9人属外省籍贯，主要来自福建、山东、吉林、安徽、江西等省，跨省取证难度大，涉案人员中具有中专以上学历的11人。

三、网络传销电子证据存在的问题和困难

汉寿县检察院派员提前介入之初，采取座谈会等方式，充分认识到电子证据收集、获取和认定是侦查机关面临的技术瓶颈性问题，并全面了解分析了侦查机关在电子证据调取、认定等方面存在的主要问题和困难。

（一）传销网络平台复杂。由于网络传销案件网络平台的复杂性，导致从中提取传销组织的体系图(“金字塔”)、层级数和返奖算法等关键证据技术难度大 。如本案中，有别如其它网络传销案件的是传销平台有两个，一个是销售管理平台，一个是消费增值平台，这两个平台由不同的公司用完全不同的计算机编程语言和完全不同的数据库开发，且这两个平台在后台实现数据交叉引用，数据量高达1.2G，此外，结算子系统核心代码还进行了加密处理。

（二）电子数据来源复杂。电子数据存储地涉及境外服务器，如何固定境外服务器电子证据，不仅涉及技术问题还涉及法律问题。如本案中，传销平台程序代码和数据库存储在租用的美国服务器上，用何种技术手段确保电子数据的完整性和真实性便成为重点。

（三）调取主体亟需明确。网络传销案件往往涉及若干电子证据，由谁作为电子证据的调取主体，由谁对电子证据进行检查、分析才能保证电子证据的效力，这都需及时明确。如本案，是由县级公安机关立案侦查，电子证据由县级公安机关网络安全监察部门进行调取、检查、分析，还是由市级公安机关来进行。

（四）犯罪构成复杂、事实认定困难。如本案中，电子证据里提取出来的注册会员数能不能认定为刑法意义上的传销人数；从电子证据里提取的金字塔层级图中的层数能不能认定为刑法意义上的传销组织层数。如果传销案件的人数和层数不能确定将导致无法定罪，人数和层数怎么确定，这些认定起来极其困难。

四、依法引导侦查取证

针对上述问题，我们结合办案经验和查阅相关法律，认真研究案例，主要采取以下步骤引导侦查取证：

（一）首先解决取证主体问题。根据《计算机犯罪现场勘验与电子证据检查规则》第八条、第九条规定，计算机犯罪现场勘验与电子证据检查，应当由县级以上公安机关公共信息网络安全监察部门负责组织实施。电子证据检查，应当遵循办案人员与检查人员分离的原则。检查工作应当由具备电子证据检查技能的专业技术人员实施，办案人员应当予以配合。据此提出如下指导意见：县级公安机关公共信息网络安全监察部门具备电子证据取证主体资格；考虑到该案电子证据复杂，县级公安机关技术力量不足的实际情况，建议公安机关请市公安局公共信息网络安全监察部门指导。

（二）规范电子证据的收集程序。电子证据的收集，是产生电子证据的第一步，如果收集环节存在合法性问题，后面的工作做得再好整个电子证据也会被否定，确保收集的合法性，对保证电子证据效力非常重要。如本案中传销平台核心程序代码的收集，由两名具备计算机专门知识的公安民警实施，严格按照《刑事诉讼法》和《计算机犯罪现场勘验与电子证据检查规则》进行收集，邀请了一名与案件无关的公民作见证人，并对整个取证过程进行了录像，保证本案收集电子证据的方法具有科学性并具有可检验性，从源头上就开始保证电子数据的原始性。

（三）科学固定电子证据。电子证据刚刚被确立法律地位，又是初次办理此类案件，要确保电子证据的一致性，必须要采取科学、稳妥的方法。如本案中核心程序代码，为了慎重起见，笔者指导侦查机关采取三种方式进行固定。一是，用MD5校验方式对收集的核心程序代码进行固定。MD5校验是一种典型的用于防止数据被篡改的方法，广泛用于确保信息传输完整一致，MD5校验码以整个数据为单位，生成一串独一无二的检验码，如果在传输环节任何人对数据作了任何改动，检验码将发生改变，MD5常常被形容为数据的“数字指纹”。笔者要求侦查机关在提取电子证据后立即制作该电子证据的MD5码，形成“数字指纹”，用于各个环节对电子证据进行校验，确保数据一致。二是制作备份。将收集到的核心程序代码刻录成光盘作为原始光盘并制作该原始光盘的备份光盘。制作与原始光盘一模一样的备份光盘是一种容易实现并且比较简单的保证数据原始性的方法，一旦对一致性有质疑需要验证时，可用原始光盘与备份光盘进行比对。三是封存原始光盘。在现场对程序代码的原始光盘进行封存，由证据持有人对MD5码进行确认，由见证人签字，并制作《固定电子证据清单》、《封存电子证据清单》。通过以上一系列技术的和法律的方法对本案电子证据进行固定后，确保了本案的电子证据从源头上是可靠的、可验证的。

（四）规范电子证据的使用。电子证据需要在不同的承办人之间传递，会被不同的人使用。如本案中的电子证据，需要进行检验、分析、鉴定，根据新获得的线索，还要经常提取电子证据中的相关数据，根据侦查需要有时要向犯罪嫌疑人、证人出示电子证据等，这些承办人使用电子证据的目的不同、方式不同。在使用和传递电子证据的过程中操作不规范，可能会导致得出来电子证据分析结果或取得的侦查成果无效，功亏一篑。笔者要求侦查机关安排专人保管封存的原始电子证据光盘，对原始光盘的启封、重新封存等关键操作必须进行录像，并制作《原始证据使用记录》，详细记载每一次使用原始证据的时间、目的和使用过程。电子证据检验、分析人员，提取电子证据时要核对检材的MD5校验值，确保检材正确，并制作《提取电子证据清单》详细记录提取的电子数据的来源、提取方法和提取数据的MD5校验值。保证每一次使用、每一次流转的电子证据都是与原始数据一致的，并有记录可查，消除厉害关系人疑虑，堵住律师的辩点。

（五）解决电子证据中的技术难题。办理该案的技术难点首先是电子数据分析平台的搭建，这是开展一切工作的前提。如本案的传销管理平台，搭建时需要反复尝试，仔细测试，确保每一个模块都能运行。其次是对数据库字段含义的分析，难点在于在没有相关开发文档的情况下要理解主要字段的含义需要花很多精力。本案采取了三种方式确定数据库字段含义，一是通过询问开发人员获取了部分字段定义，二是通过查看C#代码确定了部分字段是什么意思，三是通过在前台或后台随机填入一些数据再查看后台变化确定了一些关键字段的含义。如统计各期奖金明细和统计各期计算奖金的主要参数就是分别在前台和后台输入数据后确定的，具体做法如下：

统计各期奖金明细：

declare @strSql char(8000)

declare @i int

create table #tb(期数int,销售奖decimal(18,2),市场奖decimal(18,2),培育奖decimal(18,2),服务津贴decimal(18,2),套餐推荐奖decimal(18,2),绩优津贴decimal(18,2),推荐奖decimal(18,2),分享奖decimal(18,2),总监补贴decimal(18,2),投资返利decimal(18,2),扣税decimal(18,2),实发decimal(18,2))

/*

确定字段对应关系的方法：

随机抽取jiesuanX表（X=0至63）中一行数据，将该行中jiangjinX（X=0至12）、koushui、shifa字段置为特定值，然后在前台高级查询中以该行的编号为关键字进行查询，得出数据库表的字段和前台显示的奖金、扣税、实发的对应关系*/

set @i=1

while @i<64

begin

set @strSql='insert into #tb(期数,销售奖,市场奖,培育奖,服务津贴,套餐推荐奖,绩优津贴,推荐奖,分享奖,总监补贴,投资返利,扣税,实发)

 select  '+convert(char(2),@i)+' as 期数,'+'

        sum(jiangjin2),

        sum(jiangjin3),

        sum(jiangjin4),

        sum(jiangjin5),

        sum(jiangjin6),

        sum(jiangjin8),

        sum(jiangjin11),

        sum(jiangjin12),

        sum(jiangjin9),

        sum(jiangjin10),

        sum(koushui),

        sum(shifa)  

        from  h_jiesuan'+convert(char(2),@i)

exec (@strSql)

set @i=@i+1

end

select * from #tb

drop table #tb

统计各期计算奖金的主要参数:

select qishu  as 期数,

     cs40  as 普卡会员市场奖比例,

     cs43  as 钻卡会员市场奖比例,

     cs14  as 培育奖条件,

确定字段对应关系的方法：

随机抽取config表中一行数据，将该行中csX(X=1至61)字段置为特定值，然后在前台高级查询的结算参数中以该行的期数为关键字进行查询，得出数据库表的字段和前台显示的参数的对应关系*/

在确定字段关系后，我们还可以构建大量SQL语句查询本案关键数据，如各期汇款金额、各期新增店铺数、订货统计等都比较简单了。

最后，最重要的是对涉及定罪量刑的网络层级结构的分析。难点在于从传销网络的树型结构中计算出任一会员所辖下级总人数和最大层数。用简单的函数和循环根本无法实现这样的功能。需要综合利用多条SQL语句和一些高级特性构建递归查询实现上述功能，具体做法如下：

declare @anzhi varchar(50)   /*待查询对象会员编号*/

set @anzhi='12345'   /*12356为会员编号，可设为任一会员编号*/

/*构建子查询

ceng=会员所在层位

bianhao=会员编号

anzhi=该会员的安置人*/

with temp as (select bianhao,anzhi,2 as ceng from 会员信息表 where anzhi=@anzhi union all select a.bianhao,a.anzhi,ceng+1 from  会员信息表 a inner join temp b on a.anzhi = b.bianhao)

/*执行查询 */

select count(bianhao) as 人数,max(ceng) as 层 from temp

OPTION (MAXRECURSION 0)

/* MAXRECURSION参数指定查询所能进行的最大递归层数，当指定0时，不会限制递归层数，如果未指定这个选项，默认最大递归层数是100 */

至此，任一涉案会员在传销网络中的层位即可通过上述代码查询得到，要查询整个“金字塔”层级只需输入塔尖会员号即可。

（六）解决电子证据与本案的关联性问题。关联性是证据三性之一，技术人员取证时往往注重取证技术的科学性而忽视证据的关联性。如本案核心电子证据之一的数据库，里面存储着会员数、网络层级、返奖金额、交易记录等犯罪重要数据,该份证据怎么来的，里面的数据怎么产生的等关联性问题对本案至关重要。笔者审查本案证据后发现，侦查机关要求管理传销平台的网络管理员从美国的服务器上下载传销平台核心代码和数据库并提供给侦查机关，但对为什么要从美国服务器上调取数据、为什么美国服务器上的数据是正确的、如何确定所调取的数据就是从美国的服务器上调取的、数据库中的数据是怎么产生的、数据库中的数据为什么与本案传销有关系等关键问题没有取证证明。笔者提出，赴上海开发传销平台的软件公司：(1)调取程序员证言，彻底弄清数据的产生过程与传销的关系。(2)调取数据库管理员的证言，弄清管理员维护数据库时登录服务器的网络地址、数据库的存储位置，证明传销平台的数据库就是存储在美国的。(3)调取项目经理的证言，弄清犯罪嫌疑人委托其公司开发传销平台的过程，证明侦查机关调取的核心代码、数据库与本案传销的关联性。

经过数月的补证，本案电子证据从形式要件到实质内容均得到了全面补充、完善，形成了强有力的证明体系。侦查机关将本案移送检察机关审查起诉。检察机关经审查起诉决定以林某、王某等人涉嫌组织领导传销罪移送法院起诉。在法庭上，犯罪嫌疑人及辩护律师果然从电子证据的真实性、合法性、关联性、来源、证明力等方面入手提出了大量质疑，均被我们依法有力反驳，未得到法庭支持。

五、几点注意事项

从这一案例可以看出，技术人员全程参与该案对电子证据的技术支持对该案事实和证据的认定起了关键作用。可见在办理利用网络犯罪的案件中，科学收集、运用电子证据，并使电子证据作为有效的诉讼证据提供给法庭，对该类案件的成功办理十分关键，同时培养既懂电子证据技术又懂精通法律的办案人员，对检察办案的未来发展非常重要。最后，通过办理该案，总结了一些审查电子证据的注意事项：

（一）要注意电子证据和其它证据的印证。电子证据与其它证据之间存在矛盾或是孤证，很难被法院作为定案的证据予以采信。

（二）要注意电子证据鉴定的委托手续、检材移送程序。在鉴定意见正确的情况下，辩护律师往往从鉴定程序上找问题，无鉴定委托手续的瑕疵会让庭审出现尴尬，检材移送手续不完备、启封应该拍照、摄像的未拍照、摄像，会让人产生检材是否是原始数据的疑问，严重的会导致鉴定意见不被采信。

（三）要注意熟悉相关技术标准和规范。对电子证据检验、鉴定的方式、方法和步聚的相关技术标准和规范要特别熟悉。目前不少辩护律具备有较高的计算机水平，即便不懂计算机知识，咨询专家也是很容易的事。辩护律师提出异议时往往用很多专业术语，言词凿凿，故意虚张声势，如果我们对电子证据检验、鉴定的科学性把握不到位，庭审时无法反驳，即便电子证据检验、鉴定意见是正确的，严重的也会动摇法官信心，导致电子证据不被采信。

（四）要注意正确关联电子证据内容与案件事实。电子证据内容往往存在很多虚拟的东西，比如，传销案件中存在一人注册多个会员号的情况，电子证据中的会员人数显然不是参与传销的实际人数，起诉书中不能将电子证据中的会员数作为实际人数来认定，但电子证据所反应的网络状态也是一种客观存在，起诉书中可直接表述为会员数或节点。电子证据的上述虚拟性普遍存在，如聊天记录、电子商务、电子交易、电子邮件、微博等电子证据中的账号、时间、地点都涉及到与现实需对应的问题。稍有不慎就会导致起诉书指控的相关事实不被法院认定或被法院改变。
