# 【2016-2-15】视频侦查打开迷案僵局

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=402074616&idx=1&sn=681bbe1050bb2de509accaca67396aa0&chksm=092464093e53ed1ffe0f92b0925b4fde3fce56261b3cefe6eb0e962e976dafd9511f7dbc9962&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=402074616&idx=1&sn=681bbe1050bb2de509accaca67396aa0&chksm=092464093e53ed1ffe0f92b0925b4fde3fce56261b3cefe6eb0e962e976dafd9511f7dbc9962&scene=27#wechat_redirect)

林景，男、2002年7月毕业于中国人民公安大学，法学硕士、高级工程师，广东省公安厅刑事技术中心视频侦查专家，主要从事刑事影像检验和视频侦查工作，多次参与全省重特大刑事案件的侦破并发挥重要作用。

12月18日，番禺灭门案凶手被判死刑。作为今年轰动全城的命案，在社会高度关注的压力下，警方是怎样仅用80多个小时锁定了真凶？“广州火车站砍人事件”的嫌疑人到底有几个？“301公交车案”是怎样追踪到纵火嫌疑人？  

近日，参与了今年的“番禺灭门案”、“广州火车站砍人事件”、“301公交车案”等一系列大案的广东省公安厅视频侦查技术专家林景警官，首次揭秘近年来广东大要案背后的侦破细节，运用“天眼”成功破获一系列重特大刑事案件。

视频侦查技术是指可提取犯罪嫌疑人相关犯罪视频，最直观、全面的获取犯罪证据和线索来源的分析手段，已成为公安机关侦查破案支撑技术。

“视频侦查在整个案件侦破中是最初的一环，打开侦查的局面，关系到整个侦查的方向”，林景从事视频侦查已10余年，这门新兴的侦查技术从2005年监控普及以后才逐渐完善起来。

　　看视频是个技术活

“案件发生后，马上找摄像头”，视频侦查员的工作一般先从了解案情开始，然后带着设备去现场勘查，了解现场的情况，提取周边的视频监控，接下来，他们的主要工作就是“看视频”。

看视频可不是像看电影那样轻松，这是一门技术含量非常高的活。面对动辄几百个G的海量视频和分秒必争的侦破时间，怎样找到嫌疑目标？面对模糊不清的视频怎样通过技术处理变成“高清”？发现嫌疑人后，怎样分析追踪到目标，甚至找出目标全部活动轨迹？林景说，“看”其实只是其中的一个环节，更重要的是分析，为案件侦查提供线索，这都是侦查的技术活。

视频侦查技术尽管出现时间不长，但已在破案时屡显神威。2014年5月6日发生在广州火车站的砍人事件中，最初媒体报道是有4个嫌疑人。林景告诉记者，他看过中心现场的视频监控，仔细反复比对后，最终确定只有1个嫌疑人，为案件侦查指明方向。

2014年7月15日的广州“301公交车案”，案发后，警方仅用16个小时就抓获了纵火嫌疑人。通过视频追踪，发现目标嫌疑人从流花火车站提了一个包上车，再沿线追踪到了白云区的某公交站，最终锁定目标。

　　一眼就看出伪造的照片

近年来，一些犯罪分子运用伪造的艳照进行敲诈勒索的案件越来越多，这些艳照给当事人等带来了巨大的精神压力，其中所涉及的影像检验与鉴定技术也是林景的拿手好戏。

2012年广州某医院领导接到一封信，信中有一艳照，并要求将钱打到某个账户，否则将照片放到互联网上。

当事人为了证明自己清白，把“艳照”送检至相关专业人士进行检验，由于该照片伪造水平比较高，相关专业人士也无法给出具体的检验意见。

办案部门将此照片送至技术中心后，林景一眼就看出了照片是伪造的，当场就把原图拿了出来。林景说，因为此前就发生过很多类似的案例，电脑里还保存着犯罪分子作案用的那张原始“底片”：一个男的跟一个女的裸露着抱在一起，场景是一模一样的，只不过头部被替换了。

再通过对照片的技术分析，林景发现了照片多处伪造的地方，确定此艳照系出自同一犯罪团伙，最终检验的结果为证明当事人的清白提供了重要的证据。
