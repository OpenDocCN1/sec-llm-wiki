# 【2016-1-27】实战：Samsung GT-N7100 Galaxy Note II取证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=401641563&idx=1&sn=76e9d401781105d12ccd157a45da89ec&chksm=0923dfaa3e5456bc53410220dedb5644386b575fd9773379636c3b23c9560cbd6d647377cf5d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=401641563&idx=1&sn=76e9d401781105d12ccd157a45da89ec&chksm=0923dfaa3e5456bc53410220dedb5644386b575fd9773379636c3b23c9560cbd6d647377cf5d&scene=27#wechat_redirect)

![](../Images/c2084ca813ebb9df9d10fee5ef26b84b.png)

检材型号：Samsung GT-N7100 Galaxy Note II

操作平台：XRY6.10.1

操作系统：Windows7   64Bit

操作方式：物理

  

以“自动连接”方式加载提取模块，XRY可以自动识别出来该手机的品牌、型号。XRY支持物理提取，我们就以物理提取方式进行操作，因为物理方式得到的数据量会更大一些。

注意：

1、必须使用黄色连接线（Mini MicroUSB2）；

2、出现下面这个提示时，请选择第二项“ADB”；

![](../Images/fe3630fbc24af92f1ccd8d66b2e10961.png)

3、请严格按照该提示的步骤，按顺序执行；

![](../Images/14a51739243122a7743523451d382c54.png)

  

  

  

之后，会自动进入“挖煤模式”：

![](../Images/2a90043d9ad2e46458a3771adf935ccf.png)

取证过程将持续40分钟左右，结束之后，效果还是非常好的：

![](../Images/8b99ff4f241347414fdcf4f5bf40bb03.png)

之前，有不少同志操作过这款手机，没能成功的原因就是无法进入挖煤模式！根源就在于没有使用黄色USB2线或者是没有严格按照提示、按顺序操作！
