一、案件背景

2015年XX月XX日晚，顾某在某县城区使用“伪基站”设备向周围不特定人员发送相关广告信息。如“金沙娱乐场、全球最大的中文现金平台、百家乐、龙虎斗、牛牛、诈金花等几百款游戏尽在J2789.com”等信息，公安机关委托我单位对伪基站系统内的数据进行分析和提取。

二、技术解析及鉴定方法

“伪基站”即假基站，是未取得电信设备进网许可和无线电发射设备型号核准的非法无线电通信设备。“伪基站”设备体积小、易携带，不法分子一般在城市商圈、机场、车站等人流密集的场所通过伪基站,能够搜取一定半径范围内的手机信息，强行向不特定人群发送短信，非法经营广告业务，或者发送虚假广告，甚至实施诈骗等犯罪活动，获取巨额利益。“伪基站”设备，破坏了正常电信秩序、危害公共安全、扰乱市场秩序，社会危害非常严重。

“伪基站”是利用GSM（Global System for Mobile Communications,全球移动通讯系统）单向认证漏洞而产生的一种技术。GSM是第二代移动通信技术（TDMA、GSM和CDMA）中使用最为广泛的一种，采用蜂窝网络进行通信。GSM技术存在一个重大的安全缺陷，基站会对客户端进行验证，但是客户端不会对基站进行验证。也就是说，只要你能够发射和GSM基站行为类似的无线电信号，就可以让周围的GSM手机连接到你的假冒基站中，然后你就可以向连到你的基站上的手机群发短信了。

伪基站的原理就是自己建一个手机网，用户的手机在不知情的情况下加入了这个网络。通讯运营商基站的功率可大可小，“伪基站”设备的功率也可大可小。伪基站的基本构成包括一台发射主机、一台笔记本电脑、一根天线、一部手机和电源。其中，手机用来测得频点，即某个区域运营商正规基站的频点，然后再把频点和短信内容输入到电脑安装好的程序，通过发射主机和天线进行大批量群发。笔记本电脑和发射主机依靠一根网线连接。

伪基站的核心组件是发射主机及群发软件。发射主机主要由SSRP主板、功率放大器、机箱组成，功率越大发射器覆盖范围也越广。这些零部件在电子元件市场和网上能轻易买到，甚至还能买到伪基站整套设备。

大部分“伪基站”系统使用Ubuntu系统，鉴定人员要对Linux操作系统有一定的了解，熟悉相关Linux命令。需要鉴定人员在虚拟的环境中对伪基站系统进行仿真（如：盘石仿真取证系统SafeVM），特别要注意的是当前系统的时间属性和时区的转换。此外，鉴定人员也要对伪基站软件“OpenBTS”进行研究，了解其程序结构、使用的数据库等信息。“伪基站”设备中与鉴定相关的文件详细情况如下表所示：

对于伪基站类案件大致可分为以下几个步骤进行鉴定：

  1. 制作检材镜像。

  2. 系统仿真（一般进入系统是没有密码，若有密码，可进入单用户模式进行修改密码以便进入系统，详细操作可自行百度。注意查看系统时间），进去后打开GSMS软件页面进行查看。

  3. 进入数据库进行表文件查看，一般是gsms数据库中gsm_business表。

  4. 文件提取分析（涉及到需要鉴定的文件，详见鉴定相关的文件详细情况表）。

  5. 出具鉴定结果。

5. 检验结果

    1. 经检验，数据库中存在openbts的1条记录，其中内容为：“金沙娱乐场：全球最大的中文现金平台，百家乐，龙虎斗，牛牛，二八杠，三公，视讯直播电子游戏等几百款尽在：j2789。com”，计数总数为118,287。

    2. 数据库文件“/etc/Openbts/TMSI.db”，其中的表“TMSI_TABLE”中存在216条记录，其中，有一个字段名称为“IMSI”。

    3. 路径“/home/gsms/”下文件“913_1423178808.txt”的内容为记录的IMSI。

    4. 路径 “/home/gsms/公共/ba/crackgsms/var_usr/openbts”下文件“send.data”和“send.data~”的内容为记录的IMSI。

    5. 路径“/var/log”下存在名称为“OpenBTS.log”的文件，该文件记录“伪基站系统”运行所有的日志。
