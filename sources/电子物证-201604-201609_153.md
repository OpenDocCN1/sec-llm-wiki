# 【297期-5】视频图像信息数据库解决方案

背景介绍　　

随着视频在案事件侦破以及各类公安业务中发挥的作用越来越大，传统视频监控的局限以及对应用的制约也越来越明显。传统视频监控系统功能有限，缺乏与公安实战紧密结合的功能的深度挖掘，难以支持不同警种差异化的视频监控深化应用需求;综合分析调研发现存在以下问题。

  

　　**价值信息难共享**

  

随着平安城市建设与发展，全国城市视频监控系统已初具规模，各省市视频联网共享建设陆续完善，对于视频图像的实时共享要求，上级公安指挥中心目前已经可以调取下级单位的视频图像资源。

  

这些海量的视频信息当中对公安机关各部门有价值的信息其实寥寥，这些有价值的信息往往办案民警提前出来后很难二次利用，它们被保存在设备终端、移动硬盘、U盘等存储介质中，随着时间推进慢慢被删除或者丢失。

  

　　**价值信息难存储**

  

随着平安城市、智慧城市的建设发展以及视频监控高清化发展趋势的深入，传统的磁盘阵列存储方式已经逐渐显现它的不足，已经无法满足智慧城市建设中海量高并发实时视频数据存取的需求。传统的磁盘阵列存储方式不仅采购成本高，大量磁盘阵列管理维护困难，还不能达到网络带宽和存储器I/O资源的有效利用以及跨平台的数据共享。

  

从视频数据的数据量增长的角度来考虑，随着公安业务及视频技术的不断发展，视频数据在公安业务中所占的比例将越来越重，这势必对视频监控系统的吞吐能力及处理性能提出了很高的要求。考虑到视频监控系统部署应用后带来的群居效益，系统每日需要处理的数据量会有几何倍数的增加，因此视频监控系统必须要从系统的可扩展性和负载能力的角度考虑数据的存储问题。

  

　　**价值信息难获取**

  

在海量数据存储之后带来的又一个问题就是数据的查询问题。一方面，以往数据库在海量数据检索下，性能存在瓶颈，因此如何提高数据查询速度是系统必须考虑的问题;另一方面，随着用户的数量的增加，每天的查询、下载、浏览等操作将频繁的访问系统的数据库，对于系统的并发量也将是一个急需解决的问题。

  

　　**价值信息难挖掘**

  

我们不仅需求满足视图数据的海量存储、快速检索，同时我们也需求提供视图数据的高效利用，通过智能分析手段从海量的低价值密度的非结构化信息中获取高价值密度的结构化数据，帮助公安系统进行视图数据深度应用。

方案简介　　

要推动视频监控的公安实战应用的深度发展，首先要将连续的视频流转化成视频图像内容信息流，同时在视频图像内容信息层面完成对治安监控、治安卡口、交警监控、电子警察和智能卡口等各类视频监控资源的内在统一整合。

  

视频图像信息数据库正是一个提供除传统连续视频流以外的视频图像内容信息流的存储和相应服务的新的基础设施，是一个提供除传统视频监控实时浏览、云镜控制、录像下载回放等基本功能以外的、与公安实战应用能深度结合的视频图像信息深化应用服务支撑平台。

方案架构　　![](../Images/7abd3553d3e7f912d149df952364ee96.png)

在公安视频专网中，省、市、区县分局分别部署视频图像信息数据库，实现视频专网内视频图像信息及社会面监控的资源的采集、存储与管理，在各地建立关键数据的结构化描述信息，并通过数据级联实现对视频图像信息在省级结构化信息汇聚，并通过安全边界将信息同步到公安网省级视频图像信息数据库系统、市级视频图像信息数据库系统，以便各地各级公安机关进行跨地域、跨警种的信息共享，便于在上层实战业务平台的串并案分析、图像侦查、事态研判等更加有效的开展。图像信息数据库具备图像内容标注、图像内容存储、数据管理、数据导入导出、访问控制、权限管理、高效检索、信息关联、级联共享等功能。

  

方案特点　　

　　**打造统一标准信息库，实现数据全面共享检索**

  

按照公安部规定的标准字段打造统一标准的视频图像信息数据库，进行数据全面共享并提供快速检索服务，基于Hadoop\\Spark\\Hbase的云搜索系统，百亿级别的海量数据，可以实现检索秒级响应。

  

　　**结构化途径丰富，随心所欲完成结构化信息描述**

  

视频图像信息数据库拥有视频、图像、车辆和案件的四大类20多种视侦工具和战法，对各类视频图像资源进行针对性结构化描述，有效辅助各级办案人员对资源的结构化处理入库。

  

　　**云存储模块化设计，实现在线扩容升级**

  

视频图像信息数据库采用模块化结构设计，扩容非常方便，既可满足当前的需要又可实现今后系统发展平滑扩展。在不停止服务的情况下，动态加入新的存储节点实现扩容，最大容量仅受元数据内存限制。同时，云存储系统扩展时，对上层公安业务系统是透明的，业务系统可根据需要对配额进行调整，而不需要管理新增空间。

  

　　**海量空间存储，迎接大数据时代**

  

省市级的部署视频图像信息数据库，需要管理全省的视频图像信息资源，面对如此海量的视频图像资源，对于存储的容量要求有一定要求。云存储系统规模可支持4096PB海量存储空间，能够满足大数据时代的存储需求。

  

　　**动态分配需求，有效利用存储空间**

  

视频图像信息数据库采用通过存储虚拟化技术，各种云存储设备被虚拟化成一个统一存储池，根据需求动态分配存储空间，对存储空间进行有效利用，从而达到资源有效分配利用及性能稳定提升的目的。

  

　　**动态负载均衡，选择空间存储文件**

  

视频图像信息数据库采用两级负载均衡调度，由元数据服务器选择一个负载轻的数据节点作为当前请求的读写节点，同时节点内部还会根据每个硬盘的负载选择最合适的硬盘参与数据写入，从而提高视频图像信息数据资源的写入速度，提高整个系统的运行效能。

  

　**　数据高容错性能，保障数据安全**

  

视频图像信息数据库采用分布式文件系统，设计时假设任意机框、任意节点、任意硬盘都可能出现故障，通过分布式的数据冗余、数据操作日志、元数据主备冗余，数据自动恢复等多种机制来处理这些故障，从而保障数据安全;最低配置可实现单硬盘损坏数据可在半小时内完全恢复，能够保障视频图像信息数据库中数据的安全性。

  

　　**高并发性能，快速响应访问**

  

视频图像信息数据库存储采用文件切片、以及文件切片内再进行节点间冗余的数据分散方式，使得客户端可以有效利用众多存储节点提供的聚合网络带宽，实现高速并发访问。客户端在访问云存储时，首先访问元数据服务器，获取将要与之进行交互的数据节点信息，然后直接访问这些数据节点完成数据存取;目前最小系统性能可实现1GB/s的写入和读出性能，完全能够满足大数据时代的并发访问效率。
