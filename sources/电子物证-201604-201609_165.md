**一、不用代理**  

![](../Images/51fa519887a1d89430e282c24efbe0dc.png)  

网民发帖流程：

发帖人　→　ISP　→　服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　发帖人IP　→　发帖人ISP　→　档案

爆菊几率：100%

 

**二、只用1层私人VPN**

![](../Images/dc8db95b33276de849943b3bf853a8a3.png)  

网民发帖流程：

发帖人　→　ISP　→　VPN　→　服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　VPN的IP　→　路由日志　→　链接者IP　→　链接者ISP　→　办网档案

爆菊几率：100%

 

**三、用1层共用VPN**

![](../Images/3b90c6c9516c0398982cc47991def94e.png)  

网民发帖流程：

发帖人　→　ISP　→　VPN　→　服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　VPN的IP　→　入侵VPN服务器　→　日志　→　链接者IP　→　链接者ISP　→　办网档案

爆菊几率：80%

 

**四、用2层私人VPN**

![](../Images/e67d5c0f4ede6f100876ed0bbb10165f.png)  

网民发帖流程：

发帖人　→　ISP　→　VPN1　→　VPN2　→　服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　VPN2的IP　→　入侵VPN2服务器　→　日志查VPN1　→　路由日志　→　链接者IP　→　链接者ISP　→　办网档案

爆菊几率：40%

 

**五、用2层共用VPN**

![](../Images/5d34f9b13b37d031cd0c9a17996e7557.png)  

网民发帖流程：

发帖人　→　ISP　→　VPN1　→　VPN2　→　服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　VPN2的IP　→　入侵VPN2服务器　→　日志查VPN1　→　日志　→　链接者IP　→　链接者ISP　→　办网档案

爆菊几率：25%

 

**六、用N层私人（共用）VPN后删掉VPN，如果发帖人有QQ**

![](../Images/72deac685965d3cfc6f0e5a9f7ab6669.png)  
网民发帖流程：

发帖人　→　ISP　→　VPN1　→　VPN2　→　VPN3　→　VPN\*n服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　访问网站　→　发帖人常用用户名　→　谷歌（百度）一下　→　查到QQ　→　找企鹅公司查近期登录IP

爆菊几率：100%

 

**七、用N层私人（共用）VPN后删掉VPN，如果发帖人无QQ**

![](../Images/341eafb53435d7b308306c4c6397c9b0.png)  
网民发帖流程：

发帖人　→　ISP　→　VPN1　→　VPN2　→　VPN3　→　VPN\*n服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　访问网站　→　发帖人常用用户名　→　谷歌（百度）一下　→　查到其他论坛注册的ID　→　找管理员查注册（登录）IP

爆菊几率：100%

 

**八、用N层私人（共用）VPN后删掉VPN，如果发帖人再网上没有任何信息**

![](../Images/398db0c97756112795cdf48b36050641.png)  

网民发帖流程：

发帖人　→　ISP　→　VPN1　→　VPN2　→　VPN3　→　VPN\*n服务器托管商　→　服务器

网警追踪流程：

网监　→　服务器IP　→　访问网站　→　无常用用户名　→　根据发帖内容（如北京市海淀区XX小区）　→　监控整个小区宽带　→　分析　→　找到IP

爆菊几率：80%（如果不是严重的问题，如判国之类的应该不会用这种蛋疼方法）

  

**网警提示：请保证合法的上网行为，否则即便是你用了VPN，网警也一样能查到你！**
