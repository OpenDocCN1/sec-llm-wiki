# 【279期-4】找回被偷iPhone总共分几步？

**一个问题：iPhone被偷了以后想要找回来总共分几步？**

**我用自己的亲身经历试图来梳理一下这个问题的答案。**

![](../Images/111632c1d4008bc1ecff29073364549f.png)

**手机瞬间被盗**

时间回到6月28日下午14时左右，当天我打算前往朝阳区霄云路甲海航大夏。在距离海航大厦不到300米的时候，突然下起了阵雨。我将原本一直握在手里的iPhone6 Plus随手放在外衣口袋里，准备从双肩包里取出雨伞。就在我取伞的时候，有人撞了我的肩膀一下，当时一心想着拿伞没有太在意。

几分钟后，到达海航大厦门口，我掏出手机准备联系要见面的人时，发现原本放在口袋的手机已经找不到。

我立刻进入大厦内找到值班人员用她的手机拨通了我的电话，一连拨打两次都没有人接听。

此时，我仍然抱有一丝侥幸：会不会是掉在路上了？

在请求大厦值班人员帮忙一直拨打我的电话后，我沿着来路试图寻找我的手机。在把那条不到300米的路走了一个来回后，我才愿意确认：手机是被人偷了，而且极有可能就是在我被撞的那一瞬间。

**第一件事：查找我的iPhone**

随后，我回到大厦用在电脑上登录了我的iCloud帐户，启用了“查找我的iPhone”功能。

![](../Images/aaf1c5fad8f235a54ca61c2d8f92bb82.png)

开启”查找我的iPhone”

随后，定位显示我的手机已经到了北四环东路附近。  

![](../Images/787ba1587e2f09fb8d1b2773d9fad36c.png)

iPhone定位在北四环东路

此时拨打我的手机还能打通，但是无人接听。随后我开启了“丢失模式”，这里需要提及的是，**iPhone开启丢失模式后，手机需要输入密码才能解锁使用，同时手机屏幕会显示失主留言。**

启动丢失模式时，根据系统提示，我留下了手机号码，这个号码会显示在我的iPhone屏幕上，小偷此时除了可以回拨电话无其他功能可用。

![](../Images/e3173931fe9ae0e1b709583461ed1f6b.png)

iPhone开启丢失模式

设置好“丢失模式”后，此时地图上显示iPhone已经离开北四环东路，往奥林匹克公园方向移动。

此时我做了一个让我很后悔的事情，因为担心手机内的信息外泄，在开启“丢失模式”后我又用了“抹掉iPhone”的功能。

![](../Images/0743be5cd988c17829aaf1fc6ebc6441.png)

抹掉iPhone

抹掉iPhone后，手机所有的资料全部清除干净，小偷如果要想解锁只能用Appe ID进行激活。而在手机激活页面则会显示我的留言和留下的电话号码。

保证安全的同时，iCloud也不能再定位我的手机，意味着我再也不知道我的手机在哪里。

**第二件事：上某宝查询ICCID**

除了用“查找我的iPhone”定位手机外，还有一种方法也可以追踪到手机。**那就是查询iPhone的ICCID。**

ICCID是一个20个数字的特殊编码方式，存储在SIM卡内。通过遗失iPhone的IMEI号就可以查询刷机的ICCID和维修记录。运营商补卡也是通过ICCID进行的，在补卡的手续单上也能见到这串20位的数字。(iccid的百度百科地址是baike.baidu.com/link?url=QvbPEsllDEBdFzoFNn9CqnuqQZ3GQ0U89nXd5XgujP-Ml3jnWCSSfRdEDzsaM49Kq8vpSOu1Sqd32uQ-X6MdSK)

![](../Images/9e07f869df27e0b2096ab6f1eb58a55f.png)

登录iCloud帐户在设备中查看丢失iPhone序列号及IMEI

ICCID方法找到手机的一个关键点是“被盗iPhone被其它SIM卡重新激活”，iPhone丢失后，后续的经手人一般都会有抹掉所有内容和设置，重新插入SIM卡激活的操作。只要ICCID信息发生了变更，就可以查到通过运营商渠道查到ICCID对应的手机号码乃至姓名。如果一切顺利就可以带着包装盒、收据、发票等证据去报警或协商取回手机。

当然以上所有设想都建立在，能够查询到被盗手机的ICCID。苹果原来是开放这个查询服务的，但是由于种种原因后来关闭了。目前只有在某宝上还有部分卖家提供这种查询。我在某宝搜索后发现，提供查询以及苹果找回服务的卖家不少，服务费用从100到几块钱的都有。最多的付费人数达到100多人，最少则为0。

![](../Images/96e9a629025aa4da5bc870771d69787d.png)

提供查询以及苹果找回服务的卖家 

在与一位卖家客服交流过程中，卖家称，只要小偷换了SIM卡我就能找到他，百分百找到你的手机。但是这个周期会非常长，快的话可能两三个月，慢的话可能得半年一年都有可能。

“百分百找到手机”、“最长一年时间”……这些说辞实在不能让人信服。最终我还是放弃了这条可能寻回iPhone的方法。

时间宝贵，我选择自认倒霉。

**第三件事：报警备案并补卡**

此时距离我丢手机已经过去两个小时，下午四时许，在朋友的提醒下，我才意识到应该拨打110报警。尽管找回来的可能性不大，但留下备案信息也有一丝生机。

下午四点半左右，我到达太阳宫派出所做笔录，警察详细询问我丢失的经过后，一再提醒我，**小偷为了解锁我的手机，很可能会利用钓鱼网站向我发送邮件，要求填写苹果ID及登录密码。凡是碰到此类邮件一定不要回复，最好也不要点击。因为苹果官方是不会发送邮件要求获取我的苹果ID密码的。**

做好笔录后，我第一时间联系中国移动客服申请补卡，需要提及的是，中国移动目前是无法办理异地补卡的。我只好将身份证寄回家里，请家人代办补卡。  

尽管媒体报道过很多手机找回的案例，但不得不认清一个现实，大部分丢掉的手机其实根本不可能追回来。

此前早有过报道，被盗手机背后其实隐藏着一条完整的“洗白流通”产业链，环环相扣，防不甚防。另一方面就是，丢手机的人太多，多到每个都立案调查，警察根本忙不过来。给我做笔录的警察就说过，“手机丢了以后找回来的可能性不大，只能先给你做个备案。”

手机丢失后的这3个小时里，我最担心的就是支付宝、信用卡等存在泄露以及被盗刷的风险。手机尽管没有找回，但是我几乎已经把后续存在的所有隐患全都消除了，也算是不幸中的万幸。

  

在此也提醒朋友们，外出时手机要保护好，一定不要放在外衣口袋内。同时，手机丢了之后，第一时间去报警，留下备案信息，后续无论是查询ICCID卡或是确定了小偷的位置要拿回手机，都离不开他们的协助。

  

最后，回到文章开始的那个问题，iPhone被偷了以后想要找回来总共分三步，**第一步定位，第二步报警，第三部上某宝查找ICCID****。**  

但并不是完成这几步后就肯定能找回，在这之外，还需要有运气的助力。所以，只能尽人事，听天命。
