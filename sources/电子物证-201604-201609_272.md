# iPhone微信分身版如何手动提取数据

前言       利用手机安装微信分身版进行微信诈骗的事件越来越猖獗，但是身边又没有取证软件支持分身版微信的数据提取怎么办？今天就给大家分享iPhone微信分身版数据的手动提取方法。

**手机基本情况：**

型号iPhone5 已越狱 系统版本IOS9.0.2 

安装有iPhone微信分身版  

![](../Images/6b7506ae0c0a653f1d724a00892a8938.png)  

![](../Images/d393c45eb02f533c8b91401eaf6e6f11.png)  

具体操作方法如下：

1打开PC端iPhone连接管理工具iTools软件

![](../Images/88b691e63692607a5cd5b73708928b9c.png)  

识别iPhone手机后→点击选择应用

2找到相应的iPhone微信分身版应用程序

![](../Images/06fc0a18ca82d7cbb4ed465dee3be0b6.png)

点击文件共享

![](../Images/6290cc5ac28680b2a08c716e386c8373.png)

3将打开路径下的所有文件保存至本地电脑，并按一定名称 如：微信分身版程序名称进行命名导出

将如上所有微信分身版数据文件夹，统一放入任意创建文件夹 如：E:\\weixin\\

 ![](../Images/c9f0df85eaea12e5ff078957409062a5.png)  

4最后使用DC-4501手机取证系统→文件解析→应用程序解析功能进行提取

![](../Images/e1bc5dabfee1af7f560c099bf89fbd01.png)  

![](../Images/b133c66c70a89bc2a9f891fb59ea68de.png)
