# 【257期-1】让数据“开口”,用证据说话

“审判长，我是乐陵市检察院司法鉴定人员，这是从被告人涉案手机SIM卡提取的已删除的15条短信……”近日，山东省乐陵市法院在审理该市看守所狱医赵某帮助犯罪分子逃避处罚一案中，该市检察院技术人员赵猛对获取的涉案电子证据及法律依据进行了出庭作证。最终，法院采纳该鉴定意见，被告人赵某被当庭判决有期徒刑一年零六个月。

据乐陵市检察院检察长尹国岭介绍，近年来，在职务犯罪侦查过程中，犯罪嫌疑人较多使用手机及电子邮件进行交流和沟通，为逃避刑事处罚往往采取加密、删除的方式故意破坏相关涉案数据，加大了案件侦破难度。

为破解这一难题，该院加大电子取证装备建设力度，并率先在国内法庭科学实验室中使用分布式取证系统进行电子数据的恢复提取，对涉案信息进行综合分析研判。

为确保获取的电子证据合法有效，今年初春，该院积极创建“技术侦查联动”工作机制，技术科与自侦部门无缝衔接、职能联动。自侦部门在办案中需要技术取证协助时，由办案人员报请检察长批准并填报《电子证据调取种类单》，技术干警随后介入案件，依托实验室管理平台，全程记录证据的获取、移送和检验过程，利用多种电子取证设备，提取、恢复、固定和分析涉案电子数据，确保提取的涉案证据具备法律效力。生成检验报告后，技术干警会对全部数据进行针对性筛选分类，并以技术侦查建议的形式交与自侦部门。

据了解，该院还特别注重电子取证人才的培养，采取“走出去”的方式到先进单位及科技研发单位学习；以“请进来”的方式邀请技术和技侦专家辅导授课，积极开展电子证据干警业务练兵活动。目前，该实验室4名工作人员全部具有最高检司法鉴定资格，1人具有CNAS实验室评审员资格，2人具有实验室内部审核员资格。

据悉，该机制运行以来，该院技术部门已协助德州市检察院、德州市纪检部门和德州市部分区县检察院及公安机关，提取涉案电子数据146次，出具电子数据检验报告56份，被法院作为关键证据采用28次。
