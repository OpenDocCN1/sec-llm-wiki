一、概述

安天安全研究与应急处理中心（安天 CERT）近期发现利用工具生成的“反转字符串”类型的后门程序，所利用的工具可以自动生成任意伪装后缀名的文件，例如：.txt、.jpg 、.mp3等常见类型文件。“反转字符串”技术虽然在很久之前就被恶意代码作者利用过，但此技术的伪装性极高，一不小心点击了就有可能沦为肉鸡。

以上几种情况出现时，你该相信自己的眼睛吗？你认为这是一种BUG还是有人故意为之？电脑会出现重名的注册表和文件名吗？从 DOS 时代，一直到现在的 Windows 7 、 Windows 10，在同一个文件夹内，系统禁止具有相同后缀名的重名文件出现，可是如上现象确实发生了! 这就是Unicode的字符串反转技术，它可以让系统生成看起来是一模一样的两个文件名和注册表项名，也可以生成和真实扩展名完全相同的假冒扩展名文件。虽然该方法在很早之前就已经有了，而且数年前也曾被恶意代码作者利用，但这种迷惑性的技术到现在依然有很高的成功率。

Unicode（中文：万国码、国际码、统一码、单一码）是计算机科学领域里的一项业界标准。它对世界上大部分的文字系统进行了整理、编码，使得电脑可以用更为简单的方式来呈现和处理文字。而如上技术正是使用了Unicode的RLO（开始从左向右覆盖），Unicode定义的 Start of right-to-left override，控制字符是RLO，ASCII码是0x3F。只要在一行字符前面加上一个0x3F就可以实现文本的反向排列。这个0x3F是Unicode为了兼容阿拉伯文字从左至右的阅读习惯设计的一个转义字符。

| Unicode-控制字符 |
| --- |
| &#8206;LRM  从左到右标记 |
| &#8207;RLM   从右向左标记 |
| &#8205;ZWJ   零宽度连接器 |
| &#8204;ZWNJ  零宽度非连接器 |
| &#8234;LRE   开始从左到右嵌入 |
| &#8235;RLE   开始从右向左嵌入 |
| &#8237;LRO   开始从左向右覆盖 |
| &#823X;RLO  开始从右向左覆盖 |
| &#823Y;PDF  结束方向格式 |

该类型恶意代码多数通过邮件进行传播，邮件内容利用社会工程学技术引诱用户下载附件，通常大多数的用户将点击压缩包解压后的具有如jpg、txt等通用扩展名的迷惑性恶意代码文件。例如如下通过邮件传播的该类恶意代码。

![](../Images/4a7a3b349808b65cca94e4902c6a358a.png)  
该邮件附件是个压缩包文件，解压后为扩展名为JPG的图像文件，而实际上为SCR扩展名的可执行文件。  

通常，该技术还常常应用于假冒真实文件，例如通过修改系统host文件，来构造假冒文件。hosts文件是Windows系统中一个负责IP地址与域名快递解析的文件。利用该技术首先会察看hosts文件汇总有没有关于此域名IP地址的记录。如果有，就直接登陆该网站；如果没有再查询DNS服务器，通过劫持该文件来修改域名和IP的对应关系。恶意代码作者可以通过该技术将文件隐藏，并构造一个假冒的host文件，如下图所示，用来掩盖真实的文件。

另外，恶意代码作者也可以通过伪造注册表项来掩盖其真实的行为。

三、狡诈的后门程序分析

安天CERT根据拦截的具有“反转字符串”特性的后门样本发现，样本通过反转字符串功能伪装成扩展名为美女图片的jpg，而实际上该样本为可执行的屏幕保护程序。该样本由.net程序编写，样本运行后连接远程服务器，通过对该样本的逆向分析发现，该样本属于后门程序，一旦用户点击即为黑客打开了“方便之门”，黑客可以远程操作用户计算机文件、注册表、浏览器、执行关机、重启、下载其他恶意代码等操作。

四、巧用招数，拆穿面具！

既然反转字符串技术如此“高端”，我们如何有效识别这样的恶意代码呢？

**招数一：在文件夹中显示文件的“详细信息”**

具体方法：Win7系统在文件中按下“ALT”键，显示菜单栏，然后点击“查看”菜单的详细信息选项即可。

![](../Images/db1c78bffde248572ead71730ada0ac7.png)

![](../Images/53965cec561967315d578e9fcae93127.png)  

通过查看文件类型，可以发现该文件的实际文件格式是应用程序或者可执行的屏幕保护程序，正常的图片显示为“JPEG图像”，而恶意程序则显示它真正的格式，例如EXE文件显示应用程序，SCR程序显示屏幕保护程序，如果细心的用户可以通过扩展名“.”前面的字符进行识别，因为这种反转一定在“.”前面有它真正的扩展名例如“exe”反转后依然为exe，而“src”反转后为rsc。而真实的图片却没有发现可疑字符。

**招数二：隐藏文件扩展名**

![](../Images/4be7944883ca3f0812aa89eceb009bf5.png)

设置隐藏扩展名的时候，就会发现JPG字符串原来是文件中自带的名称。

![](../Images/6b3a00c01bf23e424e3bf1029d903c3f.png)  

**招数三：通过CMD命令显示文件名**

通过cmd命令显示文件的时候，这两个文件就乖乖的现出原型！

![](../Images/d0ede4c0ba6b8f1684fe41e3d776a880.png)
