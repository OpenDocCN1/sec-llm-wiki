# 【216期-4】新技能get：怎么恢复刚刚删除的电脑文件

我们经常会不小心误删了重要文件，更糟糕的是，连回收站都被清空了，这时候再想找回文件难上加难。不过没关系，教你一招简单易学的方法，分分钟把文件恢复过来。  

1、点击电脑桌面左下角图标，出现以下界面后，输入“运行”二字，进行搜索  

![](../Images/5a08d562499bd71d3206c385f0788792.png)

2、搜索到“运行”这个程序后（如下图所示），点击该程序  

![](../Images/9bab0fcb88da7a2e25333ea637a07738.png)

3、在运行程序的输入框中输入“regedit”点击确定

  

![](../Images/f9f105836ee0f919a5efe2c9f1c4cd8b.png)

4、进入注册表，找到“HKEY\_LOCAL\_MACHINE”，请依据下图指示，点击红色框内，箭头所示的文件夹前的三角按钮  

5、在展开的文件夹中，找到“SOFTWARE”点击红色框内，箭头所示的文件夹前的三角按钮  

![](../Images/b05c07616505a49c865e4bf9722c8dec.png)

6、在展开的文件夹中，找到“Microsoft”点击红色框内，箭头所示的文件夹前的三角按钮  

![](../Images/ca0b80ee61199e918862114c92ce1eba.png)

在展开的文件夹中，找到“Windows”点击红色框内，箭头所示的文件夹前的三角按钮  

![](../Images/6e9e00bf9a5acffe1333aca13139086b.png)

在展开的文件夹中，找到“CurrentVersion”点击红色框内，箭头所示的文件夹前的三角按钮  

![](../Images/03db9e34421aac1676170f456e5cb345.png)

在展开的文件夹中，找到“Explorer”点击红色框内，箭头所示的文件夹前的三角按钮  

![](../Images/d20960c70937a0457c9516fbb39ca4ea.png)

在展开的文件夹中，找到“DeskTop”点击红色框内。  

![](../Images/f2a7f5e558dd3396129f947376d02a53.png)

点击红色框内的“NameSpace”文件夹，右边出现“默认”等。  

![](../Images/3bd215b386a549f7267afa05390c36d9.png)

点击右键，新建“项”将新出现的项的名字（红色框框内显示）重命名为{645FFO40——5081——101B——9F08——00AA002F954E} ------------请注意，要把大括号也带入  

![](../Images/9f04422017095a3f2aaa84eeb9f2bac6.png)

![](../Images/2c877a5fb7da157ac095773823d0352b.png)

点击新建的项，右边会出现默认等显示，右键点击“默认”二字，点击修改，出现如下界面  

![](../Images/e8e709715f63bb90a8f8e689b944960a.png)

点击修改后，出现如下界面，请在数值名称一项中，将“{默认}”修改为“{回收站}”点击确定  

![](../Images/0a39ec642d683657d4811f7a023d1bc4.png)

重新启动电脑，打开回收站，是不是发现回收站刚才清空的内容都已经恢复过来啦？
