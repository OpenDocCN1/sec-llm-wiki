# 【206期-2】电子证据未必都靠谱

记者：郭卫艳

  

2015年2月4日，最高法院发布了《关于适用〈中华人民共和国民事诉讼法〉的解释》，并于当天起施行。司法解释明确，电子数据是指通过电子邮件、电子数据交换、网上聊天记录、博客、微博客、手机短信、电子签名、域名等形成或者存储在电子介质中的信息。这就意味着，平时市民在QQ或其他平台的聊天记录、博客、微博客、微信朋友圈留言、手机短信、电子签名、域名等电子数据信息，都能作为民事案件中的“呈堂证供”。  

那是不是意味着保存了QQ聊天等记录官司一定能赢？3月5日，记者对此进行了采访。  
聊天记录成了关键证据  
1997年，张某开办了一家个人独资的个体诊所。为了诊所的发展，2001年，张某邀请李某等4人做股东，合伙经营。经营过程中，除张某和李某的股东身份外，其他股东均被更换。2007年，诊所变更了名称，投资人变更为李某，但诊所依然实行股份制。2011年后，张某和李某因分红发生矛盾，张某要求退伙并清算，但李某不同意也不承认张某的股份。  
庭审中，张某在诊所还有无股份成为争议焦点。围绕这一关键问题，两人均列举了2012年5月双方的QQ聊天记录，但内容并不完全相同。法官认真核对，分析内容语句表达的完整性和合理性，发现李某的内容有删减，而张某的相对完整。  
法官认为，从双方QQ聊天记录中谈及的“张某是否能重回诊所、股利分配、退出合伙”等内容，结合其他证人证言等证据，能够确定张某提供的QQ聊天记录内容连续、完整，足以证明双方合伙的事实。于是，法庭采信了张某的QQ聊天记录内容，依法判决双方合伙关系成立，应在指定期限内清算。  
存储在电子介质中的录音资料和影像资料也作为电子数据  
上述的这起案例，是2013年新《民事诉讼法》实施后，太原市法院首次采用QQ聊天记录做证据裁判的案件。2013年实施的《民事诉讼法》63条规定的8类证据中就明确规定了电子数据。只是，当时没有对电子数据做出明确的界定。这次的司法解释，就对此做了列举式的规定，明确规定，电子数据是指通过电子邮件、电子数据交换、网上聊天记录、博客、微博客、手机短信、电子签名、域名等形成或者存储在电子介质中的信息。同时，将存储在电子介质中的录音资料和影像资料，也适用电子数据的规定。  
在之前的《民事诉讼法》中，录音资料和影像资料都作为视听资料，属于另一个证据范畴，这次将存储在电子介质中的录音资料和影像资料也作为电子数据。这也是考虑到电子数据在日常生活中的广泛使用，相对于传统的录音、录像手段，现在随着智能手机和无线网络的普及，电子录音录像的应用更为普及。  
举个简单的例子，现在人们习惯在手机上利用QQ、微信进行聊天或者发送视频。在此次司法解释出台前，这类证据算是视听资料证据，现在就算是电子数据证据。  
**电子数据不能单独作为证据使用**  
那是不是保存了QQ、微信聊天等电子数据打官司就一定能赢？北京大成（太原）律师事务所马俊律师表示，电子数据相对于传统的书证、物证而言，存在很大局限性，如容易被篡改、丢失、不易保存等缺陷。因此，切忌对电子证据产生过分依赖。  
马俊表示，最高法出台司法解释规定的意义在于弥补了司法实践中法律文件的滞后性，扩大了电子证据的界定范围。“切忌对电子数据产生过分依赖，误以为只要保存了电子聊天记录，将来就能够打赢官司。”马俊律师解释说，这是因为，电子数据有其局限性，容易被对方否认。  
举个简单的例子，A向B借款20万元，A给B发手机信息说“我收到20万元。”事后双方发生纠纷，B不能仅凭这条短信就能证明自己借钱给A的事实。他首先要证明发信人的手机号是自己的，收信人的手机号是A的。这就需要去通讯公司调阅证据佐证。同时，B还需向法院提供这笔借款的走向，如银行汇款单据等。  

所以说，电子数据不能单独作为证据使用，相比于手机短信，QQ、微信等聊天记录因不是实名登记，证明力就更差，且更容易被人篡改，作为证据的证明力就更差。  
在马俊律师看来，电子数据证据只能将电子数据作为一种固定证据的非主要手段。对于重大事项还是需要采取其他一些补充证据。如，在遭遇朋友借款等情况时，除了短信或QQ聊天记录外，最好能写个借条补充下，防范法律风险于未然。
