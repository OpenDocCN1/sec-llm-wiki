# 【206期-3】提供电子数据须补强其他证据

据无锡市崇安区人民法院法官吴伟介绍,在取证环节,基于电子数据的属性,其固定和提取需要较高的计算机专业知识,许多当事人取证时需要借助专业的鉴定机构和公证机构进行,无形中增加了诉讼成本。同时,在当事人申请法院对电子数据证据进行保全时,电子数据在存储方面也遇到难题。

“电子数据证据需要存储在特定的电子介质上,它的播放、展现需要借助电脑等特定的电子设备。但目前大部分审判法庭没有专门的设备,即使有内网电脑,也不能插入光盘、U盘等,给电子数据证据的当庭质证带来诸多不便。”吴伟说。  
“另一方面,当事人对另一方提供的电子证据自认的仅占二成左右,大多情况下,提供电子证据一方会通过公证、鉴定、证人辅助作证等形式对电子证据予以补强,但由于缺乏明确的电子证据认证规则,部分公证、鉴定存在瑕疵缺漏,这些都增加了法院对电子证据认证的难度。”吴伟补充道。  
而苏州市相城区人民法院民一庭庭长黄伟丰认为,对于公证的效力,民事诉讼法第69条规定,“经过法定程序公证证明的法律事实和文书,人民法院应当作为认定事实的根据,但有相反证据中以推翻公证证明的除外”。由此可见,经过公证的电子证据具有较高的证明力,但也有所局限。  
“因为公证只能证明电子证据的表现形式、形成过程,如在某个时间点,某邮箱向另一邮箱发送了某标题的邮件,但邮件究竟由谁发出,其内容是否真实等,则需要法官加以判断。”黄伟丰说,但是,对于电子数据证据的真实性、有效性的认定,很多都涉及到专业知识,需要一些信用良好的信息公司,参与电子证据的收集和鉴定工作,协助法院解决电子证据技术方面的难题。  
此外,在司法实践中,还存在法院向电子数据后台经营者调查时受阻。吴伟表示,有些案件需要核实账号和实际使用人是否匹配时需要去经营者处调查,但一些企业以《电信条例》仅规定公安机关、国家机关及检察机关可以对电信内容进行检查为由,拒绝法院工作人员在民事案件中调取相关证据。  
“当前,民事案件呈现事实难认定、当事人诚信不足、虚假诉讼等问题,根据法律规定,人民法院有权向有关单位和个人调查取证,有关单位和个人不得拒绝。”为此,吴伟建议,相关部门应对电信条例中与诉讼精神相违背的规定作出调整。  
黄伟丰表示,在婚姻情感纠纷、劳资纠纷、商业纠纷、名誉侵权纠纷等诸多案件中,当事一方或双方提交电子数据作为证据的情形越来越多。在只有电子数据证据的情况下,其对案件的认定能否起到决定性作用需要有相应的法律法规予以明确。  
据黄伟丰介绍,目前,我国规定电子证据收集、认证等方面内容的大多是司法解释,其内容零散不成体系,缺乏刚性条款。只有《中华人民共和国合同法》第11条、最高人民法院《关于民事诉讼证据的若干规定》第22条、刑事诉讼法第48条、民事诉讼法第63条等部分法律条文涉及到诉讼中的电子证据问题。因此,需要尽快完善相关立法,对其适用范围、采纳条件、可采性原则等作出明确规定。  
黄伟丰同时表示,在现有法律法规的框架下,遇有电子数据证据时,当事双方应当注意取证的及时性,必要时借助专业机构,提高证据的证明力。同时,特别要注意收集能补强电子证据的其他证据,比如涉及单位内部系统有关电子数据时,单位技术人员或服务器管理方的相关证明对增强证据效力就有一定作用。
