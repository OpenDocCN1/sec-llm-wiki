前言

       在实际工作中可能会遇到嫌疑人租赁国外服务器以逃避备案及检查达到犯罪目的，并且，很多服务器都是Linux系统，只能通过嫌疑人提供的IP来远程分析。远程一般是通过ssh远程控制，并不像Windows一样可以远程桌面，这就需要调查人员熟悉各Linux命令。如何使远程工作更加简便易操作呢？今天就给大家分享两种在Windows系统中以图形化的方式来显示Linux应用的方法，希望对大家的日常工作有所帮助。

方法一：使用Xming配合PuTTY来实现Linux应用图形化显示
1
安装配置Xming Server

Xming是一个Microsoft Windows平台上免费的X Window Server，可以方便地实现在Windows中运行Linux应用程序。

（1）下载并运行安装程序，按照提示点击下一步

（2） 如下图所示，选择图中所示选项，并且点击下一步


（3） 继续点击下一步直至完成安装。

（4） Windows快速启动栏中找到XLaunch，执行以下步骤。






2
通过PuTTY 连接Linux 

（1） 输入需要远程服务器的IP地址


（2） 设置”连接”->”SSH”->X11，勾选允许X11映射，X显示位置设置为localhost:0


（3） 打开SSH连接，输入export DISPLAY=192.168.1.239:0.0

（4） 输入打开程序的命令如firefox ，如下图所示，输入完命令后Windows系统下面已经打开firefox浏览器了。
