前言

       在实际工作中可能会遇到嫌疑人租赁国外服务器以逃避备案及检查达到犯罪目的，并且，很多服务器都是Linux系统，只能通过嫌疑人提供的IP来远程分析。远程一般是通过ssh远程控制，并不像Windows一样可以远程桌面，这就需要调查人员熟悉各Linux命令。如何使远程工作更加简便易操作呢？今天就给大家分享两种在Windows系统中以图形化的方式来显示Linux应用的方法，希望对大家的日常工作有所帮助。  

方法一：使用Xming配合PuTTY来实现Linux应用图形化显示1安装配置Xming Server

Xming是一个Microsoft Windows平台上免费的X Window Server，可以方便地实现在Windows中运行Linux应用程序。

（1）下载并运行安装程序，按照提示点击下一步

（2） 如下图所示，选择图中所示选项，并且点击下一步

![](../Images/5facf8eaaa8e16eccab8a04f3875ea7e.png)  

（3） 继续点击下一步直至完成安装。

（4） Windows快速启动栏中找到XLaunch，执行以下步骤。

![](../Images/126c50edb357cd646288fa65e5c63bd5.png)  
![](../Images/ed036d9b88b05a35f9693245482e2839.png)  
![](../Images/1f75576f4ce30559065226035f4d678d.png)  
![](../Images/a80e0f7a89f40a90fa524b368f6ac2a6.png)  
![](../Images/c13a8d3f5df35ac338f1ad9df142837f.png)  

2通过PuTTY 连接Linux 

（1） 输入需要远程服务器的IP地址

![](../Images/584e9c0da1322df06d55b6860688b80d.png)  

（2） 设置”连接”->”SSH”->X11，勾选允许X11映射，X显示位置设置为localhost:0

![](../Images/a8eb3865b94cfe06387f19376f7b41d1.png)  

（3） 打开SSH连接，输入export DISPLAY=192.168.1.239:0.0

（4） 输入打开程序的命令如firefox ，如下图所示，输入完命令后Windows系统下面已经打开firefox浏览器了。

![](../Images/601ec6532dba03c36fc5e05b6c3f818f.png)

方法二：使用Xmanager 实现图形化Linux应用1安装配置Xmanager

（1）下载Xmanager程序并安装，安装时都按默认配制，安装好后开始菜单可看见如下图显示程序。  

![](../Images/defbc11a3e845ab45acdb0a82d075251.png)  

2通过Xmanager连接Linux

（1）打开Xshell，新建对话，并设置好ip

![](../Images/6255fe591e518c99c50a06dea9d4cffe.png)  

（2）设置SSH 隧道

![](../Images/aa5d0aa6f02d69896620fe37c09feed2.png)  

（3）连接并登录后如下图所示

![](../Images/c193c6b6c29ac8afcf610c3eaaecf529.png) （4） 输入相应命令，打开程序。如下图所示，我输入的是KVM虚拟机管理器的命令，左侧画面就直观的显示出相应的程序了。

![](../Images/ad9f357a7171871a342b000391c946ca.png)  

方法一设置相对来说比较复杂，因为是两个程序配合使用，如果设置不匹配可能会无法显示图形化，好处是此方法使用的两个软件完全免费。方法二因为是软件集成环境设置比较方便，一般不会出现问题，但软件需要付费。
