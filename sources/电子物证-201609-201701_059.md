**授权转发！**

OTG是On-The-Go的缩写，主要应用于各种不同的设备或移动设备间的联接，进行数据交换。

OTG技术就是在没有Host的情况下，实现设备间的数据传送。例如数码相机直接连接到打印机上，通过OTG技术，连接两台设备间的USB口，将拍出的相片立即打印出来；通过OTG技术，可以给智能终端扩展USB接口配件以丰富智能终端的功能，比如扩展遥控器配件，移动存储等。 

![](../Images/2fe2d33a9b94554642ed704fb570621b.png)

根据USB接口所属协议，OTG可分为3类：  

**USB2.0 OTG：**Micro 5PIN OTG为常见Android手机OTG接口

**Micro USB3.0 OTG：**三星NOTE3、Galaxy5高端手机OTG接口

**Type C OTG：**常见乐视、小米手机Type C OTG接口

以下是OTG转接线的照片，可以清晰的看出不同协议的区别。

![](../Images/3c1e0b3e2b822ed54cfd43ba96b2410a.png)

在手机取证过程中，某些情况下会需要借助第三方备份（recovery模式）的方式实现密码绕过或获取root权限，进而实现常规提取无法获取到的数据。在recovery模式下备份时，如果手机本身不支持扩展存储卡，默认会将分区备份在机身内置存储，这样无疑对于机身存储会造成数据覆盖，对于后期想通过镜像的方式实现数据恢复会造成影响。  

是否可以利用OTG功能将机身数据备份到OTG存储呢？我们用小米4（android6.0未root，本身不支持外置扩展卡）做了尝试。因为小米4不带BL锁，通过刷入第三方recovery，重启进入recovery后我们可以看到“备份分区”功能，进入该功能后其中可选择的备份路径显示出了机身存储和OTG存储两部分，我们更改备份路径到OTG优盘，即可实现备份功能。

![](../Images/f9a0e23f1ada4b179a09a5cd78f2c8c0.png)

![](../Images/72c81aee3cbf8f37e387d8eb8eeaa1fe.png)

备份结束后，取下优盘，接入计算机后查看如下：  

![](../Images/a328dbf6ae3f0e50bb65edd388ff91db.png)  

因为在备份时只选择了data分区，而TWRP默认是将备份文件进行分卷的，所以我们看到的是以win000、win001、win002……结尾的分卷文件。同时每个分卷对应的有校验MD5值。其实以win00结尾的是压缩文件，我们手工或通过工具将分卷合并后进行解压就可以看到data分区的实际目录结构了。红色区域内的就是将分卷合并后的文件。  

![](../Images/7a20b1eab9ddb00427a9c62d6de4defe.png)  

对tar包进行解压后，data分区的目录见下图：  

![](../Images/c7a5a961cfa8a92de5217ec6266e5894.png)

拿到data分区后，我们可以通过手机取证工具的加载“文件集合”的方式进行解析，拿到相关数据。同时对于取证软件不支持的App，我们也可以针对该App的数据库文件进行手动解析查看。

一些国外手机取证产品也有效利用OTG技术来实现Android和部分iOS设备的密码破解，例如Cellebrite公司的UFED系列，可以利用OTG功能来模拟密码输入，进而达到破解部分安卓设备屏幕锁的目的。
