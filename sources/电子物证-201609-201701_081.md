# 怎么用手机号码定位找人

如果手机不慎丢失，最直接寻找手机的方法就是通过手机号码进行**定位**，实现的方法有多种，那么具体如何用手机号码定位找人呢?

  

![](../Images/036ccae86ca6a8a1f10cb2e51489e1c8.png)  

  

　　1、部分手机在出厂时其官方已设置了定位功能，只需要注册相应的账户即可用手机号码定位找人。如“魅族手机”。直接登陆官方，进行注册或登陆操作。

  

![](../Images/26bb088541882f74051ccd6c36a74e16.png)  

  

　　2、待登陆完成后，依次点击“Flyme”导航栏进入，所有有关定位信息均在此列表中进行操作。

  

![](../Images/d059766a3b2fbeef7f337dc73f8364a2.png)  

  

　　3、接着点击”云服务”-“查找手机”项，就可以定位并查看当前手机所在的位置啦。

  

![](../Images/6a00563f8a1d2b375453c99c517ba3b9.png)  

  

　　4、用用手机号码定位找人的另一种方法是通过植入客户端来实现远程定位操作。比如“腾讯管家”、“360手机助手”之类的软件就可以实现。给手机安装“腾讯手机助手”，切换到“安全防护”选项卡，点击“手机防盗”项。

  

![](../Images/88eb9e5d17e97ec2b342283ffccb992d.png)  

  

　　5、接着利用QQ号登陆并关联，就成功开启了防盗功能，此时操作方法会给予提示。

  

![](../Images/b738c330584f9b7e0d239119ff353e39.png)  

  

　　6、关于用手机号码定位找人的问题总结，根据提示，在电脑端登陆相应的网址，并输入QQ号进行登陆操作，即可进行远程控制并定位找

  

![](../Images/90bb96d0424cb027f07ca6e6b4612ebe.png)
