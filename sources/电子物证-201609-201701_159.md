# 手机取证新途径：QDLoader9008端口

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651028960&idx=1&sn=fbf8361448d1e577b57422164651af0c&chksm=80d03211b7a7bb074fffec76ee3d662cfff84ee9fe4f431b3038edd5fe5573cf91c3bd571284&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651028960&idx=1&sn=fbf8361448d1e577b57422164651af0c&chksm=80d03211b7a7bb074fffec76ee3d662cfff84ee9fe4f431b3038edd5fe5573cf91c3bd571284&scene=27#wechat_redirect)

**![](../Images/ef4355d9c625e77a0d5fb92f781bb1e9.png)**

来源：科技强检（ID：techjc）

  

高通芯片的安卓手机，如果不能用常规方法逻辑提取，比如不能正常开机、未root、有话机锁等。都可以通过识别到QDLoader9008端口进行物理镜像提取。需要注意的是，这种方法只是提取手机完整镜像，但如果本身手机有加密，备份出来的镜像同样也会加密不能解析。

* * *

  

步骤如下

  

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

1

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

首先安装 QDLoader HS-USB Driver\_64bit\_Setup.exe 驱动包，然后重启电脑。重启电脑后，打开设备管理器，看是否识别到QDLoader9008端口并且状态为运转正常。如图，证明驱动已安装成功。

  

![](../Images/f687c4b1dc4e888c89081bd1bed95e84.png)

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

2

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

如果安装后驱动不正常 （有黄色叹号、提示异常）。重启系统时F8 选择“禁用驱动程序签名强制”模式进入系统，再确认驱动状态。  

  

![](../Images/dd2392d0fbddb6352359617dd8e934cf.png)

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

3

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

将手机关机，按住音量下上键的同时，使用USB数据线与电脑连接（请尽可能用主板后置USB端口，以确保提取过程中供电正常）。等待2~3秒，确认设备管理器识别9008驱动设备，松开音量键。  

  

![](../Images/91cbf6673e80ea52a82a60af559ee922.png)

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

4

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

进入安卓手机镜像文件提取界面，点击【安卓手机镜像文件】，选择【高通QDLoader模式】，选择提取区域（Data区和System区）。加密的手机，通常开机备份Date区是没有加密可以解析的，但是这种方式与开机备份不同，如果手机有加密，备份出的Date区也同样会加密。（以下截图来源于RH-6900取证工具）  

  

![](../Images/9c87a04ad8e02abf57237975417996a9.png)

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

5

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

点击【提取镜像文件】，选择备份镜像的位置和名称，点击【保存】，镜像开始备份。  

  

![](../Images/2e8e103ec0eaffe4946ff5171b6b14ff.png)

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

6

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

正在提取界面。  

  

![](../Images/a07f412a8dde87151d07d49d0bacb56b.png)

0

![](../Images/725a3bc4347d04468bd8bce7ee6996c5.png)

7

![](../Images/76d6ee0664abae4b457a034cae19d857.png)

镜像备份完成。备份出的镜像，可以直接进行镜像分析。

  

![](../Images/7fffbea6b980d98ed22f6f1ebfef4b73.png)

  

此方法理论上适合所有采用高通CPU方案的安卓手机。
