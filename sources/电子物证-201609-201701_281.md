# 蓝牙信标：小区间谍？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651028840&idx=3&sn=d13742d9354a8fdf89fd84454e9e56bb&chksm=80d03299b7a7bb8f35865b9835a42fcf0f32a8ebeeb90a53afe582ec2eeae8e79e94f31fd360&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651028840&idx=3&sn=d13742d9354a8fdf89fd84454e9e56bb&chksm=80d03299b7a7bb8f35865b9835a42fcf0f32a8ebeeb90a53afe582ec2eeae8e79e94f31fd360&scene=27#wechat_redirect)

 今年上半年，北京市朝阳区东坝社区的多个小区里安装了一种能够监测到居民手机型号和地理位置的设备，这一设备甚至有可能导致手机泄密。这个设备被称为蓝牙信标，是一种手机应用的外置设备。蓝牙信标到底是什么？它会泄露我们手机里的秘密吗？ 

![](../Images/fd834f22cdddd8ed342027bab274940d.png)  

那么,蓝牙信标究竟有何功能,存在怎样的法律风险,消费者又该如何看待这一新生事物呢? 

       **蓝牙信标可实现定位推送服务** 

蓝牙信标是手机应用的外置设备,其工作原理是通过低功耗蓝牙向周围发送自己特有的ID,手机上的应用软件可以扫描并解析出ID,最后实现基于室内位置的信息推送。蓝牙信标本身不具备收集数据的功能,不会窃取手机用户的身份信息,但有手机定位并推送信息的功能。 

相比于传统的GPS定位,蓝牙信标具有耗电量小、定位精准、方便室内使用等优势,同时具备发送信息的“信”功能和标明位置的“标”功能。又由于蓝牙信标可以不间断发送信号,一旦手机用户进入蓝牙信标的信号覆盖范围内,就可以形成手机端的自动应答机制,无需用户多余的手动操作,即可以实现信息接收功能。

![](../Images/2e11165e7e06082569e845094cf39a2f.png)  

基于上述优势,蓝牙信标的应用前景广泛:如在饭店安装的蓝牙信标,可自动向进入餐厅的每一名手机用户推送电子优惠券；博物馆内安装的蓝牙信标,可以向参观的手机用户推送每一件展品的信息,而且在推送方式上,可以实现用户靠近展品一定距离内才推送；甚至迷路的野外探险者,也可以借助设置在路边树丛中的蓝牙信标,接收最方便的回家路线信息。正如有媒体评论,蓝牙信标的广泛应用,就像神奇魔法一样,将传统手动刷条形码或二维码的应用空间大幅缩减,从而极大方便了人们的生产和生活。 

　　**便利的同时存潜在风险**

 科技就像一把双刃剑,给人们带来便利的同时,也有可能引发诸多风险。如果对蓝牙信标的安装设置不加限制,且不附加任何接收条件,就有可能导致手机用户每天接收到很多垃圾信息,而真正对其有用的信标信息反而被淹没。如同垃圾邮件,蓝牙信标信息也可能被反复推送,消耗手机内存,浪费手机用户时间。

此外,如果蓝牙信标的维护运营权流落到不法分子手中,极有可能成为作案工具,被用来发送各类违法信息。较为常见的网络电信诈骗犯罪信息,如通过安装在老年公寓、学校的蓝牙信标发送,就使得犯罪分子更容易定向发送给老年人、在校学生等特殊群体,导致诈骗犯罪高发。由于蓝牙信标通常被用来推送各类商业广告,更为常见的是,个别广告经营者可能为了谋取不法利益,采用控制的蓝牙信标发送各类虚假广告,侵害消费者合法权益。 

![](../Images/9a257ab055ab2c496e15db0290af2cfa.png)  

此外,虽然蓝牙信标不具有收集手机用户信息数据的功能,但是其推送的信息却可以被加入木马链接,一旦手机用户点击相关链接后,即被种上隐蔽的木马程序,进而将手机内的各类身份信息、财务账户信息等发送到嫌疑人指定的手机号码中,导致手机用户的隐私被泄露、财产受到损失。因此,面对蓝牙信标这一新生事物的推广普及,需要引导其在法治轨道内发展,既不能因为“不明真相”,将其扼杀在摇篮中,又不能放任不管,任其肆意侵害社会安宁和社区居民的合法权益。 

　　**小区居民有权对蓝牙信标说不**

蓝牙信标的法律监管首先应注重源头治理,即着重从蓝牙信标的生产、安装环节着手,明确生产厂家的主体责任。对于蓝牙信标的生产应当建立产品序列号制度,明确记录每一生产批次的蓝牙信标从生产到安装的产品流转情况,保障事后倒查责任能够予以落实。在产品类型上,对于那些不需要在手机端安装解码接收程序的蓝牙信标,由于其具有全面推送信息功能,需要更为严格的监管制度,保障其信息发送的合法性。 

值得关注的是,蓝牙信标的监管主体不仅应包括蓝牙信标的生产厂家、信息运营者,还应当将蓝牙信标装置场所的第三方管理主体涵盖进来。例如,在安装蓝牙信标的居民小区或者商业楼宇,居民小区物业方和商业楼宇经营方的监管责任仍然不能推卸。王然称,从法律关系上来看,小区物业受业主委员会委托,对居民区内的安全秩序负有保障义务,商业楼宇的运营方受商业公司的委托,对商业秩序的规范负有监管责任。因此,对于各类信息发布者在小区内或商业楼宇内擅自安装蓝牙信标或者违法推送有害信息的,小区物业或者商业楼宇的运营方均负有监管责任。 

对于个人用户而言,如果不想被蓝牙信标“骚扰”,最好在不使用蓝牙功能时关闭该功能,或者关闭蓝牙的“可被发现”功能,同时,应注意更改蓝牙初始密码,防止蓝牙功能“裸跑”。

在居民区,小区业主委员会还可通过召集业主商议的方式,选择允许或不允许安装蓝牙信标,一旦一半以上小区业主明确表示反对,则不应继续安装,已经安装的应当及时拆除。对于商业楼宇内的蓝牙设备安装,应一半以上商业店铺可以行使安装否决权,保障商业楼宇的蓝牙通讯不受影响,维护手机用户的选择权利。
