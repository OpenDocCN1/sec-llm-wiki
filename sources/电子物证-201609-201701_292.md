# 使用linux单用户模式更改root用户密码

前言

        在取证过程中难免会遇到linux操作系统取证，在linux操作系统中又以ubuntu和CentOS（RedHat）系统比较常见。liunx系统取证一般需要仿真还原使用状态以获取更多数据例如数据库，软件运行环境等，因此获取root权限也是取证工作中比较重要的一环，不然很多东西都无法查看。下面我们以常见的linux系统centos6.X 7.X以及ubuntu 10.X为例来讲解如何通过单用户模式来更改root用户密码，由于linux各版本太多，此处不一一列表。

**一. Ubuntu 10.X系统进入单用户模式更改root密码方法**

  

1启动Ubuntu系统，并按住“shift”键，进入grub。

  

  

![](../Images/4bb080e0308896433708016c441d289d.png)  

  

2选中上图中第一个选项按“e”,进行编辑。

  

  

![](../Images/ed4c8196b01f8f65f148bd976391d194.png)  

  

3找到如上图中ro开头的选项，更改为 rw init=/bin/bash ，（ro后面内容，不同版本可能会有不一样），如下图所示。

  

![](../Images/3bacac320d1e6e01adf17b7101496f61.png)  

  

4按“ctrl-x”启动，当看到#号提示符后通过passwd root命令更改密码。

  

![](../Images/39de5a795b03fd127ed84b25c7373531.png)  

  

5强制重启后，可正切换到管理员权限。

  

![](../Images/ed3b03f3a261fae2d891888a3236698b.png)

**![](../Images/119cb98b17168166cfa5534d1e0b7932.png)**  

**二. CentOS6.X（redhat6.x）  如何通过单用户更改root密码**

  

1仿真操作系统，看到如下图界面是按任意键。

  

![](../Images/7b2b082b6045c71d49a4003825086455.png)  

  

2当出现如下图画面是按“e”进入下一画面。

  

![](../Images/621164307b1c32ece4eb0b373d2fcf83.png)  

  

3当出现下图界面时，选择“kernel”选项，再次按“e”进入编辑画面。

  

![](../Images/4de103e88618046b6afb6becaee2c48f.png)  

  

4当出现如下画面时，在最后面加上“single”。

  

![](../Images/84087b321d74476b6f81ca60a30661f4.png)  

  

5按“回车”键回到前一个画面，再按“b”启动。

  

![](../Images/74541a838a7599f24c245c6c55698d88.png)  

  

6启动后如下图显示，已进入单用户模式。

  

![](../Images/07d4ec041c85efded9cd72c4dc76d16d.png)  

  

7通过passwd root命令更改用户密码，并重启系统。

  

![](../Images/755270ee80ead9bfd25f08c9379a8350.png)  

  

8重启后我们就可以使用刚才更改的密码登录操作系统。

  

![](../Images/854a95f7b392c20d9214284ea3e96da7.png)  

![](../Images/119cb98b17168166cfa5534d1e0b7932.png)

**三. CentOS7.x（redhat7.x）通过单用户更改root用户密码**

  

1仿真系统，看到如下画面是按“e”进入编辑模式。

  

![](../Images/656379829104dff69b0b391bd11c9d32.png)  

  

2找下如下图所示ro开头的选项。

  

![](../Images/226d40dffa9ae5c122d71c63bbba8158.png)  

  

3

 更改ro为rw 并在后面加入init=/sysroot/bin/sh字段，如下图所示。

  

![](../Images/cb157f77e6f470ca87700e52bb63d990.png)  

  

4

按“crtl-x”启动系统，按到#号提示符后依次输入如下命令，并强制重启系统。

# chroot /sysroot/

# passwd root

  

![](../Images/7998ca44e430ea72d6fed52d6e8a0015.png)  

  

5系统重启完成后就可以使用更改后的root密码登录。

  

**![](../Images/d652846eb15e8b50422c66a1552a2cac.png)**
