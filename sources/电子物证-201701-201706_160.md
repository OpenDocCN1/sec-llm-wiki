# 【案例分析六】手机信息数据获取、恢复及固定

段颖，性别女，35岁，2月份因车祸不治身亡，留下一双年幼的儿女。3月其丈夫将溪东进出口贸易有限公司（以下简称溪东公司）告上法庭。

事情始末是这样的，段颖一直从事财务工作，2015年10月从别的公司跳槽到溪东公司。由于溪东公司规模不大，员工数量少，所以内部管理不是很规范。公司招聘由老板直接负责，新员工通常只需要经过老板面试满意后就能直接进公司上班。不仅如此，公司大部分的员工都没有五险一金，其中也包括入职没多久的段颖。2月一天的工作时间，因工作需要负责财务工作的段颖需跑一趟银行。万万没想到这时死亡的威胁已经一步步向段颖逼近了。砰！段颖倒在血泊中，命丧当场。由于当时路况比较好，一辆想闯黄灯的出租车，没来得及刹车撞倒了前往银行办事的段颖。噩耗传来，段颖的丈夫胡天几近崩溃。收拾好心情，为段颖办了一场简单的葬礼后，胡天找到溪东公司，向其索要工伤赔偿。溪东公司以没有劳动关系的理由拒绝了胡天的要求。多次交涉无果后胡天将溪东公司告上法庭。

胡天在检查段颖的手机时发现了大量段颖生前与溪东公司老板短信来往的记录，并发现微信中有一个以溪东公司命名的群，群中包含了关于公司日常工作的聊天记录。胡天的律师委托我中心对手机内的相关短信和微信群聊天记录进行提取固定。

![](../Images/5093788282c88168eb6e2c7c40a932f0.png)

在取证实验室鉴定人员对送检手机进行拍照留证，使用专业手机取证工具对已开启飞行模式的送检手机内相关短信和微信群聊天记录进行提取固定。通过查看群内微信号的基本信息，可认定群内成员都是溪东公司员工。在与委托人沟通后对送检手机进行数据恢复，恢复出一条由溪东公司老板发给段颖的内容是“你明天可以来上班了”的短信。我中心出具的鉴定意见书，最终被法院采纳，法院认定溪东公司与段颖有劳动关系，并需依法对胡天进行工伤赔偿。

**分析：**手机早已超出了通信工具的范畴，有着强大的功能，能记录我们生活中的点点滴滴。在我们执业过程手机作为送检材料越来越常见，经常会起到证明案件事实的关键作用。由于微信和QQ的聊天记录内容基本无法篡改，所以经常做为证据使用，在确认聊天双方真实身份的前提下，法院都会予以采纳。
