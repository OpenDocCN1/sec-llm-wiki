# 【案例分析五】电子邮件固定及获取

速到汽车贸易运输公司（以下简称“速到”）因业务发展需要，近期准备采购20辆大型汽车。速到与多家汽车生产商洽谈后，也算是千挑万选，最终因为可提供高品质的售后服务及过硬的产品，而选择采购千里马乘用车集团有限公司（以下简称“千里马”）的产品。在汽车购买合同中千里马同意派驻2个汽车维修工程师及必要的汽车维修工具进驻速到，提供一年的维修和技术支持的服务。合同中同时还规定，速到必须为工程师和维修工具的进驻提供20万的押金，押金在一年期限到后全部予以退还。

一年期限已至，工程师和维修工具已陆续撤离，但20万的押金却迟迟未能退还至速到的账户。起初千里马对押金未能按时退还做出了各种解释，并以电子邮件的方式表示会尽快处理，同时表达了歉意。随着时间推移千里马开始不愿承认20万押金未退还的事实。交涉无果后，速到依据《中华人民共和国民事诉讼法》第三十四条中合同签订地相关规定，将千里马告上了当地法院。

![](../Images/fabec129007cab83c40a6e4cb175ff5e.png)

能证明20万押金未退还的事实的证据不多，前面提到的电子邮件就成了关键证据。速到的法务部门人员向法庭提出申请，由鉴定中心对保存在速到电子邮箱内的相关电子邮件进行保全。经抽签确定，并由双方当事人同意，法院委决定托我中心对电子邮件内容进行固定，并确认邮件的发送时间、发件方邮箱地址。

在取证实验室鉴定人员在确保取证计算机一切正常（案例三已有相关表述在此就不赘述了）的前提下，使用送检的网易163电子邮箱账号和密码登录邮箱，对相关电子邮件进行了固定。通过对邮件头的鉴定，确认该邮件是一个星期前由slkdf@qlm.com发送。经鉴定人员分析后还发现，邮件发送时所使用的IP地址为127.0.0.1，通过百度对该IP进行查询，确认IP所属地是千里马公司所在地。最终法院采纳我中心的鉴定意见，并配合其他证据，认定千里马乘用车集团有限公司应在限定时间内退还速到汽车贸易运输公司20万押金。

**分析：**该案件牵涉到企业之间的合同纠纷，虽然有其他证据做为辅证，但电子邮件在此也十分关键。在邮件中千里马承认了押金未退，并表示会尽快退还。但是电子邮件存在于网络虚拟世界如何与现实生活中的个人联系起来呢？其次因为电子数据的易改性，如何确定电子邮件是否经过人为恶意的修改呢？关于第一个问题：发件方邮箱地址slkdf@qlm.com与千里马公司该项目负责人的名片上的邮箱地址一致，可以认定电子邮件是由该项目负责人所发送。第二个问题：因为送检电子邮箱的服务提供商是网易，并且是通过网页的方式登录电子邮箱进行的取证，考虑到进行伪造篡改的技术可行性基本不存在，推断电子邮件内容未被修改。
