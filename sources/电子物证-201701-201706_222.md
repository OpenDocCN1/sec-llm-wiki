![](../Images/5a5e134b10e1c7d11ca50155a9b0a4dc.png)今天世超要说的东西，可能不少差友都会觉得太基础，或者不适用。

  

但是回想当年我实习的时候，有一个妹子因为不会用快捷键被主管当场骂哭第二天就收拾书包回家这事。。。

  

瞬间觉得，Win 的快捷键使用虽然基础还是说说吧。

  

![](../Images/0cde99f3ad1baf00119ddb243e512209.png)毕竟我这里女粉还挺多的 （不是嘚瑟），而很多妹子的确会忽略快捷键的使用。  

  

希望大家对这群妹子多一些关爱，多一些理解~  

  

其实 Win 的快捷键有很多，甚至很多人还能自己把热键改成自己喜欢的。今天世超也不会全都说完，毕竟我自己常用的也就这么几个。。。

  

其实除了提高工作或者学习效率外，偶尔工作偷懒的时候还能完美避开老板的偷袭~

![](../Images/08bbcb5ff1703421060c7101063de142.png)

  

![](../Images/09c04f47836f4e340831e8d4a7da83d2.png)首先教大家一些，上班看视频、玩游戏必备的快捷操作。只要多加练习，熟练使用。上班看片指日可待！

**快速切回桌面**  

win + D

上班的时候难免会偷懒刷刷微博或者看视频，这时候如果老板 “ 不经意 ” 的从你身后路过。。。  

  

来不及用鼠标关闭窗口怎么破？迅速按下 **win + D **就能一秒切换回桌面上。

  

![](../Images/e3415abf108c335ebd9a7763fb5014f6.png)

  

好在差评是个好老板们，大家都很自由，只要工作做好了随便怎么玩~  

****新建桌面**  
**

win + Tab

  

![](../Images/587a1aa53635be071f91d0a8f0508610.png)好的，学会这招 win + D 快速切换回桌面了，接下来是一个晋级教程。每次我们切换回桌面时，总会在电脑桌上留下一些蛛丝马迹。

  

比如说 windows 下方的任务栏。。。

![](../Images/48c58bb4372ed99913c6f292e993f39d.png)

  

那么有没有什么解决方法呢？

  

![](../Images/719feb6e023677b7976cc42b51a500cf.png)我们只要在电脑上建一个新的桌面二就能轻松解决这个烦人问题了。只要按下 **win + Tab** 打开页面管理界面，接着新建一个桌面二。

![](../Images/f8db76b0c28e5f04704f05ebbef6bb0e.png)

  

![](../Images/ecdad85bccc03c914cfccb8fc549c549.png)然后只要把游戏拖进新创建的桌面二，最后我们只要按下 **ctrl + windows +左键 **就能迅速从桌面一切换到桌面二了。

  

从此看片不留痕，一键快过老司机！

![](../Images/2697f1ea48640dcf67feb413a08a4163.png)

  

**快捷锁屏**

win+ L

  

![](../Images/aa5edec53e66fae54f7d052fbf275c7b.png)最后一招不是用来防老板的，而是用来提防你粗心的同事们。

  

每次我们放着写了一半的文档离开电脑出去一趟，回来最怕看见的就是你写了一半的文档已经被粗心的同事关掉了！

  

**这时候就体现了及时锁屏的重要性。**

  

其实只要按下** win+ L** 就能迅速完成锁屏。

![](../Images/1073467bac254f4e4898307248b59c4f.png)

  

接下来是帮助我们提高工作效率的快捷操作。只要多加练习，熟练使用。升职加薪指日可待~

**屏幕分页**

windows+ 左键

每次我们需要在一台电脑上同时打开两个网页时，总是需要非常麻烦的把网页拖出来，然后费劲的调整两个页面的比例大小！

  

但是只要知道这个快捷操作，一键就够了~

  

![](../Images/604c8ce5e14b668e1bf091b12428946c.png)按下 **windows+ 左键** 就能迅速帮你把桌面等比例完成分屏。简直不能再方便了！

![](../Images/12b706c9a1f59036222502cc62d2b650.png)

  

**复制无格式纯文本**

ctrl + shift + V

  

![](../Images/6fc05e56d2b66be695e2ef0e98715e53.png)需要复制黏贴一些文本信息的时候，我们都会习惯性的选择 ctrl + C 和 ctrl + V 这套组合操作。但是每次黏贴过来的文字都是带格式的！！

  

事实上只需要在复制的时候多加一个shift键就统统解决了** ctrl + shift + V **可以直接复制无格式文本信息，特别实用！

  

  

**恢复关闭的网页**

 ctrl + shift +T

  

![](../Images/4c71984cbebc4ac7c4524b3a75ec0535.png)每次我们打开浏览器查阅资料时总是免不了打开多个网页。

  

可是问题在于当我们找到自己想要的资料，关闭不需要的网页时总是会误删那个我们找了很久的页面前功尽弃！

  

今天就教大家一个快速恢复关闭网页的操作—— **ctrl + shift +T **

![](../Images/72d0f9eb83781a5d1a23da1191aa5535.png)

  

方便好用的快捷操作实在太多，就不一一列举了。都已经帮你们汇聚了一波。。。

  

  

**1、Ctrl组合系列**

Ctrl + C 复制   

Ctrl + X 剪切   

Ctrl + V 粘贴   

Ctrl + Z 撤消   

Ctrl + F 寻找    

Ctrl + S 保存 

Ctrl + A 选中全部内容          

Ctrl + Shift +Esc 打开任务管理器

Ctrl + End 当前窗口或文档的最下端

Ctrl + Home 当前窗口或文档的最上端     

  

**2、Shift组合系列**

Shift + Delete 永久删除所选项，而不将它放到“回收站”中

按住SHIFT切换大小写输入

  

**3、Alt组合系列**

   Alt + Tab 在打开的项目之间切换

Alt + F4 关闭当前项目或者退出当前程序

  

**4、Fn键系列**

  

F5 刷新当前窗口

F2 重新命名所选项目
