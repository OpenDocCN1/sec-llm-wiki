随着安卓版本越来越高，应用程序安全性也越来越好，给手机取证工作带来了更多的障碍，手机应用中最常见的微信数据的获取也受到了不小的挑战。作为比较常规的逻辑获取方式，相信大家都或多或少的接触和使用过“微信降版本备份”这种解决方案，也可能被一个比较常见的现象困扰过，即微信数据没能获取到，程序图标却消失了。

为了理解这种现象，我们首先要弄清楚下面几个问题：

首先，什么是降版本备份，为什么要降版本？

其次，为什么应用图标会消失，图标消失后数据还在不在？

最后，操作上有什么要注意的地方？

一、什么是降版本备份，为什么要降版本？

安卓手机在未root的情况下最简便且相对全面的微信数据获取方式是adb备份（即通过ADB通信方式使用系统原生提供的数据备份功能），但是常见的高版本微信并不响应adb备份命令，所以我们需要在保证数据安全的前提下重新安装一个支持adb备份的低版本微信，以达到顺利备份并从中获取数据的目的。

二、为什么应用图标会消失，图标消失后数据还在不在？

解答这个关键问题，我们需要先简单介绍一下降版本备份的整个过程及原理。

降版本备份过程：

首先，为了保证在获取完成后检材手机内的微信可以恢复至其送检时的原始状态，我们在正式替换应用之前，需要先将检材手机中的高版本微信安装包保留，这里涉及到两个命令：adb shell pm path和adb pull

1、adb shell pm path是查询程序安装路径的命令，我们都知道安卓微信程序名为com.tencent.mm，所以输入命令：

adb shell pm path com.tencent.mm

在返回的结果中，能够得到微信应用所在路径，本例中微信所在路径为

/data/app/com.tencent.mm-1/base.apk

2、然后通过adb pull命令，将上面路径中的apk文件拉取到本地电脑上，命令为：

adb pull /data/app/com.tencent.mm-1/base.apk D:/weixin.apk

此命令中，“D:/weixin.apk”为拉取后的保存位置及文件名，可随意更改。

 完成后可以在D盘根目录找到刚刚拉取到的检材原版微信apk文件

3、下面开始正式的替换过程。这里涉及到adb uninstall和adb install命令。顾名思义该命令为卸载和安装，其中uninstall需要设置参数“-k”，此参数会在卸载应用时保留数据库，从而保证取证过程不丢数据。这也是业内常见手机取证软件降版本备份的核心命令。

adb uninstall -k com.tencent.mm

键入后，会有警告信息，按要求输入确认命令

adb shell pm uninstall -k com.tencent.mm

而后提示卸载完成，此时微信图标已经在手机上消失。

4、安装。准备一个低版本的微信安装包，如微信5.0版本。通过adb install命令直接装入手机，如下图，命令后添加低版本微信apk所在的路径。此时手机端微信图标出现，但点击会闪退，原因是版本过低无法运行。

5、备份。adb backup，这个命令大家应该都比较熟悉了：

adb backup –f D:\weixinbackup.ab com.tencent.mm

其中“-f”参数为指定路径和文件名，后面加“com.tencent.mm”可单独备份微信，如图：

此时手机屏幕弹出“备份我的数据”界面，点击确认，备份完成后，即可用各类取证工具加载分析生成的.ab格式备份文件。

6. 接下来是还原原始版本的过程。卸载低版本微信，同理，通过命令：

adb uninstall –k com.tencent.mm

和

adb shell pm uninstall -k com.tencent.mm

此时，手机端微信图标再次消失。

7、 还原检材内原始的高版本微信：

adb install D:\weixin.apk

微信图标再次出现，并可成功启动，至此整个微信降版本备份过程完成。

从这个过程我们不难看出，通过专业手机取证软件来进行微信降版本备份，如果微信图标消失，只要确保数据通信连接正常，一般是不会丢数据的。图标丢失的问题主要出在adb install安装的两个步骤上，即微信apk没有安装成功。

而不成功的原因主要有以下几种可能：

1） 某些高版本安卓的OPPO/vivo/小米等定制版安卓系统，是默认不支持通过usb或adb命令安装apk程序的，所以需要去相应的设置中打开安装权限。

2） 某些手机管理软件会在安装时提示“是否允许”，而漏点该提示自然就安装失败了。

三、 操作上有什么要注意的地方？

以下是最重要的！最重要的！最重要的！（重要的事说三遍）

手机端如果存在各类系统自带或第三方管理软件，在两个adb uninstall步骤中都有可能会提示“是否删除残留数据”的提示，此时务必选择“不删除“，此时千万不要手抖，定睛看准，否则你就真的悲剧了。所以建议各位在备份获取微信时先设置屏幕常亮，同时尽量关注手机端出现的各种提示，并做相应的处理，千万不要开小差！
