2015年10月，微软公司发布了第一款笔记本电脑Surface Book，键盘与屏幕部分可以分离，因此既能够当作笔记本电脑，也可作为平板电脑。屏幕与键盘部分的衔接，微软创造了一个新的名为“Muscle Wire”的机制，屏幕和键盘相接的时候非常坚固，用户需要通过按下键盘上的一个按键，系统驱动在屏幕上有所提示才能轻松分离，插上的时候也不是磁力贴，需要按下等键盘伸出支架。

Surface Book全机身甚至找不到一颗螺丝，完全不适合拆机卸下硬盘进行获取。该笔记本使用全新的UEFI启动方式，可以使用新版的SafeImager或一些U盘版的系统引导启动后制作镜像。

区别于普通笔记本的BIOS启动方式，Surface Book需要先按住音量+和电源键，进入UEFI启动界面，界面如下图所示。

修改笔记本UEFI的Boot configuration启动设置项，关闭Enable Boot Configuration Lock，同时关闭Enable alternate boot sequence、Enable IPv6 for PXE Network boot option等选项，取消Window Boot Manager、Internal Storage、PXE Network等启动选项，如下图所示。

同时需要关闭安全启动引导，修改笔记本UEFI的Security选项中的Change Secure Boot configuration项，选择None，如下图所示。

因为UEFI的设置，如果使用的是旧版本的SafeImager，可能会导致无法启动，当然也不用着急，如果手上有U盘版Ubuntu系统，也可以顺利进入该系统。

进入系统后，需要联网并下载软件Guymager，使用安装命令：sudo apt-get install guymager。

安装成功后，打开guymager软件，如下图所示。

右击源盘选择Acquire image，在弹出小窗口的里设置文件格式为dd，存储路径为外接硬盘、设置镜像文件名称、计算Hash值、校验，如下图所示:


点击“开始”制作镜像文件，如下图所示。
