# 各类手机锁机病毒解锁清除教程，仅需7步！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651029221&idx=2&sn=6338cce93ead5f4eeb6bc906dacbd331&chksm=80d03114b7a7b802290a4c6589d6a2dd00ccfa2550f282a58b4f903ea995c2e6bc7b85b99781&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651029221&idx=2&sn=6338cce93ead5f4eeb6bc906dacbd331&chksm=80d03114b7a7b802290a4c6589d6a2dd00ccfa2550f282a58b4f903ea995c2e6bc7b85b99781&scene=27#wechat_redirect)

最近看好多发帖求解锁手机的帖子，发个小教程吧！~不一定100%可以清除，但是我觉得应该可以清除大部分的锁机病毒吧。  
（PS.仅适用于已开启ADB调试和已经ROOT的手机，如果USB调试关了试试在同一WIFI环境下用远程调试试试，如果没开进RECOVERY卡刷或线刷吧）  
我把锁机病毒下下来装到手机里了。  
![](../Images/0e3fd915493432ca307cdec051040ca8.png)   
BGM还挺带感的。哈哈！~不要乱输密码，貌似尝试次数过多会清除手机。  
上ADB调试工具。  
【STEP.1】 输入“adb shell pm list packages”  
查看已安装的软件的软件包名，如果不好找可以用“APK helper”工具来查看！如图：  
![](../Images/e6094ef90707c8e6ea09d396bf79a237.png) ![](../Images/ca77b167bc2dd0dce8c9d3ca4c0ffe41.png)   
【STEP.2】 接着我们输入“adb uninstall com.h”  
用adb命令卸载病毒,扰人的BGM咩有了，锁机软件被清除了。但是因为改了系统密码，我们还是不能用~要把改了的密码也清掉。  
![](../Images/c6ee160de569caaf541c2b121588bbee.png)   
【STEP.3】 输入“adb root”提权，输入完没提示。  
【STEP.4】 输入“adb shell”进入adb shell模式，类似DOS。  
【STEP.5】输入“cd data/system”进入“data/system”目录，锁屏密码文件在这个目录里！删掉就没有密码了~  
【STEP.6】输入“rm password.key”锁屏密码就也被清除了（要是是手势密码就“rm gesture.key ”）  
最后如图咯~  
![](../Images/22e3db518530c0bc16a70f90adc8ab5a.png)![](../Images/2de2b321e4d4e5d70f6f4d8469eeaf55.png)   
【STEP.7】最后一步，在SD卡上找到病毒自己复制的副本删除，并删除相关生成文件夹就行了！（这个病毒样本貌似会在SD卡上创建一个自己的副本安装包）  
  
古董小米出镜！~第一批Mi one喔~哈哈。。  
  
如果有用这个方法清除不了的小伙伴可以发下样本，我再研究下，双清清不掉的应该是写到系统APP目录了！~请不要随意安装不明APP。  
最后祝大家新年快乐！
