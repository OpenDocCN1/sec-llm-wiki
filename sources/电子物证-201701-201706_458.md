# 【实战】Windows VHDX虚拟硬盘如何取证

随着虚拟环境的企业工作负荷的增加以及性能要求的提高，虚拟硬盘 (VHD) 格式需要适应这些变化。Windows Server 2012 和Windows 8 中引入了一个新版本的 VHD 格式，称为 VHDX。  

  

目前市面上国内外知名取证软件均还不支持VHDX取证。如果遇到VHDX虚拟硬盘文件我们该如何取证呢？今天小编就带大家了解VHDX文件是如何生成的以及在目前取证软件还不支持的情况下如何进行VHDX取证。

**DX文件是如何生成的？**

一般情况下有两种方式可以生成VHDX文件。

方式一

windows 8 或是windows server 2012以上的系统，在磁盘管理界面可以直接生成VHDX文件。操作方法如下：

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（1）在“磁盘管理”上点右键，选择“创建VHD”

  

![](../Images/c27c2cfcd77d0c13284d68415cab015d.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（2）会弹出如下设置窗口

![](../Images/dcc282e300fc17d2513ea89db9528ebd.png)  

  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)（3）设置好“位置”“大小”“格式”“类型”点击“确定”即可完成VHDX创建。

方式二

使用Windows Server 2012及以上的系统使用Hyper-V虚拟化技术创建的虚拟硬盘。操作方法如下：

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（1）打开Hyper-V 管理器

![](../Images/88e6be2605a96c5e76764b792f2339d8.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（2）点击“新建”选择“硬盘”

![](../Images/85fd8793461d268793b4a8012efd5257.png)  

  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（3）在“选择硬盘格式”中可选择“VHDX”

![](../Images/f694d49e25f17ef73e616da5042ebfc7.png)  

  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)（4）按操作提示设置好相应的选项后，即可创建好VHDX虚拟硬盘。

**VHDX虚拟硬盘如何取证？**

因为取证软件暂时不支持VHDX直接加载取证，在这里我给大家介绍两种方法，希望能给大家取证VHDX带来帮助。

方法一

需要找一台Windows Server2012 或Windows 8 及以上的系统 ，以只读形式加载，然后通过加密狗形式取证大师对虚拟硬盘进行解析。操作方法如下：  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（1）在“磁盘管理”上点右键，选择“附加VHD”

![](../Images/6df47b1f2a8395817c5e59bb44dd0790.png)  

  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（2）在弹出的窗口中选择好对应的VHDX文件，并勾选只读以免破坏源始数据。

![](../Images/50615f4622ea1226974d10dccb388432.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（3）加载好后，磁盘管理中会显示出该磁盘。

![](../Images/604c3baa6f2f902a065c666bc426bf2e.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（4）使用取证大师加载分析

![](../Images/9a91e95614fae9469772c6105476499c.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（5）下图为分析时算出的硬盘MD5值

![](../Images/e329833336e9c25b70b2ec68f6aada21.png)  

方法二

如果您取证设备只有Windows 7 ，无法找到Windows Server 2012 或Windows 8 及以上操作系统的电脑。

此时我们可以使用取证魔方或其他自带不拆机复制引导U盘的设备，找个其它电脑通过U盘引导进入Windows 8 PE系统然后加载磁盘，到时可以直接使用魔方分析，也可以把VHDX镜像下来，再使用取证塔或是其它取证设备分析。操作方法如下：

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（1）使用不拆机复制引导U盘引导进入Windows 8 PE系统

![](../Images/b85f20f2a0dbece4f4de6f3105c75c8c.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（2）通过“开始”菜单，“计算机管理”打“开磁盘管”

![](../Images/a0f2c696598d74fa0ee07f6b578b28f8.png)  

  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)（3）在“磁盘管理”上点右键选择“附加VHD”。操作方法请参考方法一。

  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（4）此次我们是在Windows 8 PE环境下把VHDX磁盘做成镜像

![](../Images/5e719873e54c3b4d0ecd924ec9ccea98.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（5）同样我们把镜像加载到取证大师算出了磁盘的MD5值

![](../Images/13c74b8b9e34ddc133d2c3ac38c88b70.png)  

![](../Images/848e82f4b816fb878b48e41fa520d052.png)

（6）分析结果如下图所示：

![](../Images/3e84a91952ed591a81e0e7d82878e4f9.png)  

  

![](../Images/43a7b6398c3e82c51d45e8a122164b0d.png)

以上就是今天分享的在无法直接加载分析的现状下，VHDX取证的2种方法。
