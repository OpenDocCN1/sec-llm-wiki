# 何为打印机清零 打印机用到一定张印量，打印机会报警或停止工作。这是生产厂家为了更大化的销售打印机耗材而设定的。

# 打印机清零分类 按部件分为使用计数清零、废墨计数清零； 按清零类型分为芯片清零、齿轮复位清零、代码清零

# 常用的激光打印机代码清零已兄弟 联想品牌颇为常见。喷墨打印机代码清零以佳能、爱普生为主，惠普、佳能则以更换计数芯片为主。下面就把这几款打印机清零方法总结一下。
