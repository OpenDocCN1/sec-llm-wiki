# 【千亿条信息中逆向查出大鳄犯罪证据】

负责侦办这起案件的现任上海市公安局经侦总队政委胡斌勇荣膺CCTV2017年度法治人物，也揭开这起与亿万股民利益攸关大案背后的故事。

![](../Images/56e56ab6739bd7dd7c89d4c65db44d08.png)

  

  

**千亿条信息中寻觅犯罪线索**

  

　　2015年6月，证券资本市场剧烈波动。为查清股市波动中的违法犯罪行为，公安部从前期搜集获取的数据资料中锁定了一批线索，决定组建专案组查找股市波动中的不法行为、惩治证券资本市场中的隐藏罪恶。胡斌勇受命担任专案组的负责人。

　　虽然经常侦办类似案件，但这一次胡斌勇明白自己肩膀上的担子份量之重：**“案件的数据信息有数千亿条，我们要从中抽丝剥茧；我们要跟时间赛跑，更要跟嫌疑人拼智力。”**

　　专案组“参战”的侦查员都是参加过大型经济犯罪案件侦查工作的行家里手，然而这次任务的困难程度远超以往：不仅超出队员们掌握的金融知识，还要在数以千亿计的证券期货交易信息中寻找不合常理的蛛丝马迹。

　　“虽然说一鼓作气、再而衰、三而竭，但承担着党和人民交付的重大使命的我们，不能因为遭遇困难而气馁，士气不能有丝毫的衰竭，即使百折不回我们也一定要找出幕后黑手。”胡斌勇回忆，2015年国庆假期，上级领导给已经连续出差两个多月的参战民警3天回家探亲的假期。但没有任何一名侦查员承兑了这张宝贵的假条：“在我们心里，始终憋着一股劲。不找到元凶祸首，我们绝不离开战场。”

　　也正是在那个国庆假期，胡斌勇和同事们在总结分析前阶段经验教训的基础上，把侦查思维逆转向了新的领域：“之前，我们一直盯着股市波动这一时期反复寻找引起股指下跌的原因，但始终未能成功。我们何不‘逆向思维’，从引起股指大幅上涨的原因开始找起呢？”

  

**逆向思维从“上涨”中找到真凶**

  

　　然而，一个很现实的问题摆在专案组负责人胡斌勇的面前：股市波动的时间短短数周，专案组分析这一阶段的市场交易情况就花了近4个多月时间。而之前股指大幅上涨的时间长达近半年，其数据分析的工作量、复杂性几乎呈几何级增长。还有一个困扰专案组的问题是，如果这条路同样行不通，随着时间的推移，警方有可能会错过破案的最佳战机。

　　走老路，可以预见是死胡同；走新路，前面不知有多少荆棘和困难——方向选择并不能轻易决定。胡斌勇牵头开展了多次“头脑风暴”。经过深思熟虑，胡斌勇最终选择了带领大家“披荆斩棘”。

　　此案考验着海量数据分析能力。从前期积累的经验看，想要突破案件，必须通过专业技术和专业手段对沪、深两市的交易进行跨行业、跨市场的全数据分析。数据有多少？“一个2000字左右的word文档是30KB，1024KB是1MB，1024MB是1GB，1024GB才是1TB，这起案件仅仅证券交易数据就多达300余TB”。

　　但是“开弓没有回头箭”。事实证明，胡斌勇的选择和策略是正确的。仅仅过了2周，专案组就从数亿手交易中筛选出特定节点的近百支股票，这些股票的波动具有相同特征：股市剧烈波动前大幅上涨至1倍甚至2倍，此后又大幅下跌3倍甚至4倍。

　　而这些股票的背后，均有着一个叫作“泽熙”公司的操作痕迹。这家投资管理公司的控制人，正是号称“中国私募一哥”的徐翔。“业绩凶悍、难以超越”，这是股民对他的评价。

  

**跨海大桥上抓捕“资本大鳄”**

  

　　初步掌握徐翔等人犯罪线索后，上级部门要求专案组以雷霆之力迅速将犯罪嫌疑人抓捕归案。此时，专案工作已经到了最关键的时刻，对犯罪嫌疑人的成功抓捕，成为了摆在专案组组长胡斌勇面前的重中之重。

　　通过数个不眠之夜的抓捕方案制定、审定，胡斌勇提出抓捕总策略：严格保密、出其不意、全部犯罪嫌疑人同步到案。最终，通过连续数日的工作，警方在宁波境内的跨海大桥上将主犯徐翔抓获归案，该案其他全部犯罪嫌疑人也同步到位。

　　在同步开展审讯的同时，胡斌勇同志带领大家在选取涉案股票样本进行成功分析的基础上，通过专业软件对反洗钱数据进行运算，建立账户之间的关联性，连续印证了徐翔交易的多支股票存在问题。随着审讯约谈、数据分析、调查取证的三管齐下，案件真相逐渐浮出了水面。

　　在确凿的证据面前、在清晰的事实面前、在法律的威严面前，“资本大鳄”徐翔低下了原本高傲的头颅：“我原以为我是站在监管之上的人，没人可以打败我，但你们却彻底打败了我，更是征服了我”。

![](../Images/1b922c27d773ff719d214e1e782cf086.png)

　　2017年1月，经过法院的审判，徐翔被绳之以法，入监服刑，**全案判处罚金合计300亿元。**这一案件的侦破，既有力惩治了证券资本市场重大犯罪，为规范金融证券市场交易行为作出有力贡献；同时也在未知的领域中开创了先河，积累了同类案件侦办的经验。

  

**“没有人可以凌驾在法律之上”**

  

　　另一起影响巨大的“伊世顿公司操纵期货市场犯罪案”同样也是胡斌勇牵头负责侦办。在6个月夜以继日的侦查取证过程中，专案组在有关部门的大力支持下，辗转苏、浙、粤、港四地，先后抓获高某等3名犯罪嫌疑人，追缴涉案资金8亿余元，并扩案捣毁一“地下钱庄”，全面查清了伊世顿公司操纵期货市场的犯罪事实。

　　案件侦办期间，胡斌勇同志秉持“有法必依、执法必严”的工作信念，带领专案组同志广泛、细致研究了我国所有涉及操纵犯罪的司法解释和人大法工委、“两高”对此类案件的各项说明意见，通过合理、严谨的逻辑体系证明伊世顿账户组的交易行为扭曲、影响了正常市场价格形成，具有操纵的本质特征。

　　“伊世顿案”是全球第二例、我国首例利用高频程序化交易实施操纵期货市场的案件。专业人士评价到，该案的成功侦破，有力打击了交易者利用我国期货市场监管、技术漏洞，操纵市场、牟取暴利的新型操纵犯罪行为，同时展示了我国政府维护金融市场正常交易秩序的坚定决心，净化了股指期货交易市场生态环境，保护了投资者的合法权益。而案件破获的背后，是胡斌勇及其战友们攻坚克难的决心，孜孜不倦的分析，夜以继日的工作；是他们为了我国经济金融市场平稳有序的默默守护。

　　党的十八大以来，胡斌勇同志作为一线指挥员，直接带队指挥侦破徐翔案、伊世顿案等极具社会影响的金融领域大要案件180余起，打击处理犯罪嫌疑人600余人，为国家和群众挽回直接经济损失400余亿元，牵头挂帅的专案组先后荣立集体一等功8次，分管的经侦总队一支队被中共中央评为“全国先进基层党组织”、被国务院授予“模范经侦支队”荣誉称号；自己也先后荣立个人一等功1次、二等功2次、三等功2次。

　　**“没有人可以凌驾在法律之上。”**胡斌勇说：“我们为经济金融市场的发展守护住底线，让它变成犯罪分子不敢逾越的高压线，让它变成市场和百姓的经济安全线，让它成为上海乃至全国打击经济金融犯罪的标尺线。”
