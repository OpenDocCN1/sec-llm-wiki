前言

       在日常取证工作中经常会遇到VIVO手机，新的VIVO手机不仅没有原生备份功能而且还采用了全盘加密，导致取证的时候可能会解析不到QQ和微信的数据。今天就给大家分享一下使用命令降级备份提取VIVO手机QQ和微信的方法，希望对大家的取证工作有所帮助。

**风险提示！！！**

**如手机有安装非官方版本微信及QQ，使用此方法会造成数据丢失！！！同时，该方法并不适用于android7.0及以上的系统。其他品牌手机及版本未经严格测试，暂不支持。**

**此方法存在误操作风险，请输入命令时务必检查命令输入正确！建议命令可以通过复制的方式拷贝到相应的界面，以免导致数据丢失！**

以上风险提示请务必知悉！！！

  

**微信提取方法**

**具体操作如下**

1

打开工具集中的Android命令行工具。

  

![](../Images/63bb23fd78b92c8b8fb61744f0963e96.png)

  

2

在命令界面下按数字6，再按回车键。

  

![](../Images/3167f00d3cdc97d909c88533e455ce0c.png)

  

3

查接着按照如下输入命令：（可直接复制这个命令在命令行内粘贴）。adb shell pm path com.tencent.mm : 获取手机里面原版本微信安装包的路径。

  

![](../Images/d102eeb8ef308d79b7da024f3a6008da.png)

  

4

adb pull加路径加weixin.apk ：备份手机里原版本微信的安装包，命名为“weixin.apk”,便于后续提完数据后把微信还原回去。  
（路径就是刚刚输入adb shell pm path com.tencent.mm后看到的那段路径） 可以看到备份安装程序到百分百。不同手机路径可能不相同，以输入命令后看到的路径为准。

  

![](../Images/0d4c45c700d0ed9836fba2351b04dc50.png)

  

5

adb push "D:\\Program Files\\MobileMaster\\Mobile Support\\BaseTool\\Android\\4.0\\MFSocket\_1.apk"  /sdcard/weixin.apk ：推送我们安装目录下低版本的微信，可以看到推送完成后有百分百的显示。

  

![](../Images/42282a3e859a9795d84c1056e29c27d5.png)

  

6

adb shell pm uninstall –k com.tencent.mm : 把手机里面原版本微信保留数据并卸载。**注意：这句命令行当中一定不能少了-K,否则微信数据就真的删除了….**

  

![](../Images/83e397af673037f9906a8a1255e3426c.png)

  

7

  

在VIVO手机的文件管理里面手动安装weixin.apk,装完后就可以用手机取证软件提取到微信数据了。

  

![](../Images/fd9cb58be6b2b0adcdfc2c98bca36911.png)

  

8

  

在提取完微信数据后，输入以下命令 adb push weixin.apk /sdcard/weixin.apk  : 推送刚才备份的原版本微信数据包。然后再到手机文件管理手动安装weixin.apk，就将手机的微信恢复到提取前的状态。

  

![](../Images/6db8c614b8a81730bd9b7423e2f6db26.png)

**QQ数据提取**

**具体操作如下**

1

adb shell pm path com.tencent.mobileqq ：获取手机里面原版本QQ安装包的路径。

  

![](../Images/7198f29236a012de9c6c2b1f6c821f9f.png)

  

2

adb pull加路径加qq.apk ：备份手机里原版本QQ的安装包，命名为“qq.apk”,便于后续提完数据后把微信还原回去。

  

![](../Images/f2ae2d632c0e10f24b63420f9baf6b8d.png)

  

3

adb push "D:\\Program Files\\MobileMaster\\Mobile Support\\BaseTool\\Android\\4.0\\MFSocket\_2.apk"  /sdcard/qq.apk :推送我们安装目录下低版本的微信，可以看到推送完成后有百分百的显示。

  

![](../Images/e34e04b67e2b645aea9e97fbe0115b51.png)

  

4

adb shell pm uninstall -k com.tencent.mobileqq :把手机里面原版本QQ保留数据并卸载。**注意：这句命令行当中一定不能少了\-K,否则QQ数据就真的****删除****了….**

  

![](../Images/33d1f44736c658e559dfb8e5e0a8c675.png)

  

5

在VIVO手机的文件管理里面手动安装weixin.apk,装完后就可以用手机取证软件提取到微信数据了。

  

![](../Images/fd9cb58be6b2b0adcdfc2c98bca36911.png)

  

6

在提取完QQ数据后，输入以下命令 adb push qq.apk/sdcard/qq.apk  : 推送刚才备份的原版本微信数据包。然后再到手机文件管理手动安装qq.apk，就将手机的QQ恢复到提取前的状态。

  

![](../Images/ec6eb8e295d805894d49c42dff8c1548.png)

  

小窍门

在软件安装目录D:\\Program Files\\MobileMaster\\Mobile Support\\BaseTool\\Android下的 setinfo.ini中存在一个配置UseUninstallMethod=0修改为UseUninstallMethod=1即可实现自动获取vivo的应用数据及分身应用。用完记得修改回UseUninstallMethod=0，切记！切记！

前面文章中输入的命令比较多，容易出现误输入命令导致数据丢失的情况，推荐使用更改配置的方法提取QQ和微信的数据，简单又实用。
