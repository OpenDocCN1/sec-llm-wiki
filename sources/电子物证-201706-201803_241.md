# 【安卓取证中打开命令行还有这种操作】

在安卓手机常规取证的过程中有时需要用到adb或者fastboot命令，那么我们就需要打开命令提示符然后进入到adb.exe和fastboo.exe相对应的目录才能进行命令操作。

常规的做法是:

Win+R打开运行窗口

  

输入"cmd"回车打开命令行窗口

  

 再依次输入“cd 文件名”，直到进入目标文件目录，或者在资源管理器的地址栏里复制文件夹地址，如"C:\\Program Files (x86)\\平航科技\\平航手机取证分析软件\\bin", 然后在命令行窗口中输入“cd”后 ，通过鼠标右键复制的方式将路径地址粘贴到cd 后面（适用于文件夹路径较长时，避免一个一个地输入）

  

如果需要进行频繁命令行操作，每次都要通过这样的方式来进行，势必很麻烦。        

**按住shift 右键打开命令提示符**

其实Windows有个不显眼的功能可以帮助我们快速打开命令行，同样还是以定位到**C:\\Program Files (x86)\\平航科技\\平航手机取证分析软件\\bin**为例，先进入到bin文件夹里，将鼠标置于空白处，按住键盘Shift键不放，同时右击鼠标，这时在右键菜单里会出现一个"打开命令行" 的菜单选项，如下图：

![](../Images/decbfaf5239f0ba1d97395ab59689fd7.png)

 点击后即可直接进入此目录位置的命令行：

![](../Images/bbbe1ba41f28bb8efbfdb677a2f15e8c.png)

**右键打开【具有管理员权限的】命令提示符**

上面的快捷方法虽然比传统打开命令行的方法方便了许多，但有些时候我们在命令行里的操作需要具备管理员权限，因为**有时当我们用backup命令行做android备份时，以管理员身份打开命令行窗口，可以避免因权限不足导致的失败情况。**

**具体操作步骤如下：**

1.我们可以通过传统的方法打开一个以管理员身份运行的命令行窗口，方法就是输入cmd右键选择"以管理员身份运行"，win10可以右键开始按钮直接选择，打开后后再手动定位到需要的文件夹目录。

![](../Images/17a7054f7b058bfae8436489d4261a72.png)![](../Images/c8673a8f355ad8ed38619ed109948502.png)  

2\. 还有一种高阶技巧，可以在右键菜单里添加一个菜单选项让我们可以在一个文件夹里直接右击鼠标便能以管理员身份打开一个命令行窗口，那样的话将会让工作变得非常轻松。

**将以下代码复制到一个文本文件，然后保存成 cmd.reg，注意文件后缀是reg，注册表文件。**

Windows Registry Editor Version 5.00

; Created by: Shawn Brink

; http://www.sevenforums.com

; Tutorial: http://www.sevenforums.com/tutorials/47415-open-command-window-here-administrator.html

 \[-HKEY\_CLASSES\_ROOT\\Directory\\shell\\runas\]

 \[HKEY\_CLASSES\_ROOT\\Directory\\shell\\runas\]

@="在此处打开管理员命令提示窗口"

"HasLUAShield"=""

 \[HKEY\_CLASSES\_ROOT\\Directory\\shell\\runas\\command\]

@="cmd.exe /s /k pushd \\"%V\\""

 \[-HKEY\_CLASSES\_ROOT\\Directory\\Background\\shell\\runas\]

 \[HKEY\_CLASSES\_ROOT\\Directory\\Background\\shell\\runas\]

@="在此处打开管理员命令提示窗口"

"HasLUAShield"=""

 \[HKEY\_CLASSES\_ROOT\\Directory\\Background\\shell\\runas\\command\]

@="cmd.exe /s /k pushd \\"%V\\""

 \[-HKEY\_CLASSES\_ROOT\\Drive\\shell\\runas\]

 \[HKEY\_CLASSES\_ROOT\\Drive\\shell\\runas\]

@="在此处打开管理员命令提示窗口"

"HasLUAShield"=""

 \[HKEY\_CLASSES\_ROOT\\Drive\\shell\\runas\\command\]

@="cmd.exe /s /k pushd \\"%V\\""

**然后双击运行，弹出确定对话框，点击确定**。

在目标目录下点击右键（无需按住shift），菜单里已经多出一个以管理员身份打开命令行窗口的选项了。

如图：

![](../Images/41bda0878a1731558317c8c7e44d11e9.png)

点击运行后的界面区别于传统命令行，如下图红框所示：

![](../Images/c47a32df1e9e7b890fa3b155063c45da.png)

如何去除：

如果哪天你不需要这个新加的选项了，可以把下面的代码复制，**同样保存到一个文本文件然后存为remove.reg，双击运行之。**选项就会消失，菜单恢复正常。

Windows Registry Editor Version 5.00

; Created by: Shawn Brink

; http://www.sevenforums.com

; Tutorial: http://www.sevenforums.com/tutorials/47415-open-command-window-here-administrator.html

 \[-HKEY\_CLASSES\_ROOT\\Directory\\shell\\runas\]

 \[-HKEY\_CLASSES\_ROOT\\Directory\\Background\\shell\\runas\]

 \[-HKEY\_CLASSES\_ROOT\\Drive\\shell\\runas\]
