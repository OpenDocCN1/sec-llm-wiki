****✪**** vivo X9******✪**

vivo X9  是目前最为常见的手机型号之一，在实际案件中也常常遇到，由于X9采用基于安卓6.0的Fun touch OS3.0操作系统，默认开启了FDE（Full Disk Encryption）全盘加密，且vivo没有原生备份应用，因此在实际检验工作中提取数据难度很大。

  

**提取难点：**

1．手机本身没有自带的备份应用，无法通过原厂备份方式获取数据，对于部分应用数据无法获取。  

  

2．通过使用基于高通芯片的物理镜像方案获取的全盘镜像加密，主要是FDE全盘加密的原因。

尽管有一定的难度，但是我们可以结合adb 命令和降低微信版本的方法提取数据，本文以此思路介绍手工提取vivo X9微信数据的方法，供各位参考。  

注：本文方法不适用于安卓7的vivo X9s

**手工提取微信操作的关键步骤**（详见下图）：  

1. /adb devices : 查看手机与电脑是否正常连接，绿色框内显示了该设备的序列号则表示正常连接成功了。

  

2. /adb shell pm path com.tencent.mm : 获取手机里面原版本微信安装包的路径。

  

3. /adb pull /data/app/com.tencent.mm-2/base.apk D:\\原版本微信.apk : 把手机里原版本微信的安装包拷贝到本地电脑D盘根目录下面，命名为“原版本微信.apk”,便于后续提完数据后把微信还原回去。

  

4. /adb shell pm uninstall **–k** com.tencent.mm : 把手机里面原版本微信保留数据并卸载。**注意：这句命令行当中一定不能少了-K,否则微信数据就真的消失了….**

![](../Images/d69f220bec7e37ff2b9334ea960227e4.png)  

完成上述操作后就可以把低版本的微信安装包拷贝到手机内部存储的根目录下面，然后到手机文件管理里面找到mm.apk点击安装即可。  

 

![](../Images/817163c5ab3b11c82ad17be8efdc4330.png)

![](../Images/523e39f147891fd29dc396ec882218aa.png)  

   

安装好低版本微信之后就可以用adb backup命令把微信数据备份出来了（见下图）

**adb backup com.tencent.mm:只备份手机里面的微信数据。** 

![](../Images/7a6f0d6302bbcf103bdd513618f0b977.png) 下图backup.ab就是该vivo X9手机的微信数据备份文件了，用平航手机分析软件解析之后就可以获取到该手机的微信数据了，这种方法也可以实现已删除微信聊天记录的恢复。

![](../Images/4903f66f08ceb94ae40fd64ffb61265a.png)

最后，把手机原版本的微信安装包再拷贝回至手机内部存储里面，然后到手机文件管理里面安装下即可把微信还原回取证之前的状态。
