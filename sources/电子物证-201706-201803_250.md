小编在ifixit上看见米家骑记电助力折叠自行车拆解，这也是他们第一次拆解交通工具，小编觉得很有趣，特分享给大家。  

  

![](../Images/b8435ab03a51bfd76d8bebd2192582dc.png)

  

多少年来，我们一直认为：任何一台能够用电力的设备，将会最终安装上电力驱动。米家骑记电助力折叠自行车现在就在我们的拆解桌上，这是我们拆解桌上的第一件交通工具。小米制造出了智能自行车，但这将成为我们的维修噩梦吗？废话少说，拆吧！

![](../Images/82ce8d92dfe70f833d68c3bc0422e34f.png)

从外观来看相当时尚了，再来看看规格吧：

```
250 W, 36 V 高速发动机

0.21 kWh 电池 （20 NCR18650PF 锂电池）

单次充电助力骑行 45 km

禧玛诺 Nexus 三变速器

根据人脚踏调节的力矩传感助力

骑行数据实时监测，包括速度、里程、动态功率和卡路里消耗。
```

### 速度传感器

![](../Images/102743370b0b6b186de3be51d3b96e2d.png)

电线连接在座椅下方，然后沿着框架延伸到（模块化）插座。

![](../Images/59581c0090893cf4b1eabfdad0a1702f.png)

我们能够剥离电线，并拆下传感器组件。

```
测量骑车人的曲柄力矩的传感器系统是IDbike TMM4 或类似的东西。
```

![](../Images/4dcbba1dc11e8b4fd4354958984e90d3.png)

推出小电路板，我们得到这个奇迹测量器的核心：一个1820A可编程线性霍尔传感器

```
这利用霍尔效应在车轮转动时跟踪车轮，使用它来确定你的行驶速度（和你的工作努力程度）。
```

![](../Images/6fa009a553b96ca36feee722fdd0218c.png)

三线系统使用简单的 JST 连接器连接，而不是焊接。现在这就是我们所说的模块化。

![](../Images/94d1c6f1297d8c7fe48fe0f6a3cf2f81.png)

### 轮轴齿轮电机

![](../Images/5159f67c752ed389240210087d1bb47f.png)

为了找到轮轴齿轮电机，我们卸下了前轮。

![](../Images/8a9be37bcf5dc677e9a854592288dd4e.png)

拧下盖子后，我们可以推出旋转运动的源头，并发现电机后盖后面的一个小圆形板。

![](../Images/53fb2c903e3b0c1c765457390fd93d15.png)

除了分配功率，它还具有用于（每四个线圈）测量速度的三个传感器。

```
外圈上12个线圈使中心主轴上的10个磁铁260次/分钟的转动。电机的连续输出功率为180 W，力矩为7.3 Nm。
```

![](../Images/46fd357719f6731ad674332a85b107ff.png)

翻转侧的三个齿轮由塑料制成，以将磨损保持在最小。

![](../Images/3157652040d604bcc4524587079315f4.png)

![](../Images/617e15b400e07931fec68149be7a8ccb.png)

我们从顶管拉出主插头，使我们能够提取连接所有电子元件的神经系统。

![](../Images/73017aca41eefa77a59e7fa740bde966.png)

只有4个 Torx 螺丝固定自行车计算机的盖子与 160 × 128 像素的 TFT 屏幕用简单的 ZIF 连接器连接。

![](../Images/8d1ca1244a051cc1cc7aa55e42326fd8.png)

在板的另一面，我们找到以下芯片：

```
联发科 MT6261A ARM 处理器

Microchip PIC16LF1518-I/MV PIC 控制器

CSR 1010D A05U 蓝牙智能IC照明

德州仪器TPS259240 eFuse 带过压保护

Winbond 25Q128FV 128 Mb 串行闪存
```

![](../Images/36f37f2967f5f2abb5578006afc096d2.png)

### 电池管

![](../Images/311defe0499ac1e127831de696ef8532.png)

该管可以单手取出，只需按下一个按钮，可以用5针连接于侧面在3小时内充电。

![](../Images/9287123b1680f567eb9704c92d064731.png)

自行车的重量大部分来源于这个电池——它重1.46公斤，当然是充满电的时候。

![](../Images/10391dc3b7832da2ad4d4ece4718865f.png)

自行车的电池容量重为5800mAh（208.8Wh）。上一个无意义的比较，电量超过5 个12.9英寸的 iPad Pro 12.9"!

![](../Images/5b877578d05d6d56263437a8e618def6.png)

我们开始撬开后灯，电缆保持在适当位置，但能看到一些隐藏的螺钉。进入内部就有办法啦。

![](../Images/a624fb2a1b1712925ad558385ce86b74.png)

这个大型脐带从充电端口通向另一端的电池和BMS（电池管理系统），并在后灯后面有一个LED板。

![](../Images/b8f613a8a9e7f9f65903adba66e71b15.png)

我们剥掉电路板，发现一些秘密。这个电路控制后面的LED阵列，以及沿管顶部的一些LED（可能指示电池活动）。

## 电池管理系统

![](../Images/9b9d4c5d20bfcd58aff74bfac59ad03c.png)

主电池盒很难打开。五个螺丝（隐藏在一些很难撬开的盖子下）并不是全部。

当我们在一些温和的加热和“良好的振动”下最终成功打开的外壳，搞坏了一些芯片。自行更换电池恐怕不行。

![](../Images/3a35891102922cb443138f5dcbf6da75.png)

我们终于拿到了奖品：20 个松下NCR18650PF锂离子电池！松下是一个很好的（安全）品牌，所以充电应该是很容易地，即使自行更换容易。

```
电池组还具有电池管理系统（BMS）电路板。	
```

![](../Images/ed188bef809b9f3268fb83d0a6354d95.png)

该板装有大量电阻器。突出的是以下组件：

```
一个ATMEL MEGA 328P 电池管理 MCU

S11428 33TVF

FL12.000 12 MHz 石英晶体振荡器
```

![](../Images/4eaf24de99edf0176ac5de68d4220164.png)

另一面，我们发现这些：

```
单n沟道沟槽MOSFET（x4）MDU1931 芯片

RS2M 整流器
```

### 自行车的大脑

![](../Images/2963b4bd9399914b10e90ff6eabc48ba.png)

控制单元安装在一个方便的把手上，使用了两个简单的螺丝连接到框架。

拆下螺丝后，我们可以通过导轨抓住控制器单元，并将其直接向外滑动。

![](../Images/29d083af052930da20d6849e32e0a82d.png)

这辆自行车的大脑是一个由 Ananda 制造的电动自行车控制器，Ananda 是许多电动自行车组件的制造商。

![](../Images/638dc86e3b576e1958dc2c49766bbb5c.png)

我们转到侧板，在里面的发现会震撼你（人们总是为内在而着迷，对吗？）

![](../Images/ead6e96b9ae99bba6a0b209631b007fa.png)

三个板 ——由一队夹子连接 ——淹没在黄色透明橡胶里。

```
我们认为这是为了减弱振动和帮助散热到铝外壳。
```

大多数重要组件都住在电池针板上，我们发现了：

```
STM32100C8 微控制器，采用 ARM Cortex-M3 32位RISC内核

MCP2003 LIN J2602 收发器

Diodes Inc AS358M 低功耗双运算放大器

GH17M 晶体管
```

![](../Images/3132169ee66038606835dadda06fb62b.png)

其余的覆盖板主要承载电容器和其它无源组件。

![](../Images/4c489b9911020d08544ddb6e0382ae89.png)

以上，这辆自行车被完全拆解。
