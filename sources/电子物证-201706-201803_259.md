# 安卓手机内的图片和视频的恢复方法及实战运用

【摘要】当前，手机已经成为人们工作和生活中不可或缺的工具。现在的公安工作中，几乎所有的案、事件都涉及到手机，并且通过对手机内电子数据的提取和分析，公安机关往往能够整理出有价值的线索或证据。但是，在民警日常办案过程中经常遇到安卓手机中涉案的图片、语音及视频被删除的情况，本文主要介绍针对此类情况的恢复方法以及实战运用。

【关键字】安卓    镜像    恢复    图片    视频

【前言】随着时代的发展、技术的进步，移动通信技术所能够提供的服务水平和服务种类不断的提高和扩充，手机已经成为人们工作生活中不可或缺的工具。工信部统计，截止今年2016年底，中国移动电话用户总数达到13.2亿户，其中4G用户总数达到7.7亿户。2016年的数据显示安卓操作系统占有全球移动智能手机系统86.2%的市场份额。在当前的公安工作中，几乎所有的案、事件都涉及到手机，并且通过对手机内电子数据的提取和分析，公安机关往往能够整理出有价值的线索或证据。但是，在民警日常办案过程中经常遇到安卓智能手机中涉案的图片、视频被删除的情况，这就需要对这些删除的文件进行恢复。

1.安卓手机取证的方法

手机取证可以分为多个层级，每个层级能获取数据的方法与获取到的数据都不相同，下面先简单介绍下安卓手机取证的各种方法以及该方法能够获取的数据种类。

1.1 API获取

API获取，是指取证过程中通过安装插件，让插件调用安卓系统的API，来向安卓系统询问有关电话本、短信、通话记录、日历等内容，然后返回给取证电脑。这种方法可以获取手机中的已有数据，无法恢复已删除数据，简单是说就是提取到手机上能看见的数据。

1.2文件系统数据逻辑获取

文件系统获取是通过Android Debug Bridge将手机文件系统中已有的文件和数据全部或部分获取。通过专业的手机取证系统，在有Root权限的情况下，不但可以获取到手机中已经保存的联系人、短信息和通话记录，而且由于安卓系统的这些信息是存储在db文件中的，因此还能基于SQLite数据库进行删除记录的恢复，提取到目标对象刻意删除的数据。但是此方法无法提取到已经删除的图片、音频和视频文件。

1.3备份数据提取

对于安卓手机来说，从4.x开始，使用adbbackup命令能够获得备份文件。同时随着备份技术的发展，不仅一些第三方Recovery的也具备了备份功能，而且如华为、小米、OPPO、魅族等手机原厂也自带了备份功能。这种方法的优点是无需root权限，获取数据较完整，也能基于SQLite文件进行数据恢复；缺点是不能对已经删除的文件进行恢复。

1.4逻辑镜像获取

在具备手机root权限的情况下，通过终端在手机执行DD命令或者采用一些类似方法将手机内存芯片中存储的所有数据转化成镜像文件的过程。这种方式最接近于传统计算机取证过程中创建硬盘DD镜像的做法，包含了隐藏文件、未分配簇等数据。物理镜像获取的优势非常明显，由于生成的镜像是采用DD命令创建的原始数据镜像，因此该镜像中的数据相较于此前的两种方式更加完整，包含了未分配簇中的数据，不但能够基于SQLite文件进行删除恢复，还能够在未分配簇中进行深度挖掘，恢复已经删出的图片、音频和视频等文件。

1.5物理镜像获取

物理获取一直被认为是安卓智能手机取证技术中数据获取最全面的一种方法，通常分为有损提取拆机镜像和无损物理镜像两种方法。

有损拆机镜像一般常用的方法有JTAG与读取芯片（chip off）。JTAG是联合测试工作组的简称，很多手机手机设备均具备JTAG端口，我们利用JTAG端口通过专业的设备获取手机镜像。读取芯片（chip off），通过拆机方式将手机的Flash存储芯片取下，使用专门的芯片编程器进行镜像的读取。

无损物理镜像的方法有很多，主要都是利用芯片生产长家或者手机制造商预留的工程协议获取手机镜像。根据不同的手机常用以下几种方式获取：MTK手机关机镜像；高通9008、9006模式下镜像；部分华为、小米手机的fastboot模式下的镜像。

物理镜像获取相当于获取到完整的Flash存储芯片的镜像文件。可以利用不同的恢复软件对镜像文件进行图片、音频和视频等文件恢复。

总而言之，要想对安卓手机中已经删除的图片、音频和视频等文件进行恢复，必须获取到手机Flash存储芯片的镜像文件。然后通过专业的，有针对性的数据恢复软件对已经删除的图片、音频和视频等文件恢复。必要的时候还可以用手工的方式对碎片文件进行重组恢复。

2.实战运用

2.1从殴打他人并拍摄裸照的行政案件中牵引出的涉嫌介绍卖淫案

2017年5月期间，李某（女）因强迫谌某（女）卖淫未能得逞，遂纠集多人对谌某进行殴打，致其受伤，并拍摄裸照威胁谌某不得告发。

其后，李某通过QQ将裸照发给谌某进行威胁，谌某将其中一张照片保存后将QQ聊天记录删除，而嫌疑人李某在抓获时已经将手机内的聊天记录和裸照删除，无法形成完整的证据链。

首先对谌某的手机数据进行逻辑提取，成功提取到其本人的裸照一张。

但是对李某的oppoa59s手机进行逻辑提取后未能发现关于谌某的照片。因为oppo a59s手机的root难度较大，很难获取逻辑镜像。

经查询，该款手机使用联发科芯片，型号为MT6750，且操作系统为安卓5.1未全盘加密。利用MTK镜像工具，成功获取到该手机数据的物理镜像，再使用恢复软件进行数据恢复，最终成功恢复出李某殴打谌某的照片和谌某的裸照。

面对铁证，李某承认了其纠集多人对谌某进行殴打并拍摄裸照的事实，并交代了其参与的多起介绍卖淫案。

2.2猥亵儿童案

2017年4、5月期间，一多起猥亵男童的案件：嫌疑人通过鸡奸、强迫男童给其口交等多种法式猥亵男童数人。

受害者家人于8月发现情况后向公安机关报案。

经调查，嫌疑人曾经对猥亵男童的过程拍摄视频，并将数段视频通过QQ发送给其中一个男童。

由于时间过久，男孩手机内的该段聊天记录与视频已被删除。

经查，该名男童使用的是一款三星SM-A7000手机，安卓系统版本6.1。

通过逻辑提取未能获取到删除的聊天记录与视频文件，但是通过刷入第三方recovery，轻松获取了root权限。利用专业的镜像下载工具，获取了手机数据的逻辑镜像。从而使用视频数据恢复软件成功恢复出一段男孩给嫌疑人口交的视频，此案顺利告破。
