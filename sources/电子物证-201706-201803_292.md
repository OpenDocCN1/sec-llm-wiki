使用一些常用的Linux命令，可以帮助用户在手机处于非root状态下开展一些分析工作。

1.获取手机的IMEI或者MEID信息

adb shell dumpsys iphonesubinfo

2.获取手机的型号等信息

adb shell "getprop | grep "product""

3.获取手机的系统版本等信息

adb shell "getprop | grep "build""

4.获取手机的MAC地址

adb shell cat /sys/class/net/wlan0/address

5.获取手机CPU信息

adb shell cat /proc/cpuinfo

6.获取手机的磁盘分区信息

adb shell df

7.获取手机的当前运行进程信息

adb shell ps

8.获取手机当前运行的服务

adb shell service list

9.获取手机的网络配置信息

adb shell netcfg

10.获取手机的网络连接信息

adb shell netstat –ap

11.手机屏幕截图

将截图文件保存在手机存储卡中

adb shell screencap -p /sdcard/screenshot.png

将截图文件下载到本地计算机中

adb pull /sdcard/screenshot.png D:\\

删除手机中的截图文件

adb shell rm /sdcard/ screenshot.png

12.手机屏幕录像(Android4.4以上支持该命令，由于现有手机版本限制未进行测试)

开始手机屏幕录像，视频格式为mp4，结果文件存放到手机sd卡里，默认录制时间为180s

adb shell screenrecord /sdcard/demo.mp4

设置屏幕录像时间为10s

adb shell screenrecord --time-limit 10/sdcard/demo.mp4

设置屏幕录像分辨率为1280\*720

adb shell screenrecord --size 1280\*720/sdcard/demo.mp4

在屏幕录像过程中，可以使用Ctrl+C进行终止

导出屏幕录像文件

adb pull /sdcard/demo.mp4 D:\\

删除手机中的屏幕录像文件

adb shell rm /sdcard/ demo.mp4

13.获取手机已安装应用程序列表

获取手机全部应用程序列表

adb shell pm list package

获取手机全部应用程序列表，包含已删除程序

adb shell pm list packages -u

获取手机系统应用程序列表  
adb shell pm list package -s

获取手机第三方应用程序列表  
adb shell pm list package -3

获取手机第三方应用程序列表和apk保存路径  
adb shell pm list package -3 -f

14.备份手机已安装应用程序apk至本机

adb pull /data/app/<apk名称>  <apk备份名称+版本>

备份微信apk，路径和文件名称可以通过上面的命令获取

例如，adb pull /data/app/com.tencent.mm-2.apk d:\\weixin\_bak.apk

15.获取已安装应用程序的详细信息(包括：版本号，apk保存路径，数据目录，安装时间，更新时间，权限等)

adb shell dumpsys package <应用程序包名称>

获取微信的详细资料

例如，adb shell dumpsys package com.tencent.mm

![](../Images/cb7d5d254001acb090dc21d87bf2f4aa.png)

16.直接获取手机中应用程序数据文件

例如，adb pull /data/data/com.tencent.mm d:\\data

例如，adb pull /sdcard/tencent d:\\data

需要注意的是，非root权限可能无法下载data分区的应用程序数据。

17.上传数据文件到手机

adb push <本地文件完整路径> <手机保存路径>

18.安装应用程序

方式一，采用pm命令进行安装（-r表示保留应用程序数据，重新进行安装；-d表示允许版本降级安装）

需要先上传apk到手机

例如，adb push d:\\test\\rimet\_10002068.apk /scard/

然后再进行安装

例如，adb shell pm install –r /sdcard/rimet\_10002068.apk

方式二，采用adb install命令进行安装（-r表示保留应用程序数据，重新进行安装；-d表示允许降级安装）

例如，adb install -r d:\\test\\rimet\_10002068.apk

19.删除应用程序

方式一，采用pm删除应用程序（-k表示保留应用程序数据）

adb shell pm uninstall -k <应用程序包名>

方式二，采用adb uninstall删除应用程序

adb uninstall <应用程序包名>

需要注意的是，删除系统程序可能需要root权限。

20.获取手机的时间信息

adb shell date

21.获取手机显示屏参数

adb shell dumpsys window displays

22.控制手机进行模拟按键

adb shell input keyevent <按键编码>

| 常用按键编码 || 功能 |
| --- | --- |
| 3 || HOME键 |
| 4 || 返回键 |
| 26 || 电源键 |
| 82 || 菜单键 |
| 224 || 点亮屏幕 |
| 176 || 打开系统设置 |
| 164 || 静音 |

滑动解锁：如果锁屏没有密码，向上滑动手势解锁：adb shell input swipe 300 1000 300 500

参数300 1000 300 500分别表示起始点x坐标，起始点y坐标，结束点x坐标，结束点y坐标。

23.获取手机分区名称及挂载点

adb shell mount

![](../Images/744f1e2ebaf9d2a485ef6754be4f81c6.png)

对于某些手机mount命令没有直接给出挂载点，可以根据上面的/dev/block/platform/xxxxxx/by-name信息，运行下列命令

adb shell ls -l /dev/block/platform/msm\_sdcc.1/by-name，可以获取挂载点。

![](../Images/f6a74248bfd4ca0b5f259c8c6b53c81d.png)

上面测试手机的userdata分区挂载的设备是/dev/block/mmcblk0p27。

24.获取手机内置存储器分区镜像（需root权限）

获取手机内置存储器分区镜像可以帮助用户对手机已删除数据的进行恢复。

使用一些命令手动进行分区镜像的过程如下：

24.1 准备工作

手机已获得root权限，手机端已安装工具busybox；电脑端需要工具软件nc.exe、pv.exe、cygwin1.dll、cygintl-8.dll，工具nc用来通过网络接收数据，工具pv用来显示已传输数据总量和传输速度。

检查手机是否成功root，可以运行命令adb shell su。

检查手机busybox是否安装成功，可以运行命令adb shell busybox。

24.2 取得手机DATA分区的挂载点

可以具体用上面介绍的“获取手机分区名称及挂载点”方法获取。

24.3 设置adb的端口映射

adb forward tcp:52330 tcp:52330

24.3 进入adb shell，并获取root权限

adb shell su

24.4 在shell中执行镜像命令

busybox nc -l -p 52330 -e dd if=/dev/block/mmcblk0p23

参数“/dev/block/mmcblk0p23”为data分区，每个手机可能不一定相同。

![](../Images/12e65e306e9db5ed9db042096c4b8177.png)

24.4 电脑端接收镜像数据

重新打开一个cmd窗口，用工具nc工具来连接52330端口，接收手机端的镜像数据并保存在电脑中。

具体命令：nc 127.0.0.1 52330 | pv -i 1 > d:\\test\\data.img

![](../Images/f5c3fb488544fa6aa61aa0b7a02cbfe9.png)

25.备份应用程序数据

在应用程序的AndroidManifest.xml文件中，有一个allowBackup属性，该属性默认是true，用户可以通过adb backup命令对应用程序的数据进行备份。但是，为了安全起见，许多开发者会将allowBackup属性值设置为false来关闭应用程序数据的备份功能。

常用的备份命令如下：

//备份所有应用程序数据

adb backup -f <filename.ab> -apk -shared –all

//备份单个应用程序数据

adb backup -f <filename.ab> -apk -shared <应用程序包名>

如果备份应用程序数据失败，可以找一个允许备份的低版本应用程序，进行保留数据降级安装，降级前必须首先将手机端现有的应用程序apk备份到电脑中，然后进行保留数据降级安装低版本apk，再用adb backup备份数据，备份完成后，最后，在保留数据的前提下安装之前电脑中备份的应用程序apk。保留数据安装或者删除应用程序涉及的命令，具体可以参考前面的内容。

判断一个版本的应用程序是否支持备份，可以对它进行反编译，通过分析AndroidManifest.xml文件的allowBackup属性来判断。

26\. ADB通过WIFI方式连接手机

当电脑的USB端口不够用，或者手机的USB端口连接不稳定时，可以通过无线WIFI方式连接手机。  
26.1当手机有root权限时

由于手机默认采用USB方式连接电脑，需要在root权限下将手机的ADB连接方式修改为WIFI。首先需要在手机端安装Android Terminal Emulator，然后在手机端打开Android Terminal Emulator命令窗口，依次执行下列命令：

su

setprop service.adb.tcp.port 5555

stop adbd

start adbd

![](../Images/adf028aa1724238fedba9ae6af9025a0.png)

然后，手机连接无线路由器，电脑也连接同一个路由器，在电脑端打开cmd命令行，输入：adb connect <手机IP地址>。当使用WIFI方式连接手机时，USB连接是无法使用ADB的。

如果需要恢复使用USB方式连接时，只需要在手机端的终端命令中运行如下命令：

su

setprop service.adb.tcp.port -1

stop adbd

start adbd

26.2当手机无root权限时

首先，需要电脑通过USB连接手机，才能切换到WIFI方式。在电脑端执行下列命令：

adb tcpip 5555

//执行完上面命令，就可以断开USB连接，通过WIFI连接手机了

adb connect <手机IP地址>

//断开WIFI连接

adb disconnect

如果需要恢复使用USB方式连接时，需要在WIFI连接状态下，在电脑端执行下面命令：

adb usb

27.使用ADB命令启动应用程序

adb shell am start <应用程序包名>/<应用程序activity名称>

应用程序包名和应用程序activity名称，可以通过反编译apk，从AndroidManifest.xml文件中获取。

例如启动微信：adb shell am startcom.tencent.mm/com.tencent.mm.ui.LauncherUI

28.强制关闭应用程序

adb shell am force-stop <应用程序包名>

例如强制关闭微信：adb shell am force-stop com.tencent.mm

29.安卓系统的EDL(emergency download)模式

大部分基于高通CPU的安卓设备都支持EDL模式，也就是常说的9008模式。在这种模式下，可以绕过BL锁刷机。

进入EDL模式（9008模式）有三种方式：

方式一：正常开机状态下，执行以下ADB命令

adb reboot edl

方式二：FastBoot模式下执行以下命令

   fastboot oem edl

   方式三：通过主板短接触发进入EDL模式。使用这种方式，需要更多的厂家资料。

adb shell dumpsys dbinfo <应用程序包名>

除了可以查看应用程序访问的数据库文件，也可以看到应用程序执行过的SQL语句，这个功能对于应用程序的逆向分析有一定的帮助。

35\. 常用的fastboot命令

在fastboot模式下，可以使用下列命令：

35.1 显示连接的所有设备

fastboot devices

35.2 获取手机基本信息

fastboot getvar all

35.3 擦除分区数据（慎用）

fastboot erase <分区名称>

例如擦除data分区，fastboot erase userdata

35.4 刷写指定分区

命令格式：fastboot flash <分区名称> <刷机文件.img>

常见的分区名称有：system（系统分区）、boot（保存内核数据）、cache（缓存分区）、userdata（用户数据分区）、recovery（恢复分区）、radio（基带数据）、oem（保存运营商配置文件）、splash1（保存开机画面）等。

例如刷入第三方recovery，fastboot flash recovery recovery.img

35.5 重启手机至正常模式

fastboot reboot

35.6 引导启动外部镜像

fastboot boot <img文件>

35.7 常见华为手机bootloader解锁命令

首先需要申请解锁码；得到解锁码后执行命令adb reboot bootloader进入fastboot模式；执行命令fastboot devices，检查设备是否正常连接；执行命令fastboot oem get-bootinfo，检查bootloader是否加锁；执行fastboot oem unlock <16位解锁密码>，开始解锁，完成后手机将自动重启，重新进入fastboot模式；再次执行fastboot oem get-bootinfo，检查bootloader状态是否为unlocked，unlocked即为解锁成功；执行命令fastboot reboot，手机回到正常开机模式。
