什么？镜像还分手工和非手工吗？

是的，镜像分为手工镜像和自动镜像。


手工镜像：使用开源或免费的工具，在理解底层实现之后，对目标盘或分区进行镜像。

自动镜像：使用商业版专业镜像工具对目标盘或分区进行镜像。

两者的效果相同，结果差异不大。我们通常都会采取商业版的镜像工具来镜像，因为这种方式对操作人员的技术要求不高，且这些工具都是经过权威测评和认证的，结果可靠，一般不会出现手工镜像误操作导致删改的情况。

但，能够使用偷懒的工具不代表我们应该放弃动手的可能，跟着晓光老师学习起来！



正文


本文所述物理镜像过程，主要针对具有root权限以及USB调试权限的Android系统手机。

▍原理简介

给安卓手机制作物理镜像，就是把手机存储芯片里最底层的数据全部提取出来。

Android系统是基于Linux内核的一个操作系统，在Linux系统里有一个dd程序可以用来备份数据，这里我们可以通过在手机上安装busybox工具来获取dd程序，再通过在手机和电脑端运行nc通过网络将手机镜像数据传输到电脑上进行保存。

▍镜像准备

手机端：root，USB调试，busybox

电脑端：nc

数据线（USB type A--USB microB 或USB type A—USB type C）

本次实验手机为本人使用的第一台Android手机。（图片左侧的两根跳线与该实验无关，具体作用暂时保密，大家可以自行脑洞。）

▍基础知识

1. ADB

Android Debug Bridge，安卓调试桥，在调试Android系统时经常被用到。可以用来直接查看Android设备里的数据，可以直接在Android设备里运行shell命令。

常见Android命令：

ADB Debugging

adb devices  显示当前连接的设备或模拟器

adb forward  创建通信端口

adb kill-server 关闭adb服务（通常在设备连接不正常时使用此命令重新开始）

Package Manager

adb install  安装应用程序

adb uninstall  卸载应用程序

adb shell pm list packages  显示设备/模拟器上的所有软件包

File Manager

adb pull  从手机端向电脑端拷文件

adb push  从电脑端向手机端拷文件。

adb shell  执行shell命令

adb shell touch  模拟触控操作



2. Busybox

BusyBox 是一个集成了一百多个最常用Linux命令和工具的软件。BusyBox 包含了一些简单的工具，例如ls、cat和echo等等，还包含了一些更大、更复杂的工具，例如grep、find、mount以及telnet等。

3. NC

NC是Netcat的简写，其作用在于：

（1）实现任意TCP/UDP端口的侦听，nc可以作为server以TCP或UDP方式侦听指定端口

（2）端口的扫描，nc可以作为client发起TCP或UDP连接

（3）机器之间传输文件

（4）机器之间网络测速

4. Android 分区概念

/data 分区：数据分区

/system 分区：系统分区

/recovery 分区：恢复分区

/cache 分区：缓存分区

/Boot 分区：内核分区

▍实际操作

接下来，开始物理镜像过程，详细步骤如下。

Step 1: 将手机通过数据线连接到电脑；

Step 2: 进入CMD，打开adb；

Step 3: 输入adb devices，查看Android设备是否与电脑正常连接；

Step 4: 输入adb shell df，查看分区大小 /data 分区大小；

（图为使用power shell，与使用cmd效果一样）

Step 5: 输入adb shell mount，查看各分区挂载点；

Step 6: 输入adb push busybox /cache，上传busybox文件进入cache分区；

Step 7: 如果出现上传错误请检查分区权限 修改分区权限 chmod 777 cache；

Step 8: 输入 adb forward  tcp:8888 tcp:8888 （建立通道8888端口 端口可以1024-65525 端口自定义 不要和windows常用端口冲突）

Step 9: Adb shell su （获取最高权限，需先对手机进行root）

Step 10: 在#后输入命令

busybox nc -l -p 8888 -e dd if=/dev/block/mtdblock13

此处需要根据上文mount命令的结果变更；

（查看data分区后还可以通过 cd  /dev/block/ 输入ls –l 查看）

Step 11: 再打开一个CMD 输入命令nc 127.0.0.1 8888 | pv -i 0.5 > d:\cnpeter.img

最后我们就可以得到data分区的完整镜像。其他分区的镜像操作类似。

至此，手工镜像就完成了。

▍技巧Tip：Android 手势密码去除

在/data/system分区有一个gesture.key的文件，删掉该文件后在手机解锁时随意划一个图案即可解锁。
