VIVO手机是目前最为常见的手机品牌之一，在实际案件中也常常遇到，由于VIVO X9系列之后的手机采用基于安卓6.0+的Fun touch OS操作系统，默认开启了FDE（Full Disk Encryption）全盘加密，且VIVO没有原生备份应用，因此在实际检验工作中提取数据难度很大。本文将特别介绍VIVO手机微信、QQ数据获取方案。

测试检材：VIVO NEX旗舰版，Funtouch OS 4.0（基于Android 8.1），CPU高通 骁龙845，RAM8GB，ROM256GB。(存在VIVO账户锁，密码未知）

1

step

拿到手机检材首先检查确保已开启“飞行模式”，然后检查QQ、微信是否存在应用分身，各个应用是否有登录记录（存在数据）。

2

step

开启USB调试

打开手机设置中的“关于手机”，连续点击“软件版本号”使手机处于“开发者模式”。

返回，进入“开发者选项”，开启“开发者选项”、“不锁定屏幕”、“USB调试”。

使用数据线连接电脑，下拉通知栏，选择连接方式为“管理文件”（MTP）。

3

step

获取通讯录、短信、通话记录、微信数据

温馨提示：这一步需要电脑有无线网卡，即，可以连接WiFi。

在平航手机取证分析软件PF5100（简称PF5100）中，建立案件，添加手机-选择Android系统。

然后数据类型选择“手机（USB连接）”。

输入物证名称（必填），物证编号（选填），PF5100自动在手机上安装一个代理提取插件。

如手机需输入账号密码，则在电脑桌面上右键PF5100的图标-“打开文件所在的位置”，找到“%\bin\TenentAdi.apk”,将其拷贝到手机存储，然后在手机上打开“文件管理”，找到“TenentAdi.apk”点击安装。

因后续选择提取的模式为“VIVO互传”，故这里选择快速读取，避免耗费重复时间。

在“备份选择”弹窗中，选择“VIVO互传”备份方式。

如果自动安装失败，则有下图弹窗。检查手机中是否有“互传”应用，有则卸载掉，然后根据提示在手机安装应用（安装方式参考上述的插件安装）。安装完成后，点击弹窗的“是”，继续提取。

电脑出现下图弹窗，同时手机自动打开“互传”应用，点击弹窗左右箭头查看参考图示，成功连接WiFi后，点击弹窗下方的“连接手机”。

提取正常则手机显示下图界面（注：无需点击“开始换机”），上图中则显示“正在导出：”字样。

随后解析日志显示“导出内部存储”，然后正式解析，解析结束界面如下图。

4

step

获取QQ数据、微信分身完整数据

风险提示：

手工降级提取数据存在丢失数据的风险！

输入命令时请务必检查确保命令输入正确！

以下操作不可用于存在QQ应用分身的检材，否则分身数据将丢失！

准备工作：打开adb工具。

右键桌面图标“平航手机取证分析软件”，“打开文件所在的位置”。

进入/bin目录，复制路径。

在命令提示符跳转路径，需先跳转到对应盘符。

到这里，已经成功打开了adb工具。


手机QQ数据获取。

在adb工具输入adb devices检测手机连接状态。

输入adb shell pm path com.tencent.mobileqq  获取原版本QQ安装包路径；

输入adb pull /data/app/com.tencent.mobileqq-1/base.apk D:\cases\0\原QQ.apk（最后一段为电脑存储全路径，可自定义）导出原版本QQ安装包。

保留数据卸载高版本QQ。

输入adb shell pm uninstall -k com.tencent.mobileqq 。

注：手机如有弹窗提示清除残留，请务必取消。

重启手机，重新检测连接（adb devices），输入adb push D:\cases\0\com.tencent.mobileqq.apk /mnt/sdcard/  将低版本QQ安装包导入手机。（安装包在平航安装路径“%\平航手机取证分析软件\bin\apk\”可以获取到，将其拷贝到简单路径，如，D:\cases\0\  ）。

在手机“文件管理”中找到安装包，点击安装。

在adb工具输入adb backup -f D:\cases\0\QQ数据.ab com.tencent.mobileqq  ,在手机点击“备份我的数据”。

备份完成之后，在adb工具输入adb pull /mnt/sdcard/Tencent D:\cases\0\   导出QQ附件。

安装原版QQ。

输入adb push D:\cases\0\原QQ.apk /mnt/sdcard/

然后在手机“文件管理”中找到安装包（原QQ.apk），点击安装。

在PF5100中，“添加手机”——“Android”——“手机助手备份”

选择数据路径，“存储卡目录”选择“Tencent”的上一层目录。

全面读取，等待解析完成。


微信分身完整数据获取。（关联附件）

导出微信分身附件。

输入adb pull storage/emulated/999/tencent/micromsg D:\cases\1\sdcard\tencent\  （部分较低版本FunTouch系统的微信分身附件路径可能存在于：/mnt/sdcard/tencent_cloned/MicroMsg   ）。

提取微信分身数据包。

在PF5100“案件管理”打开检材案件目录，进入“检材\【具体检材】\备份”目录，打开压缩包“com.tencent.mm.zip”，

将其中的“.1”目录解压至“%\data\data\”路径下，并重命名为“com.tencent.mm”。

在PF5100中，“添加手机”——“Android”——“手机数据（文件夹）”

选择数据路径，绿框内为必备结构。

全面读取，等待解析完成。

5

step（选做）

媒体文件获取

在PF5100中，“添加手机”——“Android”——“手机（USB连接）”——“数据类型”——“手机信息”——“自定义读取”（下图）

取消全选，展开“生活工具”，勾选“媒体文件”。

选择“安卓备份”。

等待解析完成。

6

step

检材合并，导出报告

选择“插件”——“检材合并”，将主要检材中的微信分身数据转移。（因其无附件）

逐一将数据合并到主要检材目录下。

数据合并完成后，选择“分析报告”导出软件的报告。

至此，VIVO手机数据获取结束。

附注：

其他第三方应用数据获取，参考手机QQ数据获取方案。

命令行adb shell pm path packages     可以获取到手机已安装应用的包名列表。‍
