# 【云取证】镜像验证与仿真

随着时代的进步，网络的发展，人们的生活与“云”越来越密切相关。当然，今天我们并不是要介绍“云”，而是来一起学习云服务器镜像的一些取证相关技巧，接下来以“阿里云”的云服务器镜像为例。当我们获取到云服务器镜像之后，可以通过仿真来获取镜像内的数据，而这种方式通常需要先进行三步操作：镜像验证、镜像仿真、破解登录密码。

一、镜像验证

![](../Images/c72248f321b0f2db9b6d73f864fa0f81.png)

    我们平时的工作中，最常用的是以MD5值来验证镜像的完整性，但是阿里云不提供MD5值，只提供CRC-64-ECMA值作为镜像完整性验证依据，并且这个值与取证软件算出的CRC-64值不一样，目前只能使用阿里云官方提供的OssUtil工具来计算完整性。

OssUtil工具下载地址：

    https://helpcdn.aliyun.com/document\_detail/50452.html?spm=a2c4g.11174283.3.2.MlKdv0

  

OssUtil工具使用  

1.下载对应系统版本的OssUtil工具并解压，进入所在目录。

![](../Images/eedfc7313c4edbb9adeb31286bc25023.png)

2.在此界面空白处按住shift键并单击鼠标右键，选择打开Powershell窗口。

![](../Images/8986751487ac9e32d40ca0d46c19756d.png)

3.使用ossutil64.exe hash xxxxxx.raw命令计算CRC-64-ECMA值（xxxxxx.raw处为镜像完整保存地址）。

![](../Images/6dc57a700f7fe379dedbde5cd0736123.png)

二、镜像仿真

![](../Images/25d1cdb16b108162a2f228ba28244c38.png)

    我们常用的Vmware虚拟机并不能直接挂载raw格式镜像，因此我们需要先将raw镜像转换为Vmware可以访问的vmdk格式镜像，我们可以借助Qemu-img工具来转换镜像格式。

![](../Images/cb61fef7a634e4183940f2d2ba31241b.png)

Qemu-img工具下载地址：

    https://www.qemu.org/download/

  

Qemu-img工具使用

1.下载安装Qemu-img后，进入安装所在目录。

![](../Images/3b6f2c43893a20e0a12ad0c8321b234c.png)

2.在此界面空白处按住shift键并单击鼠标右键，选择打开Powershell窗口。

![](../Images/a3fb4cf33f273fbf98a187d4ce0729d9.png)

3.使用qemu-img convert -f raw xx1.raw -O vmdk xx2.vmdk命令进行转换 （xx1.raw为raw文件完整地址；xx2.vmdk处为转换后的文件保存地址）。

![](../Images/970b9ba9ef5759dd7865ebd9338820e5.png)

  

使用Vmware虚拟机加载镜像

1.打开Vmware虚拟机，选择新建虚拟机， 选择自定义虚拟机。

![](../Images/767673647d44e5fed8b1dceea5de7b98.png)

![](../Images/3bde19d224f64e585e9e9d21f62a7aea.png)

![](../Images/7d1793ec946f7d22b5d10f95ffcef113.png)

2.在选择磁盘时选择使用现有虚拟磁盘。

![](../Images/9ca0f92ca41af174e9b284d2797a09af.png)

3.选择Qemu-img转换后的.vmdk文件，并保持现有格式。

![](../Images/a286751269c941aa00cac669df07719b.png)

4.开启虚拟机即可完成镜像加载。

三、破解登录密码

![](../Images/135a29668de99596dd82e9a759923019.png)

    我们平时工作中所接触的云服务器镜像，比较常见的操作系统有两种：Windows、Linux。  

Windows系统

利用微PE工具箱，修改登录账户密码。

1.找一个空闲U盘，使用微PE将U盘制作成PE工具U盘。

![](../Images/e51eda016650b430a82ac5bc23c50ae9.png)

微PE下载地址：

    http://www.wepe.com.cn/download.html

  

2.将U盘接入电脑，打开虚拟机，在启动项选择打开电源时进入固件。

![](../Images/eb6e2f0a1d0db8dc7f87e1dbf198be3b.png)

3.在Boot选项内，选择USB Device 选项使用U盘启动PE系统。

![](../Images/9b1fba8f8a2c182236a6083b53c2ac2e.png)

4.PE系统启动完成后，选择Windows密码修改。

![](../Images/a20b3c2c86ab55d38e759757a13a2de4.png)

点击打开后，修改对应用户密码保存。

![](../Images/cb9a8e5c8b082cce31f06457b3bd787f.png)

5.将U盘拔出，重启系统登录即可。

Linux系统

利用单用户模式，修改ROOT账户密码。

1.打开Linux系统，一直按e键，进入Grub编辑模式。

![](../Images/022107bd281e9c6d549d87b8ca5a8892.png)

2.找到 ro 开头字段，并删除其后内容，将其改为  rw init=/bin/bash   。

![](../Images/922b03f2c15a3edab76f252ca4817cb5.png)

3.按ctrl + x 重新启动系统。

4.重启后如显示#号后光标闪烁则表示单用户模式启动成功，

使用“ passwd 用户名 ”修改密码，输入2次新密码后修改成功。

![](../Images/9aa9c6ea6c6bfaa3de288d72c872c2fc.png)

5.使用 reboot 重启系统（或强制重启），登录即可。
