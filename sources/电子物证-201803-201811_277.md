# 【借鉴国外经验加强我国大数据反腐败能力建设】

信息时代，数据作为信息化的重要战略资源，大数据管理已经上升为国家战略，大数据应以更加积极姿态应用于公共管理和政府治理中去，未来，大数据将在惩治腐败过程中发挥不可替代的作用。

党的十九大报告着眼于实现新时代党的历史使命，针对反腐败斗争提出要“巩固压倒性态势、夺取压倒性胜利”。大数据时代的到来在给人们的生活和工作带来深刻影响的同时，也为反腐败插上了科技的翅膀。大数据反腐，就是要将“互联网+”运用到反腐监督之中，利用强大的数据信息源泉和先进的技术手段，发挥“互联网+纪检监察”功能。信息时代，数据作为信息化的重要战略资源，大数据管理已经上升为国家战略，大数据应以更加积极姿态应用于公共管理和政府治理中去，“得数据者得天下”，未来，大数据将在惩治腐败过程中发挥不可替代的作用。

**我国利用大数据反腐败存在的问题**

（一）信息孤岛难题仍待破解

从横向渠道看，各个部门信息衔接不通畅现象仍然存在。大数据收集的主体，主要是党政机关、事业单位工作人员，建立党员、公职人员基础信息数据库，涉及到个人的婚姻状况、家庭情况等各类关系，也涉及到房产、工商、税务、医保、社保、水电气缴费等多个部门，收集海量数据，由于牵扯到部门利益，因此受到的抵制力量较大。从纵向整合看，要实现全国上下的信息联网还有待时日。当前，中央与地方各省区市存储的相关信息还没有实现有效衔接，个人违纪信息等的跨省查询还没有实现，这已经严重不适应现代反腐形势的发展需求。

（二）大数据管理技术低下，人才缺失严重

利用大数据反腐必须掌握大数据技术，分别是数据收集、存储、挖掘、分析、可视化等，只有技术达到一定水平才能发掘出大数据反腐的价值。现阶段中国反腐败机构涉及大数据的各项技术都不尽成熟，在数据收集、数据存储、数据处理等方面还存在诸多问题，仍缺乏一套完善的网络系统集中处理网民提供的数据信息。此外，当前的人才建设与大数据反腐需求相脱节，目前能够真正理解与应用大数据的创新型人才还属于稀缺资源。受理网络反腐案件的政府公务人员由于自身业务素质和技能低下，不能适应大数据反腐的要求，大数据反腐相关技术人才的缺失，无疑成为大数据反腐所面临的严峻挑战。

（三）泄露个人隐私问题突出

在大数据时代，人们的教育、消费、医疗、交友、纳税、犯罪等一切生活轨迹都可以被数据记录。而大数据系统本身不考虑个体和群体是否愿意共享，而是不自觉地吸收着各种数据信息。大数据反腐过程中，监督主体具有随意性、自发性、盲目性的特征，一般而言，普通大众并没有公安机关特有的调查取证权，只能通过人肉搜索或通过曝光官员及其家人的个人隐私、照片来反腐。因此，在对官员的行为进行披露和追踪报道的过程中，很有可能已经侵犯了包括其家人在内的隐私权。

**国外大数据反腐的实践与经验**

（一）采取多种途径提升政府的大数据反腐能力

为提升大数据反腐的效率，各国也在积极探索新的途径和方法，目前，国外相对成熟的做法主要包括两个方面：一方面，提升自身的数据分析能力，着力培养具备数据分析能力的团队。目前，已有部分国家建立了政府层面的数据分析团队，并积累了一些数据分析方法。比如丹麦、英国、智利、墨西哥、巴西等国，通过建立政府层面的数据分析实验室，加强利用数据分析结果来修改反腐方案，完善相关法规政策。另一方面，在利用大数据反腐方面，各国也在创新和应用一些新的分析方法和数据软件。例如，印度一款名为“我行贿了”的应用程序，该程序主要功能就是为公民举报官员受贿贪污行为提供平台和渠道；再比如哥伦比亚政府推广了一款同样功能的应用程序，让公众监督公共工程的进度和资金使用情况来防治贪腐，据统计，该程序自开发应用以来，截止到2015年底，已经发现了83项违规的公共工程，涉案违规金额多达5亿美元。

（二）增加数据透明度，发挥公众监督效应

保证数据公开透明并接受公众监督已成为很多国家的反腐利器。目前，很多国家已加快推动数据透明化改革。早在2009年，英国政府就设立公共网站，对公众公布了七个政府部门8633条数据资料，美国也在奥巴马任期内将众多数据公布在政府网站上，首次对公众开放数据信息，方便公众查阅监督。巴西的非营利组织Contas Aber tas通过审查政府透明门户网站联邦预算网等公开的预算数据和文件，发现了巴西总统迪尔玛·罗塞夫挪用政府财政预算资金的犯罪行为，助力巴西联邦审计法院执行反贪行动。在这个案例中，政府层面强制性地公开重要领域的信息数据起到了至关重要的作用，同时，该案例也证明信息量大而范围广泛的数据透明行动能够有效促进公众参与到大数据反腐行动中来，行使监督权力。

（三）提升数据质量，扩大数据覆盖范围

来源广泛且质量可靠的数据是大数据反腐的基础。目前，国外关于大数据反腐方案的讨论逐渐从强调开放和使用大数据转向关注有效数据的产生，力求政府能够统计、收集、公开高质量的官方数据，并建立相关数据的有效管理登记系统，以此发挥高质量数据对反腐的支撑作用。例如，2016年，国际调查记者联盟联合76个国家的记者报道了1976年以来富人们在全球范围内隐瞒财产、逃税避税的行为，涉及非法获得财富的不透明离岸公司、信托公司、基金会以及某些犯罪集团等。此次行动用的数据信息主要来源于多国记者和数据专家常年对一家律师事务所的秘密调查，在调查过程中记者们获得了专业数据分析公司的大力支持，信息的云端存储让全球近400名记者得以在这个项目上协同工作，数据挖掘技术和可视化工具的大量运用，保证了高质量反腐数据的获取，从而推动反腐行动取得成功。

**加强我国大数据反腐败能力建设的举措**

（一）建设统一的电子政务监察系统

从顶层设计入手，科学规划电子政务公共平台的反腐倡廉功能，尽快建成全地域、全天候、全业务、全功能的统一网络平台，开发电子政务的反腐倡廉功能，将相关单位及部门的信息整合到国家电子政务系统中去，实现数据的整合、协同、集约和共享，形成权威、全面、统一的国家电子政务系统数据，统一的数据接口和数据格式标准，破除信息孤岛、各自为政的分裂状态，实现不同部门之间、上下级之间、跨部门之间数据的互联互通，为各单位反腐倡廉建设的信息监察提供统一、全面、可靠的数据查询和监控平台，通过这个平台，国家及各地、各单位的反腐机构、纪检工作人员可全面、客观、实时地查询到所需要的相关信息。

（二）加强防范保障数据安全

为了有效保障数据安全，一是在规划上，应将反腐大数据划分类别，对涉及国家机密、国家安全及个人安全的数据进行专门管理，为其使用和查看设置权限。二是加强立法工作，修改完善国家层面的关于保障网络信息安全的相关法律制度，填补数据安全保护的法律漏洞，切实保护反腐数据库的信息安全。三是在技术上，防范内外部风险。针对反腐大数据面临着黑客的恶意攻击和内部管理不完善等问题，采用积极备份、安装防火墙和防毒软件、使用入侵检测技术和加密技术等加以防范，特别是各单位纪委举报平台都应加强技术投入，切实保护举报人的个人信息安全。最后，在安全意识上，要加强宣传教育，提高员工安全意识，提高个人数据保护技能。

（三）建立专门的反腐大数据处理部门

反腐大数据在纵向上涉及多级机构，横向上跨越多个职能部门，对象上涉及大量的工作人员，流程上涉及线索搜寻、案件查证、立案审判等多个环节，在技术上又需要根据需求在短时间内不断改进创新，其中的管理难度很大。为了有效发挥大数据的优势，各单位应在纪检监察机构下有必要建立专业的反腐大数据部门来完成各项工作。通过这个部门统一规划、纵横协调连通各项反腐数据，进而建立反腐大数据库，通过对资金、人员、设备等资源进行统一调配来维护数据库的顺利运行。

（四）加强人才队伍建设

大数据反腐，关键在人，应强化对反腐大数据应用技术人才的培养。为此，一是要加大对大数据时代信息化建设人力和财力的投入，改善大数据反腐的技术条件，优化大数据反腐的环境。二是要加速培养适应新形势发展要求的大数据应用技术人才队伍，不断加大对相关业务人员的培训力度，使其善于收集、整理海量的反腐数据，并根据不同需要对其进行分类、筛选，大幅提升相关业务人员的数据分析和处理能力。
