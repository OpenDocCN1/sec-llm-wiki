# 【VIVIO手机】需要输入账号密码的取证解决方案

**手机直读过程中，VIVO手机会需要输入账号密码的情况。这时候常用的解决方法有三种，获取账号密码，手动降级读取和vivo互传。**

  

情形一：手机上有SIM卡，且手机已获取账号密码

  

手机上会带有手机卡，该手机号极大可能会是手机账号的绑定手机。让电脑连入WIFI，在需要输入密码的界面点击忘记密码，之后手机会收到验证码短信(为防止破坏检材，要求SIM插入其他手机接收验证码短信)，输入验证码后可以修改密码。进入设置界面退出账号即可。之后分析软件选择手机USB连接读取手机即可。

![](../Images/5f6bd97500ac15c4ff9b002ae1dcc87d.png)

**操作难度一颗星：★**

  

  
情形二：无手机SIM卡，采用手动降级方法  

  

无手机SIM卡，可以采用手机应用降级的方法进行提取。步骤如下：

  

1、手机打开USB调试模式，通过USB数据线连接电脑；

  

2、按住win+R键，输入cmd，点击“确定”按钮打开“命令行”窗口；

  

3、复制bin文件夹路径（默认为C:\\Program Files (x86)\\平航科技\\平航手机取证分析软件\\bin）

  

4、在命令行窗口通过输入cd和ctrl+v粘贴的方式输入（win7系统需要右键粘粘）：

cd C:\\Program Files (x86)\\平航科技\\平航手机取证分析软件\\bin

即可进入到bin文件夹路径下

**5、以下是手动降级操作中最为关键的几个步骤（以降级微信为例）：**

  

**1）adb devices**

查看手机与电脑是否正常连接，绿色框内显示了该设备的序列号即表示正常连接成功

**2）adb shell pm path com.tencent.mm**

获取手机里面原版本微信安装包的路径 

**3）adb pull /data/app/com.tencent.mm-2/base.apk D:\\原版本微信.apk**

该命令是将手机里原版本微信的安装包拷贝到本地电脑D盘根目录下，并命名为“原版本微信.apk”,用于后续数据提取后将微信还原回原始状态 

**4）adb shell pm uninstall –k com.tencent.mm**

保留手机中原版本微信数据的同时卸载微信应用程序

***1）~4）步骤图示***

![](../Images/ca731b116f82d162e08036ae1bc1b34a.png) 5）将电脑中的专用低版本微信安装包（默认路径是**C:\\Program Files (x86)\\平航科技\\平航手机取证分析软件\\bin\\apk\\mm.apk，**）拷入手机本地存储；

  

6）进手机文件管理应用，（7.0以上版本的手机需要重启手机），安装该低版本安装包，完成微信降级。

  

7）此方法可用于QQ和支付宝的保数据降级操作，将命令行中的**“com.tencent.mm”（微信）改成“com.tencent.mobileqq”（QQ）和“com.eg.android.AlipayGphone”（支付宝）**即可。

  

6、完成应用降级之后，打开平航手机取证软件，选择手机USB直连-->安卓备份，然后根据软件提示操作，备份方式选择“安卓备份”，即可完成手机数据提取。

  

7、完成数据提取后，把之前备份的原版本微信、QQ、支付宝的安装包拷入手机本地存储，进手机文件管理，点击安装即可还原应用。

![](../Images/3ea797c5fcabab0e1f715cb1a76f8eb1.png)

**操作难度五颗星：**★****★****★****★****★****

  

情形三：无手机SIM卡，通过vivo互传功能  

  

此方法可以支持**高版本安卓微信及分身数据的提取和恢复**，

此外需要取证设备配备无线网卡，提取步骤如下：

  

1) 在平航手机取证分析软件中，选择**手机USB直连**，之后在取证软件出现的提示窗中选择**“VIVO互传**”；  

  

2) **将vivo互传的apk拷入手机本地存储，**进手机文件管理安装应用，然后打开该应用；

  

3) 电脑搜索WiFi信号，连接该vivo手机的热点，然后在取证软件提示窗中选择“**连接手机**”；

  

4) 软件自动运行提取进程，等待完成数据提取和恢复后进行后续数据分析工作。
