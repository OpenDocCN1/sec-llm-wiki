**三、****手机IMEI定位**

** （一）、什么是IMEI**

国际移动设备标识符（International MobileEquipment Identity，IMEI），即通常所说的手机序列号、手机「串号」，用于在移动电话网络中识别每一部独立的手机等行动通讯装置，相当于移动电话的身份证。序列号共有15位数字，前6位（TAC）是型号核准号码，代表手机类型。接着2位（FAC）是最后装配号，代表产地。后6位（SNR）是串号，代表生产顺序号。最后1位（SP）一般为0，是检验码，备用。国际移动设备标识符一般贴于机身背面与外包装上，同时也存在于手机内存中，通过输入\*#06#即可查询。\[6\]

1、TAC，TypeAllocationCode，类型分配码，由8位数字组成（早期是6位），是区分手机品牌和型号的编码，该代码由GSMA及其授权机构分配。

2、TAC码前两位又是分配机构标识（ReportingBody Identifier），是授权IMEI码分配机构的代码，如01为美国CTIA，35为英国BABT，86为中国TAF。

3、FAC，Final AssemblyCode，最终装配地代码，由2位数字构成，仅在早期TAC码为6位的手机中存在，所以TAC和FAC码合计一共8位数字。 FAC码用于生产商内部区分生产地代码。

4、SNR，Serial Number，序列号，由第9位开始的6位数字组成，区分每部手机的生产序列号。

5、CD，Check Digit，验证码，由前14位数字通过Luhn算法计算得出。

6、SVN，Software VersionNumber，软件版本号，区分同型号手机出厂时使用的不同软件版本，仅在部分品牌的部分机型中存在。

7、Example :356243001532072

*   35624300 : Type Allocation Code (TAC)
    
*   153207 : Serial Number of Device
    
*   2: LuhnCode (Checksum)
    

**（二）、手机IMEI码有什么用处**

1、IMEI码可判断手机是否为正品：作为每台手机的唯一标识，所有手机的IMEI码在原厂官网站的数据库中都有记录，所以IEMI码最大的作用就是可以判断一款手机是否是官方生产的正品手机。

2、IMEI码可判断手机是否为水货：通常在购买手机时，可以看看手机的包装外盒、手机放电池处/背盖处及在手机输入＊＃06＃后的这三组数字是否相同来判断手机是否为水货，因为大部分的水货都没有外包装，就算有外包装亦不可能一支支重新核对并包装。

3、IMEI码可协助查找手机失窃后的坐标：这也是手机失窃或遗失时，找回手机的一个管道。万一手机失窃，只要将此序号给电信局，管它天涯海角就算换门号，只要一拨出，马上找到，就算找不回来可令偷窃者得物无所用。目前日本、香港的电信业者都有提供 IMEI 码数据库服务，民众遗失手机时只要上网输入 IMEI 码，只要这支手机还开机，或被他人盗用，网络可实时会提供这支手机的位置。台湾电信服务商目前尚未提供 IMEI 查询服务，但机主若能讲出手机的 IMEI 可立即停止电话继续被使用。

**（三）、手机IMEI码是否可更改**

1、通过更换手机主板，更换后IMEI码将更改。

2、通过软件工具进行更改IMEI码，例如root刷机。

**（四）、如何透过电话号码或IMEI码追踪**

1、当手机关闭时，可联系电信服务提供商，以提供在特定时间段内进行的通话的详细信息。所以可以从电信服务提供商获得最后位置。因为你连接到电信服务提供商的基地台拨打电话/短信/等等和电信服务提供商记录相同。因此，有关通话，手机和基地台的详细信息将与电信服务提供商一起存储。

2、手机开着时，可以通过三角定位跟踪，连接到基地台，可以很容易地检测到。

3、可以在购买SIM卡时获取购置者所提交的相关个人讯息，获取您的详细信息。

4、Android默认情况下会保留位置历史记录。也可透过Google等访问。

5、IMEI是一部手机（双SIM卡手机有2个IMEI）。每次拨打电话时，IMEI都会被电信服务提供商记录下来。

6、可以通过IMEI或电话号码进行跟踪，两者都记录在通话详情中。

**四、基地台仿真器**

**（一）、基地台仿真器是什么**

基地台仿真器是一种电子设备，可以使执法机构追踪目标蜂窝式手持设备的位置或识别信息。追踪器可以在用户不知状况下，截获手机中的数据。基地台仿真器可以安装在卡车或面包车等监视车辆上，有些可以装在背包里，广播半径超过约200米。

**（二）、基地站仿真器如何工作**

手机通话会会周期性发出信号，试图“与附近的基地台”连系。手机响应信号并发送至基地信息。来回的通讯使手机可以在行动通信服务供货商等网络上拨打、接听电话或传送数据。(如图8所示)

**（三）、基地站仿真器收集哪些数据**

IMSI号码（国际移动用户标识符）：这个15位唯一号码识别用户识别模块（SIM卡）。它包含一个三位电信服务商代码，一个三位国家代码和一个九位唯一ID。它被电信服务商用来识别你和你的手机到网络。

IMEI号码（国际移动设备标识）：该号码是手机唯一的号码。如果设备被被盗，电信服务商可以使用此号码跟踪手机，中断服务或将其从网络黑名单。

新式基地台仿真器，定位在一米误差范围，并且能进行电波拦截、监听以及远程录音，功能强大。
