# 【对比】一加 6/5T 拆解

一加6是一加首款采用玻璃材质和超视野全面屏的机型，机身共有24颗螺丝，由于机身密封严实，排线分布较为复杂，拆解难度较大。

值得一提的是，我们有幸拿到了一加6漫威版，与上一代旗舰一加5T的内部做工进行了横向对比，以推断出一加6在内外做工方面的进步之处以及改进空间。
