**1、Recuva**

![](../Images/06c88aa25c92ef212de4ae0d33164165.png)

  

**描述：**

**Recuva **位列数据恢复软件第一名，可能不会让大多数人感到惊讶。

现如今有很多免费的文件恢复软件，但是当涉及到硬盘和照片恢复时，它们中很少比得上 **Recuva**。

**优点：**  

*   高级文件恢复
    
*   能够从硬盘驱动器、DVD 或 CD、存储卡和外部驱动器恢复文件
    
*   返回丢失的目录结构以及在执行数据恢复时重命名两个同名文件  
    
*   高级深度扫描模式
    
*   工业和军事标准删除技术的安全覆盖
    
*   从损坏或新格式化的文件中恢复文件
    
*   简化用户界面
    
*   在最终恢复之前预览屏幕
    
*   免费/廉价数据恢复软件
    
*   在 FAT 和 NTFS 系统上都可以工作
    

**支持平台：**

Windows 10、8、8.1、7、Vista、XP 和旧版本的 Windows

**2、TestDisk**

![](../Images/c21d2284b9623e55a5920e2703f16ef1.png)

  

**描述：**

TestDisk 的功能和文件恢复系统可以轻松地超越任何其他数据恢复软件的功能，它为新手和专家提供了很多便利。

**优点：**

*   允许用户恢复/重建引导扇区
    
*   是一个开源软件，目的是恢复丢失的分区并修复非引导磁盘  
    
*   除了能够可靠地从 FAT、exFAT、NTFS 和 ext 2文件系统中删除文件之外，还可以修复或恢复已删除的分区表
    
*   可以在所有主要平台上使用，如 Microsoft Windows、MacOSX 等，事实上，它在各种 LinuxLiveCD 上都很受欢迎
    

**缺点：**

*   这个免费的数据恢复程序试图检测分区和文件条目本身，因此对已删除/损坏的分区进行更深入的扫描需要更多的时间。
    

**支持平台：**

Windows 10、8、8.1、7、Vista、XP以及 Windows、Linux、BSD、MacOS 和 DOS 的旧版本。

**3、Stellar Data Recovery**

![](../Images/d5e4a4a83e2a6bee79b5ae21a5482f3a.png)

  

**描述：**

**Stellar Data Recovery **以其名称为名，在从 Windows PC 和 Mac 中恢复数据方面发挥了出色的作用。如果你后悔你决定删除最近的文件，**Stellar Data Recovery **帮助你以有效的方式恢复。

**优点：**

*   无风险程序从不同类型的存储设备中恢复数据，如存储卡、智能手机、USB 驱动器、硬盘等
    
*   使用 **Stellar Data Recovery **很简单。只要下载它，启动扫描，您就能够从过去的数据灾难中恢复过来
    
*   充满了先进的功能和快速的驱动器文件恢复。
    
*   适用于初学者和非技术用户
    
*   在进行最后的恢复尝试之前，在应用程序中预览可用的文件；也称为“购买前尝试”功能
    

**支持平台：**

Windows 10、8、8.1、7、Vista、XP 和 MacOS。

**4、Undelete 360**

![](../Images/b24ba2ec2c2db4deb2cd4d6fd339dc42.png)

  

**描述：**  

**Undelete 360 **使用典型 Microsoft Office 应用程序的外观（由于带状样式工具栏和蓝色主题），是建立在一个快速而有效的算法之上，它使用户能够取消删除的文件。

**优点：**

*   工作在各种设备，如数码相机，存储卡，智能手机，计算机硬盘驱动器，USB等
    
*   它包括一个数据擦除工具，一个十六进制查看器，以及在恢复之前预览文件的能力
    
*   可以恢复各种类型的文件，如 DOC、HTML、AVI、MP3、JPEG、JPG、PNG、GIF 等
    

**缺点：**

*   扫描速度需要重大改进，而且该工具在恢复数据方面也落后于其竞争对手。
    

**支持平台：**

Windows 8，8.1，7，Vista，XP 和旧版本的 Windows。

**5、PhotoRec**

![](../Images/ce2002fa19a903b2fbd0ff78f36baa07.png)

  

**描述：**

**PhotoRec **绝对是最好的数据恢复软件之一，**PhotoRec **它以其强大的文件恢复功能而广受好评，涉及从数码相机到硬盘等多种设备。

它是专门从硬盘，光盘恢复数据，如图片，视频，文档等。

**优点：**

*   几乎兼容所有的主要平台，如微软 Windows，Linux，MacOSX 等
    
*   可以恢复超过440种不同的文件格式
    
*   支持很多文件系统，包括 FAT、NTFS、exFAT、ext 2/ext 3/ext 4和 HFS+
    

**支持平台**：

Windows 10、8、8.1、7、Vista、XP 和 Windows、Linux、BSD、DOS、MacOS 的旧版本。

**6、Pandora Recovery**

![](../Images/fec58e27545a4c663a9a4d3f110a5c7f.png)

  

**描述：**

**Pandora Recovery **是最可靠和最有效的免费数据恢复软件之一。**Pandora Recovery **恢复工可以提供给它的用户很多功能。

**优点**：

*   从 ntfs 和胖格式化卷中恢复已删除的文件
    
*   预览某些类型的已删除文件（图像和文本文件）而不执行恢复
    
*   通过表面扫描（允许您从格式化的驱动器中恢复数据）和恢复存档、隐藏、加密和压缩文件的能力，它带来了相当大的打击
    
*   界面非常简洁，并提供一个类似浏览器的视图，以及颜色编码和恢复百分比指示器
    

**缺点**：

*   文件检测系统并不那么可靠，需要进一步改进。
    

**支持平台**：

Windows 8、8.1、7、Vista、XP 和 Windows 的旧版本上。

**7、MiniTool Partition Recovery**

![](../Images/2e6e8b72d42dc1f9029bc59b88045a89.png)

  

**描述：**

标准的取消删除程序（如Recuva、Pandora等）非常适合恢复一些已删除的文件，但如果丢失了整个分区怎么办？那么您可能需要一个专家应用程序，例如**MiniTool Partition Recovery**。

**优点**：

*   一个简单的基于向导的界面
    
*   专门处理整个分区上的数据恢复  
    
*   当 **MiniTool Partition Recovery **指向有问题的驱动器，它将扫描丢失的分区生成一个恢复报告，该报告将使您了解该程序在数据恢复方面发现了哪些内容。
    

**缺点**：

*   无法在可引导磁盘上使用数据恢复
    

**支持平台**：

Windows 10、8、8.1、7、Vista、XP 和旧版本的 Windows。

**8、Wise Data Recovery**

![](../Images/728df21105de25a529c51fc272a5c94a.png)

  

**描述：**

**Wise Data Recovery **是最好的数据恢复软件中最快取消删除工具之一。除了速度更快，它还带有一些不错的功能。

**优点：**

*   简单直观的界面
    
*   从本地驱动器、USB驱动器、照相机、存储卡、可移动媒体设备等中恢复已删除的文件
    
*   通过使用文件类型选择内置文件扩展名组来加快搜索筛选
    
*   可以在恢复过程中快速执行文件扫描，但是深度扫描模式的可用性会更好
    
*   有一个便携式数据恢复软件版本
    

**支持平台：**

Windows 10、8、8.1、7、Vista、XP 和旧版本的 Windows。

**9、Puran file Recovery**

![](../Images/73af3435f8d19121af3827576cbc72db.png)

  

**描述：**

**Puran file Recovery **工作在三个主要恢复模式。这些恢复模式是：

*   默认的快速扫描（它只是读取FAT或NTFS文件系统中删除的文件从回收站等）
    
*   深度扫描（包括扫描所有可用的空闲空间）
    
*   全扫描（检查设备上的所有空间，以获得最佳恢复机会）
    

**优点：**

*   使用“查找丢失文件”选项将 Puran 文件恢复转换为从丢失或损坏的分区恢复所有文件的工具。
    
*   编辑自定义扫描列表，它存储文件签名，以便更准确地恢复严重损坏的数据。
    

**支持平台：**

Windows 10、8、8.1、7、Vista、XP 和旧版本的 Windows。

**10、PC Inspector File recovery**

![](../Images/77075ec47006eb92c15c82d45f10f88e.png)

  

**描述：**

**PC Inspector File recovery **即使引导扇区已被擦除或损坏，FAT 和 NTFS 驱动器也能很好地工作。

**优点**：

*   简单搜索对话框可以帮助定位文件的名称
    
*   可以将恢复的文件还原到本地硬盘或网络驱动器
    
*   可以不同格式恢复几种文件的图像和视频，如 ARJ、AVI、BMP、DOC、DXF 等
    
*   可以使用群集扫描仪只扫描光盘的特定区域
    

**缺点：**

*   此软件的界面和标签有点混乱。（小心使用这个工具）
    

**支持平台：**

Windows 10、8、8.1、7、Vista、XP 和旧版本的 Windows。

**11、Restoration**

![](../Images/3017c11bbcef2c800aae23438e962c2f.png)

**描述：**

误删恢复软件 Restoration 是时下互联网常用的软件之一，这款免费的小程序不需要安装，解压后即可使用。它的主要用途是恢复被误删除到回收站的重要文件，实际上，它也可以恢复那些被 Shift+Del 彻底删除的文件。

**优点**：

*   非常简单易用
    
*   没有令人迷惑的工具，也没有任何复杂的文件恢复过程
    
*   还可以从硬盘、存储卡、USB 驱动器和其他外部驱动器中恢复数据和文件
    
*   不需要安装并且可以从 USB 驱动器运行数据恢复
    

**支持平台**：

Windows Vista，XP，2000，NT，ME，98和95，并且成功地测试了 Windows 7 和 Windows 10。有时，Windows 8 会遇到问题

**12、DMDE**

![](../Images/bbcc2812f42bbe09ffb23d9aa9385732.png)

  

**描述：**

**DMDE **是最富功能的数据恢复软件之一。但是，各种选项的无休止列表实际上使恢复过程复杂化。

**优点**：  

*   便携  
    
*   支持深度扫描  
    
*   可以保存日志以避免在后期重新扫描  
    
*   要从其中恢复数据的设备的详细信息  
    
*   不显示原始文件夹名，但显示原始文件名  
    
*   文件搜索选项可用
    
*   多个过滤器可用
    
*   复制扇区选项以创建磁盘映像文件  
    
*   构造 RAID 的工具
    

**13、Glary Undelete**

![](../Images/54993982fab3c202762d6b11e07cde6f.png)

  

**描述：**

文件恢复软件为新手用户提供了一个干净而方便的界面。**Glary Undelete **没有多少视觉吸引力，但它可以是一个很好的解决方案，可以恢复您已删除的文件。

**优点**：

*   快速文件扫描与文件夹和文件类型视图选项
    
*   多个筛选器选项包括日期、时间、文件类型、文件大小等  
    
*   预览选项可用  
    
*   多种语言选项  
    
*   支持各种 Windows 版本，包括 Windows 10  
    
*   在扫描结果中显示恢复状态-好、差、覆盖等
    
*   不显示原始文件夹名
    
*   尝试从供应商安装配套软件
    

**14、Disk Drill**

![](../Images/f8c20d2af7e9253ababddacce36ed98f.png)

  

**描述：**

说真的，如果你在寻找一个看起来也不错的数据恢复软件，那么 **Disk Drill **就是你的选择。但是你必须通过下载一个15 MB 的安装文件来支持视觉效果。

**优点：**

*   显示机器上的所有存储空间，甚至未分配的空间
    
*   显示所有文件、图片、视频、文档、档案选项中的扫描数据
    
*   允许按文件和日期过滤扫描文件
    
*   包括搜索栏。可以保存恢复会话供以后使用
    
*   可以磁盘映像（ISO）的形式恢复数据
    
*   预览选项可用
    
*   深度扫描模式可用
    
*   保留原始文件夹名
    
*   安装后需要重新启动
    
*   扫描时间超过平均水平
    

**缺点：**

*   在免费版本中只能恢复 500 MB 的空间
    

**15、SoftPerfect File Recovery**

![](../Images/16519dc314596496106f607ee6c9124e.png)

**描述：**

恢复从硬盘软盘和其它可存储媒体误删除的文件的工具，对于那些不想安装软件麻烦的用户来说，这个数据恢复软件是非常理想的。这是一个极小的解决方案，提供了极简的界面。通用的文件系统FAT12、FAT16、FAT32、NTFS 以及压缩和加密的 NTFS5。

**优点**：

*   设置大小仅为 0.5MB
    
*   容易使用
    
*   无法恢复损坏或覆盖的文件
    
*   预览不可用
    
*   有多种语言
    
*   不显示要恢复的文件的状况
    

**缺点：**

*   不显示要恢复的文件的状况
    
*   不允许在同一磁盘上恢复已恢复的文件。最好用闪存盘运行
