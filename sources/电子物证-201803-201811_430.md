# 【教程】iPhone免越狱提权取证

前言       iphone“免越狱提权取证”功能至发布以来受到了大量关注和用户的一致好评。为了让大家能够更加熟练的使用该功能，小编今天给大家介绍一下该功能的具体使用方法，希望对大家的日常取证工作有所帮助。

**支持范围：**

服务机型为iOS 10.0-11.1.2版本64位未越狱且备份加密的iPhone手机。

**注意：**iPhone5/5C  IOS 10.3.3版本也可以支持“免越狱提权取证”。

  

**风险提示：**

**1）iPhone提权取证有小概率出现手机损坏现象（白苹果），请注意！！！**

**2）操作过程中手机需要联网，可能导致数据被远程擦除，必须严格按照提示操作手机。**

  

**检材信息：**

Iphone5C  IOS 10.3.3  未越狱并且设置了备份密码。

  

**准备工作：**

1、将取证软件升级到最新版本，手机平台支持的版本升级到V2.4.07501

2、下载好iPhone授权文件工具，在该工具中在线下载iPhone提权客户端。

（关注“美亚柏科服务之星”微信公众号，输入“苹果提权”即可获得下载链接，并且该工具会在后续版本的手机大师安装目录下的 “Mobile Support\\BaseTool\\iPhone\\iPA”中找到）。

具体操作如下：1双击运行“iphone授权文件工具”，软件提示下载成功。

![](../Images/4aa8e3e0246e6d42ea7b5ce5ba2bce26.png)

2将iphone手机接在取证电脑上面，识别到手机后点击开始取证，软件界面会跳出是否提权提取的提示，点击是。

![](../Images/abf1cc2c8e0eb58bd47d3af265ea8ab6.png)

3选择提取提取后，取证软件界面会跳出如下提示的界面，严格按照提示界面的内容操作。

![](../Images/2edfad44082b40c37135f1ebf47e210f.png)

**1）禁止手机上安装的应用程序联网，这里以禁用360手机卫士应用程序联网为例（防止一些应用程序联网更新数据）。**

![](../Images/50c0dbbaa267b8e0bea9b3fa87a5d608.png)

**2）开启手机的无线连接或者蜂窝网络。**

![](../Images/f4bca85a879eac93cd4558d242f6dbbc.png)

**3）信任企业应用。**

![](../Images/e84d77678cfaed40992c5483c8b4344d.png)

**4）手机屏幕设置常亮。**

![](../Images/76b55440c40c7c84d739b5eca024f290.png)

**5）运行手机上面的MFSocket程序。**

![](../Images/28f15dc32a6d55b25015bd53ed9e157b.png)

**注意：在手机上面点击mfsocket程序后，手机的屏幕出现白屏界面后，即可点击手机取证软件界面的确定按钮。软件界面点完确定后，手机界面会显示connect success!**

4接下来就正常提取一样，等待取证完成，提取完后即可浏览相应的数据。

![](../Images/359e0137e8b0f42c8a9cb31d47d48d30.png)

  

**提醒：提权取证完后，如需再次提取，请重启手机！！！**
