在工作或者自己练习的时候我们难免会大意忘掉自己的root密码，有些同学忘掉密码竟然第一选择是重装系统，工作中可万万使不得！本篇博客将讲解两种最常用的破解centos7忘掉密码的解决方案。 

## 第一种方法：设置光盘为第一启动项

**第一步**：进入bios界面

虚拟机中：点击左上角的虚拟机--》电源--》打开电源时进入固件 ![](../Images/a30d46517d80fc644ee23e839fa95d2f.png)

**第二步**：使用左右键选择上方的boot

按住shift+ 加号，让cd-rom第一启动项

然后按一下F10保存即可，回车即可

![](../Images/a9e03e32a93c07b7daea9c74f9426dfb.png)

![](../Images/05e2259e38010c9d0135f629a779d19b.png)**第三步**：选择troub..按回车

然后选择救援模式回车 ![](../Images/541ce86fe439faaf820dd705e3eeac8c.png)

![](../Images/0e5af7f0c9926000ec9726ea32586ba8.png)**第四步**：选择continue 即输入1

千万不要选3 ![](../Images/35dbc367ea80512a70b545d04d8e8cd1.png)

**第五步**：可以发现救援模式中有所有系统文件  

如果以后自己误删了系统文件可以在这里进行复制

自己真正的根在/mnt/sysimage下

![](../Images/8a4f7be9fd32af3467a9f0fbbe97bbc9.png)

**第六步**：切换至自己真正的根中  

第一：切换至自己的根下

```
chroot  /mnt/sysimage
```

第二：使用passwd修改密码

输入两次需要修改的密码，输入密码不可见

```
passwd root
```

第三：修改完成之后退出自己的根

```
exit
```

第四：重启

```
reboot 
```

![](../Images/6f18c9124ace05ea8a1b3f6033883445.png)

补充：如果在自己的根下进行重启会报错

 ![](../Images/3b137867fa728442bc64d473d20c15c5.png)

 第二种方法：救援模式（推荐方法）

**第一步**：启动系统

到这里之后，点击一下屏幕，输入e

![](../Images/0a2f4f936003b2a0bbd7747ea26d7761.png)

**第二步**：输入rd.break

在linux16开头的行的结尾输入rd.break

![](../Images/af7fec1a1d74cf4f75a800cbb3a56756.png)

**第三步**：ctrl+x  

输入ctrl+x运行

进入到如下的界面

![](../Images/27a6b8672b89f9144556b75991f60d25.png)

**第四步**：重新挂载根  

现在的根为只读状态，需要挂载为读写状态以便进行修改

输入红框内的内容

![](../Images/a5f05f16ef9ffb31fdfae9fa7dab2cb7.png)

**第五步**：切换根  

进入到sh，即为你真正的系统

![](../Images/a5ec94403bd0dd2dc2e219f7dd2208dc.png)

**第六步**：修改密码  

需要输入两次密码进行确认

结尾看到successfully即为修改成功

![](../Images/6d24b78a34a727e71a4cb400308445bc.png)

**第七步**：退出并重启  

![](../Images/fbb3ecee846b1b4c5dd2ec757f4b58bf.png)

**第八步**：进入系统  

可以发现我们使用修改后的密码成功进入系统

工作中推荐使用此种方法
