这篇文章的重点是介绍屏幕锁定（Keyguard）以及如何对哈希进行密码猜测。

为什么要破解密码？

破解密码可以获得设备的根级访问权限，也可以滥用开放会话（例如Facebook，Google Play或Twitter等应用程序）。

方便获取密码：

1.我们可以在本地机器上的备份文件中找到哈希值。

2.密码重用：大多数人会对他们的所有设备使用相同的PIN（甚至其他重要的东西，比如银行卡）。

3.如果密码用作Android分区加密（如果已启用）的密钥，就允许我们对其进行潜在解密。

4.Android密钥库使用主密钥（其KEK）加密，同时该密钥又基于屏幕锁定密码。

它是如何存储的？

首先，Android pre 4.2之间有一些变化，Android 4.4之后可能会有发生变化。如果设备上有多个用户，则密码的存储方式会不同。此外，文中提到的“密码”包含了PIN -这是以完全相同的方式存储的。密码存储在文件/data/system/password.key中，以哈希的十六进制为表现形式，示例如下：

1136656D5C6718C1DEFC71B431B2CB5652A8AD550E20BDCF52B00002C8DF35C963B71298

熟悉哈希长度的也可能会很困惑。该字符串长度有72个字符，这是一串特殊的数字，对大多数哈希函数都无效。不过仔细看你会发现，它实际上是两个哈希数列，一个SHA1和一个MD5连接在一起。

我们将上面的哈希分成：

SHA1：

1136656D5C6718C1DEFC71B431B2CB5652A8AD55

MD5：

0E20BDCF52B00002C8DF35C963B71298

光知道这两个还不够，你还需要salt，你可以在SQLite数据库中找到; 位置取决于您运行的Android版本：

无论你使用哪个版本;，salt都可以在locksettings表中找到，使用以下SQL：

select value from locksettings where name=’lockscreen.password_salt’

这将返回64位（或长整数），例如：

3582477098377895419

如果我们想使用这个数列，我们首先需要将其转换为十六进制，然后将其小写。在这里就可以使用Windows系统来执行此操作，然后手动转换字符（或使用类似Notepad ++），我们可以得到：

31B783F0B0C95DFB

转换成小写：

31b783f0b0c95dfb

我们开始破解它

使用Hashcat，但是Hashcat不支持Android哈希库。它有5800(三星Android密码/PIN)，这是三星特有的变体，还有8800(安卓FDE <= 4.3)，用于破解安卓磁盘加密。

但是，由于Android使用的是标准算法，我们只能使用hashcat的标准算法之一。我们可以查看AOSP源代码，了解算法是如何编码的(在/core/java/ com/android/internal/widget/lockpatternutils.java):


byte [] saltedPassword =（password + getSalt（））。getBytes（）; byte [] sha1 = MessageDigest.getInstance（algo =“SHA-1”）。digest（saltedPassword）; byte [] md5 = MessageDigest.getInstance（algo =“MD5”）。digest（saltedPassword）; hashed =（toHex（sha1）+ toHex（md5））。getBytes（）;

因此，密码密钥文件可以看作：


password.key = SHA1（$ pass。$ salt）。MD5（$ pass。$ salt）

如果我们查看Hashcat的哈希类型列表，我们可以看到这个表。这是在电脑上加入了GeForce GT 740M的基准测试来作为速度比较的依据：

特别说明

Android Jelly Bean增加了对多个用户的支持。每个用户都有单独的应用程序和数据存储，其中包括密钥保护密码。User 0是特殊用户，是设备所有者。

我们仍然可以使用上述技术破解具有多个用户的设备上的所有散列密码。

用户由用户编号标识，0为设备所有者，然后为每个新用户递增10（即0,10,20），此信息存储在/data/system/users/user.xml中。对于多个用户，password.key将以/ data / system / users / number存储在具有用户编号的目录中。

我们还必须修改locksettings数据库的查询：

select value from locksettings where name=’lockscreen.password_salt’ and user=number
