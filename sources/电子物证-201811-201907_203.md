# 【检察官背后的“技术达人”】“取证能手”叶程都

“程都，下午的视频会议需要做好连线准备。”“程都，业务系统上不去了，来帮我看一看。”“程都，市检察院有一个案子需要技术协助。”……从一天上班开始，鹿城区检察院检务保障部干警叶程都的电话就一直“铃铃铃”响个不停。

可以说，他是整个院里被大家“@”频率最高的那个人。

叶程都大学时学的是信号与信息处理专业，因为在计算机方面过硬的本领，检察院里的同事亲切地称呼他“技术达人”，可他却说自己只是服务大家的“后勤兵”。从进入检察院开始，几乎每天都能看到他在楼道里奔波的身影——网络管理、硬件维修、同步录音录像、电子证据检验鉴定、技术协助等等。虽然不负责办案，但他有时却比办案人还忙，不仅办案部门的人找他，综合部门的人也找他。事情琐碎也很繁杂，但热心的他却乐在其中：“只要能帮大家解决问题，我就高兴。”

基层检察院的办案压力比较大，即使身为综合部门的叶程都也是深有体会。近几年，他时常在思考，“能否把信息技术和检察业务进行融合，在技术手段上为大家减轻压力，提升效率呢？”想法一提出，便得到院领导和同事的大力支持。

他与同事组建信息化团队，测试开发了检察技术协助应用平台。通过这个平台，需要技术部门协助的司法鉴定、电脑维修等事项都可以在线申请，免去了以往填表、审批、找人等繁琐过程。“我们经常不在办公室。如果一时半会找不到我们，那他们的问题就没办法及时解决。”小小的创新为检察工作提高了效率，这一应用也在100多个团队中脱颖而出，通过省检察院选拔，被推选到最高检，最终获得全国检察系统网上轻应用开发活动二等奖。

检察院内不少工作都离不开技术工作，面对这方面的疑难杂症，同事们第一个想到的就是叶程都。在办理一起强奸案中，由于证据不足，涉案双方口供矛盾，案件办理陷入瓶颈。关键时刻，叶程都和技术部门的同事通过技术手段恢复、提取了涉案手机中上万条信息，并在其中找到了案件突破的关键性证据，为案件的成功办理提供了强大的技术支撑。

为了协助办案，叶程都常常和检察官们一起加班加点。“他不是在进行技术分析，就是在去技术分析的路上。”如今，同事们也常常这样打趣他。他俨然是同事们心中不折不扣的“取证能手”和“数据达人”。

![](../Images/9ff48672ec456dff70004d9ebeafa24a.png)

通过探索，叶程都找到了技术工作和检察工作的契合点，也因此获得了2014年全省检察机关电子数据取证业务标兵并多次获得三等功。“我只是在做着平凡岗位上的平凡事儿。”这是叶程都常常放在嘴边的一句话，虽然日复一日重复着这些看似琐碎、无聊的工作，但在他看来，即使是平凡的岗位也能出彩，站好每一班岗都是伟大。
