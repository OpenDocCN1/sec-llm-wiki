1     Recuva

Recuva可以说是目前市面上最好的免费数据恢复软件工具。它非常易于使用，但也有许多可选的高级功能。

Recuva可以从硬盘驱动器，外部驱动器（USB驱动器等），BD/DVD/CD光盘和存储卡中恢复文件。Recuva甚至可以恢复iPad中的文件！

Recuva使用简单，恢复已删除文件就像删除一个文件一样简单！

支持 FAT12，FAT16，FAT32，NTFS 文件系统。

2      Puran File Recovery

Puran File Recovery是一款免费的文件恢复软件，使用这款文件恢复软件免费版可以对误删除的文件或者数据进行恢复，恢复的过程很简单，选择源文件存放的分区点击“SCAN”，待扫描完成后，选择要恢复的文件，点击“RECOVER”选择路径即可。没有完全被覆盖的情况下，Puran File Recovery可以恢复丢失的分区。

Puran File Recovery适用于Windows 10、8、7、Vista和XP。对于32位和64位版本的Windows，它也以便携式形式提供，因此不需要安装。

3      Disk Drill


Disk Drill 可以从所有存储设备中扫描并恢复数据，包括大多数内置硬盘、外置硬盘、U 盘、相机、iPod、Kindle 及内存卡。即使失败、不可读或者分区丢失，它通常也能扫描你的设备。

Disk Drill 组合了多个强大的扫描算法，提供了完整的 Mac 数据恢复解决方案。

Disk Drill 使得在 Mac 上进行数据恢复变得极为简单。只需点击按钮，即能完成扫描模式并显示可恢复的文件列表。找到的文件可以预览，这样你就能知道哪些文件可进行文件恢复。

Disk Drill网站表示，它可以从"几乎任何存储设备"恢复数据（最多500 MB），例如内部和外部硬盘驱动器、USB设备、存储卡和iPad。

Disk Drill还可以在恢复之前预览图像文件，暂停扫描并稍后恢复它们，执行分区恢复，备份整个驱动器，按日期或大小过滤文件，运行快速扫描而不是完整扫描以获得更快的结果，并保存扫描结果，以便您以后可以轻松地再次导入它们以恢复已删除的文件。

Disk Drill适用于Windows 10、8、7、Vista和XP以及macOS。

4     Glary Undelete


Glary Undelete是一个免费易用、功能强大的数据恢复软件，支持FAT和NTFS文件系统。可以恢复删除到回收站的文件，从DOS窗口删除的文件，还可以恢复在资源管理器中按Shift键彻底删除的文件。

Glary Undelete支持对各种数据载体中删除文件进行恢复，对文件类型没有太大限制，各种原因导致的文件丢失都可以通过它来进行修复。使用起来非常简单，电脑新手同样可以轻松入手，过滤功能你可以筛选出你指定文件名、大小、日期可完整恢复的健康文件。

Glary Undelete的最大优势包括简单的"文件夹"视图，可恢复文件的资源管理器风格视图以及每个文件的突出"状态"指示，表明成功恢复文件的可能性。

Glary Undelete的一个缺点是在使用之前需要安装。另一个是你被要求安装一个工具栏，当然，如果你不想要它，你可以拒绝。除了这些，Glary Undelete是一流的。

Glary Undelete可以从硬盘驱动器和任何可移动介质中恢复文件，包括存储卡，USB驱动器等。

5     SoftPerfect File Recovery


SoftPerfect File Recovery是另一个极好的文件恢复程序。搜索可恢复文件非常容易。任何人都应该能够轻松使用这个程序。

SoftPerfect File Recovery将恢复硬盘驱动器，存储卡等文件。支持PC上存储数据的任何设备（CD/DVD驱动器除外）。

SoftPerfect File Recovery是一个500 KB的小型独立文件，使程序非常便携。随意从USB驱动器或软盘运行文件恢复。

Windows 8、7、Vista、XP、Server 2008和2003、2000、NT、ME、98和95都受支持。此外它还支持64位版本的Windows操作系统。

支持目前通用的文件系统FAT12, FAT16, FAT32, NTFS 以及压缩和加密的NTFS5。

6     EaseUS Data Recovery Wizard


EaseUS Data Recovery Wizard是一款功能强大并且性价比非常高的数据恢复软件，具有删除恢复、格式化恢复、高级恢复等非常强大的功能，可以针对不同情况的数据丢失来进行数据恢复，能非常有效的恢复被删除、格式化的文件以及分区异常导致丢失的文件。

EaseUS Data Recovery Wizard的是用户界面的结构与Windows资源管理器非常相似。虽然这可能不是每个人显示文件的理想方式，但它是一个非常熟悉的界面，大多数人都很满意。

EaseUS Data Recovery Wizard可以恢复硬盘驱动器，光盘驱动器，存储卡，iOS设备以及Windows视为存储设备的任何其他文件。它还可以进行分区恢复！

请注意，数据恢复向导只会在您需要升级之前恢复总共500 MB的数据（如果您使用程序中的共享按钮在Facebook，Twitter或Google+上发布有关该软件的信息，则最多可恢复2 GB）。

EaseUS Data Recovery Wizard支持Mac和Windows 10/8/7/Vista和XP，以及Windows Server 2012/2008和2003。

7     Wise Data Recovery


Wise Data Recovery 是一个智能的文件数据恢复软件。该软件由Wise公司开发，非常好用的一款硬盘删除数据恢复工具，它可用来扫描磁盘分区上的文件碎片，并将其恢复为完整的文件。重点是无论图像、文档、音频、视频、压缩文件或电子邮件，它都可以快速、安全地搜索和恢复。只要你指定的驱动器，文件类型或文件名，它都能帮你解决文件恢复的问题。


Wise Data Recovery 的独特之处在于，数据恢复完成了将显示为“良好”，“差”，“极差”，或“迷失”在扫描结果中的数据表明恢复的困难度。

支持笼统过滤（如图片，视频，还是文档），也支持对扫描结果进行精确的过滤，（如指定文件类型为*.png 通过通配符输入文件名等等）

对扫描出的文件进行标识（良好，很差，无法恢复），可以很容易判断哪些文件可以完全恢复，哪些不能。

支持从NTFS还是FAT格式的硬盘，U盘，移动硬盘恢复被删除数据。

对误删文件，清空回收站，shift+delete删除的文件有良好的恢复功能。（不支持分区，格式化及raw恢复）

Wise Data Recovery适用于Windows 10/8/7/Vista和XP。还有一个便携版本。
