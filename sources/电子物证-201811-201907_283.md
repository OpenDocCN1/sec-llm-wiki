# 【1400万元现金大劫案，警方苦追7年... ...】

2012年3月5日晚，广深高速广氮路段发生一起震惊全国的1400万现金抢劫案。专案组克服重重困难，在公安部、广东省公安厅、广州市公安局三级相关部门协助下，只用36个小时便抓获大部分嫌疑人，缴获过千万现金赃款。该案主犯朱某却在案发后隐姓埋名，辗转躲藏于湘贵云川等地，在逃时间长达近7年之久。虽已时过境迁，专案组也历经多次调整，但却始终没有停止对朱某的追缉侦查，多次派出民警前往嫌疑人家乡及有可能活动的地区进行调查。

功夫不负有心人，2019年1月23日，根据前期线索积累，广州市公安局公交分局联合四川自贡警方在自贡市荣县将朱某抓获归案！1月26日，朱某被押解回穗。至此，这起特大抢劫案的17名犯罪嫌疑人全数落网。

# **高速路上突发劫案，1400万被劫走**

2012年3月5日，司机吴某驾驶一辆小汽车搭乘事主杨某和郑某两人，从广州出发前往深圳。22时45分许，当其驾车驶过北环广氮收费站后600米，处于进入广深高速的匝道上时，突然被前面一辆无牌白色面包车和一辆银色小汽车拦截，多名嫌疑人手持枪状物、短刀、斧头等器械，迅速劫走事主放在车内后排的钱款，折合人民币近1400万元。

# **两天之内极速破案，神台暗格寻获赃款**

由于案件性质恶劣，案值数额特别巨大，引起了广东省公安厅、广州市公安局领导的高度重视，要求组织力量尽快破案。广州市公安局便衣侦查支队、刑警支队立即组成联合专案组，开展调查处置工作。

侦查人员判断，此案一定是对事主生意运作情况相当熟悉的“内鬼”勾结纠合其他人员组成抢劫团伙，并且充分预谋、策划实施的。专案组确定了侦查方向，采取了一系列侦查工作措施，包括对知情群众等进行走访摸查，调取监控录像资料，查找作案工具面包车、小汽车特征及逃跑路线。

经过夜以继日的广泛调查取证和深入摸查，专案组迅速锁定了一个以广东惠来籍嫌疑人为主的作案团伙。3月6日下午，专案组派出精干警力，赶赴揭阳市惠来县追缉该案主犯，同时派出多个缉捕小组，在广州、佛山两市展开布控抓捕工作。

![](../Images/64534bc5956b96899791b2035d7bc3f9.png)

3月7日13时许，专案组在揭阳市惠来警方的配合下，抓获了方某、许某两名广东惠来籍犯罪嫌疑人。随后在方某住所神台下、一块200多斤重的石板压住的暗格里，缴获赃款折合人民币900多万元。与此同时，广州、佛山两地警方同时出击，先后在广州市海珠区抓获犯罪嫌疑人黄某，在黄某经营的档口缴获赃款折合人民币200多万元；在佛山市张槎街抓获魏某（河南籍人）、杨某（重庆籍人）两名犯罪嫌疑人，分别在魏某办公室的杂物中和杨某汽车后备箱暗格内缴获赃款折合人民币200多万元，缴获作案车辆2辆；在广州市白云区某医院门口继续抓获许某等2名犯罪嫌疑人，缴获作案车辆1辆。广州警方在案发两日内，就成功侦破了这起发生在广深高速公路的惊天大劫案。

# **眼红亲戚，借钱不成萌生歹意**

经审讯查明，犯罪嫌疑人方某、许某、黄某、朱某是该团伙主犯，其中许某与事主杨某是堂兄弟。许某平时不务正业，游手好闲，眼红堂兄杨某的生意做得红红火火，于是找杨某借钱，杨某没有答应。许某怀恨在心，与结拜的“兄弟”方某、黄某密谋抢劫杨某。作案前，黄某找到密友---在佛山市经营小型制衣厂的魏某、杨某等人商量。杨某找来了佛山当地“混混”头目朱某，自诩“为人仗义”的朱某立即答应“办事”。3月5日晚，在朱某的指挥下，“马仔”们分头行事，一部分驾车尾随事主，另一部分负责拦截、劫持事主，还有人驾车配合掩护，最后劫走事主钱财。

![](../Images/5debb95ff47da1d1c060ec17e18064bf.png)

# **辗转多地追逃，戈壁小镇擒回在逃嫌疑人**

作案后，犯罪嫌疑人方某、许某将部分赃款分给黄某、魏某、杨某、朱某等人，自己携带大部分赃款逃往惠来，其他涉案嫌疑人作鸟兽散。为了尽早将犯罪嫌疑人绳之以法，专案组辗转广西、四川、重庆、湖南、甘肃等多地，开展艰苦的追逃工作，时间跨度长达两年之久。先后抓获8名涉案嫌疑人，其中一名嫌疑人甚至逃到了人迹罕至的甘肃瓜州，藏匿在荒凉的戈壁小镇，一样被警方缉拿归案。

2014年9月18日，广州市中级人民法院一审认定，许某是本案犯意的提起者，与黄某策划犯罪，跟踪掠取钱款；黄某密谋纠合他人进行抢劫，负责调控指挥，决定赃款分配，两人均起最主要作用，决定判处无期徒刑。另外14名涉案犯罪嫌疑人已经到案并作出判决。但是，作为组织策划犯罪的主犯朱某却一直潜逃在外。

# **追逃七年，最后一名在逃嫌疑人终归案**

在案发后将近七年的时间里，便衣侦查支队进行改制重组，与地铁分局合并组建成立为公交分局，部分办案人员也陆续离开了原来的岗位，但当年参战成员无论是领导还是民警，对朱某都依旧“念念不忘”。专案组成员、现任公交分局侦查三大队副大队长李剑和他的同事们，在完成日常工作的同时，不放过关于朱某的任何一条线索，每当收到关于他的消息都会高度重视，重点进行研判分析，希望把最后一块“拼图”找到，把案件圆满办结。

自2018年春季以来，关于朱某的举报线索逐渐增多，办案民警意识到，其极有可能认为风声已过，放松了警惕，逐渐恢复正常生活。机不可失，时不再来，办案民警随即赶赴四川成都、自贡等地，根据线索来源展开调查，同时将线索通报公安部和四川警方，促成川粤两省警方合成作战，通过信息收集研判，摸查走访蹲守，逐步确定了朱某的落脚点以及活动规律等信息。

2019年1月23日中午，办案民警掌握到，朱某有可能外出喝茶，民警迅速对线索作进一步核实，部署抓捕行动。当日18时许，警方在自贡市荣县一家茶馆将朱某抓获归案。1月26日20时，广州公交民警历经千里跋涉，将朱某押解回穗。朱某对参与组织策划2012年广深高速公路特大抢劫案的行为供认不讳，目前已被警方依法刑事拘留。
