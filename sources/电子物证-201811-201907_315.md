#### 电子文档

> 如何清除doc,xls,xlsx密码？如何在不知道密码的情况下打开doc.xls,xlsx密码？doc.xls,xlsx密码破解…密码要是能清除要加密还有何用，现在目前行之有效的办法就是暴力破解，通俗点解释就是一个一个尝试密码知道尝试出正确的密码,下面使用python演示爆破xls密码：

```
`我们这里用到 python3``python3的pypiwin32库``pip install pypiwin32``win32com主要使用com操作excel还有word，ppt等文件``初步需求->创建一个加密的xls``python脚本，打开一个加密的xls,输入密码读取第一行内容.``我这里已经创建了一个xls文件并在里面输入了hello xls,并加密为123456`

```

```
`import win32com.client``def openxls(path,password):``try:``xlsx = win32com.client.Dispatch("Excel.Application")``xlwb = xlsx.Workbooks.Open(path, False, True, None, Password=password)``print(xlwb.Sheets(1).Cells(1,1))``except Exception as e:``print("[%s]" % password, repr(e))`` ``if __name__ == '__main__':``file = r"C:\Users\Myself\Desktop\xlsfuzz\aa.xls"``password = '123456'``openxls(file,password)`

```

> 代码意思是定义导入win32com.client库，定义一个函数打开xls文档，输入密码。如果错误打印错误信息，如果程序没报错打印内容

```
`import win32com.client``def fuzz(path,password):``try:``xlsx = win32com.client.Dispatch("Excel.Application")``xlwb = xlsx.Workbooks.Open(path, False, True, None, Password=password)``if xlwb:``print('[yes]:' + str(password))``except Exception as e:``print("[%s]" % password, repr(e))`` ``if __name__ == '__main__':``file = r"C:\Users\Myself\Desktop\xlsfuzz\sx.xls"``password = ['123456','111111']``for i in password:``fuzz(file,i)`
```
