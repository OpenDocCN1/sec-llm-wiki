# 【内容不同、MD5值却可以相同？】

**数据恢复**、**哈希校验**可以说是电子数据取证的理论基石。今天，小编带您领略一下，如何制造两个**内容不同**、却**具有相同MD5值**的电子文档。

看到标题，可能有的律师朋友会觉得很兴奋，但是请耐心读完。坦白讲，去否定、排除一个电子数据证据，或者制造无法排除的合理性怀疑，也不是容易的事情。

**准备工具**

1、寻找可制造相同MD5值的碰撞软件，小编贡献一个：fastcoll\_v1.0.0.5.exe（MD5：96D652FB4D6D24184F2E096A3EFD79A5）

下载地址:

https://pan.baidu.com/s/1HkFLwhqZjUpzqTNzVfCwIA，提取码:95t7

2、准备一个文本文档：test1.txt，内容如下图。

![](../Images/5de69a221123884c9c0b848e319033bf.png)

图1  原始目标文件

**操作步骤**

1、在命令行模式下，执行可执行程序。

fastcoll\_v1.0.0.5.exe -p C:\\target\\test1.txt -o D:\\target\\test2.txt D:\\target\\test3.txt

![](../Images/221fc06b0863463241b2a19799db67c0.png)

图2  碰撞生成过程仅需0.487秒

2、在目标位置查看生成的两个文件：test2.txt、test3.txt。计算test2.txt、test3.txt的MD5值，均为:

**C2A1B83243A3C9DA6F7B617A7EC6E265**

![](../Images/fe050777a711fa21c74b324c37b8cc94.png)

图3  碰撞生成的两个文件

3、分别在ASCII模式和二进制模式下查看test2.txt、test3.txt的区别

![](../Images/0a603bd53c94d1ff128dc65b9f918efa.png)

图4  ASCII模式下的比较

![](../Images/51028d8961e3f792528ab105cb2ab049.png)

图5  二进制模式下的比较

4、计算test2.txt、test3.txt的SHA1值，发现确实不同。到目前为止，构造具有相同SHA1值内容却不同的文件的方法，还没有问世。

![](../Images/94074e1b70b09249ec359a8144b0c3ff.png)

图6  构造的两个目标文件具有不同的SHA-1值

【**编者注**】此文目的并不是宣传推翻哈希校验的可信性。只是向大家介绍一个电子取证领域的“邪星”，知道有这么一回事儿就行了。  

  

【**编者再注**】小编自始自终相信，制造两个具有相同MD5值、内容却不同的电子是可行的，但制造具有相同MD5值，同时内容**具有可读的社会意义**的文件，几乎是不可行的，特此说明。
