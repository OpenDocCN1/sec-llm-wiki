# 【名师面对面】“心理神探”毛书贵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651033333&idx=1&sn=8a138902f1e5cdc5ea8f5451cf391e95&chksm=80d0c104b7a7481242b74fffd57d5a43d61794abc065df523240f17270a3d6817b3bfe1f8ae9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651033333&idx=1&sn=8a138902f1e5cdc5ea8f5451cf391e95&chksm=80d0c104b7a7481242b74fffd57d5a43d61794abc065df523240f17270a3d6817b3bfe1f8ae9&scene=27#wechat_redirect)

2012年冬天，大连市某自来水公司会计李某某在律师刘某的陪同下，将45万现金上交大连某区人民检察院，声称公司总经理王某占有使用公司账外资金500余万元，要求检察机关查清王某的犯罪事实并称公司出纳张某可以作证。

由于能够指控王某的涉案依据只有李、张二人的证词，不足以明确事情真相，想要顺利侦破案件并非易事，于是办案部门提请心理测试人员同步介入。请来的人正是毛书贵，一名测谎专家，一直致力于心理测试技术在案件侦破中的应用。

毛书贵对王某进行心理测试后发现结果并不是预料中的以撒谎与否判断王某是否侵占公司资金这么简单，他建议扩大测试范围，查明事实真相。

![](../Images/4c89a62dbb6927c6d9885f48880aece5.png)

证人张某一开始拒绝进行心理测试，经过交涉，“为表清白”他接受了心理测试，测试发现张某坚称的自己陪同过李某某给王某送过钱的陈述不真实。面对测试结果，张某的心理防线开始崩溃，证词出现明显变化。

毛书贵继续对案件的关键人物李某某进行测试，他问“你多次从账外资金账户中提取现金给王某，是实话吗？”“你个人曾使用过这个账户中的钱吗？”两组问题直中要害，即使李某某极力表演自己非常冤枉也掩不住她撒谎的事实。李某某和张某一定有问题！

由于相关证据一时无法搜集，加之李某某和张某二人是以举报人、证人身份配合调查，办案部门当时并未对二人采取法律措施，而是前往有关部门调取了李某某、张某二人的通讯往来记录，发现两人约定咬定钱全部给了王某，千万不要让检察院查出他俩动用账外资金的事情。

一起精心策划，贼喊捉贼的贪污公款案就这样被测谎撬开了嘴，昭然若揭。假的就是假的，谎言永远不会变成真相。

![](../Images/fdceeeb6d113525425d2426e422d2583.png)

采访约在市院11楼的司法鉴定中心，毛书贵是一个温和的人，与猜想的眼神犀利、语言冷酷、不怒自威的测谎师形象不太一样，他向小院儿热情地展示了他办案的老搭档，“神秘”的测谎机器。听他聊办过的案子，智斗犯罪嫌疑人的测谎过程，精彩程度不亚于港片，但这些早已是他的寻常工作。

从零开始到打开局面  

毛书贵是大连人，曾在大连市第七人民医院从事精神病临床医疗、医学鉴定和医疗质量管理等工作，后调入大连检察科学技术研究所，经公务员考试正式成为大连市人民检察院技术处的一员，从事司法精神病检验鉴定及部分法医临床检验鉴定工作。2000年，大连市检察院引入心理测试技术，想用此为案件的侦破打开新局面。此时这项技术在全国检察机关的应用都可以说是寥寥无几，时任大连市人民检察院技术处处长王家昱带着毛书贵和同事靳跃直闯京城，在国家“九五”测谎技术科技攻关项目组组长杨承勋教授那里进行了为期一周的集训。

“纸上得来终觉浅，绝知此事要躬行”，办案一线的同志们先是好奇，再是信任，为心理测试技术的实践提供了大量案源，毛书贵和同事们也不负众望，通过测谎，为案件的侦破提供了线索和方向，心理测试工作在大连打开了局面。目前，毛书贵已进行了约2500人次的心理测试检验鉴定，为办案一线提供侦查方向，实现“零口供”突破千余起，协助突破“大案”“要案”数百起，防止错捕、错诉10余起。个人独立承担了大连地区90%以上的自侦案件心理测试工作。

  

注重积累 快速成长  

毛书贵积极从工作中总结大量的心理测试技术应用经验，撰写了多篇理论学术文章在国家级刊物发表。参与**《心理测试技术教程》《反贪污贿赂实务讲堂》《反渎职侵权实务讲堂》《科技强检人才讲演录——检察新科技》**四本国家级著作编写，与同事合著的**《涉案人员心理危机自杀预防指导手册》**受到有关部门和舆论媒体的广泛关注，中央电视台“新闻30分”栏目对此进行了宣传报道。

初次登台到远近闻名  

毛书贵第一次授课就是在最高检举办的全国性质的培训班讲台上，那是最高人民检察院反贪污贿赂总局在河南省新乡市举办的第二期全国检察机关反贪侦查技术与信息化应用培训班。聊起自己第一次走上讲台的经历，毛书贵仍记忆犹新。“我真的要感谢当时的技术处处长郭玉超同志，是她给我了极大的认可和信任，将我推荐到如此广阔的平台上。”接到授课任务后，毛书贵不敢懈怠，利用一切工作空余时间筹备课程内容，制作课件，模拟演练。

生活不会亏待努力的人，这次授课可以说非常成功，在学员的课程评价表中取得了极高的分数。学员们很兴奋，他们讶异于心理测试技术在侦破工作中的作用如此巨大。毛书贵坦言：“检察系统应用心理测试技术已趋于广泛，但是在应用效果上参差不齐，有的业务频繁，有的设备闲置，一些需要心理测试技术协助的单位，由于与测试人员无隶属关系，导致想用的用不了，能做的做不了。再一个原因是目前心理测试鉴定意见还未允许作为证据采信，所以一些人对这项技术存疑。但是随着心理测试技术在办案过程中的独特作用不断被凸显和加强，这项技术一定会逐渐被人们认可。”

在毛书贵的课中，他总结了心理测试技术在办案中的作用：一是震慑作用；二是可以提供侦查方向、节省人力物力；三是排除无辜、认定嫌犯；四是鉴别证据、固定证据；五是实施心理压力，实现“零口供”突破。每一个作用都配以真实、生动的案例影像去解释，并介绍“准绳测试”“情节测试”等测试编题环节，让学员进一步了解测谎技术是如何配合办案并发挥作用的。 这个课程的意义不单单是教给检察技术人员如何去做，更深的意义在于让所有一线的办案干警意识到，在新时代，审讯不再是一张纸、一支笔的传统模式，如何转变意识，运用类似心理测试技术这种高科技含量的办案手段非常重要。可以说，毛书贵的课给办案干警们打开了一扇科技之窗。

最高检讲台上的“一炮而红”后，全国各地检察院的授课邀请纷至沓来。近年来，他多次受到最高人民检察院反贪总局、最高人民检察院信息中心、国家检察官学院等单位邀请，为全国检察一线办案人员约5000余人次进行了心理测试专题培训。2016年作为最高人民检察院第八批西部巡讲团成员，赴西部宁夏地区进行巡讲支教活动，受到曹建明检察长的亲自接见。曾先后赴新疆、西藏等偏远地区为当地检察干警进行培训。  
![](../Images/550d03f23b47c3ab9acb464d05afdcf0.png "undefined")![](../Images/86508a6e116b3c5d14830ac5903b0993.png "undefined")![](../Images/49479ed4c8fe57a761639da5f972b29b.png "undefined")他的课程《反贪侦查中的心理测试技术》被评为国家检察官学院2013年至2015年度“百门精品课程”。《欺骗与供述心理解读》课程被评为第二批全国检察教育培训精品课程提名课程，被纳入中国检察教育培训网络学院专题培训课程。与同事共同研发的《司法心理学在检察业务中的应用》课程，被评为第二批全国检察教育培训精品课程。《心理测试技术在职务犯罪侦查中的应用》课程，被评为辽宁省第一批检察教育培训精品课程（第一名）以及第三批全国检察教育培训精品课程。根据工作积累及培训需要，他精进学习，潜心研究，又先后开发了《职务犯罪心理解读及预防》《职场心理》等课程，受到了机关公务人员的推崇。![](../Images/c5c6874ce360643f37f1adb94eb482f4.png "1344753023.jpg")只要有空，毛书贵就对着这几条波浪起伏的彩色线条研究被测人的心理变化。原来享誉全国的心理神探并没有什么神秘之处，正所谓“用心精至自无疑”，他乐此不疲，无怨无悔。
