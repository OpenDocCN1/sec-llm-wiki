前言

新的VIVO手机不仅没有原生备份功能而且还采用了全盘加密，导致取证的时候可能会解析不到QQ和微信的数据。随着手机大师版本的不断更新，工具集也对应的进行了更新。今天就给大家带来新版的android命令行工具降级提取VIVO手机QQ微信的方法。         

**风险提示！！！**

**如手机有安装非官方版本微信及QQ，使用此方法会造成数据丢失！！！其他品牌手机及版本未经严格测试，暂不支持。**

**此方法存在误操作风险，请输入命令时务必检查命令输入正确！建议命令可以通过复制的方式拷贝到相应的界面，以免导致数据丢失！**

以上风险提示请务必知悉！！！

**  
微信提取方法**

**具体操作如下**

1

打开工具集中的新版的Android命令行工具。

![](../Images/66f0c1d43a4b2e9fa8b08cc1db279454.png)

2

在新版的工具上点击检测设备，如果出现device，说明前期准备工作已经成功，可以开始降级了。

![](../Images/d8789577bc798554c541060f8ca25422.png)

3

接着按照如下输入命令：（可直接复制这个命令在命令行内粘贴）。adb shell pm path com.tencent.mm : 获取手机里面原版本微信安装包的路径。

![](../Images/19f7c580cc552f40b8918c8eae7381f6.png)

4

adb pull “路径” weixin.apk ：备份手机里原版本微信的安装包，命名为“weixin.apk”,便于后续提完数据后把微信还原回去。  
（路径就是刚刚输入adb shell pm path com.tencent.mm后看到的那段路径） 可以看到备份安装程序到百分百即为成功。不同手机路径可能不相同，以输入命令后看到的路径为准，注意路径前后的空格。

![](../Images/b36c6ccda1a6691ce9f8105554e511ec.png)

5

adb push D:\\ProgramFiles\\MobileMaster\\Mobile Support\\BaseTool\\Android\\4.0\\MFSocket\_1.apk /sdcard/weixin.apk （该命令可直接复制）：推送我们安装目下低版本的微信，同样看到推送完成后有百分百的显示即为成功。

![](../Images/e8b2560d05a2b67fa29715c94cbc6943.png)

6

adb shell pm uninstall -k com.tencent.mm : 把手机里面原版本微信保留数据并卸载。**注意：这句命令行当中一定不能少了-K,否则微信数据就真的删除了….**

  

![](../Images/9b83ac7d647d6dfeec004284af818322.png)

**注意：卸载完后手机要重启一下。**

7

在VIVO手机的文件管理里面手动安装weixin.apk,装完后就可以用手机取证软件提取到微信数据了。

![](../Images/d65f28d782ba4094512e0b3312a4cb4b.png)

8

在提取完微信数据后，输入以下命令 adb push weixin.apk /sdcard/weixin.apk: 推送刚才备份的原版本微信数据包。然后再到手机文件管理手动安装weixin.apk，就将手机的微信恢复到提取前的状态，同理百分百即为成功。

![](../Images/d6f524f4c8879e7b44f3a9007b2133ed.png)

**QQ数据提取**

**具体操作如下**

1

adb shell pm path com.tencent.mobileqq ：获取手机里面原版本QQ安装包的路径。

![](../Images/43ac73e60962e6101ff8f9bd90e9b28a.png)

2

adb pull 路径 qq.apk ：备份手机里原版本QQ的安装包，命名为“qq.apk”,便于后续提完数据后把QQ还原回去。

![](../Images/6a8ea1b4029f5cf80691e50d531b2b06.png)

3

adb push "D:\\ProgramFiles\\MobileMaster\\Mobile Support\\BaseTool\\Android\\4.0\\MFSocket\_2.apk"  /sdcard/qq.apk :推送我们安装目录下低版本的QQ，可以看到推送完成后有百分百的显示。

![](../Images/c9796e4e92c58e73a286160594984137.png)

4

adb shell pm uninstall -k com.tencent.mobileqq:把手机里面原版本QQ保留数据并卸载。**注意：这句命令行当中一定不能少了-K,否则QQ数据就真的****删除****了….**

![](../Images/9ee97b382caa673a90fd79a47428173e.png)

**注意：卸载完后手机要重启一下。**

5

在VIVO手机的文件管理里面手动安装qq.apk,装完后就可以用手机取证软件提取到微信数据了。

![](../Images/d65f28d782ba4094512e0b3312a4cb4b.png)

6

在提取完QQ数据后，输入以下命令adb push qq.apk /sdcard/qq.apk  : 推送刚才备份的原版本QQ数据包。然后再到手机文件管理手动安装qq.apk，就将手机的QQ恢复到提取前的状态。

![](../Images/b10db17217274c57c699f06d40773205.png)

小窍门

  

在软件安装目录D:\\Program Files\\MobileMaster\\Mobile Support\\BaseTool\\Android下的 setinfo.ini中存在一个配置UseUninstallMethod=0修改为UseUninstallMethod=1即可实现自动获取vivo的应用数据及分身（官方）应用。用完记得修改回UseUninstallMethod=0，切记！切记！

前面文章中输入的命令比较多，容易出现误输入命令导致数据丢失的情况，推荐使用更改配置的方法提取QQ和微信的数据，简单又实用。

       **小窍门的方式仅适用于android7.0以下的手机！！！**
