# 【手机型号后缀Note、X、Pro】代表什么意思？

“S”是Super的首字母缩写，很好理解就是“超级”的意思，指手机的硬件小升级版本，比如iPhone 5和 5S，iPhone 6和 6S。咦，iPhone 7S去哪了？

![](../Images/c4307380d6b80a28577be58782218e25.png)

“X”是Xerophyte的简写，意寓“稀有”，还具有未知、酷炫、可能性的意义。比如OPPO Find X就被官方称为是“未来”的手机。而MIX是小米独有的，其中“MI”就是小米啦，而“X”代表未来。

![](../Images/f386767ada38d5160a718af49543deee.png)

“Max”代表的意思最大。比如小米Max系列，现在iPhone也跟上了Max的脚步，主要体现在手机屏幕很大，电池很大。

“Plus”是在手机普通版上的提升，一般比大更大，比好更好。这类手机提升的方面，主要有屏幕、性能、配置，当然也有价格。

![](../Images/31bb58378a11814bf7bc21aee576c85e.png)

“Note”是笔记本的意思，比如三星的Note是带有笔记本功能的手机。就是可以用笔做记录、修改等，像随身带的笔记本一样方便。现在荣耀也推出了Note系列，比如荣耀Note 10，但不商务也没有手写笔，大概只是“大屏”的意思。

![](../Images/5dd5cc9c0eddd5a1ca269d17318c61dc.png)

“Mate”有助手、同伴的意思，主要是华为用于最高端Mate系列，有很强的商务性，可以协助办公。

![](../Images/147d4688ef101b0725b6f8657f384d91.png)

“Pro”是Professional的缩写，代表着“专业”的意思，比如华为P20 Pro，还有苹果的笔记本和平板，都代表高端机中更专业的型号。

![](../Images/a93177b603e519f4fb55de5e6c4761e9.png)
