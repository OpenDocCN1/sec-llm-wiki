# 【电信盗窃案】惯用手法取证分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651036862&idx=2&sn=5e221b9cc6a497a1680e355a6abe0f8e&chksm=80d0d34fb7a75a59bb798df6fd89ffbea252cb47a4b9d4a349bdbdd7d87b1c8cd9ea5a7b346e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651036862&idx=2&sn=5e221b9cc6a497a1680e355a6abe0f8e&chksm=80d0d34fb7a75a59bb798df6fd89ffbea252cb47a4b9d4a349bdbdd7d87b1c8cd9ea5a7b346e&scene=27#wechat_redirect)

**引  言**

随着信息技术的高速发展，人们的生活已步入智能化时代，手机支付已经成为当今社会消费方式的潮流，人们将银行卡绑定在各大移动支付平台上即可享受快捷支付带来的便利，与此同时也给不法分子非法牟利提供了一大便利。近年来，银行卡被盗刷事件频发，智能手机病毒入侵给人们的财产安全带来巨大威胁。  

![](../Images/984fea21424764a8babb2f7aa068dc7d.png)

**一、利用病毒进行电信盗窃的惯用手法**  

犯罪嫌疑人通常会将APK木马病毒的存放地址生成网络链接，通过网址缩短服务把真实的网址修改成缩短网络地址，然后用模拟号码发送短信的功能将带有病毒的缩短网络地址发送给用户，利用人们好奇的心理，引诱其点击下载并运行该木马病毒。

该木马病毒获得了手机管理的最高权限后，将自己伪装成系统程序，达到不被用户发现、隐藏自己的目的，然后在后台静默拦截、匹配、转发、删除短信，同时读取被害人个人信息及联系人信息，发送至设置好的手机号和网络地址。

最后，通过短信数据库操作代码监控处理病毒程序发回的消息，存入数据库，并在攻击者的电子设备上显示。

![](../Images/db62254d09fd2ec85059587f6b9a7563.png)

许多不法分子都是通过这一原理，窃取用户信息和支付平台的账户信息，然后在用户不知情的情况下，获取支付账户的身份验证码，达到盗走用户支付平台和银行卡里资金的目的，如图1所示。

![](../Images/d7bbb5d2921a202ff9b36b392923a279.png)

图1 电信盗窃流程图

**二、电信盗窃案的鉴定与分析**

新型手机木马病毒常以手机短信息为载体，以链接的方式隐藏在短信息中。本文所介绍的案件就是此类犯罪活动的典型案例。

某地公安机关破获一起利用木马病毒非法窃取他人隐私的案件，犯罪嫌疑人蒋某冒充受害人的同学，向其发送病毒链接，诱导其点击下载，而后，通过病毒监控被害人的手机，窃取被害人的个人信息以及银行账户和各大移动支付平台账户的信息，盗走其账户资金。

![](../Images/678a6bb4a1daf2c5d6e83a08f0290814.png)

该地公安机关将从蒋某身上收缴的一部三星手机和一个容量为16GB的U盘送至某鉴定机构委托鉴定，提出三点鉴定要求: 

1.  恢复附件所含手机内的短信、通话记录、通讯录及资金流向相关电子数据；
    
2.  对手机内程序“银联在线.apk”功能进行鉴定；
    
3.  对U盘内程序“相册.apk”功能进行鉴定。
    

**(一) 电子数据的规范化提取**

将手机的外观、颜色、品牌、型号、序列号或产品号进行文字描述、拍照记录(如图2所示)后，把手机拿到屏蔽室内进行鉴定，在关机状态下，先将手机SIM卡、micro-SD卡与机身分离，然后开机，再将手机切换到飞行模式。

![](../Images/4f7cbd7e5720f1c57eff4a58dac5b3db.png)

图2 被鉴定手机照片

为避免取证过程破坏检材数据的风险，通过只读设备分别将U盘、SIM卡、 micro-SD卡、手机与取证计算机相连，使用取证工具提取检材中的电子数据并获取备份镜像，对检材进行hash校验。对镜像进行取证操作，恢复并保存被删除相关数据。

**(二) 手机电子数据分析**

手机电子数据类型主要包括基本信息、通信录、短信、通话记录、程序列表、媒体文件、即时通讯信息、支付平台交易记录、上网记录和文件管理等十项。

通过对这十种类型的数据进行分析，在上网记录、短信、程序列表、即时通讯、支付平台交易记录、文件管理等项中发现与案件相关的内容：

**1、上网记录**

从嫌疑人手机中提取到27条历史记录，如图3所示，其中包含照片.apk的网络存放网盘地址日。经查证http://985.so是提供免费网址缩短服务的网址，嫌疑人发送的手机短信中的链接就是经修改过的病毒网址，达到迷惑受害人的目的。

**(三) 对手机木马病毒的动态取证分析**

借助Android平台虚拟机，通过手机自启动检查、文件系统检查、运行任务检查、联网检查和功能检查等方式对这两个软件进行分析。

经分析发现，相册.apk被点击后开始安装，运行程序(该程序也可在未被运行时接收系统广播从而在后台自启动)并申请设备管理器权限。被激活时，相册.apk获得设备管理器权限，并伪造程序安装失败的提示，迷惑受害人。利用获取的权限将自身伪造成系统程序，防止被害人卸载，并设置成默认短信管理工具，以获取最高的短信处理权限，在后台静默拦截、匹配、转发、删除短信，同时读取被害人个人信息及联系人信息，发送至设置好的手机号和网络地址。

该程序的后台服务若被人为或意外中止或者系统重新启动时，程序会接收系统消息并立即启动后台服务，继续监控被害人手机。

银联在线.apk则是用模拟号码向他人发送含有病毒链接的短信，诱骗受害人点击病毒链接，并监控处理病毒程序发回的消息。收到信息后，存入数据库，并在手机上显示。

**三、案件类型对取证方向的影响**

根据《刑法》第二百八十五条至第二百八十七条规定，可将计算机犯罪案件归为两类: 

(1)以计算机为主体或者对象的犯罪；

(2)以计算机为工具的传统型犯罪。

不同罪名所需要的证据支持的侧重点不同，在对以计算机为主体或者对象的犯罪案件鉴定时，取证人员只需进行日志文件分析、病毒软件功能鉴定、对计算机或用户的危害性鉴定等操作，证据侧重于证明犯罪嫌疑人是否攻击信息系统或窃取相关数据。

对以计算机为工具的传统型犯罪鉴定，除了犯罪使用工具鉴定、掌握犯罪方式及经过外，还需根据传统型犯罪的相关法律法规，对人们常用的各项数据进行提取。

例如，电信盗窃案件中，犯罪嫌疑人蒋某通过病毒监控被害人的手机，窃取被害人的个人信息及银行账户和各大移动支付平台账户信息，达到盗走被害人账户资金的目的。

蒋某的犯罪目的是为盗走他人支付平台账户的资金,并且已造成后果，而涉案病毒只是蒋某的犯罪工具，取证人员应当按照对以计算机为工具的传统型犯罪的鉴定方式，对病毒功能进行鉴定，并根据《刑法》第二百六十四条的规定，对蒋某手机中支付平台的收款、转账记录进行提取，确定涉案资金流向。

**四、结语**

案件侦查人员在计算机犯罪调查取证过程中，需要根据犯罪行为造成的结果以及前期掌握的证据，对该案件是否为电信盜窃案件进行判断，提出准确的鉴定方向。取证人员应当根据鉴定方向，通过动态分析和静态分析结合的方式对病毒功能进行鉴定，对犯罪嫌疑人的通讯记录、资金流向等数据进行多角度、全方位的取证，分析木马病毒使用者的犯罪方式及经过，进而提供案件线索，为案件的侦破提供方向和技术支撑，充分发挥现代化技术侦查的作用，以利进一步打击违法犯罪。
