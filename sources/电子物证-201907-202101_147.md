# 【Volatility Workbench】功能以及应用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651036075&idx=1&sn=6ed73878d34a5ee5136c6dea42c6e961&chksm=80d0d65ab7a75f4c276c418c6a7cc3d13ec39c12892a9d6e462e9ca0d56788cb56988076d886&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651036075&idx=1&sn=6ed73878d34a5ee5136c6dea42c6e961&chksm=80d0d65ab7a75f4c276c418c6a7cc3d13ec39c12892a9d6e462e9ca0d56788cb56988076d886&scene=27#wechat_redirect)

Volatility Workbench是Volatility工具的图形化界面（GUI）。Volatility是一个命令行内存分析和取证工具，用于从内存转储中提取信息。Volatility workbench是开源免费的并且可以在Windows中运行。  

相比Volatility，Volatility Workbench有如下几个优点：

1\.   不需要记住命令行参数。2\. 将操作系统配置文件、KDBG地址和进程列表(元数据)与内存转储文件一起存储在后缀为.cfg（配置文件）格式文件中，与内存转储文件保存在同一目录下。当一个内存映像被重新加载时，这节省了大量的时间并避免了由于不知道要选择正确的配置文件而导致的困扰。3\.   更简单的复制和粘贴。4\.   更简单的打印纸质副本(通过右击)。5\.   更简单地将转储信息保存到磁盘上的文件中。6\.   可用命令的下拉列表和命令功能的简短描述。7\.   执行命令的时间戳。8\.   自动加载在当前文件夹中找到的第一个转储文件。9\.   支持分析Mac和Linux内存转储。  
首先打开软件，界面如图所示，大致可以分为三部分

  

![](../Images/52795b81dba423d562d40b05cdbd4151.png)

操作区（加载镜像、选择配置、选择命令）

  

![](../Images/d606378aec153914bce446dadcbc5349.png)

描述区（命令的说明和流程）

  

![](../Images/e47e9b1c2b80dd71c1057b413adefd89.png)

显示区（类似控制台，显示命令执行的结果）

  

![](../Images/9a15bfc09cf2b0e7748695c6ac1f55a8.png)

支持的镜像（内存转储）默认文件格式有bin、mem、raw、dmp，其他常见的格式也是支持的，只需在添加的时候选择Any file。

  

![](../Images/07d8d213fcad1e78ea9d1021eef4682c.png)

添加镜像后，在profiles中找到对应的系统配置，点击“Get Process List”获取进程列表，如果出现报错，可根据提示更换profiles。

  

![](../Images/0940e8141b3ea1b53995df89cb3eb7ec.png)

接下来，选择需要执行的命令，勾选需要的命令参数，点击“Run”，命令开始执行，每个命令在右边的描述区都有相应的说明。

  

![](../Images/ced967d7cf8d3b6c83963fff822cbf97.png)

在显示区会展示命令的执行结果，附带时间戳，可以对结果进行打印，复制到剪贴板，清除日志，导出到文件等操作。

  

![](../Images/5a2e2f096f059bcc172ca4acd8301585.png)

这里我们引入一个内存镜像来测试下它的效果。

  

![](../Images/720204c43dc39084942ed1fd14c81f41.png)

首先我们要根据内存镜像来选择适当的profile，如果因为选错了profile而发生报错（如下图），也没有关系。

  

![](../Images/07673c27fcac5cbaccea40cf476c2d70.png)

我们可以在底下的显示区找到推荐的profile。

  

![](../Images/38cd628ae4abfd92bcd185b0f6242c18.png)

选择好正确的profile（Windows7 32bit build 23418），开始获取进程列表（Get Process List），列表中包含了偏移量、程序名称、进程ID（PID）、父进程ID（PPID）、线程、句柄、程序开始时间、结束时间。

  

![](../Images/c49914648e11fd5b3f4c4b8712830c0f.png)

hivelist获取内存中的注册表表项，以及对应的虚拟地址和物理地址。

  

![](../Images/09585cb018e1722d27d855489f386ee1.png)

netscan获取网络连接信息，包括地址、端口号、协议、连接状态等等。

  

![](../Images/3bf43c52a9a8c287bb8cc5a997f332b0.png)

hashdump从内存中获取用户的密码哈希（LM/NTLM Hash）,输出中也包含部分用户及其对应的sid。  

  

![](../Images/31d77e8eb95e00f6385350bd5c2ac79c.png)

getsids 可以指定PID，查看哪些用户对特定进程有权限。

  

![](../Images/ad85e02866d523b4edbfbfaaf3bcf3c6.png)

userassist：通过注册表userassist键值下的子键，获取进程的执行次数、总共执行的时间、最后一次执行的时间等信息。

  

![](../Images/0f5ba7c0571d842f203860938af5ee88.png)

iehistory:可以查看IE的缓存和历史

  

![](../Images/79b8c21dd3d1acf8ed1defde4c34883c.png)

filescan:扫描内存中的文件（读写权限和路径）

  

![](../Images/c1810957bcce53429cf9e04451ca5344.png)

memdump:可以将要分析的某个进程保存为.dmp文件，做进一步分析。

  

![](../Images/45ed05f28ee0c4801218d9b946d4526a.png)

  

![](../Images/089eb5945b3a150c9920b9a1c63a91aa.png)
