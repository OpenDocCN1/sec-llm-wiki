# 【解密和提取电报(Telegram)消息】

**针对Telegram消息的提取步骤：**

  

**使用的取证工具：SPF Pro**(SmartPhone Forensic System Professional)

  

**1、在启用USB调试的情况下，将智能手机连接到PC：**  

  

![](../Images/2249fd16066da18c44196b3a2d008cb5.png)

**2、运行SPF Pro ，打开一个新设备并选择智能手机（注意：手机必须是ADB模式，而不是MTP模式）：**

  

![](../Images/36a369960ccba3cb47f9ac4eb90946b0.png)

  

**3、然后，你可以看到系统推荐了一些针对该智能手机提取的解决方案，选择“自动逻辑提取”即可：**

  

![](../Images/e2be01e1b39954e657ce9bdb6b7efbf4.png)

  

**4、输入“自动逻辑提取”后，接着在社交APP类型上选择“电报”的图标：**

  

![](../Images/ed7152167a4d6a7ec421d1a0eac147f1.png)

这里顺便广告一下，SPF目前已经支持支持微信、微博、支付宝账单、滴滴路线、外卖、百度网盘文件、iCloud联系人、图库、提醒、邮件等等多款应用和APP的提取，也包括iOS系统上QQ及微信信息。

  

**5、等待提取过程：**

  

![](../Images/13b17f23d8b249ab31e6f70118456b63.png)

  

**6、等以上过程结束后，我们就可以看到电报的总数据和已删除数据，总数据为4188，已删除或丢失的数据号为103：**  

  

![](../Images/f99464d3bfbfaf3217d12d8be5b884f8.png)  
全过程傻瓜式提取，非常简单。
