# 【微信支付交易明细证明】开具指南

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651035073&idx=1&sn=9977ef932a3da52dfc9c7ab98fcf7e8d&chksm=80d0da30b7a75326c8e0cecb21c4fa3e2f59936ed393cf094647ab30d802408412d3aaf778d8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651035073&idx=1&sn=9977ef932a3da52dfc9c7ab98fcf7e8d&chksm=80d0da30b7a75326c8e0cecb21c4fa3e2f59936ed393cf094647ab30d802408412d3aaf778d8&scene=27#wechat_redirect)

 作为一个法律人在实践中经常遇到需要各种各样的举证材料。比如说银行交易流水，微信转账记录。笔者去年在办理离婚案件的过程中，男方私下拿到调取女方手机查阅个人微信支付记录、全部通过截屏的方式，一张张保存，最后打印出来。所起的作用其实并不如微信支付交易明细证明大，工作的效率和操作程度非常困难，而且还可能庭上出示保存载体的手机，作为法律人，庭上出示被告方保存载体的手机，难度、你懂的！

我们怎么样才能出具一个证明力较高的微信交易记录？今天我们通过调取个人微信支付交易明细证明。我们通过以下步骤操作。我们将获得的一个PDF文档并带有红色印章的交易证明。从这个交易证明我们可以获得被证明人的身份证信息，姓名，微信号，交易明细时间段，PDF文件中包含交易单号，交易时间，交易类型，收支其他交易方式，金额交易、对方商户单号。

  

![](../Images/6718f696a4fd0918df53f2207077d318.png)

      该证明可以查询在用户选择的时间段个人微信名下过去数年的交易证明。用户通过微信支付账户发生的历史交易记录情况，包括零钱，零钱通，银行快捷卡支付等。该证明仅用于用户申请，本证明是注明的用途，不得用于其他用途，并且不得修改或者涂改。恶意查阅他人微信账户交易记录是违法的，严禁用于非法用途。详细步骤如下操作：

 

![](../Images/bf584551e45cafe31e48ce3c99e8cee5.png)

  

**1.进入到支付页面后，在页面顶部菜单中点击选择【钱包】**  

  

![](../Images/bbd611997e94bdcb728c3845751f9eec.png)

**2.然后在钱包页面的右上方点击【账单】按钮**

  

![](../Images/eb35b55647c52698f98cac3099c7be0e.png)

  

**3.微信账单显示是按月显示的，如果想看不同月份的消费，则点击左上方的时间，设置你要查看的月份。****如果开具交易明细的话，点击页面右上方的【…】，如图所示**

![](../Images/88ddd4a05116dadc70c6c2f2588690d6.png)

  

**4.点击【…】之后弹出菜单，在页面底部点击【账单下载】**  

![](../Images/4a0db035dfc9b54f5abb968852ac1253.png)

  

**5.提示选择下载账单用途**

![](../Images/2365711c459fa7fc798fa93c1d63f646.png)

  

**6.选择账单时间段**

![](../Images/ee50ab23b45f43b97f4f3e3ff230d8e5.png)

**7.选择证明文件接受的邮箱**

![](../Images/24780f81ddbf25eaac645318458c325a.png)

  

**8.验证使用者身份信息**

**（保密工作，确实到位）**

![](../Images/2a5a4b755127bc43b2aba479504e5198.png)

  

**9.提示24小时内发送至指定邮箱，**

**实际上1分钟内就可收到证明****![](../Images/fe1b14d41f4c219ff5d639d095efef8a.png)**

![](../Images/732b8575bbbeb099cec4407637ca9c54.png)

**10.微信系统通过申请的微信下发**

**证明文件压缩包密码![](../Images/ca340fd84a10cce52f878f6f9298e387.png)**

**（超级赞，防止他人恶意）**

![](../Images/c19b6d48ce271a7bbc4b748660951c28.png)

**11，邮箱收到的系统邮件****![](../Images/13e3d947a73c8b23fdf863adb588898a.png)**

  

  

**好啦，全部操作过程介绍完毕![](../Images/f17e3d53449be08f24d374f5735ecf1a.png)**
