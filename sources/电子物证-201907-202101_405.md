# 【Android取证】通过ADB命令提取tar包解决镜像加密问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651034927&idx=1&sn=5543d356f388eee3fa7459b648f10cb3&chksm=80d0dadeb7a753c8b14d4e5afe612c90346433239976052db28efd450bb80635d9d7bab4d9d6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651034927&idx=1&sn=5543d356f388eee3fa7459b648f10cb3&chksm=80d0dadeb7a753c8b14d4e5afe612c90346433239976052db28efd450bb80635d9d7bab4d9d6&scene=27#wechat_redirect)

手机取证工作中，侦查员往往对手机的保资料密码破解和数据的恢复效果格外重视。安卓手机存在屏幕密码，我们可以直接清除密码或者利用如MTK、高通等芯片的漏洞进行离线镜像绕过锁屏密码。但是高版本的手机来说，一旦这个手机加密了，镜像也是无法解析的。

小编前段时间支持了一个案件，案件手机是金立S10，存在屏幕密码。通过进入手机工程模式知道这个手机是联发科MTK芯片6757，安卓版本7.0。

![](../Images/31620d1659d1daf44149e715862999dd.png)

从网上找到相应的刷机包进行离线刷机，很幸运，成功了。

对于取证人员来说，这是个好消息。我满怀期待的把手机镜像打出来进行解析，要么说人倒霉的时候喝凉水都塞牙，镜像有了，但是我却无法解析，看到这可能大家都猜到了，对！Android 7.0 及更高版本文件加密了！

说到这里，我们大概了解一下手机的系统和分区

**Android源码编译后的镜像文件：**

ramdisk.img是emulator的文件系统

system.img包括了主要的包、库等文件

userdata.img包括了一些用户数据

**Android分区：**

/data 数据分区存放用户安装的软件以及各种数据

/system 系统分区

/recovery 恢复分区

/cache 缓存缓存临时文件夹

/boot分区 内核分区

/SDCard分区 挂载的SD卡

而由于我打出来的镜像是全盘镜像，注定是无法解析的。看到这可能有些专家肯定会直接指出，为啥不直接打data分区呢？其实我也想啊，但是这个手机比较奇怪，就没有给我选择的余地，系统直接出来的就是全盘。

![](../Images/06d7015a036dfa05cde8956000a89ce8.png)

回过头来看到镜像文件，使用7z解压，发现文件最后边userdata文件，再次满怀惊喜的单独导出来。。。我就知道事情没那没简单。

没错，数据导出提取失败了。

思来想去，和同事沟通后，最后使用adb命令的方法，手机连接电脑，就认准data分区，事实证明，我们的成功了！话不多说，开始上菜。。。

下载BusyBox < - 用于从手机复制和发送数据的实用程序

安装ADB后。连接Android手机（当它打开时）。打开终端/命令行并运行：adb devices

![](../Images/57bc376b8f77964d5b5740139c379d71.png)

拉取当前文件adb push busybox /data/local/tmp  

![](../Images/d52ce44397f3f6f82a2cc4fe4f128cee.png)

adb shell连接到手机。我们使用ls 来测试我们是否可以访问受保护的目录。“-rw-rw-rw-”很显然，我们需要额外获取权限。![](../Images/632d318d91bb5a90410e9851aeb1404a.png)

chmod 777 busybox，修改busybox的权限，变为可执行。  

df 我们查看一下data文件在哪里。

![](../Images/d35a9894c356e8271514aac6afb8830c.png)

找到想要的data文件了，那就导出来吧  

![](../Images/80e9c5a72bb09f6bff54980a14ea4e33.png)

提示报错，提前做个adb端口转发：adb forward tcp:7777 tcp:7777 

![](../Images/306ffc700c46e1c0f1601b687943f67d.png)

data可以换成任意目录（如data分区 就是 data），通过tar命令打包，并通过busybox里的nc将数据传输出来。

最终得到了我想要的tar包镜像文件

![](../Images/634a239872735963eaa0264f6f322557.png)
