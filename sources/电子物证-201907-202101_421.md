# 【iOS取证】聚焦iOS日志分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651034889&idx=2&sn=b7bf29e6863f51de71392076efb4036e&chksm=80d0daf8b7a753ee1498be773b4288455bb0d52198ef9fd312628e7478c4d9409dcffecd5470&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651034889&idx=2&sn=b7bf29e6863f51de71392076efb4036e&chksm=80d0daf8b7a753ee1498be773b4288455bb0d52198ef9fd312628e7478c4d9409dcffecd5470&scene=27#wechat_redirect)

传统的电子数据提取过程中，由于无法获取到系统日志从而错失了许多重要的信息，殊不知手机里除了基本信息、即时通讯外，系统日志往往也能为案件的侦破提供研判的方向。

iOS系统文件目录中最常见的当属于private，private目录里有两个重要的文件夹：var和etc。var是“variable”的简写，存放一些经常更改的文件，如日志、用户数据、临时文件等，iOS中./var实际指向./private/var。某些文件在./Library和./var都存在，比如Keychain数据、系统日志等。而etc是“Et Cetera”的简称，存放系统脚本及配置文件，如passwd、hosts等，iOS中./etc实际指向./private/etc。

奇安信取证事业部今年推出的盘古石手机取证分析系统最早提出了iOS全盘逻辑镜像的概念，并能针对最新的iOS系统进行全盘镜像提取和分析。小编前段时间支援过一个案子，检材手机型号：iPhone XR ，系统版本为iOS 12.1.4，我们的取证分析系统果然不负众望，再次展现出了它的强大之处。接下来小编和大家一起分享一下分析的内容和结果。

首先使用取证系统先打一遍全盘镜像

  

![](../Images/a4e7dfc639bda5b3337e69c2a38ad346.png)

打开分析系统对镜像文件的数据进行解析

![](../Images/3b8d6ec5a4eca609aa32a84c237bbb55.png)

通过解析出日志文件，分别有应用日志、WiFi日志、文件日志以及开机日志

![](../Images/2541593981a770412d1682733647dea4.png)

**1、应用日志**

通过应用日志可以很直观的了解到该手机安装了那些应用，通过时间点还能知道该应用何时安装、何时卸载，使用者对该手机的应用又进行了哪些操作（如卸载后又进行了销毁等）

![](../Images/1a4e5a8fca3724fc8de02508d007aeba.png)

**2、WiFi日志**

WiFi日志文件里存在连接时间、网络ID、MAC地址、IP地址、无线网络类型，更甚至包含了每个连接点的经纬度信息并能在地图上显示，侦查员可以根据这些信息确定嫌疑人经常活动的区域

![](../Images/f344cfe925c43c620e35d2badffb1c54.png)

**3、文件日志**

通过文件日志能够很明确的了解到该文件都被进行了那些操作，如索引、修改、重命名等

![](../Images/7a8e87f8355a30dcd256cab0bfca6108.png)

**4、开机日志**

开机日志记录系统开机时间

![](../Images/46a4b2c10b28f0318453e199c3d973da.png)当然，除了以上分析展现的数据外，由于该手机进行的是镜像提取，已经把手机里边存在的数据全部提取出来，所以镜像文件里其实还有很多重要的参考数据。

**1、苹果手机系统启动日志**

该文件存储与private/var/logs/lockdownd.log.\[0-9\]目录中，\[0-9\]为该日志文件的标记数值。

![](../Images/64abd2f07fbcdf72c9b83556a35f9d0e.png)

通过notepad++打开得到相应数据记录，包括系统启动时间，锁屏时间等其他信息

06/26/19 11:38:02.571918 pid=65 main:Starting Up

06/26/19 11:38:03.242159 pid=65 lockstart\_local\_block\_invoke: Sending activation records to MAD

06/26/19 11:38:03.242307 pid=65 SendActivationRecord: function entry

06/26/19 11:38:03.242434 pid=65 SendActivationRecord: Removing /private/var/root/Library/Lockdown/activation\_records

![](../Images/b9545fbf6e09f1e874851e1c96b73294.png)

**2、微信登录设备记录**

具体日志文件路径为：Documents/\[user\_hash\]/mmsetting.archive

![](../Images/312b3a5d73f3d4ac87e1f8f122c92f62.png)

打开文件查看器查看，该文件记录了微信ID，微信所在地以及不同设备最后一次登录的名称和时间等，因此可以从中得知该微信最近什么时候，在哪些设备上登录过。

![](../Images/c56ace17074bb67c7e521884b8e6a805.png)

微信登录到某设备时，都会记录下每次登录设备的时间和设备名称，一般情况下会存留10个历史记录。当重复登录在同一个设备上的，会覆盖原来该设备的登录记录生成新记录。  

日志文件（log文件）记录系统（程序）运行的状态。可以通过log文件查询历史操作，在发生“灾难性”问题或者需要再次进行深入分析时，或许可以通过log文件发现问题，找到答案。
