一、drizzleDumper

adb连接夜神模拟器

1.  打开夜神模拟器，打开设置，调成手机模式，初次进入的话，进入设置，点击版本号5次，可以激活使用开发者模式，进入后打开USB调试功能

![](../Images/317a02732d1db6036001b291670ceb8c.png)

2\.  打开文件资源管理器，进入夜神模拟器的安装位置，在地址栏输入cmd，回车，会打开cmd窗口，进入的路径就是夜神模拟器的安装位置。我的默认安装位置：E:\\ProgramFiles\\yeshen\\Nox\\bin

![](../Images/d1d074fcd2abdd07d8a2c51c1df90625.png)

3.输入nox\_adb.exe connect 127.0.0.1:62001即可以连接到adb

或者是 adb connect 127.0.0.1:52001

adb connect 127.0.0.1:62001

![](../Images/44e70640e36a04d0d014015c0e1abf1c.png)

4、adb devices查看连接设备情况

![](../Images/3d06c341b52674064297bdb8157e1cb3.png)

 

拖进模拟器

1、在模拟器下，执行adb push E:\\01安装包\\02app\\Android砸壳\\drizzleDumper-master /data/local/tmp （前面是物理机下drizzleDumper工具地址，后面是模拟器下指定地址）

![](../Images/82ed86002aaf0df9e436b2a1b22f47f7.png)

 

2、adb shell进入shell模式，查看：

![](../Images/f7afb00ff55dcbf148cebe9a0224881a.png)

3、执行命令exit，退出shell模式，且用步骤1里的命adb pushC:\\Users\\Administrator\\Desktop\\apk\\anma\_driver.apk /data/local/tmp将要脱壳的APP放入到模拟器中

![](../Images/74801ec2f7153415e5acb094dc2aac1c.png)

4、赋予drizzleDumper超级权限chmod 777/data/local/tmp/drizzleDumpe/libs/x86/drizzleDumper

![](../Images/ff34248b1a00efb4c77fb4d8ac9b9038.png)

![](../Images/4bcb9b566c17c39f553a1701f746ee95.png)

脱壳

1、adb shell下执行/data/local/tmp/drizzleDumpe/libs/x86/drizzleDumper com.amcx.driver

![](../Images/35c670d6fa021669a6d41bcc5025f1c1.png)

2、可见脱了壳的文件保存在/data/local/tmp文件中

二、Xposed框架及Fdex2脱壳

安装配置环境

1、百度搜索FDex2、MT管理器、开发者助手、Xposed Installer、要实验的软件（同声翻译超级版），下载相应的APP安装包，在手机或模拟器中安装

![](../Images/708250114b654a6c6d818506312cf09e.png)

2、Xposed Installer的基本原理是修改了ART/Davilk虚拟机，将需要hook的函数注册为Native层函数。当执行到这一函数是虚拟机会优先执行Native层函数，然后再去执行Java层函数，这样完成函数的hook。在安装Xposed时会遇到一下问题：

（1）安装框架时报TheXposed framework is not installed.Please download the latest ZIP file from XDAand flash it manually via recovery.

![](../Images/91fc273ae09711b14f1eb3c9a11b8ebd.png)

下载SDKplatform23，放到模拟器安装目录的platforms文件夹下

![](../Images/2de2726ceb12f7febeaa61b9fc19d6e3.png)

（2）安装完XposedInstaller后，打开软件，状态为Xposed框架未安装

![](../Images/73e76540d6c299876e5c13473511c758.png)

点击official，选在我们需要的版本进行安装

![](../Images/ed6777ffb7262df43b0a97cf2d1110c8.png)

![](../Images/080770c706694089c1a6a00f10a12617.png)

安装完成后重启模拟器即可生效

![](../Images/7fdc6c6d15ce6e71571854c09e0602f8.png)

 

在模块中勾选FDex2软件，重启模拟器后生效

![](../Images/d85862b35bc464e340797021e9dec396.png)

脱壳步骤

1、打开开发者助手，赋予相应权限及悬浮窗

![](../Images/4ccf7fe3a4e40bec01a9284a65780803.png)

2、打开要脱壳的目标APP，点击开发者助手悬浮窗，可查看该APP是否加壳

![](../Images/1a5316d53c18901c27a72257c8500d5b.png)

3、打开FDex2，点击要脱壳的APP名称，弹出dex输出目录等信息，保存该路径

![](../Images/994fa570a184b4555a6cbd33e9675bc7.png)

4、打开MT管理器，进入/data/user/0/android.translate.xuedianba，查看hook出来的dex文件

![](../Images/a7478216e2e2f3e71f84ad9ffbb7f9cc.png)

 

5、上图红色框内的dex文件不能编译，所以我们需要把它移动到左侧文件列表中

![](../Images/42ce77226471835ae1c6134fa7b23baf.png)

6、在/data/app/android.translate.xuedianba-1路径下找到要脱壳的目标软件包，点击base.apk查看其详细信息

![](../Images/12d5f5c2d3d45dec6513003989a4313f.png)

7、点击查看，可以进入目标软件的各文件路径

![](../Images/628ba6ef820fcb7be79f5dbe7f03293a.png)

8、在步骤5中找到与步骤7中classes.dex文件大小差不多的dex文件，用dex编辑器打开，查看里面是否含有步骤3中的hook包名

![](../Images/c7437da7ebb947ac6a454ef0820d9eca.png)

![](../Images/a1dfe98d8dd55c732041fbd6378960d9.png)

![](../Images/93117aa874808fc4f90995067a853a28.png)

 

9、找到对应dex文件并删除多余的dex文件，对该文件重命名为classes.dex文件，

![](../Images/1b808cb789f8f704f1669e0fdea93057.png)

并移动到软件安装包内（如果报无权限，可在属性中修改相应权限）

![](../Images/097171346633aeecd1bd01e469fe87c0.png)

10、AndroidManifest.xml用反编译方式打开，把第15行的com.tencent.StuShell.TxAppEntry替换成18行的android.translate.xuedianba.BaseApplication,替换完之后删除第16-18行

![](../Images/4bf80f2051e9d4933b9ef77974974e83.png)

![](../Images/bd96b298b72e3ca2c8b14853d163be5d.png)

保存并退出文件

![](../Images/1f659d3c639b6b1c5b2c76490ca81f35.png)

11、提示：在压缩文件中更新，点击确定

![](../Images/7910f2a2c545876f85fad5cd5e487b6e.png)

12、打开软件的功能选项，点击apk签名

![](../Images/a52b5647c1d4db97a40f4bc34c9d23db.png)

13、签名成功后，点击安装（此处要先卸载之前安装的版本，卸载完之后安装即可）

![](../Images/a3d297370d1b1b9a207dfff82a7b227e.png)

![](../Images/6e70e1c4f804672133fe972a308e85c1.png)

三、frida脱壳

Frida安装

   Frida的安装很简单，需要在windows安装frida客户端和在安卓安装frida服务端。

 1、在windows安装客户端

      安装python和pip，注意添加环境变量，打开pip的安装包，输入命令python setup.py install

![](../Images/736fff7cc40c59418571e771cd9f1a21.png)

![](../Images/3fe2c6df628f5b6e07f054c45f9e16dd.png)

安装好后，配置环境变量

![](../Images/84d5934c24a1ae90eac7add8b74c45a1.png)

安装完python和pip之后打开CMD，使用命令 pipinstall frida，安装完如下图所示。

![](../Images/2733574da95f43e319688618c177f7e8.png)

  

安装frida-tools，执行命令pip install Frida-tools

![](../Images/d8d682d2ac778b2237f099204dddbfd1.png)

备注：解决Unknown orunsupported command ‘install’的问题

1、wherepip找出 所有 pip的路径；

![](../Images/ad8c010357f47db3ee1485c214ce358a.png)

  

2、找到，并进入Python下的那个pip路劲；

3、再通过pipinstall  selenium 安装 即可；

![](../Images/ae551461ca0b2e688b06f5ce3a82f35d.png)

 2） 在手机中安装服务端

首先到github上下载frida-server，网址为https://github.com/frida/frida/releases， frida提供了各种系统平台的server，我的手机为红米5plus，是64 arm，所以我下载的为arm64（下载版本应和frida版本对应）

![](../Images/7139070b5d3135bf5ae7ce0064c727f0.png)

解压后，使用adb将frida-server放到手机目录/data/local/tmp，

![](../Images/bb3d9d5b31defe7a5c7db04712b49a72.png)

然后修改属性为可执行

![](../Images/773e51328d2e045ff808497d5c6cee7d.png)

3） 测试安装环境

首先启动手机上的frida服务器，记得要以root权限启动，

![](../Images/462b264539b407b93a653cbe987c1010.png)

然后在windows主机上的python>Scripts目录下另外开启一个cmd，输入命令 frida-ps -U ,这行命令是列出手机上所有的进程信息，如果出现进程信息则说明环境搭配成功：

![](../Images/9060da9e7a3ec7a73d8b6a5ea416818b.png)

在手机上启动frida server端
