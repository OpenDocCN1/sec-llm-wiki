# 【照片或特殊文件丢失】试试用 winhex 脚本进行数据恢复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651034768&idx=1&sn=51d7e22c8274c2b216a0f1d23bfd357b&chksm=80d0db61b7a75277d08ad60e6230740b570d390c7bb45ef6ebdfb94a3ca923a42b6fd883ba69&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651034768&idx=1&sn=51d7e22c8274c2b216a0f1d23bfd357b&chksm=80d0db61b7a75277d08ad60e6230740b570d390c7bb45ef6ebdfb94a3ca923a42b6fd883ba69&scene=27#wechat_redirect)

**第一步****：打开winhex,打开一个正常的图片文件如:JPG CR2 BMP;  视频类文件  MP4 WAV RMVB MTS MOV ; 办法文档文件如DOC XLS PPT MDB等.查看文件前8-16位字节,然后保存下来.这就是我们要找的文件头. 最好,使用同一个相机生成的照片,或同一电脑保存的文档进行取样。**

**第二步****:确定文件头后,我们就可以用winhex打开要恢复的硬盘或分区,进行全盘扇区扫描式查找.查找到的文件一定要保存到另外一块硬盘上.一般可以接一块移动硬盘,不能像客户原存储介质存放任何数据,防止二次破坏客户重要数据。**
