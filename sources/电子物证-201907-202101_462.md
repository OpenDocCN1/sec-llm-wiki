# 【拆解】一加7

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651034768&idx=2&sn=fc8ffbd7284a479f2b931d7737bc40a1&chksm=80d0db61b7a75277bdfe0f1d033e392acd995945bf50047a9806ce2439b962ef3ea68baadb63&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651034768&idx=2&sn=fc8ffbd7284a479f2b931d7737bc40a1&chksm=80d0db61b7a75277bdfe0f1d033e392acd995945bf50047a9806ce2439b962ef3ea68baadb63&scene=27#wechat_redirect)

一加7，作为代表一加速度的旗舰产品，依然主打轻快流畅，而且在性能上依旧不可挑剔。在继承前代特点的同时，工艺设计更加精益求精，综合体验也提升了一个台阶，而且也让一加7成为了同代产品中最让人“拿的起放不下”的艺术品。一加7特色鲜明，看上一眼就很难忘记。虽说市面上的双面玻璃+金属中框的设计多如牛毛，但是能够做到一加7这样圆润自然的却屈指可数。拥有如此让人印象深刻的外观设计，一加7的“内心”世界又是怎样的呢？今天，我们就拆解一台一加7，一起去一探究竟。

![](../Images/90e8890d99ae6434e3e9715c05f62950.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")

首先我们将一加7放到已经预热到80°的加热平台上。两分左右，感觉手机有些微微烫手时，取下手机并且取出SIM卡槽，由于卡托与主板交插，忘记取卡托强行剥离主板并伤到主板的情况时有发生。

![](../Images/3e93a679f4ea897ef2b69029c96ab85b.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")然后，我们使用撬棒和拆机片割开后盖的胶水，由于一加7采用了前置屏幕指纹的解锁方式，所以不用考虑后置指纹的排线问题。另外，一加7这次在胶水上放置的还不少，电池盖很紧，拆卸的时候需要慢一点。

![](../Images/0a756e5b8718df7bd50f9ce24616a3c4.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/ca4947cda1688649b913a85743933abd.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

拆开后盖后，一加7的整个内部布局映入眼帘，依然是经典的三段式设计，主板、电池、副板依次排列。主副板都有盖板覆盖，一体性很强，整体集成度还是挺高的。

![](../Images/63f080ea4f7db509fb1ae0b2513bcf43.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")

![](../Images/2cd4f21e76b9c63cd78b739ed41e8f84.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

拆开保护盖板，主板设计引入眼帘，整体看上去很舒服，元器件排列整齐，做工在同类竞品中难寻敌手，就仿佛是一个精致的艺术品。不亏是标杆级别的产品，连内部都如此精细。

![](../Images/bb6515c4292c9a9b235d92aa12dd47cb.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/baa7d7d3f4bb0b55fbd5a654dcd7bc93.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

先撬起电池排线，然后取下前置摄像头。一加7采用1600万像素AI前置人像，自拍也有出色的背景虚化效果。美得更自然、更突出。此外，还支持EIS电子防抖，视频、直播更稳定。并且支持面部识别功能。

![](../Images/9eb54fd75e1a30980f8523cf2f4b2d49.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/33b7c2b2a490243465742a898b8e8af3.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/e48a44cd857ba289025e4e26052e607b.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

接下来我们拿下整块主板，并拆下后置摄像头，需要注意的是，后置摄像头有排线链接主板，不要强行取下。一加7搭载了和7 Pro同款的4800万像素主摄，f/1.7大光圈，支持OIS光学防抖。配上500万像素副摄，能带来出色的拍摄画质。全新的相机算法，依然延续软硬结合默契的特点，让随手都能拍出一张好的照片。

![](../Images/1d402cee03f13bfae1d200a32dbe0d01.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/d66941b6eda5ab6320a04f2a39702d97.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

拆下后置摄像头后，就可以分离出主板了。可以看到这次一加7的主板其实不算大，主板被做成不规则形状。就是在这不规则的主板上，元器件整齐排列，业内的传统金属屏蔽层也少不了。并且为了散热，一加还为其放置了导热硅脂。其中叠层封装的就是大名鼎鼎的高通骁龙855移动平台。

![](../Images/60ebf2c00813c361935de206ad7bbf3f.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/68430f410b8479dbb6a6babc19f73e02.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

主板告一段落，来看副板，拆下副板盖板才发现大有不同，一加7的盖板不同于之前拆过的其他三段式手机，传统三段式手机副板盖板仅是一个保护作用，一加7则是将扬声器以及马达统统集成在了副板盖板上。

![](../Images/a7b648e467a6e7d356a57bade66122d9.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/3c360e406a071ef15018571d638aa3e2.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

副板中间一个圆形的镂空设计是为了放下手机的振动马达，这样小的副板着实让人大吃一惊。值得一提的是，一加7采用了双立体声扬声器，搭载杜比全景声，让声音品质再上一个档次，细节更加震撼。不管看电影还是玩游戏，这种全新的听音感受，只有听过了，才知道什么叫身临其境。

![](../Images/760f5355cc9fba40bdccbef8bd5927ca.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/a4a2adf6e0a36b6d9ae42543a4fd5516.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

一加7采用了光感屏幕指纹技术，让背部在观感上更为完整，一体性更强。该指纹模块由摄像头和一个单独芯片组成，摄像头放置在屏幕下方，透过光源来看，可以看到手机屏幕下方有一个圆形的开孔，手指按在屏幕上时，摄像头透过屏幕给手指拍照，从而进行识别，这对于屏幕材质的选材想来也是下足了功夫。

![](../Images/cb565d74293599e1aab7d6d429758a68.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

![](../Images/d16fc2ec99d4286bf676be870462588d.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

最后我们拆下一加7的电池，没说什么好说的，很容易。一加7搭载了3700mAh大电池，如果是正常使用，一天没有什么问题。对重度手机用户来说，一加7的OnePlus 闪充技术也能很好的解决续航问题，而且一加7在你边玩游戏，边追剧等充电时也非常迅速。

![](../Images/11a7b0e919b842a5c9532bf3d9656a53.png "一加7拆机解析：做工精益求精 完美呈现“不将就”理念")  

到这里一加7就完全的拆卸完了，随后我们又将手机安装好。手机可以开机正常使用，摄像头功能完好。
