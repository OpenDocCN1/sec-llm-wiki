# 拆机准备

如旧~在拆机前要做好充足的准备，不要手忙脚乱！

工具：镊子、撬棒、螺丝刀、吸盘、热风枪、塑料撬棒，拆机片若干...

要注意两点：

1.提前使用取卡针取出SIM卡槽，关机；

2.拆开后盖之后先拆下电池连接器排线，拆所有电器都一样，优先切断电源。
