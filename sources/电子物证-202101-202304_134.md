# 【利用阿里云的对象存储（OSS）极速取证】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651042466&idx=1&sn=197b245ca323924cece8f0116190a2b0&chksm=80d0fd53b7a7744575ae7e26eedeb0a1db53482543d8c4b1beaecfbc0ba62e50bf4c1cee23e7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651042466&idx=1&sn=197b245ca323924cece8f0116190a2b0&chksm=80d0fd53b7a7744575ae7e26eedeb0a1db53482543d8c4b1beaecfbc0ba62e50bf4c1cee23e7&scene=27#wechat_redirect)

来源：[盘古石取证](https://mp.weixin.qq.com/s?__biz=Mzg3MjE1NjQ0NA==&mid=2247495574&idx=1&sn=0a6bef5c5b9258a5a6e840c2157a0567&scene=21#wechat_redirect)  

你是否遇到过拿到服务器账户密码不知道如何取证的困境？你是否遇到过制作镜像时网络速度较慢的场景？你是否遇到过服务器取证过程复杂、费时的问题？本次给大家带来阿里云服务器便捷、极速取证教程！  

前置条件：已获取阿里云的登录账户和密码并且可以正常登录操作。（如果与当事人不是同一个网络环境，登录需要手机验证码）

**一. 先确认阿里云的账户属于国内站或者国际站（互不相通）**

阿里云国内站：https://www.aliyun.com/

阿里云国际站：https://www.alibabacloud.com/

1、询问相关人员确认账户的属性。

2、直接把账户密码输入登录，如果使用国内账户登录国际站的会提示“该账号属于中国站点账号，请前往登录”，如下图所示：

![](../Images/d24df0b4333e8f6282a244a954cd9503.png)  

**二、修改相关的账户密码**

1、修改绑定的手机号码、邮箱，登录的密码（如果手机号码所属的当事人在现场，先修改相关的账户信息，反之应该谨慎修改，因为修改需要验证码）。  

![](../Images/68090be53afdb6dc53b51333acf4ba76.png)  

2、修改服务器SSH登录的密码。

3、删除或者禁用AccessKey ID 和 AccessKey Secret （AccessKey ID 和 AccessKey Secret 是访问阿里云 API 的密钥，具有该账户完全的权限，以防通过API 删除数据）。

![](../Images/2fd2f092373c6fb22a9d8c4cbffd31c5.png)

**三、确认阿里云的资源**

1、登录控制台之后、点击左上角的“资源管理”。  

![](../Images/652ba553e684da574ac2485bbd71976d.png)  

2、如果没开通“资源管理”，会提示需要授权开通（放心开通，不会有短信提醒等）。  

![](../Images/6b3a7a6784633469316452b3f73a1c42.png)

  

3、从该图片可以看出本账户只有一个ECS服务器。  

![](../Images/378a705dcc2ecc4c3e6a11e3e870eae7.png)  

**四、阿里云ECS服务器取证**  

方法1：使用Linux 自带的DD命令制作镜像，再使用FTP下载到本地（操作复杂，需要另外购买云硬盘且下载速度较慢，在此不做详细介绍）。

方法2：使用阿里云对象存储（OSS）取证，速度快，但操作稍微有点复杂，熟练就好。

1、登录之后找到“资源管理”，并点击ECS实例。

![](../Images/3f8df1c6ca40526ec02f9d59bbfcc184.png)  

2、点击“管理资源”。

![](../Images/b0ea43b6c1b95dfa1d68776e1cadee1a.png)

3、点击“创建自定义镜像”。

![](../Images/d1425385d2390744253113a1f6456445.png)  

4、输入相关信息，点击“创建”。

![](../Images/921dd1dde397af69973a950ac4abe072.png)

5、提示创建成功。

![](../Images/01dcf32022cd05a8450872f6ed04f5e7.png)

6、查看创建镜像状态，创建进度100% 即完成。

![](../Images/fbbcaaad03a9fdd748880005ecaee30f.png)

7、刷新查看进度。

![](../Images/5f3bab7edc946ff1a69ffc5f2d3f9573.png)

8、打开阿里云的对象存储OSS。

![](../Images/72f2b0f7a90602f11aa42135583b8540.png)

  

9、按要求开通。

![](../Images/7da453d83a3d47af06032bc66a0c9d21.png)

  

![](../Images/2c7c288e8e6d5f944ac15ad93927f4df.png)

10、开通成功（开通oss会有邮件和短信的提醒）。

![](../Images/2bec43698a62b12b6864f50a6bd10174.png)

  

![](../Images/81201519b1489ec4f4425a27b98bf808.png)

  

![](../Images/cfffc6404f38ed78a72d7d47fa10d81f.png)

  

11、创建 Bucket。  

![](../Images/a15c1ddbfb22372e2e477d3402de8a7b.png)  

12、点击 ECS的面板，导出镜像到OSS（除了导出到OSS，也可以复制镜像到另外一个账户，效果更好，时间更快）。  

![](../Images/c2f1f533acd890bbf725856d39231841.png)

13、开通云资源访问授权。

![](../Images/e98779a3df5665ce614f9d0ebe681ce1.png)  

14、填写镜像相关的信息。

![](../Images/31af6d7b3b87a4cc8049b1afd7d26ee9.png)

15、提示导出成功。

![](../Images/0629d60c553ba0efd7e1339a4dd8044b.png)

16、查看导出进度。

![](../Images/dac7d500e8a3683b7ba02a22a9ddac4b.png)  

17、导出完成（当碎片文件完成时就可以了）。

![](../Images/67e01e0893394a9db91853e003c397c2.png)  

18、下载镜像文件（40G文件压缩成6.2G）。

![](../Images/733f8c7772fdc2d24dc728787af6b4b9.png)

19、复制URL地址到迅雷下载或者直接点击下载（建议使用迅雷下载、迅雷支持断点续传）。

![](../Images/7aaafc051e69c04fc808b21f4353e5b6.png)  

20、下载的速度和时间比传统的方式快很多，对于现场取证对时间要求比较高的场景，建议使用此方法。  

![](../Images/c72606b26ad6fe801e0f1b8eb7faff3e.png)

方法3：使用盘古石星探网络取证系统对服务器进行取证。  

使用阿里云oss对ECS取证，此方法适用于现场取证。如果对时间要求比较宽裕的可以使用盘古石星探网络取证系统。适用场景：实验室取证等（输入服务器的账户密码、点击镜像制作即可，简单方便）。

1、打开盘古石星探网络取证系统，点击“新建案件”。

![](../Images/10c6e5afd9c2494be32dcc9e86ee97dd.png)

2、输入服务器的账户密码。

![](../Images/149943af969e4ca24ac9d2cb66cbace8.png)

3、成功连接之后如下图所示：

![](../Images/b20401ab7ba1e5686a8e698d5c807c9f.png)  

4、点击“制作镜像”。

![](../Images/1aa7c7be51458c5b13c47d7489ee7fad.png)  

5、点击“确定”即可。

![](../Images/7077ea7b0463f3d85a90e453bee8aa24.png)  

结束语：针对阿里云服务器取证，上文详细列举了2种取证方法，各有优势。利用对象存储（OSS）取证适用对时间要求较高的场景，但操作步骤相对多一些。利用“盘古石星探网络取证系统”操作简便，适用于实验室或者网络较好的场景。大家可以根据实际场景使用，或者两种方法结合使用。
