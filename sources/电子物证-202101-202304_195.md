# 【磁盘管理工具】——qemu-img

**1、简介**

  

        qemu-img是QEMU的磁盘管理工具，在qemu-kvm源码编译后就会默认编译好qemu-img这个二进制文件。本节将对qemu-img常用功能和其使用方法进行介绍与演示。

*   
*   

```
#下载地址：https://cloudbase.it/downloads/qemu-img-win-x64-2_3_0.zip
```

**2、命令行基本用法**

        qemu-img工具的命令行基本用法如下：

qemu-img command \[command options\]

qemu-img --help 包括以下功能：

**01**

check 检查完整性

**02**

create 创建镜像

**03**

compare 比较

**04**

convert 转换

**05**

info 获得信息

**06**

map 映射

**07**

resize 调整大小

**08**

snapshot 快照管理

**09**

commit 提交更改

**10**

amend 修订镜像格式选项

  

  

**3、常用功能实操**

  

        qemu-img工具无图形化操作界面，因此需要以管理员身份运行“CMD”并切换到该工具安装路径之下。

![](../Images/809d164b7dc8372b50dd972f2c8171a9.png)

1

check 检查完整性

        该功能是对目标磁盘镜像文件进行一致性检查，检查镜像文件中是否存在错误，目前仅支持对“qcow2”、“qed”、“vdi”格式文件的检查。

*   
*   
*   
*   
*   

```
#命令格式：check filename#示例：qemu-img check F:\volume-KrY2Tmjqu2gr-system.qcow2

```

![](../Images/97347a66959eb20ac04d67636d9afc07.png)

注：存在错误偏移位置：37915590656

  

2

查看镜像信息：info 命令

*   
*   
*   
*   

```
具体命令：qemu-img info 【镜像】#示例：qemu-img info F:\volume-KrY2Tmjqu2gr-system.qcow2
```

![](../Images/97347a66959eb20ac04d67636d9afc07.png)

  

3

create 创建镜像

        可以使用该命令创建指定格式及大小的镜像文件。

*   
*   
*   
*   

```
#命令格式：check filename#示例：qemu-img check F:\volume-KrY2Tmjqu2gr-system.qcow2
```

注：-f指定镜像格式（可以使用“-o ?”来查询某种格式文件支持那些选项），size指定大小。

*   
*   

```
#示例qemu-img create -f qcow2 F:\test.qcow2 1G
```

![](../Images/ac40ce846418034b4c16d80cd06d4047.png)

  

4

转换镜像格式

        支持不同格式的镜像文件之间的转换，例如将.raw格式的镜像转换为.vmdk格式文件。

*   
*   

```
#命令格式：命令格式:qemu-img convert -f raw xx1.raw -O vmdk xx2.vmdk
```

注：xx1.raw为raw文件完整地址；xx2.vmd处为转换后的文件保存地址。

![](../Images/bc3f7e444b1a26d5881c1f34c5841653.png)
