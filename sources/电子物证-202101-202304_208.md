# 【微信内m3u8视频固定方法】

首先，我们先了解下m3u8视频，m3u8视频是一种基于 HTTP Live Streaming 文件视频格式，它主要是存放整个视频的基本信息和分片(Segment)组成。HLS是新一代流媒体传输协议，其基本实现原理为将一个大的媒体文件进行分片，将该分片文件资源路径记录与m3u8文件置于playlist中，其中附带一些额外描述（比如该资源的多带宽信息等）用于提供给客户端。客户端依据该m3u8文件可获取对应的媒体资源，进行播放。m3u8视频一般以“.ts”结尾。  

1）微信内打开m3u8视频播放链接，选择通过默认浏览器（默认浏览器设置为Chrome）打开。  

![](../Images/d0e68eaabb6d4ee0d457e12a06b98bc4.png)  

2）使用浏览器后视频可能无法播放，如下图所示：  

![](../Images/ed2a08e6beb229a87dcc36fbe4054819.png)  

3）按F12，打开chrome浏览器开发工具，将浏览器模拟成手机，刷新视频即可播放，播放过程可能声音与图像不同步，但是不影响固定，如下图所示：  

![](../Images/a9bfbffb22e841d27eeacff267db9e72.png)

4）在浏览器右侧的开发这工具侧，选择ALL，点击TYPE进行排序，根据m3u8特征，找到ts视频链接。

![](../Images/6dd2dfe392f0fb298293e37422ee0257.png)

5）固定过程中可能会抓到多个ts视频链接，待视频播放结束，找到所有ts视频链接，一般情况所有视频链接地址都一样，文件名会按顺序排列，我们只需找到第一条视频链接和最后一条视频链接即可，中间的可以在excel里自动填充，如下图所示：  

![](../Images/b674e7d6ddb38c1498ccd679b8b0ce80.png)  

![](../Images/717ac548fd7c1b8fb68415b07c482e79.png)  

![](../Images/b46062d11beb8f615d2c70f6fa1c32fa.png)  

6）将上述ts链接复制到迅雷，通过迅雷下载视频。

![](../Images/b3ac459785eee74a71dbfa3b2559e681.png)

![](../Images/aa7a588a4b33506fa4dd02b8c6d799df.png)

7）将下载完成后的ts视频进行合并，合并可以通过“copy /b \*.ts  new.ts”命令合并。  

![](../Images/5d284bb2f3ea2f5f3049d9ba17abfd3d.png)

8）合并后的“20211117.ts”就是要固定的视频，如果需要转成MP4，可以通过转换工具进行转换。  

![](../Images/e8174d1b0cb4d1ce6e8c9df51ae903b2.png)  

另外，我们也可以通过m3u8固定工具进行固定，在使用工具时，我们需要先找到“.m3u8”的链接，方法可以参考步骤1到4，如下图所示：  

![](../Images/517900eaf5696d26280dec3f53c1fca9.png)

打开固定工具，粘贴上述链接，开始下载，如下图示所示：  

![](../Images/18028248bd0a6e08ba73e2c8adcb38d0.png)  

下载完成后，到工具目录下的output目录下即可找到。

![](../Images/c5382e2141f1df0282f2a8fc80e9e0d3.png)
