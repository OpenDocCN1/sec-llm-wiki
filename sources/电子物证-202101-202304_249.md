大疆无人机拍摄的原视频当中，以每秒为单位存储了无人机的GPS位置，速度，相机参数等数据。  
以下就是我截取的一段原视频参数。    因为数据是GPS日志数据，所以GPS坐标系为wgs84ll（ GPS经纬度），具体坐标系的问题可以参照之前的文章[【更新】GPS批量查询（附个人对于坐标系的理解）](http://mp.weixin.qq.com/s?__biz=Mzg4NDUzNzA1MQ==&mid=2247483759&idx=1&sn=b86a74a1829b05ebb251a59be714e819&chksm=cfb7e2dbf8c06bcd5069ee86fbba70ad1056381ffd0ced3c36055aa6ff617eee66b7751fda61&scene=21#wechat_redirect)。

```
`4``00:00:03,000 --> 00:00:04,000``F/2.8, SS 1613.81, ISO 110, EV 0, DZOOM 1.000, GPS (117.5642, 42.6835, 10), D 0.15m, H 15.90m, H.S 0.22m/s, V.S 2.30m/s`
```

    参数中包含了：光圈、快门速度、iso（感光度）、曝光补偿、焦距、GPS数据、起飞点水平距离、起飞点与现在的绝对高度差、垂直速度、水平速度。  
    这些数据是以字幕的形式存于视频当中，可以使用Potplayer软件进行提取出 srt 字幕文件，再将srt文件转换为csv文件进行轨迹的还原。**提取过程：**  
    首先使用Potplayer软件打开视频，之后右键→字幕→保存字幕→另存字幕为，保存为srt文件。![](../Images/e9b1f9031567f5457b3b159920eb8ac8.png)    此处提取的数据非结构化数据，或者说，非二维表格结构化数据，我写了个小的数据处理工具，方便数据提取。将数据存储到csv文件中，后续可以对轨迹进行上图还原，上图这件事我后续会考虑更新一个工具，解决轨迹上图的问题。
