NTFS是目前Windows版本的标准文件系统。Windows 会更新每个文件和文件夹的"最近访问时间"时间戳，以存储上次在 NTFS 卷上访问它们的时间。

NTFS 是 Windows NT 操作系统系列的标准文件系统。从 Windows NT 4.0 Service Pack 6 开始，它支持权限的概念，这些权限可以配置为允许或限制对本地和网络上的文件、文件夹和其他对象的访问。现在的NTFS 支持替代数据流等高级功能。

此外，NTFS 还支持对文件和文件夹进行压缩。与 ZIP 文件压缩不同，使用此压缩类型不需要创建存档文件。压缩将动态进行，并可以像压缩前一样透明地访问文件。Windows 10像以前版本的操作系统一样原生支持NTFS压缩，但它支持许多较新的算法，包括LZX，这在Windows 10之前不可用。

最近访问时间戳


在较旧的 Windows 版本中，可以启用或禁用最近访问时间戳功能。禁用可减少对文件和目录记录最近访问时间戳更新的影响，并提高文件和目录访问的速度。最新版本的Windows 10支持四种不同的模式设置，而不仅仅是禁用它们。这些模式包括：

  • 用户托管，启用最近访问更新

  • 用户托管，禁用最近访问更新

  • 系统托管，启用最近访问更新（默认情况下使用此选项）

  • 系统托管，禁用最近访问更新


在"系统托管"模式下，在启动期间，一旦操作系统装载卷，就会修改最近访问时间戳。Windows 10 不会针对大容量 （>128GB）变更，这是一种维护性能权衡的方式。

 在"用户管理"模式下，无论卷大小如何，最近访问时间戳在启动期间都保持不变。启用后，操作系统仅在发生用户活动时更改它。 

设置"系统托管，禁用最近访问更新"模式将完全禁用 NTFS 的访问时间戳功能。 

有两种方法可用于更改访问时间戳策略。

在Windows 10中禁用最近访问时间戳


  1. 打开注册表编辑器。

  2. 转到以下注册表项。

  3. HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem

  4. 在右侧，修改或创建新的 32 位 DWORD 值NtfsDisableLastAccessUpdate。
    注意：即使您运行的是 64 位 Windows，仍必须创建一个 32 位 DWORD 值。

  5. 将其设置为以下值之一：

    80000000（十六进制）= 用户托管，启用最近访问更新

    80000001（十六进制）= 用户托管，禁用最近访问更新

    80000002（十六进制）= 系统托管，启用最近访问更新

    80000003（十六进制）= 系统托管，禁用最近访问更新

  6. 使用80000003值来禁用最近访问更新。

  7. 重启Windows 10.


使用 fsutil工具更改NTFS最近访问时间戳


  1. 打开命令行.

  2. 输入下列命令: fsutil behavior set disablelastaccess <value>.

  3.  <value> 从以下选择一个值:（默认是2）

     0 = 用户托管，启用最近访问更新

     1 = 用户托管，禁用最近访问更新

         2 = 系统托管，启用最近访问更新

         3 = 系统托管，禁用最近访问更新
