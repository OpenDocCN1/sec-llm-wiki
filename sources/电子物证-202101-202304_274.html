对Linux取证，大家的关注点基本都在主要数据存储分区，对于交换分区关注不多，很重要的一个原因是交换分区没法解析，但这里存放了大量系统运行时的临时数据。
今天为大家介绍一款能对Linux交换分区进行数据分析的工具
swap_digger
swap_digger是一个bash脚本，用于自动化Linux交换数据分析。它自动为提取分析交换分区中隐藏的以下数据：
Linux 帐户明文密码
网络登录/密码
电子邮件地址
HTTP/FTP访问记录
暗网访问记录
Wifi 网络 SSID 和密钥
GPG 私钥
samba凭证及共享路径

脚本下载地址：
https://github.com/sevagas/swap_digger/archive/refs/tags/1.0.zip
也可用git直接下载到目标计算机
git clone https://github.com/sevagas/swap_digger.git
使用方法：
因为这个工具是用shell脚本编写的，所以使用起来非常方便，不需要再安装其它任何插件或模块，只要将脚本增加X权限，就可以执行了。
./swap_digger.sh -va
命令执行后稍等片刻，swap数据将被dump到/tmp/swap_dig/swap_dump.txt文件中。
- SWAP Digger - 
 [+] Looking for swap partition     -> Found swap at /dev/dm-1 [+] Dumping swap strings in /tmp/swap_dig/swap_dump.txt ... (this may take some time)     [-] Swap dump size: 578M
