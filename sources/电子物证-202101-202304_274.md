对Linux取证，大家的关注点基本都在主要数据存储分区，对于交换分区关注不多，很重要的一个原因是交换分区没法解析，但这里存放了大量系统运行时的临时数据。  
今天为大家介绍一款能对Linux交换分区进行数据分析的工具**swap\_digger**swap\_digger是一个bash脚本，用于自动化Linux交换数据分析。它自动为提取分析交换分区中隐藏的以下数据：Linux 帐户明文密码网络登录/密码电子邮件地址HTTP/FTP访问记录暗网访问记录Wifi 网络 SSID 和密钥GPG 私钥samba凭证及共享路径  
脚本下载地址：https://github.com/sevagas/swap\_digger/archive/refs/tags/1.0.zip也可用git直接下载到目标计算机git clone https://github.com/sevagas/swap\_digger.git使用方法：因为这个工具是用shell脚本编写的，所以使用起来非常方便，不需要再安装其它任何插件或模块，只要将脚本增加X权限，就可以执行了。

```
`./swap_digger.sh -va`
```

命令执行后稍等片刻，swap数据将被dump到/tmp/swap\_dig/swap\_dump.txt文件中。

```
`- SWAP Digger - `` `` [+] Looking for swap partition``     -> Found swap at /dev/dm-1`` [+] Dumping swap strings in /tmp/swap_dig/swap_dump.txt ... (this may take some time) ``    [-] Swap dump size: 578M`` `
```

dump完成后马上就可以看到分析结果，所有结果都被列出在屏幕上。

```
`==== Web entered passwords and emails === `` [+] Looking for web passwords method 1 (password in GET/POST)...`` [+] Looking for web passwords method 2 (JSON) ...`` [+] Looking for web passwords method 1 (HTTP Basic Authentication) ...``   -> neo4j:@#ds9qjA)56`` `` [+] Looking for web entered emails...``   ->  $x`` ``   ==== XML data === `` [+] Looking for xml passwords ...`` ``   ==== WiFi === `` [+] Looking for wifi access points...``   [-] Potential wifi network list this computer accessed to:`` [+] Looking for potential Wifi passwords....``   [-] Potential wifi password list (use them to crack above networks)`` [+] Looking for potential Wifi passwords method 2....``   [-] Potential wifi password list (use them to crack above networks)`` ``   ==== Mining most accessed resources === `` [+] TOP 30 HTTP/HTTPS URLs (domains only)``   ->   43656 http://schemas.microsoft.com``   ->     851 https://www.elastic.co``   ->     708 https://en.wikipedia.org``   ->     297 https://github.com``……`` `
```

以上这些数据都是正常取证分析无法获取到的，能对常规取证起到很好的补充作用。
