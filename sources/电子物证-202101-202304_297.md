# 【通过抓包方式固定微信内的视频】

在日常取证工作中，我们经常会遇到需要固定微信内小视频的情况，比如朋友圈内好友转发链接内的视频、订阅号内的视频、微信视频号内的视频，这些视频不论是在微信手机端还是PC端都无法保存。今天，小编给大家分享下微信内的视频固定方法。  

通过浏览器固定

  

通过浏览器固定微信内的视频方法适用于可以通过浏览器打开的链接及视频，比如微信订阅号或朋友圈分享的视频链接。具体固定方法如下：  

1、在PC端朋友圈或订阅号内选择要固定的朋友圈或订阅号内容，并打开查看确认；  

2、在打开的页面左上角点击使用默认浏览器打开，可自动启动电脑默认浏览器打开此视频链接，默认浏览器推荐使用Chrome；  

![](../Images/46d4bb336df0454dd03b10eb4e1a144f.png)

  

![](../Images/09f37915d62b62e942a290fc87f31ef0.png)  

3、在浏览器内按F12，调出开发者工具，如下如所示：

![](../Images/008d3fb3fb50e776ee209a5c207ef1c4.png)

4、在浏览器开发者工具内，切换至Media，然后点击播放视频，即可抓到视频播放链接，如下如所示：  

![](../Images/5e9b6346367a5d631ec8beab0daf0eaf.png)5、在抓取到的链接上单击鼠标，即可看到真实的视频地址，如下图所示：

![](../Images/88c04e0971579455b44dfe60d3479395.png)

6、复制视频链接到迅雷等下载器内下载即可。

![](../Images/ca6598097bd35ebf3a061021b3afeda3.png)

  

通过抓包方式固定

上述方法只针对能够在浏览器内打开的链接和视频的固定，但是像微信视频号、看一看内的视频无法通过浏览器打开，则可以通过抓包的方法进行固定。

  

![](../Images/d71b53d82a3b8c4cc459f540525901e8.png)

在上图中，我们可以看到此视频来源于微信视频号，在此播放链接内，我们看不到复制链接或使用默认浏览器打开的选项。

即便有链接，我们也服务在浏览器内打开，如下图所示：

![](../Images/358d01a242f7e2e11c56c0739790343e.png)

此时，我们可以通过抓包的方式来固定微信内的视频，本文我们主要通过fiddler方式来固定，fiddler的安装和设置方法大家可以百度下。

1、打开fiddler，播放要固定的视频，然后进行抓包，如下图所示：

![](../Images/48c5f105d5441d30475fbf242d0e8718.png)

2、在抓到的包内，我们可以看到主机为“finder.video.qq.com”这条，其请求的目的类型为video，如下图所示：

![](../Images/7201666de7b4c95fdfdc45856b32f8d5.png)

3、复制get后的链接到迅雷内进行下载，下载后修改文件后缀为MP4即可。

![](../Images/9016bb7efdc790eb77f59bf7f2c97322.png)
