# 【MySQL数据库删除恢复】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651040543&idx=2&sn=8402d16087b854e3cc13847ee6b83fbd&chksm=80d0e4eeb7a76df886d92e86c49d07f04b3d1dd483ce7ebbf17ecded149c186e77e379ef0e7f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651040543&idx=2&sn=8402d16087b854e3cc13847ee6b83fbd&chksm=80d0e4eeb7a76df886d92e86c49d07f04b3d1dd483ce7ebbf17ecded149c186e77e379ef0e7f&scene=27#wechat_redirect)

MySQL 是最流行的关系型数据库管理系统，在 WEB 应用方面 MySQL 是最好的 RDBMS(Relational Database Management System：关系数据库管理系统)应用软件之一。

  

目前涉电信诈骗网站后台数据库，也多为MySQL数据库。如何恢复已经删除的数据库？本文介绍了在开启binlog日志下如何恢复删除的数据库。

  

## 测试环境准备

1、Windows10操作系统主机

2、MySQL数据库（5.7.26）

  

## 新建数据库test10

1、使用create命令创建数据库，create database test10;

2、使用数据库管理工具创建数据库，本文使用Navicat Premium进行数据库创建，如下图所示：

  

![](../Images/b840e56b1352ab7a4a1557d359752249.png)

  

## 新建数据库表

在test10数据库中添加，设计test表，并添加数据。

表设计有2个字段，测试数据为1和22.

  

![](../Images/380a67678eb0d592f233dbcbb7dd1fbd.png)

## 删除test10数据库

1、使用drop命令删除test10数据库。

2、使用数据库管理工具，删除test10数据库。如下图所示：

## 恢复删除数据库

1、使用show variables like 'log\_bin';命令查看binlog日志状态，“Value"为"ON”表示已开启。

  

![](../Images/d8279f57b4817bf696381bb0e3083c97.png)

  

2、执行show master status;命令，找到当前mysql记录的binlog文件。

  

![](../Images/3452a40f0e42e570a32f6e89362a831f.png)

  

3、执行show binlog events in 'binlog.000001';命令，查看binlog日志，定位原因。

  

![](../Images/7c39c145878ac3ec718d36635970c266.png)

  

4、导出binlog日志文件为sql语句。由于binlog文件为二进制文件，使用文本编辑工具打开后无法正常阅读。

  

![](../Images/e80af3768a4bb5b21ca663f32d4f986c.png)

  

执行mysqlbinlog --no-defaults binlog.000001 >001bin.sql命令，将binlog文件导出为001bin.sql文件。

  

![](../Images/86d9477a6d81a19b0479ea32e821b8ff.png)

  

从此文件中可以看出创建数据库、创建表、设计表、添加表数据，删除数据的所有SQL语句。接下来的工作可以使用此创建数据库和数据库表部分的语句，插入表内容的语句进行数据库恢复工作。

  

![](../Images/5b4f306397076c2196b883ee69645df2.png)

  

![](../Images/5df02b7ca559911f47ef9ab5e9b12ea5.png)

  

至此，删除的数据库已经成功恢复出来。由于某些原因未开启binlog日志的删除数据库可以使用Percona Data Recovery Tool for InnoDB工具进行恢复，但是恢复效果有限。
