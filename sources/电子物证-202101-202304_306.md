# 【行驶记录仪取证技术】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651040500&idx=2&sn=c2cb7970660a936c213050e80c61ccd1&chksm=80d0e505b7a76c13d7aca87e896b8490b734c940180f9aa2a4e09338ed5c6dac7488c819aa7f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651040500&idx=2&sn=c2cb7970660a936c213050e80c61ccd1&chksm=80d0e505b7a76c13d7aca87e896b8490b734c940180f9aa2a4e09338ed5c6dac7488c819aa7f&scene=27#wechat_redirect)

**汽车行驶记录仪俗称汽车“黑匣子”，上面存储着大量车辆行驶相关的数据，可用于交通事故分析和道路安全管控。**《道路交通安全法实施条例》第14条规定:用于公路营运的载客汽车、危险货运车辆、半挂牵引车，以及总质量12吨及以上的普通货运车辆，必须安装使用具有行驶记录仪功能的卫星定位装置。

目前，符合国家标准的记录仪设备有两种。一种是《GB/T 19056\_2012》国标设备，也是目前市场占有率最高的设备，另一种是早期的其他设备，保有量相对较少。某些省份也会根据自身情况，定制地方的车载终端。还有一些厂商，他们的设备并未遵循以上标准，而是使用自定义的数据存储格式，需要单独分析和研究。

**本文美亚柏科技术专家以行驶记录仪取证作为汽车电子数据取证的切入点，介绍了行驶记录仪的存储数据标准以及设备取证方法，为大家提取汽车电子数据提供思路。**

**2.取证方法**

****2.1行驶记录仪常见安装位置****

行驶记录仪常见安装位置在：驾驶室顶部、中控台面、中控收音机附近、副驾驶手套箱附近。

  

![](../Images/8a6c0aabe5a4c0c65dbf4f285b299bc8.png)

**2.3视频数据提取**使用读卡器或硬盘连接线接入电脑读取视频卡，我们会发现有以下三种常见类型。   
(1)厂家自定义的视频格式，常用播放器无法播放：![](../Images/129fd775f7006427adba4e09e4f7f7aa.png)特殊视频格式  
(2)视频保存在隐藏分区，可见分区很小，可见分区里面没有视频文件：![](../Images/df77115db1b4d2fc91c1964825b8268e.png)无文件系统  
(3)存储卡为特殊文件系统，电脑上无法识别，提示需要格式化：![](../Images/aad316f682545d37a3126c52d005dcba.png)特殊文件系统  
由于视频行驶记录仪存储介质或视频文件通常为厂家自定义的格式，所以需要使用**专用装备**对这类视频卡或硬盘数据进行提取、分析和播放。

  

  
**总结**

综上所述，行驶记录仪的数据格式、视频格式以及设备形态多样，且绝大部分是无法直接查看里面的视频内容，因此需要一个专用装备来提取和分析行驶记录仪数据，美亚柏科推出的**汽车取证大****师**和**汽车临检大师**两款产品支持以上所有设备类型、磁盘格式、视频格式的取证和分析。 

  

司法部已于2020年5月发布《汽车电子数据检验技术规范(SFT 0077—2020)》标准(点击了解更多：[汽车数据安全管理新规发布，行业专家带你解读重点信息](http://mp.weixin.qq.com/s?__biz=MjM5NTU4NjgzMg==&mid=2651299440&idx=1&sn=a635c6c07cf97220579b591efce1797b&chksm=bd05080f8a72811931b480ab7b02906bcbd80f1036b9870152c91fa03237f8d7bd3407e34c6d&scene=21#wechat_redirect))，标准中除了有本文提到的行驶记录仪检验规范，还包含了其他车载电子终端的数据检验技术规范(如EDR、行车记录仪、信息娱乐导航系统等)。未来，我们相信汽车电子数据在交通事故分析和道路安全管控中发挥的作用将会越来越大。希望后续有更多的取证技术人员参与到汽车取证研究中，共同分析今后将面临的日益增长的汽车取证问题以及相关对策。
