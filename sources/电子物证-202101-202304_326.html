前言：近期在做一些比武案例练习的时候，发现经常出现宝塔建站工具的身影，今天给大家分享下宝塔建站工具的一些基础知识。

既然都已经出现宝塔建站工具了，那么首先我们得了解下这是个啥东西？

对于取证人来说，网站重建是这几年来很常见的一个工作，上一篇的文章也给大家说过了，几个关键要素：网站源码、数据库文件、网站运行的环境。宝塔这几年不断出现在取证工作人员的视线中，主要两个方面：

一、不少人利用其简单的环境特点，部署网站，咱们取证人得对他进行取证。

二、咱们取证人自己利用其搭建环境，进行网站重建。

那今天就给大家介绍下，拿到一个镜像之后，如果里面有宝塔建站工具，基本的取证套路。

一、密码绕过，进入系统

拿到镜像以后，利用系统仿真软件，将其仿真起来，仿真以后进入系统。

这边大家注意，如果进行密码绕过，一般重置为root/123456，如果没有绕过成功的话，就手动绕过，度娘”centos 忘记root密码”等等

二、网络设置

进入系统以后，首先使用”ifconfig”命令，查看下IP地址，如果系统使用的是dhcp获取的方法，那么就会自己获取到跟我们电脑对应网卡一样网段的地址。如何不是的话，那么我们就要修改下网络设置。

vi /etc/sysconfig/network-scripts/ifcfg-ens33

这里大家有个问题，虚拟机有不同的网络设置方法，我怎么看IP配置哪个？其实虚拟机已经定义好了。

如上图已经告诉你了，如果是桥接模式的话，看VMnet0网卡，仅主机模式看VMnet1网卡，如果是NAT模式看VMnet8网卡。

三、开启SSH，使用xshell连接。

一般来说，为了方便使用，我们会用xshell工具连接虚拟机，这时候就需要保证SSH开启（使用云取证软件也需要开启SSH）

vi /etc/ssh/sshd.config

这时候，重启ssh服务，systemctl restart sshd

这时候就可以使用xshell或者云取证软件连接服务器了，如果出现连接失败的情况，注意看下防火墙的状态，systemctl status firewalld

如果开启的状态，将其关闭，systemctl stop firewalld

到这里的话，我们对服务器前期的处理就完成了，接下来就可以对BT服务器出手了。


一、查看宝塔面板的地址，账号、密码

使用命令：bt default

二、登录宝塔查看信息。

按照输出的信息在浏览器输入相关信息，一般我们关注的信息有：网站信息、数据库信息

三、打开网站。

如果一切配置都没有问题的话，那么就可以直接打开网站，进入系统。这时候，要对本机的host文件进行修改。C:\Windows\System32\drivers\etc

四、查找登录账号密码，进行登录。

这时候可以使用navicat连接数据库，并找到相应的表。这里会有几个经常遇到的问题：

1、Navicat连接报错。

这个一般是由于root用户只有本地登录的权限。使用以下命令可以解决：

a、 mysql -u root -p

b、 mysql> use mysql;

c、 mysql> update user set 

password=password('你的密码')where user='root' and host='%';

d、 mysql> flush privileges;

e、 quit;

2、哪个表是存放账号密码的？

登录数据库之后，懵逼了，那么多张表，哪一个才是我们要找的？开启mysql的General日志，具体使用办法，之前说过。

五、进系统。

接下来就可以进系统了，至于密码加密什么的，那个之前也讲过了，自己去复习下吧。

六、备份网站源码和数据库数据。一般情况下，我们会把网站源码和数据库给备份下来，这个简单，只要知道他们在哪里就好。

站点默认位置：/www/wwwroot，网站信息那边告诉你具体的位置了

数据库默认位置：/www/server/data
