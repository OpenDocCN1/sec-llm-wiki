# 【葵花宝典】BT取证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDcwMDgzMA==&mid=2651040283&idx=1&sn=9853ac3e578b3d1b6bc9b948001a8962&chksm=80d0e5eab7a76cfc6daa5b727f1c1122b10be610dfb0b0aa57d7921f604c0e7a7064e642f218&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDcwMDgzMA==&mid=2651040283&idx=1&sn=9853ac3e578b3d1b6bc9b948001a8962&chksm=80d0e5eab7a76cfc6daa5b727f1c1122b10be610dfb0b0aa57d7921f604c0e7a7064e642f218&scene=27#wechat_redirect)

前言：近期在做一些比武案例练习的时候，发现经常出现宝塔建站工具的身影，今天给大家分享下宝塔建站工具的一些基础知识。

既然都已经出现宝塔建站工具了，那么首先我们得了解下这是个啥东西？

对于取证人来说，网站重建是这几年来很常见的一个工作，上一篇的文章也给大家说过了，几个关键要素：**网站源码、数据库文件、网站运行的环境**。宝塔这几年不断出现在取证工作人员的视线中，主要两个方面：

*一、不少人利用其简单的环境特点，部署网站，咱们取证人得对他进行取证。*

*二、咱们取证人自己利用其搭建环境，进行网站重建。*

那今天就给大家介绍下，拿到一个镜像之后，如果里面有宝塔建站工具，基本的取证套路。

![](../Images/94f926e316b19703e1be9ddad44d7690.png)

**一、密码绕过，进入系统**

拿到镜像以后，利用系统仿真软件，将其仿真起来，仿真以后进入系统。

这边大家注意，如果进行密码绕过，一般重置为*root/123456*，如果没有绕过成功的话，就手动绕过，度娘”centos 忘记root密码”等等

![](../Images/a33a298e3fb38d3a2cc034020526d536.png)

**二、网络设置**

进入系统以后，首先使用”*ifconfig*”命令，查看下IP地址，如果系统使用的是dhcp获取的方法，那么就会自己获取到跟我们电脑对应网卡一样网段的地址。如何不是的话，那么我们就要修改下网络设置。

*vi /etc/sysconfig/network-scripts/ifcfg-ens33*

里面有几个配置大家要懂：

![](../Images/f8716516232aca8dc19304a5e54263d9.png)

这里大家有个问题，虚拟机有不同的网络设置方法，我怎么看IP配置哪个？其实虚拟机已经定义好了。

![](../Images/04a1272a82f050eee00addcf53727aa4.png)

![](../Images/bcd92d1da1a2b8ce83504eac05052dd6.png)

如上图已经告诉你了，如果是**桥接模式的话，看VMnet0网卡，仅主机模式看VMnet1网卡，如果是NAT模式看VMnet8网卡。**

**三、开启SSH，使用xshell连接**。

一般来说，为了方便使用，我们会用xshell工具连接虚拟机，这时候就需要保证SSH开启（使用云取证软件也需要开启SSH）

*vi /etc/ssh/sshd.config*

![](../Images/0756c705400fb1e50b94458806048caf.png)

这时候，重启ssh服务，*systemctl restart sshd*

这时候就可以使用xshell或者云取证软件连接服务器了，如果出现连接失败的情况，注意看下防火墙的状态，*systemctl status firewalld*

![](../Images/832141738ac711e0f0b7c2c5f4ad6f6b.png)

如果开启的状态，将其关闭，*systemctl stop firewalld*

![](../Images/40f59f71254545e7f7784f2b2b022f90.png)

到这里的话，我们对服务器前期的处理就完成了，接下来就可以对BT服务器出手了。

![](../Images/35d93058b73afe7e32785909b064d7b8.png)

  

**一、查看宝塔面板的地址，账号、密码**

使用命令：*bt default*

![](../Images/8e09efeb35328d2b7517e050323928ee.png)

**二、登录宝塔查看信息。**

按照输出的信息在浏览器输入相关信息，一般我们关注的信息有：网站信息、数据库信息

![](../Images/251dcb1d4f94105f4212453dae154d2f.png)

![](../Images/2ca2d1219f541037a2a69be41914af4c.png)

**三、打开网站。**

如果一切配置都没有问题的话，那么就可以直接打开网站，进入系统。这时候，要对本机的host文件进行修改。*C:\\Windows\\System32\\drivers\\etc*

![](../Images/cad16f7f7f2c1139dfba77e015bafe43.png)

![](../Images/845d5d4d63de1edf54e081a829554571.png)

**四、查找登录账号密码，进行登录。**

这时候可以使用navicat连接数据库，并找到相应的表。这里会有几个经常遇到的问题：

**1、Navicat连接报错。**

![](../Images/f8f6656cca793dd2765a008d5a408750.png)

这个一般是由于root用户只有本地登录的权限。使用以下命令可以解决：

*a、 mysql -u root -p*

*b、 mysql> use mysql;*

*c、 mysql> update user set *

*password=password('你的密码')**where user='root' and host='%';*

*d、 mysql> flush privileges;*

*e、 quit;*

**2、哪个表是存放账号密码的？**

登录数据库之后，懵逼了，那么多张表，哪一个才是我们要找的？开启**mysql的General日志**，具体使用办法，之前说过。

[PHP网站后台密码绕过系列-查找后台的数据库表](http://mp.weixin.qq.com/s?__biz=MzkxNDE4MjgyMg==&mid=2247484166&idx=1&sn=eb3f1412a3c1f38f2a5f8f403ff75d7d&chksm=c17304cff6048dd94b5da3b715d388fc2882e714a374e04024e54ee0f75cc1a9607636dff214&scene=21#wechat_redirect)  

**五、进系统。**

接下来就可以进系统了，至于密码加密什么的，那个之前也讲过了，自己去复习下吧。

[PHP网站后台密码绕过系列--去除密码验证机制(上)](http://mp.weixin.qq.com/s?__biz=MzkxNDE4MjgyMg==&mid=2247484210&idx=1&sn=06b6ebe9cc802fbb73268c030c38c6a3&chksm=c17304fbf6048dedd4ea28498f3bcc6799d2dd4381ef76a6de9f1c60db673c72b574922b171a&scene=21#wechat_redirect)  

[PHP网站后台密码绕过系列--去除密码验证机制(下)](http://mp.weixin.qq.com/s?__biz=MzkxNDE4MjgyMg==&mid=2247484249&idx=1&sn=f9e059ebb35b992fb5cb54cf26e11f1b&chksm=c1730490f6048d86ce65afc5e6a422d6f14de44da4c9c13a3f79918ae15ed5c96b811c8c725c&scene=21#wechat_redirect)  

**六、备份网站源码和数据库数据。**一般情况下，我们会把网站源码和数据库给备份下来，这个简单，只要知道他们在哪里就好。

站点默认位置：/www/wwwroot，网站信息那边告诉你具体的位置了

数据库默认位置：*/www/server/data*

这样一套下来的话，bt服务器内容基本被你翻得差不多了，其他的命令可以参考：

*https://www.bt.cn/btcode.html*
