序言

2016年，苹果公司与美国政府之间的战争一直闹得沸沸扬扬，司法部起诉苹果，要求公司解锁San Bernardino枪击案中枪手Syed Farook使用的iPhone 5C。随后，司法部宣布将撤诉，不再起诉苹果公司。在要求法院撤诉的申请中，检方表示FBI已经成功访问了储存在iPhone 5C上的数据，而且没有苹果的帮助。由于iPhone 5C上储存的数据已经可以访问，FBI不再需要苹果的帮助。

iOS系统密码保护机制

为了保护用户的数据安全，苹果手机在错误密码输入次数过多后会出现停用或永久停用的状态，如：

前5次输入错误密码时，手机会震动并提示密码不正确，但是可以继续输入，而且不需要任何等待时间；

第6次输错密码时，会显示“iPhone已停用，请1分钟后再输入一次”。在接下来的一分钟内，手机处于锁定状态，即使想输入正确密码，也无法输入；

第7次输错密码，显示“iPhone已停用，请5分钟后再输入一次”，5分钟内无法操作；

第8次输错密码，15分钟内无法操作；

第9次输错密码，60分钟内无法操作；

第10次输错密码，显示“iPhone已停用，连接iTunes”；

这种情况下，无论等待多长时间都没有机会再出现密码框，即永久停用，在永久停用状态下即使找到了正确的手机密码，也无法重新输入并解锁手机。这个安全机制无疑为我们的手机取证和锁屏密码破解工作带来了极大的风险和挑战。

iOS常用加密方式

iOS加密其实就是指在iOS系统及应用中通过一些特殊的手段或方式，使原本可以直观看到的东西增加了高级防护的措施。例如一般的文件加密，通常是加了层密码保护。iOS常用加密方式有：

AES加密：AES（The Advanced Encryption Standard）是美国国家标准与技术研究所用于加密电子数据的规范。它被预期能成为人们公认的加密包括金融、电信和政府数字信息的方法；

BASE64编码：BASE64是网络上最常见的用于传输8Bit字节代码的编码方式之一，BASE64编码可用于在HTTP环境下传递较长的标识信息；

MD5加密：MD5的全称是Message-Digest Algorithm 5（信息-摘要算法），在90年代初由MIT Laboratory for Computer Science和RSA Data Security Inc的Ronald L. Rivest开发出来，经MD2、MD3和MD4发展而来；

iOS设备密码破解原理

在iOS系统启动的过程中，我们需要利用Checkm8漏洞来打破iOS的安全启动链，在Boot ROM运行期间植入payload，使其加载我们制作后的启动组件，使Ramdisk能在系统中访问到IOAESAccelerator，我们在能访问到IOAESAccelerator后，就能获取到0x835秘钥（由UID秘钥加密静态值派生，用来加密用户数据分区）。当利用漏洞顺利加载非官方（手动定制了Ramdisk）Ramdisk到内存后，我们在Ramdisk里设置的自启动SSHD服务就会开启，以便设备与PC通讯调试。
