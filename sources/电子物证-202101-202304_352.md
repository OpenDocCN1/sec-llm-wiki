MySQL是一个关系型数据库管理系统，由瑞典MySQL AB 公司开发，属于Oracle 旗下产品。MySQL是最流行的关系型数据库管理系统之一，由于其体积小、速度快、总体拥有成本低，尤其是开放源码这一特点，一般中小型网站的开发都选择MySQL作为网站数据库。今天我们一起来讨论MySQL数据库的几种固定与恢复的方法。

## ****MySQL数据库的固定****

![](../Images/45bc736f1410aa5c1c4ead2178e9f355.png)

**（一）利用mysqldump固定MySQL数据库**

此方法适用于知道mysql数据库的root密码的情况，其用法如下：

mysqldump \[选项\] 数据库名 >导出的文件名.sql

\[选项\]

\-h：服务器IP地址

\-P：服务器端口号

\-u：MySQL用户名

\-p：MySQL密码

\--all-databases：备份mysql服务器上的所有数据库

\[例如\]

1、备份本地数据库pay\_new到当前路径下的pay\_new.sql

mysqldump -u root -pPANsafe12# pay\_new >./pay\_new.sql  

![](../Images/867a7c3634ad84d42bef36af5db0f16e.png)

2、备份远程数据库pay\_new到/home/pay\_new.sql

mysqldump -h192.168.202.138 -P3306 -uroot -pPANsafe12# pay\_new > /home/pay\_new.sql

![](../Images/f17e1727b91e5b3532c09816dd400c80.png)

当然，使用远程固定的方式需要MySQL数据库允许远程连接，打开MySQL远程连接的命令为：update user set host='%' where user='root';

**（三）拷贝data目录固定MySQL数据库**

在MySQL数据库的数据文件所在目录（可查看mysql配置文件获取路径）下，一般有以目标的数据库名命名的文件夹，这个文件夹下的每个frm文件又对应数据表的schema(数据库的组织和结构)表结构，不含数据记录；data目录下的ibdata文件保存数据库中所有数据表的记录数据；.ib\_logfile记录一些没有提交的数据，表损坏的时候，可以用这些东东来恢复。

![](../Images/4ece15b35cde9c447baf8b70ea146e5b.png)

在固定MySQL数据库时，我们只需要固定data文件夹下的ibdata1文件和目标数据库名命名的文件夹（本例：pay\_new）即可。  

使用拷贝数据库数据路径的方法备份数据库的方法比较简单，既适用于从服务器镜像中固定数据库，也适用于远程固定（xftp下载）。

## **MySQL数据库的还原**

![](../Images/45bc736f1410aa5c1c4ead2178e9f355.png)

**（一）使用mysql命令还原MySQL数据库**

使用mysqldump命令还原的方法如下：

mysql -h\[ip\] -P\[(大写)端口\] -u\[用户名\] -p\[密码\]  \[数据库名\] < d:XX.sql(路径)

例如：

1）将pay\_new.sql数据库文件导入到本地mysql数据库内的pay\_new数据库

mysql -uroot -p123456 pay\_new <./pay\_new.sql

2）将将pay\_new.sql数据库文件导入到远程mysql数据库内的pay\_new数据库

Mysql -h192.168.202.131 -P3306 -uroot -p123456 pay\_new <./pay\_new.sql

**（二）使用Navicat还原MySQL数据库**

首先通过Navicat连接目标MySQL数据库，连接方法同上，让后在要还原的数据库上右键，选择“运行sql文件”，如下图所示：  

![](../Images/8b88bc05d6c0a6785f9befb4fad77c76.png)

运行完成后即完成MySQL数据库的恢复。

**（三）MySQL数据目录恢复**

通过MySQL数据目录来恢复数据库需要注意的是源数据库版本与目标数据库版本相差不能太大，否则会导致恢复失败。具体操作步骤如下所示：

1）停止mysql服务，备份现有的data文件夹

2）删除data目录下的ibdata1、ib\_logfile0、ib\_logfile1

3）将拷贝的ibdata1、数据库文件夹拷贝到目标data目录下

4）执行chown -R mysql:mysql data

5）启动mysql服务

6）登录mysql，查看数据库

* * *

【总结】  

本文主要介绍了三种固定和恢复MySQL数据的方法，其中使用mysqldump和Navicat来固定MySQL数据库需要知道MySQL数据库root密码，若是远程固定还需MySQL允许远程连接，得到的是sql文件，支持导入到任意版本数据库；使用拷贝MySQL数据库目录方式固定数据的，在还原的时候需要源MySQL版本与目标MySQL版本相差不大。
