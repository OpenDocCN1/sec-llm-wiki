**测试环境**

  
  

**1、主机：Mac mini 2018款，macOS：10.15.7**

**2、目标机：MacbookAir2018款  
**

**（型号：A1932），macOS：11.2.3**

**3、USB-C to USB-C数据线**

**4、软件：Checkra1n beta 0.12.4 for macOS、  
**

**Homebrew、usbmuxd、Apple Configurator 2**

  

**测试概要**

  
  

**在主机中安装Checkra1n和Apple Configurator 2软件，使目标机进入DFU模式，运行Checkra1n，使用SSH连接。**

  

**具体操作步骤**

  
  
  
01

下载Checkra1n beta 0.12.4 for macOS  
下载地址：https://assets.checkra.in/downloads/macos/754bb6ec4747b2e700f01307315da8c9c32c8b5816d0fe1e91d1bdfc298fe07b/checkra1n%20beta%200.12.4.dmg

双击DMG文件，把Checkra1n程序拖放到应用程序目录

  

  
02

使用USB-C to USB-C数据线将主机和目标机连接

  

  
03

在应用商店中下载Apple Configurator 2后并运行  

  

  
04

目标机处于关机状态，让目标机进入DFU模式：先按一下电源键，然后按住电源按钮的同时，一起按住以下所有三个按键大约3秒钟：右Shift键、左Option键、左Control键，如图1  
大约3秒后，在主机Apple Configurator 2窗口中将全显示“DFU”字符，如图2，此时可确认目标机已进入DFU模式。和iOS设备一样，目标机在进入DFU模式时全程处于黑屏状态。

参考：https://support.apple.com/zh-cn/guide/apple-configurator-2/apdebea5be51/mac

  

![](../Images/c9eb729fa53f419433106de0e91d0dbc.png)

（图1）

 ![](../Images/eea91be2eb2360296fb16303438cfda2.png)

（图2）  

  

  
05

启动台->其他->终端，使用终端命令执行Checkra1n，输入：/Applications/checkra1n.app/Contents/MacOS/checkra1n-c -v 如图3所示。  

若以GUI模式运行Checkra1n则将会提示此设备不支持，如图4

 ![](../Images/483c8b7a7fc690cad31f9efb215c8eba.png)

（图3）  

  

![](../Images/ec8731e8e5c1d09607cbd64baed25dce.png)

（图4）

  

  
06

通常情况下如出现图5所示，错误提示：Timed out waiting for bootstrap upload (error code: -20)

 ![](../Images/36dfaf8a972f380489b7870f842174bd.png)

（图5）  

  

  
07

出现上述错误信息后，可按control + z 结束进程，然后重新执行上述命令，直到出现成功启动的提示: Bootstrap already installed, done ；如图6  

  

![](../Images/c117e556e50b514bf7c02e7fb2ed2ee9.png)

（图6）  

  

  
08

安装国内版Homebrew，打开一个新的终端命令窗口，输入：/bin/zsh -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"  

  

  
09

Homebrew安装成功后，使用brew安装usbmuxd。在终端中输入：brew install usbmuxd  

  

  
010

上述两个软件安装完成后，通过SSH进入越狱后的AppleT2芯片。在终端命令窗口，输入：iproxy 2222 44，如图7  

  

![](../Images/b8e8e31f788528be3f022b52addd235a.png)

（图7）  

  

  
011

重新打开一个新的终端窗口，并输入：ssh root@localhost -p 2222。输入密码：alpine，如图8  

  

![](../Images/831e5c458ab9618aec0086921ba4e44a.png)

（图8）  

  

至此，AppleT2芯片越狱完成。就目前而言，此方法只适用于使用**Intel处理器带有AppleT2芯片**的电脑，越狱后可以**探测T2芯片并探索其安全功能**，例如：可以在Mac上运行Linux系统等。
