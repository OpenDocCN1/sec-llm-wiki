在这里，要向大家推荐一款名为“Fake Image Exploiter”的黑客工具，该工具可以在图片文件中捆绑隐藏的恶意.bat或.exe程序，方便钓鱼或社工攻击过程中的入侵控制。如果受害者点击该恶意图片文件后，将会向控制主机反弹一个管理控制会话。以下是其使用视频：

  

https://www.youtube.com/watch?v=4dEYIO-xBHU

  

配置使用

  

首先，打开Kali终端，执行下载安装和配置：

  

git clone https://github.com/r00t-3xp10it/FakeImageExploiter.git

  

  

![](../Images/aefdcd0d96a4f09ed6e2d81a4b142fe4.png)

  

下载完成之后，进入FakeImageExploiter文件夹，选择setting文件进行配置：

  

![](../Images/7513c4d95ca992008027e32edb2ecdc3.png)

  

在此，你可以选择隐藏在图片中的Payload格式，有ps1、bat、txt和exe四种格式可选，我们选择PAYLOAD\_EXETNSION=bat；在生成捆绑图片文件的替换图标icon选项中，我们选择BYPASS\_RH=NO，非自动，需要手动更改和添加最终生成的图片图标icon。

  

![](../Images/9129240c4680c02efc3877c91891abc2.png)

  

同样，在setting文件中找到以下两列进行按需修改：

  

> AUTO\_PAYLOAD\_BUILD=YES （自动生成Payload选项）
> 
> AGENT\_HANLER\_PORT=4444（植入恶意程序后的客户端监听端口）

![](../Images/1c3f825a6968e5989e917f0b61a02e71.png)

  

配置选项完成后，可以启动Fake Image Exploiter主程序。

## 生成Payload

  

> Cd FakeImageExploiter
> 
> ./ FakeImageExploiter.sh

![](../Images/f18a1b475021a2430367bdca5e7b10e7.png)

  

选择YES启动Payload生成配置框架：

  

![](../Images/12761c41d73307515a7a3325e4c20e62.png)

  

选择在捆绑在图片文件中的恶意程序需要加载利用的Payload，这里我们选择window/meterpreter/reverse\_tcp：

  

![](../Images/b0d2019e8d60616e435ea593f9a22b2a.png)

  

之后，会跳出提示框，需要手动选择你需要捆绑.bat Payload进行伪装利用的jpg图片文件：

  

![](../Images/4d7866d4582c4097f06bd53f273a8039.png)

  

以及最终图片文件的替换图标icon主题：

  

![](../Images/615d98bf13785ba9b18062058c7b54a8.png)

  

接下来，为最终捆绑好的恶意图片文件进行命名：

  

![](../Images/5ec3ce0a8ed0143c572bccbc4304e232.png)

  

FakeImageExploiter最后会生成在两个位置生成恶意图片文件，一个为本机Apache2 web服务的根目录下的.zip文件，另外为FakeImageExploiter输出文件夹（output）下的隐藏后缀恶意图片文件，点击执行后，该文件在显示jpg图像的同时，还会隐秘生成一个连向控制主机的反弹管理会话：

  

![](../Images/1ac5813935c4188d8558ed0b8947bac6.png)

  

以下是控制端成功连接后显示的反弹管理会话：

  

![](../Images/293ec5ef04458961a856779b32849afc.png)
