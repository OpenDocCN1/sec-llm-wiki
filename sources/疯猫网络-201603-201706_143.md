得知目标开放80端口，因此我们通过浏览器打开目标IP 192.168.0.151，但是没有收获。 

  

![](../Images/e85f3a838b3911344fc8a8ccc87cb224.png)

  

为了不浪费宝贵时间，我选择了另一款名为dirb的工具对目录进行暴力破解。在终端键入如下命令：

  

```

```

  

ok大方向正确，并且我们挖出了许多目录。特别是注意下面截图中我高亮标注的backups目录，接下来我们就看看该目录有没有惊喜。 

  

![](../Images/5b98a081aeedc55bf6caa9857eda478e.png)

  

在浏览器中键入192.168.0.151/backups，其中我发现一个名为simple PHP Quiz-backup.tar.gz的tar文件。下载保存到本地，以供后面分析

  

![](../Images/6d3fda4477074bab62b23cff6e7e2e16.png)

  

解压后发现其中包含php和html文件，我的小眼睛一瞄，名为db-conn.php的文件其中会不会有数据库相关的东西呢？ 

  

![](../Images/546f8ee7a2f900b5481491ed843b6493.png)

  

做了许多努力，最后发现dbuser，dbpasswords分别为数据库的用户名和密码。 

  

![](../Images/8a0acb44332e09fc5daf947a3725ead4.png)

  

在此之前我们就挖到很多目录，如果你返回前面截图还可以注意到phpmyadmin目录。接着我们在浏览器中键入192.168.0.1.51/phpmyadmin，键入上一步获得数据库用户名以及密码 

  

![](../Images/2a678f25be300da3caacff9531d247d3.png)

  

正确输入用户名密码，进入phpmyadmin管理页面。其中发现名为zenphoto的数据库，进去瞧瞧吧。 

  

![](../Images/b109d3e255698037f1b52e92cb0b0a7b.png)

  

在zenphoto数据库中发现一个设置页面可用于更新数据库配置文件，在文本框区域填入我们的信息。 

  

![](../Images/a514ac389a2f0487554cd8a23d992f24.png)

  

此处，我们填入数据库用户名dbuser和数据库密码dbpassword，其他直接默认就好 

  

![](../Images/32e6a5fecfca0ee9b919e42b58600196.png)

  

当点击页面下端的GO按钮便开始安装，在安装完成之后会要求你设置管理员账户及密码 

  

![](../Images/8f65bb4b850cf442eb9745d1f459457e.png)

  

单击继续按钮，同意给出服务条款

  

![](../Images/3b9800d20a6079d3eb9b2ab9d0894df3.png)

  

创建管理员用户就不过多叙述，之后点击页面顶部的应用按钮就好。

  

![](../Images/05985a8e17b0547a77acdc25f9d30490.png)

  

使用创建的管理员账户登录zenphoto数据库，进入管理控制台之后我们可以选择上传图片，但这里我们仅上传zip文件 

  

![](../Images/9f1e21fb875e60faab19e62881193582.png)

![](../Images/80a5018dfff30341b6f2b2ecfa643696.png)

![](../Images/ecc47eca6173d5c04977b3b21242d55b.png)

单击shell.php，我们获得metasploit内的meterpreter会话，键入以下命令获取flag：


![](../Images/c3c4089cf6096b393af62b17494c9106.png)

```

```

获得第二个flag 

  

![](../Images/fb464748a78a14045e094c670ad42b1d.png)

  

接下来获取root权限，在文本文档中引用https://highon.coffee/blog/penetration-testing-tools-cheat-sheet/#suid-binary 中的内容。    

之后将其另存为raj.c

  

![](../Images/24b6203433c02ce15ec9af777cb4b752.png)

```
Meterpreter >upload
```

![](../Images/ccc29f7abfdd4e21d4a1f69e000851d8.png)

  

从nmap的扫描结果中我们知道目标ip的nfs端口已开放，利用这个点我们可以在Kali Linux中抓取其挂载的tmp数据

  

```
mount -t nfs 
```

![](../Images/b29ea23a398a07ddc332633fa3b53f86.png)

  

```
./raj

```

![](../Images/4b379b51244477efd9f2848749e8dfcf.png)
