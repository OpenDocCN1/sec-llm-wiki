# 延长电脑寿命 6个超实用电脑保养小妙招

很多DIY玩家选购一台电脑的需求并不是很高，目的就是想长期使用，保持流畅，不想出现任何问题，能尽量不花钱就不花钱。虽然现在的硬件都很“皮实，耐燥”，但是像蓝屏、死机，等现象也是层出不穷，除了软硬件兼容问题，还会有很多情况导致电脑出现不良状况。

![](../Images/1bdd09e57912fb37aa1e3afaed350717.png)

对于很多玩家来说，可能认为在装完机之后硬件正常运行了就没有问题了，其实这个观念是错误的，殊不知电脑也需要维护和保养，今天我们就来带这些新手玩家看看有什么办法能够不花一分钱就能够延长电脑的使用寿命。

高温直接关乎电脑寿命

电脑硬件最大的隐形杀手就是热量，这一点不仅仅限制在电脑产品，对于任何发热量大的电子产品都需要进行有效的散热。产品的工作温度一直处在高温下产品的寿命也会随之减少。机箱产品中的多风扇也是为提供散热而准备的，目前DIY硬件中发热量最大的还是显卡，当然CPU、硬盘也需要有效的散热。

![](../Images/fc520a585d38d1a98530fd7d8a6c3ede.png)

对于高性能的主机来说散热是必不可少的，如果你对噪音有着一定的敏感度这就需要玩家们来考虑整台电脑散热配置了。机箱不仅仅再是保护硬件的大盒子了，而是兼顾散热需求的关键。机箱除了要有足够的风扇位支持散热外，还要有一定可以被动散热的散热孔设计。另外我们还可以通过理线功能保持机箱内部空气的畅快流动。  

![](../Images/7b942d9fe96ef9c4dde5f05e5fb11364.png)

水冷方案主机产品

目前水冷的使用已经渐渐被玩家们所使用，这种散热方式可以有效的帮助高端平台散热。不过水冷的安装复杂，配件的费用昂贵，这样的方案适合那些高富帅玩家使用。但风冷依然是散热的主力军，风冷使用时玩家们要注意灰尘和噪音的打搅。

Ps.随着夏季的到来，环境温度越来越高，很多电脑都降面临散热的问题，这点大家不容忽视哦。

# (2)

灰尘定期打扫也可长寿  

其实灰尘和散热还是息息相关的，如果灰尘严重对散热一定会造成很大影响。其中风冷散热会将机箱外部的灰尘吸入机箱内部，但灰尘覆盖了硬件就会造成散热的问题。对电脑定时清理是非常有必要的，尤其是雾霾天比较严重的地区，更要注意清理灰尘，我们建议每个3个月清理一遍。

![](../Images/82fca7b21eeaa0b487df6f53996c0cb0.png)

满是灰尘的主机内部

清理灰尘时除了硬件的电路板上，同时风扇也是灰尘附着的重点位置，除了对主机硬件进行维护和清理的同时，还需要对风扇和扇叶进行除尘处理。避免机箱内部因为风扇的灰尘而受到干扰。

![](../Images/583017a8cbd76e14b779f2a918958d75.png)

如果有鼓风机，清理主机就更方便了

每个玩家或许有自己不同的清理灰尘的方式，其实在我看来，清理灰尘根本不需要拆下硬件挨个打扫，又是刷子又是小皮吹子的没什么必要。一个鼓风机完全可以搞定，至少我就是用这个方法来清理灰尘的，把机箱拿到楼道，戴上口罩，对准CPU风扇，进风口，出风口等位置吹就可以了。

硬盘防震细节不容忽视

硬盘对于很多玩家来说是自己的命根，如果出现了问题那玩家们的资料就会一去不复返。我们知道，硬盘的转速是其几个最为重要的参数之一，当硬盘内部盘片以每分钟5400或7200甚至更高的转速旋转时，来自外部的物理冲击很容易让硬盘的磁头划伤高速旋转中的盘片。虽说目前硬盘厂商已经将硬盘的抗震能力提升到一个新的高度，不过小心驶得万年船的道理我们每个人还都是了解的。

![](../Images/aebb50993ca7cec2488eaaf8bf0283e3.png)

机械硬盘内部结构

在日常使用时，尤其在主机开机的状态下，我们应该尽可能的避免挪动或者搬运主机，任何来自外部的冲击都有可能让悬浮在高速运转盘片上只有几微米的磁头划伤盘片。另外，无论是台式机硬盘还是移动硬盘，都应该避免在读取数据时强行拔下数据线或供电线，如果在硬盘进行读写操作时强行断开连接，同样会造成无法挽回的数据丢失，甚至硬盘的损坏。

![](../Images/3794d6ac332f91c638a6d8f7ab7f6ebd.png)

机械硬盘怕震动、怕高温

硬盘的散热问题也是非常重要的，如果让硬盘长时间工作在超过50度甚至更高的环境下，那么硬盘的寿命将大大减少。不过，由于目前绝大多数机箱的前面板都可以安装风扇，所以硬盘会得到及时的冷却降温。如果你在买回电脑后，发现机箱前面板处并没有配备散热风扇，那么你需要及时的来增加一个或多个风扇来保证硬盘工作在一个较低的温度范围之内。

Ps.如果觉得机械硬盘抗震不好或者速度慢的话，可以考虑升级换个固态硬盘。如今日渐流行的固态硬盘可以有效解决这2个问题，不仅速度快，一般的震动也对SSD寿命无影响。

# (3)

选对电源很关键  

主机的电源选择是需要技巧的，需要根据整体平台选择合适的额定功率的电源产品。如果经常让平台处于额定功率下工作，电源的温度会上升，同时散热不好的话会减少电源的使用寿命。  

电源在50%负载下也就是典型负载下的转换效率最高，对于电能的利用率最高。因此，平台的日常功耗在电源额定功率的一半上下是比较合适的。

![](../Images/d8c3fb8a60156a17731227ba3ff57574.png)

电源转换效率

当然，一般玩家并非必须恪守50%这个法则。理论上说，电源有一定的余量来满足平台的用电需求就可以。我们在购买电源的时候最好根据平台功耗确定好电源功率，以免在实际使用中遇到问题。

  

![](../Images/00687d45f86c22696d1948f8ccf85eb0.png)

独立开关有妙用

很多电源都会自带独立的开关，那个开关是用来彻底切断电源的开关。当你外出时，你所有的开关都忘记关的时候，防止雷击之类的高电压通过电源烧毁主板。而且，那个开关关掉的话，可以保证你的整台电脑没有任何的电能损耗。

显示器的日常维护

除了电脑主机，显示器也是我们经常需要接触到的硬件。在目前液晶显示器全面普及的时候，在日常生活中，显示器也需要合理的维护和保养。才可以延长其使用寿命。

![](../Images/1d1071ee62f872217a4a934ca4f1ee46.png)

  

显示器清洁

电脑显示器是我们日常使用电脑必不可少的硬件。目前液晶显示器是现在最为主流的，在我们日常使用时也要进行维护和保养。我们日常要使用显示器清理套装，我们日常使用时难免会不小心将一些东西溅到屏幕上，一定不要使用像酒精这样的液体。

![](../Images/08995c09a2dfc5a8188fba4003f10682.png)

显示器设置

另外我们在长时间不使用电脑时一定要将显示器关闭或者进入睡眠模式。这样可以保证显示器灯管的使用寿命，玩家们应该在系统电源选项中进行调整，在这里我们可以看到关闭显示器和使计算机进入休眠两个选项，笔者建议玩家们将关闭显示器时间调整为15-30分钟，可以根据使用者的习惯进行设置。  

# (4)

电脑保养日常使用细节要注意  

电脑是我们日常中最长使用到的产品，我们只要在使用时细心的使用，避免日常中的那些错误操作，就可以让电脑硬件工作顺畅，并且再加上日常的清理、打扫也可以让你的电脑延长使用寿命。

![](../Images/5e70a0adf522705050e993d406efdaae.png)

电脑保养

比如使用光盘或软盘前，一定要先杀毒；安装或使用后也要再查一遍毒，因为一些杀毒软件对压缩文件里的病毒无能为力。  

系统非正常退出或意外断电，应尽快进行硬盘扫描，及时修复错误。因为在这种情况下，硬盘的某些簇链接会丢失，给系统造成潜在的危险，如不及时修复，会导致某些程序紊乱，甚至危及系统的稳定运行。

电脑保养必不可少的相关要点：

1、好散热，让硬件处在良好的工作温度；  

2、清理灰尘，机箱内部整洁干净，避免造成硬件损坏；  

3、硬盘磕碰要避免，尤其是在开机和写入写出数据过程中；  

4、显示器长时间不使用尽量关闭电源，用清洗套装进行清理；  

5、经常开机避免潮湿情况使用；  

6、电源处在最佳状体，可以避免长期高温降低寿命。  

其实只要是抽出一点时间，对自己心爱的电脑进行一下维护和打理，就能够有效延长主机的寿命，为你提供长久的服务。
