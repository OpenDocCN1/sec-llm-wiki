1、下载 MySQL Community Server 5.5.41 Linux - Generic Compressed TAR Archive mysql下载链接

2、解压tar包。例如：解压到/home/work目录下，附：由于解压文件名过长，可通过重命名或者创建软链接。小弟重命名成mysql了

3、#cd mysql –进入mysql工作目录

4、#cp support-files/my-medium.cnf my.cnf –复制官方提供的配置文件

#vi my.cnf –修改并添加一些配置项

7、#./bin/mysqladmin –defaults-file=my.cnf -u root password ‘new-password' –设置用户登录密码

8、#./bin/mysql –defaults-file=my.cnf -u root -p –重新打开一个控制台，登录mysql
