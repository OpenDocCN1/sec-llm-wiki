# 亚马逊AWS推出“机器学习”服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMzE5NTQ3Ng==&mid=2650583029&idx=1&sn=3372a8c7cb1a90f5bff060fc2b734a01&chksm=f029f7cec75e7ed8ae9ad46307741fb373550caea2a94e7e85e02c7acacd96bfbb0c2b559214&scene=126&sessionid=1681370604#rd](http://mp.weixin.qq.com/s?__biz=MzIyMzE5NTQ3Ng==&mid=2650583029&idx=1&sn=3372a8c7cb1a90f5bff060fc2b734a01&chksm=f029f7cec75e7ed8ae9ad46307741fb373550caea2a94e7e85e02c7acacd96bfbb0c2b559214&scene=126&sessionid=1681370604#rd)

  

![](../Images/c9370fa5dc5ae724ce02b8071fd0487e.png)        亚马逊公司旗下的Amazon Web Services宣布推出“亚马逊机器学习”服务。

这是一项全面的托管服务，开发者无需具备任何机器学习经验，就能轻松使用历史数据开发并部署预测模型。这些模型用途广泛，包括检测欺诈、防止用户流失并改进用户支持。

亚马逊机器学习的API和向导能够为开发者提供关于机器学习模型的创建和调试流程的指导，从而轻松部署并扩展模型，支持数十亿级别的预测。

亚马逊机器学习高级经理Jeff Bilger表示，“这项服务支持Amazon.com，能为客户推荐商品，我们的智能音响Amazon Echo能根据用户声音做出回应，这样大概30分钟内我们即可卸载满满一卡车的商品并完成上架。”

另外，通过使用亚马逊机器学习技术，在没有任何机器学习经验的前提下，单个亚马逊开发者可以在20分钟内解决之前需要两名开发者花费45天才能解决的问题——并且所建立的模型同样能够实现92%的精确度。

一旦模型创建完毕，开发者就可以直接从亚马逊机器学习轻松地进行批量处理或生成实时预测，无需开发和管理自有基础架构。
