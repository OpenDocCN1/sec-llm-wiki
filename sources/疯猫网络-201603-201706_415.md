# 游戏服务器都需要哪些维护？

          导语：现在网游是是比较流行的，大大小小的网游公司也随处可见，做游戏需要的服务器一般要求是比较高的，在维护方面需要的技术也有很高的要求。游戏服务器的维护分为日常维护和紧急维护两种。

  

![](../Images/51323b7413c47a6b502142df94389a9c.png "游戏服务器")

日常维护相对来说比较简单，可以根据一定的流程来操作，比较流程化。首先，运营部门会把需要更新的内容给出来，做好新玩法的预热工作。相关的策划会在内部服务器上跑一跑玩法，具体的还要看正式开服之后玩家的反映情况。作为程序，主要就是更新游戏的代码，然后在服务器上进行内部测试，如果架构改动比较大的话，是需要和SA 配合一起跑脚本改架构的。

而紧急维护相对来谁就会比较麻烦，因为你永远不知道下一刻会出现什么样的紧急状况。

出现紧急情况一般是硬件出现了故障，或者是程序出现了严重的bug，这个时候如果不及时处理，就会出现严重的损失。如果是硬件出现了故障，有时候会造成整个服务器的结点负载不均衡，如果是放数据库的服务器挂了，就要赶紧切换数据库了。

游戏服务器的安全好稳定是很重要的，有的出现问题之后会选择重启服务器，这个需要看情况，一种是服务器硬件重启，这个一般不轻易重启，另外一个是进程重启，这个是比较常见的重启方式。
