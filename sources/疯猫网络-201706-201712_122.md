# Petya昨日重现：Bad Rabbit勒索病毒分析

近日，互联网安全中心检测到一款名为“Bad Rabbit”的新型敲诈者木马在东欧为主的各个国家和地区开始传播。

  

![](../Images/f77e67ea8be5d383f1786a5a4517bce9.png)

  

该木马的主要来自于网页诱导——在网页上弹出一个提示框提示需要安装Flash控件：

  

![](../Images/d260bbdd070cad4ea073b8b3a1282346.png)

  

用户一旦上当，便会下载回来一个图标和文件名全面装成Flash的安装包，但该程序实际上却是一个敲诈者木马：

  

![](../Images/91c7ba42f42c0766f2b5dc1bd82b9a5f.png)

  

木马执行后，会先释放infpub.dat文件，该文件是一个动态链接库程序。生成后会调用系统的rundll32调用该库的1号函数执行：

  

![](../Images/4405adaacc6a826da6639f4c4fb86b07.png)

  

Infpub.dat的核心功能依旧是传统敲诈者木马的文件加密功能，被加密的文件扩展名如下：

  

![](../Images/d77582fe519d7187988e0f77a22a8b6b.png)

加密手法并无太大新意，使用了常见的RSA2048算法，本文不再赘述：

  

![](../Images/d2ffa846bcfabfebb5e8310fa59c6345.png)

  

而除了传统的加密文件之外。该木马还会创建一个名为dispci.exe的程序：

  

![](../Images/e8d0a56c93e70ee9dee6908525cd7e4e.png)

  

释放完dispci.exe后，会通过写入计划任务的方式定时重启机器以及在重启后让系统去执行该dispci.exe程序：

  

![](../Images/d5626c00050119c94aadd1ca262c2db4.png)

  

![](../Images/dfdf9568a00785426465471b26085007.png)

  

而这个dispci.exe在重启之后会创建一个名为cscc.dat的驱动程序并与之通信，驱动的功能则和之前曾大规模爆发的Petya相似——通过修改系统引导和MBR的方式劫持开机启动：

  

![](../Images/2a30a672fc395bc7f6fcb33445c351c7.png)

  

![](../Images/4366aefcc78f9f49fc81e872fe30fe98.png)

  

一旦驱动修修改系统引导和MBR，会再次重启系统。而这次系统重启后，被加密的就不仅仅是你的文件了：

  

![](../Images/461e8c3dd98214da655604e1878f9442.png)

  

![](../Images/fd24a29192d9cbe62476091a1c9c0ade.png)

无论是Mimikatz还是弱口令字典，一旦木马成功获取到了局域网内其他机器的登录口令，便会通过获取到的登录口令登录对方机器，再将木马放置到对方机器上启动服务执行木马：

  

![](../Images/c06d6c13bf5e7c493a4854eb8cdd7254.png)

  

![](../Images/25855a52ef48bdcc31f89506d437989d.png)

  

如果用该方法远程启动失败，木马还会再尝试wmi的远程命令以图让木马能够进一步在局域网中扩散：

  

![](../Images/3ac345ccf58d9871ea318c2079d55139.png)
