## Teensy USB开发板   

Teensy是一个非常小的完整的基于USB接口的单片机开发系统，能够实现多种类型的项目。所有的编程是通过USB端口。在没有特殊的程序要求下，只有一个标准的Mini-B USB电缆和PC或Macintosh电脑的USB端口。

主要特点：

  

> 可以是任何类型设备的USB
> 
> AVR处理器，16 MHz
> 
> 单个按键编程
> 
> 易于使用的Teensy Loader应用程序
> 
> 免费软件开发工具
> 
> 兼容Mac OS X，Linux和Windows
> 
> 小尺寸,许多项目的完美支持
> 
> 使用标签面包板
> 
> 非常低的成本

所需工具：

  

> 1.Teensy ++ 2.0 
> 
> 2.Teensyduino插件
> 
> 3.arduino

## 教程开始

下载安装 ARDUINO 1.6.5    https://www.arduino.cc/en/Main/Software/

  

![](../Images/784a5ba0d0ac32051641bf99866f6e77.png)

  

 选择对应的平台下载 

  

![](../Images/4678e0c5a31215c14e93503344fd6ced.png)

  

  

我使用的是Kali linux 系统 下载Linux 64 压缩包解压 进入arduino目录 运行 

  

> ```
> ./arduino
> ```

  

![](../Images/8708b52786a097c9519aacce0fc7d664.png)

  

终端运行打开之后,但需安装Teensyduino插件  下载地址 http://www.pjrc.com/teensy/td\_download.html

选择下载 Linux installer 64

  

![](../Images/227b32fe407e2feb885ed3faf6626785.png)

  

下载完成终端打开  teensyduino.64bit 进行安装

  

> ```
> ./teensyduion.64bit
> ```

  

![](../Images/63b84e4ef46b8f0fc9465565dffbd2e7.png)

  

  

选择 arduino 安装目录> Next

  

![](../Images/b50dbd7a66e03d0365b15425d2ec8055.png)

  

选中 ALL >Next 

  

![](../Images/5135a8dc59ac6a32f3125f73f8830793.png)

  

  

切换打开 arduino 

  

```
          选择菜单栏 Tools>board:  > Teensy ++ 2.0
```

  

开发环境已经准备好了！
