**Debinject**  

他其中就是将msf的Payload 注入到deb中。然后开启监听得到会话。

让我们看看具体的操作吧

  

![](../Images/1da9472ef92eeaa14b76d61a07be450c.png)

  

**使用方法 下载**

> git clone \[url\]https://github.com/UndeadSec/Debinject.git\[/url\]

  

运行

  

> `cd` `Debinjectpython ` `debinject.py`
> 
>   

  

**1.下载并运行软件**

  

![](../Images/4e939982ca06df95fa6aa20facfdb314.png)

  

运行后可以看到运行界面，如图：

  

![](../Images/641a1b92b807a0e7002189e4bfb3b54e.png)

  

**2.填写Deb包路径**  
运行界面直接让我们将deb包的路径写入到里面 ，由于之前作者上传了默认的deb删除了，所以这里我们就使用我本地上的freesweep安装包当做backdoor

  

![](../Images/8a86ca7fb305e1325c3c7295e8fa9533.png)

  

3.填写本机IP地址和监听端口

  

![](../Images/ea2d2cc01ed81b60e3815cb4ad812cdb.png)

  

4.填写目标的架构x86、x64（目标本机是 64位的，我这里就填写x64）

  

![](../Images/b994bf940e6525799650e38e429177e4.png)

  

**5.选择PAYLOAD 参数  我这里就直接选择2**

  

![](../Images/8e3de472070a9b20c856827c9f077580.png)

  

6.可以看到成功生成payload，生成目录在output的backdoored.deb

  

![](../Images/51d801b30d3043d1520cd1ecdc6c9922.png)

  

7.询问是否开启监听。这里选择y

  

![](../Images/e6cb35e5c090762e63b9bf5d71df49c5.png)

  

**8.安装backdoor =>这里生成的payload 在output中 我们将其解压安装**

  

![](../Images/b60b6e66e0eccee22e4fa4802e6a53bd.png)

  

9.解压并安装完毕后，得到我们想要的会话。

  

![](../Images/1479f93bca68f59cbe7d6e061e7cfcb6.png)

  

![](../Images/e039cd90c3e1a417e218e81788ecad60.png)
