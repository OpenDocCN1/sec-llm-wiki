**0x05 理解函数**  
在初中时代，我们的数学课本是可以这么定义函数的-----y=8x+6  
当然了，我们在高中时代，就可以这么定义函数了-----f(x)=8x+8  
其中，x是神马呢？是变量，你想让它是啥数就是啥数  
当x=6时，f(6)=8\*6+8=56  
But,这并不是全部，其实在函数中，并没有规定函数是一个数，它可是任何东西，你想是啥就是啥，比如说：我家的MOMO  
变量的本质，你可以把他当作一个占位符  
建立一个简单的函数  
咱们现在Python的解释器操作：

  

> \>>> x = 8\>>> y=8\*x+8\>>> y72

  

咱们在继续

  

> \>>> x = 6\>>> y72

![](../Images/c1982b16ebc630c4baf0d144f1cbd795.png)

  

这是为神马呢，当x等于6时了。y=8\*x+8为啥还是72呢？  
我想说知识因为爱情，啊哈哈哈哈，还记得咱们当初得变量赋值吗  
x=8时含义将8这个对象贴上了变量x的标签，经过计算得到了72，然后变量y就引用了72，然后当x值变了时，但是y引用得对象还没有变，所以就还是72  
这个解释完美不，有点绕，原谅我语文不好，啊哈哈哈  
这里得还“不正规”，咱们接下来就学习定义一个“正规”函数  
0x06 定义函数  
函数  
代码块以 def 关键词开头，def这个简写来自define，后接函数标识符名称和圆括号()。  
定义函数内容以冒号起始，然后必须缩进（四个空格或者一个tab键）  
定义函数格式为：

  

> `def` `函数名(参数):``        ``函数体`

  

  

举个栗子：

  

>   
> 
> `>>> ``def` `MOMO():``...     ``print` `'HELL0 MOMO!!'``...``>>> MOMO()  ``#调用MOMO这个函数``HELL0 MOMO!!`

  

![](../Images/06ea021905bb646f7069b262045303a9.png)

> `#coding = utf-8` `def` `MOMO(a,b``=``'BaZong'``):``        ``print` `"a:"``,a``        ``print` `"b:"``,b` `MOMO(``'MOMO'``)``print` `"--------------------------"``MOMO(a``=``'MOMO'``)`

**返回值**  
是不是感觉跟你见到的高大上的Python有一点差别  
也许你们会注意到上面都是用print输出结果  
当然，也可能没察觉到，啊哈哈  
用个求绝对值的栗子来引用返回值return

  

> #coding = utf-8 def my\_abs(x):        if x >= 0:                return x        else:                return -xif \_\_name\_\_ == '\_\_main\_\_':        number = 666        print number
> 
>   

  

仔细看my\_abs()函数，有return x和return -x，意思就是将x/-x的值返回，返回给谁呢？返回给MOMO，啊哈哈哈，开个玩笑，一般情况，要将返回的值传给一个变量，然后通过变量打印出来，如果没有，那就没有回显了。。。  
return还有个作用，咱们在来通过一个栗子看，想不到啥栗子了，我这里导入了base64模块，看不懂没关系，下节会讲

  

> #coding = utf-8 import base64 def demo():        str = "TU9NTyBpcyBhIGJlYXV0aWZ1bCBnaXJs"        result = base64.b64decode(str)        print result        return        print "KISS MOMO" demo()

  

![](../Images/66cfe921e459958505fbb24cef738db1.png)

  

细心的同鞋会发现，两个print语句，只执行了return上面的那个，这是为神马呢？  
因为爱情，第一个print语句遇到return，return告诉他要回家去\*\*\*，即为返回，终止了第一个print的路程  
然后就没有执行第二个print语句，你可以把它当成循环中的break，只是可以而已，啊哈哈哈哈  
0x07 全局变量and局部变量  
通过栗子来说明吧

  

> #coding = utf-8 a = 'momo'def demo():        a = 'BaZong'        print "this a is",ademo()print "---------------"print "this a is",a
> 
>   

  

  

![](../Images/c0a4e1f9e73bc4121860c42eb49692af.png)

  

前一个print输出的函数内部的变量，后一个是外部的，像这样的，只在函数体内（某个范围内）起作用的就叫局部变量  
然后咱们该讲啥了，那就是全局变量

  

> #coding = utf-8 a = 'momo'def demo():        global a        a = 'BaZong'        print "this a is",ademo()print "---------------"print "this a is",a
> 
>   

  

![](../Images/a2bb68dd800edb242bd65df8e8513ac5.png)

  

这两个栗子区别就是多了个global  a，意思就是让a是全局变量，也就是说，外面跟里面的a都一样  
学任何一门程序语言的窍门都是要多练，多琢磨
