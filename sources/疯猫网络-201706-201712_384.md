## 0×03 模块的构建

前面都是软件自带的模块，如果我们想自己建立模块，该怎么办呢？

下面是教程

如果要建立自己的模块，在home目录下的’.recon-ng’下建立modules文件夹，然后在分别根据模块属性来建立文件，如建立侦查板块，需要建立recon文件夹，下面以我建立一个模块为例:

  

> ```
> Cd ~Cd .rcon-ngMkdir modulesCd modulesMkdir reconCd reconMkdir findproxyCd findproxyVim find_proxy.py
> ```

模块文件主要的格式就是

  

> ```
> from recon.core.
> ```
