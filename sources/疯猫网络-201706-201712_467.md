## 如何使用

  

![](../Images/425166549d81b888cf3a99fe568dcb35.png)

  

–oui-file 指的是 oui.txt的路径，程序默认值为当前目录下的oui.txt ， 即：./oui.txt

–arp-tab-file 指的是 导出的arp表的路径

  

### **1、首先你要导出系统上的arp 表**

> ```
>                  windows > arp -a > arp.txt
> 
>                  Linux # arp -n >arp.txt
> ```

### **2、 然后执行网卡厂商解析工具（这里暂为mac.py）**

### **3、解析结果保存在当前目录下的result.txt 中**
