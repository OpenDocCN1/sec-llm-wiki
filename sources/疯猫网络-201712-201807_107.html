Galileo是一款针对Web应用程序的开源渗透测试工具，可帮助开发和渗透测试人员识别并利用其Web应用程序中的漏洞。

截图



安装


$ git clone https://github.com/m4ll0k/Galileo.git galileo
$ cd galileo


安装依赖


$ pip install -r requirements.txt


或


$ apt-get install python-pysocks

windows


$ python -m pip install pysocks

运行


$ python galileo.py
