# 专为游戏而生的“游戏主机

游戏主机可以说是专为大型3D游戏而生的，如果说游戏PC是重视CPU的同时加装优秀GPU的话，游戏主机就是重视GPU的同时配备可以满足使用需求的CPU，一般CPU性能不会太高，但是由于机箱散热和定制GPU等使得游戏主机可以轻松应对大型3D游戏的持续运行，而且硬件使用率极高。如果说CPU是PC的核心部件，GPU则是游戏主机的核心部件。游戏主机的主要处理任务都是由GPU完成，CPU更像是协处理器的功能（主要处理后台语音，后台下载等一些功能）。优秀的游戏主机凭借自身出色的图像处理能力，可以轻松播放4K蓝光影片。

主流的游戏主机还包括了任天堂的“switch”、微软的“Xbox One”、索尼的“PlayStation 4”以及其他一些国内游戏厂生产的游戏主机，售价一般在2000-3000元左右。

购买游戏主机的主要参考标准是GPU指标---FLOPS，即每秒浮点运算次数（亦称每秒峰值速度）是每秒所执行的浮点运算次数，游戏主机的GPU性能一般高于1TFLOPS，每秒1万亿（=10^12）次的浮点运算以上。

游戏主机的适配游戏丰富程度也是一个主要参考标准，这决定了它的可玩性。游戏主机的配套游戏都需要单独购买，这也是主机游戏玩家的的主要花销之一。

![](../Images/d28ae19d53eb952ff6dcfab67734ac7c.png)

游戏主机一般通过手柄操作，手柄配备有震动反馈装置，让你在游戏中的体验更加真实。也可以通过体感动作、VR头盔等实现操作。
