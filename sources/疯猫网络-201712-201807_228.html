0×02 配置 pyJoiner—GUI-Version 运行环境

GitHub 上有两个版本 项目地址 ，其中 kali 版必须使用 Kali Linux i386 ，我的是 x64 kali ，所以选择了 Windows版本的 pyJoiner—GUI-Version。

本次实验 pyJoiner 运行环境如下：


Windows 10

Python 3.6.3

pyinstaller 3.3.1
