X Brute Forcer是一款支持对多种常见CMS实施密码爆破攻击的工具。目前，X Brute Forcer所支持的CMS包括WordPress , Joomla , DruPal , OpenCart , Magento。



简单爆破脚本

[1] WordPress （自动识别用户名）
[2] Joomla
[3] DruPal
[4] OpenCart
[5] Magento
[6] All （自动识别CMS）

使用

简易命令格式完整命令格式描述
-l–list站点列表
-p–passwords密码列表

示例


perl XBruteForcer.pl -l list.txt -p passwords.txt

Linux 安装


git clone https://github.com/Moham3dRiahi/XBruteForcer.gitcd XBruteForcer
perl XBruteForcer.pl -l list.txt -p passwords.txt
