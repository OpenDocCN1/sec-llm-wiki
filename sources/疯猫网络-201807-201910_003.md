## McAfee  

在以往每当我们遇到McAfee Virus Scan Enterprise（VSE）的时候，都可以通过简单地查询注册表了解到那些位置是管理员指定的“特殊位置”（不受杀毒软件影响）

然而，在这次任务中，事情没那么简单。因为他们使用的是McAfee Endpoint Security，从VSE时代到现在，McAfee可能认为最好不要将“特殊位置”之类的信息以明文形式存储在任何人都可阅读的文件中。

那么，我们现在该把恶意文件放在哪里？

![](../Images/9c1aa7bfca85bc876239e9955c0fce28.png)

## 绕过管理员权限

在没有管理员权限的情况下ESConfigTool工具能使用的功能是非常有限的：

```
Microsoft Windows [Version 
```

我们怎样才能知道权限检查的流程呢？先让我们以普通用户的身份运行调试器，看看会发生什么。发现它调用一个函数，并对返回值进行字符串比较，如果返回代码不是0，则调用“exit”。

![](../Images/6fc503b8b837b0c995a9d4b97a79db78.png)

返回值检查如下：
