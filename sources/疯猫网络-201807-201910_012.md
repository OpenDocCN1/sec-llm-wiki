先给大家推荐一款截图软件，非常方便，可以把截出的图片放置到窗口上

![](../Images/6b8b59103d1b1cef0548bfaa6d51b58d.png)

并且可以随意移动，这个是微软开发的一款工具：Snipaste

  

![](../Images/878ed633e39559e1135efaa429a54e5c.png)

  

支持各类电脑系统，先简单介绍一下它的用法，F1截图，ctrl+c把图片复制到剪贴板，方便下次使用（ctrl+v）。

  

我们要做一款截图工具，也就是模仿这款软件的功能。

利用到的python模块有：

*   import keyboard
    
*   from PIL import ImageGrab
    
*   from time import sleep  
    

keyboard为我们的键盘记录模块，判断我们是否按下了F1键，PIL为我们的图片处理库导入了其中的剪贴板模块。

![](../Images/14c122b664199a78cb9be86bfdae0347.png)

若未按下F1那么程序处于阻塞状态，只有按下后代码才会向下执行。先F1截图，然后Ctrl+c保存我们的图片到剪贴板。

最后把图片从剪贴板中取出来保存为 test.png。

  

图片保存后就要识别， 这里利用到的是百度云的接口。

  

![](../Images/c17576eab2280e9b1547f972f91971ff.png)

可以看到人工智能产品中提供文字识别接口。注册账号登陆，点击进入通用文字识别即可。

![](../Images/c0a9b0d949cf00c1e4b107f1ede13943.png)

选择立即使用，创建一个应用。会自动生成一些秘钥。

最后点技术文档：

  

![](../Images/2e359f080d211ad48a298b53bbb5c967.png)

选择python-SDK，右方箭头指的是前面生成的秘钥，把这段代码复制下来，然后把接口说明内连接服务器的代码也拷贝下来即可！

![](../Images/0b47cc48f45154bd990c918d6f1f7b03.png)
