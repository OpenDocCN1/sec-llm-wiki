日常工作中我们常常会遇到CC攻击及DDoS网络攻击，以下为大家提供一些平时中工作中较常用的Linux操作系统下网络连接分析命令组合，协助我们判断攻击特征，及时应对处理网络安全问题。

  

信息安全是系统管理员关注的重点。日常工作中我们常常会遇到CC攻击及DDoS网络攻击，以下为大家提供一些平时中工作中较常用的Linux操作系统下网络连接分析命令组合，协助我们判断攻击特征，及时应对处理网络安全问题。

  

![](../Images/d60cf8a56043c8ef85e6fd9978cf857e.png)

  

**1\. 显示所有活动的网络连接**

```
1.  #netstat -na  
    
```

  

![](../Images/ca0365f82e37aa7189b7bac3230b302c.png)

  

**2\. 查看所有80端口的连接数**

```
1.  #netstat -nat|grep -i “80″|wc -l 
    
```

  

![](../Images/a87a1a35fcdbf41fbf0efcfd213d6ecb.png)

  

**3\. 对连接的IP按连接数量进行排序**

```
1.  #netstat -ntu | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -n 
    
```

  

![](../Images/63254864bfde9eab203f4fa898fd7dfa.png)

  

**4\. 查看80端口连接数最多的20个IP**

```
1.  #netstat -anlp|grep 80|grep tcp|awk '{print $5}'|awk -F: '{print $1}'|sort|uniq -c|sort -nr|head -n20 
    
```

  

![](../Images/992f4545de38b0210d6a099d3b8b1a3c.png)

  

**5\. 查找较多time\_wait连接**

```
1.  #netstat -n|grep TIME\_WAIT|awk '{print $5}' |sort|uniq -c|sort -rn|head -n20 
    
```

  

![](../Images/0ae3537db85b6d0713d0f161a0286e82.png)

  

**6\. 查找较多的SYN连接**

```
1.  #netstat -an | grep SYN | awk '{print $5}' | awk -F: '{print $1}' | sort | uniq -c | sort -nr | more 
    
```

  

![](../Images/d0d8f02cf25b31c7d29f093b7fc66dc3.png)

  

**7\. 查看同时连接到哪个服务器IP比较多**

判断cc攻击，使用双网卡或多网卡可用。

```
1.  #netstat -an|awk '{print $4}'|sort|uniq -c|sort -nr|head  
    
```

  

![](../Images/eec15bdab8b329a11e329c0e00d3576f.png)

  

**8\. 查看哪些IP连接到服务器连接多**

可以查看连接异常IP。

```
1.  #netstat -an|awk -F: '{print $2}'|sort|uniq -c|sort -nr|head  
    
```

  

![](../Images/911f3db236a34d46edbf026c3022d982.png)

  

**9\. 显示所有80端口的网络连接并排序**

这里的80端口是http端口，所以可以用来监控web服务。如果看到同一个IP有大量连接的话就可以判定单点流量攻击了。

```
1.  #netstat -an | grep :80 | sort  
    
```

  

![](../Images/3867aa49baae43fb45a77fc832864843.png)

  

**10\. 查找出当前服务器有多少个活动的 SYNC\_REC 连接**

正常来说这个值很小，最好小于5。当有Dos攻击或的时候，这个值相当的高。但是有些并发很高的服务器，这个值确实是很高，因此很高并不能说明一定被攻击。

```
1.  #netstat -n -p|grep SYN\_REC | wc -l  
    
```

  

![](../Images/1720103ddd76ddd82de1f481c9874d8a.png)

  

**11\. 列出所有连接过的IP地址**

```
1.  #netstat -n -p | grep SYN\_REC | sort -u 
    
```

  

![](../Images/48f31635225df3f5d3f8c627f3298a68.png)

  

**12\. 列出所有发送SYN\_REC连接节点的IP地址**

```
1.  #netstat -n -p | grep SYN\_REC | awk '{print $5}' | awk -F: '{print $1}' 
    
```

  

![](../Images/8758bf671c998e2eac45c6ec012c26a5.png)

  

**13\. 使用netstat命令计算每个主机连接到本机的连接数**

```
1.  #netstat -ntu | awk ‘{print $5}’ | cut -d: -f1 | sort | uniq -c | sort -n  
    
```

  

![](../Images/00a789e984288d9a7e556db63d71ad29.png)

  

**14\. 列出所有连接到本机的UDP或者TCP连接的IP数量**

```
1.  #netstat -anp |grep 'tcp|udp' | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -n 
    
```

  

![](../Images/bbe3a84a2d88b71883d056caf92ed209.png)

  

**15\. 检查 ESTABLISHED 连接并且列出每个IP地址的连接数量**

```
1.  #netstat -ntu | grep ESTAB | awk '{print $5}' | cut -d: -f1 | sort | uniq -c | sort -nr  
    
```

  

![](../Images/98b515b3545fb2c26bcd59e88fefca25.png)

  

**16\. 列出所有连接到本机80端口的IP地址和其连接数**

80端口一般是用来处理HTTP网页请求。

```
1.  #netstat -plan|grep :80|awk '{print $5}'|cut -d: -f 1|sort|uniq -c|sort -nk 1  
    
```

  

![](../Images/78c46bf07d8fb3a58a3235dad1e0d053.png)

  

**17\. 显示连接80 端口前10的ip，并显示每个IP的连接数**

这里的80端口是http端口，所以可以用来监控web服务。如果看到同一个IP有大量连接的话就可以判定单点流量攻击了。

```
1.  #netstat -antp | awk '$4 ~ /:80$/ {print $4" "$5}' | awk '{print $2}'|awk -F : {'print $1'} | uniq -c | so
    
```

  

![](../Images/21ebdfb775370a2037b3a536aa3a10ca.png)

  

**18\. 用tcpdump抓包**

```
1.  #tcpdump -i eth0 tcp and port 9000 -C 100 -W 1 -w /tmp/9000.pcap 
    
```
