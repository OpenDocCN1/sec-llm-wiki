## 前言

**SSH是一种可以让你在不安全的网络上，安全的运行网络服务的网络协议的.ssh的标准TCP端口为22端口，其最佳应用场景是用户远程登录至计算机系统。因此，SSH端口也是攻击者必扫的端口之一。本文将就SSH端口的安全性展开讨论，并为大家提供多种保护SSH端口安全性的建议和方法。**

在开始之前，让我们先在计算机上安装SSH服务器。命令如下：

  

> ```

> ```

## 公钥保护

首先，我们需要下载并安装PuTTY Key Generator。

注： PuTTYgen是一个密钥生成器，用于为PuTTY创建SSH密钥并且以自己的格式存储密钥（.ppk扩展名）

打开它，然后单击生成。

  

![](../Images/4024d9f2ae07fcafbd1b0d528443caff.png)

  

  

单击生成将启动生成公钥和私钥的过程，如图所示：

  

![](../Images/ac34106e14db735abb17aa5ac851d0df.png)

  

生成公钥和私钥后，单击“保存公钥”。这会将密钥作为一个公钥保存。

  

![](../Images/cb8646fff30b7f890a7d2d2c1da2325c.png)

![](../Images/ceb435eea348b70844647d128a8ffe3f.png)

  

在终端中，进入.ssh文件夹并键入以下命令：

  

> ```
> 
> ```

  

此命令将会生成一个密钥。

![](../Images/5b7392730c97c7840ad2ac868a3524cf.png)

## Google身份验证器

要通过SSH服务器进行双因素身份验证，你需要在手机上下载安装Google Authenticator，并使用以下命令为Ubuntu安装所需的依赖包：

  

> ```
> sudo apt-
> ```

  

注 – Google Authenticator在安装过程中会有多次询问，你只需选择是即可。

  

![](../Images/d37e233bd728cf5820d35277b5e33481.png)

  

安装完成后，打开终端并输入命令：

  

> ```
> google-authenticator
> ```

此时，将会生成一个二维码，我们使用手机上的Google Authenticator进

行扫描。

  

![](../Images/21989b7d4c569ff7f11011937b95b2a5.png)

  

成功扫描后，它将为我们生成一个动态口令，如图所示。

  

![](../Images/4f115c805805d0caa811d12c771adb4c.png)

  

  

现在，我们使用的gedit命令打开sshd的文件并进行以下更改：

  

> 在@include common-auth前添加注释符；

> 添加行（auth required pam\_google\_authenticator.so）到@include common-password下。

如图所示：

  

![](../Images/1541d8c5d7bffa1bb3635b500e15626e.png)

  

继续更改的sshd\_config文件中的以下选项。

  

> ChallengeResponseAuthentication yes

  

![](../Images/c44e775815a14f53cedc7ccbb52f2083.png)

  

现在，当我们登录SSH服务器时，它会提示要求输入验证码。这里，我们必须输入在Google Authenticator上生成的动态口令。如下所示，我们已经使用一次性密码成功登录至SSH服务器。

  

![](../Images/8b8d11fb1c55c3bedc665bbb518d8af8.png)

## 禁用空密码

从安全最佳实践来看，我们应该始终禁用空密码登录SSH服务器要启用此设置，我们只需将sshd\_config的文件的以下选项参数值更为号即可：

  

> PermitEmptyPasswords no

这将禁用空密码登录SSH服务器。
