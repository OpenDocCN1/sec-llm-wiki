**Camelishing是一款成熟的社会工程学工具，通过分析其安装与使用，可以找到合适的应对方法。**

## 特性

> 批量发送电子邮件
> 
> 基本的Python代理创建器
> 
> Office Excel宏创建器
> 
> DDE Excel创建器（或自定义Payload）
> 
> 返回信息：\[邮件打开跟踪\] \[代理打开跟踪\]
> 
> 自动保存
> 
> 统计报告
> 
> 用户控制

## 安装模块

  

> ```
> $ pip install -r requirements.txt
> $ Install Microsoft Office
> ```
