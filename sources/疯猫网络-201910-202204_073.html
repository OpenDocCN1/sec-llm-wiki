信息收集

首先使用arp-scan扫描资产：

arp-scan --interface=eth0 192.168.226.0/24


发现目标主机192.168.226.133，使用nmap做进一步端口扫描：

nmap -sC -sV -p- -sT 192.168.226.133


如上图所示，开启的服务很少，除了 22 和 80 外，还开启了 139、445 和 10123。其中 139 和 445 上运行的是 Samba 服务，说明目标机可能是一个 SMB 服务器。10123 口上是一个Python搭建的HTTP服务。


SMB（服务器消息块）是一种协议，它允许同一网络上的资源共享文件，浏览网络并通过网络打印进行。它最初用于 Windows，但 Unix 系统可以通过 Samba 使用 SMB。今天，我们将使用名为Enum4linux的工具从目标中提取信息，并使用smbclient连接到SMB共享并传输文件。

通常，服务器上有 SMB 共享驱动器，可以连接到该驱动器并用于查看或传输文件。在极端情况下，例如当SMB共享目录和Web服务器根目录相同时，攻击者甚至可能利用这种错误配置来实现代码执行。

现在，我们已经使用 Enum4linux 收集了有关目标的一些信息，我们可以使用 Smbclient 工具来与系统上的 SMB 进行交互交互。


Smbclient 是一种用于访问服务器上 SMB 的工具，就像 FTP 客户端一样，用于访问文件一样。它提供了一个简单的资源命令行界面，如果您完全了解 FTP 的话，可以轻松使用。

smbclient //192.168.226.133/welcome -U '' -N

  • -U：标志指定用户名（在匿名登录的情况下为空白字符串）

  • -N：指定无密码

Linux Container（LXC）通常被认为是量级虚拟化技术，比较合适的Chroot和完整开发的虚拟机之间，LXC可以创建一个良好的Linux操作系统十近的环境，而不需要使用到一种较轻的Linux Daemon（LXD）是一个轻量级容器管理程序，而LXD是基于LXC容器技术实现的，而这种技术之前的Docker也使用过。LXD使用了稳定的LXC API来完成所有的后台容器管理工作，并且增加了 REST API 支持，更进一步地提升了用户体验度。

LXD 是根进程，它可以主要执行任意用户很多的 LXD UNIX 主要用于访问操作。而且在某些情况下，LXD 也不会对调用它的用户权限进行检查和匹配，现在社区也有种方法可以利用 LXD 的这种特性来实施攻击。

成功的，攻击者可以将低权限的用户提升为Root权限，并且能够在不受任何限制的情况下访问目标系统的各种数据资源，避免Docker特权模式逃逸。
