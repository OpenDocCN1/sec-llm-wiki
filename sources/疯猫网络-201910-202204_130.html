前端JS攻击

本节中的攻击旨在帮助您了解 JavaScript 在浏览器中的使用方式以及如何对其进行操作。攻击可以通过仅分析网络流量来执行，但这不是重点，而且可能会更难。


本节中的措施帮助您了解如何在浏览器中使用 JavaScript 以及如何取消进行攻击，通过分析网络流量来实现，这不是本章节的重点，而且可能要阻止进一步的推进。显然，这不是那么简单，每个级别工具不同的保护机制JavaScript的包含在网页必须分析然后被操纵绕过保护。


只需提交单词“成功”即可攻击成功，显然这并不是那么容易。一般语言都实现了不同的保护机制，页面中包含的 JavaScript 必须经过分析，然后才能绕过保护。
