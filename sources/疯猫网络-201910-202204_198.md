一、使用“P2P终结者”工具进行ARP欺骗攻击

  

**实验环境：**  
这里我用Windows 7做攻击机，Windows server 2003做受害者机。  
要实现ARP欺骗攻击的条件是攻击机与受害者机一定要在同一个网段，这里自己设置下步骤：  
先尝试ping通，待会在查看mac地址表的时候才可以查看到mac地址，这是arp协议的原理。  
然后查看靶机当前的mac地址表。我们攻击的机子IP地址为10.10.66.136。mac地址表中是这样的。

  

![](../Images/1d6e7bf669216b31e1585699b19733d7.png)

  

接下来在攻击机中使用“P2P终结者”软件对Windows server 2003

进行ARP欺骗攻击  

这里先点击扫描网络，然后扫描到受害者的IP地址后，勾选它，勾选完受害者后点击启动提速。

  

![](../Images/09fde70c46e5780860b6b676e567e1e5.png)

  

在受害者使用命令arp查看MAC地址表变化情况，可以看到网关的MAC地址改变成和攻击机一样了。

  

![](../Images/9cd571632fe776b9e6c18706aa32cd63.png)

  

受害者远程登录route-server.ip.att.net服务器（输入账号密码）

  

![](../Images/680b560551294bbf23e50ed536e7000d.png)

![](../Images/855f156a97a323467655c39ad6f809ce.png)

  

然后成功登录。这里使用wireshark抓取arp与telnet数据包

  

arp数据包：

  

![](../Images/64eaf9ea228bac783b3b16f7c8ccb2b7.png)

  

telnet数据包：

  

![](../Images/0c5f1b32358093aa17a94003fc87c06e.png)

  

这里可以看见欺骗成功，受害者机telnet的数据包可以被我们所看到，然后我们右键点击追踪TCP流，还可以看到用户登录的用户名和密码。

  

![](../Images/dcc8c1b2886f8e69f4cd0abf2ab18075.png)

  

二、使用“Cain”工具进行ARP欺骗攻击

实验环境：

这里我用Windows server 2003做攻击机，Windows XP做受害者机。  
要实现ARP欺骗攻击的条件是攻击机与受害者机一定要在同一个网段，这里自己设置下。

  

**步骤：**  

利用Cain工具进行ARP获取账号信息

  

![](../Images/0b895aecf463f4191a9849233e8b73ab.png)

  

首先在攻击机上，使用命令“ipconfig /all”查看主机IP地址、MAC地址信息

  

![](../Images/596b2ef49d52f901295a0957ed598097.png)

  
查看受害者机IP地址及MAC地址信息

  

![](../Images/9354203a7e07c4547d1185fa51188986.png)

  

在受害者机使用命令进行ping的命令，检查客户机与主机是否

  

![](../Images/16891e467d8b966d574cb3c149c30ca5.png)

  

在攻击机上安装软件Cain工具

  

![](../Images/a1925763a9542bb7b2dd8653751f4abd.png)

  

然后要开始使用工具了

打开软件第一次使用界面

  

![](../Images/c0ba305ec407138be7d68df64e0a543b.png)

  

选择操作  

  

![](../Images/5be396202ba906397c5bf4f91980fb26.png)

  

根据MAC地址进行扫描，保持默认值，扫描整个网段

  

![](../Images/03506c3a973717d63da1fe206f05705f.png)

  

![](../Images/477a0e724b4219e97a5c33232ff139e8.png)

  

添加ARP客户机地址及所对应的MAC信息

  

![](../Images/dd21143f1f32bc6e3b60ae2d8751fa3d.png)

![](../Images/fd0fdcc07ab007a5ec178bfcc2eb9bf1.png)

  

受害者机打开浏览器，随便打开一个网站正常登录测试一下

  

![](../Images/b8d63d7fd30960b7f2d50714c0288894.png)

  

然后返回到攻击机上去查看ARP窃取到的信息

  

![](../Images/651ce373f291a54273eb03df861c71f2.png)

  

窃取到了账号以及Password的MD5值，说明ARP窃取成功。这里就可以去网上的MD5解密得到密码了。

![](../Images/ad0b2457a1a57e78981c13ba9a54d3a2.png)
