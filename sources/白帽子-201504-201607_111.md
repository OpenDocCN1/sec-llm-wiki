# 越权修改也能获取用户信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDQwNTE5MA==&mid=402535769&idx=1&sn=3e457f3cd70f0242e34be1ce2211c7ef&chksm=08e3eef03f9467e64c43fde84a41523bfd6e836d2b718da563c6dcb541d1d94f3d780ac8ad33&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDQwNTE5MA==&mid=402535769&idx=1&sn=3e457f3cd70f0242e34be1ce2211c7ef&chksm=08e3eef03f9467e64c43fde84a41523bfd6e836d2b718da563c6dcb541d1d94f3d780ac8ad33&scene=27#wechat_redirect)

  

        大家都知道，查看功能越权，加上id可以遍历时导致获取所有用户的信息，但如果是越权修改呢，只能把其他用户的信息替换掉，并不能获取对方的信息。

  

        比如会员资料、收货地址虽然存在越权修改，但对攻击者来说并不能拿到有用的信息，从这一层面上来说，利用的价值不高。

  

        不过也有另外,在越权修改后却能获取用户原来的信息。

  

        在一次测试中，修改常用旅客信息时存在越权，改为其它ID修改成功后，自己多了一条记录，查看信息是自己填写的，但发现“身份证”处未填写却有数据，猜想是未填写的情况下会保留原来的信息。

  

![](../Images/2ddce05e8971049f66aebe7a4858ba52.png)  

  

        于是再次修改抓包，把所有字段都清空，或者把字段名称改掉，如图：

  

![](../Images/09db16b841eb47adae1037a3751b8cf9.png)  
  

        正如所想，未填写的字段都保留了原来的信息，这样的话可以遍历所有的id而获取其他用户的资料。

  

![](../Images/560a0a84ad614797f5c78b295c466a30.png)  

  

        为什么？

        我想程序代码可能是这样的：

  

        $sql="update 表名 set mobile=if('POST存在','POST数据','原数据'),userid=".session\['userid'\]." where  address\_id=".$\_GET\["address\_id"\]

  

        把用户传过来的地址id更新至当前登录用户，如果用户提交字段为空不替换，并且未校验address\_id是否属于当前登录用户。
