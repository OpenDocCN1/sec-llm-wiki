以自定义模块扫描来做例子：

点击模块按钮，就会进入到下图显示的界面：

Settings /Basic / General这里可以添加扫描的名称，标注，已经该扫描放到哪个文件夹中（默认只能选择My scan 和Trash这两个文件夹中），target中可以输入一个目标或者多个目标，用，隔开就行了，如果觉得输入麻烦，还可以点击下面Upload Targets直接上传文件，加载扫描目标。


Settings / Basic / Schedule：这里可以设置这个扫描是否建立一个时间表，例如在某个时间段开始扫描。


Settings / Basic / Notifications：当扫描完成时，生成通知到SMTP服务器上，以便了解扫描情况。


Settings / Discovery / Host Discovery


常规设定中：

可以选择 Test the local Nessus host 该设置指定本地Nessus主机是否应该被扫描时落在目标范围内指定的扫描（也可以设置以本地nessus扫描器来进行扫描）。

也可以选择 Use fast network discovery 该设置是为了避免一个扫描器在扫描的时候，为了避免扫描目标返回的数据有误，导致扫描器判断错误，可以额外添加一个扫描器，通过不同的网络状况来验证响应来，加强扫描判断的准确性，也可能通过这样的外部响应来验证现有的扫描结果，也许可能有新的发现。


这是可以修改ping包的发送的类型，该功能是为了验证目标是否存在的办法，通常默认就可以的了，但是有的情况下，可能内部网络有防火墙等其他安全设备，导致即使目标存在，但是安全设备拦截了这些包的回包，导致返回目标不可达，这里可以设置成其他的协议，来加强对目标发现的可靠性。


Fragile Devices 可以理解成脆弱的设备，在扫描环境里面，有的系统或者网站，可能由于性能等其他问题，一旦过多的数据量会导致目标，系统不正常等其他不确定因素，这里可以选择扫描网络上的打印机或扫描网络操作系统的主机，这样选择后，扫描器会针对不同的选择进行调整。


Wake-on-LAN 可以理解成 网络发觉扫描目标的设置

List of MAC addresses 通过加装MAC地址来，发现扫描目标，通常来说都是通过IP来查询到目标的MAC地址，但是这样的过程会发送一个广播包的ARP包来获取到目标的MAC地址，如果在高安全性的环境下，这样的操作有可能被IDS发现记录下来。

Boot time wait (in minutes) 这里可以设置扫描器启动这样的网络发觉等待回包的等待时间。


Network Type 

网络类型


通常默认是混合型的，通过验证请求注解，来确定当前出于的网络类型，也可以选择为private LAN 私人局域网和private WAN 私人广域网，但是我觉得在实际使用的时候，这个可以使用默认的，因为两者之间的区别已经越来越小了。

Settings / Discovery / Port Scanning


Ports 端口

这里可以设定，Port scan range:这里也可以设置特定需要扫描的端口。


Local Port Enumerators 本地端口开放情况：

这里可以设置，当扫描器扫描时，扫描存活的活端口，可以针对特定的例如是TCP端口进行扫描的，恰当的配置，也可以一定程度上提高扫描的准确性和对减低对扫描系统的数据量。


Network Port Scanners 网络端口扫描器：

这里可以选择端口扫描器选择用什么协议来去扫描端口，由于的有的环境，可能会拦截SYN包，即使目标端口是存在的，但是它不返回任何的数据包，导致误判该端口是关闭的，但是如果选择UDP包，由于UDP协议本身的原因，有可能导致端口的误判。

Settings / Discovery / Service Discovery


这是扫描器服务器的登陆SSL设置，通常默认是如上图所示的，也可以根据需要进行调整，如ssl证书的过期时间，以加强安全性。

Settings / Assessment / General


Accuracy 精确性：

这里是为了提高扫描器的准确性，进行调整的，Override normal accuracy 

覆盖正常的准确性 这里可以选择是否覆盖Avoid potential false alarms（避免潜在的假警报）或者Show potential false alarms（显示潜在的假警报），也可以选择Perform thorough tests (may disrupt your network or impact scan speed）进行彻底的测试(可能会扰乱你的网络或扫描速度的影响）。


Antivirus 防毒：

可以设置Antivirus definition grace period (in days) 防病毒定义宽限期(天)，默认是没有限期时间的。


SMTP:

可以设置SMTP服务器来，查看警报文件。

Settings / Assessment / Brute Force


Brute Force 强力设置

默认是使用这个的Only use credentials provided by the user（用户只使用所提供的凭据）如果使用oracle 数据库这个选项的话，使用测试默认账户(速度慢)。

Settings / Assessment / Web Applications


默认是不开启的，但是如果想修改下，每次请求包里面的设置，可以打开来修改的。

Settings / Assessment / Windows


Request information about the SMB Domain（请求信息SMB领域）至于SMB是什么请谷歌。


Enumerate Domain Users （列举域用户）：

这里可以设置枚举域用户的UID的范围区间。


Enumerate Local Users（列举本地用户）：

这里可以设置枚举本地用户的UID的范围区间。


Malware Files（恶意软件文件）：

Provide your own list of known bad MD5 hashes（提供自己的列表的坏MD5散列），Provide your own list of known good MD5 hashes（提供自己的已知好MD5散列的列表），Hosts file whitelist（主机文件白名单），这里面前两个是提交被恶意软件文件攻击后文件生成的MD5值和没被攻击之前的文件的MD5值，主机文件白名单是为了减少扫描器的工作量，防止被误杀了。


Malware Settings（恶意软件设置）：

Disable DNS resolution（禁止DNS简析），检查该选项将防止Nessus使用云比较扫描结果与已知的恶意软件。


Processing（处理）：

默认是不开启的：Override normal verbosity（覆盖正常的冗长）这里可以选择I have limited disk space. Report as little information as possible（我有有限的磁盘空间。尽可能少的信息报告）或Report as much information as possible（报告尽可能多的信息），

默认开启的是：Show missing patches that have been superseded（显示已经取代缺失的补丁）和Hide results from plugins initiated as a dependency（隐藏的结果作为一个依赖插件启动）。


output（输出）：

默认开启的是：Allow users to edit scan results（允许用户编辑扫描结果）

默认不开启的是：Designate hosts by their DNS name（指定主机的DNS名称），Display hosts that respond to ping（显示响应ping主机），

Display unreachable hosts（显示主机不可到达的）。


General Settings（基本设置）：

默认开启的是：Enable safe checks（启用安全检查），

默认不开启的是：Stop scanning hosts that become unresponsive during the scan（停止扫描主机扫描期间变得反应迟钝），Scan IP addresses in a random order（扫描IP地址在一个随机的顺序）。

Performance Options（性能设置）：

默认不开启的：Slow down the scan when network congestion is detected（当检测到网络拥塞或减缓扫描），Network timeout (in seconds)（网络超时(秒)）为5秒，Max simultaneous checks per host（最大同时检测的主机数）5台，

Max simultaneous hosts per scan（最大同时扫描的主机数）5台。

默认没设置的：Max number of concurrent TCP sessions per host（最大每个主机最大并发TCP会话），Max number of concurrent TCP sessions per scan（最大每个扫描并发TCP会话的数量）。


Debug Settings（调试设置）：

默认没开启的：Log scan details to server（服务器日志扫描细节），

Enable plugin debugging（启用插件的调试）。
