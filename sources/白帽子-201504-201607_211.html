微软Security Essentials在病毒查杀测试中获得高分

原文：http://mp.weixin.qq.com/s?__biz=MzAwMDQwNTE5MA==&mid=400234347&idx=3&sn=a89c9bdb8f17e44bf43f999e939ca59e&chksm=08c6ccc23fb145d41424fa45046a262ac76df8c4291893950526cfc7c5687ba27f97536116f0&scene=27#wechat_redirect

一般认为，微软Security Essentials（MSE）不是最好的防病毒解决方案，它只是一个基本的杀毒产品。但是现在由丹尼斯技术实验室进行的一系列测试显示，MSE取得了令人难以置信的成绩。其中，合法准确性测试得分达到了100%，全部查杀准确性达到95%，这使得MSE成为市场上顶级安全解决方案之一，与卡巴斯基，诺顿，ESET和趋势科技平起平坐。

微软杀毒软件MSE，目前免费提供给运行Windows Vista或Windows 7的用户，并且是Windows 8和Windows 10内建的Windows Defender一部分，获得AAA奖项，这是在上述测试中安全产品可以获得的最高等级奖项。

更具体地说，MSE在精度试验中得到全部1020点当中的964点，这意味着它可以检测和阻止95%的威胁。卡巴斯基和诺顿安全可以阻止100%的威胁，其次是ESET的 99%，而Trend Micro可以阻止98%的威胁。

在防护等级方面，卡巴斯基再次得到了300分满分，微软Security Essential只得到到244分。丹尼斯技术实验室表示，总体而言，考虑到每个产品同时处理恶意软件和合法应用程序的能力，最终获奖者是卡巴斯基 Internet Security 2015，诺顿Security和ESET Smart Security 8。趋势科技和微软的产品紧随其后，全赢AAA奖项。

不用说，微软必须是自豪的是，它的防病毒软件居然在测试中表现如此之好，尽管微软公司本身承认MSE仅仅提供基本的防毒保障。
