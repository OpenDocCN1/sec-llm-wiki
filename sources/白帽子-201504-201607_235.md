# 维基解密宣布公开CIA局长邮箱内机密内容

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDQwNTE5MA==&mid=400080360&idx=2&sn=aa5ab7eb11e22cdcd61d13e1318ece65&chksm=08c566413fb2ef5796d98ee80b89944506b1e48935c2feedc31432a2224a4820db965589f410&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDQwNTE5MA==&mid=400080360&idx=2&sn=aa5ab7eb11e22cdcd61d13e1318ece65&chksm=08c566413fb2ef5796d98ee80b89944506b1e48935c2feedc31432a2224a4820db965589f410&scene=27#wechat_redirect)

就在《纽约邮报》报道了美国CIA局长John Brennan邮箱遭少年攻击后没几天，维基解密宣布，他们获得了该邮箱里的信息并计划在本周内公开。维基解密称：“John Brennan于2013年3月取代David Petraeus将军成为中情局局长，后者因深陷机密信息处理不当丑闻而卸任。”据悉，Petraeus将八本承载机密信息的“黑色笔记本”交给为其撰写自传的作家、同时也是其情妇的Paula Broadwell。

![](../Images/917833aad45e10555c64d86d4966a242.png "john-brennan.jpg")

在接手CIA局长一职之前，Brennan曾是白宫反恐顾问。

而在维基解密发表这份声明的同时，网站已经公布了6份来自Brennan邮箱的文件。前两份信息非常全面，涵盖了Brennan在成为CIA局长之前接受的安全调查以及CIA和The Analysis Corportaiton之间的法律辩论。另外四份文件内容相对单薄一些，全部加起来也只有10页。不过最后两份文件的标题倒是令人心中一颤，它们都谈到了torture（酷刑），在CIA看来，酷刑是一种收集信息的可靠工具。

接下来，维基解密还将公布更多来自Brennan邮箱的文件。
