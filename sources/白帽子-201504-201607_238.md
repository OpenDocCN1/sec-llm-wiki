# 科索夫黑客向ISIS递交美国军方人员的敏感信息，将被判35年

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDQwNTE5MA==&mid=400053229&idx=1&sn=99816f4b6bf30c3d6ab4b9f149a54c95&chksm=08c588443fb20152a848cfb568645820b65e5c9458bd93169dcfeac9fd4ffd0f58b3aead8880&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDQwNTE5MA==&mid=400053229&idx=1&sn=99816f4b6bf30c3d6ab4b9f149a54c95&chksm=08c588443fb20152a848cfb568645820b65e5c9458bd93169dcfeac9fd4ffd0f58b3aead8880&scene=27#wechat_redirect)

马来西亚当局在吉隆坡逮捕了一名科索夫公民，原因是他入侵了某公司电脑、并向ISIS（ISIL）提供美国军方人员的个人信息。  

据美国司法部门（DOJ）、FBI指出，科索夫公民Ardit Ferizi涉嫌入侵了美国web托管商的服务器，窃取超过1300个美国政府和军事职员的个人信息。Ferizi并没有用这些数据进行身份盗取；相反他却将这些数据递交给了Junaid Hussain（又叫Abu Hussain Al Britani，是一名ISIS成员，也是在美国空袭中击毙的黑客）。

窃取的数据包括姓名、邮件地址、密码、手机号、美国军事人员和政府人员的地理位置。

Ferizi将面临35年的有期徒刑

据弗吉尼亚的起诉，Ferizi还从美国一个未知名的网络供应商那里访问了客户信息，并获得了10万用户的信用卡数据。

Ferizi目前已被马来西亚当地政府拘留，稍后会引渡到美国面临指控。如果罪名被证成立，他则可能会面临35年的有期徒刑。

史上最粗心的黑客

Ferizi可能是至今为止见到的最为粗心大意的黑客：

```
1.推特账户使用的是自己的真实名字；
2.用推特公开与ISIS成员进行交流；
3.从来不隐藏自己的真实IP地址；
```

Ferizi，作为Kosova Hacker's Security (KHS)黑客组织的领导，经常使用@Th3Dir3ctorY推特账号与Hussain和Abu Hussain Al Britani（ISIS成员）交流沟通。而且Ferizi在入侵美国一家公司服务器时，使用的登录名为KHS，FBI推测很可能就是Kosova Hacker's Security (KHS)黑客组织的首字母缩写。
