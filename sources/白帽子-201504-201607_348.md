# 利用 Raspberry Preserve 将你的文件备份在玻璃瓶里面

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMDQwNTE5MA==&mid=209415247&idx=4&sn=797da4618237aba83bc93851764ce2e2&chksm=1366b7e624113ef026d3798e74c8f1782ee4dae2bfb4c85c4ac2b6c609be7071aaa8d3b6c034&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMDQwNTE5MA==&mid=209415247&idx=4&sn=797da4618237aba83bc93851764ce2e2&chksm=1366b7e624113ef026d3798e74c8f1782ee4dae2bfb4c85c4ac2b6c609be7071aaa8d3b6c034&scene=27#wechat_redirect)

你喜欢像 Dropbox 或者 Box 这种备份软件的概念，但是不想将自己的数据交给其他人控制？现在你就可以将自己的文件安全地保存在家里的食品室里面，放在装着水果和蔬菜的罐子旁边。

一位创意十足的 DIY 爱好者巧妙地将一 台运行 BitTorrent Sync 软件的树莓派装进了一个常见的玻璃梅森瓶里面 。他制作出来的成果就相当于一个自制的备份服务，它可以在你的所有设备之间同步文件。

在软件设置方面，你只需通过 SSH 进入树莓派，然后 安装 树莓派版本的 BitTorrent Sync（它有一个恰到好处的名字“Raspberry Preserve”）、Node.js 和其他几个软件包。你还可以为树莓派连接额外的 LED 灯，让它们在数据传输的时候进行闪烁或者保持发光。

虽然原来的制作者选择将他的玻璃瓶安装在一个木制的底座上，但是你自己也可以决定这个设备的最终外观。

BitTorrent Sync 的开发团队之前曾经开发过 BitTorrent。我们可以简单地把这个软件看成是像 BitTorrent 一样的 P2P 网络，但是这个网络中的所有节点都是你的设备。如果你在笔记本电脑上的共享文件夹添加了一个新文件，它就会被同步到树莓派上的节点，然后共享给你的手机、桌面电脑等设备。

由于这个解决方案是完全以树莓派为基础的，所以它基本上可以实现用户想要的任何扩展。例如，你可以安装一个额外的硬盘来提升玻璃瓶的储存容量，或者连接一个 USB WiFi 扩展，这样玻璃瓶就不需要使用网线连接了。
