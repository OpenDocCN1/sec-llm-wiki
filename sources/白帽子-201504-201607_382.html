微软Windows 10发布会跟以前大不同

Re/code中文站 7月21日报道

多年以前，人们也曾像现在等待最新款iPhone一样披星戴月地排队等候最新版Windows。

20年前，比尔·盖茨（Bill Gates）和杰·雷诺（Jay Leno）在 微软 总部举行了Windows 95的 盛大 发布会，很多极客早早地就在外面排队，只为尽早买到最新版Windows系统。

Windows 10将在本月晚些时候发布，但是很多年以前的那种万人空巷的场景肯定不会再现了。不会有人提前排队，甚至都不会出现盒装软件。微软将于7月29日正式发布Windows 10系统，Windows 7和Windows 8的用户将可以免费升级到Windows 10系统。最早一批获得该软件的是参与了软件测试的用户，然后是注册了升级资格的用户。最后，能够运行Windows 10系统的所有家用PC都将获得免费升级的机会。

付费版Windows 10将通过光盘和U盘来发行，但是这些产品不会在新软件发布当天出现在微软商店里。要想在7月29日当天拿到最新版Windows 10，最实际的做法就是买一台新电脑。然而这样的机会也不会很多，因为很多公司会将最新款PC暂时留下来，直到学生返校时和其他节日时才会放出来。

Windows 10发布方式的变化表明微软发生的变化肯定不小。自从上个世纪八十年代以来，Windows第一次发现自己转变成了守势，它的很多份额都被Mac抢走了。即便是它曾经的坚固堡垒即企业计算也遭遇蚕食。

为了与时俱进，微软正在摆脱旧的习惯。它正在从销售盒装软件向软件升级服务转变，微软发现 谷歌 (微博)正在不间断地升级Chromebook，而 苹果 也是一年对Mac进行一次操作系统升级。

因此，不要以为Windows 10的发布会将是一次热热闹闹的、象当年发布Windows 95一样的盛会。

可以肯定的是，Windows发布会已经很久没有引起大多数人的关注了。Windows 8和Windows 7发布时都没有用户排队的现象，Vista就更不用提了。

但是Windows 10的发布会将转变得更加彻底。微软不会安排高管到纽约去向记者们发表演讲，而是准备在13个城市面向粉丝们搞些活动，包括北京的水立方、南非约翰内斯堡的玛丽·菲茨杰拉德广场以及曼哈顿的某个屋顶。

这并不是说Windows 10的发布对微软不重要。实际上该产品对于微软来说相当重要，尤其是市场对Windows 8及其完全不同的界面的反应比较淡漠。微软急需一款畅销产品来打气。但是产品发布后的几个月内的销量比发布会当天到场的粉丝数量更加重要。为此，微软并未改变发布新款Windows时同步大肆宣传的传统做法。

最后版本的Windows？

Windows 10打算填补Windows 7和Windows 8之间的缺口，增加对移动应用的支持，同时保留经典的Windows界面。它还将用一款全新的Edge浏览器替换掉老旧的IE浏览器，以及引进最早出现在Windows Phone平台上的Cortana助手。

另外，Windows 10还将整合之前分散在不同设备上的一些软件。Windows 10可以兼容一大批设备，包括PC、平板电脑、手机、Xbox甚至某些全新的设备比如HoloLens虚拟现实头盔。微软希望这种广泛的兼容性可以吸引开发者，因为以前开发者们必须为不同的设备分别编写不同版本的同一款软件。

当然，还有以前提到过的将Windows从一种软件转变成一种服务。为了让人们不至于忽视这一变化，微软要求安装了家用版Windows 10系统的消费者允许公司自动更新他们的系统。

微软所作的这些努力到底能够取得什么样的效果还有待观察。某些人甚至说Windows 10将会是最后版本的Windows，因为微软以后将提供持续的更新。

虽然Windows 10承诺会进行频繁更新，但是现实是改变计算通常需要进行巨大的转变，这绝不仅仅是通过下载补丁来更新现有的系统那么简单。一个全新的版本可以给微软提供一个更好的营销机会，而这是传统更新无法提供的。

因此，保险地说，虽然我们现在还不知道下一个版本的Windows到底会在何时发布，但微软绝对不会在Windows 10这里止步。（林靖东）
