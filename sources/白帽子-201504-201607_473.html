由于linux服务器允许多用户登录，公司很多人知道密码，工作造成一定的障碍所以需要有时踢出指定的用户

1/#who 查出当前有那些终端登录（用 w 命令更详细）

# whoroot pts/0 2010-10-28 09:36 (192.168.1.236)

root pts/2 2010-10-28 09:40 (192.168.1.27)

root pts/3 2010-10-28 10:02 (192.168.1.82)

root pts/4 2010-10-20 16:06 (192.168.1.244)

2/我想踢出IP为82的登录，其对应的tty为pts/

3# pkill -kill -t pts/33/

再次查看# whoroot pts/0 2010-10-28 09:36 (192.168.1.236)

root pts/2 2010-10-28 09:40 (192.168.1.27)

root pts/4 2010-10-20 16:06 (192.168.1.244)

已成功踢出用kill如何剔除linux在线用户

（1）查询当前登录用户 [root@firewall ~]# finger 或者who Login Name Tty Idle Login Time Office Office Phone root root pts/0 May 4 23:19 (172.1.4.1)

（2）查询某个登录用户的所有进程

[root@firewall ~]# ps -ef | grep pts/0 root 3140 2070 0 23:19 ? 00:00:00 sshd:

root@pts/0 root 3142 3140 0 23:19 pts/0 00:00:00 -bash

root 3195 3142 0 23:24 pts/0 00:00:00 ps -ef

root 3196 3142 0 23:24 pts/0 00:00:00 grep pts/0

（3）干掉登录用户Shell 进程 kill -9 3142
