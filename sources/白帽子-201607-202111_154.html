https://www.vultr.com 一个挺有名的vps服务商  用邮箱注册，支持支付宝 watch付款。

支付自定义iso安装。可以利用这个安装kali渗透测试系统。


2

购买vps


         vps根据自身实际需要，包括性能使用途径。按需求选择。实际上这个服务器费用我觉得还是比其他平台偏搞。有条件的可以选择尝试。注册好帐号后。

来到这个页面  https://www.vultr.com/products/cloud-compute/ 选择合适的vps


一般情况下我建议选择 1cpu 2gb内存 2tb流量流量超过可以购买选择好之后点击进去查询详细参数。

选择 deploy now （部署）的意思 这个时候你还没有充值。首先充值10美元

https://my.vultr.com/billing/


选择alipay 或者wecaht pay 使用信用卡会有折扣，本人选择alipay （支付宝），它将会调到支付页面，付款后你的帐号就会多出10美元

https://my.vultr.com/billing/#billinghistory 来到这个页面查看你的充值情况。

充值之后来到这个页面增加自定义iso

https://my.vultr.com/iso/ 在点击add填写iso的地方把最新版的kali下载地址填写进去

https://kali.itsec.am/kali-images/kali-2020.4/kali-linux-2020.4-installer-amd64.iso

点击upload 它将会下载最新版本的kali到这个镜像库里。

点击 deploy new server

选择 tokyo  、upload iso 选择myiso kali


来这个页面点击view cosole 进去远程页面安装系统

这里点击Graphical install  进入界面后选择中文简体或者你喜欢的英文。接下来与我们安装的kali操作并没什么区别。密码设置复杂一些，因为我们要开开启ssh服务

一直下一步之后我会把一些容易操作错误的我会重点列出来。

这里一定要选择是。

这里一定要选择对不然启动会失败。安装完成后，启动之后还是安装界面

这个问题的解决方法，先把vps停止，把iso移除就好了重新启动进去小电视那个图标进去远程控制页面

输入账号和密码就可以登录系统。

接下来做一些细微的调整。

将power设置成自动挂起关  空白屏幕从不这样kali就不会突然访问不了。

3

开启配置ssh


这样配置已经差不多了，最后开启ssh 让root登录 以后就用xshell远程管理。
gedit /etc/ssh/sshd_config
将#PasswordAuthentication no的注释去掉，并且将NO修改为YES //kali中默认是yes
将PermitRootLogin without-password修改为
PermitRootLogin yes
最好将端口也修改。你也可以设置无钥匙登录
新版的kali不用开 直接设置ssh即可
设置ssh自启动
update-rc.d ssh enable  //系统自动启动SSH服务
update-rc.d ssh disabled // 关闭系统自动启动SSH服务
启动ssh
/etc/init.d/ssh start

启动msfconsole 没问题，至此我们就有了一个在外网的kali系统。有kali就可以做很多事了。
