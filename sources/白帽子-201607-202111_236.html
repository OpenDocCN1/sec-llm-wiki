今天来分享点关于RapidDNS使用的小技巧，加快使用效率。


Linux 命令快速查询


将以下命令加入到 bash_profile文件中。


rapiddns(){
	curl -s "https://rapiddns.io/subdomain/$1?full=1" \
	| grep -oP '_blank">\K[^<]*' \
	| grep -v http \
	| sort -u 
}


然后后面就可以使用rapiddns命令直接查询结果。

rapiddns tesla.com


浏览器搜索引擎快速查询

linux下的命令行非常强大，那么windows下呢？对于可视化界面下，我们可是利用Chrome浏览器的搜索引擎功能来简化查询。

我们打开Chrome浏览器的设置，然后找到 管理搜索引擎 ，在点击 添加 按钮，弹出如下窗口并图中配置设置：


设置完成后，以后打开浏览器，直接输入rds +{TAB}键，然后输入要搜索的域名按回车即可。



如果想查看所有，在上图的网址设置中加入加入 ?full=1  参数即可，如果要直接弹出下载窗口，在继续加入 down=1 即可。这样输入后会自动弹出下载csv的窗口。



通过同样的方式也可以设置反查IP搜索，设置一个不同的关键字就可以了。


Goby查询

Goby中有RapidDNS的插件，可以下载并安装。安装完成后在添加目标时点击RapidDNS按钮，输入要查询的域名，最后导入目标即可。
