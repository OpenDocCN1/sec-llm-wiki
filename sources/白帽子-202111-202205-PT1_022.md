***前言***

在进行逆向分析的时候，对于linux上的二进制文件，使用gdb进行动态分析必不可少。gdb确实是一个不错的工具，简单方面，但是不够实用。这里介绍一个gdb的插件pwndbg，这个插件扩展了gdb，使得调试更加得心应手。

***No.3  
***

***安装***

安装的方式比较简单，如下所示：

git clone https://github.com/pwndbg/pwndbgcd pwndbg  
./setup.sh  

但是安装比较容易失败，推荐挂上代理再进行安装。

***基础指令***

file <路径>       打开文件

start             启动调试

ni                单步步过

si                单步步进

b \*<地址>          在地址处下断点

i b               查看断点信息

del <断点编号>     删除断点

x/<数量>bx <地址>  以16进制显示地址开始往后一定数量的单字节

 b可以换成h,w,g 分别为显示双字节，四字节，八字节

x/s <地址>         显示地址上起始的字符串

c                 执行直到遇到断点

vmmap             显示程序地址段和权限以及位置信息

args              显示运行的参数信息

attach <pid>      附加到pid进程上调试

q                 退出gdb
