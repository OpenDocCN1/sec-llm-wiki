## 一、前言

        多个人同时做一个渗透测试项目，每个人挖出的漏洞不尽相同，除了平时积累的经验和做测试时胆大心细外往往还和使用的工具有关。本次我来给大家介绍各种工具中字典的整理。

## 二、敏感目录字典整理

        之前一直以为字典越大越好，于是我就搜集了大量的目录字典，当对一些src漏洞挖掘时，每个网站目录扫描至少要花费半天时间，由于实在忍不了这个时间，决定重新整理目录。

        首先还是从工具中搜集大量的目录字典，从网上搜集了二十多个目录扫描的工具，剔除其它文件后字典占用空间两百多兆。

![](../Images/54153d03bc34be5c076106f550eba07d.png)

        将所有的字典文件按大小进行排序，因为部分工具使用相同的字典，会对结果造成很大的影响，删除重复的文件还剩下两百多个文件，占用空间两百兆。

![](../Images/4116328a43d3b747c3d85bd397784691.png)

        为了查看方便，使用批量重命名工具对所有文件进行重命名操作。

![](../Images/d551fd2d1243e170c43c6fe6f174c25f.png)        文件编码存在差异，使用工具将文件编码进行统一。

![](../Images/b3f80820965cbeed74d1d1fa5f4ff6b8.png)        编写了一个python脚本，对两百文件进行处理，首先判断首字母是否为 / 结尾是否为 /，首字母不是 / 给添加，结果存在 / 给删除，接着去除无用行，如.png .css等 ，最后按照后缀进行分类，分别为asp、aspx、php、jsp、dir，并把出现次数最多的排在最上面。

```


import os
```

        查看处理后的结果，根据个人删除出现次数较少的。

![](../Images/733e3e4dddce40976ca218beb92e6a6c.png)

        Windows服务器不区分大小写，如果想要更节省时间，先把所有的字典转化为小写在进行处理。这就需要扫描前先判断是Windows和Linux。

## 三、子域名字典整理

        子域名收集就相对简单多了，从多个子域名扫描工具中将字典进行去重，字域名搜集的越多越好，可进行攻击的面越大。

![](../Images/460aeb41d002a0036fa9325c65954fe8.png)

FuzzDomain工具扫描时自动生成字典，指定扫描字域名的字符及位数，并且可扫描三级域名。

![](../Images/6521d16e4ff1c4df0f34405fd6437b94.png)

        千万不能忽略通过搜素引擎去搜集字域名。（代码水平比较水，大佬请绕过）

```


from urllib.request import urlopen
```

## 四、用户密码字典整理  

        各种爆破工具里面密码字典进行整合（kali里面比较多），将社工库里的密码也可整合进来，按照出现的次数进行排序。然后在排名前多少。

![](../Images/3e2525f425676be80cf5ddf567a95a51.png)  

        常见用户名字典，从互联网上下载中国姓名排行榜，在通过某网站将汉字转化为拼音。

![](../Images/a6a8d138a40e56d05d6c884e70881083.png)

        常见管理后台账号

![](../Images/e30b34e7dff3f194bcc1eaddd1d75edf.png)
