# **前言**

  

记录之前参加演练的一次实战过程。

  

# **演练目标**

  

拿下某医院核心his权限

  

# **web打点**

  

拿到目标，通过信息收集尽可能多的寻找目标资产，最终发现了存在漏洞的某系统，通过该系统进入内网。

  

## **用户枚举漏洞**

  

登录处存在用户枚举漏洞  
![](../Images/fc40e058ba8f9b34a0085746addf4605.png)

  

返回包可以看到该帐号的功能，所属的科室等信息。  
![](../Images/fb3b36656fa35c706d58fcb24cbfef4e.png)

  

## **弱口令漏洞**

  

通过对枚举得到的用户进行弱口令爆破，成功登陆了某医生的账户。  
![](../Images/f387d5d1243001000225dec06661454b.png)  
该账户只有一个体检预约管理的功能，经过测试无法直接getshell。

  

## **越权漏洞**

  

观察当前url地址，发现存在usersysid和deptid两个参数，usersysid为当前用户名，deptid恰好可以通过用户枚举得到，因此可能存在越权漏洞。  
![](../Images/3f6796dcfeb882eff498b725a8167201.png)  
经过测试发现可以通过修改参数进行越权，大部分为普通用户，经过反复尝试发现269用户权限比较高，尝试替换usersysid和deptid进行越权。  
![](../Images/0edf0e1bf84a0336fa37e493606ce4e7.png)  
成功访问到该帐号的功能模块。  
![](../Images/5336accf79b9f99708089f4f20602340.png)

  

## **文件上传漏洞**

  

对高权限用户的功能模块进行测试，发现上传点。  
![](../Images/171bd8e5ce47e3777a2547d754b7bfe2.png)  
网站存在某种waf，常规webshell无法直接上传，尝试进行bypass。

  

最终绕过waf成功上传webshell，对数据包进行了4次处理。  
1、"boundary="后面加tab键  
2、使用asHX后缀  
3、删除"Content-type："后面的类型信息  
4、正常图片文件的内容开头  
![](../Images/31fa1824a6f49fdc7f30a0a5800257cc.png)  
成功得到目标webshell，web打点结束。  
![](../Images/89c0d28bbf5b67b77b140d36bdebafb0.png)

## **内网信息收集**

  

具体信息收集的过程不再描述，通过内网信息收集，发现了数据库连接配置文件，包含his，lis等核心数据库。  
![](../Images/e1301d9743e56a169132c6657e3482cc.png)

![](../Images/cc86fdd1128faab5bd7fcf9db4f563df.png)

## **获取核心his权限**

  

利用得到的账户密码直接登陆his数据库。尝试使用xp\_cmdshell执行系统命令。

  

*   
*   

```
EXEC sp_configure 'show advanced options', 1;RECONFIGURE;EXEC sp_configure 'xp_cmdshell', 1;RECONFIGURE;exec master..xp_cmdshell "whoami"
```

  

成功拿到his数据库服务器权限。  
![](../Images/5183828bdf1898316d3093ddf14a394b.png)  
目标不出网，且无法ping通跳板机。  
![](../Images/2016d87a232609b294632c5ea8b32630.png)  
证实了该服务器为his服务器，且该网段为核心内网。至此达到演练目标。![](../Images/a6921aeff27ec61dcb5bd59fe93f8198.png)

  

## **扩展**

  

目前只能通过数据库来执行系统命令，尝试上线到cs上。  
该his服务器不通外网，且不通跳板机所在的网段。  
反向连接失效，尝试使用正向连接，上线目标服务器到cs。

  

![](../Images/4b074fb32fbc8b0f20191e0b2c3eec38.png)  
cs新建一个监听器，选择beacon-tcp，执行后本地开放一个端口  
![](../Images/513b1bccae9a376ee06aa2fb47ae1bf3.png)  
生成一个无状态的可执行木马文件，选择对应的监听器。  
![](../Images/9b7b0e937a6a380107c377b682caa068.png)  
上传木马文件到目标主机～  
这里遇到了困难，目标不出网，且不通当前跳板机，只有cmd命令行的情况下，无法直接上传。  
解决方法：目标开放了iis服务，向iis服务网站目录下 echo一个apsx一句话木马，然后通过webshell上传可执行exe文件。  
利用SQL TOOLS可以直观的寻找目标网站目标，然后echo写入木马。  
![](../Images/27184fad590540259020cfd2aec2da54.png)![](../Images/6a40e273ec9ab0dcffdfae8c6ac01a9d.png)  
使用webshell上传exe并且执行。  
执行后会本地开放一个8877端口。  
在跳板机的cs会话中执行:

  

```
connect x.x.x.x 8877
```

  

去正向连接目标开放的8877端口。  
![](../Images/eda82b2b57df6ee556b5bae596111318.png)  
成功通过多层内网上线了目标主机。  
![](../Images/1160726286d72b4e972dc5255edd1310.png)
