总结

通过上网搜索，得知这个这个是Data URI scheme协议，以此次头像上传为例，前端js将jpg头像转换成Data URI scheme格式，后端负责将Data URI scheme格式的头像文件进行接受并且写入。
Data URI Scheme格式如下：
data:①[<mime type>]②[;charset=<charset>]③[;<encoding>]④,<encoded data>⑤
①. data ：协议头，它标识这个内容为一个 data URI 资源;
②. [<mime type>] ：可选项，数据类型（image/png、text/plain等）
③. [;charset=<charset>] ：可选项，源文本的字符集编码方式
④. [;<encoding>]：数据编码方式（默认US-ASCII，BASE64两种）
⑤. ,<encoded data>：编码后的数据
