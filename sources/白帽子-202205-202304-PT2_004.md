***No.1

***目录遍历漏洞（ CVE-2020-11652）***

wheel模块在特定目录下读取和写入文件，path未进行过滤处理。

salt.tokens.localfs的get\_token（）方法,攻击者可以通过../的方式绕过。

第55行

def get\_token(opts, tok):  
   '''  
   Fetch the token data from the store.  
  
   :param opts: Salt master config options  
   :param tok: Token value to get  
   :returns: Token data if successful. Empty dict if failed.  
   '''  
   t\_path = os.path.join(opts\['token\_dir'\], tok)  
   if not os.path.isfile(t\_path):  
       return {}  
   serial = salt.payload.Serial(opts)  
   try:  
       with salt.utils.files.fopen(t\_path, 'rb') as fp\_:  
           tdata = serial.loads(fp\_.read())  
           return tdata  
   except (IOError, OSError):  
       log.warning(  
           'Authentication failure: can not read token file "%s".', t\_path)  
       return {}

***补丁分析***

为了修复CVE-2020-11652漏洞，SaltStack已清除了salt master提供的ClearFuncs方法中的路径。

添加了两个新函数：\_realpath（）用于解析任何文件系统链接，以及clean\_path（）用于验证路径。

新的\_realpath（）函数，该函数解析所有文件系统链接
