脚本的调用

关于漏洞  我相信各位表哥都有一些poc

  

或者在一些不可描述的地方下载下来的poc

  

但是有时候只能针对单个漏洞测试，对于我这种懒得一个个去试的人

  

该如何处理成自动化，批量处理

  

当然并不是修改代码，应该代码不是每次都有机会修改的，比如Java反序列化利用。

  
这时候我们可以用python来批量执行，模拟我们输入命令的操作 来批量操作  
  

当然这里我们使用python的subprocess模块  
  

1.  <font size="3">def checkVul(self,url):  
    
2.                  cmd = ''+url          #输入执行的命令  
    
3.                  print "TEST:......"+url  
    
4.                  try:  
    
5.                          p = subprocess.Popen(cmd ,stdin=subprocess.PIPE, stdout = subprocess.PIPE,stderr = subprocess.PIPE)  
    
6.                          stdout = p.communicate()  
    
7.                          for i in stdout:  
    
8.                                  if re.search("VULNERABLE",i).group():       #获取检查到问题的关键词  
    
9.                                          print url+'   search VULNERABLE'  
    
10.                                          with open('VULNERABLE.txt','a') as f:  
     
11.                                                  f.write(url+'\\n')  
     
12.                  except:  
     
13.                          pass</font>
