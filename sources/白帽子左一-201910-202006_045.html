一直回车，直到出现下面的界面

继续回车，等待2-3分钟那么就会出现如下界面

下面补充一个汉化的步骤:


第一步、更新kali的源
echo deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib >> /etc/apt/sources.list
echo deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib > /etc/apt/sources.list


第二步、更新kali的软件
apt-get update && apt-get upgrade && apt-get clean


第三步、选择默认语言
dpkg-reconfigure locales



第四步、安装中文语言包
apt-get install ttf-wqy-microhei #文泉驿-微米黑
apt-get install ttf-wqy-zenhei #文泉驿-正黑
apt-get install xfonts-wqy #文泉驿-点阵宋体

选择一个就可以


第五步、重启
