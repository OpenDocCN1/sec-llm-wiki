# 绕过过滤

经过测试发现只要出现尖括号就会返回404

![](../Images/55ac27b107beae139d49ad4d4f19da78.png)

  

![](../Images/eaaca846939187bca66772ab67a732a9.png)

  

可以用between来绕过

![](../Images/b8ba5ac5185a1047fb80f7a3a1d87895.png)

  

![](../Images/b81c70cdaac17d9bcd5dcc83e307c32f.png)

  

这时就继续按照 条件真=>-2 条件假=>-1 来回显

也就满足了盲注的条件

忽然一想这个情景跟第五空间决赛的那道注入题一毛一样

真返回一个页面 假返回另一个页面 出现被过滤字符返回其它页面 并且要用between来绕过

CTF诚不欺我

所以只要在sqlmap的参数里加上--tamper=between 即可
