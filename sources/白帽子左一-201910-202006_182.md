## **前言**

大家搭建kvm靶机时可以直接选择iso镜像搭建，这个一般不会出问题。故此就说下kvm中搭建的镜像，若是选择qcow2的镜像该如何搭建。

本文章纯属小白文，欢迎各位大佬吐槽。

> 实验环境:ubuntu16、VMware14

##   

**一**

**

kvm环境准备

**

  

先查看虚拟机是否支持kvm.(Intel CPU的虚拟化技术叫 vmx, AMD CPU的虚拟化技术叫 svm),输入命令 egrep”(svm|vmx)” /proc/cpuinfo

如图所示虚拟机支持虚拟化

![](../Images/9fdb9d664b0e5c0f3f88c01621f49225.png)

备注：若是输出没有svm或vmx，需开启虚拟化，如图![](../Images/d63dcf1b8cebe8d439a77e578de4f09f.png)

  

**二**

**

安装kvm

**

  

安装kvm及依赖包

> sudo apt-get install qemu-kvm
> 
> sudo apt-get install qemu
> 
> sudo apt-get install virt-manager
> 
> sudo apt-get install virt-viewer
> 
> sudo apt-get install libvirt-bin
> 
> sudo apt-get install bridge-utils
