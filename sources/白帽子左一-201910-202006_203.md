# 美议员称，抖音将为美国带来“国家安全风险”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NTcxMjQ1MA==&mid=2247483687&idx=1&sn=777edb7da26213aecafdd23beb369e5d&chksm=ebe9480adc9ec11c0953168285f59d0468f474ceb16ff2ab0651aa6532580cad27a8e019025f&scene=126&sessionid=1681659733#rd](http://mp.weixin.qq.com/s?__biz=MzI4NTcxMjQ1MA==&mid=2247483687&idx=1&sn=777edb7da26213aecafdd23beb369e5d&chksm=ebe9480adc9ec11c0953168285f59d0468f474ceb16ff2ab0651aa6532580cad27a8e019025f&scene=126&sessionid=1681659733#rd)

       近日，美国参议员查尔斯·舒默和汤姆·科顿致信美国国家情报总监，称TikTok（抖音国际版）将会对美国国家安全造成严重威胁，并要求美国情报部门立即对该应用展开调查。

![](../Images/6c91352451cfa36e318a6b865ea77350.png)

  

       美国参议员 Chuck Schumer 和 Tom Cotton 要求情报官员调查中国短视频应用抖音 (TikTok) 是否会带来国家安全风险。两人致函代理国家情报总监 Joseph Maguire ，对抖音收集用户数据及中国是否会审查美国用户看到的内容表示担忧。信中称，“单是美国的下载量就超过 1.1 亿，抖音是潜在的反情报威胁，我们不能忽视。”他们敦促调查人员调查抖音搜集用户定位相关数据和其他敏感个人信息的问题。“中国政府并不要求抖音审查内容，”   
    抖音发言人在一份声明中称。“显而易见的是，我们不会因存在香港抗议的内容而删除视频。”  

  

![](../Images/4d7a57ed1eb31c21a72f632df44ea183.png)

     对此，TikTok官方回应称，此番言论并无事实依据。首先，**中国政府从未要求该平台删除任何内容，**只有该公司的本地化内容审核小组才能决定什么内容是适合发布的，而该小组一直在严格遵守各国的法律法规。其次，**TikTok并不在中国开展业务，该平台的美国用户数据都储存在美国境内，而备份冗余则储存在新加坡，并不受中国法律约束**。

  

有意思的是，尽管二位议员声称TikTok限制言论自由，**但美国本土公司Facebook和Twitter却封杀了数百个揭露香港暴徒行径的账号**，这又何尝不是对于言论自由的践踏呢？
