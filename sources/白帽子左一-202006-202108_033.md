# 实战｜某出版社存在重置他人密码，及邮箱

这里存在两个漏洞

```
1.  `1：任意账户密码重置`
    
2.  `    2：任意账户邮箱重置`
    
```

**漏洞复现：任意账户密码重置**

  
先创建两个测试账户

  

![](../Images/11d26a5ca96b9fa5b416abc6a44f5f9d.png)

![](../Images/c0905c97e5ea008dcc8d1e48753a26e5.png)  

点进密码忘记，填写1号账户的邮箱,这里要注意一点就是，抓包修改邮箱的话，这个邮箱必须是存在的，所以抓包修改为2号账户的邮箱

![](../Images/3f134c4a14021f91053f97594c9381a6.png)!\[\]![](../Images/25b77f749806f4c7bb993b75aad2515a.png)

图中所示，修改这里就好，这里要填成2号账户的邮箱，

![](../Images/48d8578734796b0d08471cf273ed1a2c.png)

临时邮箱成功接收到了验证码，输进去

![](../Images/c20ab5f018552ed91ab33c4492e81393.png)

![](../Images/eb03468d74d375159b1d68efd1706428.png)登录成功，思路是

  

```
1.  `    填写目标账户的邮箱，在抓包修改为自己的邮箱，这样就可以修改别人的密码`
    
```

**第二个：任意重置他人邮箱**

这个说实话很危险，重置掉对方的邮箱，修改密码分分钟的事，还是这两个账户  
这里还有个问题就是，修改掉对方的邮箱

然后我的2号账户有时候会变成1号账户，换了好几个账户也是这样，认为是越权登录，可结果试了好多次也没有越权漏洞，也不会怎么回事

![](../Images/18ae799433ab94cf317ff787e21b8ebd.png)![](../Images/81b34cdcb3c3d8956ab8da98db04fd45.png)在资料修改处修改邮箱  

![](../Images/374832d44cb6d2ce96e0ca5347b1cf3c.png)  

抓包，发现这里有个账户名，可以可以，把账户名改为2号账户名，就好了

![](../Images/e680e53f27e6ea0424576a91df88f0b5.png)  

发现，成功接收到了链接

![](../Images/e7e3c8a3aa9afb8c5cfd793029a5d6ab.png)  

虽然打不开，但是2号账户只要重进一下，邮箱号就变了

![](../Images/641e8983f7ac913ea1fb1f455ca716fa.png)  
  

这里又出现了了，聂风老师帮忙解答一下，我有点迷惑

![](../Images/0c564a8a9b7ab8ce2f3ce2c8190922f3.png)  
修改成功

**思路：**

```
1.  `    这里是抓包修改账户名，来实现重置任意账户的邮箱号`
    
```
