二、实施步骤  
  

1.Hacker 克隆钓鱼网站，以 139 邮箱登录网站为例：http://mail.10086.cn，在用户 A 上进行测试目标网站是否克隆成功，查看 hacker 和用户 A 的 IP 配置。

  
（1）用户 A（windows server 2003）的 IP 配置  
  
![](../Images/85afff9fb89f198324a4b529c9b28e7c.png)  
  
（2）Hacker（kali）的 IP 配置  
  
![](../Images/e333cd80a8c853ebb19ae2bad6dcdb03.png)  
  
2.在 KALI 终端 输入 setoolkit 打开 kali 自带的社会工程学工具集

  
![](../Images/fc920d5cda367a41a507c5c20eed0c54.png)  
  
3\. 输入 1，选择社会工程攻击

  
![](../Images/711eeab1b10d29ee6d6ad74a50727ed5.png)  
  
4\. 输入 2，选择网站攻击  
  
![](../Images/85d52fd4f896c1533ba984010cfa5db3.png)  
  
5\. 输入 3  
  
![](../Images/2f06631448a7639775b5c900bcb903a2.png)  
  
6\. 输入 2，克隆网站和域名  
  
![](../Images/ba7e2b86be6f6ec5ade9ae61cc0560fb.png)  
  
7\. 在 kali 的浏览器上用 IP 登录克隆的网站,表示克隆成功

  

![](../Images/1c3aa4dcc91258cdf7bd9ef3705b1aa4.png)  
  
8\. 开启 kali 的数据包转发功能  
  
![](../Images/d50cd262f71cbed40d88578b6dc86e28.png)  
  
9．启动 ettercap

  
![](../Images/79a187415d943e3ee136546472f8a929.png)  
  
10．编辑 Ettercap 的文件(vim /etc/ettercap/etter.dns)，

  

使得用户 A 访问 http://mail.10086.cn 时，域名解析为 Hacker 的 IP  
![](../Images/f2630ba0b28738db19499f85d93c9b0c.png)  
  
11．我们使用抓包的方式实现中间人攻击。

  

选择 sniff|unified sniffing|选择嗅探网卡，默认 eth0，点击确定，见下图：  
  
![](../Images/a589400fa43960e65806cd5eae6a71f1.png)  
  
12．启动接口之后，菜单栏选择 hosts | scan for hosts，就可以  
扫描所有主机了。见下图：  
  
![](../Images/3c39418985fe81461c6e774a63e60ce6.png)  
  
13.选择 Hosts| host list，查看扫描到的主机信息。

  

该界面显示了用户 A 的 IP 和 MAC 地址。

  

见下图：  
  
![](../Images/acd56b8ca3c76fb17ff218f2352efafa.png)  
  
14．从中选择 192.168.100.129 作为目标机，单击“Add Target 1”按钮

  
![](../Images/437a5ce9ee4c325be6e7392b56bead80.png)  
  
15．启动 ARP 欺骗攻击，在菜单栏中依次选择 Mitm|Arp poisoning..，然后出现弹出框选择攻击的选项，我们使用“Sniffer remote connections”，然后点击“确定”按钮。  
![](../Images/a050d97a731988f4e526d63d65a6e4c5.png)  
  
16．在 windows server 2003 上访问 mail.10086.cn，并查看 arp 缓存表

  
![](../Images/69f4829e161efacd28a8c26807cada5a.png)  
  
![](../Images/5684e8574957c6e21f6278a8be423de3.png)  
  
17．在菜单栏中依次选择 Plugins|Manage the Plugins, 双击启用DNS\_Spoof（DNS 欺骗）  
![](../Images/40c51d0b3231c1442feea7c98c7f88b3.png)  
  
![](../Images/9c91c5f04ec8eef00b5eb9db32882276.png)  
  
18．在 windows server 2003 上访问 mail.10086.cn 时，现在已经解析为 hacker 主机的 IP  
![](../Images/b054e8742cada5d2ffad55f145d4af03.png)  
  
19．在 windows server 2003 用浏览器访问 mail.10086.cn，并输入用户名和密码登录 139 邮箱  
  
![](../Images/2d30d07c23e9c1c7cd32f3b2bf4c7300.png)  
  
20．在 kali 的 Ettercap 上可以截获到用户 A 输入的用户名和密码信息  
  
![](../Images/a6cc2a83db80a43a239731d444f88f04.png)

  

**注:**

**ettercap**是一个基于ARP地址欺骗方式的网络嗅探工具，主要适用于局域网。ettercap是一款现有流行的网络抓包软件，它利用计算机在局域网内进行通信的ARP协议的缺陷进行攻击，在目标与服务器之间充当中间人，嗅探两者之间的数据流量，从中窃取用户的数据资料。
