# 记录某一天安服仔的漏洞挖掘过程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4NTcxMjQ1MA==&mid=2247512548&idx=1&sn=87e8eb048d15c8e8418640299b4171bc&chksm=ebeaf8c9dc9d71dfff26053809c018f1bf3d1157502dc430f3eb2363ffbe11c14084083a2550&scene=126&sessionid=1681659560#rd](http://mp.weixin.qq.com/s?__biz=MzI4NTcxMjQ1MA==&mid=2247512548&idx=1&sn=87e8eb048d15c8e8418640299b4171bc&chksm=ebeaf8c9dc9d71dfff26053809c018f1bf3d1157502dc430f3eb2363ffbe11c14084083a2550&scene=126&sessionid=1681659560#rd)

* * *

作为一个拿着几 K 工资的安服仔，某一天上级给了一个网站需要挖挖洞。

  

客户不愿意提供测试账号，通过其他位置拿到账号规则，然后进行爆破的时候把账号都锁了，因此还被投诉了。

  

记录一下一天的漏洞挖掘过程，过程有点啰嗦。

  

### 干活

* * *

拿到目标，通常先扫一下端口

  

![](../Images/308b2b3c3d4629a57245de77c085f0fe.png)

![](../Images/81190c18054ae9c43a6f8242cfee2c48.png)

  

三大搜索引擎和github都没找到相关网站的信息，这个时候只能先下扫目录了  

  

![](../Images/6c4b8e4a0cecf2885a801ab2f9c6f763.png)

  

发现 net 版本的 ueditor ，还以为能 shell 了，访问发现报错了，问了一下大佬说可能需要登录。

  

看到了网站的绝对路径，二话不说先写个低危报告。

  

![](../Images/ba25493443e3401c9d067e987eae005e.png)

  

访问 wap 目录，需要在微信打开

  

![](../Images/15765ac5e609f153cb579e170a96f8b1.png)

![](../Images/729efb2f8c01cdc08ebdab577d1ca545.png)

在微信打开，提示要关注企业号，没找到企业号。

  

![](../Images/44186240abe23525a94cf3573f525814.png)

#### 未授权访问  

> API 要未授权才能捡到洞，要验证感觉没什么戏了。

查看 JS ，URL，参数，请求方式 都写明了，跟着构造就对了

  

![](../Images/b99a0c43dafb6e1882272a70abff39b3.png)

![](../Images/0dac479c9f35d96052349efc55fca510.png)

  

创建一个 html ，使用 img 标签成功得到二维码

  

![](../Images/4e8fb09cba0c65c52f976aac63ae3fd7.png)

![](../Images/cfb2bac337d163d67afc2fe91f4c0e6c.png)

#### SQL注入  

通过构造请求，发现 area 参数存在SQL注入

  

![](../Images/a9a77102ee85d8dbd69f1efa71ab9931.png)

  

手工把几个参数都尝试一遍，没 waf 没什么难度。看长度证明漏洞  

  

![](../Images/9f515d351da7918fb6da6fb736a5486c.png)

![](../Images/8e051353b397082bc11fc0987cb4deec.png)

  

第二个注入

  

![](../Images/00150ab96aebcd6ee32a0b184b46e774.png)

  

> 通过手工把上面的参数都测试一遍，一开始没发现什么。当在 ProcLnstID 使用运算符的时候发现漏洞
> 
> ProcLnstID=1/1 返回正常
> 
> ProcLnstID=1/0 返回错误

![](../Images/17bd9abfc646a84f4155df14d0f81586.png)

![](../Images/bfcf3a1333e887d7e17ba374c72bf2cb.png)

#### 任意文件下载

发现文件上传的 JS

  

![](../Images/bc74152518534f4dabe2e52ac40bbac2.png)

构造请求，发现只能上传图片，又一次与getshell无缘  

  

> burpsuite 右键 点击 change body encoding ，从post 转成 form-data ，
> 
> 在 Content-Dispostition: 加上 name="file" 就可以成功上传了

![](../Images/facf3249c90a6e51c250519aecd90a0f.png)

  

发现图片查看的 JS

然后尝试读取文件，成功读取  

  

![](../Images/7c49caa7b79fb16aabdf8b30a4c1cfd3.png)

* * *

大概流程：拿到目标 --> 扫端口 --> 扫目录 --> 发现webpack --> 查看 JS --> 构造请求 --> 捡到漏洞
