#### 0x00前言

* * *

前段时间从一位老师那边学习到的，觉得还挺有趣，就此与大家分享。

整个搭建还是非常简单的。

  

#### 0x01seeker的搭建

  

* * *

运行环境：kali linux

首先在github上下载seeker软件库  
![](../Images/4f909eb0fce8a858886c03f297e8e1b3.png)

当然直接用git 更方便

git clone http://github.com/thewhiteh4t/seeker.git

害 下的有点慢 等等吧

下载完 cd到seeker目录

直接执行install.sh脚本文件

![](../Images/d0b2efda46f5a47884628edd74159c9b.png)

当然期间可能会遇到一些问题

前面显示pip3 没有安装

先看看install文件里有啥

![](../Images/cfaad5c831dd42429173bfeff55da1aa.png)

执行了几条安装操作

和更改目录权限

查看目录权限  
![](../Images/c11098d5e7ef50862e304363999d48f9.png)

发现已经更改成功了

那么现在大概就是

第12行的requests库没有安装完成

先安装pip或者pip3

再安装request库

![](../Images/887fe25ce1710b7df94036e3e2c72cc2.png)  
发现已经有这个库了 害

好了

python3 seeker.py 打开程序

![](../Images/feafcbc87c191b88e608821b5d7bbf80.png)

注意了 这边直接只有执行是打不开的

要执行  
python3 seeker.py -t manual 加上-t 参数

![](../Images/8539d6018b78407dc73a3a7de2ed1db2.png)

中间还是会抛一个异常 可以先不管 起码程序起来了

打开程序你会看见4个模板

这边我直接用Google drive

有兴趣的可以试试其他几个

选完模板 又会让你填入一个url

这个url是在别人访问授权位置后，重定向的页面

一旦授权位置，seeker就可以获取到目标地理位置信息

这边我直接填个百度

![](../Images/c9b802446754ccbd7639efeb3598ac6b.png)

启动成功

seeker处于8080端口监听状态

到此seeker安装告一段落

中间还缺少一个让目标访问的地址

那么怎么白嫖一个域名地址 又可以隧道转发到本机呢？

  

#### 0x02ngrok安装

  

* * *

**下载地址**  

https://ngrok.com/download

下载完成后，解压，cd到目录下

![](../Images/9fc658988942f38aa6f000146ace7e29.png)

直接执行文件 后面跟上通信协议 转发端口

以为seeker监听8080 所以是8080

执行./ngrok http 8080

![](../Images/75bf2947cd4ecec52b0da215c04e89c5.png)

他会给我们一个url

http://6e4d45daafa5.ngrok.io

当有人访问这个url，他就会讲数据转发到我们本机的8080端口  
就此 准备工作完成
