另外，操作此设备需要一定的linux基础，
下面是功能介绍

1.上电开机
mini版：用自带的充电头或者手机充电器、移动电源给菠萝上电
plus版：将拨挡开关拨到左边即可开机，如果电量不足，请及时给菠萝充电，充电可用普通手机充电器通过micro usb接口充电。

另外，将拨挡开关拨到右边，还可以给手机充电，当移动电源使用。


等待大约1分钟左右，会有wifi信号发射出来，ssid名称为Pineapple5_xxxx （xxxx为mac地址后4位），用手机或者电脑可以连接此wifi。

也可以通过有线来连接设备，用网线连接设备的wan口和电脑的有线网口，将电脑的ip设置为静态ip或者自动获取ip，建议将电脑的ip设置为静态ip  172.16.42.10，这样的好处是电脑既可以通过有线访问设备，也可以通过自己的wifi网络上网。

2. web 登录
可用手机、平板电脑、电脑连接设备的wifi，打开浏览器，输入 http://172.16.42.1:1471
第一次登陆web时需要进行初始化设置。

点击Continue

随便输入一组状态，如上图，都输入On的状态

设置web和ssh登陆密码

设置管理用的SSID名称，设置之后，设备会发射两个AP热点，一个有密码，一个没密码

3. ssh 登录后台命令行
用户名为 root  密码为刚刚初始化时设置的密码
在windows下可使用ssh客户端软件来登录，如putty、xshell，推荐使用xshell

注意：
1）有线网口未做设置之前，不要将设备连接到家中的路由器上，否则，无法登录web和ssh。如果想通过有线网络使设备能够上网，请看后面的操作教程。

2）对于plus，使用时请不要通过micro usb接口连接到电脑usb口上，因为这样会将菠萝的usb设备切换到电脑端

3）恢复默认设置的方法，如果因为修改配置不当，或者操作不当导致无法连接菠萝，此时需要恢复默认设置。方法为长按reset按键保持3秒以上，然后松开按键即可，系统会恢复默认设置，并且自动重启。
