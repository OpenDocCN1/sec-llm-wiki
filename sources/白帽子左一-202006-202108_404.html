在许多情况下，你可能想从Mac中恢复被误删的文件数据，这些被删除的文件可能是您的重要照片，官方文件，财务记录等等。

这些数据的丢失可能会对您造成不必要的负面影响。

但是，在这种情况下，您可以使用数据恢复软件和服务来还原您的宝贵数据。 

在本文中，我们将介绍几种可以从Mac系统中免费恢复丢失文件的方法。 


一.

删除文件是怎样一种行为？


您可以通过下列两种方式来删除文件： 

1、将文件移到“回收站”文件夹，然后清空回收站文件夹。

2、使用键盘快捷键Option + Command + Delete，这将立即删除文件；如果您希望彻底删除文件，可以按下Shift + Command + Delete健。

在这两种方法中，我们假设这些文件已被永久删除了，

但实际上，它们只是从当前视图中消失了，而之前存储这些文件的空间可以自由地存储新数据。

简而言之，被删除的文件仍保留在系统上，并且可以轻松恢复。


二.

如何恢复MAC系统中被删除的文件？


有几种方法可以从Mac系统中恢复丢失的文件，您可以从“回收站”文件夹中恢复文件，或者使用Mac’s built-in Time Machine备份还原文件。

在其它情况下，您将需要一款可以恢复Mac文件的软件。

让我们看看从Mac中恢复被删除文件的一些方法。

（1）从回收站文件夹恢复文件

在很多情况下，我们不会去清空回收站文件夹，只是将被删除的文件保留在文件夹中。在这种情况下，您可以通过以下步骤简单地恢复这些文件：

1.找到回收站文件夹。

2.右键单击回收站文件夹，然后选择“ 打开”选项。

3.打开回收站文件夹，然后选择要还原的文件。 

4.右键单击该文件，然后选择“还原”选项。 

5.或者，您可以将文件从“回收站”文件夹中拖到桌面或任何其他位置。

（2）使用Time Machine功能

Time Machine是Mac系统中强大的内置备份功能，当使用Time Machine备份功能时，可以使用外部硬盘驱动器来备份Mac电脑中的数据，

在一定有利的情况下，被删除的文件可能不在您的Mac电脑中，但可能保留在您的Time Machine外部硬盘驱动器中，这样子您可以轻松地恢复被删除的文件了。 

（3）使用一款免费的恢复Mac文件恢复软件
