    二.

    方式


    首先声明，cnvd很好获得，很好获得，很好获得
    ok，废话不多说。上思路

    0、CNVD证书获取的条件

    • 一般而言，cnvd的获取方式分为事件型与通用型。下边是官方的说法（条件）：

      • 1.感谢您对CNVD的支持，对于通过CNVD归档的原创漏洞，只颁发

      （1）对于中危及中危以上通用型漏洞（CVSS2.0基准评分超过4.0分）（除小厂商的产品、黑盒测试案例不满10起等不颁发证书），
      （2）涉及电信行业单位（中国移动、中国联通、中国电信及中国铁塔公司）和中央部委级别(不含直属事业单位)的高危事件型漏洞，

      2.CNVD将给予原创漏洞证明（即CNVD漏洞证书，电子版），该证明可通过编号在CNVD官方网站进行查询跟踪。

      3.时限要求：按周对上一周归档漏洞且满足证书颁发条件的进行批量制作。
    • 本文仅仅分享一些通用性漏洞的思路，也就是上述（1）的获取方式。
    • 至于事件型拿到cnvd，希望小伙伴们通过此方式时，一定要掌握好“度”，不要越线，不要越线，不要越线
    1、黑盒获取
    • 黑盒拿到cnvd的过程说起来较难理解，但是操作起来并不复杂
    • 这个直接上我通过黑盒的方式拿到证书的一次实战案例来与大家分享
    （1）发现xss
    • 无聊的某日晚上，想着挖掘漏洞玩吧；进入某大型集团网站的首页
    小结：
    • 存在xss是个好兆头（虽然是反射型），
    • 但是这意味着这个网站极大可能存在别的漏洞
    （2）打出sql注入
    • 继续测试别的漏洞，这里的思路就是先找到功能点，即传参点处做手脚
    • 而且sql注入、xss是很常见的漏洞，基本上顺手测试测试
    • 然后就是爆出表名、库名、等等
    • 继续测试，看看能不能找到一些别的有趣的地方
    • 最开始比较野的想法是整进后台，传小马，进内网。。。
    • （当然这不是今天主的主要内容，不在展开）
    （3）发现线索
    • 在继续溜达别的页面的时候，一个不起眼的地方，发现了一个比较关键的信息
    • 技术支持，一般就是开发当前网站的组织
    • 二话不错，直接点进去，顺藤摸瓜、抄他老家。
    （4）怼一波建站模板
    • 首先，找找这个“母站点”是否存在一些明显的漏洞
    • 接着去找案例中心，验证一波想法
    因为是同一个组织写的网站，其他案例估计着也有类似的漏洞，
    即存在xss与sql注入。经过测试，也验证了猜想，所以子站点都存在sql注入与xss
    • 近百个网站吧，包含教育、企业、政府的。收获还是不错的。
    • 又可以小冲一下盒子的月榜了
    （5）检查收获
    1. 因为网站太多，在这就不一一展开了，每个网站都有反射型xss ,可以提交盒子
    2. 而且存在留言板，因为懒所以也没测试存储型xss，主要是因为拿不到源码，比较麻烦，但是经验告诉我 极大的可能存在
    3. 几乎每个网站都存在sql注入，但是因为一些原因吧，这些注入类型有不少（显注，报错注入，盲注等等） 将这些案例打出效果，截图保存到word，提交cnvd
    4. cnvd的附件里面有三个案例需要详细说一下过程，剩下的粘贴url就行。随便找十几个站点，但是为了稳妥，这十多个网站的过程都稍微贴了一下。
    （6）补充说明 注意点
    1. 黑盒需要收集案例网站够10个以上，不够的话是没有证书的
    2. 万一第一次提交没有够10个案例，不要急，再次提交一次够10个案例的。下来的时候很可能变成两本证书。（这个操作很迷，但是我确实亲身经历过）
    3. 有的一些已经被别人提交过了，我还有必要在此提交吗？
      有必要，提交反正不亏，即使没有证书，一般也会给你发一个cnvd编号
      即使什么都没有，也没损失什么
    4. 一个模板若是都存在about、news、catalog等等这样的界面。可以提交3次，即可以拿到3本证书
    小结：
    挖掘src的时候。
    不要仅仅盯着当前网站，注意看看是否存在一些技术支持，一个不留神错过的就是一本cnvd
    2、白盒获取
    （0）思路
    • 这个白盒审计可以获取到的方式就太多了，
    • 风哥教到的基本都可以很容易拿到证书。
    • 比如我就记得风哥之前讲过0day挖掘的课程，
    • 多去看看，更重要的是亲自复现几次
    （1）在说几个技巧，
    • 如果仅仅是单纯的想要得到一本证书的话，就把重点心思放在后台管理处。
    • 要明白，对绝大多数网站、CMS来说，后台永远要比前台脆弱的多。
    比如：
    1. 后台文件上传漏洞（即后台getshell的常用手段）
    2. 后台sql注入
    3. 交叉越权（垂直、水平）
    （2）其他
    1. 当然，以上仅仅是对一些想拿到证书的小技巧。事实上，相对于证书更重要的是自己的水平。当你通过上述技巧拿到几本证书后，就没必要用上述的方式获得证书。
    2. 相似的方式拿到1本证书与30本、80本都没有太多的差距，
      这仅仅能说明的是你比较闲，时间多
    3. 大家可以试着，找找xxe、反序列化、变量覆盖、文件包含等等稍微有点技术含量的通杀
    4. 注意的是，通用性的案例仅仅需要提供3个及以上就可以了

    三.
    得到通用性漏洞你可以干嘛？

    1. 提交cnvd获取一些证书
    2. 将多余的案例提交漏洞盒子、补天等等第三方src平台。
      这会让你冲击月榜变得异常的简单
    3. 找工作面试的极高的加分项
    补充一下：
    • 据了解，700+个漏洞就可以达到2500+分，大家可以看看盒子的榜一多少分
    • 真的是提交漏洞提交的让你吐，实在不想提交了，大家可以让朋友帮你一起提交
    • 最后，希望这篇文章可以帮助到咱们学院的一些新人，
    • 祝大家都可以拿到几本小证书。
    • 大家有什么更好的蚁剑可以评论区补充
    四.
    CNVD证书得审批流程

    1. 提交通杀至cnvd
    2. 三天内“一审、二审”。（一审二审主要验证 真实性，完整性等）很容易过。
    3. 三天内进入“验证、处置”流程
    4. 小结，正常情况一周内完成 “一审、二审、已验证、已处置”；
      ------接下来进入一个相对较慢的三审阶段（关键步骤），一般通过三审就可以静静等待证书到手了-----
    5. 两周内完成“三审、评分、归档*”
    6. 下周三、周四将证书发送到你的cnvd账号中

    五.
    小结

    1. 一周内完成“一审、二审、已验证、已处置”，
    2. 两周内完成“三审、评分、归档”，
    3. 归档后的下一周三（或者周四）
    4. 整个过程（提交到拿到证书），一般为一个月的时间。
