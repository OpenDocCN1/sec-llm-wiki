前段时间跟着网上的教程申请了cve ，申请成功了记录一下申请过程,漏洞编号了就不放了

## **获取CVE编号**

https://cveform.mitre.org/  
选择Report Vulnerability/Request CVE ID 并且填写好邮箱

![](../Images/c9e345bcb80ce0878b4e9fbc01e93d9c.png)

我这里提交的是sql注入然后填厂商地址 系统的名称 系统的版本 然后选择影响，因为我这里是sql注入所以选择信息泄露

![](../Images/f3c0f9a9194590491b58545c9381e232.png)

*   Affected component(s)（影响组件）我填的系统名称-版本
    
*   Attack vector(s)填写一下漏洞利用概述比如xxxx系统的xxxx文件存在sql注入，然后由于是不开源系统，我在我个人博客上写了一篇利用以及分析文章,然后写在了上面
    
*   Suggested description of the vulnerability for use in the CVE 填写漏洞描述 xxx系统xxx文件存在xxx漏洞可获取敏感信息
    

![](../Images/a926d9b6da0dcbeb4cdbcb6fb0d176cc.png)

提交申请后他会自动回复一封邮件

![](../Images/c035426e99d63f3162726edda321f352.png)

过了11天收到了邮件，里面有你提交漏洞的信息和分配的编号

![](../Images/8360d3e83a3be92f22361abe1bfef63d.png)

然后去查询是保留状态

![](../Images/b2170c093422f8d9f507b7ba703885b1.png)

去网上查询了一下发现说公开后才算有效漏洞

![](../Images/14a7582c86f1eaec56efbfafe64feac0.png)

现在去 https://cveform.mitre.org/ 申请公开，选择Notify CVE about a publication

![](../Images/c9e345bcb80ce0878b4e9fbc01e93d9c.png)

然后填写参考链接，我这里是我自己的博客我就附上了我自己博客的链接，也可以去GitHub新建一个项目来写，然后就是申请公开的CVEID然后下面那个框我填写了漏洞描述信息

![](../Images/d83d38720ef709ba735d076d52e330eb.png)

提交后同样会自动回复一封邮件

![](../Images/fde269eb01498830263be76d2fc84397.png)

过了两天收到了邮箱,漏洞会在进行时内更新到www.cve.org

![](../Images/d9d97d73591c468a2abf8d07c6baf089.png)

然后去网站上查询即可

![](../Images/e7b1a34b05940fc0741c2f9da0ddfd81.png)

然后等一两个小时另外一个网站也可以查询了

![](../Images/bfa49a316997dc8caef54602077fac70.png "点击放大图片")
