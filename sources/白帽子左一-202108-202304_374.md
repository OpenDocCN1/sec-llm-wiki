## **云函数隐匿真实IP**  

本次实验利用的腾\*云：(其他也相同)

话点击新建云函数，选择创建方式—自定义创建，函数名称自定义或者默认都可以，运行环境选择python3.6，其他版本也行。

![](../Images/5e75f2473a267e27031ea5f1a9011706.png)

  

云函数代码如下(可先点击完成，后面再补进去)：  

  

```


\# -\*- coding: utf8 -\*-"body":str(base64.b64encode(resp.content))\[2:-1\]
}
```

然后创建触发器，具体配置如下图：

  

使用API网关来进行触发函数。

  

![](../Images/b21aaacead12f27e41044948adc2f4d8.png)

![](../Images/da8f085c90174f645bb19ed029bc3e60.png)

  

然后配置一下网关API路径：  

  

![](../Images/27a53273a4ce5611311a1d7acbb8e8d7.png)

![](../Images/2f09b748687c17e552a57045a9b52fc1.png)

![](../Images/865d78d17412026884a485c28dd57e99.png)

  

选择立即完成并发布任务即可。  

  

这里配置完成后，我们得到API网关地址如下图：

  

![](../Images/a94ed9e5c8e80518a9c831ad73964acf.png)

  

记一下该地址，等下需要用到。  

  

接着先去修改profile文件，配置文件http-config设置如下：

```


http-config {}

```

这里是为了与上面的云函数同步使用X-Forward-For来获取真实ip。

  

然后我们就可以去CS中

  

创建一个监听器，配置如下图，HTTP Hosts处 和 HTTP Host(Stager)处填入刚才获取到的API网关地址(Port 一定要是80)。

如在云函数中指定了port，则需要创建两个监听器。

  

![](../Images/aee2fd0836e25f2da8496ae019beb4f5.png)

  

生成木马即可上线。

## **Heroku代理隐匿真实IP**

Heroku是一个支持多种编程语言的云平台即服务。

  

其实简单来理解就是通过Nginx反向代理的方式，从heroku服务器代理到我们真实的CS服务器。

  

首先：

注册heroku账号，这里需要注意的是QQ邮箱和163等国内邮箱注册不了，建议使用匿名邮箱。

  
地址：https://dashboard.heroku.com

  

注册成功后进行登录，访问以下网址进入配置页面。

  
https://dashboard.heroku.com/new?template=https://github.com/FunnyWolf/nginx-proxy-heroku

![](../Images/78095a195bb1d9e6f458cb36f151b223.png)

  

填写App name以及TARGET（可以使用域名或直接使用IP，端口在创建监听器时用作监听端口）  

点击 Deploy app 进行创建容器就可以不用管了。

  

回到Cobaltstrike，在Cobaltstrike中配置两个监听器

第一个监听器设置PAYLOAD为Beacon HTTPS，HTTPS Hosts为CS IP，HTTPS Port为7443端口(第二步设置的端口)。

  

![](../Images/936748a13b126d75f139ed92e26cf459.png)

  

继续配置第二个监听器，同样设置PAYLOAD为Beacon HTTPS，HTTPS Hosts设置为huaweiapi.herokuapp.com，也就是之前获取到的heroku的域名。  

  

HTTPS Port设置为443。（这里一定要443）

  

![](../Images/4700162340a20a63e934990383407039.png)

生成木马时，监听器设置为：第二个Beacon 即：heroku2  

  

## **CDN隐匿真实IP**

申请免费域名

  

https://my.freenom.com

  

在申请的时候直接输入 xxxxxxx.tk  否则可能会显示该域名被注册。

  

最好能开个代理，代理位置设置在美国(和个人信息中的国籍相同)，否则一个域名有极大概率会申请失败。

  

![](../Images/318647d2d3922c78921ce800f641278c.png)

  

然后去  

  

https://dash.cloudflare.com

  

添加cdn站点：

![](../Images/59671332e24961b444f04fac747452e1.png)

这一步直接继续，  

  

![](../Images/93aa70deaaa570d1851a13b5f672ac7c.png)

  

自动生成dns地址  

  

![](../Images/da0f88012c1f9608c2ba50ff4cd4eec9.png)

  

复制这两条放到freenom处：  

  

![](../Images/345b61d3f841111c60228fb0a01bb596.png)

  

cdn上关闭自动https重写和始终使用https、broti压缩：  

  

![](../Images/a603832d14520aff87ee7a3d9eebfcd7.png)

![](../Images/0756c3f8beac55696578b1d2858be7e6.png)

![](../Images/c40d0ca9a078e5d1a10f38688ed75fa5.png)

  

接着添加DNS：

  

![](../Images/d4e318545d4a14f30df84a64df043182.png)

生成证书

  

保存公钥以及私钥

  

  

![](../Images/c2e0ee9bf0b32190c7d878c8143b0824.png)

  

第一个保存pem，第二个保存key文件（复制即可）

  

![](../Images/4a082a75cd2c4fa71e3d7489fa45c6c8.png)

将证书打包并生成store文件  

```
open
ssl pkcs12 -export -in server.pem -inkey server.key -out xxx.xxxxxx.tk.p12 -name xxx.xxxxxx.tk -passout pass:123456
```

再创建一个.profile文件

```
https-certificate { set keystore "xxx.xxxxxx.tk.store"; set password "123456"; } http-stager { set uri\_x86 "/api/1"; set uri\_x64 "/api/2"; client { header "Host" "xxx.xxxxxx.tk";} server { output{ print; } } } http-get { set uri "/api/3"; client { header "Host" "xxx.xxxxxx.tk"; metadata { base64; header "Cookie"; } } server { output{ print; } } } http-post { set uri "/api/4"; client { header "Host" "xxx.xxxxxx.tk"; id { uri-append; } output{ print; } } server { output{ print; } } }
```

把xxxxx.profile和xxx.xxxxxx.tk.store拷贝到cs服务器上

执行

  

./teamserver ip password ./xxxxx.profile

  

客户端上监听:

![](../Images/e539d98b55adcca1af1a58b5b861b7f7.png)

可监听的端口  

  

http:

80、8080、8880、2052、2082、2086、2095

  

https:

443、2053、2083、2087、2096、8443
