# Facebook与Instagram上的反疫苗组织利用暗语逃避封禁

Facebook 上的一些反疫苗组织正在将他们组织的名字改为像“舞蹈派对（Dance Party）”或“晚餐派对（Dinner Party）”这样的委婉语，并使用暗语来适应这些主题，以避开 Facebook 的打击

根据多个成员提供给 NBC 新闻的屏幕截图，这些群组在很大程度上是私密的且无法搜索，但保留了在 Facebook 允许反疫苗接种内容期间积累的大量用户群，它们还更换了敏感词汇以适应该用户组主题。

一个主要的“舞会”团体拥有超过 40,000 名粉丝，并且在公众监督下已停止允许新用户加入。“舞会”的后备群被称为“晚宴”，由同一位主持人创建，拥有超过20,000名粉丝。

Instagram 上的其他反疫苗影响者使用类似的语言交换，例如将接种疫苗的人称为“游泳者”，将接种疫苗的行为称为加入“游泳俱乐部”。

Facebook 发言人拒绝置评，但向 NBC 新闻指出，该公司努力将用户吸引到Covid-19 疫苗的权威来源。

使用暗语逃避禁令在反疫苗社区中并不新鲜，它借鉴了极端分子在 Facebook 和其他地方使用多年的剧本。这种做法在很大程度上依赖于“leetpeak”，即编码人员和游戏玩家使用的修改语言，在在线讨论中经常将单词中的字母替换为数字或符号。

# 实例分析

哈佛大学肯尼迪学院肖伦斯坦媒体、政治和公共政策中心研究主任琼·多诺万说：“自从互联网出现以来，疫苗活动家就一直在参与 leetpeak。” “这是反疫苗活动家文化的一部分。”

小组成员采用了一系列编码语言来掩盖他们的讨论，其中许多使关于疫苗的被揭穿的理论永久化。“跳舞”或“喝啤酒”的意思是“接种疫苗”。对“辉瑞”的引用通常使用术语“披萨”或“披萨王”，而 Moderna 被称为“Moana”。用户通常会使用有关跳舞的非官方语言来创建更多的编码语言。

例如，一名团体成员说，她的丈夫在“我们与舞者共度两晚的越野旅行”后生病了，指的是两个刚刚接种疫苗的人。

该小组成员写道：“他认为，在那些跳舞的人身边会导致带状疱疹重新激活。” 在这种情况下，闪光指的是“疫苗脱落”，这是反疫苗活动家中的一种错误理论，声称已接种疫苗的人以某种方式将疫苗“脱落”到未接种疫苗的人身上，并导致他们因一连串的疾病。

# 暗语的使用将会在部分组织中成为常态

编码语言的使用凸显了 Facebook 在遏制多年来在社交网络和其他数字平台上建立的反疫苗情绪方面面临的挑战。Facebook于 2019 年开始打击疫苗错误信息，并承诺在 2020 年对新冠病毒错误信息采取迅速行动

其他极端组织已被发现使用编码语言来避免被发现。反政府 boogaloo 运动的大部分图像来自用于预防性绕过 Facebook 禁令的替代名称。该团体的成员穿着夏威夷衬衫和描绘冰屋的补丁，因为一些最大的 boogaloo Facebook 团体在该团体被 Facebook 驱逐之前更名为“Big Luau”和“Big Igloo”。

多诺万说，在加强公众监督的过程中，极端主义团体将他们的名字改为平庸或听起来没有攻击性的名字，以留住他们建立的观众。
