# 从LinkedIn上的公司Tesla和Breitbart中提取员工姓名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDY1NDg0OA==&mid=2247484715&idx=1&sn=7e08090020255d491e91a8039452698f&chksm=eaa81c44dddf9552efe9c6b33c2b4771230aeea888690de5fbc94e42d389b4013746430fe7f4&scene=126&sessionid=1681654101#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDY1NDg0OA==&mid=2247484715&idx=1&sn=7e08090020255d491e91a8039452698f&chksm=eaa81c44dddf9552efe9c6b33c2b4771230aeea888690de5fbc94e42d389b4013746430fe7f4&scene=126&sessionid=1681654101#rd)

Crosslinked 是另一种从庞大的存储库中自动收集这些数据的工具。

Crosslinked 是用于从 LinkedIn 中提取公司员工姓名的 Python 脚本。

![](../Images/2fe000ffd9b1794efdc756127cc33ae1.png)

当然，我们可以手动执行此操作，但是此工具将为我们节省数十小时的繁琐工作。

第 1 步：启动 Kali

当然，第一步是启动我们值得信赖的 Kali 并打开一个终端。

![](../Images/b665efba1614d1155773b879611408b4.png)

第 2 步：下载并安装 crosslinked.py

Crosslinked 没有内置在 Kali 中，也没有在我们的 Kali 存储库中，但我们可以在 github.com 上找到它。只需从m8r0wn的存储库中克隆它。

kali > git clone https://github.com/m8r0wn/crosslinked

![](../Images/2082bb30d6545b809ecd5cfe5719871f.png)

接下来，我们需要下载并安装crosslinked的依赖包。在我们新的crosslinked目录中应该有一个名为requirements.txt的文件。

kali \> cd crosslinked

kali > pip3 install -r requirements.txt

![](../Images/a936ab81f215f9b7c63ee83695cc835a.png)

第 3 步：Crosslinked Help

在我们开始使用 crosslinked 之前，让我们先看看它的粗略帮助文件。

kali \> crosslinked -h

![](../Images/708ebbe3113d42a3bbba195536d10984.png)

在最简单的形式中，crosslinked的语法如下所示；

crosslinked.py <name format><company>

同样重要的是要注意，您必须授予自己运行脚本的权限。

kali > chmod 755 crosslinked.py

第 4 步：从 LinkedIn 中提取特斯拉员工

现在我们已经用crosslinking脚本设置了所有内容，让我们看看我们是否可以找到埃隆马斯克的电动汽车公司特斯拉的员工。为此，我们需要指定名称格式和公司名称。

kali > ./crosslinked.py -f '{first}.{last}'@tesla.com' tesla

在哪里：

crosslinked.py是命令

\-f名称的格式选项

'{first}.{last}@company.com'要使用的名称格式

特斯拉我们正在寻找的公司

![](../Images/5cb4593dd02954f8747162479206b0ae.png)

当脚本完成运行后，crosslinked 应该在名为names.txt的默认目录中放置一个文件。我们可以通过简单地列出一长串来找到它。

![](../Images/19aa66b0efe671bd4e03a504aa3988ea.png)

要查看此文件的内容，只需在文件名前使用more命令即可。正如我们在上面看到的，crosslinked能够提取数百名在埃隆马斯克的特斯拉工作的人的名字。  

kali > more names.txt

![](../Images/50ae3319b8fe83e0068c15d8963be3b5.png)

第 6 步：提取在 Breitbart News 工作的人员

让我们看看我们是否可以对另一家公司执行相同的任务。让我们找到布赖特巴特新闻（Breitbart News）的员工，这是一本散播仇恨、宣扬阴谋、种族主义和神秘主义的在线杂志。

我们已经在 names.txt 文件中包含了 Tesla 员工，所以除非我们想将 Breitbart 员工附加到该文件中，否则我们需要直接交联以创建一个新文件。我们可以使用\-o开关来做到这一点（请参阅上面的帮助屏幕）。

kali > ./crosslinked.py -f '{first}.{last}@breitbart' breitbart -o breitbart.txt

![](../Images/8c6c0d85945896a20040386a181a466a.png)

现在，crosslinked 出去并从 LinkedIn 中提取 Breitbart 员工姓名。当我们在我们的默认目录上做一个长列表时，我们会发现文件breitbart.txt是我们在上面的命令中引导crosslinked创建的。  

kali> ls -l

![](../Images/32527a00ac0ea9970c9b7f904da106be.png)

我们可以通过在文件名前加上“more”来查看该文件的内容。

kali > more breitbart.txt

![](../Images/97d0490f48c7f4f20d419c99c555a5a5.png)

如您所见，crosslinked 能够从 LinkedIn 中提取数百名在 Breitbart News 工作的员工姓名。你可以感谢这些人用充满仇恨、种族主义、仇外和神秘主义的错误信息玷污了公共话语。

  

概括

互联网蕴藏着大量的信息，等待着不受限制。Crosslinked 帮助我们自动化从 LinkedIn 中提取特定公司员工姓名的过程，这在数字取证调查或渗透测试环境中可能至关重要。
