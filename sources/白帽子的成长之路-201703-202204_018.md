# 二、安全承包公司Constellis文件

泄露主体：埃里克·普林斯（Eric Prince）创立的安全承包公司Constellis文件

泄露日期：2020年

数据量：不详

包含类型：文件

包含2017年至2020年之间由埃里克·普林斯（Eric Prince）创立的安全承包公司Constellis（又名Academi，Blackwater）的文件。阿卡迪米（Academi）在2014年成为Constellis。Constellis在全球范围内安全有效地保护重要优先事项。Constellis的前瞻性解决方案包括…背景调查，社交情报工具，高级培训，后勤和生命支持，UAS和K9服务以及危机应对和缓解措施。
