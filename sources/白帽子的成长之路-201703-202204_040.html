Netcat，Nmap，Gobuster，这些渗透测试工具是渗透测试中经常使用的工具。尤其在各种CTF平台如Hack The Box，Try Hack Me等中。

下面将介绍上面几款软件的升级版的软件。这几款软件包含并比上面几款软件有更加强大的功能。

Pwncat

Netcat的升级版软件。在实验环境中，你一直利用Netcat进行远程命令执行，并且可以使用netcat接收回连的shell。但是Pwncat同样可以提供该功能，同时Pwncat可以提供更多Netcat没有的其他功能。

可以提供历史记录，Tab不全，内置文件传输命令。同时可以作为SSH客户端使用

ppData\Local\Temp\msohtmlclip1\01\clip_image002.jpg)

同时Pwncat还内置了很多内置模块，可以自动将privesc从枚举到持久性安装，甚至特权提升。

更多的功能：

•文件上传下载•自动权限提升枚举•自动化特权升级执行•自动化的持久性安装/删除•自动跟踪修改/创建的文件•自动还原这些远程“tampers”的功能

但是Pwncat是基于python环境的的软件。

安装Pwncat

pip install git+https://github.com/calebstewart/pwncat.git

或者

python setup.py install

安装脚本将会安装三个二进制文件pwncat，pc，pcat。他们都是相同的，只是为pwncat的别名。

pwncat的帮助文档如下：

https://pwncat.readthedocs.io/en/latest/

使用：

# Connect to a bind shell

pwncat connect://10.10.10.10:4444

pwncat 10.10.10.10:4444

pwncat 10.10.10.10 4444

# Listen for reverse shell

pwncat bind://0.0.0.0:4444

pwncat 0.0.0.0:4444

pwncat :4444

pwncat -lp 4444

# Connect via ssh

pwncat ssh://user:password@10.10.10.10

pwncat user@10.10.10.10

pwncat user:password@10.10.10.10

pwncat -i id_rsa user@10.10.10.10

# SSH w/ non-standard port

pwncat -p 2222 user@10.10.10.10

pwncat user@10.10.10.10:2222

# Reconnect utilizing installed persistence

# If reconnection failes and no protocol is specified,

# SSH is used as a fallback.

pwncat reconnect://user@10.10.10.10

pwncat reconnect://user@c228fc49e515628a0c13bdc4759a12bf

pwncat user@10.10.10.10

pwncat c228fc49e515628a0c13bdc4759a12bf

pwncat 10.10.10.10

计划添加的功能：

•更多特权升级方法（sudo -u＃-1 CVE，LXD容器等）•持久性方法（绑定外壳，cronjobs，SSH访问，PAM滥用等）•攻击方法（对终端的垃圾邮件随机性，清除防火墙等）•模块化（terminal-parrot, cowsay, wall, 等）•网络方法（端口转发，通过主机的Internet访问等）
