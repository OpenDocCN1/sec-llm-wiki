Tweetshell是一个shell脚本，可以对推特进行多线程暴力破解密码攻击。该脚本可以绕过登陆限制，并且可以使用20个线程以400+密码/分钟的速度测试无限数量的密码。  

![](../Images/fc03ad24876c7744dad816c9e6f94f41.png)

功能：

多线程（400次/分钟，20个线程）

保存/恢复会话

通过TOR的匿名攻击

默认密码列表

检查有效的用户名

检查并安装所有依赖项

用法：

gitclone https://github.com/thelinuxchoice/tweetshell

cdtweetshell

chmod +xtweetshell.sh

servicetor start

sudo ./tweetshell.sh

安装：  
chmod +x install.sh

sudo./install.sh
