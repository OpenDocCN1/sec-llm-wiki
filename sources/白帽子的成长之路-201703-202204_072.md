  经常会遇到可能包含重要信息的图像，但它们太模糊、嘈杂或混乱，以至于难以理解。

现在许多的的照片的模糊使用的是软件自带的滤镜功能，也就是我们要逆向滤镜功能，把处理好的照片，变得清晰。那么首先介绍一下滤镜功能是怎样实现的。

  **一、滤镜功能实现的介绍**

每个图像都由像素组成的。每个像素都有一个可产生其颜色的值。不同格式的图片保存像素不同种类的值。

例如，灰度图像是“黑白”，并且其中的每个像素都有从0到255的值，其中0是纯黑色，255是纯白色，而RGB图像的像素包含三个值，红色、蓝色和绿色，例如（0，124，255）。可以使用这三种原色来形成所有颜色。

因此照片滤镜只是使用数学运算来修改这些值的结果。请考虑一个6✖6灰度图像，其像素值介于0到255之间。

![](../Images/02da7e09f6d538fc4b263e8be5756f16.png)

  

使用称为Kernel 的东西对其应用滤镜。图像和卷积核都是矩阵。

使用 3×3Kernel：

![](../Images/19891e24924f3eb58287497adb72b1f1.png)

  

然后将这个卷积核放在这样的图像上

![](../Images/e73c3b3e8d26e063602c15be520bcb90.png)

  

把卷积核值和图像的叠加值相乘：

(94 x 0)+ (178 x 2) + (124 x 0) + (23 x 2) + (94 x 4) + (135 x 2) + (153 x 0) + (120 x2) + (140 x 0)=

0 + 356+ 0 + 46 + 376 + 270 + 0 + 240 + 0= 1288，

121288 /12 = 107

现在得出的就是中心的像素（具有94值的像素）的新值。

然后不断替换旧的值。这就是它的工作方式。

卷积核的大小和值确定了输出的图像将是什么。例如，以下卷积核将锐化图像：

```
0 -1 0
```

```
\-1 5 -1
```

```
0 -1 0
```

**  三、反转像素化模糊**

将讨论另一种流行的模糊方法，被称为 Pixelize。

使用此方法模糊的图像可以通过可见的“方格”来识别。以下面的图片为例：

![](../Images/2510e8952c8bcb6628b6b990a34bee61.png)

  

像素化模糊的工作原理是将图像划分为多个正方形，然后将每个正方形中的所有像素替换为其平均值。

例如，如果一个方格有7个黑色像素和7个白色像素，则该方格中的所有像素将变为灰色。

下面来通过应用高斯模糊开始恢复示例图像。

转到 “滤镜”>“模糊”>“高斯模糊”，并继续提高模糊大小（半径），直到那些方格消失，然后单击“应用”。

![](../Images/cbf35290eba52caaf5ff175eb39ea876.png)

  

看起来好多了！现在，按 Shift + Ctril + D 复制图层。

 

现在，转到 “滤镜”>“边缘检测”>“图像渐变”，然后单击“应用”。画面最终看起来像这样：

![](../Images/c6e6b2d82e357a126bd976c5620639b0.png)

现在，转到 “颜色”>“亮度对比” 并逐渐增加对比度，直到获得精致的边缘。

 

在GIMP窗口的右下角，找到以下标签，单击 \\/ 图标，然后从选项列表中选择 “Soft Light”。

![](../Images/075964a60f2902219a4e1037da4de91b.png)

  

可以通过移动那个 opacity 滑块调整此操作的效果。

![](../Images/ff6c6a5d9d187af8dc0b33be440d05b5.png)

将其调整到您想要的程度，这样就可以获得稍微增强的图像。
