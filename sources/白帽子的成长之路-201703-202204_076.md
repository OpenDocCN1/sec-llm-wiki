在这里我们将介绍开源情报工具中的TOP20

**1、    Shodan**

![](../Images/2c5ef453cf6256fb4ebdb714a2d58214.png)

Shodan是一个搜索引擎，用户可以使用各种过滤器查找网络上特定类型的计算机 （网络摄像头，路由器，服务器等）。将提供服务器上运行的服务与端口。

![](../Images/9fb6a71f9103f0d3367417f798e26d13.png)

网址：www.shodan.io

**2、    Recon-ng**

![](../Images/378de4f4ab996e386bfb72d03afb8c92.png)

  

  

开源情报（OSINT）是从公开来源收集的数据，可用于情报环境。Recon-ng是OSINT必备工具。它由lanmaster53用python编写，集成了许多的模块和功能。它包含4个不同类型的模块：侦察、发现、报告和实验模块。

![](../Images/a3406037cefbdb345bb72e2d77e70554.png)

  

  

网址：https : //github.com/lanmaster53/recon-ng

**3、    TheHarvester**

![](../Images/81f45803a478e60eadaaa8c378a9c0a2.png)

Harvester是一种工具，用于从不同的公开来源（搜索引擎，PGP密钥服务器）收集电子邮件账户，子域名，虚拟主机，打开的端口和员工名称。这是一个非常简单的工具，但是对于渗透测试的早期阶段或只是了解您的公司在网络上的可见性非常有效。

![](../Images/942839669d044bd19700a1af465cf3e6.png)

  

**4、    Maltego**

![](../Images/b2747c35b144b9552e45d4c3da65d651.png)

它是一种交互式数据挖掘工具，可提供有向图以进行链接分析。该工具用于在线调查中，以查找来自网络上各种来源的信息之间的关系。Maltego使用转换的思想来自动化查询不同数据源的过程。它是由Paterva开发的。  

下载免费版本：https：//www.paterva.com/downloads.php

![](../Images/f94d6ad5546b544e282d0e8421dcd6b7.png)

  

**5、    Exiftool**

![](../Images/a581c1aa781d44c3e271ebf04bc9d79f.png)

有时文件包含许多的属性信息。这些信息表示为可以使用许多工具提取的元数据。Exiftool是从图像中提取元数据的最受欢迎的工具之一。该工具是免费和开源的。  

![](../Images/97b25f074f4b3d7793425b3815427793.png)

  

  

地址：https : //exiftool.org

**6、    全球恐怖主义数据库**

![](../Images/f52caa5a0070e2551f3c9d6d8dc537c2.png)

  

  

在许多OSINT任务中，您将应对恐怖主义威胁。因此，必须在线收集许多有关恐怖主义的信息。使用最广泛的服务之一是“全球恐怖主义数据库”。该项目由国家恐怖主义与对策研究联盟（START）负责管理，其中包含有关190，000多次恐怖袭击的信息。

![](../Images/8f9314a9da9905da4e3e7778a9f7f312.png)

  

网址：https : //www.start.umd.edu/gtd/access/

**7、    OnionScan**

![](../Images/287ec457b0b068c6d0ab036e4f61f20c.png)

OnionScan 是一个用来在暗网中寻找潜在的泄露数据的利器，最新版本中还加入了一些炫酷的可视化效果，尽管项目的管理团队并没有公布实现深度扫描的技术细节，也没有说明那些看起来非常酷的可视化效果是如何生成的。

![](../Images/569a23ce990e4c476503bd3492e57444.png)

  

官方网站：https : //onionscan.org

**8、    DataSploit**

![](../Images/3262129527461a77672c3be37a4a60e5.png)

  

能够搜索有关公司，人员，电话号码，比特币地址等的信息。一旦收集了数据，它将生成报告，并以不同的格式显示，例如HTML和JSON。

![](../Images/d6dd2dbd80d293ddd219d6bc25df93a6.png)

  

官方Github存储库是：https : //github.com/DataSploit/datasploit

**9、    Openphish**

![](../Images/79d2e7fb9de318b353413d5cf2076f46.png)

  

社会工程学是用于通过心理操纵从他人那里获得有用和敏感信息的一组技术（技术和非技术）。网络钓鱼是一种基于计算机的社会工程攻击。要获取有关有效的网络钓鱼链接和URL的信息，可以使用“ OpenPhish”。它提供了免费的网络钓鱼威胁情报源，以跟踪网络钓鱼URL。

![](../Images/160955c31b285b25d5afdc06f5662135.png)

  

官方网站：https : //openphish.com

**10、  Malware Information SharingPlatform (MISP)**

![](../Images/c86f7c5cacca878b7a8e3d93e6b2e118.png)

  

Malware InformationSharing Platform (MISP)是一个开放源代码威胁共享 平台，分析人员可以在此协作并在它们之间共享有关最新威胁的信息。该项目由Christophe Vandeplas开发，并获得GPL v3许可。

![](../Images/3854e046b1f3951db26f6c5ff6878653.png)

  

官方网站：https : //www.misp-project.org

**11、  Google Dorks（Google hacking）**

![](../Images/5ba0aa02a969ed18ac18e896c024cca5.png)

  

如果你正在使用谷歌作为搜索引擎，你可以使用Google Dorks（Google hacking）。它使用先进的搜索操作符来查找信息。

谷歌Hacking数据库：https : //www.exploit-db.com/google-hacking-database/

![](../Images/46ca1488352e433a9b853f1550269097.png)

  

**12、  Spiderfoot**

![](../Images/5fd9799b9495e2b2c8ec1a5b0ff8fc8c.png)

  

Spiderfoot是一个功能强大的OSINT工具，具有200多个模块，可以执行许多操作，包括扫描，监视和分析。它是免费和开源的。借助其内置的Tor集成，它也可以执行TOR 调查。您可以生成许多不同的报告格式，包括JSON，CSV和GEXF 格式

![](../Images/aa2b086a11397cb72d79e741dc570659.png)

  

官方网站：https : //www.spiderfoot.net

**13、  Lampyre**

![](../Images/d942a2841795ef161e1a9a96ef8cd905.png)

  

Lampyre.io是一个OSINT工具，使您能够在一处获取，可视化和分析数据。您可以导入自己的数据以进行离线分析。由于许多原因，它被执法人员，网络安全专家和财务分析师广泛使用，包括拥有更新的数据源以及使用其Python API根据您的需求和目标自定义项目的能力。

![](../Images/43a0d44bce4f23700b106f9670a8829b.png)

官方网站：https : //lampyre.io

在执行开源情报（OSINT）时，您通常尝试从不同的公共社交媒体平台（包括Facebook，Linkedin，Instagram等）中找到有关人员的信息。为此，您可以使用以下强大的工具和网站：

Instagram开源情报工具：https ://github.com/sc1341/InstagramOSINT

Facebook搜索工具：https：//netbootcamp.org/facebook.html

**16、  Carrot2**

![](../Images/d5ad5f4a3b6c5a19aae777a840ea7767.png)

  

Carrot2是一个在线免费工具，使用Carot2的算法来搜索和组织结果。该工具是免费的，您可以将搜索组织为文件夹，树形图或饼图。

![](../Images/c5de4deb93a2aa06bd45ac109939f50f.png)

![](../Images/b7b2f36f32ac874a018c19cc5b26b3f5.png)

**17、  Censys**

![](../Images/3b33bf42999a26020eb6f54df3738116.png)

  

Censys是另一个出色的在线工具，可帮助你收集有关目标的技术信息。它可以帮助你收集IP地址和域名信息，包括正在运行的服务，地理位置，开放的端口和漏洞。

![](../Images/fc588deffa55ad5b5ab6d108e7094b08.png)

  

官方网站：https : //censys.io

**18、  DNS Dumpster**

DNS Dumpster是HackerTarget.com维护的功能强大的工具。此免费工具可以提供特定域名与IP地址的对应关系。你可以使用它来可视化攻击者从外部看到的内容。收集的信息可以以不同的格式呈现，包括文本和可视化地图。另外，借助其可用的API，它使你能够构建自己的脚本。

![](../Images/46d5d173c5a6538de792004b8ed3f598.png)

官方网站： https://dnsdumpster.com

**19、  VirusTotal**

![](../Images/dc8927cb1a12b9547fee99ff77f92844.png)

  

我们可以使用在线病毒扫描程序并在搜索引擎中搜索其签名。VirusTotal是免费的恶意软件和URL在线扫描服务。它将提供40多种防病毒软件的扫描结果。

![](../Images/b0e703826907acfe26436359656a7230.png)

  

**20、  FOCA**

![](../Images/48d6872d78a0f4a98922e70ba4fe2462.png)

  

FOCA是具有收集的档案的指纹组织的缩写。此工具可帮助你从文档中收集元数据和信息。它可以分析许多不同的文件格式，包括Microsoft Office，Open Office和PDF文件。

![](../Images/4dc4c49265398941194a5d627f7aaf8c.png)

  

官方github地址：https : //github.com/ElevenPaths/FOCA
