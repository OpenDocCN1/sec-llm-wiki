有时候需要mac系统来测试一些东西，这里教大家使用VMware 15安装MAC系统。需要是英特尔的CPU，AMD的不能保证成功，AMD可能会出现无法启动的问题。

环境：win10 家庭版，VMware15.Unlocker 3.0 (解锁Apple Mac OS X)：https://github.com/DrDonk/unlocker

 

VMware 15永久激活密钥：YG5H2-ANZ0H-M8ERY-TXZZZ-YKRV8

MAC OS 10.13 原版ISO系统在我的公众号中发送macos10.13，就会发送给你百度云盘的下载链接。

注意：使用MAC OS 10.13 原版ISO系统，如果使用的是CDR的可能在安装时需要使用app store的apple账号登陆，不然安装不上。安装后需要手动安装Vmware tools，有的环境可能可以直接安装但是本人的环境需要手动安装VMwaretools。存在一个不可以调整屏幕分辨率的问题。

使用Unlocker 3解锁VMware

下载最新版的Unlocker 3

可以使用git clone https://github.com/DrDonk/unlocker就可以下载。如下目录：

       

首先要在服务中手动关闭VMware的全部的服务，然后执行unlock程序。

然后以管理员的权限执行win-install.cmd和gettools.exe。

执行gettools是为了下载最新的VMware tools。但是下载比较慢，网络不稳定，下载不容易成功。可以在http://softwareupdate.vmware.com/cds/vmw-desktop/fusion/8.5.8/5824040/packages/com.vmware.fusion.tools.darwin.zip.tar下载使用，解压出darwin.iso就可以了。

注意路径中不能有中文目录，以免出错。

创建虚拟机

选中自定义或典型都可以，注意再选择系统时，要选择macOS 10.13.

网络的选择NAT，桥接都可以。创建好虚拟机后，不要急着开机。

需改虚拟机的文件。

打开选择的系统的那个目录，找到 wmx 为后缀名的文件，用编辑器打开；

找到 smc.present = “TRUE” 那一行，下面添加一行，内容为：

smc.version = “0”

否则可能会出现以下错误提示：

要把虚拟机的CD/DVD，设置加载自己的macOS 10.13.ISO的系统镜像。然后开机就可以正常安装了。

出现不识别硬盘时，需要使用MAC的磁盘工具，选中VMware虚拟的磁盘工具，抹掉，完成。关闭磁盘工具，就可以识别磁盘了，将系统安装到磁盘中，就可以顺利安装成功了。中间需要设置用户名和密码，和Apple id，也可以不等了Apple id，之后需要再登陆。

安装VMware tools

此时可以使用虚拟机中的安装VMware tools，如果没有提示如下错误，就可以正常安装。

如果出现以上错误，就需要手动安装，此时需要点击MAC虚拟机右下角的CD/DVD,断开连接，再设置CD加载之前下载的darwin.iso。再连接CD。然后MAC系统中就会出现安装VMwaretools的提示，然后就可以正常安装了。

问题：安装VMware tools之后还是无法调整分辨率。该问题，暂时没有解决。
