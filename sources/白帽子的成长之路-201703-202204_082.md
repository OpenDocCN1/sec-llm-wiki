## 一、介绍：

**受限的shell：rbash**

受限的shell用于设置比标准shell程序更受控制的环境。如果bash以rbash名称启动，或者是再调用时提供了-r参数，则shell将受到限制。

**Rbash****中的限制**

与bash相同，不同之处在于不允许或不能执行以下操作：

1、    cd(更改目录)

2、    PATH（设置或取消$PATH环境变量的设置）

3、    ENV aka BASH\_ENV(环境设置与取消设置)

4、    导入功能

5、    指定包含参数“/”的文件名

6、    指定包含参数“-”的文件名

7、    使用重定向输出“>”,“>>”，“>|”，“<>”，“>&”，“&>”

8、    关闭使用限制“set+r”或“set+o”

**受限shell的优点**

Rbash通常与chroot监狱结合使用，以尝试限制对整个过程的访问

受限shell的缺点

当执行shell脚本时，rbash切断生成的shell中的所有约束以执行代码。

不足以允许执行完全不受信任的代码。

**为用户启用受限shell**

1、    创建本地用户ignite并设置密码

2、    使用usermod为本地用户启用rbash

3、    在/etc/passwd的帮助下，确保用户可以访问受限的shell

*   

```
adduser igniteusermod -s /bin/rbash ignitetail -n 1 /etc/passwd
```

**使用vi编辑其绕过**

Vi处于编辑模式，在该模式下，需要运行一下命令来打开标准的shell。

Vi

### 使用编程语言进行绕过rbash

**使用python进行绕过**

使用以下命令生成的shell是标准的shell，而不是rbash。

python -c 'import os;os.system("/bin/sh");'

![](../Images/90b616d7199247676a8a101b9dc417fb.png)

  

  

**使用perl进行绕过**

perl -e 'system("/bin/sh");'

![](../Images/5c946e4326966b9448b75c6bb11916b3.png)
