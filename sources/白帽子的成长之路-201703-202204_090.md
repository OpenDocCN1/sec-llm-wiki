# 实践发现win10下的linux子系统是个坑（WSL）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDY1NDg0OA==&mid=2247483812&idx=2&sn=27ae1643ae15ccad11e28b1a56960684&chksm=eaa818cbdddf91ddac6c2f5930e63d842e815452bcdc87aefdd252e3ba5d08f46a4f5ccb6229&scene=126&sessionid=1681654142#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDY1NDg0OA==&mid=2247483812&idx=2&sn=27ae1643ae15ccad11e28b1a56960684&chksm=eaa818cbdddf91ddac6c2f5930e63d842e815452bcdc87aefdd252e3ba5d08f46a4f5ccb6229&scene=126&sessionid=1681654142#rd)

    以前听说过win10下有个linux子系统，知识自己没有实践过，今天有时间来实践了一下，发现这实在是一个坑，因为许多linux下的api都没有实现，导致许多命令在linux子系统中无法运行。比如ping，nmap软件等都无法运行。

   ** 优点：**可以不使用虚拟机的情况下就可以使用linux环境，保证了基本的linux的操作。  

   ** 缺点：**nmap等软件不可以使用，不可以搭建kali的环境。kali也是在微软商店中存在的，倒是只是基础班，没有安装任何的软件。需要自行安装。  

**系统环境：****win10 家庭版**

一、linux子系统的安装  

在设置中打开开发人员模式，需要一段时间安装必要的软件和库。

![](../Images/622894afa2d00c77c92cfd6a96ff9d75.png)

  

然后打开设置中的应用和功能中的程序和功能，如下图：  

![](../Images/3fb8b80ea318005dfb95d09c42105c2d.png)

在点击启用或关闭Windows功能，找到适用于linux的Windows子系统，勾选。确定。之后会安装一些库和软件，需要重启。重启后就可以安装linux系统了。

![](../Images/eeff4169917f522cc657bcf49b409f12.png)

  

## 二、linux子系统的安装

我这里采用了最简单的方式安装。打开app store，搜索linux就会出现可以安装的各个版本的linux系统了。

![](../Images/ab521c67e344737e11db72c9917ffdaf.png)

  

选择自己想要安装的linux版本。点击安装即可。会提示需要登陆账号，此处不用登陆也可以。

## 三、linux子系统的使用

安装完成后，在cmd中输入bash就可以切换到linux子系统的bash中了。首次启动会提示你输入用户名和密码。

设置root密码，sudo -I ,输入刚刚设置的密码，就可以切换到root下了。再输入passwd就可以设置root的密码了。

![](../Images/68bd25604644e36d8ea263adcf923b22.png)

  

## 四、linux系统中使用图形界面

首先要升级sudo apt update&&apt upgrade

Sudo apt install x11-apps

然后再win10下安装xming的开源软件，这样就可以了。

使用时，需要DISPLAY =:0 vi，需要在开启图形化界面的软件前增加DISPLAY=:0，这样才可以。注意：中间不要有空格。由于我本不打算使用，所以这里没有安装图像化的软件。如下图：

![](../Images/7d6392231862fc65e1e16384de07f2c9.png)

  

## 五、删除linux子系统

在应用和功能中找到，kali linux左键点击就可以卸载，高级选项中还有修复的功能。

![](../Images/b1463253d53c5ef0485f15479b6ff86e.png)

![](../Images/1b2feaa1ea9bcb38cad43e06a8d863d1.png)

  

  

## 六、放弃linux子系统

不能使用ping命令和nmap软件。查阅资料发现，错误相同。以后还不知道有什么坑，所以在此放弃。

  

 

![](../Images/2fdea17d110bc7b76fece27acf2cfac5.png)

  

错误原因是WSL还不支持linux的内核的所有功能。

https://github.com/nmap/nmap/issues/1287#issuecomment-412744085

 

此处号称可以通过更新内核可以解决该问题，因为他使用的是ubuntu，我使用的是kali（Debian）。我没有测试，有兴趣的朋友可以自行测试。链接：https://blog.csdn.net/maoyongf2008/article/details/78948813
