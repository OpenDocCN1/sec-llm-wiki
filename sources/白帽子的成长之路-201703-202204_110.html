使用requests库使用谷歌的API对路由器MAC地址进行定位，但是目前谷歌的定位的API应该是不可以正常使用了。下面还是对进行讲解。

POST数据格式为：

data = {

 "macAddress": MAC

 #"signalStrength": -43,#这里除了MAC地址其他的都可以不用设置

 #"age": 0,

 #"channel": 11,

 #"signalToNoiseRatio": 0

}

返回的数据包为json格式，使用json库进行解析
