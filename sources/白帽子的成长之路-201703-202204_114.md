# mimikatz 2.2.0 20190428发布：Windows安全性的一个小工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDY1NDg0OA==&mid=2247483668&idx=3&sn=e28b257cc3492191ed6ada276c002293&chksm=eaa8187bdddf916d081e2147b953f2bae957a1828d788d7a05f1c10650b9499db76a0cfe8d11&scene=126&sessionid=1681654142#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDY1NDg0OA==&mid=2247483668&idx=3&sn=e28b257cc3492191ed6ada276c002293&chksm=eaa8187bdddf916d081e2147b953f2bae957a1828d788d7a05f1c10650b9499db76a0cfe8d11&scene=126&sessionid=1681654142#rd)

Mimikatz是一个用C语言编写的开源小工具，于2014年4月推出。它非常强大，支持Windows系统内存提取明文密码，哈希，PIN码和Kerberos凭证，并传递哈希，传递 - 票，建立金票和其他黑客技术。它有两种版本：*x64*  或  *Win32*，具体取决于您的Windows版本（32/64位）。  
*Win32 *风格无法访问64位进程内存（如  *lsass*），但可以在Windows 64位下打开32位minidump。  
某些操作需要管理员权限或  *SYSTEM *令牌，  *因此请注意*  *Vista版本中**的**UAC*。
