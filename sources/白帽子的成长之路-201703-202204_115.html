2、获取百度搜索结果的URL

    知道了搜索待测URL关键字了。下面就是获取搜索结果的链接的过程。此处我们使用python编程自动提取搜索结果的URL。python使用的是2.7

defget_real_links(links):

   real_links = []

  #real_links为真实的搜索结果的url链接数组

   for link in links:

       retry = 2 #尝试访问百度加密url链接，如果失败，重试2次

       #printlink

       while(retry>0):

            try:

                header =requests.head(link).headers

                #print header 访问加密的百度链接后，返回数据包的头中的Location

为搜索结果的真实的url链接

                real_links.append(header['Location']) #将真实的url链接添加到数组real_links中

                break

            exceptExceptionas e:

                printstr(e)

                retry-=1

                continue

   real_links = list(set(real_links))#real_links去重

   return real_links

#将真实的Url链接的数组写入filename的文件中

defsave_file(filename,real_links):

   file_object = open(filename,"w+")

   for link in real_links:

       file_object.write(link+'\n')

   file_object.close()
