# 网络安全行业答疑

**1.学渗透或者学安全技术之前是否需要先学编程？**

我个人认为最最开始的时候可以先不用学编程，就先以掌握渗透技能为主。因为编程相对来说会比较枯燥，很多人在刚入门的时候学习编程，就会在这个阶段就被劝退。

但是如果说，你先掌握渗透技能的话，在刚开始阶段是能够很快的就能获得一些成就感，能很好的培养学习兴趣，这样是有利于你坚持去学习的。等你自己学习一段时间以后，你自然就不会再问这个问题了，因为你会发现如果你完全不懂编程的话，那么你将一直停留在脚本小子的阶段，你的渗透技能将会遇到一个不可突破的瓶颈！

所以我的结论就是：编程是一定要学的，但是不是在最最开始的时候学，可以在掌握一定的渗透技能以后再去学习编程

**2.学习网络安全需要考证吗？**

如果你是一个新手小白的话，我不建议你去考，现阶段你要做的是先打好基础，学好安全技术，通过安全能力进入安全圈，千万不要本末倒置，以为花了钱，考了证，就能找到好工作。市面上绝大部分的安全岗位，比方说渗透测试、安全研发等岗位这些技术都不是通过备题考证就能学到的。也就是说在实际的招聘环节里面，无论是企业还是面试官，百分之百考察的核心就是你的技术功底以及项目实战能力。比如说你有没有漏洞挖掘的能力，有没有在平台挖过漏洞，有没有编程开发能力？熟悉什么样的编程语言，接触过什么安全产品，有没有护网攻防演练等等的一些问题，当然了，如果你已经是进来咱们安全圈了，工作可能是1到3年，可能是3到5年，打算为你的安全职业生涯锦上添花的话那完全是可以的

**3.英语不好或者数学不好，能不能学网络安全？**

我认为目前90%以上的同学都还没有达到会受到英语或者数学水平限制你学习的程度

**4.打CTF有没有用有用？**

如果你有机会去参加这个CTF比赛的话，尽可能去参加，即使你去是去打酱油的也无所谓，一定会有收获的。但是尽量还是以实战为主，毕竟企业在招聘的时候主要看的还是你的实战经验

**5.前期刚入门开始学习的时候，该用什么系统？**

其实我觉得就用Windows足够了，因为前期学的东西都是非常基础的东西，这些东西在Windows都是有相应的工具，相应的环境的，所以说在前期你完全没必要用到Linux。

很多人在最开始的阶段，本身什么都不懂，还硬要逼自己用Linux，然后基本的命令也不会，系统也不会装，然后很多人在这个阶段就把自己劝退了。所以在最开始入门的时候，不要想着Linux看起来有那么炫酷，就以最基础的为主，不要把简单的事情搞复杂了！

**6.红蓝队是什么？**

要了解红队和蓝队这两个概念，首先大家要了解一个大的背景：就是近年来，全球的安全局势整体不是很太平，国家之间的攻防对抗也就延伸到了网络空间了。为了提高各自的防御能力，就需要提早做好军事的演习行动，实现更早的练兵。美国最早开启了网络风暴的这种演习行动。其实他就是模拟了网络空间上将安全人员分为攻击方和防守方展开攻防对抗。这里的攻击方指的就是红队，而防守方就是蓝队。

那么他们有什么区别呢？简单来讲，红队的话做的就是渗透测试。漏洞挖掘、服务器开发、APP攻击这么一些技术。而蓝队研究的就是安全响应，安全运营，安全产品、安全合规之间的一些技术。尽管红蓝的技术路线不一样，但是大家的最终的目标是一样的，都是为了保护我们的网络安全

**7.网络安全的书单那么多，全部都要看完吗？**

有很多同学会觉得书太多，看完一本都要好久，那么多要怎么看呢？其实是一个通用的学习问题，大家以前都上过学都知道，其实同类型的书籍你去阅读的时候是逐渐变薄的，比如说同样讲渗透的书，你看第一本的时候觉得挺厚，第二本的时候你就会觉得其实有很多部分跟第一本都是重复的或者非常相似的，所以说到了后面你就会越看越快，甚至有些部分是直接跳过的
