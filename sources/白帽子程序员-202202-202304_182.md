# 2022第三届“网鼎杯”启动报名， 全国级网络安全大赛

“网鼎杯”网络安全大赛是迄今为止全球范围内规模最大、覆盖面最广的国家级高水平网络安全赛事，被称为网络安全“奥运会”，目前已成功举办两届。

    2018年举办的首届“网鼎杯”网络安全大赛，吸引了来自全国14类关键行业，3200多家单位的7008支队伍、22455人参赛，创当时规模之最。

  

    2020年第二届“网鼎杯”网络安全大赛参赛规模在第一届基础上再创世界纪录，来自全国14类关键行业，6000多家行业单位的14724支战队、50165人积极响应，为业界呈现了一场全球最大规模的国家级网络安全赛事。同时，大赛形成的连带效应对全国各行业网络安全建设起到了积极有效的推进作用。

  

    第三届“网鼎杯”网络安全大赛，提档升级，由中华人民共和国公安部作为指导单位，国家网络与信息安全信息通报中心、浙江省公安厅、杭州市人民政府作为支持单位，杭州市余杭区未来科技城管委会、北京永信至诚科技股份有限公司作为主办单位，阿里巴巴（中国）网络技术有限公司、百度在线网络技术（北京）有限公司、奇安信科技集团股份有限公司、清华大学网络科学与网络空间研究院、深圳市腾讯计算机系统有限公司、中国科学院信息工程研究所、杭州根本安全科技有限公司、杭州安恒信息技术股份有限公司、杭州中尔网络科技有限公司作为协办单位，将继续以“最高水平、最大规模、最新技术”为目标，充分调动社会力量积极性，发现选拔网络安全高端人才，进一步筑牢网络安全防线，促进网络空间健康发展。
