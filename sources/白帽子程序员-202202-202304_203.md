# 瑞星兴起

提起杀毒软件，在更早的时候，不得不提的是瑞星，相信还是有部分网友对小狮子有深刻印象。你可能不知道，瑞星杀毒软件曾经占领了杀毒软件市场份额高达80%，年销售额达到了惊人的7亿元。![](../Images/e5ee45f2c651540bd9497755a22ab941.png)要说瑞星发展史就非常早了，至今都有30年了，起于90年代，那时候国内软件还处于起步阶段，正是在这样的背景下，1991年之时，一位名叫王莘的年轻人创立一家公司，名字就是叫做“瑞星”。当时杀毒软件还没有诞生，防止电脑病毒主要依靠是一种叫 “ 防病毒卡 ” 的硬件，所以在创业初期，瑞星主要是研发防病毒卡。![](../Images/60e0f953443f80ae58b7c9c1402b6393.png)到1999年CIH病毒大爆发，瑞星迅速推出相应的杀毒软件和工具，虽然是收费的，但是当时并没有竞争，以致发展成为国内第一家解决CIH病毒的杀毒软件公司，瑞星杀病毒软件月销量突破10万套，全国销量第一。直到2003年为止，瑞星都占据着市场80%的市场份额，年销量一度达到7个亿。

# 瑞星辉煌不再

1999年，金山毒霸以免费的方式高调进入软件市场，相比瑞星，金山毒霸是免费下载使用，很快就获取了第一批用户。免费当然是不长久的，到了2002年8月，金山就分别定价了199元和129元的"金山毒霸2003"和"金山网镖2003"，但是刚出了不久，又使出来营销策略，而且还给这次活动起了个极具震撼力的名字："蓝色安全革命"，价格下降到零售价50元。![](../Images/05cd59c3a56f7bcc925a43a64d5ff8f9.png)到了2006年，奇虎推出360安全卫士，并且声称“永久免费”，一段时间之后，瑞星、金山、江民等厂商受到了严重冲击，毕竟免费白嫖还是比较香的。![](../Images/3361f51e65ae471a4cc7956bf2542fbd.png)2010年，老牌厂商中的金山宣布免费，瑞星依旧还选择坚守。直到2011年，面对大势已去，瑞星才不得不放弃收费策略，转向免费。也是从那时候开始，瑞星越发低调。近几年来，甚至还有网友会问上一句“它还活着吗”？萝卜哥发现，目前瑞星的主要业务是致力于企业信息安全领域。![](../Images/86331e799a136482f4efb3e3637e440c.png)

# 瑞星现状

在瑞星官网显示，瑞星杀毒个人版的更新时间是：2021年4月28日。![](../Images/443aa8e987b90f5873d3827b705e71bf.png)在官网可以看到瑞星会员个人版本一年收费是129元，和360 Total Security收费价格还是很接近了，并且收费版本都是纯净、不弹窗、无干扰。![](../Images/4aac13d04b5f998a9e46fa9cda31232d.png)![](../Images/d8efa83578d75498a0185af564e2077f.png)为了看看瑞星现在体验如何，哥直接“哥以身试毒”，安装界面还是熟悉的小狮子。![](../Images/75ce42f874f458d54d4a11c155c80acd.png)在功能上和360安全卫士很像，都是有病毒查杀、垃圾清理、电脑提速，安全工具等功能。![](../Images/aea041425f8857f30c78230473c316e9.png)瑞星远远赶不上自己光辉的过去，如今的个人免费版本广告弹窗非常频繁，此外萝卜，自安装了瑞星之后，感觉电脑运行变得异常卡顿。![](../Images/621b7036df69fb394a6b0e8032655400.png)此外，如果有安装瑞星相关杀毒软件，那么是无法再安装火绒软件的。![](../Images/ea33d9ffd766c665e928785fb46cd133.png)
