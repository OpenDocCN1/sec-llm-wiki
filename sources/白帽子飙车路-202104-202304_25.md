## 快速上手

Burp客户端提供了所有现成的api接口

我们先把所有接口保存到本地，当然写插件不是所有接口都会用到

![](../Images/24d3f7449b865dd487e8ec56805ec315.png)对应的介绍：https://portswigger.net/burp/extender/api/index.html

### 按官网文档走一遍

#### 新建项目

#### 编写项目

将刚刚保存的接口全部复制过来，同时新建一个类：BurpExtender

```


package burp;
```

![](../Images/d8a1153b44f6c0441d40b5c3ee1e3acc.png)

文件-项目结构-工件

#### 尝试导入Burpsuite

![](../Images/9c6e54dcfac44938e47486f8e4b3d13d.png)

成功导入没有任何报错。但是我们并不知道我们这个插件开发算不算完成了，因为没有任何提示。那咱们直接拿官网的example，打包个hello world

#### hello world

修改BurpExtender

```


package burp;set
 our extension name"Hello world extension"

);true
);true

);"Hello output"

);"Hello errors"

);"Hello alerts"

);in
 our error stream"Hello exceptions"

);
```

官网这个helloworld例子真简单，看来写插件一点都不难![](../Images/32362d6776351c8d561032ca6049613e.png)
