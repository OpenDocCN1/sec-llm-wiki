SecurityTrails（前身为 DNS Trails）拥有大约3.5万亿DNS记录，3亿whois记录，8亿SSL证书记录以及超过4.5亿子域的记录数据。 自2008年以来，网站每天都收集和更新海量数据。


haktrails是一个Golang客户端，用于查询SecurityTrails API数据，由SecurityTrails赞助。


0x01 工具安装

您需要一个安全跟踪 API 密钥才能使用此工具。如果您将其用于漏洞赏金，如果您是漏洞赏金猎人，我建议您查看漏洞赏金猎人的工具包。


获得 API 密钥后，安装 golang，然后：

#Go version > 1.17go install -v github.com/hakluke/haktrails@latest~/go/bin/haktrails
# Go version < 1.17# https://golang.org/doc/go-get-install-deprecation
go get github.com/hakluke/haktrails~/go/bin/haktrails


如果您还没有，我建议您将 ~/go/bin/ 添加到 $PATH 中，然后您可以运行 haktrails


0x02 工具使用

配置文件：

您需要使用安全跟踪密钥设置配置文件才能使用此工具。默认情况下，该工具将在 

~/.config/haktools/haktrails-config.yml

中查找该文件。如果要将配置文件放在其他位置，则必须使用 -c 标志指定位置。


文件的格式非常简单，只需复制粘贴，并将  替换为您的安全跟踪API密钥：

securitytrails:  key: <yourkey>


获取子域名：

这将收集域.txt中列出所有域所有子域。

cat domains.txt | haktrails subdomains


当然，单个域也可以像这样指定：

echo "yahoo.com" | haktrails subdomains


收集关联域：

“关联域名”是一个松散的术语，但通常只是同一公司拥有的域名。这将收集域中每个域的所有关联域.txt



可以使用 -o json 或 -o list 指定输出类型。列表是默认值。列表仅与子域、关联域和关联 IP 兼容。无论如何，所有其他终结点都将返回 json。

cat domains.txt | haktrails associateddomains


收集关联的 IP：

同样，关联 IP 是一个松散的术语，但它通常是指同一组织拥有的 IP 地址。

cat domains.txt | haktrails associatedips


获取历史 DNS 数据：

返回域的历史 DNS 数据。

cat domains.txt | haktrails historicaldns


获取历史 whois 数据：

返回域的历史 whois 数据。

cat domains.txt | haktrails historicalwhois


运行 DSL 查询：

运行自定义安全跟踪 DSL 查询。

haktrails dsl -query <query>


获取公司详细信息：

返回与提供的域关联的公司。

cat domains.txt | haktrails company


获取域详细信息：

返回域的所有详细信息，包括 DNS 记录、Alexa 排名和上次查看时间。

cat domains.txt | haktrails details


获取 whois 数据：

以 JSON 格式返回 whois 数据

cat domains.txt | haktrails whois


获取域标记：

返回特定域的“标记”。

cat domains.txt | haktrails tags


标注：


可以使用 -o json 或 -o list 指定输出类型。列表是默认值。列表仅与子域、关联域和关联 IP 兼容。无论如何，所有其他终结点都将返回 json。


配置文件位置可以使用 -c 设置。默认位置为 ~/.config/haktools/haktrails-config.yml 。下面可以看到一个示例配置文件。


历史 DNS 查找的查找类型可以使用 -type 设置，可用选项为 a，aaaa，mx，txt，ns，soa。


0x03 自动完成（可选）

ZSH 和 Bash 自动完成可用 只需将其添加到您的 ~/.zshrc 或 ~/.bashrc 中即可

source ~/go/src/github.com/hakluke/haktrails/haktrails-completion.zshorsource ~/go/src/github.com/hakluke/haktrails/haktrails-completion.bash


注意：如果您使用的是自定义 GOPATH 位置，请使用它而不是默认位置（即 ~/go）
