> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzIxMjM3Mg==&mid=2247484616&idx=1&sn=eef9d345a05c8eecd33a8a65875bdb01&chksm=72ac3781146e3743456384e8ad3ba972b9a86f240e9f1dc1a0c54685ef6ddd090f556fa91062&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkyNzIxMjM3Mg==&mid=2247484616&idx=1&sn=eef9d345a05c8eecd33a8a65875bdb01&chksm=72ac3781146e3743456384e8ad3ba972b9a86f240e9f1dc1a0c54685ef6ddd090f556fa91062&scene=27#wechat_redirect)

  

SecurityTrails（前身为 DNS Trails）拥有大约3.5万亿DNS记录，3亿whois记录，8亿SSL证书记录以及超过4.5亿子域的记录数据。 自2008年以来，网站每天都收集和更新海量数据。

  

haktrails是一个Golang客户端，用于查询SecurityTrails API数据，由SecurityTrails赞助。  

  

**0x01 工具安装  
**

您需要一个安全跟踪 API 密钥才能使用此工具。如果您将其用于漏洞赏金，如果您是漏洞赏金猎人，我建议您查看漏洞赏金猎人的工具包。

  

获得 API 密钥后，安装 golang，然后：

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
#Go version > 1.17go install -v github.com/hakluke/haktrails@latest~/go/bin/haktrails
# Go version < 1.17# https://golang.org/doc/go-get-install-deprecation
go get github.com/hakluke/haktrails~/go/bin/haktrails
```

  

如果您还没有，我建议您将 ~/go/bin/ 添加到 $PATH 中，然后您可以运行 haktrails

*   
*   

```

```
