这是一款burp插件，用于Outlook用户信息收集，在已登录Outlook账号后，可以使用该插件自动爬取所有联系人的信息。  

  

**0x01 功能介绍**

加载插件后，进入Outlook联系人面板，点击All Users。  

![](../Images/102f1f4f9fe5d19d3ffdfad70e78af5d.png)

  

在burp中 Proxy -> HTTP history 筛选api接口。

![](../Images/ebdbe205372e391435a17f01910d6548.png)

  

选中该请求，右键菜单 Extensions -> OutLook information collection -> Do OoutLook Email scan -> FindPeople scan。

![](../Images/984e75abe96a26e36d0a347451c913e8.png)

  

会在 Extender -> Extensions -> OutLook information collection -> Output 中显示扫描进度。

![](../Images/5071d4a06b2cdb5eb79b88a9daf1c130.png)

  

插件会自动爬取所有数据包并生成目录树，可以查看每一个请求响应包

![](../Images/5c7c1dfe0a0af0136288d4e46a7639eb.png)

  

右击该请求会弹出右键菜单，选择获取所有用户邮箱，即可获得所有的邮箱。

![](../Images/ba13c828ede9afc3de29db51e536aaac.png)![](../Images/d754c141cece54a8a04099556beb03b3.png)

  

注意**：**

该Api会有大量相同url，不同的Post提交参数，如果选错了Api接口，有弹窗提示

![](../Images/b25991ceeda3ee11094a6b2717a588ba.png)![](../Images/5e2e5f9ee0c993a31aa62ad55c2edec3.png)

**0x03 数据保存      
**

在数据展示面板，可以在表格任意位置，右键导出数据到表格，会自动生成表格在burp当前目录，文件名使用UUID，不用担心重复，除非你是欧皇φ(\*￣0￣)
