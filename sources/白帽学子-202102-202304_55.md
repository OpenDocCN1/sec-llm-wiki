![](../Images/7cc0889112e10a3f9c930bc2bdcfb3f0.png)

  

此处有个坑，查看提权脚本

![](../Images/fa53171db49dec0d31b183fe750318d9.png)

  

常规做法是编译成可执行文件到目标机上执行，但代码里有继续调用本地库的操作，很显然，基本上目标机上是没有这些库的，所以在这里的思路是，稍稍修改下代码，再把对应库文件上传。

  

操作如下：  
1、把脚本里对ofs-lib.c操作和判断删除2、把ofs-lib.c和脚本文件上传到目标机

*   
*   

```
#编译expgcc -o exp 37292.c
```

  

找到本地的ofs-lib.so文件跟 exp 文件一起上传到目标机

![](../Images/d164b64dea77f7897d5fe31776b037d7.png)

  

*   
*   
*   

```
#目标机赋执行权限，完成提权chmod +x exp./exp
```
