# 【安全资讯】美国当局关闭了入侵数百万台设备的俄罗斯 RSOCKS 僵尸网络

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkyNzIxMjM3Mg==&mid=2247483849&idx=2&sn=5c2adeb3fa0eb5a11731a1c376bf0cb6&chksm=c22a37f2f55dbee40484c781880786a177a12704b67e7c4d26e5cbc7cef6f3d2158a8a87e12a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzkyNzIxMjM3Mg==&mid=2247483849&idx=2&sn=5c2adeb3fa0eb5a11731a1c376bf0cb6&chksm=c22a37f2f55dbee40484c781880786a177a12704b67e7c4d26e5cbc7cef6f3d2158a8a87e12a&scene=27#wechat_redirect)

美国司法部 (DoJ) 周四披露，它与德国、荷兰和英国的执法伙伴合作，拆除了与俄罗斯僵尸网络 RSOCKS 相关的基础设施。

  

该僵尸网络由一个复杂的网络犯罪组织运营，据信已经诱捕了数以百万计的互联网连接设备，包括物联网 (IoT) 设备、Android 手机和用作代理服务的计算机。

  

僵尸网络是一种不断演变的威胁，是由被劫持的计算机设备组成的网络，受单一攻击方控制，用于促进各种大规模网络入侵，例如分布式拒绝服务 (DDoS) 攻击、电子邮件垃圾邮件和加密劫持。

  

“RSOCKS 僵尸网络允许其客户访问分配给被黑客入侵的设备的 IP 地址，”美国司法部在新闻稿中说。“这些设备的所有者没有授权 RSOCKS 运营商访问他们的设备，以便使用他们的 IP 地址和路由互联网流量。”

  

检察官说，除了家庭企业和个人，包括大学、酒店、电视演播室和电子产品制造商在内的几家大型公共和私人实体迄今为止都成为僵尸网络的受害者。

  

想要从 RSOCKS 使用代理的客户可以通过基于 Web 的店面以不同的价格租用不同时间段的访问权限，从每天 30 美元访问 2,000 个代理到每天 200 美元访问 90,000 个代理不等。

  

一旦购买，犯罪分子就可以通过与受感染的受害者设备相关联的 IP 地址重定向恶意互联网流量，以隐藏他们的真实意图，即执行撞库攻击、访问受感染的社交媒体帐户并发送网络钓鱼消息。

  

该行动是联邦调查局 (FBI) 于 2017 年初开展的一项秘密行动的高潮，当时它从 RSOCKS 秘密购买以绘制其基础设施和受害者，使其能够确定大约 325,000 台受感染的设备。

  

“通过对受害者设备的分析，调查人员确定 RSOCKS 僵尸网络通过暴力攻击破坏了受害者设备，”美国司法部表示。“RSOCKS 后端服务器保持与受感染设备的持久连接。”

  

RSOCKS 的破坏发生在它查获一个名为SSNDOB的非法在线市场后不到两周，该市场用于贩卖美国约 2400 万人的姓名、出生日期、信用卡号码和社会安全号码等个人信息。
