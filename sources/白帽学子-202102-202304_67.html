【安全资讯】大量WordPress网站被黑以将访问者重定向到诈骗网站

原文：http://mp.weixin.qq.com/s?__biz=MzkyNzIxMjM3Mg==&mid=2247483836&idx=2&sn=ffb77360cbe46176fe369fe667a79ce2&chksm=c22a3787f55dbe9159fc3708a1ed29c29d2bfaf096e0b685b9f89a6f12defb10e1949cc5b6d7&scene=27#wechat_redirect


网络安全研究人员披露了一项大规模活动，该活动负责将恶意 JavaScript 代码注入受感染的 WordPress 网站，将访问者重定向到诈骗页面和其他恶意网站以产生非法流量。


Sucuri 的恶意软件分析师 Krasimir Konov在周三发布的一份报告中说：“这些网站都有一个共同的问题——恶意 JavaScript 被注入到他们网站的文件和数据库中，包括合法的核心 WordPress 文件。”


这涉及使用在每次页面加载时激活的混淆 JavaScript 来感染 jquery.min.js 和 jquery-migrate.min.js 等文件，从而允许攻击者将网站访问者重定向到他们选择的目的地。


GoDaddy 旗下的网站安全公司表示，重定向链末端的域可用于加载广告、网络钓鱼页面、恶意软件，甚至触发另一组重定向。



在某些情况下，毫无戒心的用户会被带到包含虚假 CAPTCHA 检查的流氓重定向登录页面，点击该页面会提供不需要的广告，这些广告伪装成来自操作系统而不是来自网络浏览器。


从 5 月 9 日开始，该活动是上个月检测到的另一波浪潮的延续，据信到目前为止已经影响了 322 个网站。另一方面，4 月份的一系列攻击已经入侵了 6,500 多个网站。


“已经发现攻击者正在针对 WordPress 插件和主题中的多个漏洞来破坏网站并注入他们的恶意脚本，”Konov 说。
