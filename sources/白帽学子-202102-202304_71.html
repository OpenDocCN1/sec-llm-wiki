【漏洞情报】微软针对2个Windows零日漏洞和126个其他漏洞发布补丁

0x01 漏洞描述


微软 4 月份的 Patch Tuesday 更新解决了其软件产品组合中的总共 128 个安全漏洞，包括 Windows、Defender、Office、Exchange Server、Visual Studio 和 Print Spooler 等。


修复的 128 个错误中有 10 个被评为严重，115 个被评为重要，三个被评为中等严重程度，其中一个漏洞被列为公开，另一个在发布时受到积极攻击。


这些更新是微软自本月初以来在其基于 Chromium 的 Edge 浏览器中解决的26 个其他缺陷的补充。



积极利用的漏洞（CVE-2022-24521，CVSS 得分：7.8）与 Windows 通用日志文件系统 (CLFS) 中的特权提升漏洞有关。报告该漏洞的是美国国家安全局 (NSA) 和 CrowdStrike 研究人员 Adam Podlosky 和 Amir Bazine。


第二个公开的零日漏洞（CVE-2022-26904，CVSS 得分：7.0）还涉及 Windows 用户配置文件服务中的权限提升案例，成功利用该漏洞“需要攻击者赢得竞争条件”。


其他需要注意的严重缺陷包括 RPC 运行时库（CVE-2022-26809，CVSS 评分：9.8）、Windows 网络文件系统（CVE-2022-24491和CVE-2022-24497，CVSS 评分）中的一些远程代码执行缺陷：9.8)、Windows 服务器服务 ( CVE-2022-24541 )、Windows SMB ( CVE-2022-24500 ) 和 Microsoft Dynamics 365 ( CVE-2022-23259 )。


微软还修补了多达 18 个 Windows DNS Server 漏洞、1 个信息泄露漏洞和 17 个远程代码执行漏洞，所有这些漏洞均由安全研究员 Yuki Chen 报告。还修复了 Windows Print Spooler 组件中的 15 个权限提升漏洞。


在这家科技巨头宣布计划在 2022 年 7 月推出一项名为AutoPatch的功能后一周，这些补丁就发布了，该功能使企业能够及时加快应用安全修复程序，同时强调可扩展性和稳定性。
