![](../Images/e2ec407c07226cb1f41a4d66ca4e2c46.png)

第二步：在URL后添加一个单引号，再次访问，页面返回的结果与id=1的结果不同

![](../Images/54aecd4784acadd2d58dff88c719cd2a.png)

第三步：接着使用“id =1 and 1=1”和“id =1 and 1=2”去访问网页，发现前者页面返回的与id=1的结果相同，后者返回的与id=1'的结果相同。由此可以得出此处可能存在SQL注入

![](../Images/a0cbce21f71f0ee8f9e8b1db15304778.png)![](../Images/b566e4a6601412a5ac485ca862702119.png)

第四步：通过order by语句查询数据表的字段数量。当我们访问“id =1 order by 3”时返回的结果与“id=1”相同，访问“id =1 order by 4”时返回的结果与“id=1”不同，由此可以推断出数据表的字段数为3

![](../Images/e351120e2710194c0c3be3b1cf42f53d.png)![](../Images/465fd46a2275035e4b13be9e506e5b64.png)

第五步：下面我们使用union注入。下面输入“id=1 union select 1,2,3”，显示的结果与“id=1”相同

![](../Images/2cd463dabea928c63f21d55df6d5c63b.png)

第六步：上面因为“id=1”的结果为真，所以后面的“union select 1,2,3”就没有显示出来，下面我们构造一个“id = -1 union select 1,2,3”，由于数据库中没有id=-1的数据，所以就会返回union select的结果

![](../Images/345425795c104380ac29448bd656dfe5.png)

第七步：上面的select的返回结果为“2:3”，说明“union select 1,2,3”中只有2和3的位置可以输入MySQL语句，那么下面我们在2的位置查询当前数据库名（使用database()函数），可以看到当前的数据库名为“sql”

![](../Images/f14b4c7305528d97afb838ad33d61fb4.png)

![](../Images/63a9577a6988bcc49136728fe7521834.png)![](../Images/bc2f33bade8f0cdbbfcb5cb984bb3ca5.png)

如果想要获取更多表名可以删除limit或者改变limit的参数，下面是limit 1,1来获取第二个表名（“referers”）

***02***

**Boolean注入**

Boolean注入是指构造SQL判断语句，通过查看页面的返回结果来推测哪些SQL判断条件是成立的，以此获取数据库中的数据

演示案例

Union注入的测试地址是：http://www.xxx.com/boolean.php?id=1

第一步：访问该网址时，页面返回“yes”

![](../Images/a347c6d5b2871de1516a60b6bdfdddb3.png)

第二步：在“id=1”后面加上一个单引号访问，结果变为了“no”

![](../Images/44ed5ce211637d68f2a8e4f5a6fdb033.png)

第三步：当分别使用“id=1' and 1=1%23”和“id =1' and 1=2%23”访问时，网页只返回yes或no，而没有返回其他数据库信息，说明此处不能使用Union诸如，可以尝试使用Boolean注入

第四步：我们先判断数据库名的长度，语句如下（因为有单引号，所以需要注释符来注释），我们先使用数字1来判断数据库名的长度是否大于等于，结果显示为yes

![](../Images/59d803375387ea5ace54691ccc3d3a76.png)![](../Images/0212f76bd1e5185c3ec26b73d662fbdd.png)

接着再使用3和4来判断数据库名的长度，结果分别显示为yes和no，因此可以得出数据库名的长度为3

![](../Images/7c2b4584325aa72d0080460b50e86993.png)![](../Images/d58997fc1907306f33fee74e99680029.png)

第五步：接着，使用逐字符的方式获取数据库库名（数据库名可以又a~z、0~9、特殊字符组成）

substr函数具有字符串截取的功能，下面是substr是从数据库的第一个字符开始截取，截取一个字符长度（备注：mysql中截取的索引是从1开始的，不是从0开始的）

例如下面我们截取数据库名的第一个字符，并判断是否等于字符“t”。在实际中，我们逐个判断，发现只有当字符“s”返回yes，其余均返回“no”，因此数据库名的第一个字符为“s”

![](../Images/3e58fd24a4f66c7fe5940681cb4098fb.png)![](../Images/54cf73b155ed0d804ab6d36735c86ace.png)

第六步（可选）：除了第五步中的方法，我们还可以使用Burp Suite软件的爆破功能来爆破数据库名

第七步（可选）：除了第五步和第六步中的方法，我们还可以构造其它格式的URL，例如ASCII的转换，mysql中的ASCII转换的函数为ord。字符“s”的ASCII码为115

![](../Images/a5c89040f0e9a833db503045f8ac538f.png)![](../Images/4a1a55b4bbab90f8a0730efd0846a9cb.png)

第八步：通过前面的Union注入我们可以知道，s开头的数据库可能是数据库“sql”，因此我们判断数据库名的第二个字符是否为“q”，结果显示yes

![](../Images/569cc11d008cbd33dacc26421c0e230b.png)![](../Images/6aa3de1a36c58a18c5c0595d85b7f97c.png)

第九步：我们将substr的参数1变为查询sql数据库中的第一个表名（emails）的语句，并判断第一个表名的第一个字符是是否为“e”，结果显示yes，与预期一致

![](../Images/b7d8e07b61dc655e0108a6f54cb650fb.png)![](../Images/cb0338bb3d49261af1462998383fc11d.png)

第十步：以此类推，就可以与Union一样，查询出所有的表名和字段名

Boolean注入代码分析

  

程序先获取GET参数ID，通过preg\_match判断其中是否存在union/sleep/benchmark等危险字符。然后将参数ID拼接到SQL依据，从数据库中查询，如果有结果返回yes，否则返回no

当访问“id =1' or 1=1%23”时，数据库执行的语句为（select \* from users where 'id'='1' or 1=1#），由于or 1=1是永真条件，所以页面会返回yes

当访问“id =1' adn 1=2%23”时，数据库执行的语句为（select \* from users where 'id'='1' and 1=2#），由于and 1=2是永假条件，所以页面会返回no

$id = $_GET['id'];
if (preg_match("/union|sleep|benchmark/i", $id)) {  exit("no");}
$result = mysqli_query($con,"select * from users where `id`='".$id."'");
$row = mysqli_fetch_array($result);
if ($row) {  exit("yes");}else{  exit("no");}
?>
