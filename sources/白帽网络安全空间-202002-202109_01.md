#### 实验环境：

WindowsXP、VC++6.0、OllyDbg

#### 示例代码:

```
#include <stdio.h>
#include <string.h>

#define PASSWORD "1234567"
int verify\_password(char \* password)
{
int authenticated;
char buffer\[8\]; //add local buff to be overflowed
authenticated \= strcmp( password, PASSWORD);
strcpy(buffer,password);  //溢出点
return authenticated;
}

void main( )
{
int valid\_flag \= 0;
char password\[1024\];
while(1)
{
printf("please input password: ");
scanf("%s",password);
valid\_flag \= verify\_password(password);
if(valid\_flag)
{
printf("Wrong password,please input again: \\n\\n");
}
else
{
printf("Login succeeded!\\n");
break;
}
}
}
```

**函数注释：**

头文件：`#include <string.h>`

`strcmp()` 用来比较字符串（区分大小写），其原型为：`int strcmp(const char *s1, const char *s2);`

【参数】`s1, s2` 为需要比较的两个字符串。

字符串大小的比较是以ASCII 码表上的顺序来决定，此顺序亦为字符的值。`strcmp()`首先将s1 第一个字符值减去s2 第一个字符值，若差值为0 则再继续比较下个字符，若差值不为0 则将差值返回。例如字符串"Ac"和"ba"比较则会返回字符"A"(65)和'b'(98)的差值(－33)。

【返回值】若参数s1 和s2 字符串相同则返回0。s1 若大于s2 则返回大于0 的值。s1 若小于s2 则返回小于0 的值。

  

#### 破解过程：

1.  生成Debug版的exe程序：![](../Images/b7ddb67c6f9dfae10b4d2fde10c6d515.png)
    
2.  用OllyDbg打开exe程序：
    
    ![](../Images/8f8219452dde7660652492875a3e412f.png)
    
3.  为了尽快定位到分支语句处，在反汇编窗口右击，选择"搜索"--“所有被引用的字符串”：
    
    ![](../Images/e37b080d1d5204888b06ec586da85759.png)
    
4.  然后使用快捷键Crtl+F打开搜索框，输入wrong，定位出错信息的那一行代码，如图：![](../Images/2ca2be6848a9860233a058d7a56ce8dd.png)
    
5.  双击这行代码，就会定位到反汇编中的相应代码处，如图：![](../Images/3b7cfb85bae50c82f89b8b181bd5e459.png)
    
6.  如果je条件成立，就跳转到00401106处，即密码错误分支。此时，如果将je指令改为jne（即取非），则程序逻辑相反，输入错误密码，将进入验证成功的分支中。
    
    双击je代码行，对其进行修改，如图：
    
    ![](../Images/701b7210c4bc8cdd1e09a7fd36afe200.png)
    
7.  点击【汇编】按钮，修改指令，此时并没有修改二进制文件中的有关代码，需要在反汇编窗口右击，选择“编辑”--“复制到可执行文件”，如图：
    
    ![](../Images/ed068b4f9b1cf1b827542b22c124f511.png)
    
8.  继续右击，选择保存文件：
    
    ![](../Images/f2c6b9f645c30bd255bf6018899dc933.png)
    
9.  选择另存一个exe程序，如图：
    
    ![](../Images/3cb06442475896aeefb78df4d46a8a95.png)
    
10.  运行破解程序，进行验证：
     
     ![](../Images/225656d301f5ac013fceb1949029970d.png)
     
11.  输入错误密码，成功通过登录验证，破解成功。
