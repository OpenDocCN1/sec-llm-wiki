工具准备：Burpsuite、Pkav HTTP Fuzzer1.5.6

PKAV HTTP Fuzzer是PKAV团队编写的一个带图形验证码识别的渗透测试工具。

**1****、****首先尝试登录，使用BP抓包**：

![](../Images/2d7f6f8caba9a29fc2003c78b3aae085.png)

**2****、发送到Repeater模块重放、分析：**

![](../Images/1d40191f801ab08c017cecb031db7e63.png)

用最新的验证码进行重放，如果提示“登录失败”，说明是后台验证，并且再次提交提示为“验证码错误！！”，说明验证码只能用一次，但是验证码并不在前台代码中显示，而是一个简单的图片验证码。

![](../Images/30da6e3beffd44d5488cd693cd7c5416.png)
