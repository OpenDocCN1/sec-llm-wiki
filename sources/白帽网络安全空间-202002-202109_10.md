# Pikachu漏洞练习平台之暴力破解4-token防爆破

在WEB渗透中经常可以看到页面存在一次性 token 校验的情况，即请求包中包含 token，而token 值需通过其它页面获取，导致 burpsuite 抓包后无法重放。**1、分析问题**随便输入账号密码抓个包看看![](../Images/3fd3ab725c1c811cf5cf9b321c11a654.png)![](../Images/aa1afaa77f8a6d103fedc44ba503d9b4.png)发现除了账号密码外还多了一个参数token，这是什么东东我们得去验证下它的工作方式，把数据包发送到Repeater模块，发现token值发生了变化：![](../Images/b435f8592f08f95c3751c5fa842d4137.png)再换一个账号密码提交一次，结果一样：![](../Images/522c956fda3408a5e549de2c644bf456.png)提交一个空的token，结果也一样：![](../Images/f598f46f1f5ecf1915fb2b87bfbfc131.png)这样导致 burpsuite 抓包后无法重放进行爆破。**2、****既然这个token写在了前端页面中，能不能通过动态获取页面中的token来绕过呢？**我们先来验证一下这个思路：打开firefox浏览器的开发者工具，在代码查看器中找到了页面中的隐藏元素input，它的值正是token：![](../Images/3049994e31deeee2eaf29daf96d67ce1.png)复制最新的token值到Repeater，再次验证：![](../Images/3ef5252fa8acbf76cef2cea6b6e86b85.png)出现了username or password is not exists提示，说明token验证通过了。**3、****那么疑问来了，要怎么暴破时怎样才能带上正确的token值？**可以尝试使用 burpsuite 的宏功功能，自动把登陆页的token值抓取出来填入登陆请求，创建宏，获取 token 值：![](../Images/9fed9e9c6a4688cac8227d7204116fd4.png)在 Macro Recorder 中选择包含要获取的 token 的页面：![](../Images/33517da8a3b21b17978ccaf7248c9dd2.png)![](../Images/b08715395afb30d759d1eebb568e0bd7.png)![](../Images/a3997b1fe3d4d47f22c856ff306e9d0a.png)配置 Macros 用鼠标选中 token 值，burpsuite 会自动填写开始标记以及结束标记，并且写上 Parameter name 为 token，注意这里的参数名 token 是与要爆破页面里的 token 名称一致：![](../Images/8853333533de0aa88300bd98326bb500.png)到此宏建立完成。接着创建 Session Handling Rules 然后在 Session Handling Rules 里面新建一条规则以执行宏：![](../Images/fe1cfb2a26f03bb4cd74d4d72ed06ea8.png)![](../Images/1b7dbf52d23abaeb86eb5b4caa8b648b.png)![](../Images/eb8f61e9304ecbc9b32bbe5cac14f8a8.png)设置宏的影响范围， Tools Scope 选中 Repeater、Intruder 就行了，其它模块可根据实际需要勾选：![](../Images/5c384d539480388f447d74bfeb1b96f0.png)![](../Images/266c47c2a8bc97f0cede0e7db0fae73b.png)这时候再重放发现token是自动变化的，表面通过宏自动获取了token值。![](../Images/575d471d6e5de82d3c922d6a7b908ec7.png)最后一步，将爆破线程设置为1（因为如果是多线程它们会同时刷新token，就无法取得正确的token）：![](../Images/ef29d88ba863eea259751490f471411f.png)**4、攻击测试：**![](../Images/44734456bd4189e847dbd6a1eb10be36.png)**5、以admin，123456尝试登陆：**
