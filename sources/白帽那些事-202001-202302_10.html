iwebsec漏洞靶场

集合SQL注入、文件上传、文件包含、命令执行、代码执行、XSS、SSRF、XXE、反序列化、中间件、解析、数据库常见漏洞


实验环境

centos8

docker20.10.2

VMware® Workstation 16 Pro


从软件包安装docker

先下载安装包，再用xshell传到centos

https://download.docker.com/linux/centos/8/x86_64/stable/Packages/

yum instal containerd.io-1.4.3-3.1.el8.x86_64.rpmyum install docker-ce-20.10.2-3.el8.x86_64.rpm docker-ce-cli-20.10.2-3.el8.x86_64.rpm docker-ce-rootless-extras-20.10.2-3.el8.x86_64.rpm


报错1

解决方法

yum install containerd.io-1.4.3-3.1.el8.x86_64.rpm --allowerasing

报错2

解决方法

yum clean packages  #清除安装缓存yum remove podman-manpages-1.4.2-5.module_el8.1.0+237+63e26edc.noarch #移去错误模块yum install docker-ce-20.10.2-3.el8.x86_64.rpm docker-ce-cli-20.10.2-3.el8.x86_64.rpm docker-ce-rootless-extras-20.10.2-3.el8.x86_64.rpm #重新安装


配置docker

docker -v #查看docker版本systemctl start docker #启动dockersystemctl enable docker #设置开机启动


安装靶场

docker pull iwebsec/iwebsecdocker images #列出本地镜像find / -name iwebsec_info.md #查找iwebsec说明文件cat /var/lib/docker/overlay2/ac8e8a40c2bad49900eb1d43e5417a736c11e44aa317aaf252069037037fe9eb/diff/root/iwebsec/iwebsec_info.md #查看说明文件docker run -d -p 13307:3306 -p 80:80 -p 7001:7001 -p 8080:8080 -p 8088:8088 -p 8000:8000 -p 6379:6379 iwebsec/iwebsec #启动靶场
