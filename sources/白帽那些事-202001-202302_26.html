01


表单

每个网页都存在表单，表单中存放着这个网页的一些基本信息，比如第几页，cookies等等。想要抓取某个网站的页面信息，首先要先观察其表单形式。请求包一般有两种表单提交形式：

get：get形式提交表单，表单会直接存放在url中，我们可以通过直接修改url来修改表单。

post：post形式会把表单存放在请求包正文中，因此，如果一个网站使用了post形式提交表单，我们就需要获取表单结构并构造表单。本次我们先使用get提交表单。

02


百度贴吧页面爬取

首先先观察百度贴吧某个贴吧第一页，第二页，第三页的url链接组成。（请点击最下方第一页，第二页，第三页才会看到以下截图信息）

观察三页的信息，可以看到，第一部分为百度贴吧域名，第二部分kw为访问的贴吧的名字dota2，第三部分pn为帖子开始位置。第一页为0，第二页为50，第三页为100，经过计算会发现，百度贴吧每页会显示50个帖子，因此，我们只要以50的倍数跳页，就可以进行翻页了。

代码：

#导入模块import urllib.request, urllib.parse#保存页面def save_html(html, num):    with open("第"+num+"页.html", "wb") as f:        f.write(html)#组合url链接def loadURL(url, name, num):    name = urllib.parse.quote(name)    full_url = url+"/f?kw="+name+"&ie=utf-8&pn="+num    print(full_url)    return full_url#发送请求包，返回响应包内容def searchHTML(url):    request = urllib.request.Request(url)    request.add_header("User-Agent", "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/80.0.3987.149 Safari/537.36")    html = urllib.request.urlopen(request)    return html.read()#代码运行内容if __name__ == '__main__':    url = "https://tieba.baidu.com"    name = input("请输入你要爬取的贴吧名字：")    num = input("请输入你要爬取的页数：")    name = name    for i in range(int(num)):        full_url = loadURL(url, name, str(i*50))        save_html(searchHTML(full_url), str(i+1))
