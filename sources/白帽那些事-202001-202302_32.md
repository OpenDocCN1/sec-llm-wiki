metasploit全局代理补充

说到metasploit，这里分享另一个设置全局代理的方法，这个是官方提供的，效果跟proxychains是一样的。设置命令  

*   
*   

```
setg RversAllowProxy truesetg Proxies socks5:127.0.0.1:1080
```

如图

![](../Images/0ff4c36d73326cacc2fc4d484662649f.png)

设置成功后默认就是通过代理来操作。（如果想验证的话可以利用msf中的ssh暴力破解工具，随便设置一个错误的用户名和密码，然后到你的ssh服务器查看错误登录日志的ip是不是代理的ip就可以了）  

清除代理命令

*   
*   

```
unsetg RversAllowProxy trueunsetg Proxies socks5:127.0.0.1:1080
```
