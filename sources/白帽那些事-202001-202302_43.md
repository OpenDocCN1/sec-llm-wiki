![](../Images/41714da5e745150170f2f7268e407143.png)

   6.生成秘钥对

二、Xshell连接EC2实例     1.打开Xshell，并进入”用户密钥”界面

![](../Images/5679197ce7f8cf423ad10572dcdf2702.png)

      2.在”用户秘钥”中选择”导入”按钮，导入之前准备好的.pem文件。导入之后，选择”关闭”按钮关闭该界面。

![](../Images/7b5d77a14868fc66f455908949fc3545.png)

     3.选择”文件”菜单下的”新建..."项，弹出”新建会话属性”对话框，在左侧列表框中选择”连接”，在右侧界面中输入会话名称和主机IP  

![](../Images/746a2aa6af66410691432e130279049b.png)

  
     4. 在左侧列表框中选择”用户身份验证”，修改右侧界面：”方法”项的值改成”Public Key”；”用户名”项的值固定为ubuntu（非我们在AWS注册的账户名）；“用户密钥”项的值是下拉框中选择上一步导入的pem文件，点击”确定”按钮，完成设置。  

![](../Images/178e67e8cb6c5bab9d5d2f6d19011063.png)

      5.如果是第一次连接，会弹出一个警告框，如果只是临时用的会话连接，则选择”一次性接受”按钮；如果是以后要一直使用，则选择”接受并保存”按钮。      6.之后，XShell会打印出成功登录后终端内容

![](../Images/acffad3614a267963c08cabd1796c3a6.png)

  

三、安装shadowsocks服务器

1.  # 获取root权限

         sudo -s

2.  # 更新apt-get

          apt-get update

3.  # 安装python包管理工具

         apt-get install python-setuptools

        apt-get install python-pip

4.  # 安装shadowsocks

         pip install shadowsocks

5.创建配置文件

        mkdir /etc/shadowsocks

        vim /etc/shadowsocks/ss.json

在打开的文件中按”i”键进入insert模式，然后输入

{

    "server":"0.0.0.0",

    "server\_port":443,

    "local\_address":"127.0.0.1",

    "local\_port":1080,

    "password":"你要设置的密码",

    "timeout":300,

    "method":"aes-256-cfb",

    "fast\_open":false

  }

  

后，按”ESC”退出Insert模式，再输入”:wq”保存退出配置文件。配置文件中的端口号和密码可以自行设置。

6. 运行shadowsocks服务器

在Xshell中以root权限（非root则输入sudo –s回车）输入下列命令启动shadowsocks服务

ssserver -c /etc/shadowsocks/ss.json -d start

如果出现下列错误

File “/usr/local/lib/python2.7/dist-packages/shadowsocks/crypto/openssl.py”, line 52, in load\_openssl

libcrypto.EVP\_CIPHER\_CTX\_cleanup.argtypes = (c\_void\_p,)

File “/usr/lib/python2.7/ctypes/init.py”, line 375, in getattr

func = self.getitem(name)

File “/usr/lib/python2.7/ctypes/init.py”, line 380, in getitem

func = self.\_FuncPtr((name\_or\_ordinal, self))

AttributeError: /usr/lib/x86\_64-Linux-gnu/libcrypto.so.1.1: undefined symbol: EVP\_CIPHER\_CTX\_cleanup

则按照下列方法解决

1)  用vim打开文件：vim /usr/local/lib/python2.7/dist-packages/shadowsocks/crypto/openssl.py (该路径请根据自己的系统情况自行修改，如果不知道该文件在哪里的话，可以使用find命令查找文件位置)

2)  跳转到52行（shadowsocks2.8.2版本，其他版本搜索一下cleanup）,进入编辑模式,将第52行libcrypto.EVP\_CIPHER\_CTX\_cleanup.argtypes = (c\_void\_p,) 改为libcrypto.EVP\_CIPHER\_CTX\_reset.argtypes = (c\_void\_p,)

3)  再次搜索cleanup（全文件共2处，此处位于111行），将libcrypto.EVP\_CIPHER\_CTX\_cleanup(self.\_ctx) 改为libcrypto.EVP\_CIPHER\_CTX\_reset(self.\_ctx)

4)  保存并退出,重新在Xshell中以root角色执行命令ssserver -c /etc/shadowsocks/ss.json -d start 来启动shadowsocks服务器

除了启动服务外，如果希望停止shadowsocks服务，则输入

ssserver -c /etc/shadowsocks/ss.json -d stop

如果希望重启shadowsocks服务，，则输入

ssserver -c /etc/shadowsocks/ss.json -d restart

  

四、使用shadowsocks客户端访问

1）下载shadowsocks客户端并安装。

2）找到服务器设置窗口，添加服务器，地址为AWS的外网地址，登录AWS控制台，查看正在运行中的实例，找到公有ip。端口号为刚才配置Shadowsocks服务器时的端口号，密码也是刚才配置的，加密方式选择"aes-256-cfb"，设置完之后确定。
