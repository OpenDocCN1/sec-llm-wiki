反馈也是很快的，激活码如下。

![](../Images/dd26fc402e363bbc452159b46c717fe8.png)

接着我们就可以安装使用了。  
这里我们以linux为案例。  
只需要把linux的压缩包下载下来，然后丢你的本机或者是vps即可。

然后运行两条命令即可

*   
*   

```
chmod +x install.sh./install.sh
```

![](../Images/9b76ce884993c7c07c8a44de53d1130b.png)

然后运行成功后在当前目录会有一个config.yaml文件生成，把其中的platform参数改成你vps的ip即可。

![](../Images/9229e23ceaef2e04892bc8b6d1f8db49.png)

然后需要重启一下改服务，命令如下：

*   
*   
*   
*   
*   
*   

```
# 重启systemctl restart daybreak# 查看状态systemctl status daybreak# 停止systemctl stop daybreak
```

然后访问VPS的ip+端口即可。

![](../Images/a988fecbc5c4babb7960f73446c2bdce.png)

第一次需要输入激活码，激活完成后登录即可。

![](../Images/6419d98d36295ca90097d4da83c67e3d.png)

进入之后我们可以大致看看功能，第一个是创建监听器。  

![](../Images/907f20b61fa86846fec784f475560497.png)

然后生成探针，选择上线主机的系统类型。

![](../Images/67f806a318e3de261c6725a1112623de.png)

第二个是会话管理，界面属实舒服。  

![](../Images/31e261d2c46e0950ab18141641f7cf63.png)![](../Images/6edbfcff9ea19558a889364c69e33de6.png)

倒数第二个是任务管理，我们可以添加探测任务，帮助我们内网快速打点。

![](../Images/5206f4f560101905bbb07c508b5bfdfd.png)

![](../Images/ad97987403a21e2c25b077369484c749.png)

除此之外，还有很多其他好用的功能，大家可以试试看，具体可参照官方操作文档。
