APT组织

  

**WIZARD SPIDER使用500多个域开展大规模的网络钓鱼活动**

WIZARD SPIDER组织总部位于俄罗斯，主要从事网络诈骗活动。近日，网络情报公司Prevailion研究人员发现该组织使用500多个域名开展大规模的网络钓鱼活动窃取Naver的凭证。Naver是韩国类似Google的在线平台，提供从网络搜索到电子邮件、新闻和提供在线问答平台的各种服务。在调查过程中发现，有532个域名用于以Naver为主题的网络钓鱼，下图是攻击者使用电子邮箱地址注册的大量域名和一个相同的IP解析地址。由于使用的基础设施与WIZARD SPIDER历史基础设施存在重叠，因此，将此次攻击活动归因于WIZARD SPIDER。

![](../Images/654a8a60518be96a7ad2bc7906fde76b.png)

来源：

https://www.prevailion.com/what-wicked-webs-we-unweave/

  

## **Mandiant披露新组织UNC2891**

Mandiant研究人员披露了一个安全运营能力突出的新组织UNC2891，该组织主要使用TINYSHELL和SLAPSTICK后门，针对Oracle Solaris系统开展攻击活动，攻击意图疑似为牟取经济利益。在攻击过程中，该组织展示了其在Linux和Unix操作系统中的专业性。Mandiant还发现UNC2891与此前披露的UNC1945在TTP方面存在重大重叠，目前还没有确凿的证据将UNC2891归因于特定的已知APT组织。

来源：

https://www.mandiant.com/resources/unc2891-overview

  

**MuddyWater开展新的网络攻击活动**

MuddyWater又名“MERCURY”或“Static Kitten”，被美国网络司令部归属于伊朗情报与安全部(MOIS)。MuddyWater组织至少从2017年开始活跃，经常在北美、欧洲和亚洲地区开展攻击活动。近期，Cisco Talos披露了该组织针对阿拉伯半岛的网络钓鱼活动，通过分发恶意文档部署基于WSF的恶意软件SloughRAT.攻击者会利用SloughRAT执行恶意载荷或部署开源反向隧道工具Ligolo，以更大程度地控制受害目标。下图是感染链。

攻击活动

  

## **俄罗斯国家支持的针对NGO组织的漏洞攻击活动**

美国联邦调查局(FBI)和网络安全与基础设施安全局(CISA)发布告警：俄罗斯国家支持的攻击者，通过利用默认MFA协议和已知漏洞获得网络初始访问权限，并开展攻击活动。早在2021年5月，攻击者利用了一个非政府组织(NGO)中设置默认MFA协议的错误配置的帐户，允许攻击者为MFA注册了新设备，并访问受害者网络。接入成功后，攻击者利用了一个关键的Windows Print Spooler漏洞“PrintNightmare”（CVE-2021-34527），进而使用系统权限运行任意代码。

来源：

https://www.cisa.gov/uscert/ncas/alerts/aa22-074a

  

## **使用DNS Tunnel技术的Linux后门B1txor20正在通过Log4j漏洞传播**

360Netlab系统捕获了一个未知的ELF文件通过Log4j漏洞传播。此文件在运行时产生的网络流量引发了疑似DNS Tunnel的告警。基于其传播时使用的文件名"b1t"，XOR加密算法，以及RC4算法密钥长度为20字节，360Netlab研究人员将恶意程序命名为B1txor20，并认定为一种全新的僵尸网络家族。B1txor20用DNS Tunnel技术构建C2通信信道，除了传统的后门功能外，B1txor20还具有开启Socket5代理，远程下载安装Rootkit，反弹Shell等功能。下图是基本流程图。

漏洞情报  

  

**Linux内核漏洞CVE-2022-0847**

近日，研究人员在Linux内核发现高严重漏洞，将该漏洞编号为CVE-2022-0847，它影响从5.8到5.16.11、5.15.25和5.10.102之前的任何版本的Linux内核，并可用于本地权限提升。该漏洞存在于管道工具中，管道工具用于进程之间的单向通信。目前还没有发现对该漏洞进行大规模利用，但网上有该漏洞的详细描述和有效的POC，这增加了该漏洞被攻击者利用的风险。

来源：

https://securelist.com/cve-2022-0847-aka-dirty-pipe-vulnerability-in-linux-kernel/106088/

  

## **Veeam软件中存在严重漏洞**

Veeam Software是Insight Partners旗下的一家美国私有信息技术公司。近日，研究人员发现Veeam 的数据备份软件中两个严重漏洞CVE-2022-26500、CVE-2022-26501。这两个漏洞无需身份验证就可以远程执行恶意代码。这两个漏洞可能导致攻击者获得对目标系统的控制，并影响虚拟环境的备份和复制解决方案。目前漏洞已经修复。

| 漏洞名 || 影响 |
| --- | --- |
| CVE-2022-26504 || 影响用于Microsoft System Center Virtual Machine Manager (SCVMM)集成的组件。没有域管理凭据的攻击者可以利用此问题实现远程代码执行。 |
| CVE-2022-26503 || 影响Veeam Agent for Microsoft Windows，攻击者可以利用它来提升权限并以系统权限执行任意代码。 |

来源：

https://securityaffairs.co/wordpress/129094/hacking/veeam-rce.html

## **Valorant游戏社区分发RedLine恶意软件**

RedLine恶意软件是部署最广泛的密码窃取恶意软件之一。近日，韩国研究员发现利用YouTube上的Valorant游戏社区分发恶意软件RedLine攻击活动，攻击者轻易绕过了YouTube的新内容提交审查。Valorant游戏社区，这是一款适用于Windows的免费第一人称射击游戏，在视频中提供了一个下载自动瞄准机器人的链接，该链接实际是投递RedLine窃取程序的副本。

来源：

https://www.bleepingcomputer.com/news/security/fake-valorant-cheats-on-youtube-infect-you-with-redline-stealer/

  

**新恶意软件CaddyWiper攻击乌克兰网络**

近日，研究人员在针对乌克兰的攻击中观察到新的恶意软件CaddyWiper，这种恶意软件会从连接的驱动器中删除用户数据，目前已在乌克兰少数公司的几十个计算机系统上观察到了该恶意软件。CaddyWiper是自2022年初以来在乌克兰攻击中部署的第四个恶意软件。此前，研究人员还披露了恶意软件HermeticWiper、IsaacWiper以及WhisperGate，CaddyWiper与已知的其他三种恶意软件没有任何明显的代码相似性。

来源：

https://www.bleepingcomputer.com/news/security/new-caddywiper-data-wiping-malware-hits-ukrainian-networks/

## **新的RURansom Wiper瞄准俄罗斯**

最初发现了一种针对俄罗斯的新的勒索软件RURansom。该勒索软件是一个基于.NET的二进制文件，并伪装成Россия-Украина\_Война -Обновление.doc.exe，（中文名：俄罗斯-乌克兰战争更新.doc.exe）。RURansom会加密受感染机器中的所有文件，并删除扩展名为.bak的文件。下图是RURansom赎金票据。
