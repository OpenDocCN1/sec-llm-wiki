1.概述


Lazarus组织一个具有朝鲜政府背景的组织，至少从2007年就开始活跃。该组织涉嫌网络犯罪、间谍活动和具有实质性破坏的攻击，此外还对全球的金融机构进行攻击，堪称全球金融机构的最大威胁。Lazarus组织的攻击行业包括航空航天、国防、工程、金融、政府、媒体、技术、比特币交易所，攻击目标包括澳大利亚、孟加拉国、巴西、加拿大、智利、中国、厄瓜多尔、法国、德国、危地马拉、中国香港、印度、以色列、日本、墨西哥、菲律宾、波兰、俄罗斯、韩国、中国台湾、泰国、英国、美国、越南等国家。

本次攻击事件发生在2021年末2022年初。Lazarus组织使用了他们的“job opportunities”模板对目标发起了附件钓鱼攻击，附件中包含伪装成了伪装成美国全球安全和航空航天巨头洛克希德马丁公司的诱饵文件。攻击者使用了Microsoft Windows Update 客户端执行恶意DLL来绕过安全监测机制，将GitHub作为命令和控制服务器。

3.攻击过程


攻击者向目标发送了一封伪装成航空航天巨头洛克希德马丁公司招聘信息的钓鱼邮件。邮件附件中包含恶意文档Lockheed_Martin_JobOpportunities.docx。

图 3.1 嵌入了恶意宏代码的诱饵文档

攻击者在该文档中嵌入了恶意宏代码，恶意宏代码执行一系列注入，在C:\WINDOWS\System32目录下释放恶意文件wuaueng.dll，在启动文件夹中释放WindowsUpdateConf.lnk，实现持久化。执行过程如下图所示。

图 3.2 恶意代码执行过程

WindowsUpdateConf.lnk会执行命令“C:\Windows\system32\wuauclt.exe” /UpdateDeploymentProvider C:\Wíndows\system32\wuaueng.dll /RunHandlerComServer。该命令利用Microsoft Windows Update 客户端执行恶意DLL来绕过安全监测机制。

图3.3 

wuaueng.dll中嵌入了core_module.dll，通过DLL侧加载执行wuaueng.dll后，会将core_module.dll注入到explorer.exe中。core_module.dll的功能是使用硬编码的username、repo_name、directory和token从github仓库下载恶意PNG文件。

图 3.4 从github仓库下载恶意PNG文件

从github仓库下载到的文件readme.png中嵌入了一个恶意DLL，GetBaseInfo.dll。该DLL的功能是它检索用户名、计算机名和系统上所有正在运行的进程的列表，将其提交给C2。

图 3.5 获取系统信息

攻击者在2022年1月17日创建了github账号DanielManwarningRep，利用该账户操作恶意软件。

图 3.6 账户详细信息


4.归因

4.1 攻击目标重合

“job opportunities”是Lazarus组织常用的诱饵模板，这些模板中包含知名公司如洛克希德·马丁（美国航空航天制造商）、BAE系统公司（世界上最大的国防承包商之一）、波音、诺思罗普·格鲁曼公司（军工生产厂商）的图标。

在本次攻击活动中攻击者的目标是想去洛克希德·马丁公司工作的人。国防工业，特别是洛克希德·马丁公司是Lazarus组织的已知攻击目标。

4.2 诱饵文档元数据关联到Lazarus组织使用的恶意文档

通过诱饵文档的元数据可以在VT上关联到Lazarus过去攻击活动中使用的其他恶意文档。

图 4.1 通过诱饵文档元数据关联到的其他恶意文档

 

图 4.2 关联到的恶意文档也被其他安全公司的Yara规则命中

4.3 通过宏代码关联到Lazarus

使用Frame1布局执行宏和使用较少为人所知的API调用执行shellcode是Lazarus组织曾经使用过的手法，参见报告《RIFT: Analysing a Lazarus Shellcode Execution Method》

本次攻击活动中，攻击者嵌入在文档中的宏代码通过KernelCallbackTable劫持控制流并执行恶意代码。宏代码从“wmvcore.dll”中获取“WMIsAvailableOffline”函数的地址，然后更改“WMIsAvailableOffline”中代码的内存保护权限，并继续用恶意base64解码的shell代码覆盖内存中的代码。

本次攻击活动中使用的域名markettrendingcenter.com曾经解析过IP 44.227.65.245，这个IP可以关联到Lazarus曾经使用过的lnk文件。
