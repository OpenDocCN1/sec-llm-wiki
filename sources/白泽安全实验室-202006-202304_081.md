**Equation Group的DanderSpritz框架分析**

DanderSpritz 是Equation Group使用的一个模块化、隐蔽且功能齐全的框架，依赖于数十个插件在 Windows 和 Linux 主机上进行入侵后的攻击利用活动。该框架包含了绕过防病毒和安全工具、禁用和删除 Windows 事件日志、建立持久性、执行本地和网络侦察、在网络内横向移动以及泄露数据的各种插件。DoubleFeature是DanderSpritz最重要的插件，其具有类似日志模块的独特功能，根据内部文档，DoubleFeature“生成关于可以部署在目标上的工具类型的日志和报告” 。

来源：

https://danderspritz.com/

https://research.checkpoint.com/2021/a-deep-dive-into-doublefeature-equation-groups-post-exploitation-dashboard/

  

## **Lazarus Group利用招聘信息开展攻击活动**

Lazarus Group利用招聘相关钓鱼文档来诱骗用户。钓鱼文档会启用恶意宏解密数据,并请求保留地址模板；解密后的有效载荷以隐藏文件的形式保存在系统目录%ProgramData%下；随后文档调用rundll32.exe执行有效载荷,与C2服务器建立通讯连接开展恶意活动。此次攻击使用的后门为NukeSped。NukeSped是Lazarus Group使用的具有代表性的后门恶意软件,可以通过从 C&C服务器接收攻击者的命令来执行各种恶意操作。

来源：

https://mp.weixin.qq.com/s/834tMVCCH6UQe8zW0eEMSA

## **COVID-19网络钓鱼诱骗窃取加密货币**

最近，安全研究人员观察到利用COVID-19话题的垃圾邮件活动。这些电子邮件是使用邮件程序脚本从受感染的邮箱自动发送的。邮件中包含一个指向 Word 文档的链接，图1是垃圾邮件截图。该电子邮件利用COVID-19检测为理由，诱骗用户单击链接并下载文档。下载的恶意文档利用远程模板注入启用恶意宏，释放并执行一个称为 ClipBanker 的信息窃取程序，开展窃取加密货币活动。图二是攻击流程图。

## **Apache HTTP服务器中关键漏洞已修补**

Apache修补漏洞CVE-2021-44790和CVE-2021-44224，漏洞可能导致攻击者远程执行任意代码。CVE-2021-44790是一个缓冲区溢出漏洞，可能会导致Apache HTTP Server 2.4.51版本mod\_lua多部分解析器中的缓冲区溢出。目前尚未发现利用此漏洞的攻击。CVE-2021-44224是一种可能造成NULL取消引用或服务器端请求伪造的漏洞，影响Apache HTTP Server2.4.7到2.4.51版本。

来源：

https://blog.alyac.co.kr/4381

  

## **DaVinci Resolve 软件平台存在两个安全漏洞**

DaVinci Resolve是一个免费软件平台，它是将视频编辑、色彩校正、视觉效果、动态图形和音频制作工具结合在一起的软件平台。Cisco安全研究人员检测发现该平台存在两个远程代码执行漏洞，分别为CVE-2021-40417和CVE-2021-40418。攻击者可以在低复杂性的攻击中远程利用这两个漏洞。

来源：

https://www.bleepingcomputer.com/news/security/blackmagic-fixes-critical-davinci-resolve-code-execution-flaws/

DW Morgan是一家总部位于加利福尼亚州，业务遍及全球的物流巨头。近期，该公司因数据库配置错误，泄露超过100 GB的数据和250万个文件，包括DW Morgan全球员工和客户的财务、运输等数据。其中客户包括全球500强公司爱立信和Cisco。屏幕截图显示了Cisco给DW Morgan的350,000美元发票。

## **Monongalia ****Health****遭到攻击并泄露患者数据**

近期，由于Monongalia Health的系统遭到网络钓鱼攻击，可能导致398,164名患者的健康数据被泄露。该事件影响了Mon Health和两家附属的西弗吉尼亚医院。钓鱼攻击导致从2021年5月至2021年8月，攻击者未经授权访问了多个员工电子邮件帐户中的电子邮件和附件。目前已经确定与患者相关的健康数据被泄露，泄露数据包括姓名、Medicare 健康保险索赔号码、社会安全号码、联系信息、患者帐号、保险计划成员ID号码、医疗记录号码、日期服务和其他医疗数据。

https://www.scmagazine.com/analysis/cybercrime/mon-health-phishing-attack-account-takeover-impacts-data-of-398k-patients
