APT组织


DarkHotel APT针对我国的新攻击链

DarkHotel 是一个疑似源于韩国的APT组织，自2007年以来一直活跃。在以往针对高级商业目标的攻击中，攻击者主要通过渗透酒店WiFi网络、鱼叉攻击和P2P攻击来部署恶意代码。近日，ThreatLabz研究人员披露了DarkHotel组织的新攻击链，下图是攻击流程示意图。某些恶意模块在执行过程中，会检查进程列表中是否存在我国常用的杀毒软件或个人防火墙，如“360Tray.exe ”或“QQPCTray.exe”。研究人员在C2服务器的IP上关联到多个伪装域名，这些伪装域名与中国政府、教育和政治智库实体相关，一些新注册的域名甚至伪装成了在中国流行的加密货币项目，例如Deeper网络。综合以上线索可以判定，该组织此次攻击活动主要针对我国境内目标。

攻击活动


攻击者冒充生物技术巨头辉瑞开展网络钓鱼活动

辉瑞是一家著名的制药公司，总部位于美国纽约，该公司称其实验性抗新冠药物Paxlovid可以使高危新冠患者的住院率和死亡风险减少89%。研究人员发现，自2021年8月15日开始，攻击者冒充辉瑞公司展开了网络钓鱼电子邮件活动。如下所示，列出了四个看似由辉瑞公司运营的域名，其中一个是pfizer-nl[.]com，该域名可能会诱使用户认为这是辉瑞荷兰公司的官方在线门户网站。这些域名由不同的域注册商创建，域名WHOIS中的注册人信息表明，至少有一名攻击者位于尼日利亚。

· pfizer-nl[.]com

· pfizer-bv[.]org

· pfizerhtlinc[.]xyz

· pfizertenders[.]xyz

针对全球 90 多个国家/地区的诈骗活动

Group-IB研究人员发现了一起针对全球90多个国家/地区的用户的全球性诈骗活动。攻击者通过虚假调查信息和虚假的品牌声明，来窃取受害者的个人信息和支付数据，根据Group-IB的提供的数据，仅单个骗局网络的潜在受害者估计约为1000万人，而潜在损失总计约为每月8000万美元。网络犯罪分子利用至少121个品牌作为诱饵。对托管诈骗网站的服务器基础设施的分析表明，诈骗的目标区域是：欧洲（36.3%）、非洲（24.2%）和亚洲（23.1%）；大多数受影响的品牌属于美国（20 个）、加拿大（9 个）、韩国（7 个）、意大利（5 个）、塞尔维亚（5 个）和新加坡（5 个）；网络犯罪分子主要利用领先电信公司的品牌，占被利用品牌总数的50%以上，其次是电子商务和零售。

恶意软件


隐藏在Windows注册表中的新型恶意软件

近期，出现一种名为“DarkWatchman”的新型RAT恶意软件，它是一种轻量级且功能强大的 JavaScript RAT。DarkWatchman 最初出现于2021年11月初，攻击者通过发送带有恶意ZIP附件的网络钓鱼电子邮件分发该恶意软件。ZIP文件附件包含一个可执行文件，可执行文件是一个自安装的 WinRAR 压缩文件，将安装 RAT 和键盘记录器。DarkWatchman 的不同之处在于它为键盘记录器使用了Windows注册表无文件存储机制。研究人员发现这种新型RAT主要被俄罗斯攻击者所采用，下图是分发DarkWatchman使用的网络钓鱼电子邮件示例。

Dridex 恶意软件使用虚假电子邮件来欺骗目标

一起分发Dridex恶意软件的网络钓鱼活动正在进行中，攻击者使用虚假的解雇电子邮件作为诱饵，诱导目标打开恶意 Excel文档，并显示一个模糊的“人员操作表”，提示用户只有“启用内容”方可正确查看。一旦受害者启用内容，将弹出一个节日问候窗口,并在受害者不知情的情况下执行恶意宏。Dridex是一种通过恶意电子邮件传播的银行恶意软件，最初用于窃取在线银行凭据。随着时间的推移，恶意软件开发人员不断丰富其他模块来提供额外的恶意功能，例如安装其他恶意载荷、为攻击者提供远程访问功能以及感染网站中的其他设备。如需详细了解Dridex恶意软件请阅读本公众号往期推送。

勒索软件


Conti 勒索软件利用Log4Shell漏洞

在Log4j2漏洞公开一周后，AdvIntel的研究人员发现了勒索软件组织之一的Conti对新漏洞的利用。因此，Conti成为了第一个将Log4j2武器化的复杂的勒索软件组织。Conti长期寻求新的攻击面和方法，自8月以来，陆续采用了许多新方法：隐藏的RMM后门、新的备份删除解决方案，以及最近重振恶意软件Emotet。此外，Conti已经有利用漏洞作为初始接入和横向移动手段的历史，例如该组织利用Fortinet VPN 漏洞CVE-2018-13379 将未打补丁的设备作为初始攻击目标；利用CVE-2021-34527/CVE-2021-1675、Zerologon (CVE-2020-1472)和ms17-010漏洞在受感染主机上权限提升，并完成横向移动。Conti成为第一个将Log4j2武器化的复杂的勒索软件组织。下图是勒索软件利用的时间表。如需详细了解Conti 恶意软件请阅读本公众号往期推送。

漏洞情报


APT组织利用ManageEngine Desktop Central 零日漏洞CVE-2021-44515

联邦调查局(FBI)表示，ManageEngine Desktop Central中存在一个零日漏洞CVE-2021-44515，自10月以来一直被APT组织积极利用。根据FBI披露：APT组织破坏了Desktop Central服务器，释放一个覆盖Desktop Central合法功能的 web shell，下载了入侵后利用工具，枚举域用户，完成了网络侦察、横向移动和凭据导出等战术动作。据Shodan 统计，有超过2,900个ManageEngine Desktop Central 暴露在网络中，如下图所示。

数据泄露


加纳政府机构泄露70万公民的数据

非洲西部国家加纳的政府机构NSS（全国服务秘书处 ）使用的亚马逊服务存在数据库错误配置，泄露了来自全国各地多达700,000名公民的数据，总计55GB数据。泄露的数据库包含相关人员的会员卡和身份证明文件，包括加纳国家健康保险计划、根据候选人安置行业划分的专业ID等信息。
