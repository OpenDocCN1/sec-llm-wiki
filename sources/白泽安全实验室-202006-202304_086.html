APT37组织使用Chinotto新型间谍软件攻击目标
近期，APT37针对Windows系统和Android系统发起钓鱼攻击。攻击者利用 Windows可执行文件版本和 PowerShell实现版本来控制Windows系统。如果受害者的主机和手机同时受到感染，则Chinotto恶意软件能够通过从手机窃取SMS消息来完成双因素身份验证。攻击者还会使用被盗的社交媒体帐户或电子邮件帐户联系其他受害者，进一步进行攻击。下图是其攻击的流程图。

WIRTE组织针对中东地区的攻击活动

WIRTE组织已针对外交和金融机构、政府、律师事务所、军事组织和技术公司等领域开展攻击活动。受影响的实体主要位于亚美尼亚、塞浦路斯、埃及、约旦、黎巴嫩、巴勒斯坦、叙利亚和土耳其等国家。攻击者使用了简单且相当常见的TTP，这使得攻击活动长期不被注意。近期，卡巴斯基研究人员披露了WIRTE组织针对中东地区的攻击活动，攻击者发送携带恶意的 Microsoft Excel/Word 文档的鱼叉式网络钓鱼电子邮件，诱导用户点击恶意文档执行VBS和PowerShell脚本，部署其他的恶意工具展开攻击活动。

PROMETHIUM伪造NotePad++安装包开展攻击

近日，奇安信捕获该组织伪装NotePad++安装包的攻击样本。PROMETHIUM通过水坑攻击进行初始接入，安装包中内嵌Notepad++签名的最新软件安装包，并使用Notepad++安装包图标伪装自身；通过对此次捕获样本的攻击手法，代码逻辑分析，发现捕获的攻击样本与PROMETHIUM组织常用攻击手法，恶意代码基本一致。PROMETHIUM又被称为蓝色魔眼、StrongPity。该APT组织在2016年被微软披露并命名为PROMETHIUM，其最早的攻击活动可以追溯到2012年。该组织主要针对意大利、土耳其、比利时、叙利亚、欧洲等地区和国家进行攻击活动。

APT-C-60针对贸易行业的攻击活动

该组织针对我国的攻击活动最早可以追溯到2018年，攻击活动一直持续至今，攻击目标主要以人力资源咨询和贸易相关单位为主。今年的攻击活动，是以鱼叉邮件投递恶意压缩包为主。其主要目的为获取情报，攻击手段较为单一。近期，奇安信发现APT-C-60针对贸易行业的攻击活动：发送“接种后不良反应说明.lnk”文档，其图标伪装为IE浏览器图标，诱导用户点击执行；通过mshta远程执行js脚本，但目前无法获取执行的有效载荷。

攻击活动


恶意Android应用程序窃取马来西亚银行凭据

攻击者将恶意的Android 应用程序伪装成家政服务的应用程序，从八家马来西亚银行的客户窃取网上银行凭证。该应用程序通过多个虚假网站和社交媒体帐户进行推广。安装该应用程序时，要求用户允许不少于 24 项权限，包括有风险的“RECEIVE_SMS”，它允许应用程序监控和阅读手机上收到的所有短信。此权限被滥用于监控 SMS 文本以窃取电子银行服务中使用的一次性密码和MFA代码。攻击者可以使用在虚假应用程序中输入的银行凭据以及截获的SMS代码访问受害者的电子银行帐户。

来源：https://www.bleepingcomputer.com/news/security/malicious-android-app-steals-malaysian-bank-credentials-mfa-codes/


攻击者使用Yanluowang勒索软件攻击美国实体

自2021年8月以来，攻击者正使用Yanluowang勒索软件，一直在对美国实体企业发起有针对性的攻击。其主要针对的行业包括金融部门、制造、IT 服务、咨询和工程部门。此次攻击活动中的TTP与Thieflock勒索软件存在重叠。攻击者使用AdFind工具和SoftPerfect网络扫描器进行横向移动并识别感兴趣的系统。此外，攻击者还使用了许多开源工具，例如用于复制主密钥的KeeThief、开源凭证转储工具的定制版本secretsdump.exe、屏幕捕获工具、文件泄露工具filegrab.exe、Cobalt Strike Beacon以及ProxifierPE。

警告！Apache HTTP Server中存在CVE-2021-40438漏洞

安全人员警告：Apache HTTP Server 中存在服务器端请求伪造(SSRF)漏洞CVE-2021-40438 漏洞。攻击者正积极利用该漏洞进行攻击活动。该漏洞被用于启用mod_proxy模块的httpd Web服务器。攻击者可以使用定制的请求触发漏洞，将请求转发到任意服务器上。
