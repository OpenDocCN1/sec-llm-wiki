**Lazarus Group使用木马化IDA Pro攻击研究人员**  

朝鲜国家资助的APT组织Lazarus Group再次试图入侵安全研究人员的计算机，这一次攻击者使用了木马化的IDA Pro（一种流行的逆向工程应用程序）的盗版版本作为初始接入媒介。IDA Pro是一种将可执行文件转换为汇编语言的应用程序，允许安全研究人员和程序员分析程序的运行流程并发现其中潜在的错误。安全研究人员通常使用IDA Pro来分析合法软件的漏洞和恶意软件，以确定具体的恶意行为。根据C2域名devguardmap.org和NukeSped远程访问木马的RAT，可以将此攻击活动归因于Lazarus Group。![](../Images/3303f757ebb7bec29a9000f9c8b57bcd.png)来源：https://www.bleepingcomputer.com/news/security/lazarus-hackers-target-researchers-with-trojanized-ida-pro/

  

**伊朗APT组织Lyceum利用恶意软件开展攻击活动**2021年7月至10月间，伊朗国家支持的APT组织“Lyceum”（又名Hexane，Spilrin）,攻击了中东和非洲的ISP和电信服务供应商。攻击活动中，Lyceum使用了两个不同系列的恶意软件，分别称为Shark和Milan。Shark后门是用C#和.NET框架编写的32位可执行文件，用于执行命令并从受感染系统中窃取数据。Milan是一种32位远程访问木马(RAT)，可以从受控系统中检索数据，并将数据泄露到使用自域生成算法(DGA)的C2主机。两种后门都通过DNS和HTTPS协议与C2服务器进行通信，并且Shark还使用了DNS隧道。

![](../Images/489635fcfcb8ed6a5511cc8647cb1c79.png)

**TeamTNT针对配置不当的Docker服务器发动攻击**

TeamTNT针对配置不当且暴露 Docker REST API的服务器，通过创建容器来加载会执行恶意脚本的图片实施攻击。具体可以恶意操作包括：下载或捆绑 Monero 加密货币矿工、使用已知的技术实现容器到主机的逃逸、利用受控的容器中实施网络扫描。完整的攻击流程如下图所示。

![](../Images/a328157555d061fb2177cbc5b6bdd61b.png)

来源：https://www.trendmicro.com/en\_us/research/21/k/compromised-docker-hub-accounts-abused-for-cryptomining-linked-t.html

  

**TA505利用0-day漏洞进行初始接入**TA505是知名的俄罗斯APT组织，以使用Clop勒索软件进行攻击而闻名。最近，发现其频繁利用0-day漏洞CVE-2021-35211发动攻击。攻击者利用该漏洞可以使Serv-U创建一个完全由攻击者控制的子进程，进而执行命令并部署攻击工具。漏洞利用还会导致Serv-U日志功能出错，攻击者通过PowerShell命令利用Serv-U的日志异常，在受害目标上部署了Cobalt Strike Beacon。

![](../Images/15ed0221194d31f1d090d5d196ab8c13.png)

来源：https://research.nccgroup.com/2021/11/08/ta505-exploits-solarwinds-serv-u-vulnerability-cve-2021-35211-for-initial-access/  
**Magecart组织利用浏览器脚本规避虚拟化/沙箱检测**  
Magecart组织以电子商店为目标，持续使用软件窃取器来窃取支付数据。近日，Malwarebytes研究人员发现该组织的攻击者添加了一个额外的浏览器进程，利用WebGL JavaScript API来窃取支付信息。恶意脚本执行后，窃取其将抓取多字段，包括受害者的姓名、地址、电子邮箱和电话号码以及信用卡数据。此外，窃取软件还收集受害者注册账户的在线商店的密码、浏览器的代理和用户ID。窃取的数据通过POST请求发送到托管窃取器的同一台机器上。  

来源：

https://securityaffairs.co/wordpress/124287/hacking/magecart-e-skimmer-avoids-vms.html

  

**Kimsuky APT组织攻击韩国智库**

Kimsuky，也被称为Thallium 和Black Banshee，是朝鲜国家资助的APT组织，自 2012 年以来一直活跃。本次攻击活动中，攻击者利用托管在 Blogspot 上的恶意博客分发三种类型的恶意载荷：Beacons、文件窃取程序和植入部署脚本。攻击中的植入物是至少自 2017 年以来一直由 Kimsuky 运营的 Gold Dragon/Brave Prince 系列恶意软件的衍生物。此次攻击活动的目标为研究与朝鲜、中国、俄罗斯和美国相关政治、外交和军事主题的韩国智库。

来源：

https://blog.talosintelligence.com/2021/11/kimsuky-abuses-blogs-delivers-malware.html

## **朝鲜黑客组织利用CVE-2021-40444漏洞发动攻击**

朝鲜黑客组织冒充平壤科技大学校长再次发起攻击活动。此次攻击利用了漏洞CVE-2021-40444。若被攻击目标在未安装MS Office最新安全更新的情况下打开恶意DOCX文档，就会触发漏洞。漏洞利用成功后，攻击者会执行恶意脚本，收集和窃取受害者主机内的敏感信息。

来源：https://blog.alyac.co.kr/4262?category=957259

**股票交易平台Robinhood披露数据泄露事件**

股票交易平台 Robinhood 于11 月 3 日遭到了黑客入侵。根据Robinhood事后披露的信息，攻击者获得了大约700万客户的个人信息的访问权限。泄露的数据包括：500万客户的电子邮件地址，200万客户的全名、300人的姓名、出生日期和邮政编码等。此外，在攻击发生后，RobinHood还收到了勒索要求。
