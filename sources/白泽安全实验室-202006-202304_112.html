概述


2021年1月微软和谷歌分别发布报告，披露了朝鲜的APT组织Lazarus针对安全研究人员的攻击活动。该报告称为了与安全人员建立联系和信任关系，攻击者建立了多个博客和Twitter账号，并发布漏洞利用相关技术信息。一旦与安全研究人员建立信任联系，攻击者会发送包含隐藏恶意代码的文档。恶意代码运行后会获取目标主机的敏感信息并发送到指定的C2。除了上述这种新颖的社会工程学初始接入方式外，攻击者还使用了水坑攻击，在控制的博客中嵌入恶意代码，安全研究人员访问后即受到攻击。


2021年2月，韩国安全公司ENKI发布报告披露了朝鲜黑客针对该公司安全研究人员的攻击活动，白泽安全实验室的研究人员认为此次攻击活动与微软和谷歌的披露的攻击活动高度同源，并对ENKI捕获的样本进行了详细分析。



攻击分析


攻击者将名为“Chrome_85_RCE_Full_Exploit_Code.mht”的初始接入文档作为Chrome漏洞的POC发送给安全研究人员。该文档要求使用者运行 JS脚本或ActiveX控件，才能完全读取文本内容。这种设计的目的是引导目标使用 Internet Explorer浏览器文档。

图 2-1 初始接入样本


如果允许脚本执行，样本会从远程C2(codevexillium.org)下载有效载荷。分析结果显示，样本代码经过了高强度的压缩混淆，主要恶意代码是将“https://codevexillium.org/board/view.asp?id=1”网页通过document.write函数嵌入到mht文件中，进而下载下一阶段载荷。

第三阶段的原始载荷采用base64编码，由第二阶段载荷负责解码和解密。第三阶段载荷利用了Internet Explorer 的0day漏洞(CVE-2021-26411)执行第四阶段载荷。其中，第四阶段载荷经过混淆处理后硬编码在第三阶段代码中。

CVE-2021-2641是一个典型的Double Free漏洞，发生在DOM对象的属性值释放时，将两个不同类型的指针指向了相同的内存空间，类型混淆情况导致了指针泄露和指针解引用。攻击者通过构造RPC_MESSAGE绕过了windows操作系统控制流保护(CFG)，调用rpcrt4达成任意代码执行，将shellcode注入到msi.dll并执行。

第四阶段载荷功能为获取目标进程列表、屏幕截图和网络接口信息并发送给C2，然后从C2下载下一阶段有效载荷。为了绕过安全检测，第四阶段载荷直接调用系统函数，而不使用DLL中的函数。



写在最后



Lazarus 组织是一个非常活跃且具有朝鲜政府背景的APT组织，至少从2007年就开始活跃。涉嫌网络犯罪、间谍活动和具有实质性破坏的攻击，此外还对全球的金融机构进行攻击，堪称全球金融机构的最大威胁。Lazarus组织具有多种平台的开发能力，不仅会复用已有的后门木马，也使用Objective-C开发适用于MacOS平台的后门木马。Lazarus组织曾经使用的后门木马的具有加密流量特征，包括JA3 指纹和Sectigo RSA Domain Validation Secure Server CA证书指纹等。


从此次事件分析，Lazarus 组织具备很成熟的战前规划能力、作战能力以及0day利用能力。白泽安全实验室的网络敌情综合跟踪系统（白泽图）对包含Lazarus 在内的300余个APT组织的IOC和TTP进行持续跟踪，并对外输出可操作的综合性威胁情报；在线交互式IOC关联溯源系统（白泽剑）能够辅助分析人员完成针对包括IP、域名、URL、样本、邮箱、加密指纹、服务指纹在内的多种IOC技术线索的“一站式”拓线和溯源工作。
