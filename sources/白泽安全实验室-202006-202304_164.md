# 2020年度半岛方向APT攻击活动盘点（朝鲜部分）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MTE4ODY3Nw==&mid=2247485513&idx=1&sn=444ac54d5a318ade4f2d8093ca71cce5&chksm=e90e2263de79ab75b7a8c905831019e9f89a063b872ae7f9f12f60dbb5f72aba1b68bea1d9d2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MTE4ODY3Nw==&mid=2247485513&idx=1&sn=444ac54d5a318ade4f2d8093ca71cce5&chksm=e90e2263de79ab75b7a8c905831019e9f89a063b872ae7f9f12f60dbb5f72aba1b68bea1d9d2&scene=27#wechat_redirect)

白泽安全实验室重点总结梳理了2020年南亚、朝鲜半岛和俄罗斯方向的APT组织的攻击活动情况。本次发布的是半岛方向朝鲜APT组织的总结报告。

  

![](../Images/5921bb474ce0bc76544539110de64225.png)  

APT37

![](../Images/ddbf29044888bc8742423447b4d62321.png)

  

APT37组织的主要使命是收集情报以支持朝鲜的军事、政治和经济活动。该组织惯用鱼叉式钓鱼网络攻击，且诱饵文档对目标具有很强的针对性：针对韩国目标使用HWP文档，世界目标使用office文档。大多数基于 HWP 文档的攻击以电子邮件作为传播媒介，但偶尔也会使用在 Web 公告板上注册的方式或SNS作为传播媒介。

APT37在2020年的攻击活动中使用的基于 Web 的攻击策略不是编写 Web 浏览器漏洞利用代码或将恶意脚本插入到站点中，而是直接利用恶意hwp文档文件在网站公告板上注册。这种攻击方式可能是攻击者直接渗透到目标服务器利用恶意文档替换了先前注册的普通hwp文档，也可能是入侵了帖子撰写人的计算机，从而替换了恶意文档。至于具体使用了哪种攻击路径，目前尚不明确。

在2020年的攻击活动中，APT37新增了Windows Command Shell、Powershell执行方式，对恶意文件固定字节秘钥键值使用XOR进行混淆，并且通过定制的命令和控制协议与C2通信。从历史情况看，APT37攻击活动不仅仅注重于收集信息、窃取信息，也会造成一些物理影响，如磁盘结构擦除、系统关机、重启等，但在2020年的攻击活动中并发现这些影响。

Kimsuky

![](../Images/ddbf29044888bc8742423447b4d62321.png)

  

Kimsuky是一个持续活跃的APT组织，并且擅长利用携带恶意 vbs 脚本的 hwp 文档实施攻击。Kimsuky对热点事件特别是政府相关事件高度关注，在2020年美国大选期间，以“美国大选预测”为名义实施了多轮攻击活动，并延续了2019年“Smoke  Screen”的攻击活动的手法。  

Kimsuky与其他组织不同的是，擅长创建互斥体来确保木马运行的唯一性。Kimsuky在2020年利用了Lazarus惯用的攻击手法，诱饵文档中的 VBS 脚本执行后会从失陷的服务器拉取下阶段的 VBS 脚本执行，并以失陷的服务器作为跳板进行攻击活动。该攻击手法是朝鲜 APT 组织 Kimsuky 和 Lazarus 惯用的手法之一，且这两个组织在多种技术上有不同程度的重叠。在本年度疫情大肆席卷时，Kimsuky也并未放弃这个机会，向从事COVID-19疫苗的制药、研究公司发起攻击，试图获取相关情报或利益。在历年的攻击活动中，Kimsuky组织并没有涉及横向移动这一战术环节，而在2020年的攻击活动中，Kimsuky组织使用远程哈希注入来连接TeamViewer客户端、启用RDP在受害者网络中横向移动。由此可见Kimsuky在保持自己各方面技术迭代的同时，着重于提升了内网渗透能力。

Lazarus

![](../Images/ddbf29044888bc8742423447b4d62321.png)

  

Lazarus因2014年攻击索尼影业开始受到广泛关注，其攻击活动最早可追溯到2007年，该组织早期主要针对其他国家政府机构，以窃取敏感情报为目的。但自2014年后，该组织开始针对全球金融机构，虚拟货币交易平台等，实施以敛财为目的的攻击活动，并由此衍生出了明确谋求经济利益的子组织Stardust Chollima。  

Lazarus是2020年度活跃度最高的APT组织之一，先后针对韩国证券公司、欧洲航空航天和军事公司、国防、政府公司的员工、COVID-19相关机构发起了多轮攻击活动。Lazarus组织在2020年度利用社交媒体发起了一系列攻击活动，通常先在社交软件Linkedin和WhatsAPP建立一个可控的虚拟实体，首先降低受害者的防备心，然后发起钓鱼攻击。为了获取疫情相关情报，2020年Lazarus向新冠病毒相关的研究/制药机构发起多次大大小小的攻击：在9月25日，利用 Bookcode 恶意软件攻陷了某国一家制药公司；在10月27日，利用wAgent（wAgent主要组件仅在内存中工作，并且从远程服务器获取其他有效载荷。）向某国政府卫生部的发动了攻击。接二连三地针对疫情相关机构发起的攻击活动，显示了Lazarus对疫情相关的情报的重视程度。此外，为牟取经济利益的勒索活动也仍然持续，2020年3月至5月，Lazarus使用了一种C++编写的新型勒索软件VHD，采用RSA-2048和AES256-ECB加密算法，将Mersenne Twister作为随机数来源。VHD的另一个特征是会创建互斥量“ AEEAEE SET”，以防止在同一目标重复感染。

在初始接入方面，攻击者滥用WIZVERA VeraPort安装安全软件的机制和运行TinkaOTP时安装并运行Disk iMaGe（DMG）应用程序捆绑包接入目标机器；使用非法获得的代码签名证书来签署供应链攻击中使用的初始下载器、采用模板注入技术执行后续有效载荷来实现防御规避；信息渗漏的方式也在不断地迭代，在2020年，Lazarus组织将收集到数据上传到云账户Dropbox，并且利用日程化传输，减少了资源的消耗和情报在传输过程中的丢失。

KONNI

![](../Images/ddbf29044888bc8742423447b4d62321.png)

  

KONNI组织擅长使用鱼叉式钓鱼攻击，投送HWP和Office Word文档附件，借助涉及朝鲜或热门话题的诱饵，诱导受害者执行，并利用宏等手段释放和执行恶意程序，控制目标计算机，窃取敏感信息。根据相关恶意程序的地域分布情况判断，KONNI木马主要在俄罗斯和韩国，而KaokaoTalk木马主要在韩国，因此KONNI的主要攻击目标就是韩国。  

KONNI组织于2019年被ESTsecurity首次披露针对移动端设备发起的攻击活动,但是2020年的攻击活动中并未发现KONNI组织针对移动端设备的攻击活动。KONNI组织在2020年利用附件钓鱼进行初始接入，利用cmd.exe、已签名的二进制代码Rundll32、PostScript、PowerShell脚本在受害者主机上执行恶意代码。在历年来的攻击活动中，KONNI并没有涉及权限提升与横向移动战术，在2020年的攻击活动中，KONNI复制了高完整性进程的令牌和“ AlwaysNotify”设置绕过了UAC来提升权限，然后从远程服务器获取文件。总体而言，KONNI组织的攻击技术也相对薄弱，且未发现实质性的破坏活动，可见KONNI组织虽然活跃，但发展历程太短，羽翼未丰。

总结

![](../Images/ddbf29044888bc8742423447b4d62321.png)

  

从历史情况看，朝鲜方向的各个APT组织之间具有很强的关联性：（1）KONNI利用了TeamViewer执行world文档，而Kimsuky利用了TeamViewer执行HWP文档，并且二者在攻击活动中使用了相同域名的子域名（KONNI：upgradesrv.890m.com和naiei-aldiel.16mb.com;Kimsuky:my-homework.890m.com和carolie-svr-v1.16mb.com）和相同的IP：202.168.155.156。（2）KONNI在世界杯样本诱饵文档执行完NOKKI恶意软件后，继续执行了属于APT37的DOGCALL恶意软件。（3）Lazarus组织在2017年使用的恶意文档和Kimsuky组织在2020年使用的恶意文档的内部宏代码相似。（4）APT37与Lazarus子组织Bluenoroff都使用过CVE-2016-1019、CVE-2016-4117、CVE-2018-4878等漏洞。由此可见，这些朝鲜的APT组织虽然各司其职为朝鲜政府谋取利益，但它们之间存在着明显的共享工具、基础设置、技术，乃至人员的情况，其关系是密不可分的。
