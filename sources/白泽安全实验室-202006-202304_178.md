# CISA称攻陷SolarWinds的供应链并非攻击者唯一的初始接入方式

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MTE4ODY3Nw==&mid=2247485062&idx=1&sn=7742273b7410fbc943ebf79d9a6b5918&chksm=e90e2cacde79a5baa9fa4918e994b7fc8cf5024e836f14631e463c541c88f4ee15efa530ba51&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MTE4ODY3Nw==&mid=2247485062&idx=1&sn=7742273b7410fbc943ebf79d9a6b5918&chksm=e90e2cacde79a5baa9fa4918e994b7fc8cf5024e836f14631e463c541c88f4ee15efa530ba51&scene=27#wechat_redirect)

![](../Images/1eb3c4cec097f2bd704f04ba2dc05c1a.png)

2020年12月17日，美国网络安全和基础设施安全机构 (CISA)发布公告称，至少从2020年3月开始，一个高级持续威胁(APT)组织入侵了美国政府机构、关键基础设施实体和私营部门组织。

在这些入侵行动中，该组织表现出了耐心、操作安全性以及复杂的间谍技术，在受害者的网络上持续活动了很长时间。

重点是CISA发现了除SolarWinds Orion平台以外的其他初始接入方式，具体细节仍在调查中。

CISA正在调查与本次活动使用相同TTP的攻击活动，包括一些没有使用SolarWinds Orion的受害者或者受害者机器存在SolarWinds Orion，但是没有被利用的迹象。

安全厂商Volexity也发布报告称，他们发现了一个APT组织Dark Halo利用一个之前窃取的密钥来生成cookie，用来绕过Duo Security的多因素认证保护机制以访问Outlook Web App。Volexity把这个组织的攻击活动与SolarWinds Orion供应链入侵事件归因到一起，因为两起事件的TTP是一致的。

所以，除了SolarWinds Orion平台以外，还存在其他的初始接入方式。

CISA还披露了该组织在攻击活动中使用的TTP：

| 战术（Tactics） || 技术（Techniques） |
| --- | --- |
| 资源开发 || 攻陷基础设施 |
| 初始接入 || 攻陷供应链：攻陷软件依赖关系和开发工具；攻陷软件供应链； |
| 执行 || 服务执行 |
| 维持/权限提升 || 创建或修改系统进程: Windows服务 |
| 防御规避 || 文件或信息混淆：隐写 |
| 文件删除 |
| 代码签名 |
| 发现  || 进程发现 |
| 文件和目录发现 |
| 查询注册表 |
| 软件发现 |
| 安全软件发现 |
| 命令和控制  || 工具传输导入 |
| 数据编码：标准编码 |
| 域名生成算法 |
| 应用层协议：Web协议；DNS； |

其中攻陷供应链的子技术攻陷软件依赖关系和开发工具，在对外披露的攻击详情中尚未观察到，不知是否为另一攻击向量的初始接入方式。
