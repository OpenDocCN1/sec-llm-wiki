# FireEye红队泄露武器库详解

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0MTE4ODY3Nw==&mid=2247484982&idx=1&sn=3825a21e9f9dc588f3ff654124436ba4&chksm=e90e2c1cde79a50ae89f9839903d593248f71b6dfba19d3f11054e25a69ca4de1b8f70a10eca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0MTE4ODY3Nw==&mid=2247484982&idx=1&sn=3825a21e9f9dc588f3ff654124436ba4&chksm=e90e2c1cde79a50ae89f9839903d593248f71b6dfba19d3f11054e25a69ca4de1b8f70a10eca&scene=27#wechat_redirect)

  

背景

  

2020年12月8日，美国著名网络安全公司FireEye发布通告称，其遭受了国家级APT组织的入侵，该组织使用了一些未公开的高危手段窃取了其红队在进行渗透测试过程中使用的工具集，包含60种工具。FireEye在博客中发布了数百种对策，以使更广泛的安全社区能够保护自己免受这些工具的攻击。

概述

  

研究人员分析FireEye Red Team武器库中被盗取的60种工具后发现：

*   43％的被盗工具是使用已知攻击技术的公开可用工具。
    
*   40％的工具是由FireEye内部开发的。这些工具还利用了已知攻击者的技术。 
    
*   由于FireEye没有共享有关这些工具的详细信息，因此有17％的被盗工具无法识别。根据它们的名称，这些未知工具中的大多数也都是公开可用工具的略微修改版本。
    

FireEye还宣布被窃取了16个漏洞利用。

![](../Images/7085bd93bf095f9ed25589aece463183.png)

  

被盗的红队工具

  

FireEye尚未分享有关被盗的红队工具用处的详细信息。分析人员分析了这些被盗用的工具，以揭示这些工具的功能和可能产生的影响。

这些工具可以分为四类：

1.  基于开源项目的工具：这些红队工具是开源工具的略微修改版本。
    
2.  基于内置Windows二进制文件的工具：这些工具使用称为LOLBIN（离地二进制文件）的内置Windows二进制文件。
    
3.  Fireeye红队开发的工具：这些工具是专门为FireEye红队的使用而开发的。
    
4.  没有足够数据进行分析的工具：没有足够的数据来分析这些工具。FireEye针对以下工具发布的Yara规则特定于工具的ProjectGuid。 
    

![](../Images/72f6ee0c0d8d832a736acf33ce6f268a.png)

  

工具的详细分析

  

*   基于开源项目的工具：

这些红队工具是开源工具的修改版本。

**1.ADPassHunt**

一种凭据窃取工具，可捕获Active Directory凭据。该工具的YARA规则中包含两个体现工具功能的字符串：Get-GPPPasswords 和Get-GPPAutologons 。Get-GPPPassword 是一个PowerShell脚本，用于检索通过Group Policy Preferences (GPP)推送的帐户的明文密码和其他信息。Get-GPPAutologons 是另一个PowerShell脚本，可从GPP推送的自动登录条目中检索密码。PowerSploit是结合了PowerShell模块和脚本的进攻型安全框架 。

**2.Beacon**

这个红队工具基于  CobaltStrike Beacon。Beacon是攻击者用于实现多个目标而使用的CobaltStrike有效载荷，例如维持、执行、权限提升、凭据转储、横向移动和通过HTTP、HTTPS、DNS、SMB和TCP协议进行的命令和控制（C2）通信 。根据FireEye发布的策略，Beacon工具使用HTTP、HTTPS和DNS Beacon。Beacon工具利用内置的Windows二进制文件（例如msbuild.exe 、Microsoft.Workflow.Compiler.exe和regsvr32.exe）来执行任意有效载荷，并用searchindexer.exe进行进程注入以逃避防御。通过重命名这些二进制文件进行伪装以避免基于名称的检测。

**3.Beltalowda**

Beltalowda是一个基于开源实用程序SeatBelt的红队工具。SeatBelt从与主机调查有关的进攻性和防御性安全的角度，进行各种以安全为导向的“安全检查” 。

**4.Dtrim**

Dtrim是SharpSploit 的修改版本，是一个用C#编写的开源.NET post-exploitation库 。SharpSploit导入PowerShell post-exploitation框架（例如PowerSploit）和其他工具（例如Mimikatz）的模块。

**5.EWS-RT**

EWS-RT基于开源PowerShell工具RT-EWS ，该工具是利用EWS（Exchange Web服务）API的几个cmdlet，在Microsoft Exchange服务器（包括Office365和Windows Server）上执行特定的枚举和利用任务。

**6.Fluffy**

Fluffy是Rubeus的修改版，是用于原始的Kerberos交互和滥用的开源C#工具包。红队使用Rubeus进行Kerberoasting攻击并提取Kerberos票据。

**7.G2JS**

G2JS（GadgetToJScript）是一个用于生成.NET序列化的开源小工具，当使用来自JS、VBS和VBA脚本的BinaryFormatter进行反序列化时，可以触发.NET程序集加载和执行 。G2JS的创建主要是为了在红队参与期间自动执行Microsoft Windows Script Host (WSH)脚本武器化。

**8.ImpacketObf**

ImpacketObf（ImpacketObfuscation ）是混淆的Impacket实用程序集合。使用Python编写的，用于处理网络协议。

**9.ImpacketOBF（SMBExec）**

一个基于Impacket的 smbexec .py工具。

**10.ImpacketOBF（WMIExec）**

一个基于Impacket的 wmiexec .py工具。

**11.InveighZero**

InveighZero是一种开源的欺骗和中间人（MitM）攻击工具，旨在帮助红队和渗透测试人员。它可以欺骗LMNR、NBNS、mDNS、DNS和DHCPv6协议。

**12.KeeFarce**

KeeFarce是一个可从内存中提取KeePass 2.x密码数据库信息的开源工具。它使用DLL注入利用正在运行的KeePass进程执行代码。

**13.NetAssemblyInject**

该工具将C＃.NET程序集注入到任意Windows进程中。它基于开源工具NET-Assembly-Inject-Remote。

**14.NoAmci**

NoAmci是一个使用DInvoke修补AMSI.dll并绕过AMSI （Windows反恶意软件扫描接口）检测的开源工具。

**15.PuppyHound**

PuppyHound是开源工具SharpHound 的修改版本。它是BloodHound项目的C＃数据收集器。

**16.Rubeus**

Rubeus是用于原始Kerberos交互和滥用的开源C＃工具包。红队使用Rubeus进行Kerberoasting攻击并提取Kerberos票据。

**17.SafetyKatz**

SafetyKatz是Mimikatz和.NET PE加载程序的结合 。它创建LSASS的小型转储，并使用PELoader加载自定义版本的Mimikatz以进行凭据转储。

**18.SharpUtils**

用C＃语言编写的红队实用程序的开源集合。

**19.SharpZeroLogon**

基于Zerologon漏洞（CVE-2020-1472 ）的开源漏洞利用 。它利用Netlogon中的加密漏洞绕过身份验证。

**20.TitoSpecial**

基于开源工具AndrewSpecial ，可以窃取凭据，从LSASS内存中转储凭据。

**21.TrimBishop**

基于开源工具“Rural Bishop”。

  

*   基于内置Windows二进制文件的工具

**1.DueDLLigence**

DueDLLigence是FireEye 发布的shellcode运行器框架。红队将其用于应用程序白名单绕过和DLL侧加载。它利用内置的Windows二进制文件Control.exe（Windows控制面板）、Rasautou.exe（远程访问拨号器），以及msiexec.exe文件（Microsoft安装程序可执行文件）绕过应用程序。

**2.MSBuildMe**

这个红队工具是基于MSBuild（Microsoft Build Engine）的用于构建应用程序的平台。它用于编译和执行代码并绕过应用程序白名单（AWL）。

**3.NetshShellCodeRunner**

该工具基于Netsh .exe，用于处理网络接口设置的Windows工具。被红队和攻击者用来执行.dll文件。

**4.Uncategorized**

一组利用内置Windows二进制文件dism.exe、searchprotocolhost.exe和werfault.exe进行进程注入的工具集合。

**5.Weaponize**

该工具使用Windows内置的二进制文件TSTheme .exe（TSTheme服务器模块）。

  

*   为Fireeye红队开发的工具

**1.DShell**

DShell红队工具是用D编程语言编写的后门程序。其有效载荷以Base64格式编码。根据DShell使用的Windows函数，可推测它使用进程注入技术将其有效载荷注入到合法进程中。

**2.Excavator**

这个红队工具可以直接通过其服务转储进程。红队使用它从LSASS内存中转储凭据。

**3.GetDomainPasswordPolicy**

一种侦查工具，可获取Active Directory域的密码策略。

**4.GPOHunt**

一种检索工具，可检索组策略配置。

**5.KeePersist**

为Fireeye红队开发的工具，用于建立持久性。

**6.LNKSmasher**

LNKSmasher是一种可生成恶意.LNK文件的工具。LNK是一种用于指向可执行文件的快捷方式文件的文件格式。这个红队工具可以在LNK文件中嵌入任意有效载荷。

**7.LuaLoader**

LuaLoader是一个可以加载用Lua语言编写的任意代码的红队工具。是专门为Fireeye红队开发的工具。

**8.Matryoshka**

Matryoshka是用Rust编程语言编写的工具。这是一个多阶段工具。下载第一阶段的有效载荷后，它会通过其加载程序运行第二阶段的恶意软件并安装实际的有效载荷。它使用进程镂空技术进行防御规避。

**9.MemComp**

MemComp工具用于内存编译。

**10.MOFComp**

MOFComp（MOF编译器）是一个内置的Windows工具，该工具分析包含MOF（托管对象格式）语句的文件，并将文件中定义的类和类实例添加到WMI （Windows Management Instrumentation）存储库。

**11.PGF**

一个利用多个LOLBIN（例如Netsh、InstallUtil、Regasm、RunDLL32、Control和Cstmp.exe）的后门开发框架。

**12.PXELoot**

一个红队工具，可以发现和利用Windows部署服务（WDS）中的错误配置。

**13.RedFlare**

RedFlare是木马开发框架，包括生成器、控制器、下载器和键盘记录器。它可以为Windows和Linux系统生成木马。

**14.RedFlare（GoRAT）**

GoRAT是使用Golang编程语言编写的RAT（远程访问木马）。

**15.ResumePlease**

一个Microsoft Office宏恶意软件模板，其中包含恶意VBA （Visual Basic for Application）代码。

**16.SharPersist**

用C＃编写的Windows持久化工具包。通过几种方法提供持久性，例如修改注册表运行键，将有效载荷添加到启动文件夹以及在每次启动运行时添加新的计划任务。

**17.SharPivot**

SharPivot是一个.NET控制台应用程序。利用DCOM（分布式组件对象模型）在远程目标上执行命令以进行横向移动。

**18.SharpSchTask**

一个用C＃编写的持久化工具，它利用Windows的计划任务功能。

**19.SharpStomp**

SharpStomp是C＃实用程序，可用于修改文件的创建、最后访问和最后写入时间。换句话说，它是一个时间戳工具。

**20.SinfulOffice**

此工具使用OLE （对象链接和嵌入）功能创建恶意的Microsoft Office文档。

**21.WildChild**

WildChild是一个用于创建恶意的HTA （HTML应用程序）文件的生成器工具。Microsoft HTML应用程序主机（Mshta .exe）运行HTA文件。

**22.WMIRunner**

该工具用于运行WMI命令。

**23.WMISharp**

该工具包含红队使用的WMI命令。

**24.WMISpy**

WMISpy工具使用多个WMI类，例如Win32\_NetworkLoginProfile、MSFT\_NetNeighbor、Win32\_IP4RouteTable、Win32\_DCOMApplication、Win32\_SystemDriver、Win32\_Share和Win32\_Process进行侦察和横向移动。
