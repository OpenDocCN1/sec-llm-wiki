# 揭开雇佣黑客组织DeathStalker的神秘面纱

概述

  

2020年8月24日，卡巴斯基披露一个针对律师事务所和金融业公司的威胁组织。该组织不受经济利益的驱使，不部署勒索软件，不窃取付款信息以转售，或从事通常与网络犯罪黑客相关的任何类型的活动。他们对收集敏感的业务信息的兴趣使研究人员相信DeathStalker是一群雇佣兵，他们提供雇佣黑客服务，或在金融界充当某种信息经纪人的角色。  

DeathStalker首先通过称为Powersing的基于PowerShell的植入程序引起了研究人员的注意。通过分解该线程，可将该组织的活动追溯到2018年，甚至可能追溯到2012年。

受害者

  

DeathStalker主要针对金融部门的私人实体，包括律师事务所、财富咨询公司、金融技术公司等。在一个独特的实例中，还观察到DeathStalker攻击过一个外交实体。

![](../Images/32ed7113178e138fc5e849fe2d7031c0.png)

已经能够确定的与Powersing相关的活动发生在阿根廷、中国、塞浦路斯、以色列、黎巴嫩、瑞士、中国台湾、土耳其、英国和阿拉伯联合酋长国。并且在塞浦路斯、印度、黎巴嫩、俄罗斯、约旦和阿拉伯联合酋长国发现了Evilnum的受害者。

但是，研究人员认为DeathStalkers纯粹是根据他们的感知价值或可能根据客户要求来选择目标。
