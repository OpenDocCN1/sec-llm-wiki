# 看直播，话安全 —— 百度安全与您相约安全顶会Usenix Security 2020

![](../Images/33f9564d79040fa896a8b9947d339dbe.png)第29届USENIX Security会议将于2020年8月12日至14日在美国波士顿举行，USENIX Security是世界网络和系统安全领域四大顶级学术会议之一，对信息安全领域具有重要影响，同时被中国计算机学会（CCF）认定为网络安全A类国际学术会议。  

 

受疫情影响，USENIXSecurity 2020 将采用线上会议的方式进行。在今年的大会上，百度安全将携在隐私保护、程序分析漏洞挖掘以及移动端安卓内核安全等方向的三篇论文，与世界顶级安全研究团队同场献技。同时，百度安全将在会议方提供的Slack workspace中开通专属百度的Slack Channel，扫描图片下方的二维码进入，届时恭候并欢迎业界同仁一起畅聊话安全。
