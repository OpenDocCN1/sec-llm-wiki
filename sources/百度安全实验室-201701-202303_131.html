华人首登Rust会议舞台，百度安全实验室再次书写新纪录！

当地时间5月26日，Rust 社区两大核心会议之一的 RustFest 在巴黎召开。350名来自世界各地的 Rust 爱好者汇聚一堂，分享他们在 Rust 语言和程序设计中的心得体会。

 

本次 RustFest 一共四天。第一天是正会，共有2个邀请演讲，9个同行评审通过的技术报告和一个短报告。第二天是workshop。最后两天是Rust社区的内部会议impldays。本次会议的大金主是 Ethereum 社区的著名创业公司Parity，金牌赞助商包括 Mozilla, 区块链创业公司Bitfury, 智能锁创业公司 1aim, 和语音助手创业公司snips。

图片来自 Twitter@malweene

第一天会议的Keynote是OregonTilde公司的Vaidehi Joshi带来的《Learning howto learn》。英语语言文学出身的Vaidehi毕业后依次从事了编辑、教师和作家职业。在2014年她毅然决定转行。通过刻苦的自学她在12星期的线上课程中掌握了Javascript、Ruby和Rails，之后找到了Web前端开发的工作，并越做越好。现在的Vaidehi已经是Tilde公司的Staff Engineer。她在这个演讲中分享了她在在自学Web过程中应用Feynman Technique进行辅助学习的心得体会。她对自学的深刻理解和她的励志故事，通过她声情并茂的表达，感染了所有在场观众。

 

接下来第一个技术报告也是本次会议最重量级的报告来自于英国剑桥的 Joe 'ctz'，题为《rustls: modern, faster, safer TLS》。rustls 是 Rust 社区最知名的几个项目之一，使用 Rust 语言基本重写了整个 TLS 协议栈，支持了 TLS 1.3 标准。其具有不输OpenSSL 的速度，并同时保证了严格的内存安全，从而在毫不牺牲性能的条件下，从根本杜绝“心脏滴血”漏洞的再次发生。在报告中Joe分析了当前Rust社区对于TLS标准的支持情况，并介绍了rustls的开发历程，以及在rustls中如何借助Rust的高级语法特性辅助进行形式化验证。在报告中Joe还提到了他原本计划实现的兼容openssl的一个项目，后来被百度安全实验室的MesaLink项目彻底替代了，Joe表示Mesalink项目非常酷，是一份“Amazing”的工作，兼容OpenSSL将使得MesaLink具有广阔的应用前景。最后他表示，rustls的形式化验证正在积极推进。完整的形式化验证将有力的证明：rustls是一份“诚实”的TLS 1.3实现。

第二个技术报告来自于英国的Bodil Stokke，题为“Immutable Data Structures and why You want them”。这份报告大概介绍了Rust库im是如何实现高效、内存安全的不可变数据结构，并在一定条件下可以提供可变属性的。

 

第三个技术报告来自于知名加密货币公司Bitfury的Denis Kolodin。他介绍了Yew，一个Rust+Webassembly的前端框架。这个前端框架利用Rust能够使用WebAssembly作为目标平台的特性，生成能够操作VirtualDom树的代码，生成目标wasm并交给浏览器执行，从而完成使用Rust+Webassembly进行前端开发的目标。

 

第四个技术报告来自于Mozilla的资深技术专家HenriSivonen。Henri自1999年起就参与Mozilla Gecko浏览器核心的设计和开发，并亲身开发了Gecko的HTML的parser。他曾担任W3C的顾问，并参与了HTML Working Group的大量工作。Henri有资深的C++、Java和Rust工业背景。他的技术报告介绍了他在开发encoding-rs库中遇到的问题，以及如何将Rust和C++安全的连接在一起。这个报告非常有技术含量，干货满满。

 

第五个技术报告是个短报告，来自于创业公司TreeScale的联合创始人Tigran Bayburtsyan。他介绍了TreeScale公司是如何使用Rust开发高并发的网络服务的。他精巧的使用了mio，构造了一个基于Rust语言的高并发网络基础架构。该架构可以比传统实现提高了20%的吞吐率，内存开销仅为同类型Go程序的十分之一。这个基础架构适用于任何并发式后端平台。

 

第六个报告来自于知名图形渲染库Lyon的作者Nicolas Silva。Nicolas目前是MozillaWebRender团队的核心开发者。他在这个报告中着重讲述了他是如何在Rust中高效的使用GPU进行画面渲染的。他形象生动的展示了几个关键的渲染算法的原理，并现场demo了lyon渲染出的流畅画面，震惊了全场观众，得到热烈掌声。

 

第七个报告来自于Rust社区分布式系统专家TylerNeely。他具有大量的分布式系统开发设计经验。在这个技术报告中他深入的分析了开发者容易犯错误的根本原因，并提供了一套Rust语言的设计范式，以辅助自动化测试样例生成和批量高速测试。通过推广这个设计范式，他帮助Rust社区开发者发现了数百计的逻辑错误，可以说是非常使用并且有效了。

 

第八个报告来自于百度安全实验室的Yu Ding博士。在这个报告中，他向Rust社区介绍了Intel SGX技术，分析Intel SGX作为下一代基于硬件的可信执行环境的工作原理，介绍了Intel SGX在云计算和可信计算领域的最佳应用场景和已有的应用Intel SGX技术实例。之后他介绍了Rust SGX SDK 的总体设计思想，以及其是如何把整套Rust标准库移植到Intel SGX环境中的。借助于Rust SGX SDK，开发者可以轻松的使用Rust语言开发Intel SGX可信计算程序，或者把已有的Rust库移植到Intel SGX运行环境内。最后他介绍了几个基于Rust SGX开发的优秀作品，包括在Rust SGX SDK上进行的大数据分析挑战赛冠军的解决方案、基于Rust SGX SDK的智能合约系统Ekiden，以及一个Rust SGX SDK内完美工作的WebAssembly解释器。Rust SGX SDK和这几个优秀用例得到了与会观众的高度评价，和Parity等公司的高度关注。

第九个技术报告来自于荷兰 XavaMedia Web Services 公司创始人 Dirkjan Ochtman，他同时也是硅谷ActiveVideo公司的Engineering Lead。他具有20年的Web经验，这次他带来的报告题为“A QUIC future in Rust”。QUIC全称是“Quick UDP Internet Connections”，是IETF正在进行标准化的下一代应用层协议。Dirkjan首先介绍并分析了QUIC协议，然后介绍了他使用纯Rust实现QUIC协议支持的项目quinn。目前quinn已经完整的符合了QUIC协议，并且具有非常合理的代码结构和并发模型，以及极高的测试覆盖率。目前quinn已在github上开源，感兴趣的同学可以下载参考。

 

最后一个技术报告来自于技术大咖Jonathan Pallant。他展示了在业余时间实现的一个有趣项目：在一个20美元的Cortex M4开发版上使用Rust语言在没有VGA芯片的情况下输出VGA信号，并展示了一个完整的操作系统运行界面。他的实现甚至可以在RAM大小不到framebuffer的情况下稳定输出VGA信号，并支持从PS/2端口进行IO。这个报告的现场效果非常火爆，Rust语言在他的使用下使一个Cortex M4开发版摇身一变成了一个80年带的台式机。现场气氛在一个接一个的demo中达到最高潮。

最后是结尾的Keynote。来自内罗毕的MattGathu分享了他在内罗毕推广Rust，建设Rust社区的经验和体会。

 

第一天的主会可谓是从头到尾的干货。从开头的重量级人物Joe，到结尾的神奇demo，现场气氛一浪高过一浪。在现在这个技术趋势下，一个没有提及ICO、没有区块链议题，只关注底层技术的会议能达到如此效果实属难得。


Rust社区聚集着大量有为、有理想有志气的中外开发者，百度安全实验室同他们一样，正在用自己的力量构造下一代安全、稳定的技术框架。


百度安全实验室作为第一批进入Rust社区的华人团队之一，在RustFest的舞台上首次展示了雄厚的技术实力，给现场观众留下深刻的印象，书写下华人在世界开源社区的新纪录！
