Rust SGX SDK 是百度安全实验室开发的一个Intel SGX可信计算平台的Rust语言开发工具包。基于Rust SGX SDK，程序员可以快速开发出没有内存安全漏洞的Intel SGX可信程序，即使在操作系统被恶意控制时也能提供迄今为止最强大的安全防护能力，避免敏感数据被窃取。Rust SGX SDK对于数据隐私和云安全都有着非常重要的意义。

 

这次发布的是 Rust SGX SDK 的 v0.9.7 版本，该版本可能是 v1.0.0 之前最后一个测试版。与上次发布的v0.9.1相比，该版本提供了SGX Enclave 内的网络访问、基于rustls/ring/webpki的整套 TLS 协议栈、可信/非可信文件系统操作、可信/非可信时间获取。同时支持使用跨平台工具xargo进行编译，使得库移植的过程更加简洁。


What's New


●      支持 Rust nightlyv1.25.0 (nightly-2018-02-05-x86_64)。

●      支持使用 xargo 编译整个项目(XARGO_SGX=1 make)，包括所有样例代码和第三方库，同时依旧支持使用 cargo 编译 (make)。

●      部分移植了 std::net 到 sgx_tstd::net，使得 Enclave 内可以使用 socket 收发数据。

●      移植了rustls/webpki/ring ，从而支持 Enclave 内的整套TLS 协议栈，并提供了 TLSclient/TLSserver 样例代码。

●      增加了 untrusted 命名空间：std::untrusted，在该命名空间内提供了untrusted fs/path/time 功能接口。这些接口默认开放，无需通过 feature 控制。强烈建议开发人员使用 std::untrusted 命名空间中的接口对不可信文件/时间进行访问。

●      部分移植了std::fs/time/net 到 sgx_tstd::fs/time/net，同时增加了feature定义：untrusted_fs、untrusted_time和 net，用于控制开启/关闭sgx_tstd中 std 命名空间下的 fs/time/net 功能支持。为了安全起见，默认情况下（不加feature定义时）不启用 untrusted fs/time/net 支持。若要启用，必须在 Cargo.toml 内引入sgx_tstd 时加入feature 定义，如

features=["untrusted_fs","untrusted_time","net"]

●      实现了sgx_tstd::sgxfs ，使得 Enclave 内可以使用Intel 提供的加密文件系统操作加密文件。

●      部分移植了 std::env 到 sgx_tstd::env，使得 Enclave 内可以获得 linux 运行环境的环境变量。

●      实现了sgx_tservice::sgxtime ，使得 Enclave 内可以获取基于 Intel ME 提供的可信时间戳。（需要 Intel 可信计算套件环境支持）。详细细节参见 sgxtime 样例代码说明。

●      实现了sgx_tservice::sgxcounter ，提供了基于 Intel ME 的 monotonic counter 支持（需要 Intel 可信计算套件环境支持）。

●      实现了global_dtors_object! 全局析构宏。

●      移植了更多的第三方库：bincode,dtoa, heapsize, itoa, linked-hash-map, log, ring, rust-base64, rust-serialize,rustls, safemem, sct, serde-rs, webpki 等。

●      所有样例代码同时支持cargo、xargo 编译。

○      cargo 编译：make

○      xargo 编译：XARGO_SGX=1 make
