# 共筑IoT安全生态|BSRC发布IoT安全专家招募令

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4ODc0MTIwMw==&mid=2652532747&idx=1&sn=751b425d34a30338ce67aaec75169c80&chksm=8bcb5437bcbcdd21307a8daee156f7f98a2a2088615ee9bc2fce077586ec4346633f35cfbcfb&scene=126&sessionid=1681379126#rd](http://mp.weixin.qq.com/s?__biz=MzA4ODc0MTIwMw==&mid=2652532747&idx=1&sn=751b425d34a30338ce67aaec75169c80&chksm=8bcb5437bcbcdd21307a8daee156f7f98a2a2088615ee9bc2fce077586ec4346633f35cfbcfb&scene=126&sessionid=1681379126#rd)

万物互联、智能物联，AI技术赋能智能设备唤醒万物， 智能设备在给我们带来更舒适生活体验的同时，相关的安全问题也愈发受到关注。百度安全一直致力于打造智能设备安全生态，为解决智能设备带来的安全隐患而努力，我们也希望能借助白帽极客的力量，从攻击的视角上发现更多的风险，进一步提升智能设备的安全性。为此，BSRC将发起针对多款设备的**高赏金 IoT安全挑战项目**，诚邀IoT安全领域研究专家及团队加入，与我们一起探索IoT安全之道，共筑IoT安全生态。  

BSRC IoT安全挑战项目将采用报名制

申请通过后将获得众测邀请码

**提交申请时间：7月10日-7月31日**
