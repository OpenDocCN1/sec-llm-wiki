美国时间8月9日，拉斯维加斯，第26届DEF CON正式开幕。延续往年惯例，本届DEF CON围绕当下集中爆发的安全事件和潜伏的安全隐患设置研讨议题，此外，诸如AI极客村、IoT 极客村的破解攻防演示分享，一个针对选举机的攻防分析甚至吸引了美国国土安全部的官员前来观摩学习，以及，DEF CON的经典曲目安全界“世界杯”：CTF夺旗赛。

 


相比往年，DEF CON上的中国面孔依然在不断增加。其背后，一方面，中国安全企业及社区在学术研究、技术专利研发上逐渐深入，另一方面，中国安全战队近年来在国际赛事中表现不俗，入围队伍不断增加，此外，对DEF CON此类极具极客范儿的会议充满好奇的中国观众日渐增多。

 

不过，此次DEF CON上的中国元素似乎格外引人瞩目，一把来自2500年前的鲁班锁的意外走红，点燃参会者动手破解的热情，更是让来自世界各地的极客们了解到一个事实——中国自古出极客！

 


鲁班，2018 DEF CON最高光的中国人

 

2018 DEF CON现场，一把来至中国的鲁班锁让一帮外国极客抓狂，众多五大三粗的外国壮汉，使出浑身解数试图破解，解出一个并不甘心，还要层层闯关晋级，围得展台水泄不通。当他们得知鲁班锁出自中国2500年前春秋战国时代一位名叫鲁班的木匠之手时，纷纷竖起大拇指对这个中国古代“黑科技”点赞，对这位中国古代极客大牛更是钦佩不已，有人惊呼“原来最早的极客出自中国”。


 

鲁班锁，在没有钉子、绳子的情况下，榫卯相契合，遵循力学原理，看似零碎的部件，却能在叠加中托起千斤之重，甚至被后人称之为中国第五大发明。这是中国古代建筑、家具的主要结构方式，故宫便是应用了这种建筑结构。

策展企业百度安全相关负责人表示，选择鲁班锁，“不仅因其是中国古代“黑科技”的代表，它更是千年华夏智慧的结晶，代表了2500年前中国古代人工匠们对于结构学、力学、美学的研究与思考，是中国工匠精神的体现。事实上，中国的工匠精神与DEF CON所倡导的极客精神有异曲同工之妙。”


中国极客不好惹系列


在DEF CON CHINA期间，最受欢迎的莫过于可以闪闪发亮的T恤，在这次DEF CON，百度安全也费尽心思为现场的朋友带去了DEF CON*百度安全的限定声控T恤，Free的T恤也成为DEF CON众展台的一股清流。

当然，有极客的地方就不会这么平静，极客的破解、钻研精神在DEF CON体现的淋漓尽致，飘扬过海的T恤也难逃被“开膛破肚”之命运，电路板、主控芯片、运算放大器被一一拆解重组，无破解，不极客！


躺着也中枪的T恤


自古出极客 DEF CON东风起

 

中国战队的出征、中国极客的议题分享、百度安全的独立展位，在本届DEFCON上掀起了浓郁的中国风。尤其是中国自古出极客的衬托，也让我们重新审视中国极客自身与极客文化的关系。

 

“极客”作为来源于geek的音译中文，让很多人都认为极客是一种外来文化。不可否认，中国无论是现代极客文化还是环境，确实处于起步阶段，文化氛围也有很大的提升空间，但是正所谓好奇与行动是人类发展的驱动力，以此来判断，中国其实自古出极客，虽不疯狂但绝对源远。

 

鲁班（图片来源百度百科）


无论是中国的工匠精神，还是美国的极客精神，其本质都是追求完美和极致，彰显的是丰富的想象力，善于独辟蹊径勇于挑战的精神。由于DEF CON一直以来强调对技术前沿和边界的探索精神，所以不难理解DEF CON为什么在被中国极客们所熟知后，感受到来自中国的强大的爆发力。短短几年时间，中国极客们对DEF CON的热情与日俱增。

 

今年五月，DEF CON首度出海，从拉斯维加斯来到中国北京，百度安全直接以联合主办方的身份举行了一场中国版的DEF CON，也就是DEF CON CHINA beta。作为极客先生的百度总裁张亚勤甚至为此感慨，这是中国极客最好的时代。

 


可以说，中国极客通过DEF CON找到了价值认同与共鸣，根据最新消息，DEF CON2019年将在中国正式落地，DEF CON联手百度安全在华人安全社区正式上演DEF CON1.0。
