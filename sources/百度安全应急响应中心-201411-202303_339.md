# CNCERT召开“2018中国网络安全年会”发布会 百度安全承办人工智能安全夺旗赛

2018年8月9日，国家互联网应急中心（以下简称CNCERT/CC）于国家会议中心召开“2018中国网络安全年会”新闻发布会，首次对外公布了年会的筹办情况。

CNCERT自2004年以来连续14年举办中国网络安全年会，旨在交流国内外网络安全工作新趋势、新问题、新思路，促进国家公共互联网网络安全应急体系成员间的合作，加强互联网行业的网络安全保障和突发安全事件的应急处置联动，促进政府部门、重要信息系统单位与网络安全产业界间的交流，普及宣传网络安全及网络安全应急工作知识，提升社会网络安全意识。

据悉，2018中国网络安全年会将于8月14日至8月16日在北京国家会议中心召开，以“荟聚安全大脑、护航智能生态”为主题，设置全体大会、8个特色分论坛和技术培训活动，围绕着应急响应、态势感知、网络攻击与溯源、威胁情报、物联网、人工智能、安全漏洞、数据安全等一系列热点领域展开讨论与交流，并邀请相关部委领导、工程院院士、国内外网络安全产业界的知名人士分享观点、交流思想，为各路大咖带来一场顶级网络安全头脑盛宴。

会议期间，还将举办2018中国网络安全技术对抗赛、中国互联网网络安全威胁治理联盟专业工作组竞选会和2018年网络安全创新产品（技术）评选活动。

作为“2018中国网络安全年会”的重要组成部分，2018中国网络安全技术对抗赛得到了国家网信办的指导，旨在深入贯彻落实习近平总书记网络强国战略思想，促进我国网络安全整体防护能力提升，维护国家网络安全。与往年的大赛相比，今年百度、阿里巴巴、腾讯和360这些国内互联网公司也参与了比赛的承办，比赛形式更加丰富，覆盖领域更广泛。赛事将围绕网络安全分析引擎、关键基础设施、移动设备、无线路由、车联网、物联网（IoT）产品、工业互联网等领域展开，包含网络安全引擎比赛、夺旗赛和破解赛三种形式。其中，网络安全引擎比赛由CNCERT承办，大赛将提供真实的网络安全业务数据与业务场景，旨在全方面考察参赛引擎产品的技术能力与业务实战能力。

夺旗赛（CapturetheFlag，CTF）分为AI CTF、安全攻防对抗赛(CTF-AWD,attack withdefense)和PC端安全攻防赛三个项目。其中，AI CTF由百度安全承办，将对国内AI系统的漏洞挖掘和利用的能力进行竞赛比武。比赛将选拔招募8-12支队伍，包含AI战队和人类战队。值得注意的是，AI CTF比赛允许自动化系统参赛和人类战队参赛，但仅有以纯AI战队参加竞赛的优胜者获得独立奖项。

夺旗赛的另外两个项目，分别为由阿里巴巴承办的安全攻防对抗赛和360承办的PC端CTF比赛。此外，本届对抗赛除了网络安全引擎比赛和夺旗赛外，还有由腾讯安全承办的破解赛。届时，参加破解赛的选手将对比赛项目服务和产品进行研究，发现并利用其中的漏洞，现场完成对比赛目标的攻击。

 在网络社会化、社会网络化的今天，网络安全事关国家长治久安，事关经济社会发展和人民群众福祉。中国网络安全年会作为国内网络安全“用、产、学、研”各界技术和业务交流的重要桥梁和纽带，将对推动我国网络安全、提高社会网络安全意识起到积极作用。
