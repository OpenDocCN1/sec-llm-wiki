# 百度安全BSRC年度盛典圆满举办 百位嘉宾共话AI安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4ODc0MTIwMw==&mid=2652530933&idx=1&sn=f781510eb3c7f665c643fb80715d840a&chksm=8bcb4cc9bcbcc5df4d10fe02b6b419a63b431bab119352ae57fbcab20fe77ed4dc8c894bb9bf&scene=126&sessionid=1681379217#rd](http://mp.weixin.qq.com/s?__biz=MzA4ODc0MTIwMw==&mid=2652530933&idx=1&sn=f781510eb3c7f665c643fb80715d840a&chksm=8bcb4cc9bcbcc5df4d10fe02b6b419a63b431bab119352ae57fbcab20fe77ed4dc8c894bb9bf&scene=126&sessionid=1681379217#rd)

  

1月19日至22日，由百度安全主办的国内首个规模盛大的白帽子交流活动—**“放肆AI安全”BSRC（Baidu Security Response Center）年度盛典**在云南隆重举行，国内安全领域的专家、学者、白帽子及媒体人等近百名嘉宾汇聚于此，共话AI安全。

会上，百度安全事业部总经理马杰，百度安全事业部产品总经理韩祖利以及镜相实验室创始人、初创投资媒体合伙人申音都围绕AI时代网络安全话题带来了精彩演讲。在圆桌论坛上，973首席科学家、青年长江特聘教授、复旦大学博士生导师杨珉，小米首席安全官陈洋，爱奇艺高级总监、安全负责人谢丹铭，SOBUG创始人江金涛以及百度安全事业部总经理助理刘叶五位重量级嘉宾就议题“聚焦AI安全”展开激烈的讨论。

 

![](../Images/89f1eba74d6367f2d9e5ee837006a9a8.png)

百度安全事业部总经理马杰

 

“我今天有一个梦想，梦想有一天所有的场景，我们都能以最自然本能的交互方式与机器沟通，被机器理解，梦想有一天，人工智能遍地开放，你我一起，唤醒万物。我今天有一个梦想，梦想有一天幽谷上升，高山下降，人类不再孤独，圣光披露，照满人间。”百度安全事业部总经理马杰在他演讲的开始朗读了这样一段诗，描绘了其对未来AI时代的美好期许。AI时代注定要到来，但人类的本能的反应使其面对未知充满恐惧。在镜相实验室创始人、初创投资媒体合伙人申音看来“我们是活在现在的未来人类，恐惧不是一件坏事，它让我们生存下来，人工智能和人类兼具伙伴、朋友和竞争对手的关系，安全产业是保护人类文明的希望。”

百度安全事业部产品总经理韩祖利

 

![](../Images/f18a2107e43afbcc2e5664c6972d7564.png)

镜相实验室创始人、初创投资媒体合伙人申音

 

百度安全事业部产品总经理韩祖利在演讲中提到，目前AI技术在安全场景中的应用包括营销风控、金融风控、抵御DDoS与CC、识别黑客攻击、病毒特征分析、黄赌毒和涉政网站的识别、黑灰产因子识别等多个领域；而AI自身的安全面临很多风险，百度安全希望与厂商、白帽子联手共建AI安全战线。之后，在极棒大赛中成功破解生物识别的百度安全实验室研究员小灰灰带来题为“生物特征识别真的安全吗”的精彩演讲，提醒相关厂商需要重新认识生物特征识别在身份认证、访问控制中的功能，加强活体检测能力，在敏感操作时，采用多因素认证，同时多使用基于风控的识别方法。

 

![](../Images/2cf45b746fcfb0229285339b8e110341.png)

现场“聚焦AI安全”圆桌讨论

 

圆桌论坛上围绕“聚焦AI安全”的话题，五位嘉宾各抒己见，见解独到。爱奇艺高级总监、安全负责人谢丹铭认为我们要拥抱AI，但不能把AI视为彻底解决问题的完整解药。小米首席安全官陈洋认为，当我们面临风控以及多维数据的领域，使用AI能够从更高的领域来解决问题。在973首席科学家、青年长江特聘教授、复旦大学博士生导师杨珉看来，未来AI在安全方面的份额会越来越大，但目前看来AI是安全的一个创新方法。SOBUG创始人江金涛提到，AI不是一个跨时代的发明，而是某种技术演变到一定阶段以后的产物，这个演变就是生产力的需求以及工具的进步。

随着人类社会的发展，AI已经成为决定人类文明史的重要事件。AI是人类文明最大威胁的言论不绝于耳，AI安全生态建设则显得至关重要，它很大程度上决定着人类的未来。百度安全希望联手更多的设备厂商、专家学者一起唤醒万物，共建AI安全生态。
