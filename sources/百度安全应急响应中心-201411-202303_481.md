# BSRC 九月月度现金奖励计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4ODc0MTIwMw==&mid=209209499&idx=1&sn=9827c0001f226a1f390b4c128c46f7d2&chksm=19a96ca72edee5b1970ff088840862457c1b595d979bf5dc90ffc4c25d75a4eedb33fe61d3ea&scene=126&sessionid=1681379268#rd](http://mp.weixin.qq.com/s?__biz=MzA4ODc0MTIwMw==&mid=209209499&idx=1&sn=9827c0001f226a1f390b4c128c46f7d2&chksm=19a96ca72edee5b1970ff088840862457c1b595d979bf5dc90ffc4c25d75a4eedb33fe61d3ea&scene=126&sessionid=1681379268#rd)

**1.****月度前三奖励计划：**

**评选条件：**

1.成功向BSRC提交漏洞的安全专家；

2.月度积分达到**500**分及以上的安全专家；

3.至少提交过**2**个及以上的高危漏洞的安全专家。

**奖励形式：**

一等奖一名：3000RMB+荣誉证书

二等奖一名：2000RMB+荣誉证书

三等奖一名：1000RMB+荣誉证书

![](../Images/e1f3dc74b7788a897c11c44a264990a0.png)  

**2.****额外现金奖励计划：**

**评选条件：**

1.个人月度积分达到**800**分及以上的安全专家；

2.至少提交**2**个及以上高危漏洞的安全专家；

3.若个人月度积分超过**1000**分，则奖金**翻倍**；

4.此项奖励评选可与本月其他平台活动**同时参与**。

**奖励形式：**

2000RMB现金奖励

 

**3.****高质量漏洞奖励计划：**

**评选条件：**根据漏洞等级、难易程度、影响范围、思路是否新颖等因素进行综合评选。

1.  造成较大影响的通用类型漏洞（例如百度app的某个广泛使用的SDK存在命令执行、ueditor编辑器存在上传漏洞等）；
    
2.  思路新颖、利用传统测试方法不易被发现，同时对百度业务造成较大危害；
    
3.  能够发现百度防护措施中缺失的、非已知的高危风险，协助增强整体安全防护能力；
    
4.   若本月未评选出高质量漏洞奖，则奖项可空缺；
    

**奖励形式：**

根据综合评选，奖励最高3万RMB现金奖励

 

**奖励发放形式：**

1.白帽子向BSRC提供现金奖励接收账户；

2.BSRC按照流程将现金奖励汇入指定账户；

3.荣誉证书以邮寄形式发放。
