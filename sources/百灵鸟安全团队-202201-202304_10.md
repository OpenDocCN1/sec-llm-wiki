# 手搓shellcode

《20M golang to 1KB shellcode》文章中，提到了“ShellCodeFrame”项目，整体上需要改动地方蛮多的。在搓之前，得了解下Win32API。可以参考《Programming reference for the Win32 API》文档，找到我们需要shellcode执行函数的结构体定义方法。

## shellcode 1.定义函数指针

在ShellCodeFrame”项目中，修改api.h文件，添加我们的函数指针，以及定义结构体。![](../Images/a316db4ef913b5db5dbbd8a6ef0b4cd6.png)

## shellcode 2.指定函数HASH值

这里的hash值应该指的是Win32 API hash值，函数的调用实际上是对win32 api接口的调用。![](../Images/e83c1fc5da8125f15dac39defd397b9a.png)我们修改"ShellCodeFrame"项目中,hash.h文件，添加我们需要的函数HASH值。![](../Images/1ac40062d587eeadee66f7df81406aaa.png)

## shellcode 3.通过hash值加载函数

关联之前定义的结构体，这样我们使用结构体时，就会自动调用对应函数的接口，从而我们的代码也就可以正常执行了。![](../Images/dfa7e9427a40fec537831a4b7e84edb3.png)

## shellcode 4.手搓"stager to shellcode"代码

在写的时候遇到了几个坑点，之前的文章中都没有提到，就是winsock2.h中ip地址和端口号可能使用了大小端。例如我这里的IP为"127.0.0.1"，那么我首先得转换成"1.0.0.127"然后“IPtoint”方式转换成数字“16777343”。可以用在线工具临时转换。![](../Images/dbee4bf83571cc2ce07fe66113b67282.png)端口也一样，可以使用C语言htons函数进行转换。

```
printf("%d", htons(55555));
```

最终修改了代码。

```

Sockaddr.sin\_addr.s\_addr = 16777343;
```

在"ShellCodeFrame"项目中，修改a.start.cpp文件。  
![](../Images/068f8d3d106ca6d534bf35a94f76bde8.png)实现：TCP远程连接127.0.0.1端口5555，发送标识符“Alphabug”，然后等待接收shellcode，接收完成后加载到内存里。并且这里的内存空间给了30mb左右（抄《20M golang to 1KB shellcode》中的部分代码）。

## shellcode 5.生成shellcode.bin文件

生成exe后需要执行才能落地。![](../Images/eeeb38d4c43c2860219fbb543895c636.png)执行后，生成Shellcode.bin文件![](../Images/588be6de89a29618b5ad277ff5971622.png)**688 bytes** 不到1kb，可以用于Ms17-010的Exploit中。![](../Images/215639885c7d23ef246348693cb0f8d8.png)

# Stager Demo

## demo 1.装载shellcode

将shellcode.bin文件中ip和端口进行替换，这样就可以方便我们二次使用。利用ida、hexdump等工具找到对应的偏移位置，利用go实现大小端转换，重新构造新的shellcode。“n2n”变量指的是stager server地址。![](../Images/cfc768da93d82e0abef5c955c691ff78.png)

## demo 2.修改ms17-010 Exploit

采用go版的利用工具，修改源码，把我们的shellcode装载进去，这样就可以实现stager上自定义的大文件shellcode装载。![](../Images/aec4b17744ae6d06c803e6990e4a80b7.png)

## demo 3.exe to shellcode

使用go写一个简易的程序，生成后，利用donut工具，转换下。

```


package main
```

执行编译，模式pie

```
go build -buildmode=pie -o calc.exe calc.go
```

exe转换shellcode

```
donut.exe -i calc.exe -o calc.bin
```

donut.exe工具生成的shellcode就特别大，**2.37MB.**![](../Images/fc398cc9e810b2193775cfb56e6a9fdb.png)
