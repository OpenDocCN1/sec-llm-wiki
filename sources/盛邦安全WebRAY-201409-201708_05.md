# 智能时代风险的安全治理--盛邦安全创始人权小文将在2017网络安全生态峰会发表专题演讲

 2017网络安全生态峰会(原“阿里安全峰会”)将于7月26日-27日在北京国家会议中心举行。盛邦安全（WebRAY）创始人权小文受邀参加本次峰会，并将在“威胁情报与安全智能”分论坛发表题为《智能时代风险的安全治理思路探讨》的专题演讲。权小文在演讲中将基于对上百所高校、普通教育机构的网络空间数据的积累，结合WebRAY在多所高校的一线服务实践经验，深度剖析网络空间中智能设备被忽略的空间威胁，提出智能时代网络空间安全治理的新思路。

![](../Images/b4ce89f42d6a1dfa7cb8fe34ae708623.png)

2017网络安全生态峰会（2017 Internet Security Summit，简称ISS）始办于2014年，在中央网信办网安局、工信部网安局、公安部网安局指导下，由中国互联网协会、中国网络空间协会、阿里巴巴集团、蚂蚁金服集团联合主办，是国内创办最早、规模最大、嘉宾阵容最强大、安全行业最权威的国际大型安全盛会之一。

![](../Images/398816d4e27c696f5cbe4029e6aae40f.png)

本届ISS 大会以“新安全·共担当”为主题，秉承一贯的务实、严谨、专业、富有责任的作风，邀请众多政府主管部门、国内、国际安全行业顶尖专家、学者，高端技术人才一同参与，聚焦新型网络犯罪类型、解剖新型犯罪手段，共话中国网络“新安全”，“共担当”新业态下的网络安全责任，让科技赋能社会治理，推动安全生态共建，为互联网产业的健康发展赋予更多能量与动力。
