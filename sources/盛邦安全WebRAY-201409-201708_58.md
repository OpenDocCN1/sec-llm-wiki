# 盛邦安全被中央媒体持续关注，RSA报道走进两会现场

前言——盛邦安全在RSA大放异彩，被海内外媒体广泛关注，并于3月5日被人民网海外版报道，近日更加被中国贸易报进行了追踪报道，而且送进了两会现场。 下文是来自《中国贸易报》的报道：日前,一场被誉为全球最高级别的信息安全大会在美国旧金山举办。来自官方的统计数据显示, 2016 年美国 RSA 信息安全大会(简称:RSA)参会者超过了 30000 人以上,来自全球 500多家安全厂商和100余位安全专家带来最新安全技术与理念助推RSA升级。值得关注的是,本届RSA 中国参展企业总数创下历史记录,华为、华三(H3C)、360、绿盟科技、盛邦安全、网康等17家知名安全厂商悉数亮相,位列参展商总数第三位(美国参展公司达到419家,德国28家)。展品类型涉及数据安全,网络安全,应用安全,主机安全,云安全,移动安全,无线安全等多个领域。 ![](../Images/f004c5e1d4cc304db277dfdc36756148.png)啊 啊                              ![](../Images/70d81d43a0990cbd5e31433c818e49b3.png)中国网企 RSA 大会展实力有评论认为,在全球信息安全备受各国关注的背景下,RSA 大会以其前沿的技术交流和新品展示,成为全球信息安全产业发展和技术创新的方向标,并深刻影响到全球信息安全发展态势。盛邦安全 CEO 权小文在接受《中国贸易报》记者采访时说,近年来,随着互联网技术的快速发展,以及新型贸易形式的转变和电子商务的兴起,中国越发注重信息安全建设。尤其是自 2014 年网络安全与信息化领导小组成立以来,网络安全产业得到了长足的进步,国内安全市场总额已经超过 50 亿美元,涌现出了一批在国内外都拥有很强竞争力的优秀企业。  
据介绍,本次 RSA 会议上,华为发布了自适应的 APT 防御解决方案,涵盖了从防御到检测,再到 APT 事件调查以及整网的安全态势感知等功能,该方案吸引了大量的参观者成为 RSA 大会上的一个热点;与此同时,远江盛邦(北京)网络安全科技股份有限公司(简称 WebRAY)在 RSA大会上,首次发布实时安全操作系统 RayOS,以及“多态 Web 防护”、“智能的关联分析方法”,“一体化引擎”等专利技术,在应用安全领域打造了“监控-预警-防护”三位一体的防护体系;360 在此次大会发布了面向全球互联网提供 DDoS 监测和告警服务的系统,对于全球成规模的 DDoS事件,DDoSMon 基本会在第一时间成功探测检出。利用该系统还能结合多种数据源,帮助用户看到攻击的深层内幕。 ![](../Images/abba98c91fbf58d61a35907f5d6dc6a4.png)政策牵引 助推信息安全技术创新 “信息安全问题作为企业研发首要解决的问题从未消失过”。权小文告诉记者,随着互联网的高速发展,不同类型网站被攻击的频次正呈上升态势,加大了网络信息安全的隐性风险。有数据显示,目前,中国正面临网络安全威胁,是全球网络攻击的‘主要受害国’,平均每月有 1万多个网站被篡改,80%的政府网站受到过攻击。作为信息安全的研发企业,解决信息安全问题是企业的首要任务,更是企业的使命。一个国家的网络安全能力归根结底是由其网络安全产业的能力决定的,而企业又是其中最重要的组成成分,本次中国企业在 RSA 的集体亮相,正反映出了我国网络安全整体水平的大幅提升。有业内人士表示,中国网络信息安全技术的发展得益于政府强有力的政策指引。在政策的引导下,涌现了以“龙芯”为代表的自主 CPU 芯片以及以浪潮为代表的自主主机、服务器企业,一些信息安全技术也取得了长足的进展。2013 年浪潮研发的我国首台基于自主核心技术的关键应用主机——天梭 K1 系统正式发布,填补了关键应用主机系统国内空白,并将与国际先进水平的差距缩短到一年以内。 ![](../Images/d5624e8d04e7d4c3eeaa2ca3c3fc87f1.png)海外竞争 锁定“一带一路”信息安全 “一个产业的发展需要技术创新与市场拓展同步进行,而对于网络信息安全的产业发展来说,  
更需要的更为严苛的法律环境来促进。”为此,权小文援引了本届 RSA 大会上,美国斯坦福大学医疗中心网络安全部门负责人话说:“在美国,泄露一条用户数据的罚款是 2000 美金,我们一个电子表格上存储的数据是20000个,你说说这个表格值多少钱?而且除了巨额罚金外,我们的声誉也将受到极大的损害,所以我们对于网络安全一直都保持着高度的重视和大量的投入。” 权小文认为,有效促进国家网络安全水平提升的关键来自法律和制度建设的顶层设计,只有安全责任真正落实了,安全需求才会真正爆发出来。据了解,除了为国内企业提供信息安全防护外,中国网络安防企业正通过不同的渠道拓展国际市场。权小文说:“在国内除了研发外,我们从 2013 年开始,担国家重要活动、赛事的网络安保任务。其中包括政府网站安全大检查、93 阅兵、全国两会、世界互联网大会等。”与此同时,为响应信息安全产品国产化政策和国家“一带一路”战略,WebRAY 旗下安全产品先后在印度,阿联酋,日本,图曼等国家部署上线,为“沿带沿路”企业的网络安全保驾护航。权小文告诉记者,经过几年的实践,市场受到认可了,心里也有底了,我们有能力与国际大牌叫板。 点击原文
