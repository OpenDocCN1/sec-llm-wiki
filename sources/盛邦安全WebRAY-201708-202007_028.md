# 烽火狼烟丨Apache Kylin SQL注入漏洞（CVE-2020-1937）风险提示

Apache Kylin™是一个开源的、分布式的分析型数据仓库，提供Hadoop/Spark 之上的 SQL 查询接口及多维分析（OLAP）能力以支持超大规模数据，最初由 eBay 开发并贡献至开源社区。它能在亚秒内查询巨大的表。  

  

2020年05月29日, 安全服务部监测到Apache Kylin官方发布安全公告，披露了一个Apache KylinSQL注入漏洞，攻击者可以远程在Kylin没有任何保护或验证的情况下执行SQL语句。

  

WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

  

**漏洞概述**

Apache Kylin 在Kylin 2.3.0 to 2.3.2，2.4.0 to 2.4.1，2.5.0 to 2.5.2，2.6.0 to 2.6.4，3.0.0-alpha, 3.0.0-alpha2, 3.0.0-beta, 3.0.0版本中存在SQL注入漏洞，攻击者可远程执行SQL语句。
