Nexus Repository Manager 3.x 远程代码执行漏洞的风险提示


近日，WebRAY 安全服务部发现互联网存在 Nexus Repository Manager 3的远程代码执行漏洞（CVE-2020-10199），包括版本3.21.1在内的Nexus Repository Manager 3.x OSS / Pro均受到本漏洞的威胁。Nexus Repository Manager 3是一个广泛使用的开源Java服务器应用程序，可以用来搭建仓库管理私服，因其强大的管理、搜索功能被广泛使用，拥有Repository Manager账号的恶意攻击者通过向目标发送精心构造的请求来执行任意代码。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

Nagios XI 跨站脚本攻击漏洞的风险提示


近日，WebRAY 安全服务部发现互联网存在 Nagios XI的多个跨站脚本攻击漏洞，（CVE-2020-10819，CVE-2020-10820，CVE-2020-10821），包括版本5.6.13以下的Nagios XI均受到漏洞的威胁。Nagios XI是一个建立在Nagios核心和其他证明开源组件的企业级监测和报警方案。功能包括一个PHP网站界面,综合表现图,可定制的仪表板、网络结构、配置GUI(图形用户接口)、用户管理等。2020年4月7日，Nagios官网发布了全新的Nagios XI 5.6.13版本，修复了在登陆情况下的POST型跨站脚本攻击漏洞。存在漏洞的URL路径为：includes/components/ldap_ad_integration/，account/main.php。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。
