**不一样的网络空间——病毒与漏洞篇**

  

来源于自然界的新冠病毒彻底打乱了世界秩序，成为人类生命健康的最大威胁。在网络空间中，计算机病毒成员上亿且每年增长上千万，这些人造恶意代码或藏匿于吸睛链接里，或寄生于进程代码间，或盘踞于设备固件内，或穿梭于服务会话中。人性的单纯、马虎、懈怠、贪婪都成为了病毒的吸附器。其中，与漏洞结合的病毒危害性更大，成为网络空间中的头号威胁。

**烽火狼烟**

  

  

**Nexus Repository Manager 3.x 远程代码执行漏洞的风险提示**

  

近日，WebRAY 安全服务部发现互联网存在 Nexus Repository Manager 3的远程代码执行漏洞（CVE-2020-10199），包括版本3.21.1在内的Nexus Repository Manager 3.x OSS / Pro均受到本漏洞的威胁。Nexus Repository Manager 3是一个广泛使用的开源Java服务器应用程序，可以用来搭建仓库管理私服，因其强大的管理、搜索功能被广泛使用，拥有Repository Manager账号的恶意攻击者通过向目标发送精心构造的请求来执行任意代码。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

[原文链接](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650262388&idx=1&sn=ad9d46e022989fb6e82f14778c4b8a03&scene=21#wechat_redirect)

  

**Nagios XI 跨站脚本攻击漏洞的风险提示**

  

近日，WebRAY 安全服务部发现互联网存在 Nagios XI的多个跨站脚本攻击漏洞，（CVE-2020-10819，CVE-2020-10820，CVE-2020-10821），包括版本5.6.13以下的Nagios XI均受到漏洞的威胁。Nagios XI是一个建立在Nagios核心和其他证明开源组件的企业级监测和报警方案。功能包括一个PHP网站界面,综合表现图,可定制的仪表板、网络结构、配置GUI(图形用户接口)、用户管理等。2020年4月7日，Nagios官网发布了全新的Nagios XI 5.6.13版本，修复了在登陆情况下的POST型跨站脚本攻击漏洞。存在漏洞的URL路径为：includes/components/ldap\_ad\_integration/，account/main.php。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

[原文链接](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650262401&idx=1&sn=543d72d987d94879320a41a9b60e9918&scene=21#wechat_redirect)

  

**IBM WebSphere Application Server 远程代码执行漏洞风险提示**

  

近日，WebRAY 安全服务部发现互联网存在WebSphere Application Server的远程代码执行漏洞（CVE-2020-4276和CVE-2020-4362）。该漏洞影响WebSphere Application Server 7.0.x - WebSphere Application Server 9.0.x之间多个版本。IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品。该产品是JavaEE和Web服务应用程序的平台，也是IBMWebSphere软件平台的基础。该漏洞存在于WebSphere SOAP Connector 服务，未经授权的远程攻击者可通过该漏洞在目标服务器执行任意恶意代码。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

[原文链接](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650262428&idx=1&sn=e8bfc992fba6d5b1c17312e1b2137877&scene=21#wechat_redirect)

  

**微软多个安全漏洞风险提示**

  

WebRAY 安全服务部于2020年4月15日监测到微软发布的安全更新，本次更新共发布了113个漏洞补丁，包含了Microsoft Windows、Microsoft Edge (EdgeHTML-based)、Microsoft Edge (Chromium-based)、ChakraCore、Internet Explorer、Microsoft Office and Microsoft Office Services and Web Apps、Windows Defender、Visual Studio、Microsoft Dynamics、Microsoft Apps for Android、Microsoft Apps for Mac软件的安全更新。包含CVE-2020-0760、CVE-2020-0906、CVE-2020-0938、CVE-2020-0932、CVE-2020- 0980等多个远程代码执行漏洞，建议广大用户及时更新系统并安装 windows 补丁，做好预防工作，以免遭受攻击。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

[原文链接](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650262441&idx=2&sn=6b24b8e8e2afb0a1ad8d8dadc33148f5&scene=21#wechat_redirect)

  

**Oracle WebLogic Server多个安全漏洞风险提示**

  

近日，WebRAY 安全服务部监测到Oracle官方发布的2020年4月重要关键补丁更新，本次关键补丁更新是多个安全漏洞补丁程序的集合，共计397个新安全补丁，其中CVE-2020-2801、CVE-2020-2883、CVE-2020-2884等漏洞影响范围较广，建议及时更新补丁。

WebLogic是美国Oracle公司出品的一款基于JAVAEE架构的中间件，是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。

**通达OA任意用户伪造登录漏洞风险提示**

  

通达OA是适用于企事业单位的通用型网络办公软件，融合了通达科技长期从事管理软件开发的丰富经验与先进技术，并采用B/S(浏览器/服务器)操作方式，使得网络办公不受地域限制。2020年04月17日, 安全服务部监测到通达OA官方更新了一个v11版本安全补丁, 该补丁中修复了任意用户伪造登录漏洞。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。
