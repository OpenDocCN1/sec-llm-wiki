# 烽火狼烟丨Nexus Repository Manager 3.x 远程代码执行漏洞的风险提示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650262388&idx=1&sn=ad9d46e022989fb6e82f14778c4b8a03&chksm=83204600b457cf16c94c403a2db1bebc5d3981e33f1faab07eea3b6164c827ad138a60d6da3e&scene=126&sessionid=1681374644#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650262388&idx=1&sn=ad9d46e022989fb6e82f14778c4b8a03&chksm=83204600b457cf16c94c403a2db1bebc5d3981e33f1faab07eea3b6164c827ad138a60d6da3e&scene=126&sessionid=1681374644#rd)

近日，WebRAY 安全服务部发现互联网存在 Nexus Repository Manager 3的远程代码执行漏洞（CVE-2020-10199），包括版本3.21.1在内的Nexus Repository Manager 3.x OSS / Pro均受到本漏洞的威胁。Nexus Repository Manager 3是一个广泛使用的开源Java服务器应用程序，可以用来搭建仓库管理私服，因其强大的管理、搜索功能被广泛使用，拥有Repository Manager账号的恶意攻击者通过向目标发送精心构造的请求来执行任意代码。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

  

**漏洞概述**

经过身份认证的攻击者，通过发送存在恶意的JavaEL表达式达到远程代码执行的目的。

  

  

**漏洞基本信息**  

| 

产生原因

 ||

 |

|

 || 

Nexus Repository Manager OSS/Pro 3.x <= 3.21.1  


 |
|

 ||

 |
| 

分类

 || 

远程代码执行漏洞

 |

  

  

**漏洞等级**  

WebRAY安全服务部风险评级：高危

  

  

**修复建议**

官方已发布修复版本，请更新到Nexus Repository Manager OSS/Pro 3.21.2版本：

https://help.sonatype.com/repomanager3/download/
