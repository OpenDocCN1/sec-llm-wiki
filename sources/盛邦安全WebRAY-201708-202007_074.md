**前言**

2020年3月6日，WebRAY安全服务部发现思科发布最新版本关键补丁更新，包含对CVE-2020-3127/CVE-2020-3128、CVE-2020-3148、CVE-2020-3155等多个高危漏洞的修复补丁，涉及Cisco Webex Network Recording Player、Cisco Prime Network Registrar（CPNR）、Cisco Intelligent Proximity solution等思科设备。Cisco Webex Network Recording Player是用于对会议记录进行播放的设备。Cisco Prime Network Registrar是一款集成、可扩展的可靠域名系统(DNS)、动态主机配置协议(DHCP)和适用于IPv4和IPv6的IP地址管理(IPAM)服务的解决方案。Cisco Intelligent Proximity是一套可进行无线数据共享的设备。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

  

**漏洞概述**

CVE-2020-3127/CVE-2020-3128：恶意攻击者可通过精心构造的ARF或WRF文件对Cisco Webex Network Recording Player 和 Cisco Webex Player程序进行攻击，Webex 记录信息没有被充分验证，将以目标用户的权限执行任意代码；

  

CVE-2020-3148：恶意攻击者利用Cisco Prime Network Registrar存在跨站请求伪造漏洞可修改其配置，导致可创建或修改任意权限用户；

  

CVE-2020-3155：恶意攻击者利用Cisco Intelligent Proximity solution中缺少SSL验证，拦截目标流量进行中间人攻击，并使用伪造的证书查看或修改信息。

  

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危
