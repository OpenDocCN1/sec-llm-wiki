**前言**

2020年2月26日，WebRAY安全服务部发现微软发布一个重要补丁程序，该公告表示Microsoft Exchange Server存在远程执行代码漏洞（CVE-2020-0688）。Microsoft Exchange Server 是一个消息与协作系统，可被构架应用于企业、学校的邮件系统或免费邮件系统。此漏洞是微软Exchange控制面板（ECP）组件中的静态密钥漏洞，具有邮箱的已验证用户可利用该漏洞发起恶意请求，获得system权限执行任意代码，从而完全控制Exchange服务器。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

  

**漏洞概述**

经过身份验证的攻击者利用微软Exchange控制面板（ECP）组件中的静态密钥漏洞，可发起恶意请求，获得system权限执行任意代码，并完全控制Exchange服务器。

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危

  

  

**漏洞基本信息**

产生原因：Exchange Server在安装时未能正确创建唯一的加密密钥

影响范围：

Microsoft Exchange Server 2010 Service Pack 3 Update Rollup 30

Microsoft Exchange Server 2013 Cumulative Update 23

Microsoft Exchange Server 2016 Cumulative Update 14

Microsoft Exchange Server 2016 Cumulative Update 15

Microsoft Exchange Server 2019 Cumulative Update 3

Microsoft Exchange Server 2019 Cumulative Update 4

漏洞ID：CVE-2020-0688

分类：远程代码执行漏洞

  

  

**修复建议**

微软官方已发布最新补丁，下载安装地址：      

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0688
