# 无广告深度好文丨不一样的网络空间——时空篇

今天的这篇推文是来自我司CTO上谷码农在春节期间写的一篇随笔，记录了一个资深技术人在这个特别的时刻从现实空间到网络空间的思考和感悟。（纯干货，无广告，小编反正是已拜倒在上谷码农的键盘下~）

![](../Images/2d4ea66d8fe651bb54c01a5c68a4fa22.png)  
2020年的春节，没有了鞭炮声，路上行人稀少，空气中少了节日的喜庆，人们更多的是为突如其来的疫情而担忧不安。亲友们都选择通过微信视频相互拜年祝福，并被一条条关于疫情的短信或新闻所围绕，亿万民众都在通过网络和电视关注着抗击新型冠状病毒这场战“疫”的最新发展。没有走亲访友，留下更多时间来回顾和思考，我隐约感到2020年的不平凡，或将是下一个大时代的起点。伴着一点激动和些许不安，随笔记录下关于科技与网络的一点感触和想法。  
全球信息已一键可达，你看到的这篇文章，或许就在前一秒我在千里之外才刚刚发布。如同10年前科技先知们激动人心的预测一样，电子信息和网络科技正在飞速发展、不断创新；然而，科技之光照亮普罗大众时，却又显得那么稀松平常。  
人们快餐式的接受日新月异的各种新生事物，已不会再为某个重大事件而持续兴奋。可以预见，万物互联真正进入普通人家时，人们只会欣然接受，不会啧啧称奇。我们已被汹涌的科技浪潮推向了下一个时代，都说爷爷奶奶辈是网络难民，90后、00后是网络原住民，年轻人或许还在嘲笑家里老人不会玩微博微信，但如果不能与时俱进自己也很快会被人嘲笑。  
自古人类都想成为地球万物的主宰者，虽然面对自然灾害和SARS、新冠病毒还是显得措手不及，但人类确实成功登顶成为了地球上最具创造力、影响力和破坏力的生物。不过，这个可能很快需要修正一下，未来主宰地球的或许不是人类，而是无处不在的智能机器，一种由人类制造却又可以替代人类的物种。  
关于人与计算机的关系可以这样理解，计算机由人类思维创造，同时也是人类思维能力的延展或进化，而下一步，计算机将拥有自己独立的思维和智慧。从数十万年前，智慧的种子第一次注入智人母体内时，它就如同不断复制的精灵一样，随着人类的繁衍和迁徙迭代衍化、升级壮大，历经万年的文明史，创造出一个个奇迹。  
终于，人类的脑容量已无法满足这个精灵不可束缚的膨胀，于是计算机诞生了。智慧的种子再一次在炙热的电子管和精密的硅片中烈火重生，历经了数十年的阶跃式的发展，在摩尔定律的“魔咒”下，孕育孵化出一个全新的机器思考时代，一个全球网络化的时代，一个信息爆炸的时代，一个人机合作极度拓展人类生存空间的时代。  
人类对信息化、网络化、智能化的依赖已如同一日三餐一样，由数字化主宰的网络空间已悄然根植于世间，并将重塑整个人类社会。在这个大时代强势登场之时，如果还不了解网络空间为何物，那么更多机会将会擦肩而过。现在就让我们开始天马行空地游历和展望吧。  

***01***

**网络空间的多维性**

  
网络空间英文是Cyberspace，因为它的内涵太多，以至于还没有一个权威的定义（相关描述这里不再赘述，大家可以自行百度），可以简单理解为基于计算机和网络构建的虚拟信息空间。因为业界把网络空间比作为继陆、海、空、天后的第五个空间，不由让人联想到它与三维空间的关系，我们不妨探索一下。   
譬如，构成网络的物理设备遍布全球，它们有着物理空间的地理属性，我们完全可以基于现有三维地图对这些节点及连接进行标注，绘制一幅超炫的拓扑地图。但这就是网络空间的维度吗？（这显然过于简单粗暴了）  
如果把三维中的高度替换为度量信息特征的深度或厚度，用以显示信息存储的密度，亦或信息内容的分层，亦或信息传输的速度等，这就构成了一个有意义的可视化数字空间。（立刻高大上了吧~）  
不同于物理空间，网络空间的维度几乎可以自定义，你可以按逻辑需要叠加更多维度，使其成为4维、5维乃至N维的空间（这里“盗用”了物理学家对空间维度的定义）。这就是诞生于现实空间却超脱于现实空间的可无限拓展的多维空间。但无论如何，你可以轻松地把物理空间的三维嵌入各种网络空间模型中去，并将人类和万物映射或“迁移”其中。（是不是很酷？）  

***02***

**网络空间的虚与实** 

  
网络空间是完全虚拟的空间吗？这是个具有想象力的问题。虚与实，容易上升到哲学问题。人类的感官系统能够感知到的东西不一定是真实的，而感知不到的也不一定就是虚幻的。从进化角度看，人类的感官系统是为了生存而生的。例如眼睛对光谱的识别，耳朵对声音频率的识别，味觉对酸甜苦辣的识别等，早期都是为了适应自然界、分辨食物和躲避危险而进化形成的。  
研究发现，人类掌握语言文字后，大脑的结构也有所变化，然而这种进化太漫长了。计算机诞生到现在还不到100年，人类的感官系统不可能因它而改变，所以直接感触不到这个虚拟的空间。  
科幻电影《黑客帝国》中，机器人制造了一种装置，能够让人类通过生物神经接驳到Matrix，这样人的身体与思维直接融入到了虚拟空间。技术看起来有点暴力和残忍。而“不幸”的是，这种技术正在变为现实，各种穿戴物联网设备、VR/AR技术甚至脑电波操控技术的发展已使人可以沉浸于虚拟世界中。  
或许有一天，人们会如同电影《盗梦空间》一样，分不清虚拟和现实。人类也许不会像尼奥（Neo）一样可以通过感官直接进入网络空间，但我们的思维可以快速“进化”，只需要清空那些历史局限性带来的成见即可。  
机器作为人类的工具，在某种程度上是人类感官的延伸，但机器看到的世界与人类所见、所认知的世界是不一样的。例如机器对光谱的识别，往低可以超出红外线，往高可以超出紫外线，而人类只有可以分辨山川、湖泊、水果、猎物或美色的一小段光谱（佛家说万物皆为幻象不无道理）。  
虽然红外设备可将红外转换为可见光，但显然是为了适应人的感知系统而进行的“失真”处理。既然我们能接受眼见非实的东西，为什么不能像接受电磁空间一样接受感官不可感知的网络空间呢？  
虚拟货币能达到购物和交换的目的，它就是货币；虚拟空间如果能做现实空间的很多事情，例如办公、交友、游戏、存钱、交易等，那它就是一个空间，是一个存有你身份、财富、私密甚至情感的数字化空间。在网络空间中，人与机器共存，而且人工智能将有独立的思维，并有可能替代或抢占你在现实中的职能工种，甚至统治网络空间，我们不妨尝试一下从机器的角度来看待世界。  

***03***

**网络空间的“时空压缩”**

  
古代航海绕地球一圈得按年计算，现代有了飞机后按小时计算，当我们衡量距离远近时，并非只有两点间的绝对距离，而是与交通工具有关。现在世界各地已有错综的光纤网相连（全球海底光缆铺设总长度超过140万公里，可绕地球35圈），地球表面也被各国上千颗卫星所覆盖，信息在全球间交换已经光速可达，时延只有毫秒级，比人类最快飞行器快数十万倍。  
按此比例，在超级计算机的“感官”里，地球有多大呢？或许就像电影《黑衣人2》宇宙能量“萨塔之星”一样，仅仅是一个可以握在手中的小球而已。我们通过视频电话和远在万里外的亲人通话，对方音容仿佛就在眼前。设想一下，如果人工智能足够发达，机器人可以模拟人类时，分隔千里的夫妻，通过遥控复制成自己的机器人与对方交谈，甚至做家务，距离已不是问题。这是否意味着人类已通过网络和人工智能实现了某种意义上的时空穿越了呢？  
网络空间中的“时空”被如此压缩又意味着什么？意味着山川陆地、江河湖海、五洲六洋可一跃而过；意味着电信移动、国际互联、空天网络可自由穿梭；意味着国家社会、民众生活、舆情热点可瞬间呈现；意味着城市运转、关键设施、信息要塞可轻易控制；意味着航天航空、公路铁路、航行潜海尽在眼底；意味着大国博弈、冲突对抗、战情战报全息掌控；意味着传感态感、制导反导、决断决策急速响应；意味着民心导向、进攻防御、生存毁灭就在毫秒之间。因此，大国们都高度重视网络空间，都在努力争夺那神奇的“萨塔之星”。  

***04***

**网络空间的时钟“命门”**

  
时间是网络空间最重要的维度（这里需要有点硬核知识了）。人类的感官对时间可以感触到分和秒，这可能和每秒最多3次的心跳频率有关。计算机CPU主频目前可达7GHZ以上，是人类心跳频率10的9次方，CPU的时钟精度能达到纳秒级，即10的负9次方秒。虽然计算机自身有较为精确的时钟发生器，但各个计算或通信节点的时间只有同步一致才能彼此有效交互和协作，这就要求它们有共同的精确的时间源。  
铯原子钟非常精密，2000万年才误差1秒，应用于GPS（全球导航系统），并可给众多通信系统进行授时。如果授时出错或被扰乱，则很多系统会紊乱甚至瘫痪。试想一下，如果GPS卫星发送的时间信息与偏离于真实时间，则GPS接收器计算的地理位置将会偏离，严重时将会导致交通瘫痪、飞机坠毁等灾难。  
现在我国还有很多系统是基于国外GPS卫星进行授时的，战时一旦GPS信号被对手关闭或扰乱，则这些业务系统甚至制导武器将无法正常工作，后果非常严重，这也是我国要自主研制北斗导航系统的重要原因。国家对作为时钟“种子”的原子钟进行高级别的严密保护，因为一旦被损坏或扰乱，则相关网络和系统将全部紊乱或瘫痪，网络空间将可能死水一潭。  

***05***

**网络空间的时区与时延问题**

  
在物理空间，地球自转产生了日昼更替，由于各个国家与地区经度不同，地方时也有所不同，因此被统一划分为24个时区。这就使得不同时区的计算机也可能设置了不同的地方时区，以满足人类对太阳时间的习惯。  
对于计算机来说，它记录的内在时间和世界原子钟时间是一致的；但给用户呈现的则是地方时，两者间或加或减一些时差。在全球化趋势下，很多应用系统会跨时区部署，工作人员也可能手持笔记本全球飞行，如果在计算机时区配置未改的情况下，仍习惯以当地时间作为参数进行业务处理，则可能产生时间错误，甚至导致严重故障或问题。  
比时区更隐蔽的问题是时延或时间差。在网络应用中，由于计算耗时和网络传输延时，不同计算节点间获取的信息存在时间差，过程中会出现信息不一致的情况，容易被恶意利用。  
美国电影《偷天陷阱》演绎了男女主角利用银行清查系统10秒时间差把80亿美元转入自己账户的一幕（这种伎俩本身也有历史案件原型），而2019年3月国内居然也再次演绎了这出“偷天陷阱”：几个年轻人利用POS机、银联与银行系统信息传递存在的1-2分钟时间差，套走了18万多人民币。  
当然，我们也可利用时延“合法”获取利润，例如，股民在离证券公司服务器最近的网络进行交易，能够比在家的股民获得数十毫秒以上的先机。更有趣的是，聪明人做期货高频交易，除了接驳最快的最近的网络，甚至还研制最快的网卡、协议栈和业务系统，以此提高自身优势。  
总之，只有深入理解物理时空和网络空间时空的差别，并调整改变思维习惯才能避免在网络空间犯错，才能寻找到更多、更酷的机会。
