**前言**

近日，微软补丁更新SQL Server 远程命令执行漏洞（CVE-2020-0618）。Microsoft SQL Server 是Microsoft 开发的一个关系数据库管理系统(RDBMS)，现在是世界上最为常用的数据库之一。此漏洞中，低权限的攻击者向SQL Server的Reporting Services实例发送精心构造的请求，即可造成远程代码执行漏洞。

  

  

**网络基本情况**

盛邦安全网络空间搜索引擎发现全球共有1099475台设备使用微软 SQL Server数据库管理系统，具体分布情况分布见下图（颜色深浅代表数量多少，颜色越深数量越多）。

![](../Images/10d31a3f70769c111ac321c33b7f1101.png)

在全球范围内，中国使用的微软 SQL Server数据库管理系统最多，有298120台设备。其次是美国，有228909台设备使用微软 SQL Server数据库管理系统，智利排第三，有93649台设备使用微软 SQL Server数据库管理系统。巴西有34166台设备使用微软 SQL Server数据库管理系统。摩洛哥有29355台设备使用微软 SQL Server数据库管理系统，挪威则有28998台设备使用微软 SQL Server数据库管理系统。

![](../Images/1d77f02c154a05a53a38b67c019fb008.png)

在中国境内微软 SQL Server数据库管理系统的使用中，北京最多，有95495台。其次是广东，有37980台设备使用微软 SQL Server数据库管理系统，香港排第三，有29406台设备使用微软 SQL Server数据库管理系统。浙江有22676台设备使用微软 SQL Server数据库管理系统，上海有19302台设备使用微软 SQL Server数据库管理系统，江苏有13372台设备使用微软 SQL Server数据库管理系统，山东有9446台设备使用微软 SQL Server数据库管理系统。

![](../Images/06d668d929bee5bef1464ee56e96320a.png)

  

**漏洞影响及其修复**

1\.  受影响版本：

Microsoft SQL Server 2012 for 32-bit Systems Service Pack 4 (QFE)

Microsoft SQL Server 2012 for x64-based Systems Service Pack 4 (QFE)

Microsoft SQL Server 2014 Service Pack 3 for 32-bit Systems (CU)

Microsoft SQL Server 2014 Service Pack 3 for 32-bit Systems (GDR)

Microsoft SQL Server 2014 Service Pack 3 for x64-based Systems (CU)

Microsoft SQL Server 2014 Service Pack 3 for x64-based Systems (GDR)

Microsoft SQL Server 2016 for x64-based Systems Service Pack 2 (CU)

Microsoft SQL Server 2016 for x64-based Systems Service Pack 2 (GDR)

2\.  修复建议： 

建议参考微软官方漏洞修复进行修复：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0618

  

  

**总结**

从网络空间搜索引擎的角度去探讨微软SQL Server 远程代码执行漏洞（CVE-2020-0618）对全球造成的影响力。主要的结论如下：

1\.  现阶段全球共有1099475台机器使用微软 SQL Server数据库管理系统。

2\.  此漏洞中，攻击者经过身份验证后，向SQL Server 的 Reporting Services实例发送精心构造请求，从而造成远程代码执行漏洞。
