# 烽火狼烟丨Django SQL注入漏洞(CVE-2020-7471)风险提示

**前言**

2020年2月初，Django官方发布安全通告：由于StringAgg（分隔符）造成潜在SQL注入的漏洞。Django 是一个高级的Python 网络框架，可以快速开发安全和可维护的网站。它是免费和开源的，有活跃繁荣的社区，丰富的文档，以及很多免费和付费的解决方案。在此漏洞中，攻击者将精心构造的分隔符传递给contrib.postgres.aggregates.StringAgg实例，从而绕过转义，造成恶意SQL注入。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。

  

  

**漏洞概述**

通过给contrib.postgres.aggregates.StringAgg实例传递精心构造的分隔符，可绕过转义，造成恶意SQL注入。

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危

  

  

**影响版本**

产生原因： 恶意构造分隔符绕过转义

影响范围： Django 1.11.x < 1.11.28

                  Django 2.2.x < 2.2.10

                  Django 3.0.x < 3.0.3

                  Django master branch

漏洞ID： CVE-2020-7471  

分类： SQL注入

  

  

**修复建议**

Django 官方已发布新版本,可升级为以下版本：

Django 1.11.28：

https://www.djangoproject.com/m/releases/1.11/Django-1.11.28.tar.gz

Django 2.2.10:

https://www.djangoproject.com/m/releases/2.2/Django-2.2.10.tar.gz

Django 3.0.3：

https://www.djangoproject.com/m/releases/3.0/Django-3.0.3.tar.gz
