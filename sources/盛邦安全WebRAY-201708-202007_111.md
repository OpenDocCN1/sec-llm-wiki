# 烽火十八台丨电力行业信息资产安全治理解决方案

**方案背景**  
电力行业信息化发展至今，利用漏洞、电子邮件、后门软件等进行攻击已带来诸多安全问题。随着电力资源的整合，目前大部分业务都需要依赖计算机信息系统来管理，而其中任何一个系统都可能成为黑客攻击的入侵点。  
电网中存在发电厂、变电站、控制站、配电所等诸多容易造成安全事故的重要中间系统和环节，资产类型及数量相当庞大，同时各个环节之间需要协同运行。生产控制大区及管理大区的划分规范出典型的业务系统，包括：电力MIS系统、电力营销系统、电能电量计费系统、SAP系统、电力ISP业务、人力资源系统、信息管理系统、电能量计量系统、电力市场运营系统、电力企业管理业务系统等，庞大的业务系统及快速的更新状态让电力行业信息资产安全状态和问题难以统计和梳理。  
**需求分析**![](../Images/64bf505a3654bf10668b2326fd459d44.png)1、调度、测报等重要系统的“不清晰管理”，容易导致敏感信息暴露；2、未知的物联网资产安全问题逐渐被暴露并开始被利用；3、未知暴露面造成的安全盲区难以控制和管理。  
**问题案例**  
**典型问题一：域间隔离不彻底**![](../Images/f05db9aac2d22b6390c4b9f4588ba9e0.png)  

*   **梳理**：通过资产梳理，发现从管理信息区可访问调度、自动化等生产区系统数据；
    
*   **排查**：利用策略检索，发现安全域间隔离策略不严格，各安全区域界限划分不清晰；
    
*   **溯源**：专用隔离网关设备在长期维护中积累了大量冗余策略，关键控制策略优先级被降低，生产部门为方便管理操作，违规设定了隐蔽通道；
    
*   **延展**：生产管理区（安全区Ⅱ）、非控制生产区（安全区Ⅲ）和管理信息区（安全区Ⅳ）之间均可能存在隔离不彻底的风险，从而产生新的风险暴露面。
    

  
**典型问题二：打印机被控重置**![](../Images/6765170fb3e3e1387e7b8d3d65283bdd.png)  

*   **梳理**：通过资产梳理，发现大量打印机暴露在外网，且调试管理页面未关闭；
    
*   **排查**：通过漏洞扫描，发现部分打印机出现关机、重启甚至恢复出厂现象；
    
*   **溯源**：通过检查判断，查出调试页无登录限制，造成隐私泄漏，存在严重Web漏洞，重置、重启等动作可直接执行等问题；
    
*   **延展**：摄像头、温控等大量未知物联网设备同样存在类似隐患。
    

  
**典型问题三：Tomcat引发后门**![](../Images/c163170a8a1d7f8e601326e51822dc8f.png)  

*   **梳理**：通过资产梳理，发现大量Tomcat管理网站暴露在外网区域；
    
*   **排查**：风险排查，发现存在大量弱口令（例如：tomcat/tomcat）；
    
*   **溯源**：深度扫描，发现被植入后门，并有被尝试连接的事件记录；
    
*   **延展**：IIS7等辅助搭建框架同样存在类似问题。
    

  
**典型问题四：测试系统未退运**![](../Images/d5c63f6f1eeb0cc67b795d18c84e38e2.png)

*   **梳理**：通过资产梳理，发现大量未知网站、测试网站、未及时退运的系统；
    
*   **排查**：发现“影子资产”无人维护，随意暴露在外网，且存在大量漏洞；
    
*   **溯源**：业务部门私自搭建、管理部门交接缺失导致大量资产无人看管；
    
*   **延展**：影子资产暴露导致未知安全隐患，缺乏监管，难以控制。
    

  
**解决方案**![](../Images/bbc8d2597693b6b1d3f209b52228530a.png)

  

**方案要点**  
**1、全面摸底**：采用主被动结合的方式进行资产摸排学习，全面梳理各类业务系统、调度系统及联网设备，挖掘未知资产和影子资产，收缩风险暴露面。**2、统筹部署**：采用分布式部署的方式覆盖集团及各级子单位，并设立集中统计管理中心，辅助信息中心建立层级化的资产管理体系。**3、闭环治理**：建立本地备案体系，纳入资产台账管理，并对在运信息资产进行持续的风险监测与联动防护，从而对紧急事件实现快速响应，形成闭环治理。![](../Images/7612b6d4f421f6fdb1e092f99e4fd3c5.png)END![](../Images/7612b6d4f421f6fdb1e092f99e4fd3c5.png)
