近日，知名安全行业媒体安全牛发布了中国网络安全细分领域矩阵图(Matrix)，**盛邦安全进入“Web应用防火墙 (WAF)”细分领域矩阵领先者行列。**

  

![](../Images/55a9d262dba79d6a05b2bd1572f8b65f.png)（图片来源于：安全牛）

  

Web 应用防火墙 (WAF) 属于安全牛定义的成熟市场。WAF是一款集 Web 防护、网页保护、负载均衡、应用交付于一体的 Web 整体安全防护设备，和防火墙的区别是，它是工作在应用层，主要对 Web 请求进行防护，有效阻止各类针对 Web 应用和 API 的攻击，如 SQL 注入、XML 注入、跨站脚本 (XSS)、自动化攻击（机器人程序）和应用层拒绝服务 (DoS) 等。Web 应用防火墙 (WAF) 属于安全牛全景图【应用安全】一级分类。

  

![](../Images/53571c406d78030fe7f1210ae356a135.png)（图片来源于：安全牛）

  

WAF 产品形态主要分为三种：硬件 Web 防火墙、Web 防护软件、云 WAF。本次调研中，WAF 产品提供商分为两类，1/3 安全厂商以提供云 WAF 服务为主、2/3 的安全厂商既可供软/硬件 WAF 产品也可同时提供云 WAF 服务。

  

Web 应用防火墙的技术核心是对 Web 入侵的检测能力。目前国内 WAF 产品技术能力包含：特征识别技术（语法语义分析）、机器学习、大数据分析、动态防御、RASP、威胁情报、容器技术和蜜罐技术等。WAF 产品的核心竞争力可以归结为三点：精确的威胁/攻击识别率、相关系统及设备的智能联动、规则数据库的保护和更新能力。

  

硬件 Web 防火墙为旁路式和串联式部署在 Web 服务器前，软件 WAF 为代理和嵌入式。据调研发现，对于安全需求较高的网站，如政府、金融、运营商多采购易用、稳定、高吞吐量的硬件 WAF 产品。而软件 WAF 需要单台服务器部署，占用内存过多，并可能存在影响正常业务和被绕过的风险，适合中小型网站。云 WAF 服务采用多租户模式、以云为中心，只需通过移交域名解析权就可实现安全防护，大大减轻了用户的运维成本，但对于一些数据保密级别较高的政企，数据上云是否存在数据泄漏风险，也是客户考虑的因素，国内云 WAF 用户更偏向于互联网行业。

  

**盛邦安全Web应用防护系统（RayWAF）**

  

Web应用防护系统（RayWAF）是盛邦安全基于自主研发的RayOS系统开发的应用安全产品，通常部署在用户的Web应用服务器前；相较于传统的防火墙和入侵防御系统，RayWAF更专注于Web应用自身的安全漏洞，并提供了SSL加速、抗DDoS、应用负载均衡等Web应用安全模块，是一款多安全引擎、高性价比的Web应用安全产品。以下为盛邦安全RayWAF的几个核心技术能力：

  

**威胁情报能力**

  

RayWAF内置威胁情报管理中心，同国际主流数据源和国内情报源进行对接，及时获取威胁情报。通过情报中心，针对问题IP、黑链进行实时的动态防护，并通过多样化的图表进行数据展示，实现准确识别、精准防护与溯源。

  

**安全建模能力**

  

RayWAF可智能学习流量中的Web访问流量，将网站目录结构、请求方法、条件参数及流量明细等相关信息自动生成至本地并建立模型，一方面可以对网站运行情况进行可视化的统计；另一方面直接根据学习结果建立对应的黑白名单及细粒度控制策略，并依据业务的访问情况和安全状态动态进行学习和调整。

  

**联动防护能力**

  

RayWAF能够与盛邦安全大数据分析平台、资产治理平台联动，并内置专业防篡改集中管控系统，从资产梳理、数据分析到攻击防御，形成事前、事中、事后的完整解决方案。

  

**旁路镜像主动防御能力**

  

在旁路镜像工作模式下，RayWAF可以在监测到攻击时，主动与攻击源和目标服务器取得通信，阻断后续攻击行为，使其在避免单点故障发生的同时仍能形成有效的防护，提升部署的灵活性。

  

**行为分析能力**

  

通过行为分析引擎，RayWAF可以对Webshell做有效检测，提前发现网站后门，避免网站成为受控主机，减少被黑客控制和恶意利用的风险。

  

**可视化分析统计能力**

  

RayWAF内置态势分析系统，可以对流量事件和攻击事件进行分析归类，对关键的检测防护信息进行数据钻取并可视化呈现，从而实现快速响应处置。
