前言

2019年9 月 26 日，在PHP 官方发布漏洞通告中指出：在部分配置下的 Nginx + php-fpm 的服务器都可能存在远程代码执行漏洞。此漏洞的漏洞编号为：CVE-2019-11043，由于该配置已被广泛使用，经WebRAY安全服务部研判，漏洞等级为高危。

部分配置信息如下：

 location ~ [^/]\.php(/|$) {

        fastcgi_split_path_info ^(.+?\.php)(/.*)$;

        fastcgi_param PATH_INFO       $fastcgi_path_info;

        fastcgi_pass   php:9000;

        ...

  }

}

据悉，该漏洞在9月举办的Real World CTF中被发现，攻击者可以通过精心的构造和利用，导致远程代码的执行，目前PoC 已在github上公开。

WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。



漏洞概述

换行符 \n导致参数为空引发逻辑漏洞从而导致远程代码执行。



漏洞基本信息

产生原因：触发逻辑漏洞引发远程代码执行

影响范围：使用特定配置的Nginx + php-fpm服务器

漏洞ID：CVE-2019-11043

分类：远程代码执行



漏洞等级

WebRAY安全服务部风险评级：高危



修复建议

1、关注官方网站，及时下载补丁更新；

https://www.php.net。


2、在不影响正常业务的情况下，删除 Nginx 配置文件中的如下配置：

fastcgi_split_path_info ^(.+?\.php)(/.*)$;

fastcgi_param PATH_INFO       $fastcgi_path_info;
