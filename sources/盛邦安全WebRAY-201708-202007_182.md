**每周新闻热点**

**标题：数字货币行业APT一瞥: Coinbase应对Firefox在野0day攻击详情分析**

摘要：2019年5月30日星期四，十几位 Coinbase 员工收到了一封电子邮件，声称是来自剑桥大学研究资助管理员 Gregory Harris。此电子邮件来自合法的剑桥域名，不包含恶意内容，并通过了反垃圾邮件的检测，而且可以引用收件人的背景。2019年6月17日上午6:31，Gregory Harris 发送了另一封电子邮件，但这一封不同：它包含一个 URL，当在 Firefox 中打开时，会自动安装能够接管点击人电脑的恶意软件！Coinbase Security 很快发现这些电子邮件不是普通的邮件 — 它们是使用网络钓鱼/社会工程学策略的复杂攻击，而且具有高度针对性，是深思熟虑的攻击，最重要的是，居然使用了两个 Firefox 0day 漏洞。

链接：http://t.cn/AiHVL1Ts

 

**标题：Google研究人员公布20岁的Windows CTF协议0 day漏洞**

摘要：Google Project Zero团队安全研究人员Tavis Ormandy近日公布了Windows操作系统中存在长达20年的0 day漏洞细节。该漏洞被评为高危漏洞，影响Windows XP以来的所有Windows版本。Ormandy透露了Windows kernel中msCTF模块中的多个设计安全问题。Msctf子系统是Text Services Framework (TSF)框架的一部分，用来管理输入方法、键盘布局、文本处理等任务。TSF由 ctfmon服务器和MSCTF客户端组成。

链接：http://t.cn/AiHXcZ5N

 

**标题：CVE-2019-10216: ghostscript沙箱绕过命令执行漏洞预警**

摘要：2019年8月2日晚，Artifex官方在ghostscriptf的master分支上提交合并Bug 701394的修复。旨在修复 CVE-2019-10216 漏洞。该漏洞可以直接绕过 ghostscript 的安全沙箱，导致攻击者可以读取任意文件或命令执行。

ghostscript应用广泛，ImageMagick、python-matplotlib、libmagick 等图像处理应用均有引用。

链接：http://t.cn/AiH2R08p

 

**标题：喜欢看新闻？你有可能成了姜太公的鱼**

摘要：上周，佛罗里达大学的一支团队，对黑客如何利用受害者的心理来实施网络电子邮件钓鱼一事，展开了比较深入的研究。结果发现，那些心情比较愉悦的人们，相对更容易被诱骗点击钓鱼链接。换言之，如果你的心情不太好，就会相对更少地上钓鱼邮件的当。

链接：http://t.cn/AiHveczE

 

**标题：从某cmsV9.9四个漏洞看程序开发安全**

摘要：近日，对某cmsV9.9版本进行代码审计，发现了4处漏洞。这4处漏洞漏洞比较基础，也很经典。从这4处漏洞，可以反应出在程序开发过程中一些容易忽略的问题，在开发程序时，如果没有正确的过滤单引号（'）、双引号（"）、反斜杠（\\）等特殊字符，往往会产生代码/sql注入漏洞。本文将分享此次审计过程。

链接：http://t.cn/AiHPbLnS

 

**标题：NVIDIA Windows GPU显示驱动、VMware多个远程代码执行漏洞分析**

摘要：近期，研究人员发现VMware ESXi、Workstation和Fusion存在一个越界写入漏洞，可以使用特制的Shader文件触发。该漏洞可以从VMware Guest虚拟机触发此漏洞，将会影响Vmware宿主机，从而导致主机上的vmware-vmx.exe进程崩溃（拒绝服务），该漏洞编号为CVE-2019-5521。

链接：http://t.cn/AiTD7Ydi

 

**标题：CVE-2018-8120 Windows内核空指针漏洞分析**

摘要：2018年5月微软发布了一次安全补丁，其中有一个是对内核空指针解引用的修复，本文从补丁对比出发，对该内核漏洞进行分析，对应CVE-2018-8120，实验平台是Windows 7 x86 sp1

链接：http://t.cn/AiHNgsed

**漏洞名称：微软远程桌面服务远程代码执行漏洞**  

漏洞简介：

2019年8月13日，MSRC针对于两个严重的远程代码执行漏洞（CVE-2019-1181，CVE-2019-1182）发布了安全修复通告，这一关于远程桌面服务的高危漏洞应引起人们高度重视并及早修复。

据报告，为了利用此漏洞，攻击者需要通过RDP向目标系统远程桌面服务发送精心设计的请求。此漏洞是预身份验证，不需要用户交互。成功利用此漏洞的攻击者可以在目标系统上执行任意代码。然后，攻击者可以安装程序；查看、更改或删除数据；或者创建具有完全用户权限的新帐户。

**漏洞名称：WordPress twitter-cards-meta插件跨站请求伪造漏洞**

漏洞简介：

WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。twitter-cards-meta plugin是使用在其中的一个Twitter账户信息显示插件。  
WordPress twitter-cards-meta插件2.5.0之前版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

影响范围：WordPress twitter-cards-meta plugin <2.5.0

漏洞危害：高危

漏洞ID：CVE-2017-18504

修复建议：

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：  
https://wordpress.org/plugins/twitter-cards-meta/#developers

 

**漏洞名称：Siemens SCALANCE SC-600命令执行漏洞**

漏洞简介：

SCALANCE SC firewall用于保护受信任的工业网络免受不受信任的网络的攻击。它允许以不同的方式过滤输入和输出网络连接。

Siemens SCALANCE SC-600存在命令执行漏洞。攻击者可以利用该漏洞执行任意命令。

影响范围：Siemens SCALANCE SC-600 V2.0

漏洞危害：高危

漏洞ID：CNVD-2019-27706

修复建议：

用户可参考如下供应商提供的安全公告获得补丁信息：   
https://cert-portal.siemens.com/productcert/pdf/ssa-671286.pdf
