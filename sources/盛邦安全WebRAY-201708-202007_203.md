**标题：****医疗设备再爆漏洞，搞不好身体会被黑客控制**  

摘要：GE医疗的两款麻醉机又爆出安全问题。Cyber MDX（一家专注于医疗设备的网络安全公司）的研究人员发现，医院中使用的某些麻醉机固件中的漏洞可能会被滥用，以改变正常功能，直至调整吸入物质的混合水平。该漏洞影响GE Aestiva和GE Aespire麻醉系统，型号7100和7900，来自GE医疗。  

链接：http://t.cn/AiOgcyY9

  

**标题：****新恶意软件利用NSA黑客工具在企业网络中传播**

摘要：Symantec发现了主要针对企业的新加密挖矿恶意软件，这个被称为Beapy的恶意软件利用NSA黑客工具EternalBlue（永恒之蓝）以及被盗和硬编码凭据在网络中迅速传播，以从受感染的计算机中收集凭据、迫使计算机运行挖矿代码来挖出加密数字货币——包括已修复的计算机，而且主要影响中国企业。

链接：http://t.cn/AiORHujE

  

**标题：****影响超过四百万网络摄像头：****Zoom客户端存在0 day漏洞可能导致代码执行**

摘要：近期，Zoom客户端被发现存在两个安全漏洞。其中的一个漏洞允许任何网站在未经用户允许的情况下，强行将用户加入到Zoom呼叫中，并激活其摄像头。另外一个漏洞可以通过多次将用户加入到无效的呼叫中，从而导致拒绝服务（DoS）。除此之外，如果用户曾经安装过Zoom客户端，即使将客户端卸载，计算机上也会保留一个localhost的Web服务器，只需访问特定网页，无需其他任何交互，就可以重新安装Zoom客户端。

链接：http://t.cn/AiWLElBK

  

**标题：****首例发生在巴西的仿冒WannaCry恶意软件**

摘要：巴西首例通过仿冒WannaCry勒索的移动恶意软件，该软件通过仿冒WannaCry勒索界面，向用户索要比特币，其勒索界面与2017年国内发现的“王者荣耀辅助”勒索软件类似。但此次在巴西发现的恶意软件，相比于“王者荣耀辅助”，其UI上做了借鉴，功能上做了升级，经过分析发现其为“AhMyth ”、“WannaCry UI ”、“Banker木马”类软件的结合体。

链接：http://t.cn/AiWvTymI

  

**标题：****免root将手机（Android&IOS）改造成移动渗透神器**

摘要：众所周知，手机版的kali就是Kali NetHunter，但这神器一是要刷机，二是适配的手机非常少，三是即使刷成功了，那你手机上原来的各种软件就不那么好用了。今天跟大家分享一下如何在手机（Android&IOS）上不刷机、免root安装nmap、sqlmap、msf等工具，将手机改造成移动渗透利器。

链接：http://t.cn/AiWLHxSy

  

**标题：****聊聊Go恶意软件的现状和趋势**

摘要：Go有许多吸引人的特性，最大的吸引力之一是可以为所有主要操作系统平台（包括Windows，OSX和Linux）编译单个代码库。这能让攻击者将注意力集中在一个代码库上，而其他编程语言可能需要三个不同的代码存储库。Go，有时也被称为GoLang，由Google于2009年创建，近年来在恶意软件开发群体中越来越受欢迎。

**每周漏洞热点**

  

**漏洞名称：****WordPress Plugin Like Button 1.6.0 – 身份验证旁路漏洞通告**

漏洞简介：WordPress是WordPress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress Plugin Like Button是使用在其中的一个用于在页面上添加按钮的插件。2019年7月8日，研究人员通过oss-security邮件列表披露了WordPress Plugin Like Button 1.6.0版本身份验证旁路漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，wp\_like\_button.php中的contains（）函数未检查当前请求是否由授权用户进行，因此允许任何未经身份验证的用户成功更新设置。

影响范围：WordPress Plugin Like Button 1.6.0

漏洞危害：高危

漏洞ID：CVE-2019-13344

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新。

  

**漏洞名称：Karenderia Multiple Restaurant System 5.3 - SQL注入漏洞通告**  

漏洞简介：Karenderia CMS是一个是一个餐厅点餐和餐厅会员制度。2019年7月8日，研究人员通过oss-security邮件列表披露了Karenderia Multiple Restaurant System 5.3版本SQL注入漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现Karenderia Multiple Restaurant System 5.3版本street-name、category参数存在SQL注入。请求URL：

http://localhost/kmrs/searcharea?st=Los%20Angeles,%20CA,%20United%20States&street-name=1%20+%20((SELECT%201%20FROM%20(SELECT%20SLEEP(25))A))/\*'XOR(((SELECT%201%20FROM%20(SELECT%20SLEEP(25))A)))OR'|"XOR(((SELECT%201%20FROM%20(SELECT%20SLEEP(25))A)))OR"\*/

http://localhost/kmrs/store/cuisine/?category=1%20+%20((SELECT%201%20FROM%20(SELECT%20SLEEP(25))A))/\*'XOR(((SELECT%201%20FROM%20(SELECT%20SLEEP(25))A)))OR'|"XOR(((SELECT%201%20FROM%20(SELECT%20SLEEP(25))A)))OR"\*/&page=2

影响范围：Karenderia Multiple Restaurant System 5.3

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新。

  

**漏洞名称：Redis 未授权访问漏洞通告**  

漏洞简介：Redis 是一个开源的使用ANSI C 语言编写、支持网络、可基于内存亦可持久化的日志型、Key-Value 数据库，并提供多种语言的 API。2019 年 7 月 9 日，Redis 被爆出存在新型未授权访问漏洞，经WebRAY 安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，在 Reids 4.x 及以上版本中新增了模块功能，攻击者可通过外部拓展，在两个 Redis 实例设置主从模式的时候，Redis 的主机实例可以通过FULLRESYNC 同步文件到从机上。然后在从机上加载 so 文件，我们就可以执行拓展的新命令了。

影响范围：Redis 2.x，3.x，4.x，5.x

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、禁止外部访问Redis 服务端口；

2、禁止使用 root 权限启动 Redis 服务；

3、配置安全组，限制可连接 Redis 服务器的 IP。
