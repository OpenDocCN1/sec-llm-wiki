**盛邦安全入选IDC“中国网络安全风险态势感知系统”创新者**

  

近日，全球知名咨询顾问服务商IDC发布《IDC创新者: 中国网络安全风险态势感知系统，2018》报告。报告除了对于中国网络安全风险态势感知系统的发展进行了分析，还评选出了五家公司作为该方向的创新者。其中，盛邦安全（WebRAY）凭借其因地制宜、具有业务强关联性、以解决实际问题为核心的态势感知产品与解决方案，成功入选为创新者之一。

**盛邦安全发布《银行业金融机构信息科技风险管理平台产品白皮书》**

  

近日，盛邦安全发布了《银行业金融机构信息科技风险管理平台产品（RayCOM）技术白皮书》，详细分析了当前银行业金融机构信息科技风险管理的背景和面临的挑战，提出了盛邦安全的解决方案，阐述了RayCOM平台的基本架构、创新技术和业务功能等。目前盛邦安全信息科技风险管理平台（RayCOM）已经成功落地于行业具有代表性的金融机构客户，并取得了良好的效果。

**盛邦安全2019年高校信息化技术研讨会（南昌站）圆满结束**

  

4月3日，由盛邦安全主办的“2019年高校信息化技术研讨会（南昌站）”在南昌喜来登酒店举行。研讨会吸引了来自南昌大学、江西财经大学、东华理工大学、华东交通大学、江西师范大学等多个高校及合作伙伴到现场参会。盛邦安全副总裁、教育事业部总经理任高峰现场发表了题为“高校资产安全治理那些事---资产安全治理建设的必要性”的主题演讲，获得了现场嘉宾的高度关注。

**盛邦安全入选《中国网络安全行业分类及全景图》三大分类六个细分领域**

  

近日，知名自媒体平台“数说安全”发布了最新的《中国网络安全行业分类及全景图2019H1》，盛邦安全在网络安全、应用安全、安全管理三个一级分类中入选了六大细分领域，分别是：入侵检测与防御、抗拒绝服务攻击（设备）、Web应用防火墙、Web应用安全扫描及监控、脆弱性评估与管理、网络安全资产管理。

**漏洞预警**

![](../Images/56d906bc2e550a4a7208ff12ef66fd60.png)

**Apache HTTP 2.4服务器存在权限提升等多个漏洞**

  

近期，WebRAY安全研究中心在针对不同客户的Web应用进行安全监测时，发现Apache HTTP Server更新了多个安全漏洞公告，该公告表示Apache HTTP Server 2.4版本存在包括权限提升在内的多个漏洞，大量用户受到该类漏洞的影响。

  

[**阅读详情**](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650260757&idx=1&sn=6d9c59662010be79aefbf2d13c1c1059&scene=21#wechat_redirect)

  

**关于某挖矿木马的通告预警**

  

近期，较多用户内网计算机系统遭遇挖矿木马，内部计算机系统感染较多，对正常办公及业务运行产生了严重影响。盛邦安全建议各单位对单位内网进行安全自查工作并加强防范。

**新版《政府网站与政务新媒体检查指标》出台**

  

4月18日，国务院办公厅秘书局发布关于印发政府网站与政务新媒体检查指标、监管工作年度考核指标的通知，发布了最新《政府网站与政务新媒体检查指标》和《政府网站与政务新媒体监管工作年度考核指标》，要求各地区、各部门要进一步加强和完善政府网站及政务新媒体日常管理和常态化监管工作。
