标题：微软升级病毒库导致Windows 7/8.1端Defender无法正常工作

摘要：根据多家外媒报道，在安装微软本周早些时候发布的病毒库之后，Windows 7/8.1端的Security Essentials和Windows Defender无法正常工作。从初步掌握的情况来看，部分用户升级病毒库至v1.289.1521.0之后导致实时保护功能处于关闭状态，而且诸多安全应用发出警告称病毒库已经过期。

标题：疑似MuddyWater APT组织针对伊拉克运营商的攻击活动分析

标题：高龄病毒“熊猫烧香”还没退休？

摘要：近日，深信服安全团队收到客户反馈，其内网多台主机中的文件感染了病毒，影响正常业务。经分析，该病毒为“熊猫烧香”病毒变种，虽然该病毒已有十余年历史，但由于其具有很强的感染及传播性，依然很容易在缺少防护的企业内网中传播开来。

每周漏洞热点

漏洞名称：Zeeways Jobsite CMS - SQL注入漏洞

漏洞简介：近日，安全研究人员发现互联网存在Zeeways Jobsite CMS版本漏洞公告，该公告表示Zeeways Jobsite CMS版本存在SQL注入漏洞。

Jobsite CMS是一个用PHP和MySql开发的软件，对于那些想要运营专业招聘网站或任何此类主要工作门户网站的人来说，它是一个完整的工作门户网站。2019年3月25日，研究人员通过oss-security邮件列表披露了Zeeways Jobsite CMS版本拒绝服务漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现Zeeways Jobsite CMS版本id参数存在SQL注入。请求URL：http://localhost/[PATH]/news_details.php?id=1（GET）payload：id=-5236" OR 1 GROUP BY CONCAT(0x716a627871,(SELECT (CASE WHEN (5640=5640) THEN 1 ELSE 0 END)),0x71626b6271,FLOOR(RAND(0)*2)) HAVING MIN(0)#。

影响范围：Zeeways Jobsite CMS

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新。

漏洞简介：近日，安全研究人员发现互联网存在Zeeways Matrimony CMS版本漏洞公告，该公告表示Zeeways Matrimony CMS版本存在SQL注入漏洞。

经过分析，发现Zeeways Matrimony CMS版本up_cast、s_mother、s_religion等参数存在SQL注入。请求URL：http://localhost/[PATH]/profile_list（POST）payload（up_cast）：(select 1 and row(1,1)>(select count(*),concat(concat(CHAR(52),CHAR(67),CHAR(117),CHAR(117),CHAR(82),CHAR(120),CHAR(106),CHAR(69),CHAR(48),CHAR(117),CHAR(107)),floor(rand()*2))x from (select 1 union select 2)a group by x limit 1))。

影响范围：Zeeways Matrimony CMS

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新

 

漏洞名称：Titan FTP Server Version 2019 Build 3505 – 目录遍历/本地文件包含漏洞

漏洞简介：近日，安全研究人员发现互联网存在Titan FTP Server Version 2019 Build 3505版本漏洞公告，该公告表示Titan FTP Server Version 2019 Build 3505版本存在目录遍历/本地文件包含漏洞。

Titan FTP Server是一款企业级别的服务器软件产品，可以用于存储和共享文件。2019年3月26日，研究人员通过oss-security邮件列表披露了Titan FTP Server Version 2019 Build 3505版本目录遍历/本地文件包含漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，Titan FTP Server Version 2019 Build 3505版本存在目录遍历/本地文件包含漏洞。有效载荷为：GET /PreviewHandler.ashx?path=\..\..\..\..\Python27\README.txt&filename=README.txt。

影响范围：Titan FTP Server Version 2019 Build 3505

漏洞危害：高危

漏洞ID：CVE-2019-10009

修复建议：

1、关注官方网站，及时更新至Titan FTP Server 2019 Build 3515版本。

2、尽量不使用动态包含文件，如果可以静态的去包含最好。

3、对用户的输入进行验证，特别是路径替代字符“../”。

4、合理配置web服务器的目录权限。

5、尽可能采用白名单的形式，验证所有输入。
