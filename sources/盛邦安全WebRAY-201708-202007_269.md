**每周新闻热点**

**标题：微软升级病毒库导致Windows 7/8.1端Defender无法正常工作**

摘要：根据多家外媒报道，在安装微软本周早些时候发布的病毒库之后，Windows 7/8.1端的Security Essentials和Windows Defender无法正常工作。从初步掌握的情况来看，部分用户升级病毒库至v1.289.1521.0之后导致实时保护功能处于关闭状态，而且诸多安全应用发出警告称病毒库已经过期。

链接：http://t.cn/Ex0NDHW

 

**标题：国际黑产组织针对部分东亚国家金融从业者攻击活动的报告**

摘要：安天CERT（安天安全研究与应急处理中心）发现2019年2月13日至3月7日期间发生数起大规模有组织的针对部分东亚国家（主要为日本和韩国）的钓鱼邮件攻击行为，事件涉及的样本数量较多，邮件正文和攻击文档内容分为日语和韩语版本，攻击目的是投放远控木马养殖僵尸网络以获利。

链接：http://t.cn/ExsZEit

 

**标题：一个新的门罗币挖矿恶意软件变种分析**

摘要：最近，Sand Blast Agent Forensics团队注意到，有一类新的门罗币挖矿恶意软件变种在全球各地传播。其特殊之处在于，在感染和传播技术上它与当前流行的一些木马或勒索软件有许多类似的地方——能利用合法的IT管理工具，Windows系统工具和已披露的Windows漏洞来实施攻击。

链接：http://t.cn/EJUef0A

 

**标题：新Mirai Variant瞄准企业无线演示和显示系统**

摘要：Unit 42发现Mirai的新版本添加了针对企业的新漏洞利用，表明僵尸网络正在扩大其攻击面，可为DDos攻击提供更强大的火力。

链接：http://t.cn/EJafhfx

 

**标题：Cardinal RAT攻击以色列金融科技公司**

摘要：2017年Unit 42研究人员发现了一个恶意软件家族Cardinal RAT。该恶意软件家族在过去2年间销声匿迹，通过Carp下载器进行传播。研究人员近日发现主要攻击以色列金融科技公司的攻击活动，进一步分析发现了Cardinal RAT和EVILNUM之间的关系。EVILNUM是一个基于JS的恶意软件家族，用来攻击类似的组织。

链接：http://t.cn/EJO5pfU

 

**标题：疑似MuddyWater APT组织针对伊拉克运营商的攻击活动分析**

摘要：近期， 360 威胁情报中心截获到一个针对伊拉克移动运营商 （ Korek Telecom）的定向攻击样本。该运营商是伊拉克发展最快的移动公司，服务于伊拉克的 18 个省份，为企业、政府和个人用户提供服务。攻击样本使用鱼叉式钓鱼邮件进行投递：诱导受害者打开附件 Office Word 文档，并启用恶意宏。恶意宏代码最终会释放执行 PowerShell 后门，从而实现对受害者计算机的远程控制。 360 威胁情报中心经过溯源和关联后发现，该攻击活动疑似与 MuddyWater APT组织相关，并溯源和分析了多个与之相关的恶意样本。

链接：http://t.cn/EJO4jXS

 

**标题：高龄病毒“熊猫烧香”还没退休？**

摘要：近日，深信服安全团队收到客户反馈，其内网多台主机中的文件感染了病毒，影响正常业务。经分析，该病毒为“熊猫烧香”病毒变种，虽然该病毒已有十余年历史，但由于其具有很强的感染及传播性，依然很容易在缺少防护的企业内网中传播开来。

链接：http://t.cn/EJacTAt

  

**每周漏洞热点**

**漏洞名称：Zeeways Jobsite CMS - SQL注入漏洞**

漏洞简介：近日，安全研究人员发现互联网存在Zeeways Jobsite CMS版本漏洞公告，该公告表示Zeeways Jobsite CMS版本存在SQL注入漏洞。

Jobsite CMS是一个用PHP和MySql开发的软件，对于那些想要运营专业招聘网站或任何此类主要工作门户网站的人来说，它是一个完整的工作门户网站。2019年3月25日，研究人员通过oss-security邮件列表披露了Zeeways Jobsite CMS版本拒绝服务漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现Zeeways Jobsite CMS版本id参数存在SQL注入。请求URL：http://localhost/\[PATH\]/news\_details.php?id=1（GET）payload：id=-5236" OR 1 GROUP BY CONCAT(0x716a627871,(SELECT (CASE WHEN (5640=5640) THEN 1 ELSE 0 END)),0x71626b6271,FLOOR(RAND(0)\*2)) HAVING MIN(0)#。

影响范围：Zeeways Jobsite CMS

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新。

 

**漏洞名称：Zeeways Matrimony CMS - SQL注入漏洞**

漏洞简介：近日，安全研究人员发现互联网存在Zeeways Matrimony CMS版本漏洞公告，该公告表示Zeeways Matrimony CMS版本存在SQL注入漏洞。

Matrimony CMS是一个用PHP和MySql开发的软件，适合那些想要经营专业比赛而制作网站的人。2019年3月25日，研究人员通过oss-security邮件列表披露了Zeeways Matrimony CMS版本拒绝服务漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现Zeeways Matrimony CMS版本up\_cast、s\_mother、s\_religion等参数存在SQL注入。请求URL：http://localhost/\[PATH\]/profile\_list（POST）payload（up\_cast）：(select 1 and row(1,1)>(select count(\*),concat(concat(CHAR(52),CHAR(67),CHAR(117),CHAR(117),CHAR(82),CHAR(120),CHAR(106),CHAR(69),CHAR(48),CHAR(117),CHAR(107)),floor(rand()\*2))x from (select 1 union select 2)a group by x limit 1))。

影响范围：Zeeways Matrimony CMS

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新

 

**漏洞名称：Titan FTP Server Version 2019 Build 3505 – 目录遍历/本地文件包含****漏洞**

漏洞简介：近日，安全研究人员发现互联网存在Titan FTP Server Version 2019 Build 3505版本漏洞公告，该公告表示Titan FTP Server Version 2019 Build 3505版本存在目录遍历/本地文件包含漏洞。

Titan FTP Server是一款企业级别的服务器软件产品，可以用于存储和共享文件。2019年3月26日，研究人员通过oss-security邮件列表披露了Titan FTP Server Version 2019 Build 3505版本目录遍历/本地文件包含漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，Titan FTP Server Version 2019 Build 3505版本存在目录遍历/本地文件包含漏洞。有效载荷为：GET /PreviewHandler.ashx?path=\\..\\..\\..\\..\\Python27\\README.txt&filename=README.txt。

影响范围：Titan FTP Server Version 2019 Build 3505

漏洞危害：高危

漏洞ID：CVE-2019-10009

修复建议：

1、关注官方网站，及时更新至Titan FTP Server 2019 Build 3515版本。

2、尽量不使用动态包含文件，如果可以静态的去包含最好。

3、对用户的输入进行验证，特别是路径替代字符“../”。

4、合理配置web服务器的目录权限。

5、尽可能采用白名单的形式，验证所有输入。
