每周新闻热点

标题：Citrix收到FBI警告：6TB至10TB敏感数据被窃

摘要：软件制造商Citrix近日承认公司已经沦为数据泄露的新受害者，导致国际黑客窃取了大量的数据。公司表示美国联邦调查局（FBI）已经就此事和公司取得联系，并警告称本次网络攻击行为极有可能是伊朗黑客组织所为，窃取了6TB至10TB的商业文件。。

链接：http://t.cn/EMJ8P8P

 

标题：政府网站遭勒索病毒攻击 要求支付数字货币

摘要：新浪科技讯 3月13日下午消息，宜昌市夷陵区人民政府官网发布勒索病毒预警通报，称自3月11日起，境外某黑客组织对我国有关政府部门开展勒索病毒邮件攻击，对用户主机硬盘数据全盘加密，并要求受害用户缴纳数字货币赎金。

链接：http://t.cn/EMj10BO

 

标题：攻击巴西和台湾地区的无文件银行木马

摘要：研究人员近日分析了一个含有多个.bat附件的无文件恶意软件，可以下载含有银行木马payload的powershell，并安装黑客工具和信息窃取器。研究人员分析发现，恶意软件会窃取机器信息和用户凭证、扫描与特定巴西银行相关的字符串和其他与保存的outlook联系人相关的网络链接、安装黑客工具RADMIN。统计数据表明受感染最严重的区域有巴西和中国台湾。

链接：http://t.cn/EM5Okns

 

标题：“匿影”挖矿病毒：借助公共网盘和图床隐匿自身

摘要：毒霸安全团队通过“捕风”系统监测到一款在内网中传播的挖矿病毒，该病毒打包了方程式攻击工具包，在内网中利用永恒之蓝（Eternalblue）和双脉冲星（DoublePulsar）进行横向传播，被感染的电脑首先会解析特定URL上的内容，然后进行挖矿（门罗币、BEAM币）、对抗杀软等操作，最终组成其僵尸网络中的一员。

链接：http://t.cn/EM5pju1

 

标题：Nitol僵尸网络拓展新业务：疯狂点击广告刷量

摘要：Nitol是一个相对古老的僵尸网络，之前腾讯御见威胁情报中心曾爆出Nitol新增挖矿业务，近期又监测到Nitol又开新业务“广告刷量”，通过后台模拟人工点击广告链接来牟利。病毒刷量的操作频率可用疯狂来形容：每15秒点击一个广告资源，每个广告资源会点击上万次，为避免被用户发现，病毒还会在刷量前屏蔽音频。

链接：http://t.cn/EMiAzCk

 

标题：黑客可以滥用Galaxy S6指纹技术

摘要：安全研究公司FireEye透露，三星Galaxy S6的指纹扫描仪存在缺陷，这意味着黑客可能窃取存储在设备上的个人信息。该公司的研究人员Yulong Zhang和Tao Wei表示，个人数据在到达设备上的安全区域之前可能会被截获，从而使黑客能够窃取它。

链接：http://t.cn/EMjeNEx

 

标题：超微主板曝漏洞 可致裸机云服务被植入后门

摘要：超微（Supermicro）主板上的嵌入式硬件元器件近日被曝出存在漏洞，可能让IBM或其他云服务被植入后门，使攻击者得以窃取企业客户数据、植入恶意程序或发动DDoS阻断服务攻击。

链接：http://t.cn/EfrYqe2


每周漏洞热点

漏洞名称：WordPress Plugin GraceMedia Media Player 1.0 – 本地文件包含漏洞

漏洞简介：近日，安全研究人员发现互联网存在WordPress Plugin GraceMedia Media Player 1.0版本漏洞公告，该公告表示WordPress Plugin GraceMedia Media Player 1.0版本存在本地文件包含漏洞，经检测，大量用户受到该类漏洞的影响。

WordPress是一款个人博客系统，并逐步演化成一款内容管理系统软件，它是使用PHP语言和MySQL数据库开发的。用户可以在支持 PHP 和 MySQL数据库的服务器上使用自己的博客。2019年3月13日，研究人员通过oss-security邮件列表披露了WordPress Plugin GraceMedia Media Player 1.0版本本地文件包含漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，WordPress Plugin GraceMedia Media Player 1.0版本存在本地文件包含漏洞。有效载荷为：GET  /wordpress/wp-content/plugins/gracemedia-media-player/templates/files/ajax_controller.php?ajaxAction=getIds&cfg=../../../../../../../../../../etc/passwd。

影响范围：WordPress Plugin GraceMedia Media Player 1.0

漏洞危害：高危

漏洞ID：CVE-2019-9618

修复建议：

1、关注官方网站，及时更新。

2、尽量不使用动态包含文件，如果可以静态的去包含最好。

3、对于动态包含的文件可以设置一个白名单，如果不属于白名单内的文件名，则不包含。

 

漏洞名称：NetSetMan 4.7.1 - 本地缓冲区溢出（SEH Unicode）漏洞

漏洞简介：近日，安全研究人员发现互联网存在NetSetMan 4.7.1版本的漏洞公告，该公告表示NetSetMan 4.7.1版本存在本地缓冲区溢出漏洞。经检测，大量用户受到该类漏洞的影响。

Netsetman是一个小巧实用的网络设置管理一键IP地址切换工具。2019年3月11日，研究人员通过oss-security邮件列表披露了NetSetMan 4.7.1版本本地缓冲区溢出漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，通过运行Python代码，输出payload1.txt和payload2.txt两个文件，打开NetSetMan，启用"[Double Click!]"选项卡和"SET1"选项卡的"Workgroup"， 将"payload2.txt"的内容粘贴到"SET1"选项卡的"Workgroup"字段中，再将"payload1.txt"的内容粘贴到"[Double Click!]"选项卡的"Workgroup"字段中，点击"Activate"，将会造成本地缓冲区溢出。这是一个unicode SEH溢出，但缓冲区对于unicode编码的反向shell有效载荷而言太小。因此，实现了一个egghunter来定位存储那些在存储器中的由字母数字编码而成的有效载荷

影响范围：NetSetMan 4.7

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.关注官方网站，及时下载补丁更新。

 

漏洞名称：pfSense 2.4.4-p1 (HAProxy Package 0.59_14) - 持久型跨站脚本攻击漏洞

漏洞简介：近日，安全研究人员发现互联网存在pfSense 2.4.4-p1版本漏洞公告，该公告表示pfSense 2.4.4-p1版本存在持久型跨站脚本攻击漏洞，经检测，大量用户受到该类漏洞的影响。

pfSense软件是FreeBSD的免费开源定制发行版，专门用作防火墙和路由器，完全通过Web界面进行管理。2019年3月13日，研究人员通过oss-security邮件列表披露了pfSense 2.4.4-p1版本持久型跨站脚本攻击漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现pfSense 2.4.4-p1版本存在持久型跨站脚本攻击漏洞。漏洞Url：https://192.168.1.1/haproxy/haproxy_listeners_edit.php

Payload："><script>alert("test")</script>

影响范围：pfSense 2.4.4-p1

漏洞危害：高危

漏洞ID：CVE-2019-8953

修复建议：

1.关注官方网站，及时下载补丁更新。

2.在网页代码中需要对用户输入的数据进行严格过滤。
