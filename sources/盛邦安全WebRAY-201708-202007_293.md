**每周新闻热点**

**标题：NoRelationship新型钓鱼攻击能绕过Office文档检测**

摘要：近日，Avanan发现了一种可以绕过EOP (Exchange Online Protection) URL过滤器的新型钓鱼攻击。EOP可以扫描Word (.docx)、Excel (.xlsx)和PowerPoint (.pptx)等办公文档，通过对邮件内容、header、语言、附件和所有超链接进行检测，尽量不会让垃圾邮件进入到你的邮箱中。

链接：http://t.cn/Ef2P07u

 

**标题：Formjacking已超越勒索软件和挖矿攻击，成为2018年的顶级威胁**

摘要：从2018年1月到12月，挖矿攻击活动下降了52%，但供应链攻击的数量整体增长了大约78%。此外，离地攻击是黑客进行攻击的主要手段，使他们在进行复杂攻击时不被察觉。。

链接：http://t.cn/Ef52wuk

 

**标题：Chrome扩展程序存在安全隐患**

摘要：最近一项针对12万个Chrome扩展的调查显示，超过三分之一的谷歌Chrome扩展要求用户允许访问和阅读他们在任何网站上的所有数据。同一项调查还发现，Chrome网上商店列出的12万个Chrome扩展中，大约85%没有列出隐私政策，这意味着没有具有法律约束力的文件来描述扩展开发者承诺如何处理用户数据。

链接：http://t.cn/EfxVq6i

 

**标题：疑似国内某天气APP上传用户所有WiFi账号和网络信息**

摘要：疑似国内某天气APP上传用户所有wifi账号和网络信息，进行足迹和画像、隐私追踪。

链接：http://t.cn/Ef6jPTe

 

**标题：RSA 2019创新沙盒十强：解决安全问题的内核不变**

摘要：每届RSA大会的创新沙盒环节都可谓万众瞩目。创新沙盒的初衷是为网络安全领域的初创企业提供平台，让他们展示自己的创新技术或愿景，以及他们可能为信息安全行业带来的变革与发展。

链接：http://t.cn/Ef0zOxX

 

**标题：新型浏览器攻击：离开网页不影响恶意代码运行**

摘要：希腊学者发明了一种基于浏览器的新型攻击“MarioNet”，该攻击可让黑客从用户浏览器中创建僵尸网络。在用户关闭或被引导离开受感染网页后，黑客依然可以在其浏览器中运行恶意代码。

链接：http://t.cn/EfnzT2O

 

**标题：加拿大警方通过风险数据库跟踪居民的负面行为**

摘要：在几乎没有任何监督的情况下，加拿大警方、社会服务和卫生保健工作者使用一个共享数据库去跟踪弱势群体的行为。这个数据库被称为 Risk-driven Tracking Database，包含了一个人是否使用毒品，是否是攻击受害者，是否生活在“负面社区”等信息。

链接： http://t.cn/EfgAr54

  

**每周漏洞热点**

**漏洞名称：Drupal < 8.6.10 / < 8.5.11 – 远程代码执行漏洞**  

漏洞简介：近日，安全研究人员发现互联网存在Drupal < 8.6.10 / < 8.5.11版本的漏洞公告，该公告表示Drupal < 8.6.10 / < 8.5.11版本存在远程代码执行漏洞。

Drupal是使用PHP语言编写的开源内容管理框架（CMF），它由内容管理系统（CMS）和PHP开发框架（Framework）共同构成。研究人员通过oss-security邮件列表披露了Drupal < 8.6.10 / < 8.5.11版本远程代码执行漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

发现漏洞的触发条件为开启了 RESTful Web Services，且允许 POST / PATCH 请求。根据 Drupal 的配置，此漏洞可能不需要任何权限即可触发。攻击者可以直接在Web服务器上执行任意PHP代码，造成服务器被入侵、用户信息泄露等后果。

影响范围：Drupal < 8.6.10 / < 8.5.11

漏洞危害：高危

漏洞ID：CVE-2019-6340

临时解决方案：

1、禁用RESTful Web Services模块

2、配置服务器不允许POST/PATCH请求

修复建议：

1、Drupal 8.6.x版本升级到8.6.10

更新链接：

https://www.drupal.org/project/drupal/releases/8.6.10

2、Drupal 8.5.x或更早期版本版本升级到8.5.11版本

更新链接：

https://www.drupal.org/project/drupal/releases/8.5.11

3、Drupal 7暂无更新。

 

**漏洞名称： XAMPP 5.6.8–SQL注入/跨站脚本攻击漏洞**

漏洞简介：近日，安全研究人员发现互联网存在XAMPP 5.6.8版本漏洞公告，该公告表示XAMPP 5.6.8版本存在SQL注入和跨站脚本攻击漏洞。

XAMPP（Apache+MySQL+PHP+PERL）是一个功能强大的建站集成软件包。2019年2月19日，研究人员通过oss-security邮件列表披露了XAMPP 5.6.8版本SQL注入和跨站脚本攻击漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现XAMPP 5.6.8版本存在SQL注入和跨站脚本攻击漏洞，有效载荷1：http://localhost/xampp/cds-fpdf.php?interpret=SQLi&titel=SQLi&jahr=1984%20%20AND%20sleep%285%29；有效载荷2：http://localhost/xampp/cds.php?interpret=XSS&titel=<script>alert("XSS")</script>&jahr=1984。

影响范围：XAMPP 5.6.8及之前版本

漏洞危害：高危

漏洞ID：CVE-2019-8923

CVE-2019-8924

修复建议：

官方已发布最新版本，请及时下载更新。

下载链接：

https://sourceforge.net/projects/xampp/files/XAMPP%20Windows/1.8.2/

https://sourceforge.net/projects/xampp/files/XAMPP%20Windows/5.5.19/

 

**漏洞名称：WordPress插件WooCommerce – GloBee (cryptocurrency) Payment Gateway 1.1.1- 付款绕过/未经授权的订单状态欺骗漏洞**

漏洞简介：近日，安全研究人员发现互联网存在WordPress插件WooCommerce – GloBee (cryptocurrency) Payment Gateway 1.1.1版本的漏洞公告，该公告表示WordPress插件WooCommerce – GloBee (cryptocurrency) Payment Gateway 1.1.1版本存在付款绕过/未经授权的订单状态欺骗漏洞。

WooCommerce 是 WordPress 的一个商城插件，拥有基本的商品目录，产品列表，购物车，支付功能，会员功能，优惠券功能，库存管理功能，销售记录功能等。2019年2月18日，研究人员通过oss-security邮件列表披露了WordPress插件WooCommerce – GloBee (cryptocurrency) Payment Gateway 1.1.1版本付款绕过/未经授权的订单状态欺骗漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，发现由于WooCommerce依赖于不受信任的输入（CWE-807），数据验证不足以及IPN回调无任何加密身份验证，使得远程(甚至未经授权)攻击者可以绕过支付流程和欺骗真实订单状态，而无需实际支付。

影响范围：WordPress插件WooCommerce – GloBee (cryptocurrency) Payment Gateway <= 1.1.1

漏洞危害：高危

漏洞ID：CVE-2018-20782

修复建议：

官方已发布最新版本，请及时下载更新

下载链接：

https://wordpress.org/plugins/woocommerce/#installation。
