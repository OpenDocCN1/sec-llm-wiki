 盛邦安全威胁预警周报 

2019年 总第43期

  

**每周新闻热点**

**标题：某人脸识别公司数据泄露 超250万人数据可被获取**

摘要：根据微博安全应急响应中心消息，国内某人脸识别公司发生大规模数据泄露事件。超过250万人的数据可被获取，680万条记录泄露，其中包括身份证信息，人脸识别图像及捕捉地点等。

链接：http://t.cn/EV2nfLc

 

**标题：Trickbot木马又开始造作了，VNC、RDP等远程工具凭证都是它的目标**

摘要：在2018年11月份，趋势科技发现了一个带有密码抓取模块的Trickbot木马变种，它可以从大量的应用程序中窃取凭证。在今年1月份，趋势科技继续观察到了Trickbot的多个变种（如TrojanSpy.Win32.TRICKBOT.AZ和Trojan.Win32.MERETAM.AD），它们或多或少都具备一些新的能力。

链接：http://t.cn/EV55O3v

 

**标题：中国小伙用积分买游戏机在日被捕 全是黑客盗的**

摘要：近日日本警视厅以“使用网络黑客偷窃而来的航空里程换取的积分”为名，逮捕了一名25岁的中国籍男子尹某。尹某在2018年的时候使用消费积分，在东京都福生市的一家连锁电器店里，购买了总计12万日元的平板电脑和游戏机。然而他使用的积分其实是黑客非法盗取来的。

链接：http://t.cn/EVaRHVd

 

**标题：网络黑客被公诉并获刑**

摘要：近日，重庆市忠县人民法院对忠县人民检察院依法提起公诉的32名被告人侵犯公民个人信息罪、非法侵入计算机信息系统罪一案作出有罪判决，32名被告人分别被判处有期徒刑五年六个月至有期徒刑一年缓刑一年，并处罚金。

链接：http://t.cn/EVOxlHx

 

**标题：WordPress插件WP Cost Estimation因漏洞被恶意利用**

摘要：过去几个月，商业WordPress插件WP Cost Estimation一直受到黑客的攻击。黑客们利用这些插件中的旧漏洞闯入网站并植入后门。这些持续的攻击首先被Defiant发现，他是Wordfence防火墙插件的幕后工作者。

链接：http://t.cn/EV8fi9n

 

**标题：只需要不到20分钟，报告显示俄罗斯黑客是全球最快的入侵者**

摘要：天下武功，唯快不破。速度，在众多武侠剧中都被刻画成武学精髓之一。而在网络安全领域，无论作为防御者还是攻击者，速度很大程度上也能够决定攻防一方的胜负。2019年2月19日，美国网络安全技术公司 CrowdStrike 发布了《2019年全球网络安全威胁报告》，其中重点提到了一个关键概念——突破时间（Breakout Time），是指入侵者发起攻击到成功获得系统权限的时间。

链接：http://t.cn/EV3o6NT

 

**标题：WinRAR 被曝存在遗留19年的漏洞，影响全球多达5亿用户**

摘要：WinRAR 可能是目前全球用户最多的解压缩软件了，号称拥有5亿用户，在绝大多数装机必备软件清单中几乎都能看到它的存在。近期，WinRAR被发现存在严重的代码执行漏洞，并且已经存在了长达19年的时间。

链接：http://t.cn/EVeqSMm

  

**每周漏洞热点**

**漏洞名称： FTPShell Server 6.83 – 拒绝服务漏洞**  

漏洞简介：近日，安全研究人员发现互联网存在FTPShell Server 6.83版本的漏洞公告，该公告表示FTPShell Server 6.83版本存在拒绝服务漏洞。

FTPShell server是一款功能全面、安全可靠的FTP 客户端工具。2019年2月20日，研究人员通过oss-security邮件列表披露了FTPShell Server 6.83版本拒绝服务漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，运行python脚本，通过“\\ x41”\* 417，将417个A写入ftpshell.txt文件，打开FTPShell Server，依次选择"Manage FTP Accounts" 、"Add Account Name"，复制“ftpshell.txt”中的内容，在名为“Account name to ban”的字段中粘贴，点击“Ok”，您将会看到程序发生崩溃。

影响范围：FTPShell Server 6.83

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、关注官方网站，及时更新。

2、采用高性能的网络设备。

3、升级主机服务器硬件。

 

**漏洞名称：BulletProof FTP Server 2019.0.0.50 – 拒绝服务漏洞**

漏洞简介：近日，安全研究人员发现互联网存在BulletProof FTP Server 2019.0.0.50版本的漏洞公告，该公告表示BulletProof FTP Server 2019.0.0.50版本存在拒绝服务漏洞。

BulletProofFTPServer一个FTP Server 服务器软件。2019年2月19日，研究人员通过oss-security邮件列表披露了BulletProof FTP Server 2019.0.0.50版本拒绝服务漏洞的详情，经WebRAY安全研究中心研判，该漏洞可能影响广大云服务厂商，危害严重。

经过分析，运行python脚本，通过“\\ x41”\* 257，将257个A写入bullet.txt文件，打开BulletProofFTPServer，依次选择"Settings" 、"SMTP"，在"Email Server"中选择"SMTP Server"，复制“bullet.txt”中的内容，粘贴到此处，点击“Test”，您将会看到程序发生崩溃。

影响范围：BulletProof FTP Server 2019.0.0.50

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、关注官方网站，及时更新。

2、采用高性能的网络设备。

3、升级主机服务器硬件

 

**漏洞名称：Apache CouchDB 2.3.0–跨站脚本攻击漏洞**

漏洞简介：近日，安全研究人员发现互联网存在Apache CouchDB 2.3.0版本漏洞公告，该公告表示Apache CouchDB 2.3.0版本存在跨站脚本攻击漏洞。经过分析，发现Apache CouchDB 2.3.0版本多处存在跨站脚本攻击漏洞，有效载荷：http://127.0.0.1:5984/\_node/couchdb@localhost/\_config/1/%3Cimg%20src%3Dx%20onerror%3Dalert(2)%3E

影响范围：Apache CouchDB 2.3.0

漏洞危害：高危

漏洞ID：CNVD-2019-00018

修复建议：

1.关注官方网站，及时下载补丁更新。

2.在网页代码中需要对用户输入的数据进行严格过滤。
