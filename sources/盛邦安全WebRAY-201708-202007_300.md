 盛邦安全威胁预警周报 

2019年 总第41期

  

**每周新闻热点**

**标题：PHP PEAR网站遭黑客入侵，官方软件安装包被篡改**

摘要：上周，PEAR的维护人员发现有人用核心PEAR文件系统中的修改版本替换了原来的PHP PEAR包管理器(go-pear.phar)，于是他们关闭了PEAR的官方网站(PEAR-PHP.net)。尽管PEAR开发人员仍在分析恶意包，但根据他们2019年1月19日发布的一份安全声明，因被黑客入侵，网站被恶意代码感染的安装文件至少已存在半年。

链接：http://t.cn/E5sQNUY

 

**标题：2018年Windows漏洞年度盘点**

摘要：2018年在轰动式的“幽灵”、“熔断”两大CPU漏洞中揭开序幕。“震网3漏洞利用挖矿”、“412挂马风暴”等安全事件发生表明，漏洞利用攻击，不再是APT组织的“专属”，漏洞利用正往“低成本化”趋势发展。过去一年，Windows、Office、IE、Flash等高危漏洞频繁被曝光，而各种野外漏洞利用更是攻击层出不穷，更给个人和企业的网络安全带来了严峻的威胁。本报告主要重点分析2018年Windows平台的漏洞攻击态势，并给个人和企业合理化的漏洞防护建议。

链接：http://t.cn/E5FzC4r

 

**标题：Google Chrome 增加拦截恶意下载的支持**

摘要：谷歌正在增加对拦截网站 iframe 的自动下载的支持。这是攻击者在有或没有用户允许的情况下，在易受攻击的机器上实现恶意软件下载的首选技术之一。点击式（Drive-by）下载是指浏览器在没有用户允许的情况下载文件，这种方式可以通过恶意广告、iframe的后台或攻击者在网站上植入的恶意脚本完成，所以用户基本感觉不到。

链接：http://t.cn/Et2287S

 

**标题：微博：2018年处置153.88亿条违法违规信息，平均3万条/分钟**

摘要：日前，微博发布的社区治理报告显示，2018年微博共处置各类违法违规信息共计153.88亿条，相当于每天处理4000多万条，每分钟处理近3万条。具体来看，其中买卖粉丝、恶意导流卖片等垃圾营销信息147亿条，占总量的95.53%，此类信息数量较多的主要原因是近年来倒卖粉丝、盗取账号等非法的互联网黑产逐渐增多。

链接：http://t.cn/Et2LP1U

 

**标题：俄语垃圾邮件推送Redaman银行恶意软件**

摘要：Redaman于2015年首次被发现，它是针对使用俄罗斯金融机构进行交易的客户的恶意软件。最初它被报告为RTM银行木马，2017年Symantec 和Microsoft 等厂商将该恶意软件的更新版本描述为Redaman。2018年的最后四个月，我们发现了多个俄语版本Redaman的大规模分发活动。

链接：http://t.cn/EtIsIxl

 

**标题：2018年信息安全相关大事件（国际篇）**

摘要：纵观 2018年网络安全事件，网络犯罪分子攻击手段变幻莫测，除了零日漏洞的利用外，勒索软件、恶意挖矿大行其道，区块链领域险象环生，暗网数据泄露更是层出不穷，而且攻击渠道日益变幻，IoT 设备、工业网亦成为不法黑客的攻击重点，以上这些皆都为整个网络空间安全环境带来全新挑战。

链接：http://t.cn/EtSqeXi

  

**每周漏洞热点**

**漏洞名称： Cisco Firepower Management Center 6.2.2.2 / 6.2.3–跨站脚本攻击漏洞**  

漏洞简介：近日，安全研究人员发现互联网存在Cisco Firepower Management Center 6.2.2.2 / 6.2.3版本漏洞公告，该公告表示Cisco Firepower Management Center 6.2.2.2 / 6.2.3版本存在跨站脚本攻击漏洞。经过分析，发现攻击者登录Cisco Firepower管理中心（FMC），进入Systems、Configuration menu处，可以在参数type处插入payload来实施跨站脚本攻击。有效载荷：https：// <ip address> /platinum/platformSettingEdit.cgi?type =>“> <script> alert（”XXS“）</ script>＆。

影响范围：Cisco Firepower Management Center 6.2.2.2 / 6.2.3

漏洞危害：高危

漏洞ID：CVE-2019-1642

修复建议：

1.官网已发布最新版本，请及时下载更新。

2.在网页代码中需要对用户输入的数据进行严格过滤。

 

**漏洞名称：WordPress Plugin Ad Manager WD 1.0.11–任意文件下载漏洞**

漏洞简介：近日，安全研究人员发现互联网存在WordPress Plugin Ad Manager WD 1.0.11版本漏洞公告，该公告表示WordPress Plugin Ad Manager WD 1.0.11版本存在任意文件下载漏洞。经过分析，发现WordPress Plugin Ad Manager WD 1.0.11版本存在任意文件下载漏洞，攻击者可以添加回溯符或猜测路径下载任意文件。例如：http://localhost/wordpress/wp-admin/edit.php?post\_type=wd\_ads\_ads&export=export\_csv&path=../wp-config.php。

影响范围：WordPress Plugin ad manager wd v1.0.11

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、请关注官方网站，及时进行补丁更新。

2、过滤.(点)，使用户在url中不能回溯上级目录。

3、正则严格判断用户输入参数的格式。

 

**漏洞名称：phpTransformer 2016.9 - SQL注入漏洞**

漏洞简介：近日，安全研究人员发现互联网存在phpTransformer 2016.9版本漏洞公告，该公告表示phpTransformer 2016.9版本存在SQL注入漏洞。经过分析，发现phpTransformer 2016.9版本idnews参数存在SQL注入。有效载荷：http://localhost/\[PATH\]/Programs/news/GeneratePDF.php?Lang=English&idnews=20190000000%27%20%41%4e%44%20%53%4c%45%45%50%28%35%29%2d%2d%20%2d。

影响范围：phpTransformer 2016.9

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、在网页代码中需要对用户输入的数据进行严格过滤。

2、关注官方网站，及时下载补丁更新。
