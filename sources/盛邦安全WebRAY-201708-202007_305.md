 盛邦安全威胁预警周报 

2019年 总第39期

  

**每周新闻热点**

**标题：广告恶意软件伪装成游戏、远程控制 APP 感染 900 万 Google play 用户**

摘要：研究人员在 Google play 中发现 85 个活跃的广告恶意软件家族，伪装成游戏、TV 和远 程控制模拟器 APP，感染了超 900 万 Google play 用户。

链接：http://t.cn/EqaDk1P

 

**标题：美国宇航局 NASA 内部软件暴露了员工和项目信息**

摘要：安全研究员 Avinash Jain 于上周五（1 月 11 日）发文称，美国国家航空航天局（National Aeronautics and Space Administration，NASA）内部使用的一款 Web 应用程序因为存在人 为配置错误无意间暴露了员工用户名、姓名、电子邮箱地址和项目名称等详细信息。

链接：http://t.cn/EqNRPzD

 

**标题：Systemd 曝出三个漏洞绝大部分 Linux 发行版易受攻击**

摘要：Linux 系统与服务管理工具 Systemd 被曝存在 3 大漏洞，影响几乎所有 Linux 发行 版。Systemd 是 Linux 系统的基本构建块，它提供了对系统和服务的管理功能，以 PID 1 运 行并启动系统的其它部分。目前大部分 Linux 发行版都以 Systemd 取代了原有的 System V。

链接：http://t.cn/EqYXmK2

 

**标题：美国官方机构再度开启医疗网络安全保卫战**

摘要：美国医疗行业是行业黑客的金矿。对那些实施攻击的人来说，“征用”医疗系统已经成 为一项稳定而有利可图的工作。虽然数年来遭遇多起数据泄露事件，但行业内的回应力度仍然 不足，不少人甚至毫无危机意识。

链接：http://t.cn/Eq33kgq

 

**标题：倒计时开始！微软将在 2020 年 1 月终止对 Windows 7 的支持**

摘要：对于那些仍然坚持使用 Windows 7 操作系统的人来说，这可能是一个比较重要的提醒——在微软终止对已面世 9 年的 Windows 7 操作系统的支持之前，你还有不到一年的时间。 

链接：http://t.cn/EqsPoYj

  
**标题：美国德尔里奥市遭遇勒索软件攻击，政府工作人员重回纸笔办公**

摘要：据外媒报道，位于美国德克萨斯州的德尔里奥市在上周遭遇了一起黑客攻击，该市市政 厅的服务器因感染勒索软件被迫离线，进而导致电子政务平台停止运行、市政厅工作人员不得不重新使用纸和笔来进行办公。

链接：http://t.cn/Eq31Ao5

 

**标题：人脸识别解锁能用照片绕过？华为、三星、小米、HTC 等均上榜**

摘要：荷兰消费者协会（Consumentenbond）于近日通过一篇题为《Gezichtsherkenning op smartphone niet altijd veilig（智能手机上的人脸识别并不总是安全）》的文章指出，正在 被越来越多智能手机采用的人脸识别解锁功能似乎并没有我们想象的那么安全。

链接：http://t.cn/EqshXXC

  

**每周漏洞热点**

**漏洞名称：doorGets CMS 7.0–任意文件下载漏洞**

漏洞简介：近日，安全研究人员发现存在 doorGets CMS 7.0 版本漏洞公告，该公告表示 doorGets CMS 7.0 版本存在任意文件下载漏洞。经过分析，发现 f 参数可控，并未对用户输入的数据做 过滤，导致可以添加回溯符或猜测路径下载任意文件。

例如： http://localhost/\[PATH\]/fileman/php/download.php? f=%2FExploitDb%2FdoorGets\_CMS\_V7.0%2Ffileman%2FUploads%2F%2e%2e%2f%2e%2e%2f%2e%2e%2f%2e%2e%2f%2e%2e%2f%2e%2e%2fWindows/win.ini。

影响范围：doorGets CMS 7.0

漏洞危害：高危 

漏洞 ID：暂无 

修复建议：

1、请关注官方网站，及时进行补丁更新。

2、过滤.(点)，使用户在 URL 中不能回溯上级目录。

3、正则严格判断用户输入参数的格式。

  
**漏洞名称：ownDMS 4.7 - SQL 注入漏洞**

漏洞简介：近日，安全研究人员发现存在 ownDMS 4.7 版本漏洞公告，该公告表示 ownDMS 4.7 版本存在 SQL 注入漏洞。经过分析，发现 ownDMS 4.7 版本 IMG 参数存在 SQL 注入。有效载荷：

http://localhost/\[PATH\]/includes/pdfstream.php?IMG=%27%20%55%4e%49%4f%4e%20%53%45%4c%45%43%54%20%31%2c%32%2c%33%2c%34%2c%35,0x48656c6c6f204861636b657220416269,%37%2c%38%2c%39%2c%31%30%2c%31%31%2c%31%32%2c%31%33%2c%31%34%2c%31%35%2c%31%36%2c%31%37%2c%31%38%2c%31%39%2c%32%30%2c%32%31%2c%32%32%2c%32%33%2c%32%34%2d%2d%20%2d。 

影响范围：ownDMS 4.7

漏洞危害：高危

漏洞 ID：CVE-2018-7355

临时解决方案：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新。

 

**漏洞名称：Code Blocks 17.12–本地缓冲区溢出漏洞**

漏洞简介：近日，安全研究人员发现互联网存在 Code Blocks 17.12 版本的漏洞公告，该公告 表示 Code Blocks 17.12 版本存在本地缓冲区溢出漏洞。经过分析，通过 junk = "A"\*1982、 fill = "D"\*10000 等语句，将大量数据写入 codeblocks.txt 文件，打开 Code Blocks 应用， 依次选择 File、New、Class，复制“codeblocks.txt”中的内容，将内容粘贴到“Class”中， 点击“Create”，将导致缓冲区溢出，攻击者可以利用这一点执行命令，如：msfvenom -p windows/exec CMD=calc.exe -e x86/unicode\_upper BufferRegister=EAX。

影响范围：Code Blocks 17.12

漏洞危害：高危 

漏洞 ID：暂无 

修复建议：

关注官方网站，及时下载补丁更新
