盛邦安全威胁预警周报 

2019年 总第37期


每周新闻热点

标题：不平凡的2018，但愿2019能平凡一点

摘要：也许你关注的是IG夺冠、詹姆斯转会湖人、李咏、金庸去世或是电影《我不是药神》，无疑这些都将成为2018年不平凡的元素之一。对于安全圈来说，所有的不平凡都伴随着大型数据泄露、漏洞或者网络攻击。

链接：http://t.cn/EbQ2OGs

 

标题：未经用户同意，某些流行安卓应用程序与脸书共享用户的数据

摘要：未经用户同意，某些流行安卓应用程序与脸书共享用户的数据。据MSPoweruser 12月31日报道，在“脸书”一词之后，总跟着“隐私丑闻”。这一现象，在2018年并不罕见，脸书曾多次卷入骇人听闻的非法事件——至少从欧盟的角度来看是这样。

链接：http://t.cn/Eb15Xpm

 

标题：What？黑客竟然可以利用智能灯泡渗透和传输敏感数据

摘要：近期的一项安全研究表明，攻击者可以将智能灯泡的灯光作为通信信道，然后利用这条通信信道来窃取被入侵设备中的敏感数据。

链接：http://t.cn/Ebkw5B4

 

标题：维多利亚州政府雇员详情外泄

摘要：据ABC 1月1日报道，不知名政党下载了部分维多利亚州政府名录后，3万名维多利亚州公务员工作详情数据遭窃，这个给政府员工使用的名录包含工作电邮、职称以及工作电话号码

链接：http://t.cn/EbkVzb7

 

标题：首都网警：贩卖470余万条12306用户数据的人被抓了

摘要：12月28日，北京市公安局网络安全保卫总队（以下简称网安总队）工作中发现，网传有人利用互联网贩卖470余万条疑似12306铁路订票网站的用户数据，引发社会广泛关注。中国铁路总公司官方微博回应“网传信息不实，12306网站未发生用户信息泄露”。

链接：http://t.cn/Eb15vLs

 

标题：Facebook是如何通过Android应用程序跟踪非注册用户的

摘要：12月29日，Privacy International在35C3网站提交了一份报告，报告称Facebook正通过几十款主流Android应用程序收集其社交网络的非用户数据，其中一些应用包括：Kayak，Yelp和Shazam。

链接：http://t.cn/EGZQqdj

 

标题：240万Blur密码管理器用户的数据在线曝光

摘要：Abine，公司背后的模糊的密码管理器和DELETEME在线隐私保护服务，透露周一数据泄露影响近240万用户的模糊，网易科技获悉。

链接：http://t.cn/EGZ84D1


每周漏洞热点

漏洞名称：Hashicorp Consul – 通过Rexec远程代码执行漏洞

漏洞简介：近日，安全研究人员发现互联网存在Hashicorp Consul的漏洞公告，该公告表示Hashicorp Consul存在通过Rexec远程代码执行漏洞。经过分析，发现攻击者可以利用Rexec远程执行命令。攻击者在Hashicorp Consul中通过注册得到ACL token，向服务器发送请求包，获取服务器返回包中的Session ID号，来建立连接。成功建立连接后，攻击者通过构造请求包，并通过这个路径：v1 / kv / _rexec /＃{sess ['ID']} / job？acquire =＃{sess ['ID']}远程执行代码。

影响范围：Hashicorp Consul

漏洞危害：高危

漏洞ID：暂无

修复建议：

关注官方网站，及时下载补丁更新。

 

漏洞名称：WordPress Plugin Adicon Server 1.2 - 'selectedPlace' - SQL注入漏洞

漏洞简介：近日，安全研究人员发现互联网存在WordPress Plugin Adicon Server 1.2版本漏洞公告，该公告表示WordPress Plugin Adicon Server 1.2版本存在SQL注入漏洞。经过分析，发现WordPress Plugin Adicon Server 1.2版本selectedPlace参数存在SQL注入。有效载荷：selectedPlace=1 AND (SELECT * FROM (SELECT(SLEEP(

1)))abcD); --。

影响范围：WordPress Plugin Adicon Server 1.2

漏洞危害：高危

漏洞ID：暂无

临时解决方案：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载补丁更新。

 

漏洞名称：上海求创科技有限公司建站系统存在SQL注入漏洞

漏洞简介：上海求创科技有限公司是一家专注于为客户提供高端网站策划、网站建设、网页设计、品牌网络营销以 及相关的基于互联网应用服务的专业公司。其建站系统存在SQL注入漏洞。攻击者可利用漏洞获取数据库敏感信息。

影响范围：建站系统

漏洞危害：高危

漏洞ID：CNVD-2018-26050

修复建议：

厂商尚未提供漏洞修补方案，请关注厂商主页及时更新：
