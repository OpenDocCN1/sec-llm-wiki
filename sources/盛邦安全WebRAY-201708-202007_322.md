**每周新闻热点**

**标题：6600万条信息泄露，又是MongoDB的锅**  

摘要：超过6600万条个人信息暴露在一个不受保护的数据库中，只要会上网就能查看这些信息。这些被泄露的信息很像从知名国际社交平台——领英的个人资料中截取来的。缓存数据中包括可识别用户的个人详细信息，可以帮助攻击者创建针对性的网络钓鱼攻击。根据Hacken公司的网络风险研究总监Bob Diachenko的说法，个人信息数据通过MongoDB实例被公开，无需身份验证即可访问该实例。  

链接：http://t.cn/EyWlxGI  

  

**标题：Linux.org 被黑 攻击者留下警告**  

摘要：Linux.org 昨日遭到恶意 DNS 劫持，攻击者将其指向了一个新的页面，上面包含一些非常粗俗的内容以表达自己对Linux 社区和 Linux 此前制定的行为准则的不满。Linux.org并不是 Linux 基金会旗下的官方网站，它将自己描述为“一个友好的社区，人们来这里学习并帮助解决 Linux 问题”。该网站似乎不存储代码或敏感数据。  

链接：http://t.cn/Ey3c7b4  

  

**标题：恶意网站滥用11年都未修复的Firefox 漏洞**  

摘要：据报道，恶意网站长期滥用Firefox未修复的漏洞进行非法活动。该漏洞是由于Firefox处理嵌入页面跨域时的身份验证不当造成的。该漏洞的滥用长达11年之久，刚开始被认为只有DOS攻击危害就未予处理。近期，利用该漏洞进行恶意活动的案例又多了起来，但Firefox还未修复。

链接：http://t.cn/EyDzN3V

  

**标题：丰田打造开源汽车黑客渗透平台**  

摘要：来自丰田信息技术中心的Takuya Yoshida和他的同事Tsuyoshi Toyama开发了名为PASTA（便携式汽车安全测试台）的新工具。PASTA是一个专为汽车黑客而设计的开源测试平台，旨在帮助安全专家测试现代汽车的网络安全功能。  

链接：http://t.cn/EUvSSd0  

  

**标题：新型Mac恶意软件结合了EmPyre后门和XMRig矿工**  

摘要：Malwarebytes 实验室成员于上周发现了一种新的Mac恶意软件，出于恶意目的这种软件结合了两种不同的开源工具——EmPyre后门和XMRig矿工。恶意软件的传播途径是名为Adobe Zii的应用程序。Adobe Zii是一种帮助各种Adobe应用程序盗版复制的软件，但被恶意软件利用的Adobe Zii实际上并不是真正的Adobe Zii。

链接：http://t.cn/EU4a0uA  

  

**标题：深入剖析一场针对法国工业领域的网络钓鱼活动**  

摘要：网络安全公司F-Secure的研究人员在最近观察到了一场针对法国工业领域的网络钓鱼活动，目标涵盖化工制造、航空航天、汽车、银行等领域，以及软件提供商和IT服务提供商。研究人员表示，从2018年10月开始，他们捕获了多封钓鱼电子邮件。从内容和附件来看，它们均采用了相似的模板。

链接：http://t.cn/EUcyEx4

  

**标题：新型Android恶意软件旨在从PayPal账户窃取资金**  

摘要：ESET发现，隐藏在电池优化应用程序中的新Android木马可以从用户的PayPal账户中窃取资金，即使是受双因素身份验证保护的用户也难以幸免。不过这款名为Optimization Battery的恶意应用程序目前仅通过第三方应用程序商店提供，而非官方应用商店，这意味着到目前为止受感染的用户数量不多。  

链接：http://t.cn/EU6xsXg

  

**每周漏洞热点**

**漏洞名称：WordPress Plugin AutoSuggest 0.24 - 'wpas\_keys'SQL注入漏洞**  

漏洞简介：近日，安全研究人员发现互联网存在WordPress Plugin AutoSuggest 0.24版本漏洞利用EXP，该漏洞表示WordPress Plugin AutoSuggest 0.24版本存在SQL注入漏洞，经检测，大量用户受到该类漏洞的影响。  

影响范围：WordPress Plugin AutoSuggest 0.24  

漏洞危害：高危  

漏洞ID：暂无  

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时下载更新。

  

**漏洞名称：ThinkPHP5-远程代码执行漏洞**

漏洞简介：近日，安全研究人员发现互联网存在ThinkPHP5漏洞利用EXP，该漏洞表示ThinkPHP5版本存在远程代码执行漏洞。经过分析，发现由于ThinkPHP5版本框架对控制器名没有进行足够的检测，会导致在没有开启强制路由的情况下可能的getshell漏洞，攻击者利用这一漏洞，可以进一步远程执行恶意代码。

Exp：  

http://127.0.0.1/cms/tp-5.1.24/public/index.php?s=index\\think\\template\\driver\\file/write?cacheFile=shell.php&content=%3C?php%20phpinfo();?%3E。

影响范围：

ThinkPHP5.0

ThinkPHP5.1

漏洞危害：高危  

漏洞ID：暂无  

临时解决方案：

如果暂时无法更新到最新版本，可以参考下面的版本库代码记录，自行增加相关代码。5.0版本代码：

https://github.com/top-think/framework/commit/b797d72352e6b4eb0e11b6bc2a2ef25907b7756f

5.1版本代码：

https://github.com/top-think/framework/commit/802f284bec821a608e7543d91126abc5901b2815

临时解决方案：

官方已发布最新版本，请及时下载更新。下载链接：

ThinkPHP5.0.23核心版：

http://www.thinkphp.cn/down/1279.html

ThinkPHP5.0.23完整版：

http://www.thinkphp.cn/down/1278.htm

  

**漏洞名称：Adiscon LogAnalyzer 4.1.7 - 跨站脚本攻击漏洞**

漏洞简介：近日有安全人员放出EXP表示Adiscon LogAnalyzer 4.1.7版本存在跨站脚本攻击漏洞，经过分析，发现Adiscon LogAnalyzer 4.1.7版本referer参数存在跨站脚本攻击漏洞，攻击者可利用此漏洞窃取用户的身份验证凭证、读取或修改数据等。例如：  

http://my.loganalyzer.instance/login.php?referer=%22%3E%3Cscript%3Ealert('Cinta%20Infinita')%3C/script%3E。  

影响范围：Adiscon LogAnalyzer 4.1.7之前版本  

漏洞危害：高危  

漏洞ID：CVE-2018-19877  

修复建议：  

1、官方网站已发布更高本版，请及时下载更新。

下载链接：  

https://loganalyzer.adiscon.com/news/loganalyzer-v4-1-7-v4-stable-released/  

2、建议严格过滤用户输入的数据，切记用户的所有输入都要认为是不安全的。
