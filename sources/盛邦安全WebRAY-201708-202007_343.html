每周新闻热点

标题：软件巨头Oracle修补了301个漏洞，包括46个严重等级为9.8+的漏洞

摘要：10月16日，Oracle发布了针对2018年第3季度的季度关键补丁更新（critical patch update，CPU），该期间公司共修复了301个漏洞。在这301个漏洞中，有45个严重等级为9.8级，有一个甚至是最高级10级。

链接：http://t.cn/EzX35Oy

 

标题：Windows严重漏洞严重漏洞披露：允许黑客将管理员权限转移给来宾账户

摘要：哥伦比亚网络安全专家Sebastian Castro近期分享的一份报告中，披露了Windows系统中的“关键”级别漏洞，允许黑客将管理员权限转移给其他账户。该漏洞自Windows XP系统就已经存在，在报告中Castro自己编写了Metasploit模块来测试和演示这个漏洞。

链接：http://t.cn/EzYpxTT

 

标题：特朗普说中国干预中期选举？美国网络安全公司：我们没发现

摘要：“中国试图干预美国中期选举”，美国总统特朗普最近总在释放类似的信号。但彭博社20日报道说，美国网络安全企业顺着特朗普的指控仔细搜索，却未发现“中国干预中期选举”的蛛丝马迹。

链接：http://t.cn/EzQLlXn

 

标题：美国政府网站府网站HealthCare.gov被黑，致7.5万人敏感信息泄露

摘要：据负责该政府门户网站的机构称，在本月早些时候，他们在一个与HealthCare.gov交互的政府计算机系统中发现了一起黑客攻击行为，导致大约7.5万人的敏感个人数据遭到泄露。

链接：http://t.cn/EzdSb0t

 

标题：魔高一尺：URSNIF恶意软件新变种通过回复邮件实现传播

摘要：大多数网络钓鱼活动，其本质非常简单，并且易于发现。攻击者往往会发送一些看似合法的电子邮件，并在其文本中嵌入恶意链接，或在邮件中添加恶意附件。然而，我们在今年9月监测到的恶意邮件活动却表明，攻击者正在采取更为复杂的网络钓鱼形式。该恶意活动会盗取电子邮件账户，并对邮箱中已有的邮件内容进行回复，在回复的内容中附带恶意软件。对已有邮件的回复，实际上是连续通信中的一部分，因此这种特殊的钓鱼方式难以被用户发现，也难以检测。通常，受害者都没有意识到他们正在遭受钓鱼邮件的威胁。

链接：http://t.cn/EzsfRaw

 

标题：来无影去无踪，无文件攻击悄然崛起

摘要：在任何企业的网络安全意识战略中，员工都需要遵守一项基本准则：如果不能100%确认安全，他们就绝不能打开任何文件或附件。否则，下载或打开可疑文件可能会导致整个企业产生安全危机。

但是，当恶意软件感染计算机中，却无法在任何文件中发现该恶意软件时，用户该怎么办呢?如果该恶意软件被嵌入到难以检测的进程中，又该如果呢?这些问题都是公司遭遇无文件恶意软件攻击时经常困扰他们的问题。

链接：http://t.cn/EZUIGuN

 

标题：国泰航空 940 万名乘客个人数据在 3 月被盗 包含出行地点数据

摘要：据外媒报道，日前大型国际航空公司国泰航空披露，在今年3月发生的一次数据泄露事件中，该公司的940万名乘客的记录被盗，另外含有姓名、出生日期、住址等个人信息的护照信息也可能已经泄露。据悉，此次事件还涉及到了每位乘客的具体出行地点以及客户服务代表的评论等等。

链接：http://t.cn/EZfpTRG


每周漏洞热点

漏洞名称：Cisco Webex Meetings - 经过身份验证的用户代码执行漏洞

漏洞简介：近日有安全人员放出EXP表示Cisco Webex Meetings桌面应用程序存在经过身份验证的用户代码执行漏洞。经过分析，Cisco Webex Meetings桌面应用程序可由经过身份验证的攻击者在本地利用，允许以特权用户身份执行任意命令。该漏洞是由于用户提供的参数验证不充分，攻击者可以通过使用精心设计的参数调用更新服务命令来利用此漏洞，最终可能允许攻击者使用SYSTEM用户权限运行任意命令。

影响范围：Cisco Webex Meetings < 33.6.0

漏洞危害：高危

漏洞ID：CVE-2018-15442

修复建议：

请关注官方网站，及时进行补丁更新。

 

漏洞名称：ServersCheck监控软件14.3.3– 拒绝服务漏洞

漏洞简介：近日有安全人员放出EXP表示ServersCheck监控软件14.3.3版本存在拒绝服务漏洞。经分析，ServersCheck监控软件14.3.3版本存在拒绝服务漏洞。创建一个指向第二个LNK文件的LNK文件，第二个LNK文件与“开始”菜单项相关联。这种行为导致了目录遍历错误，可以在任意目录中创建空文件。将<VICTIM>项更改为受害者用户后，受害者将收到来自服务器的错误消息，例如“从数据库检索传感器详细信息时出错”，随后，在没有IE浏览器、命令或运行提示的情况下，通过开始/程序/附件/任务菜单进行链接。

影响范围：ServersCheck监控软件14.3.3

漏洞危害：高危

漏洞ID：暂无

临时解决方案：

1、关注官方网站，及时更新。

2、采用高性能的网络设备引。

3、升级主机服务器硬件。

 

漏洞名称：Open ISES Project 3.30A  – 任意文件下载漏洞

漏洞简介：近日有安全人员放出EXP表示Open ISES Project 3.30A版本存在任意文件下载漏洞，经分析，在下载路径中，download.php文件存在下载功能，但没有对下载的文件做过滤，导致可以下载任意文件。

例如：http：//localhost/[PATH]/ajax/download.php?filename= ../../../../../Wind

ows/win.ini＆origname =＆type =。

影响范围：Open ISES Project 3.30A

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、请关注官方网站，及时进行补丁更新。

2、过滤.(点)，使用户在URL中不能回溯上级目录。
