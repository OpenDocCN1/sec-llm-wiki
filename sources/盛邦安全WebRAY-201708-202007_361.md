每周新闻热点

**标题：**西部数据My Cloud NAS又曝致命漏洞，无需密码即可提权至管理员级别

**摘要：**西部数据的My Cloud（WD My Cloud）是全球受欢迎的网络附加存储（NAS）设备之一，大量的企业和个人都使用它来托管他们的文件，并将其与各种云和基于web的服务进行备份和同步。据The Hacker News报道，有安全研究人员在西部数据（Western Digital）的My Cloud NAS设备中发现了一个身份验证旁路漏洞，该漏洞可能允许未经身份验证的攻击者获得对受影响设备的管理员级别控制。

**链接：**http://t.cn/Evk9H1Y

 

**标题：**浙江超70%网民个人信息被泄漏 警方通报三大犯罪特点

**摘要：**近年来,个人信息安全问题日益成为公众关注的焦点。在“大数据”时代背景下，社会信息化高速发展，信息资源成为越来越重要的生产要素和社会财富，个人信息安全问题日益成为公众关注的焦点。据《浙江省互联网发展报告》显示，仅2017年，浙江有72.8%的网民经历过个人信息泄露。

**链接：**http://t.cn/EP7XJ4k

 

**标题：**防不胜防 成千上万的 WordPress 网站被挂上恶意代码

**摘要：**据来自 Sucuri 和 Malwarebytes 的安全研究员称，本月有成千上万的的 WordPress 网站遭到黑客入侵并被恶意代码攻击。尽管这些事件的入口似乎都不同，但都遵循类似的模式 —— 从已知威胁者处加载恶意代码。研究人员认为入侵者正在想办法获取访问这些网站的机会，他们不是利用 WordPress CMS 本身的漏洞，而是利用过时的主题和插件中的漏洞。

**链接：**http://t.cn/EPqb76J

 

**标题：**还记得BlueBorne吗？一年过去了，仍有20亿蓝牙设备的漏洞没有修复

**摘要：**去年这个时候，国外安全厂商Armis公布了8个蓝牙漏洞，可让黑客无视蓝牙版本完全控制设备和数据。Armis将这一组漏洞合为名叫“BlueBorne”的攻击媒介。当时，BlueBorne的杀伤范围几乎涵盖所有具备蓝牙功能的Android、Linux、Windows和iOS设备。自从漏洞披露之后，各大厂商一直在稳步推送相关更新。但根据Armis的估算，仍有超过20亿的设备仍然暴露在风险之中，它们没有进行更新，或者压根就接收不到更新补丁。。

**链接：**http://t.cn/EPfCKwG

 

**标题：**Firefox出现严重Bug ，可导致浏览器和系统一起崩溃

**摘要：**安全研究人员 Sabri Haddouche 近日发现了一个可能导致 Firefox 浏览器崩溃，甚至是一同导致系统崩溃的 Bug。Sabri表示，该 Bug 能造成的影响取决于使用的操作系统，如果是在 Linux 和 Mac OS X 上，浏览器会提示 Crash Reporter，让用户选择通知 Mozilla 出现崩溃问题并重启 Firefox。

**链接：**http://t.cn/EPJb6l8

 

**标题：**凭证填充攻击——日益严重的安全威胁

**摘要：**根据Akamai公司最新发布的报告“\[互联网现状\]/安全报告：凭证填充攻击”，凭证填充攻击（又称撞库攻击）已成为一种日益严重的威胁，然而却没有引起人们足够的重视。

凭证填充是一种网络攻击手段，其中被盗的账户凭证通常由用户名/电子邮件地址以及相应密码（通常来自数据泄露）组成，通过针对web应用程序的大规模自动登录请求获得对用户帐户的未授权访问。与凭证破解不同，凭证填充攻击并不会试图暴力破解或猜测任何密码——攻击者只需使用标准Web自动化工具（如 Selenium，CURL，PhantomJS或专门为此类攻击设计的像Sentry MBA的工具）。

**链接：**http://t.cn/EP9Yrfa

 

**标题：**用户名“admin”、密码“123456”，乌克兰军方系统安全问题被曝光

**摘要：**“123456、admin”在2017年弱密码TOP 100中，分别位列第一位和第十一位。大多数账户系统在注册时基本禁止使用这种“网红弱密码”，你很难想象这竟然会成为一个国家军方系统的用户名和密码。

**链接：**http://t.cn/EPlZzrH

  

每周漏洞热点

**漏洞名称：**iWay Data Quality Suite Web控制台10.6.1.ga - XML外部实体注入漏洞

**漏洞简介：**近日有安全人员放出EXP表示iWay Data Quality Suite Web Console 10.6.1.ga版本存在XML外部实体注入漏洞，经过分析，发现iWay Data Quality Suite Web Console 插件10.6.1.ga存在XML外部实体注入漏洞。iWay Data Quality Suite Web控制台提供Web服务功能，处理时产品所特有的Web服务上存在validation，攻击者可以轻松地在SOAP请求中注入外部实体，并且可以在服务器上成功实现远程执行代码。

**影响范围：**iWay Data Quality Suite Web Console 10.6.1.ga

**漏洞危害：**高危

**漏洞ID： **CVE-2018-11776

**修复建议：**

1\. 使用开发语言提供的禁用外部实体的方法

2\. 过滤用户提交的XML数据

 

**漏洞名称：**Beyond Remote 2.2.5.3 - 拒绝服务漏洞

**漏洞简介：**近日有安全人员放出EXP表示Beyond Remote 2.2.5.3版本存在拒绝服务漏洞，经过分析，运行python脚本，通过bof = "A" \* 2000，将2000个A写入mre.txt文件，打开Beyond Remote Server 2.2.5.3，单击 "Configure" ，将mre.txt文件中的内容复制到 "Proxy Password" 字段中，然后单击 "OK"，程序将崩溃。

**影响范围：**Beyond Remote 2.2.5.3

**漏洞危害：**高危

**漏洞ID：**暂无

**修复建议：**

1、关注官方网站，及时更新。

2、采用高性能的网络设备引。

3、升级主机服务器硬件。

 

**漏洞名称：**Joomla多组件SQL注入漏洞

**漏洞简介：**近日有安全人员放出EXP表示Joomla多组件存在SQL注入漏洞，经过分析，发现Joomla多组件存在SQL注入漏洞，通过把SQL命令插入到Web表单提交或输入域名或页面请求的查询字符串,最终达到欺骗服务器执行恶意的SQL命令。
