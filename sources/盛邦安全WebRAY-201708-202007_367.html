每周新闻热点

标题：印媒：黑客利用印度网站疯狂“挖矿”，包括政府网站

摘要：据《印度经济时报（The Economic Times）》报道，尽管印度政府可能对加密货币持打压态度（印度财政部长Arun Jaitley在今年2月份发表年度预算讲话时表达了该国政府打击加密货币的明确立场），但该国的政府网站却在无意中帮助了黑客从他们的网站上赚取这种近年来被热捧的“互联网利润”。

链接：http://t.cn/Ev1O2QK

 

标题：史上危险的手机间谍软件已感染45个国家/地区

摘要：根据公民实验室（Citizen Lab）的一份最新报告显示，在过去的两年时间里，被认为是世界上最危险的手机间谍软件之一的Pegasus已经出现在了45个国家/地区，并被用于监控目标人物。

链接：http://t.cn/Ev1Ot7n

 

标题：研究人员发现可公开访问的包含 1100 万条记录的 MongoDB 数据库

摘要：9月17日，安全研究员Bob Diachenko发现了一个可公开访问的MongoDB数据库，其中包含43.5 GB的数据和10.999.535的Yahoo电子邮件地址。除其他细节外，数据库中包含的每条记录都包括电子邮件地址，全名和性别，以及其他敏感的个人数据，如城市和邮政编码，以及实际地址。

链接：http://t.cn/Ev8CfjO

 

标题：WannaMine蠕虫病毒进一步侵食着大公司的系统

摘要：WannaMine具有十分强大的侵略能力。它使用Windows管理规范来检测32位或64位系统并选择要下载的有效负载版本。它能将自身伪装为计划进程，这样在系统关闭后它也仍然存在，并且它会更改受感染计算机的电源管理设置，以确保计算机不会进入休眠状态，其挖掘活动也不会中断。它还能关闭所有与互联网协议端口连接的加密货币-采矿池（3333,5555和7777）进程，然后运行自己的基于PowerShell的矿工，连接到14444端口的采矿池。

链接：http://t.cn/EvmSNWk

 

标题：Facebook针对第三方应用程序推出漏洞赏金计划

摘要：2018年9月17日，Facebook宣布更新bug赏金计划，此次更新目的是防止令牌通过第三方应用程序的安全漏洞泄露。访问令牌是用于标识唯一用户和用户权限的凭据，并允许用户使用Facebook登录另一个应用程序。用户可以决定令牌和应用程序可以访问哪些信息以及可以采取的操作。

链接：http://t.cn/Ev80kGA

 

标题：比WannaCry更厉害的勒索软件来袭，目标瞄准Linux和Windows服务器

摘要：来自Palo Alto Networks公司旗下Unit 42威胁研究团队的安全研究员Claud Xiao、Cong Zheng和Xingyu Jin在本周一（9月17日）发布的一篇博文中指出，他们发现了一个针对Linux和Windows服务器的新型恶意软件家族，并将其命名为“Xbash”。

链接：http://t.cn/Ev8OLnL

 

标题：爆破Tomcat服务器，GandCrab 4.3勒索病毒成功入侵企业内网

摘要：近日，腾讯御见威胁情报中心拦截到专攻企业局域网的勒索病毒GandCrab，这个臭名昭著的勒索病毒版本号已升级到4.3。与以往不同的是，攻击者在已入侵网络同时释放挖矿木马和勒索病毒，针对高价值目标使用GandCrab勒索病毒，而一般目标则运行挖矿木马，以最大限度利用被入侵的目标网络非法牟利。

链接：http://t.cn/Ev85ySI 


每周漏洞热点

漏洞名称：CA Release Automation NiMi 6.5 - 远程命令执行漏洞

漏洞简介：2018年9月17日，Java平台发布了漏洞编号为CVE-2018-15691的安全漏洞，漏洞危害程度为高等（higher）。CA Release Automation是美国CA公司的一套发布自动化解决方案的企业级应用程序。该方案可在应用生命周期中实现持续交付，并能够简化和执行应用发布、集中处理从开发到生产的应用操作、通过仪表板对整个部署过程进行监督和审核等。CA Release Automation存在任意代码执行漏洞，利用该漏洞，攻击者可以在受影响应用程序环境中执行任意代码，失败的攻击会造成拒绝服务。

影响范围：CA Release Automation NiMi <= 6.5

漏洞危害：高危

漏洞ID： CVE-2018-15691

修复建议：

厂商已发布了漏洞修复程序，请及时关注更新：

https://support.ca.com/us/product-content/recommended-reading/security-notices/ca20180829-03--security-notice-for-ca-release-automation.html

 

漏洞名称：Dell EMC Unity验证绕过漏洞

漏洞简介：Dell EMC Unity是一款专为闪存设计的完全统一的存储阵列。Dell EMC Unity存

在验证绕过漏洞，经过远程身份验证的用户可利用此漏洞直接与Unity OE的某些API进行交互来读取NAS服务器中的文件，从而绕过仅在Unisphere GUI中实现的基于角色的授权控制。影响范围：

Dell EMC Unity Operating Environment (OE) <4.3.1.1525703027

Dell EMC UnityVSA Operating Environment (OE) <4.3.1.1525703027

漏洞危害：高危

漏洞ID：CVE-2018-1250

修复建议：

用户可联系供应商获得补丁信息：

https://support.emc.com/downloads/39949_Dell-EMC-Unity-Family

 

漏洞名称：Joomla Component JCK Editor 6.4.4 - 'parent'SQL注入漏洞

漏洞简介：2018年9月17日，PHP平台发布了安全漏洞，漏洞危害程度为高等（higher）。SQL注入攻击是攻击者通过在应用程序中预先定义好的查询语句结尾加上额外的SQL语句元素，欺骗数据库服务器执行非授权的任意查询。会导致网页被篡改、数据被篡改、核心数据被窃取、数据库所在服务器被攻击变成傀儡主机等后果。

影响范围：Joomla Component JCK Editor 6.4.4

漏洞危害：高危

漏洞ID：暂无

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.关注官方网站，及时进行更新。

3.对数据库操作进行监控。
