每周新闻热点

标题：港媒:黑客窃取美军无人机敏感资料 欲在"暗网"兜售

摘要：港媒称，美国一家网络情报信息公司发现，一名据信来自南美洲的黑客，早前透过一个路由器漏洞入侵美国空军一名上尉的计算机，窃取有关无人机和坦克的敏感资料，并尝试在“暗网”（Dark Web）兜售。美国联邦调查局正调查事件。

链接：http://t.cn/Rght9fO

 

标题：恶意软件分析趋势：研究网络犯罪

摘要：分析恶意软件的主要目的是确认特定恶意软件的工作方式，提取IOC（妥协指标）并找出对策。它使得安全软件供应商能够为客户构建更好的检测和保护措施。不过这项工作几乎完全是技术性的：它专注于二进制文件及其属性。恶意软件分析的结果对于组织来说至关重要，因为它们可以防止病毒爆发或修复实时渗透。研究机构发现，除了专业性问题外，研究恶意软件对于打击网络犯罪的执法活动也很有帮助。

链接：http://t.cn/Rg28YcY

 

标题：红牛3400万被黑客转给别家公司 2年多仍未讨回巨款

摘要：红牛有限公司的款项莫名其妙被黑客转到一家贸易公司的银行账号上，向警方报案后，为追回钱款又向法院起诉，法院最终以涉及刑事诈骗为由驳回起诉，尽管警方已冻结涉案账号，但3400多万被错转的款项却迟迟无法讨回，无奈之下，红牛有限公司只能向上一级法院起诉

链接：http://t.cn/RgyzOTg

 

标题：研究人员对车载导航系统成功发动 GPS 欺骗攻击

摘要：弗吉尼亚理工、中国电子科技大学和微软研究院的研究人员发表论文《All Your GPS Are Belong To Us: Towards Stealthy Manipulation of Road Navigation Systems》，演示了对人类司机成功发动 GPS 欺骗攻击。

链接：http://t.cn/Rg6Y9Zx

 

标题：沃尔玛拥有了自己的窃听技术专利，用来给员工打绩效？

摘要：在行业巨头不断超越彼此的“科技经营”中，沃尔玛似乎已经领先了一步。据报道，沃尔玛近日获得了一项将在其商场内使用的监听技术专利。尽管沃尔玛声称这只是一个监控工具，用于分析员工的表现，但它的确具备窃听员工和顾客隐私的能力。

链接：http://t.cn/Rg98rAN

 

标题：重拳出击！首都网警3个月破获涉网案件900余起

摘要：按照公安部“净网2018”专项行动的部署要求，北京市公安局网安总队与局属相关单位密切配合、整体联动，今年4月至6月，共破获涉网案件900余起，抓获嫌疑人580余名。特别是近期侦获的“北京赛车PK拾”网络赌博案及张某某特大网络赌球案，有效遏制了网络赌博违法犯罪发展蔓延势头。

链接：http://t.cn/RgW2Nkd

 

标题：电商雇“黑客” 袭击竞争对手网站

摘要：南通警方破获电商网站流量攻击系列案件，12人被采取刑事强制措施；QQ群“接单”还可学“黑客”技术。

每周漏洞热点

漏洞名称：FTP2FTP 1.0 - 任意文件下载漏洞

漏洞简介：2018年7月18日， PHP平台发布了安全漏洞，漏洞危害程度为高等（higher）。一些网站由于业务需求，往往需要提供文件查看或文件下载功能，但若对用户查看或下载的文件不做限制，则恶意用户就能够查看或下载任意敏感文件，这就是任意文件查看与下载漏洞。

影响范围：FTP2FTP 1.0

漏洞危害：高危

漏洞ID：暂无

修复建议：

1、严格检测用户下载内容，默认用户下载操作均为恶意操作。

2、确定此下载处存在的必要性，若无必要，建议删除。

 

漏洞名称：Microhard Systems 3G / 4G蜂窝以太网和串行网关 - 默认凭证登录漏洞

漏洞简介：2018年7月17日， Hardware平台发布了安全漏洞，漏洞危害程度为高等（higher）。设备在其Linux发行版图像中使用硬编码凭证，这些凭证组永远不会向最终用户公开，也无法通过更改网关的任何正常操作，但是默认凭据可成功登录，使用root权限进行访问。

影响范围：IPn4G 1.1.0 build 1098

IPn3Gb 2.2.0 build 2160

IPn4Gb 1.1.6 build 1184-14

IPn4Gb 1.1.0 Rev 2 build 1090-2

IPn4Gb 1.1.0 Rev 2 build 1086

Bullet-3G 1.2.0 Rev A build 1032

VIP4Gb 1.1.6 build 1204

VIP4G 1.1.6 Rev 3.0 build 1184-14

VIP4G-WiFi-N 1.1.6 Rev 2.0.0 build 1196

IPn3Gii / Bullet-3G 1.2.0 build 1076

IPn4Gii / Bullet-LTE 1.2.0 build 1078

BulletPlus 1.3.0 build 1036

Dragon-LTE 1.1.0 build 1036

漏洞危害：高危

漏洞ID：暂无

修复建议：

关注官方网站，及时进行补丁更新。

 

漏洞名称：QNAP Q'Center - change_passwd命令执行漏洞

漏洞简介：2018年7月17日，Linux平台发布了漏洞编号为  CVE-2018-0706、CVE-2018-0707的安全漏洞，漏洞危害程度为高等（higher）。QNAP Q'Center虚拟设备版本的Web界面中的“change_passwd”API方法中存在命令注入漏洞，该漏洞允许“admin”特权用户帐户以“admin”操作系统用户身份执行任意命令。虽然必须要“admin”用户帐户的有效凭据，但是，此模块还利用单独的密码泄露问题，允许任何经过身份验证的用户在首次安装期间查看为“admin”用户设置的密码。

影响范围：QNAP Q'Center <= 1.7.1063

漏洞危害：高危

漏洞ID：CVE-2018-0706、CVE-2018-0707

修复建议：

关注官方网站，及时进行补丁更新。
