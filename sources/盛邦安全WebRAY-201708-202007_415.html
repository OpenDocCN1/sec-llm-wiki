每周新闻热点

标题：Netflix 新型钓鱼开始使用具有有效 TLS 证书的站点

摘要：美国SANS技术研究院院长Johannes Ullrich 6月20日指出，使用TLS（安全传输层协议）认证网站的Netflix网络钓鱼邮件一直在增长。

链接：http://t.cn/RrAaeMy

 

标题：不只是Win10！黑客一台WP手机跑四个系统！

摘要：IT之家6月23日消息 在此之前，已有黑客开发者已在Lumia 950 XL上成功运行了Windows 10 on ARM系统。今日根据MSPU报道，另一位黑客开发者在此之上更进一步，在Windows Phone上运行4个了不同的微软操作系统。

链接：http://t.cn/RrUzQpd

 

标题：黑客找到iOS 11锁屏密码漏洞：连接数据线暴力破解

摘要：iOS的口碑与其良好的安全性不可分，然而随着美国相关执法部门借助Grayshift进行破解的事情曝光，公众开始极为担忧起来。安全研究人员Matthew Hickey称，自己发现了绕过iPhone锁屏密码保护的方法。

链接：http://t.cn/RrqVv4Q

 

标题：公安部：《网络安全等级保护条例》拟将于本周发布

摘要：网络安全标准论坛在京召开。由公安部牵头，会同中央网信办、国家保密局、国家密码管理局联合制定的《网络安全等级保护条例》拟将于本周在网上发布。

链接：http://t.cn/RrMzgqo

 

标题：网络间谍组织Tick通过U盘感染未联网计算机

摘要：Tick是主要针对日本和韩国组织的网络间谍活动组织。该组织以用各种定制恶意软件进行攻击活动而恶名昭彰，如Minzen、Datper、Nioupale(又名Daserf)和HomamDownloader。最近，帕洛阿尔托网络公司第42单元（Unit 42）针对他们有了新的发现。

链接：http://t.cn/RraInjp

 

标题：挑战升级：Necurs僵尸网络使用Web查询文件IQY逃避安全检测

摘要：Necurs 是全球最大的垃圾邮件僵尸网络，由数百万受感染的计算机组成，曾用于扩散 Locky、GlobeImposter Trickbot 等多个恶意软件。4月研究人员发现Necurs的操纵者使用新技术规避检测——向受害者发送含有压缩包的邮件，解压后出现扩展名为 .URL 的文件，这些文件将利用服务器消息块(SMB)协议从远程服务器执行有效负载，从而成功地避开某些垃圾邮件过滤器。“道高一尺，魔高一丈”，最近趋势科技发现Necurs的作者在被发现后对规避方法似乎进行了升级。

链接：http://t.cn/Rr92yjD

 

标题：国内某论坛遭黑客用作C&C服务器 利用Struts 2漏洞开展挖矿活动

摘要：在6月10日，F5实验室的威胁研究人员发现了一起针对Apache Struts 2服务器的新活动，使用了Apache Struts 2 Jakarta Multipart Parser插件漏洞（CVE-2017-5638）。这起活动被认为拥有一些在之前从未发现过的独有特征：

  •  采用C#语言编译自己的dropper；

  •  下载一个.NET恶意软件；

  •  将我国国内一个网络论坛作为它的命令和控制（C&C）服务器；

  •  使用自己的解码器解码C&C命令。

而研究人员还强调，这些还只是这起活动所有特征中的一部分

链接：http://t.cn/RrO6lfr


每周漏洞热点

漏洞名称：Ecessa Edge EV150 10.7.4 - 跨站请求伪造（添加超级用户）漏洞

漏洞简介：2018年6月25日，Linux平台发布了安全漏洞，漏洞危害程度为中等（moderate）。攻击者通过用户的浏览器来注入额外的网络请求，来破坏一个网站会话的完整性。而浏览器的安全策略是允许当前页面发送到任何地址的请求，因此也就意味着当用户在浏览他/她无法控制的资源时，攻击者可以控制页面的内容来控制浏览器发送它精心构造的请求。

影响范围：Ecessa Edge EV150 10.7.4

漏洞危害：中危

漏洞ID：暂无

修复建议：

1. 验证Referer

2. 在请求参数中添加token验证

3. 在HTTP头中自定义属性并验证

建议不同的网站根据需求适用不同防御方法进行组合。

 

漏洞名称：WooCommerce < 1.5.4 WordPress插件高级订单导出- CSV注入漏洞

漏洞简介：2018年6月25日，PHP平台发布了漏洞编号为CVE-2018-11525的安全漏洞，漏洞危害程度为高等（higher）。WordPress插件可以帮助您轻松导出WooCommerce订单数据。很简单导出分配的任何自定义字段，如订单、产品、优惠券等，您可以选择各种格式来导出数据，例如CSV，XLS，XML和JSON等格式。当输入有效负载@SUM（1 + 1）* cmd |' / C calc'！A0在表单域中提交，高权限用户登录到应用程序以CSV格式导出表单数据并打开文件时，公式得到执行，计算器将在他的机器中弹出。

影响范围：WooCommerce < 1.5.4

漏洞危害：高危

漏洞ID：CVE-2018-11525

修复建议：

过滤=或-号开头的单元格数据，过滤=(-)cmd或=(-)HYPERLINK或concat()等。并根据不同的业务场景，通过替换攻击代码中的关键字符，同时在后端配合正则进行校验等方式降低被攻击风险。

 

漏洞名称：WordPress Plugin iThemes Security < 7.0.3 - SQL注入漏洞

漏洞简介：2018年6月25日，PHP平台发布了漏洞编号为CVE-2018-12636的安全漏洞，漏洞危害程度为高等（higher）。SQL注入攻击是攻击者通过在应用程序中预先定义好的查询语句结尾加上额外的SQL语句元素，欺骗数据库服务器执行非授权的任意查询。会导致网页被篡改、数据被篡改、核心数据被窃取、数据库所在服务器被攻击变成傀儡主机等后果。

影响范围：WordPress Plugin iThemes Security < 7.0.3

漏洞危害：高危

漏洞ID：CVE-2018-12636

修复建议：

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.部署Web应用防火墙

3.对数据库操作进行监控

建议过滤用户输入的数据，切记用户的所有输入都要认为是不安全的。
