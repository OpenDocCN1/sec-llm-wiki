**在拥有2800万用户的全球最大的社交编程及代码托管网站GitHub上，最热门的开源项目榜单都有哪些？一起来看看程序猿与攻城狮们六月的最爱。**

  

**TOP1. javascript-algorithms（23,180 stars on GitHub，23,103 stars this month）**

**相关语言：**JavaScript

**GitHub网址：**

https://github.com/trekhleb/javascript-algorithms

  

该项目收集了多种基于JavaScript的算法与数据结构。每种算法和数据结构都有自己的README提供相关说明及相关资料的链接，同时还配有相应的测试脚本可以运行。

  

  

**TOP2. Deno（20,194 stars on GitHub，20,103 stars this month）**

**相关语言：**JavaScript

**GitHub网址：**

https://github.com/ry/deno

  

如果对于Deno项目不熟悉的话，那么说起Node一定不陌生吧。Deno是Node之父Ryan Dahl的新作。Ryan Dahl在今年JS Conf 做了《Design Mistakes in Node》的演讲，主要讲述了设计Node时的一些错误以及Deno的目标及规划。但Deno的出现并不是要取代或者兼容Node。Deno在GitHub有着非常明确的定义“A secure TypeScript runtime built on V8A secure TypeScript runtime built on V8”。目前Deno只是一个Demo，还处在初级阶段。

  

  

**TOP3. build-your-own-x（32,968 stars on GitHub，14,801 stars this month）**

**GitHub网址：**

https://github.com/danistefanovic/build-your-own-x

 

build-your-own-x项目包含了各种环境的构建技术集合，包括：区块链、加密货币、数据库、神经网络、正则引擎、搜索引擎、Web服务器、仿真器、前端框架、文本编辑器、Web搜索引擎、3D渲染器、机器人等。

  

  

**4\. vue（103,292 stars on GitHub，9,433 stars this month）**

**相关语言：**JavaScript

**GitHub网址：**

https://github.com/vuejs/vue

  

![](../Images/927932124cc115acbdc7a520878f5778.png)

  

Vue是一套用于构建用户界面的渐进式框架，采用自底向上增量开发的设计。Vue 的核心库只专注于视图层，且很容易与其他第三方库或现有项目整合。同时Vue的生态系统提供了一系列的工具与库，使Vue也可以胜任复杂的单页应用开发。

  

  

**5\. react（103,204 stars on GitHub，7,590 stars this month）**

**相关语言：**JavaScript

**GitHub网址：**

https://github.com/facebook/react

 

React是由FaceBook推出的一套用于构建用户界面的JavaScript库。通过使用React可以更加轻松的创建交互式的用户界面。React为应用的每个状态设计简洁的视图，当数据更改时，React 将高效地更新和渲染相应的组件。React另一大特色是组件化。通过创建拥有独立状态的组件，然后将这些组件组合起来实现复杂的页面。

  

  

**6\. awesome-design-patterns（6,073 stars on GitHub，6,011 stars this month）**

**GitHub网址：**

https://github.com/DovAmir/awesome-design-patterns

 

项目收集了在不同应用场景下的软件及架构设计模式的相关知识点。包括：云架构，大数据，数据库，微服务&分布式系统，Docker与DevOps，安全等方面。

  

**7\. wtf（5,868 stars on GitHub，5,856 stars this month）**

**相关语言：**Go

**GitHub网址：**

https://github.com/senorprogrammer/wtf

 

WTF是专为展示不常用但却很重要的日常数据而设计的仪表盘。WTF使用了如下开源库：

Calendar、config、go-github、goreleaser、openweathermap、tcelltview、newrelic

![](../Images/eb5d4a2f15a79b8253e331882d762a9e.png)

  

**8\. wired-elements（5,632 stars on GitHub，5,605 stars this month）**

**相关语言：**JavaScript

**GitHub网址：**

https://github.com/wiredjs/wired-elements

 

Wired Elements 是一套具有手工绘图外观的组件库，可用于原型图、线框图或者用来在网页上取得手工绘图的效果。由于这些组件生成时带有随机性，即便是同一组件的两次渲染效果也是不相同的。

  

![](../Images/c056241c06e8636972fead634106880e.png)

  

**9\. architect-awesome（20,215 stars on GitHub，4,941 stars this month）**

**GitHub网址：**

https://github.com/xingshaocheng/architect-awesome

 

不想做架构师的程序猿不是好程序猿，如果想成为一名后端架构师需要哪些技能呢？该项目详细的列举了相关的知识技能。包括：数据结构、常用算法、并发、操作系统、设计模式、运维&统计&技术支持、中间件、网络、数据库、搜素引擎、大数据、安全、常用开源框架、分布式设计、设计思想&开发模式、项目管理、技术趋势、团队管理、政策、法规、架构师素质等模块。
