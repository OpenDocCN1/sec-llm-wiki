1.每周新闻热点

**标题：**黑客积极利用Prowli僵尸网络获利 全球已有超过4万台设备沦陷

**摘要：**GuardiCore安全团队在本周三（6月6日）发布的一份报告中指出，他们发现了一起大规模的流量操纵和加密货币挖掘活动，影响了金融、教育和政府等行业的众多组织。这项被命名为“Operation Prowli”的活动将恶意软件和恶意代码传播到服务器和网站，已经在全球多个国家和地区感染了超过4万台设备。Prowli活动使用了各种攻击技术，包括漏洞利用、密码暴力破解和弱配置。

**链接：**http://t.cn/RB7pBcG

 

**标题：**美媒诬陷“中国黑客”入侵 窃取美614GB容量机密

**摘要：**据俄罗斯卫星网6月8日报道，美国华盛顿邮报宣称，“中国黑客”近期入侵了一家美国国防承包商的计算机网络，这家承包商拥有美国海军作战计划的高度敏感信息。

**链接：**http://t.cn/RBZzJKp

 

**标题：**关于勒索软件攻击隐藏的巨大成本，这里的水很深！

**摘要：**赎金只是勒索软件攻击总成本中最直观的一小部分而已，在估算总体损失时还需要考虑很多隐藏成本。 预测勒索软件攻击的整体成本对于安全管理人员而言可能是一件非常棘手的事情，因为需要考虑到响应和恢复时间可能带来的很多影响因。

**链接：**http://t.cn/RBL4YCC

 

**标题：**僵尸网络Prowli感染9000家企业的设备，中国公司较多

**摘要：**以色列网络安全公司 GuardiCore 的安全团队发现，网络犯罪分子设法组建了一个庞大僵尸网络“Prowli”， 该网络由4万多台被感染的 Web 服务器、调制调解器和其它物联网（IoT）设备组成。 Prowli 僵尸网络的操纵者利用漏洞和暴力破解攻击感染并控制设备。受影响的有9000多家公司，这些公司主要位于中国、俄罗斯、美国等国家。

**链接：**http://t.cn/RBqQHeQ

 

**标题：**黑客利用IQY文件绕过杀毒软件并通过微软Excel下载恶意软件

**摘要：**根据技术博客Barkly在上周发表的一篇文章来看，安全研究人员Derek Knight（@dvk01uk）已经发现了一系列新的垃圾电子邮件活动，采用了一种较为新颖的方法来感染受害者。这些活动并未使用Word文档或其他常被滥用的附件类型，而是使用Web查询文件（.iqy）——本质上是一种简单的文本文件，默认在微软Excel中打开，用于从因特网下载数据。

**链接：**http://t.cn/RBf2Sof

 

**标题：**暗网现A站千万条用户数据，兜售广告带上了摩拜

**摘要：**雷锋网消息，6月13日凌晨，AcFun 对用户发布公告称网站遭遇黑客攻击，近千万条用户数据外泄。据公告称，泄露的数据包括用户 ID、昵称以及加密存储的密码。同时公告也提示用户，所有的密码都是经过加密的没有明文密码。

**链接：**http://t.cn/RBJ314G

 

**标题：**交易所暂缓激活EOS主网 近百万EOS被盗

**摘要：**据IMEOS消息，EOS主网上线期间大量EOS私钥被黑客偷走。已经有60多位英文区和韩文区的受害者，中文区的还没统计。涉及的EOS总数超过百万，截止目前已经有3个账号被找回，一个被认领。目前，由EOS42发起，EOSCannon（佳能社区）、EOS纽约、EOSNation、BlockSmith、EOSAmsterdam、EOSNation、EOSRio、EOSDAC节点正在支持处理此事。

**链接：**http://t.cn/RBXCxLY

2.每周漏洞热点

**漏洞名称：**WordPress Google Map Plugin < 4.0.4 -  SQL注入漏洞

**漏洞简介：**2018年6月13日，PHP平台发布了安全漏洞，漏洞危害程度为高等（higher）。SQL注入攻击是攻击者通过在应用程序中预先定义好的查询语句结尾加上额外的SQL语句元素，欺骗数据库服务器执行非授权的任意查询。会导致网页被篡改、数据被篡改、核心数据被窃取、数据库所在服务器被攻击变成傀儡主机等后果。

**影响范围：**WordPress Google Map Plugin < 4.0.4

**漏洞危害：**高危

**漏洞ID：**暂无

**修复建议：**

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.部署Web应用防火墙

3.对数据库操作进行监控

建议过滤用户输入的数据，切记用户的所有输入都要认为是不安全的。

 

**漏洞名称：**Redaxo CMS Mediapool Addon <5.5.1 - 任意文件上传漏洞

**漏洞简介：**2018年6月13日，Windows平台发布了安全漏洞，漏洞危害程度为高等（higher）。在版本5.6.0的REDAXO CMS中，mediapool插件存在风险的，拥有用户帐户的用户（例如编辑者）可以使用mediapool上传文件；2.4.0版本下的mediapool插件使用fileupload黑名单。对于用户，不可能上传名为：php，php4，php5，php6或php7的文件。但是，如果将文件命名为php71或php53，则黑名单函数将忽略此操作，并可能上传shellcode文件。

**影响范围：**Redaxo CMS Mediapool Addon < 5.5.1

**漏洞危害：**高危

**漏洞ID：**暂无

**修复建议：**

1.严格检查用户上传的格式，建议改为白名单上传

2.严格检测用户上传内容，建议删除恶意内容

建议过滤用户输入的数据，切记用户的所有输入都要认为是不安全的。

 

**漏洞名称：**Microsoft Windows 10 - 子进程限制缓解绕过漏洞

**漏洞简介：**2018年6月13日，Windows平台发布了漏洞编号为CVE-2018-0982的安全漏洞，漏洞危害程度为中等（moderate）。Windows 10有一个缓解策略来限制创建新子进程的进程，其基本原理是避免从一些新的子进程中继承的其他缓解措施中逃脱出来，以及只能从新进程中利用的错误。该策略被强制作为标记中的一个标记，而不是允许在模拟期间跨进程边界传递限制的进程，这也会终止滥用WMI Win32\_Process和类似的进程。在进程创建期间，会在SeSubProcessToken中检查令牌标志，该标志为新进程创建新的主令牌，也可以指定一个标志来覆盖行为。

**影响范围：**Microsoft Windows 10

**漏洞危害：**中危

**漏洞ID：**CVE-2018-0982

**修复建议：**

1.在网页代码中需要对用户输入的数据进行严格过滤。

2.对用户令牌加强检测力度

建议过滤用户输入的数据，切记用户的所有输入都要认为是不安全的。
