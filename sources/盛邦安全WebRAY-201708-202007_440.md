2.每周漏洞热点

**漏洞名称：**Monstra CMS 3.0.4 - 远程代码执行漏洞

**漏洞简介：**2018年5月14日，PHP平台发布了漏洞编号为CVE-2018-9037的安全漏洞，漏洞危害程度为高等（higher）。Monstra CMS 3.0.4允许通过一个.zip文件的upload\_file请求远程执行代码，它会自动提取并可能包含.php文件。首先以具有页面编辑权限的用户身份登录，然后上传一个包含php webshell代码的插件存档，成功上传后，我们可以执行该命令。然后转到：http://127.0.0.1/plugins/{Name\_Of\_Zip\_File\_You\_Uploaded}/{File\_In\_Zip}.php。

**影响范围：**Monstra CMS 3.0.4  

**漏洞危害：**高危

**漏洞ID：**CVE-2018-9037

**修复建议：**在插件上传过程中过滤插件内容。

 

**漏洞名称：**Red Hat DHCP客户端脚本代码执行漏洞

**漏洞简介：**2018年5月15日12:00AM，Red Hat官方发布了漏洞编号为CVE-2018-1111的安全漏洞，漏洞危害程度为高等（higher）。在Red Hat Enterprise Linux的DHCP客户端软件包中包含的NetworkManager集成脚本中发现了命令注入漏洞。恶意DHCP服务器或本地网络上能够欺骗DHCP响应的攻击者可以使用此漏洞在使用NetworkManager的系统上执行具有root权限的任意命令，并配置为使用DHCP协议获取网络配置。

**影响范围：**Red Hat Enterprise Linux Server 6

Red Hat Enterprise Linux Server 7

**漏洞危害：**高危

漏洞ID：CVE-2018-1111

**修复建议：**

1、Red Hat 官方已经发布新版本修复了上述漏洞，用户应及时升级进行防护。

2、由于在 DHCP 的环境中，NetworkManager 是默认启用的，所以强烈建议受影响的用户尽快安装更新。

 

**漏洞名称：**XATABoost 1.0.0 - SQL注入漏洞

**漏洞简介：**2018年5月14日，PHP平台发布了安全漏洞，漏洞危害程度为高等（higher）。SQL注入攻击指的是通过构建特殊的输入作为参数传入Web应用程序，而这些输入大都是SQL语法里的一些组合，通过执行SQL语句进而执行攻击者所要的操作，其主要原因是程序没有细致地过滤用户输入的数据，致使非法数据侵入系统。

**影响范围：**XATABoost 1.0.0  

**漏洞危害：**高危

**漏洞ID：**暂无

**修复建议：**

1.不要信任用户的输入。对用户的输入进行校验，可以通过正则表达式，或限制长度；对单引号和双"-"进行转换等。

2.不要使用动态拼装sql，可以使用参数化的sql或者直接使用存储过程进行数据查询存取。

3.不要使用管理员权限的数据库连接，为每个应用使用单独的权限有限的数据库连接。

4.不要把机密信息直接存放，加密或者hash掉密码和敏感的信息。

5.应用的异常信息应该给出尽可能少的提示，最好使用自定义的错误信息对原始错误信息进行包装。
