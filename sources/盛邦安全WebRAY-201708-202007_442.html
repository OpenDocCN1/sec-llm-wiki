1.每周新闻热点

标题：甲骨文 Access Manager 现漏洞，黑客连管理员账号都能霸占

时间：2018-5-4

摘要：据外媒美国时间5月3日报道，来自 SEC 漏洞咨询实验室安全研究人员 Wolfgang Ettlinger 在甲骨文 Access Manager（以下简称 OAM）上发现了一个安全漏洞，黑客可以利用它远程绕过身份验证程序，接管任何用户的账号。如果黑客愿意，他们连管理员的账号都能霸占。

链接：http://t.cn/RuuztDX

 

标题：FacexWorm攻击加密货币交易平台，滥用Facebook Messenger进行传播

时间：2018-5-5

摘要：研究人员发现一种针对加密货币交易平台的攻击——FacexWorm攻击，该攻击通过Facebook Messenger进行传播。一小部分的用户受到这些恶意扩展到影响，Chrome在Trend Micro发出警告前就移除了部分恶意扩展。

链接：http://t.cn/RurDcEh

 

标题：Facbook承认用户账户有后门 部分工作人员可随时登录所有账户

时间：2018-5-6

摘要前不久Facebook因为剑桥分析的数据丑闻身陷窘境，扎克伯格本人也被美国国会要求参加听证会，并对他进行了长达数个小时的质问。

链接：http://t.cn/RuD1MYF

 

标题：日本多地佳能监控摄像头被“黑”，或因未改密码被钻空子

时间：2018-5-7

摘要：近日，日本佳能公司生产的网络监控摄像头被曝多次遭到外部的非法访问，甚至出现因遭到非法访问而无法操作的情况。

链接：http://t.cn/Rus5en9

 

标题：攻击者正利用已修复的 Drupal 漏洞挖掘数字货币

时间：2018-5-8

摘要：安全研究人员报告，攻击者正利用一个已修复的 Drupal 高危漏洞入侵网站植入挖矿脚本用访问者的计算机挖掘数字货币。被入侵的网站属于联想、UCLA 和美国全国劳资关系委员会等企业、大学和机构所有。

链接：http://t.cn/R37hTd5

 

标题：土耳其大学的计算机系统受到黑客攻击用于窃取加密货币，教育机构成为了黑客的主要目标

时间：2018-5-9

摘要：土耳其公共研究机构萨卡里亚大学的计算机系统受到黑客攻击以窃取加密货币。大学和学校是黑客的主要目标，因为他们的系统安全控制相对较差。此外，教育机构的多个计算机系统可以产生大量的计算能力。

链接：http://suo.im/5bpHWN

 

标题：美联社：俄罗斯黑客组织“奇幻熊”冒充IS黑客向美国军嫂发出死亡威胁

时间：2018-5-10

摘要：据美国CNBC财经频道报道，当美国陆军军嫂安吉拉•里基茨（Angela Ricketts）正在她位于科罗拉多洲的家中享受泡泡浴时，她的iPhone上出现了一条信息，发送者威胁要屠杀她的家人。

链接：http://t.cn/R3ytEYs

2.每周漏洞热点

漏洞名称：AMD和英特尔 - 硬件调试异常文档错误调用漏洞

漏洞简介：2018年5月8日，微软发布了漏洞编号为CVE-2018-8897的安全漏洞，漏洞危害程度为高等（higher）。因为某些架构中断、异常指令（即 MOV 到 SS 和 POP 到 SS）的开发人员对现有文档存在误读。技术上来说，漏洞即来源于操作系统和管理程序处理现代 CPU 中特定调试功能的方式。在某些情况下，在使用某些Intel x86-64体系结构指令后，指向较低环中的数据（对于大多数操作系统而言，内核Ring 0级别）的调试异常可用于在Ring 3中运行的操作系统组件。这可能允许攻击者利用操作系统API访问敏感内存信息或控制低级操作系统功能。

影响范围：

Apple、DragonFly BSD Project 、FreeBSD Project、Linux Kernel、Microsoft、Red Hat, Inc、SUSE Linux、Synology、Ubuntu、VMware  、Xen  

漏洞危害：高危

漏洞ID：CVE-2018-8897

修复建议： 在各供应商处自行下载安全更新文件。

 

漏洞名称：FTPShell客户端6.7 - 缓冲区溢出漏洞

漏洞简介：2018年5月8日，Windows平台发布漏洞编号为CVE-2018-7573的安全漏洞，漏洞危害程度为中等（moderate）。当FTP连接确认过程中最后发送目录时，如果目录的字符超过400个字节，将会引起程序崩溃。

影响范围：FTPShell Client 6.7

漏洞危害：中危

漏洞ID：CVE-2018-7573

修复建议：暂无修改意见

 

漏洞名称：Dell Touchpad - 'ApMsgFwd.exe'拒绝服务

漏洞简介：2018年5月10日，Windows平台发布了漏洞编号为 CVE-2018-10828的安全漏洞，漏洞危害程度为高等（higher）。属于戴尔触控板的ApMsgFwd.exe，ALPS触控板驱动程序，用于VAIO的ALPS定位设备，Thinkpad Ultranav Driver..etc 允许当前用户映射并写入“ApMsgFwd文件映射对象”部分。

ApMsgFwd.exe使用写入该部分的数据作为函数的参数。当无效指针写入映射部分时，会导致拒绝服务条件。

影响范围：ApMsgFwd 8.1. 0.44 

漏洞危害：高危

漏洞ID：CVE-2018-10828

修复建议：暂无修改意见
