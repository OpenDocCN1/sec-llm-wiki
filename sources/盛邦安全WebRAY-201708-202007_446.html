1.每周新闻热点

标题：新型恶意软件PyRoMine利用NSA漏洞 挖掘门罗币并禁用系统安全功能

时间：2018-4-27

摘要：安全公司Fortinet在本周二（4月24日）发表的博文中指出，他们的FortiGuard实验室研究团队最近发现了一种极具破坏性的新型恶意软件。它不仅会在受感染的Windows设备上部署门罗币矿工（XMRig），而且还会禁用Windows系统上的安全功能，这无疑会导致受感染设备暴露给其他网络威胁。之所以能够实现这些恶意功能，来源于它使用了一个由美国国家安全局（NSA）外泄的安全漏洞——永恒浪漫（EternalRomance）。

2.每周漏洞热点

漏洞名称：Apple macOS / iOS - 由于未遵守MIG所有权规则而导致的ReportCrash机械端口

漏洞简介：ReportCrash是负责制作意外用户空间进程意外转储的守护进程，大多数进程可以通过它们的异常端口（任务或主机级别）与ReportCrash通信。我们通常不会自己将消息发送到ReportCrash，但内核会在出现意外时代表您执行。但是，使用task_get_exception_ports或host_get_exception_ports MIG内核方法，即可获得ReportCrash的发送权限，恶意攻击者可以利用这些问题执行未经授权的操作，并获得提权。

影响范围：

Apple macOS 10.13.1

Apple macOS 10.13.4

Apple macOS 10.13.3

Apple macOS 10.13.2

Apple macOS 10.13

Apple macOS 10.12.6

Apple macOS 10.12.5

Apple macOS 10.12.4

Apple macOS 10.12.3

Apple macOS 10.12.2

Apple macOS 10.12.1

Apple macOS 10.12  

漏洞危害：中危

漏洞ID：CVE-2018-4206

 

漏洞名称：GPON路由器 - 身份验证旁路/命令注入

漏洞简介：2018年5月3日，Hardware平台发布漏洞编号为CVE-2018-10561、CVE-2018-10562的安全漏洞，漏洞危害程度为高等（higher）。身份认证绕过CEV-2018-10561：设备上运行的HTTP服务器在进行身份验证时会检查特定路径，攻击者可以利用这一特性绕过任意终端上的身份验证。命令注入CEV-2018-10562：该设备提供了诊断功能，通过ping和traceroute对设备进行诊断，但并未对用户输入进行检测，直接通过拼接参数的形式进行执行导致了命令注入，通过反引号“和分号;可以进行常规命令注入执行。

影响范围：所有暴露在互联网上的GPON家庭网关设备

漏洞危害：高危

漏洞ID：CVE-2018-10561、CVE-2018-10562

修复建议：

1、检查确认家用网关是否采用GPON，关闭设备对外访问功能。

2、积极与运营商沟通，获取运营商提供的应对措施。

 

漏洞名称：WordPress插件Form Maker 1.12.20 - CSV注入

漏洞简介：2018年4月30日，PHP平台发布漏洞编号为 CVE-2018-10504的安全漏洞，漏洞危害程度为高等（higher）。允许公共用户作为表单字段的一部分注入命令，并且当具有较高权限的用户以CSV格式导出表单数据时，它们在他们的机器上打开文件，该命令被执行。

影响范围：1.12.20和之前

漏洞危害：高危

漏洞ID：CVE-2018-10504

修复建议：升级到版本1.12.24
