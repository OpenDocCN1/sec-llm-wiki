# 盛邦安全亮相2017CERNET学术年会 为高校信息化建设贡献力量

2017年11月20-23日，"中国教育和科研计算机网CERNET第二十四届学术年会暨会员代表大会"在山东济南隆重召开。本次会议按照国家推进"互联网+"行动的指导意见，就推进教育信息化的网络和信息安全、云计算、教育大数据、IPv6新一代校园网络技术和应用、以及教育信息化与校园网的发展等专题进行了广泛的学术交流。

  

![](../Images/1b5d6778d39de50aef80ac2db9222097.png)

  

十余家国内外计算机和网络安全优秀厂商出席此次会议，为助力高校发展、创建信息化创新一流大学，全方位展示科研成果。盛邦安全受邀并携高教信息化创新高科技产品出席此次盛会。

  

在会议中，盛邦安全的明星产品“RayGate Web资产安全综合治理平台”以及具备“移动端一键断网”应急处置功能的“RayWAF 6.1.2最新版本”一经展出就备受瞩目。“Web资产安全综合治理平台”格外契合高校目前在面临政府监管日趋严格、外部黑客攻击愈发猖獗、内部滥用十分频发的网络安全环境下的实际需求。不仅满足了高校网络安全运维的技术需求，也实现了网站群的闭环管理，尤其在清理“僵尸网站”与“双非网站”中真正有效的实践运用更是引起了各高校老师的重点关注，被一致认为是本次会议的明星产品，同时也是目前整个安全行业认可的产品。这款明星产品的出现，也正是盛邦安全入选2017【中国大数据安全】IDC创新者的不二理由。会议现场，盛邦安全的技术专家随时解答各高校老师关于产品和技术的问题，并且进行了设备和系统的具体操作演示，热情的互动交流让盛邦安全的展台不时成为全场最受欢迎的展台之一。

  

![](../Images/c88a8ce0aafc9fcc378669d6a4ce9b65.png)![](../Images/385f4d80f4827ae3b60c4f391b02cee3.png)

  

当前世界范围内教育信息化飞速发展，以教育信息化推动教育现代化，加快我国从教育大国向教育强国迈进，是我们必须认真思考和面对的时代课题。作为国内Web安全领域的卓越厂商，盛邦安全也本着科技创新的原则，将科技情怀落地，用优秀的信息化创新产品和解决方案，为高校信息化基础建设贡献自己的力量。
