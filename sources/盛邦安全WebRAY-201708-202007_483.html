挖矿机这个名字相信大家已经越来越熟悉，但网页版的挖矿机大家有没有见过呢？


近日我们发现了这样一款以JavaScript脚本形式存在于网页中的挖矿机。在该脚本代码被嵌入的网站页面中，一旦用户打开该网站，浏览器便会按照脚本的指令变成一个门罗币挖矿机。这一行为，完全没有告知用户，更没有经过用户的同意，而这一段附加的挖矿代码通常因为大量占用CPU，使用户的计算机变得异常卡顿甚至无法正常使用。

 

通过查看该网站的源码，我们很容易地发现网页被嵌入了Coinhive JavaScript Miner代码。该代码是基于CryptoNight挖矿算法编写，该算法可以产出CryptoNote类网络货币，如Monero(门罗币)、Dashcoin(达世币)，DarkNetCoin(暗网币)等。而当前嵌入的这个Coinhive JavaScript Miner则仅支持门罗币的挖矿。

 



利用在网站中插入挖矿脚本来实现流量变现正在成为一股不可阻挡的势力，因为这显然比网站的展示广告有着更加直接可观的收益。挖矿的巨大利润势必会让许多站长效仿以及黑客们趋之若鹜。盛邦安全和Panabit此次联手打击挖矿黑产行为，保护广大网民的体验和权益。


盛邦安全对参与挖矿的网站进行分析，发现黑产实施过程及危害。



检测篇


盛邦安全可对被检测网站进行周期性扫描、分析，发现网站问题。


盛邦安全所有检测类产品均已更新规则库，可对网站进行主动检测、扫描、发觉网站是否被嵌入挖矿代码，并在第一时间发起告警。




 Panabit可检测到被入侵的客户端，并检测其受影响的程度。


Panabit通过日志查询功能，可对网内所有客户端进行域名（coinhive.com以及coin-hive.com）排查，有访问该域名行为的客户端即为被入侵的客户端；同时，通过访问该网站的源IP统计，发现受害IP占整体网络的比例，可判断出内网受影响情况。


通过对域名的排查，快速找到源IP



Panabit通过源IP可推导出有可能被入侵的网站。


Panabit通过日志导出功能，可导出源IP的会话日志，通过会话日志可快速找到源IP访问挖矿脚本源网站域名的会话时间，对该会话之前会话日志进行排查，可查出可能被入侵的网站。


通过Panabit会话日志，可清晰看到源IP访问挖矿脚本源网站的详细记录



处理篇


盛邦安全根据对用户的网站进行检测的结果，评估网站代码情况，帮助站长处理问题。


盛邦安全检测类产品如发现网站存在挖矿脚本，将发起告警，提示站长删除问题代码，从而从根本上断绝网站被迫参与挖矿行为的可能性。




 Panabit对用户进行DNS重定向，防止用户进行挖矿行为。


通过Panabit DNS重定向功能，对挖矿脚本源网站域名的DNS解析进行决绝（禁止用户访问域名coinhive.com以及coin-hive.com），这样一来就彻底阻断了客户端与挖矿网站的相互访问，就算客户端被感染，也不会进行任何挖矿行为。
