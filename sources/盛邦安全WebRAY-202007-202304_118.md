**实力入选丨盛邦安全成为首批“网络安全能力评价工作组”成员单位**

为落实《“十四五”信息通信行业发展规划》部署要求，大力推动网络安全产业创新发展，强化网络安全产业供需对接，加强网络安全创新示范应用，繁荣网络安全产业生态，中国信通院在2022年初启动“网络安全能力评价工作组”成员单位征集工作并于近日公布第一批工作组成员单位信息，盛邦安全实力入选首批“网络安全能力评价工作组”成员单位，将参与体系研究、标准研制和示范推进三个工作组的相关工作。

**《银行保险监管统计管理办法（征求意见稿）》发布，线上化信息收集和填报成为规定动作**

**CVSS评分策略分析及近年来满分漏洞盘点**

 近两年正如许多安全公司的研究员亲身经历的那样，网络攻击量显著增加，重大漏洞被相继爆出并伴随着在野利用。如去年年底的log4shell（CVE-2021-44228）和今年爆出的spring4shell（CVE-2022-22965）在安全圈里都掀起了不小的风浪。由于在分析spring漏洞时cve编号还没有出来，自评影响力也没那么“核弹级”，后续就没怎么关注这个漏洞的。最近突然想看看这个漏洞的CVSS评分，看看官方是怎么给这漏洞做影响力定义的。查看后发现该漏洞CVSSV2.0评分为7.5，CVSS3.1的评分为9.8。那么CVSS的评分依据究竟是什么？2.x和3.x的评分标准区别在哪？是否分数越高就表示漏洞危害越大？近年来又有哪些CVSS评分为满分的漏洞？本篇文章想就这些问题跟大家简单聊一聊。 [阅读全文](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269615&idx=1&sn=806e8d90885d3470f40f3121fcb3aca0&scene=21#wechat_redirect)[](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269615&idx=1&sn=806e8d90885d3470f40f3121fcb3aca0&scene=21#wechat_redirect) **Microsoft多个安全漏洞风险提示**

  

近日，WebRAY安全服务产品线监测到Microsoft官网发布了5月安全更新，本次共发布了包含Windows LDAP、Microsoft SharePoint Server、Windows Print Spooler、Windows Network FileSystem等产品在内的74个漏洞补丁。  
[阅读全文](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269638&idx=1&sn=0c6cb891f44091c211ab827809ac10dc&scene=21#wechat_redirect) **Laravel远程代码执行漏洞（CVE-2021-43503）风险提示**

 

近日，WebRAY安全服务产品线监测到Laravel官方发布Laravel远程代码执行漏洞，漏洞编号为CVE-2021-43503。在Laravel开启Debug模式的时候，由于某些函数过滤不严格，攻击者可以通过构造恶意文件等方式触发反序列化漏洞，从而执行任意命令控制服务器。 [阅读全文](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269646&idx=1&sn=fd86f832aaae57f1db52aa8ce3566e85&scene=21#wechat_redirect)[](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269646&idx=1&sn=fd86f832aaae57f1db52aa8ce3566e85&scene=21#wechat_redirect) **VMware Workspace ONE Access身份验证绕过、本地提权漏洞风险提示** 近日，WebRAY安全服务产品线监测到VMware官方发布安全公告，修复了两个存在于VMware Workspace ONEAccess产品的漏洞。    [阅读全文](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269682&idx=1&sn=6f6aef697d4ae8c0e8a1c7044ac00f67&scene=21#wechat_redirect) **Fastjson反序列化漏洞风险提示** 近日，WebRAY安全服务产品线监测到Fastjson官方发布公告，修复了一个存在Fastjson1.2.80版本以及之前的版本的反序列化漏洞。  [阅读全文](https://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650269734&idx=1&sn=10e3cf67223e69cff1bee2fe5f24a479&scene=21#wechat_redirect)
