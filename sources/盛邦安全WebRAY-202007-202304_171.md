# 世事多变，唯有守护不变 ——致所有心中有爱的人

星光璀璨，人间浪漫。

  

月上柳梢头，人约黄昏后。  
是相约与相见的浪漫。  
  
蓦然回首，那人却在，灯火阑珊处。  
是寻找和等候的浪漫。  
  
我养你啊~  
是承担责任与面对现实的浪漫。  
  
如果上天能够给我一个再来一次的机会，  
我会对那个女孩子说三个字：我爱你……  
是遗憾错过和难以忘怀的浪漫。  
  
无论是在现实空间  
还是在虚拟的网络空间  
都愿你能遇到那个心系彼此、双向奔赴的人。  

**#世事多变，唯有守护不变#**
