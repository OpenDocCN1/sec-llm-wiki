# 烽火狼烟丨Apache APISIX Dashboard未授权访问漏洞（CVE-2021-45232）通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650268688&idx=2&sn=4a7b278e68aa160e9e75cdfc6be12d7d&chksm=83206964b457e072afd32518bfaa2b3e1c235f7c7a831b3376a0b7426d4f6b79c1f56121f783&scene=126&sessionid=1681374491#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650268688&idx=2&sn=4a7b278e68aa160e9e75cdfc6be12d7d&chksm=83206964b457e072afd32518bfaa2b3e1c235f7c7a831b3376a0b7426d4f6b79c1f56121f783&scene=126&sessionid=1681374491#rd)

  

**漏洞概述**

  
近日，WebRAY安全服务部监测到Apache官方发布Apache APISIX Dashboard未授权访问漏洞，漏洞编号为CVE-2021-45232。在Apache APISIX Dashboard中，Manager API在gin框架的基础上引入了droplet框架，其中所有的API及鉴权中间件都是基于droplet框架，但是部分API使用了gin框架的接口，从而绕过了身份认证。攻击者无需登录 Apache APISIX Dashboard即可访问某些接口，从而进行未授权更改或获取 Apache APISIX Route、Upstream、Service等相关配置信息，并造成SSRF、搭建恶意流量代理和任意代码执行等问题。由于该漏洞影响较大且利用脚本已被公开，WebRAY安全服务部建议受影响客户及时更新。  
  
Apache APISIX是一个动态、实时、高性能的API网关，基于Nginx网络库和etcd实现，并提供负载均衡、动态上游、灰度发布、服务熔断、身份认证、可观测性等丰富的流量管理功能。  
WebRAY安全服务部也将持续关注该漏洞进展，第一时间为您更新该漏洞信息。

**漏洞等级**

  
WebRAY安全服务部风险评级：高危  

  

**修复建议**

  
1、厂商已发布升级修复漏洞，请及时更新至Apache APISIX Dashboard 2.10.1及以上版本。下载地址：https://github.com/apache/apisix-dashboard/releases2、若无法更新，建议用户及时更改默认用户名与密码，并限制来源IP访问Apache APISIX Dashboard。
