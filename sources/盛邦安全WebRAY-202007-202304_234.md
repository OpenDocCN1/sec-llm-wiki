# 安全周精彩瞬间丨主动防御、网安国安——盛邦安全全面参与2021国家网络安全宣传周活动

**10月11日至17日，主题为“网络安全为人民，网络安全靠人民”的2021年国家网络安全宣传周在全国范围内统一开展，盛邦安全全面参与此次国家网络安全宣传周活动，在西安主会场及全国多地网络安全展览展示、主题论坛等活动中精彩亮相。**

  

**中国网络安全产业联盟专家组**

**走进盛邦安全西安研发中心**

  

安全周期间，中国网络安全产业联盟专家组一行莅临盛邦安全西安研发中心参观交流，与盛邦安全CEO权小文等就网络安全行业面临的问题与挑战、重点技术领域创新和企业发展等话题进行了深入的交流。

  
![](../Images/0ca657ea53cd94c5b0daa90d63300c58.png)  

盛邦安全为联盟专家组的专家们详细介绍了公司11年的发展历程以及未来几年的重点发展方向。权小文谈到，公司经过技术产品化、产品场景化和安全服务化几个发展阶段，近年来在网络空间地图、网络空间资产测绘等领域的研发投入不断加大，**历经数年打磨形成了针对全球互联网的快速探测、精准识别、深度分析与直观展示的网络空间地图测绘平台。**

  
![](../Images/5d91daf46f62bdb7ef2632608330c6c0.png)  

**承办“2021年网络安全优秀创新**

**成果大赛”总决赛并获得创新产品优秀奖**

  

10月10日，“2021年网络安全优秀创新成果大赛”总决赛在陕西宾馆成功举行。大赛作为国家网络安全宣传周重要活动之一，由中国网络安全产业联盟（CCIA）主办，旨在推选我国网络安全产业优秀创新成果，激发网络安全企业加强自主创新能力，搭建网络安全企业、技术、人才和资本合作的平台，推进网安产业结构化升级，推动网络安全产业高质量发展。**盛邦安全网络安全单兵侦测系统荣获“2021年网络安全优秀创新成果大赛”创新产品优秀奖。**

  
![](../Images/c2a3f2f1fe73614ad8b8ae18584d685f.png)![](../Images/f4cde5f99650e38de3de2aef7ca63176.png)  

**承办2021年国家网络安全宣传周**

**“网络安全产业发展论坛”并发表主题演讲**

  

2021年10月11日，由陕西省委网信办，西安市委网信办指导，中国网络安全产业联盟、中国电子技术标准化研究院主办、盛邦安全等单位承办的2021年国家网络安全宣传周“网络安全产业发展论坛”在陕西西安成功召开。**盛邦安全CEO权小文应邀出席并发表供应链安全相关主题演讲。**

  
![](../Images/f2201cc0fda7ea679ed89dc899776410.png)  

**精彩亮相2021年国家网络安全宣传周**

**网络安全博览会现场**

  

盛邦安全作为国家网络安全保障的坚实力量之一，盛装亮相本届博览会现场。**此次盛邦安全重点展出的是网络空间地图测绘系统，可针对全球互联网可实现快速探测、精准识别、深度分析与直观展示；**通过绘制高清网络空间地图，分析网络空间“地形地貌”，洞察安全风险，及时掌握攻防态势，是构筑大安全体系的重要基础层。

  
![](../Images/ef03646712d5757a046242cca8744073.png)![](../Images/06f44a9712fb9e77dc46d98c0ce2c981.png)![](../Images/3941d02098f000a773988c365143405d.png)  

“网络空间地图测绘还有很多应用场景值得深入耕耘与推广，例如，网络攻防中的沙盘推演、互联网安全监管中的“挂图作战”、智慧城市感知与运营、大型企业网络资产治理等等，其应用范围和重要价值已经受到越来越多的关注和重视。”盛邦安全技术负责人在网安周博览会现场谈到。

  
![](../Images/df2961a6d5f38ad9d6888dfc7c488201.png)盛邦安全西安子公司总经理许迅飞接受当地电视台采访  

**全面参与各地网络安全宣传周活动**

  

网安周活动在全国各地陆续开展，盛邦安全在山东、河北、安徽、江西等多地亮相，积极参与宣传网络安全常识教育，加强网络安全意识培养，并展出了一系列创新安全产品与技术，受到现场高度关注。

作为在网络空间地图技术、供应链安全、应用防御技术和脆弱性检测技术等领域的国内领先的网络安全产品及服务供应商之一，本次全面参与国家网络安全宣传周活动，盛邦安全充分展示了创新的产品技术能力和公司综合实力。未来，盛邦安全将继续专注“两精一深”的发展战略，不断优化产品、服务与解决方案，充分利用和发挥自身产品技术优势，为我国建设网络强国保驾护航。
