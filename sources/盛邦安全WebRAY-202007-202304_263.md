# 喜讯 |盛邦安全入选上海市通信管理局2021年网络安全支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650267493&idx=1&sn=5dce8be3e6475faf61b8a0e260f9932a&chksm=83205211b457db07d6216a00dc8ce620a7a3a63957f173a154bf83cd1ffaf880b9f6249a1d6d&scene=126&sessionid=1681374516#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650267493&idx=1&sn=5dce8be3e6475faf61b8a0e260f9932a&chksm=83205211b457db07d6216a00dc8ce620a7a3a63957f173a154bf83cd1ffaf880b9f6249a1d6d&scene=126&sessionid=1681374516#rd)

近日，上海市通信管理局发布了关于2021年网络安全支撑单位选拔结果，经自主申请、材料初审和专家复审等环节，市通信管理局评选产生了网络安全支撑单位35家，其中一级支撑单位11家，二级支撑单位24家。各支撑单位资格的有效期为2年。**盛邦安全成功入选二级支撑单位。**  

  

入选名单公告如下（同级别以笔画顺序排序）：

  

![](../Images/dc39a33fc186f4e3c0e8f1d55ef31a53.png)

  

作为国家网络安全保障的中坚技术力量之一，盛邦安全曾参与上海世博会、广州亚运会、世界互联网大会、反法西斯战争胜利七十周年、G20峰会、一带一路国际合作高峰论坛、第十三届全运会、金砖五国峰会、党的十九大会议、新中国成立70周年庆祝活动、上合青岛峰会等重大活动网络安全保障工作。

  

未来，盛邦安全将再接再厉，不断提升自身技术与产品创新能力，在网络安全应急响应、重要活动安全保障、信息报送等方面发挥更大的作用，贡献自己的一份力量。
