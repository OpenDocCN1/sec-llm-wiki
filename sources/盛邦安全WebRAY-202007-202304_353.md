# 盛邦安全入选中国电力发展促进会网络安全专业委员会首批会员单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650265734&idx=1&sn=593a347db108b6b3a47a8203cda84606&chksm=832055f2b457dce49db361bed1f1e18385608d2f06c6027bb398c96c7def04a505aba8823b13&scene=126&sessionid=1681374557#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650265734&idx=1&sn=593a347db108b6b3a47a8203cda84606&chksm=832055f2b457dce49db361bed1f1e18385608d2f06c6027bb398c96c7def04a505aba8823b13&scene=126&sessionid=1681374557#rd)

2021年3月24日，中国电力发展促进会网络安全专业委员会（以下简称”专委会”）成立大会在北京召开。盛邦安全作为专委会首批会员单位出席会议。

  

![](../Images/8d0570c92a3097a62cfce46415e82708.png)在国家能源局、工信部、公安部、国家电网公司的大力支持和众多电力企业、安全企业和科研高校的积极协助下，在活动现场正式宣告成立以电力企业为主体、产学研用单位广泛参与的网络安全专委会。作为电促会的分支机构，专委会由国网信通公司担任会长单位和秘书长单位，国家信息技术安全研究中心、国家工业信息安全发展研究中心等8家单位担任副会长单位，电力企业、科研高校和安全公司等34家单位成为会员单位。盛邦安全凭借在电力能源行业出色的技术能力和行业经验入选首批会员单位并出席活动现场。  
  
![](../Images/6102693dff3117bc275befd6550e98a5.png)

  

随着有组织、集团化的网络攻击将越来越普遍，对社会和经济造成的危害和影响也将更加巨大。我国的网络安全建设正在由被动防御向“主动防御、纵深防御、精准防护、整体防控、动态防御、联防联控”的安全体系构建方向转变。盛邦安全结合“实战化、体系化、常态化”的主动防御需求趋势，在应用安全检测和安全防御两大核心安全基础能力上，结合电力能源行业的实际应用需求，先后推出了网络安全单兵侦测系统（RayBox）、电力行业网络安全应急指挥平台解决方案、电力物联网终端安全治理方案等一系列行业创新产品和解决方案。未来，盛邦安全将在专委会的带领下，与各成员单位积极沟通，密切配合，共同面对新型电力系统建设过程中的网络安全挑战，为保障我国电力能源行业系统的安全稳定运行做出贡献。
