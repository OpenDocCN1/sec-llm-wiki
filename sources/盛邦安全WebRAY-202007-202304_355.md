# 烽火十八台丨人行金融业科技信息综合管理平台接入报送，Yes We Can~

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650265716&idx=1&sn=428b411e6acfd931d88f28d898cad98a&chksm=83205500b457dc167794c5962b3bfc3c2fe718ba7eddfa00fcca0317f478513ac2094435c0a2&scene=126&sessionid=1681374557#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650265716&idx=1&sn=428b411e6acfd931d88f28d898cad98a&chksm=83205500b457dc167794c5962b3bfc3c2fe718ba7eddfa00fcca0317f478513ac2094435c0a2&scene=126&sessionid=1681374557#rd)

**方案背景**

为提高我国金融行业科技信息数字化管理水平，促进金融业科技信息共享交流，全面掌握我国金融业信息化建设情况，人民银行科技司组织建设了金融业科技信息综合管理平台。该平台发布了金融业相关数据接入规范，并要求相关金融机构陆续接入平台实现数据的收集。

  

数据采集范围将包括各家金融机构的基础设施、基础软件、应用系统等，《金融业信息科技综合管理平台数据采集范围-属性清单》对采集范围进行了明确的说明。按照人民银行要求，金融业科技信息综合管理平台采用一点接入模式，各金融机构直接对接平台并负责报送相关数据。

  

**解决****方案**

  

盛邦安全基于自主开发的信息科技风险管理信息化平台，根据《金融业科技信息综合管理平台接入技术规范》以及《属性清单》，定制开发了满足各金融机构对接平台的数据上报工具模块，方便金融机构通过信息化手段完成数据上报监管要求，工具简单易用，方便金融机构进行线上的增删改查等基本操作；同时平台具备灵活的扩展性，可以同行内相关管理系统进行集成，自动抽取数据并完成报送。

  

**功能介绍**

目前报送工具主要包括新建报送、数据填报、数据上报、报送记录查询、报送指标管理等基础功能。

**客户收益**

*   支持标准格式数据导入，方便灵活。
    
*   简单易用，性价比高，可快速满足平台数据报送监管要求。
    
*   可加入流程管控，提升填报数据准确性，借助流程管控和前期数据自动比对，可以快速定位填报差错，确保最终填报数据的准确性。
    
*   可同现有数据源集成，实现数据提取和报送的自动化实现。
