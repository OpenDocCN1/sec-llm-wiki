01

漏洞概述


Jumpserver 是全球首款完全开源、符合 4A 规范（包含认证Authentication 、授权 Authorization、账号 Accounting 和审计 Auditing）的运维安全审计系统。2021年1月15日，WebRAY安服人员监测到Jumpserver官方发布了一条安全通告，Jumpserver存在远程命令执行漏洞，请相关用户尽快进行修复。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。



02

影响版本



03

漏洞等级


WebRAY安全服务部风险评级：高危


04

修复建议


1、临时修复建议：
修改Nginx配置文件，以屏蔽漏洞接口：
Nginx配置文件位置如下：
社区老版本
/etc/nginx/conf.d/jumpserver.conf
# 企业老版本
jumpserver-release/nginx/http_server.conf
# 新版本在
jumpserver-release/compose/config_static/http_server.conf
 
Nginx配置文件实例为：
### 保证在/api 之前 和 / 之前
location/api/v1/authentication/connection-token/ {
   return 403;
}
 
location/api/v1/users/connection-token/ {
   return 403;
}
### 新增以上这些
修改配置文件完毕后，重启Nginx服务即可。

2、建议JumpServer堡垒机用户升级至安全版本。
安全版本如下：
JumpServer堡垒机＞=v2.6.2版本
JumpServer堡垒机＞=v2.5.4版本
JumpServer堡垒机＞=v2.4.5版本
