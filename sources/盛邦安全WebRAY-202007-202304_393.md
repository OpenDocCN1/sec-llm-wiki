# 烽火狼烟丨JumpServer远程命令执行漏洞风险提示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650265077&idx=1&sn=6fc4bea252b6d49a1dacd9a0e3085827&chksm=83205881b457d197b5f04999586e9fbc1e9de42d488ce98078a6f1c6230567b6aeaf5e23034c&scene=126&sessionid=1681374572#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650265077&idx=1&sn=6fc4bea252b6d49a1dacd9a0e3085827&chksm=83205881b457d197b5f04999586e9fbc1e9de42d488ce98078a6f1c6230567b6aeaf5e23034c&scene=126&sessionid=1681374572#rd)

  

**01**

**漏洞概述**

  

Jumpserver 是全球首款完全开源、符合 4A 规范（包含认证Authentication 、授权 Authorization、账号 Accounting 和审计 Auditing）的运维安全审计系统。2021年1月15日，WebRAY安服人员监测到Jumpserver官方发布了一条安全通告，Jumpserver存在远程命令执行漏洞，请相关用户尽快进行修复。WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。  

  

  

**02**

**影响版本**

  

![](../Images/2a320d116cbaff8eaf46c1d5cba33fa7.png)

  

**03**

**漏洞等级**

  

WebRAY安全服务部风险评级：高危

  

**04**

**修复建议**

  

1、临时修复建议：修改Nginx配置文件，以屏蔽漏洞接口：Nginx配置文件位置如下：社区老版本/etc/nginx/conf.d/jumpserver.conf\# 企业老版本jumpserver-release/nginx/http\_server.conf\# 新版本在jumpserver-release/compose/config\_static/http\_server.conf Nginx配置文件实例为：\### 保证在/api 之前 和 / 之前location/api/v1/authentication/connection-token/ {   return 403;} location/api/v1/users/connection-token/ {   return 403;}\### 新增以上这些修改配置文件完毕后，重启Nginx服务即可。  
2、建议JumpServer堡垒机用户升级至安全版本。安全版本如下：JumpServer堡垒机＞=v2.6.2版本JumpServer堡垒机＞=v2.5.4版本JumpServer堡垒机＞=v2.4.5版本
