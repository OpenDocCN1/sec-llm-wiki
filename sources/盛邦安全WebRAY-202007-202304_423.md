# 《瞄准》剧情新解

暗流涌动的6月，天气闷热异常，刚刚解放的Y市街头车水马龙，行人匆匆，表面看似热闹非凡，但暗地里敌对势力活动频繁，一场交锋正在悄然逼近。

**01**

**【兰府大厅】**

兰府的会客厅里，此时已挤满了人，一位年过四十的汉子眉头紧锁，犀利的双眼中此刻却布满血丝，正在一旁焦灼地来回踱步，手里的烟都燃掉了一半。汉子叫做老顾，是市局领导任命的行动组长，负责此次保障行动的安全指挥，根据早先截获的电文，此次敌人将派出经验丰富的洪小队对兰先生实施暗杀行动，兰先生是极具声望的和平人士，如果此次暗杀成功，将对整个战局带来致命的打击。

 

老顾戎马半生，战场上的严酷本已让他磨练出一身本领和超乎常人的意志力，但此次的对手洪小队却是恶名远扬，根据情报，在这支队伍当中既有伪装高手，又有狙击枪手，最可怕的是他们平常都潜伏在各行各业当中，不断收集各种信息，防不胜防。总而言之，此次的较量本身就不对等，敌人只需攻破一个点就能达到目的，而防守则需要面面俱到、没有失误，饶是经验丰富的老顾，此刻心里也是七上八下，所以这次行动，除了本市已有的安保力量，老顾还特别申请了兄弟部队进行协助，并且请到了一位神秘人物Ray来当教官，据说这位Ray教官曾多次阻止洪小队的行动，也是一个狠人。

老顾：Ray教官还没到？

副手：还没。

老顾：算了不等了，我们直接开始布置。

老顾说完猛吸一口烟，将烟头重重的砸在地上，指着墙上的作战地图说道。

老顾：小李，你在阁楼蹲点，守住制高点；小王，在兰先生屋子隔壁守着，把好最后一道门；方队长，你的人在大门口放四个，楼门口放四个，屋外八个人巡逻，屋里四个人巡逻，都是8小时换班一次。  

众人：收到！

  

**02**

**【洪队基地】**

三公里外一间咖啡厅的地下室里，洪小队也在秘密开会，为首的老洪目若鹰隼，一众人员围坐在茶几旁，一侧的柜子里，各种精密的武器型号多样、数量惊人。

老洪：打探的怎么样啊？

刀子：都摸清了。蓝家的厨子这几天去买菜的时候比平常多买十几斤，说明他们至少有三十多人；我这两天扮成收废品的，每天来回观察几趟，发现大门口和楼门口都有站岗的，院子里还有一队巡逻的；这几天牙科诊所的赵大夫去兰府瞧过病，有天晚上我扮成看戏的在戏园子里找他打听到，兰府屋子里也有巡逻的。

老洪：棍子你怎么看啊？

棍子：老大，除了明面上这些，兰府楼顶和主人屋子旁边肯定也有暗哨，这次对手算是重兵把守啊。

棍子眯起眼来，笑着继续道。

棍子：不过，这也给我们提供了机会，人多就会有破绽，百密一疏，我们只需要耐心寻找，肯定能找到机会。

老洪：哈哈，好。那就按老规矩，五天后你们想办法混进兰府，伺机行动；我在钟楼顶上守着，一有机会就给我信号。

众人：是！

  

**03**

**【兰府大院】**

三天后，兰府，一位中年男子行色匆匆的赶来，正是有事耽搁晚到几天的Ray。

  

老顾带着Ray教官，边巡查边将此次的保障计划做了详细介绍，Ray教官的脸色也从开始的歉意慢慢变的凝重起来。

Ray：不行老顾，你这个安排有问题。

Ray教官衣着朴素，眼神却透着一股坚定和锐利，老顾不由得更加紧张起来。

Ray：你这个部署，看似层层防守，重兵把控，但实际上漏洞很大。首先，知己知彼方能百战不殆，你们对兰府结构摸的很清，但对人员掌控不足，比方说府内人员的活动跟踪、外来人员的安全限制，都不彻底，必须要再仔细核实一遍，发现可疑人员及时报告；其次，人员安排不是越多越好，你这一大帮人互相之间是否熟悉、府里和安保人员互相是否了解、晚上光线暗淡大家是否能彼此看清，这些都是问题，万一有敌人伪装之后混进来或者突破某个点再进行冒充，剩余防线就不攻自破了，所以依我看，关键位置放合适的人选，数量足够就可以，保留楼顶、屋内和各个门口的岗哨，巡逻的人里外各留两位就可以，彼此要绝对熟悉、事现约定暗号，发现异常立即预警；最后，你这张图挂这儿干嘛？作战地图需要放在绝对安全的地方，你挂在明面上不是给敌人看的吗。

说罢，Ray将大厅里的作战地图摘下收起递给了老顾。众人听Ray教官一番话，这才意识到之前的部署破绽很大，老顾激动的握着Ray的手，感慨不已。

  

**04**

**【钟楼之顶】**

两天后的晚上，钟楼顶上，一身大衣包裹的老洪从瞄准镜中注视着兰府的动态，扮作厨子的棍子已经进去了一下午，一点动静都没有；买通的兰府园丁也没有按照约定把作为信号的兰花摆到兰先生房间窗口；就连假扮成牙医的刀子也被拦在门外，无功而返；其他人根本绕不开门口守卫的视野，稍做试探就会引起里外所有守卫的警觉，无计可施。

老洪的心越想越凉，败了败了，底数清晰、内外网监控、纵深防御、应急响应，看来是有高手部署，只能再找机会了。想到这，他艰难的取下了卡在指针上的子弹。

  

**05**

**【兰府】**

“铛铛铛......”随着黑夜里一阵洪亮的钟声，洪小队剩余人马果断撤离，这是他们撤退的暗号。兰府的一间屋子里，老顾和Ray教官等人看着绑在一旁的棍子等人，松了一口气，看看表，零点已经过了五分钟。

较量仍在继续，黎明终将到来。
