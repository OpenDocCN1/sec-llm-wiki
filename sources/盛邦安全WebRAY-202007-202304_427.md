# 烽火狼烟丨Ubuntu组合漏洞获取root权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650264500&idx=1&sn=2a558ffb7b31a34e0d402ed2d240472d&chksm=83205ec0b457d7d63de607986d983bceb7872139479000c1fd60bcfc6a90cc8cbe8360c107f3&scene=126&sessionid=1681374582#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650264500&idx=1&sn=2a558ffb7b31a34e0d402ed2d240472d&chksm=83205ec0b457d7d63de607986d983bceb7872139479000c1fd60bcfc6a90cc8cbe8360c107f3&scene=126&sessionid=1681374582#rd)

近日，WebRAY安全服务部在互联网上发现成功利用Ubuntu的accountservice拒绝服务漏洞（CVE-2020-16127）和gdm3特权升级漏洞（CVE-2020-16125）获取root权限这一严重安全问题。  
攻击者通过简单的更改语言、关闭进程等操作，即可添加拥有管理员权限的新账号。该漏洞通过拒绝accountservice服务使得accounts-daemon崩溃后，利用gdm3检测accounts-daemon超时从而启动系统初始化操作来实现管理员权限账号的获取。该漏洞对桌面版的Ubuntu危害巨大，对于命令行界面的Ubuntu虽暂无影响，但建议所有Ubuntu用户尽快安装更新。  
WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。  

  

**漏洞概述**

利用Ubuntu的accountservice拒绝服务漏洞（CVE-2020-16127）和gdm3特权升级漏洞（CVE-2020-16125）获取root权限。  

  

**漏洞基本信息**

| 产生原因 || 组合漏洞 |
| --- | --- |
| 影响范围 || 包含20.10以及20.04、18.04、16.04三个LTS在内的在维护版本 |
| 漏洞ID || 暂无 |
| 分类 || 利用拒绝服务攻击获取系统权限 |

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危  

  

**修复建议**  

请及时关注官方网站并更新补丁：https://ubuntu.com/security/notices/USN-4616-2https://ubuntu.com/security/notices/USN-4614-1
