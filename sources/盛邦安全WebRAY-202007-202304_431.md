# 光明网报道丨网络空间测绘技术将如何构建“网络空间地图”

　文/光明网记者 李政葳  
　　“网络测绘是发现、度量、掌握网络价值的重要工具。目前，网络测绘仍然有大量空白领域有待研究。”针对“网络测绘”概念，在近日举行的2020年全国首届网络空间测绘大会上北京邮电大学计算机学院副教授李昕这样说。  
　　网络空间被认为是继陆、海、空、天之后的国家主权的第五空间。网络空间蕴含着大量涉及国计民生相关的信息资产，如何更好地保护这些信息资产，了解这些信息资产状态，不仅要静态测量，更需动态测量。  
　　在业界看来，与人类所处的物理空间不同，网络空间边界相对模糊，无论是网络管理部门还是网络运维部门，都迫切需要类似地理空间地图的“网络空间地图”，用来全面描述和展示网络空间资产、网络空间各要素及要素之间关系，以及网络空间和现实空间的映射关系。  
　　“构建网络空间地图技术即网络空间测绘技术便应运而生了。”公安部第一研究所信息安全部副主任胡光俊说。  
　　何为网络空间测绘技术？记者了解到，该技术是通过网络测量、网络实体定位和网络连接关系及其他相关信息的可视化等理论和科学技术手段，对网络空间进行真实描述和直观反映的一种创新技术。网络空间测绘目标是实现对来源众多、类型各异的网络空间资源的全面测绘，是实现网络空间资产摸底的重要手段。  
　　在胡光俊等业界人士看来，这一技术汇集了网络技术、协议分析技术、大数据技术、应用安全技术、可视化技术的综合性创新性技术，需要模块化、标准化研究，也需要产业界和学术界共同研究，制定网络空间测绘技术标准，更好地集成创新应用。  
　　“对于应用层的测量，已经成为网络资源调度的主要依据。”李昕还特别提到关注“应用层”的重要性。李昕认为，要以应用层为中心，站在应用和服务的视角，对网络提供服务能力进行测量。  
　　值得一提的是，IPv6已经成为下一代互联网发展的起点。“IPv6规模部署工作广度不断拓展，其活跃用户数持续上升。尤其，移动互联网、物联网和工业互联网发展促使IPv6的普及加速，海量IPv6活跃地址发现成为当前IPv6网络空间探测研究难点之一。”清华大学网络科学与网络空间研究院教授杨家海说。  
　　杨家海表示，IPv6地址智能分析与生成是资产探测的核心技术。其中，IPv6地址空间的巨大且分布稀疏，难以全谱探测，传统探测方法已失效。现在亟需采用智能化等技术手段收集海量地址集，掌握地址分布规律，提升探测扫描的效率与精准度。“我们应该对已知IPv6种子地址进行统计分析，基于统计规律生成预测地址，再对预测地址进行探测。”  
　　本次大会由教育部高等学校网络空间安全专业教学指导委员会主办，北京电子科技学院、清华大学、远江盛邦（北京）网络安全科技股份有限公司联合承办。来自国家网信办、公安部、工信部以及全国20余所网络安全学院代表参会。
