# 烽火狼烟丨Apache Shiro < 1.6.0 权限绕过漏洞（CVE-2020-13933）风险提示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650263672&idx=1&sn=16b2460bc20a33a7fb10b8f5040e7539&chksm=83205d0cb457d41a711213ae1a398546f7f963cffb885dfed44e759df55cf83cbf71443313bf&scene=126&sessionid=1681374603#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650263672&idx=1&sn=16b2460bc20a33a7fb10b8f5040e7539&chksm=83205d0cb457d41a711213ae1a398546f7f963cffb885dfed44e759df55cf83cbf71443313bf&scene=126&sessionid=1681374603#rd)

近日，WebRAY 安全服务部监测到互联网存在Apache Shiro身份验证绕过漏洞（CVE-2020-11989）的漏洞补丁缺陷，在Apache Shiro 1.6.0之前版本中处理url与spring时依旧存在差异，因此在Apache Shiro 1.6.0之前版本中存在身份校验绕过漏洞。  
Apache Shiro是一个强大且易用的Java安全框架，用来执行身份验证、授权、密码和会话管理等功能。  
WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。  

  

**漏洞概述**

Apache Shiro 1.6.0之前的版本存在身份校验绕过漏洞。  

  

**漏洞基本信息**  

| 产生原因 || 不安全的配置 |
| --- | --- |
| 影响范围 || Apache Shiro < 1.6.0 |
| 漏洞ID || CVE-2020-13933 |
| 分类 || 身份验证绕过漏洞 |

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危  

  

**修复建议**  

Apache官方已经发布了1.6.0版本修复了上述漏洞，请受影响的用户尽快升级至Apache Shiro >= 1.6.0版本进行防护。http://shiro.apache.org/download.html
