# 烽火狼烟丨Apache Struts远程代码执行漏洞（S2-059、CVE-2019-0230）风险提示

Struts2是一个基于MVC设计模式的Web应用框架，它本质上相当于一个servlet，在MVC设计模式中，Struts2作为控制器(Controller)来建立模型与视图的数据交互。  
2020年8月13日，WebRAY安全服务部监测到Apache Struts 官方发布安全公告，披露S2-059 Struts2远程代码执行漏洞。  

  

**漏洞概述**

Struts2在使用某些tag等情况下可能存在OGNL表达式注入，从而造成远程代码执行，例如：<s:url var="url" namespace="/employee" action="list"/><s:a id="%{skillName}" href="%{url}">List available Employees</s:a>。  

  

**漏洞基本信息**  

| 产生原因 || OGNL表达式注入 |
| --- | --- |
| 影响范围 || Apache Struts 2.0.0 - 2.5.20 |
| 分类 || 远程代码执行 |

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危  

  

**修复建议**  

升级到Struts 2.5.22:https://cwiki.apache.org/confluence/display/WW/S2-059
