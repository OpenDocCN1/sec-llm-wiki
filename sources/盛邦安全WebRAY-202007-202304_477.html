IBM WebSphere Application Server（WAS）是美国IBM公司的一款应用服务器产品，该产品是JavaEE和Web服务应用程序的平台，也是IBMWebSphere软件平台的基础。


2020年8月7日，WebRAY安全服务部监测到IBM官方发布升级补丁，该补丁修复了WebSphere Application Server代码执行漏洞（CVE-2020-4534），WebSphere Application Server存在由于UNC路径处理不当，恶意攻击者经过本地用户认证后，可执行任意代码。



漏洞概述

WebSphereApplication Server存在代码执行漏洞（CVE-2020-4534），该漏洞由于UNC路径处理不当，恶意攻击者经过本地用户认证后，可执行任意代码。



漏洞基本信息


产生原因

配置不当

影响范围

WebSphere Application Server 7.0

WebSphere Application Server 8.0

WebSphere Application Server 8.5

WebSphere Application Server 9.0

分类

远程代码执行



漏洞等级

WebRAY安全服务部风险评级：高危


修复建议

目前厂商已发布升级补丁PH26083修复漏洞，补丁下载链接:

https://www.ibm.com/support/pages/node/6254980
