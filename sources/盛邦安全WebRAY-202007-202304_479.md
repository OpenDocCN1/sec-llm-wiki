# 烽火狼烟丨Nexus Repository Manager 远程代码执行漏洞风险提示

今日，WebRAY安全服务部发现Sonatype Security Team官方发布了新的安全通告，该通告披露了Nexus Repository Manager 3.25.0之前版本中存在一处远程代码执行漏洞，漏洞编号为CVE-2020-15871。经过WebRAY安全服务部分析，该漏洞可通过两种方式对Nexus Repository Manager服务器造成影响。首先，攻击者在具备一定权限后，可以远程在Nexus Repository Manager服务器上运行任意代码；其次，攻击者可以诱使具有正确权限的用户运行Nexus Repository Manager服务器时运行任意代码。  
Sonatype Nexus Repository Manager（NXRM）是美国Sonatype公司的一款存储库管理器，它主要用于管理、存储和分发软件等。  
WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。  

  

**漏洞概述**

Sonatype Nexus Repository Manager（NXRM）是美国Sonatype公司的一款管理、存储和分发软件的存储库管理器，在全球范围内有着众多的用户，Sonatype Nexus Repository Manager 3 OSS/Pro 3.25.1之前版本中攻击者可利用该漏洞运行任意代码。因此，影响范围以及影响程度较大，WebRAY安全服务部建议相关用户及时升级更新。  

  

**漏洞基本信息**  

| 产生原因 || 不安全的配置 |
| --- | --- |
| 影响范围 || Nexus Repository Manager 3.x OSS / Pro <= 3.25.0 |
| 漏洞ID || CVE-2020-15871 |
| 分类 || 远程代码执行漏洞 |

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危  

  

**修复建议**  

目前，官方已发布新版本修复了该漏洞，请受影响的用户升级到安全版本：下载地址：https://help.sonatype.com/repomanager3/download/
