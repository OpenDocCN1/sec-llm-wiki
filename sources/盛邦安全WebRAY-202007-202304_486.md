# 烽火狼烟丨OpenStack远程代码执行漏洞的风险提示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNTAxMjUwNw==&mid=2650263434&idx=1&sn=f86b1b04a107d8871666a6cb795483af&chksm=832042feb457cbe875d0730f3e989982efb6d86c02110ed83f114d45f8f9e9a8a77266adb45f&scene=126&sessionid=1681374613#rd](http://mp.weixin.qq.com/s?__biz=MzAwNTAxMjUwNw==&mid=2650263434&idx=1&sn=f86b1b04a107d8871666a6cb795483af&chksm=832042feb457cbe875d0730f3e989982efb6d86c02110ed83f114d45f8f9e9a8a77266adb45f&scene=126&sessionid=1681374613#rd)

近日，WebRAY 安全服务部发现互联网存在OpenStack远程代码执行的0day漏洞，通过对OpenStack与成功部署的数据库实例之间的连接协议进行代码审计，发现此远程代码执行漏洞存在于OpenStack的trove模块中。  
OpenStack是美国国家宇航局(NASA)和Rackspace合作开发的旨在为公有云和私有云提供软件的开源项目。OpenStack是一个IaaS层的软件,其目标在于提供可靠的云部署方案及良好的可扩展性,从而实现类似于Amazon的云基础架构服务(IaaS)。Trove是指Openstack从Icehouse版开始加入的DBaaS服务，在大数据分析越来越盛行的背景下，对数据库的可靠便捷管理的重要性日益凸显，DBase as a Service（DBaaS，数据库服务）便成为了云计算平台为用户创造价值的一个体现。至2019年底发布的Openstack Liberty版本，Trove已历经了4个版本的迭代，并成为Openstack官方可选的核心服务之一。  
WebRAY安全服务部将持续关注该漏洞进展，并将第一时间为您更新该漏洞信息。  

  

**漏洞概述**

OpenStack中用于对数据库进行高效管理的trove模块存在远程代码执行漏洞。  

  

**漏洞基本信息**  

| 产生原因 || 不安全的配置 |
| --- | --- |
| 影响范围 || 采用trove服务的openstack |
| 漏洞ID || 暂无 |
| 分类 || 远程代码执行漏洞 |

  

  

**漏洞等级**

WebRAY安全服务部风险评级：高危  

  

**修复建议**  

及时关注官网补丁发布，若条件允许请更换较为安全的模块对数据库进行管理操作，如Service Tenant模型，参考连接如下：https://docs.openstack.org/trove/latest/admin/run\_trove\_in\_production.html#service-tenant-deployment
