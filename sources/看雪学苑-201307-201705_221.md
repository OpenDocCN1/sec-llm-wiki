看雪版主&评委** netwind** 点评

  

该题把用户输入的字符串与内存中数据进行异或得到一个 key，然后再把该 key 乘以 0x5e 后对题目里的函数代码进行异或解密，如果解密正确，这段代码执行后会显示成功提示信息。  

  

作者：**上帝溜猪**

  

设计思路

拿一组字符串（苍茫的天涯是我的爱。（data））跟最后面需要执行的函数代码做运算，（最后把 EXE 文件中原代码的位置覆盖掉。）  

  

在用密码跟这段字符串做亦或操作的出来的值保存在程序中解密用（KEY）。

  

![](../Images/3a88bbe3ca98c84b31c9afcda647aed4.png)

  

当输入的字符串等于 11 时就是解密，用输入的密码跟 KEY 做亦或得出的 data 

  

![](../Images/d2261f0fdd4eb6270d36400eade87211.png)

  

读取需要执行的函数代码用得出的 data 去解密代码，然后执行，错误程序崩溃，正确弹出对话框  

  

![](../Images/fc244d517c95c141fbe4ffb1ca168c81.png)

  

找到关键代码，算法还原下套个 try catch 跑就好。

  

下面选择了分析者** loudy** 的详细分析

  

简单分析定位到此处，获取键盘按键事件，取输入字符串，且从代码看，输入至少长度为 11 才能进入正常注册流程。  

  

![](../Images/11d5e67bb2df8d637288543610491de5.png)

  

看 IDA 中反编译的 C 语言伪代码，如下，更清楚，可以看到，取输入字符串后即对 403020 处代码进行解码，此过程按代码描述为，依次取输入字符串中的字符（至少11个），每个字符依次与 403020 处每个 BYTE 值（20个）异或，结果回存 403020 处；简化为，输入字符串中所有字符依次异或的值记为x1，x1与 403020 处 20 个BYTE 依次异或结果回存 403020 处。  

  

![](../Images/281f3eb4be744b7c6e8ebfe4d5685266.png)

  

继续看伪代码，如下，可以看到程序读取了401540 处 0x2C 个字节，利用 403020 处 20 个字节值进行解码运算后回存，然后执行 401540 处函数。伪代码展示该解码过程为，依次取403020 处（20 个字节）每个字节值，该值与0x5E 相乘后取低字节，该低字节依次与 401540处（0x2C个）每个字节异或，结果回存401540；简化为，依次取 403020 处（20 个字节）每个字节值，该值与 0x5E 相乘后取低字节，所有该低字节依次异或，值记为x2，x2与401540 处每个字节依次异或，结果回存。  

  

![](../Images/782c66adf940385e1a1fe4cc796120ee.png)

  

看 403020 处原始值和 401540 处原始值，如下，

![](../Images/387c1bdf2fd1713741e67a6f5a0f0d2f.png)
