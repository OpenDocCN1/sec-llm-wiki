看雪版主&评委 netwind 点评

此题是看雪密码学版主设计的一道密码学算法题，为了吸引大家对密码学研究的兴趣，作者有意降低了算法难度。算法主要采用了base32+sha3+camellia 加密算法，若对密码学有兴趣，此题值得深入学习研究。


作者简介

cnbragon，看雪论坛密码学版主，cryptoguy，爱好各种密码学知识，加密算法库 CryptoFBC 作者。


设计思路

本题主要考察密码学中重要的两个分支方向，杂凑算法（咱们国家官方就叫这个，不叫散列算法，不叫哈希算法），对称密码算法。主要是希望大家密码学爱好者能关注国内外密码学的新进展，比如新的算法。


破解方法

这道题目主要用到 base32+sha3+camellia 三个算法，base32 是很多共享软件的常见算法就不多说了，SHA3 是美国针对 MD 系列，SHA1，SHA2 系列 Hash 算法的安全风险向全球征集的新标准，最后选中了 Keccak 作为最后的 SHA3 算法。


Camellia 是日本人设计的算法，入选了欧盟的NESSIE 和日本的 CRYPTREC，咱们要好好研究研究。


验证过程

1. 程序首先验证输入的 flag 是否是 base32，如果是则进行解码，得到 20 个字节的 BASE256 值，记为C；


2. 计算固定字符串 cnbragon@pediyctf2016 的 SHA3-256 值，记为 H；


3. 计算 H 前后两两模 2^32 相加的结果组成一个128 位的字节串，作为 Camellia 的密钥，记为 K；


4. 计算 H 模 2^32 的乘积，校验是否等于 C 的最后 4 个字节值，如果不是，则验证错误；


5. 使用 Camellia 算法对 C 的前 16 个字节进行解密，校验解密后的结果是否等于 H 的后 16 个字节，如果是则提示成功。

压缩
idxkey[i] 的有效值(不采用的"="对应的0x20除外)最大为 5-bits，
压缩即将 idxkey 总共 0x20*5=160位=20字节*(8位/字节) 压缩为 20字节
定义转换压缩后的注册码信息为五个双字数组 dword cckey[5]

截至其会用camellia对称加密算法对 cckey 前四个双字组成的 0x10 字节解密得到 cmp1key,
然后比对(cmp1key实际是与'cnbragon@pediyctf2016'的256哈希值高半部分比对)，
而 cmpkey2 = cckey[4] 直接与 'cnbragon@pediyctf2016' 的 256 哈希值累积比对。

于是通过得到 'cnbragon@pediyctf2016' 的 256 哈希值，
并处理得到累积和对高半部分进行 camellia 加密即可得到 cckey = camellia_encrypt(cmpkey1)+cmpkey2。
再对 cckey 解压逆转换，最后进行"L"反过滤补齐，即可得到原注册码

def parse_byte5(byte5 = None):
  byte_idx = []
  bits5 = c_ubyte(0)
  bits5.value = byte5[0]>>3
  byte_idx.append(bits5.value)
  bits5.value = ((byte5[0]&7)<<2) | (byte5[1]>>6)
  byte_idx.append(bits5.value)
  bits5.value = (byte5[1]>>1)&0x1F
  byte_idx.append(bits5.value)
  bits5.value = ((byte5[1]&1)<<4) | (byte5[2]>>4)
  byte_idx.append(bits5.value)
  bits5.value = ((byte5[2]&0x0F)<<1) | (byte5[3]>>7)
  byte_idx.append(bits5.value)
  bits5.value = (byte5[3]>>2)&0x1F
  byte_idx.append(bits5.value)

  byte_idx.append(bits5.value)
  return b"".join([chr(Tbl100hFF.index(bits5val)) for bits5val in byte_idx])
