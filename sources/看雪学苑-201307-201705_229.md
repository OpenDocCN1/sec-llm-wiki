# 看雪 2016 CTF 第二十四题 点评和解析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458281289&idx=1&sn=01bb0991cf2d18af017d1b45acc5d21a&chksm=b18155c386f6dcd5f59791d9f0cdca93e1a3588c0c76551fce34beeada7799df533d99a7109b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458281289&idx=1&sn=01bb0991cf2d18af017d1b45acc5d21a&chksm=b18155c386f6dcd5f59791d9f0cdca93e1a3588c0c76551fce34beeada7799df533d99a7109b&scene=27#wechat_redirect)

看雪版主&评委 **netwind** 点评

此题注册码必须以 pediy 开头，后面的部分通过数学公式进行简单运算后，与内存中的数据进行比较，如果一致则注册成功。此题是一个简单的算法题，比较适合初学者分析研究。

  

出题者：**月凉如水**

  

下面选择了分析者** loudy** 的详细分析

  

此题比较简单，分析见后文。拿到此题，首先查找 ascii 字符串，发现疑似相关字符串三个，如下图。

![](../Images/f37de92592a8343fbd77336857eab849.png)

跟进去，发现第一个“失败”受地址 0x5982E4 处的值控制，为 0 则继续执行，否则失败。  

![](../Images/01ebe5162a5158b9a002e22fdffac2fe.png)

往上找，发现 00403F71 处 call 00403230 可以改变 0x5982E4 处的值。  

![](../Images/72916cb2270026c732fbd3e7cbcb8cbc.png)

进入该函数，发现 004032A3 处 call 00403510 可以改变这一值。

![](../Images/5919f2078a094927a39a8f03cd382ffd.png)

进入函数 00403510，下图此处，为输入字符串前5位与固定字符串“pediy”逐字节比较，一致则地址 0x5982E4 处置 0，否则非 0。

![](../Images/899730985d7a8be8dc2bfa512da181dc.png)

据以上分析，可以知道，输入字符串前 5 字节为“pediy”。

  

对于 5 字节之后的内容，继续往下分析。入下图，00404069 处 call 00402E20 和 00404093 处call 00403910 为关键call，004040AD 处跳转为关键跳转。

![](../Images/96ecd60322ad5bd689d16e0159e631e4.png)![](../Images/675d26f81728fc330fc0ae42335e975d.png)

看 C 代码更直观，如下。

![](../Images/b572afc2be8cfe6dbaa1169e58137252.png)

看函数 sub\_402E20，如下图，可以猜测 5 字节后的内容必然在“0123456789abcdefABCDEF”中，且相邻两个字节对应的 16 进制值（‘0’-‘9’对应0x00-0x09，‘a’-‘f’对应 0x0a-0x0f，‘A’-‘F’对应0x0a-0x0f，大小写不区分导致多解）（奇字节在高4位、偶字节在低4位）组成一个新字节值，该值与 0x86 异或，存储以备后用（sub\_403910使用）。

![](../Images/e0806348ca706f64faf5121f9cc64b8b.png)![](../Images/f2c089e40bfdf37aa3b99295c53b633c.png)

再看函数sub\_403910，如下图。  

![](../Images/a1f6b23b9f998af17ec0bf4c4b4e119d.png)

函数中 a1 为函数 sub\_402E20 存储的结果，a2为该结果的长度，a3 为固定数组，如下图

![](../Images/e25a3eb23ceef76e3244d39d61113ffc.png)

a4 为固定值 0x9C。

函数 sub\_403910 算法思想为，a1 的每一个字节值等于 a3 的每一字节值加上 0x30（48）。

结合 sub\_402E20、sub\_403910 两个函数，反推注册算法，程序设计如下：

>   unsigned char aa\[0x9c\] = {0x01,0x04,0x08,0x02,0x04,0x08,0x03,0x04,0x08,0x04,0x04,0x08,0x05,0x04,0x08,0x06,
> 
>   0x04,0x08,0x07,0x04,0x08,0x08,0x04,0x08,0x09,0x04,0x08,0x01,0x04,0x08,0x02,0x04,
> 
>   0x08,0x03,0x04,0x08,0x04,0x04,0x08,0x05,0x04,0x08,0x06,0x04,0x08,0x07,0x04,0x08,
> 
>   0x08,0x04,0x08,0x09,0x04,0x08,0x01,0x04,0x08,0x02,0x04,0x08,0x03,0x04,0x08,0x04,
> 
>   0x04,0x08,0x05,0x04,0x08,0x06,0x04,0x08,0x07,0x04,0x08,0x08,0x04,0x08,0x09,0x04,
> 
>   0x08,0x01,0x04,0x08,0x02,0x04,0x08,0x03,0x04,0x08,0x04,0x04,0x08,0x05,0x04,0x08,
> 
>   0x06,0x04,0x08,0x07,0x04,0x08,0x08,0x04,0x08,0x09,0x04,0x08,0x01,0x04,0x08,0x02,
> 
>   0x04,0x08,0x03,0x04,0x08,0x04,0x04,0x08,0x05,0x04,0x08,0x06,0x04,0x08,0x07,0x04,
> 
>   0x08,0x08,0x04,0x08,0x09,0x04,0x08,0x01,0x04,0x08,0x02,0x04,0x08,0x03,0x04,0x08,
> 
>   0x04,0x04,0x08,0x05,0x04,0x08,0x06,0x04,0x08,0x00,0x00,0x00};
> 
>   printf("pediy");
> 
>   for(int i=0;i<0x9c;i++)
> 
>   {
> 
>         unsigned char bb = (aa\[i\]+0x30)^0x86;
> 
>         unsigned char cc = bb>>4;
> 
>         if(cc<=9) cc+=48;
> 
>         else cc+=55;
> 
>         unsigned char dd = bb&0x0f;
> 
>         if(dd<=9) dd+=48;
> 
>         else dd+=55;
> 
>         printf("%c%c",cc,dd);
> 
>   }
> 
>   printf("\\n");
> 
>   
> 
> 运行得到

![](../Images/47ae7eb485661d90434e4c93619f087a.png)

将此结果填入，得到

![](../Images/c082edf8f55d8c43c7f64dfc144a6e95.png)

当然，为什么说此题多解，从函数 sub\_402E20的分析可以知道，程序中标红的地方，每次循环都可以选择（+55（大写字母）或者+87（小写字母）），先全部换成小写字母试试，成功。  

![](../Images/ea0ab7521655314a61dedd49a6172ee8.png)

可行解一共 2 的 217（‘pediy’后一共217个字母）次方个。
