# 世界上最大的钢铁制造商之一，受到网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458281071&idx=1&sn=f17a95655df1dde675a913616dcf0571&chksm=b18154e586f6ddf36d7ffba97a8535d28d2030b54885fe802e2570fbda778aa6a409b0c615a3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458281071&idx=1&sn=f17a95655df1dde675a913616dcf0571&chksm=b18154e586f6ddf36d7ffba97a8535d28d2030b54885fe802e2570fbda778aa6a409b0c615a3&scene=27#wechat_redirect)

![](../Images/d988a8d6d5735cb0e9af87502dff76f5.png)

  

蒂森克虏伯(ThyssenKrupp) 总部位于德国，是世界上最大的钢铁制造商之一，宣称自己受到了网络攻击。

  

Thyssenkrupp 认为此次攻击非常专业，来自于东南亚地区。此次攻击的目的是窃取商业机密以及在《商业区工业解决方案》的研究成果。

  

根据路透社的调查，Thyssenkrupp 的计算机紧急响应小组在2016年4月发现攻击， 发现攻击早已从2月就开始了。这里并没有破坏的痕迹，也没有篡改数据、应用的样子。

  

Thyssenkrupp 的计算机紧急响应小组和首席信息官都在研究这次攻击，同时也在想方法改进受到攻击的 IT 系统。

  

从那以后，公司便对所有的 IT 系统进行全天候监控，预防新的攻击。

  

![](../Images/f750fd407839271c0eea69547768cb77.png)  

  

官方和相关的组织已经向大众公布了这件事，并发起调查。

  

Thyssenkrupp 认为，此次事件既不是因为安全措施不到位，也不是因为人为失误。

  

专家认为，在像 Thyssenkrupp 这样的大公司， IT 系统相当复杂，可以说，目前基本无法抵御有组织的、专业的黑客进攻。在这种情况下，**早期检测和即时的应对措施十分关键。**在这两方面，Thyssenkrupp 非常成功。他们还声称将继续和官方机构、警方网络犯罪调查机构合作，提高自己公司的网络安全。

  

日前，Thyssenkrupp 目前正在与印度跨国钢铁企业 Tata Steel 洽谈联手抵御网络攻击。
