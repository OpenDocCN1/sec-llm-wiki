看雪版主&评委 **netwind** 点评

本题主要考验 VM 的分析能力，作者在题目里使用了反调试，反虚拟机，反 API 断点，反 API 挂钩，导入表保护，OEP 抽取，代码虚拟化，代码乱序，代码拆分，代码混淆等反破解保护措施，不过题目中壳处理的指令比较少，混淆模式也比较简单。只要把 vm 流程和各个 handler 分析清楚，找到异或的 key 即可破解此题。  

  

作者简介

**demoscene**，反病毒工程师，反外挂工程师。

  

设计思路

一个专业实用的保护系统应该不仅能防 keygen 还应该能防爆破防代码分析。纵观当前市面上最好的几款保护，使用的技术皆为 RSA 算法+代码虚拟化保护，这是当前最流行，最强的软件保护技术。

  

由于本次比赛规则的限定，无法使用 RSA 算法，所以选择从代码虚拟化保护方面入手。本 CM 主要考验 VM 的分析能力，使用了本人实现的壳，包括简单的反调试，反虚拟机，反 API 断点，反 API 挂钩，导入表保护，OEP 抽取，代码虚拟化，代码乱序，代码拆分，代码混淆等，由于本次比赛要求分析注册码，所以主要考验代码虚拟化，代码混淆等代码处理的分析上，而由于本 CM 不打算考验算法分析，所以没有使用复杂的算法，只进行了简单的异或。

  

破解思路

由于本题只是对输入进行了简单的异或判断，所以无需费力气分析算法，只要把 vm 流程，各个 handler 分析清楚，找到异或的 key 即可。目前壳处理的指令还比较少，混淆模式也比较简单，所以要理清楚并不难，只是由于大家都第一次接触到此 VM，所以可能需要花点时间。
