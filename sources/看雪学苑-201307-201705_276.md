# "攻陷美国陆军", 还有奖金拿？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458280537&idx=2&sn=0b0c3181edcaff464dd49c4f0112094b&chksm=b18152d386f6dbc518d12b4f4976021a1265ff60180e64f904dc4fc5c9188b716138bfb735ed&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458280537&idx=2&sn=0b0c3181edcaff464dd49c4f0112094b&chksm=b18152d386f6dbc518d12b4f4976021a1265ff60180e64f904dc4fc5c9188b716138bfb735ed&scene=27#wechat_redirect)

![](../Images/f9d7735df1b40cdfe998ee5506c932de.png)  
美国陆军正在与HackerOne合作开展其第一次的漏洞奖励计划。  
![](../Images/e35480c7aaec7245fd4ef4dca8e7345c.png)  
在“攻陷五角大楼”倡议成功之后，美军最大的分支——陆军，首先启动漏洞奖励计划。![](../Images/563b98ed3cc1702b76f984ac5c826471.png)  
“攻险五角大楼”是联邦政府的第一个漏洞奖励计划，始于去年春季。它允许超过1400名注册黑客对选定国防部网站的防护能力进行测试。  
  
![](../Images/caaf4d8b378315bc5793eb29a851460a.png)  
这次试验性计划的结果是，安全研究人员发现了138个独特且从未被公开的漏洞，而国防部国防媒体活动办公(Defence Media Activity,DMA)几乎立刻就修复了这些漏洞。![](../Images/dc45732d484a424c8800086d86c2a507.png)10月份，国防部还向漏洞奖励平台HackerOne和Synack提供了合同，启动一个双管齐下的计划。众包安全倡议(Crowdsource Security Initiative)包括发现公众设备漏洞的奖金，这将继续由HackerOne来管理；发现存在于一些有关键任务且机密的IT设备中的漏洞，奖金较多，由Synack来运行。  
![](../Images/eabd98dc8af687bf1b9a10a37899b39e.png)  
国防部已经承诺将这些计划扩展到其它部门，“攻陷美国陆军”是这些挑战漏洞奖励计划的第一个。美国国防部说，他们将在未来几周公布参加挑战和所需资格的细节。  
  

“与黑客社区进行合作是发现最强大组织中漏洞的有效方法”，陆军部长Eric Fanning说，“邀请黑客社区发现未知安全漏洞，对陆军网络安全人员已经开展的重要工作作出了补充 ”。
