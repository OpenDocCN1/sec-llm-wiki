# 嵌入式Linux固件模拟与安全分析系统Firmadyne交流

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458280280&idx=2&sn=f3fb78647ca920c2f8238848e930d056&chksm=b18151d286f6d8c4c55e82d446006aa1847c4c881bc6b162b6380e04cbac3aae7ed36526d1fc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458280280&idx=2&sn=f3fb78647ca920c2f8238848e930d056&chksm=b18151d286f6d8c4c55e82d446006aa1847c4c881bc6b162b6380e04cbac3aae7ed36526d1fc&scene=27#wechat_redirect)

 Firmadyne是一款自动化分析嵌入式Linux系统安全的开源软件，由卡内基梅隆大学的**Daming D. Chen**开发完成的。它支持批量检测，整个系统包括固件的爬取、root文件系统的提取、QEMU模拟执行以及漏洞的挖掘。系统在github上可以下载：https://github.com/firmadyne/firmadyne

Firmadyne模拟执行框架图

一、系统的安装过程：

在ubuntu14.04的环境下过程:

1、         安装必须第三方库:

sudo apt-get installbusybox-static fakeroot git kpartx netcat-openbsd nmap python-psycopg2python3-psycopg2 snmp uml-utilities util-linux vlan

2、下载整个系统源码：

git clone --recursive https://github.com/firmadyne/firmadyne.git

3、下载并安装binwalk、jefferson和sasquatch工具，此部分的工具用来提取固件中的文件系统。

git clonehttps://github.com/devttys0/binwalk.git

sudo ./binwalk/deps.sh

sudo python ./binwalk/setup.pyinstall

*   For Python      2.x, sudo apt-get      install python-lzma
    

sudo -H pip installgit+https://github.com/ahupp/python-magic

Install jefferson.

Optionally, instead of upstream sasquatch, our sasquatch fork can be used to prevent falsepositives by making errors fatal.

4、安装数据库系统，此部分是为了支持批量检测的：

sudo apt-get install postgresql

sudo -u postgres createuser -P firmadyne, with password firmadyne

sudo -u postgres createdb -O firmadynefirmware

sudo -u postgres psql -d firmware <./firmadyne/database/schema

5、下载系统已编译好的交叉编译环境toolchain、console、libnvram等，这部分也可以通过自己编译源码完成。

cd ./firmadyne; ./download.sh

6、安装QEMU系统，也可以直接采用系统自带的QEMU系统。

sudo apt-get install qemu-system-armqemu-system-mips qemu-system-x86 qemu-utils

二、系统的使用：

1、设置firmadyne.config里面的FIRMWARE\_DIR指向根目录；

2、下载固件（以Netgear wnap320为例），

wget http://www.downloads.netgear.com/files/GDC/WNAP320 /WNAP320%20Firmware%20Version%202.0.3.zip

3、提取固件

./sources/extractor/extractor.py -b Netgear -sql 127.0.0.1 -np -nk"WNAP320 Firmware Version 2.0.3.zip" images

4、获取体系架构

./scripts/getArch.sh ./images/1.tar.gz

5、入库

./scripts/tar2db.py -i 1 -f ./images/1.tar.gz

6、制作qemu镜像

sudo ./scripts/makeImage.sh 1

7、模拟过程的网络配置，这部分很多时候无法生成run.sh,很大一部分原因是由于无法找到nvram中的配置，可以手工生成。

./scripts/inferNetwork.sh 1

8、运行模拟

./scratch/1/run.sh

9、漏洞挖掘和安全分析，此时模拟运行起来的固件就如同一个真实存在的设备，可以对其开展黑盒测试。

./scratch/1/qemu.final.serial.log.

./analyses/snmpwalk.sh 192.168.0.100

./analyses/webAccess.py 1 192.168.0.100 log.txt

mkdir exploits; ./analyses/runExploits.py -t 192.168.0.100 -oexploits/exploit -e x (requiresMetasploit Framework)

sudo nmap -O -sV 192.168.0.100

10、进入固件的console控制台:

./scripts/run-debug.sh 1

nc -U /tmp/qemu.1.S1

三、使用心得

1、目前能够支持较多固件的模拟执行，对具体的固件模拟还需要修改一些东西，如需要重新编译生成linux内核版本，修改nvram的支持等。

2、依靠软件模拟实现，我们可以对固件中的一些文件系统的内容进行修改，如一些暴力尝试登录的限制模块屏蔽掉等。

3、目前主要是对路由器的支持比较多，对摄像头等的支持还不够。
