Dirty Cow (CVE-2016-5195) 是一个Linux内核提权漏洞。
Q
为什么叫Dirty Cow？

“A race condition was found in the way the Linux kernel's memory subsystem handled the copy-on-write (COW) breakage of private read-only memory mappings. All the information we have so far is included in this page.”

简言之，就是内核子系统在执行Copy-on-Write会有漏洞，导致提权。

其中，Copy-on-Write 首字母连起来就是COW喽
Dirty 怎么来的呢？
英文里有dirty dog，意为卑鄙小人，在这里呢，用dirty cow 刚好和dirty dog类似，刚好这个COW 也不是个啥好东西，所以他们一拍脑袋决定就叫Dirty Cow 了。（纯属小编个人看法。。。）
Q
CVE-2016-5195什么意思？
CVE-2016-5195是官方对这个漏洞的一个代号。CVE (Common Vulnerabilities and Exposures) 是由MITRE维护的信息安全漏洞名的标准。
Q
Dirty Cow有什么特别之处？
没啥特别的。。。毕竟有那么多漏洞。所有漏洞都挺重要的，因为都关系到我们的安全，你说si不si。挖漏洞就和探险似的，一发现，就激动不要不要的呢~
Q
这个漏洞被解决了吗?
根据RedHat公司的报告称：目前已经发现针对这个漏洞的利用技术。官方正在积极修复。
Q
Dirty Cow的影响范围是？

Linux内核>=2.6.22（2007年发行）之后所有版本都受到影响。
