LLDB是个开源的内置于XCode的具有REPL(read-eval-print-loop)特征的Debugger，其可以安装C++或者Python插件。 

  

我当初的学习笔记毫无技术含量，今天和roysue沟通了下分享出来，老鸟掠过就可以了。感谢当初我在学习过程中几个朋友的帮助 飘云、creantan、0xcb

memory read \[起始地址 结束地址\]/寄存器 -outfile 输出路径  
![](../Images/39b835657fad5c1655ceac35c0f15c02.png "http://www.expshell.com/wp-content/uploads/2016/05/lldb-23.png")  
BTW:  memory read 只能读取1024字节数据, 超出将报错。  
  
解决方法：加－force参数  
memory read 0x10001000 0x10003000 -force  
或者:  
memory read 0x10001000 -count 0x2000 -force  
memory read $x0(寄存器) -count 0x2000 -force  
\--binary  // 二进制输出参数
