 由看雪学院和安全管佳公司举办的《走进企业看安全》沙龙于2013年12月21日在大望路温特莱中心又一次与广大坛友见面了。

本期演讲题目


13:30~14:00 签到
14:00~14:20 网友介绍
14:20~15:00 《Android Master Key 漏洞解析》，KING
15:00~15:20 茶歇
15:20~16:00 《Flash Player ActionScript漏洞》，Teddy_Joy
16:00~16:20 茶歇
16:20~17:00 《安全管家创业故事分享》，STONE


     在坛友的签到时，安管佳的MM还为每个到会的坛友送上了一份精美的礼品，让大家很是喜出望外！


　　按照我们会议以往的习惯，首先大家根据PPT上的顺序每个人坛友都站起来先做一个简要的自我介绍，由于大家知道了以往的说ID、姓名的游戏，这次很多人都变得很“狡猾”，开始做了很多的小动作。同时我们也公布了一个新的题目，要求参会的坛友在1到100之间选择一个数字，谁的数字最接近是所有人的数字的平均数的2/3，谁将获得无线路由一个。

   第一个主题是KING为大家讲解《Master Key 漏洞解析》，KING大侠从1、什么是master key 漏洞？2、最早的master key 漏洞；3、由master key 引起了什么？4、master key 的变种；5、lbe免root分析。这五个方面对Master Key 漏洞做出了详细的讲解，让现场的坛友对该漏洞又有了个更清晰的认识。

　 在精彩的讲解之后，收回了每个人写的那个数字，大家都彼此的望着对方，眼神里露出怀疑的目光。

　　第二个主题是由Teddy_Joy为大家讲解《Flash Player ActionScript漏洞》，简练而又不失逻辑的讲解让大家对Flash Player ActionScript漏洞产生的原因以及如何利用该漏洞有了更深层次的认识，同时也对这位刚出校园不久的小哥刮目相看。

　　　　
   讲解之后的说姓名、ID的游戏开始了，瞧，有人都拿出了自己的“终极武器”，又有人收获了奖品。。。。。。



　 第三个主题是安管佳公司CTO STONE为大家分享安全管家创业故事，STONE从自己刚开始参加工作的时候说起，一直到公司现在的业务都做了详细的介绍，让大家对安管佳的来自不易的发展业绩感到佩服，同时也为大家指出了一条创路路线：“如果你可以解决当下困扰很多人的事情，并且将它做好，那你就成功了”。

　　
   茶歇期间煞是友爱的自由交流。。。。。。


　 猜数字题目的答案公布了，16人参与活动，最大数为：55，最小数为：4.1，最总结果为：20.756，得奖者答案为：22。我们的幸运得主也发表了即兴的获奖感言。
