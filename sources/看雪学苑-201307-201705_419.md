     在坛友的签到时，安管佳的MM还为每个到会的坛友送上了一份精美的礼品，让大家很是喜出望外！

　　按照我们会议以往的习惯，首先大家根据PPT上的顺序每个人坛友都站起来先做一个简要的自我介绍，由于大家知道了以往的说ID、姓名的游戏，这次很多人都变得很“狡猾”，开始做了很多的小动作。同时我们也公布了一个新的题目，要求参会的坛友在1到100之间选择一个数字，谁的数字最接近是所有人的数字的平均数的2/3，谁将获得无线路由一个。  
  
   第一个主题是KING为大家讲解《Master Key 漏洞解析》，KING大侠从1、什么是master key 漏洞？2、最早的master key 漏洞；3、由master key 引起了什么？4、master key 的变种；5、lbe免root分析。这五个方面对Master Key 漏洞做出了详细的讲解，让现场的坛友对该漏洞又有了个更清晰的认识。  

![](../Images/262a47167c6ea566e3cb840f9b87a0b8.png "名称:  1.1.jpg&#10;查看次数: 0&#10;文件大小:  18.3 KB")![](../Images/e6866802de2e2768b999d97ec9b7ae5d.png "名称:  1.2.jpg&#10;查看次数: 0&#10;文件大小:  23.4 KB")

　 在精彩的讲解之后，收回了每个人写的那个数字，大家都彼此的望着对方，眼神里露出怀疑的目光。  
  
　　第二个主题是由Teddy\_Joy为大家讲解《Flash Player ActionScript漏洞》，简练而又不失逻辑的讲解让大家对Flash Player ActionScript漏洞产生的原因以及如何利用该漏洞有了更深层次的认识，同时也对这位刚出校园不久的小哥刮目相看。
