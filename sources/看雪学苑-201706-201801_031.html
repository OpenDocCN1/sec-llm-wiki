邮件客户端 Thunderbird 爆出高危漏洞，Mozilla 已修复

原文：http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458287221&idx=3&sn=6d13414e47fb9e8f34f2e70cd732b1ac&chksm=b1814cff86f6c5e95b2523bbcf7d12fe16bbec96eca8b34537d600f05eda3688aed59379ceaf&scene=27#wechat_redirect


Thunderbird 是一款流行的开源邮件客户端，在上周释出的 52.5.2 版本中，Mozilla 共修复了 5 处漏洞，包括了 1 处致命 bug，即缓冲区溢出漏洞（CVE-2017-7845）。

 

Mozilla 在公告中表示，在 Windows 系统上使用 Direct 3D 9 ANGLE 图形库进行绘制和验证对象元素时会存在这个错误。其原因是由于校验期间传入了一个不正确的值，从而造成可利用的崩溃。

 

在本月早些时候 Firefox 浏览器也修复了同样的漏洞，该错误已经于 7 号发布的 Firefox 57.0.2 版本中得到了解决。

 

另外两处高危漏洞分别是 CVE-2017-7846 和 CVE-2017-7847。前者为 Thunderbird RSS 阅读器 bug，可实现在解析 RSS 订阅的过程中执行 JS 脚本，例如通过 ‘View -> Feed article -> Website’ 或 ‘View -> Feed article -> default format’ 的方式。后者可在 RSS 源中通过精心构造的 CSS 泄露出本地路径，其中有可能会包含用户名。

 

而余下的中危漏洞（CVE-2017-7848）和低危漏洞（CVE-2017-7829）则分别对应 RSS 错误和针对邮件系统的错误。

 

“借助该低危漏洞能够显示任意的发件人地址，如果在显示字符串中以空字符开头，那么真正的发送方地址不会被显示出来。” Mozilla 方面表示。

 

同时，Mozilla 还表示，他们将会更新 Thunderbird 的 UI 和代码，并逐步淘汰基于 XUL 和 XPCOM API 构建的旧插件，使之更紧密的与 Firefox 保持一致。
