# 腾讯安全助力看雪安全开发者峰会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458286645&idx=3&sn=2f66c7376ca78bf594d69186d50a26d5&chksm=b1814abf86f6c3a91a5a07d0bd8cb9c968ab6f69e940a16439a4b73c776110d6f00f0acef161&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458286645&idx=3&sn=2f66c7376ca78bf594d69186d50a26d5&chksm=b1814abf86f6c3a91a5a07d0bd8cb9c968ab6f69e940a16439a4b73c776110d6f00f0acef161&scene=27#wechat_redirect)

本文经授权转载自腾讯安全联合实验室（知乎）

  

作为刚刚参加完会议的腾讯安全联合实验室，谈谈对这次峰会的看法。

  

这次安全开发者峰会是看雪学院举办的第一届峰会，现场氛围很好，以技术交流为主，面基大佬为辅。峰会涉及了移动安全、智能设备、物联网安全等多个时下热门安全领域。内容前沿、深刻，不仅展现了当前最新、最前沿的技术成果，还分享了年度最强实践案例，为安全人员与开发者人员们呈现了一份年度技术实战解释全景图。

  

具体议题方面，看雪主办方精心策划了安全编程、软件安全测试、智能设备安全、物联网安全、车联网安全、漏洞挖掘、APP加密与解密、系统安全等专题，吸引了多位业内顶尖的开发者和技术专家，为安全人员、软件开发者、广大互联网人士及行业相关者认识提供了极有价值的交流平台。

  

而非常有幸，我们的玄武实验室负责人于旸（TK教主）、湛泸实验室负责人袁仁广（yuange）、云鼎实验室负责人董志强（killer）、反病毒实验室负责人马劲松均受邀出席本次大会，担任嘉宾。

  

此次峰会全程高能，干货满满，每位演讲者都是携技术「尖货」上台。比如我们反病毒实验室安全专家杨经宇，他就IoT设备安全问题发表了**《开启IoT设备的上帝模式》主题演讲，还首度公开了两个危险等级较高的IoT设备漏洞**，此漏洞目前已经报送国家信息安全漏洞库（CNNVD）。

  

![](../Images/b9d46dc322c5790a1fbf163aaa8959f3.png)

  

考虑到有不少行业朋友没有去到现场，我们简单梳理了杨经宇的演讲内容，为大家分享物联网安全的最新技术研究和发展机制。

  

  

**500亿IoT设备下的新安全隐患**

  

伴随着IoT设备大量涌入智能家居领域，大众的安全也将面临更严峻的挑战。**杨经宇在会上指出，IoT设备因为自身与传统PC设备在硬件和软件上的巨大差异，引发了新的安全问题。**

  

**现场，杨经宇以摄像头固件校验漏洞为例，着重介绍了一种伪造固件绕过固件校验算法进行Root设备的方法，该漏洞也被CNNVD收录，并被评级为中危漏洞。**

  

而IoT设备被破解之后，带来的安全隐患也不仅局限于监听监控。杨经宇指出，IoT设备最大的安全威胁是在僵尸网络的操控下发起大规模分布式拒绝服务攻击（DDoS），去年半个美国断网事件的始作俑者就是Mirai僵尸网络。杨经宇还以一个DDNS智能硬件的root漏洞为例，详细讲解了如何将一个原本不具备WiFi功能的IoT设备开启WiFi功能，这将可能引发更多意想不到的攻击。

  

  

**IoT安全发展「守强攻弱」是必然趋势**

  

经过杨经宇的介绍，现场参会者进一步认识到了IoT设备发展潜伏的安全隐患，而作为安全行业从业者，其安全发展趋势和技术应对措施提起了大家的更高关注。对此，杨经宇认为，**IoT设备的安全发展会符合一种自然规律，即从攻强守弱到相互焦灼，最终实现守强攻弱。**

  

他表示，在IoT产业发展的初期，大部分安全隐患的产生都来源于我们对攻击的陌生，而这正是以腾讯安全联合实验室反病毒实验室为代表的安全厂商，开启IoT设备上帝模式（root模式）等还原不法分子破解手法的目的所在。通过这种模式，安全厂商能够实现「知己知彼」，最终占据攻防主动。

  

在演讲最后，杨经宇结合腾讯安全联合实验室反病毒实验室的研究，对IoT安全的缓解机制提出建议，**即通过固件签名、保护种子、物理手段，能够对固件校验、密码生成、WiFi扫描过程中出现的IoT设备漏洞进行有效防御。**

  

除此之外，来到峰会的还包括安全领域大家耳熟能详的几位重量级大佬，包括看雪论坛二进制漏洞版块版主仙果、威胁猎人创始人兼CEO毕裕、腾讯游戏安全高级工程师胡和君等，也同样为大家带来了时下最流行的技术干货。而后续的座谈环节，TK教主还客串了一把主持，与安全行业领头人们一起对中国信息安全的形势、未来发展给出了自己的看法和预判。

  

最后，作为峰会参与者与分享者，我们由衷感谢看雪为安全行业打造了一场纯粹的技术交流盛宴，也期待未来有更多这样的机会同行业安全人员、软件开发者、广大互联网人士及行业相关者交流、分享前沿技术经验和趋势见解，与大家一起推动网络安全事业的进步和更好发展。
