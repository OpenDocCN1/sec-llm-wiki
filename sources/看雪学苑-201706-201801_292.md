**调整第二分割区大小**  

\================================

  

调整 /private/var 分割区大小来释放空间，来建立另外两个新的分割区。

  

▶** 检查空间**  

  

使用 ssh 连接装置

  

![](../Images/8d2eb171172b57f89ecda1b75fe7b5d7.png)

/ 为系统分割区(system)  

/private/var 为资料分割区(data)

1B-blocks 总空间

Used      已用空间

Available 可用空间

  

上面看到资料分割区：

总空间为 13521633280 byte (約12.59GB)

已经使用 476921856 byte (约454.8MB)

剩余空间 13044711424 byte (约12.14GB)

  

资料分割区至少預留400-500MB的可用空间，iOS是从真实的可用空间中減去200MB，所以至少必須留700MB以上的空间。

  

例如：我們要分配8GB的空间給第二系統, 其餘的可用空间留給「disk0s1s2 资料分割区」

  

计算新的大小

8\*1024\*1024\*1024 = 8589934592 byte

  

第二分区大小 - 第三分割区大小 = 第二分割区新的大小

总空间(13521633280) - 8G(8589934592) = 资料分割区新的大小(4931698688) byte (约4.59GB)

  

用法：

hfs\_resize 挂载點 新的大小(byte)

  

范例：

调整 /private/var 容量为4.59G(4931698688 byte)

hfs\_resize /private/var 4931698688

  

然后执行df查看调整结果

![](../Images/539024a6d6132952f9da62fc31df9c9b.png)

▶ **计算第二分割区区块大小**

新的大小(byte) / 4096 = 区块大小

4931698688 / 4096 = 1204028

  

开始区块 + 区块大小 = 结束区块

569546 + 1204028 = 1773574

  

记住第二分割区结束区块大小為 1773574

****▶ ******建立第三分割区**(为第二系统的系统分割区)

  

设定前须先确定要安装的目标系统容量大小，然后计算第三分割区区块大小，设置第三分割区结束区块。或者可以自行分配大一点的区块给第三分割区

  

例如分配2.2GB的空间给第三分割区

2.2GB = 2248MB

2248\*1024\*1024=2357198848 byte

2357198848 / 4096 = 575488 (区块大小)

开始区块 + 区块大小 = 结束区块

1773576 + 575488 = 2349064

  

![](../Images/3452ac63f0edbef624970c0035831f87.png)

  

建立第四分割区(为第二系统的资料分割区）

设置第四分割区结束区块为：  

Last sector (2349066-3870728, default = 3870728) 的 3870728 - 3 = 3870725

  

也就是第四分割区结束区块后面必须预留3个区块空间

**四、安装与启动**

  

  

  

#####   

**▶ RootFS 解密**

范例 iPhone 4S 7.1.2 RootFS

  

解密

> dmg extract 058-4365-009.dmg rootfs.dmg -k <key>
> 
> dmg build decrypted.dmg rootfs.dmg
> 
> rm decrypted.dmg

  

或  

> vfdecrypt -k <key> -i 058-4365-009.dmg -o rootfs.dmg

  

上傳解密的 RootFS 到手機 /private/var/root/  

> scp rootfs.dmg  root@device\_ip:/private/var/root/

  

****▶ **格式化分割区**  

  

如果区块大小是 4096

> BSIZE="4096"
> 
> OPT="-b"

  

如果区块大小是 8192

> BSIZE="8192"
> 
> OPT="-J -b"

  

format disk0s1s3

> /sbin/newfs\_hfs -s $OPT $BSIZE -n a=$BSIZE,c=$BSIZE,e=$BSIZE /dev/disk0s1s3

  

format disk0s1s4

  

\* 如果区块大小是 4096 (iOS 9以前的版本)  

  

> /sbin/newfs\_hfs -s $OPT $BSIZE -n a=$BSIZE,c=$BSIZE,e=$BSIZE /dev/disk0s1s4

  

\* 如果区块大小是 8192 (iOS 9以後的版本要加 -P 未實驗)

> /sbin/newfs\_hfs -s $OPT -P $BSIZE -n a=$BSIZE,c=$BSIZE,e=$BSIZE /dev/disk0s1s4

  

回復rootfs到disk0s1s3  

  

> asr restore --source /private/var/root/rootfs.dmg --target /dev/disk0s1s3 --erase  

  

完成后执行

> fsck\_hfs -f /dev/disk0s1s3

  

清除暂存

> rm /private/var/root/rootfs.dmg

  

建立挂载点目录  

> mkdir -p /mnt3
> 
> mkdir -p /mnt4

  

挂载第三分割區

> mount\_hfs /dev/disk0s1s3 /mnt3

  

挂载第四分割區

> mount\_hfs /dev/disk0s1s4 /mnt4

  

移动 /private/var/ 內容到第四分割区  

> mv -v /mnt3/private/var/\* /mnt4/
> 
> rm -rf /mnt4/log/asl/SweepStore
> 
> rm -rf /mnt4/mobile/Library/PreinstalledAssets/\*

  

修改起動分割区

> sed -i 's/disk0s1/disk0s1s3/g' /mnt3/private/etc/fstab
> 
> sed -i 's/disk0s2/disk0s1s4/g' /mnt3/private/etc/fstab

  

复制基频文件  

> mkdir -p /mnt3/usr/local/standalone/firmware/Baseband/Trek
> 
> cp -r /usr/local/standalone/firmware/Baseband/Trek/\* /mnt3/usr/local/standalone/firmware/Baseband/Trek/
> 
> cd /usr/local/standalone/firmware/Baseband/Trek
> 
> zip -r0 /mnt3/usr/local/standalone/firmware/Baseband/Trek/Trek-personalized.zip \*

  

复制keybags

> mkdir /mnt4/keybags
> 
> chown -R 0:0 /mnt4/keybags
> 
> chmod -R 700 /mnt4/keybags
> 
> rm /mnt4/keybags/systembag.kb
> 
> cp -r /private/var/keybags/\* /mnt4/keybags/

  

****▶ **keybag 修复**  

  

\# keybagd 补丁  

  

详见 keybagd Patch

> rm /mnt3/usr/libexec/keybagd

  

修改好之後上傳替换  

> scp keybagd root@device\_ip:/mnt3/usr/libexec/

  

\# keybagd 重新签名

****▶ **安裝 fixkeybag**

  

下载原始码自行编译  

https://github.com/NyanSatan/fixkeybag

  

编译并复制到 /mnt3/sbin/

或从 dualbootstuff 复制  

> cp -a /usr/share/dualbootstuff/fixkeybag /mnt3/usr/libexec/

  

开机自动载入 fixkeybag

> echo "bsexec .. /usr/libexec/fixkeybag" >> /mnt3/private/etc/launchd.conf

  

或

![](../Images/2c12115b42eb5dacd1a5e80902a1e075.png)

  

重新签名

  

![](../Images/771c0b78266712db0d039f4f87e69db3.png)

  

添加 bootchain 文件

  

提取 kernelcache.release.n94 解密。

> xpwntool kernelcache.release.n94 kernelcache -iv <IV> -k <KEY> -decrypt  

  

提取 ramdisk.dmg 解密。

> xpwntool ramdisk.dmg ramdisk -iv <IV> -k <Key> -decrypt  

  

提取 DeviceTree.n94ap.img3 解密。

> xpwntool DeviceTree.n94ap.img3 devicetree -iv <IV> -k <Key> -decrypt

  

提取 applelogo@2x~iphone.s5l8940x.img3 解密

> xpwntool applelogo@2x~iphone.s5l8940x.img3 applelogo -iv <IV> -k <Key> -decrypt

  

将 applelogo、ramdisk、kernelcache、devicetree 上传第二系统根目录 root@device\_ip:/mnt3/

  

注：applelogo 非必要

  

將已修改好的 iBSS、iBEC 上传到 root@device\_ip:/

  

修复权限  

> chown -R 0:0 /mnt3/kernelcache
> 
> chown -R 0:0 /mnt3/ramdisk
> 
> chown -R 0:0 /mnt3/devicetree

  

卸载分割区  

> umount /mnt3
> 
> umount /mnt4

  

**▶ **启动系统  

  

要启动第二系统，请拔下传输线，勿处于充电状态。

  

执行multi\_kloader命令之后会进入睡眠模式，按一下Home鍵，开始引导第二系统。

  

启动命令

iPhone 4S

> 4smulti\_kloader /iBSS /iBEC

  

其他

> multi\_kloader /iBSS /iBEC
