二、Patching Bootchain




1. iBSS Patch


解密 iBSS

xpwntool 輸入 輸出 -iv <IV> -k <Key>

IDA Pro 載入

查看 ROM:00000044                 LDR             R1, =0x34000000

0x34000000 為載入基址

Edit > Segments > Rebase program...設定基址為 0x34000000

搜尋字串 iBSS ready, asking for DFU...

來到這裡



iPhone 4S 改为 #0xBFD0

0x908  ?B F? D0 ??

其他改为 #0x7FD0

0x908  ?7 F? D0 ??

iOS 8 则搜寻 HEX 00 00 E0 8F (0x8FE00000) 改为 与 multi_kloader 匹配的 iBEC Remap addresses 0x7FD00000


搜寻字串 Apple Mobile Device (DFU Mode)

x 选择第一項目

来到这里



搜寻 TEXT "CMP             R1, #0x41 ; 'A'"

代码开头 x 返回



然后往上看



来到这里



修改完后不用加密


2. iBEC Patch


解密 iBEC

用法: xpwntool 输入 输出 -iv <IV> -k <Key>

IDA Pro 载入

查看 ROM:00000044                 LDR             R1, =0x9FF00000

0x9FF00000 為载入基址

Edit > Segments > Rebase program...设定基址为 0x9FF00000

搜寻 TEXT "CMP             R1, #0x41 ; 'A'"

代码开头 x 返回



然后往上看代碼



来到这里



找寻字串 debug-enabled

x 选择第一項目

来到这里



找寻字串 upgrade 改为 fsboot


找寻字串 false 改为 true


找寻字串 Reliance on this certificate by any party assumes acceptance 位于 offset 0x42680

0x42680+0x9FF00000=0x9FF42680 Byte = 80 26 F4 9F

在 0x42680 写入 rd=disk0s1s3 cs_enforcement_disable=1 -v amfi=0xff

搜寻 rd=md0 nand-enable-reformat=1 -progress offset 位於 offset 0x3B810

0x3B810+0x9FF00000=0x9FF3B810 Byte = 10 B8 F3 9F

搜寻指标指向 0x9FF3B810 的位址

找尋 Byte 10 B8 F3 9F

0x1C250 指标指向 0x9FF3B810

将 rd=md0 ... 指标替换为 rd=disk0s1s3 cs_enforcement_disable=1 -v amfi=0xff 的指标

offset 0x1C250 写入 80 26 F4 9F (0x9FF42680)

修改完后添加img3当头


用法：xpwntool 输入 输出 -t <原始加密文件>

范例：

xpwntool iBEC.dec iBEC -t iBEC.n94ap.RELEASE.dfu
