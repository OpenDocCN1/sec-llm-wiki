# 看雪峰会携手CSDN，寻求合作伙伴

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458284365&idx=3&sn=de21a0a4e37f74c32a15e378b80e2a12&chksm=b18141c786f6c8d1a1398fc515f9b7f52b6ae082d4db5e47671b4a2e7f4739d4a5cf9548eefb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458284365&idx=3&sn=de21a0a4e37f74c32a15e378b80e2a12&chksm=b18141c786f6c8d1a1398fc515f9b7f52b6ae082d4db5e47671b4a2e7f4739d4a5cf9548eefb&scene=27#wechat_redirect)

2017 安全开发者峰会，是由看雪学院和 CSDN 联合主办的首届安全峰会，与SDCC中国软件开发者大会同场进行。安全分为攻、防两个领域，**本届大会以“防”为基准，安全开发为主旨，引导广大企业和开发者关注移动、智能设备、物联网等领域的安全。**

  

看雪学院创建于2000年，致力于PC、移动、物联网安全研究及逆向工程相关的开发者社区，已有注册会员70万。大量安全人才通过社区，从普通IT爱好者成长为安全专才，十几年的发展过程中，看雪网站形成了大量有价值的技术资料和图书，社会影响深远。

  

SDCC中国软件开发者大会（Software DeveloperConferenceChina），是由全球最大中文IT社区CSDN于2007年创办的软件技术领域顶级盛会，话题涵盖了互联网架构、编程语言、大数据、区块链、前端框架、微信开发、人工智能、运维、 机器学习等方面，旨在推动软件开发实践的深入交流与分享，为软件开发者、广大互联网人士及行业相关人士提供最具价值的交流平台。
