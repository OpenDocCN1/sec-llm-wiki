# 世界头号传奇黑客凯文·米特尼克首度来华 将亮相 CSS2017 分享安全之道

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458284069&idx=2&sn=a7ee644de6ae7c51715a85070a102e1c&chksm=b18140af86f6c9b983d0b3bbfe8af854fd91ea9fac09e4a9debc78064644d4cb9b222d200d78&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458284069&idx=2&sn=a7ee644de6ae7c51715a85070a102e1c&chksm=b18140af86f6c9b983d0b3bbfe8af854fd91ea9fac09e4a9debc78064644d4cb9b222d200d78&scene=27#wechat_redirect)

8月15日，被称为“世界头号传奇黑客”的凯文•米特尼克（Kevin Mitnick）将首度来华，亮相第三届中国互联网安全领袖峰会（Cyber Security Summit 2017，简称“CSS2017”）分享他的黑客技术与传奇经历，并与腾讯安全玄武实验室负责人“TK教主”于旸、卡巴斯基资深安全研究员Vladimir Dashchenko 、 KEEN CEO 王琦、知道创宇CEO赵伟等全球顶尖安全人才展开对话，共议“安全之道”。

![](../Images/d12b06ba4ca1431528227cdfd3522917.png)

上个世纪 90 年代，互联网还处在发展初期，凯文·米特尼克（KevinMitnick）就创造了一系列前所未有的黑客传奇故事。16岁时，米特尼克仅凭一台电脑和一部调制解调器就闯入了“北美空中防务指挥部”；他能随意潜入全球的计算机系统，查看甚至任意更改数据。

1994年的圣诞节，米特尼克向圣迭戈超级计算机中心发动了一次攻击，《纽约时报》称这一行动“将整个互联网置于一种危险的境地”。米特尼克成功地入侵了美国摩托罗拉、NOVELL、芬兰的诺基亚、美国的SUNMICROSYSTEMS等高科技公司的计算机，盗走了各式程序和数据。根据这些公司的报案资料，FBI推算的实际损害总额达至4亿美元。正因如此，米特尼克被美国联邦调查局列为头号通缉犯，最后在其与计算机专家下村勉展开激烈技术博弈后被捕。

![](../Images/0c37cb2a3fd69dc2eb23a841942d2b52.png)

如今，米特尼克已转型成为一名安全顾问，建立了自己的计算机安全咨询公司，并加入了以色列的一家信息安全服务提供商的咨询委员会，以其自身的经验传道授业，为包括IBM在内的世界知名企业提供安全咨询服务。除此之外，米特尼克还以《欺骗的艺术》、《入侵的艺术》和自传《线上幽灵》三本著作，面向大众全面解析当今网络安全面临的问题与挑战。

![](../Images/6b7d04ffd34de7ccf4669e24991b24c7.png)

据悉，此次参加第三届中国互联网安全领袖峰会的米特尼克将在现场与大家分享他从“世界顶尖黑客”到“安全咨询师”的传奇经历与前沿安全技术。此外，米特尼克还将与“TK教主”于旸、卡巴斯基资深安全研究员Vladimir Dashchenko、KEEN CEO 王琦、知道创宇 CEO赵伟等世界级安全大咖进行一场“世界安全技术尖峰对话”，共同探讨网络“大杀器”的安全之道。

![](../Images/e8f5f4694b7ebdc7547083468e2b17b7.png)

2017 年 8 月 15 日—16 日在北京国家会议中心召开的第三届中国互联网安全领袖峰会将围绕“安全新秩序、连接新机遇”这一主题，从金融安全、大数据及云安全、人工智能与安全伦理、安全法治治理、基础设施安全、智能硬件与物联网安全、网络空间威胁态势感知、腾讯安全探索等方向展开深入探讨，共同分享最前沿的安全技术与安全理念。

  

届时，启明星辰、绿盟科技、天融信、卫士通等国内13家上市安全企业领袖将在 CSS2017 首次聚首，以圆桌论坛的形式对基础设施安全问题展开深入探讨，共话如何通过安全技术的创新来驱动中国基础设施安全保障体系的建设，如何通过资本平台及生态资源来驱动产业实力的提升等议题。作为《网络安全法》正式施行以来，中国互联网安全领域大规模、强阵容、高水准的一次领袖聚首，将全面开启网络安全战略规划的新时代。

此外，包括VISA 副董事长兼首席风险官 Ellen Richey 、IBM Security 全球首席资讯安全架构师Chenta Lee、中国电子科技集团公司总工程师吴曼青院士在内的国内外安全领袖以及微软、VISA、IBM、京东、滴滴等全球500余家企业也将受邀参加 CSS2017，围绕网络安全法实施落地背景下中国互联网安全产业格局和发展机遇进行全面解读把脉，深入探讨与分享他们对互联网前沿科技及各领域网络安全的研究与观点，为产业的“数字经济”转型献策。

中国互联网安全领袖峰会（Cyber Security Summit，简称“CSS”）由腾讯公司、中国电子技术标准化研究院等企事业单位共同创办，得到了国家网信办、工信部、公安部等国家部门的大力支持和指导。自2015年第一届中国互联网安全领袖峰会举办以来，汇聚了来自高通、微软、谷歌、英特尔、思科、IBM Security、McAfee、趋势ZDI、FireEye、CheckPoint等十大国际顶尖企业的安全专家，腾讯、百度、滴滴、京东等中国互联网巨头的安全领军人物。CSS作为网络安全新生态的首创平台，将继续秉承“开放、合作、共享”的理念，旨在在此平台上，让全球的企业实现优势互补，并为全球网络安全构筑一道强强联合的重要防线。

目前，CSS2017 售票活动已正式启动，门票分为普通套票、商务套票以及VIP通票。点击**“阅读原文”**参与购票，与世界级顶级安全大咖相约北京共议“安全之道”。
