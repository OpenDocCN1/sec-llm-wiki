# 给腾讯TIM插入广告木马（一）

一

从 App 中提取木马并分析木马

**（1）iOS Application File**

最近一款在VirusTotal的应用程序引起了我们的注意。

![](../Images/69e6d64d3a8e2ca2a2d756ccfccf9772.png)

从文件名可以看出这是一款使用了Clutch的破解软件。对ipa文件进行解压（实际是zip文件）。

![](../Images/627582573ec35a4842916aa14c349318.png)

jailbreak这个库看起来很可疑

![](../Images/ee33dfa8cbc7e39f81e0b58b8c87a1a4.png)

nguyen tat hung 虽然是一个知名开发商，但不是MailTime Pro的开发商。

进一步，我们发现jailbreak动态注入到了二进制程序中。

![](../Images/72d820cac0e0bf3a0498d42cc672a845.png)

大多数的库，在导入表中包含了他们的安装路径和真实名称

![](../Images/56a96b38a5fee942a96b83f1a0467874.png)

通过assert()宏，查看项目的关联信息

![](../Images/e5f97d437db12e4354f14c4e692993a3.png)

**（2）Inject Library**

通过符号表，快速的找到知名SDK和CocoaPods。

![](../Images/74954eb4cf5007be7a87f395f44726f3.png)

一个越狱软件包括如此多的广告是不常见的，这里有剩余的类头文件。

\-\[Config getConfig\]方法从程序目录加载wrap.json文件。

![](../Images/3c05017a8dcefc31814c55ee45725c7e.png)

经过几次循环等待，注入的代码会联系一个不安全的远程主机，部分的服务可以工作。

比如，coreapi服务似乎不能工作。

http://wrapper.laughworld.net/coreapi/active\_device.php?pk=IPANAME&is\_jb=1&udid=REDACTED&signature=MD5

![](../Images/128893e829377fcbd57359db1cf386c9.png)

http://wrapper.laughworld.net/coreapi/get\_list\_message.php?pk=IPANAME&is\_jb=1&udid=REDACTED&libver=20160818&app\_pk=IPANAME\_AGAIN&app\_ver=1.2.3&signature=MD5

![](../Images/bc2508d99b72acaedc4df82f9eff43c9.png)

当api服务启动后

http://wrapper.laughworld.net/api/com.mailtime.MailTimePro\_ads.json

![](../Images/3185566888a970a23f6555f96f59893c.png)

最有趣的是update请求

\-\[API getUpdate:withSelector:\]方法会请求http://wrapper.laughworld.net/api/com.mailtime.MailTimePro\_update.json

![](../Images/76c6e18afb02eb5ef799cfb286f204cf.png)

script\_zip,script\_file和md5\_script没有被执行，script\_zip的URL指向一个加密的ZIP,并且md5\_script是无效的(最后一个字节错误)。

linkfw指向一个有效的Zip，一旦下载并解压， -\[guiinject \_loadPluginAtLocation:\]将加载框架并发送一个run消息到principalClass。md5fw用于自我更新。

到目前为止，我们没有看到任何广告，他们可能隐藏在视图中。

**（3）Downloaded Framework**

![](../Images/9f10a83099651b2f7f0ad4bcafd67b50.png)

开发者的标识发生了改变。

![](../Images/16b772d0f63ddd3722386cdddeb0410c.png)

框架的header中有开发者和组织。

![](../Images/d14e73ae1341b22779abbfd225f9784a.png)

这是有Xcode自动生成的，经itviec工作网查询， GTT Media 和 T&B 是外包公司。

一旦加载完成，框架通过lib服务请求托管在DailyUploads和FileFactory站点上的文件列表。

http://wrapper.laughworld.net/lib/DailyUploadDownloadModule.conf

![](../Images/f5d38443406615f22e945165d5be0c0c.png)

http://wrapper.laughworld.net/lib/FileFactoryDownloadModule.conf

![](../Images/04ac43fc892f873b0b030e2a4408f118.png)

框架也会使用DynDNS定期检查iOS设备的外部IP。

每当框架加载完毕或者IP变更，都会从DailyUploads和FileFactory下载一个随机文件。

dailyuploads也指向其他iOS应用，这些应用都是被nguyen tat hung签名并注入的（yara规则）。

![](../Images/157fba3e26afde286c6126be8a0d5ebc.png)

**（4）Abusing the Injected Adware Library**

一个动态库使用不安全的协议来连接远程主机并执行代码。我们是否通过拦截和修改update的response，加载了自己的代码？能否移植到别的APP中？
