小组简介


为增强看雪论坛 Web 安全版块坛友间知识交流与互动学习机会，借助看雪论坛平台更好的与业内知名企业机构，如金融企业、安全厂商、知名安全团队、大型500强企业等，共同交流时下最新、最前沿的互联网金融安全SDL实践、互联网风控反欺诈、反洗钱体系、威胁情报等安全技术方案及管理理念，并通过宝贵的与业内优秀安全团队交流实践机会，扩充视野，提升自我，成为安全大咖，特别成立了看雪 Web 安全小组。

Web 安全小组

福利


1、与业内优秀安全团队探讨 Web 安全技术方案、业内安全威胁情报，收获最前沿的网络安全技术及优秀解决方案；


2、看雪众测项目信息优先在小组里进行通知分享，借助看雪众测优秀资源平台，收获人生财富；


3、每期安全沙龙活动筹建将征询收集小组成员意见，小组成员将有机会提出自己最关心的行业信息安全建设思路与理念，并参与演讲或讨论；我们将尽最大努力尝试走进交流；


4、获知一手业内安全岗位招聘信息，为自己选择更开阔的优秀职业平台；


5、看雪出版安全书籍，优先获得作者签名书籍；
