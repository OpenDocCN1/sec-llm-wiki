# 娜迦受邀出席2018安全开发者峰会，守护移动终端

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458290724&idx=2&sn=e5c3de5f9e633752651443a0396a721c&chksm=b181baae86f633b8f539c78decc206c805b0d812c8e4146e8f958798086f8e329f2788a73c94&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458290724&idx=2&sn=e5c3de5f9e633752651443a0396a721c&chksm=b181baae86f633b8f539c78decc206c805b0d812c8e4146e8f958798086f8e329f2788a73c94&scene=27#wechat_redirect)

移动互联网是新时代的产物，也是未来发展的必然趋势，在丰富广大人民群众生活的同时，也给人民带来了强烈的娱乐体验，但是移动互联在无线接入网络、移动终端、应用服务上都面临着前所未有的挑战，其中Android平台移动应用的安全问题尤为突出，APP安全很容易被忽视，黑客一旦得手，将给用户造成很大的损失。这对于企业来说也是一样。数据信息是每家公司的核心，安全至关重要，尤其是如今深处移动互联网时代，形势比以往任何时候都更加紧迫。

北京娜迦信息科技发展有限公司应运而生，作为全球最专业的移动应用安全服务提供商，积极响应当下的移动互联网安全局势，为各行各业的企业级移动应用提供定制化、覆盖APP全生命周期的移动应用安全解决方案，为移动应用信息安全保驾护航。  

北京娜迦信息科技发展有限公司（以下简称NAGA•IN）成立于2014年，专注于移动应用安全、大数据分析整合以及物联网安全，致力于构建立体式的移动应用态势呈现方式，为移动应用提供全面的技术保障、敏感信息保护方案及全周期平台化解决方案，确保应用在整个生命周期中都处于安全状态，塑造坚固、可信、绿色的新一代移动互联网生态环境。

  

# 

## 1.   开启移动安全的第一道防线

# 移动互联网时代，如果在开发软件时缺乏对软件安全性的考虑，就会导致应用很容易被黑客攻击，让用户的信息得不到相应的保护，用户的隐私权就会受到侵害。NAGA•IN认为如果我们能够在开发阶段就将安全因素纳入考虑，那么在软件开发完成时应用本身就已经具备了一定的安全防护能力。所以NAGA•IN从不同角度多加思考，迅速发现移动应用开发阶段防护的关键点，并基于此建立了安全SDK保护机制，让应用在开发过程中就添加和使用安全键盘SDK、 防界面劫持SDK、防截屏SDK等，使软件开发完成使就已经具备了一定的安全防护能力，比起开发完成之后再通过检测，修复漏洞、通过加固增强安全性，开发时就介入软件的安全可以大大减轻移动应用安全检查和渗透测试的压力，可以明显降低安全风险。  

  

## 2.   安全检测，给您的应用体检

NAGA•IN始终相信每个开发商都不希望自己的APP有任何安全漏洞与隐患，但安全专业性的缺乏，使得开发者很难找到发现APP应用自身安全问题的有效方法。而NAGA•IN安全检测通过对应用进行静态检测，动态检测，模拟交互检测，渗透检测、指纹探测五大方面对应用进行脆弱性分析，给出漏洞的解决方案，帮助开发者对其APP应用进行全面分析，使隐藏的安全问题暴露无遗。帮助其提前规避应用中可能出现的安全风险。而用户只需提交应用，即可获得检测结果及正式报告。

## 3.   数据从未如此安全

互联网时代，数据就像黄金一样，被赋予了极高的价值。企业作为拥有海量数据的集中地，就必须要这些敏感数据进行深度的全面的安全防御。NAGA•IN认为敏感数据保护体系的建设需要由外而内采用多道安全措施进行层层防御。所以NAGA•IN推出业内首家深入追踪关键信息安全风险，保障敏感数据存放环境安全，针对用户敏感信息泄露安全风险，提供敏感信息跟踪监测平台和敏感信息保护沙盒方案。敏感数据保护系统可以实时跟踪敏感信息的流向和处理流程，改善和优化数据加密方案设计，同时结合敏感信息保护沙盒套件进行轻量化集成，通过使用高度封装和高强度加固的隔离沙箱存储关键数据，防止敏感信息泄露。支持对网络传输数据、内存常驻数据、文件数据等敏感信息进行全方位检测，对于核心逻辑的参数调用及重要值进行加密，避免被抓取。有效保护企业敏感数据，降低关键信息泄露的风险性，并且在结合高效的安全加固，为应用程序提供全方面的安全防护能力。  

  

## 4.   给应用未雨绸缪的安全保护

移动应用的加固方案从一开始最早的代码混淆技术，不断发展完善到现在较为流行的加壳防护和密匙安全校验技术，相应的黑客的攻击和破解手段也在不断升级提高。NAGA•IN作为移动互联网安全的服务提供商，安全加固是NAGA•IN的核心起步技术，经过长期的研究，NAGA•IN独创了国内唯一Native层加密技术成为国有移动应用安全领域核心技术的加固服务提供商，并提出防止动态调试与防止静态分析全面防护的思路，为APP提供移动应用加固服务，使加固后的应用静态防逆向分析、防二次打包；动态防调试、防进程注入等安全要求，避免用户被手机病毒或者盗版应用欺骗、攻击，保障终端用户的安全性。  

在投入大量的精力逐步改进独创的保护策略之后，NAGA•IN又针对不同APP的具体需求不断挖掘和扩展现有技术点，为适应移动安全新需求，提高APP的安全保护强度，首家推出行业领先的第七代多重VMP（VMProtect）加固保护技术，不仅确保了在移动应用开发和使用过程中能够全面的解决移动应用代码安全问题、移动应用盗版、移动应用被恶意篡改、二次打包和反编译等问题，杜绝了移动应用被其它手机病毒，木马，蠕虫等偷盗信息或破坏的现象，还从源代码层保障代码的合规性和安全性，防止黑客通过移动应用漏洞渗透到服务端系统造成企业经济损失。相比目前其他安全厂商普遍采用的安全策略，在安全强度和运行效率上都有了质的飞跃。NAGA•IN第七代多重VMP保护技术在大大优化了因加固导致的性能损耗问题的同时，动态选择应用运行时所需要的的安全策略强度对应用进行安全防护，力求对移动APP提供最优的安全加固保护方案的同时兼顾性能与安全。

  

# 

## 5.   构筑应用安全运营之路，让仿冒应用无所遁形

# 安全问题突出的仿冒应用，用户一旦安装下载，不仅会发生隐私泄露，账号泄露，个人财产被盗取侵害用户权益，还会造成企业经济或形象的重大损失。NAGA•IN将应用上线后的实时监测纳入了移动应用全生命周期的安全防护中，并通过7x24小时对国内外主流Android应用市场（包含网页应用市场和手机App应用市场）以及论坛、网盘、伪基站短信分发等目前非主流的恶意分发途径超六百个渠道的全面监控，快速发现被篡改的应用并定位分发渠道，精确统计篡改应用安装用户数及其影响的渠道范围，分析每个篡改样本中包含的所有篡改特征，如被插入了何种插件、广告等详细内容，快速定位自身应用存在弱环与问题，从而保护开发者利益。  

  

## 6.   威胁态势感知应对不可预知的未来

移动应用开发者竭力提高自身的安全意识及安全技术以期应对各种安全问题，来履行网络运行者的安全义务，维护企业及客户利益。然而现有的移动应用安全产品倾向于被动防御。常言道，知彼知己百战不殆。对NAGA•IN来说“全天候全方位感知移动互联网安全态势”是未来移动互联网安全的新目标。“态”指是从全局角度看到的现状，包括组织自身的威胁状态和整体的安全环境，态必须是基于真实情况所呈现的整体风险状况。更清楚的说，需要基于之前提到的5种检测能力尽可能的发现攻击事件或攻击线索，同时需要对涉及到的报警提供进一步的分析。“势”，即未来的状态。要能预测组织未来的安全状态，需要对现阶段所面临的攻击事件特别是定向攻击事件，有深入的了解。  

NAGA•IN借助于大数据分析推出白泽移动风险态势感知系统利用大数据技术统计、分析、建模，呈现移动应用的安全态势，动态感知可疑设备、攻击痕迹、异常回报信息，实时预警安全威胁，全方位助力企业提高自我保护和风险控制能力。从不同层面不同角度对信息进行统计分析，为企业展示所有移动应用及用户的安全态势，助力企业更全面的了解自己的产品及用户，为未来规划提供参考。
