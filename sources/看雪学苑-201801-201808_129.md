# 幸得诸君相扶携

因为科技发展，我们所面临的安全挑战愈加多样。

摄像头帮助我们可以在离家千里的地方感知家里的一器一物，但也为黑客窥探你的隐私提供了可乘之机；自动驾驶让我们脱离双手的束缚，但你是否也在担心《速度与激情》里那受黑客控制的在大街上横冲直撞的车辆？国家层面的网络攻击和窃密层出不穷，规模庞大的网络黑产暗流涌动，借助物联网设备发起的网络攻击此起彼伏……

正如小马哥所说，安全对整个互联网和整个社会都是至关重要的生命线。对于TSRC来说，这句话永远都是鞭策前行的箴言。

  

  

**从无到有，那是一件多么兴奋的事**

*“这个漏洞很严重，公仔不足以表达我们的感谢”*

2012年3月底，腾讯安全平台部应急响应团队刚处理完一个来自公司外部人士主动报告的严重安全漏洞，时任腾讯CTO Tony给安全部门的同事发了封Email：*“这个漏洞很严重，公仔不足以表达我们的感谢。**我有一个建议，请加我的微信聊……”。 *

由此，腾讯安全应急响应中心（Tencent Security Response Center）应运而生。由腾讯安全平台部负责人杨勇主导筹备，于2012年5月31日正式上线，是中国首家企业自建的漏洞提交平台。作为腾讯安全的先头兵，TSRC正式肩负起腾讯公司安全漏洞、黑客入侵的发现和处理工作。

![](../Images/0ea94125a69eb0ed57d1d8ccd10e8a8d.png)

  

据TSRC技术负责人Lake2回忆，“TSRC建设之初，*上线首月就有38位白帽子报告了上百个漏洞，随后漏洞数量一路攀升，2012年全年提交漏洞数量为1911个，白帽子注册量达4700名……”*

这让所有TSRC背后的安全人为之兴奋不已。

  

经过六年的迭代发展，TSRC汇聚了大批国内的安全人才，他们为TSRC提交了众多漏洞，其中不乏高危严重漏洞，及时保障了千万互联网用户的隐私和财产安全。可以说，这些年来，腾讯多个业务产品的发展，都离不开TSRC为其保驾护航。

 

  

**六年以证道，这是平台与白帽子一起成长的印迹**

*“你看不到黑暗是因为有人拼尽全力把黑暗挡在你看不到的地方”*

在某种意义上，TSRC打响了一场“全民战争”，鼓励漏洞发现者直接向企业提交漏洞，将那些崇尚黑客精神的技术极客转变为安全生态的建设者。过去的六年时间，TSRC为向广大安全人士征集漏洞，共发起了*14次双倍积分奖励活动，9次为腾讯业务单独发起的定制化漏洞征集活动*。每一次的“漏洞征集”与“漏洞处理”，都是一场场网络里看不见的保卫战。

 

![](../Images/7c00f3aa16bed0d912c32c3e69d84f2b.png)

                              

而这一切，离不开TSRC最重要的一个群体——白帽子。

  

![](../Images/c978c15c76c0088a6e43e49ae06505da.png)

*TSRC**年终盛典上的优秀白帽子*

他们，是腾讯的守护者和同路人，挖掘缺陷和漏洞，用技术保障用户的安全，解除各类隐患，与平台一起在安全这条长征路上相携前进。

  

在TSRC这个大家庭里，20-35岁的白帽子占了绝大多数，根据注册信息，最年轻的白帽子是一位17岁风华正茂的少年，而资格“老”的一名白帽子从成立之初就伴随TSRC成长，持续贡献了数百个漏洞，并且至今仍在为TSRC报告漏洞。六年以证道，热血谱春秋，要感恩业内所有安全精英和白帽子的支持与守护，他们是TSRC最为坚实的中流砥柱。

  

当然，这条征途中，有人加入，也有人离开。TSRC尝试通过各种渠道为白帽子打造了一条特色的进阶之路，通过举办沙龙、竞赛等扶持、助力白帽子的成长，希望有更多的仁人志士加入到这个中国互联网最大、最具挑战的安全战场，并肩守护亿万用户的安全。

  

所幸的是，英雄榜上不断涌现的 “新手上路”，让人仿佛看到了一路奔跑的侠客，正沿着河岸追逐心中的那片彩霞。TSRC仍充满澎湃的希望，有“老人”不忘于江湖，有“新人”踏上逐梦路。

 

  

**你报告漏洞，我守护梦想**

*“技能和本领越高，承载的社会责任也越大”*

腾讯安全平台部负责人杨勇在一年一度的TSRC年终盛典上致辞，*“腾讯承载了亿万量级的用户，当我们拥有的技能和本领越来越高，我们所肩负的社会责任、承载的社会期待也越来越大。”*

不忘初心，方得始终。在这些年里，TSRC联合高校举办*全国大学生竞赛*，助力人才培养；先后推出*星辰计划*、*安全守护者计划*等公益活动，携手白帽子资助贫困孤儿，为震灾人民发起紧急捐款重建家园；联结行业力量成立安全公益联盟，将安全的温暖散播到更远的地方……

  

![](../Images/f31fcf9156cbbcc72ae8712cf670263c.png)

  

从成立之初的种种青涩，一路摸爬滚打，凭借着一整套成熟的安全应急响应机制和漏洞奖励计划,TSRC已成为业内标杆之一。其后，阿里、百度、网易、京东、小米等企业的SRC也都陆续建立起来，如今国内已经有70余家SRC,国内的安全产业生态真正焕然一新。

  

未来，TSRC将继续和白帽子一起前行,在用技术改变世界，守护亿万用户安全的同时，承担更大的行业责任，传播更多的社会价值。腾讯安全应急响应中心，诚邀广大安全专家共捍亿万互联网用户安全。

  

![](../Images/8d227c99a6723fab4fc32ab0d18d91d6.png)

最后，让我们用一张图来认识TSRC这群可爱的白帽子们吧。**幸得诸君相扶携。**
