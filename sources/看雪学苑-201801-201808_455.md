# Windows 又有大动作：可在Linux 和 macOS 平台运行PowerShell

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458287639&idx=2&sn=23323fd65d04a4629836f5e69e25c956&chksm=b1814e9d86f6c78b6d29c0da592545982f66985bffbfe73ec9aaf91c864b9678fae45dde7344&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458287639&idx=2&sn=23323fd65d04a4629836f5e69e25c956&chksm=b1814e9d86f6c78b6d29c0da592545982f66985bffbfe73ec9aaf91c864b9678fae45dde7344&scene=27#wechat_redirect)

微软发布了一款开源、跨平台的 PowerShell，命名为 PowerShell Core 6.0。后续，该版本将进入持续开发。同时，我们在过去10年间使用的原始PowerShell版本将只进行安全性更新。  

  

1月10日发布的PowerShellCore通用包，可以用于 Windows 7及以上版本、Ubuntu、Redhat、CentOS、macOS、Fedora、OpenSUSE和Debian。这使得系统管理员可以在自己管理的所有服务器上使用相同的管理脚本语言。

 

微软已经为macOS、Linux和Windows版本的PowerShell Core 创建了安装指南。在Windows上安装 PowerShell Core，只需要下载安装包并执行即可。

  

安装后，PowerShellCore 与已安装的 PowerShell 并存。通过这种方式，你可以测试已有的 PowerShell 脚本，并迁移到 PowerShell Core。

 

为了在 Linux 和macOS 平台上安装 PowerShell，微软几乎在所有Linux 平台上发布了安装包。例如，在Ubuntu 16.04 上安装 PowerShell Core，可以使用如下命令：

 

> \# Import the public repository GPG keys
> 
> curl https://packages.microsoft.com/keys/microsoft.asc| sudo apt-key add -
> 
>  
> 
> \# Register the Microsoft Ubuntu repository
> 
> curlhttps://packages.microsoft.com/config/ubuntu/16.04/prod.list | sudo tee/etc/apt/sources.list.d/microsoft.list
> 
>  
> 
> \# Update the list of products
> 
> sudo apt-get update
> 
>  
> 
> \# Install PowerShell
> 
> sudo apt-get install -y powershell
> 
>  
> 
> \# Start PowerShell
> 
> pwsh

 

当 PowerShell Core 安装后，可以在终端输入 pwsh 命令启动它。

  

![](../Images/8691f9fb9a7c2b4b7c935e68cf56dced.png)

PowerShell Core on Ubuntu 16.04

 

遗憾地是，为了保证 PowerShell Core 在不同操作系统上正常运行，微软不得不移除了一些功能。

 

> *作为向 .NET Core 和其他操作系统迁移行动的一部分，我们被迫放弃一些 Windows PowerShell 上使用的技术。*
> 
> *另一方面，我们利用这个重构机会，停止支持了一些较少使用的技术。其中一部分会重返PowerShell Core，但是许多技术会被放弃。*

>  
> 
> 从上层看，这些技术包括：
> 
>   •    PowerShell Workflows
> 
>   •    PowerShell Snap-ins
> 
>   •    WMIv1 cmdlets (Get-WmiObject, Invoke-WmiMethod, etc.)
> 
>          ◦   我们建议使用 CIM/WMIv2 cmdlets (Get-CimInstance, Invoke-CimMethod, etc.)
> 
>   •    Executing Desired State Configuration (DSC) resources using PowerShellCore
> 
>  
> 
> 我们也进行了一系列针对 PowerShell 语言、引擎、cmdlet的改动，技术上称之为重大变化（breaking changes）。
> 
>   
> 
> 如果希望了解这些改动/移除的原因，请参考文档 Breaking Change(https://github.com/PowerShell/PowerShell/tree/master/docs/BREAKINGCHANGES.md).

  

这些改动将使得已有的 PowerShell 脚本无法直接在 Core 中正常运行。
