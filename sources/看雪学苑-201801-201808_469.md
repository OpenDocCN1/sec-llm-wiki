# Chrome在线商店惊现 4 款恶意扩展软件，50多万用户受到影响

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458287569&idx=2&sn=629da31510b4a6f1caece14ce432d3b4&chksm=b1814d5b86f6c44dcff1c6f7807a71273e03c91f74907c24e5e393932c3f4ff7d28fff656264&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458287569&idx=2&sn=629da31510b4a6f1caece14ce432d3b4&chksm=b1814d5b86f6c44dcff1c6f7807a71273e03c91f74907c24e5e393932c3f4ff7d28fff656264&scene=27#wechat_redirect)

![](../Images/6a5939b92e30c4e243d0f07586bbe15c.png)

来自美国网络安全公司ICEBRG的安全研究人员发现了四款携带恶意代码的Chrome扩展，这些扩展均可在Chrome WeB Store中找到。

 

研究人员称，攻击者可利用这四款扩展向受害者的浏览器以javascript的形式发送恶意指令，但要利用该漏洞，必须在后台运行一个网站，且受害者必须点击该广告，才能实现实现点击劫持攻击。

 

这四种扩展分别是：

> *   *Change HTTP Request Header  
>     *
>     
> *   *Nyoogle - Custom Logo for Google*
>     
> *   *Lite Bookmarks*
>     
> *   *Stickies - Chrome's Post-it Notes*
>     

 

在写这篇文章时，有三款恶意扩展已从商城下架，但仍可在Chrome的WeB Store中找到Nyoogle 。

 

直到该恶意行为被ICEBRG 公司发现时，已经有超过50万用户正在使用这些扩展，ICEBRG 公司立即通知了荷兰国家网络安全中心(ncscl - nl)、美国计算机应急准备小组(US-CERT)和谷歌安全浏览操作团队。

 

尽管已经有3个扩展被移除，但仍然有相当一部分用户在浏览器中使用该扩展。

 

ICEBRG公司已经发布了关于这些恶意扩展的细节，请用户尽快检查并将之移除。

 

目前还不清楚这四种扩展是否都是属于同一类别，但ICEBRG表示，这四种扩展的策略、技术和程序(TTPs)都有相似之处。
