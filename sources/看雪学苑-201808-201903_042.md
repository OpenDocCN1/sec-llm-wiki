Window 7以及以上系统的ETW日志自带了一个注册表日志信息的输出，在windows事件查看器的Microsoft  Windows Kernel Registry / Analytic可以看到并且开启或者关闭注册表日志，它的监控操作包括CreateKey\_Opt,OpenKey\_Opt,DeleteKey\_Opt,QueryKey\_Opt,SetValueKey\_Opt,DeleteValueKey\_Opt和QueryValueKey\_Opt，监控的输出数据根据每个不同的操作它的内容也不一样，例如：

```


CreateKey_Opt  
```

  

更多具体的数据，读者可以自行去研究我们今天讲解的不是他的具体使用方法，而是windows内核是怎么样实现输出这些数据的。
