# 使用Fing在手机上诊断网络状况

Fing是Android和iOS上的一款网络工具类应用，可以进行多种网络诊断，十分方便。  

  

  

## 

扫描当前所在的局域网的主机

  

打开app主界面，app将自动扫描手机所在局域网的所有主机。这样我们就可以知道局域网中有哪些设备，从而找到可能的恶意入侵者，如蹭网的设备。

  

![](../Images/56f9d18997e7b54a67e70d436b1a1f1f.png)

#   

#   

## 

互联网速度测试

  

很多时候，我们想弄清公网的性能参数，如网速到底快不快。这时候，可以使用Fing的“互联网速度测试”功能。点击`网络-->互联网速度测试`，即可测试到公网的延迟、上传速度、下载速度。测试数据将以可视化的方式呈现，十分直观。美中不足的是，该服务无法在国内使用。

  
![](../Images/47b9d24e94ca206f5623c80f8664f3f8.png)

#   

#   

## 

ping测试

  

在Fing中，我们可以方便地对主机进行ping测试，从而了解丢包率和网络时延。点击`网络-->ping`，并输入需要测试的主机IP地址或域名，app将会执行ping测试，并以可视化形式呈现测试结果。

  
![](../Images/472bed23ed29109375e086a2a69e8a3e.png)

#   

#   

## 

扫描开放端口

  

我们都知道，对主机进行渗透测试的第一步往往是扫描主机上开放的端口，并判定运行的服务。有了Fing，我们可以省去端着笔记本电脑运行nmap的麻烦，只需要点击`网络-->Find open ports`，并输入需要扫描的主机IP地址或域名，即可扫描该主机上开放的端口和服务名称。

  
![](../Images/a1f60e46c95b3157c0128ca94c4cc32b.png)

#   

#   

## 

traceroute测试

  

traceroute可以用于诊断主机将数据包发送到目标服务器时，数据包通过了哪些路由器，是一个重要的网络诊断工具。作为一款流行的网络工具类应用，Fing当然也内置了traceroute指令。点击`网络-->traceroute`，并输入目标主机IP地址或域名，即可进行traceroute诊断。

  
![](../Images/73e85a1ec154aca0fbfa30632b5d326f.png)

#   

#   

# 

## 

结语

#   

Fing作为一款免费的网络工具类应用，提供了实用、易用的网络诊断功能，可以让我们直接在手机上进行网络诊断，降低了网络诊断的门槛。不过，测速功能在国内无法正常使用。因此，我们建议配合著名的测速应用Speedtest来使用，以达到更好的效果。
