*   ### **3.1 补丁的探讨**
    

  

我们来对安全的版本进行一点小小的讨论：

```
[+] g_UseAfterFreeObject = 
```

  

随着思路的推理，我们的嘴角逐渐浮现出笑容， windows 7 下， 我们可以对申请0地址，并且填充相应的内容。假设shellcode地址为0x00410000，我们通过对0地址进行填充内容。

```
00000000: 00410000 
```

  
我们也能顺利执行我们的shellcode. ==> 此处引发了一个空指针解引用漏洞。
