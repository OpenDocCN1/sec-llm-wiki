# 企业不能缺“核心”？ CSS2019 带您看“核心”？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458298088&idx=5&sn=da7070887bbfe74962ed899909873faf&chksm=b181966286f61f746eab2b315604b1a426f0680fc1c091d995a1bd03d2e213a1f3dc3ca9bb3c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458298088&idx=5&sn=da7070887bbfe74962ed899909873faf&chksm=b181966286f61f746eab2b315604b1a426f0680fc1c091d995a1bd03d2e213a1f3dc3ca9bb3c&scene=27#wechat_redirect)

7月30日，为期两天的第五届互联网安全领袖峰会（Cyber Security Summit2019，简称CSS2019）在北京正式揭幕。

  

作为中国互联网安全产业发展风向标，本次大会以“产业升级、安全升维”为主题，首次聚焦产业互联网发展背景下安全行业的变化及趋势，并指出，安全将成为企业在产业互联网时代的核心竞争力之一，而这一竞争力的构建，既需要从战略视角统一规划，也离不开安全产业链的生态协同与支撑。

 

关于CSS

 互联网安全领袖峰会（Cyber Security Summit，简称CSS）由腾讯与企事业单位联合主办。自2015年首届举办以来，已吸引超过数万名行业精英参会，超过500家国内外顶尖企业与会，百位国内外大咖莅临分享前瞻观点。CSS已经成为全球规模最大、最有影响力的互联网安全合作交流平台，是安全行业和企业不容错过的世界级安全盛会。

CSS 2019以“产业升级 安全升维”为主题，围绕金融安全、云安全、大中型政企通用安全、大交通安全、产业与安全标准化等议题展开，同时邀请到来自国内外的重磅嘉宾，包括亚马逊、IDC等不同领域的企业负责人，国内知名工程院院士，共同探讨产业安全的未来与机遇。

  
十年前，在大部分人的理解中，企业很少有安全部门，至多是运维部门承担部分安全责任，大部分网络上的业务还未批量出现。2007年的《信息安全等级保护管理办法》和2008年的《信息安全等级保护基本要求》才刚刚实行并推进。安全人才还是处于被边缘化的阶段。各大企业的领导的职业晋升之路还是以业务驱动型为主。  
十年后，等级保护2.0已出台，超9亿人通过手机、电脑、平板等接入互联网。“产业升级 安全升维”刻不容缓。很多业务场景已转入互联网。我们试着想想订一瓶水，随手打开微信小程序的场景。互联网方方面面已融入生活。不同行业对安全部门的重视是前所未有的，很多企业增加了安全部门，并且也组建了应急响应中心团队，花钱收集社会安全人士提供的情报和漏洞风险。  
微信支付、Facebook的Libra等互联网创新模式，已经让很多传统行业感受到到了科技进步所带来的焦虑。很多企业领导大部分是业务出身。所以企业向互联网转型的时候需要很多思路和方案。腾讯的CSS“产业升级 安全升维”的主题正好为传统企业和互联网企业搭建良好的沟通桥梁。  
![](../Images/43da4682ab5d056dea39425d1353705a.png)腾讯与P17成员达成全新合作机制：“生态资源共享、能力互补、生态共建”  
随着互联网脚步的加快，企业要做好产品、业务、品牌，不仅仅要好的运营模式，还需要有安全保驾护航。“独行快、众行远！伴随产业互联网的发展，以及增量安全需求的复杂性，加快安全生态协同共建，已经迫在眉睫。”  
在P17安全领袖圆桌马斌表示，产业互联网背景下的安全产业趋势变化，促使安全产业链伙伴的加速融合。云计算打破了传统的网络边界防护，物联网使企业的信息资产无处不在，企业业务模式和场景越趋复杂，对于安全服务提出了更高要求；一家企业或机构的安全规划与建设，很难由单一一家安全企业提供完整技术能力来解决。  
![](../Images/d695fe9210035940b84c9bba95c95b7b.png)  
丁珂在会议最后总结中也表示，P17的存在，不仅是为了探索更深入的合作模式，打开安全行业更大的想象空间，更重要的使命是通过安全生态链的协同共建，打造贴近真实业务场景的安全解决方案，降低企业客户的安全门槛，保障各行各业的安全发展，共担守护产业互联网安全的职责。  
腾讯CSS联合各路安全厂商，共筑安全生态是为了更好的加快传统行业在互联网激流中适应生存，获得更好的资源和发展空间。CSS正在影响着行业的变革和发展。  
作为安全行业的风向标，CSS领袖峰会每年都会聚焦一个主题，和大家一起探索安全发展的趋势。今年的会议主题自然离不开产业互联网。“产业升级 安全升维”是大同，亦是未来的趋势。  
  

如何构造适应时代变化的企业？

  

![](../Images/45d938b30be92ad9a6eb93f7f9307038.png)  
小编在听过众多议题后，纷纷感慨企业的发展离不开安全技术支撑。随着5G时代的到来，未来会有更多的业务场景暴露在互联网上。这些业务场景将和我们息息相关。每个企业，都不想让自己的客户数据被黑客轻易窃取。企业安全将迎来巨大的挑战。  
4G时代我们有了很好的沟通方式，让微信支付、视频直播、打车、共享单车、物联网设备产品等得以迅速发展。5G呢，将迎来更多的未知机遇。做好安全才能拥抱未知领域的不确定性，得以安稳创新，获得更好的企业发展。  
我们建议企业需要建立自有的核心安全。很多企业会说，安全部投入没产出，建设困难且成本高。在CSS大会上，腾讯已称开放安全中台，降低企业安全建设门槛。未来，核心安全建设并不是非常困难的事情。或许在众多安全企业的支持下，反而非常简单。企业重视安全部门后，将会更好更快的适应互联网的发展。创新技术需要有良好的安全技术支撑环境。当所有的运维和测试都归属安全部门管理后，业务部门的上线业务将得到质量保证。任何产品上线通过安全部门审核并批准，将大大降低产品的使用风险。保证了其信誉、美誉及用户的认可。  
每年召开的CSS峰会在引导行业在安全建设上是非常有帮助的，从议题内容、把握的前沿科技、人才技术等做出了大量的投入。腾讯在为用户服务的时候，总结的安全建设经验、风控知识在其他行业中是可以有所借鉴。适应时代的发展，核心安全部门投入必不可少。
