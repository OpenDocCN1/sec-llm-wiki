# 迅雷下载服务加速节点的来源分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458297350&idx=1&sn=dfe85c83dc762b0320b1dba4914c1cd0&chksm=b181948c86f61d9a44e82aa234b7c9ac97edb475cb914f4eae72c7e7e27cb7afa5caf000669b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458297350&idx=1&sn=dfe85c83dc762b0320b1dba4914c1cd0&chksm=b181948c86f61d9a44e82aa234b7c9ac97edb475cb914f4eae72c7e7e27cb7afa5caf000669b&scene=27#wechat_redirect)

迅雷前端逻辑：electron + nodejs  

迅雷后端逻辑：lua5.3

随便对一个种子进行加速，种子内有5个文件。

  

![](../Images/51817f39d2ca7305f212833af9c5efbd.png)  

  

看到后端下载服务访问了以下网址：

  

![](../Images/2fba02cc970a5f9bbb475b1a462dda14.png)  

![](../Images/f14fc2a453a32b660cd6055e5f64e0c3.png)  

  

内容都经过加密，先附加到下载服务上。  

  

![](../Images/e1fd0f431d1d7a3f980d5ced11c87d50.png)  

![](../Images/2a0c86951ab3bc434a45fbb8c0e6d411.png)  

  

发现其使用AES-ECB加密，解密后，可以发现：hub5btmain.v6.shub.sandai.net 接口返回种子内每个文件的GUID和CID。

  

![](../Images/4ed1bfaf77e288e3445d1bdb79bb65a4.png)  

  

拿到gcid后，作为参数传递给lua脚本LuaServiceSHubQueryBTFileIndexCallBack::LuaCallBack 进行处理。

  

![](../Images/10c754581743a741cb34609b0d392ec2.png)  

![](../Images/bad92655e037ab64108282f7325c45ca.png)  

  

想办法把其lua脚本都提取出来，其脚本都打包为xar文件中，我们找到loadbuf函数。

  

![](../Images/6b6adf9f0cd09c3f877da5ed1f50f5da.png)  

![](../Images/20aac1f95c15492d648cfe41247bbc03.png)  

  

直接做HOOK注入到下载进程中，DUMP出来。

  

![](../Images/ab47d0dad4e6e20a4daf5bd284bc600f.png)  

  

这样我们就全部解析出来了。

  

![](../Images/f2485328823cd044c2ebff80b7745d23.png)  

  

有了种子里面的每个文件的信息后，就可以去请求加速节点了。迅雷用的是流协议，看下它是怎么请求的：

  

![](../Images/f16672fc90c372741cc3680e705c53fe.png)  

  

可以看到，迅雷请求的时候，把要查询的种子内的文件的guid和一个jwt的token还有种子信息都发给了dcdnhub.xfs.xcloud.sandai.net:80进行查询。

  

![](../Images/1f19a7c76ba5d77ed118276591f2f783.png)  

![](../Images/229c9a045fc1da0aff3ed303debf290b.png)  

  

看下token内容：

  

![](../Images/c6cd794cbb4191151d2554ece68d2c68.png)  

  

接着解密下节点服务器返回的信息：

  

![](../Images/b9d90bafe0d3380854000aff0143be0e.png)  

  

逆向其反序列的函数：

  

![](../Images/16787fb0bdcaea3d94b9f739c80abd88.png)  

  

已经很明显了，我们写个反序列化的代码：

  

![](../Images/aae5d8211e8f6274cae41a6502a79716.png)  

  

拿到这些peer\_server后就可以加速了。这样的话，我们就可以拿一个会员账号给一千个人进行加速拉。

  

奇怪的是为什么peer会有个人ip。

  

难道是~开会员用其他没开会员的人加速?。嘿嘿。
