# 【报名已开启】上海交通大学Let’s GoSSIP软件与系统安全暑期学校

从2015年开始每年暑假都与大家不见不散的上海交通大学Let’s GoSSIP软件与系统安全暑期学校，2019年活动正式定档7月20日至7月24日。作为五周年版本，今年的暑期学校邀请了来自国内、美国和欧洲学术和工业界的超豪华的讲师阵容与大家共同探讨当下最热门的安全话题。

  

![](../Images/31f35c25ae92f16492da73f69af90926.png)

关于暑期学校

  

2015年上海闵行，黄浦江边不到一公里古老而又年轻的上海交通大学闵行校区，许多年轻人在酷热的七月聚集在这里，参加了一个为期五天的课程活动，这个活动后来被命名为“Let's GoSSIP软件与系统安全暑期学校”，是国内最早的以软件系统安全为主的暑期学校。

  

这一年早些时候，Let's GoSSIP软件与系统安全暑期学校的主办方，上海交通大学蜚语软件安全研究小组（G.O.S.S.I.P）的成员们刚刚拿到了中国大陆地区在国际信息安全竞赛中的第一个世界冠军——2015年韩国的CODE GATE CTF比赛冠军，并经过48小时鏖战第一次杀入了世界最顶级CTF竞赛——DEF CON CTF决赛圈。

  

同时，蜚语软件安全研究小组（G.O.S.S.I.P）的第一篇国际顶级学术会议论文，后来荣获上海市计算机学会信息安全最佳论文奖的From Collision To Exploitation: Unleashing Use-After-Free Vulnerabilities in Linux Kernel也正在CCS会议的审稿人的案头有待接收。

  

那年夏天的暑期学校之后，有很多人继续留在交通大学的校园，开展了为期两个月的实习。蜚语软件安全研究小组的博士、硕士和本科生们，在七月流火的暑假，每天开展学术论文讨论，进行项目技术攻关，同时还会在周末通宵达旦来一把CTF竞赛。

  

这个传统被保留了下来，第二年开始，暑期学校邀请了更多的国际学术大咖授课，而国内许多信息安全氛围浓厚的高校的本科生也借暑期的空闲时间，前往交大参与了新一年的暑期交流活动。

  

此后每年的暑假，越来越多的年轻面孔出现在闵行，来自武汉、西安、南京、成都、北京、南昌、桂林等全国各个地区的小朋友们，怀着对安全研究的抱负，在交通大学闵行校区这个远离上海闹市繁华喧嚣的校园里，充分挥洒安全技术的热情。

  

一年又一年，这里走出了许许多多的安全研究新生力量：有人留在交大继续从事安全研究，并且在国际国内学术和工业界舞台上大放异彩；有人远赴美利坚攻读博士学位，在安全顶级学术会议上收获颇丰；有人前往国内顶级的企业继续从事安全研究，并在各类安全赛事上披荆斩棘。

  

暑期学校的举办，同样为G.O.S.S.I.P小组提供了与国际一流学者以及充满热情的年轻学子交流合作的契机，迎来又送走了一批批莘莘学子，2018年的G.O.S.S.I.P小组，在安静地积蓄能量，茁壮地生长。

  

2018年，我们不仅在国际顶级安全学术会议CCS上发表了研究论文《K-Hunt: Pinpointing Insecure Cryptographic Keys from Execution Traces 》，在2018 互联网安全领袖峰会发表主题演讲《易伪造的数字钥匙——智能门锁Token安全性分析与防护》，在2018 DEF CON 神州安全大会发表主题演讲《路上Wi-Fi欲断魂：攻击SmartCfg无线配网方案》，同时还荣获“蚂蚁金服2019年度安全生态杰出伙伴”奖（国内高校唯一，连续三年获奖），获得小米安全中心（MiSRC）漏洞修复致谢（2019年4月）；小组两位在读同学在第三届全国高校网安联赛（X-NUCA 2018）总决赛中获得总决赛团队特等奖（第一名）荣誉，两位在读同学在2018年网鼎杯信息安全竞赛中赢得总成绩第四名，高校组亚军荣誉，多名毕业生和两位在读同学在2018年DEF CON CTF总决赛中赢得全球第四名荣誉！2018年，G.O.S.S.I.P小组的4名90后年轻成员们还迎来了一个超级重量级的奖励——作为项目完成人荣膺2018年上海市科技进步奖一等奖表彰，成为了90后青年科学家的杰出代表！

  

2019年，Let's GoSSIP软件与系统安全暑期学校迎来了五周岁生日。作为五周年版本，今年的活动将由超级豪华、来自海内外的顶级安全研究专家组成的讲师团担纲，为大家提供最热门的软件漏洞挖掘、智能设备安全分析、人工智能安全、密码学安全等课程。
