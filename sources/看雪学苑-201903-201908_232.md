**1、极光行动----漏洞分析**（精华）****

作者：与时尽现。

原文链接：https://bbs.pediy.com/thread-251672.htm

点评：极光行动（英语：Operation Aurora）是2009年12月中旬可能源自中国的一场网络攻击，其名称“Aurora”（意为极光、欧若拉）来自攻击者电脑上恶意文件所在路径的一部分。这篇文章分析了该行动的恶意代码，虽然很老，但是很经典。

  

**2、VMProtect 3.3.1虚拟机&代码混淆机制入门（精华）**

作者：luocong

原文链接：https://bbs.pediy.com/thread-251680.htm

点评：本文是对VMProtect 3.3.1虚拟机和代码混淆机制的笔记，是最新版本的分析，值得收藏。

  

**3、某陌交友APP协议分析与加解密还原（精华）**

作者：某警官

原文链接：https://bbs.pediy.com/thread-251689.htm

点评：作者采取抓包和逆向分析的方法来分析这款APP的协议和加解密算法。适合有一定基础的同学阅读。

  

**4、xx搞笑关注功能分析（精华）**

作者：轩野

原文链接：https://bbs.pediy.com/thread-251693.htm

点评：这篇文章展示了iOS程序分析的基本思路：首先找按钮、抓包确认切入点，然后使用IDA/Hope静态分析确认函数流程，最后测试。

  

**5 、CVE-2019-0725 | Windows DHCP Server Remote Code Execution Vulnerability漏洞分析（优秀）**

作者：祈寒Alice 

原文链接：https://bbs.pediy.com/thread-251677.htm

点评：文章首先介绍了漏洞的背景，然后介绍了漏洞的影响范围，接着简单介绍了DHCP协议，最后是分析与实操部分。
