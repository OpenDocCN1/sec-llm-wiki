# 5月全球Web服务器报告，群雄逐鹿，谁会笑到最后？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458296653&idx=4&sn=e6a35bfafb5f2330928ed71d6c8ff61c&chksm=b18191c786f618d1bee2cf9c8a86dd6a6349de5424cb2be875e7a6de15f4c2cab9bb65a9e467&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458296653&idx=4&sn=e6a35bfafb5f2330928ed71d6c8ff61c&chksm=b18191c786f618d1bee2cf9c8a86dd6a6349de5424cb2be875e7a6de15f4c2cab9bb65a9e467&scene=27#wechat_redirect)

Netcraft 发布了 2019 年 5 月份全球 Web 服务器调查报告。Netcraft 公司官网每月公布的 Web Server Survey 是当前人们了解全球网站数量以及服务器市场分额情况的主要参考依据。5 月份报告共收录了 13.26亿 个站点数据，比上个月减少了 1.19 亿个，其中活跃站点有 1.87亿 个。

  

  

  

**整体呈下降趋势，Microsoft不容乐观**

  

在所有站点数据中，本月 Web 服务器排名前3 情况与 4 月份一致，分别是：

  

①   Nginx（是一款轻量级的Web 服务器/反向代理服务器及电子邮件（IMAP/POP3）代理服务器，在BSD-like 协议下发行。其特点是占有内存少，并发能力强，事实上nginx的并发能力确实在同类型的网页服务器中表现较好，中国大陆使用nginx网站用户有：百度、京东、新浪、网易、腾讯、淘宝等。）

  

②   Apache（是Apache软件基金会的一个开放源码的网页服务器，可以在大多数计算机操作系统中运行，由于其多平台和安全性被广泛使用，是最流行的Web服务器端软件之一。它快速、可靠并且可通过简单的API扩展，将Perl/Python等解释器编译到服务器中。）

  

③   Microsoft

  

![](../Images/579e9e12c11a311c3ef32286e82b1b98.png)

  

其中 nginx 相比上个月新增了 1.68%的市场份额，达到 29.20%；Apache 增长得更多，2.34% 的涨幅达到了 29.07% 的份额；而 Microsoft 继上个月下降 1.01 个百分点，本月更是下降高达 6.18%，目前占比只有 18.88%。

  

虽然 nginx 与 Apache 市场份额都上涨了，但其实在 5 月份的数据中，二者站点数量都有所下降，其中 nginx 减少了 1031 万站点，损失惨重；相比之下，Apache 仅减少了69 万站点，目前二者的市场份额也因此咬得比较紧，仅有 0.13% 的差距。

  

而 Microsoft 数据更加不乐观，它 5月份数据的低迷不仅包括市场份额巨幅下降，同时也失去了 1.12 亿托管站点，减少占比高达 30.8％。

  

这三个大头数据都下降了，特别是 Microsoft 与 nginx，其实就是造成 5 月份整体站点下降比例高达 8.2%（共减少 1.19 亿站点）的主要源头。

  

![](../Images/bdb60c7ba5f18172bc9720885fe05a22.png)

  

活跃站点方面，市场份额排名前三分别是：Apache、nginx 与 Google，三者活跃站点数量都有所增加，nginx 与 Google 市场份额小幅上涨，Apache 下降了 0.46%。

  

![](../Images/431523688b938923955fdfd44278a3cf.png)

  

  

  

**百舸争流中的后起之秀**

  

5 月数据中有两个服务器值得关注，分别是 Envoy 与 cPanel。  

  

## Envoy

Envoy 在经历了 500 倍的增长之后突然跃居第 10 位，其站点数量从 10 300 猛增到 510 万，其中包括独立域名 273 万。这些网站大部分由 SquareSpace 托管，它提供易于使用的网站和在线商店建设服务，其中包含带有现成模板的拖放式布局。  

  

Envoy 是一个开源的边缘和服务代理，用于云原生应用，它是为单一服务和应用程序设计的高性能 C++ 分布式代理，以及为大型微服务 Service Mesh 体系结构设计的通信总线和通用数据平面。

  

Envoy 最初由 Lyft 创建，但 SquareSpace 现在是其最大用户。SquareSpace 工程师追求 Kubernetes 的自助服务基础设施来处理其软件的复杂性，但为了跟上增长和需求，他们在一年多前开始将 Envoy 代理集成到他们的系统中以构建 Service Mesh 控制平面。

  

Envoy 站点数据如此变态的增长，可见被称为“新一代微服务构架”的 Service Mesh 正在得到更加广泛的应用。

 

## cPanel

本月数据还显示 cPanel 站点数量达到735 万个，排名第 9 位。cPanel 是一个基于 Linux 的 Web 托管控制面板，提供了一个图形界面，用户可通过安全管理网站。  

  

虽然 cPanel 界面针对的是个人最终用户或托管客户，但其 Web 托管管理界面允许托管服务提供商管理大量 cPanel 用户帐户并向其客户的仪表板添加自定义品牌。

纵观其他数据，以我们所知道的，Apache 从 1996 年一直都是 Web 服务器中的市场份额王者，它称霸了 18 年，近几年来这个情况才有了一些变化。在 2014 年，Apache 首次被微软挤下第一名的宝座，虽然在 2016 年初重回第一，但在本月跟上个月一样，市场份额再次被 nginx 超越。对此 Netcraft 表示，nginx 成长力道强劲，在一两年内就会挑战到 Apache 在整个互联网的地位。

  

在这场互联网服务器的竞争中，到底是三大领头羊依然笑傲江湖，还是后浪把前浪拍到沙滩上，这一切都交给时间去回答。
