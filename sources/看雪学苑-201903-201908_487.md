# **总决赛等你！**

  

想要进入2019看雪CTF总决赛？

  

![](../Images/f04071b6bba8cab29eed860c6a485c52.png)

![](../Images/153431874337c55f73e56362bb576a5e.png)

除了实力，了解规则也很重要~

  

**赛制：**

*   引入了3次晋级赛（每季度一次），1次总决赛。
    
*   每次晋级赛的防守方第1名和攻击方前3名直接进决赛。
    
*   其他战队按照3次晋级赛总排名，防守方前6名和攻击方前9名进入总决赛，缺位后补。
    
*   总决赛一共9个防守方，18个攻击方。
    

  

**题量与判定规则：**

*   晋级赛每次6-8题，一次性放题，赛期14天，主要看破解次数。
    
*   总决赛9题，2天放1题，赛期18天，主要看破解时间（与过去相同）。
