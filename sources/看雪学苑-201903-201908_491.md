```

```

2、OD载入目标PIMOne.exe，忽略所有异常，隐藏OD。

```

```

  

3、先禁用上面两个断点，F9运行，弹窗三次点OK，并Shift+F9运行，出现试用弹窗，此时先激活上面两个断点，再点OK，停在75A21B48，观察堆栈。

```
00129490 01
```

  

4、单步F7（F8）返回到：

```

```

  

在该行右键点数据窗口跟随：

```

```

  

改成：

```
01
```

  

5、（壳已自解码）反汇编窗口Ctrl+B查找74??6800010000（两个都不勾选）找到：

```

```

  

6、F9运行，断在75A21B48，禁用此断点，继续F9断在75CEDE93，也禁用此断点。F7（F8）返回到：

```

01A0713C 50 push eax
```

  

7、继续F8单步直到返回：

```

```

  

8、点01A35345这一行F4，再F7跟入到达OEP=0063374C，此时用LordPE（修正大小）来Dump为dumped.exe，填入OEP：23374C，ImportREC自动方式获取API，剪切多余项，转存为dumped\_.exe，OK。

  

  

## 二、Print2Flash4

   

 ExeinfoPE查壳，显示为：

```

```

  

1、复制ArmAccess.dll到目标主程序print2f4.exe目录；  

  

2、OD载入目标print2f4.exe，忽略所有异常，隐藏OD。

```

```

  

3、多次F9运行，弹窗三次点OK，并Shift+F9运行，停在75A21B48，观察堆栈：

```
00129010 01
```

  

4、单步F7（F8）返回到：

```

```

  

在该行右键点数据窗口跟随：

```
01
```

  

改成：

```
0202
```

  

5、交替F9、F7（F8）运行到壳自解码（出现红字），停在：

```

```

  

跟随进入01F5B15C的CALL找到段首：

```


01F7AC10 55 push ebp
```

  

6、F9运行，断在75A21B48，禁用此断点，继续F9断在75CEDE93，也禁用此断点。F7（F8）返回到：

```

01F3CC0F 50 push eax
```

  

7、继续F8单步直到返回：

```

```

  

8、点01F61CE5这一行F4，再F7跟入到达OEP=006A30D8，此时用LordPE（修正大小）来Dump为dumped.exe，填入OEP：2A30D8，ImportREC自动方式获取API，级别1修复，剪切多余项，转存为dumped\_.exe运行73571304出错。  

  

9、老OD找到73571304出错的地方：

```
0040F4C0 - FF25 78916B00 jmp dword ptr ds:[
```

  

新OD载入dumped\_.exe此处缺函数名，故在老OD用UIF修复，新IAT放在006B8000段，重新dump并用ImportREC修复转存，OK。
