多位知名艺人飞行里程被盗用



你知道里程吗？旅客注册航空公司会员后，每次乘坐其航班出行，账户中都会获得一笔里程。里程达到一定数量，就可兑换机票、商品以及其他服务。

 

但近日爆出，吴磊的某位“粉丝”擅自将自己的航空公司账号与吴磊身份证号绑定，盗用他的里程积分，免费兑换了多张机票供自己和朋友乘坐。

 

无独有偶，随后江映蓉、李晨也在微博称发现自己的里程被大额盗用。

 

此次明星里程被盗一事本质上是艺人身份信息在第三方渠道遭到泄露，有人便钻我国航司系统受益人制度的空子，盗取艺人的航空账户，把里程积分转让给自己使用。

 
事实上，不止名人，任何人的里程都有被盗刷的风险。
 
《国际金融报》的记者发现，在部分二手交易平台，里程“黑市”交易早已在暗处滋生，成为一条新的购买特价机票的渠道。不仅如此，搜索关键词“里程购票”还会发现，在售的里程积分兑换的机票几乎涵盖大部分航空公司。
 
为此，呼吁大家提高个人信息保护意识，自查航空里程是否存在异常。

Win10累积更新致WSL2出bug



为方便开发者编程，微软在Win10中直接集成了Linux子系统，称之为WSL。WSL2（Windows Subsystem for Linux 2）附带了一个真实的Linux 4.19内核，能够带来完整的系统调用兼容性，无需更新整个Windows Linux的子系统，而是可以直接借助自动更新进行升级维护。

同时，WSL2比第一代的WSL1版本运行速度更快，提升了文件系统的I/O性能和与Linux的兼容性，且可本机运行Docker容器等。
 
但据 Windowslatest 报道，微软近日在补丁星期二面向所有尚处于支持状态的 Windows 10、Windows 8.1 以及 Windows 7 ESU 客户，正式发布Win10 KB4571756 补丁后，又出现了bug。
 
有用户反馈安装更新，使版本号升至 Build 19041.508后，WSL2就无法正常加载和使用，显示“Element not found error”（元素未找到错误）。
目前尚不清楚是什么原因导致此次的bug ,微软也尚未对此事做出回应。而GitHub已表明正在努力修复该问题。
 
因此建议使用WSL2的用户先不要更新该版本。若已经更新，目前唯一的解决方法就是前通过设置>更新和安全>Windows更新>查看更新历史>卸载更新，卸载该累积补丁更新。

全球首批32亿像素照片面世



昨日，美国 SLAC 国家加速器实验室发表博文称，研究人员用全球最大的数码相机拍摄了首批分辨率高达 32 亿像素的照片，这是有史以来分辨率最高的照片。
 
而拍摄这些照片的相机将被应用于斯坦福大学位于智利的“时空遗产调查”天文望远镜中，用于观测研究暗物质、暗能量等现象，以及搜索对地球产生潜在相撞威胁的小天体。
 
这些相机分辨率达到32亿像素的秘诀在于189 个分辨率为 1600 万像素的成像传感器。这些传感器被划分为25组，其中21组用于成像，其感光灵敏度可以发现比肉眼可见的物体暗1亿倍的物体，让人们看到数千英里外的蜡烛。每一组传感器价值最高达300 万美元，所有成像传感器的安装历时6个月。
 
值得一提的是，因其极高的像素，全尺寸显示一张照片需要378台4K电视机。而拍摄所得的照片放大之后，甚至能看到24公里外的高尔夫球。
 
目前相机组装尚未完成，预计整机测试工作将从 2021 年年中开始。
