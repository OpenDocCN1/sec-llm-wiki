# Win10修改注册表将无法关闭Defender；Safari被曝存在未修复漏洞；阿里云网盘App亮相

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458339416&idx=3&sn=3336bf393269f80bc61db15a9d16eafc&chksm=b18078d286f7f1c46b101f4b3a8348f317eaf3357ca37f51145ed008211dfe2892249080f8d9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458339416&idx=3&sn=3336bf393269f80bc61db15a9d16eafc&chksm=b18078d286f7f1c46b101f4b3a8348f317eaf3357ca37f51145ed008211dfe2892249080f8d9&scene=27#wechat_redirect)

昨日，谷歌发布了稳定版Chrome 85。该版本带来了许多标签页方面的改进，也提供了一系列开发者功能。更重要的是，该版本加入一种编译器优化技术PGO，可使代码中性能最关键的部分运行得更快。测试显示，引入PGO后，Chrome的页面加载速度平均提高了10％，且当CPU同时运行多个标签页或程序时，速度甚至会得到更大的提高。

Win10修改注册表将无法关闭Defender

  

![](../Images/bb80912f5dd3314e6f00a4d12211c9c8.png)

  

# Microsoft Defender 作为微软系统自带的杀毒软件，能更好地融合到系统中，不拖慢电脑运行速度，并在后台运行，检测、隔离和删除恶意软件感染、勒索软件和其他威胁。但同时，也有相当一部分用户认为它的功能不够强大，还占用系统资源。

#  

# 自2018年Defender被爆出存在远程代码执行漏洞后，更多Win10 用户选择通过修改注册表的“DisableAntiSpyware”键值，关闭Defender，自行安装第三方杀毒软件。

  

# 对此，微软为提供用户更妥善的安全保护，在近期发布的2020年8月更新（Version 4.18.2007.8）中更新了支持文档。若用户安装了其他杀毒软件，Defender将自动关闭；若用户卸载杀毒软件解决方案，Defender将强制自动开启。

  

# 此外，微软还强调这一变化不会影响第三方杀毒软件与Windows安全应用的连接，相关功能仍可正常运作。

  

# 这就意味着现在用户将更难禁用Win 10中的Defender，修改注册表项已不再管用，只能通过安装第三方杀毒软件、使用组策略编辑器等方式来禁用它。

 Safari被曝存在未修复漏洞

  

![](../Images/41fbf0aa0b861ca6a83249a6311fe3cf.png)  
近日，安全公司REDTEAM.PL和BlackOwlSec的创始人安全研究员Pawel Wylecial披露了苹果Safari浏览器中一个未修补的漏洞，可被攻击者利用，从目标系统中窃取用户文件。 该漏洞位于Web Share API中，会影响运行iOS 13.4.1和13.6，带有Safari 13.1的macOS Mojave 10.14.16，以及带有Safari 13.1.1的macOS Catalina 10.15.5设备。 Web Share API用于共享文本、链接、文件和其他内容。用户可以通过电子邮件、消息传递应用程序等第三方应用程序，与好友们共享来自Safari的链接。 利用该漏洞，黑客可建立含有文章和图像的恶意网站，诱骗用户点击页面上的按钮，将其分享给朋友。而共享消息中将包含来自用户文件系统的实际文件，用户共享该文件时，就会在不经意间导致本地文件泄露。 值得一提的是，该研究人员表示今年4月他就向苹果报告了该漏洞。经过数月分析，苹果8月表示会在明年春季解决该问题，要求他在此之前不要公开披露漏洞详情。 然而对于苹果拖延修复漏洞的行为，该研究人员为督促苹果公司早日修复漏洞，才毅然决定亲自公开该漏洞。

阿里云网盘App亮相

  

![](../Images/57f8ba538311ff824ab1ed6316aeffaf.png)  
如今在网盘市场，百度网盘一家独大，占据约85%的市场。然而，百度网盘的痛点也同样不少，不少用户都反映下载速度缓慢、买了会员照样限速、资源总是被禁等现象。 近日，阿里巴巴就推出阿里云团队开发的阿里云网盘App，主打可靠安全的文件备份存储和智能相册等服务，力图在网盘市场也分一杯羹。  
其具备空间大速度快、支持超大文件传输、海量数据集中管理、全方位安全保护、AI分类轻松找图、全新云上文件管理等亮点。  
与百度网盘相比，阿里网盘的普通用户容量为1000GB，只有百度网盘的一半。但开通会员后，其会员个人存储容量高达6TB，高于百度的5TB容量，还能享受5G极速下载体验。  
更重要的是，对比测试得出，即使不开通会员，阿里网盘的大型文件下载速度也可达到10MB/s，比起百度网盘1-2MB/s的速度，拥有质的突破。

#  

目前，阿里云网盘App采用邀请方式注册登录，尚未提供大规模下载。但它让用户多了一个新选择，也更有利于网盘产品的创新,值得期待。
