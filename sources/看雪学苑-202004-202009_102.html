首个可扫描窃取AWS凭证的僵尸网络



近日，安全研究专家发现了首个能够扫描和窃取AWS凭证的僵尸网络TeamTNT。
 
TeamTNT是一种加密挖矿的恶意软件，至少从4月开始就一直处于活跃状态。其运作方式是在互联网上扫描那些被错误配置的 Docker 系统，在没有密码的情况下，将其管理 API 暴露在互联网上。
 
并且TeamTNT的攻击范围还在扩大，已开始波及到与Docker同类型的应用托管容器平台。根据最新报告，其能通过访问API，在Docker安装以及Kubernetes 安装内部署服务器，进行DDoS攻击，运行加密挖掘恶意软件。
 
最特殊的一点是，TeamTNT甚至能扫描底层受感染服务器的任意亚马逊网络服务（AWS）凭证，窃取 AWS 凭证。
 
这就意味着若受感染的 Docker 和 Kubernetes 系统是运行在 AWS 基础设施之上的，TeamTNT就会扫描未加密的文件，将其复制并上传到命令和控制服务器上。攻击者就能获取包含底层AWS账户和基础设施的明文凭证和配置细节。
 
目前，TeamTNT已入侵许多Docker和Kubernetes系统。建议用户可使用防火墙限制对API的任何访问。同时，系统中不需要的AWS凭证文件，应尽快删除。

咸鱼想翻身：安全研究人员和恶意软件间的博弈只会越来越激烈。

 联发科最新 5G 芯片天玑 800U问世


随着5G时代加速到来，5G各类配套设备也在不断完善中。昨日，联发科就宣布推出了最新5G SoC——天玑800U，助力加速5G普及。

作为天玑800系列的新成员，天玑800U的CPU采用八核架构设计，包括2个主频高达2.4GHz的ARMCortex-A76大核，以及6个2.0GHz主频的ARMCortex-A55高能效核心，能带来强劲的高性能。而先进的7nm制程，则有利于处理器充分发挥性能优势的同时，降低功耗。

与其配套的还有ARMMali-G57 GPU、独立AI处理器APU和LPDDR4X内存，支持turbowrite闪存加速技术。

此外，天玑800U集成5G调制解调器。不仅支持Sub-6GHz频段的独立（SA）与非独立（NSA）组网，还支持5G+5G双卡双待、双VoNR语音服务、5G双载波聚合等前沿5G技术，能给用户带来中高端智能手机更高速、稳定的5G体验。

而在很多用户都关心的续航方面，天玑800U支持MediaTek5GUltraSave省电技术，可根据网络环境及数据传输情况，动态调整调制解调器的工作模式，以保证持久的5G续航。

咸鱼想翻身：双卡双持的5G芯片有点厉害，不知道以后会搭载在哪些手机里。

京东暂停与申通合作



近日，京东在卖家论坛里挂出《关于合作快递服务调的通知》，要求商家停用申通等几家快递公司产品，及时切换快递供应商，若不切换将影响到商家正常发货。
 
据京东开放平台表示，暂停与申通的合作是因为双方的合同已过期，且并未就续约达成一致。
 
他们称此前阿里通过战略投资成为了申通的实际大股东。京东物流就对等提出了入驻阿里旗下电商平台的合作需求，但至今未得到响应，导致双方合作破裂。
 
对此，申通快递却表示京东搞错了，目前其大股东依旧是公司董事长，而非阿里巴巴。针对后续合作的事宜，申通还在积极与京东沟通解决问题中。
 
此外，申通负责人还表示“申通不是第一家被京东停用的快递公司，更不会是最后一家。霸权文化京东一直就有，只有自己，没有共生。”
 
据悉，因目前申通快递主要业务在淘宝和天猫平台，京东在申通物流中占比其实很小，所以对申通本身的影响并不大。但对于选择申通快递的客户和商家来说，会造成一定影响。
