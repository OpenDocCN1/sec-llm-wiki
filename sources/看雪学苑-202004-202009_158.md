近日，IBM发布了完全同态加密FHE工具集的 Linux 版本，并将源代码发布在 GitHub 上。FHE 工具集运行在一个 Linux docker 容器内。这项新技术可以直接在加密的数据中进行检索、比较等操作，无需对数据解密后才可处理数据，能从根本上解决将数据及其操作委托给第三方时的保密问题。

特朗普：TikTok 9/15前不卖给美企就关门

  
![](../Images/bb13f1cff0eeaea50ffd28aca6175752.png)  
继美国总统特朗普威胁禁止TikTok在美国运营后，如今事件又继续发酵。 昨日，特朗普对TikTok再次发出恐吓，要求TikTok必须在9月15日前卖给美国。他还表示赞成微软收购TikTok，且就算不是微软，只要是一家安全的美国大公司买下都可以，否则TikTok就将必须关门。 同时，他还特意强调，无论TikTok与哪家公司完成交易后，都必须交相当大一部分钱给美国财政部。因为是他们让这笔交易成为可能。 对此，微软也在与美国政府沟通后，计划重启收购TikTok的事宜，希望拥有其在美国、加拿大、澳大利亚和新西兰四国的所有权和经营权。微软前CEO也表示，此次收购是令人兴奋的，有助于微软真正扩大消费者基础。 而TikTok CEO张一鸣称目前还未完全决定最后的解决方案，但不会放弃探索任何可能性，继续尝试与一家科技公司讨论形成合作方案，以确保 TikTok 能继续服务美国用户。  
其母公司字节跳动则在最新作出的正式回应中称，正在考虑在美国之外的主要市场，重新设立TikTok总部。

咸鱼想翻身：TikTok 正是美国泛化国家安全概念，在拿不出任何证据的情况下抵制中国的受害者。你怎么看待这件事呢？

 假iPhone 749元可换真机

  

![](../Images/0f5732050872586023b388cbaf0a2712.png)  
近日，瑞士海关人员截获两个装有50部假iPhone的包裹后，才发现，有一千多部假iPhone被一对母子用来进行AppleCare欺诈活动。 他们会拿着十分逼真但无法使用的iPhone到苹果商店，声称手机被水渍损害，要求在保修期内更换设备。 此时，手机在无法开机状态下接受检查，很可能短路，电池起火。因此为避免此类现象，苹果不会在店内进行进一步检查，而是确认AppleCare+保单涵盖手机的意外损坏后，就立刻为用户更换新机。 值得一提的是，假iPhone的国际移动设备识别号码IMEI与正品号码相匹配，且也享有AppleCare+政策。因此他们顺利骗过苹果店员，支付99瑞士法郎（约合人民币749元）免赔额度，就可把手里的一台假iPhone换成正版新机。

#  

但调查显示，母子二人似乎不是主犯，而是被坑了的中间人。他们称并不知道iPhone是假的。从上游卖家那里买到后，手机便从香港运往瑞士。他们在瑞士换得正版新机后会寄回卖家，每交换一部iPhone，即可获得10瑞士法郎（约合人民币75元）“佣金”。

咸鱼想翻身：母子二人真的是被坑惨了……话说你觉得苹果的售后服务如何？

华为阿里员工加入微软遭抵制系乌龙

  

![](../Images/25ad2cd896c800b734e0e67bfa888b6b.png)  
现在，很多互联网公司，特别是大厂的工作压力非常大，996工作制屡见不鲜，甚至还有人调侃存在007工作制。加班文化仿佛变成了新的潜规则。 前阵子，就有媒体报道，一群从华为和阿里巴巴跳槽到微软的员工，遭到了微软的内部抵制。原因是他们时常自发性“比赛加班”，甚至“半夜在工作群互发消息”，给团队带来了国内互联网企业的加班文化，破坏规则，造成了恶性竞争。 此后，还爆出微软团队特意开发了一个 Hackathon 项目，检测部门内部人员晚上加班情况，并自动向其提出警告。 但近日，当时的一系列报道被证实皆为乌龙。网传截图实为开发团队测试环节在 “闲聊群”中的互动娱乐行为，Hackathon也并非真实项目，没有上线计划。 虽然员工比赛加班被抵制只是个玩笑，但互联网企业普遍的加班文化却真实存在。 对此，有人认为正是苦干、蛮干精神，才让我国互联网技术没有落后。但也有人认为加班文化不可取，会破坏工作和生活的平衡。你怎么认为呢？
