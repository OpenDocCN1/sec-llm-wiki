近日，iOS两大主流越狱团队发生激烈冲突。Unc0ver向GitHub投诉，称Chimera13的首席开发者Coolstar窃取其未公开的私有代码。随后，GitHub基于Unc0ver的DMCA（数字千年版权法）审查要求，删除了Chimera13的越狱代码存储。但Coolstar表示Chimera13是自己基于Swift语言开发的，开源代码也都基于公开许可证，强烈要求GitHub恢复代码存储。

美12岁CEO免费提供编程课程

  

![](../Images/e25a7c6d8ab372fc845c22d678b133e4.png)  

# 近年来，随着程序员成为公认的高薪职业，也带来了编程要从娃娃抓起的少儿编程热潮。

#  

# 而美国就有一名年仅12岁的天才女程序员已成为人生赢家。

#  

# Samaira Mehta有位在英特尔担任工程师的爸爸，从6岁开始学习编程语言，8岁就制作了一款编程桌游CoderBunnyz进行销售，致力于让孩子通过游戏掌握编程思维。

#  

# 她坚信任何人都能学习编程。在父亲的帮助下，作为“10亿孩子一起学编程”倡议的发起人，为106所学校的孩子们开设编程教育课程。

#  

# 9岁时她就多次担任谷歌、微软、英特尔等公司活动的演讲嘉宾，并为孩子们主持了150多场编程研讨会。

#  

# 面对谷歌和微软抛来的橄榄枝，她却表示自己不想为人打工。在家人的帮助下，她成立自己的桌游公司CoderBunnyz，担任CEO，并与弟弟一起制作出了AI主题的新桌游CoderMindz。

 在疫情严重的当下，她更是在全球提供免费的编程和AI在线课程，旨在从小培养孩子的编程思维，让他们在未来有更多机会去选择自己的发展方向，实现更远大的梦想。

 超50亿独立账户在暗网被出售

  
![](../Images/da36370e769787344ff6fc7b90ac5b96.png)  
“暗网”有网站使用者和访问者不可被追踪的特点，是非法信息和商品进行交易的最佳巢穴。 近日国外研究人员就透露，因很多人使用低强度密码，易遭暴力破解工具破解，导致目前有超 150 亿条各类账户信息将在暗网上被出售，有些信息甚至可供免费访问。 由于很多用户对自己的账户已遭到攻击并不知情，导致账户被多次分享。但即使账户信息有重复，暗网上遭出售的“独立”账户也超过50亿个。 在这些账户中，售价最高的是机构的系统管理员账户信息，可达12万美元。 而在消费类账户信息中，售价最高的是银行账户信息，平均售价为70.91美元。这就意味着犯罪分子花费500元人民币就能买到银行账户信息，进而窃取用户钱财，甚至申领信用卡、申请贷款。

#  

# 此外，杀毒软件、VPN和社交媒体等账户信息也一应俱全，明码标价在暗网上被出售。

 值得一提的是，近年来打击暗网平台的成功案例在增加。可见虽然暗网有极强的匿名性和保密性，也将越来越难逃法网。

咸鱼想翻身：暗网可不止贩卖信息那么简单，放任不管真的很可怕。

谷歌开源漏洞扫描仪“海啸”

  
![](../Images/4149d466cb7ce19bf4572cdd6acdf69e.png)  

# 谷歌的核心业务大部分是基于开源软件建立起来的。因此近年来，谷歌也在不断回馈开源所带来的巨大效益，持续部署自己的开源战略。

#  

# 近日据外媒报道，谷歌就将开源其大型企业网络漏洞扫描仪“海啸(Tsunami)”。

 这款漏洞扫描仪与市面上大部分同类产品都不同。 它能适应多样化的大型网络，可为像谷歌一样拥有数十万台服务器、工作站、网络设备和连网物联网设备的公司服务。 

# 此外，一般情况下每种类型设备都需运行不同的扫描仪。但Tsunami的侦查模块能同时扫描整个公司网络，寻找开放的端口进行测试，并识别每个端口运行的确切协议和服务，防止进行错误标记。

#  

# 之后，Tsunami的漏洞验证模块就能选择要测试的漏洞列表，检测每个设备及其暴露的端口是否极易受到攻击。

#  

因目前Tsunami只支持扫描高严重性漏洞，谷歌计划未来通过新的插件来增强它的性能，探测更广泛的漏洞，以帮助更多大型企业网络提早发现漏洞，提升安全性。

咸鱼想翻身：有一说一，国外的开源生态的确比较好。
