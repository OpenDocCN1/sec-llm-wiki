Win10背景图片工具易被黑客滥用

  

![](../Images/18bf9e062a11e58226412c50c61df70f.png)

  

Win10中的二进制文件用来为桌面和锁定屏幕设置图像。它们被称为LoLBins，与操作系统一起提供，且有合法的用途。  
但近日，研究人员却发现很多攻击者都在滥用这些文件来隐藏恶意活动。  
据思科的报告，攻击者在很多Windows本机可执行文件中，都可下载或执行恶意代码。可执行文件列表如下：powershell.exe、bitsadmin.exe、certutil.exe、psexec.exe、Wmic.exe、mofcomp.exe、命令行工具、安装程序、可执行文件、msbuild.exe、脚本文件、regsvr32.exe。  
此外，位于Win10的system32文件夹中的“ desktopimgdownldr.exe”作为配置服务提供程序的一部分，有定义锁定屏幕和桌面背景图像的功能，也可用作LoLBin被攻击者利用。   
攻击者利用LoLBins下载和安装恶意软件，可以绕过UAC或WDAC等安全控制，获得管理员权限，删除所有下载程序在Windows注册表为Personalization CSP所创建的轨道。  
这样，他们就能在系统不发出警报的情况下，攻击涉及无文件恶意软件和信誉良好的云服务。  
对此，研究人员建议用户可以通过使用mklink.exe实用工具创建符号链接，来解决此问题。

 辽宁首台“天玥”国产计算机下线

  
![](../Images/38eee1afc0974e608be6734e9a3c688c.png)

#   

# 近年来，技术国产化一直是中国各大科技产业研制的重点方向。近日，我国在国产计算机上就有了一个好消息。

#  

# 7月3日，由中国航天科工集团七〇六所自主研发的“天玥”计算机正式举办产品下线仪式，将委托国营沈阳辽声无线电厂进行生产。生产线可年产10万台/套产品，年产值预计5亿元。

 

# 作为辽宁首台纯国产计算机，其搭载麒麟操作系统，芯片和各种运行所需的核心元器件也都是国产。从硬件到软件的自主研发、生产、升级、维护全程可控，真正实现了技术上的自给自足。

 此外，“天玥”也可在黑龙江（高寒）、海南（高湿和）西藏（高海拔）以及其他供电不稳定的地区部署和应用，能经受恶劣环境的考验。 七〇六所正在和辽声无线电厂通力合作，共同建设集生产、销售、售后服务于一体的国产计算机产业基地。 相信这将减轻我国对外国技术的依赖，把国产自研计算机广泛应用于我国部委和省、市党政机关单位等，进一步保障我国信息安全。

秃头生成器让你get 张东升同款发型

  

![](../Images/208f954fe95849a8b72419180713e790.png)

  

# 最近《隐秘的角落》火爆全网，剧中秦昊扮演的张东升一角深入人心。更让人记忆犹新的还有张东升突然摘下假发，露出“地中海”发际线的那一幕。

#  

虽然剧中是特效化妆，但当下，脱发的确已成为年轻人的普遍现象。尤其是从事科研、程序员等高压行业的年轻人，都面临日益秃顶的风险。试问，你想象过自己二十年后会秃成什么样吗？  
近日，b 站 Up 主 MarsLUL 就决定用代码来实现自己的这个" 梦想 "。  
MarsLUL 是谷歌的一名在职程序员，他利用英伟达开源的 StyleGAN ，自制了一款秃顶生成器，可以在保持人脸基本不变的情况下，从发量浓密的现在，分分钟看到二十年后发量稀疏的自己。  
在他发布于b站的视频中，虽然没有详细呈现代码的实现过程，但展示了所用的核心技术和详细参考资料。  
最后，MarsLUL 坦言自己制作这款秃顶生成器，是为警醒大家合理作息防脱发。编程不易，且编且珍惜。
