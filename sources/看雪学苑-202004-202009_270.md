Win10发布紧急更新修复高危漏洞

  
![](../Images/646a6d96ccb8a67794f58505d095b3db.png)  
7月14日的补丁星期二活动日还未到来，但今天微软就匆忙发布了两个紧急安全更新，用于修复两个高危漏洞。 此次的两个漏洞 CVE-2020-1425（最高级）和CVE-2020-1457（次高级）均属于高危级别的远程代码执行漏洞，会影响所有仍在支持期限内的Windows 10和Windows Server 2019系统版本。 利用这两个漏洞，黑客可以在 Windows Codecs Library 解码器库处理内存中的对象时，利用精心制作的特制图片文件，触发内存缓冲区溢出，以此来远程执行恶意代码，获得目标设备的系统控制权限，控制被入侵的计算机。 虽然微软表示漏洞暂未被公开，被利用的可能率很低。但为确保安全，仍强烈建议用户立即更新安全补丁。 微软将通过 Windows 应用商店向受影响的用户自动推送更新，无需用户手动更新。  
若用户想要立刻获得更新，可从 Windows 应用商店进行验证并尝试更新。

 中国App Store上万手游更新被冻结

  
![](../Images/037f1f05409c9a6ff8a5fd74b4cbb233.png)  
近年来，中国对游戏上架的监管机制越来越严格，发放的游戏批准版号也大幅减少。 事实上，在中国App Store的 6万款付费或应用内购买游戏中，至少有1/3是没有中国监管机构的许可证的。正因此，《侠盗猎车手》（GTA）等游戏才得以在中国市场运营。 但为了遵守中国的相关规定，苹果的 App Store 游戏新规昨日终于正式落地。此前苹果允许游戏在等待监管机构批准的同时，于App Store先行发行的不成文规定将不复存在。 根据新规，自7月起，在中国大陆发布的任何付费游戏或可提供App内购买项目的游戏都必须有批准文号，所有无版号的新游戏将无法通过苹果审核，上架中国区 App Store。 而7月之前上架的上万游戏若不能提供批准文号，将无法更新游戏，甚至可能面临下架。如《星球大战：英雄银河》的中国用户就被开发商EA告知游戏将被下架，并将停止提供应用程序内购买服务。 预计这一新规可能会给苹果造成高达8.79亿美元（约合人民币62亿元）的销售损失。

华为 openGauss 数据库正式开源

  
![](../Images/1384ea2d917eadb4acd771fc9d7b0bdd.png)  
GaussDB是全球首个人工智能原生(AI-Native)数据库，其内核被认为具有超越现有常见开源数据库MySQL与PostgreSQL的极致性能。 继去年9月华为曾表示将开源该数据库后，近日华为正式宣布开源该数据库能力，开放 openGauss 数据库源代码，并成立 openGauss 开源社区，社区官网也同步上线。 *开源社区官网：**http://opengauss.org**开发者代码托管平台：**https://gitee.com/opengauss* openGauss 是一款开源关系型数据库管理系统，深度融合华为在数据库领域多年的经验。 其着重在架构、事务、存储引擎、优化器等方向持续构建竞争力特性，在 ARM 架构的芯片上深度优化，并兼容 X86 架构，具备高性能、高安全、易运维、全开放的优势。 相信openGauss在未来必将吸引更多的贡献者，共同构建一个能融合多元化技术架构的企业级开源数据库社区，进一步推动数据库软硬件应用生态系统的丰富和发展。 

### 但同时，开源数据库的安全问题也不容忽视，加强账号管理的安全意识至关重要。可通过删除匿名账号、设置安全密码、只赋予普通用户必须的权限等方式来预防此类现象发生。
