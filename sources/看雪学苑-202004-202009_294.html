vivo  SRC






vivo SRC送来的是五芳斋粽子大礼盒呢！五芳斋可是老字号了呢，鲜肉粽和咸蛋黄肉粽都是经典，怎么买都不会错！





vivo安全应急响应中心，简称vivoSRC，是vivo公司致力于维护互联网健康安全生态环境，保障vivo产品和业务线安全性，促进与业界个人、组织及公司密切合作与交流，而建立的漏洞收集和应急响应平台。

官方网站：https://security.vivo.com.cn。







派拉软件






派拉软件的礼盒很别致呢。上面印有中国风的插画为缀，里面还有一套茶具，真是别有一番雅趣！





上海派拉软件股份有限公司是中国领先的新一代信息安全技术公司，数据定义，科技驱动，基于零信任安全体系，融合微服务架构、AI算法、区块链、物联网、大数据等专业信息技术，为企业和机构打造一站式信息安全平台，已成功为汽车、制造、地产、金融、保险、证券、零售、教育、医疗等行业的1000+家的客户提供优质与信赖的服务。目前，派拉软件在上海、北京、广州、深圳、长春、武汉、成都均设有服务机构。







智联招聘安全应急响应中心





智联招聘安全应急响应中心的礼盒低调又不失趣味，小小的五彩礼盒上有各种端午元素的印花，很可爱呢!





智联招聘安全应急响应中心（Zhaopin Security Response Center） 诚挚邀请白帽子和各位安全爱好者同智联招聘一起保障广大用户的信息隐私、安全等问题。本平台将收集智联相关业务及产品上存在的安全漏洞等相关情报， 并为各位参与者准备丰厚的奖励果实，等待卓越的白帽子前来采摘。我们始终怀揣感恩的心，感恩每个关注智联招聘的人， 感恩所有为智联招聘的发展做出贡献的人。







京东安全应急响应中心






京东安全应急响应中心送来的礼盒色调真的很“端午”呢，上面烫金的字和花纹，低调又不失奢华。




京东安全应急响应中心（security.jd.com）是京东为致力于维护互联网健康生态环境，保障京东产品及业务线的信息安全，而建立的漏洞收集及应急响应平台。该平台旨在加强京东与安全业界的合作交流，提升京东整体安全水平。







云众可信






香囊高挂，好运绵绵引进房。感谢云众可信送来的粽子礼盒！





云众可信是启明星辰集团旗下品牌，专注于网络安全攻防领域，秉承“专业、创新、极致、担当”的理念，为党政军和企业用户提供高品质的产品及服务。核心产品：红蓝网络攻防平台、网络空间靶场、可信众测平台。安全服务：攻防演练、可信众测、暗网监控、渗透测试、代码审计、应急响应、安全评估、安全培训等。







网易易盾





网易易盾送来的礼盒貌似是黑猪肉系列？蛋黄黑猪肉粽，还有菌菇黑猪肉酱什么的。黑猪肉的价钱很贵呢，emmmm金钱的味道。




网易易盾是国内领先的内容安全&业务安全服务商。依靠网易20多年丰富的安全经验以及云计算、人工智能方面的积累，面向数字化业务提供内容安全、业务安全、移动安全和网络安全服务，保障客户业务合规、稳健和安全运营，使客户可以免受黑灰产组织非法侵害，专注创新发展。







绿盟科技






艾叶扬，粽子尝，欣然佳节逢端阳。绿盟科技送来的也是五芳斋的粽子礼盒，谢谢绿盟，大家有口福啦！





绿盟科技集团股份有限公司，成立于2000年4月，总部位于北京。公司在国内设有40多个分支机构，在美国硅谷、日本东京、英国伦敦、新加坡设立海外子公司，深入开展全球业务，打造全球网络安全行业的中国品牌。作为巨人背后的专家，绿盟科技将一如既往以创新精神、领先技术、优质产品、专业服务，在全球范围内，提供基于自身核心竞争力的企业级网络安全产品、安全解决方案和安全运营服务，成为最受用户信赖的网络安全公司。







美团安全应急响应中心






美团安全应急响应中心送来的粽子礼盒是六边形的，很有特色。而且，每个粽子上都有一句美好的祝福，很用心呢！





美团安全应急响应中心（MTSRC）自2018年正式上线运营后，平台已入驻2000+白帽，奖励金额发放达百万元，单个漏洞基础奖励最高可达6W+。欢迎广大用户和白帽子提交美团和大众点评的产品/业务安全问题，MTSRC将有专业人员跟进及处理并将结果及时反馈给您。我们向每一位信息安全从业者/守护者致敬，希望可以有更多的人与我们一路同行，共同成长。提交漏洞/情报地址：https://security.meituan.com。







补天漏洞平台






满街又闻粽叶香，眷恋源系汩罗江，缠缠绵绵情不尽，包包裹裹用心量。感谢补天漏洞平台送来的粽子礼盒！





补天漏洞响应平台成立于2013年3月，是专注于漏洞响应的第三方公益平台。帮助企业建立SRC（安全应急响应中心），最大程度避免企业由于安全漏洞遭受损失，尊重白帽子的劳动产出，让白帽子获得收益，建立起厂商与白帽子之间的桥梁，积极推动互联网安全行业的发展。截止到目前平台注册白帽子人数六万余名，入驻企业近六千家企业，发现漏洞近五十万个，截止目前奖金发放已达数千万。







极光无限

苏州极光无限信息技术有限公司，成立于2019年3月，是一家深耕于AI技术在网络安全行业的研究与应用，为政府、运营商、金融、能源、互联网以及教育、医疗等行业用户提供全方位安全解决方案和体系化安全服务的科技公司。主营业务为自有网络安全产品的研发和销售、行业客户安全解决方案和相关安全服务。







豹趣科技

珠海豹趣科技有限公司是猎豹移动旗下独立拆分出来的控股子公司，继承了金山毒霸在信息安全领域近20年技术积累基础。主营业务为金山毒霸、猎豹游览器、驱动精灵等PC互联网产品和钢琴块小程序等互联网文化创意产品。目前，旗下拥有666项专利申请，其中发明专利申请526项，在所属领域形成比较完整的自主知识产权链。







360安全应急响应中心





360安全应急响应中心送来的靛蓝色粽子礼盒很典雅呢！悠悠艾草香，绵绵情意长；丝丝问候你，甜甜粽子尝；龙舟驶江里，艾草挂门上；祝福我送上，祝端午节幸福安康！





360安全应急响应中心（ 360 Security Response Center ）是360公司对外付费收集360公司、产品安全漏洞、威胁情报的平台。360SRC于2012年上线，成为中国首家向漏洞报告者提供现金奖励的厂商。
