Chrome恶意插件泄露大量用户信息

  
![](../Images/1a3c0aec4ada358b2d04b15276ed4f6c.png)  
一直以来，谷歌的Chrome Store就是散播恶意软件的绝佳之地。2018年就有研究发现，在提交到Chrome Store的扩展程序中，每十个中就有一个存在恶意软件。 昨日下午，据外媒报道，Awake Security的研究人员就在Chrome浏览器的扩展程序中发现一个新的间谍软件。 它可以躲避反病毒企业或安全软件的扫描，对用户发动攻击，造成用户个人信息泄露，包括用户的电子邮件、工资单和其他敏感信息。 其中，使用企业网络的用户面临的安全风险会相对较小，因为企业网的安全服务能阻碍敏感信息在网上的传输。而用户在家用电脑时，若使用带有恶意扩展程序的Chrome，就要格外小心自己的个人信息在线泄露了。 值得注意的是，从下载量来看，可能含有该间谍软件的扩展程序已被下载3200万次。这就意味着，这是Chrome商店中出现过的影响最严重的恶意软件。 但由于攻击者发布这个间谍插件时，填写了虚假身份信息，因此无法确定其真实面目。而谷歌发言人只表示目前已删除该恶意扩展程序。

 苹果拟在印度组装 iPhone SE  

  

![](../Images/1c8ec6bca2021801933e329515c25018.png)  

  

“Made in China”是中国代工产业强大的代名词。因中国劳动人口基数庞大、工人制造技术优秀、能应付复杂的生产工艺，且工作效率高，全球的苹果手机也都在中国的富士康组装。 

# 但据外媒报道，苹果已开始通知中国供应商纬创，令其向苹果的印度生产伙伴配送2020款iPhone SE的零部件，准备在印度组装新款iPhone SE，以此规避该国征收的高昂进口关税。

#   

# 在苹果的未来计划中，要将供应链向除中国外的其他国家进行逐渐迁移，实现多元化发展。预计将从中国迁出20％的iPhone产能到印度。

  
目前，这项计划的推进仍然较缓慢，因为iPhone生产线对精密度要求很高,但印度工人目前生产iPhone的技术水平和熟练度仍需提高。只有克服这个问题，印度生产iPhone的产能才能得到提高。 若苹果的迁移计划真的稳步实施，必将对中国的iPhone相关供应商和代工生产厂商造成很大影响，工人或将面临大面积失业等问题，经济也会受到一定冲击。此外，印度制造的iPhone质量如何也令不少网友堪忧。

28岁退休程序员引热议

  
![](../Images/89fbe96e2912fe7b1b5d68181c29ba40.png)  

# 近日，一位28岁就退休的程序员郭宇引起了网友热议。

 郭宇至今为止的人生经历在程序员中可以说是一个传奇。他曾就读于暨南大学，但攻读的专业跟编程八竿子打不着。不安于现状的他就开始自己在宿舍里学习写代码，坚定地走上了程序员的道路。

#  

之后，他进入支付宝实习，一毕业就入职阿里巴巴，后自己创业。公司被字节跳动收购后，他在字节跳动一干就是四年，人生仿佛开了挂，每一步正好踩在中国互联网高速发展的那几年上。

#  

# 互联网从业8年后，他因持有的股票赚了钱，在日本的房租收入、其它被动收入已与工资持平，真正意义上实现了“财务自由”，他便潇洒地公开宣布退休。

#  

# 如今他在日本经营起自己的温泉旅店，还成为了一名职业作家，享受阅读和写作的雅趣。

 但面对同行们投来的羡慕的目光，面对那些感叹他运气好的人，他表示自己只是个普通人，只不过每一个时刻自己做出决定的时候，都是做自己想做的事。你怎么看待他的经历呢？

咸鱼想翻身：机会是为每一个遵从自己的内心，无所顾虑放手去干的人所准备的。
