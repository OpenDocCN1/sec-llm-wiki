Ripple20漏洞或使数亿台设备受攻击  

  

![](../Images/efa3efd2c31ff990a19c900d8f2bc35f.png)  
TCP / IP库是专门为嵌入式系统设计的高性能TCP / IP协议套件，由软件公司Treck 在 1997 年推出。至今，这个库已被广泛用于实现联网功能，也被很多设备厂商直接使用，或集成到很多软件套件中。 但今天，以色列安全公司JSOF披露了一个可怕的事实。TCP / IP库中存在19个安全风险各不相同的0 day漏洞。他们将其统称为 Ripple20漏洞。 利用这些漏洞，黑客可以在入侵时提升自己在服务器的权限，以夺取权限，通过网络远程执行代码展开攻击，或在设备中隐藏恶意代码。最终可导致用户泄露敏感信息，甚至彻底损坏入侵设备。 初步预计，将有数亿台来自各行各业的设备受到影响，包括智能家居设备、电网设备、医疗系统、工业装备、运输系统、路由器、移动/卫星通信设备、数据中心设备等产品。 

# 目前，JSOF 团队正持续与不同国家的计算机应急小组进行合作，紧锣密鼓协调披露漏洞和尽快修补漏洞的事宜，防止漏洞造成不可挽回的损失。

咸鱼想翻身：希望这些漏洞的补丁能尽快推出，否则后果不堪设想。

 红警1 公开源代码  

  

![](../Images/735c361612b02449eb3d1df7fac32889.png)  
  
相信很多人小时候都曾躲着爸妈，在砖头机上打红警1，输入命令制定计划，攻占城池，建设基地……这些都成为了童年无可取代的回忆。 红色警戒1是一款即时战略游戏，由Westwood工作室开发，后被知名游戏公司EA收购。  
但近日，EA却做出一个惊人的举动。他们在Steam平台上线了4K重制版，甚至开源了红警1的源代码，引起玩家们热议。 开源链接：*https://github.com/electronicarts/CnC\_Remastered\_Collection/* 获得开源代码后，各路大神开始互帮互助，制作MOD版游戏。同时，大部分老玩家认为重置版没有当年马赛克时候的感觉了，而且仍然无法联网也是个痛点。 众所周知，游戏源代码是一款游戏的核心，具有很高的商业价值，一旦泄露后果极其严重。 但实际上，现在很多游戏源代码都在黑市被各厂商交易着，形成了完整的黑产链。很多公司会购买游戏源代码，进行重新换皮，便可推出一款全新的游戏轻松圈钱。 因此，此次EA愿意大方公开初版红警1无比珍贵的源代码，可以说是给广大老玩家的回馈了。

咸鱼想翻身 ：据说红警1的游戏源代码写得很规范，很有学习价值呢。

电子客票将覆盖全国普速铁路

  

![](../Images/20c6176b32860e236b6628db1d5c1e00.png)

  

随着电子化不断渗透进我们的生活，它给我们的生活带来了极大的便利。  

  

继内地高铁和城际铁路实现电子客票全覆盖后，铁路部门一直在实施普速铁路电子客票的技术设备升级改造工作，目前已具备实施推广条件。

#   

# 据最新消息，6月20日电子客票将在全国普速铁路推广实施，覆盖1300多个普速铁路车站。预计全国铁路将有2400多个车站实行电子客票，覆盖95%以上的铁路出行人群。

 

届时，更多旅客将告别纸质火车票，享受到电子客票“一证通行”带来的便利。

 

旅客购买电子客票后，可直接在网上退票和改签，进出站时只要出示有效身份证件，就能轻松实现“一证通行”。

 

并且，“一证通行”使实名制核验、检票、验票更加便捷，闸机检票速度提高3倍左右，极大提升进出站效率，提高出行体验。

 

此外，这样的车票电子化还能有效防止丢失纸质车票、购买到假票等风险。  

  

电子客票的全面实施将极大地改变我们的出行，但同时，我们更多的信息也将暴露在网络中，保护个人信息安全仍然是要高度关注的问题。  

咸鱼想翻身：全面实施电子客票后，春运的效率也能高很多吧。
