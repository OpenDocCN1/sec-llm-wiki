Win10新bug：开机自启动Edge



微软一直希望扩大Edge在浏览器市场的占有率。本月初它就曾通过 Windows Update 将新版 Microsoft Edge强制推送给用户，自动取代旧版 Edge。

最近，Win10 2004又出现了一个骚操作。
 
通过官方系统更新安装新版 Microsoft Edge 的部分用户反馈，无论在edge://settings/onStartup 中进行哪种设置，只要开机登录 Windows，他们的 Microsoft Edge 都会随着Win10的启动而自动启动。只有少数用户通过关闭自动重启应用功能解决了该问题。
 
这不禁让他们认为，这又是微软为了推广Edge浏览器的一种手段。
 
微软收到反馈后，官方社区已发帖表示确认该问题，并判定这是一个 bug，但工程师目前尚未确认该错误发生的具体原因。
 
值得一提的是，由于edge://settings/onStartup设置是用来控制浏览器启动后具体打开什么页面的，与操作系统的设置并无直接关系。因此，用户对于微软在开机自启动功能中做手脚，推广Edge的猜测并没有真凭实据。
 
外媒则推测这可能与 6月3日推出的 Win10 Build 1803 版本更新有关，因为当时该版本正是连同最新的 Edge浏览器一起更新的。

 苹果涉嫌垄断或将被罚数十亿美元




据2019数据，消费者和广告商在苹果应用软件上的支出规模超5000亿美元，平均每部苹果设备年度支出达到400美元（折合人民币约2834元）。获得巨额利润的同时，苹果最近也陷入了大麻烦中。

 

据报道，目前苹果的App Store和Apple Pay成为了欧盟竞争委员会最新的调查目标。起因是此前，不少应用开发商向欧盟提出了对苹果的反垄断诉讼。

 

他们表示，苹果的条款强迫他们使用苹果设备“应用内购买”的方式向用户出售产品，限制用户的购买渠道，禁止竞争对手介入苹果的支付系统。并且，他们通过App Store平台获取的销售额，还要被苹果官方收取30%的苹果税。

 

此外，苹果还做出规定，禁止应用开发商向用户告知其他应用商店里有更便宜的产品。

 

对此，欧盟认为苹果的行为可能扭曲市场竞争，减少消费者的选择，构成垄断，违反欧盟的市场竞争规则，故要对其进行严肃调查。

 

若欧盟裁定苹果存在垄断行为，那么苹果很可能面临数十亿美元的巨额罚款。

通过灯泡可监听24米外的声音



近年来，窃听技术不断升级。现今，最新的研究技术甚至可以通过灯泡识别24米外的声音。

近日，以色列研究人员公布一项新的长途窃听技术“lamphone”，只需要装有光电传感器的一台望远镜，透过窗户对准灯泡，就能进行监听。

事实上，该技术是通过测量灯泡发光的细微变化，实现在数百英尺外的房间里实时监听房间里的任何声音。

据研究人员介绍，声音会使室内灯泡玻璃表面有微小震动，引起光的微小变化。尽管震动只有几百微米，却足以通过每台带有传感器的望远镜观测到。

之后，利用ADC（模数转换器）将传感器收集到的信号进行处理，并使用软件过滤掉噪音，就能真实重现房间里的声音。从辨别对话内容，到识别出一段音乐都不在话下。

不过，该技术目前还不太成熟，有一定局限性。例如是否所有类型灯泡的震动都能被测量到，房间里较小的声音能否被监听到等，都还是未知。
