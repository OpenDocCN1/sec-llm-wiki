“黑苹果”电脑预装 macOS 和 Win10



在未经苹果授权的硬件上运行 macOS的电脑被称为“黑苹果”。它的存在严重

违反了苹果 macOS 的最终用户许可协议（EULA）。

 

但多年来，总有一些公司意图出售搭载黑苹果的硬件或黑苹果系统，挣笔黑心钱。

 

最近，一家公司以同时预装Win10和MacOS的电脑为卖点，通过比特币交易，公开销售一款名为 “Velociraptor”的“黑苹果”电脑。其起价2199美元，有多款配置可选，比正版苹果电脑的性价比要高很多。

 
值得一提的是，这家公司虽叫OpenCore Computer，但和知名的黑苹果工具OpenCore Bootloader其实毫无关系。Bootloader的开发者们只是出于兴趣，开发软件改进MacOS与不同类型硬件的兼容性，无任何商业行为。显然，这家公司是蹭了Bootloader工具的名字进行营销。
 
为对抗这种恶意商业行为，苹果近年来一直在狠治“黑苹果”厂商。谁敢公开利用“黑苹果”盈利，苹果就告谁。
 
此次苹果想必也绝不会善罢甘休，该公司很可能要等着官方的律师函，与其在法庭见面了。

 爆三星将为华为代工5G基站芯片




华为被美国列入实体名单后，使用美国技术生产芯片的厂商需要获得美国的许可证，才能为华为制造芯片。

目前，台积电对华为断供芯片，让华为陷入困境。为保持其业务正常运转，华为一直在另辟蹊径。

近日就有报道称，三星与华为正在探索一项“合则两利”的重磅交易——华为以部分全球智能手机市场份额为报酬，让三星为其制造5G设备芯片。

对此，有人认为该计划很可能行得通。为保障其全球最大5G网络设备提供商的领导地位，华为十分重视5G基站的建设。而先进的芯片是5G基站的核心元器件，确保其稳定供应至关重要。因此这正是华为牺牲智能手机业务，挽救其电信业务的最佳机会。

但也有人认为交易达成的可能性不大。即使自研5G芯片制造受限，华为仍可通过采购第三方的非美系芯片来维持。这不足以让华为放弃仍在持续提供巨大利润的手机业务。

最终该计划实施与否，或将取决于华为在其业务的战略布局倾向上。

Win10（2004版）全新启动失效



你有遇到过电脑里安装的应用程序越来越多，兼容性问题始终无法解决，或是注册表越发臃肿，拖慢电脑运行速度的烦恼吗？
 
为解决此类问题，2017年微软就在 Windows 安全中心提供了 Fresh Start 全新启动功能，可使用户重新安装 Win10 ，并保持数据不变。
 
该功能不会尝试保留现有的应用程序，而是为用户的电脑提供一个“全新的开始”。这能一定程度上改善开机和关机体验、内存使用、Windows Store 应用性能、浏览体验和电池使用时间。
 
但在 Windows 10 更新五月版（2004 版本）中，有用户反馈微软似乎删除该功能，移除了Get Started 按钮。
 
事实上，调查发现在微软反馈中心，有不少与该问题相关的报告，且最早可追溯到至少8个月前。但至今，微软一直忽视了该问题，未将其列为该版本的已知问题，也未对其作出相应的处理。
