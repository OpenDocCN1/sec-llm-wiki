Win10 霸屏通知再“骚扰”用户



去年， Microsoft 在 Windows 10 中就曾添加一项新功能，可在系统启动时显示微软的全屏通知。
 
近日，微软故伎重施。据用户反映，这种全屏通知会在安装或升级 Win10 后首次启动时显示，也会在用户未更新系统，或是仅注销并重新登录到桌面时出现。

这甚至让一些用户误以为自己的电脑出了问题。
 
事实上，微软此举旨在鼓励用户设置 “由 Microsoft 帐户提供支持”的服务，例如 Windows Hello、指纹或 PIN 功能、OneDrive、Your Phone 应用、Microsoft 365等。

但经试验后发现，用户若觉得自己因此受到了“骚扰”，可通过以下步骤禁用全屏通知功能：

  • 从 Windows 搜索或开始菜单中打开设置应用。

  • 单击 " 系统"

  • 单击" 通知与行动"

  • 通知设置

  • 取消选中 " 建议我完成设备设置的方式，以获得 Windows 的最大益处" 的选项。

  • 用户还可取消选中 “向我展示 Windows 欢迎体验”和 “获取提示，技巧和建议”这两个选项，减少 Windows 10的建议和类似提示。

  • 重启 PC 后，更改将自动应用于系统。

苹果等公司抢占华为芯片订单




众所周知，一款手机性能高低，表现好坏要取决于强大的处理器。但很多手机厂商并没有能力自产这些高端芯片，只能依靠专业代工厂的先进工艺。

台积电作为全球最大的晶圆代工半导体制造厂，全球最大的芯片代工厂，拥有全球领先的5nm和7nm生产线。苹果、华为、高通等都是台积电的忠实客户。
 
继美国之前要求台积电断供华为的芯片后，据台湾媒体报道，近日台积电已将华为海思原本预订的第四季先进制程产能开放给其它客户。苹果、高通、联发科、AMD等大客户立即大幅追加下单。

据供应链消息，苹果iPhone 12相关芯片已在台积电投片，并有意取得华为海思预订的5nm产能。此外，其近期也计划扩大iPhone 11及iPhone SE产能来抢占华为手机市场。

目前，台积电第四季度7nm产能维持满载，5nm利用率也维持高位。

由此可见，华为将难以从台积电获得今年第四季度的芯片订单，高端旗舰机型备货压力势必将骤增。

AI换脸首入《民法典》监管范畴



AI 换脸技术相信大家并不陌生。无论是在b站的鬼畜视频，还是在抖音、微博的搞怪视频中，都能见到他们的身影。
 
但由于 AI 换脸制造影像的门槛正在变低，由此引发的侵犯个人隐私，发布虚假图片、视频，黑色产业链泛滥等现象在不断增加。用法律来对其进行严格监管迫在眉睫。
 
近日，两会已授权民法典正式文本发布，将在 2021 年 1 月 1 日正式施行。
此次关于侵犯他人肖像权的新规定，矛头就直指AI 换脸和变声技术。
 
《民法典》第 1019 条明确规定：

任何组合或者个人不得以丑化、污损，或者利用信息技术手段伪造等方式侵害他人的肖像权。

未经肖像权人同意，不得制作、使用、公开肖像权人的肖像，但是法律另有规定的除外。

这就意味着，此后若要进行 AI 换脸，或对他人声音音源进行合成、再加工，要极其谨慎，必须征得他人同意。反之，被侵害肖像权的人可以进行追诉，要求合理赔偿。情节严重的甚至可以引用侮辱罪，处以有期徒刑或给予相应惩罚。
