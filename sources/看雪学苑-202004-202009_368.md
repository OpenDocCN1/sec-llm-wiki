# 微信群控外挂被判罚260万；全国人口普查首次电子化； 2700条 JRD 数据泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458307911&idx=3&sn=73930de2800a341e5d4c42bbdca21c82&chksm=b181fdcd86f674db5cb42a4f474637c121cdebf2161a364c0caa2f7f62a07a692db8fd138e4b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458307911&idx=3&sn=73930de2800a341e5d4c42bbdca21c82&chksm=b181fdcd86f674db5cb42a4f474637c121cdebf2161a364c0caa2f7f62a07a692db8fd138e4b&scene=27#wechat_redirect)

近日，因美国暴乱，谷歌推迟了原定于本周举行的 Android 11 Beta 版本发布会。但昨日，有用户反映自己的 Pixel 4 XL 手机通过无线方式接收到了谷歌意外推送出的新版本，文件大小为 736 MB。该版本的新功能也泄露出来，包括有 3 种新图标形状；长按电源按钮时，会出现智能家居的快速控制菜单；屏幕底部将显示建议应用；开发者选项中，可将媒体控件移至快速设置面板。

  

  

1

腾讯控告群控软件不正当竞争

  

![](../Images/747566739d60f9d5def4421f4c269897.png)

  

近年来，微信营销火爆式发展。你是不是也经常被微信群里冒出来的骚扰式广告营销，朋友圈和群发好友天天卖货的微商所困扰过？ 近日，腾讯就将浙江某网络公司和杭州某科技公司告上了法庭，原因是其开发和运营微信外挂“聚客通群控软件”，擅自收集、存储微信个体用户的数据进行营销等活动，妨碍微信平台正常运行，损害了腾讯方对微信数据享有的数据权益。  
据了解，这是首例因微信数据权益认定引起的案件。法院表示网络平台方对于数据资源整体和单一数据个体享有的数据权益是不同的。腾讯方对微信平台长期经营积累所得的数据资源整体享有竞争权益，而对于单一微信用户的数据并不享有专有权。 昨日上午，杭州互联网法院就这起不正当竞争纠纷案进行宣判，判决被告公司确实违反了《反不正当竞争法》第十二条第二款第四项的规定，妨碍、破坏其他经营者合法提供的网络产品或者服务正常运行，构成不正当竞争行为。应即刻停止并赔偿腾讯方 260 万元，为其消除影响。 无疑，两被告公司破坏微信平台作为社交平台的正常生态，侵犯大量单一微信用户个人数据的行为是违法的，应引以为戒。

 全国人口普查首次电子化  

  

![](../Images/ee2e71d679822086a2f236149e4113a6.png)  

  

从纸媒到新媒体，漫画书到网络漫画，线下办手续到线上办理，电子化不断渗透进我们日常生活的方方面面。 近期，各地第七次全国人口普查准备工作就正在进行中。据了解，此次为保护个人信息，将采取电子化方式开展普查登记，可以由普查员使用PAD或智能手机上门登记数据，经加密后上传后台，也可以居民自行在网上填报。  
值得一提的是，这次是首次采用电子化信息采集方式，旨在打消居民对信息泄露的顾虑，全流程保护公民个人信息。 但是，很多人仍然担心在普查过程中可能会导致个人信息泄漏。为此，《全国人口普查条例》对保护人口普查对象的合法权益作了明确的规定，例如关于个人身份的资料，任何单位和个人不得对外提供和泄露；普查所得资料不得用于普查以外的目的；普查中获得的原始资料，需按照国家有关规定保存、销毁等。 但网络上收集的信息如何加密，如何确保被销毁不得而知，最终效果如何仍需观望。

3

2700条 JRD 数据泄露

  
![](../Images/f11956145a7b87a00c0a4f54501c7001.png)  
近日，Joomla 开源内容管理系统研发团队宣布了上周发生的安全漏洞。 由于 Joomla Resources Directory ( JRD )团队的一名成员和前团队负责人拥有的第三方公司将 JRD 网站未加密的完整数据备份存储在该公司运营的Amazon Web Services S3 存储桶中，从而造成约 2700 个用户的详细信息数据泄露。 可能遭暴露的数据如下：  

*   姓名全称
    
*   商务地址
    
*   商务邮件地址
    
*   公司 URL
    
*   业务性质
    
*   加密密码（哈希加密）
    
*   IP 地址
    
*   简报订阅偏好
    

  
对此， Joomla 团队称正在调查该数据泄漏事件，目前尚不清楚是否有人找到了并从第三方公司的S3服务器下载数据。但值得注意的是，他们确实找到了不属于“开源项目”的超级用户帐户。 虽然此次泄露的大多数数据是公共目录，但仍有不少用户的私有数据遭到泄露。因此，Joomla 团队呼吁 JRD 用户尽快更改密码，保护个人数据安全。
