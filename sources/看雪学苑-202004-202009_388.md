#   

  
  
前因  
  

  

在 2020 年 5 月 23 日，传来噩耗，某某中了勒索病毒，可惜没相关技术，帮不上什么忙，朋友只能忍痛重装系统。  
今痛改前非，要学习了，**技术才是王道**，没技术想帮忙都费劲（人脉：不能一味的寻求帮助），未避免文章枯燥，会用一些方法增加文章的阅读性。  

##   

  

  

  
  
情报部门日常巡查  
  
**流量监测**：当天流量与平均流量对比，流量告警等，例如：SMB 远程溢出攻击，弱口令爆破，数据采集等等，均可能是敌军在尝试扩散攻击。**资源监测**：检测是否存在长期占用 CPU 或内存的进程，系统运行是否正常，存不存在卡顿现象，若存在异常，有可能感染了病毒木马，恶意进程正在运行。**依据**：一般情况下，中勒索病毒前，攻击者会通过渗透测试进入内部网络的某一台主机到执行加密行为往往有一段时间，如果在这段时间能够做到响应，完全可以避免勒索事件的发生。如果有异常情况，可能是处于感染未加密状态，一般勒索病毒入侵如下图所示：  
![](../Images/54973943459abe72d6bbf8a879ed1689.png)

##   

  

  
  
内部封锁并进行排查  
  
  

**内部封锁**：断网、断连接

  

**临时文件排查**：在Windows系统下的Temp文件夹是否存在异常文件

  ![](../Images/d88e657024cd2f3edffee125c507454c.png)  
**近期使用文件排查：**在 Windows 系统用户下的 Recent 文件夹是否存在异常文件。    ![](../Images/b4fdbee262f0a980ae4b38553b688d8d.png)  
查看当前网络链接情况：Windows: netstat -ano，并使用 tasklist |findstr PID 值，查看可疑端口对应的程序。    ![](../Images/0b9c3b3e3efdb2dd34372f4d586873d2.png)  
    ![](../Images/d3b35928b526e03d446907af1ab6a27d.png)  
  
**环境变量：**查看系统环境变量是否有可疑程序路径添加    ![](../Images/3909b1991e51c72fdb32cbd4dac30e41.png)  
    ![](../Images/905796744748d125e15d34b5a2e0511d.png)    ![](../Images/10e3f66ebeb88001190bdb8e3bb04b07.png)  
用户：查看是否存在可疑用户，Windows：net user 注册表HKEY\_LOCAL\_MACHINE\\SAM\\SAM\\Domains\\account\\Users\\Names  
注意：只有通过 administrator 给 administrator 完全控制的权限，这样我们才能看到在 SAM 文件夹下的隐藏目录和隐藏文件。并且系统自带账号非特殊情况勿要删除，否则会导致一些系统自身程序（需调用相关账号使用）无法运行。  
**query user 查看当前用户**      ![](../Images/9bfdf6d09bb3583050714cb891174fd4.png)         ![](../Images/1df5291ed956e99e7f8f09ff21ec5fb7.png)      ![](../Images/80fd829d8cd432c82a5ab0cb97ac6ee5.png)  
     ![](../Images/21ef06eec9d2a7075552e084c352519b.png)  
开机启动项：查看开机启动项是否存在可疑进程    ![](../Images/02f75f52d0462b328dce83c968dd5439.png)    ![](../Images/ca03d633e50940617714443a8ea13f52.png)   ![](../Images/2deb1f62bc260a7f8da2d63fe686a200.png)  
日志文件：查看可疑操作记录，并查看异常 IP : IpAddress   ![](../Images/4c9757651f886ae391cda6f5ecd6cc97.png)  
   ![](../Images/b1cd1d09d96b97cff648924077a9375a.png)

*   数据恢复：找出勒索主程序
