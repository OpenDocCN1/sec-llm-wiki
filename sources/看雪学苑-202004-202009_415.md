0x01 Ghidra 准备  
  

##   

本人采用 openjdk11，ghidra 9.0.4 版本，运行 ghidraRun 文件，提示输入 jdk 路径，这里输入* /usr/lib/jvm/java-11-openjdk-amd64*。这里用普通用户权限也可以。 ![](../Images/2a3ef4531f569238d59a1bc304e6fbaa.png) 新建项目，并导入crackme。 file -> New Project 新建项目，直接将 crackme 鼠标拖入 project，Ghidra 自动识别文件类型，这里保持默认。 ![](../Images/861fb6792510d4e804732428bf096bf8.png) ![](../Images/4658384e033a7df6c288819881e6fbd7.png) 这里提示一些文件信息，点击 OK 即可。 ![](../Images/ec5727f4be4775bd97e25b0a295b35c5.png) 然后双击这个程序，打开 "CodeBrowser " 即“代码浏览器”，提示是否需要分析，选择 “是”。 ![](../Images/25227ff6274b53c1a046098bb736a606.png) 看右下角的分析进度，快慢视程序大小、是否加壳等而定。 ![](../Images/f0818e2313508b63983723d701d9b1eb.png) ![](../Images/c63862fc082201aee7983b82e249a2c8.png) ![](../Images/c0d10a3d35832fdb065c3942764345c4.png)

0x03 个人观点  
  

##   

Ghidra 个人感觉还是比较好用的，里面很多功能还没有介绍，但是基本和 IDA 大同小异了。  
个人最喜欢的地方是可以直接修改函数 signature，分析一些文件可以不用动态了（动静态分析都有各自的优缺点，根据实际具体运用即可）。我是一个么的感情的工具人，完结，撒花。各位天天快乐鸭~
