Github 上源代码泄露不止一两次了，看雪精华会员 cvcvxk 说道：“我们以为微软不会把重要的代码放到 Github 上，结果我低估他们了。这是 Github 出了 Private 越权，导致有大哥已经拖了微软 500GB 的代码。”

有趣的是微博网友表示，微软泄露的私有 GitHub 账号里面居然有当时 X 站泄露的源代码。


另外，外网的一篇报道说并没有 Windows 和 Office 的源码，微软不用过分担心。


当然还有很多网友担心，微软市值会跌还是会涨。比如开源出来了市值不应该会涨吗，快速提高市场占有率。

得出的结论是，重要的代码别放到 GitHub 上，吓得小编我赶紧把我的 fuzz 删了。
