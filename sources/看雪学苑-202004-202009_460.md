# 微软 500 GB 源代码惨遭泄露，罪魁祸首原来是它

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458305279&idx=2&sn=4dfcb199659a81b2ab09f608644cbe35&chksm=b181f27586f67b63efe679dca731d79e80789a8ad5e7857e0ecdb324d484ea5b4497d23189a6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458305279&idx=2&sn=4dfcb199659a81b2ab09f608644cbe35&chksm=b181f27586f67b63efe679dca731d79e80789a8ad5e7857e0ecdb324d484ea5b4497d23189a6&scene=27#wechat_redirect)

![](../Images/6ed884dacda3402f065cfdb1cc6f84c5.png)

  
Github 上源代码泄露不止一两次了，看雪精华会员 cvcvxk 说道：“我们以为微软不会把重要的代码放到 Github 上，结果我低估他们了。这是 Github 出了 Private 越权，导致有大哥已经拖了微软 500GB 的代码。”  
  
**有趣的是微博网友表示，微软泄露的私有 GitHub 账号里面居然有当时 X 站泄露的源代码。**  
![](../Images/d06ad0b2bfa84821651ba69558c992c6.png)  
另外，外网的一篇报道说并没有 Windows 和 Office 的源码，微软不用过分担心。  
![](../Images/c70093a7b0f84addf7541e2054350e4f.png)  
当然还有很多网友担心，微软市值会跌还是会涨。比如开源出来了市值不应该会涨吗，快速提高市场占有率。  
得出的结论是，重要的代码别放到 GitHub 上，吓得小编我赶紧把我的 fuzz 删了。  
![](../Images/1cf9088b3fbeb120409717ee6a040514.png)
