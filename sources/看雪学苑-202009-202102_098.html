看雪学院（www.kanxue.com）是一个致力于PC、移动、智能设备安全研究及逆向工程的开发者社区，已有注册会员近百万。于2000年创建，始终以关注信息安全技术领域的最新发展为主，为IT专业人士、技术专家提供了一个民间交流与合作空间。大量安全人才，通过论坛，从普通IT爱好者成长为安全专才。此外，网站还为 IT 企业源源不断输送和推荐众多优秀人才，在业内形成良好口碑。


20年来，在老版主和热心会员的支持下，看雪论坛逐渐成长，极大地推动了信息安全技术的发展。


现有的老版主，大多已升职加薪，成为各公司的负责人或骨干。


为了更好地发展论坛，需要更多对安全有兴趣的新鲜血液积极加入，因此现各版块开放新版主的招募。


成为版主能让你接触到看雪论坛积累20年的安全技术人才资源和学习资料。


从此更好地融入安全圈


认识志同道合的朋友和未来事业伙伴


在你的履历上添上浓墨重彩的一笔，让你在求职时更有竞争优势......


招募有效期：长期有效
申请提交时间：长期有效
审核申请时间：提交后一周内
试用时间：两个月



相信自己能够胜任的你，现在就可申请啦！



 版主专属福利 






1）论坛特殊用户组及徽章标识；

2）拥有负责论坛的操作管理权限 ；

3）具有策划、组织、实施与版面主题有关的活动的权利 ；

4）优质内容和活动会得到首页推荐；

5）根据每季度考核结果给予合格及合格以上的版主虚拟工资奖励，每个季度1000雪币；

6）年底将根据考评情况发放周边大礼包；

7）优先参与社区的各种线下活动；

8）更多福利陆续增加中。




 申请条件 






   1）申请版块范围：看雪论坛所有版块
   2）热爱看雪社区，善于沟通。
   3）至少有一篇论坛精华帖（重要）。
   4）做事认真、负责，有上进心，有版面规划能力。
   5）能够独立策划版面活动，并做好活动的跟进工作。


加分项：

1. 有其他论坛的管理经验者优先考虑；

2. 可以组织论坛线上/线下活动者优先考虑；

3. 欢迎现任版主和超级版主的推荐！



  主要负责内容 







1 ) 建立和维护版区正常的讨论秩序，例如删除非法帖子、ban违规ID、帖子分类等；

2 ) 负责收集对责任版区的发展意见和建议，并提交给管理员和分区版主；

3 ) 解答社区成员的技术问题（依个人能力而定）；

4 ) 查阅论坛每日新帖，对热心回答问题的社区成员进行设置优秀/精华和鼓励；

5 ) 引导新人熟悉论坛规则，解答常见的疑惑；

6 ) 协助社区成员的帖子发布，帮助社区成员移动帖子和修改帖子内容（修改需经会员同意）；

7 ) 营建论坛“自由、开放、分享、协作”的氛围，坚决阻止破坏论坛氛围的行为；

8 ) 主动发布新闻、教程和软件推荐等优秀帖子；

9 ) 调停社区成员的冲突，合理妥善的解决问题；

10 ) 参与社区规则和社区活动的制定和策划。




  版主工作评估 







每一季度对所有版主工作进行评价，未按要求完成工作（例如长期未上线管理论坛或者没有回答过会员问题等）的版主将会被退出版主团队，并失去享受版主福利的机会；

在所有完成工作的版主中，依据季度评价结果评选出三位年底优秀版主，可获得额外奖励。

版主评价规则如下：

1. 在线时间：每月至少20小时在线时间；

2. 发帖数：每月至少10次有内容的回帖解答会员的问题；

3. 帖子/账户管理统计：每月至少10次管理行为；

4. 组织的活动；

5. 特殊贡献；


对于严重侵害论坛会员权益、滥用职权者，以及长期未履行版主义务者，论坛管理小组有权随时免职版主身份，并予以警告。




  申请方式 







 1）申请版的版块名称

 2）申请人 ID

 3）您的专长

 4）联系方式：OQ号码 或 微信号

 5）平均上网时间和时段

 6）申请理由，管理理念

 7）对该板块的现状分析，改进建议和管理思路

 8）是否担任过（或者）正担任其他论坛的管理职务？

 9）可任职时间


申请注意事项：

1）相关人员会在15个工作日内审核，通过QQ或微信联系。

2）审核通过即为实习版主，正常实习期一个月，通过考核可申请转正式。

3）正式版主依然会有日常工作的考核，长期请假或无法完成者勿扰。

4）一旦成为正式版主，无特殊情况半年内不准辞职。
