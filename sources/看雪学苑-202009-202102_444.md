# Google从Play商店删除17个恶意软件；我国上半年减少超4万台ATM机；谷歌明年开始抽取“谷歌税”

近日，大部分的 Microsoft 365 服务，从微软 Teams 到 Azure都存在一个不明的问题，导致多个服务在全球地区范围内不可用，但所有登录到现有会话的用户仍可以继续会话。对此，微软称已经在对可能造成的影响进行修复，并正在监控环境、影响范围以确保服务的恢复，建议用户检查自己的管理门户，以了解更多细节。

Google从Play商店删除17个恶意软件

  

![](../Images/f98a8cda1d21f0da1b7b39dd455afb41.png)

#  

# 据外媒ZDNet消息，谷歌近日从官方Play商店中删除了17个涉嫌WAP欺诈的Android应用程序。

  

据悉，来自Zscaler的安全研究人员发现这17个应用感染了Joker（Bread）恶意软件，这些应用的下载量约为120,000，其中大多数是扫描仪应用程序，也有一些消息传递应用程序和照片编辑器。这些恶意软件会窃取用户的SMS消息、联系人列表和设备信息，并以静默方式签署受害者的高级无线应用协议（WAP）服务。  
值得一提的是，Google其实一直都在努力和Joker恶意软件作斗争，过去三年中成功从Play商店中删除了1,700多个被Joker恶意软件感染的应用。但今年2月，该恶意软件开发者开发了一种新的Joker恶意软件变种，使其能绕过Play商店的安全检查。因此从3月以来Joker又开始处于活跃状态，据称已感染了数百万台设备。  
目前，按照内部程序，谷歌已从Play商店中删除了这些应用程序，并在使用Play Protect服务的受感染设备上禁用了这些应用程序。但用户仍需提高警惕，手动将其从设备中卸载干净。

我国上半年减少超4万台ATM机

  

![](../Images/3575be81cc7923911fd1acd4041b7cc8.png)  

# 近年来，移动支付兴起。央行支付体系报告显示，今年二季度，我国各大银行共处理移动支付笔数同比增长26.99%，非银行支付机构处理网络支付笔数增加14.48%。今年以来，全国ATM机具数量减少已超过4万台。

 

# 事实上，ATM机逐渐被移动支付取代不仅仅是因为其购置、运维等成本居高不下，此外在这个网络时代，其安全性也日益面临风险。

#  

# 近年涉及“红外插入式伪造卡槽”的ATM相关网络攻击活动正在持续增加，不法分子能将其隐藏在正常的ATM插槽之内，利用它来捕捉卡片数据，并将其存储在自带的嵌入式闪存当中，窃取用户敏感信息。

 此外，ATM机遭受恶意软件感染导致大量信用卡信息和财产被盗，甚至ATM机里存在恶意程序，在输入特定代码后会自动吐钞的案例都在全球范围内时有发生。

#  

# 因此目前，各大银行都在逐步使用功能更多、成本更低的机柜替代ATM。虽然业内人士人认为ATM机在较长一段时间内还不会消失，但其总量或将持续萎缩，使用率不可避免持续降低。

谷歌明年开始抽取“谷歌税”

  
![](../Images/021f840feb7d484c79996b92bb519694.png)  

# 近日据外媒CNBC报道，谷歌表示将从明年开始执行应用商店规则，安卓用户可以通过第三方商店安装应用，但要求所有应用的开发者必须使用谷歌应用内支付系统。

#  

# 据悉，谷歌为应用开发者留出了一年的时间来调整，最后截止日期为 2021 年 9 月 30 日。届时，开发者将必须使用谷歌的支付系统，不能再使用其独立支付系统。这就意味着谷歌要开始像苹果一样抽取“苹果税”，此后开发者在谷歌应用内的购买收入都将被谷歌抽取 30% 的分成。

#  

# 其实，谷歌的现有政策也要求应用开发商在应用内购买交易上使用谷歌支付系统，但一直没有执行。在过去12个月里，在通过Google Play商店提供应用的开发者中，有97%遵守了关于支付系统的政策。但也有许多开发商绕过了该系统，如Netflix和Spotify的应用程序就提示消费者使用信用卡支付，绕过了谷歌抽成。

#  

# 对于谷歌此次的决定，有行业人士表示虽然安卓是开源系统，不过谷歌正在效仿苹果，更严格的管控能让其获得更多的收益和控制权。对此，你怎么看呢？
