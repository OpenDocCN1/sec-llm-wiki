# TCTF2020收官：全球顶尖极客战队云上24小时巅峰对决

9月27日上午，第四届腾讯信息安全争霸赛(Tencent Capture The Flag，以下简称TCTF)正式收官。

  

经历24个小时的鏖战之后，来自俄罗斯的**More Smoked Leet Chicken（简称MSLC）战队**凭借**999分**的总积分，从全球顶尖极客战队中脱颖而出，夺得国际赛（0CTF）冠军；新星邀请赛（RisingStar CTF）冠军则由中科院信息工程研究所**NeSE战队**摘得。

## **全球974支极客战队群雄逐鹿，**

## **30强云上巅峰对决**

  

作为由腾讯安全发起，腾讯安全学院、腾讯安全联合实验室主办，腾讯安全科恩实验室承办，0ops安全团队协办的专业CTF挑战赛，TCTF分为面向全球极客战队的国际赛（0CTF）和面向国内高校的新星邀请赛（RisingStar CTF）两个平行赛制，采用符合国际标准的**解题混合赛制**，综合考验参赛战队技术实力与团队合作能力。

  

受到疫情影响，今年的TCTF决赛首次改到线上举行，但选手们的参赛热情不减。来自中国、中国台湾、美国、日本、韩国、英国、德国、俄罗斯、波兰等国家和地区的**974支战队**参与了预赛选拔，最终**30支实力强队**杀入决赛。其中包括日本老牌劲旅TokyoWesterns战队，第二届TCTF总冠军Dragon Sector战队，CTFtimes 排名前两位的More Smoked Leet Chicken（MSLC）战队和perfect blue战队，以及2019年表现亮眼的高校“黑马”战队Whitzard等。

  

自9月26日开赛以来，国际赛（0CTF）赛场就火花四溅：中国台湾地区的Balsn战队凭借在Pwnable题型上的得分，率先斩获全场一血；日本TokyoWesterns战队、美国perfect blue战队、中国联合战队Tea Deliverers不甘示弱奋起直追，排名屡次更迭。直到首日赛事直播结束，Balsn战队仍保持着第一优势。最后1小时的冲刺时刻，MSLC战队、Balsn战队、Tea Deliverers战队始终保持比分紧咬，赛事解说员表示“前三名之间仅有一道题的差距，随时可能扭转战局”。最终**MSLC战队以微弱优势锁定第一，中国台湾地区的Balsn战队、中国Tea Deliverers战队名列第二、三名。**

  

而在线上另一端的**新星赛场**中，冠军的争夺在中科院信息工程研究所NeSE战队、浙江大学AAA战队、高校联合战队Emmmm以及复旦大学六星战队之间展开。最终制霸 KoH 榜的**NeSE 战队夺得冠军**，在解题赛中表现尤其出色的**浙江大学AAA战队夺得亚军，高校联合战队Emmmm荣获季军**。国内高校战队在KoH和解题上的表现，与国际顶尖战队同场PK也毫不逊色。

## **“双一流”人才培养平台显成效 **

## **护航产业安全筑牢人才基座**

  

在当前我国产业数字化加快转型背景下，网络安全已凝聚成为各行各业的认知共识，安全人才的培养更跃升为产业平稳健康发展的重点关注领域。在赛事对抗性逐年升级之外，TCTF打造由**一流CTF赛事**和**一流人才培养机制**组成的“**双一流”人才培养平台**成效也逐渐显现。

  

一方面，作为国际一流的CTF赛事平台，TCTF从2017年至今已吸引了来自中国、美国、俄罗斯、日本、韩国、波兰等国家共计4000多支战队参赛，促进国际顶尖白帽黑客之间的技术切磋交流。通过“以赛代练”在TCTF中拼杀出来的中国战队，逐渐在国际各大CTF赛事中崭露头角：仅在今年，腾讯eee战队联合国内高校组成的腾讯A\*0\*E联合战队就先后在DEF CON CTF外卡赛-Plaid CTF、SpamAndFlags 2020和DEF CON CTF预赛夺得三连冠，之后更摘得2020 DEF CON CTF全球总决赛的桂冠，一举刷新了中国极客战队在“网安世界杯” DEF CON CTF的最好记录。

  

另一方面，腾讯安全基于TCTF平台，持续深入**产学研一体化**探索，推动完善安全人才“发现-培养-转化”的生态链闭环。通过校企合作、实战课程以及认证架构搭建等方面的创新形式，腾讯安全已与广州大学、北京航空航天大学、西安电子科技大学、武汉学院、济南理工中等职业学校等多个学校达成战略合作，助力高校打通学生“学与用”的人才培养通路，培育适应新时期发展需要的信息安全实战人才。2020年初疫情冲击之下，TCTF全明星导师团打造了**TCTF公开课**，以线上课程的形式，为广大信息安全专业学生和安全爱好者传授**分享网络安全知识和实战经验**，提供**更好的****职业出路与平台机会**。

  

本届TCTF比赛已落下帷幕，但在数字经济全面发展的当下，信息安全攻防战永无止境。腾讯安全将持续投入网络安全竞赛“以赛代练”、完善人才培养机制等方式，进一步发挥TCTF“双一流”人才培养平台的优势，加速网络安全专业人才培养转化，为护航数字化产业发展，筑牢产业安全底座提供更多新生动力。
