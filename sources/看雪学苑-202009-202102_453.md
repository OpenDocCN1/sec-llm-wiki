# 微软回应Windows XP源代码泄露；揭秘游戏账号交易诈骗灰产；我国首枚芯片邮票面世

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458351517&idx=2&sn=e1a9203640eb1b43889b8c7e2f68a536&chksm=b180471786f7ce011e012d4e43934122ab53d0671138ed31d95fbe9b04f7a0107331d146fab7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458351517&idx=2&sn=e1a9203640eb1b43889b8c7e2f68a536&chksm=b180471786f7ce011e012d4e43934122ab53d0671138ed31d95fbe9b04f7a0107331d146fab7&scene=27#wechat_redirect)

昨日，中国银行客户端推送消息，鉴于微软公司已逐步停止对其Windows Phone系统安全更新和商店的维护服务，为给用户提供更智能、便捷、安全的移动金融服务，将于今日起停止Windows Phone版本手机银行客户端相关对外转账服务，建议用户使用中国银行iOS或安卓版手机银行进行金融交易，妥善保存您的安全认证工具和相关密码，谨防诈骗。

  

  

1

微软回应Windows XP源代码泄露

  

![](../Images/7a4804b014660f3e3007be1236d8d3e8.png)  
Windows操作系统现在依然是使用人数最多、覆盖最广的桌面操作系统，从安全角度来看，其系统源代码对于公众而言更是绝密的。然而继几年前至少有 1GB 的 Win10相关源代码泄露，以及今年一系列Xbox相关源代码泄露后，Windows又出现了源代码泄露的问题。 近日，国外论坛、社交平台上出现了一批Windows源代码的Torrent文件，经确认属于Windows XP和Windows Server 2003的源代码，且代码已被多次下载，并被打包成种子或者用网盘，在网络上传播。  
对此，微软已回应经过安全研究人员分析，认定源代码泄露属实，称这件事影响非常大，官方正在积极调查中。  
对于此次大规模泄露事件，有行业人士却有不同的看法。其表示，微软早在2014年就结束了对Windows XP的支持，最新的源代码泄露不太可能对仍然停留在运行Windows XP机器的公司构成重大威胁。 此外，其实微软此前就提供过一个特殊的政府安全计划（GSP），允许政府和组织有控制地访问源代码和其他技术内容，因此Windows XP的源代码本就并不是绝对的机密。

揭秘游戏账号交易诈骗灰产

  

![](../Images/350a2c401162a4686d7dfc4ec02d5c94.png)  
随着网络游戏产业的发展，游戏账号交易规模越来越大。这些交易主要在第三方交易平台上实现，由此催生出大量不法分子实施网络诈骗。 有不法分子会在第三方平台上谎称是购买者，要求受害者转到QQ等其他平台进行交易，再发送链接让“客服”与其对接。 当受害者答应提交“安全过户费”后，“客服”还会再次提出需缴纳押金，办理安全包赔业务，并称确保安全交易后系统会将金额全数退还。但受害者钱一打过去就会被拉黑，第三方交易平台订单交易也显示未成功，钱已被犯罪分子骗走。 此外，另一大诈骗手法是利用账号找回功能进行诈骗。今年1月就有犯罪分子假意出售其绑定“和平精英”等游戏账号的微信号，待收到对方交易资金后，利用微信账号找回功能，骗得受害人1万多元。 在此提醒大家交易一定要选择正规交易平台，并在交易过程中保存好沟通的聊天记录、交易过程的文字、录音等相关证据，一旦不慎遭遇诈骗可以利用证据进行报案。

我国首枚芯片邮票面世

  
![](../Images/bd6f5da633aa0397de67b125ddecc387.png)  
昨日，中国邮政发行《第40届全国最佳邮票评选纪念》邮票纪念张。这张邮票极其特殊，在传统印刷工艺中植入了NFC芯片，是我国首枚NFC芯片邮票。  
NFC技术是一种短距离的高频无线通信技术，在商品防伪、新零售电子价签、智能餐盘等诸多领域得到广泛应用。  
邮票印制团队经过长期研究及专项技术突破，引入多层纸张复合技术和激光打孔技术，在邮票中内置超薄NFC芯片，使邮票序列码、荧光暗码与芯片的ID一一对应，因此集邮者手中的每一枚纪念张都是独一无二的，还可通过中国邮政App读取芯片内容。  
这张特殊的芯片邮票将互联网、前沿科技与传统邮票有机结合，既保留了完整的邮票纸张属性，又能在印制工艺中保护芯片。  
它的问世既体现了高端防伪工艺技术优势，也满足了防伪溯源、信息化应用等方面需求，是中国邮政邮票发行中的重大创新，走在了世界邮票发行与印制的前列的同时，也将为集邮者带来全新的互动体验。
