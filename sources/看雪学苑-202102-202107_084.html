Windows 11预览版安装避坑指南

原文：http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458387337&idx=2&sn=9809e8d989f869fb3392145850f3c0a0&chksm=b18f330386f8ba15c88a5750696e26d4dad7aa149efbd55bfa4e41ef1277a74f8d3366c9f6dd&scene=27#wechat_redirect

近日，万众瞩目的Windows 11首个预览版 Build 22000.51已面向Dev Channel的Insider测试人员推送。

如何获取Windows 11预览版推送：

设置—更新—Windows 预览体验计划，点击开始后需要链接账户，然后选择DEV 通道，重启后进入更新界面，就可以收到 Windows 11 的推送更新了。 更新系统需要符合Windows最低安装要求，如不符合也可接到推送，但无法正常安装。



微软官方对安装Windows 11的最低配置要求如下：
 

热衷尝鲜的用户自然兴冲冲地前往安装体验，但除了功能不全、存在一些小Bug外，还有不少用户反馈称其在预览版的安装步骤就已经出现问题了。

安装失败的原因据用户反馈，主要是不支持TPM2.0、不支持Secure Boot，还有与安卓模拟器产生冲突等。对于部分安装失败的用户可以尝试以下方法：

1、win + R输入tpm.msc查看是否已启用TPM功能以及TPM的版本，若未启用需要进入BIOS中开启。

2、检查BIOS是否支持开启Secure Boot。

3、卸载安卓模拟器或删除virtualbox.exe。


虽然微软曾声称Windows 10将会是最后一个Windows版本，但如今微软还是准备好了要发布Windows 11，不过单看这已经公布的预览版，并没有太多大方向上的改变，更多的还是对界面、布局的优化。
 
作为预览版其功能不完善的地方也有很多。据用户反馈，预览版的汉化进度只完成了一半左右。而微软官方博客称，对安卓应用的支持及Microsoft Teams的内置都还需要在后续版本中实现。
