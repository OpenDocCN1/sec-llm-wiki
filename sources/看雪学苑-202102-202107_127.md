# 最新！Win7将不再通过Windows Update下载驱动更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458386934&idx=2&sn=dc857809910a5d2f55ae0ef3ea80a97f&chksm=b18f317c86f8b86a7d7e8c87249d9ce6ea17a4e39e81ad3a373cd2a5bfefe09f6fae5b92846e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458386934&idx=2&sn=dc857809910a5d2f55ae0ef3ea80a97f&chksm=b18f317c86f8b86a7d7e8c87249d9ce6ea17a4e39e81ad3a373cd2a5bfefe09f6fae5b92846e&scene=27#wechat_redirect)

![](../Images/ce4a526417ca7fec1f1eb3b3eaec6a12.png)  
  
2020 年 1 月14日，微软官方正式停止了对 Windows 7 的支持，也就是说不再对个人和普通企业用户分发任何安全补丁。  
6月17日，微软决定停止发布适用于 Windows 7 SP1、Windows Server 2008 和 Windows Server 2008 R2 的 Windows Update 驱动程序。  
据悉，此次举动是因为适用于Windows 7 SP1、Windows Server 2008、Windows Server 2008 R2 的 SHA-1 可信根证书授权已经于5月9日过期，无法再提供Windows 更新的发布选项。  
   
Windows Update 是大多数 windows 操作系统都带有的一种自动更新工具，一般用来为漏洞、驱动和软件提供升级和更新。通过及时有效地进行各种插件和驱动的更新和漏洞的修复，可以使我们使用电脑的体验更舒服、更流畅、更安全。  
  
  

由于 SHA-1 证书的停用和过期，利用微软可信根计划的合作伙伴可以向未打补丁的 Windows 客户端和 Windows 服务器设备发布不兼容的 SHA-2 签名驱动程序。

  

微软信任根证书计划（"程序"）支持在微软视窗和其他微软产品和服务中分发合格的根证书。  
但这可能会导致以下两个问题：**功能降级或设备启动时间更长**。这是由于未打补丁的系统在使用 SHA-2 签名驱动程序时会出现代码完整性问题。   
因此，为了避免以及降低不兼容的潜在影响，微软决定直接停止提供更新，具体包括：

*   （开发者）为当前支持的 Windows 和 Windows Server 版本提交的任何驱动程序包
*   任何针对已终止支持的 Windows 或 Windows Server 版本的驱动程序包。
*   从此之后，驱动程序提交者将需要在删除不受支持的系统驱动版本后向微软重新提交以重新发布。

 值得一提的是，用于 Windows 硬件兼容性计划 (WHCP) 的 Windows 7、Windows Server 2008 和 Windows Server 2008 R2 驱动程序提交将继续提供到 2023 年 1 月。 这些版本的系统将继续提供支持，以确保为批量许可的企业客户提供可靠性以及扩展安全更新 (ESU) 计划。 消息一出，网友对微软停止发布适用于 Windows 7 SP1、Windows Server 2008 和 Windows Server 2008 R2 的 Windows Update 驱动程序的这项举措发表了不同的看法：

*   有网友表示非常赞成，认为：“太好了，终于不怕windows update更新了什么补丁，系统直接挂了。” ； “好事情，windows update推送的驱动反而容易把电脑搞乱。”

  

*   部分佛系网友表示：“已经不行了，win7更新直接报错，反正淘汰了就不更了，爱咋地咋地。”
    

  

*   还有用户对这个举措提出了自己的疑问：“有点好奇和win7 同年发布的Mac OS版本现在还能不能用？”；“廉颇老矣，尚能饭否？”
