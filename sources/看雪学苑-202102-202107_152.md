# Win10六月累积更新来了！共修复49个漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458386484&idx=2&sn=5d812ac4db53f4d2864097232934e778&chksm=b18f30be86f8b9a8d78666b5a13a9c0da2f07458fae2cef5f75acb850909b18911c3d6215ad8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458386484&idx=2&sn=5d812ac4db53f4d2864097232934e778&chksm=b18f30be86f8b9a8d78666b5a13a9c0da2f07458fae2cef5f75acb850909b18911c3d6215ad8&scene=27#wechat_redirect)

6月2日，微软宣布将在24日晚23点，发布下一代Windows，引发广大用户的期待，人们纷纷猜测在这场发布会上微软将带来革命性的「Windows 11」。

  

在人们的期待中，如期迎来了6月补丁星期二活动日。

  

本次微软发布了多个累积更新，包括 version 1909 (KB5003635), version 1809 (KB5003646), version 1607 (KB5003638) 和 version 1507 (KB5003687)。  
值得注意的是，家庭版和专业版Windows 10 Version 1909在5月份获得最后一次服务更新。目前只有商业版和教育版会继续获得更新。  
本次更新主要修复了 49 个漏洞，其中 6 个是0-day漏洞，也就是说这些漏洞很有可能已经被黑客利用。  
适用于 Windows 10 Version 1909 功能更新的 KB5003635 累积更新主要亮点包括：  
1、在Windows 执行基础操作的时候提高安全性  
2、改善 Windows OLE（复合文档）安全性  
3、用于验证用户名和密码的更新  
4、存储和管理文件的更新  
5、提高使用鼠标、键盘或笔等输入设备时的安全性的更新  
6、修复在2021年5月11日或更高版本的更新并重新启动设备后，可能会阻止你登录到一些Microsoft 365桌面客户端应用程序的问题。  
7、修复了一个在Windows Update期间不一致的关机问题，该问题损害了Windows Management Instrumentation（WMI）存储库。因此，管理对象格式（MOF）高级安装程序失败。  
8、对Microsoft Scripting Engine, Windows App Platform and Frameworks, Windows Input and Composition, Windows Management, Windows Cloud Infrastructure, Windows Authentication, Windows Fundamentals, Windows Virtualization, Windows Kernel, Windows HTML Platform 和 Windows Storage and Filesystem 的安全改进。

  

面向 Beta 和 Release Preview 频道用户，微软发布了适用于 Windows 10 21H1 功能更新的 KB5003637 累积更新，在安装之后版本号升至 19043.1052。该更新现在也适用于 Windows 10 20H1 和 20H2 功能更新 。
