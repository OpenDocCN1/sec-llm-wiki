# 快来升级了！苹果发布最新版系统，修复安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458382271&idx=2&sn=1b70a4b40d717dc867837e62d427efe3&chksm=b180df3586f75623f3b74592a06f3e25836769a786ff2c1235f42bd447084e85fd454c85c0b4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458382271&idx=2&sn=1b70a4b40d717dc867837e62d427efe3&chksm=b180df3586f75623f3b74592a06f3e25836769a786ff2c1235f42bd447084e85fd454c85c0b4&scene=27#wechat_redirect)

1月26日，苹果更新的iOS/iPadOS14.4版本增加了包括 "查找我的物品 "和改进的HomePod mini Handoff在内的功能，让用户眼前一亮。  
3月9日凌晨，苹果发布了iOS/iPadOS 14.4.1、macOS 11.2.3与watchOS 7.3.2正式版，此外还发布了 macOS Big Sur 11.2.3 正式版更新。  
本次更新提供了重要的安全性更新，修复了WebKit安全漏洞，据悉WebKit是为Apple的Safari浏览器提供动力的引擎，WebKit漏洞允许黑客在苹果设备上执行代码，并在Safari浏览器引擎中所造成的内存损坏问题。

> *WebKit 是苹果Mac OS X 系统引擎框架版本的名称，主要用于Safari，Dashboard，Mail 和其他一些Mac OS X 程序。*

此外，还解决了目前现有系统了很多BUG以及软件适配、兼容的漏洞，还有一些专用软件的闪退等问题。建议所有用户安装升级。  
值得注意的是macOS 11.2.3为macOS Big Sur的第五次更新，其距离上次更新仅相隔两周时间。有不少用户认为MAC更新过于频繁，带来不便。![](../Images/607a6420b41f084664fba575cdad8c0d.png)  
除了本次更新，有关苹果春季发布会日期、具体发布产品、iPhone 13是否取消刘海与充电口以及苹果要造车等内容引发大家猜测与讨论。看来大家都十分期待苹果春季发布会了！
