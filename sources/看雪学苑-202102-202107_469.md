# Win10盗版猖獗，德国警方出手调查

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458381971&idx=2&sn=0845261f38e60cb53796fe05505f9f3a&chksm=b180de1986f7570feb909c0d8fa70ef9bb76e39e07dcb63574a27dee0678dacf1e3a708638e4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458381971&idx=2&sn=0845261f38e60cb53796fe05505f9f3a&chksm=b180de1986f7570feb909c0d8fa70ef9bb76e39e07dcb63574a27dee0678dacf1e3a708638e4&scene=27#wechat_redirect)

![](../Images/cbb06f1908d893b8804dce4b6d1dbd97.png)  
据外媒 Tarnkappe 报道，德国警方正在对多名购买盗版Win10 许可证密钥的用户进行问询笔录。若该用户无法自证清白，则有可能会被指控洗钱和侵犯版权。  
  
微软从2015年开始，向Win7、Win8.1用户开放了一年的Win10**免费升级**更新，并且在2016年夏季正式停止。不过针对残障人士，微软将Windows 10免费升级持续到2017年12月31日，否则升级到最新正版Windows 10要花费超过800元人民币，从微软购买。  
而那些没有正版 Windows 7 或 8.1 许可证的用户为了享受这一免费升级优惠，转而采用了另一种方式：他们从各种在线商店购买盗版 Windows 10 许可证密钥。  
在 eBay 和其他电商网站上，我们可以看到大量Windows 10 许可证密钥的商品，售价仅几美元，远远低于正版Windows系统售价，吸引了大量用户购买。  
一些曾购买廉价 Windows 10 许可证的用户称收到了德国警方的传票，德国警方并未对此作出回应，官方也没有发布相关的声明。该用户称这些密钥是多年前购买的，所以目前还不清楚警方近日对此发起调查是为什么。  
  
Windows盗版系统由来已久，不仅仅涉及侵权问题，还涉及到安全问题。盗版系统经常会捆绑预装软件和浏览器主页绑定，还有可能携带木马病毒，大家务必小心，切勿“贪小便宜吃大亏”。
