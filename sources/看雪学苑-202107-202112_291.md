**1、漏洞简述**• 漏洞名称：无• 漏洞编号：无• 漏洞类型：命令注入• 漏洞影响：远程命令执行• CVSS评分：无• 利用难度：简单• 基础权限：不需要

ghostscript是一款图像浏览工具。ghostscript能够查看以及打印PS、EPS、PDF格式的文件。适用于Unix、Mac OS X、VMS、Windows、OS/2和Mac OS classic等操作系统的使用。

# **漏洞分析**

  
根据流出的poc readme 得知该漏洞并不是直接由convert触发，而是convert调用了GhostScript， GhostScript触发了该漏洞。  
先找到convert调用GhostScript的地方，并观察传递的命令行参数。  
在linux系统中，调用其他进程的函数无非就system,execX,popen这几个函数，所以可以在libc中对这几个函数下断点。  
一段操作后并未发现断点命中，怀疑可能是先fork然后在子进程中调用。果然命中。![](../Images/1e56287d5b48f09127b28c0284eba39d.png)  
根据栈回溯，找到调用fork函数的地方，并修改ip强制将ip指向子进程的空间中，找到了调用gs的地方。  
![](../Images/dbd97c00e7cdce5ecfd2a653d8728ddd.png)  
![](../Images/4fb5b066a2665fe33d73edd3c90b48c8.png)  
![](../Images/11b52dabddbe92fb214f56a667be9bf4.png)  
传递的详细命令行参数如下  
gs -sstdout=%stderr -dQUIET -dSAFER -dBATCH -dNOPAUSE -dNOPROMPT -dMaxBitmap=500000000 -dAlignToPixels=0 -dGridFitTT=2 -sDEVICE=pngalpha -dTextAlphaBits=4 -dGraphicsAlphaBits=4 -r72x72 -g612x792 -dEPSCrop -sOutputFile=/tmp/magick-15565sSaJTfcgWCk7%d -f/tmp/magick-15565gqAGdyB3qGD9 -f/tmp/magick-15565RttrpTjPQ4Qb 

其中最关键的参数是/tmp/magick-15565RttrpTjPQ4Qb指向的文件。  
![](../Images/6c5868a8895f08db3e530c332ba58d65.png)

可以看到，我们传入的命令已经被写入到了其中。  
手动执行上面的命令行测试。  
/tmp/magick-15565RttrpTjPQ4Qb 是一个软连接，它指向/proc/self/fd/3, 由于进程不同所以需要将self替换为convert的进程id。  
![](../Images/bf426142e4d5c4722155bbdab4b37d2b.png)  
可以肯定该漏洞肯定是由GhostScript触发的。  
现在来调试GhostScript，和前面的思路一样，既然是命令注入肯定逃不脱system、execX、popen系列的函数，所以还是在libc中将这些函数下断点等它来即可。 ![](../Images/a14cdd3c798b25b938f2532657e9133e.png) 可以看到在popen函数中命中了断点，并且利用’;’来执行命令。 查了一下GhostScript是一个开源的软件，下载了一份源码看下具体的调用逻辑，但由于太过复杂，所以只是简单的分析了下来龙去脉。 这里有一个数据结构，应该是根据%pipe%这个字段来调用该数据结构中的函数指针进行解析。  
![](../Images/bd4223eeef41a3600fc5a553790da5d5.png)  
pipe\_fopen函数中调用了open\_pipe函数指针。  
![](../Images/bf2abc2de08b0075c432249eadff63d7.png)  
open\_pipe函数指针在pipe\_init函数中初始化并赋值为fs\_file\_open\_pipe。  
![](../Images/7781485aa140b03ac2a65a62d9a582dc.png)  
fs\_file\_open\_pipe函数中调用了popen函数，这里就是漏洞的触发点。  
![](../Images/294e8334982af6be945fc14ca42147ac.png)  
很明显，此处是将括号中的字符串当作文件名直接传递给了popen函数来进行执行，所以才导致该漏洞存在。 ![](../Images/87890d7004698998264fa869e1cee4b5.png)
