# 微软正式宣布Win 11升级时间，仍缺少一个最关键功能

距Windows 10正式发布已经过去了六个年头，曾声称Windows 10会是最后一个Windows版本的微软还是发布了Windows 11。  
  
据微软官网消息，微软将于2021年10 月 5 日正式开始推送 Windows 11。10 月 5 日起，符合条件的 Windows 10 PC 将可免费升级到  Windows 11，预装 Windows 11 的各种全新 PC 设备也将开始上市发售。 Win 11相较于Win 10有什么亮点呢，我们先来看看官方新闻稿件是怎么说的： ![](../Images/02455bfbd3f536f1a3c68cdb3d540ed9.png)   
下面我们再来看看用户反馈的意见：“任务栏为了好看改废了，功能缺失太多不好用。”“本质还是Win 10套个皮，没有太多功能更新，更多的是设计布局更新。” 用户反应最激烈的，还是微软画的饼——Android应用支持功能未上线。这块饼当初Win10的时候就在画了，有很多网友都很期待Windows能兼容Android APP运行，一直延后让大家很担心这个功能会被砍，如果正式升级时能提供这个功能想必风评会好很多。 本次升级Win 11系统的硬件要求： ![](../Images/c747a1908ff6b8bac4fc8c43ff206eee.png) 预计从今年10月5日到明年年中，微软将根据硬件条件、可靠性、使用时间，及其它会影响升级后使用体验的因素，对市场上已有的设备分阶段推送升级。用户也可以在“设置”中选择“Windows 更新”，然后点击“检查更新”，查看设备是否已经可以升级到 Windows 11。  
![](../Images/18fb2dd010062f59d58ad77f74c8f26f.png) 不知大家到时候是先观望一阵子还是立即升级呢？
