微软提醒IE浏览器将于今年6月15日停用

编辑：左右里

此前微软已宣布过，未来将会由基于Chromium的Microsoft Edge完全取代已落后于时代的Internet Explorer。近日，微软再次提醒用户：2022年6月15日，Internet Explorer桌面应用程序将不再受支持。

但这并不意味着IE浏览器就此永久消亡，在Edge中仍保留了IE模式，保证了与基于IE的旧版站点和应用程序的兼容性，以确保用户仍可在需要时打开依赖于IE的旧版网站。而Edge的IE模式至少会保持到2029年，微软表示会在决定停用IE模式的前一年向用户发布通知。

但如果对某个版本的 Windows 的支持在 2029 年之前结束，则该版本的 Windows 上对 IE 模式的支持也将结束。若要继续使用 IE 模式，需要迁移到受支持的 Windows 版本。当前支持的 Windows 版本的服务终止日期如下：


值得注意的一点是，IE所使用的MSHTML（Trident）引擎将继续受支持，WebOC和MSHTA应用程序都将继续受到支持。对于那些依赖于 MSHTML引擎的自定义应用或第三方应用，也都将不受IE停用的影响继续正常运行。

在停用IE后，用户会体验到以下直观的变化：

"开始"菜单上的IE图标将被删除，但任务栏上的IE图标会保留。

当用户尝试启动使用IE的快捷方式或文件关联时，将被重定向到在Edge中打开相同的文件/URL。

当用户尝试通过直接调用iexplore.exe二进制文件来启动IE时，将改为Edge启动。


用户若想要在Microsoft Edge中启用IE模式，可在地址栏输入edge://settings/defaultbrowser，设置"允许在 Internet Explorer 模式下重新加载网站"选项为允许，然后重新启动浏览器即可。

注入

Web安全头号大敌。攻击者把一些包含攻击代码当做命令或者查询语句发送给解释器，这些恶意数据可以欺骗解释器，从而执行计划外的命令或者未授权访问数据。


注入攻击漏洞往往是应用程序缺少对输入进行安全性检查所引起的。注入漏洞通常能在SQL查询、LDAP查询、OS命令、程序参数等中出现。
