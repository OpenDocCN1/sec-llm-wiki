# 网络安全年鉴：775亿美元并购额，293亿美元私募股权及风险投资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458428920&idx=2&sn=20717f6507e5a3e23eb8351f49d97fec&chksm=b18f957286f81c64fa7e50a7710d0dcb75bb4aae5c4d52fa7f8d0369ae4f5b7fedc236b50dd5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458428920&idx=2&sn=20717f6507e5a3e23eb8351f49d97fec&chksm=b18f957286f81c64fa7e50a7710d0dcb75bb4aae5c4d52fa7f8d0369ae4f5b7fedc236b50dd5&scene=27#wechat_redirect)

近日，网络安全投资战略咨询公司Momentum Cyber公布了一份网络安全年鉴，该年鉴根据对全球3500多家网络安全公司及其战略交易活动（包括首次公开募股（IPO）、并购（M&A）、风险投资和私募股权融资以及新闻和事件的市场影响）的分析，总结出2021年该行业的关键趋势。

 

2021年是战略收购创纪录的一年，共进行了286笔交易，据披露总价值为775亿美元。这一年有14笔交易价值超过10亿美元，是迄今为止达十亿美元的交易数量最多的一年。安全咨询和安全托管服务继续引领行业交易数量，与此同时SecOps / IR / Threat Intel同比增长171%，是所有行业中最大的。

 

2021年，网络投资与威胁保持同步，网络安全总投资飙升，比上一年增加了一倍多。投资者在1000多笔交易中投入了293亿美元的风险投资和私募股权融资，远高于2020年的124亿美元。而在1042笔交易中，有82笔超过1亿美元，总融资价值比上年增长136%。

 

创纪录的IPO活动和估值表明网络安全的重要性，"独角兽"（极具潜力且估值超过10亿美元的企业）一词不再只属于少数几家公司——2021年铸造了30多家独角兽，而2020年只有6家。在过去的一年里，随着公司通过传统途径和SPAC（特殊目的收购公司，海外一种借壳上市方式）上市，出现的主要IPO包括KnowBe4，Darktrace，SentinelOne，Riskified和ForgeRock。网络安全股的表现一直与标准普尔500指数一致，同时跑赢纳斯达克指数。

 

2021年网络攻击有显著增加，重大事件包括美国主要燃油管道关闭、对JBS的攻击导致食品供应中断，以及爱尔兰卫生系统的瘫痪等。而供应链攻击，如SolarWinds、Kaseya和Microsoft Exchange，突显了我们当今联系和技术依赖日益紧密的世界的危险。2021年发现并积极利用的重大漏洞，包括Log4j漏洞和NSO的zero-click间谍软件，强化了这一不断增长的风险，并强调了对创新的需求。

 

Momentum Cyber称，随着我们进入新的一年，许多有前途的技术和令人兴奋的趋势已经开始形成，包括网络安全与加密货币和区块链的新兴关系、专注于迎合开发人员的DevOps左移、托管检测和响应、零信任的持续关注，以及随着工业安全的发展而对ICS +OT的日益关注。这些行业在未来一年将如何发展还有待观察，而投资者肯定会密切关注。
