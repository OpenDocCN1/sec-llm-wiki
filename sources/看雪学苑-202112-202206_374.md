# 推特透明度报告：美国政府索要的信息最多

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458428051&idx=3&sn=d64ea0e2e4ad086ecaec3feb86cef12a&chksm=b18f921986f81b0f7ec2eaeb1480822616597903db4c42175133b57edc36a3dc4425ca2a13ad&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458428051&idx=3&sn=d64ea0e2e4ad086ecaec3feb86cef12a&chksm=b18f921986f81b0f7ec2eaeb1480822616597903db4c42175133b57edc36a3dc4425ca2a13ad&scene=27#wechat_redirect)

1月25日，推特Twitter透明度中心公布了一份透明度报告，以让用户了解世界范围内各国政府向他们提出的要求。 

> 推特认为透明度有利于保护持续受到威胁的开放互联网，并且对于追究公司和政府的责任至关重要。当公司、民间社会和监管机构对其依赖的数据和流程保持透明时，可以建立和增强对网络信息的信任。推特自2012年起每年都会分两次发布Twitter透明度报告，这是业内首批此类报告之一。本次报告涉及的数据范围为2021年1月1日至2021年6月30日。

  

在本次报告涵盖的六个月内，推特总共收到了12370份政府信息请求， 43387项删除内容的法律要求，对4826539个账户采取了行动。本次报告是自 2012 年发布第一份透明度报告以来，在报告期内受到移除请求的账户数量最多的一次。

  

在政府请求方面，政府关于保存帐户信息的请求相比推特上一次透明度报告减少了4%，其中美国占全球所有保存请求的57%。

  

与上一次报告相比，美国成为政府信息请求的最大来源，与印度、日本和法国合占全球政府信息请求的四分之三。美国的信息请求多数来自美国联邦调查局、特勤局和司法部，推特全部或部分遵守了这些请求的68%。对于全球范围的政府信息请求，推特不披露信息或披露部分信息的比例为64%。

  

在非政府请求方面，截至本次报告所述期间，推特自2014年以来已收到来自35个不同国家的非政府信息请求，其中阿根廷、以色列和瑞士是首次出现在本报告中。非政府信息请求中日本、巴西和美国是前三个请求国，这三个国家合占所有请求的89%。

  

这些请求通常来自从推特寻求帐户信息的第三方，例如，作为民事诉讼的非当事方，或在刑事案件中作为被告的代言人。

  

在全球全部法律要求中，95%的数量来自于仅仅五个国家（降序排列）：日本、俄罗斯、土耳其、印度和韩国。推特响应了全球54%的法律要求，令帐户持有人删除部分或全部举报内容。
