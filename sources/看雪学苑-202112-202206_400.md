# 微软及游戏行业史上最大收购：以687亿美元收购动视暴雪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458419380&idx=3&sn=371644061dfee73d78d48954a004e2bb&chksm=b18fb03e86f83928bfa71d3dca405d8e9218918294f637dec3978d24957d0aca4f01e50739aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458419380&idx=3&sn=371644061dfee73d78d48954a004e2bb&chksm=b18fb03e86f83928bfa71d3dca405d8e9218918294f637dec3978d24957d0aca4f01e50739aa&scene=27#wechat_redirect)

今天一则新闻轰动了整个游戏圈，就在1月18日，微软官方宣布将以687亿美元收购动视暴雪Activision Blizzard。这不仅是微软有史以来规模最大，亦是游戏行业史上最大的收购案。收购完成后，微软将超过任天堂，成为仅次于腾讯、索尼的第三大游戏巨头。

  

动视暴雪在2007年由动视和暴雪两个公司合并而成，曾制作发行多款经典、热门游戏，如《使命召唤》《魔兽争霸》《暗黑破坏神》《守望先锋》《炉石传说》等，在全球 190 多个国家拥有 4 亿活跃玩家。。

  

收购动视暴雪前微软的最大一笔收购是在2016 年以 262 亿美元收购领英LinkedIn。微软在过去数年间，还进行过几次大手笔收购，其中就有多家游戏公司。如2014年微软以25亿美元收购游戏开发商Mojang，将畅销游戏《我的世界》收入囊中；又于2020年以75亿美元的价格收购了游戏公司ZeniMaxMedia（《上古卷轴》及《辐射》系列等）。

  

就在今年年初，美国游戏公司Take-Two宣布计划用127亿美元收购Zynga，刚创下游戏行业并购新纪录还没保持几周，就被微软打破。

  

微软表示，全球每天有30亿人在玩游戏，游戏现已成为全球最大且增长最快的娱乐方式。这次收购将加速微软游戏业务在移动、PC、主机以及云领域的增长，这些也将为元宇宙打下基础。微软正在大力投资于世界级的内容、社区和云，以开创一个将玩家和创作者都放在首位的游戏新时代。

  

本次收购已经获得微软和动视暴雪董事会的批准，预计将于2023财年完成。在完成之前动视暴雪和微软游戏将继续独立运营，Bobby Kotick将继续担任动视暴雪的首席执行官，交易完成后动视暴雪业务向微软的Xbox负责人Phil Spencer汇报。

  

![](../Images/ca87e66b40f8f7e3164589f83a9ab5f3.png)

  

预计完成收购后，微软将拥有30个游戏开发工作室，大幅增强其游戏制作发行实力。而动视暴雪旗下的多款游戏也将登陆微软 Xbox Game Pass 游戏订阅服务。微软称，凭借动视暴雪4亿活跃玩家以及众多游戏的特许经营权，此次收购将使Xbox Game Pass成为业界最引人注目和游戏内容最多样化的平台。

  

这么看来，恐怕索尼将成最大输家。
