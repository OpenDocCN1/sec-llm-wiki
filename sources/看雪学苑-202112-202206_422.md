# 华为在美国专利授权排名第五，全球专利持有量前十中国占六家

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458418299&idx=3&sn=c994fe5558c1b90767cdc5e0a0fc9112&chksm=b18f4cf186f8c5e71b7bbdacad5e7c9d2ff0b4aa13ee1c97087498e26e0ec8a6919fb7b44a5f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458418299&idx=3&sn=c994fe5558c1b90767cdc5e0a0fc9112&chksm=b18f4cf186f8c5e71b7bbdacad5e7c9d2ff0b4aa13ee1c97087498e26e0ec8a6919fb7b44a5f&scene=27#wechat_redirect)

编辑：左右里

  

全球专利数据库提供商IFI CLAIMS Patent Services最新发布了一份统计报告，报告显示，在2021年的专利授权量下降幅度是过去十年来最大的这个背景下，中国公司在美国获取的专利授权量持续上升。

  

![](../Images/8e9ecbd078bf3f5048088d6689df456f.png)

  

据图中数据，2021年中国公司在美国获取的专利授权总量排名第四，前三名依次是美国、日本、韩国。而在绝大多数国家在美专利授权量负增长的同时，中国公司以10%的增长率脱颖而出。

  

下图为2021年美国专利授权排行榜：

![](../Images/a07a158182fc8ec53e75ef8d8bdb7b19.png)

  

在美国获取的专利授权量前十公司依次为IBM、三星、佳能、台积电、华为、英特尔、苹果、LG、微软、高通。

  

目前中国大陆共有四家公司进入前50名，其中华为排名第5，京东方排名第11，蚂蚁集团子公司Advanced New Technologies Co Ltd排名第43，OPPO排名第49。

  

下图为全球实际专利持有者排行榜：

![](../Images/f7b5c8f8a8249de2129bb702b5ffb6dd.png)

  

图中前十名依次为三星、中科院、美的、华为、中石化、中建、格力、IBM、佳能、松下。

  

之所以这个榜单与上一个榜单有比较大的差异，其中一个原因是专利通常会发生转让。例如Global Foundries在专利所有者排行榜中排名第41位，但其许多专利都是从IBM获得的。IBM经常出售他们的专利，而不是围绕它们开发产品。

  

此外，该报告还揭示了2021年企业研发的优先事项，人工智能是最热门的领域之一。
