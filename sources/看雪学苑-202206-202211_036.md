
  

使用 IDA 打开后，停在 WinMain 处，x32dbg 的 Base 为 0x00EF1000，在 IDA 中 Rebase 为 0x00EF0000，则 WinMain 的地址为 0x00EF1ECF：  

![](../Images/096682567123c67960bd89b045fa500f.png)  
在 WinMain 中，连续调用了 sub\_EF1DEF() 三次，该函数内有 XOR 等操作，猜测为字符串解密操作：  
![](../Images/8db193d80f11206f6757c5eed9636438.png)  
结合 x32dbg 可知：

*   
*   
*   

```
第 1 次调用，解密字符串：SystemRoot\\SysWow64第 2 次调用，解密字符串：SystemRoot\\System32第 3 次调用，解密字符串：TEMP
```

![](../Images/d0fa63eddafa1df088db9510558415fa.png)  
因此，重命名 sub\_EF1DEF() 为 decryptStr\_sub\_EF1DEF()；之后调用函数 sub\_EF12D3()。  

## **4.1、sub\_EF12D3 - 解密PE**

连续两次调用 sub\_EF1063()  
![](../Images/d7d59eb4220e0f45e8faf54ec040da9e.png)

###   

### 4.1.1、sub\_EF1063

查看 sub\_EF1063() 内部代码后，猜测也是执行字符串解密操作：  
![](../Images/b06951be979b861fd60fc232990740a4.png)  
结合 x32dbg 可知：

*   
*   

```
第 1 次调用，解密字符串：cdnver.dll第 2 次调用，解密字符串：LOCALAPPDATA
```

  
因此，重命名 sub\_EF1063() 为 decryptStr\_sub\_EF1063()；之后调用函数 sub\_EF1000()。  

### 4.1.2、sub\_EF1000

内部代码看着也像是在进行解密操作，对 0x00F0B880 处的 0x59BD 字节的数据进行解密，解密后的数据如下，可以很明显地看到 4D5A：  
![](../Images/010cea92a9561fa1deaac94ef6bc10f4.png)  
解密出一个 PE 文件数据后，函数结束；sub\_EF12D3() 分析完成，返回到 WinMain()。  

## **4.2 sub\_EF13F7 - 解压缩PE**

连续两次调用 decryptStr\_sub\_EF1DEF()，解密字符串，可以看到是与解压缩有关的 API ：RtlGetCompressionWorkSpaceSize 和 RtlDecompressBuffer；注：RtlGetCompressionWorkSpaceSize 函数用于确定 RtlCompressBuffer 和 RtlDecompressBuffer 函数工作空间缓冲区的正确大小。  
之后调用 LoadLibraryW 加载 ntdll，并调用 GetProcAddress 获取上述两个 API 的函数地址；  
调用 RtlGetCompressionWorkSpaceSize 获取缓冲区大小，在调用 HeapAlloc 申请空间；  
最后调用 RtlDecompressBuffer 对刚刚解密出的 PE 数据进行解压缩：  
  
![](../Images/6cabe0f742ce54fd62ca089ce7e0bd6c.png)

## **4.3、sub\_EF155B - 释放DLL**

### 4.3.1、sub\_EF10CD

连续调用两次 decryptStr\_sub\_EF1DEF，解密得到字符串：SystemRoot 和 \\\\System32；  
之后调用 GetEnvironmentVariableW 获取 LOCALAPPDATA 环境变量：  
![](../Images/8720016085761168670ecb4272e51a15.png)  
这里为：C:\\\\Users\\\\Reverse\\\\AppData\\\\Local，再将 "\\cdnver.dll" 与之拼接得到了释放文件的目标路径：  
C:\\\\Users\\\\Reverse\\\\AppData\\\\Local\\\\cdnver.dll  
![](../Images/94acc280b9c90c8ec5611b88f525138d.png)  
返回 sub\_EF155B 继续执行；  

### 4.3.2、sub\_EF155B 继续执行

调用 LoadLibraryW 加载 Kernel32.dll，并获取 CreateFile 函数地址并调用，创建文件：  
![](../Images/f6fd1730e279b97968818ab9660dde16.png)  
获取 WriteFile 函数地址并调用，把 PE 数据写入文件：  
![](../Images/8f4b5315a89a97f8ced5d9ca13e65f82.png)  
文件释放完成。  

## **4.4、sub\_EF264C - 权限维持**

连续 7 次调用 decryptStr\_sub\_EF1DEF 进行字符串解密，得到：

*   
*   
*   
*   
*   
*   
*   

```
rundll32.exe#1UserInitMprLogonScriptcdnver.dllEnvironmentLOCALAPPDATAcdnver.bat
```

![](../Images/ba0f077bc7ca94efd6065c21f1d900f9.png)  
调用 LoadLibraryW 加载 Advapi32.dll，并获取 RegOpenKeyExW 函数地址，并调用，其中 0x80000001 是 HKEY\_CURRENT\_USER：  
![](../Images/04db08e7ed280fdadfd9b3a12eb96109.png)  
获取环境变量，并判断：  
![](../Images/549786071e79a0e1e976c1a93837ce58.png)  
从 ”cdnver.dll“ 中查找 "."，获取文件后缀：  
![](../Images/7a81d0e7dcd37cf83b83190c9fe296e2.png)  
之后确认只有一个 "." 出现。

###   

### 4.4.1、sub\_EF2030 - bat脚本

连续 6 次调用 decryptStr\_sub\_EF1DEF 解密字符串：

*   
*   
*   
*   
*   
*   

```
startLOCALAPPDATAcdnver.dll#1rundll32.execdnver.bat
```

  
调用 WideCharToMultiByte 将宽字符转为多字节字符；  
调用 LoadLibraryW 加载 Kernel32.dll，\_getenv 获取环境变量，获取 CreateFileA 的函数地址并调用创建文件C:\\Users\\Reverse\\AppData\\Local\\cdnver.bat：![](../Images/9102b2403065b634961426abd49509c5.png)  
构建脚本字符串 start rundll32.exe "C:\\Users\\Reverse\\AppData\\Local\\cdnver.dll",#1，调用 WriteFile 将脚本写入 bat 文件。  
![](../Images/80aac3e0e764e16d62cc4ac1eaa996a9.png)  
返回 sub\_EF264C 继续执行；  
拼接构造字符串 C:\\\\Users\\\\Reverse\\\\AppData\\\\Local\\\\cdnver.bat，  
![](../Images/0c12cc10b2011c6f178b2e61ca8940d2.png)  
调用 LoadLibraryW 加载 Advapi32.dll，获取 RegSetValueExW 函数地址，  
![](../Images/c038afd1aef7929afe24796db38c9ffa.png)  
设置注册表，使用 Logon Scripts 机制实现持久化：  
![](../Images/be1106ace309a9e28af39ee5b0f6124c.png)  
Logon Scripts 机制：Windows允许在特定用户或用户组登录系统时运行脚本，也就是能使脚本优先于杀毒软件执行。  
注册表设置前后对比：  
![](../Images/46c8a54c4eed7177ab21da75e113191b.png)  
![](../Images/3a7526091a61c8926127f0294d5f54fd.png)

## **4.5、sub\_EF1707 - 执行dll**

调用 \_wcsstr 函数在 cdnver.dll 路径中查找 ".dll"：  
![](../Images/6d71ae48ab1460cc702eb6b60a8f4033.png)  
若找到子串，连续 3 次调用 decryptStr\_sub\_151DEF 解密字符串：代码![](../Images/76ea4d41f432fd8ff0b9b11c3093a2cf.png)

###   

### 4.5.1、sub\_EF1D09

调用 OpenProcessToken、GetTokenInformation、GetSidSubAuthorityCount、GetSidSubAuthority 等 API 获取进程的 RID 信息：  
![](../Images/b5de21ba4b894b600be1fc5f0d0f58b4.png)  
![](../Images/ed79da00894587875bb9e109a5106640.png)  
x32dbg 中，RID = 0x2000，为中完整性：  
![](../Images/14860cf00361dd3d3eddcfd7d4727654.png)  
返回 sub\_EF1707 继续执行，将 eax(0x1) 与 3 比较，不等则跳转到 loc\_EF1811 执行 shell 命令，之后返回：  
![](../Images/29bdd601401160e7faf07ea0ee3c5524.png)  
若 sub\_EF1707 返回值为 3，则继续执行 00EF17DE：

###   

### 4.5.2、sub\_EF1B02

首先会调用 sub\_EF1957 函数：首先加载 AdvApi32.dll，获取 OpenProcessToken 的函数地址并调用；获取 LookupPrivilegeValue 的函数地址并调用，查看系统权限的特权值，第二个参数表示所要查看的特权信息的名称 SeSecurityPrivilege：  
![](../Images/b8cbf1c4dc9d088efb2d728d9a113228.png)  
调用 AdjustTokenPrivileges 修改令牌权限，再调用 LookupPrivilegeValue，所要查看的特权信息的名称 SeTcbPrivilege：  
![](../Images/8eda852bb91fb7694a337238739fca39.png)  
最后再调用一次 AdjustTokenPrivileges 修改令牌权限。  
![](../Images/61e4386674469ff3917d474901466007.png)  
提权完成，返回 sub\_EF1B02。  
调用 sub\_EF1C3D 函数：通过调用 CreateToolhelp32Snapshot、Process32FirstW、Process32NextW 等 API 遍历进程，查找 explorer.exe 进程：  
![](../Images/ca67c6e5555896d31fd823b89c0df46f.png)  
调用 OpenProcess、OpenProcessToken 等 API 获取 explorer.exe 进程的访问令牌句柄 TokenHandle，并作为结果返回：  
![](../Images/15bed852ea5447758c767f07eedc7f35.png)  
在进行内存初始化后，调用 sub\_EF18DC 函数，向内存中写入命令：  
![](../Images/403f6cfb71800da66548956c8c39aa45.png)  
返回 sub\_EF1B02。  
加载 AdvApi32.dll，获取 CreateProcessAsUser 函数地址，并调用：  
![](../Images/173b4644f0358686e6bea0e622be87c1.png)  
CreateProcessAsUser 函数创建一个新的进程及其主线程，其第三个参数为指向命令行字符串的指针，即：RunDll32.exe \\"C:\\Users\\Reverse\\AppData\\Local\\cdnver.dll\\",#1  
通常，调用 CreateProcessAsUser 函数的进程必须具有 SE\_INCREASE\_QUOTA\_NAME 特权，并且如果令牌不可分配，则可能需要 SE\_ASSIGNPRIMARYTOKEN\_NAME 特权。  
返回 sub\_EF1707，进行内存释放等操作。  
返回 \_WinMain，最后调用 sub\_EF18AD。

调用 DeleteFileW 删除文件

# 

综上，该样本的主要行为有：

*   在 LOCALAPPDATA 目录下释放 dll 和 bat；
    
*   修改注册表实现持久化；
    
*   提权，加载执行 cdnver.dll。
