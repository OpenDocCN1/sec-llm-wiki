# 极客市集

10月23日，第六届安全开发者峰会将于上海举办

我们为所有热爱网络安全技术的极客们量身打造【极客市集】

极客精神的魅力在于不断打破规则、制造变量。我们诚邀各位能人异士来2022 SDC 现场，分享您的得力“武器”

重要的事情说三遍：场地 free！free！free！您只需带上您的作品即可！

  

01

# 活动详情

时间：2022年10月23日（周日）

地点：上海

形式：摊位（3～5个）通过审核后，用户可在摊位前售卖商品

对象：摊位面向个人、组织和企业开放

 

02

# 报名方式

1、个人或企业申请提交自己的工具/商品等至 **service@pediy.com**（注明极客市集，附图片与商品创意点）

2、成功通过筛选的个人或企业，可在现场免费展示自己的商品。

注意：

*   所有申请通过 service@pediy.com 提交
    
*   提交的商品内容需包含如下信息：
    

对展示内容进行简单的描述及说明之前是否发布、发布的范围。

对申请人自身和工作经历描述。

 

03

# 商品要求

1、展示商品包括但不限于：安全类书籍、硬件设备、隐私设备、黑客工具等……

2、商品审核要求：有创意、实用、无明显缺陷
