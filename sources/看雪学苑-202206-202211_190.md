# **0****1****什么是『“雪花”创作激励计划』？**  

『“雪花”创作激励计划』是指看雪推出的针对看雪论坛会员创作的原创技术文章进行综合评估并提供“雪花”奖励的计划。

  

  

# **0****2****为什么要推出『“雪花”创作激励计划』？**  

今年是看雪与大家共同走过的第22个年头，我们依旧怀揣希望，心存梦想。

  

众所周知，看雪一向非常重视知识的传承和分享，我们希望无论是刚踏入安全圈的小萌新还是深耕数载的圈内牛人，都可以在看雪平台里学习、交流。

  

目前知识付费态势凶猛，往往很多时候想找一篇好的文章、好的文档、工具都需要付钱才能完整阅读或完整下载。但是至今为止，看雪论坛本身没有靠文章去赚钱，也没有付费查看文章。

  

其实经常逛看雪论坛的人可以发现，很多大佬仍然会将自己的学习过程、研究成果通过发帖的方式无私分享出来，正是因为有这样一群人的存在，看雪论坛才能发展壮大，网络安全行业才能人才辈出。

  

因此，我们想通过『“雪花”创作激励计划』鼓励看雪社区的会员投稿技术文章、营造社区良好的干货氛围；另一方面，筛选出的精华、优秀文章，经作者同意后将发表在看雪官方公众号，希望带给读者更优质、深层次的内容分享。

  

  

# **0****3****『“雪花”创作激励计划』具体内容**  

我们将从看雪论坛中选取精华、优秀文章发布于看雪官方公众号（入选标准见后文），一般为头条，篇幅较短的优秀文章考虑次条。

  

如您的文章非常优秀、有一定的技术含量被选中，我方将主动与您联系，征得本人同意后公开发布，并且根据版主对文章的评级（精华、优秀），您将获得与之相对应的“雪花“奖励！

## **0****4****技术文章入选公众号标准**  

1）看雪论坛精华、优秀原创文章（版主评定，标准如：https://bbs.pediy.com/thread-224498.htm）

*     
    
    精华标准：
    
    1.发帖者本人原创的，转载的一律不设；
    
    2.必须是文章，工具下载或发布不设精华，没有文字说明的纯源代码，一般也不设精华（特别有价值的源码可设）；
    
    3.文章的内容有一定的技术含量，或新意等。
    
    4.精华文章得有一定的篇幅（字数不能太少），但文章有创意和新意的主题，文章简短也可以考虑精华。
    
    5.看雪精华是一位会员实力体现，精华是水平象征。
    
      
    
*     
    
    优秀标准：  
    
    1.发帖者本人原创，转载的一律不设；
    
    2.文章没达到精华要求，但有一定的保存价值，或文章不错，但内容太过简短，设优秀。
    
    3.程序源码可以设优秀；
    
    4.优秀或有价值的工具，可以设优秀。
    
      
    

2）看雪公众号能成功发布（若被申诉取消原创，扣除奖励）
