# 黑山遭受前所未有的大规模网络攻击，部分服务暂时关闭

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458465984&idx=2&sn=139f0fe43bedd78fe2a9f932b0fbeb87&chksm=b18e064a86f98f5c8a6835eb853902e6154c95649e90c7ddc7f8a6245d2a648d32b250d6833b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458465984&idx=2&sn=139f0fe43bedd78fe2a9f932b0fbeb87&chksm=b18e064a86f98f5c8a6835eb853902e6154c95649e90c7ddc7f8a6245d2a648d32b250d6833b&scene=27#wechat_redirect)

据路透社8月27日报道，黑山当局表示，其政府数字基础设施遭到“前所未有”的网络攻击。黑山政府向北约其他成员国报告了此次攻击事件，并表示已及时采取措施减轻了其影响。  

  

黑山公共行政部长Maras Dukaj在推特上发文说：“出于安全原因，某些服务被暂时关闭，但属于公民和公司的账户及其数据的安全并未受到威胁。”

  

“黑山正在遭受持续不断的网络攻击。攻击可能包括对公用事业、交通（包括边境口岸和机场）和电信部门的破坏。”美国驻黑山首都波德戈里察大使馆在其官网上警告称。其还建议美国公民将在黑山的行动和旅行限制在必需的范围内，并保持最新且易于获取的旅行证件，因其担心这次攻击会影响黑山政府的相关基础设施。

  

黑山国家安全局（National Security Agency，ANB）表示，这次攻击是“前所未有”的，并对运营关键基础设施的机构发出了警告。

  

黑山国有电力公司EPCG董事会主席Milutin Djukanovic表示，在ANB警告它可能成为攻击目标后，EPCG已将其运营模式转变为人工处理，以防止造成任何可能的损害。作为预防措施，一些客户服务已暂时停用。

  

即将离任的黑山总理Dritan Abazovic在周五晚上召开的国家安全委员会会议上讨论这次攻击时表示，这起事件是出于上周其政府倒台后的政治动机。黑山政府认为这起事件是由民族国家行为者策划的。

  

值得注意的是，黑山近几年多次遭受严重的网络攻击。2016年，有黑客在选举日这天攻击了黑山的国家数字基础设施。随后在2017年，黑山在加入北约之际再次遭受了攻击。

  

鉴于黑山其曾为前南斯拉夫联盟共和国一员的身份，这起事件背后似乎暗流涌动。一位北约官员表示，北约已获悉对黑山发起的网络攻击，并准备在必要时给予帮助。
