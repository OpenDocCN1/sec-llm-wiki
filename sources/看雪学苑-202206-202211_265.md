# 活动详情

时间：2022年10月23日（周日）

地点：上海

形式：摊位（3～5个）通过审核后，用户可在摊位前售卖商品

对象：摊位面向个人、组织和企业开放

 

02

# 报名方式

1、个人或企业申请提交自己的工具/商品等至 **service@pediy.com**（注明极客市集，附图片与商品创意点）

2、成功通过筛选的个人或企业，可在现场免费展示自己的商品。

注意：

*   所有申请通过 service@pediy.com 提交
    
*   提交的商品内容需包含如下信息：
    

对展示内容进行简单的描述及说明之前是否发布、发布的范围。

对申请人自身和工作经历描述。
