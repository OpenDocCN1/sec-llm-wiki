# 英国持续高温导致甲骨文和谷歌云服务瘫痪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458458742&idx=2&sn=28c3e4a6d909f4b04bc8260cbde5fb12&chksm=b18e2afc86f9a3ea2c65c521ee2c711e1db284ebfbb01a901ebae4e2cb0d70beda09ae3b65e1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458458742&idx=2&sn=28c3e4a6d909f4b04bc8260cbde5fb12&chksm=b18e2afc86f9a3ea2c65c521ee2c711e1db284ebfbb01a901ebae4e2cb0d70beda09ae3b65e1&scene=27#wechat_redirect)

据外媒报道，英国在过去一周遭受了百年一遇的热浪，在周二温度更是达到了该国创纪录的40.2摄氏度。7月15日，英国宣布进入国家紧急状态，随后英国气象局发布了该国历史上第一个“极端高温”红色预警。

> 英国是温带海洋性气候，通常最高气温不超过32℃，空调普及率只有5%。

7月19日，甲骨文Oracle和谷歌Google这两家知名云服务提供商接连报告称，由于高温天气，其位于英国伦敦用于托管其云基础设施的数据中心的冷却系统发生了故障。为防止对硬件组件造成永久性损坏，甲骨文和谷歌都选择了关闭设备，暂时中断其云服务。  
甲骨文是最先受到影响的公司，该公司于19日午时报告了冷却故障，并表示：“由于该地区的‘非季节性温度’，一些客户无法访问或使用该区域托管的 Oracle 云基础设施资源，包括对象存储、计算和块存储卷。”  
就在同一天，谷歌也发布了一份事件报告：“我们的一栋建筑发生了与冷却相关的故障，导致该区域的部分容量故障，导致我们的一小部分客户虚拟机终止和机器损失。”  
两家公司都报告说，事件已得到控制，在使冷却系统重新上线前不会有任何进一步的影响。  
英国的基础设施难以应对突发的极端温度，除数据中心外，不寻常的高温对该国其他基础设施也造成了严重影响，包括导致机场停运、铁路减速、公路封闭等，还在英国各地引发了多起火灾。
