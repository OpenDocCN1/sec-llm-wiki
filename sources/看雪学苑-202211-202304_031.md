# 西班牙19岁天才黑客被逮捕，该黑客自称能访问九成西班牙公民信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NTc2MDYxMw==&mid=2458501283&idx=2&sn=810f9a0e49068ac60ab98e1ed201db4e&chksm=1b17d8daca19c8a48d4c819d8e0c811c21ad2abc912dba44dd35fc6832cb90a089c6e32509ef&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5NTc2MDYxMw==&mid=2458501283&idx=2&sn=810f9a0e49068ac60ab98e1ed201db4e&chksm=1b17d8daca19c8a48d4c819d8e0c811c21ad2abc912dba44dd35fc6832cb90a089c6e32509ef&scene=27#wechat_redirect)

据西班牙国家警察官网的一份新闻稿，警方逮捕了一名19岁的黑客，该黑客被指控参与了一系列高调且危险的网络攻击，对西班牙国家安全构成了严重威胁。  

  

该黑客名为José Luis Huertas（化名“Alcaseca”、“Mango”等），虽然只有19岁，但根据调查，他在网络犯罪领域拥有相当丰富的经验，被认为是该国最危险、最难以捉摸的黑客之一。

  

西班牙警方称，调查始于去年11月，当时发生了一起针对西班牙国家司法委员会（CGPJ）的网络攻击，该次攻击还影响到其他数个公共机构（其中包括国家税务管理局），最终导致57.5万西班牙公民的个人数据、账户号码、银行余额以及其他敏感信息泄露。经过复杂的调查，警方确认José Luis Huertas就是该起事件的幕后黑手。

  

该起事件只是José Luis Huertas所进行过的多起高调网络攻击之一。此外，他还被指控运营了一个名为Udyat的平台，该平台用于向第三方出售盗窃数据。警方称，José Luis Huertas在一次次成功实施攻击后变得愈加大胆，他甚至在YouTube上声称，他能够访问大约90%的西班牙公民的信息。

  

![](../Images/d5d2ee6c3698a6eb202378f1728e66e5.png)

  

要追踪到José Luis Huertas并不容易，José Luis Huertas通过加密货币混合服务来掩盖他的收益与资金流向，该服务将数字货币汇集在一起并重新分配，使得调查人员很难将资金与接收者联系起来。

  

最后西班牙警方是在国家密码中心专家的帮助下，通过跟踪“Udyat”服务器的托管服务的资金流向，才锁定了该犯罪嫌疑人。警方表示，José Luis Huertas过着与他的年龄及无职业活动所不相称的奢华生活，他进行了昂贵的旅行，身穿名牌，经常去时尚的休闲和餐厅场所，甚至还开着豪车。

  

据悉，José Luis Huertas将一直被拘留到审判的日期，因为调查人员认为他存在相当大的逃跑、销毁证据并继续犯罪的风险。法官表示，拘留决定是鉴于嫌疑人拥有大量加密货币，能够让他在世界任何地方居住，并逃避西班牙司法追诉。
