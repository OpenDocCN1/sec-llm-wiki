**【帕特里克·沙纳汉将出任美国国防部长】**

帕特里克·沙纳汉将于1月1日出任美国国防部长，提前两个月接替即将离任的五角大楼主席吉姆·马蒂斯。虽然尚不清楚沙纳罕将任职多久，但他可能位列五角大楼全职负责人的官员名单中。

  

2018年9月19日，沙纳汉在空军协会的一次会议上说：“我非常坚信，第一和第二层领导层有责任管理供应链。”“我们将与我们的工业伙伴一起，利用我们所掌握的每个工具，结束知识产权、技术和数据对国家安全至关重要的损失，”随后，沙纳汉被派去负责五角大楼的一个新的特别工作组，主要负责国防公司的数据外泄。同时，沙纳汉也强调了智能IT收购的必要性，他对五角大楼的采购过程表示失望，他表示，我们要集中在“正确的平台和正确的集成水平”，支持高端计算和人工智能。

**数据泄露**

  

**【网传超过 400 万 12306 用户数据现身暗网，中国铁路官方已辟谣】**

  

28日，有网友爆料，60万个12306账号和410万条联系人数据在暗网低价出售。根据帖子内容，这份数据包括60万账户信息，详细到除了ID、手机号、密码之外，连姓名、身份证、邮箱、问题及答案竟然都有，根据安全问题很可能能够直接申诉获取其它平台账户的重要信息。此外，还包括每个账户中添加的联系人信息，设计姓名及身份证号，这些联系人数据总量高达410万。帖子中还给出了50条随机数据的全部信息。根据爆料者透露，这些账户数据经过验证基本是真实。

  

![](../Images/222253a638fd0b173170e42aa5bb33d1.png)

  

针对此事，28日傍晚6点左右，中国铁路总公司官方微博账号“@中国铁路”回应，“网传信息不实，铁路12306网站未发生用户信息泄漏。铁路部门提醒广大旅客，请通过铁路12306官方网站（www.12306.cn）和“铁路12306”客户端购票，避免非正常渠道购票带来的风险”。

**黑客事件**

  

**【为绕过安全系统，黑客在谷歌云存储上托管恶意程序的实体】**

据E安全报道，网络犯罪分子通过滥用谷歌合法云存储服务托管恶意程序的实体，并通过绕过安全控制破坏企业网络。该攻击是攻击者针对谷歌云存储服务域storage.googleapis.com发起的，而全球多家公司使用的都是该服务域。 自八月起，该活动主要针对银行的员工及位于美国及英国的金融服务公司。 该攻击起初是通过大规模电邮方式分发的，电邮中包含指向由谷歌云服务托管的恶意网站的钓鱼链接。

  

研究人员经分析发现，有4,600个网络钓鱼网站使用了合法托管服务，也可称为“名誉联网”，该方法可借知名的流行托管服务来躲避检测。 鉴于电邮安全系统可检测恶意附件，攻击者并未使用恶意附件，相反，他们使用电子邮件中的恶意链接以绕过电邮安全系统。

  

仅有已存在于威胁存储库的恶意URL才可能被识别出来，而鉴于攻击者会不断改变托管域的负载，这种情况并不常见。

**【黑客攻击 Electrum 钱包窃取到 200 多比特币】**

近日，有黑客或黑客组织通过攻击 Electrum 比特币钱包的基础设施窃取到了 200 多比特币，价值大约 75 万美元。攻击者针对的是 Electrum 钱包应用的弱点，Electrum 钱包网络可以加入服务器，而服务器可以对钱包应用弹出警告信息。攻击始于 12 月 21 日，在 GitHub 移除恶意库之后停止。由于漏洞尚未修复 Electrum 警告类似的攻击可能会再次发生。

**【十年数据泄露事件大观：“互联网+”时代，各行各业都易中招】**

大数据时代，数据不仅是企业的核心财产，也事关用户最关心的隐私安全。然而，数国内外大规模数据泄露事件密集发生。澎湃新闻梳理了近十年来有关企业数据泄露的报道后发现，中招的不仅仅是互联网公司，数据泄露的主要原因是恶意和犯罪攻击（48%）；面对数据泄露，多数企业反应迟钝；平均来看，泄露百万条记录会导致损失2.8亿人民币，而泄露5000万条记录的损失高达24.1亿人民币。

**【深入 Exchange Server 在网络渗透下的利用方法】**

Windows Exchange Server是国内外应用都非常广泛的邮件服务器，斗象能力中心 TCC – Cody围绕Exchange展开，介绍在渗透测试中对Exchange服务器的攻击利用。在渗透测试中，往往会遇到企业内网环境中使用的一些常用组件，这些组件对内或对外提供服务与接口，也给渗透测试人员与黑客提供了新的可尝试的攻击面，以帮助渗透测试人员完成信息收集、环境侦测，甚至通过其漏洞弱点、配置缺陷、功能滥用直接拿下权限，在渗透测试与后渗透阶段达到事半功倍的效果。

 

邮件通信是企业正常运转过程中进行沟通交流与信息传递的重要载体，因此，邮件服务涉及的相关基础设施的安全也变得至关重要，攻击者突破网络边界取得权限，其目的之一是窃取关键数据，也正因如此，邮件组件服务成了黑客攻击过程中极受重视的一环。
