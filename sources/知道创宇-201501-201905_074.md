# FP50横空出世，你可知安全行业的未来会变得怎样？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649841219&idx=1&sn=4a8ed940f2d1b396cfb95a32171ab015&chksm=beda884889ad015e53a3a9bffff1fab3d2aa2c1be44a95f84d24632f76dcc37c024068f088cd&scene=126&sessionid=1681377044#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649841219&idx=1&sn=4a8ed940f2d1b396cfb95a32171ab015&chksm=beda884889ad015e53a3a9bffff1fab3d2aa2c1be44a95f84d24632f76dcc37c024068f088cd&scene=126&sessionid=1681377044#rd)

**2018年8月28日，一场安全界首创的奥斯卡颁奖礼——Future Power 50安全新锐力量分论坛（简称FP50）成功举办，**这场由知道创宇和腾讯安全于第四届互联网安全领袖峰会（简称CSS）上联合主办的创新活动，通过汇集重要行业权威专家的意见，发掘推选了30家代表安全行业未来发展的新锐企业，并共同成立了FP50安全新锐力量俱乐部。

 

![](../Images/81575148cfcc43c0fdd0f3745a79a7bb.png)

FP50安全新锐力量合影

  

到底什么是“FP50”？为什么要办这样的活动，甚至是给竞争对手捧场？FP50和行业中众多的排名评选有何不同，是怎么选出来的？也许，我们可以从主办单位知道创宇CEO赵伟的发言中寻找到答案。

  

FP 50 中FP的涵义是Future Power，代表未来的力量。网络安全行业的发展，已经进入崭新的阶段，无论是市场的变化，还是客户需求的变化，甚至是攻击者的变化，区块链等新兴技术的发展，都给安全行业带来非常颠覆的巨变。

 

![](../Images/8e6b65136d2e92b53fe54e42eb54f204.png)

知道创宇CEO赵伟开幕致辞

   

那我们如何面对未来的新的安全形势呢？赵伟认为，未来的安全是安全的生态，而不是一家独大对整个环境产生垄断和阻挠。传统安全企业并不能完全代言这个市场，当越来越多创新安全企业涌现出来，他们才极有可能成为未来行业的主导力量。知道创宇和腾讯安全也一直在探讨，怎么把安全行业做得更大，取得更良性的发展。因此，双方共同搭建了FP50这样一个平台，试图帮助行业发掘优秀的能够代表未来的新锐力量。

 

遗憾的是，安全领域创业公司在成长过程中会遇到很多问题。拿知道创宇11年的成长经历来说，首先，安全领域创业绝大多数是技术人员出身，搞技术的人都认为自己怀揣倚天剑、屠龙刀，能力所向披靡。但是市场却不认可，无龙可屠的时候，那种巨大的对自己的质疑和心理压力的痛苦，会让人产生摇摆和惶恐。

 

技术卖不出去，是不是应该招很多销售来呢？所以一般技术型安全创业公司又陷入了销售坑。然而，以客户关系为主的打法并不是安全行业的主战场，传统销售套路与手段对安全创业公司是极大的伤害，甚至会带着公司坠入难以爬出的深渊。

 

技术不被认可，销售卖不动货，公司活不下去了怎么办？寻找投资帮助自己。其实，资本也是跟风的，当资本不是这个行业的新知和主要成员时，往往也没有办法了解行业和未来面临的威胁。创业公司花了巨大的精力投融资，却被认为这个没有方向，那个没有未来，自我怀疑更强，压力更巨大。

   

当资本对接进来后，投资与团队之间的合作关系、博弈，作为一个初创公司是非常难搞定的。安全行业又是慢热型的，是属于向未来主导的行业，甚至需要政策主导，然而VC有回报的要求和退出的周期，这些冲突确实很难解决。

 

![](../Images/0a2003f393191e8b37d111507cb23c03.png)

  

这一个又一个的坑让我们发现，安全行业如果大家不联合起来，不产生行业内的共识，是很难发展下去，很难做大的。赵伟说道，“当然有的大型安全公司会认为，初创企业倒闭了刚好可以更便宜地获取人才，这是他们喜闻乐见的。但是对于我们来说，更希望有一个真正繁荣的、多层次的、多元的安全生态来保护咱们国家，没有互联网安全就没有国家安全。”   

   

如今，知道创宇在安全行业深耕了11年，不敢说做得多么成功，但是作为云防御的领头者和先行者，我们烧了很多钱，买了很多教训，我们想用实战的历练帮助大家走过这些痛苦的阶段，这也是我们一直以来在跟腾讯探讨的，如何把成长的经验反馈给社区，助力创建更强大的行业生态。

   

所以，知道创宇联合腾讯安全，借助CSS大会行业领导者的影响力，希望搭建一个与同行业交流，和真正的安全企业家沟通，和媒体沟通，和资本对接的平台，将大家的产品和理念秀出来，帮助大家获取更多的经验，少走弯路，少花冤枉钱，获得发展的助力。

 

![](../Images/328d3624de54e5b1809080ca61ea1bd4.png)

FP50 最强评委天团

  

为了保证真正优秀的企业能够脱颖而出，我们做了大量的调研工作，制定评选标准，邀请众多专业的行业专家参与评选，以确保结果的公正公开公平。FP50的评选有几个基本原则：  

 

**首先是宁缺毋滥。**筛选出的企业必须是代表真正未来安全新兴力量的，所以这次并没有选满50家，只敢把真正各方权威意见综合认为合格的推选出来，希望这些新锐企业是独角兽一样的存在，他们有独特的思想、技术和市场，咱们并肩一路同行才能把行业做大做强。

 

虽然很多报名的企业没有入围，这并不是因为大家不够优秀，而是虽然创业公司很多，但从市场、技术、影响力等多个维度来看，依然存在一些短板和进步的空间，FP50每年都会把更好、更优秀的企业都加入进来，也希望大家能够以入围的企业为榜样，继续加油。

 

**其次是不搞排名。**行业乱象众多，烧钱的地方尤其多，资金是创业公司发展道路上保命的资源，再花大量的资金去搞无意义的排名是浪费的。如今，安全行业正处于百花齐放的时代，安全产品、业务存在大量细分，所谓排名实际上并不能客观反映市场的现状，单纯的排名有失公允，因此FP50并不会对入围企业论资排辈。

 

**再次是不搞站队。**FP50的评选招募一直秉持着开放的心态，希望能够通过自身的努力和举办相关的行业活动，来帮助行业进步和发展。所以，我们从来不搞派别、不站队、不设特殊门槛，而且不论是腾讯还是知道创宇从来都认为，安全行业只有不断加强行业内的交流和合作，才能够对未来中国网络安全行业的发展起到帮助作用。

 

**最后，入围FP50只是对企业当前状态的认可，这不是自我标榜而是对企业的鞭策和对行业的激励。**FP50每年会加入更优秀的竞争者，变成一种良性的竞争，而不是靠市场运作来哄抬自己，不拿出真正为客户服务和保证客户安全的安全公司才是在耍流氓。

  

![](../Images/39e62855c490310e9d0592998e1e5a91.png)

  

FP50的愿景，是安全行业不光有竞争，更应该良性发展。创业企业生存并不乐观，大家看到这个行业看上去非常好，但叫好不叫座，生存是很难的。但同时，安全行业的未来是大有可为的，是前途光明的，因此我们需要不断努力，需要大家多多合作，抱团取暖，资源共享，然后共同进步，为中国网络安全事业贡献力量！
