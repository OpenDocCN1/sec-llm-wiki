# 新时代威胁下的态势感知AI应用创新

6月23日，首届县域网络安全工作创新论坛在京召开，会议核心围绕基层等保工作新局面开展集中讨论，会议由公安部网络安全保卫局指导，公安部第三研究所主办，部分省市区基层网络安全负责同志出席会议。应主办方邀请，北京知道创宇信息技术有限公司解决方案中心负责人陈庆带来《新时代威胁下的态势感知AI应用创新》主题演讲，为新时代信息安全建设献言献策。

知道创宇出席首届县域网络安全工作创新论坛发表演讲

 

勒索病毒爆发性增长，漏洞威胁呈上升势头；反网络黑产诈骗初具成效，网络传销形势依旧严峻；数据加密货币引发网络安全新问题；网络攻击加剧企业安全危机；单月Web攻击次数突破20亿；80%境外攻击来自于美国和法国；新兴业务类型更易遭受威胁。来自于腾讯安全和知道创宇的2017年相关安全报告内的核心内容在演讲中最先被提及，也反映了新时代安全威胁正在发生着以往不同的变化。

 

据主持人严明主任介绍，在相应的安全建设方面，**知道创宇是国内很早建设态势感知体系的网络安全厂商，**在全新时代下，等级保护升级2.0之后，态势感知也需要增加大量的技术予以辅助应对，其中最主要的就是基于AI的技术应用创新。

  

据了解，这种AI技术的应用，全面应用到了知道创宇态势感知体系中的远程监测、流量检测、主动防御当中，分别对应创新型数字加密网络安全情报监测、基于图谱的人工智能威胁检测、基于大数据的主动云防御能力。

 

数字加密网络已经成为新型犯罪生态链中的重要一环，因此对于其中威胁信息的捕获已变的尤为重要。在创新型安全情报监测方面，据陈庆介绍，知道创宇已推出相应的监控系统，该系统以威胁情报线索挖掘为导向，辅以人工智能大数据分析系统进行全面采集、发现、整理，并予以直观可视化展示。

 

在基于图谱的人工智能威胁检测方面，基于AI深度学习技术贯穿始终，对流量、代码进行深度对比检测，从而学习已知威胁，预测未知威胁。**据了解，在知道创宇态势感知2.0体系中，云图大数据威胁检测系统就利用此技术，目前其有效性已被多个行业认可，被应用于高价值机构的APT高级威胁防范。**

 

**而基于大数据的主动云防御，则是知道创宇的看家本领。**2011年知道创宇打造云防御平台，目前已有近7年运营经验，防御用户总量百万有余，期间取得了海量的攻击日志、及访问日志数据，再会同知道创宇长期积累的全球黑客指纹、42亿IP信息资产库等，以及生态伙伴的安全大数据，通过具有深度学习能力的人工智能大数据分析系统，对攻击源及攻击手法进行画像提取，形成了独有的高纵深的防御规则体系。在等级保护2.0体系当中，知道创宇云防御的高可靠性，也势必会大有作为。

 “新时代的网络犯罪呈现出技术应用的井喷现象，为了有效应对，既要加强管理平台建设也要加强情报和技术能力；AI并不能完全替代传统检测分析方式，而是传统方式的补充和能力提升；为了更好的提升情报质量和工作效率，下一步要大力提升态势感知分析中的人工智能AI计算的可靠性和可解读性。” 陈庆在演讲中最后总结道。
