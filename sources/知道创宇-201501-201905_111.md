# 创宇盾——大数据背景下政务网站防御新利器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649839201&idx=2&sn=2c4d90cbc43b2092a7a65907249350e8&chksm=beda806a89ad097cca5d906fcd47383b52ceeafc8d7c25d7442a24dcf5313abffee2ed2e6ae9&scene=126&sessionid=1681377064#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649839201&idx=2&sn=2c4d90cbc43b2092a7a65907249350e8&chksm=beda806a89ad097cca5d906fcd47383b52ceeafc8d7c25d7442a24dcf5313abffee2ed2e6ae9&scene=126&sessionid=1681377064#rd)

2017年7月27日，为贯彻落实习近平总书记等中央领导同志重要指示批示精神，全面学习实施《网络安全法》规定相关要求，深入实施网络安全等级保护制度，安徽省芜湖市公安局举办了全市网络安全培训班，对政府、事业单位、重要企业、金融电信、县区政府、在芜高校等部门相关人员进行了“云聚安全”网络安全培训。知道创宇作为芜湖市公安局网络安全保卫支队的技术支撑单位受邀给各参会人员进行培训。

![](../Images/1755db4828cc89f34cc154dfb8739a51.png)

培训会上，知道创宇华中分区技术总监、安全专家方超分享了在大数据背景下对网络安全整体情况，并对安徽省政企网站安全现状进行了分析，提出了有效的解决方案和建议。

![](../Images/5e2f9d184f674ecfbdc7b8897c0f8613.png)

 方超表示，今年以来，特别是网络安全法实施以来，国家对网络安全高度重视，开展了IDC检查等一系列活动，并立法对相关网络安全责任进行落实。国家高度重视的同时，安全形势却不容乐观，一方面是政企网站本身存有大量的安全问题，另一方面是部分黑客、特别是境外恶意黑客的来势汹汹，其中政府网站成为他们的主要攻击对象。

![](../Images/d8ebdb212633d60d58bf1fddd3529c84.png)

 针对当前，特别是安徽本地政企网站现有问题，方超提出：“**改变原有防御思路，用新武器直面对抗**”。

 政企网站传统的防御方式是被动防御，利用防火墙将重要资产进行隔离，但在面对未知的高级可持续攻击时较为脆弱，容易暴露防御能力。而知道创宇旗下产品“**创宇盾**”采取了新型“塔防式”防御方式，通过层层部署，增加攻击成本等方式，真正达到对网站的有效保护。

![](../Images/4f86913d0083e21f88c27b9c7d40b7ab.png)

  

不管是为公安部抵御日均十几万次以上的恶意扫描、SQL注入攻击等多种网络攻击，还是提前预知并防御华中地区大规模漏洞危机，创宇盾用一个个鲜活的数据展示着强大的网络安全能力。
