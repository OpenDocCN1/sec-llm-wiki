# 创宇盾防御网站无需升级即可抵御Jenkins 反序列漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649838956&idx=1&sn=088d27f2e7f306ab0ab77df2d4e2bd83&chksm=beda836789ad0a71d21556ed3865be9fced3f9b53ef28e4af1946e899a525275b90832a480a4&scene=126&sessionid=1681377074#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649838956&idx=1&sn=088d27f2e7f306ab0ab77df2d4e2bd83&chksm=beda836789ad0a71d21556ed3865be9fced3f9b53ef28e4af1946e899a525275b90832a480a4&scene=126&sessionid=1681377074#rd)

CloudBees Jenkins 是美国 CloudBees 公司一款基于 Java 开发的，开源、可持续集成的自动化服务器，它主要用于监控持续的软件版本发布/测试项目和一些定时执行的任务。LTS（Long-Term Support）是 CloudBees Jenkins 的一个长期支持版本。

![](../Images/c865b89505a61e4d9488938371e0ff0c.png)

CloudBees Jenkins 2.56 及之前的版本和 Jenkins LTS 2.46.1 及之前的版本近日被曝存在远程代码执行漏洞，正式编号为 CVE-2017-1000353。攻击者可将序列化的 Java SignedObject 对象传输到基于 remoting 的 Jenkins CLI，使用新的反序列化 ObjectInputStream 绕过现有的基于黑名单的保护机制。

经知道创宇 404 实验室复现确认属高危漏洞，可使攻击者远程越权执行代码，相关用户应尽快完成升级修复工作，或推荐使用第三方防火墙安全产品进行防护。目前知道创宇云防御下属“创宇盾”用户无需升级即可对该漏洞进行妥善防护。

如您是 CloudBees Jenkins 的使用者，如不便确认版本是否含有该漏洞，可自行前往使用 Seebug 漏洞社区照妖镜在线检索工具，目前 Seebug 照妖镜已更新了 CVE-2017-1000353 的自检功能。
