# IIS最新漏洞影响全球10万主机 创宇盾将提供妥善防护

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649838868&idx=2&sn=fcbe00ca1239403c8d767f27ddd5c936&chksm=beda831f89ad0a0907f7a176998212dc5a4a32f1983644955ba0222fc49e324ff85a90562353&scene=126&sessionid=1681377079#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649838868&idx=2&sn=fcbe00ca1239403c8d767f27ddd5c936&chksm=beda831f89ad0a0907f7a176998212dc5a4a32f1983644955ba0222fc49e324ff85a90562353&scene=126&sessionid=1681377079#rd)

   

漏洞概述

开启WebDAV服务的IIS 6.0被爆存在缓存区溢出漏洞导致远程代码执行，在WebDAV服务的ScStoragePathFromUrl函数存在缓存区溢出漏洞，攻击者通过一个以“If: <http://” 开始的较长header头的 PROPFIND 请求执行任意代码。目前针对 Windows Server 2003 R2 可以稳定利用，该漏洞最早在2016年7,8月份就已经开始在外面被利用。

   

漏洞复现

1 验证环境

Windows Server 2003 R2 With SP2开启WebDAV服务的IIS6.0

漏洞原理

通过构造特殊的PROFIND请求，并且 HEADER 头信息带有“If<http://”字样构造出相关利用程序，可以造成目标主机的缓冲区溢出。成功通过两次溢出就可以在目标主机上执行代码，利用失败的时候也有一定几率造成目标主机的拒绝服务。

**更详细的漏洞分析请查看Seebug Paper上的漏洞分析报告点击阅读原文**

深入探测可能存在漏洞的风险设备

**1 探测方案**

为了探测该漏洞，我们必须先进行WebDav的探测，我们采用网上流行的方法：对服务器发送OPTION包。

![](../Images/ea169f3161d27824f46dc5474c5c066b.png)

一般说来，当ALLOW中包含如上方法时，可以确定服务器开启了WebDAV。

在ZoomEye进行的深度探测时，还会对报文中是否包含“IIS”“ MS-Author-Via”“DAV”等关键词进行识别，经过综合分析来探测目标主机是否存在该漏洞风险。

**2 详细探测结果**

在漏洞爆发后，404团队迅速响应，优化了IIS相关组件的识别探针和解析规则。并且在3月28日针对全球互联网设备迅速进行了探测。探测发现全球仍然存在226万目标组件中，仍然存在十多万组件(103431个)存在该漏洞风险。

2.1 地域分布

针对这十万数据，ZoomEye团队确认了ip的归属地。统计结果发现，数量最多的五个地区分别为：美国(36321)、中国(30285)、中国台湾(2663)、中国香港(2583)、韩国(2485)。下图是全球数量最多的二十个国家与地区：

![](../Images/98e0b8561d3a8afbdbffc7be9c44adfc.png)

在中国境内，风险服务器统计结果数据量最高的几个省份为浙江(3712)、广东(3550)、北京(3409)、江苏(2728)和上海(1958)。

![](../Images/7c6f356408755f9310cabb00a56db6f0.png)

2.2 端口分布统计

在探测中发现，这十多万的含有风险的IIS组件开放在不同的端口上。根据统计，风险设备开发的端口共有273种。而其中数据量最高的是80端口。在80端口上有75565个组件存在漏洞风险，占据全部端口的75%。因为80端口的数量远远超出其他端口，为了视觉效果不突兀，下图展示了除了80端口以外，使用量较多的端口：

![](../Images/6575341837c016195d328085c49b05e2.png)

2.3 主机状态统计

这十万设备中，有8272台主机开放了多个端口，运行多个有风险的IIS服务，其中最多的一台主机开放了248个端口，经查这台主机位于江苏南京。同时拥有这么多有漏洞的IIS服务，其主机安全令人担忧。有9个主机上开放了超过100个风险服务，有27台主机开放了超过10个风险服务。

2.4 主机使用的运营商统计

针对国内的风险设备，我们尝试着获取了一下其ip所在的运营商。发现数量最多的标示为为“China Telecom”(中国电信)，其数量为10740个，占全部数据量的10.4%。排名第二位的是 “China Unicom Liaoning”(中国联通辽宁),数量为4125个。排名第三位的是“Aliyun Computing Co.”(阿里云计算)，其数量为1746。下图是排名前16位的运营商关键字统计图：(没有展示第一名中国电信)

![](../Images/232c353b07dd83d6fb53893cf8b37925.png)

**3 结论**

从上述统计数据中可以看出，风险设备的分布与经济的发展状况是正相关的。从数量上看，我们国家的设备数量已经处于世界较高水平，其风险设备也是数一数二的。发展的足够快，但是安全能力并没有跟上，这将在未来留下很大的隐患。与大陆城市进行比较，中国台湾和中国香港地区的服务器数量排名在五六名，已经不是像往常一样占据Top3的位置了。

另外，有一些主机上运行了几十甚至上百个服务，这些服务开放的端口全部都可以被利用，而该IIS漏洞所造成的危害是远程代码执行，一旦一个点被攻破，所有的服务全部都可以被拿下，其主机的风险极大。在我们日常使用中，尽量做好隔离，避免这样一机多用的情况发生。

   

**临时解决方案**

1.关闭WebDAV服务。

2.使用第三方防火墙进行防护(如创宇盾)。
