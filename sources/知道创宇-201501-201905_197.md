# 知道创宇将再次参与『世界互联网大会』网络安全保障工作

第三届“世界互联网大会·乌镇峰会”将于2016年11月16日至18日在浙江省乌镇举行，我国对此次大会高度重视，中共中央总书记、中国国家主席习近平将以视频方式发表重要讲话。中共中央政治局常委、中央书记处书记刘云山将出席大会，并发表致辞。大会由中国国家互联网信息办公室和浙江省人民政府联合主办，目前，大会各项筹备工作已就绪。

 

**因为对网络安全业界的长期卓越贡献，知道创宇CEO赵伟再次受邀出席世界互联网大会，并将参加随后的网络安全闭门会议。同时，知道创宇作为我国一线网络安全企业，也将继续发扬“侠之大者，为国为民”企业核心发展理念，利用领先的网络安全能力，全力保障世界互联网大会的顺利举办。**

 

本届世界互联网大会的网络安全保障工作方面，知道创宇将主要承担会议举办地桐乡市政府企事业单位网站，以及浙江省政府重点网站，浙江省公安厅及部分企事业单位网站的安全防护工作。

 

值得一提的是，因在第二届世界互联网大会上知道创宇所表现出的万无一失的安全保障能力，在第三界大会筹备前期，知道创宇再次被给予厚望，今年由知道创宇所提供安全防护的网站数量再创新高。

 

**知道创宇旗下“创宇盾”云安全防御平台将主要完成本次重大会议的网络安全保障工作，相关网站目前已全部接入“创宇盾”获得了顶级安全防御能力，全面抵御骇客各类入侵、破坏行为。****在获得顶级安全防御的同时，洞悉区域网络空间的“创宇星图态势感知系统”也同步启用，在这一防护体系中，我们以上帝视角洞悉一切黑客攻击行为和潜在威胁。**

 

知道创宇高度重视第三届世界互联网大会网络安全保障工作，除了部署安全防护产品之外，目前技术专家团队也已奔赴到大会举办地参与现场网络安全保障驻守，配合网络安全保障部门随时应对突发情况；同时，知道创宇后方技术专家团队也同步开启执行7\*24H人员值守监测防护工作，予以远程协助支持。

 

知道创宇是一家高度重视社会责任感的高新技术安全企业，在国家网信主管部门的带领下，积极参与支撑和保障我国重大活动及会议的网络安全。本次第三届世界互联网大会的网络安全保障工作也将是知道创宇今年继两会、C20、数博会、G20、国家网络安全周、敦煌文博会之后，再次义务承担国家级重大活动、会议的网络安全保障工作。
