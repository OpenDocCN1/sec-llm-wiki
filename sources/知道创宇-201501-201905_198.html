CSS 2016知道创宇反信息欺诈解决方案受关注

2016年11月9日，为期两天的CSS（Cyber Security Summit）2016年第二届中国互联网安全领袖峰会在京隆重开幕，峰会由腾讯、中国电子技术标准化研究院等企事业单位共同创办，得到了国家网信办、工信部、公安部等监管部门的大力支持。本次峰会主题为“智慧安全，连接赋能”。大会聚焦十大热门产业的安全趋势与应对方案，总参会规模超过20000人次，全球范围与会企业超过500家，权威媒体关注超过150家，可谓规模宏大的一届盛会。
本届峰会在分会场的设置上也颇为用心，不仅仅在物联网技术得到极大发展的情况下，新增了人工智能与网络安全分会场。更值得关注的是，近年来信息诈骗、网络诈骗层出不穷，给老百姓带来了巨大的经济损失，而这些问题急需全社会的关注与解决，在这个大背景下特别设置的“大数据运用安全分会场”，对打击防范诈骗行为、守护全民财产安全等话题展开讨论。
作为在云安全大数据领域的代表性安全企业，知道创宇受邀在11月10日“大数据运用安全分会场”发表专题演讲，分享利用安全大数据协助警方有效防范打击信息欺诈的经典案例。
▲知道创宇王锋在CSS大会发表演讲
知道创宇反通讯欺诈产品总监王锋的演讲分享了腾讯&知道创宇反电信诈骗方案具体实施过程中积累的经验，据介绍，该平台已经在无锡市得到落地部署，技术上实现了以“云、管、端”交错结合对无锡市民提供基于虚假、恶意网址的欺诈拦截、预警工作。

在演讲中王锋指出，在整个“反通信欺诈管制系统”的技术架构中，知道创宇跟运营商进行了深入的合作，以达到实时拦截的目的。在具体试点过程中，不断攻克各类难题，因为无法使用综合网关系统，知道创宇联合江苏电信使用DPI的重定向系统，经过测试与试验，达到了90%的拦截率；知道创宇也在大力研发互联网出口处的智能路由技术，结合检测结果进行页面跳转，这也能对诈骗网站进行有效的拦截。

在网址的检测方面，王锋介绍道“‘反通讯欺诈管制系统’平台功能的最大亮点是腾讯&知道创宇的安全大数据能力。一方面由腾讯安全云库源源不断同步最新的恶意网址数据资源，另一方面基于知道创宇具有的国内优秀的大数据动态捕获能力对恶意网址和手机木马进行智能检测，不断将检测结果推入本地私有云中，知道创宇将这些结果与运营商的数据通过大数据分析进行检测匹配，可识别用户无意中访问的恶意网址，访问页面会自动跳转至风险提示页面，对诈骗分子的诈骗通道实施有效拦截。而且在这一系列过程中，不会用到任何的用户信息，保证用户个人隐私的安全。”

随后，王锋对案例成果做了介绍：“该系统在平台试运行以来，在打击网络信息欺诈方面取得了卓越的成绩，平台日均拦截诈骗网址60万次，拦截成功率达98%以上，准确率达到99%以上。整个江苏省十月份涉及恶意网址的电信诈骗降低了47%，其中无锡市电信诈骗的同比减少了88%，反诈骗系统平台取得了很好的效果。而知道创宇配合自有大数据分析能力，识别出不同类型的诈骗，对来自于仿冒银行与伪基站的诈骗信息拦截率达到了98%，而这些，对网络诈骗的侦破具有很大的帮助。

王锋表示，CSS 中国互联网安全领袖峰会一直强调安全生态要多方联合，而“反通讯欺诈管制系统”成功落地无锡，就是在无锡公安的统筹下，知道创宇负责具体实施，联合腾讯、无锡电信多方共同参与的一次警方与企业联动合作打击电信网络欺诈的一个典范之作。
王锋最后表示，知道创宇在反电信诈骗的路上还有很长的路要走，而无锡平台的成功，更坚定了知道创宇为网民提供更安全的网络信息保障的决心，知道创宇也会针对各地运营商的具体条件，做出针对性的方案。目前，腾讯正携手知道创宇与各地警方、运营商等合作伙伴合作，提升在反信息欺诈领域的战果。
