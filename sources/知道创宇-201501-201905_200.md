# 知道创宇邀您相约CSS 2016中国互联网安全领袖峰会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649838302&idx=1&sn=599bb7a02228a714ae2b6eb155460175&chksm=beda84d589ad0dc3b432bca8201a2ef204270b99a8400c834837988b9bfe83cff54312b0c212&scene=126&sessionid=1681377100#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649838302&idx=1&sn=599bb7a02228a714ae2b6eb155460175&chksm=beda84d589ad0dc3b432bca8201a2ef204270b99a8400c834837988b9bfe83cff54312b0c212&scene=126&sessionid=1681377100#rd)

由腾讯公司主办的CSS（Cyber Security Summit）2016中国互联网安全领袖峰会将于11月9日召开，这也将是CSS安全领袖峰会举办的第二届。今年，为顺应全球化背景下的产业领域的安全交流，第二届CSS安全领袖峰会将议题定为“智慧安全，连接赋能”，重点探讨如何加速构建安全生态，会议将邀请微软、高通、谷歌、思科、英特尔、McAfee、等国际知名企业参会。![](../Images/9762b22e4cca2ff4a5b393ff53f0fc84.png)▲知道创宇CEO赵伟（左一）受聘为中国互联网安全领袖峰会“专家智库”知道创宇作为中国很有安全实力的安全公司，受邀全面参与第二届CSS安全领袖峰会。早在半年前，知道创宇CEO赵伟就被聘为中国互联网安全领袖峰会“专家智库”，并在随后的智库专家沙龙当中，发表专业观点积极参与新一届CSS安全领袖峰会的会前各项决策。![](../Images/703cb5d60c9bcc9e3923109747cae94f.png)▲知道创宇CEO赵伟、COO兼CTO杨冀龙还共同CSS行业沙龙而后，知道创宇CEO赵伟、COO兼CTO杨冀龙还共同受腾讯邀请，出席CSS安全领袖峰会开设的首期“产业安全沙龙”，与腾讯公司副总裁马斌，以及各大金融行业高管共同讨论聚焦金融安全领域应重点关注的方方面面，为新一届CSS安全领袖峰会聚焦热点话题出谋划策。

而在CSS安全领袖峰会举办期间，知道创宇也将会有安全专家登上大会演讲台，发表技术演讲，推进安全产业进一步发展。新一届CSS安全领袖峰会相比去年在内容上多出人工智能、反欺诈等热点关键词，知道创宇安全专家就将受邀于“大数据运用安全分会场”讲解大数据打击电信网络欺诈技术。

同时，在会场外，知道创宇还设有展位（展位编号A4）将展出知道创宇的核心安全能力，敬请关注！
