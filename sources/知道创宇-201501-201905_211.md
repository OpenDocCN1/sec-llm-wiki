# 知道创宇加入W3C 将积极推动Web安全技术发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649838061&idx=1&sn=d0aab19c972ed6b238849ee85939f1cd&chksm=beda87e689ad0ef0ab324b4762724d68f78ed6a7a39cae2aff490d48dad24edc2f9cc81f1537&scene=126&sessionid=1681377110#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649838061&idx=1&sn=d0aab19c972ed6b238849ee85939f1cd&chksm=beda87e689ad0ef0ab324b4762724d68f78ed6a7a39cae2aff490d48dad24edc2f9cc81f1537&scene=126&sessionid=1681377110#rd)

8月11日，知道创宇宣布正式加入 W3C（World Wide Web Consortium、万维网联盟：http://www.w3.org)。W3C是国际最著名的标准化组织，1994年成立后，至今已发布近百项相关万维网的标准，对万维网发展做出了杰出的贡献。W3C 目前拥有来自全世界40个国家的400多个会员组织。![](../Images/5238a5cc7bcd651d7d10c3b35eae64a6.png)W3C 最重要的工作是发展 Web 规范（称为推荐，Recommendations），这些规范描述了 Web 的通信协议和其他的构建模块。每项 W3C 推荐的发展是通过由会员和受邀专家组成的工作组来完成的。W3C 主导的全球标准化工作已经深远影响着我们当下这个世界，Web 早已不仅应用于互联网，现今社会在物联网领域，也有越来越多的智能化管控设备采用 Web 技术作为交互方式，这也让 W3C 的 Web 标准制定从互联网延伸至更为宽广的领域，肩负的责任也更加重大。而在 W3C 将知道创宇纳入成为会员之后，W3C 中国区会员名单中也首次拥有专注于网络安全企业的加入，知道创宇作为一家专业网络安全公司，全部业务均围绕网络安全展开，今后，知道创宇将与腾讯、华为、阿里巴巴等 W3C 中国区会员一道，共同推动全球 Web 技术发展。知道创宇公司技术负责人表示，在成为 W3C 的会员单位之后，知道创宇将把 Web 业务安全的标准化工作作为重点，同时将积极参与物联网相关安全标准工作中。
