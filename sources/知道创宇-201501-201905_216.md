**CSS 2016金融安全产业沙龙****         连接赋能开启智慧安全模式        **

6月24日，中国互联网安全领袖峰会开设的“产业安全沙龙”在京召开，首期产业安全沙龙聚焦金融安全领域，主题为“连接安全为互联网金融赋能”。腾讯副总裁马斌、腾讯互联网犯罪研究中心主任朱劲松、腾讯财付通金融安全技术负责人李鸿、中国金融认证中心信息安全实验室主任高志民、知道创宇CEO赵伟、知道创宇CTO杨冀龙等数十名来自银行、金融企业、安全厂商的跨界精英出席了本次沙龙会议，并根据时下互联网金融产业安全的热点问题进行了深度的讨论与研究。

![](../Images/9054ace5e8f0b7a7809f8f3586fed75f.png)▲来自银行、证券、消费金融、互联网及安全行业等近30位嘉宾合影**互联网金融早已成为经济发展的潮流网络安全成为重中之重**“互联网+金融”在大数据环境下飞速发展，并被赋予了各种各样的形态。然而伴随其成本低、效率高、覆盖广、发展快等特点，网络金融诈骗、手机扫码诈骗、移动支付漏洞等事件在近年不断将互联网金融风控弱、缺乏监管和法律约束的、网络安全技术能力不足等问题暴露出来，当前资金安全与信息安全岌岌可危。 前段时间，中国人民银行金融所所长姚余栋曾在演讲中表示：“互联网金融一共有4个目标—共享、创新、风险、安全。当前，互联网金融已成为不可阻挡的发展潮流，因此我们对风险的把控要跟上，网络安全亦要随之跟上。”本期沙龙会议上腾讯副总裁马斌也表示：安全作为43万亿金融市场的地基，不容小觑。互联网新时代下，社会各界需要实现业务创新、技术创新，并不断将安全进行可视化，加强人们对安全的认知与重视，从专业层面和大众层面构建立体化的互联网安全生态，有效保障互联网金融产业的稳定发展。![](../Images/3eb63ff0d5a4106fa65f33b4839f813b.png)▲腾讯副总裁马斌**首期CSS产业安全沙龙聚焦金融安全汇聚跨界专家齐赋能**本次互联网金融安全沙龙由CSS中国互联网安全领袖峰会(Cyber Security Summit，简称CSS)发起，得到了CFCA、知道创宇等多家机构支持，聚集了来自金融行业、互联网行业、安全行业等多方精英，旨在为金融产业安全跨界提供交流平台。 腾讯副总裁马斌在沙龙会议开始时表示：“安全和金融的融合是在整个移动互联网大背景下所做的一个非常重要的板块。如何让安全和金融，技术业务更好地服务从业人员，服务大众，服务组织，服务政府，服务国家，是我们共同努力的目标。”![](../Images/9a29c31ee40e3c045b455a09992f2ef8.png)▲知道创宇CEO 赵伟![](../Images/0060298359f5b36c315cb6a4976aed97.png)▲知道创宇CTO 杨冀龙  

目前在金融体系里，用户所感觉到的所有内容的闭环在于支付，所以移动支付安全是我们现在每个用户感知度最强的地方。来自知道创宇CTO杨冀龙讲述了自身多年与信息诈骗黑色产业链的斗争经历，并表示：目前电信诈骗黑产已经从个人上升到了黑产集团犯罪，因此我们更需要跨界升级，把的更多的安全技术用到现在的应用中。建立打击黑产的“特种部队”，从而守护互联网金融安全的稳定。 

金汇金融的冉启兵也在会上讲到：面对各类互联网金融领域的问题，我们只有在信息安全、帐户封闭运行、资产三个端上都对安全进行关注，互联网安全才可以健康稳健的发展。![](../Images/e2ceedf395a816ef27fb12bd080d48de.png)▲人民银行信息中心安全部部长袁慧萍（左）、腾讯互联网犯罪研究中心秘书长朱劲松（右）来自人民银行的袁慧萍在会上发言时表示：安全和防护系统需要融合，有机地融合，按照人脑合理的思路去融合。当安全问题来临时，我们应该呼吁安全所有的从业者，我们是生态链接的一分子，应该协同推进。新时代下只有开放共享，共同承担风险，才能保障互联网金融安全的发展。其他来自政府、银行、公安、安全企业的数十名金融、安全方面的专家，也分别根据当前新时代下互联网金融安全热点问题，从互联网金融安全标准化，互联网金融安全技术融合、保障体系建设与监管立法等多个维度，全方位的进行了探讨。力求不断深化互联网金融跨界合作，整合资源与信息，连接赋能互联网金融产业，保证经济健康、快速发展。 随着首期产业安全沙龙的落幕，CSS作为安全新生态首创平台，在今年下半年还将聚焦智能汽车、物联网、人工智能、云服务与大数据等互联网产业前沿科技及生活领域网络安全问题，陆续围绕“智慧安全 连接赋能”这一主题举办产业安全沙龙、T20峰会、CSS 国际安全技术峰会、第二届互联网安全领袖峰会等互联网安全相关交流活动，保持不断创新，对各产业网络安全进行深度剖析与信息资源整合，现共享、开放、互赢互利。**关于中国互联网安全领袖峰会**![](../Images/ca3d87c59f41c7221e3df16a96281774.png)中国互联网安全领袖峰会(Cyber Security Summit，简称CSS)由腾讯公司、中国电子技术标准化研究院等企事业单位共同创办，得到了国家网信办、工信部、公安部等国家部门的大力支持和指导。中国互联网安全领袖峰会始终致力于聚合互联网产业领域与网络安全行业的力量，共筑“互联网产业安全交流与合作平台”，共建“互联网安全新生态”，进而推进产业快速、稳定创新，为国民经济的升级转型和蓬勃发展做出贡献。  
首届中国互联网安全领袖峰会于2015年11月3日－4日在北京国家会议中心召开，吸引来自互联网金融、智能汽车、物联网、智能硬件等多个热门产业领域150余家顶尖企业参加，来自不同领域参会规模达到4000人；大会将首次提出“互联网安全新生态”议题，旨在建立互联网安全新秩序，提升安全与互联网产业的深度融合。  
第二届中国互联网安全领袖峰会（CSS2016）将于2016年11月9日－10日在北京国家会议中心召开，本届峰会的主题为：“智慧安全 连接赋能”，届时，数百位精英将围绕主题，从互联网金融安全、智能汽车安全、物联网安全、云安全与数据安、人工智能与网络安全、企业信息安全等多个方面，全方位共同探讨网络安全与互联网+各个产业互助共融。![](../Images/92af85807cf309b51819d8b536397fc1.png)
