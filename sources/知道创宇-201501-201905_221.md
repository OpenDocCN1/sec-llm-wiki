# “溯源之旅”互联网安全沙龙 大牛聚集共话西部安全

KCon西部黑客大会将于2016年6月4日以“唤醒西部的力量”为主题在西安召开。今天下午，参加KCon西部黑客大会的嘉宾提前聚集西安高新区软件新城，共同出席会议前序之“溯源之旅”互联网安全沙龙，曾经西部培养的无数技术精英，如今已有多人成为了行业的中流砥柱，今天他们回到“家”里！共同探讨西部互联网安全，同时讨论相关人才培养输送计划。  

  

![](../Images/c5853f6420bdb36269d9cef8572ae724.png)  
KCon西部黑客大会前序之“溯源之旅”互联网安全沙龙成功举办

  

作为国内影响力很高的黑客大会，KCon的主场地一直都在北京，但今年KCon黑客大会首次出走北京在外地开设分场。之所以选择走进西部，KCon创办人余弦解释说：“就是想把纯正的黑客文化向西部传播，将顶级的思想、技术带过来，先把这边的安全氛围搞起来，希望吸引人才和安全企业回流西部，扩大西部互联网安全行业的影响力，推动和促进西部互联网安全技术水平发展和进步。”

  

![](../Images/903e7d4500c3c0cba939a4979f82f5d5.png)

 ![](../Images/6a3db0578a61dc99072e554ee76f269b.png)

![](../Images/305a5283decb1420949d22bb14aedf7b.png)

在这样的前提下，KCon西部黑客大会前序“溯源之旅”互联网安全沙龙得以召开，会议由陕西知道创宇负责人李玥主持，知道创宇云安全高级安全专家王利伟、西安电子科技大学裴庆祺教授、甜橙金融翼支付安全总监刘奇先后就区域安全现状，以及西部人才培养做了精彩分享。在台上嘉宾的带动下，台下技术精英畅所欲言，进一步讨论了西部互联网发展所需面对的安全挑战，以及西部互联网安全产业现状、自身责任及进军西部的愿景。

  

![](../Images/400d88817320ff77098906f38ac8409d.png)  
知道创宇CEO赵伟出席沙龙会议，并参观了西安软件新城示范展厅

  

“一带一路”把中国西部推向了开放的前沿，西部经济发展日新月异，而经济发展则必须要用安全来护航。习总书记曾说过，没有网络安全，就没有国家安全。而地域安全则是整体安全的一部分，如今互联网已经渗透到了社会的方方面面，进入了万物互联时代，西部在拥抱先进的互联网技术的同时，如同西安，西安高新区软件新城正以高速的发展吸收着最为前沿的互联网企业带动地区发展变革，而这迫切需要互联网安全的同步发展，以保障经济发展稳步前行。

  

![](../Images/95e1e6e7d4d441efec154c2f0e925234.png)  
会后嘉宾集体合影

  

“溯源之旅”互联网安全沙龙上嘉宾们的畅言现状与未来只是KCon西部黑客大会的前序，明天，KCon西部黑客大会即将启航，来自全国各地的技术爱好者将通过议题讲演的方式分享包括物理安全、网络安全、应用安全、数据安全在内的不同领域，以及包括入侵破解、安全防护、数据保护在内的不同方向的黑客技术。从来没有像KCon这个级别的纯技术型、追求干货有趣的黑客大会在中国的西部地区举办，敬请期待！
