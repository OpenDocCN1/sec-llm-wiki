# 安全联盟与中国消费者报达成战略合作

10月23日上午，安全联盟与中国消费者报（以下简称中消报）在北京共同启动了“打击网络欺诈，确保消费安全”活动。正值中消报创刊三十周年，中消报将联合北京、上海等40省市消协组织，通过与北京知道创宇公司运营的国内最大的第三方网络安全数据共享交换平台安全联盟（www.anquan.org）的战略合作，在全国范围内开通多点网络欺诈举报渠道，为保护网民线上消费安全展开全新的尝试。![](../Images/390d0cb2a4d30aa1edfa6e1ba1c03ec7.png)▲中国消费者报创刊30周年庆典  
  
国家工商行政管理总局党组成员、副局长马正其，中国记协党组书记常务副主席翟惠生，中国消费者协会副会长兼秘书长常宇，中国消费者报社社长朱剑桥，以及各地区消协领导出席会议，中国汽车流通协会副秘书长王都，浙江省消保委秘书长崔励金，知道创宇CEO、安全联盟发起人赵伟上台共同拉开仪式卷轴宣布“打击网络欺诈，确保消费安全”活动启动。  
![](../Images/0bc3d773cafaf49b24c0b4e493bf4a26.png)▲中国汽车流通协会副秘书长王都（中）、浙江省消保委秘书长崔励金（左）、知道创宇CEO安全联盟发起人赵伟（右）共同宣布活动启动  
  
据中国互联网信息中心数据显示，截止到2015年6月，中国网民规模达6.68亿，2014年中国信息消费规模达2.8万亿，预计今年将达到3.2万亿，互联网经济的蓬勃发展，消费者的消费行为、资产、隐私已经越来越多地往互联网转移，相应伴随而来的是，诈骗从线下转移到了线上，街头诈骗衍变成了各种网络诈骗、电信诈骗，网络消费纠纷、消费安全隐患等社会问题随之逐渐凸显。  
  
“打击网络欺诈，确保消费安全”合作开展后，当您再遭遇网络诈骗、电信诈骗，除了可以到安全联盟（www.anquan.org）举报专区举报外，更可以到中国消费网（www.ccn.com.cn）“投诉吧”频道、以及北京、上海等40省市消协组织官网举报，1分钟举报、5分钟（审核无误后）“全网拦截”欺诈、钓鱼不法网页（包括欺诈电话等），作为消费者，每一个人都能够参与到打击网络欺诈行为的行列中，更好地保护自身的合法权益。  
  
知道创宇CEO赵伟表示，安全联盟此次牵手中消报及全国各地区消协组织，就是要将安全联盟对所有恶意网址的识别阻断能力延伸，通过与消协体系的强强联手，达到线上与线下能力的有机整合，当消费者的更多消费行为转移到网络上之后，同样可以为保护消费者权益提供有力的支持。活动启动后，通过多平台举报网络欺诈联动体系的建立，凡是被网民举报并审核通过的不法网址都将被列入安全联盟的“网址黑名单库”，并被国内数十家主流互联网应用平台所采用。  
  
中消报相关领导表示，安全联盟一直致力于优化中国互联网环境，保护网民上网权益，作为全国较大的网址安全数据交换平台，安全联盟每天在网络上进行10亿次以上的消费风险提醒，极大的保护了网民的线上消费安全，此次与中消报及各地区消协组织合作，进一步加强了安全联盟的服务范围和服务效果。而中消报借助安全联盟的力量，从传统线下处置消费者投诉纠纷，延伸到线上的网络空间，消费者的消费行为指向哪里，我们的保护就应出现在哪里，在进入互联网+时代，中消报也迈出了更全面保护消费者权益的重要一步。
