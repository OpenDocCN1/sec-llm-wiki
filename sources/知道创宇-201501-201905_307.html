下一代网络安全观促安全企业运营变迁

日前，知道创宇 CEO 赵伟接受了《信息安全与通信保密》杂志记者的专访，就云物移大智问题与记者展开了探讨。以下是采访实录。


来源 | 《信息安全与通信保密》

记者 | 杨晨


近年来，云物移大智（即为云计算、物联网、移动互联网、大数据、智慧城市）等网络新技术逐渐兴起，由德国政府提出的工业 4.0 计划其核心理念与云物移大智不谋而合。简单来说，云物移大智的核心即是用科技改变生活。


那么，在云物移大智的时代，安全企业如何顺应时代变迁，推出适应新时代的安全解决方案，成为整个行业需要思考的话题，下一代网络安全公司知道创宇用实际行动向我们展示了云物移大智时代下的安全企业运营变迁，公司创始人及 CEO 赵伟先生日前接受了本刊记者的专访。




记者：目前云物移大智及工业 4.0 等新技术的应用和实现，为自主安全产业带来怎样的机遇，国内厂商在这方面有哪些亮点另您印象深刻？

赵伟：云物移大智正在各个领域迅猛发展、并正在冲击与革命着传统行业，自主安全产业首当其冲。而国内安全厂商要在这一场变革之中良好发展，正因顺应这一趋势，从传统的功能积累真正的向以用户体验转变，真正做对用户有用的产品。在这其中我们也看到很多亮点，比如前不久搜狗号码通在 IOS 上的拦截骚扰电话方面的创新性改进，知道创宇也正在顺应这股潮流努力转变，过去几年，我们运营的安全联盟平台成功的使用社会化管理的方式帮助着成千上万的网民免受网络欺诈。我们加速乐产品通过云的方式，利用安全大数据让超过 60 万的网站无成本享受到了安全保障。

记者：目前我国网络安全形势严峻，特别是在云物移大智正在加速推进过程中这一问题更加复杂，面对上述网络新技术安全威胁，您认为安全业界应当如何未雨绸缪？知道创宇进行了怎样的规划和布局？

赵伟：云物移大智时代网络安全是否加复杂，但复杂只是表象，只是我们遇到的安全问题的外在表现更加多样了，但安全企业下一步怎么走值得思考。最为重要的首先是思维的转变，用一句最近比较时髦的话就是需要向互联网思维靠拢。互联网思维的本质就是以客户体验为中心，说得通俗点就是安全企业首先得切实解决客户的问题，其次是要让客户能够很方便的解决问题。也就是有用 + 好用。网络安全其实是一个很专业的东西，特别是一些专业的安全名词，很多企业、政府单位并没有专业的技术人员来搞懂安全中的门门道道，要知道我们对抗的是能力非常强大的职业黑客。过去很多我们看到很多安全产品都在拼功能，可能做了 100 个功能中，客户最常用的只有两三个，而这最有用的两三个混杂在几十个复杂的参数设置中，客户看了绝大多数一时半会根本不知道怎么用。而很多安全产品都是硬件产品，等设备根据客户的实际情况调整好，再将设备部署到客户现场，可能安全问题已经造成了严重后果。网络安全就是和黑客抢时间，抢在黑客之前，或者抢在黑客实施攻击时进行阻断。知道创宇加速乐云防御平台就是洽洽就能解决遇到安全事件响应慢、使用复杂的问题，现在如果服务遇到攻击，其实很简单，直接通过互联网在我们的防御平台上注册帐号，根据引导添加网站，一般二分钟就能给网站启用保护了。这一过程比起传统的安全产品响应速度有了本质提升。

记者：互联网思维正是目前整个安全行业所缺少的。那么哪些安全问题是当前网络新技术应用层面的突出问题，知道创宇的技术优势在解决哪类新技术应用中的安全问题时效果显著？

赵伟：网络安全是一个自互联网这一伟大发明诞生以来就出现的问题，并在互联网的高速发展中问题愈发严重。现在最突出的应用层面的安全问题主要是两类，一种是网站漏洞引起的用户信息泄露，比如 CSDN 泄露类事件，一种是黑客针对网站发起的 DDOS 攻击。知道创宇针对这两类问题分别给出了解决方案，我们认为，网站存在漏洞很多情况下是因为程序开发人员安全经验偏弱，在程序开发过程中忽略了一些安全问题的处理，为此我们推出了 WEBSOC 漏洞检测产品，帮助客户发现自身产品的弱点，从而改进。而加速乐正是为抗 DDOS 而生的，目前包括中国人民银行官网、公安部官网正在采用加速乐来保障服务安全。在云物移大智时代，其实问题一样，之前有机构统计，目前国内的移动应用、智能设备中绝大多数后端其实是一个 WEB 系统，这些 WEB 系统的漏洞随时可能影响数以千万的用户，2014 年频发的国内多个知名路由器产品的漏洞正是这一问题的实际表现。


记者：那么知道创宇是如何和与自己合作紧密的上下游企业一道，共同应对网络新技术安全保障方面的技术难题，可否列举一两个成功的解决方案？


赵伟：在安全问题不断爆出的今天，网络安全其实已经不是一个厂商或者纯安全厂商可以解决的了，他更需要产业上下游的相互协作。知道创宇目前已经和国内的各大知名建站系统企业建立了合作，比如社区类网站中占有率超过 80% 的 Discuz!、知名建站系统 PHPCMS、DEDECMS 等，每当知道创宇的安全研究人员截获到针对这些系统的漏洞攻击时，都会第一时间同步给合作企业，与他们一道帮助更多客户迅速解决安全问题。

网络安全已经和每一位网民、每一个企业紧密相连。经过几年的发展，目前知道创宇已经积累了海量的数据，但海量数据并不代表就是大数据，特别在云物移大智的背影下，如何让这些数据产生价值，从而服务于社会，正在智慧城市的核心。为了解决大数据的利用问题，知道创宇目前部署了数千台服务器组成的大数据分析平台。

记者：知道创宇是如何利用大数据呢，整个流程是什么样子？赵总能否透露一二？


赵伟：我们的大数据产品主要包括两个，一个是前面讲到的加速乐，目前我们正在为 60 万网站提供服务，每天有超过 20 亿的访问，这其中包含大量的黑客攻击行为，有些是通过已知漏洞进行攻击的，还有少部分是通过零日漏洞攻击的，每天我们的安全研究团队通过对这些海量日志的分析，然后对攻击进行分类跟踪，对黑客攻击者建立黑名单，然后将这些黑名单再反向同步到加速乐防御节点上，那么以后这些黑客再有更新的攻击手法时可以直接定位，无论他怎么变换手法也无法绕过。另一方面，我们的网络空间搜索引擎 ZoomEye 通过对全球 20 亿 IP、 40 亿域名的应用识别，这样我们知道了哪个 IP 是网络设备，哪个域名使用的是 Discuz!，对它们进行分类入库到我们的大数据分析平台。这样每当我们截获到一个针对某个应用的重大漏洞时，可以很快知道受影响的 IP 有多少，他们分布在哪些国家。可以迅速对这一安全事件做出影响评估，同时我们也可以根据各国对该漏洞的修复速度间接的了解到各国网络战响应能力。

记者：最后，作为国内安全界新贵级企业，在维护网络安全、自主创新和促进产业的发展方面发挥怎样的积极作用？


赵伟：自 2007 年知道创宇成立之初，这么多年来，我们一直只致力于做好安全这一件事情。


除了为大客户去寻找 0Day 漏洞（已经存在，官方还没有相关补丁的漏洞），并通知相关的安全人员做维护，我们也会为中小网站提供更便捷可行的安全解救方案。许多做“黑产”的人扬言要把我们干掉！因为，只要我们认定是恶意软件或网站，其主要的流量入口几乎都被封了，我们希望能够做到真正的安全保护！


我们始终低调潜行、厚积薄发，面临国际信息安全日益严峻挑战，我们知道创宇将勇担重任，捍卫国家信息安全，帮助用户应对变化多端的互联网安全威胁！我们本着开放的心态愿意与其它厂商一道，推动产业发展，开创云物移大智及工业 4.0 领域的新时代！
