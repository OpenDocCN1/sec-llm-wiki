# 知道创宇入选第一届湖北省网络安全应急技术支撑单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649862103&idx=1&sn=24f88b8178c9405ead24800aa1fb2fc2&chksm=beda79dc89adf0ca896bedaade7c9572d387ca38676b17502b9a9ddaa6bdfd537a0ed200c00b&scene=126&sessionid=1681376831#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649862103&idx=1&sn=24f88b8178c9405ead24800aa1fb2fc2&chksm=beda79dc89adf0ca896bedaade7c9572d387ca38676b17502b9a9ddaa6bdfd537a0ed200c00b&scene=126&sessionid=1681376831#rd)

近日，知道创宇收到中共湖北省委网络安全和信息化委员会办公室颁发的**“网络安全应急技术支撑单位”**荣誉牌。  

  

![](../Images/ee724732a43f7790af6024eb0496ec97.png)

  

本次支撑单位遴选工作，旨在选拔一批在网络安全领域**技术实力强**、**有社会责任感**、**能有效支撑全省网络安全工作**的单位，进一步加强湖北省网络安全应急技术服务体系和支撑队伍建设，全面提升省内网络安全应急处置能力。

  

知道创宇凭借“AI+安全大数据”的技术优势和突出的应急响应能力，经层层考核和专家评审，成功入选**第一届湖北省网络安全应急技术支撑单位**。

  

![](../Images/b02316898a56104ce17e25a04607bce4.png)

  

多年来，知道创宇对实战对抗领域中的“**持续交火**”和“**向前防御**”等理念反复实践，已为国内**党政机关**、**国家部委**、**大型央企**、**头部互联网**等**数十万**信息系统和内部网络提供实战化安全防护保障，**十余年无事故**。

  

十余年的技术积累，知道创宇在应对**突发网络事件响应**方面拥有丰富经验，并获得了多项权威认可：

  

● **知道创宇与国家互联网应急中心共建国家漏洞共享平台；**

  

● **是中国信息安全测评中心技术支撑单位；**

  

● **连续五届入选CNCERT网络安全应急服务省级支撑单位，2021年入选CNCERT国家级支撑单位；**

  

● **2018至2021年，连续三届获评国家信息安全漏洞共享平台（CNVD）支撑单位综合实力第一**

  

……  

  

知道创宇在武汉设有技术中心，历年来，知道创宇大力支撑**湖北省委网信办**、**湖北 CERT** 开展网络安全检查、远程检测、应急演练等工作。

  

知道创宇发现**漏洞情报信息**第一时间进行上报，针对辖区内网站进行**舆情监测**、**违法违规内容检测**，并针对辖区地市进行**专向性检测**。

  

本次获选成为第一届湖北省网络安全应急技术支撑单位，是主管部门对知道创宇**支持力度**、**服务水平**、**技术实力**、**社会责任感**及**应急响应能力**等方面的高度认可。

  

未来，知道创宇将继续保持与湖北省主管部门的密切合作，并不断加大配合和支撑力度，协助湖北省委主管部门维护公共互联网安全，保障关键信息基础设施的安全运行。
