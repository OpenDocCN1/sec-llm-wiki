# 零信任是否可以取代VPN？又该如何选型？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649855958&idx=1&sn=611677db6ef73d66bc93685e65445101&chksm=beda41dd89adc8cb7005f257b2d0c1d3cb4dc2b4eacb3b47ad7388078690dd08a53aa511a5f1&scene=126&sessionid=1681376917#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649855958&idx=1&sn=611677db6ef73d66bc93685e65445101&chksm=beda41dd89adc8cb7005f257b2d0c1d3cb4dc2b4eacb3b47ad7388078690dd08a53aa511a5f1&scene=126&sessionid=1681376917#rd)

![](../Images/9a138dfb6c58135815f0d60815201f4b.png)

  

在新冠疫情爆发期间，VPN暴露出了作为远程访问安全方案的不足。零信任网络访问方案，因其秉持“**持续验证，永不信任**”的原则，默认不信任网络内外的任何人、任何设备及系统，基于身份认证和授权，重新构建访问控制的信任基础等特点，受到越来越多企业的青睐。

  

随着业务网络环境和安全态势变得更加复杂，许多企业正在转向零信任网络访问以提高其安全性，同时还替代或补充了VPN等旧技术。但零信任商业价值对企业业务和网络安全的潜在影响，业界依然众说纷纭。

  

  

**五问零信任的安全价值**

  

Appgate首席技术官Kurt Glazemakers接受betanews采访时指出，零信任网络访问无论是对于业务还是安全都有着极高的价值。

  

**问**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

**随着越来越多的服务和系统迁移到云端，VPN在今天还有一席之地吗？**

实际上，VPN可能仍然是最常用的技术，尤其是在新冠疫情爆发之后，我认为这是当时极为有效的手段，用户已经习惯了，然后决定尝试延长其使用周期。

  

VPN通常会成为网络的入口点，这是它的最大风险，也是企业开始转向零信任网络访问的原因之一。而在零信任网络访问中，连接性和身份验证是一致的，不仅用于网络访问，还用于访问应用程序。

**答**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

  

  

**问**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

**零信任网络访问是否与VPN直接竞争？对企业来说实施零信任网络访问的价值有哪些？**

是的，越来越多的VPN正在被零信任网络访问替换，因为企业需要采取更精细的方法，来保证在内部网络延伸到端点设备的整个系统内，只访问必要的应用程序。零信任网络访问实现了这一需求，它将企业外部的网络访问管控细粒度化到每个个体，使得安全性能大幅提升。

  

此外，**零信任网络访问还降低了互连成本并降低了复杂性，可以节省大量成本**，因为所有需要在企业网络或安全解决方案中互连的系统可以统一与云和企业数据中心建立互联网连接，因此企业可以节省大量“内部连接”开支成本，例如：减少防火墙、安全堆栈、MPLS连接以及站点到站点VPN，同时企业还可以大量节省创建和管理规则集所花费的时间。

  

VPN向零信任网络访问的大迁徙，主要发生在用户访问公司网络的部分，因此对于用户端来说，VPN的替代过程会更快，但用于安全连接网络各部分站点间的VPN还将继续存在相当长一段时间。

**答**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

  

  

**问**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

**在过去一年半的时间里，远程办公大潮对零信任市场有多大影响？**

疫情暴露了VPN的先天局限性，它不是为大量的远程流量而设计的，而且它是由设备驱动的，因此在拓展上会有延迟，且规模会受到限制。

  

以Zoom调用为例，如果用户想要捕获所有的VPN网络流量，还需要考量带宽，但零信任网络访问没有这些问题，用户只需管理一个访问配置文件，在办公室还是在其他地方工作没有区别。

**答**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

  

  

**问**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

**我们越来越多地看到企业网络和云中的安全漏洞被归结为配置错误。零信任网络访问如何帮助解决这些问题？**

配置零信任网络访问，归根结底是想让网络访问更智能。在传统方案中，用户需要安装和修补所有公司设备策略，适当的端点保护等。

  

零信任网络访问的不同之处在于，用户可自行制定描述性的策略，例如用户可下达：“将位于不同位置或云中的所有标记为工程的资产给我”的指令策略，然后零信任网络访问解决方案就会找到这些资产并建立对所有这些的个人网络访问。

  

如果用户在云上或内部为工程部门启动了新资产，这些新资产也将自动成为网络中的一部分，这有助于处理更复杂的结构。应用程序会自动启动并为用户定义，他们可以自动选择正确的控件，与VPN相比，这绝对是向前迈出的一大步。

**答**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

  

  

**问**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

**当员工离职或调岗时，零信任网络访问会让安全流程变得更容易吗？**

如果员工的工作角色发生变化，其网络访问（权限）也会发生变化，因为零信任策略会自动适应，这减少了人为错误的范围，有助于减少攻击面，尤其是对于有时会在很短的时间内临时启动的应用程序或容器。消除人为因素是敏捷和安全齐头并进的关键所在。

  

虽然零信任网络访问解决方案有很多优点，但企业在采购零信任解决方案时，仍要仔细考量在混合工作环境的适应性、数据丢失保护、高级威胁保护、可见性等方面的性能，避免各种陷阱，确保所选方案能够满足企业安全的实际需求。

**答**

![](../Images/d92abbbff487029cf2fddfffbad9602d.png)

  

  

**四大关注点**

**帮助企业进行零信任方案选型**

  

**0****1**

**能否适用用户现在负载的办公工作环境？**

  

企业在选择合适的零信任解决方案时，性能至关重要。新冠疫情爆发初期，许多组织投入巨资扩展其VPN容量以适应远程工作，但现在由于许多工作场所已过渡到混合环境，基于本地设备的VPN将配置和扩展的负担交给了消费组织。为了规避风险，企业用户应该寻求一种零信任网络访问解决方案，允许运营所需的基础设施由公共云中的解决方案提供商托管。

  

零信任网络访问解决方案只是一个开始，安全团队还需要仔细审查解决方案，以确保其响应能力和可靠性符合业务需求。为此，用户需对其需求进行评估，并检查是否存在潜在风险。优秀的解决方案，是不管用户身在何处，都能够应对流量高峰，并拥有可认证的高可用性。

  

**0****2**

**是否可以实时防护信息和数据的暴露/泄漏？**

  

企业在提供远程工作环境转移的过程中，由于非托管个人设备使用激增，防止敏感信息泄露成为安全团队面临的众多挑战之一。这也是为什么企业在选择零信任网络访问解决方案时，需要重点考虑该技术能否成功执行DLP（数据丢失保护）策略，以下载和上传（如有必要）本地资产的关键所在。

  

为了能够在整个企业组织IT基础设施中实施零信任规则，安全团队必须确保解决方案变得更加精细，并且可以根据位置、用户类型和其他身份元素等进行恰当配置。

  

**0****3**

**如何防护APT攻击？**

  

APT（高级持续性威胁）防护是零信任网络访问解决方案的另一个重要组成部分。恶意软件很容易在员工不知情的情况下上传到文档中，它可以通过下载传播到其他设备和用户。一旦发生这种情况，如果没有合适的技术，威胁行为者就可以在整个组织中横向移动。

  

这就是在零信任网络访问解决方案中，要重点考察其是否能够实时阻止恶意软件上传、下载和传播的原因。如果在远程办公环境中，不需要在远程用户设备上安装安全软件，零信任网络访问解决方案就能够实时阻止恶意软件的上传和下载，实现高级威胁防护，对于用户来说，无疑是个好消息。

  

**0****4**

**是否满足安全监管合规？**

  

企业应考察零信任网络访问解决方案是否提供实时可见性和控制，用于满足安全合规性。选择能够实现简单SIEM集成和可导出日志的解决方案，有助于扩展对企业内部网络其他部分的可见性。这些功能包括完整的日志，用于观察托管和非托管设备的所有文件、用户和应用程序活动（包括设备类型、IP地址、位置和访问时间）等。
