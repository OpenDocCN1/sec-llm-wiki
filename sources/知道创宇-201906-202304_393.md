# 知道创宇404实验室再次获IBM官方致谢

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649851575&idx=2&sn=39bbb50fe7827014c56df5789bd4d3ae&chksm=beda50bc89add9aaf6f78f2891845c7caf6cac129332ed94a11c2f0978072b39172f161fd8d9&scene=126&sessionid=1681376963#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649851575&idx=2&sn=39bbb50fe7827014c56df5789bd4d3ae&chksm=beda50bc89add9aaf6f78f2891845c7caf6cac129332ed94a11c2f0978072b39172f161fd8d9&scene=126&sessionid=1681376963#rd)

  
![](../Images/2d6feb7345cf10816946b993b1dc6e1d.png)近期，IBM官方发布了4月份安全更新补丁,本次更新修复了IBM企业级应用服务软件 WebSphere Application Server 的多个漏洞 ，针对这些漏洞，IBM官方提供了安全更新指引,同时也致谢了相关安全研究团队和人员，知道创宇再次登陆致谢榜单。  
![](../Images/1dfbc23a7dc0c84aa83780fb026ebe4a.png)  
官方公告地址：https://www.ibm.com/support/pages/node/6420361https://www.ibm.com/support/pages/node/6445171https://www.ibm.com/support/pages/node/6445481  
在本次IBM的安全公告中，IBM修复了三个由知道创宇404实验室 Longofo 发现并提交的安全漏洞，漏洞编号分别为：**CVE-2021-20353**、**CVE-2021-20453**、**CVE-2021-20454**。知道创宇404实验室建议尽快更新升级至最新版本，及时规避攻击风险。  
![](../Images/f5a34779f44a787b52f86c02229da728.png)  

知道创宇404实验室，是国内黑客文化深厚的网络安全公司知道创宇最核心的部门，404实验室长期致力于Web、IoT、工控、区块链等领域内安全漏洞挖掘、攻防技术的研究工作。

  

团队曾多次向国内外多家知名厂商如微软、苹果、Adobe、Oracle、IBM、腾讯、阿里、百度等提交漏洞研究成果，并协助修复安全漏洞，多次获得相关致谢，在业内享有极高的声誉。
