# 一文回顾：2020年重大安全事件

2020年，新冠肺炎（COVID-19）疫情爆发，人与人之间被口罩、安全距离等隔离措施所阻隔。网络，无可替代地成为了保障生产生活有序进行的重要角色，甚至是保障抗疫成功和经济发展的必要条件。

  

然而，**勒索软件**感染医院网络，危害病人生命安全；**黑客入侵**网络视频会议，打断会议或窃取会议资料；以及疫情期间统计的**个人信息泄漏**等安全事件都暴露出网络安全行业亟待解决的问题。5G、量子计算机、量子网络等新技术的兴起，也使安全行业面临新挑战。国家也有针对性地发布了相关规范和发展政策，以引导行业的健康成长。

  

本文将从安全漏洞、新冠疫情相关安全事件、数据泄露、勒索软件、供应链攻击、量子发展、行业规范、国际安全生态与形势等方面对2020年发生的重大安全事件进行回顾，以供参考。

  

**#安全漏洞**

  

2020年，知道创宇Seebug漏洞平台共收录**938个**漏洞详情，知道创宇404实验室共参与了**168个**漏洞应急。

  

根据2020年创宇资讯的全年数据，用户对影响范围大的微软漏洞、苹果设备的越狱信息比普通漏洞关注度更高；安卓设备的问题更多地集中在恶意APP上；除此之外，互联网的基础代码库仍然存在大量漏洞。

  

根据404实验室的应急数据以及创宇资讯的阅读量统计，我们总结出2020年更受读者关注和影响巨大的安全漏洞和事件如下（排名不分先后）：

  

**NSA向微软报告的签名算法漏洞（CVE-2020-0601），可以伪造签名，影响全球数十亿用户**

1月，微软修复了NSA向其报告的一个位于crypt32.dll中的有关椭圆曲线密码（ECC）证书检测绕过的漏洞。攻击者利用该漏洞，可以在未修复的系统上让任意恶意程序都拥有合法的可控签名，也可以通过中间人的手法，构造恶意tls证书。^(【1】)

**NetLogon特权提升漏洞（也被称为ZeroLogon，CVE-2020-1472）或严重影响内网安全生态**

在微软发布2020年8月安全更新的30天后，Secura的安全研究人员公开了CVE-2020-1472漏洞（Zerologon，CVSS 3.0评分10.0）的详细细节。根据该细节，2020年9月15日前后，多位安全研究员写出了该漏洞的利用脚本并公开在互联网上。该漏洞仅仅需要攻击者处于内网并能访问到域控服务器的445端口就能利用。成功利用该漏洞后，攻击者将获取到域控管理员权限。^(【2】)

**Windows DNS服务器存在漏洞（CVE-2020-1350），如不重视可能形成蠕虫攻击**

Check Point的研究人员在5月份向微软报告了一个Windows DNS服务器的安全漏洞，CVSS3的评分高达10.0分。其已经在微软的代码中存在了17年以上，如果利用脚本公开，可能会形成新一波的蠕虫攻击。^(【3】)

**Windows SMB Ghost（CVE-2020-0796）漏洞，已经被用于木马传播**

Windows SMB Ghost是一个位于 Windows SMBv3 协议下的远程命令执行漏洞。该漏洞的利用场景与“永恒之蓝”类似，黑客可以通过连接到目标主机的445端口来得到系统的最高权限。

  

在漏洞补丁公开后，安全研究人员发现该漏洞还可以被用于实现本地权限提升。根据Jan Kopriva文章中的统计结果，在微软发布补丁后，仍有103,000台计算机容易受到SMBGhost攻击。2020年6月10日，“黑球”行动新增了启用SMBGhost漏洞攻击的相关代码。^(【4,5】)

**苹果多款设备Wi-Fi组件内存破坏漏洞（CVE-2020-9906）**

这是一个由Google ProjectZero 安全研究员 Ian Beer 发现的多款苹果设备0 click内存破坏漏洞，存在于Wi-Fi组件中。若使用定向天线、更高功率的发射器和敏感的接收器，将扩大该漏洞的利用范围。

**Treck TCP/IP Stack曝Ripple20漏洞，或影响数十亿IoT设备**

国外网络安全公司JSOF研究人员在Treck TCP/IP Stack发现了19个0day漏洞，其中包含多个远程代码执行漏洞，统称为“Ripple20”。攻击者仅仅需要与目标设备建立TCP连接，就可以尝试利用这些漏洞。由于Treck TCP/IP Stack是一套专用于嵌入式系统的TCP/IP套件，所以大量 IoT 设备将会受到该漏洞的影响。

**LILIN多个型号DVR远程命令执行在野0day漏洞**

LILIN多个型号DVR被曝出硬编码凭证、任意文件读取、远程命令执行等严重漏洞。结合多个漏洞，未经授权的远程攻击者可以以root身份在目标设备上执行任意命令。值得注意的是这些漏洞早在2019年8月就被黑产用于传播Chalubo、FBot、Moobot等多个僵尸网络。

**Apache Tomcat文件包含漏洞（Ghostcat，CVE-2020-1938）**

Apache Tomcat AJP协议存在实现缺陷导致相关参数可控，攻击者利用该漏洞可通过构造特定参数，读取服务器webapp下的任意文件。如果可以上传一个内容可控的文件到服务端，攻击者可进一步实现远程代码的执行。

**Linux内核AF\_PACKET原生套接字漏洞（CVE-2020-14386）**

2020年9月3日，openwall公开了CVE-2020-14386权限提升漏洞的相关原理。该漏洞是由于net/packet/af\_packet.c中存在一个整数溢出漏洞，最终导致攻击者在拥有CAP\_NET\_RAW权限的情况下可以越界写，进而实现权限提升或者容器逃逸。

**DrayTek Vigor企业级路由器和交换机未授权RCE在野0day漏洞**

2020年1月26日，DrayTek旗下多个型号的企业级路由器和交换机设备被曝出存在未授权RCE漏洞，编号CVE-2020-8518。该漏洞源于Web登录表单的多个字段存在命令注入，未经授权的攻击者可以利用该漏洞以root权限执行任意命令。值得一提的是，早在2019年，该漏洞就已经被发现有在野利用痕迹了。

  

  

**#新冠肺炎(COVID-19)疫情相关事件**

  

新型冠状病毒肺炎（COVID-19）的疫情贯穿了2020年，线上办公和在线教育的兴起，也带来了安全攻防重心的转移。英国2020年网络安全年报就指出，英国政府通讯部下辖部门——国家网络安全中心——在2020年中先后处理超过200次与冠状病毒相关的网络事件，几乎占上报事件总数的三分之一。【6,7】

  

从普遍披露的利用疫情信息进行钓鱼、传播恶意样本到新冠疫苗的研发成果、与疫苗有关的传输冷链遭到黑客攻击，充分说明了网络攻击既可以是一个面，也可以是多个有针对性的点。鉴于目前各国疫苗研究进度和医疗科研水平的不同，各国的疫苗研究成果也成为了有组织的黑客窃取的目标之一。【8-12】

  

疫情也催化了有关行业网络安全方面的飞速发展，Zoom作为一家远程会议软件服务提供商，在疫情爆发之初用户数量激增，但也随之暴露了大量的安全问题。在业务大量增长的同时还需要修补历史遗留的安全漏洞，兼顾安全性，无异于一艘正在搏击暴风雨的航船还需要修补漏水的甲板。网络安全不是一蹴而就，没有未雨绸缪就不可能迎风破浪。【13-15】

  

  

**#数据泄露**

  

2020年数据泄漏事情依旧呈现出原因多样性的特点，有公民个人信息的泄漏、大型网站的数据泄漏、第三方导致的数据泄漏，也有勒索软件组织泄漏的数据。【16,17】

  

除去这些常见的数据泄漏方式和事件外，2020年，一些新冠病毒感染者的信息遭到泄漏，使患者在与病毒作斗争时亦承受着巨大的精神压力，这无疑是对患者的二次伤害。为了疫情防控的需要，大量个人信息必须被收集，那么，严格管理并保证这些信息不被泄漏则应是监管部门义不容辞的责任。【18】

  

除了公民个人信息被泄漏外，Xbox和Windows NT 3.5源代码也被泄漏到网上，由于Windows 3.5的支持已经于2001年12月结束，该操作系统在全球范围内使用率很低，因此源代码泄露并不是一个重大的安全问题。

  

值得一提的是，通过编译本次泄漏的Windows NT 3.5源代码，从安装盘中补充一定的缺失文件，即可获取到一个可运行的Windows Server 2003操作系统。这对安全研究有着巨大的意义。由于Windows系统长期闭源，研究者们可以根据本次泄漏的内容了解Windows系统的底层实现原理，正所谓“知己知彼，方能百战不殆”。【19】

  

  

**#勒索软件**

  

在新型冠状病毒肺炎疫情爆发的背景下，勒索软件不仅仅会对数据造成影响，甚至还可能危及到人民群众的生命健康。大部分被识别检测到的勒索软件往往会采取广撒网的方式进行传播，通过感染到的公网设备横向移动进而感染内网主机。但工厂中的设备往往无法及时更新，一旦感染到勒索软件，工厂的生产数据都将暴露在风险之中，更严重者甚至会导致生产线停摆。【20,21】

  

在疫情之下，医院也成为了部分别有用心者的攻击目标之一，这可能会间接危及人民群众的生命健康安全。【22,23】

  

但我们也要意识到，勒索软件使用的大部分漏洞都不是最新的漏洞，所以加强安全防范，建成有效的安全防御体系，就可以有效防止该类问题的发生。【24】

  

  

**#供应链攻击**

  

2020年末，火眼公司（Fireeye）公开的SolarWinds事件是本年度最受关注的供应链攻击事件。根据事后分析，整个事件中，攻击方采取了极其谨慎的方法和高超的隐蔽技巧。该攻击涉及范围之广，令人难以想象。美国财政部、商务部、能源部、国土安全部等都是被攻击的目标，且据信其中两个可能发生了邮件失窃。微软、思科、英特尔、英伟达等公司也在受影响的范围内。【25-27】

  

**#量子发展**

  

2020年12月4日，中国科学技术大学发布使用76个光子进行运算的量子计算机“九章”，并宣布实现量子优越性。虽然量子计算机的发展仍处于起步阶段，但是量子的特性也可以让它在安全领域发挥巨大的作用。5G量子手机、量子互联网都是一些新的尝试。也许这些技术现在看起来略显稚嫩，但仍然可能具有跨时代的颠覆性意义。【28-30】

  

  

**#行业规范**

  

2020年，国家集中整治了公民隐私、网络安全等多个问题，发布了《网络安全审查办法》、《中华人民共和国个人信息保护法（草案）》等，让公民隐私保护有法可依。【31-33】

  

集中整治行动建立了行业准绳、保护了用户隐私。从监管部门入手，自上而下地保护了用户的合法权益。【34-37】

  

**#国际安全生态与形势**

  

国际安全生态与形势纷繁复杂，不管同盟各国内部、联盟体之间，还是各国内部、国与国之间、以及地缘冲突等各种历史和现实的矛盾映射到互联网中，都会成为国际安全生态与形势发生变化的因素。在此我们也希望通过总结2020年国际网络空间安全生态的一些事件，来表现国际安全生态与形势发生的一些变化。

  

**▶ ****美国将会更加注重网络安全，将对具有深厚背景的大规模网络攻击采取强硬态度。**^(【38,39】)

  

****▶ **中国周边国家网络空间攻防能力的崛起，以及地缘冲突延伸到网络空间所带来的危害，值得警惕。**

  

网络空间的斗争给予了现实中实力不对等国家之间扳手腕的机会，这种网络空间的对抗本质是安全人才的竞争。中国周边国家的网络安全能力正在崛起，因此，在维护国家领土完整的背景下，也需要警惕一旦地缘冲突延伸到网络空间可能会带来的危害。^(【40,41】)**^()**

  

******▶ ****现实世界的矛盾或加剧网络巴尔干化。**

  

不同国家对于互联网的策略都不尽相同。除了已有的互联网应保持自由开放还是需要加强监管的争论，敌对国家之间、地缘冲突事件也可能会加剧互联网成为各国之间没有硝烟的战场。这也将进一步导致网络巴尔干化的加剧。甚至在这种背景下，也出现了将本国网络从互联网上分割出去的尝试，例如俄罗斯的“断网”行动。

  

这里借用《“碎片化”的网络空间趋势——基于俄罗斯“断网”的研究》中的一段话：“对于网络空间‘碎片化’的进程，需要持审慎态度。在国际领域，要处理好国家安全战略和国际信息流通性的关系；在国内领域，要保证个人信息隐私保护与数据审查管控之间的关系。只有平衡好这两个关系，才能在当今网络空间逐步‘碎片化’的情况下，更好地保护国家主权安全和个人信息数据安全。”^(【42-45】)

  

  

  

“千里之堤，溃于蚁穴”。回顾2020年，年末被曝光的SolarWinds攻击事件，让人惊叹于供应链攻击的强大威力，也再次给予我们警醒与启迪。工控安全背景下对于关键基础设施的保护既是防止网络破坏的最后一道防线，也是各国矛盾冲突的一个小缩影。如何有效识别和防御类似的、甚至包括0day的攻击，这既是课题，也是动力。一切都离不开安全研究和分析人员一丝不苟、不懈探索的辛勤付出。
