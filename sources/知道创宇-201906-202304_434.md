# 【转载】知道创宇首个爱心图书室在西安落成

11月5日，由北京知道创宇信息技术股份有限公司通过新浪扬帆公益基金建立的**首个“北京知道创宇爱心图书室”**在陕西省西安市周至县终南镇老堡子村小学落成，五百余册精美少儿图书为132名孩子带来了全新的阅读体验，并为每个学生送去一份文具礼盒助力孩子更好地学习。  
北京知道创宇信息技术股份有限公司云安全事业部总经理王利伟先生，战略支撑部总经理、党支部组织委员崔兆先生，西安分公司总经理刘治祥，行政经理王焱以及党务工作者王宁和新浪扬帆公益基金陕西站站长、红色青春志愿服务中心理事长、西安生物医药技术职业学校团委书记刘文军先生参与捐赠仪式。  
![](../Images/2d7497c9218ef17cbf2a8e132425c986.png)捐赠仪式现场  
老堡子村小学地处陕西省西安市周至县终南镇老堡子村，始建于1977年，是一所村级完全小学，现有1-6年级6个教学班，学生132人，学校教学设施缺乏，适合学生阅读的课外图书较少，此次通过北京知道创宇的捐赠极大缓解了这一难题。  
![](../Images/d733f16c033caf2664236677bd91cf7a.png)  
当天的捐赠仪式，北京知道创宇还发挥企业网络安全业务特色，为老堡子村师生举办**“防网络诈骗安全教育课堂”**，让大家对网络诈骗有一个新的认识，深刻的认识到防范网络诈骗重要性，更直观的明白防范以及遇到网络诈骗时该怎么做，增强了大家对网络诈骗防范意识，避免事故的发生。  
![](../Images/02f522a6511df227d1f88984196e5247.png)  
北京知道创宇信息技术有限公司是网络空间安全专家，长期致力于为政府、企业类客户提供完善的云安全解决方案。被评为亚洲20家最具价值企业、中国最酷网络安全公司。  
2020年，时逢北京知道创宇成立13周年之际，也是脱贫攻坚决战决胜之年，公司党支部及全体员工也紧跟党的十九大提出的“坚决打赢脱贫攻坚战、精准扶贫，坚持大扶贫格局，注重扶贫同扶志、扶智相结合”工作要求，将乡村学校最确切的阅读需求作为扶贫、扶智工作的重点，积极实践企业社会责任。  
![](../Images/10d2105ae3bde187814afac33049b19a.png)  
**扬****帆捐书的项目一直是扬帆最重要也是覆盖面最广的公益项目**，以“让乡村中小学儿童都能读好书、好读书”为愿景，致力于为乡村中小学捐赠最新、最优质课外读物，推动乡村儿童阅读的发展，提高阅读能力、养成良好的阅读习惯，让每个乡村孩子都能享受阅读的乐趣，增长见识、开阔眼界，能通过阅读在第一时间贴近时代的脉搏，在思想和意识上拉近城乡之间的差距。  
老堡子村小学爱心图书室的建立只是北京知道创宇公益项目中的一小部分，始于当下，着眼未来，今年他们还将与扬帆开展更多深入合作，**在更多需要帮助的学校再建4所爱心图书室****，从扶智起步呵护孩子们的心灵健康。**
