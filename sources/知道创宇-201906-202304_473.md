# 网络诈骗避雷指南——安全联盟《防骗秘籍》新版出炉

2020年，一场突然爆发的新冠肺炎疫情让这个春节注定难忘。已经持续许久的新冠肺炎仍在肆虐，白衣天使们一路逆行走到了疫情最前线，举国上下的民众也再次众志成城，用善良和温暖为抗击疫情，打赢疫情阻击战贡个人的力量。

  

然而，灾难这面照妖镜再一次让人性暴露出来。在举国抗疫的这个特殊时期，一些不法分子们心中的阴暗也再次滋生，他们纷纷将目光聚焦到了疫情的焦点上，利用大众对口罩等防护用品的迫切需求趁机大肆行骗。

  

近一个月来，以在社交软件平台和二手物品交易平台等渠道散发虚假货物信息，谎称拥有医用口罩、酒精等医用防护用品物资，骗取大量定金和货款；以航空公司名义假借退票名义发送诈骗短信，骗取个人信息套走账户余额；冒充感染病人家属或公益机构，以社会献爱心名义骗取社会捐款等形式的诈骗方式再次猖獗泛滥。

  

![](../Images/add275a03c7c9e5e583f015ed2acb492.png)

警方抓获以低价出售N95口罩为由诈骗嫌疑人

  

但就是这样拙劣的骗术也使得大众不慎中招，没能买到口罩捐赠不说，还造成了一大笔财产损失。其实不难发现，上述这些诈骗手段在生活中也极为常见，骗子所采用的诈骗手法和“冒充”的套路并没有改变，只需要提高安全意识和警惕心，对骗子不要轻易采信，绝大多数情况下就能够避免财产损失。

  

为了帮助公众提高防骗意识，维护健康的网络秩序，**知道创宇牵头成立并运营的公益性第三方网络安全数据交换平台“安全联盟”（www.anquan.org）**曾根据近年来的欺诈现状与安全联盟平台举报数据，整理十大经典网络诈骗案例和防骗干货知识印刷成册，于网络安全宣传周等活动中为公众免费发放，为公众分享防骗知识，远离诈骗。

  

![](../Images/e4140e3bc818dcb116ae0c0d4be81a12.png)![](../Images/813f40f53197d9431dddd7b0da916f53.png)![](../Images/129e31bb85c03f1f7746d6196ae9b671.png)

  

2020年伊始，为了进一步增进大众对新型网络诈骗方式的认知，分享不断迭代升级的骗术常识，安全联盟再次整理推出了新版《防骗秘籍》，对诈骗案例和防骗知识进行了补充和升级。

  

![](../Images/e4140e3bc818dcb116ae0c0d4be81a12.png)![](../Images/f60684b7c6a32ffce63a33ed1dd5ca3c.png)![](../Images/129e31bb85c03f1f7746d6196ae9b671.png)

  

根据平台2019年度受理的141万余条网址、电话等各类举报信息，安全联盟数据库中超过10亿条恶意网址数据以及当前欺诈现状，安全联盟再度悉心精选出了时下最常见的十大经典网络诈骗案例，包括婚恋交友“杀猪盘”、AI声纹信息欺诈、虚假招聘、网贷校园贷、虚拟币、金融传销、春运票务诈骗等骗局，全面囊括了近年来猖獗泛滥、受害群体广泛的网络诈骗类型。 

  

新版《防骗秘籍》将细致讲述每一桩案件的过程详情，从骗术手法、作案技术、受害人心理等方面深度解析诈骗过程，根据案例延伸例举同一类别的其他骗局，并针对性地为每种骗术总结了实用的防范要点和技巧，帮助公众识破骗局。

  

安全联盟通过数据分析发现，随着互联网技术的飞速发展，不法分子的犯罪工具更加智能化，诈骗场景也更加精准。

  

“ 

● 22 岁以下，尤其以00后为主体的年轻人社会阅历相对较浅，防骗意识弱，逐渐成为被蒙骗的重要群体，受骗方式更多为点击恶意链接、木马病毒而发生的网上资金代扣；

  

● 90后受骗方式更多为虚假招聘以及网络游戏交易相关诈骗；

  

● 70后、60后则因持有一定的财产储蓄，理财需求高，更容易被情感类和金融理财类诈骗手段诱骗；

  

● 男性受害人是女性受害人数量的2倍以上，男性更容易受投资、女性诱惑，不法分子通常会利用情感类、金融类手段对男性实施诈骗，尤其是在色情诈骗中，男性被害人占比达到 98%；

  

● 女性的生活习惯倾向勤俭节约，因此女性更容易被低投资高收益的理财型诈骗方式蛊惑。

”

  

网络诈骗之所以手到擒来，往往和“信息泄露”紧密相扣。大规模个人信息泄露事件频发，不法诈骗分子也正在掌握着更精准的数据，用更智能的AI工具不断实施诈骗。正是因为不法分子掌握了真实的个人信息，对受害人知根知底，才容易使人陷入这些个性化定制的精准陷阱中。防骗第一步，保护个人信息，防止信息泄露。

  

  

个人信息泄露威胁主要来自于两大方面，一是用户本身在连接公共网络或误入钓鱼网站等情况下，造成了个人信息被不法分子获取；二是用户在使用互联网服务时所提交的大量个人信息数据，由于互联网企业数据安全防范措施不严 ，而导致的个人隐私数据泄露。

  

  

面对日益严峻的个人隐私泄露问题，在新一版本的《防骗秘籍》中，安全联盟也对日常生活中信息泄露的场景和途径进行了详尽分析归纳，并整理了个人信息泄露防范妙招，细节小知识进行了分享。致力于帮助公众保护好个人隐私，提高个人安全意识，共同筑起个人信息安全的“防火墙”。  

  

新版《防骗秘籍》将在制作完成后，在各大网络安全宣传教育活动中为公众发放。**也可关注知道创宇公众号并后台发送“****防骗秘籍****”**，抢先获取电子版《防骗秘籍》一睹为快。
