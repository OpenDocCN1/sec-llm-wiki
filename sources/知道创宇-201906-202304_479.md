# 托管=甩锅？网站外包后曝出安全问题，自己还要负责吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA3Nzg2MA==&mid=2649843753&idx=1&sn=42a7275e3483ccf2d430cb7397ae955c&chksm=bedabe2289ad3734a7b6158d390877ade07f1674ce6a7011bb8a1a6e54415f55a702448a4c70&scene=126&sessionid=1681377004#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA3Nzg2MA==&mid=2649843753&idx=1&sn=42a7275e3483ccf2d430cb7397ae955c&chksm=bedabe2289ad3734a7b6158d390877ade07f1674ce6a7011bb8a1a6e54415f55a702448a4c70&scene=126&sessionid=1681377004#rd)

在此前净网2019专项行动通报案例中，江苏某市网警查获了一起案件，一所中学**因没有落实网络安全保护义务，导致系统被攻击后发布了恶意信息。**

 

在搜索引擎上输入了该校关键词后，页面上竟然出现了被篡改的不相关恶意信息。

  

![](../Images/b34175a5b22499069b1595f0d3e54a1c.png)

  

网警固定证据后，便和辖区派出所民警一起去该中学调查相关情况，**而校方直到这时才知道自己网站被黑了。**

 

相关负责人声称，**网站是全部外包给其他公司建设运维的，他们自己对这方面并不在意。**

  

![](../Images/264fc1cefb3aecaf175c50e4573ef230.png)

  

调查过程中，网警发现学校网站没有采取防范计算机病毒、网络攻击、网络侵入等危害网络安全行为的措施，给犯罪分子有可乘之机，已违反《网络安全法》中未履行网络安全保护义务的相关条款，依法对该中学给予罚款三万元的处罚，对直接责任人给予罚款一万元的处罚。

 

**企事业单位把自己的网站或应用外包给第三方公司代为维护，然后对自己的网站不闻不问，出了事后往往是相关主管部门找上门才知道情况，并认为自己网站出了问题都不是自己的责任，**这样的情况并不是少数。

 

今年3月，某市网警获悉，该市区一医疗美容医院门户网站遭到黑客入侵，网站页面被篡改，发布不正当信息。

 

经查，该医院门户网站托管在广东第三方公司，因该网站服务器未采取安全防护技术措施，导致黑客用暴力破解方式获**取了该网站后台管理权限，**并插入了**“后门”**恶意程序。

  

![](../Images/459da2047d58e552222564ea2602ccbe.png)

  

该医院违反了《网络安全法》第二十一条第二项、第二十五条之规定，构成**“不履行网络安全保护义务”**的违法行为。3月22日，警方依据《网络安全法》第五十九条第一款，对该医院予以罚款人民币一万元整的行政处罚。

 

因此特别提醒各网络运营者注意，**网站及各类系统托管出去以后，网络安全责任并不会随之转移，责任主体肯定还是自己，**所以各单位还是得把自己的安全问题放在心上，该履行的网络安全义务一个都不能少。

 

同时，这些案例也反映出部分第三方外包商的网络安全意识、安全技术处理能力均比较欠缺，对于相关政策也不甚了解，对接管的网站并没有采取任何有效防御措施，就直接放在网上裸奔，那出事只是时间早晚的问题。
