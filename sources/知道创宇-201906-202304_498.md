# CSS 2019安全升维 ——FP50俱乐部玩法升级

6月10日下午，由腾讯安全与知道创宇共同发起的互联网安全领袖峰会（Cyber Security Summit，简称“CSS”）FP50安全新锐力量俱乐部沙龙在北京腾讯汇举办。FP50俱乐部沙龙活动现场宣布今年新增安全牛主编、谷安天下副总裁李少鹏，北京赛博英杰公司创始人谭晓生两名专家评委，同时宣布启动新成员招募和行业优秀案例征集，并计划将征集成果凝练成《2019 FP50互联网安全解决方案白皮书》，于CSS 2019的FP50分论坛上发布。

  

![](../Images/5fe56fced89abd5b52a67bddc1d00546.png)

  

Future Power50安全新锐力量俱乐部由知道创宇与腾讯安全联合发起。作为安全行业内企业、专家、资本的交流平台，依托腾讯安全开放共享的生态优势，今年CSS 2019的FP50分论坛将在7月31日举办，以“行业新担当，聚力赢未来”为主题，期望促进FP50内部企业间的良性交流，共同探索更多合作空间，同时可以通过FP50的品牌号召力，展示新锐力量的企业实力。

  

![](../Images/4de07c9ac52d55b8033de434c8a31a26.png)

  

在沙龙上，知道创宇创始人兼CEO赵伟介绍：“我们发起FP50的初衷，是希望它能够改变整个安全的环境和生态，给成员们创造更多合作机会，做出能够真正为客户服务的安全解决方案。希望大家抱着开放的心态多交流多分享，合作共赢。”

  

![](../Images/3aaf7582846474127b004b0c14a7fbfd.png)

  

腾讯集团市场与公关部副总经理林涛也在沙龙上表示：“在产业互联网领域，各个行业的安全需求会越来越大。面对庞大的安全需求，腾讯也希望能够和安全领域众多的新生力量携起手来，共同把握机遇，探索新的安全形势，以应对未来愈演愈烈的安全挑战。”

  

**凝聚安全新锐力量，打造2019 FP50互联网安全解决方案白皮书**

  

FP50的愿景是，安全行业不光有竞争，更应该有良性发展。除了希望搭建同行业交流，和真正的安全企业家沟通，和资本对接的平台外，FP50也希望为各位成员提供展示各自的优秀产品和解决方案的机会，帮助大家获取更多的经验，少走弯路，获得发展的助力。 因此，本次FP50沙龙宣布正式启动行业优秀案例征集，并计划将征集成果凝练成《2019 FP50互联网安全解决方案白皮书》，于CSS 2019的FP50分论坛上发布。

数说安全创办人于江，中国信息安全杂志社主编崔光耀，安全牛主编、谷安天下副总裁李少鹏，北京赛博英杰公司创始人谭晓生等专家评委就新成员评选与优秀案例评选标准展开了热烈的讨论。

 

各位与会专家围绕着优秀案例及解决方案评选标准，从优秀案例的解决方案应用空间、落地效果、技术创新性等多个维度展开了深度探讨。详细评选标准将在专家评委正式商定后发布，并邀请众多企业提交优秀案例进行评选。

  

**吸纳新鲜血液  推动安全行业升维发展**

  

2018年的CSS，知道创宇与腾讯安全联合举办FP50分论坛，首创安全界“奥斯卡”颁奖典礼，秉承宁缺毋滥的原则，筛选出了代表未来安全新锐力量的30支安全企业。希望安全行业中能够以入围企业作为榜样，创新技术和商业模式，将安全行业共同做大做强。  

 

本次FP50俱乐部沙龙再次启动新成员招募，向广大安全公司发出邀请，寻找技术创新、服务能力强和拥有独特商业应用模式的企业加入FP50俱乐部，汲取更多的新锐力量，在合作交流中碰撞出更多的价值，共同推动安全行业的升维发展。

  

![](../Images/494437cf51a47315583bf0ed37da6b03.png)

  

![](../Images/6bf68ac55de85825d4d00c957d191dd6.png)

众多参会嘉宾也就评选标准建言献策

  

由资深行业专家、权威媒体、创投机构等组成的招募评审团队，将继续秉承开放、公开的原则，根据未来市场空间、商业模式匹配度、客户验证、盈利能力等标准进行多维度考查，审慎的推选出能够代表安全行业未来的新兴力量。最终评审结果将在7月31日举行的CSS 2019的FP50分论坛上揭晓，入围企业也将正式加入FP50安全新锐力量俱乐部。

 

自2018年于CSS成立以来，FP50安全新锐力量俱乐部一直致力于成为安全企业、专家、媒体、创投等机构的交流平台，探讨安全行业在产业互联网时代的合作共生。FP50希望凭借腾讯安全开放共享的理念与连接聚合生态伙伴的能力，共建安全生态，护航产业互联网升级。
