# crash\_for\_windows\_pkg 远程代码执行

## 漏洞描述

根据 Github 提交的 issue，漏洞已经在两天前上报，clash for windows 允许 xss 载荷以代理的名义提交，并不会对代理内容进行检测，可以执行任何的 JavaScript 代码

## 影响版本

版本：0.19.9 和0.19.9 之前的版本（只对window产生影响）
