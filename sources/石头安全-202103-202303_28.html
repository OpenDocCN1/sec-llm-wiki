    微服务的产生是由于以前的IT系统中出现了系统复杂性高，线上访问压力大，交付速度慢，运维成本高等等。就如下图所示，微服务就是将复杂的问题变为简单。说白了微服务就是使用一套小服务来开发单个应用的方式，每个服务运行在独立的进程中，一般采用轻量级通讯机制互联。

    微服务的特点：

  1. 单一职责。

  2. 轻量级的通信，通信与平台和语言无关(http是轻量的)。

  3. 隔离性，数据隔离。

  4. 技术多样性。

    微服务可以从多个方面去解决，比如在硬件层可以使用docker+k8s去解决，这里主要讲解在通信层中网络传输中使用RPC(远程过程调用)。

    RPC是一个计算机通信协议，该协议允许运行一台计算机的程序调用另一台计算机的子程序，而程序员无需额外地为这个交互作用编程，如果涉及到软件采用面向对象编程，那么远程调用亦可称为作为远程调用或者远程方法调用。目前比较流行的RPC框架有Dubbo，Motan，Thrift，Grpc。目前使用了Thrift和Grpc，效果都还不错。

在golang中实现RPC

  • 使用官方库或者第三方库

  • golang官方的net/rpc库使用encoding.gob进行编解码，支持tcp和http数据传输方式，由于其他语言不支持编码方式，所以golang的rpc只支持golang开发的服务器与客户端之间的交互。

  • 官方还提供了net.rpc.jsonrpc库实现的rpc方法。

RPC在微服务架构下数据交互一般对内RPC，对外REST，通过业务按照功能模块拆分到各个微服务，具有提高项目写作效率，降低模块耦合度，提高系统可用性等优点，在微服务架构下，需要将这个函数作为单独的服务运行，客户端通过网络调用。

服务端

package main
import (   "log"   "net/http"   "net/rpc")
type Params struct {   Width  int   Height int}
type Rect struct{}
func (r *Rect) Area(p Params, ret *int) error {   *ret = p.Height * p.Width   return nil}
func (r *Rect) Perimeter(p Params, ret *int) error {   *ret = (p.Height + p.Width) * 2   return nil}
func main() {   //1. 注册服务   rect := new(Rect)
   //注册一个rect服务   rpc.Register(rect)   //2. 服务处理绑定到http协议上
   rpc.HandleHTTP()   //3. 监听服务   err := http.ListenAndServe(":8888", nil)   if err != nil {      log.Panicln(err)   }
}

客户端

package main
import (   "fmt"   "log"   "net/rpc")
type Params struct {   Width  int   Height int}
func main() {   conn, err := rpc.DialHTTP("tcp", ":8888")   if err != nil {      log.Fatal(err)   }
   //调用方法   ret := 0   err = conn.Call("Rect.Area", Params{50, 100}, &ret)   if err != nil {      log.Fatal(err)   }   fmt.Println("面积：", ret)   err = conn.Call("Rect.Perimeter", Params{50, 100}, &ret)   if err != nil {      log.Fatal(err)   }   fmt.Println("周长：", ret)}

Thrift和rpc类似，thrift目前跨语言，具体可以查看https://thrift.apache.org/(不建议看别人写的，参差不齐)。Thrift文件书写：

namespace cpp TTG namespace go TTG enum ResponseState {    StateOK = 0,    StateError = 1,    StateEmpty = 2 }struct Request {    1:i32 studentID = 0 }struct Response {    1:i32 studentID = 0,    2:string name,    3:list<string> infos,    4:ResponseState state}service TTGService {    Response getStudentInfo(1:Request request);}

    生成CPP代码

thrift --gen cpp TTG.thrift

    生成go代码

thrift --gen go TTG.thrift

通过生成不同的代码进行改写，改写之后即可使用，比如下面生成C++为gen-cpp目录文件如下：
