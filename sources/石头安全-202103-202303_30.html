Mac 安装破解版burp 2021.6


资源下载

安装

先安装好Burp Suite,之后会在应用程序文件夹下创建burp Suite professional

在终端打开Burp Suite的Java 文件路径， 也可以通过应用程序-找到burp-右键选择显示包内容->Contents->java->app

cd /Applications/Burp\ Suite\ Professional.app/Contents/java/app && open .

将启动器burp-loader-x-AI.jar移动到该目录

配置Contents目录下的vmoptions.txt，添加 两行代码

-noverify

-javaagent:burp-loader-x-Ai.jar


最后的vmoptions.txt 内容如下


# Enter one VM parameter per line
# For example, to adjust the maximum memory usage to 512 MB, uncomment the following line:
# -Xmx512m
# To include another file, uncomment the following line:
# -include-options [path to other .vmoption file]
-XX:MaxRAMPercentage=50
-include-options user.vmoptions
-noverify
-javaagent:burp-loader-x-Ai.jar

激活 BurpSuite

运行app ，启动注册机burp-keygen-scz.jar

首先将注册机的License复制到BurpSuite的许可证密钥框，然后Next

选择手动激活

将第二步的信息 复制到注册机的Aptivation Request中，然后将注册机的Activation Response生成的信息复制到Burp Suite点击Next。

最后祝大家都能挖到洞

抓包测试

环境：google+ 代理插件SwitchyOmega

先测试下http抓包

burp Suite默认的代理配置是127.0.0.1:8080

如果不自定义的话，直接配置SwitchyOmega即可

HTTPS抓包

注意文件后缀der或crt

然后在钥匙串访问，从文件选择，点击导入项目

选择刚才导出的证书文件，之后信任证书

回到burp发现已经有https的流量了

总结

前面提到jdk的环境，我在安装时，并没有安装，可以肯定burp有自己内置的java环境了

mac上面环境搭建比较轻松，很方便，以后除了逆向，其他的环境都会移到mac上来办公
