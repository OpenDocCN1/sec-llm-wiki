## 安装

先安装好`Burp Suite`,之后会在应用程序文件夹下创建`burp Suite professional`

在终端打开`Burp Suite`的Java 文件路径， 也可以通过应用程序-找到burp-右键选择显示包内容->Contents->java->app

```


```
cd /Applications/Burp\\ Suite\\ Professional.app/Contents/java/app && open .
```


```

将启动器`burp-loader-x-AI.jar`移动到该目录

配置Contents目录下的vmoptions.txt，添加 两行代码

```
\-noverify
```

\-javaagent:burp-loader-x-Ai.jar

  

最后的vmoptions.txt 内容如下

## 激活 BurpSuite

运行app ，启动注册机`burp-keygen-scz.jar`

首先将注册机的`License`复制到`BurpSuite`的许可证密钥框，然后`Next`

![](../Images/cc3cc70c39e10f1c0feb704a5abe5db9.png)

选择手动激活

![](../Images/b59b87c94cf08fd027ffff2a5453716d.png)

将第二步的信息 复制到注册机的`Aptivation Request`中，然后将注册机的`Activation Response`生成的信息复制到`Burp Suite`点击`Next`。

![](../Images/c428456cf2643686fc735c3fde69d332.png)

![](../Images/b82bc7d254f83ef1c114d75040859853.png)

最后祝大家都能挖到洞
