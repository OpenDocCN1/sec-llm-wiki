## 为什么选择Markdown

*   维基百科介绍:Markdown是一种轻量级标记语言,它允许人们“使用易读易写的纯文本格式编写文档，然后转换有效的XHTML或者HTML文档”，这种语言吸收了很多电子邮件中已有的纯文本标记的特性。
    
*   它的优点可以概括为 ”轻量”，“易读易写”，“兼容性强”。

# 基本技巧

*   重点提示：在命令之后必须有空格，否则不识别你的命令
    

## 标题

*   在markdown中#的个数代表几级标题。 
    

举例

```
\# 一级标题
\## 二级标题
\### 三级标题
\#### 四级标题
\##### 五级标题
\###### 六级标题
```

编辑器中显示如下图 ![](../Images/c8b6e0524db140123ce6269be58162f9.png)

## 粗体斜体

Markdown 的粗体和斜体使用简单的命令就可以搞定，  1 使用两个`**`包含文本就是粗体  2 使用一个`*`包含文本就是斜体  3 使用`***`包含文本就是粗体加斜体

> 输入：*ST0new* **ST0new**  *若问使君才与术*，**何如？占得人间一味愚。**

```
输出  
\*ST0new\* \*\*ST0new\*\* \*\*\*ST0new\*\*\*  
\*若问使君才与术\*，\*\*何如？\*\*?\*\*\*占得人间一味愚\*\*\*。
```

编辑器显示如下![](../Images/a812ae3351ddb812249c0bc4e41ff46a.png)

## 链接

常用链接方法 1 文字连接 `[链接名称](https://链接网址)`  

> 举例输入：ST0new的博客

```
\>显示为：\[ST0new的博客\](https://ST0new.github.io)  
```

 2 网址链接 `<http://链接地址>`

> 举例输入：<https://ST0new.github.io\>

显示为 https://ST0new.github.io编辑器显示如下![](../Images/a88ec1dcb10633e1d9369342068c376c.png)

## 列表

普通无序列表  `*` `+` `-`三种格式都可以

```
举例：
\- 样式一
\+ 样式二
\* 样式三
```

*   样式一
    

*   样式二
    

*   样式三
    

普通有序列表 用`数字`表示

```
举例：
1\. 样式一
2\. 样式二
7\. 样式三 #这里写一个错误的数字，仔细观察显示
```

> 显示为

1.  样式1
    
2.  样式2
    
3.  样式三
    

> 这里提示 这里有两个贴心的帮助。  1 它会自动为你添加数字  2 它会帮你修改错误的数字

列表嵌套

> 1 列表的多段换行需要四个空格  2 列表里的引用也需要加四个空格，在`>`  3 列表里的代码段也是要加四个空格在按照代码语法

```
举例：
1\. A
    - B
        1. C
        - 前面加四个空格
2\. 多段换行
    - 加四个空格
3\. 列表的引用
    四个空格
    >前面空一行，在>之后需要四个空格
4\. 列表里的代码段
    \`\`\`语言
    前面四个空格
```

```
\## 换行
如果想要另起一行，只需要在结尾加两个空格  
\>举例：
我想换行\[空格\]\[空格\]
我不想换行了
\`\`\`xml
\> 显示为：我想换行  
我不想换行了
```

## 表格

```
举例：

|:--------:|-------  |----------|---:|
|  001  |  张三   |  写作  |  93   |

|  003  |  王五   |  社交  |  96   |
|  004  | ST0new|  篮球  |  90   |
```

> 这里注意在列和字段之间有还有一个|---|---|---|  `:`的使用，只有左边为左对齐，只有右边为右对齐，两边都有为居中
