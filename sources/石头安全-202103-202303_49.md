## 工具介绍

Immunity的CANVAS为全球的渗透测试人员和安全专业人员提供了数百种漏洞利用，一个自动化的漏洞利用系统以及一个全面，可靠的漏洞利用开发框架。你可以理解为带界面的`metasploit`。目前工具存在超过700个漏洞利用，可安装在`windows`和`Ubuntu`下。

## 安装步骤

下面介绍一下我在`ubuntu`中安装的过程，`windows`安装没有成功。

官方推荐版本：`Ubuntu 18.04`, `17.10`, `16.10`, `16.04`

我这里选用 `Ubuntu 18.04-desktop-amd64`

安装`Ubuntu` 采用`Vmware`的简易安装

![](../Images/c181abd5b0923559f469ec83b69cf65c.png)

安装镜像完成后，先不要着急安装工具，更新一下源  

备份之前的源

```
sudo cp /etc/apt/sources.list /etc/apt/sources\_init.list
```

更换源  

```
sudo gedit /etc/apt/sources.list

```

这里我换成了阿里源

```
\#  阿里源
deb http://mirrors.aliyun.com/ubuntu/ bionic main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-security main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-updates main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-proposed main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ bionic-backports main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-security main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-updates main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-proposed main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ bionic-backports main restricted universe multiverse
```

更换成功后，记得保存。之后更新一下  

```
sudo apt-get update
```

**正式开始安装工具，将工具解压到某个目录,记得修改一下文件名，后面安装时遇到文件名中有空格的会报错**

```
sudo apt-get update  这一步上上面已经执行过了，可以省略
sudo apt-get -y install python-pip
sudo apt-get -y install gtk2.0
sudo apt-get -y install python-glade2
sudo apt-get -y install python-nacl python-bcrypt
sudo pip install pycrypto
sudo pip install pyasn1
sudo pip install diskcache==4.1.0
sudo pip install asn1tools
sudo apt-get install -y python-pycurl
sudo apt-get install -y libcanberra-gtk-module
sudo pip install pycurl
sudo pip install requests
sudo pip install pygame==1.9.2
```

下一步 在`Canvas` 目录下执行。

```
sudo bash install/linux\_installer.sh
```

一路回车，等待安装完成，下来就可以愉快的玩耍了。

```
sudo python runcanvas.py
```
