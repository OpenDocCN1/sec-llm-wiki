纪念我最有效率的一次加班

原文：http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665513950&idx=1&sn=cec8efc747f6546b32a55a10ea68a9bd&chksm=80d67b9db7a1f28b29ecad0af09a713ad13d343b336409419991f27fab551a5512bccd4d31e8&scene=126&sessionid=1681664473#rd

在我10多年的职业生涯中， 我印象最深的超高效率的一次工作是加班， 还是主动加班。


那是进新公司没多久， 各种开发环境还没怎么熟悉，还是一脸懵逼的时候， 领导就给派了一个紧急的任务，有个系统依赖的SDK要升级， 这个新的SDK提供的API 和上个版本完全不同，所以我们的系统也要大量重写。


更要命的是，由于一些失误，这项升级工作已经对客户做了承诺，要在特定期限内完成（忘了是3天还是5天了）。


所以我这个“苦命”的新人被迫面对了三座大山：


1. 学习新的SDK

2. 立刻把我们的系统搞懂

3. 对系统进行重写，使用新的SDK API


那种感觉就是一个不会游泳的人一下被扔到了大海里。 没办法，只有硬着头皮上了。


任务的布置是在周四， 周五的时候我了解了现有系统的业务， 把要做的事情分析了一下，我发现也许并没有想象的那么难，因为这个系统逻辑简单，关键的部分都是在使用SDK做事情， 所以重点就是SDK。


时间紧迫，为了完成工作，也为了给领导留下个好印象，只剩下周末加班一条路。


周六睡到自然醒， 精力充沛，到外边的四川餐馆吃了一份宫保鸡丁盖饭，骑着自行车到地铁站，坐地铁去公司。


为什么去公司加班？  首先是家里太吵，让我分心的事情太多， 更重要的是内心估计是想追求一种“悲凉”的气氛， 偌大的办公室只有我一个人在那里辛苦地工作，这场景想想都酸爽。


到了公司，先冲了一杯咖啡（那时候公司还有点小福利，有点免费饮料）。  然后气定神闲地打开电脑，正式开工，先去看SDK的API文档， 学习新的SDK的用法 （这是个专属的SDK，网络上的文档极少）。


周边是绝对的安静，办公室的光线比暗， 只有我的座位亮着灯，电脑在嗡嗡作响，真是一个极佳的工作环境。


感觉把时间都忘记了，连续工作了四五个小时，除了咖啡续杯之外，基本上没怎么动窝。 没有智能手机可看，也没有上网去浏览网站，心无旁骛。


思维极为活跃，效率极其高， 一个下午的时间，基本掌握了新SDK的用法，按照文档写了好几个例子。 不仅如此，还基本上把我们现有的系统读明白了，三座大山被搬掉了两个，心里一下子放松起来， 看看表还不到6点钟， 收工回家！


周日继续睡到自然醒，中午继续吃宫保鸡丁，保持良好状态，不要过度放松，一举把第三座大山搬掉。


这是第一次（两个下午）超高效率的加班， 有了这一次的经验，以后每次遇到艰巨的任务，需要我一个人静心干活的时候， 我自然会想到周末的下午屁颠屁颠地跑到公司来战斗。


和这种加班形成鲜明对比的是长期的加班，我也经历过多次，有一次加班时间太长，导致握鼠标的右手开始疼痛，不得以切换到左手用鼠标。 那是一种完全没有效率的状态，就是机械地坚持着做事情， 没有激情，缺乏创造力，头脑昏昏沉沉，无时不刻都在盼着早点结束，早点回家，早点休息。


总结一下为什么我的这种主动加班的效率最高，无非是下面几点：头脑清醒、无人打扰、目标专注、时间期限， 缺一不可。


头脑不清醒对于脑力工作者来说几乎没法工作，尤其是有挑战性的工作；  有人不停地在身边聒噪很容易让人分神； 目标太多让人陷入混乱； 没有时间期限就容易放羊。


很多人都觉得深夜时的工作效率要远远超过平时，应该也是这个道理吧。
