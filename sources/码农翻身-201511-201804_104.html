时间是这么被浪费掉的

上午连续工作了一个半小时，心无旁骛，效率极高。


到了10点半大脑开始抗议，决定休息一会儿再继续工作，  于是到公众号看看大家的留言，回复一下。


发现有个留言在危言耸听： “ Spring 已经落伍了， 现在都用DropWizard ”


DropWizard ？ 这是什么鬼？ 真正的程序员看到新技术就像小孩儿看到新玩具一样， 肯定要扑上去把玩一番。


到google 搜索， 完了， VPN已经罢工，尝试着换hosts也不管用，  只好用百度。


读了国内的一篇文章， 大致知道DropWizard是怎么回事了，无非就是把一些好用的类库组织起来，让你快速地开发Web应用尤其是RESTful风格的应用， 和spring boot也许可以比一比。


又往下翻了翻搜索结果，发现了另外一个翻译的文章， 本着外国的月亮比国内圆的原则， 还是要看看的，不过看了以后就觉得被坑， 我想知道的原理几乎没讲。


拉到文章最后，发现一个链接：阿里巴巴 Java 开发手册评述  ,  心里不由得冷笑一声， 这不就是一个推广文吗， 还评述！


咦，这篇文章的标题很诱人啊《 Kotlin 喧嚣过后，谈谈 Java 程序员未来的出路》 ， 考虑到我之前也写过一篇Kotlin的文章， 忍不住点进去看看。


前面也没什么干货，无非就是java 生态圈软件的罗列， 不过后面的才是精华，这句话说的很好： ‘技术的更迭，有时候会来的很突然，很猛烈。但系统的更迭，往往会慢得多。’  太多的公司、系统、平台都在使用Java, 想替换掉他们实在太难。


50年后，世界上只剩下了不到100个Java 程序员， 有个叫“四十大盗”的公司核心系统就是用50年前的Java编写的， 由于这个核心系统每年还能产生巨额的利润， 四十大盗公司舍不得关掉， 现在只有这不到100个程序员能用面向对象和设计模式来维护了，于是他们像熊猫一样被供了起来，开豪车，住别墅，每天都是山珍海味。  那时候我都80多了，要是能成为其中的一只“熊猫”也就不愁养老了。  --- 白日梦的感觉真是不错


文章中提到了搜索GitHub热门项目的办法 ： java stars:>10000， 去github上试试吧。 果然好多星标项目， 小屁孩又发现了新玩具，赶紧点开看看。


排名第一的竟然是java-design-patterns ， 果然设计模式在java 世界是大行其道。  大名鼎鼎的elasticsearch还是热度不减啊， 阿里巴巴的fastjson 也在其中。。。


怎么回事，javascript的代码仓库也被搜出来了，有个有趣的项目是：clean-code-javascript， 其中一张图看了半天才明白： 原来就是Bob大叔(Robert Martin)在《Clean Code》 中提出的著名论断：

衡量代码质量的唯一标准就是阅读代码时骂脏话的次数


（这两个房间都在做code review, 从左边的房间传出的脏话WTF很少， 右边的房间就不行了）


虽然这个说法很早就知道，但是这个图从来没见过， 分享给群里的同学们， 大家一起乐一乐， 于是又在群里聊了半天。


Java 的项目看完了，要不再看看最近大热的Go 语言？   ： go stars:>10000


go , moby（就是原来的docker了）, kubernetes 等明星赫然在列， 还有一个怎么用go 做web 应用程序的教程， 这go语言能做web开发吗？  有中文版， 反正也不费脑子， 浏览一下。


其中讲到了开发工具，有一个是Visual Studio Code ， 这不就是原来Eclipse JDT的大拿Eric Gamma从IBM跳槽到微软后搞的项目吗？  到官网去看看， 真是慢！


自从2003年和微软分手以后， 好久都没有安装过微软出品的IDE了， 下载下来玩一下！


虽然只是一个带调试功能的编辑器，这Visual Studio Code 看起来挺酷的，很轻量级， 不过热门的插件中都是C#, Python, Go等语言， 我赖以吃饭的Java 还得搜索才能找到。


正准备开始折腾下Java,  猛然惊醒，已经11:59了 ！   时间怎么过得这么快！ 


漫无目标地浏览网页是最容易耗费时间的， 信息爆炸时代，网上有如此多新奇的东西，一个接一个，根本就看不完。


本来是想了解下DropWizard ， 竟然跑到风马牛不相及的Visual studio code 来了。 


我学到了什么？ 好像什么都没有！ 仅仅是对一些系统产生了印象，为以后增加了一点谈资而已，更关键的是我的工作没有按时完成，没有能在我精力充沛、可以高效率推进的上午完成， 这是个很大的浪费。


保持目标感，记住方向，把有限的时间花在刀刃上是多么的重要啊！
