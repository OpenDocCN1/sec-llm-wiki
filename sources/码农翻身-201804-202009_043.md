# 陈芳，高考之后我要学计算机专业，等我干 IT 发财了，我就回来娶你！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTc0NzExNg==&mid=2665520373&idx=1&sn=5d9f9dcd75e31d08b857cc8d5f2c20c2&chksm=80d664b6b7a1eda032e098ec59e6bafa16fe5a8b3cbd831cfcbb6727e2bb147277a964205edc&scene=126&sessionid=1681664205#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665520373&idx=1&sn=5d9f9dcd75e31d08b857cc8d5f2c20c2&chksm=80d664b6b7a1eda032e098ec59e6bafa16fe5a8b3cbd831cfcbb6727e2bb147277a964205edc&scene=126&sessionid=1681664205#rd)

***1***

又是一年高考时，许多人的命运在这场考试后改变。今年的高考是 7 月 7 日，比以往来的更晚一些。我总觉得 7 月 7 日这个日子特别忧伤，倒不是因为它是高考的日子，《长恨歌》中有云：

*“七月七日长生殿，*

*夜半无人私语时。*

*在天愿作比翼鸟，*

*在地愿为连理枝。”*

多美的爱情誓言呀，高考之后，进入大学，男孩子们就可以和自己喜欢的姑娘在一起了，爸妈和讨厌的班主任再也不会阻拦他们自由恋爱了。

可是，别忘记了，这四句诗只是故事的中篇，后面还有两句结尾：

“天长地久有时尽，

此恨绵绵无绝期。”

这就尴尬了。

  

![](../Images/4de385ac01877ec06005e35e3c9d8a36.png)

***2***

又是一次在夜里十二点拖着疲惫的身躯下班，淫雨绵绵这么多天，今天白天太阳竟然出来了，而晚上的月光温柔如水，但一想到我一个码农目前的境况来，这温柔的月光也有一种淡淡的忧伤。

我常常感叹自己：少年时不好好学习，高考不能考好，老大化作程序员。所以，如果当初努力学习，高考考个好成绩，现在就不是程序员了吧。

时光倒退十年，那个时候，计算机专业是个多么热门的专业呀。那个时候，我也是这个热门专业的中一员，带着执着的计算机科学家的梦想，在我的入学宣誓中写下：

*“让我们高举图灵伟大旗帜，紧密的团结在冯诺依曼周围，不舍昼夜的编程，为把我国计算机事业全面推向二十一世纪而奋斗。”*

于是大学四年，除了编程，我就和我的姑娘陈芳谈理想，一起展望高薪的计算机行业，一起畅享我们有房有车衣食无忧悠哉游哉的未来。

甚至，被那个程序员励志故事所感动的稀里哗啦：来拼多多做程序员五年了，娶了一个清华法学系的老婆，成长速度倍增呀，存款 30 万，在家人支持 270 万下，在上海成功买了房。多么励志的故事呀。

  

![](../Images/4569cebef15b1207ef0d31a4744e73a9.png)

***3***  

四年后那个柳絮飞扬的夏天，毕业了，我信心满满为我的姑娘写了一首分别情诗，对未来充满希望：

“*当蜘蛛网无情地查封了我的炉台*

*当灰烬的余烟叹息着贫困的悲哀*

*我依然固执地铺平失望的灰烬*

*用美丽的 C++ 写下：Debug 未来*

*当我的紫葡萄化为深秋的露水*

*当我的鲜花依偎在别人的情怀*

*我依然固执地用凝霜的枯藤*

*在凄凉的大地上写下：Release 未来*

*我要用手指那涌向天边的排浪*

*我要用手掌那托住太阳的大海*

*摇曳着曙光那枝温暖漂亮的笔杆*

*用美丽的笔体写下我们一起的未来*”

陈芳，等着我，等我干 IT 发财了，我就回来娶你！

后来呢，来到了上海，高楼大厦，腾讯喜马拉雅，美团阿里巴巴，平日只在屏前坐，周末格子间里写代码。就这样努力着，一点点去实现我们的未来，一年两年三年四年五年，在黎明的第一缕阳光里挤公交，在子夜来临之前叫出租车。到头来：

*“数年职业两茫茫，*

*写程序，*

*到天亮。*

*千行代码，*

*Bug到处藏。*

*纵使相逢应不识，*  

*尘满面，*

*脑勺凉。*

*夜来幽梦忽还乡，*

*想陈芳，*

*调试忙。*

*相顾无言，*

*唯有泪千行。*

*料得来年裁员时，*

*年终奖，*

*白瞎忙。”*

  

  

![](../Images/88c1425225d1ab7ab248e517b67ac8fa.png)

  

***4***

夜深人静时，是最惆怅的日子，看着 jira 上的 bug 数量，这个 list 好长。

想到白天 Leader 在会议室和我说的话：小方啊，由于上个月你的代码里多写了一个小数点，给公司造成了损失，所以这次升 P8 的机会就不能给你了，给你对面的小李吧。

哎，P8 是个让人心动的名称，P8 是个让人流泪的形容词，P8 是个让人羡慕的动词，P8 是个让人沉重的副词，P8 是我和陈芳的未来。可是......  

看着手机壁纸上陈芳的照片，不由得悲从中来，默默地问自己，还记得年少时的梦吗？还记得年轻时的诺言吗？曾经，我固执的认为，我可以 Debug 出一个美丽的未来，如今所谓的未来，也即将淹没在这一个个 bug 里。

记不清那是后来的哪一天了，我收到陈芳的一条消息，她告诉我明天她要订婚了。自毕业以后，忐忑了这么多年，反而在那一刻突然轻松了。这是一种解脱吗？于是，我给陈芳发了最后一条信息，默默地把她移进了黑名单：

*“谁言别后终无悔，*

*寒月清宵绮梦回。*

*深知身在情长在，*

*前尘不共彩云飞。”*

那天我请了一个星期的假，把自己关在出租屋里，玩了一个星期的仙剑奇侠传，我感觉我就是故事中的云天河，而陈芳就是柳梦璃。

原来不仅童话是骗人的，连公众号中的故事也是骗人的，不是说好在拼多多干五年，娶老婆买房一起过幸福生活吗？我在阿里都干了六年了啊，原来还好歹算有老婆，如今不仅没结婚，老婆还没了！

也许这就是生活吧，从选择计算机专业那一刻起，我们大多数人的生活和未来就被程式化了吧。茫茫人海，一片杂草，对象若是程序员，姑娘们请好好珍惜吧，他们可能不善于表达，但是他们直率、天真，为梦想、为共同的未来掉过头发。

![](../Images/449fc05736c7030343263ed97757c2b2.png)

  

***5***  

多年后，又是一个阳光温暖的初夏，午饭时分，我站在字节楼下，拨通了电话：

“*您好，您的外卖，请到楼下正门取一下。*”

对方不好意思的回复了我：

“*不好意思，麻烦等几分钟，我现在有个线上 bug 需要紧急修复。*”

“*好的，没关系。*” 我笑着说。

这是我今天的最后一单，虽然送完这单我要赶着去高考考场接女儿，但我真的愿意多等他一会儿，给他一点时间，因为我也曾年轻过。

**全文完**
