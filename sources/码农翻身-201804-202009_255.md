# 写技术文章也挺好的，虽然没有多少人看

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTc0NzExNg==&mid=2665516444&idx=1&sn=3209b6ad1ce28e7657b7bcd01f04c435&chksm=80d675dfb7a1fcc9e516d7880d1635f5194b11aa752a69b8fa7f05c44b4ef9f79f030651bb1f&scene=126&sessionid=1681664311#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665516444&idx=1&sn=3209b6ad1ce28e7657b7bcd01f04c435&chksm=80d675dfb7a1fcc9e516d7880d1635f5194b11aa752a69b8fa7f05c44b4ef9f79f030651bb1f&scene=126&sessionid=1681664311#rd)

微信改版信息流以后，正式进入了“拼标题”时代，如果没有一个吸引眼球、摄人心魄，不点进来心里就痒痒的标题，那阅读量肯定是嗖嗖地下降。 

  

偏偏我又不擅长此道，绞尽脑汁想了个自以为是10w+的标题， 结果读者的回复让人吐血：居然不是广告！ 

  

只看标题，现在广告和正常的文章已经雌雄难辨了。除非在标题上就写明：【广告】，【推广】，然后广告商会把你打死。 

  

最经典的失败案例就是这个：《[激烈竞争的时代，哪些能力可以帮你脱颖而出？](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665516132&idx=1&sn=7b2acfff6659a6aa75b6d0b343b33f69&chksm=80d67427b7a1fd31e4735b4b749af716c41b3609ca6772fcf1717bfe540ad25b6024e5796b86&scene=21#wechat_redirect)》，价值“千金”，居然没人看。

  

也有成功的案例：《[千万别学计算机](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665516406&idx=1&sn=e6642108d466268b47b118d8143bd6f1&chksm=80d67535b7a1fc235c61db117588e583163eeb47e1ee7f1b78e0878a4e2c6d408a6357b792e7&scene=21#wechat_redirect)》，《[四次面试：](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665516055&idx=1&sn=173e533567efb5ca10abe2e82aaeb3d8&chksm=80d67454b7a1fd424e853985e113c23d1b5267fefec0e23695c31ad0ce2638a1a082229a6915&scene=21#wechat_redirect)[程序员越来越悲催了](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665516055&idx=1&sn=173e533567efb5ca10abe2e82aaeb3d8&chksm=80d67454b7a1fd424e853985e113c23d1b5267fefec0e23695c31ad0ce2638a1a082229a6915&scene=21#wechat_redirect)》（居然有人抄袭我这个标题）等等，希望这篇也能成功。

  

对于纯技术文章，想起个“耸人听闻”的标题可不是一般的难，经常是千辛万苦，绞尽脑汁写出的文章，推送出去以后，阅读量半死不活，十分打击脆弱的心灵。

  

想想也可以理解，大家劳累了一天，躺在床上，坐在沙发上，特别想休息一下，娱乐一下，为什么要看你那干巴巴的技术文章呢？ 你的技术文章为什么不能搞得轻松愉快一点呢？

  

所以凡事都要先反思自己，找主观原因。是不是自己才思枯竭，江郎才尽了？为什么写不出 《[我是一个线程](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=416915373&idx=1&sn=f80a13b099237534a3ef777d511d831a&chksm=06ef67ee3198eef85a668f7197709b54bcd9508087ace8f6eaa11d34eb4e5392c5190a77d530&scene=21#wechat_redirect)》这样的10w+文章了？为什么没有《[我是一个Java Class](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=416976590&idx=1&sn=22823ada76d8cfd26a43e8d3a7b7a60e&chksm=06ec768d319bff9b905840c4679b3ea8a92485a2e8ade7f072bf94a60c5534ab9cae396e5510&scene=21#wechat_redirect)》, 《[JavaScript：](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665513059&idx=1&sn=a2eaf97d9e3000d15a33681d1b720463&chksm=80d67820b7a1f136d73b874e5784f06ef34eb38d7750712a5b9c7532ad44f18a3d43d2edbfbd&scene=21#wechat_redirect)[一个屌丝的逆袭](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665513059&idx=1&sn=a2eaf97d9e3000d15a33681d1b720463&chksm=80d67820b7a1f136d73b874e5784f06ef34eb38d7750712a5b9c7532ad44f18a3d43d2edbfbd&scene=21#wechat_redirect)》，《[TCP/IP之大明邮差](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665513094&idx=1&sn=a2accfc41107ac08d74ec3317995955e&chksm=80d678c5b7a1f1d3e122ae99f368671acb7f6baecebb6488c8ca63caa7f1ef28fea1a4dc1ef0&scene=21#wechat_redirect)》，《[CPU阿甘](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665513017&idx=1&sn=5550ee714abd36d0b580713f673e670b&chksm=80d6787ab7a1f16c39e1258d046b199c06a4dcc95dc192ff2f285be04f616a9ab891d6b3f7d9&scene=21#wechat_redirect)》这样的叫好又叫座的文章了？  

  

用故事的形式通俗易懂地讲技术，本来就是一件非常难的事情，我重金悬赏《[可能是全网最高稿酬，速来！](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665516192&idx=1&sn=06daa4e12d6bed5dd6a4dc68c4f08313&chksm=80d674e3b7a1fdf5a6d226ee52e5cc0b7aa407d8005e06517c2431467bfdd120c20a13a04ff0&scene=21#wechat_redirect)》，但到目前为止，也只有两篇能达到我的要求，例如北邮研究生王卓的文章《[码农们的聚餐，会复杂到什么程度？](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665515948&idx=1&sn=e6b2dd3f3a7ef0b93bc9dc7d2bf87a9e&chksm=80d673efb7a1faf950bbb4e437285b90ab3b16a22a22886f982fcf39235f90ebb66758f50f35&scene=21#wechat_redirect)》

  

写公众号文章和做其他事情一样，想要脱颖而出，除了坚持，还是得创新，得累死不少脑细胞，整天用脑，我估计我得老年痴呆的可能性很小。过些天我会放个大招出来，大家等着瞧。 

  

写技术文章难道就这么苦逼吗？ 

  

不，其实有很大的好处，就是能清楚地看到自己的成长，过了半年以后一看：霍，自己居然写了这么多 ！过了三年以后再看，小树苗已经成为参天大树了， 成就感无与伦比。 

  

让我感到欣慰的是，我每天需要回复的留言中，还有不少是之前的文章的，充分说明的文章长久的生命力。  比如《[我是一个线程](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=416915373&idx=1&sn=f80a13b099237534a3ef777d511d831a&chksm=06ef67ee3198eef85a668f7197709b54bcd9508087ace8f6eaa11d34eb4e5392c5190a77d530&scene=21#wechat_redirect)》它不是一下子就达到10万+的，而是这几年积累起来的，还有很多文章的阅读量都是如此。

  

追热点的文章一时爽，但很快就烟消云散（当然会赚到广告费）， 技术文章则具备长久的生命力，可以反复看，过段时间以后再看，还可以整理出来形成文集，或者出书：《码农翻身》

  

这也是本文的最终目的：码农翻身2019上半年精华。
