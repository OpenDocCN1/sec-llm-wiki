肉酱不是留学党，更非大佬，希望通过分享自己平凡的经历，能够让大家看到另一种可能。为了尽可能的夹带更多的干货，本文将以问答的形式展开。

正文开始前，请先让肉酱简单介绍下自己的背景。



从某种程度上来说，一个人的经验，也即是一个人的偏见，加之每个人背景和机遇都不尽相同。对肉酱的情况有所了解后，大家方能更容易理解部分答复的“出处”。


肉酱毕业于国内普通大学（211、985双非）本科文科专业，毕业后在外企干了几年文职工作，机缘巧合接触了编程，而后一头扎了进去，半路出家转行做了程序员。


在国内IT公司工作了不到两年后，偶遇赴日工作机会，三年前东渡来到了日本。在日本换过三家公司，目前的工作语言是英语，至于日语嘛，肉酱还在学习中。虽然语言不通，但从目前肉酱身体的各项指标来看，还算过得尚好。



为什么会选择去日本工作？



理由和我前辈流川枫一样，因为离家近啊！


最开始寻找海外工作机会的时候，也考虑过欧美，转行之前由于工作原因也体验过赴美的旅途艰辛，我现在这把老骨头，想到要坐十多二十个钟头的飞机，摸摸自己隐隐作痛的后腰眼，默默的将欧美从我的目的地名单中划了出去。



回过头来放眼亚洲，日本无疑是最佳的选择了，除此之外还有个很重要的是，来日本相对而言比较容易。


根据官方的说法，对口专业本科学历，或十年及以上的行业工作经验，就能够申请技术类工作签证。但日本在人才招募上的政策比较宽松，所以即使这两项都不达标（肉酱我便是宽松政策受益者 Orz），只要能拿到应聘公司的 offer，那基本都能拿到签证。而且日本工作签证除了不能换行（譬如，你不能拿着技术签证跑去拍片了，纵然少年你骨骼惊奇天赋异禀），几乎没有其他限制，所以你来了发现掉坑里了，随时可以重新换一个坑。



不是都说日本软件开发极其落后吗？这是要把大家往坑里带的节奏？


这的确是网上大部分过来人的声音，经过肉酱这几年的观察，大致是这样个情况。


大部分赴日从事软件开发的同胞，都踏上了两条路，大型日本传统公司，或外包派遣员工，前辈们说的的确没错。我认识一前辈，在一家日本大型银行做派遣员工，写了近十年的VBA。要换了我，早就在开工头一天连夜坐船逃回来了。😂



当然上面那位是极端例子，其他认识的大多数同行，每天也基本就是和Java Struts及数据库存储过程打交道，完全是以业务为驱动的开发，在技术层面没有任何创新和提升的机会。但是，由于我这几年都是在日本的创业公司摸爬滚打，在这条路上，又是另一番风景。


既然是技术为主的场子，我就直接来给大家罗列下待过的创业公司的技术栈吧。


前端框架：JS ES6 Vue.js, Vue CLI 3, Vuex | TypeScript, React.js, Redux, Redux Saga 


后端框架：Ruby on Rails, Golang | Node.js UI库：Bootstrap 4 | Semantic UI 


后端部署：AWS ECR | K8s 


前端部署：Netlify | AWS S3, Cloudfront 


数据库：AWS RDS Postgres | MySQL 


持续集成：Circle CI 


错误跟踪：Sentry | Datadog 


版本控制：Git, Github 


日常沟通：Slack 


任务沟通：Github issues, Waffle | Youtrack 


设计工具：Figma | Adobe XD 


文档管理：Docbase | Office 365 


远程会议：Zoom 


开发方式：敏捷开发


我接触过的中小型技术为主的公司技术栈都差不多，前端 React 居多，Vue.js 和 Angular 并驾齐驱，后端 Rails、Node、PHP、Python、Golang 等都较为常见，其中 Rails 所占份额感觉最大，DevOps 方面 Docker 是标配，上了 K8s 的也不占少数，此外服务都跑在 AWS 或者 GCP 上。



加入日本创业公司是否稳妥？


据说日本是美国之后第二大的 SaaS 市场，大家对 SaaS 服务接受程度很高，且市场竞争没有国内那般惨烈，加之日本客户忠诚度高，一旦用上了某家 SaaS 服务，通常不会无故转投他家。


因此，就肉酱的经历来看，加入日本创业公司，哪怕是很小的那种，也是比较稳妥的。在前期调研以及面试接触的时候，最好多了解下他家是否有靠谱的产品和商业模式，如果已经实现盈利的，那当然就稳稳的啦。



说点实际的，在日本搬砖能挣多少钱？


这事一言两语说不太清楚，有兴趣的朋友可看看我的另一篇文章，里面有更为详细的说明。



在日本写代码加班严重吗？


前几年日本电通公司职员由于过劳自杀，掀起了轩然大波，日本政府出台了法规，禁止加班，肉酱之前待过的日本公司，每隔几个月就会收到邮件，提醒大家认真打卡，并且不要加班，不然公司会被责罚。政策是一方面，市场竞争环境则是另一方面，肉酱待过的公司，都没啥很紧迫的需求非得加班赶工做完的。


虽然还是有不少日本人习惯性加（摸）班（鱼），在公司待到很晚。肉酱这三年来没在公司加过一天班，但回家后很多时间肉酱其实都是在工作，要算工作时长的话，绝对能达到996的级别，一方面肉酱喜欢写代码，另一方面回家后的工作时间部分都是在做知识的扩展，先天条件不好，后天还是得自己努力啊，这样如果碰到必须加班的，才有底气拒绝嘛。




听说日本是终身雇佣制？那35岁后继续写代码不是梦咯？


肉酱混的是创业公司圈，公司能存活多久心里都没谱，哪来的终身雇佣 😂。不仅没有终身雇佣，肉酱上一家日本公司，连一分钱奖金都没有发过，而加薪也是在干了整整两年后才给盼到的。


但35岁后继续写代码不是梦倒是真的，肉酱待过的所有公司，主力开发都是40+的大叔。所以对职场寿命的焦虑，在来了日本后也有所减缓。



在日本写代码的女生多吗？会有性别歧视吗？


肉酱碰到过的女开发者的确很少，性别歧视应该还好。之前就职的公司有三名程序媛，一位是日本主场的，另外两名分别来自中国和美国，日本那位小姑娘是外派员工，其实很努力，但经验欠缺了些，最后公司没有和她续约，她离开的时候还给团队上每个人都手写了一封感谢信，看得肉酱我都不忍心了。


最搞的是，反对为小姑娘续约声音最大的，是个来自韩国的程序员，日本人大多其实都很暧昧，为了维护表面的和谐，他们对平庸的容忍度很高，还是斯密达下得了重手 😂。


而对外国人日本表面都很客气，感觉顶多就是把你挤在外圈，这哪是伤害，这是福利好不好！



在日本工作社交圈如何？


肉酱没有社交圈，因此无法提供任何可供参考的信息，答毕。😂 其实这也是肉酱比较喜欢日本的一点，人与人之间保持距离，当然这因人而异，这也是很多人受不了日本的地方。



这样看来，在日本搬砖前途一片光明咯？


当然不是，如果你看了上面关于工资的答复，摆明了在日本从事软件开发，就工资这块对比国内几乎没有任何吸引力。在肉酱看来，工资高低其实还好，国内996每月挣4万，和在日本965每月挣3万不到，我相信生活的质量绝对是在日本更胜一筹。


除了工资外，还有两个坑需要注意。首先，日本软件开发面向的用户量比起国内差太远了，这导致了即使用的技术也挺新的，但复杂度和规模不可同日而语，那很有可能你技术经验值的点数会受到很大的影响。其次，要想凭借公司上市，一顿吃到饱的机会很要少很多。


日本哪类公司会从海外招人？


朕已阅，爱卿快告诉朕在哪上车吧。



知己知彼百战不殆，在我们说到怎么找赴日开发工作机会之前，先来看看哪类公司会从海外招人。


派遣公司


派遣公司，门槛最低，他们把你招来后，再派到各个日本公司驻地开发。现在日本对开发者的需求较大，而且日本公司也喜欢招派遣（非正社员）员工，所以这类机会应该也是最多的。前段时间听一位肉友说，只要人在日本，不会开发都行，外派公司负责培训并把你派出去。


具体情况到底如何呢？说实话肉酱也太不清楚，有个朋友就是通过这个机会来的日本，他的情况也还好，被派到一个制造业为主的日本公司做后台开发，一干就是五年，税前好像是四十多万日元的月薪。因为是制造业公司，所以工作时间很固定，每天五点就下班了（早上八点开工），周末也从不加班，但要想在技术上能有很大的提升估计就有点悬了。


一线大牌公司


真大佬当然是指哪打哪，真大佬的世界肉酱也不太懂，抱歉无法提供更多的信息。


日本创业公司


现在越来越多的日本创业公司也开始面向海外招聘了，日本人口虽也过亿，但对于野心比较大的互联网公司来说，市场规模还是太小，即使没有确定的业务机会，不少日本创业公司为了扩张也好，为了更好的融资也罢，都在进军海外市场，既然要进军海外市场，那团队结构也需要多元化咯，因此也为大家提供了机会。


去这类公司即使对方对日语不作要求，但最好还是能具备基本沟通的日语能力，因为日本人的英语的确不算好（但他们基础大多还挺好的，日常简单沟通能应付），不然工作开展起来会很吃力。


国人创办的公司


肉酱也有碰到过一些由在日多年的有为中青年创办的公司，其中不乏技术驱动的小而美公司，但待遇貌似都不算太高，当然生活肯定还是足够的。而且和同事们没有语言沟通的障碍，碰到聊得来，产品靠谱的，其实也不失为一个选择。


老外创办的公司


和上面的国人一样，也有不少欧美人在日本创业，这类公司待遇、工作时间和环境都还不错，而且不少对日语能力也没有要求，英语能沟通就行。


还有朋友询问英语六级 hold 得住不？大学英语考级和实际语言能力没办法划等号，只要你能用英语无障碍沟通，零级也行，反之，八级也白搭。


除了语言外，这类公司对技术的要求都比较高，应聘这种公司，出彩的 Github 开源项目是最大的加分项。


别再耽误了，快告诉朕在哪上车吧！




Indeed 和 LinkedIn 是两个最大的聚合信息源。其次就是各个公司的招聘页面，譬如 Rakuten Careers, LINE, Google Careers, Amazon


还有些比较小众的信息源。Wantedly.com，上面有不少日本创业公司，他家的特色是社交招聘，如果你在上面有朋友，时不时会收到这般的推送信息：



肉酱也搭了个简单的静态页面 japanjobs.dev，随时都在上面分享一些招聘信息，以帮助到有缘人。



结语，关于选择


就我来说，之所以选择出来工作，一来是想换个环境。上学时候不具备这个条件，好歹成年了，选择权在自己手中，因此想体验下异国他乡工作、生活感觉。在我决定来日本前，一位朋友语重心长的告诫我，说我这要错过了国内发展的高速列车，等将来想回来的时候估计会后悔哦。


我为数不多的优点之一是有自知之明，以我的背景和能力，即使身边有高速列车飞驰而过，我也不认为自己能有抢到车票的可能性。还不如退而求其次，争取多搭乘几趟不同的车，即使并非一路向前，但我一定会珍惜沿途的风景。


肉酱会一直留在日本吗？Hmm，计划没有变化快，目前还没有考虑那么远。但最终应该还是会回国吧，毕竟那是家。对于像肉酱这样家中无矿的普通人来说，在哪都得努力工作养家糊口，所以在哪不会有翻天覆地的差别。


这次记者会就到此结束，如果诸位还有其他问题欢迎添加我的微信。大家伙，努力吧！努力的同时不要忘了一定要善良，善待他人，善待小动物。
