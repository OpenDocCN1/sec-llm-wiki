这些优秀的年轻人

我写公众号小有名气以后，问我问题的人越来越多，有很多问题都是类似的，背后的原因主要是缺乏目标、不能坚持、找不到方法等等。


回答这些问题很容易变成鸡汤，最好是找些榜样来现身说法，这些榜样都是普通人，也许就是你的同学，或者就是坐在你身边的同事。他们是怎么突破这些困境的？怎么确定目标并且全力以赴地前行的？ 大家可以看一看这几位优秀的年轻人。


王镜鑫 


王镜鑫在三周的时间内"收割"了三家大厂的Offer：美团、百度和阿里巴巴， 最后选择了心仪的阿里。 他的故事在《大牛是怎么炼成的？》


他上大学时就明确了目标，要进入大厂，以此为驱动力，疯狂学习。 刚开始只是在应用层做项目，通过外包赚钱，后来才意识到：基础不牢，地动山摇。  “我在最该向下扎根的时候，却选择了向上生长，而且长得都是叶子。”


他的关键词是： 方向，坚持和努力。


看看他有多努力： 


 “医院的条件很艰苦，没有网，我跟我弟弟挤一张小病床，我爸在楼下陪护我爷爷，晚上根本睡不好，没有条件，创造条件也要复习，于是用自己手机开热点，把剑指offer上的题目刷完了，还刷了几套往年编程题。”


“恨不得一天24小时有25个小时学习，最多的时候我记得同时看四本书，早上看《代码的未来》这种闲书，上午看《看透SpringMVC》，下午学习《深入理解Java虚拟机》，晚上学《HTTP权威指南》。”


echo_陈


作为一个只会CRUD的普通程序员，常年与业务打交道，一套花式SSM框架三板斧从头玩到底， 你肯定会觉得无聊，迷茫。


其实机会就在眼前，需要你去思考，去发掘。 更重要的是，你发现了问题，要能去解决它，解决的过程可能会很痛苦，不断地加班，扛住压力。


echo_陈的故事《程序员应该如何自我驱动，迅速获得成长？》 就是一个很好的案例。 


他最早也是CRUD程序员，然后被拉去做运维，后来把系统架构，技术全貌看得清清楚楚，不但发现痛点问题，还加班去写程序解决，最终在公司建立了自己的技术影响力。


说白了，就是自我驱动，拿出创业者的心态去做事情，最终结果会让人大为吃惊。 



developerHaoz  


他拿到了腾讯、阿里和 CVTE 的实习offer，最终选择了腾讯， 后来转为正式员工， 他的故事在这里《春招收获阿里腾讯实习offer，学习、面试经验分享》


developerHaoz  的特点是非常善于构建自己的知识体系，然后各个击破，慢慢完善。他是做Android， 把自己的知识体系总结出来就是这样：

Java 和 Anroid 基础 

计算机网络 

操作系统 

设计模式 

数据结构和算法 


除此之外， 他还擅长“寻找自己的兴趣点，并将其培养成自己的瑞士军刀”， 比如他就对“「Android 网络」、「图片加载」这两方面的知识就有很大的兴趣”， 最终发展出了 「能超过绝大部分人」的技能， 顺利通过面试。


闪客Sun


你加入一家公司，发现文档很少，或者严重落伍，根本没法看，老员工很忙，没时间给你讲解，很快就要深入开发了，这该怎么办啊？ 


闪客孙就遇到了这种悲催的情况。但是他并没有抱怨，而是积极想办法，在一个多月时间里，靠自己的力量居然熟悉了大概十个项目，并且总结了一套方法论出来！  


他是怎么做到的？ 详情在《没有文档，没有老员工讲解，悲催的新人如何快速熟悉一个新项目？》


关键词： 积极，方法，耐心


不要和我抢鸡腿


这是一个程序媛， 从化工转到计算机，选择了IT，选择了运维。 她的故事参见《跃迁：化学系女生的工程师之路》


她在转行的过程中，展示出来这些优秀的特质：

找大神取经，得到一个全局观

制定学习计划，坚决执行，每周写总结

单点极致， 和developerHaoz 的瑞士军刀理论很像。

自我驱动


关键点还是坚持：“我曾经也是一个很浮躁的人，每周都要去到处玩到处耍，但学IT以后我觉得我整个人都沉下来了，每天三点一线宿舍休息教室上课小房间自学，后来发现，坚持着坚持，慢慢的就迈过去了。”
