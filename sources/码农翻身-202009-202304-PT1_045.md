# 上班第一件事：马上卸载这个恶心的软件！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTc0NzExNg==&mid=2665539211&idx=1&sn=cfc82848a26f32907cb440f429aa5d65&chksm=80d61ec8b7a197dec4da12a940d60ef2726ae3212e49cab6cc0259cc59ef1d9946faa132b1d7&scene=126&sessionid=1681663962#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665539211&idx=1&sn=cfc82848a26f32907cb440f429aa5d65&chksm=80d61ec8b7a197dec4da12a940d60ef2726ae3212e49cab6cc0259cc59ef1d9946faa132b1d7&scene=126&sessionid=1681663962#rd)

一上班就被Notepad++给恶心到了。

  

![](../Images/1a3492800bff46988eed384f7c6c614b.png)

  

“如果不同意政治观点，就在你的源码中添加随机字符。”

  

这个Notepad++作者侯今吾真是把自己当做大人物了啊？！

  

率性而为，根本不再考虑用户的感受了。 

  

这个Twitter帖子很快就被一片骂声淹没，这厮意识到事情不对头，很快发了另外一个帖子，辩解说这这是一个玩笑。 

  

![](../Images/b5c81c596a1a67512a086b8d5b9671c6.png)

玩笑？能这么开玩笑吗？

  

这恐怕是作者侯今吾脑子里一直在想的事情吧！

  

侯今吾不是第一次出来作妖了，从08年北京奥运会他就开始上窜下跳，各种事件他都要跳出来：

  

![](../Images/876c1bc6a3fab59f855b0ab6858f13c3.png)

![](../Images/29c0373976a62499b15a2db0761741b0.png)

![](../Images/3d17bd6c2e4b07a37c03e3b3e7bf50c9.png)

  

再看看他今年发的关于春节的言论：

  

![](../Images/98ada121cd06f8af9b18726db532ad33.png)

一个程序员，不好好地搞技术写程序，却利用自己的开源软件，不断地夹带私货，抵制这个，支持那个， 现在竟然冒出了“如果不同意政治观点，就在你的源码中添加随机字符。”这样的狗屁逻辑。

  

这样的软件，就是开源界的毒瘤。

  

如果你的机器上还安装着Notepad++，如果你还不知道Notepad++作者侯今吾的各种恶劣行为，看了这篇短文以后，建议上班的第一件事就是：**卸载Notepad++！ **

  

![](../Images/8b13074d13ed503d266ba17377fbf960.png)

  

这样的软件，让它远远地滚开吧。

  

对于程序员来说，文本编辑器替代品还有很多：

sublime text

Notepad3

CudaText

SciTE   

VS Code

...... 

完全不用在Notepad++这棵树上吊死。

  

对了，Notepad++的官网已经打不开了，希望它就此永远地消失。

  

（完）
