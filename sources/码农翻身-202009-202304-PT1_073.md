在[上一篇](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665538297&idx=1&sn=4d8dd6177ecf69b272c5cf33bdd76962&chksm=80d61abab7a193ac1165bcc40f8c1ca20b44f1314a9d83fcb7cc23b7a8ca8a10627d18a412c1&scene=21#wechat_redirect)中，我们介绍了编程语言早期的三巨头。[![](../Images/5ba3b2837e3e9e00ccef5bab295fd867.png)](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665538297&idx=1&sn=4d8dd6177ecf69b272c5cf33bdd76962&chksm=80d61abab7a193ac1165bcc40f8c1ca20b44f1314a9d83fcb7cc23b7a8ca8a10627d18a412c1&scene=21#wechat_redirect)

虽然他们面向的领域不同，但是都有一个共同的特点：**由大型机构或者委员会设计出来的。**

进入70年代，随着小型机和PC的诞生，人民的力量崛起了。

让我们先把目光转向达特茅斯学院。

![](../Images/79140a812f57b1551b8fe06cd39092da.png)

这门新的编程语言就是大名鼎鼎的BASIC。

![](../Images/3250bd6ebf7e40c9925da4baec5f5459.png)

BASIC正如其名，初学者的通用符号指令集，很简单，一看就懂。

![](../Images/6f505db27cdb842a9108a61d54b83e5c.png)

后来，它作为启蒙语言，成功地让很多人都走上了编程的道路。

![](../Images/1264083f6a04247eaf382b4b5025b921.png)

不过，当世界上第一台个人计算机 Altair出现的时候，Basic遇到了遇到的难题 ：内存不够。

![](../Images/496f353055999554d1ab7be16fbc20d8.png)

从Altair身上，比尔·盖茨和保罗·艾伦看到了巨大的商业机会

![](../Images/56635eec1b3bc2e1cb34c8ad72352b9c.png)

![](../Images/941b6114abbf2a6c31015cf3f1b7f547.png)

虽然两人在湖畔中学的时候实现过BASIC的解释器，但那是在PDP-8小型机上，内存够用。

现在要在PC的4K内存以内实现BASIC解释器，是个巨大的挑战。

![](../Images/2844dd8f018ba2062e6add7115466eab.png)

经过几周的疯狂编程，他们俩完成了 4K BASIC解释器，这就是著名的Microsoft BASIC 的第一个版本。

![](../Images/3e4db8f6001c07ebcdaa9adecbf72caa.png)

盖茨是个商业奇才，他后来成功地说服了很多电脑制造商，把Microsoft BASIC置入他们的电脑。

最后连IBM PC都包含了BASIC编程语言，BASIC从此走向世界。

![](../Images/339e41aee82323b6755f27adcf7d651d.png)

就在BASIC发明不久，在遥远的瑞士，苏黎世联邦理工学院的 Niklaus Wirth教授也在考虑同样的问题

![](../Images/78fc73bc106a4637e415f0daf112c7f7.png)

Niklaus Wirth 决定简化ALGOL，创造一门新的语言，既适合教学，又适合编程。

![](../Images/22bf33c552cb75eb9c2031c630a31429.png)

新的语言被命名为Pascal ，这是为了纪念法国数学家、物理学家、哲学家Blaise Pascal

![](../Images/688a2c8978dfb295a5ceffa8d1fc4b38.png)

为了让Pascal能在各种机器上运行，而无需从头儿写编译器，Niklaus Wirth想了一个非常超前的主意

![](../Images/8a971aa5cdf76e85a287bb73cc6b1d19.png)![](../Images/20e97abfd0567fe31b0c7170a50ff0a1.png)

俗话说，一山不容二虎，BASIC和Pascal开始了争取统治地位的终极对决

![](../Images/d620e7641ad1717c60ced8ca4a9f0e44.png)

就连伟大的Edsger Dijkstra 也加入进来。

![](../Images/18ac508cf9c6c46bb681f9b37e2858a8.png)

1983年，那个“[养活了四代程序员](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665524058&idx=1&sn=ed099878c655a6fcb9ef4b6f18493a47&chksm=80d65319b7a1da0f9c2bbcb6aebe8fa6789da3d00c2dc35029f1c466e9bc75fd01403cf3f7b8&scene=21#wechat_redirect)”的男人Anders Hejlsberg，制造了一个“核弹”，彻底改变了战局。

![](../Images/b7112ad7ce026f97f87273cfb3854a11.png)

不过靠Basic的发家的微软绝不会袖手旁观，它借助自己Windows图形界面的优势，对Turbo Pascal实施了降维打击。

![](../Images/bf70fd95183acafa24336105ab8b889b.png)

Pascal 则被Anders Hejlsberg升级为Object Pascal ，加上Delphi这个IDE，最终和VB杀得难解难分。 

![](../Images/1f0f69992605144a0d770ac5da1c5968.png)

Visual Basic 不但和Pascal开战，还在互联网时代摇身一变，四处出击。

![](../Images/a7718145f4a9d9a72068c4314d59145b.png)

![](../Images/ee98902dc099da726402e3c2b8a8e75e.png)

当BASIC和Pascal打得不可开交的时候，它们并没有意识到，贝尔实验室的两个天才正在打磨两件利器

![](../Images/9440b1eede71bf720cdd0139dafeaa4c.png)

  

Unix 和 C语言一经问世，便受到大家的热烈欢迎，迅速传播。

![](../Images/8692aff20f399dcd312840512f00ec11.png)

C语言真的不在乎应用软件吗？它能击败Basic和Pascal ，占领全世界吗？
