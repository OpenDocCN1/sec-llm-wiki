# 漫画 | Oracle 被新时代抛弃了吗？

1977年，33岁拉里·埃里森厌倦了打工的生活，和两个小伙伴一起开始创业了。  
![](../Images/f92005200cce70587901163f4423e262.png)  
拉里·埃里森曾经做过美国中情局（CIA）的项目，建立了良好的关系，这一次，他又从CIA拉来了一个咨询项目![](../Images/b3f5eca482abc3aac0c12b23601ab7d7.png)  
在做CIA项目期间，拉里·埃里森敏锐地意识到，商业数据库市场将会有大发展，公司要向这个领域进军。  
而天才的程序员鲍勃·迈纳更是不负众望，用汇编语言开发了第一个版本的关系型数据库。  
![](../Images/d9ca809c09833967510b0d5fd60a0a54.png)  
就这样，著名的数据库Oracle登上了历史舞台。  
实际上，关系数据库的发明人是蓝色巨人IBM。![](../Images/68a3197dbf288671ebc1fae1511ede1f.png)IBM迅速行动起来，1983年推出了DB2。  
但是在很长一段时间内，DB2只专注于自家的大型机市场，这给了其他数据库发挥的空间。![](../Images/a1d3b1211be00b60d008fd42fbee3bb4.png)  
80年代和90年代中后期，正是客户端/服务器架构（C/S）盛行的时候。![](../Images/922b2bc9cac848cb2532c24c8f798c14.png)  
在Unix和Windows市场，几大数据库展开了混战![](../Images/1f26e6c1ebedeb979e91edebee1d05d4.png)  
Oracle凭借技术领先的优势和激进的销售策略，成了市场老大。![](../Images/6d2f2e44494593edfe6d383ac469111f.png)  
互联网时代来临，开发网站，大家的首选依然是稳定，强大的Oracle ![](../Images/997fcbc14abe8b6c562bc9cb70e32589.png)Oracle DBA含金量极高，绝对的高薪职位![](../Images/977fe08be1c505df9ce4f135863000ac.png)  
可是，Oracle 很快就发现，互联网时代的数据和C/S时代完全不同。![](../Images/4a2f29688faabd6af91c91a129a8b404.png)  
除了流量大之外，还非常不平均，经常有突发事件让流量暴增![](../Images/c14f4c144571d1d513b2c9be32881c44.png)![](../Images/b6f9d81183ea76c16d3aaf3bdcdcdb73.png)![](../Images/0ccd268286fc32fcdca4ab5769d478fe.png)![](../Images/b7f00adfc3e642676412e4639a13f102.png)  
互联网有很多应用对数据的实时性要求都没那么高，晚一点儿看到不成问题。![](../Images/8d4e610e61bb63a77284629d296c43f9.png)  
不过，设置MySQL读写分离，Redis集群这样的操作对于中小公司也是很大的负担，云端的数据库出现了。![](../Images/4f0d73d0bdb0091e55bb8ab3f37fe5c1.png)  
随着Web应用的不断发展，互联网应用还出现了各种稀奇古怪的格式![](../Images/386f23c57c0cdb7358b2d7457b62e5f2.png)![](../Images/8bc24f155a82700ccbf4246e5648b22e.png)时间过得飞快，物联网时代已经开启，之前只有手机、电脑可以联网，以后所有设备都可以联网了。![](../Images/37ac314083f854d3eaa399d751f73983.png)  
这些物联网设备记录的数据可能是这个样子  
![](../Images/d37bc68b1ee9dddafb799b714876b092.png)  
这些数据和**时间**有密切关系，随着时间的推移会不断累积，每天可以达到TB,甚至PB级![](../Images/d684b7598cf39b2343ac0f2bf34f4465.png)  
这些数据的处理方式和关系数据库有着截然不同的特点，它们被称为“**时序数据**”![](../Images/43730a4ee14cd1b7862c6b6ecb3c46f0.png)![](../Images/c05f3ee2759e327cfb9742d1afbc063a.png)  
Oralce从单机时代起步，经历了C/S时代的辉煌，在互联网时代、云计算时代慢慢走下神坛，万物互联时代，难以上演王者归来。  
但是，关系数据库的基本盘依然存在，很多传统行业依然是Oracle的忠实用户。![](../Images/73ba42df5b7807c03a95c9ab78a20462.png)未来会如何，让我们拭目以待吧！  
（完）
