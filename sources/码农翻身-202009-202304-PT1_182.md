# 二本学生四年的求职经历

1.  从小县城来到大城市什么感觉？

高三以前，我都是在重庆的一个县城里生活，距离主城区有四小时。我去过最远的地方也就是重庆。

后来要到上海读大学，心想着要去大城市了，还满心激动。入学当天竟然发现学校门口立了一块牌子：保护森林，人人有责。校区在大上海的大郊区，要啥啥没有，去市区单趟就需要两个小时车程。红色圈起来是我们校区的位置，真的很远，而且交通不方便。

![](../Images/b43ecf48df0b56ba1a93cf6f591ddac0.png)

  

2.  人生第一桶金

上高中的时候，我就非常渴望挣钱。大一就和学长一起去必胜客兼职。早上6点30起床，坐7点的班车到市区。9点钟开始上班一直到晚上6点，又去赶回学校的班车，到宿舍已经9点。这强度不小于996，起初两个星期确实很累，后面慢慢就习惯了。在必胜客当服务员，一个小时好像是20块钱左右，记不太清具体数字。反正我每个周末都去上两天班，坚持去了一个学期，共收入了4500块钱左右。现在觉得这点钱很少，当时拿到手还是非常开心的。

![](../Images/3e4a42289c9863e02455be7978ffaf12.png)

  

3.  大学第一个转折点

我的专业是软件工程，服务员当然不能长期做。到大一第二学期，了解到学院计划参加 CCPC。一共要选拔出来９个人，到隔壁的 985 学校一起去培训。这时候我觉得机会来了，知道这个比赛含金量很高，想拿个奖对以后找工作有帮助。在顺利通过了学院内的选拔时，我真觉得我的人生快要起飞。

但是在培训中不是想的那么回事，大家都是自学，偶尔会有人来分享一下做题经验。对于我这种零基础的学生，有人分享我也听不懂。虽然没有效果，但是我还是坚持在去，心里想的是：量变决定质变。

学院在将我们和 985 大学的培训老师对接之后，几乎就消失掉了。原以为后面会安排我们报名比赛，但是并没有。

再后面ACM圈子的沃老师在秦皇岛举办了冬令营，我找家里要了3000块钱，和同学一起去秦皇岛参加算法冬令营。七天的题目都是偏难的，冬令营的目的是将银牌选手实力提升到金牌选手。所以很多大佬都只能做出一题两题。而我这种菜鸟，直接被劝退。前两天去了教室，后面５天直接躺宾馆不再出门。在秦皇岛的七天，我终于认清楚了自己。自己不适合继续参与到竞赛中，也消沉了一段时间。不过还是得感谢沃老师给了认识众多大佬的机会。ACM圈里的朋友，后续求职大部分都是各大厂 SP/SSP由着挑，有机会还是值得去试试的。

![](../Images/60ccdb0ff1eb9678021c7cea6cd265b2.png)

从求职的角度来说，这段时间其实是没有太大的收获的。学了一年半，就会做一些简单的算法题。从人生的角度看是值得的，这是自己做的选择，也让我看清楚，我只是一个智商一般的普通人，要做适合自己当下节奏的事。量变决定质变，也是在适合自己的节奏下，没有这个前提，死磕就是浪费精力。  

4.  第一份开发工作的实习

大一大二就这样过去了。那时我经常会看一些博主的公众号，像张哥，冯老师，caoz 等。得知了一份正经的实习对求职有很大帮助，于是我开始学习一些基础的开发知识，准备去找一份实习。恰好学校旁边的工厂需要实习生。是的，是正儿八经的工厂，生产厨卫用具的。

![](../Images/a5fdbcc3c522e5294f24ec4329f9489c.png)

这家工厂需要一名计算机专业的实习生，找到了辅导员。因为我平时学习还不错，辅导员就让我去试一下。我在之前做了准备，学习了一些计算机的知识，在面试的时候顺利通过。

我拿到了第一份实习工作，一周 400 工资。工作内容是做一个 excel 的对比工具。因为厂里只有一个程序员，他是做 C# 的，我想用 Java 搞，以后对求职有帮助，所以就没人带。科勒是一家外企，每天 8.30 上班，下午 4.30 准时下班，我一个人埋头干了几个月，勉强完成了工作。  

这一段工作经历是大学生活的第二个转折点，虽然工作内容没有太多的亮点，不像很多大佬大二大三能去大厂实习。对于我这样一个普通人来说，其实很不错了，有一份开发的实习，每个月能领点零花钱工资。

5.  疫情到来

在这家厂实习一个多月的时候，放寒假回家，紧接着就是武汉疫情的到来。因为武汉疫情扩散很快，都只能在家里待着。打听到科勒的正式员工的工资只有 7、8千，我一边做这个 excel 工具，一边在想我的出路。当时在知识星球看到 caoz 老师说，疫情会带给某些人机会（找不到原文了，大概意思是这样）。我就在琢磨，带给我的机会是什么？居家隔离，有的是大把的时间啊，于是我开始学基础知识，刷面经、刷 LeetCode，背八股文（当时还没这个说法）。我是坚定的不考研者，所以求职是大学最重要的事。

在五六月份，我的目标是找一份知名互联网公司的实习。投了几十家公司，阿里腾讯百度字节美团滴滴拼多多，你能叫出名字的公司我都投过，但是给我面试机会的一家没有。这两个月挫败感很大，拿到的实习 offer 都是很小的企业。

6.  重要转折

六月底的时候，有个途虎养车的 HR 打来电话，问我是否还在找实习。电话里我立马答应了下来，然后去搜了一下，这家公司貌似还可以，有几千人的规模。于是开始等待第一轮面试。等待过程中我还是在网上看一下 Java 相关的面试题，知识点。然后在面试的时候，我发现一面面试官问的问题竟然和我这几天看的资料一模一样，当然，我对答如流，成功进入二面。二面问了一下在外企做的那个 excel 工具，发现没什么技术含量，就做了两个算法题。第一个题目是走迷宫，一个是快速排序。我在准备参加 ACM 的时候，是学过一段时间的搜索的，所以走迷宫我给出了 dfs 和 bfs 两种解法。快排当然也是必须得会的。就这样我成功拿到途虎养车的实习 offer。

![](../Images/f3fee1db6f826748327151aff37b8d14.png)

7月初，在疫情稍微好转的时候，我就急急忙忙去了上海，开始我的新实习工作。因为我要租房，之前联系我的 HR 整租了一套房子，他被某个室友鸽，我去租了这间卧室。平时和他一起上下班，了解到当时他之所以安排我面试，是因为我有一段实习经历，而别人的简历上都写的课程设计。进了公司，一面面试官是我的直属 leader，坐他旁边看他面试别人。我发现他面试拿的那份资料就是我看的那份资料，怪不得题目相似度那么高。

7月到12月，在途虎实习了半年时间，组内任务多，但是招不到合适的人，实习生当作正式员工用，工作压力很大。而且有经济压力，实习生是 150 元一天，一个月上满 22 天也只有 3300 工资，学校有些课的老师不好说话，我没法全身心投入到工作中，很多时候都拿不满 3300。给完房租就剩不了多少钱了。于是熬到签完三方，我就提了休假申请，休半年，到正式入职再过来。正式入职后的薪资是 16.5k，此时已经很满意了。

7.  更上一层楼

结束了在途虎的实习，学校也放假。现在我又有了大把的时间，心里想着要好好用起来，给自己充充电。在家休息时，发现牛客网很多大公司在补招，我又开始了求职的生活。不过这段时间压力不大。已经有了保底的工作，没有更好的工作机会也没关系，起码毕业了还是有地方去的。大家都知道 Java 很卷，所以补招基本上都是前端、客户端这类岗位，很少能见到 Java 岗。由于在途虎有半年的实习经历，这次补招顺利很多。21 年 1 月份拿了 3 个 offer，选了一个平台最大、钱最多的岗位，也就是我现在工作的这家公司。不过岗位不再是后台开发，有人会觉得从后台转到客户端，对未来发展不好。我个人其实无所谓，哪个岗位都是干活，都是打工人。我相信踏踏实实地干，也能有很好的未来。

![](../Images/e166a454e2b4c36468bb0822d24062ce.png)

  

8.  总结

从大一开始，我就不停地在寻找自己的职业方向。有没有走弯路不重要，关键是不要停下来。必胜客那段经历只是一个小的分支。真正从工厂一周 400 的薪水，到 16.5k 的月薪，再到 30w+ 的年薪，都是一步一步走出来的。没有厂里那个 excel 项目，途虎的 HR 可能也不会给我面试机会；没有途虎那半年的实习经历，也就没有现在这份工作。

当然大学四年不只有求职，遇到了人生另一半，交到了深厚友谊的朋友，也更能接纳自己。本文只分享一下我的四年的求职经历，希望对看到文章的你有一些启发。你的经历和我一定会有差异，每个人有属于自己的人生节奏，干好自己手里的事，把握好节奏。

在一个好时代，我们都有未来。
