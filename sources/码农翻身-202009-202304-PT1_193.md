# 顶级代码女神，编程界最有权势的女王

今天三八节，按照惯例，我会写一篇女性程序员的故事， 去年的那一篇《[我所尊敬的三位女程序员](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665525137&idx=1&sn=0ab801c96b10c3c799955a37bc07fdc3&chksm=80d657d2b7a1dec4e639788c35d7ba22546e7d827fa253aaffa14c1b0fdd5752aa82b30fe66a&scene=21#wechat_redirect)》引起了很大的反响，没看过的同学可以看看。  
今年介绍一位在编程语言和编程工具界可能是最有权势的“女王” ：微软全球副总裁Julia Liuson（潘正磊）。  
![](../Images/74258f26a4740dcc92bb57d73d5b36ed.png)这个名字对很多人来说可能默默无闻，但是如果我说一下她麾下的牛人和产品，你肯定会发出惊叹。  
直接向Julia汇报的都是一些让我们仰望的超级大神：**1\. Guido van Rossum**  
Python之父，仁慈的独裁者， Guido 2020年11月加入微软，目前在微软带领一个小组，致力于Python性能的提升。  
**2\. Erich Gamma**  
经典书《设计模式》作者GoF之一，曾任Eclipse架构师、JUnit作者、最流行的编辑器VS Code负责人。**3.Anders Hejlsberg**  
世界上最快的Pascal编译器 Turbo Pascal作者、Object Pascal /Delphi 架构师、C#发明人、TypeScript的发明人，“[一个养活了四代程序员的男人](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665524058&idx=1&sn=ed099878c655a6fcb9ef4b6f18493a47&chksm=80d65319b7a1da0f9c2bbcb6aebe8fa6789da3d00c2dc35029f1c466e9bc75fd01403cf3f7b8&scene=21#wechat_redirect)”  
据说Anders Hejlsberg在微软一直是一个人在工作，没有管理任何人，不知道是真是假？了解详情的同学可以留个言。  
Julia 之前掌管着**Visual Studio 、.NET Framework、VS Code、TypeScript、****Microsoft Azure开发者平台**等业务和软件开发，可以说，微软所有的编程工具和编程语言都在她的掌管之下。  
2021年11月，Julia成为微软开发部门的全球总裁，又把**GitHub**业务纳入自己的领地。  
![](../Images/84c633d0fa143cb4aa7eebde0771094a.png)带领一个超3000人研发团队，做出让全球将近四成的程序员爱用的开发工具和编程语言，以及超过六成程序员喜爱的开发框架，所有说她可能是编程界最有权势的“女王”应该不过分吧。（注：信息来源引用自 StackOverflow Developer Survey 2017）  
Julia是目前微软职衔最高的华人女性，也是一个一线出身的程序媛。  
她1970年出生于中国上海，在北京读了小学和中学， 她的妈妈就是一个工程师，所以受到影响的Julia也进入了STEM领域， 与1991年获得华盛顿大学电子电器工程学士学位。  
![](../Images/569cf14a091ef796300cd18b11e60617.png)  
毕业后即加入微软，开发Access（还有人记得这个桌面数据库吗），后来加入到Visual Studio 的前身Visual InterDev做开发。  
  
![](../Images/b599d609f22a8db1b2aac16eca417dcf.png)随后Julia成为Development manager，Partner Product Unit Manager for Visual Basic， Visual Studio Team System的核心领导， 一路升迁至今。  
2019 年，Julia 进入了Women in Technology International的技术名人堂。  
在一次直播中，Julia给女程序员提了两个建议：  
1\. 要有自信和自我认可，在团队用要勇于表达自己的意见，很多时候不表述意见，别人也猜不到你在想什么，会认为你没有想法，这对职业发展是非常不利的。  
2\. 敢于据理力争，你认为是对的，要以合适的方式和团队做商讨，而不是躲在后面不发声。  
其实这两点对于男程序员也是完全适用的，尤其是对中国的程序员。  
最后，向了不起的程序媛们致敬！女神节快乐！
