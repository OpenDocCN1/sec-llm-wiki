夜深了，张大胖躺在床上，翻来覆去睡不着。


今天下班的时候经理把自己找去，告诉了自己一个坏消息：绩效小组垫底，3月的年终奖金应该是没有了。


张大胖心中愤愤不平，自己这一年辛辛苦苦，任劳任怨，经常加班，成果突出，居然落到了这么一个结局！ 


就是因为自己年轻，入职时间短，赶上了公司绩效改革，学某大厂搞什么狗屁361，自己就成了那个1，背了黑锅。


想到这里，张大胖一咕噜爬起来，上网修改简历。


明天就投简历，立刻离开这个鬼地方。



第二天张大胖早早起了床，打开电脑浏览各大招聘平台，发现各类网站五花八门，但还是一个个的去注册上传简历，东看看西看看找到几个觉得不错的职位进行了投递。


几天过去了，投递的简历都石沉大海，每次提醒有新消息时激动地打开，又失望地关闭，找自己最多的永远是销售。




那么，问题到底出在哪儿了？


张大胖遇见的求职问题相信许多人找工作都会遇到，自己修改好了简历，选择了适合心仪的职位进行简历投递，但迟迟未有回音，就像等不来的初恋一般。


无非是以下几大类问题：


求职平台不匹配的问题


求职平台选择不是很匹配，将会大大降低成功率。


网络招聘平台大部分有自己的人群定位，有综合类的、有侧重蓝领人群的、侧重中高端管理和技术人才的、有应届生求职平台、也有专注于某一个行业的行业性垂直平台。


如果没有使用匹配的平台，相当于找错了方向，成功率自然会降低。如果是专业技术人员，除了综合类的之外，在专注该行业垂直领域人群的平台求职的成功率将会更大，也是现在招聘平台走向精准化，垂直细分化的趋势的体现。


自身简历问题


1.未展现技能能力


HR搜索简历时除了搜职位名称，还会搜索招聘职位的具体能力对求职者进行判断，这是许多人所不知道的。



举个例子，当HR想招一个web前端开发，用人部门会给到HR相应的人才需求，HR在搜索时，则会对应其中的关键词进行搜索，具体搜索可以见下文，加粗的字体则是会特别搜索的：


1. 本科及以上学历，计算机相关专业，2年以上前端项目开发经验；


2. 具备扎实的 Javascript 和 TypeScript 编程基础，熟悉 Node.js、ES6 开发优先；


3. 熟练运用Fastify、Express的 Web 框架，熟悉Jest、Mocha等测试框架；


4. 熟练掌握Reactjs、Nuxt、Next前端框架，熟悉Ant Design、Element、Vant、IView等UI组件。



这样多个关键词复合，一般能比较有效地提高简历的曝光率。


2. 项目经验



许多人的项目经验常常会出现的一个问题是进行无意义的描述：


XXX平台

根据项目任务要求完成规划工作和按时完成软件开发。

完成爬虫模块，展示模块。

开发后台管理系统，实现自定义分页，第三方登录。

完成数据整理与入库功能。


HR从这段项目描述中无法获得有效的项目信息，并且无法按判断你的能力，想要让项目经验一眼能看出能力就需要以下几个要点：


什么事情：构建IP代理池，优化爬虫策略和防屏蔽规则

使用的工具是什么：使用Scrapy开发异步爬虫系统

结果是什么：提升200%网页抓取速度


XXX平台


构建IP代理池，使用Scrapy开发异步爬虫系统，优化爬虫策略和防屏蔽规则，提升200%网页抓取速度。


使用Vue框架完成后台管理系统，实现自定义分页，第三方登录等6个主要功能。


负责数据的清洗与存储到MySQL数据库，使用数据库索引减少50%数据查询时间。


这样HR挑选简历时能一眼看出你做过的项目是干什么的，你的技术能力是怎样的，提高求职效率。


掌握了这几项要点，张大胖恍然大悟，原来如此！


赶忙完善简历，再次踏上了找工作的征程。


这次他发现了一个专注程序员招聘的平台，八戒招聘。


张大胖疑惑，这名字感觉挺熟悉的，好像似曾相识。


经过了解后张大胖突然想起，这不是以前我兼职做威客时经常去接单的猪八戒网嘛，原来他们也开始做招聘了，并且专注于程序员、设计师的招聘，这确实挺符合他们定位的。


很快，张大胖在八戒招聘上和心仪职位的HR直接聊天，并投递了简历，很快就收到了入职offer。


其实猪八戒网在程序员和设计师人群中还是有一定的名气的，很多程序员和设计师都使用过这个平台，如果有读者不是很了解，下面简单介绍下：


猪八戒网作为一站式企业服务平台，拥有数百万名威客，他们主要为各种机构、企业组织、社会团体以及个人提供在线创意和技术服务，这意味着，猪八戒网本身聚集着万千设计师、程序员，为社会提供各类在线服务。


而八戒招聘正是依托于猪八戒网生态，聚焦细分招聘市场，主要提供面对程序员、设计师垂直人群的招聘服务，可以和HR或者业务负责人直接聊，智能匹配岗位，支持附件简历上传解析，并且注重隐私安全保护，致力于成为程序员找好工作最专业的平台。


不仅仅如此，在八戒招聘，全职/兼职/实习各类型的工作都有，可以让程序员找到适合自己的好工作，如果暂时不换工作，利用业余时间做兼职它也是一个不错的平台。
