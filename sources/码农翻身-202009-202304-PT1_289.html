软件时代


软件时代的微软真的是大杀四方。


凭借以下三家马车组合、大杀四方：


1、客户端开发语言：VB、PB（Sybase公司出品）、Delphi（Borland公司出品），PB和VB必须基于Windows客户端才能运行。


2、客户端操作系统：Windows


3、服务器端数据库：SQL Server（最初与Sybase合作开发）（必须基于Windows Server才能运行）


4、服务器端操作系统：Windows Server


VB/SQLServer/Windows Server都是通用系统基础设施软件，标品。


我也挺赞叹微软的产品用户体验，不用怎么实施和培训，安装容易、使用操作容易。



02
互联网（Web技术）时代


1995年，正是微软最火的时候，Windows95发布、最经典的SQL Server6.0发布、Windows NT成熟可用了，大杀器组合完毕。


但1995年也是微软噩梦的开始，因为那一年，互联网时代来了，资讯门户雅虎成立、电子商务Amazon成立。


它们都有庞大的开发团队，但是对不起，它们不是做IT卖IT，它们是给自己做IT，它们的商业模式是：羊毛出在狗身上。


不仅商业模式不一样，而且使用的技术也都不一样。因为这些互联网公司面对的不是一个企业的员工用户和客户，而是全球的用户，这连接数是海量的。


1、客户端开发语言：HTML/CSS/JavaScript/XML，全是国际通用标准，不是类似VB/PB/Delphi这样专属公司的开发语言


2、服务器端开发语言：Java、PHP、Python等，全是跨服务器操作系统的，不用锁定Windows Server


3、客户端操作系统：应用不再基于桌面操作系统，而是基于浏览器容器，而浏览器可以跨各种操作系统


4、服务器端中间件：跨操作系统的商业中间件，后来有了免费开源的跨操作系统的中间件


5、服务器端数据库：免费开源的跨操作系统的MySQL


6、服务器端操作系统：免费开源的Linux


所以，盖茨自任首席架构师，搞：C#开发语言+.NET平台+什么中间件+SQLServer数据库+Windows Server。


这套组合仍然对抗不了上述那套免费、开源、跨操作系统的技术。在遭遇了Vista客户端操作系统发布失败之后，2009年，这个移动互联网爆发的起点之年，盖茨退位。


033
移动互联网（App）时代


2009年，盖茨的多年好战友鲍尔默接棒，率领微软迎接移动互联网时代。


微软重新研发了适用于智能手机的操作系统。但商业模式变了。因为其他两大竞争对手：Google的Android是免费开源的，苹果的iOS是随硬件免费发布免费升级的。都不收钱。


微软懵了，这怎么挣钱？


而Google和Apple都是再一次羊毛出在狗身上：Google有自己的互联网广告业务，Apple有自己的智能手机硬件业务。


微软有的是人才和现金流，那就两条战线同时出击。在互联网广告方面，微软在2009年也搞了bing搜索；在智能手机硬件方面，鲍尔默在2013年也收购了NOKIA。


有人说，微软被盖茨搞.NET战略和Vista战略拖时间了，鲍尔默在移动互联网时代搞晚了，所以没机会了。


我倒不这么看。大家想啊：微信和小米都是2011年才推出的。鲍尔默在2013年收购智能手机硬件，真的时间晚吗？


但微软的董事会认为晚了。好吧，那就算晚了吧。2013年，鲍尔默退位。


我想作为马后炮再问一下大家：微软该不该开展智能硬件业务？微软该不该在2013年开展智能硬件业务？微软该不该收购NOKIA？


针对这三个问题，大家的分别对应的三个答案是什么？


04
云计算时代


2014年2月4日，萨提亚纳德拉上台。既然微软董事会认为微软搞移动互联网搞晚了，或者说微软就根本不适合搞移动互联网，那萨提亚就选择了搞云计算。


毕竟，从SQL Server+Windows Server组合开始，微软已经从Windows+Office 这种to C商业模式，开始转向to B商业模式。


微软既然在to C的搜索和to C的智能手机业务方面不能占到便宜，那么在to B的云计算领域一争高下。


第一呢，在2014年，全球云计算已经显露出峥嵘。AWS云计算增速飞快、营收起了规模、利润也非常可观。这是微软的市场诱惑。


第二呢，我们也要承认，如果不是鲍尔默在移动互联网时代打下基础，喊出Smart Device First，恐怕微软也没有决心杀入云计算这个市场。


为什么这么说呢？


就是因为鲍尔默推行Smart Device First这个战略，所以微软从一家纯软件公司，开始拥有一堆硬件业务。如：XBOX、Kinect、HoloLens、Surface、NOKIA...。


大家可能不知道这个玄妙。只有做过软件的人才能体会到我所说的。


因为一个软件公司的商业模式、财务成本利润现金流结构、人才素质能力模型、组织结构、研发流程/销售流程/服务流程、考核、激励，和一家硬件公司是完全不一样的。


硬件有库存、软件没有库存。硬件有物理老化，软件没有物理老化...。对于一家从未有过库存和库存成本概念的软件公司来说，决心搞硬件业务是需要下很大决心的。


但是，鲍尔默搞了，微软上过这一课了，微软有这个心理认知了。所以萨提亚搞云计算，大力搞IDC资产、服务器硬件资产、存储硬件资产、CDN硬件资产...，微软董事会才没有反对。


而且，Azure IaaS这个业务，是微软过去没有的，这是微软新增量出来的一块新市场。所以萨提亚也不涉及到微软内部的左右手互搏。


你看IBM的硬件设备业务就和IBM的公有云IaaS业务左右手互搏，所以IBM转向公有云IaaS服务就缓慢甚至不怎么成功。


要知道，在一家大公司，内斗内耗、内斗杀死，是最常见的结果。


我想问下中国软件行业，你们对于自己开展硬件业务，做好认知和成本准备了吗？


05
再说移动互联网时代


萨提亚把Azure带上轨道。咱们还有一块业务刚才没有讲。那就是Office业务。


Office业务一直是微软的现金牛业务。不管是鲍尔默喊的Smart Device First，还是萨提亚喊的Mobile First，Office业务一直按照自己的规划往前走。


在移动互联网时代，Office做了App版本。


其实Office业务要非常感谢Apple从2008年就一直建设的应用商店商业模式，让广大非欧美用户们形成了购买软件的认知与购买习惯。而且Office业务其实也得非常感谢中国互联网公司对支付宝&微信支付这些移动支付工具的推广。


因为Office在中国一直是盗版大户，Office在中国使用量很大，但营收很低。和Office一样的难兄难弟是Adobe的PS。


你看Adobe自从把输入KEY序列号的软件模式，改成在线用户注册、在线支付的软件模式之后，Adobe的营收和股价，真是蹭蹭蹭的往上涨啊。


Office亦同。没有Apple应用商店商业模式打下的消费认知与购买习惯，人们会继续盗版。没有支付宝和微信支付打下的普及，即使中国人想购买，也被支付这个复杂环节给堵住了。


所以，Office不仅改成应用商店里的App版本，而且也和Adobe一样，改成在线用户注册、在线支付商业模式。


盗版消灭了，Office的营收蹭蹭蹭的往上涨。


如果你的软件产品也深受盗版收不到钱的痛苦，那赶快改成在线用户注册、在线支付的商业模式吧。至于是不是App版本或Web版本，至于是不是多租户架构，至于是不是公有云安装部署，还不用太纠结这个。
