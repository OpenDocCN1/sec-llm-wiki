# 漫画 | 程序员才是真正的“甩锅”大师！

你肯定经历过这样的时刻，自己辛辛苦苦、花几天功夫写好的程序被人发现了Bug

![](../Images/43ca64e31ff018f599d6cca92d7a51d5.png)

你的第一反应很可能是：

![](../Images/e3367c68fd6ef557bd7ceedefee91706.png)

程序员为什么会有这样奇怪的反应呢？为什么喜欢“甩锅”呢？（有时候嘴上不说，心里也会说的![](../Images/07cb97c4e4e1cf30ce5617e3fb0f8771.png)）

  

这是因为辛辛苦苦写出的程序已经变成了你的自我延伸，你绝对不希望在其中发生任何错误！

  

在心理学上，有个专门的名词来描述：

![](../Images/2bce4ae3a3b0823352d227d9302f81dd.png)

认知失调不是病症，而是描述一种现象， 我们对事物的认识和对外界的感知出现了矛盾。

![](../Images/61c2fc5b38b16e90396d88c6be561a6e.png)

  

认知失调让人感觉不舒服、焦虑。

  

其实解决问题的方法是接受现实，但是接受现实意味着高昂的代价：否定自己的工作和努力，成本很高。

![](../Images/b37c9fadfdf45948fb7a05fdd9c20e87.png)

  

于是，我们就寻找成本较低的方式，找个借口来解决问题。

![](../Images/cf3051407cf5dc7a165637ceee892423.png)

找到借口以后，我们心里就会舒服一些。

  

再比如你花了很大的精力去学习Java

![](../Images/36cf72b8a11d88cb8e4566ade9cc58f5.png)

好不容易熬出头，可以工作了，这时候居然有人对Java说三道四，你绝对不会客气。

![](../Images/6831c7a866fd7535f84d638d8e26bee5.png)

这时候你对语言的认知也失调了

![](../Images/6e8742424ff96369fbc00e14a1a5b776.png)

为了平衡，你可能会立刻反击

![](../Images/a46e95748dcc2b8ceed76b1236452aa4.png)

为认知失调找的借口并不能解决问题，甚至可能会激化矛盾，破坏团队之间良好的气氛

![](../Images/3568b9a3d67cbf69cdaf258710113534.png)

  

如何解决认知失调呢？关键是要有开放的心态。

  

真正厉害的人都很清楚：我有认知盲区，需要别人发现。

  

比如天才的冯诺依曼对自己的认识就非常清楚。

![](../Images/4d3c6bd56f651e6d30c3e3c2b15f4b77.png)

做为团队领导，有责任在团队建立起一种“无私式”程序开发的氛围

![](../Images/f1f0cacc86e8779d1020bece02c2955d.png)

作为个人，坦然接受别人指出的问题不容易， 这时候，至少可以自嘲一下：

![](../Images/1a6f1095ab4d30ea43b0748a8597e49d.png)

然后赶紧研究下，看看究竟是不是自己的问题，默默地把它改了吧！

![](../Images/608d94dc5873ef642c54f6f07d980164.png)
