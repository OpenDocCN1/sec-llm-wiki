# StackOverlfow调查8万程序员以后发现Clojure最赚钱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTc0NzExNg==&mid=2665528855&idx=1&sn=063d6788baeba1b154be4f32762090a7&chksm=80d64654b7a1cf4218de2195c96faa64d19fc9492db2100ac23222cbf1fa787fcf9299954bd4&scene=126&sessionid=1681664094#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665528855&idx=1&sn=063d6788baeba1b154be4f32762090a7&chksm=80d64654b7a1cf4218de2195c96faa64d19fc9492db2100ac23222cbf1fa787fcf9299954bd4&scene=126&sessionid=1681664094#rd)

每年我都会关注一下Stack Overflow的开发者调查，因为从中可以观察到一些有趣的东西和业界的趋势， 然后和自己的技能点比较一下，瑟瑟发抖或者心中窃喜一下......  
2021年的调查有**8万**多人参与，主要以欧美+印度为主， 中国程序员参与不多，也许是语言障碍吧。  
![](../Images/519d1a4881212f8b5ae851c4a174ee52.png)  
70%的程序员年龄都在34岁以下，看来“35岁”是全世界程序员的魔咒  
![](../Images/d2d67d549e3101c6515f237d6765684d.png)  
毫不意外， 男生占到了90%以上  
![](../Images/d5926f300e63c0a3a5bb2b0a19b3f9bf.png)  
  
**最常用的编程语言**  
JavaScript继续问鼎，这已经是连续第九年排名第一了，用JavaScript做开发的人可真多啊！  
让我感到意外的是，Go语言排名居然这么低 ！难道真是如网上所说，Go语言在中国的火爆程度超越外国？  
![](../Images/de676553140cedfed929e599c914eb56.png)  
  
**最常用的数据库**MySQL 依然排在榜首， PostgreSQL紧随其后。  
Oracle 怎么这么低？  
SQL Sever怎么这么高？应该是微软Azure的功劳吧！  
不过，开源软件占据了统治性的地位！  
![](../Images/f578946ccad60e7f14a06cfdfea9646d.png)  
  
**最常用的Web框架**前端框架再次刷榜，别的框架都没有“活路”了！  
Spring排名真低！  
我怀疑这是因为前端程序员参与调查的人比较多，后来看了看开发人员的类别调查，有近一半的人选了全栈程序员，他们肯定也会选前端框架，于是把前端框架拉高了吧。  
![](../Images/6dd199ed47a42159a4580382df8db9eb.png)  
  
**最常用的IDE**  
Visual Studio Code 已经成神， Eric Gamma实在是牛逼，不知道他看到自己一手缔造的Eclipse的排名会是什么感觉。  
Visual Studio还是那么强势，从上世纪90年代开始，微软在开发工具上一直挺立潮头。  
注意一下Vim ，排名很高  
![](../Images/b6e0f93896420c72bbf4aafbf5df9426.png)  
  
**最爱的和最想抛弃的编程语言**  
这是Stackoverflow调查最有趣的地方。  
对于一门语言，如果你今年用了，明年还想用，就被划分到“最爱的” 范畴。  
如果你今年用了，但是明年不想用了，就被划分到“最想抛弃的”范畴。  
没想到Rust, Clojure, Elixir, Julia 这些小众语言有这么多人热爱，它们身上肯定有与众不同的东西。  
![](../Images/a42ffede634fba62eaaf2c0670e2eb35.png)  
大Java有近53%的人想抛弃它，惨！![](../Images/5afe2577a40a4a46b40a5a4723945210.png)![](../Images/8a05afb7bf98d6de4ed1ec2342c1da31.png)  
估计是维护祖传代码受不了了吧！  
**最想学习的语言**  
对于一门语言，如果你今年没用，明年想用，就被划分到“最想学习的”范畴。  
Python名列榜首， 两个Script紧随其后。  
我觉得我也应该写一个Python教程了。![](../Images/6740e55b44a34fe0f4c3fdae9b1c43b9.png)  
![](../Images/653864966e920a8430e96ce505f176c7.png)  
  
**收入最高的编程语言**终于来到激动人心的环节 ！  
Clojure排名第一， 解决10万美元！想不想学一下？但是估计职位不好找吧。  
F#, Elixir, Erlang , Perl , Ruby紧随其后。  
这些都不是最常用的编程语言，看来小众语言人才不好找啊。  
![](../Images/5802030db1561f888749668725cb4f1d.png)  
  
**收入最高的编程框架**Ruby on Rails居然排名第一！  
Spring只能排名第9 。  
![](../Images/e178868173400fe1237817fc48f27c61.png)  
  
**收入最高的职业**收入高的除了管理人员，CXO，还有SRE，DevOps，Data工程师，意外吧？  
![](../Images/9b1f1c0eabdc8556f781568d163a86eb.png)  
不知道在中国是不是这样，希望国内也有知名的网站发动一下程序员，做一下类似调查，看看国内的情况如何，如果已经存在了，欢迎留言告诉我。
