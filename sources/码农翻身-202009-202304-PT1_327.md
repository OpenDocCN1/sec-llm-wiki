# 美国软件业凭什么远超中国？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTc0NzExNg==&mid=2665528370&idx=1&sn=6dde33eded8830afa0d38607693d9907&chksm=80d64471b7a1cd6742cadff26ecc5fcc6a24b32ad57086fed3815f00d139d2b2a853afab7d0b&scene=126&sessionid=1681664099#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665528370&idx=1&sn=6dde33eded8830afa0d38607693d9907&chksm=80d64471b7a1cd6742cadff26ecc5fcc6a24b32ad57086fed3815f00d139d2b2a853afab7d0b&scene=126&sessionid=1681664099#rd)

周末有位小伙伴给我发了一个截图，问我的看法。

  

![](../Images/3ffc9b955d9088f6457f3a4fc27e5b3c.png)

  

我很喜欢吴军老师和他的《浪潮之巅》、《文明之光》、《数学之美》。

  

但是就这个截图来说， 我不能完全赞同吴军老师的观点，美国软件业凭什么远超中国？我觉得还得加上一个重要的原因: **先发优势**。

  

美国是计算机、软件和互联网的发源地，基础的、关键的软件都是美国人先搞起来的。

操作系统（VMS 、 DOS、Unix、 Windows......）

办公软件（Office、 WordStar、 Lotus1-2-3......）

数据库(Oracle，Sybase, Db2, SQL Server......)

多媒体软件(Photoshop......）

......

  

美国对知识产权的保护也很完善，收入水平也比较高，我记得Windows 95在美国的建议零售价是209美元，对美国人来说完全可以购买正版。后来的iPhone也是一样，499美元的价格和普通民众的收入是匹配的。

  

这就进入了正向循环，公司开发出的软件能大批量卖出去 --> 获得大量收入-->有足够利润投入研发-->开发出更好的软件--> 获得更高的利润，最后成为软件巨头。

  

当这些软件巨头携带功能强大，制作精良的软件来到中国，就发现情况完全不同。

  

90年代我们的软件业非常弱小，很多都是小作坊和个人英雄，比如求伯君、王志东、严援朝、朱崇君....

  

搞行业软件（财务）的北用友、南金蝶算是不错的了。

  

更关键是还很穷，那时候工资才几百块钱一个月，Windows已经是好几千了，正版对于普通民众是承受不起的。

  

你咬咬牙，好不容易攒了一台电脑， 要安装操作系统，一边是1998元的Windows 98，另一边是5块钱的盗版光盘，你会选哪一个？

  

于是Windows、 Office、 Photoshop这些软件就以盗版的方式迅速占领了市场，并且迅速建立了生态。

  

不只是软件生态，还包括市面上海量的图书和相关的培训生态 ——这一点可能更加厉害。

  

国产软件也努力过， DOS时代的WPS是国产办公软件之光， 巅峰期占据了90%以上的市场，但是Office 已经在Windows平台上发展到所见即所得，相当于降维打击， 再加上5块钱一张的盗版光盘，即使求伯君卖掉别墅，孤注一掷开发出WPS 97，也无力回天。

  

盗版确实对中国的软件伤害巨大， 在面向普通消费者的软件中，除了WPS ，我甚至想不起来有哪些的软件公司开发过哪些**知名的商业软件**。

 

只有做行业应用（财务、电力、税务、烟草、金融等）的公司会活下来，因为这种定制软件开发无法盗版。

  

那国产软件就不能卖得便宜些， 和国民收入相配，这样不就可以进入正向循环了？

  

1999年，雷军到我们学校搞宣传活动：红色正版风暴

  

![](../Images/9b4c463de031a7374b0246c78d7d3c10.png)

  

金山词霸原价168，现在只要28元，场面火爆， 我们这些穷学生纷纷掏钱购买。

  

28元是我两三天的生活费，但是我们觉得已经很值了！

  

这个风暴瞬间席卷全国，100天内销售过100万套，刷新了国内正版软件的销售记录，100万现在的互联网公司根本看不到眼里，但在90年代，是非常“吓人”的销量。

  

可惜类似这样的风暴，只刮了一次， 以后再也没有了，不知道是不是价格太低，导致利润率太低的缘故。

  

这种情况到了互联网时代终于获得了改变，一方面这是新的赛道，有很多新的软件兴起， 比如美图秀秀这样的工具类软件，在之前根本就不存在这样的需求。

  

另外一方面，收入模式从直接向用户收费，变成了通过广告或者增值服务收费，所谓羊毛出在猪身上。

  

互联网产品和服务是免费的，产品中展示一些广告，或者通过会员/高级功能收点儿钱，借助于海量的互联网用户 ，每个用户不需要付出太多，公司就能获得极好的收入，走向正向循环。做得好的还能获得极高的估值，上市获取资金。

  

WPS就在移动端做得风生水起，现在都可以反攻桌面端了！

  

总结一下，知识产权，数字资产必须要保护，但它们并不是美国软件业远超中国的唯一原因。

  

我们的软件业在起步的时候，在国民收入很低的情况下，受到了拥有先发优势的软件巨头和盗版的沉重打击，几乎全军覆没。

  

幸运的是，我们爬上了互联网这艘大船。

  

（完）
