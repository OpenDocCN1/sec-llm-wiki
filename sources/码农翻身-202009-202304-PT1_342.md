# 漫画 | 浏览器一个比一个“无耻”

张大胖初学Web开发， 遇到了一个古怪的东西：

  

  

![](../Images/31fadd56b5b37e0f3f64e81d64f55cfc.png)  

  

这个**User Agent**字符串之所以这么古怪， 要从20多年前的Mosaic说起。

  

1993年，在伊利诺伊大学的国家超级计算中心（NCSA），第一个支持图片的浏览器Mosaic诞生了！

  

  

![](../Images/16d496bfaf2d8c3e9b3b5476ef43cb64.png)

  

  

不久，开发Mosaic的骨干Marc Andreessen前往硅谷，开始创业， 开发了一个叫Mozilla的浏览器

  

![](../Images/4c8b85e72fbe2ef0c307134f235aea98.png)

  

  

伊利诺伊大学和NCSA对Marc Andreessen的所作所为很不高兴， 于是Mozilla被改名为Netscape。

  

  

![](../Images/39cb8142ae98f2dcfff8bae43baeda7e.png)

  

可以看出，无论是Mosaic还是Netscape，它们的User Agent还是很清爽的。

  

![](../Images/6a6f82fe67050d4977713f1760fbba5d.png)

  

  

  

不同的浏览器有不同的能力，于是在服务器端发展出了User Agent 嗅探技术。

  

  

![](../Images/602d1109ccfba70a532a14549687eb2b.png)

  

  

Netscape风靡网络，这让当年的软件霸主微软感受到了巨大的威胁， 微软推出了自己的浏览器Internet Explorer，希望成为Netscape Killer。

  

![](../Images/47cfd6d70947af76b94dc1d3b180a08d.png)

  

  

IE等不及了， 它决定假装自己就是Mozilla ！

  

![](../Images/deeeef7df9d6a3383fc227e4513eab22.png)

  

  

IE的欺骗成功了 ！

  

![](../Images/8103c6cae65a13aebc19eb9064f2c663.png)

  

  

微软通过在Windows上捆绑IE， 迅速把Netscape 击败。

  

![](../Images/20b72a3189a704a0bdc754b19dff7ef2.png)

  

  

正面战场搞不过微软， Netscape决定另辟蹊径：开源

  

新的Mozilla 诞生了，与此同时，它还拥有了一个叫做Gecko的渲染引擎

  

![](../Images/596d8f2a26bc7824b3c2bad47e7093a3.png)

  

  

然后Mozilla变成了Firefox 。

  

![](../Images/c4bdefab18ce23719ced53bb1d6389ca.png)

  

  

Gecko这个渲染引擎很厉害，很多浏览器开始使用它。

  

![](../Images/6552e1c6c78d2fa3628221ac8218707a.png)

  

  

Gecko 被广泛认可， 服务器又开始进行User Agent 嗅探了

![](../Images/c539d496f1c85562dd814ace061f991f.png)

  

  

此时Linux刚搞了一个叫做Konqueror 的浏览器， 用的是自家的KHTML渲染引擎

  

![](../Images/53cfcebb384336f8b8df9a3a0384135c.png)

  

  

于是，Konqueror 在User Agent中也做了点手脚。

  

  

![](../Images/166d749c715556da5480a11331913b00.png)

  

  

![](../Images/b51af94af4e982913c319c69461d21a2.png)

  

Apple 也决定搞一个自己的浏览器Safari ，它基于KHTML，创建了新的渲染引擎 Webkit

  

![](../Images/832a7bc6e9d663a86915fea789043cbd.png)

  

最后，Google也来了，它想做一个叫做Chrome的浏览器， 也基于WebKit引擎。

  

  

![](../Images/5eb3d7813c55a0fa9dce89c72380102f.png)  

  

这就是你看到的奇怪的User Agent的来历。

  

![](../Images/10ee135c760a3d7b15f04e09c10112b8.png)
