# 看完粉丝和他女朋友的爱情故事，我泪目了。。。

我是一个程序员。

和职业不符的是，我有个很爱我的女朋友，从聊天记录就可见一斑。

比如`爱你`

![](../Images/7bc3a4f1c20b14ed43701f8f0796a5c6.png)比如 `我在想你`

![](../Images/a091e7ad4a43dcbf2fb5dd48312dac6b.png)

某些情况下，女朋友的爱甚至会让我莫名感动。

![](../Images/f3038c10250bc1958a587a1d1b4e7aad.png)

这几天不知道怎么回事，她总是说一些奇奇怪怪的话。  

![](../Images/7fafb133163cf228c4eca69d40e194c6.png)

当天晚上回家之后，看见她在客厅一边傻笑一边说："没想到县城还挺有意思的。"

我立马搭讪到："是吧是吧，我从小就在县城长大的，比大城市舒服多了。"

女朋友白了我一眼，说："亏你还是个程序员"，说完就回卧室了。

我一脸懵逼，但是多年的经验告诉我，女朋友生气不要问为什么，直接哄就好了。

于是我决定按照菜谱，给她做一份美龄粥，让她体验下霸道总裁的铁汉柔情。

1.准备好浸泡的糯米

![](../Images/1926c9560c50e556a675004962bc155d.png)

2.准备好剥皮的山药

![](../Images/810602341826cfbcdf29b8d5b825be52.png)

3.小火熬四十分钟

![](../Images/2d690a875b47b917cd8df3cd1b2d3e52.png)

emmmm...

没事，我还有Plan B。

趁女朋友睡着了，打开她的购物车，看她最近想要什么直接买了，让她体验下霸道总裁的一掷千金。

![](../Images/d891e84de8ba31f49c7a8699de011c2d.png)

可以看出来我女朋友涉猎还是比较广泛的，一时间不知道应该买哪一个。

对了，她平常还发一些只有自己可见的朋友圈，也可以参考下这个。

![](../Images/d60fb1c98776a2598147952d1cc35140.png)

![](../Images/dd31a04ccd0d13494ddd7f764b61d832.png)

奥，原来是最近迷上了`码农翻身`的公众号啊，难怪又是张大胖又是线程的，这就简单了，直接送她书就行。

果然，第二天她就开心了起来，但是也提出了更高的要求。

![](../Images/3e31ccd58b613a36b59caf87e978ec29.png)

我想了一下，有两个方案。

一是自己也写公众号，这样有机会能和刘老师合作一次，再要本签名书就顺其自然了。

二是加上刘老师的微信，时不时送上诚挚的关心与问候，搞好关系也能要一本签名书。

第一个方案不太顺利，选择恐惧症的我，光取名字就花了一年半。

![](../Images/2a4e74bc3748d2ba9b94d15eccffa37e.png)

和刘老师日常沟通收获还是比较大的，因为终于发现了他的爱好！

![](../Images/fae5cd15c8777aed89a40a0abc0ee798.png)

以我工作四年的程序员情商来看，刘老师平常都是回复`好的，谢谢`，唯独提到了吐槽大会，他回复我`哈哈，谢谢`。  

所以刘老师应该是比较喜欢吐槽大会的，相反如果送他秋裤，他的反应估计就很一般。

所以可以写一篇关于吐槽大会的文章。

刚好易立竞很火，刚好我是程序员，刚好易老师还没来及吐槽程序员。

我决定替她执笔，替她杀疯，替她吐槽码农。

文章很快写好了，嗯，就是下面这个，没看过的同学可以看一下。

[假如易立竞吐槽程序员。。。](http://mp.weixin.qq.com/s?__biz=MzI4ODIzMzIwNg==&mid=2247484475&idx=1&sn=a7dc78307164cf0996dabd8eae5cd826&chksm=ebc0c7a2dcb74eb4c1d8739e56885116c6453292f638c98e43b259ecd5c8af9f277923725970&scene=21#wechat_redirect)  

但是我不知道写的好不好，想起来之前有个程序员同事，现在在做脱口秀，好久没联系了，正好可以问下他。

![](../Images/20332a53e39d9d7641fe6fc57ef3d23a.png)

小呼的脱口秀我个人觉得还是不错的，所以这篇文章应该也会火。  

但是，现实并没有这么美好，文章发出去之后无人问津。

我有点沮丧，这时，我又看见了码农翻身公众号推送了一篇新的文章，里面有送书的抽奖！

[嘚瑟一下，我的书上电视了！](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665526011&idx=1&sn=1f2f7440ff7306d77249342ecd5fdcad&chksm=80d64ab8b7a1c3ae828f9304b946d71143381dd74cbe3088729d9bd5a7ce729939b5f35a6b9d&scene=21#wechat_redirect)  

![](../Images/c198ab4ca3caf04f90a3db7e46cc8a71.png)

虽然抽奖的书不是签名版的，但是我发现了另外一种方式。

![](../Images/80c52ae2ce0ed3fa08b11b4739ec7171.png)

然后，平常二倍速看国产电视剧的我，十年来第一次认真看电视剧片尾。

![](../Images/33b94525ead30c89a35bd9c589154f8b.png)

好的，马上成功了！

![](../Images/696d18a7d0d0f9ba4899db80780cba45.png)但是刘老师并没有回复我，我知道，像他这种level的super star，肯定是比较busy的，ignore了我也正常。

那一刻真的累了，也倦了，看来这个城市，注定要多一个伤心的人。

但是一天早上，突然发现了很多人私信我，给了我一些非常客观公正的评价。

![](../Images/c39c9e76b7f490e0beff18eac0461917.png)![](../Images/8513b40d8dba7e8bb2fdf2c2044269ae.png)![](../Images/558891fb1b70979fef30c382733ef814.png)

原来，我的文章被刘老师转发了！！！！

![](../Images/af4ed237565f7b30f712c41cdf748e64.png)

于是，剩下的事情，就顺理成章了。

![](../Images/b6183abd2c22a7a4edfaaa387d785f5b.png)

果然，只凭借英俊的外表，显赫的身世，不俗的谈吐，都难以获得刘老师的亲笔签名书。  

唯有坚持，唯有才华，唯有坚持才华，方得始终。
