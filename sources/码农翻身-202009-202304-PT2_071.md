# 论公众号内卷

**曾几何时  
公众号文章的标题单纯且没有套路  
七年前的我就是这样  
仅仅把公众号当做一个写文章的博客平台  
甚至是像有道云一样的在线笔记平台  
当时的标题是这样子滴****  
  
《hashmap 的学习笔记》  
《hashmap 原理&技术知识整理》  
  
我把它称之为"学习笔记型标题"  
大家朴实地记录自己的知识  
并期待对别人能有些许帮助  
  
但后来  
一些人发现  
只要稍稍美化一下样式  
再把标题大众化一点  
就能得到很不错的效果  
于是  
就成了下面这样子  
  
《hashmap 源码分析》  
《hashmap 的核心原理与应用》  
《hashmap 面试常见知识点》  
  
我把他称之为  
清晰明了型标题  
这个阶段也许  
是公众号文章的质量巅峰了  
大家把自己的所学所想  
毫无保留地记录下来  
并且用最舒服的样式  
最直观的标题  
给读者最好的阅读体验  
  
但后来  
有人就在想了  
同样是写 hashmap  
我怎么才能体现出  
比你写的更好  
甚至比所有人写的都好呢  
于是  
标题中开始有了一些额外的  
修饰词  
变成了下面这个样子  
  
《万字长文！带你从头梳理 hashmap》  
《100 张图！搞定 hashmap 全部知识点》  
《吐血整理！！hashmap 面试题集》  
  
我把它称之为  
真诚夸张型标题  
相比于之前朴实的标题  
你是不是更倾向于点击这种呢  
的确  
很有视觉冲击力  
让人有点进去的欲望  
但最起码  
标题并没有骗人  
万字长文，真的就超过了一万个字  
100 张图，还真的就有 100 张图  
吐血整理，说不定还真的就...  
但总之  
没有骗人  
只是用词夸张  
  
再后来  
修饰词已经被各路文豪用尽了  
你实在是想不出  
还有什么更夸张的词汇  
于是  
你开始变得不再真诚  
  
《一文带你彻底搞懂 hashmap 底层原理》  
《全网最硬核解读 hashmap 底层原理》  
《hashmap 看这篇文章就够了》  
  
刚开始看到这种文章的读者  
就像捡了宝一样  
赶紧点进去  
秒收藏  
觉得终于有人一篇文章就讲明白了  
终于有全网最硬核的讲解了  
终于有一篇可以看完就不用了再看其他的  
hashmap 讲解了  
看到一半  
失望地点了返回按钮  
说好的一文就带我搞懂呢？  
说好的全网最硬核呢？  
说好的看你这一篇文章就够了呢？  
  
这个阶段  
所有文字都是最硬核  
所有图片都是最生动  
所有文章都是秒杀一切  
读者也慢慢麻木了  
学会过滤掉这些修饰词  
把它当做一篇普普通通的厕所文章来读  
  
后来  
创作者终于发现  
无论加多少个“最”字  
都骗不到读者了  
于是  
不再从修饰词上做文章  
开始从标题本身的含义入手  
贩卖起了焦虑  
  
《今年三十二，还在被问 hashmap》  
《搞定这道 hashmap 面试题，大厂随便进》  
《你知道现在的 hashmap 面试有多难么？》  
  
今年 32 了  
真的还在被问 hashmap  
我很焦虑  
文中一定有缓解我焦虑的灵丹妙药吧  
点进去  
一直在小厂游荡  
我很焦虑  
大佬说搞定这道面试题就能去大厂  
进去看看吧  
好几年没学新技术了  
成了随时都要被淘汰了老程序员  
现在的 hashmap 已经难出我的认知了么  
赶紧去看看  
  
这个阶段  
标题很焦虑  
人也很焦虑  
贩卖焦虑真的爽  
而且还能让读者持续焦虑  
就像吸毒一样  
  
再后来  
读者变得佛系了  
不能进大厂？  
无所谓  
被人说成是打工人？  
正合我意  
一辈子在一个公司出不来？  
那太好了  
对我贩卖焦虑？  
我呵呵一笑  
  
读者不再那么好骗了  
不再相信一篇文章可以是世界第一  
不再理会你那些无病呻吟的焦虑  
你敢用焦虑烦我  
我立刻取关你的号  
  
创作者们收敛了  
但想出了新的办法  
贩卖 Title  
贩卖 IP  
  
《阿里 p9 带你手撕 hashmap 源码》  
《阿里面试官最喜欢问的 21 个 hashmap 面试题》  
《字节内部疯传的一份 hashmap 失传资料》  
《这 21 个刁钻的 hashmap 面试题，我把阿里面试官吊打了》  
  
读者再次兴奋了起来  
理我如此遥远的阿里高管  
居然手把手教我写代码！  
字节内部的失传资料  
居然被放出来了！  
赶紧点进去  
生怕错过这个让自己远超他人的真经  
后来却发现  
阿里 p9 带你写的代码  
居然和网上的随处可见的文章一模一样  
字节内部疯传的真经  
居然也在阿里内部失传了  
而且说不定就是当年自己写过的  
已经失传了的学习笔记！  
  
于是  
读者终于醒悟了  
读者把标题里的  
修饰词  
夸张词  
title  
ip  
统统过滤掉  
剩下的  
只有一个 hashmap 关键字了  
  
创作者也终于醒悟了  
知道了  
无论在标题中加入什么新鲜词汇  
最后都会被读者过滤  
于是  
开始把信息隐藏到标题之外  
  
《原来还能这样看 hashmap》  
《关于 hashmap 的那些你不知道的真相》  
《一道 hashmap 面试题引发的血案》  
  
最悲哀的就是  
读者明明知道是套路  
可还是抱着万分之一的侥幸心理  
点了进去  
万一真的有我不知道的真相呢  
我不信  
但我不敢错过  
我点  
我再点  
十篇里有一篇也行啊！  
我点  
可惜  
就是没有  
读者不再思考了  
hashmap 相关的文章  
我再也不看了  
  
睡前  
我打开手机  
又刷到两篇文章  
  
《睡前给女友讲了遍 hashmap，没想到...》  
《妹子让我带她看 hashmap 源码，结果...》  
  
我的大脑屏蔽了 hashmap  
但荷尔蒙还是让我点开了文章  
滑到最后发现妹子只出现了一次  
然后默默关了手机  
关了灯  
睡觉  
  
再后来  
公众号文章的标题  
似乎恢复了以往的宁静  
没有修饰  
没有夸张  
没有 title  
  
《hashmap 源码分析》  
《hashmap 的核心原理与应用》  
《hashmap 面试常见知识点》  
  
我兴奋地点了进去  
津津有味地读了起来  
滑到最后

后记：“闪客Sun”的这篇文章写得不要太真实， 自从公众号变成信息流以后，一个非常明显的变化就是：**标题的重要性变得无以复加了**，用个中规中矩的标题，阅读量就会腰斩，让用心创作者很受伤， 就像上周的《[从量子力学到抖音](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665523232&idx=1&sn=4dc7613bb5be208452677485d7e8e7c2&chksm=80d65063b7a1d975d5598f7159b33eb3b13d3dc0df5beffe0f89ab9439e7dd0c7fadee5301fb&scene=21#wechat_redirect)》一样，看过了都说好，但就是没人点进去。 标题越来越夸张，内卷不可避免。  
我以后还是会努力原创，在标题也会尽最大努力，保证内容和标题匹配，如果哪一次没控制住，出格了，请大家多多包涵。![](../Images/ffa32d526fe74f50564e9c295b0e61f4.png)![](../Images/e468561bbeb039121f64dc6350066e41.png)
