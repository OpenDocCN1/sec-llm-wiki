# 完了，我人格分裂了

[![](../Images/e96af994ebb71189409374af4eb360f0.png)](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665523232&idx=1&sn=4dc7613bb5be208452677485d7e8e7c2&chksm=80d65063b7a1d975d5598f7159b33eb3b13d3dc0df5beffe0f89ab9439e7dd0c7fadee5301fb&scene=21#wechat_redirect)

  

我觉得这一篇漫画画得挺好的，可能是近期漫画中比较高质量的一个，既有创意又有干货，看过的都说好，可是阅读却翻车了。

  

我拿去给老婆看，她一看标题就说：“你这标题就是自嗨，自己觉得不错，别人Get不到，一点儿都没有让人点击的欲望，内容再好也白搭。”

  

真是一语中的， 我无话可说。

  

看了文章，她笑眯眯地说：“我看你这文章写得挺有趣的，怎么生活中老是板着脸呢？太严肃了！能不能把你这种诙谐幽默也搬到生活中啊！”

  

这句话一下子把我震住了！是啊，**我咋就变成了一个人格分裂的人了？**

  

![](../Images/ebb158d402198ffe988ebcf911d76171.png)

  

我为什么能在文章中塑造幽默的人物，创作有趣的情节，但是回到了现实生活，却不能做一个有趣的人呢？

  

有趣的灵魂只能在虚拟的空间出现吗？

  

其实我在生活中也是能表现出一些有趣特质的，比如孩子早晨赖床不起，我就随机地编一个非常简短的小故事，留一个搞笑的，或者悬疑的点儿来吸引他，他很快就能睁大眼睛，瞬间清醒，问道：“然后呢？”

  

在生活中，我确实比较严肃，在饭局尤其是大的、陌生人的饭局上，和人说话比较谨慎，也不会讲段子、笑话，很难像那些社交达人那样如鱼得水，逗得别人哈哈大笑。

  

平时待人接物办事也都是一本正经，中规中矩，不认识我的人绝对想不到我能写出有趣的文章。

  

我能把这种文章的风格带入到生活中吗？

  

不能，这样心就太累了。　

  

好玩的情节是精心构思出来的，也是不断修改出来的，得累死不少脑细胞。如果在现实生活中也让我这么做，我就要哭了。当然，现实生活的即时性，随机性也不允许我这样做。

  

所以，还是继续人格分裂吧！

  

不过还是要做点儿改变，不要那么严肃，对身边人多笑笑，保持一个好心情，没准儿还能多活几年呢！

  

又要到周末了，发了一点感概，预祝大家周末愉快！

  

没看过那篇漫画的可以去看看，错过就可惜了！
