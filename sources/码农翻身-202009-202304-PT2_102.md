# Google真的会被拆分吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTc0NzExNg==&mid=2665522108&idx=1&sn=afc0ca89ea3193671805c9280fb0c4f5&chksm=80d65bffb7a1d2e9e35b4e9c7e993423275bc43a1a89a6359854d2110d14e32f9c4097e45653&scene=126&sessionid=1681664180#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTc0NzExNg==&mid=2665522108&idx=1&sn=afc0ca89ea3193671805c9280fb0c4f5&chksm=80d65bffb7a1d2e9e35b4e9c7e993423275bc43a1a89a6359854d2110d14e32f9c4097e45653&scene=126&sessionid=1681664180#rd)

最近有报道说美国司法部经过长达是十几个月的调查，认为Google涉嫌违反垄断法，可能要对Google动刀了：考虑强迫Google出售Chrome浏览器和利润丰厚的广告业务。

  

Google会被拆分吗？

  

这不由得得让我想起了另外两家美国的IT巨头，它们也曾由于市场垄断，面临美国政府的反垄断大棒，我们先说说它们的反垄断战争，然后回头再说Google。

  

  

01蓝色巨人IBM  

  

  

现在的同学对IBM可能没有太大感觉了：ThinkPad和x86服务器早就卖给了联想， IBM最著名的Z系列大机基本上也见不着，非常知名的5大品牌软件在互联网软件的冲击下也逐渐式微，日常接触最多的可能是Eclipse，但是也被IDEA压一头。

  

实际上IBM是计算机发展历史上最重要的参与者，它最辉煌的时候是在上世纪60年代，尤其在小沃森的“世纪豪赌”System/360成功以后，更是所向披靡，碾压对手。

  

  

![](../Images/62247594ab90f8f91ce9c44f1793c236.png)

(IBM的System/360)

  

到1969年，IBM在全球大型计算机市场的份额接近80%， 其他7位竞争对手各自占据可怜巴巴的2%到5%的份额， 被人们戏称为“IBM和七个小矮人”。

  

![](../Images/9ad599efc79eddad8e81e90c3f7062c0.png)

(IBM和七个小矮人)

  

如果任由IBM这么高速发展下去，整个计算机行业很可能只剩下IBM一家公司！

  

1969年1月，美国司法部对IBM提起了反垄断诉讼，指责它垄断市场、阻止竞争。之后的几年里，大大小小的竞争对手共对IBM发起22起反垄断诉讼，要求IBM赔偿损失，甚至要求分拆IBM。

  

对于这些诉讼，IBM聘请了大批律师进行应诉，最多同时雇用了200名律师。起初，IBM无意和解，但它面临的压力越来越大，小沃森心力交瘁，一度因心肌梗塞住进医院。

  

IBM与小矮人们的官司很快和解，但是与司法部的官司则旷日持久，直到1982年里根上台，政府积极推行经济自由化和放松管制运动， 时任反托拉斯局领导人威廉·巴斯特认为计算机行业与电信业不同，是无管制的，承受着市场竞争的强大压力， 从而以“没有价值”为由撤销了这一诉讼。

  

IBM避免了像AT&T那样被拆分的厄运，但是也付出了极为沉重的代价，10亿多美元的费用就不说了，关键是它从一家积极进取、野心勃勃的公司变成了一个小心谨慎的庞然大物。

  

从1972年起，IBM制定的每项政策都要经过反垄断法的过滤，所以当IBM开创了兼容PC机的巨大市场后，在反垄断压力下却不敢独占电脑产业，从而让康柏，Dell做大，更是让微软和Intel崛起，成为新一代霸主。

  

02微软帝国  

  

二十年以后，反垄断的利剑砍到了微软的头上。

  

相比IBM垄断大型计算机，微软垄断的是软件。

  

比尔·盖茨在PC业兴起的时候，就敏锐地意识到，垄断了操作系统，就能垄断软件业！

  

所以他费劲心力让DOS搭上了IBM兼容机的快车，占领了用户的桌面，然后锲而不舍地发展图形化的Windows操作系统，经过Windows 1.0, 2.0的惨败，终于通过Windows3.0大获成功，继而通过Windows 95 走向巅峰。

  

垄断了桌面操作系统还不算，微软还要垄断应用软件，它四面出击，挑起了无数的战争：

Excel vs Lotus 1-2-3

Word vs WordStar/WordPerfect

IE vs Netscape

Media Player vs Real Player

VS Studio  vs Delphi/C++ Builder

........

占领桌面还不算，还要占领服务器

Windows NT  vs Unix

SQL Server  vs  Oracle , Db2

MS Exchange vs Lotus Note

IIS vs Apache

.NET  vs Java

......

  

![](../Images/4c2e73a944c531d678eece5521322a5a.png)

(2006年的微软帝国)  

  

但是微软牛X的是， 除了服务器端的领域， 它全部打赢了！

  

这些战役中最知名的就是IE vs Netscape，IE通过捆绑和免费，成功地在浏览器市场翻盘。而微软还振振有词地狡辩说：IE不是“产品”，而是一个操作系统中的一个“功能”！

  

微软犯了众怒，但是大家谁都搞不定它，美国司法部出手， 祭出反垄断的利剑。

  

![](../Images/543c443664bfd3f313fcb055d3ca9e7f.png)

比尔·盖茨在作证

  

比尔·盖茨在法庭上很不“老实”，经常用“我不记得了”这种说辞来应付。在审判期间微软还提供了很多录像带，其中一盘还显示IE从Windows中删除以后，导致Windows减慢和故障，以此证明IE是个重要的功能， 但被火眼金睛的法官发现视频是拼接起来，故意达成这个效果。

  

到了2000年，哥伦比亚地方法官托马斯-杰克逊做出了初审裁决：把微软拆分成两个公司，一个主攻操作系统，另外一个经营应用软件。省得它利用操作系统的优势，捆绑应用程序来击败竞争对手。这个消息一出，微软的股票应声暴跌一半，微软以外的人都兴高采烈。

  

但是微软还是逃过了分拆的命运，在随后的拉锯战中，微软和司法部达成和解，交了一大笔赔款了事。

  

后来的事情大家都知道了，互联网崛起，Google，Facebook成为巨头， 微软先是被Web夺走了开发的王座；十年后，苹果推出iPhone, Google推出Android，微软又被智能手机夺走了客户端的王座。

  

微软在鲍尔默时代，抱着Windows和Office这两颗摇钱树摇了很久，也曾尝试互联网服务（MSN, Bing）和手机（Windows Phone），但都已失败告终。

  

微软没有败给美国政府，它败给了时代。

  

幸运的是微软也出现了一个力挽狂澜的新CEO纳德拉，带领微软走上了云计算之路。

  

  

03Google  

  

又是二十年过去了，这次轮到了Google 。

  

微软垄断了桌面软件， Google垄断了网络服务。

  

在美国市场

Google在网络搜索市场的份额超过90%

Android在手机操作系统的份额超过80%

Chrome在浏览器市场的份额超过70%

Google在视频，地图等细分领域也超过70%

  

即使在全球市场，除了在中国等少数国家，Google都占据主导地位， 看看Google禁止华为使用GMS，华为手机在海外有多么痛苦就知道了。

  

根据IBM和微软有惊无险的诉讼经历，我个人觉得Google的反垄断调查的结局很可能和IBM/微软差不多：赔偿一笔对它来说微不足道的金额，拆分则不大可能。

  

但是反垄断调查和诉讼会对后续的竞争产生深远影响，无论是否拆分，这些巨头都会被迫改变自己的业务策略，给诸多竞争对手带来成长的机会，就像IBM之于PC业。如果遇到了时代的变迁，很可能会被另外一个巨头击败，正如微软之于互联网。

  

然后，下一个巨头再次获取垄断地位，再次反垄断，如此循环不息。

(完)
