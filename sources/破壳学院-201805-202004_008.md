# 1000元奖励丨破壳把最骚的姿势交给你

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4Nzc1MDc3Mw==&mid=2247484638&idx=1&sn=59208905356c5f4d478e4d83502f378e&chksm=ebc9abc4dcbe22d261d75c9aa2c4ca71eb49c38ccae5615e3232165dac585797b6e03bb02214&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4Nzc1MDc3Mw==&mid=2247484638&idx=1&sn=59208905356c5f4d478e4d83502f378e&chksm=ebc9abc4dcbe22d261d75c9aa2c4ca71eb49c38ccae5615e3232165dac585797b6e03bb02214&scene=27#wechat_redirect)

实不相瞒，那一天，破壳和运营的风花雪月经过是这样的：  

 

破壳去年隐藏了一个彩蛋课程，当时只提供给了报读M1课程的学员们进行购买实操练习——**《WEB安全实战案例与靶场（精华靶场训练）》**，后来由于破壳与靶场平台的合作到期，默默的把该课程**下架了**。

 

![](../Images/7bad91b45b8ace3b03db194d74ddfa76.png)

  

然后在下架课程以后，我们光明正大（toutou）的**全方位去观察**了这批学员，经过一年的观察和对比

  

破壳发现有报读精华靶场课的**学员学成率提高了不少（估算高达50%）**，也说明了这门课程很好的为M1或者说是WEB安全课程**提供了帮助**

  

不仅从原理上更详细的讲解了漏洞的过程，还提供学员复现漏洞的靶场进行实操练习，加深了学员们的理解和动手能力（所以为什么说学长们会的姿势更骚一些）

 

**这不双十二又要来了，这似乎和破壳一点也没有关系**，但是仔细回想下下去年的双十二，破壳究竟在做什么呢...

 

emmm对的！

 

上一年破壳运营们在双十二期间为了完成老板设定的KPI，在**拼命招生ing**

 

所以！今年双十二，破壳要做点什么好呢？

 

经过非常严谨而且精密并且周全的考虑以后

 

破壳**决定！**

 

重启靶场课程的上线！！！！

 

所以我们决定把**原价RMB299的课程，卖到...**

![](../Images/0f5798e331743fce48bf1cc8ecb5b574.png)

   

等等，光有课程，没有靶场，这门课程就**失去灵魂**了啊~

 

没有灵魂的课程如何为已经报读破壳课程的学员们提供更好的辅助学习

 

所以还是先考虑**重新把靶场环境搭起来**再说

 

不对！破壳自己搭靶场？太寂寞了...不如...手动奸笑

 

不如借此机会让学员参与进来，这也是很好的实操练习机会啊！！

 ![](../Images/05c2b8be910a18e9e018ad4d83df1556.png)

  

故事的结局：

因此破壳打算**开放****靶场源文件**，并拿出一点**小奖励**，让大家一起来搭环境，玩靶场（有本事就来把破壳的靶场玩坏），加快完成这次靶场的环境搭建。

 

**【双12福利】**

1000元现金奖励，破壳邀你一起搭环境玩靶场

  

**活动任务：**帮助破壳完成课程《WEB安全实战案例与靶场（精华靶场训练）》配套的靶场环境搭建，能够提供学员正常使用靶场并实操训练

 

**活动规则如下：**找喵喵酱报名——等待发放靶场源文件——完成靶场搭建——发邮件提交靶场——审核评分——公布结果

  

**步骤1：**凡是关注破壳学院的学员，均可扫描下方二维码添加喵喵酱微信好友，申请报名本次活动

![](../Images/638d0b26cb59dcebacfe08352d16d9bc.png)

 

**步骤2：**申请报名成功后，喵喵酱发放靶场源文件进行下载（文件共12.04G，请预留好足够的空间和足够快的网速）

  

**报名需求及条件：**

1、准备1份个人简历，报名时一同提交给喵喵酱审核

2、遵守破壳的规则安排，禁止未经授权私自传播靶场源文件

 

**步骤3**：学员根据靶场源文件进行环境搭建

 

**步骤4：**完成搭建后，将靶场搭建文档以及搭建流程通过邮件的方式发送到以下地址：assistant@sobug.com

  

  

**靶场需要符合以下2个条件：**

1、提供搭建流程文档；

2、搭建成功后能够正常运行并且使用，并导出docker镜像

 

**步骤5：**PT老师审核靶场搭建的情况，审核通过后，按提交时间先后顺序，**给予第一名学员1000元现金奖励**（其他未能获得奖励的学员也不用灰心，破壳还可以奖励喵喵酱的安慰表情包1个）

 

![](../Images/d2c24b5a9218a398277fd2e89e085aa8.png)！

什么人可以申请报名活动？

**会搭靶场，能熟练运用docker即可**

 

完成靶场的环境搭建后，《WEB安全实战案例与靶场（精华靶场训练）》将会重启上线为大家提供更强大的辅助学习，敬请期待！
