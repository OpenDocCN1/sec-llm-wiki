rsync未授权访问漏洞


rsync是Linux下一款数据备份工具，支持通过rsync协议、ssh协议进行远程文件传输。其中rsync协议默认监听873端口，如果目标开启了rsync服务，并且没有配置ACL或访问密码，就可以读写目标服务器文件。


首先利用命令进行访问：



如图所示，有一个src模块，然后列出这个模块下的文件。



看到一个linux的根目录，接下来可以使用：

rsync -av rsync://192.168.53.128:873/src/etc/passwd ./  来下载任意文件

或者，可以通过写入一个cron任务，然后利用nc来反弹出shell




接下来查看配置文件的相关选项（cat /etc/rsync.conf）,这一项read only表示只读，如果这一项为no，说明就具有写的权限了，也就可以像之前那样写入一个cron任务，最后来反弹shell



rsync未授权访问漏洞的防御方式


第一点：要配置认证用户名或者密码，不直接开放访问

第二点： 利用host allow/deny 来控制接入源IP

tomcat的PUT方法上传任意件漏洞


当存在漏洞的Tomcat 运行在 Windows 主机上，且启用了 HTTP PUT请求方法，攻击者通过构造的攻击请求向服务器上传包含任意代码的 JSP 文件，造成任意代码执行，危害十分严重。


参考链接：https://dwz.cn/HiOrf30d
