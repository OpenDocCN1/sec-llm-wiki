**01**

**rsync未授权访问漏洞**

  

rsync是Linux下一款数据备份工具，支持通过rsync协议、ssh协议进行远程文件传输。其中rsync协议默认监听873端口，如果目标开启了rsync服务，并且没有配置ACL或访问密码，就可以读写目标服务器文件。  

  

首先利用命令进行访问：

  

![](../Images/f4b88113bbaddbc1541e374bb7b4da35.png)

  

如图所示，有一个src模块，然后列出这个模块下的文件。

  

![](../Images/2043fc0545a04c0de65fdc0de02123d8.png)

  

看到一个linux的根目录，接下来可以使用：

rsync -av rsync://192.168.53.128:873/src/etc/passwd ./  来下载任意文件

或者，可以通过写入一个cron任务，然后利用nc来反弹出shell  

  

![](../Images/481e01d8f6406062f1474211ac5739c1.png)

  

![](../Images/222c5c9a67aa37abd9533d72542fa98b.png)

  

接下来查看配置文件的相关选项（cat /etc/rsync.conf）,这一项read only表示只读，如果这一项为no，说明就具有写的权限了，也就可以像之前那样写入一个cron任务，最后来反弹shell

  

![](../Images/4460f986f0754ed3ca1f3055670919fe.png)

**rsync未授权访问漏洞的防御方式**  

  

第一点：要配置认证用户名或者密码，不直接开放访问

第二点： 利用host allow/deny 来控制接入源IP

第三点： host allow/deny 来控制接入源IP

第四点： host allow/deny 来控制接入源IP

第五点：非必要应该仅限制配置路径下可访问

  

参考链接：[https://www.jianshu.com/p/615669b7311f](https://www.jianshu.com/p/615669b7311f)

  

**02**

**tomcat的PUT方法上传任意件漏洞**

  

当存在漏洞的Tomcat 运行在 Windows 主机上，且启用了 HTTP PUT请求方法，攻击者通过构造的攻击请求向服务器上传包含任意代码的 JSP 文件，造成任意代码执行，危害十分严重。

  

参考链接：[https://dwz.cn/HiOrf30d](https://dwz.cn/HiOrf30d)

  

本次使用的漏洞环境主要为：**Tomcat版本：8.5.19**

  

在Tomcat安装目录下的配置文件web.xml中的org.apache.catalina.servlets.DefaultServlet方法下如果该方法有如下代码，即表示Tomcat已开启PUT方法，就可以通过PUT方法直接上传一句话木马 

  

![](../Images/215ed78e29e041ca25f88ca540355b52.png)

  

接下来打开漏洞环境：

  

![](../Images/fb4549c10ab3039d00a5e35794f46c11.png)

  

一般情况下可以使用脚本进行攻击，也可以使用burpsuite进行PUT传输webhsell然后进行命令执行。为了更好地理解，这里分享的是第二种方法，用burpsuite进行PUT上传webshell。

  

打开burp进行抓包，发送到repeater模块，将传输方式修改为PUT，然后带着webshell，点击GO之后，返回状态码为201即可。

  

![](../Images/92d6d38b6176fdb93686a89deccf895c.png)

  

![](../Images/b6a8c8edef07139a6162ab877fc9c7b5.png)

  

接下直接访问查看文件是否真的已经上传上去了。  

  

![](../Images/65563376d8597c17b026d1655fdbab7d.png)

上传成功之后连接webshell就可以直接执行系统命令了

  

![](../Images/d2b79e5e1c60dbb1e0c5022065c0444d.png)

另外，建议大家将漏洞环境搭建在windows环境下之下，因为用centos搭建的时候会遇到很多问题。有时上传上去显示404，有时上传上去却执行不力命令。

  

参考链接：[https://dwz.cn/pZ10g7PQ](https://dwz.cn/pZ10g7PQ)
