# 01 XSS可以做什么

  

  

对于XSS，大家对于他的危害的感受最直观的可能就是盗取Cookie和弹框，利用XSS还可以进行内网渗透、调用摄像头、挖矿等。  

  

![](../Images/191eabdb7b3f60a189ab0daa0d72dc35.png)

  

# 02 XSS的挖掘流程

  

  

![](../Images/1789f4c12e18b170e0a5f8cba761d01a.png)

  

*   任何可以进行数据提交的点都是注入点，比如说GET/POST提交的内容、HTTP请求的header头等，这些都属于注入点。
    

  

*   第二步就是根据这些注入点进行测试，看看哪些注入点提交的内容可以注入到页面里；测试的方法就是通过这些注入点提交关键词，然后再到页面的DOM数中查找关键词。
    

  

*   一旦找到了可以注入内容到页面的注入点后，接下来要做的就是根据页面的DOM结构或者过滤的情况，去构造Payload来生效XSS。当然，也有可能虽然内容可以注入到页面，但是确实不存在XSS的情况。整体的一个挖掘过程其实就相当于不断构造Payload进行测试的过程。

# 04 XSS防御 

  

  

*   首先可以做的就是转义，针对script等特殊标签直接做HTML的转义，让Payload失效。
    
*   还有就是可以使用CSP，也就是内容安全策略，现在的浏览器基本都支持，直接对页面加载的资源进行限制，采用白名单的形式，我们可以通过它设置比如允许页面加载哪些来源的JS文件。这样的话，类似于XSS盲打中的JS攻击链接不在于白名单中就无法被加载，于是攻击就无法产生。
    

  

*   另外的话，比如使用一些语言的开发框架，比如Python的Web开发框架Django，就自带安全机制或者API，只要按照规范开发，框架本身会自动化进行相关的处理。
    
      
    
*   还有就是可以使用一些WAF产品，WAF就是针对Web攻击进行防护的，现在很多的WAF产品也基本使用AI等进行规则训练和识别，在针对大部分的攻击防护上效果也是比较好的。
