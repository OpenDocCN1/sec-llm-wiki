# 01CSP是什么

  

  

W3C组织还针对XSS攻击制定了一个叫做CSP的东西，也就是内容安全策略(Content Security Policy)的东西；它的出现是为了帮助检测和缓解某些类型的攻击，比如跨站脚本(XSS)和数据注入等攻击，从而引入的浏览器策略。

  

开发者可以根据CSP的规范，去创建一些很严格的规则，比如说白名单策略，管理网站允许加载的内容。当网站加载了非预期的内容，浏览器会及时阻止并且上报，减少出现安全风险时的损失。

  

CSP可以在HTTP的响应头中设置Content-Security-Policy的值，或者在html里插入meta标签来实现，如果都设置的话，以HTTP响应头里的为准。
