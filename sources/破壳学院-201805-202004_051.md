个人背景

Li，本科，电子信息工程专业，毕业一年半，有javascript、php、python 语言基础，目前自学Web 安全中。

  

一、认识 HTML

  

简单理解 HTML 就是标签集，像这些  <h1>你好</h1> 是标题标签。网页的前端页面由许许多多HTML的标签写成。

  

在Web安全中我们需要认识的标签有：

  

*   <img> 图片标签；
    
*   <link> 引入外部资源标签；
    
*   <script> JavaScript 脚本标签；
    
*   <iframe> 嵌入页面标签；
    
*   <form> 表单标签；
    
*   <object> 引入对象标签，比如引入图像、音频、视频、PDF 以及 Flash等；
    
*   <video> 引入视频标签；
    
*   <audio> 引入音频标签。
    

  

我看了这几个标签都有一个**共性**，**都是带有 href 或 src 属性的**，**也就是说****，这些可以在网页中引入内容的标签，如果我们用它们引入恶意的内容或代码，那么漏洞就产生了。**

  

二、认识 CSS  

  

CSS 是用来修饰 HTML 的，让网页更美观，也可以增加一些动画效果。

  

引入CSS的方式有两种：

  

*   在<link> 标签中引入 .css 文件；
    
*   在其他html标签中添加 style 属性，直接编写样式。
    

  

**在 Web 安全中，CSS 也会产生安全问题，比如利用CSS窃取用户密码，具体原理是通过选择器定位密码输入框，根据输入框内最后一个字符加载不同的网络图片，然后查看图片服务器的日志来判断你在密码输入框内输入了什么内容。**  

  

三、认识 JavaScript  

  

JavaScript是脚本编程语言，在网页中执行 JavaScript 的方式有几种：

  

*   创建 <script> 标签，标签之间编写JavaScript代码；
    
*   创建script标签并设置src属性,加载外部的JavaScript脚本；
    
*   各种HTML标签的属性中编写,比如<img src="x" onerror="alert(1)">
    

  

**在前端漏洞挖掘中，通常需要用 JavaScript 语言写一些验证漏洞代码，来控制页面，获取信息等。**

  

四、个人心得总结

  

我们在学习 Web 安全中，肯定需要 HTML、CSS、JavaScript 这些基础，不是说需要 Web 前端开发很厉害，但与 Web 安全相关的知识点还是一定要掌握的，至少什么标签容易利用，会基本的 JavaScript语言编写，这些基本的需要掌握。不断学习，多动手，多总结，相信自己一定可以的。
