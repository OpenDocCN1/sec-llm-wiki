# 俄罗斯银行失窃100万美元，原因居然是路由器太渣

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4Nzc1MDc3Mw==&mid=2247483907&idx=1&sn=906733b4961aa466899d6b1703219db9&chksm=ebc9ad19dcbe240f29db84ba5fa6dc5435b852b688a6717794ea1f2749054d41d7111d92cbe2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4Nzc1MDc3Mw==&mid=2247483907&idx=1&sn=906733b4961aa466899d6b1703219db9&chksm=ebc9ad19dcbe240f29db84ba5fa6dc5435b852b688a6717794ea1f2749054d41d7111d92cbe2&scene=27#wechat_redirect)

最不起眼的东西，往往可能是最致命的。

  

国外恶意软件研究技术网站 BleepingComputer 报道，俄罗斯 PIR 银行最近遭到黑客组织 MoneyTaker 攻击，通过技术手段，Money Taker 从 PIR 银行系统里窃取了近 100 万美元。

  

![](../Images/a57e24e56e0fba0a3d96f50ef30e7f61.png)

  

而这个锅，要甩给在角落里默默付出的路由器。

  

**01**

  

据俄罗斯安全网络公司 Group-IB 表示，5 月底，MoneyTaker 通过 PIR 银行一个区域分支机构的「过时路由器」逐步渗透到 PIR 银行的网络中。

  

![](../Images/c495fe2eed966ad9962ec7772ca67563.png)

  

路由器有隧道（ tunnels ，类似于点对点的连接），允许攻击者直接访问银行的本地网络。

  

Moneytaker 利用这一特性，攻击拥有区域分支网络的银行至少三次，但只有倒霉的 PIR 银行，因为路由器没有及时更新而遭殃。

  

黑客通过路由器给银行分支机构植入恶意软件，然后，他们使用 Powershell 脚本，持续进行而已操作，并且难以被检测得到。

  

Moneytaker 倾向于用一些常见的工具进行入侵，并会在犯案后抹去自己的痕迹。

  

当 Moneytaker 渗透到 PIR 银行的内网时，他们获得了访问 AWS CBR 账户的权限，这是银行控制金融交易的系统。

  

经过近两个月的入侵，在 7 月 3 日，Moneytaker 开始大肆地将 PIR 银行的资金转移到预先准备好的 17 个银行账户中，并组织人员迅速从 ATM 中提取现金。

  

当第二天银行工作人员发现系统遭受到黑客攻击时，撤销交易已经为时已晚。

  

这不是 Moneytaker 第一次对银行下手，从 2016 年成立以来，这个黑客组织已经从银行手里窃取了数千万美元的资金，包括 15 家美国银行，1 家英国银行软件公司和 5 家俄罗斯银行。

![](../Images/a63e50eceea10fdbcf9f38b147e89ef7.png)

  

  

**02**

  

路由器几乎是每个家庭必备的网络中枢，但无论是机构还是个人，往往都很容易忽略掉路由器的安全。下面这些设置能在一定程度上保证路由器不被轻易入侵，将危险程度降到最低的同时，也能杜绝一切蹭网者。

  

![](../Images/68c9d427772611a68b315b620d973298.png)

  

**1）关闭 WPS 功能**

  

路由器的 WPS 是 Wi-Fi Protected Setup（Wi-Fi 保护设置）的简称，目的是为了简化设备与路由器的连接步骤，当支持 WPS 的无线设备在登入 WIFI 提醒输入密码时，只需要按下路由器的 WPS 按钮，就可以免去密码登录这一步。

  

但 WPS 方便了用户的同时，也方便了入侵者。启用 WPS 加密后，路由器非常容易遭到蹭网软件破解，为什么家里的网络越来越卡？也许你就是被蹭网了。

  

**2）使用 MAC 地址过滤功能**

  

每一个电子设备都有一个唯一的 MAC 地址，一般情况下是无法更改的。在启用 MAC 地址过滤后，只有添加在 MAC 地址过滤列表里的设备才会允许接入网络。

  

**3）开启 DHCP 服务器**

  

DHCP 服务原本是自动给接入设备分配 IP 地址和子网掩码，但我们可以利用它的特性，限制接入设备的数量。

  

只需要按照接入设备的数量，在地址池开始和结束框中制定相应的范围（比如有 5 台设备，范围就设定在 192.168.1.10——192.168.1.14）。

  

当然，我们还可以利用 DHCP 分配静态 IP 地址，相当于将 IP 地址和设备的 MAC 地址绑定，双重保障。

  

**4）设置复杂密码**

  

无论任何时候，越复杂的密码意味着被破解所需的时间就越多，因此，为了安全，密码还是尽量复杂一些吧。
