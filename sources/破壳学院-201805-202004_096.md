**第一阶段作业**

**1-4.使用 Arachni 发现 Web 漏洞作业:**

  

搭建 Arachni，并创建一套规则,然后扫描 [http://www.vulnweb.com/ ](http://www.vulnweb.com/)上面的其它测试网站,输出扫描报告

  

**2-3.了解一个网站的部署与运行机制：**

  

利用 PHPStudy 或者宝塔搭建 wordpress ，并记录下中途出现的错误和解决过程

  

**3-3.Web 工作流程(包含 HTTP 协议)：**

  

配置好浏览器和burp工具，访问 [pockr.org (http://pockr.org/)](http://pockr.org/)，并拦截数据包，尝试修改请求和响应内容观察变化，记录下来

  

**3-6.Cookie 与 Session：**

  

选一个熟悉的网站访问，分析出用于保存登录状态的信息是在哪一段 cookie 中(请注意对 cookie 的内容进行马赛克处理)
