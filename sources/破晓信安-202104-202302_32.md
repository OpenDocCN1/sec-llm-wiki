0x01 信息收集  

##1. 靶机IP查找：

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop]└─$ sudo netdiscover -i eth0 -r 192.168.94.0/24
```

![](../Images/a08907ef0bbe8508d1cb28c4b01a5c96.png)

##2. 端口信息枚举:

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop]└─$ sudo nmap -sS -sC -sV -Pn -p- 192.168.94.129
```

开放了两个端口，分别是9999和10000，9999为该系统的监听端口，10000为http服务端口

![](../Images/f18acd382092a6a957b397b2c1dd6343.png)

##3. 枚举http路径:

*   
*   

```
┌──(cxyzupup㉿kali)-[/usr/share/wordlists/dirbuster]└─$ gobuster dir -w directory-list-lowercase-2.3-medium.txt -u http://192.168.94.129:10000
```

发现bin路径，访问后发现一个exe的文件

![](../Images/f0eb510f119cfc3ddb0ef318d3844682.png)

##4. 收集exe文件信息：  

###4.1 运行环境检查：  

发现该文件运行环境为Windows 32

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop]└─$ file brainpan.exe
```

![](../Images/3967c48373c7242ef617b972b7cf13f3.png)

###4.2 运行行为检查：  

使用wine运行该文件，发现该文件开启了9999端口监听

*   

```

```

![](../Images/4bab6f56dd0563490483220ddd9cd666.png)

###4.3 文件下载到本地使用nc建立连接

*   
*   

```

```

![](../Images/65fe2e2c4c9f6ddd745daa1e71491606.png)

###4.4 枚举二进制文件中的可打印字符串

0x02 弱点测试

##1. 二进制文件溢出测试：

这里需要把二进制文件拷贝到一台测试环境机器中，使用Immunity Debugger工具进行调试

###1.1 测试二进制文件可接受的字符长度：

长度达到1000后，连接异常

![](../Images/971b5cb00ae96ab9d60a0f75ba857309.png)

###1.2 生成1000长度的字符串：

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ /usr/share/metasploit-framework/tools/exploit/pattern_create.rb -l 1000
```

![](../Images/52be8015110f026681312ccd244c30b4.png)

###1.3 运行脚本后查看EIP位置：

发现EIP位置已被35724134替换

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ python brainpan1.py 192.168.94.130 9999
```

![](../Images/e176307229cf661577a6de82e87ba946.png)

###1.4 获取缓冲区可接受控制的字节数（EIP位置）：

匹配到可偏移的长度为524

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ /usr/share/metasploit-framework/tools/exploit/pattern_offset.rb -q 35724143
```

![](../Images/d41e45ef4ba537a78fa047ca05f52890.png)

发送524个A、4个B、472个C进行测试，发现eip位置已被3个42（ascii：B）填充了

![](../Images/0f127b4147c585299c828fff4791cb30.png)

###1.5 测试应用程序可识别的错误字符（ESP位置）：

发现除了空字节外其他都能使用

*   
*   

```
┌──(cxyzupup㉿kali)-[~/Desktop/brainpan溢出测试]└─$ python brainpan3.py 192.168.94.130 9999
```

![](../Images/c0b800fee2bcc7c219623edc86f2dd32.png)

![](../Images/94c49f250e1cdbb8ed419a406f842b40.png)

###1.6 找到堆栈地址：

堆栈地址为311712F3

![](../Images/5eab91bbeabf184ae210083f7692bdd5.png)
