10:弱注册表权限


来源: Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc

继续接着上篇文章的首先使用sc qc regsvc查询注册表信息。可以看到在SERVICE_START_NAME这里是System权限。


当然按照之前的套路我们是用accesschk.exe来检查这个BINARY_PATH是否允许普通用户有特权。当然这里我自己试验过了失败了。这里就要用到另外一种方法了。

















先引入一波概念。这次我们是注册表提权,所以得先理解一波前置知识。在Windows系统上，操作系统、驱动程序、和系统安装组件、服务会存放在注册表中。而注册表会通过树类进行区分,如下图所示，会分成四个树类型。而我们的regsvc是在HKLM \ SYSTEM \ CurrentControlSet \ Services 红色箭头这里。



接下来再讲讲这个注册表树, 根据微软的官方手册介绍https://docs.microsoft.com/zh-cn/windows-hardware/drivers/install/hklm-system-currentcontrolset-services-registry-tree

在这个注册表树中，会存放着有关系统上的每个服务信息。每个驱动程序/服务都有一个格式为HKLM\SYSTEM\CurrentControlSet\Services\服务名 的键。比如说regsvc对应的格式为

HKLM\SYSTEM\CurrentControlSet\Services\regsvc。

















用accesschk.exe检测regsvc注册表可以知道当前用户权限发现是可修改的。(\INTERACTIVE代表着所有登录用户都有权修改)


/accepteula=自动接受许可协议

-u=抑制/忽略错误 -v=详细信息 -w=只展示有读写权限的用户组 -q=忽略banner -k=后面是注册表项如\hklm



那我们的提权思路有了通过修改注册表路径指向我们的反弹文件然后获得一个更高权限。使用reg add命令进行修改。关于修改命令可以参考这篇文章 https://blog.csdn.net/opl001/article/details/1597779 最后重启 服务


修改格式为:reg add KeyName /v EntryName /t DataType /d value /f

Keyname=具体的注册表路径比如这里的HKLM\SYSTEM\CurrentControlSet\Services\regsvc

/v =指定要添加到指定子项下的名称

/t=数据类型这里的REG_EXPAND_SZ意思是长度可变的数据字符串。

/d=指定新注册表项的值

/f=不用询问信息而直接添加子项


再次开启nc成功接收。

这里先简单介绍下AutoRun,它是一个window下自动运行的文件命令。你可以把它理解为Windows开启时可能会自动运行某些杀毒软件或者自带的程序。我们假设作为普通用户进去到Windows以后想提权可以检查下有没有AutoRun的程序，可以把之前准备好的反弹shell作为代替。这样当管理员上线的时候系统也会运行一些管理员能够使用的某些自动运行的特权程序从而可以得到一个反弹shell。注:Autorun提权还需自己模拟管理员。


这里在windows靶机上进入powershell模式先运行PowerUp.ps1提权辅助工具然后执行Invoke-AllChecks找找哪有问题。

















拉到下面这就是我们这次要找的autorun自动开机会运行的文件。

















在拷贝覆盖AutoRun文件前需要先用accesschk.exe检查一下当前用户是否有权限随意更改这个program.exe文件。在检查以后可以看到有个RW Everyone代表任何人都可做更改。

命令:accesschk.exe /accepteula -wvu “C:\Program Files\Autorun Program\program.exe”

-w=只列出拥有可写权限的角色

/accepteula=自动接受许可协议

-v=详细信息

-u=忽略错误

















那容易了直接用copy复制覆盖过去。

















然后这里需要自己模拟管理员上线输入其账号什么都不用做就可获得管理员的反弹shell了。



12:弱AlwaysInstallElevated权限


来源: Try Hack Me

房间链接: https://tryhackme.com/room/windows10privesc


这里先简单介绍下AlwaysInstallElevated。它是一个Windows策略允许普通用户在使用MSI包安装软件时获得系统权限去操作。同时它在注册表里面也会由一个值，如果为1的话普通用户拥有和system一样的权限去安装.msi文件。关于更多的资料可以看看微软官方对此的介绍 https://docs.microsoft.com/en-us/windows/win32/msi/alwaysinstallelevated

















关于alwaysinstallelevated在注册表的位置如下只有值为1才代表具有系统权限:

HKEY_CURRENT_USER\Software\Policies\Microsoft\Windows\Installer

HKEY_LOCAL_MACHINE\Software\Policies\Microsoft\Windows\Installer

















这里可以用reg query对alwaysinstallelevated在注册表的值查询了下都为1

















满足基本条件以后我们可以重新用msfvenom制作一个新的.msi 恶意软件出来。

















用刚才传文件的方法传过去，或者是MSF直接用upload命令传文件过去。传完以后使用msiexec 命令执行。

















新开一个nc监听会获得一个更高权限的shell。

















如果觉得刚才的方法过于复杂也可用MSF脚本小子的方法。前提是你MSF也能获得一个shell。先按住ctrl+Z退出去，搜索alwaysinstallelevated可以找到一个可利用的模块。

















使用该模块，填好刚才建立起来的会话。更新自己的lhost和端口以后执行就会自动帮你弄好变成高权限了。

15:令牌窃取

来源:Try Hack Me

房间链接: https://tryhackme.com/room/alfred


注:这个方法是在MSF实现的。

在Windows系统里面，它会用令牌(tokens)确保电脑上每一个账户具有不一样的特权。当用户成功登录或通过身份验证或通过魔法攻击进入后会分到一块令牌。


这个令牌会包含三个东西，一个是用户的SID(安全标志)，一个是组SID,最后一个是特权/权限。


当然令牌也分两种:

1.主要访问令牌:与登陆时生成的用户相关的令牌

2.模拟令牌:允许特定进程使用另外一个进程的令牌去访问资源


这次的重点是模拟令牌,而模拟令牌也有不同的级别:

SecurityAnonymous:当前用户不能冒充另外一个用户

SecurityIdentification:当前用户可以获得客户端的身份和权限但无法冒充

SecurityImpersonation:当前用户可以在本地模拟客户端的相关安全信息

SecurityDelegation:当前用户可以在远程系统上模拟客户端的相关安全信息


账户的权限有很多，其中以下是最常用被用来提权的:

SeImpersonatePrivilege

SeAssignPrimaryPrivilege

SeTcbPrivilege

SeBackupPrivilege

SeRestorePrivilege

SeCreateTokenPrivilege

SeLoadDriverPrivilege

SeTakeOwnershipPrivilege

SeDebugPrivilege

















在做该靶机的时候有两个shell，yige1是普通的一个是MSF的，在普通的nc shell上先执行whoami /priv可以看到SeDebugPrivilege, SeImpersonatePrivilege是Enabled状态，有权限配置失误。

















回到MSF的meterpreter这里，加载最重要的incognito来窃取我们的令牌，然后可以用list_token查看参数(忽略我总是忘了s),主要有-g 和-u

















使用list_tokens -g 发现目前我们有机会窃取到管理员的令牌。(-u也可)

















最后来个impersonate_token "BUILTIN\Administrators" 绝杀 提权成功。

















然而此时还有个问题，由于我们是用模拟令牌提权成功的，Windows权限这里还会考虑检查主要访问令牌。所以我们需要线程注入，溜到其它地方才行

附录1:Windows下信息收集


1.用户枚举

-查看当前用户权限:whoami /priv

-列举目前这台机子上存在的用户


-查看当前有谁远程登录


2.查看系统信息: systeminfo


3.查找某些文件: findstr /si password *.txt/.xml/.ini/.config

Findstr: 类似于LINUX里面的find查找功能

/si: 查找当前目录和所有子目录且忽略大小写

Password: 关键词可替换

*.txt:覆盖所有txt文件可替换为xml或其它

4.查看什么时候打的补丁: wmic qfe get Caption,Description,HotFixID,InstalledOn


5.查看当前防火墙window defender状态:sc query windefend


附录2:Windows下接收文件


方法1:

首先需要目标开启了3389可远程登录，然后你得拿到一个正常权限的用户以后你就可以用kali自带的xfreerdp来远程登录

命令: xfreerdp /v:10.10.66.160 /u:Atlas /p: H0ldUpTheHe@vens /cert:ignore +clipboard /dynamic-resolution /drive:share,/tmp

解析一下/v:后面跟的是IP, /u后面加的是用户名, /p后面跟的是密码 /cert:ignore忽略后面可能会出现的 yes和no, +clipboard允许复制粘贴, /dynamic-resolution重新设置窗口大小 /drive:share,/tmp挂载kali下的/tmp目录，达到共享文件的效果 这里点击This PC以后可以看到有个share on kali的字样点它就对了。可以看到除了默认文件可以加自己想要的文件。摸鱼方法但只适用于靶机上。
