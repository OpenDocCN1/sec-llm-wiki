02前置知识之简单概括和常见术语


这里会先翻译下Attacking Kerberos的基础内容。Kerberos是域内默认的身份认证服务,通过使用第三方门票授权系统以及更强的加密方法比只用NTLM更安全一点。当然,Kerberos虽然是进化版的NTLM但仍然有漏洞可以利用。



接下来是一些常见的术语:

Ticket Granting Ticket(TGT 门票发放):访问者想要访问域内某些资源需要得到一张身份授权的门票才可访问。


Key Distribution Center (KDC 密钥分发中心):KDC由身份验证服务和票证授予服务组成。主要用来分发门票(TGT)和服务票证。


Authentication Service(AS 身份验证服务):KDC组成的一部分,可以当成门票上的盖章,认可访问者的身份。


Ticket Granting Service(TGS 票证授予服务):TGS会获取TGT然后把门票转回给域



Service Principal Name(SPN 服务主体名称):SPN是kerberos身份验证时唯一的网络标识符号。用来把具体的某个服务和其域服务账号关联。Windows要求每个服务抖要有一个域服务账号,比如说MYSQL数据库需要一个数据库账号。


KDC Long Term Secret Key (KDC LT Key KDC 长期密钥): KDC 密钥是基于 KRBTGT服务账号的。主要用来给TGT加密和给PAC签名。


Client Long Term Secret Key (Client LT Key 客户端长期密钥):客户端密钥是基于计算机或服务账号。主要用来解密密钥和检查时间轴是否对的上。



Service Long Term Secret Key (Service LT Key 服务端长期密钥):服务端密钥是基于服务账号,专门用来加密服务票据的服务部分和给PAC签名。


Session Key(会话密钥):在请求服务票据时,用户会把TGT和会话密钥一起给KDC。


Privilege Attribute Certificate(特权属性证书):上面会记载每个用户的具体信息和不同的权限。


03前置知识之Kerberos验证过程


上面讲了一些基础的常见Kerberos术语，下面会讲讲kerberos的身份验证过程

1:客户端访问者首先向域控发起一个请求，请求域控发张门票回来。

2:KDC这里会验证客户端请求者的身份，然后返回一张加密好的门票(TGT)。

3:客户端访问者会把加密好的TGT与客户端想要访问的域服务发给TGS审批。

4:KDC会检查访问者的TGT和想要访问的域服务,如果审核通过会返回一给会话密钥给访问者。

5:访问者可以凭借此密钥访问域服务并使用。


04利用Kerberute枚举域内有效用户


前置知识讲的差不多了，现在开始进入靶机实战环节,右上角开启靶机。


前面提及到Kerberos是一个门票系统，当用户持有对应的门票才能进去。门票上会包含用户的具体信息权限blablabla。为了伪装成正常用户混进去，首先需要知道有哪些正常的用户在某个域里面。使用的方法就是枚举,类似于加载一个用户字典不断的询问Kerberos该用户在不在域内的方法。需要的工具可自行下载https://github.com/ropnop/kerbrute。这里我提前安装好了


需要先在/etc/hosts里面加入一条新的信息进去。


用户字典https://github.com/Cryilllic/Active-Directory-Wordlists/blob/master/User.txt


然后就可启动kerbrute枚举域内有效用户了最后有以下用户

命令: ./kerbrute userenum --dc 10.10.190.43 -d CONTROLLER.local User.txt -t 100


05 AS-REP Roasting收割门票信息


在枚举完有效用户后下一步我们就开始精挑细选其中的账号使用AS-REP Roasting攻击获取具体的门票上的密码信息。AS-REP Roasting,是由于某些域内用户可能开启了不使用Kerberos预验证功能。

可以这样理解，你和老王长的很像，某天你去他公司,楼下保安见你长得像老王，外加平时老王跟保安的关系很不错。看了你一眼不会把你当成陌生人拦下来问各种问题验证是否为来客。此时你可以去到老王的办公座位随意找信息,说不定能找到一些密码信息出来。


这里会用到kali下的/usr/share/doc/python3-impacket/examples/GetNPUsers.py工具去收割门票上的密码信息。通过不断替换用户,最后admin2和user3启用了不使用kerberos预验证功能。顺便获得他们的hash，可解密。

命令: python3 GetNPUsers.py CONTROLLER.local/admin2 -no-pass


最后用john搭载一个密码本解密成功，成功得到admin2的账号密码，密码本字典链接

https://github.com/Cryilllic/Active-Directory-Wordlists/blob/master/Pass.txt


最后使用SSH成功登录
