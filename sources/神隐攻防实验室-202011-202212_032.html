靶场介绍

本次靶场是Try Hack Me的authenticate https://tryhackme.com/room/authenticate ,翻译过来是突破验证,本文会讲讲几种突破登录界面的方法。


02

暴力破解方法


破解登录端口最简单的方法就是抓包加载一个字典爆破看看有没有用户能跑出来。这种方法虽然简单但是成功率是个谜,有时也许admin 123456就进去后台了有时你把kali上所有字典跑一遍都不一定能成功,这里只为简单的演示。
























这里Try hack me减轻了难度，给定了一个用户Jack,只需要爆破其密码即可。开启Burp 启动抓包功能。
























捕捉到输入的信息右击点send to Intruder里面把123456密码段标起来
























然后点Payloads选择加载字典这里的字典我选用的是kali自带的/usr/share/wordlists/fastattack.txt字典。选择好以后点击Start attack
























最后可以通过长度判断，如果有其中一条跟其它格格不入的多半是它了。最后密码为12345678.
























最后登录成功。


03

重新注册方法


重新注册一般存在于注册界面主要是欺负系统的逻辑，判断不出哪个是注册过的账号。
























比如说现在输入一个已有的账号名darren重新注册,密码随便设计正常的系统会先拿去后台检验发现该账号已存在会返回用户已存在。
























那此时我们可以尝试一个新的方法去欺负系统的智商。Darren存在但是不代表空格darren注册不了。
























此时点注册会成功弹回去，这里用空格darren登录，此时系统判断不出来哪个是darren毕竟都是一样的东西。直接把你当成darren放你进去了。


04

篡改JSON WEB TOKEN方法

JSON WEB TOKEN简称JWT, 是一串比较长的base64加密字符串也是比较主流的授权方式之一。主要是用了公钥和私钥来生成一个cookie，从而让系统知道该用户登录以后要赋予什么权限。


先解析一下JWT的组成。下面是一个JWT的例子，JWT由三部分组成以点作为分割。


eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9. eyJzdWIiOiIxMjM0NTY3ODkwIiwibmFtZSI6IkpvaG4gRG9lIiwiaWF0IjoxNTE2MjM5MDIyfQ. SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c


一般第一部分称为header,里面会包含使用的算法和token类型。Alg里面的值可以为RSA, SHA256 之类的甚至是NONE也可以。

比如第一部分解密后为:

{ “alg”: “HS256”, “type”: “JWT”}


第二部分称为payload,里面会包含用户的ID和一些其它个人信息

解密后为:

{

  "sub": "1234567890",

  "name": "John Doe",

  "iat": 1516239022

}


第三部分为签名主要是确保数据的完整性，一般不会篡改这部分。一般解密后也是串奇怪的字符串。
























接下来通过一个实际案例看看如何更改JWT部分达到偷换身份效果。


首先输入一个已知用户user,点击验证顺便开启抓包模式可以看到其数据。
























验证完点击GO以后看到授权这里有串JWT 字符串,可以复制下来等下解密。
























点击Forward可以看到弹出欢迎user用户。
























先解析下刚才的JWT字符串。可以用https://jwt.io/#debugger-io 该网站解析。第一段是加密类型和信息，第二段有个关键词identity 1。


篡改JWT的目的就是为了获得其它用户的身份令牌，让网站赋予更高的权限。当然不能直接把identity改为其它值，由于第三段是加密套娃所以需要联动第一段一起改掉。
























由于是base64加密那好吧随便选一个在线的先把HS256改为NONE加密获得第一段。


然后就可改identity的值这里可以改为0或者2都行
























第三段不用改，每段加.作为分割最后点GO用Burp抓包以后把原有的JWT字符串做替换
























点击Forward以后可以看到已经变成欢迎管理员而不是guest了。
