# **0x00:前言**  

Openvas是一个开源免费的漏扫，由于是免费的所以大家对它不用太过看重。毕竟免费开源给我们随便用准确率我只能说还行。

  

# **0x01:安装**

1.首先可以更新一波当然这个是可选项非必须

命令:sudo apt-get update

![](../Images/48368cab1a3bb61513ecfb6a4bd21c94.png)

  
  
  
  
  

  

2.然后就是正式安装了有多种安装方法，可以在github上下载过来，也可用docker,这里我直接用apt-get install命令安装

命令:sudo apt-get install openvas

![](../Images/2c5a99e0a83b154368dff607425254ba.png)

  
  
  
  
  

  

3.安装好之后就可以开始进行一波设置了等待的时间有点长,最后会顺便告诉你用户为admin密码为一串长字符串如下图所示

命令:sudo gvm-setup

![](../Images/999aaca4c78f1e206406cd45e881cb74.png)

  
  
  
  
  

  

3.5如果想检查看看安装有没有问题可以用以下命令查看一波最底下出现It seems like your GVM installation is OK那应该没问题了

命令:gvm-check-setup

![](../Images/98301decc2ef08ea0330a9af7615ce20.png)

  

# **0x02:启动**

4.设置成功以后就可以启动了

命令;sudo gvm-start

![](../Images/8aaab216070d6dce70d4815355c07728.png)

  
  
  
  
  

  

运行完上面那条命令会自动打开浏览器输入刚才的admin和其密码就可登录成功了。

![](../Images/28b2d899f935da459a33cda31f1e3d42.png)

  
  
  
  
  

  

如果想改密码的话我这里用的方法是先点Administrator下的users先点第一行最右边出现绵羊的那个图标克隆一波然后再点下面的修改按钮重新设置一个新密码，相当于多添加一个最高权限管理员进去。

![](../Images/2d7b8f1a7513c4ea5d98a927ccf7000b.png)

  

# **0x03:扫描**

这里开始进行测试，这里的靶机使用HackTheBox的Blue就是永恒之蓝专用靶机。开始测试，首先点击scan下的task会跳到一个新的页面，点击魔法棒旁边的按钮是添加新的扫描。

![](../Images/4708e76585ac46d4b903add7a84319e7.png)

  
  
  
  
  

  

点击去以后名字随便填，这里需要点Scanhosts旁边的那个按钮

![](../Images/57f078480b31ab988ee561cfab3575ac.png)

  
  
  
  
  

  

这里它会带你又跳到新的页面，在Hosts这里填目标IP进去，就可以点击save了,连点两次save。

![](../Images/28da3af46137dc72c88ae1b782aa3f3a.png)

  
  
  
  
  

  

保存完之后就可以点三角按钮启动扫描。

![](../Images/42e5f79e291e1755f0a7b9b938caab9d.png)

  
  
  
  
  

  

扫描完以后可以点Reports看详细信息，先点击1

![](../Images/972a83c79cee8cf5444d610800283027.png)

  
  
  
  
  

  

然后再点Task

![](../Images/fb415d400e2d9cacdc0f7ca510012b2d.png)

  
  
  
  
  

  

最后点上面的report

![](../Images/2107d7731242c7825505f805f531185c.png)

  
  
  
  
  

  

就可以看到最终结果了,最后能扫出存在MS17010永恒之蓝这个漏洞和另外一个绕过验证的漏洞。总的来说还行也可以尝试玩玩。

![](../Images/b9a6d8ac26cfa178f91c148320f05c8c.png)
