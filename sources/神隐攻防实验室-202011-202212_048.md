# **0x00:工具介绍**  

AutoRecon是一款信息收集工具，使用方法比较简单，只需要autoreon ip就可以自动联动nmap, gobuster, nikto,如果有smb服务的话也会顺便联动smbclient之类的工具。适合我这种懒人做信息收集，Github下载地址为 https://github.com/Tib3rius/AutoRecon

  

# **0x01:安装方法**

点击右上角的绿色按钮code,有个Download,熟练git的话可以直接下载也可。

![](../Images/caddae3744142ab38afa8f37258d3725.png)

![](../Images/3de5646fc1fba2af4263e3408f657a4d.png)

  

解压缩包以后进入目录文件夹会有一个requirements.txt,里面需要python的额外库函数可以使用pip install -r requirements.txt 进行安装

![](../Images/8cc9dd524b78280277756028cefa606b.png)

![](../Images/3de5646fc1fba2af4263e3408f657a4d.png)

  

安装完成后继续进src目录再进autorecon目录最后看到autorecon.py就到了。

![](../Images/8b00624900e9b1d4c073cf63a1f5b664.png)
