# **0x03:利用Burp/Hydra爆破后台**

Try hack me 这里也没有太为难我们，告诉我们可以爆破，且用户名为admin，所以只需要爆破密码就可。关于爆破你可以用Burp或者是hydra。先说说Burp,开代理，然后抓包丢到intruder这里，给密码标起来。

![](../Images/c8e304fb6798882da833f0c78595ddb6.png)

  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  

  

去payload加载字典，关于字典的选择kali其实有很多，不建议用rockyou.txt因为太大了，Burp会卡住然后崩溃。这里我用的字典是/usr/share/wordlists/Metasploit/adobe\_top100\_pass.txt这个密码本。然后选择启动攻击

![](../Images/8feed7e5b02cefcbb0c3dbff8be55af0.png)

  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  
  

  

最后查看length总有一个是与众不同的。如果没有那可能是密码本不行换下一本

![](../Images/eb5d4ab8148fccd63514e8f999cc7f28.png)
