# **0x01:Windows文件系统解析**

Windows文件系统系统结构如下:

本地磁盘(C\\D\\E盘)

默认的文件夹(下载、文档、音乐之类的)

自己创建/下载的文件

  
  
  
  
  

  

当然在C盘下会有一些比较特别的文件，也许你装应用的时候会自动帮你装到这里，但是你不一定能明白它们有啥用。这里简单讲解下

![](../Images/1eeb2521fd269248926f78c3568918a8.png)

  
  
  
  
  

  

PerfLogs:存放系统问题和其它有关性能的报告

Program Files和Program Files(x86):程序安装时默认存放的地方，除非你改自定义安在其它地方。

Users:存放用户数据的地方，比如说你在桌面新建一个word文档，就是放在这里。

Windows:操作系统存放代码的地方和一些自带的工具。

  

# 0x02:Windows文件权限解析

文件系统一般是由管理员或者是某些特权账号所设置的。权限可以分给用户或者是组。

  
  
  
  
  

  

在Windows下通常有以下常见的权限:

  

Full control(完全控制权):允许用户/组设置文件的所有权和给他人设置权限，包括修改，读取、写入和执行文件。

Modify(更改权):允许用户/组去修改，读取，写入和执行文件。

Read&execute(读和执行权):允许用户/组去读取和执行文件。

List folder contents(列出文件内容权):允许用户/组在文件夹里列出里面的所有内容。

Read(阅读权):允许用户/组阅读文件

Write(写入权):允许用户/组写入数据到文件里。

  
  
  
  
  

  

如果想给某个文件或者是文件夹设置权限的话,右击点属性，然后再点安全,最后再点编辑。比如说当前Users拥有读和执行权，列出文件夹内容和阅读权。如果想添加全息点击Allow就可。

# **0x03:Windows身份验证方法**

身份验证在内网里面算是一个比较重要的环节。主要目的就是验证你是谁，你想干什么。在内网里面主要有三种协议认证方法:

1.NTLM/NTLM2

2.LDAP/LDAPS

3.KERBEROS

  
  
  
  
  

  

这里只是简单介绍，不会涉及过深的原理。

  

NTLM/NTLM2:

NTLM在客户端和服务器之间使用一个挑战/应答协议。它不为经过身份验证的网络连接提供数据完整性或机密保护。

![](../Images/0fe9cf8e63da863cd92cc3221b197870.png)

  
  
  
  
  

  

在网上找了找挑战/应答协议的定义:

![](../Images/4959280b58a4b3215c8e9ab890b4b321.png)

  
  
  
  
  

  

LDAP/LDAPS:

LDAP和LDAPS的区别在于LDAPS可以给信息加密。这里提一下域控(DC)可以把它当成一个大的数据库里面存放用户，组和其它的信息。使用LDAP/LDAPS，用户的电脑使用API把身份信息发给域控，验证用户的信息是否正确。

# **0x04:常见的windows服务器**

在windows下有以下常见的服务器:

1.域控(域控有可能是内网里面最重要的。在内网里面通过它可以控制用户、组的权限同时可以提高安全性以及更多的操作)

2.文件服务器(在内网里面提供共享文件)

3.WEB服务器(常见的HTTP服务)

4.FTP服务器(可以在计算机之前移动一个或多个文件,同时提供文件安全传输控制)

5.邮箱服务器(通过内网和网络移动和存放邮件)

6.数据库服务器(存放各种用户数据或其它数据，用户可以访问和查看数据)

7.代理服务器(用来过滤请求、提高性能和共享连接)

8.应用程序服务器(用来连接数据库服务器和用户)
