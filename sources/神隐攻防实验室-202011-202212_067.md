# 0x00:靶机介绍

这次的靶机是Tiki,下载链接为 http://www.vulnhub.com/entry/tiki-1,525/，可在VM下进行。准备好一台kali即可。

  

  

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

看描述其实是一个复现0day攻击的靶机。号称有OSCP级别。但做完以后才发现应该是个OSCP简单级别适合新手进行信息收集，初级的脚本利用即可无需复杂的提权操作。  

![](../Images/db5923106c93406fc59f4d7773bda7b1.png)

  

# 0x01:信息收集

  

在安装完成启动靶机后首先第一步要确定的是靶机IP,排除.1, .2和.254这些默认IP剩下的148就是我们的靶机IP地址。

命令:netdiscover -r 192.168.72.0/16

![](../Images/b5d94e646e6bf4d5520270f7af14dea4.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

还是像往常一样用python autorecon.py去收集端口跑目录信息,这次跑完有很多信息建议多少看一眼

![](../Images/0a416c0932e284915d3851175d0fae60.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

先看看nmap报告,开了22，80，139和445端口

![](../Images/ada551c805143bb405623996bd5e5741.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

接下来打开smbmap-list发现可以读到Mail.txt记录下来等下可以看看

![](../Images/2037553255f3a257b3f45a026266dbd3.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

Gobuster表示80端口只有个/tiki 和robots.txt是可以正常访问的。

![](../Images/26ba37865cf782ae7ce1f5bad9a235e4.png)

  

# 0x02:收集SMB端口信息

SMB端口由于autorecon可以直接读到一些有用的信息，那么我们可以考虑用波smbclient进行连接密码为空登录成功以后可以用get下载到本地

命令:smbclient \\\\\\\\ip\\\\目录

![](../Images/315885f816d7daaa087ac6087649615b.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

打开一看发现一个用户名Silky和一个新的密码

![](../Images/306430edd9c8ddb3bf6dfe33680864d3.png)

  

# 0x03:挖掘80端口信息

由于前面知道gobuster唯一能扫到的信息是tiki跟进一波首页有个大大的CMS。

![](../Images/6b0f7346d9fd150a9b964c6ffe6206ad.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

当然不急先点右上角的Login试试账户是否正确，用刚才Mail.txt里面的账号信息可以登录成功

![](../Images/9f68baa86ae330cfd9795ddeaf117e72.png)

  

# 0x04:收集CMS信息

既然我们目前知道了CMS的名字是tiki wiki,我们首先需要确定版本才能找到相关漏洞根据CMS官网和靶机发布时间为20207月大概推断该CMS版本为21

![](../Images/76af8490f0fbe645831ea2f438491dd6.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

也可以直接在IP后面加changelog里面会包含版本信息。

![](../Images/cb366b8bab3ab9b011aef45d3318e934.png)

  

# 0x05:相关payload

确定完版本号后得找找相关漏洞可以在kali本地下直接搜关键词searchsploit Tiki Wiki 21找到一个相关的绕过漏洞

![](../Images/4de82ba6d9a9fcce900bd487e1f2eade.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  
  

顺着相关名称找到一个CVE漏洞脚本。

![](../Images/cf4eca6b0d3014824c87b913cfb851ef.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  

用searchsploit -m 复制脚本到目前文件夹以后，如果不确定如何用的话可以直接python +名字在最底下有个usage说明方法只需要加个IP就可。

![](../Images/31b3a53ed95d9bb91fcde29a4f2256f4.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

![](../Images/414f411504809b35f6555db981ed5bae.png)

# 0x06:提权

登录进来以后不要向我直接找文件上传点一顿操作猛如虎结果0输出 在所有页面这里有个Credentials页面

![](../Images/2991df103858a27465bdcb6f14558e2c.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)

  

  

点进去有个账号后面的字符串明显不同于前面的Mail.txt的内容

![](../Images/5dcfe165209a6a6aab40b0dbc974bb88.png)

  

![](../Images/414f411504809b35f6555db981ed5bae.png)
