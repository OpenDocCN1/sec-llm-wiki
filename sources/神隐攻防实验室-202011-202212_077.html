0x00:靶场概况

这次的环境是Hack the box challenge的FreeLancer。目前challenge是可以免费玩的。只需要注册一个Hack the box账号即可。这次的FreeLancer需要掌握的技术有sqlmap的工具使用以及目录扫描器的尝试。




0x01:漏洞挖掘


点击Start Instance以后会给出一个IP地址点进去以后是一个正常的页面可以随便到处看看，不过功能点比较少




顺便按住F12或者是右击检查波页面源代码逐层点开以后发现有个portfoli.php?id=1的href链接




跟进一波页面可以正常回显同时是个/id=1的参数







0x02:sqlmap的使用

遇到?id=1我们可以使用sqlmap看看能不能挖掘到SQL注入

命令:sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度)




等了一会如果出现Parameter就是代表注入成功了




接下来输入—dbs查看波数据库 这里选择freelancer

命令: sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度) –dbs(列出数据库出来)




接下来继续深入挖掘数据选择波safeadmin表

命令:sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度) –dbs(列出数据库出来) -D safeadmin(指定表)





这里我直接跑里面的数据了可以看到一个账号和密码但是都无法解密出来卒

命令: sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度) –dbs(列出数据库出来) -D safeadmin(指定表) –dump(跑数据)






然后我们查看波当前用户，当前数据库用户,密码,当前的权限。看到有一个root跑出来可以猜测出这是一个linux系统。那么它存放的路径一般为/var/www/html ,同时往下拉可以看到privilege有个FILE 有可读文件的权限。我们可以尝试把源码拷贝下来等下。

命令: python sqlmap.py -u http://46.101.91.21:30251/portfolio.php?id=1 --current-user -current-db -users -passwords -privileges --batch







0x03:挖掘目录信息

既然无法解密出safeadmin的密码出来改变策略看看能不能挖到后台出来,这里使用kali的自带扫描器dirb命令也很简单只需要dirb + URL就可这里我顺便选上/usr/share/dirb/wordlists/big.txt 大字典扫到一个/administart





跟进一波是个登录页面(这里IP变了是由于死机了重启了靶场一次)





这里我双扫描器跟进了dirsearch这边继续扫 /administrat下面的内容还有个/include





Dirb这边继续配合扫/include的内容扫到一个config.php。如果我们在前台输入的话会发现是空白页面





那只好使用sqlmap使用—file-read功能把源码读出来看看有什么东西,结果只有个数据库密码。。。。


命令:sqlmap -u http://206.189.121.131:31237/portfolio.php?id=1 – file-read=/var/www/html/administrat/include/config.php





改变方向这次把index.php看看登录框里面有什么




发现还有一个panel.php





继续扫这次读到flag了。。。。
