0x00:VPS现状

默认的服务器镜像中都没有kali，常见的就是debian、ubuntu、centos这三种，而这几种我们要各种配置环境，安装软件太繁琐了，可是又不能直接装kali，网上给的方法都是花钱买一块硬盘，而在再一次和大佬吹水时候，学到了还有另一个方法，只测试了ubuntu和debian操作系统，其他的并未测试（Github上有安装脚本，但是安装过程中有一些坑，可能不会自动解决）


方法也很简单，我们将本身的源，修改成kali源，然后更新软件和系统内核，从而将其打造成kali一样的服务器


0x01:VPS网站推荐


关于VPS的网站推荐，可以使用virmarch来搭建网站服务器https://virmach.com/,服务器价格比较便宜,可以选择十几块到四十多块的。而且可以使用支付宝支付。


0x02:实际操作


下面以ubuntu为例子，操作一下，debian的我已经装过了，所以就拿自己虚拟机在在演示一下好了


首先配置下源，别忘了将其备份一份，可能会需要用到

vim /etc/apt/sources.list

把原本的删掉换成kali的源，国内的就用国内源，国外的就用官方源



保存后我们更新下源

apt update

这时候会提示一个错误，说没有公钥，所以不安全巴拉巴拉什么的，解决方法就是将公钥导入一下，公钥他也给我们了，就是下图标出来的



导入公钥（xxxx为要导入的公钥），这里我在服务器debian系统导入公钥时候，它提示我缺少一个什么gnupg或者gnupg2要求安装其中一个，如果遇到这个问题，我们就先把源换回服务器自带的，然后安装这个后再换kali源导入公钥

apt-key adv --keyserver keys.gnupg.net --recv-keys xxxxxxxxxxx

稍等片刻就会导入成功了，然后我们在更新一下源



成功更新源





0x03:更新操作


然后我们执行下kali的更新操作，apt upgrade && apt dist-upgrade，这里我个人比较推荐安装aptitude这个软件包管理工具，个人感觉他比apt要好用多了，会自动解决依赖问题，当然看你个人需求，效果都一样（建议先用apt更新，更新完成后在安装然后再用aptitude检查下更新）

apt install -y aptitude

apt更新

apt update && apt upgrade && apt dist-upgrade

aptitude更新

aptitude update && aptitude safe-upgrade && aptitude full-upgrade

不管用aptitude还是apt因为安装过于庞大，都可能会遇到一些无法处理的依赖错误，一般他们会给一个参数用以解决这个依赖错误，比如如果aptitude更新系统时候出现了处理不了的错误，就可以使用apt upgrade来更新一下，一般这时候apt会给一个解决错误的选项来纠正这个错误。


aptitude报错



如果出现上面这个报错，我们可以参考apt，先用apt更新，修复了依赖再用aptitude更新


apt报错


apt --fix-broken install

0x04:意外BUG解决方案

白师傅很细心的把一些他遇见到的意外情况也列了出来，希望能帮到大家。


如果使用这个修复依赖还出现了报错，（如下图）可以使用终极办法，将报错的依赖强行卸载掉，然后再次apt更新。（基本这个自动修复都可以修复好，修复不好的情况我也只遇到了一次）



如果遇到这个错误就执行下面的命令，--force-overwrite后替换成报错的那个软件包，注意有几个报错就卸载几个，比如下图里有三个就要把出问题的三个都干掉

sudo dpkg -i --force-overwrite /var/cache/apt/archives/nvidia-340_340.107-0ubuntu0~gpu18.04.1_amd64.deb



然后再用apt fix修复



修复完成后再进行更新就可以更新完成了


更新完成后他用起来就和kali一样了，只是没有安装kali自带的那么多软件，如果你需要全部安装可以apt命令来把kali所有的软件都装上，但其实kali用到的也没那么多并不推荐，安装自己需要的就可以了

apt-get install kali-linux-everything

注意安装完成后，它默认只装了python环境，java环境要自己用命令装上去

apt-get install openjdk-11-jdk

其他kali自带的软件也只需要用命令就可以安装了，像msf、beef，这两个框架如果直接在系统上安装很麻烦，各种依赖什么的，有不少坑，但换成kali源更新完成后，因为他们都是kali自带的软件，所以只需要一条命令就可以安装配置完成，不需要你东配置西配置各种报错什么的了，安装msf时候要注意用apt install -y metasploit-framework，这个名字来安装，如果名字不对会提示找不到的


最后别忘了用apt clear命令清理一下下载的安装包，这些安装包还是很占地方的。
