# **0x00:靶机介绍**  

这次的靶机是Nibbles,难度还行难点在于后台密码猜解。。。。![](../Images/ce4203d6a2eb100ceb8bc4d7d94955d6.png)  

# **0x01:探测靶机**

还是使用autorecon做前期的探测，这次扫的挺快的扫了半个钟就扫完全部了![](../Images/c2a88c93b1129cc1187a25f149872114.png)  
这次只开了22和80端口![](../Images/3ff1459c1c9473cf0b8e7f5a0c564ae0.png)  
一开始我看到hello world 有点懵逼。幸好F12一波看到有隐藏目录![](../Images/45a6aaad8ccd8947f48b998ace91e6d8.png)

# **0x02:收集信息**

这次跟过去终于有一个正常页面。同时看到右下角有一个大大的Powered by Nibbleblog![](../Images/e452e640133965cec4082c04ecd33b53.png)  
第一时间冲到MSF用searchsploit找到一个payload。然而想用的时候才发现需要一个账户密码才行。又回到起点。。。。。![](../Images/6bc39960b82c22c2f2b05a2b5d6e20d8.png)  
这里找到了这个CMS还有其它的漏洞试了一下不行。。。起码可以确认不是3这个版本![](../Images/ba359f816330ee0e03f133dfee64f1f5.png)  
好消息是起码在网上找到后台地址是单纯的/admin.php![](../Images/7582f2309ecc7286832fdd084eb4c6c1.png)  

# **0x03:破解后台**

那由于是登录框只能走三种办法打后台登录框。第一种回到/nibbleblog收集信息然后用Burp爆破一波，或者是抓包放到SQLMAP里面让它跑。第三种就是对着它进行弱密码猜解。我先用第一种用cewl爬虫一波顺便自己加上admin之类的。![](../Images/7a6b376fbed55bd21be8dd7ccea098db.png)  
结果我大E了没有闪,这里面居然有黑名单保护机制。。。。同理sqlmap也失败了直接把我拉黑了。![](../Images/1eca3961557629c4310021348c657825.png)  
这里我只能手工重新启动靶场，对着这个登录框发呆逐一尝试密码进去,拉黑了重启靶机![](../Images/7582f2309ecc7286832fdd084eb4c6c1.png)  
最后账号密码为admin nibbles …..![](../Images/a9cd5ded1111533073367a9a4d1595d3.png)

# **0x04:上传反弹shell**

这里在网上找到一个上传文件漏洞的利用。![](../Images/62458d34394704d1631edb779ba6078a.png)  
首先需要获得一个admin账号(已经难道一大片人了)然后去到My image 插件那里，忽略报错上传PHP反弹马。最后前台访问那个地址这里来到My image这个插件这里![](../Images/3824a7d4dfe4cd78dfbbdc5fa996d732.png)  
改好IP和端口。![](../Images/93e0aef4b71643c66bad1776dee8ec52.png)  
前台访问那个地址。记得提前开启nc啪的一下很快就得到一个nibbler用户的shell了。然后拿flag![](../Images/58a49c249547bd1b7f9614e3fdd7c3d1.png)

# **0x05:提权**

首先使用sudo -l发现一个monitor.sh具有root权限(这个文件你需要在/home/nibbler下有个personal.zip的文件。解压它跟着往下走就得到一个monitor.sh的文件了)![](../Images/a1f657642a23b77b5b733d43d2b855f1.png)  
如果你用cat 打开这个文件是又臭又长的各种信息。但是尝试一波用echo写入hello world进去会直接覆盖掉里面的内容。想法来了![](../Images/4ced40e5af975e52c99099f738aa3df2.png)  
写入bash -i(即shell语句)再运行直接升级变成root![](../Images/659612a19070b476e3e24bbaa22de1fa.png)
