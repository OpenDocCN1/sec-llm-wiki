0x00:构造思路

而写脚本的思路，首先就是我们要确定自己要用它来做什么，先确定好主题，然后细分细节，比如在内网的时候有个大杀器永恒之蓝，而我们在内网时候发现了很多机器，要一台一台扫看看是否开了445端口，然后再利用比较麻烦，所以这次目的就是写一个能自动扫描是否开放了445，如果开放了就用永恒之蓝打他、没有就用其他的。这让可以减少工作量


0x01:构造扫描脚本

然后我们划分细节，先完成第一步条件，永恒之蓝的前置条件就是目标开放了445端口的SMB服务，那么第一个条件就是要有扫描功能，来扫描目标开放了的端口，这部分就需要导入nmap模块。并使用了nmap模块的Port Scanner类，这个类很好用，我们传输的地址就跟nmap一样，可以直接192.168.2.0/24，让他扫整个网段，也可以192.168.2-5.6-8这种格式，端口部分也可以根据需要设置1-666这种写法或者1,2,4,5,6这样


import nmap


def findTgts(subNet):

    #实例化PortScanner这个类的对象

    nmScan = nmap.PortScanner();

    #scan(self, hosts='127.0.0.1', ports=None, arguments='-sV')方法，参数host=主机地址，ports=要扫描的端口，arguments=使用的命令参数

    #端口可以多个，arguments是我们扫描时候在nmap后面加的参数，比如-st -Pn 这些

    #调用scan方法扫描目标地址，和445端口

    nmScan.scan(subNet,'445');

    #创建空列表用来存储ip

    tgtHost = [];

    #all_hosts(self)方法，返回nmap扫描的主机清单，格式为列表类型

    for host in nmScan.all_hosts():

        #nmScan['127.0.0.1'].has_tcp（445）＃主机127.0.0.1上是否有端口445 / tcp的任何信息

        #has_tcp方法会判断当前主机是否有445端口的信息

        if nmScan[host].has_tcp(445):

            #这里取键为host中键名为tcp中，键名为445中键名为state的键值，他是一个多维字典，如果看不懂就print一下看看他的结构

            state = nmScan[host]['tcp'][445]['state'];

            #判断state的值是否为open

            if state == 'open':

                print('[+] Found Target Host: ' + host);

                #添加进列表中

                tgtHost.append(host);

    return tgtHost;


0x02:联动MSF

然后我们需要另一个模块，这里我们用它来写msf的配置文件，msf有读取批处理资源文件的功能，会按照顺序依次执行，所以我们可以把符合目标的IP和端口等需要的信息写进去，然后达到让他自动化批量攻击符合的目标（也可以不使用msf，但个人感觉使用msf更方便，主要原因是自己太菜了）,这个模块主要就是调用写入攻击的目标地址，使用什么模块，并后台运行，我们也可以根据自己需求进行修改
