# 0x00:HTB介绍

Hackthebox是一个在线的渗透练习平台，里面有大量的题目可以练习，也提供氪金靶机在线练习，如果不想下载几个G的靶机的话，不氪金变成会员的话能练习的靶机比较少。

  

  

# 0x01:获取邀请码

Hackthebox是需要邀请码才能注册的

![](../Images/80660bb1b3595568ed3edbf4ccae3f80.png)

  

点击click here,建议我们打开控制台。看到有说里面有个JS脚本

![](../Images/8686124940b46e8c8c866122ada2b80a.png)

  

  

去到Debugger那里打开js折叠的内容选中inviteapi.min.js以后看到有行注释提示说这段javascript看起来有点迷惑?

![](../Images/f6f690c6d871f095cff4fedcf10e279b.png)

  

用浏览器打开以后发现有个makeInviteCode的东西

![](../Images/0c4ef44b695977a09d9c9608a68248e4.png)

并且提示ROT13加密

返回到控制台输入进去得到串数据

![](../Images/0da65f4da1229166f48471578b4fc9e5.png)

  

那么找一个在线解密的网站解密以后得到信息为我们需要发送POST请求到/api/invite/generate

![](../Images/b8e97d70a07c0633228ebe0c405fc884.png)

  

那我们可以使用curl发送或者是插件或者是burp都可以，这里我选择用curl又获取到一串加密，数了一下长度为40可以被4整除，可以确定是base64编码，再用echo成功解码出来然后就可以把它放进去进行注册了，注册的时候需要谷歌的人机识别，只能靠大家想办法了

![](../Images/beda77321786a942c83a06ac2770023a.png)

# 0x04:端口探测

如果你是一个新手对于nmap还没完全熟悉的话，推荐用autorecon,在github上一搜就有了。只需要加个IP就可以联动nmap和gobuster等工具就行扫描目标网站，这里看到只开了8080端口

![](../Images/b91a6b170177339f47c4c2694e84197b.png)

# 0x06:上传反弹shell

![](../Images/078a620dd23898be745e6721359a8ecb.png)

![](../Images/41d376c6fbab4449a7b773c869e8ba50.png)
