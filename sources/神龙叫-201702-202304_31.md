# 产品定价法门？梦想价值法。

一、价值定价

  

小和尚：师傅，产品价格怎么定？你看我这个自动美发机器人花了5年终于研制成功，你看该卖多少钱合适？3万如何？

老和尚：价格取决于产品给客户带来的整体价值收益。

小和尚：能具体点不？

老和尚：给客户带来的整体收益 = 产品带来的价值 -  产品使用成本  -  产品购买成本。

小和尚：我是学数学的，能公式表示下不？

老和尚：V=dV - dP -PR  

小和尚：……  能解释一下不？

老和尚：当然--

dV就是用了产品后，给客户带来的价值增益；

dP是用了产品后，带来的使用维护成本；

PR是购买花费的价格，包含价格运费安装费用；

V就是给客户最终带来的价值。

  

老和尚：以你的美发机器人为例子 --

你这个机器人可以美发1千次。

没有这个机器人前，美发每次50元，美发1千次要花5万。

有了这个机器人，就可以省下这5万，dV=5万。  

但你这个机器人要充电，每次平均花10度电，按1元一度电计，1千次累计成本1万元。dP=1万  

这个机器人打算卖3万元，PR=3万。

给客户带来的最终价值，

V=dV-dP-PR=5-1-3=1万，

即客户使用你这款美发机器人，能带来1万元的价值收益。  

  

小和尚：V=1万元，意味着，我们还能再提价，再加1万元，客户也可以接受？

老和尚：想得美！选哪家，取决于和竞品相比，谁家带来的整体价值最大。

小和尚：还得看对手的产品情况？  

老和尚，必须的呀。你看来自印度的阿莎牌美发机器人，更结实，更省电，一个机器人能美发2千次，每次只花一度电，研发成本高所以售价也高达8万，你买谁？

小和尚：我肯定谁也不买，我自己有呀！

老和尚：那隔壁老王买谁家的？

小和尚：我算算，节约你发费用2000\*50元=10万，2000次电费2000元，V=10-0.2-8 = 1.8万元，可以收益更高！看来老王会买他家的！

老和尚：那你咋办？

小和尚：看来只能降价了，得降价8000元，才能和他们家给客户提供的价值收益一致……

老和尚：别只想降价呀，打价格战是没有底的，没有最低，只有更低。你得想想如何提供差异化价值！

小和尚：什么是差异化价值？

老和尚：为了实现客户梦想，把梦想价值计算进去！

小和尚：能具体点不？

老和尚：美发是为了吸引漂亮小姐姐，你的机器人能理出更能吸引回头率的发型，才是你产品的灵魂。你得不断测试本地区什么发型的回头率最高，然后让你的机器人支持这种发型！

小和尚：这就不是节约理发费用问题了！

  

  

二、梦想更贵

![](../Images/73f0a34cd4efd1ef9d1f9b6f82a7cb4e.png)

老和尚：是的。再问你一个问题，我这批开光的梳子，你打算如何定价？

小和尚：这个V怎么算呀！

老和尚：算法是一样的，唯一变化是dV，要按梦想背后的钱来计算。

小和尚：梦想？

老和尚：对，卖给程序员，告诉他们，用了这把梳子，不掉头发。就可以算算掉头发植发要多少钱？

小和尚：得要1万吧！看来一万以内，遇到程序员，都可能卖出去！  

老和尚：对！如果是卖小姑娘，梦想就是，用了这个梳子，就能有一头光鲜靓丽的头发，能够吸引很多暖男帅哥哥。

小和尚：这个梦想够有吸引力，我也喜欢体贴帅哥！小姑娘打扮，买帽子买护发品，也得上万，看来遇到小姑娘，2万以内都能卖出去。  

老和尚：遇到求子的，能卖更贵！

小和尚：师傅，你这梳子还能帮人生子！

老和尚：你要相信希望的力量，让人有了希望，感觉好，心情好，更容易怀娃！

小和尚：师傅厉害！佩服佩服！

小和尚，想了想：师傅，你这个梳子成本1元，能卖2万，我的美发机器人成本2.5万，只能卖2.2万 ，为啥会差距这么大 ？！

老和尚：记得要和梦想挂钩，才能有更高价值。

小和尚：可是你刚才还教我，要测试统计计算本地区回头率最高的发型，要量化测试核心指标，这才能支撑价格，你这梳子功效如何量化？

老和尚：佛祖说的还需要量化？

小和尚心想：当然需要量化了！你这不是损坏佛祖信用来销售么？你倒是赚钱了，牺牲了佛教几千年信誉呀！

老和尚看小和尚没再接话找茬，放下心来。

  

三、成本无关，梦想值钱

![](../Images/b4b816a50ad773b56975b851c9d1bfac.png)

小和尚突然想到了一个关键问题：…… 对了师傅，你刚才给的价格计算里面，和成本没有关系？

老和尚：当然没关系，我送你一个不能转的洗衣机，占地10平米，你要不？

小和尚：不要！我已经有了，而且我们寺庙在市中心，每平米地还很贵！10平米值100万！  

老和尚：我洗衣机成本1000元呢，你也不要？

小和尚：坚决不要！我可不愿意用这个宝地放破烂。

老和尚：记住怎么定价了么？  

小和尚：记住了，按给客户带来的价值计算，价值定价原则！帮助客户实现梦想，可以算梦想背后的价值！

老和尚：对，梦想尤其值钱。

小和尚：有点感觉了。

老和尚：客户花的每分钱，都是在为自己的梦想花钱。

小和尚：都是为梦想？不是为产品花钱？

老和尚：产品只是梦想的载体而已。

小和尚：不明觉厉！
