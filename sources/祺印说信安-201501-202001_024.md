# 2019年五月份恶意软件之“十恶不赦”排行榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086099&idx=1&sn=1d0f8e4ad52ab949aae7903d05d1f002&chksm=8bbcb56abccb3c7cb1b1e638c3f3d1db629f8a7f00cdb6b55e82bc0f5d688376239675569812&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086099&idx=1&sn=1d0f8e4ad52ab949aae7903d05d1f002&chksm=8bbcb56abccb3c7cb1b1e638c3f3d1db629f8a7f00cdb6b55e82bc0f5d688376239675569812&scene=27#wechat_redirect)

5月份，威胁形势中最重要的事件不是新型恶意软件，是Windows旧版操作系统中的一个严重漏洞，该漏洞一旦被犯罪分子利用，可能导致大规模勒索软件攻击，重现2017年WannaCry和NotPetya那样的灾难。该漏洞是Windows 7和Windows Server 2008计算机中的“BlueKeep”Microsoft RDP漏洞（CVE-2019-0708），此漏洞在不需要用户交互情况下可以被利用。互联网电脑数近千万台受其影响，据我国CNVD统计全世界规模约为939.0万，我国境内的用户规模约为193.0万。RDP已经是一种成熟的，流行的攻击媒介，已用于安装诸如Samsam和Dharma之类的勒索软件，其中我国也受到勒索软件GandCrab结合RDP攻击的影响。这是一个一旦发动恶意攻击，可能威胁到所有易受攻击设备的漏洞，其攻击速度可能呈指数级迅速扩散。对于，勒索病毒，我们还是强调预防为主，修补漏洞是至关重要的。

5月份有关恶意软件另一个重大新闻是GandCrab Ransomware-as-a-Service开发者，宣布将停止运营，并要求其关联公司在20天内停止分发勒索软件。该行动自2018年1月开始运作，据统计仅仅两个月就感染了50,000多名受害者。据称其开发商和附属公司的总收入为数十亿美元。Gandcrab通过不断更新迭代，开发出躲避检测工具的新功能，最近一段时间影响不可谓不大！

**2019年5月恶意软件之“十恶不赦”：**

*\***箭头与上个月的排名变化有关。*

三个最著名的**Cryptominers** - **Cryptoloot**，**XMRig**和**JSEcoin**继续位居恶意软件指数之首。

![](../Images/be034e95cfcbc9f82aa638a30f4802bc.png)

  

1.**↔****Cryptoloot** \- Crypto-Miner，使用受害者的CPU或GPU电源和现有的资源开采加密的区块链和发掘新的加密货币，是Coinhive的有力竞争对手，本月较上月持平，稳居第1名地位，取代长期占据第1的Coinhive。。  

2.**↔****XMRig** \- 是一种开源利用CPU进行挖掘恶意软件，用于挖掘Monero加密货币，并于2017年5月首次被发现，较上个月排名不变。  

3.**↔****JSEcoin** \- 可以嵌入网站的JavaScript矿工。使用JSEcoin，可以直接在浏览器中运行矿工，以换取无广告体验，游戏内货币和其他奖励。本月为第3名的位置，与上个月排名未发生变化。

4.**↔****Emotet** \- 高级，自我传播和高级模块化的木马。Emotet曾经被用作银行木马，最近被用作其他恶意软件或恶意广告的分销商。它使用多种方法来维护持久性和规避技术以避免检测。此外，它还可以通过包含恶意附件或链接的网络钓鱼垃圾邮件进行传播，排名较上个月未发生变化。

5.**↑Ramnit** \- 是一款能够窃取银行凭据， FTP密码，会话cookie和个人数据的银行特洛伊木马，对比上个月上升1个名次，由第6名上升为本月的第5名。。

6.**↑Lokibot** \- Info盗窃者主要通过网络钓鱼电子邮件分发，用于窃取各种数据，如电子邮件凭证以及密码到CryptoCoin钱包和FTP服务器，上月名列第9名的恶意软件，本月上升至第6名。

7.**↓**基于**Dorkbot** \-IRC-是一种基于IRC设计的蠕虫，可以以操作员执行远程代码，以及下载其他恶意软件到被感染的机器。是一个银行木马，其主要动机是窃取敏感信息并可以发起拒绝服务攻击，本月影响程度较上月下降2个名次，为第7名。

8.**↔****Trickbot** \- Trickbot是一种占主导地位的银行木马，不断更新新功能，功能和分发向量。这使得Trickbot成为一种灵活且可定制的恶意软件，可以作为多用途广告系列的一部分进行分发，本月排名较上月未发生变化

9.**↑Nivdort** \-Multipurpose bot，也称为Bayrob，用于收集密码、修改系统设置和下载其他恶意软件。通常通过垃圾邮件传播，其中收件人地址以二进制文件编码，实现每个文件唯一性。

10.  **↓Agentesla-** AgentTesla是一种先进的RAT，可用作键盘记录器和密码窃取器。AgentTesla能够监控和收集受害者的键盘输入、系统剪贴板、截取屏幕以及泄露属于受害者机器上安装的各种软件（包括Google Chrome，Mozilla Firefox和Microsoft Outlook电子邮件客户端）的凭据。本月较上个月，排名下降3个名次。

**五月份三大移动恶意软件**  

![](../Images/8e5d7ba90cea71cad67babc6250b1765.png)  

本月移动恶意软件前三位名次有所变化，然而仍然是这三款恶意软件，**Lotoor** 从四月份的第2 名变成本月的第1名。**Hiddad** 从四月份的第3名升至本月第2名。**Triada**从1 名滑落至第3名，具体情况如下：

1.**↑****Lotoor** \- Hack工具利用Android操作系统上的漏洞获取受感染移动设备的root权限。

2.**↑Hiddad** \-是一款Android恶意软件，对合法应用程序重新打包，然后将其发布到第三方应用商店。主要是显示广告，也能够访问操作系统内置的关键安全细节，允许攻击者可获取敏感的用户数据。 

2.**↓****Triada** \-适用于Android的ModularBackdoor，它为下载的恶意软件授予超级用户权限，有助于它嵌入到系统进程中。Triada也被视为欺骗浏览器中加载的URL。

**五月份十大漏洞**  

![](../Images/d72d072df38b7106cfc41eee5e19d620.png)

5月份，随着Cryptominers的盈利可见性的下降，传统攻击技术的有所抬头，SQL注入技术引领漏洞攻击，全球影响力占监测范围的49％，Web服务器暴露的Git存储库信息披露和OpenSSL TLS DTLS心跳信息披露排名顺序为第2和第3，全球影响力分别占监测范围的44％和41％。  

1.**↑****SQL****注入（若干种技术） -**在从客户端到应用程序的输入中插入SQL查询注入，同时利用应用程序软件中的安全漏洞。

2.**↑Web****服务器暴露的Git存储库信息泄露** \- **Git****存储库中报告了**一个信息泄露漏洞。成功利用此漏洞可能会无意中泄露帐户信息。

3.**↑OpenSSL TLS DTLS****心跳信息泄露（CVE-2014-0160; CVE-2014-0346）** \- OpenSSL中存在信息泄露漏洞。该漏洞是由于处理TLS / DTLS心跳包时出错。攻击者可以利用此漏洞披露已连接客户端或服务器的内存内容。

4.**↑****Joomla****对象注入远程命令执行（CVE-2015-8562**） - Joomla平台已经报告了一个远程命令执行漏洞。该漏洞是由于缺少对输入对象的验证而导致远程代码执行。远程攻击者可以通过向受害者发送恶意请求来利用此漏洞。成功利用此漏洞可能导致在目标用户的上下文中执行任意代码

5.**↓****Microsoft IIS WebDAV ScStoragePathFromUrl****缓冲区溢出（CVE-2017-7269）** \- 通过Microsoft Internet Information Services 6.0将精心设计的请求通过网络发送到Microsoft Windows Server 2003 R2，远程攻击者可以执行任意代码或导致拒绝服务条件在目标服务器上。这主要是由于HTTP请求中对长报头的不正确验证导致的缓冲区溢出漏洞。

6.**↓****Apache Struts2****内容类型远程执行代码（CVE-2017-5638）** \- 使用Jakarta多部分解析器的Apache Struts2中存在一个远程执行代码漏洞。攻击者可以通过在文件上载请求中发送无效内容类型来利用此漏洞。成功利用可能会导致在受影响的系统上执行任意代码。

7.**↑****PHP DIESCAN****信息泄露 -** PHP页面中已报告信息泄露漏洞。成功利用可能会导致从服务器泄露敏感信息。

8.**↓****D-Link DSL-2750B****远程命令执行** \- D-Link DSL-2750B路由器中报告了一个远程执行代码漏洞。成功利用可能导致易受攻击的设备上的任意代码执行。

9.**↓****OpenSSL tls\_get\_message\_body****函数init\_msg结构使用后免费（CVE-2016-6309）**\- 在OpenSSL的tls\_get\_message\_body函数中报告了一个释放后使用的漏洞。未经身份验证的远程攻击者可以通过向易受攻击的服务器发送精心设计的消息来利用此漏洞。成功利用允许攻击者在系统上执行任意代码。

10.  **↑WordPress portable-phpMyAdmin****插件身份**验证绕过 - WordPress portable-phpMyAdmin插件中存在身份验证绕过漏洞。成功利用此漏洞将使远程攻击者获取敏感信息并获得对受影响系统的未授权访问。
