# 微软为79个漏洞发布补丁，一个可能助长加密勒索软件传播

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086076&idx=1&sn=9dc319714696781eab184f290c204c45&chksm=8bbcb505bccb3c1373424cf910c7b5f0cc97d5d02d16bd1b48584972f08cad6466dfb253c9f3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086076&idx=1&sn=9dc319714696781eab184f290c204c45&chksm=8bbcb505bccb3c1373424cf910c7b5f0cc97d5d02d16bd1b48584972f08cad6466dfb253c9f3&scene=27#wechat_redirect)

又到了微软每月发布其软件安全更新的那天，一个微软周二的补丁日。

 ![](../Images/f3351c73a8e242367ab8c36fac527180.png)

Microsoft本次软件更新针对其产品79个CVE漏洞，其中包括无需用户交互可以将恶意软件在计算机之间传播的严重漏洞。

在79个漏洞中，有18个问题被评为严重，其余部分严重，其中一个在发布时被列为主动攻击。

2019年5月安全更新解决了Windows操作系统，Internet Explorer，Edge，Microsoft Office，Microsoft Office服务和Web应用程序，ChakraCore，.NET Framework和ASP.NET，Skype for Android，Azure DevOps Server和NuGet Package Manager中的缺陷。

![](../Images/4c104e5dbdb2e25baae2320cb88bc501.png)

**严重的Wormable RDP漏洞**

漏洞（CVE-2019-0708）驻留在远程桌面服务（以前称为终端服务）中，可通过将特制请求通过RDP协议发送到目标系统来远程利用。该漏洞可能被利用来传播可疑恶意软件，其方式与打击可以回顾2017年WannaCry恶意软件遍布全球的惊险案例。

Microsoft在一份详细说明Wormable漏洞的咨询中显示“此漏洞是预身份验证，无需用户交互。成功利用此漏洞的攻击者可以在目标系统上执行任意代码。虽然没有观察到直接利用此漏洞的案例，但恶意攻击者极有可能很快为此漏洞编写漏洞，并将其合并到恶意软件中。”

本次除了为受支持的系统（包括Windows 7，Windows Server 2008 R2和Windows Server 2008）发布补丁之外，Microsoft还单独发布了针对Windows的不支持版本（包括Windows 2003和Windows XP）的修复程序，以解决这一关键问题，由此可见该微软对该漏洞的重视。

作为一种解决方法，Microsoft已建议Windows Server用户阻止TCP端口3389并启用网络级别身份验证，以防止任何未经身份验证的攻击者利用此Wormable漏洞。![](../Images/68a480ad874dbef11ec5cf0d0ef00612.png)

**其他漏洞**

一个严重缺陷是Windows中的一个重要的特权提升漏洞（CVE-2019-0863），它存在于Windows错误报告（WER）处理文件的方式中。该漏洞被公开为众所周知，并且已经在针对特定目标的有限攻击中被积极利用。

成功利用该漏洞可能允许低权限远程攻击者以管理员权限在内核模式下运行任意代码，最终让他们安装程序，查看，更改或删除数据，或创建具有管理员权限的新帐户。

另一个公开披露的漏洞会影响Skype for Android应用。该漏洞（CVE-2019-0932）可能允许攻击者在他们不知情的情况下收听Skype用户的会话。

要成功利用此漏洞，攻击者需要的只是调用安装了Skype for Android的Android手机，该手机也与蓝牙设备配对。

本月列出的所有关键漏洞主要影响各种版本的Windows 10操作系统和服务器版本，主要存在于Chakra ScriptingEngine中，其中一些还存在于Windows图形设备接口（GDI），Internet Explorer，Edge，Word，远程桌面服务，和Windows DHCP服务器。

许多重要评级的漏洞也会导致远程代码执行攻击，而其他漏洞则允许特权提升，信息泄露，安全绕过，欺骗篡改和拒绝服务攻击。强烈建议用户和系统管理员尽快应用最新的安全补丁，以防止网络犯罪分子和黑客控制他们的计算机。

系统及时更新，在网络安全等级保护测评过程中，这是一个测评项，而人人都知道安全没有绝对的，但是风险可控是网络安全的思路。也就是在风险是不一定要全部消灭的，但是在发声安全事件时，必须要能够做到可控。在此诚挚建议安装最新的安全更新，**设置→更新和安全→Windows Update→检查计算机上的更新，或者手动更新**。

Adobe同期还推出了安全更新，以修复87个安全漏洞在其几个产品中。建议受影响的Windows，macOS，Linux和Chrome操作系统的Adobe软件用户将其软件包更新到最新版本。
