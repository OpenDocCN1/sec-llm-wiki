# 美国国家安全局NSA发布免费强大的逆向工程工具GHIDRA 9.0

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086063&idx=1&sn=bc39ba7984c9961395ddc79341b982ac&chksm=8bbcb516bccb3c0033cf7b8abaebdd68f8a40049f8809ba1fa2366830c619873c3fd7a21631f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086063&idx=1&sn=bc39ba7984c9961395ddc79341b982ac&chksm=8bbcb516bccb3c0033cf7b8abaebdd68f8a40049f8809ba1fa2366830c619873c3fd7a21631f&scene=27#wechat_redirect)

据国外安全媒体报道，近期美国国家安全局（NSA）终于免费发布了GHIDRA版本9.0，是该机构原先的秘密软件逆向工程工具，NSA内的专家已在内部使用了十多年，用以寻找软件和应用程序中的安全漏洞。  

![](../Images/777a3f62b5567f31b81b48d5cb41ed93.png)

GHIDRA是一个基于Java的逆向工程框架，具有图形用户界面（GUI），可以在各种平台上运行，包括Windows，macOS和Linux。逆向工程程序或软件涉及反汇编，即在源代码不可用时将二进制指令转换为汇编代码，帮助软件工程师，尤其是恶意软件分析师，了解代码的功能以及实际的设计和实现信息。其实，维基解密在CIA Vault 7泄密 事件中首次进行公开披露GHIDRA ，而NSA最近在RSA会议上把原本的秘密武器开始公开免费发布，使其成为昂贵的商业逆向工程工具（如IDA-Pro）的绝佳竞争者。

![](../Images/af9e5248af76351660280a0446a53252.png)

NSA官方网站在描述GHIDRA时说 “它（GHIDRA）帮助网络安全人员分析恶意代码和恶意软件，如病毒。使网络安全专业人员更好地了解其网络和系统中的潜在漏洞。”

高级NSA顾问罗伯特·乔伊斯在RSA会议上发言，保证GHIDRA没有后门，有没有后门，在此我就不在赘述，希望看到本文的朋友明智选择，安全多一份警惕不是坏事。乔伊斯表示GHIDRA包括高端商业工具所需的所有功能，NSA独特开发的新功能和扩展功能，支持各种处理器指令集，可执行格式，可以在用户交互和自动模式下友好运行运行。

![](../Images/5a64a7e625ee9695d8f2030e15d10032.png)

Joyce 推文介绍：“GHIDRA处理器模块：X86 16/32/64，ARM / AARCH64，PowerPC 32/64，VLE，MIPS 16/32/64，微型，68xxx，Java / DEX字节码，PA-RISC，PIC 12/16/17 / 18/24，Sparc 32/64，CR16C，Z80,6502,8051，MSP430，AVR8，AVR32，以及其他变体。“

![](../Images/eed5f71a1e1e97a1795b01a2d1138e0f.png)

GHIDRA受到了信息安全社区的热烈欢迎，研究人员和开发人员已经开始通过报告其Github问题跟踪器上的漏洞和安全漏洞为该项目做出贡献。

第一个报告GHIDRA安全问题的人Matthew Hickey使用在线别名“HackerFantastic”， Hickey注意到当用户在调试模式下启动GHIDRA时，逆向工程套件为所有接口打开JDWP调试端口18001，允许网络中的任何人远程执行分析师系统上的任意代码。虽然默认情况下未调试模式并且应该按预期工作，但软件应仅侦听来自localhost的调试连接，而不是网络中的任何计算机。根据Hickey的同时表示只需更改软件中的一行代码就可以解决这个问题。
