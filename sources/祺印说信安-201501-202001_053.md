# 中国在全球宽带速度表中排名第141位

我们从英国《卫报》的一篇文章《英国在全球宽带速度表中排名第35位

》不经意间看到了中国在全球宽带速度的排名，是尴尬的141位。文章显示，英国在全球宽带速度年度排名中跌至第**35**位，仅超过三分之一的欧盟国家，低于马达加斯加和保加利亚。

![](../Images/20dbc6eae1f3491cb6587e67a0c21eae.png)

根据对200个国家进行的1.6亿多次宽带速度测试的分析显示，新加坡再次成为世界上最快的国家，其次是瑞典，丹麦和挪威，而西亚的也门则排在全世界的最后。

![](../Images/d1d2cb8667bfe393a70bec96e29953a3.png)

《卫报》批评到，今年早些时候，英国政府宣布承诺将“**超高速**”宽带扩展到95％的家庭 。 但编制排行的数据的公司认为英国未来几年可能会落后于其他国家。  

  

根据分析，在截至5月29日的12个月期间，英国的平均速度达到了18.57Mbps，这意味着下载5GB高清电影通常需要超过36分钟。这比去年排名下降了4个名次，排在全球第35位。![](../Images/e9ec98006ab07ac974f12143bbcbd437.png)

英国落后于其他25个欧洲国家，其中20个在欧盟国家，以及美国（第20位）和日本（第12位）。发布调查结果的宽带，电视和电话网络方面，英国领先于其他165个国家，包括爱尔兰（第36位），奥地利（第38位），意大利（第43位）和澳大利亚（第52位）。

![](../Images/b459ddb42dfe867dc260ad08c872be37.png)

从排行榜上，我们看到我国的宽带速度排行，位居全球200个国家的141位，而较去年相比，下降了7个名次，提供的平均下行带宽为2.38MB。而我国香港地区的速度高达26.45MB，位居全球第19位。名次，是我们无法感受到的，而我国的带宽的速度问题，通过下载各方面的测试，平均速度应该出入不是太大。而参与排名的全球平均速度已经9.1MB了。
