# 中兴事件下的联想窘境是个难题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652085938&idx=1&sn=9a8ace5a44cd55ae7b59d953d8c9c3c2&chksm=8bbcb48bbccb3d9daa0bac5db5238b1e052154df80466dc59e15e64291d05b31c2c2d3db6243&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652085938&idx=1&sn=9a8ace5a44cd55ae7b59d953d8c9c3c2&chksm=8bbcb48bbccb3d9daa0bac5db5238b1e052154df80466dc59e15e64291d05b31c2c2d3db6243&scene=27#wechat_redirect)

两年前的东西，又被人翻出来，可能导火线就是中兴事件吧。从事后诸葛亮的思维去看，对比华为与联想，眼光、格局、人品都在里面了！

今天看来，对任柳二人的评价，应该与百年后评价无二致，很难反转了。任正非有可能在中国历史上留下精彩华章，并且无论华为以后走向如何，任正非的民族成就已经定格了。

![](../Images/9dcaeef5ed798c44ca8aa5d31480f4ad.png)

另外，在任面前柳的鼠目寸光以及买办角色也将定格，几百年后如果还有影视剧，或许如同我们今天看清末民初那些洋买办一样的情感立场去看柳杨二人。我国从落后就要挨打的百年屈辱历史中刚刚醒悟过来，又轮回到落后，这种买办思维不得不说起到很大的作用。造船不如买船，买船不如租船的论调把买办们推上了昔日中国商业的中心，而技术冷板凳却没人去做。而华为实力不如联想，而边研发边发展的道路，奠定了今天华为蒸蒸日上的基础。

![](../Images/f7111894dade0030584868395273bb61.png)

呜呼哀哉，联想后面的局面不堪设想！综合柳倪之争、华为崛起、中兴事件、联想没落，使得国人前后联系起来，总体判断认为联想至少是肥己误国的方面是坐实了的。而无论柳杨如何申辩，此时此事国人必然是不接收的。

总体说还是联想与华为对比后形成的短视，另外中兴事件让很多人得到“柳倪之争”的过往种种，再现世人眼前，为如今联想的窘境助力不少。

国人清楚认识到这些后，每一个国人作为联想的直接或间接消费者，是国人捧起了联想，所以联想还是需要考虑自身错误以及老生常谈的“**水能载舟亦能覆舟**”。人们会不自觉的将倪柳做对比，来看待今天中兴事件，也会拿任柳来对比，看待今天联想与华为。

说实在的真应了那句“**出来混迟早要还的！**”。“**今日种种果，皆是昨日因**”世人都能从最近事件以及对比中去参悟与发泄，所以此时此刻联想无论如何都是被动的，任何公关与辩解都是无力的，经过此番挖掘，联想已经失去了舆论阵地，即使此时联想全是真投了华为，其发展与华为对比产生的短视，给中国科技界带来的冲击力，也足以让大部分当下中国人对其不信任。

![](../Images/b51bc199715cb32bf57e5644427b2818.png)

当然，过去的事件被重新炒作起来，我们也要考虑到此时也存在可能有人攻击联想，致使其面临破产进而准备对联想下手收购。联想，如今处于一个不敢往下联想的窘境，其可悲可叹，值得深思。

落后就要挨打，大清末年是武力，如今是综合国力。中兴事件下的联想，还在想用传统的方式化解新时代的矛盾，已经显得无能为力了。
