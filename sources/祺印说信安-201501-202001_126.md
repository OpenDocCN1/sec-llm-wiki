# 从香菇往下看“永恒之蓝”，继续借鉴着谈一谈

上次我引述了英国《卫报》报道的信息，今天从英国《金融时报》来说一二。近日也报道了关于“永恒之蓝”，这个毒性较大的“想哭”（WannaCry）软件病毒，肆虐到世界各地。据当时《金融时报》报道，数据显示超过130万电脑系统仍然容易被感染，这种病毒致使英国医院大面积瘫痪，中国高校中招，企业无法运转。

 

![](../Images/83869533f1c5f69b7d7451f3b0f73191.png)

  

当时报道，欧洲刑警组织（Europol）表示，有超过150个国家的20万台电脑，在第一波网络攻击中，遭受了感染。这次袭击水平可谓前所未有。上周末，同期欧美的情报机构都通报企业和组织威胁可能会升级。英国部分官员也认为，有理由相信病毒是一个犯罪集团的产物。当然，上次我也说道了。维基解密解密的文件，直指美国的NSA，而美国NSA不小心就被黑客收集走了病毒工具了。那么，后微软公司，又有什么看法呢？

 

说微软前，何不看看NSA如何说的呢？下面属于引述《金融时报》内容，下面加粗部分属于摘抄，以作参考。

**“我们正与国家打击犯罪局(NationalCrime Agency)合作，全天候追查罪魁祸首，”马丁表示。“我们有一些线索，但现在不能置评。”**

**美国国家安全委员会(NationalSecurity Council)网络事件响应(CyberIncident Response)前主任安东尼•费兰特(AnthonyFerrante)表示：“周一上午，当人们上班后，我们可能会看到一些活动。”**

**如今担任富事高咨询(FTIConsulting)司法鉴定和诉讼部门董事总经理的费兰特表示，美国政府“非常重视”这一威胁。**

![](../Images/d4cea7230f1c2447122c8e1cc5cd8bb5.png)

  

那么，最终暴露出受害者又都是什么部门呢？

**除了致使英国的NHS近三分之一以上医院和诊所陷入瘫痪，还有德国铁路、美国物流集团（FedEx）、俄罗斯内务部、法国雷诺汽车、西班牙电信，以及我们自己国家的中石油（CNPC）**

 

**微软**方面**公开证实**“想哭”病毒的传播利用了**美国国家安全局**开发的技术，并称**各国政府**应把这次攻击视为一记警钟。![](../Images/9175e3b00d05c9f982748765c9a6e993.png)

微软(Microsoft)向美国政府发出了抨击，指责其“囤积”网络武器、为“想哭”(WannaCry)这类勒索软件发起的攻击提供了“方便”。使得“想哭”病毒在全球肆虐。

上周日下午，微软法律总顾问布拉德•史密斯(BradSmith)在一篇措辞激烈的博客文章中写道：“**全球各国政府应该把这次攻击视为一记警钟。**”这个可能对美国来说，我想微软意味深长的说了一句“全球各国政府应该把这次攻击视为对美国政府的一次警告！”

微软在其声明中**首次公开证实**了安全分析师和情报官员只会私下吐露的说法：黑客用来散播“想哭”病毒的技术，是最初由**美国国家安全局****(NSA)****开发的**，后来又被人从该局“窃”走。从《金融时报》报道“**首次公开证实**”来看，我们知道在冰山下隐藏多少呢？![](../Images/dc7337e4df444f40e3aeff95dae95e7c.png)

最为技术团队与黑客较量那么多年的微软，私下里与NSA有多少勾当，这个不可而至。而微软的团队与NSA黑客团队的技术，会不会有那么大的技术差，以至于几年后才发现漏洞，发布漏洞补丁，这个直接证据其实不得而知的。然而根据部分文章透露，美国政府与美国高科技企业，联合绞杀中国高科技企业是不遗余力的。而从中美国为了获取充足的借口，往往对外界宣传他们遭到黑客攻击，而这些材料我上次提到，都是美国政府自说自话，没有第三方佐证。而他们囤积漏洞，以及制造黑客工具，也是得到维基解密与爱德华斯诺登的一致证实的。作为美国，有没有实力分两队做演练，其中一队伪装地址来一个自说自话，大家都心知肚明。美国网络有可能被攻击，也有可能是演练，而都可以形成文件，宣传遭受到外来攻击。![](../Images/1f5c087385708c9e4d3c44f3aed6ba21.png)

美国政府，在维基解密之前，多么的义正言辞的宣扬别人攻击他们，好像一个无辜的受害者。而是否美国企业与美国政府有一大的阴谋，我们可以不去考虑太多，这个可以参看《零日漏洞：震网病毒全揭秘》这本书，而我们今天就先从《金融时报》观点看看这次事件吧。有机会，搜集一下这方面信息，仔细思考分析后，再做介绍。

![](../Images/ae4c9aa9e302166384d8eeddc6e9292f.png)

史密斯写道：“**这次攻击是又一个例子，证明了为何政府囤积软件漏洞是如此重大的问题。**”这句话指向**了维基解密****(WikiLeaks)**披露的、**美国中央情报局****(CIA)**对明显的漏洞加以利用的行为。

他说：“政府手中掌握的漏洞泄露至公共领域、并造成大范围破坏，这样的情况已多次发生。若以常规武器来类比，这就好像是美国军方部分战斧导弹(Tomahawk)被窃。”

尽管从NSA泄露的工具无法证明是用来创造“想哭”病毒本身，但这些工具确实帮助“黑客”加速了该病毒的传播，美国政府豢养的黑客，谁人能够鉴别呢？他们对世界各地机构造成了严重破坏。

NSA雇佣者爱德华•斯诺登(EdwardSnowden)也称称，微软方面的这些话“非同寻常”。斯诺登因泄露了成千上万份机密文件而被美国通缉，这就是网络段子中大咖们最后闭嘴的一个逻辑故事，把斯诺登故事名字隐藏，大咖都认为是说中国的异见人士，变现的正义凛然，而后才知道客观叙述的只是斯诺登，接着就是主观内心的一片凌乱。

他在Twitter上发帖称：“直到周末的攻击发生前，微软一直拒绝公开证实这一点，美国政府则既不愿证实也不否认这个漏洞出自他们之手。”

![](../Images/7b0d5ecc9e28bc909e8a62f269f26eaa.png)

  

NSA未对微软的说法作出回应。

微软对美国当局对网络攻击和国家安全的处理方式，不由得让人们想起了去年苹果(Apple)与美国联邦调查局(FBI)之争：当时美国执法部门试图破解制造圣贝纳迪诺(SanBernardino)枪击案的恐怖分子的iPhone，要求苹果编写解锁锁定IPhone的新软件。苹果当时据理拒绝了这个命令。苹果称这样做将制造一个“后门”，一旦解锁软件误入坏人之手，将会给所有iPhone用户的安全带来巨大隐私。

随着“想哭”的美好“永恒之蓝”的名字不断在我们脑海深刻的同时，我们每一个人都已经深深被锁在了信息中，而我们的身体和灵魂已经被绑定在内内外外的信息世界里，而当今时代，信息其实就是财富。个人信息就是个人财产，无论是闯入你的家中，还是冻结你的财产，你都是一万个不同意，特别是你的合法收益，随便被人锁定并冻结，我想你的态度应该是更明了的了。

![](../Images/986a0f7957404cbee185cd986c79bd8b.png)

这或许就是美国政府吧！有能力，也愿意尝试去冻结你的财富。只是为了在政治上，给予世界一种压力，刷存在感。以传达不确定的信息，给大咖们信息吗？或许是吧。不过在当今时代，其实龌龊是无从遁形的。从虐囚门到今天的“永恒之蓝”，从远方与我们无关，到我们周边的学生的论文被锁定，我们深深发现美国的善心竟然如此遥远。

通过这件事情，让我想到并去再次看了一下中国的《网络安全法》。开宗明义，直指网络已经称为海陆空之外的主权之地，有了网络安全法，我们有了切实的法理依据，也让我们更加明白我们的信息安全，只有我国的基础网络安全以及重要信息系统得到全面保护，才能够有我们个人信息的安全。![](../Images/bab3bf248a1d2d389fe60b86153f9429.png)

很多人，特别大咖们会从另一个角度出发，认为中国在收紧网络。我个人认为，规则正义是必然的。大咖所考虑的是实践或人为正义的问题，所以他们考虑的永远是自私的，而与苏格拉底以及耶稣，是不可同日而语的。当然，退一步讲。如果大咖能够愿意为世界被攻击的系统而负责，愿意用自己一生来为这次灾难而买单，我真的愿意赞成大咖们的逻辑与思维。如今已经造成了几十亿美元损失，再侃侃而谈时，也要看看自己有没有能力为世界买单！

六一快到了，《网络安全法》即将实施，这部法律的实施放到六一节，也充分考虑到法律层面关爱孩子的精神健康。现在网络充斥的暴力、色情、以及极端的物质化宣传，对孩子的侵蚀确实非常严重，希望这部安全法可以带来下一代精神的转变，以及规则正义的信念从苏格拉底到耶稣到未来，得以发扬与延续
