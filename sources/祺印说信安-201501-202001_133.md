# “我有被黑客攻击的危险吗？并且谁才是在CIA的要监控最多的神秘人？您需要了解“Vault 7”文档

**你应该担心被监听吗？这个维基解密发布只是冰山一角吗？****并且谁才是在CIA的监控最多的神秘人？**  

![](../Images/823f079e7f7542c0802c51d623f3791a.png)

Julian Assange的维基解密将“Vault 7”描述为“CIA上最大的机密文件出版物”。照片：Kirsty Wigglesworth / AP

  

**CIA究竟发生了什么？**

众所周知的**WikiLeaks**是由**Julian Assange**运营的解密网站，发布了一个称为“**Vault 7**”的文件，其中包含CIA使用的黑客工具的详细信息。

  

**什么是“Vault 7”？**

维基解密说，7,818网页和943附件发表，但这只是众多的材料的第一部分。维基解密表示，它有一个完整的归档数据组成的几百万行的计算机代码。文件显示到2013年至2016年。维基解密将他们描述为“机构文件最大的出版物”。

  

这些文件有对**CIA** 的计划描述以及对其恶意软件和其他工具的描述，这些工具可用于攻击世界上最流行的一些技术平台。文档显示，开发人员旨在能够将这些工具注入到目标计算机中，而无需计算机拥有者同意。

  

这些文件没有描述可能的攻击的目标是谁，但文件显示了CIA，国家安全局和其他美国联邦情报机构之间广泛的工具和信息交流，以及密切关注盟友的情报服务。如澳大利亚，加拿大，新西兰和联合王国。

  

**这又意味着CIA可以做什么？**

该机构针对广泛的设备进行攻击。集中注意力旨在打破通用计算设备，包括PC和智能手机。文档显示，恶意软件影响系统包括iOS和Android手机，以及Windows和Linux计算机。

  

解密文档所描述的工具将允许**CIA**对用户的电话进行几乎完全的远程控制，将其转换成向机构报告的完整监视设备。当然它只会对最重要的目标这样做，因为每次该机构使用恶意软件，它运行都有被发现的风险，以促使制造商发布补丁进行修复，以防止未来的攻击取得成功。

  

在2016年8月就发生了这种情况，当苹果发布了一个全球iOS更新后三个尝试攻击执行和突破，被使用iPhone的阿拉伯人权活动家发现。

  

这些文件还包括讨论如何控制一些互联网连接的三星电视，把他们变成监听设备。像许多其他人一样，这种攻击只能以非常有针对性的方式工作：它需要物理访问有问题的电视，因为恶意软件要通过USB端口才能加载。

  

另一份文件讨论了黑客车辆系统，似乎表明中央情报局有兴趣利用复杂的车载计算机系统攻击最近的模型车。

  

**为什么我听到哭泣的天使和南道的名字？**

 哭泣的天使，一个医生谁在雕像的幌子的坏人

![](../Images/7b0d5ecc9e28bc909e8a62f269f26eaa.png)

在文件中详细的三星恶意软件称为哭泣的天使，显然以一个“Doctor Who”恶棍命名。照片：BBC / Adrian Rogers / BBC

  

所谓的CIA文档涵盖从复杂的计算机编码到组织计划，以及关于工具有效性的讽刺评论。这些评论描绘了一个充满了相当典型的开发者，喜欢分享表情符号，讨论最好的文本编辑器，并在他们的代码中做流行文化引用的机构的图片。

  

发布中的一些工具以酒精为参考，包括酒保，野生火鸡和玛格丽塔。其他参考流行电影，包括战斗俱乐部和塔拉迪加之夜。一个黑客工具，代号为**RickyBobby**，后是一个赛车手在**Talladega**之夜的角色，据称是用于上传和下载信息“**未被检测为恶意软件**”。

  

与英国GCHQ联合开发的三星恶意软件，被称为“**哭泣的天使**”，显然是以一个 “Doctor Who”的名字命名的。

![](../Images/91e5791f13c29ab3495bcf201562f7fa.png)

**那么又是谁在泄漏？**

维基解密说，该材料来自CIA网络智能中心内的一个“**孤立的，高安全网络**”，间谍机构的内部武器，进行网络攻击和防御。它说这些文件是“**以未经授权的方式在美国前政府黑客和承包商之间传播，其中一个向维基解密提供了部分存档**”。它没有清楚说明谁是漏洞的背后，也留下了几种可能性：**间谍，流氓员工，涉及联邦承包商的盗窃或暂存服务器的入侵，这些信息可能已被临时存储**。

  

**那么到底，还有更多来自“Vault 7”吗？**

Wikileaks承诺将来进一步发布信息，但没有给出预期的日期，也没有说他们可能包含些什么。

  

该组织还提到，从最初版本中编辑的一些数据看，如所有实际的计算机代码公布，一旦确定它构成对CIA的风险，可能会被下线。

  

**中情局和美国政府如何回应发布？**

中情局发言人说，该机构不会就“**所谓情报文件的真实性或内容**”发表评论。特朗普管理发言人Sean Spicer也拒绝了对此置评。

  

**目标设备的制造商说什么？**

  

诸如苹果，许多技术公司之一的设备似乎有针对性发布了一个声明，周二晚些时候说，文档描述的许多漏洞已经在最新版本的iOS移动操作系统得到修复，并旨在安抚客户它正在修补其余的洞。

  

它说：**“****虽然我们的初步分析表明，今天泄漏的许多问题已经修补在最新的iOS，我们将继续工作，以迅速解决任何已识别的漏洞，****”**它补充说。**“****我们总是敦促客户下载最新的iOS，以确保他们有最新的安全更新。”**

  

**微软**和**三星**都表示，他们正在调查报告。安全消息应用程序**Signal**的制造商说，泄露的文档中描述的声称工具似乎影响用户的实际手机，但不是其软件设计或加密协议。流行的电报移动消息应用程序的制造商在声明中说，手机及其操作系统的制造商，包括**苹果**，**谷歌**和**三星**，负责提高他们的设备的安全性。它说，这项工作将需要“**许多小时的工作和许多安全更新**”，并向客户保证：“**如果CIA不在你的调查范围内，你不应该开始就担心**。”

  

**我有被监视的危险吗？**

![](../Images/d4cea7230f1c2447122c8e1cc5cd8bb5.png)

CIA的目标应该谨慎，但该机构不可能一次性地窃取数百万台电视机。照片：彭博/彭博通过Getty图片

与大规模“**SIGINT**”实践的NSA或信号情报不同，**中央情报局倾向于专注于有针对性的监视**。执行所描述的攻击的成本很高，并且每次使用它们时，如果被发现和加固它们，则它们被使得无用。这意味着，CIA不太可能一次使用这种技术来攻击数百万台电视机 ——至少是因为特定的攻击需要物理访问电视。

  

原子能机构需要对智能手机和其他设备进行有针对性的攻击，部分是由于加密通信的一般成功。尽管维基解密的声明很小，但文档并没有指出WhatsApp和Signal等加密的消息传递应用程序已被破坏。**但如果他们正在运行的电话在根级别受到损害，即使最安全的应用程序也不能保证其用户的安全**。  

  

因此，加密通信开发人员正在呼吁泄漏，作为他们成功的证据。Open Whisper Systems 周二发布的一份声明称，**“****无处不在的端到端加密正在将情报机构从不可检测的大规模监控推向昂贵，高风险，有针对性的攻击。”**这个故事不是关于**Signal**或**WhatsApp**的，但在某种程度上，我们认为它是确认我们正在做的是工作。

  

**有什么我可以做的，以帮助确保隐私？**

安全研究员**Matt Blaze** 在Twitter上分享了他的提示：**“****作为用户，你可以做什么防护？无聊的东西。让您的软件更新保持最新状态。不要运行不必要的应用程序。”**但是，最重要的是：“**不要成为中央情报局的目标，不要让它找上你**”
