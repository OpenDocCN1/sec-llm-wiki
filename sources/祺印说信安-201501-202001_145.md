# 报告显示Windows 10系统去年的安全漏洞比Windows7更多

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652085484&idx=4&sn=fbcebbd5194b4e2ab77476243543fbb9&chksm=8bbcb6d5bccb3fc3cec4c4dd3074cde2cd40c2501bd45ee786e38e3cacf411bc0fa3f2a990fe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652085484&idx=4&sn=fbcebbd5194b4e2ab77476243543fbb9&chksm=8bbcb6d5bccb3fc3cec4c4dd3074cde2cd40c2501bd45ee786e38e3cacf411bc0fa3f2a990fe&scene=27#wechat_redirect)

win10在美国，据说占有率已经超越win7了。而win10的安全状况，又是怎样的呢？对于每一个习惯在微软视窗系统下工作的朋友们，应该更加关注一下。  

一项由RiskBased Security所做的调查显示，微软于2016年全年修补的安全漏洞总数比2015年的有所增加，而在历史漏洞数排名表格中，Internet Explorer和Windows 10分别位居第一和第二。**这个结果令人有点吃惊，Windows 10系统于2015年7月才推出，而它的历史安全漏洞数已经排在第二，共有705个。Windows 7系统则排在第四，共有647个。**

![](../Images/d7494f7c90f43aa2092cc39ddb9150f4.png "报告显示Windows 10系统去年的安全漏洞比Windows7更多的图片")

具体地来说，2015年微软修补的安全漏洞总数为703，2016年这一数字增加到729。而在2014年时，这一数字只有383，也就是说2016年与2014年相比，安全漏洞的数量增加了一倍左右。

有一点需要知道的是，虽然Windows10系统的安全漏洞数增加了很多，但这并不表明这一最新的操作系统不安全。因为这些安全漏洞中的大多数都是秘密报告给微软，微软会在漏洞给公众造成危害之前就将其修复好。另外，微软在去年8月发布的Windows10创造者更新能够处理对于未经修复的漏洞的攻击，在微软进行修复之前保障用户的安全。
