# IT网管之三种层次

今天是几号？这个问题，有时间很简单。不过对于做IT的我们来说，可能有好多人记不清楚。但是，在电脑前，我会很快知道答案，同时告诉你。可能这是我们做IT的职业习惯引起的吧，时间长了，很多习惯不经意间潜移默化的与电脑有关了，以电脑而引起很多习惯。

使用电脑，作为IT从业人员，我们的电脑还是有点不同的。我们一定不会把重要文件放在桌面上去，临时存放的文件，我喜欢归类后，保存后删除桌面上无用的文件。当然，我们会安装很多程序，你会发现我们的电脑开始菜单很长。对自己的电脑安全，也比较重视。

同是网管的我们，如果是企业的网管和网吧的网管，是很不同的。不过，很多人，把网管和IT管理人员等同的是很正常的事情。网吧的网管，环境单纯而复杂，工作基本上是一个服务员。而迎来送往的人，又是形形色色的人，耳闻目染间，不自觉会养成一些习惯。这也是我一些朋友曾经告诫我的，他说做IT我会很快学会抽烟，喝酒，玩游戏。当然，我是个个例吧。我既没有学会抽烟、喝酒、玩游戏，连酒都很少沾。很多人，在这些环境中，一年后都五毒俱全了吧。网吧的网管，无论在什么地方，听见有人喊网管，一定会跑去帮忙的；网吧网管，是网民口中的技术支持的代名词，很少有敬意的意思。每日的生活暗无天日，缺少锻炼。坐着能睡着，站着可以打瞌睡，一天可以吃一顿饭，几天不睡觉，很正常。喜欢异想天开的，无所事事时，对着屏幕发呆，顺手胡乱点击鼠标……

  

而企业里的IT，也是一部分人称作IT从业人员的人呢？在企业里，每天面对一大堆技术问题，很多问题无法远程操作时，也要跑来跑去，有时某些技术好的人朋友背冠以“师傅”或者“高手”，而同事也会时不时，咨询一些电脑问题，比如让你帮他参详一些机器的配置，品牌。偶尔，会去同事家里，帮忙处理一些电脑问题等。而，同事都客客气气的和你交往，慢慢很多人就把自己的脾气养大了，对人不够尊重。这些人，其实要自己不断时刻反省自己的，毕竟大家在人格上是平等的，人各有所长而已，别人尊重你，同样要保持谦卑的心，尊重别人。对待同事，以平等待人，工作分出轻重缓急。

  

听人说，事业单位的员工，都很官僚，会以权谋私的，嫉妒别人比自己强，对朋友不仗义，以次充好等，不过和这些人接触不多，如果是真的，那么作为IT从业人员，是凭技术水平吃饭的人，品质不要太差才好吧。

  

其实，IT网管，很多习惯个性，来自职业。任何职业都一样，差异就是在于工作对象的不同。IT是信息技术，对象是比较只能化的东西吧。不过，智能化的东西，你对它所做的一切他又是如此客观的反应给你。好的IT从业者，对技术是怀着敬畏心里的，不断进步的一群人。不懂的勾心斗角，因为技术是不能通过耍心眼能解决的，你有多少能耐，就能处理多大的问题。这使得，IT从业者，给人的感觉是很内向和沉闷。属于静默一族吧。因为他们面对的是同样静默而又是人类智慧的结晶。
