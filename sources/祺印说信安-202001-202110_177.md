# 由美国最大肉类加工巨头被黑的一点点浅想

美国燃料管道被黑客攻击后，世界肉类加工企业巨头JBS也在近日被“黑”，北美地区和澳大利亚的部分工厂受到影响，据报道美国的肉类批发价格应声出现上涨。

  
此前，5月12日，国外securityweek网站就食品供应链的网络安全威胁发布文章，文章先是发出食品供应到底有多安全的疑问？

![](../Images/7fe9cde0bbee97154b44bf90d3fc38ab.png)

**食品供应链有多安全？**  

这是一个需要问的问题。粮食供应是社会安全有序的基本支柱，灾难性的粮食短缺会迅速导致社会混乱。这个，我们很多人都在老人的教育下，不断强调那个饥饿年代的恐慌，老人们耳提面命告诫我们需要珍惜粮食，最近一直关注温铁军教授谈论三农问题，也对粮食安全有了不同的认知。加之，我国袁隆平院士的离开，让我们重新看待粮食安全，粮食安全自然也涉及到食品供应链安全。

**什么是食品供应链安全呢？**风险来自威胁，对社会影响最大的莫过于粮食安全。所谓，民以食为天，又说人是铁饭是钢。那么，除了自然灾害外，食品安全还存在于其供应链安全上。在现代社会中，供应链安全又涉及非常广，如运输安全、仓储安全、加工安全等等，加工安全，这些都与网络安全息息相关，由于现代信息化的影响之深远，网络风险也成为供应链安全的最重要一环，时刻影响着交通、仓储、加工方方面面的安全。

那么，第一个问题是食品供应是否存在网络威胁。网络犯罪分子是否有可能攻击食品行业的可能呢？

从最近报道来看，我们已经应验了。据彭博社周二报道，**JBS在美国的所有牛肉工厂全都被迫停工**，而据行业人士估计，JBS大致控制着美国20%的牛和猪的屠宰产能。攻击事件导致的停工对美国肉类市场已经产生明显影响。

答案已经被这次对JBS网络攻击验证了，无需多言。黑客攻击可能来自于四个方向，黑客行动主义者、网络犯罪团伙和民族国家都可能作为攻击食品供应链的攻击者，也可能是食品工业组织的竞争对手。

另外食品供应链的安全不局限于自身的网络安全，食品供应涉及交通、运输、仓储、销售各个环节，每一个环节的网络风险都可能间接影响食品供应链安全。

  

所以，我们关注网络安全，特别是供应链安全，需要更深入更全面的考虑网络安全。随着信息化不断深入，养殖、屠宰、仓储、运输各个环节，都将引入网络提升生产效率，同时各个环节也都将面临供应链攻击，都能影响最终食品安全。  

当然食品安全既有供应充足与否，饿不饿肚子的安全；也有食品是否质量良好，健不健康的安全。我们讨论的是前者，后者不在此讨论范围。这也是脚踩西瓜皮，胡乱唠叨几句，不专业也不系统，仅仅粗聊一下，还望方家见谅！
