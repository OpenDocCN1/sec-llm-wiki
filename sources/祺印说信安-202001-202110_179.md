# Firefox ESR 78.11 中修复安全漏洞

#### NIST报道称Mozilla 已发布安全更新以解决 Firefox 和 Firefox ESR 中的漏洞。攻击者可以利用其中一些漏洞来控制受影响的系统。

#### **#CVE-2021-29964：解析“WM\_COPYDATA”消息时越界读取**

本地安装的恶意程序可能会发送`WM_COPYDATA`Firefox 会错误处理的消息，从而导致越界读取。

*此错误仅影响 Windows 上的 Firefox。其他操作系统不受影响。*

![](../Images/d77ebd297f33f3b1cf1b32b600798d44.png)

  

#### **#CVE-2021-29967：在 Firefox 89 和 Firefox ESR 78.11 中修复了内存安全错误**

Mozilla 开发人员 Gabriele Svelto、Anny Gakhokidze、Alexandru Michis、Christian Holler 报告了 Firefox 88 和 Firefox ESR 78.10 中存在的内存安全错误。其中一些错误显示了内存损坏的证据，我们假设通过足够的努力，其中一些可能已被利用来运行任意代码。
