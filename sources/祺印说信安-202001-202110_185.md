# 西门子 PLC 发现一个新漏洞黑客可远程运行恶意代码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652088772&idx=1&sn=31fe2d1c6630fbd46399f3abc7f3267d&chksm=8bbc83fdbccb0aebded0d7fcd286237bb5642dcd29bdae615bab63e25dad093445ee6ad179d7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652088772&idx=1&sn=31fe2d1c6630fbd46399f3abc7f3267d&chksm=8bbc83fdbccb0aebded0d7fcd286237bb5642dcd29bdae615bab63e25dad093445ee6ad179d7&scene=27#wechat_redirect)

![](../Images/09ae575cfa52545bb55dacf0bf958903.png)

西门子于上周五发布了固件更新，解决 SIMATIC S7-1200 和 S7-1500 可编程逻辑控制器 (PLC) 中的一个严重漏洞，黑客可利用漏洞远程访问受保护的内存区域并获取不受限制和未被检测到的代码执行，研究人员将其描述为攻击者的“**圣杯**”。

![](../Images/b655c8e0c2b5afb98446456931453e07.png)

内存保护绕过漏洞，编号为CVE-2020-15782（CVSS 评分：8.1），是由运营技术安全公司 Claroty 通过对用于在微处理器中执行 PLC 程序的 MC7 / MC7+ 字节码语言进行逆向工程而发现的。暂时没有证据表明漏洞在野外被滥用。

  

在西门子发布的一份咨询报告表示，未经身份验证的远程攻击者可以通过网络访问 TCP102 端口 ，向受保护的内存区域写入任意数据和代码，或读取敏感数据以发起进一步攻击。![](../Images/37f702490e5860156c5c7b17876a91b1.png)  
新漏洞允许攻击者在 Siemens S7 PLC 上获得本地代码执行，复杂的远程攻击还能逃避用户沙箱将任意数据和代码直接写入受保护的环境中，从而避免被底层操作系统或任何诊断软件检测到。  

![](../Images/fe29e58202210dd6eef831acca56d789.png)

2010 年，臭名昭著的Stuxnet蠕虫利用 Windows 中的多个漏洞，通过修改西门子 PLC 上的代码来重新编程工业控制系统，以进行网络间谍活动和秘密破坏。  
  
在 2019 年，研究人员展示了一种名为“ Rogue7 ”的新型攻击，利用其专有 S7 通信协议中的漏洞创建一个流氓工程师站，伪装成PLC的TIA并注入任何有利于攻击者的消息。![](../Images/890ee47047dff01ea2740f2eef9c3185.png)西门子官方“**强烈**”建议用户更新到最新版本以降低风险。该公司表示，还将进一步汇总更新，并敦促客户对尚未提供更新的产品采取对策和变通方法。
