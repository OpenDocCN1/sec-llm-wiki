# 微软2020年9月份于补丁日针对129个安全漏洞发布补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652087137&idx=1&sn=dee3d8ee0201fe189c22fa7b3c54d16f&chksm=8bbc8958bccb004e89d6fad4ad05abddd006f6dc79b4e06d9fd7ee5a16a2a5b46c8a93cd60fd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652087137&idx=1&sn=dee3d8ee0201fe189c22fa7b3c54d16f&chksm=8bbc8958bccb004e89d6fad4ad05abddd006f6dc79b4e06d9fd7ee5a16a2a5b46c8a93cd60fd&scene=27#wechat_redirect)

微软本月发布了新的一批安全更新，再次破百。修复总共129个新发现的安全漏洞漏洞影响其Windows操作系统和相关软件的各种版本。  
  

在涵盖其各种产品（Microsoft Windows，Edge浏览器，Internet Explorer，ChakraCore，SQL Server，Exchange Server，Office，ASP.NET，OneDrive，Azure DevOps，Visual Studio和Microsoft Dynamics）的129个漏洞中，23列为紧急，105个为重要。

![](../Images/0f34806c16d0f3806d87111c3e31089f.png)

  
  
  

\-        **CVE-2020-16875**  -Microsoft Exchange内存损坏漏洞

这是本月解决最严重的漏洞之一。攻击者可以通过向受影响的Exchange Server发送特制电子邮件来在SYSTEM执行代码。

  

 -        **CVE-1120-1129** -Microsoft Windows编解码器库远程代码执行漏洞 

如果受影响的系统查看特制图像可能允许执行代码。由于此漏洞位于编解码器库中，因此可能会影响多个应用程序。HEVC  流的解析中存在特定缺陷 。视频文件中精心制作的HEVC流可能触发基于固定长度堆栈的缓冲区溢出。

\-        **CVE-2020-0922 ** -微软COM的Windows远程代码执行漏洞允许攻击者在受影响系统上执行代码，通过一个特制的文件或引诱目标的网站托管恶意JavaScript。由于此错误位于COM中，可能会有多个应用程序受此漏洞影响。\-        **CVE-2020-0951 ** - Windows Defender的应用控制安全功能绕过漏洞在本地计算机上具有管理特权的攻击者可以连接到PowerShell会话并发送命令以执行任意代码。此行为应被WDAC阻止，却使其成为一个有趣的绕过。需要管理员主动下载补丁进行修补。

  

  
  

强烈建议Windows用户和系统管理员尽快应用最新的安全补丁，以使网络犯罪分子和黑客远离控制他们的计算机的能力。

  
  
Windows安全更新：设置→更新和安全→Windows更新→检查更新或手动安装更新。
