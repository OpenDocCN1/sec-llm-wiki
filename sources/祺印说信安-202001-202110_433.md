# 本田勒索攻击验证工业蜜罐研究的成果

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086686&idx=1&sn=c1832171825b5b6e4b9e61afbba701d9&chksm=8bbc8ba7bccb02b1a5e2c6d2c3929d93cb6f65ae55a1575f548129b2b919c92a97ea15109b39&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086686&idx=1&sn=c1832171825b5b6e4b9e61afbba701d9&chksm=8bbc8ba7bccb02b1a5e2c6d2c3929d93cb6f65ae55a1575f548129b2b919c92a97ea15109b39&scene=27#wechat_redirect)

黑客组织针对关键基础架构的多阶段目标的勒索软件攻击，旨在最大程度地提高破坏和恢复成本，已越发普遍。对蜜罐捕获攻击的分析显示了入侵、持久性和横向移动，在尽可能多的系统上同时引爆三个基本步骤。

此次攻击是由Cybereason的2020年蜜罐研究捕获的。与2018年的研究类似，使用的蜜罐看起来像是一家在北美和欧洲都有业务的电力公司。在2018年，该系统被渗透，表明攻击者打算在暗网上出售访问权限。今年，研究人员确定了多个攻击者正在执行勒索软件操作，攻击涉及数据盗窃，用户凭据窃取以及跨受害者网络的横向移动，以破坏尽可能多的端点。 综合研究表明，网络犯罪分子越来越多地将目标对准具有关键基础设施的大型公司。

![](../Images/4fb115bd0d0afa4459465b29caf6091a.png)

Cybereason蜜罐伪装成发电和输电提供商网络（包括IT，OT和HMI环境）的一部分。攻击者通过远程管理界面获得了最初的访问权限，并强行接管管理员帐户。攻击者通过上传一个PowerShell脚本，创建了一个称为“ Admin”的后门用户帐户。这样可以确保将来的访问并创建持久性连接，使攻击者可以上传其他攻击工具。其中之一就是**Mimikatz**，用来窃取用户凭证，进行服务器的横向移动。在这种情况下它是失败的，因为其获得的所有凭据都无法访问域控制器。相反，攻击者使用网络扫描程序来发现其他端点，在尽可能多的端点被检测到并遭到破坏后，勒索软件才会同时被引爆。该报告缺少许多细节，没有命名用于蜜罐捕获的勒索软件或勒索软件样本。没有指出可能危害了多少个端点，也没有说环境的IT和OT方面是否都受到损害，没有提供任何攻击日期或持续时间的任何指示，也没有提及赎金记录，也没有提及攻击的“数据盗窃”要素的任何细节等。尽管如此，该项研究的基本发现和结论几乎可以肯定是准确的。首先，关键行业越来越多地受到勒索软件的攻击；其次，攻击者试图将自己深深地嵌入受害者网络中，以最大程度地增加引爆时造成的伤害。本周，日本本田汽车制造商遭到重大勒索软件攻击的消息，正好印证了这一研究成果。安全研究人员越来越有信心的认为攻击涉及到了SNAKE勒索软件。本田只是证实本田网络发生了网络攻击，工业蜜罐研究对日本以外的生产系统也产生了影响。实际上，英国Swindon以及北美、土耳其、意大利和日本的工厂已暂停生产。Sentinel One的首席安全顾问Morgan Wright评论道：“SNAKE勒索软件旨在攻击工业控制系统网络。本田已暂停生产并将工厂工人送回本国，这是破坏其制造系统的既定事实。”  
也证实了Cybereason的结论，即关键行业的制造现在是勒索软件的主要目标。就像世界各地不同工厂的同时关闭，证实横向移动结合同时引爆以实现最大效果的做法是一致的。本田周三表示，本田经历了一次网络攻击，影响了美国一些工厂的生产运营。但是，目前没有证据表明会丢失个人身份信息。已经恢复了大多数工厂的生产，并且正在努力争取在俄亥俄州的汽车和发动机工厂生产线的恢复。
