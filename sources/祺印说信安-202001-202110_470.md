# 僵尸网络恶意软件“黑玫瑰露西”添加勒索功能

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086402&idx=1&sn=9c18eeeabc8d38e6c9d206e1a24fa9f6&chksm=8bbc8abbbccb03ad8ccf715c2c31f539d13bee4e72eecb9d6f76cefa2cad29ed511fb3efbc62&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086402&idx=1&sn=9c18eeeabc8d38e6c9d206e1a24fa9f6&chksm=8bbc8abbbccb03ad8ccf715c2c31f539d13bee4e72eecb9d6f76cefa2cad29ed511fb3efbc62&scene=27#wechat_redirect)

**据国外安全媒体报道，Check Point研究人员发现**僵尸网络**恶意软件****“黑玫瑰露西”已将勒索软件功能整合到其攻击工具包中。**

Check Point Research得知黑玫瑰露西（Black Rose Lucy）已经回归后，该安全公司随后收集了一些样本，发现该恶意软件伪装成视频播放器应用程序。在这种伪装下，恶意应用程序试图诱使用户启用**Accessibility Services**，以最大程度地减少最终安装勒索软件有效负载所需的用户交互量。同时，使用两个命令来指示设备保持其屏幕和Wi-Fi连接保持打开状态。

连接到其四个服务器（命令与控制）之一后，该恶意软件会收到一个名为“ Key”的字符串作为响应。然后，威胁使用服务来获取受感染设备目录的数组。使用此信息，Lucy设置为对存储在已标识阵列中的所有文件进行加密。正是在这一点上，显示了一张似乎来自美国联邦调查局（FBI）的赎金记录。该消息告知受害者，执法人员在其设备上发现色情内容，要求他们支付500美元的罚款，以减轻其罪行。

![](../Images/0e738ee0881145927fd2d8b7f7e2d8df.png)

Black Rose Lucy恶意软件于2018年被发现，发现它的安全公司是以色列的Check Point，当时未发现勒索软件功能。僵尸网络依靠两个组件来进行恶意活动，恶意软件即服务（MaaS）。Lucy Loader充当远程控制仪表盘的第一个元素，目的是将受感染的设备合并到僵尸网络中并安装其他恶意软件有效载荷。Black Rose Dropper作为第二个要素，通过收集信息并从僵尸网络的C＆C服务器中检索辅助恶意软件来定位Android设备。

组织的安全安全专家可以利用强大的策略来实施移动安全最佳实践，从而帮助他们的组织抵御Lucy恶意软件。准则应包括限制员工可以在其工作设备上安装应用程序的位置和开发人员的类型等。此外，信息安全人员可以考虑使用由人工智能（AI）驱动的工具来辅助应付复杂的威胁。
