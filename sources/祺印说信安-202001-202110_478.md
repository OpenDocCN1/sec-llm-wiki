# 万豪再曝泄露520万酒店客人数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086352&idx=1&sn=ef24a75d8c2cec4d98ee02ab208c2f88&chksm=8bbc8a69bccb037f0d93a37f2b286ac581fb1049717076500a6a8ac15f5ae6e49527b41c7bfb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086352&idx=1&sn=ef24a75d8c2cec4d98ee02ab208c2f88&chksm=8bbc8a69bccb037f0d93a37f2b286ac581fb1049717076500a6a8ac15f5ae6e49527b41c7bfb&scene=27#wechat_redirect)

2016年万豪酒店将喜达屋酒店（Starwood Hotels）纳入旗下，喜达屋酒店客人预订数据库于2014年遭黑客破坏。喜达屋酒店数据库被黑客窃取于2018年11月被发现，泄露客户涉及全球超过3.39亿位客人的个人详细信息，因此欧盟根据GDPR法律，被英国数据隐私监管机构信息专员办公室处以9,900万英镑（1.23亿美元）罚款。  

![](../Images/c989742b46977631ca6e5e354791ad3b.png)

  

  

  

据国外安全网站披露，万豪酒店最近又宣布了一项数据泄露事件，此次数据泄露涉及客户达520万名人，万豪在一份声明中说：“2020年2月底，发现黑客可能使用两名雇员在一家特许经营场所的登录凭据访问了访客信息，该事件始于2020年1月中旬。在发现后，禁用客人的登录凭据，并立即展开调查，加强监控，并安排人员来告知和帮助客人。”  

![](../Images/6cd490104bce542417a99b34d679d82b.png)

  

此次泄露客人信息包括如联系方式（姓名，邮寄地址，电子邮件地址和电话号码）、会员帐户信息（帐号和积分余额）以及其他信息如公司、性别、出生日期、房间偏好和语言偏好。万豪针对此事件，已采取相应的安全措施，禁用有泄露嫌疑的会员密码，并且通知客人更改密码，并建议客人启用多因素身份验证。  
  
个人隐私信息的泄露，容易引发社会工程学攻击，黑客对你个人信息了解的越多，就越有机会实施社会工程学攻击。除了我们不断重申的GDPR以外，我国在个人隐私方面也不断加强了监管，个人信息在一部讲述个人隐私的电影里，说个人信息已然成为一个万亿级商品，这就是我们常说的集腋成裘，汇聚了海量的个人信息成为大数据，对个人、社会、国家的影响都是至关重要的，所以个人、企业、社会都有义务保护好个人隐私信息。
