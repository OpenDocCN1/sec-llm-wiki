# 美国NIST发布隐私框架1.0版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652086284&idx=1&sn=917e9caac566833ebc244125ea2b0fdf&chksm=8bbc8a35bccb0323cb7df8a7c55048ad56861dfacabce652fec27191e84fb3a188aa374669f7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652086284&idx=1&sn=917e9caac566833ebc244125ea2b0fdf&chksm=8bbc8a35bccb0323cb7df8a7c55048ad56861dfacabce652fec27191e84fb3a188aa374669f7&scene=27#wechat_redirect)

### 该工具将有助于优化数据的有益使用，同时保护个人隐私。

我们的社会已然成为数据驱动型社会，有一项棘手的平衡行为要执行即：构建使用个人数据的创新产品和服务，同时保护人们的隐私。为了帮助组织保持这种平衡，美国国家标准技术研究院（NIST）提供了一种用于管理隐私风险的新工具。

该机构在一月份发布了***NIST隐私框架* 1.0版***：通过企业风险管理改善隐私的工具。*该框架是与众多利益相关者合作，一路从草案版本到最终确定发布版本开发而来的，为希望改进其使用和保护个人数据方法的组织提供了一组有用的隐私保护策略。该出版物还提供了有关隐私风险管理概念以及隐私框架与NIST网络安全框架之间关系的说明。

![](../Images/6507015ffb2f10736391111c9016a6c2.png)

  

标准与技术商务部副部长兼NIST主任Walter G. Copan认为：“在当今的数字时代，隐私比以往任何时候都重要，隐私框架的开发已经获得了强有力的支持，这表明迫切需要工具来帮助组织构建提供真正价值并保护人们隐私的产品和服务。”

个人数据包括公司在正常业务过程中可能会收集和使用的有关特定个人的信息，例如其地址或社会安全号码。可以使用此数据来标识提供该数据的人员，所以组织必须经常采取措施以确保不会以可能使人难堪、危害或损害客户的方式滥用这些数据。

NIST隐私框架不是法律或法规，而是一种自愿性工具，可以帮助组织管理因其产品和服务而引起的隐私风险，并证明其符合可能影响它的的法律，例如《**加州消费者隐私法**》和欧盟的**通用数据保护条例**。它可以帮助组织确定他们想要实现的隐私结果，然后确定需要采取的行动的优先级。

NIST的高级隐私政策顾问兼框架负责人**Naomi Lefkovitz**说：“您会在框架中找到构建模块，可以帮助您实现隐私目标，其中可能包括组织需要遵循的法律。如果您想考虑如何通过更具隐私保护性的产品或服务来提高客户信任度，则该框架可以帮助您做到这一点。但是我们将其设计为对任何法律均不可知，因此无论您的目标是什么，它都能为您提供帮助。”

文章认为隐私作为美国的一项基本权利，已根植于美国宪法。其实隐私权利不仅仅是美国人关注，全世界人都在关注，我国有关隐私相关法律法规的出台，欧盟的GDPR等的出台，无不在强调合法利用个人隐私数据的重要性。但在数字时代的应用仍在不断发展，技术本身正在以迅猛的速度变化。数据的新用途层出不穷，特别是在物联网和人工智能的大背景下，组织就有了共同收集和分析个人数据的渴望，以应用于以前无法识别的现实世界中的模式。这些是机会同时带来了新的风险，个人信息是万亿级别的商品，我们的个人信息就是商品。

**Naomi Lefkovitz**同时认为：“如今，我们认为一类低价值的个人数据可能会在几年后有全新的用途，或者您可能拥有两类对自己并不敏感的数据，但是如果您将它们放在一起，它们可能突然变得整体敏感。这就是为什么您需要一个用于隐私风险管理的框架，而不仅仅是一个任务清单：您需要一种允许您不断重新评估和适应新风险的方法。”

![](../Images/1a983aeac4eb5837f40c2090cdc57ab4.png)

Privacy Framework 1.0具有一个以广泛使用的NIST网络安全框架为模型的总体结构，并且这两个框架被设计为互补的，并且会随着时间的推移而更新。莱夫科维茨说，隐私和安全是相关的，但概念却截然不同，仅仅采取良好的安全状态并不一定意味着组织可以满足其所有隐私需求。

与它的草案版本一样，隐私框架集中在三个部分上：***核心，***提供一系列隐私保护活动；***配置文件，***有助于确定适合该核心活动的组织应该追求最有效地实现其目标；***执行层级****，*有助于优化资源专门用于管理隐私风险。

NIST的作者计划继续以他们的工作为基础，以使框架的用户受益。数字隐私风险管理是一个相对较新的概念，Lefkovitz说，他们收到了许多澄清隐私风险性质以及其他支持资源的要求。

她说：“人们继续渴望获得有关如何进行隐私风险管理的更多指导。我们已经发布了该框架的配套路线图，为进一步研究以解决当前的隐私挑战指明了道路，并且我们正在建立指导资源库以支持该框架的实施。我们希望用户社区能够为所有人的利益做出贡献，以提高隐私权。”
