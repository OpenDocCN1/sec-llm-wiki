多家网络安全供应商产品受最新 OpenSSL 漏洞影响

自 2014 年 Heartbleed 漏洞披露以来，OpenSSL 在安全性方面有了很大的发展。

OpenSSL 是一个实现传输层安全 (TLS) 和安全套接字层 (SSL) 协议的开源库，被组织广泛用于保护通信。

2014 年 4 月，全世界获悉 OpenSSL 受到了一个名为Heartbleed并被跟踪为 CVE-2014-0160 的严重漏洞的影响，该漏洞可被利用从本应受保护的通信中窃取潜在的敏感信息，而不会留下任何痕迹。

Heartbleed 漏洞允许 Internet 上的任何人读取受 OpenSSL 软件易受攻击版本保护的系统的内存，这会损害用于识别服务提供商和加密流量、用户名和密码以及实际内容的密钥。这使得攻击者可以窃听通信，直接从服务和用户那里窃取数据，并冒充服务和用户。

网络安全、云、存储和其他供应商正在评估最近的 OpenSSL 漏洞对其产品和服务的影响。

OpenSSL 项目本月早些时候发布的更新修补了与证书解析相关的高严重性拒绝服务 (DoS) 漏洞。

该安全漏洞被跟踪为CVE-2022-0778，由 Google 漏洞研究员 Tavis Ormandy 报告，影响 OpenSSL 版本 1.0.2、1.1.1 和 3.0，已在 1.0.2zd、1.1.1n 和 3.0.2 版本的发布中得到修复。

在某些情况下可以利用该漏洞，它可能导致对解析外部提供的证书的进程进行 DoS 攻击。

技术细节和至少一个概念验证 (PoC) 漏洞利用是公开的，其产品和服务依赖于 OpenSSL 的公司已经开始评估其影响。

Palo Alto Networks周三通知客户，仍在调查 CVE-2022-0778 对其产品的影响，但该公司迄今已确认 PAN-OS、GlobalProtect 应用程序和 Cortex XDR 代理软件包含易受攻击的版本OpenSSL。正在为受影响的产品开发修复程序。

“对于 PAN-OS 软件，这包括硬件和虚拟防火墙、Panorama 设备以及 Prisma Access 客户。该漏洞降低了 Cortex XDR 代理和 Global Protect 应用程序的严重性，因为成功利用需要中间攻击（MITM），”该公司解释说。

F5表示 OpenSSL 漏洞会影响 BIG-IP 和 Traffix 产品，并且正在开发补丁。只有使用特定配置时，BIG-IP 才会受到影响。

Check Point还确认其部分产品受到影响，该公司已发布补丁。

Sophos表示，该漏洞影响其防火墙、UTM 和 Web Appliance 产品。该公司的咨询通知客户，修复计划在 3 月下旬和 4 月进行。

目前正在调查 CVE-2022-0778 影响的其他网络安全供应商包括SonicWall和Pulse Secure。

QNAP本周发布公告，通知客户其用于 NAS 设备的多个版本的 QTS、QuTS 和 QuTScloud 操作系统受到影响。存储解决方案提供商正在开发补丁。

VyOS开源路由器和防火墙平台的开发者也确认1.3.0版本受到影响。OpenSSL 组件已使用最近的 VyOS 1.3.1 版本进行了更新。

AWS还发布了一份简短的安全公告，告知客户它已意识到该问题并调查对其服务的影响。

NetApp还发现了十多种受影响的产品，并已开始发布补丁。

Red Hat最初表示它没有直接受到该漏洞的影响，但进一步调查显示，某些版本的 Red Hat Enterprise Linux 容易受到 DoS 攻击。

其他 Linux 发行版也相继发布了公告。
