# 未来 SOC 的第一个组成部分是数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652092690&idx=2&sn=adb91a6df4a83c35a9aef8a8c0316984&chksm=8bbc932bbccb1a3d5ce65e7806b0130998e70869122e6dbacfe6e9b23e36f1446ca0d2685911&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652092690&idx=2&sn=adb91a6df4a83c35a9aef8a8c0316984&chksm=8bbc932bbccb1a3d5ce65e7806b0130998e70869122e6dbacfe6e9b23e36f1446ca0d2685911&scene=27#wechat_redirect)

**数据是安全的命脉，因为其它提供了来自广泛的内部和外部来源的上下文。**之前，讨论未来 SOC的概念，其使命是成为检测和响应组织。已经出现了全新的解决方案类别来支持这一使命，包括安全编排、自动化和响应 (SOAR)，以及最近的扩展检测和响应 (XDR)。 

![](../Images/67b61bb0edb4a6c894f3e273365bd07f.png)

  
作为一名安全专家，随时了解安全创新并更新工具和技术非常重要。但是，可能会限制你的组织可以从下一次安全投资中获得的价值，而无需首先考虑主要用例以及解决这些用例所需的功能。威胁检测和监控、调查、事件响应和狩猎都是针对检测和响应的用例。每个用例的起点都是关注数据。

**数据是安全的命脉**，因为它提供了来自广泛的内部和外部来源的上下文，包括系统、威胁、漏洞、身份等。当安全性由数据驱动时，团队可以专注于相关的高优先级问题，做出最佳决策并采取正确的行动。**数据驱动的安全性还提供了一个持续的反馈循环**，使团队能够捕获和使用数据来改进未来的分析。 

数据驱动的安全方法挑战了早期的流程驱动方法，这些方法通过定义流程和自动化完成该流程所需的步骤来加速响应。相反，数据驱动的前提是需要首先分析数据以确定是否满足正确的标准，一旦满足标准，就会触发适当的流程。自动化和编排嘈杂的数据只会放大噪音。在动态多变的环境中，运营现实是，需要不断确保拥有正确的数据来专注于对组织真正重要的事情，使用这些数据来确保更快地采取正确的行动，并获取反馈以进行学习从为改进而采取的行动。

那么，如何帮助 SOC 专注于数据呢？ 

首先从环境内部聚合事件和相关指标，例如来自 SIEM 系统、日志管理存储库、端点检测和响应 (EDR)、案例管理系统和其他安全基础设施。然后，关联这些数据以连接各个点并了解事件如何相互关联，并使用来自订阅的多个来源（商业、开源、政府、行业、现有安全供应商）的威胁数据自动扩充和丰富这些数据，以及像 MITRE ATT&CK 这样的框架。对来自不同来源、格式和语言的所有这些数据进行规范化，可以使用它。可以将环境内部的事件和相关指标与指标、对手及其方法的外部数据相关联， 

了解与组织的相关性后，可以确定首先关注的正确数据，哪些可以作为外围数据，这样就可以高效地工作。分配风险评分的能力可以根据环境和公司特定的风险概况对数据进行优先级排序。使用围绕源、类型、属性和上下文以及对手属性设置的参数，可以过滤掉对组织来说是什么噪音，并优先考虑真正重要的事情。例如，来自受信任来源的围绕特定于行业和地理区域、或业务模型和支持基础设施或可能影响与组织合作的第三方的攻击和漏洞的数据，再加上在环境中发现的指标或漏洞，需要立即关注。

数据驱动的方法来了一个完整的循环，提供不断丰富数据的反馈。采取行动的结果提供了额外的背景。优先级、威胁、活动和漏洞会随着它们的发展而更新，以使数据保持可靠。可以学习并适应所有这些动态，在整个过程中收集更多数据和上下文，并分析和应用它来更新优先级和评分以实现持续改进。

专注于数据的能力只是未来 SOC 需要高效和有效的核心能力之一。但还有更多。人的参与对于学习和效率至关重要。而且我们还没有涉及到有效地获取数据和发送数据所需的架构。
