## 

美国网络司令部的统一平台

  

**![](../Images/5fc98100dd671ba69feb42531defdb44.png)**

美国网络司令部统一平台计划的重要里程碑之一将是全面建设其软件工厂（美国空军）。图片来源于2019年10月外媒。

  

美国网络司令部统一平台计划的下一个重要里程碑将是一个完全建成的软件工厂，一个用于整合应用程序和开发新工具的环境。一旦启动并运行，软件工厂将帮助为网络任务部队集成和部署不同的分析能力。  
统一平台将整合和标准化网络司令部及其下属组织（包括国防信息系统局）使用的各种大数据工具。这将使部队能够更轻松地共享信息，并构建用于跨服务网络组件的通用工具，从而实现更大的互操作性。  
统一平台计划一直在稳步推进。诺斯罗普·格鲁曼公司于 2018年10月获得了该项目价值5400万美元的系统协调员合同，项目办公室建立了一个“软件工厂”，五家公司获得了名为Cyber Enterprise Services的项目下属合同，该项目将增强多个网络平台指挥和控制、规划、生成、执行、评估、报告和可视化方面的服务。  
诺斯罗普·格鲁曼公司负责网络解决方案的副总裁瓦伦蒂诺（Chris Valentino）提供了有关该计划所需工作类型的更多详细信息。软件工厂正在使用一种称为 Kubernetes的技术“容器化”应用程序，作为提供更灵活的平台和具有一套标准的基础设施的手段。  
Kubernetes是容器化的开源版本，它是微服务的一种虚拟化形式，瓦伦蒂诺说，它允许人们快速创建适用于网络任务部队的能力。“通过软件工厂的标准化和应用程序的容器化，这就创造了一个环境，人们可以为其开发软件，开发一个适用于CMF的任务应用程序，将其引入工厂，然后工厂包含所有的DevSecOps工具链，从而不仅为应用程序提供了一个通用的环境，同时也提供了检查，以确保它符合整体的连续（操作权限）环境。”  
统一平台计划将为网络部队构建和交付工具，尤其是分析工具提供环境。  
“归根结底，这真的是一个整体环境，它将使任务区能够集成不同类型的数据源，然后将其返回给任务部队，”他说，该项目目前的重点是数据接收和集成，不一定是进攻和防御工具。  
作为系统协调员，瓦伦蒂诺还表示，诺斯罗普公司正在帮助代表网络司令部和联合网络部队运行统一平台的空军“实施其敏捷实践和流程，以便能够快速创建和部署任务能力。”  

## 

网络司令部的第一个主要武器系统需要云

  

# 2019年9月，外媒曾报道称，美国空军计划在多家公司的云服务上花费高达9500万美元，以开发网络司令部的首批主要武器系统之一。  

  

# ![](../Images/0cdb5bb072e826d55c86c32c5674c644.png)

#    该合同将支持空军的LevelUP软件工厂。图片来源于2019年9月外媒。

#   

# 统一平台将允许网络团队共享信息、进行任务规划并提供执行任务所需的指挥和控制工具。它将整合网络司令部及其下属组织（例如国防信息系统局）使用的大数据平台。

  

# 空军表示，云服务将支持空军生命周期管理中心的LevelUP分支机构，该分支机构是一家软件工厂。作为其与统一平台合作的一部分，空军创建了一个软件工厂，将各种软件容器放在一起，并在此过程中允许工作人员在各种环境中复制数据库和服务，并最终允许这些服务按需扩展。

  

# 报道称，空军预计将授予多达15份的一揽子采购协议，该协议的估计价值为9500万美元。一揽子采购协议将“消除签约和公开市场成本，例如寻找货源、开发技术文件和招标以及评估报价。通过消除重复和单独购买的需要，进一步降低成本、减少文书工作并节省时间。”

  

## 

美国国防部加快发展“网络工厂”

  

2019年外媒曾报道称，美国国防部加快发展“网络工厂”。  
  
文章称，美国国防部网络部队所需的武器系统项目在2018年10月份获得第一份重大合同后正在加速推进。诺斯罗普·格鲁曼公司获得了一份统一平台系统协调员合同，这是美国网络司令部迄今为止最大和最关键的国家安全计划之一。官员们表示，该计划将整合开展运营所需的能力，并通过“网络工厂”持续交付。

  

![](../Images/5a5eb990394b11df5da4d7a11878279f.png)

美国国防部正在迅速努力在统一平台下提供网络部队能力（陆军）。图片来源于2019年1月外媒。

  

随着系统协调员合同的授予，该计划正在迅速提高生产能力。作为该计划的执行代理人，美国空军说：“根据国会的指示，我们正在整合和合理化当前的能力，并评估如何利用下一代能力最好地满足当前和新兴的作战人员需求。”主要工作将在德克萨斯州圣安东尼奥市统一平台项目管理办公室进行，该办公室隶属于空军生命周期管理中心指挥、控制、通信、情报和网络局下属的密码学和网络系统部。  
美国空军表示：“通过混合承包工具可使用广泛、可用和经过审查的人才库，统一平台将受益于最优秀和最聪明的人才，”以满足新兴的网络战士需求。  
目前，美国网络部队使用各种不同的系统，这些系统由各军种经过多年来开发。现在，在一个四星联合司令部下有了一支统一的网络部队，这些系统需要得到整合，以帮助指挥控制和任务规划。  
美国空军指出诺斯罗普公司系统协调员的角色是作为项目管理办公室的助手，执行项目管理办公室指导的某些任务。最初的两项关键任务包括建立“网络工厂”和扩展敏捷框架（SCALE Agile Framework，SAFe）实施，这是一个旨在指导企业完成复杂软件开发的框架。  
同样重要的是，国防部网络部队获得了自己的基础设施，以便在国家安全局之外规划和发动攻击，而国家安全局主要将其系统用于间谍活动。

  

背景补充1：**网络司令部5400 万美元的合同给了谁**

  

2018年10月，美国空军授予诺斯罗普·格鲁曼公司一份价值 5400万美元的合同，以成为美国网络司令部顶级武器系统统一平台的系统协调员。  
国家安全专家将统一平台描述为“网络载体”，国防部的网络战士将在其中计划和发起进攻性和防御性网络行动。作为统一平台系统协调员，诺斯罗普·格鲁曼公司将“整合不同的网络空间平台，实现综合管理和同步网络操作，使美军能够快速获得全方位的网络能力”。  
该合同旨在为统一平台计划提供持续开发、集成、部署和维护服务。根据国防部当年10月26日的公告，预计工作将于2021 年10月31日完成。  
“诺斯罗普·格鲁曼公司很自豪能与美国空军和美国网络司令部合作，提供这一关键任务能力，以支持我们国家的网络任务部队，”该公司表示，“我们期待提供集成的共享能力，让我们的网络作战人员在网络空间和所有领域都处于优势地位。”

  

背景补充2：**诺斯罗普·格鲁曼公司（Northrop Grumman）**

  

该公司成立于1994年，是诺斯罗普公司收购格鲁曼公司后组成的，是世界上最大的雷达制造商和最大的海军船只制造商，也是世界屈指可数的军工生产厂商。该公司最著名的产品有大名鼎鼎的B-2“幽灵”隐形轰炸机、RQ-4“全球鹰”无人机和F-14“雄猫”战斗机等。  
该公司航空航天系统部门主管载人飞机、自主系统、航天器、高能激光系统、微电子等系统的设计开发；集成和生产任务系统部门主管国防部、国际民用和商业客户的端到端任务解决方案，产品包括雷达传感器、情报处理系统等。作为一家全球性的军品安全公司，该公司在全球多地设有分公司，为当地的国防安全提供了大量的技术和产品支持；例如在东京的日本总部就为日本航空自卫队提供了F-35A战斗机的组件及雷达通信系统，同时为其他机型提供对应的雷达导航以及IFF系统等。
