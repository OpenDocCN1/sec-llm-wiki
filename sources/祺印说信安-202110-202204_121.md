#### **PseudoManuscrypt 恶意软件被用来针对工业系统展开大规模间谍攻击**

  

**事件概述：**

近日，卡巴斯基发表报告指出 PseudoManuscrypt 新型恶意软件针对工业系统展开大规模攻击。PseudoManuscrypt 恶意软件是卡巴斯基研究人员于今年6月份首次发现的新型恶意软件，主要针对工业、能源、建筑等行业，其受害者主要集中于俄罗斯、印度、巴西、越南和印度尼西亚等地区。

  

**谁是 PseudoManuscrypt？** 

虽然该攻击活动与已知的 Manuscrypt 活动之间存在一些相似之处，但研究人员分析后尚未确定对新的攻击者，故将其命名为 PseudoManuscrypt。该恶意软件实则是一个名副其实的间谍软件，具备记录按键信息、收集有关已建立的 VPN 连接和保存的密码信息，窃取剪贴板内容，使用内置麦克风（如果计算机有麦克风）录制声音并捕获图像。并且该恶意软件的一种变体还可以窃取 QQ 和微信应用程序的凭据，捕获屏幕图像并具有尝试禁用安全解决方案的功能，然后将收集到的数据发送到攻击者的服务器。

  

**如何感染系统？**

PseudoManuscrypt 加载程序通过大量其他恶意文件的安装和创建许多不同进程的复杂链进入用户系统。这些链是多种多样的，但它们都是从伪造的盗版软件安装程序档案开始的。【来源】https://mp.weixin.qq.com

**谷歌商店 Color Message 应用程序被曝存在 Joker 恶意软件**

**  

#### **事件概述：**

#### 继谷歌商店多款应用程序被曝存在恶意软件后，谷歌商店应用程序 Color Message 于近日又被曝出存在恶意软件 Joker，这已不是 Joker 恶意软件首次出现在谷歌商店的应用程序中。最新曝出的这次 Joker 恶意软件是隐藏在名为 Color Message 的移动应用程序中，该款应用程序在从谷歌商店下架之前被下载了超过 500,000 次。研究人员以此还警告用户应该立即从他们的设备中删除 Color Message 以避免付费欺诈。

  

#### **技术详情：**

#### Joker 是一个持续存在的威胁，自2017年以来一直存在，通常将自己隐藏在看似合法的常见应用程序类型中，如游戏、信息、照片编辑器、翻译器和壁纸等应用程序。当受害者一旦安装包含 Joker 恶意软件的应用程序后，恶意软件便会操作受害者订阅由攻击者控制的且受害者不需要的付费高级服务。通常这种付费欺诈在受害者收到移动账单之前受害者是并不知情的。
