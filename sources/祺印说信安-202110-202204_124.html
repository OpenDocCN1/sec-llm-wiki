数字技术与乌克兰战争

以下是来自微软官方网站，最新有关微软总裁对数字技术与乌克兰战争的解读，因欧美对事件解读往往存在严重双标，在阅读时请谨慎选取：

我们所有在微软工作的人都在密切关注对乌克兰的悲惨、非法和无理入侵。这已成为一场动态战争和数字战争，来自乌克兰各地的可怕图像以及对计算机网络的不太明显的网络攻击和基于互联网的虚假宣传活动。我们正在处理越来越多的关于这些方面和我们工作的询问，因此我们在此博客中将关于它们的简短摘要放在一个地方。这包括四个方面：保护乌克兰免受网络攻击；防止国家赞助的虚假宣传活动；支持人道主义援助；以及对我们员工的保护。
首先，重要的是要注意我们是一家公司，而不是政府或国家。在这种情况下，与政府部门协商对我们来说尤为重要，在这种情况下，我们的努力涉及与乌克兰政府以及欧盟、欧洲国家、美国的持续密切协调政府、北约和联合国。

防止网络攻击
作为一家公司，我们的一项主要和全球责任是帮助保护政府和国家免受网络攻击。过去一周在乌克兰，这一角色从未像现在这样重要，乌克兰政府和许多其他组织和个人都是我们的客户。
在 2 月 24 日发射导弹或坦克移动前几个小时，微软的威胁情报中心 (MSTIC) 检测到针对乌克兰数字基础设施的新一轮进攻性和破坏性网络攻击。我们立即向乌克兰政府通报了这一情况，包括我们发现使用了一种新的恶意软件包（我们将其命名为 FoxBlade），并就防止恶意软件得逞的步骤提供了技术建议。（在此发现后的三个小时内，检测此新漏洞的签名已写入并添加到我们的 Defender 反恶意软件服务中，有助于防御此新威胁。）最近几天，我们向乌克兰人提供了威胁情报和防御建议官员关于对一系列目标的袭击，包括乌克兰军事机构和制造商以及其他几个乌克兰政府机构。这项工作正在进行中。
这些最近和持续的网络攻击已经成为目标，我们没有看到在 2017 年 NotPetya 攻击中使用了遍布乌克兰经济和境外的不分青红皂白的恶意软件技术。但我们仍然特别关注最近对乌克兰民用数字目标的网络攻击，包括金融部门、农业部门、应急响应服务、人道主义援助工作以及能源部门组织和企业。根据《日内瓦公约》，这些针对平民目标的袭击引起了严重关切，我们已与乌克兰政府分享了有关这些袭击的信息。我们还向乌克兰政府提供了有关最近网络窃取大量数据的建议，包括健康、保险和与交通有关的个人身份信息 (PII)，
我们还继续与欧洲的北约官员和华盛顿的美国官员分享适当的信息。所有这一切都建立在我们最近几周和几个月的工作之上，以解决针对乌克兰目标的不断升级的网络活动，包括我们之前公开讨论过的新型破坏性恶意软件。当我们发现需要与全球安全社区共享的新恶意软件时，我们将继续公开共享更详细的信息。我们还将继续不断更新 Microsoft 的所有服务，包括我们的反恶意软件 Defender 服务，以帮助防止恶意软件向其他客户和国家/地区的任何潜在传播。我们正在进行更广泛的网络攻击监测工作，我们将继续向乌克兰网络防御官员提供建议并协助他们进行防御。

防止国家赞助的虚假信息

作为一家公司，我们还专注于防止国家赞助的虚假信息活动，这些活动在战争时期早已司空见惯。在过去的几天里，在信息生态系统中，动能战伴随着一场精心策划的战斗，其中弹药是虚假信息，破坏真相并播下不和谐和不信任的种子。这需要整个科技行业做出果断的努力——无论是公司个人还是与其他人合作——以及政府、学术界和民间社会。
我们正在迅速采取新措施，减少俄罗斯国家宣传的曝光度，并确保我们自己的平台不会无意中为这些行动提供资金。根据欧盟最近的决定，Microsoft Start 平台（包括 MSN.com）将不会显示任何国家赞助的 RT 和 Sputnik 内容。我们正在从我们的 Windows 应用程序商店中删除 RT 新闻应用程序，并进一步降低这些网站在 Bing 上的搜索结果的排名，以便它仅在用户明确打算导航到这些页面时返回 RT 和 Sputnik 链接。最后，我们在我们的广告网络中禁止来自 RT 和 Sputnik 的所有广告，并且不会在这些网站上放置来自我们广告网络的任何广告。
我们将继续密切监视事件，并将进行持续调整以加强我们的检测和破坏机制，以避免虚假信息的传播，并改为推广独立和受信任的内容。

支持人道主义援助

所有战争的悲惨后果之一是对平民的影响，包括在原地避难的个人和家庭以及逃离其他地方寻求安全的流离失所者。乌克兰最近几天向世界提供了一个明显的提醒，即我们在全球范围内努力帮助解决世界各地冲突地区的人类影响。我们的 Microsoft 慈善事业和联合国事务团队与红十字国际委员会 (ICRC) 和多个联合国机构密切合作，我们迅速采取行动，调动我们的资源来帮助乌克兰人民。
我们致力于利用我们的技术、技能、资源和声音来协助人道主义响应工作。我们最初和当前的重点一直是支持红十字国际委员会等人道组织，这些组织正在开展关键工作，帮助支持逃往邻国的难民。我们还启动了 Microsoft 灾难响应团队以提供技术支持，他们经常与其他第一响应者联系以提供帮助。
我们还利用微软业务的其他部分来帮助公众寻找和支持人道主义组织。再一次，我们也鼓励并看到我们在美国、欧洲和世界各地的员工通过微软的员工捐赠计划慷慨解囊。员工捐款以及微软的配套捐款目前主要用于帮助为一线的非营利组织提供资金，包括红十字国际委员会、联合国儿童基金会和波兰人道主义协会。在接下来的几天和几周内，我们将继续在整个公司范围内动员必要的额外资源。

员工保护

微软的员工遍布世界各地，包括乌克兰、俄罗斯和东欧。我们还有许多乌克兰和俄罗斯血统的员工在许多其他地方工作，包括西欧和美国。
正如我们在最近的其他冲突中所看到的那样，我们在员工身上看到了一种跨越国界的共同纽带和人道主义精神，渴望和平，关心彼此的福祉，无论他们出生在哪个国家或持有何种护照。每一小时都在提醒人们，最黑暗的日子也可以激发人们最好的一面，无论是通过雄心勃勃的努力来防止广泛的网络攻击，还是一个人询问他们可以做些什么来帮助另一个人的一个小小的善意姿态。
与其他跨国公司一样，微软致力于保护其员工。这对我们在乌克兰的员工来说显然具有至关重要的意义，其中包括我们的团队为帮助我们的员工和家人（包括那些需要逃离生命或安全的人）所做的持续和非凡的努力。它还包括我们在俄罗斯本身的员工，他们没有发动这场战争，也不应该因为雇主保护他人的行为或不受他们控制的政府的决定而冒着在国内或国外受到歧视的风险。我们还继续密切关注对更广泛地区的员工的支持，我们正在密切关注那里的情况。作为一家公司，我们始终致力于为每个国家/地区的员工提供安全保护，
展望未来，数字技术显然将在战争与和平中发挥至关重要的作用。像许多其他人一样，我们呼吁恢复和平、尊重乌克兰的主权和保护其人民。我们不仅期待而且将为未来使用数字技术来保护国家和人民而努力，帮助我们所有人发挥彼此的最佳状态。


原作者：布拉德史密斯 - 总裁兼副主席
