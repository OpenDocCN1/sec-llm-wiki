# 伊朗 MuddyWater 黑客组织在全球网络攻击中使用新的恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652092178&idx=2&sn=7d1819431add8810d4c76465b8c78ee3&chksm=8bbc9d2bbccb143d03f55c1a922c9bb5645a2a6cc6ae385576b96fdca189431ed3389af15a9a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652092178&idx=2&sn=7d1819431add8810d4c76465b8c78ee3&chksm=8bbc9d2bbccb143d03f55c1a922c9bb5645a2a6cc6ae385576b96fdca189431ed3389af15a9a&scene=27#wechat_redirect)

俄乌之间的炮火与网络战如火如荼的开展中，俄乌两国网络战也在紧锣密鼓中展开，不过西方媒体好像在这么大好时光里，也没有减少对伊朗的关注。同时，也对朝鲜关注度不减，美国舰队在中国台湾海峡继续向台湾传递错误信息。

![](../Images/2d00c607a0b4368121e750a0ae0f5d2b.png)

英国和美国的网络安全机构揭露伊朗政府资助的高级持续威胁 (APT) 组织在针对全球政府和商业网络的攻击中使用的一种新恶意软件。两国安全机构透露MuddyWater 参与者是向伊朗政府提供被盗数据和访问权限，并与其他恶意网络参与者共享这些数据。此次的联合咨询由美国联邦调查局 (FBI)、美国网络安全和基础设施安全局 (CISA)、美国网络司令部网络国家任务部队 (CNMF) 和英国国家网络安全中心 (NCSC) 共同提供。他们认为作为伊朗情报和安全部 (MOIS) 的一部分，这名网络间谍行动者今年被揭露为针对广泛的政府和私营部门组织的恶意行动，包括电信、国防、地方政府以及石油和天然气部门，在亚洲、非洲、欧洲和北美。

MuddyWater 被更广泛的网络安全社区以 Earth Vetala、MERCURY、Static Kitten、Seedworm 和 TEMP.Zagros 的名义追踪，从大约 2018 年开始以支持 MOIS 目标的网络攻势而闻名。除了利用公开报告的漏洞之外，历史上还观察到黑客团体使用开源工具来访问敏感数据、部署勒索软件并在受害者网络上实现持久性。

情报当局揭露的新活动没有什么不同，因为利用混淆的 PowerShell 脚本来隐藏攻击中最具破坏性的部分，包括命令和控制 (C2) 功能。

入侵是通过鱼叉式网络钓鱼活动来促进的，该活动试图诱使其目标下载可疑的 ZIP 档案，这些档案要么包含带有与攻击者的 C2 服务器通信的恶意宏的 Excel 文件，要么包含将恶意负载发送给受感染者的 PDF 文件系统。此外，该组织使用多个恶意软件集——包括 PowGoop、Small Sieve、Canopy/Starwhale、Mori 和 POWERSTATS——来加载恶意软件、后门访问、持久性和渗透。

虽然 PowGoop 充当负责下载第二阶段 PowerShell 脚本的加载器，但 Small Sieve 被描述为基于 Python 的植入物，用于通过利用 Telegram API 进行 C2 通信来逃避检测，从而在网络中保持立足点。其他关键恶意软件包括 Canopy，一个 Windows 脚本文件 (.WSF)，用于收集系统元数据并将其传输到攻击者控制的 IP 地址，以及两个名为 Mori 和 POWERSTATS 的后门，用于运行从 C2 接收的命令并维护持久访问。

MuddyWater 使用的工具库是一个调查脚本，用于枚举有关受害计算机的信息并将其传输回远程 C2 服务器。还部署了一个新发现的 PowerShell 后门，用于执行从攻击者收到的命令。

为了为潜在的攻击创造障碍，这些机构建议组织在适用的情况下使用多因素身份验证，限制管理员权限的使用，实施网络钓鱼保护，并优先修补已知的被利用漏洞。
