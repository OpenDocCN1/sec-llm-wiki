如何选择这些 CPU 的？

如果不知道正确的术语，购买游戏 CPU 可能会让人不知所措。CPU 有自己的语言，这常常会让新手用户感到困惑。应该考虑的一些因素，以帮助找到适合需要的 CPU 型号。

  • 制造商：为了获得更好的可靠性，请考虑谁制造了您的 CPU。AMD 和英特尔都是领先的 CPU 制造商，它们都在我们的榜单中占据主导地位。 

  • 发布日期：技术快速且不断发展，因此更新的模型可能会提供功能。当然，可能会为此付出更高的价格。

  • 代系：代系的类型可以告诉 CPU 使用哪种编程和处理器。

  • 核心：CPU 核心数代表速度，同时处理多个不同指令的核心。今天的 CPU 通常使用多个内核来获得更高的性能。

  • 时钟速度：也称为时钟速率或频率，时钟速度显示 CPU 每秒可以执行多少个周期。它以千兆赫 (GHz) 为单位进行测量。 

  • 超频：超频可提高 CPU 的时钟速度。例如， 英特尔® Performance Maximizer 是实现更高性能超频的主要方法之一。

  • 集成显卡：为了获得更好的成像效果，请考虑 CPU 是否提供集成显卡。如果打算编辑和流式传输视频，这一点尤其重要。

在 2022 年找到最适合游戏的 CPU 的另一个好方法是查看打算玩哪些 PC 游戏。这些规格有助于确保购买适合个人需求的正确 CPU。
