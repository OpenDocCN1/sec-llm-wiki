# 顶尖级黑客大赛PWN2OWN 2022年温哥华赛事计划安排

据ZDI官网介绍，自2007 年始，Pwn2Own 已经从一个以浏览器为中心的小型活动发展成为业内最知名的安全竞赛之一。当时，一个成功的漏洞利用为获胜者赢得了一台 MacBook 和 10,000 美元。去年，ZDI 在全球 Pwn2Own 比赛中为参赛者发放超过 250 万美元的奖金（外加一大堆硬件）。2022 年是比赛的 15 周年，他们已着手将其打造成有史以来最好的比赛。

报道称首先，将于2022 年 5 月 18 日至 20 日亲自返回温哥华喜来登墙中心参加CanSecWest会议。仍将允许远程参与此混合活动。如果有旅行限制或旅行安全问题，可以选择远程竞争。需要在比赛注册截止日期（2022 年 5 月 12 日）之前进行注册，并提交一份详细的白皮书，完整地解释漏洞利用链以及如何运行该条目的说明。温哥华的 ZDI 工作人员将为运行提交的漏洞利用程序。

![](../Images/7096132410d225d8361282216643b24d.png)

接下来，特斯拉作为合作伙伴回归，但今年驾驶新车将更具挑战性。将有一辆特斯拉 Model 3和一辆特斯拉 Model S 作为目标。当然，更大的挑战会带来丰厚回报，最高奖金为 600,000 美元（加上汽车本身）。今年的其他合作伙伴包括Zoom和微软。在去年的活动中，Zoom 和 Teams 漏洞利用是亮点，并且都作为企业通信类别的目标返回。当然，虚拟化漏洞利用始终是比赛的亮点，VMware作为赞助商回归，VMware Workstation 和 ESXi 作为目标回归。

除了比赛中亲自尝试之外，还将在 Twitch、YouTube 等平台上直播精选尝试。参赛者将能够远程参加几乎所有类别的比赛。总而言之，包括特斯拉 Model 3 在内的参赛者可以获得以下类别的超过 1,000,000 美元的现金和奖品：

**\-- 虚拟化类****\-- Web 浏览器类****\-- 企业应用程序类****\-- 服务器类****\-- 本地权限升级类****\-- 企业通信类****\-- 汽车类**当然，如果没有为 Pwn 大师加冕，任何 Pwn2Own 比赛都不完整。由于比赛的顺序是由随机抽签决定的，因此抽签失败的参赛者仍然可以展示出色的研究成果，但由于后续轮次的价值下降，因此获得的奖金较少。但是，每次成功参赛所获得的积分不会减少。有人可能有一个糟糕的平局，但仍然积累了最多的分数。比赛结束时得分最高的人或团队将被加冕为 Pwn 大师，获得 65,000 ZDI 奖励积分（即时白金身份）、杀手奖杯和 漂亮的时髦夹克 。**让我们来看看今年比赛的规则细节。*****虚拟化类别***ZDI对 VMware 作为 2022 年的 Pwn2Own 赞助商回归表示非常高兴。今年，他们将再次将 VMware ESXi 和 VMware Workstation 作为目标，分别设150,000 美元和 75,000 美元的奖励。VMware 多年来一直是 Pwn2Own 的赞助商，在过去几年的比赛中看到了一些出色的研究成果。Microsoft 作为 2022 年的目标回归，并以 250,000 美元的奖金引领虚拟化类别，奖励成功的 Hyper-V 客户端来宾到主机提权。Oracle VirtualBox 以 40,000 美元的奖金完成了这一类别。在之前的 Pwn2Own 竞赛中，已经看到了一些令人惊叹的客户机到主机操作系统提权。希望今年我们能看到更多精彩呈现。此类别中还有一个附加奖金。如果参赛者能够逃脱来宾操作系统，然后通过 Windows 内核漏洞（不包括 VMware ESXi）提权主机操作系统的权限，可以获得额外的 50,000 美元和 5 个 Pwn 大师积分。这可能会将 Hyper-V 漏洞的支出推高至 300,000 美元。以下是虚拟化类别中目标和可用支出的详细介绍：![](../Images/dc2d73ee7e34a6ebbbc231b2a8752602.png)***网络浏览器类别***虽然浏览器是“传统”的 Pwn2Own 目标，但在不断调整此类别中的目标以确保其保持相关性。对于今年的活动，成功的演示不再需要沙盒逃生。仅渲染器的攻击将获得 50,000 美元，但如果有 Windows 内核特权升级或沙盒逃逸，则将分别为参赛者赚取高达 100,000 美元或 150,000 美元。如果漏洞利用在*两者上都有效*Chrome 和 Edge，将有资格获得 25,000 美元的“双击”附加功能。基于 Windows 的目标将在 VMware Workstation 虚拟机中运行。因此，所有浏览器（Safari 除外）都有资格使用 VMware 转义插件。如果参赛者可以通过逃逸 VMware Workstation 虚拟机以在主机操作系统上执行代码的方式破坏浏览器，他们将额外获得 75,000 美元和 8 个 Pwn 大师积分。以下是目标和可用支出的详细信息：![](../Images/af130f6a30b2135483423b4c4ece04dc.png)***企业应用类别***企业应用程序也作为目标返回，Adobe Reader 和目标列表中的各种 Office 组件再次出现。此类奖项的奖金为 50,000 美元（用于沙盒逃逸的 Reader 漏洞或具有 Windows 内核权限升级的 Reader 漏洞）和 Office 365 应用程序的 100,000 美元。Word、Excel 和 PowerPoint 都是有效的目标。基于 Microsoft Office 的目标将启用受保护的视图。Adobe Reader ProxyShell。这两个目标都返回了今年的竞赛，SharePoint 获得了更大的回报。还在今年的活动中添加了 Samba。此类别由 Microsoft Windows RDP/RDS 完成，其支出也为 200,000 美元。以下是服务器类别中目标和支出的详细介绍：![](../Images/35d76a5caed40101709d6c37e1eec0b0.png)***本地特权升级类别***此类别是 Pwn2Own 的经典，侧重于源自标准用户并导致以高权限用户身份执行代码的攻击。此类别中的成功条目必须利用内核漏洞来提升权限。Ubuntu Desktop 和 Microsoft Windows 11 是该类别中可用作目标的两个操作系统。![](../Images/d94bc00d198b7d1e0c58a2563a6f1924.png)***企业通讯类***去年推出了这一类别，以反映这些工具在现代远程员工队伍中的重要性， Zoom 作为今年 Pwn2Own 活动的合作伙伴回归。此类别中的成功尝试必须通过与参赛者通信来破坏目标应用程序。示例通信请求可以是音频呼叫、视频会议或消息。Zoom 和 Microsoft Teams 都有 150,000 美元的奖金，因此希望在这一类别中看到更多出色的研究。
