律师、会计师注意了！GootLoader 黑客正在针对法律和会计师事务所的员工

GootLoader Gang 发起广泛网络攻击，诱使法律和会计员工下载恶意软件

据国外安全机构eSentire信息，其威胁猎手已经拦截并关闭了GootLoader Gang 针对三家律师事务所和一家会计师事务所发起的网络攻击，据其分析GootLoader 黑客组织是攻击的幕后黑手。GootLoader 是一种隐蔽的初始访问恶意软件，在进入受害者的计算机系统后，用勒索软件或其他致命的恶意软件感染系统。注意：在执法部门关闭其运营商之前，GootLoader 在传播 REvil（又名 Sodinokibi 或 Sodin 勒索软件）方面有着丰富的历史。

员工必须记住的格言：“没有免费的午餐或免费的商业协议”

GootLoader 通过由搜索引擎优化推动的 Drive-By-Download 活动传播，特别是通过 Google。在当前的这些攻击中，与之前的 GootLoader 活动一样，黑客正在引诱商业专业人士访问合法但受到损害的网站，这些网站已填充了数百页内容，其中包括对商业协议的大量引用，包括法律和财务协议。该内容旨在提供这些文档的免费样本以供下载。事实上，在去年 12 月发起的广泛的GootLoader 活动中，发现 GootLoader 黑客站了超过 100,000 多个恶意网页，宣传不同类型的商业协议。在一个案例中，其中一个受感染的网站托管了 150 页的黑客内容。 


GootLoader 帮派已经确定了数十个使用 WordPress 作为其内容管理系统的合法网站。与许多内容管理系统一样，WordPress 有许多漏洞，黑客很容易利用这些漏洞并在这些网站上填充他们想要的任意数量的恶意页面，而所有这些都是在网站所有者不知情的情况下进行的。这些网站涵盖了广泛的行业，包括：酒店、高端零售、教育、医疗保健、音乐和视觉艺术等。

随着内容量的增加，威胁行为者已经涌入网络，当专业人士进入谷歌搜索商业协议样本时，黑客的恶意网页出现在谷歌搜索的热门搜索中，当计算机用户导航到这些恶意网页之一并点击链接以下载所谓的商业协议时，他们在不知不觉中下载了 GootLoader。因此，除非组织有适当的安全保护措施，否则组织很可能感染了 GootLoader，这可能导致勒索软件部署，然后游戏就结束了。


一旦感染了 GootLoader，典型的目标就是将勒索软件或 Cobalt Strike 下载到受害者的计算机上，Cobalt Strike 是一个功能齐全的入侵套件。起源于一个合法的远程访问工具，为红队开发用于渗透测试。在过去的一年中，已成为网络犯罪分子将立足点（例如 GootLoader 提供的）转变为动手入侵的主要手段。毫无疑问，它已成为网络犯罪分子“武器库”中最喜欢的工具之一。Cobalt Strike 套件包括运行网络入侵所需的一切，从初始访问（例如将 Cobalt Beacon 嵌入文档和漏洞利用）到横向移动（将凭据窃取程序注入合法的 Windows 进程、滥用共享、并利用 PsExec 和 PowerShell 等管理工具）。此外，Cobalt Strike 是高度可定制的——可以更改设置以伪装命令和控制 (C2) 流量和注入目标，以避免被发现。

保护自己的公司和员工免受 GootLoader 的侵害

GootLoader 黑客诱捕他们的受害者，因为他们欺骗他们从 Web 下载文档。因此，公司可以针对 GootLoader 实施的最重要的防御措施之一是对其员工进行安全意识培训。

  • 公司必须让员工了解 GootLoader 的风险，以及更广泛地说，使用搜索引擎发现免费文档模板所涉及的安全风险

  • 员工需要确保他们可以信任文档来源。即使是来自 Internet 的合法 Word 和 Excel 文档也可能导致恶意软件

    ！警惕从未知来源发送或从 Internet 获取的提示“启用宏”的 Word 和 Excel 文档

  • 员工需要确保下载的内容是他们打算下载的内容。如果一个人从 Internet 下载了一份文档，但他们得到了一个 JavaScript 文件，那么不应该打开它。应该上报给内部 IT 安全团队

  • 确保制定标准程序，让员工提交潜在的恶意内容以供审查

  • 使用 Windows 攻击面减少规则阻止 JavaScript 和 VBScript 表单启动下载的内容

  • 使用端点检测和响应 (EDR) 产品

留意 GootLoader 的妥协指标 (IOC) 和作案手法 (MO)

对于公司的安全团队来说，快速识别和修复其环境中的 GootLoader 感染以防止后续攻击和部署更具破坏性的恶意软件（如勒索软件或 Cobalt Strike）至关重要，了解黑客组织的典型 MO，例如：感染过程及其 IOC 是识别和关闭 GootLoader 攻击的关键。

GootLoader的典型感染过程：

  1. 用户对文档或文档模板执行 Web 搜索

  2. 用户点击搜索结果导致 GootLoader 登陆页面

  3. 登陆页面显示一个虚假的网络论坛并链接到所请求的文档

  4. 用户点击显示的链接，收到一个 Zip 存档

  5. 用户打开存档，找到伪装成请求文档的 JavaScript 文件（.js 扩展名）

  6. 用户通过双击执行 JavaScript 文件

  7. Windows 使用 Windows 脚本宿主进程执行 JavaScript 文件，从而导致执行 GootLoader 恶意软件
