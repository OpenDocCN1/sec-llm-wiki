# 网络安全知识之减少垃圾邮件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652091624&idx=1&sn=e57478599c0485c8af9b0bee84f26101&chksm=8bbc9ed1bccb17c7c4e985d2aa13a34371d51d266b17bb652562139d37504396d234bc54f295&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652091624&idx=1&sn=e57478599c0485c8af9b0bee84f26101&chksm=8bbc9ed1bccb17c7c4e985d2aa13a34371d51d266b17bb652562139d37504396d234bc54f295&scene=27#wechat_redirect)

**什么是垃圾邮件？**

垃圾邮件是“垃圾邮件”的电子版本。垃圾邮件一词是指未经请求的、通常是不需要的电子邮件。垃圾邮件不一定包含病毒——来自合法来源的有效邮件可能属于这一类。

**如何减少垃圾邮件的数量？**

·     **在发布电子邮件地址时要小心。**在通过网络、口头或书面回复任何对电子邮件地址的请求之前，请三思。垃圾邮件发送者可以收集发布在网站上的任何电子邮件地址。如果将电子邮件地址提供给公司，该信息通常会输入到数据库中，以便可以跟踪客户信息和偏好。如果这些电子邮件数据库被出售给其他公司或与其他公司共享，可能会收到没有要求的电子邮件。

·     **检查隐私政策。**在在线提交电子邮件地址之前，请查看隐私政策。大多数信誉良好的网站都会以要求提交个人数据的任何形式提供指向其隐私政策的链接。在提交电子邮件地址或任何其他个人信息之前，应该阅读本政策，以便了解网站所有者计划如何处理这些信息。

·     **请注意默认选择的选项。**当注册某些在线账户或服务时，可能会有一个部分提供接收有关其他产品和服务的电子邮件的选项。有时默认情况下会选择一些选项，因此如果不取消选择它们，也可能会开始接收来自这些列表的电子邮件。

·     **使用过滤器** **或垃圾邮件标记。**许多电子邮件程序提供过滤功能，允许阻止某些地址或仅允许来自联系人列表中地址的电子邮件。许多 Internet 服务提供商 (ISP) 还提供垃圾邮件标记服务，允许用户选择在删除可疑垃圾邮件之前查看它们。垃圾邮件标记与许多电子邮件程序提供的过滤功能结合使用非常有用。

·     **将邮件报告为垃圾邮件。**大多数电子邮件客户端都提供将邮件报告为垃圾邮件或垃圾邮件的选项。如果电子邮件客户端有该选项，请利用它。将邮件报告为垃圾邮件有助于训练邮件过滤器，使邮件不会发送到收件箱。但是，请定期检查垃圾邮件或垃圾邮件文件夹，以查找被错误归类为垃圾邮件的合法邮件。

·     **不要点击垃圾邮件中的链接。**一些垃圾邮件依赖于在特定域尝试不同电子邮件地址的生成器。如果单击电子邮件中的链接或回复某个地址，只是在确认电子邮件地址有效。提供“取消订阅”选项的垃圾邮件特别诱人，但这通常只是一种收集有效地址的方法，然后将这些地址作为其他垃圾邮件的目标。

·     **禁用 HTML 邮件中图形的自动下载。**许多垃圾邮件发送者发送带有链接图形文件的 HTML 邮件，然后用于跟踪谁打开了邮件消息。当邮件客户端从其 Web 服务器下载图形时，垃圾邮件发送者就知道我们已打开邮件。完全禁用 HTML 邮件并以纯文本查看邮件也可以防止出现此问题。

·     **考虑开设一个额外的电子邮件账户。**许多域提供免费的电子邮件账户。如果经常提交电子邮件地址（用于在线购物、注册服务或将其包含在评论卡之类的东西中），可能需要一个辅助电子邮件账户来保护主电子邮件账户免受可能生成的任何垃圾邮件，也可以在向公共邮件列表、社交网站、博客和网络论坛发帖时使用此辅助账户。如果账户开始被垃圾邮件填满，可以摆脱它并打开另一个账户。

·     **在社交网站上使用隐私设置。**社交网站通常允许选择谁有权查看电子邮件地址。考虑隐藏电子邮件账户或更改设置，以便只有信任的一小部分人能够看到地址。请注意，当在这些网站上使用应用程序时，可能会授予他们访问个人信息的权限。因此，请谨慎选择使用哪些应用程序。

·     **不要向其他人发送垃圾邮件。**做一个负责任和体贴的用户。有些人认为电子邮件转发是一种垃圾邮件，因此重新分发的邮件要有所选择。不要将每条消息都转发给地址簿中的每个人，如果收件人要求不要向他们转发消息，请尊重他们的要求。
