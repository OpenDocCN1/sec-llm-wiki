# 网络安全知识之了解 ISP

**什么是ISP？**

ISP 或 Internet 服务提供商是一家为其客户提供 Internet 和其他 Web 服务访问权限的公司。除了保持与互联网的直接联系外，这些公司通常还维护网络服务器。通过提供必要的软件、受密码保护的用户账户和连接到互联网的方式（例如调制解调器），ISP 为其客户提供了浏览网络和与其他人交换电子邮件的能力。一些 ISP 还提供附加服务。随着智能手机的发展，很多手机厂商也是ISP。

ISP 的规模各不相同——有些是由一个人运营的，而有些则是大公司。它们的范围也可能不同——一些只支持特定城市的用户，而另一些则具有区域或国家能力。

**ISP****提供哪些服务？**

几乎所有 ISP 都提供电子邮件和网页浏览功能，还提供不同程度的用户支持，通常采用电子邮件地址或客户支持热线的形式。大多数 ISP 还提供网络托管功能，允许用户创建和维护个人网页；有些甚至可以提供页面开发服务。一些 ISP 将 Internet 服务与其他服务（例如电视和电话服务）捆绑在一起。许多 ISP 提供无线调制解调器作为其服务的一部分，以便客户可以使用配备 Wi-Fi 的设备。

![](../Images/e94023dcac7953de11aec6ce395b7ff2.png)

  

作为正常操作的一部分，大多数 ISP 会备份电子邮件和 Web 文件。如果恢复电子邮件和 Web 文件的能力很重要，需要咨询 ISP，看看是否备份了数据；它可能不会被宣传为一项服务。此外，大多数 ISP 实施防火墙来阻止传入流量的某些部分，尽管应该将其视为自己的安全预防措施的补充，而不是替代。

**如何选择ISP？**

传统的宽带 ISP 通常通过电缆、DSL 或光纤选项提供互联网访问。这些选项的可用性可能取决于居住的地方。除了访问类型之外，可能还需要考虑其他因素：

*   **安全**——你觉得ISP关心安全吗？它是否使用加密和 SSL来保护提交的任何信息（例如，用户名、密码）？如果 ISP 提供无线调制解调器，它支持哪些无线安全标准，这些标准是否与自己现有的设备兼容？
    
*   **隐私** - ISP 是否发布了隐私政策？是否对谁可以访问信息以及这些信息的处理和使用方式感到满意？
    
*   **服务** - ISP 是否提供自己想要的服务？它们符合要求吗？是否有足够的服务支持？如果 ISP 提供无线调制解调器，其无线标准是否与现有的设备兼容？
    
*   **成本** - ISP 的成本是否负担得起？它们对于接受的服务数量以及这些服务的水平是否合理？是否会牺牲质量和安全性来获得最低的价格？
    
*   **可靠性** - ISP 提供的服务是否可靠，或者由于维护、安全问题、大量用户或其他原因而经常无法使用？如果 ISP 知道由于特定原因服务将不可用，它是否充分传达了该信息？
    
*   **用户支持** - 是否有已发布的联系客户支持的方法？你得到及时和友好的服务吗？他们的可用时间是否满足需求？顾问是否具备适当的知识水平？
    
*   速度 - ISP 连接速度有多快？是否足以访问电子邮件或浏览互联网？
    
*   建议 - 否听说过或看到了有关 ISP 的正面评价？它们是否来自可信赖的来源？ISP 是否为所在的地理区域提供服务？如果发现了负面因素，它们是否是担心的因素？
