# 英国新国家网络战略将中俄视为“战略竞争对手”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652091459&idx=3&sn=c6723ba67777660b7576bc0849048705&chksm=8bbc9e7abccb176cfbf2c0f89f0b86f2e764b7b758bb89d7aa7facbca332e8e495cd248bc312&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652091459&idx=3&sn=c6723ba67777660b7576bc0849048705&chksm=8bbc9e7abccb176cfbf2c0f89f0b86f2e764b7b758bb89d7aa7facbca332e8e495cd248bc312&scene=27#wechat_redirect)

## 

本期关键词：英国 国家战略 网络空间

  
在网络空间领域制造对立、抹黑中国和俄罗斯等国家似乎成了美国盟友的“政治正确”。2021年9月，美国的“死忠跟班”日本政府审议通过适用于未来三年的《网络安全战略》，首次点名中俄朝为网络安全威胁。美国的 “铁杆兄弟”英国政府2021年12月15日发布了《网络战略2022---与全英国共同开创网络未来》报告（以下简称“新战略”），将中国和俄罗斯视为其网络空间的“战略竞争对手”，认为英国需与中国和俄罗斯竞争在网络世界的主导权，以维持一个基于开放社会制度的网络。该战略甚至认为中国是英国未来十年在网络安全领域的主要“驱动力”。对于点名抹黑中俄的原因，除了“遭到中俄网络攻击”这一例行的悲情戏码，英国在此次发布的新战略中终于道出了实情：“英国与中俄在网络空间的矛盾是价值观之争。”  
  
![](../Images/fa7a5bdfaf2fe48932cd9e2f7ab532ca.png)（《网络战略2022---与全英国共同开创网络未来》封面 下文图片均来自该报告）  

## 

新战略概要

  
新战略由英国国家网络安全中心（National Cyber Security Centre）撰写，建立在2016年发布的《国家网络安全战略2016---2021》基础上。新战略全文长达130页，比2011年和2016年发表的同系列文件分别长90页和50页。之前两份文件的题目都使用“网络安全战略”（Cyber security strategy）一词，但新文件就只用“网络战略”一词，显示其关注点已不仅仅在网络安全上，而是扩大到整个互联网的运作主导权。新战略核心内容包括“战略”和“实施”两部分。“实施”部分提出了5个支柱和7类重点发展的关键技术，并列出了2025年底前英国将在每个支柱下采取的具体行动。  
英国杜伦大学（Durham University）网络领域学者德怀尔（Andrew Dwyer）指出，英国的新网络战略显示出一种重新转向，表明处理系统性竞争是英国安全的重要部分，以及只依赖现有的“威慑”（deterrence）策略并不足够。德怀尔称，继今年初英国发表一份名为“综合评估”（Integrated Review）的国策之后，新网络战略继续强调将注意力放在印太地区，并从“社会整体”的角度来考虑国家安全，即不只是关注网络攻击，其他与网络有关的事宜亦同样重要，例如投资方面和科技标准，其目标是令英国成为一个科技大国。

## 

新战略称英国与中俄在网络空间的对立是理念之争

  
除了“遭到中俄网络攻击”这一例行的悲情戏码，英国这一次破天荒道出了实情：“英国与中俄在网络空间的矛盾是价值观之争”---这反映出英国人思考和处理网络空间国际关系的出发点仍然基于他们根深蒂固的冷战思维。  
新战略指出，中俄是英国在网络空间领域的主要威胁，甚至把中国抬高到英国未来十年在网络安全领域加大投入的主要驱动力。新战略称，“2021年，英国继续与全球合作伙伴协作，以检测和破坏共同威胁，而其中最一致的威胁来自俄罗斯和中国。除了俄罗斯国家构成的直接网络安全威胁外，许多对西方目标发动勒索软件攻击的有组织犯罪团伙都设在俄罗斯，这是显而易见的。中国仍然是网络空间中高度成熟的参与者，其将影响力投射到境外的野心越来越大，并且已证明其对英国的商业机密感兴趣。中国未来十年的发展可能是英国未来网络安全的最大单一驱动力。虽然伊朗和朝鲜不如俄罗斯和中国先进，但其继续使用数字入侵来实现目标，包括盗窃和破坏”。  
英国在新国家网络战略中声称，“关于网络空间管理规则的争论将越来越多地成为大国之间系统性竞争的范畴，希望维护一个以开放社会为基础的体系的国家与中国和俄罗斯等系统性竞争对手之间爆发了价值观冲突”；并指控“中国和俄罗斯正在推动加强国家控制，以此作为保障网络空间安全的唯一途径。这将给自由开放的互联网带来压力，因为民族国家、大型科技公司和其他参与者都在推动相互竞争的技术标准和互联网治理方法”。  
分析人士指出，英国将会更广泛地关注中国与其国家安全有关的行为，并采取更坚定的态度；在未来5年中国将是英国网络议题的焦点，比任何其他国家都更甚。英国或许会在如5G或6G，以及人工智能的关键技术上与合作伙伴统一标准和分享技术，务求赶超中国的科技发展。新成立的英国国家网络部队会干扰被英国认定是损害其利益的中方活动，他们有可能会有针对性地打击中国的网络基础设施。英国国家网络部队在去年成立，由英国多个情报部门抽调人员组成，目的是发动网络攻势，打击敌对国家的恐怖和犯罪分子以及相关行动。  
新战略将“网络力量”定义为“在网络空间和通过网络空间保护和促进国家利益的能力”。该战略认为，英国高度数字化的经济既“特别容易”面临风险，又可能会抓住这个时代带来的机遇，并通过“全社会层面的努力”来解决这一问题，其中一个短期步骤是模仿美国网络安全与基础设施安全局2021年6月成立的网络安全咨询委员会，成立一个国家网络咨询委员会 (NCAB)，将公共和私营部门联合起来。

## 

新战略提出五个支柱和七类关键技术

  

## 五个支柱

  
新战略提出，英国的愿景是在2030年继续成为负责任和民主的网络强国，能够保护和促进英国在网络空间中的利益，并通过网络空间支持国家目标。  
为实现这一愿景，英国将追求五个支柱，即五项战略目标，这构成了指导英国活动的战略框架。新战略的第二部分列出了2025年底前英国将在每个支柱下采取的具体行动。  

支柱1：加强英国网络生态系统，投资英国的科技人员和科技产业，并深化政府、学术界和工业界之间的伙伴关系。

支柱2：建设一个有弹性和繁荣的数字英国，降低网络风险，使企业能够最大限度地利用数字技术的经济效益，保障公民在线安全并确保他们的数据受到保护。

支柱3：在与网络力量密切相关的技术领域处于领先地位，构建英国的工业能力并开发框架以确保未来技术的安全。

支柱4：提升英国的全球领导地位和影响力，以建立更安全、繁荣和开放的国际秩序，与政府和行业合作伙伴协作并分享支撑英国网络力量的专业知识。

支柱5：检测、干扰和威慑英国的对手，以加强英国网络空间和利用网络空间的安全，更加综合性、创造性和常规性地利用英国的全方位杠杆。

  
  

## 七类技术

  
大国战略竞争的核心就是争夺技术优势，特别是争夺新兴和颠覆性技术领域的优势，作为一个没落的强国，英国对此有着别样的感受。新战略指出，一些技术对于塑造网络空间的未来至关重要。能够在这些技术中发挥主导作用的国家将更有能力影响这些技术的设计和部署方式，更有能力保护其安全和经济优势，并可以更快地抓住机会实现网络能力的突破。随着技术成为日益重要的地缘政治力量工具，这一领域的竞争将愈演愈烈。  
对英国而言，通过科技追求战略优势及其所依赖的数据访问，将是实现英国作为网络强国的更广泛目标的先决条件。英国现在需要一种更加野心勃勃和积极主动的方法来维持关键技术的利益，避免过度依赖竞争对手。对网络力量至关重要的技术包括：5G和6G技术，以及其他新兴的数据传输形式；人工智能(AI)，包括保护AI系统安全的需求以及使用AI增强网络监控等广泛应用中的网络安全的潜力；区块链技术及其应用，如加密货币和去中心化金融；半导体、微处理器芯片、微处理器架构及其供应链、设计和制造过程；密码认证，包括身份和访问管理以及高保证密码产品；用于消费者、企业、工业和物理环境（例如连接场所）的物联网和技术；量子技术，包括量子计算、量子传感和后量子密码学，等等。
