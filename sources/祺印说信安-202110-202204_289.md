# 微软2021年12月份于周二补丁日针对 67 个漏洞发布安全补丁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652091429&idx=2&sn=bc2916b5cfa35fec12f154e29734f19c&chksm=8bbc9e1cbccb170a14893eb514e60e2ea7998d3785335e2d94ad373c8670edb5c209e80b1313&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652091429&idx=2&sn=bc2916b5cfa35fec12f154e29734f19c&chksm=8bbc9e1cbccb170a14893eb514e60e2ea7998d3785335e2d94ad373c8670edb5c209e80b1313&scene=27#wechat_redirect)

本月是2021年的最后一个月，因最近有点忙未及时跟踪微软的周二补丁日。其实，只要你是网络安全从业人员，都更加会关注CVE-2021-44228：Log4Shell(Log4j)这个漏洞，它甚至称为史诗级漏洞。国外安全网站，这么去形容它的影响：除非你一直闭着眼睛躲在岩石下，用手捂住耳朵，否则你应该听说过最近披露的 Java 日志库中一个名为Apache Log4j 的漏洞。

该漏洞可以通过记录某个字符串来允许在受影响的应用程序和服务器上远程执行代码。当然，最大的问题是受影响的应用程序列表有多大。除了用“一大堆”来形容之外，好像没有人有更好的答案，因为这个库几乎无处不在。

以下是感染流图片演示：

![](../Images/d6c3b7d6b822b1c8fa2a16c0b704ca1a.png)

受影响的产品仍在确定中，范围从 Apache Struts 之类的网络服务到 Minecraft 之类的游戏，再到银行和金融应用程序。如果运行基于开源软件构建的服务器，很可能会受到此漏洞的影响。

我们回到微软周二补丁日更新情况。今年，微软修补 CVE漏洞总数达到887 个，较 2020 年减少了 29%。就12 月份来说，微软发布了针对Microsoft Windows 和 Windows 组件、ASP.NETCore 和 Visual Studio、Azure BotFramework SDK、Internet Storage Name Service、Defender for IoT、Edge（基于 Chromium）、Microsoft Office 和Office 组件、SharePoint Server、PowerShell、远程桌面客户端、Windows Hyper-V、Windows Mobile 设备管理、Windows 远程访问连接管理器、TCP/IP 和 Windows 更新堆栈的67个漏洞发布安全补丁。结合本月早些时候 Microsoft Edge（基于 Chromium）修补的 16 个漏洞补丁， 12 月的 CVE 漏洞总数达到 83 个。

![](../Images/0f34806c16d0f3806d87111c3e31089f.png)

 

微软本月推出补丁星期二更新，解决 Windows 和其他软件中的多个安全漏洞，包括一个被积极利用的漏洞，该漏洞被滥用于提供 Emotet、TrickBot 或Bazaloader 恶意软件负载。其中，CVE-2021-43890（CVSS 评分：7.1），是一个Windows AppX 安装程序欺骗漏洞，微软表示可利用该漏洞实现任意代码执行。较低的严重性评级表明代码执行取决于登录用户级别，这意味着“账户配置为在系统上拥有较少用户权限的用户可能比使用管理用户权限操作的用户受到的影响更小。”

本月较严重的漏洞如下：

 

*   CVE-2021-43240（CVSS 评分：7.8）——NTFS 设置短名称特权提升漏洞
    
*   CVE-2021-43883（CVSS 评分：7.8）——Windows Installer 特权提升漏洞
    
*   CVE-2021-41333（CVSS 评分：7.8）——Windows Print Spooler 特权提升漏洞
    
*   CVE-2021-43893（CVSS 评分：7.5）——Windows 加密文件系统(EFS) 特权提升漏洞
    
*   CVE-2021-43880（CVSS 评分：5.5）——Windows Mobile 设备管理特权提升漏洞

除了影响 iSNS 服务器 (CVE-2021-43215 )、4K 无线显示适配器 (CVE-2021-43899 )、Visual Studio Code WSL 的严重错误外，12 月的补丁还修复了 Defender for IoT 中的 10 个远程代码执行缺陷扩展 ( CVE-2021-43907 )、Office 应用程序 ( CVE-2021-43905 )、Windows 加密文件系统 ( CVE-2021-43217 )、远程桌面客户端 ( CVE-2021-43233 ) 和 SharePoint Server (CVE-2021- 42309）。

  

**CVE-2021-43890 - Windows AppX 安装程序欺骗漏洞**Emotet 卷土又重来，前几天转载山东三正科技公众号已经提到。此补丁修复了影响 Windows 的 AppX 安装程序中的错误。在 Emotet/Trickbot/Bazaloader 系列的恶意软件中发现该漏洞。攻击者需要制作恶意附件以用于网络钓鱼活动，然后说服用户打开特制的附件。代码执行似乎会发生在登录用户级别，因此攻击者可能会将其与另一个错误结合起来以控制系统。这个恶意软件家族已经存在一段时间了，可能会持续一段时间。 **CVE-2021-43215 – iSNS 服务器远程代码执行漏洞**修复 Internet 存储名称服务 (iSNS) 服务器中的一个错误，攻击者向受影响的服务器发送特制请求，可能允许远程执行代码。iSNS 是一种协议，支持自动发现和管理 TCP/IP 存储网络上的 iSCSI 设备。换句话说，如果在企业中运行 SAN，要么拥有 iSNS 服务器，要么单独配置每个逻辑接口。此错误是本月修复的三个 CVSS 9.8 错误之一。如果有 SAN，请优先测试和部署此补丁。  **CVE-2021-43899 – Microsoft 4K 无线显示适配器远程代码执行漏洞**漏洞可能允许未经身份验证的攻击者在受影响的设备上执行其代码。攻击者需要与 Microsoft 4K 显示适配器在同一网络上，可以将特制的数据包发送到受影响的设备。修补这个不会是一件容易的事。为了受到保护，用户需要从 Microsoft Store 将 Microsoft 无线显示适配器应用程序安装到连接到 Microsoft 4K 无线显示适配器的系统上。只有这样才能使用应用程序的“更新和安全”部分下载最新固件以缓解此错误。这是本月修补的第二个 CVSS 9.8 错误。 **CVE-2021-43907 – Visual Studio Code WSL 扩展远程代码执行漏洞**本月修补的最后一个 CVSS 9.8 漏洞。受影响的组件允许用户使用 Windows Subsystem for Linux (WSL) 作为 VisualStudio Code 的全时开发环境，在基于 Linux 的环境中进行开发，使用特定于 Linux 的工具链和实用程序，以及在 Windows 中运行和调试基于 Linux 的应用程序。DevOps 社区中的许多人都在使用这种跨平台功能。此补丁修复了扩展中的远程代码执行错误，但微软并未具体说明该代码执行的具体方式。他们确实将其列为未经身份验证并且不需要用户交互，因此如果使用此扩展程序，请快速**测试和部署**此更新。 **CVE-2021-42309 – Microsoft SharePointServer 远程代码执行漏洞**允许用户在服务账户的上下文中提升和执行代码。攻击者需要在 SharePoint 网站上拥有“管理列表”权限，但默认情况下，任何授权用户都可以在他们拥有完全权限的情况下创建自己的新网站。此漏洞允许攻击者绕过对运行任意服务器端 Web 控件的限制，类似于先前修补的CVE-2021-28474。然而，在这种情况下，不安全控件被“走私”在允许控件的属性中。微软下一个补丁更新日，是2022年 1 月 11 日，在此之前，期盼大家系统安全，运行稳定，开心、安心过元旦，迎新年！
