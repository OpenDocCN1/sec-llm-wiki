安全漏洞

国外厂商漏洞


1

---Apache Log4j2存在远程代码执行漏洞

Apache Log4j是一个基于Java的日志记录组件。Apache Log4j2是Log4j的升级版本，通过重写Log4j引入了丰富的功能特性。该日志组件被广泛应用于业务系统开发，用以记录程序输入输出日志信息。Apache Log4j2存在远程代码执行漏洞，攻击者可利用该漏洞向目标服务器发送精心构造的恶意数据，触发Log4j2组件解析缺陷，实现目标服务器的任意代码执行，获得目标服务器权限。 

来源：国家信息安全漏洞共享平台

2

---Dell Networking OS10身份验证绕过漏洞

Dell Networking OS10是美国戴尔（DELL）公司的一套基于Linux的网络交换机操作系统。Dell Networking OS10（2021年10月之前启用了Smart Fabric服务的版本）存在身份验证绕过漏洞。未经身份认证的远程攻击者可利用该漏洞获取访问权限并在受影响的系统上执行操作。

来源：国家信息安全漏洞共享平台

3

---Fortinet FortiWeb命令注入漏洞

Fortinet FortiWeb是美国飞塔（Fortinet）公司的一款Web应用层防火墙，它能够阻断如跨站点脚本、SQL注入、Cookie中毒、schema中毒等攻击的威胁，保证Web应用程序的安全性并保护敏感的数据库内容。Fortinet FortiWeb多个版本的命令行解释器存在命令注入漏洞。攻击者可利用该漏洞通过特制的命令参数在底层系统shell上执行任意命令。

来源：国家信息安全漏洞共享平台

4

---Sourcecodester Engineers Online Portal SQL注入漏洞

Sourcecodester Engineers Online Portal是开源的一个在线门户。Sourcecodester Engineers Online Portal in PHP存在SQL注入漏洞，攻击者可利用该漏洞通过my_classmates.php的id参数从Web服务器中提取敏感数据，并在某些情况下远程执行代码。

来源：国家信息安全漏洞共享平台

5

---WordPress WP Data Access插件SQL注入漏洞

WordPress是Wordpress基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress WP Data Access插件在5.0.0之前版本存在SQL注入漏洞，该漏洞源于插件的 backup_date参数缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令窃取数据库敏感数据。

来源：国家信息安全漏洞共享平台

1

在针对最近披露的Log4Shell漏洞利用的前一个补丁被认为“在某些非默认配置中不完整”之后，Apache 软件基金会 (ASF) 推出了针对 Log4j 日志记录实用程序的新修复程序。第二个漏洞 - 被跟踪为CVE-2021-45046 - 在 CVSS 评级系统中被评为 3.7 分（满分 10 分），并影响从 2.0-beta9 到 2.12.1 和 2.13.0 到 2.15.0 的所有 Log4j 版本，其中项目维护人员上周发布了一个关键的远程代码执行漏洞 (CVE-2021-44228)，该漏洞可能被滥用以渗透和接管系统。对于不完整的修补CVE-2021-44228可能会被滥用为“使用工艺恶意输入数据JNDI导致拒绝服务（DoS）攻击查找模式”的ASF说，Log4j 的最新版本 2.16.0（适用于需要 Java 8 或更高版本的用户）几乎取消了对消息查找的支持，并默认禁用了 JNDI，这是漏洞的核心组件。建议需要 Java 7 的用户在可用时升级到 Log4j 版本 2.12.2。“处理 CVE-2021-44228 表明 JNDI 存在严重的安全问题，” ASF 的 Ralph Goers解释说。“虽然我们已经减轻了我们所知道的情况，但默认情况下用户完全禁用它会更安全，特别是因为大多数人不太可能使用它。”

来源：https://securityaffairs.co


2

约会应用程序 Grindr 因未经广告商明确同意向广告商出售用户数据而被罚款 650 万欧元（550 万英镑）。罚款是由挪威数据保护局 (DPA) 因“严重”违反 GDPR 规则而发出的。这是因为 Grindr 在未经用户明确同意的情况下与第三方共享高度敏感的“特殊类别”数据，这是法规的要求。这包括 GPS 位置、IP 地址、广告 ID、年龄和性别。此外，第三方知道用户正在使用 Grindr，这是一款面向同性恋、双性恋、跨性别和酷儿的约会应用程序，这意味着他们的性取向数据被暴露了。用户被迫同意公司的隐私政策，而没有被特别询问他们是否同意出于行为目的共享他们的数据。

来源 ：https://www.infosecurity-magazine.com


3

据研究人员称，一个伊朗国家资助的威胁组织正在使用消息平台 Slack 上的免费工作空间在一家亚洲航空公司的系统中部署一个后门。IBM Security X-Force 的一份报告称，被称为 Aclip 的后门可能使威胁行为者能够访问航空公司的乘客预订数据。

来源：https://www.inforisktoday.com


4

恶意行为者正在Microsoft Exchange Outlook Web Access 服务器上部署一个以前未被发现的二进制文件，一个名为“ Owowa ”的 Internet 信息服务 ( IIS ) 网络服务器模块，目的是窃取凭据并启用远程命令执行。“Owowa 是一个 C# 开发的 .NET v4.0 程序集，旨在作为模块加载到 IIS Web 服务器中，该服务器还公开 Exchange 的 Outlook Web Access (OWA)，”卡巴斯基研究人员 Paul Rascagneres 和 Pierre Delcher说。“以这种方式加载时，Owowa 将窃取任何用户在 OWA 登录页面中输入的凭据，并允许远程操作员在底层服务器上运行命令。”

来源：https://thehackernews.com/


5

据Security Affairs网站报道，来自姆施塔特大学、布雷西亚大学、CNIT 和安全移动网络实验室的一组研究人员发现了WiFi芯片中的安全漏洞，攻击者可利用这些漏洞通过定位设备的蓝牙组件来提取密码并操纵WiFi芯片上的流量。根据专家发表的研究论文，现今的移动设备使用独立的无线芯片来管理蓝牙、Wi-Fi 和 LTE 等无线技术。但是，这些芯片共享组件和资源，例如相同的天线或无线频谱，以提高设备的效率，从而降低能耗和通信延迟。研究人员表示，攻击者可以用这些共享资源跨无线芯片边界发起横向提权攻击。WiFi芯片会加密网络流量并保存当前的WiFi凭证，从而为攻击者提供更多信息。此外，攻击者可以在WiFi芯片上执行代码，即使它没有连接到无线网络。

来源：https://securityaffairs.co
