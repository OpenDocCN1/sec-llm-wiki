# **2、CYBOK知识域**

CyBOK分为21个顶层知识域(KAs), 分为五大类，如图所示1.显然，其他可能的分类KAs可能同样有效，最终某些结构是相对武断的。

CyBOK前言描述了这些过程KAs被确定和选择。

我们的分类并不完全正交，这些旨在获取与网络安全本身有关的知识：为了理解其中一些知识，需要辅助和背景知识——无论是在硬件和软件设计方面，还是在法律等其他不同领域。

![](../Images/236331d0ef87771f07cd8e0a8fc36ac2.png)

接上图，我们探讨一下21个知识域。

**人力、组织和监管方面**

| **风险管理和治理** || 安全管理系统和组织安全控制，包括标准、最佳实践，以及风险评估和缓解的方法。 |
| --- | --- |
| **法律法规** || 国际和国家法律法规要求、合规义务和安全道德，包括数据保护和制定网络战理论。 |
| **人为因素** || 影响安全、安全文化和意识的可用安全、社会和行为因素，以及安全控制对用户行为的影响。 |
| **隐私和在线权利** || 用于保护个人信息的技术，包括通信、应用程序以及从数据库和数据处理中推断的信息。它还包括其他支持在线权利的系统，涉及审查和规避、秘密、电子选举以及支付和身份系统中的隐私。 |

**攻击和防御**

| **恶意软件与攻击技术** || 利用漏洞和分布式恶意系统的技术细节，以及相关的发现和分析方法。 |
| --- | --- |
| **敌对行为** || 攻击者使用的动机、行为和方法，包括恶意软件供应链、攻击向量和资金转移。 |
| **安全运营和事件管理** || 安全系统的配置、操作和维护，包括安全事件的检测和响应以及威胁情报的收集和使用。 |
| **取证** || 收集、分析和报告数字证据以支持事件或犯罪事件。 |

**系统安全**

| **密码学** || 目前实践的密码学核心原语&新兴算法、分析这些算法的技术以及使用它们的协议。 |
| --- | --- |
| **操作系统&虚拟化安全** || 操作系统保护机制，实现硬件的安全抽象和资源共享，包括多用户系统中的隔离、安全虚拟化和数据库系统中的安全。 |
| **分布式系统安全** || 与大规模协调分布式系统相关的安全机制，包括安全共识、时间、事件系统、对等系统、云、多租户数据中心和分布式账本等方面。 |
| **安全形式化方法** || 关于系统、软件和协议安全性的正式规范、建模和推理，包括基本方法、技术和工具支持。 |
| **认证、授权和责任** || 身份管理和身份验证技术的所有方面，以及支持独立和分布式系统中的授权和责任的体系结构和工具。 |

**软件与平台安全**

| **软件安全** || 导致安全漏洞的已知编程错误类别，以及通过编码实践和改进的语言设计避免这些错误的技术，以及在现有系统中检测此类错误的工具、技术和方法。 |
| --- | --- |
| **Web和移动安全** || 与跨设备和框架分布的web应用程序和服务相关的问题，包括不同的编程范例和保护模型。 |
| **安全软件生命周期** || 安全软件工程技术在整个系统开发生命周期中的应用，导致软件在默认情况下是安全的。 |

**基础设施安全**

 

| **应用密码学** || 密码算法、方案和协议的应用，包括有关实现、密钥管理及其在协议和系统中的使用的问题。 |
| --- | --- |
| **网络安全** || 网络和电信协议的安全方面，包括路由安全、网络安全元素和用于网络安全的特殊加密协议。 |
| **硬件安全** || 通用和专业硬件设计、实施和部署的安全性，包括可信计算技术和随机性来源。 |
| **网络物理系统安全** || 网络物理系统的安全挑战，如物联网和工业控制系统、攻击者模型、安全设计以及大型基础设施的安全。 |
| **物理层和电信安全** || 物理层的安全问题和限制，包括射频编码和传输技术、非预期辐射和干扰等方面。 |
