电子邮件客户端如何工作？

每个电子邮件地址都有两个基本部分：用户名和域名。当我们向其他人发送电子邮件时，我们域的服务器必须与收件人的域服务器通信。

例如，假设我们的电子邮件地址是johndoe@example.com，我们联系的人是janesmith@anotherexample.org。用非常基本的术语来说，在我们点击“发送”后，托管域的服务器 (example.com) 会查看电子邮件地址，然后联系托管收件人域的服务器(anotherexample.org)，让它知道有给某人的消息在那个域。建立连接后，托管收件人域(anotherexample.org) 的服务器会查看电子邮件地址的用户名并将消息路由到该账户。

有多少电子邮件客户端？

有许多不同的电子邮件客户端和服务，每个都有自己的界面。有些是基于 Web 的应用程序，有些是直接安装在计算机上的独立应用程序，还有一些是基于文本的应用程序。许多此类电子邮件客户端也有许多变体，它们专为移动设备（如手机）设计。

如何选择电子邮件客户端？

安装操作系统时通常会包含一个电子邮件客户端，但也有许多其他替代方案可用。警惕“自制”软件，因为可能不如经过测试和积极维护的软件安全或可靠。在决定哪种电子邮件客户端最适合我们的需求时要考虑的一些因素包括

  • 安全性-是否认为电子邮件程序为我们提供了发送、接收和阅读电子邮件消息所需的安全级别？它如何处理附件？如果我们正在处理敏感信息，是否可以选择发送和接收签名和/或加密的消息？

  • 隐私- 如果我们使用的是基于 Web 的服务，是否阅读过其隐私政策？是否知道正在收集哪些信息以及谁可以访问这些信息？是否有过滤垃圾邮件的选项？

  • 功能- 软件是否适当地发送、接收和解释电子邮件？

  • 可靠性- 对于基于 Web 的服务，服务器是否可靠，或者电子邮件是否由于维护、安全问题、大量用户或其他原因而经常无法使用？

  • 可用性-是否需要能够从任何计算机访问账户？

  • 易用性- 菜单和选项是否易于理解和使用？

  • 视觉吸引力-界面吸引人吗？

每个电子邮件客户端可能有不同的方式来组织起草、发送、保存和删除的邮件。熟悉该软件，以便可以轻松查找和存储消息，并且不会无意中丢失消息。选择要用于电子邮件的软件后，请遵循良好的安全实践来保护我们自己和我们的联系人。

可以使用多个电子邮件客户端吗？

可以拥有多个电子邮件客户端，尽管可能会遇到兼容性问题。某些电子邮件账户，例如通过Internet 服务提供商 (ISP) 或工作地点发布的账户，只能从具有适当权限和设置的计算机访问，以便访问该账户。可以使用任何独立的电子邮件客户端来阅读这些消息，但如果计算机上安装了多个客户端，则应选择一个作为默认客户端。当单击浏览器或电子邮件中的电子邮件链接时，计算机将打开我们选择的默认电子邮件客户端。

大多数供应商都允许我们直接从官方网站下载其电子邮件软件。确保在下载任何文件之前验证站点的真实性，并遵循其他良好的安全实践，例如使用防火墙和保持最新的防病毒软件，以进一步降低风险。

我们还可以通过可从任何计算机访问的基于浏览器的电子邮件客户端（例如QQ、163、Sina、Yahoo!、Hotmail、Gmail）维护免费电子邮件账户。由于这些账户直接在供应商的服务器上维护，因此它们不会干扰其他电子邮件账户。
