# 网络安全知识之识别和避免间谍软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652091194&idx=1&sn=7a44dd3a4fb74999e88ebb68002174f7&chksm=8bbc9903bccb1015f46db8611ba1e875971dfd7aa4cbd7faf6653341853fc48893ded4ab6357&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652091194&idx=1&sn=7a44dd3a4fb74999e88ebb68002174f7&chksm=8bbc9903bccb1015f46db8611ba1e875971dfd7aa4cbd7faf6653341853fc48893ded4ab6357&scene=27#wechat_redirect)

**什么是间谍软件？**

尽管我们把他的名称叫“间谍软件”，但这里的术语“间谍软件”并不是指卧底特工使用的东西，而是指广告行业使用的东西。事实上，间谍软件也被称为“广告软件”，是指一类软件，当安装在我们的计算机上时，可能会向我们发送弹出广告、将浏览器重定向到某些网站或监控我们访问的网站。某些极端的、侵入性的间谍软件版本可能会准确跟踪我们键入的键。攻击者还可能出于恶意目的使用间谍软件。

由于额外的处理，间谍软件可能会导致我们的计算机变慢或运行缓慢。还有隐私方面的影响：

*   正在收集什么信息？
    
*   谁在接收它？
    
*   它是如何使用的？

**怎么知道电脑上是否有间谍软件？**  

以下症状*可能*表明我们的计算机上安装了间谍软件：

*   会受到无休止的弹出窗口的影响
    
*   将被重定向到在浏览器中输入的网站以外的网站
    
*   新的、意外的工具栏出现在 Web 浏览器中
    
*   新的意外图标出现在屏幕底部的任务托盘中
    
*   浏览器主页突然改变了
    
*   单击“搜索”时浏览器打开的搜索引擎已更改
    
*   某些键在浏览器中不起作用（例如，当移动到表单中的下一个字段时，tab 键不起作用）
    
*   开始出现随机的 Windows 错误消息
    
*   打开程序或处理任务（保存文件等）时，计算机突然变得很慢
    

**如何防止间谍软件安装到计算机上？**

为避免自己意外安装，请遵循以下良好的安全实践：

*   **不要单击弹出窗口中的链接**\- 因为弹出窗口通常是间谍软件的产物，单击窗口可能会在我们的计算机上安装间谍软件。要关闭弹出窗口，请单击标题栏中的“X”图标而不是窗口内的“关闭”链接。
    
*   **当被问到意外问题时选择“否”** - 小心意外对话框询问我们是要运行特定程序还是执行其他类型的任务。始终选择“否”或“取消”，或通过单击标题栏中的“X”图标关闭对话框。
    
*   **警惕可免费下载的软件**\- 有许多网站提供定制的工具栏或其他吸引用户的功能。不要从我们不信任的站点下载程序，并意识到通过下载其中的一些程序，可能会将我们的计算机暴露给间谍软件。
    
*   **不要访问声称提供反间谍软件的电子邮件链接**\- 与电子邮件病毒一样，这些链接可能会起到相反的作用，实际上会安装它声称要消除的间谍软件。
    

作为额外的良好安全实践，特别是如果我们担心自己的计算机上可能有间谍软件并希望将影响降至最低，请考虑采取以下措施：

*   **调整浏览器首选项以限制弹出窗口和 cookie** -     弹出窗口通常由某种脚本或活动内容生成。调整浏览器中的设置以减少或阻止脚本或活动内容可能会减少出现的弹出窗口的数量。某些浏览器提供了阻止或限制弹出窗口的特定选项。某些类型的 cookie 有时被视为间谍软件，因为它们会显示我们访问过的网页。可以调整我们的隐私设置以仅允许我们正在访问的网站使用 cookie。
    

**如何删除间谍软件？**

*   **使用防病毒软件对计算机进行全面扫描**\- 某些防病毒软件会发现并删除间谍软件，但在实时监控我们的计算机时可能找不到间谍软件。将防病毒软件设置为提示我们定期运行全面扫描。
    
*   **运行专门设计用于删除间谍软件的合法产品**\- 许多供应商提供的产品可以扫描计算机以查找间谍软件并删除任何间谍软件。流行的产品包括 Lavasoft 的 Ad-Aware、微软的 Window Defender、Webroot 的 SpySweeper 和 Spybot Search and Destroy。
    
*   **确保防病毒和反间谍软件兼容**\- 采取分阶段安装软件的方法，以确保我们不会无意中引入问题。
