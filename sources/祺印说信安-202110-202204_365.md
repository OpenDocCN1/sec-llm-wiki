# 网络力量——第三梯队：伊朗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652091051&idx=2&sn=e841552e5fc767228814045b8073a2f2&chksm=8bbc9892bccb118427f675da23905ee4ae14b17ae1feac10003d19ecd6a5ee53917b880dfd8a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652091051&idx=2&sn=e841552e5fc767228814045b8073a2f2&chksm=8bbc9892bccb118427f675da23905ee4ae14b17ae1feac10003d19ecd6a5ee53917b880dfd8a&scene=27#wechat_redirect)

英国国际战略研究所根据**首字母排序**将伊朗列到第三梯队的第三个。第三梯队：IISS 网络力量方法论中某些类别的优势或潜在优势，但其他类别的存在重大弱点。伊朗入选，应该在预料之中的，毕竟也是美国媒体中的常客，美国发生点网络攻击都需要有个描述对象，俄罗斯、中国、伊朗、朝鲜，都是他们媒体的座上宾。

**伊朗**伊朗认为自己正处于与敌人的情报和网络战争中。2010 年，当美国和以色列对伊朗的震网攻击被曝光时，该国几乎无法接触到国际网络安全供应商，只有极少数国内该领域的研究人员。然而，从那时起，它已成为一个坚决反对美国、海湾阿拉伯和以色列利益的网络行为者。

![](../Images/9763ac861556b9c2b0fb64a1d2e76c5b.png)

与此同时，通过增加内部网络监视来平息国内反对派的需求与政府应对外部威胁的愿望相吻合。然而，经济萧条、政治动荡和内部缺陷表明，伊朗将无法轻松或快速地提升其本土网络防御能力。它的整体网络能力与其弹道导弹或核计划的规模和复杂程度不匹配。例如，它缺乏开发和部署复杂的进攻性网络能力所需的资源、人才和技术基础设施，尽管它广泛使用了较低级别的进攻性网络技术并取得了一些成功。伊朗是第三级网络强国，它利用不太复杂的网络技术和作战能力来实现其战略目标，包括间谍活动、力量投射和战略信号传递。  
**参考来源：英国国际战略研究所**
