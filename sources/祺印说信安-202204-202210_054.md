# 微软警告针对游戏玩家的大规模点击欺诈活动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652095965&idx=2&sn=9b862c589a11cb20e326fdcdd5885c36&chksm=8bbcefe4bccb66f2439701a58f29262cade2b6e4044bbcb71baf6162d250bc6c9152d85143bc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652095965&idx=2&sn=9b862c589a11cb20e326fdcdd5885c36&chksm=8bbcefe4bccb66f2439701a58f29262cade2b6e4044bbcb71baf6162d250bc6c9152d85143bc&scene=27#wechat_redirect)

微软表示，它正在通过在受感染系统上秘密部署浏览器扩展来跟踪针对游戏玩家的持续大规模点击欺诈活动。

“\[The\] 攻击者通过浏览器节点 webkit 或设备上秘密安装的恶意浏览器扩展产生的点击获利，”微软安全情报部门在周末的一系列推文中表示。

这家科技巨头的网络安全部门正在以 DEV-0796 的名义跟踪发展中的威胁集群。攻击者安装的附加链从一个 ISO 文件开始，该文件在点击 YouTube 上的恶意广告或评论后下载到受害者的机器上。ISO 文件在打开时旨在安装浏览器 node-webkit（又名NW.js）或流氓浏览器扩展。

![](../Images/05d4848fc0bc2a068f0404a6539a59a9.png)

值得注意的是，ISO 文件伪装成 Krunker 第一人称射击游戏的黑客和作弊程序。秘籍是帮助游戏玩家在游戏过程中获得超出可用功能之外的额外优势的程序。

攻击中还使用了 DMG 文件，这些文件是主要用于在 macOS 上分发软件的 Apple 磁盘映像文件，表明攻击者针对多个操作系统。

随着卡巴斯基披露另一项活动的细节，该活动的详细信息引诱在 YouTube 上寻找作弊的游戏玩家下载能够安装加密矿工和其他信息窃取程序的自我传播恶意软件。

这家俄罗斯网络安全公司在最近的一份报告中表示： “作为作弊程序分发的恶意软件和不需要的软件对游戏玩家的安全构成了特别的威胁，特别是对于那些热衷于流行游戏系列的人来说。”
