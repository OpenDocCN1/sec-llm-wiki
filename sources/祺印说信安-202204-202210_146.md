# 驻马店：2022年网民网络安全感满意度调查活动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652095283&idx=4&sn=88bb4ccbb5eb325bc5882e08fccb6927&chksm=8bbce90abccb601c853f6f07891d868b9276e310e5e09e60fe046c3f33a7fdcebe2a8ab39df5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652095283&idx=4&sn=88bb4ccbb5eb325bc5882e08fccb6927&chksm=8bbce90abccb601c853f6f07891d868b9276e310e5e09e60fe046c3f33a7fdcebe2a8ab39df5&scene=27#wechat_redirect)

为积极响应习近平总书记近期提出的“要走好新形势下的群众路线，善于通过互联网等各种渠道问需于民、问计于民，更好倾听民声、尊重民意、顺应民心”的重要指示精神，更好收集网络安全民意，服务国家网络安全监管和治理及公安机关网络安全保卫工作，喜迎党的二十大，活动组委会定于8月3日正式启动“2022网民网络安全感满意度调查活动”网民意见采集工作，届时全国各大网络平台将同步开通线上采集通道，历时10天，于8月12日结束。
