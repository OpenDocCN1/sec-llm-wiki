# 兰德报告：识别关键 IT 产品和服务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652094366&idx=2&sn=ff322952e628afea310a3a1fd4f0291f&chksm=8bbc95a7bccb1cb1e1b9ba8744328cf7920d375a1dca5a587056e7540d2156ff8cd9b9f86577&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652094366&idx=2&sn=ff322952e628afea310a3a1fd4f0291f&chksm=8bbc95a7bccb1cb1e1b9ba8744328cf7920d375a1dca5a587056e7540d2156ff8cd9b9f86577&scene=27#wechat_redirect)

美国兰德公司，在今年7月6日发布《识别关键 IT 产品和服务》，报告认为在过去的 20 年中，美国政府在美国国土安全部 (DHS) 的支持下并与其他公共和私营实体合作，在列举该国的关键基础设施组成部分和国家关键功能 (NCF) 方面取得了相当大的进展。然而，这些努力并没有实现对网络中最关键的计算系统的具体识别。为了帮助填补这一空白，国土安全运营分析中心的研究人员试图检查和列举提供最关键的信息技术 (IT) 产品和服务的企业，并为国土安全部和其他联邦和私营部门的要素奠定基础更好地应用基于风险的方法来保护国家最重要的资产和系统。他们试图 (1) 创建提供 IT 产品和服务的软件和企业的优先列表，以及 (2) 开发一个框架，该框架可以继续并将这种分析扩展到未来，以适应新兴技术和技术市场的发展。

![](../Images/f776551f02b975e0f1ceba49d83e558c.png)

该工作包含四个工作流程：**（1）**识别和整合不同的数据源，以识别美国互联网协议空间中最关键的漏洞和软件应用程序；**(2) **收集原始数据以映射被引用最多的库的软件依赖和所有权结构；**(3) **利用现有工作，确定互联程度最高且可能遭受最大经济损失的特定 IT 和通信公司；**(4) **开发一种将 NCF 与支持这些功能的实际软件公司联系起来的方法。

## 主要发现

*   了解软件风险需要来自互联网和安全公司的数据，以及存在的漏洞、存在的行业和公司以及应用程序如何支持公司及其运营的知识。
    
*   现代商业应用程序建立在数百个小型分布式免费和开源软件库之上，这些软件库的拥有和维护方式各不相同，有自己的风险概况需要了解，并且经常添加和更新。
    
*   规模较小但联系更紧密的公司可能会产生不成比例的更大商业风险。
    
*   NCF 框架可以揭示关键基础设施与 IT 产品和服务之间的相互依赖关系。
    

![](../Images/29148ab2570c5213ea86f5c7f0eb8889.png)

## 兰德在报告中给出建议

*   收集有关哪些行业和公司中存在的漏洞以及这些应用程序如何支持公司及其运营的其他上下文信息。
    
*   让政策制定者将新漏洞通知软件制造商，或让运行易受攻击软件的公司更新或升级其系统。
    
*   在风险评估中包括这些公司和部门中使用的应用程序调用的库的风险概况。在添加和更新库时保持更新风险概况。考虑一种考虑软件风险评估的新方法，该方法将来自开源软件依赖项的风险纳入更广泛的软件风险框架。
    
*   使用本报告中描述的客观方法来确定业务供应链对 IT 和通信行业的上市公司的潜在影响。
    
*   使用此处描述的方法来利用市场分析来识别与特定软件细分市场相关的公司。
