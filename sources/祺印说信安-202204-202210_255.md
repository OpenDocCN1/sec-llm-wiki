# 闲谈等级保护：在43号文之前2006年发布过过渡文件7号文

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652094259&idx=1&sn=a949fd86b9a92ebbe9e38e1c755760e2&chksm=8bbc950abccb1c1c524b3d6616df2e7cb6923d1ec5f1ce43327e2c1fee89d24ab6ab133adc90&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652094259&idx=1&sn=a949fd86b9a92ebbe9e38e1c755760e2&chksm=8bbc950abccb1c1c524b3d6616df2e7cb6923d1ec5f1ce43327e2c1fee89d24ab6ab133adc90&scene=27#wechat_redirect)

在整理网络安全等级保护有关政策文件过程中，好像未看到2006年有什么大的政策文件。直到一次细看《信息安全等级保护管理办法》（公通字〔2007〕43号），才发现被自己漏了一个过渡性的规范性文件。

  
![](../Images/5455ad3d1ee097056b0274ed8977fde6.png)  

原本我想继续往下分享2007年43号文的，在以往的工作学习中，也未有人提及2006年有比较重要的规范性文件支撑等级保护工作，不过在研读43号文的过程中，发现43号文的：**第四十四条    本办法自发布之日起施行，《信息安全等级保护管理办法（试行）》（公通字〔2006〕7号）（以下简称“7号文）同时废止。**对我个人来说至此，才发现原来在2006年发布过一个7号文作为过渡形式的规范性文件。这个闲谈系列，也是在原来的基础上在探讨，就是希望给朋友们一个等级保护发展的粗略的历史线，所以就在此也简单聊聊这个7号文了。

也就是，在我们常规资料里，还曾经有一个公通字\[2006\]7号的规范性文件。那么这个《信息安全等级保护管理办法（试行）》与后来的信息安全等级保护管理办法（公通字〔2007〕43号）中间有何差异呢？

  

通过对7号文的学习了解，发现在7号文里，五个级别还是沿用了66号文的描述方式，即五个级别分别为第一级为自主保护级、第二级为指导保护级、第三级为监督保护级、第四级为强制保护级、第五级为专控保护级。

在43号文中，规定了我们熟知的等级保护五个标准动作，但在7号文件中未全面提及。

![](../Images/9f633ce7c0e67548aa5f234b31b42bc1.png)

  

7号文件2006年1月17日印发，2006年3月1日起实施。而43号文则2007年6月26日印发，当日起开始实施。也就是7号文实施时长也就一年三个月多一点，是一个过渡性的规范性文件。

对比两份文件，想必7号文实施一年多的时间里，为43号的起草制定提供了很大的参考，创造了时间窗口。![](../Images/8afb14d818dc9837fedb4b8903f45816.png)  
鉴于，7号文已经废止，我无意于做过多赘述，本文只想传达一个信息，就是在43号之前，7号文作为过渡性文件曾经为等级保护工作开展提供过参考，期待接下来能和大家一起探讨学习43号，43号是做等保的里程碑性的文件。
