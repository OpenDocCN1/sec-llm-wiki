如何检查硬盘空间

在学习如何删除 PC 上的应用程序之前，您应该先查看硬盘驱动器上的空间，看看有多少空间正在使用中。检查可用空间非常容易，特别是如果您有 Windows 操作系统。

1.打开“这台电脑”应用程序

  • 如果您在桌面上没有看到标有“这台电脑”的图标，请打开开始菜单。

  • 如果计算机图标和相应的标题不在您的 Windows 菜单中，请在弹出的搜索框中搜索“这台电脑”。

  • 找到“这台电脑”应用程序后，单击它会弹出一个窗口。

2. 找到硬盘的可用空间

  • 从这里您可以看到标有 (C:) 的银色小盒子图标。这是您的硬盘存储。

  • 正下方以较小的字体显示可用空间与占用空间的比率。例如，232.7GB 免费 412GB。

如果您有一个 500GB 的硬盘驱动器，并且想知道为什么最大可用空间为 412GB，那是因为您的操作系统占用了很大一部分存储空间，并且没有计入该比率。

  • 右键单击硬盘驱动器图标，然后单击“属性”。

  • 应该会出现第二个窗口，显示一个描述已用和可用空间的饼图。

3.如何清理你的硬盘

  • 从这里您可以选择磁盘清理。

  • 您可以删除临时文件以及不再使用的文件和程序。

  • 如果您想节省空间而不必从计算机中删除太多应用程序，您也可以压缩文件。

虽然加载压缩文件需要 CPU 做更多的工作，但压缩文件更小，占用的磁盘空间更少。这实际上可以提高系统读取文件的速度。如果您的计算机具有强大的 CPU 但硬盘驱动器速度较慢，则压缩文件可能会提高 PC 的整体速度。

如何从硬盘中删除应用程序

要记住的一件事是，删除桌面上的图标不会从计算机中删除应用程序。这只是摆脱了快捷方式。卸载程序会擦除硬盘驱动器中的数据。

小心删除

对选择删除或卸载的程序和文件非常小心，这一点很重要。虽然您删除的文件最终会进入回收站，这意味着您可以根据需要检索它们，但您已卸载的程序将被完全删除。如果您决定要重新安装它们，则必须重新安装它们。

在决定哪些应用程序能够晋级哪些不能晋级时，要具有战略性。例如，您可能希望保留 Microsoft Word、PowerPoint 和 Excel 等程序。尽管这些往往是驱动器上的一些较大的程序，但它们也是最有用的。

在删除它们之前，请务必仔细检查您不确定的任何文件。重要的应用程序可能在其标题中标有令人困惑的文本和数字字符串，因此在筛选时要特别小心。

删除重复文件

考虑使用在您的计算机上查找重复文件并将其删除的程序。在大多数情况下，您会在保存同一文件的第二份副本之前看到一个弹出窗口；但是，如果您不是最精通技术的人，那么这些在线资源可能具有极大的用途和价值。

计算机可能运行缓慢的其他原因

如果您的计算机由于硬盘驱动器已满而运行缓慢，则在将程序检索到 RAM 后它应该会加快速度。

如果按照上述说明清除硬盘驱动器中大量不必要的应用程序和文件后，您的 PC 仍然运行缓慢，则您的 PC 可能还有其他方面需要注意。

关闭不必要的应用程序

一次打开多个文件和应用程序会大大降低您的速度。你的 RAM 一次只能处理这么多任务，所以如果你把它推到它的能力之外，它可能会导致你的 PC 像使用 RAM 一样使用它的硬盘驱动器。这有时被称为“围栏跳跃”。

由于您的硬盘驱动器的设计与运行 RAM 的方式不同，因此计算机上的压力通常会导致崩溃。为避免这种情况，请点击“control+alt+delete”以调出您的任务管理器并关闭您不使用的所有文件和应用程序。

检查病毒

除了学习如何从计算机中删除应用程序之外，您还应该了解如何删除病毒。当计算机未以最佳条件或速度运行时，有时可能难以诊断。

如果您的计算机速度明显变慢，则它可能感染了病毒。虽然病毒可能会减慢您的 PC 硬盘驱动器，但后果还不止于此。您的特权信息也将面临风险。

安装杀毒软件

如果您的计算机未安装反恶意软件或订阅已过期，请立即重新安装或续订。

最好的反恶意软件程序通常具有内置工具，可用于扫描和删除不应在您的计算机上的文件或应用程序。McAfee、Norton 和 Webroot 等防病毒软件可以帮助防止病毒侵入您的 PC，并为您提供删除任何现有病毒所需的资源。

从硬盘驱动器中删除病毒

以下是如何从您的 PC 中删除病毒和恶意软件的基本概要：

1.断开连接

您不想在从 PC 中删除病毒的同时保持与 Internet 的连接。在防病毒过程中断开互联网连接将防止病毒泄露您的信息并传播到其他计算机。

2.进入安全模式

如果您怀疑您的 PC 已被感染，请关闭您的计算机并以安全模式启动它。只会加载最基本的程序，这将使删除恶意文件更容易，因为它们实际上不会启动和运行。

3.释放磁盘空间

磁盘清理是删除 PC 上临时文件并减少反恶意软件必须筛选的数据量的最简单方法。您可以通过在搜索栏中键入或右键单击硬盘图标来找到磁盘清理选项。

4. 运行你的杀毒软件

在您的防病毒软件的启动菜单上应该有一个扫描和删除病毒的选项。如果您不确定如何使用特定的反恶意软件程序，可以在线获取说明。

在大多数情况下，在删除恶意软件时，您的防病毒软件将承担大部分繁重的工作，而您的任务是释放磁盘空间。这就是为什么为您的计算机购买高质量的防病毒软件非常重要的原因。
