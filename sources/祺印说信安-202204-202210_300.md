# APT 黑客利用 ShadowPad 后门攻击工业控制系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652094061&idx=2&sn=ac6c704d4d33254dd3fecb0133f93545&chksm=8bbc9454bccb1d42837c9b9527983f82a99ff7139527023c705743e234eeff4b4ae4a0441cce&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652094061&idx=2&sn=ac6c704d4d33254dd3fecb0133f93545&chksm=8bbc9454bccb1d42837c9b9527983f82a99ff7139527023c705743e234eeff4b4ae4a0441cce&scene=27#wechat_redirect)

位于阿富汗、马来西亚和巴基斯坦的实体正处于攻击活动的目标中，该活动将未修补的 Microsoft Exchange 服务器作为部署 ShadowPad 恶意软件的初始访问媒介。

俄罗斯网络安全公司卡巴斯基于 2021 年 10 月中旬首次检测到该活动，并将其归因于一个以前不为人知的说中文的威胁行为者。目标包括电信、制造和运输部门的组织。

  

该公司表示：“在最初的攻击中，该组织利用 MS Exchange 漏洞部署 ShadowPad 恶意软件并渗透到其中一名受害者的楼宇自动化系统中。” “通过控制这些系统，攻击者可以访问被攻击组织的其他甚至更敏感的系统。”

ShadowPad于 2015 年作为 PlugX 的继任者出现，是一个私人销售的模块化恶意软件平台，多年来已被许多中国间谍活动者使用。

虽然它的设计允许用户远程部署其他插件，这些插件可以将其功能扩展到隐蔽数据收集之外，但使 ShadowPad 变得危险的是恶意软件中包含的反取证和反分析技术。

卡巴斯基说：“在被观察者的攻击期间，ShadowPad 后门以合法软件的名义下载到受攻击的计算机上。” “在许多情况下，攻击组织利用 MS Exchange 中的一个已知漏洞，并手动输入命令，这表明他们的活动具有高度针对性。”

![](../Images/262b2083e5333d67c91f85785cf28da7.png)

有证据表明，攻击者发起的入侵始于 2021 年 3 月，就在 Exchange Server 中的ProxyLogon 漏洞成为公众所知的时间。据称，一些目标已通过利用CVE-2021-26855（邮件服务器中的服务器端请求伪造 (SSRF) 漏洞）遭到破坏。

除了将 ShadowPad 部署为“mscoree.dll”（一个真正的 Microsoft .NET Framework 组件）外，这些攻击还涉及使用 Cobalt Strike、一种名为THOR的 PlugX 变体以及用于远程访问的 web shell。

![](../Images/7544365496a54ae5098a402e130a0dcc.png)

尽管该活动的最终目标仍然未知，但据信攻击者对长期情报收集感兴趣。

“楼宇自动化系统是高级威胁参与者的罕见目标，”卡巴斯基 ICS CERT 研究员 Kirill Kruglov 说。“然而，这些系统可能是高度机密信息的宝贵来源，并可能为攻击者提供通往其他更安全基础设施领域的后门。”
