谷歌宣布为企业推出新的 Chrome 和 Chrome 操作系统安全功能

谷歌周四为使用 Chrome 和 Chrome OS 的企业宣布了几项新的安全功能。

谷歌吹嘘 Chrome OS 从未受到勒索软件的攻击，并表示没有证据表明“成功的病毒攻击”。另一方面，Chrome 浏览器越来越成为零日攻击的目标。

这家科技巨头希望继续提高 Chrome OS 和 Chrome 的安全性，包括对企业而言。

该公司现在为企业安全团队提供一系列与第三方身份和访问、端点管理以及安全洞察和报告产品的即插即用集成。


新的 Chrome 企业连接器框架支持 Chrome 和 Chrome OS 与 Netskope、Okta、BlackBerry、Samsung、VMware、Splunk、CrowdStrike 和 Palo Alto Networks 的产品集成。并非所有这些都立即可用，但谷歌表示它们“即将推出”。

Netskope 产品优化了用户对关键数据的访问，BlackBerry 和三星产品使 IT 团队更容易管理 Chrome OS 设备，Splunk 提供对潜在风险事件的可行洞察。

另一个新功能称为 Chrome OS 数据控制，它通过使 IT 团队能够定义规则以触发可能导致数据泄漏的操作（例如打印、复制和粘贴以及屏幕截图）的控制，从而帮助组织防止数据泄露。


谷歌还宣布了硬件安全改进。HP Elite Dragonfly Chromebook 是第一款采用 Intel vPro Enterprise 的 Chrome OS 设备，它提供了基于硬件的数据安全功能，例如 Key Locker 和 Total Memory Encryption。

HP Elite Dragonfly Chromebook 包括隐私摄像头、指纹传感器、Sure View 隐私屏幕和 HP Proactive Insights 等功能，可提供对设备运行状况、性能和安全数据的访问。

谷歌将在 6 月 8 日（称为 Chrome 企业日）提供有关这些新功能的更多信息。
