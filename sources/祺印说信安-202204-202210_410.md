# 基本八成熟度模型：成熟度一级

**成熟度一级**

| **缓解策略** || **描述** |
| --- | --- |
| **应用程序控制** || 在操作系统、Web浏览器和电子邮件客户端使用的标准用户配置文件和临时文件夹中，在工作站上禁止执行可执行文件、软件库、脚本、安装程序、已编译的HTML、HTML应用程序和控制面板小程序的执行。 |
| **补丁应用程序** || 面向Internet的服务中安全漏洞的修补程序、更新或供应商缓解措施将在发布后两周内应用，如果存在漏洞，则在48小时内应用。针对Office生产力套件、Web浏览器及其扩展、电子邮件客户端、PDF软件和安全产品中的安全漏洞的修补程序、更新或供应商缓解措施将在发布后一个月内应用。至少每天使用漏洞扫描程序来识别面向Internet的服务中缺少的安全漏洞补丁或更新。至少每两周使用一次漏洞扫描程序来识别办公生产力套件、Web浏览器及其扩展、电子邮件客户端、PDF软件和安全产品中缺少的安全漏洞补丁或更新。面向Internet的服务、办公生产力套件、Web浏览器及其扩展、电子邮件客户端、PDF软件、Adobe Flash Player以及供应商不再支持的安全产品将被删除。 |
| **配置****Microsoft Office ****宏设置** || 对于没有已证明业务需求的用户，将禁用 Microsoft Office 宏。源自互联网的文件中的Microsoft  Office 宏将被阻止。Microsoft Office 宏防病毒扫描已启用。用户无法更改  Microsoft Office 宏安全设置。 |
| **用户应用程序强化** || Web浏览器不从互联网处理Java。网络浏览器不处理来自互联网的网络广告。Internet Explorer 11 不处理来自互联网的内容。用户无法更改 Web 浏览器安全设置。 |
| **限制管理特权** || 对系统和应用程序的特权访问请求在首次访问时进行验证要求。特权账户（不包括特权服务账户）被阻止访问互联网、电子邮件和 Web 服务。特权用户使用单独的特权和非特权操作环境。非特权账户无法登录到特权操作环境。特权账户（不包括本地管理员账户）无法登录到非特权操作环境。 |
| **修补操作系统** || 面向 Internet 的服务操作系统中安全漏洞的补丁、更新或供应商缓解措施将在发布后两周内应用，如果存在漏洞，则在 48 小时内应用。工作站、服务器和网络设备操作系统中安全漏洞的补丁、更新或供应商缓解措施将在发布后一个月内应用。至少每天使用漏洞扫描程序来识别面向 Internet 的服务操作系统中缺少的安全漏洞补丁。至少每两周使用一次漏洞扫描程序，以识别工作站，服务器和网络设备操作系统中缺少的安全漏洞补丁。供应商不再支持的操作系统将被替换。 |
| **多重 身份验证** || 如果组织的用户向其组织的面向 Internet 的服务进行身份验证，则组织的用户将使用多重身份验证。如果组织的用户向处理、存储或传达其组织的敏感数据的第三方面向  Internet 的服务进行身份验证，则组织用户将使用多重身份验证。如果组织用户向处理、存储或传达其组织的非敏感数据的第三方面向  Internet 的服务进行身份验证，则组织用户将使用多重身份验证（如果可用）。默认情况下，如果非组织用户向组织的面向 Internet 的服务进行身份验证，则会为非组织用户启用多重身份验证（但用户可以选择退出）。 |
| **定期备份** || 根据业务连续性要求，以协调和弹性的方式执行和保留重要数据、软件和配置设置的备份策略。作为灾难恢复演习的一部分，以协调的方式测试备份中的系统、软件和重要数据的恢复。非特权账户只能访问自己的备份。阻止非特权账户修改或删除备份。 |
