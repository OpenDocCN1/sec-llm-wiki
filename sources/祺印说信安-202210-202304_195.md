# 网络安全知识体系1.1风险管理和治理（一）什么是风险？

**风险**是一个给定的威胁，利用一项资产或多项资产的脆弱性，对组织造成损害的潜能。可通过事件的概率及其后果进行度量。![](../Images/236331d0ef87771f07cd8e0a8fc36ac2.png)

# **1、前言**

该知识域将解释网络风险评估和管理的基本原则及其在风险治理中的作用，并在此基础上进行扩展，以涵盖对该主题及其子领域的工作理解所需的知识。我们首先讨论日常风险之间的关系，以及为什么这在当今互联的数字世界中很重要。我们解释了为什么作为人类，我们需要有效的风险评估和管理原则来支持捕获和传播可能影响我们价值观的因素。然后，我们继续描述网络风险评估的不同视角——从单个资产到整个系统目标。我们取消了一些主要的风险评估方法，突出了它们的主要用途和局限性，并提供了指向更详细信息的指引。在风险评估和管理领域，安全度量是一个持续争论的话题：哪些系统功能需要度量风险，如何度量风险，以及为什么要度量风险？这些问题是在关于这个主题的现有文献的背景下提出的。这涉及到风险治理，这就解释了为什么有效的治理对于维护网络安全和一些在发展治理框架时必须考虑的社会和文化因素是很重要。几乎所有的系统仍然包括人的控制因素，这必须从一开始就加以考虑。最后，即使有明确定义和执行的风险评估和管理计划，风险仍有可能变成现实。在这种情况下，需要事件响应。我们讨论事件响应的重要性及其与风险治理流程的联系。

# **2、什么是风险？**

风险是日常生活的核心。从一个孩子做出从树上跳下来的决定到CEO在一家价值数十亿美元的公司中作出决定，我们都会做出可能影响我们个人、影响我们更广泛的社交网络和环境的决策。因此，定义风险是一个高度哲学化和有争议的问题。**Slovic**和**Renn**关于风险感知精选作品，抓住围绕这场辩论的广泛问题，并提供一个抽象问题的工作定义，使我们能够在社会技术层面上参与风险主题。**Renn** 对风险的工作定义是人类行为或事件导致影响人类价值的后果的可能性。这从根本上说是人类价值风险的基础，适用于儿童和CEO例子。它也适用于人与技术内在联系的世界中的网络安全环境。一方未能支持另一方的成功可能导致社会、经济和技术灾难。价值影响的工作定义提出了一个进一步的问题，即如何定义价值并获取可用于衡量和管理风险的指标。**Renn**定义了实现这一点所需的三个基本抽象元素：**影响人类价值的结果、发生的可能性（不确定性）以及结合这两个元素的公式**。这些要素是大多数风险评估方法的核心。这些方法旨在提供一种结构化的方法来获取价值实体以及影响实体的不必要结果的可能性，同时也要记住，即使是概率很低的事情也可能实现，并可能对价值产生重大影响。因此，我们在网络风险的背景下，在本KA中使用Renn的风险工作定义进行讨论。风险评估和管理的一个关键挑战是明确假设，并在主观风险感知和客观证据之间找到平衡。因此，风险评估是一个整理对世界的观察和看法的过程，可以通过逻辑推理或与实际结果的比较来证明其合理性。另一方面，风险管理是以价值观可能受到影响的人同意的方式开发和评估解决风险的选项的过程，同时铭记如何解决风险的协议可能涉及从接受到拒绝的（不）容忍范围。风险治理是一整套总体的持续的流程和原则，旨在确保在某些行动发生时对所面临的风险进行意识和教育，并向参与管理的所有人灌输责任感和问责制。它支持集体决策，包括风险评估和管理，包括考虑评估风险的法律、社会、组织和经济背景。本知识域探讨所有这些主题，并从个人、中小企业和大型组织等都可以访问的网络安全科学角度提供了对风险评估、管理和治理的见解。[**网络安全知识体系1.1简介（一）网络安全定义**](http://mp.weixin.qq.com/s?__biz=Mzg2NjY2MTI3Mg==&mid=2247484551&idx=1&sn=c0f4821ebf4eaa2d9375467a5cac56a6&chksm=ce462270f931ab66acf650d189a2c50ad1464a23f47943dc5577b9457d838d006edb247bd5de&scene=21#wechat_redirect)
