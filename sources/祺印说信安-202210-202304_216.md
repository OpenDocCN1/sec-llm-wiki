# 网络安全等级保护：云计算安全扩展测评PPT

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652098174&idx=1&sn=b6b3f619ae64b817dc1e3abb5057fc43&chksm=8bbce447bccb6d51c418b182386751fa2ad1d357f9dce112a80e27fcf28c96dcf828662ad2aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652098174&idx=1&sn=b6b3f619ae64b817dc1e3abb5057fc43&chksm=8bbce447bccb6d51c418b182386751fa2ad1d357f9dce112a80e27fcf28c96dcf828662ad2aa&scene=27#wechat_redirect)

**该PPT是我2022年为某学校录播等级保护测评相关课程时，结合等级测评标准及北京培训的课程，整理的这套PPT中的一个PPT。因本人对等级保护工作的理解水平限制，其中还存在诸多不足之处。虽然，我个人能力是有限的，但是我传递的却是我国网络安全领域最精彩的部分，由于个人能力限制未能传递更好罢了。**  
  

  

![](../Images/d098f4d5828b080a95cf1c06a8d0de71.png)

**在本节课程结束时，我和学校的两个班级的同学以“后记”的形式，做了一点点交流，也是希望更多的有志青年能够加入的等级保护工作的大军中来，众人拾柴火焰高，共同为我国的网络强国事业而努力奋斗。**  
![](../Images/f172879bbc5ef023abb456230ea17561.png)  
**网络安全等级保护制度进入2.0时代，保护对象、保护方法都发生了很大变化。保护对象除了传统的信息网络、信息系统和信息，增加了云平台、大数据、工业控制系统、物联网、移动互联、卫星系统、智能制造系统等新的保护对象。保护方法增加了密码技术、可信计算、人工智能、大数据分析等核心技术，以及动态防御、主动防御、纵深防御、精准防护、整体防控、联防联控等重要措施。因此、网络安全等级保护工作更加体系化、实战化和常态化，需要认真组织开展。**![](../Images/b67b6ab4a19764534bd5b16e908c079b.png)  
**网络安全等级保护测评作为网络安全等级保护工作重要的组成部分，未来可期，也期盼大家有志于从事等级保护工作，为我省网络安全事业作出应有的贡献！**
