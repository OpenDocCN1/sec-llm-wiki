去年，Pwn2Own举办了一场盛大的比赛来庆祝 Pwn2Own 成立 15 周年。展示的惊人研究奖励了超过 1,000,000 美元。回到温哥华参加 2023 年的 Pwn2Own。与去年类似，将在 2023 年 3 月 22 日至 24 日的CanSecWest会议上在温哥华喜来登华尔中心与大多数人亲自举行混合会议。混合活动的另一部分意味着允许远程参与。如果您有旅行限制或旅行安全问题，可以选择远程比赛。

特斯拉作为合作伙伴回归。更新了目标列表以跟上。添加了具有多个目标的Steam VM Escape类别。以电动汽车上的蒸汽机为目标可能有点奇怪。将同时提供 Tesla Model 3和Tesla Model S 作为目标，最高奖金为 600,000 美元（加上汽车本身）。当然，虚拟化漏洞利用始终是比赛的亮点，VMware作为赞助商回归，VMware Workstation 和 ESXi 作为目标回归。

还在其他现有类别中添加了几个新目标。DNS是互联网的核心服务之一，云计算离不开它。这就是将 Microsoft DNS 服务器和 ISC BIND 添加到服务器类别的原因。Apple 系统是工作中心的常见物品，因此将 macOS 添加回“本地权限升级”类别，重点放在 M 系列 MacBook Pro 上。

除了在会议上亲自尝试之外，还将制作有关漏洞利用的快速视频，因此如果不能参加，仍然可以在房间里感受一下。总而言之，参赛者可以获得超过 1,000,000 美元的现金和奖品，包括特斯拉汽车，分为以下几类：

-- 虚拟化类别
-- Web 浏览器类别
-- 企业应用类别
-- 服务器类别
-- 本地权限升级类别
-- 企业通信类别
-- 汽车类别

当然，没有加冕 Pwn 大师，任何 Pwn2Own 比赛都是不完整的。由于比赛的顺序是由随机抽签决定的，抽签不顺利的参赛者仍然可以展示出色的研究成果，但由于随后的轮次价值下降，因此获得的资金较少。然而，为每个独特的、成功的参赛作品所获得的积分不会 下降。有人可能抽得不好，但仍然积累了最多的分数。比赛结束时得分最高的个人或团队将加冕为 Pwn 大师，获得 65,000 ZDI 奖励积分（即时 白金 状态）、杀手 奖杯和一件 漂亮的 时髦 夹克 。

一起看看今年比赛的详细安排。

虚拟化类别

 VMware 再次成为 2023 年的 Pwn2Own 赞助商，今年，将再次以 VMware ESXi 和 VMware Workstation 作为目标，分别提供 150,000 美元和 80,000 美元的奖励。多年来，VMware 一直是 Pwn2Own 的赞助商，在过去几年的比赛中看到了一些很棒的研究。Microsoft 也作为目标返回并以 250,000 美元的奖励领导虚拟化类别，奖励成功的 Hyper-V 客户端来宾到主机升级。Oracle VirtualBox 以 40,000 美元的奖金在这一类别中脱颖而出。在之前的 Pwn2Own 竞赛中，已经看到一些令人惊叹的来宾到主机操作系统升级。希望今年能看到更多。

此类别中也有附加奖金。如果参赛者可以逃脱来宾操作系统，然后通过 Windows 内核漏洞（不包括 VMware ESXi）提升主机操作系统的权限，他们可以获得额外的 50,000 美元和 5 个 Master of Pwn 积分。这可能会将 Hyper-V 错误的支出推高至 300,000 美元。以下是虚拟化类别中的目标和可用支出的详细信息：

网络浏览器类别

虽然浏览器是“传统的”Pwn2Own 目标，但会不断调整此类别中的目标以确保它们保持相关性。去年重新推出了仅限渲染器的漏洞，今年，它们的价格上涨到 60,000 美元。但是，如果您拥有 Windows 内核权限升级或沙箱逃逸，您将分别获得高达 100,000 美元或 150,000 美元的收入。如果你的 exploit 对两者都有效Chrome 和 Edge，它将有资格获得价值 25,000 美元的“Double Tap”附加组件。基于 Windows 的目标将在 VMware Workstation 虚拟机中运行。因此，所有浏览器（Safari 除外）都有资格使用 VMware escape 附加组件。如果参赛者可以通过逃避 VMware Workstation 虚拟机以在主机操作系统上执行代码的方式破坏浏览器，他们将额外获得 80,000 美元和 8 个 Master of Pwn 积分。Apple Safari 和 Mozilla Firefox 仍然需要完整的漏洞利用。以下是目标和可用支出的详细信息：

企业应用类别

企业应用程序也作为目标返回，Adobe Reader 和目标列表中的各种 Office 组件再次出现。今年，还允许这些应用程序在 M 系列 MacBook 上运行。此类奖项的奖金从 50,000 美元起，用于 Reader 漏洞利用沙盒逃逸或 Reader 漏洞利用内核权限升级和 100,000 美元用于 Office 365 应用程序。Word、Excel 和 PowerPoint 都是有效目标。基于 Microsoft Office 的目标将在适用的情况下启用受保护的视图。Adobe Reader 将在适用的情况下启用保护模式。以下是企业应用程序类别中目标和支出的详细视图：

服务器类别

如前所述，通过将 ISC BIND 和 Microsoft DNS 服务器添加到目标列表来再次扩展服务器类别。成功利用其中一个漏洞，参赛者将分别获得 200,000 美元或 150,000 美元的奖金。去年将 Samba 添加为目标，但没有人接受。将在 2023 年查看是否有任何注册。此类别由 Microsoft Windows RDP/RDS 完成，它也有 200,000 美元的支出。以下是服务器类别中目标和支出的详细信息：

特权类别的本地升级

此类别是 Pwn2Own 的经典类别，专注于源自标准用户并导致以高权限用户身份执行代码的攻击。成功进入此类别的参赛者必须利用内核漏洞来提升权限。Ubuntu Desktop、Apple macOS 和 Microsoft Windows 11 是可用作此类别目标的操作系统。 

企业通讯类别

在 2021 年引入了这个类别，以反映这些工具在现代远程劳动力中的重要性，这两个目标在比赛中都受到了损害。去年的活动包括对 Microsoft Teams 的零点击攻击。此类别中的成功尝试必须通过与参赛者通信来破坏目标应用程序。一些示例通信请求可以是音频呼叫、视频会议或消息。Zoom 和 Microsoft Teams 都有 75,000 美元的奖励，因此希望在这一类别中看到更多出色的研究。

汽车类

在 2019 年推出了汽车类别，特斯拉作为合作伙伴在 2023 年回归。在第一场比赛中授予了特斯拉 Model 3，希望提高构成成功利用的复杂程度。Tesla 车辆配备了多层安全保护，对于今年的活动，汽车类别中有多个奖励等级，对应于 Tesla 汽车内的一些不同安全等级，在某些情况下还提供额外的奖励选项。参赛者可以针对 Tesla Model 3（基于英特尔或 Ryzen）或 Tesla Model S（基于 Ryzen）注册参赛作品。

第 1 层获得最高奖项，代表了完整的车辆妥协。相应的，这也是奖励金额最高的。为了赢得这一关卡，参赛者需要在车内的多个系统之间切换，这意味着他们需要一个复杂的漏洞利用链来在车内的三个不同子系统上执行任意代码。在这里的成功将获得丰厚的回报，当然还有全新的特斯拉。 

除了车辆本身和 500,000 美元外，参赛者还可以选择其他选项，将奖金提高到 600,000 美元。这代表了 Pwn2Own 历史上最大的单一目标。如果有人能做到这一点，那也意味着总共60个Pwn大师点数，这几乎是不可逾越的。以下是有关不同层级中包含的可选附加组件的一些附加信息。
