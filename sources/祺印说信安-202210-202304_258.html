Twitter数据泄露表明API是PII和社会工程的金矿

2021 年 6 月发布的一个 Twitter API 漏洞（后来修补）再次困扰着该组织。去年 12 月，一名黑客声称在暗网上出售 4 亿用户的个人数据，而就在昨天，攻击者免费公开了 2.35 亿用户的账户详细信息和电子邮件地址。 

作为泄露的一部分暴露的信息包括用户的帐户名称、句柄、创建日期、关注者数量和电子邮件地址。当放在一起时，威胁行为者可以创建社会工程活动来诱骗用户交出他们的个人数据。 

重建网络安全威胁检测和响应

虽然暴露的信息仅限于用户的公开信息，但在一个位置暴露的大量账户为威胁行为者提供了信息金矿，他们可以使用这些信息来策划高度针对性的社会工程攻击。 

推特：社会工程金矿 

社交媒体巨头为网络犯罪分子提供了一座信息金矿，他们可以利用这些信息进行社会工程诈骗。 

只需从用户的公开资料中获取姓名、电子邮件地址和上下文信息，黑客就可以对目标进行侦察，并开发有目的的诈骗和网络钓鱼活动，以诱使他们交出个人信息。

隐私事务安全研究员Miklos Zoltan 表示：“这次泄露实质上是对知名用户（也包括普通用户）的个人电子邮件地址进行 doxx，这些地址可用于垃圾邮件骚扰，甚至试图破解这些帐户。” “高利润用户可能会被大规模的垃圾邮件和网络钓鱼尝试淹没。”

出于这个原因，Zoltan 建议用户为他们使用的每个站点创建不同的密码，以降低帐户接管 尝试的风险。

社会工程和 API 黑客之间的联系 

不安全的 API 为网络罪犯提供了直接访问用户个人身份信息 ( PII )、用户名和密码的途径，这些信息在客户端连接到第三方服务的 API 时被捕获。因此，API 攻击为攻击者提供了一个窗口来收集个人数据以进行集体诈骗。 

这发生在一个月前，一名威胁行为者成功申请了FBI 的InfraGuard 情报共享服务，并利用 API 漏洞收集了私营部门 80,000 名高管的数据，并将其放在暗网上出售。 

事件期间收集的信息包括用户名、电子邮件地址、社会安全号码和出生日期等数据——所有这些对于开发社会工程诈骗和鱼叉式网络钓鱼攻击都非常有价值的信息。 

不幸的是，这种利用 API 的趋势似乎只会变得更糟，Gartner预测，今年 API 滥用将成为最常见的攻击媒介。 

超越“正常工作”的 API


组织也越来越关注API 安全，94% 的技术决策者报告说，他们对组织从实质上减少 API 数据安全问题的能力信心不足。 

从现在开始，利用 API 的企业需要更加主动地将安全性融入其产品，而用户需要格外小心潜在的恶意电子邮件。 

Jamie Boote 说：“这是一个常见的例子，说明开发人员设计为‘正常工作’的不安全 API 如何保持不安全，因为在安全性方面，看不见的东西往往是心不在焉的，” Synopsys Software Integrity Group的副软件安全顾问。“从现在开始，最好删除任何看起来像是来自 Twitter 的电子邮件，以避免网络钓鱼诈骗。” 

保护 API 和 PII 

解决 API 漏洞的核心挑战之一是现代企业需要发现并保护数以千计的 API。  

“保护组织免受 API 攻击需要对供应商管理进行一致、勤勉的监督，特别是确保每个 API 都适合使用，” ClearDATA的 CISO Chris Bowen 说。“组织需要管理的事情很多，但风险太大，不能不去管理。”

错误的余地也很小，因为单个漏洞可能会使用户数据直接面临泄露的风险。 

“例如，在医疗保健领域，患者数据受到威胁，每个 API 都应解决多个组件，如身份管理、访问管理、身份验证、授权、数据传输和交换安全以及可信连接，”Bowen 说。 

同样重要的是，安全团队不要错误地仅仅依靠简单的身份验证选项（例如用户名和密码）来保护他们的 API。 

“在今天的环境中，基本的用户名和密码已经不够用了，” Jitterbit的 DevOps、运营和站点可靠性高级总监 Will Au 说。“现在使用双因素身份验证 (2FA) 和/或 OAuth 安全身份验证等标准至关重要。”

部署 Web 应用程序防火墙 (WAF) 和实时监控 API 流量等其他步骤可以帮助检测恶意活动并减少受到危害的机会。
