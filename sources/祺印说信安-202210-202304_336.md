# 暗网工具Tor浏览器12.0带来Apple Silicon 支持和Android 增强功能

Tor 项目团队宣布发布 Tor 浏览器 12.0，这是一个主要版本，引入了对 Apple Silicon 芯片的支持以及对 Android 版本的多项增强。

Tor 是一种基于 Firefox 的浏览器，用于访问只能在 Onion 网络上访问的特殊 .onion 域，并以更多的匿名性和隐私性浏览 Web。

浏览器通过在加密网络数据的同时通过网络节点路由流量来实现这一点。连接请求通过用于将信息中继回用户的出口节点到达目的地。

## Tor 12.0 的新功能

Tor 浏览器版本 12.0 基于 Firefox 102，它是 Firefox 版本 91 的升级版，后者用作先前 Tor 版本 v11.5 的基础。

这意味着 Firefox 在新的 ESR（扩展支持版本）中实施的所有安全修复、性能增强和代码改进现在都已登陆 Tor。

Tor 12.0 的一项值得注意的新功能是引入了对 Apple Silicon 芯片（即 M1 和 M2 设备）的原生支持。

Tor 现在使用捆绑 x86-64 和 ARM64 构建的通用二进制文件，并自动为其运行的平台选择正确的版本。

原生支持 Apple 新架构的主要好处是 Tor 浏览器在 macOS 系统上的性能更好。

之前被 Tor Project 团队忽视的 Android，更新不频繁，新功能获取延迟，现在正在赶上桌面版本。

“自今年年初以来，我们的开发人员一直在努力重新开始 Android 的定期更新，提高应用程序的稳定性，并赶上 Fenix（Android 版 Firefox）的发布周期，”  Tor 的发布公告中写道。

“我们 Android 计划的下一阶段是开始将最近为桌面推出的选定的高优先级功能移植到 Android。”

Tor 12.0 版引入了首次 登陆 11.5 版桌面版的 HTTPs-only 模式，该模式使浏览器能够在可用时自动切换到所访问站点的 HTTPS 版本。

HTTPS 优于 HTTP 连接，因为站点访问者和托管站点的服务器之间的信息交换是加密的，可以防止中间人攻击和敏感数据泄露。

Android 版本的 Tor 浏览器中添加的另一个新功能是“优先处理 .onion 站点”，如果可用，它会重定向到所访问站点的“.onion”版本。新选项已添加到“隐私和安全”设置菜单中。

最后，Tor 浏览器 12.0 通过语言包下载系统添加了对英语以外的多种语言的支持，该系统取代了以前用于不同语言的专用安装程序。

这也使得安装后随时更改为不同语言或安装多个语言包并在它们之间随意切换成为可能。
