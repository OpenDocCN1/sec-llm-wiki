# 洛克希德马丁公司的陆军网络训练平台走向民用

MR2 是一个简单的概念。它是一个基于云的管理应用程序，显示为可自定义的仪表板，用于监视人员、团队、设备和基础结构的容量。但这只是触及了表面。

该技术在军事网络和通信系统之间同步。这包括非机密互联网协议路由器网络（NIPR），安全互联网协议路由器网络（SIPR）和全球联合情报通信系统（JWICS），填补了大多数现有系统的空白。它还跟踪、培训状态并为未来的任务需求提供预测分析。  

“对于我们的客户来说，将信息从一个网络传输到另一个网络是一项持续的斗争，时间始终至关重要，”Rourke 解释道。“像MR2这样的平台不仅可以让他们全面了解人员培训状态，还可以全面了解任何给定时间的人力位置。它改变了游戏规则。

## MR2的未来

洛克希德马丁公司目前将MR2能力用于美国陆军文职职业管理活动（USACCMA）。该系统将支持多达17，000名民用网络人员的网络准备和培训，并可扩展到跟踪多达100，000名人员。

“MR2令人兴奋的事情是，它不依赖于本地系统来高效运行，”Rourke说。“凭借我们的技术，USACCMA能够在Amazon Web Services govCloud上利用Ultimate Knowledge Institute和Aries Security，LLC等合作伙伴的培训工具，并将所有数据集中。我们的客户将能够保留他们使用的系统，同时推进数字化转型。

由于其许多独特且可定制的功能，它可以扩展为医疗保健、教育和商业等行业提供服务。

MR2平台在最重要的地方实现了培训管理的现代化，并帮助美国军方保持领先。

这家国防承包商将为陆军的文职职业管理活动提供其新的任务准备和报告 (MR2) 平台，该平台最初是为美国军方的联合网络指挥和控制生态系统设计的。 

洛克希德·马丁公司将 MR2 描述为“一个简单的概念”，其运行方式类似于其他基于云的管理应用程序，并将数据显示为“一个可定制的仪表板，用于监控人员、团队、设备和基础设施的能力”。 

MR2 还能够在军方的分段机密和非机密通信网络之间同步数据，并“允许网络操作员全面了解整个劳动力的能力和技能水平，无需咨询多个系统和网络，”洛克希德马丁公司马丁说。

对于陆军的民用应用，MR2 将用于“根据个人能力”对员工进行最佳实践培训，同时持续监控培训状态并为未来的任务需求提供预测分析。

洛克希德马丁公司负责网络和情报的副总裁 Tish Rourke 声称 MR2“将网络培训和任务准备联系起来，确保民用网络工作人员敏捷、有弹性并领先于威胁。”

作为与国防部交易的一部分，洛克希德·马丁公司正在与包括 IT 咨询和培训公司 Ultimate Knowledge Institute 和网络安全企业 Aries Security 在内的第三方合作，提供基于网络的培训工具。AWS govCloud 将用于托管整个操作，Lockheed Martin 将使用 MR2 分析培训数据，以解决劳动力技能发展问题。

虽然目前仅支持对多达 17,000 名文职陆军雇员进行培训，但洛克希德马丁公司表示，该系统可以扩展到跟踪多达 100,000 名人员。Rourke 表示，MR2 不依赖于本地系统，“客户将能够在推进数字化转型的同时保留他们使用的系统。”

根据洛克希德马丁公司的说法，MR2 可以扩展以服务于医疗保健、教育和商业等行业，考虑到这些行业的安全攻击状况，这可能会很方便。 

例如，医疗保健组织发现勒索软件攻击在 2020 年至 2021 年期间翻了一番，而保险和金融行业的事件也有所增加。
