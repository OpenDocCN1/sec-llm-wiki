## 第 2 步：确定组织中的关键参与者

拥有合适的人员来支持供应链网络安全将有助于推动所需的变革。考虑组织内的人员，并考虑：

1.需要说服谁来建立或改进供应链网络安全评估？

谁最适合影响变革并围绕投资和资源使用做出决策？有关更多信息，请参阅向董事会报告进度。

2.谁负责开发评估供应链网络安全的新方法？

理想情况下，这应该是具有供应链和网络安全专业知识的人或人员组合，或者具有可应用于供应链的网络安全实践的足够知识。

3.在制定这一新方法的过程中，应该咨询谁？

供应链网络安全需要多个学科之间的协作，例如 IT 安全、采购、风险管理、法律、业务利益相关者等。考虑贵公司中哪些团队参与了受此活动影响的供应商生命周期，以及他们是否可以在开发新方法中发挥作用。

4.谁应该随时了解活动？

这将包括那些不直接参与新方法的创建，但对其进展感兴趣或可能受到其影响的人。例如：

o 可以向其报告进度的领导团队成员

o 在建立新方法时可能在实施新方法方面发挥作用的同事

o 希望随时向其通报安全要求和实践的任何变化的供应商（有关应该参与的人员的更多信息，请参阅下面的“谁应该参与供应链网络保障活动？相关内容）

一旦确定了上述内容，就向影响者和决策者推销他们为什么应该投资保护供应链，把从步骤1中学到的东西。请记住，还要向可能受影响的人寻求意见。

创建可用于启动变更工作的职权范围。使用这些来了解组织的重要网络安全目标，并开始在供应链中推广安全文化，从需要了解问题的高级领导到需要共同努力以确保有效进行尽职调查的各个团队（组织和供应商方面）。

建立一个治理流程，让安全领导层定期与董事会会面，并阐明组织在供应链网络安全方面的立场，以确保充分了解供应链网络安全挑战，并做出适当的决策。

### 定义具有明确角色、职责和标准的流程

一旦确定了合适的人，就可以创建一个适合组织的流程来评估供应商。请注意，这可能涉及比用于定义方法的人更多的人。

典型阶段可能包括：

·使用问题为采购建立供应商安全配置文件

·与供应商确认其供应商安全配置文件的预期控制措施

·确保供应商完成保证问卷，以评估对控制措施的遵守情况

·与供应商合作完成供应商管理计划

·供应商管理计划中概述的对供应商的持续审查和评估

### 谁应该参与供应链网络保障活动？

可能参与评估供应链网络安全的角色（可能因组织而异和重叠）包括：

| 角色 || 描述: |
| --- | --- |
| **信息技术/网络安全** || 拥有技术专长，就供应商架构和提议的控制提供建议，并就所需的任何缓解措施提供建议。负责制定整个供应链所需的供应链安全标准和保证活动。了解采购如何适应组织更广泛的技术计划和安全计划。 |
| **采购** || 确保将供应商保证实践嵌入到采购流程中。 |
| **风险管理** || 为组织制定风险管理方法，努力确保任何第三方活动都遵循标准。 |
| **软件开发** || 了解安全软件开发的各个方面，并可以提出建议，以确保交付的产品尽早识别和解决漏洞。 |
| **信息技术工程** || 评估新硬件产品的安全性并了解应应用的配置设置。特别感兴趣的（在供应链环境中）是评估来自外部来源的组件。 |
| **法律** || 确保合同包括供应链网络安全条款和合同问题的解决方案。 |
| **人力资源** || 定义和实施背景调查和培训政策，以确保个人接受适当的供应链网络安全流程和程序的培训。 |
| **企业主** || 获取请求的发起人/所有者/最终用户。负责确保收购满足他们的需求，并可能在定义收购可能构成的风险水平方面发挥作用。 |
| **领导** || 高级领导层在为供应链风险管理提供适当的网络安全资源指导和投资方面发挥着作用。 |

#### 第 2 步：延伸阅读

# 第 3 步：了解组织如何评估风险

有效的网络安全必须适合系统、流程、员工、文化以及愿意承担的风险水平。因此，评估供应链中网络安全的方式将取决于组织如何运作、其功能以及其风险偏好。这项活动没有一种方法，企业通常有自己的方法来应对风险。首先了解组织对供应链风险的偏好与管理该风险所需的资源：

·如果在评估供应链网络安全方面几乎没有经验，可以查看第 2 阶段中的步骤执行此操作

·如果组织已经有管理网络安全风险的方法，那么应该使用它来帮助了解和管理与供应链相关的网络安全风险。
