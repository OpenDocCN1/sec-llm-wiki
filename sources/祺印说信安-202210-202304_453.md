# 美国拉拢数十个国家参加勒索软件峰会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MzU5MzQzMA==&mid=2652096665&idx=4&sn=14204228cc2a06ef0d8ff12b9c9e4070&chksm=8bbce2a0bccb6bb6fce74395790628b9ab586202f3178ed215157ec61972082fcdf6a69e557a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652096665&idx=4&sn=14204228cc2a06ef0d8ff12b9c9e4070&chksm=8bbce2a0bccb6bb6fce74395790628b9ab586202f3178ed215157ec61972082fcdf6a69e557a&scene=27#wechat_redirect)

**白宫正在召集三个国家、欧盟和大量私营部门公司，从周一开始举行为期两天的峰会，探讨如何最好地打击勒索软件攻击。**

第二届国际反勒索软件峰会将重点关注诸如确保系统更具弹性以更好地抵御攻击并破坏计划此类攻击的不良行为者等优先事项。

拜登政府的一名高级官员引用了最近的袭击事件，例如上个月针对洛杉矶学区的袭击事件，以强调问题和峰会的紧迫性。该官员在不愿透露姓名的情况下预览了该事件。

![](../Images/dc6ae2f78df3352031cac3216f738d1c.png)

计划参加此次活动的政府官员包括联邦调查局局长克里斯托弗·雷、国家安全顾问杰克·沙利文、财政部副部长沃利·阿德耶莫和副国务卿温迪·谢尔曼。预计乔·拜登总统不会出席。

参与国是澳大利亚、奥地利、比利时、巴西、保加利亚、加拿大、克罗地亚、捷克共和国、多米尼加共和国、爱沙尼亚、欧盟委员会、法国、德国、印度、爱尔兰、以色列、意大利、日本、肯尼亚、立陶宛、墨西哥、荷兰、新西兰、尼日利亚、挪威、波兰、大韩民国、罗马尼亚、新加坡、南非、西班牙、瑞典、瑞士、乌克兰、阿拉伯联合酋长国、英国和美国。

将参与的公司包括 Crowdstrike、Mandiant、Cyber Threat Alliance、Microsoft、Cybersecurity Coalition、Palo Alto、Flexxon、SAP、the Institute for Security + Technology、Siemens、Internet 2.0、Tata – TCS 和 Telefónica。
