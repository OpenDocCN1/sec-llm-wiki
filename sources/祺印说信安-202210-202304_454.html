VMware 发布9.8分高危漏洞补丁

原文：http://mp.weixin.qq.com/s?__biz=MzA5MzU5MzQzMA==&mid=2652096665&idx=3&sn=2cb41c3b978c52323d4810a9e2dd7537&chksm=8bbce2a0bccb6bb61ccdec290c9ed5ab918da640f4e8c955c5f13de08883fd0f36fb7696d022&scene=27#wechat_redirect

VMware 本周发布了针对 VMware Cloud Foundation 和 NSX Data Center for vSphere (NSX-V) 中的一个严重远程代码执行漏洞的补丁。

跟踪为CVE-2021-39144（CVSS 评分为 9.8），XStream 中存在安全缺陷，这是一个将对象序列化为 XML 并返回的开源库。

该错误会影响所有 XStream 迭代，直到版本 1.4.17（包括版本 1.4.17）。只有开箱即用的版本会受到影响，但不会影响 XStream 的安全框架设置的白名单仅限于最低要求类型的版本。

“由于在 VMware Cloud Foundation (NSX-V) 中利用 XStream 进行输入序列化的未经身份验证的端点，恶意行为者可以在设备上的‘root’上下文中远程执行代码，”VMware 在其咨询中指出。

NSX-V 6.4.x 已于 2022 年 1 月终止一般支持。VMware 表示，它通常不会在其公告中提及停产 (EOL) 产品，但在这种情况下，它已决定发布补丁，因为漏洞的严重程度。

1. 受影响的产品

·VMware 云基础（云基础）

2. 简介

多个漏洞已私下报告给 VMware。已提供更新以解决受影响的 VMware 产品中的此漏洞。

3.VMware Cloud Foundation 更新解决了通过 XStream 的远程代码执行漏洞(CVE-2021-39144)

描述

VMware Cloud Foundation 包含一个通过XStream 开源库的远程代码执行漏洞。VMware 已将此问题的严重性评估为处于严重严重性范围内，CVSSv3 基本得分最高为 9.8。

已知的攻击媒介

由于在 VMware Cloud Foundation (NSX-V) 中利用 XStream进行输入序列化的未经身份验证的端点，恶意行为者可以在设备上的“root”上下文中远程执行代码。

解决方法

笔记

·尽管 VMware 没有在 VMware 安全公告中提及停产产品，但由于 NSX-V 的严重性，产品团队已经提供了一个补丁。

·VMware 已确认针对受影响产品的利用 CVE-2021-39144 的漏洞利用代码已发布。

VMware 表示 6.4.14 之前的所有 NSX-V 版本和 VMware Cloud Foundation (VCF) 3.x 版本都会受到影响。该漏洞已在 NSX-v 6.4.14 和 VCF 3.11.0.1 的发布中得到解决。

VMware 的公告还描述了 VCF 中的一个中等严重性 XML 外部实体 (XXE) 漏洞 (CVE-2022-31678)，未经身份验证的攻击者可以利用该漏洞导致拒绝服务 (DoS) 条件或泄露信息。

根据 Tenable 高级研究工程师 Satnam Narang 的说法，该漏洞的严重性以及 VMware 选择为其发布补丁的事实可能表明它很容易被利用，并且可能很快就会观察到野外利用。

“虽然这个漏洞不在 Log4j 漏洞的级别上，但它提醒人们注意使用开源软件的供应链风险，”Narang 说。

在随附的常见问题解答中，VMware 警告说，成功利用此漏洞可能允许对 NSX-V Manager 具有网络访问权限的恶意行为者接管设备。

据该公司称，所有 NSX-V 配置都会受到影响，并且没有可用的产品内解决方法。

VMware 通过发布 NSX-V 版本 6.4.14 解决了该漏洞。该公司敦促所有客户将他们的安装升级到此产品迭代。

VMware 指出：“该安全修复仅适用于 NSX Manager，但升级到 6.4.14 涉及完全升级，因为该版本包含其他组件修复。”
