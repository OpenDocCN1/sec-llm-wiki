全文本搜索和挖掘的引擎

Elastic Search

Elastic Search（ES）是一个基于 Lucene 构建的、RESTful 风格的开源分布式搜索分析引擎，可以近实时的索引、检索数据。具备高可靠、易使用、社区活跃等特点，在全文检索、日志分析、监控分析等场景具有广泛应用。

https://www.elastic.co/cn/elasticsearch/

不仅可自定义搜索方式，执行及合并多种类型的搜索（结构化数据、非结构化数塔据、地理位置、指标），也支持分析大规模数据。由于高可扩展性，集群可扩展至百节点规模，处理 PB 级数据。通过简单的 RESTful API 即可实现写入、查询、集群管理等操作。

ES日志分析原理

（日志采集、文本解析、数据存储、可视化分析）


Open Semantic Search

https://www.opensemanticsearch.org/

Open Semantic Search是一款集成开源研究工具，用于通过语义搜索引擎和开源文本挖掘和文本分析平台搜索、浏览、分析和探索大型文档集合，集成用于文档处理的 ETL、用于图像和 PDF 的 OCR、用于人员、组织和位置的命名实体识别, 同义词库和本体的元数据管理等。主要功能有：


搜索引擎（全文搜索）：在多个数据源和许多不同文件格式中实现全文搜索。支持搜索运算符。


词库和语法（语义搜索）：基于同义词库，多语言语义搜索引擎也会找到同义词、下义词和别名。


交互式过滤器（分面搜索）：使用交互式过滤器（分面搜索）浏览结果，过滤器汇总了（元）数据概述和交互式过滤器。


探索、浏览和预览（探索性搜索）：使用命名实体的不同方面的聚合搜索结果概览来探索数据结果。通过预览、提取的文本或用于文本挖掘的单词列表来分析或查看文档集。


协同注释和标记（社交搜索和协同过滤）：使用原始内容中未包含的关键字、类别、名称或文本注释标记文档，以便以后文档管理和知识管理。


数据可视化（Dataviz）：将文档日期等数据可视化为趋势图或文本分析，例如可视化图形视图中的文字云、连接和网络，或使用地理数据作为交互式地图查看结果。


监控：警报和监视列表（新闻源）：通过监视列表随时了解来自媒体监控的新闻警报或文件共享上新文档或更改文档的活动流。可订阅搜索和过滤器作为 RSS 新闻源并接收通知。


*需要先安装Oracle VM VirtualBox，更多安装配置问题可查看：

https://www.opensemanticsearch.org/


Recoll
是一个适用于 Linux 系统的桌面搜索引擎（目前有适用于Linux、 MS Windows和 Mac OS X的版本），可根据其内容和文件名查找文档。

可搜索大多数文档格式，在GUI中提供全文搜索（从单个词到任意复杂的布尔搜索），单击即可在本机编辑器中打开文档或显示更快的文本预览。

http://www.lesbonscomptes.com/recoll/


Solr

Solr 是 Apache Solr 项目中流行的、速度极快的开源 NoSQL 搜索平台。


主要功能包括强大的全文搜索、命中突出显示、分面搜索、动态聚类、数据库集成、丰富的文档处理和地理空间搜索。Solr 具有高度可扩展性，提供容错分布式搜索和索引，并为许多世界上最大的互联网站点的搜索和导航功能提供支持。

https://solr.apache.org/



文件管理系统和内容管理工具


Zotero
Zotero是一款自由及开放源代码的文献管理软件，管理书目信息（如作者、标题、出版社、摘要、阅读笔记等）及相关材料（如PDF文件等)。

它可以作为浏览器插件，在线同步，与文档编辑软件如Microsoft Word、LibreOffice、OpenOffice.org Writer、NeoOffice等集成，可生成文内引用、生成页面脚注或文后的参考文献（bibliographies）。

https://www.zotero.org/

Document cloud
DocumentCloud 是一个多合一的文档管理系统/平台，可管理纸质文件扫描版本或者 PDF 格式文件。可上传、组织、分析、注释、搜索和嵌入。

https://www.documentcloud.org/home

Drupal CMS
Drupal内容管理系统 (CMS) 是一款软件工具（不过在业界，Drupal常被视为内容管理框架（CMF），而非一般意义上的内容管理系统）。用户可以使用智能手机、平板电脑或台式计算机上的网络浏览器添加、发布、编辑或删除网站内容，也可以让你快速便捷地以用户界面创制自己的内容格式、数据字段和表格。

Drupal（https://www.drupal.org/）



文本文件挖掘、分析

文本搜索工具 Jigsaw
想以图解的方式查看文本检索结果？Jigsaw（非开源软件，但可免费下载）可统计文本中最重要的人物、地点、组织等实体的出现频率，并将他们之间的关系以列表、图表、时间表和关系图的形式呈现出来，提高文本分析效率。

https://www.cc.gatech.edu/gvu/ii/jigsaw/

TAPoR

TAPoR是用于复杂文本分析和检索的工具的门户 ，最初创建为仅用于文本分析的工具的目录。后发展迭代到版本 TAPoR 3.0，包含更多范围的工具及代码。2018 年，TAPoR 吸收了 DiRT 项目（数字研究工具），现在包括处理非文本数据的工具和提供数字人文主义者使用的服务的工具。

https://tapor.ca/pages/about_tapor

TAPoR 3.0的主要功能有：

  • 探索文本操作、分析和可视化工具

  • 探索历史工具

  • 阅读工具评论和建议

  • 了解有关特定工具的论文、文章和其他资源

  • 协作标记、评论、评分和审查

  • 浏览相关工具列表

抽取、转换数据

ETL：抽取（extract）和清洗（cleaning），转换（transform），装载（load）

1.从网站抽取数据（网络信息采集/爬虫）

Web Scraper


Web 数据提取工具，适合数据爬取小白，是一款简单点击式界面的网络数据提取工具。Web Scraper 使用由选择器组成的模块化结构，指示抓取器如何遍历目标站点以及要提取哪些数据。由于这种结构，适用于大多数网站的数据挖掘。数据提取就在浏览器上运行，不需要安装，也不需要 Python、PHP 或 JavaScript 编码经验即可开始抓取。


可在 Web Scraper Cloud 中完全自动化数据提取。抓取数据后，将其下载为 CSV 或 XLSX 文件，可以进一步导入 Excel、Google 表格等。


Web Scraper（插件）


Scrapy
可依托 Scrapy 建立自己的网络爬虫工具，编写 Python 代码，在 Windows,Mac,Linux 和 BSD 系统上都可运行。
https://scrapy.org/

2.从文件抽取结构化数据

Tika
支持从文档和文件抽取文本和元数据。

Apache Tika™ 工具包从一千多种不同的文件类型（如 PPT、XLS 和 PDF）中检测和提取元数据和文本。所有这些文件类型都可以通过一个界面进行解析，使 Tika 可用于搜索引擎索引、内容分析、翻译等。

https://tika.apache.org/

Tabula 
Tabula可直接从 PDF 文件抽取数据表格（到 CSV 或 Microsoft Excel 电子表格中）。Tabula 适用于 Mac、Windows 和 Linux。

https://tabula.technology/

编写文件、修改元数据

Dangerzone
PDF 和办公文档可以在文档打开时自动从远程服务器加载图像，跟踪文档何时打开以及来自哪个 IP 地址，也可以包含 JavaScript 或宏，根据软件的配置方式，在打开时自动执行代码，从而可能接管计算机。同时，和其他软件一样，用于打开文档的程序——Preview、Adobe Reader、Microsoft Word、LibreOffice 等也可能存在漏洞，这些漏洞有时会被利用来接管你的计算机。

Dangerzone可在发布前安全地编辑和剥离文档中的元数据，尽可能规避上述风险。

https://dangerzone.rocks/

PDF Redact Tools
PDF Redact Tools 与Dangerzone类似。使用时将原始文档转换为PDF，然后将PDF分解为PNG文件。

https://github.com/firstlookmedia/pdf-redact-tools


MAT:
mat2 是一个元数据删除工具，支持广泛的常用文件格式，用 python3 编写。它的核心是一个库，由同名的命令行界面以及几个文件管理器扩展使用。

https://0xacab.org/jvoisin/mat2

LibreOffice Calc
LibreOffice Calc是一款与Microsoft Excel功能类似的开源表格程序，可以打开或存储为Microsoft Excel的文件格式，也可存为.pdf格式。

其具备对新手的友好性以及对专业数据挖掘者和数字计算者则喜欢全面的高级功能，可以灵活配置样式和格式及单元格格式选项，自由旋转内容、模板、背景、边框等，也可使用内置模板及场景管理器，比如可以一键进行“假设...”分析来比较高、中、低销售预测的盈利能力。

https://www.libreoffice.org/discover/calc/
