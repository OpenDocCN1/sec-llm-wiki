**全文本搜索和挖掘的引擎**  

**Elastic Search**

Elastic Search（ES）是一个基于 Lucene 构建的、RESTful 风格的开源分布式搜索分析引擎，可以近实时的索引、检索数据。具备高可靠、易使用、社区活跃等特点，在全文检索、日志分析、监控分析等场景具有广泛应用。

![](../Images/18f171120f0b11edd029455ac07f7cd7.png)

https://www.elastic.co/cn/elasticsearch/

不仅可自定义搜索方式，执行及合并多种类型的搜索（结构化数据、非结构化数塔据、地理位置、指标），也支持分析大规模数据。由于高可扩展性，集群可扩展至百节点规模，处理 PB 级数据。通过简单的 RESTful API 即可实现写入、查询、集群管理等操作。

![](../Images/c6ba622c8d1739935fe239cca3514a89.png)ES日志分析原理

（日志采集、文本解析、数据存储、可视化分析）

  
**Open Semantic Search**  

![](../Images/da9a237b95d51d69a40bd2fee857ba53.png)

## https://www.opensemanticsearch.org/

## Open Semantic Search是一款集成开源研究工具，用于通过语义搜索引擎和开源文本挖掘和文本分析平台搜索、浏览、分析和探索大型文档集合，集成用于文档处理的 ETL、用于图像和 PDF 的 OCR、用于人员、组织和位置的命名实体识别, 同义词库和本体的元数据管理等。主要功能有：

## 

  

**搜索引擎（全文搜索）：**在多个数据源和许多不同文件格式中实现全文搜索。支持搜索运算符。

### 

  

### **词库和语法（语义搜索）：**基于同义词库，多语言语义搜索引擎也会找到同义词、下义词和别名。

  

### **交互式过滤器（分面搜索）：**使用交互式过滤器（分面搜索）浏览结果，过滤器汇总了（元）数据概述和交互式过滤器。

  

### **探索、浏览和预览（探索性搜索）：**使用命名实体的不同方面的聚合搜索结果概览来探索数据结果。通过预览、提取的文本或用于文本挖掘的单词列表来分析或查看文档集。

###   

### **协同注释和标记（社交搜索和协同过滤）：**使用原始内容中未包含的关键字、类别、名称或文本注释标记文档，以便以后文档管理和知识管理。

###   

### **数据可视化（Dataviz）：**将文档日期等数据可视化为趋势图或文本分析，例如可视化图形视图中的文字云、连接和网络，或使用地理数据作为交互式地图查看结果。

  

### **监控：警报和监视列表（新闻源）：**通过监视列表随时了解来自媒体监控的新闻警报或文件共享上新文档或更改文档的活动流。可订阅搜索和过滤器作为 RSS 新闻源并接收通知。

**Recoll**是一个适用于 Linux 系统的桌面搜索引擎（目前有适用于Linux、 MS Windows和 Mac OS X的版本），可根据其内容和文件名查找文档。  
可搜索大多数文档格式，在GUI中提供全文搜索（从单个词到任意复杂的布尔搜索），单击即可在本机编辑器中打开文档或显示更快的文本预览。

**Solr**

Solr 是 Apache Solr 项目中流行的、速度极快的开源 NoSQL 搜索平台。

  

主要功能包括强大的全文搜索、命中突出显示、分面搜索、动态聚类、数据库集成、丰富的文档处理和地理空间搜索。Solr 具有高度可扩展性，提供容错分布式搜索和索引，并为许多世界上最大的互联网站点的搜索和导航功能提供支持。

# **Web Scraper**

  


**

Web 数据提取工具，适合数据爬取小白，是一款简单点击式界面的网络数据提取工具。Web Scraper 使用由选择器组成的模块化结构，指示抓取器如何遍历目标站点以及要提取哪些数据。由于这种结构，适用于大多数网站的数据挖掘。数据提取就在浏览器上运行，不需要安装，也不需要 Python、PHP 或 JavaScript 编码经验即可开始抓取。

  

可在 Web Scraper Cloud 中完全自动化数据提取。抓取数据后，将其下载为 CSV 或 XLSX 文件，可以进一步导入 Excel、Google 表格等。
