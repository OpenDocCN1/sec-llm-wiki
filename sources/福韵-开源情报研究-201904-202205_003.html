今天福韵君为大家介绍一些全球性的数据资源库，有专门报道报道世界各地有组织犯罪和腐败行为的OCCRP，“揭露”离岸公司数据的ICIJ’s Offshore Leaks，各国政府开放数据库、研究机构网站等。


写在前面：其实在我们深度调查的过程中，每一个数据源都不会直接形成最终“答案”，而是作为有效“线索”和信息，情报调查是一个系统性的工作，多方验证信息才能发挥这些数据源真正的价值。



1.OCCRP’s Investigative Dashboard

https://data.occrp.org/


OCCRP 是一个致力于报道世界各地有组织犯罪和腐败行为的非营利组织，信息专业人员包括内部专家、来自新闻机构、学术图书馆和其他地方志愿者，主动提出帮助国际记者追踪资金追踪以揭露贿赂和腐败。而这个网站是他们建立的一个在线资源中心。在这个网站里，你可以找到 93,801,673 （不断更新中）条法庭记录、法律条款、研究报告等文件。


2. ICIJ’s Offshore Leaks


https://offshoreleaks.icij.org/


ICIJ （国际调查新闻工作者联合会）由超过 65 个国家的 190 多名调查记者组成。

他们根据自2013年至今多个“离岸泄密”调查的资料，建立了一个涵盖 32 万家离岸公司的公共数据库。


Ps数据库在首页告知：“离岸公司和信托有合法用途。我们无意暗示或暗示 ICIJ 离岸泄漏数据库中包含的任何个人、公司或其他实体违反了法律或以其他方式不当行为。”因为有人指出正常经营的的企业可能也会利用离岸立法简化国际贸易手续。



3. Open Corporates


https://opencorporates.com/


该数据库是“全球最大的开放数据库”，致力于促进企业部门的数据透明度，曾获开放数据商业奖。数据库包含了 1.38 亿家企业和 1.76 亿员工的信息，而且还在不断更新。


4. OpenSpending


https://openspending.org/


使用简单且免费，目前可以搜索到 78 个国家 5900 万份政府财政记录，并支持可视化与分析。


5. Global Open Data Index


https://index.okfn.org/dataset/


集合了各国政府开放数据，比如政府预算、国家法律、空气质量、水质等等。


6. Open Data Inception Project


https://opendatainception.io/


世界各地近 3000 家开放数据门户网站，可在地图上选择不同国家查看。中国有十几个网站被收录。


7. LittleSis

https://littlesis.org/


这个以前也介绍过，我们可以找到许多关于商界领袖、政治家、金融家及其附属机构信息的数据，数据可以免费下载。


8. IATI registry


https://www.iatiregistry.org/


IATI 是一个致力于国际援助款透明化与开放化的研究机构网站，目前有 5760 个数据集。如果你想了解国际援助方面的数据，这个网站很有用。


数据源往往作为情报收集环节的“供货渠道”，有了原材料，下一步就是进行分析与研判。后期福韵君会继续为大家带来一些数据分析方面的小工具，感兴趣可以留言或私信交流。
