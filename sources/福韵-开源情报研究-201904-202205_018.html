如何更改 Jpeg、Tiff 或 RAW 图像文件格式的数据和属性？下面福韵君为大家推荐7款可以进行简单 exif 编辑的免费软件。


1.AnalogExif 

https://sourceforge.net/projects/analogexif/


AnalogExif 是一个免费的元数据编辑器，用于扫描电影和 DSC 捕获的数字图像，为 JPEG 和 TIFF 文件修改大多数 EXIF、IPTC 和 XMP 元数据标签。


  • 存储胶片相机和其他模拟设备元数据属性的设备库；

  • 用于胶片相机属性（例如胶片名称、曝光编号等）的自定义 XMP 架构和用户定义的 XMP 架构以提供额外的灵活性；

  • 批量操作（从另一个文件复制元数据，自动填充曝光数）；

  • 可自定义的支持元数据标签集。


2. ExifTool GUI 

https://exiftool.org/gui/


该软件可能是最强大的 Exif 编辑器之一。ExifTool 可在 Microsoft Windows 和 macOS 上运行，是一款功能强大的编辑器，可读取、写入和编辑各种文件中的元数据。


ExifTool 支持多种不同的元数据格式，包括 EXIF、GPS、IPTC、XMP、JFIF、GeoTIFF、ICC Profile、Photoshop IRB、FlashPix、AFCP 和 ID3，以及 Canon、Casio、FLIR、FujiFilm、 GE、惠普、JVC/Victor、柯达、Leaf、美能达/柯尼卡-美能达、尼康、奥林巴斯/爱普生、松下/徕卡、宾得/朝日、Phase One、Reconyx、理光、三星、三洋、适马/Foveon和索尼。


3. Exif Pilot 

https://www.colorpilot.com/exif.html


Exif Pilot 是一个免费的 EXIF 编辑器，可操作图像文件中的元数据。免费版本不附带批处理功能，用户需要为插件插件支付少量费用。


  • 查看 EXIF、EXIF GPS、IPTC 和 XMP 数据；

  • 编辑、创建 EXIF、EXIF GPS、IPTC 和 XMP；

  • 移除 EXIF、IPTC 标签，并清理所有元数据；

  • 添加、编辑和删除关键字；

  • 从 XML 文件导入/导出 EXIF 和 IPTC；

  • 从 MS Excel 文件导入/导出 EXIF 和 IPTC；

  • 从 CSV 格式的文本文件导入/导出 EXIF 和 IPTC。


4. EXIFManager 

https://sourceforge.net/projects/exifmanager/


EXIFManager 是一款免费软件，允许用户在 EXIF 数据中快速输入一组图片的图像描述/用户评论/作者，还可以使用 EXIF 数据和强大的格式编辑器重命名图片文件。


5. Metadata++

https://www.logipole.com/metadata++-en.htm


Metadata++ 是一个功能强大且易于使用的免费软件工具，用于查看、编辑、修改、提取、复制各种文件格式的元数据。Metadata++ 被设计为尽可能快：目录之间的快速导航、快速目录读取、面板和缩略图的快速平滑绘制。Metadata++ 是可移植的，它被配置为将所有配置和设置存储在运行它的同一文件夹中。


6. EXIF Date Changer Lite 


https://www.relliksoftware.com/exifdatechanger/


几乎所有数码相机都将各种相机设置、场景信息、照片拍摄日期/时间等记录并存储为可交换图像文件格式 (EXIF) 数据。此元数据存储在图像文件中，在将照片复制或传输到其他计算机时不会丢失或覆盖。EXIF Date Changer Lite 能够快速轻松地调整照片和扫描图像上拍摄的日期/时间。


  • 调整或设置数码照片的“拍摄日期时间”——在整个图像文件夹的几秒钟内补偿不正确的相机设置或不同的时区；

  • 处理选定的图像或批处理整个图像文件夹 - 通过选择文件夹或单个图像快速轻松地选择所需的图像。


 7. GeoSetter 

https://geosetter.de/en/main-en/


GeoSetter 是用于 Windows 的免费软件工具，用于显示和更改图像文件（例如数码相机拍摄的图像）的地理数据和其他元数据 (IPTC/XMP/Exif)。GeoSetter 的嵌入式地图在 Windows 上不起作用。


  • 读取和写入 JPEG 和 TIFF 格式以及相机 RAW 格式 DNG (Adobe)、CRW、CR2 和 THM (Canon)、NEF 和 NRW (Nikon)、MRW (Konica Minolta)、PEF (Pentax)、ORF (Olympus) , ARW, SR2, SRF (Sony) and RAF (Fujifilm), RW2 and RAW (Panasonic), RWL (Leica)；

  • 使用 Phil Harvey 的 ExifTool 写入数据；

  • 在嵌入式谷歌地图上显示现有的地理坐标、图像方向和轨迹（需要互联网连接）；

  • 使用嵌入式 Google Maps 地图（需要互联网连接）或直接输入坐标和高度的已知值来设置地理数据；

  • 自动填写位置 IPTC 字段和海拔值（需要互联网连接）；

  • 可编辑的 IPTC 数据 (IPTC-NAA/XMP)；

  • 可以更改图像的拍摄日期；

  • 与轨道文件同步（NMEA、GPX、PLT、Sony LOG、IGC 等）；

  • 与已标记地理标记的图像与好友图像同步（例如，在 RAW 图像与其对应的 JPEG 图像之间）；

  • 谷歌地球导出。
