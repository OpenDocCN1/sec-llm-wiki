【情报工具】社交媒体的“别样”用法

当我们对某个不熟悉的国家或地区的某处地域进行调查的时候，一般会使用Google Earth、Bing 的 Birds Eye View、Sentinel Hub等工具，来查看该地区的卫星图像或街景图像。


但是如果你调查的区域显示没有卫星/街景图像或者是非常旧的图像，该怎么办呢？


今天，福韵君教你一招，通过一些常用的社交媒体或许能提供一些新鲜的素材。


1.Facebook 


使用 Facebook 中的搜索栏输入感兴趣的位置，在左侧菜单中选择“地点”类别以查找任何国家、地区、城市或实际位置（如餐厅或旅游景点）。


如果有任何在该位置拍摄的照片或视频，这将显示在搜索结果中。单击位置名称以查看其他信息（例如营业时间或活动）。


如果你想专门寻找在某个地点拍摄的任何帖子、照片或视频，在搜索栏中输入位置名称，然后选择“帖子”“照片”或“视频”类别，然后使用“标记位置”过滤器，输入用于标记帖子、照片或视频的位置名称。


在右侧地图上搜索位置（或在左侧框中输入坐标），选择一个仪表范围，然后按“搜索”，该特定位置附近的所有位置页面的列表将出现。


如果在 Facebook 页面上找不到足够的图像？看看 Facebook 位置是否也可能是 Instagram 位置呢？我们可以找到 Facebook 位置并复制 ID 号（显示在 URL 末尾或在源代码中搜索“id”（包括参数））。


现在复制 ID 并将 ID 粘贴到以下 URL 中（将“PasteIDHere”替换为 ID）：

https://www.instagram.com/explore/locations/PasteIDHere


现在你就能够看到阿姆斯特丹的 Instagram 页面。当然还可以尝试查看 Instagram 位置是否也可能是 Facebook 位置。复制 Instagram 位置的 ID（显示在位置 URL 的末尾）并将其粘贴到“facebook.com/”后面。


这仅在位置以某种方式连接时才有效。因此，并非所有 Facebook 位置都链接到 Instagram 位置。但绝对值得一试！



2.Instagram


要搜索 Instagram，最好使用帐户登录。使用顶部的搜索栏搜索您要查找的特定位置。如果有位置，在搜索结果中看到一个大头针图标提示位置。单击结果以查看标记有该位置的前 9 篇文章，然后进一步向下滚动以查看任何其他最近的文章。


如果你想查看旧帖子，例如，某个地点在因任何原因被摧毁之前的样子的帖子？使用OsintCombine Instagram搜索引擎在Instagram 上查找某个位置的旧帖子。



在右侧或左侧框中搜索位置。复制该特定 Instagram 位置的 URL 并将其粘贴到“查找照片：”框中。选择你希望查看其帖子的日期。（请记住，Instagram 于 2011 年 8 月上线，因此在该日期之前不会有任何帖子）。


当你看到结果页面时，请确保向下滚动到“最近”部分，以便查看该特定日期的照片。


另一种选择可能是探索某个国家或城市中可能存在的地点类型。登录 Instagram 并导航至https://www.instagram.com/explore/locations/，这是 Instagram 大部分已知位置的概览，单击感兴趣的位置以查看任何相关帖子。



3.YouTube


即使 YouTube 视频没有 GPS 位置，标题或描述中也可能包含位置名称。使用 YouTube 中的搜索栏查看是否有任何与您感兴趣的地方相关的视频。


想要得到更多结果，还可以将你想要搜索的地点与“行车记录仪”“网络摄像头”或“无人机”等词结合起来，看看是否有人可能拥有来自道路或天空的特定镜头。



4.Snapchat


使用map.snapchat.com 时，你可以查看由 GPS 标记到某个位置的公共可用快照。尽管大多数 Snap 只能“存活”24 小时，但还可以找到感兴趣区域的一些镜头，可以滚动并移动鼠标以放大。



5.推特

 

尽管 Twitter 是基于文本的，但我们也可以在推文中或作为推文上传图像，可以使用 Twitter 搜索栏搜索标记为你感兴趣的位置的推文。


使用以下搜索来查找任何标有特定 GPS 位置的媒体项目（注意：逗号之间没有空格！）：geocode:longitude,latitude,radius filter:media

geocode:longitude,latitude,radius filter:media


例如：如果你想在巴塞罗那 50 公里半径内搜索推文，这就是搜索的样子。


如果你对最近的推文感兴趣，请确保选择“最新”。如果你对特定日期感兴趣，可以单击搜索栏右侧的三点菜单，然后选择“高级搜索”以填写确切日期。
