# 人物说 | 帕梅拉·皮吉恩：“隐身”76年的英国首位女情报官

 **// 前言//**  

每一个领域，都拥有百千风流人物。

从开源网络情报诞生至今，亦不乏惊艳卓绝之才。故此本号特设「人物说」专栏，以收录近当代互联网翘楚，道尽情报界“风流人物”。

本期「人物说」将给大家介绍英国首位女情报官——**帕梅拉·皮吉恩。**

  

![](../Images/0872d6068d8ba09947dfd9cc82c06ed9.png)

英国情报基地首位女指挥官

  

1943 年，在英国乡村一个不起眼的小镇上，一名新西兰人悄悄创造了历史，她成为英国情报基地的首位女指挥官。

  

直到现在，她依然默默无闻，在历史的尘埃中，她“隐身”了 76 年。

  

![](../Images/96c037510fd8a090af3a04d34d26ec95.png)

Pamela Pigeon（中排中间） 图源：GCHQ

  

2019年11月3日，英国间谍机构 GCHQ 发布了有关 Pamela Pigeon 的英雄事迹，以纪念机构成立100周年。正因如此，Pamela Pigeon 隐藏76年的间谍身份才让世人所知。

在英国，政府通信总部 ( Government Communications Headquarters，缩写为 GCHQ) 是一个情报机构和国家安全机关，向外交大臣负责，惟不隶属于英国外交部。和英国安全局（MI5）、秘密情报局（MI6）一同受到联合情报委员会（JIC）的领导。主要职责是向英国政府和英军提供信号情报和信息保障。

  

政府通信总部的前身是创建在第一次世界大战时的政府密码学校，于1946年进行改组。在第二次世界大战期间，学校迁入布莱切利园，进行对德国英格玛机的破译工作。2013年，美国国家安全局外判技术员爱德华·斯诺登披露，英国政府通信总部通过颞颥计划收集英国境内所有的互联网和电话数据。这引发了民众对政府监控的担忧。

![](../Images/53b1f5dfcfd12f34284d4e9f4cb42e39.png)

GCHQ的总部大楼，昵称为“甜甜圈”（"The Doughnut"）

  

在一战期间，英国陆军和英国皇家海军各自拥有自己的信号情报部门。1919年，由寇松侯爵为主席的内阁情报委员会建议和平年间的密码破译部门应当成立。结果是陆军和海军的信号情报部门合并成一个新的机构，被命名为政府密码学校（Government Code and Cypher School, GC&CS）。这个新的机构在1919年11月1日正式宣告成立。

  

布置在远东的外设机构于1935年在香港成立，1939年迁至新加坡。随后因为日军在马来半岛长驱直入，机构内的陆军和空军的破译人员加入设置在印度德里的无线电试验中心，海军的人员则先在科伦坡落脚，后来迁至肯尼亚。

  

政府密码学校在1946年的6月更名为“政府通信总部”，并沿用至今。

  

而 Pamela Pigeon 就是英国“政府通信总部”的元老间谍，曾担任其最高级别的女情报指挥官。Pamela Pigeon 出生于英国，曾就读于惠灵顿玛格丽特女王学院，从小便有过人的语言和演讲天赋，其父亲是 1902 年移民到新西兰的外科医生。

1924年，年仅6岁的 Pigeon 在一次化妆舞会上因扮演一位“穿着粉色和白色衣服的英国老太太”而获奖；19年后的她成为了英国首位女情报官，负责追踪纳粹军队的行动。

  

在惠灵顿长大的 Pamela Pigeon 是英国最高级别的女情报官员，她曾指挥一个由无线电操作员组成的单位，在二战中为击沉德国臭名昭著的战列舰“俾斯麦”号立下汗马功劳，那个时候她年仅25岁。

  

25岁时，她指挥了一个由语言学家组成的绝密小组，他们通过短波收听德国海空军的广播。为了防止德军轰炸，这次行动是在散布于乡间的一系列不起眼的木屋中进行的。

  

无线电操作员可以观察到敌方无线电的独特“指纹”，通过人们输入摩斯电码的速度做出判定。一旦识别出，情报人员就可以立即分辨出来者是轰炸机还是战斗机，而不需要解码任何信息。一旦确定了敌方操作人员，这些信息就可以用来拼凑出对方部队的行动。

![](../Images/0741bee87fb5b43c10611204aa81a51a.png)

俾斯麦号于1940年  图源：维基百科

  

正是这个无线电网络，定位到了德国头号战舰“俾斯麦号”，并帮助英军将其击沉。“俾斯麦”号在一次海战中受损，当时它正前往维希法国的一个港口，但它发出的无线电信号被英国截获。在 Pigeon 团队的帮助下，英国皇家海军准确定位“俾斯麦号”所在的位置，将其一举击沉。

军事历史学家伊恩·麦克吉本说，像 Pigeon 这样的“无名英雄”的密码破解工作对于赢得这场战争“至关重要”，特别是在大西洋之战中。Pigeon 带领的绝密小组主要通过代码破解和无线电指纹识别来击败德国潜艇威胁，同时对西部非洲沙漠的作战行动产生了至关重要的影响。

![](../Images/c0b464239dad2ec1d6c5b000b0e9918b.png)《模仿游戏》

  

最著名的密码破解操作是在布莱奇利公园（Bletchley Park）乡村庄园进行的，这是由艾伦·图灵（Alan Turing）领导的秘密机密行动，在2014年模仿本尼迪克特·坎伯巴奇（Benedict Cumberbatch）和凯拉·奈特利（Keira Knightley）主演的电影《模仿游戏》中获得了不朽的胜利，英国最聪明的人都在努力破解密码破解程序，德国的U型潜艇 Enigma 机器。

  

在过去的一个世纪里，GCHQ 组织拯救了无数人的生命，但由于工作的机密性质，使得历史上的关键人物往往被人们忽视。像 Pigeon 这样在战争背后默默努力的“无名英雄”还有很多，而他们都慢慢湮没在历史长河之中。
