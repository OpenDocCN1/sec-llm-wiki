如何复原电子设备被删除的数据？

老规矩，墙裂建议收藏：

互联网的迅猛发展让电脑等电子设备的使用进一步得到普及，这些电子设备在给人们的工作、生活带来便利的同时，也带来了诸如信息泄露、数据被盗等许多安全隐患。而其中，最令人烦闷的便是由于个人失误造成的数据丢失的问题。

相信很多朋友都有过一不小心把电脑硬盘、U盘、移动硬盘或储存卡里的重要文件资料、照片、视频误删经历，有时甚至连回收站也清空了才惊呼，“啊，我的文件！”。


误删的结果不仅会影响工作，甚至可能会造成重大经济损失，让人悔不当初。

从根源上讲，福韵君建议大家一定要养成备份重要资料的习惯，尤其是需要经常跟文档资料打交道的职业，有备才无患。

但万一误删又没有备份，该怎么办呢？那就要求助数据恢复软件了。

首先，我们来了解一下数据恢复软件的工作原理。

为了整个系统的效率，Windows操作系统在真正删除一个文件时（比如从回收站里面清除一个文件），并不是从磁盘记录中直接抹去这个文件的所有数据，它只是将这个文件所在的磁盘位置标注为已删除。当再次需要用这些磁盘位置来记录其他数据的时候，新的数据就会直接写在这些位置上，原来的数据就会被覆盖。


显然，假如一个文件被删除之后，它所在的磁盘记录还没有被写入其他数据，那么这个文件的数据其实一直都还存在着，只是操作系统“假装”没有认识它们而已。

因此，数据恢复软件的工作原理便是：绕过操作系统，直接从磁盘里将那些被标记为“已删除”的文件数据重新读取出来，恢复到指定的目录下。

但互联网上的资源错综复杂，良莠不齐，数据恢复软件也是层出不穷，收费的、免费的、绿色免安装版、广告软件打包下载版、甚至还有带木马病毒的，难以甄别、防不胜防。

No.1 DiskGenius

第一款要给大家介绍的就是DiskGenius，它是一款专业级的数据恢复及硬盘分区管理软件。


它支持多种情况下的文件丢失、分区丢失恢复；支持文件预览；支持扇区编辑、RAID恢复等高级数据恢复功能。此外还有分区备份、分区还原、分区复制、磁盘复制等功能。

比起其他软件来说，DiskGenius更加全面、专业，同时它也是一款强大的硬盘分区工具和备份、还原工具。

最为重要的是，DiskGenius有绿色安全、免安装、免注册的版本可以使用，方便快捷，也是最为推荐大家使用的文件恢复软件。



No.2 金山数据恢复


第二款要给大家介绍的就是金山数据恢复，它是一款功能强大的数据恢复软件，能强力恢复各种原因丢失的数据。


包括删除文件恢复、误格式化恢复、病毒感染丢失文件恢复、U盘/手机相机卡恢复、误清空回收站恢复、磁盘分区丢失恢复以及手机内置卡恢复等，可以恢复多种格式文件，包括文档、视频、照片、软件、压缩包等等。


虽说金山数据恢复功能强大，但对用户是有要求的，必须是付费会员才可以，遇到紧急情况需要处理可以去某宝买一个会员账号。


No.3 Windows File Recovery

Windows File Recovery是一款微软官方推出的免费命令行数据恢复软件，支持多种文件系统（比如NTFS、exFAT、FAT、ReFS），可对多种文件格式（比如照片、视频、文档等等）进行恢复。



比方说你可以用它恢复HDD（硬盘）上的已删除文件，或者恢复闪存（如U盘、内存卡）、SSD（固态硬盘）上的已删除文件。不过由于SSD的特殊机理，通常成功恢复的机率会低一些，这一点也是和其他数据恢复软件一致的。



Windows File Recovery支持三种恢复模式，分别是：普通、分段（segmentmode）、签名（signature mode），各模式使用场景如下：


普通模式：用于最近删除过的文件恢复，支持文件格式为NTFS。

分段模式：用于恢复已删除一段时间的文件，或者对已经格式化过的磁盘执行恢复操作。

签名模式：针对FAT、exFAT、ReFS等文件系统恢复，此外如果其他恢复模式不顺利，也可用这个模式试一试。


恢复过程视文件多少而定，通常会有几秒或几分钟时间。命令完成后，将在目标磁盘上建立一个恢复文件夹（自动建立），所有恢复文件会被放置到这里。此外软件还会在恢复完毕后生成一份恢复报告，当然你也可以选择不生成。



为便于用户掌握，微软还专门提供了一个命令说明网页，以便新手熟悉，如有需要大家可以去官方自行下载阅读。



那么，假如在恢复数据之前，存储这个文件的磁盘空间被写入了其他数据呢？

那么福韵君只能很遗憾地告诉你，被误删的文件可能会被破坏，数据恢复软件只能尝试进行修复，但很可能会出现恢复失败的情况。

因此，为了最大限度的提高文件恢复的成功率，在找回文件前我们需要尽量做到以下几点：

① 在文件恢复之前，要尽量避免文件覆盖。

这是文件恢复专业技术人员最常给的一个忠告。事实上，当你删除了某个文件或文件夹，它只是在存储设备中被标记为“删除”状态，也就是说，它是隐形存在的。如果你想把它找回来，那么就要尽力确保它隐形时所占的空间没有被新文件覆盖，这样才有较大的成功率。

② 不要将文件恢复到原有的磁盘上。

也就是说，如果你想恢复某个硬盘上的文件，就不要再对该硬盘写入新的文件，哪怕是你想下载文件恢复工具，也切不可保存在这个路径上。其中的道理与上述的文件覆盖相似。

③ 禁止做磁盘检查或格式化。

不论是进行磁盘检查，还是格式化，事实上都是一个文件写入的过程。一般来说，进行格式化操作后，系统会写入一串“0”，它们也会把“隐形的它”所占有的空间占为己有。

④ 选择专业而合适的文件恢复工具。

一般来说，专业的文件恢复工具功能较为齐全，且恢复能力较好，能够确保所恢复的文件是有效的。但在使用工具之前，要先了解清楚所要使用的文件恢复工具是否能够支持你所使用的操作系统。

⑤ 选择专业的文件恢复工具且要正确操作。

误操作很可能会对文件造成二度破坏，那么恢复的可能性就降低了。

⑥ 操作过程中不能断电。

这是一件极为细微的事情，也是一件存在一定无法预测性的事情，但是，倘若是文件恢复过程中，电源被强制切断，文件受损的程度将比原来要大很多。

最后还是那句话，对于重要的文件保存一定要从备份开始进行保护，良好的备份习惯是避免文件丢失的保障。

作为文件保存的最后一步抢救措施，文件恢复也能极大挽回我们的损失，而且越多的了解以上的文件恢复知识，方能帮助我们把损失降到最小。
