# 人物说 | 胡安·普约尔·加西亚：拥有28个身份的神秘特工“嘉宝”

每一个领域，都拥有百千风流人物。从开源网络情报诞生至今，亦不乏惊艳卓绝之才。故此本号特设「人物说」专栏，以收录近当代互联网翘楚，道尽情报界“风流人物”。本期「人物说」将给大家介绍一位西班牙著名特工——**胡安·普约尔·加西亚**。![](../Images/9af5bb85da3f5d34e44a5d66373df869.png)二战时期著名双重特工曾被希特勒授予“铁十字勋章”同时被乔治六世授予“大英帝国勋章”

 

  

*即使不被接受，也要“为了人类的利益”奋斗*

*从此他成为了史上最传奇的双面间谍*

  

  

二战时期，曾经涌现出一批优秀的双面间谍，他们以德国间谍的身份同时为联盟军国效力，以套取情报并误导敌军，为人类反法西斯战争的胜利做出了杰出的贡献，却因为特殊时期的顾虑而被埋没在历史的河流中。而在这些伟大的特工中，普约尔无疑是最神秘而传奇的一个。

  

**早年生活**

胡安·普约尔·加西亚（Juan Pujol García），1912年出生在巴塞罗那，他的母亲加泰罗尼亚人琼·普约尔·佩纳来自一个严格的罗马天主教家庭，每天都会参加聚会，但是他的父亲梅塞德斯·加西亚拥有自由的政治信仰。

  

普约尔是家里的第三个孩子，7岁时就被送到了Valldemia寄宿学校，并在那里度过了4年的时光。13岁时，经由父亲的某个牌友，他被转入巴塞罗那的一所学校，又在那里住了三年，在一次与老师发生争吵后，普约尔决定离开学校，成为了一家五金商店的学徒。

![](../Images/94b17949ded730c3715077c6528f33e3.png)

图片来源：ABC CULTURA

  

在西班牙内战前后，普约尔从事过各种职业，例如在滨海阿雷尼斯的皇家家禽学校学习畜牧业，并管理包括电影院在内的各种业务。1931年，普约尔在第7轻炮兵骑兵部队中服了六个月的义务兵役，但他厌恶骑马，并认为自己缺乏“忠诚，慷慨和荣誉的基本素质”，因此并不适合从事军事事业。

![](../Images/864f1e518256ff293febb1c2180017d6.png)

内战前与一些朋友 图片来源：EL DIARIO VASCO

  

1931年第二共和国成立后数月，普约尔的父亲不幸去世，之后他以家禽养殖者的身份完成学业，并在塞罗那以北的家禽养殖场从事管理工作。

  

  

**西班牙内战风波**

  

1936年，西班牙内战爆发，普约尔姐姐Elana的未婚夫被共和党军队带走，随后姐姐和母亲一起被指控为反革命分子而被逮捕，直到一个工会的亲戚将他们解救出来。

  

普约尔被共和党强制征兵，但他由于家人的遭遇而拒绝，并逃到了女友家中藏了起来，直到被警方突袭抓捕。在入狱一个星期后，他被Socorro Blanco抵抗组织营救出来，他们帮助他伪造了文件，证明他年龄已过服役年纪，使他得以在共和党军队中担任退伍军人，这是实现他转入国民党目标的前一步。

  

随后，普约尔再次使用伪造的证件重新加入了共和党军队，自愿在前线附近铺设电报电缆，以求尽快离开军队。1938年9月，在埃布罗（Ebro）战役中，他设法逃到了民族主义一方，然而由于不喜欢他们的法西斯主义，普约尔再次遭到国民党的虐待。

  

这些经历导致了普约尔对法西斯主义和共和主义的失望，也因此对纳粹德国和苏联都深感厌恶。

  

1939年，从国民党军队退伍后，他在布尔戈斯（Burgos）遇到了他的第一任妻子阿拉西里·冈萨雷斯（Araceli Gonzalez），他们在马德里结婚并有个第一个孩子琼·费尔南多（Joan Fernando）。

![](../Images/9a1ffeeb4b23c550eadf1323e0227d0f.png)

图片来源：维基百科

  

阿拉西里对普约尔的前期自发行动的间谍职业生涯起到了非常重要的辅助作用，甚至在他对英国情报部门提出的许多建议中担任使者，但遗憾的是，最终她厌倦了身为间谍的生活方式，极力离开了普约尔。

  

  

**德国“伪间谍”**

1939年第二次世界大战爆发时，普约尔因反对西班牙政府，以及想“为人类利益而战”而采取了行动，决定为英国工作。但是，他（身体上）不适合（积极地）参加战争，所以决定尝试从事间谍活动。1941年，普约尔曾三度试图与马德里和里斯本的英国当局接触，但由于没有这份工作的经验，均遭到拒绝。最后，普约尔决定成为德国间谍，然后再次联系英国获取双重间谍的身份。

  

他伪造了一个狂热的亲纳粹西班牙政府官员的身份，并欺骗印刷商他在西班牙大使馆工作，从而获得了伪造的西班牙外交护照。之后他与德国情报机构Abwehr的特工Friedrich取得了联系，尽管英语不流利，他仍旧说服了纳粹高级官员，被招募为特工并取得“Alaric”的代号。德国政府同意对他进行培训，并给了他42,000美元，并指示他搬到英国并招募英国特工网。

![](../Images/74fad79e7cdb4a4ea1621843585f31dc.png)

图片来源：英国国家档案馆

  

在搬到里斯本后，普约尔利用了英国的旅游指南、里斯本公共图书馆的参考书和杂志、在电影院中看到的新闻报道等等信息创建了貌似可信的来自伦敦的报道。在葡萄牙期间，他声称自己正在英国旅行，并根据英国铁路指南中列出的票价提交了旅费。他创建了一个遍布英国不同地区的虚构的子代理商网络，给德国发送了无数“仿真”情报。

  

事实上，由于当时没有真正访问过英国，普约尔的情报中有过一些明显的错误，譬如他声称在英国访问时发现男人们“愿意为一公升葡萄酒做任何事情”，但正确应该是啤酒或威士忌，所幸纳粹也并没有发现这个问题。

  

  

**英国“真间谍”**

  

终于，英国超通信拦截计划了普约尔的情报，在花费了资源试图追捕普约尔及实际并不存在的情报组织后，英国意识到了这是其刻意对德国的误导，并意识到了这项举措的价值。

  

1942年，普约尔再次向英国官员表明双重间谍身份的意愿，军情六处官员德斯蒙德·布里斯托（Desmond Bristow）对普约尔进行了安全检查，并推荐他和军情五处（MI5）官员汤玛斯·哈里斯（Tomás Harris）（西班牙语流利）合作。4月24日，普约尔移居英国伦敦，他获得了“Garbo”的代号。

  

到1944年为止，普约尔和哈里斯共同创造了不少于27个子代理，每个子代理都有完整的故事，虚构的人物包括格拉斯哥的委内瑞拉人、卑鄙的美国陆军中士和威尔士民族主义者等。

![](../Images/bf1186ce16f6417f8a61500a3c11a3dd.png)

图片来源：维基百科

  

他们共同写了315封信，平均2,000字，写给德国人在里斯本提供的邮局。根据《第二次世界大战英国情报机构官方史》的报道，他虚构的间谍网络是如此高效且冗长，以至于他的德国操作人员不知所措，并且没有进一步尝试在英国招募其他间谍。

  

  

**逆转二战局势**

  

1944年1月，德国人告诉普约尔，他们认为欧洲即将进行大规模入侵，并要求及时通报。这次入侵事实上就是盟军的“霸王行动”，而盟军准备将计就计，在计划入侵诺曼底海滩的过程中，必须要误导德国领导人以为登陆将发生在多佛海峡，而这次误导德军的行动被称为“坚毅行动”。

  

为了提高普约尔伪造的情报组织的可信度，他们决定提前告知德国人入侵诺曼底的一些真实但已经过时的时机和细节。在1944年1月至登陆日之前，普约尔发送了500多条广播消息，有时每天发送超过20条消息。战后对德国记录的检查发现，在“坚毅行动”期间，俄克拉荷马州情报摘要中包含不少于62份普约尔的报告。

  

最终，作为“Alaric”，普约尔因对德国战争的贡献而被授予“ 铁十字勋章”二等奖，该奖项通常保留给前线战斗人员，并且需要希特勒的个人授权。战争结束后，普约尔从他的一位德国商人那里获得了实物勋章。

![](../Images/c28698b46f279c040a72f2d7e601aba4.png)

图片来源：RTVE.es

  

作为“Garbo”，他于1944年11月25日被安全局局长David Petrie爵士大英帝国勋章。1945年欧洲战争结束后，普约尔继续为MI5工作，以调查德国是否有任何计划复活第四帝国。

  

  

**后期生活**

  

第二次世界大战后，普约尔带着妻子和三个孩子一起搬到了委内瑞拉，但由于无法摆脱婚姻磨难，1947年阿拉西里与普约尔离婚，带着三个孩子返回了西班牙。1949年，普约尔担心会遭到纳粹报复，在MI5的帮助下前往安哥拉制造了疟疾的假死事件，一年后，英国特使向西班牙通报了普约尔的死讯。

  

随后，他搬到委内瑞拉的拉古尼拉斯，以相对匿名的身份经营书店和礼品店，还借助眼镜和胡须改变了自己的容貌。

![](../Images/6e15998b81191d531c8f65938b9b66cb.png)

图片来源：First Run Features

  

普约尔后来与第二任妻子卡门·西莉亚·阿尔瓦雷斯（CarmenCilia Alvarez）结婚，两人育有两个儿子和一个女儿，不幸的是，这个小女儿年仅20岁便去世了。

![](../Images/dba006efd602c12b1da06c7544561581.png)

与第二任妻子卡门·西莉亚·阿尔瓦雷斯及其儿子

  

1971年，英国政客鲁珀特·阿拉森（Rupert Allason）以笔名奈杰尔·韦斯特（Nigel West）写作，对特工“Garbo”的故事产生了兴趣。他采访了各种前情报官员，但没人知道“Garbo”的真名，唯一的线索是有特工将“Garbo” 称为“琼（Joan）或何塞·加西亚（Jose Garcia）”。

  

阿拉森的调查就一直停滞不前，直到1984年3月，当时曾在西班牙服役的一名前MI5军官提供了普约尔的全名。阿拉森立即聘请了一名研究助理，给巴塞罗那电话簿中的每个加西亚打电话，最终才联系了普约尔的侄子。

![](../Images/38ff0e73c090ca94a619dc82819d3f95.png)

D日40周年，普约尔与前同事一起（左二）

  

1984年5月20日，普约尔和阿拉森终于在新奥尔良见面。在诺曼底登陆40年周年时，在阿拉森的敦促下，普约尔前往了伦敦，在白金汉宫被菲利普亲王接见，他才同意公开了自己的故事。

  

1988年，这位“死而复活”的传奇特工在加拉加斯逝世，享年76岁。在D日75周年的时候，关于“特工嘉宝”的事迹再次被宣扬，“西班牙电视二号”在Documentos Tv上播出纪录片向这个双重间谍致敬，该纪录片的名称是“FORTALEZA”。
