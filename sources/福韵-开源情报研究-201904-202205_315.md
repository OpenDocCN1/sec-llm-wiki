# 起底FPX ：世界冠军的背后究竟是谁？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NTg4Mzc0MA==&mid=2247485539&idx=1&sn=d97b60ab837e8489fba5d7d76739ee39&chksm=fd828150caf50846a9a2bd60999896c6fc5e2dbc65bf194f75a27dcd7ed778eb44983cf4b501&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU4NTg4Mzc0MA==&mid=2247485539&idx=1&sn=d97b60ab837e8489fba5d7d76739ee39&chksm=fd828150caf50846a9a2bd60999896c6fc5e2dbc65bf194f75a27dcd7ed778eb44983cf4b501&scene=27#wechat_redirect)

![](../Images/87a510f66c871dabbbe11d75ff49caaf.png)  
**凤凰涅槃，出道即巅峰！**11月10日晚8点，英雄联盟S9总决赛在巴黎开赛。  
23:20分 ，FPX 3-0成功拿下了“电竞世界杯”S9总冠军，成为继IG战队之后，中国区第二支在S赛上拿下总冠军的队伍。作为一支新兴战队，FPX在总决赛的表现堪称势如破竹，甚至有人评价“FPX完成涅槃神话，这一战打出了中国电竞的统治力”。![](../Images/9e21632862d6366865b32d4eb599e1f6.png)

  

中国电竞粉丝们掀起了狂欢，热搜话题层出不穷，“FPX夺冠”成为与“双11”流量匹敌的热门话题。不论之前喜欢的是哪支战队，这一刻，所有中国电竞粉丝都与有荣焉。  
  
对于去年被IG战队圈粉的电竞“伪粉”小福妹而言，在疯狂为“小凤凰”打call的同时，内心蠢蠢欲动的“深扒欲”又冒出了头。FPX究竟是一支怎样的队伍？是谁支撑着这支新兴队伍走到最后？今天，小福妹就带领大家一起揭开这支冠军队伍的神秘面纱 。  
  
**FPX从何而来？**首先，小福妹凭借开源网络情报技术，对FPX电竞俱乐部进行了一波深入调查。  
据调查，FPX（FunPlus Phoenix）电竞俱乐部又称趣加电子竞技俱乐部，成立于2017年，LPL联盟成员之一，旗下有英雄联盟分部、绝地求生分部。在对其所属公司的调查中发现，FPX电竞俱乐部的所属公司在对外公布的资料上出现了三个不同的信息源。![](../Images/6407131dc4a6c9c50d64912a59113b48.png)

数据源：360百科

![](../Images/bbe6aebdec19af8ab4afb31c0af425ac.png)

钟英武采访中提到FPX背后的资本来源为FunPlus互动娱乐公司（中文名为：趣加）

![](../Images/f76a5d7a82884a62dd7a957b64b8b1c0.png)  
因此，小福妹对相关的这几家公司进行了关联关系调查。结果发现，北京云如斯科技有限公司目前已经注销，但公司曾经的股东与北京趣加科技有限公司完全一致。![](../Images/ad7f90b5bbcb6be0464886415232cb69.png)

  

再进一步调查发现，北京趣加科技有限公司其实隶属于趣加集团。趣加FunPlus是一家全球性的互动娱乐公司，成立于硅谷，总部在北京，是FPX电竞俱乐部的创立投资方。![](../Images/573c75b3215ff7644274ff3cea89890b.png)

  

而上海翻盘侠文化传播有限公司又名趣加体育，法人为李淳，由一家香港企业独家控股，企业名称为FunPlus Esports Hong Kong Limited，可以推测同样为趣加集团分支。![](../Images/2bafd25e2af2d108b1b5ad9ae1927312.png)

  

基于以上信息，小福妹整理关联图如下：![](../Images/5bd1cd468b5253f2b0ff77d90550707f.png)

  

调查到这里，结果其实已经十分明了，FPX的背后“金主”究竟是谁，大家请自行解读咯~  
  
**FPX的老板是谁？**在夺冠的兴奋慢慢冷却之后，大家一定会十分好奇，这个组建不满2年、第一次参加世界赛就能抱回冠军奖杯的队伍，背后的大Boss究竟是谁呢？会不会成为另一个“国民老公”王校长呢？  
为了满足大家的好奇心（绝对不是小福妹自己好奇哦），小福妹又展开了调查，结果显示，FPX电竞俱乐部的背后的大老板名叫钟英武，英文名AndyZhong，也就是我们上文提到的趣加集团的创始人。  
据调查，钟英武于2006年毕业于大连理工大学，之后在极负盛名的Maharishi大学获得管理学硕士学位。他曾先后担任贝尔实验室搜索工程师（2005年-2006年）、RockYou公司技术产品总监。![](../Images/18d30e317b9e71052939aaac4a94e30e.png)

![](../Images/2ef3cf754f8342be78799d04c266c8f2.png)

  

在卸任TheGameNet.com公司技术及产品的副总裁之后，钟英武在美国硅谷创立了FunPlus。

  

不查不知道，一查吓一跳，大佬果然是大佬！  
据调查，钟英武名下控股的公司至少有11家（包括已注销的公司）。2019年10月28日，更是以36亿元荣登胡润研究院《2019胡润80后白手起家富豪榜》第31位。![](../Images/89642bca23e97a621660ea41c1de0cf6.png)

  

而其创立的FunPlus更是连续九次坐上App Annie的月度出海报告的收入榜冠军位。在2018年移动数据平台Sensor Tower盘点的“2018年成功出海美国的中国游戏厂商”榜上更是名列第一位。

![](../Images/e539364e0211bd54b5e16b35d0bb8926.png)

  

在对FunPlus的调查中，小福妹还发现了一件有趣的事情，趣加集团曾经投资过北美电竞团队Cloud9，看来大佬真的是电竞行业的资深爱好者啊~  
据调查， C9曾经连续三年获得The Game Awards（TGA）年度最佳电竞俱乐部奖以及2018年Esports Awards最佳俱乐部奖的荣誉。其英雄联盟分队获得过2次北美LCS冠军，CSGO分队曾获2018波士顿ELEAGUE Major冠军，守望先锋分队则是OWL第一赛季的总冠军，可以说是北美最顶尖的战队之一。![](../Images/1df85f3cc318c5be1fb7b57e0bae1d29.png)

  

在FPX夺冠之后，有网友戏称钟英武就是“大连理工韩商言”，看来大佬要火了呀！小福妹就先粉为敬了！  
至此，关于FPX的神秘出身小福妹已经了解了许多了，真真是越了解越崇拜吖！最后，再次恭喜小凤凰夺冠！恭喜中国电竞双连冠！也预祝明年主场作战三连冠，加油！
