# 《哪吒》涉嫌抄袭，是实锤还是碰瓷？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NTg4Mzc0MA==&mid=2247485000&idx=1&sn=7c4a8b576f36558bb270f20e29e09ca3&chksm=fd828f7bcaf5066d42589921bd42a89e011d70248b70b3ef2f3737c8d15c0cc31e1f788ac4ed&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU4NTg4Mzc0MA==&mid=2247485000&idx=1&sn=7c4a8b576f36558bb270f20e29e09ca3&chksm=fd828f7bcaf5066d42589921bd42a89e011d70248b70b3ef2f3737c8d15c0cc31e1f788ac4ed&scene=27#wechat_redirect)

![](../Images/87a510f66c871dabbbe11d75ff49caaf.png)

  
8月19日，作为《五维记忆》创意秀主演之一的石璟箜篌（微博名称），看完电影《哪吒》后发文质疑《哪吒》抄袭，声称感觉整部剧的灵魂都被挖走，还质问《哪吒》官微和导演饺子：我们以后还怎么演下去！  
随后，中影华腾喊话饺子要求对剧本，一时间哪吒涉嫌抄袭的传闻甚嚣尘上。那么，《哪吒》到底是否抄袭呢？今天，福韵君借助网络情报给大家分析分析。  

![](../Images/fdb52d75000d88630e9ee2665ad0c5cf.png)

![](../Images/efcc6fa1c99ee1820b33edda5ad10ec4.png)

  

  
**| **** 时间线**

根据开源网络查实，《五维记忆》创意秀的创作完成时间是在2017年12月20日，也就是说在此之前，除了作品相关工作及演出人员以外，没有任何其他人观看过这部作品。而《哪吒》的官方信息显示：出品时间为2016年，拍摄时间为2015-2019年。

![](../Images/9076d0c6754dfacdb2a260d09ee4b0e0.png)

![](../Images/e69cb6f508c93b6f9e661188897ca957.png)  
这个所谓的出品时间到底是什么意思呢？目前还没有明确的官方定义，从字面上解释就是一个作品正式出产的时间点，但《哪吒》的完成时间显然不是2016年，所以这里的2016年究竟是个什么时间点呢？  
此时，福韵君找到一篇｢每经影视｣对导演饺子的采访，采访中明确提到2015年以前《哪吒》已经开始筹备，且2015年已经有了初稿并开始“死磕”剧本，而这个打磨时间花了一年。 

![](../Images/d0b60930810a22ec8ce3ae64ce8d6865.png)

  
所以，我们可以理解为这个出品时间指的是《哪吒》剧本确定的时间。也就是说《哪吒》的剧本早在2016年就已经确定完成，而这个2018年才正式公演的《五维记忆》又怎么会“被抄袭”呢？  
  
**|****  创意概念**

石璟箜篌声称哪吒的里用了“阴阳”的概念，而阴阳的概念是他们先展现的，所以同样用了阴阳元素的哪吒抄袭……这一点福韵君其实不是很想拿出来说，因为真的很无力。

![](../Images/24196df197df20a2a0c076e42c97b349.png)

  
太极阴阳的概念作为中国古代哲学，早在战国时期就已经被提及，且在中国各大神话传说中皆有体现，可以算是中国传统文化的精华之一。而哪吒作为中国古代神话故事中的主要人物之一，和东海三太子敖丙的故事更是在《封神榜》就已有记录，哪吒的火属性和敖丙的水属性也恰好符合阴阳的对立平衡关系。因此，拿“阴阳”来说抄袭简直是过于自以为是了，也不知道是谁给他们的胆量，竟然意欲将“阴阳”据为己有。

  

  

**|  ****画面展示**

石璟箜篌在微博控诉《哪吒》抄袭主要针对两方面的内容：宣传海报及其中五幕动画效果呈现：

![](../Images/ca4b014c4d84f80856484de563aacbc0.png)

  
我们先不论这其中的相似度，事实上要用一部动画片和一部真人舞台剧作品进行比较，真的是仁者见仁智者见智。而在我们下定义之前，我们需要来看看另外一组对比：  
**（1） 海报**

![](../Images/6f09e540401d17ce19c9a9fb61ead6dd.png)

（左：你的名字   中：五维记忆   右：阿凡达）  
按照石璟箜篌提出的抄袭逻辑，《五维记忆》的宣传海报不仅在布局和配色上涉嫌抄袭《阿凡达》和《你的名字》，在应用元素上更是涉嫌抄袭《功夫熊猫》、《疯狂动物成》、《狮子王》……等一系列电影。  
**（2） 画面**

在画面上，五维记忆的画面更是被《太阳系旅行》的创作者实锤抄袭：

![](../Images/6141557d6305197b427684aff7928a8c.png)

（太阳系旅行创作者发文）![](../Images/7ab64781719b7e82898380623749d38f.png)（上：五维记忆  下：哪吒）![](../Images/b8898df77272fe0e8b08a2da7d712969.png)（太阳系旅行）  
而他们指责《哪吒》抄袭的场景更是与《火影忍者》、《七龙珠》等多部动漫相似。 至此，《五维记忆》这出“哪吒抄袭”梗明显已经一锤定音，不仅碰了瓷，还把自己碰出了bug。

  

  

**|****  衍生问题**

在《五维记忆》这出碰瓷戏中，主创方不仅被群嘲，更是被扒出了商标使用权的问题。

![](../Images/a6cd435dfb8e3b02514c7d6b40e211a6.png)

  
经查证，这部创意秀用于宣传的商标竟然是无效的。

![](../Images/3cf135b6fceedda659bc5c8d6f257593.png)

  
声称国际非遗文化的公司，致力于保护非遗文化，却连基本的知识产权保护都不懂。
