# 开源网络侦缉档案之《铁探》

> CIA（美国中央情报局）认为有价值的情报，80%是通过各类型的公开信息中收集来的，其中的40%信息是通过开源网络获得的。

如今，**开源网络情报技术**已经应用到各方各面，小到今晚去那里吃饭（大众点评、美团等APP），大到收集国家情报（加拿大间谍案等）。

在电视剧中也经常能看到开源网络情报的影子。如，今年4月份播出的TVB电视剧《铁探》中，开源网络情报就在帮助警察确定嫌疑人方面起了重大作用。

案件是一起“高楼丢强酸”事件，警方初步筛选出了3100名可疑人员，可到这步就头疼了，没有办法对着3000多人全部进行监视。但是，开源网络情报却帮了大忙。

![](../Images/c03ce38e7be115578dfda966f7329715.png)

（图片来源于电视剧截图）  

警员通过对可疑人员的社交媒体进行排查，发现其中有一部分人专门点赞撞车、烧伤或者各种灾难短片的变态页面，这类人可能会有恋灾癖（Symphorophilia）。

![](../Images/49ea18a8031e9a3feab3879bdd4bae2d.png)

（图片来源于电视剧截图）

于是警员将3100名可疑人员按照不同的喜好进行分类，并将这类有特殊嗜好的人群列入重点监察对象。同时，根据分析得到的罪犯的犯罪习惯，设计了一个场景引诱罪犯再次犯案。果然，一名重点监察对象进入了警员的视线。

![](../Images/0536ab2b33ed471e0545723201c2bda2.png)

（图片来源于电视剧截图）

警员通过暗地接触，果不其然，这名监控对象就是“强酸案”的犯罪嫌疑人。

  

![](../Images/eac4f7a21c7e28f918cdadffcd180778.png "undefined")

福韵君对警员工作流程进行还原

Step1，针对3100名可疑人员的社交媒体（facebook、twitter、instagram等）进行逐一调查，按照其主页，发表、关注及点赞的帖子类型的危险级别进行分类。

Step2，针对可疑人员的言论、行为再次划分危险级别，并结合上一步的分类交叉制作一个危险人物表格。

Step3，通过危险人物的社交媒体分析其生活习惯、居住地址、联系方式、朋友圈等等信息，并做出关联分析图谱及人物侧写。

  

都说情报分析师是网络情报界的“福尔摩斯”，和上述案件中警员破案的过程类似，我们**利用开源网络情报技术，通过商业调查、数据分析等方式**，为诸多企业解决了很多由于信息不对称造成的难题。

以下是一个**真实案例**：

一家律师事务所在代理一个案件的时候，遇到了一个难题，找到了福韵君，希望福韵君能帮助他们找到一些线索或证据。

*案件：**国内的**一家进出口公司与外国的一家农业公司合作，代理其产品，但几年后因纠纷闹上了法庭。**这个律师事务所的委托方是这家外国的农业公司，他们的官司胜诉后，这家国内的进出口公司却无法支付合同资金。**法院对这家进出口公司的账户调查时，发现账户里只有50块钱。**律师事务所希望福韵君能帮助他们找到有用的信息能追到货款。*

福韵君首先调查了这家进出口公司的情况：

这家进出口公司的母公司代理委托方的农产品，但委托方提供的资料里面没有与母公司相关的信息及情况。同时在开源网络中也没有找到进出口公司与其母公司的直接财务关系。但这点小困难困不住福韵君。我们通过运用开源网络情报技术以及情报思维模式，将目标锁定在母公司与该进出口公司的关联关系上（公司法规定：关联公司如果因人员混同、业务混同或财务混同，导致各自财产无法区分等情况发生，关联公司对外债务需承担连带责任）。

**福韵君是如何调查的呢？**

首先，了解进出口公司及其母公司的运营情况（使用全国企业信息公司平台，及第三方数据库等）。

其次，调查实际关联情况，发现重要线索（人员混同、业务混同）。

![](../Images/7f9122241f32d124b32dcdf35edacf08.png)

（母公司的产品在对外贸易方面全部是由进出口公司负责的，人员也相同）

![](../Images/abc54b5a41b247fa7264cdf9852390b5.png)

（母公司与进出口公司人员混同）

![](../Images/7ad28bafa7326e10c6a2bb94497c50c5.png)

（母公司与进出口公司的办公地址相同）

![](../Images/69a09e56015e5f3e89208a821b638815.png)

（在公司招聘时，进出口公司不进行独立的招聘活动，全部由母公司负责）

最后，通过分析调查到的多项证据，证明这家进出口公司就是母公司的一个部门，它并没有能力独立运营，符合关联公司之间人员、业务甚至财务的混同情况。

同时，福韵君还帮助找到了进出口公司所拥有的一部分可变现资产情况，方便委托方追讨资金。

福韵君找到的多项证据帮助律师事务所成功地帮助委托人追回了货款，挽回了损失。而福韵数据也成为这家律师事务所的战略合作伙伴。
