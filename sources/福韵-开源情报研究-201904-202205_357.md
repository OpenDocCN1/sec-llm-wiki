# 答案揭晓-寻找福韵君位置

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NTg4Mzc0MA==&mid=2247484338&idx=1&sn=819d3251556ea4a7a51e2636120fdd9c&chksm=fd828a81caf5039700c1ee9a5c9755d57c17b20c043956af3fd18de2e3c4684c8ab40073d8f9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU4NTg4Mzc0MA==&mid=2247484338&idx=1&sn=819d3251556ea4a7a51e2636120fdd9c&chksm=fd828a81caf5039700c1ee9a5c9755d57c17b20c043956af3fd18de2e3c4684c8ab40073d8f9&scene=27#wechat_redirect)

给大家公布正确答案啦！福韵君所在位置就是**竹塘西路天鸿小区的这家易裕和粉店**！

下面福韵君给大家分享一下如何利用开源网络情报分析方法来解决这个问题。

首先这张照片是福韵君用手机拍的，如果手机相机的设置并没有关闭GPS位置信息，那使用Opanda IExif这款软件，可以直接获取照片的经纬度信息，再通过百度地图等就可以直接查到照片拍摄的具体位置。

![](../Images/bbc7047a6f4f36cefe7aa4fd852fad9f.png)

但是福韵君关闭了手机拍照保留GPS位置信息的功能，所以只有从照片中找线索了。

![](../Images/3d63141f641983b8ec10f164094de264.png)

**品牌名称**

这张照片中可以看到“YI YU HE”以及部分商标名称，百度搜索“YIYUHE 长沙”后发现店名叫易裕和，知道店名就成功一半啦！

![](../Images/ee996af7e5e122d16f25ab71dd369f4f.png)

**两家店铺位置**

在百度地图中搜索“易裕和”，发现长沙只有两家店，分别是位于竹塘西路的“易裕和粉店”和友谊路的“易裕和面馆”。

![](../Images/1e04c22ec09e7902141c02b4a5cf29ec.png)

**店内环境**

福韵君拍的第二章照片是店内环境，可以看到店内有枫叶装饰点缀，特点明显。接下来就是确定福韵君究竟是在哪家店啦！

![](../Images/1728ca61ac64d1d3a21b951f8c84d7d7.png)

**易裕和面馆**

百度搜索“易裕和面馆”后，我们在大众点评里面找到了位于友谊路的面馆的外部环境，如上图所示，店面好像并不大。

![](../Images/6c1d66fc37a2dbb01bf18823d92a7a3e.png)

**易裕和粉店**

接下来再去看看“易裕和粉店”，搜索后发现了一篇文章，里面详细介绍了这家店的情况，可以看到店内的装修跟照片中一模一样，这样就可以确定福韵君是在竹塘西路这家“易裕和粉店”觅食的！

其实福韵君是去位于湖南商会大厦的福韵公司长沙数据中心出差的，肯定是就近找好吃呀！同时福韵君也在这里欢迎各位长沙的同学加入福韵大家庭，大家一起去吃粉呦！

![](../Images/e1bee5ac47c0d3aa32e2cec6fda80485.png)

昨天很多粉丝积极留言，大部分人都猜到了是易裕和，但是最先猜对的人才有机会领取奖励，我们也在第一时间私信了这位粉丝，加福韵君好友领取红包！
