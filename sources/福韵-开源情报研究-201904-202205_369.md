# 都9102年了，你还搞不清楚网络情报和舆情？

每当谈起网络情报，大多数人的第一反应是：不就是舆情嘛！但实际上，网络情报和舆情是有着很多差别的：从概念到本质，再到表现形式和信息的加工程度等方面。今天小福妹就来和大家聊聊网络情报和舆情到底有什么不同。

  

01本质概念不同

  

传统舆情是指在一定的社会空间内，较多群众关于特定对象或事件所表达的信念、态度、意见和情绪等表现的总和。从传统的社会学理论上讲，舆情本身是民意理论中的一个概念，它是民意的一种综合反映。

![](../Images/08e5e4173db516cccf776cb9fab2e089.png)

而网络空间情报是需要对特定对象和事件进行精准、深入的调查，重点在于对背后真相、隐情的探索和揭示，对即将发生情况的预测和研判。

![](../Images/995807715320ceca788021e6a7b9cab2.png)

传统舆情可作为网络空间情报的素材之一，或称其调查为初级情报产品，一般情况下不直接作为决策依据。

  

02信息搜索程度不同

  

舆情大多只用公用搜索引擎收集网站、网页的信息。而网络情报则需动用不同手段、方法，深层次搜集、挖掘各种网站包括社交媒体、论坛甚至暗网的数据和信息。

一般大家将互联网信息分为3个层面：表网、深网和暗网。简单的说，各种网站、网页都属于表网，只需公用搜索引擎即可在其中收集信息；深网一般指的是各类社交媒体、论坛等需要账号登录，或需被“许可”进入的网络媒体或社交圈；暗网则指的是刻意隐匿出处，避免被溯源、追踪的各种信息源。一般认为表网所获得信息量只占5%，而深网可获得信息量则多达80%。所以舆情所收集信息量，特别是一些有价值的信息远不如网络情报搜集获取的。

网络情报工作的一项重要内容是要研究特定的信息源，从哪能获取你最需要的信息？各种信息源纷繁杂乱，或深藏不露，或难为人知。不少特定的信息，仅出自特定的信息源。网络情报还讲究搜索技术和搜索方法，与舆情常用的技术和方法相比，更复杂、更专业，结果也大不相同。

  

03信息加工程度不同

  

舆情只是收集信息和直接罗列信息，再做一些“热度”、“情感”方面的标注。

![](../Images/21fc33d4b72479a468cf5ff93203096e.png)

网络情报则需对各方面不同信息、各种碎片化、离散化的信息作综合整理分析、并不断循环深入反复，最终对事件、人物做出具体、全面的描述（有人称之为人物画像、事件画像）及评判。

![](../Images/1b75271705b2159ed815b1f295545972.png)

  

04信息价值不同

  

舆情只是收集媒体和公众对已发生事件的报道、评论、议论，反映的是社会的关注度和公众的情绪。网络情报的重点是要发现线索，追踪过程、监测动向、预报险情。对已发生的事件则需深究其成因、背景、真相、态势。网络情报对政府部门以及商业公司的决策有着更重大的参考价值。

网络情报涵盖了舆情，舆情是网络情报的初始素材。舆情服务关注的是时间的反映，情报服务探究的是事件的成因；舆情服务调查反映的是问题的表象，情报服务调查揭示的是问题的本质；前者关注现状的展现，后者针对将来的预测。

网络情报的最重要贡献及其价值在于其：“追根溯源、探求真相、揭示隐情、预示风险”的特性。
