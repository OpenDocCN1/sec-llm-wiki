最后我决定把另外一台手机拔掉。。。

# 解决提出问题的人

只要在你的`~/.bash_profile`或`~/.zshrc`或者其他`profile`里加上两行代码，就可以实现比较方便的 adb 设备切换。

*   
*   

```
adbs(){export ANDROID_SERIAL=$1; echo "\033[32m[adb-select] current device <$ANDROID_SERIAL>\033[0m"}adbls(){adb devices}
```

( 经过某羽绒服巨鳄的敲打之后，直接使用ANDROID\_SERIAL实现

1\. 使用`adbs serial`来切换当前终端控制的设备2\. 使用`adbls`来代替`adb devices`当然，命令名字你可以随便自己换。最后效果差不多是这样的：
