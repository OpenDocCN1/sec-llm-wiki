**3.基本类型在三元表达式内可赋值为null，编译通过但运行出错**

首次发现时的环境： JDK 1.7

测试用例：

```
int i = 
```

首次发现所在项目：ZBLibrary

解决方案：

在给基础类型用3元表达式赋值时，null 先转为基础类型的默认值。

如果两个变量中间隔了比较长的其它代码，很可能会导致开发人员将两者混淆，导致逻辑认知错误，从而写出或改出有问题的代码。
