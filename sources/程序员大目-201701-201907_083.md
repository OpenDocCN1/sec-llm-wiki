# 一个原创作者的心声……

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQ3NjE2OA==&mid=2247484673&idx=1&sn=89ea2abcac8ee081723833d7513d6de5&chksm=ec3c9866db4b117003dddaadff587a2de56bd5081ad2985f23cc2b4a78f3e4e2aa14010a369c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247484673&idx=1&sn=89ea2abcac8ee081723833d7513d6de5&chksm=ec3c9866db4b117003dddaadff587a2de56bd5081ad2985f23cc2b4a78f3e4e2aa14010a369c&scene=27#wechat_redirect)

前天，朋友翟永超（程序猿DD）和我吐槽，说自己的原创文章被人洗稿不算，还被别人质疑是抄袭，不禁哭笑不得。

我和DD于16年8月认识，当时，他在写Spring Cloud系列博客，我在写Spring Cloud开源书（https://gitee.com/itmuch/spring-cloud-book）；他在写《Spring Cloud实战》，我在写《Spring Cloud与Docker微服务架构实战》。

几次聊天后，发现都有技术人的天真，他写书的动机是：不想以后儿子介绍自己父亲的时候是知名技术博主（因为博主在这个年代基本是脑残的代名词）；我则受到Pieter Hintjens（AMQP协议提出者）选择安乐死那篇博客《A Protocol for Dying （http://hintjens.com/blog:115）》的影响，觉得得给孩子留点念想，于是录制Spring Cloud视频 + 写书。

相见恨晚，于是面基，后来发展成为朋友；再之后成为革命情谊，联合创办Spring Cloud中国社区；再后来，因为社区和我当初技术驱动的愿景偏离太远，我选择离开社区（或者应该说被某一言堂逐出创始人群），DD几天后也选择了退出；再后来，DD、泥瓦匠（http://bysocket.com）、我联合创办了Spring4All社区。

16年，Spring Cloud/Spring Boot生态不像现在，百花齐放，各种技术文章层出不穷（当然多少是抄袭，多少是洗稿就不说了）——当时Spring Boot文章相对较少，Spring Cloud更是市面上连篇像样的文章都很难找到。

然而，这个世界从来不公平——

*   原创有时候干不过洗稿的
    
*   洗稿的有时候干不过抄袭的
    
*   正版视频卖不过盗版
    
*   正版书卖不过盗版书
    

举个例子，我的博客（http://www.itmuch.com）在16年成立，也只在博客发布，不发CSDN、博客园等平台（主要是体验太差，用不下去），快三年了，目前日IP只有800+，PV3000+（我现在妥协了，会在CSDN同步发布），而转载我文章到CSDN的，随便找一篇，例如这个：

![](../Images/1db84d8cd4acdc6736f41febff41ed95.png)

几千的阅读，比我博客上的数据好N倍。

我的Spring Cloud视频（国内第一个，比第二个早至少7个月），最好的一个月，收入7000元，正常月收入3000左右；从2017年4月开始，盗版泛滥，每况愈下，几乎没有销量，加上Spring Cloud版本升级太快，当初的视频逐渐不再适合新的版本，索性下架…

后来某一次，无意间了解到一个朋友在卖盗版视频，打听了一下月收两万+，心里不知道是什么滋味……

可能说得有点碎，其实我想说的只有三点：

*   请给原创者一点空间，原创一篇文章我至少得半天……
    
*   转载请帮忙注明出处，作者会感激你的，例如我
    
*   洗稿可以，但是改时间真的很low比，真的就是真的，假的就是假的
    

下面是DD的文章，技术剖析谁是原创，谁是洗稿。

[原创不易，李鬼太多，套路可以，不要太脏！](http://mp.weixin.qq.com/s?__biz=MzAxODcyNjEzNQ==&mid=2247487136&idx=1&sn=31a216decf9a0254191997a8347e69b3&chksm=9bd0a338aca72a2eb92e9fbd2ae2f8f094efd35228bda8d46f539b5578b1d9dc71fe1eb6a03e&scene=21#wechat_redirect)

即使是这样，DD依然拒绝透露究竟是谁在洗稿他的文章，也算高风亮节了。如果觉得他的公众号不错，请关注他，不用跟我客气，哈哈哈。
