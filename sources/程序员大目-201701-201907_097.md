# F5 收购 NGINX的一些思考

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQ3NjE2OA==&mid=2247484567&idx=1&sn=22ac070bcd380e421d06a7fb15fc2452&chksm=ec3c99f0db4b10e64095e7df5eba7e43c8948afb7ea6fe2ed30deb534fac2036a0adb607122b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247484567&idx=1&sn=22ac070bcd380e421d06a7fb15fc2452&chksm=ec3c99f0db4b10e64095e7df5eba7e43c8948afb7ea6fe2ed30deb534fac2036a0adb607122b&scene=27#wechat_redirect)

今天我被 `NGINX被收购` 的新闻刷屏，内容大致如下：

> 11 日，F5 与 NGINX 宣布了一项最终协议，根据该协议，F5 将收购 NGINX 的所有已发行股票（ https://www.nginx.com/press/f5-acquires-nginx-to-bridge-netops-and-devops ），总价值约为 6.7 亿美元。
> 
> ![](../Images/1e55c73830e18db206e0657b5a2552ad.png)
> 
> F5 是应用交付网络（ADN）领域的全球领先厂商，其解决方案有助于整合不同的技术，以便更好地控制基础架构，提高应用交付和数据管理能力，并使用户能够通过企业桌面系统和智能设备无缝、安全并更快速地接入应用。
> 
> 而 NGINX 最知名产品 Nginx 是互联网上最受欢迎的 Web 服务器之一，NGINX 提供一整套用于开发和交付现代应用的技术，同时它也是应用交付领域的开源领导者。
> 
> 收购声明指出，此次战略收购和有机投资，将确保长期收入和每股盈利增长；F5 和 NGINX 将在所有环境中实现多云应用服务，提供开发人员所需的易用性和灵活性，同时还提供网络运营团队所需的规模、安全性和可靠性等能力。
> 
> ![](../Images/c8df1ff1ff59ae60ff80918662c269fc.png)
> 
> 此外，F5 将致力于持续创新并增加对 NGINX 开源项目的投资，以增强 NGINX 广泛的用户群体能力。F5 将通过 F5 安全解决方案增强 NGINX 目前的产品，并将 F5 云原生创新与 NGINX 的软件负载均衡技术相集成，从而加速 F5 为现代容器化应用提供应用服务的上市时间。F5 还将利用其全球销售团队、渠道基础设施和合作伙伴生态系统来扩展 NGINX 向企业销售的机会。
> 
> “F5 收购 NGINX 会加速我们的软件和多云转型”，F5 总裁兼首席执行官 FrançoisLocoh-Donou 表示：“通过引入 F5 的世界级应用安全性和丰富的应用服务组合，加上 NGINX 领先的软件应用交付和 API 管理解决方案，以及 DevOps 社区中无与伦比的可信度、品牌认知度与庞大的开源用户群，我们将弥合 NetOps 和在企业多云环境中提供一致应用服务的 DevOps 之间的鸿沟。”
> 
> NGINX 首席执行官 Gus Robertson 表示：“NGINX 和 F5 拥有相同的使命和愿景，我们都相信应用是推动数字化转型的核心。我们都相信，端到端的应用基础架构——从代码到客户的应用需要在多云环境中交付。F5 通过专为 DevOps 设计的解决方案获得了深度，而 NGINX 获得了广泛的成功，可以触及成千上万的客户和合作伙伴。”
> 
> 此次收购已经获得 F5 和 NGINX 董事会批准，预计将于今年第二季度完成。

## 碎语

还记得Oracle把MySQL收购的故事吗？那是一个世界上最流行的商业数据库收购世界上最流行的开源数据库的案例。

十几年过去了，F5收购了 NGINX 的案例，相信未来也会被业界谈到。这是一个世界上最贵的负载均衡器收购世界上最（第二）流行的反向代理的例子。不知道NGINX创始人老毛子 `IgorSysoev` 未来怎么选择……是财富自由了退出还是……君不见 Spring Framework 创始人 `RodJohnson` 已经退出了嘛。

这再次说明了开源软件的背后从来不是纯粹的“免费”、“无私“、”自由“，伴生的是”商业“、”资本“、”利益“。了解一下Kubernetes诞生的历史，你会有更深的感受。另外，Netflix宣布Eureka 2.0孵化失败、Hystrix进入维护状态，背后其实都是商业利益在作祟，有兴趣可详见：《 [关于Eureka 2.x，别再人云亦云了！](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247483989&idx=1&sn=cd8c5a552d7dee68173154730c676acd&chksm=ec3c9f32db4b1624136c9715e3748c82ad2a30ea784dac8ddabf8eacc99095056eed4b7a37b9&scene=21#wechat_redirect) 》、 《 [Hystrix停止开发，我们该何去何从？](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247484046&idx=1&sn=165b644a727046a94bbc9bf62712248e&chksm=ec3c9fe9db4b16ffbcabc16308f164c002a92a4e2e9a70308a566f980fbea4b2f092cbe78494&scene=21#wechat_redirect) 》、 《 [Spring官方宣布Netflix项目进入维护模式解读后续](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247484260&idx=1&sn=dfdff64508f2f115d4e0f258311d2e88&chksm=ec3c9e03db4b171529fb138d6b478c172cb6a40c8e8272a8dba45ebbb08a4e60f4b19426a899&scene=21#wechat_redirect) 》 。
