代码世界值得你珍藏的 72 张面孔

开源 可能是21世纪最大的科技催化剂，他已渗透入我们生活的方方面面，我们访问的每一个网站或APP，使用的每一台电脑或手机，都离不开开源技术。然而，对于科技行业以外的人而言，开源，仍然是陌生的。



2014年，摄影师Peter Adams启动了一个 face of open source 的项目，以黑白影像的形式记录开源世界那些极具影响力的人物，涵盖了Unix / BSD / Linux / ROS / Language / X Window等领域，并已经有 72 位开源领域的知名人物加入了该项目，不乏一些大家耳熟能详的技术牛人，本文将甄选10位人物，带你走进开源的魅力世界。 


 -> 点击文末“阅读原文”，访问该项目网站（http://facesofopensource.com/）  



1. Linus Torvalds（林纳斯·托瓦兹）



个人名望：

Linux 操作系统和 Git 版本控制系统的创造者。


个人简介/主要荣誉：

Linus Torvalds 和 Shinya Yamanaka 一起获得了芬兰科技学院举办的2012年千禧年科技奖年度会议的荣誉，以表彰他为发明广泛使用的 Linux 内核的计算机开发的新的开源操作系统。 他还是2014年 IEEE 计算机学会计算机先驱奖和2018年 IEEE Masaru Ibuka 消费电子奖的获得者。 


媒体评价：

“你的手机、你家的电视机顶盒、甚至你取款的 ATM，都是基于林纳斯·托瓦兹做的 Linux 系统改的，没有这个人，就不会有你现在用的开源软件。”



2. Kenneth Thompson（肯·汤普森）


个人名望：

C语言前身B语言的作者，Unix的发明人之一(另一个是Dennis M. Riche，被尊为DMR)，操作系统Plan 9的主要作者。


个人简介/主要荣誉：

Kenneth Thompson是美国计算机科学学者，与丹尼斯·里奇同为1983年图灵奖得主。2000 年 12 月时，Thompson 退休，离开贝尔实验室，成为了一名飞行员。2006 年，汤普逊加入 Google 公司工作，参与设计了 Go 语言。在 2016 年，GO 语言成为热门度上升最快的编程语言。


媒体评价：

“无论是在编程界这个圈子里，还是在计算机这个大行业内，都称得上是“祖师爷”级别的人物。”


3. Vinton Cerf（文顿·瑟夫）



个人名望：

TCP/IP协议和互联网架构的联合设计者之一，被誉为互联网之父之一。


个人简介/主要荣誉：

1994年12月，Vinton Cerf入选《人物》杂志当年评选的“25个最令人着迷的人”之一，联合国数字合作高级别小组成员，其他荣誉包括国家技术勋章、图灵奖、总统自由勋章和马可尼奖，并入选美国国家工程学院 。


媒体评价：

“今天互联网成功的原因之一就是Vinton Cerf和鲍勃·卡恩（Robert E. Kahn）没有申请专利，没有把TCP/IP视为私有财产。”


4. Larry Wall （拉里·沃尔）



个人名望：

Perl 编程语言之父，阅读Usenet新闻群组的程式Rn的作者，开放源码界的重要程序patch的作者。


个人简介/主要荣誉：

Larry Wall 获得两次IOCCC（全球难以读懂C程式码比赛）的大奖，于 1998 年获得第一届自由软件奖， Programming Perl(通常被称为 ”骆驼书”)的共同作者之一，参与和引领了开源软件运动，他的成就获得自由软件基金会的认可。


媒体评价：

“无论是在推动Web的发展，还是在制造了众多Internet基础设施的FreeSoftware/Open Source运动的发展过程中，Wall都扮演了一个重要的角色，他的谦卑个性使得他区别于该运动的其他领导人物。”



5. Guido Rossum（吉多·范罗苏姆）


个人名望：

Python 编程语言之父，于1989年在ABC语言的基础上创建了Python语言，Python 在Github于2017年的一项最受欢迎语言的调查中排名第二，仅次于Java。


个人简介/主要荣誉：

Guido Rossum 获得由自由软件基金会颁发的2001年自由软件进步奖，被美国计算机协会（ACM）认定为著名工程师。在2013年1月正式从Google离职后并正式加入 Dropbox，帮助Dropbox得到了第一亿位用户。


媒体评价：

“Python社区的人赋予他“仁慈大君” 的称号，这一称号直接来自英国肥皂剧《Monty Python飞行马戏团》。Guido当初之所以选中Python作为语言的名字，是因为他太喜欢这部肥皂剧了。”



5. Brendan Eich（布兰登·艾奇）


个人名望：

JavaScript的创造者，浏览器上应用最广泛的脚本语言之一，Mozilla基金会创建人之一。


个人简介/主要荣誉：

Brendan Eich 获得由自由软件基金会颁发的2001年自由软件进步奖，被美国计算机协会（ACM）认定为著名工程师。在2013年1月正式从Google离职后并正式加入 Dropbox，帮助Dropbox得到了第一亿位用户。


媒体评价：

“他只用10天时间就把Javascript设计出来了，虽然设计初期存在诸多不够严谨的地方，但这并不影响他在之后成为世界上使用最为广泛的语言之一，这一切离不开开源。”



6. Doug Cutting（道·卡廷）


个人名望：

Doug Cutting是Lucene、Nutch 、Hadoop等项目的发起人，他将高深莫测的搜索技术形成产品，贡献给普罗大众。


个人简介/主要荣誉：

Doug Cutting毕业于斯坦福大学，先后任职于Xerox、Architext、Yahoo和Cloudera，2010年当选 Apache 软件基金会主席，2015年获得O'Reilly 颁予的开源贡献奖。


媒体评价：

“提到大数据， Doug Cutting可能是最应该被记住的角色。他的作品Hadoop运用分布式存储、运算技术为大数据处理带来了巨大突破。”



7. Jeff Dean（杰夫·狄恩）


个人名望：

大规模数据处理系统MapReduce、分布式存储系统BigTable、数据库系统Spanner，以及TensorFlow的项目负责人。


个人简介/主要荣誉：

1996年，Jeff Dean从华盛顿大学的计算机科学方向获得博士学位，毕业后加入谷歌，参与谷歌的网络爬虫、索引、查询系统、AdSense、谷歌翻译的设计与实现，于2009年当选美国工程院院士。


媒体评价：

“他是谷歌成长过程的关键人物，谷歌分布式计算基础构架主要由他设计和完成，该构架支持了谷歌的大部分产品，他还被称为“谷歌大脑背后的大脑”。”



8. Matt Mullenweg（马特·穆伦维格）


个人名望：

Wordpress创始人，WordPress 是世界上使用最广泛的博客系统之一，全球30%的网站采用WordPress这一开源软件进行搭建。


个人简介/主要荣誉：

Matt Mullenweg，于2003年创办WordPress，并于2005年开始全职从事这项工作。2011年3月,被Business Inside 评为“互联网十大最具影响力人物”之一，2012年，入选福布斯30位30岁以下移动社交领域领袖榜单。


媒体评价：

“WordPress是企业如何在开源生态系统中茁壮成长的最佳例子之一，有很多估值数百万美元的企业从WordPress相关产品和服务中获得了收入。”


9. Karen Sandler（凯伦·桑德勒）



个人名望：

Karen Sandler是软件自由协会的执行主任、GNOME基金会的前执行主任、律师和软件自由法中心的前总法律顾问。


个人简介/主要荣誉：

Karen Sandler是一名律师和自由软件活动家，她与许多非营利组织合作，包括自由软件基金会、GNOME基金会、Apache软件基金会以及X.Org基金会和软件。在担任GNOME基金会的执行主任期间，吸引了大量女性程序员加入自由和软件开源活动。


媒体评价：

“Karen Sandler在2006年被诊断患有严重的心脏疾病，依赖于心脏起搏器，面临突然死亡的可能，但这并不影响她对软件自由化的追求。”


10. Katherine Maher（凯瑟琳·马赫）



个人名望：

维基媒体基金会执行董事。


个人简介/主要荣誉：

Katherine Maher 曾在联合国儿童基金会工作，致力于与产妇健康、预防艾滋病毒/艾滋病和青年参与技术相关的问题，也曾作为世界银行的ICT创新专家，推动互联网、智能手机和其他技术在促进民间社会和机构改革方面的作用，入选AUCians于2013年公布的“99位33岁以下全球青年领导人”榜单。


媒体评价：

“Katherine Maher有着丰富的个人履历，活跃于对人权、民主和国际发展有影响的非盈利性领域，她正努力帮助更多人了解开源技术。”
