## 配置刷新三要素

1 依赖中有 `spring-boot-starter-actuator`

2 添加如下配置，暴露 `/actuator/refresh` 端点：

```
1.  `management:`
    
2.  `  endpoints:`
    
3.  `    web:`
    
4.  `      exposure:`
    
5.  `        include: refresh`
    
```

3 待刷新的配置属性所在的类上添加了 `@RefreshScope`注解 ，例如：

```
1.  `@RestController`
    
2.  `@RefreshScope`
    
3.  `public class ConfigClientController {`
    
4.  `  @Value("${profile}")`
    
5.  `  private String profile;`
    
6.  
    
7.  `  @GetMapping("/profile")`
    
8.  `  public String hello() {`
    
9.  `    return this.profile;`
    
10.  `  }`
     
11.  `}`
     
```

这样，修改 `profile` 配置后，只需向应用的 `/actuator/refresh` 端点发送POST请求，即可刷新该属性。例如：

```
1.  `curl -X POST http://localhost:8081/actuator/refresh`
    
```
