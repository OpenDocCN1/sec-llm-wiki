## 过滤器详解

过滤器是Zuul的核心，Zuul大多功能都是基于过滤器实现的。详见：[Spring Cloud Zuul过滤器详解](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247483684&idx=1&sn=0dd793c83c403770fc17001e97a1b5f0&chksm=ec3c9c43db4b155557cd35b40c05eb6d61dcf5fd91408d802302b128dad81c1fd85e7efdc88a&scene=21#wechat_redirect) ，文章着重探讨了Zuul过滤器的生命周期、如何自定义过滤器、如何禁用指定过滤器等。

## 内置过滤器详解

Zuul内置了很多过滤器，这些过滤器帮助我们实现各种能力，来分析一下内置过滤器有哪些，分别是干嘛的。

详见：[Spring Cloud内置的Zuul过滤器详解](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247483689&idx=1&sn=3357e9cbe2586b1299b2403084e864a3&chksm=ec3c9c4edb4b1558b011b1555a20914c12f99c3ebdc3fb2fe18a8f70b220f410a69b6bf40f45&scene=21#wechat_redirect)

## 为Zuul提供回退

8.  `    // 表明是为哪个微服务提供回退，*表示为所有微服务提供回退`

10.  `  }`
     
11.  
     
12.  `  @Override`
     
13.  `  public ClientHttpResponse fallbackResponse(String route, Throwable cause) {`
     
14.  `    if (cause instanceof HystrixTimeoutException) {`
     
15.  `      return response(HttpStatus.GATEWAY_TIMEOUT);`
     
16.  `    } else {`
     
17.  `      return this.fallbackResponse();`
     
18.  `    }`
     
19.  `  }`
     
20.  
     
21.  `  public ClientHttpResponse fallbackResponse() {`
     
22.  `    return this.response(HttpStatus.INTERNAL_SERVER_ERROR);`
     
23.  `  }`
     
24.  
     
25.  `  private ClientHttpResponse response(final HttpStatus status) {`
     
26.  `    return new ClientHttpResponse() {`
     
27.  `      @Override`
     
28.  `      public HttpStatus getStatusCode() throws IOException {`
     
29.  `        return status;`
     
30.  `      }`
     
31.  
     
32.  `      @Override`
     
33.  `      public int getRawStatusCode() throws IOException {`
     
34.  `        return status.value();`
     
35.  `      }`
     
36.  
     
37.  `      @Override`
     
38.  `      public String getStatusText() throws IOException {`
     
39.  `        return status.getReasonPhrase();`
     
40.  `      }`
     
41.  
     
42.  `      @Override`
     
43.  `      public void close() {`
     
44.  `      }`
     
45.  
     
46.  `      @Override`
     
47.  `      public InputStream getBody() throws IOException {`
     
48.  `        return new ByteArrayInputStream("服务不可用，请稍后再试。".getBytes());`
     
49.  `      }`
     
50.  
     
51.  `      @Override`
     
52.  `      public HttpHeaders getHeaders() {`
     
53.  `        // headers设定`
     
54.  `        HttpHeaders headers = new HttpHeaders();`
     
55.  `        MediaType mt = new MediaType("application", "json", Charset.forName("UTF-8"));`
     
56.  `        headers.setContentType(mt);`
     
57.  `        return headers;`
     
58.  `      }`
     
59.  `    };`
     
60.  `  }`
     
61.  `}`

这样，当Zuul后端服务发生异常时，就会进到该Fallback类，并返回 `服务不可用，请稍后再试。` 。
