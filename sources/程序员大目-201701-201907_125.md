Feign默认已经整合了Hystrix，本节详细探讨Feign使用Hystrix的具体细节。

## 服务降级

1 加配置，默认Feign是不启用Hystrix的，需要添加如下配置启用Hystrix，这样所有的Feign Client都会受到Hystrix保护！

```
1.  `feign:`
    
2.  `  hystrix:`
    
3.  `    enabled: true`
    
```

2 提供Fallback：

```
1.  `@FeignClient(name = "microservice-provider-user", fallback = UserFeignClientFallback.class)`
    
2.  `public interface UserFeignClient {`
    
3.  `  @GetMapping("/users/{id}")`
    
4.  `  User findById(@PathVariable("id") Long id);`
    
5.  `}`
    
6.  
    
7.  `@Component`
    
8.  `class UserFeignClientFallback implements UserFeignClient {`
    
9.  `  @Override`
    
10.  `  public User findById(Long id) {`
     
11.  `    return new User(id, "默认用户", "默认用户", 0, new BigDecimal(1));`
     
12.  `  }`
     
13.  `}`
     
```

## 获得造成fallback的原因

```
1.  `@FeignClient(name = "microservice-provider-user", fallbackFactory = UserFeignClientFallbackFactory.class)`
    
2.  `public interface UserFeignClient {`
    
3.  `  @GetMapping("/users/{id}")`
    
4.  `  User findById(@PathVariable("id") Long id);`
    
5.  `}`
    
6.  
    
7.  `@Component`
    
8.  `@Slf4j`
    
9.  `class UserFeignClientFallbackFactory implements FallbackFactory<UserFeignClient> {`
    
10.  `  @Override`
     
11.  `  public UserFeignClient create(Throwable throwable) {`
     
12.  `    return new UserFeignClient() {`
     
13.  `      @Override`
     
14.  `      public User findById(Long id) {`
     
15.  `        log.error("进入回退逻辑", throwable);`
     
16.  `        return new User(id, "默认用户", "默认用户", 0, new BigDecimal(1));`
     
17.  `      }`
     
18.  `    };`
     
19.  `  }`
     
20.  `}`
     
```

## Feign启用/禁用Hystrix

### 全局启用

```
1.  `feign.hystrix.enabled: true`
    
```

### 全局禁用

```
1.  `feign.hystrix.enabled: false`
    
```

或直接省略不写。

### 局部启用

利用Feign配置的自定义，为指定Feign Client指定如下配置类即可，Feign配置自定义详见：[跟我学Spring&nbsp;Cloud（Finchley版）-10-Feign深入](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247484348&idx=1&sn=1f9a2e477df9de73e746cc87c64f67f7&chksm=ec3c9edbdb4b17cd8d151e4d24312a547fba5edb4d061c8dcd64ae171167f0f2d984964e6599&scene=21#wechat_redirect)

```
1.  `public class FeignDisableHystrixConfiguration {`
    
2.  `    @Bean`
    
3.  `    @Scope("prototype")`
    
4.  `    public HystrixFeign.Builder feignBuilder() {`
    
5.  `        return HystrixFeign.builder();`
    
6.  `    }`
    
7.  `}`
    
```

### 局部禁用

```
1.  `public class FeignDisableHystrixConfiguration {`
    
2.  `    @Bean`
    
3.  `    @Scope("prototype")`
    
4.  `    public Feign.Builder feignBuilder() {`
    
5.  `        return Feign.builder();`
    
6.  `    }`
    
7.  `}`
    
```
