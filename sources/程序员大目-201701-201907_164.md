## 1\. 概述

有时 OAuth2 API 可能与标准有一些不同，在这种情况家，我们需要对标准 OAuth2 请求进行一些自定义。

Spring Security 5.1 支持自定义 OAuth2 授权和令牌请求。

在本教程，我们将了解人如何自定义请求参数和相应处理。
