本书第一版基于Spring Cloud Camden SR4 & Docker 1.13编写，而Spring Cloud/Docker都是版本帝……  

大半年的时间——

\* Spring Cloud发布了Spring Cloud Edgware

\* Docker发布到17.12（哈哈，直接用年年.月月命名了）

  

于是乎，笔者执笔编写了本书第二版。

第二版基于Spring Cloud Edgware + Docker 17.09进行编写，已于2018年1月2日交稿（没办法，交稿那会儿Docker 17.12还没发布，校对完成后，考虑升级到最新版本），现在已进入校对阶段，预计2月 - 3月发布！

  

**新版本新增内容**：

\* 补充Spring Cloud/Docker新版本带来的新特性（30+）；

\* 新增若干避免踩坑的TIPS（10+）；

\* 删除第一版啰嗦的内容、废弃的TIPS（这是一本不写废话的书）；

\* 补充性能优化、超时、重试等在生产中需要关注的内容；
