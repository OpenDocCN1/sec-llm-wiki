Spring Cloud Edgware对Hystrix回退的逻辑进行了一些改进。本文将信息探讨新旧版本的回退操作，并分析的原因及改进后的优势。

Dalston及更低版本

对于Dalston及更低版本，要想为Zuul提供回退，只需编写代码如下：

  1. @Component
  2. public class MyFallbackProvider implements ZuulFallbackProvider {
  3.   @Override
  4.   public String getRoute() {
  5.     // 表明是为哪个微服务提供回退，*表示为所有微服务提供回退
  6.     return "*";
  7.   }
  9.   @Override
  10.   public ClientHttpResponse fallbackResponse() {
  11.     return new ClientHttpResponse() {
  12.       @Override
  13.       public HttpStatus getStatusCode() throws IOException {
  14.         // fallback时的状态码
  15.         return HttpStatus.OK;
  16.       }
  18.       @Override
  19.       public int getRawStatusCode() throws IOException {
  20.         // 数字类型的状态码，本例返回的其实就是200，详见HttpStatus
  21.         return this.getStatusCode().value();
  22.       }
  24.       @Override
  25.       public String getStatusText() throws IOException {
  26.         // 状态文本，本例返回的其实就是OK，详见HttpStatus
  27.         return this.getStatusCode().getReasonPhrase();
  28.       }
  30.       @Override
  31.       public void close() {
  32.       }
  34.       @Override
  35.       public InputStream getBody() throws IOException {
  36.         // 响应体
  37.         return new ByteArrayInputStream("用户微服务不可用，请稍后再试。".getBytes());
  38.       }
  40.       @Override
  41.       public HttpHeaders getHeaders() {
  42.         // headers设定
  43.         HttpHeaders headers = new HttpHeaders();
  44.         MediaType mt = new MediaType("application", "json", Charset.forName("UTF-8"));
  45.         headers.setContentType(mt);
  47.         return headers;
  48.       }
  49.     };
  50.   }
  51. }

Edgware及更高版本

  1. @Component
  2. public class MyFallbackProvider implements FallbackProvider {
  3.   @Override
  4.   public String getRoute() {
  5.     // 表明是为哪个微服务提供回退，*表示为所有微服务提供回退
  6.     return "*";
  7.   }
  9.   @Override
  10.   public ClientHttpResponse fallbackResponse(Throwable cause) {
  11.     if (cause instanceof HystrixTimeoutException) {
  12.       return response(HttpStatus.GATEWAY_TIMEOUT);
  13.     } else {
  14.       return this.fallbackResponse();
  15.     }
  16.   }
  18.   @Override
  19.   public ClientHttpResponse fallbackResponse() {
  20.     return this.response(HttpStatus.INTERNAL_SERVER_ERROR);

  24.     return new ClientHttpResponse() {

分析

由代码可知：

  • Dalston及更低版本通过实现 ZuulFallbackProvider 接口，从而实现回退；

  • Edgware及更高版本通过实现 FallbackProvider 接口，从而实现回退。

  • 在Edgware中：

  • FallbackProvider是ZuulFallbackProvider的子接口。

  • ZuulFallbackProvider已经被标注 Deprecated ，很可能在未来的版本中被删除。

  • FallbackProvider接口比ZuulFallbackProvider多了一个 ClientHttpResponsefallbackResponse(Throwablecause); 方法，使用该方法，可获得造成回退的原因。
