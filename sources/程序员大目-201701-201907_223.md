> Confluence可谓目前最强大的Wiki系统，但它是个收费软件。本文讲解如何安装、部署、破解Confluence，部署的环境是Docker。

## WARNING

*   不建议大家在公司使用破解版，用收费版的吧^\_^。如果不想掏钱，可以尝试开源的 `XWik` ，功能也非常强大。
    
*   本文只提供破解的思路及步骤，破解补丁 `atlassian-extras-decoder-v2-3.2.jar` 不提供，聪明如你，一定能在谷歌、百度、bing、ask上找到。
    

最近公司想将Confluence迁到Docker环境，同时顺序想升级一下。虽然公司用的是收费版，不过我顺便也研究了下怎么破解。以下是步骤，所用版本是 `Confluence6.6` 。

Confluence的破解比较简单，只需要替换JAR包 `atlassian-extras-decoder-v2-3.2.jar` 就可以了。

## 准备

### Dockerfile

以下是Dockerfile。

```
1.  `FROM atlassian/confluence-server`
    
2.  `MAINTAINER 周立<eacdy0000@126.com>`
    
3.  `# 传入破解补丁`
    
4.  `ADD crack/atlassian-extras-decoder-v2-3.2.jar ${CONFLUENCE_INSTALL_DIR}/confluence/WEB-INF/lib/atlassian-extras-decoder-v2-3.2.jar`
    
5.  `# 设置文件属组`
    
6.  `RUN chown -R ${RUN_USER}:${RUN_GROUP} ${CONFLUENCE_INSTALL_DIR}/confluence/WEB-INF/lib/atlassian-extras-decoder-v2-3.2.jar`
    
7.  
    
8.  `CMD ["/entrypoint.sh", "-fg"]`
    
9.  `ENTRYPOINT ["/sbin/tini", "--"]`
    
```

### docker-compose.yml

为了让配置更加简单，我们使用Docker Compose编排Confluence。这边提供下docker-compose.yml

```
1.  `version: '2'`
    
2.  
    
3.  `services:`
    
4.  `  mysql:`
    
5.  `    image: mysql:5.7`
    
6.  `    volumes:`
    
7.  `      - ./mysql/:/etc/mysql/conf.d/`
    
8.  `      - ./db_data:/var/lib/mysql`
    
9.  `    restart: always`
    
10.  `    ports:`
     
11.  `      - "3306:3306"`
     
12.  `    environment:`
     
13.  `      MYSQL_ROOT_PASSWORD: root123`
     
14.  `      MYSQL_DATABASE: confluence`
     
15.  `      MYSQL_USER: confluence`
     
16.  `      MYSQL_PASSWORD: confluence123`
     
17.  `  confluence:`
     
18.  `    build: .`
     
19.  `    ports:`
     
20.  `      - "8090:8090"`
     
```

MySQL所使用的配置文件 `my.cnf` ：

```
1.  `[client]`
    
2.  `default-character-set = utf8`
    
3.  
    
4.  `[mysql]`
    
5.  `default-character-set = utf8`
    
6.  
    
7.  `[mysqld]`
    
8.  `character_set_server = utf8`
    
9.  `collation-server = utf8_bin`
    
10.  `transaction_isolation = READ-COMMITTED`
     
```

需要注意的是，Confluence需要使用 `utf8_bin` ，并将事务隔离策略设为 `READ-COMMITTED` （B.T.W，扩展一下，大家还记得Spring的事务传播特性吧？如果不记得，请打开浏览器，搜一下）

## 安装

安装Confluence比较简单，以下是步骤：

1.  如下图，在右上角选择 `中文` ，然后就会变成中文界面了。
    
    ![](../Images/1136e3ea3d56eda8807fd8f4fa29ff8b.png)
    
    选择产品安装，并点击下一步。
    
      
    
2.  安装插件。安装你想要的插件。看着办吧，我实验的时候没有安装。
    
    ![](../Images/c69038ba7914f09ccffc730e72109a0d.png)
    
    勾选想要安装的插件，并点击下一步：
    
      
    
3.  此时将会出现类似如下的界面，让我们输入授权码。这个没有啊……
    
    ![](../Images/0a987dcb6c5bfb7a62d6975f1e68cd7c.png)
    
      
    
4.  点击上图中的获得试用授权 按钮，跳转到 `Atlassian` 的官方网站，并注册一个账号，将会显示类似如下的界面：
    
    ![](../Images/c80c2354fccdc09836f3209c57be56ad.png)
    
    其中Server ID输入上一步中的Server ID即可，输入后，点击Generate License。
    
      
    
5.  点击后将会弹出类似如下的界面
    
    ![](../Images/55f15294a66b2a20040b40e9f93136ad.png)
    
      
    
6.  生成的License Key贴到第三步中，并点击下一步，这样将会显示类似如下的界面。
    
    ![](../Images/dd95cb7ad436d7e5303aa08263ca65d1.png)
    
      
    
7.  配置数据库，账号/密码是confluence/confluence123
    
    ![](../Images/1632a06c8d17bccc1d887660004ac08e.png)
    
      
    
8.  配置管理账户
    
    ![](../Images/4bd1a15670515327807f0160e37de33c.png)
    
      
    
9.  点击在Confluence中管理用户与组，然后输入你的管理员账号密码，Confluence就安装完成了。
