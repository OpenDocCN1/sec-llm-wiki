# 如何自定义微服务的Instance ID

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQ3NjE2OA==&mid=2247483777&idx=1&sn=fb0413a0dc503bdc04ce32edb0d0a6bb&chksm=ec3c9ce6db4b15f0a5918e3fb26a2356569b478ab0c2cc52e6be440ab57b1d02df2a9a94df71&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247483777&idx=1&sn=fb0413a0dc503bdc04ce32edb0d0a6bb&chksm=ec3c9ce6db4b15f0a5918e3fb26a2356569b478ab0c2cc52e6be440ab57b1d02df2a9a94df71&scene=27#wechat_redirect)

本文我们来探讨如何自定义微服务的Intance ID。Instance ID用于唯一标识注册到Eureka Server上的微服务实例。

我们可在Eureka Server的首页直观地看到各个微服务的Instance ID。例如，图11-1中的`itmuch:microservice-provider-user:8000` 就是Intance ID。

![](../Images/a3e46f0ea8f77b6396af061ebbbe9d6e.png)

图11-1 Eureka Server上的微服务列表

在Spring Cloud中，服务的Instance ID的默认值是`${spring.cloud.client.hostname}:${spring.application.name}:${spring.application.instance_id:${server.port}}` 。如果想要自定义这部分的内容，只需在微服务中配置`eureka.instance.instance-id` 属性即可，例如：

  

| 

```
123456
```

 || 

```
spring:  application:    name: microservice-provider-usereureka:  instance:    instance-id: ${spring.cloud.client.ipAddress}:${server.port}	\# 将Instance ID设置成IP:端口的形式
```

 |
| --- | --- |

  

这样，就可将微服务`microservice-provider-user` 的Instance ID设为IP:端口的形式。这样设置后，效果如图11-2所示。

![](../Images/6e68cef753bbee443a677925a4b5fe45.png)

图11-2 Eureka Server上的微服务列表
