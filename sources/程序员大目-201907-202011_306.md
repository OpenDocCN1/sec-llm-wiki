# 20个堪称神器的命令行软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI4ODQ3NjE2OA==&mid=2247486236&idx=2&sn=2cb9dc29ce8b523a96a82773237e8cfc&chksm=ec3c967bdb4b1f6d9dd76fb4bb1fd299d2d39a74c88d2003b2f5476f22c76bd0fcef04572fd1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI4ODQ3NjE2OA==&mid=2247486236&idx=2&sn=2cb9dc29ce8b523a96a82773237e8cfc&chksm=ec3c967bdb4b1f6d9dd76fb4bb1fd299d2d39a74c88d2003b2f5476f22c76bd0fcef04572fd1&scene=27#wechat_redirect)

### 点击上方**"IT牧场"**，选择**"设为星标"**技术干货每日送达！

**1.ag：**比grep、ack更快的递归搜索文件内容。

![](../Images/6d6b9499b712330d0f38b142254fe1c1.png)

**2.tig：**字符模式下交互查看git项目，可以替代git命令。

![](../Images/08ee0ce93006fe2e7c1da516807f951a.png)**3.mycli：**mysql客户端，支持语法高亮和命令补全，效果类似ipython，可以替代mysql命令。

![](../Images/23e3545e0a4e7a9979fa68a4374cddb1.png)

**4.jq:** json文件处理以及格式化显示，支持高亮，可以替换python -m json.tool。

![](../Images/3259bf1f32ebfd9c2e685f0dc179e8b0.png)

**5.shellcheck：**shell脚本静态检查工具，能够识别语法错误以及不规范的写法。![](../Images/4e0e6eee082650a23a8a7f05cd1f34a2.png)

**6.yapf：**Google开发的python代码格式规范化工具，支持pep8以及Google代码风格。

**7.mosh：基于UDP的终端连接，**可以替代ssh，连接更稳定，即使IP变了，也能自动重连。

**8.fzf：**命令行下模糊搜索工具，能够交互式智能搜索并选取文件或者内容，配合终端ctrl-r历史命令搜索简直完美。

**![](../Images/ce41b53056fa511a783cb34696f4fcc2.png)9.PathPicker(fpp):**在命令行输出中自动识别目录和文件，支持交互式，配合git非常有用。

运行以下命令：

```
git diff HEAD~8 --stat | fpp
```

![](../Images/e2253896d83eedd5745a72972ea2c25a.png)

**10.htop: **提供更美观、更方便的进程监控工具，**替代top命令。**

![](../Images/6ae45141c5ab61cc45dbc228da424ddb.png)

**11.axel：**多线程下载工具，下载文件时可以替代curl、wget。

```
axel -n 20 http://centos.ustc.edu.cn/centos/7/isos/x86_64/CentOS-7-x86_64-Minimal-1511.iso
```

![](../Images/ee428e300799a15020801a7ef59237ed.png)

**12.sz/rz：**交互式文件传输，在多重跳板机下传输文件非常好用，不用一级一级传输。

**13.cloc：**代码统计工具，能够统计代码的空行数、注释行、编程语言。

![](../Images/0294c1c8aad8e53e9393a6d872a14205.png)

**14.ccache：**高速C/C++编译缓存工具，反复编译内核非常有用。使用起来也非常方便：

```
gcc foo.c
```

改成:

```
ccache gcc foo.c
```

**15.tmux：终端复用工具，替代screen、nohup。**

![](../Images/f544a2488eeb8351e027528be4c9c290.png)

**16.neovim: **替代vim。

**17.script/scriptreplay: **终端会话录制。

```
script -t 2>time.txt session.typescript # 录制开始# your commandsexit # 录制结束
```

回放:

```
scriptreplay -t time.txt session.typescript
```

**18.you-get: **非常强大的媒体下载工具，支持youtube、google+、优酷、芒果TV、腾讯视频、秒拍等视频下载。

还有mac专有的pbcopy/pbpaste：

把命令行输出拷贝到系统粘贴板：

```
cat test.sh| pbcopy
```

把系统粘贴板内容拷到终端:

```
pbpaste
```

mac下的say命令支持多种语言(英语、普通话、粤语)文本朗读，支持各种销魂恐怖的语气。跑这个命令感受下，小心被吓着了：

```
for i in `say -v '?' | cut -d ' ' -f 1`; do echo $i && say -v "$i" 'Hello World';done
```

**19.thefuck：**用途是每次命令行打错了以后，打一句fuck就会自动更正命令。比如apt-get打成了aptget。fuck以后自动变成apt-get。但还是没加sudo。再fuck，成功！

![](../Images/cb675dd4b9b30e7281deaf90275735e0.png)又比如git branch打成了git brnch。fuck！更正成git branch。  
![](../Images/a818daf355d7a31662a105902944ab28.png)又比如python打成了puthon。fuck！一秒变python。  
![](../Images/96c535e07d4c4a80481e14c47a21b6f5.png)而且关键是每次打命令和内心os完全一致，有种人机合一的快感。fuck！
