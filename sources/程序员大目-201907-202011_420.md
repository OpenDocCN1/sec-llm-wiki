## 构建环境  

*   macOS 10.13.6
    
*   JDK1.8
    
*   IntelliJ IDEA 2018.3.6 (Ultimate Edition)
    
*   Spring v5.1.9.RELEASE
    
*   Gradle 5.5.1。直接使用brew安装Gradle `brew install gradle`
    

## 源码构建

1.  源码导入
    

![](../Images/31ee9d850bfb498f2a0086f810ee1515.png)

源码导入

2.  阅读Spring源码下的 import-into-idea.md 文件可知，需要预先编译`spring-oxm`模块：
    

> Precompile `spring-oxm` with `./gradlew :spring-oxm:compileTestJava`

![](../Images/c79310416ba3398232f15a3432e99219.png)

compileTestJava

3.  修改 gradle/docs.gradle 脚本。一开始尝试直接构建Spring源码，在构建的过程中会报错，通过修改docs.gradle 脚本，注释 `dokka` 和 `asciidoctor`。
    

![](../Images/854e10e16a90a09c234c9f58a51a9a35.png)

修改docs.gradle 脚本

4.  源码构建。
    

![](../Images/332789fd88a2b8df1af3e14919c85016.png)

源码构建1

等了好长好长的时间，终于构建完成了。

![](../Images/4357b11b4a8b9c44965ca59874a5212f.png)

源码构建2

5.  在Spring项目中新增一个自己的module，尝试运行hello world，引入spring-context 依赖：`compile(project(":spring-context"))`
    

![](../Images/28bb4039d6feb6edbe16cee2b1724ee8.png)

my module

6.  运行main方法，发现报错
    

> Error:(160, 32) java: 找不到符号 符号: 变量InstrumentationSavingAgent 位置:

![](../Images/2822e025317180b069fa23e470a9fc3a.png)

报错

网上搜索了一大堆的解决方法，发现都不行。后来看了spring-context的依赖发现，spring-instrument 在 spring-context 中为 optional 依赖：`optional(project(":spring-instrument"))`，于是在自己的模块中添加spring-instrument依赖

![](../Images/95fadaf2f76da0f672465808286c915f.png)

添加依赖

再次运行main方法，程序运行成功。

ps：令我感到奇怪的是，当我在写这篇总结时，尝试通过移除spring-instrument依赖来复现上述的问题时，发现复现不了了，好神奇。
