Data Deposit Box's patented continuous cloud backup technology for Synology provides real time, end-to-end data cloud backup protection for 40+ Synology NAS devices with Synology OS 6.0 or higher across the FX and RS, Plus, Value and J Series lines. Synology admins can backup and manage an unlimited number of Synology, Windows, MacOS, iOS, Android, and Linux devices under a single account.
