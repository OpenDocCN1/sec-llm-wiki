英文：The professional data management suite Archiware P5 offers modules to manage data at any point in its life cycle: P5 Synchronize replicates data for immediate availability. P5 Backup creates security copies for easy restore. P5 Archive migrates data to disk or tape for long-term storage and provides a searchable catalogue including metadata and previews. Modules can be combined freely to achieve maximum security. Archiware P5 runs on Mac, Windows,Linux, FreeBSD and Solaris and is compatible with virtually any tape and disk storage hardware.  
中文：专业数据管理套件Archiware P5提供了在其生命周期的任何点管理数据的模块：P5 Synchronize可复制数据以立即可用。P5备份创建安全拷贝，以便于恢复。P5 Archive将数据迁移到磁盘或磁带以进行长期存储，并提供可搜索的目录，包括元数据和预览。模块可以自由组合以实现最大安全性。Archiware P5可在Mac、Windows、Linux、FreeBSD和Solaris上运行，并且几乎与任何磁带和磁盘存储硬件兼容。
