0x01 MISC一些基础解题方式整理

1)图片隐写

png隐写

1、图片内容隐写

面对这种隐写，直接将图片拖入010Editor中，拉到尾部，或者搜索关键字即可找到信息。

2、LSB隐写

拿到一个图片，拖入stegsolve中，在变换的时候，如果看到一边有一条的东西，那很可能就是LSB隐写。

比如这道经典的题目

拖入stegsolve中，发现在RGB的0通道都有一条横线。

使用Data Extract功能将0通道的数据分离。

保存为一张图片，即可得到LSB隐写的东西。

也可以用kali中的zsteg工具，来查看各个通道，将包含文件的通道分离。使用下列命令

zsteg flag11.pngzsteg flag11.png -e b1,rgb,lsb,xy(有文件的通道) > flag.png

4、文件长宽隐写

在PNG文件头的这八位数据分别表示PNG文件的长和宽,可以通过010自带的校验工具来计算，这个图片的长宽是否正确。

选中文件头中从IDAT开始到CRC之前的数据，点击工具里的计算校验和，选择CRC32，即可计算，若计算出的CRC值与图片中的CRC值不符，则说明长宽被改了，修改长宽即可得到隐藏的信息。

修改图片的高度为800

原来图片的隐藏信息就可以看到了

高度被修改了，将高度改高即可，但是长度被修改了，不修改为正确的值一般图片都是糊的，这就需要爆破脚本

import binasciiimport structimport sys
file = input("图片地址：")fr = open(file,'rb').read()data = bytearray(fr[0x0c:0x1d])crc32key = eval('0x'+str(binascii.b2a_hex(fr[0x1d:0x21]))[2:-1])#原来的代码: crc32key = eval(str(fr[29:33]).replace('\\x','').replace("b'",'0x').replace("'",''))n = 4095for w in range(n):    width = bytearray(struct.pack('>i', w))    for h in range(n):        height = bytearray(struct.pack('>i', h))        for x in range(4):            data[x+4] = width[x]            data[x+8] = height[x]        crc32result = binascii.crc32(data) & 0xffffffff        if crc32result == crc32key:            print(width,height)            newpic = bytearray(fr)            for x in range(4):                newpic[x+16] = width[x]                newpic[x+20] = height[x]            fw = open(file+'.png','wb')            fw.write(newpic)            fw.close            sys.exit()

这是CISCN2021隔空传话的题，在提取好短信的信息后得到图片，直接使用上面脚本爆破CRC即可得到正常的图片。

jpg隐写

1、jhps隐写

使用JHPS工具，打开图片，点击seek，有密码输入密码，没密码直接点击OK（一定要尝试一下，有的题目确实是没密码的），然后将txt保存，即可提取jhps隐写的文本。


这题是提取之后，看到右边有滚动条，拉到地下可以看到有一串数字。后面的步骤可以看DJBCTF2021十八般兵器具体研究。

2、文件属性隐写

直接将隐写的信息藏到文件的属性中，查看属性即可。

gif隐写

gif隐写通常是吧隐写的信息放在某一帧中，由于删过的速度很快难以捕捉，所以需要用stegsolve来将gif的每一帧拆开，来获得信息。这道经典的金三胖题目就是把隐写的信息藏在了一个帧里面。

通过stegsolve拆分帧，一帧一帧翻就可以翻到隐写的信息

其他图片隐写(apng等)

当遇到一种陌生的图片格式时，就需要用百度来搜索，收集信息。下面以GKCTF 你知道apng吗为例。拿到题目，题目名称是你知道apng吗。

于是搜索apng，发现apng是一种动图，但是打开文件发现是静态的，那就要想办法让图片动起来，并且发现firefox好像可以兼容apng文件。

于是把图片拖进firefox图片就动起来了，发现里面有些帧有二维码，把二维码扫描到的信息拼起来就是flag了。



2)音频隐写

解音频隐写的题目，通常需要Audacity软件，将音频文件直接拖进去，分析频谱找到隐写的信息。比如这段音频，上面的频谱图可能就是摩丝电码、盲文、或者是01编码等的一种需要具体分析。

mp3隐写

mp3有一个mp3stego的隐写，通常使用MP3Stego工具，使用密码解密即可得到隐写的内容。

Decode.exe -X -P 98eb1b1760bcc837934c8695a1cee923(解密密码) cov.mp3(文件名)

可以看到文件夹里面多了一个cov.mp3.txt里面就是隐写的内容 ![mp3隐写]

wav隐写

wav隐写通常会用到一个工具SilentEye,用这个工具来提取wav中的隐写信息。将有隐写的wav拖到SilentEye中

然后点击Decode，在跳出来的框中选好sound quality再点击decode。

即可提取隐写的信息。

DTMF隐写

DTMF隐写的特征是听到音频里面有电话号码的声音，或者分析频谱后，频谱图是这样的特征，那很可能就是dtmf隐写了。

DTMF通常参照DTMF音频的表来找

或者也有dtmf2num的软件来将音频转化为数字

3)压缩包解密

伪加密

拿到一个压缩包的时候，没有任何提示，不知道是什么密码，那很有可能就是伪加密。伪加密的原理是，压缩文件包头的全局方式位标记，有数字就表示加密。

伪加密只需要将压缩包拖到010Editor中，将文件全局方式位标记中的奇数改为00，那加密就消失了。

明文攻击

指的是题目给了一个加密的文件，和一个没有加密的另一个文件，那么就可以把这个没加密的文件，单独压缩成压缩包，两个相同的部分进行对比就可以爆破出压缩包的密码。

解这种提供可以用Elcomsoft Password Recovery中明文功能。

这个压缩包就是一个加密的文件，另一个没有加密的文件，将没有加密的文件提取出来，然后尝试各种压缩方式,当压缩方式相同时，就可以使用Elcomsoft Password Recovery的明文功能了

 

一般题目中间会有提示，使用了什么压缩方式。

最后选好压缩包，和自己创建好的明文压缩包就可以明文攻击了。

弱口令爆破

遇到需要爆破zip压缩包密码时，使用ziperello来进行爆破。这道题注释提示密码是8位数字直接爆破。

设置界面选择8位数字。

很快就能得到压缩包的密码。

hash爆破

有时候Elcomsoft Password Recovery爆破rar时，无法正常运行，那可以使用hashcat来进行密码的爆破。首先用rar2john命令来获得rar的hash。

再用hashcat来解出密码,这里注释里面提示密码是4位数字所以用?d?d?d?d来爆破

hashcat64.exe -m 13000 -a 3 $rar5$16$1349cb834c70bf27bb4e48bb3fbe6975$15$ca4a3bc58278b04d9fba4d7d52acb196$8$56245cd11e4a1c2e ?d?d?d?d

得到密码是9705

0x02总结

上述所讲的都是一些比较基本的隐写题目类型和解题方式，CTF比赛中通常都是比这些更复杂或者灵活得使用这些隐写方式的题目，因此当遇到比较陌生或者无从下手的题目时，百度搜集信息就非常重要，往往解题的关键就在你百度搜集到的信息那里。
