0x01 前言

Linux作为物联网领域的主流底层操作系统，安全问题将会愈发严峻。要想将linux的安全问题解决，得从它的运行、功能等多方面角度来分析，从而解决那些显而易见的安全问题。Linux有很多发行的版本，目前大部分用的是centos6.5 、7，其次是Ubuntu16、14等。系统之间存在差异，但安全的大体方向是相同的。

关于linux的更多动态和知识，可以参考：https://www.linuxidc.com/

0x02 帐号管理

1、密码设置

•避免弱口令•口令设置有效期•是否有人长时间猜测口令•自检自查。JOHN、crack等暴力工具。•在BIOS设置中设定一个BIOS密码，不接收软盘启动。这样可以阻止他人用专门的启动盘启动你的Linux系统，并避免BIOS设置被更改

2、shadow文件

/etc/shadow 文件，用于存储 Linux 系统中用户的密码信息，又称为“影子文件”。

/etc/shadow 文件只有 root 用户拥有读权限，其他用户没有任何权限，这样就保证了用户密码的安全性。

与 /etc/passwd 文件不同的是，/etc/passwd 允许所有用户读取。为了安全起见，需定期检查shadow文件的内容，例如是否存在空口令。

该文件各字段含义：用户名：加密密码：最后一次修改时间：最小修改时间间隔：密码有效期：密码需要变更前的警告天数：密码过期后的宽限时间：账号失效时间：保留字段

3、密码管理

•设置口令有效最长时限 （编辑/etc/login.defs文件）•口令最短字符（如linux默认为５，可以通过编辑/etc/login.defs修改）•只允许特定用户使用su命令成为root。•编辑/etc/pam.d/su文件，在文件头部加上：

#This allows root to su without passwords (normal operation)
auth sufficient /lib/security/pam_rootok.so debug  
auth required /lib/security/pam_wheel.so group=wheel  //这表明只有wheel组的成员可以使用su命令成为root用户。你可以把用户添加到wheel组，以使它可以使用su命令成为root用户。

4、账户清理

•清除不必要的系统帐户

userdel lp
userdel adm
userdel sync
userdel shutdown
userdel halt
userdel news
userdel uucp
userdel operator
userdel gopher
userdel games  (如果不使用 X Window，则删除)
userdel ftp    （如果不使用ftp服务则删除）
修改shadow,passwd,gshadow文件不可改变位
chattr +i /etc/passwd  //不允许修改。若是目录，则不允许新建、删除文件
chattr +i /etc/shadow
chattr +i /etc/group
chattr +i /etc/gshadow

•不要使用.netrc文件（可被用来自动地ftp）•使用ssh来代替telnetd,ftpd.pop等传统的网络服务程序，因为它们在网络上用明文传送口令和数据。

0x03 服务管理

对外开放的服务是很多安全问题的根源。针对这一点，主要就是两个原则：

①只开放需要的服务
②不同的服务部署在不同的主机上。

0x04 系统设置

1、限制控制台的使用

禁止使用控制台程序：删除/etc/security/console.apps中的服务

rm -f /etc/security/console.apps/servicename，
rm -f /etc/security/console.apps/halt
rm -f /etc/security/console.apps/poweroff
rm -f /etc/security/console.apps/reboot
rm -f /etc/security/console.apps/shutdown
rm -f /etc/security/console.apps/xserver

禁止控制台的访问：在/etc/pam.d中的所有文件中，给包含pam_console.so的行加上注释

2、系统关闭Ping

关闭ping，使系统对ping不做反应，对网络安全大有好处。

可以使用如下命令：

echo 1 > /proc/sys/net/ipv4/icmp_echo_ignore_all

可以将这一行加到/etc/rc.d/rc.local文件中去，这样系统重启动后会自动执行

恢复系统的Ping响应：

echo 0 > /proc/sys/net/ipv4/icmp_echo_ignore_all

3、关闭或更改系统信息

关闭telnet系统信息：

在Red Hat 6.2中,编辑/etc/inetd.conf

telnet stream tcp nowait root /usr/sbin/tcpd in.telnetd –h

加上参数-h可以关闭telnet信息。

在Red Hat 7.0中,编辑/etc/xinetd.d/telnet。加上

server_args = -h

,可以关闭telnet信息。

在/etc/rc.d/rc.local中关闭或修改系统信息：

/etc/issue和/etc/issue.net中包含本地登录和网络登录时提示的系统信息,对它们进行更改可以改变系统信息。

也可以直接删除,并在/etc/rc.d/rc.local文件中注释相关行:

echo "" > /etc/issue
echo "$R" >> /etc/issue
echo "Kernel $(uname -r) on $a $(uname -m)" >> /etc/issue
cp -f /etc/issue /etc/issue.net
echo >> /etc/issue

4、etc/securetty文件

/etc/securetty文件规定root从哪个TTY设备登录,列出的是允许的tty设备,将不允许的tty设备行注释掉.

5、etc/host.conf文件

/etc/host.conf定义主机名怎样解析,使用什么服务,什么顺序解析

# Lookup names via DNS first then fall back to /etc/hosts.
order bind,hosts
# We have machines with multiple IP addresses.
multi on
# Check for IP address spoofing.
nospoof on

order指定选择服务的顺序

multi指定主机能不能有多个IP地址,ON代表允许

nospoof指定不允许IP伪装,此参数必须设置为ON

6、禁止IP源路径路由

允许IP源路径路由(IP source routing)会使得黑客能够欺骗你的计算机,截取信息包，强烈建议禁止，使用如下命令：

for f in /proc/sys/net/ipv4/conf/*/accept_source_route; do
echo 0 > $f
done

将accept_source_route设置为0，并将上述命令加到/etc/rc.d/rc.local中去，每次重启动将自动执行。

7、资源限制（防DDOS）

为了避免拒绝服务攻击，需要对系统资源的使用做一些限制。

首先，编辑/etc/security/limits.conf，加入或改变如下

* hard core 0 （禁止创建core文件）

* hard rss 5000 （除root外，其他用户最多使用5M内存）

* hard nproc 20 （最多进程数限制为20）

编辑/etc/pam.d/login,在文件末尾加上：

session required /lib/security/pam_limits.so

对TCP SYN Cookie的保护：（防止SYN Flood攻击）

echo 1 > /proc/sys/net/ipv4/tcp_syncookies

8、LILO安全

LILO（Linux Loader)，即Linux引导程序。LILO是一个在系统启动时运行的程序，它用于选择引导计算机启动的操作系统。

在“/etc/lilo.conf”文件中添加3个参数：time-out、restricted 和 password。这些选项会在启动时间（如“linux single”）转到启动转载程序过程中，要求提供密码。

步骤1

编辑lilo.conf文件(vi　/etc/lilo.comf),加入或改变这三个参数：

　　boot=/dev/hda

　　map=/boot/map

　　install=/boot/boot.b

　　time-out=00　　　 #把这行该为00

　　prompt

　　Default=linux

　　restricted　　　 #加入这行

　　password=xxx　　　#加入这行并设置自己的密码

　　image=/boot/vmlinuz-2.2.14-12

　　label=linux

　　initrd=/boot/initrd-2.2.14-12.img

　　root=/dev/hda6

　　read-only

步骤2

因为"/etc/lilo.conf"文件中包含明文密码，所以要把它设置为root权限读取。

chmod 600 /etc/lilo.conf （不再为全局可读）

步骤3

作了上述修改后，更新配置文件“/etc/lilo.conf”。

/sbin/lilo -v （更新lilo.conf文件）

步骤4

使用"chattr"命令使"/etc/lilo.conf"文件变为不可改变。

chattr +i /etc/lilo.conf

它将阻止任何对“lilo.conf”文件的更改。

9、Control-Alt-Delete键盘关机命令

编辑“/etc/inittab”文件，只要在下面行前面加“＃”，改为注释行。

ca::ctrlaltdel:/sbin/shutdown -t3 -r now

然后，为使更改生效，在提示符下输入：

/sbin/init q

10、日志系统安全

为了保证日志系统的完整性，防止黑客删除日志，需要对日志系统进行安全配置。

11、修正脚本文件在/etc/rc.d/init.d”目录下的权限

对脚本文件的权限进行修正，脚本文件用以决定启动时需要运行的所有正常过程的开启和停止。添加：

chmod -R 700 /etc/rc.d/init.d/*

0x05 文件系统

1、文件权限

(SUID 是 Set User ID, SGID 是 Set Group ID的意思。)

•去掉不必要的suid程序，可以通过脚本查看

find / -type f \( -perm -04000 -o -perm -02000 \) \-exec ls –lg {}\;

通过下面的命令来去掉不需要的程序的‘s’位(所有用户都不再具有s权限)

chmod a-s /usr/bin/commandname

•重要的配置文件如/etc/passwd,/etc/shadow,/etc/inetd.conf等设置为0755,并设置为不可更改•/etc, /usr/etc, /bin, /usr/bin, /sbin, /usr/sbin, /tmp and/var/tmp的属主是root,并且设置粘滞（设置了粘滞位后，只有目录内文件的所有者或者root才可以删除或移动该文件。）。•/dev目录下没有特殊文件。•查找任何人可写的文件和目录

find / -type f \( -perm -2 -o -perm -20 \) -exec ls -lg {} \;
find / -type d \( -perm -2 -o -perm -20 \) -exec ls -ldg {} \;

•查找异常文件，如..文件，…文件等

find / -name ".. " -print –xdev
find / -name ".*" -print -xdev | cat -v

•检查没有属主的文件。

find / -nouser –o –nogroup

•检查在/dev目录以外还有没有特殊的块文件

find / \( -type b -o -type c \) -print | grep -v '^/dev/'

•使用checksum md5 或者PGP来效验文件

2、控制mount上的文件系统

可以使用noexec, nodev, nosuid来控制mount上的文件系统.在/etc/fstab中设置，比如：

将/dev/sda11 /tmp ext2 defaults 1 2

/dev/sda6 /home ext2 defaults 1 2

改为：/dev/sda11 /tmp ext2 nosuid,nodev,noexec 1 2

/dev/sda6 /home ext2 nosuid,nodev 1 2

noexec表示不允许可执行，nodev表示不允许块设备，nosuid表示不允许suid位

3、备份与恢复

定期对文件系统进行备份，可以将损失减小到最小程度。

Linux下有多种方法进行备份，如：dd, cpio, tar, dump等

0x06 iptables的使用

•安装iptables

yum install iptables-services

•关闭

systemctl stopfirewalld.service
systemctl disablefirewalld.servic

•查看现有规则

iptables -L

•清空所有默认规则

iptables -F

•清空所有自定义规则

iptables -X

•所有计数器清零

iptables -Z

•允许来自于lo接口的数据包本地访问

iptables -A INPUT -I lo -jACCEPT

•指定开放22端口

iptables -A INPUT -p tcp–dport 22 -j ACCEPT

•禁止111.111.11.1 IP地址访问

iptables -A INPUT -s 111.111.11.1 -p tcp-dport 22 -j DROP

•开放固定IP访问8080

iptables -I INPUT -s 111.111.11.1 -p tcp –dport 8080 -j ACCEPT

•禁止ping

iptables -A INPUT -p icmp–icmp-type 8 -s 0/0 -j DROP

•添加内网IP信任

iptables -A INPUT -p tcp -s 10.0.0.2 -j ACCEPT

•允许接受本机请求之后的返回数据RELATED

iptables -A INPUT -m state–state RELATED,ESTABLISHED -j ACCEPT

•限制流量

iptables -A INPUT -I eth0-m limit --limit 5/m –limit-burst 15 -j ACCEPT

•特定时间内匹配

iptables -A INPUT -i eth0-m time --weekdays 1,3,5 -j ACCEPT

•匹配符合规则的TTL值得数据包

iptables -A OUTPUT -m ttl–ttl-eq 51 -j ACCEPT

•匹配指定的状态数据包

iptables -A INPUT -m state --stateNEW,ESTABLISHED -j ACCETP

•匹配带有指定的mark值的数据包

iptables -t mangle -A INPUT-m mark --mark 1 -j DROP

•匹配指定的mac地址

iptable -A FORWARD -m mac --mac-source 00:0C:22:38:49:61 -j DROP

•映射端口(将mysql默认的3306端口映射到1306对外提供服务)

iptables -t mangle -IPREROUTING -p tcp -dport 1306 -j MARK --set-mark 3306

•过滤所有非以上规则的请求

iptables -P INPUT DROP

•保存iptables规则

service iptables save

•自动开启iptables服务

systemctl enableiptables.service

•查看状态

systemctl status iptables.service

0x07 日志管理

1、syslog登录事件

more /etc/syslog.conf

查看参数authpriv值。若未对所有登录事件都记录，则低于安全要求。

2、syslog.conf的配置审核

执行：more /etc/syslog.conf，

查看是否设置了下列项：

 kern.warning; *.err; authpriv.none\t@loghost   *.info; mail.none; authpriv.none; cron.none\t@loghost   *.emerg\t@loghost   local7.*\t@loghost

若未设置，则低于安全要求。

3、非日志服务器禁止接收syslog、

cat /etc/rc.config.d/syslogd

检查是否存在SYSLOGD_OPTS="-N"

ch_rc -a -p SYSLOGD_OPTS="-N" /etc/rc.config.d/syslogd

4、启用inetd日志记录

cat /etc/rc.config.d/netdaemons | grep INETD_ARGS=-l

查看该文件是否存在INETD_ARGS=-l

ch_rc -a -p INETD_ARGS=-l /etc/rc.config.d/netdaemons

5、检查日志文件权限

使用chmod配置相关文件的权限即可。

0x08 协议配置

1、关闭IP转发

ndd -get /dev/ip ip_forwarding

查看是否关闭IP转发，返回值应为0

操作：

1、备份cp -p /etc/rc.config.d/nddconf /etc/rc.config.d/nddconf_bak2、执行下列命令，设置参数使参数在当前系统状态下临时生效：ndd -set /dev/ip ip_forwarding 0建立启动项，使参数重启后永久生效：cd /etc/rc.config.dcat <<EOF >> nddconf# Don't ip forwardingTRANSPORT_NAME[0]=ipNDD_NAME[0]= ip_forwardingNDD_VALUE[0]=0EOF

2、关闭转发源路由包

ndd -get /dev/ip ip_forwarding

查看是否关闭IP转发，返回值应为0

ndd -set /dev/ip ip_forward_src_routed 0建立启动项，使参数重启后永久生效：cd /etc/rc.config.dcat <<EOF >> nddconf# Drop source-routed packetsTRANSPORT_NAME[1]=ipNDD_NAME[1]=ip_forward_src_routedNDD_VALUE[1]=0EOF

3、增大最大半连接数

ndd -get /dev/tcp tcp_syn_rcvd_max

查看返回值应最小为4096

ndd -set /dev/tcp tcp_syn_rcvd_max 4096

4、关闭ICMP重定向

ndd -get /dev/ip ip_send_redirects

查看是否关闭ICMP重定向，返回值应为0

ndd -set /dev/ip ip_send_redirects 0

5、关闭响应echo广播

ndd -get /dev/ip ip_forward_directed_broadcastsndd -get /dev/ip ip_respond_to_echo_broadcast

查看是否关闭IP转发，返回值应为0

ndd -set /dev/ip ip_forward_directed_broadcasts 0ndd -set /dev/ip ip_respond_to_echo_broadcast 0

6、关闭响应地址掩码和时间戳广播防止探测

ndd -get /dev/ip ip_respond_to_address_mask_broadcast
ndd -get /dev/ip ip_respond_to_timestamp_broadcast

返回值应为0

ndd -set /dev/ip ip_respond_to_address_mask_broadcast 0ndd -set /dev/ip ip_respond_to_timestamp_broadcast 0

0x09 其它

作为管理人员，应当配置日志轮转工具，定期下载备份日志，这样不但能减少日志的消耗的磁盘空间，提高系统效率，更能及时发现问题，linux下有些很好的系统日志分析器可以拿来用。

另外，应当使主机处于单独（或隔离）的网络中。以防止未受保护的主机连接到其它网络，或在互联网中受到可能的攻击。

用下面的命令卸载一些不需要的软件：

rpm –e softwarename

卸载它们之前停掉三个进程：

/etc/rc.d/init.d/apmd stop //电源管理
/etc/rc.d/init.d/sendmail stop //邮件发送
/etc/rc.d/init.d/kudzu stop //硬件自动检测程序

另外，在安装系统时应该注意，如果用root分区记录数据，如log文件和email，就可能因为拒绝服务产生大量日志或垃圾邮件，从而导致系统崩溃。因此，最好为特殊的应用程序单独开一个分区，特别是可以产生大量日志的程序，以避免root分区被溢出。如/var,/home等。

至此，大部分可能存在安全隐患的点就被清除了。当然，主机安全中要做的远远不止这些，这些只是被动的、静态的防御，现实的主机安全还需要更多维度的考量。
