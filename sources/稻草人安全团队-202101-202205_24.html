0x01 基础知识

动态代理

•动态代理是由Proxy Java反射类提供实例创建的调派，由Proxy.newProxyInstance()方法帮我们创建对应的实例对象。•通过InvocationHandler接口中的invoke方法进行调用、增强、转发实现业务。

实现动态代理需要4个角色：抽象接口(比如某个共同动作)、真实对象、代理对象(负责生成代理对象)、测试类(调用者可以说是客户)

import java.lang.reflect.InvocationHandler;import java.lang.reflect.Method;import java.lang.reflect.Proxy;//抽象对象interface ASellService {    void sale(String name);}//真实对象Aclass ASA implements ASellService {    @Override    public void sale(String name) {        System.out.println(name + "购买了A的商品");    }}//真实对象Bclass ASB implements ASellService {    @Override    public void sale(String name) {        System.out.println(name + "购买了B的商品");    }}//代理对象class Agency implements InvocationHandler {    //为了提高复用性,这里把真实对象写成Object    private Object object;    public Object getObject() {        return object;    }    public void setObject(Object object){        this.object = object;    }    //使用jdk代理类获取代理对象    public Object getProxyInstance() {        return Proxy.newProxyInstance(                object.getClass().getClassLoader(),                object.getClass().getInterfaces(),                this        );    }    @Override    public Object invoke(Object proxy , Method method , Object[] args) throws Throwable {        System.out.println("JDK动态代理对业务进行增强处理");        //通过反射的方法调用方法本身        Object invoke = method.invoke(object,args);        System.out.println("JDK动态代理对业务增强结束");        return invoke;    }}//测试类public class N0Tai1 {    public static void main(String[] args) {        //A商品        ASellService A = new ASA();        //B商品        ASellService B = new ASB();        //购买者        String name = "N0Tai1";        //代理公司        Agency agency = new Agency();        //使用set将代理公司的代理目标设置成A商家        agency.setObject(A);        //将代理公司生成的A商家代理对象强转成A商家的类型        ASellService Asa_Proxy = (ASellService) agency.getProxyInstance();        System.out.println("业务员"+Asa_Proxy.getClass()+"接待"+name);        Asa_Proxy.sale(name);    }}

了解下几个Class文件

先了解一下这几个class文件

Transformer

只是一个接口，里面是一个Object类型的待实现方法，接受的参数也是Object类型，跟我们上面写的动态代理的接口长得不能说一模一样，但是可以说没什么区别

package org.apache.commons.collections;
public interface Transformer {    Object transform(Object var1);}

ChainedTransformer

内容有点多，不过链子里就用到了一个构造方法，就是单纯的把收到的参数给了iTransformers这个数组

把transformer连接成一条链，对一个对象依次通过链条内的每一个transformer进行转换

package org.apache.commons.collections.functors;
public class ChainedTransformer implements Transformer, Serializable {    private final Transformer[] iTransformers;    public ChainedTransformer(Transformer[] transformers) {         this.iTransformers = transformers;    }}

ConstantTransformer

0x05 基于LazyMap类下get方法的完整POC

参考：https://www.cnblogs.com/nice0e3/p/13791793.html

利用链是这样的

AnnotationInvocationHandler该类是用来处理注解的

AnnotationInvocationHandler类的构造函数有两个参数，第⼀个参数是⼀个Annotation类类型参数，第二个是map类型参数

getDeclaredConstructor方法

参考：https://blog.csdn.net/J_Jie_/article/details/109607661

getDeclaredConstructor().newInstance()得到实例化对象:这个方法会返回制定参数类型的所有构造器，包括public的和非public的，当然也包括private的,getDeclaredConstructors()的返回结果就没有参数类型的过滤了
getConstructor().newInstance()得到实例化对象:这个方法返回的是上面那个方法返回结果的子集，只返回制定参数类型访问权限是public的构造器,getConstructors()的返回结果同样也没有参数类型的过滤

我们需要给他来一波实例化，我尝试过直接实例化来着，但是这个是一个default类型的构造方法....只能当前package中调用，这里我们需要 getDeclaredConstructor(参数类型).newInstance(参数)来实例化这个构造器，这里AnnotationInvocationHandler的构造方法要的刚好是Class和Map

往下看invoke

这里会调用get

是一个Map类型，那问题是我们怎么调用到invoke，这里用到了一个动态代理的特性 代理对象调用任意方法，调用处理器中的invoke()方法都执行一次(这里我们在上面的动态代理例子中有写) ，就会调到前面说的get方法造成rce

invoke的部分，我们可以通过InvocationHandler来代理后触发

InvocationHandler handler = (InvocationHandler) AIHconstruct.newInstance(Retention.class, lazyMap);//通过newInstance实例化了一个对象
Map proxyMap = (Map) Proxy.newProxyInstance(                Map.class.getClassLoader(),                new Class[] {Map.class},                handler        );//这里就已经代理成功触发到了invoke
handler = (InvocationHandler) AIHconstruct.newInstance(Retention.class, proxyMap);//这里只是为了拿到这个实例化对象,方便生成payload....

newProxyInstance的3个参数

•ClassLoader : 1.类的加载器•Class[] : 2.数组 因为一个类可以实现多个接口 被增强的对象实现的所有接口•InvocationHandler : 3. 是一个接口 处理类
