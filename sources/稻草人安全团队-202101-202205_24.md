### 动态代理

•动态代理是由Proxy Java反射类提供实例创建的调派，由Proxy.newProxyInstance()方法帮我们创建对应的实例对象。•通过InvocationHandler接口中的invoke方法进行调用、增强、转发实现业务。

实现动态代理需要4个角色：抽象接口(比如某个共同动作)、真实对象、代理对象(负责生成代理对象)、测试类(调用者可以说是客户)

先了解一下这几个class文件

#### Transformer

只是一个接口，里面是一个Object类型的待实现方法，接受的参数也是Object类型，跟我们上面写的动态代理的接口长得不能说一模一样，但是可以说没什么区别

*   
*   
*   
*   
*   

```
package org.apache.commons.collections;
public interface Transformer {    Object transform(Object var1);}
```

#### ChainedTransformer

内容有点多，不过链子里就用到了一个构造方法，就是单纯的把收到的参数给了iTransformers这个数组

把transformer连接成一条链，对一个对象依次通过链条内的每一个transformer进行转换

*   
*   
*   
*   
*   
*   
*   
*   

```
package org.apache.commons.collections.functors;
public class ChainedTransformer implements Transformer, Serializable {    private final Transformer[] iTransformers;    public ChainedTransformer(Transformer[] transformers) {         this.iTransformers = transformers;    }}
```
