知识点

「MP3Stego」

https://www.petitcolas.net/fabien/software/

MP3Stego是MP3的隐写工具，可以将数据隐写如MP3，也可以提取MP3中隐写的数据。

使用方法

decode.exe -X MP3文件名 -P 密码

「SilentEye」

https://sourceforge.net/projects/silenteye/

音频中的LSB(最低有效位)隐写，通常在题目中遇到wav文件，拖入软件解码即可得到隐写的信息。

「Steghide」

Steghide是一个可以将文件隐藏到图片或者音频工具中的文件

在Linux中用如下命令安装

apt-get install steghide

提取文件，再输入密码即可

steghide extract -sf 1.jpg

「维吉尼亚密码」

属于多表密码的一种简单形式，加解密需要密钥。在题目中遇到维吉尼亚密码，一定要考虑到会给密文和密钥，而且都是纯字母的。

解密网站https://www.qqxiuzi.cn/bianma/weijiniyamima.php

操作内容：

首先下载下来一个COV和hint压缩包，COV里面的是一个wav和mp3音频，还有一个内容加密的压缩包，hint里面是base32加密的。解码后得到三个网站和一句话，三个网站和一句话是用来解mp3隐写的密码。

由第三个网站知S为最大的结构蛋白

再通过第一个网站找到病毒代号和对应序列号，用第二个网站搜索对应的基因序列。

使用python idle进行md5加密

再用mp3stego进行解密

得到压缩包的密码。

将pass.wav拖到SilentEye解出一些东西。

用之前的密码解密压缩包，得到一个Hint2和jpg，hint2十六进制转字符串得到

由Hint2知道jpg是steghide隐写，他的密码由维吉尼亚密码加密，密钥就是第一句话的NME蛋白序列计数由高到低排的二十位字符+COMBAT。用网上找的脚本跑出来，由于有几位是相同的，所以要换位置尝试，最后得到密钥是LGASTRIQKNDPFEVYMWHCCOMBAT。

知识点

「OurSecret」

https://oursecret.soft112.com/

一款可以把可以把私密留言、照片或影片等藏进让人看到的图片、影片、文件这些负载文档里面的软件。这题就考察了工具的积累，通过图片名来猜测使用了这个软件进行隐写。

「零宽字符隐写」

零宽度字符是一种字节宽度为0的不可打印的Unicode字符, 在浏览器等环境不可见, 但是真是存在, 获取字符串长度时也会占位置, 表示某一种控制功能的字符。

解密网站 http://330k.github.io/misc_tools/unicode_steganography.html

「hashcat」

hashcat是一款自称为世界上最快的密码破解工具。详细的使用方法可以参考这篇文章https://blog.csdn.net/SHIGUANGTUJING/article/details/90074614?utm_medium=distribute.pc_relevant.none-task-blog-2%7Edefault%7EBlogCommendFromMachineLearnPai2%7Edefault-2.control&dist_request_id=&depth_1-utm_source=distribute.pc_relevant.none-task-blog-2%7Edefault%7EBlogCommendFromMachineLearnPai2%7Edefault-2.control在这道题里我们只用了hashcat RAR5的破解模式

下载地址https://hashcat.net/hashcat/

「CyberChef」

一款加解密工具，里面集成了各种各样的加解密方式

下载地址 https://github.com/gchq/cyberchef

总结

这两道题目都是路程比较长，综合性比较强的题目，当遇到题目给了完全陌生的东西时，需要静下心来，慢慢分析所给的网站怎么使用，所给的文件里面有什么线索是能代表这个是什么文件的。对于题目中的隐写，需要一些知识的累积，才能在拿到文件时，反应出来时什么隐写。最后还需要有一定的脚本编写能力，来处理做题过程中，发现的一些难以处理的字符。当给的话和文件名摸不着头脑时，可以尝试搜索一下其中的词或句子，说不定能找到相关的东西。
