## 0x01 fastjson原理解析

### 关于fastjson

*   Fastjson是Alibaba开发的，Java语言编写的高性能JSON库。采用“假定有序快速匹配”的算法，号称Java语言中最快的JSON库。
*   Fastjson接口简单易用，广泛使用在缓存序列化、协议交互、Web输出、Android客户端。
*   提供两个主要接口toJsonString和parseObject两个方法来分别实现序列化和反序列化。

fastjson的简单使用

![](../Images/189a23d0c7b8d3301749e7e8835c327b.png)反序列化![](../Images/19cb1e9405f7629605bf650f367b118a.png)

如下是Fastjson反序列化流程![](../Images/f2e58233c1c993a7a245cbcf96963d6f.png)简述一下反序列化流程

1.  DefaultJSONParser初始化
2.  parseobject会判断第二个参数传入的类

*   不存在第二参数,按照第一参数的类处理
*   第二参数是initDeserializers中的类则获取相应的deserializer
*   如果不是initDeserializers则由fastjson来完成创建新的deserializer

3.  进入JSON解析环节

上例的people类明显属于第二步的三者。简单对poc分析：

```

{
```

经过一系列的方法，最终调用JavaBeanDeserializer.deserialize接口,反序列化得到Gadget相关域。在这个过程中都是通过反射调用这些域的getter，setter或者is方法。其中就有dataSourceName属性。

```

public void setDataSourceName(String name) throws SQLException {
```

以及autoCommit属性

```

public void setAutoCommit(boolean var1) throws SQLException {
```

其中，在setAutoCommit被调用时，触发InitialContext的lookup方法，会连接到我们布置好的LDAP服务，从而加载恶意类，达到远程代码执行的目的。
