# \[安全资讯\] | 网络历史记录删得掉吗？

分享一个老掉牙的笑话：“如果我死了，请让我的网络历史记录陪葬。” 我相信每个人都这么想，因为无论如何小心翼翼，总会有一些不联系当时环境就无法理解的诡异浏览历史；而且还会手抖多次点进别人的脸书首页。即便当今互联网的发展神速，人们对网络隐私的理解却总是慢半拍。

这就是《就不告诉你(Stuff They Don't Want You To Know)》栏目组与《兼职天才(Part-Time Genius)》的威廉·皮尔逊和门戈·哈迪库多尔合作的原因，两者共同制作了网络隐私相关的两集节目。节目中马特·弗雷德里克、本·鲍林和诺埃尔·布朗先发制人，回答了一个棘手的问题：网络浏览记录是否删的掉？结果可能让你大吃一惊。

20世纪90年代末以来，互联网已与我们的生活密不可分。千禧伊始全球只有7%的人上网，而现在上网人数已突破40亿，超过了全球总人数的一半。因为网络已经影响到生活的方方面面，它不再是有钱人的专利，而成了天赋人权。

由于互联网用户基础庞大，收集用户信息成为一项艰巨的任务。搜索引擎(如谷歌)和社交媒体(如脸书)都存储着有极高商业价值的用户数据。这些日常生活数据对政府，包括黑客也价值不菲。但多亏了目标营销，越来越多的人意识到了自己网络信息的重要性。然而删除自己在网络社交媒体上的个人信息绝不是个一劳永逸的办法。

这种做法的问题在于数据库里的东西并没有真正的消失了。然而由于未经阅读就不假思索的同意了服务条款，收回已分享的个人信息只是痴人说梦罢了。虽说可能用户群体无法查看已删除的信息，但它并没有消失，该内容不再属于用户本身，只是换了个方式存储罢了。

举个栗子，只有申请永久销号才能删除脸书数据；而谷歌则可以永久保留个人信息，并在公司认为合适时使用；你可以在油管上删除视频，但视频还是会保存在服务器上；安卓手机可以在未经许可的情况下监听电话并录音。而这些行为在美国都是合法的：2017年3月，国会投票决定允许公司收集售卖用户的浏览数据；但在欧洲却不行。

但这不限于那些兜售用户信息的公司，美国国家安全局(National Security Agency)也从中获利。马特、本和诺埃尔在先前的视频里就讲了很多关于国家安全局的内容，主要是政府需要知道谁在何时何地出于何种原因浏览了这些网页。打着国家安全的幌子无所不用其极，从通过后台解锁iPhone寻找恐怖分子，到寻找那些浏览声援特朗普下台网站的用户。公民权力还是国土安全？法律的天平将倾向更有利的一方。
