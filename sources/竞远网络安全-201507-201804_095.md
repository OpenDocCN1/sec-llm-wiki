# \[安全资讯\] | “工具党”是如何破解游戏反修改功能的

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650268872&idx=1&sn=b0cbb515f4ab527408d1970f82b21d33&chksm=82d4dab1b5a353a7054e08afd20daf2dbe7cfa5be477062c3bb4dbec953a7b219203e48eba67&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650268872&idx=1&sn=b0cbb515f4ab527408d1970f82b21d33&chksm=82d4dab1b5a353a7054e08afd20daf2dbe7cfa5be477062c3bb4dbec953a7b219203e48eba67&scene=27#wechat_redirect)

游戏修改器可以实现很多变态功能，像无敌、倍攻、秒杀等，但是现在很多游戏都使用了MTP手游保护，游戏修改器无法使用。

使用某修改器添加游戏，可以看到很多进程，选择主进程4333。

![](../Images/ff0d9be8f52d590f88ed53a5a68873a6.png)

附加后会出现如下图所示异常：

![](../Images/6a16984c14a7d7ae6242458416ef7bcd.png)  

无法正常使用修改器，出现这个界面后，游戏即会闪退。这是因为MTP也就是手游保护模块带有反修改器功能。下图是他的功能介绍和收费标准：  

![](../Images/c4d231bd8f71b7111dbd1b2b42a65e12.png)  

对外服务的话，反修改器功能需要5000元每月。

下面就来分析一下，如何能把这个功能过掉。

运行adb shell,进入命令行模式，先找到该游戏进程的uid为u0\_a78：

![](../Images/99c4ae104b582d03a63bae5fc05cd4e3.png)  

把uid为u0\_a78都列出来：  

![](../Images/162f6c0641ea82e9bc0b8eb4293126de.png)  

看下debuggerd进程的程序路径：  

![](../Images/7a214b797f3066081ad2387646f66abe.png)  

/data/data/com.tencent.tmgp.sgame/files/路径是APP运行后才生成的，游戏在这个目录释放了一个GameProtector3文件，并做为一个子进程运行。

下图是IDA分析出来的，释放GameProtector3过程的代码。

![](../Images/09839f6b95bb05cb762605ee76c6774c.png)  

GameProtector3顾名思义，这是一个游戏保护程序。假设如果让这个进程运行不起来，应该就会使反修改器功能失效了。

使用MT管理器，做如下操作:把/data/data/com.tencent.tmgp.sgame/files/目录取的可执行权限都去掉。

![](../Images/630c97e3959e1b0bbad3681ed0d9a04c.png)  

重新启动游戏，使用修改器attach的时候，界面变成了下图所示：  

![](../Images/63865fec6426e3e4fc4d4bb4a40c231c.png)  

已经没有了debuggerd进程，也就是/data/data/com.tencent.tmgp.sgame/files/GameProtector3没有被执行起来。

下面就可以愉快得使用修改器了。

![](../Images/fa184f43356b68c91176798f12636ea0.png)  

整个过程只要使用MT管理器，就可达到过掉反修改器的功能，实际上反暂停之类的功能也都失效了。
