# \[安全资讯\] | Face ID是否使iPhone X更安全？答案可能取决于你自己

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650268794&idx=1&sn=b0b7e1437f03eca2835424033e0e44b3&chksm=82d4da03b5a35315eaf2dfcf90666459f523fada7812cc25828e457656ff0c6f8c319bef15c9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650268794&idx=1&sn=b0b7e1437f03eca2835424033e0e44b3&chksm=82d4da03b5a35315eaf2dfcf90666459f523fada7812cc25828e457656ff0c6f8c319bef15c9&scene=27#wechat_redirect)

这次的苹果发布会看完之后感觉如何，是否也觉得乏善可陈没有太多亮点呢，当然 iphone X 可算是主角中的主角了。

苹果周二宣布推出三款新款 iPhone（X，8和8 Plus）iPhone X（发音为“十”）标志着 iPhone 诞生十周年。

推出的 iPhone X 配备先进的面部识别技术，称为Face ID，它依赖于苹果的 TrueDepth 相机系统。该技术具有七种传感器和机器学习算法，但它是否真能保证你设备的安全呢？

![](../Images/fbe3fa8b8b98c9e0e49fdb151b5b3c83.png)  

SecureAuth 首席安全架构师 Stephen Cox 表示：

> 复制使用者的面部特征很困难，所以有人直接将用户的照片放在相机前，这样可以轻松地骗过面部识别的早期技术。而 iphone X 具有3D功能，可以判断距离，让简单的破解方法不能再起作用。对于Face ID 安全性如何，还要再观察观察，但可以肯定的是，黑客们已经都对此跃跃欲试了。

看来那些准备偷几张朋友圈自拍就能骗过Face ID 的人可以洗洗睡了。

这项新技术使用面部生物识别功能来鉴别你是否是手机的主人。Face ID 也取代了手机上的 Touch Id 指纹传感器。近年来，生物识别技术被运用到手机和平板中，一定程度上是因为它要比指纹识别更安全。

密码和 PIN 码可以被复制，被盗。生物技术其实有很多的优势，同时也为客户和企业提供了更安全的验证方式，虽然生物识别并不是一夜之间发生的，但消费者设备（如 iphone）中生物识别技术的普及可以让消费者熟悉越来越多的新技术。在苹果的带动下，脸部识别可能会成为一种业界标准。

![](../Images/9f3d8aa123782eeb1efd69505a1043c7.png)

实际上，指纹和脸部识别安全的安全性是否比指纹识别强，还是取决于你的威胁模式（threat model）。

> 威胁模式简单说就是你自己的“漏洞”。如果能知晓自己防御中的漏洞，并且洞悉攻击者的动态，隐私防护的成功性就会高很多。

每个人的威胁模式都是不同的，一名高中老师与咖啡厅中的工作人员面临的威胁是不同的。对于保护好我们的手机，最重要的就是不要轻易让别人获取到你的数据。手机上存储着我们最私密的信息，知晓你的威胁模式可以确定自己需要什么样的防护措施。

对于大部分人来说，一个小偷千辛万苦的在酒吧偷了你的手机，然后发现手机上锁了，然后小偷再跑回来把手机按在失主脸上进行Face Id 解锁是不可能的。你的手机虽然丢了，但是你的数据是安全的。

像别的人，比如记者，律师，活跃分子，都会受到不容程度的限制，比如他们可能在会在外国边境遭到警方逮捕或拘留，而当地的法律是允许执法人员搜查他们的手机。

在一些国家（比如美国）的法律规定中，那些有权限的警官是可以强迫嫌疑人将手放在 Touch ID 传感器上，强行搜索你的数据。同理，警察也可以把手机放在你的脸前，并用 Face ID 解锁。（这一过程反而更简单）

但你不能用法律强制嫌疑人告知你密码来解锁。因为宪法虽不保护你身上的东西，但保护你头脑中的东西。而且对于真正想负隅顽抗的嫌疑人来说，若要想方设法不透露密码的话，警方也确实没什么太好的方法。

![](../Images/3e0c6c04bf71dd9afed289c4157a9964.png)

大多数人不会觉得这样就会被拘留，解雇。因为他们觉得这样的事情离他们很远，倒霉的事情生活中太多了，怎么会就落到我身上呢——一个人被错误的逮捕了，手机上的信息也被查看了，然后莫名其妙地被无罪释放了。不到大祸临头，人们是不会主动争取自己的权利的。

选择手机解锁模式并不比交友，工作，恋爱简单多少。 Face Id 是否够安全，那还取决于你。
