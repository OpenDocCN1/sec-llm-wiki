# 竞远安全作为“安全发展联盟”创始成员出席2016广东互联网大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650268284&idx=1&sn=c5437d11c70364fa579e748ce02366c7&chksm=82d4dc05b5a3551337294572d1f4f330b8ca82adbe965404a18ce34f47100380e581841eaf1b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650268284&idx=1&sn=c5437d11c70364fa579e748ce02366c7&chksm=82d4dc05b5a3551337294572d1f4f330b8ca82adbe965404a18ce34f47100380e581841eaf1b&scene=27#wechat_redirect)

11月25、26日, 由广东省互联网信息办公室 、广东省通信管理局、 中国互联网协会发起，广东省互联网协会主办，广东互联网大会组委会及艾媒咨询集团承办的2016广东互联网大会暨全球移动互联网CEO峰会在广州琶洲保利世贸博览馆3楼5、6号馆隆重举行。

  

![](../Images/ad8cc776fd102873f5598abc0583cea0.png)  

  

![](../Images/98d681504da174cb752d6e9d253987a7.png)  

  

25日上午，由国家计算机网络应急技术处理协调中心广东分中心和广东省互联网协会共同发起，广东省互联网信息办公室和广东省通信管理局指导,“广东省移动互联网应用安全发展联盟”（以下简称“安全发展联盟”）成立仪式于“2016广东互联网大会”开幕式上举行，竞远安全作为“安全发展联盟”初始19家创立成员之一，与腾讯、百度、华为、中兴及三大运营商等创始成员，一起受邀出席了联盟成立仪式。共同参与移动互联网环境治理工作，建立移动应用安全应急协调和处置机制，推动应急防范平台建设，为联盟会员提供应急支撑等服务。

  

此外，竞远安全作为一家专业的安全服务机构，设立了专门的展位，积极学习其他行业的先进技术和理念，吸取行业大咖的专题分享经验。前来展台咨询安全业务的企业和个人川流不息，大家进行探讨和交流，促进合作。竞远安全公司不仅拥有雄厚的安全技术实力和技术过硬的专业团队，而且在风险评估、等级保护、渗透测试、安全应急、安全巡检、安全咨询等领域均有丰富的客户实践经验。不仅为工信部有关单位提供安全防护技术支撑，也为通信运营商及互联网等企业提供专业的安全服务。

本次广东互联网大会演讲嘉宾与参会企业阵容强大，两天共计250位演讲嘉宾。大会汇聚了来自硬件厂商、软件提供商、服务平台、大数据行业、企业服务、营销服务、新媒体等不同行业和领域的276余家参展企业，130多家媒体。8000余家知名互联网企业高层， 600多个知名企业家参会。从行业来看：包括投资者、创业者、从业者、互联网企业CEO/高管、数码达人等多元化人才。据不完全统计，现场参会观众多达8万人次。大会还组织了10余场高质量专业峰会，如：人工智能&大数据应用领袖峰会、企业服务与应用安全发展峰会、互联网金融发展峰会、泛娱VR/AR行业峰会等。

  

大会旨在传播广东前瞻领先的互联网思维，打造开放性、引领性、多样性于一体的互联网行业盛会，为企业发展提供一个资源互补、学习交流、拓展人脉、携手创新的好机会。促进了广东互联网产业的新一轮发展，顺应“互联网+”潮流，践行创新发展的思路。
