# 广东省第七期《网络通信安全管理员》培训与考试圆满落幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650268235&idx=1&sn=088a4eb78520e5d1df1860094935c45b&chksm=82d4dc32b5a3552438ac2e8fb3228cae216e12c9eae2e8b3399f1ad616e4ab01c5d6094fac7b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650268235&idx=1&sn=088a4eb78520e5d1df1860094935c45b&chksm=82d4dc32b5a3552438ac2e8fb3228cae216e12c9eae2e8b3399f1ad616e4ab01c5d6094fac7b&scene=27#wechat_redirect)

10月28日，“第七期增值电信企业网络通信安全管理员培训与考试”在广东邮电职业技术学院圆满落幕。来自广州、深圳、佛山、湛江、汕头、珠海等广东省近10个城市的100名考生参加了本期考前集训与考试。培训考试进行半年多以来，已经有近500家公司700多名学员参加。同时也得到了广东省通信协会和学员们的高度认可。

  

![](../Images/8d63f4eca3867179c6cbbba87828ebb9.png)  

  

广州竞远安全培训事业部总监陈金讲师根据知识点的重要性，在考前做了针对性培训，强化学员记忆，对考试起到了很好的辅导作用。作为安全员上岗考试培训课程提供方，广州竞远安全公司不仅承担了广东省通信企业协会的技术支撑工作，也为学员在实际工作中遇到的网络安全问题提供技术咨询服务，同时与学员之间建立了很厚的友谊。
