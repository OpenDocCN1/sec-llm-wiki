# 第六期《网络通信安全管理员》考试在竞远安全配合下顺利完成

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650268115&idx=1&sn=e2d0c6e781ca6cd17fbf91172a027768&chksm=82d4dfaab5a356bc1640eeaa51d90993c869ced7e29f440e97af931812c59ae2f8676b8833bf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650268115&idx=1&sn=e2d0c6e781ca6cd17fbf91172a027768&chksm=82d4dfaab5a356bc1640eeaa51d90993c869ced7e29f440e97af931812c59ae2f8676b8833bf&scene=27#wechat_redirect)

9月23日，“第六期增值电信企业网络通信安全管理员培训与考试”在广东邮电职业技术学院顺利结束。自2016年4月展开首期培训考试以来，进展非常顺利，得到了广东省通信协会和学员们的一致认可。截止到发稿日，《网络通信安全管理员》培训与考试已进行了六期，参加培训及考试的企业近500家，学员已超过600人。

  

![](../Images/bb80fc589d26f3df2ea92dc91b497d25.png)  

  

作为安全员上岗考试培训课程提供方，广州竞远安全公司不仅承担了广东省通信企业协会的技术支撑工作，也协助协会与学员进行沟通，同时解答学员日常工作中遇到的网络安全问题，更为学员之间学习探讨提供了一个交流的平台。

  

![](../Images/9e6ee546009e022ea68a56ab59316446.png)  

  

在本次培训学员中，一位来自湛江的坐轮椅的同学，长途跋涉，专程赶到广州参加考试，深深的感动了在场的全体人员。协会林主任表示了亲切了慰问和关心，竞远工作人员也做出了特别的安排，学员们也投来关注的目光。该同学身上那份坚韧、乐观以及对学习的热爱值得我们所有的人学习。
