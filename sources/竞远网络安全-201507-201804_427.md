# 防艳照门利器！金士顿U盘带物理密码锁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=401693748&idx=1&sn=95b7a518d61b7dad7a13ac38b41b691f&chksm=08d2624d3fa5eb5be5c9e45fb46a15aca9936a1611852384db58d519337c1aa5dc9c3d00f620&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=401693748&idx=1&sn=95b7a518d61b7dad7a13ac38b41b691f&chksm=08d2624d3fa5eb5be5c9e45fb46a15aca9936a1611852384db58d519337c1aa5dc9c3d00f620&scene=27#wechat_redirect)

绝大多数U盘都没有安全防护，想在里面放一些私密照片、重要信息就要掂量掂量了。金士顿近日推出了全新的DataTraveler 2000加密U盘，专为用户私密信息保驾护航。

 

该U盘基于硬件加密，支持XTS模式下的AES 256-Bit数据加密，而且提供了物理PIN密码锁，双重保护，破解难度较大，如果输错密码10次以上，就会自动锁定。

 

此外，用户每次使用后(从电脑拔出)，U盘会自动锁定，所以每次插入U盘，都需要再次输入密码。值得一提的是，该U盘的加密系统独立设计，不需要其它软件支持，可在Windows、Mac OS、Linux、Chrome OS、Android等多个系统环境下使用。

 

DataTraveler 2000支持IP57防尘、防水，采用的是USB 3.1接口，有16GB、32GB、64GB三个容量版本，读写速度如下：

 

USB 3.1:

 

16GB: 120MB/s, 20MB/s

 

32GB: 135MB/s, 40MB/s

 

64GB: 135MB/s, 40MB/s

 

USB 2.0:

 

16GB: 30MB/s, 20MB/s

 

32GB: 30MB/s, 20MB/s

 

64GB: 30MB/s, 20MB/s

 

据悉，DataTraveler 2000将于2016年第一季度上市，售价暂未公布。
