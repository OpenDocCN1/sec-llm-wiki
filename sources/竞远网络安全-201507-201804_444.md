# 小心：通过洗衣机可偷走电脑文件！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=208210563&idx=1&sn=f0f53abcbb9b3fb80b62d9a84dd9265a&chksm=134a34fa243dbdec787416f46bd2c46ec86c8fe19ee5e6d4c88f22d1b7e3a55db193a60e198a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=208210563&idx=1&sn=f0f53abcbb9b3fb80b62d9a84dd9265a&chksm=134a34fa243dbdec787416f46bd2c46ec86c8fe19ee5e6d4c88f22d1b7e3a55db193a60e198a&scene=27#wechat_redirect)

最近，据CNN报道，假如黑客想要从军事基地窃取绝密文件时，他们不再需要通过互联网将军事基地内获得的计算机数据传出去。他们可以通过软件感染办公室中的打印机或洗衣机，然后将其变成无线电台，将信息变成无线电信号发送出去。

 

这听起来好像科幻作品中的场景，但很快将成为现实。美国纽约安全公司Red Balloon Security的研究人员已经研制出一种设备，可使用任何现代设备将看不见、听不到的信号发送到数公里之外，比如打印机、洗衣机以及空调等。

 

这将是一种改变计算机安全领域游戏规则的技术，对于黑客来说，更是一种突破性技术。目前网络安全行业的市场价值高达770亿美元，并在快速扩张中，其主要任务是确保计算机网络的安全。许多公司和政府机构都在购买大量安全产品，以确保自己受到保护。但是他们正耗尽有效的防御选项。

 

Red Balloon Security公司首席研究员崔昂（AngCui）及其团队已经发现，在不触动任何警报的情况下，他们可以从计算机网络中窃走数据。这是一种突破性研究，因为其还拥有从未联网计算机中窃走数据的能力，比如核电站的计算机网络。

 

上周，Red Balloon Security团队向多名记者演示了他们的方法。他们感染了一台奔图激光打印机，并改变了它的线路，令其可以做一些从未做过的事情。通过快速改变芯片的能源输出频率，打印机就可以发射电磁辐射。在非常缓慢的情况下，你可以听到时髦的韵律。而在速度加快后，它就变成无线电波。高低音分别代表着1和0，也就是计算机代码。

 

Red Balloon Security称这种设备为“Funtenna”，这是一种非常缓慢的信息流，每秒钟可能只能传递一个字母。但是粗大的电缆，比如那些连接大型计算机房服务器的电缆，可以充当放大器。这就意味着，崔昂等人正在研发的方式将变成从储存大量信息的计算机中窃取大量数据的最有效方式。

 

崔昂说：“你拥有网络监测、防火墙等防御系统，但我们的数据传输方式无法被监测到。这将从根本上挑战网络安全。”事实上，唯一能够发现这种先进黑客技术的方法就是带着AM无线电四处走动。如果你接近这台设备，无线电静电就会被声音阻断，无法继续秘密传输无线电信号。
