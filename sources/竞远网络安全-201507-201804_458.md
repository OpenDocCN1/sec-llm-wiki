# 微软结束对Windows Server 2003的补丁支持

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=207782581&idx=1&sn=5c5ae425db4330682c10106dd37c51b8&chksm=1341bccc243635daa6a86afb69637b47152421033cf9bfcb7985eb6f6a0ec887b8dab03854d4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=207782581&idx=1&sn=5c5ae425db4330682c10106dd37c51b8&chksm=1341bccc243635daa6a86afb69637b47152421033cf9bfcb7985eb6f6a0ec887b8dab03854d4&scene=27#wechat_redirect)

微软公司在本周二所发布的7月份补丁包中，公布了14条更新补丁的信息，其中有4个补丁修复的是“高危漏洞”，其余的10个补丁被微软公司定位为”重要补丁”。Windows Server 2003最后的修复补丁可以在这个月的补丁计划中找到详细信息，这也同样意味着，微软公司将结束对Windows Server 2003的补丁支持。在这14个修复补丁中，有9个补丁会对Windows Server 2003产生影响。

 

那4个高危漏洞的修复补丁解决了会对Windows操作系统以及IE浏览器产生影响的远程代码执行漏洞(RCE)。其中的一个补丁对IE浏览器进行了更新(MS15-065)，这个补丁修复了编号为CVE-2015-2425的漏洞，而这个漏洞是在最近发生的Hacking Team的数据泄漏事件中被发现的。

 

值得注意的是，MS15-077补丁的安全级别为”重要”，该补丁修复了Adobe Type Manager Font Drive中的一个漏洞，这个漏洞可能会允许系统的特权提升。而且，这个漏洞同样可以在Hacking Team所泄漏的400GB秘密数据中找到。在黑客所公布的漏洞利用细节中，还包括有意大利公司所出售的漏洞信息。

 

微软公司所发布的其余9个“重要补丁”修复了微软SQL服务器、Windows操作系统以及Office中的远程代码执行漏洞，而且还针对Windows操作系统中允许特权提升的问题进行了修复和解决。

 

Wolfgang Kandek是Qualys公司的CTO，根据他的描述，攻击者将会继续寻找产品中的问题和漏洞，这个速度与产品的更新速度是差不多的。他说到：“如果想要避免这种威胁，我们有两件事情可以做\--将我们的数据从Server 2003的服务器中迁移出来，或者向微软公司支付费用，通过一个特殊的技术支持合同让他们来对这个产品提供必要的补丁支持。”

 

Kandek认为，用户应该确保安装了微软公司以及Adobe公司所发布的针对以下漏洞的补丁更新：微软公司用于修复CVE-2015-2387以及CVE-2015-2424的补丁，还有Adobe公司为修复Flash Player 0 day漏洞，CVE-2015-5122以及CVE-2015-5123漏洞所分别发布的更新补丁。
