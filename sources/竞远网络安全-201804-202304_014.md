# 产教融合促进网络安全实践人才培养，竞远安全与番职院共建“网络空间安全产业学院”!

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650273350&idx=1&sn=c1a95b74d8e88e913aafa7c564e8afaa&chksm=82d4c83fb5a34129c37ba791007b58b45c3564e6863c48834f1764dc21925babb4250ffe2107&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650273350&idx=1&sn=c1a95b74d8e88e913aafa7c564e8afaa&chksm=82d4c83fb5a34129c37ba791007b58b45c3564e6863c48834f1764dc21925babb4250ffe2107&scene=27#wechat_redirect)

为推进网络安全产业发展，充分发挥校企合作共建优势，培养多层次网络安全人才，9月20日广州番禺职业技术学院（以下简称“番职院”）、广州竞远安全技术股份有限公司（以下简称“竞远安全”）、奇安信安全技术（广东）有限公司（以下简称“奇安信”）共建“网络空间安全产业学院”签约及揭牌仪式在番职院举行。番职院党委书记林洽生、副校长欧阳丽、竞远安全董事长林殿魁、奇安信（广东）总经理罗建华，以及三方相关领导、教师出席仪式。

番职院林洽生书记在致辞中指出，学院专业设置要对接高端产业和产业高端，坚持以培养高素质的复合型、创新型技术技能人才为目标。学校与奇安信、竞远安全两家网络安全龙头企业深度合作，希望为大湾区经济社会发展培养一大批高素质的“刚需”人才，助力粤港澳大湾区产业发展，在中国职业教育改革创新方面作出新的贡献。  
  竞远安全董事长林殿魁先生在会上表示，竞远安全响应国家关于支持高校学生开展社会实践和就业的政策号召，与番职院联合共建“网络空间安全产业学院”，是网络安全领域产教融合、为政企单位输送实战型人才的重要举措。双方在未来合作中将围绕“人才培养、技术创新、社会服务、就业创业、文化传承”等多个领域，竞远安全为番职院学生提供网络安全项目实践机会，实际接触安全领域前沿技术，深入认知网络空间安全场景，助力培养“思想政治正确、社会责任合格、理论方法扎实、技术应用过硬的应用型工程技术人才”。![](../Images/7ec4d86225093f52bec68c0111f47577.png)

番职院、奇安信、竞远安全共建网络空间安全产业学院揭牌  

番职院是教育部、财政部首批国家示范性高等职业院校，中国特色高水平高职学校建设单位“30强”。学校以高等职业技术教育为主，设有信息工程学院、现代物流学院、智能制造学院、国际学院、创新创业学院等13个学院（部）, 开设45个紧贴珠三角地区产业结构和社会发展需求的专业，现有全日制在校大学生生超过14000人。竞远安全适应社会对网络安全人才多方面的需求，通过与番职院合作建设“网络空间安全产业学院”，努力在网络空间安全人才培养方面摸索出一条有效途径，为我国网络安全产业发展培养更多更好的人才。
