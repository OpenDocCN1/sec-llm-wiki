# 竞远安全入选“广东省工业企业网络数据安全技术支撑单位”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650273340&idx=1&sn=32e8d1721f4574210c1a4a74dc6516c0&chksm=82d4c845b5a34153490e5ef5b87f0918142574ee4e8391d4a4cc51f2857b6709983fe8b51d86&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650273340&idx=1&sn=32e8d1721f4574210c1a4a74dc6516c0&chksm=82d4c845b5a34153490e5ef5b87f0918142574ee4e8391d4a4cc51f2857b6709983fe8b51d86&scene=27#wechat_redirect)

9月7日，广东省通信管理局举办2022年广东省网络安全宣传周“电信日”主题座谈会。会上，省通管局、省工信厅为竞远安全、启明星辰、神州绿盟、安恒等六家企业授予“广东省工业企业网络数据安全技术支撑单位”资质称号。![](../Images/c0faad552e0f83e756c737b54595397b.png)本次主题座谈会邀请了省委网信办、省公安厅、省工信厅、广州工信局等相关负责人出席，省内基础电信企业、重点互联网企业、网络数据安全支撑单位、新闻媒体等参加活动。广东省通信管理局党组书记、局长蔡立志等领导为大会致辞，强调各相关单位要深入宣传贯彻习近平总书记关于建设网络强国的重要思想，认真贯彻落实《网络安全法》《数据安全法》等有关要求，切实提升全民网络安全意识和网络安全防护能力。

![](../Images/ee24ac03f406212d6153ee18a10a3452.png)

广东省通信管理局党组书记、局长蔡立志致辞![](../Images/4cd344c6052642cad2446516a70620d9.png)

广东省工业企业网络数据安全技术支撑单位授牌

工业企业数据作为国家基础性战略资源，是驱动工业数字化转型发展的核心，是构建数字经济的基石。工业领域已成为我国数字化转型发展的主阵地，也是数字经济发展的前沿，工业数据安全成为工业转型升级的重中之重。竞远安全作为国内第一批持有工业互联网安全评估资质的测评机构，将全力配合广东省通信管理局、广东省工业和信息化厅开展工业企业网络数据安全技术支撑工作，加速构建工业企业网络数据安全管理体系，为广东工业企业网络数据安全保驾护航，让安全更安全！
