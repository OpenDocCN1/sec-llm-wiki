# 数字经济发展加剧网络安全挑战，华为联袂竞远安全打造乾坤云MSS安全托管服务为政企单位保驾护航

8月26日，华为广东数字峰会暨数据通信创新峰会在珠海隆重举行，竞远安全作为华为乾坤云服务重要生态合作伙伴应邀出席。会上，华为乾坤安全云服务广东MSSP运营支撑中心隆重发布，竞远安全首席安全官汤志明先生就广东MSSP运营支撑中心的服务与成果做分享。

目前，全球网络安全形势严峻，我国数字经济进入深化发展新阶段，数字经济发展面临的安全问题主要体现在数据安全、个人隐私保护、关键信息基础设施安全。为应对网络安全新形势、新挑战，网络安全服务模式、技术产品需要因应变革。

早在2020年，华为已开始携手竞远安全拓展乾坤安全云服务；2021年8月，正式启动了华为乾坤安全云服务的商用推广项目；2022年8月，经过两年多的并肩作战，华为乾坤安全云服务广东MSSP（Managed Security Service Provider）运营支撑中心（以下简称“MSSP运营支撑中心”）正式成立并落户竞远安全。汤志明先生提到，**MSSP运营支撑中心为客户提供安全托管服务，解决现有网络安全建设“大量安全设备运维难、专业人员驻场成本高、海量安全事件处置慢”三大难题，**同时为政企单位提供安全规划、等保、密码合规、安全培训等合规咨询服务，助力政企单位全面提升网络安全防护能力。
