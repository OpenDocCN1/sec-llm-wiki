# 大力推进信息安全人才培养，广大数院信息安全实践基地隆重揭牌

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650273006&idx=1&sn=457598abefe47e7db840cf33654279cf&chksm=82d4ca97b5a34381392845ec95666d28cdaec231b1a2919ed14905d963f047f6e3ca623ac7e8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650273006&idx=1&sn=457598abefe47e7db840cf33654279cf&chksm=82d4ca97b5a34381392845ec95666d28cdaec231b1a2919ed14905d963f047f6e3ca623ac7e8&scene=27#wechat_redirect)

![](../Images/51541157b621970e893112e73602698c.png)5月16日，“广州大学数学与信息科学学院信息安全实践基地” （下称“实践基地”）签约与揭牌仪式在竞远安全广州总部隆重举行，广州大学数学与信息科学学院（下称广大数院）院长彭济根教授，信息科学系系主任唐屹教授，林志强副教授、学工办郭翠敏老师、竞远安全董事长林殿魁、常务副总裁梁承东、密评业务中心总经理王海华、密评业务中心总工程师王正临出席本次活动。  

![](../Images/d153aaf4d1741d053434356c45b782eb.png)

广州大学数学与信息科学学院信息安全实践基地正式揭牌

网络空间安全已经成为国家安全发展战略的重中之重，而商用密码应用安全是网络安全中的核心领域。竞远安全高度重视密码安全业务，于2021年获批成为“商用密码应用安全性评估试点机构”，公司专门设立密评业务中心，面向全国提供商用密码应用安全性评估服务，业务覆盖政府机关、公安机关、电力行业、医疗卫生、公共交通等多个领域。竞远安全董事长林殿魁表示，“实践基地”是我司与广州大学响应国家对高校学生社会实践和就业政策，在信息安全领域产学研合作的又一重要举措。该基地将为广大数院本科学生提供信息安全和密码评估项目实践机会，学生们通过实际接触安全领域前沿技术，深入认知网络空间安全场景，有助于培养“思想政治正确、社会责任合格、理论方法扎实、技术应用过硬的应用型工程技术人才”。![](../Images/b63f38084d7bd0b8363b14a852aeade3.png)  

彭济根院长表示，大学生缺乏社会实践经验，理论知识再扎实，亦需要到市场中“真枪实弹”历练，才能快速成长。彭院长认为，“实践基地”的建立，是响应党和国家对科技创新“四个面向”战略部署的重要举措和实践。当今大学生要面向经济主战场，要学有所用，才能为党和国家做出贡献，也是自身价值的体现。竞远安全深耕网络安全行业近二十年，获得主管单位和客户的一致认可，而广大数院是广东省高水平大学重点学科建设项目“数学与信息科学学科群”的主要承担单位，其中数学与应用数学、信息与计算科学、信息安全入选国家级一流本科专业建设点；数学学科为广东省攀峰重点学科，在教育部第四轮学科评估中获评B级（并列全国第39位），入选2021年软科世界一流学科。学院愿为竞远安全输送优秀的数学与信息安全人才，彭院长认为竞远安全不仅能为学生提供专业的实战培养，更可成为学生们未来大展拳脚，实现梦想抱负的事业发展平台，本次与竞远安全共建“实践基地”，是学院、企业、学生三方共赢！

  

![](../Images/d0f3fd314d1cbbe3aec03737143c933d.png)

广州大学数学与信息科学学院

  

2021年我司与广州大学研究生学院建立了“联合培养研究生示范基地”，主要围绕商密评估领域开展研究生联合培养，目前已有广州大学多名研究生进驻该“示范基地”，成为该基地首批学员，并已顺利完成实习工作。研究生们在实习期间通过实际项目历练，成长迅速，进步显著。现在竞远安全又与广大数院开展产学研合作，共建“实践基地”，旨在信息安全本科人才培养方面摸索出一条有效途径，推进我省信息安全和密码产业发展，培养更多更好的人才。

  

![](../Images/e4562f32a0dd5d5c742585c96499de84.png)

广州大学数学与信息科学学院嘉宾与竞远安全领导合影

未来，竞远安全将与广大数院合作加快推进校企合作计划，让我们共同期待竞远安全与广州大学数学与信息科学学院产学研合作早结硕果，“实践基地”人才辈出，助力信息安全及密码产业发展！
