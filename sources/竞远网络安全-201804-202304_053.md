# 第三届竞远杯“三人制”篮球对抗赛激情开赛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650272110&idx=1&sn=85c7ed4f4c1e08d1f1e3283385dff571&chksm=82d4cf17b5a346010c8da2f86bfb5dc8bbf05e76e52e7f822d26161bda6c899c95980cd466c1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650272110&idx=1&sn=85c7ed4f4c1e08d1f1e3283385dff571&chksm=82d4cf17b5a346010c8da2f86bfb5dc8bbf05e76e52e7f822d26161bda6c899c95980cd466c1&scene=27#wechat_redirect)

专业可靠彰显安全本质，活泼热情挥洒青春魅力。11月19日，秋高气爽，十二支参赛队伍齐聚广星篮球公园，第三届竞远杯“三人制”篮球对抗赛在同事们的欢呼声中激情开赛！竞远杯篮球对抗赛旨在促进各部门之间的友谊交流和员工身心健康发展，自2019年开始举办，每年秋季开赛，至今已有三个年头。

![](../Images/fdaed92181362c6bb00a2e7ee7d98bf0.png)

竞远安全常务副总裁梁承东致辞

  

本届篮球赛共有十二支队伍参赛，赛制按循环赛-淘汰赛-半决赛-总决赛层层晋级。热情在对抗中释放，激情在跑动中点燃，斗志在赛场中飞扬，精彩在篮筐上跳跃！经过激烈的角逐，中国青年队、少先队队、对对队和A3小队脱颖而出，成功晋级四强。最终，对对队以13：12一分之差险胜A3小队，取得第三名；总决赛中，少先队队对阵中国青年队，经过激烈比赛中国青年队摘得冠军宝座！
