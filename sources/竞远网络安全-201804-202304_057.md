# 竞远安全2021年第三期新员工培训圆满结束

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650272052&idx=1&sn=4f59ee34fdc607a01e563ef380712198&chksm=82d4cf4db5a3465b68cc2948b0b95696abc7896c33a2c38327ea5ee26f0e88f3eb92ad374663&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650272052&idx=1&sn=4f59ee34fdc607a01e563ef380712198&chksm=82d4cf4db5a3465b68cc2948b0b95696abc7896c33a2c38327ea5ee26f0e88f3eb92ad374663&scene=27#wechat_redirect)

9月16-18日，竞远安全顺利举办了2021年第三期新员工入职培训，来自广州总部及全国各办事处、分公司的新入职同事近70人参加了本次培训。竞远安全新员工入职培训旨在通过介绍公司企业文化、发展历程与前景、公司主营业务，提升新员工网络安全意识和普及安全培训知识，帮助新员工尽快融入实践工作中。  

![](../Images/7d1aacb6e9a32bd3772464e3a1732f55.png)

线下培训现场

   

根据疫情防控需要，本次培训采用线上线下相结合的模式开展，广州总部同事以线下培训为主，外地办公的同事，采用线上直播听课的方式进行学习。新员工入职培训内容涵盖了企业战略与愿景篇章、职业规划与个人素养篇章、公司业务与前沿科技篇章，旨在通过课程讲授，系统、全面地提升新员工的综合素质。

  

![](../Images/27ac80d1401b8d658c0c76f8b236d5b1.png)

![](../Images/72c6652aacd05ec57372f79294446046.png)

直播授课  

  

今年是竞远安全成立的第十八年，竞远安全秉承“进取、担当、开新、协作”的企业价值观，以“专业可靠”的企业精神，为客户提供安全可靠的服务，赢得了主管部门与客户的高度认可，目前，公司的业务网络不断扩张、业务规模不断提升，我们肩负的责任与使命也更加重大。网络安全行业对从业人员的职业道德和专业要求都有严格的标准，竞远安全对员工的培养，尤其在新人的培育上，从不松懈。每一期的新员工入职培训都会以企业价值观为重点学习脉络，从立意、内涵、实践各个维度，向员工分享公司的价值观，希望每一位进入竞远大家庭的同事，以专业精神投入到本岗位的工作中，成为一名合格的、专业可靠的竞远人。
