# 《数据安全法》正式通过， 工信部认证数据安全师开班报名啦！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650271918&idx=1&sn=74f34d1afc9f40b0151efcbf0c6c0312&chksm=82d4ced7b5a347c163a009d3e5975ef584397b2b568a5fc12926028abcca1ee369eadcb44540&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650271918&idx=1&sn=74f34d1afc9f40b0151efcbf0c6c0312&chksm=82d4ced7b5a347c163a009d3e5975ef584397b2b568a5fc12926028abcca1ee369eadcb44540&scene=27#wechat_redirect)

2021年6月10日，十三届全国人大常委会第二十九次会议表决通过《中华人民共和国数据安全法》（以下简称《数据安全法》），自2021年9月1日起施行。

  

![](../Images/5b4415a196374fc717e6500b4657bb28.png)

  

《中华人民共和国网络安全法》、《中华人民共和国密码法》于2016年、2019年相继发布，如今《数据安全法》的颁布与实施是进一步贯彻落实总体国家安全观的重要举措。《数据安全法》要求政企单位重视数据安全领域的风险隐患，确立数据分类分级管理、数据安全审查、数据安全风险评估、监测预警和应急处置等管理机制。与此同时，网络安全特别是数据安全人才的培训培养问题也引起了政企单位日益重视。

  

竞远安全是工信部工业和信息化领域职业能力等级评价机构、工业和信息化职业技能提升行动委员会第一批会员单位，获得相关授权开展网络安全、大数据等信息化培训工作，**参加相关培训考核通过的学员，信息纳入工业和信息化技术技能人才数据库，企业和学员可登录官网（www.miiteec.org.cn）查询证书信息。**

  
![](../Images/cc14993efe22db558eba363bc90df760.png)

为满足《数据安全法》颁布实施对网络安全特别是数据安全人才急剧提升的需求，竞远安全将于近期开设**数据安全师、网络与信息安全管理师、CISP（注册信息安全专业人员）-PTE/PTS/IRE**等多项网络安全类培训课程，旨在强化学员对专项技术安全态势及数字化转型趋势，提升数据安全管理与应急处置等多项实用技能，学员毕业之后将大大加强政企单位网络安全与数据安全管理能力，提升整体安全防护实力。
