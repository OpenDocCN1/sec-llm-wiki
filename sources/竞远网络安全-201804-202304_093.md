# 祝贺竞远安全获得网络安全技能大赛团队赛三等奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650271451&idx=2&sn=11eebefcc243fc6896f8aee51a42c04d&chksm=82d4d0a2b5a359b466b1d7970788b6a73ddc0480b3571af5504fead68632ed07af43fb85285a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650271451&idx=2&sn=11eebefcc243fc6896f8aee51a42c04d&chksm=82d4d0a2b5a359b466b1d7970788b6a73ddc0480b3571af5504fead68632ed07af43fb85285a&scene=27#wechat_redirect)

9月29日，由广东省通信管理局与广东省总工会、广东省人力资源和社会保障厅、广东省工业和信息化厅、广东省科学技术厅共同主办的“任子行杯”广东省信息通信行业第三届网络安全技能大赛决赛在广东邮电职业技术学院举行，大赛分为个人赛和团体赛，竞远安全凭借过硬的专业技能和默契的团队配合，在36支决赛队伍中脱颖而出，喜获团队赛三等奖。  

![](../Images/7201c6508eb4c425b16b67760ab8304a.png)

竞技现场 作为行业领先的智能网络安全综合服务提供商，竞远安全在广州、北京、深圳、贵阳等全国20个城市设有专业素质高、技术过硬、安全可靠的精英技术团队及服务队伍，拥有雄厚的安全技术实力和服务优质的专业团队，历年来，在多项网络安全竞技大赛中均获得优异成绩。  

![](../Images/bf2656238a76d50661e1e19b55613a58.png)

竞远安全获得团队赛三等奖  
网络安全行业方兴未艾，网络安全专业人才缺乏，竞远安全十分注重员工的成长与发展，从技能提升、个人素养、职业规划等方面，建立了由线到面、由内至外的人才培养机制，旨在全方位提升员工综合实力，打造技术过硬、安全可靠的精英服务团队，为国家培养网络安全高素质、专业人才队伍，全力护航网络安全。
