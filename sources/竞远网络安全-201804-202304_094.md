# 竞远安全参加广东省和深圳市网络安全周“电信日”主题活动

网络安全为人民，网络安全靠人民。2020年广东省网络安全宣传周活动于9月14日至20日举行。9月16日，信息通信行业以线上线下相结合的方式，开展2020年国家网络安全宣传周“电信日”主题活动。广州竞远安全技术股份有限公司（下称竞远安全）作为智能网络安全综合服务提供商，受邀参加了广东省、深圳市的“电信日”主题活动。

 

![](../Images/4330c3f08cb219813ba82ab139f2928d.png)

  

综合考虑疫情防控要求，充分发挥网络传播优势，广东省网络安全宣传周以线上线下相结合的形式，全方位、多维度展示网络安全宣传周活动内容。竞远安全首席安全咨询顾问汤志明就“夯实基石，打造坚实的网络安全治理体系”主题展开演讲，针对网络安全合规治理的顶层设计：等级保护的践行、密码测评、应用安全治理和数据安全治理四大基石展开论述，获得省通管局及与会企业的高度认可。

  

![](../Images/6057981c98aad5f03842034bf3cc755a.png)

竞远安全首席安全咨询顾问汤志明先生演讲

 

9月16日上午，深圳市网络安全周“电信日”主题活动正式开启直播。深圳市通信管理局、深圳市各基础电信运营企业、铁塔公司主要负责同志，竞远安全、恒安嘉新专家代表参加论坛，与会嘉宾围绕信息通信行业的网络安全热点议题展开交流研讨。竞远安全作为协办单位为大会提供技术支撑并做了“构建坚实网络安全体系为网络空间安全保驾护航”的主题演讲。

 

![](../Images/da926e545788a316327d4e1b0cdcf84e.png)

深圳市网络安全周“电信日”主题活动

  

![](../Images/17f1d20085b12e70f7f6e354e868e14c.png)

竞远安全汤志明在深圳市网络安全周活动直播间

 

竞远安全致力于构建中国特色网络安全防护体系，首创安全咨询、安全测评、安全保障三位一体的智能网络安全综合服务解决方案，为企业提供专业可靠的新一代智能网络安全综合服务。**竞远安全积极参与本次网络安全宣传周“电信日”主题活动，紧紧围绕“网络安全为人民，网络安全靠人民”的主题，宣讲普及法规政策、知识技能，旨在促使广大政府部门、企事业单位了解网络安全风险、提升网络安全防范意识，推动网络空间共建共治共享。**
