# 网络与信息安全管理师等级证书可以查询啦！

第一步：登录证书查询网站(工业和信息化部教育与考试中心)：www.miiteec.org.cn（点击文末阅读原文可直接进入）  
第二步：选择“证书查询”入口  
第三步：选择“工业和信息化领域职业能力等级评价证书”入口  
第四步：填写身份证、证书号码、姓名  
注意：证书查询可在考试结束后3个月左右尝试查询，如遇查询无相关资料，请耐心等待。
