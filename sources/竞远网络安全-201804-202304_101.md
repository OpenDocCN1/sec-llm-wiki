# 同频共振创明天 ——竞远安全2020年第二期新员工入职培训圆满结束

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650271103&idx=1&sn=25c3dfddbc063e5cb363c4dea73bb0d9&chksm=82d4d306b5a35a104f7dfe326fdff72af04ce5e806d18b9569aaa94f941a80d27cb21288851f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650271103&idx=1&sn=25c3dfddbc063e5cb363c4dea73bb0d9&chksm=82d4d306b5a35a104f7dfe326fdff72af04ce5e806d18b9569aaa94f941a80d27cb21288851f&scene=27#wechat_redirect)

为加快新员工融入竞远安全大家庭，提高协同工作效率，帮助新员工对公司企业文化、业务、规章制度有更体系化、全面化的认知， 6月1-3日，竞远安全举办了2020年第二期新员工入职培训。  
  
  
  
  
![](../Images/7a7ccb11b1affd7f024b5825b456d280.png)  
竞远安全严守疫情防控，本次培训采用线上直播、总部部分员工线下面授方式同时进行，来自等保业务中心、广州研发中心、安防业务中心、运维中心、培训中心、综合部、北京办事处、肇浮办事处、深圳办事处、贵阳分公司的37名新员工参加培训，经过3天学习，全体学员顺利通过线上考试**。**

![](../Images/c3d67441ce079709ec78c58ef430f5d5.png)

竞远安全讲师团队  
  
本次培训内容涵盖了企业战略与愿景篇章、职业规划与个人素养篇章、公司业务与前沿科技篇章，旨在通过课程讲授，系统、全面地提升新员工的综合素质。本次新员工入职培训是竞远安全开展的首次线上线下相结合的直播授课，全程直播环节流畅，氛围轻松愉悦，受训员工互动交流热烈，大家纷纷表示，本次培训让他们能够全面地了解公司实力与前景，拓宽了他们对于整个公司发展的全局观，从企业文化、专业技术、管理技能等方面，都展现出竞远安全团队的专业实力，为新员工更好的融入团队打下坚实的基础。  
  
![](../Images/da7a5b75abb96983dfc767bf96a89397.png)在线互动  
本次培训的首席导师、董事长、总裁林殿魁主讲第一节课，他语重心长的教导新员工，要秉承**“专业可靠”**的企业精神，做到：“**做事专业，做人可靠；技术专业，服务可靠；过程专业，结果可靠；企业专业，企品可靠”，才能不断进步，在工作岗位上有所成就。**竞远安全聚焦于提供智能网络安全综合服务，拥有雄厚的技术实力和专业的技术团队，连续多年蝉联全国信息安全等级保护测评机构先进单位称号，为新员工提供实现个人价值的舞台，新员工同时为公司发展带来新的活力，双方是良性的共赢共同体，希望新员工能紧跟公司的发展步伐，同频共振共创美好明天。
