# 只争朝夕，不负韶华，党支部吹响新年冲锋号

**\----**记广州竞远安全党支部党员活动室启用暨共产党员先锋岗授牌仪式

2020年1月15日下午，广州竞远安全党支部迎来了新的里程碑，党员活动室在上级党组织联和街党群服务中心领导的见证下正式启用，从此公司的党员们有了自己的党员之家。值此之际，联和街党群服务中心罗珊主任和龚燕党建指导员在百忙之中拨冗光临，前来指导广州竞远安全党支部的党建工作。

  

![](../Images/7acbada593eddb851eca1707d9c930f0.png)

**会议现场**

广州竞远安全技术股份有限公司副总裁兼党建顾问张林保同志和运维中心总监兼党支部委员詹前进同志以及其他几位党员代表参与了此次活动，与上级党组织进行了热烈交流。首先，詹前进同志代表党支部向上级党组织汇报了广州竞远安全党支部党建工作的开展情况，罗珊主任对广州竞远安全党支部工作表示了肯定，并对党建工作进行悉心指导。随后，张林保副总裁代表公司向上级党组织介绍公司业务的开展情况，并对公司筹建党支部及支部开展党建工作表示肯定与支持。最后，党支部请罗珊主任为广州竞远安全党支部党员同志们颁发“共产党员先锋岗”号牌。她鼓励大家：要敢于亮出党员的身份，充分发挥党员先锋模范作用，把党支部打造成坚强的战斗堡垒，为企业为国家作出更大的贡献！支部党员们表示：根据公司发展战略，今年是实现公司三年战略目标的关键之年，党支部为党员颁发“共产党员先锋岗”号牌之举，就是通过“亮身份，树先进”，吹响新年冲锋号，号召党员们充分发挥先锋模范作用，带领大家奋力拼搏，攻坚克难，为实现公司发展战略、为国家网络安全事业作出贡献！
