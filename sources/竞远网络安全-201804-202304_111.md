# 竞远安全连续五年荣获全国网络安全等级保护测评机构“先进单位”称号

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650270835&idx=1&sn=4ff4fb70701738084866efde875b2818&chksm=82d4d20ab5a35b1c2df4d7f6c1a8539078499a8af616e9e370a37d4853a74233f9a80d4f9c60&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650270835&idx=1&sn=4ff4fb70701738084866efde875b2818&chksm=82d4d20ab5a35b1c2df4d7f6c1a8539078499a8af616e9e370a37d4853a74233f9a80d4f9c60&scene=27#wechat_redirect)

2019年12月9日召开，“第九届全国网络安全等级保护测评体系建设会议”在福建省福州市成功召开。来自公安部网络安全保卫局、福建省公安厅网安总队、信息安全测评联盟等单位领导，以及全国180余家测评机构负责人共计600余人参加了会议。会上，广州竞远安全技术股份有限公司（简称：竞远安全）再次获评全国网络安全等级保护测评机构“先进单位”称号，这是竞远安全连续五年获此殊荣，也是对竞远安全多年来从事网络安全服务工作的高度肯定。

  

![](../Images/c49450d7fcb0c7f3e300cb6bb7f5040a.png)

**竞远安全副总裁梁承东先生领取"先进单位"牌匾**  

会议着重围绕“网络安全等级保护2.0新技术新应用测评实践指导、测评能力建设及规范化、测评成果和经验交流”等几大主题，研究等级保护2.0时代的工作重点，宣贯交流等级保护新的标准和测评实践的成果。  

  

![](../Images/3899163cde33a42def7fc1a92dc85eeb.png)

**会议现场**

  

竞远安全自2007年以来开展网络安全等级保护工作，打造了一支高标准、严要求的优秀测评队伍，得到客户和主管机构的肯定。未来，竞远安全将坚守“服务国家安全发展战略，构筑中国特色的网络安全防护体系”的企业使命，在联盟和主管机构的指导下，秉承“专业、客观、公平、公正”的原则，发挥安全测评机构的优势，不断提升客户等保服务价值，让安全更安全！
