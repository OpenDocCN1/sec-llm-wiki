# 竞远安全智能网络安全综合服务护航5G智能时代——第十一届天翼智能生态博览会圆满落幕

2019年9月22日，由中国电信股份有限公司主办，广东省人民政府支持的第十一届天翼智能生态博览会在广州琶洲国际会展中心A区顺利闭幕。今年恰逢5G元年，中国电信融合产业链打造一个全新的智能生态圈，今年博览会参展企业突破200家，展馆面积达5万平方米，为历年之最。作为天翼智能生态博览会、美国CES、西班牙MWC并称国际通信展“三巨头”之一的天翼智能生态博览会，本届博览会吸引了全球各大媒体参与报道，触达10亿行业内外人士。作为中国电信5G合作伙伴，竞远安全高度重视，投入超过一百人团队参与，全力支撑中国电信办好此次博览会盛事。充满独特科技感勾勒设计的竞远安全展馆在为期四天的展会上累计接待领导、嘉宾和观众共计超过1万人次；竞远安全先后主办智慧生态网络安全高峰主论坛和智慧生态等级保护2.0分论坛，共计吸引近千位嘉宾到场聆听。

今年5月，国家正式发布了等保2.0标准。等保2.0标准的发布，将网络安全合规要求从常规IT系统扩展到移动互联网、云计算、大数据、工业控制、物联网等5G业务重点布局的领域，为5G智能时代的健康发展保驾护航。竞远安全积极开展等保2.0的安全服务实践，于今年7月率先实施了全省首个等保2.0标准测评——广东省政数局政务一体化平台等保2.0测评。适应5G智能时代的到来，竞远安全在本次展会发布了智慧安全生态解决方案，满足中国电信政企客户特别是天翼云客户快速、高性价比地落实等保2.0要求，并同步推出了网络安全监管平台、云安全巡检服务——企智通（增强包）等新业务，吸引了众多省电信公司、以及广州、深圳、东莞、佛山等多个地市电信公司代表及客户的浓厚兴趣，纷纷前来了解，交流合作。

开幕式当天下午，中国电信、竞远安全在5.2号主会馆联合主办了以“5G引领世界，安全护航未来”为主题的智慧生态网络安全高峰主论坛，中国电信广东公司政企客户部副总经理孙黎先生、广东电信行业DICT中心副总经理刘铭先生、广东广信通信服务有限公司副总经理赵刚先生、竞远安全副总裁余小葵先生等领导出席论坛。现场气氛热烈，超过五百位观众在科技感满满的会场上认真聆听八位专家嘉宾的精彩演讲。  

  

![](../Images/7e211ebd597c0776a127966db1231ced.png)  

智慧生态网络安全高峰主论坛现场  

  

中国电信广东公司政企客户部副总经理孙黎先生首先发表精彩致辞。他表示，在日益严峻的网络安全形势下，中国电信广东公司将利用自身积累的核心优势，联合优秀合作伙伴的优势能力，为各行业客户提供具有针对性的安全产品和解决方案，促进5G时代网络安全的发展。随后广东电信行业DICT中心副总经理刘铭先生就《广东电信主旨——共筑网络安全防线 构建智慧产业生态》这一主题展开演讲，精彩解析了广东电信构筑智慧产业生态的主旨与内涵。

20日下午，竞远安全在A区1.2号馆发布区域开设智慧生态等级保护2.0分论坛，公司首席安全咨询顾问汤志明先生围绕“智慧生态安全解决方案，洞见5G时代网络安全等级保护”展开了精彩的演讲，现场还设置了抽奖环节，演讲嘉宾与观众热情互动，知识性与趣味性交织在一起。

21日下午，竞远安全等5家企业作为广东电信重要政企生态合作伙伴代表出席了广东电信政企DICT生态合作签约仪式，竞远安全作为智能网络安全综合解决方案提供商，在网络安全业务方面将与广东电信开展全面深度合作。  

  

![](../Images/31718b6bcbabd7db1452086931f76989.png)

随着5G智能时代的到来，一场深刻的变革正在各行各业展开，竞远安全作为国家重大活动网络安全保卫“技术支持单位”、全国网络安全等级保护测评机构“先进单位”、国家信息安全漏洞库（CNNVD）“技术支撑单位”，将继续坚守“服务国家安全发展战略，构筑中国特色网络安全防护体系”的企业使命，与时俱进、开拓创新，与中国电信紧密合作向政企客户提供智能网络安全服务解决方案，为5G智能时代保驾护航，让安全更安全！
