# 等保宣贯助力汕尾，网络安全再添华章

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650270505&idx=1&sn=7199d774187046ed0fea5adc87f87923&chksm=82d4d550b5a35c46e947c4bcff3df3b17baac0ec17279406177793bef0f40ff18e4b496cf97a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650270505&idx=1&sn=7199d774187046ed0fea5adc87f87923&chksm=82d4d550b5a35c46e947c4bcff3df3b17baac0ec17279406177793bef0f40ff18e4b496cf97a&scene=27#wechat_redirect)

7月19日下午，由汕尾市网信办和公安局主办，华为技术有限公司、广州竞远安全技术股份有限公司和广东恒宇信息科技有限公司共同组织的“汕尾市网络安全等级保护制度2.0国家标准宣贯会”于汕尾圆满闭幕。  

  

![](../Images/5aa682b86922bb71d4f2c281899e9b76.png)

  

汕尾市党政相关领导、市公安局网警支队、驻汕单位、华为、竞远安全、恒远科技的网络安全专家和本市企事业单位的网络安全部门管理和技术人员近300人参加本次宣贯会，我司副总裁余小葵应邀出席会议。  

  

![](../Images/f019d1edd0550161b76b926c1c008eb4.png)

  

![](../Images/b8c0834f8013ddc41d3c0552b4af4672.png)

  

华为公司的安全专家分别介绍了等保2.0安全标准和华为在等级保护建设中的经验，我司方案部副总经理、网络安全研究员汤志明先生以网络安全等级保护2.0标准体系定级指南为切入点，系统解读了等保2.0新时代下如何准确定级、备案，让参会人员对等保2.0有了更加全面、客观和深入的理解。  

  

![](../Images/d1e634c5ab37be526519bf061d924e96.png)

  

本次宣贯会上，汕尾市的网络安全主管部门要求全市各行各业要统一认识，认真落实，坚定不移的按照习近平总书记网络强国战略思想，严格执行《中华人民共和国网络安全法》的要求，抓住网络安全等级保护制度2.0国家标准颁布的良好契机，深入推进全市网络安全等级保护工作，为构建汕尾市的网络安全贡献力量。
