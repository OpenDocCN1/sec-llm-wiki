# 广州竞远安全技术股份有限公司 荣获中国电信广东分公司“政企优秀合作伙伴”称号

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650269928&idx=1&sn=c104f55247508f1e427eaf8c0f1056a0&chksm=82d4d691b5a35f87b3ef0f493f667a30a081e3161e0cdf977c23dfb9a3828706219d39954b09&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650269928&idx=1&sn=c104f55247508f1e427eaf8c0f1056a0&chksm=82d4d691b5a35f87b3ef0f493f667a30a081e3161e0cdf977c23dfb9a3828706219d39954b09&scene=27#wechat_redirect)

1月23日，竞远安全获邀参加中国电信广东分公司政企生态合作伙伴大会，数百名来自全国各地的生态合作伙伴共聚一堂，以“共生同创，强智慧生态圈”为主题，分享行业数字化转型的最新实践，共商新年新机遇。

  

![](../Images/b08a4dc8b358646a7df13c42bd76207d.png)

![](../Images/4057dedfb85062542fa5d66f06a825e9.png)

  

竞远安全销售部总经理郭红亮先生代表公司上台领取了“政企优秀合作伙伴”奖牌，参与了中国电信广东分公司智慧医疗生态联盟启动仪式。2019年，在新一轮科技革命引发的技术创新浪潮驱动下，传统产业开始释放出新动能，中国电信广东分公司作为产业信息化转型的重要“推手”，积极联合优秀合作伙伴，成立生态联盟，我司将与中国电信一起向客户提供优质的安全一体化解决方案，共拓行业蓝海。

  

![](../Images/33cc55af43f5b925f8e90c2d132f8d2b.png)

![](../Images/90ead11c7d648e6f3bdf2991e1117167.png)

  

回顾过去的一年，我们辛勤耕耘，获得合作伙伴的高度认可。展望2019，我们肩负新的使命，与合作伙伴携手，共同做强智慧生态圈，把握发展机遇，共享生态成果。竞远安全将以本次颁奖会议为契机，不断加强与地市电信分公司之间的协作，把各地市的支撑工作做深做细，联动一切可以联合的力量，再创佳绩！
