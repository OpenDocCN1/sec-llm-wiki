# 竞远安全参展第五届广东省网络安全宣传周

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650269561&idx=1&sn=c882c4c93bb07597a3016493bd995ec9&chksm=82d4d900b5a35016c722093775e77d7d55681b312525f2893f96402b03328dc84680d6d2431b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650269561&idx=1&sn=c882c4c93bb07597a3016493bd995ec9&chksm=82d4d900b5a35016c722093775e77d7d55681b312525f2893f96402b03328dc84680d6d2431b&scene=27#wechat_redirect)

9月18日上午，第五届广东省网络安全宣传周在广州开幕，省委宣传部、省委网信办、省教育厅、省公安厅、省总工会等活动主办单位领导，以及特邀嘉宾中国工程院院士吴清平，与媒体代表、现场观众等共同出席了启动仪式。其中，广东省通信管理局局长苏少林出席开幕式并以“加强网络空间综合治理 守护网络安全‘南大门’”为题发表了演讲。

  

![](../Images/966017352e2518a58c5f52377f4a1d7f.png)

  

竞远安全为安全行业参展单位之一，特地在展馆内设立了专门的展位，来展现竞远公司在安全领域的业务内容，包括等保测评、风险评估、安全培训等，以及获得的荣誉。竞远安全履行社会责任，在安全服务领域积极开展网络安全宣传，助力提升企业及大众网络安全防范意识，强化企业自身网络安全防护措施。

  

在本届宣传周活动中，广东省通信管理局，以及启明、深信服、360、天融信等安全企业都有参与。其中，省通管局举办的多项宣传活动最引人瞩目，包括设置专门展位现场向公众展示工业互联网安全、互联网基础资源管理、打击通讯信息诈骗、网络安全检查执法、网络安全防护能力提升、网络安全人才培育等，且有由专业人员演示常见的网络安全陷阱，向公众提供学习网络安全知识的平台。比如，在省通管局展台，工作人员利用DNS劫持技术模拟了网站钓鱼的过程，展示了日常生活中可能的安全隐患与安全陷阱，获得与会参观领导的驻足关注，以及大量热情观众的咨询。

本届网络安全周活动是根据中央网信办统一部署，围绕“网络安全为人民，网络安全靠人民”主题，举办的网络安全博览会，展示和推广了网络安全前沿技术，营造了网络安全学术氛围，打造了网络安全技术创新应用高地，提升了全社会参与网络安全普及活动的积极性和关注度。
