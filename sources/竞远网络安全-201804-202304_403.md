# \[安全资讯\] | 汽车、冰箱、传真机……令人意外的7个黑客藏身地

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650269457&idx=2&sn=63ea85de7986d00fafc3d60c54a67857&chksm=82d4d968b5a3507e35f9854791e10d4fe9d4c24528c027d023c1a86dbadb1530f38c51f870e0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650269457&idx=2&sn=63ea85de7986d00fafc3d60c54a67857&chksm=82d4d968b5a3507e35f9854791e10d4fe9d4c24528c027d023c1a86dbadb1530f38c51f870e0&scene=27#wechat_redirect)

物联网(IoT)让万事万物都更智能了，从冰箱到恒温器到微波炉，智能便捷得好像了解你一切日常习惯的贴心小助手。但随着联网技术走进千家万户，恶意黑客也能利用这些创新干坏事，我们需要加强认识，提高警惕。虽说强化口令和利用其他安全应用程序有助于增强网络安全，但封锁访问仍不失为非常有效的第一步。

  

![](../Images/3f649903a7bc3de84a9e699779c40da5.png)

**1\. 第三方应用**

如果你正在使用第三方App，小心了！

  

今年秋天，Snapchat用户沦为重大数据泄露事件的受害者，超过9万张照片和9000段视频被盗。这些黑客下载了第三方应用以绕过Snapchat不兼容其操作系统的限制。Snapchat声明，某些第三方开发者会构建服务诱骗用户并盗取他们的登录信息。

  

**2\. 智能冰箱**

去年，一家名为Proofpoint的安全公司发现，12月13日到1月14日期间，有10万台联网家用电器(比如智能冰箱)被黑客当成了发送带毒电子邮件的入口点。

  

**3\. 汽车**

马萨诸塞州民主党参议员爱德华·马克特发布的报告称，几乎所有车辆都存在无线漏洞，黑客可利用车上的无钥匙进入、导航系统和远程启动功能。不仅如此，汽车制造商收集的个人信息也往往存储在第三方处，容易遭泄露。

  

**4\. 社交媒体账户**

沦为社交媒体账户被黑受害者的知名新闻机构和著名公司不知凡几。尤其是推特，因公司推特账户被黑而蒙羞的公司企业数不胜数。Chipotle快餐连锁事件和《新闻周刊》不过是最近刚刚遭遇社会形象损失的两个例子。

  

**5\. 收银机**

一些零售商数据泄露事件——塔吉特百货、内曼马可斯百货、Michaels工艺品连锁、P.F. Chang’s 中餐连锁、家得宝连锁等等，都被质疑销售终端(POS)系统和支付终端安全性问题导致黑客获取到了客户的信用卡信息。如果使用移动支付系统，请确保已尽力降低被骗可能性。

  

**6\. 婴儿监视器**

如果你家的婴儿监视器是无线的，那么你用来看护小宝宝的东西也可能被黑客用来监视你自己，尤其是监视器上还连有摄像头的时候。

  

**7\. 传真机**

即便不常使用传真机，尤其是不经常使用传真机的情况下，黑客反而能通过传真黑进连接了传真机的每台电脑。安全公司 Check Point Software 的研究团队就能以隐写了恶意代码的图片传真，黑掉连接HP全功能打印机的所有电脑。传真机会将传真文件存储在系统中，这就给黑客制造了访问整个系统的机会。于是，正因为不是日常技术工作的一部分，反而要确保经常性清理。或者，升级你的系统，让黑客无法突破和潜伏。
