# 韩国ZPER联盟、香港互金协会及广东互金协会到访竞远安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTU3NTcwMg==&mid=2650269423&idx=1&sn=8c91a927d8878a97849cb45b031bb4af&chksm=82d4d896b5a351807f1753aadb0b7e5b2cd8e5f810ee90125a374571be0793df99ee8d062e53&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTU3NTcwMg==&mid=2650269423&idx=1&sn=8c91a927d8878a97849cb45b031bb4af&chksm=82d4d896b5a351807f1753aadb0b7e5b2cd8e5f810ee90125a374571be0793df99ee8d062e53&scene=27#wechat_redirect)

    8月7日，韩国ZPER联盟、香港互金协会与广东互金协会一行（以下简称ZPER联盟）莅临竞远安全广州总部参观交流，会议由风评事业部总监刘礼主持。会议中，ZPER联盟代表介绍了基于区块链技术的去中心化金融科技生态系统，竞远安全则分享了金融科技安全测评领域的服务及技术心得，双方对金融生态、金融系统开展的业务模式与网络安全防护进行了深入探讨，对中韩金融科技安全交流与技术合作交换了意见。  

  

![](../Images/b5f6843ed8c3f99348e53bc0cd2d7223.png)

  

    韩国ZPER是由国际互金企业、信息提供者、智能投顾等组成的国际联盟；香港互金协会和广东互金协会分别是特区级和省级互联网金融协会自律组织。本次交流会，竞远安全等保部王海华总监，综合部张少妹总监，方案部郑灿丹总监，风评部王佳，徐志强等也出席了会议。  
  

![](../Images/49c5cd31877cd508ea30cef4a2c0c6bd.png)

  
    竞远安全致力于网络安全风险评估、等保测评、安全培训、移动安全、漏洞检测等业务的研究和探索，结合客户实际情况，针对不同领域客户，提供个性化、有侧重的、有行业属性的专业安全服务，此次ZPER联盟及香港、广东互金协会到访竞远安全，让我司对区块链技术在金融科技领域的实际应用有了进一步理解。竞远安全也会继续践行“让安全更安全”的服务理念，跟随新型行业的应用，在安全测评领域创新开拓，不断提升安全技术服务水平。
