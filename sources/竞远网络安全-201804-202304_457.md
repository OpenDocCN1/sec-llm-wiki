# 汇聚天下红帽英才，共谱网络安全乐章

2018年5月26日，由“竞远安全”协办的第二届“红帽杯”网络安全攻防大赛在广州塔圆满落幕。作为在广东举办的最受瞩目的网络安全赛事之一，本届“红帽杯”吸引来自各地的512支队伍，约1300名队员报名。经过多轮角逐，“抓住历史机遇建设网络强国战队”、“万家灯火战队”、“SAINTSEC战队”分别在“高校组”、“政府国企事业单位组”、“安全企业组”三大组别独占鳌头，登上冠军宝座。

  

![](../Images/84301d66252d56dfefdf02f79cfd2018.png)

**红帽杯第二届网络安全攻防大赛火热现场**

 

本次大赛由广东省公安厅、共青团广东省委员会、广东省教育厅指导，广东省计算机信息网络安全协会、南方报业传媒集团联合主办，华南理工大学承办，广州竞远安全技术股份有限公司协办。中国工程院院士、红帽杯网络安全攻防大赛顾问方滨兴、共青团广东省委副书记唐锐、省公安厅网络警察总队总队长李正祥、政委戴自力、广东省计算机信息网络安全协会会长陆以勤、广州竞远安全技术股份有限公司董事长林殿魁等出席了活动的启动仪式。

  

![](../Images/3f18bc4efc352d5e8c5047e3a825b74a.png)

**“红帽杯”中国网络安全攻防精英大赛启动仪式**

 

随着《中华人民共和国网络安全法》全面实施，我国各知名高校、政企和安全企业高度重视网络安全发展和网络安全人才培养。 “红帽杯”网络安全攻防大赛在大力推进广东省“红帽先锋”网络安全人才培养计划，探索网络安全人才培育新模式上谱写了新的篇章，通过打造一个面向网络安全攻防技术的交流平台来锻炼网络安全技术人员的实战水平，从而推动网络安全新技术的应用水平，促进网络安全事业的加速发展上做出了巨大贡献。

 

**主题沙龙聚专家、分享顶级新技术**

 

在比赛的同时，由广州竞远安全技术股份有限公司承办的“行动、赋能、创新”--《网络安全法》实施一周年VIP主题沙龙在广州塔珠江五会议厅如期举行。整场沙龙分两部分：第一部分，“专家思绪，科技未来”为主题的网络安全新技术、新理念和新服务论坛；第二部分，沙龙互动；本次沙龙在短短三个小时中，成功完成了沙龙配合大赛共同提升的目标，通过两场相互关联的单元活动，达到提升“红帽杯”大赛的权威性、专业性和影响力。

  

![](../Images/9314775cbf11d90a0f14476569dc8365.png)

  

沙龙首先以“专家思绪，科技未来”为主题论坛作为开场，邀请了广东省网警总队蔡旭副总队长、北京大学李挥教授、中山大学温武少教授、华南理工大学陆以勤教授、竞远安全董事长林殿魁和永信至诚副总裁章珑先后从拟态防御、数据安全、等保服务、网络安全及未来等方面发表了精彩演讲。

  

在“沙龙互动”环节中，来自电子五所的专家张昊先生从习总书记提出利用“旋转门”制度培养网络安全的优秀人才理念出发，与演讲嘉宾一起探讨新形势下如果保障“红帽”英才的培养计划，演讲嘉宾各自从不同的角度发表看法，获得现场观众的热烈掌声。随后，观众争先恐后的提出各种问题与演讲嘉宾交流，整个沙龙始终处于活跃、热烈的氛围之中。

 

![](../Images/c9fb4a7c997e055e4e8f2e43fef84a87.png)

  

**竞远安全新荣誉、应急响应增保障**  

  

“红帽杯”网络安全攻防大赛广东省网络安全应急响应平台发起的“红帽先锋”网络安全人才培养计划的重要组成部分，是面向政府机关、企事业单位、以及高等院校和信息安全企业的一次网络安全赛事。由于出色的工作、精湛的技术、雄厚的实力、优良的服务而著称的竞远安全在此次大赛中被授予技术支撑单位的称号，为广东省网络安全应急响应增添了重要保障力量。

  

![](../Images/6acaa4cdae83c0101ab5a7d12dfd6301.png)

**广东省网络安全应急响应平台技术支撑单位授予现场**

  

广东省网络安全应急响应平台（www.gdcert.com.cn）是广东省计算机信息网络安全协会在省公安厅指导下，参照现实社会120应急系统，联合国内网络安全专业技术企业建立的新型网络安全应急体系。在广东省21个地市和重点行业设立分中心，开通7×24小时应急服务热线，为全社会提供专业化的应急处置服务，及时有效解决网络安全问题。平台开通一年半以来，注册使用企业用户5700多家，技术支撑单位40多个，派出技术专家300多人次，处置各类网络安全事件近200起。除应急响应外，平台日常还为注册用户提供漏洞检测、预警、修补服务，目前已发现修补高危漏洞3700多个，有效提升安全防护能力。还组织相关公司采编发布最新网络安全咨询、风险提醒，制作各类安全指引、防范知识，帮助广大群众提高安全意识，保护好个人隐私，防止上当受骗。
