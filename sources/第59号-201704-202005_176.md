# lucky？？lucky勒索病毒，这次是Linux和Windows“双击”！

近日，某安全厂商发现**国内首例可加密Linux服务器的勒索病毒**，该勒索病毒可攻击WINDOWS和LINUX服务器，并将文件后缀加密为.lucky，该病毒的传播方式和Satan勒索病毒相似。   

![](../Images/5cf8ef74212d9ef24bdf8d67c8f92d38.png)

  

在内网，Lucky勒索病毒主要通过弱口令，利用永恒之蓝工具包进行传播；在外网，则是通过弱口令和Web应用漏洞，如JBoss反序列化漏洞（CVE-2017-12149)；JBoss默认配置漏洞(CVE-2010-0738)；Put任意上传文件漏洞；Tomcat web管理后台弱口令爆破；Weblogic WLS 组件漏洞(CVE-2017-10271)；apache Struts2远程代码执行漏洞S2-045、Apache Struts2远程代码执行漏洞S2-057。   

  

遗憾的是，**一经被Lucky勒索病毒加密，目前暂无法解密**。   

![](../Images/2a583c3cee30617da66717e4a2d69444.png)

  

59号安全实验室建议，为避免勒索中招，赶紧开启防御模式吧！   

  

**防御方式如下：**

  

1、隔离感染主机：已中毒计算机尽快隔离，关闭所有网络连接

2、关闭445；135；137等网络共享端口

3、windows下安装专门的防勒索软件，如诺亚防勒索系统。

4、若存在以上web应用，及时修复相应漏洞

5、针对22；3389端口的远程服务，及时增加密码强度。如数字、字母、特殊字符12位以上 

  

  

**更多阅读**

继今年8月台积电因中电脑勒索病毒损失26亿之后，据台媒报道，又一家半导体公司——台湾合晶科技中电脑勒索病毒，全线电脑感染，造成产线瘫痪，工厂全部停产！

  

专家建议，企业必须在感染病毒之前采取适当的预防措施，而不是坐以待毙。同时，专家警告不要支付赎金，因为它并不能保证攻击者会释放解密密钥，而且在许多情况下他们都不会。相反，每个人都应该确保他们设置了安全防护措施，并且要注意不要随意点击任何的链接或可疑的附件。
