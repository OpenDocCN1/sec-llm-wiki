**漏洞分析**

对于路由器中的敏感信息搜索，我们可以通过firmwalker.sh进行查找，项目地址为https://github.com/craigz28/firmwalker.git 

git clone https://github.com/craigz28/firmwalker.git 下载到本地环境中。

接下来通过binwalk提取dir815固件

binwalk -Me DIR-815A1\_FW101SSB03.bin --run-as=root

![](../Images/6fae6b4f379c14edc656955f2b8c9fad.png)

切换终端到firmwalker目录下，执行

*   
*   

```
./firmwalker.sh /home/sojrs/Desktop/firewalk/_DIR-815A1_FW101SSB03.bin.extracted/squashfs-root./dir815.txt
```

该命令将会搜索位于/home/sojrs/Desktop/firewalk/\_DIR-815A1\_FW101SSB03.bin.extracted/squashfs-root目录下的敏感信息，并将搜索结果保存到当前目录的dir815.txt文件中

![](../Images/ab5a8b7356e08a4dd1a33118e9725127.png)

查看dir815.txt文件，在可执行脚本栏目中，其中etc/init0.d/S80telnetd.sh保存有账号

![](../Images/f5174da8b5bd0661f9bce0605910b6e8.png)![](../Images/246c95be77dd9679ccb77e585bd093a6.png)

用户名为Alphanetworks，密码位于/etc/config/image\_sign文件中，查看文件内容得到密码为wrgnd08\_dlob\_dir815ss

![](../Images/035762bac754c8c294717f0ca7f87ae3.png)

这个漏洞提醒我们在路由器系统中，不要忘记默认配置类的漏洞，由于是配置文件中可能保存有系统的一些默认口令等。
