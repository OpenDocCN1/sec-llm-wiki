**漏洞简述**

Huawei HG532系列路由器是一款为家庭和小型办公用户打造的无线路由器产品。2017年11月，Check Point发布安全预警CPAI-2017-1016，报告了华为 HG532 产品的远程命令执行漏洞(CVE-2017-17215)。认证后的攻击者可以向设备37215端口发送恶意报文发起攻击，成功利用漏洞可以远程执行任意代码。

**漏洞分析**

通过上述漏洞利用脚本不难发现，该漏洞所利用的服务端口为32715，存在漏洞的接口为/ctrlt/DeviceUpgrade\_1，存在漏洞的参数为NewStatusURL

接下来可以在binwalk解压得到的/squashfs-root目录中搜索32715、DeviceUpgrade\_1、NewStatusURL、NewDownloadURL关键字，看看哪个文件调用了这些存在漏洞的关键点

*   
*   
*   

```
grep -r 37215grep -r DeviceUpgrade_1grep -r NewStatusURL
```

![](../Images/b6bdc616c4e534758a12fd4437f7a8a3.png)

可以发现，上述漏洞应和bin/upnp、bin/mic有关
