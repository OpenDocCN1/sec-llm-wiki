# 【漏洞通告】 Apache Linkis反序列化漏洞&文件读取漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247494028&idx=1&sn=a7fcd9688b69069cb4aeb618d7a9b142&chksm=e95ab315de2d3a037e2e316701f0e835d02db385b928e427c3d49bd49f0887ab76e7913c868c&scene=126&sessionid=1681405345#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247494028&idx=1&sn=a7fcd9688b69069cb4aeb618d7a9b142&chksm=e95ab315de2d3a037e2e316701f0e835d02db385b928e427c3d49bd49f0887ab76e7913c868c&scene=126&sessionid=1681405345#rd)

01**漏洞描述**![](../Images/0498ba277ff73f9ca2b36cbec02e94d8.png)Apache Linkis（Incubating）是一个开源的上层应用与底层引擎之间的计算中间件，提供了强大的连接、复用、编排、扩展和处理能力。美创安全实验室监测到Apache官方发布安全公告，修复了Linkis DatasourceManager模块中的一个反序列化漏洞和一个文件读取漏洞，漏洞编号：CVE-2022-44645，CVE-2022-44644，漏洞等级：高危。

*   **CVE-2022-44645: Apache Linkis反序列化漏洞**

简述：Apache Linkis版本<=1.3.0与MySQL Connector/J一起使用时，当对数据库具有写入权限并使用MySQL数据源和恶意参数配置新数据源时，存在反序列化漏洞，可能导致远程代码执行。

*   **CVE-2022-44644: Apache Linkis文件读取漏洞**

简述：Apache Linkis版本<=1.3.0与MySQL Connector/J一起使用时，通过在jdbc参数中将allowLoadLocalInfile添加为true，经过身份验证的用户可以通过连接恶意MySQL服务器读取任意本地文件。02**影响范围**![](../Images/0498ba277ff73f9ca2b36cbec02e94d8.png)

目前受影响的Apache Linkis版本：

*   Apache Linkis 版本 <= 1.3.0
    

03**处置建议**![](../Images/0498ba277ff73f9ca2b36cbec02e94d8.png)

目前这些漏洞已经修复，受影响用户可及时升级到Apache Linkis 1.3.1版本。
