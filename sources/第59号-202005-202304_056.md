# 【漏洞通告】 Cacti命令执行漏洞（CVE-2022-46169）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247493665&idx=1&sn=27f959f2cd8db16650d4fddbac1fc8eb&chksm=e95ab2b8de2d3baeba4db0a43d107a2275c174d2183f97b37ed34c1ec511c543ef10504402f6&scene=126&sessionid=1681405362#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247493665&idx=1&sn=27f959f2cd8db16650d4fddbac1fc8eb&chksm=e95ab2b8de2d3baeba4db0a43d107a2275c174d2183f97b37ed34c1ec511c543ef10504402f6&scene=126&sessionid=1681405362#rd)

**1****漏洞描述**

美创安全实验室监测到Cacti项目发布安全公告，修复了Cacti中的一个命令注入漏洞，漏洞编号：CVE-2022-46169，漏洞等级：严重，漏洞评分：9.8。

Cacti项目是一个开源平台，可为用户提供强大且可扩展的操作监控和故障管理框架。

该漏洞存在于“remote\_agent.php”文件中，攻击者无需身份验证即可访问此文件。攻击者可通过控制由get\_nfilter\_request\_var()函数检索的参数$poller\_id，来满足poller\_item =POLLER\_ACTION\_SCRIPT\_PHP条件，触发proc\_open()函数，从而导致命令执行。漏洞利用成功后，未经身份验证的攻击者可以在运行 Cacti 的服务器上执行任意代码。

**2****影响范围****受影响版本：**

*   Cacti == 1.2.22

**不受影响版本：**

*   Cacti == 1.2.23
*   Cacti == 1.3.0

*   
*   

```
function poll_for_data() {// ...$cactiphp = proc_open(read_config_option('path_php_binary') . ' -q ' . $config['base_path'] . '/script_server.php realtime ' . escapeshellarg($poller_id), $cactides, $pipes);// ...
```
