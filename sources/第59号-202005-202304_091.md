# CVE-2022-36446 Webmin命令注入漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247493102&idx=2&sn=f15ee8aa770955e95a4d95d636f6dfbb&chksm=e95abf77de2d3661a1f9ec1e1916e1166fd4129a05a52ac819fbcbbd4cb34c750187beb29dc5&scene=126&sessionid=1681405372#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247493102&idx=2&sn=f15ee8aa770955e95a4d95d636f6dfbb&chksm=e95abf77de2d3661a1f9ec1e1916e1166fd4129a05a52ac819fbcbbd4cb34c750187beb29dc5&scene=126&sessionid=1681405372#rd)

**漏洞简介**![](../Images/3e8988aacab8c5f7d1f8e27c7443d96f.png)Webmin是功能最强大的基于Web的Unix系统管理工具。管理员通过浏览器访问Webmin的各种管理功能并完成相应的管理动作。在版本1.997之前的Webmin中存在一个任意命令注入漏洞，触发该漏洞需登录Webmin。**影响范围**![](../Images/3e8988aacab8c5f7d1f8e27c7443d96f.png)WebMin版本小于1.997**环境搭建**![](../Images/3e8988aacab8c5f7d1f8e27c7443d96f.png)

可通过vulhub搭建漏洞环境

执行命令git clone https://github.com/vulhub/vulhub

将vulhub下载到本地

![](../Images/3f2281c171b2714ce384384df29eba63.png)

进入vulhub/webmin/CVE-2019-15107目录，CVE-2019-15107漏洞环境也可用作CVE-2022-36446

![](../Images/9a4e871fd3ecf1e039c1a8339e5d867a.png)

执行命令

docker-compose up -d启动漏洞环境

![](../Images/acea0045231543c2bd634545710144e8.png)

待漏洞环境启动后

执行

docker-compose ps查看漏洞环境映射端口

![](../Images/d4704859545dc3b1359bab371cb2da28.png)

访问https://ip:10000，出现以下界面代表环境部署成功

![](../Images/4f8cb5ead6655ab3bd42110aafdc857a.png)

接下来需进入漏洞环境容器修改webmin密码

执行命令

docker ps

查看漏洞环境容器id

![](../Images/c99ca5d55c88549ad08b3a9ed14b7d23.png)

执行命令

docker exec -it ccbc3fcb60b6 /bin/bash

进入docker容器内部

![](../Images/b67a7ff6f8bf03dcd39aafe929d12c5b.png)

之后进入docker容器的/usr/share/webmin/目录下

![](../Images/d125d2a9646dffe67cdf981f0e036375.png)

执行命令

./changepass.pl /etc/webmin root root

将root密码设置为root

![](../Images/79a03896dbbd61c293854d488e39c27d.png)

设置完成后即可以root/root登录https://ip:10000/

![](../Images/e8982001cbd30128461686b5284f6fac.png)
