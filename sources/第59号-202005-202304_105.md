# 【漏洞通告】Atlassian Bitbucket 命令注入漏洞（CVE-2022-36804）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247492849&idx=1&sn=ce07810f39b15329f5ab6258b35cf17a&chksm=e95abe68de2d377e1fa18ee49189282c6fbd5c54349264852dce87787cd38d07f6910e3f31f8&scene=126&sessionid=1681405377#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247492849&idx=1&sn=ce07810f39b15329f5ab6258b35cf17a&chksm=e95abe68de2d377e1fa18ee49189282c6fbd5c54349264852dce87787cd38d07f6910e3f31f8&scene=126&sessionid=1681405377#rd)

**漏洞概述**

  
  

美创安全实验室监测到Atlassian官方发布安全公告，修复了Bitbucket Server和Bitbucket Data Center中的一个命令注入漏洞，该漏洞允许攻击者在有权访问公共 Bitbucket 存储库或对私有存储库具有读取权限的情况下，可以通过发送恶意 HTTP 请求来执行任意代码，最终获取服务器权限。漏洞编号：CVE-2022-36804，漏洞等级：严重，CVSS 评分：9.9。

目前，Atlassian官方已发布新版本修复了此漏洞，请用户及时确认是否受到漏洞影响，尽快更新到安全版本。**影响范围**  
  

目前受影响的版本：

7.0.0 ≤ Atlassian Bitbucket Server ≤ 8.3.0

7.0.0 ≤ Atlassian Bitbucket Data Center ≤ 8.3.0**处置建议**  
  

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。
