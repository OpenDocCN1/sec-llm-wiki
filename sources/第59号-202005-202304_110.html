01




漏洞概述

美创安全实验室监测到GitLab官方发布安全公告，修复了GitLab社区版（CE）和企业版（EE）中的一个远程代码执行漏洞，该漏洞允许经过身份验证的用户通过GitHub API端点导入的方式远程执行代码，最终接管服务器。漏洞编号：CVE-2022-2884，漏洞等级：严重，漏洞评分：9.9。

目前，GitLab官方已发布新版本修复了此漏洞，请用户及时确认是否受到漏洞影响，尽快更新到安全版本。

02




影响范围

影响版本

安全版本

11.3.4 <= GitLab CE/EE < 15.1.5
GitLab CE/EE = 15.1.5
15.2 <= GitLab CE/EE < 15.2.3
GitLab CE/EE = 15.2.3

15.3 <= GitLab CE/EE < 15.3.1

GitLab CE/EE = 15.3.1
03




处置建议
受影响用户可升级到GitLab 15.3.1、15.2.3、15.1.5或更高版本。
