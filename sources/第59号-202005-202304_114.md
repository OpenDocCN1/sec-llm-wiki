# 【漏洞通告】Google Chrome代码执行漏洞（CVE-2022-2856）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247492734&idx=1&sn=b51db0bc30407d3fa0ce851ceb95d979&chksm=e95abee7de2d37f14e43a73a1eb648851ae19a4d946fe290d4e99ff04bdae2db457aafaeefa0&scene=126&sessionid=1681405377#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247492734&idx=1&sn=b51db0bc30407d3fa0ce851ceb95d979&chksm=e95abee7de2d37f14e43a73a1eb648851ae19a4d946fe290d4e99ff04bdae2db457aafaeefa0&scene=126&sessionid=1681405377#rd)

  
**漏洞概述**  
  

美创安全实验室监测到Google Chrome官方发布安全通告，其中包含Google Chrome 代码执行漏洞。漏洞编号：CVE-2022-2856，漏洞等级：高危，且已监测到在野利用。

Chrome中的Intents功能可以直接从网页上启动应用程序和web服务，由于Intents对不可信输入数据的验证不足，Google Chrome 存在远程代码执行漏洞。攻击者可通过诱导用户打开特制的页面来利用此漏洞，配合其他漏洞可在目标系统上执行任意代码。

目前，Google Chrome官方已发布新版本修复了此漏洞，请用户及时确认是否受到漏洞影响，尽快更新到安全版本。

  
**影响范围**  
  

*   Google Chrome Desktop < 104.0.5112.101 (Mac/linux)
*   Google Chrome Desktop < 104.0.5112.102/101 (Windows)
*   Google Chrome Extended < 104.0.5112.101（Mac）
*   Google Chrome Extended < 104.0.5112.102（Windows）
    

  
**处置建议**  
  

升级到以下版本：

*   Google Chrome Desktop >= 104.0.5112.101 (Mac/linux)
    
*   Google Chrome Desktop >= 104.0.5112.102/101(Windows)
    
*   Google Chrome Extended >= 104.0.5112.101（Mac）
    
*   Google Chrome Extended >= 104.0.5112.102（Windows）
