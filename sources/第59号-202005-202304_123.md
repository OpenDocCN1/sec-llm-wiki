# Apache Spark 命令注入漏洞（CVE-2022-33891）复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247492491&idx=2&sn=92bacc0bfe5fbdef728645532218f2aa&chksm=e95ab912de2d300421daf2ea17cdb0753918ca954cacc08aef5d4828a2cfb48d19cdca4078b7&scene=126&sessionid=1681405377#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247492491&idx=2&sn=92bacc0bfe5fbdef728645532218f2aa&chksm=e95ab912de2d300421daf2ea17cdb0753918ca954cacc08aef5d4828a2cfb48d19cdca4078b7&scene=126&sessionid=1681405377#rd)

**漏洞概述**

![](../Images/725114fe35eb0e94a7af95d185c2730c.png)

Apache Spark UI 提供了通过配置选项 spark.acls.enable 启用 ACL 的可能性。如果启用了 ACL，则 HttpSecurityFilter 中的代码路径可以允许攻击者通过提供任意用户名来执行模拟。因此，攻击者能够访问权限检查功能，该功能最终将根据攻击者的输入构建一个 Unix shell 命令并执行。成功利用此漏洞可导致任意 shell 命令执行。

**漏洞影响范围**![](../Images/725114fe35eb0e94a7af95d185c2730c.png)

| 影像版本  
 || 安全版本 |
| :-: | :-: |
| Apache Spark<= 3.0.3 || Apache Spark>= 3.3.0 |
| 3.1.1≤ Apache Spark ≤ 3.1.2 || Apache Spark>= 3.1.3 |
| 3.2.0≤ Apache Spark ≤3.2.1 || Apache Spark>= 3.2.2 |
