# 【漏洞通告】Google Chrome远程代码执行漏洞（CVE-2022-2294）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247492126&idx=1&sn=c4ea4ee69dd3aa3b3572d2b9946922d8&chksm=e95ab887de2d3191fde52aea1e25228aa85c426a21e726ddb73e0d0d769ef903e58070acdc8b&scene=126&sessionid=1681405382#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247492126&idx=1&sn=c4ea4ee69dd3aa3b3572d2b9946922d8&chksm=e95ab887de2d3191fde52aea1e25228aa85c426a21e726ddb73e0d0d769ef903e58070acdc8b&scene=126&sessionid=1681405382#rd)

**漏洞概述**  
  

美创安全实验室监测到Google Chrome官方发布Google Chrome远程代码执行漏洞通告，同时已监测到在野利用。漏洞编号：CVE-2022-2294，漏洞等级：高危。

该漏洞是由于 Google Chrome WebRTC （网络实时通信）组件中存在基于堆的缓冲区溢出漏洞。攻击者可利用该漏洞，构造恶意数据造成缓冲区溢出攻击，并执行远程代码。**影响范围**  
  

目前受影响的 Google Chrome 版本：

*   Google Chrome Desktop < 103.0.5060.114
    
*   Google Chrome Extended < 102.0.5005.148
    
*   Google Chrome Android < 103.0.5060.71
