# CVE-2022-22965：Spring Framework远程代码执行漏洞简析

![](../Images/ed2af7698ce845986586da15f34f99df.png)**漏洞概述**![](../Images/ed2af7698ce845986586da15f34f99df.png)

Spring是一个开源应用框架，是针对bean的生命周期进行管理的轻量级容器，近年来被广泛应用到系统开发中。 

Spring Framework存在一个远程代码执行漏洞(CVE-2022-22965)，该漏洞是由于Spring框架存在处理流程缺陷，攻击者可远程实现对目标主机的后门文件写入和配置修改，继而通过后门文件访问获得目标主机权限。使用Spring框架或衍生框架构建网站等应用，且同时使用JDK版本在9及以上版本的，易受此漏洞攻击影响。![](../Images/ed2af7698ce845986586da15f34f99df.png)**影响版本**![](../Images/ed2af7698ce845986586da15f34f99df.png)

*   JDK版本号在9及以上，且使用了Spring框架或衍生框架的系统。
*   Spring Framework 5.3.X < 5.3.18
*   Spring Framework 5.2.X < 5.2.20
    

![](../Images/ed2af7698ce845986586da15f34f99df.png)**安全版本**![](../Images/ed2af7698ce845986586da15f34f99df.png)

*   Spring Framework = 5.3.18
    
*   Spring Framework = 5.2.20

**1.JDK版本号排查**

在业务系统的运行服务器上，执行“java -version”命令查看运行的JDK版本，如果版本号小于等于9，则不受漏洞影响。

  

**2.Spring框架使用情况排查**

如果业务系统项目以war包或者jar包进行部署，按照如下步骤进行判断：

1）将war文件或者jar文件的后缀修改成.zip，解压zip文件；

2）在解压缩目录下搜索是否存在 spring-beans-\*.jar 格式的jar文件，如存在则说明业务系统使用了spring框架进行开发。

3）如果spring-beans-\*.jar 文件不存在，则在解压缩目录下搜索CachedIntrospectionResuLts.class 文件是否存在，如存在则说明业务系统使用了Spring框架开发。

  

**3.综合判断**

在完成以上两个步骤排查后，同时满足以下两个条件可确定受此漏洞影响：

1）JDK版本号在9及以上的；

2）使用了Spring框架或衍生框架；![](../Images/ed2af7698ce845986586da15f34f99df.png)**处置建议**![](../Images/ed2af7698ce845986586da15f34f99df.png)
