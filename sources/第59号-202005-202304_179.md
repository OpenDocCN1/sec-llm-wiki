# CVE-2022-24112：Apache APISIX 远程代码执行漏洞分析与复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247491423&idx=2&sn=9b9dcee8c5b499a93155b989014b0cc4&chksm=e95945c6de2eccd0f8e07d45ce59f95d3cea35eefab70c7a931c6a1a58895cdfe44c82f3335b&scene=126&sessionid=1681405392#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247491423&idx=2&sn=9b9dcee8c5b499a93155b989014b0cc4&chksm=e95945c6de2eccd0f8e07d45ce59f95d3cea35eefab70c7a931c6a1a58895cdfe44c82f3335b&scene=126&sessionid=1681405392#rd)

![](../Images/5b9b89ffa7098db8fb1ff037baeb7bfb.png)漏洞概述Apache Apisix是美国阿帕奇（Apache）基金会的一个云原生的微服务API网关服务。该软件基于 OpenResty 和 etcd 来实现，具备动态路由和插件热加载，适合微服务体系下的 API 管理。

Apache APISIX中存在远程代码执行漏洞，该漏洞源于产品的batch-requests插件未对用户的批处理请求进行有效限制。攻击者可通过该漏洞绕过Admin API的IP限制，容易导致远程代码执行。

![](../Images/62f9a633bf0a6b4e21e20287853e12b3.png)影响版本

Apache APISIX >=2.11.0，<2.12.1

Apache APISIX <2.10.4![](../Images/e5d3e12ab260aba1192b91239a7ba284.png)环境搭建

（1）本次使用docker搭建本地测试环境进行复现：

*   
*   
*   

```
git clone https://github.com/twseptian/cve-2022-24112cd cve-2022-24112/apisix-docker/example/docker-compose -p docker-apisix up -d
```

![](../Images/94f3030e5254a11f0c93f82d442689c2.png)  

（2）服务启动后，访问http://your-ip:8080即可看到演示页面

![](../Images/0426fbc503b801426fa21d8f9a658530.png)

（3）默认管理员用户名及密码为admin/admin，可登录管理后台
