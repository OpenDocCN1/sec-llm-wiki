漏洞简介

Spring Cloud Function 是基于Spring Boot 的函数计算框架，它抽象出所有传输细节和基础架构，允许开发人员保留所有熟悉的工具和流程，并专注于业务逻辑。

由于Spring Cloud Function中RoutingFunction类的apply方法将请求头中的“spring.cloud.function.routing-expression”参数作为Spel表达式进行处理，造成了Spel表达式注入漏洞，未经授权的远程攻击者可利用该漏洞执行任意代码。![](../Images/14465563cd7710d620f3afd6b7505058.png)漏洞影响范围

3.0.0.RELEASE <= Spring Cloud Function <= 3.2.2

git clone https://github.com/Pizz33/Spring-Cloud-Function-SpEL

其中
