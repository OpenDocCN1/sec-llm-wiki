# 【高危漏洞通告】Spring Cloud Function SPEL表达式注入漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247491203&idx=1&sn=a03c26d2ee96bd5743baeca62975edbe&chksm=e959441ade2ecd0cbb393530c6ba186c10e4043173e5986913f21678b65a549fa38960f39671&scene=126&sessionid=1681405398#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247491203&idx=1&sn=a03c26d2ee96bd5743baeca62975edbe&chksm=e959441ade2ecd0cbb393530c6ba186c10e4043173e5986913f21678b65a549fa38960f39671&scene=126&sessionid=1681405398#rd)

**1****漏洞概述**

Spring Cloud Function 是基于Spring Boot 的函数计算框架，它抽象出所有传输细节和基础架构，允许开发人员保留所有熟悉的工具和流程，并专注于业务逻辑。

由于Spring Cloud Function中RoutingFunction类的apply方法将请求头中的“spring.cloud.function.routing-expression”参数作为Spel表达式进行处理，造成了Spel表达式注入漏洞，未经授权的远程攻击者可利用该漏洞执行任意代码。

**2****影响范围**

*   3.0.0.RELEASE <= Spring Cloud Function <= 3.2.2

**3****漏洞利用条件**Spring Cloud Function 项目中引用了 spring-cloud-function-context 组件即可。**4****处置建议**目前官方已针对此漏洞发布修复补丁，请受影响的用户尽快更新进行防护，官方链接：https://github.com/spring-cloud/spring-cloud-function/commit/0e89ee27b2e76138c16bcba6f4bca906c4f3744f

注：目前官方暂未发布新版本，请持续关注并及时更新：https://github.com/spring-cloud/spring-cloud-function/tags
