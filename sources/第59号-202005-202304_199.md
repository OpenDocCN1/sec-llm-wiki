# CVE-2022-0847 Dirty Pipe linux提权漏洞分析与复现

![](../Images/2d2f75753629946c2cb100e48445bd2a.png)1漏洞概述  
  
CVE-2022-0847（Dirty Pipe）是存在于 Linux内核 5.8 及之后版本中的本地提权漏洞。攻击者通过利用此漏洞，可覆盖重写任意可读文件中的数据，从而可将普通权限的用户提升到特权root。CVE-2022-0847 的漏洞原理类似于 CVE-2016-5195 脏牛漏洞（Dirty Cow），但它更容易被利用。![](../Images/2d2f75753629946c2cb100e48445bd2a.png)2影响版本  
  
Linux Kernel版本 >= 5.8

Linux Kernel版本 < 5.16.11 / 5.15.25 / 5.10.102

注：该漏洞已在 Linux 5.16.11、5.15.25 和 5.10.102 中修复。

![](../Images/2d2f75753629946c2cb100e48445bd2a.png)3漏洞复现  
  

查看系统内核版本，大于等于5.8符合本次漏洞利用前提。
