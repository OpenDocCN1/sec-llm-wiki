# CVE-2021-4034：Linux Polkit权限提升漏洞分析与复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247490861&idx=2&sn=ecbc7f4ff2379d23673c8221a9f2c357&chksm=e95947b4de2ecea24de8318c651436c4a57de2dc5b08386f03d5361568154a1cc848584f4801&scene=126&sessionid=1681405408#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247490861&idx=2&sn=ecbc7f4ff2379d23673c8221a9f2c357&chksm=e95947b4de2ecea24de8318c651436c4a57de2dc5b08386f03d5361568154a1cc848584f4801&scene=126&sessionid=1681405408#rd)

**0****1****漏洞概述  
**  

  

Linux Polkit权限提升漏洞（CVE-2021-4034）是由于pkexec无法正确处理调用参数，从而将环境变量作为命令执行，具有任意用户权限的攻击者都可以在默认配置下通过修改环境变量来利用此漏洞，从而获得受影响主机的root权限。  

  

**02****影响版本**  

  

由于为系统预装工具，目前主流Linux版本均受影响。  

  

**0****3****安全版本**  

  

**CentOS系列：**

CentOS 6：polkit-0.96-11.el6\_10.2

CentOS 7：polkit-0.112-26.el7\_9.1

CentOS 8.0：polkit-0.115-13.el8\_5.1

CentOS 8.2：polkit-0.115-11.el8\_2.2

CentOS 8.4：polkit-0.115-11.el8\_4.2  

  

**Ubuntu系列：**

Ubuntu 20.04 LTS：policykit-1 -0.105-26ubuntu1.2

Ubuntu 18.04 LTS：policykit-1 - 0.105-20ubuntu0.18.04.6

Ubuntu 16.04 ESM：policykit-1 -0.105-14.1ubuntu0.5+esm1

Ubuntu 14.04 ESM：policykit-1 -0.105-4ubuntu3.14.04.6+esm1  

  

**0****4****漏洞检测**  

  

Linux系统用户可以通过查看Polkit版本来判断当前系统是否在受影响范围内，主流Linux发行版命令如下：  

  

CentOS：

rpm -qa polkit

Ubuntu：

dpkg -l policykit-1
