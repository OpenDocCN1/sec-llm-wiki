# CVE-2021-42342：GoAhead 远程命令执行漏洞分析与复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247490576&idx=2&sn=7258fc039729f7921faf8c74c3ed05d9&chksm=e9594689de2ecf9fa6c84b773eca739c3e79d08b771dc25bd72934c463ca4371fe1a75f3b272&scene=126&sessionid=1681405408#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247490576&idx=2&sn=7258fc039729f7921faf8c74c3ed05d9&chksm=e9594689de2ecf9fa6c84b773eca739c3e79d08b771dc25bd72934c463ca4371fe1a75f3b272&scene=126&sessionid=1681405408#rd)

GoAhead 是一个开源、简单、轻巧、功能强大、可以在多个平台运行的嵌入式 WebServer。该漏洞是由于上传过滤器没有设置不受信任的 var 位绕过 CGI 处理程序的前缀检测，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程命令执行攻击，最终获取服务器最高权限。  

  

  
影响版本  
  
  

  

目前受影响的 GoAhead 版本：  

  

4.0.0<= GoAhead <= 4.1.2

5.0.0<= GoAhead < 5.1.5  

  

  
漏洞复现  
  
  

  

本次使用vulhub搭建本地测试环境进行复现：  

  

https://github.com/vulhub/vulhub/tree/master/goahead/CVE-2021-42342  

  

（1）打印测试内容

编写打印测试文件的poc代码如下（poc.c）：  

  

![](../Images/90875c83bf96b425e866f509a71b4fb4.png)

  

使用如下命令编译以上代码：

gcc -s-shared -fPIC ./poc.c -o payload.so

使用自带的poc.py脚本对测试环境进行测试,获取回显。

python3 poc.py http://target-ip:8080/cgi-bin/indexpayload.so

  

![](../Images/9f1207a44383bed91ed188a37d689191.png)

  

（2）反弹shell

反弹shell的poc代码如下（shell.c）：  

  

![](../Images/ef5726fd4d7f0f7e8d0f27c8cc4cc922.png)

  

使用如下命令编译以上代码：

gcc -s-shared -fPIC ./shell.c -o shell.so

在对应的ip端口上开启监听  

  

![](../Images/f1b1165e84b12ddfbfd56970d4582f2d.png)  
  

执行payload，此时脚本可能会报错，但没有影响。

python3 poc.py http://target-ip:8080/cgi-bin/index shell.so  

  

![](../Images/526334be80fb84dce6e2f2e232cd2118.png)
