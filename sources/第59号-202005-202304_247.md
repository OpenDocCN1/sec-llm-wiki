# 【紧急通告】Apache Log4j 远程代码执行漏洞！！！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247490210&idx=1&sn=59a028a5e9ceb148d535fb163a655c9e&chksm=e959403bde2ec92d91185187f660da667bb228bc344ab97a83e39cb2703282a97eb583f28065&scene=126&sessionid=1681405424#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247490210&idx=1&sn=59a028a5e9ceb148d535fb163a655c9e&chksm=e959403bde2ec92d91185187f660da667bb228bc344ab97a83e39cb2703282a97eb583f28065&scene=126&sessionid=1681405424#rd)

  
漏洞描述

  

Apache Log4j2是一款Java日志框架，是Log4j 的升级版。可以控制每一条日志的输出格式。通过定义每一条日志信息的级别，能够更加细致地控制日志的生成过程。  

  

美创安全实验室监测到一则Apache Log4j2组件存在远程代码执行漏洞的信息，并成功复现该漏洞。该漏洞是由于Apache Log4j2某些功能存在递归解析功能，攻击者可利用该漏洞在未授权的情况下，构造恶意数据进行远程代码执行攻击，最终获取服务器最高权限。  

  

因该组件使用极为广泛，美创安全实验室建议所有用户尽快升级到安全版本，避免被外部攻击者入侵。  

  

  
漏洞威胁等级

  

**高危，该漏洞影响范围极广，危害极大。**

   

  
目前受影响的Apache Log4j2

  

2.0 ≤ Apache Log4j <= 2.14.1  

  
安全版本

  

log4j-2.15.0-rc1

 

  
漏洞处置建议

  

1\. 当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：  

  

https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc1

 

2\. 临时解决方案  

  

1)设置jvm参数 “-Dlog4j2.formatMsgNoLookups=true”

2)设置“log4j2.formatMsgNoLookups=True”

3)系统环境变量“FORMAT\_MESSAGES\_PATTERN\_DISABLE\_LOOKUPS”设置为“true”

4)关闭对应应用的网络外连，禁止主动外连
