XXL-JOB简介


XXL-JOB是一个分布式任务调度平台，其核心设计目标是开发迅速、学习简单、轻量级、易扩展。其项目代码已在GITEE和GITHUB开源，开箱即用。XXL-JOB基于JAVA语言开发，并使用MYSQL作为其后端数据库，目前在GITHUB上已有将近20K的Star，其官网地址为：https://www.xuxueli.com/xxl-job/。

 

XXXL-JOB安装部署


1.本地部署


首先安装一个MYSQL数据库，版本要在5.7以上，使用navicat等工具进行连接。




下载XXL-JOB的源码包，下载地址为https://github.com/xuxueli/xxl-job/releases


下载后，在目录xxl-job-2.3.0\doc\db下会有一个初始化SQL脚本，使用navicat将该脚本导入到MYSQL数据库中。






使用IDEA打开源码包，修改\xxl-job-2.3.0\xxl-job-admin\src\main\resources\application.properties配置文件中的MYSQL数据库配置。



运行\xxl-job-2.3.0\xxl-job-admin\src\main\java\com\xxl\job\admin\XxlJobAdminApplication.java



访问http://localhost:8080/xxl-job-admin/toLogin



2.docker部署


执行下列两条命令即可完成部署

docker pullxuxueli/xxl-job-admin

docker run -ePARAMS="--spring.datasource.url=jdbc:mysql://ip:3306/xxl_job?useUnicode=true&characterEncoding=UTF-8&autoReconnect=true&serverTimezone=Asia/Shanghai--spring.datasource.username=username--spring.datasource.password=password" -p 8080:8080 -v /tmp:/data/applogs--name xxl-job-admin -d xuxueli/xxl-job-admin:2.3.0

 

XXL-JOB漏洞合集


1.XXL-JOB后台默认弱口令漏洞


影响版本：全版本

XXL-JOB安装后，存在默认口令，且该口令为弱口令，为admin/123456




2.XXL-JOB后台任意命令执行漏洞


影响版本：全版本

登录进入XXL-JOB后台，点击任务管理，新增一个任务



运行模式选择GLUE(Shell)，调度类型选择CRON，Cron表示计划任务的运行时间频率。



点击保存后进入GLUE IDE



输入反弹shell命令，VPS开启监听




保存后关闭，点击执行一次操作。



VPS收到反弹shell，命令执行成功。



3.XXL-JOB未授权远程命令执行漏洞


影响版本：XXL-JOB <= 2.2.0


该漏洞的成因是XXL-JOB默认不开启API接口认证，攻击者可以通过调用未经授权的API接口，直接发送恶意请求，执行任意系统命令，达到控制服务器的效果。目前在最新的2.3.0版本中已默认开启API接口认证。


XXL-JOB默认的执行器端口为9999



在未登录的情况下构造如下POST请求包

POST /run HTTP/1.1

Accept-Encoding: gzip,deflate

Connection: close

XXL-JOB安全建议


1.安装部署XXL-JOB后及时修改默认口令为强口令，密码至少为8位以上的大小写字母与数字组合；


2.将XXL-JOB部署在内网，禁止开放在公网；如必须部署在公网，则修改后台默认端口，同时屏蔽执行器端口或者设置ip白名单；


3.由于XXL-JOB为开源下面，在条件允许的情况下可以自行二次开发加入登录防爆破功能。
