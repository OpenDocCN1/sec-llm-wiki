# Xstream远程代码执行漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDgxMzgxNA==&mid=2247488624&idx=1&sn=7141c8657e2e811f6e08dff6d1226e46&chksm=e9594ee9de2ec7ff16959fab5776c25727d57ecd4fb2a213c29e3256919c919513a8885c72a2&scene=126&sessionid=1681405465#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDgxMzgxNA==&mid=2247488624&idx=1&sn=7141c8657e2e811f6e08dff6d1226e46&chksm=e9594ee9de2ec7ff16959fab5776c25727d57ecd4fb2a213c29e3256919c919513a8885c72a2&scene=126&sessionid=1681405465#rd)

XStream是一个常用的Java对象和XML相互转换的工具，攻击者通过构造恶意的XML文档，可绕过XStream的黑名单，触发反序列化，从而造成反序列化代码执行漏洞。该漏洞允许远程攻击者直接获取服务器权限。  

  

**漏洞编号**

CVE-2021-29505  

  

**影响范围**

  

xStream <= 1.4.16  

  

**环境搭建**  

  

1\. 使用vulhub进行漏洞环境搭建  

  

https://raw.githubusercontent.com/vulhub/vulhub/master/xstream/CVE-2021-29505/docker-compose.yml  

  

2.执行如下命令启动镜像环境  

  

docker-compose up -d
