漏洞详情  

  

**漏洞介绍：**  

  

Apache Tomcat文件包含漏洞（CNVD-2020-10487/CVE-2020-1938）是由于Tomcat AJP协议存在缺陷而导致，攻击者利用该漏洞可通过构造特定参数，读取服务器webapp下的ROOT目录下的任意文件。若目标服务器同时存在文件上传功能，攻击者可进一步实现远程代码执行。  

  

受影响版本

Apache Tomcat 6

Apache Tomcat 7< 7.0.100

Apache Tomcat 8< 8.5.51

Apache Tomcat 9< 9.0.31  

  

不受影响版本

Apache Tomcat =7.0.100

Apache Tomcat =8.5.51

Apache Tomcat =9.0.31

 

**漏洞复现：  
**

  

下载exp：  

https://github.com/sv3nbeast/CVE-2020-1938-Tomact-file\_include-file\_read  

  

执行python2tomcat\_file\_read.py -p 8009 -f /WEB-INF/web.xml 192.168.99.145，可以成功读取web.xml文件  

  

![](../Images/1793e8f4ef26fea962a10663954c7cf0.png)

  

在ROOT目录下创建一个test.txt测试文件  

  

![](../Images/580ea5d2c783e1ac1b8ed9ffd66971fe.png)
