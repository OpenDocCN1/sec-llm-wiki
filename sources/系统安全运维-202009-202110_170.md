《每日分享好工具》

基于 Python 的 Web 应用程序扫描器，用于收集目标网站上的 OWASP 漏洞的 OSINT 和模糊测试

![](../Images/de331672318f7c66f3664e5799405144.png)

BlackWidow 是一个基于 Python 的网络应用程序蜘蛛，用于从目标网站收集子域、URL、动态参数、电子邮件地址和电话号码。该项目还包括 Inject-X 模糊器，用于扫描动态 URL 以查找常见的 OWASP 漏洞。  

## 特征：

*    自动收集目标网站的所有 URL
    
*    自动从目标网站收集所有动态 URL 和参数
    
*    自动收集目标网站的所有子域
    
*    自动从目标网站收集所有电话号码
    
*    自动收集目标网站的所有电子邮件地址
    
*    自动从目标网站收集所有表单 URL
    
*    自动扫描/模糊测试常见的 OWASP TOP 漏洞
    
*    自动将所有数据保存到排序的文本文件中
