## 代理服务器

在内网中的机器，也可能是通过代理连接内网。

检查方法：

1.  查看内网中，与其他机器的网络连接。
    
2.  查看内网中是否有主机名类似于`proxy`的机器。
    
3.  根据pac文件的路径，将其下载下来并查看。
    
4.  执行如下命令，进行确认。
    

```
curl \-x proxy\-ip:port www.baidu.com
```
