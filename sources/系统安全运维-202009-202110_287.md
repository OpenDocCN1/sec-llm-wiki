# 知识星球-资料与工具常年分享

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0NjE0NDc5OQ==&mid=2247486365&idx=2&sn=c7c5e3fd2803e16124d0a3129c52c0ff&chksm=c30bd8edf47c51fbe3756262b119731758fab94d1aa842fcc635a43c5940ee17dfe794cbfcab&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzk0NjE0NDc5OQ==&mid=2247486365&idx=2&sn=c7c5e3fd2803e16124d0a3129c52c0ff&chksm=c30bd8edf47c51fbe3756262b119731758fab94d1aa842fcc635a43c5940ee17dfe794cbfcab&scene=27#wechat_redirect)

知识星球已经运营24天，内容大致为：（1）每日分享资料与工具，并进行了分类（2）创办了作业模块，偶尔发布作业与大佬互动，（3）成员可在星球内发布问题，会有大佬及时给与回复。（4）成员可定向提问，星主与其合伙人都会及时给与回复。（5）成员如需要提供特定资料可在星球发布需求，星主与其嘉宾会及时给与回复。

**详细如下：**  

（1）星球中暂时分类为7类，成员可根据自己需求查找资料，我们会每天进行资料更新，成员或有其他需求可以提出。
