# 六款Linux常用远程连接工具介绍

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0NjE0NDc5OQ==&mid=2247500459&idx=2&sn=225fd8e180f69047dc861e52725e639b&chksm=c30811dbf47f98cd3aee447a3b71564b7126c9e97f4e50ae32fcf876aec104be47fc2a667339&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzk0NjE0NDc5OQ==&mid=2247500459&idx=2&sn=225fd8e180f69047dc861e52725e639b&chksm=c30811dbf47f98cd3aee447a3b71564b7126c9e97f4e50ae32fcf876aec104be47fc2a667339&scene=27#wechat_redirect)

**1、Xshell**

介绍：

xshell 是一个非常强大的安全终端模拟软件，它支持 SSH1, SSH2, 以及 Windows 平台的 TELNET 协议。Xshell 可以在 Windows 界面下用来访问远端不同系统下的服务器，从而比较好的达到远程控制终端的目的。

![](../Images/264da183a18452e95f624e360760922e.png)官网：

```

https://www.netsarang.com/zh/xshell/
```

**2、secureCRT**

介绍：

SecureCRT 支持 SSH，同时支持 Telnet 和 rlogin 协议。SecureCRT 是一款用于连接运行包括 Windows、UNIX 和 VMS 的理想工具。通过使用内含的 VCP 命令行程序可以进行加密文件的传输，网工应该很熟这个软件，经常使用它连接设备。

![](../Images/f6207e636e19c736313a1726a2ed517b.png)

官网：

```

https://www.vandyke.com
```

**3、WinSCP**

介绍：

WinSCP 是一个 Windows 环境下使用 SSH 的开源图形化 SFTP 工具客户端。同时支持 SCP 协议。它的主要功能就是在本地与远程计算机间安全的复制传输文件。

![](../Images/b969abc79030d92213e72eba148f6c0e.png)

官网：

```

https://winscp.net/
```

**4、PuTTY**

介绍：

PuTTY 是 SSH 和 telnet 客户端，最初由 Simon Tatham 为 Windows 平台开发。用 MIT 许可证授权。包含的组件有：PuTTY, PuTTYgen,PSFTP, PuTTYtel, Plink, PSCP, Pageant, 默认登录协议是 SSH，默认的端口为 22。

![](../Images/9067db76fa0175fd755623f3c96dc093.png)

Putty 主要是用来远程连接服务器，它支持 SSH、Telnet、Serial 等协议的连接。

官网：

```

putty.org
```

**5、MobaXterm**

介绍：

mobaxterm 的功能非常全面，几乎提供了所有重要的远程网络工具（比如 SSH、X11、RDP、VNC、FTP、MOSH 等），以及 Windows 桌面上的 Unix 命令（bash、ls、cat、sed、grep、awk、rsync 等），登录之后默认开启 sftp 模式。

![](../Images/62f68316d18cf646d976ac3ffe76930b.png)官网：

```

mobaxterm.mobatek.net
```

❝大多企业运维都喜欢用它❞

**6、FinalShell**

介绍：

FinalShell 是一体化的服务器网络管理软件 (java 语言编写)，不仅是 ssh 客户端，FinalShell 还是功能强大的开发、运维工具，充分满足用户的开发运维需求。

![](../Images/18c0769fb46997d00d8ea4f3d679ad51.png)

官网：

```

http://www.hostbuf.com/
```

❝可以直观的看出远程服务器的硬件运行情况❞
