> 通过Ping命令监控主机是否存活，如果ping失败则继续ping，三次不通就认为主机宕机或网络有问题

```

#!/bin/bash
ping_status
(){if ping -c 1 $IP > /dev/null ; then
echo "$IP is ok"
continue
fi

"192.168.18.1 192.168.1.1 192.168.18.2"
for IP in $IP_LIST; do

echo "$IP is failure"
done
```
