**1****freeCodeCamp**

https://github.com/freeCodeCamp/freeCodeCamp Star 328640

  

Free Code Camp是一个帮助开发者学习代码社区，由非盈利组织创办的开源项目，用户可通过完成编码调整和构建项目来学习编程，学习编程摆脱枯燥式学习方法，采用闯关式的游戏化学习机制，学完所有的课程可以获得4个证书。

**3****DeepLearning-500-questions**

深度学习500问，以问答形式对常用的概率知识、线性代数、机器学习、深度学习、计算机视觉等热点问题进行阐述，以帮助自己及有需要的读者。全书分为18个章节，50余万字。由于水平有限，书中不妥之处恳请广大读者批评指正。

  

  

**4****tailwind-nextjs-starter-blog**

https://github.com/timlrx/tailwind-nextjs-starter-blog

  

这是Next.js, Tailwind CSS博客入门模板。开箱即用，配备最新技术，让技术写作变得轻而易举。易于配置和定制。完美替代现有的Jekyll和Hugo个人博客。

**6****axios**

https://github.com/axios/axios Star 86819

  

Axios，基于 Promise 的 HTTP 客户端，可以工作于浏览器中，也可以在 node.js 中使用。功能特性如下：

*   从浏览器中创建 XMLHttpRequest
*   从 node.js 中创建 http 请求
*   支持 Promise API
*   拦截请求和响应
*   转换请求和响应数据
*   取消请求
*   自动转换 JSON 数据
*   客户端支持防止 XSRF 攻击
