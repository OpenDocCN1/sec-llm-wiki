### 1.什么是WebLog Expert

Weblog expert是一个快速和强大的访问日志分析器。这会让你了解你的网站的访客：活动统计，访问的文件的路径，通过该网站，信息指页面，搜索引擎，浏览器，操作系统，和更多。该计划所产生的易于阅读的报告，包括文本信息（表）和图表。

官方网站：http://www.weblogexpert.com

### 2.WebLog Expert 的安装

因为是运行在windows平台上的一个程序，安装过程非常简单，不懂的话，一路next 就可以完成软件的安装。

从官网下载一个试用版的，正式版的要花钱哦

http://www.weblogexpert.com/files/WLExpertSetup.exe

### 3.WebLog Expert 的使用

首先，新建一个站点实例

![](../Images/19c6cb55b211bd36cfb0edd2ee5e83b5.png "windows日志分析工具–WebLog Expert")

点击new按钮，打开创建对话框。

Perfile ：填写你网站的名称

Domain ： 输入你的网站的网址

Index ： 分析网站的页面。

Retrieve page tit （检索页面标题）

Lookup DNS names  （查看DNS 名称）

Custom analysis sett （自定义分析设置） 勾选之后，打开自定义分析设置对话框。

其次，指定日志路径，如果是目录下面的所有日志，可以使用\*.log

![](../Images/aedc01d6adc5ca763c013c0ecaecb733.png "windows日志分析工具–WebLog Expert")

 

默认下一步。到后面的一个report，这个是报表存放的路径及文件夹名称

![](../Images/529c4fab00361720b4492e3a4689ec63.png "windows日志分析工具–WebLog Expert")

Destination  ：保存位置。当然是本地，你也可以选择保存FTP 服务器上。

Format  ：生成文件有格式

Folder  ：生成文件的路径

Remove old report files from the specified form  （删除旧报告文件指定的形式）

Create click overlay report  （创建点击覆盖报告）

Custom report conte   （创建图表）

Create charts insted of  （创建图表上下文）

Show generated report  （显示生成的报告）

选择完成

 

![](../Images/eaa218a716f36ed48c519939b9d084ad.png "windows日志分析工具–WebLog Expert")

日志分析中
