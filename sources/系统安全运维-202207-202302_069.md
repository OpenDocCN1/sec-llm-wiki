一、工具介绍xp\_CAPTCHA (白嫖版)，是一款验证码识别工具，是BurpSuite的一款插件，支持验证码返回包为json格式。  
二、安装与使用(需要python3 小于3.7的版本)1、安装 muggle\_ocr 模块（大概400M左右）

*   

```
`python3 -m pip install -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com muggle-ocr`
```
