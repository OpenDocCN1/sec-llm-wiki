# Nginx限制IP访问只允许特定域名访问

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0NjE0NDc5OQ==&mid=2247509484&idx=3&sn=5afaad4f8502a058dcbda67155cf5f93&chksm=c308769cf47fff8a4c541abb5f5e145f501c35315d112b1b35e5dc0b828065640e4539bf7c99&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzk0NjE0NDc5OQ==&mid=2247509484&idx=3&sn=5afaad4f8502a058dcbda67155cf5f93&chksm=c308769cf47fff8a4c541abb5f5e145f501c35315d112b1b35e5dc0b828065640e4539bf7c99&scene=27#wechat_redirect)

> 为了我们的服务器安全，我们需要禁止直接使用 IP 访问我们的服务器，我们可以借助 \[Nginx\]完成

### 1、找到 nginx 的配置文件

```
cd /usr/local
/nginx/conf/
```

> 找到 nginx.conf 文件

![](../Images/9dbf81fe9b0207819404c30e00d3a525.png)

编辑它

### 2、添加新的 server

```
# 禁止ip访问

return

 403;
```

> 注意是在所有的 server 前面添加一个新的 server，如图所示

  

![](../Images/fdeea52136b5b0a02b5afccc7ef906ed.png)

> 这里我们开启了 http 和 https 的监听，如果是直接使用 ip 访问的，我们将会返回 403 状态码给客户端

### 3、修改 server

> nginx.conf 文件中默认配置信息为

```


server {
```

> server\_name 对应的是 localhost，这里我们需要更改成我们指定的域名，如：

```


server {
```

### 4、访问测试

> 重启 nginx

```

./nginx -s reload
```

> 浏览器输入 IP 地址，出现如下

  

![](../Images/bf0a41458b14994b2cafe968769b9077.png)

  

> 说明我们的配置已经成功了

> 我们输入域名试试

  

![](../Images/18f4d7eca72f90a96868de446c85e93a.png)输入域名能够正常访问，说明我们的配置生效，此时就限制了 IP 的访问，只允许特定域名访问了
