> 本文介绍了如何使用 windows10 远程连接虚拟机桌面（已使用远程连接工具连接了虚拟机，如 xshell），亲测可用，不懂的地方欢迎交流！

## 1 安装 epel 库

> 先查看下虚拟机上是否安装 epel 库

```

rpm -qa|grep epel
```

![](../Images/32156d21376743945e344226d06a0d10.png)

> 我已经安装了，如果没有安装，使用下面的命令进行安装

```

yum install epel-release
```

## 2 安装 xrdp

> 执行下面的命令，安装 xrdp

```

yum install xrdp
```

> 会出现一些提示，不需要管是什么，全部输入 y 就行了。安装好的结果如下：

![](../Images/26560a9d00450cc4ecd47f4af9091e23.png)

## 3 安装 tigervnc-server

> 执行下面的命令，安装 tigervnc-server

```

yum install tigervnc-server
```

> 安装成功的结果如下：

![](../Images/d55a8bf577976f7cb430e1f5001b748d.png)

## 4 配置或关闭 SELinux

> 执行下面的命令查看 SELinux 状态

```

/usr/sbin/sestatus -v
```

![](../Images/25708539eb80d362ba54d1b367dddcba.png)

> 执行下面的命令，设置 SELinux 成为 permissive 模式

```

setenforce 0
```

> 然后再查看下 SELinux 状态

![](../Images/e9a2edc6ac0113f48af486aa1cd3af94.png)

## 5 关闭防火墙

> 执行下面的命令关闭 centos8 的防火墙（其他版本的可能不一样）

```

systemctl stop firewalld.service
```

> 然后执行下面的命令，查看下防火窗的状态是否关闭

```

systemctl status firewalld.service
```

![](../Images/12b8fadf2b4e4131c835e7d46245e018.png)

## 6 启动 xrdp 服务，并且设置为开机启动

> 执行下面的命令，启动 xrdp 服务

```

systemctl start xrdp
```

> 可以执行下面的命令，查看 xrdp 是否启动

```

systemctl status xrdp
```

![](../Images/ba157fdd713253875713c546efde8349.png)

> 执行下面的命令，设置 xrdp 开机自启动

```
systemctl enable
 xrdp
```

![](../Images/f760b32769e3fdd6111c152cfae92058.png)

## 7 使用 windows10 连接

> 左下角搜索远程连接

![](../Images/484e41434a6010eb5f8f7b35494d3981.png)

> 打开 Windows 远程连接，输入虚拟机的 ip

![](../Images/2a98b4bf89f29648667120f9e62ec31e.png)

> 在弹出的 xrdp 用户验证界面，输入连接的用户名和密码就可以了

![](../Images/ecd4aa0ced3571420551b10284fd9581.png)
