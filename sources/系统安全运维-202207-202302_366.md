登录后台后发现版本是1.7.0版本是2021年8月份发布的  

![](../Images/36ae9d86bcf75273742f0f56e34d8ff3.png "image-20220221134501729")  
首先查看 后台登录后可以在网站设置里设置允许上传的文件类型，通过修改发现没啥用 :@(不高兴)  
![](../Images/f8dcf628d15f9ea68ecb624c6b967107.png "image-20220221134624374")

改完以后还是无法上传

![](../Images/d60a8c2d450da3789b4c29862d5df516.png "image-20220221135144037")

仔细看存在主题管理和插件管理，渗透wp的思路肯定能getshell

![](../Images/a7a44cb3c2ef7f2b8e74274492999b48.png "image-20220221135416401")

下载z-blog 主题发现文件后缀名为.zba

![](../Images/86338f96518aff355225709a05ff564c.png "image-20220221135820100")

```
` <path></path>中的内容是文件的路径  `
```

getshell 只需要修改<stream></stream>中的内容即可

![](../Images/fba569892f5692865cda404764dbcacb.png "image-20220221140318182")

然后在后台直接上传主题文件即可成功拿到shell

```
`/path/zb_users/theme/demoTheme  //目录`
```

完整路径

```
`http://www.url.com/zb_users/theme/aymFreeFive/template/single.php`
```

![](../Images/51db6be2ff69343c98bcb8419e757edd.png "image-20220221140612714")

**成功getshell**

使用`cat /proc/version`查看linux 版本

![](../Images/a42edc3215783f3b7dd1a4eeb0c15df2.png "image-20220221140854259")

发现是Red Hat 的Linux系统尝试使用CVE-2021-4034进行提权

![](../Images/39ed1cb81b06d833a285e3af49d1d246.png "image-20220221141329092")

*   一把梭提权
    

![](../Images/7afab8a69b5a4e5894184bfe10a17173.png "image-20220221141435776")
