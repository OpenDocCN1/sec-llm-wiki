# 日常渗透(批量刷洞)工具 -- SecurityServiceBox

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0NjE0NDc5OQ==&mid=2247507631&idx=1&sn=e979fd93ccd8bb89692ba39e5a0fb984&chksm=c3080ddff47f84c9910e4e0dbf8c068d8be21f4f6e85095ddee7e98f9d262cb623cb3b2ed287&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzk0NjE0NDc5OQ==&mid=2247507631&idx=1&sn=e979fd93ccd8bb89692ba39e5a0fb984&chksm=c3080ddff47f84c9910e4e0dbf8c068d8be21f4f6e85095ddee7e98f9d262cb623cb3b2ed287&scene=27#wechat_redirect)

一、工具介绍  

一个既可以满足安服仔日常渗透工作也可以批量刷洞的工具盒子。集合了常见的域名收集、目录扫描、ip扫描、指纹扫描、PoC验证等常用工具，方便安服仔快速展开渗透测试。

  

二、运行界面

1、基于Win环境下运行cmd /k 即可新开cmd窗口，除collect\_subdomain之外，其余工具均可无需等待当前命令执行结束直接执行下一条命令。且支持TAB键关键字自动补全。

![](../Images/479d573e69d82aaa33977a40506f5a54.png)

  

2、命令执行结束后，在results文件夹下可查看输出的报告(Finger扫描的结果在tools/collect/finger/output文件夹内)

![](../Images/5bfa5162d44ad544c218ee0a39a85b50.png)
