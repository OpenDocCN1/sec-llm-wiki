## 使用环境

目标机不出网，可以在边界服务器上设置代理就可以访问目标机的整个内网网段。

  

## reGeorg简介

reGeorg是一个内网穿透工具，基于socks5，而且支持众多脚本。因为使用频繁，所以较多的杀软都会拦截，需要做免杀处理。

  

免杀reG下载地址：https://github.com/L-codes/Neo-reGeorg

  

此工具还做了加密，所以很多特征都没有了

  

## 使用方法

#### 一、输入密码生成加密脚本

```
 python3 neoreg.py generate \-k tenet
```

  

![](../Images/09d175bb9c83840930403b23e437be7d.png "image-20210518233516499.png")![](../Images/76f23673803d46c850070e75b4697d7f.png "image-20210518233546583.png")

文件生成的目录

![](../Images/7c987539bb4c4792eb08ce5cc7d028a8.png "image-20210518233644268.png")

#### 二、选择相应的脚本放入边界服务器中

放入WWW目录下，前提是要可以访问到的

![](../Images/ad811656638716275e92ca79310678dd.png "image-20210518234023842.png")

  

可以尝试访问看下，没有出错就说明没有问题

![](../Images/bb9fdeb44266d8bd25934d430358beb8.png "image-20210518234227565.png")

#### 三、Kali内做转发

成功转发，访问自己的1080端口即可

```
python3 neoreg.py \-k tenet \-u http://192.168.137.131/tunnel.php
```

![](../Images/6133eb70ec0cc34e9ff08e110a6b6797.png "image-20210518234442763.png")

打开浏览器设置代理，即可访问10.10.10.132主机的80端口![](../Images/2de5b2538b4426cfd9f4eb0fa7c54275.png "image-20210518235037395.png")![](../Images/700f99c21d8974f115cbbcd2f3ce5981.png "image-20210518235111325.png")

#### 四、proxychains代理使用nmap

```
vim /etc/proxychains.conf
```

  

![](../Images/3ea77466007acdd694df3f76c142c899.png "image-20210518235414212.png")

这里nmap不能用root权限，切换一下普通权限扫描，成功
