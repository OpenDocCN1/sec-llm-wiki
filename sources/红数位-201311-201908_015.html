赛门铁克和诺顿用户慎更新Win7,2008R2补丁，会致机器无法启动

如果使用SHA-2证书对代码进行签名并且计算机安装了Symantec或Norton防病毒软件，则Microsoft阻止安装Windows 7和Windows Server 2008 R2更新。这是因为防病毒软件在安装过程中删除了更新并导致Windows无法启动。

在过去的几个月中，Microsoft一直在更新支持公告，以提醒公司和用户有关SHA-1签名更新的退休以及他们使用SHA-2证书的举措。


作为8月补丁周二更新的一部分，昨天开始，Windows 7 SP1和Windows Server 2008 R2 SP1只会在使用SHA-2代码签名证书签名时安装更新。之所以这样做是因为先前用于签署更新的算法SHA-1由于算法中发现的弱点和高CPU计算的可用性增加而被发现随着时间的推移而不安全。


根据昨天的Windows 7 KB4512506安全月度汇总和 仅KB4512486安全性更新中的说明，SHA-2更改导致Symantec和Norton防病毒软件在安装时删除更新。这可能导致Windows 7和Windows Server 2008 R2无法启动。


“微软和赛门铁克已经确定了一个问题，当设备运行任何赛门铁克或诺顿防病毒程序并安装仅使用SHA-2证书签名的Windows更新时，”微软在KB4512506更新说明中指出。“在安装过程中，防病毒程序会阻止或删除Windows更新，这可能会导致Windows停止工作或无法启动。”


作为安全措施，Microsoft已对这些更新发布了阻止，直到Symantec发布其软件修复程序，以便不删除SHA-2签名更新。赛门铁克在一份公告中表示，此修复程序将在下一版本中发布。


“将发布即将发布的Symantec Endpoint Protection版本，该版本增加了对仅签署SHA-2的更新安装的支持。”


SHA-2迁移尚未结束，因为在2019年9月补丁周二期间，微软将通过要求Windows Server 2012，Windows 8.1，Windows Server 2012 R2仅支持SHA-2签名更新来结束其迁移。


希望该公司下个月做好准备。
