# 中兴,网件,TP-link 4G路由器存漏洞或让攻击者完全控制

安全研究人员在几家公司制造的4G路由器中发现了多个漏洞，这些漏洞使用户面临信息泄露和命令执行攻击。

  

Pen Test Partners研究员'G Richter'  在今年的DEF CON黑客大会上分享了 4G设备的缺陷，称“现有的许多4G调制解调器和路由器都非常不安全。”

  

“我们在各种供应商的设备中发现了严重的可远程利用的缺陷，而无需做太多操作即可达成”里希特说。

![](../Images/4ddf1432329bb27f16107390851c5f27.png)

  

“此外，只有少数原始设备制造商认真对待蜂窝技术，他们的硬件（和软件依赖性）可以在各种各样的地方运行。”

  

最糟糕的是，在检查了一套有限的4G路由器后，发现了安全漏洞，这些路由器覆盖了整个价格范围，从消费级路由器和加密狗到设计用于大型企业网络的非常昂贵的设备。

  

在Pen Test Partners报告发布之前，所有发现的安全漏洞都被报告给了解决了大部分已发现问题的供应商，但不幸的是，披露过程没有像预期的那样顺利。

  

**中兴路由器漏洞**

在研究人员眼中真正脱颖而出的供应商是中兴通讯，他们清除了MF910和MF65 +路由器中发现的漏洞，因为它们影响了报废产品 - 即使在MF910的情况下，它仍然是在该公司的网站上列出，但没有暗示它不受支持（此处提供咨询）。

  

研究人员随后对另一台ZTE路由器MF920进行了测试，该路由器共享相同的代码库，因此几乎完全相同的漏洞。这次，中兴通讯决定修复报告的缺陷，这些缺陷也得到了CVE标识符。

  

在检查MF910和MF65路由器时发现了以下问题，供应商无法修补的问题：

  

•管理员密码可能泄露（预身份验证）。

•其中一个（验证后）调试端点易受命令注入攻击。

•在完全未使用的“测试”页面中还有一个跨站点脚本点。

  

“这些问题可以链接在一起，只允许用户访问恶意网页，从而允许在路由器上执行任意代码，”Richter补充道。有关MF910安全性分析的更多详细信息，请参见此处。

  

另一个检测到的中兴通讯4G路由器中的两个漏洞MF920收到了以下CVE - 供应商发布的咨询报告可在此处获取：

  

• CVE-2019-3411 - 信息泄漏（7.5高严重级CVSS v3.0基本分数）  

• CVE-2019-3412 - 任意命令执行（9.8严重级别CVSS v3.0基本分数） 

  

**Netgear美国网件和TP-LINK 4G路由器中存在安全漏洞**

Pen Test Partners的研究人员还发现了由Netgear和TP-LINK制造的4G路由器的安全问题，其中至少有四个也被分配了CVE。

  

对于Netgear Nighthawk M1 Mobile路由器，跨站点请求伪造旁路（跟踪为  CVE-2019-14526）和后验证命令注入（CVE-2019-14527）可能允许潜在的攻击者执行任意代码如果“用户未在Web界面上设置强密码”，则易受攻击的设备。

  

攻击者可以通过欺骗设备的用户访问恶意制作的页面来轻松利用此漏洞链。研究人员还提供了有关CSRF保护旁路缺陷的更多信息，  以及如何打破Netgear Nighthawk M1的固件加密。

  

TP-LINK的M7350 4G LTE移动无线路由器也被发现易受攻击，这次是针对以下命令注入漏洞，这些漏洞在向供应商披露之后也得到了自己的CVE：

  

• CVE-2019-12103 - 预认证命令执行

• CVE-2019-12104 - 认证后命令执行

  

Pen Test Partners的研究人员补充说：  “随着越来越多的数据，许多带宽要求较低的消费者不可避免地开始使用移动电话进行全职互联网接入。”

  

“那些将要销售5G路由器的制造商目前正在销售3G和4G路由器。有哪些? 我真的不能强调这一点 。”
