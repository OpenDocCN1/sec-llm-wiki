# 美国已占全球 勒索软件攻击的一半以上

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484283&idx=2&sn=87c23fef42c06115cb2bd596f394d670&chksm=cef36ec8f984e7de429d5cdf0dcf1a3d52a3df256c24df02810b92a71c4eba6279b5bce7bec3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484283&idx=2&sn=87c23fef42c06115cb2bd596f394d670&chksm=cef36ec8f984e7de429d5cdf0dcf1a3d52a3df256c24df02810b92a71c4eba6279b5bce7bec3&scene=27#wechat_redirect)

  

**![](../Images/f5f9be74f8cf55b770c0a86b83131d84.png)**

  

一份新报告称，勒索软件的威胁在美国更为普遍，超过一半的全球检测来自这个国家。

  

随着GandCrab离开现场，其他文件加密恶意软件填补了缺口，减少了对消费者的关注，更多地关注企业，增加了获得更大赎金的机会。

  

**转向业务目标**

来自Malwarebytes的统计数据显示，消费者系统的勒索软件检测在过去一年（2018年6月至2019年6月）下降了12％，比上一季度下降了25％。

  

与此相反的是商业环境，自2018年6月以来检测率增加了363％，自2019年第一季度以来增长了14％。

  

![](../Images/aacec00f73db5bc319cd2d993339a08d.png)

据统计，Ryuk目前是企业面临的主要勒索软件威胁。尽管是一个新的入口，但恶意软件位居榜首，领先GandCrab，其运营商宣布 将于6月1日退休。

  

**美国是主要目标**

根据Malwarebytes 针对此类恶意软件的全球检测统计数据，受勒索软件影响最严重的国家是美国。 

  

该公司的遥测数据显示，53％的勒索软件检测来自该国，而其他地区则远远落后。

  

加拿大是该名单中受影响最大的第二大国，仅占Malwarebyte全球勒索软件检测的10％，其次是英国，占9％，证实了大多数勒索软件针对英语国家的理论。

  

![](../Images/e2f0d50e434d81bf22f5240d334eced7.png)

ID Ransomware  服务收集的统计信息绘制了不同的图片，可以根据勒索信息或加密文件识别恶意软件的类型。

  

根据该服务受文件加密威胁影响的最大国家是韩国，其次是美国和巴西。

  

![](../Images/3b76aa4dc886c816aa81af81190a0bf9.png)

  

这些信息涵盖了过去12个月来自世界各地的意见书。

  

进一步打破Malwarebytes的统计数据表明，勒索软件攻击在德克萨斯州和加利福尼亚州最为普遍。 

  

人口在区分目标方面发挥着重要作用，因为消费者是人口较多的州中最常见的受害者，而企业的检测起源于在勤劳地区混合的地区。

  

![](../Images/0f0e2c6a361b60e1fb1db938e80bd844.png)

无论目标类型和受影响的地区如何，勒索软件仍然是企业面临的最大威胁。只要公司继续为恢复数据而付费，这仍然是网络犯罪的良好商业模式，可以激励他们部署新的攻击。

  

此外，由于许多企业在勒索软件攻击后投资升级其安全性，因此财务影响并未停止支付赎金。通过为实时系统设置备份过程并从主网络中隔离副本，可以避免这种情况。

  

![](../Images/8b72b6a927bc002495e7f6d64ee48eff.png)
