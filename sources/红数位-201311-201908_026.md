# 研究人员发现波音787固件中的漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484270&idx=3&sn=c2a130f27c38bd39031212dcae932aa1&chksm=cef36eddf984e7cb308c2adade66fac604ef93695ed6e0f0fa094012057853e04be292606764&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484270&idx=3&sn=c2a130f27c38bd39031212dcae932aa1&chksm=cef36eddf984e7cb308c2adade66fac604ef93695ed6e0f0fa094012057853e04be292606764&scene=27#wechat_redirect)

  

**![](../Images/f5f9be74f8cf55b770c0a86b83131d84.png)**

  

**安全公司IOActive的研究人员发现了他们认为可能在波音787梦想飞机上发生的一系列漏洞和攻击。**

  

去年9月深夜，安全研究员Ruben Santamarta坐在马德里的家庭办公室，参与了一些有创意的谷歌搜索，寻找与他长达数年的痴迷相关的技术文件：飞机的网络安全。他惊讶地发现波音公司网络上一台完全没有保护的服务器，似乎充满了设计用于公司巨型737和787客机的代码，可以公开访问并向任何发现它的人开放。所以他下载了他能看到的一切。

  

![](../Images/7507111ec350a0e631e3e64455621edf.png)

  

现在，差不多一年之后，Santamarta声称泄露的代码使他得到了前所未有的东西：787梦想飞机组件之一的安全漏洞，深入飞机的多层网络。他建议，对于黑客而言，利用这些漏洞可能是飞机机载娱乐系统中多阶段攻击的一个步骤，并扩展到高度保护的安全关键系统，如飞行控制和传感器。

  

波音断然否认这种攻击是可能的，并且它拒绝了他发现可能将其拉下来的主张。桑塔马塔本人承认，他没有足够的飞机图片或者获得价值2.5亿美元的飞机，以证实他的说法。但他和其他航空电子网络安全研究人员对他的研究结果进行了回顾，他认为虽然飞机上最敏感的系统上的全面网络攻击仍远未构成重大威胁，但787规则中发现的缺陷仍然代表着对网络安全的不足关注。波音公司。他们还表示，鉴于保持商用飞机不受黑客攻击的重要性，该公司的回应并未完全令人放心。

  

在今天拉斯维加斯举行的黑帽安全会议上，安全公司IOActive的研究员Santamarta计划展示他的发现，包括787组件代码中的多个严重安全漏洞的详细信息，称为船员信息服务/维护系统。CIS / MS负责维护系统和所谓的电子飞行包，飞行员使用的导航文件和手册等应用。Santamarta说他在CIS / MS中发现了大量的内存损坏漏洞，他声称黑客可以利用这些漏洞作为飞机网络受限制部分的立足点。Santamarta说，攻击者可能会从机上娱乐系统转向CIS / MS，向更敏感的控制飞机的组件发送命令。安全关键系统，包括发动机，制动器和传感器。波音公司坚持认为，787网络架构中的其他安全障碍将使这种进展变得不可能。

  

Santamarta承认，他对787的内部结构没有足够的了解，无法知道这些安全障碍是否可以绕过。但他表示，尽管如此，他的研究仍然是展示实际平面黑客技术可能性的重要一步。“我们没有787进行测试，所以我们无法评估其影响，”Santamarta说。“我们不是说它是世界末日，或者说我们可以坐飞机。但我们可以说：这不应该发生。”

  

**飞行防火墙**

在一份声明中，波音公司表示已调查了IOActive的索赔，并得出结论认为它们并不代表网络攻击的任何真正威胁。“IOActive的情景不会影响任何关键或必要的飞机系统，也不会描述远程攻击者访问航空电子系统等重要787系统的方法，”该公司的声明说。“IOActive仅使用基本工具审查了787网络的一部分，并且无法访问更大的系统或工作环境.IOActive选择忽略我们在其研究中验证的结果和限制，而是做出具有挑衅性的陈述，好像他们可以访问虽然我们感谢独立网络安全研究人员的负责任参与，但我们对IOActive不负责任的演示感到失望。“

  

在与WIRED的后续电话会议中，公司发言人表示，在调查IOActive的索赔时，波音公司竟然将实际的波音787置于“飞行模式”进行测试，然后让其安全工程师试图利用漏洞Santamarta暴露了。他们发现他们无法成功进行攻击。向波音公司提供CIS / MS代码的霍尼韦尔也在向WIRED的一份声明中写道：“经过大量测试，霍尼韦尔及其合作伙伴确定不会对飞行安全构成威胁，因为787的关键系统不会受到影响。”

  

IOActive的攻击声称 - 以及霍尼韦尔和波音的否认 - 都是基于787内部的特定架构。梦想飞机的数字系统分为三个网络：开放数据网络，其中非敏感组件，如机上娱乐系统，隔离数据网络，包括一些更敏感的组件，如IOActive所针对的CIS / MS; 最后是通用数据网络，三者中最敏感的，连接到飞机的航空电子设备和安全系统。Santamarta声称他在CIS / MS中发现的漏洞夹在ODN和CDN之间，提供了从一个到另一个的桥梁。

  

但是波音公司反驳说它在CIS / MS中既有“额外的保护机制”，可以防止其从ODN中被利用，也可以在CIS / MS所在的半敏感IDN之间使用另一个硬件设备，高度敏感的CDN。该公司认为，第二个障碍只允许数据从网络的一部分传递到另一部分，而不是影响飞机关键系统所必需的可执行命令。

  

“尽管我们没有提供有关我们的网络安全措施和保护措施的详细信息，但出于安全考虑，波音公司确信其飞机不会受到网络攻击，”该公司的声明总结道。

  

波音表示，它还与美国联邦航空管理局和国土安全部就Santamarta的袭击事宜进行了磋商。虽然美国国土安全部没有回复评论请求，但美国联邦航空局发言人在给WIRED的一份声明中写道，它“对制造商对该问题的评估感到满意”。

  

**“这是安全101”**

新的软件缺陷声称是在波音公司停飞的737 Max飞机遭遇丑闻的背景下，此后该飞机的错误控制导致两起坠机事件造成346人死亡。与此同时，Santamarta在航空航天业的网络安全措施方面有着自己未解决的分歧。他之前曾攻击过松下航空电子设备的机上娱乐系统。例如，在去年的黑帽大会上，他提出了卫星通信系统中的漏洞，他说这些漏洞可能会被用来攻击一些非敏感的飞机系统。航空工业分享与分析中心在一份新闻稿中回击他的发现是基于“技术错误”。Santamarta反驳说，A-ISAC“正在杀死信使 ”，企图诋毁他而不是解决他的研究。

  

加利福尼亚大学圣迭戈分校的计算机科学教授Stefan Savage表示，即使授予波音公司关于其安全障碍的说法，Santamarta发现的缺陷也足以让他们不被解雇，他目前正在与其他学术研究人员合作在航空电子网络安全测试平台上。萨维奇说：“人们不应该担心漏洞，因为其他保护措施阻止它被利用，这在计算机安全方面有着非常糟糕的历史。” “通常情况下，有烟的地方会发生火灾。”

  

Savage特别指出了Santamarta在嵌入式操作系统VxWorks版本中突出显示的漏洞，在这种情况下，为霍尼韦尔的波音公司定制。Santamarta发现，当应用程序要求写入底层计算机的内存时，定制的操作系统无法正确检查它是否覆盖了内核，这是操作系统中最敏感的核心。结合几个应用程序级错误Santamarta发现，所谓的参数检查权限升级漏洞代表了一个严重的缺陷，Savage认为，由于VxWorks可能在飞机上的许多其他组件中运行可能具有相同的概念而变得更加严重错误。

  

“每一个软件都有漏洞。但这不是我想找到错误的地方。检查用户参数是安全性101，”Savage说。“他们不应该有这些直接的漏洞，特别是在内核中。在这个时代，消费者操作系统不检查用户指针参数是不可想象的，所以我希望飞机也是如此。 “

  

华盛顿大学的另一位学术航空电子网络安全研究员Karl Koscher表示，他发现飞机部件存在严重的安全漏洞，正如Santamarta在CIS / MS报道的那样。“也许波音故意将其视为不受信任，系统的其余部分可以处理不受信任的情况，”Koscher说。“但是说，'没关系，因为进一步降低缓解'并不是一个好的答案。特别是如果某些缓解措施不像你认为的那样强大。“

  

Koscher还指出CIS / MS可以访问电子飞行包，其中包含飞机驾驶员可能通过驾驶舱内的平板电脑参考的文件和导航材料。破坏这些数据可能会导致其自身形式的混乱。“如果你能在驾驶舱内制造混乱和错误信息，那可能会导致一些非常糟糕的结果，”科斯赫指出。（波音公司的一位发言人表示，EFB也不会受到CIS / MS的影响，尽管两者都位于787网络的同一部分。）

  

**大型，飞行的计算机集合**

要明确的是，Savage和Koscher都不相信，根据Santamarta的研究结果，黑客可能会对飞机或其乘客造成任何直接危险。“这距离即将到来的安全威胁还有很长的路要走。基于他们现在所拥有的东西，我认为你可以让IOActive家伙在787上玩得很开心，而且我仍然可以放心使用它，”萨维奇说。“但波音公司有工作要做。”

  

Savage指出，评估IOActive的研究结果是否真正代表了向严重攻击迈出的一步很难，仅仅是因为飞机安全研究的物流不可能。像波音这样的公司有能力全面测试价值25亿美元的飞机的安全性，但也对他们发布的结果产生了深刻的利益冲突。像IOActive的Santamarta这样的独立黑客没有足够的资源来进行那些完整的调查 - 即使是资源丰富的国家黑客或其他愿意在现场机载飞机上进行测试的人也可能。

  

尽管波音公司的否认和保证，Santamarta的研究应该提醒人们，飞机安全远未解决网络安全问题。“这提醒人们，像汽车这样的飞机依赖于日益复杂的网络计算机系统，”萨维奇说。“他们无法摆脱随之而来的漏洞。”
