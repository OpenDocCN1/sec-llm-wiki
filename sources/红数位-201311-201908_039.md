# 大砍刀组织针对拉丁美洲军方间谍活动

拉丁美洲在持续威胁和具有政治动机目标的群体方面经常被忽视。然而，有一个针对备受瞩目的高层组织的网络间谍活动案例已经成功地受到了关注。这些攻击背后的团体窃取了数十亿的机密文件，其中大部分来自军事组织。在本文发布时，它仍然非常活跃，定期对其恶意软件，基础设施和鱼叉式网络钓鱼活动进行更改。

  

ESET一直在跟踪新版本的Machete（该组的基于Python的工具集），该版本于2018年4月首次出现。虽然后门的主要功能与以前的版本保持一致，但它已经在课程中扩展了新功能一年

  

**目标**

从3月底到2019年5月底，ESET研究人员观察到有超过50台受害计算机正在与C＆C服务器进行通信。这相当于每周上传的千兆字节数据。受影响的计算机中有一半以上是委内瑞拉军队，而其他计算机则与教育，警察和外交部门有关。这延伸到拉丁美洲的其他国家，厄瓜多尔军队是另一个以Machete恶意软件为目标的组织。这些国家/地区的恶意软件分布如图1所示。

  

![](../Images/542d80b379a8c5120debaf55b18575b3.png)

图1. 2019年有大砍刀受害者的国家

  

**恶意软件运营商**

Machete的操作员使用有效的鱼叉式钓鱼技术。他们长期的攻击集中在拉丁美洲国家，这让他们多年来收集情报并改进战术。他们知道自己的目标，如何融入常规沟通，以及哪些文件最有价值。Machete不仅可以处理常见的办公套件文档，还可以使用地理信息系统（GIS）软件使用的专用文件类型。该小组对使用军事网格描述导航路线和定位的文件感兴趣。

  

Machete小组直接向其受害者发送非常具体的电子邮件，这些电子邮件从目标更改为目标。这些电子邮件包含运行恶意软件的压缩自解压存档的链接或附件，并打开用作诱饵的文档。

  

图2是在妥协期间向潜在受害者显示的典型PDF文件。为了欺骗毫无防备的目标，大砍刀经营者使用他们以前偷过的真实文件; 图2是分类的军事文件，其日期为2019 年5月21 日，同一天。相关的.zip文件首次发送给目标。ESET已经看到更多这样的案例，其中某一天的被盗文件与恶意软件捆绑在一起，并在同一天被用来诱骗新受害者。

  

![](../Images/1ca4c02db9d54a0abe782deb538aa4e1.png)

图2.其中一个Machete下载器中的诱饵（PDF文件）（模糊）

  

用作诱饵的文件类型是由该组的目标每天合法地发送和接收几次。例如，Radiogramas是用于委内瑞拉军队通信的文件。攻击者利用这一点，以及他们对军事行话和礼节的了解，制作出非常有说服力的网络钓鱼电子邮件。

  

**主要特征**

Machete集团非常活跃，自2018年4月发布新版本以来，已对其恶意软件进行了多项更改。之前的版本由卡巴斯基于2014年和Cylance于2017年描述。在图3中，我们展示了新版Machete恶意软件的组件。

  

![](../Images/15515403707d9af119540a450dc23b6d.png)

图3.大砍刀的组件

  

攻击的第一部分包括一个下载器，它是一个自解压存档，由7z SFX Builder制作。一旦归档文件被自解压代码解压缩，提取器就会打开一个PDF或Microsoft Office文件作为诱饵，然后从归档文件中运行下载程序可执行文件。该可执行文件是另一个自解压文件，包含实际的下载二进制文件（py2exe组件）和配置文件，下载程序的目标URL作为加密字符串。

  

我们看到的所有下载网址都位于Dropbox或Google文档中。这些URL上的文件都是自解压（RAR SFX）存档，包含加密配置和py2exe后门组件。然而，自2019年5月以来，Machete运营商停止使用下载程序并开始在同一档案中包含诱饵文件和后门组件。

  

可以对py2exe二进制文件进行反编译以获取Python代码。所有组件 - 下载程序和后门程序 - 都使用pyobfuscate进行模糊处理。这也已用于以前版本的恶意软件中。图4显示了这些混淆脚本之一的一部分。

  

![](../Images/26224e986c337bc43b0a3a019a089dcc.png)

图4.使用pyobfuscate进行模糊处理的脚本

  

自2018年8月以来，Machete组件已经交付了一层额外的混淆。这些脚本现在包含ZLIB压缩，base64编码文本块，其中，在被解码，产生一个脚本像在图4的模糊处理该第一层使用产生pyminifier与-gzip参数。

  

**后门组件**

Machete的dropper是RAR SFX可执行文件。删除了三个py2exe组件：GoogleCrash.exe，Chrome.exe和GoogleUpdate.exe。删除单个配置文件jer.dll，它包含与AES加密字符串对应的base64编码文本。总结组件的模式如图5所示。

  

![](../Images/3256ddc6668d89bcb662b1ed1f78c14e.png)

图5. Machete的后门py2exe组件

  

GoogleCrash.exe是恶意软件的主要组件。它计划执行其他两个组件并创建Windows任务计划程序任务以实现持久性。

  

该的chrome.exe组件负责从受害计算机数据的收集。它可以：

  

*   截图
    
*   记录击键
    
*   访问剪贴板
    
*   AES加密和exfiltrate文件
    
*   检测新插入的驱动器并复制文件
    
*   执行从C＆C服务器下载的其他二进制文件
    
*   从系统中检索特定文件
    
*   从多个浏览器中检索用户配置文件数据
    
*   收集受害者的地理位置和附近Wi-Fi网络的信息
    
*   对可移动驱动器执行物理渗透
    

  

Machete操作员有兴趣从他们的目标中获取特定的文件类型。除Microsoft Office文档外，还会搜索驱动器

  

*   备份文件
    
*   数据库文件
    
*   加密密钥（PGP）
    
*   OpenOffice文档
    
*   矢量图像
    
*   地理信息系统的文件（地形图，导航路线等）
    

关于受害者的地理位置，Chrome.exe会收集有关附近Wi-Fi网络的数据，并将其发送到Mozilla位置服务API。简而言之，该应用程序在提供其他数据源（如蓝牙信标，手机信号塔或Wi-Fi接入点）时提供地理定位坐标。然后恶意软件采用纬度和经度坐标来构建Google Maps URL。部分代码如图6所示。

  

![](../Images/f998c763231fc4d0959c01154aebad5a.png)

图6.地理定位代码

  

使用Mozilla定位服务的优势在于它允许在没有实际GPS的情况下进行地理定位，并且可以比其他方法更准确。例如，IP地址可用于获取大致位置，但不是那么准确。另一方面，如果该区域有可用数据，Mozilla位置服务可以提供诸如目标所在的建筑物之类的信息。

  

的有GoogleUpdate.exe组件负责与远程C＆C服务器进行通信。从jer.dll文件中读取设置连接的配置：域名，用户名和密码。Machete的主要通信方式是通过FTP，尽管HTTP通信是在2019年作为后备实现的。

  

此组件将加密文件上载到C＆C服务器上的不同子目录，但它还检索由Machete操作员放在服务器上的特定文件。这样，恶意软件可以更新其配置，恶意二进制文件和文件列表，但也可以下载和执行其他二进制文件。

  

**结论**

即使在研究人员发布了针对此恶意软件的技术描述和妥协指标之后，Machete集团的运营也比以往任何时候都更加强劲。ESET几个月来一直在跟踪这种威胁，并且观察到了一些变化，有时甚至在几周之内。

  

在本出版物发布时，最新的更改引入了六个后门组件，这些组件不再是py2exe可执行文件。用于恶意组件的Python脚本，Python 2.7的原始可执行文件以及所有使用的库都打包到一个自解压文件中。

  

我们在Machete的代码和底层基础设施中看到的各种工件让我们认为这是一个讲西班牙语的团体。当存在对受感染计算机的物理访问时，存在将数据泄露到可移动驱动器的代码可能表明Machete运营商可以在其中一个目标国家/地区存在，尽管我们无法确定。
