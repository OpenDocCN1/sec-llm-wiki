# 谷歌浏览器76再次在地址栏中隐藏WWW和HTTPS：//

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484198&idx=3&sn=caa3f8afccc7bfdd6a1fe1bb24148e9b&chksm=cef36e95f984e7831208d6a902e0eec0b56f31d68ddff9fab1428284f28203657c1492ad41db&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484198&idx=3&sn=caa3f8afccc7bfdd6a1fe1bb24148e9b&chksm=cef36e95f984e7831208d6a902e0eec0b56f31d68ddff9fab1428284f28203657c1492ad41db&scene=27#wechat_redirect)

安装Google Chrome 76后，如果您觉得地址栏中缺少某些内容，那么您就是正确的。这是因为Google决定再次隐藏或删除地址中的“www”子域名和“https：//”。

  

![](../Images/997c0f3d5f15469771938896b1a45fee.png)

当Chrome 69于2018年9月发布时，Google决定 从地址栏中的网址中删除“www”和“m”“琐碎的子域名”。例如，当用户访问www.reddigit.cn时，www将被剥离并显示为reddigit.cn。

  

这些子域名被归类为“微不足道”，因为Google认为这不是大多数人需要关注的信息。

  

在用户大声喊叫www.reddigit.cn和m.reddigit.cn与www.reddigit.cn不同的主机名之后，Google停止隐藏这些子域名。

  

不过谷歌确实表示，他们将在以后再次隐藏“www”子域名，但会继续使用“m”子域名。

  

WWW后时代已经到来

借助Chrome 76，Google再次开始从地址栏中显示的网址中删除“www”子域名和“https：//”标识符。

  

在关于此问题的Chrome漏洞帖子中，产品经理Emily Schechter 表示，在Canary，Dev和Beta渠道中测试了几个月之后，他们将开始在Chrome omnibox中隐藏“https”和“www” 76在桌面和Android上。

  

“Chrome团队重视UI表面的简单性，可用性和安全性。为了使网址更易于阅读和理解，并消除可注册域名的干扰，我们将隐藏与大多数Chrome用户无关的网址组件。我们计划隐藏“桌面上的Chrome omnibox”和“M76中的Android”中的“https”方案和特殊情况子域“www”。“

如何在Chrome中显示www和https

对于不希望Chrome隐藏“www”或“https：//”的用户，您有两种选择。第一个也是最好的方法是禁用

  

方法1：禁用 chrome：// flags / #omnibox-ui-hide-steady-state-url-scheme-and-subdomains flag

要禁用删除简单的子域，您可以按照以下步骤操作：

  

打开Chrome浏览器， 在地址栏中输入 chrome：// flags / #omnibox-ui-hide-steady-state-url-scheme-and-subdomains。然后按 Enter键。

Chrome将打开一个页面，显示“Omnibox UI隐藏Steay-State URL Scheme和Trivial Subdomains”设置。将此设置更改为 已禁用 ./li>

然后，浏览器将显示一个提示，您需要重新启动浏览器才能使设置生效。单击“ 立即重新启动 ”按钮，浏览器将重新启动。

Chrome旗帜

![](../Images/16de28fa11ffd1da39313d6730263f9a.png)

重新启动浏览器后，www和https：//将再次显示地址栏。

  

方法2：安装可疑站点报表扩展

Schechter表示您可以安装Google的Chrome 可疑站点报告扩展程序，Chrome将停止使用www和https。

  

此扩展程序允许用户报告包含在Google SafeBrowsing中的恶意，诈骗和网上诱骗网站。

  

Microsoft Edge开发人员Eric Lawrence的推文显示了Chromium中的代码，该代码在安装扩展时禁用了删除功能。
