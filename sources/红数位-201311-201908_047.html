新TrickBot木马专门瞄准微软Windows Defender

新版本的TrickBot银行木马继续发展目标安全软件，以防止其被发现和删除。在这个新版本中，TrickBot将目光瞄准了Windows Defender，对于许多人来说，这是Windows 10计算机上唯一安装的防病毒软件。



TrickBot是一种银行木马，试图窃取您的PC和浏览器上保存的在线银行凭证，加密货币钱包，浏览器信息和其他凭据。


当TrickBot执行时，它首先启动一个加载程序，通过禁用与安全软件相关的Windows服务和进程并执行提升来获得更高的系统权限，从而使系统准备就绪。完成后，它将通过注入DLL加载“核心”组件，然后下载用于从计算机窃取信息的模块，包含通信层，并执行其他任务。


在此版本之前，TrickBot加载程序将通过执行以下步骤执行Windows Defender的基本定位，很快称为Microsoft Defender：


  • 禁用然后删除WinDefend服务。

  • 终止  MsMpEng.exe，MSASCuiL.exe和  MSASCui.exe进程。

  • 添加  DisableAntiSpyware  Windows策略并将其设置为true以禁用Windows Defender和可能的其他软件。

  • 禁用Windows安全通知。

  • 禁用Windows Defender实时保护。

因为这还不够，在安全研究人员MalwareHunterTeam  和Vitali Kremez发现的一个新的TrickBot示例中，对其进行了逆向工程，可以看出该特洛伊木马已经进一步尝试禁用Windows Defender。


如下所示，TrickBot现在添加了12种其他方法来定位和禁用Windows中的Windows Defender和Microsoft Defender APT，如下所示。这些方法使用注册表设置或Set-Mp Preference PowerShell命令来设置Windows Defender首选项。


增强的Windows Defender定位


这些新方法执行以下步骤，如果启用，大多数（如果不是全部）将被TamperProtection阻止：


为以下内容添加策略到SOFTWARE \ Policies \ Microsoft \ Windows Defender \ Real-Time Protection：

  • DisableBehaviorMonitoring：  禁用Windows Defender中的行为监控。

  • DisableOnAccessProtection：  打开程序或文件时禁用扫描。

  • DisableScanOnRealtimeEnable：  禁用进程扫描。

  • 通过PowerShell配置以下Windows Defender首选项：

  • -DisableRealtimeMonitoring：  禁用实时扫描。

  • -DisableBehaviorMonitoring：  与上面相同，但作为Windows Defender首选项除外。

  • -DisableBlockAtFirstSeen：  禁用Defender的云保护功能。

  • -DisableIOAVProtection：  禁用对下载的文件和附件的扫描。

  • -DisablePrivacyMode：  禁用隐私模式，以便所有用户都可以查看威胁历史记录。

  • -DisableIntrusionPreventionSystem：  禁用已知漏洞利用的网络保护。

  • -DisableScriptScanning：   禁用脚本扫描。

  • -SevereThreatDefaultAction：  将值设置为6，这将关闭严重威胁的自动修复。

  • -LowThreatDefaultAction：将值设置为6，这将关闭低威胁的自动修复。

  • -ModerateThreatDefaultAction：将值设置为6，这将关闭适度威胁的自动修复。

当TrickBot检测到安装了某些安全程序时，它将使用映像文件执行选项注册表项为该进程配置调试程序  。这会导致调试器在执行的程序之前启动，如果该调试器不存在，则预期的程序将无法启动。


虽然与Windows Defender无关，但在此版本中，用作调试器的进程名称已更改为“kakugulykau”，这将导致程序无法启动。


配置了IFEO调试器的程序是：


  • MBAMService

  • SAVService

  • SavService.exe

  • ALMon.exe

  • SophosFS.exe

  • ALsvc.exe

  • Clean.exe

  • SAVAdminService.exe

  • SavService.exe

  • ALMon.exe

正如您所看到的，TrickBot的开发人员一直在监控新的技巧和方法，以绕过安全性并让研究人员保持警惕，我们应该期待看到这种行为继续下去。

Windows Defender现在正式更名为Microsoft Defender，以表明它现在是跨平台产品系列的一部分。这包括为多个OS平台提供解决方案的企业产品。


从历史上看，微软的消费者防病毒产品被称为Windows Defender。随着他们的企业安全产品发布，称为Microsoft Defender Advanced Threat Protection（ATP）和Microsoft Defender ATP for Macs，微软决定以此系列名称重新命名Windows版本。
