# Microsoft 365全球范围遇到登陆问题 Outlook服务器临时关闭

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484178&idx=2&sn=dcf5209a43ac48b199c842b1b27069ae&chksm=cef36ea1f984e7b7f70f513cef66a5dd8b4a3c666397cd452fdb0956cf8384f9ef64afbca6a6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484178&idx=2&sn=dcf5209a43ac48b199c842b1b27069ae&chksm=cef36ea1f984e7b7f70f513cef66a5dd8b4a3c666397cd452fdb0956cf8384f9ef64afbca6a6&scene=27#wechat_redirect)

![](../Images/f5f9be74f8cf55b770c0a86b83131d84.png)

  

Microsoft 365客户在全球范围内遇到问题，用户在尝试登录Outlook，OneNote和OneDrive帐户时会遇到登录失败和重复凭据提示。

  

![](../Images/cc0139940ea76331c18bf1a20d020a1c.png)

  

“我们正在调查一些用户可能无法访问Outlook和OneNote的问题。其他信息可以在管理中心的OC186848和OL186847或http://status.office.com上找到 ，”发布的消息说通过Microsoft 365状态 Twitter帐户。

  

在过去的一小时内，用户报告也在Twitter上涌现，其中许多人说他们已经从他们的帐户中退出，并显示“MSPError = -805308370”错误以及使用正确的URL登录的请求。

  

![](../Images/6011e680588015a03822b58ed3b76de7.png)

Outlook登录错误

  

官方Microsoft 365服务运行状况页面还表示用户“可能无法访问Outlook和OneDrive服务或功能”，“网络基础架构的降级部分”是客户遇到的问题的背后。  

  

Microsoft 365的团队目前正在通过“重新路由流量以减轻影响”来解决影响Outlook，OneNote和OneDrive用户的问题。

  

![](../Images/ace7f1b2246c1c24a73d2b98b330e84d.png)

停电地图 

 

 Microsoft 365服务健康状态现在说：

我们改变了流量，我们的遥测表明该服务已基本恢复; 但是，某些用户可能仍会受到影响。我们正在执行目标组件重新启动以完全解决问题。 

  

更新18:53 EDT：Microsoft 365服务运行状况页面和Microsoft 365状态Twitter帐户表明Outlook，OneNote和OneDrive问题已得到缓解：

  

![](../Images/f603afa884883b116f7cb2575f508a13.png)

Outlook问题得到缓解
