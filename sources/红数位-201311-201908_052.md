# 紧急：超20亿关键基建设备VxWorks系统发现严重缺陷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484155&idx=2&sn=32d7650573b2ee8bd94635f262ede61a&chksm=cef36f48f984e65e30bba66fe149b5bc69847b07d561dba2d9494a308592efdc1e3dd406711f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484155&idx=2&sn=32d7650573b2ee8bd94635f262ede61a&chksm=cef36f48f984e65e30bba66fe149b5bc69847b07d561dba2d9494a308592efdc1e3dd406711f&scene=27#wechat_redirect)

![](../Images/f5f9be74f8cf55b770c0a86b83131d84.png)

  

在过去的13年中，在用于为关键任务嵌入式设备供电的VxWorks实时操作系统（RTOS）中，已经出现了近十二个严重的漏洞。

  

![](../Images/57dafe5e44347dc7f5922f1d2655ac55.png)

VxWorks由Wind River构建和维护，旨在满足关键基础架构中的计算需求，其中数据处理中的低延迟是绝对必需的。

  

据Wind River称，超过20亿的嵌入式系统依赖于其RTOS操作系统，并受到来自各个行业领域的顶级组织的信任：国防，安全，航空航天，机器人，工程，工业自动化，甚至太阳系探索（NASA）喷气推进实验室）。

  

VxWorks用于关键系统

诸如SCADA，电梯和工业控制器，病人监护仪和MRI机器，防火墙，路由器，卫星调制解调器，VOIP电话和打印机等系统可能会受到影响。

  

利用这些故障的对手可以接管受影响的设备，而无需用户进行任何交互。更令人担忧的是，防火墙和NAT系统等网络级安全解决方案无法阻止攻击。这是因为在攻击期间发送的数据包看起来像非威胁性的网络通信。

  

下面的视频演示了研究人员如何能够接管SonicWall防火墙。根据Armis对Shodan所做的搜索，有超过800,000可通过互联网访问。

  

![](../Images/4b539218b37edee044106e59904b0499.png)

SonicWall承认，其SonicOS软件版本为其某些物理安全设备提供动力，其代码中存在漏洞，可用于远程管理。该公司告诉BleepingComputer，它没有发现这些缺陷在野外被利用的证据。补丁 自7月19日起可用，该公司建议客户和最终用户应用更新。

  

因此，研究人员表示，这些故障可能与EternalBlue和WannaCry攻击类似，后者允许恶意软件在整个公司的全球网络中传播。

  

Armis实验室的研究团队发现了11个影响IPnet不同部分的漏洞，即VxWorks中的TCP / IP堆栈。研究人员将该系列称为“URGENT / 11”，其中一些错误会影响不同版本的操作系统，最早的版本是2006年发布的6.5版本。

  

![](../Images/82fb0aa2e7ae97b4ad7f937ee2f09d59.png)

可利用其中六个URGENT / 11错误来实现远程代码执行（RCE） - 其中至少有一个会影响从6.5开始的操作系统的每个版本，而其他版本可能导致拒绝服务，信息泄漏或归类为逻辑缺陷。

  

值得注意的是，Armis发现的漏洞不会影响为认证而设计的产品版本 - 特定行业使用的VxWorks 653和VxWorks Cert Edition，包括运输。

  

VxWorks是封闭源代码，因此评估漏洞并不容易。在今天发表的一份白皮书中，Armis解释说，其研究人员下载了过时的源代码和逆向工程的真实最终用户产品，以获得更新的二进制文件。

  

Armis说，当二进制文件是带有调试符号的ELF文件时，很容易分析旧版本的源代码。

  

攻击场景

根据研究人员的说法，有三种攻击途径，取决于网络上易受攻击设备的位置和对手的位置。

  

“攻击者可以使用URGENT / 11来控制位于网络周边或其中的设备。即使是远程登陆互联网的设备也可能受到攻击并被接管。” - 阿米斯

  

该公司在一篇博客文章中指出，如果攻击者在网络内部，那些错误集合可以帮助他们定位特定设备，“甚至可以广播能够同时接管网络中所有受影响的VxWorks设备的攻击” 。

  

攻击者可以将网络边缘的安全设备作为目标，这些设备会暴露在互联网上并控制它们。目标的一个示例是运行易受攻击的VxWorks版本的SonicWall防火墙。

  

![](../Images/bfe21f38618adecb801d4a6538fb4377.png)

URGENT / 11可用于另一种网络外攻击场景，以绕过保护本地设备的安全解决方案的安全性。Armis的研究人员表示，这些漏洞的低级性质使得攻击无法被安全解决方案所发现。

  

![](../Images/4e08164b92c3a834992c9682847f2000.png)

Armis想象的第三种攻击场景是威胁行为者已经进入网络的地方。在这种情况下，他们可以通过在整个网络中发送恶意TCP数据包，使用URGENT / 11同时破坏所有受影响的设备而无需用户交互。

缓解选项和修补

Armis负责任地告知Wind River，开发人员努力消除其产品中的故障，并提供更安全的VxWorks RTOS版本。

  

客户已收到安全漏洞的通知，并被指示采取缓解措施或安装最新补丁。

  

Wind River解释说IPnet“网络堆栈是某些版本的VxWorks的组件，包括寿命终止（EOL）版本的6.5。” URGENT / 11漏洞影响运行旧版VxWorks的嵌入式设备。

  

“最新版本的VxWorks 不受漏洞的影响，Wind River的安全关键产品也不是专为认证而设计的，例如VxWorks 653和VxWorks Cert Edition，”开发人员说。

  

“受影响的人构成了我们客户群的一小部分，主要包括位于面向互联网的组织网络周边的企业设备，如调制解调器，路由器和打印机，以及一些工业和医疗设备。组织部署使用VxWorks的设备应立即修补受影响的设备。“ - 风河

  

如果在可预见的将来无法修补或安装最新的VxWorks，客户可以依赖入侵检测系统（IDS）的规则来识别开发尝试。
