微软傻大个发声 近期Windows 10累积更新可能会破坏部分PC

原文：http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484129&idx=4&sn=67bbb55e690080a68e0ff8335da0d7e1&chksm=cef36f52f984e644dd628f18390eaf04cd12d92823ecc3575edb29f862ee3297b710fbf979e3&scene=27#wechat_redirect


Microsoft已承认Windows 10的一些最新累积更新中存在错误，表明安装这些补丁可能会导致使用MIT Kerberos实时连接到域的设备无法启动或继续重新启动。


该公司解释说，此错误会影响安装了最新累积更新的大多数Windows 10版本，包括2019年5月更新。


受影响的平台（客户端和服务器）如下：


Windows 10版本1903

Windows 10版本1809

Windows 10企业版LTSC 2019

Windows 10版本1803

Windows 10版本1709

Windows 10版本1703

Windows 10 Enterprise LTSC 2016

Windows 10版本1607

Windows Server版本1903

Windows Server版本1809

Windows Server 2019

Windows Server版本1803

Windows Server版本1709

Windows Server 2016

“连接到配置为使用MIT Kerberos域的域的设备可能无法启动或在安装[累积更新号]后可能继续重新启动。作为域控制器或域成员的设备都受到影响，“Microsoft解释道。


如果您不确定设备上是否存在该错误，可以使用注册表编辑器检查计算机上是否存在以下注册表项：


HKLM\Software\Microsoft\Windows\CurrentVersion\Policies\System\Kerberos\MitRealms

Microsoft表示您还应该在GPE中的以下路径中查找名为“定义可互操作的Kerberos v5领域设置”的策略：


Computer Configuration -> Policies -> Administrative Templates > System -> Kerberos

该问题已在以下累积更新中确认存在：


Windows 10版本1903：OS Build 18362.145，May 29,2019- KB4497935

Windows 10版本1809：OS Build 17763.652，2019年7月22日 - KB4505658

Windows 10版本1803：OS Build 17134.915，2019年7月16日 - KB4507466

Windows 10版本1709：OS Build 16299.1296，July 19,2019- KB4507465

Windows 10版本1703：OS Build 15063.1955，2019年7月16日 - KB4507467

Windows 10版本1607：OS Build 14393.3115，2019年7月16日 - KB4507459


Microsoft建议用户在错误影响其生产力时避免安装这些累积更新，并表示预计会在8月中旬进行修复。
