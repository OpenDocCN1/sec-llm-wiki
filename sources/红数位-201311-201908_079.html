Firefox将所有HTTP站点标记为“不安全”

Firefox将很快标记仍然使用HTTP而非HTTPS连接的任何网站，因为在浏览器的地址栏中不安全。


最新的Let's加密统计数据显示，Firefox中所有页面加载的78％以上使用HTTPS，与2018年7月相比增加了约6％。所有连接中只有不到22％，这些将被Firefox标记为不安全一旦Firefox 70于2019年10月推出。


当Mozilla，尤其是谷歌等公司开始竞选采用HTTPS时，开始认真地将HTTPS作为网络上的默认设置。如果连接在2018年使用HTTP，Google开始在Chrome中显示非安全指示器，Mozilla Firefox用户可以在浏览器的配置中翻转某些交换机，以便在2018年实现相同的效果。


这些配置标志存在于Firefox的稳定版本中，Firefox用户可能会在稳定版本的浏览器中更改其状态以立即获得非安全指示器。所需要的只是在about：config上将security.insecure_connection_icon.enabled和security.insecure_connection_icon.pbmode.enabled设置为True，以在Firefox地址栏中显示正常和私人浏览连接的非安全指示符。


如果HTTP页面具有登录表单，则Mozilla在2016年未向Firefox添加安全指示器，因为这意味着敏感信息（例如用户密码）以明文形式传输。默认情况下，Firefox 70 Stable会将任何HTTP站点连接显示为“不安全”。Firefox Nightly用户，浏览器目前已经是70版，当他们连接到使用HTTP进行连接的网站时，已经看到了这一点。


三年前，Mozilla开始研究这个功能。Meta Bug 1310842强调了该组织“显示HTTP的负面指标而无HTTPS指示”的意图。目前仍在进行讨论。


Firefox 70将于2019年10月23日根据时间表发布到发布频道。


结束语

HTTPS的采用率仍在上升，并将在未来几年内实现。浏览器中不安全的指标甚至更多，而Firefox显示“不安全”的标签不会像Chrome那样具有如此重大的影响，并且由于其在市场上的份额，它仍然会有所贡献。

CCleaner被Avast强制捆绑浏览器 - 还不怎么好用


自 Avast 在 2017 年接管 CCleaner 开发商 Piriform 以来，这款流行的系统清理工具的粉丝们已经经历了一场漫长的噩梦，比如恶意软件、捆绑软件、以及弹出广告。或许是觉得招牌砸得还不够响，Avast 甚至让 CCleaner 开始窥探用户，甚至无法退出该软件，导致外媒纷纷警告用户不要安装最新版本的 CCleaner 。没想到的是，在平息了上一次风波之后，不老实的 Avast 再次打起了 CCleaner 的主意。



如上图所示，如果你在 CCleaner 时无脑“下一步”，很可能被捆绑安装一个并不需要的、有缺陷的网页浏览器、以及更改的文件名。


最近事情已经平息了，但是使用最新版本的CCleaner似乎Avast再次出现了旧的技巧，这次捆绑了一个不需要的、有缺陷的网页浏览器。


此前，Avast 经常将自家软件与 CCleaner 捆绑到一起，导致不够细心的用户误入“全家桶”，即便他们最初只是想要单纯地装一款系统清理工具。


至于本文提到的这款浏览器，其名为 CCleaner Browser，基于开源的 Chromium 项目改造，目前仍处于 bug 较多的预览阶段。（官方声称‘已修复了一些小问题’）


然而 Techdows 指出，Avast 根本就没做好正式发布的准备，就匆匆上马了 CCleaner 浏览器的推广。更令人无语的是，它不仅要成为用户的默认浏览器，还会接管某些文件扩展名。


对于有经验的网民来说，默认打钩的复选框，还是相对比较容易被发现并取消的。但是粗心的人们并不在少数，这也是此类软件长期以来的如意算盘 —— 打你个措手不及。


据悉，该浏览器会接管用户的 PDF 文件，将类型更改为 CCleaner HTML Document，并设置默认通过网页的形式打开 PDF 。


此外，该浏览器还会组织某些已安装的软件的正常工作，导致用户在 Piriform 论坛上怨声载道。如此毁口碑的捆绑操作，似乎是从 5.59 版本开始的，并在近期发布的 5.60 版本上卷土重来。


外媒 BetaNews 在检验时发现，或许是遭到了大量的投诉，Avast 当前已经取消了浏览器捆绑。当然还有一种可能，那就是 Avast 仅在部分地区实施了强推 CCleaner 浏览器的政策。


如果你不小心安装了不需要的软件，还请移步至“控制面板 -> 添加/删除程序”进行卸载。


F-Secure开发平台让用户轻松找到各大科技公司收集的数据


据外媒报道，在现在这个时代当希望在网上得到的东西是免费的同时人们也必须要付出一定的代价，那就是自己的隐私。社交媒体显然就是个人数据收集者，但看起来它做的还远不止此。而这正是F-Secure希望能传达给网友的。


据悉，其最新开发的Data Discovery Portal就是为了向用户展示其在使用一些最受欢迎的免费网络服务的真实成本，其中涵盖了亚马逊、苹果、Facebook、谷歌、Snapchat和Twitter。


为了让用户们关注个人隐私这件事变得更加容易，于是F-Secure开发了Data Discovery Portal。虽然所有大型科技公司都让用户知道他们收集了哪些数据，但看起来他们对此的宣布做得并不好，很多时候人们并不知道应该去哪里找这些东西。数据发现门户就解决了这个难题。


F-Secure表示，它提供这一工具是公司日益关注身份保护的一部分工作。身份保护可以在数据泄露之前、期间和之后保护到消费者。

荷兰警察逮捕Nab宏恶意软件嫌疑人


荷兰警方逮捕了一名涉嫌开发和销售工具包的男子，该工具包旨在制造用于攻击的恶意Office文件。

在周三的一份声明中，该国的高科技犯罪团队（THTC）透露，在迈克菲的帮助下监控了他参与黑客论坛后，已经逮捕了一名20岁的乌得勒支男子。


他怀疑销售专门的现成工具包，例如Rubella Macro Builder，它通过使用混淆的宏代码来提供恶意负载，绕过传统的安全过滤器，从而有效地武器化Office文档。


然而，在一名男子涉嫌黑客论坛的帖子中，调查人员发现使用荷兰语版本的Microsoft Word。鉴于全球人口相对较少，迈克菲的研究人员继续寻找更多线索。


“在我们的研究过程中，我们能够在多年的时间跨度内链接演员在多个论坛上使用的不同昵称，”该供应商在博客文章中说。“将这一切拼凑在一起，Rubella展示了一个有抱负的网络犯罪分子的经典增长模式，首先是通过低开销的初学者论坛获得技术安全知识，并逐渐转移到一些更大的独家论坛来提供产品和服务。”


在被捕时，嫌疑人被发现有关于梳理的数十张信用卡和手册的数据，以及数千个网站的访问凭证。


“犯罪嫌疑人已经收集了约数额。比特币等加密货币20,000欧元。这些都被查封了。对年轻人可能（非法）赚取的额外金额的调查将继续进行。警察声明指出，将在适当时候发布没收令。


“检察官同时决定嫌疑人将面临审判。尚未确定法庭日期。“



香港malvertiser被指责入侵微软应用程序的恶意广告


一名嫌疑人在香港被认为是过去几个月内侵入微软应用程序和服务的恶意广告浪潮背后的罪魁祸首。


根据专门跟踪恶意广告活动的网络安全公司Confiant 本周与外媒分享的一项调查，嫌疑人被认为是一名香港男子，至少经营两家名为Fiber-Ads和Clockfollow的前线公司。


Confiant表示，嫌疑人使用这两家公司在广告中放置合法的广告网络。隐藏在广告中的恶意代码劫持了查看广告的用户，并将其重定向到其他网站。


然后，嫌疑人在MyMediaAds（一个在线广告商平台）上使用一个帐户，将被劫持的流量出售给其他威胁演员，将用户从合法的应用程序和网站重定向到推送虚假防病毒应用程序，Flash更新，技术支持网站和其他诈骗的网站。


乌克兰逮捕了一直被美国寻找的黑客


乌克兰逮捕了一名据称是美国多年来一直寻求的主要电脑黑客。


乌克兰国家安全部门负责人Ivan Bakanov周二表示，Mykhailo Rytikov在敖德萨市被逮捕，该行动是在与英国和美国的协调下进行的。


巴卡诺夫表示，该行动发现了一个拥有约150台服务器的数据中心，对该设备的研究表明，有些设备是在“俄罗斯特殊服务的控制和覆盖范围内”运营的。莫斯科没有评论这一指控。


Rytikov是乌克兰国民，于2013年在美国被指控经营一家复杂的黑客组织，该组织窃取了至少1.6亿信用卡和借记卡号码。但华盛顿和乌克兰没有引渡条约。


StrongPity APT返回带有延迟间谍软件

该组织正在使用恶意版本的WinRAR和其他合法软件包来感染目标，可能是通过水坑攻击。


据研究人员称，该综合恶意软件名为StrongPity（又名Promethium）背后的APT小组已经开展了一项新的间谍软件活动，该活动截至2019年7月仍在进行。该小组已经重新调整了新的恶意软件以控制受感染的机器。


根据AT＆T的分析，“ 新的恶意软件样本[首次在7月初确定]已经未报告，并且通常似乎已经根据2018年第四季度的公开报告重建工具集后创建并部署到目标。” Alien Labs部门于周三发布并与Threatpost分享。“根据编制时间，基础设施建设和使用以及样本的公开分发，我们评估该活动在本报告中继续成功运作。”


根据该研究，改进后的恶意软件现在面向位于土耳其的用户，类似于该集团的标志性StrongPity / Prometheus代码，具有完整的间谍软件功能。它构建用于定位敏感文档，同时为远程访问建立持久后门。


“除了完整的主机细节之外，间谍软件还会在受害主机上寻找文件文件类型，”AT＆T Alien Labs的安全研究员Tom Hegel告诉Threatpost。“虽然这份报告并非完全独特，但这是一个有趣的趋势，因为它有助于指导攻击者收集/窃取受害者数据的潜在利益。此外，恶意软件通过SSL完全通信，因此网络层的检测可能会给维护者带来挑战。“


据研究显示，作为最初的感染媒介，StrongPity正在部署WinBox路由器管理软件的恶意版本，WinRAR免费加密和文件压缩实用程序，受安全和隐私保护用户以及其他可信软件的欢迎。例如，一个样本隐藏在WinBox的安装程序中，WinBox是一个允许使用简单的GUI管理Mikrotik RouterOS的实用程序。


研究人员解释说：“该软件的恶意版本安装了StrongPity的恶意软件，没有任何明显迹象表明受害者，然后就像是可靠软件的标准版本一样运行。” “恶意的WinBox安装程序将StrongPity示例放入Windows临时目录...... [和]类似于先前的StrongPity报告，恶意软件通过SSL与命令和控制（C2）服务器通信。”


该分析还发现该组使用较新版本的WinRAR和一个名为Internet Download Manager（IDM）的工具来隐藏恶意软件。研究人员表示，考虑到这些选择，目标可能是技术型的。


报告补充说，该恶意软件会发送到之前StrongPity广告系列中使用的已知信标目的地。


“总的来说，确定的TTP，更新版本的StrongPity以及用于提供它的合法软件的操作方式与对手历史上的操作类似，”Alien Labs的研究人员说。“这很可能是由于对手的操作成功率很高，而且在多年来的公开报道之后，对于逃避检测的修改极少。”


黑格尔说，不断的改造并不一定能转化为复杂性。


他告诉Threatpost，“我认为他们只是更了解公众曝光度，而不是高度复杂化。” “如果他们作为一家企业运营，那么只需保持运营就行了。根据我们的调查结果和过去报告的结果，我们可以评估他们可能具备大规模交通操纵和政府潜在参与的能力。“


他补充说，StrongPity还可能将恶意软件的功能出售给多个实体，用于他们自己的白标用途。


StrongPity随着时间的推移而演变

StrongPity于2016年10月首次公开报道，此前针对比利时和意大利的用户发起攻击，使用水坑攻击传送恶意版本的WinRAR和TrueCrypt文件加密软件。卡巴斯基研究人员将演员描述为一个特色的APT装备，利用其零日漏洞和模块化攻击工具来渗透受害者并进行间谍活动。


随后 在2016年，微软公司开展了 更多研究，称为恶意软件Promethium，该组织针对欧洲个人提供零日漏洞。然后在2017年，ESET研究人员 在两个未命名的国家中确定了在ISP级别使用的 Pro / Thium / StrongPity变种，标志着 方法的变化。


它在2018年3月再次出现，当时公民实验室报道了针对土耳其和叙利亚用户的活动。研究人员表示，他们通过滥用TürkTelekom网络中的Sandvine / Procera深度包检测（DPI）硬件，发现了ISP级别的APT攻击。ISP通常使用DPI盒来帮助管理其网络上的流量负载，并启用基于策略的应用程序感知带宽管理; 我们的想法是确保消费者在交通繁忙时不会感到网速下降。


但是，公民实验室表示，它看到威胁组织妥协这些合法的DPI盒，将StrongPity恶意软件插入其他良性流量，针对土耳其的地区。


“当这些用户试图下载某些合法的Windows应用程序时，这些中间盒被用来将土耳其和叙利亚的数百名用户重定向到民族国家的间谍软件，” 当时公民实验室 说。


Sandvine否认这是由于ISP本身的共谋而做出的，但无论归属如何，该报告都对StrongPity团伙产生了影响：在发布后两周，Cylance观察到新的Promethium / StrongPity活动改变策略，利用新的基础设施。


研究人员表示，在公开宣传活动之后，这种持续的改造是StrongPity演员的标志。


“随着新信息的发布，恶意软件继续适应，”Cylance研究员当时解释说，回应本周Alien Labs的评估，即公开披露会促使该集团的策略发生变化。“在目标组织的历史以及更大的威胁情报界的历史中，捍卫者和他们所服务的人都会做好以前的思考并更频繁地回顾以检查威胁行为者行为和活动的'生存记忆'。”
