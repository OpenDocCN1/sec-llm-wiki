# 中国美国仍是重灾区，BlueKeep补丁修补进展太慢

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484050&idx=1&sn=b373bb2ce9c602737170846a57633b96&chksm=cef36f21f984e6378dc35606f29d71992eeed92b5e0b132a49c00ee85de18fc28776395c9d97&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484050&idx=1&sn=b373bb2ce9c602737170846a57633b96&chksm=cef36f21f984e6378dc35606f29d71992eeed92b5e0b132a49c00ee85de18fc28776395c9d97&scene=27#wechat_redirect)

![](../Images/f5f9be74f8cf55b770c0a86b83131d84.png)

  

  

2个月前，5月末时候，BlueKeep高危漏洞安全隐患，该漏洞编号为CVE-2019-0708，存在于Windows远程桌面服务（RDP）中，微软在5月的补丁日中已经发布修复补丁。

  

该漏洞被描述为蠕虫式（wormable），可以利用RDS服务传播恶意程序，方式类似于2017年肆虐的WannaCry勒索软件。目前已经有匿名黑客尝试利用该漏洞执行任意代码，并通过远程桌面协议（RDP）来发送特制请求，在不需要用户交互的情况下即可控制计算机。

  

![](../Images/b4c7a6f704c6bd764a087ed1e5945d10.png)

微软当时发布了适用于Windows 7、Windows Server 2008、Windows XP、Windows Server 2003的补丁。Windows 7和Windows Server 2008用户可以通过启用Network Level Authentication (NLA)来防止未经身份验证的攻击，并且还可以通过阻止TCP端口3389来缓解威胁。

  

昨天网络安全评级公司BitSight发布BlueKeep漏洞补丁修补进展报告：

  

自从首次发布BlueKeep漏洞暴露于全球许多组织的外部网络以来已经过去了五周。关于漏洞的能力已经有了进一步的发展，包括国土安全部开发了一个有效的漏洞，私人部门的个人也开发了一个远程代码漏洞。这两个里程碑进一步证明了此漏洞引发的风险以及Microsoft和NSA发布的紧急声明。

  

几周之后，我们来了解所有行业中外部暴露系统的修补是否有任何有意义的变化，以及各个组织和国家内部的响应是如何表现的。在此漏洞引入的攻击面上关闭此新入口点时响应的组织将降低未来受到危害的风险。

  

概观

截至2019年7月2日，大约有805,665个未打补丁系统仍然在线，容易受到BlueKeep的影响，与5月31日相比，减少了17.18％（167,164个系统）。部分减少是由于92,082个系统仍然是外部暴露的可被扫描之外。

  

![](../Images/6ce801d7d1537b1526ad82fb803d1c25.png)

假设取平均值，则表示每天暴露的易受攻击的暴露系统平均减少5,224个。通过持续观察仍然暴露在互联网上的个别易受攻击的系统，然后确定何时进行修补，我们可以计算出每天至少平均有854个易受攻击的系统被修补。这两个估计值之间的差异可能代表当前不再向Internet提供服务的系统，或者经常更改IP地址的系统。

  

易受影响的系统的绝对数量将随着时间的推移而变化，因为这些系统在一天中关闭或打开电源，或者如果机器轮换IP地址，这可能导致数字被夸大。我们可以通过了解与这些系统相关的公司来减少这些行为引入的噪音。

  

行业曝光

下图显示了5月31日与7月2日相比，每个行业中公司的外部易受攻击系统暴露的百分比。

![](../Images/c32c28f92a08f582d7bcb61ca3b77e46.png)

图片2自从2019年5月31日收集到的数据以来，所有行业都表现出减少了暴露易受攻击系统的组织数量，并且每个行业都取得了不同程度的进展，因此全面取得了进展。

  

法律，非营利组织/非政府组织和航空航天/国防部门几个类别中，非营利组织/非政府组织和航空航天/国防领域减少BlueKeep的响应能力最强的行业分别在5月31日受到影响的组织数量减少了32.9％，27.1％和24.1％。相反，消费品，公用事业和科技行业反应最少，仅有5.3％，9.5％和11.7％的受影响的组织已采取行动。我们最近报道了公用事业行业在其他领域的网络安全性能。

  

随着观察到的缓解措施，法律行业仍然是保险和金融行业是未打补丁最明显的行业。在电信和教育之后，暴露最多的仍然是技术，效用和政府/政治。电信和教育通常提供过境服务，因此影响这些行业的许多问题都在其客户的系统上。住宅网络是电信行业的一部分，而在教育领域，最大的群体通常代表学生。

  

下图显示了与仍然存在易受攻击的系统的组织相比，采取快速操作并修复其所有公开系统的组织的分布安全评级。

![](../Images/fcdb08a2da2c1049dbdbe8f1373afdbe.png)

图像-7-对于几乎所有行业而言，采取更快行动修复BlueKeep的组织集合的BitSight安全评级中位数仍然高于那些仍然暴露系统的组织。在一段时间内受到BlueKeep影响的组织中，法律，保险和商业服务行业的安全评级中位数最高，而教育，公用事业和电信行业的安全评级最低。

  

地理位置曝光

理解缓解进展的另一种方法是按国家评估这些系统。下图显示了5月31日在x轴上暴露的易受攻击系统数量的国家，以及7月2日在y轴上暴露的易受攻击系统的数量。请注意，下面的散点图使用对数刻度，因此绝对值中每个国家/地区的百分比变化比图表显示的更明显。黑线表示标准线性回归，线上的点表示这两个观察值之间没有变化。

  

![](../Images/d34908815f09e032fe81e6254e11e4a3.png)

理想情况下，人们希望观察自己处于黑线以下的国家，因为这表明这些国家的脆弱系统减少了。但是，仍有相对不变的国家以及暴露系统数量增加的国家。

  

更具体地说，一些国家的攻击面显着减少。通过将暴露的脆弱系统数量减少109,670，中国的绝对改善率最高，减少了23.9％。在美国通过展示26787个较少暴露脆弱的系统，代表了20.3％的跌幅紧随其后。其他显示暴露系统显着减少的国家是哥伦比亚（减少21.3％），拉脱维亚（减少20.7％）和危地马拉（减少45.4％）。但是，还有一些其他国家的暴露系统数量有所增加。最值得注意的是韩国显示增加了3,430个易受攻击的暴露系统，增加了14.5％，爱沙尼亚增加了146个，增加了32.2％。即使在最近的进展之后，中国和美国仍然拥有最多的暴露系统。

  

在此，我们督促各行各业系统，使用Windows 7、Windows Server 2008、Windows XP、Windows Server 2003的系统用户尽快打补丁。
