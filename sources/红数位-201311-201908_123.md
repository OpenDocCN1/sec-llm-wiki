# 名为沉默APT组织从孟加拉银行偷走了300万美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247483791&idx=5&sn=0683c5dda22fc0b471b7fa1dc73f89aa&chksm=cef36c3cf984e52a938aaa575c3b7caaab8145ea61cb1e0e8125904f138874c64064ef9f5889&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247483791&idx=5&sn=0683c5dda22fc0b471b7fa1dc73f89aa&chksm=cef36c3cf984e52a938aaa575c3b7caaab8145ea61cb1e0e8125904f138874c64064ef9f5889&scene=27#wechat_redirect)

对孟加拉国银行的攻击造成至少300万美元的损失可能是名为沉默黑客组织的所为，这是一个相对较新的，有经济动机的组织。

![](../Images/04aa7683ff68efc2281e0496089205f9.png)

沉默在9月份成为人们关注的焦点，当时总部位于新加坡的Group-IB专门负责防范网络攻击，发布了一份  详细介绍该集团资源和策略的报告。

  

他们至少在2016年开始运营，当时他们试图通过俄罗斯中央银行的自动化工作站客户端窃取资金。

  

报道说一个说俄语的网络犯罪集团可能会对荷兰孟加拉银行的ATM机进行无耻的攻击，导致300万美元被盗，报告的金额由当地媒体报道。被盗的实际金额可能要高得多。这是沉默最近的一次国际攻击之一，表明该团伙已扩大其地理范围并已走向全球，现在关注亚太市场。

  

根据当地媒体的报道，5月31日在达卡举行了几个月前开始的激烈网络攻击的最后阶段。在当地报纸发布的闭路电视录像带中，有两只乌克兰骡子带着遮面，从荷兰孟加拉银行的自动取款机上取钱。他们每次拨款前都会拨打电话，这立即引起了Group-IB的威胁情报团队的兴趣，并表示这可能是一个有组织的财务网络犯罪团体的参与，而不是简单的略读攻击。到那时，Group-IB威胁情报团队已经意识到Silence一直在亚洲开展业务。

  

自2016年以来，Group-IB一直在追踪Silence及其基础设施，并发表了一份报告“沉默：走入黑暗的边缘”在2018年9月，这是第一个详细描述该组织战术和工具的人。Group-IB的威胁情报团队收集的信息以及有关Silence基础设施的全面知识表明，至少自2019年2月以来，拥有外部知识产权103.11.138.47和103.11.138.198的荷兰孟加拉银行主持人与Silence的C＆C（185.20.187.89）进行了沟通。对荷兰孟加拉银行网络犯罪分子的攻击可能使用了以下特洛伊木马 - Silence.Downloader（又名TrueBot），Silence.MainModule（MD5 fd133e977471a76de8a22ccb0d9815b2），它允许隐蔽地执行远程命令并从受感染服务器下载文件，以及Silence.ProxyBot（MD5 2fe01a04d6beef14555b2cf9a717615c） ） 

  

一旦他们进入银行的基础设施，Silence就会进入下一阶段的攻击 - 取款。其中一个实例于5月31日在中央电视台播出，由当地媒体发布。根据Silence使用的TTP，这些钱本来可以通过两种方式被盗：黑客可能已经破坏了银行的卡处理系统，或者使用了自定义的Atmosphere软件 - 一套用于自动柜员机累积奖金的工具。有关Silence工具集的详细说明，请参阅Group-IB的报告“Silence：Moving into the darkside”。

  

“我们现在看到的是，沉默正在继续将其焦点从独联体和邻国转移到国际市场，” Group-IB恶意代码动态分析负责人Rustam Mirkasymov评论道。“在俄罗斯测试了他们的工具和技术之后，Silence获得了成为国际银行和企业国际威胁所必需的信心和技能。亚洲尤其引起网络犯罪分子的注意。荷兰孟加拉银行不是该地区第一个沉默的受害者。总的来说，我们最近发现至少有4个目标沉默在亚洲受到攻击。“

  

**另外两家孟加拉国银行也遭遇攻击**

孟加拉国当地媒体报道，另外两家当地银行--NCC银行和Prime银行 - 也面临与荷兰孟加拉银行类似的问题，但他们设法避免了经济损失。目前还不清楚沉默是否也参与了这些攻击。

  

Group-IB表示，Silence确实袭击了其他三个国家的银行 - 印度，斯里兰卡和吉尔吉斯斯坦 - 但无法透露他们的名字。

  

在2018年9月，Group-IB表示该组织只是成功地攻击了独联体和东欧国家，但他们向世界各地的银行发送了鱼叉式网络钓鱼邮件。

  

今天的报告显示，该集团最终成功地破坏了正常运营区以外的其他目标。

  

根据Group-IB从2018年9月起对沉默黑客组织的报告，该组织是一个小型的两人操作，其中一名成员被怀疑是网络安全行业的一部分。

  

然而，Mirkasymov告诉ZDNet，“自该报告发布以来，该团伙的结构可能已经发生变化”。Mirkasymov表示，他的公司最近发现其中一位Silence开发人员将“FlawedAmmyy loader”恶意软件作为其他网络犯罪操作的第三方开发人员编写。

  

根据Group-IB恶意代码动态分析负责人Rustam Mirkasymov的说法，这是该集团首次进军亚洲市场。

  

  

**关于沉默APT组织**

沉默是一个活跃但非常小的俄语黑客群体。Group-IB于2016年首次发现该集团的活动。在他们的“工作”过程中，Silence攻击了银行管理系统，卡处理系统和俄罗斯银行间转账系统（AWS CBR）。该团伙的目标主要位于俄罗斯，乌克兰，白俄罗斯，阿塞拜疆，波兰和哈萨克斯坦，但网络钓鱼电子邮件已发送给中欧，西欧，非洲和亚洲的银行员工。
