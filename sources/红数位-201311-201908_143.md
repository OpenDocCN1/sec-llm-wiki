# 新加密僵尸网络恶意软件攻击Android设备

在总部位于东京的网络安全和威胁防御公司趋势科技进行的一项研究中透露，有一种新的加密恶意软件机器人特别针对Android安卓设备。矿工利用设备的Android Debug Bridge端口系统执行解决应用程序缺陷的功能。

![](../Images/0fe571fd4431f94d29d90b91eee7835b.png)

值得注意的是，该系统默认安装在大多数Android智能手机和平板电脑上。这意味着，大量设备目前容易受到新发现的僵尸网络恶意软件的攻击。**该恶意软件在21个国家/地区被识别，但大多数目标都是在韩国发现的。**

  

该恶意软件攻击目标设备通过利用亚行方式端口默认设置工作。默认情况下，这些端口不需要身份验证，可以分发给以前具有SSH连接的系统。SSH连接几乎可以连接从智能手机到物联网小工具的所有内容。

  

根据趋势科技的说法，这两个系统一旦连接，就可以在初始密钥交换发生后无需任何身份验证即可相互通信。研究人员评估说，这种传播机制允许恶意软件滥用创建SSH连接的整个过程。

  

然后攻击继续利用命令shell软件修改ADB执行权限，并使用“wget”命令从三个不同的矿工中获取最佳选择。之后，它使用“chmod 777 a.sh”命令修改其他权限。

![](../Images/8fe2b2f47cb9ef2c8f41d18257379549.png)

新的加密僵尸网络恶意软件攻击Android设备

  

使用命令“rm -rf a.sh \*”它会设法保持不被发现，甚至在删除下载之前隐藏其先前和即将到来的路径。运行新的优化后，攻击变得更有效率。这三名矿工都有相同的网址：

  

http://198\[.\]98\[.\]51\[.\]104:282/x86/bash

http://198\[.\]98\[.\]51\[.\]104:282/arm/bash

http://198\[.\]98\[.\]51\[.\]104:282/aarch64/bash

  

“为了优化挖掘活动，该脚本还通过启用HugePages来增强受害者的记忆，这将有助于系统支持大于其默认大小的内存页面，”研究人员说。

  

Android无疑是全球最常用的智能手机操作系统。目前，全球有数十亿的Android用户使该平台成为网络犯罪分子和在线诈骗者的有利目标。因此，请保持警惕，保持手机更新，使用值得信赖的防病毒软件并定期扫描。

  

此外，密码管理恶意软件现在正在迅速发展，现在我们将这些嵌入在Google Play商店等可靠平台上的应用程序中。正在开展研究以了解问题的严重程度，并确定在下载之前检测虚假应用的方法。

  

此外，根据研究，数以千计的受感染的应用程序被上传到在线商店，通过模仿作为昂贵应用程序的最佳替代品来欺骗用户。

  

研究人员使用人工智能检测虚假应用程序并测试它们是否存在恶意软件感染和其他问题。他们检查了图标设计和描述措辞，总共审核了120万个应用程序，然后才得出Google Play商店在49,608个应用程序中包含超过2,040个包含恶意软件的热门应用程序的假副本。

  

正如福布斯指出的那样，这些应用程序“显示出与Google Play商店中最受欢迎的10,000个应用程序之一的高度相似性\[和\] 1,565种潜在的假冒产品，要求至少五个额外的危险权限，而不是原始应用程序和1,407个具有至少五个的潜在假冒产品研究人员指出，“2000多个最危险的拷贝被不少于五种商业用途的反病毒工具标记为恶意软件” 。

  

研究人员声称，许多流行应用程序的假副本只有在下载和安装后才能被普通用户检测到，除非用户具有足够的技术知识，足以在安装之前了解其中的差异。
