# Scranos针对Windows和Android设备的恶意软件广告团队已改变其攻击技术

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490905&idx=3&sn=9717d7ec6255cbf23cbea7a0cb03bba2&chksm=cef370eaf984f9fcdb77bc3101740fe1c2fac8bc9a40f04fa9f621a45d587dc7ad82f1dbcfda&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490905&idx=3&sn=9717d7ec6255cbf23cbea7a0cb03bba2&chksm=cef370eaf984f9fcdb77bc3101740fe1c2fac8bc9a40f04fa9f621a45d587dc7ad82f1dbcfda&scene=27#wechat_redirect)

针对欧洲和美国，在Windows和Android设备的恶意软件广告系列背后的团队已经改变了其攻击技术，并添加了新的有效负载，包括加密器和特洛伊木马，显然是为了从受感染的设备中获取更多资金。

![](../Images/1cd24888a16392cc7cc2ba0cf28168c7.png)

多功能Scranos恶意软件的详细信息最初于4月份出现，但不久之后，当他们非法使用Authenticode证书被撤销时，运营商失去了持久性和伪装的主要机制。

  

但这并未阻止网络犯罪活动，因为在短短几周内，Scranos已经更新了其攻击方法，试图重建他们的僵尸网络。

  

网络安全研究人员详细介绍了Scranos采用的新技术，他们还负责今年早些时候发现恶意软件活动。人们相信这场运动起源于中国 - 但它的影响遍布全球。

  

威胁研究和报告主管Bogdan Botezatu：“迅速调动其操作员以控制损坏并保持对已经受感染的机器的控制，这表明他们还没有准备放弃。”

  

“他们采用了一种新颖的方法来隐藏他们在微软可执行文件背后的恶意软件，他们也开始传播新的有效载荷以保持资金的流动”。

  

Scranos的新版本附带了一个基于假应用程序CClear的更新感染技术。它基于合法且广泛使用的系统优化应用程序CCLeaner，并被宣传为执行类似的功能。 

  

恶意软件删除程序使用恶意广告的组合提供，并捆绑在其他软件包中。

  

下载并安装后，dropper会联系命令和控制服务器，并使用新的下载替换其中一个hosts文件，以及尝试窃取cookie，登录凭据，Facebook信息和支付帐户。滴管器还将下载并安装Chrome和Firefox，如果它们不在系统上，因为它需要使用这些插件来运行。

  

从此处，合法的Microsoft可执行文件与恶意DLL放在同一文件夹中，以确保恶意软件具有持久性，并在系统重新引导后保持活动状态。与此同时，安装了虚假的CClear应用程序，甚至还有一个桌面快捷方式，可以阻止用户怀疑他们被骗过。它甚至还有一个功能正常的用户界面 - 虽然实际上在运行时它什么都不做。

  

最后，使用新创建的rundll32.exe进程安装实际的下载程序，允许Scranos下载并执行其他有效负载。

  

通过在安装过程中使用合法的Windows可执行文件，Scranos几乎没有留下任何活动痕迹，甚至融入标准网络流量，因此降低了在为攻击者创造收入之前被发现的风险。

  

Scranos的主要目标是根据命令和控制服务器的指示生成URL流量。这些网址包含各种广告，视频和其他创收链接，这些链接使用隐藏的Google Chrome实例运行。每个网址都会在新标签页中打开，每个网址都会为攻击者带来收入。这是在幕后完成的，不需要用户的知识。

  

但该活动并不仅仅涉及广告欺诈，Scranos背后的运营商在恶意软件的最新版本中添加了几个新的有效载荷 - 包括Yoddos木马。

  

Yoddos不是一种新的木马，自2012年以来一直存在于野外，但除了能够利用这些系统进行DDoS攻击之外，它还为受感染的机器提供了后门。

  

研究人员认为，Yoddos正在被部署以提供其他类型的恶意软件 - 并且它构成了赚钱计划另一部分的一部分，Scranos的运营商为其他犯罪分子租用他们的网络以丢弃新的有效载荷。

  

“最有可能的是，推销五年木马的原因与该团伙的二级商业模式密切相关。当他们在受害机器上获得重要立足点时，Scranos团队开始租用基础设施，以便网络犯罪分子可以为受害者提供额外的有效载荷，“Botezatu说。

  

Scranos还配备了一个加密货币挖掘机，秘密利用受感染机器的处理能力为攻击者生成Monero - 为他们提供又一个收入来源。

  

如果这还不够，Scranos在安装过程中窃取不同类型帐户（如Facebook，亚马逊，Airbnb等）的登录信息的原因是，攻击者也可以通过将其出售给其他人来赚钱。罪犯。

  

“他们可能要么在黑市上重新出售，要么正在为目前路线图上的商机铺平道路，”Botezatu说。

  

Scranos僵尸网络的确切大小尚不清楚，但据认为它在世界各地检测到的感染都很大，其中美国，巴西和印度的检测水平最高。

  

虽然Scranos变得多产，但它也很容易避免。主要的安装方法是通过鼓励下载，用户可以通过小心安装它们来避免恶意软件，并且只从可信网站下载应用程序。

  

“盗版软件不仅是Scranos的根本原因，它还成为勒索软件的重要交付机制。如果有疑问，请不要从第三方网站安装应用程序 - 而是转到供应商的页面并获取该软件的副本， “Botezatu说。

  

“最重要的是，如果安全解决方案检测到您要安装并阻止它的软件中的某些内容，请不要尝试暂停保护并重试安装，”他补充说。
