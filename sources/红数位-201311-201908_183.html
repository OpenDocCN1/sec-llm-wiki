微软周二累积补丁安装后，将导致某些蓝牙设备和系统事件查看器不可用

微软表示，在Windows用户应用今天发布的累积，安全或每月汇总更新后，某些蓝牙设备可能会开始遇到配对和连接问题和系统事件查看器不可用。

某些蓝牙设备不可用

正如Microsoft今天发布的Windows支持文档所详述，“这些安全更新通过故意阻止从Windows连接到不安全的蓝牙设备来解决安全漏洞。使用众所周知的密钥加密连接的任何设备都可能受到影响，包括某些安全保险箱。 “


BLE Titan Security Keys和Feitian Multipass被封锁

最后的安全密封件部分是指谷歌的蓝牙低功耗（BLE）Titan安全密钥，上面已经召回了T1或T2代码 以及Feitian Multipass（飞天CTAP1 / U2F安全密钥）。


发生这种情况之后，发现 “在您使用安全密钥时 - 在大约30英尺内 - 与您保持密切关系的攻击者（a）与您的安全密钥进行通信，或（b）与设备进行通信你的钥匙是配对的。“


“微软已经阻止这些蓝牙低功耗（BLE）密钥与配对错误配置的配对”雷德蒙德的  ADV190016蓝牙低功耗咨询公司表示。


有关此漏洞的更多详细信息，请参见常见漏洞和披露数据库中的漏洞  CVE-2019-2102条目。


检查蓝牙设备是否受到影响

安装了Microsoft今天发布的更新之一后，在配对，连接或使用蓝牙设备时遇到问题的Windows用户应该“联系蓝牙设备的制造商以确定设备更新是否退出”。


客户还可以查看事件日志，查看他们的蓝牙设备是否受到查找事件的影响，并显示以下消息：


您的蓝牙设备尝试建立调试连接。Windows蓝牙堆栈在不处于调试模式时不允许调试连接。


受影响的Windows更新

至于详细的由微软，安装下列累积更新（LCU），每月汇总，或安全更新可能会导致某些蓝牙设备配对和连接问题：


KB4503293  或更高版本的LCU for Windows 10，版本1903。

KB4503327  或更高版本用于Windows 10，版本1809和Windows Server 2019的LCU。

KB4503286  或更高版本用于Windows 10的版本，版本1803。

KB4503284  或更高版本适用于Windows 10，版本1709的LCU。

KB4503279  或更高版本适用于Windows 10，版本1703的LCU。

KB4503267  或更高版本适用于Windows 10，版本1607和Windows Server 2016的LCU。

KB4503291  或更高版本的LCU for Windows 10，版本1507。

KB4503276  或更高版本Windows 8.1和Windows Server 2012 R2的月度汇总。

KB4503285  或更高版本Windows Server 2012和Windows Embedded 8 Standard的月度汇总。

KB4503290  适用于Windows 8.1和Windows Server 2012 R2。

适用  于Windows Server 2012和Windows Embedded 8 Standard的KB4503263。


系统事件查看器不可用

随着微软于2011年6月发布补丁周二更新，用户注意到尝试访问Windows 10事件查看器的自定义视图部分将导致程序停止正常工作。 

这是由Windows 10版本1903累积更新KB4503293和Windows 10版本1809累积更新  KB4503327中的未知更改引起的，这会导致事件查看器在尝试加载自定义视图时失败。 


对于先前在安装累积更新之前创建的自定义视图，以及在我们的实验中，之后创建的新视图，会出现此问题。这使得该程序的这一部分目前无法使用。


尝试访问自定义视图时，事件查看器将声明“MMC已在管理单元中检测到错误并将其卸载”。然后，它为您提供报告错误或卸载管理单元并继续的选项。


Windows事件查看器中的自定义视图错误


当您按确定时，将显示一个“System.IO.IOException”错误，指出该管理单元不可用，并且“进程无法访问文件C：\ ProgramData \ Microsoft \ Event Viewer \ Views \ [custom_view ] .XML”。


管理单元不可用错误


一些用户还报告看到“托管代码管理单元中未处理的异常”错误，如下所示。


未处理的异常错误


发生此错误时，在关闭程序并再次启动它之前，事件查看器将不再有效。重新启动后，请不要返回自定义视图，否则将再次发生错误。


不幸的是，修复此错误的唯一方法是删除有问题的自定义视图。在许多情况下，这意味着删除所有自定义视图，直到使用下面的说明修复错误。


访问自定义视图时修复“管理单元不可用”错误

如Deskmodder.de所述，如果您看到“管理单元不可用错误”或“MMC在管理单元中检测到错误”错误，您可以使用以下步骤修复事件查看器：


1.在Windows 10计算机上打开文件资源管理器，然后导航到C：\ ProgramData \ Microsoft \ Event Viewer \ Views文件夹。此文件夹包含在该计算机上创建的自定义视图的配置文件。


2.在此文件夹中，您将看到以单词View开头的各种.xml文件，如下所示。

C：\ ProgramData \ Microsoft \ Event Viewer \ Views文件夹


3.将这些XML文件复制到备份文件夹中，以便在Microsoft修复错误时，您使用的任何自定义视图都不会丢失。


4.现在删除该View文件夹中使用格式View_ [number] .xml命名的所有文件。例如，View_0.xml如上所示。


5.再次启动事件查看器，您应该可以再次进入自定义视图部分。

如前所述，这不会解决问题，因为新的自定义视图也会导致此错误。


目前，建议在Microsoft可以解决问题之前避免使用事件查看器的“自定义视图”部分。
