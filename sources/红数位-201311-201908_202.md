# MuddyWater更新POWERSTATS后门进行多阶段攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490908&idx=2&sn=3dc4a85eac789cb0823514b3497d47aa&chksm=cef370eff984f9f9096bedca3f9c5001193e37453053edf391fd01e74863a20541456b4534f3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490908&idx=2&sn=3dc4a85eac789cb0823514b3497d47aa&chksm=cef370eff984f9f9096bedca3f9c5001193e37453053edf391fd01e74863a20541456b4534f3&scene=27#wechat_redirect)

伊朗支持的MuddyWater网络间谍组织最近不断升级和改进其工具，该组织的POWERSTATS后门是最后一次获得更新。

  

虽然之前MuddyWater在攻击的第一阶段部署了基于PowerShell的Windows后门，如2017年 Palo Alto Networks的第42单元所述，这次恶意工具在感染过程的第二阶段使用。

  

**更新的后门**

正如安全研究人员在分析MuddyWater活动时发现的那样，后门的更新版本被称为POWERSTATS v3能够截取屏幕截图，执行命令和PowerShell代码，在攻击的后期阶段，已经被攻陷的机器上被删除。

攻击的第一阶段

在最初的攻击阶段，黑客会尝试使用带有通过鱼叉式网络钓鱼电子邮件传递的恶意宏的Microsoft Word文档来感染他们的目标。

  

一旦在受害者的机器上执行，宏就会删除一个Microsoft Script Encoder编码的VBE文件，该文件包含一个模糊的PowerShell脚本，该脚本收集操作系统（OS）信息并将其保存到日志文件中。

  

“该文件将被上传到指挥与控制（C＆C）服务器，每个受害机器会产生一个随机GUID号码，将被用于机器识别，” 说趋势科技的研究团队。

  

“稍后，恶意软件变体将启动无限循环，查询C＆C服务器上某个文件夹中的GUID命名文件。如果找到这样的文件，将使用Powershell.exe进程下载并执行该文件。”

更新工具和攻击方法

MuddyWater（又名  SeedWorm  和  TEMP.Zagros）于2017年首次  被发现，  并被威胁情报专家称为主要  针对Midle Eastern实体。

  

尽管相当新，但该集团非常活跃，因为它在2018年9月底至11月中旬期间在30个组织中造成了131名受害者，详见  赛门铁克  2018年12月的报告。

  

而来自北美，欧洲，和亚洲的政府和国防中部和西南地区的实体，以及众多私人持有和公共组织扩大他们的攻击MuddyWater也观察到1，  2，  3 \]。

  

上个月，思科Talos发现威胁组更新了他们的TTP  ，包括新的反检测技术，这些技术可以远程访问受感染的系统，同时努力避免被视为BlackWater活动的一部分。

![](../Images/ece292d7dbec9db32dd122cf8c829dd1.png)

Trojanized BlackWater文档  （图片来源：Cisco Talos）  

在BlackWater活动期间，黑客组织通过在定制工具的帮助下试图绕过Yara规则和基于主机的签名，尽力避免检测。

  

正如Clearsky Security上周进一步显示的那样，MuddyWatter威胁演员补充了他们的策略，技术和程序（TTP）以及旨在通过受损服务器丢弃有效负载的新诱饵宏驱动文档，以及利用CVE-2017的新文档-0199漏洞即使用Windows API的Microsoft Office / WordPad远程执行代码漏洞。
