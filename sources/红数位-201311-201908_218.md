# 德国：后门在四种智能手机型号中找到; 20,000名用户被感染

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490911&idx=4&sn=ec405a6e08a466cf92a5e8ac1df9f947&chksm=cef370ecf984f9faa19474c52920e19a86a8055ec7d65d2066195f89ebc86a162401ce083263&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490911&idx=4&sn=ec405a6e08a466cf92a5e8ac1df9f947&chksm=cef370ecf984f9faa19474c52920e19a86a8055ec7d65d2066195f89ebc86a162401ce083263&scene=27#wechat_redirect)

德国网络安全机构警告不要购买或使用四种低端智能手机型号。

![](../Images/4925ccd4884ea4d5f9d378ff70b9ac93.png)

德国联邦信息安全办公室（或BundesamtfürSicherheitin der Informationstechnik - BSI）今天发布了安全警报，警告在该国销售的至少四款智能手机型号的固件中嵌入了危险的后门恶意软件。

  

受影响的型号包括Doogee BL7000，M-Horse Pure 1，Keecoo P11和VKworld Mix Plus（固件中存在的恶意软件，但不活动）。这四款都是低端Android智能手机。

  

**感染了后门特洛伊木马的电话**

BSI称这些手机的固件包含一个名为Andr / Xgen2-CY的后门木马。

  

英国网络安全公司Sophos Labs于2018年10月首次发现了这一恶意软件病毒。在当时发布的一份报告中，Sophos表示恶意软件嵌入在一个名为SoundRecorder的应用程序中，默认包含在uleFone S8 Pro智能手机上。

  

Sophos表示，Andr / Xgen2-CY旨在成为受感染手机上不可移动的后门。

  

恶意软件的基本设计是在手机开机后开始运行，收集有关受感染手机的详细信息，ping其命令和控制服务器，并等待将来的指示。

  

根据Sophos的说法，Andr / Xgen2-CY可以收集如下数据：

  

设备的电话号码

位置信息，包括经度，纬度和街道地址

IMEI标识符和Android ID

屏幕分辨率

制造商，型号，品牌，操作系统版本

CPU信息

网络类型

MAC地址

RAM和ROM大小

SD卡大小

语言和国家

手机服务提供商

一旦受感染的手机的个人资料在攻击者的服务器上注册，他们就可以使用该恶意软件：

  

下载并安装应用程序

卸载应用

执行shell命令

在浏览器中打开URL（虽然此功能似乎是我们分析的样本中正在进行的工作）

**恶意软件删除“不可能”**

恶意软件不仅仅是一些过于激进的广告模块。Sophos表示，其作者试图隐藏恶意代码，后门被伪装成Android支持库的一部分，其方式是将其隐藏起来。

  

“由于固定在固件的内部区域，手动删除恶意软件是不可能的，”BSI今天表示。

  

只需通过手机制造商发布的固件更新即可删除恶意软件。遗憾的是，没有恶意后门的固件更新仅适用于Keecoo P11型号，而不适用于其他型号。

  

这家德国网络安全机构表示，每天至少有2万个德国IP地址连接到Andr / Xgen2-CY的命令和控制服务器，这表明仍有许多德国用户使用受感染的手机进行日常任务。其他国家/地区的用户也很可能受到影响。

  

BSI警告说，这些设备的用户现在有可能将其他恶意软件从恶意软件的控制服务器推送到他们的设备，例如勒索软件，银行特洛伊木马或广告软件。

  

**以前的一系列事件清单**

  

这不是同类事件中的第一起事件。2016年11月，来自Kryptowire和Anubis Networks的两份报告发现，两家为大型中国手机制造商制造固件组件的中国公司正在其代码中嵌入类似后门的功能。

  

2016年12月，Dr.Web的安全研究人员在26款Android智能手机型号的固件中发现了Android恶意软件的下载程序。

  

2017年7月，Dr.Web发现隐藏在几款Android智能手机固件中的Triada银行木马版本。

  

在2018年3月，同样的Dr.Web 在42个其他Android智能手机型号的固件中嵌入了相同的Triada木马。

  

在2018年5月，Avast的研究人员在141款Android智能手机的固件中发现了Cosiloon后门木马。

  

在所有事件中，所有智能手机型号都来自鲜有名的供应商，销售低端级Android设备。
