# 黑客攻击自2015年以来下降了95％

威胁情报分析师长期以来一直表示黑客行为主义已经死亡，但IBM X-Force今天发布的新数据证实了黑客主义现象的彻底崩溃，自2015年以来活动水平下降了95％。

  

![](../Images/3d80cbcdcce9d3ff95da7e0691e39dc6.png)

图片：IBM X-Force

根据IBM的说法，黑客组织在黑客活动下运营引发的安全事件自2015年以来一直在下降，当时该公司实现了高峰，其中有35起公开报道事件。

  

从那以后，事件以稳定的速度下降，2017年仅报告了5起，2018年报告了两次，而今年头几个月报告为零。

  

来自黑客组织的攻击继续发生，但实际事件（成功违规）的数量却在不断下降。

  

研究人员将这种下降归咎于两个因素 - 匿名黑客集体的死亡和执法官员的持续镇压，这些行为已经削弱了黑客行列。

  

**匿名者死亡**

黑客攻击活动崩溃的最大角色可能是匿名黑客集体的解体，根据IBM的说法，该集体占所有黑客行为主义安全漏洞的近45％。

![](../Images/0aa7d8a1d5b1db2f6c0be704a5f3db34.png)

图片：IBM X-Force

匿名黑客曾经因为各种人道主义或社会原因而侵犯了公司和政府网络，但据IBM称，该组织的名称现在已经因参与2016年左右开始的政治主题活动而受到损害，IBM表示已经拒绝了许多活动。其成员。

这导致“虚假的匿名”一词的出现，以描述与该团体无关或匿名行为的匿名成员 - 看到促进各种社会或政治宣传，或从匿名社区获得经济利益。

  

伪造的Anons已经将较大的群体（一旦按照共同的信念行动）分裂成更小的分裂小区，这些小组在他们自己的信条上运作，有时与其他匿名派别完全对立，导致更广泛的公众和其他成员之间的混淆。由于缺乏领导能力和令人困惑的议程，成员们慢慢剥离，否认匿名。

  

IBM威胁分析师卡米尔·辛格尔顿表示，“任何减少假Anons数量的尝试都可能导致真正的匿名演员数量减少。”

  

此外，民族国家集团的参与也玷污了匿名。这些民族国家集团通常由精英情报机构经营，他们伪装成匿名者，推动政治宣传或推动公众影响力运动。

  

他们的行为导致许多匿名成员不信任整个集团，并将他们的努力集中在除了黑客主义之外的其他事情上。

  

但没有任何因素导致该组织的死亡超过其大部分攻击的低效率。破坏网站和发起DDoS攻击很少做任何事情。

  

也没有从与特定主题完全无关的网站窃取数据。在许多情况下，匿名黑客最终将个人用户信息泄露到公共领域，并因为荒谬的原因伤害无辜的人，同时吸引了嘲笑和嘲笑。

  

反过来，这又引起了执法机构越来越多的关注，这些机构打击了较大的Anonymous和LulzSec组织的成员，但也攻击了较小的组织。

  

**逮捕，逮捕，逮捕**

“X-Force IRIS对相关逮捕的内部追踪显示，自2011年以来，美国，英国和土耳其的执法机构至少逮捕了62名黑客行为主义者，” 辛格尔顿说。“我们怀疑实际数字大于公开宣布的数字。”

  

一些最引人注目的逮捕行动包括DitsSed波士顿儿童医院的匿名黑客 Martin Gottesfeld ; 詹姆斯罗宾逊，在俄亥俄州抗议警察虐待 ; 和Deric Lostutter，一名在肯塔基州暴露强奸案的匿名成员。

  

但是，许多其他更逮捕也发生\[ 1，2，3 \]。尽管如此，辛格尔顿并没有看到黑客主义的好消息。

然而，有些人不同意辛格尔顿的结论。对许多人来说，黑客主义已经死了。
