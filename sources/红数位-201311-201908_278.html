Sophos报告说，如果他们的商业产品安装在Windows 7上，安装微软5月更新可能会导致Windows挂起显示“配置35％”的更新屏幕，进退两难。

在Sophos的一个新的支持公告中，反病毒公司表示他们的Sophos Endpoint Security and Control和Sophos Central Endpoint Standard / Advanced的Windows 7和Windows 8.1用户会在安装更新时发现他们的计算机挂在配置更新屏幕上。


我们已经增加了客户报告，继续从Microsoft Windows 14月5日修补程序开始，他们正在遇到启动挂机，机器似乎停留在“配置35％”


初步调查结果表明，这与以下Microsoft补丁有关：


2019年5月14日-KB4499164（每月汇总）

2019年5月14日-KB4499165（仅限安全更新）


KB4499164更新是一个Windows 7更新，标题为“2019-05安全每月Windows 7质量汇总”，KB4499165是“2019-05安全唯一质量更新Windows 8.1”和Windows Server 2012 R2。


虽然  Sophos公告声称他们“仅在Windows 7和Windows Server 2008 R2上发现了问题”，但KB4499165安全更新适用于Windows 8.1和Windows Server 2012 R2。因此，这个bug也可能会影响这些Windows版本。


于受此问题影响的用户，Sophos声明您可以在安全模式下卸载更新，以便允许计算机正常启动。


他们还说明，如果您在安全模式下删除更新时遇到问题，可以禁用“Sophos Anti-Virus”服务，然后在安装后尝试删除更新。


遵循2019年4月更新中的类似问题

上个月 Sophos用户在安装2019年4月更新后发现Windows冻结并变慢，这个问题也出现了类似问题。 


在该特定情况下，确定Windows客户端服务器运行时子系统（CSRSS）服务的Windows安全更新导致各种防病毒程序和Windows出现问题。
