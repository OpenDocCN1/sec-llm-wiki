微软2019年5月周二的补丁修复了79个漏洞

今天是微软2019年5月的补丁星期二，这意味着Windows管理员正在倾吐自己的饮料（可能是两个）并准备好在测试微软发布的新补丁和安全更新时脱掉头发。本月的更新中包含针对公开披露或被利用漏洞的修复程序。


随着2019年5月安全更新的发布，微软发布了针对79个漏洞的3个建议和更新，其中19个被归类为严重漏洞。这些更新包括Palo Alto Networks发现的一个被主动利用的漏洞的修复程序以及一个公开披露的漏洞。


有关非安全Windows更新的信息，您可以阅读今天的  Windows 10 May 2019累积更新。

所有用户都应尽快安装这些安全更新，以保护Windows免受安全风险。

针对主动利用漏洞发布的安全更新

Microsoft发布了由Palo Alto Networks发现的名为“ Windows错误报告特权提升漏洞（CVE-2019-0863）” 的安全更新。已发现此漏洞在野外被积极利用。


据微软称，为了利用此漏洞，攻击者必须首先获得对系统的非特权访问。这可以通过恶意软件或手动攻击来完成。

“Windows错误报告（WER）处理文件的方式中存在一个特权提升漏洞。成功利用此漏洞的攻击者可以在内核模式下运行任意代码。然后攻击者可以安装程序;查看，更改或删除数据;或者使用管理员权限创建新帐户。

要利用此漏洞，攻击者必须首先在受害者系统上获得非特权执行。“

另外还修复了Skype for Android中的一个漏洞，该漏洞被公开披露为“ Skype for Android Information Disclosure Vulnerability（CVE-2019-0932） ”。此漏洞允许攻击者在用户不知情的情况下收听用户的Skype会话。

针对旧版Windows发布了远程桌面修复程序

微软今天发布了针对Windows XP，Windows Server 2003，Windows 7，Windows Server 2008 R2和Windows Server 2008上的远程桌面服务的安全更新，这些更新可能被蠕虫恶意软件利用以通过暴露的计算机进行传播。

由于微软认为这个漏洞可能会被发现和利用，并且由于其严重性，他们甚至发布了Windows XP和Windows 2003的更新，这些更新已不再受支持。

强烈建议所有用户尽快安装此更新。有关此漏洞和可用更新的更多信息，请访问此处。
