# 黑客组织Fxmsp攻击窃取出售美国三家反病毒公司的新细节曝光

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490922&idx=1&sn=ccfb60849924af71bd8f6eabf0ce86f9&chksm=cef370d9f984f9cf5b8760336e91537ca1c2ddee0ac9b6dbe10997a66035624d13129b5a3944&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490922&idx=1&sn=ccfb60849924af71bd8f6eabf0ce86f9&chksm=cef370d9f984f9cf5b8760336e91537ca1c2ddee0ac9b6dbe10997a66035624d13129b5a3944&scene=27#wechat_redirect)

5.10  国外媒体报道，曝光爆黑客窃取美国三家顶级反病毒公司的源代码并在线销售的新闻，黑客组织Fxmsp称可以提供来自美国的三大反病毒企业的机密信息，其确认他们拥有这三大公司软件开发相关的源代码。提供直接出售和访问两个服务方式，定价超过30万美元。

  

目前，更多黑客组织Fxmsp攻击美反病毒公司的新细节出现。

  

难以理解威胁行为者可能会破坏知名安全公司的网络。然而，这不仅是可能的，而且也发生在过去;  本周早些时候BleepingComputer报道，至少有三家反病毒厂商被验证情况如此。

  

2012年，全世界都了解到，黑客已经在六年前破坏了赛门铁克网络，并取得了诺顿防病毒企业版，诺顿网络安全特警，诺顿公用事业，诺顿GoBack和pcAnywhere的源代码。

2015年，卡巴斯基宣布其内部网络已被一位威胁行动者渗透，该行动者有兴趣了解该公司为其安全操作系统，欺诈预防，安全网络和反APT解决方案以及服务开发的技术。

作为同样的受害者，Bitdefender在同一年成为人们关注的焦点，当时一名黑客试图以 15,000美元的价格敲诈该公司，因为它窃取了非加密的登录客户数据。这是可能的，因为服务器正在运行过时的软件包，因为人为错误。

  

在所有这三起案件中，这些公司都表示该事件没有产生持久影响或产生重大影响。赛门铁克的源代码适用于旧产品; 与卡巴斯基一起，入侵很早就被发现，让公司深入了解对手的工具和基础设施; 而Bitdefender表示，泄密影响的中小企业客户不到1％。

  

**Fxmsp**惹恼了赌注

一个名为Fxmsp的地下论坛上的俄罗斯黑客组织在4月份开始做广告宣传，他们持续远程访问在美国设有办事处的多家反病毒公司的网络。

![](../Images/0e4da53348989f9bfe05f0fa9c528808.png)

他们提出销售访问权限以及与受害者的各种产品相关的源代码：防病毒软件基本代码，人工智能模型，客户面板，Web安全软件和实用程序。

即时消息通信表明Fxmsp能够从至少两家公司获得源代码。

欺诈预防公司**Advanced Intelligence**  （AdvIntel）安全研究主任Yelisey Boguslavskiy  告诉BleepingComputer，Fxmsp用了6个月的时间来攻击AV公司，并且这两个团队精心策划了这项行动。一个在美国和另一个在台湾的合伙人。

![](../Images/94cee916d66afa8248e207205c8db004.png)

虽然没有正式确认Fxmsp违反的三家反病毒公司的名称以及联邦调查局的调查正在进行中，但Boguslavskiy告诉BleepingComputer，“其中一家受害者反病毒公司已承认此事件的存在。”

  

有些人在  Twitter  和Reddit上  表示受害者是赛门铁克，迈克菲和趋势科技。但是，他们没有提供任何证据支持这些断言。

![](../Images/14d8b652da9d1b07402c8bb2e86d83fc.png)

Boguslavskiy告诉我们，AdvIntel目前正在与受信任的各方合作，以修复违规行为并保护受害者信息。第四家反病毒公司也可能遭到黑客攻击，但它的名称和位置仍然未知。

**Active Directory**访问声明

2018年10月，Fxmsp的卖家之一BigPetya发布了一份公告，提供了对多个实体的内部服务器的访问权限。其中包括Reliance Industries Limited，一家在能源，石化，纺织，自然资源，零售和电信领域活跃多元化的印度巨头。

卖方宣传“具有管理员权限，所有服务器数量和网络上所有PC的完全访问权限”（自动翻译）和“访问域控制器”。

![](../Images/866b923fa9f667fed3bc21efa79a0529.png)

  

  

域控制器是Active Directory（AD）服务的重要组成部分，因为它们管理对Windows域资源的访问。它们存储用户帐户信息，负责用户身份验证以及在域上实施安全策略

声称他们具有这种级别的访问权限，因为它提供了对Windows网络及其连接的所有资源的完全访问权限。

在AdvIntel的屏幕截图中显示了Fxmsp访问属于其中一个受害者的内部文件夹的证据，图形用户界面似乎支持黑客组织到达Active Directory的声明。

![](../Images/938abbce0e0cff03bf5a412089382c1f.png)

Active Directory安全专家Huy Kha告诉BleepingComputer，上面的屏幕截图“实际上看起来像是Windows Server 2012 R2的域控制器”。

为了比较，他从他的测试域控制器提供了下面的屏幕截图，说攻击者可能有权访问域网络服务器，这可能是因为Active Directory中的高权限用户遭到破坏。

![](../Images/b4fdb6630b3a867fe4016d2cc89b7479.png)

信用：Huy Kha

Kha的理论还包括远程桌面访问声明，默认情况下，只有Domain Admins，Enterprise Admins和Administrator组中的用户可以在域控制器上外部启用RDP。

具有此级别权限的用户可以访问服务器上的远程桌面设置，并可以通过Internet将其打开。默认情况下，该选项处于非活动状态

“默认情况下，通过外部方式到DC的RDP实际上是禁用的，但是攻击者可以启用它，因为它们似乎已经破坏了域中的高权限用户，”Kha假设。

 该理论将解释Fxmsp如何建立对受害者网络的持久访问。Kha说，一个组织在其Active Directory环境中几乎没有可见性，无法看到网络上发生了什么。

专家告诉我们，Active Directory本身并不安全，但管理不善是削弱其默认安全性的主要原因。

他提供了一些保护Active Directory免受潜在入侵的提示，其中一个是确保他们了解Domain Admin组的角色，并仅将权限赋予具有正确作业属性的用户，以便提升域控制器或提升域的功能水平。

如果无法避免委派权利，最好以最小权限原则为基础。此外，共享管理员帐户远非健康的做法。

另一项措施是限制对DC的访问。除了非IT部门（会计，市场营销）之外，拒绝工作站进行工作站通信是关闭攻击者路线的好方法。否则会出现横向移动问题。
