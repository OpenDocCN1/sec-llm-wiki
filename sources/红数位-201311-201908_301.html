  • 提供有效安全管理的新视图，提供非常高水平的数据保护和可靠性

  • 完全德国制造，符合欧盟GDPR标准的本地管理，企业完全控制自己的安全数据

  • 适用各型企业及单位，小红伞控制台联网激活后可实现完全内网管理（无外网）

  • 一键轻松获取完整而全面的IT环境清单(AD域)，无域扫描全局IP

  • 远程推送代{过}{滤}理强劲有力，基于域环境一键安装，基于IP地址范围的客户端安装

  • 强大的报告引擎可让您生成详细的报告（安全信息，已安装软件，硬件，资产管理，漏洞管理）

  • 管理全局小红伞产品安全情况，推送小红伞配置，推送扫描，内网推送病毒库升级，安全邮件通知

三、安装要求
小红伞企业版控制台安装需要：
操作系统最低要求：Windows Server 2008R2（2020 年 1 月 14 日结束支持，见资料）

建议：Windows Server 2012 R2起 ，最优Windows Server 2016
MS SQL Server最低要求：SQL Server 2008 R2；最高达SQL Server 2017

安装控制台目前有5.4.0和5.4.1 ，安装包自带 SQL Express2012（5.4.0）或SQL Express2016（5.4.1）
安装一路畅行，最后进入控制台。

四、操作步骤
打开小红伞企业版控制台：

 

打开导航内AVIRA小红伞控制台：


分别可以看到：客户端数量一览，5日内检测病毒一览，
TOP中毒电脑一览，客户端各版本号一览，最新客户端安装包和AVIRA授权，右侧显示已安装电脑

右侧任意电脑可以在左侧分组容器内进行拖拽分组，分组容器可以手动分组，根据客户端操作系统分组，自动推送安装小红伞防病毒软件等
右侧菜单上部可对客户端实现远程安装，卸载，扫描，推送更新病毒库，同步最新配置等（最大缺点，控制台目前菜单完全汉化，细节还有待汉化）

 
右侧菜单windows update可实现全局打补丁

检测到补丁，服务器双网卡，可实现内网打补丁



推送杀毒到客户端，可以看到，直接双击右下角小红伞直接出来杀毒软件界面（无Avira Connect），此处应有掌声
