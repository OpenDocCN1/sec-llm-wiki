# 小红伞防病毒软件荣获AV-TEST 2014年度最佳可用性大奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490940&idx=1&sn=4440d1db02069b28718eaea0f57f85f6&chksm=cef370cff984f9d957e4bcdea1024429efe9aaca40fa016cc1873555988755e75a35605b73c7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490940&idx=1&sn=4440d1db02069b28718eaea0f57f85f6&chksm=cef370cff984f9d957e4bcdea1024429efe9aaca40fa016cc1873555988755e75a35605b73c7&scene=27#wechat_redirect)

据AV-TEST 2014年度报告，小红伞防病毒软件荣获AV-TEST 2014年度最佳可用性大奖。

![](../Images/67a78ec305a5c0aa7cbc9939a2f902b8.png)  

个人用户产品：小红伞防病毒专业版

该公司的小红伞防病毒专业版（前身为互联网安全）显示可用性，在所有2014年认证测试类别中获得最佳成绩，并由此为小红伞防病毒专业版颁发AV-TEST最佳可用性2014年度奖。

![](../Images/869bacfb632c2555636159d06603c022.png)  

小红伞防病毒专业拥有一些令人印象深刻的特点：

![](../Images/e738bca2e40a93599634ca763bac3253.png)  

在2014年的所有6项认证测试，AV-TEST实验室严格评估了安装安全软件影响了用户计算机整体友好性，特别是关于误报。个人版产品中，小红伞防病毒专业版（前身为互联网安全），总是取得所有的测试软件中最优异的成绩。在测试中，在实验室测试了众多网站，每个测试扫过400000良性的应用程序和程序的安装过程中记录没有任何阻塞动作，流畅性值得充分肯定。

此外，在附加测试类别中，如保护能力和性能（速度），小红伞防病毒专业版始终表现出了优异的效果。  

“A security solution that offers the user a wide range of freedom and is only heard from when the situation requires it.“ --Guido Habicht, CEO AV-TEST GmbH
