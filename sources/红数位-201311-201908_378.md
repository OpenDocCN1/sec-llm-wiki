# Avira小红伞正式宣布完成对系统优化软件360Amigo的收购

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490954&idx=1&sn=e500204ca32a3ad1016c58f7f74cf227&chksm=cef37039f984f92f5654babe7ea066b5a002230852d1e37ff543427a39f24667ee253b610ca4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490954&idx=1&sn=e500204ca32a3ad1016c58f7f74cf227&chksm=cef37039f984f92f5654babe7ea066b5a002230852d1e37ff543427a39f24667ee253b610ca4&scene=27#wechat_redirect)

近日，英国著名系统优化和清理软件360Amigo System Speedup在其官网发布公告，宣布德国安全厂商Avira（小红伞）于2014年6月完成对其的整体收购，并将正式升级成为小红伞安全套装的新组件——Avira System Speedup，已购买360Amigo授权的老用户仍将得到来自Avira的支持。

![](../Images/2c1046ab49aa58c7a7ae108b7b54f713.png)  
  
事实上，Avira早在2012年就已接手360Amigo的开发维护工作，当年8月，Avira System Speedup正式发布，其核心技术即来自360Amigo。此后，360Amigo的创始团队逐渐淡出，直至2013年3月26日发布V1.2.1.8200后完成产品技术和软件代码的移交。据传，该开发团队来自中国，从2010年开始在英国注册公司经营360Amigo品牌产品，在把成熟之作出手并告别后，已转赴新加坡跳槽新公司开发了新作品ToolwizCare（兔卫士），开始了新的创业。而在得到360Amigo后，Avira已将其版本号更新到了V1.3.1.9930。今年开始，Avira正着手发力对System Speedup组件作出重大更新和功能完善，届时将推出官方中文版，不过这都需要最早等到第四季度。  
  
值得一提的是，Avira原先的收购目标并非360Amigo，而是另一款著名的系统优化软件TuneUp Utilities。Avira很多年前曾和同是德国出产的TuneUp Utilities搞过捆绑销售的合作，当时业界普遍认为这宗联姻板上钉钉了，但后来捷克安全公司AVG通过漂亮的商业运作，成功上市募集到资金，于2012年底整体收购了TuneUp Utilities。  
  
更有趣的是，360Amigo原先的收购方也并非Avira，而是挪威安全厂商Norman。一度Norman官网所有产品都是捆绑360Amigo组合销售的，之后甚至传出Norman成功收购360Amigo的新闻。相信是TuneUp Utilities被AVG截胡的教训激发了Avira的决心，在眼看360Amigo将属于Norman之际，最后一刻介入了进来，通过先OEM再收购的方式抢下了360Amigo，并发展成了自己的新产品Avira System Speedup。  
  
经历了两年的恋爱长跑后，360Amigo最终嫁入Avira，这宗收购案以这样圆满的结局画上句号。在全球各大安全厂商均在开发或收购系统优化组件的热潮下，Avira虽错过了TuneUp Utilities，但最终没有错过360amigo，这也算是小红伞用户之幸吧。  
  
根据长期使用者反馈，System Speedup集成有许多特别有用的工具，且清理很干净，比很多其它软件清理出的磁盘空间都要大，和同为英国产的CCleaner相比，总体上CC的清理偏温和、偏保守，SS的清理偏激进、偏彻底，不过也同样安全和放心。这也给不喜国内各种卫士管家的用户提供了另一种选择，特别是对于小红伞用户，毕竟是套装自带，方便又省心。
