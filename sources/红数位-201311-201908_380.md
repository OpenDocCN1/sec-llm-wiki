# Avira Version 2014 (Update 4) 新版特点

常规信息

小红伞2014版本，更新4将包含以下更改：

1，新功能

•实时扫描误杀预防

•实现更新功能增强

•日语版软件购买链接登陆网上商店

2，错误修正

•IPM“服务器忙”的消息弹窗固定

•在启动过程中增加了自动清除旧扫描缓存文件（scaninfoXXX.tmpfiles），以防止增加磁盘空间。

备注：

更新4将公布仅供工作站产品！在某些情况下更新需要重新启动。
