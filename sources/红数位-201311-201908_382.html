自从2014版发布起，AVIRA小红伞对于每次大的更新，通过“UpdateX”（X为数字）来命名，让我们看看本次Avira Version 2014 Update 3新版特点吧。

New fixes and changes in build 14.0.3.332


Changelog 14.0.2.286/344 to 14.0.3.332


免费版:

正式新增APC（小红伞云安全保护）至免费版

现时APC(Avira Protection Cloud)只限于收费版本,但Update3后将改变

由更新3开始:Avira将为免费版增加APC功能,但有关的加入进度会跟据服务器上的负载来调节

首个测试版本,将试行只执行所有云端扫瞄要求内的50%

 

所有版本:

新增Avira Intelligent Repair System Technology(AIRS)(智能型修复系统)

AIRS为之前的首个内测版本,主要针对Avira对受感染系统(Windows)的修复能力太弱进行强化

AIRS是对应现时恶意程式所使用的技术及为受感染的使用者可以加快修复进度和清除相关问题

而加的的新技术.

AIRS 例子:Avira可以修复以往由恶意程式建立,但不能清除的随机生成登录键值.另一项特点是:

AIRS 将强化变更或删除有关问题的选项,例如:AIRS可变更登录档内并非受感染路径,但是由恶意

程序建立的安全性选项或限制.

 

修复BUG：

从SFX开始进行任何更新/修复安装确实会导致邮件和WebGuard的服务被删除，导致小红伞闭合的问题。
