Snatch勒索软件以重新启动Windows进入安全模式以绕过防病毒

研究人员发现了一种新的Snatch勒索软件，可以重新启动感染了该病毒的计算机进入安全模式，以禁用所有驻留的安全解决方案，并在系统加载后立即开始加密文件。



由于Sophos托管威胁响应（MTR）团队和SophosLabs研究人员发现，当Windows设备以安全模式启动时，大多数安全工具会自动禁用，因此可以对受害者的文件进行加密。


他们补充说：“ Snatch可以在Windows的最常见版本（从7到10）上以32位和64位版本运行。” “我们看到的样本还与开源打包程序UPX打包在一起，以混淆其内容。”


Snatch勒索软件于2018年底问世，并在2019年4月变得非常活跃，如勒索笔记和提交给Michael Gillespi e的  ID Ransomware平台的加密文件样本激增所示。


抢夺勒索软件2019活动（ID 勒索软件）


持久性，窃取数据和有效负载交付

Sophos的研究人员观察到Snatch勒索软件团队的一名可疑成员，同时“在公司网络，商店和其他公司中寻找可以访问RDP \ VNC \ TeamViewer \ WebShell \ SQL inj（SQL注入）的会员伙伴”。


这表明该组织或其分支机构在组织的计算系统中滥用了这种类型的安全漏洞，如研究人员在受害人的加密服务器上发现的日志所指向的日志所示，这些威胁指向暴力行为的威胁者强行使用了服务器的Microsoft Azure管理员帐户并进行了日志记录。通过远程桌面（RDP）进入。


Sophos说： “随后对相关文件的搜寻发现了其他几种攻击，其中使用了完全相同的工具集，似乎是对包括美国，加拿大和几个欧洲国家在内的世界各地组织的机会主义攻击。”


“后来发现所有发现相同文件的所有组织，也都拥有一台或多台装有RDP的计算机，这些计算机都已暴露在互联网上。”


最初的入侵之后，攻击者使用相同的管理员帐户登录域控制器（DC）计算机，并保持访问，收集和泄露信息以及监视受害者的网络数周。


安装服务以窃取被盗数据（图片：Sophos）

他们还在网络上大约5％的计算机（大约200台计算机）上安装了监视软件，该软件还允许进行远程访问，即使被破坏的Azure服务器已被关闭，也可以保持对被破坏的网络的持久性。


Sophos补充说：“威胁行为者还以另一种重要方式革新了犯罪手段：Snatch攻击中使用的一种恶意软件能够并且已经从目标组织那里窃取了大量信息。”


还观察到了其背后的组织，同时删除了一系列其他工具，包括Process Hacker，IObit卸载程序，PowerTool和PsExec，这也将帮助他们在受到破坏的设备上禁用安全工具。


将Snatch勒索软件组件的有效负载丢弃到受感染的网络上是按照看似随机的时间轴完成的，有时情况下需要几天，而在另一些情况下则可能需要数周。

禁用反恶意软件解决方案和加密设备

为了利用未在安全模式下加载的反恶意软件解决方案的优势，Snatch勒索软件组件将自己安装为Windows服务，称为SuperBackupMan，能够在安全模式下运行，无法停止或暂停，然后强制重新启动受感染的计算机。


设备进入Windows安全模式后，Snatch勒索软件将删除研究人员发现的“系统上的所有卷影副本”，从而防止“法医恢复由勒索软件加密的文件”。


在下一阶段，该恶意软件将开始加密其受害者的文件，而攻击者现在可以确保无法进行无偿恢复。


研究人员制作了一个视频演示，展示了其中一个Snatch勒索软件样本，该样本在加载Windows安全模式后会重新启动受感染的系统并加密文件。

Coveware是一家专门从事勒索软件谈判的中介的公司，对Sophos表示，他们“代表客户在7月至10月之间与Snatch团队进行了12次谈判”，要求赎金的范围在2,000美元至35,000美元之间，四个月。


为了避免遭到Snatch勒索软件的破坏和感染，Sophos建议公司不要将RDP服务公开到Internet或使用VPN保护它们。


由于该勒索软件背后的组织也正在积极寻找能够访问公开的VNC和TeamViewer端点以及具有SQL Server骇客和部署/使用Web Shell经验的会员，因此暴露此类服务也可能使潜在的受害者受到攻击。


最后但并非最不重要的一点是，Sophos建议组织使用多因素身份验证（MFA）保护管理员帐户，以防止暴力攻击。


此处提供了广泛的危害指标（IOC）列表，包括恶意软件样本哈希，渗透服务器地址，攻击中使用的命令等。
