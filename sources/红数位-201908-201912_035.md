# 全球安保公司巨头Prosegur受到勒索袭击，被迫关闭网络

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486813&idx=2&sn=dfda473da7c96975f3b94a0b491a26e9&chksm=cef360eef984e9f89c9523117b9e0db75ed6ac398f8267b1f9e4230f2b27ddcb274ac1b7b63c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486813&idx=2&sn=dfda473da7c96975f3b94a0b491a26e9&chksm=cef360eef984e9f89c9523117b9e0db75ed6ac398f8267b1f9e4230f2b27ddcb274ac1b7b63c&scene=27#wechat_redirect)

**全球安全公司Prosegur是私人安保行业及市场跨国企业中的主要领导者之一，自1987年在马德里交易中心上市起便成为行业先锋。****提供各种安全服务，包括警卫和现金装甲车。****它还开发警报系统，安全监控应用程序和现金处理系统。****该公司是全球大型企业，拥有170,000多名员工。**

**足迹遍布世界4大洲-亚洲（中国、印度和新加坡）、欧洲（法国、德国、卢森堡、葡萄牙和西班牙）、拉丁美洲（阿根廷、巴西、智利、哥伦比亚、墨西哥、巴拉圭、秘鲁和乌拉圭）和大洋洲。**

  

![](../Images/dc1103451782dbf71c01d5d656136b95.png)

  

全球安全公司Prosegur表示，Ryuk勒索软件在上周三攻击了该公司。

  

该公司在一条推文中说，勒索软件“已被完全遏制，该公司已经部署了所有必要的缓解措施。同样，Prosegur也已经开始恢复其服务的过程。”

  

![](../Images/67e5351234115eb6e6874f61a099dc99.png)

  

总部位于马德里的Prosegur并未详细说明使用Ryuk的攻击者所要求的赎金，也未提供公司官员是否已考虑支付赎金。一些网络保险政策将涵盖支付全部或部分赎金的费用。但是许多安全专家和执法人员警告说，支付勒索软件会促使网络犯罪分子继续进行此类攻击。

  

**警报故障**

英国安全研究员凯文·博蒙特（Kevin Beaumont）表示，Prosegur的网站于周四离线，但现在又重新上线。

  

![](../Images/78a932528878755cc2053f64f8abf04c.png)

  

该事件可能已破坏网络警报系统。博蒙特（Beaumont）在推特上发了推特的屏幕截图，这些用户的举报似乎是在举报困难。

  

![](../Images/941c9974676c9ffdbfe3056b13c975cc.png)

  

该公司对此次攻击的广泛影响仍然持怀疑态度。周五在工作时间以外与Prosegur发言人取得联系的努力并未立即获得成功。

  

**调查正在进行中**

Prosegur在Twitter声明中表示，“已经开始调查，以确定事件的类型，行为，对范围的定义以及遏制和恢复程序的定义，所有这些都包括在对事件的响应计划中信息安全。” 该公司表示已经建立了一个多学科团队进行调查。

  

Prosegur还指出，Ryuk勒索软件在过去几个月中已经袭击了西班牙的其他组织。实际上，Ryuk今年在世界范围内造成了惨重损失（请参阅11重点：Ryuk有针对性地袭击Pummel企业）。

  

美国卫生与公共服务部于8月30日警告称，琉球对医疗机构构成了威胁。根据HHS引用的Check Point Software Technologies研究，Ryuk感染通常要求赎金为15到50个比特币-截至周五价值114,000到380,000美元。Check Point和其他安全公司认为Ryuk源自Hermes勒索软件。

  

HHS说，持Ryuk攻击者通常通过恶意电子邮件将受害者作为目标，这通常会将他们驱赶到托管漏洞利用工具包的站点。此类漏洞利用工具包通常尝试使用各种软件漏洞来攻击计算机。如果成功利用了这些缺陷，漏洞利用工具包可以在目标系统上安装并执行恶意代码（例如勒索软件）。

  

网络安全公司CrowdStrike认为Ryuk由CrowdStrike冠以“ Wizard Spider”之称的集团经营，该集团很可能在俄罗斯运营。该公司称，该组织与Trickbot恶意软件有关，后者是已经存在至少三年的高级银行木马。
