# 科技巨头微软一直在追踪世界上最危险的黑客

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486758&idx=5&sn=56a13a20e68990c5441c9f3cf13625c2&chksm=cef36095f984e983d97bf62e73c56e4a9e70f69aab35a2391c40d3d149875f5f2f142f0a7c73&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486758&idx=5&sn=56a13a20e68990c5441c9f3cf13625c2&chksm=cef36095f984e983d97bf62e73c56e4a9e70f69aab35a2391c40d3d149875f5f2f142f0a7c73&scene=27#wechat_redirect)

微软团队内部一直在追踪世界上最危险的黑客，从俄罗斯奥运会的网络攻击到数十亿美元的朝鲜恶意软件，这个科技巨头如何监视地球上世界各地由国家发起的黑客攻击。

  

五角大楼最近与微软签署了一份价值100亿美元的合同，以改造和托管美国军方的云计算系统，这笔资金之多带来了一个隐含的挑战：微软能否让五角大楼的系统免受某些资源最丰富，最持久和最安全的攻击。地球上老练的黑客？

  

![](../Images/e7e45bea44ff27ddb1db0dd2dbb2458f.png)

  

战略与国际研究中心副总裁詹姆斯·刘易斯（James Lewis）说：“他们每天每天都有遭到袭击。”

  

微软最新的云计算竞争对手亚马逊赢得了超丰厚的军事合同，这意味着世界上最重要的情报收集设备位于西雅图以外的树林中。这些国家安全责任几乎几乎完全由华盛顿特区承担。现在，在华盛顿州的这个角落，数十名工程师和情报分析师致力于观察和制止由政府资助的黑客在世界范围内扩散。

  

所谓的MSTIC（Microsoft威胁情报中心）团队的成员以威胁为重点：一个小组负责代号为Strontium的俄罗斯黑客的攻击，另一小组负责监视代号为Zinc的朝鲜黑客的攻击，而另一组则跟踪代号为Zinc的伊朗黑客的攻击。钬。 MSTIC跟踪了70多个代号为政府赞助的代号威胁团体，还有更多未命名的团体。

  

在我到达华盛顿雷德蒙市典型的秋季一天之前，开始下雨。在我整个访问期间，它一直在下降。微软总部像任何政府机构一样宽敞而迷宫，拥有数百座建筑物和数千名员工。我将与微软团队会面，该团队追踪世界上最危险的黑客。

  

进攻与防御

  

约翰·兰伯特（John Lambert）自2000年以来一直在微软工作，当时新的网络安全现实首先在华盛顿特区和微软华盛顿州总部设立。

  

![](../Images/d32dcef642cc732931bb0545b2c01524.png)

John Lambert创立并管理MSTIC

  

微软，当时是一家垄断PC软件的强大公司，直到最近才意识到互联网的重要性。 Windows XP在征服世界的同时仍保持着令人震惊的不安全感，该团队目睹了一系列巨大而令人尴尬的安全性失败，包括诸如Red Red和Nimda之类的自我复制蠕虫。这些失败影响了微软的大量政府和私营部门客户，危及其核心业务。直到2002年，当比尔·盖茨（Bill Gates）发出著名的备忘录敦促强调“可信赖的计算”时，雷德蒙德才终于开始努力应对网络安全的重要性。

  

这是Lambert着迷于网络进攻方面的时候。

  

兰伯特对我说：“在进攻和防御方面都需要完善。” “要保卫好自己，你必须能够进攻。您也必须具有进攻性的思维定势。如果您不知道如何在进攻方面发挥创造力，您就不能只考虑防守。”

  

在看到政府资助的黑客活动数量增加之后，Lambert运用了这种进攻性的思维方式来帮助推动微软解决问题的方式发生根本性的变化。目标是从一个无法理解的“影子世界”过渡到一个可以看到几乎所有内容的域，在这个“阴影世界”中，防御团队感到沮丧，因为老练的黑客渗透具有强大的“零日漏洞”的网络。

  

“微软的超级大国是什么？”兰伯特回忆道。

  

答案是，其Windows操作系统和其他软件几乎无处不在，从而为Microsoft提供了感知巨大互联网状况的工具。这引起了我们仍未完全解决的真实和持续的隐私问题。但是，对于安全性而言，这是一个巨大的优势。

  

微软的产品已经内置了Windows错误报告系统，以试图通过遥测或从公司使用的任何硬件或软件收集数据来了解一般的错误和故障。但是，正是兰伯特和安全团队将遥测系统变成了功能强大的安全工具，从而改变了过去缓慢而艰巨的任务。以前，安全团队通常不得不亲自环游世界，找到特定的目标计算机，复制其硬盘，然后慢慢潜入事件中。现在，这些机器只是与Microsoft联系。实际上，每一次崩溃和意外行为都会报告给公司，该公司对大量数据进行分类，并且通常比其他任何人先发现恶意软件。

  

这种被称为Bad Rabbit的恶意软件在2017年假装是Adobe Flash更新，然后擦除了受害者的硬盘驱动器，充分体现了Microsoft如何改变弱点。勒索软件推出后的14分钟内，机器学习算法对数据进行了整理，并迅速开始了解威胁。 Windows Defender开始自动阻止它，远早于任何人都知道发生了什么。

  

**坏兔子恶意软件代码**

2017年，主要在俄罗斯和乌克兰发现了坏兔子。这是受害者收到的赎金记录。

  

![](../Images/40c85029b5f9041a940f0017eef6cb4e.png)

来源图片：卡巴斯基实验室

  

“这就是其他人所没有的：可见性和数据。国家安全局前成员杰克·威廉姆斯（Jake Williams）说，其他人周围的应用程序周围的数据都在操作系统和软件层崩溃。 “即使是第三方崩溃，他们也可以进行遥测。当您开始寻找攻击目标时，Microsoft便具备了通过遥测进行攻击的能力。”遥测使每台Windows机器和产品都变成了可以在任何异常情况下即时且在全球范围内馈送Microsoft数据和日志的源。

  

创立网络安全公司Rendition Infosec的威廉姆斯说：“微软看到的东西只有其他人能做。” “例如，我们通常会发现一些东西，例如Microsoft标记的Office 365中的恶意IP标记，但几个月后我们再也看不到它了。”

  

**将点连接**

网络威胁情报是跟踪对手，跟踪细节并产生情报的学科，可用于帮助您的团队并使对方的生活更加艰难。为了实现这一目标，成立了5年的MSTIC团队包括前间谍和政府情报人员，他们在国家安全局和美国网络司令部所在地米德堡等地的经验立即转化为他们在Microsoft的角色。

  

MSTIC列举了数十种威胁，但地缘政治却很复杂：中国和美国，这两个是网络空间最重要的参与者，也是地球上两个最大的经济体，实际上从来没有像伊朗，俄罗斯和朝鲜这样的国家经常。

  

“我们的团队使用数据，点点滴滴，讲述故事，追踪演员及其行为，” MSTIC战略计划和合作伙伴关系主管Jeremy Dallman说。 “他们在寻找演员，包括他们所处的位置，下一步计划，他们的目标对象，然后超越他们。”

  

Tanmay Ganacharya领导Microsoft Defender团队的高级威胁防护研究，该团队正在将数据科学应用于大量传入信号，以努力构建新的防御层。他说：“由于我们在您可以想到的任何领域都有产品，因此我们的传感器可以为我们带来正确的信号。” “问题是，我们实际上如何处理所有这些数据？”

  

像谷歌和Facebook等其他科技巨头一样，微软会定期通知政府黑客所针对的人，从而使目标有机会捍卫自己。去年，MSTIC已经通知了大约10,000个Microsoft客户，他们已成为政府黑客的攻击目标。

  

**新目标**

从8月开始，MSTIC发现了所谓的密码喷雾广告系列。黑客对与美国总统竞选，政府官员，新闻记者以及居住在伊朗境外的知名伊朗人有关的帐户的密码进行了大约2700次有根据的猜测。在此攻击中有四个帐户被盗。

  

MSTIC的分析师部分是通过跟踪基础设施来发现这些妥协，微软表示，该基础设施完全由伊朗黑客组织Phosphorus控制。

  

“一旦我们了解了他们的基础架构，我们就知道了他们用于恶意目的的IP地址，我们便可以开始查看DNS记录，创建的域，平台流量，” Dallman说。 “当他们转过身来并开始使用这种基础设施进行这种攻击时，我们会看到它，因为我们已经将其作为该行为者行为的已知指标进行跟踪。”

  

经过大量的侦查工作，Phosphorus尝试通过使用目标的真实电话号码来利用帐户恢复过程。 MSTIC已发现Phosphorus和其他由政府赞助的黑客，包括俄罗斯的Fancy Bear，反复使用该策略来尝试诱骗针对高价值目标的两因素身份验证代码。

  

这次微软发出的警报超出了正常水平，原因是磷改变了其追究非政府组织和制裁组织的标准操作程序。十字准线转移了，战术改变了，范围扩大了。

  

达曼说：“这并不少见，但区别在于，它的规模比我们以前看到的要大得多。” “他们经常针对这类人群，但这是他们为这次运动所做的规模和大量侦察工作\[与众不同\]。然后最终归结为他们所针对的个人，包括总统竞选中的个人。”

  

微软的侦查最终将矛头指向伊朗黑客，以针对总统竞选活动，据路透社报道，唐纳德·特朗普（Donald Trump）2020年的连任行动。

**“我们已经看到了模式。”**

在兰伯特（Lambert）在微软工作的二十年里，网络领域的工具和武器已经扩散到更多国家，数百个有能力的网络犯罪组织，并且，越来越多的私营公司在全球范围内向愿意支付最高价的买家出售剥削产品。

  

兰伯特说：“扩散意味着更大范围的受害者。” “有更多演员需要跟踪。”

  

这在政治骇客中表现出来。 2016年美国大选的后果之一是，为入侵政党，竞选活动和智囊团而战的人数激增，更不用说政府本身了。与选举有关的黑客攻击通常是俄罗斯，中国，伊朗和朝鲜这“四大”省份。尽管微软研究人员拒绝透露他们所看到的内容，但它正在向其他国家蔓延。

  

MSTIC的首席项目经理Jason Norton表示：“不同之处在于，您正在吸引更多以前未必有的国家加入竞争。” “俄罗斯和中国这两个大国-现在，我们可以说，自2016年大选以来，他们一直在追随此事。但是现在您将看到更多的国家/地区这样做-戳穿和刺穿软肋，以了解合适的部件在未来产生影响或影响。”

  

“领域变得越来越拥挤，”达曼同意。演员们互相学习。当他们从更显赫的名字中学习策略时，他们会扭转并使用它们。”

  

即将举行的选举也有所不同，因为没人会惊讶地看到这种恶意活动。进入2016年，俄罗斯的网络活动受到一群目瞪口呆的naïveté的欢迎，导致瘫痪和不确定的反应。这次不行。

  

“差异确实归结于我们所知道的将要发生的事情，” Dallman解释说。

  

“然后，这几乎是个未知数，我们不确定战术将如何发展。现在我们知道了；我们已经看到了模式。您在2016年看到了他们，看到了他们在德国所做的事情，看到了他们在法国大选中的经历，所有这些都遵循相同的MO。同样在2018年期中考试中（程度较小），但我们仍然看到了一些相同的MO，相同的演员，相同的时间，相同的技术。现在我们知道，到2020年，这就是我们正在寻找的MO。现在我们开始看到其他国家出来并开始采取其他策略。”

  

新常态是，在政府紧随其后的情况下，行业网络情报商店往往在这种类型的公共安全活动中处于领先地位。

  

2016年，正是CrowdStrike进行了首次调查，并将矛头指向了旨在干扰美国大选的俄罗斯活动。美国执法和情报界后来证实了该公司的调查结果，并最终在罗伯特·穆勒（Robert Mueller）进行调查后，起诉了俄罗斯黑客并详细介绍了莫斯科的竞选活动。

  

微软的总规模超过1万亿美元，规模大一个数量级，为安全挑战带来了巨大的资源。科技巨头还有另一个巨大的优势：到处都有眼睛，耳朵和软件。就像兰伯特可能说的那样，那是它的超级大国。
