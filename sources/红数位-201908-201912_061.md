# 卡巴斯基全球透明度计划实施状态更新

美国国土安全部门雇员Reality Winner检举揭发，他说卡巴从自己电脑获取了敏感资料并外泄。随后，卡巴承认从扫描中拿到了Winner一些文件资料，但察觉到不对后便立即删除。

  

于是美国在2017年底通过2018财年国防授权法案(NDAA)，并由总统特朗普签署，其中将封禁卡巴斯基旗下的安全软件正式写入，直接上升到国家高度。

**于是卡巴斯基至此被美国佬直接封禁。**

**美国佬嘴里一直说卡巴斯基鼓吹自己的透明计划，到底是什么？  
**

**我们来一探究竟？！**

  

**卡巴斯基于2017年10月宣布了“ 全球透明度计划”。其目的：向世界展示卡巴斯基没有什么可隐瞒的，让他们的客户可以信任他们。他们也旨在证明这一点-不仅仅是寻求信任。**

  

![](../Images/d5760502c5622110994b1f2a5e96dd7d.png)

  

在过去的几年中，卡巴斯基一直受到许多错误指控的攻击。尽管没有提出任何事实来支持这些指控，但他们认为证明卡巴斯基实验室可以而且应该受到信任是他们的责任。信任他们是有根本原因的，这就是他们的全球透明度倡议的宗旨。

  

随着项目的成熟，卡巴斯基将更新此信息。

  

**最新更新：2019年11月13日**

前天，卡巴斯基宣布将于2020年1月在巴西圣保罗开幕的第四个透明中心。这将是卡巴斯基在拉丁美洲的第一个透明中心，紧随该公司在马德里和苏黎世的欧洲透明中心以及在赛城的亚太透明中心，马来西亚。新中心进一步体现了卡巴斯基致力于证明卡巴斯基是透明的并且可以迅速而彻底地解决任何安全问题的承诺。

  

卡巴斯基的数据存储和处理基础架构重定位正在进行中。将欧洲客户的数据迁移到瑞士之后，现在卡巴斯基也开始转移美国和加拿大的客户数据。卡巴斯基安全网络（KSN）自愿共享数据，这是卡巴斯基基于云的高级系统，可自动处理与网络威胁相关的数据。卡巴斯基预计将在2020年底之前完成这一阶段的迁移，并将稳步增加其他地区。

  

作为《巴黎网络空间信任与安全呼吁》的早期签署者，卡巴斯基很荣幸在2019年巴黎和平论坛上宣布这些步骤。

  

卡巴斯基的透明中心访客有机会了解更多有关工程和数据处理实践的信息，在卡巴斯基专家的帮助下，从其源代码中编译卡巴斯基的软件，并将其与公开的代码进行比较。卡巴斯基还将使用该中心来展示卡巴斯基的产品组合以及卡巴斯基的工程和数据处理实践。

  

**更新：2019年8月15日**

卡巴斯基很高兴地宣布，卡巴斯基的第三个透明中心将于2020年初在马来西亚赛城成立。就像卡巴斯基早先在苏黎世和马德里开设的商店一样，这个透明中心将成为合作伙伴和政府利益相关者可信赖的设施，在这里他们可以检查卡巴斯基产品的源代码。马来西亚的网络安全机构CyberSecurity Malaysia将主持此会议。

  

卡巴斯基的首席执行官尤金·卡巴斯基（Eugene Kaspersky）指出，该透明度中心是公司在亚太地区的第一个透明度中心，展示了卡巴斯基具有开创性的“全球透明度计划”，该计划旨在满足合作伙伴和政府利益相关者对卡巴斯基产品和技术如何运作的更多信息不断增长的需求。跟踪。

  

**更新：2019年7月11日**

卡巴斯基的第二个透明度中心于6月在马德里为卡巴斯基的客户和合作伙伴开业。卡巴斯基计划到2020年在全球至少建立三个透明中心。

  

但这还不是全部。卡巴斯基网络安全风险管理控制措施的第三方服务组织控制（SOC2 Type 1）审查已经完成，这是卡巴斯基全球透明度计划的重要组成部分。四大审计师之一审查了卡巴斯基对Windows和Unix Servers产品防病毒数据库的定期自动更新的控制，并得出结论认为，保护和开发这些数据库不受未经授权的更改。这再次证明卡巴斯基的产品是安全的并且可以信赖。根据合同条款，卡巴斯基可以根据要求向客户和监管机构披露该报告。

  

除此之外，卡巴斯基正在继续扩展Bug赏金计划，最近卡巴斯基加入了Disclose.io运动，这意味着卡巴斯基现在为研究卡巴斯基产品的漏洞研究人员提供了安全港，并保证不会采取任何法律行动。反对他们。您可以在卡巴斯基的博客文章中找到有关Disclose.io的更多信息。

  

**更新：2019年4月2日**

卡巴斯基的全球透明计划正在取得良好进展：今天，卡巴斯基宣布开设第二个透明中心。它将位于西班牙马德里，目的是提供有关卡巴斯基实验室产品和技术工作方式的更多信息。除此之外，新的中心还将充当一个简报中心，访客可以在其中了解卡巴斯基的产品组合，工程和数据处理实践。卡巴斯基预计该中心将于今年6月首次到访。计划在2020年在亚洲和北美开设透明中心。

  

卡巴斯基的数据处理基础架构的迁移也正在按计划进行。卡巴斯基已经将接收基础设施迁移到了瑞士，并计划在第二季度末完成存储部分的迁移。卡巴斯基希望在今年年底之前完成对欧洲客户的数据处理的全部重新安置。

  

除此之外，卡巴斯基还发布了对俄罗斯立法行为的自愿第三方法律评估结果以及这些法律如何应用于卡巴斯基实验室的结果。评估由瑞典乌普萨拉大学国际投资和贸易法教授，俄罗斯法律体系专家Kaj Hober博士进行。主要发现如下：

  

联邦安全局（FSB）可能会要求卡巴斯基实验室与之合作，但该公司没有义务这样做。

迫使供应商协助FSB开展运营调查活动的法律仅适用于提供电子通信服务的公司，而卡巴斯基实验室则不适用。

  

强迫公司将数据存储在俄罗斯并将其提供给FSB的加密密钥（用于解密）的法律仅适用于电信提供商，而卡巴斯基实验室不是电信公司。

  

最后但并非最不重要的一点是，卡巴斯基改进了卡巴斯基的Bug赏金计划，将Kaspersky Password Manager和Kaspersky Endpoint Security for Linux以及一些其他产品添加到了可供审查的软件范围内。到目前为止，已通过该程序发现并报告了50多个错误，研究人员因指出这些错误而获得了17,000多美元的赏金。

  

**更新：2018年11月13日**

卡巴斯基的第一个透明中心现已正式开放，使授权合作伙伴可以访问有关公司代码，软件更新和威胁检测规则的评论。

  

从今天开始，卡巴斯基还将在卡巴斯基位于苏黎世的两个世界级数据设施中处理欧洲卡巴斯基实验室产品的用户与卡巴斯基共享的恶意和可疑文件。

  

按照承诺，卡巴斯基实验室还与四大专业服务公司之一签约，根据SSAE 18标准对公司围绕威胁检测规则数据库的创建和分发的工程实践进行审核，以独立确认其遵守最高的行业安全惯例。

  

**更新：2018年8月29日**

卡巴斯基已经取得了很大的进步，已经实现了一项重大更改，将卡巴斯基的bug赏金提高到100,000美元。这有助于使卡巴斯基的产品更加安全可靠。在这一点上，卡巴斯基还启动了全球透明度倡议项目的下一阶段，安装了将卡巴斯基的用户数据处理移至欧洲所需的设备。

  

卡巴斯基实验室还与两家欧洲提供商Interxion和NTS签订了合同，以托管必要的新基础架构，以在2018年底之前在瑞士苏黎世收集，处理和存储客户数据，从而解决公共和私营部门利益相关者的担忧未经授权访问客户数据。数据处理和存储的重定位将从欧洲客户开始，其他国家也将随之而来。卡巴斯基计划在2019年第四季度完成对欧洲国家的全面搬迁。

  

**为什么选择瑞士？**

卡巴斯基选择地点的原因有很多。一方面，瑞士位于欧洲的心脏地带。另一方面，瑞士不是欧盟的一部分，这使其成为一个可以自行决定的独立国家。卡巴斯基还发现象征主义很吸引人：全球透明度倡议的主要原则之一就是表明卡巴斯基是独立的，因此没有比瑞士更好的起点了。

  

瑞士还以其高度创新和先进的IT环境以及对处理从当局收到的数据请求的严格规定而闻名。因此，卡巴斯基的客户数据将在世界上最安全的位置之一进行存储和处理。

  

**全球透明度倡议阶段**

卡巴斯基的全球透明度倡议的其他要素也正在制定中。

  

卡巴斯基正计划在瑞士开设第一个透明中心。目前正在设置中，一旦卡巴斯基准备开始在苏黎世数据中心中处理数据，它将被打开（计划于今年晚些时候进行）。\[更新：卡巴斯基在苏黎世和马德里开设了两个透明中心。\]

  

卡巴斯基也决心将其他国家/地区用于客户数据处理的设施也重新定位。这是一个非常复杂的过程，因此为了最大程度地减少保护客户的潜在干扰，卡巴斯基决定坚持采用渐进的方法。因此，在将欧洲公民的数据处理设施重新安置到瑞士之后，卡巴斯基将回到这一点。\[更新：搬迁过程已经开始，并将于2019年完成对欧洲公民的搬迁。\]

  

第三方代码和流程审核也将在重新安置之后进行；卡巴斯基正在寻找合适的合作伙伴。\[更新：四大审计师之一使用SOC 2 Type 1报告框架完成了审计。

  

卡巴斯基范围的另一部分是将软件和威胁检测规则数据库的组装过程移至瑞士。但是，解决对未经授权的用户数据访问的担忧是更高的优先级，因此，在卡巴斯基启动了数据重定位过程之后，此举就会发生。

  

对卡巴斯基来说，实施全球透明度计划是一个非常重要的过程。卡巴斯基绝对有信心，为证明卡巴斯基实验室完全透明，独立且有充分的理由值得信赖，必须花时间和精力进行这个冗长的项目。当卡巴斯基可以分享有关全球透明度计划正在进行的流程的更多新闻时，卡巴斯基将继续更新此博客以及卡巴斯基的透明度中心网站，以便每个人都可以在一个地方找到有关卡巴斯基与透明度相关的活动的信息。
