# Adobe在Illustrator中修补严重的远程执行代码错误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486630&idx=6&sn=06f552a304d1f729f705550dc21ca984&chksm=cef36115f984e803330ab43d54b277eaa25cbd4c55308176277f14bb5acd919307af2934b45e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486630&idx=6&sn=06f552a304d1f729f705550dc21ca984&chksm=cef36115f984e803330ab43d54b277eaa25cbd4c55308176277f14bb5acd919307af2934b45e&scene=27#wechat_redirect)

**![](../Images/533414f6c4ac61ba1231567613f86972.png)**

  

Adobe发布了安全更新，以解决安全问题，这些问题可能使攻击者能够远程执行恶意代码，提升特权，并获得对运行未修补Illustrator，Animate CC，Bridge CC和Media Encoder版本的系统上信息的未授权访问。

  

![](../Images/41a09b53d190aa780961e0396c04bc3e.png)

  

特别引起关注的是两个严重的内存损坏漏洞，这些漏洞导致在Adobe Illustator软件中发现远程代码执行，并跟踪为  CVE-2019-8247  和  CVE-2019-8248。

  

由于该程序被广泛使用，并且这些安全问题可能使攻击者能够在易受攻击的计算机上执行代码，因此Adobe强烈建议用户尽快进行更新以锁定潜在的利用尝试。

  

Fortinet的FortiGuard Labs的Kushal Arvind Shah报告了发现会影响Adobe Illustrator的两个RCE漏洞，而 nsfocus安全团队的Liu Yongjun Liu发现并报告了另一个被评为重要严重程度并跟踪为CVE-2019-7962的特权升级问题。

  

**以下是今天的Adobe安全更新：**

**APSB19-34 Adobe Animate CC的安全性更新已推出**

Adobe已发布Adobe Animate CC的安全更新，该更新解决了影响Windows版本的一个重要的严重漏洞。

  

APSB19-34更新解决了一个不安全的库加载（DLL劫持）漏洞，该漏洞可能导致特权提升。

  

跟踪为CVE-2019-7960的漏洞已在Adobe Animate CC 20.0中修复，并由nsfocus安全团队的Liu Yongjun报告。

  

**APSB19-36适用于Adobe Illustrator的安全更新**

Adobe已发布Adobe Illustrator的安全更新，该更新解决了影响Windows版本的几个重要和严重严重性漏洞。

  

APSB19-36更新修复了关键和重要漏洞，这些漏洞可能导致在当前用户的情况下特权升级和远程代码执行。

  

该漏洞已在Illustrator CC 2019 24.0中修复。

  

**APSB19-52适用于Adobe Media Encoder的安全更新**

Adobe已发布Adobe Media Encoder的安全更新，该更新解决了影响Windows和macOS版本的重要和严重严重性漏洞。

  

APSB19-52更新解决了多个文件解析漏洞。成功利用这些问题可能导致当前用户和任意代码执行情况下的信息泄露。

  

该漏洞已在Adobe Media Encoder 14.0中修复，并由趋势科技零日活动（CVE-2019-8241，CVE-2019-8243，CVE-2019-8244）的Mat Powell报告，Francis Provencher与趋势科技零日活动合作。 Initiative（CVE-2019-8242）和Qihoo 360 Core Security的Wen Guang Jiao（CVE-2019-8246）。

  

**APSB19-53适用于Adobe Bridge CC的安全更新**

Adobe已发布Adobe Bridge CC的安全更新，该更新解决了影响macOS和Windows版本的两个重要的严重漏洞。

  

APSB19-53更新解决了在解析格式错误的SVG图像时发生的多个漏洞，一旦成功利用，这些漏洞可能导致当前用户上下文中的信息泄露。

  

该安全问题已在Adobe Bridge CC 10.0中修复，并由Qihoo 360 Core Security的Wen Guang Jiao报告。
