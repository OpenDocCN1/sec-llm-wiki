# 美国土安全部和CISA警告美敦力医疗设备中严重漏洞问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486597&idx=4&sn=8d6eec393b22e63a437718f1b80cb08c&chksm=cef36136f984e820295e763c7d15316fb77265d47fdece8273474bb5da3ee2eae6ddfda591a8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486597&idx=4&sn=8d6eec393b22e63a437718f1b80cb08c&chksm=cef36136f984e820295e763c7d15316fb77265d47fdece8273474bb5da3ee2eae6ddfda591a8&scene=27#wechat_redirect)

**![](../Images/533414f6c4ac61ba1231567613f86972.png)**

  

国土安全部（DHS）警告，影响Medtronic Valleylab产品的严重漏洞可能使攻击者覆盖文件并实现远程代码执行。(**CVSS V3 9.8)**

详见报告：https://www.us-cert.gov/ics/advisories/icsma-19-311-02

  

![](../Images/8d96347770f2099933081d058e8a64a2.png)

  

国土安全部网络安全和基础设施安全局（CISA）发布的一份警告警告说，最近修复的Medtronic Valleylab FT10和FX8设备存在三个漏洞，这些漏洞可能允许攻击者安装非根外壳。

  

尽管默认情况下应禁用这些产品上的网络连接，并在重新启动后禁用以太网端口，但通常会启用网络连接，从而使它们容易受到攻击。

  

受影响的设备使用多组硬编码的凭据，如果暴露，则可能允许攻击者读取文件，CISA的建议是读取。这些漏洞中的第一个漏洞跟踪为CVE-2019-13543，基本得分为5.8。

  

还发现易受攻击的产品使用descrypt算法进行OS密码哈希处理。尽管基于网络的登录已禁用，但其他漏洞也可以用于获取本地Shell访问并获取这些哈希。该问题的跟踪记录为CVE-2019-13539，CVSS评分为7.0。

  

此外，在这些产品中使用的易受攻击的rssh实用程序版本可促进文件上传，这可能会使攻击者获得对文件的管理访问权限或执行任意代码。这些严重错误被跟踪为CVE-2019-3464和CVE-2019-3463，并具有9.8的CVSS评分。

  

该漏洞影响Valleylab Exchange Client 3.4及更低版本，Valleylab FT10能源平台（VLFT10GEN）软件版本4.0.0及以下，以及Valleylab FX8能源平台（VLFX8GEN）软件版本1.1.0及以下。

  

美敦力公司发布的安全补丁现已可用于FT10平台，预计将在2020年初针对FX8平台发布。

  

![](../Images/63ca2864fdc5bb7c81113fe01b279531.png)

  

“ Medtronic建议外科医生和护士继续按预期使用这些设备。客户应保持良好的网络安全习惯，只需在必要时将这些设备连接到医院网络，并在两次使用之间关闭它们，直到完成新软件更新为止。”医疗设备提供商说。

  

**CISA的忠告是，应该将易受攻击的产品与IP网络断开连接，或者将网络隔离，以确保无法从不受信任的网络访问设备。**

  

DHS还警告了另外两个漏洞会影响Valleylab FT10能源平台（VLFT10GEN）2.1.0及更低版本和2.0.3及更低版本，以及Valleylab LS10能源平台（VLLS10GEN）1.20.2及更低版本。

  

详见报告：https://www.us-cert.gov/ics/advisories/icsma-19-311-01

  

这些问题会影响这些设备的RFID安全机制，并可能使攻击者将不真实的仪器连接到受影响的产品。

  

CISA解释说：“由于不正确的仪器标识和相关参数，这可能会导致性能完整性和平台可用性的损失。”

  

已发现的漏洞跟踪为CVE-2019-13531（CVSS分数为4.8）和CVE-2019-13535（CVSS分数为4.6）。

  

已经针对所有受影响的设备发布了解决这两个缺陷的软件更新。

  

“ Medtronic建议外科医生和护士继续按预期使用这些电外科发生器和相关的LigaSure设备，并更新至最新软件版本。因为不真实的LigaSure设备的潜力，由发电机的认可，客户应该确保所有的LigaSure设备只能从美敦力公司购买或授权分销商美敦力公司，”该公司说。
