# 疑似朝鲜黑客拉撒路组织破坏了印度航天局月球飞行计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486597&idx=1&sn=0056a79520791042764a74d95ec13e4a&chksm=cef36136f984e82064ba7c3b397c07f73a7e6db9c392caa1466fa852516a3d50a09604eab84f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486597&idx=1&sn=0056a79520791042764a74d95ec13e4a&chksm=cef36136f984e82064ba7c3b397c07f73a7e6db9c392caa1466fa852516a3d50a09604eab84f&scene=27#wechat_redirect)

**![](../Images/533414f6c4ac61ba1231567613f86972.png)**

  

据《 Quint》报道，印度太空研究组织（ISRO）证实，他们在9月的Chandrayaan-2月球飞行任务期间，被朝鲜骇客警告，怀疑是网络攻击。

  

此前有报道称，印度位于泰米尔纳德邦的库丹库拉姆核电站是朝鲜网络攻击的受害者。

  

印度网络安全专家称，印度空间研究组织（ISRO）进行的雄心勃勃但注定要失败的登月任务Chandrayaan-2被朝鲜故意破坏了。但是，ISRO官员否认该任务是由于恶意软件攻击而失败的，并解释说其系统完全没有受到影响。

  

据信，臭名昭著的朝鲜黑客组织拉撒路（Lazarus）大约在印度空间研究组织试图将飞船送入月球的同时，袭击了ISRO的系统。具有讽刺意味的是，ISRO在2019年初收到有关可疑恶意软件攻击的警报，但该组织忽略了该警告，并没有采取任何具体步骤来减轻威胁。

  

![](../Images/eda24ac73e33fc4a663406f8d4cb2f43.png)

  

作为每一个报告从印度快报，在库丹库拉姆核电站（KNPP），泰米尔纳德邦也与印度空间研究组织的攻击一起。分析师评估认为，攻击是通过发送给高级官员的网络钓鱼电子邮件发起的。该威胁已由印度计算机紧急响应小组（CERT-In）确认，但是，尽管ISRO发出通知，仍未对付该威胁。

  

[印度核电公司(NPCIL)官方证实：Kudankulam核电站的确感染了朝鲜Dtrack变种恶意软件](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486214&idx=1&sn=18665bf3fb2470452544e862046275a6&chksm=cef366b5f984efa30c9bbcb49cec2d4edf127b7c0d5e2328fc92bd339a8f9965258c70d2bdb4&scene=21#wechat_redirect)  

  

![](../Images/87a4608634db54c94a9bc7be5cdd531a.png)

  

印度网络安全公司Security Bridge的创始人Yash Kadakia 告诉英国《金融时报》，电子邮件中装有恶意软件，并已发送给至少五个政府机构，包括KNPP和ISRO。 

  

*卡卡迪亚（Kakadia）透露：**“他们用含有与其主题相关的恶意软件附件的电子邮件来攻击高级官员，”他补充说，如果安装成功，恶意软件很容易劫持电子邮件ID，黑客可能会使用该ID发送更多电子邮件。*

  

  

显然，**ISRO员工打开了由朝鲜黑客发送的受感染电子邮件，并在其系统上安装了恶意软件。**

“我们知道他们是针对性的，他们知道了链接，然后单击了链接。到目前为止，我们可以证实的事情就很多了。”

  

根据安全桥（Security Bridge）从犯罪嫌疑人入侵的服务器中获得的信息，已经确认来自五个政府机构的至少13位收件人已从一台相关服务器发送了网络钓鱼电子邮件。尽管该服务器不是在朝鲜托管，但仍被用于这些攻击。

  

“我们确实有目标ISRO科学家的电子邮件地址，但尚未公开披露该信息。我们已经与国家关键信息基础设施保护中心（NCIIPC）共享了该文件，以便他们可以对其进行调查和调查。”

  

但是，卡达基亚（Kadakia）澄清说，他不确定是否成功执行了网络钓鱼恶意软件，以及ISRO官员是否正在使用公司的官方设备，个人电话或家用笔记本电脑来访问邮件。

  

网络安全专家还声称，Lazarus黑客使用DTrack恶意软件攻击了政府组织，DTrack恶意软件与Lazarus紧密相关，Lazarus是一个为朝鲜政府服务的组织。

  

这不是Lazarus黑客被第一次指控如此大规模的恶意软件攻击。在2018年，这个臭名昭著的组织被指控针对银行和其他金融巨头窃取比特币。
