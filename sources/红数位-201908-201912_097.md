# 威联通群晖(QNAP)官方警告用户确保设备免受QSnatch恶意软件侵害

[群晖用户注意！QSnatch恶意软件感染了数千个NAS设备，窃取了凭证](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486263&idx=2&sn=e4cfdda0a51c4c98c72700a8b356e0fb&chksm=cef36684f984ef92650b6a6feed262eea732b3b6b6eb9904c479f9bd2f5fd1311e55bf20510e&scene=21#wechat_redirect)  

  

网络存储（NAS）制造商威联通QNAP官方也开始行动了。

他们敦促客户保护其NAS设备，使其免受正在进行的恶意活动的攻击，该活动利用能够窃取用户凭据的QSnatch恶意软件对其进行感染。

  

![](../Images/7299a3d9da280f2c4f8b7ad2647b6c1b.png)

  

**QNAP建议用户尽快为该公司的NAS设备上运行的QTS操作系统安装最新版本的Malware Remover应用程序。**

  

在公司于11月1日更新了新规则之后，Malware Remover 3.5.4.0和4.5.4.0版本现在可以删除QSnatch。

  

“用户务必安装最新版本从QTS应用中心或通过手动下载恶意软件卸妆应用程序的QNAP网站，” 说 QNAP。

  

“建议用户采取安全通报中列出的措施，或者，联系QNAP寻求技术帮助。有关创建支持请求的说明，请参见此处：https://www.qnap.com/go/support-ticket/”

  

**QNAP NAS设备受到攻击**

芬兰国家网络安全中心（NCSC-FI）的研究人员于10月下旬发现，  感染QSnatch的数千台QNAP NAS设备的固件中注入了恶意代码。

  

**该恶意软件收集并泄露在受感染的NAS设备上找到的用户凭据，并且还能够加载从其命令和控制（C2）服务器检索到的恶意代码。**

  

**德国计算机紧急响应小组（CERT-Bund）说在德国大约7000 NAS设备是由QSnatch感染。**

  

NCSC-FI发现，在感染阶段，QSnatch被注入到QNAP NAS设备的固件中，恶意代码“作为设备内正常操作的一部分运行”。

  

**感染固件后，设备受到威胁，恶意软件使用“域生成算法从C2服务器检索更多恶意代码”。**

  

它从C2服务器下载的有效负载将在具有系统权限的受感染QNAP NAS设备上启动，并将执行以下操作：

  

*   修改了操作系统定时作业和脚本（cronjob，init脚本）
    
*   通过完全覆盖更新源来阻止固件更新
    
*   阻止了QNAP MalwareRemover App运行
    
*   检索了与设备相关的所有用户名和密码，并将其发送到C2服务器
    
*   恶意软件具有模块化功能，可以从C2服务器加载新功能以进行进一步的活动
    
*   将对C2服务器的回拨活动设置为以设置的间隔运行
    

  

**保护您的QNAP NAS**

  

威联通（QNAP）建议用户采取以下措施防御感染：

*   将QTS更新到最新版本。
    
*   安装安全顾问并将其更新为最新版本。
    
*   使用更强的管理员密码。
    
*   启用IP和账户访问保护以防止暴力攻击。
    
*   如果不使用这些服务，请禁用SSH和Telnet连接。
    
*   避免使用默认端口号443和8080。
    

  

该公司还提供有关如何更改设备密码，启用IP和帐户访问保护，禁用SSH和Telnet连接以及更改系统端口号的详细操作过程：https://www.qnap.com/en/security-advisory/nas-201911-01

  

这是不是第一次QNAP的NAS设备已被围困在公司发出安全公告在10月初期SQL服务器弱密码和运行phpMyAdmin的设备被攻击Muhstik勒索。

  

关于 以弱密码和过时的QTS固件为目标的QNAP NAS设备的  eCh0raix勒索软件（也称为QNAPCrypt）活动的另一份公告于8月发布。一周前，勒索软件专家BloodDolly  在BleepingComputer支持主题中针对某些变体发布了eCh0raix解密器。

  

在2018年5月，威联通还向其客户通知了  正在进行的VPNFilter恶意软件攻击，试图使用默认管理员帐户密码或运行QTS 4.2.6 build 20170628、4.3.3 build 20170703和更早版本来感染NAS设备。
