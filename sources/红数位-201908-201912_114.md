# Firefox 被曝安全漏洞：攻击者使用此Firefox错误锁定屏幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486474&idx=6&sn=904c600e4038c79b9476a65d6f0023ff&chksm=cef361b9f984e8af3de611c605474d61b3ad5f37b0cd8b0f3fc563b775b3c59066d496d4b8cb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486474&idx=6&sn=904c600e4038c79b9476a65d6f0023ff&chksm=cef361b9f984e8af3de611c605474d61b3ad5f37b0cd8b0f3fc563b775b3c59066d496d4b8cb&scene=27#wechat_redirect)

![](../Images/533414f6c4ac61ba1231567613f86972.png)

  

技术支持诈骗者正在积极利用Firefox浏览器锁定（browlock）错误，诱使潜在受害者在5分钟内致电假冒的Windows支持热线，以避免系统被禁用。

  

![](../Images/e2ef257856fc5daf8cebec6cf32294d5.png)

  

该错误使骗子可以锁定目标的浏览器，从而阻止他们关闭显示技术支持欺诈页面的浏览器选项卡。

  

这是通过向他们发送大量授权确认提示来进行的，因为没有防止它的速率限制，并且是从主页上窃取了焦点。

  

要控制Firefox并消除浏览器锁定，您将必须  使用Windows任务管理器终止  与Web浏览器关联的过程。

  

下面嵌入了Malwarebytes威胁情报研究员JérômeSegura发现的技术支持骗局网站的视频演示。

  

📹 [https://mp.weixin.qq.com/mp/readtemplate?t=pages/video\_player\_tmpl&action=mpvideo&auto=0&vid=wxv\_1064882080502398976](https://mp.weixin.qq.com/mp/readtemplate?t=pages/video_player_tmpl&action=mpvideo&auto=0&vid=wxv_1064882080502398976)

  

Segura表示，这是针对6月份发布的类似Firefox错误的修复程序的变通办法，该bug  允许页面显示所需数量的登录弹出窗口，从而导致浏览器选项卡被锁定。

  

根据Mozilla的PaulZühlcke所说，该漏洞是在三个月前发现的，它影响到Firefox 70.x Stable，71.x Beta和72.x Nightly。

  

Zühlcke当前正在研究一个修补程序  ，该修补程序将在将来的Firefox版本中提供，并阻止诈骗者锁定受害者的Web浏览器。

  

**技术支持骗局滥用新错误**

Segura发现的骗子在积极利用新的Firefox浏览器时正试图通过在锁定浏览器的无数身份验证弹出窗口后面显示以下消息来吓victims受害者，称其为“支持专线”：

  

*   不要忽视这一重要警告
    
*   请停止并且不要关闭电脑
    
*   您的计算机的注册表项被锁定。
    
*   为什么我们阻止您的计算机？
    
*   Windows注册表项是非法的。
    
*   该Windows桌面正在使用盗版软件。
    
*   该Windows桌面通过Internet发送病毒。
    
*   该Windows桌面被黑客入侵。
    
*   为了您的安全，我们封锁了这台计算机。
    
*   请在5分钟内致电给我们，以防止您的计算机被禁用。
    

  

  

尽管他们的信息显然是胡言乱语，旨在吓their目标，并且对于大多数到达其欺诈页面的人来说可能不起作用，但有些人会被欺骗，并会向他们求助。

  

为了阻止浏览器，骗子在昨天报告问题时使用与Firefox团队共享的Segura代码利用此错误。

**Browlocks和技术支持骗局齐头并进**

密码锁阻止网络浏览器的用户执行某些操作，例如打开新的标签页或窗口，浏览到另一个网站，甚至无法访问桌面。

  

这种类型的问题也影响了  Chrome用户  在过去，但Firefox browlocks的报告在技术支持诈骗活动正在积极地利用了很多更为普遍。

  

技术支持诈骗者使用各种方法来接近目标，将假冒广告植入Google搜索结果中并设计为  模仿合法的eBay广告，然后重定向到技术支持诈骗网站，这些网站还将尝试锁定其浏览器，而不是加载eBay拍卖网站。

  

在2018年12月，骗子使用JavaScript创建了一个不可避免的循环，该循环将占用  所有CPU资源，从而使用户无法在不杀死Chrome进程的情况下关闭选项卡，Web浏览器甚至计算机。
