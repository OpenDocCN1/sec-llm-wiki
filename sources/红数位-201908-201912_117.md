# 华为呼吁黑客前往慕尼黑参加秘密漏洞悬赏会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486437&idx=7&sn=8da4dab64ef00c299ebe2fd3201420df&chksm=cef36656f984ef40979af99628fd68f12ac5d4bd11401b90a5d59a0fa0d4ffa3d54c56aaeb62&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486437&idx=7&sn=8da4dab64ef00c299ebe2fd3201420df&chksm=cef36656f984ef40979af99628fd68f12ac5d4bd11401b90a5d59a0fa0d4ffa3d54c56aaeb62&scene=27#wechat_redirect)

![](../Images/533414f6c4ac61ba1231567613f86972.png)

  

中国科技巨头华为已邀请世界上最好的手机黑客参加本月晚些时候在慕尼黑举行的秘密会议，因为该公司试图受到全球政府的青睐。

  

![](../Images/4ad9dee6fa664c403213df06808f87b9.png)

  

知情人士在11月16日的会议上说，华为将私下提出其新的漏洞赏金计划，该计划将使研究人员可以通过提交安全漏洞获得经济奖励。消息人士称，漏洞赏金将集中在过去和未来的移动设备上，以及新的移动操作系统华为的竞争对手HarmonyOS上。

  

其他电话制造商，包括苹果，谷歌和三星，也有漏洞悬赏。

  

此举是在华为与中国政府的联系面临越来越大的压力之时。华为否认了美国主导的说法，即可能被迫代表北京进行间谍活动。但这并没有阻止联邦政府对在美国开展业务施加制裁和障碍。这种压力导致谷歌等公司停止了对Android的支持，而华为正是依靠Android为其手机提供支持，从而促使这家科技巨头找到或制造替代产品。

  

一位消息人士称，该事件与苹果公司 8月份举行的一次秘密会议相似，当时苹果公司将其最受尊敬的安全研究人员专用的“开发” iPhone交给了黑客，以发现安全漏洞。

  

![](../Images/234eecd338c68d7dc4c177d7ea58d5de.png)

  

消息人士称，华为的漏洞赏金会议可能是向政府表明它愿意与黑客和安全研究人员合作以增强其产品安全性的一种方式。

  

华为还生产用于电信网络的网络设备，由于在试图证明其技术不会对国家安全构成威胁时未能解决其软件中的“严重和系统性缺陷”，因此今年初遭到英国当局的抨击。。

  

华为发言人蔡斯·斯金纳（Chase Skinner）没有回应置评请求。
