# 全球首个BlueKeep大规模黑客攻击来袭！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486369&idx=1&sn=1f506128095cd42a127c11430ae1e7cd&chksm=cef36612f984ef04c7b6f114e114a4744001ae5077da15678aff62037573358c735588870197&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486369&idx=1&sn=1f506128095cd42a127c11430ae1e7cd&chksm=cef36612f984ef04c7b6f114e114a4744001ae5077da15678aff62037573358c735588870197&scene=27#wechat_redirect)

  

**![](../Images/533414f6c4ac61ba1231567613f86972.png)**

  

网络安全研究人员发现了一种新的网络攻击，**这被认为是头一次，但却是业余尝试，它在野外以臭名昭著的BlueKeep RDP漏洞为武器，以大规模破坏易受攻击的系统来进行加密货币挖掘。**

![](../Images/ff3ac51474067ded5cf85568f25daaed.png)

红数位制作配图  

  

今年5月，Microsoft 在其Windows远程桌面服务中发布了针对高度关键的远程代码执行漏洞的补丁，称为**BlueKeep**，可以通过仅通过RDP发送经特殊设计的请求来对其进行远程利用，以完全控制易受攻击的系统。

  

**BlueKeep跟踪为CVE-2019-0708，是一个可感染蠕虫的漏洞，因为它可以被潜在的恶意软件武器化，以自动将自身从一台易受攻击的计算机传播到另一台计算机，而无需受害者进行交互。**

  

自从发现BlueKeep以来，它就被认为是一种严重的威胁，以至于微软甚至政府机构\[ NSA和GCHQ \]都一直在鼓励Windows用户和管理员在黑客无法掌握其系统之前应用安全补丁。

  

甚至许多成功开发了BlueKeep漏洞利用程序的安全公司和个人网络安全研究人员也保证不会为了更大的利益而将其发布给公众，尤其是因为即使在发布补丁程序一个月后，仍有近100万个系统易受攻击。

  

**这就是为什么业余黑客花了近六个月的时间才开发出BlueKeep漏洞的方法，该漏洞仍然不可靠，甚至没有可感染的组件。**

  

![](../Images/6cd09f8a5acb948e53da067fb6bf2162.png)

  

一个黑客组织一直在使用Metasploit团队在9月份发布的演示BlueKeep漏洞，以入侵未打补丁的Windows系统并安装加密货币矿工。

  

这场BlueKeep活动已经进行了将近两个星期，但直到今天才被网络安全专家Kevin Beaumont发现。

这位英国安全专家说，他在几个月前建立并忘记了的蜜罐记录的日志中发现了这些漏洞。**博蒙特说：****首次袭击事件可追溯到10月23日。**  

  

  

**安全研究员Marcus“ MalwareTech” Hutchins 证实了Beaumont的发现，他阻止了WannaCry勒索软件的爆发，并且是BlueKeep漏洞利用的公认专家。**

  

**BlueKeep Exploit传播加密货币恶意软件**

凯文·博蒙特（Kevin Beaumont）在周六 首次推测了他在野外对BlueKeep的开发，当时他的多个EternalPot RDP蜜罐系统崩溃并突然重启。

  

![](../Images/43989cbec6b3172f596a56455e512fc3.png)

  

![](../Images/abeda70a2f072c8d51d0e5a1186c4cad.png)

  

  

![](../Images/781379bda8fc4f7494bd1b0e9122cea1.png)

  

![](../Images/c065695f4b1e70e9bcff757ae3ddf4df.png)

  

研究人员马库斯·哈钦斯（Marcus Hutchins）帮助阻止了2017年WannaCry勒索软件的爆发，然后分析了博蒙特共享的崩溃转储，并确认“内存和Shellcode中的BlueKeep工件丢弃了Monero Miner”。

  

![](../Images/706daffe7d546d98e59d21623b23aba5.png)

  

![](../Images/732a91b4fe91d0477a3763f209847384.png)

  

Hutchins 在今天发表的博客文章中说：“最后，我们确认\[崩溃转储中的\]此段指向可执行的shellcode。在这一点上，我们可以在野外断言有效的BlueKeep漏洞利用尝试，甚至可以与shellcode匹配。BlueKeep Metasploit模块中的shellcode！”

  

![](../Images/720f32230bda89406954920e50a1981c.png)

  

  

该漏洞利用包含编码的PowerShell命令作为初始有效负载，然后最终从远程攻击者控制的服务器下载最终的恶意可执行二进制文件并在目标系统上执行。

  

![](../Images/4a0700c7af9b56387c1cc9d796f2ecb2.png)

Bluekeep蠕虫RDP漏洞

  

根据Google的VirusTotal恶意软件扫描服务，恶意二进制文件是加密货币恶意软件，它利用受感染系统的计算能力挖掘Monero（XMR），从而为攻击者创造收入。

  

![](../Images/440f9c03c32cbc21d84e8120377e9dab.png)

  

**博蒙特发现的攻击远不及微软在5月份所担心的攻击规模，当时微软将BlueKeep比作EternalBlue，这是WannaCry，NotPetya和Bad Rabbit勒索软件在2017年爆发的核心漏洞。**

  

但是，最初的大规模黑客攻击活动并未包括自我传播的蠕虫般的功能。取而代之的是，**黑客似乎在搜索Windows系统，并在Internet上暴露了RDP端口，并部署了BlueKeep Metasploit攻击，后来又使用了加密货币矿工。**

  

但是这些特定的BlueKeep攻击似乎无效。博蒙特说，攻击使他正在运行的11个蜜罐中的10个坠毁。

  

这表明攻击者的利用代码无法按预期工作。

  

这与过去几个月中大多数专家对BlueKeep所说的完全吻合。BlueKeep漏洞可能会带来灾难性的后果，但是要使漏洞无法正常工作，而又不会因蓝屏死机（BSOD）错误导致操作系统崩溃而很难工作。

  

这些攻击在Beaumont的蜜罐基础设施上产生了超过2600万起事件，这使得确定危害的指标更加耗时。但是，研究人员答应对它们进行排序以找到相关序列并提供数据。

  

![](../Images/54ef1007b32d1e7074f179819c6fabf1.png)

资料来源：Kevin Beaumont

  

今天，我们从这个威胁参与者那里看到的是第一个黑客组织，该组织正试图在大规模行动中而不是在特定目标上为这种危险利用提供武器。

  

但是我们还意识到，其他黑客已将BlueKeep用于更具针对性的攻击中，并成功使用了它。

  

在将来的某个时刻，一些低技能的威胁参与者将弄清楚如何正确运行BlueKeep，这就是我们将看到它得到更广泛使用的时候。很有可能它仍将被用于挖掘加密货币-如今EternalBlue也经常使用该东西。

  

![](../Images/e747b200493c44bfd43a409ca58bbd72.png)

  

**但这不是蠕虫攻击！暂无传播性！**

Hutchins还确认，通过BlueKeep漏洞传播的恶意软件不包含任何自动传播功能，可以自动从一台计算机跳到另一台计算机。

  

取而代之的是，未知的攻击者似乎首先在Internet上扫描以找到易受攻击的系统，然后再利用它们。

  

换句话说，如果没有可感染蠕虫的组件，攻击者将只能攻击直接连接到Internet的易受攻击的系统，而不能攻击内部连接且可从其访问的系统。

  

**尽管经验丰富的黑客可能已经在利用BlueKeep漏洞来隐秘地解决目标受害者，但幸运的是，该漏洞尚未得到更大规模的利用，例如WannaCry或NotPetya。最初推测的可蠕虫攻击。**

  

**但是，在撰写本文时，目前尚不清楚在最新的网络攻击中有多少BlueKeep易受攻击的Windows系统受到了攻击，以在野外部署Monero矿机。**

  

**VirusTotal将这个二进制文件的哈希称为加密货币矿工。**

  

![](../Images/64245fc1c7c4139e6f5fc5a290abb0ce.png)

它被发布来帮助系统管理员测试易受攻击的系统，但是它也可以被恶意参与者重新利用。自6月以来，由网络安全公司开发的其他数十种私人攻击也已存在，但为了避免帮助攻击者，将其保密。

**简短的BlueKeep历史**

BlueKeep（CVE-2019-0708）是一个严重的漏洞，可以允许恶意软件在连接的系统中传播，而无需用户干预。微软在5月14日对其进行了修补，随后，来自政府和安全公司的大量警报对其进行了警告，其中一些人重申了他们的关注。

  

利用此RDP缺陷进行远程代码执行（RCE）并不容易，并且这种尝试的最常见结果是目标系统崩溃。创建工作漏洞的安全研究人员将细节保密，  以延迟攻击者创建其版本并破坏仍未打补丁的系统。

  

分别在6月和7月开发了两个私有漏洞利用模块，用于Metasploit  和CANVAS  渗透测试工具。两者都很难获得，因为前者是私人的，而后者则交付给了至少支付32,480美元的订户。

  

在企业级别，6月份的全球更新率为83％。但是，此统计数据不包括消费类计算机。这表明网络犯罪分子可能正在打击消费计算机。

  

该漏洞并不影响Windows操作系统的所有版本。Microsoft的通报列出了Windows 7，Windows Server 2008 R2和Windows Server 2008。
