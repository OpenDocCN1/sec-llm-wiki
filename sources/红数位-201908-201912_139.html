两个Chrome零日正在积极被野外利用攻击，立即更新你的Chrome！

昨天，在万圣节之夜，Google工程师得到的礼物是当晚的最大恐慌，他们紧急发布了针对Chrome浏览器的紧急更新，以修补被积极利用的零日漏洞。



漏洞跟踪为CVE-2019-13720和CVE-2019-13721，分别位于Chrome的音频组件和PDFium库中：

[$ 7500] [ 1013868 ] 高 CVE-2019-13721：PDFium中的免费使用。banananapenguin在2019-10-12上报

[$ TBD] [ 1019226 ] 高 CVE-2019-13720：音频后释放后使用。卡巴斯基实验室的Anton Ivanov和Alexey Kulaev于2019-10-29上报


Google称已经知道存在针对CVE-2019-13720的漏洞正被积极利用，Google工程师在博客中宣布发布最新的v78.0.3904.87版本。


正在积极被利用的零日漏洞被描述为Chrome音频组件中的一种无使用错误的错误。


释放后使用漏洞是当应用程序尝试引用先前分配给它但已被释放或删除的内存时发生的内存损坏错误。这通常会导致程序崩溃，但有时也可能导致其他意想不到的后果，例如代码执行方案。


该漏洞已被利用来在与先前与朝韩相关的攻击具有相似性的活动中传播恶意软件。

Google感谢卡巴斯基的两位恶意软件研究人员Anton Ivanov和Alexey Kulaev报告了此问题。根据这篇文章发表后发表的博客文章，卡巴斯基表示，零日漏洞被用来在用户设备上安装恶意软件。


它已通过朝鲜语新闻门户网站部署在用户设备上。卡巴斯基表示，尽管与过去的朝鲜恶意软件存在一些代码相似性，但它无法将零日使用率与特定的黑客组织联系起来。该公司正在使用代号“ Operation WizardOpium”来跟踪这些攻击。


根据卡巴斯基的说法，零日活动已被称为“ Operation WizardOpium”行动利用。该公司表示，尚未找到任何证据可以使它与已知的威胁因素有信心地联系起来。


但是，一些“非常弱的代码相似性”表明可能与拉萨鲁斯集团有联系，拉萨鲁斯集团是与朝鲜有联系的威胁者。另一方面，研究人员认为，这些代码相似之处可能是错误的标志，意在使归因更加困难。


卡巴斯基说，黑客所针对的网站之一使人想起了归因于DarkHotel的早期攻击，DarkHotel是一个威胁组织，已知针对的是对朝鲜感兴趣的实体，有人认为这可能是由韩国赞助的。


卡巴斯基在博客中说：“目标网站的配置与最近部署了类似虚假标志攻击的早期DarkHotel攻击更加吻合。”


据该网络安全公司称，作为水坑攻击的一部分，攻击者破坏了一家韩国新闻网站，并滥用该网站通过Chrome零日漏洞传播恶意软件。受感染的网站会加载脚本，这些脚本旨在检查访问者的浏览器和操作系统，以确定是否可以利用Chrome漏洞执行任意代码。


如果漏洞利用成功，则将伪装成无害.jpg文件的加密有效载荷发送给受害者。然后，对有效负载进行解密，并删除并运行可执行文件。


卡巴斯基仅分享了有关该恶意软件的有限信息，但透露它利用Windows Task Scheduler来实现持久性，其主要模块旨在从命令和控制（C＆C）服务器下载其他模块。


除零日外，最新的Chrome更新还修复了CVE-2019-13721，该问题是PDFium组件中的一个严重的无使用后使用问题。一位研究人员于10月12日向Google报告了此漏洞，该黑客使用在线绰号banananapenguin，并为黑客赢得了7,500美元的赏金。


这是今年第二次检测到Chrome零日。早在3月，Google修补了另一个Chrome零日（Chrome 72.0.3626.121中的CVE-2019-5786），当时它与Windows 7零日（CVE-2019-0859）一起使用，于4月修复。星期二更新）。卡巴斯基在4月份表示，这两个漏洞利用程序都被尚未命名的APT（一个用来描述民族国家黑客组织的术语）一起使用。


Chrome 78.0.3904.87适用于Windows，Mac和Linux。该版本将在未来几周内逐步向所有Chrome用户推出，但用户可以立即访问浏览器的“ 帮助”>“关于Google Chrome”部分来触发手动更新。
