微软警告多个Windows版本会由于永久性内存而导致启动缓慢

原文：http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490889&idx=8&sn=c48ecf99703673b7226c8c0251680d65&chksm=cef370faf984f9ecdc9cf68a6166f5dae47d8bfdc2116dc2cc09f2703dd4c1c726167afdeb8a&scene=27#wechat_redirect


微软在10月30日承认了Windows设备上的一个新错误，但是这次对个人来说好消息是它们没有受到影响。

他们在支持文档中警告说，如果使用永久性内存内存，则某些计算机的启动速度可能会很慢。



永久性内存官方普及贴：

https://docs.microsoft.com/zh-cn/windows-server/storage/storage-spaces/deploy-pmem



“将基于Windows的计算机配置为使用大量内存（包括持久性内存）后，计算机花费的时间比预期的启动时间长。此外，启动后短时间内会增加CPU使用率。当应用程序快速连续释放并重新分配大范围的内存时，CPU使用率就会增加。




该公司补充说，这都是一个已知问题，以后的更新将包括针对启动程序的其他优化措施，以解决此问题。


受影响的Windows版本

如前所述，Windows 10消费者版本不受此错误影响，微软表示可以确认以下Windows版本可能会遇到启动缓慢的问题：


  • Windows Server IoT 2019标准版

  • Windows Server IoT 2019数据中心

  • Windows Server 2019标准版

  • Windows Server 2019数据中心

  • Windows Server 2016标准版

  • Windows Server 2016数据中心

  • Windows 10 服务器数据中心


Microsoft解释说，仅当在内存模式下使用持久性内存时才会触发该错误，因为当将此功能设置为存储设备时，在正常的系统启动时间，一切似乎都可以正常工作。


“永久内存用于Windows客户端和Windows服务器。如果将系统配置为使用大量内存（包括持久性内存），则需要额外的启动时间。在重新启动过程中以及在运行时释放内存期间，系统必须先清除所有物理内存，然后才能使用该内存。”


目前，尚无关于何时可以发送修补程序的其他信息，但是目前，既然微软发布警告，有限数量的设备受到影响是是肯定的。
