# Uber优步曾为掩盖数据泄露支付10万美元20岁的佛罗里达黑客认罪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486263&idx=4&sn=a5c78bdde6c6c083f27b4739de3dc1cf&chksm=cef36684f984ef924ccace49c2916881b0ee8ec569f9ca8b57300bc7f7871a9b9a76bcfee401&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486263&idx=4&sn=a5c78bdde6c6c083f27b4739de3dc1cf&chksm=cef36684f984ef924ccace49c2916881b0ee8ec569f9ca8b57300bc7f7871a9b9a76bcfee401&scene=27#wechat_redirect)

****![](../Images/533414f6c4ac61ba1231567613f86972.png)****

**两名戴着灰色帽子的黑客认罪**，勒索Uber优步，LinkedIn和其他美国公司以勒索金钱，以换取承诺删除他们在2016年底盗窃的数百万客户数据的承诺。

  

![](../Images/726f40f4dc43760ebfda714ffa22336b.png)

  

周三，在加利福尼亚州圣何塞法院，布兰登·查尔斯·格洛弗（Brandon Charles Glover）佛罗里达（26）和多伦多的Vasile Mereacre（23）承认他们使用被盗凭证访问并下载了Amazon Web Services上的机密公司数据库。

  

根据美国司法部发布的新闻稿，在下载数据后，两人联系了受影响的公司以报告安全漏洞，并要求资金以删除数据。

  

黑客在一封电子邮件中对受害者公司说：“我能够在备份时访问备份，我和我的团队希望为此获得丰厚的回报。”

  

“请记住，我们期望获得一笔大笔付款，因为这对我们来说是一项艰苦的工作，我们已经帮助了一家支付近7位数字的大公司，一切进展顺利。”

  

正如两年前《黑客新闻》报道的那样，黑客设法不当访问和下载了5700万名Uber骑手和驾驶员的敏感信息，据报道，**Uber向二人支付了100,000美元的比特币，以掩盖该漏洞。**

  

![](../Images/62c090135cc901751a60cd5732841408.png)

  

*起诉书中写道：**“被告使用虚假名字与受害者公司进行通信，并多次告知受害者公司，其他受害者公司已向他们支付了费用，以确认安全漏洞。**”*  

  

*“他们还向受害者公司发送了数据样本，以便受害者公司验证数据的真实性。**”*

  

起诉书还显示，**二人于2016年12月以同样的方式勒索LinkedIn，告知该公司他们已经破坏了LinkedIn子公司Lynda.com的数据库并窃取了超过90,000条用户记录，包括其信用卡信息。**

  

当时，据报道，Uber派出分析专家小组前往佛罗里达和加拿大的黑客之家，分析他们的计算机，以确保所有被盗的数据都已被擦除，并让黑客还签署了保密协议以防止进一步的不法行为。

  

**Uber等了一年才揭露2016年10月的数据泄露事件，后来被所有50个州和哥伦比亚特区的司法部长下令，在所有50个州和华盛顿特区支付1.48亿美元以解决调查。**  

![](../Images/e68408d24216baa479d516f701442314.png)

  

**英国和荷兰的数据保护监管机构也因在2016年网络攻击中未能保护其客户的个人信息而对该乘车公司处以总计约110万美元的罚款。**

  

当时也有报道称，Uber隐藏了美国联邦贸易委员会（FTC）的数据泄露事件，该事件正在调查针对该公司的另一起黑客事件，并且仅在2017年末向该委员会通报了2016年的数据泄露事件也被公开。

  

**格洛弗和梅里亚克雷均对一项串谋勒索罪名认罪，当他们被判刑时将面临最高五年的监禁和25万美元的罚款。**

  

两人已被释放保释，将于2020年3月被判刑。
