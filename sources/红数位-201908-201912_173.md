# 美司法部官员称美中贸易谈判进展不会影响美对涉华间谍案的调查

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490890&idx=3&sn=84a65dd809e58f1c7f8d1a36c852ac65&chksm=cef370f9f984f9ef913f8850e74616aa1e58d948607b91aa7d4a196cbfb567eff70e42b8859c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490890&idx=3&sn=84a65dd809e58f1c7f8d1a36c852ac65&chksm=cef370f9f984f9ef913f8850e74616aa1e58d948607b91aa7d4a196cbfb567eff70e42b8859c&scene=27#wechat_redirect)

10月24日，美国司法部助理部长、该部涉华案件工作组负责人约翰.德莫斯（John Demers）在当日的CyberTalks会议上表示，美司法部将继续彻底调查与中国有关的间谍案件，而不会受美中两国贸易谈判进展的影响。他表示他个人不会妥协，美司法部正在开展的涉华案件调查活动也不会与美中两国在贸易领域的谈判联系在一起；即便是两国最终达成贸易协议，美司法部也不会撤销这些案件，“除非中国真正停止针对美国知识产权的盗窃行为”。特朗普政府一直被外界批评其在与他国交往时没有严格地区分国家安全、贸易、国内政治、总统家族生意等概念。  

  

德莫斯本人在2016年曾参加美国总统选举，他在被特朗普任命为美司法部国家安全处（National Security Division）负责人之前，曾在波音等机构从事法务工作，并曾担任美国最高法院法官安东尼.斯卡利亚（Antonin Scalia）的书记官。德莫斯在2018年2月掌管美司法部国家安全处之后，该部门启动了若干起针对中国公民和美籍华人的间谍案件调查，去年该部门还与美国商务部合作，以“窃取美国企业的知识产权”为由将中国企业福建晋华集成电路有限公司列入实体清单，德莫斯认为这个措施将令晋华公司“无法利用其窃取自美国美光公司（Micron）的商业秘密来生产芯片”。

  

德莫斯认为，针对晋华公司的制裁案是美国政府与私营企业合作应对“中国商业间谍活动”的重要例子，因为私营企业往往是最早发现自己的网络遭到入侵或雇员出现问题的一方，当然私营企业也需要美国政府提供“对抗中国情报机构”的资源支持。德莫斯还认为，目前中国情报机构针对美国私营企业的做法与政治间谍活动并无太大区别，“这对于美国政府人员来说仍难以分辨或抵抗，没有接受过反间谍训练的私营企业雇员更是难以抵挡”。
