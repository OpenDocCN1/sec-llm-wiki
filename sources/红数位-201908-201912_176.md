# 博通+赛门铁克：适用于华尔街，而不适用于安全性

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486173&idx=3&sn=8a0595dbb0d4418a4328edef4f08933c&chksm=cef3676ef984ee78d84d2aea04bc6725d3b9639026db5e8d0de90fbcc9747aaba890867fb1e3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486173&idx=3&sn=8a0595dbb0d4418a4328edef4f08933c&chksm=cef3676ef984ee78d84d2aea04bc6725d3b9639026db5e8d0de90fbcc9747aaba890867fb1e3&scene=27#wechat_redirect)

![](../Images/533414f6c4ac61ba1231567613f86972.png)

  

2019年8月8日是华尔街的重要日子，博通宣布有意以107亿美元现金收购赛门铁克的企业业务。赛门铁克的股票上涨了12％以上。这一增长似乎并不算是一笔巨大的溢价，但是鉴于赛门铁克在上一财年中最热门的技术领域之一的收入在下降，我们认为这一价格是慷慨的。

  

![](../Images/bdea67bc8f4ace38c2f65463be4e16dc.png)

  

博通自己的声明侧重于财务收益：

*减少10亿美元的运营费用，侧重销售，市场营销和G＆A*

*利用企业许可模式，专注于向全球2000强最大的客户销售*

 

对合并后的公司的财务收益是显而易见的。但是，很难在产品或技术协同方面找到很多东西，从而为客户提供更好的安全产品的清晰途径。

  

**这个消息对赛门铁克的客户有好处吗？**

收购后，博通仍主要是一家半导体公司。它确实在2018年收购了CA Technologies，以扩展到软件，但是CA的优势是用于大型机，开发和测试的软件，而不是安全性。通过赛门铁克，博通已成为技术的核心，是一个在同一主体上连接了三个头部的怪兽。三个脑袋都有自己的主意，因此必须注意不要互相吞食对方市场。

  

与任何财务驱动的收购一样，赛门铁克的收购后重点可能不是开发市场领先的产品或突破性创新，而是要为博通提供10亿美元的增量EBITDA。这可能来自对交叉销售机会的推动。

  

**如果他们遵循与CA相同的剧本，那么由于他们减少了人员，您还可能会看到另一个“大屠杀”。**除非赛门铁克的客户需要更多的芯片或大型机软件，否则很难看到很大的增长空间。

  

**客户应该怎么做？**

**博通收购的负面影响可能导致产品减少，创新减少以及对Symantec 客户的支持减少。****客户绝不能被动地等待这些影响，而应积极考虑其他供应商和解决方案，以弥补出现的空白，因为博通致力于向华尔街承诺提供每年10亿美元以上的节省。企业最糟糕的事情是等到最后一分钟才被迫进行更改。**
