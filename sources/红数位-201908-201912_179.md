# Google禁用Chrome 78功能，导致"喔唷 崩溃啦！"错误消息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486173&idx=6&sn=4b2f8e07a50e62b1f050a66bb64a2d10&chksm=cef3676ef984ee78e741e9bd0879cae59b7235485acb2182abac20efb9aa9c1cfb06364eee73&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486173&idx=6&sn=4b2f8e07a50e62b1f050a66bb64a2d10&chksm=cef3676ef984ee78e741e9bd0879cae59b7235485acb2182abac20efb9aa9c1cfb06364eee73&scene=27#wechat_redirect)

![](../Images/533414f6c4ac61ba1231567613f86972.png)

  

Google发现与某些软件解决方案的兼容性错误会破坏浏览器并在每次加载页面时导致"喔唷 崩溃啦"错误后，已禁用Chrome 78中的Renderer Code Integrity功能。

  

![](../Images/14636390e9ef5b85e93e29d23da445ff.png)

谷歌最初表示该问题仅限于Symantec Endpoint Protection，但经过进一步调查后，该公司表示另外三个应用程序可能会引起兼容性问题，例如PC Matic，Print Audit和Palo Alto Traps。

  

![](../Images/719655f7e6942d642499090f398d003d.png)

  

Google 表示：“我们已经确认，除了与特定版本的Symantec Endpoint Protection不兼容之外，某些其他软件应用程序还可能在最新的Chrome M78版本中引起"喔唷 崩溃啦"消息。

  

**修复已经在工作中**

目前，公司正在与软件开发人员合作修复此问题，但Chrome 78已禁用了“渲染器代码完整性”功能，以防止更多设备受到影响。

  

“我们暂时禁用了新的Chrome功能，这会导致不兼容，而我们与这些软件提供商合作以提高兼容性。如果您受到上述产品不兼容的影响，请与应用程序提供商联系，以了解其修复时间表。”一位Google工程师在论坛上解释道。

  

暂时尚无关于何时可以重新启用该功能的预计到达时间，但谷歌表示目标是“不久的将来”。

  

但是，此时，在启用了Renderer Code Integrity的情况下使用Google Chrome可能会导致"喔唷 崩溃啦"错误，这不仅是由于防病毒软件的兼容性问题，还因为设备上其他软件的问题。

  

我不知道其他任何应用程序都没有被Google提及，可能是Chrome的新功能遇到了兼容性错误，但是如果您突然遇到"喔唷 崩溃啦"错误，则有可能默认情况下启用了新功能Chrome 78是应受谴责的一个。
