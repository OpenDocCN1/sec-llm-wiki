# 警告：iPhone 5用户不安装新iOS版本或失去互联网访问权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247486110&idx=6&sn=cf66a97d3f29f02cf924ccce035a3b0b&chksm=cef3672df984ee3b084a758de39e6d9dc18e5f6ddf691e5aa96c0d99f8eae3a2ce68fe509f41&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486110&idx=6&sn=cf66a97d3f29f02cf924ccce035a3b0b&chksm=cef3672df984ee3b084a758de39e6d9dc18e5f6ddf691e5aa96c0d99f8eae3a2ce68fe509f41&scene=27#wechat_redirect)

据报道，iPhone 5尚未在11月3日之前更新到iOS 10.3.4，苹果现在正在更改影响的设备上显示警告。

  

![](../Images/a8d696f0e52d701f8f6bf9935160cc24.png)

  

基本上，未在其iPhone 5上安装此特定iOS版本的用户将不再能够使用Safari浏览Internet，访问电子邮件和iCloud，以及连接到App Store来安装应用程序。

  

一旦达到了11月3日的里程碑，仍将使用与计算机和iTunes的连接来更新仍在运行旧版软件的iPhone 5机型，因为这将阻止Internet访问并且不再提供OTA更新。

  

“在2019年11月3日之前更新到iOS 10.3.4，以继续使用App Store，iCloud，电子邮件，Web和其他服务。如果对iPhone 5的更新在2019年11月3日之前尚未完成，则您将需要使用Mac或PC进行备份和还原以进行更新，因为无线软件更新和iCloud Backup无法正常工作。” iPhone 5上显示的警告读取。

  

**11月3日截止**

苹果在一份支持文件中说，这完全是由于该公司今年早些时候发布的GPS修复程序造成的。

  

“从5月2019年11月3日UTC凌晨1点开始，iPhone 5将需要进行iOS更新，以维护准确的GPS位置，并继续使用依赖正确日期和时间的功能，包括App Store，iCloud，电子邮件和网络浏览。这是由于GPS时间转换问题于2019年4月6日开始影响其他制造商的GPS产品。受影响的Apple设备直到UTC于2019年11月3日凌晨12:00才受到影响。”

  

根据9to5mac，其他设备将在11月3日受到GPS错误的影响，包括iPhone 4S，iPad 2，带有Retina Display的iPad和第四代iPad，但在这种情况下，上网不会受到限制。

  

幸运的是，此访问限制可能只针对少数设备，因为Apple数据显示，当前运行iOS 10或更早版本的iPhone中不到10％。
