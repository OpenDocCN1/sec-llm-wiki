# 再见，Flash

谷歌周一宣布，谷歌搜索将在今年年底停止支持Adobe Flash。在包含Flash内容的网页中，Google会忽略Flash内容。搜索还将停止索引独立的SWF文件。 

  

![](../Images/1be868307eba220f86c1bbac1e7ca8b0.png)

  

![](../Images/459160b5a8a2b03b345ca5ce8c5db02f.png)

  

早在2017年，Adobe宣布将停止支持曾经丰富的技术，而Google表示将在2020年底之前完全从Chrome Web浏览器中删除Flash。从Chrome 76版开始，默认情况下已禁用Flash。

  

**时代的终结– Adobe Flash的后续步骤**

*\[2019年8月30日更新 –我们发布了有关从Microsoft浏览器中删除Flash支持的计划的更新，包括基于Chromium的新版本Microsoft Edge。**– Ed。**\]*

  

*今天，Adobe宣布 2020年之后将不再支持Flash。**Microsoft将在此日期之前逐步淘汰Microsoft Edge和Internet Explorer中的Flash支持。*

  

*Flash引领了网络上各种内容，游戏，动画和各种媒体的发展，并启发了许多当前为HTML5提供支持的网络标准。**Adobe已与Microsoft，Google，Mozilla，Apple和许多其他公司建立了合作伙伴关系，以确保开放的网络能够满足并超越Flash传统上提供的体验。**在所有现代浏览器中实施的HTML5标准为这些功能提供了改进的性能，电池寿命和更高的安全性。**我们希望继续与Adobe和我们的行业合作伙伴合作，以在无需插件的情况下丰富开放的Web。*

  

*我们将逐步淘汰Microsoft Edge和Internet Explorer中的Flash，最终将在2020年底之前完全从Windows中删除Flash。**此过程已针对Microsoft Edge 在Windows 10 Creators Update中通过Flash即点即用开始。**该过程将在以下阶段继续进行：*

  

*从2017年底到2018年，Microsoft Edge会继续在首次访问该网站时要求用户在大多数网站上运行Flash的权限，并会记住用户对后续访问的偏好。**在这段时间内，Internet Explorer将继续允许Flash，而无需任何特殊权限。*

*在2018年中下旬，我们将更新Microsoft Edge，以要求获得在每个会话中运行Flash的权限。**Internet Explorer将在2018年继续允许所有网站使用Flash。*

*在2019年中下旬，我们将默认在Microsoft Edge和Internet Explorer中禁用Flash。**用户将能够在两个浏览器中重新启用Flash。**重新启用后，Microsoft Edge将继续要求逐站点批准Flash。*

*到2020年底，我们将取消在所有受支持的Microsoft Windows版本中的Microsoft Edge和Internet Explorer中运行Adobe Flash的功能。**用户将不再具有启用或运行Flash的功能。*

*此时间线在包括Google，Mozilla和Apple的浏览器之间是一致的。**我们期待与Adobe，其他浏览器供应商和发布社区继续紧密合作，因为我们将为所有人发展网络的未来。*

  

*— Microsoft Edge首席程序经理主管John Hazen*

  

微软，苹果和Mozilla也宣布了在各自的浏览器中淘汰Flash的计划。今年早些时候，微软详细说明了从基于Chromium的Microsoft Edge浏览器中删除该技术的计划。

  

Google工程经理Lee Dong-Hwi Lee在一篇博客文章中强调了Flash曾经无处不在的情况-Flash运行时在2013年下半年安装了5亿次。

  

“ Flash，您激发了网络的灵感。” Lee写道。“现在，有**HTML5**之类的网络标准可以延续您的传统。”
