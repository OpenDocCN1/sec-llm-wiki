# 研究人员找到了一种仅使用软件即可扩展Wi-Fi范围的方法

简单的软件更新使研究人员可以将Wi-Fi范围扩展60米。

  

![](../Images/10d54807a33c86061e2696e41c7c8c7b.png)

  

犹他州杨百翰大学（BYU）的研究人员发现了一种方法，该方法可以通过简单的软件更新就可以在很长的距离内发送和接收Wi-Fi信号。

  

根据测试结果，新协议称为“开-关噪声功率通信（ONPC）”，可以将门传感器或运动检测器等物联网（IoT）设备的范围扩展60米以上。使用相同的硬件，可以在现有Wi-Fi协议的顶部对新协议进行编程。

  

BYU计算机工程助理教授Phil Lundrigan 表示：“这是这项技术的真正酷之处：都是用软件完成的。“理论上，我们可以通过简单的软件更新将其安装在几乎所有支持Wi-Fi的设备上。”

  

当前，Wi-Fi要求至少每秒1兆位（1 Mbps）的速度才能保持信号，但是创建的新ONPC协议可以将信号保持在每秒1位的低位，相当于所需数据速度的百万分之一通过Wi-Fi。

  

Lundrigan认为，对于许多启用Wi-Fi的设备（例如车库门传感器，空气质量监控器甚至是洒水器系统），仅需要一个开/关消息就可以使用1位信息就足够了。

  

该协议通过允许启用Wi-Fi的设备传输无线噪声和数据来实现此目的。研究人员在Wi-Fi传感器中设置了一系列的1和0，实际上是按特定的模式打开和关闭信号。完成的编程足以告诉Wi-Fi路由器该设备仍在传输某些内容（即使未接收到数据）并保持信号。

  

“如果接入点（路由器）听到此代码，它会说：'好吧，我知道传感器仍在运行，并试图与我联系，它超出了范围。” 基本上，它发送的是1位表明生命的信息，”圣路易斯华盛顿大学的Neal Patwari说。

  

根据测试结果，当ONPC协议与名为“ Stayin'Alive”的应用程序配对时，它可以将现成设备的范围扩大67米（约200英尺），超出标准Wi的范围。\-Fi。

  

“无论Wi-Fi在做什么，我们都可以发送和接收数据；我们需要的只是传输能量然后接收噪声测量的能力。” Lundrigan说。“我们也可以将其应用于蜂窝或蓝牙。”

  

关于ONPC的最好的事情是它完全基于软件，并且可以通过简单的软件更新从技术上推广到现有的路由器和设备。但是，研究人员清楚地指出，他们的ONPC协议不能替代Wi-Fi或LoRa等远程无线协议。它主要用于“补充Wi-Fi”。特别是，只有在Stayin'Alive发现Wi-Fi设备失去连接后，它才开始使用ONPC传输数据。

  

这项研究提出了在移动计算国际会议和在墨西哥洛斯卡沃斯网络10月22日第二。
