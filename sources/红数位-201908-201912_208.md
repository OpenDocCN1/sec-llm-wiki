# 宝洁在线美容店被盗窃付款信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490892&idx=6&sn=50b09e1283642fc4b2a3d0aebf0ef00c&chksm=cef370fff984f9e9978a7bbf5effdb2d95712ab8a85cb3acc9145b1618b05e449a017f4f16ca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490892&idx=6&sn=50b09e1283642fc4b2a3d0aebf0ef00c&chksm=cef370fff984f9e9978a7bbf5effdb2d95712ab8a85cb3acc9145b1618b05e449a017f4f16ca&scene=27#wechat_redirect)

![](../Images/9cff7422ef9bffa57de52edf433b70f4.png)

  

五月份，黑客在宝洁公司的网站First Aid Beauty上植入了木马，而今天它仍在窃取支付卡数据。这个特殊的MageCart脚本从美国选择受害者。

  

![](../Images/9a67e450ea02d9b6c9bcf1ba366ec0fe.png)

www.firstaidbeauty.com

该网站目前显示ERROR 503

  

如果购物者来自其他国家或使用Linux操作系统，则该脚本将保持不活动状态，很可能是为了抵御安全研究人员。

  

尽管“急救美容”没有宝洁商标，但该公司今年以2.5亿美元的价格收购了该美容品牌。

  

**公司约一个星期没有反应**

Sanguine Security的研究人员Willem de Groot跟踪在线付款的掠夺和欺诈行为，发现该恶意脚本自5月5日以来一直隐藏在First Aid Beauty网站上。

  

大约一周前，他联系了公司代表和支持团队，但在撰写本文时仍未收到该脚本的答复。

  

研究人员告诉外媒，他在周日和本周几次联系急救美容公司，但没有收到任何回复。

  

![](../Images/8a3764f715b739e237fd9296fdbd5cd5.png)

  

我们在发布时再次检查了该网站，该网站不再可用，显示503 Service Unavailable错误。

  

目前尚不清楚有多少游客在急救美容商店购物，但过去六个月该网站每月有大约100,000名访客，其中约80％来自美国

  

选择性地选择受害者是使MageCart交易记录“相当先进”的原因。但是，它也很模糊并且使用加密，这表明其背后的人员都熟悉这种类型的业务。

  

de Groot告诉我们，网站所有者通常会在几周后发现这些撇取者，但这个抵抗者抵抗了五个多月，“因此，该演员的隐身水平非常出色。”

  

![](../Images/d4a8801ef117c8ae10c40871d8f802bc.png)

  

de Groot提供了 该脚本的模糊版本，可以清楚地显示其功能。它查找的数据包括卡号，有效期，所有者名称以及用于卡不存在交易的CVV代码。

  

**保持电子商务软件更新**

急救美容公司使用了本月初更新的Magento电子商务平台，以修补56个安全问题。其中一个严重程度得分为10（最高），而其他11个严重程度得分为9.1。

  

在本月初的一份报告中，网络安全公司RiskIQ 指出  ，MageCart或电子窃听威胁已经影响了成千上万个网站，并已成为一种现今的现象。

  

威胁是如此之大，以至于联邦调查局（FBI）在几天前发出警告，警告  它针对中小企业以及处理在线支付的政府机构。

  

除了应用最新的补丁程序并安装最新的防病毒产品外，商家还可以使用内容安全策略（CSP）工具允许JavaScript仅从受信任的域列表中加载JavaScript来抵御支付卡窃取脚本。

  

使用子资源完整性（SRI）是另一种机制。它可以通过检查合法资源的加密哈希值来阻止加载修改的JavaScript代码。

  

**更新\[10/25/2019\]：在发布后几分钟，我们再次检查了该网站，并且该网站没有恶意脚本即可备份。幸免于难的事实已经持续了很长时间，这是公司应解决的一个问题。**

  

**更新\[10/25  /2019，17 :35 ET\]：宝洁（Procter＆Gamble）从BleepingComputer返回了征求意见的请求，称他们正在努力识别并通知可能受影响的客户。完整的声明如下：**

  

*“消费者的信任是我们的根本，我们非常重视数据隐私。一旦我们了解了急救美容网站的危害，我们便迅速采取行动，将该网站撤下并最大程度地降低了对消费者的影响。我们目前调查恶意软件的来源，并努力识别并通知可能受到影响的那些消费者，以确保我们为他们提供必要的支持。”*
