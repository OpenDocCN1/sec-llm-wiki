# Windows 10 1903 KB4522355更新发布，最终修复了开始菜单错误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485986&idx=6&sn=f62fbed941767a8b27c43c2e3937e1f8&chksm=cef36791f984ee87db0d4076b33214e9b63039718b8965d2e38ff0e9e59df137e8d33b46bd5b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485986&idx=6&sn=f62fbed941767a8b27c43c2e3937e1f8&chksm=cef36791f984ee87db0d4076b33214e9b63039718b8965d2e38ff0e9e59df137e8d33b46bd5b&scene=27#wechat_redirect)

Microsoft已发布Windows 10 1903的KB4522355累积更新（2019年5月更新），其中引入了各种质量改进和错误修复。

  

![](../Images/6655fbac7f27291a2195d53bcf406ac8.png)

在此累积更新中，Microsoft声明他们终于解决了导致“开始菜单”，Cortana搜索栏和任务栏图标停止响应或显示严重错误的问题。在受影响的用户安装此更新后，我们将必须查看是否确实如此。

  

此版本中已修复的其他显着问题是针对Windows 10挂在登录屏幕或在安装更新后显示黑屏的修复。

  

此更新不包含任何安全修复程序。

  

**KB4522355中的更改**

通过“ Windows Server 2019-10累积更新，版本1903（KB4522355）”更新，Windows 10的内部版本号已提高到18362.449。

  

用户可以通过Windows Update或Microsoft目录安装此更新。

  

以下是修复和改进的完整列表：

  

*   解决了当您使用Internet Explorer进行跨源资源共享（CORS）请求以重定向内部子网中的资源时，Origin HTTP标头行为的问题。 
    
*   解决了阻止Microsoft Narrator在某些触摸模式下工作的问题。 
    
*   解决了禁用“在此设备上继续体验”组策略时从“帐户”页面同步设置的问题。 
    
*   解决了在“轻松访问中心”设置要求登录前启动AT时登录后启动辅助技术（AT）（例如Microsoft Narrator，Magnifier或NVDA）的问题。 
    
*   解决在启用NT虚拟DOS计算机（NTVDM）和旧版控制台模式后打开应用程序时出现的错误消息。错误消息是，“ OACClearArry：无法连接到Trace32 OLE自动化服务器。错误代码：\-2147483645。” 
    
*   解决了导致放大镜在某些情况下停止工作的问题，用户必须手动重新启动它。 
    
*   更新澳大利亚诺福克岛的时区信息。 
    
*   更新斐济群岛的时区信息。 
    
*   解决了在某些情况下导致Microsoft Narrator在用户会话中停止工作的问题。 
    
*   解决了使用 不带参数的color命令时无法设置默认命令提示符窗口颜色的问题  。 
    
*   解决了导致Microsoft Windows搜索索引器（searchindexer.exe）添加或修复所需访问控制列表（ACL）而不检查ACL是否存在的问题。 
    
*   解决了使用“运行关闭脚本可见” 策略从注销脚本启动时，Win32应用程序中的控件间歇性地无法正确呈现的  问题。
    
*   解决了在系统中安装许多字体会导致应用程序停止响应的问题。 
    
*   解决了与远程桌面协议（RDP）会话断开连接时，桌面窗口管理器（dwm.exe）中CPU使用率过高的问题。 
    
*   解决了ActiveX控件实现CScrollView  类时可能阻止选择滚动条的问题  。如果您移动Internet Explorer窗口，然后将滚动条向左移动，则会发生这种情况。 
    
*   解决了一个问题，即使您将睡眠计时器配置为永不睡眠，该问题也允许系统在两分钟不活动后进入睡眠（S3）。 
    
*   解决了在某些情况下阻止用户减小窗口大小的问题。 
    
*   解决了导致Microsoft SharePoint文件名在快速访问和最近项文件夹中错误显示的问题。 
    
*   解决了阻止您建立虚拟专用网络（VPN）连接的问题。 
    
*   解决了在高每英寸点数（DPI）监视器上显示应用程序缩略图时导致屏幕闪烁或显示屏幕缓慢的问题。 
    
*   解决了对用户的类注册表项权限不正确的问题，该问题阻止用户打开文件，链接和应用程序。 
    
*   解决了在某些情况下导致“照片”应用程序的磁贴看起来比“开始”菜单中的预期更大的问题。 
    
*   解决了导致系统在登录屏幕上停止响应的问题。 
    
*   解决了Windows Hello for Business的多因素解锁策略的问题，该策略在Windows 10设备上无法显示默认登录选项。 
    
*   解决了当组策略将子组应用于“开始”菜单布局时导致Windows搜索意外关闭的问题。 
    
*   通过将DHCP LeaseTerminatesTime  和  LeaseObatinedTime  参数设置为正确的格式来解决阻止您检索正确的动态主机配置协议（DHCP）信息的问题  。
    
*   解决了当设备启用了诊断数据设置并将其设置为基本时诊断数据处理的问题。 
    
*   解决了使用Microsoft User Experience Virtualization（UE-V）漫游许多收藏夹时阻止Internet Explorer打开的问题。 
    
*   解决了提高UE-V AppMonitor可靠性的问题。 
    
*   解决了Microsoft AppLocker可能阻止应用程序运行或记录误报错误而不是运行该应用程序的问题。 
    
*   解决了阻止  netdom.exe  为显示或查询模式显示新的授予票证的票证（TGT）委派位的问题。 
    
*   解决了可能导致Direct Access服务器使用大量非页面缓冲池内存（pooltag：NDnd）的问题。 
    
*   解决了AppContainer防火墙规则的问题，该规则在访客用户或强制用户配置文件用户登录Windows Server和从Windows Server注销时会泄漏。 
    
*   解决了阻止Windows Update的统一写入筛选器（UWF）服务模式与Windows Server Update Services（WSUS）服务器一起使用的问题。 
    
*   解决了导致所有传输控制协议（TCP）动态端口被消耗的问题。结果，对于使用动态端口的任何协议或操作，网络通信都将失败。 
    
*   解决了与调用NetQueryDisplayInformation  API或  WinNT提供程序  等效项的应用程序和脚本有关的问题  。他们可能无法在第一页数据（通常为50或100个条目）之后返回结果。当请求其他页面时，您可能会收到错误“ 1359：发生内部错误”。 
    
*   解决了在工具提示出现在RemoteApp窗口中后中断窗口顺序的问题。 
    
*   改进了对“已知文件夹”的访问控制列表（ACL）检查，以防止在安装功能或质量更新后用户首次登录时出现黑屏。 
    
*   解决了评估Windows生态系统的兼容性状态以帮助确保Windows的所有更新的应用程序和设备兼容性的问题。 
    
*   解决了自动驾驶仪自动部署模式和白手套部署的问题。
    
*   解决了在InitializeSecurityContext（）  API中错误设置pszTargetName 参数  的问题  。
    
*   解决了在安装每月更新后导致“开始”菜单，Cortana搜索栏，任务栏图标或Microsoft Edge在某些情况下停止响应的问题。
    

  

Microsoft声明他们“当前不知道此更新有任何问题”。不过，这已经在前面说过了，因此我们将不得不看看随着更多人安装此更新而发生的情况。
