# 2019年兴起地下集团：网络入侵者与勒索软件开发人员相互勾结入侵企业

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485883&idx=7&sn=0f10418f6e7652a518106ca099ed890c&chksm=cef36408f984ed1e79fa09ce346a544d89313b76814272e6418dde354d3a223c1c416e21815a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485883&idx=7&sn=0f10418f6e7652a518106ca099ed890c&chksm=cef36408f984ed1e79fa09ce346a544d89313b76814272e6418dde354d3a223c1c416e21815a&scene=27#wechat_redirect)

**网络攻击每天都在迅速增长，这已成为企业面临的最大挑战之一。****网络入侵者和勒索软件开发人员团体彼此结成联盟，以利用勒索软件市场获得最大收益。**

  

**他们相互勾结攻击最安全，最有利可图的目标。**AdvIntel报告显示了地下社区如何发展犯罪联盟的多维结构。

  

**地下集团相互勾结访问公司网络数据**

勒索软件团体倾向于遵循几种战略方法来感染大量攻击者，他们攻击企业或政府实体等备受瞩目的目标，以产生数千美元。

  

为了执行操作，勒索软件组与几个第三方合作，例如网络漏洞专家和开发其恶意软件菌株的恶意软件开发人员。

  

AdvIntel报告读到：“讲俄语的地下室是许多熟练的网络漏洞专家的家，他们精心策划复杂的入侵操作并获得引人注目的访问权限。”

  

对于网络违规专家来说，货币化是一个巨大的挑战，勒索软件组织提供了一种货币化解决方案。

  

*研究人员观察到，一个被称为“ -TMT-”的黑客加入了地下社区，以利用其公司网络漏洞获利。**该组织宣传说，他们窃取了各种公司网络的凭证，价格从3,000美元到5,000美元不等。*

  

![](../Images/01a63051829d86e03c8a9106384201c8.png)

网络入侵者和勒索软件组织相互勾结：AdvIntel  

  

通过私人聊天，他们提供“对受感染实体的若干访问权限，以及受害者网站上管理帐户的被盗凭据”，博客文章中写道。

  

他们的目标不是任何特定的管辖区或行业媒介。以下是“ -TMT-”的受害者。

  

*   一家在智利，玻利维亚和秘鲁运营的拉丁美洲房屋产品提供商-1069台主机，105台服务器受到威胁
    
*   一家台湾元件制造商– 388台主机，其中15台服务器被盗
    
*   哥伦比亚金融服务提供商– 623名房东受到了损害
    
*   国际海上物流服务提供商-668名船东受到影响
    
*   美国大学和教育机构的网络– 875名主机，87台服务器受到威胁
    
*   丹麦一家乳制品生产商– 1台主机，72台服务器受到威胁
    
*   玻利维亚能源部门的一家公司– 270台主机，12台服务器受到威胁
    

  

**\-TMT-黑客还提供了违规证据，这是AdvIntel向美国执法部门报告的。****黑客还声称他们已经窃取了登录凭据并在网络中导航以提升特权。**

  

黑客主要关注公司网络，并且在攻击的初始阶段使用受感染的RDP和恶意软件。

  

**\-TMT-与REvil勒索软件**

在私人通信中，TMT建议“打开单个会话并上传勒索软件和其他有效载荷，或提供对网络的连续访问。”

  

“根据AdvIntel敏感的源情报，自2019年8月以来，-TMT-和其他勒索软件组织一直在与REvil开发人员合作，以支持其加密储物柜上传。”

  

这种联系可能源于两个威胁参与者共享其专业知识，并且两个威胁参与者同时离开了Exploit论坛。

  

网络入侵者，Metasploit / Cobalt Strike专家和勒索软件开发人员之间的合作关系依靠坚实的基础来发起备受瞩目的攻击。
