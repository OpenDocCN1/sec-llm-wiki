超级隐形MSSQL服务器后门被安全机构发现

原文：http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485883&idx=3&sn=4509973f392a1151e5f3af95e8fa52f3&chksm=cef36408f984ed1e072a40b415c294d414c27ab6ad0510b47f879d69952ae30ef85bf1d18d7d&scene=27#wechat_redirect


ESET研究人员发现了温蒂黑客团体Winnti Group创建的新恶意软件，该恶意软件被用于在Microsoft SQL Server（MSSQL）系统上且保持持久性。



攻击者可以使用被称为skip-2.0的新恶意工具(以前未公开的后门程序)来对MSSQL Server 11和12服务器进行后门操作，从而使他们能够使用所谓的“魔术密码”连接到服务器上的任何帐户，并从安全日志中隐藏其活动 。


ESET说：“此后门程序使攻击者不仅可以通过使用特殊密码来获取受害者的MSSQL Server的持久性，而且由于使用了该密码时被禁用的多种日志和事件发布机制，也无法被检测到。”研究员Mathieu Tartare。


温蒂集团的武器库正在增长

Winnti Group是一个总括性名词（ 赛门铁克追踪为Blackfly和Suckfly，   CrowdStrike称之为Wicked Panda，微软称之为BAR BARIUM，FireEye称之为APT41），它们共享与自2011年左右开始使用。


那是当卡巴斯基 通过游戏的官方更新服务器发布后，在大量受感染的游戏系统上发现了黑客的Winnti Trojan  。


在分析了新的后门程序之后，ESET的研究人员还发现skip-2.0与其他Winnti Group恶意软件具有某些特征，“尤其是与PortReuse和ShadowPad后门程序”。


Winnti Group工件和TTP  （ESET）

WinReti黑客使用PortReuse（模块化Windows后门）进行攻击，该攻击针对一家知名亚洲移动软件和硬件制造商的服务器。


同样，PortReuse是“一种网络植入程序，它将自身注入到已经在侦听网络端口的进程中，并等待传入的魔术包触发恶意代码。”


ShadowPad是该组织使用的另一个Winnti后门，是 2017年供应链攻击的一部分，该攻击对Soth韩国网络连接解决方案制造商NetSarang产生了影响，当时黑客组织成功地通过后门感染了该公司的服务器管理软件。


所有这三个后门都使用相同的VMProtected启动器和该组的自定义恶意软件打包程序，并且最重要的是，还与与该威胁组过去的操作相关的其他几个工具共享了多个其他相似之处。


MSSQL Server 11和12受到攻击

一旦被放置在已经受到威胁的MSSQL服务器上，skip-2.0后门将继续通过sqllang.dll将其恶意代码注入sqlserv.exe进程，从而钩住用于记录身份验证的多个功能。


这使恶意软件可以绕过服务器的内置身份验证机制，从而即使其输入的帐户密码不匹配，也允许其操作员登录。


ESET说：“此函数的挂钩检查用户提供的密码是否与魔术密码匹配，在这种情况下，原始函数将不会被调用，并且挂钩将返回0，即使没有提供正确的密码也允许连接。” 。


Tartare补充说：“我们针对多个MSSQL Server版本测试了skip-2.0，发现只有使用MSSQL Server 11和12才能使用特殊密码成功登录。”



skip2.0注入（ESET）


尽管ESQL研究人员从Censys获得的数据显示，MSSQL Server 11和12不是最新发布的版本（它们分别在2012年和2014年发布），但它们是最常见的版本。


ESET的研究小组总结道： “ skip-2.0后门程序是Winnti Group武器库中的一个有趣的补充，它与Winnti Group的已知工具集具有许多相似之处，并允许攻击者在MSSQL Server上实现持久性。”


“考虑到安装钩子需要管理特权，必须在已经受到威胁的MSSQL Server上使用skip-2.0，以实现持久性和隐身性。”
