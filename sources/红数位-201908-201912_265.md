# 微软奖励在开源选举软件中发现错误的黑客

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485847&idx=4&sn=f8827c620ac7d92baa79b1cdae00d6cb&chksm=cef36424f984ed32f2174328d5a0f85d8f860a28f09a29a43b04ec50e605cd7fedda7505a149&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485847&idx=4&sn=f8827c620ac7d92baa79b1cdae00d6cb&chksm=cef36424f984ed32f2174328d5a0f85d8f860a28f09a29a43b04ec50e605cd7fedda7505a149&scene=27#wechat_redirect)

公平选举是民主的命脉，但是近年来，黑客入侵已成为全世界的热门话题。

![](../Images/e87c32494d88f9273845948d7c0a1a32.png)

无论是2016年总统大选期间的美国投票机，还是2014年大选期间印度的EVM，电子投票机的完整性，透明性和安全性仍然值得怀疑，这在许多人的心灵中留下了难以治愈的伤口。 许多国家，包括世界上最大的民主国家，即印度，都认为确保EVM安全的最佳方法是使其技术对不良行为者不透明，但近年来，很大一部分人口对任何系统都失去了信任仅由封闭的专家组认证的产品。

  

为了在透明性和安全性之间取得平衡，Microsoft在2019年5月发布了一个名为ElectionGuard的免费开源软件开发工具包（SDK），旨在实现端到端的投票验证。

  

微软的ElectionGuard SDK可以集成到投票系统中，旨在“启用端到端的选举验证，向第三方组织开放结果以进行安全验证，并允许单个选民确认自己的选票得到正确计数”。

  

**ElectionGuard Bug赏金计划**

由于没有软件能够完美无缺，Microsoft今天终于启动了ElectionGuard Bounty计划，邀请来自世界各地的安全研究人员帮助该公司发现ElectionGuard SDK中的高影响力漏洞。

  

该公司在今天发布的博客中说：“ ElectionGuard Bounty计划邀请安全研究人员与Microsoft合作，以保护ElectionGuard用户，这是Microsoft在捍卫民主计划下维护和保护选举程序的更广泛承诺的一部分。”

  

“来自全球的研究人员，无论是专职网络安全专业人员，兼职业余爱好者还是学生，都被邀请发现ElectionGuard SDK目标区域中的高影响力漏洞，并通过协调漏洞披露（CVD）与Microsoft分享。

  

![](../Images/2cd4265624e2ea90551ac82c89f9f7a2.png)

  

ElectionGuard Bounty为网络安全研究人员提供高达15,000美元的奖励，奖励他们提交清晰，简洁的概念证明（POC）的合格作品，以展示如何利用发现的漏洞实现范围内的安全影响。

  

当前可用于漏洞赏金的ElectionGuard组件包括ElectionGuard API SDK，ElectionGuard规范和文档以及验证程序参考实现。

  

但是，这家科技巨头表示，它将使用其他组件更新ElectionGuard赏金范围，以在将来奖励进一步的研究。
