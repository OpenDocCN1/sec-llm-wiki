# 赛门铁克企业用户再次遭遇噩梦：蓝屏死机

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485686&idx=1&sn=557c00c194501812dca9421a3c38d2fa&chksm=cef36545f984ec53b076937e4af25d31679abaa84e2134afe323579022e7554e118c5a659b94&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485686&idx=1&sn=557c00c194501812dca9421a3c38d2fa&chksm=cef36545f984ec53b076937e4af25d31679abaa84e2134afe323579022e7554e118c5a659b94&scene=27#wechat_redirect)

  

**赛门铁克昨日已确认其Endpoint Protection客户端更新后存在问题，该更新导致用户昨日早上（美国时间）会导致蓝屏死机事件进而导致Windows内核异常。**

  

用户纷纷在Twitter来报告问题：  

![](../Images/c873295f2b127f0c34106dca663e81f2.png)

一位接触到该问题的用户确认运行Symantec的“多个”企业终端遇到BSOD（蓝屏死机），并定位问题所在：错误的入侵防护驱动导致。

  

  

![](../Images/963e525c2b665b36e184448f71fa2f96.png)

  

  

**根据赛门铁克官方支持说明TECH256643：**

![](../Images/ebae4c3257ee7576de108fb29ad2c4ac.png)

  

*   

```

```

此BUG赛门铁克官方技术支持页面：

https://support.symantec.com/zh/cn/article.TECH256643.html

  

发生蓝屏死机（BSOD）时，**入侵防御**签名版本为2019/10/14 r61。

  

**假定您可以让Windows成功启动，则该解决方案是运行进一步的更新以获得正确的的Intrusion Protection签名的2019/10/14 r62版本，或者回滚到更早的版本。**

  

赛门铁克表示已经意识到了这一问题，并将在“获得新信息时”更新支持文档。

  

**目前尚不清楚哪些Windows版本受到影响。**
