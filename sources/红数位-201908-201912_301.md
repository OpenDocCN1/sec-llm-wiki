# 土耳其ISP封锁了叙利亚边境附近的社交媒体网站

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485612&idx=7&sn=37b63b730f7c5afa2a88df05a26af2f5&chksm=cef3651ff984ec0915ad72830780b4726633c382e5147df423211e8262c47bc4c268e757c3cf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485612&idx=7&sn=37b63b730f7c5afa2a88df05a26af2f5&chksm=cef3651ff984ec0915ad72830780b4726633c382e5147df423211e8262c47bc4c268e757c3cf&scene=27#wechat_redirect)

  

民间社会组织NetBlocks和Net收集的数据显示，土耳其在本周早些时候对叙利亚北部发动了袭击，因此在该国南部至少三个城市中限制访问Facebook，Instagram，Twitter和WhatsApp约48小时。有线评论。在唐纳德·特朗普总统将美军撤离该地区后的几天，土耳其对叙利亚北部的库尔德军队发动了空袭，对与美国结盟的民兵发动了空中和地面攻击。

  

![](../Images/13d84ab6394625b22bc4f84d4bc9d00d.png)

靠近边界的土耳其人依靠这些社交媒体服务来访问和共享未经审查的新闻。

  

NetBlocks测试表明，从UTC周三凌晨1点（美国东部时间周二晚上9点）开始，Gaziantep，Şanlıurfa和Hatay等城市的用户在连接到土耳其领先的互联网服务提供商的同时，无法访问某些流行的社交媒体平台和消息服务， TürkTelekom。数据显示，UTC周五早上似乎恢复了访问。TürkTelekom 由土耳其政府部分拥有。NetBlocks说，该国其他地区的用户可以正常使用该服务。

  

![](../Images/821ec9a81fe40a3701d4b9e4263926f2.png)

  

NetBlocks主管Alp Toker表示，限制的期限很长。他说，这使该国最后一个主要的社交媒体封锁相形见，。2016年8月，Facebook，Twitter，YouTube，Vimeo和Instagram被切断了七个小时。

  

“这不是第一次，而且可能不会是最后一次。”公民自由监管机构自由之家的技术与民主研究主管阿德里安·沙巴兹（Adrian Shahbaz）说。Shahbaz说，近年来，通常是在恐怖袭击，政治破坏性泄密或公民抗议之后，土耳其当局经常封锁该国部分地区的社交媒体。从政治分歧到露骨内容的存在，土耳其还直接封锁了数十万个网站。

  

他说，土耳其政府对新闻界的敌视与日俱增，导致该国国内外的许多记者直接向社交媒体发布，以逃避政府的审查制度。与说服外国社交媒体巨头（如Facebook或Twitter）删除特定帖子或个人资料相比，当局限制对特定网站或URL的访问要容易得多。

  

Shahbaz解释说，这鼓励了许多独立记者在Twitter，YouTube和其他社交媒体平台上开设自己的新闻媒体，从而使他们能够接触到大量观众。

  

沙巴兹说：“如今，很多土耳其人都将在社交媒体上获得可靠的新闻。” “在东南部，与叙利亚现在发生的冲突有关的一切都在发生，土耳其当局对社交媒体采取这种广泛的镇压行动也就不足为奇了。”

  

Toker说，尽管如此，这一障碍还是令人惊讶。“过去，在全国范围内对社交媒体进行过滤时，这是一种集体经验，”托克说。”将会有强烈的抗议。但是在这种情况下，因为它相当具体，而且实际上只影响某些区域，所以引起了混乱。”
