# 黑客可拦截GPS流量,窃取数据,设后门，海事卫星终端科巴姆探索者710中曝6严重零日漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485578&idx=1&sn=dbbeb7a6414127c8fee70e81d57540ba&chksm=cef36539f984ec2fb43f3a98c140a611f6dc2d6329c2d63d366a7ba7df8e0cdafc44d4c5a25a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485578&idx=1&sn=dbbeb7a6414127c8fee70e81d57540ba&chksm=cef36539f984ec2fb43f3a98c140a611f6dc2d6329c2d63d366a7ba7df8e0cdafc44d4c5a25a&scene=27#wechat_redirect)

  

来自CERT / CC的研究人员在Satcom终端**科巴姆探索者710(**Cobham EXPLORER 710)中发现了6个零日漏洞，这些漏洞同时影响固件和设备。

![](../Images/956e6e4e3f1e9e4303bf7f4e8e9c8b46.png)

  

  

![](../Images/85f1416b196a1f82327daf72e65bc211.png)

  

**该漏洞使黑客能够执行多种攻击，例如拦截流量，远程执行命令，植入和隐藏后门，DoS攻击，泄露敏感数据等等。**

  

****科巴姆探索者710** -Cobham EXPLORER 710是卫星电信终端，该设备可通过卫星为您提供互联网访问，并具有多种功能，包括通过卫星提供最快的点播视频流。**

**该航站楼版本广泛应用于各个领域，包括航天系统，商业航空航天，海上SATCOM，陆军和空军防空，战斗机等。**

![](../Images/1068349ca0ea247100260fbefd5f84ea.png)

![](../Images/d7567874154492d74232974a9d0a4f8d.png)

  

**EXPLORER 710还是一种高度复杂的通信工具，可通过以太网连接提供1 Mbps甚至更高的IP流速率。**

  

![](../Images/ccfd4b72005fb666c877cbd43fc39b69.png)

  

Cobham EXPLORER 710提供的通信接口包括2个以太网，USB，WLAN 802.11 a / b / g，数字I / O，蓝牙，并且该终端还能够提供Internet，电子邮件，电话，VoIP，FTP，FoIP（传真），短信，卫星视频流。

  

**Cobham EXPLORER 710中发现了6个严重零日漏洞，所有这些漏洞都影响固件版本1.07**

  

*   CVE-2019-9529 –身份验证失败
    
*   CVE-2019-9530 –无限制目录访问
    
*   CVE-2019-9531 –身份验证失败
    
*   CVE-2019-9532 –计划文本数据交换
    
*   CVE-2019-9533 –默认登录凭据
    
*   CVE-2019-9534 –验证失败
    
*   CVE-2019-9529 –身份验证失败
    
      
    

**CVE-2019-9529 –身份验证失败**

身份验证失败漏洞驻留在Web应用程序门户中，未经身份验证的攻击者可以使用该漏洞访问门户并执行对设备的任何更改。

  

**CVE-2019-9530 –无限制目录访问**

在webroot目录中发现的不受限制的目录访问漏洞，它不包含访问限制，并且允许本地攻击者从Web根目录执行读取，写入和下载任何文件。

  

**CVE-2019-9531 –身份验证失败**

Cobham EXPLORER 710 Satcom终端Web应用程序门户中发现的另一个身份验证失败漏洞使攻击者可以对设备上的端口5454执行未经身份验证的访问。

“这可能允许未经身份验证的远程攻击者通过Telnet连接到此端口，并执行86 Attention（AT）命令，其中包括一些提供未经身份验证的类外壳访问设备的命令。”

  

**CVE-2019-9532 –计划文本数据交换**

Web应用程序门户网站中发现的一个漏洞，它以明文形式传递登录密码，该漏洞使本地攻击者可以拦截流量并获得对该门户网站的完全控制。

  

**CVE-2019-9533 –默认登录凭据**

设备包含的root密码对于v1.08（含）以下的所有固件版本均相同。

  

通过使用默认的root密码，设备极易受到攻击者的攻击，他们可能会对所有可用版本中的密码进行反向工程，以获取未经身份验证的设备的完全访问权限。

  

**CVE-2019-9534 –验证失败**

由于验证失败，设备不会验证其固件映像，并且固件中保留的开发脚本可用于上载设备运行的自定义固件映像。

  

利用此漏洞，攻击者可以上传自己的固件映像并拦截或修改流量，欺骗或拦截GPS流量，泄露私人数据，隐藏后门或导致拒绝服务。CERT / CC研究人员说。

  

除了上述缺陷外，研究人员还发现缺少重要的安全标头，这些标头对于设备非常危险，并且容易受到跨站点脚本  和  点击劫持的攻击  。 

  

CERT / CC表示，他们目前尚未意识到针对这些问题的实际解决方案。
