# Microsoft发布Office的2019年10月安全更新，含9个远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485496&idx=2&sn=b60390d2c9235a9281fc33f3375a891c&chksm=cef3658bf984ec9d094610d62c7460816c6f36123592a31751429ca1bba39a42d16deeaf3401&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485496&idx=2&sn=b60390d2c9235a9281fc33f3375a891c&chksm=cef3658bf984ec9d094610d62c7460816c6f36123592a31751429ca1bba39a42d16deeaf3401&scene=27#wechat_redirect)

  

微软发布了2019年10月的Microsoft Office安全更新，发布了**7个产品中总共14个安全更新和4个累积更新**，其中**修补了****9个远程代码执行漏洞。**

![](../Images/0b083b0f538e01a23289aff776857f7b.png)

  

强烈建议客户尽快安装它们，因为今天发布的某些Microsoft Office安全更新也解决了各种关键漏洞，要下载今天的Microsoft Office安全更新，用户必须单击下表中的相应知识库文章，然后向下滚动到“ 如何下载和安装更新 ”部分，以在打开的页面上下载更新程序包。

  

微软还发布了2019年10月补丁星期二的安全更新，其中包含1个公告（Windows 10服务堆栈更新）和59个漏洞的更新。这些漏洞中有八个被Microsoft评为严重。

  

  

**修补的Microsoft Office漏洞**

在Microsoft今天发布的14个Office安全更新中，其中五个修补了Office 2016，Office 2013，Office 2010，Excel 2016，Excel 2013，Excel中的远程执行代码漏洞（CVE-2019-1327和CVE-2019-1331） 2010，Office Online Server，SharePoint Enterprise Server 2013和SharePoint Server 2010。

  

**Microsoft修补了今天的远程执行代码安全漏洞，严重等级为“危急”，他们发现，它们可以使攻击者在成功利用易受攻击的Windows设备后执行任意代码和/或命令。**

  

Microsoft今天发布的其余安全补丁程序还修复了特权提升，跨站点脚本（XSS）和欺骗漏洞（即CVE-2019-1070，  CVE-2019-1328，  CVE-2019-1329，  CVE -2019-1330）影响SharePoint Server 2019，SharePoint Enterprise Server 2016，SharePoint Enterprise Server 2013，SharePoint Foundation 2013和SharePoint Foundation 2010。

  

**2019年10月Microsoft Office安全更新信息汇总**

在十月的Microsoft Office安全更新都可以通过现有的  Microsoft更新平台和下载中心。
