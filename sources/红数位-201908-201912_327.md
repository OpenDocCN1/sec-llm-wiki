# 4款D-Link路由器存高危远程攻击漏洞且无法修复

**Fortinet的FortiGuard实验室的安全专家  披露了一个称为CVE-2019-16920的远程执行代码漏洞 。****该漏洞是未经认证 在2019年9月发现的命令注入问题。****该漏洞的CVSS v31基本得分为9.8，CVSS v20基本得分为10.0。**  

  

对于用户来说，坏消息是供应商将无法解决它，因为它会影响停产的产品。  

  

根据Fortinet所说，此漏洞影响**DIR-655，DIR-866L，DIR-652和DHP-1565路由器系列中的D-Link固件**。

  

**D-Link路由器**

“在2019年9月，Fortinet的FortiGuard实验室发现并报告了 未经认证D-Link产品中的命令注入漏洞（FG-VD-19-117 / CVE-2019-16920），一旦成功利用，可能会导致远程执行代码（RCE）。我们将此视为严重问题，因为该漏洞无需身份验证即可远程触发。” Fortinet发布的安全公告中写道。

  

攻击者可以向“评测网关接口实现命令注入。

  

“该漏洞始于错误的身份验证检查。要查看实际问题，我们从管理页面开始，然后执行登录操作。”继续进行咨询。“在这里，我们通过操作ping\_test将POST HTTP请求实现到“ apply\_sec.cgi”。然后，我们在ping\_ipaddr中执行命令注入。即使返回登录页面，仍然会执行ping\_test操作– ping\_ipaddr的值将执行“ echo 1234”命令在路由器服务器，然后将结果发送回我们的服务器。“

  

专家发现，由于错误的身份验证检查，即使没有必需的特权也可以远程执行代码。

研究人员于9月22日向供应商报告了D-Link的漏洞，该漏洞发生在供应商承认该漏洞的第二天，但三天后证实该产品未发布，因此不会发布补丁。结束 生命（EOL），

  

**披露时间在下方：**

*   **2019年9月22日：FortiGuard实验室向D-Link报告了该漏洞。**
    
*   **2019年9月23日：D-Link确认了此漏洞**
    
*   **2019年9月25日：D-Link确认这些产品已停产**
    
*   **2019年10月3日：公开发布该问题并发布了通报**
