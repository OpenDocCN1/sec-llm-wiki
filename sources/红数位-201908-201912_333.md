# 影响谷歌,三星,华为,小米,三星,Oppo和摩托罗拉手机，Android零日漏洞被积极利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485437&idx=3&sn=44da41150c4466b69b67372aede423f3&chksm=cef36a4ef984e358251075a86f311624a4cab6bf1b07ff1f686bf55916546180943b4a211d53&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485437&idx=3&sn=44da41150c4466b69b67372aede423f3&chksm=cef36a4ef984e358251075a86f311624a4cab6bf1b07ff1f686bf55916546180943b4a211d53&scene=27#wechat_redirect)

  

谷歌威胁分析小组（TAG）表示，针对脆弱的谷歌Pixel，华为，小米，三星，Oppo和摩托罗拉智能手机的攻击正在积极地利用新的Android零日攻击。

  

![](../Images/6285371466b798af719e361784ea5f20.png)

  

此零日漏洞是一个内核本地特权提升（LPE）错误，它使用了Android绑定程序驱动程序中的“先用后用”漏洞，潜在的攻击者可以利用此漏洞来完全控制未打补丁的设备。

  

Google Project Zero研究人员Maddie Stone表示：“如果通过网络发布漏洞利用程序，则只需将其与渲染器漏洞利用程序结合使用，因为可以通过沙箱访问此漏洞。”

  

即使该问题先前已于2017年12月在不带CVE的4.14 LTS Linux内核中以及由Android 3.18、4.4和4.9内核中的Android开放源项目（AOSP）修复，但该错误已在后续版本中重新引入。

  

![](../Images/49bc78d1d394f914610d069b216db909.png)

  

  

影响谷歌,三星,华为,小米,三星,Oppo和摩托罗拉智能手机

根据Stone的说法，跟踪为CVE-2019-2215的漏洞会影响“大多数Android设备于2018年秋季之前”，要求“对每台设备进行少量或完全不需要自定义”。

  

以下Android设备已在Project Zero的错误跟踪器上确认为易受攻击：

  

•具有Android 9和Android 10预览的谷歌Pixel 1和2（和XL）

•三星 S7，S8，S9 

•华为P20 

•小米Redmi 5A 

•小米Redmi Note 5 

•小米A1 

•Oppo A3 

•摩托罗拉 Z3 

•LG 奥利奥手机

尽管Google的“零号项目”通常会在90天后披露漏洞，但被主动利用的漏洞将受到为期7天的披露期限。 

  

斯通说：“经过7天或补丁广泛发布（以较早者为准），该错误报告将对公众可见。”

  

![](../Images/8e703de1b10093d495dbc739b48d3c39.png)

PoC漏洞演示

  

**归因于NSO组**

谷歌的威胁分析小组表示，“据称该漏洞是由国家统计局组织使用或出售的”，这是一家以色列公司，以开发，利用和销售Pegasus Android和iOS间谍软件等漏洞利用和工具而闻名。

  

尽管成功利用此漏洞可以使潜在的攻击者完全控制受感染的Android设备，但不能将其用于远程破坏它们。 

  

AOSP声明说：“在Android上，此问题的严重性等级很高，它本身需要安装恶意应用程序才能进行潜在利用。任何其他媒介，例如通过Web浏览器，都需要与其他利用进行链接，” AOSP声明说。

  

“我们已经通知Android合作伙伴，并且该补丁已在Android Common Kernel上提供。Pixel3和3a设备不易受到攻击，而Pixel 1和2设备将在10月更新中收到此问题的更新。”
