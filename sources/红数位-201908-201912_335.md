# Novter木马专对微软Windows Defender下手

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485437&idx=5&sn=d0bd719d3678f20caa2f70b67bae48f3&chksm=cef36a4ef984e358e7a7cd307c827567c84bf061a0809cb42c5742aea43494abeb3ebbf95a6f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485437&idx=5&sn=d0bd719d3678f20caa2f70b67bae48f3&chksm=cef36a4ef984e358e7a7cd307c827567c84bf061a0809cb42c5742aea43494abeb3ebbf95a6f&scene=27#wechat_redirect)

  

Novter木马，也称为Nodersok或Divergent，是通过尝试禁用Windows Defender来主动锁定Microsoft Windows Defender的最新木马。

  

![](../Images/576d881d6a7e0476934f47429df16ea5.png)

  

上周，三份报告发布了有关  一个新的无文件木马的信息，该木马将Node.JS安装到受害者的计算机上，并将其配置为单击欺诈和其他恶意活动的代理服务器。该木马被Microsoft命名为Nodersok，被Cisco Talos 命名为Divergent ，被趋势科技命名为Novter 。

  

随着Windows Defender逐渐成熟为一个完善的AV解决方案并紧密集成到Windows操作系统中，最近的特洛伊木马一直在努力禁用其实时保护和其他功能。这将使特洛伊木马能够下载其他恶意软件，而没有Defender检测到它们的风险，也不会因检测到现有恶意软件而导致将来的定义更新。

  

正如所有三家公司先前所解释的那样，在安装Novter时，它将执行PowerShell脚本，该脚本禁用Windows Defender并修改Windows Update设置。由于我们已经看到TrickBot和Gootkit在最近的变体中禁用Windows Defender，因此这种情况变得越来越普遍。

  

据同时对Novter进行反向工程的安全研究员  Vitali Kremez称，该恶意软件将添加各种Windows策略，这些策略将禁用Windows Defender中的各种功能。
