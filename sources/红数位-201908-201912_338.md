# 美国国家安全局（NSA）启动新的网络安全局

国家安全局正在重新定义其网络安全代表团和网络安全局将通过未分类的协作和信息共享来增强其伙伴关系。在新成立的网络安全局下–一个统一了NSA的外国情报和网络防御任务的主要组织。

  

![](../Images/3c60d9ef969beccb15241498898aa3d8.png)

  

**美国国家安全局（NSA）宣布成立新的网络安全局-这将有助于保护国内组织免受外国攻击网络攻击—在简短的新闻发布中。**

  

美国国家安全局**（NSA）**有时被昵称为“没有这样的机构”，以机密着称。

  

但是，这个新的理事会似乎标志着一个向原子能机构过去采取更加公开的安全态度的方向。

  

**新国家安全局**

该局还反映了国家网络安全重要性的变化，并暗示了政府机构如何重新考虑应如何组织网络安全部门。

  

**国家安全局将网络防御放在首位**

该局将统一国家安全局当前的外国情报和网络防御行动，将它们合并为一个旨在保护国内组织免受外国网络攻击的“主要组织”。美国国家安全局（NSA）希望该局通过使原子能机构转向向合作伙伴和“客户”提供威胁信息，以及通过其他方式使他们免受网络攻击，来“重振国家安全局的白帽任务”。

  

该局将使国家安全局将其工作转向确保军事和国防工业的安全。一个  短，NSA制作的视频  在新闻稿的末尾提供了有关NSA希望从维护公共什么威胁的详细信息-包括机密信息被窃取的基础设施的攻击，以及“大众大众欺骗。”

  

关键时刻是在该国面临数个安全危机和合理担心的情况下，网络攻击几乎会破坏或破坏计算机上运行的几乎所有内容（银行，投票机和关键基础设施）。

  

国家安全局首席顾问格伦·格斯特尔（Glenn Gerstell）于9月份发表了评论，随后成立了新的董事会，并将新闻发布的重点放在网络防御上。当时，格斯特尔说，  国家安全局不会  在发生网络攻击的情况下“反击”，而原子能机构则专注于保护关键信息和基础设施免遭外国行为者盗窃或破坏。

  

该局不是原子能机构首次向国内私人组织提供有关外国黑客的情报。2011年，由于金融业仍在从2008年的金融危机中恢复，原子能机构开始向  华尔街银行提供网络安全信息  ，以期防止“金融破坏”。

  

**网络安全状况**

该局反映了更广泛的变化，私营部门也正在看到这一变化。网络安全不再被视为整体安全计划的子组成部分，也不被视为技术部门的一部分，而是被视为一项需要高级人才和认真投入资源的必要投资。网络更有可能被  视为脆弱的  网络，需要更好地防御网络攻击。

  

企业越来越依赖物联网或“智能”设备来提供数据。但是这些设备通常没有适当的安全保护，并允许访问点保护安全的网络以及在那里保存的宝贵信息。随着世界之间的联系越来越紧密，黑客有更多机会在网络防御的漏洞之间穿梭，一旦他们访问安全网络便会造成破坏。

  

国家安全局在新闻稿中表示，该机构将“投资并依靠其专家队伍。”目前尚不清楚新董事会是否会导致国家安全局扩大其网络安全队伍。如果是这样，它们可能会遇到私营部门面临的一些问题，因为网络安全专家的数量未能跟上网络攻击的频率，强度和破坏。

  

**国家安全局理事会对网络安全的意义**

新任主任表明，网络安全是原子能机构前所未有的重中之重，并标志着转向公众更多参与国家安全的趋势。时间将证明该局在预防或减少网络攻击的危害方面的有效性，但是国防工业很乐意获得他们所能提供的任何帮助。

  

向前走， 网络安全随着关键基础设施以及我们经济和国防的重要组成部分之间的联系越来越紧密，它将继续变得越来越重要。是否网络安全 行业将能够跟上不断增长的攻击速度还有待观察。
