# 微软宣布2023年1月前将向中小型企业(SMB)提供Win7拓展安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485407&idx=5&sn=25a92da2744edd4fd14f555909a2c49e&chksm=cef36a6cf984e37a97a7deb522f6e8d96939be77c982e21aab7b6e2e95e06b479562a6863be7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485407&idx=5&sn=25a92da2744edd4fd14f555909a2c49e&chksm=cef36a6cf984e37a97a7deb522f6e8d96939be77c982e21aab7b6e2e95e06b479562a6863be7&scene=27#wechat_redirect)

  

微软宣布，还将为中小型企业（SMB）提供Windows 7 扩展安全更新（ESU），以使其在Windows 10迁移过程中保持安全。

  

![](../Images/bf0dbd736cb25eb522e165715c193f04.png)

  

此项优惠是对企业在其环境中部署最新Windows 10版本所采用的不同步伐的回应，以及它们在整个过程结束直到Windows 7终止支持之前都保持系统安全的需求。

  

“考虑到这一点，今天我们宣布，到2023年1月，我们将向所有规模的企业扩展付费Windows 7扩展安全更新（ESU）的可用性，” Microsoft 365公司副总裁Jared Spataro说。

  

**以前仅在批量许可中可用**

在未来三年中，中小型企业将能够按设备购买ESU，价格逐年增加，连续三个月递增12个月。

  

有关Windows 7 ESU定价的信息， Microsoft 建议客户联系  其“客户团队CE，以获取针对特定客户方案定制的价格和订购信息”。

  

Windows 7 ESU以前仅适用于具有Windows 7 Professional或Windows 7 Enterprise批量许可协议的大型企业和教育客户。

  

微软对Windows 7的支持终止后，微软表示： “扩展安全更新（ESU）包括Microsoft安全响应中心（MSRC）定义的针对关键和重要问题的安全更新，最长期限为2020年1月14日之后的三年。”

  

Spataro 补充说： “从2019年12月1日开始，任何规模的企业都可以通过云解决方案提供商（CSP）计划购买ESU 。” “这意味着客户可以在使用Windows 10的过程中与合作伙伴一起获得所需的安全性。”

  

**Windows 7安全修补程序也可以作为微补丁提供**

ACROS Security在9月份表示，在Microsoft终止对Windows 7的支持之后，其运营的0Patch平台将继续向其代理发布漏洞补丁。

  

有关Windows 7 ESU定价的信息，Microsoft 建议客户联系其“客户团队CE，以获取针对特定客户方案定制的价格和订购信息”。

  

由0Patch发布的微补丁是设计用于操作系统的微型补丁，而无需重新启动机器或需要修补的应用程序。

  

“ 0patch联合创始人” Mitja表示：“每个补丁程序星期二，我们将审核Microsoft的安全公告，以确定它们针对受支持的Windows版本修复的哪些漏洞可能适用于Windows 7或Windows Server 2008，并且存在很大的风险可能需要进行微补丁。”科尔斯克当时说。

  

虽然通常会向平台的付费客户提供0Patch的微补丁，但Kolsek表示，极有可能针对高风险安全漏洞（例如可用于创建自动传播恶意软件的漏洞）进行例外处理。
