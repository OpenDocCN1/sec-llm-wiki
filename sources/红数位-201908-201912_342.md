# 苹果iOS 13新Bug：破坏了某些应用中的触摸ID

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485407&idx=8&sn=1364f78dcd142a17268ba41df7045680&chksm=cef36a6cf984e37a97317fad1620b5e4a24b5f7fdd7e29148614877a20e89847fe34ee64a725&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485407&idx=8&sn=1364f78dcd142a17268ba41df7045680&chksm=cef36a6cf984e37a97317fad1620b5e4a24b5f7fdd7e29148614877a20e89847fe34ee64a725&scene=27#wechat_redirect)

  

苹果显然最近进入了一个疯狂的更新，最近几天发布了如此多的软件更新，但这并不一定意味着该公司设法解决了所有错误。

  

未能解决的问题之一是具有Touch ID并更新到iOS 13的iPhone。

  

![](../Images/ada486a600c46e91676a62268bb32d03.png)

  

根据报告，**这些iPhone的所有者无法再使用其指纹在一系列应用中进行身份验证。**该问题似乎与Touch ID API有关，在安装最新的iOS主要版本后，Touch ID API出现了问题。

  

在启动诸如移动银行甚至密码管理器之类的应用程序时，不再显示扫描指纹的提示，尽管从外观上看，它是在后台触发并运行的。

  

**该错误发生在iOS 13到iOS 13.1.1上，并且不会影响具有Face ID的iPhone型号，例如iPhone X和iPhone 11。**

  

**如何“修复”错误**

受此错误影响最大的是移动银行应用程序，因为通常需要登录ID身份验证才能登录，但其他应用程序也可能会遭到攻击，包括密码管理器和带有指纹保护功能的客户端。

  

尽管Apple尚未确认该错误，但已经存在修复程序。遇到该错误且不再看到Touch ID提示的用户仍可以用注册的手指触摸指纹传感器以登录。由于该提示在后台运行，即使未显示任何提示，扫描也应按预期进行屏幕。

  

根据上述消息来源，**在某些情况下，摇动iPhone（对吗？****）也可以暂时解决此问题。**

  

Apple修复此补丁的速度有待观察，但是鉴于最近的更新发布速度，现在应该每周有新补丁发布。
