Comodo论坛被黑泄露了170,000个用户的数据

属于Comodo论坛所有用户一半以上的帐户数据已被盗，现在被放到网络在线交易。该漏洞可能是通过利用为论坛提供支持的软件中的漏洞来实现的。


Comodo今天发布了一个安全通知，通知用户入侵者可能已经访问了论坛数据库。



通知开始说：“最近，vBulletin软件中的一个新零日漏洞已公开，它是用于网站注释（包括Comodo论坛）的最受欢迎的服务器应用程序之一。”


vBulletin中的错误非常关键，非常容易利用。一周前已经公开了详细信息，但是漏洞利用经纪人已经知道了三年。


自漏洞利用代码发布以来，攻击者开始捣鼓由vBulletin支持的论坛。一个僵尸网络甚至 通过修改易受攻击的代码来破坏服务器，从而保护了服务器，从而使命令执行需要输入密码。


Comodo通知其论坛用户

根据Comodo的公告，攻击者于周日美国东部时间04:57利用vBulletin安全漏洞；他们的行动导致“在Comodo论坛上潜在的数据泄露”。


该调查尚处于初期阶段，并且正在努力确定已访问了哪些数据。


Comodo论坛由开放源代码的Simple Machine Forum软件提供支持，但是vBulletin在另一个专门用于产品更新和讨论的板上使用，该委员会的成员要少得多。同样由Comodo开发的ITarian论坛拥有45,300个用户，并且位于vBulletin上。他们发布了类似的公告和相同的建议。


“论坛上的用户帐户包含诸如用户名，名称，电子邮件地址，用于访问论坛的最后IP等信息，如果使用的话，在非常有限的情况下可能还会包含一些社交媒体用户名。” - 科摩多



通知中指出，所有密码均以加密形式存储，但为预防起见，建议论坛用户更改密码。


填补空白

在一个用户交换和出售因破坏或泄漏事件而导致的数据库的站点上，有人提供了一个转储，其中至少包含超过170,000个Comodo论坛用户的密码，电子邮件和用户名。根据Comodo的说法，他们的论坛有大约245,000个注册用户。


广告数据库的个人特别指出，该转储来自Comodo的讨论网站，该网站运行在Simple Machines Forum（SMF）软件上，并且数据是9月29日以来的最新信息。他们还说，密码是使用MD5算法进行哈希处理的，即不仅非常脆弱，而且非常容易破解并找到哈希的原始字符串。



外媒收到了该数据库的样本，并能够验证它是真实的。该论坛中的大多数用户都是非活跃的Comodo论坛成员，但其中一个是活跃用户，并确认了我们提供的电子邮件地址以及他们在论坛上使用的电子邮件地址以及其他详细信息。


数据库中可用的用户详细信息的全部范围尚不清楚，但外媒看到的示例包括以下内容：


  • ID

  • 名称

  • 国家

  • 上次登录的IP地址

  • 密码及其盐

  • 提供的出生日期

  • 安全问题

  • 哈希安全答案

  • 登记日期

  • Messenger使用者名称

  • 总登录时间

  • 某些信息仅提供给提供该信息的用户 



更新[10.01.2019]：对该事件更熟悉的人告诉外媒，最初的漏洞是通过利用vBulletin漏洞在ITarian论坛上发生的。从那里，攻击者以某种方式设法访问了Comodo的SMF驱动的论坛-一种理论上他们使用了被盗的凭据。


安全研究员发布的非官方补丁

vBulletin已发布官方补丁。

这个远程执行代码漏洞存在于include / vb5 / frontend / controller / bbcode.php  文件中，由（evalCode ($code）函数引起。


执行此函数时，它将使用eval（）函数启动$ code参数中传递的任何命令。这可以是系统上可用的任何命令，例如可能添加新用户，打开防火墙端口或下载并执行文件和脚本。


为了修复此漏洞，安全研究人员Nick Cano创建了一个非常简单的补丁， eval()将evalCode函数中的语句注释掉。


要自己添加此补丁，请编辑文件include / vb5 / frontend / controller / bbcode.php 并查找以下功能：


function evalCode($code){    ob_start();    // find in: public_html/includes/vb5/frontend/controller/bbcode.php    eval($code);    $output = ob_get_contents();    ob_end_clean();    return $output;}


现在编辑此函数，以便将eval（$ code）注释为：


function evalCode($code){    ob_start();    // comment out. idk what it breaks but it's a fix for now    //eval($code);    $output = ob_get_contents();    ob_end_clean();    return $output;}


一旦注释掉eval（）函数，就不再可以利用此特定漏洞。


强烈建议需要的用户立即应用上述补丁来解决此漏洞。
