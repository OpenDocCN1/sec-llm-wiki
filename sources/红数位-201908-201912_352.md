# 全球第二大听力集团DEMANT被勒索直接损失达6亿人民币

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485377&idx=2&sn=2a28fd6befdbaf76d91decd7ce449ad0&chksm=cef36a72f984e364658fdfb751c150432cc19c8e879a155b4b3d0947a21b19b9748b82dafaaa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485377&idx=2&sn=2a28fd6befdbaf76d91decd7ce449ad0&chksm=cef36a72f984e364658fdfb751c150432cc19c8e879a155b4b3d0947a21b19b9748b82dafaaa&scene=27#wechat_redirect)

丹麦W.D.H听力集团(William Demant Holding )是历史悠久的综合性听力集团，由创始人汉斯·戴蒙特创立于1904年，他的妻子是一位听力损失患者，他希望可以帮助妻子和其他受听力损失困扰的人们过上更好的生活。也是目前听力行业唯一产品线涵盖助听器、人工中耳、骨导助听器、电子耳蜗及调频语训系统的全面听力解决方案提供者，同时也是全球听力检测设备领域的领先者。

  

![](../Images/de8997585b4d8d905f8745e7f4451695.png)

丹麦Demant(W.D.H听力集团)经历了超过110多年漫长的专业积累，目前，W.D.H听力集团旗下拥有**Oticon奥迪康, Bernafon博瑞峰, Sonic,Sennheiser森海塞尔,GSI，Medrx, Ampllivox等一大批享誉世界的专业听力品牌，同时也是PHILLIPS飞利浦公司的全球听力技术合作伙伴。****（2019，William Demant Holding A / S更名为Demant A / S）**

Demant集团在全球市场开展业务，在30多个国家/地区设有公司，拥有14,000多名员工，年收入达140亿丹麦克朗\[1465亿人民币\]。产品销往130多个国家/地区，在这些国家，通过听力健康创造出改变生活的差异。

**作为全球领先的助听器制造商的迪曼特集团（Demant）表示，它在9月3日经历了一次“严重事件”。****尽管该公司拒绝澄清事件的性质，但当地的报道透露为勒索软件攻击。**

  

“目前还不清楚是否是黑客攻击导致丹麦公司Demant的IT基础架构严重崩溃。” 外媒报道。“但是，有很多迹象表明，根据IT安全公司FireEye的日常员工安全专家Jens Monrad的说法，这可能是勒索软件攻击袭击了公司。”

  

![](../Images/5c20a42fff0099ba56b161adc88def8f.png)

  

尽管该公司已经备份了数据，但攻击的规模似乎对其恢复具有重大影响。

  

*“该集团的IT基础架构受到网络犯罪的打击。**我们通过关闭多个站点和业务部门中的IT系统来对问题做出快速反应，这限制并限制了问题的发生，但是整个价值链的关键业务流程仍然受到事件的影响，包括研发，生产和分销。**”。*

  

*“我们将继续加大工作量，以适应事件发生以来积压的积压工作，以重建整个供应链中的必要库存，并减少维修和定制助听器的周转时间。**在丹麦的放大器生产基地和法国的人工耳蜗生产基地，我们仍处于恢复和加速阶段。**”*

  

这些中断的累积影响将对该公司2019全年造成5500万至6.5亿丹麦克朗（合8000-9500万美元）**【或高达6亿人民币】**的负面财务影响。这要归功于该公司的预期购买保险政策减少损失，可扣除1亿丹麦克朗（合1500万美元）。

  

Demant预计，本次直接损失将达5000万丹麦克朗（合700万美元）**\[5000万人民币\]**。

  

该公司的听力批发业务受到的影响尤其严重，约占估计销售损失的一半。  

  

“这一事件使我们无法在一些一年中最重要的月份执行我们雄心勃勃的发展活动-尤其是在美国，这是我们最大的市场，”官方说道。

  

“尽管我们尽最大努力以最好的方式运营业务，但我们立即专注于支持现有客户以防止他们受到事件的影响，这已经影响了销售，并有可能影响我们全年剩余的自然增长率。”

  

**对于目前还没有准备好应对继续在全球范围内传播的勒索软件流行的巨头公司来说，这一消息是另一个警告。**

全球巨头受勒索软件打击的主要制造商包括：全球最大的铝生产企业之一挪威金属和能源巨头Norsk Hydro，该公司报告称这次袭击造成的损失高达3亿人民币；航运巨头马士基和快递服务公司FedEx分别遭受了超过3亿美元的损失，台积电芯片制造基地遭遇勒索病毒，损失超过11亿，世界最大飞机零件供应商之一比利时飞机零部件制造商ASCO Industries损失超2.8亿；以及瑞士特种设备制造商专用汽车制造商Aebi Schmidt，最近一期巨头勒索事件是9月24日全球军工百强德国莱茵金属惨遭恶意软件袭击，每周损失欲达3000万人民币。
