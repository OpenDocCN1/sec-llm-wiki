技术细节


由于恶意软件在变量声明和环境变量创建过程中使用的命名约定，Talos识别出了一种新型的模块化恶意软件，该恶意软件可用于便利安装以前未记录的恶意软件家族，我们称其为Divergent。尽管我们无法确定所使用的传递机制，但我们能够对恶意软件加载器以及用于安装在受害系统上的Divergent恶意软件进行分析。Divergent是一个恶意软件家族，旨在通过使用点击欺诈为攻击者创造收益，这与其他点击欺诈恶意软件（例如Kovter）类似。以下各节介绍了与Divergent恶意软件的安装和操作相关的技术细节。


安装


该恶意软件与其他流行的无文件恶意软件家族（尤其是Kovter）具有许多相似之处。与Kovter一样，它在很大程度上依赖于注册表来配置和存储配置数据，同时避免对磁盘上的文件进行更传统的按访问端点扫描。它还使用注册表中的密钥来保持持久性，并依靠PowerShell在受感染的主机上自行安装。


首次在受害者的计算机上交付并执行时，恶意软件采用可移植可执行（PE）格式。但是，它的首要任务是以一种不太可疑的形式将自身安装到系统中，即以HTML Application（HTA）的形式从注册表中加载恶意软件。


安装首先创建几个注册表项，其中包含加载程序的不同部分以及恶意软件PE的数据。该恶意软件读取嵌入在其数据部分中的所有信息，并创建三个新的随机命名的注册表项，每个注册表项包含使用反射注入执行恶意软件PE所需的加载程序代码的不同阶段。 


接下来，将HTA加载程序写入CSIDL_COMMON_APPDATA文件夹（通常为C：\ ProgramData \），并通过将条目添加到“ HKLM \ SOFTWARE \ Microsoft \ Windows \ CurrentVersion \ Run”注册表项中来设置为每次用户登录时执行。

结论


所描述的恶意软件加载器目前正在积极开发中。Talos已观察到用于安装Divergent恶意软件的加载程序的多个版本。攻击者正试图通过使用点击欺诈将这些感染货币化。随着攻击者测试新技术和方法以最大化其创收能力，威胁格局正在不断发展。组织应意识到这些变化，并确保其安全程序能够针对这些变化的策略，技术和程序保持有效。思科高级恶意软件防护（AMP）漏洞防御引擎成功阻止了该威胁，并且所产生的事件数据有助于我们对威胁进行分析。Talos将继续监视威胁状况，以确保客户受到保护。
