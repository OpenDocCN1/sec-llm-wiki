# Apple推出iOS / iPadOS 13.1.1修复了第三方键盘应用程序的安全性问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490895&idx=7&sn=eab0bb151f3a7dc686bd9c470f4ae384&chksm=cef370fcf984f9ea3c1f33d90832a5a83fe207fa99f1bd18445d353deadf32d5109bce5fd604&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490895&idx=7&sn=eab0bb151f3a7dc686bd9c470f4ae384&chksm=cef370fcf984f9ea3c1f33d90832a5a83fe207fa99f1bd18445d353deadf32d5109bce5fd604&scene=27#wechat_redirect)

  

苹果今天发布了针对iPhone和iPad设备的最新iOS 13.1和iPadOS 13.1操作系统的次要安全更新，以解决重要的安全问题以及其他一些错误和退化。

  

![](../Images/8d813e4e76031118eea0d43b999fde69.png)

  

现在可以为所有受支持的iPhone和iPad设备下载iOS 13.1.1和iPadOS 13.1.1软件更新，解决了严重的安全问题，该问题可能使第三方键盘应用程序（例如Microsoft的SwiftKey或Google的GBoard）获得完全访问权限设备的。

  

最重要的是，iOS 13.1.1和iPadOS 13.1.1更新还修复了可能阻止设备从备份还原的问题，该问题可能导致Reminders应用程序缓慢同步，这是一个Safari错误，可能会重新启用搜索建议以及可能导致电池更快耗尽的问题。

  

![](../Images/27db8ab79bb389ac9188c677b71ae400.png)

  

对于最新的iPhone 11，iPhone 11 Pro和iPhone 11 Pro Max设备，iOS 13.1.1软件更新还修复了可能影响Siri请求识别的问题。

  

![](../Images/b63e6224394ecf66a9a6146f3f237719.png)

  

苹果敦促用户立即更新其设备

即使iOS 13.1和iPadOS 13.1发行仅在几天后，iOS 13.1.1和iPadOS 13.1.1软件更新仍然非常重要，必须由所有用户安装。因此，我们建议所有iPhone和iPad用户立即将它们安装在其设备上。

  

要将您的iPhone或iPad设备更新到iOS 13.1.1或iPadOS 13.1.1，只需打开“设置”应用，转到“常规”部分，然后点击“软件更新”。您应该立即看到新版本，因此只需点击“下载并安装”按钮即可将其下载并安装到设备上。
