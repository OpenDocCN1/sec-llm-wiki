# 黑客公布苹果芯片级(A5到A11)越狱漏洞Checkm8，称永久性不可修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490895&idx=4&sn=a895d46d2121c1a9889e2a932d34d812&chksm=cef370fcf984f9ea0e2fa36624211a3ac2e2dea8dab829722af293202d07b7fa2394cf0c4c8f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490895&idx=4&sn=a895d46d2121c1a9889e2a932d34d812&chksm=cef370fcf984f9ea0e2fa36624211a3ac2e2dea8dab829722af293202d07b7fa2394cf0c4c8f&scene=27#wechat_redirect)

  

专门研究iOS安全性的研究人员声称已创建了bootrom漏洞，可以利用该漏洞对数以亿计的iOS设备进行越狱，包括iPhone 4S和iPhone X之间的所有iPhone。

  

![](../Images/9acadf2025ff26d92e76159a1fb8310d.png)

  

这位使用在线绰号axi0mX的黑客免费发布了该漏洞利用程序，希望它能使安全研究人员和iOS越狱社区受益。他将其描述为“永久性，不可修补的bootrom攻击”，“可能是多年来iOS越狱社区中最大的新闻。”

  

![](../Images/4d8482e4c5ba8a0c6d6ed1fd225f92e8.png)

![](../Images/e36bc4b331b909f43a900500c580e5e7.png)

  

该漏洞被称为Checkm8，本身并不是一个完整的越狱漏洞，但它可以用于具有Apple处理器的越狱设备，**从A5（于2011年推出iPad 2和iPhone 4S推出）到A11（于2017年推出） iPhone 8和iPhone X的发布）。****iPhone XS和XR，2019 iPad Air和iPhone 11中配备的具有A12和A13处理器的设备似乎没有受到影响。**

  

axi0mX说，

该安全漏洞的别名是axi0mX，被安全研究人员称为“ checkm8”。该攻击利用了所谓的bootrom漏洞。顾名思义，**bootrom指的是只读存储器（ROM），其中包含iPhone的启动（或启动）指令。****由于内存是只读的，因此无法通过安全更新修补漏洞。**

  

研究人员声称是在分析苹果大约一年前发布的一个iOS更新后发现了它，该更新修复了iBoot USB中的一个严重的无使用后漏洞。axi0mX指出，在大多数设备上都不容易利用此漏洞。

  

“针对较旧设备的bootrom漏洞使iOS更好地适合所有人。越狱者和调整过的开发人员将能够在最新版本的手机上越狱，而他们无需停留在较旧的iOS版本上等待越狱。他们将更加安全，” 发布漏洞利用后axi0mX在Twitter上说。

  

他补充说：“对于对Apple Bug Bounty感兴趣的安全研究人员来说，这也将更好。他们不需要手头的漏洞，因此他们可以访问研究所需的信息。可能会立即向Apple报告更多漏洞。”

  

由于bootrom是只读的，因此无法使用软件或固件更新来修补bootrom（也称为SecureROM）中的漏洞。

  

**研究人员在GitHub上公开了Checkm8攻击的源代码。**

**hxxps://github.com/axi0mX/ipwndfu**  

  

星期五在推特上说axi0mX表示：“直到今天，最后一款使用公开bootrom攻击的iOS设备是iPhone 4，该手机于2010年发布。” “这可能是iOS越狱社区多年来最大的新闻。为了iOS越狱和安全研究社区的利益，我免费发布了漏洞利用程序。”![](../Images/f4a241a12983cdfd22b71c6fb3cbaf77.png)

  

利用发布和越狱

Axi0mX认为，发布BootROM漏洞“针对较旧的设备可使iOS更好地适合所有人”。

  

他说：“越狱者和调整过的开发人员将能够越狱最新版本的手机，而他们无需停留在较旧的iOS版本上等待越狱。” “他们会更安全。”

  

他还表示，该漏洞利用将帮助对苹果的Bug Bounty  计划感兴趣的安全研究人员，因为它将使他们能够更多地访问研究所需的手机部件。–因此可能会立即向Apple报告更多漏洞。

  

但是，安全领域中的一些人担心威胁者可能将其利用为恶意目的，而有些人则在Twitter上称这种公共利用为“不负责任的”。

  

![](../Images/87a81525a62ab2268074602dcbfeae60.png)

  

“我支持人们越狱手机的权利，”伊娃·加帕林在推特上说。“但是我也为即将到来的iOS速配软件和跟踪软件的功能升级做好准备。”

  

里德（Reed）表示，对苹果和iOS用户而言，公开利用漏洞主要意味着坏消息，“但也有一些积极意义。”

  

他说：“首先，就任何人所知，这种攻击还没有被武器化。” “但是，当然，它可能已经被罪犯，Cellebrite和Grayshift之类的取证公司以及NSO之类的监视公司秘密使用。其次，使checkm8可以远程利用的任何可能手段都将依赖于iOS中的漏洞。尽管Apple无法修补受影响设备中的bootrom漏洞，但他们当然可以修补iOS软件。”

  

研究人员已经发表了一系列利用iPhone开辟越狱的漏洞。一月份，一位研究人员发表了他所谓的概念验证漏洞，该漏洞将使远程攻击者越狱用户不知道的iPhoneX，从而使他们能够访问受害者的数据，处理能力等。

  

**苹果目前暂未对此漏洞发布任何回应。**
