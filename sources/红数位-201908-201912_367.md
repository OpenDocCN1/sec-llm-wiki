# 全球军工百强德国莱茵金属惨遭恶意软件袭击，每周损失欲达三千多万

德国莱茵金属公司（Rheinmetall GmbH）为德国一家战斗车辆武器配件及防卫产品制造商，著名产品包括豹2、M1A1、M1A2等装甲车辆及自行火炮的主炮。

世界著名坦克中，美国M1、德国豹Ⅱ、以色列梅卡瓦Ⅳ、日本90式、意大利公羊Ⅱ五种坦克的火力方面都采用了莱茵公司的滑膛坦克炮。特别是M1和豹Ⅱ采用了最新的L55RH-120mm滑膛炮，炮口初速达到1750m/s，使用钨合金弹，在常温状态下穿深达900mm均质钢装甲，而且精度相当高。射程5000m，为目前射程最远的坦克火炮。火炮性能非常出色。莱茵金属公司成立于1889年,拥有员工19200名，年销售额约为4.0亿欧元（2007年）。

总部位于德国的德国莱茵金属公司（Rheinmetall）昨天宣布，由于受到恶意软件攻击，其在美国，巴西和墨西哥的汽车工厂的生产受到了严重干扰。

  

攻击涉及一个未知的恶意软件，该攻击于9月24日晚上开始。该公司表示，该事件导致该恶意软件进入IT系统的工厂受到“重大破坏”。

  

该公司认为，从攻击中恢复需要花费两到四周的时间，并且估计从第二次攻击开始，该事件将导致每周损失300万欧元（2336万人民币）至400万欧元（3115万人民币）。该公司已向客户保证，它将能够在短期内交付订单。

  

该事件提醒人们最近发生了一些涉及文件加密勒索软件的攻击，但该公司拒绝证实或否认这一理论。该公司表示，除了其网站上的公告外，目前没有提供任何其他信息。

  

![](../Images/f0aeae529d9e5cf741e2203dbca3016d.png)

莱茵金属集团官网公告

  

“攻击主要针对美洲（美国，墨西哥，巴西）的系统，而仅针对汽车系统。该公司发言人通过电子邮件说：“该地区以外和国防领域的其他系统目前都没有受到影响。”

  

违规行为被披露后，该公司股价暴跌。

  

最近几个月受勒索软件打击的主要制造商包括：挪威金属和能源巨头Norsk Hydro，该公司报告称这次袭击造成的损失高达4100万美元；比利时飞机零部件制造商ASCO Industries；以及瑞士特种设备制造商，专用汽车制造商Aebi Schmidt。
