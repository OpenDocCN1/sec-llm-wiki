# Windows 10累积更新KB4517211修复了音频错误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485260&idx=3&sn=1c2cb401cb9f1261d6cd8de7871921f7&chksm=cef36afff984e3e973b20a6467b4b56469c1f384726ab80ef86efdf4a9f5092e3ddb23d7a6a0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485260&idx=3&sn=1c2cb401cb9f1261d6cd8de7871921f7&chksm=cef36afff984e3e973b20a6467b4b56469c1f384726ab80ef86efdf4a9f5092e3ddb23d7a6a0&scene=27#wechat_redirect)

  

Microsoft针对Windows 10版本1903或2019年5月更新发布的最新累积更新解决了在玩游戏时会损坏音频的问题。

  

Windows 10累积更新KB4517211已于9月26日发布到Windows 10版本1903，作为可选更新。但是，音频修补程序将作为10月8日补丁星期二周期的一部分自动发送到所有设备。

  

![](../Images/db7a355f6f45178ed482ed3098eb8a8e.png)

  

微软在本月初承认了该错误，并解释说某些安装了累积更新KB4515384的计算机在游戏中可能会遇到音频中断的情况。

  

**立即修复**

该公司表示，这完全是因为音频合作伙伴要求进行更改。

  

“微软已经收到报告，某些游戏的音频比预期的安静或不同。应某些音频合作伙伴的要求，我们实施了兼容性更改，使某些游戏可以查询支持并呈现多通道音频。由于客户的反馈，我们正在恢复此更改，因为某些游戏和某些设备未按预期呈现多通道音频。这可能会导致游戏听起来与客户习惯不同，并且可能缺少渠道。”微软说。

  

![](../Images/1e60ee9481a6aa27e1734280aba48109.png)

  

累积更新KB4515384是9月10日发布的Windows 10版本1903的安全补丁程序，解决了Windows 10中的漏洞。

  

该问题仅限于Windows 10版本1903，其他功能更新均不受影响。

  

Windows 10 May 2019更新是Windows 10的最新稳定版本，Microsoft目前正在将其推广到世界各地的设备。尽管某些升级块仍然存在，但用户可以通过在Windows Update中检查更新来手动安装May更新。

  

Windows 10的新版本预计将在本月定稿为19H2，并在10月或11月开始公开发布。
