# 最近Mac无法开机背后罪魁祸首居然是Google Chrome浏览器所为

今天我们表示道歉，并且揭秘真正的罪魁祸首：  

**Google Chrome更新导致！**

  

大量报告的Mac无法启动的原因是最近的Google Chrome浏览器更新损坏了必要的操作系统文件夹。安装更新后，受影响的用户发现他们不再能够启动进入macOS。

  

昨天我们报告说，某些Avid Media Composer视频编辑程序用户在关闭或重新启动后无法启动Mac。尽管有些用户担心这是一种病毒，但他们认为系统文件夹已损坏。

  

事实证明，此问题不是由病毒或Avid更新引起的，而是**由错误的Google Chrome for Mac更新引起的，该更新导致/ var符号链接被删除。**

  

根据Google Chrome浏览器的公开错误帖子，这是由新版本的Google软件更新程序（代号为Google Keystone）中的错误引起的。

  

![](../Images/1ab952469aead726d2558362a294d39d.png)

来自Google工程师的帖子  

  

Mac博客Macintosh先生  解释说，这是由于运行macOS 10.9 – 10.14 Mojave的用户禁用了软件完整性保护（SIP）。

  

他们进一步指出，许多Avid用户使用第三方视频卡进行视频编辑，并且需要禁用SIP才能使用它们，这可能是该社区中许多人注意到此问题的原因。

  

Google发布了一篇有关如何解决此问题的支持文章，**方法是删除当前的Google Updater程序包，然后重新创建/ var符号链接。**

  

Google说：我们最近发现，Chrome更新可能附带一个错误，该错误会损坏禁用了系统完整性保护（SIP）的macOS计算机上的文件系统，包括不支持SIP的计算机。在我们完成解决该问题的新更新时，我们已暂停发行。

  

如果您尚未采取措施禁用系统完整性保护，并且您的计算机位于OS X 10.11或更高版本上，则此问题不会影响您。

  

要恢复受此错误影响的计算机，  请引导至恢复模式，然后从“实用工具”菜单中打开“终端”应用程序。

  

**在终端应用程序中，您可以运行以下命令：**

```
chroot /Volumes/Macintosh\ HD   # "Macintosh HD" is the defaultrm -rf /Library/Google/GoogleSoftwareUpdate/GoogleSoftwareUpdate.bundlemv var var_back  # var may not exist, but this is fineln -sh private/var varchflags -h restricted /varchflags -h hidden /varxattr -sw com.apple.rootless "" /var
```

  

  

然后重启。这将删除受影响的Google软件更新版本，然后恢复文件系统的损坏部分。

  

注意：此页面的早期版本提到了OS X 10.9，而不是OS X 10.11。

  

至于Avid，他们很高兴这不是他们的程序导致了问题，并发布了声明：

  

*今天，Avid正在确认我们的一些客户遇到的重启问题的根本原因已经确定，并且与Avid及其创意工具无关。**Google确认Chrome更新“可能附带了可能损坏macOS计算机上的文件系统的错误。**” Google已暂停其发布并向受影响的用户提供了说明。*

  

*Avid也很高兴分享它尚未收到受影响客户的数据丢失报告。**从Avid意识到这一问题开始，我们的团队就与客户，Apple和合作伙伴进行积极合作，以确定解决方案并将其传达给客户。**目前，大多数受影响的Avid客户已通过重新安装macOS从此问题中恢复过来。**Avid没有收到来自非Mac操作系统上运行的客户的事件报告。**重申一下，这不是Avid的问题，正如一些早期媒体报道所报道的那样。**我们为Avid，Apple和我们的合作伙伴的协调响应感到自豪，我们共同感谢客户在我们为快速解决此问题而给予的耐心，支持和帮助。*

  

*Avid首席执行官Jeff Rosica表示：**“ Avid感到高兴的是，解决了部分客户面临的重启问题，尽管Avid产品不是根本原因，但我们一直非常重视使所有客户重新上网并重新投入工作。**在过去的36个小时中，与Apple，PACE和其他合作伙伴紧密合作进行的尽职调查耗尽了所有选择，我们已尽快到达正确的位置。**我们要特别感谢Avid的客户和用户社区在此时通常表现出的强大支持，尤其是那些欢迎我们的工程师进入工作室进行故障排除的人。**”*
