# MAC预警：Avid视频编辑器将导致Mac电脑无法开机！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247485107&idx=4&sn=6baeceba0dd31651e90223cdac934e40&chksm=cef36b00f984e2160c4deb2c96992d2dec8f9b3ddac62decfca72a9142cd8be55d52b41ca60b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247485107&idx=4&sn=6baeceba0dd31651e90223cdac934e40&chksm=cef36b00f984e2160c4deb2c96992d2dec8f9b3ddac62decfca72a9142cd8be55d52b41ca60b&scene=27#wechat_redirect)

  

**Avid视频编辑器公司报告说，安装有Avid软件的用户，当他们关闭Mac时，以后将再无法启动MAC。**目前尚不清楚是什么导致了此问题，但是它似乎正在影响安装了Avid Media Creator软件的Mac OS X的较旧版本。

  

![](../Images/0157bcd81b3b8b7bee70d03e474a1868.png)

  

正如报道的品种，电影和电视编辑在世界各地昨天突然发现，关停后，他们再也无法引导其Mac电脑，如果他们有安装在计算机上的Avid Media Composer的。 

  

尽管Apple或Avid对此没有任何消息，但Avid编辑器Facebook页面上的帖子指出，运行OS X 10.13.x及更早版本且安装了Avid Media Creator的Mac会突然发现其帐户已更改为标准用户，并且可能会收到有关其iLock许可证的错误，这将导致其Mac无法启动。

  

![](../Images/86c1074ea2d18d51f81ff8770eaed2d8.png)

  

由于某些人担心这是针对这些计算机的恶意软件感染，他们建议所有用户断开与Internet的连接，直到获得更多信息为止。  

  

其他人认为它不是病毒，而是病毒更新，不兼容，它导致macOS使用的系统文件夹损坏，并导致系统随后无法启动。

  

![](../Images/cf4e591f87bc34723215de6f28d3b369.png)

  

目前，用户报告他们可以通过从拇指驱动器重新安装macOS并选择在现有安装上进行安装，而不是执行完整的擦除和安装操作来重新启动Mac。

  

我们已联系Avid和Apple，并将通过任何回复更新此故事。

  

“ Avid意识到重启问题会影响运行某些Avid产品的Apple Mac Pro设备，该问题已于昨天晚些时候出现。对于我们的工程和支持团队，他们一直努力确定并解决根本原因，此问题是当务之急。要了解更多信息，我们将立即将信息直接发布给我们的客户，并通过我们的社区论坛和社交媒体平台发布给我们，以便为所有受影响的客户解决此问题并防止出现任何其他问题。”
