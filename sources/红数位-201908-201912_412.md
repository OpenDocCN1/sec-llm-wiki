# Windows 10补丁新的CPU飙高以及KB4515384系统断网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484943&idx=4&sn=78f2002a150410bbcdf4122f416c89e2&chksm=cef36bbcf984e2aa141b1099b485a68c5b9d8c0ea5063d3aa8fa5a693f108f148b5b52fed783&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484943&idx=4&sn=78f2002a150410bbcdf4122f416c89e2&chksm=cef36bbcf984e2aa141b1099b485a68c5b9d8c0ea5063d3aa8fa5a693f108f148b5b52fed783&scene=27#wechat_redirect)

  

微软最近在Windows 10中确认了另一个高CPU使用率的错误，而这次2019年9月更新并不是唯一受到影响的版本。

  

![](../Images/6c3211045b95ff6c000f3786ff113600.png)

  

该软件巨头在其Windows 10更新仪表板上解释说，**作为补丁周二周期的一部分，2019年9月的累积更新带来了一个问题，****导致许多设备的CPU使用率过高。**

  

微软表示，故障会影响输入法编辑器或IME，并且已经存在手动解决方法来修复它。然而，一个完整的补丁正在开发中，它将在未来几周内上线，尽管尚未提供特定的ETA。

  

“某些输入法编辑器（IME）可能无响应或可能具有较高的CPU使用率。微软解释说，受影响的IME包括CHS（简体中文）和CHT（繁体中文）和Changjie / Quick键盘。

  

本月晚些时候推出的新一组Windows 10累积更新

根据以下列表，Windows 10的客户端和服务器版本都会受到影响：

  

Windows 10，版本1903 

Windows 10，版本1809 

Windows 10企业版LTSC 2019 

Windows 10，版本1803 

Windows 10，版本1709 

Windows 10，版本1703 

Windows 10企业版LTSC 2016 

Windows 10，版本1607 

Windows Server 2016，版本1803 

Windows Server 2016，版本1709 

Windows Server 2019，版本1903 

Windows Server 2019，版本1809 

  

  

**Windows 10的新一轮累积更新预计将在本月底上线，希望此问题的解决方案也将包括在内。**

  

同时，Microsoft建议用户将“触摸键盘和手写面板服务”切换为手动启动类型，以防止自动运行并解决错误。完整修补程序上线后，您可以返回到服务的原始配置。

  

**新问题多多：****开始菜单无响应，变哑，断网！****！****！**  

周二补丁日，微软下发了一大批补丁，其中包括对部分v1903用户电脑CPU占用率过高问题的修复。

  

然而继开始菜单无响应、声卡“变哑”等问题后，网卡问题也纷纷出现。

  

在反馈中心，部分安装**KB4515384补丁**迭代为Build 18362.356的用户表示，其网卡适配器挂了，有线和Wi-Fi都没法使用，症状还有设备管理器中出现名为“#2”的隐藏设备。

  

诡异的是，卸载KB4515384补丁后，一切又恢复正常了。Reddit上也有类似的声音出现，受影响用户表示，下载安装Intel最新的网卡驱动无济于事。

  

就目前情况来看，**KB4515384问题不少**，希望微软能尽快查明并予以解决。
