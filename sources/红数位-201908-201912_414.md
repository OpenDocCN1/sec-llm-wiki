# 美国最大的广播电台之一安德康传播受勒索影响全美办事处

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484921&idx=4&sn=8bea3215ff2c3aa507b70932d40bf2a5&chksm=cef3684af984e15cc68e931508378166ec7a46b68ebcf979807de8771d624bc1aa0996e6b7a4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484921&idx=4&sn=8bea3215ff2c3aa507b70932d40bf2a5&chksm=cef3684af984e15cc68e931508378166ec7a46b68ebcf979807de8771d624bc1aa0996e6b7a4&scene=27#wechat_redirect)

  

安德康传播（Entercom Communications）是美国最大的广播电台所有者之一，被曝目前正在处理类似于勒索软件事件的网络攻击。该问题在上周末发生，影响了该公司在全美各地的所有办事处。

  

![](../Images/9c528aa7baf333372372a3fdf05bd356.png)

  

Entercom的全美网络拥有超过235个广播电台，每月向超过1.7亿人播放新闻，体育和音乐。

  

**该司对此事件保持沉默**

据报道，该公司尚未发布有关其网络或网络事件现状的官方声明，该事件显然扰乱了电话和电子邮件通信，音乐调度，生产，计费和其他内部数字系统。

  

All Access  出版物本周通过电子邮件与广播电台小组联系的尝试均未成功，因为这些消息回显了一条自动消息，通知“技术问题”影响了电子邮件系统。

  

![](../Images/60ba9a065abc26f0e3fc7c46482f55cd.png)

  

芝加哥媒体博客罗伯特·费德还伸手  向中企通信的确认或否认勒索攻击的声明。该公司的答案是他们“正在经历一些IT系统的中断，包括电子邮件。”

  

勒索软件可能有问题

然而，Radio Ink  获得了看起来像上周末分发的Entercom内部备忘录，它提供了足以指向勒索软件事件的线索。

  

它通知已连接到各种服务器（网络共享，打印，活动目录）的系统受到影响，并敦促员工不要将计算机连接到公司的有线网络。

  

在备忘录的底部解释了Entercom对此网络事件的沉默。

  

![](../Images/35d4654ddf43161f45338ebfca826689.png)

  

有关勒索软件事件的进一步迹象是 Radio Insight发布的一份报告，该报告提到了袭击者所要求的50万美元赎金。

  

该出版物称恶意软件通过编程部门的计算机进入公司的共享内部系统。 

  

播出系统没有受到影响，这解释了为什么广播似乎可能在正常情况下（某些电台无法运行广告，手工完成音乐日志，重复使用过去的流量日志）。

  

尽管网络中断，但Entercom显然决定不向攻击者付费，选择自行恢复系统。

  

虽然支付赎金可能更便宜，更容易，但该公司决定未决，因为它可以利用这笔钱来提高其网络的安全性并防止未来的网络攻击。
