# 微软补丁再次拙劣，KB4515384出现更多严重症状

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484883&idx=5&sn=440e9dd2d08bb08b64fc42b56f011b82&chksm=cef36860f984e17644cf11db48a108092c85761194793815732acbad6d2d061d85a1d6cb9a9f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484883&idx=5&sn=440e9dd2d08bb08b64fc42b56f011b82&chksm=cef36860f984e17644cf11db48a108092c85761194793815732acbad6d2d061d85a1d6cb9a9f&scene=27#wechat_redirect)

本周二，Windows 10版本1903的最新累积更新修复了导致属于数字助理Cortana的服务的高CPU使用率的问题。

  

![](../Images/5fb4a930e06cce6fa4d018a6596d9200.png)

  

与周二补丁中发布的其他累积更新一样，KB4515384同时具有安全性和非安全性方面的改进，其中一个最显着的问题是针对称为微架构数据采样并影响32位版本Windows的推测性执行端通道漏洞的保护措施。

  

此外，此更新修复了Cortana中的高CPU使用率错误，同时还针对Edge，Internet Explorer，Microsoft Scripting Engine，Windows身份验证和其他Windows组件进行了改进。

  

![](../Images/1e0a56d7a98c183aeca28fde36c4640e.png)

  

Microsoft解释了以下官方发行说明：

  

“解决了导致少量用户使用SearchUI.exe导致CPU使用率过高的问题。此问题仅发生在已禁用使用Windows桌面搜索搜索Web的设备上。“

  

这个新的累积更新没有任何已知问题，因此用户在安装后应该基本上期望完美的性能。当然，历史表明有时候等待更好，尽管在KB4515384的情况下，值得记住的是，还包括已知漏洞的安全补丁，建议您尽快安装。

  

**没有已知问题**

微软表示，相同的累积更新还包括验证用户名和密码的改进，以及存储和管理文件的改进。

  

此累积更新中没有已知问题，考虑到许多用户在Patch Tuesday推出之后遇到的问题，这绝对算是一件好事。

  

![](../Images/f88a161a716bd041bb9623ed6edcee66.png)

  

**孤立的KB4515384问题**

1.首先，超过一小部分用户声称**KB4515384破坏了Windows搜索**。这是安装累积更新KB4512941后首次遇到的问题，但是这个新版本应该解决它。

  

2.有人说Windows 10累积更新**KB4515384无法安装**。这似乎是一个孤立的案例，但遇到这种情况的用户的错误是0xe0000100。

  

3.一位用户声称他们在Windows 10版本1903上遇到了**蓝屏死机**，但目前尚不清楚这是否是在安装累积更新KB4515384之后造成的。

  

4.其他人声称，**有些应用程序不再运行**，并且相信此累积更新应归咎于此。**在某些情况下，这些应用程序在重新启动一次或多次后会恢复正常工作状态。**

  

5.在微软的社区论坛上，有一位用户抱怨在“最新的Windows Update”之后**删除了音频驱动程序。**

  

6.几个用户**表示“开始”菜单已损坏**，尝试启动它失败，屏幕上出现空白窗口。删除更新显然会恢复“开始”菜单。

  

**第二次拙劣的累积更新**

这是导致KB45版本1903出现问题的连续第二次累积更新，因为该公司发布了KB4512941，其中包含一个错误，该错误还会破坏搜索功能并导致高CPU使用率。

  

“微软正在收到报告称，在使用Windows桌面搜索时，少数用户可能无法收到结果，并且在安装KB4512941后搜索时可能会看到SearchUI.exe的CPU使用率过高。只有在禁用从Windows桌面搜索中搜索网页的设备上才会遇到此问题，“微软表示。

  

Windows 10累积更新KB4515384，导致开始菜单问题，它应该修复此行为并恢复搜索功能的全部功能，但事实证明，这只发生在最幸运的用户身上。

  

**这个bug何时可以修复还有待观察，但目前还没有解决方法。**

  

有几个用户确认音频质量受到此累积更新安装的影响，并且删除它似乎恢复了正常。

  

“我遇到了同样的问题。在PUBG和APEX都有。播放器模型前面的声音听起来很正常，但是从侧面或从后面传来的一切，基本上所有不在你面前大约90°宽的区域的声音都是低沉而安静的。可能是正常音量的10％。到目前为止，除了卸载更新之外，我还没有找到任何解决方案，“reddit用户Reklenamuri在对该漏洞进行更详尽的描述时说。

  

**Bug尚未得到承认**

虽然许多人继续完全卸载累积更新以恢复原始音频质量，但看起来将Windows声音设置更改为16位，44100 Hz（CD质量）也可以在某些设备上发挥作用，尽管此时我可以不能肯定这对每个人都有用。

  

微软尚未承认累积更新KB4515384存在任何问题，这意味着该公司尚未就人们在此抱怨的音频错误正式回应。

  

微软何时以及是否确认故障还有待观察，但目前，如果在玩游戏时音频大幅降低或完全崩溃，你应该知道你并不孤单，**累积更新KB4515384可能是罪魁祸首**。
