# Ryuk相关恶意软件窃取机密军事，财务档案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484883&idx=7&sn=5f7b4c564c5ca93e2a81646a9ea414c6&chksm=cef36860f984e176c2e6a9e34cccb5f4d8ed6148189c3bffe6d120c432f817a65e99582c251c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484883&idx=7&sn=5f7b4c564c5ca93e2a81646a9ea414c6&chksm=cef36860f984e176c2e6a9e34cccb5f4d8ed6148189c3bffe6d120c432f817a65e99582c251c&scene=27#wechat_redirect)

安全人员已发现一种与Ryuk Ransomware有奇怪关联的新恶意软件，可以查找和窃取机密的财务，军事和执法文件。

  

![](../Images/967a9c873468df3c2e85addee283b558.png)

  

虽然Ryuk Ransomware会加密受害者的文件，然后要求勒索赎金，但实际上从受感染的计算机窃取文件并不为人所知。MalwareHunterTeam今天发现了一种新的感染，它通过搜索敏感文件并将其上传到受攻击者控制的FTP站点来完成。

  

为了使这个样本更有趣，这个泄露恶意软件的数据在代码中也包含一些对Ryuk的奇怪引用。

  

**搜索机密文件**

在与逆向工程师和安全研究员Vitali Kremez的对话中，我们了解了文件窃取程序的工作原理。执行时，窃取程序将对计算机上的所有文件执行递归扫描，并查找Word .docx和Excel .xlsx文件以进行窃取。

  

在查找文件时，如果遇到任何与某些字符串匹配的文件夹或文件，它将停止检查文件并转到下一个文件，类似于勒索软件的操作方式。 

  

本文末尾列出了列入黑名单的文件和文件夹的完整列表，包括标准文件和文件夹，如“Windows”，“Intel”，“Mozilla”，“Public”等。

  

此外，它还会跳过与Ryuk相关的任何文件，例如“RyukReadMe.txt”和带有“.RYK”扩展名的文件。

  

![](../Images/9e54a079f69ac87730678549b84991f6.png)

黑名单

如果文件通过黑名单，窃取者将检查它是否是.docx或.xlsx文件，如下所示。

  

  

![](../Images/00bbe6e1e90312e2c8ce3b9a40bed566.png)

搜索.docx和.xlsx文件  

当找到.docx或.xlsx文件时，窃取程序将使用libzip和zip\_open和zip\_trace函数来验证该文件是否是有效的Word或Excel文档。它通过检查和验证Office文档中是否存在word / document.xml（word）或xl / worksheets / sheet（excel）文件来完成此操作。

  

  

![](../Images/d5889b57f55ea7f13ab88fb380ae82d4.png)

验证Word文档  

如果它是有效文件，则会将文件名称与77个字符串列表进行比较。所有字符串都列在文档末尾，包括“marketwired”，“10-Q”，“欺诈”，“黑客”，“坦克”，“防御”，“军事”，“检查”等条目， “分类”，“秘密”，“秘密”，“卧底”，“联邦”等。

  

  

![](../Images/d38663ea8b78c75f28be4b575c826c89.png)

感兴趣的词  

正如您所见，演员正在寻找机密的军事机密，银行信息，欺诈，刑事调查文件和其他敏感信息。

  

奇怪的是，它还寻找包含名字“Emma”，“Liam”，“Olivia”，“Noah”，“William”，“Isabella”，“James”，“Sophia”和“Logan”的文件。据怀疑，这些名称来源于2018年顶部的宝宝名字由美国社会保障部门上市。

  

然后，通过FTP将任何匹配字符串的文件上载到66.42.76.46/files\_server/a8-5  服务器，如下面的代码所示。

  

  

![](../Images/9bdbe230fafda212e81b8af0b45c155f.png)

通过上传到FTP服务器来窃取文件  

扫描本地计算机后，恶意软件将从计算机的ARP表中获取IP地址列表。然后它继续搜索任何可用共享上的文件。

  

  

![](../Images/9087705d88f1af4b5c9b28dd331e3f2c.png)

获取ARP表  

目前尚不清楚这个恶意软件是如何安装的，但BleepingComputer，Kremez和MalwareHunterTeam认为，这种感染可以在感染机器之前运行，以便在加密之前收集有趣的文件。

  

**与Ryuk Ransomware有着奇怪的联系**

正如我们已经讨论过的，这个窃取者故意跳过与Ryuk Ransomware相关的文件，例如RyukReadMe.txt，UNIQUE\_ID\_DO\_NOT\_REMOVE以及任何具有.RYK扩展名的文件。  

  

此外，窃贼和Ryuk Ransomware有一些共同的代码相似之处。例如，窃取程序包含一个创建新文件的函数，并附加.RYK扩展名，就好像它正在加密文件一样。窃取者不使用此功能。

  

  

![](../Images/3d017891ec584359b6e791c93df7e273.png)

Stealer包含Ryuk的创建文件方法  

窃取者还检查是否存在名为Ahnlab的文件，如下所示。

  

  

![](../Images/e8dbd544c248efccc4a671393de4a20f.png)

窃贼搜索Ahnlab  

Kremez告诉BleepingComputer，Ryuk Ransomware还会检查是否存在此文件，如下所示。 

![](../Images/a0c1e576bf55ca04526d45ecc6001dbc.png)

Ryuk Ransomware搜索Ahnlab  

虽然这个窃取者与Ryuk之间存在明确的联系，但不知道实际来自同一组或某人是否获得了对代码的访问并在自己的程序中使用它。

  

“它可能表明某人有源访问Ryuk勒索软件只需复制/粘贴和修改代码，使其成为一个偷窃者或看起来像它，”Kremez告诉BleepingComputer一个关于这个恶意软件的对话。

  

此外，在过去使用BleepingComputer进行测试时，Ryuk运行时没有任何依赖关系，而这个窃取程序似乎是一个MingW可执行文件，需要存在大量的DLL才能正确执行。

  

这可能表示窃取器正在手动安装或作为包装与所有必要组件一起丢弃。

  

随着更多样品的推出，我们希望将来能够看到它的安装过程。
