# Microsoft发布了针对Office的2019年9月安全更新

微软发布了2019年9月的Microsoft Office安全更新，在七种不同的产品中捆绑了总共19个安全更新和五个累积更新，其中五个修补了远程代码执行缺陷。

  

![](../Images/18651bbb31e99faaf107b4d01c76e8cf.png)

鉴于今天发布的某些Microsoft Office安全更新还可以解决各种严重漏洞，强烈建议用户尽快安装它们。

  

**微软官方补丁下载：**https://support.microsoft.com/zh-cn/help/4517986/september-2019-updates-for-microsoft-office

  

**修补了Microsoft Office漏洞**

在Microsoft今天发布的19个Office安全更新中，有五个修补了远程代码执行漏洞（CVE-2019-1246，  CVE-2019-1257，  CVE-2019-1295，CVE-2019-1296和  CVE-2019- 1297）在Office 2016，Office 2013，Office 2010，Excel 2016，SharePoint Server 2019，SharePoint Enterprise Server 2016，SharePoint Foundation 2013和SharePoint Foundation 2010中。

  

所有修补的远程代码执行安全漏洞被Microsoft评为严重或重要，因为它们可以允许潜在的攻击者在成功利用易受攻击的Windows设备后执行任意代码和/或命令。

  

今天微软发布的其他安全补丁还修复了信息泄露，安全功能绕过，特权提升以及欺骗影响其他几个Microsoft Office产品的漏洞。
