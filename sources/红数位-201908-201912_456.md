# 华为指责美国政府的黑客攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484673&idx=4&sn=ba8fb75ed62434a6e6c61aa1d11edb04&chksm=cef368b2f984e1a45800912d73b8ac9e4f28e362d98837a318e85922687b7255477597e11091&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484673&idx=4&sn=ba8fb75ed62434a6e6c61aa1d11edb04&chksm=cef368b2f984e1a45800912d73b8ac9e4f28e362d98837a318e85922687b7255477597e11091&scene=27#wechat_redirect)

华为技术与白宫之间的争夺战继续加剧。

  

这家中国制造业巨头周二指责美国“利用其掌握的所有工具”来破坏其业务，包括网络攻击和员工恐吓，以及针对华为已经解决的民事案件的联邦调查。

  

“在过去的几个月里，美国政府一直利用其政治和外交影响力游说其他政府禁止华为设备，”华为在周二发布的一份媒体声明中表示。

  

一年多以来，华为和美国政府陷入了激烈的争执，华盛顿游说盟友避免使用中国制造商的电信设备进行敏感操作，包括国家5G网络部署。在没有发布任何证据的情况下，白宫指责华为太容易受到中国政府的干扰，因为它的设备值得信赖，从而构成安全风险。

  

![](../Images/09992eb4e0da3a88dab73e056ae033e2.png)

华为是全球最大的电信设备制造商和第二大智能手机制造商。

  

它与白宫的分歧正在正在进行的美中贸易战中发挥作用，各国对彼此的商品征收数十亿美元的关税。美国总统唐纳德特朗普长期以来一直指责中国支持大规模的知识产权盗窃活动，不公平的交易行为和货币操纵。

  

**华为回击**

由于制造商对特朗普政府提出了新的指责，本周华为与美国政府之间的战斗进一步加剧。它指责白宫“利用其掌握的所有工具 - 包括司法和行政权力，以及其他一些不道德的手段 - 来破坏华为及其合作伙伴的正常业务运营。”

  

在没有引用任何证据的情况下，华为指责美国政府“发起网络攻击渗透华为的内部网和内部信息系统”，并利用联邦调查局特工向华为员工施压，要求他们分享有关该公司的信息并“反对公司和工作对他们来说。“

  

这家技术巨头表示，此外，员工的签证被拒绝，员工被拘留，遭受非法搜查以及通过政府授权的诱捕计划进行攻击。它还声称，美国政府一直在“与华为合作或与华为发生业务冲突的公司动员和密谋，对该公司提出无根据的指控。”

  

“作为一般事项，我们不确认或承认存在调查，”司法部发言人告诉信息安全媒体集团。“在所有事项上，我们的调查技术都符合法律规定，所有调查对象都享有与我们的宪法所提供的正当程序相同的权利，并受到独立司法机构的保护。”

  

一位知情人士告诉华尔街日报，今年至少有三名在华为美国办事处工作的员工已被美国执法机构联系。它还报告说，来自纽约东区的联邦调查局和联邦检察官一直在调查华为在美国的商业行为。

  

**白宫游说继续**

白宫继续敦促盟友不要将华为设备用于任何敏感应用。在本周访问爱尔兰期间，美国副总统迈克·彭斯出现在爱尔兰总理利奥·维拉卡尔身边，发表了新的抨击。

  

“众所周知，中国法律要求中国电信公司向北京的大型安全机构提供访问任何触及其网络的数据，”彭斯周二在联合记者招待会上说。“在我们安全的5G供应链中，任何地方都不存在不受信任的供应商。我们正在与世界各地的电信公司合作，为华为开发5G替代品。”

  

华为继续否认它向中国情报机构提供协助。

![](../Images/ca0825ea6d0237bf51b959ef80c17045.png)

华为也是两项联邦起诉书的焦点。今年1月，美国司法部在联邦法院起诉了华为，首席财务官孟万洲以及华为业务子公司华为设备美国公司和天通科技有限公司的13项起诉书。这些指控包括银行和电汇欺诈并违反对伊朗的国际制裁。

  

同月，西雅图的联邦检察官启动了针对华为和华为美国的10项指控起诉，指控他们从位于华盛顿州贝尔维尤的T-Mobile美国窃取了商业机密。作为调查的一部分，FBI收到的电子邮件显示，2013年7月，华为根据他们从全球其他公司窃取的信息价值向员工发放奖金，并通过加密电子邮件地址提供给华为，司法部表示。

  

华为否认这些指控，将T-Mobile的指控称为“出于政治动机”。

  

司法部表示，80％的经济间谍案追溯到中国政府，商业秘密盗窃案件中有60％以上的中国关系，并根据指称受害者的要求展开调查（见联邦调查局对中国反间谍能力的争论。

  

**新技术盗窃问题**

周二，华为还批评华尔街日报周五发布的一份报道称，司法部正在调查新的技术盗窃指控，以及从竞争对手那里招募员工的可疑问题。

  

华尔街日报首次报道，技术盗窃探测器的问题是美国发布给葡萄牙多媒体制作人Rui Oliveira的智能手机摄像头技术专利。在奥利维拉于2014年试图将其正在申请专利的设计出售给华为后，他指责该公司窃取了这些设计并将其用于EnVizion360相机。

  

今年3月，华为起诉奥利维拉在德克萨斯州联邦法院，要求宣布它没有侵犯他的专利权。

  

该公司在周二的一份声明中表示，“华为断然拒绝奥利维拉先生的专利侵权诉讼，并提供了支持其立场的详细文件，”包括两种设备的视觉比较。它还指责奥利维拉“利用当前的地缘政治局势”试图“利用争端”，并表示应该在美国民事法庭处理。

  

该公司还指出其在研发方面的30年投资以及180,000名员工。“这是我们公司成功的源泉，”它说。“没有公司通过盗窃成为他们领域的全球领导者。”
