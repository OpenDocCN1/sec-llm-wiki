# 新式机器人船将穿越大西洋并改变世界

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484645&idx=3&sn=94a57aa2649133cd6f64ee5a9273567a&chksm=cef36956f984e040971472073e9c1ce88b41dfd0279ba65092e8ac96048164bd0bd6a0235cf5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484645&idx=3&sn=94a57aa2649133cd6f64ee5a9273567a&chksm=cef36956f984e040971472073e9c1ce88b41dfd0279ba65092e8ac96048164bd0bd6a0235cf5&scene=27#wechat_redirect)

这条36英尺长的黄色和白色条纹船只在英国海岸边漂浮，确实看起来并不多。但Maxlimer可能是目前世界上最重要的船只。

  

![](../Images/d91ecdebfc4772026289987190ac7bbb.png)

  

Maxlimer完全是机器人。它有望成为第一艘穿越大西洋的无人水面舰艇（USV）。这个旅程可以证明一系列新的远洋无人机：无船员的货船; 无人驾驶油轮; 机器人工作船。

  

但是不要太激动，广泛采用可能需要数年甚至数十年。

  

Maxlimer是SEA-KIT的产品，SEA-KIT是一家位于英格兰东南部的海事科技公司。关注支持海上石油和天然气钻探的潜在利润丰厚的合同，SEA-KIT旨在生产一种比有人驾驶船舶更便宜，更安全的灵活船舶。

  

由于无需支持人员，机器人支援舰可以为设备投入更多空间，包括可以发射和回收的小型无人机船和潜艇的船队。因为它不会感到饥饿，疲倦或生病，所以它可以悠闲地以每小时8英里的速度航行，直到它耗尽燃料，可以连续行进9个月。

  

Maxlimer “几乎就像海上的公用事业皮卡车”，SEA-KIT总经理Ben Simpson 说。“它坚固，适应性强，范围广。”它可以携带21/22吨的货物。

  

它很便宜。SEA-KIT的首席运营官Neil Tinmouth告诉The Daily Beast说：“SEA-KIT船只使用不到5％的燃料来运行标准的远洋船只。” “在涉及这些业务的碳足迹和环境影响方面，这是一个改变游戏规则的方法。”

  

从2016年开始，SEA-KIT 与一家英国造船厂合作生产Maxlimer的铝制船体。一家挪威国防公司为远程控制提供电子设备。在港口拥挤的水域中，人类操作员通过无线电远程操纵Maxlimer。在开阔的海洋上，它自动跟随GPS信号。

  

Maxlimer于2017年推出，并在测试中花了几年时间。结果令人鼓舞。五月2019 Maxlimer球队陷入僵局壳牌发现海洋X大奖，一个$ 700万大奖最佳海洋测绘技术。 

  

同月，Maxlimer在英国和比利时之间快速运输货物，运送牡蛎和啤酒。今年秋天，机器人船驶向挪威，因为Tinmouth称之为“首次使用机载传感器和小型无人机潜艇进行完全无人驾驶的海上商业管道检查”。

  

Tinmouth告诉The Daily Beast说：“无数任务使得我们的岸上机组人员能够在各种情况下和海上状态下对海上船舶进行操作和测试。”

  

接下来：大肆吹嘘的大西洋过境点。Tinmouth表示，为期一个月的旅程将在2020年上半年按计划进行。假设Maxlimer成功完成了这次旅行，SEA-KIT希望开始扩展这项技术。“我们已经设计并正在寻求开发具有更多功能的更大的USV。”
