# 没有Windows XP，世界会更美好

Windows XP于2014年4月正式退役，但这并不意味着每个人都放弃了它。

![](../Images/69e4349424e04ad53eacf471cfd557f8.png)

无论我们是指硬件无法运行Windows 10的旧计算机，还是因兼容性原因需要坚持使用Windows XP的企业，2001年的操作系统仍然会逐步发布每月发布的市场份额数据。

  

但好消息是Windows XP缓慢但肯定会彻底变暗。这绝对是一件好事。

  

首先，让我们看一些数字。

  

**Windows XP目前的市场份额为1.57％，这使其成为全球第六大使用率最高的桌面操作系统。**

  

虽然它仍然拥有比Linux更大的份额，但Windows XP每个月都在不断下降，并且在大约一年内，它应该接近0％的市场份额。

  

此时，Windows XP主要运行在由政府机构，公共服务或需要古老系统的组织运营的计算机上，这仅仅是出于旧硬件或兼容性原因。为Windows XP开发的应用程序和服务可能无法在较新的Windows上按预期运行，并且升级到受支持的操作系统版本通常需要新硬件。

  

反过来，新硬件需要投资，鉴于其机队中的设备数量，政府和企业无法承受如此大规模的投资。

  

但是这种下降的份额显示Windows XP已经接近灭绝，因此Windows 7迟早会成为微软的头疼（Windows 7也将在2020年1月失去支持，并且鉴于它仍然超过30％的设备运行在那里，微软将有一个艰难的任务，即说服客户升级到支持的Windows）。

  

至于为什么在没有Windows XP的情况下世界变得更好，这一切都是因为它已成为一种古老的操作系统，当安装在现代设备上时它没有任何好处。从安全角度来看，在连接到更大网络或访问Internet的计算机上运行Windows XP会带来巨大风险，因为在一个Windows版本中发现的大量漏洞也会影响其他版本。

  

然而，不同的是，虽然有些人获得了补丁，比如Windows 7和Windows 10，但其他人却没有，而Windows XP也是如此。如果在所有Windows版本中发现漏洞，则Windows XP是无法获得修复的漏洞之一，因为它已经不受支持。

  

全世界的用户都喜欢Windows XP，这主要是因为它是微软开发的现代Windows体验的基础。Windows 7是锦上添花，这就是为什么我希望Windows版本的转换至少与Windows XP一样困难。

  

**事实上，杀掉Windows 7可能会打击另一个障碍。**

  

Windows 7是最后一个“传统”Windows，因为它的后续产品Windows 8是第一个引入Metro应用程序和触摸支持的现代体验的版本。Windows 7的存在主要是因为用户只想坚持使用Windows XP引入的熟悉的桌面，它的退役基本上标志着整个世界的终结。

  

但最终，安全风险仍然存在。运行18年前推出的操作系统绝不是任何人应该做的事情，特别是考虑到经常发现新的漏洞。

  

Windows XP的时代早已过去，经过5年的奋斗，看起来世界已经准备好让这个OS版本死掉。有关它有多快达到0％份额的赌注？
