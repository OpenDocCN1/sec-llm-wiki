# Reddit因亚马逊AWS问题而遭遇停摆

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484622&idx=1&sn=d111feb2ec8e4954e0c7893a342b3340&chksm=cef3697df984e06bbeb96dda81d190e1a0dc38edc5e3136eb9494b4106667d2d3b20d1885d45&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484622&idx=1&sn=d111feb2ec8e4954e0c7893a342b3340&chksm=cef3697df984e06bbeb96dda81d190e1a0dc38edc5e3136eb9494b4106667d2d3b20d1885d45&scene=27#wechat_redirect)

  

昨日，世界上某些地区的Reddit用户在访问该网站时遇到了问题。连接问题的原因是Amazon Web Services（AWS）上发生的事件，该事件是Reddit的托管服务提供商亚马逊问题。

  

![](../Images/08dfdfc5aa028370411756c644c2c594.png)

  

看看评论此问题的用户，似乎在欧洲一些国家（芬兰，西班牙，意大利，葡萄牙）以及加拿大，菲律宾和澳大利亚加载网站时遇到问题。英国的一些用户报告网站加载速度非常慢或根本没有加载。

  

据DownDetector称，用户报告Reddit连接问题的地区是美国东海岸，其次是北欧。

![](../Images/d16566aba85f80d588af6e53b44714a2.png)

有些用户说他们看到了503错误，这是一个HTTP状态代码，当网站的服务器由于各种原因（过载，维护）而无法用于该连接时会显示该状态代码，这种情况就是这种情况。

  

Reddit在太平洋夏令时间06:09发现了这个问题。大约两个小时，平台的状态页面显示没有停机时间。关于这些问题的说明是，Reddit正在处理正在调查的“高级错误”。

  

调整在太平洋时间07:53改变，当Reddit宣布他们受到他们的托管服务提供商AWS的事件的影响。

  

“我们正在努力缓解这个问题，”Reddit告诉我们。

  

![](../Images/77e5bc2917132c872f2a8785d9c80d1b.png)
