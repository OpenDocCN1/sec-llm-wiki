**Apple苹果的安全漏洞今天将再次成为头条新闻。**

  

![](../Images/0572e9f3a4485a4a9d89229b182ae1f1.png)

  

在其高度宣传紧急iPhone补丁发布几天后，**谷歌的安全研究人员发布了一个新的“网站黑客”警告。**

  

**这是对库比蒂诺科技巨头安全声誉的巨大打击。**

**更糟糕的是，****警告是在iPhone 11发布确认发布日当天发出的。**

![](../Images/bee90d41649ac8bd5e6b5da088106164.png)

苹果公司终于确认其下一代iPhone三重奏组将在9月10日举行  

**随着安全警告的发生，这个问题很严重。**  

  

谷歌的Project Zero团队已经披露，一些“黑客入侵的网站”已被用于攻击iPhone两年：至少从2016年开始。而且每一款最新的iPhone都容易受到攻击。“没有目标歧视，”研究人员报告说，“只要访问被黑网站就足以让攻击服务器攻击你的设备，如果成功，就安装一个监控植入物。”

  

![](../Images/1395a5083710dcc895bf22188cd7dcc2.png)

直到iOS更新12.1.4才解决这些问题。

  

**谷歌的研究团队“能够收集五个独立，完整和独特的iPhone开发链，****几乎涵盖从iOS 10到iOS 12的最新版本的所有版本。****这表明一个团队持续不断地努力攻击iPhone的用户，至少两年。****“**

  

谷歌的Project Zero团队已经发现攻击行动，该团队搜索零日漏洞。它说攻击活动被用来感染iOS设备的植入物 - 也就是恶意软件 - 可以窃取私人数据，包括Telegram，iMessages和Gmail中的照片和消息，以及将GPS数据发送到命令和控制服务器只要他们在线，就可以实时跟踪用户。

  

**“没有目标歧视; 只需访问被黑网站即可让攻击服务器攻击您的设备，如果成功，则安装监控植入程序。****监控植入程序**监控一些更受欢迎的资源和应用程序，包括雅虎邮件应用程序，Microsoft Outlook，Viber，Gmail，WhatsApp，Facebook，Skype和其他一些。攻击者还可以从使用端到端加密的聊天应用程序，照片，联系人，实时位置，电子邮件以及其他所有内容中完全访问聊天数据库。

  

**攻击者的植入物可以每60秒上传一次内容。****更令人感兴趣的是，这种攻击采用了二进制形式，在重新预订后不会在设备上持续存在。****但是当用户访问特定网站时，植入的监控程序将会回来。**

  

即使用户重新启动，攻击者也已拥有包括各种服务的用户名和密码在内的信息，即使他们不再拥有控制权。更糟糕的是，**监控植入程序**是在野外发现的，这意味着它正在被使用，而且它不仅仅是一种理论练习。

  

“今年早些时候谷歌的威胁分析小组发现了一小部分被黑网站。黑客网站被用于对游客进行不分青红皂白的攻击，使用iPhone 0天，” Project Zero团队的Ian Beer在一篇博客文章中说道。周四发表。  

  

“没有目标歧视;只是访问被黑网站就足以让攻击服务器攻击您的设备，如果成功，则安装监控植入物，”他说。“我们估计这些网站每周会接待数千名访客。”

  

![](../Images/af94e09f7f7e15c9ec7909177b85863f.png)

谷歌对植入物的测试 - 恶意软件 - 由网站安装，发现它可以泄露多种类型的个人数据，包括iMessages（来源：Google Project Zero）

  

**Apple没有立即回复评论请求。**

  

谷歌在2月1日向苹果报告了两个严重的缺陷--CVE-2019-7287和CVE-2019-7286，在公开发布之前设定了7天的截止日期，因为它们显然仍然是零日漏洞以及被使用在积极的，在野外的攻击。

  

Apple通过2月7日发布的iOS 12.1.4以及安全警报修补了这些漏洞。

  

  

**五个漏洞链**

黑客攻击现代操作系统 - 包括iOS--通常需要将漏洞链接在一起以解决多个漏洞。例如，在移动操作系统的情况下，攻击者可能需要工作漏洞，允许他们最初访问设备 - 通常是通过基于WebKit的浏览器 - 然后逃离沙箱并越狱设备以安装恶意代码。

  

总而言之，谷歌表示它计算了五个使用14个漏洞的漏洞利用链：“7个用于iPhone的网络浏览器，5个用于内核，两个单独的沙箱逃脱。”

  

已识别的漏洞本可用于破解运行iOS 10的设备，该设备已于2016年9月13日发布，几乎每个新版本的iOS都会发布到最新版本的iOS 12。

![](../Images/507dbd01d7bc5b82e7c2ee47228f12cd.png)

利用链时间轴（来源：Google Project Zero）

  

“这表明一个团体在至少两年的时间内持续努力在某些社区攻击iPhone用户，”Beer说。

  

攻击者能够使用恶意软件感染iOS设备，而无需通过绕过强制代码签名来越狱设备，这限制了设备可以运行的应用程序。相反，根据Beer编写的漏洞攻击，攻击者能够将他们的代码的哈希值隐藏到iOS“信任根”，然后允许他们的代码运行。

  

“由于攻击者只希望执行他们的植入二进制文件而不是禁用系统范围内的代码签名，因此只需将他们的植入代码签名blob的哈希值添加到内核动态信任缓存中就足够了，他们使用内核任务端口执行此操作。“Beer说。

  

**植入物可以攻击的iOS秘钥**

谷歌Project Zero对植入物的分析发现，恶意软件可能会泄露来自受感染设备的数据，包括来自Telegram，WhatsApp，Gmail，iMessage等应用程序的数据。每分钟最多一次，命令和控制服务器还可以接收在线的任何受感染用户的GPS坐标。

  

![](../Images/734eb52ebcf3c4bba31f7d38321f6846.png)

  

这张图片显示了“当我带着植入物在我口袋里的手机上运行时植入物收集的实时位置数据的真实样本，”Google的啤酒说。

植入物还可以窃取存储在iOS内置密码管理器中的密码，称为密钥链。但它不仅包括应用程序，网站和服务的密码。

  

![](../Images/14cd8416733df7f01860c8755743fdba.png)

  

攻击者也可以窃取访问令牌，例如，Gmail（来源：Google Project Zero）

“钥匙链还包含服务使用的长期令牌，例如谷歌的iOS单点登录，以使谷歌应用程序能够访问用户的帐户，”比尔说。“这些内容将上传给攻击者，然后可用于维护对用户Google帐户的访问权限，即使植入物不再运行也是如此。”

  

**已识别的缺陷已修复**

到2月份，网站使用的所有漏洞链都被发现并报告给了Apple。其中包括360 Security的@ S0rryMybad在2018年11月17日的天府杯PWN比赛中赢得20万美元的漏洞。

  

另外，**Google Project Zero的Brandon Azad发现了这个漏洞并于2018年12月6日向Apple报告，导致Apple 于1月22日发布其iOS 12.1.4更新，并认为@ S0rryMyBad和Azad已经发现并报告该漏洞，指定为CVE-2019-6225。**

  

**随后，该漏洞在Black Hat 2019获得了Pwnie奖，因为它是最佳的特权升级缺陷。**

  

  

**专家劳德研究员**

鉴于此次活动可能造成的损害，安全专家称赞谷歌的工作。

  

“谷歌沙盒攻击iPhone水坑攻击 - 拆除和植入，这是开发和执行攻击的重要时间 - 坚实的研究，\[Google Project Zero\]，” 安全公司联合创始人Matthew Hickey（@hackerfantastic）说。黑客之家。

  

约翰斯·霍普金斯大学（Johns Hopkins University）密码学教授马修·格林（Matthew Green）等专家表示，他们希望看到更多细节，包括究竟是哪些网站正在进行这些攻击，以帮助个人了解他们是否可能成为受害者。

  

“零点项目赢得了这篇文章所获得的每一滴赞誉，” 格林通过推特说道。“但P0帖子没有说明服务这些漏洞的网站是什么，以及他们瞄准的人群。有人知道吗？”

  

**围墙花园和单一文化风险**

**此次攻击活动还突出了苹果公司安全方法的一些优势和劣势。**Apple严格控制iOS开发以及Apple Store，并限制设备只允许他们在允许它们进入App Store之前安装它首先经过审查的应用程序，除了一些企业例外。

  

例如，Android操作系统是一个开源项目，许多设备制造商继续定制。虽然谷歌在其Pixel设备上使用了“vanilla”版本的Android，但几乎所有使用Android的OEM都会首先对其进行定制，以及用户开发自己的硬件。在电信公司将智能手机出售或出租给其客户之前，操作系统还可以由电信公司进一步定制。

  

因此，虽然在Android设备中发现的一些缺陷可能会影响整个生态系统，但许多缺陷仅针对部署在特定电信公司提供的某些设备上的某些Android版本。然后推出自己也开发的硬件。

  

这与Apple设备形成鲜明对比，Apple设备的成功利用链可能会对所有当前和最新的iOS设备起作用。

  

![](../Images/0b5b66edaa06292cd3503b998bd554ed.png)

  

“iPhone是一种单一文化，一旦你选择它，你就会把它们全部展现出来，” 在推特上称为Grugq的运营安全专家说道。**中国话叫：****一荣俱荣，一损俱损。**

  

应用安全研究公司Thinkst的创始人南非信息安全专家Haroon Meer表示，iOS水坑攻击表明苹果移动操作系统的代码应该受到更严格的审查。

  

“大量拥有的iOS设备（虽然未被发现）清楚地表明可检查性是安全性的重要组成部分，” Meer推文。

![](../Images/0af01c3af46d56d9a57dc940b5b52f87.png)

  

  

**发展问题**

与此同时，谷歌的啤酒表示，这些缺陷揭示了苹果公司的开发和质量保证实践中存在的明显问题，这些问题反映了整个行业普遍存在的“被忽视”的问题，包括“似乎从未发生过代码的代码案例，代码可能会跳过QA或者在发送给用户之前很少进行测试或审查。“ 随着时间的推移，糟糕的代码可以安装，为攻击者提供更多可能的方法来攻击操作系统。

  

![](../Images/ef927eb857abe4ca8d43d045892b178f.png)

  

就Apple而言，比尔表示谷歌发现使用这五个独立漏洞利用链的网站表明，可能仍有其他网站 - 和攻击者 - 在工作，在iOS上遇到漏洞，目前只有攻击者知道这些漏洞。

  

“对于我们所见过的这场竞选活动，几乎可以肯定其他活动还有待观察，”他说。

  

  

**手机是我们的数字王国的关键**  

谷歌披露警告称，“真实用户”根据公众对这些设备安全性的看法做出风险决策。现实仍然是，如果你成为目标，安全保护永远不会消除攻击风险。“

  

Apple的问题在于，这将破坏对品牌安全性的信心。这种披露如此严重，对漏洞的性质具有破坏性和侵扰性，它会让用户提出有关如何将这种严重漏洞留下来的问题。

  

![](../Images/9ddfda3809d5a104f99e3306769b928d.png)

  

在我们看来，公司对越狱问题的反应速度（以及Zoom问题，甚至是最近的Siri问题）都是保持对品牌信心的一个原因。这种披露很可能会破坏这一点 - 不是因为响应，而是因为漏洞的严重性。

  

当然，这提出的另一个问题是，如果这些漏洞利用在被发现之前已经存在了两年，那么还有什么我们还不知道的。 

  

“所有用户都可以做到的是意识到大规模开发仍然存在并且相应地表现出来，”Google在其披露中表示，“将他们的移动设备视为现代生活中不可或缺的一部分，同时也将其作为受到损害的设备，将他们的每个动作上传到数据库中，以便对他们使用。“
