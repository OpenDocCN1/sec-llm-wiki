# 微软已在使用赛门铁克和诺顿防病毒软件的设备上删除了SHA-2升级块

**微软最近证实，它已在使用赛门铁克和诺顿防病毒软件的设备上删除了升级块。**

  

[赛门铁克和诺顿用户慎更新Win7,2008R2补丁，会致机器无法启动](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484342&idx=2&sn=b8584091b5cf9ff16d9e2a743b06e25b&chksm=cef36e05f984e7137b23736c51bebcea145551caa1b72104bc037248fc8c51f9ef7e4361126f&scene=21#wechat_redirect)  

本月早些时候，该公司表示赛门铁克发现了SHA-2 Windows更新的潜在问题，可能无法提供给安装了Symantec或Norton防病毒程序的设备。

  

为防止出现任何潜在问题，微软决定停止向检测到该软件的Windows 7设备提供Windows更新。

  

![](../Images/5ebb20e0800fa3640742c02e1f92e212.png)

  

“赛门铁克发现，在安装了Symantec或Norton防病毒程序的设备上安装了仅使用SHA-2签名的Windows更新代码后，可能会发生负面互动。微软表示，该软件可能无法正确识别更新中包含的文件，因为微软会签署代码，导致设备面临延迟或不完整更新的风险。

  

所有Symantec Endpoint Protection版本都被认为会受到影响

在今天的更新中，微软解释说赛门铁克完成了调查，并发现SHA-2签名更新没有任何风险。

  

“保护措施已被删除。赛门铁克已完成对此更新的影响以及对Windows 7 / Windows 2008 R2的未来更新的评估，并已确定所有现场版本的Symantec Endpoint Protection和Norton防病毒程序均不会增加误报检测的风险， “ 它说。

  

赛门铁克还介绍了在咨询用户可以继续安装上运行的Symantec Endpoint Protection他们的设备更新的Windows和KB4512506 KB4512486。

  

该块仅针对运行Windows 7 Service Pack 1和Windows Server 2009 R2 SP1的设备，最初据称所有版本的Symantec Endpoint Protection都会受到影响。运行任何其他Windows版本（包括Windows 10）的设备可以从Windows Update更新。
