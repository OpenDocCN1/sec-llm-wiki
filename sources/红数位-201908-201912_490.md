# GitHub昨日经历了全球性服务中断

GitHub Git存储库托管平台昨日经历了广泛而重大的全球性服务中断，影响了问题，PR，仪表板，项目和通知功能。

  

![](../Images/42e11372269a4a9f9800cc4c5c382b75.png)

  

GitHub为其用户提供Git的源代码管理（SCM）和分布式版本控制功能，无需在本地配置自己的服务器来承载Git安装。

  

除了默认的Git功能之外，GitHub还提供团队协作和访问控制功能，如任务管理和错误跟踪。

  

但是，鉴于它是一个云解决方案，GitHub平台偶尔会受到影响其部分或全部功能的各种问题的影响，直接影响其用户管理平台上托管的Git存储库的能力。

![](../Images/3d8b482d1bfee43584275e9f6284ffc4.png)

GitHub中断地图

  

全球GitHub服务中断  

在美国时间10:59，GitHub工程团队在该平台的状态页面上发布了一份事故报告，称他们“正在调查影响许多服务的问题的报告”。

  

一小时后，在美国时间12:05，发布了一个更新，声明“工作继续进行早先发现的错误”。

  

又过了20分钟，GitHub的工程团队解决了这个问题，然而，他们没有在事故报告中提到这次广泛停电的原因。

  

![](../Images/5b557a2b498d08341eb6cc9ad16933aa.png)

事件报告

  

根据状态站点，GitHub服务中断阻止用户创建新问题和拉取请求，接收通知以及访问仪表板和项目。

  

GitHub用户在过去一小时内也在Twitter上报告他们遇到各种类型的问题，从整个站点到500个内部服务器错误状态代码和拉取请求不起作用。
