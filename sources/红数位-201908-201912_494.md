# 互联网暴露的Sphinx服务器面临攻击风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247484447&idx=2&sn=37ac7e4d7d7d17fc721eb41f3e3ce7d7&chksm=cef369acf984e0baea7664da27cf9d9a05c65f86ea2ea2c219f5649b6a12f681e7dcb8d198e8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247484447&idx=2&sn=37ac7e4d7d7d17fc721eb41f3e3ce7d7&chksm=cef369acf984e0baea7664da27cf9d9a05c65f86ea2ea2c219f5649b6a12f681e7dcb8d198e8&scene=27#wechat_redirect)

德国CERT-Bund计算机应急响应小组警告称，攻击者可以利用互联网上公开的Sphinx Web服务器访问，更改或删除数据库中的数据。

  

![](../Images/8ba6921c12cbb360654983f86eaeba2a.png)

  

作为一种流行的开源文本搜索服务器，Sphinx为数据库或文件中的数据索引和搜索提供了出色的性能。它是跨平台的，适用于Linux，Windows，macOS，Solaris，FreeBSD和其他一些操作系统。

  

**仅限本地访问**

CERT-Bund今天在Twitter上发布了警告，警告网络运营商和提供商使用网络上打开的默认配置运行Sphinx服务器的风险。

  

该组织强调，Sphinx缺乏任何认证机制。将其暴露在网络上可以让攻击者“阅读，修改或删除存储在Sphinx数据库中的任何数据”。

  

![](../Images/c013ee737aaacc39c01f40147274b3bb.png)

  

默认情况下，服务器侦听所有网络接口上的端口9306 / TCP和9312 / TCP.Shodan在搜索其中一个端口时返回了几千个结果，其中大部分都用于Sphinx服务器。

  

管理员可以使用Linux / Unix系统中提供的标准工具，通过简单的方法检查是否可以从Internet访问他们的服务器。

  

通过从本地网络外部的计算机运行“netcat”，管理员可以检查是否可以建立连接。如果是这种情况，他们将看到服务器的版本信息。

  

![](../Images/ecd9513e8d9f8f0ced7b946a76b89747.png)

  

CERT-Bund建议不要在线公开Sphinx服务器并阻止从互联网到其通信端口的任何传入连接。

  

对于Sphinx和Web服务器共享同一台计算机的设置，管理员可以将Sphinx配置为侦听本地接口。

  

该通报还附带了运行最新版Sphinx的标准建议。我们在Shodan注意到的许多版本已经过时了。

  

![](../Images/8b72b6a927bc002495e7f6d64ee48eff.png)

  

转发是对我们最大的鼓励
