# Gmail刚经历宕机，全球停运，显示“出错”错误

****![](../Images/f5f9be74f8cf55b770c0a86b83131d84.png)****

  

谷歌的免费Gmail电子邮件服务中国时间昨天夜里经历了全球范围内停运，它阻止用户登录，在他们尝试登录自己的帐户时显示“出错”错误。

  

![](../Images/f3e1d0e7f5e7eaba8ddea51fc5f12b65.png)

  

在太平洋时间11:30（中国晚上23：30）开始的身份验证问题影响了Google云端控制台事件＃19008中详述的Google App Engine，Google云端控制台，身份识别代理和Google OAuth 2.0端点。

  

根据用户报告以及能够观察到的内容，即使清除cookie或切换帐户和计算机，登录尝试也无法正常工作。

  

谷歌还在G Suite Status Dashboard上发布了一个新问题，称 “我们正在调查有关Gmail问题的报告。我们会在短期内提供更多信息。受影响的用户无法访问Gmail。用户可能会遇到登录所有问题的问题谷歌服务。“

  

![](../Images/2f05f6fdb86ae47905a9b384cd1bcb55.png)

Gmail身份验证错误  

该公司还在美国东部时间晚上11:53更新了其Google Cloud Status Dashboard的新问题，称“我们正在调查Google App Engine网站，Google云端控制台，身份识别代理和Google OAuth 2.0端点的身份验证问题。”

  

“我们的工程团队正在调查可能的原因。我们将在美国/太平洋地区2019-08-19 12:15周一提供另一个状态更新，其中包含当前的详细信息，”谷歌补充道。

  

根据谷歌的G Suite状态仪表板，他们的工程团队也在“调查管理控制台问题的报告”，受影响的用户无法访问管理控制台。该状态还补充说“用户可能会遇到登录所有Google服务的问题”。

  

![](../Images/f0ba08ece645676aa7541e342ebdfbe7.png)

Google管理控制台问题  

 

美国东部时间8月19日15:22更新：谷歌在太平洋标准时间12:18发布的更新中称，“我们正在调查Google App Engine，Google云端控制台，身份识别代理和Google OAuth 2.0终端的身份验证问题工程团队。我们将在2019-08-19周一美国/太平洋时间周一提供另一个状态更新，并提供最新信息。“

  

此外，作为当前问题的解决方法：

  

*一些客户报告成功尝试使用Chrome浏览器下的隐身窗口进行登录。*

  

更新日期：美国东部时间8月19日15:44：部分用户现在可以根据G Suite状态信息中心的新更新登录其Gmail帐户：

  

*某些用户已经恢复了Gmail服务，我们希望在不久的将来能够为所有用户提供解决方案。**请注意，此时间范围是估计值，可能会发生变化。**受影响的用户无法访问Gmail。*

用户可能会遇到通过OAuth或Chrome设备登录所有Google服务的问题。已登录的用户不应受到影响。

  

谷歌云工程团队还表示“错误率正在下降，我们看到了服务改进。”

  

美国东部时间8月19日16:04更新：  Google表示绝大多数用户不应再遇到任何Gmail身份验证问题：

  

*应该为绝大多数受影响的用户解决Gmail的问题。**我们将继续努力为剩余的受影响用户恢复服务，但G Suite状态信息中心不会提供进一步的更新。**请放心，系统可靠性是Google的首要任务，我们正在不断改进，以使我们的系统更好。*

  

在谷歌云端控制台事件＃19008也被更新：

  

*应该为大多数客户解决对Google App Engine网站，Google Cloud Console，身份识别代理和Google OAuth 2.0端点进行身份验证的问题，并且我们希望在不久的将来能够获得完整的解决方案。*

  

美国东部时间8月19日16:50更新：Google表示已为所有用户解决了身份验证问题：

  

*截至2019-08-19 12:30美国/太平洋地区，所有受影响的客户都已解决了对Google App Engine网站，Google云端控制台，身份识别代理和Google OAuth 2.0终端进行身份验证的问题。**我们将对此问题进行内部调查，并对我们的系统进行适当的改进，以帮助防止或最大限度地减少将来的再次发生。 *
