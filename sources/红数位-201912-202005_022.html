Windows 10版本2004将修复CPU使用率高问题

Windows 10版本2004指日可待，尽管变更日志包含了许多新功能，但新功能更新显然具有许多其他改进。



其中之一似乎是对臭名昭著的bug的修复，该bug导致CPU使用率很高，在reddit上的讨论线程显示了新版本对旧计算机的影响有多大。


您在照片中看到的比较显示Windows 10版本1909（带有错误）和Windows 10版本2004（没有错误）在同一硬件上运行。这非常清楚，后者从一端到另一端将提供更加流畅的体验。



“微软对Windows 10 Search的索引方式进行了重大更改。屏幕截图来自具有4 GB RAM和250 GB 3.5“ 7200 RPM HDD（我已经躺在要测试的旧单元）的旧OptiPlex7010。两个屏幕截图均来自全新安装的更新（因此没有Windows Updating等操作）然后在YouTube上观看录像。1909版的录像机限制了光盘的使用，而2004版的录像机则没有，”发布比较镜头的Redditor解释说。


Windows 10版本2004预计下个月

您知道，高CPU使用率的错误同时影响了HDD和SSD，因此，Microsoft最终对其进行修复无疑是一个好消息。


Windows 10版本2004当前在Release Preview环中供用户使用，预计将在5月的某个时候开始向生产设备推出该版本。


就像以前的功能更新一样，此新版本将分阶段上线，但是还将提供其他下载方法（例如Media Creation Tool）来安装新版本，而无需等待自动推出。
