# Windows 10四月更新可能导致C盘文件被删或蓝屏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488572&idx=8&sn=9c3a4463770639e100f186f706575c27&chksm=cef3798ff984f0996d78cd73eecef65812add7ef3e118089d51f415428658072cc255a907a36&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488572&idx=8&sn=9c3a4463770639e100f186f706575c27&chksm=cef3798ff984f0996d78cd73eecef65812add7ef3e118089d51f415428658072cc255a907a36&scene=27#wechat_redirect)

Windows 10 用户通过微软支持论坛和社交媒体抱怨，最新更新导致了文件被删。这不是第一次 Windows 10 更新导致了用户数据删除。

  

![](../Images/9f18db537553882234b2d81615ba7f26.png)

  

微软是在本月中旬释出了四月例行更新，其中累积更新 KB454995 修复了一个拒绝服务漏洞 CVE-2020-0794，正是该补丁导致了问题。

  

用户报告，该补丁更新失败然后反复尝试重新安装更新；或者在“成功更新”之后出现了**蓝屏死机**；还有用户报告**重启之后 C 盘所有文件全部删除**。

  

在观念上有很多道理，因为微软太了解了：您无法一直取悦所有人。Windows 10现在已安装在十亿多台设备上，用户满意度始终存在很大差异。可以最清楚地看出这种变化的领域是更新领域。在每月一次的星期二补丁更新之后，这几乎已成为一种规范，用户可以参加该论坛以支持论坛，并抱怨其结果令人厌烦。除了两个引起我注意并且也应该引起您注意的事情，本月在这方面没有什么不同。首先，该补丁星期二更新集合中涉及的部分是安全修复程序。其次，投诉的性质是尽可能严重的。

  

**修补星期二的问题**

4月14日补丁程序星期二更新包括针对总共133个漏洞的修复程序，其中包括Windows 10中的七个关键安全漏洞。我们一直说，用户确实需要非常认真地解决安全漏洞。当新的研究表明Windows 10 PC的平均漏洞不少于14个时，如果您想知道的话，这些漏洞就是已知漏洞，那么这种严重性就得到了加强。

  

确实，当宣布4月14日更新时，我建议用户可能要跳过自动更新枪，并使用“检查更新”选项来强制下载。我还说过，“ 以防万一有错误，值得在安装任何更新之前备份您的数据 ”。

  

**KB4549951可能会遇到一些麻烦**

而且似乎存在一个漏洞，其中包含一个累积性安全修复程序KB4549951，该漏洞修复程序适用于所有Windows 10版本1903和1909版本。有问题的安全漏洞是一个拒绝服务漏洞CVE-2020-0794，但仅在攻击者已经登录到您的系统然后运行恶意应用程序的情况下，才会影响用户。您可能会说，在整体安全方案中，漏洞并不是最关键的漏洞。但是，所有安全漏洞都需要修复，因为任何安全漏洞都太多了，因此尽快应用更新对于确保系统和数据的安全至关重要。而这正是问题来了，据报道中安装KB4549951更新用户的一些后果的警告。

  

**保持镇定，不要惊慌**

首先，鉴于存在大量Windows 10用户，抱怨这些问题的人数（数百人）相对较少。如果您是其中之一，这并没有使其变得更好，但是确实需要从某种角度入手。这些用户向Microsoft支持论坛和社交媒体报告的问题包括安装失败并循环返回以再次重新启动，“成功”更新后可怕的蓝屏死机（BSOD）以及仅拒绝再次启动的计算机之后。就Windows 10更新后的投诉而言，最常见的问题是与蓝牙和Wi-Fi连接相关的问题。但是也有用户抱怨重启后，C驱动器中的所有文件都被删除了。

  

微软表示，它“ 没有在遥测，支持数据或客户反馈渠道中看到这些问题，”但是知道社交媒体报道中提到了蓝牙，蓝屏停止错误以及其他相关问题。微软在更新说明的“已知问题”部分说：“我们将不断调查所有客户的反馈，并密切监视这种情况。” Microsoft要求遇到问题的所有用户都使用Windows + F键盘快捷方式，或从“开始”菜单中选择“反馈中心”，以提供反馈，以便进行调查。
