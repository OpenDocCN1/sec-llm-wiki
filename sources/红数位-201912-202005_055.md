# 黑客更新了古老的Excel 4.0宏攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488488&idx=4&sn=b21ab6d5e191de35b284539ae2d9259b&chksm=cef37e5bf984f74d62f3291ec760e3f27f627825b88de87f9d4bb4ea39e5077686a8a120ef57&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488488&idx=4&sn=b21ab6d5e191de35b284539ae2d9259b&chksm=cef37e5bf984f74d62f3291ec760e3f27f627825b88de87f9d4bb4ea39e5077686a8a120ef57&scene=27#wechat_redirect)

据研究人员称，通过电子邮件发送的XLS文件似乎受密码保护，但不受密码保护，它们会自动打开以从受感染的宏安装恶意软件。

  

![](../Images/2f344ce945872e7b0b4f14adee00014a.png)

  

黑客通过一种新的无密码方式更新了古老的Excel恶意软件攻击技术。研究人员已经确定了一种新方法，该方法不再要求受害者输入密码来打开危险文档，使他们更容易受到潜在的恶意软件感染。

  

来自安全公司Trustwave的研究人员说，他们发现了一个新的恶意垃圾邮件活动，该活动会发送Excel 4.0 xls 97-2003文件，并在电子邮件中包含被破坏的宏。这种策略是可预见的，并且会尝试以从虚假发票到COVID-19相关诱饵等主题欺骗用户。

  

在过去的战役中，这种类型的攻击使用受密码保护的Excel 4.0文档。邮件正文包含一个密码，攻击者使用该密码来诱骗目标以打开Excel文档。这个想法是，使用Microsoft增强加密提供程序v1.0加密发送受密码保护的Excel文档。加密层通常允许恶意电子邮件绕过电子邮件防御。该文档本身包含Excel 4.0宏表-其中一个包含恶意宏。

  

更新的技术将维护加密的Excel文档。它还仍然需要用户交互-仍然必须诱使用户从网络钓鱼电子邮件中打开Excel文档。不同之处在于，当受害者打开受密码保护的文档时，黑客已经设计出一种无需加密密码即可打开加密和受密码保护的文档的方法。

  

据Trustwave研究人员Diana Lopera在周五概述该发现的博客文章中说：“密码已被应用于Excel文件，该文件使用Microsoft增强加密提供程序v1.0算法对附件进行加密。”

  

接下来，她解释说：“密码保护的文档只能使用正确的密码打开，因为这是解密过程中所需的密钥。Excel首先尝试在读取的文件中使用\[a\]默认密码“ VelvetSweatshop”打开受密码保护的Excel文件，唯一模式。”

  

研究人员说，在后台使用预设的默认密码打开Excel文档。“因此，不需要用户输入密码，也不会提示应用程序发出警告。XLS文件的内容将立即显示。”

  

这允许恶意的Excel 4.0文档遵循熟悉的感染例程。

  

参与者将恶意活动嵌入带有随机名称的宏表中。Excel工作表中包含一个恶意宏。

  

她说：“宏将从受影响的站点下载二进制文件，将其保存在C驱动器的磁盘上，然后执行它们。”

  

宏链接到托管Gozi的受感染站点，Gozi是一种银行木马，可以利用它来处理受害者的银行交易，窃取用于从受害者帐户中转移资金的凭据。

  

的确，Trustwave研究人员指出，当用户单击文件时，Excel处理文件的方式是一个已知的错误，已有10多年了。Mimecast威胁中心的研究人员还发现了一项活动，该活动最近传播了LimeRAT恶意软件，该恶意软件利用了与2013年在线发布的此只读功能有关的漏洞。

  

Trustwave的研究人员说，这种威胁是大量新的垃圾邮件活动之一，这些活动利用受密码保护的Excel 4.0宏进行恶意活动。
