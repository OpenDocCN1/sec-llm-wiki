Zoom RCE零日漏洞正在以50万美元价格销售

黑客正在出售一种利用零日远程执行代码漏洞的漏洞，该漏洞会影响Zoom的Windows客户端。零日漏洞利用的价格为50万美元正在出售，黑客还提供了另一个漏洞利用代码，以解决苹果系统客户Zoom中的漏洞。



“黑客正在出售视频会议软件Zoom的两个关键漏洞，这使某人可以黑客用户并监视他们的呼叫，Motherboard获悉。” 


“三个漏洞就是所谓的零日漏洞（Zero-days），目前据Zoom的Windows和MacOS客户端中存在，这是三位知情人士透露的。消息来源没有看到这些漏洞的实际代码，但提供这些漏洞的经纪人已与他们联系。”


Zoom是最受欢迎的视频会议软件之一，每天都有数百万用户在使用它，特别是在COVID爆发期间。为此原因，网络罪犯 以及国家级参与者都对在Zoom中获得有效的零日漏洞利用感兴趣，这些漏洞可能会让间谍 用户 流行软件。


零时差经纪公司Netragard的创始人  Adriel Desautels告诉Motherboard，他相信一旦在野外使用，这些零时差将不会长寿。


“ [Windows零日]很不错，一个干净的RCE [Remote Code Execution]，”一位消息人士说。网络安全行业。“非常适合从事工业间谍活动。”


Windows Zoom客户端的利用程序是一个远程执行代码漏洞，攻击者可以利用此漏洞在运行有漏洞的应用程序的系统上执行任意代码。将问题与其他漏洞联系起来，有可能接管运行有缺陷软件版本的设备。据Motherboard称，MacOS漏洞并不是远程执行代码的缺陷，它的危险性较小，在实际的攻击情况下更难采用。



消息人士说，零日漏洞利用要求黑客与目标进行通话，这是一种攻击者方案，限制了其对民族国家行为者的可用性。


macOS漏洞对源的描述较少，因为它不会滥用RCE错误，因此对安全性的影响较小。


Zoom宣布正在与领先的安全公司调查这两个问题。


“ Zoom非常重视用户安全性。自从了解到这些谣言以来，我们一直在与一家知名的行业领先的安全公司进行全天候的调查，” Zoom发表声明说。“到目前为止，我们还没有发现任何证据可以证明这些说法。”
