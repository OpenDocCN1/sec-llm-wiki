# 微软警告4月补丁影响VBA问题，附解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488474&idx=6&sn=cfac15990618ee7c2fca835564633bc8&chksm=cef37e69f984f77fcf0208fc8a9b1fc3691ce84b194c8dea579d388bb90cf87db7f50f1b40fd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488474&idx=6&sn=cfac15990618ee7c2fca835564633bc8&chksm=cef37e69f984f77fcf0208fc8a9b1fc3691ce84b194c8dea579d388bb90cf87db7f50f1b40fd&scene=27#wechat_redirect)

微软在几个小时前将2020年4月的安全更新作为典型的补丁星期二周期的一部分进行了发布，现在该公司返回警告，并解释说其中一个补丁可能会破坏某些类型的Visual Basic for Applications（VBA）参考。

  

更具体地说，问题出在Microsoft Office安全更新中，并且如果您的设备受到影响，则应该收到以下错误：

  

![](../Images/d5251d35ca2e2af866d6b0bf5a007c92.png)

“编译错误：找不到项目或库。”

  

**使用以下文件时，会遇到此错误，以下类型的VBA引用可能会受到影响：**

  

*   Typelibs（\* .olb，\*。tlb，\*。dll）
    
*   可执行文件（\* .exe）
    
*   ActiveX控件（\* .ocx）
    

  

如果这些文件位于Internet或Intranet服务器上，或者从Internet下载，则可能被阻止。

  

**解决方法**

Microsoft解释说，无论它们位于Internet或Intranet服务器上还是直接从Internet下载，它们在安装更新后最终都会被阻止。

  

“当您安装Microsoft常见漏洞和披露CVE-2020-0760中列出的Microsoft Office安全更新之一时，您可能会注意到某些类型的Visual Basic for Applications（VBA）引用被阻止，并且您收到一条错误消息。”微软说。

  

那么，如果最终在屏幕上出现此错误，该怎么办？微软表示，唯一的方法就是用本地库替换被阻止的库。Microsoft在这方面有更多指导：

  

“ Internet VBA对象库：我们建议您阻止这些对象，因为它们很容易受到攻击。

![](../Images/d5251d35ca2e2af866d6b0bf5a007c92.png)

  

**Intranet VBA对象库：可以通过GPO设置启用这些对象库，如下图所示。该设置位于“用户配置”>“管理模板”>“ Microsoft Office 2016”>“安全设置”下。”**

  

Windows 10用户的一个重要注意事项：在撰写本文时，本月的累积更新没有报告的问题，因为所有更新（无论使用什么操作系统）都似乎运行平稳，没有任何安装问题。
