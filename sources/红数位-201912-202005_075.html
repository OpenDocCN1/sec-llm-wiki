微软延迟终止对旧版Windows软件版本的支持

原文：http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488421&idx=4&sn=b315e9126a556e2b534157b243922d3c&chksm=cef37e16f984f70085971d214c84f97336d4893aa80625cbfc7402b4a5dd5d499f50135041da&scene=27#wechat_redirect

微软已经推迟了Windows 10版本1709/1809和较旧的软件和服务的支持日期，以减轻组织在冠状病毒大流行期间已经感受到的压力。



由于大多数组织的员工都在远程工作，因此几乎没有劳动力和时间来充分准备软件，服务和操作系统，直到支持结束并进行必要的升级。


因此，Microsoft现在将终止对各种较旧软件的支持，直到Coronavirus危机过去之后。



“ Microsoft已与受当前公共卫生状况影响的全球客户深入合作。作为全球社区的一员，我们希望为减轻客户目前面临的压力做出贡献。为此，我们推迟了支持和服务于对下面的产品可以帮助个人和组织的日期计划结束专注于保持业务连续性，”在新表示，他们关注支持文章。


以下是受影响的产品，支持的原始终止日期及其新的EoS日期。对于任何具有有关此延迟的其他信息的产品，我们已从产品名称链接到它们。


微软产品原始EoS日期新的EoS日期
Windows 10版本1709（企业，教育，IoT企业）2020年4月14日2020年10月13日
Windows 10版本1809（家庭，专业版，专业教育版，专业版工作站，IoT核心版）2020年5月12日2020年11月10日
Windows Server版本1809（数据中心，标准）2020年5月12日2020年11月10日
Configuration Manager（当前分支）版本18102020年5月27日2020年12月1日
SharePoint Server 2010，SharePoint Foundation 2010和Project Server 20102020年10月13日2021年4月13日
Dynamics 365云服务2020年9月2020年12月
Exchange Online中的基本身份验证2020年10月13日2021年下半年

Microsoft进一步声明，此公告不影响上面未列出的软件的支持终止日期。

这意味着Exchange Server 2010，Office 2010，Project 2010，Mac的Office 2016和Office 2013与Office 365服务的连接的支持终止日期将与计划的日期继续。
