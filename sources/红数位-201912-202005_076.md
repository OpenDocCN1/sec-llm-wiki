# Windows 10累积更新KB4549951和KB4549949已发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488421&idx=5&sn=d3ddd5675db48dee28f849ab9a6c0585&chksm=cef37e16f984f700c6cc09e9b77cdcf4fb968d4087fbfcd3682c2513777ce13afde611062f9c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488421&idx=5&sn=d3ddd5675db48dee28f849ab9a6c0585&chksm=cef37e16f984f700c6cc09e9b77cdcf4fb968d4087fbfcd3682c2513777ce13afde611062f9c&scene=27#wechat_redirect)

今天星期二补丁程序（2020年4月更新）将推出到所有受支持的Windows 10版本。具有安全修复程序的累积更新将在2019年11月更新，2019年5月更新和2018年10月更新向PC推出。

  

![](../Images/8164891dff7e880024a50ac818c6a98a.png)

  

在2020年4月Windows 10版本1909、1903和版本1809的累积更新中，仅对系统，核心组件和其他基本功能进行了安全性增强。

  

如果您没有应用3月的可选更新，则还将获得这些修复程序。

  

与每个Windows Update一样，您可以打开“设置”应用程序，然后单击Windows Update选项以安装修补程序。如果您拥有多台PC，或者想要手动修补PC，则可以在此处了解更多信息  。

  

**Windows 10的版本18362.778和18363.778**

Windows 10 1903版的April Patch（KB 4549951）调出了Windows 10 1909版的Build 18362.778和Build 18363.778。

  

这些改进仅是安全修复程序：

  

*   解决了某些应用程序使用组策略对象发布时阻止其安装的问题。
    
*   解决了在有线802.1x重新认证后，有线网络接口无法在新子网和虚拟LAN（VLAN）上获得新的动态主机配置协议（DHCP）IP地址的问题。如果您使用基于帐户的VLAN，并且用户登录后发生VLAN更改，则会出现此问题。
    
*   Microsoft脚本引擎，Windows App平台和框架，Windows云基础结构，Windows虚拟化，Microsoft图形组件，Windows内核，Windows Media，Windows Shell，Windows管理，Windows基础知识，Windows虚拟化，Windows存储和文件系统，Windows Update的安全更新堆栈和Microsoft JET数据库引擎。  
    

  

**Windows 10 October 2018 Update的内部版本17763.1158附带以下修复程序：**

  

*   解决了某些应用程序使用组策略对象发布时阻止其安装的问题。
    
*   Microsoft脚本引擎，Windows内核，Windows App平台和框架，Microsoft图形组件，Windows Media，Windows Shell，Windows管理，Windows Cloud Infrastructure，Windows基础知识，Windows虚拟化，Windows Core Networking，Windows存储和文件系统，Windows的安全更新更新堆栈和Microsoft JET数据库引擎。
