# 微软的Windows 7新浏览器将在一年多后淘汰

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488405&idx=5&sn=9b3822f5038c67a870bf7c7a68b13054&chksm=cef37e26f984f730778d0786b204197be88e516a0183805e1121d809ef04a119c7147ad41344&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488405&idx=5&sn=9b3822f5038c67a870bf7c7a68b13054&chksm=cef37e26f984f730778d0786b204197be88e516a0183805e1121d809ef04a119c7147ad41344&scene=27#wechat_redirect)

Microsoft的Edge浏览器的现代版本运行在Chrome引擎上，现在也可以在非Windows 10操作系统（包括Windows 7，Windows 8.1和macOS）上使用。

  

![](../Images/db33d391085abb8d755559bf54b014b9.png)

  

Windows 7上的新浏览器对于某些人来说是令人惊讶的消息，因为该平台已经淘汰，并且自今年1月起不再获得安全更新。

  

但是，基于Chromium的Edge在Windows 7上保留的时间不会太长，因为微软计划在2021年中期退休。

  

**支持至少持续到2021年中**

微软在今年早些时候至少在 2021年7月之前支持Windows 7上的Edge的消息首次出现，但是现在这家软件巨头已经更新了其官方文档，其中包含有关此日期的更多详细信息。

  

该公司解释说：“我们将继续在Windows 7和Windows Server 2008 R2上支持Microsoft Edge，直到2021年7月15日。这些操作系统已不再受支持，Microsoft建议您迁移到受支持的操作系统，例如Windows10。” AskWoody）。

  

“尽管Microsoft Edge可以帮助您提高网络安全性，但您的PC仍可能容易受到安全风险的影响。为了在这些操作系统上支持IE模式，设备将需要具有Windows 7的扩展安全更新。如果没有Windows 7扩展安全更新，Internet Explorer功能将很容易受到安全风险的影响。此外，如果不通过扩展的安全更新进行持续服务，则IE模式功能可能会停止工作。”

  

当然，这样做的目的是给Windows 7用户足够的时间来升级到仍受支持的Windows新版本。Windows 10是Microsoft的推荐选择，原因很明显-Windows 10上提供了新的Edge作为新的默认浏览器，取代了系统上的Edge旧版。

  

**Chrome浏览器再支持18个月**

  

Google Cloud对企业的建议是过渡到Windows10系统。对于尚未升级的用户，它将“在微软终止服务之日起至少18个月内，至少在2021年7月15日之前，继续完全支持Windows 7上的Chrome浏览器。”
