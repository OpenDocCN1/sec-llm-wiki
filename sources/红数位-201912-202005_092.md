# 黑客可以通过新修补的漏洞破坏VMware vCenter Server

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488375&idx=5&sn=8022cdd6deada7838f1ba53c27d3f62d&chksm=cef37ec4f984f7d23dbdc4fa1f137a27638a3dd930ebc55764e453b5b50f7661408920bbd4d1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488375&idx=5&sn=8022cdd6deada7838f1ba53c27d3f62d&chksm=cef37ec4f984f7d23dbdc4fa1f137a27638a3dd930ebc55764e453b5b50f7661408920bbd4d1&scene=27#wechat_redirect)

VMware已修复了一个严重漏洞，该漏洞可被利用来破坏vCenter Server或依赖目录服务进行身份验证的其他服务。

  

![](../Images/6f5ad2ca647af1c92a209dcda8602b3a.png)

  

VMware于周四披露了该漏洞，其追踪为**CVE-2020-3952，CVSS评分为10。**这家虚拟化巨头从一位尚未在公司安全公告中被任命的研究员那里得知了它的存在。

  

![](../Images/d66940a19688d1bc6a6b46295c36ac63.png)

该漏洞影响Windows和虚拟设备上的vCenter Server 6.7，并已通过6.7u3f更新进行了修补。但是，该公司指出，**只有从先前版本升级安装后，vCenter Server才会受影响。如果用户直接安装6.7版，则该产品不会受到影响。**

  

VMware将漏洞描述为与目录服务（vmdir）相关的信息泄露问题。

  

“在某些情况下，作为嵌入式或外部Platform Services Controller（PSC）一部分的VMware vCenter Server附带的vmdir无法正确实现访问控制，” VMware在其通报中表示。

  

![](../Images/a4ce92fd10cb3b291357fd9e62fce816.png)

  

  

该公司补充说：“具有对受影响的vmdir部署具有网络访问权限的恶意参与者可能能够提取高度敏感的信息，这些信息可用于破坏vCenter Server或其他依赖vmdir进行身份验证的服务。”

  

![](../Images/2e0db736da7a9ba76239f06d31558352.png)

  

VMware表示，用户可以通过检查其日志中的某些vmdir条目来确定自己是否受到影响。

  

上个月，VMware 针对特权升级漏洞发布了两个补丁，这些漏洞影响了macOS版本的Fusion。但是，向VMware报告该问题的研究人员说，他们两个都不完整。
