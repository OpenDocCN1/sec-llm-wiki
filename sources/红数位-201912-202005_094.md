# RigUp数据库暴露来自美国能源部门的76,000个文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488375&idx=6&sn=a5e6ba24cd3cfeaf0f51bdbcaf02a5f8&chksm=cef37ec4f984f7d2486ceeb9d178944483665d399f34886dca1331392016fc3f5be82e75d378&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488375&idx=6&sn=a5e6ba24cd3cfeaf0f51bdbcaf02a5f8&chksm=cef37ec4f984f7d2486ceeb9d178944483665d399f34886dca1331392016fc3f5be82e75d378&scene=27#wechat_redirect)

vpnMentor报告称，发现一个属于RigUp的暴露的Amazon Web Services（AWS）S3存储桶暴露了成千上万个属于美国能源部门组织和个人的私有文件。

  

![](../Images/d5543a02f20719367b3df114cd56576c.png)

  

总部位于美国的RigUp成立于2014年，是该国能源行业的劳动力市场和服务提供商。该软件公司将独立承包商与美国各地的公司联系起来

  

vpnMentor 说，发现的数据库包含超过76,000个与使用该平台的公司和个人有关的私人文件。

  

3月10日，安全公司发现了暴露的S3存储桶，该存储桶标有“ ru”字样，其中包含许多带有RigUp名称的文件，从而可以快速识别所有者。

  

实时数据库的大小超过100GB，其中包含2018年7月至2020年3月之间存储的数据。RigUp在该数据库中存储了属于客户，承包商，求职者和应聘者的大量文件。

  

在数据库中找到的与人力资源相关的文件包括雇员和候选人的简历，个人照片（甚至私人家庭照片），与保险单和计划相关的文书工作和ID，专业ID，个人资料照片（包括美国军事人员）以及专业扫描不同领域的证书。

  

这些文件中包含大量个人身份信息（PII），例如完整的联系方式（姓名，地址，电话号码，家庭住址），社会保险信息，出生日期，保险单和税号，个人照片，以及与教育，专业经验和个人生活有关的其他信息。

  

在数据库中还可以找到与许多能源公司的业务运营，项目和公司关系相关的内部记录，包括项目建议和应用，项目大纲，钻井设备的技术图纸以及公司保险文件。

  

vpnMentor说：“如果恶意黑客发现了该数据库，那么对于各种欺诈方案和对涉及的所有人的犯罪袭击，它绝对是金矿。”

  

该安全公司指出，此问题的根本原因是RigUp没有适当地保护数据库的安全，从而使数千个人暴露了信息。但是，该公司在收到有关此事的警报后很快就解决了该问题。

  

这些类型的漏洞几乎总是与人为错误相关，要么不遵循文档说明，要么在部署过程中未能自动执行重要的安全步骤。答案仍然是不断提高人们对与网络安全相关的风险的认识，以及在涉及人为行动时保持警惕的重要性。Cerberus Sentinel总裁比尔·桑托斯（Bill Santos）在一封电子邮件中表示，树立这种意识文化是任何组织减少网络暴露的第一步，也是最重要的一步。
