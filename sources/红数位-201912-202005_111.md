# Microsoft推迟TLS 1.0和1.1的淘汰

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488313&idx=4&sn=d9cb897a8e3d0cb616cbb00a1c4cbf2f&chksm=cef37e8af984f79c3c869554a7f775053ed643ce92c63b486373237dad9bd8575cd25caa8697&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488313&idx=4&sn=d9cb897a8e3d0cb616cbb00a1c4cbf2f&chksm=cef37e8af984f79c3c869554a7f775053ed643ce92c63b486373237dad9bd8575cd25caa8697&scene=27#wechat_redirect)

微软刚刚宣布由于冠状病毒的爆发而推迟了其浏览器中TLS 1.0和1.1的淘汰。

  

![](../Images/1cf78a4a4d2a0afab37c90917fd9bc55.png)

  

由于大量开发人员为了避免感染该病毒而留在家里，由于这种重大更改而通常需要进行的工作需要更多的精力和明显更多的时间，因此Microsoft已决定推迟TLS 1.0和1.1的撤消日期。到下半年。

  

TLS 1.0和1.1最初定于2020年上半年淘汰，从技术上讲，它们仍会破坏仍在使用它们的网站。虽然数量不多，但是鉴于在每个人都需要这些站点的时候，世界各地的某些政府页面可能仍在使用它们，因此Microsoft重新考虑了时间表。

  

**主要浏览器版本也被取消**

在Microsoft Edge中，默认情况下将禁用TLS 1.0和1.1的日期现在为版本84，当前日期为2020年7月。对于原始Microsoft Edge版本（也称为旧版）和Internet Explorer 11，现在的新默认值为2020年9月8日。

  

“正如2018年10月宣布的那样，Microsoft很快将默认在Microsoft浏览器中禁用传输层安全性（TLS）1.0和1.1。鉴于当前的全球形势，我们将推迟原计划于2020年上半年进行的计划变更。”

  

“尽管这些协议仍可供客户根据需要重新启用，但我们建议所有组织在可行的情况下尽快退出TLS 1.0和TLS 1.1。较新版本的TLS协议支持更现代的加密技术，并且在现代浏览器（例如新的Microsoft Edge）中得到广泛支持。”

  

微软还跳过了Microsoft Edge的主要版本（82版本已被永久取消）。下一个重大更新是Edge 81，将于4月初发布。
