# 谷歌表示将于4月初发布重要的Chrome更新版本81

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488250&idx=6&sn=5c3719337fde6cc8d24d89a500a11fce&chksm=cef37f49f984f65ff8e1e9cbce750cd1cdd2d58801d31ee7dbb4cf0fd7fb614572b9acf9bd80&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488250&idx=6&sn=5c3719337fde6cc8d24d89a500a11fce&chksm=cef37f49f984f65ff8e1e9cbce750cd1cdd2d58801d31ee7dbb4cf0fd7fb614572b9acf9bd80&scene=27#wechat_redirect)

谷歌最近宣布，由于冠状病毒的爆发，它将暂停谷歌浏览器的主要更新，以使开发人员有更多的担忧，因为他们在发布后必须进行典型的兼容性工作，现在该公司共享有关其工作方式的更多信息。计划维护浏览器。

  

![](../Images/a2677c71e20935ad798fe2013f094846.png)

  

首先，大多数用户当前正在运行的Google Chrome稳定版将在下周尽快进行重大更新。

  

但是，重要的是要知道，此更新将仅包含针对现有版本的Google Chrome浏览器的安全性和关键修复程序。因此，此更新将不是新的主要版本，而仅修复了我们对于Chrome 80绝对需要的修复程序。

  

另一方面，Chrome 81指日可待，因为Google表示它将在4月7日的第一周登陆。

  

**Chrome 82被取消**

同时，Google已决定完全取消Chrome 82，因此在81版之后，该公司将直接跳至Chrome 83。

  

谷歌说：“ M83将比原计划提前三周发布，并将包括我们取消M82版本（所有渠道）后的所有M82工作。”

  

换句话说，Google Chrome 83是继Chrome 81之后的下一个主要更新，根据现有时间表，它应该在5月中旬登陆。

  

从本周或下一个周开始，所有其他Chrome通道应重新开始正常接收更新。Chrome 81将继续为Beta版，而Chrome 83将移至Dev通道。

  

“我们将继续密切监视Chrome和Chrome操作系统的稳定性，安全性和可靠运行。Google会在发布博客上向所有人通知我们日程安排的任何更改，并根据需要在Chromium Developers组中共享日程安排的其他详细信息。”
