黑客利用Draytek设备中的零日漏洞来瞄准企业网络

原文：http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488250&idx=7&sn=fa00fcfbd5faf271a8415677cf2fa147&chksm=cef37f49f984f65f2244f7a530e4dc631b75c7a4215e0eb5a1ac833772009aafe4806c05a034&scene=27#wechat_redirect

奇虎360的NetLab网络安全研究人员今天揭晓了针对台湾台湾DrayTek制造的企业级网络设备的两场最近发现的零日网络攻击活动的详细信息。



根据该报告，至少有两个单独的黑客组织利用了两个关键的远程命令注入漏洞（CVE-2020-8515），这些漏洞影响了DrayTek Vigor企业交换机，负载均衡器，路由器和VPN网关设备，以窃听网络流量并安装后门。


零日攻击在去年十一月底或12月初开始的地方，并有可能仍在进行对数以千计的公开曝光居易的SwitchE S，活力2960，3900，300B尚未上个月发布的最新固件更新补丁的设备。


任何未经授权的远程攻击者都可以利用所涉及的零日漏洞来在系统上注入并执行任意命令，这也由另一位研究人员在其博客中详细介绍。


路由器交换机VPN黑客攻击


报告说：“两个为期0天的漏洞命令注入点是keyPath和rtick，它们位于/www/cgi-bin/mainfunction.cgi中，而对应的Web Server程序是/ usr / sbin / lighttpd。”


DrayTek骇客入侵


NetLab研究人员尚未将这两种攻击都归因于任何特定的组，但它确实确认了，虽然第一组只是监视网络流量，但第二组攻击者使用rtick命令注入漏洞来创建：


  • 永不过期的Web会话后门，

  • TCP端口22335和32459上的SSH后门，

  • 用户“ wuwuhanhan”和密码“ caonimuqin”的系统后门帐户。


需要注意的是，如果您刚刚安装了补丁固件或现在安装了该固件，则如果您已经受到威胁，它将不会自动删除后门帐户。


 “我们建议DrayTek Vigor用户及时检查并更新其固件，并检查系统上是否存在tcpdump进程，SSH后门帐户，Web Session后门等。”


该公司建议：“如果在路由器上启用了远程访问，请在不需要时将其禁用，并在可能的情况下使用访问控制列表。”


受影响的固件版本列表如下：

  • Vigor2960 <v1.5.1

  • Vigor300B <v1.5.1

  • Vigor3900 <v1.5.1

  • VigorSwitch20P2121 <= v2.3.2

  • VigorSwitch20G1280 <= v2.3.2

  • VigorSwitch20P1280 <= v2.3.2

  • VigorSwitch20G2280 <= v2.3.2

  • VigorSwitch20P2280 <= v2.3.2


强烈建议受影响的公司和个人安装最新的固件更新，以完全保护其宝贵的网络免受恶意软件和新兴在线威胁的侵害。
