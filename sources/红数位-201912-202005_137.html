微软偷偷修复了导致Windows Defender漏扫

Microsoft默默解决了导致Windows Defender在Windows 10上执行扫描期间跳过文件的问题。



根据BornCity的报告，此错误已通过3月24日发布的更新得到解决。我可以确认，在安装了Windows Defender的最新更新之后，快速和完整的扫描可以正常进行，没有任何问题。


解决此问题需要安装的更新为KB4052623，它被描述为Windows Defender 反恶意软件平台的更新。它针对Windows 10，Windows Server 2016和Windows Server 2019。


奇怪的是，正式的KB页面（上面带有链接）要求对3月5日发布的KB4052623进行最新修订。另一方面，Microsoft Update Catalog显示3月24日发布了一个新版本，但是该版本尚未发布。标记为反恶意软件引擎的更新，但标记为“定义更新”。


但是，Microsoft确认在安装此3月24日更新之后，Windows Defender引擎版本为4.18.2003.8。


更新Windows Defender

根据以前的报告，此问题是由于Windows Defender不再扫描网络文件引起的，并且Microsoft在KB页上解释说它知道导致网络流量较高的问题，尽管尚不清楚这两个问题是否直接相关，并且可能会导致跳过的项目错误。


“在审核或阻止模式下使用网络保护的企业可能会遇到超出预期的网络流量，从而将其网络转移到与Microsoft Defender SmartScreen相关的域。这会影响正在运行4.18.2001.10版本的客户。我们正在努力进行服务更新以解决此问题。在此期间，您可以通过暂时禁用网络保护来解决此问题。”


您可以从Windows安全>病毒和威胁防护>病毒和威胁防护更新>检查更新来更新Windows Defender引擎。安装最新版本后，无需重新引导系统。
