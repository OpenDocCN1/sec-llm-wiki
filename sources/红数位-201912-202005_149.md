# 微软即将杀死Windows 10中的经典控制面板

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488212&idx=7&sn=343579154ed028a7ca8769d7c870e01d&chksm=cef37f67f984f6712eef96401c7c5604f8e6534b06999c5f144942786e759404f434c12384b4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488212&idx=7&sn=343579154ed028a7ca8769d7c870e01d&chksm=cef37f67f984f6712eef96401c7c5604f8e6534b06999c5f144942786e759404f434c12384b4&scene=27#wechat_redirect)

一段时间以来，我们就已经知道微软计划杀死Windows 10中的经典控制面板，并用“设置”应用程序代替它，但是现在看来，整个事情即将发生。

  

![](../Images/d625dc4196281e400a59c4060548f559.png)

  

微软本质上希望摆脱传统的控制面板，仅仅是因为它是经典Windows体验的最后一部分。

  

借助Windows 10，该公司已迁移到一个现代概念，希望从一端提供到另一端。为了使之成为可能，Microsoft将以前在经典“控制面板”中提供的选项迁移到“设置”应用程序，并且最新的Windows 10功能更新使这一新想法得以进一步发展。

  

但是，微软从传统的“控制面板”过渡到“设置”应用程序的步伐也非常缓慢，这家公司本身甚至都没有提供有关旧功能何时将全部消失的ETA信息。。

  

**Windows 10版本2004**

但是，根据拉斐尔·里维拉（Rafael Rivera）在Twitter上分享的一项最新发现，实际上，与控制面板本来应该拿到斧头的那一刻相比，我们实际上比我们想象的要近。Microsoft已将控制面板的更多内容移至“设置”应用程序，以前作为传统体验的一部分提供的某些页面现在已嵌入到现代UI中。

  

“在版本19587中可以看到-新速度，HideSystemControlPanel（vso / tfs 25175482）。看来微软正在努力杀死{BB06C0E4-D293-4f75-8A90-CB05B6477EEE}，”里维拉（Rivera）发推文说。

  

Windows 10的下一个功能更新将在2004版本发布。但是，尚不清楚该版本是否应该是将控制面板淘汰的版本，因为当前的预览版本对此没有任何更改。
