# 3月星期二补丁导致Windows Defender漏扫

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488143&idx=1&sn=b89b9e891b7707110229abe872ee000d&chksm=cef37f3cf984f62a89f0e06432da4570c2f50202dccbe5507efbfe426f6af9300f3b20eaa8c5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488143&idx=1&sn=b89b9e891b7707110229abe872ee000d&chksm=cef37f3cf984f62a89f0e06432da4570c2f50202dccbe5507efbfe426f6af9300f3b20eaa8c5&scene=27#wechat_redirect)

在过去的两周中，Windows 10用户一直报告由于配置的排除或网络扫描设置，Windows Defender扫描正在跳过文件。

  

但是，报告收到这些消息的用户没有在Windows Defender首选项中配置任何排除项。

  

即便如此，当他们使用Windows Defender进行快速扫描或完全扫描时，也会创建Windows 10操作中心通知，指出在扫描过程中项目被跳过，并显示以下消息：

  

***扫描期间跳过的项目由于排除或网络扫描设置，Windows Defender防病毒扫描跳过了一个项目。***

  

近日的反病毒软件测试结果表明，Windows 10 操作系统预装的 Windows Defender，已能够与业内领先的第三方安全供应商相当。**尴尬的是，如果你的系统已经打上了三月的补丁，那它很可能漏过对某些文件的扫描。**外媒 BornCity 报道称，微软在 3 月的“补丁星期二”那天发布了面向 Windows 和其它产品的安全更新。 

![](../Images/c19304f6b89f07f8f1113a64ffa24f95.png)

用户汇报称，无论是选择快速或完整扫描，Windows Defender 都有可能在期间跳过对某些文件的检查，就像是在配置文件中已经将之列入了排除项一样。

与此同时，行动中心也会在遇到该问题时，向用户推送一条错误消息。其写道：“由于排除或网络扫描设置的原因，扫描期间跳过了某个项目”。

有些人可能觉得这与 Windows Defender 的特定版本有关，且能够通过与 Windows 10 系统拆分的升级措施来避免。

然而现在的情况是，无论你用的是哪个版本的 Windows Defender 反病毒软件客户端，它都会在打上三月补丁后遇到这个问题。

外媒 Softpedia 在运行 Windows 10 1909 的设备上尝试了最新的客户端和病毒定义，结果也在执行快速或完整扫描时重现了这个故障。

了100％确保没有隐藏的排除项或奇怪的网络设置，我使用以下命令提取Windows Defender首选项。

  

Get-MpPreference | findstr /i "net exc" 

如您所见，我们没有配置排除对象，并且我们的网络设置已配置为默认首选项。

  

![](../Images/030eed030cf1bc0f5198ac2dbf1cecb6.png)

Windows Defender中配置的排除和网络首选项  

  

可以肯定，这是一个奇怪的错误，因为在受影响的用户中似乎看不到任何共同点。

  

尽管没有设置任何排除项，但扫描结束后，还是在 Windows 10 的行动中心里看到了跳过某些文件扫描的错误通知。

截止发稿时，微软似乎尚未意识到这个问题。目前暂不清楚这是个例还是普遍现象，以及到底有多少设备受到了影响。

对于用户来说，或许可以尝试其它方法来确保安全，或等到微软在 4 月 14 日发布下一批安全更新时再修复。
