# Windows 10累积更新KB4541331修复了升级期间的蓝屏错误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488074&idx=7&sn=bb1bfbf8aae32215e042009992eae9cf&chksm=cef37ff9f984f6ef4a7587d3d085cc55b39aec1844cf0d4d538ade81e3de90eaef277df126c0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488074&idx=7&sn=bb1bfbf8aae32215e042009992eae9cf&chksm=cef37ff9f984f6ef4a7587d3d085cc55b39aec1844cf0d4d538ade81e3de90eaef277df126c0&scene=27#wechat_redirect)

微软针对较旧的Windows 10版本发布了许多新的累积更新，包括版本1809，也称为2018年10月更新。

  

![](../Images/e177750cc536d192d49f96877c3e556f.png)

  

由于此更新不会在星期二的补丁程序中发布，因此重点是非安全性改进，但无论如何它都包含许多欢迎修复程序。

  

例如，累积更新KB4541331解决了一个长期问题，当升级到Windows 10版本1809时，该问题可能会导致蓝屏死机错误。Microsoft并未提供太多有关此问题的详细信息，但它确实说仅在以下情况下会发生在某些情况下，因此很可能不会影响大量设备。

  

此外，此更新还附带了针对企业的一系列修补程序。

  

解决了可能导致域控制器（DC）在\_MSDCS。<目录林根域> DNS区域中注册小写和混合或全部大写的域名系统（DNS）服务（SRV）记录的问题。DC计算机名称包含一个或多个大写字符时，会发生这种情况。”

  

**4月补丁星期二的新更新**

微软表示，它还包括一些兼容性改进功能，以在更多设备配置上从Windows 10的较早版本升级到1809版，从而更加平滑。

  

“解决了评估Windows生态系统的兼容性状态以帮助确保应用程序和设备与Windows所有更新的兼容性的问题。”

  

完整的变更日志可在跳转后的框中找到。

  

此新的累积更新中没有已知问题，您需要知道的是，它在部署后会将操作系统内部版本号增加到17763.1131。

  

此更新中的所有改进也将作为Windows 10发行版的下一个累积更新的一部分，作为4月补丁星期二的一部分。根据微软的典型日历，下一个补丁星期二于4月14日进行。
