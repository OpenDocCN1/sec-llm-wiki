# 美国Cyber Dome组建PC-ISAO集团以共享网络威胁信息

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488046&idx=4&sn=6a48a8394caa8fd5fa8958a69d4814b2&chksm=cef37f9df984f68b3482f6d0fd70809113b54500dfd6989aa5ac16cc2754cf81930f3a67a925&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488046&idx=4&sn=6a48a8394caa8fd5fa8958a69d4814b2&chksm=cef37f9df984f68b3482f6d0fd70809113b54500dfd6989aa5ac16cc2754cf81930f3a67a925&scene=27#wechat_redirect)

美国政党的网络安全提供商US CyberDome宣布将与政治活动共享网络威胁信息。该组织还通过美国总统行政命令建立了政治运动信息共享和分析组织（PC-ISAO），以促进私营部门网络安全信息共享。

  

![](../Images/5cd0e219cc1a769c78d3b931a365d739.png)

  

特许PC-ISAO来帮助经常需要外部网络安全支持的组织。邀请美国联邦，州，地方，部落和领土政府各级的政治运动参加。

  

“ Cyber-ISAO是一个中立且无党派的场所，技术人员可以在其中共享关键的网络安全警报和最佳实践，”担任美国CyberDome顾问委员会主席的国土秘书Michael Chertoff说。“ PC-ISAO帮助成员在关键的网络安全挑战方面进行协作。”

  

美国CyberDome为跨党派的政党，民选代表和候选人提供免费的网络安全服务，以确保流程的完整性和对结果的信心。它由网络安全专家组成，这些专家在世界上最大的认可计算机取证和事件响应研究所，国防网络犯罪中心，美国国防部以及美国国家标准与技术研究院培训和实践。

  

“美国CyberDome是一个无党派，非营利性组织，旨在保护政治活动不受网络和信息威胁的侵害。这一努力现在该组织进一步加强宣布的首次信息共享和分析组织政治运动形成的，” 说，前国土部长杰·约翰逊，谁担任顾问的美国CyberDome的董事会主席。
