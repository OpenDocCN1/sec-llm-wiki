# 美国就网络安全担忧报废导弹

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488020&idx=3&sn=dac0005019c281997b674c008c78b842&chksm=cef37fa7f984f6b173d283ab367f1285a53dd137e3ae65ee7e01f0da5b4727a04a30a34fe7bf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488020&idx=3&sn=dac0005019c281997b674c008c78b842&chksm=cef37fa7f984f6b173d283ab367f1285a53dd137e3ae65ee7e01f0da5b4727a04a30a34fe7bf&scene=27#wechat_redirect)

由于担心网络安全，美国放弃了引入以色列制造的导弹系统的计划。

  

![](../Images/005cf84a73051478afe4392bd36e2a9e.png)

  

去年美国陆军对购买铁穹导弹的两节电池花费$373美元。据报道，以色列拒绝交出该系统的源代码后，到2023年在两个新电池和铁穹顶部件上再花费6亿美元的计划现在被取消了。

  

如果没有源代码，军队将无法将电池与其他防空系统集成。军方担心未能集成电池会造成严重的网络安全漏洞。

  

3月5日，在美国陆军武装部队战术空军和陆军小组委员会上发表讲话时，陆军未来司令部司令迈克·默里将军说：“我们花了比原本想要的时间花的时间更长。 

  

“我们认为，我们不能基于一些互操作性挑战，一些网络（安全）挑战和其他挑战将它们集成到我们的防空系统中。因此，我们最终拥有的是两个非常强大的独立电池，但是它们无法集成。”

  

去年试图将“铁穹”系统与美国陆军的“综合作战指挥系统”（IBCS）相集成的尝试带来了一些挑战，其中包括网络安全问题。 

  

默里说，“将铁穹顶集成到我们的分层防空体系中\[并且\]使铁穹顶与其他系统\[和\]其他雷达，特别是Sentinel雷达进行对话，异常困难。” 

  

“几乎可以肯定，您将要看到的是两个独立系统。如果我们能做的最好的就是独立系统，我们不想再购买两节电池。”

  

美国陆军购买的两枚铁穹顶电池包括12个发射器，两个传感器，两个战备管理中心和240个拦截器。

  

“铁穹”最初是   由以色列于2011年4月在贝尔谢巴郊外部署的。该系统由  拉斐尔高级防御系统，  以色列航空航天工业公司和  制造美国制造的爱国者导弹系统的雷神公司制造。 

  

具有讽刺意味的是，2012年国会同意 向以色列提供15亿美元用于开发和生产该系统时，Iron Dome的资金主要来自美国纳税人  。
