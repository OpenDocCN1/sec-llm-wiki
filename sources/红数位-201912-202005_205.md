# 网络空间日光浴室委员会呼吁改进美国网络安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488020&idx=7&sn=85e751de977026a1bb69e7d388a766e5&chksm=cef37fa7f984f6b1549a006f6948aa77bf4fb49e781b0798d8a323d7b1c6d29d6e91aaf14db0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488020&idx=7&sn=85e751de977026a1bb69e7d388a766e5&chksm=cef37fa7f984f6b1549a006f6948aa77bf4fb49e781b0798d8a323d7b1c6d29d6e91aaf14db0&scene=27#wechat_redirect)

新成立的网络空间日光浴室委员会本周发布了备受期待的报告，建议美国对网络威胁进行防御。它为振兴美国的网络安全提供了75多项建议，其中特别强调了到11月的选举安全。

  

![](../Images/acf6d4fdb6190c7fbd22bbc76c701b92.png)

  

**关键建议包括：制定更新的美国国家网络战略；在众议院和参议院中成立新的网络安全常设security选委员会；并任命一名经参议院确认的国家网络总监。**

  

该委员会是根据2019年国防授权法授权的，由I-Maine参议员Angus King和R-Wis众议员Mike Gallagher共同主持。它还包括特朗普政府官员。该报告称，其使命是“就在网络空间保卫美国免受严重后果的网络攻击的战略方法达成共识”。

  

**民族国家威胁**

该报告将中国，俄罗斯，伊朗和朝鲜列为美国网络安全的主要威胁，指出中国运营商进行的知识产权盗窃以及俄罗斯演员进行的干预选举损害了公众对美国选举完整性的信任。

  

该报告将重点放在选举安全以及其他国家如何通过黑客手段和虚假信息操纵选举上。

  

金和加拉格尔在报告中指出：“如果我们没有正确的选举安全权，威慑将会失败，子孙后代将怀着渴望和遗憾地回顾这个曾经强大的美国共和国，并想知道我们如何把整个事情搞砸了。”

  

**分层威慑**

该报告的主要发现之一是，美国政府目前处于劣势，无法以所需的速度和敏捷度采取行动，以确保自己免受快速发展的网络威胁的侵害。报告称，该国正因“过时的规则，法律和法规的迷宫，限制了美国捍卫网络空间的能力”而感到沮丧。

  

报告呼吁公共部门和私营部门之间进行合作，该报告说：“美国现在在网络环境中运作，要求数据安全性，弹性和可信赖性水平，目前美国政府和私营部门都没有能力独自提供这些数据。”

  

**关键零件**

该报告概述了分层网络防御的三个关键组成部分：

  

*   **塑造行为：**美国需要建立合作伙伴和盟友联盟，并与他们合作以确保其对网络空间的兴趣。
    
*   **剥夺利益：**需要公共部门和私营部门之间的合作，以增强国家的抵御能力，并剥夺对手的利益。
    
*   **施加成本：**美国必须有能力报复威胁者，以制止未来的恶意行为。

该报告呼吁采取主动防御网络威胁的“防御向前”战略。报告称：“这种态势向敌人发出信号，美国政府将对网络攻击作出反应，即使是那些没有造成人身破坏或死亡的武装冲突程度以下的网络攻击，也要使用所有工具并符合国际法。”

  

**超过75条建议**

该委员会的报告提供了超过75条建议，这些建议分为六个主要组或“支柱”。这些包括：

  

1.  改革美国政府的网络空间结构和组织：该报告要求更新美国的国家网络战略；众议院和参议院新设立的网络安全常设security选委员会；一位经参议院确认的国家网络总监，他将就网络安全相关问题以及领导政策和策略向总统提供建议；招聘和发展更好的网络人才；以及美国国土安全部下的美国网络安全和基础设施安全局的加强。
    
      
    
2.  使用非军事手段执行网络规范：委员会建议建立一个盟国联盟，这些盟国将通过使用非军事工具（例如执法行动，制裁，外交和信息共享）来帮助美国实施当前的网络规范。该报告还建议国会建立一个助理国务卿职位来履行这一职责。
    
      
    
3.  增强国家抵御能力：报告指出，美国需要做好准备，以迅速应对袭击并从袭击中恢复。因此，委员会建议国会确保向CISA和其他机构提供资金，以确保快速恢复。
    
      
    
4.  重塑网络生态系统：报告得出结论，联邦政府必须探索立法，法规和行政措施以及在各个领域的投资。它还建议创建一个针对云安全和网络保险等网络产品的认证机构，并建议建立一项法律，规定这些产品的制造商应对利用已知或未修补漏洞的事件负责。该报告还呼吁制定国家数据安全和隐私保护法以及网络统计局，以指导进一步的决策。
    
      
    
5.  与私营部门实施网络安全协作：该报告称，联邦政府必须通过建立更具协作性的环境并确保重要的关键基础设施始终由美国政府支持来帮助私营部门进行网络安全工作。
    
      
    
6.  消除武器漏洞：最后，联邦政府，特别是军方，必须采取更多措施消除漏洞，包括可能损害武器系统或核控制系统的漏洞。
    

  

**下一步是什么？**

报告发布后，金在推特上说，美国需要在联邦一级采用更简化的网络安全方法。

  

*国会应建立众议院常设Select选委员会和参议院Select选委员会。目前，网络责任在各个委员会中得到了分散，这为进步有时造成了无法克服的障碍。我们不能让国会官僚主义阻碍必要的行动。*

*\-参议员安格斯·金（@SenAngusKing）2020年3月11日*  

  

众议院国土安全委员会网络小组的排名第一的共和党众议员约翰·卡特科（RN.Y.）告诉希尔，该报告及其建议将随后举行听证会和新立法。
