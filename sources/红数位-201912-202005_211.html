本周三，我们发布了

微软泄漏SMBv3 CVE-2020-0796漏洞信息，但本月未释放补丁修补


3月12日，也就是本周四，微软正式发布漏洞通告和相关补丁，红数位建议用户尽快进行修复。


这个漏洞被评为“  Critical”高危级别，攻击者利用该漏洞无须权限即可实现远程代码执行，受黑客攻击的目标系统只需开机在线即可能被入侵。


这个漏洞会影响目前主流的Win10版本，具体如下：


  • Windows 10 Version 1903 for 32-bit Systems

  • Windows 10 Version 1903 for x64-based Systems

  • Windows 10 Version 1903 for ARM64-based Systems

  • Windows Server, Version 1903 (Server Core installation)

  • Windows 10 Version 1909 for 32-bit Systems

  • Windows 10 Version 1909 for x64-based Systems

  • Windows 10 Version 1909 for ARM64-based Systems

  • Windows Server, Version 1909 (Server Core installation)


微软昨天夜里单独发布了KB4551762安全更新，以修补在Microsoft服务器消息块3.1.1（SMBv3）中发现的预身份验证RCE Windows 10漏洞，这是关于该漏洞的详细信息作为2020年3月补丁星期二泄露的一部分，在3月周二补丁发布两天后。


微软Server Message Block 3.0（SMBv3）协议的内存破坏漏洞，编号CVE-2020-0796，并表示该漏洞无需授权验证即可被远程利用，可能形成蠕虫级漏洞。


你可以通过Windows Update检查更新或通过从Microsoft Update目录手动下载Windows版本来安装KB4551762 。


微软表示：“虽然我们没有发现利用此漏洞的攻击，但我们建议您将此更新优先其他更新应用于受影响的设备。”


该漏洞被称为SMBGhost或EternalDarkness，仅影响运行Windows 10版本1903和1909以及Windows Server Server Core安装版本1903和1909的设备。


微软解释说  ，此漏洞仅存在于Windows 10版本1903中添加的一项新功能中，并且旧版本的Windows不提供对SMBv3.1.1压缩的支持，该功能是此bug的功能。


已确认Microsoft通过Windows Update将KB4551762 OOB安全更新推送到受影响的系统


SMBv3 RCE漏洞

只有在Microsoft Active Protections计划的安全供应商的一部分可以早日访问该漏洞的详细信息的安全供应商在2020年3月的补丁程序星期二发布信息之后，Microsoft才共享CVE-2020-0796  的详细信息。


当时，Microsoft发布了  一份通报，其中包含有关泄漏的漏洞和缓解措施的更多信息，该漏洞和缓解措施旨在在出现可感染的经过身份验证的RCE漏洞影响SMBv3的消息后，阻止潜在的攻击。


该公告写道：“ Microsoft通过Microsoft Server Message Block 3.1.1（SMBv3）协议处理某些请求的方式意识到了远程执行代码漏洞。” “成功利用此漏洞的攻击者可以获得在目标SMB服务器或SMB客户端上执行代码的能力。”


“要利用此漏洞针对SMB服务器，未经身份验证的攻击者可以向目标SMBv3服务器发送特制数据包。要针对SMB客户端利用此漏洞，未经身份验证的攻击者需要配置恶意的SMBv3服务器，并诱使用户连接到它。”


研究人员演示的DoS和LPE概念验证

网络安全公司Kryptos Logic的研究人员发现了48,000台Windows 10主机容易受到针对CVE-2020-0796漏洞的攻击，并分享了由安全研究员Marcus Hutchins创建的拒绝服务概念验证漏洞的演示视频。


SophosLabs的Offensive Research团队还开发并共享了一个本地特权升级概念证明漏洞利用的视频演示，该  漏洞使具有低级特权的攻击者可以获得系统级特权。

Kryptos Logic表示：“即使不存在要分析的补丁程序，也很难发现SMB错误，”恶意行为者可能也接近于为CVE-2020-0796开发自己的漏洞。


对于暂时无法应用此安全更新的管理员，Microsoft提供了针对SMB服务器的缓解措施，并建议使用此PowerShell命令禁用SMBv3压缩（无需重新启动，不会阻止SMB客户端的利用）：


Set-ItemProperty -Path 

"HKLM:\SYSTEM\CurrentControlSet\Services\LanmanServer\Parameters" DisableCompression -Type DWORD -Value 1 -Force


还建议企业客户在企业外围防火墙处阻止TCP端口445，以防止试图利用此漏洞的SMB服务器受到攻击。


尽管到目前为止尚未检测到针对易受攻击的Windows 10系统的恶意扫描，但针对未打补丁的设备的攻击正在密切注意，因为已经开发出PoC漏洞并且易于分析该错误。
