# 国家支持黑客使用复杂的服务器防火墙绕过技术

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247487915&idx=7&sn=82e7132b55085fbc968c2ab3199a9b66&chksm=cef37c18f984f50e9ea436b5021658b30c2ef156b5a498f7c7012e33aa23672e1d11b4f7d7f9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247487915&idx=7&sn=82e7132b55085fbc968c2ab3199a9b66&chksm=cef37c18f984f50e9ea436b5021658b30c2ef156b5a498f7c7012e33aa23672e1d11b4f7d7f9&scene=27#wechat_redirect)

威胁参与者（可能是国家赞助的网络间谍组织）已使用一种先进的技术，使服务器上托管的恶意软件可以通过防火墙与命令和控制（C2）服务器进行通信。

  

![](../Images/c99f36179dbdd87ba70fab054da4826c.png)

  

该攻击被Sophos发现，该黑客将黑客使用的方法命名为“ Cloud Snooper”。该公司在调查AWS托管服务器上的恶意软件感染时遇到了该攻击，但表示该攻击可能对防火墙后的任何服务器（包括本地服务器）都有效。

  

在Sophos分析的攻击中，受感染的系统同时运行Windows和Linux EC2实例。尽管将AWS安全组配置为仅允许入站HTTP或HTTPS流量到达服务器，但遭到黑客攻击的Linux系统也接受了攻击者打开的TCP端口2080和2053上的连接。

  

目前尚不清楚攻击者如何植入该恶意软件，但研究人员认为他们可能已经通过对暴露的SSH端口的字典攻击来访问服务器。

  

黑客部署了rootkit，后者又安装了后门Trojan。攻击者可能利用后门从目标实体窃取敏感数据，并通过rootkit与C＆C服务器进行了通信。

  

研究人员确定了一个Windows系统和多个Linux主机上的后门。分析表明，Windows后门基于Gh0stRAT恶意软件。

  

为了绕过服务器的防火墙，攻击者将C2流量伪装为合法流量。这样可以确保防火墙不会阻止包含恶意软件说明的流量或包含发送回C2服务器的数据的流量。

  

“为了避开防火墙规则，攻击者通过在普通Web服务器端口上向Web服务器发送无害的请求来与rootkit通信。Sophos威胁研究经理Sergei Shevchenko 解释说，一个侦听器会在流入网络服务器之前对其进行检查，以拦截特制的请求，并根据这些请求的特征向恶意软件发送指令。

  

“侦听器向rootkit安装的后门特洛伊木马发送“重构的” C2命令。根据C2通信中包含的命令，攻击者可能会使用后门从目标窃取敏感数据。” “然后，收集的数据与C2流量一起传递回去。只有这一次，rootkit才必须再次伪装它，以便再次绕过\[防火墙\]。到达外部后，C2流量会将收集的数据传递回攻击者。”

  

云窥探者

  

尽管在这次攻击中观察到的个别技术并不是什么新鲜事物，但Sophos说这是它们首次以这种方式结合在一起。

  

舍甫琴科说：“攻击的复杂性和使用定制的APT（高级持久威胁）工具集使我们有理由相信，该恶意软件及其操作员是高级威胁参与者，可能是国家赞助的。”
