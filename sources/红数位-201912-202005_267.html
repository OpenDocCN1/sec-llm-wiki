Windows 10X是专门为双屏和可折叠设备提供动力而构建的，它首先是最主要针对UWP应用程序或许多人称为它的现代应用程序的操作系统。



这些应用程序可在Microsoft Store中找到，并由Microsoft在上线之前进行检查，因此从技术上讲，它们应该比您可以从各种来源在线下载的应用程序更安全。


但是，由于Microsoft Store尚未成熟，并且许多流行的应用程序尚未使用UWP版本进行更新，因此如果Windows 10X希望被视为Windows 10的完全替代者，则无法忽略Win32程序。


因此，Microsoft在Windows 10X中所做的就是引入了容器，这项技术使操作系统能够以安全地运行它们的方式来模拟Win32程序。



微软已经确认，尽管添加了容器，但并非所有Win32程序都可以在Windows 10X上运行，但该公司仍承诺提供最先进的体验。换句话说，Windows 10X将支持大多数程序，但是如果偶尔遇到一些无法使用的程序，您也不要感到惊讶。


因此，鉴于Windows 10X在容器中运行UWP应用程序和Win32程序，您仍然需要防病毒软件吗？


Windows 10X中的Windows安全性

这个问题尚未得到Microsoft的解答，并且Windows 10X的当前预览版表明不再需要传统的防病毒引擎。但是，安全工具仍将作为Windows安全性的一部分提供。


在Windows 10中，Windows安全中心是对所有安全功能进行分组的枢纽，包括父母控制，防火墙过滤器和Windows Defender防病毒引擎。另一方面，在Windows 10X中，Windows 10X附带了所有这些功能，但没有Windows Defender防病毒引擎，因此有可能无法提供。


或者，由于Windows 10X仍在开发中，因此Microsoft会在以后的时间中添加它，因为它将继续改进操作系统。


Windows Defender已发展成为一种超级高级的安全产品，其检测率和性能指标已经与世界领先供应商的第三方安全解决方案相匹配。在Windows 10中，默认情况下启用Windows Defender，这是许多用户为了保护其设备而进行的选择。



无论Microsoft是否在Windows 10X中启用防病毒保护，很明显，此双屏操作系统将比台式机上当前的Windows 10版本更加安全。这完全归功于应用程序的加载方式，因为从技术上讲，此新系统将阻止网络罪犯为了感染设备而使用的主要方法之一：部署在易受攻击的主机上的恶意可执行文件。


但这并不一定意味着Windows 10X无论如何都会保护用户。用户仍将面临不涉及损害设备（包括网络钓鱼）的常见威胁，以及可能被Windows安全性阻止的其他威胁。这可能是Windows Defender仍然存在的原因。


当然，很多事情可能在一夜之间发生变化，随着操作系统的进一步完善，我们将在未来几周内进一步了解Windows 10X处理安全性的方式。Windows 10X还将为微软自己的Surface Neo提供动力，Surface Neo是双屏设备，有望引领这一新产品类别，但微软表示，无论如何，我们应该期待合作伙伴会大量涌入类似机型。
