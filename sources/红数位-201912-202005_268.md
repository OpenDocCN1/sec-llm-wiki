# 1月14日后 Windows 7仍可曲线接收到安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247487844&idx=3&sn=b3e88bc92862ffc1b27d72d6e8f034f9&chksm=cef37cd7f984f5c1de42082e1e405eb13a1be34fb4f7f9ef5f77a56210d216d4427b8fd46be3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247487844&idx=3&sn=b3e88bc92862ffc1b27d72d6e8f034f9&chksm=cef37cd7f984f5c1de42082e1e405eb13a1be34fb4f7f9ef5f77a56210d216d4427b8fd46be3&scene=27#wechat_redirect)

尽管微软已经在 2020 年 1 月 14 日终止了面向公众用户的 Windows 7 技术支持，但企事业单位那里的存量用户仍然不少，且微软有在提供付费的扩展安全更新（ESU）计划。因此从理论上来说，大家还是可以通过一些特殊的技术手段，继续接收来自微软的后续安全更新的。

  

![](../Images/43342f950fc31bd297d285fdc2e757ff.png)

  

  

如果遵从微软的建议，过期后的 Windows 7 用户应该升级到 Windows 8.1 / Windows 10 操作系统，以继续获得微软提供的功能更新和安全保障。

  

但正如当年 Windows XP 终止支持那样，Windows 7 旧设备的基数太过庞大，很多人并不愿升级到更现代的操作系统。此时如果还想继续接收扩展安全更新，该如何操作呢？

  

***据悉，在 Windows 7 终止支持后的第一年，企业可支付 25 美元的单价，为每一台运行 Windows 7 操作系统的旧设备获得扩展安全更新（ESU）。***

  

***第二年的价格翻倍（50 美元），第三年继续增加到 100 美元 ……***

  

这样的增值收费模式，显然不适用于家庭用户，因为官方并未提供任何选择来继续安全地运行 Windows 7 。

  

庆幸的是，网络上有人在教授绕过限制的方法，让任何 Windows 7 设备都可以接触到微软的 ESU 项目。

  

***事实证明，2020 年 2 月的补丁星期二，将迎来破解工作的一个里程碑。******通过技术手段，系统依然可以正常工作，所有更新都可在设备上进行。***

  

***换言之，相关更新仍会正常显示在 Windows Update 上，让用户可以像截止日期（1 月 14 日）前那样修复已知的漏洞。***

  

当然，不排除微软在将来的某个时候封堵这项破解工作。至于事件会如何发展，还请耐心等待 2020 年 3 月份的星期二补丁（3 月 10 日发布）。
