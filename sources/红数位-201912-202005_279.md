# 微软“最后第2个补丁”再出BUG，部分Win7用户遭遇无法关机重启问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247487802&idx=2&sn=4ad88e06ad6a626a996d00860132fccc&chksm=cef37c89f984f59f60c2c7a917396dd53e531f5c2a4dfe4e9178558f3147056414f1209fd4cf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247487802&idx=2&sn=4ad88e06ad6a626a996d00860132fccc&chksm=cef37c89f984f59f60c2c7a917396dd53e531f5c2a4dfe4e9178558f3147056414f1209fd4cf&scene=27#wechat_redirect)

微软于2月8日如约发布了 KB4539602 更新，以修复上月的"Windows7最后一个累积更新"导致的桌面壁纸变黑问题。

  

作为一个可选更新，KB4539602 仅包含了与壁纸相关的 bug 修复（拉伸导致显示黑色壁纸的问题）。遭遇该问题的 Windows 7 SP1 和 Server 2008 R2 SP1 用户，可在‘控制面板’中手动检查 Windows Update 并安装。

  

如果没有网络连接，亦可通过官网链接下载 KB4539605（含 32 / 64-bit 版本）：

  

http://www.catalog.update.microsoft.com/Search.aspx?q=KB4539602

  

在应用该修补程序之前，微软建议用户先确保已安装 SHA-2（KB4474419）和 SSU 服务堆栈（KB4490628）更新。

  

如果实在不想安装 KB4539605 壁纸修复程序，亦可选择“填充”、“适应”等显示模式。

  

**殊不知新BUG出现！**  

  

继微软为解决拉伸壁纸造成的黑屏问题推送KB4539602后，关于电脑无法关机的抱怨也开始在网上出现。

  

部分Win7用户遭遇无法关机重启问题：附解决办法

  

![](../Images/1ec57838d58dd56453d243e912da4ffe.png)

  

**具体来说，一些Win7用户试图从开始菜单关机或者重启时，遭遇了报错提示“You don't have permission to shut down this computer（你没有关机权限）”。**

  

**目前大家探索出了两套解决办法，****一是创建一个新管理员账户，登陆后再切换到原管理员账户，关机和重启就正常了。**

  

**另一个解决办法繁琐但一劳永逸，****运行组策略（gpedit.msc），进入计算机配置-Windows设置-安全设置-本地策略-安全选项，搜索“User Account Control: Run all administrators in Admin Approval Mode（用户账户控制）”并双击，将该策略启用。**
