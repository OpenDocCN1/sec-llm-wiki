全球1/5公司仍未能修复Citrix软件漏洞，内部网络一分钟内可访问

在积极技术公司发布了有关 Citrix软件的一个严重漏洞的概述之后的一个半月，该漏洞正在威胁158个国家的80,000家公司，五分之一的公司仍未采取任何措施来修复此漏洞。这可以从Positive Technologies的威胁情报中看出。


参考：

Citrix严重缺陷可能使158个国家8万家公司遭受攻击


积极技术专家Mikhail Klyuchnikov于12月发现了Citrix应用交付控制器（NetScaler ADC）1和Citrix Gateway（NetScaler Gateway）中的严重漏洞 CVE- 2019-19781。根据截至2019年底的 Positive Technologies数据，最大数量的潜在脆弱组织位于美国（占所有脆弱组织的38％以上），以及德国，英国，荷兰和澳大利亚。2020年1月8日，漏洞被释放。它允许潜在的攻击者对未能修复漏洞的公司进行自动攻击。



“ Citrix开发人员计划在1月27日至1月31日解决此问题，但在此之前一周发布了针对各种产品版本的一系列补丁。必须尽快安装必要的更新。在此之前，请遵循以下安全建议：思杰，自该漏洞的信息发布以来就可用。” PT专家安全中心主任Alexei Novikov说道。


总体而言，该漏洞正在快速修复，但是仍有19％的公司处于风险之中。当前易受攻击公司数量最多的国家包括巴西（最初检测到该漏洞的所有公司中的43％），中国（39％），俄罗斯（35％），法国（34％），意大利（33％），和西班牙（25％）。美国，英国和澳大利亚正在更快地保护自己，但他们中仍有21％的公司仍在使用易受攻击的设备而没有采取任何保护措施。


再次，如果利用了此漏洞，攻击者便可以从Internet直接访问公司的本地网络。此攻击不需要访问任何帐户，因此可以由任何外部攻击者执行。


为了抵御潜在的攻击，公司可以使用Web应用程序防火墙。例如，PT应用程序防火墙可以立即检测到此攻击。必须将系统设置为阻止所有危险请求，以确保实时保护。考虑到该漏洞已经存在多长时间了（自该软件的第一个漏洞版本于2014年发布以来），追溯检测该漏洞的潜在利用（并因此危害基础设施的危害）也同样重要。从2019年12月18日开始，PT Network Attack Discovery用户可以使用特殊规则来检测尝试在线利用此漏洞的尝试。

问题描述


在以前称为NetScaler ADC的Citrix应用程序交付控制器（ADC）和以前称为NetScaler Gateway的Citrix Gateway中，已发现一个漏洞，如果利用该漏洞，则可能允许未经身份验证的攻击者执行任意代码执行。


此漏洞的范围包括在Citrix Hypervisor（以前称为XenServer），ESX，Hyper-V，KVM，Azure，AWS，GCP或Citrix ADC服务交付设备（SDX）上托管的Citrix ADC和Citrix Gateway虚拟设备（VPX）。 ）。


Citrix的进一步调查显示，此问题还影响Citrix SD-WAN的某些部署，尤其是Citrix SD-WAN WANOP版本。Citrix SD-WAN WANOP版本将Citrix ADC打包为负载平衡器，从而导致受影响的状态。


已为漏洞分配了以下CVE编号：


•CVE-2019-19781：Citrix Application Delivery Controller，Citrix Gateway和Citrix SD-WAN WANOP设备中的漏洞导致任意代码执行


该漏洞影响所有受支持平台上的以下受支持产品版本：


•Citrix ADC和Citrix Gateway版本13.0在13.0.47.24之前均支持所有版本


•12.1.55.18之前的所有版本均支持NetScaler ADC和NetScaler Gateway版本12.1


•12.0.63.13之前的所有版本均支持NetScaler ADC和NetScaler Gateway版本12.0


•11.1.63.15之前的所有版本均支持NetScaler ADC和NetScaler Gateway版本11.1


•10.5.70.12之前的所有版本均支持NetScaler ADC和NetScaler Gateway版本10.5


•型号为4000-WO，4100-WO，5000-WO和5100-WO的Citrix SD-WAN WANOP设备的所有受支持软件版本均在10.2.6b和11.0.3b之前构建


客户应该做什么

在野外已经观察到此问题在未经缓解的设备上的利用。Citrix强烈建议受影响的客户立即升级到固定版本，或者应用提供的缓解措施，该缓解措施同样适用于Citrix ADC，Citrix Gateway和Citrix SD-WAN WANOP部署。选择立即应用缓解措施的客户应尽快将所有易受攻击的设备升级到设备的固定版本。订阅https://support.citrix.com/user/alerts上的公告警报， 以在新修补程序可用时得到通知。


以下知识库文章包含在系统已更新到固定版本之前部署响应者策略以缓解临时问题的步骤：CTX267679-CVE-2019-19781的缓解步骤


应用缓解步骤后，客户可以使用此处发布的工具来验证正确性：CTX269180-CVE-2019-19781 –验证工具


在Citrix ADC和Citrix Gateway版本“ 12.1 build 50.28”中，存在一个问题，该问题影响响应者和重写策略，导致它们不处理与策略规则匹配的数据包。在“ 12.1 build 50.28 / 31”中解决了此问题，此后，如果应用了缓解措施，则该步骤将有效。但是，Citrix建议使用这些内部版本的客户现在更新为``12.1内部版本55.18''或更高版本，该版本已解决了CVE-2019-19781问题。


希望将更新推迟到“ 12.1内部版本55.18”或更高版本的“ 12.1内部版本50.28”的客户应从以下两个选项中选择一个，以使缓解步骤按预期运行：


1.更新到刷新的“ 12.1 build 50.28 / 50.31”或更高版本，并应用缓解步骤，或者


2.按照CTX267679中的说明，采用缓解措施来保护管理界面。这不仅可以缓解管理接口上的攻击，还可以缓解所有接口（包括网关和AAA虚拟IP）上的攻击


已在所有受支持的Citrix ADC和Citrix Gateway版本中发布了固定版本。还为适用的设备型号发布了Citrix SD-WAN WANOP的固定版本。Citrix强烈建议客户尽早安装这些更新。可以从https://www.citrix.com/downloads/citrix-adc/  和  https://www.citrix.com/downloads/citrix-gateway/  和  https://www.citrix.com下载固定版本。/ downloads / citrix-sd-wan /


升级到固定版本的客户不需要保留CTX267679中描述的缓解措施。
