# Ragnarok勒索软件针对Citrix ADC，作者将中国排除在外

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247487745&idx=2&sn=67988f0ef07ed2c10f21ac1b9980d5dc&chksm=cef37cb2f984f5a4483797a9da5cd6b3c97853d14f6a5b51adf9f61338e15da25d230e59b653&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247487745&idx=2&sn=67988f0ef07ed2c10f21ac1b9980d5dc&chksm=cef37cb2f984f5a4483797a9da5cd6b3c97853d14f6a5b51adf9f61338e15da25d230e59b653&scene=27#wechat_redirect)

**已检测到一种名为Ragnarok的新勒索软件，用于针对容易受到CVE-2019-19781攻击的未修补Citrix ADC服务器的定向攻击。**

  

  

![](../Images/e1f88367e3957e2dc8243d784b55fbfc.png)

上周，FireEye的发布了有关新的攻击利用了现在修补的报告思杰ADC漏洞来  安装新**仙境传说勒索**脆弱的网络。

  

当攻击者可以破坏Citrix ADC设备时，将下载并执行各种脚本，以扫描容易受到EternalBlue漏洞攻击的Windows计算机。

  

如果检测到，脚本将尝试利用Windows设备，如果成功，则注入DLL，该DLL将Ragnarok勒索软件下载并安装到被利用的设备上。

  

在SentinelLabs负责人  Vitali Kremez 提取了勒索软件的配置文件之后，我们能够发现一些其他勒索软件中不常见的有趣行为，我们将在下面详细介绍。

  

**排除俄罗斯和中国的加密**

许多勒索软件操作是由来自俄罗斯或其他独联体国家的开发人员创建的。

  

为了逃避当局的监视，勒索软件开发人员通常会阻止俄罗斯和其他前苏联国家的用户被感染后再进行加密。

  

仙境传说通过检查已安装的Windows语言ID进行类似的操作，如果它与以下之一匹配，则不会对计算机进行加密。

  

0419 = Russia 

0423 = Belarus

0444 = Russia

0442 = Turkmenistan

0422 = Ukraine

0426 = Latvia

043f = Kazakhstan

042c = Azerbaijan

  

奇怪的是，除了独联体国家外，仙境传说还将**避免对安装有中国0804语言ID的受害者进行加密。**

  

**同时将俄罗斯和中国都排除在外的勒索软件很少见**，因此尚不知道这是否是执法的诱饵或勒索软件在两个国家/地区之外都可以使用。

  

**尝试禁用Windows Defender**

随着Microsoft的Windows Defender成为可靠，可靠的防病毒和安全程序，我们发现许多恶意软件程序都试图禁用或绕过该程序，以更轻松地进行恶意操作。

  

例如，我们已经看到GootKit，TrickBot和Novter感染都利用某种Windows Defender绕过技术。

  

但是，很少看到勒索软件感染本身试图禁用Windows Defender的功能，这是Ragnarok尝试的。

  

它通过添加以下Windows组策略来禁用Windows Defender中的各种保护选项来实现此目的：

  

HKLM\\SOFTWARE\\Policies\\Microsoft\\Windows Defender "DisableAntiSpyware" = 1

HKLM\\SOFTWARE\\Policies\\Microsoft\\Windows Defender\\Real-Time Protection "DisableRealtimeMonitoring" = 1

HKLM\\SOFTWARE\\Policies\\Microsoft\\Windows Defender\\Real-Time Protection "DisableBehaviorMonitoring" = 1

HKLM\\SOFTWARE\\Policies\\Microsoft\\Windows Defender\\Real-Time Protection "DisableOnAccessProtection" = 1

  

好消息是，如果您启用了Windows 10的防篡改功能，则这些方法将不起作用，Windows只会忽略任何绕过Windows Defender的尝试。

  

除了Windows Defender之外，Ragnarok还将尝试使用以下命令清除卷影副本，禁用Windows自动启动修复并关闭Windows防火墙：

  

cmd.exe /c vssadmin delete shadows /all /quiet

cmd.exe /c bcdedit /set {current} bootstatuspolicy ignoreallfailures

cmd.exe /c bcdedit /set {current} recoveryenabled no

cmd.exe /c netsh advfirewall set allprofiles state off

  

**奇怪的Unix文件参考**

该勒索软件的另一个奇怪方面是Windows可执行文件中对各种Unix / Linux文件路径的大量引用，例如：

  

    "no\_name4": "/proc",

    "no\_name5": "/proc/%s/status",

    "no\_name8": "/tmp/crypt.txt",

    "no\_name9": "/proc/%s",

    "rand\_path": "/dev/random",

    "home\_path": "/home/",

  

目前尚不清楚为什么包括这些路径以及它们的用途，但Kremez认为，攻击者可能会使用正在开发中的跨平台目标。

  

“我相信“ no\_name5”：“ / proc /％s / status”专门表明参与者正在通过Unix命令“ / proc / \[proccess\_id\] / status检查系统上是否正在运行恶意软件。”鉴于Citrix被利用了跨平台，并且可能同时在Unix和Windows系统上运行。此特定的“ no\_name”设置允许跨平台定位并考虑Windows和Unix系统。在开发中；但是，鉴于此配置设置会影响更多系统，Ragnarok背后的犯罪分子似乎尽可能模块化和自适应。”

  

**标准加密程序**

Ragnarok加密过程的其余部分类似于我们在其他勒索软件感染中看到的过程。

  

加密文件时，它将使用AES加密，并且生成的密钥将使用捆绑的RSA加密密钥进行加密。这使得只有勒索软件开发人员才能解密受害者的加密密钥。

  

扫描要加密的文件时，Ragnarok将跳过所有扩展名为“ .exe”，“。dll”，“。sys”和“ .ragnarok”的文件。它还将跳过路径包含以下字符串的所有文件：

  

content.ie5

\\temporary internet files

\\local settings\\temp

\\appdata\\local\\temp

\\program files

\\windows

\\programdata

$

  

每个加密文件将在文件名后附加.ragnarok扩展名。例如，1.doc将被加密并重命名为1.doc.ragnarok。

  

![](../Images/a6238bfba5e0922960a1175ac8a2ea54.png)

文件夹由Ragnarok加密  

  

加密计算机时，它将在每个遍历的文件夹!! ReadMe\_To\_Decrypt\_My\_Files.txt中创建一个赎金记录。

  

该赎金文档包含有关受害者文件发生了什么情况的说明，他们的加密解密密钥以及三个用于联系付款说明的电子邮件地址。不知道攻击者需要多少个比特币来解密。

  

![](../Images/7a93ba9018a972b6cd615fb84d65ac0a.png)

仙境传说勒索赎金文档

  

目前看来，Ragnarok的加密无法破解，但安全人员将会针对任何弱点进行进一步研究。
