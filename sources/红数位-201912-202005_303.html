微软表示将免费向所有Windows 7用户再发一次补丁

Windows 7再见！微软发布7最后一个补丁并全屏推送Windows 10升级警告


一些安装KB4534310（补丁细节见上面链接）更新的Windows 7用户发现他们的桌面变黑了。


微软表示，由于该操作系统的寿命已尽，该公司只会向付费使用Windows 7扩展安全更新（ESU）的组织提供修复程序。


此举无疑激怒了无数的Windows 7 用户。



终于，微软现在改变了主意。


现在，它说它将为所有Windows 7用户提供一个补丁，以解决最后一次免费提供的Windows 7更新补丁带来的错误。


微软承认：“安装KB4534310后，将桌面墙纸设置为“拉伸”时可能显示为黑色。” 它似乎只影响拉伸的墙纸，并且“适合”，“填充”，“平铺”或“居中”选项仍适用于Windows 7用户。


这是一个令人尴尬的错误，正如Microsoft本应停止支持Windows 7一样引入的。这也给Microsoft带来了一个难题，即引入了一个显而易见的bug，客户必须为修复该bug而付费。


尽管微软最初表示正在开发Windows 7修复程序，但该修复程序仅适用于“已购买Windows 7扩展安全更新（ESU）的组织”，但微软一夜之间改变了主意，现在表示该修复程序将对所有人开放。运行Windows 7和Windows Server 2008 R2 SP1。奇怪的是，这意味着微软必须扩展其对Windows 7的支持，以修复它所引入的错误。


正如前几天报道的那样，Microsoft已经建议了解决黑色桌面问题的一些解决方法。该公司表示，正在研究下个月发布的修复程序：“我们正在制定解决方案，并估计对于购买Windows 7扩展安全更新（ESU）的组织，该解决方案将在2月中推出。” 。


目前尚不清楚是什么原因使微软改变了主意，但不仅仅是提供给现在将收到此修复程序的Windows 7用户。


现在，KB453431更新的已知问题页面显示为（强调我们的）：


我们正在制定解决方案，并将在即将发布的版本中提供更新，该更新将发布给所有运行Windows 7和Windows Server 2008 R2 SP1的客户。


在这样的回溯中，Microsoft对规则进行了一些更改。该公司曾表示，不会为非付费Windows 7用户提供针对最近发现的Internet Explorer漏洞的补丁，而让0patch之类的漏洞介入并提供帮助。但是，由于微软在解决黑色桌面问题上表现出了柔和的态度，因此该公司在处理更严重的安全问题上将有希望，期望和压力，但这无疑会使任何为Windows 7扩展安全更新付费的人感到恼火。
