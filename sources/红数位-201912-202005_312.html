1月14日，微软正式停止对Windows 7系统的更新维护服务。未来，Windows 7系统还可以继续使用，但微软不会再对Windows 7有相关的技术支持、软件更新或程序修正。


WINDOWS 7 最后一个补丁！


微软本月同时发放了Windows 7最后一个官方补丁。


这个“终极补丁”仍然分为两个版本，一个是包含安全与非安全升级的月度累积KB4534310，另一个是仅限安全更新的KB4534314。

https://support.microsoft.com/en-us/help/4534310/windows-7-update-kb4534310

https://support.microsoft.com/en-us/help/4534310/windows-7-update-kb4534310


不过，两个补丁的更新内容几乎完全一致，并无Bug修复或者功能升级，都是安全方面的，涉及脚本引擎、输入法、存储和文件系统、服务器等组件。


同时微软强调，新补丁暂无已知问题，可以放心升级。


Windows 7 Starter初级版、Windows 7 Home Basic家庭基础版、Windows 7 Home Premium家庭高级版、Windows 7 Professional专业版、Windows 7 Ultimate旗舰版，都可以安装上述补丁。


从此以后，Windows 7将不会再得到来自微软的任何安全、非安全补丁更新。或许，除非出现勒索病毒那样的高危紧急安全事件。


WINDOWS 7 再见！你好，弹窗！

当用户今天开始登录Windows 7时，如果看到全屏警报告诉他们不再支持该操作系统，容易受到病毒感染，并且应该升级到Windows 10来修复所有问题，则不要感到惊讶。



前天，2020年1月14日，Windows 7正式终止使用，这意味着它将不再受支持，将无法再获得免费的安全更新和错误修复。


为了警告用户并同时推广Windows 10，Microsoft在12月Windows 7  KB4530734月度汇总中安装了一个名为EOSNotify的程序。


从那时起，每当Windows 7用户每天中午登录其计算机时，都会启动计划任务，该任务启动％windir％\ system32 \ EOSNotify.exe程序。


该日期到2020年1月15日之后，该程序不再处于休眠状态，而是开始在全球所有Windows 7机器上显示全屏警报，该警报将覆盖整个屏幕，包括笔记本和台式机。当警报显示在屏幕上时，您将在监视器上看到的全部内容如下所示。


Windows 7生命周期终止警报


对于没有时间阅读的用户，他们可以单击“ 稍后提醒我”按钮以关闭警报，并在以后开机再次显示它。


如果用户不再希望再次看到此警报，则可以单击“ 不再提醒我 ”按钮。


对于尚未显示此警报的用户，他们可以配置以下注册表项，以防止它再次显示在屏幕上。


[HKEY_CURRENT_USER \ Software \ Microsoft \ Windows \ CurrentVersion \ EOSNotify]

“ DiscontinueEOS” = dword：00000001

 

对于那些想要有关此警报如何工作的更多技术信息的人，您可以阅读我们在EOSNotify应用程序上的原始报告。


尽管此警报令人讨厌且具有侵入性，但显示它以让所有人都知道他们的系统将不再受到充分保护是很有意义的。


这样一来，他们就可以决定是否要升级到Windows 10，目前仍然是免费的，当然你也可以切换到Mac，甚至可以尝试使用Linux及其Windows 7主题做出明智的决定。


转战LINUX


Win7正式退役，一些人选择继续坚守，一些人选择升级Win10，还有一些人，则另辟蹊径，转投Linux阵营。


Ubuntu背后的Canonical，就派出硬件组的产品经理Rhys Davies，游说那些Win7用户可以安装Ubuntu系统。这位经理表示，Win7换装Ubuntu无需硬件升级，常用的Chrome浏览器、Spotify、Blender、Skype等都有对应版本，用户可无缝切换。


不仅如此，韩国的一些致力于编译Linux发行版的公司们，也加大了宣传力度。


TMaxOS背后的Tmax公司称，Win7退役这两天，自家系统的下载量明显增加。


事实上，早在Win7停更前，这些系统厂商就开始游说韩国的政府部门、科学组织、教育机构等，力劝他们切换到成本更低的Linux发行版。目前，TMaxOS已经在韩国邮政、基础设施促进委员会等机构部署；Gureum OS则覆盖韩国海洋技术研究所、海军学院等；HamoniKR也走入不少高校甚至国防部。
