# 手机圈炸了！碰瓷界王者加入小米集团，江湖再起一波腥风血雨...

今天上午，雷军在微博上发了条消息，宣布**常程正式加入小米集团。**  

  

![](../Images/5fbfdb223d75a6d06cd63044d0c47ab3.png)

  

消息一出，许多吃瓜群众都兴冲冲，认为今后手机圈要热闹了。  

  

那么常程是何许人也呢？不关注手机圈的人可能不大熟悉。  

  

**常程，前联想集团副总裁，主要负责联想的手机业务。**  

  

![](../Images/8a822e3448b9cde0eddc06737b2d7399.png)

  

**以“碰瓷”闻名整个手机圈，江湖人称“万瓷王”！**  

  

**那些年，被常程碰瓷过的手机厂商可绕地球一圈。**

  

从苹果到华为、小米一个不落...

  

iPhone发布前一天，发微博欢迎苹果加入四摄家族——

  

![](../Images/fd9cd3db0ce279f4ccc894ff04fce1af.png)

  

时有华为余承东在网上声称有吓人的技术（GPU TURBO），刚好小米8也即将发布。

  

联想是小米和华为一块碰瓷，在其官博发出了张图。上有斜放的数字8以及讽刺华为吓人技术的文案。

  

**“别害怕，吓人的东西都是联想出来！”**一语双关，不得不说，这文案还真有创意。

  

![](../Images/01755db1dca44a7f41d78df163488e28.png)

  

对于此次离开联想，常程曾回应称是**个人身体健康和家庭的缘故。**

  

可万万没想到，2天后就宣布加入小米...

  

是雷军的小米养人还是咋地？

  

![](../Images/28252696fe8ef4e7fd87a5087647dc05.png)![](../Images/7ad723b5d96daac2efce0aa6e89fc8bc.png)  

说好的顾家，怎么也变为梦想奋斗了？  

  

商人的嘴，骗人的鬼...  

  

![](../Images/d26c2838da0c12bc55622ac9a3754a86.png)

  

巧的是，常程2020年1月2日入职小米；

  

而小米的另一位副总裁、前金立的**卢伟冰**是在2019年1月2日宣布入职小米的，刚好间隔一周年。

  

这可能是一种宿命的安排吧，毕竟卢伟冰也是全年在微博和友商、网友对线。

  

![](../Images/5410946b75207fadfd3175a6ba108e9d.png)

  

曾因荣耀9X开倒车采用了10W充电，卢伟冰连续几天狂怼，分别用Redmi的百元机、千元机和旗舰机对标。

  

**后来江湖人送雅号“卢十瓦”，1卢等于10W。**

  

![](../Images/0d93ed390abf1abb1caf2f13125ea21a.png)

  

对此，雷军还曾转发调侃。  

  

![](../Images/cb6f99d5aa42424465c41bbd2e09abeb.png)

  

现在这两位手机圈的著名骂匠，一同加入小米，以后好戏可有得看了。

  

![](../Images/17382a53e6e31fe16073114164dd0e70.png)

  

有网友将雷军、常程、卢伟冰称为小米的**“电（雷）磁（常）炉（卢）”**组合。

  

![](../Images/fbd733015a9b0b14b82a5c250cd1d786.png)
