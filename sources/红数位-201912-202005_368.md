# 五角大楼希望将成群的人工智能无人机用于“营救”任务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247487486&idx=1&sn=448d94d5952c2829776ecb2469218951&chksm=cef3624df984eb5b7b61022e3a9cf78a4ef46de35dbd49aa33fe22776693309acf03d36198e6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247487486&idx=1&sn=448d94d5952c2829776ecb2469218951&chksm=cef3624df984eb5b7b61022e3a9cf78a4ef46de35dbd49aa33fe22776693309acf03d36198e6&scene=27#wechat_redirect)

五角大楼正在整合AI开发人员社区，以尝试构建能够识别和跟踪目标的自启动式AI无人机，这些无人机表面上可以进行搜索和救援，但有可能进行搜索和摧毁。

  

![](../Images/afef442eb55ffaa941c5932d2ffc2b38.png)

  

联合人工智能中心（JAIC）在12月下旬发布了一项请求（RFI），以寻求人工智能和无人机群技术的最新，最先进的方法-并寻求有关如何将两者结合的巧妙思路。该机构表示，由此产生的聪明人群体应该是自我指导的，能够自行发现和跟踪人类（RFI指定为“和人造物体 ”），能够流式传输其活动的视频，并愿意轻推其活动。当它锁定了一些有趣的东西时，他们（大多数时候不会在意，因为它主要是由AI驱动的）。蜂群将必须能够以至少50节（93 km / h）的速度移动，在空中停留至少2小时，并覆盖100平方海里（343平方公里）。

  

RFI解释说，“ 智能群 ” 的官方目的是搜索和救援，而JAIC计划包括四个“ 任务计划 ”，即“ 预测性维护，人道主义援助和救灾以及网络空间和机器人过程自动化。 ”

  

那么，第四位在哪里？RFI并未透露，但我们可以根据已知的JAIC进行推测。AI专家部门直到2018年才首次亮相，但最终运行了**Project Maven**，该计划旨在为机器学习和大数据提供武器，而在员工对帮助五角大楼杀死人的态度冷淡之后，Google拒绝了该倡议。

  

Maven项目不仅提高了战术无人机的视频输入质量，还提高了计算能力来组织通过监视获得的大量数据，还教会了参与者如何“ **使用战争算法** ”。 

  

能够以最小的外部方向（按照RFI中指定的路线）猎杀人类的智能群是否会遵循规则并坚持搜寻和营救，或者其AI会将其与“搜寻并摧毁”相混淆  ？如果五角大楼的人员无法从恐怖分子那里告诉平民，那么它的无人机群应该如何做到？即使算法运行良好，如何阻止负责人员使用他们的新玩具杀死动物呢？

  

JAIC与DARPA和五角大楼的其他秘密高级机构合作；如果美军研发出无人驾驶的杀手无人机群（他们已经有可以与人类向导协同工作的无人机群），那就在那里发生  。

  

在您认为“ 但他们不敢 ”之前，要起诉针对战争罪的AI算法（尤其是以开放源代码编写的AI算法）将非常困难。

  

![](../Images/a5d124e8b1c279a49c55beedacf19f51.png)

  

从前，我们看过这部电影。反乌托邦技术电视节目《黑镜》中的 “ 仇恨国家 ”一集中，一群无人驾驶的无人机“ 蜜蜂 ”在大规模灭绝后取代了真实事物。这种数字蜂巢证明是可入侵的，每天，都有一个单独的无人机刺客被武器杀死任何引起社会媒体最讨厌的公众人物。不管最后一秒的神风表演，蜜蜂都以如此缓慢的速度迷失，这意味着那些养蜂人不会介意。

  

《黑镜》中的养蜂大师通过夸大“ 军事级 ”加密技术来捍卫自己的创造力，坚持认为没人能破解他们的比自然界更好的高科技传粉者。到那时，已经有人了。 

  

军用级加密仅与故意安装的后门一样好，司法部长William Barr和整个“五眼”情报网络都打算安装足够的后门，以使它们在余生中忙于浏览您的私人数据。一旦这样做，每个人的无人机群（字面上和象征意义上的）就属于其他所有人。如果曾经有一段时间不急于制造世界末日技术，那现在才是开始。

**五角大楼的DARPA寻求手段传播转基因细菌作为“爆炸物传感器”**

  

五角大楼与雷神公司合作开发了一个系统，该系统能够将转基因细菌运送到地下。当然，仅出于防御目的。

  

![](../Images/ca0188f6d5e8d9c2f759b8318c7d6b25.png)

  

国防承包商雷神公司在与伍斯特公司联合发布的新闻稿中说，由DARPA发起—该机构领导了创建远程机动超级士兵和武器化机器人昆虫的计划—该项目旨在“对两种细菌菌株进行编程，**以监测地面的爆炸性材料。**”

  

两种菌株中的第一种被称为**“生物传感器”**，将**“检测掩埋在地下的炸药的存在与否”**，而第二种在发现这种物质的情况下会发出“发光的细菌”。然后，将远程操作的摄像机或无人机发送到该区域进行调查，以**发现发光的细菌，最后找到掩埋的炸药。**

  

雷神公司的研究员艾莉森·塔格特（Allison Taggart）说：“我们已经知道，**某些细菌可以被编程为非常擅长于探测爆炸物，因为地下却很难。**”

  

我们正在研究如何将报告细菌运送到所需的地下深度。

  

尽管据说该设备旨在检测外国战区内的简易爆炸装置，但塔格特并未掩盖细菌传递系统的“模块化设计”和内部可互换的“组件”将“按需”用于其他应用。

  

尽管五角大楼声称只打算将该系统用于“防御性”目的，但有些人可能会发现军事化微生物的想法令人反感-让人联想到失控的基因工程超级细菌的世界末日情景。
