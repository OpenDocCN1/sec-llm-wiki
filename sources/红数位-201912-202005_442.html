下一代防火墙是基于硬件或软件的网络安全产品，可识别和阻止传统防火墙技术以外的有组织的攻击。最近针对某些最大，看似最安全的网络环境的安全漏洞表明，需要使用下一代防火墙（NGFW）及其提供的额外保护。尽管传统的防火墙可以满足中小企业的基本安全需求，但NGFW的范围却超出了这些功能，为大型企业提供了新的改进功能。



在最终确定在其组织中实施NGFW的选择之前，公司应分析所有提供商。


下一代防火墙提供商可以使用的某些功能包括嵌入式深度数据包检查，网站过滤和入侵防御系统，以保护网络免受最新的复杂网络攻击。


该购买者指南探讨了NGFW，传统防火墙和UTM之间的区别，以及为您的组织选择正确的下一代防火墙的选择标准。该指南还通过NGFW产品比较以及主要NGFW供应商以及市场上的专业机构的深入综述，对该领域进行了广泛的研究。

下一代防火墙与传统和UTM的对比


了解保护企业网络免受攻击和入侵的下一代防火墙的优点，以及NGFW与传统防火墙之间的区别。


最近对某些很大看似最安全的网络环境的安全漏洞引发了一个问题：现有的保护机制是否足以阻止未经授权的人员访问关键资产？


尽管有些人认为传统的防火墙，防病毒软件和入侵防御系统（IPS）失去了用处，但实际上，这些安全技术仍在大量使用中-并且是必需的。但是，通常需要更全面，更有效，尤其是集成的产品来跟上威胁当今网络基础架构的产品。


那么你应该考虑下一代防火墙（NGFW）。


NGFW是集成的网络安全平台，包括嵌入式深层数据包检查防火墙，IPS，应用程序检查和控制，SSL / SSH检查，网站过滤以及服务质量（QoS）/带宽管理，以保护网络免受最新的复杂网络攻击和攻击入侵。


下一代防火墙与传统防火墙

与旨在阻止在OSI网络堆栈的第4层到第7层上发生的越来越多的应用程序攻击的NGFW不同，传统的数据包筛选防火墙仅在第3层（网络）和第4层（传输）提供保护。它们包括通过区分传入数据包的源IP地址，目标IP地址，数据包可能包含的Internet协议的类型（例如，正常的数据传输IP数据包以及本地链接网络发现协议）来允许和拒绝数据包的度量标准和路由功能。


尽管通常在公共Internet和DMZ内部的内部网络之间部署防火墙，但是攻击者已经找到了规避这些控件并在检测之前造成相当大破坏的方法。传统防火墙的范围有限，仍然需要其他安全控制措施来保护企业网络，包括入侵防御系统，Web应用程序防火墙，基于Open Web Application Security Project的十大漏洞的安全编码标准，Web层的强加密（ SSL /传输层安全性）以及防病毒和恶意软件防护。


至少可以说，必须部署，管理和监视数量庞大的网络安全产品以减轻多个异构攻击媒介的挑战。此外，安全产品之间无法预料的交互可能会损害某些产品的功能，但会占用宽带资源使用，响应时间，监视和维护要求。


NGFW可以通过为单个供应商的产品提供包含多个安全服务的通用管理流程来解决许多此类问题。在大多数情况下，它是一种更具成本效益且更加实用的网络安全方法。


NGFW不是UTM

统一威胁管理（UTM）系统是一种多合一的网络安全平台，旨在提供简单性，简化的安装和使用以及同时更新所有安全功能的能力。像NGFW一样，这些系统显然比获得各种网络安全技术具有主要优势，因为无需维护不同的安全产品并弄清它们如何协同工作。


UTM主要服务于中小型企业，而不是大型组织。另一方面，下一代防火墙的优点是它们通常更扩展，可以保护从SMB到大型企业的企业网络的安全。与UTM不同，NGFW可以集成威胁情报，一定程度的移动设备安全性，防止数据丢失，并使用开放的体系结构，该体系结构允许客户端使用正则表达式来定制应用程序控制甚至某些防火墙规则定义。


尽管如此，安全供应商在UTM和NGFW的定义上通常会有所不同，这就是为什么了解下一代防火墙与UTM之间的区别非常重要的原因。随着时间的流逝，UTM引用可能会消失（NGFW甚至可能会发生这种情况），但是可以肯定的是，多功能安全产品的增强功能将继续。


最佳NGFW功能指南

最佳的NGFW产品必须全面，灵活且易于使用。尽管这似乎是无法实现的组合，但对于NGFW供应商而言，实现这一三连胜是非常可行的。


首先，NGFW可能包括IPS，防病毒和恶意软件防护，应用程序控制，深度数据包检查和状态防火墙，加密，压缩，QoS和其他功能。NGFW需要克服的一个缺点是，许多企业不愿意依靠单点故障来进行许多不同的网络安全控制。


其次，NGFW必须具有灵活性，这也意味着可扩展性，以便可以根据需要对功能进行模块化和激活。


第三，NGFW应该提供全面的用户界面，无论是通过传统的命令行界面还是GUI仪表板，都可以提供对产品功能的明确定义的访问，并具有对功能激活，规则集定义，配置分析，漏洞的有据可查的访问权限评估，活动报告和警报。


如今的NGFW构成了网络安全产品的一支干部，这些产品据称可以提供这三个特征。尽管列出了NGFW服务具有通用名称的功能，包括数据丢失预防，应用程序控制和威胁情报，但仔细观察会发现NGFW供应商产品之间存在一些差异。



一些NGFW可以终止SSL /传输层安全性电路并执行URL过滤。它们还支持软件定义的广域网。


一些NGFW供应商提供移动设备安全性，但它们不是全面的移动设备管理（MDM）产品。这些NGFW可以识别移动设备和操作系统。根据应用，用户和内容提供策略执行；甚至扩展了VPN隧道以防止恶意软件，但它们不能提供MDM产品提供的全部设备管理。


客户应仔细审查单个NGFW产品的功能，以确定最适合他们的产品。例如，并非所有NGFW都提供两因素身份验证或移动设备安全性，但是，并非每个客户都需要这些功能。尽管有NGFW表示它们支持此类功能，但有些可能需要其他模块或产品才能使其正常工作。


如何购买NGFW

大多数NGFW是基于设备的，但是有些可以作为软件产品获得，企业可以将其安装在自己的服务器上，也可以作为SaaS通过云交付。大多数都是模块化的，使企业能够购买和激活与其特定需求和风险相称的功能。


但是，对于这些云产品是否提供与传统本地设备相同的保护，还是针对与企业使用云资源的方式相关的特定威胁提供保护，存在一些问题。为了进一步了解这一点，公司应研究下一代防火墙与传统防火墙之间的区别。


当企业正在考虑在其IT安全体系结构中部署云NGFW技术时，仍为时过早，实际部署有所不同。因此，企业对SaaS NGFW的需求可能会严重影响该技术的增长。


关于NFGW的另一个重要点：永远不要按公开价购买。


企业应根据产品是否足以维持组织预期的增长速度来做出NGFW的购买决策。


NGFW的未来

到2023年，全球NGFW市场预计将增长到46.9亿美元。作为IT安全产品的最大市场，它仍以每年8％的速度增长。


与NGFW顶级供应商交谈时，正在开发一些功能，这些功能将使IT部门的工作更加轻松，同时进一步加强网络安全性。这些公司还决心开发可满足各种规模组织的网络安全要求的NGFW产品。


NGFW供应商还花费大量时间和金钱进行研发，以跟上当今的复杂攻击并满足上述概述的全面，灵活性和可访问性要求。主要NGFW公司提供的主要功能之一是威胁情报，它是当前，开放，连续，自适应和自动的。


一家供应商的研发工作产生了诸如强大的集中式管理控制台和可抵抗逃避技术的检测引擎之类的功能。


此外，NGFW供应商旨在在不牺牲性能的情况下，为客户提供最全面的覆盖服务。为了帮助确定哪一个最适合您的环境，请在NSS实验室的2018 NGFW比较分析中查看NGFW的性能结果。这项独立研究报告了10个供应商NGFW，并讨论了性能，安全性和总拥有成本。



发现购买下一代防火墙的六个标准


这六个关键因素将帮助您的公司确定适合您组织需求的最佳NGFW产品。

下一代防火墙是基于硬件或软件的网络安全产品，可以检测并阻止传统防火墙技术之外的复杂攻击。


NGFW有许多选项，尽管它们都提供产品中通常可用的各种保护功能-例如传统防火墙，入侵检测系统（IDS），入侵防御系统（IPS），无线管理系统，质量服务（QoS）和应用程序控制系统-特定NGFW产品所提供的服务之间通常存在重大差异。


例如，一些供应商为中小型企业提供与NGFW分开的统一威胁管理产品，而其他供应商  在其NGFW基本产品中嵌入了UTM功能。


因此，很明显，无论供应商如何称呼他们的NGFW产品，买方都有责任了解所考虑的每种NGFW产品的确切功能。为了帮助读者着手进行此过程，并指导他们针对特定环境做出最佳的NGFW购买决策，本文提出了六种防火墙选择标准，并在采购过程中比较和对比这些IT安全产品时提出了一些问题处理。


1.平台类型

大多数下一代防火墙是硬件（设备），软件（可下载）或基于云的（SaaS）。基于硬件的NGFW最适合大中型企业。基于软件的NGFW，面向具有简单网络基础架构的小型公司；以及基于云的NGFW到高度分散的多地点站点或企业，这些站点或企业需要或重新分配管理它们所需的技能。


2.功能集

并非所有NGFW供应商都提供类似的功能。NGFW功能通常包括嵌入式  深层数据包检查防火墙，IDS / IPS，应用程序检查和控制，SSL / SSH检查，网站过滤和QoS /带宽管理，以保护网络免受最新的复杂网络攻击和入侵。


此外，大多数NGFW都提供威胁情报，移动设备安全性，数据丢失预防（DLP），Active Directory集成和开放式体系结构，该体系结构允许客户端定制应用程序控制甚至某些防火墙规则定义。


一个重要的警告是，NGFW中传统防火墙阻止和处理之外的可用功能并未提供每种功能的完整补充。例如，NGFW DLP不能达到专用DLP产品通常提供的水平。此外，NGFW应用程序控件还提供对已定义应用程序的标识和授权，用户访问权限以及其他时间和上载/下载权限。一些NGFW还能够基于应用程序过滤数据包并提供应用程序的内容过滤。


关键是组织要知道他们要购买什么，以及它是否为所需安全性的每个特定区域提供所需的保护级别。


3.表现

由于NGFW将许多功能集成到单个设备中，因此它们对于某些组织来说似乎很有吸引力。但是，一次启用所有可用功能可能会导致严重的性能下降。诚然，多年来，NGFW的性能指标有所提高，但是购买者在确定供应商和他们选择的NGFW的型号时，需要认真考虑性能与他们想要启用的安全功能之间的关系。


例如，2018年7月，NSS Labs Inc.发布了10个NGFW的比较研究结果，涉及三个主要领域-安全有效性，性能和总拥有成本（TCO）。


关键发现表明，其中有七个测试产品的TCO总平均价值/受保护的兆比特/秒达到了平均水平，而三个产品却低于平均水平。


此外，NSS测试了所有10个NGFW的性能，发现吞吐量从1,028 Mbps到7,888 Mbps，其中三个产品的速率明显低于其供应商的声明。


4.可管理性

此标准涉及系统配置要求和管理控制台的可用性。系统配置更改和管理控制台的用户界面应具有三个关键特性。它们应该是全面的，以使其涵盖一系列功能，而无需其他平台进行扩充；可以排除企业环境中不必要的功能；且易于访问，因此管理控制台，各个功能仪表板和报告都直观而敏锐。


5.价格

NGFW设备，软件和云服务的价格因供应商和型号而异，每台设备的价格从300美元到35万美元不等。有些服务合同有单独的定价。


公司应仔细审查各个产品的供应情况，以确定哪些功能最适合企业，同时还要考虑组织可以或不能承受的功能。如果可能，请勿支付零售价。大多数供应商将提供批量折扣 -例如，支持的用户越多，每用户的成本就越低-或具有进一步购买前景的折扣。


总体而言，定价应是确定TCO，NGFW的成本及其运营成本的几个因素之一。例如，NGFW的TCO不仅是购买价格，还包括其使用，维护，支持和运营所产生的费用。NGFW似乎很划算，实际上其TCO可能高于另一个NGFW，甚至是平台的组合。


6.技术支持

从企业需求的角度来看，2018年Gartner“ 企业网络防火墙魔力象限 ”对NGFW产品的质量，广度和价值进行了评级支持。考虑到NGFW的关键性质，及时准确的支持至关重要。公司应获取参考，并要求在没有供应商出席的情况下与供应商客户交谈。


NGFW的支持标准应解决按服务请求类型，服务响应的质量和准确性，产品更新和客户教育的时事以及对时事的意识进行排名的响应性。


结论

NGFW提供的保护（控制）级别应与资产（风险）的价值相称。


组织必须熟悉最适合其IT环境和业务模型的NGFW供应商和产品，这一点很重要。


为此，请考虑以下六个标准：平台基础，功能集，性能，可管理性，价格和技术支持。然后确定其余的NGFW产品中最符合组织的TCO要求的产品。


此外，请执行概念验证评估，以确保选定的NGFW在组织的IT基础架构中运行良好。例如，某些NGFW供应商声称安装起来像搬家一样容易。对于某些NGFW，这是正确的说法，但是在部署之前进行谨慎的计划和测试至关重要。


雇用合适的人或建立与现有人员一起管理和维护此IT安全环境所需的技能集也很重要。最后，在月底和季度末进行购买，以利用供应商的销售配额要求，以使组织受益。



基于公司需求的下一代防火墙比较


比较领先的下一代防火墙，以帮助找到最适合您的IT环境和安全需求的选项。

下一代防火墙通过集成的网络安全平台来保护企业网络免受入侵和攻击，这些平台包括嵌入式深层数据包检查防火墙，入侵防御系统，应用程序检查和控制，SSL / SSH检查，网站过滤以及服务质量和带宽管理。


选择最佳的NGFW可能具有挑战性，但是组织可以通过完成下一代防火墙比较并创建产品清单来简化购买过程。他们不必选择行业中顶级的NGFW产品，而是选择最适合并满足其特定企业要求的NGFW。


那么谁是全球主流NGFW供应商？本文研究了这8家NGFW供应商：梭子鱼网络公司，Check Point软件技术有限公司，思科，Fortinet公司，Forcepoint，瞻博网络，Palo Alto网络公司和SonicWall。


寻找最佳NGFW供应商产品时应考虑的问题包括：公司的产品线是什么？它的下一代防火墙适用于云服务提供商，大型企业还是中小型企业？基本产品附带哪些NGFW功能？哪些功能需要额外的许可证？防火墙如何出售和定价？什么使一种产品与另一种产品区分开？


如人们所料，NGFW之间有许多相似之处。但是，这些差异值得一提和比较。


NGFW服务什么？

所有NGFW旨在保护中型到大型企业。思科，Check Point，Fortinet，梭子鱼和瞻博网络也为中小企业提供NGFW产品。同时，本文中讨论的所有NGFW都支持虚拟和物理部署，以及Azure，AWS和Google Cloud Platform 等云环境中的部署  。


有哪些可用功能？

NGFW所有产品中可用的通用功能包括统一威胁管理（UTM），无中断在线嵌入式突跳式配置，网络地址转换，状态数据包检查，VPN，基于集成签名的入侵防护系统（IPS）引擎和应用意识。它们还倾向于包含从防火墙外部合并信息的功能-包括基于目录的策略，黑名单和白名单。此外，它们提供升级路径以包括将来的信息提要和安全威胁，并提供SSL解密以识别不需要的加密应用程序。


NGFW的罕见功能因供应商而异，因此组织可以在这里开始区分产品：


  • SonicWall通过基于云的实时威胁防护来防御高级威胁，其中包括多引擎沙箱，反恶意软件，入侵防御和Web过滤。
