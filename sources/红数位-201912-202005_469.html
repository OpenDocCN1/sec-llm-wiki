微软警告，GALLIUM镓威胁组织瞄准全球电信公司

微软昨天博客撰文：

Microsoft威胁情报中心（MSTIC）通过一个名为GALLIUM的威胁组织来提高对正在进行的活动的认识，该组织针对电信提供商。当Microsoft客户以此活动为目标时，我们会直接通知他们他们需要保护自己的相关信息。通过分享与GALLIUM活动有关的详细方法和指标，我们鼓励安全社区实施主动防御，以保护更广泛的生态系统免受这些攻击。




为了破坏目标网络，GALLIUM使用公开可用的漏洞来针对未打补丁的面向互联网的服务，并且已知针对WildFly / JBoss中的漏洞。在网络中建立持久性后，GALLIUM将使用Mimikatz等通用技术和工具来获取凭据，以允许在目标网络中进行横向移动。在受感染的网络中，GALLIUM不会试图掩盖其意图，并且已知会使用经过恶意修改的通用版本的恶意软件和可公开获得的工具包。运营商依赖于低成本，易于更换的基础架构，该基础架构由动态DNS域和定期重用的跳点组成。


从GALLIUM开展的这项活动主要已确认到2018年至2019年中期。镓仍处于活动状态；但是，与以前观察到的相比，活动水平下降了。


按照Microsoft将化学元素分配给活动组的内部惯例，GALLIUM是该活动组的代号。


GALLIUM的特征资料


侦察方法


与侦察方法一样，很难确定GALLIUM所采用的方法。这是由于演员的侦察活动是被动的，包括使用来自公开资源（例如公共网站和社交媒体）的免费可用数据。但是，根据MSTIC分析师的评估，GALLIUM对面向互联网的服务的利用表明，他们很可能会使用开源研究和网络扫描工具来确定可能的目标。


交付和利用

为了获得对目标网络的初始访问，GALLIUM定位并利用了面向Internet的服务，例如Web服务器。有人发现，GALLIUM是在利用未打补丁的Web服务（例如WildFly / JBoss）进行开发的，而针对这些服务的漏洞得到了广泛的利用。破坏Web服务器可以使GALLIUM在不需要用户交互的受害者网络中立足，例如网络钓鱼等传统交付方法。


利用Web服务器之后，GALLIUM actor通常会安装Web shell，然后再安装其他工具以使他们能够探索目标网络。


横向运动


GALLIUM使用各种工具来执行侦察并在目标网络内横向移动。其中大多数是现成的工具或已知安全工具的修改版本。MSTIC的调查表明，GALLIUM在逃避反恶意软件检测而不是开发自定义功能的程度上对其工具进行了修改。在多个操作区域中，使用GALLIUM角色已观察到此行为。

安装


镓主要使用广泛使用的工具。在某些情况下，GALLIUM修改了这些工具以添加其他功能。但是，很可能已经进行了这些修改，以颠覆反恶意软件解决方案，因为GALLIUM所采用的许多恶意软件和工具都是历史悠久的，并且被安全产品广泛检测到。例如，QuarkBandit是广泛使用的Gh0st RAT（一种公开可用的远程访问工具（RAT））的修改版本。同样，GALLIUM也使用了广泛使用的Poison Ivy RAT的修改版。这些RAT和China Chopper Web Shell构成了GALLIUM用于维护对受害网络的访问的工具包的基础。


基础设施


GALLIUM主要使用动态DNS子域为其恶意软件提供命令和控制（C2）基础结构。通常，该组使用noip.com提供的ddns.net和myftp.biz域。MSTIC分析表明，使用动态DNS提供商而不是注册域与GALLIUM趋向于低成本和省力运营的趋势一致。


在中国大陆，香港特别行政区和台湾的基础设施上都发现了GALLIUM域。


当连接到目标网络上的Web Shell时，已发现使用基于台湾服务器的GALLIUM。观察到的IP地址似乎是GALLIUM所独有的，几乎没有合法活动，甚至可以在多个操作中重复使用。这些服务器在调查过程中提供了高保真度的关键点。


已为Azure Sentinel准备了包含此操作期间使用的GALLIUM命令和控制域的GALLIUM指示符包，该包已在Microsoft GitHub上提供。

第一阶段


GALLIUM通常不使用传统的第一阶段安装程序来安装其恶意软件。取而代之的是，该组严重依赖于Web Shell，这是成功利用后在受害者网络中持久保留的第一方法。然后，通过现有的Web Shell访问来传递后续的恶意软件。


Microsoft Defender高级威胁防护（ATP）通过分析脚本文件的写入和过程执行来揭示异常行为，该异常行为指示Web Shell安装和后泄露活动。Microsoft Defender ATP提供了多种Web Shell活动检测功能，不仅可以保护客户免受GALLIUM活动的侵害，还可以保护客户免受Web Shell活动的影响。在Microsoft Defender ATP门户中阅读完整的报告。

除了标准的China Chopper之外，还发现GALLIUM使用本机Web Shell用于运行基于China Chopper Web Shell的运行Microsoft IIS的服务器。微软称其为“ BlackMould”。


BlackMould包含在受害主机上执行以下任务的功能：


  • 枚举本地驱动器。

  • 采用基本文件操作，例如查找，读取，写入，删除和复制。

  • 设置文件属性。

  • 渗入和渗入文件。

  • 使用参数运行cmd.exe。


命令在HTTP POST请求的主体中发送。


第二阶段


如果GALLIUM在受害网络上部署了其他恶意软件，则他们使用Gh0st RAT（检测为QuarkBandit的经过修改的Ghost RAT）和Poison Ivy恶意软件的版本。在这两种情况下，GALLIUM都修改了恶意软件使用的通信方法，这可能会阻止通过现有的反恶意软件签名进行检测，因为这两个恶意软件家族都基于其原始通信方法进行了多次检测。表2中列出了恶意软件家族。

GALLIUM的恶意软件和工具似乎是高度一次性且低成本的。如果GALLIUM投资对其工具集进行了修改，则他们似乎将重点放在逃避反恶意软件检测上，这可能会使恶意软件和工具更加有效。

除了这些恶意软件家族之外，还发现GALLIUM使用SoftEther VPN软件来促进访问并保持对目标网络的持久性。通过在内部系统上安装SoftEther，GALLIUM可以通过该系统进行连接，就像它们在目标的内部网络上一样。SoftEther为GALLIUM提供了另一种持久性和灵活性，其附加好处是它的流量在目标网络上可能看起来是良性的。


推荐防御

建议采取以下防御措施，以帮助安全运营团队减轻企业环境中GALLIUM等威胁的影响：


  • 维护Web服务器修补程序和日志审核，以最低的操作系统权限运行Web服务

  • 立即在所有应用程序和操作系统上安装安全更新。查看安全更新指南，以获取有关可用的Microsoft安全更新的详细信息。

  • 为了获得有效的事件响应，请使用集中式事件记录，文件服务和最新资产清单来维护可进行取证的网络。

  • 启用云提供的保护并维护更新的防病毒软件。

  • 在Windows Defender防病毒上启用云提供的保护和自动示例提交。这些功能使用人工智能（AI）和机器学习来快速识别和阻止新的未知威胁。

  • 使用行为检测解决方案来捕获凭证转储或其他可能表明违规的活动。

  • 采用Azure ATP（一种基于云的安全解决方案，利用您的本地Active Directory信号）来识别，检测和调查针对您组织的高级威胁，泄露的身份以及恶意的内部行为。

  • 使用Microsoft Defender ATP帮助企业网络预防，检测，调查和响应高级威胁。对用户进行有关保护社交媒体中的个人和企业信息，过滤未经请求的通信，识别鱼叉式钓鱼邮件和水坑中的诱饵以及报告侦察尝试和其他可疑活动的信息。

  • 鼓励用户使用Microsoft Edge和其他支持SmartScreen的Web浏览器，后者可识别和阻止恶意网站，包括网络钓鱼网站，欺诈网站以及包含漏洞利用和托管恶意软件的网站。

  • 进行多因素身份验证（MFA），以缓解遭到破坏的帐户。

  • 注意：Microsoft强烈建议所有客户下载和使用无密码解决方案，例如Microsoft Authenticator应用程序或Windows Hello，以保护您的帐户。

  • 对于Office 365用户，请参阅MFA支持。

  • 对于消费者和个人电子邮件帐户，请参阅如何使用两步验证。
