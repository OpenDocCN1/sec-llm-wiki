当Windows 7终止支持时，操作系统将显示全屏警告，指出Windows更容易受到病毒的攻击，您应该升级到Windows 10。



2020年1月14日，Windows 7将正式终止支持（EoS），除非您购买了Extended Security Updates，否则您将不再收到安全更新，Microsoft Security Essentials定义，软件更新或操作系统的技术支持。


为了向Windows 7用户警告即将到来的EoS，某些Windows 7更新将安装名为EOSnotify.exe的程序，该程序将定期通过计划的任务运行。


在今天的Windows 7  KB4530734每月汇总中，Microsoft推出了新版本的EOSnotify.exe程序，该程序现在将显示警报，解释用户为什么应升级到Windows10。此警报将全屏显示并显示在所有打开的位置。Windows以及桌面和“开始”菜单。


Windows 7支持终止广告


从2020年1月15日开始，所有Windows 7 Service Pack 1入门版，家庭普通版，家庭高级版和专业版客户在登录时或下午12点将开始看到上述全屏警报。该警报指出：


您的Windows 7 PC不受支持


截至2020年1月14日，对Windows 7的支持已终止。由于以下原因，您的PC更容易受到病毒和恶意软件的攻击：


  •  *没有安全更新

  •  *没有软件更新

  •  *没有技术支持

 

Microsoft强烈建议在新PC上使用Windows 10，以获取最新的安全功能并防御恶意软件。


已购买扩展安全更新，加入域的计算机或自助服务终端模式的计算机的Windows 7 Professional客户将不会看到此消息。


关于EOSnotify.exe的技术细节

该EOSnotify程序位于％windir％\ SYSTEM32 \ EOSNotify.exe，由两个名为计划任务启动EOSNotify和EOSNotify2 位于下  微软 - > 视窗 - > 设置在任务调度。


每当用户登录Windows时，都会启动EOSNotify任务，并且EOSNotify2每天晚上12点运行。


EOS通知计划任务


当EOSNotify.exe程序运行时，它将检查HKEY_CURRENT_USER \ Software \ Microsoft \ Windows \ CurrentVersion \ EOSNotify  项下的LastRunTimestamp值，  并且如果当天已运行，则不会显示警报。


EOSNotify.exe还将检查DiscontinueEOS值是否存在，  如果将其设置为1，  则不会显示警报。


因此，从不希望看到警报的用户可以在2020年1月15日之前配置以下注册表项。


[HKEY_CURRENT_USER \ Software \ Microsoft \ Windows \ CurrentVersion \ EOSNotify] 

“ DiscontinueEOS” = dword：00000001

 


尽管有些人可能会觉得这些警报很烦人，但明智的做法是在Windows 7到达EoS之前升级到Windows 10。


每天都会发现新的安全漏洞和恶意软件威胁，因此，请务必确保您和您的操作系统受到保护。


只要您拥有Windows 7的正版激活密钥，您仍然可以使用此方法免费升级到Windows 10。
