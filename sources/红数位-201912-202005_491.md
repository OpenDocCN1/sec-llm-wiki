# 英特尔修补了平台更新中的Plundervolt高严重性问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247487010&idx=4&sn=340162d95c7d69415d5f221cc3a58f7c&chksm=cef36391f984ea873d7e1398bb6bebbbf08d70d8682ae53fcc9ffd36306c0ca8a199829f961b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247487010&idx=4&sn=340162d95c7d69415d5f221cc3a58f7c&chksm=cef36391f984ea873d7e1398bb6bebbbf08d70d8682ae53fcc9ffd36306c0ca8a199829f961b&scene=27#wechat_redirect)

**![](../Images/367001a0301def9911d3f0298bf7cedc.png)**

  

英特尔在2019年12月补丁程序星期二期间解决了14个安全漏洞，其中七个是高中级安全漏洞，影响包括Windows和Linux在内的多个平台。

  

![](../Images/9407c4ca7d72507426350d70997a0a3e.png)

  

英特尔在其产品安全中心发布的9个安全公告中详细介绍了今天修补的安全问题，该公司已通过英特尔平台更新（IPU）流程将其交付给客户。

  

今天公开的漏洞可能允许经过身份验证或特权的用户潜在地启用信息公开，触发拒绝服务状态，提升特权或通过本地访问以提升的特权级别执行恶意代码。

  

每个通报都附带所有受影响产品的详细列表以及对易受攻击产品的建议，还包括希望报告英特尔品牌技术或产品中其他漏洞的用户和研究人员的详细联系信息。

  

**遭受Plundervolt攻击的台式机，移动机，嵌入式和服务器CPU**

今天的更新还修补了Intel CPU，使其免受研究人员称为Plundervolt的新发现的攻击，并针对现代Intel CPU中与安全相关的指令代码的Intel Software Guard eXtensions（SGX）集。

  

电压过高攻击将 通过本地访问滥用  CVE-2019-11157漏洞，这是英特尔作为INTEL-SA-00289 通报的一部分解决的漏洞。

  

“INTEL-SA-00289是咨询，我们有多个学术研究工作的影响客户端系统，以及一些基于至强平台ê一些研究人员已经证明同一类问题对非英特尔架构，”英特尔说。

  

“在系统上启用SGX时，特权用户可能能够通过控制CPU电压设置来发动攻击，从而可能影响软件资产的机密性和完整性。英特尔已与系统供应商合作开发微码更新。通过将电压锁定为默认设置来缓解该问题。”

  

开发攻击状态的研究小组说：“我们能够通过在执行安全区计算时控制电压来破坏Intel Core处理器上Intel SGX的完整性。” “这意味着，即使是英特尔SGX的内存加密/身份验证技术也无法防范Plundervolt。”

  

受Plundervolt影响的CPU型号列表包括：

*   英特尔第六，第七，第八，第九和第十代核心处理器。  
    
*   英特尔至强处理器E3 v5和v6  
    
*   英特尔至强处理器E-2100和E-2200系列。  
    

  

英特尔还指出，该漏洞尚未被攻击者广泛利用，它建议上述英特尔处理器的用户安装其系统制造商提供的最新BIOS版本，以尽快解决此问题。
