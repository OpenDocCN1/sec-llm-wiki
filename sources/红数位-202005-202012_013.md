# CISA和FBI：APT团体正瞄准美国智库

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247494051&idx=1&sn=b2c61c42de492143c2707702f7d6c3d0&chksm=cef08410f9870d06d3f1ecb24e94e666856e44490ca147b96a41662ef18ed82a3a1524d018ca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247494051&idx=1&sn=b2c61c42de492143c2707702f7d6c3d0&chksm=cef08410f9870d06d3f1ecb24e94e666856e44490ca147b96a41662ef18ed82a3a1524d018ca&scene=27#wechat_redirect)

美国网络安全与基础设施安全局（CISA）和联邦调查局（FBI）就他们所说的针对美国智囊团的先进持续威胁（APT）行为者持续，持续的网络攻击发出警告。

  

![](../Images/1d0d486e657219ef84eac8d39442a1a0.png)

  

据联邦调查局称，攻击者正试图窃取敏感信息，获取用户凭证并获得对受害者网络的持久访问。

  

网络入侵特别针对那些关注国际事务或国家安全政策的入侵，本周发布的警报称–考虑到APT的地缘政治性质，这往往不足为奇，这往往受到民族国家的支持。

  

“鉴于智囊团在制定美国政策方面的重要性，CISA和FBI敦促国际事务和国家安全部门的个人和组织立即采取提高意识的状态，”该警报说。

  

在影响方面，APT首先要注意间谍活动，并希望窃取数据。CISA和联邦调查局说，观察到的间谍活动包括凭证转储，键盘记录，收集音频，窃取电子邮件，下载文件等等。

  

“网络罪犯正在努力与最有才华的人接触，以收集某些信息，有关'最先进'技术的数据或战略项目，以更好地发挥自己的作用，”安全意识倡导者James McQuiggan说。KnowBe4，通过电子邮件。

  

Lookout安全解决方案高级经理斯蒂芬·班达（Stephen Banda）通过电子邮件补充说：“我们继续看到以犯罪分子为目标的组织，这些组织开发或管理高价值知识产权，因此，智囊团是主要目标。”

  

但是，该访问也可以用于更邪恶的目的。

  

“如果某人在不知不觉中与网络罪犯共享用户凭据，则黑客不仅可以访问受害者的网络，而且还可以从该人的帐户发送电子邮件，从而使他们看起来像发送的邮件是100％合法的，并且， Tessian的首席技术官兼联合创始人Ed Bishop表示：“这可能会影响美国的政策。

  

除信息盗窃外，该警报还警告说，某些攻击正在提供勒索软件，劫持资源以进行加密挖掘，安装分布式拒绝服务（DDoS）攻击，甚至在破坏性攻击中擦除磁盘。

  

**攻击向量**

CISA和FBI做出的评估表明，APT行动者迄今仍依赖多种途径来进行攻击的初始访问，包括聪明的社会工程技术和冒充受信任的第三方来欺骗受害者，以通过鱼叉骗局共享信息或帐户凭据。

  

Bishop说：“人们更依赖电子邮件与同事，客户和供应商保持联系，我们最近的调查发现，一半的员工在家工作时不太可能遵循安全数据惯例。”

  

但是，CISA和FBI也指出，APT正在进行更复杂的渗透网络的尝试，例如利用远程网络和其他与Internet连接的设备中的漏洞。

  

联邦调查局表示：“在COVID-19大流行期间，远程办公的增加，扩大了员工对远程连接的依赖，为恶意行为者提供了更多机会利用这些连接并与增加的流量融合。”

  

结果，一些攻击者正在利用虚拟专用网络（VPN）和其他远程工作工具中的错误来获取对受害者网络的初始访问或持久性。研究人员说，个人设备和网络使用的远程工作扩展使此过程更加容易。

  

班达说：“不幸的是，尽管远程工作可以提供一些便利和效率，但它已大大扩展了包括智囊团在内的所有企业的攻击面，”班达说。“例如，通常将在一个中央办公室开会的由10名研究人员组成的专家团队现在正在与10个单独的远程办公室进行协作。每个“个人办公室”都有其自己的安全要求，并具有各种连接的移动和固定端点。”

  

最后，警报还说，某些攻击始于供应链受损，暴力破解密码或使用被盗的有效凭证。

  

**智囊团攻击**

对智囊团的已知攻击一直在进行。例如，微软在2019年2月警告说俄罗斯APT花式熊正在袭击欧洲的民主智囊团。

  

最近，埃森哲（Accenture）透露，另一家俄罗斯APT Turla正在利用企业友好型平台（最著名的是Microsoft Exchange，Outlook Web Access（OWA）和Web on Outlook）来攻击智囊团和其他组织，以窃取业务凭证和其他敏感数据。

  

在10月下旬，CISA警告称，朝鲜APT团体Kimsuky经常冒充韩国记者，积极攻击智囊团，商业部门和其他组织。CISA指出，其任务是全球情报搜集，通常从电子邮件冒充，水坑攻击，洪流共享和恶意浏览器扩展开始，以便在目标网络中初步立足。

  

**保护与缓解**

CISA和FBI建议智囊机构采用一系列关键（但基本）的最佳实践来保护自己，包括实施社会工程和网络钓鱼培训。

  

McQuiggan说：“包括智囊团在内的所有组织都是民族国家和网络犯罪分子的目标，通过网络钓鱼，他们将其视为进入系统和基础设施的更便捷途径。” “组织需要维持强大的安全意识培训计划，并经常对其进行更新，以使员工了解最新的攻击方式和网络钓鱼电子邮件。员工可以做出适当的决定，以识别潜在的网络钓鱼电子邮件并进行报告。此举将建立更牢固的安全文化，并使组织能够努力成为安全部门的重要资产。”

  

该警报还提倡网络分段，良好的密码卫生和多因素身份验证，及时修补，使用防病毒软件以及强大的数据加密功能。

  

班达还强调说，智囊团应该意识到，移动设备可能是一个特别薄弱的环节。

  

他说：“考虑到85％的移动网络钓鱼攻击是在电子邮件之外发生的，仅关注基于电子邮件的网络钓鱼攻击的日子已经过去了。” “网络钓鱼攻击针对跨文本消息传递，社交消息传递平台和移动应用程序的移动用户。”
