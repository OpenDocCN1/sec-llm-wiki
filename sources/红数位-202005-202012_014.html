“避税天堂”开曼群岛某基金发生严重数据泄露

一家来自世界“避税天堂”开曼群岛投资基金数据泄露。该公司声称管理着5亿美元资产，投资者包括主权财富基金，著名的金融机构，公司和家族办公室。它的投资者之一是著名的投资银行罗斯柴尔德公司。这次泄露导致个人银行信息，护照数据甚至在线银行PIN集体外泄，影响严重。



该投资基金在未能正确配置安全的Microsoft Azure Blob，其所有备份已被公开到网络上。任何人只要拥有指向其Azure blob（Microsoft相当于Amazon Web Services S3存储桶）的URL，都可以免费阅读该基金的成员登记册详细信息以及与投资者的往来信件。


除了公开披露其股东是谁，持有多少股份以及所持股份的价值外，该基金还保存了一份网上银行PIN的副本扫描件。我们看到查看了Blob中的一部分文件，以确认其所有权和真实性。


该基金的在线银行PIN是任何人都可以在其不安全的Azure Blob上查看的文件之一


研究人员指出了巨大的网络安全失误，后者同意不透露受侵害基金的名称，以换取有关此事的详细信息。


基金的成员登记册（股东）–开曼群岛公司没有义务向不列颠海外领土的地方当局提交的文件之一


Register补充说，该公司的员工“完全不知道” Azure Blob是如何工作的（Azure Blob是与Amazon Web Services S3存储桶和其他云存储解决方案竞争的Microsoft备份存储解决方案），整个操作完全取决于外部提供商的网络安全性。


该报称，该公司声称管理着5亿美元的投资。


Azure blob上的任何人都可以查看敏感的内部文档，包括银行对账单



在无担保Blob中看到的文件可以追溯到几年前，包括：董事护照的扫描；与投资者的来信，包括在商业谈判期间发送的评论文件；条款表；股份证明书（包括空白副本）；由其董事签署的文件等。


该银行员工在接受采访时说：“这是我们在香港的IT供应商提供的备份解决方案，我们认为这是相当正常的云服务。” “显然这很有问题！”


不仅会扫描和上传完整的股票证书，还会扫描空白副本以及董事签名



从人数上看，这只基金属于中小型企业的中端，它的内部IT专业知识水平似乎很低。他们完全不知道Azure的运行方式或文件如何通过Web浏览器暴露给任何人，并且似乎完全依赖于其IT提供商来提供除基本办公生产力软件以外的所有内容。


该基金的一位董事已经扫描了他护照的所有身份页




此后，该数据已被IT供应商从服务器中删除。


网络安全和法律专家Ilia Kolochenko创立并担任ImmuniWeb的首席执行官，他表示，这家投资公司应该期待此次违规事件的影响。


科洛琴科表示：“对于这种特殊情况，大多数司法管辖区可能会将这一事件视为重大过失，使该基金受到客户的一系列诉讼。” “过去，类似事件导致破产，原因是其声誉受到不可弥补的影响，并且无法与受挫的客户继续运营。我们还应该期望负责起诉逃税或洗钱的各种执法机构对文件进行调查，以进行调查。”


云配置错误

无论云存储的风格或品牌如何，最近几个月，错误的配置困扰着各种企业。


酒店使用的预订平台Cloud Hospitality将其系统与在线预订系统集成在一起，最近由于Amazon Web Services S3存储桶配置错误而暴露了大约1000万人的数据。


订阅基督教应用程序Pray.com已被超过一百万的人下载到Google Play上，该应用程序还暴露了其数千万客户的个人数据，包括订户提交的用于捐赠的付款信息。罪魁祸首也是错误配置的AWS S3存储桶。


Google Cloud用户遇到了类似的云配置挑战。去年9月，Comparitech对2,064个Google Cloud Bucket进行了一项调查，结果发现6％的Google Cloud Bucket配置错误并向公众开放。
