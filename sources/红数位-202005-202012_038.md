# 微软11月周二补丁日修复112漏洞，含1零日

今天是微软的2020年11月星期二补丁日，虽然对于大多数人来说这只是普通的一天，但世界各地的Windows管理员今天又要发挥自己的作用了。

  

![](../Images/34119b71deabed13ecedea60cf5c8697.png)

  

随着2020年11月星期二补丁程序安全更新发布，Microsoft已发布针对Microsoft产品中的112个漏洞的修复程序。**在今天修复的112个漏洞中，有17个被分类为“**危急**”，有93个被分类为“重要”，另外两个则为“中等”。**

  

**零日漏洞修复**

**今天的补丁程序星期二更新中包括对Windows内核密码驱动程序（cng.sys）中的零日特权升级漏洞的修复。**

  

上周，该漏洞在被Google Project Zero检测到用于有针对性的攻击后被披露 。 

  

谷歌解释说：“该错误驻留在cng！CfgAdtpFormatPropertyBlock函数中，并且是由16位整数截断问题引起的。”该漏洞当前被跟踪为 CVE-2020-17087。

  

**其他公司的最新安全更新**

十月份发布安全更新的其他供应商包括：

  

*   Adobe 今天发布了适用于Android和Adobe Connect的Adobe Reader安全更新。
    
*   苹果 发布了针对iOS，macOS，tvOS和watchOS的安全更新。
    
*   SAP今天发布了 2020年11月的安全更新。
