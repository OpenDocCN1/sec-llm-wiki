微软基于Chromium的Edge于1月首次发布给Windows消费者和企业，后来又发布给macOS用户。Edge已在Android和iOS上提供，现在Linux用户终于可以体验Microsoft的新浏览器了。



今天，您终于可以在Linux上下载Microsoft Edge的第一个Dev通道版本，它具有所有基本功能，包括对平滑滚动的支持，Google扩展，主题等。



微软还指出，它旨在通过Chromium Edge为开发人员提供最佳体验。该浏览器旨在帮助开发人员在Linux上构建和测试其站点或应用程序。



不幸的是，第一次更新有一些限制。根据Microsoft的说法，某些最终用户功能和服务现在可能无法正常工作。此外，用户只能使用其本地帐户来设置Edge，而不能通过Microsoft帐户或AAD帐户登录Microsoft Edge。

Edge Dev当前支持Ubuntu，Debian，Fedora和openSUSE发行版。Microsoft确认用户可以直接从其网站下载.deb或.rpm软件包的浏览器，但您需要使用Terminal才能正确安装浏览器。


根据我们的测试，如果仅在.deb或.rpm上双击，则Edge Dev安装当前将失败。


如何在Ubuntu / Debian上安装Microsoft Edge

在Ubuntu / Debian上，通过在Terminal中运行以下命令来设置Microsoft的存储库：


curl https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > microsoft.gpg
sudo install -o root -g root -m 644 microsoft.gpg /etc/apt/trusted.gpg.d/
sudo sh -c 'echo "deb [arch=amd64] https://packages.microsoft.com/repos/edge stable main" > /etc/apt/sources.list.d/microsoft-edge-dev.list'
sudo rm microsoft.gpg


完成此操作后，请使用以下两个命令来安装Microsoft Edge Dev：


sudo apt update
sudo apt install microsoft-edge-dev


您可以从Ubuntu的启动器运行浏览器。您也可以先使用sudo apt update，然后进行sudo apt upgrade（更新所有软件包）来手动更新Edge版本 。或者，您也可以使用 sudo apt install microsoft-edge-dev仅更新Microsoft Edge Dev。


如何在Fedora上安装Microsoft Edge

在Fedora上，使用以下命令设置Microsoft的存储库：


sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
sudo dnf config-manager --add-repo https://packages.microsoft.com/yumrepos/edge
sudo mv /etc/yum.repos.d/packages.microsoft.com_yumrepos_edge.repo /etc/yum.repos.d/microsoft-edge-dev.repo


现在，您可以通过键入以下内容开始安装： sudo dnf install microsoft-edge-dev


如何在openSUSE上安装Microsoft Edge

在openSUSE上，您可以按照以下步骤设置Microsoft存储库：


sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc
sudo zypper ar https://packages.microsoft.com/yumrepos/edge microsoft-edge-dev


要安装Edge，请使用以下命令：


sudo zypper refresh
sudo zypper install microsoft-edge-dev
