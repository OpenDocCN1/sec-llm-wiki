# 微软发布紧急REC远程执行代码严重漏洞公告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247493206&idx=1&sn=41491a39fb79e5dfe865bba72ce1480b&chksm=cef08be5f98702f378235f0eda87339ea8401099ba038b355f323e42cc2c2eacb19f4ac1cf7f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247493206&idx=1&sn=41491a39fb79e5dfe865bba72ce1480b&chksm=cef08be5f98702f378235f0eda87339ea8401099ba038b355f323e42cc2c2eacb19f4ac1cf7f&scene=27#wechat_redirect)

RCE英文全称:remote command/code execute漏洞。RCE漏洞导致的危害不用多说，可以让攻击者直接向后台服务器远程注入操作系统命令或者代码,从而控制后台系统。高危致命漏洞可以获得系统最高权限，从而直接获取系统的控制权(既然系统控制都拿下了，想干啥就干啥了。)

  

**【红数位中国区首发】Microsoft周五时候已经发布了两个危急安全公告，旨在解决被发现会影响Microsoft Windows Codecs库和Visual Studio Code的远程代码执行（RCE）漏洞，不幸的是目前暂无补丁也未给出缓释措施，简单说就是无解。**

  

![](../Images/727b0988b1871e9078e502d2b3cf44ae.png)

  

**跟踪这两个漏洞为：**

  

*   **CVE-2020-17022**
    
*   **CVE-2020-17023**
    

  

**它们都被评为重要严重性并标记为未经野外利用。**  

  

**涉及影响操作系统：**

  

*   **Windows 10版本1709**
    
*   **Windows 10版本1803**
    
*   **Windows 10版本1809**
    
*   **Windows 10版本1903**
    
*   **Windows 10版本1909**
    
*   **Windows 10版本 2004**
    

  

**仅Windows 10客户端平台受影响**

**📌****CVE-2020-17022 | Microsoft Windows Codecs库远程执行代码漏洞会影响所有运行Windows 10版本1709或更高版本以及易受攻击的库版本的设备。**

  

该漏洞是由Microsoft Windows Codecs库处理内存中的对象的方式引起的，并且成功利用漏洞需要程序来处理特制图像文件。

  

> **Microsoft Windows Codecs库处理内存中对象的方式中存在一个远程执行代码漏洞。成功利用此漏洞的攻击者可以执行任意代码。****利用此漏洞需要程序处理经特殊设计的图像文件。****此更新通过更正Microsoft Windows Codecs库如何处理内存中的对象来解决此漏洞。**

  

微软表示，Windows 10设备的默认配置不易受到攻击，“只有安装了Microsoft Store中可选HEVC或'HEVC from Device Manufacturer'媒体编解码器的客户才可能受到攻击。

  

进入 “设置” >“应用和功能”，然后选择“ HEVC”，“高级选项” 使您可以检查编解码器是否已更新-安全版本为1.0.32762.0、1.0.32763.0和更高版本。

  

微软在6月修补了两个类似的RCE漏洞，由于通过Microsoft Store而不是通过正常的Windows Update通道交付安全更新，导致用户很困惑。

[**微软紧急发布Windows 10两个RCE漏洞补丁**](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489347&idx=2&sn=1423a66d964c7295bb63ea5b62d2ea8f&chksm=cef37af0f984f3e67f123559c81ba743df5616bd8283727177ff9d7161f4ea9cd0f0644b6601&scene=21#wechat_redirect)  

  

****📌******CVE-2020-17023 | 用户打开恶意制作的“ package.json”文件时，将触发“ Visual Studio JSON远程执行代码漏洞”，它使攻击者可以在当前登录用户的上下文中远程执行代码。**

  

如果用户具有管理权限，则成功利用漏洞还使攻击者能够在受到感染的Windows设备上创建恶意管理员帐户。

  

> ****当诱****使用户打开恶意的“ package.json”文件时，Visual Studio Code中存在一个远程执行代码漏洞。成功利用此漏洞的攻击者可以在当前用户的上下文中运行任意代码。如果当前用户使用管理用户权限登录，则攻击者可以控制受影响的系统。然后，攻击者可能会安装程序。查看，更改或删除数据；或创建具有完全用户权限的新帐户。********要利用此漏洞，攻击者需要说服目标来克隆存储库并在Visual Studio Code中打开它。当目标打开恶意的“ package.json”文件时，将执行攻击者指定的代码。********此更新通过修改Visual Studio Code处理JSON文件的方式来解决漏洞。****

  

CVE-2020-17023实际上是CVE-2020-16881的安全更新旁路，CVE-2020-16881是Microsoft试图在9月8日修复的另一个Visual Studio Code RCE漏洞。

**没有缓解措施和解决办法，更新将自动安装**

  

**微软表示，尚未确定这两个漏洞的任何缓解措施或解决办法。**

  

![](../Images/c1667925fa051ad02203437aef5bf772.png)

图片来源微软此次两个漏洞发布页  

  

受影响的客户无需采取任何措施来保护其计算机免受CVE-2020-17022的侵害，因为除非禁用了Microsoft Store应用程序的自动更新，否则安全更新将通过Microsoft Store自动传递给所有受影响的设备。

  

“另外，想要立即接收更新的客户可以使用Microsoft Store App检查更新；有关此过程的更多信息，打开 Microsoft Store 后，选择“更多” >“下载和更新”>“获取更新”。” Microsoft解释说。

  

火眼公司的Dhanesh Kizhakkinan向Microsoft报告了CVE-2020-17022，而Justin Steven报告了CVE-2020-17023 。
