今天是微软的2020年10月补丁程序星期二，虽然对于大多数人来说这只是普通的一天，但世界各地的Windows管理员今天又要发挥自己的作用了。



随着2020年10月星期二补丁程序安全更新发布，Microsoft已发布了针对Microsoft产品中的87个漏洞的修复程序以及有关今天的Adobe Flash Player更新的资讯。


在今天修复的87个漏洞中，有12个被分类为“危急”，有74个被分类为“重要”，其中一个被分类为“中等”。


有关非安全Windows更新的信息，您可以阅读有关今天的Windows 10 KB4579311和KB4577671累积更新。


公开披露的漏洞：

本月的补丁星期二安全更新包括六个公开披露的漏洞。好消息是，微软表示，没有人公开这些漏洞并利用。


安全研究员Jonas L发现了其中一个漏洞CVE-2020-16938， 他在受到Microsoft的赏金后，最近开始在Twitter上披露了这个漏洞。


  • CVE-2020-16938 -Windows内核信息泄露漏洞

  • CVE-2020-16885 -Windows Storage VSP驱动程序特权提升漏洞

  • CVE-2020-16901 -Windows内核信息泄露漏洞

  • CVE-2020-16908 -Windows安装程序特权提升漏洞

  • CVE-2020-16909 -Windows错误报告特权提升漏洞

  • CVE-2020-16937-.NET Framework信息泄露漏洞


Microsoft尚未透露谁发现了其他五个漏洞。


感兴趣的漏洞

尽管本月没有零日漏洞出现，但仍有许多有趣的漏洞可以远程利用。


以下是今天修复的更有趣的关键安全漏洞：


  • 通过“ CVE-2020-16911 -GDI +远程执行代码漏洞”，攻击者可以创建专门制作的网站，这些网站可以在访问者的计算机上以提升的特权执行命令。


  • “ CVE-2020-16947 -Microsoft Outlook远程执行代码漏洞”允许攻击者发送经特殊设计的电子邮件，这些电子邮件在Microsoft Outlook软件中打开时可以执行命令。在预览窗格中查看电子邮件时，此攻击也有效。


  • 📌通过将特制的ICMPv6路由器播发数据包发送到远程Windows计算机，可以利用“ CVE-2020-16898 -Windows TCP / IP远程执行代码漏洞”。如果成功，它可能允许远程攻击者在目标计算机上执行命令。（*漏洞评分：9.8 ）


📌临时修补建议：

可以禁用IMCPv6 RDNSS来缓解风险，使用以下PowerShell命令禁用ICMPv6 RDNSS，以防止攻击者利用此漏洞。此解决方法仅适用于Windows 1709及更高版本。

netsh int ipv6 set int *INTERFACENUMBER* rabaseddnsconfig=disable

进行更改后无需重新启动。

可以使用以下PowerShell命令禁用上述解决方法。

netsh int ipv6 set int *INTERFACENUMBER* rabaseddnsconfig=enable


  • “ CVE-2020-16891 -Windows Hyper-V远程执行代码漏洞”将允许来宾Hyper-V虚拟机上的攻击者或恶意软件在主机操作系统上执行命令。


  • 通过诱使用户访问恶意网站，可以利用“ CVE-2020-16915 -Media Foundation内存损坏漏洞”来执行远程代码。
