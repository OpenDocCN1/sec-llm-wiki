# 传奇大佬McAfee创始人约翰·迈克菲在西班牙被捕，或判5年

迈克菲（McAfee）创建了以他的名字命名的反病毒公司，在美国，他至少十年的时间规矩的遵守法律。最后，传奇的约翰·迈克菲离开了McAfee这家安全公司20多年。这位杀毒软件先驱者自2012年以来就一直在逃，此前他涉嫌参与了邻居伯利兹的一起谋杀，不过他否认了这一指控，佛罗里达法院为此命令他去年向死者家属支付2500万美元。

  

他曾逃到瓜地马拉并躲在一个衣橱数周，同时不断在网络上秀自己生活吊警察胃口，并还让记者来采访他，最终行踪暴露他行踪是的与外媒一位VICE的记者与他用iphone合照，并还公开照片坐标。

![](../Images/767a154e63d8446b384eae298d5f4ecd.png)

![](../Images/e6dd7401cc18968ae0e9f15f66f3703a.png)

  

8月10日，因为拒绝戴符合医疗防护规范的口罩，还将一条蕾丝丁字裤戴在脸上招摇过市，被挪威警方逮捕，因为挪威警方不认可他用女士蕾丝内裤自制的口罩。他的妻子也被警方拘留。迈克菲被逮捕后5小时，他的妻子詹尼斯又发了一条推特。这一次她手拿香槟和高脚杯，写道：“迈克菲是我认识的唯一一个被拘留还能弄到香槟的人。” 而后被释放。

  

![](../Images/b04b50b4313a1ac0e812ed03b958fdbb.png)

  

在美国司法部和美国证券交易委员会（SEC）监管机构开始对税收犯罪进行联合调查之后，迈克菲就躲藏起来了，但**昨天在西班牙被捕**。美国司法部昨天发布起诉书对他进行了起诉，迈克菲被指控逃税，部分原因是使用加密货币。

  

![](../Images/ba1888ae62b79572a326bf93e1603b70.png)

  

  

起诉书指出，在四年的时间里，他的数百万美元收入来自推广加密货币，咨询工作，演讲活动以及他获得纪录片的故事权。

  

根据起诉书公开的指控，美国司法部声称获得2300万美元的加密货币收入，旨在通过假人购买房地产，游艇和各种车辆。 其中一位是迈克菲的保镖，已注册为McAfee团队总监Jimmy Watson。

  

他在西班牙等待引渡，罪名是对10种偷税漏税和不愿交税的指控。他尝试联系过去曾代表McAfee公司的律师并没有立即成功，但他也没有尝试直接联系McAfee公司。

  

迈克菲毫不掩饰自己对纳税的不屑，去年在 推特上说，他没有提交纳税申报表已经有八年了，因为“税收是非法的”而“我的净收入是负的”，还有其他众多不满。

  

律师说，在去年，迈克菲在多米尼加监狱度过了一段时间后被转移到英国，他因通过游艇将武器带入该国而被拘留。

  

值得一提的是，此案还附有一个录像带，网络安全先驱者公开披露了使用加密货币逃税的计划，并对此表示认罪。SEC监管机构已经确定并证实了通过推广ICO接受资金的事实。

  

在对令牌问题进行大量调查的过程中，初创公司“捐赠”了McAfee，以及将加密货币转移到的钱包地址。 收到此信息后，司法部跟踪了兑现收到款项的方式及其支出方向， 参与该计划的许多前锋已经认罪。

  

根据律师的说法，如果完全认罪，**约翰·迈克菲将面临5年的监禁和罚款，并附带所有索赔的补偿。 来自西班牙的引渡程序将被添加到该截止日期。**
