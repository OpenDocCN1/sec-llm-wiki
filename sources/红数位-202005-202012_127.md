# 针对全球物联网设备新威胁“行星际风暴”变种，亚洲感染率达62%，附IOC

**2019年5月出现的InterPlanetary Storm僵尸网络的第一个版本针对基于Windows的设备。到2019年6月，该恶意软件也开始危害Linux设备。**

最近，“行星际风暴”InterPlanetary Storm恶意软件背后的网络犯罪组织已经发布了一个新版本，**现在不仅针对Windows和Linux计算机，还****针对Mac和Android设备****。**该恶意软件正在构建一个僵尸网络，据梭子鱼研究人员估计，**目前该僵尸网络包括位于全球84个不同国家的大约13,500台受感染的计算机，并且这一数字还在继续增长。**

![](../Images/806fa66bc4d619d9dafa22c814c63725.png)

  

被恶意软件感染的大多数计算机位于亚洲。

  

**全球受感染的计算机占比：**

  

*   59％在香港，韩国和台湾
    
*   8％在俄罗斯和乌克兰
    
*   6％在巴西
    
*   5％在美国和加拿大
    
*   3％在瑞典
    
*   3％在中国
    
*   所有其他国家/地区都在1％或以下
    

  

以下是对这种不断发展的威胁以及有助于检测，阻止和补救攻击的解决方案的详细介绍：

  

**行星际风暴**

  

**突出威胁**

InterPlanetary Storm恶意软件的新变种—这种新的恶意软件变种通过对SSH服务器运行字典攻击来获得对计算机的访问权限，类似于另一种对等（p2p）恶意软件FritzFrog。它也可以通过访问打开的ADB（Android调试桥）服务器获得进入。该恶意软件可以检测受害者的CPU架构和运行的操作系统，并且可以在基于ARM的计算机上运行，该架构在路由器和其他IoT设备中非常常见。

  

该恶意软件之所以称为InterPlanetary Storm，是因为它使用了InterPlanetary File System（IPFS）p2p网络及其底层libp2p实现。这使受感染的节点可以直接相互通信，也可以通过其他节点（即中继）进行通信。

  

2019年5月，Anomali的研究人员发现了针对Windows机器的Interplanetary Storm的第一个变体，并于今年6月报告了一种能够攻击Linux机器的变体。梭子鱼研究人员在8月下旬首次发现了这个新变种，其目标是物联网设备（例如在Android操作系统上运行的电视）和基于Linux的机器（例如具有错误配置的SSH服务的路由器）。

  

尽管此恶意软件正在构建的僵尸网络尚不具备明确的功能，但它为活动的运营者提供了被感染设备的后门，因此以后可将其用于加密，DDoS或其他大规模攻击。

  

**细节**

InterPlanetary Storm的此变体用Go编写，使用libp2p的Go实现，并且与UPX打包在一起。它使用SSH暴力破解和开放的ADB端口进行传播，并将恶意软件文件提供给网络中的其他节点。该恶意软件还启用反向shell，并可以运行bash shell。

  

梭子鱼研究人员发现了几种独特的功能，旨在帮助恶意软件在感染计算机后继续存在并提供保护。

  

*   **它检测蜜罐。**该恶意软件会在默认Shell提示符（PS1）中查找字符串“ svr04”，该字符串以前曾被Cowrie蜜罐使用。
    
*   **它会自动更新。**该恶意软件会将正在运行的实例的版本与最新的可用版本进行比较，并将相应地进行更新。
    
*   它将使用Go**守护程序包通过安装服务**（system / systemv）来尝试保持自身状态。
    
*   它会**杀死计算机上对恶意软件构成威胁的其他进程**，例如调试器和竞争性恶意软件。

**通讯协议**

Libp2p应用程序基于称为协议ID的逻辑地址（即，传输层未知）处理传入连接（流）。按照约定，协议ID具有类似路径的结构，其中版本号是最终组件。

  

恶意软件正在使用以下协议ID：

  

| 协议ID || 目的 || 笔记 |
| --- | --- | --- |
| /sbst/1.0.0 || 用于生成反向外壳 || 托管在节点上 |
| /sfst/1.0.0 || 用于文件传输 || 托管在节点上的文件校验和用于确保所提供文件的完整性 |
| /sbpcp/1.0.0 || 用于代理，连接到后端服务 || 托管在后端服务器上 |
| /sbptp/1.0.0 || 用于代理，转发代理频道 || 托管在节点上 |
| /sreque/1.0.0 || 用于扫描程序队列。 || 来自c2的命令托管在节点上，包含签名。  
该通道上的消息使用JSON对象进行序列化。来自c2的消息将用于“ brute-ssh”或“ tcp-scan”，指示节点扫描易受攻击的计算机。该节点将发送这些扫描的结果。来自c2的“ brute-ssh”消息将包括要攻击的Ips列表以及应使用的凭据。 |

如何防范这些攻击

您可以采取一些重要步骤来防御此恶意软件变体。

  

*   在所有设备上正确配置SSH访问。这意味着使用密钥而不是密码，这将使访问更加安全。启用密码登录并可以访问服务本身时，恶意软件可以利用配置错误的攻击面。这是路由器和IoT设备常见的问题，因此它们很容易成为该恶意软件的目标。
    
*   使用云安全状态管理工具监视SSH访问控制，以消除可能导致灾难性的任何配置错误。如果需要，提供对外壳的安全访问；与其将资源暴露在互联网上，不如部署启用了MFA的VPN连接并针对特定需求对网络进行分段，而不是授予对广泛IP网络的访问权限。
