美国从来将不断强大CH变成自己的假想敌，在网络安全方面更是不断恶意中伤，越演越烈，我外交部多次就此类事件严正声明和抗议。眼下临近2020美国总统大选，美方面更是无所不用其极，总结并污蔑所有CH针对美国网络的威胁论调。红数位为了传递美方信息，让CH安全界了解动向并及时采取应对措施，部分文字使用关键字代替。



美网络安全与基础设施安全局（CISA）于美国时间10月1日发布警报（AA20-275A）提供具体的CH政府及相关网络威胁行为者的战术，技术和程序（TTP），并向网络安全社区建议缓解措施，用于协助保护美国的关键基础设施。


概要

除了本警报的缓解措施部分中列出的建议外，CISA还建议组织采取以下措施。


  • 采取提高意识的状态。最小化人员可用性的差距，持续消耗相关威胁情报，并更新紧急呼叫树。

  • 增强组织警惕性。确保安全人员监视关键的内部安全功能，并可以识别异常行为。标记任何已知的CH妥协指标（IOC）和TTP，以立即做出响应。

  • 确认报告过程。确保人员知道如何以及何时报告事件。组织的员工队伍和网络基础设施的健康状况取决于对威胁活动的了解。考虑将事件报告给CISA，以帮助其作为CISA预警系统的一部分（请参阅下面的“联系信息”部分）。

  • 行使组织的事件响应计划。确保人员熟悉事件中需要采取的关键步骤。他们有他们需要的访问权限吗？他们知道过程吗？各种数据源是否按预期记录？确保人员能够以冷静和统一的方式行事。


技术细节(CH=中国)

CH网络威胁简介

  • CH有利用国家军事和经济资源来利用进攻性网络战术追求国家利益的历史。

  • “CH制造2025”十年计划概述了CH的最高政策重点。

  • CH可能寻求针对以下对美国国家和经济利益至关重要的产业：新能源汽车，下一代信息技术（IT），生物技术，新材料，航空航天，海事工程和高科技船舶，铁路，机器人技术，动力设备和农业机械。

  • CH已行使其日益复杂的能力来非法获取美国知识产权（IP），压制对CH有害的社会和政治观点，并损害地区和国际对手。


美国情报共同体和各种私营部门威胁情报组织已将CH人民JF军（PLA）和国家|安全|部（M|SS）确定为CH政府支持的网络攻击的推动力-通过CH私营部门的承包商或PLA和MSS实体本身。CH继续从事与间|die活动有关的活动，包括盗窃创新资本，知识产权和个人身份信息（PII）等敏感信息。CH已表明愿意突破自己的活动界限，以获取对促进其经济实力和竞争优势至关重要的信息。


CH网络活动

根据开放源代码的报道，属于CH政府的进攻性网络运营以美国并将继续瞄准美国的各种行业和组织，包括医疗保健，金融服务，国防工业基地，能源，政府设施，化工，关键制造业（包括汽车和航空航天），通信，IT，国际贸易，教育，视频游戏，基于信仰的组织和律师事务所。


此外，几年来美国司法部（DOJ）的众多起诉提供了证据，表明CH威胁行动者不断寻求非法获取和渗入美国IP。他们的目标还包括在CH有业务的西方公司。


CH威胁行为者与一系列引人注目的攻击和进攻性网络活动联系起来的公开报道包括：


  • 2013年2月–网络威胁情报研究人员将高级持续威胁（APT）1与CH联系起来：一份全面的报告公开了APT1作CH军事网络运营的一部分，并经过多年努力，从20个主要行业的大约141家公司中窃取了IP。APT1建立了受害人网络的访问权限，并有条不紊地窃取了CH“十二五”规划确定的众多行业的知识产权。一年后，美国司法部首次起诉了分配给JF军第61398号BUDUI的CH网络威胁行为者（报告中也强调了这一点）。

  • 2017年4月–针对12个国家/地区的IP的CH|APT：CISA宣布，CH政府支持的APT开展了一项针对网络的IP盗窃多年活动，目标是全球技术服务提供商及其客户。威胁参与者利用被盗的管理凭据（本地和域）并将复杂的恶意软件放置在关键系统上，以窃取至少12个国家/地区的公司的IP和敏感数据。

  • 2018年12月–CH网络威胁行为者被指控损害托管服务提供商（MSP）：美国司法部起诉两名据信与APT10相关的CH网络威胁行为者，他们通过旨在窃取敏感业务数据的网络钓鱼和鱼叉活动针对MSP及其庞大的客户群，CISA还向利益相关者介绍了CH|APT团体，这些团体针对MSP及其客户窃取数据并进一步实施商业和经济间谍活动。

  • 2020年2月–CH|J方被控2017年Equifax Hack：美国司法部起诉CH人民JF军成员盗窃大量PII和IP。CH的网络威胁参与者利用公司争端解决网站中的漏洞进入网络，进行侦察，上传恶意软件并窃取凭据以提取目标数据。此次违规事件影响了大约一半的美国公民，并窃取了Equifax的商业机密。

  • 2020年5月–CH针对COVID-19研究组织：美国联邦调查局（FBI）和CISA报告了美国组织针对与CH有联系的网络参与者进行与COVID-19相关的研究的目标和妥协。大型密码从与COVID-19相关研究相关的网络和人员非法获得与疫苗，治疗和测试相关的IP时，喷洒运动是一种常见的策略。

系统网络配置发现[ T1016 ]

  • 监视进程和命令行自变量可以被对手用来收集系统和网络信息。

  • 这种技术很难通过预防控制来减轻。组织应专注于检测和响应恶意活动以限制影响。

命令和脚本解释器：Windows Command Shell [ T1059.003 ]

  • 确定系统上的正常脚本行为，然后监视进程和命令行参数是否存在可疑的脚本执行行为。

  • 仅允许执行签名的脚本。

  • 禁用所有未使用的shell或解释器。

     

用户执行：恶意文件[ T1204.002 ]

  • 监视可能被对手用来执行用户交互的应用程序（包括压缩应用程序）的命令行参数的执行。

  • 设置防病毒软件以检测在端点上下载并安装的恶意文档和文件。

  • 使用执行保护来防止伪装成其他文件的可执行文件运行。

  • 培训用户以识别网络钓鱼攻击和其他可能需要用户交互的恶意事件。

引导或登录自动启动执行：注册表运行项/启动文件夹[ T1547.001 ]

  • 监视开始文件夹中的添加和更改。

  • 监视注册表以查找与已知补丁或软件更新不相关的运行密钥的更改。

  • 这种技术很难通过预防控制来减轻。组织应专注于检测和响应恶意活动以限制影响。

命令和脚本解释器：PowerShell [ T1059.001 ]

  • 启用PowerShell日志记录。

  • 监视PowerShell执行策略中的更改，作为识别恶意使用PowerShell的一种方法。

  • 通常在通常不使用PowerShell的环境中监视PowerShell的执行情况。

  • 将PowerShell执行策略设置为仅执行签名的脚本。

  • 如果系统不需要，请禁用PowerShell。

  • 禁用WinRM服务以帮助防止将PowerShell用于远程执行。

  • 将PowerShell执行策略限制为管理员。

劫持执行流：DLL侧加载[ T1574.002 ]

  • 跟踪动态链接库（DLL）元数据，并将在进程执行时加载的DLL与以前的执行进行比较，以检测与修补无关的通常差异。

  • 使用该程序sxstrace.exe检查清单文件是否存在软件中的侧面加载漏洞。

  • 定期更新软件，包括DLL侧加载漏洞的修补程序。

入口工具转移[ T1105 ]

  • 监视意外的文件创建或文件从外部系统传输到网络的情况，这可能表明攻击者在受感染的环境中升级了工具。

  • 分析网络流量中是否存在异常数据流（即，客户端发送的数据比从服务器接收的数据多得多）。

  • 使用网络入侵检测和防御系统来识别特定对手恶意软件的流量或通过诸如文件传输协议之类的协议进行的异常数据传输。

远程系统发现[ T1018 ]

  • 监视进程和命令行参数以了解可采取哪些措施来收集系统和网络信息。

  • 在云环境中，结合使用命令和应用程序接口（API）来请求有关远程系统的信息以及其他意外命令的使用可能是恶意使用的迹象。

  • 这种技术很难通过预防控制来减轻。组织应专注于检测和响应恶意活动以限制影响。

软件部署工具[ T1072 ]

  • 确定第三方部署软件的典型使用模式，然后监视不规则的部署活动。

  • 使用组策略，多因素身份验证（MFA）和防火墙隔离关键的网络系统访问。

  • 定期修补部署系统。

  • 使用唯一且受限的凭据来访问部署系统。

蛮力：喷涂密码[ T1110.003 ]

  • 监视日志以查看对有效账户的身份验证尝试失败。

  • 使用MFA。

  • 尝试登录失败一定次数后，设置帐户锁定策略。

网络服务扫描[ T1046 ]

  • 使用NIDS识别扫描活动。

  • 关闭不必要的端口和服务。

  • 分割网络以保护关键服务器和设备。

电子邮件收集[ T1114 ]

  • 监视进程和命令行参数以了解可以采取哪些措施来收集本地电子邮件文件。

  • 加密敏感电子邮件。

  • 定期审核自动转发电子邮件规则。

  • 将MFA用于面向公众的Webmail服务器。

代理：外部代理[ T1090.002 ]

  • 分析网络数据中不常见的数据流，例如，客户端发送的数据要比从外部服务器接收的数据多得多。

  • 使用NIDS和预防系统通过网络签名识别特定攻击者恶意软件的流量。

偷渡妥协[ T1189 ]

  • 使用防火墙和代理检查URL，以了解潜在的已知坏域或参数。

  • 监视网络入侵检测系统（IDS）以检测恶意脚本，并监视端点的异常行为。

 

  • 隔离并沙盒影响系统和应用程序，以限制恶意软件的传播。

  • 利用安全应用程序来识别利用过程中的恶意行为。

  • 通过广告拦截器和脚本拦截扩展来限制基于Web的内容。

服务器软件组件：Web Shell [ T1505.003 ]

  • 分析身份验证日志，文件，netflow / enclave netflow，并利用过程监视来发现异常活动。

  • 面向Internet的应用程序中的修补程序漏洞。

  • 利用文件完整性监视来识别文件更改。

  • 配置服务器以通过最小特权原则阻止对Web可访问目录的访问。

应用层协议：文件传输协议[ T1071.002 ]和DNS [ T1071.004 ]

  • 分析网络数据中不常见的数据流（例如，客户端发送的数据比从服务器接收的数据多得多）。

  • 分析数据包内容以检测未遵循有关语法，结构或任何其他可变对手可能无法利用的预期协议标准的应用层协议，以隐藏数据。

  • 利用网络签名利用NIDS和NIPS来识别特定对手恶意软件的流量。



其他APT活动

上面列出的TTP已在CH威胁行为者的各个领域中反复使用。此警报中引用的缓解措施可以帮助减少这些TTP的脆弱性；但是，捍卫者还应提高对威胁行为者的认识，这些威胁行为者的做法更具创新性，因此很难发现和应对威胁。公开报道的示例\包括：


  • APT3（称为UPS Team）以部署针对Internet Explorer，Firefox和Adobe Flash Player的零日攻击而闻名。该小组的自定义植入物和不断变化的命令与控制（C2）基础结构使其难以跟踪。APT3漏洞利用Rivest Cypher 4（RC4）加密，通过使用面向返回的编程（ROP）链来通信和绕过地址空间布局随机化（ASLR）/数据执行保护（DEP）。

  • APT10（称为MenuPass组）已通过受感染的服务提供商建立了对受害者网络的访问权限，这使得网络防御者很难识别恶意流量。

  • APT19（称为Codoso和Deep Panda）以开发自定义的RTF格式（RTF）和启用宏的Microsoft Office文档（用于植入物和有效载荷）而闻名。该小组拥有后门软件，例如软件串行生成器，并且通过超文本传输协议（HTTP）/安全超文本传输协议（HTTPS）精通使用PowerShell for C2。

  • APT40（称为Leviathan）已成功针对外部基础设施，包括面向Internet的路由器和虚拟专用网络。

  • APT41（称为Double Dragon）已利用Citrix NetScaler / ADC，Cisco路由器和Zoho ManageEngine Desktop Central中的漏洞来危害受害者。


缓解措施

建议措施

下表为IT安全专业人员提供了可行的技术建议，以减少其组织的总体漏洞。这些建议并不详尽。相反，他们专注于将大大减少利益相关者的攻击面的行动。

  1. 及时而勤奋地修补系统和设备。建立并始终保持一个完整的补丁程序周期仍然是抵御恶意TTP的最佳方法。专注于修补关键漏洞和高漏洞，这些漏洞允许在面向外部（即，互联网）的设备上远程执行代码或拒绝服务。某些漏洞（包括Microsoft产品中的CVE-2012-0158 [ 17 ]，Citrix设备中的CVE-2019-19781 [ 18 ]和BIG-IP流量管理用户界面[ 19 ]中的CVE-2020-5902 ）已经向APT提出了以下漏洞：主要目标以获得初步访问权限。CH的APT经常使用现有的漏洞利用代码来锁定常规利用的漏洞[ 20），这是需要有限资源的机会主义攻击。有关CH|APT经常利用的CVE的补丁程序信息，请参见表3。


  2. 实施严格的配置管理程序。审核配置管理程序，以确保它们可以跟踪和缓解新出现的威胁。查看系统配置以了解配置错误和安全漏洞。实施强大的配置和补丁程序管理程序会限制机会性攻击的有效性，从而阻碍了复杂的APT操作。


  3. 禁用不必要的端口，协议和服务。查看网络安全设备日志，并确定是否关闭不必要的端口和协议。监视公共端口和协议的C2活动。关闭或禁用设备内任何不必要的服务或功能（例如，通用即插即用[UPnP]，PowerShell）。


  4. 增强对网络和电子邮件流量的监视。查看网络签名和指示符以进行有针对性的操作活动，监视新的网络钓鱼主题，并相应地调整电子邮件规则。遵循通过电子邮件限制附件的最佳做法。确保汇总和关联日志信息以实现最大的检测功能，重点是监视帐户滥用情况。


  5. 使用保护功能来阻止恶意活动。实施防病毒软件和其他端点保护功能，以自动检测并阻止恶意文件的执行。使用网络入侵检测和预防系统来识别和预防常用的对抗性恶意软件，并限制有害的数据传输。


编者按

气势汹汹的抹黑


　　就网络威胁而言，美国不管打什么幌子，都遮不住其在网络空间实施霸权行径的事实。美国在网络领域的军事实力首屈一指、有目共睹，美国也是目前世界上唯一公开承认正对别国采取网络战行动的国家，曾利用“震网”蠕虫病毒攻击伊朗的铀浓缩设备。这样一个执著追求网络霸权的国家，在网络安全问题上对中国横加指责怎能让人信服？更何况美国打出的“中国威胁论”幌子，细看之下倒更反映出美方的无理，因为事实上中国是遭受网络攻击最严重的国家之一。


客观而言，网络攻击具有跨国性、匿名性和欺骗性等特点，要找出那些真正作恶的黑客是一个全球性难题。在这个问题上，中国等发展中国家面临的网络安全威胁远比发达国家更大、更多。


自欺欺人的把戏


　　一提到黑客就言必称中国，而西方的机构和企业永远是“无辜的绵羊”。但众所周知，网络黑客攻击是国际社会和各国政府面临的共同难题，仅凭一些捕风捉影的猜测和单方面的所谓调查就妄下结论是不严肃的。中国网络技术发展与西方相比仍有较大差距。事实上，中国非但不是西方媒体口中的“黑客大本营”，反而还是网络攻击的主要受害国之一。


　　当前美西方深陷金融债务危机，诬告中国经济发展靠“窃取”西方所谓商业机密，或许会使他们心里好过一些，还能为向中国打“贸易战”、制定不公平国际规则等拼凑口实。但这也无异于自欺欺人。


应该“摘掉眼镜”


　　长期以来，美西方习惯于戴着“有色眼镜”看中国。除“网络威胁论”外，西方还频繁炒作各式各样的“中国资源威胁论”、“中国投资威胁论”、“中国军事威胁论”等等，企图将中国形象“妖魔化”，为遏制中国发展壮大寻找理由，从而达到某些国内政治目的。包括最近还有德国媒体污蔑3万在德华人都是中国的工业间DIE，其数据和事实之歪曲，恐怕连编造者自己都难以相信。


　　网络安全关系一国的政治、经济、军事乃至个人生活安全，日益成为全球治理的重要议题。网络空间需要的不是战争，而是规则与合作。中国政府一直高度重视网络安全问题，积极参与网络领域的国际合作。


　　如果西方国家真的那么关心网络安全，现在就应该“摘掉眼镜”，停止对中国的不实指责，而改用一种更专业和建设性的态度，来与包括中国在内的国际社会一道研究加强网络安全领域的国际合作。
