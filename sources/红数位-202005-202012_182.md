# 哈佛发布2020年国家网络能力指数

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247492240&idx=4&sn=050a57707a1dc9f5836612b43c1eb3ee&chksm=cef08f23f98706356b766db4b86ebd4142c4354783a782f2be10028555cc84ff06b212387030&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247492240&idx=4&sn=050a57707a1dc9f5836612b43c1eb3ee&chksm=cef08f23f98706356b766db4b86ebd4142c4354783a782f2be10028555cc84ff06b212387030&scene=27#wechat_redirect)

哈佛大学贝尔弗科学与国际事务中心**(以下简称贝尔弗)发布2020年**国家网络能力指数（NCPI），在32个意图指标和27个能力指标以及从公开数据中收集的证据的基础上，根据七个国家目标来衡量30个国家的网络能力。

  

![](../Images/f90b4a61fbf40446120fe4cfc99b6266.png)

  

与现有的网络相关指数相比，他们认为没有单一的网络能力指标。网络力量由多个部分组成，应在一个国家的国家目标范围内加以考虑。他们采用全球性方法来衡量网络能力。通过考虑“所有国家”，他们尽可能将所有方面纳入政府的控制之下。在NCPI中，评估政府的战略，防御和进攻的能力，资源分配，私营部门，劳动力和创新能力。评估是对已证明的能力和潜力的衡量，最终得分是假设该国政府可以有效地运用这些能力。

  

NCPI确定了各国使用网络手段追求的七个国家目标。

  

七个目标是：

1.  监视和监测国内团体；
    
2.  加强和加强国家网络防御；
    
3.  控制和操纵信息环境；
    
4.  国家安全外国情报收集；
    
5.  商业收益或促进国内产业增长；
    
6.  破坏或破坏对手的基础设施和能力；
    
7.  定义国际网络规范和技术标准。
    

  

与普遍认为网络力量意味着破坏或破坏对手的基础设施（通常称为进攻性网络行动）相反，犯罪只是国家使用网络手段追求的七个目标之一。

  

NCPI总体评估衡量一个国家作为网络参与者的“综合性”。在NCPI的背景下，全面性是指一国使用网络实现多个目标而不是几个目标。最全面的网络力量是指拥有（1）使用网络手段追求多个国家目标的意图和（2）实现这些目标的能力的国家。

  

![](../Images/c6f4486eba172e34659996eefb88dc19.png)

  

**NCPI 2020涵盖所有七个目标的最全面的网络力量从第1位到第10位：美国，中国，英国，俄罗斯，荷兰，法国，德国，加拿大，日本，澳大利亚。**

  

他们提出了三个不同的指标。

*   NCPI
    
*   网络意图指数（CII）
    
*   网络能力指数（CCI）
    

  
CII和CCI都是独立的措施。NCPI是CII和CCI的组合。

  

国家网络目标并不是孤立地构成的：网络能力只是一系列工具之一，即与传统的军事手段，外交，公共政策，惩罚性措施和贸易政策一起，各国可以用来实现其国家目标。

  

NCPI建立在现有数据库上，这些数据库测量网络力量的特定元素，并将此数据与内部来源的多个指标进行核对。他们的数据分析遵循严格的方法和程序，所有方法和程序均可应要求提供。

  

他们使用自然语言处理验证了对国家网络策略的分析。将NCPI综合指标与相关的可衡量现象（相似的综合指标，但也包括相关的数量，例如GDP /人均，国际电信联盟网络安全指数等）相关联，以识别相似或不同之处。

  

网络意图指数反映了一些国家在制定具体目标时所采用的不同优先顺序，因此，在其网络能力概念化方面比其他国家更为重要。

  

对于朝鲜，他们找不到索引中列出的许多功能的可靠度量。因此，他们已请几位专家就与朝鲜有关的各种能力向他们提供评估，以告知NCPI。研究人员和从业人员应记住，与该指数中的其他国家相比，**朝鲜在参考其NCPI分数时是一个特例。**

  

他们使用了Min-Max归一化技术来重新调整网络能力指标，因为它：

（1）最好地反映了我们的概念框架；

（2）最适合数据属性；

（3）易于用户理解。

  

我们公式的意图部分可以认为等同于权重。

  

研究人员和从业人员应使用NCPI对组成网络力量的组件以及如何利用网络手段实现一系列目标有更全面的了解。对特定国家目标感兴趣的用户可以通过意图和能力分析NCPI，以更好地了解他们感兴趣的国家。

  

在本文中，他们将NCPI与现有的与网络相关的指标进行了对比，概述了他们的概念框架，提供了有关如何解释我们的发现，提供评分意图，功能和综合指标的方法的指南，列出了我们使用的来源，并提供了概述我们方法的局限性。

  

NCPI的目的是扩大对网络力量的讨论，以反映它可以用于实现除破坏性能力之外的功能，并且它是政府实现多个目标的重要工具。我们认为，需要围绕国家网络目标和能力进一步提高透明度，以制定更相关和有效的政策并防止国家之间的危险升级。我们希望NCPI有助于推动有关网络能力和提高功能透明度的实用性的讨论。
