# 现代和起亚警告：车要停在室外！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247492100&idx=3&sn=cf3d81fc1d86996068058d973dc6da23&chksm=cef08fb7f98706a10f74c799cb4cadeafcf8eddda076f2c310a676f37a7d0d54a11f39846afd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247492100&idx=3&sn=cf3d81fc1d86996068058d973dc6da23&chksm=cef08fb7f98706a10f74c799cb4cadeafcf8eddda076f2c310a676f37a7d0d54a11f39846afd&scene=27#wechat_redirect)

**现代汽车本月第二次告诉一些SUV车主将车停在户外，因为计算机的电气短路可能会导致车辆着火。**

  

![](../Images/c63a8661e02e06a321667c73c944794d.png)

  

为了解决这个问题，**这家韩国汽车制造商从2019年到2021年在美国召回了约18万辆图森SUV。**该公司表示，**腐蚀可能会导致防抱死制动电路板短路，即使发动机关闭也可能引起火灾。**  

  

**现代汽车周五说，它知道有十二起发动机起火是由该问题引起的，但没有人员受伤。**

  

此外，现代汽车表示，如果防抱死制动警告灯亮起，则不应驾驶SUV，车主应断开电池上的正极电缆。他们应联系经销商，经销商将在需要时提供代步工具。

  

另外，**起亚隶属于现代，起亚也召回了9,000多辆配备3.3升涡轮增压发动机的Stinger索伦托斯跑车，以解决类似问题。**美国安全监管机构发布的文件说，防抱死制动控制计算机区域可能发生火灾。

  

![](../Images/59682d09412e05f7edb9e9450a9be4bf.png)

  

起亚周五在一份声明中说，它有六起火灾报告，没有人员伤亡。声明说，**该公司说虽没有关闭发动机后发生火灾的报道，但仍建议将其停放在室外，直到进行维修为止，火灾原因尚不清楚。**

  

此次召回是困扰这两家汽车制造商的一系列发动机起火问题中的最新问题，并引发了美国国家公路交通安全管理局的调查。

  

**现代汽车将从10月30日左右通过邮件通知召回车主。在此期间，车主可以在www.hyundaiusa.com/recalls上键入其17位车辆识别号，以查看其图森是否受到影响。**

  

该汽车制造商表示，正在调查其他国家是否也发生了同样的问题。

  

9月3日，**美国安全监管机构宣布，现代和起亚将在美国和加拿大召回超过60万辆汽车，以修复可能导致发动机起火的制动液泄漏。**

  

这些召回与Tuscon召回无关。它们涵盖了2013年至2015年的440,000多辆起亚Optima中型轿车以及2014年和2015年的起亚Sorento SUV。还涵盖了2013年至2015年的203,000辆现代圣达菲SUV。

  

一天后，**现代汽车表示建议将车辆停在室外，直到问题解决。**起亚本周五说，**索伦托斯跑车应该停在户外。**

  

2月，现代汽车因类似问题召回了近430,000辆小型汽车。该公司表示，**水可能进入防抱死制动的计算机，导致电路短路甚至可能引起发动机起火。**此次召回涉及某些2006年至2011年伊兰特和2007年至2011年伊兰特旅行车。

  

**该公司表示，即使关闭汽车，电气短路也可能引起火灾。**

  

2019年4月，美国国家公路交通安全管理局（NHTSA）在接到涉及3,100起大火和103人受伤的投诉后，对涉及现代和起亚汽车的大火展开了两项新调查。

  

这项调查是针对现代的，另一项针对起亚的调查涵盖了来自相关汽车制造商的近300万辆汽车的非撞车大火。

  

该机构批准了一项由消费者权益保护组织非营利性汽车安全中心（Center for Auto Safety）进行调查的请愿书。

  

该中心执行主任杰森·莱文（Jason Levine）周五表示，召回事件表明，美国国家公路交通安全管理局（NHTSA）和汽车制造商应监视并认真对待消费者的投诉。

  

莱文说：“对新车型的召回最终使人们回想起了现代起火的流行只发生在他们的旧车上，他们解决了这个问题。”

  

NHTSA此前曾表示将把非碰撞大火纳入2017年的调查中，该调查检查了现代和起亚汽车召回的发动机故障。它“基于该机构对从多个制造商处获得的信息，消费者投诉和其他来源的信息进行的分析”开启了新的调查。

  

**根据美国国家公路交通安全管理局（NHTSA）的文件，自2015年以来，现代和起亚的发动机故障和起火问题已影响超过600万辆汽车。**

  

现代汽车在一份声明中说，当发现安全缺陷时，他们已召回车辆。

  

该公司表示：“我们一直在评估来自各种来源的数据，当我们确定有必要保护业主的安全时，会毫不犹豫地进行或扩大召回范围。”
