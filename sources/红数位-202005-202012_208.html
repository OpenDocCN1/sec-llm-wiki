比特梵德误杀Windows10更新补丁

微软作为2020年9月补丁周二发布为Windows 10系统发布的累积更新之一被Bitdefender的防病毒引擎错误地标记为潜在威胁。



KB4574727是Microsoft于9月8日发布的针对Windows 10版本1903和1909的累积更新，重点解决操作系统和内置组件的安全漏洞。从本质上讲，KB4574727是重要的安全更新，显然，建议用户尽快安装，尤其是因为它可以解决Microsoft操作系统中的漏洞：


  • 解决了用户代理和基于HTTP的Intranet服务器的安全漏洞问题。安装此更新后，默认情况下，基于HTTP的Intranet服务器无法利用用户代理来检测更新。如果客户端没有配置的系统代理，使用这些服务器的扫描将失败。如果必须利用用户代理，则必须使用Windows Update策略“如果使用系统代理检测失败，则允许用户代理用作后备”来配置行为。此更改不会影响使用传输层安全性（TLS）或安全套接字层（SSL）协议保护Windows Server Update Services（WSUS）服务器安全的客户。有关详细信息，请参阅  确保客户端安全，更改对Windows Server Update Service（WSUS）服务器的扫描。

  • Windows App平台和框架，Microsoft图形组件，Windows输入和合成，Windows Media，Windows Shell，Windows云基础结构，Windows基础知识，Windows管理，Windows内核，Windows虚拟化，Microsoft脚本引擎和Microsoft JET数据库的安全更新发动机。

  • Windows执行基本操作时进行更新以提高安全性。

  • 更新以提高使用输入设备（例如鼠标，键盘或笔）时的安全性。

  • 更新以提高使用Microsoft Office产品时的安全性。


但是，正如某些用户想出的办法一样，如果他们正在运行Bitdefender安全软件，则无法在其设备上安装更新。防病毒引擎错误地将KB4574727标记为潜在威胁，尽管确实从Windows Update下载了此更新，但在重新启动设备以完成安装补丁过程时，Bitdefender将阻止补丁安装，系统随后会在不安装更新的情况下引导回到桌面。



Bitdefender安全软件在受影响的Windows 10设备上显示以下错误：


Trojan.Ciusky.Gen.13 

感染

\Device\HarddiskVolume4\WINDOWS\SoftwareDistribution\Download\ 021b4073b65a625a58c006858ea0a97d\Windows10.0-KB4574727-x64.cab文件

该威胁已被成功阻止，您的设备是安全的。


解决此问题的最简单方法是在Bitdefender软件上为此Windows更新配置一个例外，从而避免Bitdefender防病毒引擎隔离文件。


其他用户试图从Microsoft更新目录下载更新，并尝试手动安装补丁。但是，考虑到Bitdefender在启动安装时（在文件已下载之后）会发出误报，因此此方法并不能解决问题。因此，即使在手动下载更新的情况下，防病毒引擎也会阻止安装。



毫无疑问，微软发布的更新是完全安全且干净的，对于下载它的Windows 10设备没有风险。换句话说，尽管有Bitdefender警告，您仍可以安全地将其安装在计算机上，因为没有特洛伊木马实际上安装到你的电脑。


可想而知，Bitdefender将更新病毒定义，以消除Windows Update提供了更新且其防病毒引擎处于活动状态的设备上显示的误报。安装此防病毒更新后，警告应不再显示。


同时，好消息是Windows 10累积更新KB4574727似乎可以在大多数设备上正确安装。最近半年Windows 10用户发现累积更新的体验通常像俄罗斯轮盘赌，尽管Microsoft最初不承认任何问题，但他们最终在设备上造成了严重破坏。


对比来说，累积更新无法安装相对好些，因为在某些情况下，它们最终会破坏操作系统中的某些功能。这就是某些用户决定每月尽可能长时间推迟更新过程的原因，尽管微软不建议这样做，因为通常包括关键的安全修复程序。


安装KB4574727后，Windows10版本1903版本号将增加到18362.1082，而Windows 10版本1909内部版本号将达到18363.1082。
