# Microsoft Defender惊现任意下载漏洞，自身能被下载恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247491698&idx=5&sn=799133c9c63b49419d5b5ce85c0f0d3c&chksm=cef08dc1f98704d740d34cd12ff4c09a89d7519918095e1ab20ef36c365821b02cb75c1a65d1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247491698&idx=5&sn=799133c9c63b49419d5b5ce85c0f0d3c&chksm=cef08dc1f98704d740d34cd12ff4c09a89d7519918095e1ab20ef36c365821b02cb75c1a65d1&scene=27#wechat_redirect)

Microsoft Defender，以前称为Windows Defender，是Windows 10附带的防病毒解决方案，为安装Microsoft桌面操作系统的每个用户提供默认保护。

  

![](../Images/aee4ef2b0d832aca41c56b3dafa1231f.png)

  

最新的防病毒测试表明，Microsoft Defender提供的恶意软件检测和清除功能与您今天在第三方产品中可以找到的功能相当，因此很容易看到为什么越来越多的人坚持使用默认的防病毒引擎Windows 10。

  

但这并不一定意味着一切都绝对无瑕，Microsoft AntiMalware Service命令行实用程序（也称为MpCmdRun.exe）可能需要进一步完善。

  

**虽然仍然检测到恶意软件**

正如安全研究员Mohammad Askar发现并由BC报道，**Microsoft最近更新了命令行实用程序，错误地为简单的漏洞利用打开了方便之门，该漏洞使得可以从远程位置下载文件。**

![](../Images/ce39f7b85a6170760226f049f1678135.png)

![](../Images/b7aa1f5837ac75e537950bbd68bc164e.png)

  

而且，**此远程存储的文件可以是任何文件，从合法文件到恶意软件，事实证明，绝对有可能下载恶意负载。**

  

另一方面，**虽然确实可以使用命令行工具来下载受感染的文件，但Microsoft Defender仍会扫描下载的内容，****但是微软扫描率不是100%导致风险增加**。

  

**防止任何利用的最简单方法是仅阻止MpCmdRun.exe连接到远程位置，IT管理员可以设置防火墙规则以限制Internet访问。**

  

在类似的方面，Microsoft最近确认已删除了一个注册表黑客，该操作允许黑客在其Windows 10设备上禁用Microsoft Defender，并解释说此方法是多余的，[Microsoft Defender再难注册表关闭](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247491250&idx=3&sn=1cbe46892ddcfe5667cc3a85c09a9b04&chksm=cef37301f984fa17e164c6ec4aff51f728176c62f6b8d6d12519ead3b828947bfa281e047649&scene=21#wechat_redirect) 。因为在部署第三方安全产品时防病毒本身也会关闭在电脑上面的Defender。
