# 适用于安卓手机最佳防病毒软件

尽管许多人仍然认为，始终可以从各种国内市场（程序都经过安卓市场检测病毒）和Google Play商店下载应用程序以在Android驱动器上保持受保护。但安全专家仍然建议安装专用的软件解决方案，以检测恶意软件和恶意应用程序。

  

![](../Images/1ac31529e927e3ff59fbb85ff0c32225.png)

  

就像在Windows上发生的一样，要找到一款能够完成所有任务的Android安全产品，就很难了，尤其是因为几乎所有供应商都向您保证可以保证安全。

  

防病毒测试实验室AV-TEST已进行了为期六个月的耐用性测试，以确定与Android 本身提供的检测Google Play商店应用中的恶意软件的解决方案Google Play Protect 相比，当前针对Android的安全产品到底有多先进。

  

该研究是在Android 8.0上进行的，并且测试了以下供应商的应用程序：  

  

*   **AhnLab**
    
*   **Avast**
    
*   **AVG**
    
*   **Avira小红伞**
    
*   **Bitdefender比特梵德**
    
*   **F-Secure芬安全**
    
*   **G Data  歌德塔**
    
*   **Ikarus**
    
*   **Kaspersky卡巴斯基**
    
*   **McAfee迈克菲**
    
*   **NortonLifeLock诺顿**
    
*   **securiON**
    
*   **Trend Micro趋势科技**
    

  

根据AV-TEST的典型测试，防病毒解决方案在三个不同类别中进行了测试，即保护，性能和可用性。每个产品的最高分数是每次测试六个月，这意味着在所有测试中均能完美执行的安全解决方案获得18分。

  

![](../Images/4d7a17278402114c244b3ad5e5505e7a.png)

  

从总体上看，有几个安全解决方案获得了最高分，如下所示：  

  

*   **Avira Antivirus Security     小红伞**
    
*   **Bitdefender Mobile Security  比特梵德**
    
*   **G Data Internet Security     歌德塔**
    
*   **NortonLifeLock Norton 360    诺顿360**
    
*   **Trend Micro Mobile Security  趋势科技**
    

  

  

**所有这些解决方案均获得6分保护，6分性能和6分可用性。**

  

**Google Play Protect提供了最差的保护，它是测试的基准，但是它仅获得6分的性能。**

  

但是，**在第三方产品方面，Avast Mobile Security和AVG Antivirus Free得分最低，因为它们获得的最终评分为15.4分–两者共享同一引擎，因此在Android设备上提供相似的性能。**

  

就Google Play保护而言，AV-TEST明确表明，如果要在Android设备上保持受保护的地位，则不应依赖它。

  

测试包括10,000个新感染的应用程序以及10,000个旧的和现有感染的应用程序的参考集，其中Google Play Protect甚至无法检测到已知威胁。

  

“ Google的结果令人震惊：在整个测试期间，Google Play Protect的实时测试平均检测率为64.6％。该参考集最多只能检测到45.4％。提醒您：这些是较旧的，大多为知名的恶意软件应用程序。以四舍五入的数字表示，在测试中，Google Play Protect丢失了大约3500至5500个包含隐藏恶意软件的应用程序。” AV-TEST表示。

  

更糟糕的是，对于从Google Play商店安装的应用，Google Play保护已向用户发送虚假警报的垃圾邮件。

  

“在整个测试期间，其中涉及Play商店中的6,000多种无害应用，以及其他来源中的近2500种其他无害应用。结果令人惊讶：在测试中，Play Protect在源自其自家商店的无害应用程序上触发了近50次错误警报。此外，还有来自其他来源的应用程序将近80个其他虚假警报。这就是为什么在耐久测试中，在可用性类别中没有给Google Play Protect奖励积分的原因。” AV-TEST表示。

  

归根结底，Android安全产品已成为许多用户的必备工具。但是同时，还有其他几种方法可以确保您不下载受感染的应用程序。

  

首先，坚持使用Google Play商店确实是一个好主意。然后，在点击下载按钮之前，请确保您始终选中“评论”部分，因为用户通常会返回Google Play商店以抱怨他们可能遇到的任何问题。当然，请避免下载评级较低的应用程序，因为这可能表明该应用程序存在问题。
