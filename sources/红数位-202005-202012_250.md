# 程序员离职后一段代码让公司损失1600万

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247491479&idx=1&sn=23078c804ce5b376087638d23a758d8f&chksm=cef37224f984fb32963fcf676e12227428708cbe34a14d43adfec65e6934978b1485921e779c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247491479&idx=1&sn=23078c804ce5b376087638d23a758d8f&chksm=cef37224f984fb32963fcf676e12227428708cbe34a14d43adfec65e6934978b1485921e779c&scene=27#wechat_redirect)

据外媒报道，**思科的一位程序员在离职后入侵思科代码库，一段代码导致思科损失了超过240万美元（1600万人民币+）**。

![](../Images/52c89487f69660cfe343d365d1e970e5.png)

思科前员工Sudhish Kasaba Ramesh已在圣何塞联邦法院认罪，承认自己非法入侵思科的云基础设施，并破坏大量资源。

Sudhish Kasaba Ramesh在思科供职不到两年，2016年7月入职，2018年4月离职。

2018年9月24日，在离职五个月后，Ramesh在未经许可的情况下，擅自访问思科托管在Amazon网络服务平台上的云基础设施。

他利用自己的Google Cloud Project账户**在思科代码库中部署了一段代码，导致456个WebEx Teams应用程序的虚拟机被删除**。

WebEx Teams是思科旗下一款受欢迎的协作办公软件，该应用程序提供视频会议、视频消息、文件共享和其他协作工具等。

![](../Images/9f15a18dcb198ad211fb5909e9404819.png)

Ramesh的行为导致超过1.6万个WebEx Teams帐户被关闭长达两周，**思科花费了约140万美元来修复程序，并向受影响的客户退款超过100万美元**。**损失了超过240万美元（1600万人民币+）**。

幸运的是，此次事件没有造成客户数据泄露。

思科表示，吃一堑长一智，今后会防止此类事件再次发生。

Ramesh于2020年7月13日被正式指控，目前已保释。拉梅什面临长达五年的监禁和高达25万美元的罚款。量刑听证会定于2020年12月9日。
