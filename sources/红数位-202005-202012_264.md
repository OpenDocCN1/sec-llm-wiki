# “危险的勒索软件”，顺便diss下国内安全

**自从2017年**5月12日，全球爆发的勒索病毒WannaCry借助高危漏洞“永恒之蓝”（EternalBlue）在世界范围内爆发，据报道包括美国、英国、中国、俄罗斯、西班牙、意大利、越南等百余个国家均遭受大规模攻击。我国的许多行业机构和大型企业也被攻击，有的单位甚至“全军覆没”，损失之严重为近年来所罕见。

  

![](../Images/7fa5dbb790f28c71a5da1c2ef11216e4.png)

  

自此**勒索软件**变成了家喻户晓的名词。

  

**今天我们来聊聊面向企业部门的勒索软件攻击在2020年上半年创下历史新高。**

尽管每个勒索软件组织都基于各自的技能，但2020年上半年的大多数勒索软件事件可归因于这帮人今年似乎优先考虑的少数入侵媒介。

  

最流行的三种入侵方法包括：

*   **不安全的RDP端点**
    
*   **电子邮件网络钓鱼**
    
*   **对公司VPN设备的利用**
    

  

**RDP-利用名单上的第一名**

我们所有公司几乎都用到微软远程桌面协议（RDP）。

  

**RDP**是Microsoft开发的一种网络通信协议。它可用于大多数Windows操作系统，并提供图形界面，**使用户可以远程连接到服务器或另一台计算机。**RDP将远程服务器的显示传输到客户端，并将外围设备（例如键盘和鼠标）的输入从客户端传输到远程服务器，有效地使用户可以像亲自操作一样控制远程计算机。

  

![](../Images/8443eed324341767a5900ced7356d003.png)

RDP-可使用mstsc命名运行  

  

RDP通常用于商业环境中，以允许最终用户远程访问组织的本地网络上存储的文件和应用程序。管理员通常还使用RDP远程诊断和解决最终用户设备的技术问题。

  

从国外Coveware公司、Emsisoft公司和Recordedfuture公司综合发布的报告中明确提出**RDP仍是目前最流行的入侵载体和最勒索事件在2020年的来源。**

![](../Images/2825e0f61a563d1af842df30c6bf54ab.png)

自2020年勒索团体市场份额

  

网络安全公司Emsisoft上个月表示：**“今天，RDP被视为勒索软件的最大攻击媒介。**”

  

提供勒索软件事件响应和勒索协商服务的公司Coveware的统计数据也表达了该评估；该公司将RDP坚定地列为今年调查的勒索软件事件的最受欢迎入口点。

  

![](../Images/43467ab65c79d94884be644ca07e739c.png)

图片：Coveware  

  

此外，来自威胁情报公司Recorded Future的数据也使RDP稳居榜首。

  

Recorded Future威胁情报分析师Allan Liska在上次发布的报告中写道：**“远程桌面协议（RDP）目前存在很大差距，这是威胁参与者用来访问Windows计算机并安装勒索软件和其他恶意软件的最常见攻击媒介。”**一周有关勒索软件对美国大选基础设施的危害。

  

![](../Images/9f48bd7d4299c0cf55f45dddf891f650.png)

图片：Recorded Future  

  

**自去年以来，RDP一直是勒索软件帮派的最大入侵媒介，当时勒索软件帮派基本停止瞄准家庭消费者，而将目标转向公司。**  

  

***RDP是当今用于连接远程系统的顶级技术，并且有数百万台RDP端口在线暴露的计算机，这使RDP成为对各种网络犯罪分子的巨大攻击媒介，而不仅仅是勒索软件帮派。***

  

***今天，我们有专门负责扫描Internet上RDP终结点，然后对这些系统进行暴力攻击的网络犯罪组织，以试图猜测被入侵机器设备的密码凭据。***

  

***使用弱用户名和密码组合的系统会遭到入侵，然后在所谓的“ RDP商店”中出售，各种网络犯罪集团从那里购买它们。***

  

***RDP商店已经存在多年了，它们并不是什么新鲜事物。***

入侵网络公开的RDP系统，该过程通常如下所示：

  

1.  **扫描暴露的RDP端口：攻击者使用免费的，易于使用的端口扫描工具（例如Shodan）来扫描整个Internet，以查找暴露的RDP端口。**
    
      
    
2.  **尝试登录：攻击者尝试使用可以在黑市上购买的被盗凭证来获得对系统的访问权限（通常以管理员身份），或更常见的是，暴力破解工具会系统地尝试使用每种可能的字符组合进行登录直到找到正确的用户名和密码。**
    
      
    
3.  **禁用安全系统：一旦攻击者获得对目标系统的访问权限，他们就会着眼于使网络尽可能不安全。根据受损帐户的特权，这可能涉及禁用防病毒软件，删除备份以及更改通常被锁定的配置设置。**
    
      
    
4.  **交付有效负载：在安全系统被禁用并且网络容易受到攻击之后，就可以交付有效负载。这可能涉及在网络上安装勒索软件，部署键盘记录程序，使用受感染的计算机分发垃圾邮件，窃取敏感数据或安装可用于将来攻击的后门程序。**
    

  

  

但是，随着勒索软件组织去年从针对家庭消费者的企业迁移到企业，勒索软件帮派在这些商店中发现了易于获得的易受攻击的RDP系统库，出现天壤之别。

  

**如今，勒索软件团伙是RDP商店的最大客户，一些商店运营商甚至关闭了他们的商店，专门与勒索软件团伙合作，或者成为了勒索软件即服务（RaaS）门户的客户，入侵了RDP系统本身，以通过其勒索软件获利。**

  

**VPN设备-新的RDP**

但是到2020年，又出现了另一种主要的勒索软件入侵媒介，即使用VPN和其他类似网络设备进入公司网络。

  

**自2019年夏季以来，当今全球顶级公司的VPN设备中已披露了多个严重漏洞，包括**

*   **Pulse Secure 保思安**
    
*   **Palo Alto Networks 派拓网络**
    
*   **Fortinet 飞塔**
    
*   **Citrix 思杰**
    
*   **Secureworks**
    
*   **F5**
    

  

一旦针对这些漏洞中的任何一个公开了概念验证漏洞利用代码，黑客组织便开始利用这些漏洞来访问公司网络。黑客对此访问权限的处理方式各不相同，具体取决于每个小组的专业程度。

  

**一些APT团体从事国家级的网络间谍活动，一些黑客团体从事金融犯罪和知识产权盗窃，而其他团体则采取“ RDP商店”盈利方法，然后将其转售给其他帮派。**

  

**去年报告了使用此媒介的一些稀疏勒索软件事件，但到了2020年，我们看到越来越多的勒索软件组使用被入侵的VPN设备作为进入企业网络的入口。**

  

根据SenseCy上周发布的一份报告，在2020年期间，VPN迅速成为勒索软件帮派中新的热门攻击媒介，Citrix网络网关和Pulse Secure VPN服务器成为他们的最爱目标  。

  

根据SenseCy，已经看到像REvil（Sodinokibi），Ragnarok，DoppelPaymer，Maze，CLOP和Nefilim之类的帮派使用易受漏洞CVE-2019-19781攻击的Citrix系统作为攻击的切入点。

  

![](../Images/fa7d3154ab17ae5c048bfbcfd8ffde92.png)

图片：Recorded Future

  

**同样，SenseCy表示，REvil和Black Kingdom等勒索软件组织已利用未针对漏洞CVE-2019-11510进行补丁的Pulse Secure VPN攻击其目标。**

  

根据“记录的未来”，此列表中的最新条目是NetWalker帮派，该帮派似乎已开始将Pulse Secure系统作为目标，以将其有效负载部署在可能安装了这些系统的公司或政府网络上。

  

![](../Images/895890f30f39223708ded668fa25ed02.png)图片：Recorded Future  

  

随着全球各种报道中被黑客入侵的RDP和VPN的发展，以及数十家网络安全公司和专家不断提醒大家修补和保护这些系统，**公司的安全部门应该不再有借口允许黑客通过这些媒介入侵。**

  

**让员工沦为巧妙伪装的鱼叉式钓鱼电子邮件的受害者是一回事，而没有为您的VPN或网络设备打补丁超过一年或使用admin / admin作为您的RDP凭据又是另一回事。**

**防止RDP入侵的最佳做法**

除非有必要，否则应始终禁用RDP。对于需要RDP的组织，以下最佳做法对于保护RDP免受暴力攻击可能很有用。

1.  **使用VPN：如前所述，当RDP向Internet开放时会产生严重的安全风险。相反，组织应使用VPN允许远程用户安全地访问公司网络，而不必将其系统暴露于整个Internet。**
    
      
    
      
    
2.  **使用强密码：大多数基于RDP的攻击都依赖破解弱凭据。因此，组织必须在所有RDP客户端和服务器终端上强制使用强密码。密码应长，唯一且随机。**
    
      
    
      
    
3.  **使用多因素身份验证：即使最强的密码也可能受到威胁。多因素身份验证（MFA）并非绝对可靠，它通过要求用户提供至少两种形式的身份验证（例如一次性代码或生物识别通知）来登录RDP会话，从而提供了额外的保护层。**
    
      
    
      
    
4.  **使用防火墙限制访问：防火墙可用于将RDP访问限制为特定IP地址或IP地址范围。**
    
      
    
      
    
5.  **使用RD网关：RD网关服务器是Windows Server 2008以来所有版本Windows Server上都可用的功能，它对于简化RDP部署和安全管理非常有用。**
    
      
    
      
    
6.  **阻止多次登录尝试失败的IP：在短时间内大量失败的登录尝试通常表示暴力攻击。Windows账户策略可用于定义和限制用户尝试登录RDP的次数。当Emsisoft保护软件检测到多次登录尝试失败时，它会自动向管理员发出警报。**
    
      
    
      
    
7.  **限制远程访问：尽管默认情况下所有管理员都可以使用RDP，但是很有可能这些用户中有许多不需要远程访问即可完成工作。组织应始终遵守最小特权原则，并将RDP访问权限限制为仅真正需要特权的人。**
    
      
    
      
    
8.  **更改RDP侦听端口：攻击者通常通过在Internet上扫描在默认RDP端口（TCP 3389）上侦听的计算机来识别潜在目标。尽管通过Windows注册表更改侦听端口可以帮助组织“隐藏”易受攻击的连接，但它不能提供针对RDP攻击的保护，因此应仅用作补充技术。**
    

  

**加强组织系统的安全状态**

*   **保持最新的防病毒病毒库和引擎。**
    
*   **保持操作系统补丁程序为最新。**
    
*   **禁用文件和打印机共享服务。如果需要这些服务，请使用强密码或Active Directory身份验证。**
    
*   **限制用户的能力（权限），以安装和运行不需要的软件应用程序。除非需要，否则请勿将用户添加到本地管理员组。**
    
*   **实施严格的密码策略并实施常规密码更改。**
    
*   **在打开电子邮件附件时，请谨慎操作，即使该附件是预期的并且发件人似乎是已知的。**
    
*   **在代理工作站上启用个人防火墙，该工作站被配置为拒绝未经请求的连接请求。**
    
*   **在代理工作站和服务器上禁用不必要的服务。**
    
*   **扫描并删除可疑的电子邮件附件；确保扫描的附件是其“真实文件类型”（即，扩展名与文件头匹配）。**
    
*   **监控用户的网页浏览习惯；限制对内容不利的网站的访问。**
    
*   **使用可移动媒体（例如USB拇指驱动器，外部驱动器，CD等）时，请务必小心。**
    
*   **执行之前，请扫描从Internet下载的所有软件。**
    
*   **保持对最新威胁的态势感知，并实施适当的访问控制列表（ACL）。**
