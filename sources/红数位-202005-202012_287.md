# 美国封杀阿里？路透社炮制假新闻！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247491106&idx=4&sn=cdf7ca66fa0deaf60361ec0a362c6210&chksm=cef37391f984fa8701328548de0fe31e86c5ea924e66e3da1cbd61a4102c5078a5db80126cd9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247491106&idx=4&sn=cdf7ca66fa0deaf60361ec0a362c6210&chksm=cef37391f984fa8701328548de0fe31e86c5ea924e66e3da1cbd61a4102c5078a5db80126cd9&scene=27#wechat_redirect)

当地时间8月15日，路透社报道称，美国总统特朗普在白宫发布会上表示，正在调研美国是否应该“封杀”中国科技巨头阿里巴巴。

![](../Images/41c8a6e778c2600e7410d60ed74c3c64.png)

在此之前，TikTok、微信已经先后被美国盯上，阿里“树大招风”也被美国下手似乎是很自然的。

但是**过了几个小时，路透社就修改了自己的报道，承认美国“封杀”阿里是一条彻头彻尾的假新闻！**

据悉，在本次白宫发布会上，确实涉及了美国对中国科技企业采取行动的话题，但是特朗普并未针对阿里巴巴。

在会上，彭博社记者向特朗普询问在对TikTok、微信采取行动后，是否还想禁止其他中国科技公司在美国的运营。

对此，特朗普直言不讳地称，**最重要的就是华为，不允许华为(在美国运营)，也告诉了欧洲国家和其他国家，比如澳大利亚，华为不能用，英国最后也放弃了。**

随后，彭博社记者问有没有其他特定的中国科技企业，特朗普回答称正在进行其他调查，但**当记者提出阿里巴巴的名字后，特朗普似乎没有听清楚，反问了一句，但并未继续，这个话题就结束了。**
