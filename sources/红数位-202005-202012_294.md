# Citrix思杰警告：黑客将迅速利用新高危漏洞进行攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247491055&idx=6&sn=27b8085abe450f82c76fd26b1235cde7&chksm=cef3705cf984f94a540d7ab37efb0f1384d5e9db40ef25c2da196d5934159b75ac751d3bdd50&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247491055&idx=6&sn=27b8085abe450f82c76fd26b1235cde7&chksm=cef3705cf984f94a540d7ab37efb0f1384d5e9db40ef25c2da196d5934159b75ac751d3bdd50&scene=27#wechat_redirect)

Citrix发布了涵盖Citrix Endpoint Management（CEM）中多个漏洞的更新，该漏洞也称为XenMobile。链接漏洞可以使未经身份验证的远程攻击者获得对Citrix Endpoint Management（CEM）服务器的控制。

  

![](../Images/9b563c2366b6eb1762cf0fd4e0445c52.png)

  

这些漏洞可以跟踪为CVE-2020-8208，CVE-2020-8209，CVE-2020-8210，CVE-2020-8211和CVE-2020-8212。

  

**受影响的Citrix版本**

该漏洞的影响在所使用的软件的特定版本之间有所不同，并且无需利用授权即可利用该漏洞。

  

未经身份验证的攻击者可以通过使用特制URL来利用此漏洞，该URL允许访问敏感数据，例如配置文件和加密密钥。

  

**受到严重严重漏洞影响的Citrix Endpoint Management（CEM）的以下版本**

  

*   RP2之前的XenMobile服务器10.12
    
*   RP4之前的XenMobile服务器10.11
    
*   RP6之前的XenMobile服务器10.10
    
*   10.9 RP5之前的XenMobile服务器
    

  

**以下是受中等和低严重性漏洞影响的版本**

  

*   RP3之前的XenMobile服务器10.12
    
*   RP6之前的XenMobile服务器10.11
    
*   RP6之前的XenMobile服务器10.10
    
*   10.9 RP5之前的XenMobile服务器
    

  

Citrix 建议具有10.9、10.10、10.11和10.12版本的用户申请最新的滚动修补程序，并建议使用10.9.x之前的版本升级受支持的版本。

  

“我们建议立即进行这些升级。尽管在撰写本文时尚无已知的利用，但我们确实预期恶意行为者会迅速采取行动。”

  

思杰表示，XenMobile的云版本已经打补丁，“但是混合权限用户需要将升级应用到任何本地实例。”
