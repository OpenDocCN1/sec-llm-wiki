# 波音747时至今日仍通过软盘获得重要更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247490338&idx=1&sn=2191de25b10ecd3bf32abb6706b69e1c&chksm=cef37691f984ff87a9fd62f4b27e1ab4d90d63b4bee70b25e2241bf770c11529393b69c48f6e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247490338&idx=1&sn=2191de25b10ecd3bf32abb6706b69e1c&chksm=cef37691f984ff87a9fd62f4b27e1ab4d90d63b4bee70b25e2241bf770c11529393b69c48f6e&scene=27#wechat_redirect)

波音公司的747-400飞机于1988年首次推出，近日被曝波音公司的**747-400飞机历经22个年头目前仍通过3.5英寸软盘接收重要的软件更新。**

  

![](../Images/6c9ee38a461238aa465aefb27feb6a4e.png)

  

据外媒报道，在冠状病毒大流行期间旅行骤降后，该航空公司决定退休其747-400飞机机队。Pen Test Partners的安全研究人员终于获得机会可以使用英国航空公司747飞机来做研究。该团队能够检查乘客甲板下方的整个航空电子设备舱，其数据中心状的模块化黑匣子机架可为飞机执行不同的功能。

![](../Images/37aafe273c4af9b0a6d23ab5c7b7796d.png)

  

研究人员在座舱中发现了一个3.5英寸的软盘驱动器，该驱动器用于加载飞机重要的导航数据库。这是一个必须每28天更新一次的数据库，并且工程师每月都会上传最新的更新。

  

![](../Images/7cb026c3f8a15c8159fb666ecf2b8bcc.png)

  

尽管今天的飞机上仍在使用3.5英寸软盘听起来令人惊讶，但许多波音737飞机也一直在使用软盘加载航空电子软件。根据《今日航空》（Aviation Today） 2015年的一份报告，这些软盘上存储的数据库越来越大。一些航空公司已经不再使用软盘了，但是其他航空公司仍被波音工程师困在每个月依赖装载八张软盘，其中包括对机场，飞行路线，跑道等的更新。

  

![](../Images/90c5513d2ed013a8cb6f7fba0b659c95.png)

  

747（上图）的10分钟视频之旅是对您从未见过的飞机各个部分的有趣洞察，尤其是对于拥有数十年历史的客机而言。这次巡演是今年虚拟的Def Con会议的一部分，Def Con会议是美国最大的黑客会议。随着现代飞机依靠越来越复杂的技术，安全研究人员对飞机如何防止旅客干扰飞行的兴趣日益浓厚。

  

当涉及机上娱乐系统时，安全性尤其重要。一位网络安全教授去年发现了英国航空公司航班上的缓冲区溢出漏洞。这位教授能够使用USB鼠标将长文本字符串输入到机上聊天应用程序中，从而使整个机上娱乐系统崩溃。安全研究人员仍在寻找漏洞，以使他们能够从飞机的公共可访问部分与飞行系统进行通信。

  

![](../Images/7ae45b6db7503bd9e776289f69cfb878.png)

  

对安全性的关注在最新飞机上更为重要。波音777X和787等现代飞机使用光纤网络，所有航空电子设备都插入该网络，并由运行飞行关键软件的两台计算机控制。就像您在办公大楼内发现的那样，它更像是一个传统网络，一些最新的客机甚至可以通过空中接收软件更新。但是，为现代飞机提供动力的软件并不总是可靠的。

  

在软件故障导致两起致命坠机事故，造成346名乘客和机组人员死亡之后，波音公司仅恢复了其故障737 Max飞机的生产。
