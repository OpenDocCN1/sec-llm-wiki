从Windows XP到Windows 10的开始菜单的演变

“开始”菜单已成为Windows中的必备工具，因为它几乎是许多人在启动系统后启动的第一件事。


Windows 10开始菜单当前版本


Microsoft本身非常了解这一点，并且公司正在努力通过“开始”菜单进一步完善体验。而且，由于“开始”菜单本身已成为使用Microsoft设备的必不可少的一部分，因此，软件巨头正试图将其超越传统台式机。


例如，Windows 10X是一个旨在为双屏和可折叠设备供电的操作系统，它本身也具有“开始”菜单，所有这些都是为了帮助人们更轻松地使用操作系统。


多年来，“开始”菜单已经发生了很大的变化，并且由于某种方法使很多人感到意外，甚至使用户感到迷失在Windows桌面上，因此它甚至完全消失了。


每个人都记得Windows XP的“开始”菜单，这是因为Windows XP本身是Microsoft有史以来最成功的操作系统之一。Windows XP于2014年4月退休，带有一个现代的“开始”菜单，与Windows 98中的菜单相比，它的设计更加丰富多彩。


顶部和底部的蓝色横条，以及指向Windows中最重要位置（如“我的文档”，“我的电脑”和“控制面板”）的快捷方式，使Windows XP“开始”菜单成为大多数用户开始在其台式机上工作所需的东西。


Windows XP还支持主题，并且第三方工具对标准设计进行了许多更改，其中包括彻底修改了“开始”菜单的新外观。但是总而言之，大多数人喜欢默认配置下的Windows XP“开始”菜单，仅仅是因为这正是他们所需要的。


Windows XP“开始”菜单


在Windows Vista开始菜单在Windows XP中使用的设计的演变并出台了一系列的变化与它的前辈，包括黑色主题，并在用户界面的底部集成了一个搜索框。这使每个人都可以更快地执行搜索，就像他们现在在Windows 10中可以执行的方式一样。


底部电源选项仍然存在，这次有一个按钮来扩展它们并到达其他控件。仍然提供了Windows中“控制面板”和文件库的快捷方式以及“所有程序”链接，以查看设备上已安装的所有应用程序。


像Windows XP中一样，第三方应用程序允许对Windows Vista“开始”菜单进行大量自定义，尽管在某些情况下，它们引起或多或少的系统速度下降，但人们还是非常喜欢这些功能。


Windows Vista开始菜单


每个人都知道Windows 7的“开始”菜单，这是因为这些日子仍然存在。作为Windows Vista设计的改进版本，Windows 7的“开始”菜单基于几乎相同的方法，并在设计上做了一些改进。


实际上，Microsoft不再支持Windows 7，因为该公司已于今年1月停止推出安全更新。


换句话说，如果您仍在运行Windows 7，则最好升级到受支持的操作系统，因为运行不再接收更新的软件可能会为黑客打开大门。


Windows 7开始菜单


Windows 8和Windows 8.1完全放弃了“开始”菜单，因为微软将其替换为针对触摸输入进行了优化的“开始”屏幕。


这是一个有争议的更改，最终使Windows 8本身变成了许多人都避免使用的操作系统，选择保留在Windows 7上以获得更熟悉的方法。


许多升级到Windows 8的人最终都安装了Classic Shell之类的应用程序，该应用程序带回了“开始”菜单，有时会带有一个熟悉的主题，例如Windows 7中的主题。


Windows 8.1“开始”屏幕


Windows 10重新显示了“开始”菜单，这一次它使用了更现代的方法。微软实现了实时磁贴，这是从Windows Phone借来的功能，自从该操作系统于2014年10月在Insider程序中首次亮相以来，该设计就发生了很大的变化。


Windows 10中带有新主题感知磁贴的“开始”菜单


微软针对Windows 10的``开始''菜单宣布的最新更改被称为主题感知磁贴，并且几乎包括了用于用户固定到菜单的实时磁贴的现代设计。


此功能仍在测试中，但在接下来的几个月中，它将为所有人使用。
