# 英美联合警告QNAP设备已有62000台感染QSnatch恶意软件(附IOC)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489953&idx=1&sn=50fe0b4fb1fbaf549785ee8855c9a9e7&chksm=cef37412f984fd04ce5f459056db5223d6b813ba22c795c6c1995388e654bee524e25689fae0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489953&idx=1&sn=50fe0b4fb1fbaf549785ee8855c9a9e7&chksm=cef37412f984fd04ce5f459056db5223d6b813ba22c795c6c1995388e654bee524e25689fae0&scene=27#wechat_redirect)

美国网络安全和基础设施安全局（CISA）和英国国家网络安全中心（NCSC）今天发布了有关重新启动QSnatch恶意软件攻击QNAP NAS设备面临感染风险的警报。

  

![](../Images/130c4b53c19258ba54242ff123eaad12.png)

  

尽管以前的QSnatch攻击（从2014年初到2017年中以及从2018年底到2019年底）使用的攻击基础结构目前不活跃，但这两个机构敦促所有QNAP客户尽快更新其NAS设备以阻止以后的活动。

  

**全球感染了62,000台QNAP设备**

“所有的QNAP NAS设备都可能受到恶意软件QSnatch如果不使用最新的安全补丁更新，”两个机构解释。

*   **NCSC:**
    
    **https://www.ncsc.gov.uk/news/legacy-risk-malware-targeting-qnap-nas-device**
    
*   **CISA:**
    
    **https://us-cert.cisa.gov/ncas/alerts/aa20-209a**
    

  

联合警报警告说：“ 仍在运行易受攻击版本的组织必须在设备上进行完全出厂重置，然后才能完成固件升级，以确保设备不会受到攻击。”

  

![](../Images/4c77c2db4b8e508de9a4818b3c067a73.png)

  

到2020年6月中旬，这两个机构已在全球范围内发现了约62,000台受感染的设备，其中在美国发现了约7,600台，在英国发现了3,900台。

  

![](../Images/f590f3a22d9e685ff1c498031b9e7305.png)

  

为了阻止QSnatch恶意软件感染，建议组织遵循QNAP 关于Qsnatch恶意软件的安全建议中列出的建议，包括将QTS NAS OS，恶意软件删除程序和安全顾问更新到最新的可用版本。

  

[数以十万计威联通QNAP设备易受远程接管攻击](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488846&idx=3&sn=a3264e9c66cc80a5fb2d060f82412b51&chksm=cef378fdf984f1eb01baaf43a06792bb9ad02385923150495697e29688258857dd7ad3641bf7&scene=21#wechat_redirect)

  

CISA和NCSC还共享以下缓解措施，以防止将来遭受攻击：

  

*   确认您是从信誉良好的来源购买QNAP设备的。如果有疑问，请在完成固件升级之前在设备上进行完全出厂重置。
    
*   如果打算将设备严格用于内部存储，请阻止外部连接。
    

  

**QSnatch恶意软件**

芬兰国家网络安全中心（NCSC-FI）的安全研究人员发现了数千个受感染的QNAP NAS设备后，QNAP在2019年11月警告其客户正在进行攻击，试图用QSnatch恶意软件感染其NAS设备。

  

正如他们发现的那样，QSnatch可以窃取在受感染的NAS设备上找到的用户凭据，并注入从其命令和控制（C2）服务器检索到的恶意代码。

  

QSnatch具有多种功能，包括但不限于：

  

*   CGI密码记录器，用于安装伪造的设备管理员登录页面以进行网络钓鱼凭据
    
*   凭据抓取器
    
*   SSH后门，使攻击者能够在受感染的设备上运行任意代码
    
*   Web Shell提供远程访问权限
    
*   渗透模块用于窃取预定义的文件列表（包括日志和系统配置）
    

  

一旦感染了QNAP NAS设备，QSnatch还将通过编辑cronjob和init脚本，阻止恶意软件卸妆程序运行以及覆盖更新源并将更新域和URL重定向到本地版本来阻止软件更新，从而获得持久性。

  

尽管感染媒介仍是未知的（除了QSnatch已注入到设备固件中），但这些机构提到在被感染的NAS设备上发现的一些样本“会故意修补被感染的QNAP，以解决Samba远程执行代码漏洞。CVE-2017-7494。”

  

这是阻止其他人在感染了QSnatch的设备后控制其控制权的一部分，或者是以前的攻击中用于部署恶意软件的潜在感染媒介的标志。

  

**QNAP NAS设备备受争议**

当QNAP的NAS设备受到攻击时，QSnatch并不是第一个实例，该公司在2019年10月初发布安全公告，内容涉及运行phpMyAdmin的设备被Muhstik Ransomware击中了弱SQL服务器密码  。

  

在2019年八月，QNAP得到了另一个咨询约一出 eCh0raix勒索（也称为QNAPCrypt）系列的弱口令和过时的QTS固件针对QNAP设备的攻击。

  

[威联通群晖(QNAP)官方警告用户确保设备免受QSnatch恶意软件侵害](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247486509&idx=4&sn=e1b2191fe70958c0e601d8992cd4ac04&chksm=cef3619ef984e888a588b6fb26771e5e5f19c7cc7d8e2b2af783901abdd58ce923db0185ac1a&scene=21#wechat_redirect)  

  

一周前，勒索软件专家BloodDolly  在BleepingComputer支持主题中发布了eCh0raix勒索软件病毒变种的解密器。

  

在2018年5月，威联通还将其正在进行的VPNFilter恶意软件攻击通知其客户，  试图使用默认管理员帐户密码或运行QTS 4.2.6 build 20170628、4.3.3 build 20170703和更早版本来感染NAS设备。
