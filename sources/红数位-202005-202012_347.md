# NSA和CISA紧急警告对美关键基础设施OT资产和工业威胁和网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489894&idx=3&sn=be5fbed607037f55c763d3e1f240a1c3&chksm=cef374d5f984fdc30c7b6b76aa12da209f130a750d7d3ff3ee27789844d718663e004cd47bf2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489894&idx=3&sn=be5fbed607037f55c763d3e1f240a1c3&chksm=cef374d5f984fdc30c7b6b76aa12da209f130a750d7d3ff3ee27789844d718663e004cd47bf2&scene=27#wechat_redirect)

**美国警告说，发电厂，工厂，石油和天然气精炼厂等等都在外国对手的视线范围内。**

![](../Images/f0092de6a99f235be0d6fd2585875e3b.png)

  

美国国家安全局（NSA）和网络安全与基础设施安全局（CISA）已发出警告，警告说攻击者可能将目标对准了美国的关键基础设施

  

另外，ICS-CERT还发布了有关Schneider Electric Triconex TriStation和Tricon通信模块中严重安全漏洞的咨询。这些安全仪表系统（SIS）控制器负责在出现问题时关闭工厂运行，并充当工业设施的自动安全防御措施，旨在防止设备故障和爆炸或火灾等灾难性事件。过去，他们一直是2017年TRITON攻击的目标。

  

NSA / CISA 联合咨询报告说：“近几个月来，网络参与者表现出了他们继续通过利用可访问互联网的运营技术（OT）资产对关键基础设施（CI）进行恶意网络活动的意愿。” “由于对手能力和活动的增加，对美国国家安全和生活方式的重要性以及旧约系统的脆弱性，民用基础设施为外国大国提供了有吸引力的目标，这些外国大国企图损害美国利益或报复美国的侵略行为。”

  

**脆弱的OT系统**

该通报还指出，OT系统通常由既不设计为无法连接到互联网也不防御恶意网络活动的旧设备组成。同时，越来越多的公用事业，石化装置，工厂等正在寻求增加远程操作。这意味着使用IT网络连接到OT端，可以通过Web进行各种活动，从而实现监视，仪表和控制，OT资产管理/维护，在某些情况下还可以进行过程的操作和维护。

  

该通报补充说，通常，对手在转向OT网络之前，会通过鱼叉式网络获取对组织IT网络的初始访问权限。

  

“与识别通过互联网连接的OT资产（例如Shodan，Kamerka）的随时可用的信息相结合，正在掀起一场“完美风暴”，轻松访问无担保资产，使用有关设备的通用开放源代码信息以及广泛的信息。可以通过通用漏洞利用框架进行部署的漏洞利用清单。”

  

NSA / CISA咨询还详细说明了在野外已经观察到几次网络攻击尝试。这些尝试包括：在IT和OT网络上部署商品勒索软件；与控制器通信并下载修改后的控制逻辑；使用供应商工程软件和程序下载；并修改可编程逻辑控制器（PLC）上的控制逻辑和参数。PLC负责直接读取和操作工业环境中的物理过程。

  

如果成功，这些努力可能会导致OT网络瘫痪，对操作员的视线部分丧失，生产力和收入的损失，或者在最坏的情况下，对手的控制和对物理过程的破坏。

  

CyberX工业网络安全副总裁Phil Neray表示：“网络运动是民族国家在全球舞台上施加压力的理想方式，因为它们提供了合理的可否认性以及不确定的参与规则，” 。“这项NSA / CISA咨询特别有趣，因为它似乎与针对工业控制系统的正在进行的运动有关，并且明确提到组织需要防止复杂的偏远地区策略，例如修改控制逻辑。过程控制器，这正是我们在TRITON攻击中看到的。”

  

![](../Images/d68dbcb00596e41284e1c627f4836f8c.png)

  

以前在美国已记录了两起视线局部丢失事件：一是2月份对管道的勒索软件攻击，导致该病毒停运了两天。另一个是去年11月对风能和太阳能发电厂的袭击。失明意味着组织失去了监视其物理系统当前状态的能力。

  

Neray当时在接受Threatpost采访时说：“如果攻击者想关闭部分电网，他们的第一步可能正是这种视线丢失的步骤，因为这会使公用事业运营商'盲目'攻击者随后采取的破坏性行动，例如关闭继电器以阻止电流流动。”

  

**Triconex Redux…和一个严重的错误**

与NSA / CISA警报相对应的是ICS-CERT通报，该通报针对Schneider的Triconex SIS设备中的几个错误，其中一个很严重，在CvSS漏洞严重性等级中排名十分之十。

  

该文件称：“成功利用这些漏洞可能使攻击者能够查看网络上的明文数据，导致拒绝服务状况或允许不正确的访问”。

  

鉴于过去一直以Triconex SIS为目标，因此本公开内容令人担忧。2017年，一个中东石油和天然气石化设施被名为TRITON（也称为 TRISIS或HatMan）的恶意软件袭击，该恶意软件直接与Triconex SIS交互并对其进行控制，因此超过了其他工业网络攻击。因为SIS是针对工业设施的自动安全防御的最后一道防线（即旨在保护人类生命的保护功能），所以关闭SIS可以为破坏性的物理攻击铺平道路，而不受故障保护机制的阻碍。在TRITON攻击的情况下，值得庆幸的是，下一阶段从未到来-攻击在达到目标值之前就被手动阻止了。

  

新的错误影响在Windows NT，Windows XP或Windows 7上运行的TriStation 1131，v1.0.0至v4.9.0，v4.10.0和4.12.0；安装在Tricon v10.0至v10.5.3系统中的Tricon通信模块（TCM）4351、4352、4351A / B和4352A / B。当前版本和较新版本没有暴露于这些特定漏洞-但是许多ICS安装仍在运行旧版。

  

严重的错误（CVE-2020-7491）是不当的访问控制漏洞：“在网络上可见安装在Tricon系统版本10.2.0至10.5.3中的TCM中的旧调试端口帐户，并且可能允许不当访问。”

  

还有四个严重程度不高的问题。根据ICS-CERT，该漏洞跟踪为CVE-2020-7484（严重等级为7.5）允许不受控制的资源消耗：“与TriStation 1131版本1.0到4.12.0中的密码功能相关的漏洞可能允许拒绝-如果用户未遵循与专用TriStation 1131连接和按键开关保护有关的文档指导，则将对服务进行攻击。”

  

同时，不受控制的资源消耗错误（CVE-2020-7486）的CvSS评分也为7.5，当处于高网络负载时，可能会导致Tricon系统版本10.0.0至10.4.x中安装的TCM重置。此重置可能导致SIS拒绝服务行为。

  

另一个错误（CVE-2020-7485）是隐藏功能问题，严重性等级为5.5：“与TriStation 1131版本1.0至4.9.0和4.10.0中的旧支持帐户相关的漏洞可能允许对TriStation的不当访问。1131项目文件。”

  

最后，CVE-2020-7483（严重等级为5.3）允许通过明文传输敏感信息。该通报称：“与TriStation 1131版本1.0到4.12.0中的“密码”功能相关的漏洞可能导致启用该功能后，某些数据在网络上可见。”

  

NSA / CISA警报敦促在民用和军事OT领域进行修补和缓解，并提供了在该建议中采取的措施。

  

它说：“ OT资产对于国防部（DoD）的任务至关重要，并支撑着重要的国家安全系统（NSS）和服务以及国防工业基地（DIB）和其他关键基础设施。” “在紧张局势加剧的时候，至关重要的是资产所有者和关键基础设施的运营商应采取……立即措施，以确保在短期内出现危机时，美国系统的弹性和安全性。”
