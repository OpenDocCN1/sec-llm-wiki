# 苹果向安全研究人员提供可入侵的iPhone

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489876&idx=4&sn=788531a927295cc9d1adcb76160f8c33&chksm=cef374e7f984fdf1a7bc020ac8503f731ea5361bbee05fbba528d721854df153da68f4705575&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489876&idx=4&sn=788531a927295cc9d1adcb76160f8c33&chksm=cef374e7f984fdf1a7bc020ac8503f731ea5361bbee05fbba528d721854df153da68f4705575&scene=27#wechat_redirect)

苹果本周启动了另一项旨在通过为安全研究人员提供可黑客入侵的手机来改善iPhone安全性的计划。

  

![](../Images/bd68e94f0142734b42fb76882c0316d7.png)

  

这些设备专门为安全研究人员设计，具有独特的代码执行和遏制策略，并作为公司安全研究设备（SRD）计划的一部分提供，该计划最初于去年12月宣布。

  

希望识别SRD iPhone上的iOS漏洞的安全研究人员将可以使用Shell访问并可以运行所需的工具。

  

**需要说明的是，iPhone只能在受控环境中使用，它们是Apple的财产，以12个月的可续期方式向与会的研究人员提供，并且“****必须始终在计划参与者的住所内使用****” 。”-苹果提供可入侵的iPhone**

  

这家位于库比蒂诺（Cupertino）的科技巨头表示，这些设备的行为“尽可能接近标准iPhone”，但指出这些设备并非供日常个人使用，并且只能将其用于授权人员。

  

任何发现的漏洞都应报告给Apple或第三方，具体取决于发现的位置。Apple鼓励研究人员报告安全漏洞，即使未通过使用SRD进行发现也是如此。

  

这些Apple iPhone上发现的所有漏洞都被视为有资格获得金钱奖励，这是Apple Security Bounty计划的一部分，该计划已为公众所用。

  

该公司要求报告研究人员不要共享发现的漏洞的信息，直到苹果自己披露其详细信息和/或发布补丁为止。

  

我们邀请有兴趣的研究人员申请该计划，但由于设备数量有限，因此并非所有合格的申请人都会收到SRD iPhone。苹果表示，在2021年的下一个申请期内，将自动考虑不接收设备的用户。

  

符合SRD资格的研究人员是已经加入Apple Developer Program的人员，具有确定操作系统漏洞的跟踪记录，并且位于合格的国家或地区。苹果公司的员工或最近12个月内被苹果公司雇用的员工没有资格。

  

有兴趣的研究人员可以在Apple网站上申请SRD计划：

**https://developer.apple.com/contact/request/security-research-device/**

  

尽管苹果声称已经启动了该计划，以吸引对确定其平台漏洞感兴趣的安全研究人员，但其中一些限制将使久经考验的漏洞搜寻者远离SRD。

  

Google的“零号计划”研究人员将无法参与，因为他们倾向于在漏洞披露90天后发布漏洞详细信息，而不管补丁程序是否已发布。网络安全公司ZecOps表示，由于施加的限制，它也不会参加。
