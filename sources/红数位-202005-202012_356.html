Microsoft Outlook升级后崩溃会删除某些POP帐户邮件

根据Office支持文档，某些Microsoft 365客户在更新到版本2006 Build 13001.20266及更高版本后，可能会遇到Outlook崩溃。



Outlook还将从其收件箱中删除三封或三封以上电子邮件，这些帐户的帐户配置为从仅具有下载头的POP（邮局协议）帐户中检索邮件。


POP帐户通常配置为在用户Internet连接速度较慢时仅从邮件服务器下载标头（包括发件人和电子邮件的主题）。


另一个用例是用户希望立即通过大量邮件进行访问，而不必等待服务器也下载电子邮件正文和附件。


将POP帐户配置为仅下载电子邮件标头将大大减少从服务器下载所有电子邮件所需的时间，并大大加快了电子邮件浏览的速度。


具有仅下载标题的POP帐户


Outlook团队目前正在调查此问题，并将在发现更多具体信息时提供有关该错误的更多信息。


在Outlook由于此问题而崩溃的系统上，以下事件详细信息将被写入Windows Event Viewer应用程序日志：

如何防止Outlook崩溃

需要变通解决此问题以防止Microsoft 365电子邮件客户端在其系统上崩溃并删除邮件的客户可以还原到不受此问题影响的以前的Office版本。


根据Microsoft的说法，还原到6月24日发布的2005版（内部版本12827.20470）应该可以阻止所有崩溃。


为此，您可以按照以下步骤操作：


  • 在Windows搜索框中键入run，然后选择“ 运行”应用程序。


  • 将以下行复制并粘贴到“ 运行”框中，然后选择“ 确定”以开始还原过程：


C：\ Program Files \ Common Files \ microsoft shared \ ClickToRun \ officec2rclient.exe / update用户updatetoversion = 16.0.12827.20470


上个月，Microsoft还解决了导致某些用户Outlook启动失败的另一个问题，显示错误提示用户修复其某些收件箱文件。


本月初，雷德蒙德不得不处理一个事件，来自世界各地的Outlook用户都报告了启动时的立即崩溃，Windows事件查看器中显示了0xc0000005错误。


在周一发布的新支持文档中，微软还表示， 如果启用了用户体验虚拟化（UE-V），则用户将在运行Windows 10版本1809或更高版本的设备上体验  一分钟的Outlook启动。
