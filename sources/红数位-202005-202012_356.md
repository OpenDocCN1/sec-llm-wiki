# Microsoft Outlook升级后崩溃会删除某些POP帐户邮件

根据Office支持文档，某些Microsoft 365客户在更新到版本2006 Build 13001.20266及更高版本后，可能会遇到Outlook崩溃。

  

![](../Images/6baf4d8f9fd3ff3fe985bf839d817843.png)

  

Outlook还将从其收件箱中删除三封或三封以上电子邮件，这些帐户的帐户配置为从仅具有下载头的POP（邮局协议）帐户中检索邮件。

  

POP帐户通常配置为在用户Internet连接速度较慢时仅从邮件服务器下载标头（包括发件人和电子邮件的主题）。

  

另一个用例是用户希望立即通过大量邮件进行访问，而不必等待服务器也下载电子邮件正文和附件。

  

将POP帐户配置为仅下载电子邮件标头将大大减少从服务器下载所有电子邮件所需的时间，并大大加快了电子邮件浏览的速度。

  

![](../Images/4f85342ff2880b9a331c86d8881e801b.png)

具有仅下载标题的POP帐户  

  

Outlook团队目前正在调查此问题，并将在发现更多具体信息时提供有关该错误的更多信息。

根据Microsoft的说法，还原到6月24日发布的2005版（内部版本12827.20470）应该可以阻止所有崩溃。
