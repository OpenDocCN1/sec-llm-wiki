# 巴西的银行木马走向全球

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489696&idx=6&sn=23739a85d8c101fddb02b34e5046d720&chksm=cef37513f984fc0517335daa0379db8ec5a01e75fea00bc2b39bda168f5250c10faf30b0db53&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489696&idx=6&sn=23739a85d8c101fddb02b34e5046d720&chksm=cef37513f984fc0517335daa0379db8ec5a01e75fea00bc2b39bda168f5250c10faf30b0db53&scene=27#wechat_redirect)

四个复杂的恶意软件家族正在增加其技术，并积极地传播到包括美国在内的新国家。

  

![](../Images/06bce2cdb5b3519c8f5cbc4ceda6d1c3.png)

  

在巴西通常使用的恶意软件正在扩大其地理范围，以北美，欧洲和拉丁美洲其他地区的用户为目标。

  

银行木马很普遍，它们从毫无戒心的受害者那里窃取在线银行登录信息和其他财务凭证，但是更复杂的例子通常是在巴西开创的。据卡巴斯基的研究人员称，根据周二发布的一份报告，巴西的四个银行木马家族（Guildma，Javali，Melcoz和Grandoreiro，统称为Tetrade）已将其分布在全球。

  

***根据“在过去，巴西犯罪分子主要针对地方金融机构的客户” 的报告。“这种情况在2011年初发生了变化，当时有几个组织开始尝试向国外出口基本木马。今年，四个被称为Tetrade的家族实施了必要的创新，以使其在全球范围内推广。”***

  

该报告称，自2015年以来一直活跃的Guildma集团倾向于使用伪装为合法业务通信或通知的网络钓鱼电子邮件。

  

研究人员指出：“大多数网络钓鱼邮件都模仿业务请求，通过快递服务或任何其他常规公司发送包裹，包括COVID-19大流行，但始终带有公司外观特征。”

  

不过，与众不同的是，它使用了创新的规避技术，从而使其恶意软件特别难以检测。

  

***卡巴斯基解释说：“从2019年开始，Guildma开始使用特殊文件格式将恶意有效负载隐藏在受害者的系统中。” “此外，Guildma将其与控制服务器的通信以加密格式存储在Facebook和YouTube页面上。结果，很难将通信流量检测为恶意流量，并且因为没有防病毒软件阻止这些网站中的任何一个，所以可以确保控制服务器可以不间断地执行命令。”***

  

该公司表示，Guildma最近在整个南美以及美国，葡萄牙和西班牙活跃起来。

  

![](../Images/5a633b891eb272450b9567ce86367146.png)

  

同时，Javali集团（自2017年以来活跃）最近已扩展到墨西哥。报告称，与Guildma一样，它也通过带有恶意附件的网络钓鱼电子邮件进行传播，并且它已开始使用YouTube托管其命令和控制（C2）通信。

  

此外，“这些电子邮件包括带有嵌入式Visual Basic脚本的MSI（Microsoft安装程序）文件，该文件可从远程C2下载最终的恶意负载；研究人员解释说：“它还使用DLL侧载和多层混淆，以向分析人员和安全解决方案隐藏其恶意活动。”

  

![](../Images/eee71e508ceb31ea6c611c106dd7de1c.png)

  

初始的Microsoft Installer下载器包含一个嵌入式自定义操作，该操作将触发Visual Basic脚本。该脚本连接到远程服务器，然后检索恶意软件的第二阶段。

  

第三家族梅尔科兹（Melcoz）自2018年以来一直活跃，并以恶意软件闻名，该恶意软件与其他银行木马一样，会从浏览器和计算机内存中窃取密码; 但它也包含用于窃取比特币钱包的模块。卡巴斯基说，它将用网络罪犯自己的信息代替原始的钱包信息。

  

梅尔科兹现在已扩展到拉丁美洲的其他地方。

  

研究人员说：“我们发现该组织自2018年以来就袭击了智利，最近又袭击了墨西哥。” “不过，由于某些目标银行在国际上经营业务，因此在其他国家/地区还是很有可能会遭受受害者...由于这些集团使用不同的语言（葡萄牙语和西班牙语），我们相信巴西的网络犯罪分子正在与当地的编码人员和mu子组合作，撤回由不同运营商管理的赃款，出售对其基础架构和恶意软件构造者的访问权。”

  

每个Melcoz广告系列均以其唯一ID运行，该ID在所使用的版本和C2之间会有所不同。

  

报告称：“通常，恶意软件使用添加到MSI文件中的AutoIt或VBS脚本，这些脚本使用DLL-Hijack技术运行恶意DLL，旨在绕过安全解决方案。”

  

研究人员说，最后一个家庭Grandoreiro自2016年以来一直活跃，并且最近针对拉丁美洲和欧洲的用户。卡巴斯基表示，其恶意软件以服务形式提供，因此，它已成为四个家族中分布最广泛的恶意软件。

  

该恶意软件通过受感染的网站以及鱼叉式网络进行分发，并且像Guildma和Javali一样，将其C2通信隐藏在合法的第三方网站上。

  

“巴西骗子正在迅速创建会员生态系统，招募网络犯罪分子与其他国家合作，采用MaaS（恶意软件即服务），并迅速向其恶意软件中添加新技术，以使其保持相关性并在财务上具有吸引力。他们的合作伙伴。”报告指出。

  

卡巴斯基拉丁美洲和加勒比地区GReAT负责人Dmitry Bestuzhev补充说：“此外，他们还在不断创新，增加了新的技巧和技术来隐藏其恶意活动，并使攻击更加有利可图。我们预计这四个家庭将开始攻击其他国家/地区的更多银行，并涌现出新的家庭。因此，对于金融机构来说，密切监视这些威胁并采取措施增强其反欺诈能力至关重要。”
