我们已在测试中确认了崩溃，如下图所示。

在Microsoft 365管理中心的标题为“ EX218604：用户遇到Outlook连接问题和崩溃”的事件状态消息中，Microsoft建议用户使用Web和移动客户端，直到问题解决。

  

***标题：遇到Outlook连接问题和崩溃的用户***

  

***用户影响：用户可能会遇到崩溃，或者可能无法通过Outlook访问Exchange Online。***

  

***更多信息：我们的分析表明，Web和移动客户端上的Outlook不受影响。在我们修复此问题的同时，用户可能可以利用这些协议作为访问电子邮件和服务功能的替代方法。***

  

***当前状态：我们对可用数据的初步审查表明，最近部署的更新可能是问题的根源。我们正在对所有最近的服务更新进行分析，以找出问题的根本原因并确定恢复服务的最便捷方法。***

  

***影响范围：此问题可能会影响您尝试使用Outlook的任何用户。***

  

Microsoft Outlook用户已经成功回滚到以前版本的Microsoft Outlook，以解决此问题，这将在下一部分中进行说明。

  

**如何修复Microsoft Outlook崩溃**

如果Microsoft Outlook为您崩溃，则可以通过以安全模式启动Microsoft Outlook或回滚到以前版本的Microsoft Outlook来解决此问题。

  

**方法1：将Microsoft Office回滚到2020年6月最新版本**

要回溯到2020年6月24日，发布并修复Microsoft Outlook崩溃，请按照以下步骤操作：

  

1.通过单击“开始”菜单并键入CMD来打开命令提示符。当出现“命令提示符”结果时，单击它。

2.在命令提示符下，键入  cd "\\Program Files\\Common Files\\microsoft shared\\ClickToRun"，然后按回车。

3.您现在将位于ClickToRun文件夹中。键入  officec2rclient.exe /update user updatetoversion=16.0.12827.20470 并按回车。

  

![](../Images/bee8de594c3963c8b07b33cf1cba3433.png)

在命令提示符中输入命令  

  

4.Microsoft Office现在将下载指定版本的Microsoft Office并回滚到该以前的版本。请耐心等待，因为这可能需要几分钟或更长时间，具体取决于您的计算机和Internet连接速度。

![](../Images/1d1d978edef6a0d1518be9e1c32976d6.png)

将Microsoft Office回滚到以前的版本  

  

5.更新安装完成后，将显示一个屏幕，指出“已安装更新”。您可以按此 屏幕上的  关闭按钮。

![](../Images/2dc263fe6fc42d2fb69c29715e036d58.png)

已安装Microsoft Office更新  

  

6.现在，Microsoft Outlook将回滚到以前的版本，您应该能够再次启动Microsoft Outlook。

7.现在，您可以通过单击X按钮关闭命令提示符。

  

一些Outlook用户报告上述步骤不适用于他们，但是他们可以使用  officec2rclient.exe /update user updatetoversion=16.0.12527.20880命令代替此问题。

  

**方法2：在安全模式下启动Microsoft Outlook**

如果您不想回滚到以前的Microsoft Office版本，则可以在安全模式下启动Microsoft Outlook来修复崩溃。

  

应该注意的是，在安全模式下启动Outlook时，所有加载项都将被禁用，包括安全加载项。

  

**要以安全模式启动Outlook，请按照下列步骤操作：**

  

1.按住键盘上的Ctrl键，然后启动Microsoft Outlook。Outlook将继续启动，然后询问您是否确定要以安全模式启动。

![](../Images/67ba85c00c9af78d9e01f7d9141339bf.png)

是否要以安全模式启动Outlook？  

  

2.现在，您应该按“ 是”  按钮，Outlook将在禁用加载项的情况下以安全模式启动。

3.Outlook启动后，您可以确认您处于安全模式，因为Outlook窗口的标题将显示“ Microsoft Outlook（安全模式）”，如下所示。

![](../Images/e4efea870998ff84b81000972ad53fdb.png)

Microsoft Outlook以安全模式启动  

  

4.使用Outlook完成后，您只需关闭程序即可。

  

**应该注意的是，您每次想以安全模式启动Outlook时都需要重复此过程。**

  

如果这些方法不起作用，请忽略。
