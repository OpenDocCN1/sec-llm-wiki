微软修复了Windows 10和Server问题，导致重启，LSASS崩溃

Microsoft今天修复了导致本地安全机构子系统服务（LSASS）崩溃并在某些Windows设备上强制重新启动系统的已知问题。


LSASS是Windows服务，负责执行安全策略，用于将条目添加到安全日志，以及处理用户登录，访问令牌创建和密码更改。


如果LSASS进程失败，则用户将立即失去对计算机上可用Windows帐户的访问权限，将显示错误，并且将在一分钟之内强制重启设备。


微软今天在2020年7月修补程序周二发布的KB4565503累积更新中解决了LSASS崩溃问题，  旨在为运行Windows 10版本2004的设备提供改进，修复和安全更新。


Windows 10重新启动消息


错误影响了台式机和服务器设备

如Microsoft所揭示，在受此Windows错误影响的设备上，关键的LSASS（lsass.exe）系统进程将失败，并显示以下错误消息：


A critical system process, C:\WINDOWS\system32\lsass.exe, failed with status code c0000008. The machine must now be restarted.


Microsoft已于6月24日（即将其添加到KB4557957和KB4560960累积更新条目以及KB4567512  和KB4567523  可选更新的条目中）的  第二天，将该问题包含在Windows 10运行状况仪表板上。


已知问题影响了台式机和服务器Windows平台，包括：


•客户端：

Windows 10版本2004版；

Windows 10版本1909; 

Windows 10版本1903; 

Windows 10版本1809; 

Windows 10企业版LTSC 2019

•服务器：

Windows Server版本2004；

Windows Server版本1909；

Windows Server版本1903；

Windows Server版本1809; 

Windows Server 2019


KB4565503还解决了IME问题

Microsoft今天还解决了5月27日发布的KB4565503的另一个已知问题，该问题导致使用ImeMode属性控制Windows 10（2004版）和Windows Server 2004版系统上各个文本输入字段的IME模式。


微软解释说：“某些应用程序利用ImeMode属性来控制单个文本输入字段的IME（输入法编辑器）模式，以提高键入效率。”


“ Windows 10版本2004（2020年5月更新）中的某些IME可能对某些应用程序使用ImeMode属性会出现问题。 


“例如，输入模式不会自动切换到全角片假名模式，全角字母数字模式或全角平假名模式。”
