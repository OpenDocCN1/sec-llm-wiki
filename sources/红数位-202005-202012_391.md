# Windows 10累积更新KB4565503和KB4565483已发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489582&idx=4&sn=d2e0c4ce79770f125400a0c8c81b53bc&chksm=cef3759df984fc8bce7b9f1d8f6ef8627a8b9839b704b268d59b90c4aace3fdb4feda11ddc7b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489582&idx=4&sn=d2e0c4ce79770f125400a0c8c81b53bc&chksm=cef3759df984fc8bce7b9f1d8f6ef8627a8b9839b704b268d59b90c4aace3fdb4feda11ddc7b&scene=27#wechat_redirect)

Windows 10版本2004及更高版本的2020年7月补丁星期二更新现已推出，您可以通过在设置中检查更新来下载并安装最新的安全修补程序。

  

![](../Images/c53092aeed68d650398f9d45aa8184eb.png)

  

像每个星期二的补丁程序一样，累积更新附带安全修复程序和常规错误修复程序，并且该补丁程序将在2020年5月更新，2019年11月更新，2019年5月更新及更高版本中推出。

  

在Windows 10版本2004，版本1909和版本1903的最新累积更新中，微软表示已解决了可能导致  lsass.exe  失败并显示错误消息“关键系统进程C：\\ WINDOWS \\ system32 \\”的问题。lsass.exe，失败，状态码为c0000008。现在必须重新启动计算机。”

  

与往常一样，Microsoft Store，经典Microsoft Edge浏览器，Microsoft Store，核心组件和其他基本功能都有安全增强功能。

  

以下是Windows 10所有新更新的列表：

  

*   Windows 10版本1507-  KB4565513（操作系统内部版本10240.18638）
    
*   Windows 10版本1607-  KB4565511（操作系统内部版本14393.3808）
    
*   Windows 10版本1703-  KB4565499（操作系统内部版本15063.2439）
    
*   Windows 10版本1709-  KB4565508（操作系统内部版本16299.1992）
    
*   Windows 10版本1803-  KB4565489（操作系统内部版本17134.1610）
    
*   Windows 10版本1809-  KB4558998（操作系统内部版本17763.1339）
    
*   Windows 10版本1903/1909- KB4565483（操作系统内部版本  18362.959和18363.959）
    
*   Windows 10版本2004 —  KB4565503（操作系统内部版本19041.388）
    

  

要安装补丁，请转到“设置”应用，然后单击Windows Update选项以安装补丁。如果您拥有多台PC，或者想手动修补PC，则可以在此处了解更多信息  。

  

**版本2004的内部版本19041.388**

Windows 10版本2004的第一个累积更新为KB 4565503，它包含以下修复程序：

  

*   解决了在Windows 10版本2004（2020年5月更新）中使用ImeMode属性控制输入法编辑器（IME）模式的某些应用程序中的问题。例如，此问题阻止输入模式自动切换到汉字或平假名。有关更多信息，请参见  KB4564002  和博客文章“  为发布的2020年5月更新做好准备-UPDATED”。
    
*   解决了可能阻止您使用PowerShell更改Server Core平台上的系统区域设置的问题。
    
*   解决了在窗口模式下调整大小或从全屏模式切换到窗口模式时可能导致某些游戏和应用程序出现视觉失真的问题。 
    
*   解决了可能导致  lsass.exe  失败并显示错误消息的问题，“关键系统进程C：\\ WINDOWS \\ system32 \\ lsass.exe失败，状态码为c0000008。现在必须重新启动计算机。”
    
*   解决了在安装2020年6月9日发布的Windows Update之后可能阻止某些应用程序打印包含图形或大文件的文档的问题。
    
*   解决了可能导致您无法使用OneDrive应用连接到OneDrive的问题。在某些较旧的设备上或在具有较旧应用程序的设备上使用旧文件系统筛选器驱动程序，就会发生此问题。因此，这可能会阻止这些设备下载新文件或打开以前同步或下载的文件。
    
*   Microsoft脚本引擎，Windows App平台和框架，Microsoft Store，Windows图形，Windows输入和合成，Windows Media，Windows Shell，Windows基础知识，Windows管理，Windows内核，Windows混合云网络，Windows存储和文件系统的安全更新，Windows更新堆栈，Windows MSXML，Windows文件服务器和群集，Windows远程桌面，Internet Explorer，  Microsoft Edge旧版以及Microsoft JET数据库引擎。

**版本1903/1909的版本18362.959和18363.959**

*   解决了在Microsoft Edge IE模式下加载浏览器帮助器对象的问题。

*   解决了在安装2020年6月9日发布的Windows Update之后可能阻止某些应用程序打印包含图形或大文件的文档的问题。
    
*   Internet Explorer，Microsoft脚本引擎，Windows App平台和框架，Windows Apps，Microsoft图形组件，Windows输入和合成，Windows Media，Windows Shell，Microsoft Store，  Microsoft Edge Legacy，Windows Cloud Infrastructure，Windows基础知识， Windows管理，Windows内核，Windows存储和文件系统，Windows Update堆栈，Windows MSXML，Windows文件服务器和群集，Windows远程桌面以及Microsoft JET数据库引擎。
