# 传华为鸿蒙OS 2.0今秋推出

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489283&idx=2&sn=89dd963a30956e1b550fdba8ba7b560f&chksm=cef37ab0f984f3a6f1f306e5e996d4924ef7d49125185e84b29c93f5acb4a282e299f5a03847&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489283&idx=2&sn=89dd963a30956e1b550fdba8ba7b560f&chksm=cef37ab0f984f3a6f1f306e5e996d4924ef7d49125185e84b29c93f5acb4a282e299f5a03847&scene=27#wechat_redirect)

在华为去年8月份的开发者大会上，华为自研的鸿蒙操作系统（英文名HarmonyOS）正式面世。关于华为的这款自研操作系统，最大的特色就是覆盖使用全场景，可以用于智能手机、智能电视、智能手表、汽车以及PC等等。到目前为止，鸿蒙OS仅仅被应用在智慧屏产品上。

![](../Images/0bea9ecf9b9db24d699d747320fec7b4.png)

根据华为去年在开发者大会上公布的信息，鸿蒙OS 2.0版本将会在今年推出，并且搭载新版本系统的消费者产品将会从智慧屏扩展到创新国产PC、手表/手环以及车机。从这个信息来看，华为将会在今年推出搭载鸿蒙OS 2.0的智能手表产品。目前，关于搭载鸿蒙OS 2.0系统的智能手表产品已经有了新的消息。

根据目前多方的爆料消息，华为将会在今年秋推出新款智能手表产品，并且这款产品将会归属于定位高端的Mate系列，时间上回合Mate40系列产品重叠。根据目前华为产品线来看，如果华为在今年晚些时候随着Mate40系列产品推出Mate Watch，那么新系列的智能手表产品很有可能会成为取代目前的watch GT的产品。

其他方面，华为在今年5月份的时候申请了Mate Watch商标。相较于目前的watch GT产品，**搭载鸿蒙OS 2.0的Mate Watch应该是一款所谓的“真正的智能手表”，运行完整的操作系统，可以通过安装应用的方式对手表的功能进行管理。而目前的watch GT产品更多像一款智能手环产品，主打健身、健康监测，很像一款多功能功能机，好处就是续航时间非常长。**

目前，在智能穿戴市场上，苹果无疑是这一领域的霸主，随着这家公司对其Apple Watch的不断升级改造以及重新定位，苹果已经在今年第一季度拿下了全球可穿戴市场29.3%的份额（IDC数据，下同），比排在第二第三加起来的量都大。不过，华为在可穿戴市场的表现也是十分亮眼的，在今年一季度大家都呈现下滑态势的时候，华为逆势实现同比年增长率118.5%。

而在国内市场上，华为在今年一季度已经成为最大的可穿戴设备厂商，占据了24.3%的市场份额，而苹果则是第三。

根据华为公布的内容来看，鸿蒙OS 2.0的主要改进点将有升级的通用微内核架构、高性能图形性、支持多语言统一编译、多终端开发IDE以及满足车机标准等等。我们可以期待在今年8月份的时候看到鸿蒙OS 2.0正式亮相。
