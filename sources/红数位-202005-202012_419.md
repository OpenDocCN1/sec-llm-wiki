# 微软Windows 10防病毒现已可用Linux上

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489275&idx=2&sn=542be3d18fc5f2966960dad8f0bd4a33&chksm=cef37b48f984f25e35bebd9670e090bd4473e4016eff593256c604c47e29384758229aee1de4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489275&idx=2&sn=542be3d18fc5f2966960dad8f0bd4a33&chksm=cef37b48f984f25e35bebd9670e090bd4473e4016eff593256c604c47e29384758229aee1de4&scene=27#wechat_redirect)

微软在推出预览版应用程序几个月后，刚刚宣布了适用于Linux的Microsoft Defender ATP的全面可用性。

  

![](../Images/60d9bd210cd2ffb4be6e3cd600a2adb0.png)

  

“ Microsoft Defender ATP将Linux添加到现有的本机支持平台的选择中，对我们所有客户而言都是重要的时刻。它使Microsoft Defender安全中心成为真正的统一表面，用于监视和管理在企业环境（Windows，Windows Server，macOS和Linux）中常见的台式机和服务器平台的全部安全。”

  

Microsoft Defender ATP for Linux当前支持总共六种不同的服务器发行版，包括以下内容：  

*   RHEL 7.2以上
    
*   CentOS Linux 7.2以上
    
*   Ubuntu 16 LTS或更高版本
    
*   SLES 12+
    
*   Debian 9+
    
*   Oracle Linux 7.2
    

  

**微软对Linux的热爱**

微软将更多精力放在Linux生态系统上并不一定会感到惊讶，因为该公司正在努力扩展这个世界。

  

在这方面，当前是Windows 10的第二代产品的Linux的Windows子系统是这方面的生动证明，因为它允许用户在Windows之上运行Linux。在2020年5月更新（或2004年版本）中首次亮相的新版本还带有Linux内核，并且已经可以使用最受欢迎的发行版，包括Ubuntu。

  

新的防病毒软件应该在客户端上提供完整的命令行体验，但是管理员需要知道的是，安装Microsoft Defender ATP for Linux需要Microsoft Defender ATP for Servers许可证。

  

该公司表示，它计划对Linux进行更多的改进，并且更多的公告将在不久之后被共享。

  

“我们才刚刚开始Linux之旅，我们并没有就此停止！我们致力于不断扩展Linux功能，并在未来几个月内为您带来增强功能。”
