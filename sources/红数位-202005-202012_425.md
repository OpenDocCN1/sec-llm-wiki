# CIA发现无法保护自己的系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489210&idx=4&sn=a4e3e856a242f36cec4021da3e59a56c&chksm=cef37b09f984f21fff30205eab362a273c3d3481ffb2d87c51a09a4cae0c99d08d9b950b4636&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489210&idx=4&sn=a4e3e856a242f36cec4021da3e59a56c&chksm=cef37b09f984f21fff30205eab362a273c3d3481ffb2d87c51a09a4cae0c99d08d9b950b4636&scene=27#wechat_redirect)

周二发布的内部CIA内部报告发现，该机构未能保护自己的系统导致了2017年大规模数据泄露，使机密信息（包括35个CIA黑客工具的详细信息）泄露给了WikiLeaks。

  

![](../Images/986e4af0564e1c6e986419ae0895b785.png)

  

这份由美国中央情报局的维基解密特别工作组于2017年编写的报告的修订版由参议院情报委员会成员D-Ore 的罗恩·怀登（Ron Wyden）发布。

  

该报告指出，中央情报局的网络情报中心没有优先考虑内部网络安全，而是着重于开发进攻性网络武器。

  

报告指出，即使在此前该机构和其他情报部门的高调数据泄露之后，对CIA内部预防性网络安全措施的松懈态度仍在继续。

  

周二，怀登致信国家情报局局长约翰·拉特克利夫（John Ratcliffe），要求了解美国情报界是否计划实施更好的网络安全措施，并质疑中央情报局为何不做更多工作来保护其内部安全行动免受外部攻击和内部攻击威胁。

  

Wyden写道：“ CIA的WikiLeaks Task Force报告中记录的松懈的网络安全实践似乎不仅限于情报界的一部分。” “情报共同体监察长办公室在去年发布的一份报告的公开摘要中透露，它发现了情报共同体的网络安全实践中存在许多缺陷。”

  

**中情局报告**

WikiLeaks Task Force报告是在CIA黑客工具泄漏后编写的，该工具被称为“ Vault 7”（请参阅：WikiLeaks转储指控CIA恶意软件和Hacking Trove）。

  

直到2016年WikiLeaks公布了Vault 7系列之后，才发现了盗窃工具的行为，这种盗窃事件显然是在2016年的某个时候才发现的。后来，美国司法部对前CIA员工若舒·舒尔特（Joshua Schulte）提出了指控，他涉嫌偷窃了该工具。据《华盛顿邮报》报道，美国中央情报局的黑客工具，然后将其提供给WikiLeaks 。

  

据《邮报》报道，维基解密特别工作组的报告是司法部针对舒尔特案的一部分，舒尔特将于今年3月在其悬而未决的陪审团中首次审判结束后，于今年晚些时候因Vault 7泄漏而再次受审。

  

在报告中，调查人员描述了一位未透露姓名的前CIA雇员如何管理180至34 TB高度机密的机构信息和数据。

  

该报告描述了一种仅专注于开发进攻性网络武器而忽略了导致多个漏洞的基本安全程序的CIA文化。

  

“日常的安全实践变得非常松懈。...我们的大多数敏感网络武器都没有分隔，用户共享系统管理员级别的密码，没有有效的可移动媒体控件，并且历史数据可以无限期地提供给用户”，根据中央情报局的报告。

  

WikiLeaks称，Vault 7黑客工具来自位于弗吉尼亚州兰利的CIA网络情报中心内部的隔离，高安全性网络。

  

**防止泄漏的困难**

研究网络安全问题的约翰·霍普金斯大学高级国际研究学院的教授托马斯·里德（Thomas Rid）在推特上写道，美国情报界很难阻止泄密事件，包括7号避难所以及前陆军切尔西·曼宁和前国家安全局承包商爱德华斯诺登。

  

![](../Images/dd08326125a325de147ddc69cdf245e6.png)

  

  

网络安全咨询公司Rendition Infosec的总裁杰克·威廉姆斯（Jake Williams）以及前NSA职员指出，Vault 7的披露，以及被称为Shadow Brokers的组织在2016年发布的NSA黑客工具，表明美国情报界并未采取认真对待其网络安全责任。

  

威廉姆斯对信息安全媒体集团说：“在至少两种情况下（Vault 7和Shadow Brokers），没有迹象表明在公开发布数据之前有任何检测到。” “如果将情报界与一个商业组织进行比较，该商业组织在过去几年中发生了三处重大漏洞，并且直到有人公开泄漏数据才发现其中两处，我很难认真对待它们的安全性。”

  

**需要改进安全性**

怀登在致国家情报局局长拉特克利夫的信中问，为什么各个机构都没有遵守安全指导。这包括：

  

*   2017年10月16日，网络安全和基础设施安全局发出通知，要求所有联邦机构使用加密和基于域的消息身份验证以及DMARC电子邮件身份验证，策略和报告协议来保护其网站和电子邮件；
    
*   CISA于2019年1月22日发布的紧急指令要求各机构在10天内实施多因素身份验证以保护其.gov域。
    

  

Wyden还质疑为什么联合世界英特尔通信系统（情报界处理机密信息的机密计算机网络）仍未实施多因素身份验证以使其符合美国国家标准技术研究院特别出版物800-63B（尽管2019年8月发表了声明）美国国防情报局（Defense Intelligence Agency）网络和企业运营负责人表示，DIA正在研究此升级。

  

在信中，怀登问拉特克利夫（Ratcliffe）是否打算实施由情报社区监察长办公室于2019年11月发布的众多网络安全建议。

  

“您打算采用情报共同体监察长的22条网络安全建议中的每条建议吗？” 怀登问。“如果是，请提供您预计何时将实施这些建议的估计。如果否，请解释原因。”

  

中央情报局发言人告诉《华盛顿邮报》，该机构未对Wyden周二发布的2017年报告发表评论。

  

**遵循准则**

安全公司Vectra的CTO团队技术总监，前空军官员蒂姆·韦德（Tim Wade）指出，政府机构，尤其是情报界，需要遵循网络安全准则。

  

韦德说：“接受在脆弱状态下继续运行此类系统的风险，可以减轻与破坏任务成功有关的更大风险。”
