# 微软6月周二补丁日修复了129漏洞 史上最多补丁日

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247489163&idx=1&sn=684f0835d69ed9b7b509e6a239467d80&chksm=cef37b38f984f22e3cf281b46b68012516459445d940eb98c70a660dc0e1e769fca9eada0996&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247489163&idx=1&sn=684f0835d69ed9b7b509e6a239467d80&chksm=cef37b38f984f22e3cf281b46b68012516459445d940eb98c70a660dc0e1e769fca9eada0996&scene=27#wechat_redirect)

今天是微软的2020年6月补丁程序星期二，由于许多Windows管理员会头大，因为今天史上最多一次补丁发布！

  

![](../Images/a3d8380183c35509c902c2c297e2652f.png)

  

**随着2020年6月补丁星期二安全更新的发布，Microsoft已发布Adobe Flash Player更新的一个公告，并修复了Microsoft产品中的129个漏洞。**

  

**在这些漏洞中，有11个被分类为危急，将109个分类为重要，将7个分类为中等，将2个分类为低。**

  

这是微软有史以来最大的补丁周二更新，**第二大更新是2020年3月的115个修复程序，第三大更新了2020年4月的113个修复程序。**

  

***本月没有零日漏洞或已知的未修补漏洞。***

  

用户应尽快安装这些安全更新，以保护Windows免受已知的安全风险。

  

**关键的重要漏洞**

Microsoft Edge和VBScript引擎中存在三个“关键”漏洞，这些漏洞可能使攻击者通过诱骗用户访问恶意制作的网站来执行远程代码执行。

  

*   **CVE-2020-1219-Microsoft浏览器内存损坏漏洞**
    
*   **CVE-2020-1216 | VBScript远程执行代码漏洞**
    
*   **CVE-2020-1216 | VBScript远程执行代码漏洞**
    

  

如果利用这些漏洞，攻击者可以利用与用户相同的特权在计算机上执行命令。

  

其他有趣的“严重”漏洞需要攻击者诱骗用户下载特制恶意文件。这些漏洞可用于网络钓鱼或网络攻击。

  

*   **CVE-2020-1248-GDI +远程执行代码漏洞**
    
*   **CVE-2020-1281-Windows OLE远程执行代码漏洞**
    
*   **CVE-2020-1299-LNK远程执行代码漏洞**
    

  

**其他公司的最新安全更新**

其他在六月发布安全更新的供应商包括：

  

*   Adobe  今天发布了针对Flash Player，Experience Manager和Framemaker的安全更新。
    
*   Android 于6月1 日发布了2020年6月的安全更新。
    
*   Google Chrome 83.0.4103.97于6月3日发布，  具有五个安全修复程序。
    
*   英特尔今天通过2020年6月平台更新修复了22个漏洞。
    
*   Mozilla发布了Firefox 77.0.1，以防止来自DDoSing DNS提供商的HTTP-over-HTTPS。
    
*   SAP 今天发布了2020年6月的安全更新。
    
*   VMWare 发布了  针对VMware ESXi，Workstation和Fusion的安全更新。
