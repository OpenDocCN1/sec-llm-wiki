# VMware Cloud Director中修补的远程执行代码漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488888&idx=7&sn=91be79dbb9740212a031a1253cce6d16&chksm=cef378cbf984f1dde7da3c12a806d309697d97b11c1cb3b122623af87e8692e19f9b483ef115&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488888&idx=7&sn=91be79dbb9740212a031a1253cce6d16&chksm=cef378cbf984f1dde7da3c12a806d309697d97b11c1cb3b122623af87e8692e19f9b483ef115&scene=27#wechat_redirect)

VMware周二通知客户，它已在其Cloud Director产品中修复了一个严重性很高的远程代码执行漏洞。

  

![](../Images/83670a2d015013c4f79ad63568ca6216.png)

该漏洞被跟踪为CVE-2020-3956，已被描述为代码注入问题，允许经过身份验证的攻击者向Cloud Director发送恶意流量，这可能导致任意代码执行。

  

“这个漏洞可以通过HTML5-和基于Flex的UI被利用，该API资源管理器界面和API访问权限，” VMware的在说咨询。

  

该安全漏洞影响Linux和Photon OS设备上的VMware Cloud Director 10.0.x，9.7.x和9.5.x，以及Linux上的9.1.x版本。版本8.x，9.0.x和10.1.0不受影响。

  

VMware已发布了应修补此漏洞的更新，以及用户可以用来防止攻击的变通办法。

  

Citadelo的TomášMelicher和LukášVáclavík因向VMware报告此问题而受到赞誉。

  

本月早些时候，VMware发布了vRealize Operations应用程序远程收集器（ARC）的补丁程序，以解决最近披露的两个Salt漏洞，这些漏洞已经被用于组织攻击。

  

今年4月，这家虚拟化巨头修补了一个关键漏洞，黑客可以利用该漏洞来破坏vCenter Server或其他服务。几天后，研究人员披露了有关该漏洞的详细信息。
