# 特朗普的"黑历史"被买走了

在上几期，黑鸟对Sodinokibi/REvil*[勒索软件黑客团伙威胁特朗普，声称拥有其黑历史](http://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451180483&idx=1&sn=22c2ad133fc835e2d3c8124d066d6ef9&chksm=8c26fd1abb51740cad34ad2751e9479e2996cec6335e1577d5055b474ef822f4dbaed3a902cd&scene=21#wechat_redirect)*一事进行了报道，详情可点击蓝字链接查看。

  

简单来说，黑客因为拿不到预期的赎金，因此将其资金需求增加了两倍，达到4,200万美元，同时还声称他们可以访问涉嫌与美国总统唐纳德·特朗普有关的机密数据。

  

根据REvil勒索软件组织的说法，该数据有可能影响即将举行的特朗普总统的竞选活动，因此，其目的是使特朗普迫使律师事务所付清款项。

  

  

![](../Images/04a43b3b11476e6af0f561a8c64d8fcb.png)

  

但是就在最近，攻击者发布了169封电子邮件，其中显示了所谓的证据，证明他们确实声称有权访问有关特朗普的材料。

  

![](../Images/dd45726ee30776553783814cb2afe8ae.png)

  

这169封电子邮件毫无疑问是从Grubman Shire Meiselas＆Sacks律师所的系统中非法获取的。

  

但这些内容仅仅包括在某些电视节目和广告中对特朗普的讽刺性讨论，以及他在2015年接受美国广播公司新闻“ 20/20”对芭芭拉·沃尔特斯的采访。

  

同时，被黑的电子邮件中有邮箱地址，其中包含有关当前白宫居住者文章的链接。其他一些是与一家公司的信件，该公司的办公室在纽约特朗普大厦。另一封电子邮件链引用了一位住在纽约特朗普国际大厦酒店的客户。

  

因此可能是这群黑客，通过邮件搜索，然后把含有Trump关键字的邮件全部提取了出来。

  

而上期也讲过了，黑鸟已经铁定认为特朗普的黑历史要被放出来了，结果还是被打脸了。

  

就在近日，该黑客团伙在其网站上发布了新闻稿3，其中居然提到，有人把有关美国总统的所有数据全部购买了！  

  

![](../Images/b1c1051ef8a1ecd658229133aee93f35.png)

  

翻译如下:

  

有兴趣的人联系我们，并同意购买有关美国总统的所有数据，这些数据是我们在整个活动期间积累的。我们对这笔交易感到满意，并恪守诺言。

  

2020年5月25日，我们正准备拍卖麦当娜的数据。规则是相同的：

1.单手信息

2.交易的保密性

3.我们删除数据副本

4.买方有权对收到的数据采取其认为合适的一切。

  

起拍价-一百万美元。

  

而他的诺言，便是将含有特朗普邮件下载链接的地址给删除掉了！  

  

erased = 已擦除

  

![](../Images/11954f28b8aebf66d4c902fc06dff95a.png)

个人对此进行分析，首先卖肯定是要卖的，这群黑客可是利益至上主义者，外加公布的小部分邮件确实为真，有钱为啥不赚，卖个假货直接删库跑路也是一条出路，然而他们选择的是擦除下载链接，这从该黑客团伙前几次的交易成功后擦除链接的行为如出一辙。

  

此外，关于买方身份，可能是特朗普非常密切，希望可以泄露"黑历史"，也可能是特朗普的敌对势力，想搞大事情。而既是敌对势力，又想试图从中找到特朗普黑历史从而使特朗普落选的，无论如何这口黑锅都得美国民主党来背了。
