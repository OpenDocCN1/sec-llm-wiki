# 欧洲超级计算机遭到神秘网络攻击,沦为挖矿肉鸡

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488846&idx=4&sn=4b666319c3c35afd33fa9738068d4dbc&chksm=cef378fdf984f1eb5d5066ef8c0c941720749aad73e07adfea1041d906acdc10ab7a36a744f0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488846&idx=4&sn=4b666319c3c35afd33fa9738068d4dbc&chksm=cef378fdf984f1eb5d5066ef8c0c941720749aad73e07adfea1041d906acdc10ab7a36a744f0&scene=27#wechat_redirect)

  

由于安全事件，本周在欧洲各地关闭了一些用于研究项目的高性能计算机（HPC）和数据中心。

  

![](../Images/3698eaebb6f84c5417e33104cc8d38dd.png)

  

这些超级计算机中大约有十二个在德国，英国和瑞士受到影响，研究人员无法继续他们的工作。一些最早在一月份就受到了损害。

  

超级计算机是建立在传统硬件上的功能强大的系统，可以执行高速计算。它们主要用于科学工作和测试复杂物理现象和设计的数学模型。

  

**德国有多个集群**

周一，英国和德国开始发出有关网络攻击后超级计算机被关闭的通知。

  

由于其登录节点的安全漏洞，英国国家超级计算服务机构ARCHER在5月11日对研究人员不可用。该服务仍然锁定外部访问，明天将发布新消息。

  

![](../Images/55209ca5afe4893af6b83c3e32d7c39b.png)

  

“当前正在运行或正在排队的作业将继续运行，但是您将无法登录或提交新作业”

  

另一个通知所有现有的ARCHER？密码和SSH密钥将被重置。服务恢复在线状态时登录的用户将需要两个凭证：带密码的SSH密钥和新鲜的ARCHER密码。

  

![](../Images/f1832dc77f4afc77adc4557f1b71c1c1.png)

  

同一天，德国的巴登-符腾堡州高性能计算（bwHPC）项目宣布发生安全事件，导致五个集群不可用，没有恢复运行的时间表：

  

*   **卡尔斯鲁厄理工学院的bwUniCluster 2.0**
    
*   **卡尔斯鲁厄理工学院的ForHLR II**
    
*   **bwForCluster JUSTUS，用于化学应用**
    
*   **蒂宾根大学的bwForCluster BinAC，用于生物信息学和天体物理学项目**
    
*   **Hawk于2月在斯图加特的高性能计算中心揭幕**
    

  

莱布尼兹超级计算中心周四通知用户，安全事件影响了其高性能计算机，促使该研究所将其与外界隔离。

  

同样在星期四，德国的Jülich超级计算中心（JSC）宣布，由于IT安全事件，其JURECA，JUDA和JUWELS超级计算机不可用。

  

SPIEGEL记者Patrick Beuth称，到本周末，至少有9台德国超级计算机受到了网络攻击。

  

 德累斯顿工业大学针对Taurus系统发布了类似的注释：“由于安全问题，我们暂时关闭了对Taurus的访问。”

  

位于弗莱堡的bwForCluster NEMO也被黑客入侵，该bwForCluster NEMO用于神经科学研究，基本粒子物理学和微系统工程研究。

  

Beuth报告说，用户收到了一封电子邮件，指出攻击者的进入方式是一个具有root特权的帐户被盗。总共检测到七次攻击，第一次是1月9日。

  

瑞士科学计算中心（CSCS）周六通知其用户，由于在系统上检测到恶意活动，因此无法再访问几台高性能计算机和学术数据中心。

  

***“我们目前正在调查非法进入该中心的情况。我们的工程师正在积极致力于尽快恢复系统，以将对用户的影响降至最低。”-CSCS总监Thomas Schulthess***

  

**加密劫持意图**

有关攻击目的的细节很稀少，但是欧洲网格基础设施（EGI）昨天在一份通报中发布了有关两次袭击学术数据中心的网络攻击的细节，这些袭击似乎是同一行为者的工作。

  

在这两种情况下，攻击者都使用受感染的SSH凭据从一台主机跳到另一台主机，从而滥用CPU资源来挖掘Monero加密货币。一些主机用于挖掘，另一些是用于连接到挖掘服务器的代理。

  

EGI的计算机安全事件响应团队（CSIRT）发现，在一种情况下，恶意挖掘活动被配置为仅在夜间运行，最有可能避免检测。

  

CSIRT发布了针对他们分析的事件的技术细节和妥协指标，并指出受害者位于中国，美国和欧洲。

  

**恶意软件详细信息**

CrowdStrike的安全研究员Tillmann Werner告诉BleepingComputer，该恶意软件的一个组件具有root特权并加载其他程序。另一个组件用于从日志数据中删除跟踪。

  

研究人员还说，这两个组件都是ELF64二进制文件。加载程序位于“ /etc/fonts/.fonts”下，日志清理程序位于“ /etc/fonts/.low”下。

  

显然，在目标系统上编译的文件不同，但是它们的功能是相同的。他提供YARA吗？检测规则为两个部件（1，2） ：

  

rule loader { strings: $ = { 61 31 C2 8B 45 FC 48 98 } condition: all of them }

rule cleaner { strings: $ = { 14 CC FC 28 25 DE B9 } condition: all of them }

  

美国网络安全公司Robert Helling和  Cado Security提供了对这两个恶意软件组件的分析。该公司表示，该恶意软件已从德国，英国，瑞士和西班牙上载到VirusTotal扫描服务。

  

安全研究员费利克斯·冯·莱蒂纳（Felix von Letiner）在博客中说，他在波兰的同事报告说，巴塞罗那的一台超级计算机也受到了影响。
