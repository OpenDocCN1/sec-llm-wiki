# 朝鲜黑客感染真正的2FA应用以危害Mac

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488787&idx=3&sn=00a1a6e35ff76de1ff518fc49404ee52&chksm=cef378a0f984f1b65ea9d0225d4c4c58aed8fe10c2fa827d2ba1194f144d4424a210e6d13b75&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488787&idx=3&sn=00a1a6e35ff76de1ff518fc49404ee52&chksm=cef378a0f984f1b65ea9d0225d4c4c58aed8fe10c2fa827d2ba1194f144d4424a210e6d13b75&scene=27#wechat_redirect)

黑客在适用于macOS的合法两因素身份验证（2FA）应用程序中隐藏了恶意软件，以分发**Dacls（与朝鲜拉撒路组织相关的远程访问木马）**。

  

![](../Images/5cfb59665306581cdb7308fa3e290c8a.png)

  

**Dacls已用于Windows和Linux平台，而最近发现的macOS RAT变体借鉴了其中的许多功能和代码。**

  

**设置持久性**

威胁者将恶意软件植入了在中国用户中普遍存在的免费可用的MinaOTP应用程序中。上个月，从香港上载了一个名为TinkaOTP的带有武器版本的样本，该样本已提供给VirusTotal扫描服务。

  

Malwarebytes的恶意软件分析师在本周的报告中说，当时是4月8日，它未被检测到。目前，在59个防病毒引擎中，有29个发现了恶意文件。

  

![](../Images/f98915e61dcb9ed0104e3f40b79702dc.png)

  

  

重新启动系统后，恶意软件会执行，因为它已添加到LaunchDaemons和LaunchAgents用于在启动时运行应用程序的属性列表（plist）文件中。

  

***“LaunchAgents和LaunchDaemons之间的差别在于LaunchAgents代表的登录用户运行的代码而LaunchDaemon运行代码作为根用户” - 的Malwarebytes***

  

**相同的RAT，不同的操作系统**

与Windows和Linux上的Dacls的连接是显而易见的。研究人员在macOS变体中发现，证书和专用文件的名称“ c\_2910.cls”和“ k\_3872.Cls”在所有三个操作系统中都相同。

  

恶意软件的配置文件提供了对通用根的进一步证据，该配置文件使用与Dacls RAT for Linux中相同的AES密钥和初始化矢量进行了加密。

  

研究人员发现，macOS示例中的七个插件中的六个也存在于Linux变体中。新颖的是Socks模块，它可以启动恶意软件和C2基础结构之间的代理。

  

![](../Images/ee50da5d3ab5794a16f1b4478b5edc89.png)

  

奇虎360的Netlab的研究人员详细分析了2019年12月中发布的六个插件的功能。这些插件用于以下目的：

  

*   CMD / Bash插件-接收和执行C2命令
    
*   文件插件-文件管理（读取，写入，删除，从特定服务器下载，搜索）；Mac OS的Dacls不支持写入功能
    
*   流程插件-流程管理（杀死，运行，获取流程ID，枚举）
    
*   测试插件-macOS和Linux版本中的代码相同，测试与C2指定的IP地址和端口的连接
    
*   RP2P（反向对等）插件-C2和受感染系统之间的代理服务器
    
*   LogSend插件-检查与Log Server的连接，扫描端口8291或8292上的网络，执行需要很长时间的系统命令
    

  

与C2服务器的连接依赖于用于安全通信的开源WolfSSL库，该库由多个威胁参与者使用。

  

对于Lazarus而言，将恶意软件放入macOS的合法应用程序中并不是第一次。卡巴斯基（Kaspersky）2018年的一份报告显示，黑客已经木马破解了加密货币交易平台的安装程序。

  

2019年9月，恶意软件研究人员分析了macOS交易应用程序，该应用程序打包了恶意软件以窃取用户信息。快进到12月，来自Lazarus并使用相同策略的新macOS恶意软件出现在公众视野中。

  

总而言之，这不是该组织第一次攻击macOS。因此，作为用户，我们可以采取简单的预防措施，例如安装信誉良好的防病毒程序，下载文件以及使用可靠的防病毒软件扫描文件以查找任何恶意软件，以及检查其哈希值以验证其原始性。
