# 微软GitHub帐户疑被入侵,盗500GB

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488719&idx=1&sn=688d77c2d5ee34deb49833862835c8f4&chksm=cef3797cf984f06aa408a2a848285c747266ff11daa3e813185dd75dfd8155f1c5e26711859b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488719&idx=1&sn=688d77c2d5ee34deb49833862835c8f4&chksm=cef3797cf984f06aa408a2a848285c747266ff11daa3e813185dd75dfd8155f1c5e26711859b&scene=27#wechat_redirect)

一名黑客声称从微软的私有GitHub存储库中窃取了500GB以上的数据。

  

今天晚上，一个名叫Shiny Hunters的黑客联系了外媒，表示他们已经入侵了Microsoft GitHub帐户，并获得了对该软件巨头的“私人”存储库的完全访问权限。

  

![](../Images/dad49c8e9deb8e41448ccae73ba78923.png)

黑客访问Microsoft的私有GitHub存储库的证明

  

这位个人告诉外媒，他随后下载了500GB的私人项目，并最初计划出售它，但现在决定免费泄漏它！

  

根据泄露文件中的文件戳记，泄露可能发生在2020年3月28日。

  

![](../Images/02641b5a4e44b0372fb0934827afcfb3.png)

泄漏的数据清单显示违反日期  

  

今天该黑客表示他不再有权访问该账户。

  

**私人储存库泄漏**

作为预告，黑客在黑客论坛上提供了1GB的文件，供注册成员使用网站的“信用”来访问泄漏的数据。

  

由于某些泄露的文件包含中文文本或对latelee.org的引用或中文文本，因此论坛上的其他威胁行为者并不认为这些数据是真实的。

  

在目录列表和发送到外媒的其他私有存储库的样本中，被盗的数据似乎主要是代码样本，测试项目，电子书和其他常规项目。

  

一些私有存储库看起来更有趣，例如那些名为“ wssd云代理”，“ Rust / WinRT语言投影”和“ PowerSweep” PowerShell项目的存储库。

  

**总体而言，从共享的内容来看，似乎没有什么值得微软担心的事情，例如Windows或Office源代码。**

  

在黑客论坛上看到漏洞的网络情报公司Under Breach也认为没有什么可担心的。

  

他们确实表示担心，像过去其他开发人员所做的那样，私有API密钥或密码可能会意外地遗留在某些私有存储库中。

  

![](../Images/962c5476391ad0aa09915090bb8c8d33.png)

微软员工山姆·史密斯（Sam Smith）在Under Breach的推文中回复说，他认为该泄漏是假的，因为“ Msft有一个“规则”，要求GitHub存储库必须在30天内公开。

  

![](../Images/14ac58d5f99987634d771cc5070ad1d5.png)

  

外媒已与Microsoft联系，以确认这些文件是否确实是合法文件，但尚未收到答复。

  

这是一个发展中的故事。
