# SAP提醒客户基于云产品中的安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488707&idx=6&sn=d5adde9e0f77201f52ff64029df1693e&chksm=cef37970f984f066c6b6f7ddbb012cb53698e40cd940d5e5266a8883eb23c9da6e49e7729c2d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488707&idx=6&sn=d5adde9e0f77201f52ff64029df1693e&chksm=cef37970f984f066c6b6f7ddbb012cb53698e40cd940d5e5266a8883eb23c9da6e49e7729c2d&scene=27#wechat_redirect)

德国软件制造商SAP周一宣布，它已开始修复其几种基于云的产品中发现的安全问题。

  

![](../Images/93fe2cb0539cd34010b4b2109aba2815.png)

  

该公司通过内部审核发现了问题，并已开始着手消除漏洞。

  

**修复程序来了**

有关安全漏洞的详细信息尚未公开。该公司在本周的咨询中表示，修复这些错误“将在2020年第二季度基本完成。”

  

受影响的产品列表包括：

*   SAP Success Factors
    
*   SAP Concur
    
*   SAP / CallidusCloud Commissions
    
*   SAP / Callidus Cloud CPQ
    
*   以及SAP C4C / Sales Cloud
    
*   SAP Cloud Platform
    
*   SAP Analytics Cloud
    

  

  

这些年来，其中一些平台及其基础设施被收购，该公司为此付出了数十亿美元。

  

这样，SAP继承了所有潜在的漏洞，并且必须使它们与公司当前的合同约定或法定IT安全标准保持一致。

  

**要联系的客户**

据估计，**SAP的440,000个客户中约有9％受此漏洞的影响。他们将收到有关风险的通知，并将获得协助以解决问题。**

  

SAP的调查尚未完成，但公司不认为客户数据已因这些问题而受到损害。

  

“为了确保受影响的产品符合相关条款和条件，以及技术补救措施，SAP决定更新其与安全性相关的条款和条件。这些与市场同行保持一致”-SAP

  

这些安全更新预计不会对公司2020年的财务前景产生影响。
