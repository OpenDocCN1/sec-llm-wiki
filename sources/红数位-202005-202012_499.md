# 全球第一域名注册商GoDaddy通告数据泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247488685&idx=1&sn=2b0291905ae79a14e680b01de4f145a1&chksm=cef3791ef984f0081a4c36a3d655e4e03e471c7d4be5319330d277ffa395ae770e525de442aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247488685&idx=1&sn=2b0291905ae79a14e680b01de4f145a1&chksm=cef3791ef984f0081a4c36a3d655e4e03e471c7d4be5319330d277ffa395ae770e525de442aa&scene=27#wechat_redirect)

GoDaddy一直在通知客户数据泄露，告知其Web托管帐户凭据遭到破坏。

  

![](../Images/3b207a20d8bee8dbf4cce2e90d15b541.png)

  

GoDaddy是目前全球最大的域名注册服务商、互联网主机服务商(来自美国)，放置它上边的域名数量高居全球第一，同时它还提供独立IP、SSL证书、WordPress托管主机、虚拟主机等多种服务。其公司总部位于亚利桑那州斯科茨代尔，声称在全球拥有超过1900万客户。

  

**今天，该公司向加利福尼亚州总检察长提交了数据泄露通知，显示其系统数据于2019年10月被泄露。**

  

随附的客户通知书中写道：“我们需要通知您发生影响您GoDaddy Web托管帐户凭据的安全事件。”

  

![](../Images/ea4167797f625be883942faf64d6672c.png)

  

该公司表示，在识别出一部分服务器上的可疑活动之后，便立即开始调查，这表明“未经授权的个人”能够访问客户用来连接其托管帐户的SSH的凭据。

  

**“我们已主动重置您的托管帐户登录密码，以帮助防止任何潜在的未经授权的访问；您将需要执行以下步骤才能重新获得访问权限。” GoDaddy说。**

  

未经授权的一方被阻止访问公司的系统，但是对该事件的调查仍在继续。

  

**网络托管服务提供商说：“我们没有证据表明您的帐户中添加或修改了任何文件。”但建议客户对其托管账户进行审核。**

  

互联网注册商还解释说，主要GoDaddy.com客户帐户不受此事件影响，并且黑客未访问这些帐户中存储的信息。仅托管账户受到影响。

  

**GoDaddy为受影响的客户提供了一年的高级安全服务，这应有助于他们识别其网站上的任何潜在安全漏洞。**

  

“对此造成的任何不便，我们深表歉意。我们已经针对这一事件采取了并将继续采取措施来增强我们的安全性。”

  

这家域名巨头还表示，客户应审核其托管帐户。

  

*   2月份，该公司公布的全年净收入为1.384亿美元，营收为29.9亿美元。GoDaddy表示，截至2019年底，它拥有1,930万客户。
    

  

该公司第四季度报告的收入为7.8亿美元，其中包括来自域的3.52亿美元，来自托管的2.93亿美元和来自业务应用程序的1.35亿美元。

  

*   3月，KrebsOnSecurity报告说GoDaddy的一名员工遭到了钓鱼攻击，这导致攻击者更改了Freelancer拥有的Escrow.com的DNS条目。
    

  

两个小时后，自由职业者首席执行官Matt Barrie在通知中  说，Escrow能够重新获得其DNS条目的控制权，并且其系统均未受到损害。

  

**“在事件发生期间，我们的安全团队设法通过电话与黑客交谈。一个多小时以来，黑客试图说服他认为域注册中心的操作来重新获得对该帐户的访问权限，”巴里说。**

  

“在打这个电话时，我们的安全团队得知进入途径是黑客非法访问了我们注册服务商的内部支持系统，并使用它们在Escrow.com的帐户上进行了更改。”
