# Twitter部分源代码泄露，被公开到GitHub

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247499552&idx=1&sn=d24a78efe26eb4f6b59c08edc8790615&chksm=13de7726a1758135aae24fdd46282057b3fca13147f3a0ca6098309e2e8e976fc8600560fad5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247499552&idx=1&sn=d24a78efe26eb4f6b59c08edc8790615&chksm=13de7726a1758135aae24fdd46282057b3fca13147f3a0ca6098309e2e8e976fc8600560fad5&scene=27#wechat_redirect)

根媒体最新报道，Twitter部分源代码在网上被泄露可能长达数月之久，给马斯克(Elon Musk)旗下的这一社交网络带来巨大风险。

![](../Images/b35009fd5495086124cb1a08de5f9e1f.png)

Twitter上周五在一份法律文件中披露了源代码被泄露的消息，同时向软件开发平台GitHub发送了一份版权侵犯通知，试图将涉事源代码移除。这些源代码随后立即移除，但显然已在网上公开了数月之久。消息人士称，除了作为知识产权的价值外，Twitter源代码还可能暴露安全漏洞，使黑客有机会窃取用户数据或封闭整个网站。

向美国加利福尼亚州北区地方法院提交的文件表明，用于在线运营公司的 Twitter 源代码的“各种摘录”被名为“**FreeSpeechEnthusiast**”(“自由言论爱好者”)的用户发布在 Github 上，泄露的内容包括“Twitter 平台和内部工具的专有源代码。”

Twitter 正在寻求法院的帮助，以确定泄露代码者和下载者的身份，Twitter 内部猜测，代码可能是一名前雇员泄露的，该雇员于 2022 年底被解雇。

根据提交给美国加利福尼亚州北区地方法院的法律文件，Twitter 已要求软件开发的互联网托管服务 GitHub 删除其发布的代码。备案文件显示，该平台遵守了规定并表示内容已被禁用。推特还要求法院查明涉嫌侵权人或未经推特授权在GitHub运营的系统上发布推特源代码的侵权人。最后社交媒体的法律行动还包括让软件协作平台**不仅识别上传代码的人，还识别下载代码的人。**![](../Images/d125e80e908e1fc30917626f3c4be30d.png)  
与此同时，根据一份国会报告中描述的文件，联邦贸易委员会正在调查马斯克在 Twitter 的大规模裁员，并试图获取他的内部通讯，作为对这家社交媒体公司隐私和网络安全做法的持续监督的一部分。  

**有个细节，此前马斯克在本月承诺将在月底最后一天开源推特推荐算法的源码，难道是因为发现被泄露了所以才选择公开？  
**

![](../Images/13ea6073973f34dfe1e5285ca4a508f9.png)

公开算法的举动是前所未有的，因为它们通常是严密保护的商业机密。社交媒体算法可以将用户与各种人或帖子或其他相关内容联系起来。批评者警告说，研究透这些算法可用于提升某些意识形态或观点。在马斯克决定发布Twitter的推荐算法之前，参议院商业、科学和交通委员会对由参议员特德克鲁兹(R-Texas)领导的问题进行了调查。克鲁兹警告说，推荐算法会影响政治观点和结果。“在一个十分之七的美国人从社交媒体接收政治新闻的世界里，通过推荐系统过滤内容的方式对美国人的看法、想法和最终信仰有着不可否认的影响，”克鲁兹在最近的一封信中说给技术主管。这位共和党议员表示，此类算法会助长社交媒体成瘾并增加有害内容的曝光率，或者它们可能会被重新定向以达到党派目的。

马斯克去年 10 月以 440 亿美元的价格收购了 Twitter，随后将该公司私有化，此次泄密事件又增加了亿万富翁埃隆·马斯克面临的越来越多的挑战。从那以后，这家社交媒体巨头陷入了动荡，大规模裁员和广告商大量外流。

马斯克随后直接解雇了该公司7500人中的四分之三的Twitter员工，所以这次泄露我们不应该感到惊讶。
