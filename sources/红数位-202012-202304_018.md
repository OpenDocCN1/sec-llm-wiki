# 再见，Win7/8.1！1月10日后再无安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247499401&idx=1&sn=413ecf3d538ac0c8bd52da49efc65022&chksm=cef0933af9871a2ce273af4373c6d231cdf96aab8dfbd6fe821aca6044c57b044f89ec66648d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247499401&idx=1&sn=413ecf3d538ac0c8bd52da49efc65022&chksm=cef0933af9871a2ce273af4373c6d231cdf96aab8dfbd6fe821aca6044c57b044f89ec66648d&scene=27#wechat_redirect)

过去2年，微软就曾多次告知用户，将在2023年1月停止对Win7与Win8.1的安全更新和技术支持。

![](../Images/7b4ac969e4617e62974f349287066184.png)

**现在，微软再次明确警告，Win7与Win8.1将在1月10日停止获取关键安全更新，这意味着这两款系统再无任何安全更新，继续使用该系统的安全风险将会大大增加。**根据此前调查报告显示的信息，目前全球仍在运行的Win7(8.1)设备有约1亿多台，在停止技术支持后，这些用户将不可避免面对过时操作系统带来的安全风险。为此，微软已经提前很长时间通知用户，并多次告知用户进行升级。可以理解用户不愿意升级的心情类似当年的Windows XP，但是在缺乏新的补丁及安全更新的情况下，Windows 7和8.1不再是一个好选择。所以此时是一个更换系统（Win10或Win11）的好时机；而如果设备性能不足，这也是一个更换设备的好机会。**特别在此提醒一些企业用户：继续使用Windows 7和8.1，将面临巨大风险，新出的**0day（零日漏洞）可以瞬间击穿系统，****很有可能在某天一次性影响所有生产力，所以务必将更换Windows 7和8.1提上日程。****
