微软1月补丁又翻车，紧急带外补丁现已发布

微软已发布紧急带外 (OOB) 更新，以解决由2021年1月星期二补丁日期间发布的Windows更新引起的多个问题。（以后要不我们称带外补丁为手动补丁吧，因为基本上都需要手动操作！！！）



微软表示：“微软于2022年1月18日今天发布针对某些版本的Windows的带外(OOB)更新。”


“此更新解决了与VPN连接、Windows Server域控制器重新启动、虚拟机启动失败以及ReFS格式的可移动媒体无法安装相关的问题。”


今天发布的所有OOB更新都可以在Microsoft Update Catalog上下载，其中一些还可以作为可选更新直接通过Windows Update安装。


如果要通过Windows更新安装紧急修复程序，则必须手动检查更新，因为它们是可选更新，不会自动安装。


更新：https://www.catalog.update.microsoft.com/Home.aspx


以下更新只能通过微软更新目录下载和安装：


  • Windows 8.1、Windows Server 2012 R2：KB5010794

  • Windows Server 2012：KB5010797


这些Windows版本的更新也可作为可选更新通过Windows Update获得：


  • Windows 11 版本 21H1（原始版本）：KB5010795

  • Windows Server 2022：KB5010796

  • Windows 10 版本 21H2：KB5010793

  • Windows 10 版本 21H1：KB5010793

  • Windows 10，20H2，Windows Server，版本 20H2：KB5010793

  • Windows 10，20H1，Windows Server，版本 20H1：KB5010793

  • Windows 10 版本 1909、Windows Server 版本 1909：KB5010792

  • Windows 10 版本 1607、Windows Server 2016：KB5010790

  • Windows 10 版本 1507：KB5010789

  • Windows 7 SP1：KB5010798

  • Windows Server 2008 SP2：KB5010799


微软一月补丁更新问题和修复


在本月星期二补丁日之后，最新的Windows Server更新给管理员带来了一系列严重问题。


根据管理员报告，Windows域控制器受到自发重启的困扰，Hyper-V不再在Windows服务器上启动，并且在部署2021年1月更新后不再可以访问Windows弹性文件系统(ReFS)卷。


Windows 10用户和管理员在安装最近的Windows 10和Windows 11累积更新并看到“无法连接到 VPN”后，也报告了L2TP VPN连接错误问题。


无法立即安装今天的带外更新的用户可以 使用以下命令从命令提示符中删除导致这些问题的 KB5009624、KB5009557、KB5009555、KB5009566 和 KB5009543 更新：


  • Windows Server 2012 R2: wusa /uninstall /kb:KB5009624 

  • Windows Server 2019: wusa /uninstall /kb:KB5009557 

  • Windows Server 2022: wusa /uninstall /kb:KB5009555

  • Windows 10: wusa /uninstall /kb:5009543

  • Windows 11: wusa /uninstall /kb:5009566


但是，由于微软还将所有安全更新与这些 Windows 累积更新捆绑在一起，因此删除它们也将删除针对2021年1月星期二补丁期间修补的漏洞的所有修复。 


Windows管理员和用户需要考虑影响其系统的未修补漏洞的风险与本月Windows更新引起的问题所造成的中断风险。
