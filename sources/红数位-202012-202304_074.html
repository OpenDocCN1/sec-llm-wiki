白宫定于今日举办开源软件安全峰会

原文：http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247498897&idx=1&sn=c332b9abaf23e26dec3ed6b97ba79661&chksm=cef09122f98718343b0e44e19c06e52eb8710e46a53f0b7ca903b45cde6a009f7323c71ad1c9&scene=27#wechat_redirect

白宫已于今天会见美国主要科技巨头的领导人，讨论开源软件的安全性。白宫声称这是对令行业和网络界担忧的广泛存在的史诗级Log4j漏洞的回应。



与会者包括苹果、谷歌、亚马逊、Meta、IBM 和微软等公司，以及构建Log4j的Apache(音译为阿帕奇)软件基金会，这是一个在互联网上无处不在的网站开源日志框架。


上个月，中国公司阿里巴巴在名为“Log4j”的软件中发现了一个漏洞，他们说，“鉴于其广泛使用，这对网络防御者来说是一个紧迫的挑战”。CISA的官员表示，该漏洞构成“严重风险”，并敦促私营部门组织与联邦政府合作采取行动。 



Log4j是一个史诗级漏洞，可让基于网络的攻击者轻松控制从工业控制系统到 Web服务器和消费电子产品的所有内容。简单地确定哪些系统使用该程序是一个挑战，它通常隐藏在其他软件的层之下。受影响的软件以 Java 编程语言编写，记录用户活动。它由少数志愿者在开源Apache软件基金会的赞助下开发和维护，在商业软件开发人员中非常受欢迎。据安全公司 Bitdefender称，它可以在许多平台上运行：Windows、Linux、Apple MacOS，包括从网络摄像头到汽车导航系统和医疗设备的一切提供支持，Log4Shell的漏洞可能会影响全球多达数亿台设备。


“在Log4j事件的基础上，本次会议的目的是促进重要的讨论，以提高开源软件的安全性，并集思广益，新的合作如何能够迅速推动改进，”一位高级政府官员在会议前表示。“软件安全对我们的国家和经济安全至关重要，”这位官员继续说，并指出最近发生的事件，包括SolarWinds黑客事件，“最近提醒我们，战略对手积极利用漏洞进行恶意攻击。”

这是拜登几次白宫网络安全峰会中的最新一次。开源软件安全会议应国家安全顾问杰克沙利文(Jake Sullivan)的邀请，将由国家安全委员会的副顾问安妮纽伯格(Anne Neuberger)主持。



“开源软件加快了创新步伐，带来了巨大的社会和经济风险，虽然它被志愿者广泛使用和维护，但事实上这是一个关键的国家安全问题，正如我们正在经历的log4j漏洞，”这位高级官员说。“这个问题并不新鲜，”这位官员继续说道。“在这次会议上，我们将一起讨论解决这个问题的现有努力，哪些行之有效，以及可以做些什么来保护我们都依赖的开源软件。”


可想而知的是政界和科技巨头会达成一定的协议，后续会议主要细节或协定放出，我们将再次撰文。
