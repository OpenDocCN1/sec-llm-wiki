# 微软刚紧急推送修复服务器远程桌面BUG

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247498803&idx=2&sn=b49d5ffff71b07a8e58af76c2e951f9f&chksm=cef09180f987189603c67f6e2dba11c77c6cdc8d8b64909a2edff12fea588ad2eb0f8fd8678b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247498803&idx=2&sn=b49d5ffff71b07a8e58af76c2e951f9f&chksm=cef09180f987189603c67f6e2dba11c77c6cdc8d8b64909a2edff12fea588ad2eb0f8fd8678b&scene=27#wechat_redirect)

**Microsoft刚发布关于微软服务器操作系统紧急带外更新，以解决导致远程桌面连接和Windows Server**性能问题****的**错误。**

![](../Images/9fb8c16aa1d5d4c9fb4d8b14495d2c3c.png)

  

  

***“微软刚发布带外(Out of Band, OOB) 更新今天，美国时间2022年1月4日更新，以解决问题，其中的Windows Server可能会遇到黑屏，有缓慢的迹象，或一般缓慢，”***该公司解释说。***“您也可能无法使用远程桌面访问服务器。在某些情况下，服务器可能会停止响应。”***

  

**受影响的平台包括：**

*   Windows Server 2022
    
*   Windows Server 2019
    
*   Windows Server 2016
    
*   Windows Server 2012 R2
    

  

**注意：解决此问题的更新无法从Windows更新中自动获得，且不会自动安装在受影响的系统上。****这意味着你需要手动下载独立更新包自行更新！！！**

  

您还可以从Microsoft 更新目录下载更新。企业管理员可以使用Microsoft Update Catalog中提供的说明手动将此更新导入Windows Server Update Services (WSUS) 。

  

![](../Images/e6cc83b3f29df497a9ddb9a8d85613a4.png)

  

**本次针对Windows Server 2012 R2的补丁包为KB5010215，Windows Server 2019的补丁包为KB5010196，KB5010196是累积更新，因此您无需在安装之前部署以前的Windows Server更新就可以直接安装。**

  

**修复尚未适用于所有受影响的Windows版本**

  

Microsoft尚未发布Windows Server 2022、Windows Server 2016的更新，但它正在努力修复并将在未来几天提供解决方案。

  

**目前仅提供了针对Windows Server 2012 R2和2019的更新：**

**带外更新不断发，手动安装有点坑  
**

  

11月，微软发布了带外更新，以修复与委派方案相关的身份验证问题，这些问题会影响运行受支持版本的Windows Server的域控制器 (DC)。正如微软所解释的那样，在受影响的系统上，最终用户无法在本地 Active Directory或混合Azure Active Directory环境中使用单点登录 (SSO) 登录服务或应用程序。

  

1周前，由于Microsoft数字证书过期，Microsoft不得不发布另一组紧急更新**KB5008295带外更新**来解决**Windows 11**在打开或使用某些内置应用程序和功能时出现的问题。

*   补丁包下载：
    
    https://www.catalog.update.microsoft.com/Search.aspx?q=KB5008295
    

  

去年，该公司还推出带外更新的字符串来修复打印问题，无线网络崩溃，PDF开放问题，视窗PrintNightmare零日，和另一系列的打印问题。
