今天是微软2021年12月星期二补丁日，本月修复了6个零日漏洞和总共67个漏洞。这些更新中包含了恶意软件积极使用主动利用的Windows Installer漏洞的修复。



微软在今天的更新中修复了67个漏洞，其中7个列为严重漏洞，60个列为重要漏洞。


下面列出了每种类型的漏洞数量：


  • 21个提权漏洞

  • 26个远程代码执行漏洞

  • 10个信息泄露漏洞

  • 3个拒绝服务漏洞

  • 7个欺骗漏洞


6个零日漏洞，其中2个被积极利用


12月的周二补丁日包括对6个零日漏洞的修复，其中一个被积极利用的Windows AppX安装程序漏洞。如果漏洞被公开披露或被积极利用而没有官方修复可用，则Microsoft将漏洞归类为零日漏洞。


Windows AppX Installer被滥用来安装Emotet


本月修复的被积极利用的漏洞是：


  • 被积极主动利用的Windows AppX安装程序零日漏洞被跟踪为CVE-2021-43890，并用于各种恶意软件分发活动，包括Emotet、TrickBot和BazarLoader。相关恶意软件背后的威胁行为者现在通过使用Windows 10和Windows 11的内置功能App Installer安装恶意软件包来感染系统。


作为2021年12月补丁星期二的一部分，微软还修复了其他5个公开披露的漏洞，这些漏洞不会在攻击中被利用。


  • CVE-2021-43240 - NTFS 设置短名称特权提升漏洞

  • CVE-2021-41333 - Windows 打印后台处理程序特权提升漏洞

  • CVE-2021-43880 - Windows Mobile 设备管理特权提升漏洞

  • CVE-2021-43883 - Windows 安装程序特权提升漏洞

  • CVE-2021-43893 - Windows 加密文件系统 (EFS) 特权提升漏洞


其他公司的最新更新


其他在12月发布更新的供应商包括：


  • Android 12月安全更新已于上周发布。

  • Apache Log4j：针对席卷互联网的史诗级漏洞发布了许多安全公告。

  • Apple发布了适用于iOS、iPadOS、macOS、tvOS和watchOS的安全更新。

  • 思科本月发布了许多产品的安全更新，包括与其产品中的Log4j漏洞相关公告。

  • SAP发布了2021年12月的安全更新。

  • VMWare的发布了一个有关当前补丁在他们的产品Log4j的漏洞的公告。


Windows 10最新累积更新的新增功能


微软已通过12月更新修复了安全性和非安全性漏洞。例如，可能影响可变字体渲染的错误已得到修复。同样，另一个错误已得到修复，即卸载字体后“设置”页面意外关闭。以下是其他修复程序的列表：


  • 更新了在导出为 PDF 时可能导致 32 位版本的 Microsoft Excel 在某些设备上停止工作的问题。 

  • 更新了使用 Meiryo UI 字体和其他垂直字体时以错误角度显示字母或字符的问题。这些字体在日本、中国或亚洲其他国家/地区经常使用。  

  • 更新了在使用输入法编辑器 (IME) 插入元素时导致 Internet Explorer 停止工作的问题。 

  • 更新导致卸载字体后“设置”页面意外关闭的问题。 

  • 更新了一个问题，该问题会影响您在使用新的日语 IME 时使用文件资源管理器中的文件夹视图重命名文件的能力。 

  • 更新了在服务失败后关闭 Windows 游戏栏上的屏幕捕获和录制功能的问题。 

  • 更新了一个问题，该问题阻止您经常使用的应用程序正常出现在“开始”菜单上。

  • 更新导致 Internet Explorer 停止工作的问题。
