# 愤怒员工窃取公司数据并把公司股票拉跌20%

**今天我们来看一个内部威胁的典型案例：**

  

美国司法部(DOJ)日前公布了一个案例，夏普先生(Nickolas Sharp)被公司起诉，这个由联邦调查局(FBI)逮捕的个人成为被告，公司起诉泄露了前雇主的机密信息。美国司法部称，被告从他曾经工作过的一家位于纽约的无线通信公司窃取了数千份机密记录。

  

司法部称当他掌握了机密信息后，被告匿名试图向公司勒索钱财，要求支付200万美元(约合人民币1275万)以换取这些文件，最终调查确定被告可用来访问这些数据的后门。攻击者并没有就此止步，因为在威胁该公司后没拿到勒索款后，他开始泄露有关该公司机密文件，导致该公司股价下跌 20%。

  

![](../Images/14bf68d2370c1fdea5d0847632483934.png)

  

经过几天的不确定后，当局于周三确认了夏普先生身份并逮捕了他。

  

**司法部提到夏普先生滥用其作为受影响公司的亚马逊网络服务 (AWS) 云管理员的角色，由于对公司的不满，愤怒的他在2020年的某个时候下载敏感数据。夏普先生随后向公司代表发送了一封匿名赎金票据，要求支付50比特币，约200万美元(约合人民币1275万)，具体价值取决于袭击发生时的汇率。在公司拒绝付款后，被告在可公开访问的在线平台上发布被盗信息的样本。**

  

被告在入侵期间还严重破坏了公司的IT基础设施，他修改了访问和安全策略，以便在窃取敏感信息时不被注意。FBI补充说，被告使用Surfshark VPN服务隐藏发起恶意活动的IP地址。

  

尽管试图掩盖自己的踪迹，夏普先生还是犯了一个严重的错误，在他的一次入侵中短暂地暴露了他家的IP地址；使用这些数据，特工获得了搜查令，在此期间他们查获了多台电子设备。

  

联邦调查局纽约办公室副主任迈克尔·德里斯科尔说：“夏普先生策划利用他的技术和数据向他工作的公司勒索钱财，这显然违反了多项联邦法律。”

  

如果被判有罪，被告将面临最高20年的监禁。
