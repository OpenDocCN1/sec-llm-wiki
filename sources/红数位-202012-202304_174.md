# 兄弟打印机警告WIN11上大范围不可用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247497830&idx=1&sn=b09ecaf192243abfb4def159eead5570&chksm=cef095d5f9871cc363216fab0967739a451b2f5ec77a4da2d6ad6565487ae9f81cea35a2c4f4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247497830&idx=1&sn=b09ecaf192243abfb4def159eead5570&chksm=cef095d5f9871cc363216fab0967739a451b2f5ec77a4da2d6ad6565487ae9f81cea35a2c4f4&scene=27#wechat_redirect)

10月6日，经过几个月的Windows Insider计划测试，微软正式发布了 Windows 11，你可以直接在系统升级中体验最新版本的微软操作系统啦。

  

![](../Images/f08c36dfd1e325de05fcb588ddbaeabe.png)

  

兄弟(Brother)打印机在中国使用率很高，特别是针式打印机。

  

兄弟(Brother)在官网发布警告说，在Windows 11中使用USB连接时，他们的许多打印机可能不再工作或显示错误。

  

![](../Images/058765b6290bee64440c6bb8b5cfe30b.png)

  

兄弟(Brother)官网帮助文章指出，当通过USB连接、更改打印机设置或通过USB连接多台打印机时，更新到Windows 11可能会阻止操作系统检测到您的Brother打印机设备。

  

兄弟(Brother)表示有92种打印机型号受此行为影响，如下所列：

  

DCP-B7500D, DCP-B7535DW, DCP-J1050DW, DCP-J1100DW, DCP-J1140DW, DCP-J1200W(XL), DCP-J572DW, DCP-L2531DW, DCP-L2535D , DCP-L2535DW, DCP-L2550DW, DCP-L3510CDW, DCP-L3551CDW, DCP-L5500D, DCP-L5600DN, DCP-T220, DCP-T310, DCP-T420W, DCP-T510W, DCP-T520W, DCP-T710W, DCP-T720DW, DCP-T820DW, DCP-T825DW, HL-B2000D, HL-B2080DW, HL-L2310D, HL-L2335D, HL-L2350DW, HL-L2351DW, HL-L2370DN, HL-L2375DW, HL-L2376DW, HL-L2385DW, HL-L2386DW, HL-L2395DW, HL-L3210CW, HL-L3230CDN, HL-L3230CDW, HL-L3270CDW, HL-T4000DW, MFC-B7715DW, MFC-J1010DW, MFC-J1300DW, MFC-J2330DW, MFC-J2730DW, MFC-J3530DW, MFC-J3930DW, MFC-J4340DW(XL), MFC-J4440DW, MFC-J4540DW(XL), MFC-J491DW, MFC-J5330DW, MFC-J5730DW, MFC-J5845DW, MFC-J5930DW, MFC-J5945DW, MFC-J6530DW, MFC-J6545DW, MFC-J6730DW, MFC-J690DW, MFC-J6930DW, MFC-J6935DW, MFC-J6945DW, MFC-J890DW, MFC-L2710DW, MFC-L2713DW, MFC-L2715DW, MFC-L2716DW, MFC-L2730DW, MFC-L2750DW, MFC-L2751DW, MFC-L2770DW, MFC-L2771DW, MFC-L3710CW, MFC-L3735CDN, MFC-L3745CDW, MFC-L3750CDW, MFC-L3770CDW, MFC-L5700DN, MFC-L5755DW, MFC-L5900DW, MFC-L6700DW, MFC-L6900DW, MFC-L8690CDW, MFC-L8900CDW, MFC-L9570CDW, MFC-T4500DW, MFC-T810W, MFC-T910DW, MFC-T920DW, MFC-T925DW

  

打印时，兄弟(Brother)还警告说，106种不同打印机型号的用户可能会收到来自“USB 连接修复工具”的错误消息，指出“无法打印到 USB 打印机”。

  

![](../Images/36b0a9c489c0ea9415f9c07d1fd555d1.png)

Windows 11中的Brother USB 连接修复工具  

  

但是，兄弟(Brother)声明您可以忽略该错误，并且文档应该可以成功打印。

  

最后，兄弟(Brother)表示USB连接的打印机将无法与Windows 11中的各种打印实用程序进行通信，包括：

  

*   设备设置工具
    
*   纸张尺寸设置工具
    
*   分布式打印工具
    
*   专用 ID 设置工具
    
*   无线设置向导
    
*   P-Touch 编辑器 5.4
    
*   更新软件
    
*   传输经理
    
*   中转快递
    
*   模板设置
    
*   打印机设置工具
    

  

对于受这些问题影响的用户，兄弟(Brother)建议暂时使用不同的连接方法，例如无线或有线网络连接。

  

兄弟(Brother)表示他们正在调查该问题并正在制定解决方案。

  

虽然微软尚未承认这些打印问题，但如果未来微软对装有Brother设备的计算机设置保护措施以防止它们升级到Windows 11，也就不足为奇了。

  

微软已经在调查其他八个问题，包括网络软件、Oracle VirtualBox和 Cốc Cốc网络浏览器(越南人用的浏览器)的保护措施。

  

![](../Images/3d28c8f4734293abf3845f3956b9747e.png)

  

目前的Windows 11兼容性稀碎，大家谨慎升级。
