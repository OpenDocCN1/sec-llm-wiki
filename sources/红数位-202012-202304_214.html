微软计划即将拆分其商业版防病毒产品（称为Microsoft Defender for Endpoint）的定价模式，引入更便宜的价格计划，并使其产品更容易、更广泛地提供给通常负担不起的公司。



在昨天宣布之前，Microsoft Defender for Endpoint端点防御主要适用于注册Microsoft 365 E5许可证或具有E5安全扩展层的E3许可证的公司，这两个层都是Microsoft 企业许可计划中最昂贵的层级，简单说就是大客户。


价格分别为57美元(367元人民币)和44美元(284元人民币)/用户/月，这两个主要选项对于许多IT预算较小的公司来说都是遥不可及的，这些公司通常会使用更便宜的第三方防病毒解决方案。


但在昨天的一篇新博文中，微软表示计划将Defender for Endpoint拆分为两个新的许可选项，名为Plan 1和Plan 2。



两者之间的区别在于，计划1将仅包含Defender for Endpoint功能的一个子集，即那些专注于端点保护功能的功能。Defender for Endpoint功能的其余部分将作为计划2的一部分提供，微软目前的大多数客户将在今年晚些时候自动迁移。


Microsoft Defender for Endpoint Plan 1目前在公共预览版中是免费的。公司可以通过注册预览期免费测试它。


测试地址：

https://winatpregistration-prd.trafficmanager.net/P1/UserAgreement?Length=4


微软预计Plan 1正式版将在今年晚些时候全面上市。一旦普遍可用，计划1将以两种方式提供：


  • 作为每个用户许可的独立SKU。符合条件的许可用户将能够在最多五个并发设备上使用Microsoft Defender for Endpoint Plan 1。

  • 包含在Microsoft 365 E3/A3中，具有与上述相同的每个用户模型和设备权利。


一旦计划1全面上市，将提供其他详细信息和确切价格。E3许可证目前的价格为32美元(206元人民币)/用户/月。尽管预计2022年Office订阅价格会有所上涨，但微软上周透露，E3和E5许可证将保持相同的价格点。

那么为什么微软之前一直没称霸杀毒行业？我们相信微软只要想，一定能在每次国际权威机构的测试中拿到第一的成绩。但一方面单凭微软安全实力还不足以抵抗来自黑客的攻击，必须联合发展整个安全行业来对抗网络黑暗势力。也因此为了一直给第三方杀毒一碗饭吃，他玩起了中庸之道。


而现如今，微软自家的杀毒玩起了大小通吃，对于全球杀毒软件行业，是否意味着要变天了？我们拭目以待。

攻击面减少


组织的攻击面是易受网络攻击的所有位置。借助Defender for Endpoint Plan 1 (预览) ，可以通过保护组织使用的设备和应用程序来减少攻击面。以下部分介绍了Defender for Endpoint Plan 1 (预览版) 攻击面减少功能。


  • 攻击面减少规则

  • 勒索软件缓解

  • 设备控制

  • Web 保护功能

  • 网络保护

  • 网络防火墙

  • 应用程序控制


攻击面减少规则


攻击面减少规则针对被视为有风险的某些软件行为。此类行为包括：


  • 启动尝试下载或运行其他文件的可执行文件和脚本

  • 运行混淆的或可疑的脚本

  • 启动应用通常在正常工作期间不启动的行为


合法业务应用程序可以展示此类软件行为;但是，这些行为通常被视为有风险，因为它们通常被攻击者通过恶意软件滥用。攻击面减少规则可以限制风险行为，并有助于保证组织安全。


勒索软件缓解


借助受控文件夹访问权限，你可以获取勒索软件缓解。受控文件夹访问权限仅允许受信任的应用访问终结点上的受保护文件夹。根据应用的普遍程度和信誉，将应用添加到受信任的应用列表中。安全运营团队还可以在受信任的应用列表中添加或删除应用。


设备控制


有时，对组织设备的威胁以可移动驱动器（如USB驱动器）上的文件的形式出现。Defender for Endpoint 包括可帮助防止未经授权的外围设备威胁威胁设备的功能。你可以将Defender for Endpoint配置为阻止或允许可移动设备上可移动设备和文件。


WEB保护

借助Web保护，你可以保护组织设备免受Web威胁和不需要的内容。Web保护包括Web威胁防护和Web内容筛选。


  • Web威胁防护 阻止对钓鱼网站、恶意软件矢量、攻击网站、不受信任的或低信誉网站以及您明确阻止的网站的访问。

  • Web内容筛选 (预览) 基于其类别阻止访问某些网站。类别可以包括成人内容、成人网站、法定责任网站等。


网络保护

借助网络保护，你可以阻止组织访问可能承载互联网上的网络钓鱼欺诈、攻击和其他恶意内容危险域。


网络防火墙

使用网络防火墙保护，可以设置规则，以确定允许哪些网络流量流入或流出组织设备。借助使用 Defender for Endpoint 获取的网络防火墙和高级安全，你可以：

  • 降低网络安全威胁的风险

  • 保护敏感数据和知识产权

  • 扩展安全投资


应用程序控制

应用程序控件通过仅在系统核心和内核Windows中运行受信任的应用程序和代码来保护 (终结点) 。安全团队可以定义考虑应用程序属性的应用程序控制规则，如其代码签名证书、信誉、启动过程等。应用程序控件在Windows 10或更高版本中可用。


集中管理

Defender for Endpoint Plan 1 (preview) 包括Microsoft 365 Defender门户，使安全团队能够查看有关检测到的威胁的当前信息，采取相应措施缓解威胁，并集中管理组织的威胁防护设置。



基于角色的访问控制

使用基于角色的访问控制 (RBAC) ，安全管理员可以创建角色和组，以授予对Microsoft 365 Defender门户https://security.microsoft.com。使用 RBAC，可以精细控制谁可以访问安全中心，以及他们可以看到和执行哪些操作。


报告

Microsoft 365 Defender(security.microsoft.com)门户可轻松访问有关检测到的威胁和操作的信息，以应对这些威胁。


  • 主页包含卡片，可一目了然地显示哪些用户或设备处于风险中、检测到的威胁数量以及创建哪些警报/事件。

  • “事件& 警报”部分列出了因触发的警报而创建的任何事件。当跨设备检测到威胁时，将生成警报和事件。

  • 操作中心列出了已采取的修正操作。例如，如果文件被发送到隔离区，或URL被阻止，每个操作都列在"历史记录"选项卡上的“操作中心”中。

  • “报告”部分包括显示检测到的威胁及其状态的报告。



API

使用Defender for Endpoint API，可以自动执行工作流，并与组织的自定义解决方案集成。
