今天是微软 2021年7月星期二补丁日，它修复了9个零日漏洞和总共117个重要漏洞，因此Windows管理员将在争先恐后地为设备打补丁和保护时竭尽全力。



微软在今天的更新中修复了117个漏洞，其中13个被归类为危急，1个为中等，103个为重要。117个漏洞中，44个为远程代码执行，32个为提权，14个为信息泄露，12个为拒绝服务，8个为安全功能绕过，7个为欺骗漏洞。


修复了9个零日漏洞，其中4个被积极利用


7月周二补丁包括9个零日漏洞，其中4个在野外被积极利用。Microsoft 将零日漏洞归类为公开披露或在没有官方安全更新或发布的情况下被积极利用。


5个公开披露但未被利用的零日漏洞是：

  • CVE-2021-34492 - Windows 证书欺骗漏洞

  • CVE-2021-34523 - Microsoft Exchange Server提权漏洞

  • CVE-2021-34473 - Microsoft Exchange Server远程代码执行漏洞

  • CVE-2021-33779 - Windows ADFS安全功能绕过漏洞

  • CVE-2021-33781 - Active Directory安全功能绕过漏洞


有一个公开披露并被积极利用的漏洞，称为PrintNightmare。

  • CVE-2021-34527 - Windows Print Spooler 远程代码执行漏洞


最后，还有4个未公开披露的积极利用的Windows漏洞。

  • CVE-2021-33771 - Windows 内核特权提升漏洞

  • CVE-2021-34448 - 脚本引擎内存损坏漏洞

  • CVE-2021-31979 - Windows 内核特权提升漏洞


打印噩梦


上个月，针对允许远程代码执行和本地提权的零日PrintNightmare漏洞意外发布了一个概念验证漏洞。由于攻击的严重性，微软发布一个紧急KB5004945 安全更新 ，该更新本应修复被追踪为CVE-2021-34527的PrintNightmare漏洞。详情请查阅：微软紧急推送PrintNightmare零日更新


微软的OOB补丁仅在禁用指向和打印策略的情况下解决该漏洞。对于仍启用此注册表设置以实现远程代码执行和本地权限提升的那些设备，可以绕过该补丁。但是，微软表示补丁正在按预期工作，并且Windows管理员应立即安装补丁，因为这些漏洞正在被积极利用。


微软安全响应中心解释说：“我们的调查表明，OOB安全更新按设计运行，并且对已知的打印机假脱机攻击和其他统称为PrintNightmare的公共报告有效。”“我们调查的所有报告都依赖于将与指向和打印相关的默认注册表设置更改为不安全的配置。”安全研究和Mimikatz创建者认为补丁仍然需要改进以防止他和其他人发现的绕过。
