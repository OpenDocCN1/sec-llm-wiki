# 韩国唯一潜艇制造商证实被黑

前天我们报道了：[**韩国唯一核能研究院KAERI承认被黑**](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247496284&idx=1&sn=681d857e18af22db10d30f67cb477f7c&chksm=cef09feff98716f9b48ab4877bb829a200342f8c793d806a566a042897e544717c5116406868&scene=21#wechat_redirect)

  

据韩国时事周刊《时事杂志》(Sisa Journal)周日独家报道，据信朝鲜黑客在过去十年中第二次入侵了韩国最大的潜艇制造商 。据与记者交谈的多名政府消息人士称，此次泄露事件发生在去年，并且在这次攻击中获取了一些数据。

  

**袭击的目标是大宇造船和海洋工程公司 ( DSME )，它是该国包含现代和三星三大主要造船公司之一，但**DSME**是唯一的潜艇制造商。**

  

![](../Images/7ace4562c4808c3d209cbfbc2b283547.png)

  

****大宇造船和海洋工程公司 ( DSME )**从去年到今年上半年设计和建造了海军各种舰艇和潜艇，**消息人士称，一些被盗文件包括大宇机械和韩国海军过去几年一直在研究的核动力潜艇计划。****

  

**韩国国防采办计划管理局 (DAPA) 证实了此类长期持续的黑客攻击行为及最近DSME的安全漏洞，并与该公司共同采取了安全措施。**但DAPA否认了JoongAng的报告，该报告将入侵归咎于朝鲜黑客，声称调查仍在进行中。 DAPA 的一名官员表示：“有人试图入侵相关公司”，但“朝鲜的假定黑客部队试图破解与核动力潜艇相关的信息，这不是真的”。另一位消息人士解释说：“去年和今年入侵大宇造船和海洋工程的组织不同。”

  

据专家称，朝鲜的网络行动近年来一直在上升。东方安全安全响应中心负责人文钟铉说：“自去年以来，朝鲜一直在全方位进行黑客攻击，包括外交和安全。“我们需要采取更强有力的措施来追究朝鲜的责任，就像美国当局一样，”他补充说。

  

引进核动力潜艇是卢武铉政府秘密推动的一项计划，但以失败告终。当时，政府甚至将其命名为“362计划”，意思是2003年6月2日，即前总统卢武铉批准该计划的日期。

核动力潜艇和柴油潜艇的比较  

  

明知这些事实的总统文在寅在竞选总统期间宣称，“我们需要核动力潜艇的时候到了”，“如果当选，我们将与美国政府讨论核协议修正案”。然而，在距离执政不到一年的时间里，韩美在核潜艇发展问题上的分歧仍未解决。一位政府消息人士表示，“据评估，该国拥有建造核动力潜艇的技术。问题是美国坚决反对引进核燃料，除非解决，否则很难发展。”。

  

政府内部也有人观察到，大宇造船和海洋工程的黑客攻击企图可能与原子能研究所最近的黑客攻击有关。据韩国人民政权办公室消息，上月14日，朝鲜侦察总局下属的黑客组织“Kimsuky”的IP入侵了原子能研究所的内部系统。目前，国家情报局正在调查破坏的具体程度和背后的力量。 

 

对此，一位消息人士称，“卢武铉政府放弃发展核动力潜艇的决定性背景与2004年国际原子能机构（IAEA）对原子能研究所的秘密检查有关，政府担心会升级为发展核武器等的怀疑，也停止了核动力潜艇项目，”他说。“渴望开发新型潜艇的朝鲜可能已经入侵了原子能研究所，以获得核动力潜艇所需的小型反应堆技术，”他说。

  

这不是大宇造船和海洋工程公司第一次成为目标，本次透露事件标志着朝鲜黑客第二次被怀疑从DSME窃取潜艇相关文件。第一次事件发生在2014年7月至2016年3月之间，当时黑客入侵了两家韩国电信公司，并转向使用其服务器的160家公司。被认为是韩国历史上最严重的黑客攻击之一，当时，发生了大约40000条内部数据被黑客窃取。当时，军事当局向国民议会报告说，在泄露的数据中，仅包括大约60起1至3级军事机密。据信黑客已经获得了韩国的战争计划、  F-15发动机和电子系统的设计以及与大宇造船和海洋工程公司 ( DSME )当时正在建造的DSME潜艇相关的秘密文件。

  

**纵观亚太各国，韩国网络安全防御能力目前的确处于中弱局势，就事件中涉及目标多为军事尖端级别，恐给亚太地区稳定带来一定的风险。**
