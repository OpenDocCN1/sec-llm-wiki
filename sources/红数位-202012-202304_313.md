# 全球最大CDN服务商Akamai中断导致澳大利亚主要银行和航空公司离线四小时

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247496220&idx=1&sn=332de7f4fc937f9ba26c6be776e1d37e&chksm=cef09faff98716b947ca2cafb4a90575c375e9de0d6265f94b553ca7da77028a56ab12f57338&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247496220&idx=1&sn=332de7f4fc937f9ba26c6be776e1d37e&chksm=cef09faff98716b947ca2cafb4a90575c375e9de0d6265f94b553ca7da77028a56ab12f57338&scene=27#wechat_redirect)

**全球最大CDN服务商Akamai(阿卡迈)证实，当地时间周四下午，其Prolexi防护DDoS服务中断是导致澳大利亚一些主要银行和航空公司系统的在线服务中断的罪魁祸首。**

  

![](../Images/39081ca2bc15bd78b08245be04fca606.png)

  

Prolexic是Akamai公司在云中缓解DDoS攻击，提供的一种前置防御，可阻止最大规模的攻击并在DDoS流量到达应用程序和数据中心之前清理它。

  

![](../Images/6d6b2c78516f4818872f983d9d79c7d2.png)

  

**该公司保证该问题不是由系统更新或网络攻击引起的，并详细说明其 Prolexic DDoS 服务使用的路由表值被“无意中超出”。该公司表示：“结果是服务意外中断。”这家总部位于美国的服务提供商将自己宣传为“世界上最大、最复杂的边缘平台”，表示它立即检测到问题，并在几秒钟内向受影响的客户发出警报。问题开始出现在美国东部标准时间周四下午2:20左右。**

  

![](../Images/424063bbe1e6a8be2156e0255a3b5417.png)

  

“影响仅限于使用 Routed 服务 3.0 版的 Akamai 客户，”该公司在一篇帖子中证实。“使用这项服务的大约 500 名客户中的许多人都自动重新路由，这在几分钟内恢复了运营。其余的大部分客户此后不久就手动重新路由。”

  

**受影响的客户包括澳大利亚四大银行中的三个：**

**澳大利亚联邦银行**

**西太平洋银行**

**澳新银行**

  

**以及澳大利亚邮政公司和维珍澳大利亚航空公司。**

  

这些公司都在Twitter上通知客户这个问题。

  

![](../Images/38d7462d2cbe6e0d1dc29e8a2a3c2883.png)

澳联邦银行

  

![](../Images/80c621b56067dde315ac3e69f430cd76.png)

西太平洋银行

![](../Images/632c1ce6d15f6e4ea1c7b3f58c1aba02.png)

澳新银行

  

“我们知道你们中的一些人在访问我们的服务时遇到了困难，我们正在紧急调查。我们深表歉意并感谢你们的耐心，我们会尽快提供更新，”澳大利亚联邦银行说。西太平洋银行和澳新银行也发表了类似的言论 。

  

维珍澳大利亚航空在推特上表示，系统中断正在影响其网站和联络中心。

  

![](../Images/75b9ec472aba5f0038c4410c0ef0a5b9.png)

  

与此同时，澳大利亚邮政表示这是由于“外部”中断。 

  

![](../Images/1eb77607110b01edf9b20b16d65ce984.png)

  

**服务于澳大利亚东部标准时间晚上18:47恢复，从时间上看，前后经历了“暗黑4小时”。**

  

Akamai此后向其客户和受影响的最终用户道歉。“我们已采取措施防止此问题再次发生。我们还将努力确保未来每个Akamai客户都设置为自动重新路由”该公司表示。

  

**本事件也是近期比较明显的CDN影响民生事件之一（时间更长）。**

**此前6月8日晚全球大量热门网站突然无法访问，显示“服务不可用”503错误。受影响网站包括亚马逊、PayPal、Shopify、Reddit、GitHub、Hulu、HBO、英国政府网站gov.uk等互联网服务网站，以及CNN、BBC、卫报、纽约时报等新闻网站。据悉，根源是这些网站使用了Fastly的CDN服务加快全球各地的网站访问速度。Fastly官方服务状态页面显示发现CDN服务的故障，整个**修复**过程持续约1小时。**
