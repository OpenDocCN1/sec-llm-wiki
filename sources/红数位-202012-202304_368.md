# 2021年5月微软周二补丁修复55个漏洞3零日

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247495641&idx=1&sn=e559bc063b132e460538e45be6e00fe6&chksm=cef0826af9870b7cca765ee2597810d6fe00bbd9b6c00c2a3895b9035bd3a3520a6df3b45e8c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247495641&idx=1&sn=e559bc063b132e460538e45be6e00fe6&chksm=cef0826af9870b7cca765ee2597810d6fe00bbd9b6c00c2a3895b9035bd3a3520a6df3b45e8c&scene=27#wechat_redirect)

今天是2021年5月微软周二补丁程序发布日，本月微软修复了三个零日漏洞，请大家务必更新。 

  

![](../Images/34119b71deabed13ecedea60cf5c8697.png)

  

**通过今天的更新，微软已修复了55个漏洞，其中4个为“危急”，50个为“重要”，1个为“中等”。****今天修补的三个零日漏洞已公开披露，但用于攻击情况**未知**。**

  

**修复了三个零日漏洞**

作为今天周二补丁的一部分，微软已修复了三个公开披露的漏洞。

  

**微软公开指出但尚未利用的以下四个漏洞：**

  

*   CVE-2021-31204-.NET和Visual Studio特权提升漏洞
    
*   CVE-2021-31207 -Microsoft Exchange Server安全功能绕过漏洞
    
*   CVE-2021-31200-通用工具远程执行代码漏洞
    

  

CVE-2021-31200漏洞用于Microsoft的NNI（神经网络智能）工具包。Resec System的Abhiram V在GitHub提交中披露了此漏洞。

CVE-2021-31207 Microsoft Exchange漏洞由2021 Pwn2Own黑客攻击使用。目前尚不清楚这是否是Devcore或Team Viettel公开的漏洞。  

  

众所周知，当今的零日活动都没有在野外积极被利用。 预计威胁参与者会分析补丁程序以创建漏洞利用程序，尤其是针对微软Exchange的漏洞利用程序。

  

**本月还修复了Internet Explorer 11全系远程执行代码漏洞，WINDOWS 7也再次沾光。**

  

因此，务必尽快完成应用的安全更新。
