# 美国国防部漏洞披露程序启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247495536&idx=2&sn=cf93b0efac356079e8c4793b0a1f25d8&chksm=cef082c3f9870bd5fb82b0cc372ce28d3ebca74977cc5f5e0c699cceee12e58622f12e1b73d3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247495536&idx=2&sn=cf93b0efac356079e8c4793b0a1f25d8&chksm=cef082c3f9870bd5fb82b0cc372ce28d3ebca74977cc5f5e0c699cceee12e58622f12e1b73d3&scene=27#wechat_redirect)

美国国防部（DOD）官员今天宣布，该部门的漏洞披露程序（VDP）已扩展到包括所有可公开访问的DOD网站和应用程序。

  

![](../Images/fa09d9e995ad2d36e0fda018fe9caff6.png)

  

DOD的VDP 由国防部网络犯罪中心（DC3）领导，它使安全研究人员可以搜索和报告影响面向公众的 DOD信息系统的任何漏洞 。

  

**预计报告数量将急剧增加**

随着今天的扩展，研究人员可以寻找会影响所有可公开访问的“ DOD网络，基于频率的通信，物联网，工业控制系统等”的安全问题 。

  

在VDP启动之前，道德黑客即使发现有效漏洞也无法与DOD进行交互。“正因为如此，许多漏洞都没有报案，”布雷特·戈尔茨坦，国防部数字化服务的主任说。 

  

**“ DOD漏洞政策于2016年启动，因为我们证明了与黑客社区合作，甚至雇用黑客来查找和修复系统漏洞的功效。”**

  

随着VDP范围的扩大，DOD网络犯罪中心主任Kristopher Johnson预计，由于安全研究人员发现和报告以前无法报告的漏洞，报告的数量将急剧增加。

  

约翰逊补充说：“国防部一直认为，国防部网站只是一个开始，因为它们只占我们总体攻击面的一小部分。”

  

**通过国防部的VDP提交了30,000多个报告**

自2016年正式成立以来，已经通过该计划提交了30,000多个漏洞报告，其中70％以上包含影响DOD系统的有效漏洞。

  

国防部使用通过漏洞赏金计划收集的信息来增强美国国防部信息网络（DoDIN）的安全性。

  

国防部网络犯罪中心与国防反情报安全局合作， 于4月为国防工业基地（DIB）公司启动 了为期12个月的国防工业基地漏洞披露程序（DIB-VDP）试点。

  

DIB-VDP允许道德的黑客报告DoD承包商合作伙伴的信息系统，网络媒体资源和其他范围内的资产中的漏洞。

  

DoD的网络犯罪中心解释说：“将漏洞研究扩展到参与的DoD承包商网络，通过使参与的DoD承包商网络可用于漏洞研究来复制DoD的成功 。”
