# 再遭威胁：将泄漏新iPad设计图及雇员信息

6天前，我们报道了：[苹果发布会前遭勒索1亿美元，产品蓝图或被盗](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247495340&idx=1&sn=4f34283a464a9840dbf0ef7f5c640c25&chksm=cef0831ff9870a094b07940fa08024e18c4bd2559cd7effe03e534f06aac237f2fddfb3351fc&scene=21#wechat_redirect)

  

![](../Images/c7782b7271f10de6933cc0935bc059e0.png)

  

本月早些时候，REvil勒索软件团伙对一家来自中国台湾的原始设计制造商（ODM）Quanta(广达)进行了攻击，Quanta(广达)帮助制造Apple Watch，Apple Macbook Air和Apple Macbook Pro的。

  

作为此次攻击的一部分，REvil声称窃取了该公司的数据，包括Apple产品的图纸和示意图。在没有收到来自Quanta(广达)的赎金付款之后，REvil起价为5,000万美元，并选择在苹果春季发布会前一天在其数据泄漏站点公开发布了Apple Macbook的原理图作为证实泄漏的一部分。

  

![](../Images/6c74f61ab23edb462a14c67f0f8cd19b.png)

  

REvil警告苹果，他们应该在5月1日之前回购数据，否则倒计时结束后价格增至1亿美元，届时也将会泄漏更多数据。

  

**目前最新动态  
**

  

REvil以不同情和不会轻易放弃而出名，令人惊讶的是今天我们观测到REvil勒索软件团伙从其数据泄漏站点删除了Quanta(广达)泄漏页面（包括Apple示意图和图纸），这是比较罕见的，除非你支付了赎金。

  

从那以后，我们观测到REvil和Quanta(广达)之间在四天前建立了新的私人聊天室。在这次私人聊天中，REvil告诉Quanta(广达)，他们隐藏了数据泄漏页面，并将停止与记者交谈以允许谈判继续进行。

  

**虽然我们没有看到来自Quanta(广达)代表的任何消息，但REvil表示：“与我们开始对话后，您可以期望获得很大的折扣。”此折扣将赎金需求从5000万美元减少到2000万美元，并设定了新的**截止日**：5月7日，如下图所示：**

  

![](../Images/a9e2605b9c5c070348d4a53a667b73a4.png)

  

**此后，REvil警告Quanta(广达)，如果他们再未收到Quanta(广达)的答复，他们将公开“新iPad，新Apple徽标”发布图纸以及雇员个人数据和公司更多设计图。**

  

![](../Images/02e3ff1d887406d76fd077b7be78748e.png)

**新的REvil和Quanta聊天的一部分**

  

**我们不知道Quanta(广达)是否在另一个频道与REvil通信，或者谈判是否停止。但是如果REvil再次开始泄漏数据，我们就能知道Quanta(广达)还未支付勒索赎金。**
