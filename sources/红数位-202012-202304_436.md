# 迈克菲再次卖身将以40亿美元出售企业部门

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247494780&idx=1&sn=4b789276b55640f41ee1de863204096d&chksm=cef081cff98708d9f18e93ef6183f1a1bde40da59ee5ec5a6e0462d850ca828f44b630a91435&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247494780&idx=1&sn=4b789276b55640f41ee1de863204096d&chksm=cef081cff98708d9f18e93ef6183f1a1bde40da59ee5ec5a6e0462d850ca828f44b630a91435&scene=27#wechat_redirect)

美国网络安全公司迈克菲公司（McAfee Corp.）宣布，将以40亿美元现金的价格将其企业业务部门出售给私募股权公司Symphony Technology Group(STG)，然后仅专注于其消费者个人板块业务。

  

![](../Images/567dce8d3e377a76073f0b7b18f511fb.png)

  

迈克菲说，与已经拥有RSA的STG的交易有望在2021年底完成。

  

迈克菲总裁兼首席执行官彼得·利夫（Peter Leav）周一在一次会议上说：“我们认为这项交易在多个方面都很引人注目，因为它将释放我们的消费者业务，成为我们未来的重点，同时以极具吸引力的估值释放企业业务的价值。”与分析师通话。

  

**再次卖身**

  

早在2010年8月，英特尔公司正式对外宣布斥资77亿美元收购知名安全杀毒软件McAfee。而当时这家芯片巨头以每股48美元的价格进行收购，高于当时McAfee公司股价的60%。几年来一直使用“McAfee, an Intel Company”这一名称。

  

![](../Images/44e62bd94beb3cf28a910993e8c83c7c.png)

  

  

2012年，McAfee的创始人John McAfee因枪杀邻居被通缉，一系列特立独行的活动让McAfee声名狼藉。对那次更名John McAfee也表示非常开心。

  

到2017 年 4 月 3 日，迈克菲宣布独立，再次进行自主运营。此前，迈克菲被称为 Intel Security，即英特尔公司的安全组。

  

之前作为英特尔旗下公司，迈克菲发布的软件产品均冠以 Intel Security 名称和品牌。 

例如：

*   Intel Security True Key
    
*   Intel Security Safe Family
    

  

迈克菲独立后，原先的 Intel Security 品牌软件正在逐步改回迈克菲品牌。 

例如，上述名称现已更改为：

*   McAfee True Key
    
*   McAfee Safe Family
    

  

**这次卖身如果迈克菲McAfee的创始人John McAfee坐牢的话，相信还会再次更名。  
**

  

**为什么出售  
**

据McAfee报道，到2020年，McAfee消费者业务的净收入增长了20％，该公司增加了280万新消费者用户，总计1800万。

  

根据3月1日提交的10-K安全和交易委员会的报告，McAfee的企业部门在2020年创造了约14亿美元的收入，其中消费者领域的收入约为16亿美元。

  

利夫说：“我们相信，纯粹的消费者个人网络安全业务可以通过持续的营销改进继续以两位数的速度增长收入。”

  

**出售所得款项中约有10亿美元将用于偿还债务。McAfee CFO Venkat Bhamidipati表示，McAfee A类股东将获得每股4.50美元的一次性付款。**

  

Bhamidipati表示，目前在6,900名员工中，约有4,600名McAfee工人将转移至STG领导下的新企业业务。

  

Gartner高级研究总监Paul Webber在评论这笔交易时指出：“保留业务\[消费者\]部分的决定可以用消费者业务的相对良好表现，再加上以下事实来解释：这些解决方案不需要像企业产品和服务那样进行大量的投资，开发和客户迁移活动。”

  

Webber说，另一方面，STG在收购McAfee的企业业务方面具有很大的潜在上升空间，因为该部门拥有大量的大型企业客户。

  

**STG最新系列的收购**

此前，Symphony Technology Group收购了另外两家网络安全公司。

  

它于2020年9月以21亿美元的价格**从戴尔技术公司收购了RSA**，该交易还涉及其他投资者，包括安大略省教师退休金计划委员会和AlpInvest Partners。STG成立了RSA，以独立公司的身份运营。

  

2019年4月，STG收购了**网络风险管理公司RedSeal**的多数股权。财务细节尚未公布。
