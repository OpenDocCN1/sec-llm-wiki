美Exchange事件暗示即将对中发动网战？

一个黑客团体似乎在持续的攻击中渗透了成千上万的美国微软Exchange服务器。在过去几天中，美国至少有30000个组织-包括大量的小型企业，城镇，城市和地方政府-被一个异常激进的黑客网络组织所入侵，该部门致力于从受害组织中窃取电子邮件，黑客组织正在利用Microsoft Exchange Server电子邮件软件中的四个新发现的漏洞，并在全球范围内为成千上万的受害组织提供了工具，这些工具可以使攻击者对受影响的系统进行全面的远程控制。



这里涉及到一家美国公司Volexity，Volexity是一家总部位于华盛顿特区的网络安全公司，业务遍及全球。它由商业，开放源代码，政府和国防行业中一些主题专家领导，他们在内存取证领域（例如，波动性）方面开创了先河，撰写了畅销的安全书籍，并开发了突破性的工具和技术。在业内被称为安全事件处理公司，跟火眼类似。


事件经过


3月3日，Volexity这家公司发布了一篇名为：Operation Exchange Marauder: Active Exploitation of Multiple Zero-Day Microsoft Exchange Vulnerabilities（Exchange掠夺操作者：积极利用Microsoft Exchange多个零日漏洞）博客文章。



随后当天，Microsoft发布了紧急安全更新，以填补2013年至2019年Exchange Server版本中的四个安全漏洞，黑客正在积极利用这些漏洞来窃取运行Exchange的面向网络系统的电子邮件通信。


从那以后的三天内，安全专家说，同一黑客组织已经大大加强了对全球任何易受攻击且未打补丁的Exchange服务器的攻击。


在每次事件中，入侵者都留下了“网络外壳”，这是一种易于使用且受密码保护的黑客工具，可以从任何浏览器通过网络进行访问。Web Shell使攻击者可以对受害者的计算机服务器进行管理访问。


在匿名的情况下，向美国国家安全顾问介绍了此次攻击的两名网络安全专家宣称，黑客组织被认为负责控制了全球“数十万”台Microsoft Exchange Server的控制-每个受害系统代表大约有一个使用Exchange处理电子邮件的组织。


微软最初对Exchange漏洞的咨询归功于总部位于弗吉尼亚州Reston的Volexity报告了该漏洞。Volexity总裁史蒂芬·阿黛尔（Steven Adair）表示，该公司于2021年1月6日首次看到攻击者在悄悄地利用Exchange的漏洞，这一天全世界大部分目光都被美国国会大厦的暴动所吸引。


但是阿代尔说，在过去的几天里，黑客组织已迅速发展起来，迅速采取行动，在Internet上扫描尚未受到Microsoft周二发布的安全更新保护的Exchange服务器。


Adair说：“到目前为止，我们已经处理了数十起案件，直到2月28日（在Microsoft发布补丁程序之前），Web外壳才被安装在受害系统上。” “即使您在Microsoft发布补丁程序的同一天打了补丁，服务器上仍有一个Web Shell的可能性仍然很高。事实是，如果您正在运行Exchange，但尚未对此进行修补，则您的组织很有可能已经受到威胁。”


微软表示，已与美国网络安全与基础设施安全局（CISA），其他政府机构以及安全公司密切合作，以确保其为客户提供最佳指导和缓解措施。


微软发言人在一份书面声明中说：“最好的保护是尽快在所有受影响的系统上应用更新。” “我们将继续通过提供其他调查和缓解指导来帮助客户。受影响的客户应联系我们的支持团队，以获取更多帮助和资源。”


同时，CISA发布了一项紧急指令，命令所有运行易受攻击的Microsoft Exchange服务器的联邦民政部门和机构更新软件或将产品与网络断开连接。


阿代尔说，他今天接到来自州和地方政府机构的数十个电话，这些电话已经确定了Exchange服务器中的后门，并正在寻求帮助。问题在于，修补漏洞只会阻止黑客进入的四种不同方式。但是，它并不能消除可能已经造成的损害。



美国政府反应及影响


白宫新闻秘书詹·普萨基 （Jen Psaki）昨天对记者说，微软广泛使用的Exchange服务器中发现的漏洞“非常重要”，并且“可能产生深远的影响”。


普萨基说：“我们担心有大量受害者。”


众所周知，根除这些入侵者将需要在全国范围内进行前所未有的紧迫的清理工作。Adair和其他人说，他们担心受害者拆除后门所需的时间越长，入侵者越有可能通过安装更多后门来跟进，并可能扩大攻击范围，使其涵盖受害者网络基础设施的其他部分。。


安全研究人员已经发布了几种检测易受攻击的服务器的工具。这些工具之一，从微软的脚本大神凯文·博蒙特的GitHub下载：

https://github.com/microsoft/CSS-Exchange/blob/main/Security/http-vuln-cve2021-26855.nse


整体已经可以看到了通过运行这样的工具而编译的受害者列表的某些部分，但这不是一幅完整的图画。后门Web Shell可验证地存在于成千上万个美国组织的网络中，包括银行，信用合作社，非营利组织，电信提供商，公用事业和警察，消防和救援部门。


一位消息人士说：“这是警察部门，医院，大量的城市和州政府以及信用合作社，”与联邦官员就此事密切合作的消息人士说。“几乎所有运行自托管Outlook Web Access且截至几天前尚未修补的人都遭到了零日攻击。”


另一位政府网络安全专家最近参加了一次电话会议，受到了这一黑客热潮的影响，与多个利益相关者进行了担忧，他们担心需要进行清理工作，这次被命名为Herculean行动。


消息人士说：“在电话中，许多问题都来自学区或地方政府，都需要帮助。”在没有用名字识别的情况下，他们说。“如果这些数字成千上万，事件响应如何完成？只是没有足够的事件响应团队来快速地做到这一点。”

为什么栽赃中国


微软已经表示，对易受攻击的Exchange服务器的入侵与单独的SolarWinds相关攻击没有任何关系，在该攻击中，一个可疑的俄罗斯情报组织在超过18,000个组织使用的网络管理软件中安装了后门程序。



该公司表示：“我们仍然看不到有证据表明SolarWinds背后的参与者发现或利用了Microsoft产品和服务中的任何漏洞。”


纵观媒体似乎将过去几天的事件最终影响定义为远远超过SolarWinds入侵者所遭受的损害。


当微软在周二发布针对四个Exchange Server漏洞的补丁时，微软强调该漏洞不会影响客户运行其Exchange Online服务（微软的企业云托管电子邮件）。但是消息人士称，迄今为止，受害的绝大多数组织都在内部与Exchange服务器协同运行某种形式的面向网络的Microsoft Outlook Web Access（OWA）电子邮件系统。


政府网络安全专家说：“这是一个值得询问的问题，微软的建议是什么？” “他们会说'Patch，但最好还是去云端。' 但是，他们如何保护自己的非云产品呢？让他们在葡萄树上枯萎。”


这位政府网络安全专家表示，最近一轮攻击与典型地归因于中国的各种国家/地区级黑客行为不符，中国通常将重点放在破坏特定的战略目标上。


消息人士说：“愚蠢。”，“对于中国国家黑客来说，这种滥杀滥伤似乎是不合时宜的。”


我们都知道，在2020年12月爆出美国SolarWinds被黑事件，SolarWinds多达18,000个全球客户，包括政府机构，私人公司和其他组织。微软12月表示，这次袭击“已到达俄罗斯以外的许多主要国家首都”。


白宫官员已经准备好透露俄罗斯是黑客的“主要角色”，但在最后一刻被告知要站下来。在该报告的12月19日当天，时任总统的特朗普在推特上发文说：“假新闻媒体的网络黑客比实际情况要严重得多”，并在没有任何证据暗示可能是中国发起入侵。



看来美国在遭遇入侵的第一反应就是试图栽赃中国。


新上任总统拜登在12月18日针对美国各企业及政府所谓SolarWinds被黑事件的发表了第一个正式回应。


拜登表态：我的政府将把网络安全作为各级政府的首要任务，我们将从上任之日起就把处理这一漏洞作为首要任务。我们将把网络安全提升为政府的当务之急，进一步加强与私营部门的伙伴关系，扩大对基础设施和人员的投资，以防范恶意网络攻击。并让攻击者付出代价。


美国国家安全顾问杰克·沙利文（Jake Sullivan）一周前在媒体表态，美国将在几周内对毁灭性的SolarWinds供应链的攻击做出反应并说美国政府的反应将不仅限于制裁。
