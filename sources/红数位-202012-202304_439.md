# 美国起诉约翰·迈克菲加密货币欺诈和洗钱

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247494755&idx=2&sn=8589c5a6a24227a96db40269dc9f9542&chksm=cef081d0f98708c6d7dd9ff094b3bcecac45267595f31580735c94174d3a2d9a0164c82a04f8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247494755&idx=2&sn=8589c5a6a24227a96db40269dc9f9542&chksm=cef081d0f98708c6d7dd9ff094b3bcecac45267595f31580735c94174d3a2d9a0164c82a04f8&scene=27#wechat_redirect)

美国联邦检察官已正式指控网络安全公司McAfee的创始人约翰·迈克菲（John McAfee）及其执行顾问吉米·盖尔·沃森（Jimmy Gale Watson Jr）涉嫌加密货币欺诈和洗钱。

  

![](../Images/865332769fdc4758670bf3754f9dd3fa.png)

  

根据法院文件，总共McAfee，Watson和McAfee Team的其他成员能够从两个加密货币抽放方案中收取1300万美元 。

  

![](../Images/fb80fae41e416d73bb6f619608dd9fbc.png)

  

**Twitter账户用于加密货币欺诈**

在2017年12月至2018年1月之间，他们通过山寨币剥夺净赚取了超过200万美元的非法利润。山寨币剥夺是一种被称为\`\`甩卖''计划的欺诈行为。

  

从2017年12月到2018年，他们通过运行一项并行计划来获利约1100万美元，该计划用于推广多个初创公司的初始代币发行（ICO），同时隐藏了他们从ICO投资者那里获得的付款。

  

在2017年12月至2018年10月之间，McAfee，Watson和另一位团队成员还洗了洗钱和ICO兜售计划产生的数字资产收益。

  

曼哈顿美国检察官奥德丽·施特劳斯（Audrey Strauss）表示：“据称，被告利用迈克菲的Twitter帐户将消息发布给成千上万的他的Twitter追随者，他们通过虚假和误导性陈述来兜售各种加密货币，以掩饰其真实的，自私的动机 。”

  

“据称，迈克菲，沃森以及迈克菲加密货币团队的其他成员从因欺诈计划而受害的投资者那里筹集了超过1300万美元。”

  

**迈克菲目前在西班牙被拘留**

**他们被控以七项罪名，每项罪名最高可能被判处5至20年徒刑。**

  

美国证券交易委员会（SEC）也已  在另一项执法行动中对McAfee提起了民事诉讼。

  

他被指控支付了超过2300万美元的数字资产，并假装是公正且独立于他所推广的ICO。

  

SEC网络部负责人克里斯蒂娜·利特曼（Kristina Littman）表示：“据称，在沃森的协助下，迈克菲利用自己的名声欺骗了众多追随者的数字资产证券，而没有告知投资者其作为有偿发起人的角色。”

  

迈克菲（McAfee） 去年在美国司法部税务部门提起的另一项逃税指控中被捕，目前正被拘留在西班牙 。
