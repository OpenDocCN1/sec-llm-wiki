# 能用来窃听Signal,Duo和FB Messenger的漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247494548&idx=1&sn=21f6de54be8107090df9d59d8ce2b4e5&chksm=cef08627f9870f315784d7f70d7f2775fc764917fb34c4238b88c0a41f3de357e37f61888da1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247494548&idx=1&sn=21f6de54be8107090df9d59d8ce2b4e5&chksm=cef08627f9870f315784d7f70d7f2775fc764917fb34c4238b88c0a41f3de357e37f61888da1&scene=27#wechat_redirect)

尽管已被修补，但如果被利用，这些漏洞将对用户的隐私和安全性构成重大威胁。

  

![](../Images/c5c117293a3e70b5dd89e6158ca5925f.png)

  

Google Project Zero研究人员Natalie Silvanovich透露了一些视频会议和消息传递应用程序中的漏洞，这些漏洞可能允许恶意用户和威胁参与者进行窃听而不被发现。

  

**借助这些漏洞，攻击者甚至可以在接听电话之前就收听他们所呼叫人员的周围环境。**值得注意的是，该特定错误的详细信息也已于2020年11月20日在Facebook Messenger中报告。

  

根据Silvanovich所说，这些是在**包括Signal，JioChat，Mocha，Google Duo和Facebook Messenger消息传递应用程序中发现的逻辑漏洞。**

  

***“我研究了七个视频会议应用程序的信令状态机，发现了五个漏洞，这些漏洞可能允许呼叫者设备强迫被呼叫者设备传输音频或视频数据，” Silvanovich在博客中写道。***

  

**在2019年发现的漏洞**

根据报道，该漏洞于2019年1月在Apple的FaceTime群聊功能中被发现，并允许用户发起FaceTime视频通话并监视目标，方法是仅在他们接受此人之前在群聊中添加第三人的号码来电。

  

该漏洞极为严重，苹果公司从FaceTime中删除了群聊功能，直到在iOS更新中解决该问题为止。后来，在上述聊天应用程序中发现了各种类似的错误。

  

**关于漏洞**

  

**Signal**

Silvanovich透露，Signal应用程序中发现的漏洞已于2019年9月修复。它使攻击者无需任何用户交互即可从呼叫者设备向被呼叫者发送连接消息。实际上应该是相反的方式。

  

![](../Images/4a892a34ff4c0bc7a211cf9400651517.png)

  

**Google Duo**

相反，Google Duo错误是一种竞赛条件，允许被叫方将未应答的呼叫视频数据包泄漏给呼叫者，以便在被接听之前连接音频呼叫。它在2020年11月进行了修补。 

  

**Facebook Messenger**

Facebook Messenger的错误可能允许攻击者登录到应用程序后发起呼叫并向任何目标发送自定义消息。但是，目标应同时登录Messenger客户端和应用程序（例如Web浏览器），以从被叫方的设备接收音频。此错误也已在2020年11月修复。

  

**Mocha和JioChat **

在Mocha和JioChat Messenger中发现了两个类似的缺陷。这些错误允许发送JioChat音频和Mocha音频/视频。两者都分别于2020年7月和2020年8月修复。

  

有趣的是，所有这些漏洞都是在对等呼叫中发现的，而不是在群聊功能中发现的。

  

结论：

如果您使用的是消息传递应用程序，请确保将其更新为最新版本，因为更新旨在修复不知情的用户所不知道的错误和缺陷，但对于恶意元素而言却是丰厚的机会。
