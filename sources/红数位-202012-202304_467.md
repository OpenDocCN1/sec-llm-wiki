# 美网络安全公司Malwarebytes自曝被入侵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247494529&idx=1&sn=b214b1cf2afd225e99267fca79757bfe&chksm=cef08632f9870f2439cec08344ad594d3cd0d892a5c4912aad0b90fb90c9c4c34a6610b2652f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247494529&idx=1&sn=b214b1cf2afd225e99267fca79757bfe&chksm=cef08632f9870f2439cec08344ad594d3cd0d892a5c4912aad0b90fb90c9c4c34a6610b2652f&scene=27#wechat_redirect)

美国网络安全公司Malwarebytes今天表示，该公司遭到了去年入侵IT软件公司SolarWinds的同一黑客团体攻击。

  

![](../Images/183212d820433105bf5dd30b91ec7875.png)

  

Malwarebytes表示，其入侵与SolarWinds供应链事件无关，因为该公司未在其内部网络中使用任何SolarWinds软件。

  

相反，这家安全公司表示，黑客通过利用Office 365租户中的休眠电子邮件保护产品来破坏其内部系统。

  

Malwarebytes表示，**他们是12月15日从Microsoft安全响应中心（MSRC）获悉入侵的，该漏洞检测到了来自休眠Office 365安全应用程序的可疑活动。**

  

当时，微软正在对其Office 365和Azure基础结构进行审核，以查找由SolarWinds黑客创建的恶意应用程序的迹象，这些黑客在网络安全圈中也称为UNC2452或Dark Halo。

  

**Malwarebytes表示，一旦得知该漏洞，便开始进行内部调查，以确定黑客可以访问哪些内容。**

  

Malwarebytes联合创始人兼现任首席执行官Marcin Kleczynski今天说：**“经过广泛调查，我们确定攻击者仅能访问公司内部电子邮件的一部分。”**

  

**MALWAREBYTES产品不受影响**

由于相同的威胁参与者入侵了SolarWinds，然后通过将Sunburst恶意软件插入SolarWinds Orion应用程序的某些更新中来毒化该公司的软件，因此Kleczynski表示，他们还对其所有产品及其源代码进行了非常彻底的审核，以查找任何类似妥协或过去供应链攻击的迹象。

  

“我们的内部系统没有任何证据表明在任何本地和生产环境中都有未经授权的访问或损害。

  

“我们的软件仍然可以安全使用，” Kleczynski补充说。

  

**在今天的披露之后，Malwarebytes成为UNC2452 / Dark Halo威胁对象的第四大主要安全供应商， 美国官员已将其与俄罗斯政府的网络间谍活动联系在一起。**

  

**先前针对的安全公司包括 FireEye，  Microsoft和 CrowdStrike。**
