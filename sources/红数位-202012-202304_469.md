# 英警方误删除21万条指纹、DNA和逮捕记录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MjI1MDU4OA==&mid=2247494520&idx=1&sn=443dc8d61546c101bc42d0db9b64df8a&chksm=cef086cbf9870fddd2a8efd22eae2eab828eea4e6c58aedbd77e5a077302c99f37157e624a74&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3MjI1MDU4OA==&mid=2247494520&idx=1&sn=443dc8d61546c101bc42d0db9b64df8a&chksm=cef086cbf9870fddd2a8efd22eae2eab828eea4e6c58aedbd77e5a077302c99f37157e624a74&scene=27#wechat_redirect)

英国政府正在评估“技术问题”的影响，该问题导致从英国警察数据库中删除21.3万条记录。在意外将其标记为删除后，擦除了包括指纹，DNA和逮捕历史在内的数据。

  

![](../Images/00473191c409efc9ffa39b77518d6ec8.png)

  

最开始英国政府承认，技术故障导致意外删除了全国警察数据库中的150000个逮捕记录。经过调查后，英国国家警察局长委员会说，删除了213,000条记录-超过首次报告的150,000条记录。《时代》报道，这种擦除是无意的，是人为错误造成的。

  

内政部表示正在评估错误的影响。在无意中将其标记为删除之后，从全国警察存储和共享犯罪记录信息的警察国家计算机（PNC）中删除了包括指纹，DNA和逮捕历史在内的数据。

  

**意外删除**

据消息人士称，有缺陷的代码负责保留错误的文件以供删除。该错误影响了警察国家计算机上的记录，并影响了英国的签证系统，导致签证申请处理暂停两天。

  

**异常安全漏洞**

影子内政大臣尼克·托马斯·西蒙兹（Nick Thomas-Symonds）表示，这是“非常严重的安全漏洞”。

  

*“这是一个非常严重的安全漏洞，对公共安全构成了巨大的危险。尼克·托马斯·西蒙兹（Nick Thomas-Symonds）的官方声明说：“这个残酷的政府的无能不能使人民处于危险之中，让罪犯自由，并否认受害者的正义。”*

![](../Images/fee2bf7ebf58b1ebfe3db50764a43631.png)

  

英国内政部国务卿普里蒂·帕特尔（Priti Patel）也被敦促解释一下粗心大意的安全失误，该失误抹掉了国家警察数据库中的记录。

  

**生物特征证据丢失**

由于该软件故障，英国警方丢失了超过21.3万个DNA，指纹和逮捕历史记录。由于从犯罪现场收集的生物特征证据将不再在警察国家计算机上提供，这可能会导致严重的后果，因为罪犯很容易逃脱定罪。

  

**"除草"期间清除数据**

根据英国内政部的消息来源，该部门在每周一次的数据删除过程（称为“除草行动”）中意外删除了这些记录。《泰晤士报》报道说，犯罪嫌疑人的关键情报数据已经消失，但罪犯或危险人物的记录并未删除。此外，丢失的数据是那些无罪被逮捕和释放的个人。值得注意的是，在英国与英国脱欧后与欧盟达成交易之后，从同一数据库PNC中删除了大约40,000个与欧洲罪犯有关的警报。不排除跟此种操作有关。

  

**调查正在进行中**

英国警务大臣基特·马尔特豪斯（Kit Malthouse）证实，官员正在调查此事，并试图追回丢失的记录。他们已经确定并解决了问题，因此不会再次发生。

  

**延伸阅读：脱欧对英国警务影响**

当一线警务人员收到有关通缉或失踪人员，汽车或其他物品的警报时，其中一些警报来自整个欧盟范围内称为SIS 2的庞大数据库。

  

英国警察将其9100万个条目的搜索内容整合到日常工作中，英国警察每年对其进行大约10亿次访问。政府自己的脱欧文件中的这个例子说明了它的优势。2016年6月，葡萄牙上传了有关毒品贩子的警报。英国的系统发现有人飞入该国与嫌疑犯相匹配-导致他们被捕并在两周内返回葡萄牙。

  

还有其他数据库：

*   Ecris-用于检查犯罪记录的泛欧洲系统
    
*   Prüm-连接整个欧洲警察使用的DNA和犯罪指纹记录的系统。NCA称，普鲁姆以达成协议的德国小镇的名字命名，已帮助500项调查确定了嫌疑人
    
*   Eurodac-一种迁移指纹系统，可跟踪同一个人的多次庇护申请
    

  

到2020年底，内政部将SIS 2和其他数据库拔出，因为它们受欧盟法律管辖。上个月，国家警察局长委员会负责人马丁·休伊特（Martin Hewitt）表示，失去SIS 2将会“产生重大的运营影响”。
