微软来救火，马上隔离SolarWinds二进制文件

微软昨日宣布，Microsoft Defender将从北京时间今晚8点开始全球隔离受威胁的SolarWind Orion二进制文件。



上周末，有消息称俄罗斯民族国家的黑客入侵了网络管理软件开发商SolarWinds，并向其Orion Platform添加了恶意代码。


然后，通过SolarWinds的自动更新机制将恶意二进制文件分发给大约18000个客户，其中包括许多美国政府机构。威胁者使用这些恶意二进制文件安装了称为Solorigate（Microsoft）或SUNBURST（FireEye）的后门。


尽管Microsoft已经在检测并隔离后门程序，但他们尚未隔离受感染的SolarWinds二进制文件，因为它可能会影响客户使用的基本网络管理操作。


由于该木马软件带来的威胁，Microsoft已宣布，从今天（北京时间）12月16日晚上8:00开始，Microsoft Defender将开始隔离受损的SolarWinds二进制文件。


“很重要的一点是，这些二进制文件对客户环境构成了重大威胁。客户应考虑将任何二进制文件损坏的设备，并且应该已经在调查具有此警报的设备。从12月16日（星期三）北京时间晚上8:00开始， Microsoft Defender防病毒软件将开始阻止已知的恶意SolarWinds二进制文件。即使该进程正在运行，这也将隔离该二进制文件。” 微软昨天宣布。


Microsoft Defender将受感染的SolarWinds二进制文件检测为“ Trojan：MSIL / Solorigate.BR！dha”。


Microsoft还建议将所有运行SolarWinds软件的服务器与其他环境隔离开来，并在重新使用之前彻底调查恶意软件。


建议执行以下步骤：


  1. 立即隔离受影响的设备。如果启动了恶意代码，则设备很可能受到攻击者的完全控制。

  2. 确定受影响的设备上已使用的帐户，并认为这些帐户已被盗用。重置密码或停用帐户。

  3. 调查受影响的端点可能是如何受到威胁的。

  4. 使用受损帐户之一调查设备时间轴以指示横向运动活动。检查攻击者可能已放弃使用其他工具来启用凭据访问，横向移动和其他攻击活动。


如果你不想中断服务，则Microsoft已创建GPO策略，该策略可用于更改Microsoft Defender的行为，以便不会删除检测到的受到威胁的SolarWinds二进制文件。


对于通过GPO的Microsoft Defender防病毒说明：

路径：“计算机配置” >“管理模板” >“ Windows组件” >“ Microsoft Defender防病毒（或Windows Defender防病毒）”>“威胁” >“指定威胁警报级别”，在检测到该警报级别时不应采取默认操作。

值名称：2147771206

值：6


对于通过GPO的SCEP说明：

路径：“计算机配置” >“管理模板” >“ Windows组件” >“端点保护” >“威胁” >“指定威胁警报级别”，在检测到该警报级别时不应采取默认操作。

值名称：2147771206

值：6


对于通过SCCM的Microsoft Defender防病毒软件和SCEP说明：

路径：资产和合规性，端点保护>反恶意软件策略>威胁替代>输入威胁名称：Trojan：MSIL / Solorigate.BR！dha

路径：资产和合规性，端点保护>反恶意软件策略> <选择相关策略>>威胁替代>输入威胁名称：Trojan：MSIL / Solorigate.BR！dha

覆写动作：允许


对于使用PowerShell指令通过MEM的MDAV：


  1. 创建具有以下内容的PowerShell脚本：

    Set-MpPreference-ThreatIDDefaultAction_Ids 2147771206 -ThreatIDDefaultAction_Actions 6


  2. 将该脚本命名如下：Allow_SolarWinds.ps1

  3. 将其保存到一个临时位置，例如C：\ Temp。

  4. 转到https://endpoint.microsoft.com并登录。

  5. 浏览到设备> Windows > PowerShell脚本。

  6. 选择+ Add，然后指定以下设置：

    名称：暂时允许SolarWinds

    说明：修补时暂时允许SolarWinds


7.选择“下一步”，然后浏览到保存PowerShell脚本的位置（例如C：\ Temp \ Allow_SolarWinds.ps1）。

8.使用以下设置运行脚本：

使用登录的凭据运行此脚本：否

强制执行脚本签名检查：否

在64位PowerShell主机中运行脚本：是

9.选择下一步。

10.对于Scope标签，请使用<default>。

11.选择下一步。

12.对于分配，选择选择要包括的组，然后选择具有Windows 10设备的安全组。

13.选择选择，然后选择下一步。

14.查看您的设置，然后选择添加。

注意：有关MEM（Intune）PowerShell脚本故障排除，请查看：C：\ ProgramData \ Microsoft Intune管理扩展\ Logs \ IntuneManagementExtension.log


对于通过PowerShell手动安装Microsoft Defender Antivirus的说明：

以管理员身份启动PowerShell

Set-MpPreference -ThreatIDDefaultAction_Ids 2147771206 -ThreatIDDefaultAction_Actions 6

 

对于通过PowerShell说明进行手动SCEP：

以管理员身份启动PowerShell

导入模块“ $ env：ProgramFiles \ Microsoft安全客户端\ MpProvider \ MpProvider.psd1”

Set-MpPreference -ThreatIDDefaultAction_Ids 2147771206 -ThreatIDDefaultAction_Actions 6

 

被动模式下的Microsoft Defender防病毒注意事项：

  • 如果阻止模式下的EDR启用并且Microsoft Defender AV与第三方防病毒产品处于被动模式，则Microsoft Defender Antivirus将采取措施（如果未按照提供的说明进行排除）

  • 如果阻止模式下的EDR未启用并且Microsoft Defender Antivirus与第三方防病毒产品处于被动模式，则Microsoft Defender Antivirus将发出警报，但不会采取任何补救措施。
