A SQL Injection Vulnerability has been discovered in the Joomla Module called com\_blog\_calendar.   
The Vulnerability is located in the index.php?option=com\_blog\_calendar&modid=xxx Parameter.   
Attackers are able to execute own SQL commands by usage of a GET Method Request with manipulated modid Value.   
Attackers are able to read Database information by execution of own SQL commands.

\================================
