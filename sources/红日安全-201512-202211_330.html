什么是Web scraping?

几乎从互联网诞生开始，便有了从互联网自动收集数据。尽管Web scraping是一种新的形式， 在过去的几年里，这项技术以screen scraping，data mining,web harvesting或其他类似的词被人们熟知。今天，人们通常更喜欢web scraping,因此，在本书接下来的介绍里，我会称Web -scraping 程序bots

理论上，web scraping是指通过各种方法获得数据，而不只是通过一个用API交互的程序（简单的说，是指一个人使用一个web浏览器）。这通常是通过写一个自动化的程序来实现，这个程序实现查询web服务器，请求数据（通常是以HTML和其他包含web页面文件的形式），然后分析这些数据，进而抽取需要的信息。

在实践中，web scraping包含了许多编程技术，如数据分析和信息安全，这本书讲涵盖web scraping和Crawling的基础知识（Part 1），并在part2钻研一些前沿话题。

from urllib.request import urlopen
html = urlopen("http://pythonscraping.com/pages/page1.html")
print(html.read())
你可以保存这个代码为scrapetest.py并使用命令在终端运行它：
$python scrapetest.py

注意，如果你也有Python 2.x安装在你的机器，你可能需要显式调用Python 3.x通过这种方式运行命令：
$python3 scrapetest.py
这会输出对于地址为http://pythonscraping.com/pages/page1.html的网页的完整的HTML代码。更准确地说，这将会输出HTML文件page1.html，在目录<web root>/页面下，在域名为http://pythonscraping.com的服务器上。
有什么区别吗？大多数现代的网页都有许多与它们相关的资源文件。这可能是图像文件，JavaScript文件，CSS文件，或任何其他的你所请求的页面链接内容，。当Web浏览器点击一个标签如<img src=“cutekitten .jpg”>，浏览器知道它需要发送另一个请求到服务器，从而获取在文件cutekitten.jpg的数据，进而为用户充分渲染页面。记住，我们的Python脚本没有回退和请求多个文件的逻辑（还）；它只能阅读，我们已经请求的单一的HTML文件。

那么它是怎么做到的呢？由于Python语言简明自然，行
 from urllib.request import urlopen
意味着：Python 组件（module）请求((在urllib库中寻找)并导出函数urlopen
如果你在Python 2.x使用urllib2库，你可能已经注意到，urllib和urllib2已经有所改变，在Python 3.x，urllib2更名为urllib,b，并分为几个子模块：urllib.request，urllib.parse，和URL lib.error。虽然函数名大多是相同的，当你使用新的urllib时，你应该注意某些功能已经移到了子模块。
urllib一个标准的Python库（这意味着你不需要安装任何额外的东西来运行这个实例）包含通过网络请求数据，处理cookie，甚至改变的元数据，如头部和你的用户代理的功能。我们全书都将使用urllib，所以我们建议你阅读Python文档（https://docs.python.org/3/library/urllib.html）。urlopen用于在网络上打开一个远程对象并读取它。因为这是一个相当普通的库（它可以读取HTML文件，图像文件，或任何其他文件流），我们在书中将经常用到它。
Beautifulsoup介绍

“美丽的汤，那么丰富和绿色，
在炎热的盖碗等待！
谁为这样的美食不会屈尊？”
晚上的汤，美丽的汤！

The BeautifulSoup library was named after a Lewis Carroll poem of the same name in Alice’s Adventures in Wonderland. In the story, this poem is sung by a character called the Mock Turtle (itself a pun on the popular Victorian dish Mock Turtle Soup made not of turtle but of cow).
Like its Wonderland namesake, BeautifulSoup tries to make sense of the nonsensical;it helps format and organize the messy web by fixing bad HTML and presenting us with easily-traversible Python objects representing XML structures.
BeautifulSoup库被命名为刘易斯卡罗尔诗（Lewis Carroll poem），与爱丽丝梦游仙境里一样的名字。在这个故事中，这首诗是由模拟海龟（Mock Turtle）唱的。（Mock Turtle这是一个很受欢迎的维多利亚菜的双关语，它不是乌龟，而是牛的汤）。
与仙境同名，beautifulsoup尝试使荒谬的变得有意义；BeautifulSoup通过修复坏的的HTML，并向我们呈现容易traversible 代表XML结构的Python对象，来格式化和组织混乱的网络 。

安装 BeautifulSoup
因为BeautifulSoup库不是默认的Python库，必须安装。我们将在这本书中使用BeautifulSoup 4库（又称BS4）。安装beautifulsoup 4的具体说明可以发现在crummy.com中找到；然而，Linux的基本方法如下：
$sudo apt-get install python-bs4

Macs的方法：
$sudo easy_install pip
这安装了Python的包管理器pip, 然后执行下列语句：$pip install beautifulsoup4来安装库
再次，注意，如果你有Python 2 .x 和3. x安装在你的机器，你可能需要明确调用Python3：
$python3 myScript.py
当安装包时，也要使用这条语句，否则包可能安装在Python 2.x下，而不是Python 3 X：
$ sudo Python3 setup.py install
如果使用PIP，你也可以调用PIP3安装Python 3.x版本的软件包：
$pip3 install beautifulsoup4
在windows中安装包几乎是与Mac和Linux相同的过程。从上面的下载地址下载最新版本浏览BeautifulSoup 4，到您解压缩的目录并运行它：

>python setup.py install
就是这样！beautifulsoup现在将在你的机器上被识别成为一个的Python库。你可以通过打开Python终端并输入下列命令测试：
$python
> from bs4 import BeautifulSoup
输入应无错误的执行。

此外，在Windows上还有一个PIP的.exe安装包，这样你就可以轻松地安装和管理软件包：
>pip install beautifulsoup4

用虚拟环境保持库 
如果你打算工作在多个Python项目上，或者你需要一种方式来轻松地捆绑项目和所有相关的库，或者你担心安装库之间的潜在冲突，你可以安装一个Python虚拟环境保持各部件互不分离和易于管理。 
当你在非虚拟的环境下安装一个Python库，你安装了它的全局。这通常需要管理员身份，或作为root运行，Python库存在，为每一位用户和机器上的每一个项目的使用。幸运的是，创建一个虚拟环境是很容易的 ：
$ virtualenv scrapingEnv
这将创建一个新的环境scrapingenv，你必须激活才能使用：
$ cd scrapingEnv/
$ source bin/activate
当你激活了环境，你将在你的命令行提示符看到环境的名字，提醒你，你目前的工作。你安装的任何库或运行的脚本，都将在虚拟的环境中，在新创建的scrapingenv环境下工作，我们可以安装和使用BeautifulSoup，例如： 
(scrapingEnv)ryan$ pip install beautifulsoup4
(scrapingEnv)ryan$ python
> from bs4 import BeautifulSoup
>
我可以关闭命令，离开这个环境，之后我不再能访问安装在虚拟环境中的任何库：
(scrapingEnv)ryan$ deactivate
ryan$ python
> from bs4 import BeautifulSoup
Traceback (most recent call last):
File "<stdin>", line 1, in <module>
ImportError: No module named 'bs4'
通过项目将所有的库分离，也可以很容易地将整个环境文件夹压缩，并将其发送给其他人。只要他们的计算机上安装Python的版本相同，您的代码将从虚拟环境中工作，无需自己安装任何库。虽然我们不能明确地指示你在这本书的例子中使用一个虚拟的环境，记住，你可以简单地通过预先激活虚拟环境来应用它。
