# Apache Flink jobmanager/logs 目录穿越漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NDk0ODYzMw==&mid=2247484760&idx=1&sn=2baac667b5edbb56e837943765ca815b&chksm=9fde26aea8a9afb8f755cdd447aeed71bdb2e224ae1a2d1a6b22fb4c051131e067355ab9982b&scene=126&sessionid=1681656948#rd](http://mp.weixin.qq.com/s?__biz=MzA4NDk0ODYzMw==&mid=2247484760&idx=1&sn=2baac667b5edbb56e837943765ca815b&chksm=9fde26aea8a9afb8f755cdd447aeed71bdb2e224ae1a2d1a6b22fb4c051131e067355ab9982b&scene=126&sessionid=1681656948#rd)

**1、漏洞描述**  

Apache Flink 是一个开源流处理框架，具有强大的流处理和批处理能力

Apache Flink 1.11.0 中引入的一项更改（也在 1.11.1 和 1.11.2 中发布）允许攻击者通过 JobManager 进程的 REST 接口读取 JobManager 本地文件系统上的任何文件

**2、漏洞影响范围：**  

Apache Flink 1.11.0、Apache Flink 1.11.1、Apache Flink 1.11.2

**3、漏洞复现:  
**

环境：

ubuntu:192.168.4.128  

docker
