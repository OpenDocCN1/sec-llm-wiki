# Fluxion伪造wifi热点钓鱼密码

1.Fluxion是一个无线破解工具，自己动手实验了一下，成功钓鱼到wifi密码(自己的wifi)  
2.kali上安装fluxion  
   Github地址：  
   https://github.com/deltaxflux/fluxion.git  
   那Kali-linux系统 在Github如何下载：  
   命令：Git clone  
有一些需要安装的依赖，会提醒你安装，安装即可  
3.启动fluxion  

![](../Images/1f96e0ff2619d19c53e85494de208be8.png)  

  
4.选择语言，选英语了，没有中文。。。。。  

![](../Images/839cda17772a19c39b7b87bc11960119.png)  

  
5.选择网卡  

![](../Images/7bc584312cb1bf56184f945dcd6be198.png)  

  
6.通道选择，选全部吧  

![](../Images/1d665656003e6a15f6e351d9973b1bd5.png)  

  
7.自动扫描周围的无线AP  

![](../Images/58a59c538bf4bd2ca1a7ac35ca6227ec.png)  

  
8.我电脑把自己的wifi设置忘记密码（用于测试），  
ctrl-c停止后，在扫描后的的列表里选择要测试的ssid（最前面的号码），我选的21  

![](../Images/cf38452c541ef482d7855ce9d5c15d70.png)  

  
9.之后设置假AP，选1  

![](../Images/23bf11ebc618d2562b65641bcd5be671.png)  

  
10.选择握手包的保存路径。你可以直接空格键跳过  

![](../Images/9a164053f282f61418db6be36bb83054.png)  

  
11.选择aircrack-ng开始抓取握手包  

![](../Images/176f4f088550b7bdab07daa90930234e.png)  

  
12.选1，不是很清楚为什么，说是可以统一分配用户  

![](../Images/3f71067502696b7a99cb9bd9e6f54418.png)  

  
13.开始抓取握手包，如果有人在用无线的话，几分钟就好了，我等了几分钟，自己选择了1，检查握手包。  

![](../Images/282fcdf12efb44f5995661a48c697b3c.png)  

  
14.有了握手包之后，可以建立假AP来钓鱼密码了，选1  

![](../Images/6d8143677c5cad22c6663dd97f7b7f5d.png)  

  
15.选择完语言后开启四个窗口，等待用户连接等等  

![](../Images/4ecf66d169e5c59b42f6821c83d206d2.png)  

  
16.然后我用手机连接我的无线网，这时候连接的是一个假的AP，没有密码，我也没办法连接到真的无线上，所有终端都会自动连接到假的无线上，  
之后打开手机浏览器，自动跳转到登录页面，如果是中文的话那就很逼真了，但是是英文的，呵呵呵  

![](../Images/0c534446fc5a82692113f3c68cf09bdc.png)  

  
17.不明所以的吃瓜群众输入密码后  

![](../Images/58ba31a62d8eccf3fc7486110be0cf21.png)  

  
18.如果密码错误，fluxion依然会弹出登录页面，如果正确，程序会自动结束并显示密码，用户会连接真实的AP，如果真不知情，用户可能就忽略了，但是密码已经被人窃取了  

![](../Images/398e84fdab69f21504eb9f9eb7401399.png)
