# 通过shift漏洞对Windows系统登录密码进行破解

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NDk0ODYzMw==&mid=2247483653&idx=1&sn=2f42f12b5f8f341c7c0ef87591b0ecdb&chksm=9fde22f3a8a9abe5e3d80cd02d40d291abd80b2295ae078bce139e6fb1c83ac5a687aa8ed65f&scene=126&sessionid=1681656976#rd](http://mp.weixin.qq.com/s?__biz=MzA4NDk0ODYzMw==&mid=2247483653&idx=1&sn=2f42f12b5f8f341c7c0ef87591b0ecdb&chksm=9fde22f3a8a9abe5e3d80cd02d40d291abd80b2295ae078bce139e6fb1c83ac5a687aa8ed65f&scene=126&sessionid=1681656976#rd)

实现过程：

1，开启win7虚拟机，开机，并设置一个复杂的密码；

2，关机，并开机，出现Windows启动界面时强制关机；

3，再次开机，出现“启动修复（推荐）”及选择该项；

4，出现“系统还原”提示，点击取消，等待几分钟，会出现问题原因，点击查看详细信息，

5，打开最后一个链接即一个记事本

6，记事本操作：“文件”-》“打开”，找到系统文件system32并选择显示“所有文件”

7，找到sethc并改名sethc-bak,复制一份cmd改名为sethc

8,全部关闭，重启。

9，系统重启完毕后，连续按5下shift键，弹出cmd指令，此时可使用命令行，完成创建新用户且提升为管理员

10，cmd中输入以下命令：

net user user password /add

net localgroup administrators user /add'

10,注销切换用户登陆
