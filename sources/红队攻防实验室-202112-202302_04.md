## 前言 

一次攻防演练中首先是团队拿到了一个 Webshell ，后续又把权限弹到了 CobaltStrike 方便我来做内网渗透：  

![](../Images/a13e8f79511446281b7807fd014d0582.png)

通过发现当前机器是一台公网服务器，只有公网 IP：xxx.xxx.xxx.16

![](../Images/55b2f6122ecd9aaefcab024efc552325.png)

通过查看 arp 缓存发现当前是有一些公网机器的：

![](../Images/c9d057c7ea891f4303b74b35727fa97f.png)

通过查询这些 IP 发现是"某网络"，而且通过 Nbtscan 发现当前 C 段有主机存活：（初步判断当前 C 段机器有可能存在域，但不确定）

![](../Images/44829ac638e4747cc6f5f90567f7c41f.png)

## 对当前第一层内网机器 C 段进行横向移动 

由于是攻防演练，拿到越多的分数越好，在这里就不考虑一些其他问题，拿到当前机器后我抓到了明文密码：

![](../Images/81b324a9f00051209363a8f5f963ce3b.png)

但是通过此密码去利用 MSF 对 C 段进行密码喷洒发现没有一台主机被成功横向出来：

![](../Images/30381e6024fed8e86a1ca76a39da8506.png)

就在这个时候我又扫了一下看看有没有 MS17010：（一般来说向这种"某某网"基本上都有几台存在永恒之蓝，所以直接去扫就行）

![](../Images/4d1ad8dda9fcc6a8ee8c65ff193de5e6.png)

发现 92、151、200 这三台是存在 MS17010 的，随后打了 92 这台：

![](../Images/ca7dce5352195724230e45ab78fbd1ad.png)

随后 MSF 和 CS 联动，我把 MSF 的 shell 又弹到了 Cs，并且做了权限维持：

![](../Images/161f85a40a7662c22527d091ee5a31a0.png)

这个时候其实用这两台跳板机器就够了，另外两台存在 MS17010 没必要继续打，随后我对当前 C 段进行信息搜集，对 Web 资产进行扫描存活发现大量 Web 资产：

![](../Images/a098b4ae6f3ebb9ff434acfb3216b952.png)

通过手工分析发现一枚 SQL 注入，而且是 DBA 权限：

![](../Images/7a46665ccf49fc77e226c8bd4eedada0.png)

然后添加了一个管理员用户然后开启了 3389 （因为有诺顿，常规免杀没时间弄了，主要拿分，索性直接登录服务器）

而且直接通过 socks 连接不了，感觉是做了限制，后续发现使用 `mstsc /admin` 是可以登录的：

![](../Images/7f09597dd577085d1f9d194e8ded429d.png)

这个时候我用 92 这台机器当作跳板远程登录到 71 桌面：

![](../Images/0353451140aa5fd3ea0a162e5066b283.png)

随后克隆了 administrator 的桌面：

![](../Images/dc89ddfad5020e9e54b10872ffee2978.png)

此时重新登录之前添加的账号到远程桌面就是 administrator 的桌面了：

![](../Images/e1d265e2afc0709ff394f2a999241edc.png)

通过一系列的信息搜集并且翻密码，拿到了 Mssql 和所有旁站的权限：

![](../Images/0367f1b0db59cd75176b4270fd30881a.png)![](../Images/7fe50e0dd43e11c6095d90f49966bca6.png)

通过已搜集到的密码去对 C 段继续密码喷洒成功喷洒出 C 段的一台 Mssql：xxx.xxx.xxx.239

![](../Images/0c9c785c60b310433e8eaedaccbcacbb.png)

后续直接调用 XP\_cmdshell 执行命令，发现权限还很大：

![](../Images/a97ce21150ee37bc953eecccea95998e.png)

随后直接利用 bitsadmin 上线到 cs：

![](../Images/16f5cd6b1f9d7810f289c232b997194b.png)

此时已经拿到了：16、92、239 这三台机器的权限，但是还没有发现有内网，这个时候就陷入了瓶颈。

搞到这里发现横向不了，其他 Web 又不想用 0day 打，回过头来用 MS17010 打下了 200 这台：

![](../Images/5d5096d0acb7dae71afb5c94878de154.png)

随后通过同样的方式把 shell 弹到了 CS 并且添加了用户而且加入远程桌面组：

![](../Images/871ea92096ece74caa7fb6a89abfecaf.png)

随后登录发现登录失败：

![](../Images/9c749168e04b0377e8bfdb39a41e5ba5.png)

这个时候利用 `mstsc /admin` 可以绕过并成功登录到目标远程桌面：

![](../Images/33132978bf3769f921f691710566dc7e.png)

同样的方式克隆了 administrator 的桌面：

![](../Images/d9eddba264f348681cc779f380666acd.png)

通过信息搜集翻文件我发现了大量有价值的东西，比如 mstsc 登录记录：

![](../Images/54ae1f1f055787e9eadecabf4ad74dfd.png)

拿到 navicat 数据库凭证：

![](../Images/8c2346ef27bbf03f990223a81f57d4b2.png)

并且发现 Xshell 里面有很多台 SSH：

![](../Images/2674c5070f3f7cd3a7a8cdfe5f767e81.png)

里面所有 Linux 主机都可被登录，这个时候只需要利用 SharpDecryptPwd 把它们的密码抓下来就好，但是发现出问题了：

![](../Images/8979cb7ef90177614744ed209cf50dd3.png)

后面用这玩意查看了密码：（本来不想用这几把玩意的，太麻烦得一个个的去查看密码）

![](../Images/37aee361f55db08b89b6c4ae36d1f8c3.png)

发现有几台机器有 10 的内网：

![](../Images/75414c9328117910548406054d832908.png)

通过已有的密码再去横向喷洒了一下 C 段的 Linux 主机：

![](../Images/ff6300783a436a2a0cb558eb4dcf1517.png)

然后弹了几个 Shell 到 MSF：

![](../Images/e5282c2a6273e207b3517c63072a2241.png)

至此这个公网的 C 段基本上已经穿了，大量核心数据库、交换机、Web服务器都拿下，接下来就是对 10 的内网进行内网渗透。

## 来自第二层内网 10 段的内网渗透 

因为我已经拿到了 root 的密码，我直接扫了一下 10.10.10.1/16 的 B 段，有一大波资产，这里就不截图了，有几百个，其中发现有 ESXI：

![](../Images/777f592a673785076446c3627b57d8d9.png)

并且拿到了一个门禁系统：

![](../Images/3e66cb289591a6966a605ad48aede108.png)

通过特殊手段横向移动拿下了 10 段的两台 SSH，并且发现有第三层内网是 192 段、还有 docker 环境：

![](../Images/a168b016bbcb7d4e95f53a8a58dcc9ba.png)

![](../Images/2f5cff79b1145df598a5332e27478c4a.png)

由于 10 段有 ESXI ，我直接利用漏洞拿到了 ESXI 云平台，旗下所有机器都被控：

![](../Images/96f627a455ce6f692342adfca86bffa1.png)

此时 10 段基本上已经穿了，接下来就是对 192 的内网进行渗透。
