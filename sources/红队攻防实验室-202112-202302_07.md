## 登陆Mysql数据库，管理员账号 

但是 `configuration.php~` 这个文件泄露了 `mysql` 的数据库连接信息：

![](../Images/bc9648b1455deb8cf2e54f92b0bb0bb8.png)

如上图所示，我们得到了一个 `mysql` 的用户：

```


user：testuser 
```

用泄露的用户名和密码尝试登陆 `mysql`：

```


mysql -h192.168.93.100 -utestuser -p
```

![](../Images/d48872433f91b47c38e767f8954a9b56.png)

通过查询 `joomla` 数据库的 `am2zu_users` 表下的 `username`、`password` 字段内容发现 `administrator` 用户的密码是加密的，而且不知道是啥加密，估计是加盐了。有知道的大佬麻烦告诉我，我会很感激的！

https://github.com/FireFart/dirtycow/blob/master/dirty.c

## 内网横向渗透 

登陆成功！接下来通过 `MSF` 生成一个木马来得到一个 `shell` 进行后渗透：

![](../Images/da578395354c6bed9139382ad7170c5c.png)

图片

通过 `xshell` 我发现上传不了文件：

后来通过 `WinSCP` 工具才上传成功的！

![](../Images/65689db8b9bdec16b299c39bff89ce0a.png)

图片

给 `shell.elf` 文件`可执行`权限，然后运行后 `MSF` 反弹回来一个 `shell`：

![](../Images/5f063bcdea1041f0cfea5c93dfa0d227.png)

图片

![](../Images/2a2705ee3472914b9beee0b4d8e74dc6.png)

图片

之后先添加`路由表`扫描一下`内网存活`主机：

![](../Images/0ab1646073a18749b9f1b33a58693fa1.png)

图片

扫描存活主机使用的模块是这个：

![](../Images/4438ea5ec7340d0ab861d118c2b9fcb0.png)

图片

这个时候扫描出来发现内网存活了这些：

```


192.168.93.1
```

但是不知道它具体是什么操作系统，那么可以通过这个模块来对内网进行探测操作系统：

```
auxiliary/scanner/smb/smb_version
```

![](../Images/dddf9a5ff182f8dfe8e0ff8d7b7c48c5.png)

图片

扫描出来有三台主机，其实探测出来的和我们`NMAP`信息搜集出来的结果八九不离十，只不过是我们知道了靶机 `IP` 的情况下才探测出来操作系统，而现在是通过横向渗透才知道的：

```


[+] 192.168.93.20:445     - Host is running Windows 2008 Datacenter SP2 (build:6003) (name:WIN2008) (domain:TEST)
```

以上三台主机是有 `TEST域`的，说明他们在一个`域`里！我通过`MSF` 爆破 `Windows 2008` 这台主机的 `smb` 登陆凭证爆破成功：

![](../Images/fdf035ede4e74271ddb2abf07a194bbb.png)

图片

```


user：administrator
```

接着我先把它的流量代理出来，使用 `socks4` 代理：

```

auxiliary/server/socks4a
```

![](../Images/eab9bb93381b49d7eef1d037e80c938f.png)

图片

![](../Images/0e2b1b5bdcfd41839f836459921e020d.png)

图片

![](../Images/fefe8c693366d476c2217c846cf38ce6.png)

图片

设置完毕后，配置 `proxychains` 在 `/etc/proxychains.conf` 这个文件，在末尾吧端口更改为刚刚设置监听的 `1080` 端口：

```

socks4 	127.0.0.1 1080
```

![](../Images/e5ef1f7bb0e798faba49b150c0c76df1.png)

图片

为了验证我们是否代理流量成功，我扫了一下 `192.168.93.20`（Windows 2008）这台主机的端口开放情况：

```

proxychains nmap -T4 -P 80,1433,3306,3389 192.168.93.20
```

![](../Images/b4685e721055cbe70110cef4c7c3ce9c.png)

图片

扫描成功！这个时候就可以在扫它内网了！然后我本来想用 `Socks4`的，但是失败了不知道为啥，后面我又把它换成 `Socks5`：

![](../Images/60dcc3a993b7f24ce896a35729b21392.png)

图片

在扫它内网之前我需要吧 `KALI` 这台主机的流量给代理出来，下面我用到的 `socks5`代理，工具是 `SSF`:

```


Win10：ssfd.exe -p 1050
```

![](../Images/bc7174bc160193d2f4a04a1a78a145c5.png)

图片

![](../Images/58a4174dd3c377e756736e92c8c7cfe1.png)

图片

## 获取域控密码拿到Flag 

代理成功后我们通过 `wmiexec` 去连接 `windows 2008`：

```

wmiexec.exe administrator:123qwe!ASD@192.168.93.20
```

![](../Images/a4dd798bf3302995abfbb41450c8a0ce.png)

图片

![](../Images/4b788ff996fe08fabe4db25a8f927425.png)

图片

![](../Images/617239ef3324cce465167e1d4a2842c1.png)

图片

查看 `Windows 2008` 的 `ip` 后发现 `dns` 为 `test.org`，接着 `ping test.org` 获取到了域控制器的 `IP` ：

![](../Images/614aa3022f347d69cb5f1192c4da0788.png)

图片

这个时候尝试抓取 `test.org` 域里的 `administrator` 密码，先上传一个 `mimikatz` 到 `windows2008`：

![](../Images/87f993232e11e0ccd0554d27f279bf6b.png)

图片

之后本来想用 `mimikatz` 读取密码的，但是在 `dos` 下进入不了 `mimikatz` 的交互界面...还是太菜了！我接着 `MSF` 生成了一个木马得到了 `Windows 2008` 的`shell`，然后直接运行 `getsystem` 得到了 `SYSTEM` 权限 ：

![](../Images/fdb324573b0276dc7d6b43bc70baa7aa.png)

图片

然后上传了一个 `mimikatz` 直接读取到了明文密码：

![](../Images/308415c78e0adafc9d596d1bea4d7314.png)

图片

最后通过 `smb` 连接到了`2012`机器拿到 `flag`：

![](../Images/058055eb108e97cc308c57a0040d6257.png)

图片
