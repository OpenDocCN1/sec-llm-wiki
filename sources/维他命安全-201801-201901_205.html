Microsoft Exchange Server 内存破坏漏洞（CVE-2018-8302）

      


  首发日期: 2018年8月14日

   CVE ID：CVE-2018-8302

   漏洞等级：高危

   CNNVD ID：CNNVD-201808-413

   CNVD ID :CNVD-2018-15416

  


01

漏洞描述

       Microsoft Exchange Server 是微软开发的一款邮件服务器，本周二微软集中发布的8月份漏洞补丁中包含Microsoft Exchange Server 内存破坏漏洞（CVE-2018-8302）的补丁。

当Microsoft Exchange无法正确处理内存中的对象时，可导致远程代码执行。攻击者将精心构造的邮件发送给目标用户，成功利用此漏洞的攻击者可以系统用户权限执行任意代码；进行完成应用程序安装， 查看、更改、删除数据， 或创建新帐户等行为操作。

此漏洞来源于名为TopNWords.Data的收件箱目录属性，该数据存储在Exchange服务器上；用户可以通过 Exchange Web Services (EWS) 来对其进行更改。Exchange Web Services 是一组客户端与 Exchange 服务器通信的接口，在启用 Unified Messaging (UM) 后，收到语音邮件时，Exchange 服务器会读取TopNWords.Data配置，利用.NET BinaryFormatter对配置属性进行反序列化，尝试将语音转换为文字显示在收件人的收件箱中。如果TopNWords.Data的配置属性中包含恶意代码，其代码将被执行。


漏洞的利用需要满足以下两个条件：

       1. Exchange 服务器开启 Unified Messaging (UM) 功能（默认不开启）；

       2. 攻击者有一个已开启 UM 语音功能的邮箱账号。

02

影响范围

微软官方公告提供的受影响的版本如下：

  • Microsoft Exchange Server 2010 Service Pack 3 Update Rollup 23

  • Microsoft Exchange Server 2013 Cumulative Update 20

  • Microsoft Exchange Server 2013 Cumulative Update 21

  • Microsoft Exchange Server 2016 Cumulative Update 10

  • Microsoft Exchange Server 2016 Cumulative Update 9


注意：

以上软件版本为官方明确会受到影响的版本；未列出的软件版本，可能是因为不受漏洞影响，也可能是因为超出了微软的支持生命周期。

要确定软件版本的支持生命周期，请参阅Microsoft Support LifeCycle（https://support.microsoft.com/en-us/hub/4095338/microsoft-lifecycle-policy）。
