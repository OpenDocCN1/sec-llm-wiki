01

**安全厂商发布勒索软件趋势的分析报告，2017年比2016年增加415%**

![](../Images/1a7b9ea0ba441de5c9a8ebb313cd1e0e.png)

F-Secure的勒索软件趋势报告指出，2017年的勒索软件攻击比2016年增长415％，这些威胁来自于Locky、Cryptolocker和Cerber等勒索软件家族，但最频繁的威胁仍然是WannaCry：到年底每10个勒索软件检测报告中就有9个是关于WannaCry感染的。虽然到2017年年末勒索软件攻击正在下降，但也有证据表明勒索软件更侧重于针对企业的攻击。

   原文链接：

https://press.f-secure.com/2018/05/02/ransomware-gold-rush-looks-finished-but-threat-remains/

  

02

**研究团队发现朝鲜反病毒软件SiliVaccine包含恶意软件JAKU**

![](../Images/2f2b129f5bf696cc86a9c65c6450bed5.png)

Check Point的研究人员分析了朝鲜反病毒软件SiliVaccine的一个样本，发现SiliVaccine是基于日本趋势科技公司10年前开发的反恶意软件引擎。趋势科技证实SiliVaccine包含属于趋势科技的大量10多年前的防病毒引擎代码。研究人员还发现SiliVaccine将特定恶意软件的签名加入白名单，并且还捆绑了恶意软件JAKU。JAKU是一个感染了约1.9万个系统的僵尸网络，主要针对韩国和日本。

  原文链接：

https://research.checkpoint.com/silivaccine-a-look-inside-north-koreas-anti-virus/

  

03

**安全研究团队发现黑客团伙APT28劫持合法软件LoJack**

![](../Images/13a73461864049eb730e0f81801fdd71.png)

Arbor Networks的研究人员发现APT28劫持合法软件Lojack，受感染的LoJack app的二进制文件中包含微小的改动，将其代理指向恶意命令与控制（C&C）服务器。恶意Lojack样本的分发机制尚不清楚，但APT28通常使用网络钓鱼邮件感染目标系统。

  原文链接：

https://asert.arbornetworks.com/lojack-becomes-a-double-agent/

  

04

**研究人员发现潜伏8年的Linux内核提权漏洞（CVE 2018-8781）**

  

![](../Images/c14a89aa2282571c037a05cc00648df4.png)

Check Point的研究人员发现一个潜伏8年的Linux内核提权漏洞（CVE 2018-8781）。该漏洞存在于DisplayLink的驱动程序udl的fb\_helper文件定义的内部函数mmap()中，可导致本地特权提升。该漏洞于3月18日报告给Linux Kernel，并于3月21日发布了修复补丁。

  原文链接：

https://www.securityweek.com/privilege-escalation-bug-lurked-linux-kernel-8-years

  

05

**研究团队发现与AnyDesk捆绑的勒索软件新变体RANSOM\_BLACKHEART**

![](../Images/469cb3bc0353da68b061df0f0f8122a0.png)

趋势科技安全研究团队发现与合法远程桌面软件AnyDesk捆绑的勒索软件新变体RANSOM\_BLACKHEART.THDBCAH。RANSOM\_BLACKHEART感染系统的方式尚不明确，其会在加密的文件后附加.BlackRouter扩展名，勒索的赎金为50美元或0.006164比特币。研究人员认为与AnyDesk捆绑可能是一种逃避策略。

  原文链接：

https://blog.trendmicro.com/trendlabs-security-intelligence/legitimate-application-anydesk-bundled-with-new-ransomware-variant/

  

06

**施耐德电气发布安全更新，修复一个RCE漏洞（CVE-2018-8840）**

  

![](../Images/78518aaead5f1dd2825f3e022a1c4093.png)

Tenable Research的研究人员发现施耐德电气的两款工控相关产品-InduSoft Web Studio和InTouch Machine Edition-中存在严重的远程代码执行漏洞（CVE-2018-8840）。该漏洞可能导致工厂运营的中断或关闭。施耐德电气发布了InduSoft Web Studio v8.1 SP1和InTouch Machine Edition 2017 v8.1 SP1以修复此漏洞，建议用户尽快进行更新。

  原文链接：

https://threatpost.com/schneider-electric-patches-critical-rce-vulnerability/131610/
