**微软发布更多关于Intel CPU Spectre漏洞的微代码更新**

![](../Images/d78ffa22c8e910567d043f46900a1981.png)

微软发布更多关于Spectre漏洞的CPU微代码更新，将该漏洞的修复进一步扩展到Intel CPU的Broadwell和Haswell平台。此次更新包括KB4091666和KB4078407两个补丁包，均可从Microsoft Update Catalog门户网站手动下载。

   原文链接：

https://threatpost.com/microsoft-issues-more-spectre-updates-for-intel-cpus/131468/

  

02

**研究人员发现西数的My Cloud EX2 NAS设备存在安全漏洞，可导致文件泄露**

![](../Images/0107c2f1788847efd9b354ee7873345a.png)

Trustwave的研究人员发现西数的My Cloud EX2 NAS设备在默认情况下允许任何未经身份验证的本地网络用户通过HTTP请求获取设备上的文件，可导致文件泄露。其原因是该设备的UPnP媒体服务器在设备开机时默认自动启动，攻击者可向端口9000发出HTTP请求来获取设备上的文件。

  原文链接：

https://threatpost.com/western-digital-my-cloud-ex2-nas-device-leaks-files/131447/

  

03

**研究团队发现主要针对印度的新恶意软件GravityRAT**

![](../Images/f8f89f3a8f6ab1930e60a372554b2dde.png)

思科Talos研究团队发现新恶意软件GravityRAT。GravityRAT至少持续开发了约18个月，其开发者不断实现新的功能。在GravityRAT的整个生命周期内，研究人员都发现了文件渗透、远程代码执行和反虚拟机技术。印度的国家计算机应急响应小组（CERT）提供的一些信息表明GravityRAT被用于针对印度的APT攻击。

  原文链接：

https://blog.talosintelligence.com/2018/04/gravityrat-two-year-evolution-of-apt.html

  

04

**研究团队发布关于恶意软件工具包Rubella Macro Builder的分析报告**

  

![](../Images/e56f0d20a4f7742e52482190c36a1296.png)

FlashPoint研究团队发现在俄罗斯黑客论坛上越来越受欢迎的恶意软件工具包Rubella Macro Builder。该工具包相对较新，而且比较简单，但由于其价格低廉、速度快，并且可以击败基本的静态防病毒检测，其对网络犯罪分子具有很强的吸引力。

  原文链接：

https://www.flashpoint-intel.com/blog/rubella-macro-builder/

  

05

**研究团队发现主要针对巴西的恶意攻击活动Metamorfo**

![](../Images/8c9b70a8f388ec7293f6fff8a65e1521.png)

FireEye Labs研究团队发现主要针对巴西企业的malspam（包含恶意软件的垃圾邮件）活动。该活动被命名为Metamorfo，Metamorfo主要用于分发银行木马，其使用了多种策略和技术来逃避检测。研究人员在报告中剖析了该恶意活动的感染流程。

  原文链接：

https://www.fireeye.com/blog/threat-research/2018/04/metamorfo-campaign-targeting-brazilian-users.html

  

06

**研究人员发现加密货币Bezop的超过2.5万名持有者的个人信息泄露**

  

![](../Images/bc1ad946da1f11cd3b351feffbd01133.png)

Kromtech的研究人员发现一个可公开访问的MongoDB数据库，该数据库内包含超过2.5万名Bezop币持有者的个人信息。这些信息包括姓名、家庭住址、电子邮件地址、加密过的密码、钱包信息和扫描的护照、驾照或ID等信息。

  原文链接：

https://www.bleepingcomputer.com/news/security/exposed-mongodb-server-exposes-details-of-cryptocurrency-users/
