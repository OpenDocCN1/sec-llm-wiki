**泰国运营商TrueMove H的用户数据泄露，约4.6万用户受到影响**

![](../Images/51c40e6d9d9667b15deef4ad7c4a353b.png)

安全研究人员Niall Merrigan发现泰国最大的4G移动运营商TrueMove H的一个Amazon AWS S3可公开访问，泄露的数据包含用户的驾驶执照和护照等身份证件的扫描，数据总量为约4.6万条记录，共32GB。该数据库直到4月12日还可继续访问，随后该公司限制了其访问权限。TrueMove H声明称数据泄露事件影响的是其子公司I True Mart。

   原文链接：

https://securityaffairs.co/wordpress/71406/data-breach/truemove-h-data-leak.html

  

02

**安全厂商联合破坏恶意软件分发网络EITest的感染链**

![](../Images/a5863c3f10bcbdaec10dcfdff4b81684.png)

来自Abuse.ch、BrillantIT和Proofpoint的安全研究人员通过劫持恶意软件分发网络EITest的C&C流量，破坏了其感染链，阻止了每天超过200万次的重定向攻击。对这些流量的分析发现，EITest共感染了约5.2万台服务器，大部分是WordPress网站。目前，EITest的作者似乎已经放弃了试图重新控制该网络。

  原文链接：

https://www.bleepingcomputer.com/news/security/researchers-take-down-network-of-52-000-infected-servers-distributing-malware/

  

03

**研究人员演示可通过电力线窃取数据的恶意软件PowerHammer**

![](../Images/947fbbf6d343d0d6dbfe4848a40b6b78.png)

以色列本-古里安大学的研究团队演示可通过电力线窃取数据的PowerHammer技术。PowerHammer的原理是通过恶意软件故意改变CPU利用率，使计算机消耗更多或更少的电力，通过这种模式将二进制数据编码为功耗模式，再读取功耗变化并解码数据。实验表明，这种攻击对台式机、笔记本电脑、服务器甚至是IoT设备都起作用。

  原文链接：

https://www.bleepingcomputer.com/news/security/researchers-create-malware-that-steals-data-via-power-lines/

**研究团队披露NASA CFITSIO库中的多个远程代码执行漏洞**

  

![](../Images/e75d4f7f39d3e94f641d4a830fc613cd.png)

思科Talos研究团队在NASA的CFITSIO库中发现了多个远程代码执行漏洞（CVE-2018-3846、CVE-2018-3847、CVE-2018-3848和CVE-2018-3849）。CFITSIO是一个C语言和Fortran语言的库，用于以灵活图像传输系统（FITS）数据格式读取和写入文件。攻击者可通过恶意FIT图像文件触发栈溢出，导致任意代码执行。

  原文链接：

https://blog.talosintelligence.com/2018/04/vulnerability-spotlight-talos-2018-0529-531.html

  

05

**研究团队披露SDL2\_Image库中的多个安全漏洞，建议用户尽快更新**

![](../Images/f603a76fc6144cc24c6d5f4390240eb2.png)

思科Talos研究团队披露SDL2\_Image库中的多个安全漏洞。SDL多媒体库旨在通过OpenGL和Direct3D为音频、键盘、鼠标和图形硬件等提供底层访问，它支持Windows、Mac OS X、Linux、iOS和Android。漏洞包括信息泄漏漏洞（CVE-2018-3837和CVE-2018-3838）以及堆越界读导致的代码执行漏洞（CVE-2018-3839）。建议用户尽快更新至最新版本SDL 2.0.8。

  原文链接：

https://blog.talosintelligence.com/2018/04/simple-direct-media-layer-vulnerabilities.html

  

06

**Intel修复CPU SPI闪存中的安全漏洞（CVE-2017-5703）**

  

![](../Images/2e80208bac8935e4c2d0b288b831d059.png)

根据Lenovo工程师的描述，Intel CPU SPI闪存的配置可能导致攻击者阻止BIOS/UEFI更新，或者有选择性地擦除和破坏部分固件。Intel在4月3日修复了该漏洞（CVE-2017-5703），受影响的CPU系列包括5、6、7、8代酷睿处理器和多个至强、赛扬、奔腾、凌动等型号。

  原文链接：

https://www.bleepingcomputer.com/news/security/intel-spi-flash-flaw-lets-attackers-alter-or-delete-bios-uefi-firmware/
