# 维他命安全周报2018年第13周

 本周安全态势综述

 

  

2018年03月26日至30日共收录安全漏洞56个，值得关注的是Cisco IOS Software和IOS XE Software缓冲区溢出漏洞；Trend Micro Smart Protection Server命令注入漏洞；ISC DHCP CVE-2018-5732缓冲区溢出漏洞；Intel Software Guard Extension本地权限提升漏洞；Apache Syncope XSLT多个远程代码执行漏洞。

  

本周值得关注的网络安全事件是研究人员发现Facebook收集部分用户的电话和短信等数据；僵尸网络Hajime卷土重来，3天内扫描MikroTik路由器超过86万次；安全团队发现新Android恶意矿工HiddenMiner可导致设备故障；研究团队发布关于恶意软件QuantLoader的分析报告；研究人员发现多个VPN供应商因WebRTC漏洞导致用户IP泄露。

  

根据以上综述，本周安全威胁为**中**。

  

  

重要安全漏洞列表

 

**1.Cisco IOS Software和IOS XE Software缓冲区溢出漏洞**

  

Cisco IOS Software和Cisco IOS XE Software Smart Install功能存在缓冲区溢出漏洞，允许远程攻击者利用漏洞提交特殊的请求，使系统崩溃或可执行任意代码。

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180328-smi

  

**2.Trend Micro Smart Protection Server命令注入漏洞**

  

Trend Micro Smart Protection Server登录凭证处理存在安全漏洞，允许远程攻击者可以利用漏洞提交特殊的请求，绕过安全限制，执行任意命令。

https://success.trendmicro.com/solution/1119385

  

**3.ISC DHCP CVE-2018-5732缓冲区溢出漏洞**

  

ISC DHCP处理请求存在缓冲区溢出漏洞，允许远程攻击者利用漏洞提交特殊的请求，使应用程序崩溃。

https://kb.isc.org/article/AA-01565/75/CVE-2018-5732

  

**4.Intel Software Guard Extension本地权限提升漏洞**

  

Intel Software Guard Extension存在安全漏洞，允许本地攻击者利用漏洞提交特殊的请求，提升权限。

https://security-center.intel.com/advisory.aspx?intelid=INTEL-SA-00117&languageid=en-fr

  

**5.Apache Syncope XSLT多个远程代码执行漏洞**

  

Apache Syncope XSLT处理存在安全漏洞，允许远程攻击者可以利用漏洞提交特殊的请求，进行文件读写和执行代码。

http://syncope.apache.org/security.html#CVE-2018-1321:\_Remote\_code\_execution\_by\_administrators\_with\_report\_and\_template\_entitlements

  

  

 重要安全事件综述

 

**1.研究人员发现Facebook收集部分用户的电话和短信等数据**

  

![](../Images/877721c10b69696a2abe6a97a99dfdbd.png)

部分Facebook用户下载了他们的数据档案后发现，Facebook一直在收集他们的联系人、短信和通话记录数据，包括呼入呼出的完整记录和SMS短信，但不包括短信的实际内容。早前Android安全专家Simone Margaritelli曾报告过这个问题，但当时并没有引起太多关注。Apple用户没有受到影响。

  

  

原文链接：  

https://www.bleepingcomputer.com/news/technology/facebook-collected-call-and-sms-metadata-from-some-users-smartphones/

  

  

**2、僵尸网络Hajime卷土重来，3天内扫描MikroTik路由器超过86万次**

![](../Images/e8c3a8c74b2e6bc129662567786177c7.png)

IoT僵尸网络Hajime从3月25日开始针对MikroTik路由器进行大规模的扫描活动，研究人员称Hajime在过去3天内共完成了超过86万次扫描。攻击者试图利用MikroTik RouterOS固件6.38.4及更早版本中的Chimay Red漏洞，以执行代码和接管设备。针对该漏洞的MikroTik固件更新已经发布了约一年的时间。

  

原文链接：  

https://www.bleepingcomputer.com/news/security/hajime-botnet-makes-a-comeback-with-massive-scan-for-mikrotik-routers/

  

**3、安全团队发现新Android恶意矿工HiddenMiner可导致设备故障**

![](../Images/826d526c72fb6a7b7a51f27094902958.png)

趋势科技安全团队发现新Android恶意软件HiddenMiner。HiddenMiner使用设备的CPU来挖取门罗币，由于其代码中没有开关、控制器和优化器，感染了HiddenMiner的设备将持续挖矿直到资源耗尽。因此，HiddenMiner可能会导致被感染的设备过热及发生故障。研究人员发现HiddenMiner存在于第三方应用市场，目前其主要针对印度和中国。

  

原文链接：  

https://blog.trendmicro.com/trendlabs-security-intelligence/monero-mining-hiddenminer-android-malware-can-potentially-cause-device-failure/

  

  

**4、研究团队发布关于恶意软件QuantLoader的分析报告**

![](../Images/3fcd6ae55c39611c926df40630b5433f.png)

QuantLoader是一个木马下载程序，它被广泛用于各种恶意软件活动，包括勒索软件、银行木马和RAT。Malwarebytes Labs研究团队分析了QuantLoader的一个新变体，该变体的有效荷载是一个后门程序。恶意活动从钓鱼邮件开始，邮件中包含一个JS下载程序的链接，攻击人员选择使用file：//（SMB）协议而不是传统的http：//协议。研究人员主要分析了该恶意软件的执行方式及网络功能。

  

原文链接：

https://blog.malwarebytes.com/threat-analysis/2018/03/an-in-depth-malware-analysis-of-quantloader/

  

  

**5、研究人员发现多个VPN供应商因WebRTC漏洞导致用户IP泄露**

![](../Images/ab12f634e80dc7c4b94dca0cddc6b664.png)

安全研究人员Paolo Stagno审计了83个VPN应用程序，发现在通过浏览器浏览网页时，有17个VPN客户端泄露了用户的IP地址，占比约20%。该泄露是由一个已知的WebRTC漏洞（2015年1月发现）导致的，但目前大多数浏览器默认启用了WebRTC。受影响的VPN供应商列表请参考以下链接。

  

原文链接：

https://www.bleepingcomputer.com/news/security/many-vpn-providers-leak-customers-ip-address-via-webrtc-bug/
