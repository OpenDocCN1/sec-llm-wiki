Cisco Smart Install远程代码执行漏洞

(CVE-2018-0171)

01

漏洞描述




Critical

超危




国际漏洞编号：CVE-2018-0171 

国内漏洞编号：CNVD-2018-06774、CNNVD-2018-201803-0139

首次发布时间: 2018.03.28 16:00 GMT

最新更新时间: 2018.03.29 17:13 GMT

CVSS Score:    Base 9.8

公告 ID: cisco-sa-20180328-smi2

Cisco Bug IDs:  CSCvg76186


Cisco IOS是多数Cisco系统路由器和网络交换机上使用的互联网络操作系统。


Cisco IOS、IOS XE软件Smart Install客户端中存在缓冲区堆栈溢出漏洞（CVE-2018-0171），该漏洞是由于对分组数据验证不当造成的。未经身份验证的远程攻击者，可以通过构造恶意Small Install消息包，向受影响设备的TCP 4786端口发送该数据包，重载目标设备，造成设备拒绝服务（DoS）或允许远程代码执行。


据悉，4786端口默认打开，该漏洞PoC已经被公开，思科已发布针对该漏洞的相关更新，建议相关用户尽快更新升级。


02

影响范围

该漏洞仅影响：运行了Cisco IOS/IOS EX受影响版本软件，且为Smart Install Client模式的设备。未开启Cisco Smart Install，或被设置为Smart Install Director模式的设备不在影响之列。

03

检测方法

1. 确认设备是否为Smart Install Client 模式

    在EXEC指令中输入：“show vstack config ”，若返回结果为“Oper Mode: Enabled Role: Client”或“Role: Client (SmartInstall enabled) ”，则表示设备为Smart Install Client模式。

2.确认设备版本

    管理员用户可以登录到设备，在CLI中输入“show version”。来查询设备版本，利用该版本信息，用户可以在Cisco官方确认是否受漏洞影响。

3.通过Cisco IOS Software Checker，确认设备是否受漏洞影响

    在工具中输入设备版本信息，即可查询（https://tools.cisco.com/security/center/softwarechecker.x）


04

解决方案

Cisco官方已经发布了更新补丁，目前该漏洞的PoC已被公布，建议相关用户尽快更新升级。

Cisco QoS远程代码执行漏洞

(CVE-2018-0151)

01

漏洞描述




Critical

超危




国际漏洞编号：CVE-2018-0151 

国内漏洞编号：CNVD-2018-06854、CNNVD-2018-201803-0138

首次发布时间: 2018.03.28 16:00 GMT

CVSS Score:    Base 9.8

公告 ID:  cisco-sa-20180328-qos

Cisco Bug IDs:  CSCvf73881

Cisco IOS是多数Cisco系统路由器和网络交换机上使用的互联网络操作系统。


Cisco IOS、IOS XE系统的QoS子系统中存在缓冲区堆栈溢出漏洞（CVE-2018-0151），允许未经身份验证的远程攻击者造成设备拒绝服务（DoS）或实现权限提升执行任意代码。


该漏洞是由于受影响设备，对到达其UDP 18999端口的数据包中某些值的边界检查不当造成的。攻击者可通过向受影响设备发送恶意构造的数据包来利用漏洞，受影响设备在处理数据包时可能发生缓冲区溢出，导致设备重载。恶意数据包必须指向受影响的设备并由该设备进行处理，通过设备传输的流量不会触发该漏洞。


思科已发布针对该漏洞的相关更新，建议相关用户尽快更新升级。


02

影响版本

该漏洞影响所有运行了Cisco IOS/IOS EX受影响版本软件的设备。


 不受影响版本：Cisco IOS XR Software or Cisco NX-OS Software


03

检测方法

1. 确认设备是否开启了UDP 

    管理员用户可以登录到设备，在CLI中输入“show udp”，如果输出与以下结果类似，则设备很可能受影响。

    若18999为监听端口，则务必通过第3步进行确认。

2. 确认设备版本

    管理员用户可以登录到设备，在CLI中输入“show version”。来查询设备版本，利用该版本信息，用户可以在Cisco官方确认是否受漏洞影响。

 3. 通过Cisco IOS Software Checker，确认设备是否受漏洞影响

    在工具中输入设备版本信息，即可查询（https://tools.cisco.com/security/center/softwarechecker.x）


04

解决方案

Cisco官方已经发布了更新补丁，建议相关用户尽快更新升级。
