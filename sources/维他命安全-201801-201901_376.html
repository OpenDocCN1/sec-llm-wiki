Windows内核提权漏洞预警

(CVE-2018-1038)


【维他命每日安全简讯】2018.03.27期发布资讯：

      瑞典安全专家Ulf Frisk发现微软的Meltdown补丁意外地导致了另一个安全漏洞，该补丁修改了对内核内存的访问权限，导致用户应用程序可访问内核内存。该问题只影响Windows 7和Windows Server 2008 R2的64位版本，微软在本周的周二安全更新中修复了这个bug。


01

漏洞描述



高危





国际漏洞编号：CVE-2018-1038 

国内漏洞编号：CNNVD-2018-04-001

首次发布时间: 2018.03.29 

CVSS Score: Temporal 7

Article ID：4100480


微软发布的Windows7 x64和Windows Server 2008 R2 Meltdown安全补丁中，Windows内核处理内存对象不当，将PML4权限设定成用户级，导致用户态进程可对系统内核进行任意读写操作。利用该漏洞攻击者可实现在内核模式下任意代码执行，包括安装程序、查看、更改或删除数据；或者创建具有完全用户权限的新帐户。



02

影响范围

Windows7 x64 
Windows Server 2008 R2 x64 

03

修复建议

1、打开Windows Update功能，点击“检查更新”，下载安装相关安全补丁。


2、或者直接更新补丁，补丁链接：http://www.catalog.update.microsoft.com/Search.aspx?q=KB4100480，根据系统版本进行安装。


建议：

更新补丁前做好相关系统备份，防止意外事故发生。
