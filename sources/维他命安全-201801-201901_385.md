# 维他命安全周报2018年第12周

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247483884&idx=2&sn=3f4516d9cc6c11e4c30959ed896452e9&chksm=f9024b7dce75c26b692ada71ddc3932bc4274157a0485e062bec2576d4c8dfd239748ab8ef8c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247483884&idx=2&sn=3f4516d9cc6c11e4c30959ed896452e9&chksm=f9024b7dce75c26b692ada71ddc3932bc4274157a0485e062bec2576d4c8dfd239748ab8ef8c&scene=27#wechat_redirect)

  

 本周安全态势综述

 

  

2018年03月19日至23日共收录安全漏洞74个，值得关注的是Huawei eSpace远程代码执行漏洞；Joomla! Core SQL注入漏洞；Adobe Dreamweaver CC OS命令注入漏洞；Intel Software Guard Extensions Platform Software Component权限提升漏洞；Mozilla Firefox处理vorbis音频数据远程代码执行漏洞。

  

本周值得关注的网络安全事件是波兰执法部门逮捕勒索软件Polski、Vortex和Flotera的作者；Facebook发生大规模数据泄露事件，超过5000万用户或“被助选”；Frost Bank遭到黑客入侵，其系统中存储的支票图片泄露；在线旅行社Orbitz遭到黑客入侵，约88万用户的数据泄露；波多黎各电力管理局遭到黑客入侵，客户数据未泄露。

  

根据以上综述，本周安全威胁为**中**。

  

  

重要安全漏洞列表

 

**1.Huawei eSpace远程代码执行漏洞**

  

Huawei eSpace多个设备Import Signal Tone函数存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，可执行任意代码。

http://www.huawei.com/en/psirt/security-advisories/2018/huawei-sa-20180131-01-espace-en

  

**2.Joomla! Core SQL注入漏洞**

  

Joomla! Core对SQL语句内的变量缺少类型转换，允许远程攻击者可以利用漏洞提交特殊的SQL请求，操作数据库，可获取敏感信息或执行任意代码。

https://developer.joomla.org/security-centre.html

  

**3.Adobe Dreamweaver CC OS命令注入漏洞**

  

Adobe Dreamweaver CC存在输入验证漏洞，允许远程攻击者利用漏洞提交特殊的请求，注入任意OS命令并执行。

https://helpx.adobe.com/security/products/dreamweaver/apsb18-07.html

  

**4.Intel Software Guard Extensions Platform Software Component权限提升漏洞**

  

Intel Software Guard Extensions Platform Software Component存在安全漏洞，允许本地攻击者可以利用漏洞提交特殊的请求，提升权限。

https://security-center.intel.com/advisory.aspx?intelid=INTEL-SA-00117&languageid=en-fr

  

**5.Mozilla Firefox处理vorbis音频数据远程代码执行漏洞**

  

Mozilla Firefox处理vorbis音频数据存在越界写漏洞，允许远程攻击者利用漏洞构建特殊的WEB页，诱使用户解析，可执行任意代码。

https://www.mozilla.org/en-US/security/advisories/mfsa2018-08

  

  

 重要安全事件综述

 

**1.波兰执法部门逮捕勒索软件Polski、Vortex和Flotera的作者**

  

![](../Images/719bde7fa515670240c0927a6632a385.png)

上周五波兰执法部门宣布逮捕勒索软件Polski、Vortex和Flotera的作者Tomasz T.。当局从Tomasz的笔记本电脑和远程服务器中恢复了数据，包括加密密钥等。波兰警方正在鼓励勒索软件Polski、Vortex和Flotera的受害者向地方当局提交正式申请，以便获取其解密密钥。警方称Tomasz通过勒索软件感染了数千名用户，并获得了超过14.5万美元的赎金。

  

原文链接：  

https://www.bleepingcomputer.com/news/security/author-of-polski-vortex-and-flotera-ransomware-families-arrested-in-poland/

  

  

**2、Facebook发生大规模数据泄露事件，超过5000万用户或“被助选”**

![](../Images/13fc4cac516cd59f21ac6cf35d050a3d.png)

Facebook在周末的报告中证实，在2016年的美国大选期间剑桥分析公司非法盗取了超过5000万Facebook用户的信息为特朗普助选。报告指出剑桥大学心理学讲师Dr. Aleksandr Kogan以学术研究为名，通过thisisyourdigitallife在线调查程序收集用户的数据，这些数据随后被特朗普雇佣的剑桥分析公司在美国大选中利用。

  

原文链接：  

https://www.bleepingcomputer.com/news/technology/facebook-confirms-gross-misuse-of-user-data-for-us-election/

  

**3、Frost Bank遭到黑客入侵，其系统中存储的支票图片泄露**

![](../Images/58898353ffe1ae605b64f9d16f094002.png)

上周五Frost Bank发布声明称其于2018年3月检测到对第三方密码箱软件的未授权访问，系统中以电子图像方式存储的支票图片泄露，攻击者可能会利用它们伪造相关支票。该银行是Cullen/Frost Bankers, Inc.的子公司，执法机构正在调查此案。

  

原文链接：  

http://securityaffairs.co/wordpress/70468/data-breach/frost-bank-security-breach.html

  

  

**4、在线旅行社Orbitz遭到黑客入侵，约88万用户的数据泄露**

![](../Images/863b3122ef85992a2fe2a8c9b2392a9d.png)

芝加哥在线旅游预订公司Expedia的子公司Orbitz宣称其一个旧网站遭到黑客入侵，约88万用户的支付信息泄露。数据泄露可能发生在2016年10月至2017年10月之间，黑客可能访问了存储在平台上的银行卡信息以及用户的姓名、地址、出生日期、电话号码、电子邮件和性别等个人信息。

  

原文链接：

https://thehackernews.com/2018/03/expedia-data-breach.html

  

  

**5、波多黎各电力管理局遭到黑客入侵，客户数据未泄露**

![](../Images/5756032bf0a73246e43e5aaa5d934fcf.png)

根据路透社的报道，波多黎各电力管理局（PREPA）证实其在上周末遭到黑客入侵。PREPA执行董事Justo Gonzalez Torres表示，PREPA的客户服务系统并没有遭到入侵，因此客户的信息没有泄露风险，目前调查正在进行中。

  

原文链接：

http://securityaffairs.co/wordpress/70534/hacking/prepa-power-utility-hacked.html
