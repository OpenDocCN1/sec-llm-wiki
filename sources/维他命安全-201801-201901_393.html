 本周安全态势综述


2018年03月12日至16日共收录安全漏洞85个，值得关注的是Microsoft Windows CredSSP协议远程代码执行漏洞；Microsoft ChakraCore脚本引擎CVE-2018-0925内存破坏漏洞；ManageEngine Applications Manager CVE-2018-7890远程代码执行漏洞；NTP decodearr函数缓冲区溢出漏洞；F5 BIG-IP ASM远程拒绝服务漏洞。


本周值得关注的网络安全事件是俄罗斯犯罪团伙从罗马尼亚Raiffeisen银行ATM上偷走86万欧元；研究团队发现针对Redis、Windows服务器和Apache Solr的攻击活动；研究机构发现针对中东地区的攻击活动与MuddyWater相关；研究人员发现通过耳机从PC窃取数据的MOSQUITO攻击；美国能源公司因数据安全事件被罚款270万美元。


根据以上综述，本周安全威胁为中。



重要安全漏洞列表

1.Microsoft Windows CredSSP协议远程代码执行漏洞


Microsoft Windows CredSSP协议在实现上存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，接替用户凭证，以系统上下文执行任意代码。

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0886


2.Microsoft ChakraCore脚本引擎CVE-2018-0925内存破坏漏洞


ChakraCore在处理内存对象存在安全漏洞，远程攻击者利用漏洞提交特殊的WEB页，诱使用户解析，可使应用程序崩溃或执行任意代码。

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0925


3.ManageEngine Applications Manager CVE-2018-7890远程代码执行漏洞


Zoho ManageEngine Applications Manager存在安全漏洞，远程程攻击者利用漏洞可以提交特殊的请求，以应用程序上下文执行任意代码。

https://github.com/rapid7/metasploit-framework/pull/9684


4.NTP decodearr函数缓冲区溢出漏洞


NTP decodearr函数存在缓冲区溢出漏洞，允许远程攻击者利用漏洞提交特殊的请求，可使应用程序崩溃或执行任意代码。

http://support.ntp.org/bin/view/Main/SecurityNotice#February_2018_ntp_4_2_8p11_NTP_S


5.F5 BIG-IP ASM远程拒绝服务漏洞


F5 BIG-IP ASM处理未公开的数据类型存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，可使应用程序崩溃。

https://support.f5.com/csp/article/K38243073



 重要安全事件综述

1.俄罗斯犯罪团伙从罗马尼亚Raiffeisen银行ATM上偷走86万欧元


俄罗斯犯罪团伙在2016年的一个晚上，利用被感染的RTF文件从属于罗马尼亚Raiffeisen银行的32台ATM机上偷走了大约86万欧元，该团伙于2016年8月9日至2016年9月4日期间对罗马尼亚Raiffeisen银行发起了鱼叉式网络钓鱼攻击，他们使用武器化的RTF文件发送电子邮件。最终控制银行的整个网络。


原文链接：

http://securityaffairs.co/wordpress/70046/cyber-crime/raiffeisen-cyber-heist.html



2、研究团队发现针对Redis、Windows服务器和Apache Solr的攻击活动

研究团队发现两个非常活跃的攻击活动，一个是RedisWannaMine，网络犯罪分子通过大量的互联网扫描来查找运行旧的Redis版本的系统，从而危及服务器的安全，不仅针对Redis服务器，还针对暴露SMB端口的Windows服务器。另一个是未修复CVE-2017-12629漏洞的Apache Solr服务器的攻击活动。这些攻击的最终目的是要在服务器上安装挖矿软件。


原文链接：

https://www.bleepingcomputer.com/news/security/coinminer-campaigns-target-redis-apache-solr-and-windows-servers/


3、研究机构发现针对中东地区的攻击活动与MuddyWater相关


我们发现了一项新的针对土耳其、巴基斯坦和塔吉克斯坦的组织的新活动，与先前发起的一项名为MuddyWater的活动有某些相似之处，该活动袭击了若干国家的多个行业，主要是中东和中亚。鉴于相似点的数量，我们可以假设这些新攻击与MuddyWater运动之间存在关联。这也意味着攻击者不仅对一次性活动感兴趣，而且可能会继续对目标国家和行业进行网络间谍活动。


原文链接：

https://blog.trendmicro.com/trendlabs-security-intelligence/campaign-possibly-connected-muddywater-surfaces-middle-east-central-asia/



4、研究人员发现通过耳机从PC窃取数据的MOSQUITO攻击

来自以色列内盖夫本古里安大学的研究人员今天详细介绍了一种使用扬声器从气隙式计算机提取数据的新方法。这种攻击现在只是实验性的，并没有在现实世界中看到，但已被证明是可行的，研究人员还创建了一个用于在两台计算机之间传输数据的自定义协议，一个空隙式和一个互联网连接，可以进一步转发数据。这种攻击命名为MOSQUITO，可能是因为一种称为“插孔重新分配”的技术，可以将输出音频插孔反向输入插孔，从而将扬声器有效地转换为（非传统）麦克风。


原文链接：

https://www.bleepingcomputer.com/news/security/data-exfiltration-technique-steals-data-from-pcs-using-speakers-headphones/



5、美国能源公司因数据安全事件被罚款270万美元

美国一家能源公司因数据安全事件被罚款270万美元，导致重要的网络资产曝光。北美电力可靠性委员会（NERC）上个月透露，一家未命名的电力公司已同意支付巨额罚款并采取行动以避免再次发生类似事件。NERC发布的罚款通知提供了有关该事件的一些细节，并澄清说，虽然能源公司同意支付罚款，但既不承认也不否认违反关键基础设施保护（CIP）NERC可靠性标准。事件的风险评级为“严重”，涉及第三方承包商不正确地将数据从能源公司复制到自己的网络。尽管接受了培训，但承包商未能遵守公司的信息保护计划。


原文链接：

https://www.securityweek.com/us-energy-firm-fined-27-million-over-data-security-incident
