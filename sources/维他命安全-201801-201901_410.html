 本周安全态势综述


2018年02月26日至03月02日共收录安全漏洞71个，值得关注的是Exim 'base64d()'函数缓冲区溢出漏洞；Apache Thrift远程命令注入漏洞；Pelco Sarix Pro system.download.sd_file命令执行漏洞；Microsoft SharePoint Server CVE-2018-0869远程权限提升漏洞；Microsoft Excel CVE-2018-0841远程代码执行漏洞。




本周值得关注的网络安全事件是研究人员演示通过枚举方式查看PayPal账户的余额和近期交易；以色列移动取证公司Cellebrite声称可解锁任意型号的iPhone；研究人员发现利用Adobe Flash Player安全漏洞的大规模垃圾邮件活动；研究人员发现Memcached服务器可能会被滥用于大规模的DDoS攻击；研究人员发现700多个网站感染恶意软件ionCube。


根据以上综述，本周安全威胁为中。



重要安全漏洞列表

1.Exim 'base64d()'函数缓冲区溢出漏洞


Exim 'base64d()'函数存在缓冲区溢出，允许远程攻击者利用漏洞提交特殊的请求，可使应用程序崩溃或执行任意代码。

https://git.exim.org/exim.git/commit/cf3cd306062a08969c41a1cdd32c6855f1abecf1


2.Apache Thrift远程命令注入漏洞


Apache Thrift存在安全漏洞，允许本地攻击者利用漏洞提交特殊的请求，可以应用程序上下文执行任意代码。

https://issues.apache.org/jira/browse/THRIFT-3893


3.Pelco Sarix Pro system.download.sd_file命令执行漏洞


Pelco Sarix Pro /login/bin/set_param程序对system.create.sd_file_link参数处理存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，可执行任意命令。

https://www.pelco.com/search?documentUUID=e88d9bca-0062-4f85-8f4165982d304c69&title=Sarix%20Professional%20-%20Firmware%20Release%20Notes%20v3.29.67#tab/documents


4.Microsoft SharePoint Server CVE-2018-0869远程权限提升漏洞


Microsoft SharePoint Server处理WEB请求存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，可以高权限执行任意代码。

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0869


5.Microsoft Excel CVE-2018-0841远程代码执行漏洞


Microsoft Excel处理特殊的文件存在安全漏洞，允许远程攻击者利用漏洞提交特殊的EXCEL文件，诱使用户解析，可执行任意代码。

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0841




 重要安全事件综述

1.研究人员演示通过枚举方式查看PayPal账户的余额和近期交易


研究人员称该攻击方式的先决条件是攻击者已知目标PayPal账户相关联的电子邮件地址和电话号码。攻击者首先可以通过PayPal的忘记密码功能获取到该账户的支付方式（如信用卡或银行卡）的最后2位数字，然后通过PayPal的交互式语音响应系统，以每次电话只枚举一次最后四位数字的方式，最终获取正确的最后4位数字，从而可以查询当前的账户余额和近期的交易记录。


原文链接：

http://securityaffairs.co/wordpress/69502/hacking/paypal-data-disclosure.html



2、以色列移动取证公司Cellebrite声称可解锁任意型号的iPhone

据福布斯报道，以色列移动取证公司Cellebrite是美国执法机构的主要安全承包商，其声称具有一款新的黑客工具，可以解锁运行iOS 11及更早版本的所有iPhone，包括最新的iPhone 8和iPhone X。除了Apple设备之外，Cellebrite还可以解锁Android系统的智能手机，如三星、Nexus、HTC和华为等。


原文链接：

https://thehackernews.com/2018/02/unlock-iphone-software.html




3、研究人员发现利用Adobe Flash Player安全漏洞的大规模垃圾邮件活动


安全公司Morphisec称，网络犯罪分子正在利用本月早些时候由Adobe修复的Flash Player安全漏洞（CVE-2018-4878）进行大规模的垃圾邮件分发活动。当目标用户打开邮件中的恶意附件Word文档时，攻击者可利用该漏洞获取其系统的控制权。该漏洞于1月31日被发现，影响了Windows 10、macOS、Linux和Chrome操作系统上运行的Adobe Flash Player。


原文链接：

https://threatpost.com/massive-malspam-campaign-targets-unpatched-systems/130136/



4、研究人员发现Memcached服务器可能会被滥用于大规模的DDoS攻击

本周二Akamai、Arbor Networks和Cloudflare报告称，在过去两天内使用由Memcached服务器放大的UDP数据包的DDoS攻击有所增加。当攻击者伪造目标的IP地址向Memcached服务器发送请求时，作为响应，Memcached服务器会向目标IP发送大量不成比例的响应，从而构成反射攻击和放大攻击。这种放大倍数最大可达51200倍。据估计，超过88000个配置错误的开放式Memcached服务器易被滥用，北美和欧洲最多。防护措施包括将Memcached服务器配置为在防火墙之后运行并关闭对UDP的支持


原文链接：

https://threatpost.com/misconfigured-memcached-servers-abused-to-amplify-ddos-attacks/130150/



5、研究人员发现700多个网站感染恶意软件ionCube

SiteLock公司的安全研究人员发现数以百计的基于WordPress，Joomla和CodeIgniter的网站感染ionCube恶意软件。ionCube是一种编码技术，用于保护PHP软件免于在未经许可的计算机上查看、更改和运行。SiteLock研究团队分析感染的网站发现了一些可疑的混淆文件，这些文件与合法的ionCube编码文件几乎完全相同。


原文链接：

http://securityaffairs.co/wordpress/69672/breaking-news/ioncube-malware.html
