 本周安全态势综述


2018年02月19日至23日共收录安全漏洞65个，值得关注的是eQ-3 AG Homematic CCU2 TCL script interpreter代码执行漏洞；Quagga BGP后台程序UPDATE消息两次释放漏洞；LinuxVNC VNConsole.c vcSetXCutTextProc()整数溢出漏洞；strongSwan rsa_pss_params_parse拒绝服务漏洞；Nortek Linear eMerge E3 series命令注入漏洞。




本周值得关注的网络安全事件是研究人员发现利用Oracle WebLogic Server漏洞进行挖矿的活动；研究机构发布2017年年终报告，Android勒索软件数量有所下降；研究人员发现Anchor CMS漏洞，可导致数据库密码泄露；Apple发布安全更新，修复iOS中的印度字符崩溃问题；研究团队发布APT组织Tempting Cedar Spyware的分析报告。


根据以上综述，本周安全威胁为中。



重要安全漏洞列表

1.eQ-3 AG Homematic CCU2 TCL script interpreter代码执行漏洞


eQ-3 AG Homematic CCU2 TCL script interpreter存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，执行任意代码。

http://atomic111.github.io/article/homematic-ccu2-remote-code-execution


2.Quagga BGP后台程序UPDATE消息两次释放漏洞


Quagga BGP后台程序处理UPDATE 消息存在两次释放漏洞，允许远程攻击者利用漏洞提交特殊的请求，进行拒绝服务攻击或可执行任意代码。

https://gogs.quagga.net/Quagga/quagga/src/master/doc/security/Quagga-2018-5379.txt


3.LinuxVNC VNConsole.c vcSetXCutTextProc()整数溢出漏洞


LinuxVNC VNConsole.c vcSetXCutTextProc()存在整数溢出漏洞，允许远程攻击者利用漏洞提交特殊的请求，执行任意代码。

https://github.com/LibVNC/vncterm/issues/6


4.strongSwan rsa_pss_params_parse拒绝服务漏洞


strongSwan libstrongswan/credentials/keys/signature_params.c rsa_pss_params_parse函数存在安全漏洞，允许远程攻击者利用漏洞提交特殊的RSASSA-PSS签名，进行拒绝服务攻击。

https://www.strongswan.org/blog/2018/02/19/strongswan-vulnerability-%28cve-2018-6459%29.html


5.Nortek Linear eMerge E3 series命令注入漏洞


Nortek Linear eMerge E3 series存在命令注入漏洞，允许远程攻击者利用漏洞提交特殊的请求，执行任意代码。

https://www.nortekcontrol.com



 重要安全事件综述

1.研究人员发现利用Oracle WebLogic Server漏洞进行挖矿的活动


FireEye报告称攻击者正在利用Oracle WebLogic Server中最近修复的漏洞（CVE-2017-10271）来感染目标系统并进行挖矿。该漏洞存在于Oracle WebLogic Server 12.2.1.2.0及之前的版本中，于2017年10月的Oracle重要补丁更新中修复。研究人员发现位于多个地区（包括美国、澳大利亚、中国香港、英国、印度、马来西亚和西班牙）的几乎所有垂直行业的组织都受到这种攻击活动的影响。


原文链接：

https://www.securityweek.com/oracle-weblogic-server-flaw-exploited-deliver-crypto-miners



2、研究机构发布2017年年终报告，Android勒索软件数量有所下降

根据ESET发布的年终报告，2017年Android设备上的勒索软件感染数量下降。Android勒索软件感染数量于2016年4月达到顶峰，随后一直在下降。尽管存在这种下降，2017年整体的恶意软件感染数量创下新高。研究人员还未能确定这种下降趋势的具体原因。


原文链接：

https://www.bleepingcomputer.com/news/security/android-ransomware-numbers-went-down-in-2017/




3、研究人员发现Anchor CMS漏洞，可导致数据库密码泄露


荷兰安全研究人员Tijme Gommers发现，使用Anchor CMS构建的网站可能会意外地将其数据库密码暴露在公开的错误日志中。Anchor CMS在错误日志中转储了明文的数据库密码，虽然errors.log文件应该是私有的，但在默认安装的情况下，该文件是公开的，这可能导致数据库密码的泄露。


原文链接：

https://www.bleepingcomputer.com/news/security/anchor-cms-sites-may-be-spewing-their-database-passwords/



4、Apple发布安全更新，修复iOS中的印度字符崩溃问题

Apple发布macOS High Sierra 10.13.3补充更新、iOS 11.2.6、watchOS 4.2.3和tvOS 11.2.6安全更新，修复应用程序在显示特定印度字符时出现崩溃的问题。该漏洞（CVE-2018-4124）是处理特定字符串时触发的堆损坏导致的，受影响的应用包括Twitter、Firefox、Chrome和Safari等。能够触发该漏洞的字符串是如图所示的印度泰卢固语的文字 。


原文链接：

https://www.securityweek.com/apple-fixes-indian-character-crash-bug-ios-macos



5、研究团队发布APT组织Tempting Cedar Spyware的分析报告

Avast威胁情报小组发现了一个用于欺骗Facebook用户下载Kik Messenger间谍软件的社交工程活动。研究人员将该APT称为Tempting Cedar Spyware，它用于窃取用户的联系人、通话记录、短信、照片和地理位置等设备信息，并能够进行录音。该APT非常具有针对性，研究人员认为它背后的攻击者是黎巴嫩人。


原文链接：

https://blog.avast.com/avast-tracks-down-tempting-cedar-spyware
