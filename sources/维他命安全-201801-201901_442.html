 本周安全态势综述


2018年01月29日至02月02日共收录安全漏洞73个，值得关注的是Microsoft Office公式编辑器内存破坏漏洞；Siemens SIMATIC WinCC Add-On CVE-2017-11497栈缓冲区溢出漏洞；Cisco D9800 Network Transport Receiver远程命令注入漏洞；Mozilla Firefox未明内存破坏任意代码执行漏洞；Apple iOS蓝牙内存破坏漏洞。




本周值得关注的网络安全事件是2017年Google从Play商店中删除了70多万个恶意Android应用；研究人员发现利用Rig exploit kit传播的新勒索软件GandCrab；据荷兰媒体报道，上周荷兰3大银行遭到多起DDoS攻击事件；健身追踪软件存在安全隐患，意外泄露美军事基地信息；美国ATM首次遭遇Jackpotting攻击，长期以亚欧的银行为目标。


根据以上综述，本周安全威胁为中。



重要安全漏洞列表

1.Microsoft Office公式编辑器内存破坏漏洞


Microsoft Office公式编辑器存在内存破坏漏洞，允许远程攻击者可以利用漏洞构建恶意文件，诱使用户解析，可使应用程序崩溃或执行任意代码。

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2018-0845


2.Siemens SIMATIC WinCC Add-On CVE-2017-11497栈缓冲区溢出漏洞


Siemens SIMATIC WinCC Add-On hasplms实现存在安全漏洞，允许远程攻击者利用漏洞提交特殊的ASN.1流请求，进行拒绝服务攻击或者执行任意代码。

https://ics-cert.us-cert.gov/advisories/ICSA-18-018-01


3.Cisco D9800 Network Transport Receiver远程命令注入漏洞


Cisco D9800 Network Transport Receiver的web management GUI在实现上存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，执行任意命令。

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180117-ntr


4.Mozilla Firefox未明内存破坏任意代码执行漏洞


Mozilla Firefox处理WEB请求存在内存破坏漏洞，允许远程攻击者利用漏洞提交特殊的WEB页，诱使用户解析，可使应用程序崩溃或执行任意代码。

https://www.mozilla.org/en-US/security/advisories/mfsa2018-02/


5.Apple iOS蓝牙内存破坏漏洞


Apple iOS处蓝牙存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，可使应用程序崩溃或执行任意代码。

https://lists.apple.com/archives/security-announce/2018/Jan/msg00000.html



 重要安全事件综述

1.2017年Google从Play商店中删除了70多万个恶意Android应用


谷歌表示，它在2017年从Play商店中删除了超过70万个恶意应用，比2016年上涨了70％。该公司还表示，禁止了超过10万个属于“bad actors”的开发者账户。同时也承认部分恶意软件躲过其安全检测机制。


原文链接：

https://www.bleepingcomputer.com/news/security/google-removed-over-700-000-malicious-android-apps-from-the-play-store-in-2017/



2、研究人员发现利用Rig exploit kit传播的新勒索软件GandCrab

新勒索软件GandCrab上周被安全研究人员大卫·黑山（David Montenegro）首先发现，并发布该勒索软件的分析报告，GandCrab主要通过Rig exploit kit进行传播，目前还没有该恶意软件的免费解密工具。


原文链接：

https://www.bleepingcomputer.com/news/security/gandcrab-ransomware-distributed-by-exploit-kits-appends-gdcb-extension/




3、据荷兰媒体报道，上周荷兰3大银行遭到多起DDoS攻击事件


荷兰3大银行在上周曾遭受多起DDoS网络攻击，网站和网上银行服务受到影响。周一荷兰税务局也遭到类似的攻击。但是很快恢复了。荷兰央行行长克拉斯·诺特（Klaas Knot）周日在电视新闻节目中表示，荷兰银行是首次遭到DDoS攻击，目前他们每天都有数千起攻击事件。


原文链接：

http://www.securityweek.com/top-dutch-banks-hit-cyber-attacks



4、健身追踪软件存在安全隐患，意外泄露美军事基地信息

Strava是一个健身追踪应用程序，该应用程序使用手机的GPS追踪用户何时何地进行锻炼，并通过分享进行社交。据媒体报道，美国健身追踪软件开发商Strava意外泄露美国军方机密，包括遍布世界各地的美国军事基地以及间谍前哨的位置及人员配置信息。


原文链接：

https://www.bleepingcomputer.com/news/technology/fitness-tracking-app-accidentally-exposed-military-bases/



5、美国ATM首次遭遇Jackpotting攻击，长期以亚欧的银行为目标

ATM Jackpotting攻击是一种复杂的犯罪行为，盗贼在ATM上安装恶意软件，长期以来主要是针对欧洲和亚洲的银行，美国FBI已经警告相关金融机构。盗贼似乎在使用Ploutus.D恶意软件进行一系列攻击，将Opteva 500和700系列Dielbold ATM作为目标，并且有迹象表明，正在计划进一步的攻击全国各地。


原文链接：

https://krebsonsecurity.com/2018/01/first-jackpotting-attacks-hit-u-s-atms/
