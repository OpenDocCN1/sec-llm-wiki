 本周安全态势综述


2018年01月01日至07日共收录安全漏洞63个，值得关注的是Intel CPU预取指令分支目标注入漏洞；Trend Micro Smart Protection Server CVE-2017-14094远程命令执行漏洞；TP-Link多个设备任意命令执行漏洞；Trustwave Secure Web Gateway ROOT访问漏洞；OP-TEE私钥恢复漏洞。


本周值得关注的网络安全事件是Google披露CPU安全漏洞Meltdown和Specter，影响1995年后的所有CPU；美国国土安全部的员工信息泄露，约24.7万人受影响；多家供应商发布针对SPECTRE和MELTDOWN漏洞的补丁；前NSA黑客演示如何利用卡巴斯基杀毒软件检索机密文件；网络犯罪团伙Lurk的黑客承认曾参加WannaCry和DNC的开发。


根据以上综述，本周安全威胁为中。



重要安全漏洞列表


1.Intel CPU预取指令分支目标注入漏洞


Intel CPU预取指令Speculative Execution）技术存在安全漏洞，允许本地攻击者可以利用漏洞可以通过类似的ROP的方式来进行信息泄露。

https://spectreattack.com/spectre.pdf


2.Trend Micro Smart Protection Server CVE-2017-14094远程命令执行漏洞


Trend Micro Smart Protection Server存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求，注入命令并执行。

https://www.coresecurity.com/advisories/trend-micro-smart-protection-server-multiple-vulnerabilities


3.TP-Link多个设备任意命令执行漏洞


TP-Link TL-WVR及TL-WAR设备admin/dhcps命令在实现上存在安全漏洞，允许远程攻击者利用漏洞提交特殊的请求可执行任意代码。

https://github.com/L1ZhaoXin/Router-Vulnerability-Research/blob/master/Tplink_LUCI_Dhcps_Authenticated_RCE_Record.txt


4.Trustwave Secure Web Gateway ROOT访问漏洞


Trustwave Secure Web Gateway /sendKey URI处理‘publicKey’参数存在安全漏洞，允许远程攻击者可以利用漏洞提交特殊的请求，将任意的公钥添加到SSH Authorized Keys数据，获得ROOT权限。

http://seclists.org/fulldisclosure/2017/Dec/88


5.OP-TEE私钥恢复漏洞


OP-TEE LibTomCrypt存在安全漏洞，允许本地攻击者可以利用漏洞构建恶意请求，恢复秘钥信息。

https://github.com/OP-TEE/optee_os/blob/2.5.0/CHANGELOG.md


 重要安全事件综述

1.Google披露CPU安全漏洞Meltdown和Specter，影响1995年后的所有CPU


Google披露了CPU安全漏洞Meltdown（CVE-2017-5753和CVE-2017-5715）和Specter（CVE-2017-5754）的细节，其影响了自1995年以来的所有CPU。Google表示，攻击者可利用这两个漏洞窃取计算机当前处理的数据，这种攻击方式目前无法被检测到，所有的主要芯片厂商（Intel、AMD、arm）、主要操作系统（Windows、Linux、macOS、Android、ChromeOS）、云服务商（Amazon、Google、Microsoft）以及应用程序开发商都受到影响。大多数OS厂商已经或即将发布相关的修复补丁。


原文链接：

https://www.bleepingcomputer.com/news/security/google-almost-all-cpus-since-1995-vulnerable-to-meltdown-and-spectre-flaws/



2、美国国土安全部的员工信息泄露，约24.7万人受影响



美国国土安全部DHS发布声明称，约24.7万名员工的个人信息泄露。事件涉及的是OIG使用的数据库，该数据库存储在OIG的案件管理系统中。泄露的数据包括个人身份信息（PII），如姓名、社保号码、出生日期、职位、等级和工作地点等。DHS称数据泄露不是外部攻击的结果，而是一个前OIG员工拥有OIG数据库的一个未授权的副本。


原文链接：

http://www.securityweek.com/247000-dhs-employees-affected-data-breach




3、多家供应商发布针对SPECTRE和MELTDOWN漏洞的补丁


CPU漏洞SPECTRE和MELTDOWN影响了全球范围内的计算机、服务器和移动设备，目前其漏洞利用被确认为“边界检查绕过”（CVE-2017-5753/Specte）、“分支目标注入”（CVE-2017-5715/Spectre）和“恶意数据缓存加载”（CVE-2017 -5754/Meltdown）。英特尔表示将发布固件更新以修复此问题，微软已发布了紧急更新，Linux安全更新也已在上周推出，苹果在macOS10.13.2中部分解决了该问题，亚马逊发布声明称已对AWS底层基础架构进行了更新。


原文链接：

https://threatpost.com/vendors-share-patch-updates-on-spectre-and-meltdown-mitigation-efforts/129307/


4、前NSA黑客演示如何利用卡巴斯基杀毒软件检索机密文件



前NSA黑客Patrick Wardle通过逆向卡巴斯基的杀毒软件发现，卡巴斯基的恶意软件签名很容易更新，这个功能可以被调整为自动扫描用户的系统和窃取机密文件。Wardle指出官员经常对最高机密文件进行“TS/SCI”（最高机密/敏感分区信息）分类，当在卡巴斯基杀毒软件中增加一条规则以过滤具有TS/SCI标记的文档时，卡巴斯基杀毒软件就会标记并隔离这些文档。


原文链接：http://securityaffairs.co/wordpress/67344/breaking-news/kaspersky-lab-antivirus-hack.html


5、网络犯罪团伙Lurk的黑客承认曾参加WannaCry和DNC的开发



俄罗斯叶卡捷琳堡市被捕的黑客Konstantin Kozlovsky承认曾参加WannaCry和DNC的开发工作。Kozlovsky是网络犯罪团伙Lurk的一名成员，根据他的说法，这项工作是在情报机构的要求下进行的，WannaCry的目标是企业网络，通过感染大量的机器而快速传播，以实现用“一个按钮”瘫痪目标组织的活动的目的。


原文链接：http://securityaffairs.co/wordpress/67262/cyber-crime/wannacry-lurk-group.html
