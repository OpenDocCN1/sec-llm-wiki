# 【漏洞预警】三菱电机MELSEC-Q系列PLC DoS漏洞（CVE-2019-10977）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247485851&idx=3&sn=abf3c705073ce0fca3448e252efdc9d0&chksm=f902430ace75ca1c86f8cbb4c529128d0e0fb4d8532811dcaa06476a81045ca3f2a8837554d8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247485851&idx=3&sn=abf3c705073ce0fca3448e252efdc9d0&chksm=f902430ace75ca1c86f8cbb4c529128d0e0fb4d8532811dcaa06476a81045ca3f2a8837554d8&scene=27#wechat_redirect)

01

背景描述

三菱电机修复MELSEC-Q系列PLC中的一个可导致DoS的高危漏洞（CVE-2019-10977），该漏洞主要影响了PLC的以太网模块QJ71E71-100（序列号20121及之前的版本）。

  

02

漏洞列表

CVE ID  ：   CVE-2019-10977

CNNVD ID：   CNNVD-201905-839   

漏洞等级：   高危

CVSS评分：   7.5

影响范围：   MELSEC-Q系列以太网模块QJ71E71-100（序列号20121及之前的版本）

  

03

漏洞详情

日本电气设备制造商三菱电机制造的MELSEC-Q系列PLC受到高危漏洞（CVE-2019-10977）的影响，这些PLC在全球范围内被广泛用于关键制造业。该漏洞主要影响PLC的以太网接口模块QJ71E71-100，攻击者可通过将恶意TCP数据包发送至FTP服务，迫使目标设备进入错误模式并导致拒绝服务。

成功利用此漏洞可导致设备无响应，必须对PLC进行物理复位。该漏洞可被远程利用，并且只需低技能级别即可利用。

  

04

修复建议

升级到最新版本。
