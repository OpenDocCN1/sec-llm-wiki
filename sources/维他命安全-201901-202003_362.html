【漏洞预警】Windows RDP远程执行代码漏洞（CVE-2019-0708）

原文：http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247485790&idx=2&sn=c96eee0a2724643df5660332f3d760a1&chksm=f90243cfce75cad9943dfd1cd53a07863ef137440aeeeb796e338df854969b23ed3cddb0cdd7&scene=27#wechat_redirect



01

背景描述

5月14日微软发布了针对远程桌面服务（以前称为终端服务）的远程执行代码漏洞CVE-2019-0708的修复程序，该漏洞影响了某些旧版本的Windows。远程桌面协议（RDP）本身不容易受到攻击。此漏洞是预身份验证，无需用户交互。成功利用此漏洞的攻击者可以在目标系统上执行任意代码。然后攻击者可以安装程序、查看、更改或删除数据，或创建具有完全用户权限的新帐户。

要利用此漏洞，攻击者需要通过RDP向目标系统远程桌面服务发送特制请求。

该漏洞可能会被用来为恶意软件提供支持，像2017年的WannaCry勒索软件攻击一样。

2017年5月，WannaCry勒索软件威胁在全球迅速蔓延，运行Windows XP和旧版Windows系统中尤为普遍。微软已经发布了针对该漏洞的补丁，但许多较旧且易受攻击的操作系统从未更新过。

02

影响范围

CVE ID:       CVE-2019-0708

漏洞等级：  高危

影响版本：

            Windows 7

            Windows Server 2008 R2

            Windows Server 2008

            Windows 2003

            Windows XP

注意：目前Windows 8和Windows 10不受此漏洞影响


03

修复方案

1.强烈建议更新所有受影响的系统

2.禁用远程桌面服务（如不需要）

3.启用网络级认证（NLA）
