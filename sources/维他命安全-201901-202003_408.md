# 【漏洞预警】Apache Tomcat远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247485592&idx=4&sn=1fde22c71a51eea41306228ee909e911&chksm=f9024209ce75cb1ff503a40e36a69e7d89f25614135fc73d1e60586247fb8a2e00493d7a3a87&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247485592&idx=4&sn=1fde22c71a51eea41306228ee909e911&chksm=f9024209ce75cb1ff503a40e36a69e7d89f25614135fc73d1e60586247fb8a2e00493d7a3a87&scene=27#wechat_redirect)

![](../Images/ab0468280ebc74d6b7cb10ea2d54bbe9.png)

  

01

背景描述

4月10日，Apache官方发布通告称将修复Windows版本中的一个远程代码执行漏洞（CVE-2019-0232）。

02

影响范围

CVE ID  ：   CVE-2019-0232    

漏洞等级：   高

影响范围：   Apache Tomcat 9.0.0.M1 to 9.0.17

                     Apache Tomcat 8.5.0 to 8.5.39

                     Apache Tomcat 7.0.0 to 7.0.93    

影响平台：   Windows

03

漏洞详情

    该漏洞是由于在将参数从JRE传递到Windows环境时CGI Servlet中存在输入验证错误。远程攻击者可以向CGI Servlet发送特制的请求，使用Apache Tomcat权限在系统上注入和执行任意OS命令。

    成功利用此漏洞需要在Windows操作系统上安装Apache Tomcat，并启用选项“enableCmdLineArguments”（默认情况下禁用CGI Servlet和“enableCmdLineArguments”选项）。  

04

修复建议

Tomcat官方尚未发布更新补丁，此漏洞将在下个版本中修复。
