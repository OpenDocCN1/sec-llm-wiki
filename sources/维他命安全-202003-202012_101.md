# **介绍**

巴哈姆特（BAHAMUT）是一个巨型海怪的名字。故事起源于阿拉伯，中世纪的爱德华·莱恩（Edward Lane）的阿拉伯社会中就讲述了巴哈姆特的故事，而豪尔赫·路易斯·博尔赫斯（Jorge Luis Borge）的《虚构的人本》中也摘录了莱恩的译本。博尔赫斯将巴哈马特比作圣经中的巨兽\-一种“巨大到……人类的眼睛无法直视它”的生物（Borges，1967）。BAHAMUT也是2017年为Bellingcat撰稿的研究人员对黑客组织的称呼。多年来，国际特赦组织、卡巴斯基、趋势科技、Cymmetria、DarkMatter、ESET、Norman、Antiy、Forcepoint、赛门铁克、Palo Alto、Fortinet、4Hou、bitdefender、Cisco Talos、Microsoft、Qianxin等其他几个组织的研究人员也曾针对该组织进行过研究，并提出了不同的看法。BAHAMUT还大量利用了开源的工具，这进一步增加了溯源的难度。该组织将其活动、网络基础结构和网络钓鱼工具分开，反逆向功能通常直接嵌入到后门中，并且可以利用shellcode。一旦暴露后，该组织会立即改变策略，并从错误中吸取教训。BAHAMUT似乎不仅资金雄厚、资源丰富而且精通安全研究，导致分析师的考虑通常会出现偏差。

## **历史目标**

2017年6月，科林·安德森(CollinAnderson)和克劳迪奥·瓜涅里(Claudio Guarnieri)在为开源情报和新闻调查网站Bellingcat撰写的文章中，认为BAHAMUT专注于中东的政治、经济和社会领域，针对个人而非组织，包括中东人和以新闻工作者、外交官或人权倡导者等身份在中东长期生活的非中东人。在那些可以明确确定的目标中，主要涉及到埃及、伊朗、巴勒斯坦、土耳其、突尼斯和阿拉伯联合酋长国。根据Bellingcat的研究结果，受害目标包括：•伊朗妇女维权人士•土耳其政府官员•沙特阿拉伯国家石油公司•重点关注该地区的欧洲人权组织•与卡塔尔的国内和国际政治有关人民•提供金融服务的公司•关注埃及的媒体和外国媒体，包括先前在该国被监禁的个人•多个中东人权非政府组织和地方活动家•阿联酋外交部外交官，阿联酋外交大臣和阿联酋外交政策智囊团负责人•著名的苏菲伊斯兰学者•阿拉伯银行联盟•土耳其驻联合国教科文组织代表•土耳其外交部长•伊朗总统的亲戚•一个妇女权利活动家和散居国外的杰出女记者•一位改革派政治家，曾担任前总统哈塔米的顾问•巴林总理府•沙特能源部长•沙特阿拉伯国家安全委员会前成员此外，通过对先前研究的调查，黑莓了解到BAHAMUT的另一个目标群体集中在南亚，其中印度和巴基斯坦是主要目标国家，其次是中国。在某些情况下，我们发现研究人员声称可以确定进入北欧和东欧的目标。黑莓了解到，BAHAMUT主要对政府和军事组织、私人以及与技术、媒体、航空航天和金融行业有关的公司感兴趣。并且，随着时间的流逝，BAHAMUT的目标范围千差万别，但似乎通常会避开位于美国的资产和目标。总之，过去的研究结果集中在两个主要领域：南亚（特别是印度和巴基斯坦）和中东（特别是阿联酋和卡塔尔）。黑莓评估了广泛的针对性，无论是在地理位置上还是在目标上，为Bellingcat的理论提供了佐证，即BAHAMUT是一场“雇佣黑客”(hacker for hire)行动。

## **近期目标**

黑莓对BAHAMUT当前目标的分析表明，该组织的兴趣始终集中在同一重点领域（南亚和波斯湾）的团体和个人。黑莓通过对BAHAMUT当前的某些网络钓鱼活动进行分析，发现其针对西方某些流行的网站，例如Google™、Microsoft®、Yahoo！®和Telegram、的用户，中国新浪、QQ、126和163用户，中东的政府机构、私人企业和个人，沙特阿拉伯的七个不同的政府部门和其他机构，阿联酋、卡塔尔、巴林和科威特的外交和国防政府部门。  

# **战术:****“假”帝国**

BAHAMUT的战术的最独特的方面是他们使用原创的、精心制作的网站、应用程序和人物角色，在众多令人眼花缭乱的行业中，塑造一种令人信服的合法外表。**Techsprouts****镜厅**作为第一个宣传或传播一种理念的人，无论他是谁，通常都是这个理念在现实世界中得以体现和确立的全部。BAHAMUT利用这项技术，在不同的时间点运行了几个不同的虚假新闻网站，并只是模仿其他合法的新闻文章。在那之后的几年里，黑莓成功识别出了另一个活跃的技术新闻网站:Techsprouts，它定期生成原创内容。通过对Techsprouts网站历史的研究，黑莓发现它最初是一个合法网站，主要关注的是对移动设备的评论。在隐私服务失效后，黑莓通过注册域名的电子邮件确定了该网站的原始所有者，是一位印度自由技术记者和评论家Nitin Agarwal。但是，在过去一年中，BAHAMUT似乎已经重新注册了Techsprouts域，并继续运营，且没有改变名字。![](../Images/66dc39650ab80d868df546a7fd6d2915.png)***Figure.1 Techsprouts******主页***如下图所示，高级作家爱丽丝·简（Alice Jane）的形象实际上是北卡罗来纳州格林斯伯勒的当地CBS电台晚间主持人朱莉·勒克（Julie Luck）的照片。艾伦·帕克（Allen Parker）的照片实际上是布莱恩·施拉德（Brian Shrader）的照片。经过进一步检查，整个网站上看到的每位作者的缩略图照片都是从其他网站和名称完全不同的其他人那里窃取的。![](../Images/6d0d2248b835f3580f0a6eb147202a93.png)***Figure.2 ******爱丽丝·简和朱莉·勒克的照片***除了照片之外，在BAHAMUT接管Techsprouts域之后，文章的语气和主题发生了变化。对移动设备的评论仍然存在，但现在更多涉及安全研究和地缘政治主题的文章。在回顾最近的新闻文章时，黑莓注意到，Techsprouts密切关注着像NSO集团这样的私人安全公司的动向。**Techsprouts –****比你看到的要多**黑莓在调查Techsprouts子域mail.techsprouts\[.\]com时，发现BAHAMUT是Techsprouts网站的控制者。其通过三种方式进行评估以得出此结论，首先，也是最重要的是，该域包含BAHAMUT独有的网络服务指纹。其次，所讨论的域指向IP地址“185.122.58\[.\]133”。从端口和服务的角度来看，此IP的配置与其他BAHAMUT控制的网站（包括Windows®、Android™和iOS命令与控制（C2）服务器）相同。当它运行c-panel时，对指向该IP地址的域的被动DNS历史记录的广泛审查显示，只有与BAHAMUT相关的域才可以对此解析。第三，自签名SSL证书提供了额外的证明：“https://beta.shodan.io/host/185.122.58.133/history#993”。该证书在创作时已在IP上生效。![](../Images/ddaf8177acdc2ba4f281c407e38dd9e2.png)***Figure.3  IP******地址******185.122.58.133******上的******SSL******证书*****“假”帝国的扩展**通过分析，黑莓扩大了对其他由BAHAMUT控制的伪造网站的搜索范围。使用独特的网络服务指纹，发现了许多受BAHAMUT控制的其他网站。其中一些还与BAHAMUT的恶意软件或攻击有关。其他则绑定到BAHAMUT网络钓鱼服务器，或充当BAHMAUT后门的C2。如下表所示，这些网站要么是在短时间内运行过，要么在撰写本文时仍处于活跃状态。

# **战术：网络钓鱼的艺术**

      
黑莓分析发现，BAHAMUT的网络钓鱼和凭据收集技术比大多数的APT组织要好得多。研究人员在Bellingcat上写的文章中定义了BAHAMUT最初的网络钓鱼框架，如今已演变为针对精确目标的更为完善的凭据收集系统。在监控BAHAMUT过去一年的运营情况时，黑莓每周都会观察到新的网络钓鱼方式。正如其他研究人员之前所观察到的那样，这些针对性很强的鱼叉式网络钓鱼行动会进行数小时到几个月的时间，具体取决于领域和成功率。BAHAMUT还会从错误中学习。通过仔细分析其各个域和子域的运行时间表，很明显，BAHAMUT非常仔细地监视了信息安全社区发布的有关它们的所有研究。从某些方面来说，攻击者都是如此，但很少有人反应如此敏捷。在关于该组织遭到披露后，BAHAMUT几乎会立即关闭任何相关的设备。其似乎还仔细研究了研究人员以前如何将他们的活动与其联系在一起的，然后进行相应的调整。在对其网络钓鱼行为的分析中，黑莓观察到，在进行网络钓鱼之前，BAHAMUT通常会搜集有关其目标的大量信息。显然，这是强大的侦察行动的结果。黑莓怀疑其中许多数据是该组织的假网站。（例如Techsprouts）。如今，BAHAMUT通常使用免费的URL缩短服务，例如“ grabify.link”、“ 1hr.hu”、“ t.co”、“ u.nu”、“ tinyurl.com”、“ bit.do”。其也会建立自己的站点，例如“ ghelp.co”，以执行初始重定向。正是这些服务为攻击者提供了有关受害者实际点击链接的详细信息，这些信息通常包括IP地址、本地时间和所用浏览器的用户代理。可以快速分析此信息以确定预期目标是否点击了诱饵，有时其还会将新的URL重新发送给相同的目标以进行跟踪。第二次重定向通常是到freenom托管的域(https://www.freenom.com/)，如之前在WINDSHIFT研究中记载的那样(Karim, 2018)。这些网站被伪造一个合法的页面，用来收集凭证，然后转发目标到原网站请求，或其他登陆页。目标点击的链接不是一次重定向，而是四次或更多的重定向，都是为了加大研究人员和受害者的分析难度。黑莓观察到其仿照各种政府机构登录界面，以及私人电子邮件和其他账户入口，包括微软Live、Gmail™、Yahoo!、Apple ID、Twitter、Facebook、Telegram、微软OneDrive、163、新浪、ProtonMail等。尽管BAHAMUT的大部分间谍技术都非常出色，但他们在几个关键领域的渗透，让黑莓得以发现其活动。黑莓于2018年首次披露了该组织的重定向方式。在端口443上向这些钓鱼网站的IP地址发出请求将触发重定向到另一个安全网站，以避免被怀疑。如果受害者浏览到网络钓鱼网站的基本域，则它将重定向到来自Apple或Google等服务的合法错误消息。黑莓利用Shodan（https://shodan.io）之类的扫描服务来进行检测，并列举了大约十五个活动的网络钓鱼域：![](../Images/5f53d2e140da0053fb768bafe1de0fec.png)***Table.2 ******由******BAHAMUT******控制的******IP******地址被重定向到短******URLs*****运营安全****++**黑莓之前曾指出，BAHAMUT在网络钓鱼、凭据收集、Android、iOS和Windows基础架构方面做得非常出色。但黑莓发现，该组织当前的运营职能之间没有跨域或IP地址。例如，没有用于控制或分发Windows恶意软件的域或IP地址被用于钓鱼或管理为任何其它操作系统设计的恶意软件。同样，在任何给定时间很少有单个服务器用于多个移动应用程序。 BAHAMUT确保没有任何托管服务提供商被过度利用，并将其当前的活动分布在50多个不同的托管服务提供商中，从保证任意单个活动或恶意软件被披露的情况下操作的连续性。这是非常耗时且昂贵的，并且需要非常注意细节。BAHAMUT对域名注册非常谨慎，使用不同的隐私服务、从不同的注册商和经销商处购买域名，并且该组织限制了可以与任何单个电子邮件地址关联的域名数量。总而言之，黑莓发现BAHAMUT的社会工程技术远远高于平均水平。该组织具有真正令人印象深刻的运营安全性，尽管多次反复尝试揭露其业务，但仍未成功。
