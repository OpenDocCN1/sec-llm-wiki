# 【事件通告】近期关于利用CVE-2020-1472的攻击事件通告

### **0x00 事件概述**

 

![](../Images/053e3554582f3665effa5c4708149e5a.png)

                           

2020年09月下旬，微软发布预警称网络犯罪团伙MuddyWater（SeedWorm）已开始在其攻击工具中加入了ZeroLogon漏洞的利用代码；10月06日，SI-LAB检测到有攻击者结合CVE-2020-25213漏洞和Zerologon漏洞来攻击域控制器的攻击活动；10月07日微软再次发出警告，关于犯罪团伙TA505使用Zerologon漏洞的攻击活动。由于该漏洞利用简单，影响范围广，目前已被多个犯罪团伙利用。

 

### **0x01****事件详情**

ZeroLogon由Secura的Tom Tervoort发现，它可以让域网络上的攻击者无需进行身份验证即可将权限提升到管理员级别，并且可以通过Netlogon远程协议强制以未加密状态（非安全RPC通信）连接到域控制器。通过利用Netlogon加密算法中的缺陷，可以欺骗域管理员登录。当涉及到勒索软件攻击时，此漏洞尤其令人关注，因为它允许控制某个PC的攻击者获得Windows域网络的完全控制权。

９月下旬，微软研究人员报告说，伊朗间谍组织MuddyWater在野外攻击中利用Zerologon漏洞。该组织也被称为 MuddyWater、SeedWorm 和 TEMP.Zagros。

10月06日，SI-LAB检测到有攻击者结合CVE-2020-25213漏洞和Zerologon漏洞来攻击域控制器。

此外，SI-LAB还发现一些的犯罪团伙使用此漏洞的攻击行为，如：网络钓鱼活动，并传播恶意软件;植入后门，窃取数据、信用卡信息或敏感信息(PII);在特定页面(如index.php)的源代码中添加加密器(java脚本)。

SI-LAB还注意到一些攻击者结合CVE-2020-25213漏洞和Zerologon漏洞：以目标系统为中心，逐步横向移动到Doman Controller上并最终控制域控，这种情况将造成巨大损失。

此外，还可以从域控制器中提取NTLM哈希值，包括Domain Admin哈希值，并通过“哈希传递”攻击访问在该域中注册的所有计算机。

python3 cve-2020-1472-exploit.py DOMAIN\_NAME192.168.x.x

Performing authentication attempts...

\===========================================================================

Target vulnerable, changing account password toempty string

Result: 0

Exploit complete!

最后，可以远程提取域控制器NTML哈希。请注意，必须快速恢复机器密码，否则DC将不会同步，这可能会中断网络。

![](../Images/2072bdcddd7df142ca29c34c3c8fc16a.png) 

微软于2020年10月07日发出警告，关于犯罪团伙TA505的使用Zerologon漏洞的攻击活动，通过虚假的安全更新，意图连接到受害者的命令与控制(C2)基础设施。虚假更新的目的是在目标系统上运行恶意脚本。

![](../Images/dba67c46da6eefbe03b7d3f8bb0d841e.png)

目前，研究人员已经发布了CVE-2020-1472漏洞的PoC，利用此PoC可在十秒钟内成功控制Windows域。微软表示，TA505使用Microsoft Build Engine 重新编译Mimikatz，以构建应用程序，该程序包括ZeroLogon漏洞（CVE-2020-1472）的利用代码。

 

**通报时间**

09月15日，[启明星辰VSRC发布此漏洞的预警](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247489936&idx=2&sn=f1897811e59de94fe690e4e3bdf0024a&chksm=f9025301ce75da17a0708b4534976ea2629d23157cb0286c46b5b6bdfd7e054c56c47a407868&scene=21#wechat_redirect)。

09月18日，美国网络安全与基础设施安全局（CISA）要求联邦平民行政部门将修复此漏洞视为紧急情况。

09月23日，微软发布利用ZeroLogon漏洞进行攻击活动的预警，之后是再次利用此漏洞MuddyWater的通告。

 

**安全更新**

Microsoft通过阻止Windows Active Domain控制器通过非安全RPC通信来部分解决此漏洞。此更新自08月11日开始可用。在2021年02月09日，新的更新将强制对网络上的所有设备执行相同的安全通信。

补丁链接地址：

https://portal.msrc.microsoft.com/zh-CN/security-guidance/advisory/CVE-2020-1472

由于该漏洞涉及了像TA505这种网络犯罪团伙，因此应优先考虑为此漏洞应用安全补丁，因为类似于Microsoft所述的攻击很可能会以更高的频率发生。

 

 

### **0x02 ****附录**

**Seedworm****（也被称为MuddyWater）**

Seedworm被认为是一个网络间谍团伙，目的是收集有价值的情报，从而为其资助者牟利。在最新的活动中，该团伙使用的工具与在过去入侵中使用的工具一致，包括Powermud和自定义PowerShell、LaZagne和Crackmapexec脚本。自2017年初以来，该团伙不断更新其Powermud后门和其它工具，以避免被发现，并阻止安全研究人员分析这些工具。

自2018年09月份以来，已经有来自30个组织的130人成为了该团伙的受害者。比如，2018年09月，MATI团队在某石油生产国驻巴西大使馆的一台电脑上发现了Seedworm和另一个间谍团伙APT28（又名Swallowtail和Fancy Bear）留下的攻击痕迹。

 

**TA505**

2014年TA505首次发布银行木马Dridex，之后又发布Locky、Jaff和The Trick等恶意软件，对攻击的受害者不加区分。多年来，该攻击者一直提供从后门到勒索软件的各种恶意软件。

TA505在电子邮件威胁领域有很强的影响力。该组织例行分发了比其他任何参与者都要多的恶意软件，并定期向数百万人发送垃圾邮件。分布更广泛的恶意软件（例如Dridex和Pony）似乎为该组独有的，数量多且危害大。

他们曾将GlobeImposter和Philadelphia提升为针对区域的小型勒索软件变种，使其成为全球威胁。

最近，该组织在入侵之后又部署了勒索软件Clop，比如去年对马斯特里赫特大学的攻击导致支付了30个比特币（约合22万美元）的赎金。
