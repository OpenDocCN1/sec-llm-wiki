# Unit 42：针对Mirai变体的攻击活动分析

### **概述**

2021年2月16日，Unit 42的研究人员发现了Mirai僵尸网络恶意软件变体整合了针对各种目标的多个漏洞的利用程序，其中包括：

*   VisualDoor(SonicWall SSL-VPN)；
    
*   CVE-2020-25506(D-Link DNS-320防火墙)；
    
*   CVE-2020-26919( Netgear ProSAFE Plus)；
    
*   疑似 CVE-2019-19356 ( Netis WF2419 无线路由器)；
    
*   尚未确定的其它三个IoT 漏洞。
    

![](../Images/2fbb0f4163fbcc9bbe4982587938fc3f.png)

  

2021年2月23日，在漏洞细节公布后的几个小时，其中一个参与攻击的IP便得到更新，以通过Mirai变体利用CVE-2021-27561和CVE-2021-27562漏洞。2021年3月3日，第三个IP地址使用了相同的样本，并添加了CVE-2021-22502的漏洞利用。此外，在3月13日，一个针对CVE-2020-26919的漏洞利用也被纳入样本中。

在撰写本文时，攻击仍在进行中。成功利用后，攻击者会尝试下载一个恶意shell脚本，其中包含进一步的感染行为，如下载和执行Mirai变体和brute-forcers。

**Exploit Payloads**

**1.VisualDoor****：SonicWall SSL-VPN远程命令注入漏洞**

该exploit针对SonicWallSSL-VPN使用的旧版Bash，该版本容易受到ShellShock的攻击。攻击者可以将特制的通用网关接口（CGI）请求发送到特定的Shell脚本，从而导致未经身份验证的远程代码执行（RCE）漏洞。

下图为VisualDoor SonicWall SSL-VPN的exploit payload：

![](../Images/47012c39962700c3b33342108cd4a77c.png)

  

 

**2.CVE-2020-25506****：D-Link DNS-320防火墙远程命令执行漏洞**

该exploit针对system\_mgr.cgi组件中的命令注入漏洞。由于该组件无法成功清除HTTP参数f\_ntp\_server的值，从而导致任意命令执行。

下图为D-Link DNS-320的exploit payload：

![](../Images/ff621a6e262ea5514aed015d19aa24fb.png)

  

 

**3.CVE-2021-27561****和CVE-2021-27562：Yealink设备管理预认证“root”级别远程代码执行漏洞**

该exploit的原理是链接一个预授权服务器端请求伪造（SSRF）漏洞和一个命令注入漏洞，只要向远程目标发送HTTPS请求，就可以在没有身份验证的情况下以root身份执行命令。

下图为Yealink设备的exploit payload：

**4.CVE-2021-22502****：Micro Focus OperationBridge Reporter (OBR)远程代码执行漏洞**

该漏洞是由于在对LogonResource API的请求中用了未经清理的username和password参数。此漏洞被利用将导致攻击者在OBR服务器上以root用户远程执行代码。

该exploit针对诊断工具实用程序中的RCE漏洞。经过身份验证的攻击者可以通过使用多个参数（如IP地址或域名）远程执行命令。

### **恶意软件行为**

**二进制文件：lolol.sh**

**功能**：从目标计算机上删除一些密钥文件夹（例如包含现有计划任务的密钥文件夹以及启动脚本）后，此脚本将下载下面说明的“dark”二进制文件，将其保存到一个误导性的文件“ nginx”中，并尝试运行每个文件。由于下载的“dark”二进制文件均针对不同的体系结构进行编译，因此只有与目标计算机兼容的二进制文件才能真正执行。

然后，它设置了一个每小时运行一次的任务，以重新运行lolol.sh脚本。但是，cron配置不正确。这本来是为了确保该过程在崩溃或由于某些其它原因被终止时重新启动。

最后，创建了几个数据包过滤规则，以阻止针对常用端口，如标准SSH、HTTP和telnet端口等的传入流量。这可能会使管理员对受影响的系统进行维护和远程访问更具挑战性。

在观察到的脚本的两个版本之一中，它还会下载并运行下面描述的“install.sh”脚本。

 

**二进制文件：install.sh**

**功能：**该脚本将GoLang v1.9.4下载到目标系统并将其添加到系统路径。此外，它还会安装GoLang标准的SSH软件包和zmap（常见的网络扫描软件包）。

它还下载下面描述的“ nbrute”二进制文件和“combo.txt”文件。与以前的脚本一样，下载的“nbrute”二进制文件均针对不同的体系结构进行编译，从而增加了与目标计算机兼容的可能性。

最后，运行zmap扫描端口22，并将在端口22打开的情况下找到的IP作为输入发送到nbrute二进制文件。

 

**二进制文件：nbrute.\[arch\]**

**功能：**这些二进制文件是用GoLang编写的，主要作用是在启动与某个IP的SSH连接时，强制执行 “combo.txt“中的各种凭证。

**二进制文件：combo.txt**

**功能**：纯文本文件，包含多种凭证组合（通常是设备上的默认凭证）。

 

**二进制文件：dark.\[arch\]**

**功能**：这些二进制文件基于Mirai代码库，主要用于传播目的，使用上文描述的漏洞、或者使用二进制文件中的一些硬编码凭证来强行连接SSH。标准Mirai字节逐字节XOR加密例程使用的密钥是0xbaadf00d。

  

 

### **结论**

物联网领域仍然是攻击者容易利用的目标，尤其是许多设备或系统中的漏洞。在某些情况下，这可能会带来灾难性的后果。因此，我们强烈建议在可能的情况下及时应用补丁。
