# 【译】 2010-2020：10个最常见的安全漏洞

自2010年到2020年已经过去十年，但这十年在IT中发现的安全漏洞多不胜数。以下，我们将介绍10个最常见的安全漏洞，攻击者能够利用这些漏洞破坏应用程序、窃取用户凭据并影响数百万人。

  

 

![](../Images/06c5ae593722241506408ec969bf8347.png)

  

以下列表并未列出十年来在IT中发现的所有漏洞，我们将重点介绍影响Unix、Linux、macOS、服务器和云计算的漏洞。

**1\. BlueBorne：**该攻击是通过Android、iOS、Linux和Windows中的Bluetooth发起的。报告显示，blueBorne漏洞影响全球超过82亿个设备。IoT安全公司Armis于2017年9月12日首次报告了此漏洞，其影响如智能手机、笔记本电脑、智能汽车和可穿戴设备等多种电子设备。

 

**2\. Badlock：**2016年4月12日，在MicrosoftWindows和Samba中发现一个严重的安全漏洞CVE-2016-2118。该漏洞会影响Windows和Samba网络支持的安全帐户管理器（SAM）和本地安全授权（域策略）（LSAD）远程协议。

 

**3\. DirtyCow：**这是一个在Linux内核中发现的非常严重的安全漏洞。其影响所有2018年之前的旧版Linux内核系统。该漏洞是一个本地权限提升漏洞，其利用在内核内存管理子系统中执行copy-on-write工具时存在race危险。需要注意的是，那些仍使用Linux旧内核的计算机和设备仍然容易受到此漏洞的影响。

 

**4\. ForShawod：**十年来，许多Intel/AMD处理器因安全漏洞而瘫痪。L1Terminal Fault或Foreshadow影响现代微处理器。第一个版本公开了来自PC和云网络的敏感信息，而第二个版本则针对管理程序（VMM）、虚拟机（VM）、系统管理模式（SMM）内存和操作系统（OS）内核内存。

 

**5\. Heartbleed：**这是流行的OpenSSL加密软件库中的一种非常危险的网络攻击，它允许在正常情况下通过SSL / TLS加密（用于保护Internet）来窃取敏感信息。SSL / TLS为包括电子邮件、即时消息（IM）、Web和某些虚拟专用网络（VPN）在内的应用程序提供Internet上的通信安全和隐私等服务。在这个漏洞之后，Google建立了“Project Zero”，其任务是保护网络和社会的安全。

 

**6\. iSeeYou：**该漏洞影响Apple笔记本电脑，攻击者可通过利用此漏洞远程访问并拍摄照片。由于苹果的笔记本电脑涉及多种操作系统，如macOS、Linux和Microsoft Windows。因此，针对此漏洞的攻击会因操作系统而异。为响应被发现的攻击，攻击者发布了iSightDefender来减少攻击。

 

**7\. Lazy：**此漏洞影响Intel CPU。攻击者利用此漏洞泄漏FPU寄存器中属于另一个进程的内容。该漏洞与Spectre和Meltdown漏洞相关。已发布了OpenBSD、Linux、Xen等补丁程序来修复此漏洞。

 

**8\. Linux.Encoder：**也称为ELF/Filecoder.A和Trojan.Linux.Ransom.A。这是第一个针对计算机、服务器、云和运行Linux的设备的勒索软件木马。此外，此木马还有其它变种，它们针对Unix和类Unix系统。

 

**9\. POODLE：**这种攻击也称为中间人，它利用Internet和安全软件客户端对SSL3.0的回退功能，任何支持回退到SSL 3.0的软件都会受到影响。为避免影响，人们不得不在客户端和网络端禁用SSL 3.0。微软、谷歌、苹果、OpenSSL等各平台都发布了软件补丁，以免受到POODLE攻击。

 

**10\. Rootpipe：**在OS X中已经发现了Rootpipe安全漏洞，该漏洞可提升权限。利用系统上的安全漏洞可以使攻击者获得超级用户（root）访问权限，并利用Mac上的其它错误（如未修复的Apache Web浏览器），攻击者可以利用root管道来获得对运行系统和Apple计算机或网络的完全控制。研究人员在2017年11月表示，在macOS High Sierra中发现了类似的攻击，攻击者无需密码和root帐户即可轻松访问系统。
