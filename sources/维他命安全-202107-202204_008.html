0x00 风险概述

2022年3月31日，CISA将7个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及Trend Micro（趋势科技）、Sophos、Microsoft、QNAP、Dell和Dasan等供应商。

 

0x01 攻击详情

CISA本次新增的7个漏洞都是已知被积极利用的安全漏洞，对企业和组织构成了重大风险，漏洞详情如下：

CVE-2022-26871

Trend  Micro

Trend  Micro Apex  Central 任意文件上传漏洞

Trend Micro Apex Central 中的任意文件上传漏洞允许在未经身份验证的情况下上传任意文件，这可能导致远程代码执行。该漏洞已在Trend Micro Apex Central 2019 Patch3（Build 6016）中修复，Apex Central(on-prem)  for Windows用户应尽快应用补丁，SaaS用户则无需执行其它操作。

2022/4/21

CVE-2022-1040

Sophos

Sophos Firewall身份验证绕过漏洞

Sophos  Firewall 的用户门户和 Webadmin 中的身份验证绕过漏洞可能导致远程代码执行，该漏洞的CVSS评分为9.8。

2022/4/21

CVE-2021-34484

Microsoft

Microsoft  Windows 用户配置文件服务权限提升漏洞

Microsoft  Windows User Profile Service存在允许权限提升的未明漏洞。

2022/4/21

CVE-2021-28799

QNAP

QNAP NAS 授权不当漏洞

运行 HBS  3 的 QNAP NAS 包含一个授权不当漏洞，允许远程登录设备。

2022/4/21

CVE-2021-21551

Dell

Dell dbutil 驱动程序访问控制不足漏洞

Dell  dbutil_2_3.sys 驱动程序包含访问控制不足漏洞，可能导致权限提升、拒绝服务或信息泄露。

2022/4/21

CVE-2018-10562

Dasan

Dasan GPON 路由器命令注入漏洞

Dasan GPON路由器存在命令注入漏洞，可以通过对GponForm/diag_Form URI的diag_action=ping请求中的dest_host参数实现。（目前受影响的产品已报废，如果仍在使用中，应断开连接。）

2022/4/21

CVE-2018-10561

Dasan

Dasan GPON 路由器认证绕过漏洞

Dasan GPON 路由器存在身份验证绕过漏洞，可以在设备的任何需要认证的URL上附加"?images "就可以绕过认证并实现设备管理。（目前受影响的产品已报废，如果仍在使用中，应断开连接。）
