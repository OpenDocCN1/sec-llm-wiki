0x01 漏洞详情

Spring Cloud Function 是基于Spring Boot 的函数计算框架，它抽象出所有传输细节和基础设施，允许开发人员保留所有熟悉的工具和流程，并专注于业务逻辑。

近日，Spring Cloud Function 修复了一个SpEL表达式注入漏洞，可利用该漏洞在未认证的情况下在目标 Spring Cloud Function系统中远程执行任意代码。

由于Spring Cloud Function将请求头中的“spring.cloud.function.routing-expression”参数作为 SpEL表达式进行处理，造成SpEL表达式注入漏洞，成功利用此漏洞可实现任意代码执行。目前漏洞的PoC/EXP已公开，建议相关用户尽快采取安全措施。

 

影响范围

3.0.0.M3 <= Spring Cloud Function <=3.2.2

 

0x02 安全建议

目前Spring Cloud Function官方已发布此漏洞的补丁，但尚未正式发布修复版本，建议相关用户尽快应用补丁进行防护并关注官方的更新版本。
