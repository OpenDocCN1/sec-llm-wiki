【风险通告】Windows Server 2019更新导致DNS解析失败

0x00 风险概述

2022年3月23日，Microsoft解决了Windows Server 2019 系统上因安全更新导致DNS 存根区域（DNS stub zones）加载失败而导致的DNS解析失败。

 

0x01 攻击详情

DNS 存根区域是DNS区域的副本，其中仅包含标识该区域的 DNS 服务器的资源记录。

Microsoft表示，在运行DNS服务器角色的受影响版本的Windows Server上安装2022年1月25日（KB5009616）及之后发布的更新后，DNS存根区域可能无法正确加载，这可能导致DNS名称解析失败。

此外，另外两个 Windows 更新 KB5010427（2 月 15 日发布）和KB5011551（3月 22 日发布）也可能触发此 DNS 解析问题。

Microsoft 已通过已知问题回滚 (KIR) 功能解决了此问题，但是该KIR不会自动传播到受影响的设备。已经安装了受影响的更新并遇到此问题的设备可以通过安装和配置下面列出的2个用于部署 KIR 修复的组策略来解决此问题（见参考链接）：

  • 下载 1 适用于 Windows Server 2019

  • 下载 2 适用于 Windows Server 2019

自从发布2022年1月更新以来，微软已经修复了多个因更新导致的安全问题，包括：导致Windows 蓝屏的蓝牙问题、由 LSASS 崩溃导致的 Windows 域控制器重启、  Netlogon 问题和 WindowsActive Directory 错误等。
