0x00 风险概述

2022年3月7日，CISA将11个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及Mozilla、VMware、PulseConnect、Atlassian、NETGEAR和Adobe等供应商。

 

0x01 攻击详情

CISA本次新增的11个漏洞都是已知被积极利用的安全漏洞，对企业和组织构成了重大风险，部分漏洞详情如下：

CVE-2022-26486

Mozilla

Mozilla  Firefox Use-After-Free漏洞

Mozilla  Firefox 在 WebGPU IPC 框架中包含一个释放后使用漏洞，可利用该漏洞执行任意代码执行。

2022-03-21

CVE-2022-26485

Mozilla

Mozilla  Firefox Use-After-Free漏洞

Mozilla  Firefox 在 XSLT 参数处理中包含一个释放后使用漏洞，可利用该漏洞执行任意代码执行。

2022-03-21

CVE-2021-21973

VMware

VMware  vCenter Server 和  Cloud Foundation 服务器端请求伪造 (SSRF) 漏洞

由于vCenter Server 插件中的 URL 验证不正确，VMware vCenter Server 和 Cloud Foundation 包含一个 SSRF 漏洞。能够导致信息泄露。

2022-03-21

CVE-2020-8218

Pulse  Secure

Pulse  Connect Secure代码注入漏洞

Pulse  Connect Secure存在代码注入漏洞，攻击者可以利用该漏洞制作 URI 以通过管理 Web 界面执行任意代码执行。

2022-09-07      

CVE-2019-11581

Atlassian

Atlassian  Jira Server 和 Data  Center服务器端模板注入漏洞

Atlassian  Jira Server 和 Data  Center 包含一个服务器端模板注入漏洞，允许远程执行代码。

2022-09-07

CVE-2017-6077

NETGEAR

NETGEAR  DGN2200 远程代码执行漏洞

NETGEAR  DGN2200 无线路由器存在远程代码执行漏洞。

2022-09-07

CVE-2016-6277

NETGEAR

NETGEAR  多个路由器远程代码执行漏洞

NETGEAR多个路由器允许未经认证的网页将表单输入直接传递到命令行界面，从而允许远程代码执行。

2022-09-07

CVE-2013-0631

Adobe

Adobe  ColdFusion 信息泄露漏洞

Adobe  Coldfusion 包含一个未明漏洞，该漏洞可能导致受感染服务器的信息泄露。

2022-09-07

CVE-2013-0629

Adobe

Adobe  ColdFusion 目录遍历漏洞

Adobe  Coldfusion 包含一个目录遍历漏洞，该漏洞可能允许未经授权的用户访问受限目录。

2022-09-07

CVE-2013-0625

Adobe

Adobe  ColdFusion 身份验证绕过漏洞

Adobe  Coldfusion 包含一个身份验证绕过漏洞，该漏洞可能导致未经授权的用户获得管理访问权限。

2022-09-07

CVE-2009-3960

Adobe

Adobe  BlazeDS 信息泄露漏洞

在LifeCycle和Coldfusion中使用的Adobe BlazeDS包含一个信息泄露漏洞。

2022-09-07
