0x00 风险概述

2022年3月3日，CISA将95个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及Microsoft、Adobe、Cisco、Oracle和Apache等供应商和项目。

 

0x01 攻击详情

CISA本次新增的95个漏洞都是已知被积极利用的安全漏洞，对企业和组织构成了重大风险，部分漏洞详情如下：

Apache

Apache  Tomcat权限管理不当漏洞

Apache  Tomcat 将 Apache  JServ 协议 (AJP) 连接视为比类似的 HTTP 连接具有更高的信任度。如果攻击者可以使用此类连接，则可以利用它们。

CVE-2019-1652

Cisco

思科小型企业路由器不正确的输入验证漏洞

Cisco  Small Business RV320 和 RV325 双千兆广域网 VPN 路由器的基于 Web 的管理界面中存在一个漏洞，该漏洞可能允许在受影响设备上拥有管理权限的远程认证攻击者执行任意命令。

2022/3/17

CVE-2019-1297

Microsoft

Microsoft  Excel 远程代码执行漏洞
