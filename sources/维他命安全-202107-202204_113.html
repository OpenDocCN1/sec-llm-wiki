Cisco：利用云服务分发恶意软件的活动分析

Cisco Talos 在 2021 年10 月发现了一个恶意活动，该活动分发可窃取用户信息的 Nanocore、Netwire 和 AsyncRAT 变体。


执行摘要

攻击者越来越多地使用云技术来实现他们的目标，而不必依靠于自己的基础设施。Azure 和 AWS等云服务允许攻击者以最少的时间或金钱建立他们自己的基础设施，并连接到互联网。这使研究人员更难追踪攻击者的行动。

在该案例中，攻击者从2021年10月26日左右开始，使用云服务分发和安装具有信息窃取功能的 RAT 变体。这些远程管理工具 (RAT) 变体具有多种功能，可以控制目标的环境，远程执行任意命令并窃取受害者的信息。

最初的感染媒介是带有恶意 ZIP 附件的钓鱼邮件。这些 ZIP 文件包含一个带有恶意加载程序的 ISO 映像，其形式为 JavaScript、Windows 批处理文件或 Visual Basic 脚本。当在目标设备上执行初始脚本时，会连接到下载服务器来下载下一阶段恶意软件，该恶意软件可以托管在基于 Azure 云的 Windows 服务器或 AWS EC2上。

为了分发恶意软件payload，攻击者使用免费的动态 DNS 服务 DuckDNS 注册了多个恶意子域。与此活动相关的恶意软件家族是Netwire、Nanocore 和 AsyncRAT变种。

研究人员建议组织检查其向云服务发出的连接是否存在恶意流量。这篇文章中描述的活动揭示了越来越多的常见云平台被用于托管恶意基础设施。

Payload

这些活动使用Nanocore、Netwire和AsyncRAT的变体作为payload，它们是被其它恶意活动广泛使用的商用 RAT。

Nanocore

Nanocore 是 32-bit .NET 可移植可执行文件，于 2013 年首次出现。2017 年出现了泄露版本（leaked version）的Nanocore，并被攻击者广泛用于攻击中。

在提取了与此活动相关的 Nanocore 样本中的配置信息后，发现攻击者使用的是 1.2.2.0 版本，这是一个泄露的版本，构建日期为 2021 年 10 月 26 日。使用的 C2 服务器是 mback5338[.]duckdns[.]org，侦听 TCP 端口 7632。构建日期可能与活动的开始时间相关。

Nanocore 变体配置文件

我们还观察到与这些活动相关的不同 Nanocore 客户端样本使用的其他 C2 域和不同端口号：

nanoboss[.]duckdns[.]org

justinalwhitedd554[.]duckdns[.]org

payload中包含的插件是 Client 和 SurveillanceEx。RAT 使用Client插件处理与 C2 服务器的通信，SurveillanceEX 插件可用来捕获视频音频和远程控制桌面。

NetwireRAT

NetwireRAT 是攻击者用来窃取目标密码、登录凭据和信用卡数据的工具。它具有远程执行命令和收集文件系统信息的功能。

此木马通过写入注册表项来建立持久性：

HKEY_CURRENT_USER\Software\NETwIRe\HostId

HKEY_CURRENT_USER\Software\NETwIRe\Install Date

HKEY_CURRENT_USER\SOfttware\Microsoft\WIndows\CurrentVersion\Run\SysWOW32，其值为木马的路径。

AsyncRAT

AsyncRAT 是一种远程访问工具，旨在通过安全的加密连接远程监控并控制计算机。此活动中的攻击者通过将 AsyncRAT 的配置设置为连接到 C2 服务器，来获得对目标计算机的远程访问权限。它还有一些其它功能，如键盘记录、屏幕录像、系统配置管理，从目标设备上窃取数据。

AsyncRAT创建互斥体（mutex ）"AsyncMutex_6SI8OkPnk"作为目标设备中的感染标记。

感染链

感染链始于包含 ZIP 文档的邮件。该ZIP 附件是一个 ISO 映像文件，其中包含 JavaScript、Visual Basic 脚本或 Windows 批处理文件格式的加载程序。该邮件伪装成发票来诱惑收件人。

JAVASCRIPT DOWNLOADER

 JavaScript downloader是一个混淆脚本，有四层混淆。每一阶段都会进行去混淆过程，下一阶段作为前一阶段去混淆函数的结果生成。

第一层去混淆

第一级解密由函数“ejv()”执行，该函数将混淆数据的每个字符迭代到一个数组中，并执行一些算术运算来解密字符并返回去混淆结果。

去混淆过程的结果包含另一个解密函数'Ox$()'，它是第三层解密函数。

POWERSHELL DROPPER

PowerShell droppers

攻击目标

根据此次活动的恶意子域的 DNS 请求分布情况，目标主要来自美国、加拿大、意大利和新加坡的，还有部分来自西班牙和韩国的。


结论

在这篇文章中，描述了攻击者在恶意活动中积极使用云服务的活动。最初的感染媒介主要是带有恶意 Zip 附件的钓鱼邮件。尽管这是最古老的感染媒介之一，但电子邮件仍然是需要保护的重要感染途径。

ZIP 文件包含一个 ISO 映像文件，其中包含恶意的混淆下载程序。这些活动的payload是 Nanocore、Netwire和 AsyncRAT。RAT payload使用 DuckDNS.org 动态 DNS 服务器，因此它们可以定期更改 C2 服务器的 IP 地址并快速添加新的子域。

还发现了一个由 HCrypt 构建器构建的混淆 PowerShell dropper 脚本，该脚本与该活动的下载服务器相关联。

组织应部署全面的多层安全控制，以检测类似威胁并保护其资产。安全人员应监控其组织的流量，并围绕其计算机上的脚本执行策略实施强大的规则。对于组织而言，应提高邮件安全性以检测和缓解恶意邮件，并尽早破坏感染链。
