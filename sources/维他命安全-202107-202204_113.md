# Cisco：利用云服务分发恶意软件的活动分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247498660&idx=2&sn=4ef903442864f1cac5bed354b3afb34e&chksm=f901b135ce763823944cdae10bf45308e5ccd222f951ceafd3bb5f8a341e563a69a13d1d40af&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247498660&idx=2&sn=4ef903442864f1cac5bed354b3afb34e&chksm=f901b135ce763823944cdae10bf45308e5ccd222f951ceafd3bb5f8a341e563a69a13d1d40af&scene=27#wechat_redirect)

Cisco Talos 在 2021 年10 月发现了一个恶意活动，该活动分发可窃取用户信息的 Nanocore、Netwire 和 AsyncRAT 变体。

###   

### **执行摘要**

攻击者越来越多地使用云技术来实现他们的目标，而不必依靠于自己的基础设施。Azure 和 AWS等云服务允许攻击者以最少的时间或金钱建立他们自己的基础设施，并连接到互联网。这使研究人员更难追踪攻击者的行动。

在该案例中，攻击者从2021年10月26日左右开始，使用云服务分发和安装具有信息窃取功能的 RAT 变体。这些远程管理工具 (RAT) 变体具有多种功能，可以控制目标的环境，远程执行任意命令并窃取受害者的信息。

最初的感染媒介是带有恶意 ZIP 附件的钓鱼邮件。这些 ZIP 文件包含一个带有恶意加载程序的 ISO 映像，其形式为 JavaScript、Windows 批处理文件或 Visual Basic 脚本。当在目标设备上执行初始脚本时，会连接到下载服务器来下载下一阶段恶意软件，该恶意软件可以托管在基于 Azure 云的 Windows 服务器或 AWS EC2上。

为了分发恶意软件payload，攻击者使用免费的动态 DNS 服务 DuckDNS 注册了多个恶意子域。与此活动相关的恶意软件家族是Netwire、Nanocore 和 AsyncRAT变种。

研究人员建议组织检查其向云服务发出的连接是否存在恶意流量。这篇文章中描述的活动揭示了越来越多的常见云平台被用于托管恶意基础设施。

### **Payload**

这些活动使用Nanocore、Netwire和AsyncRAT的变体作为payload，它们是被其它恶意活动广泛使用的商用 RAT。

**Nanocore**

Nanocore 是 32-bit .NET 可移植可执行文件，于 2013 年首次出现。2017 年出现了泄露版本（leaked version）的Nanocore，并被攻击者广泛用于攻击中。

在提取了与此活动相关的 Nanocore 样本中的配置信息后，发现攻击者使用的是 1.2.2.0 版本，这是一个泄露的版本，构建日期为 2021 年 10 月 26 日。使用的 C2 服务器是 mback5338\[.\]duckdns\[.\]org，侦听 TCP 端口 7632。构建日期可能与活动的开始时间相关。

![](../Images/0f8a1474ea8d4d233a3b07163e29c1e8.png)

***Nanocore 变体配置文件***

我们还观察到与这些活动相关的不同 Nanocore 客户端样本使用的其他 C2 域和不同端口号：

nanoboss\[.\]duckdns\[.\]org

justinalwhitedd554\[.\]duckdns\[.\]org

payload中包含的插件是 Client 和 SurveillanceEx。RAT 使用Client插件处理与 C2 服务器的通信，SurveillanceEX 插件可用来捕获视频音频和远程控制桌面。

**NetwireRAT**

NetwireRAT 是攻击者用来窃取目标密码、登录凭据和信用卡数据的工具。它具有远程执行命令和收集文件系统信息的功能。

此木马通过写入注册表项来建立持久性：

HKEY\_CURRENT\_USER\\Software\\NETwIRe\\HostId

HKEY\_CURRENT\_USER\\Software\\NETwIRe\\Install Date

HKEY\_CURRENT\_USER\\SOfttware\\Microsoft\\WIndows\\CurrentVersion\\Run\\SysWOW32，其值为木马的路径。

**AsyncRAT**

AsyncRAT 是一种远程访问工具，旨在通过安全的加密连接远程监控并控制计算机。此活动中的攻击者通过将 AsyncRAT 的配置设置为连接到 C2 服务器，来获得对目标计算机的远程访问权限。它还有一些其它功能，如键盘记录、屏幕录像、系统配置管理，从目标设备上窃取数据。

AsyncRAT创建互斥体（mutex ）"AsyncMutex\_6SI8OkPnk"作为目标设备中的感染标记。

![](../Images/236c6a0464f68c0b44842696adb365f8.png)

***AsyncRAT 变体互斥函数***

AsyncRAT 配置文件被解密并包含 C2 域等配置信息。在本例中，C2 域是 asyncmoney\[.\]duckdns\[.\]org，使用 TCP 端口 7829。我们观察到AsyncRAT 的这种变体通过 TCP 端口 7840、7841 和 7842 与 C2 域通信。

![](../Images/5c510449375f6495ddb50a462f67947f.png)

***AsyncRAT 变体 C2 连接参数***

 

### **感染链**

感染链始于包含 ZIP 文档的邮件。该ZIP 附件是一个 ISO 映像文件，其中包含 JavaScript、Visual Basic 脚本或 Windows 批处理文件格式的加载程序。该邮件伪装成发票来诱惑收件人。

![](../Images/708f55b6afc53b190754578ae2ac9efe.png)

***网络钓鱼电子邮件示例***

ZIP 文件名的前几个字符是随机生成的，可能是针对活动的。观察到的一些ZIP文件名是：

WROOT\_Invoice\_Copy.zip

YUEOP\_Invoice\_Copy.zip

HOO8M\_Invoice\_Copy.zip

TROOS\_Invoice\_Copy.zip

TBROO1\_Invoice\_Copy.zip

**JAVASCRIPT DOWNLOADER**

 JavaScript downloader是一个混淆脚本，有四层混淆。每一阶段都会进行去混淆过程，下一阶段作为前一阶段去混淆函数的结果生成。

**第一层去混淆**

第一级解密由函数“ejv()”执行，该函数将混淆数据的每个字符迭代到一个数组中，并执行一些算术运算来解密字符并返回去混淆结果。

![](../Images/9d79ca97de8ebba8fc95c3aa8dc95de0.png)

***一级解密函数***

函数“ejv()”生成第二阶段解密程序。

![](../Images/6c9a015a838124ce3de19c391319db5d.png)

***二级解密函数***

**第二层去混淆**

JavaScript下载程序加密内容的其余部分在第二层去混淆过程中分为两个子阶段解密。首先，它由解密函数'ejv()'解密，然后将结果传递给第二级解密函数。

去混淆过程的结果包含另一个解密函数'Ox$()'，它是第三层解密函数。

![](../Images/c8bfe59f47b7dc1a7ba9ba94d53ce6c4.png)

***三级解密函数***

 

**第三层去混淆**

第二层去混淆过程的加密字符串由'Ox$()'函数解密。第三层去混淆过程的解密结果是另一个被混淆的函数，该函数有多个函数调用返回值，一系列eval()函数调用第三级解密函数'Ox$()'来解密下载程序代码。

![](../Images/8eaaa719068f0648de92b787be5355ab.png)

***混淆的下载程序代码***

在分析此活动的另一个 JavaScript 下载程序样本时，我们观察到与第三阶段去混淆过程略有不同的结果。代码很可能是自动生成和随机化的，这使检测过程更加困难。

![](../Images/49bb40ae901d3e16fcb346f64048db8e.png)

***混淆的恶意下载器代码***

**第四层去混淆**

恶意下载程序代码去混淆的最后阶段在第四层执行，借助第三级解密函数及其代码中的一些自解密逻辑。我们观察到第四层解密代码不仅仅是一个下载程序——它还执行其他活动，例如：

配置登录自启动注册表项“HKEY\_CURRENT\_USER\\Software\\Microsoft\\Windows\\CurrentVersion\\Run”以建立持久性。

通过调用schtasks.exe 进程配置计划任务作业。

![](../Images/09ca658808f89bde000a71e03fb383c1.png)

使用 URL http://gg1592661\[.\]duckdns\[.\]org:7924/vre 从下载服务器下载payload。此次活动下载的payload是 Netwire、Nanocore 和AsyncRAT，在目标计算机的用户临时文件夹中保存和执行。

该脚本尝试与备用数据流交互，以隐藏从 Internet 下载的有关其来源的信息。

从注册表项 HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\ProductId收集信息对目标计算机进行指纹识别。

除了 JavaScript 加载程序，还观察到了 Batch 文件下载程序和 VBScript 下载程序。

**Batch****文件下载程序**

包含一个模糊命令，该命令运行 PowerShell 以从下载服务器下载和运行payload，在本例中为 Azure Cloud 上的 13\[.\]78\[.\]209\[.\]105。

![](../Images/707076d25bf343a06ad509836c329947.png)

***Batch 文件下载程序***

**VBSCRIPT****下载程序**

混淆的 VB 下载程序会执行一个 PowerShell 命令，该命令运行并连接到下载服务器，例如，连接到 AWS EC2 上运行的 52\[.\]27\[.\]15\[.\]250。

![](../Images/6aabe3f4a3406c2ef1a4e7a6ae2c310f.png)

***VBScript 木马下载程序***

**POWERSHELL DROPPER**

在对 Azure 中下载服务器的调查发现了一个似乎是使用 HCrypt builder 构建的 PowerShell dropper 脚本。该脚本在目标计算机中安装并运行AsyncRAT变体。TrendMicro 研究人员在另一个名为“ Water Basilisk ”的活动中发现了类似的 PowersSell droppers。

![](../Images/7b095adf1ee25853312a78c524a1101d.png)

***PowerShell droppers***  

去混淆的二进制文件是使用字符串替换函数构造的，用数字 0 替换所有出现的分隔符。这个包含payload的字符串，连同一个包含注入器 .NET 程序集 DLL 模块的字符串，被传递给函数 H2，它将其转换为二进制字节数组。从那里开始，生成的字节数组作为组装模块加载并用于注入payload。

![](../Images/26e8b6e6f2489bb76fe8297d18e1162d.png)

***去混淆的注入程序***

![](../Images/0fbcfb91d7a839f7994ee05db63c9f9c.png)

***去混淆的 PowerShell 加载程序命令***

该脚本尝试在目标计算机上启动进程 aspnet\_compiler.exe，注入 AsyncRAT payload，并调用线程来运行payload。在本例中，payload的 C2 服务器是 yuri101\[.\]duckdns\[.\]org，托管在 IP 地址 64\[.\]188\[.\]16\[.\]134 上。

### **攻击者基础设施**

该活动中的攻击者使用了一个分布式基础架构，其中包括下载服务器、命令和控制服务器以及恶意子域。下载服务器托管在 Microsoft Azure 和 AWS 云服务上。我们在 Azure Cloud 上发现了 Windows 实例，其 IP 地址如下所示：

23\[.\]102\[.\]1\[.\]5位于NorthEurope 云区域，并启用了 SMB 身份验证。

40\[.\]85\[.\]140\[.\]7位于NorthEurope云区域。

13\[.\]82\[.\]65\[.\]56 位于East US云区域。

137\[.\]135\[.\]65\[.\]29 位于East US地区，FQDN 为“sj-2nd”，并启用了SMB 身份验证。

我们发现的另一台服务器托管在 AWS 云上，IP 地址为52\[.\]27\[.\]15\[.\]250，FQDN 为 ec2-52-27-15-250.us-west-2.compute.amazonaws.com。我们不确定此实例的操作系统。

一些下载服务器正在运行 Apache Web 服务器应用程序，HTTP 服务器配置为允许列出包含 NanocoreRAT、Netwire RAT 和 AsyncRAT 恶意软件变种的开放目录。

### **攻击目标**

根据此次活动的恶意子域的 DNS 请求分布情况，目标主要来自美国、加拿大、意大利和新加坡的，还有部分来自西班牙和韩国的。

###   

### **结论**

在这篇文章中，描述了攻击者在恶意活动中积极使用云服务的活动。最初的感染媒介主要是带有恶意 Zip 附件的钓鱼邮件。尽管这是最古老的感染媒介之一，但电子邮件仍然是需要保护的重要感染途径。

ZIP 文件包含一个 ISO 映像文件，其中包含恶意的混淆下载程序。这些活动的payload是 Nanocore、Netwire和 AsyncRAT。RAT payload使用 DuckDNS.org 动态 DNS 服务器，因此它们可以定期更改 C2 服务器的 IP 地址并快速添加新的子域。

还发现了一个由 HCrypt 构建器构建的混淆 PowerShell dropper 脚本，该脚本与该活动的下载服务器相关联。

组织应部署全面的多层安全控制，以检测类似威胁并保护其资产。安全人员应监控其组织的流量，并围绕其计算机上的脚本执行策略实施强大的规则。对于组织而言，应提高邮件安全性以检测和缓解恶意邮件，并尽早破坏感染链。
