0x00 风险概述

2022年1月18日，CISA将13个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及node.js、BIG-IP、Nagios XI、Microsoft Exchange Server、Apache Airflow和Drupal等。

 

0x01 攻击详情

CISA本次新增的13个漏洞都是已知被积极利用的安全漏洞，对企业和组织构成了重大风险，13个漏洞如下：

 

部分漏洞详情如下：

CVE-2021-32648：Octobercms验证不当漏洞

Octobercms是一个基于Laravel PHP框架的CMS平台。在october/system包版本1.0.471和1.1.1中，攻击者可以请求重置账户密码，然后使用特制请求访问该账户。该漏洞的CVSSv3评分为9.1,目前已在1.0.472、1.1.5中修复。

参考链接：

https://github.com/octobercms/october/security/advisories/GHSA-mxr5-mc97-63rc

 

CVE-2021-21315：System Information Library for node.js命令注入漏洞

Node.JS的系统信息库（npm包 "systeminformation"）是一个开源的函数集合，用于检索详细的硬件、系统和操作系统信息。在5.3.1版本之前的systeminformation中，存在一个命令注入漏洞，其CVSSv3评分为7.8。该漏洞已在5.3.1版本中修复。

参考链接:

https://security.netapp.com/advisory/ntap-20210312-0007/

 

CVE-2021-21975：vRealize Operations Manager API中的服务器端请求伪造

8.4版本之前的vRealize Operations Manager API中存在服务器端请求伪造漏洞（CVE-2021-21975），能够网络访问vRealize Operations Manager API的攻击者能够利用此漏洞窃取管理凭据。该漏洞的CVSSv3评分最高为8.6。

参考链接:

https://www.vmware.com/security/advisories/VMSA-2021-0004.html

 

CVE-2021-22991：BIG-IP Traffic Microkernel缓冲区溢出漏洞

F5BIG-IP 16.0.x（16.0.1.1之前）、15.1.x（15.1.2.1之前）、14.1.x（14.1.4之前）、13.1.x（13.1.3.6之前）和12.1.x（12.1.5.3之前）版本中，流量管理微内核（TMM）URI规范化可能会不正确地处理对虚拟服务器的未公开请求，这可能会触发缓冲区溢出，从而导致DoS攻击。在某些情况下，理论上它可能允许绕过基于URL的访问控制或远程代码执行（RCE），该漏洞的CVSSv3评分为9.8。注：不包含已达到软件开发结束（EoSD）的软件版本。

参考链接:

https://support.f5.com/csp/article/K56715231

CVE-2021-25296：Nagios XI OS命令注入漏洞

Nagios XI xi-5.7.5版本存在OS命令注入漏洞。该漏洞存在于文件/usr/local/nagiosxi/html/includes/configwizards/windowswmi/windowswmi.inc.php中，原因是单个 HTTP 请求对经过身份验证的用户控制输入进行了不当清理，这可能导致Nagios XI服务器上的系统命令注入。该漏洞的CVSSv3评分为8.8。

参考链接：

https://github.com/fs0c-sh/nagios-xi-5.7.5-bugs/blob/main/README.md

 

CVE-2020-11978：Apache Airflow命令注入漏洞

Apache Airflow 1.10.10及更低版本中存在一个命令注入漏洞，允许任何认证用户作为运行airflow worker/scheduler（取决于使用的执行器）的用户运行任意命令。可以通过在配置中设置load_examples=False来修复此漏洞。

参考链接：

https://lists.apache.org/thread/cn57zwylxsnzjyjztwqxpmly0x9q5ljx

 

CVE-2020-13671：Drupal 文件上传漏洞

Drupal核心没有正确处理上传文件的某些文件名，这可能导致文件被解释为不正确的扩展名，并作为错误的MIME类型，或者在某些主机配置中作为PHP执行。该漏洞影响9.0.8之前的Drupal Core 9.0版本，8.9.9之前的8.9版本，8.8.11之前的8.8版本，以及7.74之前的7版本。

参考链接：

https://www.drupal.org/sa-core-2020-012
