0x00 风险概述

近日，Claroty发布了一份检查 URL 解析库安全性的研究报告。该报告披露了16 个不同 URL 解析库之间的不一致而导致的 8 个安全漏洞，这些漏洞可能导致各种Web 应用程序中的拒绝服务 (DoS) 、信息泄漏和远程代码执行 (RCE)。

 

0x01 攻击详情

研究人员检查的 16 个不同的URL 解析库包括：urllib(Python)、urllib3 (Python)、rfc3986(Python)、httptools (Python)、curllib (cURL)、Wget、Chrome(Browser)、Uri (.NET)、URL (Java)、 URI (Java)、parse_url (PHP)、url (NodeJS)、url-parse (NodeJS)、net/url (Go)、uri (Ruby) 和 URI (Perl)。

在研究过程中，研究人员发现这些库在解析组件时存在五类不一致的地方：

  • 方案混淆：涉及缺少或格式错误的方案的 URL 的混淆。

  • 斜杠混淆：涉及包含不规则斜杠数量的 URL 的混淆。

  • 反斜杠混淆：涉及包含反斜杠 (\) 的 URL 的混淆。

  • URL编码数据混淆：涉及包含 URL 编码数据的 URL 的混淆。

  • 方案混淆：涉及在没有特定方案解析器的情况下解析属于某个方案的 URL 的混淆。

在真实攻击场景中，斜杠混淆可能导致服务器端请求伪造 (SSRF) ，这可用于实现 RCE。通过检查第三方 Web 应用程序，研究人员发现了8个由URL 解析混淆导致的安全漏洞：

  • Flask-security 开放重定向 (Python, CVE-2021-23385)

  • Flask-security-too开放重定向(Python, CVE-2021-32618)

  • Flask-User开放重定向(Python, CVE-2021-23401)

  • Flask-unchained开放重定向(Python, CVE-2021-23393)

  • Belledonne SIP堆栈空指针解读(DoS) (C, CVE-2021-33056)

  • Video.js 跨站脚本 (XSS) (JavaScript,CVE-2021-23414)

  • Nagios XI 开放重定向(PHP, CVE-2021-37352)

  • Clearance开放重定向 (Ruby, CVE-2021-23435)

开放重定向漏洞很容易被利用，因为它们可以被用于欺骗、网络钓鱼和中间人攻击 (MITM)。开放式重定向攻击通常通过验证来阻止：Web 服务器验证给定的 URL，并且只允许属于同一站点或受信任域列表的 URL。URL 库混淆会干扰正确的验证，并导致RCE、SSRF和开放重定向等多种漏洞。

 

0x02 风险等级

高危。


0x03 影响范围

  • CVE-2021-23385：暂未公开

  • CVE-2021-32618：Flask-Security-Too的所有版本

  • CVE-2021-23401：Flask-User 的所有版本

  • CVE-2021-23393：0.9.0 之前的Flask-Unchained包

  • CVE-2021-33056：4.5.20 之前的 Belledonne Belle-sip

  • CVE-2021-23414：7.14.3 之前的video.js包

  • CVE-2021-37352：5.8.5 之前的NagiosXI版本

  • CVE-2021-23435：2.5.0 之前的Clearance包

更多详情请参考Claroty发布的报告或CVE官网：

0x04 安全建议

目前，除了不受支持的 Flask 版本中发现的漏洞之外，所有漏洞都已经修复，建议相关开发人员及时升级更新。
