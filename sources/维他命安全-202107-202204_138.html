摘要

供应链是攻击者的常见目标，因为控制供应链中的薄弱环节可以让攻击者感染更多的目标——尤其是当薄弱环节是供应链的源头时。最近，发现新的供应链攻击利用云视频平台分发skimmer（又名表单劫持）。在skimmer分发活动中，攻击者注入恶意 JavaScript 代码来入侵网站，并接管网站 HTML 表单以收集敏感的用户信息。在此处描述的攻击案例中，攻击者将 Skimmer JavaScript 代码注入视频中，因此每当其他人导入视频时，他们的网站也会注入 Skimmer 代码。
通过 Palo Alto Networks 的主动监控和检测服务，共检测到 100 多个受到相同skimmer攻击的房地产网站。经过对被入侵网站的分析后，发现所有网站都属于一家母公司，它们都从云视频平台导入相同的视频（带有恶意脚本）。
研究人员已与云视频平台和房地产公司合作，帮助他们删除恶意软件。这篇文章是为了提醒组织和用户，供应链攻击有可能在这些组织不知情的情况下感染合法网站。此博客将逐步了解此攻击是如何安装恶意软件，以及skimmer如何窃取受害者的敏感信息。

视频中的恶意代码

攻击者如何将恶意代码注入云视频平台的播放器？当云平台用户创建播放器时，可以上传一个JavaScript文件来添加他们自己的自定义JavaScript。在本例中，用户上传了一个脚本，该脚本可以篡改上游来注入恶意代码。
因此推断攻击者通过使用skimmer代码在其托管位置篡改了静态脚本。在下一次播放器更新时，视频平台重新提取受感染的文件，并将其与播放器一起提供。

结论

在这次skimmer活动中，从skimmer脚本到云视频平台源头追踪了此次恶意活动，还深入研究了该活动中的代码。
skimmer本身是多态的，难以捉摸并且不断发展。当与云分发平台结合使用时，这种类型的skimmer的影响可能非常大。因此，此类攻击增加了安全研究人员的风险，他们需要解开复杂的策略，并追踪到根本原因。所以必须发明更复杂的策略来检测这种类型的skimmer活动，因为仅仅阻止skimmer使用的域名或 URL 是无效的。
对于网站管理员来说，最好保护好所有账户，避免其在网络钓鱼或社会工程中被盗，并做好权限管理。此外，强烈建议您定期进行 Web 内容完整性检查，这有助于检测和防止网站被注入恶意代码。
