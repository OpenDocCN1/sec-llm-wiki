0x01 漏洞详情

MinIO是基于Apache License v2.0发布的一款开源对象存储服务器，专为AI等云原生工作负载而设计，并友好支持Kubernetes。

2021年12月28日，MinIO官方发布安全公告，修复了MinIO中的一个权限提升漏洞（CVE-2021-43858），该漏洞的CVSSv3评分为8.8。

MinIO AddUser() admin API 主要用于创建用户或更新用户密码。由于其代码实现存在安全问题，AddUser() API接受"policy"字段，攻击者可以通过手工制作HTTP API调用以更新用户策略并实现权限提升。

但攻击者需要事先了解Admin API调用才能利用此漏洞，并且必须具有访问MinIO服务的有效凭据。

 

影响范围

MinIO版本< RELEASE.2021-12-27T07-23-18Z

 

0x02 处置建议

目前此漏洞已经修复，建议受影响用户及时升级更新至MinIO RELEASE.2021-12-27T07-23-18Z版本。

下载链接：

https://github.com/minio/minio/releases/tag/RELEASE.2021-12-27T07-23-18Z

注：版本RELEASE.2021-12-27T07-23-18Z中的补丁更改了接受的请求主体类型，并删除了通过该API应用策略更改的能力（任何策略更改只允许使用 Policy 'set' API 调用）。

缓解措施：

可以通过添加Deny规则来禁用用户的API，从而禁用更改密码。
