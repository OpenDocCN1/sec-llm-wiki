Microsoft：Qakbot的技术分析

多个 Qakbot 活动证明，这种已有十年历史的恶意软件仍然是许多攻击者的首选工具，它是一种可定制的工具，可以满足不同黑客团伙的需求。自 2007 年作为银行木马出现以来，Qakbot 已发展成为一种多用途恶意软件，可为攻击者提供广泛的功能：执行侦察和横向移动、收集和泄露数据，或在受影响的设备上传送其它payload。

Qakbot的模块化特性使它能够在当今的计算环境中持续存在，攻击者能够根据恶意软件所在的网络环境为每个攻击链（attack chain）挑选合适的“构建块（building blocks）”。在许多情况下，使用 Qakbot 的攻击者还会把被黑设备的访问权出售给其他攻击者，后者利用这些访问权发动攻击。例如，众所周知，Qakbot 感染会导致感染勒索软件，包括 Egregor 或 Conti。因此，其影响是深远的，根据Microsoft威胁数据，最近在几乎所有大陆的几个国家和地区都可以看到 Qakbot 活动：非洲、亚洲、欧洲和美洲。
Qakbot 的模块化和灵活性可能给安全分析师带来挑战，因为同时发生的 Qakbot 活动在每个设备上看起来可能截然不同，从而影响了这些防御者如何应对此类攻击。因此，更深入地了解 Qakbot 对于针对它制定全面协调的防御策略至关重要。
根据对最近的3个 Qakbot 活动的研究和分析，将 Qakbot 攻击链分解为几个不同的构建块。在每个活动中，有些构建模块是一致的，尽管不是所有的都将被观察到。了解这些详细信息可以让防御者正确识别相关威胁和攻击，也融入了Microsoft 的多层保护技术，例如通过 Microsoft 365 Defender技术，在攻击链的各个阶段检测和阻止这些威胁。
这篇文章提供了构成 Qakbot 活动的每个构建块的技术细节。它还包括缓解建议等，以帮助防御者主动发现这种威胁。

分解 Qakbot 活动
与其它模块化恶意软件一样，Qakbot 在每个被感染的设备上可能会有所不同，具体取决于使用恶意软件的运营团伙及其对攻击活动的部署。但是，根据分析，可以将与 Qakbot 相关的事件分解为一组不同的“构建块”，这可以帮助安全分析师识别和响应 Qakbot 活动。下面的图 1 代表了这些构建块。根据观察，每个 Qakbot 攻击链只能有一个颜色的模块。第一行和Macro块代表用于分发 Qakbot 的电子邮件机制。
图 1. Qakbot 攻击链的构建块

研究人员确定了10个构建块，并将在接下来的部分中讨论。

第一部分：电子邮件分发

Qakbot 通过以下3种方法分发：恶意链接、恶意附件或嵌入图像。
这些邮件活动中的消息通常包含一两句话的诱饵（例如，“请参阅附件”或“单击此处查看文件”）。这种简洁的风格为目标用户提供了足够的信息且具有号召性，还可以绕过内容安全解决方案的检测。

图 3. Qakbot活动的邮件示例

恶意链接

分发 Qakbot 的邮件通常在正文中包含下载恶意软件的 URL。今年早些时候，研究人员开始观察到其中一些 URL 缺少 HTTP 或 HTTPS 协议，导致它们在大多数电子邮件客户端中无法直接打开。因此，要想下载恶意软件，目标收件人必须手动将链接输入浏览器。

图 4. 包含不可点击的 URL 和虚假回复诱饵的 Qakbot 活动电子邮件示例
尽管这种方式对一些通过沙箱检测恶意链接的电子邮件安全解决方案构成了挑战，但复制和粘贴 URL 所需的额外步骤降低了此类攻击的成功率。还应该注意的是，这些邮件有时格式不完整，它们通过使用虚假回复诱饵在内容中进行弥补。
这种虚假回复技术在之前的 Qakbot 和其它主要的恶意软件传播活动中已经出现，它使用窃取的主题和消息内容来构建恶意回复，作为先前电子邮件对话的一部分出现。Qakbot 还会重用从先前活动中窃取的电子邮件来为其下一次攻击活动创建新模板，允许攻击者使用真实的主题行和消息内容来构建欺骗性回复，这增加了目标用户点击或复制粘贴链接的可能性。同时，攻击者可以从邮件中不断增长的信息熵中受益，因为在同一攻击活动中，不会有两封相同的电子邮件。不幸的是，这种信息熵也使安全分析师和防御者更难以确定活动范围。

恶意附件

攻击者发送的一些与 Qakbot 相关的电子邮件可能包含 ZIP 附件，ZIP 中会有 Excel 4.0 宏的电子表格。
附件名称会让它看起来像正式的公司文件，以欺骗目标收件人打开它。例如，在今年 9 月至 11 月期检测到的附件命名模式包括但不限于以下内容：
  • CMPL-[digits]-[month]-[day].zip
  • Compensation_Reject-[digits]-[mmddyyyy].zip
  • Document_[digits]-[mmddyyyy].zip
  • Document_[digits]-Copy.zip
  • PRMS-[digits].zip
  • Rebate-[digits]-[mmddyyyy].zip
  • REF-[digits]-[month]-[day].zip
  • TXN-[digits].zip

图 5.  Qakbot 活动中电子邮件的 ZIP 附件示例

嵌入图像

在其第三次也是最近一次的演变中，Qakbot 通过一封电子邮件发送信息，在其正文中仅包含一张嵌入图像，这与其以前使用文件附件或超链接的分发机制形成鲜明对比。研究人员在调查与电子邮件相关的Excel恶意文件感染时发现了Qakbot活动，这些电子邮件滥用Craigslist的电子邮件消息系统来传播恶意文件——这是INKY首先报告的一种惯例。
与之前的 Qakbot 电子邮件活动相比，该活动的参与度更高，因为与之前的分发方法不同，电子邮件中的恶意组件（在本例中为恶意 URL）并非以文本形式存在于邮件正文中，而是包含在看起来像消息主体的图像中。该图像要求收件人直接在浏览器中输入 URL 以下载最终指向 Qakbot 的 Excel 文件。
该图片是伪造成自动的 Craigslist 通知的文本屏幕截图，并通知目标收件人其 Craigslist 发布的内容违反政策。这个虚假通知进一步指示用户在浏览器中输入 URL以获取更详细的信息，如果他们不关注，则威胁要删除他们的帐户。

图 6. 带有嵌入图像的 Craigslist 电子邮件示例
攻击者收集 Craigslist 广告帖子以获取电子邮件中继地址，然后直接发送定制的信息。电子邮件中继会接收发送的消息，并删除个人数据(包括发件人的实际电子邮件地址)，将原始邮件细节附加到邮件的末尾，然后通过Craigslist基础设施转发它，以掩盖原始发件人。因此，广告所有者将收到一封来自合法的craigslist.org域名的匿名电子邮件。
攻击利用电子邮件中继系统来匿名并冒充 Craigslist。它还增加了邮件的合法性，因为它来自一个传统安全解决方案认为是安全的域名。
根据观察，此电子邮件活动回复了与工作相关的广告，这可能是攻击者试图针对那些在公司网络中打开此类邮件的收件人。但是，根据威胁数据，用户访问相关恶意域的成功率相对较低。这样的结果很可能是因为该活动需要目标收件人额外输入 URL。

第二部分：启用宏

尽管攻击者分发 Qakbot 的电子邮件方法各不相同，但这些活动的共同点是在 Office 文档中使用恶意宏，特别是 Excel 4.0 宏。值得注意的是，虽然活动试图使用 Excel 4.0 宏绕过检测，但此功能现在默认禁用，因此需要用户手动启用它才能执行恶意操作。
一旦用户下载并打开恶意 Excel 文件，文档中的文本就会试图引诱他们启用宏。下图中的文本声称该文件受到 Microsoft 或 DocuSign 等服务的保护，并且用户必须启用宏才能查看文档的内容。

图 7. 带有 DocuSign 诱饵的 XLS 文件诱使目标启用宏
如果用户启用宏，Excel 会立即检查宏中是否有预定义的子进程，以便在文档打开后自动运行；在本样本中是     auto_open()。在此进程中编写的Visual Basic for Applications (VBA) 代码会创建一个新的宏表，然后在其多个单元格中写入 Excel 4.0 公式。接下来，它通过调用 Application.Run 方法跳转到此工作表中的一个单元格。这样，VBA 代码就会启动刚刚写入宏表的 Excel 4.0 宏代码。

图 8. VBA 脚本生成的 Excel 4.0 宏示例
从 VBA 生成和调用 Excel 4.0 宏是一种绕过静态分析工具解码宏的技术。当用户关闭文档时，auto_close() 函数就会启动来清理和删除由 VBA 宏创建的恶意宏表。

第三部分：Qakbot 分发

一旦启用宏，攻击的下一阶段就开始了。首先，恶意宏会连接到一组预定义的 IP 地址或域名，来下载恶意文件。某些宏可以同时连接3个域，下载同名文件。这样做可能是出于以下两个原因之一：首先，作为一种冗余措施，以确保即使其中的一个或两个域被删除或关闭后，恶意软件仍能正常分发；其次，如果需要，攻击者能分发多个payload。

图 9. 生成的 Excel 4.0 宏的一部分，它尝试从3个地址下载3个payload
在大多数情况下，下载的文件是一个便携式可执行 (PE) 文件，使用 .htm 或 .dat 文件扩展名重命名，以绕过阻止某些文件类型的 Web 过滤系统。根据不同的活动，这些文件的命名方式差异很大。例如，最近使用 .htm 文件的活动以简单的字母和数字命名，例如 goh[1].htm 或 j[1].htm。但是，使用发票主题并使用 .dat 文件的活动会使用极长的数字字符串命名它们，例如 44494.4409064815[1].dat。同样，这些活动与活动之间的差异凸显了Qakbot 在被不同的攻击者，这会使同一恶意软件的活动看起来截然不同。
一旦将该文件下载到设备上，该文件立即被重命名为另一个不存在扩展名，例如test.test 和 good.good（源自 .htm 文件），或 GiCelod.waGic 和 Celod.wac（源自 .dat 文件）。在许多涉及 .htm 文件的案例中，会创建一个名为 C:\Datop 的文件夹，并将文件保存在该位置。同时，带有 .dat 文件会保存在 C:\Users\AppData\Local\Temp 。

ping.exe 用于复制数十个电子邮件文件并将它们保存在“Email Storage”文件夹中。这些电子邮件消息以顺序命名模式保存，从 1.eml 开始，并随着攻击者复制的电子邮件消息递增 1。现在已经确定攻击者从单个设备复制了 100 多封邮件。
一旦成功窃取电子邮件文件，就会通过 rmdir 命令删除“Email Storage”文件夹来删除攻击证据。

第八部分：其它payload、横向移动和勒索软件

与当今许多恶意软件变体的情况一样，将 Qakbot 安装到目标设备上通常只是更大攻击的第一步。攻击者可以使用 Qakbot 感染的访问权限来分发额外的payload，或将访问权限出售给其它攻击者。
在许多情况下，攻击者会使用在攻击早期阶段获得的凭据在整个网络中横向移动，从而扩大攻击范围。有时，攻击者会使用 Windows Management Instrumentation (WMI) 横向移动并在新访问的设备上安装恶意 DLL。然后，攻击者将进行他们在初始访问设备上所做过的事，执行一系列侦察命令，并进一步窃取凭据。
在另一种情况下，攻击者会同时安装其它恶意文件与恶意 DLL。例如，在安装恶意 DLL 之前，会安装一些用于关闭目标设备上安全工具的 BAT 文件。攻击链中的这些细微差异证明了多个攻击者在使用 Qakbot 进行横向移动。
除了横向移动之外，攻击者还经常在目标设备上分发其它payload，尤其是 Cobalt Strike。Qakbot 有一个 Cobalt Strike 模块，购买感染 Qakbot 的设备的攻击者也可能会安装他们自己的 Cobalt Strike beacons和其它payload。使用 Cobalt Strike 可以让攻击者手动访问被入侵的设备，并能够进行额外的侦察活动、在网络上寻找高价值目标、横向移动并分发额外的payload，尤其是人为运营的勒索软件变种，例如Conti和Egregor。
