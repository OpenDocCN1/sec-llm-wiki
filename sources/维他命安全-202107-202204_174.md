**0x00 风险概述**

2021年12月10日，CISA将13个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及Apache、Zoho、Fortinet、Realtek、Linux Kernel、MongoDB和Red Hat等。

 

### **0x01 攻击详情**

![](../Images/56b732e91fc4f42d86c5845e9f1691d0.png)

  

CISA本次新增的13个漏洞是正在被积极利用的安全漏洞，对企业和组织构成了重大风险。漏洞详情如下：

![](../Images/be24fcf6503584660a74fba6bf1cd756.png)

其中最为严重的漏洞包括但不限于：  

**Apache Log4j2 ****远程代码执行漏洞（CVE-2021-44228**）

Apache Log4j2 <=2.15.rc1中存在Java JNDI注入漏洞，成功利用此漏洞可以在目标服务器上执行任意代码。该漏洞的CVSS评分为10.0，影响范围极其广泛，且已出现大量利用，建议立即修复。

下载链接：

https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc2

 

**Fortinet FortiOS ****任意文件下载漏洞（CVE-2021-44168）**

FortiOS的 "execute restore src-vis"命令中存在无完整性检查的代码下载漏洞，可能允许本地认证的攻击者通过特制的更新包下载设备上的任意文件。

参考链接：

https://www.fortiguard.com/psirt/FG-IR-21-201

 

**Realtek Jungle SDK ****远程代码执行漏洞（CVE-2021-35394）**

Realtek Jungle SDK v2.x至v3.4.14B版本提供了一个名为 "MP Daemon "的诊断工具，通常被编译为 "UDPServer "二进制文件。该二进制文件受到多个内存损坏漏洞和任意命令注入漏洞的影响，可被未经认证的远程攻击者利用。该漏洞的CVSS评分为9.8。

参考链接：

https://nvd.nist.gov/vuln/detail/CVE-2021-35394

 

**Zoho ManageEngine Desktop Central****身份验证绕过漏洞（CVE-2021-44515）**

Zoho ManageEngine Desktop Central存在认证绕过漏洞，可导致服务器上的远程代码执行，2021年12月已检测到在野利用。对于企业版10.1.2127.17和更早版本，升级到10.1.2127.18。对于企业版10.1.2128.0到10.1.2137.2，升级到10.1.2137.3。对于MSP构建的10.1.2127.17及以前的版本，升级到10.1.2127.18。对于MSP构建的10.1.2128.0到10.1.2137.2，升级到10.1.2137.3。

参考链接：

https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2021-44515

 

此外，CISA还将９个往年的漏洞添加到已知的被利用漏洞目录中，这些漏洞都是经常被攻击者利用的高危或严重漏洞，影响了Sonatype Nexus Repository Manager、Linux内核、MongoDB、Apache Solr和Jboss等应用。CISA发布的完整漏洞列表如下：

https://www.cisa.gov/known-exploited-vulnerabilities-catalog
