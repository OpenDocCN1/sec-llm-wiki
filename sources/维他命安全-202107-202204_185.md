# 【供应链安全】可劫持Discord 令牌的恶意npm软件包

**0x00 风险概述**

近日，JFrog 安全研究团队公开披露了17 个恶意 npm包，这些恶意软件包中有的试图收集用户的Discord 令牌，以访问用户的Discord帐户和服务器。

 

### **0x01 攻击详情**

![](../Images/f8f05397f846d2f8bb77f2807c6acb5d.png)

  

这17个包的Payload多种多样，从信息窃取到远程访问后门，并且这些包具有不同的策略，包括域名抢注、依赖混淆和木马功能，如下：  

![](../Images/d530783ffafdcf1ef781ebb7a1f1e049.png)

为了引诱用户下载软件包，恶意项目采用了各种策略。例如，discord-lofy和discord-selfbot-v14包伪装成合法库discord.js 的修改，该库能够与discord API互动。以典型的木马方式，这些软件包试图通过复制原始软件包的README.md来误导受害者。

这些恶意软件包有的是针对 Discord 而构建的，Discord 是一个被 3.5 亿用户使用的虚拟会议平台，支持通过语音通话、视频通话、短信和文件进行通信。Discord令牌是一组字母和数字，用作访问 Discord 服务器的授权码，它实际上是用户的凭据。研究人员表示，最近发现了大量抓取 Discord 令牌的恶意软件，包括前段时间披露的恶意的python包，Discord对攻击者有吸引力的原因如下：

1.使用该平台作为攻击的一部分。Discord 服务器通常用作匿名命令和控制 (C2) 服务器，控制远程访问木马(RAT) 甚至整个僵尸网络。

2.向 Discord 用户传播恶意软件。攻击者窃取的Discord 帐户可用于社会工程目的，以继续传播恶意软件，手动或通过蠕虫自动传播。

3.出售被盗的高级帐户。攻击者可能会针对已购买 Nitro（高级服务）的 Discord 帐户，以便在交易市场上以低价转售它们。

GitHub上很容易找到带有构建说明的Discord token grabbers项目，攻击者可以利用这些模板开发定制的恶意软件，而不需要大量的编程技巧，这意味着攻击者可以在几分钟内轻松完成操作。此外，这可以与各种在线混淆工具结合使用，以避免基本的检测技术。更重要的是，与完整的 RAT 后门相比，这些Payload不太可能被防病毒解决方案检测到，因为 Discord 窃取程序不会修改任何文件，也不会在任何地方注册自己（例如在下次启动时执行）并且不执行可疑操作，例如生成子进程。

 

### **0x02 风险等级**

高危。

 

### **0x03 影响范围**

这些恶意软件包中有的可获取用户的Discord 令牌，以便攻击者能够访问受害者的 Discord 帐户或服务器。

 

### **0x04 安全建议**

目前这些恶意npm包已经被删除，建议相关用户及时检查自己的开发环境。
