# 【风险通告】CISA 2021年已知被利用的漏洞列表（三）

**0x00 风险概述**

2021年12月1日，CISA将5个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及高通、MikroTik路由器、Zoho ManageEngine ServiceDesk Plus和Apache。

 

### **0x01 攻击详情**

![](../Images/289c8af2cc8bba8d72d26f4746d67465.png)

CISA本次新增的5个漏洞是正在被积极利用的安全漏洞，对企业和组织构成了重大风险。漏洞详情如下：  

*   **高通多芯片组输入验证不当漏洞（CVE-2020-11261）**
    

在Snapdragon Auto、Snapdragon Compute、Snapdragon Connectivity、Snapdragon ConsumerIOT、Snapdragon Industrial IOT、SnapdragonMobile、Snapdragon Voice & Music、Snapdragon Wearables中，当用户应用程序请求分配巨大的内存时，由于检查不当而导致内存损坏。该漏洞的CVSS评分为7.8。

参考链接：

https://www.qualcomm.com/company/product-security/bulletins/january-2021-bulletin

*   **MikroTik ****路由器操作系统目录遍历漏洞（CVE-2018-14847）**
    

由于WinBox界面中存在目录遍历漏洞，MikroTik RouterOS允许未经身份验证的远程攻击者读取任意文件，以及经过身份验证的远程攻击者写入任意文件。该漏洞的CVSS评分为9.1。该漏洞的影响范围如下：

运行如下RouterOS 版本的 Mikrotik 设备：

长期：6.30.1 - 6.40.7 ，于2018 年 4 月 23 日在 6.40.8 中修复。

稳定：6.29 - 6.42，于2018年4月23日在6.42.1中修复。

测试版：6.29rc1 - 6.43rc3，于2018年4月23日在6.43rc4中修复。

参考链接：

https://nvd.nist.gov/vuln/detail/CVE-2018-14847

 

*   **Zoho ManageEngine ServiceDesk ****身份验证绕过漏洞（CVE-2021-37415）**
    

11302之前的Zoho ManageEngine ServiceDeskPlus存在认证绕过问题，导致一些REST-API URL无需经过身份验证。该漏洞的CVSS评分为9.8。

参考链接：

https://www.manageengine.com/products/service-desk/on-premises/readme.html#11302

 

*   **Apache HTTP Server****跨站请求伪造漏洞（CVE-2021-40438）**
    

该漏洞存在于Apache HTTP Server的mod\_proxy模块中，允许通过恶意的请求uri-path导致mod\_proxy 将请求转发到远程用户选择的源服务器，涉及Apache HTTP Server 2.4.48及之前的版本，其 CVSS评分为9.0。该漏洞自公开披露以来，互联网上已经发布了多个PoC/EXP。

参考链接：

https://mp.weixin.qq.com/s/Je22S1yDx7PsSxFNCjqQ8A

 

*   **Zoho ManageEngine ServiceDesk Plus ****远程代码执行漏洞（CVE-2021-44077）**
    

11306 之前的 Zoho ManageEngine ServiceDeskPlus、10530 之前的 ServiceDesk PlusMSP 和 11014 之前的 SupportCenterPlus 中存在未经身份验证的远程代码执行漏洞，该漏洞与 servlet 中的 /RestAPI URL 和 Struts 配置中的 ImportTechnicians 有关，其CVSS评分为9.8。

参考链接：

https://nvd.nist.gov/vuln/detail/CVE-2021-44077

 

CISA发布的完整漏洞列表如下：

https://www.cisa.gov/known-exploited-vulnerabilities-catalog
