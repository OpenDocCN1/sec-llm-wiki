【风险通告】CVE-2021-40438：Apache HTTP Server SSRF漏洞已被利用

0x00 风险概述

近日，攻击者正在积极利用Apache HTTP Server中一个已被修复的SSRF漏洞（CVE-2021-40438），未经身份验证的远程攻击者可以使用恶意的请求uri-path来让httpd-server将这些请求转发到任何服务器。

 

0x01 攻击详情

2021年9月16日，Apache HTTP Server发布了安全更新版本2.4.49，修复了多个安全漏洞，其中CVE-2021-40438是Apache HTTP Server中的服务器端请求伪造(SSRF)漏洞，该漏洞的CVSS评分为9.0（严重），影响了Apache HTTP Server 2.4.48及之前版本。

该漏洞存在于Apache HTTP Server的mod_proxy模块中，攻击者可以通过恶意的请求uri-path导致mod_proxy 将请求转发到远程用户选择的源服务器。该漏洞自公开披露以来，互联网上已经发布了多个PoC/EXP。

近日，德国BSI 机构和Cisco公司警告攻击者正在积极利用CVE-2021-40438。Cisco在其公告中表示，已经发现了识别为CVE-2021-40438漏洞的利用企图，德国BSI 机构也发布了CVE-2021-40438的警报，并表示攻击者能够利用该漏洞从受害者系统获取用户凭据的哈希值。

 

0x02 风险等级

高危。


0x03 影响范围

目前该漏洞已发现在野利用，且漏洞利用程序已经公开，具有潜在的安全风险。

 

0x04 安全建议

建议及时升级更新到Apache HTTP Server 2.4.51或更高版本。
