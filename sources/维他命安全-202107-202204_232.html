0x00 风险概述

2021年11月17日，CISA将4个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及ExifTool、Microsoft Win32k、Microsoft Excel和Microsoft Exchange Server。

 

0x01 攻击详情

11月3日，CISA发布了约束性操作指令 (BOD) 22-01，要求联邦机构在规定时间内修复数百个在野外被利用的安全漏洞。这些漏洞涉及面向互联网和非面向互联网的信息系统上的软件和硬件，以及联邦机构管理或第三方托管的资源。

同时，CISA 还发布了数百个被利用的安全漏洞的目录，如果攻击者成功滥用这些漏洞将导致政府系统面临重大风险。并且该目录将随时间更新，更新的漏洞具有以下特征：

  • 该漏洞已经分配CVE ID。

  • 有可靠证据表明该漏洞已在野外被积极利用。

  • 该漏洞有明确的补救措施，例如供应商提供的更新。


11月17日新增的4个正在被攻击者积极利用的漏洞详情如下，CISA要求FCEB机构在12月1日之前修复这些漏洞：

  • Exiftool远程代码执行漏洞（CVE-2021-22204）

ExifTool 7.44－12.23版本在DjVu模块中存在一个错误，该错误允许在解析恶意图像时执行任意代码，其CVSS评分为7.8。

参考链接：

https://nvd.nist.gov/vuln/detail/CVE-2021-22204

 

  • Microsoft Win32k 特权提升漏洞（CVE-2021-40449）

该漏洞为Windows Win32k 内核驱动程序中的权限提升漏洞，已于10月12日修复，其CVSS评分为7.8，攻击复杂度和所需权限低，无需用户交互即可被本地利用。据卡巴斯基表示，该漏洞正被威胁行为者用于针对 IT 公司、军事/国防承包商和外交实体的广泛间谍活动，并用于提升MysterySnail远程访问木马 (RAT)的权限，卡巴斯基将其归因于IronHusky APT活动。

参考链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-40449

 

  • Microsoft Excel 安全功能绕过（CVE-2021-42292）

该漏洞已于11月9日修复，其CVSS评分为7.8。该漏洞的攻击复杂度低，无需特殊权限即可被本地利用，但需与用户交互。该漏洞目前尚未公开披露，但已检测到在野利用。

参考链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42292


  • Microsoft Exchange Server 远程代码执行漏洞（CVE-2021-42321）

该漏洞是Microsoft Exchange Server中经过身份验证的RCE漏洞，已于11月9日修复，其CVSS评分为8.8，攻击复杂度和所需权限低，无需用户交互即可被远程利用。此漏洞目前尚未公开披露，但已检测到在野利用。

参考链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42321

 

CISA发布的完整漏洞列表如下：
