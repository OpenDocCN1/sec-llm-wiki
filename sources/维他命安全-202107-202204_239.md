### **0x01 漏洞详情**

![](../Images/e5669ac9e1744c76bcb2d5849adde37c.png)

2021年10月21日，Apache Storm被公开披露存在一个命令注入漏洞（CVE-2021-38294），其CVSS评分为9.8，攻击者无需与用户交互即可远程利用此漏洞。  

该漏洞是Nimbus Thrift服务器中的 Shell 命令注入漏洞，存在于getTopologyHistory服务中，攻击者可以通过向Nimbus服务器发送恶意制作的Thrift请求以在身份验证之前远程执行代码。

  

**影响范围**

Apache Storm 2.2.X < 2.2.1

Apache Storm 2.1.X < 2.1.1

Apache Storm 1.X < 1.2.4

 

### **0x02 处置建议**

目前此漏洞已经修复，建议将Apache Storm更新到以下版本之一：

Apache Storm 2.2.x：2.2.1 或 2.3.0

Apache Storm 2.1.x：2.1.1

Apache Storm 1.x ：1.2.4

下载链接：

https://storm.apache.org/downloads.html
