ANALYSIS

CVE-2021-3654：开放重定向漏洞

noVNC 组件中存在开放重定向漏洞，导致OpenStack Nova 允许远程攻击者进行网络钓鱼攻击。

https://www.ibm.com/blogs/psirt/security-bulletin-openstack-compute-nova-novnc-proxy/


CVE-2021-41173：Go Ethereum中漏洞

Go Ethereum 1.10.9 之前存在漏洞，受影响节点在处理来自对等方的恶意制作的消息时容易崩溃。

https://cve.mitre.org/cgi-bin/cvename.cgi?name=CVE-2021-41173


Chrome Ad-Heavy 检测机制绕过

Chrome 跟踪 Ad-Heavy 广告的方式存在漏洞，允许攻击者使用消耗大量内存或 CPU 的广告来绕过检测。

https://ssd-disclosure.com/ssd-advisory-chrome-ad-heavy-bypass-via-sharedworker/


WordPress 插件存在漏洞

WordPress 插件 Hashthemes Demo Importer中漏洞允许攻击者重置和擦除易受攻击的网站。

https://www.bleepingcomputer.com/news/security/brutal-wordpress-plugin-bug-allows-subscribers-to-wipe-sites/


Microsoft 365 将支持自定义 ARC 配置

Microsoft Defender for Office 365 将添加自定义身份验证接收链 (ARC) 配置支持。

https://www.bleepingcomputer.com/news/microsoft/microsoft-365-will-get-support-for-custom-arc-configurations/


DiploFoundation 开发模拟网络攻击游戏

卡巴斯基和 DiploFoundation作开发了一款游戏，使缺乏技术背景的外交官和专业人士了解网络攻击。

https://www.infosecurity-magazine.com/news/diplofoundation-simulated/


终结勒索软件的三个秘诀

Cybereason提出三种方式抵御勒索攻击：采用以运营为中心的方法、保持领先于勒索软件曲线和解决动机。

https://www.cybereason.com/blog/three-secrets-to-ending-ransomware


渗透测试的步骤

介绍了渗透测试，包括：渗透测试包括什么；它们是如何执行的，由谁执行；渗透测试后应该采取哪些步骤等。

https://thehackernews.com/2021/10/before-and-after-pen-test-steps-to-get.html


Windows 权限提升：启动登录自动启动执行

Windows Startup 文件夹可能成为攻击者的目标，以提升权限或持久性攻击。

Kunyu - 企业资产收集
