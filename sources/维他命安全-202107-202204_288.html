0x00 风险概述

2021年10月22日，CISA发布安全公告，每周有数百万次下载量的流行NPM包ua-parser-js被劫持并植入了恶意代码，远程攻击者可以利用恶意软件包获取敏感信息或控制系统。

 

0x01 攻击详情

 


UA-Parser-JS是一个开源轻量级 JavaScript 库，被用来解析浏览器的用户代理，以识别访问者的浏览器、引擎、操作系统、CPU和设备类型/型号。该库非常受欢迎，每周下载量超百万次。此外，该库还被用于一千多个项目，包括 Facebook、微软、亚马逊、Instagram、谷歌、Slack、Mozilla、Discord、Elastic、Intuit、Reddit等知名公司的项目。

10月 22 日，攻击者劫持了开发者的NPM 账户并发布了三个恶意版本的 UA-Parser-JS NPM 包，并在 Linux 和 Windows 设备上安装加密矿工和窃取密码。这三个包含恶意代码的ua-parser-js版本为：

  • ua-parser-js0.7.29

  • ua-parser-js0.8.0

  • ua-parser-js1.0.0


研究人员发现，当恶意软件包被安装到用户的设备上时，preinstall.js脚本将检查设备上使用的操作系统类型，并启动一个Linuxshell脚本或Windows批处理文件。

用于检查操作系统类型的preinstall.js 脚本

 

如果软件包运行在Linux设备上，将执行preinstall.sh脚本，检查用户是否位于俄罗斯、乌克兰、白俄罗斯和哈萨克斯坦。如果设备不在这些国家，该脚本将从159[.]148[.]186[.]228下载jsextension[VirusTotal]程序并执行它。jsextension程序是一个XMRig Monero矿工，它将仅使用设备的50%的CPU，以避免被检测到。

安装矿工的Linux shell脚本

 

而对于Windows设备，批处理文件还将下载XMRig Monero加密矿工，并将其保存为jsextension.exe [VirusTotal]并执行。此外，该批处理文件将从citationsherbe[.]at下载一个sdd.dll文件[VirusTotal]并将其保存为create.dll。

用于安装加密矿工的 Windows 批处理文件

 

下载的DLL是一个密码窃取木马（可能是DanaBot），将试图窃取存储在设备上的密码。当使用regsvr32.exe -s create.dll命令加载DLL时，它将试图窃取各种程序的密码，包括FTP客户端、VNC、消息传递软件、电子邮件客户端和浏览器等，目标程序如下：

除了窃取上述目标程序中的密码外，DLL 还会执行 PowerShell 脚本从 Windows 凭据管理器中窃取密码，如下所示：

从 Windows 窃取存储的密码

 

根据猜测，这次攻击似乎是之前发现的其它恶意NPM包背后的同一个团伙进行的。几天前，安全公司 Sonatype 的研究人员发现了隐藏在官方 npm 包存储库中上传的三个 JavaScript 库中的加密挖掘恶意软件。这三个 npm 包为 klow、klown和 okhsa，它们在Windows 或 Linux 平台上以几乎相同的方式部署加密矿工，启明星辰VSRC及时跟踪了此事件。

 

0x02 风险等级

高危。

 

0x03 影响范围

Linux 和 Windows 设备。

 

0x04 安全建议

目前该恶意软件包已经修复，鉴于供应链攻击的广泛影响，建议受影响用户将UA-Parser-JS升级更新到以下版本：

  • ua-parser-js 0.7.30

  • ua-parser-js 0.8.1

  • ua-parser-js 1.0.1

使用UA-Parser-JS 库的所有用户检查其项目是否存在恶意软件的措施包括但不限于：

  • 检查是否存在jsextension.exe（Windows）或jsextension（Linux），如果它们存在，就删除它们。

  • 对于Windows用户，应扫描设备是否存在create.dll文件，并立即删除它。

  • 所有受感染的Linux和Windows用户应改变他们的密码、密钥和更新令牌，因为它们很可能被入侵并发送给攻击者。
