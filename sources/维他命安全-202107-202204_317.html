安/全/工/具

02

TOOLS

Jaws语言

Jaws是一种隐形的解释型编程语言，专为防病毒研究而创建，可以与其他语言共存以创建多语言代码。

https://github.com/lawndoc/jaws


Zed Attack Proxy  - 渗透测试工具

Zed Attack Proxy (ZAP) 是一种易于使用的集成渗透测试工具，用于查找 Web 应用程序中的漏洞。

https://packetstormsecurity.com/files/164458/ZAP_2.11.0_Crossplatform.zip


Owt - WiFi 审计工具

该工具在具有用户友好界面的 unix bash 脚本中编译了一些用于 wifi审计的必要工具。

https://www.kitploit.com/2021/09/owt-most-compact-wifi-auditing-tool.html


PyRDP - RDP中间人工具

PyRDP 是 Python 远程桌面协议 (RDP) 中间人 (MITM) 工具和库。

https://packetstormsecurity.com/files/164378/pyrdp-master.zip


StreamDivert - 流量重定向

StreamDivert 是一种工具，用于在系统上进行中间人或中继进出网络连接。

https://securityonline.info/streamdivert-redirecting-specific-tcp-udp-and-icmp-traffic/


Seth - RDP中间人工具

Seth 是一个用 Python 和 Bash 编写的工具，通过尝试降级连接以提取明文凭据来连接 MitM RDP 连接。

https://packetstormsecurity.com/files/164377/Seth-master.zip


EDD - 枚举域数据

Enumerate Domain Data设计为类似于PowerView，但在 .NET 中，本质上是终极域枚举工具。

https://www.kitploit.com/2021/09/edd-enumerate-domain-data.html


MedSec - 网络实用工具

MedSec 是一种网络实用工具，开发用于执行一些网络、安全管理员和渗透测试任务。

https://packetstormsecurity.com/files/164376/medsec-master.zip


cloudquery - 合规工具

CloudQuery 将来自不同云和 SaaS 提供商的分散 API 的数据提取、转换（规范化）和加载 (ETL) 到 PostgreSQL 关系数据库中。

https://securityonline.info/cloudquery-pulls-normalize-expose-and-monitor-your-cloud-infrastructure-and-saas-apps/
