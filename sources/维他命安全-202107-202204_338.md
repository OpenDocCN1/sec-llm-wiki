#                             

在研究网络钓鱼攻击时，研究人员发现一个攻击活动使用了大量新的子域——单次运行超过 300,000 个。该活动由名为BulletProofLink的大规模“钓鱼即服务”(phishing as a-service)运营团队支持，该运营团队以相对较低的成本销售钓鱼工具、电子邮件模板、主机和自动化服务。

BulletProofLink 拥有 100 多个模仿知名品牌和服务的网络钓鱼模板。多个攻击团伙以一次性购买或按月订阅的模式使用BulletProofLink（其在各种网站、广告和其他宣传材料中也称为 BulletProftLink 或 Anthrax），这为该运营团队创造了稳定的收入来源。

这项对 BulletProofLink 的综合研究揭示了PhaaS如何运营。还演示了PhaaS运营团队如何推动网络钓鱼技术的扩散，例如“双重盗窃”，这种方法将被盗的凭据发送给PhaaS运营团队及其客户，从而在几个方面实现货币化。

## **了解钓鱼工具和钓鱼即服务(PhaaS)**

由于网络钓鱼攻击的设计和分发方式有所改进，基于电子邮件的持续攻击始终是网络防御者面临的挑战。现代网络钓鱼攻击通常是通过大量的电子邮件和伪造的登录模板、代码和其他资产进行的。虽然攻击者曾经有必要单独构建网络钓鱼电子邮件和冒充品牌的网站，但网络钓鱼领域已经发展出了自己的基于服务的经济模式。旨在进行钓鱼攻击的攻击者可能会向其他黑客团伙购买资源和基础设施，包括：

*   **网络钓鱼工具包**：指的是从卖家和经销商处一次性销售的工具包。这些是打包文件，通常是 ZIP 文件，带有现成的电子邮件网络钓鱼模板，旨在绕过检测，并且通常带有访问它们的门户。网络钓鱼工具包允许客户建立网站并购买域名。网络钓鱼网站模板或工具包的可供选择的方案还包括电子邮件本身的模板，客户可以自定义和配置这些模板。一个已知的网络钓鱼工具包的样本是 MIRCBOO。
    
*   **PhaaS**：与勒索软件即服务 (RaaS) 类似，PhaaS遵循软件即服务模型，该模型要求攻击者向运营团队支付全部开发费用和通过虚假登录页面开发、网站托管以及凭据解析和重新分发部署大部分或完整的网络钓鱼活动。BulletProofLink 是PhaaS运营的一个示例。
    
    ![](../Images/195bf483f968b57a5eb1a6032cf320cc.png)
    

  

*图 1. 网络钓鱼工具包和PhaaS之间的功能比较*

值得注意的是，一些PhaaS可能提供从模板创建、托管和整体编排的全部业务，使其成为对其客户具有吸引力的业务模型。许多网络钓鱼服务提供商提供一个托管的诈骗页面解决方案，他们称之为“FUD”链接或“完全未检测”链接，这是这些运营团队使用的一个营销术语，提供链接并保证链接直到用户点击是可用的。这些钓鱼服务提供商负责托管链接和页面，而付费的攻击者只须在稍后接收被盗凭证。与某些勒索软件运营团队不同，攻击者不会直接访问设备，而只是收集未经测试的被盗凭证。

## **分解 BulletProofLink 服务**

为了详细了解PhaaS的工作原理，研究人员深入研究了BulletProofLink运营团队提供的模板、服务和定价结构。根据该团队的About Us网页，BulletProofLink PhaaS自2018年以来一直活跃，并声称他们为每个“专门的垃圾邮件发送者”提供独特的服务。

运营团队以其别名 BulletProftLink、BulletProofLink 和 Anthrax 维护多个网站，包括带有教学广告的 YouTube 和 Vimeo 页面以及论坛和其他网站上的宣传材料。在许多情况下，包括在运营团队发布的 ICQ 聊天日志中，客户均以别名称呼该组织。

研究人员在监控此运营团队的过程中，发现在线商店进行了多次修改。该网站页面的源代码包含了对网站上其他地方的工件的引用，其中包括 ICQ 聊天消息和广告。虽然这些引用只存在于较新的版本中，但月度订阅网站的登录页面不再包含服务定价信息。在以前的版本中，这些网站提到了运营团队托管 FUD 链接并将凭据返回给购买方的成本。

### **网络钓鱼模板**

BulletProofLink 运营团队提供了 100 多个模板，并以高度灵活的商业模式运营。这种商业模式允许客户自己购买页面发送电子邮件，并通过自己的登录页面来控制密码收集的整个流程，或者通过使用 BulletProofLink 的托管链接窃取目标的凭据。

这些模板旨在通过网络钓鱼获取凭据的同时绕过检测，但也因购买方而异。同样，提供的各种模板并不能保证所有 BulletProofLink的活动都相同。相反，攻击活动本身可以通过网络钓鱼页面源代码、其中引用的 PHP 密码处理网站以及在其更大规模活动中使用的托管基础设施相结合来识别。这些密码处理域通过域注册期间的托管、注册、电子邮件和其他元数据相似性与运营团队相关联。

提供的模板与网络钓鱼页面本身相关，因此为它们提供服务的电子邮件可能看起来完全不同，并由多个运营团队处理。

### **提供服务：托管和支持**

网络钓鱼运营团队在其网站上列出了一系列服务以及相应的费用。正如其他研究人员指出的那样，每月的服务费用高达 800 美元，而其他服务的一次性托管链接费用仅为 50 美元。BulletProofLink 网站接受的一种常见支付方式就是比特币。

除了通过网站账号与客户沟通外，运营团队还使用了各种与客户互动的方式，包括Skype、ICQ、论坛和聊天室。就像真正的软件企业致力于为客户服务一样，运营团队为新老客户提供客户支持服务。

## **BulletProofLink 活动**

如前所述，研究人员在调查一次网络钓鱼活动时发现了 BulletProofLink，该活动在攻击者控制的网站或 BulletProofLink的网站上使用 BulletProofLink 网络钓鱼工具包。该活动本身以使用了 300,000 个子域而闻名，但此次的分析暴露了 BulletProofLink 网络钓鱼工具包的众多实现之一：

![](../Images/33bd9e0d38cde855cb4e5ab4dbf28544.png)

*图 9. 使用 BulletProofLink 的网络钓鱼活动的端到端攻击链*  

此活动活动使用了一种“无限子域滥用（infinite subdomain abuse）”的技术，当攻击者破坏网站的 DNS 或当受感染的网站配置了允许通配符子域的 DNS 时，就会发生这种情况。“无限子域”允许攻击者为每个收件人使用唯一的 URL，由于以下原因，该技术在攻击者中越来越受欢迎：

*   它与以前黑客获取大量一次性域的技术不同。为了在电子邮件链接中使用无限子域来重定向到较小的最终登录页面，攻击者只需攻击网站的 DNS，而不是网站本身。
    
*   它允许网络钓鱼运营团队通过将动态生成的子域配置为每个单独电子邮件的基本域的前缀来最大化他们能够使用的唯一域。
    
*   创建唯一 URL 增加了仅依赖域和 URL 精确匹配的检测方法的难度。
    

网络钓鱼活动还冒充了（尽管效果不佳）Microsoft 徽标和品牌。利用伪造技术使用了纯色的微软徽标，这可能是有意地绕过对 Microsoft 徽标四种不同颜色的检测。值得注意的是，后续活动已转为使用四种颜色的 Microsoft 徽标。

![](../Images/996425609e59611b736dd8826333d522.png)

*图 10. 来自最近的凭证网络钓鱼活动的网络钓鱼诱饵*  

这些邮件还使用了一种称为零点字体（zero-point font）的技术，该技术使用对用户不可见的字符填充邮件的 HTML，以混淆电子邮件正文来试图绕过检测。网络钓鱼者越来越多地使用这种技术来绕过检测。

![](../Images/6f1051446d675c2401339cc467ecaf97.png)

*图 11. HTML 显示电子邮件中的零点字体日期填充*  

电子邮件中的网络钓鱼 URL 包含了使用 Base64 编码的受害者信息以及一个攻击者拥有的网站，在该网站中用户将被重定向。在此活动中，单个基本域用于无限子域技术以启动该活动的重定向，该活动在数周内利用了多个辅助网站。

![](../Images/59c374e5565c57d4f993131334328dce.png)

*图 12. 钓鱼 URL 的格式和示例，解码后重定向到受感染网站*  

受感染的网站重定向到托管网络钓鱼页面的第二个域，该页面模仿 Outlook 登录屏幕并为每个用户生成特定的 URL。研究人员发现该页面是为输入到 URI 中的任意数量的电子邮件地址生成的，并且无法确保它是否被使用过或与是否与实时的钓鱼电子邮件相关。

凭证可以发送到一个或多个地址，但该页面采用了一些混淆技术来隐藏这些地址。试图混淆密码处理网站地址的方法是使用一个函数，该函数基于回调一个数字和字母数组来解码地址:

![](../Images/c7365b6783b608bc89d866f556aeda65.png)

研究人员在 Python 中逆向了这一点，发现凭据被发送到了网站：hxxps://webpicture\[.\]cc/email-list/finish-unv2\[.\]php。模板“email-list/finish-unv2.php”来自以下变体之一：finish-unv2\[.\]php、finish-unv22\[.\]php 或finish\[.\]php。这些变体通常使用术语“电子邮件列表”以及引用特定网络钓鱼页面模板（例如 OneDrive 或 SharePoint）的另一个文件路径段。  

有时，会使用多个地址向其发送凭证，包括一些可能由购买方而非运营团队拥有的地址，这些地址可以在单独的函数中调用。这可能是遗留工件保留在最终模板中或发生双重盗窃的示例。

![](../Images/2517b3d89479851a19592f11591aba28.png)

*图 13. 最终网站的格式采用这些模式变体中的任何一种*  

对这些模板的分析使研究人员得到了一份广泛的密码收集 URI 列表，详细信息在一项关于 BulletProofLink 网络钓鱼服务运营团队的独立研究中进行了详细说明。他们列出了与之前观察到的模式相似的模式，使研究人员能够找到 BulletProofLink 使用的各种模板，包括前面讨论过的带有伪造 Microsoft 徽标的网络钓鱼电子邮件。

一种模式是，活动中使用的许多密码处理域直接将电子邮件地址与“Anthrax”、“BulletProofLink”、“BulletProftLink”或证书注册中的其他术语相关联。正如其他调查中所指出的，电子邮件地址本身并未在每个证书上列出相同的内容，并且还与使用了非专用于密码处理的域。

从那时起，在跟踪的无限子域激增活动中发现的登录页与现有对 BulletProofLink 运营背后的对手的深入研究之间产生了更多相似之处。

这个过程最终让研究人员跟踪和发现了其他研究中引用的相同资源，因而发现了有关长期运行的大规模网络钓鱼服务 BulletProofLink 的更多信息。此外，还发现了运营团队以前和现在正在使用的密码处理网站，以及托管在合法托管网站上用于此运营活动的其他组件的大量基础设施。

## **双重盗窃（Double theft）**

到目前为止，所描述的 PhaaS 工作模型让人想起勒索软件即服务 (RaaS) 模型，它涉及双重勒索。勒索软件中使用的勒索方法通常涉及攻击者泄露和公开发布数据，除了在受感染的设备上对数据进行加密之外，还向组织施加压力以支付赎金。这让攻击者可以通过多种方式来确保赎金的支付，同时发布的数据可以在其他运营团队的未来攻击中被武器化。在 RaaS 场景中，即使已经支付了赎金，勒索软件运营团队也没有义务删除被盗数据。

 在PhaaS中的凭据盗窃经济中使用了相同的工作流程。对于网络钓鱼工具包，运营团队可以轻松地将凭据发送到二级地址，并希望网络钓鱼工具包的购买者不要更改代码以删除凭据。BulletProofLink 网络钓鱼工具包也是如此，如果使用该服务的攻击者在一周结束时收到凭据和日志，但不是自己发起活动，PhaaS 运营团队会控制他们转售的所有凭据。

在勒索软件和网络钓鱼中，提供资源以促进攻击的运营团队通过确保尽可能多的方式使用被盗数据、访问权限和凭据来最大化货币化。此外，受害者的凭据最终可能进入暗网市场。

对于相对简单的服务，就电子邮件威胁形势而言，投资回报提供了相当大的动力。
