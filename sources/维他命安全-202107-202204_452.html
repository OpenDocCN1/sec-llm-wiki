Windows管理员可以通过分层组策略阻止外部设备

https://www.bleepingcomputer.com/news/microsoft/windows-admins-now-can-block-external-devices-via-layered-group-policy/

Microsoft Edge新功能

Edge正在试验名为“Super Duper Secure Mode”的新功能，旨在在不显着性能损失的情况下带来安全改进。

https://www.bleepingcomputer.com/news/microsoft/microsoft-edge-just-got-a-super-duper-secure-mode-upgrade/

TOOLS

InvisibilityCloak - PoC 混淆工具包

用于C#后开发工具的概念验证混淆工具包，可更改工具名称、更改项目GUID等。

https://securityonline.info/invisibilitycloak-poc-obfuscation-toolkit-for-c-post-exploitation-tools/


TeamsUserEnum - 用户枚举

使用 Microsoft Teams API进行用户枚举，确定电子邮件是否已注册Teams。

https://www.kitploit.com/2021/07/teamsuserenum-user-enumeration-with.html


domhttpx - 谷歌搜索引擎dorker

domhttpx是谷歌搜索引擎dorker，带有一个用python构建的HTTP工具包，可以更轻松地一次找到多个URL/IP。

https://securityonline.info/domhttpx-google-search-engine-dorker/


In0ri - 污损检测系统

In0ri是一种利用图像分类卷积神经网络的污损检测系统。

https://www.kitploit.com/2021/07/in0ri-defacement-detection-with-deep.html


karton - 分布式恶意软件处理框架

基于Python、Redis和MinIO的分布式恶意软件处理框架，用于创建灵活且轻量级的恶意软件分析后端。

https://securityonline.info/karton-distributed-malware-processing-framework/


Pathprober - 暴力破解网站目录

使用蛮力方法探测和发现HTTP路径名，并一次按特定单词或2个单词过滤。

https://www.kitploit.com/2021/07/pathprober-probe-and-discover-http.html


reconmap - 漏洞评估和渗透测试平台

Reconmap是漏洞评估和渗透测试 (VAPT) 平台，帮助信息安全人员在安全项目上进行协作，从规划到实施和文档。

https://securityonline.info/reconmap-vulnerability-assessment-and-penetration-testing-platform/


Ppmap - 扫描器/漏洞利用工具

一个用GO编写的简单扫描器/利用工具，它自动利用已知和现有的小工具通过Prototype Pollution执行XSS。
