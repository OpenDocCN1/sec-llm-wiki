# 【漏洞通告】Splunk Enterprise 2月多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247502015&idx=2&sn=2af9087b63815f01e8f6ac3f4f4f05ea&chksm=f901822ece760b38c73369da415002263dc0cca580a25620e8ee50a944514f5c0a26baaf8087&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247502015&idx=2&sn=2af9087b63815f01e8f6ac3f4f4f05ea&chksm=f901822ece760b38c73369da415002263dc0cca580a25620e8ee50a944514f5c0a26baaf8087&scene=27#wechat_redirect)

**0x00 漏洞概述**

Splunk Enterprise是一款专业的数据分析软件，能够对采样的数据以及统计图做出专业分析，支持跨平台使用，常用于金融、IT、财务等多个领域。

2023年2月14日，Splunk发布安全更新，修复了影响Splunk Enterprise的多个安全漏洞，这些漏洞可能导致安全绕过或跨站脚本（XSS）攻击等。

  

### **0x01 漏洞详情**

本次修复的部分高危漏洞包括：

| **CVE** || **评分** || **说明** || **影响范围** || **修复版本** |
| --- | --- | --- | --- | --- |
| CVE-2023-22939 || 8.1 || Splunk Enterprise中通过'map'SPL命令绕过SPL保护措施。该漏洞需要更高权限的用户在其浏览器中发起请求，并且仅影响启用了 Splunk Web 的实例。 || Splunk Enterprise（Splunk Web）  <= 8.1.12、8.2.0 - 8.2.9、9.0.0 - 9.0.3；Splunk Cloud Platform<=  9.2.2209 || Splunk Enterprise：升级到 8.1.13、8.2.10、9.0.4  或更高版本；Splunk Cloud Platform：升级到9.2.2209.3。 |
| CVE-2023-22935 || 8.1 || Splunk Enterprise中通过"display.page.search.patterns.sensitivity "搜索参数绕过SPL保护措施。该漏洞需要更高权限的用户在其浏览器中发起请求，并且仅影响启用了 Splunk  Web 的实例。 |
| CVE-2023-22934 || 7.3 || Splunk Enterprise中通过'pivot'SPL命令绕过SPL保护措施。该漏洞需要经过身份验证的用户制作保存的作业，并需要更高权限的用户在其浏览器中发起请求。该漏洞影响启用了 Splunk Web 的实例。 |
| CVE-2023-22933 || 8.0 || 在Splunk Enterprise中通过'模块'标签中的'layoutPanel'属性以可扩展标记语言（XML）视图进行跨站点脚本（XSS）攻击。该漏洞影响启用了Splunk Web的实例。 || Splunk Enterprise（Splunk Web）  <= 8.1.12、8.2.0 - 8.2.9、9.0.0 - 9.0.3；Splunk Cloud Platform<=  9.0.2208 || Splunk Enterprise：升级到 8.1.13、8.2.10、9.0.4  或更高版本；Splunk Cloud Platform：升级到9.0.2209。 |
| CVE-2023-22932 || 8.0 || 通过Splunk Enterprise视图中Base64编码的图像中的错误信息进行跨网站脚本（XSS），该漏洞影响启用了 Splunk Web 的实例。 || Splunk Enterprise（Splunk Web）9.0.0 - 9.0.3；Splunk Cloud Platform<= 9.0.2209 || Splunk Enterprise和Splunk Cloud Platform：升级到9.0.2209.3。注：该漏洞不影响Splunk Enterprise 9.0之前的版本。 |

Splunk还针对 Splunk Enterprise 中的多个中危漏洞发布了补丁，其中一些漏洞可能导致信息泄露、以 Splunk 实例身份发送电子邮件、上传带有不必要文件扩展名的查找表以及服务器端请求伪造（SSRF）等。

此外，Splunk还针对Splunk Enterprise第三方库中的多个漏洞发布了补丁，其中较为严重的漏洞包括llibxml2中的释放后使用漏洞（CVE-2021-3518，CVSS评分8.8）和llibxml2中的越界读取漏洞（CVE-2021-3517，CVSS评分8.6），这些漏洞可能会影响应用程序的可用性、机密性和完整性。

Splunk还修复了第三方库Node.js中的命令注入漏洞（CVE-2022-32212，CVSS评分8.1），以及Moment.js中的路径遍历漏洞（CVE-2022-24785 ，CVSS评分7.5）和低效解析算法问题（CVE-2022-31129），后者可能导致(Re)DoS 攻击。

  

### **0x02 处置建议**

目前这些漏洞已经修复，受影响用户可及时升级到相应修复版本。
