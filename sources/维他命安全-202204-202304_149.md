### **0x01 漏洞详情**

Spring Boot Admin是一个用于管理 Spring Boot 应用程序的开源管理用户界面。

12月9日，Spring Boot Admin项目发布安全公告，修复了Spring Boot Admin中的一个代码注入漏洞（CVE-2022-46166），该漏洞的CVSSv3评分为8.0。

Spring Boot Admin集成的Notifier通知程序容易受到代码注入攻击，可利用此漏洞通过向 Spring Boot Admin Server 的 /env执行器端点发送恶意POST 请求来远程执行代码。所有运行 Spring Boot Admin Server、启用通知程序（例如 Teams-Notifier）并通过 UI 写入环境变量的用户都容易受到该漏洞影响。

  

**影响范围**

Spring-Boot-Admin版本 < 2.6.10

Spring-Boot-Admin 版本 < 2.7.8

Spring-Boot-Admin 版本 < 3.0.0-M6

###   

### **0x02 安全建议**

目前该漏洞已经修复，受影响用户可升级到 Spring-Boot-Admin版本2.6.10、2.7.8、3.0.0-M6或更高版本。

下载链接：

https://github.com/codecentric/spring-boot-admin/releases

缓解措施：

1.禁用任何通知程序。

2.禁用/env执行器端点上的写访问（POST请求）。
