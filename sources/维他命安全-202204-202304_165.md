# 【漏洞通告】NVIDIA GPU 11月多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247501505&idx=2&sn=bd9aae81a71d0599b2154f0708efb3e8&chksm=f9018c50ce760546b7bc8349a51965d5aba97622b68afaf5fb2e3cd6c2aabad25d955a624509&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247501505&idx=2&sn=bd9aae81a71d0599b2154f0708efb3e8&chksm=f9018c50ce760546b7bc8349a51965d5aba97622b68afaf5fb2e3cd6c2aabad25d955a624509&scene=27#wechat_redirect)

**0x00 漏洞概述**

NVIDIA（英伟达）是GPU（图形处理器）的发明者，也是人工智能计算的引领者。

11月28日，NVIDIA 发布了GPU 显示驱动程序的软件安全更新，修复了Windows 和 Linux GPU 驱动程序中的多个安全漏洞，成功利用这些漏洞可能导致代码执行、拒绝服务、权限提升、信息泄露或数据篡改等。

###   

### **0x01 漏洞详情**

本次NVIDIA GPU安全更新共修复了7个评级为“高危“的漏洞，详情如下：

| **漏洞编号** || **评分** || **远程利用** || **描述** |
| --- | --- | --- | --- |
| CVE 2022 34669 || 8.8 || 否 || 适用于  Windows 的 NVIDIA GPU 显示驱动程序在用户模式层中存在漏洞，无特权的普通用户可以访问或修改系统文件或其他对应用程序至关重要的文件，这可能导致代码执行、拒绝服务、权限升级、信息泄露或数据篡改。 |
| CVE 2022 34671 || 8.5 || 是 || 适用于Windows的NVIDIA GPU显示驱动程序在用户模式层存中存在漏洞，非特权普通用户可越界写入，导致代码执行、拒绝服务、权限提升、信息泄露或数据篡改。 |
| CVE 2022 34672 || 7.8 || 否 || 适用于  Windows 的 NVIDIA 控制面板存在漏洞，未经授权的用户或无特权的普通用户可以通过获取特权、读取敏感信息或执行命令来破坏软件的安全性。 |
| CVE 2022 34670 || 7.8 || 否 || 适用于  Linux 的 NVIDIA GPU 显示驱动程序在内核模式层处理程序中存在漏洞，非特权普通用户在将图元转换为较小尺寸的图元时可能会出现截断错误，导致数据在转换中丢失，这可能造成拒绝服务或信息泄露。 |
| CVE 2022 42263 || 7.1 || 否 || 适用于  Linux 的 NVIDIA GPU 显示驱动程序在内核模式层处理程序中存在漏洞，可能导致整数溢出，造成拒绝服务或信息泄露。 |
| CVE 2022 34676 || 7.1 || 否 || 适用于  Linux 的 NVIDIA GPU 显示驱动程序在内核模式层处理程序中存在漏洞，可能导致越界读取，造成拒绝服务、信息泄露或数据篡改。 |
| CVE 2022 42264 || 7.1 || 否 || 适用于  Linux 的 NVIDIA GPU 显示驱动程序在内核模式层存在漏洞，非特权普通用户可通过使用超出范围的指针偏移量，导致数据篡改、数据丢失、信息泄露或拒绝访问。 |

此外，NVIDIA还修复了 VGPU 软件中的多个漏洞，如CVE‑2022‑42260（CVSS评分7.8），该漏洞存在于NVIDIA vGPU Display Driver for Linux guest 的D-Bus配置文件中，可能导致代码执行、拒绝服务、权限提升、信息泄露或数据篡改。

GPU和硬件驱动在操作系统上通常以高权限运行，攻击者可以利用驱动中的漏洞为恶意软件或代码提供同样的权限，因此这些漏洞往往成为攻击者的目标。
