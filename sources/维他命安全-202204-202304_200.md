# 【漏洞通告】Checkmk 11月多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247501311&idx=2&sn=393052ac464adbb79c735c439a76f8f2&chksm=f9018f6ece7606782ce3ce5138ca6b9ac54f7bbe1f6ee465f357da427430d499f6f7b76c2a36&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247501311&idx=2&sn=393052ac464adbb79c735c439a76f8f2&chksm=f9018f6ece7606782ce3ce5138ca6b9ac54f7bbe1f6ee465f357da427430d499f6f7b76c2a36&scene=27#wechat_redirect)

**0x00 漏洞概述**  

2022年11月01日，Checkmk中被披露存在多个漏洞，可在未经身份验证的情况下组合利用这些漏洞来控制受影响的设备。

  

### **0x01 漏洞详情**

Checkmk是使用 Python 和 C++ 开发的 IT基础设施监控解决方案。Checkmk的开源版监控工具基于Nagios Core，并提供与NagVis的集成，用于可视化和生成基础设施、服务器、端口和进程的拓扑图。

研究人员公开披露了Checkmk 及其 NagVis 集成中4个安全漏洞的详情，目前这些漏洞暂未分配CVE-ID，如下：

CVSS评分 9.1：watolib 的auth.php 中的代码注入漏洞

CVSS评分 9.1：NagVis 中的任意文件读取漏洞

CVSS评分 6.8：ajax\_graph\_images.py 中的换行注入漏洞

CVSS评分 5.0：agent-receiver中的服务器端请求伪造（SSRF）漏洞

虽然一些漏洞个体本身影响有限，但可以通过组合利用这些漏洞在运行Checkmk 易受攻击版本的服务器上远程执行代码，并完全控制服务器。

**影响范围**

Checkmk 版本 <= 2.1.0p10

###   

### **0x02 处置建议**

目前这些漏洞已经修复，受影响用户可升级到Checkmk 2.1.0p12或更高版本。
