# 【漏洞通告】Microsoft Edge 10月多个安全漏洞

**0x00 漏洞概述**10月14日，微软发布了Microsoft Edge（基于 Chromium）安全更新，修复了Edge中的多个安全漏洞，成功利用这些漏洞可能导致代码执行或其它恶意操作。

  

### **0x01 漏洞详情**

这些漏洞存在于Microsoft Edge（基于 Chromium）使用的 Chromium 开源软件 (OSS) 中，目前漏洞详情暂未公开：

| 产品 || CVE || 描述 || Microsoft Edge修复版本 || 基于 Chromium 的版本 |
| --- | --- | --- | --- | --- |
| Microsoft Edge（基于 Chromium） || CVE-2022-3445 || Skia中的释放后使用 || 106.0.1370.47 || 106.0.5249.119 |
| CVE-2022-3446 || WebSQL 中的堆缓冲区溢出 |
| CVE-2022-3450 || 对等连接中的释放后使用 |
| CVE-2022-3449 || 安全浏览中的释放后使用 |
| CVE-2022-3447 || 自定义选项卡中的不恰当实施 |

**影响范围**Microsoft Edge 版本 < 106.0.1370.47

###   

### **0x02 安全建议**

目前微软已经发布了最新的 Microsoft Edge Stable Channel（版本 106.0.1370.47），该版本包含了Chromium 项目的最新安全更新。参考链接：https://learn.microsoft.com/en-us/DeployEdge/microsoft-edge-relnotes-security注：Microsoft Edge用户可通过以下方式查看Microsoft Edge的版本信息并更新到最新版本：1.打开Microsoft Edge 浏览器，单击窗口最右侧的3个点【...】；2.点击【帮助和反馈】；3.点击【关于 Microsoft Edge】，并更新到最新版本（当前为106.0.1370.47）。4.更新完成后重启Microsoft Edge浏览器。
