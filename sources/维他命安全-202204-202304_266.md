# 【漏洞通告】Lenovo BIOS 9月多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247500973&idx=3&sn=8617f3b8700fae91942c33ee10a02d85&chksm=f9018e3cce76072a3b7e147bb497e6d6c4b61b12ca6e87583b76f3799a0dbfac68f12e2fcb3b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247500973&idx=3&sn=8617f3b8700fae91942c33ee10a02d85&chksm=f9018e3cce76072a3b7e147bb497e6d6c4b61b12ca6e87583b76f3799a0dbfac68f12e2fcb3b&scene=27#wechat_redirect)

### **0x00 漏洞概述**

9月13日，Lenovo（联想）发布BIOS更新，修复了其数百款设备中的多个安全漏洞，这些漏洞可能会导致信息泄露、权限提升、拒绝服务，并在某些情况下导致任意代码执行。

  

### **0x01 漏洞详情**

Lenovo是一家全球知名的ICT科技企业，也是全球智能设备的领导厂商。Lenovo本次更新修复了Desktop、All in One、ThinkPad、ThinkAgile、ThinkStation、ThinkServer、ThinkSystem等数百款设备型号中的多个漏洞，详情如下：

| CVE-ID || 类型 || 说明 |
| --- | --- | --- |
| CVE-2021-28216 || 代码执行 || 修复了TianoCore EDK II BIOS 中的固定指针漏洞，成功利用此漏洞可能导致任意代码执行。 |
| CVE-2022-40137 || 缓冲区溢出 || 某些 Lenovo 型号的 WMI SMI 处理程序中存在缓冲区溢出漏洞，成功利用此漏洞可能导致任意代码执行。 |
| CVE-2022-40134 || 信息泄漏 || SMI Set Bios Password SMI 处理程序中存在信息泄漏漏洞，成功利用此漏洞可能导致读取 SMM 内存。 |
| CVE-2022-40135 || 信息泄漏 || 某些Lenovo型号的Smart USB Protection SMI处理程序中存在信息泄漏漏洞，成功利用此漏洞可能导致读取 SMM 内存。 |
| CVE-2022-40136 || 信息泄漏 || 在某些Lenovo型号中，用于通过WMI配置平台设置的SMI处理程序存在信息泄漏漏洞，成功利用此漏洞可能导致读取 SMM 内存。 |
| Null || 安全增强 || AMI BIOS 的安全增强。 |

  

**影响范围**Desktop、Desktop - All in One、Hyperscale、Lenovo Notebook、Smart Edge、Smart Office、Storage、ThinkAgile、ThinkPad、ThinkServer、ThinkStation、ThinkSystem等多个系列型号。注：具体受影响产品型号及其BIOS固件版本信息请参考Lenovo官方公告列表：https://support.lenovo.com/us/en/product\_security/LEN-94953

  

### **0x02 安全建议**

目前Lenovo已经发布了受影响设备的BIOS更新，Lenovo用户可参考官方公告将系统固件更新到相应修复版本（或更高版本）。下载链接：https://pcsupport.lenovo.com/us/en/
