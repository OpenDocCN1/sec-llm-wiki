0x01 漏洞详情

Apache Flume 是一种分布式、可靠且可用的服务，用于高效收集、聚合和移动大量日志数据。
8月21日，Apache发布安全公告，修复了Apache Flume中一个可导致远程代码执行的JNDI注入漏洞（CVE-2022-34916）。
由于JMSMessageConsumer中的不正确输入验证，可能导致JNDI注入。当控制目标LDAP服务器时，且配置使用带有JNDI LDAP数据源URI的JMS源，则Apache Flume版本1.4.0到1.10.0中容易受到远程代码执行（RCE）攻击。


影响范围
1.4.0 <= Apache Flume 版本 <= 1.10.0


0x02 安全建议

目前此漏洞已经修复，受影响用户可升级到Apache Flume 1.10.1 或更高版本。
下载链接：
https://flume.apache.org/download.html
注：可以通过将JNDI限制为仅允许使用java协议或不允许使用协议来修复此漏洞。
