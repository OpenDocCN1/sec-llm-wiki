其中，值得关注的漏洞包括：
CVE-2022-21548：Oracle WebLogic Server未授权操作漏洞
Oracle WebLogic Server（组件：Core）中存在安全漏洞，可以在未经身份验证的情况下通过 T3、IIOP 协议进行网络访问，从而破坏 Oracle WebLogic Server，成功利用此漏洞可实现Oracle WebLogic Server可访问数据的未授权操作（如更新、插入或删除等），或导致部分拒绝服务。
CVE-2022-21560：Oracle WebLogic Server拒绝服务漏洞
Oracle WebLogic Server（组件：Core）中存在安全漏洞，可以在未经身份验证的情况下通过 T3、IIOP 协议进行网络访问，从而破坏 Oracle WebLogic Server，成功利用此漏洞可导致部分拒绝服务。
CVE-2022-21564：Oracle WebLogic Server拒绝服务漏洞
Oracle WebLogic Server（组件：Web Services）中存在安全漏洞，可以在未经身份验证的情况下通过 T3、IIOP 协议进行网络访问，从而破坏 Oracle WebLogic Server，成功利用此漏洞可导致部分拒绝服务。

0x02 处置建议

目前Oracle已经发布了相关漏洞的补丁集合，受影响用户可更新。
参考链接：
https://www.oracle.com/security-alerts/cpujul2022.html
缓解措施：
如非必要，可以禁用T3和IIOP协议。
禁用T3协议：
具体操作：
1）进入WebLogic控制台，在base_domain的配置页面中，进入“安全”选项卡页面，点击“筛选器”，进入连接筛选器配置。
2)在连接筛选器中输入：weblogic.security.net.ConnectionFilterImpl，在连接筛选器规则中输入：127.0.0.1 * * allow t3t3s，0.0.0.0/0 * *deny t3 t3s(t3和t3s协议的所有端口只允许本地访问)。
3）保存后需重新启动，规则方可生效。



禁用IIOP协议：
登录WebLogic控制台，base_domain >服务器概要 >AdminServer
