### **0x01 漏洞详情**

AWS IAM Authenticator for Kubernetes是适用于 Kubernetes 的 AWS IAM 身份验证器，它使用AWS IAM凭证对Kubernetes集群进行身份验证。7月12日，AWS IAM Authenticator被披露存在一个验证绕过漏洞（CVE-2022-2385），该漏洞的CVSS评分为8.1。当用户使用 AccessKeyID 模板参数构造用户名并根据用户名提供不同级别的访问权限时，AWS IAM Authenticator版本v0.5.2到v0.5.8中容易导致AccessKeyID 验证绕过， 成功利用此漏洞可实现在目标 Kubernetes 集群上提升权限。

  

**影响范围**AWS IAM Authenticator版本v0.5.2- v0.5.8

  

### **0x02 安全建议**

目前此漏洞已经修复，受影响用户可升级到AWS IAM Authenticator版本v0.5.9。下载链接：https://github.com/kubernetes-sigs/aws-iam-authenticator/releases/tag/v0.5.9缓解措施：若无法升级，可以通过不使用{{AccessKeyID}}模板值来构造用户名以缓解此漏洞。
