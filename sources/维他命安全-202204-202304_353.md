# HavanaCrypt冒充 Google 更新程序

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247500446&idx=2&sn=905769ce6e34c16a7cf7387170843625&chksm=f901880fce760119fdc4fe149b3860e19637d3691fbe3b238bb63d3b8552a2f629e5a7ac9846&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247500446&idx=2&sn=905769ce6e34c16a7cf7387170843625&chksm=f901880fce760119fdc4fe149b3860e19637d3691fbe3b238bb63d3b8552a2f629e5a7ac9846&scene=27#wechat_redirect)

## 勒索软件仍然是当今世界上最大的网络威胁之一。根据 Trend Micro的数据， 2022年第一季度通过电子邮件、URL和文件层检测并阻止了超过440万个勒索软件相关威胁，比2021年第四季度增加了37%。

勒索软件的普遍性源于其进化性：它采用不断变化的策略来欺骗目标并成功入侵系统。例如，今年有报道称勒索软件通过伪造 Windows 10、Google Chrome 和 Microsoft Exchange 更新来分发，以诱使目标下载恶意文件。最近，研究人员发现了一个采用类似方案的全新勒索软件家族：它伪装成 Google 软件更新应用程序，并使用 Microsoft 网络托管服务 IP 地址作为其命令和控制 (C&C) 服务器来绕过安全检测。调查还表明，该勒索软件在其文件加密例程中使用了QueueUserWorkItem 函数，这是一个 .NET System.Threading 命名空间方法，以及一个开源密码管理器KeePass Password Safe 的模块。这篇文章将对新勒索软件家族 HavanaCrypt 的的感染技术进行深入的技术分析。

### **收集机器信息**

HavanaCrypt使用 QueueUserWorkItem 函数为它的其它payload和加密线程实现线程池。此函数用于在线程池可用时执行任务。

![](../Images/35d8f83e38a936e2c21eba833c456263.png)

***图 24. HavanaCrypt 使用的 QueueUserWorkItem 函数***它还使用 DebuggerStepThrough 属性，该属性使它在调试期间逐步遍历代码，而不是进入代码。在分析函数内部之前，必须删除此属性。

![](../Images/68df743461ff8e3de267c0513a46bf29.png)

***图 25. HavanaCrypt 使用的 DebuggerStepThrough 属性***在继续其加密程序之前，HavanaCrypt 收集某些信息并将它们发送到其 C&C 服务器 20\[.\]227\[.\]128\[.\]33/index.php。它们是唯一标识符(UID) 以及令牌和日期。**用户标识符（UID）**UID包含机器的系统指纹。HavanaCrypt 收集机器信息片段，并通过通过一个附加到另一个的方式将它们组合在一起，然后将信息转换为SHA-256 哈希：*\[{Number of Cores}{ProcessorID}{Name}{SocketDesignation}\] BIOS Information \[{Manufacturer}{BIOS Name}{Version}\] Baseboard Information \[{Name}\]*

![](../Images/d5d3c3c1205848e9f5d1ac7daa30acc9.png)

### **结论**

HavanaCrypt勒索软件将自己伪装成谷歌更新应用程序，目的是诱骗潜在的目标执行恶意二进制文件。该恶意软件还通过检查与虚拟机应用程序相关的进程、文件和服务来实现许多反虚拟化技术。勒索软件使用的C&C 服务器是Microsoft 网络托管服务的一部分，这种情况是不常见的，可能被用作网络托管服务可以绕过检测。除了不寻常的 C&C 服务器外，HavanaCrypt 在加密阶段还使用 KeePass Password Safe 的合法模块。勒索软件的开发者很有可能计划通过 Tor 浏览器进行通信，因为 Tor 是该软件不会加密文件的目录之一。应该注意的是，HavanaCrypt 还加密了文本文件 foo.txt，并且不会留下赎金记录。这可能表明 HavanaCrypt 仍处于开发阶段。尽管如此，在它进一步发展造成更大的伤害之前，发现并阻止它仍是很重要的。
