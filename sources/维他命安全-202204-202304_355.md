# 【漏洞通告】Lenovo UEFI固件多个缓冲区溢出漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUxMDQzNTMyNg==&mid=2247500379&idx=2&sn=bef15dba260da9879c385a74173f3ec5&chksm=f90188cace7601dceda577b9db467564b5b8487e5863115e1c86e3b563d57046f3f2f502d862&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUxMDQzNTMyNg==&mid=2247500379&idx=2&sn=bef15dba260da9879c385a74173f3ec5&chksm=f90188cace7601dceda577b9db467564b5b8487e5863115e1c86e3b563d57046f3f2f502d862&scene=27#wechat_redirect)

**0x00 漏洞概述**  

2022年7月12日，联想（Lenovo）发布BIOS更新，修复了影响70多款笔记本电脑型号的3个缓冲区溢出漏洞。

  

### **0x01 漏洞详情**

本次更新修复的3个漏洞是由于传递给UEFI Runtime Services函数GetVariable的DataSize参数验证不足导致的缓冲区溢出漏洞，成功利用这些漏洞可以实现任意代码执行、劫持系统执行流程并禁用安全功能等。漏洞详情如下：**CVE-2022-1890****：****Lenovo ****ReadyBootDxe****缓冲区溢出漏洞**某些Lenovo笔记本产品的 ReadyBootDxe 驱动程序中存在缓冲区溢出，可以本地利用此漏洞实现任意代码执行。**CVE-2022-1891****：****Lenovo ****SystemLoadDefaultDxe****缓冲区溢出漏洞**某些Lenovo笔记本产品的 SystemLoadDefaultDxe 驱动程序中存在缓冲区溢出，可以本地利用此漏洞实现任意代码执行。**CVE-2022-1892****：****Lenovo SystemBootManagerDxe****缓冲区溢出漏洞**某些Lenovo笔记本产品的SystemBootManagerDxe驱动程序中存在缓冲区溢出，可以本地利用此漏洞实现任意代码执行。
