### **0x01 漏洞详情**

Spring Data for MongoDB是 Spring Data 项目的一部分，该项目旨在为新的数据存储提供熟悉和一致的基于Spring的编程模型，同时保留存储的特定特征和功能。6月20日，VMware发布安全公告，修复了Spring Data MongoDB中的一个SpEL 表达式注入漏洞（CVE-2022-22980），该漏洞的CVSSv3评分为8.2。Spring Data MongoDB应用程序在对包含查询参数占位符的SpEL表达式使用带@Query或@Aggregation注释的查询方法进行值绑定时，如果输入未被清理，则容易受到SpEL注入攻击。

  

**影响范围**Spring Data MongoDB 3.4.0Spring Data MongoDB 3.3.0 - 3.3.4以及其它旧的、不受支持的版本。

  

### **0x02 安全建议**

目前此漏洞已经修复，受影响用户可以升级到以下版本：Spring Data MongoDB 3.4.1或更高版本；Spring Data MongoDB 3.3.5或更高版本。缓解措施：重写query 或aggregation声明，在表达式中使用参数引用（"\[0\]"而不是"?0"）；在调用查询方法前对参数进行过滤；通过具有受限QueryMethodEvaluationContextProvider的BeanPostProcessor重新配置repository factory bean。注：当满足以下任一条件时，则不受此漏洞影响：

*   当带@Query或@Aggregation注释的查询方法不包含表达式；
*   带@Query或@Aggregation注释的查询方法不使用表达式中的参数占位符语法；
*   过滤了用户提供的输入；
*   存储库配置为使用限制SpEL使用的QueryMethodObservationContextProvider。
