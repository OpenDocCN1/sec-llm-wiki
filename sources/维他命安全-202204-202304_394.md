### **0x01 漏洞详情**

Apache Hadoop 软件库是一个框架，它可以跨计算机集群分布式处理大型数据集。6月15日，Apache官方发布安全公告，修复了Apache Hadoop中的一个权限提升漏洞（CVE-2021-33036）。在受影响的Apache Hadoop版本中，由于未对用户的身份进行合理限制，可以通过升级为yarn用户，从而实现以root用户的身份运行任意命令。

  

**影响范围**Apache Hadoop 2.2.0 - 2.10.1Apache Hadoop 3.0.0-alpha1 - 3.1.4Apache Hadoop 3.2.0 - 3.2.2Apache Hadoop 3.3.0 - 3.3.1

  

### **0x02 安全建议**

目前此漏洞已经修复，受影响用户可以升级到以下版本：Apache Hadoop >= 2.10.2Apache Hadoop >= 3.2.3Apache Hadoop >= 3.3.2下载链接：https://hadoop.apache.org/releases.html缓解措施：若无法立即更新到修复版本，在用户可以升级为yarn用户但不能升级为root用户的情况下，可以通过删除其升级为 yarn 用户的权限来缓解此漏洞。
