僵尸网络 EnemyBot 的分析

摘要

研究人员一直在追踪名为“EnemyBot”的物联网僵尸网络，据信它是由攻击团伙Keksec 分发的。在调查中，Alien Labs 发现EnemyBot 正在开发其它功能，利用了最近发现的漏洞 (2022年)，目前可攻击物联网设备、Web 服务器、Android设备和内容管理系统(CMS) 服务器。此外，现在可以在 Github 上找到恶意软件的基本源代码。

文章要点包括：

  • EnemyBot 的源代码可以在 Github上找到，任何想要利用恶意软件的攻击者都可以使用它。

  • 该恶意软件正在迅速地利用 one-day 漏洞。

  • VMware Workspace ONE、AdobeColdFusion、WordPress、PHPScriptcase 等服务以及物联网和 Android 设备都成为它的攻击目标。

  • EnemyBot 背后的Keksec 资源丰富，能够每天更新并为其恶意软件库添加新功能。

背景

EnemyBot是由Securonix在2022年3月首次发现的，后来在Fortinet的深入分析中也有详细说明，它是由攻击团伙"Keksec" 针对 Linux 系统和物联网设备分发的新恶意软件。

根据恶意软件的Github存储库，EnemyBot从多个僵尸网络的源代码中衍生出一个功能更强大且可调整的恶意软件。EnemyBot正在使用的原始僵尸网络代码包括Mirai、Qbot和Zbot。此外，该恶意软件还包括定制开发（见图1）。

图 1. Github 上的 EnemyBot 页面

据报道，Keksec在2016年由一些经验丰富的僵尸网络参与者组成。2021年11月，研究人员在一份报告中详细描述了该团伙的活动，将针对Windows 和 Linux 等不同平台的僵尸网络的开发归因于 Keksec。

  • 基于 Linux 的僵尸网络：Tsunami和Gafgyt

  • 基于 Windows 的僵尸网络：DarkIRC和DarkHTTP

  • 双系统：Necro (用 Python开发)


源码分析

EnemyBot的Github页面上的开发人员自称是一个"全职的恶意软件开发者"，也可以从事合同工作。该人称其工作场所为“Keksecurity”，暗示与 Keksec 团伙存在潜在关系（见图 2）。

图 2. EnemyBot 开发人员描述

Github上的恶意软件存储库包含四个主要部分：

cc7.py

该模块是一个Python 脚本文件，用于下载所有依赖项并将恶意软件编译成不同的操作系统架构，包括 x86、ARM、macOS、OpenBSD、PowerPC、MIPS等（见图 3）。

图 3. 将恶意软件源代码编译为 macOS 可执行文件

编译完成后，脚本会创建一个批处理文件“update.sh”，该文件被bot用作downloader，然后发送到目标中以传播恶意软件。

图 4.  update.sh 文件在不同架构上传播 EnemyBot

enemy.c

这是主要的bot源代码。虽然它缺少主要的开发功能，但包含了恶意软件的所有其它功能，以及 bot通过混合各种僵尸网络源代码（Mirai、Qbot和Zbot）支持的攻击——主要是Mirai 和 Qbot（见图 5 ）。

图 5. EnemyBot 源代码

hide.c

该模块由攻击者编译并手动执行，对恶意软件的字符串进行编码/解码，以将字符串隐藏在二进制文件中。为此，恶意软件使用了一个简单的交换表，其中每个字符都被替换为表中对应的字符（见图 6）。

图 6. 字符串解码

servertor.c

图7显示了命令和控制组件（C＆C）的僵尸网络控制器。C&C将在一台由攻击者控制的专用机器上执行。它可以控制和发送命令到被感染的机器(图7)。

图 7. C&C 组件


新变体分析

EnemyBot的大部分功能都与恶意软件的传播、扫描资产和寻找易被攻击的设备的能力有关。但是，该恶意软件还具有DDoS 功能，并且可以从攻击者那里接收用来下载和执行新代码（模块）的命令，从而为恶意软件提供更多功能。

在EnemyBot 的新变体中，该恶意软件添加了一个 webscan 功能，其中包含 24 个漏洞，来攻击不同设备和 Web服务器（见图 8）。

图 8. EnemyBot 调用新函数“webscan_xywz”

为了执行这些功能，恶意软件会随机扫描 IP 地址，当它获得SYN/ACK 响应时，EnemyBot 就会执行多个漏洞利用来扫描远程服务器上的漏洞。

第一个漏洞是去年发现的Log4j漏洞，即CVE-2021-44228和CVE-2021-45046：

图 9. 利用 Log4J 漏洞

恶意软件还可以在这些漏洞被发现的几天内采用新的漏洞。一些样本包括Razer Sila中漏洞（2022 年 4 月），它在发布时没有 CVE（参见图 10），以及同月的一个影响了VMWare Workspace ONE的远程代码执行 (RCE) 漏洞CVE-2022-22954（参见图 11）。

图 10.利用 Razar Sila 中的漏洞

图 11. 利用 VMWareWorkspace ONE 中的漏洞

EnemyBot还开始针对内容管理系统（如Wordpress），搜索各种插件中的漏洞，如"Video Synchro PDF"（见图 12）。

图 12.针对 WordPress 服务器的 EnemyBot

在图 12 所示的样本中，该恶意软件通过将恶意代码注入“/proc/self/environ”，将本地文件包含(LFI) 漏洞提升为 RCE。这种方法并不新鲜，在 2009 年就有描述。该恶意软件使用 LFI调用'environ'并在用户代理http 头中传递shell 命令。

图 13 显示了恶意软件如何使用此方法的另一个样本。其中，恶意软件正在利用DBltek GoIP 中的漏洞。

图 13. 通过 DBltek 中的 LFI 漏洞执行 shell 命令

如果通过 USB连接Android 设备，或者设备上运行 Android 模拟器，EnemyBot将尝试通过执行shell 命令来感染它（图 14）。

图 14. EnemyBot“adb_infect”函数攻击 Android 设备

结论

Keksec的EnemyBot 似乎刚刚开始传播，但由于开发者的快速更新，这个僵尸网络有可能成为物联网设备和 Web服务器的主要威胁。该恶意软件可以迅速地采用one-day漏洞（在发布概念证明后的几天内）。这表明Keksec 的资源充足，并且该组织已经开发了恶意软件以在修复漏洞之前利用，从而提高了其传播的速度和规模。
