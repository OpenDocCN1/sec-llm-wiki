0x00 漏洞概述

Citrix Gateway和ADC是美国思杰（Citrix）公司的产品。

2022年5月25日，Citrix发布安全公告，修复了Citrix ADC 和 Citrix Gateway中2个可导致拒绝服务的漏洞（CVE-2022-27507和CVE-2022-27508）。

 

0x01 漏洞详情

Citrix Gateway是一套安全的远程接入解决方案，可提供应用级和数据级管控功能，以实现用户从任何地点远程访问应用和数据；Citrix ADC是一个全面的应用程序交付和负载平衡解决方案，用于实现应用程序安全性、整体可见性和可用性。

由于设备可能存在不受控制的资源消耗，Citrix ADC 和 Citrix Gateway某些版本中存在如下2个拒绝服务漏洞：

CVE-2022-27508：Citrix ADC & Gateway未经验证的拒绝服务漏洞（高危）

当设备配置为 VPN（Gateway）或 AAA 虚拟服务器时，此漏洞将影响以下受支持的Citrix ADC和Citrix Gateway版本：

Citrix ADC 和 Citrix Gateway 12.1-64.16 。

CVE-2022-27507：Citrix ADC & Gateway经验证的拒绝服务漏洞（中危）

如果启用了DTLS并配置了 "HDX Insight for EDT traffic"或 "SmartControl"，此漏洞将影响以下受支持的Citrix ADC和Citrix Gateway版本：

Citrix ADC和Citrix Gateway 13.1 < 13.1-21.50

Citrix ADC和Citrix Gateway 13.0 < 13.0-85.19

Citrix ADC 和 Citrix Gateway 12.1< 12.1-64.17

Citrix ADC 12.1-FIPS < 12.1-55.278

Citrix ADC 12.1-NDcPP < 12.1-55.278

 

0x02 安全建议

目前这些漏洞已经修复，建议受影响用户及时升级更新到以下版本：

Citrix ADC 和 Citrix Gateway 13.1 >= 13.1-21.50 

Citrix ADC 和 Citrix Gateway 13.0 >= 13.0-85.19

Citrix ADC 和 Citrix Gateway 12.1 >= 12.1-64.17

Citrix ADC 12.1-FIPS >= 12.1-55.278 

Citrix ADC 12.1-NDcPP >= 12.1-55.278

下载链接：

https://www.citrix.com/support/

注：针对CVE-2022-27507可按以下方式排查。

1.查看是否启用 DTLS。客户可以通过执行以下 CLI 命令来确定是否启用了 DTLS：

show vpn vserver

2.查看是否配置了 "HDX Insight for EDT traffic "或"SmartControl"。客户可以通过检查 ns.conf 文件中的 ICA_REQUEST 类型的 VPN vserver 策略绑定来确定是否已配置“HDX Insight for EDT traffic”或“SmartControl”。例如：

bind vpn vserver <name> -policy<policy_name> -priority 100 -type ICA_REQUEST

3.如果仅受CVE-2022-27507影响并启用了DTLS和配置了 "HDX Insight for EDT traffic"或 "SmartControl "的客户可以选择禁用 "HDX Insight for EDT traffic "以缓解此漏洞。
