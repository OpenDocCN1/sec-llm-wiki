0x00 风险概述

2022年4月11日，CISA将8个已知漏洞添加到被利用的安全漏洞目录中，这些漏洞涉及WatchGuard、Microsoft、Google、Checkbox、Linux、QNAP和Telerik等厂商和项目。

 

0x01 攻击详情

CISA本次新增的8个漏洞都是已知被积极利用的安全漏洞，对企业和组织构成了重大风险，漏洞详情如下：

CVE-2022-23176

WatchGuard

WatchGuard  Firebox 和 XTM 权限提升漏洞

WatchGuard  Firebox 和 XTM 设备允许在具有非特权凭据的情况下通过公开的管理访问权限远程访问具有特权管理会话的系统。该漏洞影响了12.7.2_U1之前的Fireware OS，12.1.3_U3之前的12.x，以及12.2.x到12.5.7_U3之前的12.5.x。

2022/5/2

CVE-2021-42287

Microsoft

Microsoft  Active Directory Domain Services权限提升漏洞

Microsoft  Active Directory Domain Services存在允许权限提升的未明漏洞。该漏洞已于2021年11月修复。

2022/5/2

CVE-2021-42278

Microsoft

Microsoft  Active Directory Domain Service权限提升漏洞

Microsoft  Active Directory Domain Service存在允许权限提升的未明漏洞。该漏洞已于2021年11月修复。

2022/5/2

CVE-2021-39793

Google

Google Pixel  越界写入漏洞

由于代码中的逻辑错误，Google Pixel 存在越界写入漏洞，可能导致本地权限提升。

2022/5/2

CVE-2021-27852

Checkbox

Checkbox Survey

反序列化漏洞

Checkbox  Survey 的 CheckboxWeb.dll 中的不可信数据反序列化漏洞允许在未经身份验证的情况下远程执行任意代码。该漏洞影响了Checkbox Survey 7之前的版本。

2022/5/2

CVE-2021-22600

Linux

Linux kernel权限提升漏洞

Linux kernel在数据包套接字 (AF_PACKET) 实现中存在一个缺陷，可能导致错误地释放内存，本地用户可以利用此漏洞导致拒绝服务或实现权限提升。

2022/5/2

CVE-2020-2509

QNAP

QNAP 网络附加存储  (NAS) 命令注入漏洞

QNAP NAS 设备存在命令注入漏洞，允许远程执行代码。

2022/5/2

CVE-2017-11317

Telerik

Telerik UI  for ASP.NET AJAX 无限制文件上传漏洞

由于使用弱的RadAsyncUpload加密，

Telerik.Web.UI  in Progress Telerik UI for ASP.NET AJAX允许上传任意文件或远程执行任意代码。

2022/5/2
