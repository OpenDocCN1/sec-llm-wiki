**Pulsar **是一款适用于 Red Teams、Pentesters 和 Bounty Hunters 的自动化网络足迹扫描器。它专注于发现组织面向公众的资产，而对其基础设施知之甚少。连同网络数据可视化，它试图给出一个基本的漏洞分数，以找到基础设施的弱点及其与其他资源的关系。它还可以用作广泛和未知范围的自定义漏洞扫描程序。该软件的创建考虑了可用性和开放性，因此它是 100% 免费的，并且不需要任何 API 密钥即可使用其功能。

  

## 主要特征

*   子域发现
    
*   顶级域名发现
    
*   云资源发现
    
*   基础漏洞扫描
    
*   扫描策略和优化
    
*   数据可视化
    
*   协作和数据导出
    
*   调度和通知
    
*   REST API
    
*   外部 API 集成
    
*   OAUTH 集成
    
*   自定义扫描仪扩展
