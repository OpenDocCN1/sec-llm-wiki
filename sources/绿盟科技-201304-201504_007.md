# 绿盟数据泄露防护系统（NSFOCUS DLP）上市

4月8日，国内信息安全领军企业绿盟科技发布了一款数据安全产品——绿盟数据泄露防护系统（NSFOCUS Data LossPrevention System，以下简称NSFOCUS DLP ），这是继2014年的绿盟数据库审计系统（NSFOCUS DAS）之后，绿盟科技发布的又一款数据安全产品，从而形成了对结构化数据和非结构化数据的全面保护。

  

![](../Images/c26ff80b000d6a860817b00d0844a133.png)  
  

近些年频频发生的用户敏感信息泄露事件，给企业信誉、经济等方面带来了巨大的损失；而棱镜门事件的发生，则威胁到了国家的安全。这使得国家在政策层面、企业在意识层面，对敏感信息泄露的防护以及安全产品的自主可控提出了前所未有的严格要求。绿盟数据泄露防护系统的发布将打破这一领域长期被国外厂商垄断的局面。

  

“专攻术业、成就所托”，绿盟科技始终秉承着为客户打造业界最值得信赖的安全产品的理念，此次发布的NSFOCUS DLP产品又有哪些地方值得期待呢？
