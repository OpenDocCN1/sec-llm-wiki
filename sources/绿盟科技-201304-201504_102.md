# 【Web漏洞响应】Drupal惊爆SQL注入漏洞

**漏洞概述**

今日上午消息：连续多年荣获全球最佳CMS大奖，基于PHP语言最著名的开源WEB应用程序Drupal被爆出SQL注入漏洞（CVE-2014-3704）。该漏洞广泛存在于Drupal 7.x系列中7.31之前所有版本（Drupal >= 7.0 <= 7.31），远程攻击者可以非登录状态SQL注入，获取管理员权限，甚至实现远程代码执行，获取webshell。

考虑到此注入漏洞利用没有任何限制，且影响范围非常广泛，目前国际安全专家认定这一SQL注入漏洞的严重程度为8级，这就是说会有更多的黑客利用它造成更严重的安全危机。

**成因分析**

Drupal在所有的SQL查询语句当中都是用的预编译来处理。在处理IN语句时，存在逻辑问题，有一个expandArguments函数来展开数组。该函数若带入数组当中有key并且不是整数，由于Drupal使用PDO，因此可以多语句查询。所以这个SQL注入向数据库里插入任意数据，下载或者修改存在的数据，甚至drop掉整个数据库。导致攻击者可以通过向数据库里插入任意的数据，利用Drupal的特性执行PHP代码，获取管理员权限，甚至通过这个问题实现远程代码执行。

**如何核查是否存在该漏洞**

绿盟科技依托于多年来在攻防领域的技术积累，Web漏洞应急响应团队依据漏洞成因分析，第一时间权威发布此高危Web漏洞的检测插件。

用户可选择专攻于Web脆弱性安全评估的绿盟Web应用漏洞扫描系统（简称WVSS产品），通过更新最新插件库进行该漏洞的快速定位发现。
