# 什么叫工控系统？ICSScan面前你必须了解的

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=201095320&idx=1&sn=0844828e5b0c48a5539ae099b78078bc&chksm=28cf21331fb8a825617481cbf75bdaff4516268ab74e111cc4fb2230b511fa569de6c0d0962f&scene=126&sessionid=1681372671#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=201095320&idx=1&sn=0844828e5b0c48a5539ae099b78078bc&chksm=28cf21331fb8a825617481cbf75bdaff4516268ab74e111cc4fb2230b511fa569de6c0d0962f&scene=126&sessionid=1681372671#rd)

绿盟工控漏洞扫描系统（ICSScan）已在上周正式发布了。这款产品在能源烟草行业和测评机构都很受关注。顾名思义，工控漏洞扫描系统可以对工控系统的漏洞进行扫描，但什么是工控系统呢？今天就给大家扫个盲。

工控系统指的是工业自动化控制系统，主要利用电子电气、机械、软件组合实现。主要是使用计算机技术，微电子技术，电气手段，使工厂的生产和制造过程更加自动化、效率化、精确化，并具有可控性及可视性。

工厂里会有很多元器件：阀门、开关、温度计、压力计等一系列东西。这些东西都有特定的功能，但本身这些元器件是“傻”的，只知道按命令开、关或上报数据……而他们接受的命令就是类似计算机领域的机器码（比汇编语言还要低级）。

工控系统就是控制这些元器件的，什么时候开，开多大，什么时候报数据……工控系统直接给元器件下命令。

直接给元器件下命令的工控设备是一些专用的设备（DCS、PLC），这些专用设备接收高级的指令，然后翻译成元器件能执行的命令。这些设备叫下位机。

工控系统还有上位机，上位机就是控制计算机系统，包括工控软件、数据库等。上位机主要供人员操作。工程师在上位机上直接操作，上位机接收工程师的命令后，将命令分解给下位机。

![](../Images/748e2ab7babd6ea18645e25d98d05f76.png)

总结一下，工业系统是一个类似分布式计算机系统的系统。上层是上位机，中层是下位机，下层是元器件设备。其中上位机和下位机共同组成了工业控制系统。
