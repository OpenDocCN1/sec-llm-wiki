# 【Web漏洞响应】ECShop系统被爆任意用户登陆漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=200515692&idx=1&sn=52803a46f72aba107ce2f1e881d41126&chksm=28c0f9c71fb770d19e9a9f20acaccdcc344322c1723f20c8d07cfd9d28d274a47aee2d2ebb84&scene=126&sessionid=1681372676#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=200515692&idx=1&sn=52803a46f72aba107ce2f1e881d41126&chksm=28c0f9c71fb770d19e9a9f20acaccdcc344322c1723f20c8d07cfd9d28d274a47aee2d2ebb84&scene=126&sessionid=1681372676#rd)

日前，网店系统ECShop被爆存在任意用户登陆的高危漏洞。远程攻击者可在装有ECShop系统官方所有下载版本的服务器端，利用此漏洞无需密码，登陆任意用户的账号，获取任意用户敏感数据，进行一系列重大破坏活动。

 

绿盟科技第一时间分析出该漏洞成因是ECShop系统某页面的流程有效性判断有误，从而导致此漏洞发生。目前绿盟科技的Web应用漏洞扫描系统（简称WVSS产品）已经实现了此Web漏洞的检测能力，强烈建议装有ECShop系统服务器的用户尽快进行补丁修复。
