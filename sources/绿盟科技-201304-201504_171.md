# 【紧急安全通告】Apache Struts2 CVE-2014-0094修复补丁绕过漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=200164033&idx=1&sn=1ca8977d23376b5bdc3b8459514cf969&chksm=28dd1b6a1faa927c3b53bfdbaf5cb6b8fb29cd15f0455f96a43b847d8cadf24cd8d5313004bb&scene=126&sessionid=1681372679#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=200164033&idx=1&sn=1ca8977d23376b5bdc3b8459514cf969&chksm=28dd1b6a1faa927c3b53bfdbaf5cb6b8fb29cd15f0455f96a43b847d8cadf24cd8d5313004bb&scene=126&sessionid=1681372679#rd)

  

发布日期：2014-04-24

  

CVE ID：CVE-2014-0094

  

受影响的软件及系统：

\====================

Apache Struts 2.0.0 - Apache Struts 2.3.16.1

  

综述：

\======

Apache Struts2在处理修复CVE-2014-0094的漏洞修补方案存在漏洞，导致补丁可被完全绕过，攻击者通过提交精心构造请求，绕过修复补丁造成文件泄漏或拒绝服务，在特定情况下（例如Tomcat 8）可造成远程执行任意命令。

  

目前Apache Struts2在Github上提交的修复方案仍然存在被绕过的可能性。强烈建议Apache Struts2用户暂时启用WAF、IPS等设备防御可能的攻击。

![](../Images/fd453ca9f4f975dc67fd67175296cb99.png)

  

分析：  

\======

Struts2 是第二代基于Model-View-Controller (MVC)模型的web应用框架。 Struts2是java企业级web应用的可扩展性的框架。它是WebWork和Struts社区合并后的产物。

  

Apache Struts2在2.3.16.1版本之前，提供class参数传递的功能，但由于此功能可导致用户操控服务器运行环境中的一些对象，因此在2.3.16.1中禁用了此功能。但是由于防护规则不完善，导致可被攻击者绕过。

  

  

厂商状态：

\==========

厂商暂未修复此安全漏洞，强烈建议Struts用户启用WAF、IPS等设备防御可能的攻击。

并在厂商修补后及时升级到最新版本。

http://struts.apache.org/
