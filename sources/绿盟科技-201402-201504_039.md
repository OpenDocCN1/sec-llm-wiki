# 绿盟科技四款产品入围电信集采

在2014年中国电信集团的集采中，绿盟科技4款产品:ADS、IPS、FW、WAF均表现优异，全部入围！这是中国电信集团对绿盟科技产品的认可，也证实了绿盟科技在安全行业领军者的地位。

  

绿盟科技4款产品在各自领域中均表现出了优异的竞争力：

  

ADS：

  

*   卓越的处理性能表现。单体可达到40Gbps的转发性能，支持在各类复杂的网络环境中部署，并具备丰富的流量牵引、流量分析、流量净化和流量疏导方式，能够与绿盟WEB应用防护系统以及第三方流量分析设备联动，构成一体化网络边界安全纵深防护体系。
    
      
    
*   领先的DDoS攻防技术。产品针对网络层洪水攻击、应用层攻击、CC及其变种、慢速攻击、畸形报文攻击、可变窗口攻击和混合攻击能够进行准确的识别，并通过牵引、清洗和回注来实现全局流量的安全闭环管理。
    
      
    
*   优秀的一体化应急保障体系。绿盟ADS成为亚太区唯一被国际三大权威咨询机构提及的抗DDoS产品。配合国家级应急响应支撑单位的称号和覆盖全国主要省市的本地化技术支持网络，能够为客户持续提供全面、及时和专业的抗DDoS应急响应服务。
    
      
    

IPS：

  

*   领先的攻击检测能力。绿盟科技有着十余年的攻防研究积累，使绿盟NIPS具备着业界领先的攻击检测能力，在电信测试中检测率处在业界领先水平。从2012年到2014年连续三年入选国际知名第三方咨询机构Gartner IPS魔力象限，从2009年到2014年连续六年国际知名机构IDC报告市场占有率第一，进一步证明绿盟科技多年在电信集采都入围并且保持领先的表现绝非偶然。
    
      
    
*   独创的高级威胁防护能力。提供Web安全、服务器异常、客户端防护、敏感数据外泄拦截等防护能力，为客户提供全面的基础设施、服务器及客户端的入侵防护。
    
      
    
*   完善的新一代入侵威胁解决方案。绿盟NIPS与绿盟新一代威胁分析检测设备（TAC）组成绿盟新一代安全威胁防护解决方案NGTP，能够对未知威胁和高级持续性威胁APT进行防护，为客户提供了一套全面、精准、高效易用的入侵防护解决方案。
    
      
    

FW：

  

*   完善的基础功能。可以针对应用、用户、IP、端口、服务等信息对流量做多管道式的控制管理，并提供IPSEC VPN和SSL VPN灵活的远程安全连接，全面适用于IPV4及IPV6的网络防护。
    
      
    
*   可靠的稳定性。采用数通和安全双引擎，数通引擎负责业务转发，安全引擎负责安全检查及防护。当安全引擎升级或故障时，数通引擎仍然可以顺畅地进行转发，保障业务不中断。
    
      
    
*   全方位的威胁管控。提供入侵防御，病毒防护，内容管理，URL过滤等功能，对隐藏于应用流量中的潜在威胁做到多层级，全方位的扫描和防护。
    
      
    

WAF：

  

*   高效细致的规则体系。绿盟WAF的规则体系基于多年网络安全研究积累，已高度细化，可完美防护各类攻击。凭借其强大的研发团队入选2014 Gartner WAF魔力象限。
    
      
    
*   高稳定性。绿盟WAF具备硬/软件bypass、逃生机制、紧急机制等措施，大大降低了WAF单点故障概率，保证客户业务畅通，在金融、运行商、政府等行业饱受好评。
    
      
    
*   智能联动方案。绿盟WAF可以和抗DDoS设备以及扫描器进行联动，通过立体化的解决方案，为客户解决安全问题。
    
      
    

北京神州绿盟信息安全科技股份有限公司（以下简称绿盟科技）成立于2000年4月，总部位于北京。在国内外设有30多个分支机构，为政府、运营商、金融、能源、互联网以及教育、医疗等行业用户，提供具有核心竞争力的安全产品及解决方案，帮助客户实现业务的安全顺畅运行。基于多年的安全攻防研究，绿盟科技在网络及终端安全、互联网基础安全、合规及安全管理等领域，为客户提供入侵检测/防护、抗拒绝服务攻击、远程安全评估以及Web安全防护等产品以及专业安全服务。
