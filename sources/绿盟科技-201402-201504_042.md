# 绿盟科技连续三年入选Gartner IPS魔力象限

近日，国际权威咨询机构Gartner发布了2014年IPS魔力象限《Magic Quadrant for IntrusionPrevention Systems》报告，2014年的IPS魔力象限入选厂商从上一年度的10家减少为7家，在此严峻的环境下，绿盟科技第三次入选Gartner IPS魔力象限。

  

2012年之前的Gartner IPS魔力象限无一亚太厂商入选，绿盟科技率先以亚太唯一厂商的身份进入了Gartner IPS魔力象限，从2012年到2014年，已连续三年入选。

  

绿盟科技凭借多年在入侵防护领域的研究和大量的研发投入，以其领先的技术实力，强大的攻防研究能力，保持了IPS产品国内领先水平并得到了市场的认可，IDC市场报告显示绿盟科技NIPS从2009年到2013年连续五年国内市场占有率第一。

  

绿盟网络入侵防护系统（简称，绿盟NIPS）是绿盟科技推出的最新一代入侵防护和检测产品，面向互联网时代激增的网络安全问题，提供Web安全、服务器异常、客户端防护、高级威胁防护、敏感数据外泄拦截等防护能力，为金融、运营商、政府等客户提供全面的基础设施、服务器及客户端的入侵防护。绿盟NIPS使用领先的下一代网络分析引擎，在传统漏洞攻击签名基础上，使用全球信誉库机制，小时级的漏洞库更新保证了防护的及时全面。引入业界领先的软硬件检测框架，在流量峰值时，依然能保证性能稳定。绿盟NIPS通过内置丰富的面向客户场景的策略模板和配置向导，可实现零配置上线，策略管理极其简便易用。绿盟NIPS与绿盟新一代威胁分析检测设备（TAC）组成绿盟新一代安全威胁防护解决方案NGTP（Next Generation Threat Protection），能够对未知威胁和高级持续性威胁APT进行防护，为客户提供了一套全面、精准、高效易用的入侵防护解决方案。
