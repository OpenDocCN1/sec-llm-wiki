# 一大波Web漏洞来袭 绿盟科技紧急安全响应

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=201036946&idx=2&sn=f32c25fa939f3ba2834007a3cdce3140&chksm=28c8cd391fbf442fb97f18e3980774c45638f940466a5655377e0bb175f8a55c75653bca6f10&scene=126&sessionid=1681372672#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=201036946&idx=2&sn=f32c25fa939f3ba2834007a3cdce3140&chksm=28c8cd391fbf442fb97f18e3980774c45638f940466a5655377e0bb175f8a55c75653bca6f10&scene=126&sessionid=1681372672#rd)

**漏洞概述**

近日，广泛应用于政府门户、信息公开的内容管理系统大汉版通JCMS，及知名论坛Discuz!、PHPWind、建站工具PHPCMS系统被爆多处漏洞，存在被恶意利用和入侵的高危风险。

大汉版通JCMS，远程攻击者可在其全版本的服务器端，任意读取系统文件来获取Webshell，或sql注入非法获取数据库敏感信息；

Discuz!系统，其Discuz X3.2及以下版本存在sql注入漏洞，远程攻击者通过管理员权限可以利用此漏洞获取数据库敏感信息；

PHPWind系统，全系列版本都存在信息泄露漏洞，远程攻击者可以利用此漏洞查看任意用户信息甚至修改用户密码 ；

PHPCMS系统，其PHPCMS V9.5.7及以下版本存在某处SQL注入漏洞，远程攻击者无需登录，即可利用此漏洞获取数据库敏感信息。

**成因分析**

绿盟科技依托于多年来在攻防领域的技术积累，第一时间分析出漏洞成因：

系统任意文件读取漏洞。由于大汉版通JCMS对某参数过滤不严，导致访问者可以读取任意配置文件，并从中获取管理员密码、数据库登陆用户名和密码。利用这些信息攻击者可以实现进一步攻击，从而获取webshell；

信息泄露漏洞。由于PHPWind对某关键信息操控不严，导致攻击者在拥有一定权限的前提下可以直接获得，如查看任意用户信息甚至修改用户密码等。

SQL注入漏洞。皆因大汉版通JCMS、Discuz、PHPCMS对某处参数处理不当，导致用户输入的数据可以直接拼接进入代码和SQL语句中，从而造成此类SQL注入漏洞发生。

**如何核查是否存在该漏洞**

专攻于Web脆弱性安全评估的Web应用漏洞扫描系统（简称WVSS产品），已在漏洞爆出后的第一时间内完美实现此波Web漏洞的检测能力，可通过更新插件库进行快、准、全的扫描发现。

**推荐用户应急措施**

鉴于如上应用范围广，覆盖用户多的特点，且考虑到目前还未提供补丁和升级程序，绿盟科技建议装有其系统的服务器用户，在关注其厂商主页以获取最新补丁或者最新版本程序的同时，也可以联系绿盟科技尝试本地化完美的安全解决方案。

备注：

大汉版通JCMS（Java Content Management System）是一套基于J2EE构架设计，以全新理念构建的内容管理系统。系统提供了从内容采集、创建、管理、传递、发布、共享呈送等信息全生命周期过程中所需的各项功能。

Crossday Discuz! Board 论坛系统（简称 Discuz! 论坛）是一个采用 PHP 和 MySQL 等其他多种数据库构建的高效论坛解决方案。Discuz! 在代码质量，运行效率，负载能力，安全等级，功能可操控性和权限严密性等方面都在广大用户中有良好的口碑。

PHPWind 论坛系统是一套采用 php+mysql 数据库方式运行并可生成 html 页面的全新且完善的强大系统。因具有非凡的访问速度和卓越的负载能力而深受国内外朋友的喜爱。

建站关键PHPCMS V9版于2010年推出，是应用较为广泛的建站工具。第三方数据显示，目前使用PHPCMS V9搭建的网站数量多达数十万个，包括联合国儿童基金会等机构网站，以及大批企业网站均使用PHPCMS V9搭建和维护。
