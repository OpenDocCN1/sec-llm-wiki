本期DDoS兵器谱将要介绍的三款工具的最新进展，他们是**XOIC、Zarp**和**Slowhttptest**。

*   XOIC可以说是工具LOIC的加强版，使用C#编写，运行于win7及以上系统（.NET FRAMEWORK 3.5及以上）；
    
*   Zarp是一款综合性攻击测试框架，DDoS仅是其一部分功能，其它的还包括漏洞扫描等，并且新增加的模块不涉及DDoS攻击；
    
*   Slowhttptest新版最大的改进是界面以及日志的输出，比之前更为简洁。
    

# 1.XOIC

![](../Images/14964a376df9e2a8ded1500bf599d8bb.png)

   

相对于LOIC的多平台（GNU/Linux, Windows, Mac OS以及Android），XOIC可运行的环境则少的多，仅支持win7以上的Windows平台。和LOIC相比，工具主打的还是流量型攻击，不过相比前者增加了Testmode模式，可以测试攻击主机的性能。 另外，在实际的测试中发现了工具的一个小BUG。

![](../Images/f5a1cacc32036fe70a0cc502bf73d390.png)

   

# 2.Zarp

Zarp是采用Python编写的、类似MSF的一款网络攻击测试框架。工具采用模块化设计，集漏洞扫描、嗅探、DDoS压力测试于一身。Zarp主要接口是一个CLI驱动的图形界面，采用多层菜单，使用起来相当方便。目前运行平台只限于linux，同时在安装之前要确保系统存在python2.7.x、git以及scapy。

 

![](../Images/275f7191049ed0008e9f5b66e6ef483a.png)

  

# 3.Slowhttptest

Slowhttptest主要用于慢速攻击测试，它包含了多种流行的攻击方式，如slowloris、slow http post以及slow read attack等。主要工作于linux平台。新版本除修复部分bug外，最大的改变就是界面的改进。下面对其主要的攻击方式做简要概述，并给出可能的防御建议。

**3.1.Slowloris**

slowloris在这里又被称为slow headers，其基本原理是制造不完整的header。完整的http请求头结尾应该是“0d0a0d0a”，而但攻击工具只发送“0d0a”。然后以固定的时间间隔，反复发送随机的key-value键值对，迫使服务器持续等待（至超时）。最终通过不间断的并发连接耗尽系统的最大连接数直至服务端DOS。

**3.2. Slowhttp post**

Slow http post也称为Slow body。顾名思义，攻击的着眼点放在了发送内容的过程中。

**3.3. Slowread**

Slow read攻击简单说就是，通过调整TCP协议头中的window size来控制双方的数据流速率，尽可能长的保持单次连接的交互时间，直至超时。要使这种攻击效果更加明显，请求的资源要尽量大，比如我这里的测试图片test.png，其大小为4M多。如果目标网站没有这么大的资源，但若其支持http\_pipelining的话，可以采用在同一连接中多次请求同一资源的方法来增大返回内容。从捕获的数据包中可以看出，当请求 test.png资源时，客户端window size被刻意设置为1120字节。客户端缓冲区在被来自服务的数据填满后，发出了\[TCPZeroWindow\]告警，迫使服务端等待。从交互开始到断开，单个连接耗费了14秒。

**检测防御**

特征匹配： 这里看一下工具的部分源代码，我们可以把useragent搭配referer作为特征。

![](../Images/c6b0fa04dee34054889743ced7c87e37.png)

   

使用ModSecurity： 基于特征匹配其局限性比较大，容易被绕过，尤其是针对开源的工具。我们的另一种选择是使用专业的检测模块ModSecurity。最新版本为2.8，支持多个平台，它采用的是基于规则的匹配。它有基础的免费防护规则，不过商业规则需要付费。

![](../Images/2a960c535f7f514871328b4f2b653796.png)

   

通用方案： 设置单个IP单位时间内的并发连接数，并对每个连接请求创建一个定时器并设置合适的超时时间，触发任一规则，则断开连接，当然也可配合黑白名单机制。
