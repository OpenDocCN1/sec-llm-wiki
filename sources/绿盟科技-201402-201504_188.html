金银两项国际奖项 绿盟科技获得认可

       Info Security Products Guide第10届2014年度Global Excellence Awards颁奖典礼现场，业界各领域表现卓越的产品云集，绿盟科技MSS服务中的绿盟ADS可管理安全服务（NSFOCUS MSS for ADS）荣获两项大奖：“Best Managed Security Service（最佳可管理安全服务）”金奖和“Business Expansion of the Year（年度业务拓展）”银奖。

这次信息安全行业的盛会，来自全球广泛领域的50多个评委参与了评选，他们给出的平均分确定了2014 Global Excellence Awards的入围者和获奖者。对这些卓越的产品、成功产品背后的人和最优秀的公司，给予充分认可。

负责北美市场的绿盟科技美国子公司总经理Frank Ip 在获奖感言中提到：“安全行业各同仁对我们公司MSS产品的这一认可，印证了我们对客户的承诺，也就是为客户提供可以抵御任何规模威胁的一流安全保护。受‘黑客经济学’（即攻击者会使用最少的资源造成最大的破坏或收益）的驱动，DDoS在不断发展变化中，而MSS可以帮助我们的客户处于安全等级最前沿。”

绿盟可管理安全服务（MSS）

绿盟可管理安全服务（MSS）是绿盟科技云安全运营中心在原有优秀安全产品的基础上，进一步融合云平台技术，推出的可管理的7x24小时安全闭环运营解决方案。包括：

n  绿盟ADS可管理安全服务（NSFOCUS MSS for ADS）

绿盟科技在原有ADS和NTA产品基础上，进一步融合云平台技术，推出7x24小时DDoS监测与防御解决方案。该方案可以实现将客户本地的ADS和NTA设备与绿盟安全云对接和同步，由绿盟安全专家团队提供专业的拒绝服务攻击监视、响应、防护服务。目前，该方案已经在国内外运营商、数据中心、互联网、企业等行业积累了众多成功案例。

n  绿盟WAF可管理安全服务（NSFOCUS MSS for WAF）

绿盟科技在原有WAF产品的基础上，进一步融合云平台技术，推出7x24小时WEB应用云监护解决方案。该方案可以实现将客户本地WAF设备与绿盟安全云对接和同步，由绿盟安全专家团队提供专业的网站安全隐患和遭受的攻击威胁监视、响应、防护服务。目前，该方案已经在国内外政府、教育、互联网、企业、IDC等行业积累了较多成功案例。

补充信息：

《Info Security Products Guide（信息安全产品指南）》是美国信息安全行业内一家知名杂志，它在让最终用户随时了解保护资产的可选方案方面，具有至关重要的作用。该杂志主要面向那些必须随时了解安全隐患信息及相应防御措施的读者。读者可从该杂志中可以找到大量的信息，包括T3信息 (tomorrow's technology today)、最佳部署方案、对构筑信息安全有重要意义的人物和技术信息、畅销产品，以及有助于用户作出最佳安全决策的独立产品测评结果等。该杂志每年都会对所有信息安全领域的卓越产品、技术和公司进行表彰和奖励。
