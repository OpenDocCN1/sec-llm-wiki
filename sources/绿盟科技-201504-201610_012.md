# 你的DNS有漏洞啦！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650386941&idx=3&sn=68c90ab4706dad7292a6a19173bb440e&chksm=becae85689bd6140dac3363308c59ccecdb76af434a858d0340e7eedcdf4f1caac9a61cb0e1f&scene=126&sessionid=1681372606#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650386941&idx=3&sn=68c90ab4706dad7292a6a19173bb440e&chksm=becae85689bd6140dac3363308c59ccecdb76af434a858d0340e7eedcdf4f1caac9a61cb0e1f&scene=126&sessionid=1681372606#rd)

2016年10月14日，现今互联网上最常使用的DNS服务器软件BIND（Berkeley Internet Name Daemon）爆出一个惊天漏洞！黑客只需精心构造一个查询请求的攻击包访问使用该软件的DNS服务器，程序立刻崩溃无法对外提供服务。如今，这个"精心构造"的攻击包现在在互联网上已经是唾手可得……  
想知道自己的DNS服务器是否受该漏洞影响？即刻关注“绿盟云”微信服务号，选择“服务”菜单栏“紧急漏洞检测”检测结果立等可取！![](../Images/1229d77f29e0102e3928e3b1c2626009.png)  
![](../Images/9a35798e9baf4b7a2c8941357702d578.png)  
**背景**ISC互联网系统协会（Internet Systems Consortium）官网发布了一个安全通告，公布了编号为CVE-2016-2776的漏洞及其修复情况。该漏洞位于文件buffer.c中，当程序在为精心构造的查询请求构建响应时会遇到断言失败，导致程序崩溃，从而造成拒绝服务。详情请见如下链接：https://kb.isc.org/article/AA-01419**中国及全球漏洞分布情况****中国受影响设备分布**中国各省份及地区分布的受此漏洞影响的设备总数量达6039个。其中台湾地区所占数量最多，有1752台设备受影响，国内受影响最大的省份是北京、山东、黑龙江。TOP10省份的受此漏洞影响的设备数量占中国总数的84.47%。其余15.53%的数量分散于其他省份或地区内。![](../Images/ee30e093295cf797dd9b489cc39db3b8.png)![](../Images/e4dde5324010406cf79af06d0fd5165f.png)**全球受影响设备分布**同时，截止到今天，我们统计全球范围内存在此安全漏洞的设备数量就已经达到70,392个。受此漏洞影响的设备数量最多的国家是美国，占全部的43.13%，其次是俄罗斯，占10.7%，第三是中国，占8.58%，剩余国家分别是印度、瑞典、印度尼西亚、巴西、德国、乌克兰、保加利亚等。![](../Images/06722f1bc7e7f31c2b3bfa15afc2ce44.png)![](../Images/05b7dd6bafa6b9924941f5dfbf2523d5.png)**总结**绿盟威胁情报中心NTI会持续关注此漏洞，建议用户启动应急响应，尽快进行漏洞修复。
