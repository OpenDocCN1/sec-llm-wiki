# 绿盟科技深度参与第五届全国信息安全等级保护技术大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650386872&idx=1&sn=b16da87ac2af128838680c36a16b9775&chksm=becae81389bd6105968971c6931d0022e3cd006d8a9b5094d794c6b1da4dd5efa4630eff6013&scene=126&sessionid=1681372608#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650386872&idx=1&sn=b16da87ac2af128838680c36a16b9775&chksm=becae81389bd6105968971c6931d0022e3cd006d8a9b5094d794c6b1da4dd5efa4630eff6013&scene=126&sessionid=1681372608#rd)

![](../Images/927c8b78afcc0b8c4fa2cfd4efb305a0.png)

2016年10月10日，第五届全国信息安全等级保护技术大会于云南昆明成功举办，绿盟科技携绿盟安全态势感知平台、等保扫描器、绿盟网站安全监测平台等安全产品参与本次大会，绿盟科技副总裁陈珂为与会各界嘉宾带来了题为《情报驱动的安全治理创新——威胁和漏洞管理》的专题演讲。本次大会吸引了来自国家部委央企、全国的公安网安、全国各地信息安全测评机构、安全企业、各大高校的代表以及本届大会优秀论文的作者等近600人出席。中科院、国家密码局、工信部、网信办、国家信息中心、公安部网络安全保卫局、云南省公安厅、中海油、银监会等部委，以及部分信息安全企业专家、领导在会上做了重要讲话和专题演讲，本次大会为信息安全职能部门、专家学者、行业用户和信息安全企业提供一个开放的技术交流平台，共同分享等级保护的技术、方法以及实践的最新研究成果。![](../Images/d0c26ba05f7a2793c75530695ff1059a.png)信息安全等级保护制度是指导我国信息安全工作的基本制度。绿盟科技副总裁陈珂在专题演讲中就等保体系中非常核心的一个技术点——漏洞与风险管理，与参会嘉宾分享了绿盟科技的想法和实践经验。![](../Images/d2a0e0a62ed7a3a72584c49bbab3de1f.png)陈总强调，在企业安全建设中，应不断地将大数据分析、威胁情报等最新的攻防技术，安全防御的最佳实践与等级保护的基本要求相结合，最终形成集预警、防护、检测和响应于一身的可落地闭环安全运营体系。![](../Images/d9e6d4213466c34226521bf3f8a1feff.png)  
绿盟科技以现场动态展示吸引与会嘉宾了解绿盟安全态势感知平台、等保扫描器、绿盟网站安全监测平台等产品，展示绿盟科技在安全领域的经验积累及不懈创新的成果。![](../Images/3277972ce17bfa954ddc634a88565b5f.png)  
此外，公安部第三研究所胡传平所长在致辞中表示，掌握互联网核心技术，掌握互联网主动权，才能保障安全。如何突破核心技术难题实现弯道超车，在大数据、云计算、物联网、智慧城市、工控信息安全及系统安全方面快速发展，是本次大会的核心主旨。会上的成果展示、成功经验交流和技术前沿探索，围绕网络安全保护策略、机制、新技术新应用、信息安全产品、国外网络安全政策标准和等级保护技术体系等核心内容，将推动企业技术水平和服务能力的提高。![](../Images/287bb14ef7d8919c8270026e114f99d3.png)随后，公安部网络安全保卫局郭启全总工发表了题为《加快完善国家信息安全等级保护制度，全力保卫关键信息基础设施安全》的演讲，他提到，等级保护制度已经进入2.0时代，构建“打防管控”一体化的网络安全综合防护体系、开展信息通报预警平台、建立网络安全重大漏洞隐患的监测发现和整改督办机制，是需要思考和落实的重点问题。同时，他还分享了网络安全战略规划目标，从国家等保制度和防御管理方面做了详细阐述。  
  
绿盟科技作为安全领域领军企业，始终积极参与着等保体系的推进、落地以及维护和修订工作，在网络安全建设方面有着义不容辞的责任。未来，绿盟科技将继续专注研究，实现技术突破和创新，在网络安全防护、保护关键信息基础设施安全等方面持续发力。
