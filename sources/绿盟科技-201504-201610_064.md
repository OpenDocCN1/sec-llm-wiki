# 拉萨站 |自治区安全周全面宣传引热议 绿盟科技深度合作持续发力

2016年9月19日，“2016年国家网络安全宣传周西藏自治区活动开幕式暨网络安全启动日主题宣传活动”在西藏自治区首府拉萨市宇拓路举行。绿盟科技在本次宣传周活动中展示了多种防护平台及安全防护产品，并与自治区内多家单位达成深度合作，为西藏全区网络安全提供切实完善的保障。![](../Images/47334fec10ef78377294250fd22a6515.png)  
本次活动由西藏自治区党委网信办牵头组织，由西藏自治区教育厅、自治区公安厅、自治区工信厅、自治区通信管理局、团区委以及自治区内三大运营商、七大银行、北京神州绿盟信息安全科技股份有限公司等20余家企事业单位共同参与举办。![](../Images/d36252776c187280b2bfd8db3726b594.png)  

**西藏自治区党委副书记、自治区主席洛桑江村，**

**自治区党委副书记、自治区常务副主席、自治区党委政法委书记、自治区互联网党工委书记邓小刚，**

**自治区副主席、自治区党委政法委副书记何文浩，**

**自治区党委宣传部副部长欧阳方兴******参观**绿盟科技展台**

西藏自治区党委副书记、自治区主席洛桑江村，自治区党委副书记、自治区常务副主席、自治区党委政法委书记、自治区互联网党工委书记邓小刚，自治区副主席、自治区党委政法委副书记何文浩，自治区党委宣传部副部长欧阳方兴等领导赴现场出席了活动。![](../Images/a11b81bc6235342b17560728a39aa5ea.png)本次网络安全宣传周以“网络安全为人民，网络安全靠人民”为主题，通过集中展示网络安全发展成就、发放网络安全宣传资料、推广网络安全新技术和新应用、现场讲解网络安全知识技能等方式，培养干部群众的网络安全意识，有效掌握网络安全技能。绿盟科技在本次活动中也向自治区人民群众展现了自己的网络信息安全保障实力，以及与各行业用户丰富的合作经验，以多种方式引导大众关注网络信息安全，维护企业及个人的合法权益。多元化媒体宣传掀热潮  
围绕今年的网络安全周活动主题，西藏自治区通过多元化的媒体渠道对自治区群众进行全覆盖式的宣传。利用电视、横幅等多种载体，播发、张贴标语、海报，向群众免费发放网络安全知识手册，围绕网络安全知识技能、网络安全案例，用图文、图表、音视频、动漫、H5等形式，集中展示网络安全知识和各单位网络安全宣传成果，组织协调各单位充分调动所属网站和“两微一端”，在全区范围内掀起网民聚焦热议网络安全的热潮。 “西藏网警”上线清理网络环境显决心  
除此之外，西藏自治区公安厅还推出了“西藏网警”微信公众号。在目前网络环境日益复杂的情况下，网络谣言、网络黄赌毒等有害信息层出不穷，愈演愈烈，为清理自治区网络环境，增强全社会网络安全意识，提升自治区广大网民的安全防护技能与对有害信息的识别能力， “西藏网警”将会及时关注网络安全热点事件，并向公众第一时间发布辟谣、警示、防诈骗等信息，避免人民群众的网络信息安全、个人财产安全受到损害。主题活动日引各领域聚焦网络安全  
为积极响应国家号召，西藏自治区2016年网络安全宣传周活动将与全国同步进行，持续到9月25日。期间各相关单位将分别开展一系列重要活动，包括9月20的“教育日”，9月21日的“电信日”，9月22日的“法制日”，9月23日的“金融日”，9月24日的“青少年日”以及9月25日的“公益宣传日”等主题教育活动，同时，还将开展网络安全进校园主题宣讲、网络安全有奖征集、网络安全专家智库建设、网络安全知识大讲堂、涉藏网络安全和信息化工作高峰论坛等一系列活动，力争使网络安全知识成为全社会的共识。![](../Images/f48db970bc6f757a6bef03ad902c484f.png)  
绿盟科技也会在今后的具体工作中与自治区的多家合作伙伴同心携手，持续发力，共同撑起网络信息安全绿色天网， 应用公司先进的安全防护技术及产品为自治区的网络安全贡献力量！
