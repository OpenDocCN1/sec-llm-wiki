# 网络安全走进夏令营，学习与交流两不误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650386057&idx=1&sn=002fd16968944d97de055a1a90b5533c&chksm=becaf72289bd7e346b0fe3a47746b6916bc75f15215af02238a5f1dcbc57d4fae0b9c5f0dc74&scene=126&sessionid=1681372619#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650386057&idx=1&sn=002fd16968944d97de055a1a90b5533c&chksm=becaf72289bd7e346b0fe3a47746b6916bc75f15215af02238a5f1dcbc57d4fae0b9c5f0dc74&scene=126&sessionid=1681372619#rd)

2016年7月24日，因为同一个向往，第二届网络安全夏令营的学员和导师们聚在一起，在思想上碰撞火花，共同迎向安全行业的明天。

  

开幕式上邀请了主办方领导致辞席丽萍、云安信息安全产业联盟副理事长谷晶中、西安电子科技大学计算机学院副院长沈玉龙，以及绿盟科技技术总监杨方宇等专家领导致辞讲话，一起探讨了信息安全的变化和未来发展，并对参与本次夏令营活动的学生们寄予了厚望。

![](../Images/c77d3e39c0d1f80a6b53b3ed5328b2a6.png)  
图1：主办方领导席丽萍致辞

  

之后，云安信息安全产业联盟副理事长谷晶中在致辞中启发大家不仅要在夏令营中学习知识，更要学习思考自己要成为什么样的人，自己在网络安全这条路上要怎么走。

  

西安电子科技大学计算机学院副院长沈玉龙沈院长看到学员自身学习态度上都很积极，对这届学员期待的是他们能够让自己对网络安全的热情辐射和带动一批人来学习和从事网络安全，打造学员自身在网络安全圈的影响力。

  

随后，绿盟科技技术总监杨方宇从网络安全应急响应中心安全工程师的角度，为各位学员讲解了信息安全产业的变迁和发展，并阐述了国家对于信息安全从业者的切实需求。同时提醒学员，安全是攻与防的艺术，学习是重要的环节，但更重要的是所学的技能可以为国家做哪些事情。

![](../Images/a3592f2505a0c5d00dd1bdea842ffb19.png)  
图2：绿盟科技技术总监杨方宇致辞

  

紧接着，赛客人才育成计划首席战略导师魏强回顾了自己17年的网安路程，感慨现在的网安学术界和企业界人才有一定的断层现象，我们和国外相比意识上是存在差距的。所以希望能够做一些事情，改善这种状况。

![](../Images/eb9609a8e16dc514afdc0a08b3ccc7cd.png)  
图3：赛客人才育成计划首席战略导师魏强致辞

  
![](../Images/5f6ed5e5a2a96c8d412fb97f1a343142.png)  
图4：到场嘉宾一起为赛客夏令营开营助力共同开启启动仪式

  

本届“赛客”网络安全夏令营将持续一周，在一周的学习过后，会安排考试和CTF比赛，分为解题、攻防和混合（沙盒）3种模式，闭幕式上将为优秀的学员颁奖，并获得进入绿盟科技的机会。
