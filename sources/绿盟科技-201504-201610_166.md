# 【云栖大会】网站安全的SaaS解决之道

6月29日，2016阿里云栖大会成都峰会在在成都世纪天堂洲际大饭店顺利召开。绿盟科技副总裁周凯也受邀做客安全专场，与大家分享了大数据时代网站安全的SaaS解决之道。

 

![](../Images/1f34b5bff8211bddc28ac3742df109eb.png)  

绿盟科技副总裁周凯精彩演讲

 

在互联网时代，所有的企业都面临着互联网带来的不确定性挑战，而传统IT架构固有的孤岛模式无法因应新时代需求。随着云计算越来越深入人心，几乎所有企业都在寻求互联网转型，并且更加务实地寻求在云上解决自身所属行业的应用性安全问题。绿盟君在此为您解读**绿盟网站安全解决方案**的五大亮点。

亮点一：强强联合 不含糊

![](../Images/81034dd15a6fa89a9886ff9eb96a7ab8.png)  

阿里云始终致力于打造公共、开放的云计算服务平台，通过创新的技术和服务为合作伙伴、客户和开发者创造价值。是中国最大的云计算平台，为全球200多个国家和地区的创新创业企业、政府机构等提供服务。  

 

绿盟科技是国内云安全领域的领航者，此次与阿里云合作，在阿里云云市场上开设绿盟科技官方旗舰店，达成在安全领域展开合作，面向阿里云上的客户，提供极光自助扫描服务、网站安全检测服务等绿盟云服务商品，提供购买咨询、部署实施、故障解决等远程技术支持服务。将共同向企业提供更加灵活、敏捷和高性价比的安全服务。体现出了阿里云的通道效应与绿盟品牌效应的融合，实现双赢。

亮点二： 评估 + 检测 + 防护  = 闭环

EDP(Evaluation/Detect/Protect)模型借鉴PDRR模型（Protect/Detect/React/Restore），把信息的安全保护作为基础，将保护视为活动过程。用评估手段来发现安全漏洞，及时更正；同时采用检测措施对付各种入侵；同时采取相应的防护措施，这样使信息安全得到全方位的保障。我们正是依托该模型，从而打造闭环的动态防护能力。![](../Images/abc4b25b8f3187adc5c6a3eb2d23cad5.png)  

亮点三：全套资质，金牌保障

![](../Images/e3eee7853a9e7c60ee9a80b14321b621.png)  

亮点四：人机合一  7\*24小时贴心服务

以往用户购买安全设备后，基本上是本单位的人员使用，设备的使用效果在很大程度上取决上使用人员的能力。而厂商在设备出售后，很少或很难介入用户设备的使用。随着云计算技术应用的深入发展，绿盟科技以绿盟云为依托，以安全专家为核心，打通云地人机环节，共享威胁情报，共享专家能力，为用户提供7X24小时的贴心服务。

![](../Images/00a10485d19a030a57299017f469a02f.png)  

亮点五：移动端尽在掌握

网站安全问题随时都可能发生，所以需要有更便捷的方式能够全天候的了解当前安全态势。通过绿盟安全管家APP，可以随时了解受保护网站的漏洞信息、安全风险情况。同时，安全资讯涵盖国、内外24小时内最热安全新闻资讯、安全热点、行业安全动态等，安全风险“早”识别，安全问题“早”知道。

![](../Images/818f01a4c1b693e5bebdcdc4c7b93884.png)  

写在最后的话

绿盟科技副总裁周凯指出，单纯靠纯硬件安全设备取胜的时代即将过去，通过SaaS整合并以服务的形式为用户提供更加简单、高效的云安全能力已成为趋势。云安全已经成为未来十年影响各政企云计算的重要因素，我们期待与阿里云的合作正是开启了云安全领域的美好前景。

  

阿里云将为绿盟提供强大的合作平台，相信双方的密切合作将有助于各自优势的充分发挥和市场渠道的有效拓展，从而为企业用户提供更加便捷、高效、安全的解决方案与服务，推动云安全服务的快速发展。
