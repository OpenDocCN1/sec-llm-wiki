# 绿盟科技携手伙伴共筑网络空间安全 恭祝CSAC正式成立

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=402746914&idx=1&sn=98b66b34d6f395a73e511866368ccecd&chksm=3b3237890c45be9f0a1d0c0fba500273cf9be826cb4bc526e7b754cd9338d2531567ebfe79ca&scene=126&sessionid=1681372632#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=402746914&idx=1&sn=98b66b34d6f395a73e511866368ccecd&chksm=3b3237890c45be9f0a1d0c0fba500273cf9be826cb4bc526e7b754cd9338d2531567ebfe79ca&scene=126&sessionid=1681372632#rd)

3月25日上午，我国首个网络安全领域的全国性社会团体——中国网络空间安全协会（Cyber Security Association of China，CSAC）在京正式成立。民政部、工信部、公安部相关负责人及中国互联网协会等单位代表在会上分别致辞。部分全国性网络社会组织、高校科研机构、互联网企业代表及中国网络空间安全协会会员代表280多人与会。

  

会上，国家互联网信息办公室副主任王秀军致辞，对中国网络空间安全协会提出了四点希望：

![](../Images/3953d7005a075306eb4461f63170ef3d.png)  

  

中国网络空间安全协会是由中央网络安全和信息化领导小组办公室（简称：网信办）创建筹备，由国内从事网络空间安全相关产业、教育、科研、应用的机构、企业及个人共同自愿结成的全国性、行业性、非营利性社会组织。中国网络空间安全协会经由国务院批准同意成立，协会接受业务主管单位国家互联网信息办公室，社团登记管理机关中华人民共和国民政部的业务指导和监督管理。

  

![](../Images/6b76ae3790d72fc988304315ac4c8783.png)  

协会发起会员共计257个，其中单位会员190多个，囊括了国内主要互联网企业和网络安全企业、权威科研机构，具有广泛的代表性。协会成立顺应了我国互联网行业和社会各界共同参与维护网络安全的愿望，对加强行业自律、促进行业健康发展、维护我国网络安全、加强网络安全国际交流合作将发挥积极作用。

  

作为中国网络空间安全协会理事成员，绿盟科技（NSFOCUS Co., Ltd.）是中国网络安全领域的领导企业，是国内最具安全服务经验的专业公司，致力于网络和系统安全问题的研究、高端网络安全产品的研发、销售与网络安全服务，在入侵检测/保护、远程评估、DDoS攻击防护等方面提供具有国际竞争能力的先进产品。绿盟科技将为协会的工作提供坚实的后盾，并与业界同仁一起“共担网络安全，共建网络强国”，为促进网络安全产业的可持续发展做出贡献。
