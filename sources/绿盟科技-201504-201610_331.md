# 绿盟科技受邀参加第三届云安全联盟亚太年会

12月2日至3日，第三届云安全联盟亚太年会（简称CSA亚太年会）在广州召开。云安全联盟（CSA——Cloud Security Alliance）发起于2008年12月，是中立的非盈利世界性行业和标准组织，致力于国际云计算安全的全面发展。本届年会以“云计算－亚太掌握未来”为主题，围绕国际上最新的技术及发展趋势、战略、治理和风险管理和案例研究和技术解决方案三大议题，包括三个并行的分论坛、会前云安全联盟国际工作组会议、培训课程(CCSK、CCSP、STAR认证)等。作为CSA云安全联盟中国区分会的发起人之一，绿盟科技CTO赵粮博士获邀参加本届云安全联盟亚太年会，并做主题演讲。

  

本次会议，赵博的演讲围绕“利用移动和社交网络提升大规模安全防护服务的交付能力”进行，强调在当今的网际威胁场景下，业务必须具备网络攻击之下的复原力才能持续成长。绿盟科技为提升事件响应能力及安全运营效率，提出智慧安全2.0战略，要求企业安全防护实现智能、敏捷、可运营：威胁情报和安全数据分析是“互联网+”时代安全攻防的两大核心能力，安全决策活动和控制措施需要威胁情报时刻被感知；充分利用云计算、移动计算和互联网思想和技术，业务系统、安全系统、安全专家和维护人员、决策和执行活动等尽快迁移到线上；充分利用软件定义架构、持续集成等提升安全运营效率和时效性。与传统专注安全硬件产品不同的是，智慧安全战略指引下的企业安全解决方案提供商需要围绕用户需求，大力提升线上也就是云中的安全能力，打通技术、产品和服务、解决方案、交付运营等各个环节。企业迈向智慧安全2.0还需要三个成功因素，即态势感知、软件定义及纵深防御：态势感知使安全耳聪目明、软件定义给安全运维带来敏捷应变、纵深防御带来弹性和生存能力。

  

变革从来不是一蹴而就的，绿盟科技一路走来，从对传统安全的战略回顾和反思、启动云安全和A计划，到发布下一代安全研究报告、推出下一代系列安全产品，再到今年内部启动P2SO、发布智慧安全2.0战略，都在逐步践行变革之路，不断通过自身平台的持续创新，以帮助客户业务更智慧、更有效的发展。
