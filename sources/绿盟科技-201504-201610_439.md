概述

  

欧姆龙是来自日本的自动化控制及电子设备制造厂商，其小型PLC在国内市场有较高的市场占有量，有CJ、CM等系列，PLC可以支持Fins，Host link等协议进行通信。

  

关于欧姆龙 Fins协议

  

　FINS(factory interface network service)通信协议是欧姆龙公司开发的用于工业自动化控制网络的 指令／响应系统。使用FINS指令可实现各种网络间的无缝通信，包括用于信息网络的 Etherne(以太网)，用于控制网络的Controller Link和SYSMAC LINK。通过编程发送FINS指令，上位机或PLC就能够读写另一个PLC数据区的内容，甚至控制其运行状态，从而简化了用户程序。FINS协议支持工 业以太网，这就为OMRON PLC与上位机以太网通信的实现提供了可能。Omron fins协议使用TCP/UDP的9600端口进行通信，fins协议封装在TCP/UDP上进行通信，需要注意的是TCP模式下组包和UDP模式下在头部上有所差异。

  

后记

  

1.欧姆龙为知名日本自动化控制及电子设备制造厂商，从得来的数据看，我国的欧姆龙设备接入公网排名在第8位，虽然数量都不是太多，工控安全建设不可或缺。

  

2.需要注意的是此类型的PLC一旦暴露在公网就意味着可以通过协议、软件等直接操作该PLC的所有功能（如果使用者没有设置等级存取密码等信息安 全级别限制）。如果PLC需要跨地域进行远程通讯，在配置路由的端口映射时，建议同时还需要给PLC设置权限密码，或者在防火墙添加可信的基于源地址的过 滤，用来消减暴露在互联网的工控安全风险。

  

3.绿盟工控漏洞扫描系统可以通过远程安全检测的方式，批量发现工控设备、工控软件以及支撑它们运行的服务器、数据库、网络设备，针对工业控制系 统中所特 有的设备/系统（如SCADA、DCS、PLC等）进行漏洞扫描，并可以对一些关键系统的安全配置进行评估，完整的呈现工业控制系统的安全风险。

  

4.本信息仅用于工控设备风险态势统计和发现，如需更多，可微信留言，一起交流讨论。

  

*数据来源于绿盟研究院广谱平台数据统计*
