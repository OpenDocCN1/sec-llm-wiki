# 绿盟科技EMEA子公司首次亮相INFOSECURITY EUROPE

近日，欧洲最大的信息安全展会INFOSECURITY EUROPE在伦敦Olympia展馆进行了为期三天的讨论，探讨关于欧洲安全领域的发展趋势。一年一度的INFOSECURITY EUROPE展会是欧洲信息安全行业最重要的盛事，每年都会吸引很多来自世界各地的安全专家及优秀厂商参加这场盛大派对。本届大会的主题为“智能安全：保护、检测、响应、恢复”（Intelligent Security- Protect. Detect.Respond. Recover），各领域的安全专家们将围绕这一主题深入探讨我们应该如何提高各行业的信息安全意识以及如何采取有效的防护措施。

  

本次是绿盟科技EMEA子公司成立后在欧洲信息安全展会中的首次亮相。绿盟科技在展示了Anti-DDoS Solution (ADS)，Web Application Firewall (WAF) 以及Web Vulnerability Scanning System (WVSS)。欧洲当地的杂志对科盟科技进行了采访，针对绿盟科技2014年第二季度的安全研究报告，对IOT增长的趋势给DDoS攻击带来的影响做出深入的探讨。

  

围绕大会主题，“Think outside the security box—Think DDoS”是绿盟科技在这次大会的话题之一。DDoS攻击与一般的安全问题不同，尤其是过去一段时间层出不穷的新攻击手段，危害面大，且各种行业都可能成为受害者，所以要采用不同的思维方式来考虑DDoS。绿盟科技的抗DDoS专家以及经验丰富的工程师也在会议现场同与会者进行交流、答疑解难。

  

作为INFOSECURITY EUROPE中唯一的中国厂商，绿盟科技通过展会的平台与业界同行沟通和交流，把握国际信息安全走向、密切关注国际安全发展趋势，跟踪产品技术动态，不断提升自身能力及优势，为国内外客户提供更为优质的安全解决方案与高水平的服务。
