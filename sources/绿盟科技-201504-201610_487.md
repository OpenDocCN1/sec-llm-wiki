# 绿盟科技：做互联网金融安全的专家

中国金融业的改革是全球瞩目的大事，尤其是利率市场化、汇率市场化和金融管制的放松。而全球主要经济体每一次重要的体制变革，往往伴随着重大的金融创新。中国的金融改革，正值互联网金融潮流兴起，在传统金融部门和互联网金融的推动下，中国的金融效率、交易结构，甚至整体金融架构都将发生深刻变革。随着信息通讯技术和互联网的发展，互联网金融信息对金融市场的影响已经越来越不容忽视。

  

2015年4月，《绿盟科技互联网金融安全报告》重磅发布（点击左下方阅读原文进入）。据不完全统计，截至2014年底，已有近165家P2P平台由于网络攻击造成系统瘫痪、数据被恶意篡改、资金被洗劫一空等。目前很多P2P平台整体安全技术水平跟其业务的风险性不相匹配，缺乏专业、核心的防范网络攻击技术，给了攻击者乘虚而入的机会，如何提升平台安全能力成为亟待解决的问题。近几年互联网金融行业新上线的系统非常多，绿盟科技NSTRT安全团队收集了在2014年互联网金融行业中的134份安全漏洞报告，并对漏洞类型和数量做了统计。

  

从国家层面，信息安全也上升到了战略的高度。十二届全国人大常委会4月24日下午在人民大会堂举行第十六讲专题讲座，题目是《信息技术与信息安全》。据新华社报道，主讲人工业和信息化部副部长、中国科学院院士怀进鹏介绍了信息技术及其演进趋势、互联网对经济社会的影响，分析了信息安全问题面临的严峻形势，并就提升信息技术发展与信息安全保障能力谈了看法。

  

党的十八大提出要建设下一代信息基础设施，发展现代信息技术产业体系，健全信息安全保障体系，推进信息网络技术广泛应用。这是党中央准确把握全球新一轮技术和产业变革趋势提出的重要部署，对新时期提升经济和社会综合竞争力具有重大战略意义。

  

金融行业作为国民经济的命脉，信息安全更是重中之重。2015年4月9日，由山西银监局、山西省银行业协会主办的“移动互联网时代的金融与安全”专题讲座在太原举办。

  

本次讲座，由绿盟科技金融销售管理部总监郝东林全程主讲，山西省银行业协会副会长赵邯平、山西银监局信息科技监管处贺晓云处长主持，祁绍斌纪委书记、杨庆和副局长参加了学习；各银监分局分管信息科技工作的局领导、信息科技部门负责人、省局信科处全体工作人员及省局其他处室工作人员，全省各银行业金融机构、28家农村商业银行分管信息科技工作的领导及信息科技部门负责人共计180余人参加了学习。

  

面对互联网金融来势汹汹的冲击，传统金融机构如何应对？在讲座上，郝东林从移动互联网金融模式下的金融创新、新形势下信息安全形势及特点、金融行业对信息安全的解决之道、IT与安全地位的新变化等四个维度进行讲解，列举了近年来发生在网络安全领域的很多著名案例并逐一剖析了原因。

  

将近三个小时的讲座，让所有客户对金融行业的现状、面临的新变化有了系统全面的理解，对如何面对互联网金融的冲击也有了整体的认识。这次专题讲座，得到了与会客户的一致好评，提升了金融行业高层领导对信息安全的重视程度。

  

绿盟科技作为国内技术能力最强的安全公司之一，服务过几乎全国所有国有银行、股份制银行、省会城市的城商行。凭借对金融行业、互联网金融客户的理解，绿盟科技会定期发布各种报告，包括《中国网上银行安全报告》、《绿盟科技DDOS威胁报告》等，更好的提升金融客户的信息安全意识水平。
