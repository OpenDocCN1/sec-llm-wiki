# 绿盟科技营业收入同比增长12.78% 献礼十五周年庆

4月25日，绿盟科技在成立十五周年之际发布了2014年年度报告。公司在2014年实现营业收入70,266.82万元，同比增长12.78% ；实现归属于上市公司股东净利润14,450.35万元，同比增长22.34%。2014年来自于海外的营业收入为2,638.56万元，同比增长98.93%。一年来，公司紧紧抓住国家政策向好带来的机遇，积极推进内生式增长和外延式扩张的发展战略，以稳步发展的态势为十五周年庆献礼。  

  

经董事会审议通过的2014年度利润分配预案为：以公司2015年4月23日公司总股本143,193,882股为基数，向全体股东每10股派发现金股利人民币2.1元（含税），共计派发现金股利30,070,715.22元（含税）；同时，以资本公积金向全体股东每10股转增15股，合计转增214,790,823股。转增完成后公司总股本为357,984,705股。

  

专攻术业，成就所托。2015年是绿盟科技成立的第十五个年头，在全球范围内，绿盟科技会继续秉承巨人背后的安全专家，保障客户业务顺畅运行的使命，提供基于自身核心竞争力的企业级网络安全解决方案，成为最受客户信赖的网络安全公司。
