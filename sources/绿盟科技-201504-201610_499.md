# 绿盟科技连续八年获邀参展RSA大会

2015年RSA大会已于4月20日在美国旧金山拉开帷幕。一年一度的RSA会议早已成为信息安全行业最重要的盛事，来自世界各地的安全专家及优秀厂商齐聚这场盛大派对，共同探讨安全领域的发展趋势及前沿科技。本届大会的主题为“变化：挑战当今的安全理念”（CHANGE Challenge today’s security thinking），各领域的安全专家们将围绕这一主题深入探讨我们未来该作何改变。

  

绿盟科技在本次大会中围绕着DDoS攻击和与会者讨论两个话题。

  

话题一：“Stop DDoS Attacks Before They Stop You”，别等被DDoS攻击了才想到防御，延续了去年的主要内容。近年来，DDoS攻击日益严重和猖獗，绿盟科技在大会中展示了运营商级的抗DDoS方案，分享了DDoS攻击实战中积累的经验、分析见解及改进技术。

  

话题二：“Think outsidethe security box—Think DDoS”。DDoS攻击与一般的安全问题不同，尤其是过去一段时间层出不穷的新攻击手段，危害面大，且各种行业都可能成为受害者，所以要采用不同的思维方式来考虑DDoS。绿盟科技的抗DDoS专家以及经验丰富的工程师也会在会议现场同与会者进行交流、答疑解难。

  

绿盟科技今年已连续八年获邀参展RSA大会，从2008年第一次参加会议以来的八年间，绿盟科技已在安全技术研发及海外市场的拓展中获得了更长远地发展。绿盟科技会继续与业界同行沟通与交流，把握国际信息安全走向、密切关注国际安全发展趋势，跟踪产品技术动态，不断提升自身能力及优势，为国内外客户提供更为优质的安全解决方案与高水平的服务。
