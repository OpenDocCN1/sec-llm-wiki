# “协同运营 聚焦终端”｜绿盟亮相教育网络安全工作研讨会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650388282&idx=1&sn=f296125cd6b62bcf274b7aaf0ff01ef9&chksm=becaee9189bd67878b1ebdb1c554a8ac72a17a83187be70e7dc9dcd36b7c13eaefe1b02c8c7d&scene=126&sessionid=1681372569#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650388282&idx=1&sn=f296125cd6b62bcf274b7aaf0ff01ef9&chksm=becaee9189bd67878b1ebdb1c554a8ac72a17a83187be70e7dc9dcd36b7c13eaefe1b02c8c7d&scene=126&sessionid=1681372569#rd)

![](../Images/1621abc0fbfc2330ffef804f68e530b1.png)

2017年5月17日，2017教育网络安全工作研讨会在著名的英雄城江西南昌盛大召开，本次会议由教育部教育管理信息中心主办，以“教育信息化与网络空间安全新技术融合发展”为主题，特邀绿盟科技安全专家为与会嘉宾带来题为《从重点系统保护到安全协同运营---教育行业信息安全思考》的主题演讲。

![](../Images/12eecbc68c6d9f00724a4bfb5d2293bc.png)

绿盟科技携信息安全攻防实验室方案、教育信息安全等级保护解决方案、教育城域网安全解决方案、智慧校园安全解决方案亮相南昌，其中信息安全攻防实验室方案通过绿盟科技信息安全实训平台及信息安全竞技平台，提升安全专业人才能力，从根本上解决教育网络安全建设及教育信息化发展问题，受到与会嘉宾的广泛关注及咨询。  

![](../Images/c0dc9535fdf545a17ee32b2130110614.png)

本次大会以深入学习贯彻《网络安全法》为核心，以全面落实《教育信息化“十三五”规划》和《2017年教育信息化工作要点》有关要求，切实提高全行业网络安全意识和重视程度，交流分享网络安全建设经验为目的，特邀中央网络安全和信息化领导小组办公室、公安部、国家密码管理局、教育部等相关部门领导，网络安全和教育行业专家学者等参与本次会议，分享专题报告，深入交流，聚焦网络安全。

![](../Images/da033a33f8835598da02cf572490e3d8.png)

**教育部教育管理信息中心副主任罗方述****致辞**  

教育部教育管理信息中心副主任罗方述首先在致辞中指出：“随着网络环境快速发展，网络威胁也变得日趋复杂，以去年令人扼腕的徐玉玉事件，及近期被波及的勒索病毒事件为例，网络安全再次敲响警钟，也预示着网络安全建设已经成为国家发展的重中之重。国家出台的一系列法律法规也为教育信息化的高速发展提出了更高要求，以期达到更高水平，形成更高标准。”

![](../Images/7cf8325a09fd4ca996927e9b0901b94b.png)

**公安部第十一局总工程师郭启全发表重要演讲**  

公安部第十一局总工程师郭启全发表了题为《教育行业如何深入开展网络安全工作》的重要演讲，并强调了《网络安全法》重点内容。他表示：“教育行业的网络安全工作应该紧密围绕《网络安全法》要求，积极落实关键信息基础设施防护、强化网络安全主体责任与意识、提高网络安全技术防护和态势感知检测能力、促进高校网络空间安全人才培养。一次次安全事件证实，我国的信息安全企业在国家网络安全建设发展中发挥了重要作用。继续贯彻落实等级保护制度，加快建设关键信息基础设施安全防护平台是教育信息化发展的工作重点。”

此次大会，绿盟科技安全专家从上周末席卷全球的WannaCry勒索病毒事件出发，引出针对教育行业网络安全建设的深入思考，与参会嘉宾分享了教育信息安全保障新思路，及此次勒索病毒事件应急响应的全过程，共同探讨网络安全防护与预警监测的新技术、新方法、新方向。

![](../Images/1bcf0efe8d81a4a538d66cd54bdbcb1d.png)

**绿盟科技安全专家发表主题演讲**

   

**聚焦虚拟桌面技术  增强终端安全管理**

绿盟科技安全专家指出，以往教育行业在等级保护的指导下，面向重要信息系统的安全保障，主要重视服务端资产的安全保障，但经过此次勒索软件事件来看，终端安全管理仍存在欠缺，相应的终端安全越来越应该被重视起来。

虚拟桌面技术在终端安全管理的应用与传统分散的管理模式相比，完美解决了频繁重装系统、分散安装软件、病毒库未升级、未打补丁、易泄密、难监控等关键问题。

绿盟下一代安全云桌面NGSD即可在不关闭全部终端的情况下直接进行镜像升级管理，100% 同步成功。持跨VLAN部署和兼容微软的域环境。在网卡驱动层实现精确流量控制，无论是蠕虫病毒或者突发流量都无法影响网络，避免对交换机的冲击和堵塞带宽。

![](../Images/3d921382be79cea66633f643fc2e2719.png)   

**协同安全运营是大势所趋**

面对攻防的不对等，国际社会已逐渐形成了协同安全运营的共识，2016、2017连续两年的信息安全领域盛会——RSA Conference都围绕“协同合作”进行深入交流。想要实现保护就必须建立连接，安全厂商和客户建立紧密的安全连接，同时形成行业协同安全运营，是对抗攻防不对等的必由之路。绿盟科技积极创新，在绿盟科技智慧安全2.0战略引导下，形成“云地人机”双闭环运营体系，通过信息共享有效加强云端安全能力建设及威胁能力情报建设， 建立智慧、敏捷、可运营的安全运营体系，促使闭环中的客户及安全厂商都成为协同运营的贡献者及受益者。

![](../Images/c018d8bbb1c1403255fcdb121f640098.png)

绿盟科技依托于在网络安全领域的丰富经验和威胁情报积累，经过多年的应用研究，于2016年正式推出绿盟威胁情报中心（NTI）。应用威胁情报切实服务于企业客户。

中国正在从网络大国向网络强国的道路上不懈前进，面临国际纷繁复杂的网络发展形势，网络信息安全早已成为各行各业关注的焦点，网络基础设施建设及网络空间管理更是国家战略发展的重要一环。绿盟科技也将基于17年丰富的网络安全服务经验，服务行业客户，为“网络强国”战略目标贡献自己的力量！
