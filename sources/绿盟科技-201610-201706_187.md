# 【预警通告】Microsoft Windows Server 2003 R2 IIS 6.0 远程代码执行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650387909&idx=3&sn=548be1b3e39f7e1b8fa7a3aa56d3c8df&chksm=becaec6e89bd65781994b4459c35deb339cd80d592bf12fe39e0c9d932ff883a6bcfd28ed0f6&scene=126&sessionid=1681372579#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650387909&idx=3&sn=548be1b3e39f7e1b8fa7a3aa56d3c8df&chksm=becaec6e89bd65781994b4459c35deb339cd80d592bf12fe39e0c9d932ff883a6bcfd28ed0f6&scene=126&sessionid=1681372579#rd)

> **  综 述  **
> 
> 3月27日，Zhiniang Peng 和Chen Wu发布了关于IIS 6.0 WebDAV远程代码执行的漏洞信息（CVE-2017-7269，CNNVD-201703-1151）。该漏洞源于Microsoft Windows Server 2003 R2的IIS 6.0 中WebDAV 服务下ScStoragePathFromUrl函数存在缓冲区溢出漏洞。如果一个PROPFIND请求中包含以"If: <http://"开头的超长头部，将触发一个缓冲区溢出漏洞，攻击者可以利用此漏洞远程执行任意代码，此利用方法和2016年7-8月份暴露的方法一致。网上已有公布的POC。
>

>

## **临时防护方法                                               **

 |
| --- | --- |

1.  禁用IIS 下的WebDAV服务。
    
2.  2015年7月15日，微软已停止对Windows Server 2003的支持，所以官方没有相关解决方案，建议用户升级到最新系统 Windows Server 2016。
