# 年终总结现在发会不会有点晚啊！！！

眼瞅着，农历新年马上就要到了，身为国人，总感觉过了农历新年才算一年的正式开始。

眼下，该交的总结都交了，该做的计划也做完了，年会开完了……年货买起来，出行攻略做起来，亲朋好友约起来……

也恰恰是这个时间节点，每个人的心里都会泛起波澜……

  

于绿盟君而言，一年的忙碌就快过去了，紧绷的神经也终于可以松懈几天，北漂多年，依然住着不属于自己的小房子，吃着简单又仓促的三餐，呼吸着雾霾爆表的空气、赶着人潮拥挤的十号线……生活在这钢筋水泥的大都市，总是不自觉的武装自己，或许不轻松，却又充实地乐在其中。

  

尽管年初立下的小目标很多没实现，但是绿盟君有未完待续的决心啊，而身边的同事们，也都有着自己不同的苦和甜。

![](../Images/88e887f9e21a24f1979c4d83968bf109.png)![](../Images/bce2af3030df5bfb23d67c2089a079dd.png)

**职务：**部门总监

**年龄：**不告诉你

2016年调回绿盟科技总部工作后，机会更多了，挑战也更大了。收获最多的是，对行业和产品有了更多的了解，演讲技巧也有了很大提升，在重大场合代表公司的演讲宣传推广总结出了自己的一套方法。2017年会重点发力在产品规划设计层面，包括产品架构，原型设计等。预感到今年春节会在一片祝福声中度过，除夕前跟心爱的姑娘扯证，大年初六在家乡的教堂办一场简约的西式婚礼。在这里也要表个态，虽然现在没房没车没存款但是我有一颗陪她到老的心，一起携手为未来奋斗打拼。
