# 【通告】OpenSSH远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650387368&idx=4&sn=e6a9fccd51e37eead374062b1c070ec4&chksm=becaea0389bd6315707b6a057568b1f1811389e10ff0e4d369913d0cba518515f747952f91dc&scene=126&sessionid=1681372596#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650387368&idx=4&sn=e6a9fccd51e37eead374062b1c070ec4&chksm=becaea0389bd6315707b6a057568b1f1811389e10ff0e4d369913d0cba518515f747952f91dc&scene=126&sessionid=1681372596#rd)

![](../Images/927c8b78afcc0b8c4fa2cfd4efb305a0.png)

综述

2016年12月19日，OpenSSH官网发布了一个OpenSSH的版本更新，在新版本中修复了编号为CVE-2016-10009的漏洞。该漏洞允许攻击者在运行ssh-agent(该程序通常运行在客户端)的机器上加载一个恶意模块PKCS#11从而使攻击者有机会执行远程代码。

相关链接地址如下：

**http://www.openssh.com/txt/release-7.4**

  

**![](../Images/410e2f8d59fffc3b407d5bd4a9821c71.png)****受影响的版本：**  

•  OpenSSH version < 7.4

**![](../Images/410e2f8d59fffc3b407d5bd4a9821c71.png)****不受影响的版本：**  

• OpenSSH version = 7.4

官方已经发布了该漏洞的版本更新，建议用户升级到不受影响的最新版本，下载页面如下：

**http://www.openssh.com/portable.html**
