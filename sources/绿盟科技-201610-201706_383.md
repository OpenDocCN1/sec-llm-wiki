# 【活动】湖南媒体都在关注这匹“马”

由于赶时髦，善于相千里马的伯乐也加入了穿越大军，来到长沙体验现代生活。

伯乐仍未放弃自己的老本行，每天上街四处找千里马，数日无所得。

  

这一天，他发现一个路边小摊围满了人，只听人群中一个小伙子拿着喇叭大声广播：“XXApp送好礼，所有礼物，扫码就送啊！扫码就送！”![](../Images/2ef6d34bcca074d02ab48ec23fc1e2f8.png)伯乐听见“马”字就凑过去，看见小桌上印着一个奇怪的符号。

“马呢？”

“这就是码，这叫二维码，大哥你刚从古代来的吧，这些礼物扫就送！”

“你们这马长这样啊……扫就送？”

“对，大哥扫就送！”

伯乐犹豫着掏出手机扫完码，挑了一个马玩偶走了。

当天就收到短信通知，存到银行的全部积蓄不见了……

伯乐把整件事情的始末发到自己的朋友圈，引起了湖南多家媒体的广泛关注！

![](../Images/93cbec973c9228cf6a1d2d172b9e4716.png)  
很快许多媒体热评见诸报端，

《伯乐错相“二维马”，一生积蓄付之东流》

《古代名人长沙街头被骗，人心不古！》

网络信息安全再次被推到了大众舆论的风口浪尖！

湖南经视记者走上街头采访路人，许多普通民众也表示扫码需谨慎。

![](../Images/9b5a95b0acdfdc6e1b308a2bccc2dce6.png)

![](../Images/9211f6ee4b1909783fdfcebd449b1763.png)
