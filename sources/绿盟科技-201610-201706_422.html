● 焦点漏洞

ntp拒绝服务漏洞

◆NSFOCUS ID 

35472

◆CVE ID

CVE-2016-9312

◆受影响版本

• nptd version < ntp-4.2.8p9

• ntp-4.3.0 <= ntpd version < ntp-4.3.94

◆漏洞点评

2016年11月21日，ntp进行了一次更新，此次更新修复了多个漏洞，这些漏洞可导致信息泄露、拒绝服务等多种后果。强烈建议用户检查自己使用的ntp是否为受影响的版本，如果是，请尽快升级。
