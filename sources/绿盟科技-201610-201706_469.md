# 【先导】绿盟科技受邀出席第二届中国互联网安全领袖峰会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650387124&idx=2&sn=fda5989520de491d7072e3df23541fef&chksm=becaeb1f89bd620936df273b3be5c7e92c73c2b200e0052ed6bad536562211cfa1a0cb6e5fac&scene=126&sessionid=1681372603#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650387124&idx=2&sn=fda5989520de491d7072e3df23541fef&chksm=becaeb1f89bd620936df273b3be5c7e92c73c2b200e0052ed6bad536562211cfa1a0cb6e5fac&scene=126&sessionid=1681372603#rd)

![](../Images/927c8b78afcc0b8c4fa2cfd4efb305a0.png)

11月9-10日，第二届中国互联网安全领袖峰会（Cyber Security Summit）即将在北京国家会议中心拉开帷幕。此次峰会由国家互联网信息办公室网络安全协调局指导，腾讯集团、中国信息安全认证中心、中国电子技术标准化研究院共同主办。来自政府、企业、学校、科研机构的数百位精英齐聚一堂，共谋互联网安全之道。![](../Images/a5ce956bc97bcddf24766f962e0411ee.png)在万物互联的时代，人们的生活越来越便捷智能，但其面临的安全威胁也与日俱增，产业链上任何一个环节的纰漏，都有可能造成互联网生态系统的灾难。本届峰会以“智慧安全·连接赋能”为主题，在“互联网+时代”，产业链安全能力更需要相互连接，共同打造基础安全平台。 

**大会日程安排如下：**

  

![](../Images/5f682f13ed6490079b83d33c232ff0a3.png)  

绿盟科技作为业内领先的信息安全企业，受邀出席本届峰会。并针对“互联网+时代”下的安全风险和层出不穷的威胁迭代，为与会嘉宾分享了实践中获得的解决之道。

  

11月9日主论坛，绿盟科技高级副总裁叶晓虎博士将在圆桌讨论上就“信息安全之于现代企业的战略价值“与众多业内大咖共话企业信息安全威胁防护。

  

11月10日智能汽车安全分论坛，绿盟科技威胁响应中心专家为与会嘉宾带来“隐秘的杀手—车联网安全隐患分析”的主题演讲，多角度阐述车联网面临的安全风险，并针对性的给出防范建议。    “互联网+时代”产业链的防御安全能力需要相互“连接”，绿盟科技愿与机构、服务商、企业等社会方方面面的力量”连接“在一起，聚焦产业前沿科技及生活领域安全问题，为”互联网+“的健康发展赋予更多能量与动力，令产业链各方同繁荣，共生长。
