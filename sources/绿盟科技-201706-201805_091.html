Joomla! Core SQL注入漏洞

◆ NSFOCUS ID

39158

◆ CVE ID

CVE-2018-8045

◆ 受影响版本 

Joomla! Joomla! 3.5.0－3.8.5

◆ 漏洞点评 

Joomla是一套网站内容管理系统,使用PHP语言和MySQL数据库开发。Joomla! 3.5.0－3.8.5版本对SQL语句内的变量缺少类型转换，导致User Notes列表视图内SQL注入漏洞，可使攻击者访问或修改数据等。目前厂商已经发布了升级补丁，修复了这个安全问题，请用户及时到厂商的主页下载。
