# 必读|5个价值百万的人工智能问题

当今， 机器学习风行一时。可悲的是，市场推广时将其称为人工智能 ，实乃谬误。根据宣传，它为我们带来了一个全新的世界，在这个新世界里，只有我们想不到、没有数字设备做不到的，梦想、愿望顷刻变为现实。它甚至帮助我们摆脱了烦人的员工以及人肉凡胎才会有的各种需求和期望。 

  

1.第五代AI过热后的低谷 

实际上，这些宣传言过其词，不过是商家的营销噱头而已。理智一点儿看，现在的人工智能恰如马戏团里的跳舞熊。我们着迷，并不是说狗熊跳得好，因为它不可能跳得好，我们着迷是因为狗熊竟然会跳舞！ 

  

近日，Gartner将公司AI化热潮比作“漂绿”，后者指公司标榜自己具有环保意识，是环境友好型企业。看一下Gartner的 2017新兴技术成熟度曲线 ，会发现机器学习已进入过热期。熟悉Gartner的技术成熟度曲线的人都知道，在过热期后就是低谷期；熟悉AI历史的人也都知道，我们之前也经历过这样的阶段，还不止一次。每次，AI都在辜负人们期望之后因为缺乏资金支持而沉沦数十年。现在，我们面临的是第五代AI。 

![](../Images/d96a3a58ed205bbace3b94eb06ba88ea.png)

当然，这并不意味着当今的机器学习技术没有任何好处。重要的是要了解这些技术适于解决什么样的问题，它们又有什么局限性。然而，这需要数学、物理或AI博士才能说得清。若你是其中之一，那么恭喜，你多了一个就业机会，也许可以成为顾问，为组织建议投资方向。 

  

然而，对于我们这些凡人来说，可以问一下那些鼓吹机器学习能力的厂商一些基本问题，他们的机器是确实学习到了有用信息，还是只是浪费CPU周期为了看起来炫酷一些。 

  

2.你的机器学习到了什么？

这个问题看似轻巧，但你会惊奇地发现，大把厂商回答时前言不搭后语。首先，学还是没学？特别提出这一点，是因为在Gartner时，我发现有一些厂商错误地将较为基础的分析技术和计算方法（如统计分析或关联）标榜为机器学习。其次，若学习到了信息，如何储存并重放这些信息呢？ 

  

3.你的机器学习从哪儿学? 

从实验室还是自己的环境中学？前者意味着模型或分析并未基于组织的独特状况，如数据、基础设施或环境；还意味着机器不会自动感知或适应所分析数据的变化。若是从自己的环境中学，机器及其产生的模型或分析是基于本组织的特定情况，且机器会学着适应组织情况。   

  

将两者结合是完全可以的。对于可以处理的问题，机器学习有时包含多个方面，如首先学会如何检测一般攻击，接着从组织环境中学习信息，建立通用基线。仅在实验室中学习有两个先天缺陷—除非问题非常具体，范围狭窄（如识别猫）—实际数据复杂、多样，难以处理；学习到的内容很难把控、理解，成为无法评估输入的黑匣子。 

  

声称进行机器学习的厂商应能够概要介绍实现中使用了哪些机器学习方法。这里的关键词包括监督式、非监督式及增强型，还有高级算法描述。有些资料非常棒，若他们无法借助于这些现成的信息定义其方法，建议远离他们。知道厂商使用哪种（些）方法，理想的情况下，可以作进一步的研究和评估，了解算法是否可用于解决自己的问题；最不济，也能够知道厂商至少对其机器学习有所了解。   

  

有些厂商可能拒绝回答这个问题，表示这是私有技术或商业秘密。这个理由站不住脚，因为并没有要求他们详细解释算法的数学实现方式。我还没遇到任何一位厂商发明了任何全新、未知的方法。严肃、可信的厂商会告诉你，许多厂商采用的是现成的开源算法，其效果与声称采用神秘私有算法的效果并无二致。若有人声称进行了改进，问一问他们是如何改进的。 

  

4.你的机器为什么学? 

为什么要学习这些数据而不是其他数据？为什么使用的是这种方法而不是其他方法？有各种不同的算法和方法可以使用。例如，聚类分析基于相关或相似属性为对象分组，可用于自动识别具有类似功能或配置的主机或用户组/集，还能辨识这些群组之间的变化与差异。   

  

所有厂商都应该能解释自己选择某种特定方法而非其他方法的原因：可能是因为更看重精度而非速度，或更看重速度而非精度。这种情况下，他们需要能解释为什么精度不那么重要或速度优先级更高。 

  

5.你的机器学习解决了什么问题？ 

显然，这个问题价值百万。有如下一些简单标准： 不解决，就需要用更复杂的方式，或者效率低下，甚至完全不可行 。这个问题很重要， 旨在识别毫无意义的机器学习以及为了学习而学习 。例如，许多UEBA（用户实体行为分析）厂商常提到这样的用例：识别用户是否从两个不同位置同时登录。实际上，这并不需要通过机器学习来解决，简单关联就够了：A用户使用X和Y地址访问Z系统，有些SIEM（安全信息和事件管理）系统早几年就已经能够识别。   

  

更重要的是， 机器学习是否解决了多个问题 ，抑或只是“雨人”？考虑到资金成本、耗费的时间和精力以及要搭建的架构，若只解决一个问题，这个问题须非常严重，解决它就像治愈癌症一样。 

  

一般情况下，我的建议是留心厂商的营销方式。没有什么机器学习厂商，只有 应用机器学习解决特定问题的厂商 。用户实体行为分析（UEBA）就是一个很好的例子，它根据解决特定用例所使用的方法而不是用例本身来命名，这是很有问题的，导致了很多误解，对于市场营销人员来说是个教训。 可以将机器学习用于事件响应、高级威胁检测、溯源和调查 ，它本身无法独立解决任何问题，只是解决特定问题的手段。
