# BTV“315专题报道”绿盟科技教你拿好个人信息“金钥匙”

3月15日，中国人民大学金融科技与互联网安全研究中心等联合发布《移动金融用户个人信息安全测评报告》。此次测评涵盖了200款移动金融交互类 APP 产品，其中六成受测APP未经用户明示同意就收集了用户的财产身份信息。BTV就报告中披露的个人信息使用乱象，采访了绿盟科技安全专家。

![](../Images/fed87d6c969d6bf20b99ec1cb3126d61.png)

近年，个人信息倒卖现象愈演愈烈，严重侵害着消费者的合法权益。个人信息的泄露，一方面可能由于用户个人保管不当，被不法分子获得；另一方面就可能是拥有个人信息的商业机构，被外部窃取或技术漏洞，造成用户隐私大量被曝光。

  

在采访中，绿盟科技安全专家就用户如何保护自己的个人信息提出建议。专家表示，目前收入情况、乘坐航班、上网记录等个人信息的买卖已形成成熟的黑色产业链，从采集到售卖、应用，各个环节都会对公民个人财产造成威胁。

**什么是“黑色产业链”？**

以网络作为媒介，利用病毒，木马以及其它恶意工具，通过漏洞或其它非法途径控制他人计算机、窃取或盗用合法用户权限以及身份，从而谋取金钱利益的各类行为的总称。“漏洞”和“利益”是保证这台巨型黑色机器转动的媒介和燃料。

  

![](../Images/4f79dde6876864ea4c5a7dedb6636d02.png)

**你和“木马”之间，只差一点**

黑客惯用的窃取信息手段就是钓鱼邮件，通过主题为薪资单、领导邮件等的钓鱼邮件，裹挟木马病毒，吸引内部员工点击，一旦打开此类邮件，木马就很有可能瞬间进入内部办公网络，大量窃取个人信息。

  

![](../Images/4f79dde6876864ea4c5a7dedb6636d02.png)

**个人信息如何变成“金钥匙”？**

另一种方法，黑产人员在搜集到大量相关个人信息之后，或将启动撞库攻击，通过专门的程序进行大量尝试，匹配出可以使用的用户名密码，进行贩卖。至此你的个人信息将在“黑色产业链”中迅速升级，摇身一变成为撬开你个人财产的“金钥匙”。

  

绿盟科技安全专家建议

1.  用户在社会生活中应提升个人安全意识，妥善管理自己的账号密码，在网购和移动支付时保持警惕，谨防钓鱼邮件及诈骗短信等攻击；
    
2.  分级管理密码，重要帐号（如常用邮箱、网上支付、聊天帐号等）单独设置密码；
    
3.  定期修改密码，可有效避免网站数据库泄露影响到自身帐号；
    
4.  建议不将工作邮箱用于网络帐号注册，以免密码泄露后危及企业信息安全；
    
5.  不让电脑自动“保存密码”，不随意在第三方网站输入帐号和密码；
    
6.  定期在所有已登录站点手动强制注销进行安全退出。
