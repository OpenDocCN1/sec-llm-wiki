# AMD芯片存在13个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650391270&idx=2&sn=475aab9e9aa46791fa11ec24d783e704&chksm=beca9b4d89bd125be4967fa3552bb0d15707d6c0f31d08ff1b8c1ef2acd346be353ba96196e8&scene=126&sessionid=1681372530#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650391270&idx=2&sn=475aab9e9aa46791fa11ec24d783e704&chksm=beca9b4d89bd125be4967fa3552bb0d15707d6c0f31d08ff1b8c1ef2acd346be353ba96196e8&scene=126&sessionid=1681372530#rd)

**综述**

 

以色列安全公司 CTS Labs 于当地时间周二发布了一份白皮书，其中指出 AMD 芯片中存在四类共计 13个关键安全漏洞，影响 EPYC、Ryzen、Ryzen Pro 和 Ryzen Mobile 系列处理器。据称攻击者可以利用这些漏洞窃取基于AMD CPU 设备的敏感数据，并安装恶意软件。四种漏洞类型包括 Chimera漏洞、Ryzenfall漏洞、Fallout漏洞和Masterkey漏洞。

解决方案

CTS-Labs表示已经与AMD、微软和“少数可以提供补丁和缓解措施的公司”共享漏洞信息，AMD官方发布声明表示“正在积极的调查和分析验证CTS Labs所提供的漏洞”，目前还没有可用的修复补丁。后续进展详见以下官方链接。
