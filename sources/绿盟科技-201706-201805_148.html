◆ 漏洞点评 

Electron 框架是 GitHub 团队在2013年开发的，能让 App 开发人员通过简单的 Web 技术如 JavaScript (Node.js)、HTML 和 CSS 创建跨操作系统应用。近日，使用自定义协议处理程序的Electron应用程序被发现存在一个远程执行代码漏洞。该漏洞源于应用程序在设计时，将自身注册为协议的默认处理程序。目前Electron官方已经发布了最新版本，修复了上述漏洞，受影响的用户请尽快更新升级进行防护。
