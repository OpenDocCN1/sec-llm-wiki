# 闪付&零元购，你的支付安全么？

随着越来越多的无辜消费者陷入“闪付”、“0元购”、“抽奖”陷阱，我觉得无论如何强调和提醒大家注意支付安全都不为过。近年来，随着智能手机的不断普及，移动钱包的概念逐渐渗透到人们生活的方方面面，出门还带钱包？你就Out了，甚至有人在婚礼上用二维码收礼金，坐公交不必带公交卡，手机扫下就OK，滴滴打车用完车钱被直接划走。

**你的“闪付”安全么？——且用且小心**

闪付基于NFC技术，近距离无线通讯技术，不用密码，不用签名，就可快捷支付，前几天CCTV经济信息联播中报道了记者把装有闪付卡的钱包通过安全门时，银行卡的姓名、身份证号、消费记录这些重要信息就出现在大屏幕上了，这模拟了日常生活中大家都会遇到的“黑客擦身攻击”,具有闪付功能的卡片靠近POS机，银行卡的信息就能在POS机上进行抓取，然后刷卡消费，不仅有银行卡，包括身份证、社保卡都具有这种功能，目前复制和盗刷芯片卡的技术没有泛滥，恶意程序目前只是停留在获取卡片信息的阶段，只要我们做好精心防范就能保护好个人的信息安全。

![](../Images/addaa358124f509d52b8d530330b6239.png)

让人欢喜让人忧的“0元购”的猫腻

2018年跨年夜，红包雨如雨后春笋般冒出，小伙伴们跃跃欲试，都要抢夺先机，争一片“红”运当头。我也聚精会神地于手机前，奈何家里无线路由器信号不给力，让我错失无数红包，痛定思痛，当下准备出手换个新的路由器，于是在某知名电商网站上搜索“无线路由器”。然后发现有一款排名靠前的XX品牌的路由器，最吸引人的是，价格虽然近千元，但旁边赫然写着“0元购+抽奖”，于是我点开看详情。看了不放心，我致电了厂商客服电话，了解了0元购的活动详情，原来，要参与0元购，需要下载注册一个他们指定的金融理财APP，期间要提供你的身份证、绑定的信用卡及理财密码。然后20天后可以提现消费的金额，于是我填写了相关信息，然后就在昨天，20天后，我想提现是发现无论如何，页面都显示正在刷新…

**7**

条移动支付安全建议：

1.  支付时，建议在手机“设置”中，关闭定位服务等隐私相关功能。

2.  设置银行卡余额变动实时提醒，随时查一查、看一看，一旦发现帐户异常变动，及时联系银行进行维权。

3. 最好把相应的银行卡进行区分，大笔金额的主账户不建议用来做免密免签支付用，为加强防范，持卡人需要养成定期管理账户的习惯。

4. 取消小额免密的缺省设置，或降低免密额度上限。

5. 建议不要设置单一“指纹”支付。且不要使用相同密码。使用”闪付”支付功能时，建议使用金属涂层卡套，可防止卡片信息被盗。

6. 谨慎参加“0元购”等活动，在对方要求提供身份证号、银行卡、住址、密码等敏感信息时要提高警惕。

7. 保留相关的支付凭证、账户变动截图等。

3

条建议：卡片被冒用该怎么办：

1 .如果卡片被冒用，一定要第一时间致电银行客服中心，对卡片进行挂失或冻结处理，避免资金的进一步扩大。

2.及时到就近的ATM或POS机上进行一笔用卡消费，比如在ATM机上进行一笔余额查询交易，银行可以在后台去识别持卡人当时的时间点以及大致上的地理位置，后期再做伪卡认定的时候，会拿这个时间及地理位置和盗刷的时间及地理位置进行比对，会起到不在场证明的作用，

3.及时到公安机关报案，获得报案回执。

当然，也不必因噎废食，其实小额免密的支付还是相对比较安全的，您只要设置好合适的免密支付上限， 留心保护好自己信用卡的重要信息，出现问题第一时间挂失，就可以放心享受科技为生活带来的便捷。
