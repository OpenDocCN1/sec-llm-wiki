**威胁信息回顾**

****●  **标题：境外APT-C1组织攻击我国某互金平台 得手150万美元 互金大盗恶意软件现身**

  

时间：2017-01-11

摘要：绿盟科技发布 APT 报告《互金大盗背后的高级威胁组织APT-C1》。报告首次发现并命名了境外APT-C1组织，他们利用“互金大盗” 恶意软件 攻击我国某互金平台，导致平台数字资产被窃，损失高达150万美元。

  

******●  ****标题：DedeCMS最新版(20180109)任意用户密码修改**  

时间：2018-01-11

摘要：2018年01月09日，Dedecms官方更新了DedeCMS V5.7 SP2正式版，后续在10日有网友爆出其存在任意用户密码重置漏洞。

  

******●  ****标题：Apple Releases Multiple Security Updates**

时间：2018-01-08

摘要：Apple has released security updates to address vulnerabilities in multiple products. An attacker could exploit these vulnerabilities to obtain access to sensitive information.

  

******●  ****标题：It gets worse: Microsoft’s Spectre-fixer wrecks some AMD PCs**  

时间：2018-01-08

摘要：A lengthy thread on answers.microsoft.com records numerous instances in which Security Update for Windows KB4056892, Redmond’s Meltdown/Spectre patch, leaves some AMD-powered PCs with the Windows 7 or 10 startup logo and not much more.

  

******●  ****标题：Hardcoded Backdoor Found on Western Digital Storage Devices**  

时间：2018-01-08

摘要：Firmware updates released by Western Digital for its MyCloud family of devices address a series of security issues, including a hardcoded backdoor admin account.

  

******●  ****标题：Wi-Fi Alliance launches WPA3 protocol with new security features**

时间：2018-01-08

摘要：The Wi-Fi Alliance has finally announced the long-awaited next generation of the wireless security protocol—Wi-Fi Protected Access (WPA3).

链接：https://thehackernews.com/2018/01/wpa3-wifi-security.html?utm\_source=feedburner&utm\_medium=feed&utm\_campaign=Feed%3A+TheHackersNews+%28The+Hackers+News+-+Security+Blog%29

  

******●  ****标题：Intel AMT又出新漏洞 黑客可能完全控制数百万笔记本电脑**

时间：2018-01-14

摘要：研究人员称发现英特尔的主动管理技术 AMT漏洞 。在2017年5月， Intel多款产品远程管理技术AMT出现本地及远程提权漏洞CVE-2017-5689， 攻击者可以获得高级权限 ，这次危害就更大了， 黑客可以在几十秒钟内完全控制易受攻击的设备，这可能影响数百万企业笔记本电脑。

  

******●  ****标题：联想IBM交换机产品安全绕过漏洞CVE-2017-3765；HP Backdoor后门存在了13年**

时间：2018-01-14

摘要：近日，联想最终确认，在其交换机产品rackswitch和BladeCenter中存在 安全绕过漏洞 ，CVE编号CVE-2017-3765，这个名为“HP Backdoor”的漏洞存在于交换机操作系统 ENOS中， 在特定情况下执行本地身份验证时，就可以利用并获得交换机的管理权限。更惊悚的是，该后门历经两次收购，依然存在。

  

******●  ****标题：微软Office公式编辑器爆出远程代码执行漏洞CVE-2018-0802 所有版本受影响**  

时间：2018-01-10

摘要：近日， Microsoft Office软件中爆出 远程代码执行漏洞 ， CVE编号CVE-2018-0802，攻击者可以利用此问题，在当前登录用户的上下文中执行任意代码。失败的攻击尝试可能会引发 DoS攻击 ，全部版本受影响。 Embedi、 SecurityFocus、Checkpoint、绿盟科技发出预警通告，相关信息如下

  

******●  ****标题：微软office爆出内存破坏漏洞CVE-2018-0812 可执行任意代码也可DoS**  

时间：2018-01-10

摘要：Microsoft Office 内存破坏漏洞 ，CVE编号CVE-2018-0812， 攻击者可以利用这个问题在当前登录的用户的上下文中执行任意代码。 失败的利用尝试可能会可引发 DoS攻击 。SecurityFocus 发布预警通告。

  

********●  ******标题：黑莓手机官网被挖矿门罗币 警惕Coinhive加密货币挖矿代码**  

时间：2018-01-09

摘要：像比特币这样的一些 加密货币 的价值飙升，吸引了 网络犯罪 分子的兴趣。 涉及矿工和采矿脚本的事件和网络攻击的数量不断增加，最近就轮到了黑莓手机官网网站。 入侵的原因 ，据说是因为 Magento电子商务软件存在漏洞。
