# 【盘点】拼搏在重大安保的身影 2017铭记绿盟科技

时间飞逝，2018年翩然而至，放眼望去，在世界范围内，和平与发展仍是时代主旋律。面对风云变幻的国际形势，2017年的中国在坚持走和平发展之路、坚持推动合作共赢的同时，更加注重主动谋划、积极作为。今天就让小编带着大家细数一下这一年中绿盟科技参与的重大活动吧！

![](../Images/448eeaa458c4cf02aeb42a8a40cbaa3c.png)

**中国主场外交的重大活动**

![](../Images/0ab08aa381532264747d5b54343b824c.png)

“一带一路”国际合作高峰论坛

早在2013年秋天，国家提出共建“一带一路”的合作倡议，旨在通过加强国际合作，对接彼此发展战略，实现优势互补，促进共同发展。求木之长者，必固其根本，欲流之远者，必浚其泉源。“一带一路”国际合作高峰论坛于北京成功举行，此次论坛作为2017年中国重要的主场外交活动，对推动国际和地区合作具有极其重要的意义。

![](../Images/eefa153150018b98b10a32778952b4dc.png)

绿盟科技作为本次论坛网络安保工作的技术支持单位，接到了中国交通通信信息中心发来的感谢信，感谢信中肯定了绿盟科技在“一带一路”国际合作高峰论坛网络安全保卫工作中的鼎力支持，并表示愿在今后的工作中与绿盟科技一同为交通运输行业网络安全保驾护航。

  

金砖国家领导人第九次会晤

9月5日，金砖国家领导人第九次会晤在厦门国际会议中心圆满落幕。随着“金砖国家”合作机制的日趋成熟，金砖国家不仅因为经济规模和经济活力为全球瞩目，更是作为上一轮全球化的得益者和后发国家中的优等生在全球治理议程中发挥着越来越重要的作用。此次峰会是我国举办的“世界级”重要会议，得到了全国人民乃至世界各国的高度关注，绿盟科技作为金砖会议安保工作的重要保障单位，投入百余名专项技术保障人员，历时半年，圆满完成了保障任务。

![](../Images/005e6f5d91bc4a86029ca916fbf57c6c.png)

绿盟科技积极于全国筹备技术力量，奔赴厦门、福州等多家涉及重点保障的客户现场，配合客户进行各类风险排查，对潜在风险点进行持续监控，并在会议保障前期，结合用户主要业务和风险场景编制应急响应预案，连续奋战半年，全力确保会议安全稳定，以专业的安全技术和服务能力得到了监管部门和重点保障客户的充分认可。

![](../Images/448eeaa458c4cf02aeb42a8a40cbaa3c.png)

**国家级重大活动**

![](../Images/0ab08aa381532264747d5b54343b824c.png)

中国共产党第十九次全国代表大会

十九大于2017年10月18日至10月24日在北京召开。党的十九大，是在全面建成小康社会决胜阶段、中国特色社会主义发展关键时期召开的一次十分重要的大会。承担着谋划决胜全面建成小康社会、深入推进社会主义现代化建设的重大任务，事关党和国家事业继往开来，事关中国特色社会主义前途命运，事关广大人民根本利益。

![](../Images/efc4727bc006e3562b2ceea778fa4ba4.png)

绿盟科技在短时间内组建了一批以高级安全专家为核心的安全工作保障团队，在网络安全威胁预警、关键信息基础设施安全防护、重要业务系统和政务网站攻击检测、重大安全事件应急处置等方面付出了大量努力，圆满完成了会议期间客户的重大安保任务。

  

全国两会

两会召开集中了各方智慧，修改、完善已有的法律和政策，通过人大议案和政协提案，以及代表委员的呼吁，解决政治经济和社会生活中的复杂难题，平衡各方面利益，缓解各方面矛盾，促进社会和谐稳定。

![](../Images/180354de6643bd594bbab2284e509e8b.png)

两会期间，绿盟科技云安全运营平台对主管机构指定的网站进行7\*24小时监测，监测项目包括挂马监测、篡改监测、漏洞扫描，并且生成安全监测日报和漏洞扫描报告，反馈给监管部门。绿盟多次作为两会的安保支持单位，体现了主管部门对绿盟科技保障国家重大活动安全方面的实力的肯定。

![](../Images/448eeaa458c4cf02aeb42a8a40cbaa3c.png)

**其他重大活动**

![](../Images/0ab08aa381532264747d5b54343b824c.png)

全国网络安全大检查

经中央网络安全和信息化领导小组批准，全国范围的关键信息基础设施网络安全检查工作启动。绿盟科技紧扣本届网络安全大检查活动主题，结合各地实际情况，针对重点突出问题，切实服务于“国家网络安全周”，拓展网络安全防护思维，普及防护手段，提供全面有效的安全解决方案，增强宣传推广力度，促进全民提高网络安全认知，切实达到“网络信息人人共享，网络安全人人有责”的宣传效果。

  

国际刑警大会

国际刑警组织是全球覆盖范围最大、成员数量最多、代表性最广的国际执法合作组织。国际刑警组织成立近百年来，以增进互信协作、促进世界安全为己任，遵循让世界更安全的理念，为凝聚世界各国警方共识、深化国际执法安全合作、共同打击犯罪发挥了不可替代的重要作用。此次大会在北京召开，为推动全球安全治理、维护世界安全稳定作出新贡献。

![](../Images/41f02d7a90dace16d58b65022cd316d2.png)

绿盟科技历经世博会、亚运会等世界级重要活动网络安保工作的洗礼，期间与运营商、重点职能机构的合作经验极其丰富，此次国际刑警大会期间的网络安保工作为绿盟科技在重要会议期间的网络安保工作部署及防御体系建设与完善提供了重要经验，为绿盟科技在重要时期的防御应急工作中更出色的表现奠定了坚实的基础。

  

第十三届全运会

第十三届全运会以“创新、安全、节俭、绿色、精彩”为理念，天津用饱满的热情以及万全的准备向全国人民交出了一份满意的答卷。

![](../Images/45b2cc999b14ed6e6194649a790377bb.png)

此次全运会中，绿盟科技作为网络安全保卫的唯一中标安全厂商，面对任务重、目标多、网络安全形势复杂的客观情况，在主管部门的统一部署下，牢固树立底线思维，利用安全平台及产品，强化应对方案，争分夺秒直面网络安全威胁。第十三届全运会安保部（天津市公安局网络安全保卫总队）特此发来感谢信，对绿盟科技一直以来对公安机关网络安全保卫工作的高度重视和全力支持，以及在全运会网络安保中作出的重要贡献表示衷心感谢。
