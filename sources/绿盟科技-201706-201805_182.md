# 谁动了我的注销权？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650390627&idx=2&sn=cb030cb2db20ea8f75ed8eee0f4f696a&chksm=beca99c889bd10de50616fc311dde7a2b8e2c212937c3eb81c522f659c29f759b437eb831293&scene=126&sessionid=1681372537#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650390627&idx=2&sn=cb030cb2db20ea8f75ed8eee0f4f696a&chksm=beca99c889bd10de50616fc311dde7a2b8e2c212937c3eb81c522f659c29f759b437eb831293&scene=126&sessionid=1681372537#rd)

目前互联网上的很多网站为了追求用户量，故意屏蔽注销功能，这仿佛也成了各大网站默认的“潜规则”，注册容易注销难一直是一个比较普遍的现象，其实，在《电信与互联网用户个人信息保护规定》中明确规定了：用户终止使用电信服务或者互联网信息服务后，电信业务经营者、互联网信息服务提供者应停止对用户个人信息的收集和使用，并为用户提供账号注销服务。

![](../Images/b3b8f1f1387e52a3916144be31395ed7.png)  

谁动了我的注销权？【央视采访】

同时，今年网络安全法的出台，更加明确了个人信息保护的范围，网络运营商应依法收集和使用个人信息，确保个人信息的安全。我们在注册时输入的个人信息，其实更像是我们将个人信息授权给网络运营者在一定范围内使用。因此，网络运营商应当对用户提供相应的功能，来明确这些信息的使用范围以及我们授权给网络运营者的授权时限。不提供注销服务，其实是强制用户对其进行个人信息的使用进行了无限期授权，这就增加了个人信息被窃取或被恶意利用利用的可能性，如：  

*   隐私泄露：一旦我们注册过的网站存在漏洞，或者不法分子利用其他站点窃取的信息进行撞库，就可能导致个人网上交易信息，邮件，照片、通讯录等隐私信息泄露。
    
*   财产损失：不法份子可能利用我们的个人信息进行不正当交易或其他非法行为。
    
*   身份被冒充：不法分子可以通过这些泄露的个人信息盗用他人身份进行诈骗。

对于用户来讲注销不常用网站的账号，可以减少个人信息的暴露面，降低信息泄露概率。通过注销，用户可以主动收回存在安全隐患网站的个人信息使用授权，维护自己的合法权益。

对于提供互联网服务的企业来讲，注册用户量是企业生存之本，有利于企业的发展和宣传，所以网站要想办法“留住”每一个用户。但注册容易注销难，不但是对相关法律法规的漠视，还涉嫌侵犯用户的合法权益，如果网络运营者可以设置有时限的授权或者提供账号注销功能，那么由于用户信息泄露所带来的安全隐患的可能性就会大大降低。
