# 车联网“端-管-云”防护 全周期安全保障

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650390505&idx=1&sn=c0a9da29edb5efba658f3f70f9ca373e&chksm=becae64289bd6f54f19c4ce0d49778aca9a5aec5e886b0f668b22ce7b3f7c96ab926fc968fa0&scene=126&sessionid=1681372539#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650390505&idx=1&sn=c0a9da29edb5efba658f3f70f9ca373e&chksm=becae64289bd6f54f19c4ce0d49778aca9a5aec5e886b0f668b22ce7b3f7c96ab926fc968fa0&scene=126&sessionid=1681372539#rd)

![](../Images/1621abc0fbfc2330ffef804f68e530b1.png)

近日，2017中国车联网安全论坛在武汉VV+车联网产业园圆满举办。本次论坛诚邀了绿盟科技、SecZone、梆梆安全、东软等领军研究单位，以及全国多个地区的近100名专家与车企、行业安全公司代表到场，分享思想创见、汇聚智慧力量，凝聚共建车联网安全生态圈的共识。

![](../Images/ec7e4f36d3ad6830b3ed7606a481a191.png)

随着汽车产业正在不断的发展，增加更多的便利和个性化的驾驶体验的能力特点。人们希望不断地加以连接，这是推动汽车制造商增加车辆和个人设备之间进行更多的整合，如智能手机等。

  

以前，汽车是孤立的，物理隔离的，因此黑客很难远程入侵汽车内部控制器，除非进行物理入侵，而这个是需要很高的犯罪成本。随着互联网的进化，当TSP通过T-Box 与汽车内部网络联网之后，汽车受到的远程网络攻击就不再是猜想。

![](../Images/a13dbc80d46dd78141a83bdb16fe41de.png)

绿盟科技资深架构师对于车联网的安全体系提出专业见解，从“端-管-云”以及新兴外部生态安全防护技术等角度探讨智能网联汽车网络安全最新的解决方案和实践。

![](../Images/1186223d68a344c5e2d934e081319601.png)

对于车联网安全体系的理解有助于快速找到安全的切入点。车联网体系结构通常认为有3个层面，包括：云侧、管侧和端侧。云侧可以实现后台大数据分析和车辆特定服务；管侧提供通信连接管道；端侧实现车辆控制、车辆对周边环境的感知和通信等。

![](../Images/4f00e4372ab2c6b0603cfe707d08e52c.png)

从车联网安全事件为入手点，进一步梳理分析车联网安全威胁及风险，并提出针对车联网云、管、端体系化进行防护。绿盟建议基于车联网安全体系进行全生命周期安全保障，并进一步阐述包含安全服务及安全产品的解决方案。

  

绿盟科技以社会责任为己任，期待大家共同努力、共话合作，促使车联网的信息安全从整体架构、标准规范、关键的共性技术到未来的产品开发，形成全链条的防护体系，来推动智能网联汽车跟智能交通的深度融合发展。
