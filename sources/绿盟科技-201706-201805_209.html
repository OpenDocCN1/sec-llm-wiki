威胁信息回顾

●标题：Apple Releases Security Updates

时间：2017-12-12

摘要：Apple has released security updates to address vulnerabilities in AirPort Base Station. An attacker could exploit some of these vulnerabilities to take control of an affected system.


●标题：19-YEAR-OLD TLS VULNERABILITY WEAKENS MODERN WEBSITE CRYPTO

时间：2017-12-13

摘要：A vulnerability called ROBOT, first identified in 1998, has resurfaced. Impacted are leading websites ranging from Facebook to Paypal, which are vulnerable to attackers that could decrypt encrypted data and sign communications using the sites’ own private encryption key.


●标题：Microsoft Says ERP Product Private Key Leak Posed Little Risk

时间：2017-12-11

摘要：It took Microsoft more than 100 days to address a problem related to the use of the same digital certificate for all installations of its Dynamics 365 enterprise resource planning (ERP) product, but the company said the issue posed little risk.


●标题：Google Researcher Releases iOS Exploit—Could Enable iOS 11 Jailbreak

时间：2017-12-11

摘要：As promised last week, Google’s Project Zero researcher Ian Beer now publicly disclosed an exploit that works on almost all 64-bit Apple devices running iOS 11.1.2 or earlier, which can be used to build an iOS jailbreak, allowing users to run apps from non-Apple sources.


●标题：Millions Impacted by Credential-Stealers in Google Play

时间：2017-12-12

摘要：During October and November 2017, Kaspersky Lab researchers discovered 85 applications in Google Play that were designed to steal credentials for Russian social network VK.com. One of the malicious applications had more than a million downloads.

焦点漏洞

◆ 焦点漏洞 

Apache Synapse 远程代码执行漏洞

◆ NSFOCUS ID 

38381

◆ CVE ID

CVE-2017-15708

◆ 受影响版本 

Apache Group Synapse <= 3.0

◆ 漏洞点评 

Apache Synapse是一个轻量级且高性能的企业服务总线。Apache Synapse在小于3.0.0的版本中存在远程代码执行漏洞，可使攻击者利用此漏洞在受影响应用上下文中执行任意代码。目前，Apache官方已经发布了最新的3.0.1版本修复了该漏洞，请受影响的用户尽快升级到最新版本进行防护。
