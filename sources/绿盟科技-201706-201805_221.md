# 中国企业在网络安全投资布局领跑全球，物联网受关注

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650390328&idx=1&sn=c1c75432c573399e71917c72c778558c&chksm=becae69389bd6f85a5cf1b7a4aa3d6c31e3fc4388fda7c1536ac2eda40bc20a3b1ff702388f1&scene=126&sessionid=1681372541#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650390328&idx=1&sn=c1c75432c573399e71917c72c778558c&chksm=becae69389bd6f85a5cf1b7a4aa3d6c31e3fc4388fda7c1536ac2eda40bc20a3b1ff702388f1&scene=126&sessionid=1681372541#rd)

![](../Images/1d1577e6cfa9f42a7772124309644a74.png)

在刚刚结束的世界互联网峰会上，各位互联网大佬的谈话中，互联网安全已然成为主要讨论的话题之一。互联网安全问题不仅仅涉及支付安全、未成年人使用网络安全、数据存储安全，还涵盖了社会伦理与道德、知识产权保护、甚至关系到社会公共安全和国家军事安全。

![](../Images/34dc165fee67c6614e337a448f22a67f.png)

近日权威机构调研显示，中国内地与香港的企业在网络安全方面的平均投入比全球数值高出近四分之一，受访企业的平均预算达630万美元。在具体的投资布局上，64%的受访企业将物联网安全(IoT)标记为最优先项。

  

物联网在全球呈快速发展趋势，欧美等发达国家都将物联网作为国家级战略新兴产业快速推进。我国在“十三五”规划中明确提出了物联网国家战略，为信息产业开拓了新的空间。市场研究机构Gartner预测，到2020年将有超过200亿台的物联网设备接入网络。

![](../Images/bd80f782ca0afd393f9cf031c361e855.png)

物联网安全事件频发，安全成为其发展的最大障碍。2016年下半年，全球发生多起由物联网设备构成的僵尸网络发动的DDoS攻击事件，造成严重的社会影响。

![](../Images/2d0e4f181109fbed443e415f346e4bcc.png)

物联网在全球呈快速发展趋势，物联网面临仿冒接入、隐私泄露、设备受控、蓄意破坏等越来越多的安全问题。

![](../Images/14fb9fcbdc8be92d38554452eda06cf5.png)

作为一家老牌的信息安全厂商，绿盟科技持续关注物联网安全，**提出智能家居、物联网平台、工业物联网和运营商四大安全解决方案。**  

![](../Images/0975a4be28309d1e488f59090e861798.png)

绿盟科技针对家庭设备缺乏统一管理，易受网络攻击造成隐私泄露和设备受控等主要安全问题，提出由智能安全网关、云端安全平台和用户管理客户端组成的一体化智能家居安全解决方案。

![](../Images/51ea0d58c7156ff2f41e50125eb09600.png)

绿盟科技物联网平台安全解决方案在终端设备和物联网管理平台间设置安全功能层，仅需极小改动就能为现有物联网平台提供强大的立体安全防护能力；整个方案包括终端接入安全、边界防护、可视化安全管理与绿盟云安全支持四大方面。

![](../Images/bb1353311defccb78613e3e5ae68c9d6.png)

绿盟科技针对运营商物联网业务监管和威胁态势感知的需求，提出物联网安全解决方案。该方案基于物联卡产生的业务运营数据、用户行为数据和基础流量数据，采用用户行为分析、网络威胁建模、威胁情报关联等大数据分析技术，识别物联卡业务使用异常和大规模的网络威胁事件，可实现物联卡的业务可管可控，网络威胁态势可见。

![](../Images/72a7e3dd68d04fe58ee222058a116452.png)

绿盟科技针对工业系统中的物联网设备发起的攻击有可能导致严重的安全生产事故，提出了边界防护，资产管理，安全监控和服务支持四位一体的防护策略，有效的提升工业物联网整体安全防护的能力。

![](../Images/3a77295a54ce06f8747dcfb2270636d8.png)

**在研究方面，绿盟科技建有物联网安全实验室。**已发布多份白皮书；对安全事件第一时间发布研究报告；漏洞挖掘能力出众；具备一线的安全数据分析经验和能力，为绿盟科技产品线提供大数据分析和安全数据挖掘方面的支撑；承担多项国家课题。

  

**在服务方面，我们提供安全咨询、安全评估、安全运营三大安全服务，为用户的物联网安全运营提供全面保障。**安全评估包括设备评估、平台评估和移动应用评估。安全咨询包括技术咨询、服务咨询、产品咨询。安全运营包括自动化运营平台和专家运营团队。

在物联网被受关注的今天，绿盟科技将不断提供具有核心竞争力的安全产品及解决方案，帮助客户实现业务的安全顺畅运行。
