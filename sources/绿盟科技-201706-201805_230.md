# 【预警通告】RSA Authentication Agent 漏洞

综述

近日，RSA Authentication Agent被发现存在2个关键漏洞：

CVE-2017-14377，CVE-2017-14378。成功利用这些漏洞可能导致验证绕过从而访问其他资源。具体的漏洞信息请参考下文。

相关链接：

http://securityaffairs.co/wordpress/66325/hacking/rsa-authentication-sdk-flaws.html

http://seclists.org/fulldisclosure/2017/Nov/46

http://seclists.org/fulldisclosure/2017/Nov/48

**CVE-2017-14377**

用于Apache Web Server的RSA身份验证代理的Web上的安全漏洞可能会导致身份验证绕过。

CVSS v3.0 Base Score: 10

(AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:N)

**影响的产品及版本**

*   RSA® Authentication Agent for Web: Apache Web Server version 8.0
    
*   RSA® Authentication Agent for Web: Apache Web Server version 8.0.1 prior to Build 618
    

**不受影响的产品及版本**

*   RSA Authentication Agent for Web: Apache Web Server version 8.0.1 Build 618
    

**处理方案**

RSA建议所有用户尽快升级到安全版本。

参考链接：https://community.rsa.com/community/products/securid/authentication-agent-web-apache.

http://seclists.org/fulldisclosure/2017/Nov/46

**CVE-2017-14378**

RSA Authentication Agent API / SDK for C版本8.5和8.6中的一个安全漏洞可能导致在某些有限的实现中绕过身份验证

CVSS v3 Base Score: 10

AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H

**影响的产品及版本：**

*   RSA® Authentication Agent API 8.5 for C
    
*   RSA® Authentication Agent SDK 8.6 for C
    

**不受影响的产品及版本**

*   RSA Authentication Agent API 8.5.1 for C
    
*   RSA Authentication Agent SDK 8.6.1 for C
    

**处理方案**

RSA建议所有用户尽快升级到安全版本，同时请确保其API / SDK的实现符合“RSA身份验证代理API for C开发人员指南”中记录的编码准则。

参考链接：  

https://community.rsa.com/docs/DOC-40601#agents

http://seclists.org/fulldisclosure/2017/Nov/48
