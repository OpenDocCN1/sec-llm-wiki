近日，中央国家机关政府集中采购2017年信息类产品协议供货采购项目名单出炉，绿盟科技以包括虚拟化管理软件、漏洞扫描软件、基线扫描软件、安全管理中心SOC软件四类产品入围。

“

这是中央国家机关政府对绿盟科技产品的认可，也证实了绿盟科技在安全行业领军者的地位。

![](../Images/7b07bbe129734b3ddcd3617a6210a853.png)![](../Images/2ae45e964db1946a4e11140e17e1dc4c.png)

**入围情况介绍**

![](../Images/e6f7d0dfc101b4dde637989f88655dd7.png)

中央国家机关政府采购中心就中央国家机关政府集中采购2017年信息类产品协议供货采购项目的相关货物和有关服务进行国内公开招标，绿盟科技四款投标产品全部入围：

绿盟下一代安全云桌面系统、绿盟远程安全评估系、绿盟安全配置核查系统、绿盟企业安全平台。中标产品为2017年的信息类产品协议供货采购以及公司产品品牌的延续打下了坚实基础。

![](../Images/2ae45e964db1946a4e11140e17e1dc4c.png)

**产品情况介绍**

![](../Images/e6f7d0dfc101b4dde637989f88655dd7.png)

**绿盟下一代安全云桌面系统**：NGSD（Next Generation Security Desktop）是一款基于下一代云桌面架构的云计算产品，采用了双核心的设计，对于性能强劲的PC机可采用VOI模式启动，充分发挥PC本地CPU、GPU的硬件性能，无需任何重定向技术的支持即能完美支持3D图形图像的建模、渲染、后期处理、高频解码及后期处理等工作，对服务器的计算资源几乎零占用。 

**绿盟远程安全评估系统**：RSAS（NSFOCUS Remote Security Assessment System）绿盟科技结合多年的漏洞挖掘和安全服务实践经验，自主研发的新一代漏洞管理产品，它高效、全方位的检测网络中的各类脆弱性风险，提供专业、有效的安全分析和修补建议，并贴合安全管理流程对修补效果进行审计，最大程度减小受攻击面，是您身边专业的"漏洞管理专家"。

![](../Images/989cc8e2bd43664e9d732431ebdb2cd9.png)

**绿盟安全配置核查系统**：BVS  （NSFOCUS Benchmark Verification System）具备完善的安全配置库，采用高效、智能的识别技术，可以实现对网络资产设备自动化的安全配置检测、分析，并提供专业的安全配置建议与合规性报表。该系统的应用，将大大提高安全配置检查的方便性、准确性，在节省时间成本的同时，让安全配置维护工作变得有条不紊而且简单、易于操作。

![](../Images/c6435420a7955877bedf8bdc04536a8a.png)

**绿盟企业安全平台**：ESP（NSFOCUS Enterprise Security Planning）采用云化的方式来建立一个可以将企业安全服务和业务适当外包给专业安全公司的平台，同时用户可以将自己核心和不愿外包的数据保留在自己的平台层面。

![](../Images/2ae45e964db1946a4e11140e17e1dc4c.png)

**入围背景介绍**

![](../Images/e6f7d0dfc101b4dde637989f88655dd7.png)

自从2002年6月29日第九届全国人民代表大会常务委员会第二十八次会议通过《中央政府采购法》以来，中央政府的采购招标已经越来越规范。而无论是厂商还是经销商已经越来越重视能否成功入围政府采购，成为指定单位。入围政府采购协议供货目录不仅可以扩大产品的销售范围，也是对企业、厂家实力的展示。而信息类产品的政采协议供货的出货量，也直接关系着生产厂家的产品在整个信息安全行业的品牌排名。

今年第二季度绿盟科技11类产品全线入围政府集采项目，涉及低中高端型号，覆盖全系列69款产品，包含：NF产品24款、NIDS产品24款、NIPS产品3款、RSAS产品3款（含WVSS产品）、SAS产品3款、SASH产品3款（含DAS产品）、WAF产品3款、ADS产品3款、NTA产品3款，这是对绿盟科技品牌、产品、服务以及特色解决方案等多方面价值的全面肯定，也是推动绿盟科技不断进步的动力。

十几年来，中央预算单位信息类产品协议供货规模超过350亿元，协议供货制度配合政府采购制度改革，较好地发挥了产品多样、下单快捷的制度优势，受到广大采购人的肯定。而国家政府也在大力推广协议供货制度，使之日趋完善。对政采协议供货产品的入围要求也越来越高。

作为中国信息安全行业的领航企业及国家信息安全顶层设计的参与者，绿盟科技拥有完整的网络安全产品线及解决方案，拥有100%自主研发的安全技术，构建了一个完整的安全防护生态体系，为百行百业的发展提供扎实可靠的安全服务。
