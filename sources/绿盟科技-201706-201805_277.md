时间：2017-10-31

摘要：Early this week FireEye released a managed password cracking tool, dubbed GoCrack, that is able to execute tasks across multiple GPU servers.

时间：2017-10-31

摘要：A flaw in the Google Issue Tracker, also known as the “Buganizer,” might have exposed details about unpatched flaws listed in the database.

**焦点漏洞**

**◆焦点漏洞**

Oracle Identity Manager Connector本地安全漏洞

**◆NSFOCUS ID**  

37911

**◆CVE ID **

CVE-2017-10270

**◆受影响版本**

Oracle Identity Manager Connector 9.1.1.5.0

**◆漏洞点评**  

Oracle Fusion Middleware是一个全面的中间件产品系列，由SOA和中间件产品组成,它的Oracle Identity Manager Connector组件存在安全漏洞，可使未经身份验证的远程攻击者破坏Oracle Identity Manager Connector，成功利用后可访问敏感数据。目前厂商已为此发布了一个安全公告（cpuoct2017-3236626）以及相应补丁，请受影响的用户及时下载补丁升级更新。
