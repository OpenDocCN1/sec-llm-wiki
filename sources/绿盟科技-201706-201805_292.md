# 【威胁通告】Apache OpenOffice多个代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650389852&idx=2&sn=51f144aefcb53874a1f692278bb9bfb4&chksm=becae4f789bd6de13ee2a73ad789da01ed872506661eb795564999319e0db74decbe028941dd&scene=126&sessionid=1681372547#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650389852&idx=2&sn=51f144aefcb53874a1f692278bb9bfb4&chksm=becae4f789bd6de13ee2a73ad789da01ed872506661eb795564999319e0db74decbe028941dd&scene=126&sessionid=1681372547#rd)

综述

 

今天，Talos发布了Apache OpenOffice应用程序中发现的三个新的可以任意代码执行漏洞的详细信息。

**参考网站如下：**

http://blog.talosintelligence.com/2017/10/vulnerability-spotlight-apache.html

![](../Images/22d58577a5fefb3fb0fe514063f11a05.png)

  

   

**受影响的版本**

● Apache OpenOffice version <= 4.1.3

   

**不受影响的版本**

● Apache OpenOffice version 4.1.4

   

  

**规避方案**

  

● 受影响的用户请及时到产品官方进行升级。

http://www.openoffice.org/download/index.html

● 如果使用了开源Snort的用户，可以更新如下规则：

42008 - 42009, 42144 - 42145, 42076 - 42077
