# 【预警通告】Apache Tomcat 远程代码执行漏洞 CVE-2017-12617

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650389550&idx=2&sn=ae4d107dc2c1b25fb00c497e7441b2fb&chksm=becae58589bd6c93d7499eb03947b042a9cfb19b3bf3d776bde4b1604f3728a7adc99741edc2&scene=126&sessionid=1681372549#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650389550&idx=2&sn=ae4d107dc2c1b25fb00c497e7441b2fb&chksm=becae58589bd6c93d7499eb03947b042a9cfb19b3bf3d776bde4b1604f3728a7adc99741edc2&scene=126&sessionid=1681372549#rd)

![](../Images/1621abc0fbfc2330ffef804f68e530b1.png)

**综述**

 

近日，Apache官方发布了Tomcat的新版本，修复了一个远程代码执行漏洞（CVE-2017-12617）。该漏洞源于在HTTP PUT方法时，攻击者可以通过特制请求将JSP文件上传到服务器。 然后可以请求此JSP，让服务器执行该JSP中包含的任意代码。

**相关地址：**

https://lists.apache.org/thread.html/3fd341a604c4e9eab39e7eaabbbac39c30101a022acc11dd09d7ebcb@%3Cannounce.tomcat.apache.org%3E

http://tomcat.apache.org/security-7.html

http://tomcat.apache.org/security-8.html

http://tomcat.apache.org/security-9.html

   

**受影响的版本**

*   Apache Tomcat 9.0.0.M1 – 9.0.0
    
*   Apache Tomcat 8.5.0 – 8.5.22
    
*   Apache Tomcat 8.0.0.RC1 - 8.0.46
    
*   Apache Tomcat 7.0.0 – 7.0.81
    

   

**不受影响的版本**

*   Apache Tomcat 9.0.1
    
*   Apache Tomcat 8.5.23
    
*   Apache Tomcat 8.0.47
    
*   Apache Tomcat 7.0.82
    

   

**解决方案**

官方已经发布了新版本修复了该漏洞，受影响的用户请尽快升级至最新版本来防护该漏洞。

https://tomcat.apache.org/download-80.cgi

https://tomcat.apache.org/download-70.cgi
