**威胁信息回顾**

**标题：Joomla!潜伏8年的LDAP注入漏洞CVE-2017-14596 20秒拿下网站**

时间：2017-09-21

摘要：在静态代码分析的帮助下, RIPS检测到 Joomla! 3.7.5中存在一个关键的 LDAP 注入漏洞 (CVE-2017-14596), 这个漏洞已经有8年多未曾发现。该漏洞允许攻击者窃取来自 Joomla! 的登录凭据!使用 LDAP 身份验证的安装。joomla!最新版本3.8 已修复了漏洞。

  

**标题：DropShot恶意软件攻击美多个行业 APT33此次攻击方式是鱼叉式攻击**

时间：2017-09-24

摘要：在2017年3月，绿盟科技曾截获shamoon 2.0恶意软件样本，当时的分析报告指出， Shamoon2恶意软件在国外有数次攻击石油机构的事情，其主要功能是硬盘数据清除 ，也是在3月，卡巴斯基报告称 攻击石油公司的恶意软件又出来一个StoneDrill，它跟Shamoon的攻击行为很类似 ，上周三FireEye发布报告称，这个恶意软件家族又出来相关恶意程序，称为DropShot恶意软件，正在攻击美国的航空及能源行业

  

**标题：通用漏洞报告框架CVRF1.2发布 标准、机读且可以应用于生产**

时间：2017-09-22

摘要：国际标准组织OASIS于9月20日发布了OASIS发布通用漏洞报告框架CVRF v1.2，CVRF框架是一种交流安全公告的语言, 通过确保机读的安全警告可以更广泛的在生产中应用，进而提高产品之间的互操作性。该版本的发布标志着广大的安全厂商以及他们的客户，将会使用更为标准的方式发布安全公告，并且能够直接投入生产应用。

  

**标题：Westermo三款工业路由器高危漏洞 硬编码密码及跨站请求伪造 PoC已公开**

时间：2017-09-21

摘要：瑞典工业数据通信公司Westermo部分无线3G和4G路由器爆出高危漏洞。Qualys的研究人员Mandar Jadhav发现，Westermo的MRD-305-DIN、MRD-315、MRD-355和MRD-455工业路由器存在三个漏洞。这些路由器用于商业设施、关键制造业和能源行业的全球远程访问。

**焦点漏洞**

**◆焦点漏洞**

Apache Tomcat 远程代码执行漏洞

**◆NSFOCUS ID**  

37671

**◆CVE ID **

CVE-2017-12615

**◆受影响版本**

Apache Tomcat 7.0.0-7.0.79

**◆漏洞点评**  

Apache Tomcat是一个流行的开源JSP应用服务器程序。Windows平台下的Apache Tomcat 7.0.0-7.0.79版本，在启用HTTP PUTs功能后，攻击者可以通过构造特殊的请求，上传恶意JSP文件到服务器，进而执行任意命令控制服务器。此漏洞影响Windows平台下的Apache Tomcat 7.x版本，目前已在Apache Tomcat 7.0.81中修复。请用户及时升级。
