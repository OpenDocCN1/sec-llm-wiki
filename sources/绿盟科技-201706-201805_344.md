**◆NSFOCUS ID**

Microsoft .NET Framework 3.5

Microsoft .NET Framework 2.0 SP2

Microsoft .NET Framework 2.0

**◆漏洞点评**  

Microsoft .NET Framework在验证输入时安全漏洞，可导致代码注入，被成功利用后，可使攻击者控制受影响系统。由于主流的Windows操作系统都默认内置了.NET Framework，且攻击形式多样，可以通过Office文档嵌入远程的恶意.NET代码进行攻击，所以该漏洞危害很大，建议用户及时升级更新相应的系统补丁，修复漏洞。
