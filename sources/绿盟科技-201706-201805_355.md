**焦点漏洞**

**◆ 焦点漏洞**

Cisco Meeting Server命令注入及权限提升漏洞

**◆ NSFOCUS ID**

37480

**◆ CVE ID **

CVE-2017-6794

**◆ 受影响版本**

Cisco Meeting Server <= 2.2

Cisco Meeting Server <= 2.1

Cisco Meeting Server <= 2.0

**◆ 漏洞点评**  

Cisco Meeting Server是Cisco公司推出的网络会议解决方案。Cisco Meeting Server在CLI命令解析代码中存在漏洞，对用户提供的输入验证不足，可能允许经过身份验证的本地攻击者执行命令注入，并将其权限升级为root。目前Cisco已经发布补丁，请用户及时去Cisco官网下载更新，修复漏洞。
