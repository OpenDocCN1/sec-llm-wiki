# 新能源电厂并网之痛——涉网安全防护治理

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650389209&idx=2&sn=86b1de3c21b4c814e81b1c75a1977af8&chksm=becae37289bd6a641a92e7c63995ba82888caf7acc7444b99cffb6128bce5eb081dbc624d8e4&scene=126&sessionid=1681372553#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650389209&idx=2&sn=86b1de3c21b4c814e81b1c75a1977af8&chksm=becae37289bd6a641a92e7c63995ba82888caf7acc7444b99cffb6128bce5eb081dbc624d8e4&scene=126&sessionid=1681372553#rd)

**前言**

改革开放以来，我国经济高速发展的同时，能源消费结构不合理引起的资源环境问题却日益突出。近几年为调整能源结构、促进节能减排和实现可持续发展。国家相继出台了多份关于大力发展新能源发电的相关文件，以风电和光伏为代表的新能源电厂出现了井喷式的增长。

![](../Images/ccad197bc0e8f6facda31a2b217f2f57.png)

尽管新能源发电厂建设速度一直在高速增长，但是作为生产控制核心的发电厂电力监控系统却未同步进行安全建设工作。  

安全风险

 

近期，国家能源局在部分省份新能源电厂现场检查发现，大量电厂存在不同程度的网络安全隐患，这给电厂和调度网络的安全稳定运行带了巨大的安全隐患。对此，调控中心针对已并网问题电厂采取了强制解网的措施，并切断其与调度数据网的连接。另外，也加强了针对新建电厂监控系统安全防护方案的审核及工程实施的验收工作，未被验收通过的电厂将无法并网发电。

![](../Images/8ed1924de12280c9193edd15516c8d8a.png)

解决方案

 

为此，绿盟科技结合新能源电厂网络系统现状，并依据发改委14号令和国家能源36号文中有关发电厂监控系统安全防护要求，面向新能源电厂发布电厂监控系统安全防护解决方案，助力新能源电厂顺利安全并网运行：

  

横向边界防护

在生产控制大区与管理信息大区之间部署电力专用横向单向安全隔离装置，隔离强度接近于物理隔离；生产控制大区内部的安全区之间采用具有访问控制功能的网络设备和安全可靠的硬件防火墙，实现逻辑隔离、报文过滤、访问控制功能。

![](../Images/367fa8ee68339273bacf4238dfaefde5.png)

  

纵向边界防护

纵向边界防护是指发电厂生产控制大区系统与调度端系统通过电力调度数据网进行远程通信时，应当采用认证、加密、访问控制等技术措施实现数据的远方安全传输以及纵向边界的安全防护。

![](../Images/7b3e2348130c96f3b1221ba53cc66539.png)

  

第三方边界安全防护

第三方边界安全防护主要是指管理信息大区和OMS工作站与外部网络之间应采取防火墙、VPN和租用专线等方式，保证边界与数据传输的安全。

![](../Images/11394c4ec47b178809e170c19a261b1a.png)

  

网络入侵检测

生产控制大区与OMS工作站区域应当具备网络入侵检测能力，检测发现藏匿于流经网络边界正常信息流中的入侵行为，分析潜在威胁并进行审计。

![](../Images/9566b61168e0ae9cae0fcba72e814601.png)

  

安全审计

生产控制大区的监控系统应具备安全审计功能，能够对操作系统、数据库、业务应用的重要操作进行记录、分析，及时发现各种违规行为以及病毒和黑客的攻击行为。对于远程用户登录到本地系统的操作行为，进行严格的安全审计。

![](../Images/67960c9dd4e40a1fad23e472a588cc78.png)

![](../Images/d3248206da7c4e59cf82bf9883f5d5e0.png)![](../Images/65f6cc746a09996c8b24b3a3e6f60a63.png)

发电厂监控系统在发电企业中具有重要的地位和作用，其信息安全防护建设工作则关乎发电企业生产的安全稳定运行。绿盟科技长期关注发电厂监控系统安全防护建设工作，致力于为发电企业提供符合国家要求及贴合企业实际安全需求的综合解决方案。
