# 当围棋大咖遇上网络安全精英：Google人工智能与机器学习探讨

TechWorld2017大会上最有火花的时刻莫过于围棋世界冠军古力、绿盟科技副总裁周凯和滴滴Labs安全研究负责人蔺毅翀参与的圆桌论坛：**Google人工智能与机器学习**。

众所周知，AlphaGo已经成了围棋界的神话，那作为世界围棋冠军的人类棋手古力对人工智能有什么样的看法呢？当围棋遇到了网络安全，又会碰撞出什么样的火花呢？网络安全与人工智能将如何齐头并进？ 

带着这些疑问，让我们从TechWorld2017的圆桌论坛中一探究竟吧！

围棋世界冠军古力：人工智能棋手比人类棋手拥有更强的大局观

![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

古力老师，一个公认的围棋高手需要什么样的核心能力？

大局观。像我以前可能就是计算力和战斗力比较强，但是大局观比较弱，所以只能算是一般的高手。后面到北京的深造以后，经过聂卫平老师的指导后，把大局观提高了以后才步入了顶尖高手行列。

![](../Images/4121f9020972195feaa17ed7767adbb4.png)![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

大局观如果换到AlphaGo的身上，它是一个什么样的表现，机器能表现出来大局观吗？

从它在棋盘上的表现，或者是我们人类高手对它的理解来说，它的大局观应该远强于我们。在我们认为它比较强的计算力方面它能力却表现一般，但是在大局观上面却远远胜于我们人类高手，这真是颠覆了我们职业棋手对人工智能围棋的最基本的一些看法。

![](../Images/4121f9020972195feaa17ed7767adbb4.png)![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

普通人都认为在大局观或者是虚的方面人类应该强于机器，而在实际的计算方面人类应该弱于机器，实际上正好相反，颠覆了。是个什么意思呢？就在具体的某一步计算的时候，机器已经完全看到最后了，就没有必要在计算上跟你较真了。所以它现在比的是大局观，棋盘可能性越大的时候越强于人类，而不是越小的时候，因为那个时候它已经完全的看到底了，这是颠覆了我们所有人的固有看法的。

人工智能的出现加速了人类棋手的进步。没有人工智能之前，我们是觉得我们的围棋水平想要在现有的水平进步可能性已经很小了。但是有了人工智能以后，我们发现原来我们对围棋的理解还那么的少，它给我们的空间已经无限的大。像柯洁经历过人工智能跟他下棋，我觉得他的水平已经长了六七步棋，像我的水平还比较低，可能我的成长空间还更大一些。

![](../Images/4121f9020972195feaa17ed7767adbb4.png)![](../Images/b3535007c64f869615e3adb61725f60a.png)

**绿盟科技周凯：**

**网络安全距离人工智能的实现还有差距**

![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

谈到的人工智能对人类的辅助，这在我们的安全行业是一个比较常见的现象。通过人工智能的技术来辅助我们的分析员、分析师做决策。那人工智能和网络安全行业的结合，周总您来给大家分享一下绿盟科技在这块儿的见解吧。

围棋跟安全有相通的地方，围棋是人和人做对抗，安全也是人和人做对抗。不同是说围棋在某种程度上讲信息是对称的，你下一步，我下一步，你走一个子我走一个子，一步一步地去做对抗。并且有它自己的规矩以及评判胜负的规则在里边。但是，安全我相信大家都是专家，它不是对称的，是一个没有什么太多的边界或者是规范。所以这的确是跟围棋属于截然不同的思路。对于安全的从业人员来讲，这也是一个非常大的挑战，因为这个的确是人和人智慧的比拼，你需要考虑方方面面的情况。

![](../Images/7ed19ed688caab856326fbf4eeeae6fa.png)![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

人工智能在网络安全方面有具体的应用吗？

其实上午的演讲中，我们的顾博士和陈博士都已经提到过机器学习以及大数据在安全领域上面的一些实践。但是要说如果我们能够通过AI实现像AlphaGo在围棋上的这种地位的话，现阶段可能还不太成熟，在某一个特定的领域有可能，但是整体上来讲还需要一些时间和积累。

![](../Images/7ed19ed688caab856326fbf4eeeae6fa.png)![](../Images/b3535007c64f869615e3adb61725f60a.png)

**滴滴安全蔺毅翀：**

**安全最大的挑战是如何应对未来**

![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

滴滴对于AI的实际应用有什么心得呢？

如果我们按照围棋的思路，回到我们的机器学习或者是人工智能，你会发现所有的技术发展都经过了几个阶段，最初的就是很简单的规则系统，你来一个我怎么对应。第二个过程是专家系统，我可以抽象出一种东西来，把这个转化成一种逻辑再和你去对抗。再到最后就是最近比较流行的深度学习这些东西，更多的是在学习，其实并不是说人工智能。为什么我说人工智能离我们相对比较远，从技术的角度来说并不是智能，只是在学习，包括AlphaGo用的那些深度学习的东西，还是基于很多人的先验知识，它有那么多的棋谱，已经学到了在什么样的情况下是一个最优解，在什么样的情况下可以按我们以前的做法，帮你把决策缩小到一个可控的维度上。

![](../Images/ec02cd1f519aac02ecabfa328093f4d4.png)![](../Images/a336b4ed897c373d60a2bc5912a4684d.png)

那滴滴有没有借助AI这样的东西在做一些算法、排序和汽车的优选路径方面的应用？

滴滴的很多应用都借助AI，比如图象识别、智能驾驶这些方面真的是突飞猛进。信息安全方向，现在包括一些主流的机器学习的方向，人脸识别、大数据的建模、后台的离线学习，在滴滴都有很不错的应用场景，我相信各家企业也都有应用。但是从攻防对抗这个角度来说，还相对是一个刚起步的阶段。怎么衡量这个问题呢？我们一般说的围棋是有一个固定的场景，有一个固定的评判的规则，每一步是回合制的。但是安全是没有规则的，你面临的威胁是各方面都有可能。今天你面临一个问题，很可能明天你面临的是一个新的问题。那在这种场景下，你会发现机器学习只能解决固定场景、固定输入、固定输出，这个方面可以做的很好，不管是从大局观来说，还是计算能力。我觉得在这点上已经相对比较公认，就是时间的问题。但是安全最大的挑战就是怎样去应对未来。这个问题上，现在我们也没有什么特别好的思路或者是方法。大家看到为什么人工智能，为什么智能驾驶还有图象识别那么突飞猛进，但是安全相对在这个方向上还比较滞后一些。
