绿盟数据库审计系统（NSFOCUS DAS）可以帮助企业快速定位数据库风险，及时告警，事后为追责提供有力的数据依据，作为一款专业的数据库审计产品应该具备全面审计的特点，即数据库访问审计日志的要素要尽量全面而详细、兼容各种数据库访问协议、支持三层数据库部署环境中的各种中间件，方便管理员全面掌握数据库访问情况。

**NSFOCUS DAS精细的数据库协议解析**

全面支持常用数据库协议，国外数据库Oracle、IMB DB2、Microsoft SQL Server、MySQL、Sybase和PostgreSQL，以及国产数据库达梦DM、人大金仓Kingbase和奥斯卡Oscar。

**NSFOCUS DAS SQL语句类型及执行全覆盖**

SQL是用于访问数据库的最常用标准化语言，他是由ANSI/ISO SQL标准定义的。包括：

  

**DQL：数据查询语言（用于检索数据）**

Select //检索数据

  

**DML：数据操作语言（用于检索或者修改数据）**

Insert //增加数据到数据库

Update //从数据库中修改现存的数据

Delete //从数据库中删除数据

 

**DDL：数据定义语言（用于定义数据的结构，比如创建、修改或者删除数据库的对象）**

create table //创建表

alter //修改表

drop table //删除表

create index //创建索引

drop index //删除索引

create view //创建视图

drop view //删除视图

 

**DCL：数据控制语言（用于定义数据库用户的权限）**

grant //授权

revoke //撤销授权

set //设置

 

**SQL函数**

Aggregate 函数

Scalar 函数

 

**存储过程**

被封装起来的可完成一定操作的一组SQL语句
