# 威胁预警 | 多家企业感染MBR勒索病毒

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650388660&idx=1&sn=e9a7d79f3467c5b7906525005a52d7ad&chksm=becae11f89bd6809b83b83dcc89545f89eaa2fe09ced4a786f7b85b7d4156e61a0b3ce10f31f&scene=126&sessionid=1681372562#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650388660&idx=1&sn=e9a7d79f3467c5b7906525005a52d7ad&chksm=becae11f89bd6809b83b83dcc89545f89eaa2fe09ced4a786f7b85b7d4156e61a0b3ce10f31f&scene=126&sessionid=1681372562#rd)

![](../Images/1621abc0fbfc2330ffef804f68e530b1.png)

北京时间6月27日，据国外社交媒体消息，乌克兰、俄罗斯两国的政府机构、机场、银行以及多家大型工业企业部分计算机系统遭受勒索病毒威胁，导致主机无法正常引导开机，严重影响了国家多个正常业务的运转；同时6月27日晚间，国内部分外企也确认有发现感染同样的勒索病毒。

  

根据勒索信息判断，该病毒为去年出现的新型勒索Petya的变种，Windows主机感染该病毒后，整个硬盘的MBR将会被覆盖，并导致系统崩溃蓝屏，而当用户重启计算机时，修改后的MBR会阻止Windows正常加载，而显示攻击者的勒索信息，在支付赎金获得解密秘钥前，用户将无法正常启动主机，从而失去文件和计算机的访问权限。

![](../Images/a6197f374d212c7374272d9124e6cfe2.png)

该Petya变种病毒还具备蠕虫传播特征，目前有证据表明其蠕虫功能利用了永恒之蓝（EternalBlue）漏洞，同时结合今年4月份曝出的Office 0day漏洞（CVE-2017-0199），通过恶意RTF文件进行钓鱼攻击，此外结合绿盟科技安全事件响应团队以往对此类病毒的应急处理经验，其往往还会通过多种应用弱口令进行自动化攻击，例如：RDP、WEB中间件、数据库等。

![](../Images/f2f5896ccd26cb6243894de2feedf34f.png) 

临时防护方案

![](../Images/cab40a063824e81eb4c28fd573376243.png)

1. 及时更新终端安全防护软件及Windows安全补丁，重点检查MS17-010补丁安装情况；

  

2. 利用威胁分析系统（TAC)检测通过网页、邮件或文件共享方式试图进入内部网络的恶意软件；

  

3. 及时告知终端用户尽量避免打开未知邮件中的链接或附件，谨慎从网络下载各类可执行程序。
