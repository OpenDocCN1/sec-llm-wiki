# 发力混合云安全 绿盟云亮相微软云服务商转型研讨会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650388660&idx=3&sn=e3ed18ddb87ca08e028127dcdf541c4a&chksm=becae11f89bd6809777a9cd470cc5fe5ebe747cb45ab8fde7dac7d5bb2d16c1c691873d7082d&scene=126&sessionid=1681372562#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650388660&idx=3&sn=e3ed18ddb87ca08e028127dcdf541c4a&chksm=becae11f89bd6809777a9cd470cc5fe5ebe747cb45ab8fde7dac7d5bb2d16c1c691873d7082d&scene=126&sessionid=1681372562#rd)

微软不仅是全球智能云服务领导者，更在混合云领域提供大量技术解决方案。2017年微软在人工智能、混合现实等领域黑科技层出不穷，为客户、合作伙伴实现数字化转型提供了创新基础。在商业合作方面，微软大生态全面转向云计算，不断推陈出新，创造大量合作机遇。

![](../Images/7a0110cffd74fea2cb2fbfef22ef7b2e.png)

日前，微软在北京、上海、广州三地召开了云服务商转型研讨会，绿盟云作为微软云计算的安全合作伙伴受邀出席并做了关于混合云安全管理实践方面的主题分享。

![](../Images/03ee63821db2b93f27e8c3708b895e7f.png)

绿盟科技SaaS事业部业务拓展经理陶智在分享中谈到，绿盟虚拟设备方案采用虚拟化和SaaS服务形态，重新定义安全商业模式，由传统安全产品的卖所有权模式转变为云计算安全产品的卖使用权模式，通过“订阅”为客户提供按需购买、灵活扩容的SaaS安全服务。绿盟云已经在微软Azure上完成WAF等虚拟化技术适配，配合绿盟云上的网站评估、系统扫描、网站监测等SaaS服务，为客户提供租户级云安全解决方案。

绿盟安全资源池方案采用软件定义安全（SDS）的架构，通过将安全数据与控制平面分离，对物理及虚拟的网络安全设备与其接入模式、部署方式、实现功能进行解耦，底层抽象为安全资源池里的资源并在顶层统一通过软件编程的方式进行智能化、自动化的业务编排和管理，以完成相应的安全功能从而实现灵活的安全防护。

![](../Images/9877331bc0b6dfaea6ec51a31f05ce03.png)

作为国内最早一批从事网络安全服务的厂商，绿盟科技在2015年成立绿盟云安全服务平台并提出了智慧安全2.0战略。自此，绿盟科技正式从传统产品模式向解决方案及安全运营模式转型。

近年来国家对网络安全的愈加重视促使着安全市场的不断扩大，作为一家从事网络安全17年的老牌公司，绿盟科技正加快向云安全等新型技术手段和市场方向拓展。
