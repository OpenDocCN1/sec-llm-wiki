# 【预警通告】Cisco IOS XR 64位软件高危漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650395534&idx=3&sn=5c57d052768b4ab3cdd7c002e61e47af&chksm=beca8a2589bd033399de7c3e8fd51e9a3edb4c88d4e35a6c3fe3af37926215e18d1c3ec097d2&scene=126&sessionid=1681372478#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650395534&idx=3&sn=5c57d052768b4ab3cdd7c002e61e47af&chksm=beca8a2589bd033399de7c3e8fd51e9a3edb4c88d4e35a6c3fe3af37926215e18d1c3ec097d2&scene=126&sessionid=1681372478#rd)

01  

**综述**

  

Cisco发布公告修复了一个Cisco ASR 9000系列中用到的IOS XR 64位软件的漏洞（CVE-2019-1710）。该漏洞是由于辅助管理接口与内部sysadmin应用程序的错误隔离造成的，攻击者可以通过该漏洞在未授权的情况下远程登录受影响的设备或者造成拒绝服务攻击。

CVSS 3.0评分：9.8

AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:X/RL:X/RC:X

  

详细信息可参考：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20190417-asr9k-exr

  

**02**

影响范围

  

**受影响的版本**

Cisco IOS XR 64-bit Software Release 6.5.x < 6.5.3

Cisco IOS XR 64-bit Software Release 7.0.x < 7.0.1

  

**不受影响的版本**

Cisco IOS XR 64-bit Software Release 6.5.3

Cisco IOS XR 64-bit Software Release 7.0.1

  

03

**解决方案**

  

Cisco官方已经发布最新版本修复了上述漏洞，请受影响的用户尽快升级进行防护。

  

具体操作方式请参考官方通告：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20190417-asr9k-exr
