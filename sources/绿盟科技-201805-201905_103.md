# 海南软件职业技术学院携手绿盟科技发力校企合作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650395203&idx=1&sn=c705333414d2ff16b8eae25a4c843e53&chksm=beca8be889bd02fed5cbd948a3e312072292ab6d2f06ab3137cb7e7f6634c810985f6db7b5c8&scene=126&sessionid=1681372482#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650395203&idx=1&sn=c705333414d2ff16b8eae25a4c843e53&chksm=beca8be889bd02fed5cbd948a3e312072292ab6d2f06ab3137cb7e7f6634c810985f6db7b5c8&scene=126&sessionid=1681372482#rd)

  ![](../Images/48efb5ec66be06740783d7bf7aff6828.png)

2019年3月26日，海南软件职业技术学院与绿盟科技共同签署校企合作协议，双方将在网络空间安全专业建设、“双师型”师资培训基地建设、应用型人才培养、实习实训等方面展开深度合作，共同培养网络安全应用型技术技能人才。海南软件职业技术学院院长魏应彬、网络工程系主任白晓波、副主任杨登攀、校企合作部主任郑全军、绿盟科技教育行业高级总监李永松、绿盟科技海南办事处首席代表张文杰等出席本次签约仪式。

![](../Images/a3219754d4a6bf5c668e178b3f4f3252.png)

签约仪式现场

 

**多角度探索，打破人才培养僵局**

  

“网安人才培养”已成为近几年网络安全产业最热门的行业焦点。来自国家层面的利好政策，让网络安全企业在实现校企合作深度融合，突破人才培养瓶颈方面进行着各种探索与尝试。这其中就包括绿盟科技。

  

传统的人才培养模式，往往是高校、企业“两张皮”，多流于形式，不具备可持续发展。而作为网络安全行业领军企业老兵的绿盟科技，则提出应以产学研深度融合培养人才。通过“共建基地、培训师资、共建课程、培训认证、网安竞赛、科创服务、就业创业”等措施，打破人才培养僵局，助力学科与人才建设。绿盟科技教育行业高级总监李永松表示：校企合作人才培养，应在感知网络空间人才需求情况的基础上，为学校构建合理的教学知识体系、专业的课程资源，为校企合作人才培养提供有效支撑。

  

  

**校企深度融合，助力打造国际教育创新岛**

  

当前，网络空间安全已上升到国家层面，学科发展、人才培养也应与产业、地区的发展相协调。海南软件职业技术学院院长魏应彬表示：海南软件职业技术学院正在积极探索网络安全学科建设与人才培养的新模式。希望双方能够在海南自由贸易岛体系下，结合区域发展形势，以国际教育创新岛为主题，大胆创新开拓新的校企合作模式。通过优势资源互补、共建攻防实验室、共研专业核心课程、师资互聘、攻防竞赛、企业实践等，共同为网安人才培养创造良好的环境。

  

而这也与绿盟科技不谋而合。绿盟科技以“校企合作、工学结合、优势互补、资源共享、互惠双赢、共同发展”为宗旨，依托高校与企业的各自优势，加快推动网络安全人才的培养与高水平成果转化。在网络安全人才的培养中，绿盟科技不仅为高校量身打造了网络空间安全综合实训平台、竞技平台、网络靶场、网络安全培训中心、高校应急响应服务中心等实验平台，更好地支撑了信息安全专业的实践教学。同时，对现有企业生态圈进行整合，为合作院校提供更多、更好的专业实训机会。还为高校学生提供“企业+高校”双师型师资培训体系，通过引入企业导师，为人才培养提供支撑，最大限度地激发安全产业潜力。

校企合作、人才培养是一个将理论付诸实践的过程，更是一个需要产学研紧密协作配合的过程。高校与企业应秉持不急不躁的心态，一步一个脚印，在提升自身业务能力的同时，更好地适应国家与区域发展，为我国网安产业的发展贡献自己的力量。
