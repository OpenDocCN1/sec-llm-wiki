受影响版本 

*   Microsoft Windows Server 2019
    
*   Microsoft Windows Server 2016

04

漏洞点评

Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows kernel没有正确地处理内存对象时，在实现中存在权限提升漏洞。本地攻击者可登录到系统并运行特制的应用程序，利用该漏洞执行任意代码。目前厂商已经提供补丁程序，请到厂商的相关页面下载补丁。
