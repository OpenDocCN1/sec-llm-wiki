01  

**综述**

微软近日发布了2019年3月安全补丁，本次发布的补丁共修复68个不同威胁程度的安全问题，其中包含16个严重漏洞。

![](../Images/31a92ffc2e2b129012eb2a1e4477510b.png)

  

**02**

**重点关注**

  

**CVE-2019-0775 | Windows 内核信息泄漏漏洞**

  

这是一个严重的内核级别信息泄露漏洞。攻击者可以精心构造一个恶意应用程序，通过伪装、网络钓鱼等方式投放至本地。当该应用程序运行时，可以读取当前内核中敏感信息，并将信息发回给攻击者。攻击者在掌握内核中敏感信息后，便可以掌握目标计算机的关键情况，从而大大增加入侵成功的概率。该漏洞影响最新版本Windows操作系统，且容易被利用，因此风险较高。  

  

**官方详细信息**

当 Windows 内核不正确地处理内存中对象时，存在信息泄漏漏洞。成功利用此漏洞的攻击者可以获取信息，从而进一步入侵用户系统。若要利用此漏洞，攻击者必须登录到受影响的系统并运行经特殊设计的应用程序。虽然攻击者无法利用此漏洞来执行代码或直接提升他们的用户权限，但此漏洞可用于获取信息，这些信息可用于试图进一步危及受影响系统的安全。  

  
此更新通过更正 Windows 内核处理内存中对象的方式来修复此漏洞。  

  

**03**

**解决方案**

微软官方已经发布更新补丁，请及时进行补丁更新。
