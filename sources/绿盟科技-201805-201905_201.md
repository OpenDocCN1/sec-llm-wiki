# 绿盟云技术开放日丨企业上云，安全仍需一马当先！

站在数字化转型的十字路口，中国依然有很多企业在观望，原因不外乎两个：一是原有的IT建设模式"良好"，为何非得迁移云端；另一个则是了解了上云的真正价值，但又担心云上数据和业务的安全。

  

的确，云上安全已成为目前云业务的主要痛点，也是网络安全企业的主攻方向。日前，绿盟云技术开放日北京活动现场集结了100多名用户参与到绿盟科技最新云端安全技术与方案探讨当中。会上，绿盟安全专家就容器安全研究、政务云安全、企业一体化安全运营、网站安全SaaS解决方案等多个热点领域同与会嘉宾进行深入探讨。同时，来自微软的技术专家也分享了其微软智能云与人工智能技术的最新进展。

**容器安全风险及应用方向**

虽然容器技术备受追捧，在多个领域得到了广泛使用，但其背后的安全问题却不容忽视。容器安全问题主要集中在容器漏洞风险、Docker架构风险和镜像风险当中。

  

![](../Images/469b891060b4ef4ae5c7f06be6936bc0.png)

  

对此，绿盟科技创新中心刘文懋博士提出了三个容器应用的方向：  

● "盒子"产品微服务化。基于Docker容器，实现安全功能更轻量的虚拟化，更好支持按需、弹性的安全能力。

●平台产品微服务化。针对平台的架构设计，对其进行微服务架构升级，完全将各个功能组件（资源管理、数据处理、API、web服务等）进行解耦合，实现模块化拆分，更好的实现兼容性、扩展性、敏捷性。

●安全应用商店。实现在线功能演示，更方便的实现产品的前后端同步，实现安全能力SaaS化。  

  

**政务云：鼓励用云，更需安全合规**

  

近年来，在国家大力引导和业界的共同推动下，我国政务云行业发展迅猛，在助力政务建设、打破信息孤岛、实现数据共享共治方面效果显著。同时，相关政策的出台使安全受到持续关注。  

  

![](../Images/6c69dab1ad3d54a60681e943667ea78b.png)

  

针对于此，绿盟云政务安全设计遵循以合规性原则为核心、以安全资源池化为基础、以运营管理为手段、多层面保护租户安全，贯穿政务云业务安全全流程。

  

绿盟云安全事业部安全专家提出绿盟政务云整体方案：  

● 基础设施层——防护区部署安全硬件设备，包括下一代防火墙、抗拒绝服务、流量监测分析、入侵检测防护、远程安全评估系统、堡垒机等，保护云平台和边界。

● 虚拟化云平台层——安全资源池，保护云内的虚拟化层安全。采用虚拟化防火墙实现租户间或者虚机间的流量监控、数据隔离和防护；采用虚拟机版防病毒实现虚机的防病毒功能，同时采用EDR（终端检测与响应）实现主机入侵检测、恶意程序威胁、高级威胁攻击、虚机间的微隔离以及虚机上的基线配置检查等功能。  

● 政务云业务层——租户防护，本地安全资源池安全。通过提供运维审计、Web应用防护、抗DDOS、安全评估服务等对租户进行防护。安全资源池是政务云安全建设的核心方案，是保证云上不同政务服务和政务系统安全的关键。通过安全资源池的编排和整合能力，为云上系统提供一体化的防护能力，满足安全等保合规要求。

● 安全运营层——基于大数据进行安全能力的建设，针对安全实践的智能化处置与响应，帮助客户建立安全运营体系闭环。  

  

**企业安全运营：安全运营＋**

  

绿盟云安全事业部安全专家提出，与传统安全产品与服务不同，体系化的安全运营解决方案根据客户自身需求与现状进行客户安全运营体系咨询、评估与设计，通过整合安全平台与设备、安全运维、专业安全服务及安全管理支撑服务的一体化安全运营服务落地。绿盟一体化运营服务集威胁情报、大数据分析平台与技术、威胁和漏洞管理、安全专家与人才储备积累等优势于一身，率先提出了绿盟科技“安全运营+”体系。  

  

![](../Images/edcfcd8efa713959d28ac018beaa5a14.png)

  

**"体检-治病-预防-急救"**

  

针对政府和企业网站的安全需求，过去的做法是部署硬件扫描器、Web应用防火墙、本地网站监测设备， 这只是技术与产品的简单堆叠；同时要求网站管理者要学会看懂漏洞报告、配置防护策略、各厂商设备的运维等技能，门槛高、设备误报和漏报多。  

  

![](../Images/c4c393bd34425854f9a0adc593d6ed67.png)

  

绿盟云安全事业部安全专家介绍到，绿盟网站安全SaaS解决方案能够实现无硬件部署即可实现云端扫描、云端监测、云端防护、云端平台；简单易用，具有漏洞自动验证、零误报，安全事件人工确认、网站一键下线、一键对比检测、永久在线、扫描IP自动封禁、移动端/PC端全覆盖等优势；高效运营，支持漏洞人工验证，最快24小时检测封堵0Day漏洞，网站篡改应急响应，重保期间1vs1应急响应等，真正实现了以解决问题为中心的"体检-治病-预防-急救"的一体化运营流程。
