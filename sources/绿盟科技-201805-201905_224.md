# 权威机构最新报告显示绿盟科技是Web应用安全市场“领导者”

喜讯

近日，国际知名权威咨询机构IDC发布了《中国Web应用安全看法，2018》报告，报告从能力和未来发展机会两个维度对厂商进行评估，绿盟科技成为领导厂商象限首位。

  

![](../Images/d0b8a3003c4a3b07028b43f38c566e48.png)

  

报告指出，绿盟科技凭借成熟的技术与多年的市场积累获得客户的广泛认可，推出Web 应用安全相关的硬件、虚拟化软件、SaaS 模式的解决方案。采用了行为分析算法对规则无法覆盖的技术领域进行覆盖，并基于海量的入网设备和其分布全球的蜜罐系统，在云端训练基于机器学习的智能检测引擎，并按版本更新至设备中，降低误报、漏报率。在市场竞争性及成长性方面表现优异。

  

绿盟科技作为国内优秀的Web应用安全产品提供商，目前已可以为客户提供整套成熟的解决方案：

  

1  

事前绿盟漏扫来协助，防患于未然

绿盟Web应用漏洞扫描系统（WVSS）是基于绿盟科技多年对WEB应用安全的研究与积累研发的产品。自上市以来，将不断的创新型技术及对用户的使用需求了解快速转化为产品能力，受到了用户的一致认可与好评。

  

  

2

事中WAF来护航，实时阻断 Web 应用攻击威胁

绿盟全新一代WAF更加智能，在保留深耕多年的优秀算法和丰富规则外，引入基于机器学习算法的智能检测引擎，通过海量的攻击样本进行学习构建模型，从而大大降低纯规则检测机制下带来的漏报和误报情况。

 

同时绿盟提供基于SaaS模式的“云WAF”交付及防护解决方案，绿盟网站云防护服务把传统硬件WAF的能力集成在云端，通过云服务（SaaS）的方式提供给客户，客户网站只需要修改DNS解析地址即可使用到全面Web安全防护。同时，服务化后的云WAF不再需要客户去维护和配置设备，服务完成站点的策略配置、故障迁移、规则升级等运维工作，极大降低了客户的使用门槛和运维成本。

  

3

事后网站监测来取证，提供及时告警与事后报告

针对网站的脆弱性、完整性、可用性以及认证（如网站挂马、篡改、钓鱼等）提供7\*24小时的检测服务，及时发现网站风险状况，并提供专业的安全建议，定期提供的综合评估报告，让用户对网站的风险状况及安全趋势有整体掌握。

  

    ·  关于IDC ·    

国际数据公司（IDC）是在信息技术、电信行业和消费科技领域，全球领先的专业的市场调查、咨询服务及会展活动提供商。IDC 帮助IT 专业人士、业务主管和投资机构制定以事实为基础的技术采购决策和业务发展战略。IDC 在全球拥有超过1100 名分析师，他们针对110 多个国家的技术和行业发展机遇和趋势，提供全球化、区域性和本地化的专业意见。

  

在IDC 超过50 年的发展历史中，众多企业客户借助IDC 的战略分析实现了其关键业务目标。IDC 是IDG 旗下子公司，IDG 是全球领先的媒体出版、研究咨询以及活动策划公司。

  

  关于绿盟科技  

  

北京神州绿盟信息安全科技股份有限公司（简称绿盟科技）成立于2000年4月，总部位于北京。在国内外设有30多个分支机构，为政府、运营商、金融、能源、互联网以及教育、医疗等行业用户，提供具有核心竞争力的安全产品及解决方案，帮助客户实现业务的安全顺畅运行。

  

基于多年的安全攻防研究，绿盟科技在网络及终端安全、互联网基础安全、合规及安全管理等领域，为客户提供入侵检测/防护、抗拒绝服务攻击、远程安全评估以及Web安全防护等产品以及专业安全服务。

  

北京神州绿盟信息安全科技股份有限公司于2014年1月29日起在深圳证券交易所创业板上市交易，股票简称：绿盟科技，股票代码：300369。
