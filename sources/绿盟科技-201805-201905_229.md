# 绿盟科技WAF入围Gartner 2018 Web 应用防火墙魔力象限报告亚太版

喜讯

  

近期，国际权威咨询机构Gartner发布了2018 Web 应用防火墙魔力象限报告亚太版（下文简称亚太报告），绿盟科技WAF成功入选。同时，绿盟科技也是国内唯一一家厂商，连续4年（2014-2017）入选Gartner WAF魔力象限。

  

  

今年9月，Gartner一方面提高了WAF魔力象限的入围要求，象限厂商需要在其他大洲的销售额达到指定比例；另一方面，针对亚太地区的特殊性，推出了该份亚太报告，Gartner在报告中表示，亚太客户可以选用入围厂商，享受优质的Web安全防护能力以及更加舒适的本地支持服务和云服务节点。  

  

绿盟科技自发布WAF产品以来，不断更新迭代，从最开始提供传统硬件盒子，到如今的WAF虚拟化版本和云WAF的SaaS交付模式，以及基于机器学习算法，智能检测引擎的应用，不断坚持技术突破与创新，为客户提供可信赖的安全产品和服务。
