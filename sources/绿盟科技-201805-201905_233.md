# 绿盟科技鼎力支持第五届电信和互联网行业网络安全技能竞赛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650394096&idx=1&sn=33f2b76697aa96a2469885ed8ac3b274&chksm=beca945b89bd1d4db78ae7a2aeadea6b033951c85ce54d3682335199120ed58eec95b19ec2c5&scene=126&sessionid=1681372495#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650394096&idx=1&sn=33f2b76697aa96a2469885ed8ac3b274&chksm=beca945b89bd1d4db78ae7a2aeadea6b033951c85ce54d3682335199120ed58eec95b19ec2c5&scene=126&sessionid=1681372495#rd)

![](../Images/efd867454a274c5816f185506d3351b2.png)

  

经过两天激烈的角逐，由中国通信企业协会主办，中国通信企业协会通信网络安全专业委员会承办的“第五届电信和互联网行业网络安全技能竞赛”于12月6日在京圆满落幕。  

  

绿盟科技依靠过硬的技术、产品和丰富的网络攻防赛事服务经验，在2012年、2016年、2017年和2018年四次为大赛提供技术支持。

  

激烈的比赛之余，绿盟科技为电信和互联网行业的领导和到场人员带来了绿盟科技全流量威胁分析系统和绿盟科技物联网安全解决方案。  

  

![](../Images/67e5776a676068fe583995145629b54e.png)

中国通信企业协会副秘书长柏国林莅临展位

  

绿盟科技参与了团队赛、个人赛和安全卫士精英赛的比拼，NSCTF-NULL战队获得优秀团体一等奖和安全卫士精英奖，NSCTF-P4战队获得优秀团体二等奖，一位选手获得技术能手一等奖，两位选手获得了技术能手二等奖。

  

![](../Images/aeeb1e6891db99f988275d344bb7f39c.png)

  

![](../Images/979dce489daf40c3b586a418a51238eb.png)  

  
![](../Images/f15b3f75ef00c19e3ecd4d4d9fa78594.png)  

在信息化的快速发展下，网络安全的边界在不断改变，国家对网络安全的重视程度也在逐年提高。第五届电信和互联网行业网络安全技能竞赛的举办，旨在提高网络安全技术人员在安全技能和团队协作方面的综合素质。绿盟科技将一直以“巨人背后的专家”为使命，在信息安全领域持续发力，深入研究攻防对抗能力，积极探索安全防护技术，促进安全产品和服务模式创新，也将为培养行业技术人才贡献绿盟力量！  

  

历届回顾

2012

![](../Images/f0e99b9b093803375ca55fe7d5730799.png)

早在2012年，绿盟科技就与主办单位合办了“绿盟杯”通信网络安全知识技能竞赛。

2016

![](../Images/1fb9cd8246169bdd587cf3167f30206c.png)

第四届通信网络安全知识技能竞赛在西安举办，绿盟科技第二次为大赛提供技术支持，全程提供比赛系统和硬件设备、技术支持和运维响应。

2017

![](../Images/96a53b67778cdd1bd9fbffff4ca4e45b.png)

第二届通信网络安全管理员技能大赛在京举行，绿盟科技作为赛事综合支撑单位，全程提供技术支持。

2018

![](../Images/da647652c4fbd1f88eaf12057db033a1.png)

2018年迎来了第五届电信和互联网行业网络安全技能竞赛，大赛共汇集了来自全国的55支队伍，165名选手参赛。绿盟科技依然作为技术支持单位，深度参与该项赛事，保障大赛的顺利进行。
