焦点漏洞

  • Apache Hadoop 权限提升安全漏洞（CVE-2018-11766）

  • CVE ID：CVE-2018-11766

  • NSFOCUS ID：42041


02

受影响版本 


  • Apache Hadoop 2.7.4版本至2.7.6版本


03

漏洞点评

Apache Hadoop是一套开源的分布式系统基础架构，它能够对大量数据进行分布式处理。Apache Hadoop 2.7.4版本至2.7.6版本在实现中存在安全漏洞。攻击者可利用该漏洞以root权限执行任意命令。目前厂商已经发布了升级补丁以修复这个安全问题，请到厂商的主页下载。

标题：路由器漏洞频发，Mirai新变种来袭

时间：2018-11-30

简介：近期发现一款攻击路由器的蠕虫病毒，经过分析，认定此款蠕虫是 mirai 病毒的新变种，和之前的 mirai 病毒不同，该蠕虫不仅仅通过初代 mirai 使用的 telnent 爆破进行攻击，更多通过路由器漏洞进行攻击传播。

链接：

https://www.freebuf.com/articles/terminal/190554.html


标题：Emotet在黑色星期五期间攻击活动

时间：2018-11-26

简介：在黑色星期五Emotet进行了大规模的攻击活动并且新增了一个攻击载荷Gootkit银行木马。在黑色星期五高峰期之后Emotet仍在高度活跃。在黑色星期五期间发送的钓鱼邮件附件和链接中带有误导性的.doc扩展名的XML文件，而不是利用先前发现的PDF和DOC文件。下发的银行木马包括Ursnif，TrickBot和最常见的IcedId。受影响最大的是拉丁美洲，墨西哥、厄尔瓜多和阿根廷尤甚，前十的受害者中还包括美国，英国和南非。

链接：

https://www.welivesecurity.com/2018/11/23/black-friday-special-emotet-filling-inboxes-infected-xml-macros/


标题：2018年77％的组织遭受DNS攻击

时间：2018-11-27

简介：DNS-DHCP-IPAM供应商EfficientIP发布了《全球 DNS 威胁报告 2018》白皮书，报告指出，2018 年有77％的组织至少经历过一次基于DNS的网络攻击。在全球组织经历的五大基于 DNS 的攻击中，基于 DNS 的恶意软件和钓鱼占据了绝大比例，锁定、DNS 隧道与 DNS DDoS 攻击比例则相当。相比 2017 年，2018 年 DNS 攻击的损失率增加了 57％，平均损失从 456000 美元增加到了 715000 美元。

链接：

http://www.efficientip.com/resources/dns-security-survey-2018/


标题：优步被英国和荷兰处以100多万美元罚款

时间：2018-11-27

简介：Uber近日被英国和荷兰当局罚款117万美元，原因是该公司在2016年的一次数据泄露事件中暴露了数百万客户的个人信息。英国信息专员办公室（ICO）对决定对Uber公司处以38.5万英镑（合计约490760美元）的罚款，而荷兰数据保护机构（DPA）则决定对其处以60万欧元（合计约678780美元）的罚款。2016 年 Uber 数据泄露事件影响到全球5700万用户，其中包括270万名英国用户和17.4万名荷兰用户。被盗数据包括客户和司机的姓名、电子邮件地址和电话号码。

链接：

https://thehackernews.com/2018/11/uber-data-breach-fine.html


标题：全新的工业间谍活动利用基于AutoCAD的恶意软件

时间：2018-11-28

简介：安全研究人员发现了一个针对使用AutoCAD的公司恶意软件分发活动，该恶意活动主要对工业领域，利用AutoCAD作为感染媒介，攻击者成功地针对处于不同地理位置的多家公司进行了攻击，其中至少有一项活动可能专注于能源行业。

链接：

https://www.zdnet.com/article/new-industrial-espionage-campaign-leverages-autocad-based-malware/


标题：因发生未授权的网络活动，戴尔为所有Dell.com用户重置密码

时间：2018-11-28

简介：戴尔披露了11月发生的一次网络攻击，并重置了所有客户的密码，作为事件发生后的预防措施。戴尔表示发现并阻止了其网络上试图提取戴尔客户信息的未经授权活动，这些信息仅限于姓名、电子邮件地址和散列密码。戴尔没有发现客户信息从服务器中被窃取的任何证据，但该公司确实承认发生这种情况的可能性。

链接：

https://threatpost.com/dell-warns-of-attempted-breach-on-network/139464/
