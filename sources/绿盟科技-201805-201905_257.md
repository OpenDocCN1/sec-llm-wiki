# 细数|这些年分析机构为绿盟科技盖过的戳儿

不知不觉，距离2018年结束只剩下 **30**个工作日。想想距离年初定下的小目标是更近了，还是更远了呢？

![](../Images/c241f857a17733f0e9ccddba98e90c54.png)

回首一年，绿盟科技在技术研究、产品创新等领域取得了很大的收获，受到了业界及国内外用户的高度赞誉。下面，就让绿盟君为您盘点一下这些年IDC、Gartner、Frost&Sullivan为绿盟科技盖过的那些戳儿。

  

绿盟远程安全评估系统（RSAS)

2014-2015年，**连续2年**入选Gartner漏洞评估市场报告。

  

2011-2017年，**连续7年**安全性与漏洞管理软件市场份额**第一**（数据来源：IDC）。

  

2017年，绿盟RSAS的市场份额为**24.8%**。 

![](../Images/ce5e186649d4c0607309418169fa7244.png)![](../Images/5cff37f8aae8572d3480f703d39bb1e8.png)

  

绿盟WEB应用防火墙（WAF）

2014-2017年，**连续4年**入选Gartner WAF魔力象限。

![](../Images/8d90d2886796db60be44d4be43168329.png)![](../Images/5cff37f8aae8572d3480f703d39bb1e8.png)

2010-2017年，**连续8年**中国地区Web应用防火墙市场份额**第一**（Frost&Sullivan 市场报告）。

  

2017年，绿盟科技WAF产品的市场份额为**20.1%**。

![](../Images/b7f714109db09b6dc07310ea9b86de35.png)![](../Images/5cff37f8aae8572d3480f703d39bb1e8.png)

  

绿盟抗拒绝服务系统（ADS）

2014年，入选Gartner市场报告。

  

2014-2017年，**连续4年**中国地区分布式拒绝服务攻击市场份额**第一**（Frost&Sullivan 的市场报告）。

  

2017年，绿盟ADS的市场份额为**23.2%**。

![](../Images/0b8b8904c90edf02d6a971a3311b022d.png)![](../Images/5cff37f8aae8572d3480f703d39bb1e8.png)

  

绿盟网络入侵防护系统(NIPS)

2012-2018年，**连续6次**入选Gartner魔力象限。

![](../Images/6ff9a6741cc8eeeb71cb0212111eefce.png)![](../Images/5cff37f8aae8572d3480f703d39bb1e8.png)

2009-2015年，**连续7年**入侵防护市场份额第一（数据来源：IDC）。

  

*2016年后，入侵防护与入侵检测市场合并，绿盟在合并后的入侵检测和防护市场份额位列第二。*

![](../Images/bad471cb6e10fc62ca6d5b7ce09ed720.png)

数据是过去市场反馈与产品实力的见证。面向未来，绿盟科技也将继续以“巨人背后的安全专家，保障客户业务顺畅运行”为使命，不懈前行，以更可靠的产品技术、更有效的解决方案服务客户，建立有效的防御机制，与客户共同应对未来多样化、复杂化的安全威胁。
