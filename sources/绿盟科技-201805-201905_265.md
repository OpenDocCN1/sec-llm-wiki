# 绿盟科技亮相大数据和实体经济深度融合大会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650393803&idx=1&sn=b778b8651bb2a6a0b0b32bc09d8ff5ba&chksm=beca956089bd1c76cac11c24dbb061b154d1e478c3062c6c6d8bea0e18a56e97eba3d34e4c98&scene=126&sessionid=1681372499#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650393803&idx=1&sn=b778b8651bb2a6a0b0b32bc09d8ff5ba&chksm=beca956089bd1c76cac11c24dbb061b154d1e478c3062c6c6d8bea0e18a56e97eba3d34e4c98&scene=126&sessionid=1681372499#rd)

2018年11月14-15日，大数据和实体经济深度融合大会在南通市召开，会议由江苏省工业和信息化厅和南通市人民政府主办，国家工业信息安全发展研究中心、南通市经济和信息化委员会、南通市经济技术开发区管理委员会承办，以“大数据和实体经济深度融合”为主题，旨在推动实施国家大数据战略，落实《促进大数据发展行动纲要》和《大数据产业发展规划（2016-2020年）》。

  

工业和信息化部、地方工信部门领导，大数据领域知名院士专家以及入围2018大数据产业发展试点示范项目的企业代表参加了本次大会。

  

绿盟科技为唯一的网络安全企业受邀参会。绿盟科技副总裁宫智在会上发表了题为“工业大数据时代的安全思考与实践”的主旨演讲。

  

![](../Images/6b8d76e8e4112fe9f51f3047abe7a1a1.png)

图1. 绿盟科技副总裁宫智发表主题演讲

 

宫智从当下工业大数据的发展以及安全态势分析入手，**从6个方面提出了构建工业大数据闭环安全能力基础要素，**包括安全方案设计阶段的安全构建、上线前的安全检测、运营中的安全能力、协同安全能力、业务融合的安全赋能、有效的人员安全能力基线的构建等。通过对数据的有效挖掘，在业务中感知安全，从安全中协助业务发展，实现基于安全的综合业务诊断分析，基于工业安全大数据分析平台综合性的提升工业系统的运行能力。平台主要从数据采集、数据感知、数据计算和存储、业务与安全分析来可视化的展示业务与安全的融合。

![](../Images/31399b954180208524626d4e8a9e9e5d.png)

图2. 绿盟科技工业安全大数据分析平台

在工业和信息化部组织开展的2018年大数据产业发展试点示范项目评审中，**绿盟科技“工业大数据安全监测预警平台研制及应用推广”成功入选“大数据安全保障方向“相关项目**。

  

绿盟科技工业大数据安全监测预警平台，已经成功应用于政府与企业用户的安全运营当中，覆盖电力、能源、烟草、市政、制造业等多个行业。平台为工控系统的安全防护、生产系统的安全防护提供了体系化的安全解决方案；为企业建立完善的工业大数据安全防护体系，防患于未然。
