# 【预警通告】Cisco Stealthwatch管理控制台验证绕过和Unity Express任意命令执行高危漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650393736&idx=2&sn=920283ca3c33631bc3d6f7d9ebf356f2&chksm=beca952389bd1c3521e892f9c8decc5015712c65d95b073fc6b79243e2228ddaccf8764ca48f&scene=126&sessionid=1681372499#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650393736&idx=2&sn=920283ca3c33631bc3d6f7d9ebf356f2&chksm=beca952389bd1c3521e892f9c8decc5015712c65d95b073fc6b79243e2228ddaccf8764ca48f&scene=126&sessionid=1681372499#rd)

当地时间11月7日，Cisco官方发布安全通告称修复了Stealthwatch  Management  Console 以及 Unity Express 的2个高危漏洞。

  

**Stealthwatch Management Console Authentication Bypass**

  

*   CVE-2018-15394
    
*   CVSS 3.0: 9.8
    
*   AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:X/RL:X/RC:X
    
      
    

该漏洞源于系统配置存在隐患，一个未授权的攻击者可以远程绕过验证流程，从而受影响的系统上以管理员身份执行代码。

  

**受影响的版本：**

Cisco Stealthwatch Enterprise releases  <= 6.10.2

  

**不受影响的版本：**

Cisco Stealthwatch Enterprise releases  6.10.3

  

**解决方案：**

Cisco官方已经发布了新版本修复了上述漏洞，受影响的用户可以在登录后访问

*https://stealthwatch.flexnetoperations.com/*进行更新。

  

更多信息请参考官方通告：

*https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181107-smc-auth-bypass*

  
     

  

**Cisco Unity Express Arbitrary Command Execution**

  

*   CVE-2018-15381  
    
*   CVSS 3.0：9.8
    
*   AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H/E:X/RL:X/RC:X  
    

  

该漏洞源于对用户提供的内容进行反序列化操作是没有进行足够的过滤。攻击者可以向受影响的系统RMI服务发送一个恶意的java序列化对象来触发该漏洞，从而以root权限执行任意shell命令。

  

**受影响的版本：**

Cisco Unity Express release < 9.0.6

  

**不受影响的版本：**

Cisco Unity Express release 9.0.6

  

**解决方案：**

Cisco官方已经发布了新版本修复了上述漏洞，受影响的用户可以在登录后访问

*https://software.cisco.com/download/navigator.html*进行更新。

更多信息请参考官方通告

  

参考链接：

*https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20181107-cue*
