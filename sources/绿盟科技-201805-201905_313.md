# 战略合作 | 绿盟科技携手西北工业大学，聚焦网络空间安全创新研究

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650393367&idx=1&sn=be4b065e02804619f3c0703f9340c03d&chksm=beca92bc89bd1baa8e6e5d2053361d26c1c60daa9e3aa3dd2427005c954478fa62be5415e2b3&scene=126&sessionid=1681372502#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650393367&idx=1&sn=be4b065e02804619f3c0703f9340c03d&chksm=beca92bc89bd1baa8e6e5d2053361d26c1c60daa9e3aa3dd2427005c954478fa62be5415e2b3&scene=126&sessionid=1681372502#rd)

![](../Images/efd867454a274c5816f185506d3351b2.png)

  

2018年10月11日，第二届中国（西安）网络创新发展论坛暨西北工业大学网络安全学院成立大会，在西北工业大学友谊校区隆重召开。绿盟科技受邀参与本次活动，并与西北工业大学强强联合，通过共建网安学院、信息安全联合实验室等方式，就网络空间安全领域的人才培养、技术研发等展开战略合作。中国工程院院士倪光南、陕西省委网信办主任鲍永能、西北工业大学党委书记张炜、西北工业大学网络空间安全学院院长张艳宁、绿盟科技副总裁李晨等领导参加了本次签约仪式。  

   

![](../Images/d187c529117b31cc00b7ad8b1eddb955.png)

  

随着国家网络强国战略的深入贯彻与实施，网安产业正处于全面发展阶段，但随之而来的人才短缺问题，也逐渐制约着行业的发展。绿盟科技作为国内最早从事网络安全业务的企业之一，始终致力于网络安全产业的发展，特别是网安人才的培养。本次的战略合作立足于国家战略需要，依托西北工业大学多学科交叉融合，以及绿盟科技在技术、市场方面的优势。双方将通过共建网络空间安全人才培养基地、博士后工作站等多种方式，加快推动高水平成果转化，促进人才培养与产业发展的深度融合。

  

![](../Images/f147fdb6afc851bb91c5a78382684b8a.png)

**绿盟科技与西北工业大学签署战略协议**

 

![](../Images/bc9e54f1b3a581ad219dee8351aae0cd.png)

**西北工业大学网络空间安全学院成立仪式**

  

近年来，绿盟科技在网安人才培养、产学研融合等方面不断探索，并取得了一定的成果。通过面向合作学校，推广网络空间安全技术、建立网络空间安全教育基地、开展网络空间安全师资培训、导入网络空间安全课程资源、协同开展网络空间安全人才培训与认证等方式，营建网络空间安全领域产教融合生态体系。还通过与高校实现信息、资源贡献，让学生在校所学与企业实践有机结合，实现优势互补。不仅如此，绿盟科技还与中国计算机学会(CCF)联合发布“鲲鹏”科研基金，为推动高校与外部优秀研发团队科研技术的成果转化提供研究支持。

  

“ 

会上，绿盟科技副总裁李晨就网络安全行业的创新发展研究与观察进行了分享。他指出，由于产业环境的变化，出现了很多新技术和与之对应的新威胁，安全建设不能依靠单点防御的升级，而是需要依赖复杂环境下攻防能力、数据分析能力，并在这些能力的基础上建立协同运营的体系。此次和西工大合作将进一步加快人才培养步伐、促进高水平研究和相关成果的转化。

”![](../Images/185bba975b0b52b7a20200beeda59ceb.png)

**绿盟科技副总裁李晨分享网安行业创新与发展趋势**

  

未来，绿盟科技仍将扎根教育行业，以自身技术为依托，通过与高校开展技术合作、为高校提供完善的实践平台等方式，加大对人才培养与产学研融合的投入力度，为我国网安产业的发展贡献自己的力量。
