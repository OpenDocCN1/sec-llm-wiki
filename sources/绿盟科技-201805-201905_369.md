# AE50网络安全产学研合作协同育人联席会 绿盟推动产教融合新进程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650392992&idx=1&sn=bd12c6994edcc4d20786a619ca61be11&chksm=beca900b89bd191d389b6645de6df92b9cd8202992c28d3b4412397e5d9744c3c64fd3ac96e7&scene=126&sessionid=1681372508#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650392992&idx=1&sn=bd12c6994edcc4d20786a619ca61be11&chksm=beca900b89bd191d389b6645de6df92b9cd8202992c28d3b4412397e5d9744c3c64fd3ac96e7&scene=126&sessionid=1681372508#rd)

![](../Images/efd867454a274c5816f185506d3351b2.png)

**绿盟科技**

8月28日，以“安全强驱动，数字新生态”为主题的第四届互联网安全领袖峰会在京举办。峰会特设“AE50安全产学研论坛”，由绿盟科技与腾讯安全联合主办，会上同期**举办AE50网络安全产学研合作协同育人联席会发布仪式**，旨在搭建中国信息安全人才培养体系，切实推动产学研深度融合。

![](../Images/0f2578904044a65e516f165d7a34d10c.png)

会议伊始，教育部信息安全教指委秘书长封化民发表致辞。

![](../Images/ea8c2b94fd15bd6b05d94a880c7c0dde.png)

教育部信息安全教指委秘书长封化民

他表示，2017年中央网信办提出了关于加强网络安全学科建设和人才培养的意见，对高校建设一流网络安全学院提供了政策支持和制度保障。此次搭建AE50网络安全产学研合作协同育人联席会这样的平台，组织召开联席会议，更有利于汇聚各方人才培养经验，进行深入交流，探寻产学研深度融合方式。

![](../Images/9ac893e1a7632930e8fdb842946ce8e8.png)

绿盟科技高级副总裁崔培升

绿盟科技高级副总裁崔培升也在致辞中表示，在产学研融合发展初级阶段，即产学研融合1.0时代，主要以教育教学、生产劳动、素质养成、技能历练、社会服务于一体，以行业为导向，培养具有创新能力的应用型技术人才。但也面临着企业内驱力不强，校企合作多流于形式，缺乏长期保障与规划，不具备可持续发展性等问题。本次绿盟科技与腾讯安全携手搭建“AE50产学研合作协同育人联席会“，将开启产学研融合2.0时代。

 

本次AE50安全产学研论坛是由教育部高等学校网络安全教育指导委员会指导，绿盟科技、腾讯安全共同发起。邀请7所首批网络安全学院建设示范院校以及22所首批网络空间安全一级学科示范院校一起，未来还将邀请50+网络安全学院加入。聚焦安全人才培养，推动科研成果产业转化、提升网络空间安全水平。论坛上，同期举行了AE50网络安全产学研合作协同育人联席会成立仪式。

![](../Images/c4fd739d2e6f58820b37840ce746e279.png)

教育部信息安全教指委秘书长封化民，国家网络安全人才与创新基地副主任朱江涛，腾讯高级副总裁丁珂，绿盟科技副总裁李晨参与发布仪式，共同开启以“产学研结合共建人才培养新体系”为基的产学研融合新进程。

![](../Images/d81399bdc378df492a1a80aa60a8839c.png)

北京航空航天大学网络空间安全学院院长兼党委书记刘建伟

![](../Images/a0ce2c7d41343d1cba0721c8dedab40f.png)

西安电子科技大学网络与信息安全学院网络工程系主任杨超

![](../Images/92a57ace3f8f1d8b5b1c028be71e5a36.png)

武汉大学国家网络安全学院副院长赵波

北京航空航天大学网络空间安全学院院长兼党委书记刘建伟，西安电子科技大学网络与信息安全学院网络工程系主任杨超，武汉大学国家网络安全学院副院长赵波分别就三大高校为加强产学研融合，建设一流网络安全学院所做的工作进行了分享。

![](../Images/a3a1335787608077d69df2ffab00d7fe.png)

国家网络安全人才与创新基地建设办公室副主任朱江涛

国家网络安全人才与创新基地建设办公室副主任朱江涛也以国家安全人才培养工作规划为主题为与会嘉宾带来了精彩演讲。

 

此外，绿盟科技副总裁李晨出席“安全产学研问道”圆桌论坛，就建设中国信息安全人才培养体系、推动科研成果产业转化、提升中国网络空间安全水平及企业的社会责任等话题与在座的各位专家进行了深入探讨。

![](../Images/067a8014cb145d13b0730b0d73ad38f4.png)

  

绿盟科技近年来重点发力网安学科建设及人才培养。先后与多所高校进行深度合作，联合成立了高校安全应急响应中心和安全实验室，通过共同开发网络空间安全课程、对网络空间安全课题进行研究等，助力国家产学研人才培养。此次，为促进政府、学校、企业之间的产学研融合，校企合作，全面升级教育行业服务，绿盟科技积极推进联席会平台建设，将覆盖基地建设、师资培训、课程开发、培训认证、信安竞赛、科创服务、就业创业、学术交流、技术推广等项目，助推产学研融合生态圈的健康发展。

 

未来，绿盟科技期待有更多有志于网络安全人才培养和产学研合作协同的高等院校、科研机构和企事业单位加入AE50网络安全产学研合作协同育人联席会，为我国产学研事业健康持续发展及网络空间安全水平提升做出贡献！
