# 我们来了！绿盟亮相2018中国网络安全年会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650392852&idx=1&sn=d83c283eb4d861ee62e409ee8783383d&chksm=beca90bf89bd19a93f252d6b8eb388ec163f7c791601914b57b29ddc9c1fb99b67da36b07610&scene=126&sessionid=1681372510#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650392852&idx=1&sn=d83c283eb4d861ee62e409ee8783383d&chksm=beca90bf89bd19a93f252d6b8eb388ec163f7c791601914b57b29ddc9c1fb99b67da36b07610&scene=126&sessionid=1681372510#rd)

![](../Images/efd867454a274c5816f185506d3351b2.png)

2018年8月14日，由国家计算机网络应急技术处理协调中心(CNCERT/CC)主办的第15届中国网络安全年会在北京国际会议中心隆重召开。绿盟科技受邀参加，并将在8月16日的应急响应分论坛、威胁情报分论坛、物联网分论坛上分别带来《基于容器技术的安全机制重构》、《威胁聚焦和安全运营》、《物联网情报修炼X-I》的主题演讲。

![](../Images/56aa6d8fe9259e33816aacc325344bc1.png)

![](../Images/8e8410205f2171ed19a4ec4471abfa03.png)

本次会议作为国内网络安全“用、产、学、研”各界技术和业务交流的重要桥梁和纽带，以“融合促进发展 协作共建安全”为主题，旨在交流国内外网络安全工作新趋势、新问题、新思路，促进国家公共互联网网络安全应急体系成员间的合作，加强互联网行业的网络安全保障和突发安全事件的应急处置联动，促进政府部门、重要信息系统单位与网络安全产业界间的交流，普及宣传网络安全及网络安全应急工作知识，提升社会网络安全意识。

  

当前，人类的生产生活已经和网络密不可分，维护网络安全是国际社会共同的课题。随着我国数字经济进入快车道和高速发展期，全球视野下的互联网已经进入了“大安全”时代，这就需要国家层面的大战略以及安全行业协同合作的支持。绿盟科技作为中国信息安全行业领军企业，多年来专注于网络安全事业。面对严峻的网络安全形势，绿盟科技逐步由传统产品模式向安全解决方案+安全运营模式转型，安全防御体系也从静态、被动、基于规则的防御，转变为主动、动态、自适应的弹性防御体系。  

 

绿盟科技将携各行业信息安全防护及解决方案亮相大会现场，向参展嘉宾展示公司近年来在政府、金融、运营商、卫生医疗、教育等行业取得的优异成绩，并准备了绿盟自制安全意识漫画，旨在普及信息安全知识，提升大众网络安全意识。
