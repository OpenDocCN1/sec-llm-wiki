**◆ 漏洞点评 **  

北京时间7月18日凌晨，Oracle官方发布了季度补丁更新，其中修复了一个 Oracle WebLogic Server 任意文件上传漏洞CVE-2018-2894。通过此漏洞攻击者可以在未经身份验证的情况下对WebLogic进行攻击，目前相关PoC已经公开，建议相关用户尽快进行安全升级。
