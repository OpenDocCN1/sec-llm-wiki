# 绿盟科技科研成果亮相国际核心期刊与学术会议

近日，绿盟科技星云实验室负责人刘文懋博士、天枢实验室顾杜娟博士和伏影实验室负责人吴铁军的安全研究类论文收到期刊和会议的录取通知，受到全球权威学术界的认可，为绿盟科技享誉海内外的安全研究能力添砖加瓦。

  

  

***No.1***

**云计算领域的国际学术期刊《IEEE Transactions on Cloud Computing》**

基于绿盟科技“鲲鹏”基金校企合作的研究成果，星云实验室负责人刘文懋博士与华中科技大学谢雨来老师联合发布名为《Real-time Prediction of Docker Container Resource Load Based on A Hybrid Model of ARIMA and Triple Exponential Smoothing》的论文收录于云计算领域的国际学术期刊《IEEE Transactions on Cloud Computing》，该期刊提供有关云计算所有领域的创新研究思路和应用成果。主题聚焦于新颖理论、算法、性能分析等与云计算领域相关的技术应用。截止目前，中国科学院官方文献中心认证该期刊为SCI期刊。

  

***No.2***

**SCI期刊《Computer Communications》**

天枢实验室顾杜娟博士与清华大学、中国科学院大学的老师们联合发布名为《Modeling IPv6 Adoption from Biological Evolution》的论文收录于SCI期刊《Computer Communications》。该期刊聚焦于计算机和电信技术领域的实际发展，发表数据通信相关的研究类和应用类论文及案例。截止目前，中国科学院官方文献中心认证该期刊为SCI期刊。

  

***No.3***

**IEEE Cyber Science 2020 Conference**

伏影实验室负责人吴铁军与英国圣安德鲁斯大学王蕴佳博士共发表两篇论文，分别为《Cost Effective OCR Implementation to Prevent Phishing on Mobile Platforms》 和《ISP Hijacking Protection via DOM Tree Comparison》，两篇文章均被IEEE Cyber Science 2020 Conference录取。

  

Cyber Science会议是由IEEE发起的多学科研究、创新与合作中心（C-MRiC）的旗舰会议，着力于网络态势感知、社交媒体、网络安全和网络事件响应方面的开拓性研究和创新。2020年，Cyber Science会议将在爱尔兰的都柏林城市大学举行。疫情原因，Cyber Science会议已经改为云端会议，届时将对两篇论文进行精彩讲解。
