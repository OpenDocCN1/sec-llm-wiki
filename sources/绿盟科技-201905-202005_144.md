# 【威胁通告】Google Chrome发布更新修复0day漏洞（CVE-2020-6418）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650400730&idx=2&sn=6417e45494c83431aa46e6078d0dbe44&chksm=becabe7189bd37678287abdafe6483687484e7b047f20efbbcf66f161e393068937afc5884f6&scene=126&sessionid=1681372439#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650400730&idx=2&sn=6417e45494c83431aa46e6078d0dbe44&chksm=becabe7189bd37678287abdafe6483687484e7b047f20efbbcf66f161e393068937afc5884f6&scene=126&sessionid=1681372439#rd)

01  

**综述**

当地时间 2月24日，Google 针对桌面版Chrome浏览器发布更新以解决多个漏洞，其中包括已被发现在野利用的高危漏洞CVE-2020-6418。

  

完整信息请查看官方通告：

https://chromereleases.googleblog.com/2020/02/stable-channel-update-for-desktop\_24.html

  

02  

**影响范围**

  

  

受影响的版本

Google Chrome Version < 80.0.3987.122

  

  

不受影响的版本

Google Chrome Version = 80.0.3987.122

  

适用于Windows，Mac和Linux

  

03  

**解决方案**

官方已经发布新版本修复了该漏洞，请用户检查Google Chrome浏览器的当前版本，并尽快更新至80.0.3987.122或更高版本进行防护。
