# 绿盟科技业务安全网关喜获中国国际金融展“金鼎奖”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650400145&idx=2&sn=d33b03243e56bc78b22814c235b570e9&chksm=becabc3a89bd352c11b33848c7a8c676381143d6edc28afda18cee4e4907d18c352d1c9d21c0&scene=126&sessionid=1681372444#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650400145&idx=2&sn=d33b03243e56bc78b22814c235b570e9&chksm=becabc3a89bd352c11b33848c7a8c676381143d6edc28afda18cee4e4907d18c352d1c9d21c0&scene=126&sessionid=1681372444#rd)

2020年1月9日，中国国际金融展“金鼎奖”评选结果隆重揭晓。绿盟科技业务安全网关通过严格评审，荣获金鼎奖2019年度优秀金融科技解决方案奖。

  
  
![](../Images/fda1ea7cf2bfe91166f17aecdf3b807f.png)![](../Images/02c54d938afab161a916e652e1b0fe04.png)

绿盟科技业务安全网关

  

绿盟科技业务安全网关主要解决客户Web系统安全风险，对前端应用加固从源头减少Web攻击风险。防护自动化攻击，解决薅羊毛、恶意爬虫、撞库、隐私泄露等问题。提升Web网络安全的追踪溯源、API防护能力，隐藏漏洞阻挡潜在威胁。

![](../Images/0ed3a6578a7b6278fb8fc67eb62e6cfd.png)

  

  

**源头防控风险**

极大增加了分析破解难度，从源头减少风险。业务安全网关具备前端应用加固的功能，使网站无法被分析、调试、抓包、获取关键API接口。  

  

  

**自动化攻击防护**

有效防护恶意爬虫带来的非法查询、数据泄露，营销活动中薅羊毛、自动化抢券、抢票、刷票等欺诈行为，以及非法扫描带来的一系列安全风险。适用于网络查询平台、网络预约平台、政务平台、网上银行、信用卡中心等系统的自动化攻击防护。  

  

  

**网络安全防护能力提升**

攻击溯源和攻击者画像，能够通过设备指纹技术，代理IP发起的网络攻击、低频持续性网络攻击，识别攻击意图，还原攻击者作案手法，增强Web网络安全防护效果。智能监测API参数列表、调用频率，智能学习API参数范式防护参数篡改，强化API的管理和防护。

  

  
       

  

中国国际金融展作为金融开放创新成果的展示、交流、传播平台，历经27载发展,已成为展示中国金融发展成就、宣传金融改革成果、促进金融产业创新和推动金融信息化发展的有效平台，绿盟科技已连续三届参与中国国际金融展。

  

金鼎奖评选旨在表彰金融类优秀科技、产品、解决方案及服务，通过大力宣传推广参展单位的新技术、新产品、新服务模式，不断推动金融与科技深度融合，提升我国金融行业的综合管理和服务水平。

  

本次荣获的2019金鼎奖“年度优秀金融科技解决方案奖”，是绿盟科技近期获得的第二个金融领域重量级奖项，这无疑是金融行业对绿盟解决方案的高度认可。未来，绿盟科技将继续发挥自身技术实力和业务优势，以更加优质的安全产品、服务和解决方案为金融客户的发展提供坚实有力的信息安全保障。
