# 基于SOAR构建自动化闭环运营|绿盟科技亮相2019年中国金融业信息安全发展研讨会

11月19-20日，2019年中国金融业信息安全发展研讨会在北京举行。本次活动由《金融电子化》杂志社主办，以“保障金融网络安全 ，服务社会经济稳定”为主题，邀请网络安全主管部门、金融业监管部门领导，以及金融机构、学术组织专家，围绕“全面推进金融业关键基础设施保护”等话题进行研讨和交流，旨在推进行业网络安全水平整体提高。

![](../Images/0b7e66b6912a23ec50483f4498241b63.png)

**基于SOAR（安全编排与自动化响应）的安全运营新方向**

绿盟科技作为深耕金融行业多年的信息安全企业受邀出席本次会议，绿盟科技技术总监徐特发表题为《基于SOAR（安全编排与自动化响应）的安全运营新方向》的精彩演讲。

![](../Images/22cae2f24afff556d52148d2a6249750.png)

会上，徐特表示，随着安全设备、控制措施的持续增加，和大数据技术的不断发展，企业安全运营中心SOC处理的安全日志与数据与日俱增。根据今年的一项研究报告显示，70%的企业只能处理不超过60%的安全日志数据。在高对抗环境下，如何支撑对海量攻击行为进行处置成为新的难题。SOAR（安全编排与自动化响应）技术通过自动执行重复性任务，可以使分析人员将注意力更多放在关键任务，并通过整合现有的安全基础设施加强防御，使每个部分都成为积极的参与者。  

  

论坛同期，绿盟科技还在现场展示了绿盟智能安全运营平台（Intelligence Security Operation Platform，简称 NSFOCUS　iSOP）以及研究成果，赢得现场嘉宾的认可与关注。

![](../Images/1494ac37940e41c829361abc98ee7a16.png)![](../Images/9a600f378d48dfcafcdff894fbb4ea98.png)

绿盟科技专注金融行业的信息安全研究，持续跟踪信息安全发展趋势，不断洞察和深入分析银行、证券、保险及互联网金融等行业客户在信息安全方面所面临的信息安全风险和信息安全需求，在电子银行整体安全防护、移动金融交易安全、金融云安全建设与防护、网络安全保险等具体业务场景不断推出适应安全需求的产品和服务，并在企业安全度量、应用开发安全、企业员工内部安全意识教育等运维和管理方面提供相应服务，业务几乎涵盖金融客户数字化转型的全生命周期。未来，绿盟科技将继续以巨人背后的安全专家为使命，为金融客户的发展提供坚实有力的信息安全保障。
