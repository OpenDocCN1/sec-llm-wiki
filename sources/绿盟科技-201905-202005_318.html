【预警通告】Harbor访问控制绕过漏洞(CVE-2019-16919)

1

综述

近日，VMware 官方发布安全通告，修复了一个Harbor API中存在的漏洞（CVE-2019-16919）。成功利用该漏洞可以使攻击者在未授权的情况下push/pull/modify其他项目镜像。VMware已经发布补丁进行了修复。

CVSS 3.0评分：9.1

AV:N/AC:L/PR:H/UI:N/S:C/C:H/I:H/A:H


VMware 官方安全通告：

https://www.vmware.com/security/advisories/VMSA-2019-0016.html


2

受影响产品及版本


VMware Harbor Container Registry for PCF < 1.8.4

注：

VMware Cloud Foundation只有在开启了“Harbor Registry”后才受影响。



3

不受影响产品及版本


VMware Harbor Container Registry for PCF 1.8.4


4

安全建议


VMware 官方已发布相关版本修复了上述漏洞，建议用户前往以下地址下载更新进行防护。

VMware Harbor Container Registry for PCF 1.8.4 下载地址：https://network.pivotal.io/products/harbor-container-registry#/releases/484772

截止本通告发布时，官方还未发布VMware Cloud Foundation的补丁，用户可对以下VMware官方通告保持关注，在补丁发布后及时更新。

https://www.vmware.com/security/advisories/VMSA-2019-0016.html
