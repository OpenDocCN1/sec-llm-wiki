1

综述

近日，Ghostscript公布了一个 -dSAFER 沙箱绕过漏洞（CVE-2019-10216）。漏洞成因是Ghostscript中的.buildfont1在执行时没有正确地限制特权调用，导致攻击者可以通过创建一个特别设计的PostScript文件来利用该漏洞提升特权并访问限制区域之外的文件。

  

参考链接：

https://seclists.org/bugtraq/2019/Aug/16

  

  

2

影响范围

  

  

受影响的版本

Ghostscript commit 5b85ddd19a8420a1bd2d5529325be35d78e94234 之前版本。

  

http://git.ghostscript.com/?p=ghostpdl.git;a=commitdiff;h=5b85ddd19

  

  

 不受影响的版本

Ghostscript commit 5b85ddd19a8420a1bd2d5529325be35d78e94234 及之后版本。

  

3

解决方案

当前官方暂未发布修复该漏洞的 release 版本，不过在Ghostscript commit 5b85ddd19a8420a1bd2d5529325be35d78e94234 及之后版本中已修复了该漏洞，用户应尽快升级进行防护。

  

**缓解措施：**

用户可通过禁用Policy.xml中的ps、EPS、pdf及XPS编码器来实现对此漏洞的有效防护。以ImageMagick为例，修改其policy配置文件，默认路径/etc/ImageMagick/policy.xml，添加如下代码至<policymap>部分：
