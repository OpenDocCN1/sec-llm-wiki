# 【预警通告】Exim 远程代码执行漏洞（CVE-2019-10149）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650396332&idx=2&sn=dc50c5834eef4c041506732887b440ea&chksm=beca8f0789bd061155fd7443e0f749e1a79a099b096ab0fe956d8ae3a333c97d236948bb79c3&scene=126&sessionid=1681372473#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650396332&idx=2&sn=dc50c5834eef4c041506732887b440ea&chksm=beca8f0789bd061155fd7443e0f749e1a79a099b096ab0fe956d8ae3a333c97d236948bb79c3&scene=126&sessionid=1681372473#rd)

01  

**综述**

近日，Linux的邮件传输代理Exim被曝出存在一个远程代码执行漏洞（CVE-2019-10149），该漏洞是由/src/deliver.c 中deliver\_message()函数里对收件人地址的不正确验证造成。

  

CVSS:3.0 Base 9.0

AV:N/AC:H/PR:N/UI:N/S:C/C:H/I:H/A:H

  

Exim 在 2017 年就被报道过存在远程代码执行漏洞（CVE-2017-16943）和拒绝服务（CVE-2017-16944）漏洞，去年还公布了一个缓冲区溢出漏洞（CVE-2018-6789）。

  

参考链接：

http://www.exim.org/static/doc/security/CVE-2019-10149.txt

http://blog.nsfocus.net/cve-2017-16944/

http://blog.nsfocus.net/exim-cve-2018-6789/

  

**02**

**影响范围**

  

**受影响的版本**

  

*   Exim Version >= 4.87 
    
*   Exim Version <= 4.91
    

  

注：其中Windows Server 2003以及Windows XP已经不再受支持，但此次仍会发布对应的漏洞补丁。

  

  

03

**解决方案**

Exim官方已在4.92版本中修复了该漏洞，请受影响的用户尽快采取措施进行防护。

  

参考链接：

https://access.redhat.com/security/cve/cve-2019-10149

http://www.exim.org
