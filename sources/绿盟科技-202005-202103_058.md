# 绿盟科技荣获广州市网络安全技术支撑单位

1月19日，粤港澳大湾区（广州）网络安全产业园授牌暨广州市网络安全产业促进会第一届第二次会员大会在广州科学城会议中心举行。会上，**绿盟科技荣获广州市网络安全技术支撑单位，并获颁2020年度促进会优秀会员单位牌匾。**

  

![](../Images/7a6ae65c839767e665300750973d278f.png)![](../Images/266a3a488238ae84d44f53c80f8c34a2.png)

  

广州市委宣传部副部长、市委网信办主任陆志强，广州市黄浦区委副书记、宣传部部长李雪枝等出席“粤港澳大湾区网络安全产业园”揭牌仪式。

  

绿盟科技华南分公司高级销售总监王端作为会员单位代表上台发言，王端表示，粤港澳大湾区网络安全产业建设是推动广东改革开放的新举措，绿盟科技将长期跟随广州市网络安全产业促进会的步伐，积极投身于广东网络安全产业的大局之中，同其他会员成员一起推动广东网络安全产业新格局。

![](../Images/1dbb0303f612dc7684117b46ebf80c57.png)

绿盟科技华南分公司高级销售总监王端

  

2020年以来，绿盟科技积极履行广州市网络安全促进会副会长义务，充分利用自身技术优势，先后配合促进会组织的“2020年广州网络安全攻防演练”、“2020年广州首届网络安全知识有奖问答”活动，以自身在广州范围内的影响力，有力帮助公众了解网络安全产业知识，提升网络安全意识。未来，绿盟科技将一如既往地为促进网络安全产业建设与发展提供更多资源、贡献更多力量。
