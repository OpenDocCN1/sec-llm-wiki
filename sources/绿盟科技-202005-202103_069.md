# 绿盟科技获批“网络与信息安全应急响应人员（CCSRP）”培训机构

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650409492&idx=2&sn=4e8dddcecca877ffab2d35fc88f650ac&chksm=bec953bf89bedaa999e72e1e6a746384124b2c21ec335505a8a082b52c974e664c1703ea5781&scene=126&sessionid=1681372390#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650409492&idx=2&sn=4e8dddcecca877ffab2d35fc88f650ac&chksm=bec953bf89bedaa999e72e1e6a746384124b2c21ec335505a8a082b52c974e664c1703ea5781&scene=126&sessionid=1681372390#rd)

![](../Images/a5f662d7ee6d323314cbb009cfcd9ef1.png)

近日，通过对绿盟科技师资水平、培训环境、实施能力及教学理念等多方面审核，**国家计算机网络应急技术处理协调中心（CNCERT）正式认定绿盟科技为“网络与信息安全应急人员认证”培训机构**。同时，绿盟科技多位讲师经过能力审核，成为CNCERT认定的“网络与信息安全应急人员认证”培训讲师。

![](../Images/9c14aa4ff0b9466a9cbd25954c3ea778.png)

  

“网络与信息安全应急人员认证”（Certified Cyber Security Response Professional, CCSRP）是CNCERT推出的，面向重点行业网络与信息安全从业人员的技能认证。CCSRP认证以网络安全应急响应为切入点，覆盖网络与信息安全的事前、事中和事后等各方面的能力。该认证管理和技术并重，通用与特殊兼顾，理论与实践结合，重点培养网络信息安全从业人员解决实际问题的能力，致力于满足重点行业对网络安全人才的迫切需求。

  

作为CNCERT评定的国家级网络安全应急服务支撑单位和网络安全应急服务支撑单位（工业控制领域），绿盟科技多年来积极推动国家公共互联网网络安全应急体系建设，为维护公共互联网网络安全不懈努力。

  

 CNCERT简介

国家计算机网络应急技术处理协调中心（CNCERT）是中央网信办直属事业单位，是“网络安全万人培训资助计划”的发起和技术指导单位之一。CNCERT具备先进的实验平台、顶级的专家队伍和丰富的人才培养经验，熟悉政府部门、行业协会和企事业单位的网络信息安全人才需求。

  
CCSRP认证以网络安全应急响应为切入点，覆盖网络与信息安全的事前、事中和事后等各方面的能力。该认证管理和技术并重，通用与特殊兼顾，理论与实践结合，重点培养网络信息安全从业人员解决实际问题的能力，致力于满足重点行业对网络安全人才的迫切需求。

  

CCSRP面向对象

CCSRP认证面向重点行业（电信、金融、制造、能源等）的大中型国有及民营企业的信息安全应急人员，职位包括但不限于安全管理类的首席安全官、网络安全经理、安全总监、合规经理、审计员等，安全技术类的系统安全管理员、安全运维中心分析员、工业控制系统工程师等。

  
绿盟科技基于多年安全行业人才培养经验，围绕人才发展所需的知识、技能以及经验进行人才发展路线牵引，通过自有认证体系结合第三方认证，知识传递与实训赋能相结合，打造具有实战化能力+体系化思维的安全行业人才。

  

 绿盟科技网络安全学院 

 

绿盟科技网络安全学院隶属于绿盟科技集团股份有限公司，是中国信息安全行业人才的重要发源地之一。致力和专注于中国网络空间安全人才的培养；自学院成立以来，学院依托集团在安全领域深耕二十多年的安全知识积累，为政府、能源、金融、运营商、交通和教育等关乎国计民生的重要行业培养了数以万计的信息安全专业人才，助力和有效提升了相关行业的安全建设和防护水平为建设网络强国、保障国家网络空间安全做出了积极贡献。
