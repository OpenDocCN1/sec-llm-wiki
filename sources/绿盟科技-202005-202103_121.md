# 聚焦智慧民航发展 安全运营稳护航

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650408789&idx=3&sn=b0001fd690a04eafc8bf595a0a7ee75b&chksm=bec95efe89bed7e87eec86fb99ba59740c934084a49eb0c16bdd2d90cf88d2c2d98c1ea9404e&scene=126&sessionid=1681372394#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650408789&idx=3&sn=b0001fd690a04eafc8bf595a0a7ee75b&chksm=bec95efe89bed7e87eec86fb99ba59740c934084a49eb0c16bdd2d90cf88d2c2d98c1ea9404e&scene=126&sessionid=1681372394#rd)

12月10日，由中国信息协会主办的“2020 年第三届民航网络安全与信息化建设发展趋势高峰论坛”在北京召开，绿盟科技高级安全专家周金鹏受邀出席并发表题为《攻防对抗下的安全运营实践》主题演讲，向与会嘉宾分享了绿盟科技在民航领域的安全能力及创新技术。

![](../Images/68ce27988e634f7d15c214d059ede13d.png)

绿盟科技高级安全专家周金鹏发表演讲

  

会议以“让信息更安全、让安全更智能、科技助力＇智＇在民航”为主题，汇聚来自民航局相关部门、国内知名院校和安全企业等领导专家，围绕民航网络与信息安全、智慧民航与智能应用等行业热点话题进行深入讨论，共同研究推进民航网络安全与信息化建设工作。

  

**安全运营，为民航网络安全护航**

  

绿盟科技高级安全专家周金鹏在演讲中提到，新基建浪潮下，智慧民航飞速发展，网络安全正走向常态化，当今的网络安全建设应从传统产品模式向解决方案及安全运营模式转型，安全防御体系从静态、被动、基于规则的防御，转变为主动、动态、自适应的弹性防御体系。绿盟科技基于高强度、高烈度的对抗演练分析和沙盘推演方法，描绘攻防双方能力画像，提升攻防对抗的理解，促进安全运营保障体系落地。

![](../Images/6c3081fc258986b5547482658c76e01c.png)

  

绿盟科技为用户提供安全管理、安全运维、安全技术保障一体化的安全运营方案，协助客户建设适用于自己业务的安全运营保障体系。基于安全运营体系，以“一个中心，三重防护”为核心理念，全天候常态化的保障能力面向客户提供集威胁情报、运营平台、中台专家能力的7x24小时一站式服务，通过安全运营中心实现监测、预警、防御、应急、处置和治理为一体的全方位感知，从而实现常态化、实战化的安全运营保障，助力民航业务安全发展。

  

多年以来，绿盟科技始终致力于洞察民航行业业务需求，为用户提供场景化解决方案。未来，绿盟科技将持续进行技术革新，全面守护智慧民航安全。
