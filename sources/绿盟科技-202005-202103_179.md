# 超越挑战 | 绿盟科技助力江苏银行业和保险业首届网络安全竞赛圆满收官

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650407869&idx=5&sn=c296235269001900c8f4964672753c30&chksm=bec95a1689bed3006e756c94bfac490d89f80b5583a32be32cbf104f6096ce87dac829715ff0&scene=126&sessionid=1681372399#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650407869&idx=5&sn=c296235269001900c8f4964672753c30&chksm=bec95a1689bed3006e756c94bfac490d89f80b5583a32be32cbf104f6096ce87dac829715ff0&scene=126&sessionid=1681372399#rd)

![](../Images/d6e7e64d37a3990f15de6c0820bea63a.png)

近日，江苏银行业和保险业首届网络安全竞赛在南京顺利闭幕。本次竞赛由江苏银保监局、江苏金融工会联合举办，江苏省银行业协会协办，南京银行承办，**绿盟科技作为独家技术支撑单位，全程为本次赛事提供支撑与保障，助力竞赛完美收官。**

![](../Images/91033aa0e2c545f13527134b17ee7fc6.png)

本次竞赛旨在以竞赛促提升，激发江苏银行保险业网络安全工作发展新动能，进一步提高银行保险机构信息科技工作的合规意识、网络安全实战能力，防范网络安全风险。共有来自江苏省金融机构80名参赛选手和20支队伍参赛。

  

为了更好地锻炼和提高银行保险机构安全队伍，本次比赛采用了国际流行的CTF夺旗比赛和团队攻防竞赛形式，在赛题类型设计方面，包括热点的漏洞利用、SQL注入、WEB安全、移动安全、Python Cookie反序列化利用方面的题型。同时，为了贴合金融行业和保险行业的的业务特点，设计了网上银行、积分商城系统环境，通过模拟真实的业务环境，以赛代练，提高参赛团队的攻防对抗能力。

![](../Images/c54753e02a6c353ed7dc3db0ea4eacba.png)

赛后，绿盟科技华东分公司技术总监孙昌卫受邀在2020年度江苏省法人银行保险业信息科技风险管理指导委员会全体会议暨网络安全专题会议上为参会嘉宾做本次竞赛赛事回顾讲解，得到了与会领导认可。

![](../Images/a730f5b3c2c7671c99e2fc674f38859a.png)![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

网络安全的本质是对抗，对抗的本质是攻防两端的人才较量，作为本次竞赛技术支撑单位，绿盟科技希望通过贴合实战的攻防竞技比赛形式，为江苏省银行业和保险业网络安全人才培养和网络与信息化建设贡献安全力量。
