# “天府杯”网络安全大赛下周开赛 顶级“黑客”蓉城竞技

2020年11月7日—8日，“‘天府杯’2020国际网络安全大赛暨2020天府国际网络安全高峰论坛”将在中国成都中国西部国际博览城国际展览展示中心9号馆举行。**作为本次大赛的主办单位之一，绿盟科技将全力支撑大赛的举行，助力推进网络安全行业健康快速发展。**

  

世界顶级网络安全技术碰撞和思想饕餮盛宴即将拉开帷幕。

![](../Images/40a855a37a0b96513590a5ba494ed3c8.png)

顶级“黑客”在蓉秀“肌肉”

主办方透露，“天府杯”2020国际网络安全大赛以逐步打造属于中国自己的“Pwn2Own”(全世界最著名、奖金最丰厚的黑客大赛)为目标，将设置三个独立并行的比赛项目，原创漏洞演示复现赛、产品破解赛和系统破解赛。

  

其中，原创漏洞复现赛方面，不设场景限制，给参赛选手提供展示个人珍藏0day漏洞的舞台，从电视机顶盒到手机，从PLC硬件到SCADA软件，从小小芯片到整车装备，攻击对象由网络安全团队自主选定。漏洞复现环节充分考验全场选手的技能积累和现场实操能力。

  

产品破解赛方面，组委会结合世界知名黑客大赛战况，精心遴选了难度大、漏洞影响范围广、对我国有特殊影响、体现网络安全发展趋势的赛题，破解赛题涵盖PC端、移动端、服务器端、IOT设备等在内的16道破解题目。

  

而系统破解赛方面，组委会设置了开放性趣味答题区域，现场设置一些工业场景的控制设备及题目，参赛队伍可在现场酌情进行破解。

  

“大赛奖金总额将达100万美元，奖金比例足以抗衡各大顶级公司的专项奖金池，奖励足够诱人，大赛组委会立志打造一场网络安全技术盛宴，吸引顶级黑客，奉献一场震撼带感的饕餮盛宴。”主办方负责人说，大赛目前已经吸引了多家海内外知名公司热切关注和踊跃报名，截至目前共有20余支队伍参赛，参赛人数近百人。

  

在奖金发放方面，主办方表示，今年大赛奖金池共计100万美元，90%奖金用于产品破解赛，剩余10%奖金用于漏洞演示复现赛，根据参赛队伍和漏洞提交等情况动态调整奖金分配比例。其中，在产品破解赛方面，一旦参赛队伍成功破解某道赛题，该队伍将获得该赛题所对应的全额奖金。单项最高奖金高达30万美元。为最大程度上保证选手的奖金利益，今年组委会还将启用等比例下调机制和单个赛项最高奖金池等机制，确保百万美金花落众家。

  

除奖金外，比赛将设置最佳漏洞演示奖、最佳漏洞复现奖、最佳产品破解奖(分一、二、三等奖)、最具价值产品破解奖及系统破解赛的成功破解奖。

  

网安高峰论坛引领先锋话题

除一览国际顶级网络安全技术大赛外，“2020天府国际网络安全高峰论坛”也将同期在中国西部国际博览城国际展览展示中心9号馆举行。

  

本次论坛主题为“数字驱动发展 安全守护未来”。论坛立足“新基建”时代网络安全产业发展最新态势，聚焦西南地区引领网络安全产业发展所面临的机遇和挑战，由一个主论坛和系列分论坛组成，将采用线上线下相结合的方式，同步线上直播。

  

在主论坛上，“新基建时代下的网络安全机遇与挑战”等先锋话题将迎来全面释疑，国内外知名企业负责人将碰撞出行业新风向。物联网安全、AI安全、关键基础设施保护、网络安全人才培养等行业“痛点”与“痒点”亦将在多个分论坛得到深度解惑。

  

现场将邀请中央和地方政府主管部门领导、业内顶级专家、顶级安全企业代表、高校和科研机构专家等做主题演讲，围绕物联网、AI、漏洞挖掘、网络安全专业人才培养等内容展开讨论，共商解决方案，共谋合作之道。

  

主办方表示，此次大赛和高峰论坛的举行是为广泛吸引海内外网络安全技术人才，为其提供切磋技术和交流平台，构建具有中国特色的网络安全技术盛宴，锻造出中国网络安全品牌，提升我国网络安全技术技能和实力。
