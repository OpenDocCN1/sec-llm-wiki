# 聚焦工业信息安全 | 边缘智能与控制协同的安全思考

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650405566&idx=2&sn=a25b36b1b4e6d94f1075e99dac818f10&chksm=becaa31589bd2a035aff90a587eb463e306a5e8af05af44d27c4d635116881a6d5adb683af76&scene=126&sessionid=1681372411#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650405566&idx=2&sn=a25b36b1b4e6d94f1075e99dac818f10&chksm=becaa31589bd2a035aff90a587eb463e306a5e8af05af44d27c4d635116881a6d5adb683af76&scene=126&sessionid=1681372411#rd)

9月3日 ，“2020 ALL IS工业信息安全技术峰会-石化/电力专场”在上海召开，绿盟科技受邀参加并发表主题演讲。本次峰会由上海工业控制系统信息安全技术服务联盟和上海工业自动化仪表研究院指导，来自石油石化、电力行业专家学者共聚一堂，探讨工业信息安全关键需求及应对策略。

![](../Images/4c8f7d08fc1641d9ff90586983282c6c.png)

  

绿盟科技华东分公司技术总监孙昌卫在本次峰会上发表了题为《边缘智能与控制协同的安全思考》主题演讲。随着工业互联网的发展，边界不断扩展且愈加模糊，边缘与设备侧面临的安全风险愈发明显，本届工业信息安全技术峰会上，绿盟科技从边缘智能与控制协同方面提出安全解决方案。绿盟科技认为，解决边控安全风险，需要构建多技术融合的动态感知与智能防护体系，可以通过将安全能力部署至边缘计算网关侧，确保边缘侧的设备安全、控制安全、网络安全。同时，通过多边计算管理形成基于业务场景的自动化安全资源编排能力，并和边缘安全网关进行智能协同。此外，还需要将安全监测预警、攻击溯源、应急响应等纳入常态化的安全运营管理，形成边控一体的综合安全保障能力。

![](../Images/2d7079dcb4f22e9463eb8433310cb004.png)

绿盟科技华东分公司技术总监孙昌卫

![](../Images/619cc53fd0eae59fdbea7b5c0a016db2.png)

 

绿盟科技从2010年开始在工业信息安全领域布局，并将其作为重要的战略发展方向。不忘初心，方得始终。绿盟科技秉承着“巨人背后的专家，保障客户业务顺畅运行”的企业使命，用更专业、全面的安全防护能力服务于行业用户，为推动国家工业信息安全体系建设、保障工业信息安全做出积极贡献。
