# 国开金融有限责任公司蒋道振一行 莅临绿盟科技参观调研

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650402539&idx=3&sn=f86c814fe3ad647223b5612758f650b6&chksm=becab74089bd3e56832ba92cae81d2f18cb4313f37a8d9c0e4a68fddd83b23f8b87f590c8e6a&scene=126&sessionid=1681372424#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650402539&idx=3&sn=f86c814fe3ad647223b5612758f650b6&chksm=becab74089bd3e56832ba92cae81d2f18cb4313f37a8d9c0e4a68fddd83b23f8b87f590c8e6a&scene=126&sessionid=1681372424#rd)

6月1日，国开金融有限责任公司党委副书记、监事长蒋道振一行莅临绿盟科技参观调研，绿盟科技金融事业部总经理王俊、技术总监徐特等出席接待。

  
![](../Images/9685723ff2237a4dcd2ac3f3f8c0ce8a.png)

蒋道振一行首先参观了绿盟科技位于总部三层的资质荣誉展区，全面听取了绿盟科技作为值得信赖的安全企业在20年的发展历程中所取得的各项资质、荣誉及成绩。参观结束后，蒋道振一行重点了解了绿盟科技20年来的发展情况、在金融行业的投入和发展、参与国家重点专项保障工作及应用案例等，并就绿盟科技在金融机构的专项行动安全保障服务情况进行了深入探讨。

  

在听取汇报后，蒋道振对绿盟科技公司实力和在网络安全行业取得的成绩表示认可，他表示，目前需要像绿盟科技这样有实力、肯担当的网络安全企业来为金融机构发展保驾护航。希望绿盟科技积极投入到国开金融的网络安全建设工作中。
