# 绿盟科技入选江苏省“网安2020”网络安全保障行动检查服务机构名单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650402293&idx=2&sn=7f686f58c8648a1989504044af0a89ba&chksm=becab45e89bd3d4813960593bfa0bc5ad478ee85d590c0ecade02ff615028b65f1056a1a174a&scene=126&sessionid=1681372426#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650402293&idx=2&sn=7f686f58c8648a1989504044af0a89ba&chksm=becab45e89bd3d4813960593bfa0bc5ad478ee85d590c0ecade02ff615028b65f1056a1a174a&scene=126&sessionid=1681372426#rd)

5月19日，江苏省“网安2020”网络安全保障系列活动启动会在苏州举行，大会公布了江苏省“网安2020”网络安全保障行动检查服务机构名单，并举行了授牌仪式，绿盟科技凭借过硬的实力和网络安全领域技术积累，成功入选。

  
![](../Images/251fcd01200b805b2864e5599272bbb8.png)![](../Images/ddb071002b131c544cb3505c4fe192e8.png)

当前，我国正在加快5G、大数据中心、工业互联网等新型基础设施建设。新基建会进一步加快网络世界和物理世界的融合，这意味着两者的边界将逐渐不再清晰，对网络的攻击就等同于对物理世界的攻击，直接影响人民生活、社会稳定、甚至是国家安全。

  

为全面提升江苏省网络安全防护能力，确保江苏省“网安2020”网络安全保障系列行动顺利实施，省网信办特遴选出一批能力强、素质优的网络安全企事业单位支撑行动开展。

  

绿盟科技将发挥多年来在网络安全领域的积累和实力，助力江苏省筑牢网络安全防护网，夯实网络安全根基，对被检测单位开展全面的网络安全技术检查，切实推动提升网络安全防护能力。

  

![](../Images/f7cfbbdd76a282225ef95947dd79c332.png)

入选江苏省“网安2020”网络安全保障行动检查服务机构名单，是对绿盟科技二十年来不断完善产品和服务的认同和赞誉。未来，绿盟科技将继续秉承“巨人背后的专家，保证客户业务顺畅运行”的使命，为筑牢国家网络安全屏障提供力量。
