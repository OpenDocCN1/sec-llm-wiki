# 绿盟科技云安全市场份额缘何位居前三？

随着云原生技术的逐步兴起及网络攻击的愈演愈烈，提升云安全防护能力迫在眉睫。在2020年中国云安全市场规模迅猛增长的态势下，绿盟科技云安全解决方案结合外部市场需求及内部技术创新双轮驱动，市场份额大幅提升，在赛迪顾问《2020-2021年中国云安全市场研究年度报告》（以下简称《报告》） “安全云服务”主要市场中排名第二，综合排名位居行业第三，市场认可度和影响力不断扩大。

![](../Images/a5f9c0075bf8e2919f29c514aadc08f6.png)

2020年中国安全云服务市场品牌结构

  

一、需求加速增长 市场大有可为  

5G和工业互联网时代的来临，带来了海量数据的存储问题，随着“新基建”的加快推进，大型甚至超大型数据中心的建设需求呈指数级增长，云计算安全作为云数据中心建设的重要保障也取得了长足发展。《报告》指出，2020年，中国云计算安全市场规模达到53.4亿元，同比增长54.8%。

  

同时，国内企业的业务安全借力于SaaS安全服务的比例依旧偏低，市场主要集中于抗DDoS和WAF类产品的SaaS化，多数产品仍采用纯线下或线下与虚拟化云主机协同的混合安全模式。《报告》数据显示，2020年，中国安全云服务市场规模达到29.1亿元，同比增长41.3%。未来，随着全球SaaS服务市场步入成熟期，国内云服务商也开始重视SaaS安全生态的深度建设，安全云服务市场将迎来发展良机。

  

二、紧跟行业趋势 着眼能力建设

2010年，绿盟科技成立独立的云安全研究团队，并基于在云安全领域深厚的技术积淀，于2018年成立星云实验室，致力于云原生安全落地、云化安全能力扩展、多云技术预研等安全研究。

  

2016年，云安全研究团队发表著作《软件定义安全：SDN/NFV新型网络的安全》，阐述了面向云计算系统的下一代安全防护体系。2018年，星云实验室发布《绿盟科技容器安全技术报告》。2020年与中国移动云能力中心联合发布《云原生安全技术报告》，并与国家工信安全中心等联合发布《信息技术应用创新云安全白皮书》，聚焦信创产业的云安全发展。此外，绿盟科技还参与CSA云安全联盟发起的“云计算安全技术要求”标准制定。2021年，绿盟科技联合信通院等发布业界首份《云原生架构安全白皮书》，共同制定云原生架构安全标准。

  

三、创新驱动发展 战略成果丰硕

**云计算安全**

绿盟科技云计算安全解决方案采用软件定义安全SDS架构，整理零散的虚拟化安全设备和传统安全设备，在政务云、金融云、医疗云、企业云等场景落地大量案例，通过安全资源池的方式帮助用户快速提升云平台东西向及南北向的安全能力，满足用户快速扩展、集中运维、等保合规等需求。

**云原生安全**

2020年，绿盟科技发布容器安全管理系统，秉承DevSecOps理念，率先采用微服务设计，借助容器编排技术将安全容器部署于容器环境中，实现云原生环境中的容器检测和防护，同时具备多维度资产自发现、流量可视化等创新技术能力。该系统为金融、政府、运营商等行业用户提供一站式容器安全解决方案，为构建、部署和运行的容器提供全生命周期防护。

**5G与边缘计算安全**

绿盟科技在5G接入侧、MEC 多接入边缘云、5G传输侧和5G核心网领域打造安全解决方案，解决5G基础设施和业务的安全防护问题。在边缘计算安全方案中，绿盟科技充分利用MEC的服务开放能力，将MEC数据、控制和管理层面无缝对接，并支持以云原生MEC安全应用、内置安全资源池、外部安全资源池等多种方式部署安全能力，满足不同业务场景需求。

**SASE**

2021年6月，绿盟科技安全访问服务边界方案SASE正式发布。SASE改变了传统应用访问和安全防护模式，极大地提升了各类服务在用户访问混合环境中的便利性和安全性。绿盟科技的SASE私有应用访问服务为运营商、企业、政府用户提供收敛资产暴露面、零信任接入控制、多分支访问等能力，帮助用户实现快速建设零信任安全，减少IT一次性投入，降低IT建设复杂度，优化访问体验。

未来，绿盟科技将不忘初心，砥砺前行，紧跟云计算技术发展趋势，持续加大在云安全技术和市场的投入，以技术推动产业发展，为用户提供优质的云安全产品和服务。
