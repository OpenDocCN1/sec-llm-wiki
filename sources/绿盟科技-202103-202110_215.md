# 2021绿盟科技“网络安全服务”暑期教师研修班在成都正式开班

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650415660&idx=2&sn=fc49ee50d30e57dcff085afa7f5aa4b5&chksm=bec97b8789bef291d0b3e6407e51fc45e28aca25f1e8c4e6394d1e15260bd4078f177cba8300&scene=126&sessionid=1681372359#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650415660&idx=2&sn=fc49ee50d30e57dcff085afa7f5aa4b5&chksm=bec97b8789bef291d0b3e6407e51fc45e28aca25f1e8c4e6394d1e15260bd4078f177cba8300&scene=126&sessionid=1681372359#rd)

![](../Images/0e778a3f8482870c6a93851d45e706a3.png)

2021年7月19日，由绿盟科技集团主办的“2021绿盟科技网络安全服务暑期教师研修班”在成都信息工程大学正式开班。来自全国高校网络安全人才培养、学科建设的专家，共同就高校网络空间安全产教融合、产学合作、协同育人进行深入交流。绿盟科技集团高级副总裁孙冀平、成都信息工程大学网络空间安全学院党总支书记张仕斌、绿盟科技集团科教文卫本部总经理李永松等领导出席开班仪式。

  

![](../Images/491aa1fa30f7cab826e6c2a2473f9954.png)

据悉，本次研修班主要面向全国网络空间安全院校的老师，旨在进一步贯彻落实教育部产学合作协同育人的相关规定，促进网络安全实战型人才的培养。研修班课程涵盖四大知识域、9个知识子域、19个课程模块，参与课程的老师将通过体系化的学习，掌握网络安全知识体系以及各知识域重要知识点，具备网络安全运维相关技能的教学传授工作能力。

  

在会议致辞环节中，绿盟科技集团高级副总裁孙冀平表示，绿盟科技近年积极响应国家号召，持续加大资源投入力度支持高校人才培养，伴随着教育行业的发展与积淀，与国内众多知名高校开展“产学研”校企合作。在协同育人、技术创新、成果转化等多方面取得了较好的效果。希望通过本次研修班的举办，能够为促进产、学、研、用、策的深度融合而贡献一份力量。

![](../Images/f1e295d293a3c4de11c81843e90d2379.png)

 绿盟科技集团高级副总裁孙冀平

  

成都信息工程大学网络空间安全学院党总支书记张仕斌发表了致辞及演讲。他表示，成都信息工程大学近年来积极落实国家对于产教融合的相关政策要求，在网安人才培养方面不断进行尝试，通过实践培训、以赛促学等方式，将产学研工作落实到实处，带动提升学生网络安全技能，帮助学生提高网络实践能力。希望通过本次研讨会能够和众多专家相互交流，共同做好网安人才培养工作。

![](../Images/5db8377a990c73d4163b67f43750b6e2.png)

成都信息工程大学网络空间安全学院党总支书记张仕斌

  

会议中，各位专家对教育行业网络安全人才培养、校园网络安全建设实践与探索进行了分享。绿盟科技集团科教文卫本部总经理李永松就新形势下网络安全人才培养的思考与行动进行了分享。绿盟科技在网安人才的实践与探索中进行优势资源整合，提出“推广技术、建立基地、培训师资、导入课程、培训认证、攻防竞赛、科创服务、就业创业”32字方针，促进产、学、研、用的深度融合。

![](../Images/b89c8eeb4a7bb2fe2bee01d8c2d791e5.png)

绿盟科技集团科教文卫本部总经理李永松

  

绿盟科技安全专家重点介绍了绿盟网络空间安全仿真平台。该平台通过虚拟化、虚实结合、安全编排、行为及流量仿真、效果评估、智慧安全知识图谱等技术构建各类应用场景，并对场景中生成的用户行为和攻防行为进行评估分析，满足高校进行人才培养，攻防演练和测试研究等需求，帮助高校培养更有“战斗力”的专业人才。

![](../Images/fe83319c2673c98d9836bb29b76e4078.png)

绿盟科技安全专家

  

华中科技大学网络空间安全学院院长助理张云鹤表示，学院依托产学合作协同育人，提升与企业合作层次，加强协同合作面，打造全覆盖协同育人体系，提高学生的实践实操能力。

![](../Images/a788c742be3a9abf0cbc4f893f8b1635.png)

华中科技大学网络空间安全学院院长助理张云鹤

  

常州信息职业技术学院实践教学管理教研室主任姜晓武表示，学院结合地区信息安全产业发展状况及人才需求，明确专业发展方向，在专业群“工程导向、一专多能、多元发展”人才培养模式下，结合本专业的特点，制定具有鲜明特色的专业人才培养方案。同时，加强与行业领军企业合作，促进专业持续发展。

![](../Images/4e2c8923c5c38b6aab403215a491041c.png)

常州信息职业技术学院实践教学管理教研室主任姜晓武

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)
