# 构建电子政务安全监测体系｜绿盟电子政务网络安全监测平台解决方案荣获嘉奖

近日，由工业和信息化部网络安全产业发展中心（工业和信息化部信息中心）、福建省数字福建建设领导小组办公室、厦门市人民政府、信息中心技术创新应用协作组联合主办，厦门市工业和信息化局承办的2021年信息技术应用创新产业发展高峰论坛暨2020年信息技术应用创新典型解决方案发布会在厦门市成功举办。会上，**绿盟科技“电子政务网络安全监测平台解决方案”荣获2020信息技术应用创新典型解决方案奖。**

![](../Images/fc6b3fed7f84c51cbc830a259b68db53.png)

绿盟科技集团副总裁崔媛媛代表绿盟科技领奖（右七）

  

论坛以“信创领航 协同发展”为主题，聚焦信创领域产学研用政各界代表，共同探讨供需协同机制下的新技术、新应用和新方案，促进信息技术应用创新产业高质量发展。

![](../Images/18e9568020dc2f9e9850d1a0aa2aa2bd.png)![](../Images/1c32a2d1b66fa92d62ae3e751a79662f.png)

  

绿盟电子政务网络安全监测平台解决方案

绿盟科技秉持智慧安全3.0理念，通过独创的威胁分析算法、人工智能技术融合大数据智能分析，针对电子政务场景深度定向开发了信创版电子政务网络安全监测平台解决方案。该解决方案全面应用信创产品，以运营为中心，以实战化为基准，实时掌握各级电子政务系统的网络安全态势，实现对电子政务网络的全场景安全监测与统一安全管理。

![](../Images/c7cee6697fdf11e26dc417415f16835f.png)

绿盟科技安全专家在分论坛上介绍获奖方案  

  

![](../Images/99752cc442fd841e5e98a61876d85183.png)

  

**全面适配信创生态**

绿盟科技一直致力于电子政务领域态势感知和信息技术应用创新产品研究工作，全面实现了与主流信创平台的兼容适配，提供从网络安全到业务安全的多种安全防护能力，并针对主流信创平台完成了针对性的性能调优，可为电子政务网络安全提供保障供应链安全的高性能、全面的安全防护能力。

![](../Images/b85a077c17d092012c5e02ec5e667120.png)

  

**护航电子政务**

绿盟科技态势感知产品已连续两年获得IDC AIRO市场份额第一，绿盟电子政务网络安全监测平台解决方案作为唯一的安全解决方案入选工信部《大数据优秀产品、服务和应用解决方案案例集》。方案客户遍及全国多个省/直辖市，全力守护电子政务信息系统和数据，让市民和企业可以安心的使用和办理政务业务。同时，方案能够帮助主管部门和各委办局履行安全防护职责，持续促进电子政务健康发展。

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

聚焦信息技术应用创新产业安全现状，绿盟科技基于多年的安全研究，为用户提供安全评估类、检测防御类、安全审计类、安全平台类信创产品，覆盖事前、事中和事后多个环节。作为巨人背后的专家，绿盟科技将立足长远，积极推进信创产业发展，探索建立产业多方协同机制，构建信创产品安全保障体系，为促进信创产业发展贡献力量。
