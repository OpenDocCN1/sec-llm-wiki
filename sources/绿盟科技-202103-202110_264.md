# 天津市委网信办与绿盟科技达成战略合作, 携手推进网络安全和信息化建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650414609&idx=1&sn=9cb7911c22a934c21e8cb60537c15165&chksm=bec947ba89beceac085bfe0e5fd53b661ded76a142f3226115447c067fe8599fddd069ccfda8&scene=126&sessionid=1681372364#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650414609&idx=1&sn=9cb7911c22a934c21e8cb60537c15165&chksm=bec947ba89beceac085bfe0e5fd53b661ded76a142f3226115447c067fe8599fddd069ccfda8&scene=126&sessionid=1681372364#rd)

![](../Images/0e778a3f8482870c6a93851d45e706a3.png)

2021年6月24日，天津市委网信办与绿盟科技在天津举行战略合作签约仪式。天津市委宣传部副部长、天津市委网信办主任、市大数据管理中心党委书记、主任王芸，天津市委网信办副主任徐滨彦，天津市委网信办总工程师李磊，绿盟科技集团总裁胡忠华，绿盟科技集团首席技术官叶晓虎博士等领导参与了本次活动。

  

天津市委网信办副主任徐滨彦和绿盟科技集团首席技术官叶晓虎博士分别代表双方签约。

![](../Images/989800dd9a86bc143670d3b28fce5c21.png)

签约仪式

王芸主任表示，我们要牢记总书记“四个面向”的要求，坚持加快科技创新。天津市委网信办持续认真贯彻落实市委、市政府部署，围绕“四个坚持”重要要求，倾力为企业当好“店小二”，为企业发展做好保障，共同探索数字产业发展、网络安全治理的新路径，为维护国家网络安全贡献智慧和力量。  

  

绿盟科技集团总裁胡忠华表示，绿盟科技成立21年来，一直坚持技术创新，期待在产学研协同、数据安全建设、城市级安全运营中心等领域与天津市网信办开展合作。绿盟科技将充分发挥自身优势，用好政府政策支持，聚焦技术创新，培养和集聚人才，寻求与天津市委网信办在数字经济时代网络安全生态构建的深度合作，携手推动网络安全产业，为天津市社会高质量发展做出积极贡献。

![](../Images/1aeed060223d0a3f9ff75ad34d733696.png)

天津市委宣传部副部长、天津市委网信办主任、市大数据管理中心党委书记、主任王芸（图右）

绿盟科技集团总裁胡忠华（图左）

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

本次战略合作标志着双方在人才培养、网络安全研究实验基地、产品及应用开发、城市级应急响应中心建设等方面合作迈出了新的一步。未来，绿盟科技将利用自身在网络安全领域的资源优势和影响力，以更加积极务实的态度，推进与天津市委网信办的战略合作。
