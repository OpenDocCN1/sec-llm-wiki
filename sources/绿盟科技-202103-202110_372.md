# 携手合作伙伴 聚力共赢商机 | 2021绿盟科技合作伙伴峰会·西安站圆满落幕

近日，“聚以致远·同心领航——绿盟科技合作伙伴峰会·西安站”顺利举办，400余位网络安全行业专家及合作伙伴代表齐聚西安，共同探讨合作共赢战略。大会对绿盟科技2021年合作伙伴政策、商业产品及西安研发中心进行介绍，同时举行了商业合作金牌签约仪式及战略合作伙伴签约仪式，并邀请到陕西优秀合作伙伴代表分享与绿盟科技的合作体会。

![](../Images/2d548ea73346579fe98582fbaae95ca3.png)

  

![](../Images/6ee849ca7dfa15902295c372be769c81.png)

绿盟科技集团副总裁欧阳闽泽

绿盟科技集团副总裁欧阳闽泽详细阐述了2021年绿盟科技合作伙伴政策。近年来，绿盟科技不断优化组织架构、考核体系和系统流程，重塑合作伙伴体系和管理机制、加大资源投入与合作伙伴赋能、打造面向合作伙伴的产品体系，以此加速推进合作伙伴转型落地。在合作伙伴体系的打造上，通过构建两级合作伙伴架构，严守公平、公正的市场秩序，为合作伙伴构建阳光、透明的商业环境。

  

通过推出“星空计划”和“丰收计划”，与合作伙伴建立了广泛的合作。通过各项改革措施支撑渠道战略的落地执行，和伙伴共赢网络安全行业的丰收。在合作伙伴的坚定支持下，绿盟科技得以倡导“聚以致远，同心领航”的网络安全新生态格局。接下来，绿盟科技将会更开放地拥抱合作伙伴，一起同心携手齐奋进，领航安全新征程。

  

![](../Images/86046ba02f5fcfc5444364a3c218e1dd.png)

绿盟科技集团副总裁宫智

绿盟科技集团副总裁宫智为大会致辞，并详细介绍了公司的商业产品。他表示，公司一直以来高度重视安全研究和技术创新，目前能为用户提供安全评估、安全检测、安全防御、安全平台类等60多款高品质安全产品。其中绿盟抗拒绝服务系统（ADS）、绿盟入侵检测防御系统（IDPS）、绿盟WEB应用防护系统（WAF）、绿盟远程安全评估系统（RSAS）等产品多年保持国内市场占有率第一。  

  

2021年，面向中小型企业市场用户的网络安全需求，绿盟科技重磅推出了14类、28款型号的商业渠道产品，全面覆盖安全防护、安全审计、安全管理、检查评估类等众多场景。产品具有“合规、适用等保，易用、快速上线，稳定、高效运行”的特点。同时发布“绿盟科技安全服务智能工具箱（NSmart）”，通过绿盟科技安全专家团队云端赋能，助力安全服务质量提升，帮助合作伙伴合作伙伴快速提升安全服务交付能力和市场竞争力，开拓安全服务市场。

  

![](../Images/02d61a9dc915ed5020cf2eaea68b0492.png)

绿盟科技集团西安办事处首席代表程旗保

绿盟科技集团西安办事处首席代表程旗保从公司概况、安全研究、安全产品、解决方案、服务体系、安全运营及绿盟科技在陕西的发展情况进行了详细介绍。他谈到，绿盟科技作为国内优秀的网络安全产品与解决方案提供商，二十多年来持续加大研发投入，深耕行业，专注攻防对抗、技术创新和安全能力研究。如今，网络安全产业发展已进入“快车道”，网络安全行业持续“高增长”，期待大家携手一起，聚以致远，同心领航，赢得更为广阔的网络安全市场。

  

![](../Images/3093c4a528a2725e46fdc2a293377954.png)

绿盟科技集团西安研发中心产品研发线副总经理樊志甲

绿盟科技集团西安研发中心产品研发线副总经理樊志甲详细介绍了绿盟科技西安研发中心。西安研发中心专注于安全研究和安全产品及安全服务的研发创新。依托于八大实验室的研究积累，绿盟科技始终致力于让用户获得专家级安全服务体验，凭借深厚的研发能力不断推动产品创新，同时配备应急响应团队以及安全技术研究院，为用户的发展提供坚实有力的信息安全保障。

  

![](../Images/e9cf9fc4d188c25c6e3eff16ef0cff36.png)

陕西尉图实业有限公司总经理周亚军

陕西尉图实业有限公司总经理周亚军谈到，尉图实业与绿盟科技合作的10年历程中见证了绿盟科技产品体系和管理体系的不断完善，绿盟科技目前的合作伙伴政策更加的阳光透明，使得合作伙伴更有信心与绿盟科技携手合作，共同发展。

  

会上，绿盟科技与陕西拓源网络科技有限公司、陕西易维计算机技术服务有限公司、中通服科信信息技术有限公司、陕西志成新业网络技术有限公司、陕西金鹰信息技术有限公司进行了商业合作金牌签约仪式及战略合作伙伴签约仪式。

未来，绿盟科技将长期坚持渠道战略不动摇，构建多赢的合作伙伴关系，与所有合作伙伴共同发展、共同成长、共同服务客户，互相交流合作模式与成功经验，携手助力绿盟科技合作伙伴业务有序推进，实现客户、合作伙伴、绿盟科技的“三赢”。
