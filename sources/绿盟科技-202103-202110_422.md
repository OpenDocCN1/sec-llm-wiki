# “邮”实力｜绿盟科技获“邮政行业网络安全技术研发中心”认定

近日，**绿盟科技作为首批网络安全技术认定单位获邮政行业技术研发中心授牌。**在北京市邮政管理局举行的邮政行业科技研发中心授牌仪式上，绿盟科技集团首席行业专家张智南博士代表绿盟科技领取授牌并发言。

![](../Images/33f5ff788ee19e0631e653cf5ea97556.png)

  

邮政行业技术研发中心（以下简称研发中心）是以现代邮政业发展需求为导向，开展邮政行业科技研发活动、推动科技成果转化和技术交流、培育行业科技创新人才的重要基地，是邮政业技术创新体系的重要组成部分。绿盟科技深耕网络安全行业二十余载，凭借深厚的技术积累和扎实的专业能力成为“邮政行业网络安全技术研发中心”首批认定单位。

![](../Images/02df6e1af33d940a8665a196a14f7ff6.png)

绿盟科技集团首席行业专家张智南博士（左）领取授牌

  

绿盟科技集团首席行业专家张智南博士表示，绿盟科技高度重视安全研究和技术创新，作为邮政行业网络安全技术研发中心，将与国家邮政局及各技术研发中心全力合作，结合全国邮政寄递行业特色，大力推动行业网络安全技术发展，在攻防对抗技术、数据智能、云计算安全、数据安全、工业互联网、物联网、车联网和威胁情报研究等领域，提供全线网络安全产品，打造具有邮政寄递行业特色的全方位安全解决方案和体系化安全运营服务。

  

近年来，邮政寄递行业持续快速发展，从业规模不断扩展，为国民经济做出巨大贡献。绿盟科技将深入行业研发需求，携手研发中心成员单位展开合作，打造产、学、研、用深度融合的技术创新体系，推动科技成果转化和技术交流落地，切实提升邮政寄递行业科技创新能力和水平，持续为其网络安全发展提供关键技术支撑。
