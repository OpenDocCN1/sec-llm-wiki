# 武汉开讲｜第二期《数据安全实践专题培训》正式开课

4月26日，由绿盟科技网络安全学院组织举办的第二期《数据安全实践专题培训》在“九省通衢“之地武汉正式开课。参加本期培训的学员来自全国各地的银行、金融机构、运营商以及能源、高校等行业的网络安全及数据安全相关从业人员。

![](../Images/d1b3b3f9b8811dbe890467b08940e858.png)

  

本期《数据安全实践专题培训》主要围绕数据安全和个人信息保护、强监管、数据确权、个人权益等热点内容展开。通过聚焦企业或组织关注重点难点、整合现有绿盟科技数据安全专业服务实践，基于实际项目经验，构建出一套知识点关联清晰、成体系、有层次的数据安全课程体系，确保学员能够获取数据安全专业能力。培训讲师为绿盟科技资深数据安全专家。

![](../Images/7433bd8e82dc7f6235d1f2d0afe0356a.png)

  

本次数据安全课程开发历时数月，由多位绿盟科技数据安全咨询专家及资深讲师倾力打造，在为期4天的课程培训中，绿盟科技网络安全学院会通过优质的服务和丰富实用的课程内容回馈本次参训学员的支持与信赖。
