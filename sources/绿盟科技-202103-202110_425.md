# 绿盟科技二十一周年庆：向下一个跨越式发展迈进

2021年4月25日，绿盟科技迎来了21岁生日。

![](../Images/91fe0f68cd8df52bd789036d3768c252.png)

  

绿盟科技集团总裁胡忠华在司庆致辞中表示，2020年是极不平凡的一年，在董事长沈继业及董事会的带领下，公司成员上下一心，奋力拼搏，克服了疫情带来的困难，取得了良好的成绩。

![](../Images/dcf3a8a9abb0937450a1e32336e6c9e1.png)

  

“ 

回顾过去一年，在业务领域持续巩固优势行业的同时，抓住了新的机会点，为向各行业均衡发展迈出了坚实一步；渠道业绩同比增长2.2倍，渠道战略转型初见成效；持续加大产研体系投入，人员净增长超过20%；技术研究不断创新，产品竞争力不断增强，研发效能显著提升；后端组织进行整合优化，更好地支撑一线业务拓展。

  

展望未来，网络安全产业发展进入“快车道”，网络安全行业持续“高增长”，未来几年，是网络安全产业格局重构的关键时期，机遇和挑战并存。为促进战略落地和目标的达成，公司将围绕以客户为中心，在组织、流程、人才进行持续调整和优化。行者常至，为者常成，期待大家一起，不忘初心，砥砺前行，为绿盟科技的崛起而奋斗，为年度目标的实现、百亿战略目标的实现而奋斗。

”

  

为服务满一定年限的绿盟人颁发纪念金牌，是多年来司庆的保留项目。纪念金牌承载的不仅仅是对绿盟人的青春纪念，也饱含着公司对绿盟人辛勤付出的衷心感谢。获牌代表和大家分享了在公司的点滴经历，这些故事见证了员工和公司的共同成长。一位在公司服务超过10年的员工代表说，和绿盟科技一起共同成长的历程，才是人生真正宝贵的财富，时光仍在继续，我们仍在进取，趁大家还年轻，一起再走十年。

![](../Images/dc358ea53f4622152039a77fb2a9f5bb.png)![](../Images/7dacc141023b640d143a30854e35dfbf.png)![](../Images/a07eb6693c0ebaeaa1b0c91eb414ef27.png)![](../Images/2efbf10aafa9d935dfcbab2ae9382858.png)![](../Images/eda24a288d3bb20d4a7c2373f80fa497.png)

  

二十年铿锵步伐，绿盟科技始终以攻防能力作为锤炼立身之本，高度重视网络安全技术研究，持续推进网络安全产品创新。通过绿盟科技研究院和八大实验室的潜心专研，公司始终保持着前沿的技术水平和雄厚的专业实力。

  

2021年，绿盟科技智慧安全3.0理念体系发布，标志着绿盟科技的P2SO（Products to Solution + Operations）计划迈入新的阶段，向“全能力，全运营”方向进化。围绕智慧安全3.0“全场景 可信任 实战化”的理念体系，绿盟科技的安全产品已全面覆盖等保、新基建、数字化等应用场景，同时不断优化安全体系建设，提升整体网络安全防护能力。

  

作为中国网络安全行业的实力企业，绿盟科技以技术起家，始于技术，忠于专业。21载栉风沐雨，绿盟人凝心聚力，不断突破；未来征途漫漫，绿盟人将携手并肩，敢为敢战，再创一个崭新的辉煌里程。

  

今日，也是清华大学建校110周年，“自强成就卓越,创新塑造未来”，值此之际，**祝贺清华大学110岁生日快乐！**
