# 绿盟科技加入openEuler 社区，助力开源生态建设

近日，绿盟科技签署 CLA（Contributor License Agreement 贡献者许可协议），正式加入 openEuler 社区，绿盟科技将积极参与社区合作，与行业内的生态伙伴共建创新平台，推动行业生态繁荣发展。

  

openEuler是一个开源免费的Linux发行版系统，通过开放的社区形式与全球的开发者共同构建一个开放、多元和架构包容的软件生态体系，openEuler同时是一个创新的系统，倡导客户在系统上提出创新想法、开拓新思路、实践新方案。

  

绿盟科技作为开源产业链中的一员，一直在开源领域里积极探索，并为打造一个安全、可靠的开源环境做出自己的贡献。未来，绿盟科技的安全实验室，将会在openEuler 社区中进行持续地投入和创新。

  

**绿盟科技星云实验室**专注于云计算安全。基于IaaS环境的安全防护，利用SDN/NFV等新技术和新理念，提出了软件定义安全的云安全防护体系。承担并完成多个国家、省、市以及行业重点单位创新研究课题，已成功孵化落地绿盟科技云安全解决方案。在云计算领域，星云实验室会从架构层面关注开源系统的安全性，为开源社区贡献自己的力量。

  

**绿盟科技天机实验室**专注于攻防对抗技术。研究方向主要包括漏洞挖掘技术研究、漏洞分析技术研究、漏洞利用技术研究、安全防御机制及对抗技术研究等。研究目标涵盖主流操作系统、流行的应用系统及软件、重要的基础组件库以及新兴的技术方向，开源系统也是天机实验室重点的研究对象，可以助力开源社区提升开源系统自身安全性。

  

**绿盟科技格物实验室**专注于工业互联网、物联网、车联网三大业务场景的安全研究。致力于以场景为导向、智能设备为中心的漏洞挖掘、研究与安全分析，目前已发布多篇研究报告。在这些新兴领域中，开源的安全性需要格外重视。绿盟科技格物实验室将会围绕这些新兴领域中的安全价值，输出安全研究报告。

  

**在威胁情报领域**，绿盟科技除了在互联网空间测绘、全球恶意资产挖掘、黑客威胁动态跟踪等方面进行深入研究外，也会针对主流开源系统进行威胁情报收集，为开源系统的安全发展提供关键技术支撑。

  

良好的开源环境离不开安全，绿盟科技作为深耕网络安全行业二十余载的安全企业，会继续携手 openEuler 社区成员及合作伙伴，合力打造一个安全、可靠的生态环境。
