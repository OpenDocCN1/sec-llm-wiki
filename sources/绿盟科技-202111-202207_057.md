# 第十五届全国大学生信息安全竞赛创新实践能力赛（东北赛区）圆满落幕

6月18日，第十五届全国大学生信息安全竞赛创新实践能力赛（东北赛区）圆满落幕。本次比赛是由中国互联网发展基金会主办，长春理工大学承办，绿盟科技提供技术支持。长春理工大学副校长付跃刚、计算机科学技术学院党委书记刘博、计算机科学技术学院院长蒋振刚、网络中心主任底晓强、教务处副处长王文晶、绿盟科技集团北区总经理崔鸿、科教文卫本部总经理李永松等领导出席开幕式，长春理工大学计算机科学技术学院院长蒋振刚做会议主持。本次比赛受疫情影响，采用线上赛方式进行，共吸引了来自东北三省的28所高校，共50支队伍参赛。

![](../Images/7cbaac2319da4a9f520b246f62d1f7a6.png)![](../Images/5524117d711674cbfe66db25bb3d93de.png)

“全国大学生信息安全竞赛”主要面向全国全日制在校本、专科学生，旨在通过赛事培养大学生的创新意识，提高大学生信息安全技术水平和综合设计能力、促进高等学校信息安全专业课程体系、教学内容和方法的改革。  

  

在东北赛区开幕式中，长春理工大学副校长付跃刚表示，全国大学生信息安全竞赛创新实践能力赛（东北赛区）是面向东北地区师生的年度赛事，代表了目前东北三省信息安全创新能力实践类竞赛的最高水平和最高规格，旨在激励大学生运用信息安全技术和技能来解决实际问题，激发其学习信息安全知识的兴趣，培养其团队合作意识、创新能力和挑战精神。长春理工大学非常荣幸能够承办本次竞赛，相信通过本次比赛，可以增进与东北各高校之间的交流，活跃大学生的课外科技文化生活，让本次竞赛将成为东北信息安全教育界的一次盛会，为网络安全行业输送高素质人才，为中华民族伟大复兴的中国梦和东北老工业基地的全面振兴贡献智慧和力量！

  

绿盟科技作为东北赛区的技术支持单位，已连续两年参与到大赛支撑工作中。绿盟科技集团北区总经理崔鸿在致辞中表示，绿盟科技很高兴作为支撑单位又一次参与本次大赛。全国大学生信息安全竞赛连续举办了15届，为我国网络安全领域培养、选拔了一批又一批优秀的网络安全人才。虽然受疫情的影响，但本次大赛如期举办，体现了组委会和承办方的领导、专家和老师们对大赛的高度重视和辛勤付出。绿盟科技作为网络安全从业企业，深感责任的重大，将全力做好比赛的技术支撑工作，为大赛保驾护航。

  

本次支撑东北赛区赛事的绿盟网络空间安全仿真平台，是一款专门面向高等院校开展网络空间安全一级学科或信息安全专业建设的一体化解决方案，可以从专业实训授课、实验实践、攻防技能训练等方面，帮助高校培养新安全时代下的攻防实战型人才。在网络空间安全技术创新研究、课题申研等方面，绿盟网络空间安全仿真平台还可以帮助专业教师开展相关科研创新工作。

  

同时，绿盟网络空间安全仿真平台能够通过SDN、Docker、流量仿真、虚实结合、APT知识图谱等技术，帮助高校师生构建网络安全实训、竞技比赛、APT仿真演练、实战攻防演练、攻防武器测试、产品测试评估和技术研究验证等仿真场景，满足高校进行人才培养、攻防演练和测试研究等多方面的需求。

![](../Images/0055d132dccfcbf202e5c7b58df0f1b6.png)![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

据悉，第十五届全国大学生信息安全竞赛创新实践能力赛决赛，将于8月在天津举办。作为本次大赛的重要参与者、技术支持单位，绿盟科技将继续全力支持剩余赛事圆满、顺利的举行。未来，绿盟科技将持续扎根教育行业，在高校网络安全发展、人才培养等领域不断进行探索与实践，助力我国网安产业与人才发展。
