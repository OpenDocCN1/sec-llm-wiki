# 第十四届信息安全高级云论坛来袭 洞见网络安全“转型”战略方向

拥有31年历史的RSA大会（RSAC），作为世界网络安全行业的盛会，每年汇聚来自全球范围的网络安全公司及安全高级专家齐聚旧金山，对当下的安全趋势、挑战、解决方案和创新点进行探讨。

![](../Images/6146133028f932c223fbb21d5835774b.png)

  

2022年不仅是绿盟科技在RSAC连续参展的第十五年，也是自2009年起，绿盟科技参与承办信息安全高级论坛的第十四年。一直以来，论坛致力于为国内网络安全行业打开国际视野，拓展技术领域，它的成功举办将有助推进我国网络安全企业从多角度对比国际网络安全产业发展，激发出大量对我国网络安全产业的思考与建设性意见。

  

“第十四届信息安全高级云论坛暨美国RSA热点研讨”将于7月1日如期举行，本届论坛围绕“转型·Transform”展开。面对复杂多变的国际形势及数字化转型时代下网络安全技术变革新挑战，研讨会将与业内各界人士聚焦国际网络安全趋势及热点，交流中国网络安全新兴的技术和安全实践。

  

七月盛夏，邀您绽放。
