# 绿盟科技入选山东省工业信息安全产业发展联盟数据安全工作组特邀单位

近日，为贯彻落实《工业和信息化部办公厅关于做好工业领域数据安全管理试点工作的通知》要求，探索构建山东省工业领域数据安全管理机制，有效保障工业领域数据安全，提升行业数据安全防护水平，山东省工业信息安全产业发展联盟启动了 “数据安全工作组成员单位征集工作”，**绿盟科技****凭借在工业互联网安全领域的多年实践研究经验**，**成功入选山东省工业信息安全产业发展联盟数据安全工作组特邀单位**。

![](../Images/c28373b5d8ed578a6fe76a3f2742842a.png)

同时，**在山东省工业和信息化厅发布的“2022年度山东省工业领域数据安全优秀产品、服务和应用解决方案名单”中，绿盟数据泄漏防护系统——网络防护系列、工业领域数据安全分类分级服务、工业互联网数据安全监测平台成功入选。**

![](../Images/d73e28f0498357fd36a702ea201a023f.png)![](../Images/304070a950c280e922040609efee7591.png)![](../Images/522cc35f1a6e001f46f0c93bd444fa2a.png)

绿盟科技依照《数据安全法》的要求，以“智慧安全3.0”理念为依托，基于一个中心、四个领域、五个阶段的数据治理思路，以“知、识、控、察、行”的数据安全治理方法论为抓手，通过采用人工服务+技术工具+防护监测引擎等多维数据关联融合的新技术方式，构建工业互联网数据安全运营平台，贴合客户需求，形成场景化的工业互联网数据安全解决方案，实现工业领域数据分类分级、风险评估、安全防控、追踪溯源、持续运营，达到“全面防护，智能分析，自动响应”的数据安全防护效果。让数据所有者看得到风险、让数据使用者看得到约束、让服务运营者看得到策略，有效的应对数据安全风险与挑战，满足数据安全合规要求，在保障数据安全的同时让数据价值最大化。

![](../Images/ca70cbae2311959242b2c2bfc3d8313a.png)

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

未来，绿盟科技将继续加大在工业互联网和数据安全领域的研究力度，秉持“巨人背后的专家 保障客户业务顺畅运行”之使命，以自身丰富的技术经验为依托，推动行业交流和网络安全建设，为网络强国战略提供有力保障。
