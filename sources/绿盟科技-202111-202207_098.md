# 绿盟科技助力贵州省铜仁市首届“场景大数据·电信杯”网络（数据）安全技能竞赛圆满结束

近日，由贵州省铜仁市委网信办、市大数据局、市总工会主办的全市首届“场景大数据·电信杯”网络（数据）安全技能竞赛在南长城大酒店圆满结束。绿盟科技作为独家技术支撑单位，全程提供技术支持，助力大赛圆满举办。

![](../Images/e2962135ac921ef0c5ede863cc898e63.png)

本次大赛旨在贯彻落实网络（数据）安全法律法规，加强互联网知识和技术的普及，发现培养更多高技术人才，推动建设知识型、技能型、创新型网络（数据）安全人才队伍。为铜仁市深入实施推动网信事业高质量发展提供强有力的人才保障和技能支撑。

  

此次比赛采用了线上初赛、线下决赛的模式进行。线上初赛以“个人线上理论答题”+“CTF线上夺旗赛”形式开展，其中“个人线上理论题”150道共150分，包括单项选择题、多项选择题和判断题3种题型；“CTF线上夺旗赛”由参赛人员通过互联网访问在线部署的竞赛平台进行解题，每道赛题均内置1个Flag，选手解题得到Flag后提交至相应服务器即可获得相应的分数。比赛结束后1小时内，选手需提交每道赛题详细的解题报告（WriteUp）。

![](../Images/823cf73a20a7086fcfed08cee7f6d1fc.png)![](../Images/c7d46d95ee76d36ec999aaf60a6e9f4e.png)

比赛共吸引了来自全市各参赛单位的159名选手、39支团体队伍展开了激烈的线上角逐。最终，30名个人选手、12支团体队伍进入线下决赛。

  

在决赛个人赛中，比赛从上午九点一直进行到下午一点半，时长3.5小时。比赛按照"CTF夺旗赛"解题模式（Jeopardy）进行，内容包括安全理论及实践技能两方面内容，并采用动态计分的方式，第一个选手的赛题分数为满分，解题越慢得分越低，直至设置的最低阈值（满分100分，阀值设置为50%），既展现了选手们专业知识积累，也反映出了选手的实操能力。

![](../Images/4577b69cc6a24808810f374486068325.png)

铜仁市委常委、市政府副市长闫晓青率队参观个人赛比赛现场图

在团队决赛现场，12支团代表队各自加固自身系统防守，同时寻找其他队的弱点相互攻击。每个队的基础分为1000分，攻击或防守成功得分，反之则扣分，且分数不上线最低分为0分。现场的大屏幕上显示着攻击的影像不断变化，大家有来有往，比赛异常激烈。  

  

“举办这次比赛的目的是提高各单位对网络和数据安全的重视程度，通过搭建平台让大家进行技术交流，并挖掘和培养一批安全人才，从而提升全市的网络和数据安全保护能力，为我市发展数字经济保驾护航。”铜仁市大数据发展管理局科长高波说。

  

此次竞赛的举办，是贵州省铜仁市网络（数据）人员素质的一次集中展示，绿盟科技为铜仁市培育和提升全市重要部门技术人才提供了平台支撑，对于铜仁市实施数字化战略，发展数字化经济，推进场景数据化在铜仁走深走实，提供了强大的网络安全保障能力。
