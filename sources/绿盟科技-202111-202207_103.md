旧金山时间6月6日至6月9日，RSA2022在旧金山Moscone中心正式启幕。今年大会以“Transform”为主题，聚焦“转型”相关的元素对网络安全产生的影响。

2022年是 RSA 大会的第31届，也是绿盟科技连续参加的第15年。2022年，绿盟科技以“Trusted Partner To Fortune 500 & Top Telcos”为主题，携数款绿盟科技国际市场拳头产品亮相RSA2022展会。绿盟科技凭借在安全产品研发及技术革新方面的多年积淀，持续在国际网络安全市场发出属于中国网络安全企业的声音。

**绿盟国际云安全服务全新升级**

绿盟科技深耕网络安全行业22年，潜心技术研究和市场分析，适应行业发展趋势和用户需求变化，在国际市场推出全新升级的绿盟国际云安全服务（NSFOCUS Cloud Security Services）。本次升级将为客户带来云Web应用程序和API防护服务（Cloud Web Application and API Protection Service）、网站安全监测服务（WebSafe Service），这两项新服务将同原有国际云清洗服务（Cloud DDoS Protection Service ）一起为拉美、西欧、亚太及中东非洲区域的运营商、服务提供商、银行、企业、政府等客户提供更完善的一站式应用及网络防护。

  

**国际市场拳头产品现场一览**

**绿盟国际云清洗中心（Cloud DPS）**

绿盟国际云清洗中心旨在最大程度上为用户提供云端DDoS防护服务，根据攻击量和持续时间灵活调整部署，通过在全球布局多个清洗中心，实现近源清洗DDoS攻击流量，并通过Anycast技术提供优质的网络链路，最终形成了现在可以进行多地联动，近源清洗的防护体系，有效保证了客户对低延时的需求。同时整合云清洗和本地设备的能力，实现全自动的云地清洗切换，可以抵御流量超过T级的DDoS攻击。绿盟国际云清洗中心不仅可以为小型企业用户解决大流量攻击的问题，同时也为一些在本地拥有抗DDoS设备的企业提供服务，作为本地清洗的备援服务，是应对大流量攻击的关键手段。配合绿盟科技提供丰富的运营服务及技术探索经验，建立了一支反应速度快、技术能力好、应变能力强的安全运营团队。可以在短时间内帮助用户解决DDoS攻击问题，全天候监控保证用户业务可用性。这一创造性的服务模式解决了诸如本地用户带宽不足、安全人员缺失、基础设施建设投资需要等一系列问题，让用户不论通过电脑Web还是手机APP都可以一键清洗、一键查看，防护无忧。

  

**绿盟抗拒绝服务系统（ADS）**

绿盟抗拒绝服务系统基于机器学习建模、交互式动态防护算法、行为模式分析等先进技术，能够精准高效阻断网络层、应用层各类DDoS攻击，使得用户合法业务正常通行，满足用户在各类复杂网络环境中对于Web网站、支付系统、游戏、音视频、移动APP、DNS服务器等重要业务系统和关键基础设施的防护，保障业务可靠性和连续性。在应对大规模流量攻击时，绿盟抗拒绝服务系统还可实现业务自动切换上云，避免本地带宽因大流量阻塞而影响全面业务。依托精准全面的攻击识别能力、电信级的功能防护性能和灵活的应用部署方式，绿盟抗拒绝服务系统在国内国际一线运营商、大型金融、互联网、游戏等行业得到了广泛部署应用，每年成功帮助用户防护上千万次DDoS攻击，保障用户免受DDoS攻击引起的经济和名誉损失。

  

**绿盟科技网络流量分析系统（NTA）**

绿盟科技网络流量分析系统是一款基于Flow流/镜像分光技术的流量分析和DDoS攻击检测产品。不仅可以通过流量分析能力帮助用户掌握网络情况，优化业务服务质量，还能在发现异常攻击事件时，发出告警并提供多种处置方式缓解攻击。适用于运营商、数据中心、金融、企业等多个行业的异常攻击检测场景，主要功能包括网络流量日常监控分析、异常攻击流量检测、网内威胁检测等。通过历史信息统计、报表统计等能力，助力用户快速发现网络瓶颈，合理优化网络结构。产品部署灵活，支持软硬件两种部署方式，同时适配各主流公有云环境。可联动绿盟抗拒绝服务系列产品组合形成针对流量的分析检测、告警处置和溯源追踪多种解决方案。

  

**绿盟抗拒绝服务系统管理中心（ADSM）**

绿盟抗拒绝服务系统管理中心联合清洗设备ADS、检测设备NTA形成三位一体的抗DDoS解决方案。主要功能包括集中管理、报表整合、分域自治及自助终端等。通过将检测和清洗设备的数据进行整合并管理，形成高效清洗、简化运维的抗DDoS解决方案。对于集中管理需求最为旺盛的运营商客户，ADSM可提供分域自治、portal终端等针对性功能对客户需求进行覆盖，并始终致力于提高易用性，不断提升产品竞争力。

  

**绿盟流量清洗业务运营系统 （ADBOS）**

绿盟流量清洗业务运营系统是一款以DDoS攻击检测、清洗为底层能力的抗D管理、运维及增值运营一站式综合平台，致力于为大型服务提供商、云厂商等提供云化服务的业务管理、运营交付、快速响应等能力。平台通过设备集中管理、多点业务拨测、一键牵引调度等方式，使部署在不同节点的流量清洗设备和检测设备可以进行集中运维，实现资源最大化利用，平台基于用户视角和资源视角双覆盖的纵深权限模型实现多租户的分权分域，提供运维管理页面、租户访问页面和手机APP，简化运维难度，提升运营效率，从而实现设备可管理、服务可视化、运维智能化、操作自主化的多层次增值运营体系。

  

**绿盟下一代WAF**

绿盟下一代WAF是集Web安全、Bot管理、DDoS防御和API保护为一体的智能防护系统，保障Web业务和API应用不受已知和未知威胁。不仅拥有API识别、基线合规、威胁检测能力，帮助客户梳理API资产，识别API漏洞，保障API安全；还支持BOT的识别，可识别好坏BOT, 减少自动化工具带来的经济和名誉损失；同时，支持云原生&容器化WAF，可贴身防护K8S架构下的微服务业务；支持WAF集群方案、对业务“零”影响的插件式部署方案，有效保障大流量场景下的高可靠和可扩展性。

  

绿盟科技第一款WAF自2008年国内发布以来，已被超过5000家机构选中，受到运营商、金融、教育、政府、能源、企业等行业头部客户青睐。同时，为美国、日本、澳大利亚、迪拜和东南亚多家客户提供产品和服务，并与超过130家渠道建立合作伙伴关系。

  

绿盟下一代WAF获多个国际权威机构认可：不仅连续十年位列Frost&Sullivan大中华区市场前三，连续三年获得IDC中国硬件WAF市场占有率第一，还连续四年入选Gartner魔力象限，入选Gartner WAF魔力象限亚太版（2018年），并于2021年入选Forrester Now Tech报告，成为唯一进入国际市场中等收入阵营的中国安全厂商。

  

**绿盟科技威胁情报（NTI）**

作为绿盟科技智慧安全3.0战略的重要组成部分，绿盟科技威胁情报依托公司专业的安全团队和强大的安全研究能力，对全球网络安全威胁和态势进行持续观察和分析，以威胁情报的生产、运营、应用等能力及关键技术作为核心研究内容，推出了绿盟威胁情报平台及一系列集成威胁情报的新一代安全产品，为用户提供可操作的情报数据、专业的情报服务和高效的威胁防护能力。

  

绿盟科技威胁情报依托公司在安全领域的长期积累，具有极大的丰富度和覆盖度。基于绿盟大数据分析平台，结合安全情报专家对情报数据进行深度挖掘分析，获得高质量的多维度威胁情报，覆盖网络资产基础信息、指纹、漏洞库、TTP、高级威胁分析结果等不同层面。通过NTI Portal界面、API接口、订阅推送等不同输出方式将威胁情报与安全设备、客户和安全厂商进行共享，有效保护客户安全。
