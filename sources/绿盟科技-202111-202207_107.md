# “中国芯”更安全｜绿盟数据库审计系统（DAS）获得鲲鹏Validated认证

近日，绿盟数据库审计系统（DAS）获得鲲鹏Validated认证。绿盟科技与鲲鹏联合创新中心基于鲲鹏基础架构，合打造了绿盟数据库审计系统-鲲鹏版。该版本使用鲲鹏应用使能套件BoostKit，基于鲲鹏软硬件底座进行全栈优化。对比传统数据库审计系统的数据库流量吞吐性能，提升120%。性能的大幅度提升，更好的提升了数据库安全监管能力，加快了对数据库安全事件的响应速度，更加精准定位了安全风险。

![](../Images/a25bd8c18f3db0d2a1a13f11938f3791.png)

  

绿盟数据库审计系统（DAS）基于数据库网络流量采集，数据库协议解析与还原技术的安全审计类产品。通过对访问数据库行为进行记录与多角度分析，对异常行为进行告警通知、审计记录和事后追踪分析。帮助用户规范数据使用行为，保障数据资产安全。

  

绿盟数据库审计系统-鲲鹏版基于鲲鹏硬件产品、BiSheng JDK，采用鲲鹏BoostKit加速套件在多个维度进行了深度调优。

![](../Images/68b477b0fc29e6b0cffebca337a641a4.png)![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

未来，绿盟科技和华为将进一步开展基于鲲鹏以及生态合作伙伴的应用实践，实现在业务和技术等多方面的合作，共同推进我国各行业数字化转型，为企业级客户保驾护航。
