# 担当责任，守护安全｜绿盟科技获公安部感谢信

近日，公安部为绿盟科技发来感谢信，对绿盟科技在2021年公安部网络安全专项行动中给予的大力支持表示感谢。绿盟科技对此次活动高度重视，组织专业力量，调动资源全面支撑，圆满完成任务。

![](../Images/a9d51a2a1090359d40de216746073ddf.png)

  

此次由公安部组织的网络安全专项行动，是专门针对国家关键基础设施领域开展的安全检查工作，绿盟科技作为网络安全企业参与了此次任务。

  

绿盟科技依托专业的保障团队，整合绿盟科技威胁情报运营能力、安全预警和处置能力、产品平台支撑保障能力以及应急响应和安全研究能力，紧密围绕行动任务，提供恶意样本、攻击线索等威胁情报数据，为公安部工作提供重要参考数据。

  

同时，绿盟科技组织技术支撑人员配合属地公安机关赴相关单位开展现场检查，排查办公终端情况，提高专项行动工作效率；通过绿盟综合威胁分析系统，结合专家研判，提供相关威胁情报全量数据，并针对攻击线索撰写形成多维度的技术分析报告，用“专业精进，值得信赖，责任担当”态度保证了此次网络安全专项行动的顺利进行。

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

关键信息基础设施是国家网络安全战略的核心，作为网络安全行业的一分子，绿盟科技始终以安全运营为中心，落实“全场景、可信任、实战化”的安全原则，从资产、应用、数据、身份四个要素着手，实现“全面防护、智能分析、自动响应”的防护效果，为关键信息基础设施安全保驾护航。未来，绿盟科技将秉承“巨人背后的专家，保护客户业务顺畅运行”之使命，不断探索、持续创新，为加强国家网络安全保障体系和能力建设作出更大贡献。
