# 绿盟科技深度参与2022年漏洞管理平台建设思路研讨会

近日，由中国通信企业协会通信网络安全专业委员会主办、绿盟科技集团承办的“2022年漏洞管理平台建设思路研讨会”在北京召开。**研讨会由中国通信企业协会通信网络安全专业委员会秘书长孟楠主持，中国信息通信研究院安全研究所专家杨刚、中国电信集团网络安全部安全管理处处长刘亚天、中国移动集团信安中心网络安全研发中心副经理董航、中国联通集团信息安全部高级专家林海、绿盟科技集团首席技术官叶晓虎、绿盟科技集团运营商事业部总经理汤旭等领导专家**现场参会，全国各省基础电信网络安全管理人员以线上参会方式听取会议。

  

面对当前漏洞管理工作的形势、挑战和实践，与会专家分别从监管视角、运营商集团视角以及安全厂商视角，对平台行业规范解读、建设思路和方案落地等多个维度进行研讨与分享。

  

中国电信集团网络安全部安全管理处处长刘亚天介绍了中国电信在漏洞治理工作中的实践，表示漏洞治理工作应从事前、事中、事后建立全生命周期的漏洞治理体系，并介绍了电信集团漏洞管理平台的建设现状以及后续建设思路。

中国信息通信研究院安全研究所专家杨刚介绍了国家与行业的安全漏洞监管要求以及两部委考核及专项行动的相关要求，提出了行业网络运营者安全漏洞技术手段愿景和举措。

中国移动集团信安中心网络安全研发中心副经理董航围绕当前全球严峻的网络安全形势以及国内外网络安全的管理要求，分享了中国移动在新形势下的网络安全漏洞处置实践相关思路和经验。

中国联通集团信息安全部高级专家林海围绕资产运营管理进行分享。他提到，通过资产全生命周期安全管控以及常态化漏洞安全检测，并依靠建立内部线上漏洞闭环流程，以及组建漏洞检测及运营团队，形成漏洞台账，实现漏洞统一分析运营管理。

绿盟科技集团运营商事业部行业技术总监雷新从网络安全漏洞运营管理以及行业监管要求的角度，详细介绍了绿盟行业漏洞管理平台。该平台从行业运营者业务和监管需求出发，依托绿盟科技丰富的漏洞研究能力以及基于大数据平台架构下的漏洞发现、漏洞验证、漏洞优先级评估、漏洞处置、处置评估、漏洞运营等全流程漏洞管理能力，实现漏洞全生命周期的管理、漏洞应急闭环管控，以及漏洞的简捷、高效、安全运营。

![](../Images/6e052562aad51191232e3ad7a8e1c53c.png)

  

**绿盟行业漏洞管理平台关键技术能力**

1.  多源漏洞融合：利用本地知识库，对多源异构数据进行融合分析，解决多个漏洞标准共存问题，统一漏洞处置。
    
2.  聚焦优先级分析：基于威胁情报+VPT技术，定位关键风险点，聚焦在可被利用的漏洞上。
    
3.  漏洞精准验证：基于原理的漏洞验证，POC管理，保证处置漏洞的真实有效性。
    
4.  专业的云端情报支撑：依托绿盟威胁情报中心（NTI）多年的威胁情报运营经验，第一时间跟踪到紧急漏洞的爆发，评估受影响的资产，实现快速预警处置。
    
5.  漏洞自动化攻击模拟验证：基于攻防对抗的视角评估资产漏洞的风险，依赖模拟技术漏洞验证手段无损于业务、进一步确认漏洞修复优先级。
    
6.  智能协同监管：模拟监管业务场景、例如重要节假日保障等，编排组织任务及工单，按需加权定制度量评价指标，提前摸底监管考核结果，支持标准接口规范指令交互，数据传输原生实现，无缝对接监管。    
    

  

**核心价值体现**

1.  符合行业合规要求：满足《行业网络运营者漏洞管理平台建设指南》和《行业网络运营者漏洞管理平台接口规范》规范建设要求。
    
2.  漏洞运营更简单：创新的VPT技术，结合资产和情报信息，对全网漏洞进行跟踪，评估修复优先级，跟踪重点资产重点漏洞修复情况，指标化运营，呈现漏洞管理工作成果。
    

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

本次研讨会旨在更好地帮助基础电信运营企业网络安全管理人员和技术人员全面了解当前漏洞管理态势，解读和学习漏洞管理新政策和新标准，交流漏洞管理建设新思路，探讨企业漏洞管理技术思路和趋势，以期推动和保障漏洞管理平台建设工作顺畅开展。未来，绿盟科技也将不断跟踪国内外最新网络安全漏洞研究动向，持续开展漏洞相关研究和分析，为客户提供全方位的漏洞管理平台解决方案能力。
