# 绿盟科技受邀参与《科学数据安全标准体系》等15项团体标准研制工作

近日，由中国信息协会主办的《科学数据安全标准体系》等15项团体标准研制工作启动会暨首次研讨会在京召开。15项标准涉及数据安全管理、安全分类分级、安全防护要求等多个方面，代表着今后我国在包括网络空间安全在内的多领域科学数据，将拥有全新的团体标准。绿盟科技受邀参与了本次科学数据安全标准的研制工作。

![](../Images/3ac556e90395c7bc54949bcb816f3acc.png)

  

科学数据与工业数据、金融数据并称为三大数据，是大数据时代最为重要的数据之一。在科学数据领域，团体标准一直处于空白状态。制定团体标准，对于对保障科学数据安全、构建科学数据生态具有非常重要的意义。

  

据悉，2019年国家重点研发计划“国家质量基础的共性技术研究与应用”重点专项“科学数据安全技术及基础技术标准研究”启动，中国科学院研究计算机网络信息中心联合六个国家科学数据中心依托单位、中国标准化研究院、中国网络安全审查技术与认证中心等共同承担。此次启动研制工作的标准当中，有9项为通用标准，6项是针对具体应用领域的标准。这些标准都来自于国家重点研发计划（NQI），是顺应国家要求将课题进行成果转化，因此每一项标准都很重要。

  

企业单位同样是标准研制工作的重要参与者之一。绿盟科技作为深耕网络空间安全行业二十余年的安全企业，近年来一直高度关注数据安全的建设工作。此次参与标准研制工作，有助于科学数据在网络空间安全产业中的发展。通过完善的标准体系，可以让科学数据的应用更合理、更规范。

  

据了解，各标准制定组将根据会上各参编单位提出的建议和意见进行分析和研究，并对标准草案进行相应修改与完善。今年，还将陆续推出多项团体标准，为将科学数据更好地运用到市场提供规则。
