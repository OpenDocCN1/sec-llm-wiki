# 绿盟科技荣获中国信通院2021年度网络安全保险优秀案例

近日，中国信息通信研究院正式发布“2021年度网络安全保险优秀案例”，本次案例征集活动受到了保险公司、再保险公司、安全服务公司、金融服务公司等产业主体的广泛关注和踊跃参与。绿盟科技提交的《面向中小企业的网络安全保险实践》荣获2021年度网络安全保险优秀案例。

![](../Images/ba8cd120c0e6b699e218ea61548ae1a3.png)

  

随着企业数字化转型的快速发展，中小企业在业务发展过程中虽然主动着手实施信息安全管理体系的建设，但由于经验积累、技术力量和资源配备的不足，对于合规要求的执行和检查，缺少足够的技术支撑，企业信息系统在安全管控方面存在短板。面对上述中小企业现状，网络安全保险这一革新的安全服务模式，可以为中小企业风险管理提供一种全新的思路，即在帮助企业建设安全能力的同时，以保险减轻企业资金负担，也基于保险服务的工作流形成更加体系化的安全能力架构，监控企业安全风险、动态管理安全风险并且形成风险动态闭环。

  

绿盟科技积极贯彻落实工业和信息化部《关于促进网络安全产业发展的指导意见（征求意见稿）》，以“保险+风险管控+服务”为核心理念，以实战化的安全运营和风险管理为支撑，持续探索网络安全保险服务的创新模式。基于客户侧的应用和落地，形成了覆盖全流程的网络安全保险服务机制：事前基于企业安全能力评估、安全意识测评、系统风险评估等开展核保体检，事中通过脆弱性管理、威胁管理、动态监测等实现风险监测，事后利用应急响应、事故鉴证、定损理赔等完成事件处置复原，综合提升企业风险识别和管控能力、突发安全事件应对能力和事后的恢复能力，从而协助企业构建事前识别与降低、事中监控与发现、事后响应与补偿的风险管理体系，形成风险闭环管理的安全运营和风险管理机制。

![](../Images/ca8a192359530615a70082ae7258a1d1.png)

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

相信随着我国网络安全保险顶层设计的不断完善，相关法律政策与标准规范的起草与出台，网络安全保险作为风险管理的最后一环，可成为企业提升网络安全风险治理能力和完善网络安全保护机制的新途径，以传统安全服务和传统金融手段的跨界融合新安全服务模式，指导企业形成更加体系化的安全体系，为企业安全保驾护航。
