# 数据安全认证你有几个？来了解一下

随着数据安全法和个人信息保护法的颁布实施，数据安全相关的职位成为安全行业最热门的岗位之一。数据安全法第二十条规定，国家支持教育、科研机构和企业等开展数据开发利用技术和数据安全相关教育和培训，采取多种方式培养数据开发利用技术和数据安全专业人才，促进人才交流。从业人员通过数据安全领域的培训和认证，掌握相关知识体系和技能，为职业发展带来益处。

  

相关机构很早就开始开展数据安全方面的培训和认证。下图按照“人员能力认证”和“企业安全认证”两个维度列举了国际国内的认证。本文主要介绍国内人员能力相关的数据安全认证情况。

![](../Images/e7a94b428edf3924cbab81f72e242c12.png)

  

**CCSC-数据安全方向认证**

网络安全能力认证（Certification for Cyber Security Competence—数据安全方向，简称CCSC—数据安全方向）是国家互联网应急中心与绿盟科技联合开发的针对数据安全人才的培养认证，本课程通过传授知识（Knowledge）、技能（Skill）、能力（Ability），帮助学员构建数据安全知识框架，掌握数据安全治理工作的核心能力，并在模拟实践中习得实际工作环境中所需的技能，使学员具备在企业中建立数据安全管理体系和防护体系、开展数据安全规划等工作的能力。对准予注册的申请人，国家互联网应急中心会发放CCSC-数据安全管理认证证书。

![](../Images/20f85579e105472103aa472db959d092.png)

  

**CISAW-DSP 信息安全人员认证**

信息安全人员认证-数据安全岗位能力（Certified Information Security Assurance Worker -Data security post capability，简称"CISAW-DSP"）是中国网络安全审查技术与认证中心面向数据安全领域从业人员的技能认证，针对当前数据业务领域突出的安全风险采用的管理与技术方法进行深入阐述，以及时应对实际生产过程的安全挑战。该认证不仅注重理论知识学习，更注重安全实践，以达到学以致用的目的。

![](../Images/713e6e98712a6103af9bb42b49796dd4.png)

  

**CISP-DSG 注册数据安全治理专业人员认证**

注册信息安全专业人员-数据安全治理专业人员（Certified Information Security Professional - Data Security Governance，简称CISP-DSG）是中国信息安全测评中心联合天融信开发的针对数据安全人才的培养认证，是业界首个针对数据安全治理方向的认证培训。证书持有人员主要从事数据安全治理相关工作，具有数据安全治理过程管理、数据安全技术体系设计、数据安全管理体系设计的基本知识和能力。

![](../Images/6a9b0a8e17c27540bf6f6e453c3a3cd6.png)

  

**CSA-CDSP 数据安全认证专家**

数据安全认证专家（Certified Data Security Professional，简称CDSP)是数据安全领域专业认证资质。本课程以数据安全法和个人信息保护法为指导，针对云数据安全、ICT数据安全和新兴热点业务（如AI和 IoT等）的数据安全展开阐述，并结合各类新兴技术的不同场景，给出数据安全架构、安全设计、隐私保护的一般原则和业界最佳实践。

![](../Images/904d3646c03fc69695444918b1cf9567.png)

  

**PIPP 个人信息保护专业人员**

PIPP个人信息保护专业人员（Personal Information Protection Professional ，简称PIPP）是中国电子技术标准化研究院面向互联网、互联网金融、金融、大数据等行业中承担个人信息保护相关工作的专业人员所颁发的专业证书。根据工作领域和实际岗位工作的需要，PIPP分为三类证书：数据保护官（Data Protection Officer）简称DPO，数据保护高级工程师（Data Protection Senior Engineer）简称DPSE，个人信息保护工程师（Personal Information Protection Engineer）简称PIPE。另外，中国电子技术标准化研究院面对企业推出了数据安全能力成熟度评估认证。

  

在数字化转型的大浪潮中，网络安全和数据安全越来越重要。想成为真正的数据安全专家，既要不断的学习积累知识，又要通过实践，获得专业技术能力。数据安全领域的培训和认证，能够加快这个过程。通过认证考试，在工作中不断前行，希望大家都可以成为数据安全专家。
