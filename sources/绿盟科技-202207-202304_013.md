# 北京航空航天大学网络空间安全学院领导一行莅临绿盟科技参观交流

近日，北京航空航天大学网络空间安全学院院长助理张宗洋教授带领教研团队一行莅临绿盟科技北京总部，与绿盟科技集团总裁助理张铭、创新研究院总经理刘文懋、产业合作部总监尤扬、科教文卫事业部售前总监石伟辰等公司领导，共同就探索和发展校企合作的新领域、新途径进行交流座谈。

![](../Images/0b23d66c2ad3e1c68a00833bbb909936.png)

绿盟科技集团总裁助理张铭对公司的发展情况、重点业务规划、发展机遇进行了介绍，创新研究院总经理刘文懋介绍了近年网络安全行业发展的新形势、新趋势和新机遇，围绕人工智能赋能安全、云安全、车联网安全、5G安全等前沿领域内容展开分享。

  

在座谈中，双方在科研项目、技术研究、人才培养等方面达成深度共识，并就如何加强学术交流和教学实践等方面的合作展开深度交流。张宗洋教授对绿盟科技的技术能力和积累表示高度认可，他表示网络空间安全学院高度重视校企合作，经过多年的发展，学校在科技创新、学科建设、人才培养等多方面形成了一定成果，由衷地希望与绿盟科技在产学研融合创新等方面有更深入地合作，充分发挥校企双方优势。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

通过座谈，双方下一步将建立常态沟通机制，搭建绿色通道，促进校企合作成果转化，深化产学研合作，营造产业创新发展生态环境。未来，绿盟科技也将依托自身技术优势和创新实践能力，搭建校企合作平台，充分整合优质资源，积极培养网络安全人才，推动中国网络安全事业的快速发展。
