# 绿盟科技亮相第五届中国智慧医院建设与发展大会

近日，由《中国医院院长》杂志主办，中国医药物资协会智慧医疗分会和《中国医疗器械信息》杂志社联合主办的“第五届中国智慧医院建设与发展大会”在苏州圆满落幕。大会以“新趋势 新效能 新动力——助力医院高质量发展”为主题，汇集全国各级卫生健康行政部门、医疗机构、科研院所等单位的专家、学者、研究人员等，围绕智慧医疗、医院网络安全等议题展开研讨交流。绿盟科技受邀参加本次大会，并分别在主论坛与医院网络信息安全分论坛发表主题演讲。

![](../Images/cc04a56715a90ddf51603306104425ce.png)

绿盟科技集团科教文卫事业部总经理李永松在主论坛上发表了《医疗领域HCPS网络安全的思考与实践》的主题演讲，从人-信息-物理系统HCPS视角分析了医疗领域数字化转型的难点与挑战，并分享了数字化转型背景下的医疗网络安全整体设计思路。

![](../Images/0e3b59168e6dc8707ca236352b2a9e2c.png)![](../Images/c86b80c4b693c00b1024a3ae0b33cb84.png)

绿盟科技集团科教文卫事业部总经理 李永松

随着全球数字化转型的快速发展，多元化的业务场景、复杂多变的IT环境、持续创新的技术，以及数据泄露、勒索病毒、钓鱼等多样的网络威胁演进，导致网络安全风险持续增加。在此背景下，智慧医院应基于实战对抗能力，构建网络安全总体框架。绿盟科技集团科教文卫事业部总经理李永松表示，智慧医院建设与网络安全发展并重。通过借鉴网络安全滑动标尺，形成医院网络安全建设规划。同时，应重点投入主动防御的纵深防御体系建设，加强医院安全监控、处置响应等能力。  

  

绿盟科技智慧医院网络安全建设方案，依据绿盟科技成熟的安全能力，将安全物理环境、“一个中心”管理下的“安全通信网络、安全区域边界、安全计算环境”、安全管理制度、安全管理机构、安全管理人员、安全建设管理、安全运维管理等各个层面的安全需求，全部转化为可以实现的技术防护、安全管理措施，安全运营手段。在满足帮助运营、使用单位的业务系统等保合规的基础上，提升等级保护对象的整体安全防御能力，构建可信、可控、可管的安全防护体系。通过体系化的建设，可帮助智慧医院构建“三级+三线”联防联控7×24安全保障能力，保障智慧医院网络，安全顺畅地运行。

  

在随后举行的“医院网络信息安全”分论坛中，绿盟科技集团首席创新官刘文懋博士则围绕隐私计算技术助力智慧医疗发展展开分享。数据已成为新时期的核心生产要素，在赋能医疗产业水平提升的同时，也为数据安全保护提出了新的要求。如何保证数据在高效使用和流转中的安全性，已成为医疗产业中的新课题。在此背景下，隐私计算应运而生，刘博士介绍了隐私合规的关键技术和面向医疗行业的若干应用场景，以及绿盟科技在保障隐私计算安全性方面的研究和工作。

![](../Images/b2d82fb7c3db1d9ff2a29ad7e7308d49.png)

绿盟科技集团首席创新官 刘文懋

医疗机构可通过隐私计算技术，安全有效地对影像学数据进行多中心数据协作，提高训练样本数据量和质量，帮助医生更好进行辅助诊断。还可实现区域内医疗信息安全共享，以帮助医生更好地对患者进行临床诊疗和指导。同时，医疗机构可利用隐私计算技术，实现“数据可用不可见”的效果，最大化发挥各个医院的数据价值，从而更好地帮助医生进行临床诊断。  

  

在数据合规方面，医疗机构和监管机构可通过基于可信执行环境TEE的数据保险箱实现敏感数据的安全存储和代码的可信执行，从而避免了攻击者未授权窃取数据，也能赋能数据的安全流转、可信租赁和可控销毁等场景。

  

绿盟科技结合隐私计算在科教卫生行业的应用实践，撰写并发布了《隐私计算在科教卫生领域应用白皮书》。白皮书对隐私计算的背景、技术路线、安全风险、生态体系等做了详细介绍和分析，着重介绍了科教卫生行业的数据安全现状以及隐私计算在科教卫生领域的应用实践。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

未来，绿盟科技将继续聚焦隐私计算技术创新，使能隐私计算产业协同发展，激发数据流通新动能。同时，面对新时期医疗卫生产业的巨大变化与发展，绿盟科技将始终砥砺前行，持续助力医疗卫生产业网络安全发展，为医疗卫生产业提供强有力的安全支撑。
