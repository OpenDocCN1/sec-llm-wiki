# 绿盟科技受邀出席中关村网络安全与信息化产业联盟会议并斩获两项荣誉

近日，中关村网络安全与信息化产业联盟召开第二届第五次会员大会，来自全国的联盟成员代表、政府机关领导、行业专家等参加会议。绿盟科技作为理事单位受邀参会，并获得“2022年度联盟工作特别支撑单位”、“2022年度网信技术应用融合发展特别贡献单位”荣誉。

![](../Images/c2db2e2e37610575f9ae244aed7134dc.png)![](../Images/0e4f39bd04a10a3df16622d1a5a81bbc.png)

一直以来，绿盟科技充分响应网络安全领域面临的新形势，不断深耕细作，以持续的技术创新和产品研发，积极参与、配合联盟各项工作，双方在产业调研、技术交流等方面进行深度合作，建立起深厚的合作关系。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

此次获得两项荣誉，是对绿盟科技参与联盟工作的肯定与认可，下一步，绿盟科技将继续发挥理事单位的职责作用，依托联盟搭建的优质行业平台，加强深度交流与合作，助力资源共享，推动网信产业高质量发展，为维护国家网络安全工作贡献力量。
