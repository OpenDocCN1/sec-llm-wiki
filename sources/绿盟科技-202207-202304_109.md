# 深植红色基因｜绿盟科技集团党委荣获2022年度海淀区两新组织“党建强、发展强”品牌项目

近日，海淀区以“学习贯彻二十大 奋进时代新征程”为主题，举办海淀区两新组织“红领”党建主题活动暨“红领杯”两新党建业务大练兵总决赛。现场北京市委“两新”工委正式公布“党建强、发展强”党建品牌项目评选结果，绿盟科技集团党委“青春绿盟+党建融合业务发展”荣获**2022年度海淀区两新组织“党建强、发展强”品牌项目**，绿盟科技集团党委副书记肖蓬获评**2022年度海淀区“两新”组织优秀党务工作者**。

![](../Images/a2c213335ea0153cf8ec11287f67b107.png)![](../Images/1471b90fac4c05d87564f3706f8f6d25.png)

两新组织是指新经济组织和新社会组织的简称。近年来，海淀区“两新”组织在党的领导下，创新开展两新党建“红领”计划，旨在让红色基因深植企业高质量发展全过程。作为扎根海淀沃土的安全企业，绿盟科技牢牢把握“党建引领，推动发展”的工作思路，推动业务发展与党建工作实现“同频共振”。

![](../Images/c33abc9834ed5c381e5177e3c3d2b39e.png)![](../Images/ed90609a6c2f09cd9dc61284618c701e.png)

绿盟科技集团党委于2021年7月1日成立，此前作为绿盟科技党支部组织党建工作有15年的时间。一直以来，绿盟科技坚持在党的领导下扎实做好新时代网络安全工作，着力打造绿盟科技“青春绿盟+党建融合业务发展”品牌项目，强化青年党员平台思维和生态思维，引导青年党员在服务群众一线守初心、重实干、强根基方面开拓新思维，摸索新做法。推动以政治引领实现业务跃升，以党建活动融合企业业务，以网安科普深化党群关系，以实际行动回馈社会发展。  

  

在党委书记胡忠华的带领下，绿盟科技集团党委不断发挥“两新”组织带头示范作用，把党的方针、政策落实到各项工作中，在党组织建设、党建品牌建设、党员学习等工作中持续发力，推进业务学习与交流齐头并进，实现以强党建引领强发展，以强发展回馈强党建。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

未来，绿盟科技将继续发挥党委的政治核心和引领作用，以共同学习提升能力水平，以企业自身的高质量发展助力海淀经济再上新台阶，让党建融合业务发展，让青春“绿盟＋”守护网络安全。
