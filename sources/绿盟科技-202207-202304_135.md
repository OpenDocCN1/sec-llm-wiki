# 绿盟科技荣获CCIA 2022年度“先进会员单位奖”和数据安全工作“突出贡献奖”

近日，中国网络安全产业联盟（CCIA）针对2022年度对联盟工作做出积极贡献的会员单位进行了表彰。绿盟科技荣获2022年度“先进会员单位奖”和数据安全工作“突出贡献奖”。

![](../Images/1bad4ea598cd933723b742470d35dc3c.png)![](../Images/2d52e37f672fb88589187a7c45138d5c.png)

中国网络安全产业联盟（CCIA）由中央网信办网络安全协调局指导，旨在聚合产业势能，营造良好产业发展环境，促进产业创新发展，为推动网络安全产业做大做强，提升中国网络安全产业竞争力提供有力支撑。  

  

绿盟科技作为联盟的发起单位之一，积极投身参与联盟的筹备工作，公司也成为首届理事长单位。从2016至今，绿盟科技积极参加联盟组织的各项工作，为产业的发展献计献策，致力于中国网络安全产业良性健康发展，打造清朗网络空间，持续做出努力。

  

2022年度，绿盟科技多次荣获CCIA荣誉表彰，并参与多项工作：

  

\*CCIA发布《中国网络安全产业分析报告（2022年）》，绿盟科技位列2022年中国网络安全竞争力50强，并参加2022网安强星企业深入报道；

\*绿盟漏洞全生命周期解决方案荣获CCIA 2022年网络安全优秀创新成果大赛三等奖；

\*参与CCIA牵头的《网络安全产品互联互通》系列标准并参与试点工作；

\*参编CCIA《网络安全技术和产业动态》供应链安全专报，并承办“聚焦攻防趋势，探讨安全热点”为主题的技术沙龙。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

未来，绿盟科技将持续发力数据安全领域，努力推进网络安全产业环境进一步改善，与各单位团结在一起，提升网络安全产业的竞争力，为实现网络强国战略贡献自己的一份力量。
