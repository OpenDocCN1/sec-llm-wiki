# 绿盟科技获评“证券期货业风华正茂科技人·最美科技团队”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYyMTM4MA==&mid=2650435717&idx=2&sn=f13cd9efc38b3b0bec6dddbf4897d0c5&chksm=bec9292e89bea0388487226c01b9423160d8f6e5c77ce64524c3a1ca4a8001d949d20c369129&scene=126&sessionid=1681372277#rd](http://mp.weixin.qq.com/s?__biz=MjM5ODYyMTM4MA==&mid=2650435717&idx=2&sn=f13cd9efc38b3b0bec6dddbf4897d0c5&chksm=bec9292e89bea0388487226c01b9423160d8f6e5c77ce64524c3a1ca4a8001d949d20c369129&scene=126&sessionid=1681372277#rd)

由中国证监会科技监管局指导，中证信息技术服务有限责任公司组织开展的“证券期货业风华正茂科技人”团队视频展示活动，经公开征集、投票评选，结果于近日正式揭晓。绿盟科技报送的团队展示视频，获评“2022年证券期货业风华正茂科技人·最美科技团队”作品。该评选是中国证监会科技监管局《关于开展2022年“证券期货业数字化转型主题宣传月”活动的通知》的安排，绿盟科技获此荣誉，是证券行业对绿盟科技品牌的充分认可。

![](../Images/d04a9b973defdf6f68efaa688be501c1.png)

（点击观看视频）

  

随着证券行业高频复杂的业务场景对业务系统交付速度的要求不断提升，如何保证业务高效连续性的同时，感知和抵御无处不在的信息安全风险，成为证券机构数字化转型面临的一项挑战。依托深厚的技术积累和高品质的创新能力，绿盟科技20余年对证券行业信息安全领域开展深入研究，并持续跟踪信息安全发展趋势，不断地洞察和分析证券、基金、期货等证券行业客户在信息安全方面所面临的风险、威胁；在电子银行整体安全防护、移动金融交易安全、网上证券防盗买盗卖、网上保险交易、金融云安全建设与防护、金融企业数据中心安全防护、金融数据安全、网络安全保险等具体业务场景不断推出适应安全需求的产品和解决方案；在企业安全能力建设、企业数据安全咨询、企业安全度量、应用开发安全、员工安全技能培训和安全意识教育等运维和管理方面提供专业的体系化安全运营服务。  

  

绿盟科技还拥有一支长期研究攻防技术的应急响应团队，实时跟踪全网安全动态及证券行业突发的安全问题，凭借积累20余年的安全服务能力和安全事件处置经验，通过覆盖全国的专业服务人员和云端专家团队的快速响应，面向全行业提供7×24小时的本地与远程响应，协助客户抑制损失，定位源头，根除隐患，恢复业务；为客户提供弹性高效、全面防御、运营闭环的安全保障。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

经过20余年在证券行业的辛勤耕耘，绿盟科技已获得包括监管单位、核心机构、经营机构等百余家证券行业用户的一致认可。作为巨人背后的专家，绿盟科技将一如既往以创新精神、领先技术、优质产品、专业服务，在全球范围内，提供基于自身核心竞争力的企业级网络安全产品、安全解决方案和安全运营服务，为证券行业的发展提供坚实有力的信息安全保障。
