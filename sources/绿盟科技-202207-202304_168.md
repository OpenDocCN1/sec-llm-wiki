# 探讨前沿｜清华-绿盟研究中心促进产学研融合

近日，由“清华大学网络研究院-绿盟科技集团未来互联网安全联合研究中心”主办的网络安全技术分享会成功举办。会议由清华大学网络科学与网络空间研究院李宗鹏教授主持，绿盟科技集团首席创新官刘文懋博士进行在线分享。来自清华大学网络科学与网络空间研究院的几十位师生参与了本次活动。

![](../Images/c8548886f23a8ee6d618e02fd7826f70.png)

  

**紧贴产业，夯实产学研深度融合**

本次分享是清华大学网络研究院与绿盟科技集团成立联合研究中心的第一次较大范围内的技术交流, 旨在落实今年10月双方在产学研融合创新领域的相关合作工作，共同助推高层次人才培养和联合研究。  

  

绿盟科技集团首席创新官刘文懋博士介绍了近年网络安全行业发展的新形势、新趋势和新机遇，围绕云原生安全、人工智能安全、隐私计算和物联网安全等前沿领域内容展开分享。

  

刘文懋博士从今年的热点网络事件开始，介绍了网络安全的前沿趋势，指出了网络安全与地缘政治的相关度日益紧密，有针对性的高级持续威胁不断曝光；而高级威胁等安全事件曝光漏洞的武器化又引发了大规模的网络攻击，如勒索软件、数据泄露层出不穷。网络攻防实战化成为显著趋势，与此同时，国家层面的合规性驱动、多源异构安全能力融合、基础设施云化趋势也在深刻地改变安全防护体系的整个地貌。这些产业界新兴的变化，也激发了同学们的兴趣，产业新动态与学术新技术的结合，正是创新的源动力。

  

网络安全是一个细分领域众多的行业，在一些具体领域，刘博士也介绍了产业界的新进展。如在云原生安全方面，刘博士介绍了云原生完整的生态体系，针对新的系统环境，入侵检测、API安全、微隔离等技术不断演进与变革。此外，云安全的相关技术也应用到了5G和边缘计算等新型基础设施的安全。在人工智能领域，刘博士深入浅出地介绍了网络安全为什么需要可信的人工智能，以及人工智能在企业与云端安全运营中的应用，以及学术界在应用知识图谱、图神经网络进行攻击溯源和推理方面的研究热点。在数据安全领域，刘博士提醒同学们需要关注政策红利对于数据要素流通的刺激作用，但同时法律法规对数据合理使用提出了严格的要求，因而要重点关注如何运用技术解决数据安全场景中的实际问题，如数据可用不可见、数据脱敏及评估等。此外，刘博士结合了绿盟科技与清华大学的一些共同研究关注点，如网络空间测绘、物联网威胁分析、DDoS等重点问题，进行了详细的技术分享，并展示了绿盟科技研究院在产业界的顶会、学术顶刊上发表的工作。

  

随后的交流环节，参会人员围绕本次技术交流所涉及的核心问题展开热烈讨论。同学们在会后表示刘文懋博士的报告内容重点突出，简洁清晰，让他们对网安行业的前沿动向有了更深刻的理解。有老师表示，后续希望就一些热点方向展开合作研究。

  

**理论支撑实践，助推产学研融合创新形成合力**

近年，绿盟科技一直积极响应国家号召，努力承担起国家网络空间安全捍卫者、网络强国建设者、网络空间安全人才培养者的职责、使命。通过产学研融合创新、资源优势互补、校企协同育人等培养模式，为我国打造一支理论功底扎实、解决实际问题能力强、具有宽广国际视野、适应新时代需要的高层次、复合型网络空间安全人才队伍而不断努力。  

  

经过不断地探索与实践，逐渐形成了一条“以研为源，驱动网络安全技术创新能力提升”、“以学为基，引育网络安全精英人才”、“以产为本，促进网络安全治理体系与能力持续提升”的产学研融合创新之路。

  

目前，已先后与包括清华大学在内的200余所顶尖院校形成合力，在多元化安全技术研究、师资队伍能力水平提升、专业课程体系建设、强化网络安全普及教育等多方面展开深度合作，共同探索产学研融合创新模式。每年可为产业输送**10000余名**高素质网络空间安全人才，覆盖**千余家**企业。

  

绿盟科技还作为校企实习基地，吸纳了众多安全人才进入企业研发团队中来，帮助高校培养更有“战斗力”的专业人才。不仅锻炼了学生们的实践能力，也加速了联合研究成果在项目与产品中的应用，让专业人才和企业共同成长。

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

面向新时期，面对新征程，绿盟科技将持续聚焦产学研融合创新，充分发挥好院校与企业的优势，不断创新协同育人模式，促进教育链、人才链与产业链、创新链有机衔接，为技术创新、为建设高等教育强国作出新贡献！
