# 绿盟下一代WEB安全防护解决方案荣获 CCIC 2022年度通信产业金紫竹奖

近日，作为通信产业年度方向标活动，由通信产业报社主办的2022中国通信产业大会暨第十七届中国通信技术年会、第二届工业互联网金紫竹峰会圆满落幕 ，大会以“共赢主航道：面向数字经济的能力与创新”为主题，邀请主管部门领导、业界大咖、运营商和产业链企业高管、资深专家齐聚一堂，直面大变局下行业创新与企业机会，共享行业专家与企业领袖智慧，为行业企业发展提供决策支撑与商业判断。大会期间，重磅发布了2022通信产业年度十大事件、2023通信产业十大技术趋势以及年度通信产业金紫竹奖项。

  

绿盟下一代WEB安全防护解决方案成功摘得通信产业金紫竹奖--2022年度优秀产品技术方案。

![](../Images/15892f271569185288d1e54491200e50.png)

绿盟科技下一代WEB安全防护解决方案，从WEB应用及API出发，基于用户面临的Web漏洞利用、资源滥用、资源访问控制等多方威胁，提供包含DDoS防护、Bot流量管理、WAF、API防护于一体的协同解决方案，升级整体安全架构，保障企业用户的Web应用安全、业务安全、数据安全，为用户提供端到端的全面防护。

  

方案横向扩展覆盖数字变革下的全新服务提供场景，对外解决身披“合法身份”进行账号接管、黄牛党、薅羊毛这些引发敏感数据泄露、业务过载，以及造成的客户经济、声誉双重受损的问题；对内帮助客户梳理API资产，分类安置，基于不同的API类型，按行为、按上下文逻辑，在合规检测的基础上、解决API控制、防护等多方面问题。同时，方案组合后，还具备攻击意图分析，攻击行为分析等能力，全面评估业务系统网络、业务安全风险。

  

纵向延伸DEVOPS及云化带来的环境变更，识别新需求，跟进新难点，保持前瞻性。适配最新服务网格架构，轻量级、无感知，融入微服务应用，安全防护贯穿南北与东西。落地DevSecOps供应链安全，与SCA等组件审计配合，增加全量的API调用，支持接收防护组件的名称、版本，从而生成对应的精准防护能力。

  

在云化部署方面，该方案可以支持多种部署方式适配客户不同成熟度的云原生环境。无论是基于K8S架构下的透明引流方式或是service mesh下的sidecar部署，该方案都可以贴合业务特点进行安全防护。基于微服务，该方案可以精准的为不同微服务提供不同的防护策略，同时提供全方位（南北向、东西向）流量的防护能力。

  

在API安全方面，绿盟科技下一代WEB安全防护解决方案可以根据业务流量自动学习API资产，生成API列表，也可对API资产进行导入导出，帮助客户识别和梳理API资产；针对重要业务的关键API，还支持OAS合规检测，通过设置API参数的有效范围、长度等，有效防范API资产的注入攻击及溢出攻击风险；针对OWASP API TOP 10的攻击类型，我们可提供规则+语义等多维度的检测机制，有效识别和拦截网络中的已知、未知威胁。

  

在BOT防护方面，在面临黑产的自动化攻击，绿盟科技下一代WEB安全防护解决方案集成了BOT动态防护的能力。一方面，通过下发JS脚本对非浏览器行为进行识别和处置；另一方面，可以通过令牌认证、页面元素混淆、提交数据混淆等方式进行身份验证及数据混淆。此外，还支持基于业务视角对攻击者意图、攻击路线、攻击时间、业务所受影响等进行可视化展示，帮助客户将安全能力转变为实际业务价值。

  

绿盟科技下一代WEB安全防护解决方案可以覆盖各行业的WEB业务的安全防护场景，包括但不限于如下行业。

**金融行业**

提供API资产识别，基于生成的API基线，提供非法API调用防护、API接口滥用识别处置、API流量异常监控告警。全面助力开放银行，拥抱API经济业务场景发展。  

**运营商行业**

辅助监管机构，严厉打击黑灰产团伙批量开卡行为，打击网络诈骗行为；解决营销活动薅羊毛、撞库、恶意注册所带来的声誉下降及经济损失。支撑重大安全演练，有效进行策略布防，溯源反制。  

**科教文卫**

降低基础设施运作成本，有效解决民生就医问题，黄牛党自动化抢号、医患个人敏感信息爬取；防患教学资源爬虫，解决非法贩卖师生信息，有效降低高校面临的声誉风险。  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

绿盟科技下一代WEB安全防护解决方案技术能力领先，获得国内外多家权威机构的认可。它在国际咨询机构Gartner的WAAP全球魔力象限被荣誉提及，在22年最新报告中，成为国内唯二厂商获得单独荣誉介绍；也入选全球权威咨询机构Forrester 《Now Tech:Bot Management,Q4 2021》报告、《Now Tech: Web Application Firewalls, Q2 2022》报告；并入围2022年CCIA 网络安全创新解决方案。
