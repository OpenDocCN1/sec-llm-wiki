# 绿盟科技集团党委书记、总裁胡忠华荣获首届“安全可信领军人物”

为落实《网络安全法》、国家等级保护制度和国家关键信息基础设施保护条例要求，进一步促进可信计算产业生态快速发展，引领成员单位在主动免疫可信计算核心技术上取得突破，加快安全可信的产品和服务推广应用，在中关村可信计算产业联盟成立八周年之际，举办首届“安全可信领军人物”等评选表彰活动。  

  

评优活动自启动，得到会员单位的普遍欢迎和积极响应。报奖推荐渠道由科学技术指导委员会院士提名推荐及联盟专委会提名推荐。历经5场专家评审会和1场媒体评审会，绿盟科技集团党委书记、总裁胡忠华从37位企业家中脱颖而出，荣获首届“安全可信领军人物”。

![](../Images/4865c38ef75a53d0043e41d9b502b9f6.png)

  

绿盟科技高度关注可信动态及进行相关技术研究，专注于安全可信相关产品的研发。积极推动构建安全可信产品的安全保障体系建设。依靠在安全领域多年的积累，以安全产品及平台为抓手，研制出了基于可信3.0的安全解决方案。该方案以密码为基因实施身份识别、状态度量、保密存储等功能，可及时识别“自己”和“非己”成分，从而破坏与排斥进入系统的有害物质，极大地提高了网络信息系统的免疫能力。

  

同时，绿盟科技还与行业翘楚强强联合，安全可信系列产品已先后与申威、飞腾、鲲鹏、兆芯、海光、麒麟软件、统信等进行全面适配，拥有完善的安全产品线和安全服务，覆盖事前、事中和事后多个环节。因有着丰富的数据接入、高处理性能以及精确的安全威胁监测、控制和审计能力，绿盟科技的安全可信产品与服务获得了主管单位与用户的广泛认可。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

作为国内网络安全的排头兵，绿盟科技将踔厉奋发、勇毅前行，和中关村可信计算产业联盟一道，为筑牢国家网络安全防线、助力我国实现高水平科技自立自强、加快把我国建设成为创新高地，提供坚强支撑。
