# 绿盟科技成功获批“工业和信息技术人才培养工程培训基地”

近日，经审核评定 ，绿盟科技获得工业和信息化部教育与考试中心颁发的“工业和信息技术人才培养工程培训基地”认证，并授权开展相关专业技能培训与认证业务。

![](../Images/275e70502969bd83cac350e8c71b8599.png)

“工业和信息化人才培养工程”由工业和信息化部教育与考试中心发起并组织，旨在落实制造强国、网络强国、人才强国战略，建设工业和信息化技术技能人才队伍。通过优化整合涵盖学历教育、技术水平、专业技能和复合型高新技术培训等优质教育资源，为工业和信息化事业高质量发展提供人才保障。此次获批“工业和信息技术人才培养工程培训基地”，是对绿盟科技技术实力和培训能力的认可。

![](../Images/fac50d88b99893b8b51ea5479caa0829.png)

证书样本

人才是制造强国和网络强国建设的根本。未来，绿盟科技将在工业和信息化部教育与考试中心的指导下，聚焦网络安全和数据安全，以应用能力培养为核心，以绿盟科技完善专业的职业能力培训认证体系为基础，努力做好人才培育工作，为网络安全行业的发展提供人才保障。
