# 绿盟科技重大活动期间网络安全保障工作获运营商用户点赞

新安全格局保障不断重塑新发展格局，“健全国家安全体系，完善重点领域安全保障体系和重要专项协调指挥体系，强化网络等安全保障体系建设” 为打造网络安全基座提供了根本遵循。近日，绿盟科技依托其专业能力、周密部署和协同联动，全力支撑重点领域安全保障，顺利护航重大活动期间运营商用户的网络安全保障工作。

![](../Images/14f5d120bc404a3656e5ce9e0608696a.png)![](../Images/2de2779b4caa8b92ceeb58eb2c157e48.png)

  

![](../Images/281cbed5d201f324b13a04d20e89b2a8.png)![](../Images/9d90cc52ddae33d644ffb93c4c71550c.png)

绿盟科技获移动、联通、电信运营商用户感谢信

伴随新一轮科技革命和产业变革的蓬勃兴起，网络安全挑战进阶繁复，重要时期网络安全保障服务已成为数字时代政企客户的必修课。为切实做好重大活动期间网络安全保障工作，绿盟科技成立专项小组，联动全国10余城安全运营中心，以“整体安全、全面保障”为总体目标，旨在为客户提供重要时期安全事件的事前检测、攻击感知、事中防护、事后应急四类安全保障，覆盖“监测、预警、防护、检测、响应、闭环”全过程，全方位强化网络安全纵深保障体系。

  

绿盟科技网络安全重要保障工作依托专业保障团队，整合绿盟科技威胁情报运营能力、安全预警和处置能力、产品平台支撑保障能力以及应急响应和安全研究能力，为用户提供7\*24安全监控、高效研判和应急响应处置服务。从风险排查、多重防护、云地协同以及联防联控出发，护航多行业安全保障，筑牢网络安全防线。

  

一直以来，绿盟科技与运营商用户联动密切，不断深化业务领域深度合作。绿盟科技党支部与运营商用户党支部定期开展各类党建活动，在党建共建上寻求创新，以党建引领助推高质量发展。此次与运营商用户在重保期间再次取得高效协同，为今后绘就安全生态新格局打下了坚实基础。

![](../Images/1d10bfe8935093db408532dd4d5499ed.png)![](../Images/b7609507b1b979e82bf49bc2d2bbb517.png)

绿盟科技与运营商用户举行“党建和创”签约仪式（左）、开展“党建翼联”主题活动（右）

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

作为巨人背后的专家，基于成熟的重大活动保障体系，绿盟科技已先后为上合峰会、世博会、APEC峰会、世界互联网大会等重大活动期间用户的网站提供保障技术支持，以实际行动践行使命，为重大活动期间的网络安全保驾护航。
