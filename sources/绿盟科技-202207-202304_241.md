# 强强联合，护航“产学研”｜绿盟科技集团与浙江科技学院战略合作签约仪式顺利举行

11月15日，绿盟科技集团与浙江科技学院战略合作签约仪式在杭州顺利举行。浙江省委网信办网络数据与技术处处长顾小卫、浙江科技学院副院长万健、信息中心主任徐兴、信息与电子工程学院院长雷景生，绿盟科技集团副总裁陈珂、浙江代表处首席代表吴昕等领导出席本次签约活动。

![](../Images/83d7bbffbca9f444664076986c6a69f1.png)

浙江科技学院副院长万健（左） 绿盟科技集团副总裁陈珂（右）

本次战略签约旨在立足国家战略需求，依托浙江科技学院多学科交叉融合优势与绿盟科技深厚的技术实力，共同助力产学研成果转化、人才培养与学科建设。双方将秉承“优势互补、互惠共赢、加强合作、共同发展”的原则，为实现人才培养与产业发展的深度融合，贡献自己的力量。

![](../Images/4d8274227fa2493dcf6d77f8a56cbb4d.png)![](../Images/00e12a0574ffcd23b991400a71ea170d.png)

浙江省委网信办网络数据与技术处处长顾小卫在致辞环节中分享了浙江省信息化建设成果及对学校的愿景，他表示，党的二十大报告指出，要加快建设数字中国。面对复杂严峻的国际形势和新冠肺炎疫情多发散发的不利影响，省委省政府高度重视数据安全治理工作，强调数据安全事关数字化改革成败。浙江省作为数字化转型的先行者，从责任、管理、技术三个维度认真抓好落实。企业要为数字化改革提供行业安全解决方案、先进技术和优质服务，为护航数字化改革网络安全提供技术支撑。同时对学校的网络安全建设提出“提升网信工作水平，落实网络安全责任、监测与演练常态化，推动关键任务落地以及强化安全宣传教育，搭建多维人才培养体系”的工作建议。

![](../Images/20789751f22a1a564ccd786a0a11886c.png)

浙江省委网信办网络数据与技术处处长  顾小卫

浙江科技学院经过40多年的建设，已拥有一支具有国际化视野、学术水平较高、师德师风高尚、梯队结构合理的优秀人才队伍。学院始终把国际交流与合作作为学校发展的重要战略，强化应用型办学，以学科专业一体化建设为龙头，以产教融合、国际合作为两翼，以产业学院、产业行业研究院、国际化特色学院建设为主体，以大学治理现代化为动力，高水平建设特色鲜明的社会主义浙江科技大学。浙江科技学院副院长万健表示，双方要依托联合共建的大数据安全与智能处理实验室和高校网络安全应急响应中心，在网络安全、数据安全、人工智能等领域开展更加紧密而富有成效的合作，共同进行“产、学、研”深度合作，联合开展科研课题及科研成果转化与推广合作，进一步提升学校网络安全防护水平，加强网络安全人才培养。

![](../Images/cb92ebcc513ce891fa257aee62d3ad11.png)

浙江科技学院副院长  万健

绿盟科技集团副总裁陈珂在致辞中介绍了绿盟科技概况以及校企合作方面的发展情况。他表示，当前，网络安全形势仍然严峻，绿盟科技作为深耕行业二十余年的网络安全企业，深感责任重大。绿盟科技很高兴能够有机会与浙江科技学院强强联合，双方将共同进行“产、学、研”深度合作，包括产学合作协同育人、成立智能化大数据安全实验室和高校网络安全应急响应中心、联合开展科研课题及科研成果转化与推广合作。绿盟科技愿与国内高校在前沿技术研究、一流研究成果转化、核心竞争力提升与自主创新安全产品研发等多方面实现合作，共同维护国家网络安全。

![](../Images/12de595c5805447bb30cfeb9a958619c.png)

绿盟科技集团副总裁  陈珂

  

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

未来，绿盟科技将踔厉笃行，发挥好在科技成果转化应用与创新中的角色，不断推进、扩大与各大院校的产学研融合创新工作，共同探索产学研、协同育人新模式、新思路和新路径，为我国的网络空间安全建设与人才培养保驾护航。
