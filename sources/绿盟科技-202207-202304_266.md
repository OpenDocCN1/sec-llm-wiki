# 绿盟科技列入Gartner《可管理检测与响应服务中国区市场指南》报告

近日，Gartner®发布了《Market Guide™ for Managed Detection and Response Services, China》报告（以下简称《报告》），绿盟科技凭借其一体化安全运营服务被列入该报告，认可为代表供应商。这是今年继入选Forrester《The Managed Security Services Landscape In Asia Pacific, Q3 2022》报告后，绿盟MDR服务再被列入国际机构研究报告。

《报告》\[1\]指出，中国的MDR服务与全球市场服务不同，更合适通过远程和现场服务团队结合的方式进行混合交付。MDR服务往往和各种相邻服务绑定，因为购买方希望MDR服务不仅可以监测和应对威胁，而且能够通过提供知识和能力，融入到客户的安全运营流程，助力形成一个预防-检测-响应-预测的闭环。围绕资产、脆弱性、验证等相关的服务在中国也很受欢迎。

  

绿盟MDR服务基于绿盟TONE-CLOUD自动化安全运营能力，提供远程7\*24的威胁检测与响应服务。通过对威胁事件的实时监测、快速分析研判、主动处置闭环管理，提升客户威胁响应效率、降低安全风险。

  

绿盟MDR服务优势是围绕业务资产为核心，采用云地结合的方式，通过绿盟T-ONE CLOUD支撑，中台运营体系打通云端能力建设团队与客户侧运营人员的支持与配合，真正实现7\*24小时的资产、威胁、脆弱性闭环管理，持续提升企业安全能力和成熟度。

![](../Images/100b67b2466389654edd851a81bc020d.png)

绿盟MDR服务通过成熟的安全运营流程支撑，可帮助客户实现安全建设能力提升，主要体现在以下几个方面：  

  

**提升威胁处置能力，关注自身业务**

通过安全运营体系建设，将技术、人员和流程协同起来，提升威胁感知和事件响应能力应对复杂攻击，客户可以将更多经历投入到自身业务建设中。

  

**降低威胁处置时间，降低MTTD、MTTR**

通过整合安全工具，利用联动编排等技术，实现威胁自动化处置，有效降低了威胁处置时间。

  

**安全建设成果直观化，提升闭环管理感知**

基于成熟度模型制定安全评价指标，定期开展安全度量，展示企业网络安全状态和防护水平，并持续改进。

  

**减少安全建设投入，降低建设成本**

云端7\*24小时的专家支撑，解决了客户侧安全人员紧缺问题，实现全天候安全监测。

  

今年，绿盟科技已先后上榜Gartner《工具包：中国云安全、数据安全、IAM和安全运营的厂商一览》、《中国云安全资源池创新洞察》、《2022年安全编排自动化与响应解决方案市场指南》、《2022中国ICT技术成熟度曲线报告》、《2022年中国安全技术成熟度曲线》、《工具：2022年数据泄漏防护厂商识别报告》、《2022年中国智慧城市与可持续发展技术成熟度曲线报告》等多项报告。此外，在IDC近期发布的《2022上半年中国IT安全服务市场跟踪报告》中，绿盟托管安全服务（MSS）以第三名的成绩名列前茅。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

绿盟科技作为国内安全运营服务的先行者，已经在政府、金融、运营商、企业、交通、能源、科教文卫等多行业有成功的服务落地案例。2022年，绿盟科技推出T-ONE CLOUD 平台，以云的思路重构安全运营体系，为客户提供弹性敏捷的安全闭环保障能力，为全行业用户按需提供快速安全闭环保障能力。T-ONE CLOUD平台为绿盟安全运营业务的开展，提供更加智能的云端服务能力，将进一步提升对资产、脆弱性、威胁、设备的一体化安全运营体系保障。
