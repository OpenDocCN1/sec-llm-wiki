# 知攻善守 重保安全｜央企CIO论坛在京成功举办

近日，由绿盟科技与CIO时代联合主办，新基建创新研究院作为智库支持的第23期“央企CIO论坛”在北京顺利举办。公安部网络安全保卫局巡视员、副局长兼总工程师郭启全、中国航空油料集团有限公司信息中心主任周文，绿盟科技集团副总裁孙冀平、副总裁曹嘉，中国通用技术集团控股有限责任公司数字化部信息安全总监金波出席本次活动并作主题分享。

![](../Images/84b4c20b369d0ecdc12eabe15f781bac.png)

本期CIO论坛以“知攻善守，构建重保安全防护新范式”为主题，邀请到30多位业内专家、央国企CIO代表和技术专家共聚一堂，共同探讨新形势下的央企网络安全体系建设的新方向与新实践。

  

绿盟科技集团副总裁孙冀平在致辞中表示，央企站在国家网络安全的最前线，是关键基础设施的守护者。绿盟科技作为网络安全领域的先行者和实践者，希望与国家主管部门及广大央企用户共同构建国家网络安全的坚固长城。

![](../Images/8be23758df3b072b0f8e734d4c4f3b48.png)

绿盟科技集团副总裁  孙冀平

随后，绿盟科技集团副总裁曹嘉带来题为《云化时代的对抗》的精彩分享。他表示，央企在以云计算为核心加速数字化转型的同时，也带来了区别于传统安全的云上安全问题。在云计算架构下，开放网络和业务共享场景更加复杂多变,安全性挑战更加严峻，如何用云的方式解决云上安全问题成为各行业的重要命题。

  

曹嘉特别强调，企业在云化时代可以更加快速地进行业务部署，运用低成本实现高效的系统运营和更加安全的网络环境。绿盟科技一直在技术变革中不断创新与突破，构筑覆盖各类安全场景的全栈式云安全服务能力，为更多央企数字化发展提供更为全面、开放的安全服务。

![](../Images/27c1b2fe57b6323fe62fb9c20fbf9597.png)

绿盟科技集团副总裁  曹嘉

中国通用技术（集团）控股有限责任公司数字化部信息安全总监金波带来题为《通用技术集团的实战化网络安全体系建设实践》的精彩分享。金波从技术、管理、专业化组织建设及运营层面上，为我们全面细致剖析了目前企业在网络安全建设中的战略战术。特别是在技术层面，应通过实战攻防演练加强能力建设，实现“一体化、实战化”；并进行集团级的基础架构优化和一体化安全防护体系建设，减少攻击暴露面，实现“一张网 全链条”；同时，应当回归业务场景，在具体的业务场景下建设安全防护能力，实现“全场景、数治化”。

![](../Images/adef2b62ed0143516331dabb62e9b592.png)

中国通用技术（集团）控股有限责任公司数字化部信息安全总监  金波

本期活动的“圆桌对话”环节，在场的各位嘉宾围绕“网络安全建设发展趋势”主题，以“企业如何研判与监控网络风险、提升监管工作效率”为引展开讨论，将所在行业或企业在攻防演练中的实践体会进行了分享与交流，现场气氛热烈，金句频出。

  

在热烈的讨论中，本期央企CIO论坛圆满落下帷幕。与会嘉宾纷纷表示此行受益匪浅，也期待日后能够继续深入交流。
