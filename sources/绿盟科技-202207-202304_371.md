# 聚力密码与安全融合应用，护航数字经济发展｜绿盟科技与三未信安达成战略合作

9月8日上午，绿盟科技与三未信安科技股份有限公司（以下简称“三未信安”）战略合作签约仪式在北京举行。绿盟科技首席技术官叶晓虎、副总裁孙冀平、行业技术中心高级总监张智南，三未信安董事长兼总经理张岳公、副总经理兼营销中心总经理白连涛、技术支撑中心总经理鹿淑煜等领导及相关同事参与本次活动。

![](../Images/5110148f8f33782e080ace8c42808ba6.png)

随着《网络安全法》《密码法》《数据安全法》《关键信息基础设施安全保护条例》等法律法规的发布，密码使用由行政推进向依法规范应用转变，强化了密码应用要求。在加快推进数字化转型背景下，密码是赋能数字经济发展的核心技术和基础支撑，密码是安全的基因，融合应用才能体现价值。聚力密码与安全融合应用，围绕数字化催生的新场景、新需求，双方结合各自业务优势，进行能力互补，在市场开拓、技术研发、产业合作等多方面开展深度合作，共同助力网络安全产业生态发展。

![](../Images/8caf367425d9bfb181fdc03d443450c5.png)![](../Images/77c287b8ae040cc4dcc0e023735547f3.png)

绿盟科技首席技术官叶晓虎表示，在政策法规的陆续出台和行业改革的必然趋势下，密码安全愈发受到重视。在强合规市场驱动下，希望双方深入了解行业客户需求，以密码与安全深度融合，从技术预研、产品合作、场景化解决方案等方面加强合作，实现共享、共赢。  

  

三未信安董事长兼总经理张岳公表示，作为密码基础设施提供商，三未信安多年来一直深耕密码技术领域，面向用户提供全面的商用密码产品和解决方案。通过此次合作，希望双方优势互补，挖掘行业新需求、新业务，聚焦核心技术和产品，为行业用户提供优质的产品和服务，实现共赢。

![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

  

未来，双方将重点围绕密码技术应用、密码应用安全性评估、数据安全、云安全、零信任、物联网等多个产品技术及解决方案方面进一步深化合作，携手共进、持续拓展网络安全产品与服务市场，护航数字经济发展。
