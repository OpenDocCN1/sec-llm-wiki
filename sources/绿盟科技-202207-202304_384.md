# 绿盟科技出席第八届中国（福州）智慧轨道交通与创新发展大会

近日，由福州地铁集团和世界轨道交通发展研究会主办的第八届中国（福州）智慧轨道交通与创新发展大会在福州隆重召开。绿盟科技作为分论坛协办单位参与本次大会，并发表题为《城市轨道云网络安全方案及实践》的演讲。

此次大会以“创新驱动数字化转型，智慧引领高质量发展”为主题，围绕“交通强国“和“数字城市”战略，聚焦轨道交通建设与运营的数字化、智能化、智慧化等行业热点，重点硏讨新兴信息技术在城市轨道交通建设与运营中的应用与应用分享。大会邀请了中国工程院卢耀文院士、丁荣军院士、王复明院士，世界轨道交通发展研究会会长国林，福州市人民政府市委副书记、市长、党组书记吴贤德，中国城市轨道交通协会副会长李国勇，广州地铁设计研究院股份有限公司党委书记党委书记、董事长农兴中、福州地铁集团有限公司党委书记、董事长黄朝光等领导和嘉宾参与。

![](../Images/0a514f35a843b7b5f59c4e7d2310437c.png)

在“数字化、信息化、云平台、大数据“分论坛上，绿盟科技集团高级安全专家姚宇发表名为《城市轨道云网络安全方案及实践》主题演讲。目前，大部分地铁业主对网络安全的要求是满足国家等级保护合规，城市轨道信息系统没有针对性的防御体系且专业人员不足，网络安全形式严峻。绿盟科技通过充分调研各地方地铁业主的城轨云建设模式，有针对性地提出了城市轨道云网络安全方案。该方案在《智慧城轨信息技术架构和信息安全规范》要求的基础上，强化城轨云网络安全纵深防御，对三个业务区的特点有针对性的安全能力防御提升。外部服务网以防范互联网攻击为主，保障对外服务，并增强云主机内合规、审计、防篡改等安全能力。内部管理网以数据安全为核心，在数据的采集、交换、共享和开放等环节，及时发现和解决问题。利用大数据分析能力，进行敏感数据行为分析，实时监控和呈现数据安全态势，掌握敏感数据分布、流转和风险的状态和发展趋势。安全生产网应兼顾工业控制安全和传统信息系统安全，构建传统信息安全、云计算安全、工业控制安全的软硬一体综合安全能力。最终利用云计算技术和大数据技术，实现整个城市的全域网络安全态势感知和快速响应。

  

绿盟科技开发了沉浸式三维城市轨道全域网络安全运营平台，实现城市轨道网络安全全线路、全业务系统的全域集中管控、可视，满足国家对城市轨道的合规要求以及网络安全防护需求，为保障城市轨道信息系统网络安全提供“绿盟智慧”。

![](../Images/39917998a552b05e60a0c0f959978f14.png)![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

未来，绿盟科技将持续研究创新，助力营造良好的网络安全生态，为交通行业客户构建安全运营保障体系，提供全方位安全能力支持，持续为客户创造价值。
