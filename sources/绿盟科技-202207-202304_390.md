# 三连冠｜绿盟科技荣获2022年广州市网络安全攻防演练第一名

6月20日至30日，广州市委网信办牵头联合广州市公安局、广州市政务服务数据管理局组织开展了2022年广州市网络安全攻防演练活动。绿盟科技凭借扎实的技术功底和顽强的拼搏精神，经过层层考验，荣获2022年广州市网络安全攻防演练“攻击队总分第一名”的荣誉。

![](../Images/e27eb4615e00ee55055141825b045ed8.png)![](../Images/651dd7593b150ce526e41740235e959a.png)

本次攻防演练旨在持续提升广州市重要信息基础设施、关键业务系统运营单位的安全防御和应急响应水平。大赛共邀请了8支国内一流的网络安全机构和企业队伍作为攻击方。绿盟科技梅花K战队代表绿盟科技作为攻击队参与演练。历经10天的鏖战，绿盟科技攻击队脱颖而出，一举夺魁。截至2022年，绿盟科技攻击队已连续3年获得广州市网络安全攻防演练第一名的好成绩。

  

绿盟科技梅花K战队是一支专注实战的专业攻防团队，战队秉承“以攻促防，以攻塑防”的技术理念，分别设立了以高级攻击技术研究、攻击自动化与基于ATT&CK的防御能力度量为目标的实战攻击小组，以及专注于前沿性防护技术研究、产品对抗能力提升以及威胁分析与狩猎的实战对抗小组。

  

战队成员均具有丰富的攻防对抗领域经验，在各级实战攻防演练与攻防竞赛中披荆斩棘、屡获佳绩。战队以提升客户实战对抗水平为目标，在攻防视角下，指引客户防御能力构建，助力绿盟科技核心产品能力提升，为国家级重大活动的网络安全保驾护航。
