“志合者，不以山海为远。”2022年8月27日，绿盟科技联合运营合作伙伴峰会在黄山成功举行。大会以“服务构基石  运营聚未来”为主题，邀请合作伙伴共同探讨数字化时代市场的新机遇，分享绿盟科技合作运营业务探索成果，洞见绿盟T-ONE CLOUD核心产品竞争力，与各位伙伴共建安全生态。


会上同期举行了绿盟科技&合作伙伴联合运营中心发布及签约仪式。绿盟科技携手华讯 、北明、神州新桥、赛尔网络等多家合作伙伴，共建合作运营中心。


胡忠华

绿盟科技集团总裁

绿盟科技集团总裁胡忠华在致辞中表示，网络安全成为国家安全中重要的战略组成部分，《网络安全法》《数据安全法》等法律、法规的相继发布，为产业落地带来机遇和提供支撑。从需求的角度，行业客户尤其是关键信息基础设施运营者，数字化转型过程中面临的安全风险挑战更加多变，我们认为，如下几个趋势愈发清晰：


1、随着客户的业务上云，安全行业的产业结构出现了云化的趋势，从产品化逐步过渡到服务化、SaaS化的安全运营模式。


2、客户的业务上云，数据安全的价值愈发重要，安全运营将以高频发生的数据和信息安全风险场景为中心，以动态的视角对抗各类风险。


安全如何云化，是安全厂商和合作伙伴需要把握的行业机遇。以安全运营为中心，以持续运营的模式，以云的视角解决客户的问题，这是安全厂商都要思考的问题。今年5月，绿盟科技重点推出“云运营再造新安全”的云化战略，并发布T-ONE CLOUD 解决方案，将安全资源池NCSS、魔力防火墙NF-SSE、SASE、手机APP等一系列产品进行整合，用“云地人机”协同解决客户的安全痛点。基于这个解决方案，一起打磨创新产品，提升客户体验，实现合作共赢。


发展能力型合作伙伴，通过自身不断进化的攻防能力持续赋能，从产品到服务、运营，资源共享，优势互补，全面合作，共同为客户持续创造价值，是绿盟科技推进和深化渠道战略的重要举措。服务构基石，运营聚未来，以合作运营中心为载体，以安全交付最后一公里为桥梁，期待和在座的合作伙伴，早日在安全运营市场乘风破浪，共谋未来。



绿盟科技集团首席技术官叶晓虎：T-ONE CLOUD云化战略下，携手合作伙伴共建云运营

绿盟科技集团首席技术官叶晓虎博士指出，数字经济已经成为全球新一轮科技革命和产业变革的重要引擎。作为数字时代网络安全的“守护者”，绿盟科技持续加大研发投入，以创新解决客户安全需求，为客户提供更好的体验。2022年重点推出“云运营再造新安全”的云化战略，发布T-ONE CLOUD 解决方案，提出云化时代的用户价值主张，以及新形势下的企业安全建设建议：


1、采用云化交付的安全产品和服务以获得弹性全面的安全能力。
2、引入高效敏捷的安全运营体系以达到最优的安全效能。
3、与专业安全公司建立持续可信任的连接以获得最新安全能力。


结合绿盟科技的渠道战略，T-ONE CLOUD推出了全新的合作运营模式，携手合作伙伴，共建T-ONE CLOUD安全运营中心。绿盟科技为合作伙伴提供全套建设合作运营中心所需的安全能力和系统软件，同时提供品牌支持、安全专家支持及技术指导培训，帮助合作伙伴快速了解安全市场，掌握安全服务技能，通过一线安全运营服务与最终客户产生更紧密的价值连接。

绿盟科技集团首席技术官叶晓虎


绿盟科技集团副总裁曹嘉：云时代下客户需要的安全

绿盟科技集团副总裁曹嘉表示，科技正在加速推行数字经济的发展进程，企业在以云计算为核心加速数字化转型的同时，也带来了区别于传统安全的云上安全问题。在云计算的架构下，云计算开放网络和业务共享场景更加复杂多变，安全性方面的挑战更加严峻，一些新型的安全问题变得突出，如何用云的方式去解决云上安全问题成为各行业的重要命题。


当前，云安全相对于中小企业而言更具有吸引力，尤其是SaaS在中国市场快速落地让中小企业越来越倾向于云服务。绿盟科技一直在技术变革中不断进行创新与突破，以客户为中心，构筑能够覆盖各类安全场景的全栈式云安全服务能力，赋能现代企业数字化发展，为客户提供更为全面、更加优质的数字化服务。

绿盟科技集团副总裁曹嘉


伙伴声音：共同抓住数字化转型机遇，扬帆行业新蓝海


会上，绿盟科技特别邀请了西安天互通信有限公司副总经理王文玺、赛尔网络有限公司总经理助理张满龙，从伙伴角度分享了与绿盟科技共建合作运营中心的经历。代表们表示，云时代需要我们打开新思路，与绿盟科技的合作是符合时代潮流的选择。绿盟科技是安全圈里的技术型企业，产品在客户和市场上有良好的口碑，拥有阳光、透明、公平的渠道生态环境。期待双方互相支撑、紧密合作，一同构建与壮大主动安全生态体系，共享网络安全产业的增长红利，为数字经济提供全方位的安全保障。

西安天互通信有限公司副总经理王文玺

赛尔网络有限公司总经理助理张满龙


绿盟科技集团副总裁欧阳闽泽：发展能力型伙伴，共创云服务新未来

绿盟科技集团副总裁欧阳闽泽指出，过去三年是绿盟科技渠道战略转型的1.0时代。公司从组织、考核、流程等维度调整优化了自身，让合作伙伴能初步合作起来。在未来2.0时代，尤其是疫情常态化背景下，绿盟科技不断探索云化趋势下的安全优化合作模式，合作运营中心应运而生。绿盟科技将与运营合作伙伴之间采用“合作分工、联合服务、联合运营”的协作方式，建设“云运营”平台，形成技术壁垒，全方位成体系解决客户安全问题，为客户提供“花小钱办大事”的更高性价比方案。


T-ONE CLOUD是技术方案的闭环，绿盟科技更愿意打造“客户、合作伙伴、绿盟”多赢的商业模式闭环。绿盟科技希望与IDC伙伴、行业集成商、等保测评机构等合作伙伴，共同打造行业、客户、地市三种不同维度的联合安全运营中心，分工合作，数据是客户本地的、客户是合作伙伴的，绿盟科技作为巨人背后的专家，提供技术和云化产品。同时，为闭环商业模式，绿盟科技将采取“云化安全产品纳入战略考核、联合营销支持、第一条件续约方保护联合运营伙伴的客户资源”的方式，前端与伙伴共同拓展客户，后端共同做好保障。针对等级保护、业务风险管理、云地协同等不同云运营，绿盟科技采用“多投入多收益，早投入早收益”等多种模式帮助合作伙伴盈利，为合作伙伴业务添砖加瓦，在美丽的黄山与伙伴一起“会心今古远、放眼天地宽”。

绿盟科技集团副总裁欧阳闽泽


共发展 赢未来 ：绿盟科技&合作伙伴联合运营中心

IDC发布的《2022年V2全球网络安全支出指南》指出，2021年全球网络安全IT总投资规模为1687.7亿美元。聚焦中国市场，2026年中国网络安全IT支出规模将达到318.6亿美元，全球占比约为11.1%，五年CAGR约为21.2%。中国网络安全市场前景广阔。面对不断扩大的网安市场、成长机遇，仅凭一己之力很难满足用户业务不断变化的更高需求。


会上，绿盟科技与西安天互通信有限公司、赛尔网络有限公司共同发布“绿盟科技&合作伙伴联合运营中心”。同时，绿盟科技与湖南承希科技有限公司、湖南紫薇垣信息系统有限公司、湖南盈聚信息技术有限公司、浙江鑫诺检测技术有限公司、杭州天宽科技有限公司、浙江安腾信息技术有限公司、华讯网络系统有限公司 、北明软件有限公司、北京神州新桥科技有限公司、赛尔网络有限公司、北京天一恩华科技股份有限公司、广西金普威信息系统有限公司 、安徽安联云服务有限公司、福州欣凯思达电子有限公司、天津国资云科技有限公司、河南众诚信息科技股份有限公司、河南悦海数安科技有限公司等举行签约仪式。绿盟科技将与合作伙伴，本着“真诚合作、优势互补、相互促进、共同发展”的原则，利用各自的优势相互赋能，去应对当前越来越复杂的网络攻击场景，让每一个用户都能快速享受到“全场景、可信任、实战化”的高质量安全运营服务，实现共赢与利益最大化。


T-ONE CLOUD ：打造云化时代“利器”，携手伙伴共赢未来

进入“十四五”时期，数字化的发展一定需要强有力的网络安全保障。以防护效果为首要目标，“最后一公里”难关的攻克成为关键。合作运营模式充分利用本地与云端资源的结合，可很好解决近客侧人力和能力不足的问题，为企业的数字化高质量发展保驾护航，同时也为合作方实现了增值、战略转型和竞争力的提升。


在下午的分论坛上，绿盟科技集团产品研发线副总经理何坤介绍了合作运营中心的核心组件，包括提供统一用户视图，实现全面安全可视的SOC门户；支持弹性按需订阅多种安全能力和服务的魔力防火墙NF-SSE；以及支撑实时风险管理和安全运营的全新手机APP等。

绿盟科技集团产品研发线副总经理何坤


绿盟科技的三位安全专家，分别就绿盟T-ONE CLOUD SASE-等保服务、一站式企业安全检测与防护方案、轻量化渗透测试服务进行了详细介绍。

同道中人，奔赴黄山；集结伙伴，共商大业。面对数字化转型带来的机遇和挑战，绿盟科技愿携手合作伙伴聚焦客户实际需求，以合作运营中心为载体，搭建好最后一公里桥梁的同时，以T-ONE CLOUD具备前瞻性的下一代架构，让每一个用户都能快速享受到“全场景、可信任、实战化”的高质量安全运营服务，守护数字经济时代安全基座，携手生态共赢未来。
