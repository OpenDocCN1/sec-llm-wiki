# 海淀区市场监管局经济服务办走访绿盟科技

8月3日上午，海淀区市场监督管理局经济服务办公室主任王健一行莅临绿盟科技集团开展交流活动，对企业经营中涉及到的市场监管类问题进行了指导和解答。在绿盟科技集团总裁助理张铭等领导陪同下，王健主任一行首先参观了绿盟科技总部展厅，详细了解绿盟科技的总体发展情况。

  

![](../Images/22cd9ce294738d3ba95edf4c6a630809.png)

  

  

会上，王健主任表示，此次走访是为了更好地了解企业情况，并将充分发挥海淀区市场监管局作为企业**“创新合伙人”**的角色，助力企业发展。随后，海淀区市场监管局执法八队队长王翀为参与交流的绿盟科技员工介绍了《明码标价和禁止价格欺诈规定》；执法十二队副队长郭敬峰为参与交流的绿盟科技员工介绍了《中华人民共和国商标法》；执法一队一级主办张涛对《中华人民共和国广告法》中涉及到的企业传播问题进行了重点讲解，同时**对绿盟科技传播工作的合规性表示了赞赏**。

  

![](../Images/9b09ed37352b50fb81cf5069a9ef58e9.png)

  

会后，海淀区市场监管局经济服务办为绿盟科技送上“一企一策”服务大礼包。绿盟科技集团总裁助理张铭为北京市海淀区市场监管局经济服务办公室和北京市海淀区市场监管综合执法大队赠送了锦旗，对他们的专业指导表示了诚挚感谢。

  

![](../Images/52a3700e4dd481e031de49a84e2afdb6.png)![](../Images/47e4d63fd7764ee9f4e7f2c236fd0135.png)

此次交流活动，对于绿盟科技是一种鞭策和勉励。员工纷纷表示，学习到了很多知识。绿盟科技将继续坚持”巨人背后的专家“企业使命，更加诚信、合规地经营，做让政府和客户信任的网络安全企业。
