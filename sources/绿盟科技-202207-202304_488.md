# 中国互联网协会副理事长兼副秘书长何桂立莅临绿盟科技考察调研

7月22日，中国互联网协会副理事长兼副秘书长何桂立一行莅临绿盟科技考察调研。绿盟科技集团副总裁刘多、总裁助理张铭、首席行业专家张智南、政府事务部总监高超、市场营销中心总监徐钏等陪同参观了集团总部展厅，并就绿盟科技集团业务发展情况进行了介绍。

![](../Images/691e47c9e13fc4ab607e2060f020fbdd.png)

会谈伊始，刘多详细讲述了绿盟科技集团的发展历程和主要业务布局。他表示，作为深耕网络安全行业二十余年的安全厂商，绿盟科技集团始终聚焦网络安全领域，高度重视安全研究和技术发展。今后，绿盟科技将继续在网络安全行业新领域中积极探索，全力支撑中国互联网协会有关工作，共同推进我国网络安全产业高质量发展。随后，张铭从绿盟科技集团的战略方向出发，进一步指出，网络安全厂商应当肩负起洞察网络安全全局态势的责任，守护安全，共谋发展。张智南博士就公司的产品体系和解决方案进行了详细的汇报，他表示，作为“巨人背后的专家”，绿盟科技集团始终致力于研究前沿技术引领网安变革，变中求新，稳中求进，以期在瞬息万变的信息时代开拓新局。  

![](../Images/08f69ff3661278714c849f567c4830d2.png)![](../Images/8e1fd7f0d2f1366920903e7d7ceb7233.png)

何桂立介绍了中国互联网协会的业务发展、服务项目和当前工作等情况，同时充分肯定了绿盟科技集团在安全研究和技术创新领域发挥的积极作用，并对绿盟科技集团的产品价值与产业发展前景表示认可。他表示，网络安全、信息安全是互联网发展的基础和关键，是支持数字化转型和数字经济发展的保障，作为政府和企业的纽带，中国互联网协会将积极发挥行业组织作用，进一步与会员单位开展全方位、深层次的交流与合作，围绕维护网络空间国家战略利益的目标，共同营造网络安全产业创新发展的良好环境。  

  

双方还就推动中小企业数字化转型、团体标准制订、联合党建工作、企业合规发展等方面进行了交流。
