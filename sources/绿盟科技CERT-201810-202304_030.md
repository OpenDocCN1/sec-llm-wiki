**漏洞概述**

11月9日，绿盟科技CERT监测到微软发布11月安全更新补丁，修复了68个安全问题，涉及Windows、Microsoft Office、Microsoft Exchange Server、Windows Print Spooler等广泛使用的产品，其中包括权限提升、远程代码执行等高危漏洞类型。

本月微软月度更新修复的漏洞中，严重程度为关键（Critical）的漏洞有11个，重要（Important）漏洞有57个，其中包括6个0day漏洞：

Windows Scripting Languages远程代码执行漏洞（CVE-2022-41128） 

Windows Mark of the web安全特征绕过漏洞（CVE-2022-41091） 

Windows Print Spooler权限提升漏洞（CVE-2022-41073）

Windows CNG Key Isolation Service权限提升漏洞（CVE-2022-41125）

Microsoft Exchange Server权限提升漏洞（CVE-2022-41040）

Microsoft Exchange Server远程代码执行漏洞（CVE-2022-41082）

值得关注的是，官方在本次更新中发布了于9月29日公开的两个Exchange Server漏洞（CVE-2022-41040、CVE-2022-41082）的安全补丁，请相关用户尽快更新补丁进行防护，完整漏洞列表请参考附录。

**绿盟远程安全评估系统（RSAS）已具备微软此次补丁更新中大****部分****漏洞的检测能力（包括****CVE-2022-37966****、CVE-2022-37967、CVE-2022-41039、CVE-2022-41047、CVE-2022-41073****等高危漏洞），请相关用户关注绿盟远程安全评估系统系统插件升级包的更新，及时升级至****V6.0R02F01.290****6****，官网链接：http://update.nsfocus.com/update/listRsasDetail/v/vulsys**

**2****重点漏洞简述**

根据产品流行度和漏洞重要性筛选出此次更新中包含影响较大的漏洞，请相关用户重点进行关注：

**Microsoft Exchange Server权限提升漏洞（CVE-2022-41040）：**

9月29日，微软安全响应中心发布安全公告首次公开了该漏洞。经过身份验证的远程攻击者通过该漏洞可实现在目标系统上获取运行PowerShell的权限，绿盟科技CERT已针对该漏洞发布预警通告。CVSS评分为8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-41040

  

**Microsoft Exchange Server远程代码执行漏洞（CVE-2022-41082）****：**

9月29日，微软安全响应中心发布安全公告首次公开了该漏洞。具有访问PowerShell权限的攻击者利用此漏洞，最终可实现在目标系统上任意执行代码。绿盟科技CERT已针对该漏洞发布预警通告。CVSS评分为8.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-41082

  

**Windows CNG密钥隔离服务****权限提升****漏洞（CVE-2022-41125）：**

由于Windows CNG中未实行正确的安全限制，具有低权限的本地攻击者通过利用该漏洞绕过安全限制，可在目标系统上提升至SYSTEM权限，且无需用户交互。目前已监测到该漏洞存在在野利用，CVSS评分为7.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2022-41125

  

**Windows Mark of the web安全****功能****绕过漏洞（CVE-2022-41091）：**

Windows Mark of the web存在安全功能绕过漏洞。攻击者通过诱导用户访问定向的攻击站点的链接，或打开恶意附件时，可实现安全功能绕过。该漏洞细节已被公开披露，且存在在野利用。

官方通告链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-41091

  

**Windows Print Spooler**** 权限****提升漏洞（CVE-2022-41073）：**

Print Spooler是Windows系统中管理打印相关事务的服务，用于管理所有本地和网络打印队列并控制所有打印工作。由于Windows Print Spooler中未施加正确的安全限制，经过身份验证的本地攻击者利用该漏洞可实现在目标系统上以SYSTEM权限执行任意代码，且无需用户交互。目前已监测到该漏洞存在在野利用，CVSS评分为7.8。

官方通告链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-41073

官方通告链接：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-41128

**4.1 补丁更新**

目前微软官方已针对受支持的产品版本发布了修复以上漏洞的安全补丁，强烈建议受影响用户尽快安装补丁进行防护，官方下载链接：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Nov

注：由于网络问题、计算机环境问题等原因，Windows Update的补丁更新可能出现失败。用户在安装补丁后，应及时检查补丁是否成功更新。

右键点击Windows图标，选择“设置(N)”，选择“更新和安全”-“Windows更新”，查看该页面上的提示信息，也可点击“查看更新历史记录”查看历史更新情况。

针对未成功安装的更新，可点击更新名称跳转到微软官方下载页面，建议用户点击该页面上的链接，转到“Microsoft更新目录”网站下载独立程序包并安装。
