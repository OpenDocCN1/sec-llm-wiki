**漏洞概述**

  

8月11日，绿盟科技CERT监测到微软发布8月安全更新补丁，修复了46个安全问题，涉及Windows、Microsoft Office、ASP.NET Core、Microsoft Visual Studio、Azure等广泛使用的产品，其中包括权限提升、远程代码执行等高危漏洞类型。

本月微软月度更新修复的漏洞中，严重程度为关键（Critical）的漏洞有7个，重要（Important）漏洞有39个。其中有3个为0day漏洞，有2个漏洞信息已在上月发布：

Windows权限提升漏洞（CVE-2021-36934）

Windows Print Spooler 远程代码执行漏洞（CVE-2021-34481）

请相关用户尽快更新补丁进行防护，完整漏洞列表请参考附录。

**绿盟远程安全评估系统（RSAS）已具备微软此次补丁更新中大多数漏洞的检测能力（包括CVE-2021-36936、CVE-2021-26424、CVE-2021-36947、CVE-2021-34534、CVE-2021-26432等高危漏洞），请相关用户关注绿盟远程安全评估系统系统插件升级包的更新，及时升级至V6.0R02F01.2405，官网链接：http://update.nsfocus.com/update/listRsasDetail/v/vulsys**

  

参考链接：

https://msrc.microsoft.com/update-guide/en-us/releaseNote/2021-Aug

**2****重点漏洞简述  
**

根据产品流行度和漏洞重要性筛选出此次更新中包含影响较大的漏洞，请相关用户重点进行关注：

**Windows Print Spooler****远程代码执行漏洞（****CVE-2021-36936****）****：**

 Print Spooler是Windows系统中管理打印相关事务的服务，域用户可远程利用该漏洞以SYSTEM权限在域控制器上执行任意代码，从而获得整个域的控制权，该漏洞细节已公开。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-36936

  

**Windows Print Spooler ****远程代码执行漏洞（****CVE-2021-36947****）**

Windows打印后台处理程序中存在远程代码执行漏洞，拥有低权限的攻击者可以在不需要用户交互的情况下，在目标主机远程执行代码。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-36947 

  

**Windows TCP/IP ****远程执行代码漏洞（****CVE-2021-26424****）**

Windows TCP/IP 存在远程代码执行漏洞，该漏洞源于 tcpip.sys 在处理通过 IPv6 协议发送的 TCP/IP 数据包时存在边界错误。远程 Hyper-V 来宾可以向受影响的 Hyper-V 主机发送特制的 IPv6 ping，触发内存损坏从而在目标主机上执行任意代码。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/ CVE-2021-26424

  

**Windows LSA ****欺骗漏洞（****CVE-2021-36942****）****：**

Windows LSA存在欺骗漏洞，未经身份验证的攻击者可利用此漏洞从域控或者其他主机窃取NTLM哈希，且无需用户交互，目前该漏洞细节已公开。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-36942

  

**Windows Update Medic Service****权限提升漏洞（****CVE-2021-36948****）**

由于 Windows Update Medic 服务存在边界错误，攻击者可利用此漏洞获得高等级用户权限，从而接管设备控制权限。目前此漏洞已发现在野利用。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-36948

  

**Windows Services for NFS ONCRPC XDR Driver****远程代码执行漏洞（****CVE-2021-26432 ****）**

NFS Windows Services的RPC调用（RPCXDR）内核驱动中存在漏洞，未经身份验证的远程攻击者可以利用该漏洞在目标主机上执行代码，且无需用户交互。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-26432 

  

**Remote Desktop Client ****远程代码执行漏洞（****CVE-2021-34535 ****）**

Windows远程桌面客户端存在远程代码执行漏洞，未经身份验证的攻击者利用此漏洞可使用与受害者相同的方式进行身份验证，从而获得系统权限，该漏洞需要和用户交互。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-34535 

  

**Scripting Engine****内存损坏漏洞****(CVE-2021-34480)**

Windows脚本引擎存在内存损坏漏洞，远程攻击者通过欺骗受害者访问恶意网站或打开特制文件，触发内存损坏从而在目标系统上执行任意代码。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/ CVE-2021-34480

**4****漏洞防护**  

**4.1  补丁更新  
**

目前微软官方已针对受支持的产品版本发布了修复以上漏洞的安全补丁，强烈建议受影响用户尽快安装补丁进行防护，官方下载链接：

https://msrc.microsoft.com/update-guide/en-us/releaseNote/2021-Aug

注：由于网络问题、计算机环境问题等原因，Windows Update的补丁更新可能出现失败。用户在安装补丁后，应及时检查补丁是否成功更新。

右键点击Windows图标，选择“设置(N)”，选择“更新和安全”-“Windows更新”，查看该页面上的提示信息，也可点击“查看更新历史记录”查看历史更新情况。

针对未成功安装的更新，可点击更新名称跳转到微软官方下载页面，建议用户点击该页面上的链接，转到“Microsoft更新目录”网站下载独立程序包并安装。
