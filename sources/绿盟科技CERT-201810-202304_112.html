通告编号:NS-2021-0008

2021-02-10
TAG：

安全更新、Windows、Office、Exchange、Visual Studio、.NET Framework

漏洞危害：

攻击者利用本次安全更新中的漏洞，可造成信息泄露、权限提升、远程代码执行等。

版本：1.0

1

漏洞概述


北京时间2月10日，微软发布2月安全更新补丁，修复了56个安全问题，涉及Microsoft Windows、Microsoft Office、Microsoft Exchange Server、Visual Studio、Microsoft .NET Framework等广泛使用的产品，其中包括远程代码执行和权限提升等高危漏洞类型。

本月微软月度更新修复的漏洞中，严重程度为关键（Critical）的漏洞有11个，重要（Important）漏洞有43个。请相关用户及时更新补丁进行防护，详细漏洞列表请参考附录。


参考链接：

https://msrc.microsoft.com/update-guide/releaseNote/2021-Feb

2重点漏洞简述

根据产品流行度和漏洞重要性筛选出此次更新中包含影响较大的漏洞，请相关用户重点进行关注：

Windows Installer权限提升漏洞（CVE-2021-1727）：

 此漏洞为（CVE-2020-16902）的补丁绕过，拥有低权限的用户帐户的攻击者，利用此漏洞提升账户权限，从而目标主机控制权限，此前已有此漏洞的利用方式公开。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-1727


Windows Win32k权限提升漏洞（CVE-2021-1732）：

 Windows内核模式驱动对内存对象处理不当导致的权限提升漏洞，经过身份验证的本地攻击者可利用此漏洞在目标系统上提升其权限以执行任意代码。目前已监测到在野利用。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-1732


Windows TCP/IP远程代码执行漏洞（CVE-2021-24074）：

Windows IPv4 协议栈中存在一个远程代码执行漏洞，远程攻击者通过构造特制的数据包，可在目标主机上远程执行任意代码。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-24074


Windows DNS Server 远程代码执行漏洞（CVE-2021-24078）：

未经身份认证的攻击者通过向受影响的DNS服务器发送特制数据包，即可在目标系统上以本地系统账户权限执行任意代码。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-24078


Windows TCP/IP拒绝服务漏洞（CVE-2021-24086）：

Windows IPv6协议栈存在一个拒绝服务漏洞，远程攻击者通过向受影响的主机发送特别构造的数据包，可导致目标系统拒绝服务。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-24086


Windows TCP/IP远程代码执行漏洞（CVE-2021-24094）：

Windows IPv6协议栈存在一个远程代码执行漏洞，远程攻击者通过构造特制的数据包，可在目标主机上远程执行任意代码。

官方通告链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2021-24094


Windows控制台驱动程序拒绝服务漏洞（CVE-2021-24098）：

ConDrv.sys存在一个拒绝服务（DoS）漏洞，该漏洞会在Windows 10系统上触发蓝屏（BSOD）。攻击者通过诱使用户点击链接（通常是通过电子邮件或即时通讯消息的方式），然后打开特制文件触发此漏洞。前段时间利用方式已被大肆传播。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-24098


.NET Core远程执行代码漏洞（CVE-2021-26701）：

.NET Core 存在一个远程代码执行漏洞，远程攻击者可利用此漏洞获得目标主机控制权限，目前漏洞细节信息已公开。建议用户及开发者谨慎打开和使用 .NET 相关组件和应用程序。

官方通告链接：

https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2021-26701

4漏洞防护

4.1  补丁更新

目前微软官方已针对受支持的产品版本发布了修复以上漏洞的安全补丁，强烈建议受影响用户尽快安装补丁进行防护，官方下载链接：

https://msrc.microsoft.com/update-guide/releaseNote/2021-Feb

注：由于网络问题、计算机环境问题等原因，Windows Update的补丁更新可能出现失败。用户在安装补丁后，应及时检查补丁是否成功更新。

右键点击Windows图标，选择“设置(N)”，选择“更新和安全”-“Windows更新”，查看该页面上的提示信息，也可点击“查看更新历史记录”查看历史更新情况。

针对未成功安装的更新，可点击更新名称跳转到微软官方下载页面，建议用户点击该页面上的链接，转到“Microsoft更新目录”网站下载独立程序包并安装。
