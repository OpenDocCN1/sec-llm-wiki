**漏洞概述**

  

近日，绿盟科技监测到Apache Solr发布安全公告，修复了ConfigSet API中存在的未授权上传漏洞（CVE-2020-13957）。攻击者可以结合使用UPLOAD/CREATE这两个ACTION来绕过检查，以获取服务器权限。成功利用此漏洞可导致远程代码执行。请相关用户采取措施进行防护。

Apache Solr是 Apache Lucene 项目的开源企业搜索平台，由Java开发，运行于Servlet容器（如Apache Tomcat或Jetty）的一个独立的全文搜索服务器，主要功能包括全文检索、命中标示、分面搜索、动态聚类、数据库集成，以及富文本的处理。

  

参考链接：

https://issues.apache.org/jira/browse/SOLR-14925

2**影响范围**

**受影响版本**  

*   Apache Solr 6.6.0 -6.6.5
    
*   Apache Solr 7.0.0 -7.7.3
    
*   Apache Solr 8.0.0 -8.6.2
    

  

**不受影响版本**

*   Apache Solr => 8.6.3
    

  

3漏洞检测  

**3.1  版本检测  
**

相关用户可通过版本检测的方式判断当前应用是否存在风险：

在Solr管理后台的Dashboard仪表盘中，查看当前Solr的版本信息。

![](../Images/3ea339c6dc6ac23d5307501f414b0540.png)

若当前使用的版本在受影响范围内，则可能存在安全风险。

  

4漏洞防护  

**4.1  官方升级**

目前官方已在新版本中修复了该漏洞，请受影响的用户尽快升级版本进行防护，官方下载链接：https://lucene.apache.org/solr/downloads.html

  

**4.2  其他防护措施  
**

若相关用户暂时无法进行升级操作，也可使用以下方法进行防护：

1、如果未使用ConfigSets API，请禁用UPLOAD命令，将系统属性： “configset.upload.enabled ”设置为 “false” ，详细请参考：https://lucene.apache.org/solr/guide/8\_6/configsets-api.html

2、开启身份验证/授权，参考官方文档：https://lucene.apache.org/solr/guide/8\_6/authentication-and-authorization-plugins.html

3、使用补丁修复程序 SOLR-14663，下载链接：

https://issues.apache.org/jira/browse/SOLR-14663

4、配置防火墙策略，确保Solr API（包括Admin UI）只有受信任的IP和用户才能访问。
