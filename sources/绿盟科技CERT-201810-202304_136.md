**漏洞概述**

  

10月14日，绿盟科技监测到微软在10月的补丁更新中修复了Windows TCP/IP远程代码执行漏洞（CVE-2020-16898），此漏洞被称为”Bad Neighbor”，CVSS评分为9.8。Windows TCP/IP协议栈在处理ICMPv6 Router Advertisement数据包时存在漏洞，攻击者可向受影响主机发送特制的ICMPv6 Router Advertisement数据包进行利用，实现在目标服务器或客户端上执行任意代码 。目前已有可导致蓝屏死机的PoC出现，请相关用户尽快采取措施进行防护。

  

参考链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-16898

3漏洞防护  

**3.1  官方升级**

目前微软官方已针对受支持的系统版本发布了修复该漏洞的安全补丁，强烈建议受影响用户尽快安装补丁进行防护，官方下载链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-16898

注：由于网络问题、计算机环境问题等原因，Windows Update的补丁更新可能出现失败。用户在安装补丁后，应及时检查补丁是否成功更新。

右键点击Windows图标，选择“设置(N)”，选择“更新和安全”-“Windows更新”，查看该页面上的提示信息，也可点击“查看更新历史记录”查看历史更新情况。

针对未成功安装的更新，可点击更新名称跳转到微软官方下载页面，建议用户点击该页面上的链接，转到“Microsoft更新目录”网站下载独立程序包并安装。

  

**3.2  临时防护措施  
**

若相关用户暂时无法安装补丁，也可通过以下措施进行缓解：

使用以下 PowerShell 命令禁用 ICMPv6 RDNSS，以阻止攻击者利用漏洞。

| netsh int ipv6 set int \*INTERFACENUMBER\* rabaseddnsconfig=disable |
| --- |

  

用户可以执行下面的PowerShell命令进行恢复：

| netsh int ipv6 set int \*INTERFACENUMBER\* rabaseddnsconfig=enable |
| --- |

  

**注：****此解决方法仅适用于 Windows 1709 ****及更高版本，****使用此方法****进行更改后，无需重启系统。****更多信息请参阅：https://docs.microsoft.com/zh-cn/windows-server/get-started/whats-new-in-windows-server-1709**
