**漏洞概述**

近日，Jenkins官方发布了Git client插件远程命令执行漏洞的安全公告，漏洞编号为：CVE-2019-10392，官方定级为高危。该漏洞存在于Git客户端插件中，若攻击者获取到具有Job/Configure权限的账号，可在Jenkins服务器上执行任意系统命令。Jenkins是一款基于Java开发的开源项目，用于持续集成和持续交付的自动化中间件，是开发过程中常用的产品，来自绿盟科技威胁情报的数据，将近有4万Jenkins服务开放在公网。为保证Jenkins服务器的安全，建议相关用户将受影响的Jenkins插件升级至修复版本。![](../Images/c372d14a73fb2416251ddb429a038d8a.png)

2**影响范围**

**受影响版本**

*   Git client Plugin <= 2.8.4
    

  

**不受影响版本**

  

*   Git client Plugin > 2.8.4
    

  

  

3漏洞检测  

**3.1 人工检测  
**

用户可通过查看当前Git client插件版本，对当前服务是否受此漏洞影响进行排查。

点击“Manage Jenkins”进入管理模块，选择“Manage Plugins”管理插件。

![](../Images/c6466db3c9ae337e13f0be7943d9d0fd.png)

点击“installed”即可对当前已安装的插件版本进行查看。

![](../Images/297dfce77914c49281842853b3414f36.png)  

如果当前的插件版本在受影响范围内，则可能存在安全风险，请尽快采取防护措施。

  

4漏洞防护  

**4.1  官方升级  
**

目前Jenkins官方已经针对该漏洞发布了新版本，请受影响的用户尽快升级Git client插件至2.8.4以上版本进行防护，操作步骤如下：

点击“Manage Jenkins”->“Manage Plugins”，进入插件管理界面

![](../Images/ba907031052bcc19a0060d74ccae68f9.png)

选择需要升级的插件，点击“Download now and install after restart”进行更新操作。

![](../Images/29cf142d4afef8c0eeb8712af312f26d.png)
