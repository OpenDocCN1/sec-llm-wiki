**漏洞概述**

  

微软于北京时间2019年2月13日发布了2月安全更新补丁，修复了79个从简单欺骗攻击到远程执行代码的安全问题，包含18个高危漏洞，涉及DHCP、SMB、Exchange Server、.NET Framework、Adobe Flash Player、Azure、Internet Explore、Microsoft Office等多个产品。

2**安全更新修复漏洞总结**

此次安全更新，共针对79个不同危害程度的漏洞发布补丁，包含18个高危漏洞（Criticle），其中DHCP、SMB、Exchange Server产品漏洞影响范围广，且危害严重，请相关用户尽快下载安装最新补丁。

*   **Windows DHCP Server远程代码执行漏洞（CVE-2019-0626 ）：**
    

Windows DHCP服务器中存在内存损坏漏洞，利用此漏洞，攻击者只需构造恶意DHCP请求，并发送至攻击目标，即可实现远程代码执行。本次发布的补丁对DHCP服务器处理网络包的方式进行了修正。

官方参考链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0626

  

*   **Windows SMB 远程代码执行漏洞（CVE-2019-0630及CVE-2019-0633）：**
    

这两个漏洞均存在于Micrisoft Server Message Block 2.0（SMBv2）处理请求的过程中，授权攻击者可通过向目标SMBv2服务器发送恶意包，来实现远程代码执行。本次发布的补丁对SMBv2处理特殊请求的方式进行了修正。

官方参考链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0630

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0633

  

*   **Microsoft Exchange Server特权提升漏洞（CVE-2018-8581、CVE-2019-0686、CVE-2019-0724）：**
    

此次发布的补丁包对Exchange Web Services（EWS）的推送通知认证功能做出重大修改，使用该服务的用户需对此变动重点关注。针对此漏洞，微软官方修改了EWS客户端和Exchange服务器之间建立通知协定的方式，客户端必须通过匿名认证后才可以建立连接，以此来保护服务器凭据和标识。同时补丁还会降低Exchange服务器和管理员在域中的权限，实际权限更改会根据Exchange的版本而不同。

CVE-2018-8581 在2018年11月份安全更新中没有给出补丁，只给出防护建议，修改NTLM身份验证的注册表值。CVE-2019-0686和CVE-2019-0724是漏洞（CVE-2018-8581）的两种攻击利用方式。该漏洞在本次发布的补丁中已得到根本解决，用户可关注绿盟科技安全预警微信公众号，在历史消息中搜索相关关键词Exchange，了解关于此漏洞的技术分析细节及临时防护方案。

官方参考链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0686

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2019-0724

  

3**官方补丁安装**

微软官方已经发布更新补丁，请用户及时进行补丁更新。获得并安装补丁的方式有两种：内网WSUS服务、微软官网Microsoft Update服务。

注：如果需要立即启动Windows Update更新，可以在命令提示符下键入wuauclt.exe /detectnow。

**方式一：内网WSUS服务**

无法联网的主机，需通过内网WSUS服务器实现补丁安装。

适用对象：已加入搭建有WSUS服务器内网活动目录域的计算机，或手工设置了访问内网WSUS服务。

系统会定时自动下载所需的安全补丁并提示安装，请按提示进行安装和重启系统。

如果希望尽快安装补丁，请重新启动一次计算机即可。

  

**方式二： 微软官网Microsoft Update服务**

适用对象：所有不能使用内网WSUS服务的计算机，包括未启用内网WSUS服务的计算机、启用了内网WSUS服务但未与内网连接的计算机。

未启用内网WSUS服务的计算机，请确保Windows自动更新启用，按照提示安装补丁并重启计算机。

启用内网WSUS服务的计算机但没有与内网连接的计算机，请点击开始菜单-所有程序-Windows Update，点击“在线检查来自Windows Update的更新”，按提示进行操作。
