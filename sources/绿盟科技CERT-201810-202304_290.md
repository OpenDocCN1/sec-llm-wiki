**漏洞概述**

  

近日，安全研究人员在Linux包管理器apt中发现了严重漏洞。该漏洞源于apt没有合理的处理重定向，攻击者可以利用中间人攻击或者恶意的下载镜像可触发该漏洞，导致远程代码执行。

攻击者通过修改响应标志位，可将安装包的下载链接重定向恶意服务器上，同时将通信数据中的哈希值修改为恶意安装包的哈希，即可绕过apt的本地校验。如果在网络环境中存在中间人攻击，或者下载镜像服务器被攻击者所控制，可导致该漏洞触发。攻击者可利用该漏洞在root权限下执行恶意代码。

2**影响范围**

**受影响版本：**

*   Ubuntu 18.10 apt < 1.7.0ubuntu0.1
    
*   Ubuntu 18.04 LTS apt < 1.6.6ubuntu0.1
    
*   Ubuntu 16.04 LTS apt < 1.2.29ubuntu0.1
    
*   Ubuntu 14.04 LTS apt < 1.0.1ubuntu2.19
    
*   Debian apt 1.8.0- alpha3
    
*   Debian apt 1.4.8
    
*   Debian apt 1.9.8.4
    

  

**不受影响版本：**

*   Ubuntu 18.10 apt - 1.7.0ubuntu0.1
    
*   Ubuntu 18.04 LTS apt - 1.6.6ubuntu0.1
    
*   Ubuntu 16.04 LTS apt - 1.2.29ubuntu0.1
    
*   Ubuntu 14.04 LTS apt - 1.0.1ubuntu2.19
    
*   Debian apt（unstable）1.8.0- alpha3.1
    
*   Debian apt Jessie 1.0.9.8.5
    
*   Debian apt stretch 1.4.9
    

  

3**漏洞排查**

**3.1 版本检查**

用户可执行下列命令，查询当前系统apt版本信息，若apt版本号在受影响范围内，则当前系统受此漏洞影响。

| apt-get --version |
| --- |

![](../Images/df7e7b1e724cab53a7e0df2b4c7a9e13.png)

Ubuntu版本信息可通过下列命令查看：

| lsb\_release -a |
| --- |

  

4**漏洞防护**

**4.1 版本升级**

Ubuntu及Debian已发布针对此漏洞的修复版本，用户可通过升级apt至最新版本对此漏洞进行防护。

升级过程中，用户可以通过禁用HTTP重定向功能来保证系统安全，操作如下：

| $ sudo apt update -o   Acquire::http::AllowRedirect=false$ sudo apt upgrade -o   Acquire::http::AllowRedirect=false |
| --- |

   

无法使用apt安装升级的用户，也可下载离线安装包进行本地安装。

*   Debian用户的升级步骤请参考：
    

https://lists.debian.org/debian-security-announce/2019/msg00010.html

*   Ubuntu用户的升级步骤请参考：
    

https://usn.ubuntu.com/3863-1/
