关于SiLK与YAF

我们要说的这两个工具来自美国卡内基梅隆大学的网络应急响应组（CERT）。SiLK与YAF都是由CERT下属的网络态势感应小组（CERTNetSA）开发的网络流量分析工具。

![](../Images/f454da998b6521c7dcbfdf0d0ba1725c.png)

SiLK工具套件支持网络流数据的高效收集、存储和分析，使网络安全分析人员能够快速查询大型历史流量集。SiLK非常适用于分析大型分布式企业的网络流量，以及中型ISP的骨干网络或边界流量。SiLK工具分为两种类型：包装系统和分析套件。包装系统收集IPFIX、NetFlow v9或NetFlow v5流量，并将数据转换为一种节约存储空间的格式，然后记录到特定的SiLK文件中。分析套件可以读取SiLK格式文件，并执行各种查询、统计和过滤操作。

YAF工具可以处理tcpdump产出的pacp格式文件，将其打包成yaf格式文件，或者使用pacp实时捕获一个网卡的流量，将其转化为双向流，然后输出给IPFIX收集程序或基于IPFIX格式的文件。YAF的输出可以用SiLK的分析套件来进行分析。

SiLK与YAF环境搭建

以下展示如何搭建单机版SiLK和YAF流量收集和分析环境。

1**安装依赖的库**

依赖glib2-dev和libpcap，直接apt-get安装：

sudo apt-get -y install libglib2.0-dev

sudo apt-get -y installlibpcap-dev

下载并安装libfixbuf：

wget http://tools.netsa.cert.org/releases/libfixbuf-1.7.1.tar.gz

tar -zxvf libfixbuf-1.7.1.tar.gz

cd libfixbuf-1.7.1

./configure && make

sudo make install

2**下载并安装YAF与SiLK**

下载并安装最新版的SiLK：

wget https://tools.netsa.cert.org/releases/silk-3.16.0.tar.gz

tar -zxvf silk-3.16.0.tar.gz

cdsilk-3.16.0

./configure \\

\--enable-data-rootdir=/data \\

\--prefix=/usr/local

make

make install

安装成功后如下图:

![](../Images/a698f66e69faf12dfa59f33c1c0f21e3.png)

下载并安装最新的YAF：

wget https://tools.netsa.cert.org/releases/yaf-2.8.4.tar.gz

tar -zxvf yaf-2.8.4.tar.gz

./configure && make

sudo make install  

3**配置SiLK和YAF**  

1.新建一个/data路径作为SilK的知识库存储目录，并把默认安装路径里的初始的silk.conf文件复制到/data路径下：

mkdir -p /data

cp site/twoway/silk.conf /data

2.添加sensor.conf文件到/data路径下，sensor.conf文件内容如下：

probe S0 ipfix

listen-on-port 18001

protocol tcp

listen-as-host 127.0.0.1

end probe

group my-network

ipblocks 192.168.1.0/24 # address of eth0. CHANGE THIS.

ipblocks 10.0.0.0/8 # other blocks you consider internal

end group

sensor S0

ipfix-probes S0

internal-ipblocks @my-network

external-ipblocks remainder

end sensor

3.修改rwflowpack的配置文件如下：

cat /usr/local/share/silk/etc/rwflowpack.conf | \\

sed 's/ENABLED=/ENABLED=yes/;' | \\

sed's/SENSOR\_CONFIG=/SENSOR\_CONFIG=\\/data\\/sensors.conf/;' | \\

sed 's/SITE\_CONFIG=/SITE\_CONFIG=\\/data\\/silk.conf/' | \\

sed 's/LOG\_TYPE=syslog/LOG\_TYPE=legacy/' | \\

sed 's/LOG\_DIR=.\*/LOG\_DIR=\\/var\\/log/' | \\

sed's/CREATE\_DIRECTORIES=.\*/CREATE\_DIRECTORIES=yes/' \\

\>> rwflowpack.conf

sudo mv rwflowpack.conf /usr/local/etc/

4.复制rwflowpack启动脚本到/etc/init.d路径下：

sudo cp /usr/local/share/silk/etc/init.d/rwflowpack /etc/init.d

sudo sudo update-rc.d rwflowpack start 20 3 4 5 .

sudo service rwflowpack start

5.为yaf日志创建目录

mkdir /var/log/yaf

mkdir /var/log/yaf/log

mkdir /var/log/yaf/run

export LTDL\_LIBRARY\_PATH=/usr/local/lib/yaf

6.配置yaf，配置文件路径/usr/local/etc/yaf.conf:

ENABLED=1

YAF\_CAP\_TYPE=pcap

YAF\_CAP\_IF=eth0

YAF\_IPFIX\_PROTO=tcp

YAF\_IPFIX\_HOST=localhost

YAF\_IPFIX\_PORT=18000

YAF\_STATEDIR=/var/log/yaf

YAF\_EXTRAFLAGS="--silk --applabel --max-payload=2048--plugin-name=/usr/local/lib/yaf/dpacketplug

4**运行YAF**
