近两年来，随着物联网相关技术的发展，几乎所有的家用电器都可以接入网络。智能化的功能为生活确实增添了不少便利，可是这种便利也是把双刃剑，在一个物联网环境中你传输的数据越多，信息暴露的可能性就越大，存在的安全隐患也因此而剧增。尤其是家里的一些摄像头、智能门锁等涉及隐私安全的设备，一旦被入侵将会对使用者造成不可估量的损失。路由器作为家居智能生态系统平台入口，在智能家居安全中占有举足轻重的位置。所以本文将对市场主要的家用的物联网安全终端产品进行调研，整理了此类设备的部署方式、配置以及主要功能。


市场上主要的家庭网关产品
 


1BitDefender Box

BitDefender(中文名:比特梵德，简称BD)是来自罗马尼亚的老牌杀毒软件，拥有超大病毒库，防病毒引擎被业界公认领先，独有游戏免打扰模式，Top Ten Reviews网站全球杀毒软件评比排名第一。BitDefender Box是融合了硬件，软件和云端的一款终端防护设备，旨在保护智能家居等物联网设备。BitDefender Box可以连接路由器，也可以当成路由，根据具体环境而定。               

配置：                

  • 支持802.11b/g/n标准的无线路由器

  • 内置了400MHz的单核处理器

  • 64MB RAM+16MB ROM              

                

主要功能：                

  • 脆弱性分析(Vulnerability Assessment)

       连续扫描，识别网络安全漏洞。查找隐藏的后门、未保护的管理端口及弱口令等。

  • 网址黑名单(URL Blacklisting)

      任何出站连接都将针对BitDefender云端进行检查，将URL列入不安全或不安全的列表。

  • 设备管理(Device Management)

       允许控制整个网络，而不仅仅是通过哪些用户或设备加入，而是能识别更细小的物联网设备。

        

2Home Network Security

趋势科技——网络安全软件及服务领域的全球领导者，以卓越的前瞻和技术革新能力引领了从桌面防毒到网络服务器和网关防毒的潮流，以独特的服务理念向业界证明了趋势科技的前瞻性和领导地位。Home Network Security是趋势科技的家庭网关产品，可帮助您设定儿童如何以及何时使用互联网的限制。          

主要功能：                            

  • 网络防御

       入侵防御系统（虚拟补丁）

  • 安全路由器

       路由器默认密码检测

  • 扩展设备保护

       所有连接设备的Web威胁防护

  • 儿童互联网

       基于白名单的家长控制政策管理

  • 平台支持

       运行iOS 8+和Android 4.1+的iPhone的管理应用程序                 

 

               

3Symantec Norton Core Router

赛门铁克是信息安全领域全球领先的解决方案提供商，为企业、个人用户和服务供应商提供网络安全软件及硬件的解决方案，可以帮助个人和企业确保信息的安全性、可用性和完整性。Norton Core router是其旗下的安全路由器品牌。                                       

配置：                                        

  • 1.7GHz dual-core processor

  • 1GBRAM

  • 4GB eMMC Flash

  • IEEE 802.11a/b/g/n/ac

  • Simultaneous Dual Band 2.4GHz &5GHz


  主要功能：                                        

  • 防火墙保护

  • 防范病毒、间谍软件等

  • 在线设备保护

  • 家长控制

  • IoT设备保护

  • 移动应用网络控制

                                       

4CUJO

CUJO是一家美国的创业公司，其主要产品是家用智能防火墙，功能是保护你家庭内部的智能设备安全。从智能手机到笔记本电脑，保护所有设备免受黑客和网络威胁。此外，CUJO可让你控制孩子在线访问的地址以确保安全。

配置：                                        

  • 内置了双核1GHz处理器

  • 1GB运行内存

  • 4GB的机身存储空间

  • 使用了专用的加密芯片


                                        

主要功能：                                        

  • 截止恶意访问

  • 防止黑客入侵

  • 保护接入设备

  • 自动更新
