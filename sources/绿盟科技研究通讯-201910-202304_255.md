# AISecOps：基于动态图的威胁分析

一、概述  
智能安全运营（AISecOps）\[1\]涵盖了预防、检测、响应、预测、恢复等网络安全风险控制与攻防对抗技术，将大幅提升威胁检测、风险评估、自动化响应等关键运营环节的处理效率，减少对专家经验的过度依赖，有效降低企业、组织乃至国家级关键信息基础设施、数据资产的整体安全风险。如何利用多种关键技术构建AISecOps，研究任务任重而道远。利用异构数据保护网络安全已成为业内共识，此前公众号发表过的文章[《AISecOps：基于异构图的威胁分析技术》](https://mp.weixin.qq.com/s?__biz=MzIyODYzNTU2OA==&mid=2247490038&idx=1&sn=5a871a1da25d1e73adf7320d359a13b0&chksm=e84fbf29df38363fde5974f971c13dc6054611f00170fcb69290c92ec93c6891d81d5bfe5698&token=1898818104&lang=zh_CN&scene=21#wechat_redirect)介绍了异构图在威胁分析中的应用。在真实的网络环境中，为了实时的威胁分析，需要构建动态图，即图中的节点和边是随着时间变化的。本文将分析基于动态图的异常检测在威胁分析中的应用，以供从事网络安全运营的人员参考。二、基于动态图的威胁分析  

2.1**背景**

随着图技术的发展，研究人员开始利用基于图的异常检测技术进行威胁分析。然而大多数提出的基于图的异常检测方法关注静态图，基于静态的链接方法会忽略图中异常的时间特征。在基于动态图的异常检测技术的研究中，大多会将边聚合为图快照（利用过去时间段内数据构建的图）。例如，研究人员提出一种用于异常边检测的半监督学习框架AddGraph\[2\]，其核心思想是采用GCN和基于注意力机制的GRU来学习长期行为模式和短期行为模式，在训练阶段利用GCN处理当前快照中的之前节点状态，传播隐藏状态矩阵，通过注意力模型捕捉节点的短期模式，输入GRU得到包含结构、内容、时间特性的隐藏矩阵，最终在大量的数据集上证明该异常边检测方法的有效性。为了降低威胁分析与响应的周期需要实时地威胁分析，因此将基于动态图的异常检测技术应用到威胁分析中具有很高的研究价值。

2.2**一种实时检测异常边的方法**

为了在基于图的威胁分析方法中实时检测异常，需要在接收到图的边的时候就进行威胁分析。现有在线方式实时处理图中边的方法，大多检测单一异常边，因此带来的误报较多。本小节通过分享一篇论文MIDAS\[3\]来介绍一种有效的实时检测异常边的方法MIDAS将每条边看成一个三元组，包括源节点，目的节点和边添加到图中的时间。由于在一些应用场景下的时间是离散的，因此MIDAS中的图是一个多重图，即同一对节点之间有多条边，且边可以同时创建。单一源-目的对（u，v）之间的时间序列示例如图1所示，在t=10的时刻出现了大量的爆发活动包含了大量相似的节点和边，可被视为微簇异常（突然出现爆发的活动且共享大量重复的节点或边）。在离线检测中，该活动易被轻松检测出，但是在线环境中如果内存是有限的，则无法追踪该时间序列。![](../Images/281ea5a799b23b3a74c5f046535a714b.png)图1（u，v）的时间序列研究人员提出MIDAS算法，如图2所示，其利用固定的时间和内存来检测边中微簇异常或突然增加的一组可疑相似边。他们采用了Count-Min-Sketch (CMS)的数据结构\[4\]，该方法用较少的数据来描述全体数据的特性，但牺牲了准确性。表示节点u和节点v到当前时间的全部边的数量，通过CMS数据结构可以维护所有的节点之间边的近似数量。表示节点u和节点v在当前时刻（不包含过去时刻）的边的数量，该数量同样通过CMS数据结构进行维护，且该CMS数据结构会在下一个时刻的时候被重置，即可以提供当前时刻节点u和节点v的边的近似数量。当新的边到达的时候会更新CMS的数据结构，并检索更新后的计数。由于数据分布可能不同，因此采用一个弱假设：当前时刻边出现的平均概率与当前时刻之前的边出现的平均概率相同。因此需要将边分成两个类别，当前时刻边的数量和过去时刻边的数量\-。在上述假设的情况下，卡方检验定义如下所示，由于表示节点u和节点v到当前时间的全部边的数量，则在t=10的时刻期待的值为，t<10的时刻期待的值为。![](../Images/c5838e71828694874927a5ed24e0dd6f.png)通过维护的CMS数据结构可以获得和的近似值和，因此当新的边到来的时候可以采用以下公式来计算异常分数。![](../Images/839a274919fae04437f59133d066934c.png)![](../Images/586c9acbbb1df178d2aaa6dfbdfc51ca.png)图2 MIDAS算法研究人员在MIDAS算法的基础上提出了MIDAS-R算法，该方法用关系方式来处理边，将时间和空间上相邻的边组合到一起。他们将最近时刻的边也计算到当前时刻中，不再重置CMS数据结构，而是将计数减少一个固定的分数，通过权重递减来实现过去时刻到当前时刻的边的计数，该算法如图3所示。为了观察到突然出现大量边的节点，除了像MIDAS算法采用CMS数据结构来记录边的数量，还需要通过CMS数据结构和来近似计数节点u当前时刻和所有时刻边的数量。计算的异常分数包括（u，v）的边，节点u和节点v的异常分数，并选取其中的最大值来作为最终的异常分数。

当前火热的研究技术如人工智能技术等虽然应用场景较多，但是应用深度略显不足，大多限制于低层次的感知任务。在自动化过程中需要复杂任务决策的场景，现有的技术大多难以胜任，网络安全运营就是此类场景之一。AISecOps 智能安全运营技术尚处于快速演进的阶段，所采用的技术方案迭代非常快。基于动态图的威胁分析技术可以实时有效地识别威胁，为智能安全运营提供新的思路。随着智能分析技术的发展，如何促进AISecOps更好地发展还有很长的路要走，这需要网络安全人员共同探索。 欢迎点击阅读AISecOps系列相关文章。**能力框架篇：**[《AISecOps：打造可信任安全智能》](http://mp.weixin.qq.com/s?__biz=MzIyODYzNTU2OA==&mid=2247487904&idx=1&sn=0bc00ecb38f5c491ceaddd1d85b73e78&chksm=e84fb77fdf383e69429ca8987ec4e1f140be231523edcc6d3b6f415cdfe9b7c95933d7f115f2&scene=21#wechat_redirect)**数据建模篇：**[《智能威胁分析之图数据构建》](http://mp.weixin.qq.com/s?__biz=MzIyODYzNTU2OA==&mid=2247485983&idx=1&sn=a7195a5a552b3e78edd636f6863c64a3&chksm=e84facc0df3825d6ce2888e0588a219654f9ae4f8ca014bacae31a0d607e99a03c45732c422a&scene=21#wechat_redirect)[《以ATT&CK为例构建网络安全知识图》](http://mp.weixin.qq.com/s?__biz=MzIyODYzNTU2OA==&mid=2247487167&idx=1&sn=d0ee3b7369c806c3e7f4f7e926b8ccf9&chksm=e84fa860df38217679d033ffcc26682af5f3a4d84950b2ce57c07098bddc5f3d94fd6084f33f&scene=21#wechat_redirect)**技术分析篇：**[《知识图谱技术如何赋能智能安全运营》](https://mp.weixin.qq.com/s?__biz=MzIyODYzNTU2OA==&mid=2247489265&idx=1&sn=8c75ab46b58253fdcd331d44d89d2109&chksm=e84fb02edf383938d68a1bd15134613077e0a77b6d44417c24a60b8a705edcc870c6e276e763&token=1147153525&lang=zh_CN&scene=21#wechat_redirect)[《基于图的技术在企业威胁评估中的应用》](https://mp.weixin.qq.com/s?__biz=MzIyODYzNTU2OA==&mid=2247489046&idx=1&sn=b9db34a65882b47d0e586041522ee284&chksm=e84fb0c9df3839df45a687f5b9c087f282cc9616401f4eafa462ab850d4fb10370d74fe3b43f&token=1147153525&lang=zh_CN&scene=21#wechat_redirect)
