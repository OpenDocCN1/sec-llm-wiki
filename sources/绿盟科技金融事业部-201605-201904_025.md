# 微软发布1月补丁修复51个安全问题 安全威胁通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDI5MTg4MA==&mid=2247486318&idx=1&sn=69f57cfed78a5247628fd58d5ab720ee&chksm=eaaf9829ddd8113fa40fdb97f13da13f8d2d8168af5d8188cb02bab1c903635a96808d5715ca&scene=126&sessionid=1681322672#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDI5MTg4MA==&mid=2247486318&idx=1&sn=69f57cfed78a5247628fd58d5ab720ee&chksm=eaaf9829ddd8113fa40fdb97f13da13f8d2d8168af5d8188cb02bab1c903635a96808d5715ca&scene=126&sessionid=1681322672#rd)

![](../Images/85d96bc9e908b7eb533659a2c3f01fb5.png)

微软于周二发布了1月安全更新补丁，修复了51个从简单的欺骗攻击到远程执行代码的安全问题，产品涉及.NET Framework、Adobe Flash Player、Android App、ASP.NET、Internet Explorer、Microsoft Edge、Microsoft Exchange Server、Microsoft JET Database Engine、Microsoft Office、Microsoft Office SharePoint、Microsoft Scripting Engine、Microsoft Windows、Microsoft XML、Servicing Stack Updates、Visual Studio、Windows COM、Windows DHCP Client、Windows Hyper-V、Windows Kernel以及Windows Subsystem for Linux。  

![](../Images/67e34dfdcbb639accd520b7c331f6e85.png)

修复建议

微软官方已经发布更新补丁，请及时进行补丁更新。
