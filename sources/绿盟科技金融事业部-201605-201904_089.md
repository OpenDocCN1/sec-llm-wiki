> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDI5MTg4MA==&mid=2247485860&idx=1&sn=eae257c2f8728c13768581c71f41807c&chksm=eaaf9ae3ddd813f5685b3ee34c261c8e3dab0b6e59c0b5c9fed3aeef8980ced1a7c24bedcbfb&scene=126&sessionid=1681322702#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDI5MTg4MA==&mid=2247485860&idx=1&sn=eae257c2f8728c13768581c71f41807c&chksm=eaaf9ae3ddd813f5685b3ee34c261c8e3dab0b6e59c0b5c9fed3aeef8980ced1a7c24bedcbfb&scene=126&sessionid=1681322702#rd)

发布时间：2018年9月12日

概述

微软于周二发布了9月安全更新补丁，修复了64个从简单的欺骗攻击到远程执行代码的安全问题，产品涉及.NET Core、.NET Framework、Adobe Flash Player、Azure、Device Guard、Internet Explorer、Microsoft Edge、Microsoft Graphics Component、Microsoft Identity Services、Microsoft JET Database Engine、Microsoft Office、Microsoft Scripting Engine、Microsoft Windows、Microsoft XML Core Services、Windows Hyper-V、Windows Kernel、Windows Media、Windows Shell、Windows SMB Server以及Windows Subsystem for Linux。
