# 证券业金融企业网络安全建设应用篇 ——运用业务部门视角（上）

摘要：本文介绍业务安全重点和技术，梳理业务部门痛点并提出解决方案，对业务安全目标进行重点防御。本文运用业务部门视角，希望提供信息安全经理与业务部门良性沟通合作的契机，达到高阶的安全建设应用阶段。

前言  

据统计，2016年因为业务安全问题给全球经济带来的损失高达4450亿美元，比上年增加了18%。全球97%的500强企业发生过业务安全事件。关注业务安全问题已成为全球的热点与方向。在2017年度的RSA大会上，从IT安全转向业务安全成为一大行业趋势。在边界防护模式乏力之际，对于散布各处、甚至不为人所知的业务系统进行一体化的管理，成为解决数据泄露等业务安全问题的必然选择。

证券公司中核心业务部门包括投资银行业务、经纪业务、自营业务和资产管理业务等。以资产管理业务为例，其本质是信托业务，接受客户的资金或者资产委托，以某个计划的名义进行投资，投资结果返还给投资者。资管分析金融市场的长短期趋势，选择投资对象，开展资本投资管理，包含长短期投资计划及具体下单操作等。从这个角度来说，各家证券公司的分析研究能力是核心，研究数据是核心资产。那么，依托其建立的产品及其业务系统的正常运营就是业务部门的关注重点。

基于风险的管理和控制，几十年来一直是企业经营发展的标准套路。虽然信息安全领域的风控也讲了很多年，但是大到业务方向，小到界面功能，都需要衡量风险和收益。用户操作界面去掉一步冗余安全认证，能不能刺激用户多加使用从而带来更多收益，企业能不能消化随之而来的风险损失？

  

业务部门视角

如果你做过企业传统内控，你就会知道，在传统业务流程上，漏洞和弱点依旧处处都是，至少看起来一点都不比信息系统的少。以漏洞加固为例，投入所有资源和精力，期望修补所有已知的漏洞是不可行的。因此，损失可控或极低的潜在风险，本就不应成为安全团队的优先关注。如何建立正确的行业属性，提出适合业务现状的业务安全与风控方法，需要安全团队管理层、企业管理层、外部团队与业务团队共同开展良好的沟通，取得相互信任和支持。笔者以外部咨询团队身份与证券公司业务部门沟通交流，整理出信息安全领域的业务部门视角。

业务部门的关注点包括以下三个方面：

*   设计和发布符合行业客户需求的产品和配套业务（系统）；
    
*   保障业务正常运营，避免发生损害公司利益的事件，如数据泄露或勒索事件；
    
*   安全团队指导建立日常安全意识和风险管理方法，团队间取得信任和支持。
    

  

数据泄露事件

业务部门关注数据泄露对于业务经营损失和企业品牌形象的损害后果。

首先，介绍一个互联网企业事件。此事件双方是二手车信息服务领域的竞争对手，分别运营两款二手车信息服务类APP。在长达八个月期间，一方派出的“卧底”在另一方以员工身份持续窃取公司敏感数据。由于受害公司接到其客户来电反映有另一家公司赤裸裸地挖墙角，以更低报价拉客户，询问两家公司的关系才东窗事发。事件后果是造成受害公司大量客户流失，公司经营受到影响，两家公司最终对簿公堂。

![](../Images/68da4898523c8d515043d7699160a7a2.png)

图1 敏感数据泄露事件

  

同样，证券行业2015年发生的证券幽灵攻击，过程更加隐蔽，手法技术门槛更高。自被发现回溯潜伏最长十多年，默默窃取交易数据，以此谋取利益。事件分析发现，该攻击过程并不会在目标网络中大范围传播，而更加倾向于控制IT人员终端、AD域控制器以及应用服务器（DNS、防病毒服务器等），通过对IT相关设施的控制，更便于攻击者在内网范围内横向移动，窃取账号／口令、文档等关键数据，并逐步渗透进核心业务区域。

  

安全态势展示

  

在2017年上半年，针对证券业的信息安全威胁主要由DDoS攻击、WannaCry勒索事件、客户资料数据窃取等，需要关注事件背后的攻击动机。安全事件的细节是企业安全团队需要了解并解决的工作。对于业务部门最大的挑战并非技术，而是体现业务部门能够直观理解的结果展示。

业务安全风控与技术对抗完全不同，业务安全的目标是相对意义上的风险控制，而不是绝对意义上的防黑。攻击者实施拖库行为，只需一次后果就非常严重。另一方面，业务安全即使漏掉了一些，但解决了大部分的问题，整个风险也是可以被接受的。安全态势能否直观展示业务部门的关注结果和建议，是需要信息安全经理思考和解决的。

结合业务部门视角，业务安全需求转换成安全团队的理解，包括以下三个方面：

*   保障信息系统可用性和敏感数据的机密性和完整性。
    
*   利用技术和管理手段解决大规模、集中的数据泄露或勒索事件，对外部业务访问防控、内部人员操作行为内控。
    
*   利用平台资产管理能力，定义资产/数据的安全价值，资产威胁情况和资产脆弱性情况，体现安全态势。

业务安全  

业务安全的起源是由于黑产的存在，很多年前黑产就通过黑客入侵、拖库，变卖数据挣钱。随着近三年互联网金融蓬勃发展，黑产盈利门槛也随之降低。不再需要入侵对方才能套利，仅通过业务层面漏洞，对人员行为防范不严和法律空子就能获利。
