# 绿盟科技再获银联卡账户信息安全合规评估机构资质-成为唯一具有该资质的商业公司

‍‍‍‍‍ 银联卡账户信息安全合规评估的依据是《银联卡收单机构账户信息安全管理标准》，即市场上简称的ADSS标准(Account Date Security Standard)。该标准由中国银联风险管理委员会在2008年首次发布，旨在维护持卡人用卡安全，帮助银联网络内成员机构及商户提升账户信息安全管理水平。

该标准参照国际银行卡支付产业账户信息安全相关标准的同时，专门结合国内监管要求，对收单机构和商户的账户信息安全管理提出了更为具体和细致的合规要求。顺应创新支付的快速发展，该标准已于2013年完成修订。

绿盟科技凭借多年来的安全技术积累，结合中国银联制定和发布的《银联卡收单机构账户信息安全管理标准》，对银联收单网络的相关参与方提供专业化银联卡账户信息安全合规评估服务。目前协助十余家机构通过了银联卡账户信息安全合规评估，得到了一致的认可。

2017年中国银联风险管理委员会经过严格审核，绿盟科技符合《银联卡账户信息安全合规评估机构管理办法》（银联风管委\[2013\]5号）关于银联卡账户信息安全合规评估机构的基本资质要求，**于2****017年12月成功完成银联卡账户信息安全合规评估机构资质证书的续证工作，成为续证单位中唯一一家商业公司。**
