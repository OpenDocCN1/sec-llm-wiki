# Microsoft Windows 6月份安全补丁修复严重漏洞 安全漏洞通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDI5MTg4MA==&mid=2247484405&idx=1&sn=d46366be2152cb145ac701a2bb013d22&chksm=eaaf90b2ddd819a40fbc57adf1a6795ea9f15a03160f05614d4fc79ab5f5ed52e6f46f0c8fda&scene=126&sessionid=1681322803#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDI5MTg4MA==&mid=2247484405&idx=1&sn=d46366be2152cb145ac701a2bb013d22&chksm=eaaf90b2ddd819a40fbc57adf1a6795ea9f15a03160f05614d4fc79ab5f5ed52e6f46f0c8fda&scene=126&sessionid=1681322803#rd)

  

**综述**

今天微软发布了6月份例行安全更新，包含了对两个严重远程代码执行漏洞的修复：Windows Search远程代码执行漏洞（CVE-2017-8543）以及LINK文件快捷方式远程代码执行漏洞（CVE-2017-8464）。

用户应立即启动自动更新服务，下载并安装此次安全补丁来防护相关漏洞。同时本次月度例行更新还提供了一些已知漏洞的新版本补丁，也需要用户注意。

相关地址：

https://technet.microsoft.com/en-us/library/security/4025685.aspx

https://blogs.technet.microsoft.com/msrc/2017/06/13/june-2017-security-update-release/

  

  

****漏洞概述****

  

  

*   **Windows Search服务远程代码执行漏洞：**
    

      **CVE编号：CVE-2017-8543**

当Windows Search处理内存中的对象时，存在远程执行代码漏洞。 成功利用此漏洞的攻击者可以控制受影响的系统。 攻击者可以安装程序; 查看，更改或删除数据; 或创建具有完全用户权限的新帐户。

为了利用此漏洞，攻击者可以向Windows Search服务发送特制的SMB消息。 访问目标计算机的攻击者可以利用此漏洞提升权限并控制计算机。此外，在企业场景中，远程未经身份验证的攻击者可以通过SMB连接远程触发漏洞，然后控制目标计算机。

参考链接：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8543

  

*   **Windows LINK文件远程代码执行漏洞**
    
    **CVE编号: CVE-2017-8464**
    

MicrosoftWindows中存在远程代码执行漏洞，如果处理了.LNK文件，则可能允许远程执行代码。

成功利用此漏洞的攻击者可以获得与本地用户相同的用户权限。其帐户被配置为具有较少用户权限的系统的用户可能比使用管理用户权限的用户受到的影响更小。

攻击者可以向用户呈现包含恶意的.LNK文件和相关联的恶意二进制文件的可移动驱动器或远程共享。 当用户在Windows资源管理器或解析.LNK文件的任何其他应用程序中打开此驱动器（或远程共享）时，恶意二进制程序将在目标系统上执行攻击者选择的代码。

参考链接：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2017-8464

    

其余被修补的漏洞信息，请参考微软官方说明：https://technet.microsoft.com/en-us/library/security/4025685.aspx
