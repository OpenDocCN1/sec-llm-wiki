# 【紧急漏洞通告】OpenSSL官方发布更新修复多个安全漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI2NDI5MTg4MA==&mid=2247483878&idx=1&sn=7420376682bbec65c52924cc29e8d866&chksm=eaaf92a1ddd81bb710afbe665a7e3616928fd18bf82052d893776cfb4886108e8a8cf4bfdeaf&scene=126&sessionid=1681322839#rd](http://mp.weixin.qq.com/s?__biz=MzI2NDI5MTg4MA==&mid=2247483878&idx=1&sn=7420376682bbec65c52924cc29e8d866&chksm=eaaf92a1ddd81bb710afbe665a7e3616928fd18bf82052d893776cfb4886108e8a8cf4bfdeaf&scene=126&sessionid=1681322839#rd)

OpenSSL官方在9月22日发布新版本的更新，更新内容修复了自2016年5月以来的安全漏洞，包含1个高危漏洞，1个中危漏洞以及12个低危漏洞，共14个安全漏洞。

  

**CVE-2016-6304   严重程度：高**

提交时间：2016年8月29日

漏洞描述：一个恶意客户端可以向服务器持续发送超大的OCSP状态请求扩展，从而耗尽服务器的内存导致拒绝服务。

\-----------------------------------------------

**CVE-2016-6305   严重程度：中**

提交时间：2016年9月10日

漏洞描述：攻击者可以通过发送一个空记录，从而在调用SSL\_peek()函数时引起拒绝服务。

  

【本次通告详细漏洞列表请看文末附表】

官方公告地址如下：https://www.openssl.org/news/secadv/20160922.txt

漏洞影响

**影响的版本**

OpenSSL Project OpenSSL < 1.1.0a 

OpenSSL Project OpenSSL < 1.0.2i

OpenSSL Project OpenSSL < 1.0.1u

**不受影响的版本**

OpenSSL Project OpenSSL 1.1.0a 

OpenSSL Project OpenSSL 1.0.2i

OpenSSL Project OpenSSL 1.0.1u

  

漏洞修复

1    官方已经发布版本更新，建议尽快升级到最新版：

https://www.openssl.org/source/

2    如果无法升级到最新版本，为了在一定程度上缓解该威胁，则需要重新编译OpenSSL源代码，在重新编译的时候，启用“no-ocsp”编译时选项。

3    使用绿盟科技的防护类产品WAF进行防护。

4    使用绿盟科技的远程评估系统RSAS进行安全评估。

什么是OpenSSL

SSL是Secure Sockets Layer（安全套接层协议）的缩写，可以在Internet上提供秘密性传输，能使用户/服务器之间的通讯数据不被攻击者窃听，并且始终对服务器进行认证和有条件的对用户进行认证。SSL协议要求建立在可靠的传输层协议（TCP）之上，实现对应用层数据的加密传输与完整性保护。

OpenSSL是一个强大的安全套接字层密码开源库，囊括主要的密码算法、常用的密钥和证书封装管理功能及SSL协议，并提供丰富的应用程序供测试或其它目的使用。

大多数通过SSL/TLS协议加密的网站都使用了OpenSSL的开源软件包。当OpenSSL被爆出安全漏洞，影响将会涉及到所有使用OpenSSL开源包的应用。
