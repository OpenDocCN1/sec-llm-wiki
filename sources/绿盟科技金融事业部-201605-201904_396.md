# Docker Remote API未授权访问漏洞预警

**Docker 是一个开源的应用容器引擎广泛的应用于各大云平台上，百度云、亚马逊云等都有使用。**

**![](../Images/6a7dd73eb03e5d48403f32ea51e57650.png)**

**漏洞分析**

在Docker Swarm的默认配置中，远程默认启用了2375端口，且在此端口上运行的Docker Remote API支持远程配置，如果将此端口暴露在公网上，可导致攻击者远程控制主机获取root权限等危险操作。

**影响范围**

1.  开启了remote调用的Docker
    
2.  使用了Docker swarm 的企业
    

**修复建议**

限制2375端口的访问，设置ACL策略。
