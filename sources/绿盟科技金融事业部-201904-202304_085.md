# 背景需求

随着金融科技的发展，商业银行电子渠道业务的迅速扩张，如网上银行、手机银行、直销银行等一系列的电子银行业务，由于其全天候、不分地域、开放程度高等特点，成为了网络攻击的重点，带来了更多的信息安全风险。各种网络攻击、数据泄露事件层出不穷，要确保金融科技的平稳健康发展，必须妥善解决好网络安全的问题。当前金融行业的 IT 管理系统主要面临着以下几种挑战：多源异构数据采集需求、海量数据存储与分析需求、安全指标及态势的可视化展现需求、信息安全一体化建设和监管需求。

根据金融十四五规划中的要求，我们可以发现态势感知平台仍然是监管重点关注领域。

**《金融标准化“十四五”发展规划》**

建立健全金融业关键信息基础设施保护标准体系，支持提升安全防护能力。加强金融网络安全能力评估、风险排查、安全防御、漏洞管理等标准建设，助力提升网络安全威胁发现、监测预警、应急处置、攻击溯源能力。

**《保险科技 “ 十四五 ”规划》**

有效提升安全防护能力。持续推进网络安全保障能力建设，强化安全管理整体协同、统筹协调，构建安全运营中心，以面向新型未知威胁、大规模网络安全事件的监测预警作为重点，持续提升网络安全威胁态势感知能力。

**《证券期货 “ 十四五 ”规划》**

研究探索态势感知等新技术在网络安全防护中的应用实践，提升动态防御和主动防御能力。建设行业威胁情报平台，提升行业整体监测预警、溯源分析、联防联控能力。通过人工智能算法和威胁情报机制，提升威胁检测能力，实现全局感知、上下联动、群防群治的效果。

# 解决方案

**合规-人行数据上报**

![](../Images/597f77def5aa7a1cb6eb463cc543b5f6.png)

针对于人行标准的理解及多年金融行业项目的积累，绿盟科技在原有BSA大数据安全平台基础上，引入格式化转换APP及前置通信模块，实现人行要求数据格式的采集、转换、管理配置、查询检索、录入编辑、外发上报。

**合规+运营-日志威胁集中管理**

![](../Images/36ee8479819a09f050748a1e481095ef.png)

日志威胁集中管理包含日志的全量存储和日志分析，两类信息均将存储于安全运营平台，全量日志作为溯源依据，完整记录在平台内；日志分析后的安全事件，将通过上层应用在不同业务单元中展现，供日常运维使用。

**运营-全流量溯源取证检测**

![](../Images/37e5c913931595034a15e74b6c96b98d.png)

全流量溯源取证通过结合综合威胁分析系统（UTS），进行全流量元数据的记录和可疑行为检测，并将所有日志信息传递给安全运营平台。同时，所有流量信息将根据配置规则在本地存储，安全运营平台可按需进行数据提取。

安全运营平台基于UTS传递的信息，结合平台分析规则和攻击链模型，进行攻击结果判断、失陷资产检测；为提高运营研判效率，平台进行了攻击特征高亮、流量上下文展示，并提供Pcap溯源取证；同时避免0day、Nday漏洞的遗漏，可设置自定义回溯检测。

**运营-异常行为分析**

![](../Images/a6fb0526bca49ec27c8fdec44ce7c608.png)

UEBA （Use Entity Behavior Analytics）指的是用户与实体之间行为的分析，异常行为与安全攻击有所区别，无法通过常见的攻击检测引擎进行识别，如风险账号、风险终端、内部异常访问和数据泄露，平台中行为分析引擎可支撑静态基线检测引擎和动态基线检测。异常行为分析覆盖内部访问、数据泄露、风险账号、风险终端四大类百余个子场景，可从海量数据中找到主体与客体间潜在的异常关联行为，提前防患于未然。

**运营-安全编排与自动化响应处置S****OAR**

![](../Images/6309d08a8da0433b033112e2ce843ec6.png)

对于安全人员比较稀缺的单位，可以借助ISOP-SOAR模块实现安全编排与自动化响应。该模块通过可视化编排将人、安全技术、流程进行深度融合；将L1、L2、L3安全运营工程师操作的经验与知识固化为SOAR中的案例及playbook剧本，Playbook剧本可串并联构建安全事件处置的工作流，自动化触发不同安全设备执行响应动作，案例管理功能建立了攻击识别规则、运维事件与自动化响应处置动作之间的关系，一旦攻击事件与SOAR中开启的案例得到了匹配，该事件可在无需人工干预的情况下，通过剧本完成自动化闭环处置。

**运营-资产安全管理**

![](../Images/d84cb517a8c4db461816377f2ebd7425.png)

资产安全是安全防护的基础和前提，安全运营平台中资产安全管理包括资产发现、资产底图信息库建立、资产变化跟踪、异常资产识别分析、资产安全预警、资产安全画像几个步骤。

**运营-威胁情报预警**

“威胁情报”是网络安全滑动标尺模型的第四阶段。通过威胁情报，可以了解更多攻击者信息，更好的识别攻击者，从而更好的响应和处置攻击活动。平台主要作为威胁情报的消费者，结合威胁情报对网络风险进行预警，实现事前防护及对网络威胁进行确认和溯源。

**运营-M****DR****辅助人工运营服务**

![](../Images/8e70c4a45cb6aad89c98fcea7c803a45.png)

MDR安全运营服务以资产为基础，实现威胁、脆弱性管理闭环，并通过服务工具提升检测及防护效果的一站式安全运营解决方案，通过为客户提供从运营落地规划、建设到运维的全价值链，贯穿预警、防护、监测、响应和处置的安全闭环流程，持续降低企业的安全风险。

# 方案价值

1. 满足人行数据上报的强制要求

有效协助金融机构完成人行态势对接和情报数据上报。

2. 满足金融等保的安全管理中心要求

  安全运营平台可完全胜任安全管理中心的功能要求，进行全网设备的日志收集，并进行安全事件集中研判、处理。

3. 提升行方安全防护能力

安全运营平台将行方的不同安全能力融合，实现安全能力并集。同时基于全方位、多角度的监控覆盖，实时发现行方资产存在的风险，并及时进行处置缓解，有效降低企业信息安全风险，提升企业安全防护能力。

4. 提高安全事件分析能力

安全运营平台将攻击链模型、ATT&CK模型、威胁知识图融入到平台威胁分析建模，从海量数据中聚效到攻击者攻击行为，同时结合全流量相关信息，提升分析研判准确度。

5. 提高响应处置能力

通过安全编排自动化响应组件可以将安全工程师分析、研判、处置经验固化，在事件发生时实现自动化编排与响应的能力，提降低MTTR处置响应时间。
