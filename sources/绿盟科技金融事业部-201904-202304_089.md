# 绿盟科技被列入Gartner发布的《中国云安全资源池创新洞察报告》

近日，Gartner发布《Innovation Insight for Cloud Security Resource Pools in China》报告（中国云安全资源池创新洞察报告），绿盟科技凭借在云安全领域的优异表现，成为云安全资源池代表厂商之一。

新冠疫情加速了数字化转型进程，上云用数赋智已成为千行百业转型的必然选择，云计算安全亦备受关注。Gartner指出“随着数字化和云应用的增加，组织应寻求更灵活和敏捷的方式来部署安全能力。”  

  

绿盟科技自2010年起开展云安全研究，致力于以软件定义安全，重塑传统安全，提供更全面、灵活和高效的云安全解决方案，并发布了绿盟云安全集中管理系统。该系统利用软件定义安全，将安全能力整合为统一安全资源池，管理能力汇集到统一安全平台，通过统一安全平台与云计算环境融合，实现安全能力的统一管理、安全数据的统一分析、流量与能力的自动编排和安全事件的自动化响应，为云计算构建弹性、智能、协同和开放的原生安全防护。

![](../Images/a6c9a5f673244bc3d5d05e6d18e930b8.png)

  

***01***

一致安全能力

绿盟云安全集中管理系统利用网络功能化，将多种安全设备转化为安全功能单元，统一部署在安全资源池，其形态可以是虚拟机或软件，甚至是容器，并可集中部署在云平台旁边或云中，能适应不同云计算环境。安全能力由统一安全平台进行统一管理，能够快速部署和弹性扩展。安全资源池采用开放式架构，可扩展新安全能力，如数据安全和零信任，甚至是第三方的安全能力，适应新的安全场景。

  

***02***

统一安全平台

绿盟云安全集中管理系统利用MANO、大数据安全分析和SOAR，建立统一安全平台。一方面，安全平台提供统一安全管理界面，可实现多个云平台安全能力的统一使用、统一策略配置和统一交付。通过大数据安全分析能力，统一收集和分析各种安全能力所产生的安全数据，以及云平台所产生的大量日志和配置数据，建立统一和更全面的安全可见性。安全管理人员根据安全状态，自主调整安全策略，为多个云平台提供主动的安全防护；另一方面，安全平台采用开放架构，可与云平台、DevOps进行集成和自动化交付，成为云或DevOps的一部分，也可将安全数据和安全事件提供第三方平台。

  

***03***

统一安全服务

基于资源池的安全能力，统一安全平台对安全能力进行封装和抽象，以安全能力或服务的方式在Web页面进行展示和使用，如防火墙服务、入侵防御服务、WAF服务和主机安全等安全即服务。根据安全需求，租户自助使用安全服务，最终由统一安全平台把安全能力交付到各种云环境中，快速保护云平台、信息系统和数据。

  

为了更好的服务用户，绿盟科技于2022年5月在合作伙伴大会上正式发布云化战略——T-ONE CLOUD。T-ONE CLOUD是绿盟科技“智慧安全3.0”理念的全新实践，旨在以云的思路重构安全运营体系，为用户提供弹性敏捷的安全闭环保障能力。绿盟科技长期积累的各类不同形态的安全能力，都可以通过T-ONE CLOUD的模式为用户提供服务，为千行百业数字化转型保驾护航。

绿盟科技已经入选“Gartner Hype Cycle for ICT in China（2020、2021）”和“Tool: Vendor Identification for Cloud Security in China（2022）”报告，此次再次入选“Gartner Innovation Insight for Cloud Security Resource Pools in China”报告是对绿盟科技云安全能力的进一步认可。未来，绿盟科技将继续加大云安全领域的投入，贡献更多的研究成果，提供更优秀的云安全产品和方案。
