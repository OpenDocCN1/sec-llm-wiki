# 双双入选｜绿盟NF防火墙系统和绿盟WEB应用防护系统喜获首批IPv6 Enabled Security Logo认证

近日，由下一代互联网国家工程中心和全球IPv6论坛联合主办的“2021全球IPv6下一代互联网峰会”在广州召开，会上正式发布了IPv6 Enabled Security Logo认证。**绿盟NF防火墙系统和绿盟WEB应用防护系统作为参测代表产品均率先通过认证，成为首批获得认证的安全产品。**

![](../Images/442a1d9583ca7a42781aac1fd3ea693c.png)

  

如今以IPv6为基础的下一代互联网产业发展势如破竹，但IPv6网络的普及也将为网络安全带来了不容小觑的风险和挑战。网络安全设备只有在协议层和应用层均完全支持IPv6，才能保证在IPv6网络环境实现网络功能防护，这对网络安全设备厂商提出了更高的要求。

  

绿盟科技深度洞悉下一代网络技术发展方向，深刻理解用户需求趋势，并且不断推出符合市场需求的安全产品。

本次获得IPv6 Enabled Security Logo认证的绿盟NF防火墙系统是绿盟科技构建在新一代高速多核硬件平台之上的防火墙产品，其高度融合绿盟科技在安全、技术方面的一贯优势，体现了专业的应用和用户识别控制能力、高性能的一体化安全防护能力、以及多方位的联动协同防护能力。结合诸多的产品优势和丰富的产品功能，绿盟NF防火墙系统将为用户带来诸多智能便捷服务，包括安全风险的可视可知、全面一体的安全防护以及稳定高效的无忧部署等，为客户业务的安全顺畅运行保驾护航。

  

2021年6月，IDC发布《中国硬件Web应用防火墙（WAF）市场份额，2020：贴合业务需求，关注技术升级》研究报告，绿盟科技WEB应用防护系统市场份额再次稳居中国硬件WAF市场第一。绿盟科技WEB应用防护系统自2008年上市以来，致力于为用户提供全方位企业级WEB安全防护能力和服务。其具备多引擎防护，精准检测；轻部署，按需使用，快速灵活的特点，同时支持在私有云、国内主流的公有云上快速部署，解决当前有“云上”业务的企业用户有业务、没安全的尴尬局面，帮助企业全面抵御各类WEB威胁。

  

此次首批获得IPv6 Enabled 安全认证的绿盟NF防火墙系统和绿盟WEB应用防护系统，更加适配用户的IPv6环境改造，面向L4至L7层的网络环境，提供全面的IPv6安全防护，保障用户在IPv4、IPv6及其混合环境下的业务安全。

  

IPv6 Enabled Security Logo认证，是面向网络安全产品在L4-L7 层进行IPv6支持情况的测评，从网络防护、应用防护和入侵检测等方面来检验产品对IPv6的支持程度。通过该测评表明网络安全设备在IPv6网络协议安全和IPv6网络功能防护方面具备了较强的能力，能够有效保障用户在IPv6环境下的网络安全。
