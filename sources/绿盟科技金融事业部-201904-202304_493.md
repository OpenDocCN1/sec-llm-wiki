03

漏洞点评

Oracle Database Server存在一个远程安全漏洞。该漏洞可通过多个协议利用，影响Java VM组件。Oracle Database Server 11.2.0.4、12.1.0.2、12.2.0.1、18c、19c版本受此漏洞影响。目前厂商已经提供补丁程序，请到厂商的相关页面下载补丁。
