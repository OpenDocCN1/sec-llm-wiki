# 钱学森智库聚焦宁夏水治理现代化 第十期钱学森论坛在宁夏银川圆满闭幕

**钱学森智库聚焦宁夏水治理现代化**

**深入贯彻中央新时期治水方针**

  

  

  

![](../Images/c60620e466b513d365dad4651fa8cd57.png)

  

  

  

![](../Images/e9335aa6fbdb3c70f33dc750ba9df82a.png) 9月27日         第十期钱学森论坛在宁夏银川隆重举行！本期钱学森论坛由宁夏回族自治区人民政府、中国工程院、中国航天科技集团公司指导，我院联合宁夏回族自治区水利厅、中国航天工程科技发展战略研究院共同主办，论坛主题为“钱学森智库聚焦宁夏水治理现代化——深入贯彻中央新时期治水方针”。论坛前，自治区主席咸辉会见了出席此次论坛的嘉宾、院士及专家一行。国家水利部党组成员、副部长魏山忠，宁夏回族自治区党委常委、副主席马顺清及10余位水利、航天、经济社会等领域院士和专家出席论坛！其中，王礼恒、李佩成、傅伯杰、王玉民、汪同三等院士、专家围绕新时期治水方针“节水优先、空间均衡、系统治理、两手发力”作主旨报告，领导嘉宾近千人参加论坛。

  

  

![](../Images/e36c4ffd062a140fd7d32c308c18ba5b.png)

![](../Images/271bc92d1caa2d6f4a6f03d2d03a4235.png)        论坛前，自治区主席咸辉等自治区领导会见了出席此次论坛的嘉宾、院士及专家一行。

![](../Images/8b1c8d1a4bb42f5d805f0eb33169900a.png)        本期“钱学森论坛”旨在践行中央新时期治水方针政策，全面贯彻中央“五位一体”总体布局和“四个全面”战略部署，深入落实新时期发展理念，聚焦水利发展大局，推进治水兴水新跨越，结合宁夏水利发展的自身条件，瞄准制约宁夏治水兴水的技术和管理瓶颈，广泛集成国内院士、知名专家学者的创新思想，为宁夏水利转型升级、服务宁夏经济社会可持续发展提供智力支持。  

![](../Images/bc91a21564698cb46afe6b87cde60529.png)

        郭京朝书记在开幕词中指出：宁夏是我国最古老的灌区之一，引黄灌溉已经有2000年的历史。古老的水利工程，造就了沃野千里、稻田遍布的宁夏平原。“塞上江南”稻米飘香，沙湖苇海放眼千里，候鸟高飞翱翔天际。“天下黄河富宁夏”，宁夏的历史，很大程度上就是治水兴水的创业史。本次论坛的召开，就是要“揽天下之英才，聚八方之智慧”，齐心描绘“以水兴业、以水惠宁”的壮美画卷。期盼各位专家畅所欲言，激荡真知灼见，传承源远流长的治水文明，彰显经略江河的中国力量，以优异的成绩，迎接党的十九大胜利召开！

![](../Images/acf27c866b5b2868bacc10673c666c2b.png)

        自治区党委常委、副主席马顺清作题为“坚持节水优先、推进协调发展”主旨报告，介绍了宁夏与全国同步建成全面小康社会进程中的水治理策略。他提出，宁夏的经济社会发展史就是一部生生不息的治水史。历届自治区党委、政府高度重视水利事业，带领各族人民用艰辛与智慧，初步建立起一个统筹水资源节约、水环境治理、水生态保护，兼顾生活、生产、生态用水的水安全保障体系，描绘着中国西北地区精彩治水篇章。后续，宁夏将把治水放在基础设施和生态文明建设的重要位置。全面应对水困局，抓好水治理，破解水瓶颈，保障水安全，推动新发展，实现经济繁荣、民族团结、环境优美、人民富裕的美好目标，共同构建水生态治理命运共同体，为开创水生态文明建设的美好未来，贡献宁夏智慧和担当，产生宁夏与全国同频共振效应。  

![](../Images/36c60a15eee1672e309ec8dc62150e35.png)

        论坛上，薛惠锋院长谈到，贯彻以习近平同志为核心的中央治水方针，运用钱学森智库思想，为“中华水文明”的永续传承，谋长远之计、行根本之举。中国航天系统科学与工程研究院具有无比广阔的时代舞台，无比深厚的历史底蕴，无比强大的实践优势：战略上，以“文艺复兴”指引“产业兴水”；战役上，以“综合集成”推动“系统治水”；战术上，以“天地一体”实现“数据管水”。当前，宁夏发展的最大瓶颈在水、最大出路在水、最大动力在水、最大价值也在水。运用钱学森智慧，做好“以水兴业、以水富民、以水维安”的大文章，构建涵盖经济、政治、文化、社会、生态的“大水业”工作格局，就一定能够为贯彻中央治水方针闯出新路、打造宁夏典范！

![](../Images/200b517baab722f430e59e2ab1c0c6e2.png)

         李佩成院士对新时期治水方针中的“节水优先”畅谈了自己的认识。他指出，在节水领域，宁夏为全国开了好头，取得了许多成功经验。望今后大力推进节水优先战略，践行新时期治水方针，为新常态下的宁夏提供可持续的生命之源，为经济社会发展提供更坚实的水安全保障。

![](../Images/e96e67395e4421d44b37aab2ef75b911.png)

        傅伯杰院士提出：破解我国水资源瓶颈的根本出路是集约和高效节水，依靠的基本力量是科技创新和制度创新，当务之急和长远之策是全民全社会强烈节水意识和理念指引下的生产生活方式根本转变。下一步的实施措施是尽快制定国家节水规划和节水战略路线图，把节水贯穿于经济社会发展、国民素质教育和水资源开发利用的全过程和全方位中。实现2030年逐步达到总用水“负”增长的总体目标，推动中国社会经济可持续发展！

![](../Images/2d4668be297b70e19b9f7c20b6060337.png)

        许健民院士回顾了风云气象卫星中心的发展历程；介绍了风云气象卫星作为国内最大的遥感卫星共享中心之一，具有强大的数据服务功能；重点分析了气象卫星在环境监测中的应用主要体现在对生态系统的植被、土壤、水、大气以及气象灾害、次生衍生灾害发展情况的实时观测等方面。许健民院士强调地球的降水总量是不变的，因此对于破解水资源缺乏困局，最重要的是节水而不是降水。

![](../Images/10cdeb88a0fd42b62b366b7d92c24fcc.png)

        中国社会科学院学部委员汪同三指出：“新常态”下进行经济建设必须对投融资进行创新。汪委员以马克思的扩大再生产理论为基础，以投资作为生产活动的重要投入要素为出发点，重点分析了投资对经济社会的重要意义。报告回顾了我国投资工作的历史沿革，引入现代市场经济中与投融资密切联系的虚拟资本的有关问题，介绍了当前我国创新投融资中民间投资、国企改革和PPP融资创新模式等内容。通过解读国务院最近发布的《关于进一步激发民间有效投资活力促进经济持续健康发展的指导意见》，重点分析了PPP融资创新模式。

![](../Images/ec04939488729c68255531d75d01894e.png)  

        王玉民院士首先表示宁夏人民在长期的水治理与经济社会发展经验中，形成了独到的“宁夏特色”发展模式，取得了骄人的业绩。但相对于中部崛起战略目标与国家跨越发展战略目标的要求，差距较大，潜力巨大！他提出：借鉴以色列水资源革命，在国家创新驱动战略的牵引下，智慧水利是破解宁夏水治理现代化的金钥匙！建议发挥区位优势、借助国家战略因素，尽力争取将宁夏发展置于更大区域甚至国家战略部署的“大棋盘”中，加速实现宁夏水治理的现代化！![](../Images/c0c42bd7166b50ef5eedb4f1ba7ca178.png)

        水利水电规划设计总院李原园副院长在保障水资源-经济社会-生态环境性协同发展提出前瞻性想法：划定水生态空间和生态保护红线；形成“四横三纵、南北调配”的国家层面河湖水系连通总体格局，提高国家水资源统筹调配能力和生态环境保护能力；塑造合理健康良性的流域循环过程；构建防控水安全风险体系。

![](../Images/fb580551c4e6e9b5ff92b1e310066ab4.png)

        中国水利水电科学研究院高占义总工介绍了世界灌溉遗产和我国灌溉遗产的基本情况。他提出，宁夏古代引黄灌溉工程作为我国四大古老灌区之一，支撑了区域社会经济发展，赋予了宁夏“塞上江南”的根本，是宁夏区域历史文化的重要组成部分。宁夏古代引黄工程遗产不仅属于宁夏，也属于中国、属于世界。保护引黄古灌区意义重大！宁夏引黄灌溉工程遗产保护需要各相关部门和行业共同努力，形成合力，需要健全引黄古灌区保护利用体制机制。

![](../Images/87e62cb46f41aa732cc77ba7cfb598c0.png)

        军事科学院姜春良少将指出，宁夏水安全发展战略应当以“节水优先、空间均衡、系统治理、两手发力”新时期治水方针为指导，结合宁夏水利实际情况，制定符合宁夏的兴水治水战略。要牢固树立绿水青山，就是金山银山的理念，推进山水林田湖系统治理，治水与治山、治林、治荒、治田有机结合，使水资源、水生态环境承载力与经济社会发展相协调，走出一条生态优先、绿色发展之路，使水利事业成为经济社会发展全局中战略支撑。

![](../Images/cab65f53a267713afeaed0502b96551b.png)

        中央党校李宏伟教授以水生态文明在生态文明建设中的重要地位为背景，介绍并分析“河长制”推进下的制度创新以及推进过程中存在的问题，提出全面推行河长制，是助力美丽生态文明建设迈入新时代的利器，需要统筹好水资源开发与保护关系；加快构建责任明确、协调有序、监管严格、保护有力的水治理长效机制；将河长制落实情况纳入到最严格水资源管理制度的考核中，提升水生态文明建设的水平。并表明，推进水生态文明体制机制创新需由被动治理向主动防护转变，从“点源治理”为主向“点源、面源同控”转变。

![](../Images/90efa0c90a7e30bcfab2841e70a9bac8.png)

        最后王礼恒院士作论坛的总结发言，他指出：水是生命之源、生产之要、生态之基。兴水利、除水害，事关人类生存、社会进步，历来是治国安邦的大事。习近平总书记提出的“节水优先、空间均衡、系统治理、两手发力”的治水思路，既是实践经验的总结，也是思想理论的发展，对推进中华民族治水兴水大业具有重大而深远的意义。宁夏自治区虽然是人均水资源占有量不足全国人均水平1/3的西部内陆省份，但却是全国唯一的省级节水型社会建设示范区。在中国治水的宏大版图之上，宁夏通过实施分区治水、探索水权管理、倡导全民节水等多项措施，取得了巨大成效。结合今天各位院士、专家的现场讨论，王院士指出，加快推进宁夏水治理现代化的步伐，可以考虑从以下几方面开展：一是要继续完善提升宁夏治水战略；二是要推动落地宁夏重大水工程，加快构建完善宁夏水工程网络，提升水资源调控和保障能力；三是要推动宁夏“智慧水利”十三五规划的完善提升和建设实施；四是要加快建设宁夏现代灌区；五是要举全社会之力，合作治理保护宁夏水生态水环境。当前，我国水治理形势严峻，我们一定要把习近平同志治水兴水的新思想、新思路、新要求落到实处，加快推进治水兴水新跨越，为实现中华民族伟大复兴的中国梦提供更加坚实的水安全保障，为子孙后代留下生存发展的资源和空间！

![](../Images/6511c8c008678382b6cf56645211ab91.png)

        此外，受宁夏回族自治区水利厅委托，中国航天十二院与宁夏回族自治区水利科学研究院共同开展的《宁夏水治理发展战略研究》课题启动会在悦海宾馆同期举行。
