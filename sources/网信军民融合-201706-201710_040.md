# 砥砺奋进的五年 | 北斗导航 俯瞰大地

今年9月开学，安徽合肥市庐江县金牛小学的学生们坐上了北斗校车。通过在校车上安装北斗卫星定位装置，能随时获取校车位置，实时监控校车是否超载、超速。

“天上”建好、“地上”用好，离不开北斗人的奋斗。中国电科54所高级工程师王晓玲团队潜心研发北斗，把最美的青春都奉献给了北斗事业。

这支从事北斗地面系统研发的团队由16位女性组成，平均年龄只有34岁，是不折不扣的“娘子军”“青年军”，也是北斗这张“国家名片”的有力支撑。她们研发的数字多波束系统，作为北斗系统的核心装备，已达到国际卫星导航领域的领先水平，“北斗智慧景区智能搜救终端及区域应用系统”亮相国家“十二五”科技创新成果展。

尽管科研面前没有性别，但她们确实付出了更多。为家人做早餐、陪孩子出去玩都是一种奢侈，经常加班到深夜。朱姗姗经常一个人出差，一年最多要200多天，而联试地区基本在郊外，生活条件十分艰苦。郑迎春在九寨沟测试设备，途中脚底被扎伤,在同事搀扶下，还是保质保量完成了测试任务。

“一切辛苦与艰难，都不及成功的喜悦让人记忆深刻。”王晓玲说，看着北斗系统核心关键技术全面突破，北斗的应用越来越广泛、深入，她们觉得一切都值得。

**点 睛**

北斗卫星导航系统是全球四大卫星导航系统之一，也使我国成为继美、俄之后世界上第三个拥有自主卫星导航系统的国家。自2012年北斗卫星导航系统实现区域组网并投入运行以来，北斗系统的性能指标稳中有升，可以为用户提供与美国GPS性能相当的高质量导航定位服务。北斗系统已名声在外，是国际海事组织认可和国际移动通信标准支持的全球卫星导航系统。在2020年形成全球服务能力后，将成为世界一流的全球卫星导航系统。
