# 全军“作战概念推演-2018”举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247487071&idx=3&sn=64a57aa9fb77b79b2870e39d330e65f6&chksm=e9bc1ae1decb93f76f7a156970f7b5dec56e2ed480b5a92ef45b6616a09a287a4a078ed28fe4&scene=126&sessionid=1681311556#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247487071&idx=3&sn=64a57aa9fb77b79b2870e39d330e65f6&chksm=e9bc1ae1decb93f76f7a156970f7b5dec56e2ed480b5a92ef45b6616a09a287a4a078ed28fe4&scene=126&sessionid=1681311556#rd)

12月13日，来自全国20多个军地单位的50多名专家代表在陆军指挥学院齐聚一堂，参加“作战概念推演-2018”，这是全军首次组织作战概念推演活动。

  

![](../Images/960d466883885b34600cf2b9dc4ee8f6.png)

  

军委机关、陆军机关领导出席会议并参与研讨。

  

![](../Images/f23c6b8d4a804f84d0a7bc552cd47e69.png)

  

此次推演活动成立了由战区、院校、部队、企业成员构成的联合推演组，并邀请军委机关、陆军机关、军种院校、科研院所、工业部门等各方专家参与研讨，目的是建立一套科学的作战需求供应链，探索出我军作战概念创新和发展的新路子。

  

![](../Images/8b09de6faebebe68a863e2b999b7e36c.png)

  

联合推演组详细汇报此次推演活动的具体情况。各领域专家就相关问题积极发言。并组织与会代表参观各类推演系统。

  

![](../Images/a2effb3287b05dbca41796fdec3c3389.png)

  

会后，与会代表进行了充分的研讨交流，对建立科学的作战需求“供应链”，推动我军作战概念创新发展提出了许多创新理念，为进一步激发动力、达成共识，加快推进我军转型建设，探索作战概念创新发展之路奠定了基础。

  

  

![](../Images/5eba9871e892cad85b4c8d463f6925e3.png)

  

活动突出作战概念牵引。推演是对未来作战形态、样式、行动和力量的超前设计和概要描述。作战概念紧贴军事需求，重点回答未来打什么仗、怎么打仗、用什么打的问题。只有把作战概念研究透了，才能搞清楚未来作战方式、部队建设发展。

  

![](../Images/f573dde96a96e7c390978c51223227c3.png)

  

活动突出理技融合推动。习主席在视察军事科学院时指出，要坚持理技融合、研用结合、军民融合，加快发展现代军事科学。组织作战概念推演是落实习主席指示，探索“需求牵引、技术支撑、实验优化、体系联动”的研究范式。

  

![](../Images/394879388e14e03813217b17514e0049.png)

  

活动突出开放融合研究。前瞻性的作战概念仅靠一个研究机构、一所院校、一家企业，甚至一个军种的力量都没办法研究透。因为这涉及到作战背景、武器装备、作战设计、作战数据、作战环境、作战对手等方方面面的内容，所以必须集智攻关、开放研究、融合创新。

  

![](../Images/2f834423b5c4a085a5e80855fffeabc3.png)

  

“作战概念推演-2018”在军委机关、陆军机关指导下，采取“开小口，迈大步”的方式，先行尝试探索新型作战概念推演的模式和方法，通过搭建平台、开放研究积累经验，为后续展开大规模作战概念推演奠定基础，探索出军民深度融合创新作战概念的新路子。
