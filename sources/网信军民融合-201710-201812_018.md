# 扣押孟晚舟，美国叵测用心昭然若揭

**种种信息综合来看，正如中国驻加拿大使馆所发表的声明，这是一场确凿的侵犯中国公民人身自由的违法行动。**

![](../Images/eee1422a543e9baf5676c58e81ffceac.png)

“美国为什么要一直针对华为，是因为我们在5G方面做得太好，还是因为其他我不确定的原因？”华为副董事长徐直军近日在接受媒体采访时说的话，现在来看，更像是一种预警。

  

**一次蹊跷的“执法行动”**

  

一周后的今天，加拿大《环球邮报》传来一条爆炸性消息——华为首席财务官（CFO）孟晚舟被加拿大警方暂时扣留。国外媒体推测的理由是“华为涉嫌违反了美国对伊朗的贸易制裁规定”。

  

![](../Images/89c6ff4b48e432026136bcb4d7881593.png)

  

事发后，华为副总裁陈黎芳证实孟晚舟被加拿大当局代表美国政府暂时扣留。但因信息非常少，华为并不知晓孟女士有任何不当行为。并强调，华为遵守业务所在国的所有适用法律法规，包括联合国、美国和欧盟适用的出口管制和制裁法律法规。根据陈黎芳的回应，“华为涉嫌违反了美国对伊朗的贸易制裁规定”的逮捕理由显然是不成立的。

  

此前据《华尔街日报》报道，美国司法部门自2016年起对华为涉嫌违规出口通讯设备进行调查，至今仍无结果。

  

根据美国法律，此次通过第三方逮捕孟晚舟，与其处理其他案件的方式明显不同，没有给出明确的司法理由，加拿大警方作为执行方也没有给出明确的司法理由。

  

种种信息综合来看，正如中国驻加拿大使馆所发表的声明，这是一场确凿的侵犯中国公民人身自由的违法行动。

  

**一轮疯狂的市场围剿**

  

一直以来，华为在美国遭受了严重的不公平待遇。“反华为”甚至已经成为美国政府、政客、电信厂商的一致口径。美国市场禁售华为设备，并宣称使用华为设备存在网络安全隐患，但实际上美国自己的互联网技术公司经常发生信息安全事件。今年四月，脸书（Facebook）CEO扎克伯格因为信息泄露案件专门在美国国会听证会上接受质询。

  

华为作为5G技术的领导者，一直被阻于美国市场之外，美国的5G市场是没有进行充分竞争的市场。正是因为美国政府的各种保护主义做法，美国厂商未与华为在5G领域进行过正当的市场竞争。缺少了华为的良性市场竞争，美国关起门来自己玩独角戏又能好到哪里去？

  

华为经过多年的努力，已经在世界上很多国家建立起成熟的业务网络和良好的用户口碑。然而，美国现在要求其盟友英国、澳大利亚、新西兰等国拒绝让华为参加本国建立5G移动网络设备投标。近日，英国宣布逐步弃用华为4G通讯设备，并在该国的5G招标中排除华为。澳大利亚通信部部长也要求必须将“某些特定供应商”排除在澳大利亚的5G网络之外，却完全不顾华为已经是澳大利亚最大的电信设备供应商的事实。

  

**一场没有硝烟的战争**

  

孟晚舟作为华为首席财务官主要负责华为的财务工作。即使美国政府怀疑华为存在向伊朗出售设备的行为，孟晚舟无论如何也不是第一负责人，但孟晚舟的另一个身份是华为创始人任正非的女儿，她是一直被外界看好的华为接班人。

  

需要指出的是，孟晚舟作为当事人有权申请司法缄口令，可以要求不公开相关信息，但美加两国当局在不与中国方面事先沟通的情况下、在不说明任何理由的情况下公然限制中国公民自由。很难让人相信美加的司法部门此次行动具有合法性。

  

事实上，美国政府一直惯用各种合法不合法的手段来打压潜在的外国竞争企业。回顾华为这几年的遭遇，我们可以清晰地看出美国政府的“套路”。美国政府先是从安全上抹黑华为，通过议员讲话、政府站台等方式用各种安全威胁来吓退与华为合作的企业和购买产品的消费者，然后发起调查、发布政令严禁华为参与市场竞争。与这些措施相比，此次以限制人身自由的强制手段扣留孟晚舟更显尽其叵测居心。

  

面对华为这样蒸蒸日上、发展迅猛的中国高科技企业，美国政府和相关利益集团显然是下定了决心要将华为逼入绝境。因为华为是当今5G技术的有力领导者。5G就是未来。谁掌握了5G技术的领先优势，谁就掌握了未来信息世界的领导地位。美国政府岂能甘愿一家中国企业走在时代的前列，站在世界的潮头？

  

此次孟晚舟事件不仅揭露出美国的霸权主义逻辑和霸凌作风，更再次提醒中国人一定要丢掉幻想、自强自信,一场没有硝烟的战争已经拉开帷幕。
