# 倪光南院士：Intel（x86）、ARM、RISC-V未来将三分CPU天下

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247486953&idx=1&sn=9bf85001450e86932b529388b72b88a8&chksm=e9bc1957decb904182238078f33a35304aa2ad67121a81cb8a88f921e17f2e1662c03c41564b&scene=126&sessionid=1681311561#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247486953&idx=1&sn=9bf85001450e86932b529388b72b88a8&chksm=e9bc1957decb904182238078f33a35304aa2ad67121a81cb8a88f921e17f2e1662c03c41564b&scene=126&sessionid=1681311561#rd)

**【编者按】**在2018创新者年会上，中国工程院院士倪光南做了《中国开源芯片（RISC-V）的前景》的主题演讲。他指出，RISC-V具有模块化、可扩展、成本低等很多好处，未来RISC-V很可能发展成为世界主流CPU之一，从而在CPU领域形成Intel(x86)、ARM、RISC-V三分天下的格局。

  

![](../Images/c907a9e8ab4e1e2c099788df7a5ac287.png)

倪光南院士

  

**以下为倪光南院士现场演讲整理：**

  

女士们，先生们，上午好！很高兴有机会来参加亿欧创新者年会，以及第四届创新奖颁奖典礼。我谈一下在芯片方面新的发展，希望我这个题目《中国开源芯片（RISC-V）的发展》能够为我们中国网信领域的发展，或者说各行各业的发展提供新的动能。

  

![](../Images/a6b7a8a03d29329d9e1c19aa858cedcf.png)

  

大家知道芯片很重要，最近出现的芯片潮流叫做开源芯片，当时我们申请这个联盟的时候，网信办批的叫做“中国开放指令生态（联盟）”，我就说不如叫中国开源芯片联盟，还比较通俗一点，也比较容易说。这个原文英文可以翻译成**“精简指令集第五版”**，但是太长，**一般我们就是叫RISC-V**。

  

为什么说开源重要？现在互联网中那么多服务，那么大的巨头企业，所依托的后台服务平台的软件支撑绝大部分都是开源软件，即开放源代码的软件。一般来说软件分为两类：一类是源代码开放的，一类是源代码不开放的。两类没有好坏之分，是不同的商业模式。但是从市场的反映来看，绝大多数的软件服务商，像中国的BAT，或者亚马逊、谷歌、facebook等中外的服务商基本上都基于开源，说明什么问题呢？说明它有它的好处。

  

第一个好处就是它能够让我们的服务商按照市场的需求做升级。假如买的商品软件不是开源的，如果请提供商升级版本，假如提供商不升级就没有办法升级你服务的版本，你的服务就没有办法升级，那你怎么和竞争对手竞争？开源软件当中所有好处中的第一位就是可以自己发展，不受制于人。

  

芯片这方面也有开源的，但是由于GPL许可证的原因，不易产业化。现在开源用的许可证是非常宽松的BSD许可证，谁都可以把开源CPU的代码拿下来，自己学了以后加以定制、改造、剪裁变成自己所用的芯片，你可以自己创新，推出自己的芯片，没有任何限制，不用交任何的钱，唯一需要做的就是声明一下我是用了RISC-V。这种许可证非常适合于创新发展，特别对于中国来讲，我们国家提倡大众创业、万众创新，非常适合中国双创的要求，所以我们非常支持。

  

![](../Images/a594b76a7eb2051cd90441d847d70f25.png)

  

目前在我们数字领域最复杂的往往就是CPU，CPU的世界形势怎么样？在网信领域垄断性非常强。比如手机，只有两种，不是安卓，就是苹果。**目前世界上来看，能够站稳脚跟的CPU只有两种，第一种是英特尔架构（X86架构），**历史悠久、生态成熟，性能指标各方面都很好，美中不足的这个架构就是全世界只有美国两家公司（英特尔和AMD）能做，别人不能做吗？没有现成的商业模式作为支撑。所以我认为只有这两家能做，谁要想做，对不起，现实可能会证明你不太可能达到你的目的，因为你拿不到授权。

  

**第二种是ARM架构，**这个大家比较熟悉，我没有精确统计，中国至少几十家在做，历史很长，生态也成熟，特别是在移动领域是垄断的，比如手机一定是ARM的CPU。有什么美中不足呢？中国也有很多公司做得很好，唯一不足的地方是代价比较大，一般来讲你要是拿到授权，我们说不同的条款是商业秘密，每家公司不一定一样。

  

比如说最高的你要拿到架构授权，可以任意修改，是要付代价的，我估计需要有几个亿，一般公司没有那么多钱；比较低的，也需要几百万人民币，可以买一个黑盒子来用，但不能修改，也不能自己改进。事实上，即使几百万对于中小型团队来讲还是不小的负担，如果你想修改、发展，对不起，没有几个亿别做了。我们希望有新的CPU出现，更适合于中国市场大多数中小企业，或者创新团队，有他们需要的CPU技术出现。

  

所以我们可以看到，**开源芯片对于我们有很大的好处，因为可以大大降低我们的芯片业创新门槛。如果我们现在用这样的CPU支撑我们的创新，支撑AI等等新一代信息技术，将会是非常有利的。**

  

我刚才已经讲了，一个中小企业有可能几个人的团队花了几万块钱，花几个月推出一个定制的，比如说是区块链定制的、AI定制的、机器人定制的、物联网定制的等等芯片，中小公司都可能做出来的，而不需要花几百万、几个亿，花几年的时间去做。我们希望把新的开源芯片潮流引入中国，符合我们国家战略发展的要求，符合我们国情。

  

![](../Images/cc8fb6666153b613fd61e8365759d484.png)

  

RISC-V的好处，第一，简单。这个CPU是新出来的，在我们信息领域往往认为新的比老的好，可以把很多东西简化。

  

![](../Images/4d7e5011fe6ff853d75aed805de02702.png)

  

比如你要看一个芯片的介绍手册，RISC-V的差不多是200页，ARM差不多2000多页，新手要学芯片喜欢学哪种？当然学RISC-V，学2000多页太辛苦了。同样功能的芯片，RISC-V的面积最小，意味着什么呢？价格最低，而且成品率会高，越小越好，这个优势是比较明显的。

  

![](../Images/9eabbf98fd0b4cfdfece7155556cb607.png)

  

最老牌的CPU是英特尔架构，1978年已经开发出来了，那时的英特尔架构有80条指令，现在多少条指令呢？它在不断增加，一个月要增加几条指令，按照这个趋势下去，现在就这么多条了，再几年要有2000条了，这个包袱太重了，英特尔的CPU要兼容，1978年到现在40年了，40年的时间，老产品都得兼容，所以它的包袱太重。

  

这些是大概从技术上可以看**到RISC-V的很多好处：模块化、可扩展、成本低，缺点则是没有生态，**毕竟英特尔经过40年的发展，已经积累了那么多生态。所以，**RISC-V要扬长避短，不在传统领域里面，比如说电脑、移动，不和英特尔和ARM在这种领域竞争，而是去占新的市场，比如人工智能等等。**新一代信息技术也够大了，大家不要认为这些新的领域没有传统领域大。

  

2007年以前智能手机一台也没有，现在智能手机光中国就有13亿台，人工智能的设备、机器人、物联网、5G、云计算、大数据这些新一代技术覆盖的领域可能比现成的领域还要大。在新一代信息技术领域，我们的优势就有了，劣势就避免了，这就是扬长避短。

  

新一代信息技术将把RISC-V推向前进，我们也成立了前面提到的联盟，帮助中国企业和创新团队掌握这个技术。RISC-V是一个开源的机制，而开源在软件方面已经取得了很大的成功，刚才已经讲到成本低、开放，还有一个很重要的，是原始创新。

  

在初级阶段企业使用开源学习，很快企业能力提高了，我们参与到开源组织里面，可以做更多的贡献和创新。谁说开源不能有原始创新？当然可以引进、消化、吸收再创新，开源也是可以做原始创新的，问题是你有没有真正投入。

  

![](../Images/8510f39b07e570e5f9c3803d90ac4d67.png)

  

举个例子，RISC-V在中国怎么做出贡献？比如我们可以在安全方面做出新的贡献。中国科学院大学杨力祥教授的团队，提出了一个新的安全理论，就是说现在病毒非常猖狂，安全是大问题，将来人工智能的芯片也会受到各种各样的攻击。为了避免这个攻击，传统手段当然有，但是很麻烦，他们提出一个理论，在多样的攻击中，其中有一类超越权限的攻击是最主要的，最多的，他们这个体系就能防止这类攻击。

  

所以这个也是很好的创新，它需要硬件、软件支持，正好结合RISC-V就可能按照他们的理论构建一个安全的芯片，配上安全的操作系统。这种芯片在物联网、智能家居、AI中间应用就可能就是最好的防御，比其他系统能更好地防御黑客的网络攻击，提供更安全的应用，这是很好的方案，我们将作为中国方面对于RISC-V的贡献，将来也会开放给全世界。

  

最后我们看一下，如果按照这条道路走下去会怎么样呢？我刚才讲了世界CPU两大流派已经站住了，我们今天不妨预料一下，**相信几年以后，3、5年，或者更多年以后，将会有3驾马车、三足鼎立在CPU领域，除了老的英特尔架构、ARM以外，第三个就是新兴的，刚才我介绍的RISC-V。**

  

在外观上，当然可以打任何的商标，因为基于这个许可证谁都可以打自己的商标，但是在内部用了RISC-V，中国的、世界的科技工作者所贡献的架构。总之，三足鼎立将会是CPU的大势所趋，谢谢大家。
