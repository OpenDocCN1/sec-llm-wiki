# 第五届世界互联网大会将于11月7日至9日举行

9月28日，国务院新闻办公室就第五届世界互联网大会有关情况及筹备工作进展举行发布会。

  

记者28日从国务院新闻办公室发布会上获悉，第五届世界互联网大会将于11月7日至9日在浙江乌镇举行。本届大会主题为“创造互信共治的数字世界——携手共建网络空间命运共同体”。

  

**国家互联网信息办公室副主任刘烈宏**在发布会上介绍，本届大会将深入贯彻落实习近平新时代中国特色社会主义思想，特别是习近平总书记倡导的推进全球互联网治理体系变革的“四项原则”、构建网络空间命运共同体的“五点主张”，着力突出论坛加领先科技成果发布和博览会的“1+2”功能定位。今年的大会将凸显传承与创新，推出大会五年成就回顾，集中展现五年来世界互联网大会走过的非凡历程。大会设置“创新发展”“普遍安全”“开放包容”“美好生活”“共同繁荣”5大板块共19个分论坛，重点探讨人工智能、5G、大数据、网络安全、数字丝路等议题。大会还将举办“互联网新产品新应用推介会”，发布《世界互联网发展报告2018》《中国互联网发展报告2018》蓝皮书、“乌镇展望2018”成果性文件和本年度全球互联网领域顶级领先科技成果。此外，本届大会会务服务等基础保障方面的智能化水平将得到全面提升。

　　**浙江省政协主席、省委宣传部部长葛慧君**在发布会上介绍，经过四届大会的积累沉淀，浙江的承办能力在逐年提升，对办好本届大会更加充满信心。目前大会各项主体活动已基本就绪，特色活动正在抓紧筹备，会务服务保障工作有序推进。大会期间，将举办浙江专场分论坛“工业互联网的创新与突破”、“直通乌镇”“资本相亲会”等新活动，继续推出“乌镇咖荟”等品牌活动；将启用5G通信商用试点展示、人脸识别、智能会务系统等一批科技产品，为中外嘉宾提供智慧化的会务体验。作为东道主，浙江将一如既往为与会嘉宾提供良好服务。

　　据悉，大会已向全球范围内1500多位重要嘉宾发出邀请，届时来自政府、国际组织、企业、技术社群和民间团体的嘉宾，将重点围绕创新发展、网络安全、文化交流、民生福祉和国际合作等议题进行探讨交流。

　　本届大会由国家互联网信息办公室与浙江省人民政府共同主办，联合国经济和社会事务部、国际电信联盟、世界知识产权组织、世界经济论坛、全球移动通信系统协会协办，浙江省网信办、浙江省经信委、桐乡市人民政府、中国互联网络信息中心承办。
