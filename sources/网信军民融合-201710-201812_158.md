# 公安部十一局副局长李彤：维护网络安全需要政府、企业、社会组织和广大网民共同参与

【**编者按**】在2018中国网络安全年会上，**公安部十一局副局长李彤**出席并讲话。他表示，当前传统违法犯罪加速向网上蔓延，各类网络新型犯罪不断涌现，网络空间成为公安机关打击犯罪和社会管理的新平台，近年来，公安部门积极开展针对侵犯公民个人信息、电信网络诈骗的专项打击和网站违法有害信息治理，建立健全网络安全等级保护制度和通报预警制度，开展网络安全国际执法合作，希望各行业各单位牢固树立网络安全共担共享理念，齐心协力、携手并进，为建设网络强国、维护网络安全作出新的贡献。

**以下为讲话原文：**

  

尊敬的各位领导，各位专家，女士们，先生们：

  

大家上午好！

  

非常高兴参加2018年中国网络安全年会。近年来，国家计算机网络应急技术处理协调中心在网络安全保障和突发事件应急处置方面做了大量的工作，为推动我国网络安全、加强各行业各部门网络安全保障、提高社会公众网络安全意识方面发挥了重要作用。

  

本届中国网络安全年会紧扣“荟聚安全大脑 护航智能生态”等热点议题开展多角度、前瞻性的探讨，对促进中国网络安全发展具有很强的现实意义。

  

借此机会，我代表公安部网络安全保卫局对本次会议的召开表示热烈祝贺，并向国家计算机网络应急技术处理协调中心和网络安全界的同仁长期以来对公安工作的关心支持表示衷心感谢！

  

随着网络技术的发展和信息技术的广泛应用，人类社会已经进入网络时代，网络空间已成为国家主权的新疆域、国际博弈的新舞台、国家安全的新领域，也成为公安机关打击犯罪和社会管理的新平台。网络社会和现实社会深度交融，网络安全不再是一般意义上的通信安全和舆论安全，而是直接关系国家安全、社会安全和人民群众切身利益，成为国家安全和社会公共安全的重要组成部分，对国家的经济、政治、军事、文化、科技都带来了深远影响。

  

公安机关是维护网络安全的重要职能部门。近年来，公安机关坚持以习近平新时代中国特色社会主义思想为指导，牢固树立“四个意识”，着力强化责任担当，在维护网上公共安全、网络基础设施安全、开展国际合作等方面发挥了重要作用。

  

当前，传统违法犯罪加速向网上蔓延，各类新型网络犯罪不断涌现，已成为影响群众安全满意度的突出问题。网络空间作为亿万群众共同的精神家园，谁都不愿生活在一个充斥虚假、诈骗、攻击、谩骂、恐怖、色情和暴力的空间，也没有哪个国家允许这样的情况滋生蔓延。

  

公安机关牢固树立“以人民为中心”的理念，紧紧围绕群众反映强烈的侵犯公民个人信息、黑客攻击、电信网络诈骗等违法犯罪，深入开展打击整治工作，仅2017年就侦办各类网络案件20余万起。目前，我们正组织开展“净网2018”专项行动，特别是针对侵犯公民个人信息高发的问题，我们在连续开展专项打击的同时，深入推进网站及应用清理整治、网络安全执法大检查等基础工作，不断提升网民自我保护意识和能力。

  

针对电信网络诈骗多发问题，我们牵头23个部委建立联席会议制度，在全国32个省级公安机关建立反诈骗中心，加大违法犯罪嫌疑人的境外抓捕力度，取得显著成效。同时，我们还建立健全网络综合治理体系。在全国重点网站设立网安警务室1164个，使相关网站出现违法有害信息数量平均下降85%以上；组织全国372个省市网安部门开展网警公开巡查执法账号，网上治理能力明显提升；部署全国公安机关建立网站分级管理、属地管理机制，推出大型网站常态化的约谈监督制度，有效净化网络环境；开设网络违法犯罪举报网站，十八大以来累计受理网民举报138.7万条，积极回应了群众呼声，有效维护了网络公共秩序。同时，公安机关不断建立健全网络安全等级保护制度，有力维护了网络和数字系统安全。

  

关键基础设施是经济社会运行的神经中枢，是维护网络安全的重中之重，保护关键基础设施安全也是中央赋予公安机关的重要职责。经过十几年的探索实践，我们建立了符合我国网络安全实际的等级保护体系，对国家信息系统实施分级保护，对其中1.89万个三级以上系统，特别是6600余个关键信息基础设施实施重点防护。至今出台100余个等级保护制度的政策文件、国家标准、行业标准，对大型互联网企业和三峡等重大工程开展了网络安全专项保卫，有效提升了企业安全防护能力。同时，公安部充分发挥国家网络与信息安全信息通报中心职责作用，建立了国家网络与信息安全信息通报预警机制，实时通报处置网络风险漏洞，会同有关部委和行业主管部门、技术支持单位建立国家最高水平的整体防御屏障，确保了抗战胜利70周年庆典、G20峰会、“一带一路”高峰论坛、党的十九大等重大活动的网络系统安全。

  

我们积极开展网络安全国际执法合作，有力提高国际互联网领域的话语权。我们牵头成立了中美打击网络犯罪及相关事项高级别联合对话机制，成功举办了3次高级别联合对话，并在工作层面保持着密切沟通，取得了丰硕成果。我们还围绕“一带一路”国家战略，积极与70多个国家和地区开展了网络安全执法合作，着力加强与欧、美、东南亚等重点国家和地区的网络安全交流合作，深入参加联合国国际刑警组织、上合组织等国际会议，有力提升了我国在国际网络领域话语权。

  

习近平总书记明确指出，要提高网络综合治理能力，形成综合治理格局，构建“网上网下同心圆”。我们坚持“网络安全为人民 网络安全靠人民”，维护网络安全是全社会的共同责任，需要政府、企业、社会组织、广大网民共同参与。这次网络安全年会提供了这样的好机会，希望大家充分依托这一平台，牢固树立“网络安全共担 网络生活共享”理念，齐心协力，携手并进，牢固“网上网下同心圆”，共建“共治共享、天朗气清”的网络空间。同时，希望社会各界一如既往地支持公安工作和安全工作，公安机关也将以习近平新时代中国特色社会主义思想为指导，进一步解放思想，改革创新，坚决履行党和国家赋予的维护网络安全的职责使命，为建设网络强国、维护网络安全作出新的贡献！

  

最后，预祝本次大会取得圆满成功。
