# 薛惠锋：坚持自主创新的中国道路

本文刊登于《网信军民融合》杂志2018年5月刊

  

习近平总书记在全国网络安全和信息化工作会议上强调，我们必须敏锐抓住信息化发展的历史机遇，自主创新推进网络强国建设。他深刻指出，核心技术是国之重器，是我们最大的命门，必须紧紧抓住自主创新这个核心技术突破的“牛鼻子”。信息革命大幕开启，总书记站在人类历史发展的高度，科学分析信息化变革趋势，深刻指出了技术创新对于我国各项事业的引领和驱动作用。

  

由于互联网技术源自美国等诸多历史原因，我国网络空间领域关键基础设施、核心技术、重要产品无法自主可控，网络主权面临着重大现实威胁和潜在挑战。与此同时，“陆海空天电网”融合一体的太空时代正加速来临，万物互联、人机交互、天地一体逐步成为现实，以“制天权”保障“制网权”，以“制网权”掌控“制数权”，以“制数权”获取“制脑权”，成为网络强国建设的必然逻辑。可以说，没有太空安全，就没有网络、海洋、经济、国防安全；没有天基信息系统，就不可能在网络主权的维护中掌握主动权。钱学森智库以系统工程思想为统领，提出构建“天地一体、自主可控、稳定运行”的“星融网”体系，将信息化发展的历史机遇与航天强国、网络强国建设融为一体，是天网融合发展的必然趋势，为太空时代我国通过颠覆性技术创新实现“弯道超车”，提供了具体方法和实践路径。

  

日前，习近平总书记在两院院士大会上发表重要讲话，强调自力更生是中华民族自立于世界民族之林的奋斗基点，自主创新是我们攀登世界科技高峰的必由之路。我们推出“星融网”的自主创新设计，就是积极响应“把握大势、抢占先机，直面问题、迎难而上”的号召，在太空“高边疆”和网络“新边疆”的加速融合中，凝聚智慧力量，凸显创新力度，肩负起历史赋予的重任，勇做新时代科技创新的排头兵，为建设世界科技强国贡献网信军民融合的力量。
