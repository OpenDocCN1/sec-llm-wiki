# 第三届军民两用技术创新应用大赛开始项目征集

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247485803&idx=2&sn=080e54fe8d9cbf1ebe9e561017886a20&chksm=e9bc1dd5decb94c38b4d15b4d98b2ac4672d4522b121171798d2fa9d8f952ffae53831a5d25b&scene=126&sessionid=1681311622#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247485803&idx=2&sn=080e54fe8d9cbf1ebe9e561017886a20&chksm=e9bc1dd5decb94c38b4d15b4d98b2ac4672d4522b121171798d2fa9d8f952ffae53831a5d25b&scene=126&sessionid=1681311622#rd)

通过对应用于航空航天领域的镁合金材料进行改造，可以生产出既耐用又防辐射的手机外壳；通过对应用于飞机上的气凝胶耐火材料进行创新改造，可以生产出建筑玻璃，大大提高了安全性……这些都是来自军民创新应用的产品，展现了军民融合的强大技术和品质积淀。

第三届军民两用技术创新应用大赛已于4月26日面向社会征集参赛项目，大赛将于7月至11月举办初赛、半决赛以及决赛。

何为创新项目？如何编写项目材料才能脱颖而出？第三届军民两用技术创新应用大赛的关注点又在哪里？为帮助各参赛企业了解比赛的意义，大赛组委会在多个城市举办说明会，介绍赛程安排和规则，同时邀请大赛专家指导参赛者撰写大赛项目申报书、创新计划书及商业计划书。

“总有一些项目名称夸大其词。”大赛组委会专家在首场说明会上表示，要杜绝项目标题引发歧义。

第三届军民两用技术创新应用大赛现已面向社会征集项目，如何填写内容才能更好地突出项目特色？是否只要项目技术够硬，就一定能顺利进入决赛？大赛专家更注重项目材料的哪些方面……很多拟参赛企业都有这样的疑问。

“项目主要注重创新性，最好既能突显在军民两用方面交叉的关系，又有自身的技术创新性。”大赛组委会专家在总结前两届的比赛情况时表示，前两届比赛中许多项目更侧重展示技术，不太重视包装自己产品的形象。“应该通过比赛有意识地督促企业对自己产品的优势、行业的发展规模、产品的研发规划以及未来新项目的储备和创新性、自身的商业模式等进行清晰地梳理，这个过程也相当于在梳理整个公司的商业模式。”该专家表示，参赛企业可以通过本次比赛提供的资料，总结自身特色，更好地规划企业的发展路线。
