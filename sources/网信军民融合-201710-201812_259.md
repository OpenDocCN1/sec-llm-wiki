# 从微软最新战略看我国操作系统发展

操作系统是所有计算平台的核心，是信息技术产业发展的战略制高点。从全球发展看，谁掌握了操作系统，谁就在新一轮的计算平台竞争中掌握了绝对的话语权。因此，操作系统之争贯穿了整个信息技术与产业发展的历程，也必将持续影响未来信息产业的全球竞争格局。

在桌面OS领域，微软依旧占据着全球绝对领先地位。根据NetMarket Share的最新数据，截至2018年2月，全球桌面OS市场的绝大多数份额都被微软Windows所占据，高达接近90%，而非Windows产品市场份额总和仅为10.88%。

在此背景下，国产操作系统厂商如果需要进一步发展壮大甚至试图弯道超车将国产操作系统做到和Windows同样优秀的水平，那么总结并分析微软最新发展战略及技术创新趋势将有助于研究国产操作系统在新一代信息技术影响下该如何进行创新发展。

  

  

一、微软新的发展战略

2018年3月9日，微软刚刚宣布Windows 10的下一个主要版本将支持人工智能（AI）和机器学习（ML）。这就是微软Azure的首席技术官Mark Russinovich在加利福尼亚州Sonoma召开的Linux基金会的开放源代码领袖峰会（Open Source Leadership Summit，OSLS）上传递的消息。他表示，人工智能科技和技术正在经历复兴。开源技术和社区的库和框架推动了自我教育机器学习开发人员的增长。云的计算能力使得大数据集的处理成本变得高效且普遍。随着开源社区分享的力度不断加大，将会有更多的智能应用程序采用各种各样的开放源代码技术，这些技术跨越了所有的处理平台。

  

2018年3月28日，微软公司CEO纳德拉正式宣布：象征微软的标志的Windows部门将会被“肢解”，与此同时组建两大新部门，一个叫体验与设备部，另一个是云计算与人工智能平台，称要拥抱未来、拥抱智能云和智能终端。从字面含义不难看出新部门的重组目标所在，既新战略决定了公司主要聚焦在两个方面，一是从不同端出发，保持操作系统的高度一致性，无论桌面端、移动端乃至服务器端都尽量维持几乎相同的用户体验；二是操作系统也得从底层架构开始纳入云计算和人工智能的相关应用和开发工具。

  

此次微软最新公司革新战略和技术创新倾向充分体现了操作系统新的发展趋势，既从底层架构就开始支持人工智能和机器学习相关应用和开发工具。可见，开源社区的不断完善以及云计算能力的日益提高，都从基础设施的角度对于人工智能和机器学习提供了坚实的基础，同时也奠定了操作系统今后智能化的发展趋势。可以预见，随着新一代信息技术的热潮的风起云涌，国产操作系统今后进一步的发展也将走上同样的道路。

**二、发展战略分析**

**是跨终端OS平台将成为未来发展趋势**。当前，随着计算平台的不断丰富，跨终端OS成为诸多OS研发厂商进行产品研发的重要方向。长期以来，微软在桌面、服务器OS领域占据了较大的市场份额，但在移动终端OS领域受到谷歌的严峻挑战，为提升自身在移动终端OS领域的市场份额，微软着力打造能够跨PC和智能手机的新一代OS。从微软产品研发路径来看，Windows 8和Windows 10都强调了其操作系统在智能终端上的可操作性和易用性。Windows 10为了扩大其兼容范围，提供了支持Web应用、传统桌面程序、安卓应用和iOS应用向Windows10平台的迁移等功能。

  

**二是应用驱动成为OS演进的重要动力**。随着信息技术的不断演进和信息系统在生产生活中的加速普及，人类对于信息系统的要求也在不断提升，不仅要安全、可用，更要易用、友好。因此，作为连接底层硬件设备和上层应用软件的操作系统，其技术、功能、性能要求也在不断提升。从微软Windows操作系统发展历程来看，早期的产品主要关注于产品的稳定性和兼容性，而最新的Windows产品则更强调资源配置的有效性，操作的便捷性和界面的友好性，提供了大量的面向用户操作的基本功能。

  

**三是面对不同行业需求和应用场景的专业化OS将不断涌现**。伴随信息系统的专业化发展，OS的专业化发展水平也将不断提升。在通用型操作系统领域，由于市场格局已经基本稳定，市场后来者很难获得广阔的发展空间。但在专业领域中，由于各行各业的业务重点不同、模式不同，对于OS的需求也不尽相同，专业化的OS发展前景较为广阔。同时，伴随开源技术的不断发展，开源OS降低了OS定制研发的门槛，有力推动了专业化OS的发展。例如，微软的Azure云服务在高性能计算领域，也使用了Linux为操作系统内核。并且针对不同领域的厂商，专业化的Azure也是扩展微软OS商业市场的重要途径。

  

**四是云计算、大数据人工智能决定了OS的发展方向**。发展历程表明，操作系统的创新演进都是和底层硬件计算平台的演化紧密相关的。网络作为人们日常生产生活中的重要部分，操作系统也日益依赖于网络通信和资源共享，网络在操作系统演进中的作用和价值日益凸显。正是由于移动互联网的发展，移动终端OS才登上了历史舞台，并经过多年的市场竞争形成当前以安卓为主的竞争格局。从信息系统计算平台创新的方向来看，以云计算、大数据和人工智能为基础、基于分布式架构、能够智能化、个性化的提供信息技术服务的新一代操作系统将成为未来最为主流的操作系统，未来操作系统的市场竞争势必将以云计算为架构中心，智能化分布应用的操作系统生态为主。因此，微软也开始从Win10着手，开始在底层基础设施中纳入对云计算、大数据、人工智能的技术应用支持范式，并谋求开源技术对微软自身的产品的融合创新。

******三、发展我国操作系统的三点建议******

**一是联合相关企业， 营造良好的产业生态**。在PC行业占据统治地位20余载的Wintel联盟就是一个典型案例。微软和英特尔，CPU和操作系统领域的两家公司结成联盟，成为事实上技术互相分享并且对彼此产品做特殊适配的“铁盟友”。国产基础软件要想进一步发展壮大，可仿效Wintel联盟，相关联厂商建立并保持长期战略技术伙伴合作关系，成为事实上的互帮互助的“铁盟友”。联合操作系统、数据库、中间件、办公软件领域乃至硬件芯片领域的厂商，达成有效技术分享合作机制，互相在产品和服务中做出联动性、针对性的适配优化。一旦某一方的产品取得市场优势，因存在潜藏的彼此关联性适配优化，就会引导用户从单个厂商的产品开始使用联动合作厂商的产品，真正形成一点突破，带动全局的发展势头。  

  

**二是发展跨终端OS，建立完备的产品脉络**。国产基础软件虽然在桌面端市场近期发展势头放缓，但在移动端市场发展潜力无限。在桌面端的市场份额较为固化的态势下，继续执着于技术差距依然较大的桌面端市场并不是一个明智之举，瞄准多平台、多终端的更广阔的市场，突破专有领域势在必行。从微软的革新战略可以看出，跨终端OS的庞大市场绝不仅仅只有手机这一方面，还有物联网和其相关的各大智能设备器件，甚至还有未来更多的新兴领域。突破传统桌面端市场领域，聚焦新兴领域，国产基础软件很有可能在跨终端这一个新的发展战略中拥抱更广阔的市场空间。

![](../Images/8dbb070658e06ecbacc70c60ad7bd97d.png)

**三是开拓创新， 拥抱“ABC + IoT”**。A代表了AI，B代表了Big Data , C 代表了Cloud Computing,IoT代表了物联网，这3个字母和一个缩写共同构成了未来新一代信息技术的缩写。任何产品的技术创新都离不开科技力量的驱动，只有跟上新一代信息技术浪潮，才能做出更符合市场需求和消费者特性的操作系统。微软宣布Win10下一代产品将从底层技术架构就纳入云计算和人工智能的应用支持和开发工具也正昭示了操作系统技术创新势必协同新一代信息技术的发展。国产操作系统要想弯道超车，在技术创新的角度，就势必拥抱“ABC+IoT”，从操作系统的层面就开始做出相应的调整和基础设施的创新。通过云计算的算力提升，大数据的客观分析、人工智能对用户操作体验的巨大提升，不断调整和适应市场需求，对国产操作系统产品及时做出颠覆性、智能化的创新，乃至做出特色，做出亮点，是国产操作系统提升自身在商业市场核心竞争力的关键举措。
