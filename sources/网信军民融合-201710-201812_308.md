# 一． **谁在垄断高端芯片技术？**

  

中国核心集成电路国产芯片占有率多项为0，贸易逆差高达1657亿美元。对通信行业来说业内的一种分类方法是将通信类芯片分为成熟度、可靠性较高的基站芯片和一般的消费终端芯片。前者是中兴等信息通讯技术服务商所要用到的，而后者主要用在智能手机等数码类产品上。“（两者）不可同日而语，(基站芯片)从开始试用到批量使用起码需要两年以上的时间,主要玩家有TI、ADI、IDT等厂商”，招商电子发布的公告表示，高端通信芯片基本上被外国厂商垄断。从第三方报告来看，这一市场的核心玩家均为高通，且从份额来看高通均保持着市场龙头地位。技术咨询公司Canalys认为，65％的中兴手机都包含高通芯片。

  

跳出通信行业，全球芯片市场上巨头更多。IC Insights报告显示，全球半导体市场规模达到了4385亿美元，前十大半导体厂商占据了整个市场58.5%的份额，这些厂商分别是三星、英特尔、SK海力士、Micron、博通、高通、德州仪器、Toshiba、英伟达和恩智浦，并没有出现中国厂商的身影。国内最大的半导体企业华为旗下海思半导体的2017年销售额约为61.6亿美元，而十大巨头中三星电子的销售额为656亿美元，最末的恩智浦半导体的销售额为92亿美元。

  

如下图可以看出，除了移动通信终端和核心网络设备有部分集成电路产品占有率超过10%外，包括计算机系统中的MPU、通用电子系统中的FPGA/EPLD和DSP、通信装备中的Embedded MPU和 DSP、存储设备中的DRAM和Nand Flash、显示及视频系统中的Display Driver，国产芯片占有率都是0。

# 二． **中国通讯企业对美国依赖程度有多大？**

  

中国通信产业存在无芯之痛。以国内第二大通信技术服务企业中兴通讯为例，其去年向供应商采购金额超过百亿元。中兴通讯2017年财报显示，中兴向最大供应商的采购金额为31.69亿元，占本集团年度采购总额5.46%，向前五名最大供应商合计的采购金额为106.12元，占本集团年度采购总额的18.28%。不过，中兴并未披露供应商名字。

  

中兴公司多款通信设备的核心零部件中的芯片100%来自美国公司，中兴有1-2个月的备货，如果不在这个时间内达成和解，会影响中兴设备的生产。这对电信行业，特别是中国运营商网络建设会造成影响，影响未来5G建设。芯谋咨询首席分析师顾文军表示，看似庞大的中国电子产业却处于产业链的最下游，即使中兴拥有比较多的专利，主要芯片和元器件却大多来自于美国厂商，仅仅芯片（还不包括为数众多的元器件）领域，中兴通讯就有多达数十家美国芯片供应商，更为致命的是，在通信行业几乎所有产品领域、所有细分环节都有着美国芯片的身影，而国内的芯片少之又少（被寄予厚望的中国通信行业巨头华为，其自产芯片目前为华为所用，并不对外销售），业内有分析认为，中兴在短时间内很难找到替代品，中国厂商短期内还很难跳过高通，高通控制着智能手机等终端芯片。

中美贸易摩擦背后是科技和战略主导权之争，此次中兴事件并非独立事件，美国主要目标是狙击中国在高端制造领域的拓展，不排除其他科技公司后面有受到类似限制的可能。87岁高龄的老科学家邹世昌曾说：“我作为‘两弹一星’研制体系大家庭中的一员，曾为‘两弹一星’付出辛劳和汗水，也在集成电路与半导体材料科研领域摸爬滚打了近30年。在我国的重大科技项目中，20世纪60年代的‘两弹一星’与集成电路研制形成了强烈反差。‘两弹一星’使我国一举跻身少数拥有核武器的国家行列，而当时起步并不晚的集成电路却与国际集成电路产业的发展渐行渐远。”

  

“朋友可以帮你发展，而对手可以逼你强大！”这次的“美国釜底抽芯事件”对于中国来说，并不是一件坏事，更是一次千载难逢的战略机遇期，肯定会激励自主芯片产业的发展。这次事件，一方面可以帮助我们凝聚集成电路领域相关核心资源，另一方面可以倒逼我们形成“技术在我，与狼共舞”的顶层思路。我们应该拿出当年钱学森带领团队攻关“两弹一星”的魄力，挑起集成电路领域的民族脊梁。

**星融网：化解中兴磨难的中国动力**

张佑任 《网信军民融合》战略论坛评论员

 

习近平总书记主持召开中央网络安全和信息化工作座谈会两周年之际，钱学森智库发布《智慧社会建设“郑州宣言”》，以更大的智慧、更广的视野、更高的谋略，构建自主可控的“星融网”，以摆脱美国“大国中心”的互联网，走出了抵抗“网络霸权”的有力步伐。

  

当下，网信领域“六大问题”的提醒声犹在耳，美国商务部突然宣布禁止美国企业向我国重要通信企业中兴出售技术、芯片、软件（操作系统），禁令有效期长达七年。

  

分析人士认为，美国此举将对中兴造成重大打击，同时“项庄舞剑，意在沛公”，背后的战略意图，是瞄准了我国在信息技术核心领域仍然不能自主可控的软肋，试图以此遏制我高新技术发展，甚至阻击中国制造2025计划顺利实施。

  

此次“中兴磨难”，只是国产自主可控道路艰难、重点技术受制于人现状的缩影。我们在半导体加工、超高精度机床、工业机器人、高精材料制造等多项基础领域，距离国际先进水平仍有差距。而恰恰是这些差距，如今成为了制约网络强国、中国制造、军民融合等重要国家战略实施的关键瓶颈。

  

痛定思痛，压力未尝不是好事。“中兴磨难”打碎了拿金钱换技术的梦想，戳破了技术全面赶超的自大。疮疤解开，止血之后，我们需要再次重温“核心技术受制于人是最大的隐患，而核心技术靠化缘是要不来的，只有自力更生”的警世之语。战略方向已定，真正缺乏的是执行的智慧和决心。

  

习总书记强调，贯彻落实党中央决策部署，不是喊口号。实现技术赶超，需要避免盲目自大、卑躬屈膝、追逐私利，需要回归科学规律和基本逻辑，需要在国家战略的指引下，做好技术发展的顶层设计，按照一张蓝图绘到底的决心，久久为功，深耕细作，谋求大成。

  

要实现技术赶超，我们就要认识到：创新无大小，应当延续和发展中华民族骨子里的创新精神，鼓励一切创新。既要鼓励共享单车式的商业创新，更要看到核心技术创新是我们当前的短板，要下大力气去提升。承认创新没有高低贵贱之分，尊重一切创新者和创新尝试，不以成败论英雄，形成全社会创新的氛围是创新的首要前提。

  

要实现技术赶超，我们就要认识到：我们既要有弯道超车的勇气，更要认识科学发展的规律。总书记提出，争取在某些领域、某些方面实现“弯道超车”，就是指出了这一科学规律：在有些领域，没有时间和经验的积累，没有大量资源的投入，很难实现跨越式发展。这就需要我们在关乎国家利益、需要长期投入的核心技术领域，克服浮躁，力戒虚妄，拿出“两弹一星”精神，发挥社会主义制度集中力量办大事的制度优越性，打一场攻坚战，逐步缩小技术差距。

  

要实现技术赶超，我们就要认识到：真正的弯道超车在于前瞻布局、引领创新。信息革命刚刚拉开大幕，互联网只是序章。很快“互联网”这个词会消失在我们的语境中，成为如同“电力”一样的基础概念。站在互联网的基础上展望未来，我们和世界同在一个起跑线，面对的都是茫茫无际的创新荒原。只有利用好信息时代技术快速迭代的特征，提前认识物理空间领域的拓展、人类社会的智慧化将成为科技创新的发展主线，提前布局相关技术研发，通过重点工程拉动，才能加速整体科技水平的发展。

  

要实现技术赶超，我们就要认识到：创新永远是在积累中前进。不能用现在否定过去。必须看到，长期以来，国家、社会、智库多个层面都在一直行动，一大批专家学者机构在奔走呼号，取得的一系列的成就支撑了我们未来突破的可能。反思过去不是为了否定过去，而是要在昨天的基础上调整方向，加速前进。
