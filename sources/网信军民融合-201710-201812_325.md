# 薛惠锋院长受邀出席第二届“强网杯”全国网络安全挑战赛暨强网论坛并做发言 与相关单位开展交流与合作

        4月14日-15日，受主办方战略支援部队信息工程大学邀请，薛惠锋院长出席了在郑州举办的第二届“强网杯”全国网络安全挑战赛暨强网论坛并做发言。强网论坛以“新时代、新空间、新路径”为主题，邀请国内有关专家学者就网络空间军民融合策略、国际合作、法律支撑、人才培养和新型智慧城市、5G安全、工控安全、IPV6安全等热点领域进行交流研讨，中央网信办、战略支援部队、河南省政府、郑州市政府领导和多位院士专家出席了会议。

  

![](../Images/efd4fc83608faab5310358cdef639bd7.png)

  

        薛惠锋院长作了题为《用钱学森系统工程思想助推网信军民融合深度发展》的报告。报告指出，钱学森倾注毕生智慧建立的一整套思想、方法、工具体系，造就了今天“钱学森智库”，运用钱学森智库思想，维护网络主权、掌控数据主权，推动网信军民融合发展的新跨越，需要在战略、战役、战术上统筹考虑。战略上，要占领“制高点”，掌控“四权”：以“制天权”保障“制网权”，以“制网权”掌控“制数权”，以“制数权”获取“制脑权”，构建“从定性到定量的综合集成研讨厅体系”，打造“人机结合、人网结合、以人为主”智慧化系统。战役上，要加速“一体化”，实现“三合”：跨部门的顶层统合、跨政企的信息融合和跨公私的创新联合。战术上，要构建“星融网”，破解“四难”：在技术层面，构建“天地一体、自主可控、稳定运行”的“星融网”，掌握自己的网络主权。薛惠锋院长“巡天遥看一千河”的高度、“接万物以通天下”的广度，赢得了现场热议和思想共鸣。

  

![](../Images/a79dcde484e46468726dc03f955f31b3.png)

  

论坛期间，中国航天十二院院长薛惠锋向解放军信息工程大学副校长孟繁浩赠送了《网信军民融合》杂志。

  

![](../Images/54aefb39a85bfece9d8810b5ca2823bf.png)

  

        论坛期间，薛惠锋院长与网信军民融合发展联盟理事长邬江兴院士就联盟工作方向进行了深入沟通，并签署了进一步加强联盟秘书处建设、推进联盟实质化发展的战略框架协议。邬江兴院士表示，网信军民融合发展联盟是一个能高效链接军地的优质资源集聚平台，相信在秘书处依托单位航天十二院的支撑下，联盟必将又快又好地发展壮大，同时助力航天十二院成为军民融合产业平台建设抓总单位。

  

![](../Images/952608e0f1482e7a9ba711bd41ba4f5a.png)

  

        论坛期间，薛惠锋院长择机接受了河南电视台《法在中原.网安金盾》的专访，系统讲解了钱学森智库的核心和根本，全新提出了对人工智能特别是无人驾驶的新锐观点，重点讲述了构建“星融网”的必要性、紧迫性和具体规划构想。

  

  

![](../Images/1d8070886ceaa88dd7c9c7337d4ba348.png)

  

        期间，一行人前往战略支援部队信息工程大学外国语学院进行调研，针对十二院即将与战略支援部队信息工程大学开展的战略合作内容，进行了资源条件全面考察。

  

![](../Images/6bbaf0338e2be5d633df1745057d2514.png)

  

        期间、 与郑州高新区王新亭书记进行了会晤，双方充分沟通了第十五期钱学森论坛的筹备情况，并针对论坛策划进行了实地勘察和提升设计，为4月19日在郑州高新区召开第十五期钱学森论坛夯实了基础、打好了前战。
