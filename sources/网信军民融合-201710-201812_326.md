# 成立刚满一个月，中央军委科技委快响小组就发布首批项目需求

国防科技创新快速响应小组是由中央军委科技委为推进科技领域军民融合发展而成立，全国首个国防科技创新快速响应小组于2018年3月14日在深圳启动运行。成立国防科技创新快速响应小组，是中央军委科技委推进科技领域军民融合发展，利用先进商用技术为军服务的一种机制探索。首个国防科技创新快速响应小组启动后，将依托深圳经济特区创新优势，通过多种形式快速响应国防科技创新需求，为推动形成灵活高效的国防科技创新价值链积累经验。

近日，中央军委科技委快响小组发布首批项目需求，面向社会公开征求。

| **名称** || 一、共形天线及电路一体化快捷制造技术 |
| --- | --- |
| **需求描述** || 天线是军工产品不可缺少部件，一般采用相控阵天线结构，这种结构由天线、电路等单元组成，涉及用线路板制造的天线阵面、线缆和电路模组、支撑件等传统的结构。为了节省体积和降低重量，提升射频性能，相控阵射频电路，需要把天线阵元和移相器芯片一体化最优路径整合在一起，采用共面波导形式来省略线缆和金属部件，实现结构功能两者一体化设计，且同步的用最小的体积和最小重量来满足设计指标。需要采用新型的材料和装备、新型工艺方可同时达到以上目的。如采用非金属不等密度材料结构实现轻质化，并在这种结构上直接设计金属天线实现共形化，采用增值制造方式来满足小批量快捷制造且成本便宜的要求。一般来说，3D打印可以增材制造复杂结构的非金属部件，到达轻质、复杂、快捷、低成本的要求，若同时又能在3D打印部件上选择性的3D打印金属天线，并解决金属的附着力难题，即采用“3D打印+3D表面打印技术”实现本项目需求。**技术指标：**1.      天线部件尺寸范围：300mm×300mm×600mm；2.      制造周期：24h内完成天线制造和表面选择性金属化，金属层厚度≥12μm（镀金）；3.      金属附着力：金属表面附着力通过百格测试（测试胶带3M610）；4.      可焊接性：金属部分能通过260℃回流焊接；5.      工作温度范围：\-100℃~250℃；6.      制造天线精度：金属线条的线宽±50μm；7.      最细线宽和线距：0.1mm和0.1mm；8.      天线几何结构：任意曲面构型；9.      天线材质：高分子复合材料；10.  成型方式：3D打印天线附着结构，再在其上选择性金属化；11.  结构功能一体化：产品的支撑件内外表面布设电子元件线路并实现一体化组装。**成果形式：**完成技术研究报告一份，结合应用提出单位提供的典型应用场景，完成设计报告一份，仿真设计模型一份，并完成样机一套，在应用提出单位完成试验测试基础上，给出数据分析报告。 |
| **其他要求** || 1. 项目能在一年内完成样品和小批量制造；2. 两年内能满足长期的连续不断的小批量制造需求；3. 项目知识产权清晰，优选发明专利项目；4. 项目所选用的材料和装备能国产化的优选；5. 项目能军民两用，能不依赖军品实现自我业务增长。 |

| **名称** || 三、基于视频的海上智能目标识别技术 |
| --- | --- |
| **需求描述** || 利用先进光学视频图像处理分析技术，实现舰艇平台在复杂海况条件下对小目标的探测识别，以提高决策和执行过程的准确性和有效性。对于视频图像中的模糊图像自主、快速有效的智能识别，并自动进行分类信息标定。支持对多种制式和多种清晰度的电视和红外视频图像进行识别处理。**技术指标与成果形式：****1.****功能要求**1）能够实现四级海况条件下小目标的识别；2）能够对海上主要非海浪的小目标进行智能识别及分类，并自动进行分类信息标定；3）能够支持对电视视频图像和红外视频图像的处理；4）能够实现对多种制式和多种清晰度的视频图像进行识别处理；5）能够对输入的视频图像进行相应的质量评估和目标识别准确性的预估；6）具有一定可成长性，能够支持在线或离线方式更新和升级。**2.****技术指标要求**1）能够有效处理四级海况下航速≥35节航行的小型艇平台的视频图像；2）能够实现四级海况条件下≤10m×5m×3m的小目标的有效识别；3）基于≥100组的样本数据，目标识别分类标定正确性≥80％；4）在周视场景下，能够对视场范围内距离≥300m内的小目标进行自动识别；5）识别响应时间≤5s；6）数据处理周期≤50ms。**3.****成果形式**成果形式应包括研究报告，算法模型，软件模块，试验报告。软件文档还应包括：《需求分析》、《概要设计及详细设计》、《测试计划》、《测试报告》、《用户手册》、《开发总结报告》。**4.****软件要求**1）功能要求a. 算法模型中主要参数可进行配置调节；b. 能够支持在Linux、国产嵌入式操作系统中运行；c. 能够在视频图像中进行信息标记；d. 数据传输采用以太网形式，满足甲方的信息接口要求。2）软件可靠性要求通过完备的数据验证、异常诊断与处理机制，保证软件的高可靠性；设计阶段充分考虑避免出现数据越界、无效对象引用等情况。3）软件交付形式最终交付的软件产品包括产品的可执行程序安装包、源程序、软件文档，以光盘为介质存放，同时提供纸介质打印的软件文档的硬拷贝。其中，光盘介质盘面标识包含软件名称及版本号。**5.****接口要求**采用1000M以太网通讯接口，传输周期≤50ms，输出数据至少包括信息标定和处理后的视频图像，视频质量评估，目标识别准确性预估，目标数据（依据视场中心推算出目标的相对位置信息，以及预估距离）等数据信息。**6.****验证需求**1）可装载嵌入甲方相关的硬件设备或板卡中，结合甲方的水上平台进行验证；2）可与甲方共同搭建海上视频图像的仿真训练平台进行仿真训练和验证。**7.****软件移交测试需求**最终移交测试文件由甲乙双方共同拟定。移交测试在乙方人员的督导下由甲方人员进行，如果移交测试没有满足测试文件的要求，则应重新进行软件测试。**8.****售后需求**乙方提供终验合格后一年免费保修，包括免费上门服务和维护以及包括所有相关软件的免费升级。如发生紧急故障，在得到用户通知后，乙方技术人员应在8h内到达现场，并提供应急策略，相关问题保证在24h内解决。在保修期内（非人为因素）软件应免费升级。在保修期结束后，产品寿命期内投标人必须继续提供对故障处理和软件升级等的服务，不得以任何借口拖延或中断对产品的售后服务。 |

| **需求描述** || 在机载环境有限资源限制下高效率完成特定场景的人机交互，需采用集人脸识别和语音识别于一体的独立功能模块，来满足特定场景的人及交互需求。独立功能模块以摄像头、耳机麦克风作为外部辅助设备，完成识别数据的输入，通过以太网完成识别结果的输出。独立功能模块可接收摄像头输入的模拟信号数据，将模拟信号数据进行数字化后进行识别，并将识别结果通过以太网发送至控制计算机，摄像头分辨率≥640×480；可接收耳机麦克风输入的话音模拟信号数据，将话音数据进行数字化后对特定语音词条进行识别，生成对应指令，并将处理结果通过以太网发送至控制计算机。**技术指标：**1、硬件指标1）处理器：FT2000，不低于2核；2）操作系统：银河麒麟4.0.2及以上；3）重量：<500g；4）功耗：<20W；5）指标验证：借助银河麒麟操作系统本身预装的工具软件检测硬件指标是否满足要求。2、语音识别指标1）命令词识别率：\>95% ；2）语法支持：支持符合SRGS  1.0规范的语法；支持多槽语法识别；支持用户自定义文法格式；3）支持语种：汉语普通话、英语；支持中英文混读；4）支持词条数量：\>5000条；5）识别速度：<1s；6）指标验证：搭建验证环境，提供用于测试的词条集合（5000条），提供测试语音样本数据，将样本数据作为独立功能模块的语音输入，统计测试结果，根据测试结果数据验证指标是否满足要求。3、人脸识别指标1）拒识率：<1%；2）识别正确率：\>95%，低光照下\>93%；3）识别速度：<1s；4）指标验证：搭建验证环境，提供用于识别的人脸库（100个），提供测试视频数据，视频数据内包含用于人脸检测与识别的场景，将测试视频数据作为独立功能模块的视频输入，统计测试结果，根据测试结果数据验证指标是否满足要求。4、其他在满足主要指标要求的前提下，对CPU、内存、硬盘等计算机资源占用越少越好，同时，在交互模块中用于人脸识别和语音识别的程序要求使用C/C++语言开发；用于人脸识别和语音识别的支撑数据/支撑库要求提供以太网形式的更新接口，即可以通过以太网对支撑数据/支撑库内容进行更新；摄像头输入的视频信号数据具有一定程度的抖动，用于人脸识别的程序一定程度上要能消除视频源抖动对识别的影响；人脸识别程序要具有活体检测的能力；语音识别程序运行于噪声环境下，语音识别算法要有一定程序的降噪处理。 |
