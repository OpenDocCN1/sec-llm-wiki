# 赛宁网安竞赛平台将赴欧洲，亮相HITBSecConf 2018-阿姆斯特丹

去年8月，由赛宁网安总体承办的XCTF联赛与亚洲地区历史最悠久、影响面最广的安全大会HITBSecConf达成合作，在新加坡举办了第三届XCTF联赛新加坡站国际赛HITB GSEC CTF 2017，取得圆满成功，开启了中国团队出国办网络攻防赛事的先河。

  

![](../Images/18a2f6fa1ae960f7b1c382f3e098010a.png)

HITB GSEC CTF 2017-新加坡现场

  

今年，赛宁网安将再度携手HITBSecConf 2018，再次精诚合作，并首次在欧洲落地XCTF分站赛事！HITBSecConf 2018将于4月9日-13日在古丝绸之路的终点城市荷兰阿姆斯特丹举办，大会将延续一贯风格，除了安全大会，高规格论坛，展会之外，CTF竞赛一直是颇受众人期待的重头戏。为了更多爱好者能够参与赛事，本届大会赛事对比DEFCONCTF，同期举办线上线下两场赛事。

  

本次大赛线下赛与线上赛将同期分别举办，线下赛场将会有来自8个国家的24支战队齐聚阿姆斯特丹竞技比拼，线上赛场将面对全球网络安全爱好者开放，赛宁网安将受邀为本次赛事的提供平台支持，赴欧洲展示实力。

  

![](../Images/c4bee9914031d569ec4cae284ba0974d.png)

  

去年在HITBSecConf-新加坡现场，作为技术支持的赛宁网安攻防竞赛平台，炫酷的3D动态展示效果，引来HITB合作方、参赛队伍和观众、印度、新加坡等国际同行的一致好评（“Cool”、“Wonderful”、“Sexy”）。此次赛宁网安平台亮相欧洲，对赛宁网安来说也是展示实力的大好时机，团队表示信心满满。 

  

同期举办的线上赛也将于荷兰当地时间4月11日14:00开赛，持续48小时的比赛将采用解题的形式，排名前十五的战队将受邀入围HITB-XCTF GSEC CTF 2018线下赛（8月30-31日于新加坡）。全球的网络安全爱好者及HITB大会现场的观众都可以加入到比赛中，线上赛同样由赛宁网安提供平台支持、第三届XCTF联赛总决赛冠军战队FlappyPig担任出题。
