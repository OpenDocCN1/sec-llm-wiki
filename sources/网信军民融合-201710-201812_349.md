# 第二届“强网杯”全国网络安全挑战赛线上赛第二日战报

3月25日晚9点，“强网杯”全国网络安全挑战赛线上赛圆满落幕。经过36小时的鏖战，来自腾讯公司的“eee”战队凭借高超的技能，以解题31道7780分的成绩占据积分榜首位。  

  

“强网杯”全国网络安全挑战赛是面向高等院校和国内信息安全企业的一次国家级网络安全赛事，旨在通过激烈的网络竞赛对抗，培养和提高国家网络安全保障能力和水平，发现网络安全领域优秀人才，提升全民网络空间的安全意识和能力水平。本次比赛受到全国网络安全界人士的高度重视，注册队伍达2622支，网络安全专业传统强校（如浙江大学、复旦大学、上海交通大学等），知名网络安全企业（如腾讯、阿里巴巴、长亭科技等）均组队参赛。

  

3月24日上午9时比赛正式开始，各队快速进入状态，厮杀十分激烈。开赛仅6分钟便有队伍率先斩获了web 签到赛题，随后各个队伍逐渐发力，前十名的分数线也水涨船高。开赛两小时，比赛得分情况非常胶着，ROIS、Nu1L、Oops三支队伍作为CTF联赛传统强队一如既往的强势，排名稳居前列，并保持着较高的解题速度。在前几名队伍比分交替上升的同时，“楼上两队快点合并吧”战队异军突起，连续拿下了两道难题的一血，比分跃居第一。随着比赛进行至下午，各队暂时进入调整阶段，名次变化不大，此时来自浙江大学的“AAA”战队展现了他们老牌强队的底蕴，不断刷新答题数，迅速建立起近1000分的优势，在很长一段时间内占据榜首。3月24日18时，随着新一批赛题发布，赛场形势瞬间风云变幻。老牌强队sixstars、0ops、NeSE等对榜首发起猛烈冲击，第一名的队伍交错更替，迎来了第二波答题热。众多蛰伏的战队也开始发力，其中“无声双螺旋”战队更是一匹黑马，在拿下两道高分Web赛题后，成功跻身前三。在黑马的刺激下，一个个赛题相继被攻克，各战队的竞争进入白热化阶段。

  

强网杯全国安全挑战赛进行至第二个比赛日。经过一夜的鏖战，AAA、eee、NeSE战队暂列前三甲，各队答题数都在稳步上升。上午9时，随着一批新赛题的发布，各队伍进入又一轮激烈的比拼阶段。上午11时，Eur4kAXEur6kA战队连续提交两道题，成功跻身前五。中午12时，随着新一轮赛题的发布，比赛进入新的高潮，各支队伍各显神通，在擅长的领域各有斩获。eee战队更是其中翘楚，以27道答题成绩稳居榜首，AAA、0ops战队不甘示弱，紧随其后。之后，eee战队仍保持着较高的答题速度，AAA战队虽几次企图超车，但都未能如愿。在比赛最后阶段，sixstars战队突然发力，反超0ops战队跃居第三。晚上21时，比赛结束，最终排名前三的队伍定格为：eee、AAA、sixstars战队。导调裁评组待选手提交完Writeup审核后将发布最终名次。
