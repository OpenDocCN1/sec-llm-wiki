# 第二届“强网杯”全国安全挑战赛线上赛实时战报

第二届“强网杯”全国安全挑战赛于3月24日上午9点钟准时开赛。赛程伊始，各个队伍很快进入了状态，仅仅6分钟便有队伍率先斩获了web 签到题目，随后各个队伍逐渐发力，前十名的分数线也水涨船高。开赛两小时，比赛得分情况非常胶着，“ROIS”、“Nu1L”、“Oops”三支队伍作为CTF联赛传统强队一如既往的强势，排名稳居前列，并保持着较高的解题速度。在前列队伍比分交替上升的同时，“楼上两队快点合并吧”战队异军突起，连续拿下了两道难题的一血，在12:30时拿下了misc ai-nimals题目的一血，比分跃居第一。

  

经统计，截止到下午3点，参与答题的队伍已到达1954支，提交答案的人数达到1245名，已正确解题数达到15题。其中，楼上两队快点合并吧、Eur4kAXEur6kA、gogogo、ROIS、Nu1L五支队伍分列前五名。

  

![](../Images/aaae08cb5954b019bc3bb758ef86d8b2.png)

![](../Images/9c38165ae2df2f88a9c562ce0f539a8c.png)

  

本次强网杯线上赛已放出的题目类型包括PWN（漏洞挖掘利用）、Crypto（密码分析）、Misc（杂项）、Reverse（逆向）、Web（Web渗透）五类技术挑战。

  

本次比赛采取严格的反作弊措施和技术手段，力争为选手提供一个公平公正的比赛环境。目前，经过作弊监控系统和流量分析发现疑似作弊行为三起，两起经申诉核实已澄清，第三起涉事“REDS”战队未能在1个小时以内提交解题思路，已作禁赛处理。

  

预祝选手们取得好成绩！
