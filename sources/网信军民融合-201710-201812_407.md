# CCTV-1《晚间新闻》、CCTV-13《新闻直播间》一天内两次报道第十三期钱学森论坛

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247484930&idx=1&sn=d74b3ab5c831f2dbb4a2b97f0c242a0d&chksm=e9bc12bcdecb9baae9734cf3f08cd937c3199a703d3aaf5d4b3e985883d8e07a060388b94d83&scene=126&sessionid=1681311678#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247484930&idx=1&sn=d74b3ab5c831f2dbb4a2b97f0c242a0d&chksm=e9bc12bcdecb9baae9734cf3f08cd937c3199a703d3aaf5d4b3e985883d8e07a060388b94d83&scene=126&sessionid=1681311678#rd)

1月13日，由中国航天系统科学与工程研究院（中国航天第十二研究院）、中国航天工程科技发展战略研究院、钱学森军事系统工程研究院联合主办的第十三期钱学森论坛 “相聚丝绸之路起点，奏响强国战略号角——钱学森智库聚焦古都复兴”在西安盛大开幕。陕西省委常委、西安市委书记王永康出席，薛惠锋院长作报告。

  

此次论坛的举办，吸引了各领域、各层级媒体的高度关注，中央媒体、省级媒体、省会级媒体、新媒体等均进行了多角度、大篇幅报道。**1月14日，CCTV-1《晚间新闻》和CCTV-13《新闻直播间》分别对论坛召开进行了报道。一个多月以来，央视已对钱学森论坛进行了四次报道。**经过近两年的努力，钱学森论坛已经显现出其理论的高度和影响的维度，为各领域创新发展提供了不竭动力。
