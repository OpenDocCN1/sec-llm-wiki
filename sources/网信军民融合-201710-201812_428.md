# 北京指掌易科技有限公司创始人兼CEO王伟：维护移动空间安全，提升移动作战能力

编者按：习总书记在十九大报告中指出，深化科技体制改革，建立以企业为主体、市场为导向、产学研深度融合的技术创新体系，加强对中小企业创新的支持，促进科技成果转化。还要支持民营企业发展，激发各类市场主体活力。本期产业视点邀请**北京指掌易科技有限公司创始人兼CEO王伟**畅谈对十九大精神的学习体会，并对相关产业发展进行分析。

  

![](../Images/f8c81f25acb5f8cf0727f38ede5e29b5.png)

北京指掌易科技有限公司创始人兼CEO  王伟

  

在十九大报告中，习总书记特别强调要完善国家安全战略和国家安全政策，坚决维护国家政治安全，加强国家安全教育，增强全党全国人民国家安全意识，推动全社会形成维护国家安全的强大合力。同时十九大报告中有多处讲到“军民融合”，深刻阐明了军民融合在富国强军中的战略地位，明确了新时代军民融合发展的新目标新任务。还要统筹推进传统安全领域和新兴安全领域军事斗争准备，加快军事智能化发展，提高基于网络信息体系的联合作战能力。

  

将民用的智能终端设备用于军事单兵作战，这是不可避免的趋势，然而，移动终端设备的独特属性导致其信息容易被泄露，容易被不法分子非法利用，电信诈骗犯罪时有发生，甚至在国家安全层面也受到不小的威胁。如何发挥移动设备技术先进性的同时又保障移动设备上的军事信息安全，如何真正实现网络强国建设，如何让互联网的发展真正惠及十三亿中国人民，保证国家信息安全，是一大挑战。在深刻学习了习总书记报告内容后，结合时代发展背景，指掌易对自身的发展道路提出了三点要求：第一，不断提升自身的业务能力和水平，潜心钻研，不断创新，加快技术革新和发展；实现安全技术能力完全自主可控，并在移动安全领域达到全球领先水平。第二，在人才培养方面，不断完善创新人才评价体系和管理奖励制度。移动网络空间安全是一个综合能力体系，涉及技术攻关、产品研发、工程研究、大数据分析、业务研判等多个方面，每个方面都需要大量的专业人才。指掌易将培养移动安全全方位人才为己任，积极引进、培养、鼓励人才创新发展。第三，指掌易会与我军部队保持密切联系，不断为我军部队士兵提供最先进的移动安全保障系统。目前，指掌易的移动产品已经在我国多个地方部队得到应用，为移动网络空间的安全起到了推动作用，后续，我们会继续深入研究更符合军队需要并能提升单兵作战能力的移动安全解决方案。

  

新时代新征程下，网络空间安全能力已成为一个国家的核心能力，指掌易将继续秉持着强烈的社会责任感，坚定对国家安全的信仰和信念，为国家网络安全和信息化建设提供最强有力的支持，为我军官兵提供强有力的安全管控，为全国企事业单位提供最专业的安全防护。
