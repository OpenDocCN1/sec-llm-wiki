# 俄罗斯将测试脱离国际互联网的能力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247489445&idx=4&sn=375d12c0005176b5ed01e9fcaaab70ab&chksm=e9bc031bdecb8a0de038fa9a4bdce89ba817c5e962c75e5769c1e6a48bdacae272b8f0f3ef55&scene=126&sessionid=1681311438#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247489445&idx=4&sn=375d12c0005176b5ed01e9fcaaab70ab&chksm=e9bc031bdecb8a0de038fa9a4bdce89ba817c5e962c75e5769c1e6a48bdacae272b8f0f3ef55&scene=126&sessionid=1681311438#rd)

**【导读】**俄罗斯政府10月21日宣布，俄罗斯将测试整个国家脱离国际互联网的能力，同时测试俄罗斯构建的国内互联网能否在没有国际互联网的情况下独立运行。此次测试范围包括了俄罗斯联邦的领土内以及拥有俄罗斯联邦政府选民的地区。

  

**一、演习要求和目的**

  

根据4月份通过的俄罗斯“互联网主权法”，此次测试演习要求：俄罗斯所有互联网运行必须经过俄罗斯官方控制中心、允许政府能够切断外部进入、政府能够关闭未经同意的网站、能够监视互联网运行。俄罗斯政府表示：此种测试每年都将举行，每年的测试时间还将不同；俄罗斯政府今后将采取一系列的技术手段并制定相关政策，来保障俄罗斯能够脱离国际互联网；新生的俄罗斯国内互联网将使俄罗斯无惧国际互联网上的网络攻击；俄罗斯国内互联网并不期望能够提高俄罗斯人及俄罗斯公司互联网在线使用的便捷性，只寻求使国家在技术上更独立，弥补逐步显现的网络安全缺陷。

**二、演习准备**  

  

 来自“新美国”研究互联网管理和数字信息权威的网络安全政策专家表示：俄罗斯政府看到了过去十年在阿拉伯地区出现的由于互联网在线信息传播导致的动乱，因此决定控制互联网信息的传播，以免其威胁到国家的稳定。2006年的俄罗斯法律限制了“领英”职业社交网站、Zello聊天通信软件、Telegram即时聊天工具等的使用，要求相关外国公司对俄罗斯安全部门开放其软件、并允许俄罗斯法律执行部门处理用户数据。  
2016年，俄罗斯启动了“保密的数据传输系统”：主体是一个大型军事保密数据内部互联网，类似于美国国防部的“联合全球情报通信系统”。2017年，俄罗斯宣布将构建其自主域名系统。2018年，普京的首席信息技术顾问赫尔曼·克利门科以及其他专家建议，新系统（指“保密的数据传输系统”）应能够承担国内其他互联网功能。2019年4月，俄罗斯颁布“互联网主权法”；10月21日，俄罗斯政府根据该法案批准了相关规定，同意实施此次演习，以确保俄罗斯联邦网络和公共通信的稳定、安全和功能完整。

  

**三、美媒看法**

  

美国外国政策委员会等多个机构专家称：俄罗斯政府此举，是为了应对其战略上的缺陷，即过于依赖西方的信息技术；俄罗斯整个国家在高技术方面过于依赖外国进口，俄罗斯认为这种技术利用方式对俄罗斯国家独立而言过于脆弱；俄罗斯国内政府机构、社会领域和私营部门采用了大量外国技术，俄罗斯政府决定采取一系列手段控制互联网通信对外国技术的使用；俄罗斯政府想知道外部势力在何种程度上影响俄罗斯国内互联网，因此，才实施了此种年度演习。  

![](../Images/9779784917dccc486c786151071da1e3.png)

  

由于俄罗斯政府已构建了能够脱离国际互联网的基础设施，才使得俄罗斯政府有能力限制相关人员进入集会和抗议网站，有能力限制相关人员通过互联网开展集会和抗议活动。俄罗斯的“互联网主权法”将加强这种趋势。
