# 想去世界互联网大会博览会？报名渠道来了！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247489138&idx=2&sn=d1ec55a5b94c71e88c6826040ea45337&chksm=e9bc02ccdecb8bdaff9a9583c9142daaddd7e23173c1782905f697d647ab13d811f4e1b3d3cd&scene=126&sessionid=1681311453#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247489138&idx=2&sn=d1ec55a5b94c71e88c6826040ea45337&chksm=e9bc02ccdecb8bdaff9a9583c9142daaddd7e23173c1782905f697d647ab13d811f4e1b3d3cd&scene=126&sessionid=1681311453#rd)

  

由国家互联网信息办公室、科学技术部、工业和信息化部、浙江省人民政府共同主办的第六届世界互联网大会“互联网之光”博览会将于2019年10月18日至22日在浙江乌镇举行。诚挚欢迎全国各地的互联网业界人士及社会大众前往乌镇现场参观。

  

现将有关事项通知如下：

  

![](../Images/9a5bea60788ae7a812b080249fb3c8cf.png)一、博览会时间地点

  

  

**时间**：10月18日-22日。其中，数字经济人才对接会时间为10月18日—19日。  

  

**地点**：乌镇互联网国际会展中心展览中心和“互联网之光”博览会扩建展馆A馆（浙江省嘉兴市桐乡市乌镇镇）。

  

![](../Images/9a5bea60788ae7a812b080249fb3c8cf.png)二、博览会展示内容

  

本届博览会聚焦世界互联网最新发展趋势和前沿技术，突出展示全球范围的新技术新成果，包括展览展示、新产品新技术发布、产业合作项目对接、数字经济人才对接会等板块。预计将有近600家中外企业参加本届博览会。其中，展览展示板块设置人工智能、云计算、大数据、网络安全、工业互联网、电子商务、未来社区与智慧医疗、数字文化传媒、智慧社会等主题展区，并设有5G应用体验区；新产品新技术发布板块以“新品发布+专场演讲”形式，由120余家中外企业、团队、机构发布新产品新技术和研究成果；数字经济人才对接板块由数字经济高成长企业在展会期间设置招聘展位，并进行“人才需求目录”发布，组织人才与需求方进行面对面交流对接；产业合作项目对接板块搭建专门的产业合作洽谈平台，举办系列专题对接会、资本相亲会。

  

![](../Images/9a5bea60788ae7a812b080249fb3c8cf.png)三、博览会参观须知

  

  

“互联网之光”博览会免费面向注册报名的专业观众限额开放，名额满后将关闭报名渠道。  

  

**1.团体观众报名。**欢迎全国各地政府部门、高新园区、开发区、众创空间、特色小镇、行业协会、企业等组团参观。各地团体观众参观时间段为10月18日-19日、21日-22日。每天上午9:00开幕，下午17:00闭馆（其中18日上午9:30开馆，22日下午15:00闭幕）。报名时间截止到10月8日17点。

  

报名方式：请填写《“互联网之光”博览会专业观众团体报名信息表》，加盖公章后将电子版及扫描件发送至博览会团体观众报名邮箱wxl@zqa.org.cn，我们将在审核后通知团队联系人。此外，博览会网络报名平台将于近期正式上线，上线后可登录世界互联网大会官网“展会博览”板块进入“团体观众报名”栏目进行注册报名。  

  

**2.社会个人报名。**参观时间段为10月18日-19日、21日-22日。每天上午9:00开馆，下午17:00闭馆（其中18日上午9:30开幕，22日下午15:00闭幕）。报名时间截止到10月8日17点。

  

报名方式：关注“互联网之光”博览会官方微信公众号“世界互联网大会互联网之光博览会”进入“报名通道”栏目进行注册报名。此外，博览会网络报名平台将于近期正式上线，上线后可登录世界互联网大会官网“展会博览”板块进入“社会观众报名”栏目进行注册报名。收到审核通过短信的观众可凭本人有效身份证安检后入场参观。  

  

**3.参观出行安排。**各地专业观众可自行选择公共交通前往乌镇观展。乘坐高铁到达浙江省嘉兴市桐乡站的观众乘坐K282路公交车，乘坐汽车到达浙江省嘉兴市桐乡汽车站的观众乘坐K231路公交车，均可抵达乌镇禽蛋市场站。在此按照博览会工作人员的引导调度，换乘接驳车前往“互联网之光”博览会场馆。公共交通路线如有调整则后续另行公布。

  

浙江省以外的各类团体组织的专业观众，如确实需要，博览会将提供杭州、桐乡等地至乌镇的车辆接送服务，请务必在报名时注明，并留意短信通知，确认接送相关事宜，现场核对身份后方能乘车。  

  

参观期间，参观人员需严格遵守博览会组织方及公安等部门的规定，服从组织安排，自觉维护秩序。
