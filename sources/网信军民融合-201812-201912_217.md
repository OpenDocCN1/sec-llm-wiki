# **工业和信息化部**

# **关于信息系统工程监理单位资质认证**

# **有关事项的通告**

  

工信部信软函〔2019〕169号

  

  

“信息系统工程监理单位资质认证”已于2014年由国务院明令取消，任何组织和机构不得继续实施。存在上述问题的应立即纠正，确保国务院的“放管服”改革要求落实到位。

  

特此通告。

  

工业和信息化部

2019年6月20日

  

来源：工业和信息化部信息化和软件服务业司
