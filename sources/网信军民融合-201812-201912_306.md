# 第二届数字中国峰会有哪些大咖参加，分别做何主题报告？

**【导读】**由**国家互联网信息办公室、国家发展和改革委员会、工业和信息化部、福建省人民政府**共同主办的**第二届数字中国建设峰会**于**2019年5月6日至8日**在**福建省福州市**举办。峰会主题为：**以信息化培育新动能，用新动能推动新发展，以新发展创造新辉煌。**峰会包括**开幕式、主论坛、分论坛、成果展览、报告发布、创新大赛和闭幕式**等七个环节。在峰会上，**都有哪些大咖参加，分别做哪些主题报告？**小编为大家一一整理如下，以飨读者。
