# 美国网络司令部2020财年项目与投资计划

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247487888&idx=2&sn=077a81535c604db04b11d21a65b0f39a&chksm=e9bc052edecb8c387cb9b4a5efe420100eae708623cc3a47556ac000935360b4cd06c30557fc&scene=126&sessionid=1681311514#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247487888&idx=2&sn=077a81535c604db04b11d21a65b0f39a&chksm=e9bc052edecb8c387cb9b4a5efe420100eae708623cc3a47556ac000935360b4cd06c30557fc&scene=126&sessionid=1681311514#rd)

**【导读】**在3月18日发布的美2020财年预算请求文件中，美国国防部网络部队的具体项目和预算金额的细节逐渐清晰。该文件提供了某些网络项目的发展方向，以及美国网络司令部投入资金以装备其网络部队的计划。

  

![](../Images/3966439bb65f265c94e35977d0fbe244.png)

  

尽管网络司令部拥有特殊的采办权限，但作为作战司令部，网络司令部依赖各军种作为执行代理来采办系统、基础设施和工具，其中大多数由空军担任主要执行代理。**网络司令部寻求在四个领域开发并扩大基础设施和能力：联合公共服务（joint common services）、联合访问平台（joint access platforms）、联合工具（joint tools）以及联合分析（joint analytics）。**根据空军2020财年的研究与开发预算文件，这四个项目的预算总计**1.988亿美元**。这一数字逐年上升，预计2024财年将达到**2.33亿美元**。

  

  

**联合公共服务（3630万美元）**

  

该资金将支持网络部队开展网络作战，继续发展联合网络作战人员架构。鉴于网络空间作战的联合性质，国防部需要统一方法来处理各军种内网络任务部队将使用的工具和平台。此项工作还包括开发跨领域解决方案、技术、政策与流程，以实现威胁情报的共享。

  

  

**联合访问平台（6860万美元）**

  

该资金将支持网络任务部队访问目标和检索数据的能力，包括网络作战基础设施的开发和客户端/服务器平台的改进，以实现多种基于任务的网络影响。

  

  

**联合工具（8,630万美元）**

  

该资金将支持网络任务部队用于对联合目标实施网络作战的能力。包括网络任务部队在作战期间持续为目标开发专门工具。

  

  

**联合分析（740万美元）**

  

该资金支持网络任务部队将从多个来源收集的数据关联起来以建立支持决策的见解的能力。包括继续开发与维护网络作战框架以及相应的数据分析。

  

  

**联合网络指挥与控制**

  

空军预算项目中的另一项被称为联合网络指挥与控制（JCC2）。空军研究与开发预算文件称，JCC2是一个能够为指挥官增强态势感知并提供网络作战管理的系统。

  

2020财年预算请求文件为该项目的基础工作申请1160万美元，用于软件工程、风险管理、开发框架管理和采办活动。具体行动包括开发能力、启动网络任务部队用于开展网络作战的网络任务命令、建立开发环境，以及建立一支开发运维团队以便持续在战斗指挥部进行试点。
