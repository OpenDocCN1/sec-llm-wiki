# 马化腾：人工智能“伤人”怎么办？监管需引导“科技向善”

近年来，我国科技产业取得长足进步，科技实力显著增强。腾讯公司董事会主席兼首席执行官马化腾认为，以信息技术和生物技术为代表的新技术广泛应用，释放了巨大的创新潜力，也带来了风险挑战，存在忽视社会效益，片面利用科技手段追求经济利益，缺乏制度规则导致新技术滥用等问题。

  

在《关于加强科技伦理建设 践行科技向善理念的建议》中，马化腾提出，加强科技伦理的制度化建设，在国家层面制定伦理准则，引导和规范新技术应用，在国际层面积极参与国际标准、规则制定，推动新技术领域的全球治理；加快研究数据、人工智能、基因编辑等新兴技术领域的法律规则问题，如在数据规则方面，应进一步完善数据治理的顶层设计，建立数据收集、利用与保护的基本规则秩序，防范并打击数据滥用行为。马化腾还建议，**要加强科技伦理的教育宣传，鼓励全社会践行“科技向善”的理念。**

![](../Images/4f550d693f2b8c0ddccb2e3dfa23bff2.png)

  

今天上午，马化腾接受央视财经专访时，进一步解释了此观点：**科技像一个工具，好人用的好是好事情，如果说坏人拿高科技作恶的话，我觉得危害是非常大的。**

  

比如有的时候过度地利用个人的信息，有可能它的安全性，包括它的可能阅读的一些内容就会越来越像，需要外界力量能够对一些算法进行管理和控制。再比如，机器人整合了人工智能，有一定程度的自主运动、自主控制，但如果发生了意外、发生了问题，这是谁的责任，在这种全自动运作的过程当中要遵循什么原则，这是非常重要的。

  

交叉学科、跨界部分往往是过去法律法规、伦理的标准都是非常缺失的，也是研究和讨论比较少的地方，现在是随着各种事件和各种科技的发展，我觉得这个是要公众更多地去讨论的话题，学界更多地做研究，政府部门、监管部门要更多地看这方面如何更好地去规范。

  

但是要注意两个倾向，第一是完全放任不理，第二是过度地去监管，可能在一些新兴的业态还没有成熟之前，**过早地完全去刹车，也会扼杀一些创新。**这两者都要考虑。
