# 美国军工企业界对2019年作战趋势的预测

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247487263&idx=2&sn=a8f075888692c4850461c2a5841e8d2a&chksm=e9bc1ba1decb92b79c05cd400a1efa045815d6de19288c502920e08765a98c696dd804514b43&scene=126&sessionid=1681311546#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247487263&idx=2&sn=a8f075888692c4850461c2a5841e8d2a&chksm=e9bc1ba1decb92b79c05cd400a1efa045815d6de19288c502920e08765a98c696dd804514b43&scene=126&sessionid=1681311546#rd)

随着马蒂斯的离任，美国下一任国防部长可能会重新强调五角大楼采办改革，并继续关注中国的科技发展。美知名军事网站c4isrnet近日对多名美国军工业内人士进行了采访，他们对2019年作战趋势分别作出了各自的预测：

**快速采办**

  

在开始应对诸如人工智能等重大技术之前，美国必须改变开发武器装备的方式。2019年，国防部将真正开始从采购专有的、烟囱式的、封闭的硬件系统转向商业软件领域，以此作为开发和集成武器系统的模式。专注于商业软件研发是能够真正快速开发开放、可升级、具有网络弹性的系统的方式。当前科技发展的速度比以往任何时候都快，特别是在软件领域，新系统的周期常常以周或月为单位。如果想保持领先，就必须认清现实并快速采取行动。

  

![](../Images/9741355e1c9303afa93e5ba0ce12d782.png)  

  

**多域协同响应**

  

世界安全环境正在向多域协同作战演变，这迫使美军更加具有适应性和协调性。随着威胁的加剧，美军需要的是在多域之间同时无缝作战的方法。C4ISR技术是在较短时间内管理和响应这些复杂任务的基础。美军需要继续投资转型技术，提高“多域作战”的可预测性和有效性。这包括：

跨新老数据链路的机对机通信；

将多源信息进行融合，并减少决策时间轴数据；

将人类角色从控制者转变为思考者的技术，从而专注于策略而不是执行细节；

算法战，以支持人类与计算机系统之间的伙伴关系，大幅提高处理、开发、发布和指控作战的速度；

先进多级安全建模和仿真。

  

**小型网络**

  

2019年，预计国防部将大幅增加对小型网络、安全无线和虚拟计算的投资，以提高作战人员的机动性和战术远征计划中的态势感知能力。战术通信计划已经证明了通过减少尺寸、重量和功率（SWaP）以转型到小型设备的有效性。特别是使用商业技术、数据中心服务和存储以及防御性网络安全方案的机密无线战术部署将在2019年得到相当大的新应用。

  

![](../Images/1dff3a936566890c9856fe56d4aac0fb.png)  

  

**音频认证**

  

音频将成为2019年网络方案的热门词汇。在IP视频中引入音频作为安全层，为物理安全方案提供了一个新的整体安全层。音频技术允许专业安全人员与用户进行远程交互，并通过识别攻击性声音、玻璃破碎甚至枪声，提供自动响应，以防止威胁升级。有了这种新的音频技术和分析能力，专业安全人员就能主动发现、解读和应对突发事件和紧急情况。

  

![](../Images/296445271e016729d54b353d9dcdf794.png)

  

**云攻击**

  

预计在2019年，针对云端数据的攻击将显著增加。随着Office 365软件的普及，对这项服务的攻击也将激增，尤其是试图攻击电子邮件的行为。另一个威胁是新型僵尸网络KnockKnock，通常针对的是没有多重身份验证的系统账户。过去几年，发生多起备受瞩目的数据泄露事件，都是由Amazon S3存储桶配置不当造成的。在共享责任模型的基础上，客户需要正确配置IaaS/PaaS基础架构，并适当保护数据和用户权限。更复杂的是，许多配置错误的数据存储桶由供应商持有，而不是由目标企业所有。随着数千个公开的存储桶和凭证的使用，令不法分子有了可乘之机。

  

![](../Images/963e242ba00b825be0bbbdf5b4285f34.png)  

  

**反无人机技术**

  

小型无人机（SUAS）不断扩散，导致无人机事件迅速增多，使得安全人员迫切需要对这一新的、不断演变的威胁采取全面的解决方案。反无人机技术是评估空域活动、了解无人机入侵的严重性和制定新协议以减轻潜在威胁的重要工具。使用反无人机技术，安全人员现在可以观察无人机的行为并部署适当的进攻性或防御性对策，其中可能包括与飞行员的直接接触或与当地执法部门的协调。在任何情况下，侦察小型无人机活动是任何反无人机项目的关键基础。反无人机不存在放之四海而皆准的解决方案。此外，反无人机技术必须具有灵活性，以满足特定环境的需要。
