# 助力“新基建” 中国互联网络信息中心（CNNIC）IP地址管理政策修订

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247491745&idx=2&sn=31e0ed38afebca084fd9f4d7f1d8ead9&chksm=e9bff41fdec87d094ce30e97bbdadc747ec6e1471a71b722ed9a8d59aacb6430673b084df09d&scene=126&sessionid=1681311357#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247491745&idx=2&sn=31e0ed38afebca084fd9f4d7f1d8ead9&chksm=e9bff41fdec87d094ce30e97bbdadc747ec6e1471a71b722ed9a8d59aacb6430673b084df09d&scene=126&sessionid=1681311357#rd)

　　为支持新型基础设施建设，加快推进我国IPv6规模部署，**中国互联网络信息中心（CNNIC）于近日发布了新修订的《中国互联网络信息中心IP地址资源管理办法》（以下简称“《办法》”）。**

  
  
  
  
  
  
  
  

　　原《CNNIC IP地址分配联盟管理办法》发布于2015年，CNNIC按照有关规定对联盟会员IP地址和AS号码资源进行管理。近年随着“新基建”的加速推进，5G、云计算、工业互联网的繁荣发展，行业对IP网络自动化、智能化、稳定性提出了新要求。经过长期详实产业调研、广泛征询会员意见，CNNIC对原有政策进行修订，使其更加有利于推动新科技应用带动下产业进程的发展。此次修订所涉及的主要内容如下：

  

　 **一是规范IPv4地址转移政策。**严格IP地址转移申请审核管理，对IP地址转移双方、待转IP地址段的历史转移记录进行明确规定。

  

**二是加大IPv6地址优惠力度。**鼓励联盟会员申请、使用IPv6地址，确保相关内容与最新国际IP地址分配管理政策、国内相关主管部门对企业和组织主体资格方面的规定保持一致。  
  
  
  
  
  

　　新修订的《办法》将在积极落实IPv6行动计划、加快网络基础设施升级、提高IP地址的使用效率、加强技术创新应用，共同创建良好的产业创新与应用环境方面起到积极的作用。

  

来源：网信中国、中国互联网络信息中心（CNNIC）
