# 带动千亿产业规模！全球低轨卫星移动通信与空间互联网系统项目启动运营

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NjU2NDMwNQ==&mid=2247489783&idx=2&sn=5136b82829dd639b83eda5aed9095869&chksm=e9bc0c49decb855f14d3d71d3b143a96c8c2255b2487669ec4ed6ac5e5d6b4fa467c5ee84d2a&scene=126&sessionid=1681311423#rd](http://mp.weixin.qq.com/s?__biz=MzI0NjU2NDMwNQ==&mid=2247489783&idx=2&sn=5136b82829dd639b83eda5aed9095869&chksm=e9bc0c49decb855f14d3d71d3b143a96c8c2255b2487669ec4ed6ac5e5d6b4fa467c5ee84d2a&scene=126&sessionid=1681311423#rd)

12月16日，全球低轨卫星移动通信与空间互联网系统项目启动运营活动在重庆两江新区举行。

  

重庆市委副书记、市长唐良智，中国航天科技集团有限公司党组成员、副总经理张建恒出席启动运营活动，并参观了航天科技集团所属东方红卫星移动通信有限公司展厅和实验室，详细了解项目规划建设情况。

  

![](../Images/97ec4689700854a6541d5e7026dfd57e.png)

  

全球低轨卫星移动通信与空间互联网系统项目由航天科技集团所属东方红卫星移动通信有限公司具体实施，将建设覆盖全球的星座及运营系统，提供各种终端产品，构建**海、陆、空、天一体化****新型信息网络**，实现面向**全球**的**移动通信、物联网、导航增强、宽带互联网**等运营服务。

  

该项目将带动上下游**千亿元**的产业规模，以航天产业引领，吸引和带动产业集群发展，建设开放、融合、共赢的互联网经济生态圈，创造更多的商业价值和社会财富，打造央企和地方政府合作的典范，为建设**科技强国、航天强国、网络强国、数字中国、智慧社会**作出贡献，对重庆集聚智能产业，推动数字经济和实体经济深度融合，建设“智造重镇”和“智慧名城”具有十分重要的意义。

  

![](../Images/76b993b4a0b06fbbb8f867b3dfbd9bcf.png)

  

活动中，航天科技集团与地方政府进行了座谈交流。张建恒在讲话中对重庆市及两江新区给予项目发展的大力支持表示感谢。他表示，航天科技集团将发挥自身优势，加快推进项目建设，不断拓展应用场景，助力重庆抢占新一轮产业竞争制高点，为重庆早日建成“智造重镇”、“智慧名城”做出应有贡献。希望重庆市及两江新区继续加大对东方红卫星移动通信有限公司的支持力度，特别是在项目应用示范方面加大引领力度，为项目立足重庆走向全球打下坚实基础。
