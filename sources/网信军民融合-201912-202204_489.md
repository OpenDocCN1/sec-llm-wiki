# 不断推进系统工程在新时代的发展 中国航天十二院举办缅怀钱老暨钱学森智库发展研讨会

![](../Images/5c83cd743b30a52418d424f00f50395f.png)

  

12月11日，为纪念中国航天事业奠基人、人民科学家钱学森同志诞辰108周年，进一步深入探讨钱学森智库的发展与建设，由中国航天系统科学与工程研究院主办的“缅怀钱老暨钱学森智库发展研讨会”在京举行。多位院士、将军以及曾与钱老共事的多位专家、学者围绕议题展开对话与交流。

  

![](../Images/6fd1a530bce42d96b7a9899a38453b6a.png)

  

大多数人对于钱学森的认识一般局限于他在"两弹一星"中的贡献。的确，钱学森在推动中国导弹和航天事业发展中发挥了别人无法替代的关键性作用。但是,很多人不知道的是，钱学森在系统科学领域的贡献同样巨大,甚至更加巨大。钱学森曾说“两弹一星”工程所依据的都是成熟的理论，他只是把别人和他经过实践证明可行的成熟技术拿来用，这个没有什么了不起，只要国家需要他就应该这样做。系统工程与总体部思想才是他一生的追求。钱学森甚至把这个思想称为"我们中国人的发明，中国的智慧，是我们的命根子"。  

  

![](../Images/fa13cf7eaf09ce8c37ec949d4242d75e.png)  

会议认为，科学化、专业化的决策支持，已经成为国家治理体系和治理能力现代化不可或缺的重要组成部分。新的时期，钱学森智库应坚持传承并弘扬钱学森系统思想精髓，不断推进系统工程在新时代的发展，运用系统工程的思想方法、工作方法和思维方法解决我国当前带有全局性、复杂性、整体性的社会问题，为治国理政提供理论支撑和智力支持，更为新时代中国特色社会主义建设提供科学理论和思想武器。让钱学森智库建设真正起到支撑航天、服务国家的作用与意义。

  

![](../Images/3ca6cdd2f0f8e43d6f717384b0c702c2.png)

  

中国工程院院士、中国航天科技集团高级技术顾问王礼恒谈到，总书记指出，国家高端智库要开展前瞻性、针对性、储备性战略研究，提高综合研判和战略谋划能力，提出专业化建设性的意见和建议，为推动党和国家科学决策、民主决策、依法决策、推进国家治理体系和治理能力现代化贡献更多的智慧和力量。钱学森智库的发展与建设应加强与国家高端智库联盟的联系和中国工程院的合作，加强选题的战略性与实用性。畅通渠道，不要局限于航天，要综合各领域优势资源，促进老中青力量相结合。智库建设的核心在于质量，重点在于选题。做好顶层谋划，提高咨询质量，才能建设出更有影响力、更加辉煌的智库。

  

![](../Images/201d0e9d438465f268c4afffbc989896.png)

  

原国资委国有重点大型企业监事会主席刘顺达在致辞中指出，建设好智库，关键要把质量链和责任链通过基于区块链技术的数字链链接起来，这样就可以做到用标准衡量，用实践检验，用数据说话，让决策者把方向、管大局、保落实的时候能够做到胸中有数、有的放矢。钱学森智库要做好智库中的智库，以此来更好的缅怀钱老。

  

![](../Images/9b3115e8193672422f60d05f098405f1.png)

  

国防大学原副政委李殿仁中将表示，钱学森作为一位人生楷模，他在立德、立功、立言方面都树立了新的高峰。学习弘扬钱学森精神，也是我们钱学森智库所应发挥的重要作用之一。我们学习钱学森的系统论，不仅要运用这种方法去认识世界，更重要的是去改造世界。

  

![](../Images/c7c4c743604fa1666c9848dc09962719.png)

  

中国工程院院士、空军航空医学研究所航空医学工程研究中心主任俞梦孙在讲话中谈到，虽然今年已经84岁了，但是自己回忆这一生最有意义的工作，还是在学习了钱学森的思想以后工作至今的十年。总书记在2016年全国卫生健康大会上讲，要把以治病为中心转变为人民健康为中心。俞梦孙认为，要解决13亿人的健康问题，还是要运用钱老的系统学思想，开展新时代的中医现代化工程，概括来说就是 “规模化的有序性开放”，为实现“人民健康为中心”的战略提供新途径。

  

![](../Images/c27e0731385b928f3f5ce286bcef4722.png)

  

原航天 710 所副所长于景元分享了自己跟随钱老学习、工作的一些故事。他表示，钱老的一生是科学的一生、创新的一生、辉煌的一生，在70多年丰富多彩的科学生涯中，钱学森建立了许多科学丰碑，在现代科学技术发展和我国现代社会主义社会建设都做出了巨大贡献。而跟随钱老学习的时光里，更深深感到钱老作为一名人民科学家所具有的高尚品德。

  

![](../Images/fc8a9adee8e5947ad548ec5bc7839ebf.png)

  

国际系统与控制科学院院士顾基发谈到，钱学森晚年30年将研究重心从导弹、卫星领域研究转到了社会系统的研究，并创新系统工程的理论方法，并将其运用到更为宽广的应用对象和应用领域，为产业革命、社会精神文明建设提供了丰富的策略和方法。顾基发认为，一个智库的研究，除针对课题的研究之外，也要注重理论方法的不断研究与革新，这样才能保证智库的研究既有应时的，也有自己所独有的。

  

![](../Images/2ebbdb87da77002e7cbde2ceaf256abc.png)  

国际宇航科学院院士、中国航天系统科学与工程研究院院长薛惠锋谈到，钱学森的系统工程理论和方法经受了从航天领域到社会各领域、从技术科学到社会科学的多重实践和反复验证。1978年钱老等人推出的组织管理技术系统工程，是对管理技术升华的一次革命，在当今全面建成小康社会的伟大征程中仍闪烁着思想的光辉和智慧的光芒。把钱学森系统工程理论与新时代中国特色社会主义建设有机结合起来，正是运用“中国理论”回答“中国问题”、运用“中国智慧”提供“中国方案”，实现系统思维“涌现”的最佳途径。

  

![](../Images/02300d2ad257357ed8b11c68e2ab68b6.png)  

中国航天系统科学与工程研究院党委书记雷刚表示，系统院作为中国系统科学与系统工程的发源地和钱学森智库的依托机构。为进一步挖掘并传承钱学森学术思想，自2013年起恢复了钱老的“系统学讨论班”，在中宣部、中央党史办、中国航天科技集团领导下开展了“口述钱学森工程”、“群星灿烂工程”，形成了一批富有影响力的钱学森思想理论研究成果，为助推高层决策和地方发展起到了咨政建言的作用。

  

![](../Images/84279b0ebb8df49a49175131cddf5f0f.png)![](../Images/58d33a09f0b03cddceb51c51e2d0047d.png)  

全国政协委员王一莉、空军某部原副军长刘子贤少将也围绕主题进行了发言，对于十二院在弘扬钱学森科学精神，继承和发展钱学森系统工程思想方面所做的卓有成效的工作表示敬佩和赞扬。

  

![](../Images/eedb88c221147f6939afa5f6785937d1.png)

  

此次研讨会，进一步阐明了钱学森的科学思想精髓，更为钱学森智库在新时代的发展提供了新思路、新方向。同时，也是对钱学森先生的一次深情告慰。
