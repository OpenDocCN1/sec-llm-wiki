玩转Kali Linux——在Kali Linux上优雅的玩游戏

Kali Linux是用来玩游戏的？

大约 2% 的计算机用户使用 Linux，这就是游戏公司不关注 Linux 的原因。所以 Linux 不适合硬核游戏，而 Kali 显然不适合游戏。我们都知道，它是为网络安全和数字取证而设计的。
但是在 2020 年默认的非 root 更新到来之后，许多用户将 Kali Linux 用作全时操作系统。非 root 更新是为此而来的，但作为全时操作系统，应该有一些游戏可以打发时间。我们列出的游戏可以在其他基于 Debian 的 Linux 发行版上运行，例如Ubuntu。使用wine 工具在 Linux 中玩 Windows 游戏有一个过程，但这里我们讨论直接安装。

Kali Linux中的一些游戏

我的世界


Minecraft 是 Mojang 非常受欢迎的游戏，我们认为它不需要任何介绍。是的，我们可以在我们的 Kali Linux 系统中玩这个令人上瘾的游戏。

我们只需要从以下这个官方链接

https://launcher.mojang.com/download/minecraft.deb

下载Minecraft.deb文件。下载完成后，我们需要打开终端并移动到下载的（默认为cd download）位置并运行以下命令

sudo apt install ./Minecraft.deb

它将开始安装过程，安装完成后，我们可以在菜单上运行 Minecraft 搜索，如下图所示：

或者我们可以在终端中使用minecraft-launcher命令

我们刚刚在 Kali Linux 上安装完 Minecraft。现在我们只需要登录并开始游戏就可以。

Torcs

TORCS（The Open Racing Car Simulator）对于赛车游戏爱好者来说是一款非常酷的游戏。Torcs 可以作为一个标准的赛车游戏来玩，玩家在赛道上开车试图获得第一名，但另一种用途是作为一个平台来开发一个人工智能驱动程序，它可以驾驶自己通过 Torcs 的赛道。

我们可以用 C 或 C++ 开发我们自己的 AI 驱动程序（也称为机器人）。Torcs 被编程为使预编程的 AI 驱动程序能够相互竞争。

单人比赛的范围从练习跑到锦标赛，并且有一个分屏多人模式，最多可容纳 4 名玩家。要使用多显示器进行设置，请参考此网站

http://torcs.sourceforge.net/?name=Sections&op=viewarticle&artid=30#c4_4_4


该游戏支持键盘、鼠标、操纵杆和方向盘所有类型的输入。

我们可以使用以下命令安装这个游戏：

sudo apt-get install torcs

这是一个很大的下载（大约一半 GB），因此根据我们的互联网连接安装需要一点时间。安装过程完成后，我们可以使用以下命令运行torcs ：

torcs

国际象棋

国际象棋游戏已有 1300 多年的历史，是世界上最受欢迎的棋盘游戏之一。我们可以很容易地在我们的 Kali Linux 中安装国际象棋并享受它。
要安装 gnome-chess，我们只需使用 apt-get install 命令：

sudo apt-get install gnome-chess

安装后，我们只需在终端中输入gnome-chess即可打开它。

吃豆人

Pacman 是街机游戏的真正王者。我们可以使用以下命令在 Kali Linux 中轻松安装 Pacman：

suodo apt-get install pacman4console

然后要玩 pacman 我们需要输入以下命令：

pacman4console

注意： 我们不能在小终端窗口中运行 pacman ( pacman4console )。最好在运行 pacman4console 命令之前最大化终端。

俄罗斯方块

这让人怀旧。这个令人上瘾的益智游戏可以在我们的 Kali Linux 终端窗口中玩。首先我们需要从这里下载它。

https://www.victornils.net/tetris/vitetris-0.55-i486-linux.tar.gz


它现在将被下载到我们的下载文件夹中以解压缩它，我们使用以下命令：

cd Downloads && tar -xvf vitetris*.tar.gz

然后我们使用以下命令进入 vitetris 文件夹：

cd vitetris

然后我们使用以下命令对其进行配置：

sudo ./configure

现在我们需要运行 make 命令：

sudo make

是时候安装了，所以我们使用以下命令：

sudo make install

现在我们可以使用以下命令调整俄罗斯方块：

./tetris

该游戏有 2 人模式，支持控制器。

还有另一种在 Linux 上安装俄罗斯方块游戏的简单方法。我们只需要输入以下命令来安装它：

sudo apt-get install quadrapassel

然后在终端输入quadrapassel来运行它。

Quadrapassel 是带有 GUI 的俄罗斯方块的克隆，但它没有 2 人模式。

这样我们就可以在我们的 Kali Linux 中享受著名的街机游戏俄罗斯方块。
