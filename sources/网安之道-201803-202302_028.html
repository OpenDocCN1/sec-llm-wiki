如何安装 eDEX-UI 终端 || 安装 H4cking 系统














eDEX-UI 是一个极客、全屏、高度可定制和跨平台的桌面应用程序，具有未来主义的计算机界面，类似于电影，可在 Linux、Windows 和 macOS 上运行。这将产生桌面的错觉，没有窗口。 





















它做到了ham DEX-UI 和 TRON Legacy 电影的效果。它使用许多开源库、框架和工具。它是为带有大触摸屏的设备而设计的，并打算供其使用，但效果很好，通常用于台式计算机或平板电脑、PC 或带触摸屏的笔记本电脑。 





















eDEX-UI启动，实时选择shell，实时显示CPU使用率、内存使用率、温度、高端进程、网络等系统信息。默认情况下，eDEX 开始在 Linux 上进行 bash，但是，必须这样做。它还有一个文件管理器和一个屏幕键盘。它带有多种自定义选项，包括多个同时可以下载的选项，以及很多界面。




















这个应用程序不是为了执行你的系统的实际工作而设计的，可以装13




















如何在 Linux 中安装 eDEX-UI 终端仿真器













01

终端仿真器 eDEX-UI 的集合 








模拟器 eDEX-UI 的官方商店托管在 GitHub 上，可以查看这里。要下载并保存 eDEX-UI 的 AppImage 终端要安装机器，使用 install 命令。可以在终端 shell 中使用以下任一安装命令将文件上传到文件系统。通常，它会将文件保存到主目录。 


















 下载64 位 Linux 的eDEX-UI 终端 系统











wget -c https://github.com/GitSquared/edex-ui/releases/download/v2.2.7/eDEX-UI-Linux-arm64.AppImage











下载 32 位 Linux 的 eDEX-UI 终端系统











wget -c https://github.com/GitSquared/edex-ui/releases/download/v2.2.7/eDEX-UI-Linux-i386.AppImage



02

如何安装 eDEX-UI 版本 








下载完成后，需要允许 root 用户执行该文件。可以运行以下命令来更改终端的 shell 位置权限以访问此权限。在要运行的 shell 脚本中运行以下命令以开始安装过程。







chmod +x eDEX-UI-Linux-arm64.AppImage./eDEX-UI-Linux-arm64.AppImage









几分钟后，将打开一个弹出窗口，询问是否允许在 Ubuntu 系统上安装终端模拟器 eDEX-UI。请单击“yes”按钮继续。 
在安装过程的eDEX-UI，Ubuntu的版本用不了多少时间。可以在屏幕上看到安装进度。


开始使用 eDEX-UI 终端 


安装终端时，eDEX-UI版本即将结束，首次自动显示在屏幕上。之后，还可以在该部分找到所有打开的应用程序和程序。eDEX-UI 终端模拟器将引导完成并在主屏幕上显示一个小注释。 
在终端仿真器的左侧，eDEX-UI 能够找到的情况是，当前时间的 CPU 使用率、电池状态信息、CPU 温度的型号、RAM 使用率等与系统整体状态相关的信息。在将要查看网络状态和网络状态的部分的左侧。 
在 Linux 机器上打开了 eDEX-UI 终端仿真器的大门，因为它独特的外观，事实上，它非常吸引人。使用了一个小的 apt update 命令来检查它是否真的有效，但它工作正常并且 Linux 存储库已更新。 
如果想更改主题，在文件部分，同时单击，只需单击它。想使用的主题的 json 文件（如果能够为了更改字体或键盘、设置）。
之后，打开终端模拟器，eDEX-UI是多系统，你会看到屏幕键盘（OSK）。实际上，O 是为触摸屏设备而设计的。可以单击选项卡的目录选项卡，在 bash 的帮助下打开目录菜单。如果找不到十字键退出终端，eDEX-UI版本，可以在模拟器界面输入“exit”，然后按回车键退出。
