简介：
Malbox是一个Linux恶意软件模拟器，使用docker-compose即可一键模拟恶意软件运行环境。

构建机器的最低规格

  • 至少 5 GB 的 RAM

  • 强烈推荐 VT-X 扩展



工具使用方法：

# 下载项目git clone https://github.com/G4rb3n/Malbox.gitcd Malbox/
# 进入某一个恶意软件家族的目录cd StartMiner/
# 自动化编译环境docker-compose build
# 启动整个环境docker-compose up -d
# 进入容器docker exec -it [container_name] /bin/bash

分析完毕后，可一键清除容器。

docker-compose down


malbox.sh为采集脚本，可以一键打包中毒主机的病毒项，自动构建容器环境。

chmod 777 malbox.sh./malbox.sh
