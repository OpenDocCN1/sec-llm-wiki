介绍：
SSRFIRE——是一个自动化的SSRF查找器。只需提供域名和自己的服务器即可，它还具有查找 XSS 和打开重定向的选项。

语法：

./ssrfire.sh -d domain.com -s yourserver.com -f custom_file.txt -c cookies



domain.com ---> 需要测试的域

yourserver.com ---> 检测 SSRF 的服务器

custom_file.txt ---> 可选参数。提供自己的自定义 URL，而不是使用 gau

cookies ---> 可选参数。以经过身份验证的用户身份发送请求

BurpSuite专业版想必各位师傅都有吧？这里就不提及了。

要求：
由于这使用 GAU、FFUF、qsreplace 和 OpenRedirex，因此需要 GO 和 python 3.7+。不需要安装这些工具，因为脚本setup.sh将安装所有内容。只需要安装 python 和 GO。即使安装了这些工具，建议再次安装它们，以便在设置路径时不会发生冲突。

如果不想再次安装这些工具，请将此代码粘贴到主目录中的 .profile 中并获取 .profile 它们。此外，各位师傅们必须在第 10 行的 ssrfire.sh 中做一个小改动，必须在没有 .profile 路径的情况下替换 source /home/hari/.profile。（仅当不通过 setup.sh 安装工具时）

#Replace /path/to/ with the specific directory where the tool is installed#If you already have configured paths for any of the tools, replace that code with the below one.ffuf(){        echo "Usage: ffuf https://www.domain.com/FUZZ payloads.txt"        /path/to/ffuf/./main -u $1 -w $2 -b $3 -c -t 100}
gau(){        echo "Usage: gau domain.com"        /path/to/gau/./main $1}
gau_s(){  /path/to/gau/./main --subs $1}
openredirex(){        echo "Usage: openredirex urls.txt payloads.txt"        python3 /path/to/OpenRedireX/openredirex.py -l $1 -p $2 --keyword FUZZ}qsreplace(){    /path/to/qsreplace/./main $1}

用法：

chmod +x setup.sh./setup.sh (preferably yes for all ---> **highly recommended**)./ssrfire.sh -d domain.com -s yourserver.com

寻找 SSRF
现在，gau 通过获取域的所有 URL 开始行动。这可能需要很多时间。可以在 output/domain.com/raw_urls.txt 检查到现在生成的输出。
让它运行至少 10-15 分钟。但是，如果想测试到目前为止获取的 URL，请退出该过程。复制 output/domain.com 中的 raw_urls.txt 并将其放在 domain.com 文件夹之外再运行。

./ssrfire.sh -d domain.com -s yourserver.com -f /path/to/copied_raw_urls.txt


当询问是否删除现有文件夹时选择是。

这将跳过 GAU 获取 URL 的过程。

现在所有带参数的 URL 都将被过滤，yourserver.com 将被放入它们的参数值中。(final_urls.txt)

下一步是向所有最终 URL 发出请求。

寻找 XSS
警告：这会产生大量流量。请勿将其用于无权测试的网站！！！

这会测试所有获取的 URL，并根据输入在响应中的反映方式，将特定 URL 添加到 output/domain.com/xss-suspects.txt （这可能包含误报）

为了进一步测试，可以将此列表输入到 XSStrike 等 XSS 检测工具中以查找 XSS。

寻找开放的重定向
只需输入有效负载文件的路径或使用默认有效负载。我个人更喜欢 openredirex，因为它专门设计用于通过从列表中加载 URL 来检查打开的重定向，它看起来更干净，并且不会淹没终端。
