log4j2-scan简介

  

log4j2-scan是用于CVE-2021-44228漏洞扫描和缓解补丁的单个二进制命令行工具。它还支持嵌套的JAR文件扫描和补丁。

  

![](../Images/913cc8c83255cf050b48b05ddcd21f1a.png)

使用方法

  

只需使用目标目录路径运行log4j2-scan.exe或log4j2-scan。

  

*   
*   
*   

```
在Windows上
log4j2-scan [--fix] 目标路径
```

  

  

*   
*   
*   

```
在Linux上
./log4j2-scan [--fix] 目标路径
```

  

*   
*   
*   

```
在UNIX(AIX、Solaris等)上
java -jar logpresso-log4j2-scan-1.2.2.jar[--fix][--trace] 目标路径
```

  

  

如果添加--fix选项，该程序会将易受攻击的原始JAR文件复制到.bak文件，

并创建新的JAR文件，无需

org/apache/logging/log4j/core/lookup/JndiLookup.class

输入。

![](../Images/b1bc1a8be19b3c6f7edc8a41c18a6cb1.png)

在大多数环境中，不会使用JNDI查找功能。但是，您必须自行承担使用此选项的风险。在应用补丁之前，有必要关闭任何正在运行的JVM进程。修复后启动受影响的JVM进程。

![](../Images/b1bc1a8be19b3c6f7edc8a41c18a6cb1.png)

(mitigated)

如果

org/apache/logging/log4j/core/lookup/JndiLookup.class

条目从JAR文件中删除，则将显示标记。

![](../Images/b1bc1a8be19b3c6f7edc8a41c18a6cb1.png)

如果添加--trace选项，该程序将打印所有访问过的目录和文件。此选项仅用于调试。

![](../Images/b1bc1a8be19b3c6f7edc8a41c18a6cb1.png)

运行原理

  

分5步运行：  
1、递归查找所有.jar文件。  
2、从JAR文件中查找条目。  
3、读取groupId、artifactId和version。  
4、比较log4j2版本并打印易受攻击的版本。  
5、如果使用–fix选项，请备份易受攻击的文件并对其进行修补。  
例如，将原来的vulnerable.jar复制到affect.jar.bak
