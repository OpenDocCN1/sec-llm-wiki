# 2021年第2季度的DDOS攻击资源分析报告

内容摘要：

本报告为2021年第2季度的DDOS攻击资源分析报告。围绕互联网环境威胁治理问题，基于CNCERT监测的DDOS攻击事件数据进行抽样分析，重点对“DDoS 攻击是从哪些网络资源上发起的”这个问题进行分析。主要分析的攻击资源包括：控制端资源，指用来控制大量的僵尸主机节点向攻击目标发起DDoS攻击的僵尸网络控制端。
