NExfil：如何通过用户名来查找用户资料


01


关于NExfil











NExfil是一款功能强大的OSINT公开资源情报工具，该工具采用Python开发，可以帮助广大研究人员通过用户名来查找目标用户的个人资料。
研究人员在将目标用户名提供给NExfil之后，NExfil会在几秒钟之内快速查询超过350个网站。该工具的主要目标就是在保持低误报率的同时快速得到扫描结果。


02


功能介绍


1

快速扫描查询，20秒内即可完成查询;


2

支持对超过350个网站进行扫描;


3

Batch批处理：可通过命令行提供目标用户名，也可通过文件提供目标用户名列表;



4

扫描结果自动存储至txt文件中;


5

即将支持JSON和CSV文件格式;


6

即将添加代理支持;


7

即将支持Tor;


03


工具安装


各位师傅们输入git clone https://github.com/thewhiteh4t/nexfil.git进行拷贝




切换到nexfil文件下输入cd nexfil




开始安装，输入pip3 install -r requirements.txt




输入python3 nexfil.py -h查看帮助
usage: nexfil.py [-h] [-u U] [-d D [D ...]] [-f F] [-l L] [-t T] [-v]
nexfil - Find social media profiles on the web | v1.0.0
optional arguments:
  -h, --help      显示帮助信息和退出
  -u U          指定目标用户名
  -d D [D ...]   指定DNS服务器【默认为 1.1.1.1】
  -f F         指定一个包含用户名列表的文件 
  -l L         指定多个目标用户名，使用逗号分隔
  -t T         指定超时时长【默认为20秒】
  -v           输出当前工具版本信息




以查询单个目标名为例
python3 nexfil.py -u admin
出现如下结果即为安装正确。
