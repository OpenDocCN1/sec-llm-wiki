**1**

  

Pikachu简介

  

  

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

Pikachu是一个中文版的漏洞靶场根据Pikachu的介绍，Pikachu是一个带有漏洞的Web应用系统，在这里包含了常见的web安全漏洞。如果你是一个Web渗透测试学习人员且正发愁没有合适的靶场进行练习，那么Pikachu可能正合你意。Pikachu上的漏洞类型列表如下：

  

**01**

Burt Force(暴力破解漏洞)

  

  

  

**02**

XSS(跨站脚本漏洞)

  

  

  

**03**

CSRF(跨站请求伪造)

  

  

  

**04**

SQL-Inject(SQL注入漏洞)

  

  

  

**05**

RCE(远程命令/代码执行)

  

  

  

**06**

Files Inclusion(文件包含漏洞)

  

  

  

**07**

Unsafe file downloads(不安全的文件下载)

  

  

  

**08**

Unsafe file uploads(不安全的文件上传)

  

  

  

**09**

Over Permisson(越权漏洞)

  

  

  

**10**

../../../(目录遍历)

  

  

  

**11**

I can see your ABC(敏感信息泄露)

  

  

  

  

**12**

PHP反序列化漏洞

  

  

**13**

XXE(XML External Entity attack)

  

  

  

**14**

不安全的URL重定向

  

  

  

**15**

SSRF(Server-Side Request Forgery)

  

  

  

**16**

管理工具

  

  

  

**17**

More...(找找看?..有彩蛋!)

  

  

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

管理工具里面提供了一个简易的xss管理后台,供你测试钓鱼和捞cookie,还可以搞键盘记录!后续会持续更新一些新的漏洞进来,也欢迎你提交漏洞案例给我,最新版本请关注pikachu每类漏洞根据不同的情况又分别设计了不同的子类同时,为了让这些漏洞变的有意思一些,在Pikachu平台上为每个漏洞都设计了一些小的场景,点击漏洞页面右上角的"提示"可以查看到帮助信息。

安装Pikachu(皮卡丘)靶场

  

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

首先第一步，需要下载Pikachu的完整靶场。

  

  

![](../Images/3d88664405e1941e963ed9b333c194f5.png)

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

已经上传好了，各位师傅们只需要在公众号后台回复“皮卡丘”即可获得下载链接(再次提醒有些师傅，是公众号的聊天界面，不是留言区!!)  
下载好之后应该是一个仅有3MB的压缩包文件，之后将其解压到PHPstudy的WWW目录下，如图  

  

  

  

  

![](../Images/84eede1949eebc1b556c3fe263e45729.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

打开pikachu-master文件，找到inc的文件夹，如图

  

  

![](../Images/06e937d929cc3cc80edbd3249d29771d.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

打开此文件夹，找到第一个PHP文件，config.inc.php，如图

  

  

![](../Images/7d31ed960be2b474330e72eff2f9af7b.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

双击打开该文件进行编辑，将第11行DBPW后的单引号内加上root并保存，如图

  

  

![](../Images/74ca7589cd79a65b1dc2802b5f82bdfb.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

把文件夹名pikachu-master改成pikachu，如图

  

  

![](../Images/99eb276bcfd31f8084769f17d1b31d7d.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

打开PHPstudy，开启Apache和MySQL服务，如图

  

  

![](../Images/a42b2cf4bb36e82acd4ad58c4d6f3d08.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

打开浏览器，输入127.0.0.1/pikachu访问，如图(域名不一定要用127.0.0.1，这里仅供安装演示)

  

  

![](../Images/61359008ec64d191c147e95b7ba28bcc.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

访问安装页面，http://127.0.0.1/pikachu/install.php点击“安装/初始化”进行安装，如图则表示成功

  

  

![](../Images/05af091511a7be827c3af0b27e64648d.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

点击该蓝色文字“点击这里”，出现出下图则表示靶场搭建成功。

  

  

![](../Images/0db2d105791ab95d730e251d787e2a5e.png)

  

![](../Images/6c2001bf1911be668cf1318bb4586a7a.png)

到这里靶场环境搭建就结束了，好了，各位师傅们开始探索吧~
