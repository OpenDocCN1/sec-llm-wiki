首先要在kali当中安装GO语言环境

下载安装包命令如下：

wget -chttps://storage.googleapis.com/golang/go1.8.3.linux-amd64.tar.gz


下载完成后，解压到/usr/local目录下

tar-C /usr/local/ -xzf go1.8.3.linux-amd64.tar.gz


开始配置环境，vim打开文件.profile输入以下命令：

exportPATH=$PATH:/usr/local/go/bin

编辑完成之后保存并退出

输入以下命令：

source/etc/profile


让环境变量立即生效，这样kali下的GO环境就安装成功了。

cariddi的安装方法：


git clone https://github.com/edoardottt/cariddi.git; cd cariddi; go get; make linux

卸载的时候把make linux改成make unlinux

使用方法：

cariddi-h 在命令行中打印帮助


cariddi用法:-cint并发性线程。(默认20)-cache使用.cariddi_cache文件夹作为缓存-d int
一个页面和另一个页面之间的延迟-e 寻找有趣的端点。-ef string 使用一个外部文件(txt，每行一个)来使用自定义参数查找端点。-examples 打印示例-ext int 寻找有趣的文件扩展名。从1(多汁)到7(不多汁)的整数。-h 输出帮助文件.-i string忽略包含此数组中至少一个元素的URL。-it string忽略包含此文件中至少一行的URL。-oh string将输出写入HTML文件。-ot string将输出写入txt文件。-plain只输出结果-s    寻找机密数据.-sf string使用外部文件(txt，每行一个)来使用自定义正则表达式查找秘密文件。-t int 设置请求超时时间。(默认10)-version 输出版本信息
