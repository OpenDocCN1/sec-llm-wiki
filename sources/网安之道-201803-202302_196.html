Web App与框架简介




什么是Web App？


Web App运行于网络和标准浏览器上，基于网页技术开发实现特定功能的应用。
前端：HTML、CSS、JavaScript
后端：java、PHP、Python
数据库：MySQL、Oracle、MongoDB
容器：Windows（IIS）、Linux（Nginx、Apache）
在过程中涉及到的协议：TCP、DNS、HTTP、HTTPS





网址到网页浏览过程



请求过程



输入URL，DNS解析URL得到ip地址，根据ip地址找出对应服务器
通过TCP/IP协议建立到web服务器的TCP链接
向web服务器发送http报文，请求服务器里资源文档
web服务器收到http请求报文，发出http响应报文


请求种类



如果请求HTML文档，web服务器会将对应目录下的HTML文档打开，然后将文档的相应内容发送出去
如果请求是PHP文件，web服务器自身是不能够处理PHP动态语言脚本文件的，就会寻找并委托PHP应用服务器，然后将HTML静态代码发送给web服务器，最后web服务器会把HTML静态代码发送出去
如果请求的资源师访问数据库，则web服务器会通过PHP应用服务器去访问数据库。

小结

客户机收到的是HTML的这种静态文档，收到后会解析进行进一步的渲染，最后完成整个访问流程之后会与服务器断开连接。




常见的web服务器有哪些？



Apache

是一个开放源代码的网页服务器软件，可以在大多数电脑操作系统中运行，由于其跨平台和安全性被广泛使用，是最流行的web服务器软件之一。


Nginx

是一个网页服务器，能够反向代理HTTP、HTTPS、SMTP、POP3、IMAP的协议链接，以及一个负载均衡器和一个HTTP缓存。Nginx是一款面向性能设计的HTTP服务器，相较于Apache、Lighttpd具有内存占有少、稳定性高等优势。


IIS

是微软公司推出的服务器


Lighttpd

是一款开源的web服务器软件，具有非常低的内存开销、CPU占用率低、效能好以及丰富的模块等特点。

Tomcat

Tomcat技术先进、性能稳定并且免费，深受Java爱好者的喜爱并得到了部分软件开发商的认可，成为比较流行的web应用服务器。





Python实现简单服务器：

import socket def handleRequest(client):   buf = client.recv(2048)   print(buf)   msg = "HTTP/1.1 200 OK\r\n\r\n"   msg1 = "Hello World~"   client.send(('%s' % msg).encode())   client.send(('%s' % msg1).encode()) if __name__ == '__main__':   ip_port = ('0.0.0.0', 8000)   sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)   sock.bind(ip_port)   sock.listen(5)    while True:       conn, addr = sock.accept()       handleRequest(conn)       conn.close()




在这行代码中，定义了一个handleRequest函数，可以接收客户端向服务器的请求并同时打印这个请求，之后会返回一个HelloWorld~的内容，用http协议封装成一个包之后返回给客户端，所以整个函数处理非常简单。



主函数也比较简单，在本地监听8000端口，并且持续接收来自客户端的输入并且进行返回。


通过以上的代码就可以实现一个最简单的webserver，通过Firefox浏览器访问图如下：



可以看到我们的访问直接解析成了“Hi,helloworld~~”，所以说我们的webserver是可以正常解析HTTP请求并且返回正确内容的。

可以看到接收到了正常的HTTP请求报文，并且返回了正常内容。

通过一共20行的代码，完整的实现了一个HTTP协议。虽然代码结构很简单，但是具备正常完善的功能。

什么是框架？


web应用框架是一种开发框架，用来支持动态网站、网络应用及网络服务的开发。其类型有基于请求、基于组件的两种框架。
有助于减轻网页开发时共通性活动的工作负荷，如：许多框架提供数据库访问接口、标准样板以及会话管理等，可以提升代码的可再用性。
前端：jQuery、Bootstrap、React.js、Vue等。
后端：SpringMVC、Django、Flask、Tornado等。
