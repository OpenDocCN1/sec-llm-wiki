      软件简介

Mem Reduct是一款来自于哈萨克斯坦的Evgeny Kotov设计与开发的轻量级系统内存实时监测与清理工具，这款程序采用无说明内部系统功能即本机系统服务，主要用于清理如系统工作集、工作集、备用页面内存或已更改页面内存等系统缓存，能够帮助计算机安全、瞬间且稳定的节约 10~50% 的内存使用量。虽然 Mem Reduct 能够有效兼容 Windows XP 系统，不过建议在 Windows Vista 或者更高版本平台中使用。使用较小内存及较高系统平台的用户来说，那么 Mem Reduct 着实是个不错的小帮手。为了能够使其正确地工作，需以管理员身份运行使用。
