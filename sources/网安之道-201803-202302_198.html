安装







在termux上安装





pkg install wget && wget https://raw.githubusercontent.com/termuxhackers-id/SIGIT/main/install.sh&& bash install.sh





在kali Linux上安装





apt-get install wget && wget https://raw.githubusercontent.com/termuxhackers-id/SIGIT/main/installkali.sh&& bash installkali.sh





接下来演示在kali Linux上的安装过程。





直接安装上面给出的命令输入到kali Linux中。

然后执行安装命令，各位师傅们可能会碰到如图所示中无法建立SSL连接





解决方案如下：





继续打开hosts文件，编辑输入



192.30.253.112 github.com199.232.28.133 raw.githubusercontent.com

再次执行安装命令，如果还不行的话，就在weget后加-no-check-certificate，原因是wget在使用HTTPS协议时，默认会去验证网站的证书，而这个证书验证经常会失败。






然后就安装成功了，使用sigit命令启动控制台即可。

卸载
