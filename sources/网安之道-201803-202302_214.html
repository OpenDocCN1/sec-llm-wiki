Kali Linux切换python版本

随着python3.X的普及，在Kali linux安装完python3后，因为有些软件不支持python3，是经常报错的。所以找了一个比较简便的办法。安装两个版本，如果软件报错就切换到另一个python版本上，这样的话使用起来也是比较方便。




01

打开终端分别输入下面两条命令


update-alternatives --install /usr/bin/python /usr/bin/python2 100
update-alternatives --install /usr/bin/python /sur/bin/python3 150




02

打开终端输入


python --version



03

如果需要切换python版本则输入：

update-alternatives --config python



04

最后选择需要的python版本输入序号即可。


update-alternatives --config python (选择序号)
