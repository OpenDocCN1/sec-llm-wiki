四、测试：

1、开两个终端窗口，一个ssh连上服务器，另一个用错误的密码连接服务器几次。

很快，服务器上黑名单文件里已经有记录了：  

```

```

再看看服务器上的hosts.deny  

```
[root@ ~]# cat /etc/hosts.deny

sshd:13.7.3.6:deny
```

2、从另一个终端窗口继续“暴力”连接服务器。

看看服务器上的黑名单文件：  

```
[root@ ~]# /var/log/sshlogin.log
13.26.21.27=6
```

再看看服务器上的hosts.deny  

```
[root@ ~]# cat /etc/hosts.deny

sshd:13.7.3.6:deny
```

IP 已经被加入到服务器的hosts.deny，再用正确的密码连接服务器，被拒绝：  

```
$ ssh

 root@myserver.mydomain.com -p 2333ange_identification: Connection closed by remote host
```
