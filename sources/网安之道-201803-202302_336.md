**简介**  

sqlmap是一个自动化的SQL注入工具，其主要功能是扫描，发现并利用给定的URL的SQL注入漏洞，目前支持的数据库是MySQL, Oracle, PostgreSQL, Microsoft SQL Server, Microsoft Access, IBM DB2, SQLite, Firebird, Sybase和SAP MaxDB。采用五种独特的SQL注入技术，分别是：

1）基于布尔的盲注，即可以根据返回页面判断条件真假的注入。

2）基于时间的盲注，即不能根据页面返回内容判断任何信息，用条件语句查看时间延迟语句是否执行（即页面返回时间是否增加）来判断。

3）基于报错注入，即页面会返回错误信息，或者把注入的语句的结果直接返回在页面中。

4）联合查询注入，可以使用union的情况下的注入。

5）堆查询注入，可以同时执行多条语句的执行时的注入。

**0x01****准备工作**

安装sqlmap需要用到python的2.7版本，目前sqlmap支持的python不高。先去官网下载zip文件，下载好后解压。

![](../Images/d775462e876cbb22407dca49ef859d0f.png)

接着去python官网下载python2.7版本，同样解压。

![](../Images/7b89c4eef555fa77c84f80e85e408276.png)

解压完成后按照老规矩开始设置环境变量。“Path”下面的变量值后面跟python的安装目录就行。

![](../Images/ca12710a3a5c5130bca84762bb78f2e7.png)

调出cmd输入“python”回车，如果返回结果如下图所示则代表安装成功。

![](../Images/24df20003885913149b86f579e79571a.png)

**0****x02****开始安装s****qlmap**

把下载好的sqlmap文件全部复制到python的所在目录下。

![](../Images/58dcc7927610a9109364dfcc84d693f7.png)

在桌面创建一个快捷方式，这里写“cmd”。单击下一步。

![](../Images/f4cc9b2b12d621ff3dda562a25ef1eed.png)

快捷方式命名为“sqlmap”点击完成。

![](../Images/845815fd7504e4639e2af2f10bd76202.png)

右键刚刚创建的sqlmap快捷方式找到“属性。这里将起始位置修改为“C:\\Python27\\sqlmap”然后改完自己喜欢的颜色等，单击完成。

![](../Images/a48aa55159f94777b2a10406ce40b8a6.png)

打开刚刚的快捷方式输入“sqlmap.py -h”若返回结果如下图所示则安装成功。

![](../Images/0f94d1126f2572e442eb804ffd29e7e6.png)
