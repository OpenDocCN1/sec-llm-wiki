解决Kali Linux最新版本2019.4中文乱码的问题

1. 找到国内源，我这里用的是阿里源

deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

deb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

2. 打开终端输入vi /etc/apt/sources.list回车

3.回车之后按“O”键把阿里源放进去，按“Esc”退出

4.退出后输入“：”按“W”进行保存，然后再按“：”输入“Q”退出

5.输入命令“apt-get update”回车并对源进行更新。

6.输入命令“apt upgrade”回车

7.我这里是Y更新一下

8.耐心等待更新完成之后在命令行输入“dpkg-reconfigure locales”，进入图形化界面后找到“en_US.UTF8”用空格选中

9.再找到“zh_CN.UTF8”空格选中，然后回车到选择界面找到“en_US.UTF8”回车设置默认

10.回车之后将会返回到这个页面，安装中文字体：“apt-get install xfonts-intl-chinese”

11. 上一个安装完成之后再安装这个“apt-get install ttf-wqy-microhei”

12.安装完成后输入“reboot”重启

13.我们看到这个界面安装之前是乱码，现在已经显示字体了。登录进入

14.中文乱码问题解决了~
