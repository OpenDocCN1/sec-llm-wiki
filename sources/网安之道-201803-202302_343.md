# 解决Kali Linux最新版本2019.4中文乱码的问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMDI2ODM1OA==&mid=2651495418&idx=1&sn=af3ab3a263203bae081b368a9117e709&chksm=8c990253bbee8b45340672605208bb3f6acbb7498803b385e64139fa902206a9d348e4f15046&scene=126&sessionid=1681665484#rd](http://mp.weixin.qq.com/s?__biz=MzIxMDI2ODM1OA==&mid=2651495418&idx=1&sn=af3ab3a263203bae081b368a9117e709&chksm=8c990253bbee8b45340672605208bb3f6acbb7498803b385e64139fa902206a9d348e4f15046&scene=126&sessionid=1681665484#rd)

![](../Images/50dc5e6f1593ef387d21aa9eee47562f.png)1. 找到国内源，我这里用的是阿里源

deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

deb\-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

2. 打开终端输入vi /etc/apt/sources.list回车

![](../Images/f56d8ea36f7e93888846a519564b8ca3.png)

3.回车之后按“O”键把阿里源放进去，按“Esc”退出

![](../Images/3a66eeeeedf6d944f1dd1e66396120bf.png)

4.退出后输入“：”按“W”进行保存，然后再按“：”输入“Q”退出

![](../Images/912e8638fb9745dc71a28287574c3f15.png)

5.输入命令“apt-get update”回车并对源进行更新。

![](../Images/f1a333e3aea9e03cd2fb0d41b7fb75bd.png)

6.输入命令“apt upgrade”回车

![](../Images/9559b46f587a0fe0829122e36ec24124.png)

7.我这里是Y更新一下

![](../Images/0de05dcdbcf46a5000f984c71d738ba7.png)

8.耐心等待更新完成之后在命令行输入“dpkg-reconfigure locales”，进入图形化界面后找到“en\_US.UTF8”用空格选中

![](../Images/897cbb810e4e03f3774e0e282da94b00.png)

9.再找到“zh\_CN.UTF8”空格选中，然后回车到选择界面找到“en\_US.UTF8”回车设置默认

![](../Images/337d12f74eab37b1d948a1c8e0ee99a4.png)

10.回车之后将会返回到这个页面，安装中文字体：“apt-get install xfonts-intl-chinese”

![](../Images/e14561a54743c0d195b270dea45ae309.png)

11\. 上一个安装完成之后再安装这个“apt-get install ttf-wqy-microhei”

![](../Images/6a82ceb242c85440ac98058431451a71.png)

12.安装完成后输入“reboot”重启

![](../Images/6079a252edbad020441614569fa65c7d.png)

13.我们看到这个界面安装之前是乱码，现在已经显示字体了。登录进入

![](../Images/89d0f475c22649803925e93c29f1167b.png)

14.中文乱码问题解决了~

![](../Images/50a9c558ebf4c3b3ae7f5fc53941e8dc.png)
