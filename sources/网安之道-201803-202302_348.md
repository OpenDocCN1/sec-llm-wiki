# 在VMware Workstation中安装Windows7系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMDI2ODM1OA==&mid=2651495312&idx=1&sn=629c2c07f43f339445613f45f51c475d&chksm=8c990239bbee8b2f55d3c471bcb918fb9c3d2b3d7acb637a1cef4700f5f8fab5f7aa0a771dd0&scene=126&sessionid=1681665484#rd](http://mp.weixin.qq.com/s?__biz=MzIxMDI2ODM1OA==&mid=2651495312&idx=1&sn=629c2c07f43f339445613f45f51c475d&chksm=8c990239bbee8b2f55d3c471bcb918fb9c3d2b3d7acb637a1cef4700f5f8fab5f7aa0a771dd0&scene=126&sessionid=1681665484#rd)

之前我们介绍了VMware的作用、特点以及VMware的安装，今天我们给大家带来的是在VMware Workstation中安装Windows7的系统。

首先，我们要下载Windows7的一个.iso镜像文件。在微信公众号回复“Win7”下载。

下载好Windows7的镜像文件以后

双击VMware打开，选择“创建新的虚拟机”

![](../Images/184389b3265cf4faabb3dc9542831002.png)

选择“典型”

![](../Images/ad1fec0e507d639e473216a1439434b4.png)

选择“安装程序光盘映像文件”或“稍后安装操作系统”这里选择的是安装程序光盘映像文件，注意选择“安装程序光盘映像文件”时浏览Windows7存放的位置

![](../Images/d52cba9c99b7fe19463853ba77fee439.png)

这里输入Windows7旗舰版的激活密钥。在公众号回复“win7密钥”即可获得。

![](../Images/c06b9910b21e325491604d8ec03bca69.png)

“要安装的Windows版本”选择“Windows7 Ultimate”

![](../Images/c06b9910b21e325491604d8ec03bca69.png)

这里个性化设置看自己的喜好

![](../Images/4863e235b1f1bed08435853535f72ca7.png)

虚拟机名称自定义就行

![](../Images/8f316b77fe65db6b6e0561ec55d36040.png)

磁盘大小默认60GB根据个人电脑实际情况做调整，然后点击下一步

![](../Images/d68701b253b8c6960af65ae74f48c5dc.png)

完成了虚拟机的创建，点击完成。

![](../Images/e43f394b5c192ca407416e63b1c3e08c.png)

到这个步骤就是操作正确

![](../Images/dceafa70be8ac9154267475cb024219f.png)

这里是简易安装的步骤

![](../Images/ca6c2439206eebaf95e00f7e8a6a19ba.png)

到这个界面，安装程序正在启动

![](../Images/1869b4c33fce99a64c615120b3611acb.png)

正在安装

![](../Images/8325b286c3613b377dbf671a18bfb87d.png)

正在准备桌面

![](../Images/bb926faf5557f51de1d85660867381fe.png)

自动安装VMware Tools

![](../Images/96cde163956e6d7e0f8b0e80630f763f.png)

安装Windows7旗舰版成功

![](../Images/423d6b789fb16bea745a87c0f03c14db.png)

最后调节到适当的分辨率即可

![](../Images/5f224302d7fe55a197e2eca4be3cc082.png)
