# 【活动预告】本周四（27日）中国电子信息技术年会专题论坛三：大数据驱动的网络安全研究与实战

　　4月27日，一年一度的中国电子信息技术年会将在石家庄盛大开幕。本次年会以“信息科技驱动智能产业，引领京津冀协同发展”为主题，主论坛加六大专题论坛，来自信息科技领域的院士专家、行业大咖和技术大牛们将就这些引人关注的话题进行深入剖析探讨，一场超乎想象的信息科技高端学术交流与火花碰撞即将呈现。  

　　

　　其中，由中国电子学会主办，清华大学承办、InForSec网安国际学术论坛协办的专题论坛三，主题为“大数据驱动的网络安全研究与实战”，将邀请清华大学、东南大学、百度、360等学术界和业界的专家，就网络地下产业检测、APT攻击检测、软件定义网络安全、DNS域名系统异常检测等展开研讨。

　　

　　届时，清华大学教授段海新将带来“基于黑帽搜索引擎优化检测网络地下产业”的专题研讨；东南大学网络空间学院执行院长程光教授将分享“基于TCP和DNS流量特征的APT攻击检测”的先进技术；百度Web安全产品总经理刘焱将带来“骨干网大规模DDoS智能检测与对抗”的研究成果；360公司侯曼将带来“Domain Prank在DNS异常检测上的应用和分析”的技术分享；清华大学深圳研究生院李琦教授将分享“软件定义网络中的安全威胁”的专题研讨。

嘉宾介绍

  

　　1、演讲嘉宾：段海新  清华大学网络科学与网络空间研究院研究员

　　

![](../Images/60c06c16e609afd7b7e35039971256aa.png)

　　段海新，工学博士，现任清华大学网络科学与网络空间研究院研究员，网络与信息安全实验室主任。长期从事网络安全研究和教学，在国际网络和系统安全四大顶级学术会议上发表多篇论文，并获NDSS 2016年“杰出论文奖”。2016年获国家网信办组织的首届“网络安全优秀人才”奖。 他近年的主要研究方向包括网络基础设施安全、地下产业监测。段海新教授是著名的 “蓝莲花战队”联合创始人，他的学生多次在国际著名的网络安全竞赛中名列前茅。另外，段海新作为联合发起人组织了网络安全研究国际学术论坛InForSec，在国内外安全学术和工业圈具有重要影响。

　　

　　2、演讲嘉宾：程光  东南大学计算机科学与工程学院教授

　　

![](../Images/85190290b3f41f6a2524e0ae96450ada.png)

　　程光，东南大学计算机科学与工程学院教授、博士生导师、工学博士， 现任网络空间安全学院常务副院长，计算机网络和信息集成教育部（东南大学）重点实验室主任，东南大学计算机科学与工程学院、软件学院党委书记。2005-2006年期间在美国佐治亚理工大学从事博士后研究，分别于2012年在美国亚利桑那大学和2016年期间在美国德州奥斯汀分校从事高级访问学者研究工作。在科研方面，主要在SDN网络测量与管理、网络流量测量与大数据分析、 僵尸网络和APT攻击检测等领域进行了理论探索性与应用研究。近5年主持国家省部级纵向科研项目10余项， 已发表学术论文100余篇。已出版专著5部。

　　

　　3、刘焱  百度Web安全产品总经理

　　

![](../Images/691bb498a2367bd8db9280f046c97c2e.png)

　　刘焱，百度公司Web安全产品线负责人，负责抗DDoS产品、web应用防火墙、高级web威胁感知、服务器安全产品，大数据安全专家，具有十年云安全产品经验，主要研究方向为机器学习、僵尸网络、威胁情报、沙箱技术，全程参与了百度公司内部安全的防护与监控体系建设，具有多年企业安全建设经验。  

　　

　　4、侯 曼  360公司数据安全分析工程师

　　

![](../Images/73b8667bc851e0b16389357a847409d6.png)

　　侯曼， 360公司数据安全分析工程师，当前主要研究方向为大数据安全威胁情报分析。研究生期间，开始从事Passive DNS系统开发和DNS数据安全分析工作。目前，基于Passive DNS系统做反钓鱼欺诈与域名异常检测方面的研究和系统研发。

　　

　　5、李琦  清华大学深圳研究生院副研究员

　　

![](../Images/d55d28ca50777fe596098c162ce5f62d.png)

　　李琦毕业清华大学计算机科学与技术专业获得工学博士，目前为清华大学深圳研究生院副研究员，曾经在苏黎世联邦理工学院，美国德州大学和中国科学院等单位从事网络安全研究和教学工作，研究兴趣包括互联网和云安全、移动安全以及大数据安全。目前发表70多篇论文，包括IEEE/ACM汇刊等顶级期刊和IEEE ICDCS、IEEE DSN、RAID等重要国际会议论文。目前他是安全期刊IEEE TDSC编委，并担任IEEE ICDCS等多个国际会议的程序委员会委员。
