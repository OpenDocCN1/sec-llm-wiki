# 数据保护官（DPO）沙龙第十一期报名开始

数据保护官（DPO）沙龙已经办了十期，针对各项热点如国内外立法，展开了热烈、富有建设性的研讨。**本期沙龙将重点讨论“网络与数据安全防护”这个新话题。**法律、法规、标准要求的落地，需要企业管理和技术措施并举，此次沙龙聚焦网络与数据安全方面的技术措施和方案。**感谢中国信息通信研究院安全所为此次线下沙龙提供场地和会务支持。**

 

**为何选择这个主题？**

在欧美的数据保护或个人信息保护相关法律中，对数据安全的规定通常只有寥寥数笔。例如，在欧盟GDPR中，只有第32条“处理过程的安全性”涉及了采用适当的技术性和组织性措施保护个人数据安全的内容。

  

这种情况在国标《个人信息安全规范》中也同样存在，未对如何保护数据机密性、完整性、可用性进行内容展开，可能的原因是数据安全的背后是由已经相对成熟网络安全技术体系作为支撑的，不必赘述。

  

但是，对于非网络安全专业人士，对这套技术体系并不熟悉。**因此，本期沙龙选择了“网络与数据安全防护”这个主题，通过讲解和讨论，帮助沙龙成员了解网络安全的基本概念和理论方法，从技术层面理解网络安全与数据安全的关系。**

 

**讨论将如何进行？**

 

现场流程：

1.  主持人开场；
    
2.  信通院安全所专家主题分享；
    
3.  知名安全企业专家主题分享；  
    
4.   沙龙成员讨论及分享。
