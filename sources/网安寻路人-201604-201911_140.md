# 数据保护官（DPO）沙龙第六期报名开始

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxODM0NDU4MQ==&mid=2247485804&idx=1&sn=5d62fb1aed7097ebefa17e3cd6156725&chksm=97eab486a09d3d9045de64b9760a1d7c4420131ed746b45cd4cc36f193b60364c66e674cc239&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxODM0NDU4MQ==&mid=2247485804&idx=1&sn=5d62fb1aed7097ebefa17e3cd6156725&chksm=97eab486a09d3d9045de64b9760a1d7c4420131ed746b45cd4cc36f193b60364c66e674cc239&scene=27#wechat_redirect)

第六期数据保护官（DPO）沙龙将重点**就“2018年隐私条款专项工作评审要点”中的相关内容以及企业实践案例**进行讨论。非常感谢中国电子技术标准化研究院承办此次沙龙。

  

**为什么选择这个主题**

  

2017年7月，在《网络安全法》生效之际，中央网信办、工信部、公安部、国家标准委等四部门为确保网络安全法中个人信息保护相关要求有效实施，提升网络运营者个人信息保护水平，启动隐私条款专项工作。首批对微信、新浪微博、淘宝、京东商城、支付宝、高德地图、百度地图、滴滴、航旅纵横、携程网等十款网络产品和服务的隐私条款进行评审，形成了良好的社会示范效应，带动行业整体个人信息保护水平的提升。

  

2018年9月，在《网络安全法》实施一年后，第二期隐私条款专项工作启动。第二期专项工作按照《网络安全法》等法律法规中关于个人信息保护的要求，依据国家标准GB/T35273-2017《信息安全技术 个人信息安全规范》，**选取与民众日常生活紧密相关、具有较大用户数量的出行旅游类、生活服务类、影视娱乐类、工具资讯类和网络支付类5类30款网络产品，对其隐私政策进行评审，以提升企业个人信息保护水平**。

  

本次数据保护官（DPO）沙龙拟**在评审要点中选取企业普遍关心的若干要点进行探讨。重点关注网络产品与服务功能区分；告知定向推送活动规则；告知个人信息保存期限等话题。**

  

**讨论将如何进行**

  

1.  主持人开场；
    
2.  隐私条款评审调研组代表引出企业关心的话题；
    
3.  沙龙成员讨论及分享。
    

 

**如何报名本期沙龙？**

活动时间：2018年11月23日（周五）上午9点-下午5点

活动地点：中国电子技术标准化研究院1号楼第二会议室（北京市东城区安定门东大街1号）

人数限制：限40人以内，满额为止。**请凭参会确认参加本期沙龙。**
