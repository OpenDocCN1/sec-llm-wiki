# 数据流通障碍初探——以四个场景为例

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxODM0NDU4MQ==&mid=2247484607&idx=1&sn=e207177ef805ee22eb1f0965f01ac6c0&chksm=97eab955a09d30431b262d8ad563d43dbc0057317ca328b46ef2d8db4873544eaf989d224e0e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIxODM0NDU4MQ==&mid=2247484607&idx=1&sn=e207177ef805ee22eb1f0965f01ac6c0&chksm=97eab955a09d30431b262d8ad563d43dbc0057317ca328b46ef2d8db4873544eaf989d224e0e&scene=27#wechat_redirect)

中共中央政治局12月8日下午就实施国家大数据战略进行第二次集体学习。总书记做了如下强调：

  

推动实施**国家大数据战略**，加快完善数字基础设施，推进数据资源整合和开放共享，保障数据安全，加快建设**数字中国**，更好服务我国经济社会发展和人民生活改善。

  

1.  推动大数据技术产业创新发展：构建**自主可控的大数据产业链、价值链和生态系统**；
    
2.  构建以数据为关键要素的数字经济：发挥数据的**基础资源作用和创新引擎作用**；
    
3.  运用大数据提升国家治理现代化水平：建立健全**大数据辅助科学决策和社会治理**的机制；
    
4.  运用大数据促进保障和改善民生：利用大数据**强化民生服务，弥补民生短板**；
    
5.  切实保障国家数据安全：强化**国家关键数据资源保护能力**。
    

  

可以看到，五点要求中有四方面都是**强调数据要用起来**。而用起来的前提，就是能够**数据能够流动和共享**。总书记就此强调如下：

  

1.  以数据集中和共享为途径，推动技术融合、业务融合、数据融合，打通信息壁垒，形成覆盖全国、统筹利用、统一接入的**数据共享大平台**，构建全国信息资源共享体系；
    
2.  要加强政企合作、多方参与，加快公共服务领域数据集中和共享，**推进同企业积累的社会数据进行平台对接**；
    
3.  要制定**数据资源确权、开放、流通、交易相关制度**，完善**数据产权保护制度**。  
    

  

第1点是强调公共部门内部数据要打通，第2点是强调公私部门数据要打通，第3点则是强调在私营部门中，通过市场路径，来促进数据流通和共享。
