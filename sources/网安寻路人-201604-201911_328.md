# 个人信息保护标准的路径选择

2016年第二届中国互联网安全领袖峰会（Cyber Security Summit）的**网络安全标准化论坛**，由中国电子技术标准化研究院具体承办。对于网络安全国家标准，论坛给出了非常精准、生动的定位：“没有标准规范的安全防护，就像没有靶心的箭靶，容易无的放矢。没有标准规范的安全生态，就像没有罗盘的轮船，容易迷失方向。网络安全国家标准是国家利益和意志的体现，将在网络治理中发挥基础性、规范性、引领性作用。”

**【背景介绍】**  

  

中国互联网安全领袖峰会(Cyber Security Summit，简称CSS)由腾讯公司、中国电子技术标准化研究院等企事业单位共同创办，得到了国家网信办、工信部、公安部等国家部门的大力支持和指导。中国互联网安全领袖峰会始终致力于聚合互联网产业领域与网络安全行业的力量，共筑“互联网产业安全交流与合作平台”，共建“互联网安全新生态”，进而推进产业快速、稳定创新，为国民经济的升级转型和蓬勃发展做出贡献。
