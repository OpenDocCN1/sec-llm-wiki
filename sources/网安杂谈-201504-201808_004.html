是真的吗？

这两天GSM嗅探突然刷屏了，很多同行在问这是真的吗，然后晚上关机管用吗？其实终结诈骗公众号在六月份就刊登了分析文章，恐怖！诈骗界“核武器”来袭！骗子可劫持手机短信盗刷银行卡，多人损失惨重！（点击阅读）予以警示。

针对这类案件，警方也及时进行了的打击。广州、郑州、南京等地相继发布了案情通报。

下面是郑州警方通报：劫持短信就能刷爆你的卡 嫌犯已被警方抓获

据嫌疑人交代，"2G 短信采集设备 " 是由电源 ( 银色金属方盒 ) 、手机号码采集器、一根黑色天线组成，某品牌手机来接受采集到的号码。"2G 嗅探设备 " 是由黄色木盒 ( 内置 7 个来拦截附近短信的某 c118 主板 ) 、一台笔记本电脑，笔记本上面插又一个 U 盘装置的嗅探系统组成。

据了解，嫌疑人先是用某品牌手机在骨科医院的走廊内来回测试频点，和电脑上相符，再把匹配的手机频点输入到电脑上，进行连接，测试附近的手机。检测到附近有针对的移动用户后，用手机测试采集到附近方圆 500 米的移动手机号码，通过发送垃圾短信的方式看看哪个手机号可被 " 劫持 " 接收到短信，从而后面可以进行盗刷这个手机机主银行卡和信用卡的钱。

一位民警透露说，因为用户短信里有包括验证码在内的很多敏感信息。不少 APP 只要输入 " 姓名 + 银行卡账号 + 身份证号码 + 手机号码 + 动态验证码 "，就默认是本人操作，骗子进入以后马上就会盗刷或者购买点卡类虚拟物品。

没法防范？

全国信息安全标准化技术委员会2018年2月11日发布的《网络安全实践指南——应对截获短信验证码实施网络身份假冒攻击的技术指引》，通过启动短信上行验证、启用语音通话传输验证码、对常用设备开展绑定、运用生物识别技术开展验证等，做好安全策略升级工作。

这事从根上说需要做到：

1.2G网络的尽快退网，

2.各家服务商要启用多因素验证，绝不能一个验证码打天下

3.用户自己防范例如通过飞行模式关机等方式只能是治标不治本。

4.及时报警，如果在这个标准出台后，还发生了类似盗刷的情况，我认为完全可以去告他们。


技术原理

前面已经提到，短信嗅探技术14年就已经出现，只是没有被黑产团伙大量应用，看下图是国内某黑客圈子技术交流活动的宣传材料，可见技术确实是双刃剑。这一武器掌握在黑产手中就是灾难。


嗅探装置价格低廉，很容易买到，一般几百块钱就可以配一套。一般使用摩托罗拉C118手机主板、天线、串口模块改装成嗅探设备。
