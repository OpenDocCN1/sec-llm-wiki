事情要从几天前一位安全界一位德高望重的大大牛朋友圈发的一张截图说起。当然这位大牛的打码水平有点低。你能看出是谁吗？（提示下，这个是大牛的真名，大牛的ID是h开头）。


这又是典型的钓鱼短信，链接点开是一个安卓木马apk文件，一旦安装就会发生可怕的事情。具体怎么可怕呢,请参加相关报道。

回到这条钓鱼短信上来，好奇到底是一个什么样的木马呢？仔细看那个被打码链接。



仔细分辨加猜测，大概能猜到完整链接应为：qal*.com/pig。大牛抹掉的应该是两到三个字母。用PS处理效果也不怎么理想，仍然猜不出来到底是什么。仔细辨认意思仿佛有m之类的字母。


根据这个字体的外观特性，大牛这样涂抹是不能完全盖住q,l,g这样的字母的。我们猜需要补齐的字母只可能是：a,c,e,m,n,o,r,s,u,v,w,x,z，两到三个字母的组合轮番实验一下，应该就可以找到真实的url了。因为猜测里面可能有m，那就先假设缺失的字母是两个。

排列可以借助Python中的itertools模块。

List(itertools.permutations(‘a,c,e,m,n,o,r,s,u,v,w,x,z’,2))结果为

[(a,c),(a,e),(a,m)……,(c,a),(c,e),(c,m)……]（ps:这次没有考虑两个字母重复的情况）

 

通过对木马钓鱼链接站点特征的观察发现：

1.有的钓鱼链接站点会判断user_agent,限制非移动端的访问，所以设置headers参数。

2. 很多钓鱼网站会设置跳转，设置的方法一般有：

方法一：Html head头指令跳转

例：

<html>

<head>

<meta http-equiv="Content-Language"content="zh-CN">

<metaHTTP-EQUIV="Content-Type" CONTENT="text/html;charset=gb2312">

<meta http-equiv="refresh" content="0.1;url=录像Mz21.apk">

<title></title>

</head>

<body>

</body>

</html>

方法二：JS跳转

 例：

<!DOCTYPE html PUBLIC"-//W3C//DTD XHTML 1.0 Transitional//EN""http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

<htmlxmlns="http://www.w3.org/1999/xhtml">

<meta name="apple-mobile-web-app-capable"content="yes">

<meta name="viewport"content="width=device-width, minimum-scale=1.0,maximum-scale=1.0,user-scalable=no">

<title> ==</title>

</head>

<body>

 <script>location.href='相片.apk';</script>

 </body>

</html>

这两种情况下url的HTTP状态码都是200    

PS:跳转时的HTTP的状态码一般为200，301，302： 

200 正常状态

301 永久性转移(Permanently Moved)

302 暂时性转移(Temporarily Moved)

状态码200的跳转： 

<meta http-equiv="refresh" content="3; URL=default.aspx" /> 

Server.Transfer("default.aspx"); 

URLRewrite－－严格来说，这个不算是跳转，只是一种URL“欺骗” 

JS

状态码302的跳转： 

Response.Redirect("default.aspx");  

状态301的跳转： 

Response.Status = "301 Moved Permanently";

Response.AddHeader("Location", http://www.XXX.com);  

 

结合木马钓鱼链接站点特定，为了猜测大神收到的钓鱼链接，简单脚本如下：

import requests

import re

import itertools

urllist=list(itertools.permutations('acemnorsuvwxz',2))

headers={'User-Agent':'Mozilla/5.0(Linux; U; Android 4.0.3; zh-cn; U8817 Build/MocorDroid4.0.3) AppleWebKit/533.1(KHTML, like Gecko) Version/4.0 Mobile Safari/533.1'}

for m in urllist:

    url="http://qal"+"".join(m)+".com/pig/"

    printurl

    try:

      r=requests.get(url,headers=headers,allow_redirects=False)

       print r.status_code

       f=open('list.txt','a')

       lst=[url,'\n',str(r.status_code),'\n']

       f.writelines(lst)

       f.close()

    except:

        continue

依次验证各个返回值200的链接,我们终于找到了大牛短信里的链接就是http://qalmw.com/pig/ 并顺利下载到名为相片.apk的木马样本。WHOIS信息关联还能找到其他关联域名。


还可通过对木马样本本身的分析来扩展线索。网上已有很多相关分析，这里不再赘述。

后续：

因为整个分析的过程搞了好多天，当我再次访问http://qalmw.com/pig/的时候发现木马已无法下载。访问http://qalmw.com/提示 Directory Listing Denied，站点还活着，猜测是站点管理人员调整了钓鱼链接。

那我们可以把前面的脚本略做修改，尝试爆破下url（类似这种http://qalmw.com/xxx）。可惜尝试了所有3,4位小写字母组合也没有结果。

但在跟踪另一样本的过程中，发现103.*.*.20/ Yiop这一url，根据其命名规律，爆破出103.*.*.20/Zxcv、103.*.*.20/Ping、103.*.*.20/Admin、103.*.*.20/Xiaor等多个url，证明思路还是可行的。
