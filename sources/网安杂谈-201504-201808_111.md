# 解决Genymotion出现Unable to load VirtualBox engine错误

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTMzMDUwNg==&mid=2650878684&idx=1&sn=80ddbaaaae2cee4bedb352e3cbbc2ab0&chksm=812ecef9b65947efa94be54085cb516d0fd3b380d714c31751fd2cf947e305d744854e818e6d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTMzMDUwNg==&mid=2650878684&idx=1&sn=80ddbaaaae2cee4bedb352e3cbbc2ab0&chksm=812ecef9b65947efa94be54085cb516d0fd3b380d714c31751fd2cf947e305d744854e818e6d&scene=27#wechat_redirect)

从升级了Genymotion后，突然出现这个问题，一下摸不到头脑。搜索了下网上出现这个问题的还有很多，后来终于解决了。。。

  

我的系统是win7 64位

解决方法很简单：

右键-->VirtualBox-->属性-->兼容性-->(打钩)以兼容模式运行这个程序-->(选择)Windows vista-->应用-->确定  
右键-->Genymotion-->属性-->兼容性-->(打钩)以兼容模式运行这个程序-->(选择)Windows vista-->应用-->确定
