# 安卓拦截马分析方法釜底抽薪之抓包

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTMzMDUwNg==&mid=403145872&idx=1&sn=57f7bb4adf6751b0edaa875b2d40e282&chksm=072878b5305ff1a3cf483bb0daff3969f67b7c0275c85be2104086fb0145e69b58ebd13eef6e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTMzMDUwNg==&mid=403145872&idx=1&sn=57f7bb4adf6751b0edaa875b2d40e282&chksm=072878b5305ff1a3cf483bb0daff3969f67b7c0275c85be2104086fb0145e69b58ebd13eef6e&scene=27#wechat_redirect)

由于目前流行的安卓拦截马一般具备回传短信、通讯录、发送远程指令等功能，其中具有木马所有者邮箱、手机等信息。为了对抗反编译，一般通过加密关键信息、加壳、利用库文件等手段防止对抗反编译，分析的难度进一步加大。如果安卓拦截马具有通过邮箱回传数据的功能，可以直接通过釜底抽薪的分析方法，那就是抓包分析。

推荐组合工具：Genymotion（或其他模拟器）+wireshark(或其他抓包工具)

0x01 Genymotion可能遇到的问题

Genymotion功能强大，速度快，确实是神器。但在分析木马的过程中发现可能存在几个问题：

a.INSTALL\_FAILED\_INVALID\_URI报错

 

![](../Images/2adc69484b0f5ea97e96137d465b27f7.png)  

查了一下，原因是部署一个文件安装路径错误没找到，原因是因为Genymotion没有汉化处理，如果把Genymotion安装在中文目录，或者配置Genymotion的时候使用了中文，或者apk的文件名是中文，都会出现报错的现象。排除掉这几点原因，一般就可以了。

b. Installation error: INSTALL\_FAILED\_CPU\_ABI\_INCOMPATIBLE

出现这个错误的原因是Genymotion默认的处理器是x86的，不是arm。需要进行转换。

解决方法是下载Genymotion-ARM-Translation.zip（http://pan.baidu.com/s/1h7yPD），下载好的压缩文件不要解压缩，直接用鼠标拖到Genymotion模拟器中，然后重启模拟器。

0x02 抓包过程 

a.开启wireshark 等待抓包。

b.将木马程序直接拖到Genymotion中，这点确实很方便。

c.分析数据包

因为发送邮件通过smtp协议发送，只需要设置wireshark过滤条件为tcp.port==25，就可以过滤拦截马回传信息的过程，邮箱的账号，密码都是经过base64编码的，解码即可。
