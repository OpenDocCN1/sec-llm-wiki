# 取证

## 2019级 Marmalade | 从一道题目学习手动仿真

### **\[2021年祥云杯\]层层取证**

想从该题为例进行一下手动仿真的学习

下载得到memdump.mem和Forensic\_image.001-009

前者为内存镜像，后者在查看txt内容看到是使用AccessData FTK Imager生成的硬盘镜像

![](../Images/59ab40de4e453206f87d61bbcab3286e.png)

取证比赛结束后授权过期了，于是考虑手动仿真

![](../Images/c39bda6096cf4c67ea27155139682f86.png)

手动仿真有两种方法，第一种是先挂载到本地磁盘再用vmware仿真

#### **方法一**

##### **一.FTK IMAGER 挂载镜像到本地**

使用FTK Imager“可写”模式，挂载系统镜像到本地驱动器

###### **1.选择 IMAGER MOUNTING**

![](../Images/bef32c31ecc0915e5a2acace6c10a33b.png)

###### **2.选择系统镜像挂载**

```







1）选择需要挂载的镜像文件;
```

mount成功后，会在本地磁盘显示出新的分区，可以打开Windows资源管理器查看，以及默认在镜像位置新生成一个后缀为“.adcf”的镜像同名文件，用来存放可写模式下镜像虚拟写入的文件。

![](../Images/503f8f83b9a3d7b0f4ad8bc2fc590a69.png)![](../Images/9775dd89a93e9b981ba7ddf1139bc5b5.png)

点击mount挂载后就会将镜像挂载到本地

![](../Images/6105934fbb14bdaaf968f35ba8878c35.png)

##### **二.VMWARE新建虚拟机导入本地磁盘**

可参考博文https://www.freesion.com/article/51701409948/#DDE01\_8的第二部创建虚拟机

经过内存镜像分析可得该镜像为为win7 64位系统

![](../Images/fbc9fa0f6ca92692a7fde41a680a97e0.png)

选择使用物理磁盘，找到FTK Imager挂载的驱动器号

![](../Images/90d96f6cdcc59911048a6ae020e20be9.png)![](../Images/a84e02e7b633ab856f52e8808ea78483.png)

可是使用vmware启动却一直报错已被占用，经百度查询无法解决。。。于是采用另一种仿真方法

![](../Images/1dc59758bdcde67224df2a238f14932c.png)

#### **方法二：制作镜像为vmdk然后再仿真**

##### **一.FTK里将Forensic\_image导出为img文件，输出到本地**

![](../Images/1dd87b0bed48dd0222b57a767b2d08b7.png)

选image File

![](../Images/08cfc69f255e7bfb3cace1be74476b73.png)

将Forensic\_image.001文件导入然后点击finish，之后

![](../Images/4f66bbf33b7c8d690c24ff9997b06865.png)

点击下一步，选择输出的文件夹和文件名，注意下方改为0

![](../Images/46ec57e19e2b1fcf8455518bb41bb6e8.png)

提取镜像后改后缀名为img即可

##### **二.使用V2V\_Converter工具输出为vmdk文件**

打开V2V\_Converter，导入.img文件，之后全选默认即可

![](../Images/54e056991fa19b966cfefe85475bef31.png)

##### **三.vmware新建虚拟机，导入vmdk文件**

和方法一新建虚拟机步骤相似，只是在下面的一步选择使用现有磁盘

![](../Images/e79cd1ea2fd1e29f99deef6be53e65bb.png)

接着启动虚拟机就可以了

![](../Images/d087eca4621c094e2cab0d551d4c4fce.png)

我们接着回到本题，用取证大师加载一下，发现有一个磁盘采用了bitlocker加密

![](../Images/056942dd6fc7b0c891df50438b9f4dbf.png)

使用efdd工具可以通过内存镜像破解bitlocker加密的磁盘

![](../Images/ae0e4674d3d6f8207cd95df9360f17f1.png)

恢复出key了

![](../Images/13b27246b2068511dbd1188c755c1705.png)

用该key在取证大师bitlocker用恢复密钥串可解密该磁盘，看到该盘下有一个流量包

![](../Images/ed3a5122813fb1aef0732a310dc2d354.png)

导出分析一下

追踪udp流里找到一个rar，里面包含了一个flag.docx

![](../Images/521fbd9e1e160c70993efa56b3d05874.png)

导出rar压缩包，发现加密，且提示与计算机加密密码相同

![](../Images/a61da1aa0946b830ab464b0e7073cd48.png)

再考虑看一下用户桌面，用户XinSai的桌面只有一个wireshark安装包，不知道题目是否与流量分析有关，用户Xiaoming的桌面有一个flag.txt

![](../Images/7cf0ccd249c5205a60a12d20d051491c.png)

提示让我们仿真，猜测是windows桌面便签可能有什么信息

登录xiaoming需要密码，可以在给定的内存镜像中获取

使用passwarekit工具加载内存镜像可得

![](../Images/927243dd0053c24c635950149bcc77ee.png)

仿真进入桌面

![](../Images/e21aaa5aac2c98fe986fb924de5f3e60.png)

知道开机密码了就可以解压之前导出的压缩包

再用桌面的文档密码解密flag.doc进入可以看到flag

![](../Images/5a6dce7d08ea8d07fff191c6cf393441.png)
