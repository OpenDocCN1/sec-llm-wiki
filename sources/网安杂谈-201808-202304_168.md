# 关于征集网络安全公益课程的通知

为宣传贯彻习近平总书记关于网络强国的重要思想，更好地普及网络安全意识，现面向社会征集网络安全线上公益课程，具体通知如下：

1.  **课程发布：**征集课程将在“中国网络空间安全协会人才培养平台（试验版）”（以下简称培养平台）上发布。
    
2.  **课程类型：**此次征集课程为公益课程，面向培养平台注册用户免费开放。培养平台将展示课程提供方宣传材料，帮助打造会员单位公益形象，提高显示度。如有非公益课程希望在培养平台展示，可单独联系沟通具体情况。
    
3.  **课程内容及录课要求：**详见附件。　　
    
4.  **征集时间：**长期。
    
5.  **征集流程：**根据要求录制或选报相应课程，课程材料发送至指定邮箱；中国网络空间安全协会组织专家对课程课件进行评审；课程评审通过后在培养平台上发布，网安协会向课程提供方颁发荣誉证书。
    

联系人： 尹凤芹15201390916
