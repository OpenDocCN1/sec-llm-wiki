一、整体流程

整个流程分为两大部分

1.训练和预测生成结果：这部分就是常规的预训练模型进行训练和预测，比赛当然还需要一些改进提高预测效果。

2.通过docker提交结果：第一次参加天池的比赛，提交结果的方式是通过docker,需要安装配置好docker.

三、训练与预测流程

这次跑程序租的极客云机器，配置：GTX 1080 Ti 双卡 显存11Gx2 E5 20核 内存128G 600GB SSD + 2TB硬盘 网速D500/U100

环境配置：pytorch 1.7 装transformers

注册极客云用这个邀请码，可以省10块钱：http://www.jikecloud.net/register.html?iid=8ABG3HA7A70GgLk5lDV7VQ==

1.下载预训练模型

下载Bert模型，地址：https://huggingface.co/bert-base-chinese/tree/main
下载config.json vocab.txt pytorch_model.bin，把这三个文件放到一个文件夹如tianchi-multi-task-nlp/bert_pretrain_model下。

2. 下载比赛数据集

把数据集分别放进 tianchi-multi-task-nlp/tianchi_datasets/数据集名字/文件夹下


以OCNLI为例，下面分别放test.csv和total.csv文件

数据内容：id 句子1 句子2 标签[蕴含0，中性1，不相关2]

3. generate_data.py拆分数据

主要功能是把total.csv文件分训练集（train.csv）和验证集（dev.csv）（默认参数是3000条）两部分。

4. train.py训练模型

python ./train.py 会保存验证集上平均f1分数最高的模型到 ./saved_best.pt

5. inference.py 生成结果

用训练好的模型 ./saved_best.pt 生成结果：

python ./inference.py

6. 打包预测结果

zip -r ./result.zip ./*.json

四、Docker提交结果

1.安装配置Docker

本机是win10专业版，安装还是比较顺利的。但也有遇到不少问题。



启动 WSL 2时警告“参考的对象类型不支持尝试的操作”。解决方法：

管理员方式执行cmd命令  

 netsh winsock reset  

 然后启动  docker-desktop ，可以了

2. 创建云端镜像仓库

创建命名空间和镜像仓库：https://cr.console.aliyun.com/


地域选深圳。

完成创建后，在仓库管理功能中就可以看到仓库的基本信息，后面提交结果要用

3.准备提交文件

根据比赛提交说明，每个任务提交一个json文件（utf8编码，每一行为json格式数据，需包含id，顺序排列，命名规范为 "任务名称+_predict.json"格式）

如：

ocnli_predict.json

tnews_predict.json

ocemotion_predict.json

最后将这些文件压缩，命名为 result.zip 压缩格式文件

submission文件夹有以下文件：result.zip是前面打包好的

Dockerfile配置文件参考，Dockerfile是固定名称，注意首字母大写。Dockerfile中命令皆大写：

# Base Images

## 从天池基础镜像构建

FROM registry.cn-shanghai.aliyuncs.com/tcc-public/python:3


## 把当前文件夹里的文件构建到镜像的根目录下

ADD . /


## 指定默认工作目录为根目录（需要把run.sh和生成的结果文件都放在该文件夹下，提交后才能运行）

WORKDIR /


## 镜像启动后统一执行 sh run.sh

CMD ["sh", "run.sh"]


4.docker提交

Powershell切换到submission文件夹下：

登录仓库：

docker login --username=****（你自己的id） registry.cn-shenzhen.aliyuncs.com

会要求输入密码


创建镜像：

docker build -t registry.cn-shenzhen.aliyuncs.com/sally/tianchi:1.0 .

注意：registry.~~~是上面创建仓库的公网地址，用自己仓库地址替换。地址后面的：1.0为自己指定的版本号，用于区分每次build的镜像。最后的.是构建镜像的路径，不可以省掉。

创建成功以后，返回了一个image id b0b485d82b01

docker tag b0b485d82b01 registry.cn-shenzhen.aliyuncs.com/sally/tianchi:1.0

这时候看docker desktop是这样的：

推送镜像到仓库：

docker push registry.cn-shenzhen.aliyuncs.com/sally/tianchi:1.0

这样就推送成功了。

5.提交结果

配置路径，填入前面申请的公有地址及用户名密码，点击提交


提交成功就可以看到分数了，不过排行榜还得等等才能有名次。
