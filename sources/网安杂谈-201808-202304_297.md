3.准备提交文件

根据比赛提交说明，每个任务提交一个json文件（utf8编码，每一行为json格式数据，需包含id，顺序排列，命名规范为 "任务名称+\_predict.json"格式）

如：

ocnli\_predict.json

tnews\_predict.json

ocemotion\_predict.json

最后将这些文件压缩，命名为 result.zip 压缩格式文件

submission文件夹有以下文件：result.zip是前面打包好的

![](../Images/3b8f0dbbbafe9efb3440cdbfb30033ba.png)

Dockerfile配置文件参考，Dockerfile是固定名称，注意首字母大写。Dockerfile中命令皆大写：

\# Base Images

\## 从天池基础镜像构建

FROM registry.cn-shanghai.aliyuncs.com/tcc-public/python:3

  

\## 把当前文件夹里的文件构建到镜像的根目录下

ADD . /

  

\## 指定默认工作目录为根目录（需要把run.sh和生成的结果文件都放在该文件夹下，提交后才能运行）

WORKDIR /

  

\## 镜像启动后统一执行 sh run.sh

CMD \["sh", "run.sh"\]

  

**4.docker提交**

Powershell切换到submission文件夹下：

登录仓库：

docker login --username=\*\*\*\*（你自己的id） registry.cn-shenzhen.aliyuncs.com

会要求输入密码

  

创建镜像：

docker build -t registry.cn-shenzhen.aliyuncs.com/sally/tianchi:1.0 .

注意：registry.~~~是上面创建仓库的公网地址，用自己仓库地址替换。地址后面的：1.0为自己指定的版本号，用于区分每次build的镜像。最后的.是构建镜像的路径，不可以省掉。

![](../Images/b47277dd6f0c5d4ba58e6b6f9370502a.png)

创建成功以后，返回了一个image id b0b485d82b01

docker tag b0b485d82b01 registry.cn-shenzhen.aliyuncs.com/sally/tianchi:1.0

这时候看docker desktop是这样的：

![](../Images/39788027bfdcc5689818ad9451e59e48.png)

推送镜像到仓库：

docker push registry.cn-shenzhen.aliyuncs.com/sally/tianchi:1.0

![](../Images/841713b0cfa3c003bed148535edb16a8.png)

这样就推送成功了。
