二、NumPy
1.NumPy简介
参考NumPy官网的介绍（中文：https://www.numpy.org.cn/；英文：https://numpy.org/）：
NumPy是使用Python进行科学计算的基础软件包。它是一个Python库，提供多维数组对象，各种派生对象（如掩码数组和矩阵），以及用于数组快速操作的各种API，有包括数学、逻辑、形状操作、排序、选择、输入输出、离散傅立叶变换、基本线性代数，基本统计运算和随机模拟等等。

NumPy包的核心是 ndarray 对象。它封装了python原生的同数据类型的 n 维数组，为了保证其性能优良，其中有许多操作都是代码在本地进行编译后执行的。

NumPy数组 和 原生Python Array（数组）之间有几个重要的区别：

NumPy 数组在创建时具有固定的大小，与Python的原生数组对象（可以动态增长）不同。更改ndarray的大小将创建一个新数组并删除原来的数组。
NumPy 数组中的元素都需要具有相同的数据类型，因此在内存中的大小相同。例外情况：Python的原生数组里包含了NumPy的对象的时候，这种情况下就允许不同大小元素的数组。
NumPy 数组有助于对大量数据进行高级数学和其他类型的操作。通常，这些操作的执行效率更高，比使用Python原生数组的代码更少。
一句话总结：方便，简洁，好使
要注意人家是叫NumPy,而不是Numpy...

2.NumPy的使用
2.1NumPy Ndarray 对象

NumPy 最重要的是其 N 维数组对象 ndarray，它是一系列同类型数据的集合，以 0 下标为开始进行集合中元素的索引。

ndarray 对象是用于存放同类型元素的多维数组。ndarray 中的每个元素在内存中都有相同存储大小的区域。ndarray 内部由以下内容组成：

一个指向数据（内存或内存映射文件中的一块数据）的指针。

数据类型或 dtype，描述在数组中的固定大小值的格子。
一个表示数组形状（shape）的元组，表示各维度大小的元组。
一个跨度元组（stride），其中的整数指的是为了前进到当前维度下一个元素需要"跨过"的字节数。

ndarray 的内部结构


跨度可以是负数，这样会使数组在内存中后向移动，切片中 obj[::-1] 或 obj[:,::-1] 就是如此。

创建一个 ndarray 只需调用 NumPy 的 array 函数即可：

numpy.array(object, dtype = None, copy = True, order = None, subok = False, ndmin = 0)

‍

参数的含义：

object 数组或嵌套的数列

dtype 数组元素的数据类型，可选

copy 对象是否需要复制，可选

order 创建数组的样式，C为行方向，F为列方向，A为任意方向（默认）

subok 默认返回一个与基类类型一致的数组

ndmin 指定生成数组的最小维度

2.2NumPy 数组属性

NumPy 数组的维数称为秩（rank），秩就是轴的数量，即数组的维度，一维数组的秩为 1，二维数组的秩为 2，以此类推。
在 NumPy中，每一个线性的数组称为是一个轴（axis），也就是维度（dimensions）。axis=0，表示沿着第 0 轴进行操作，即对每一列进行操作；axis=1，表示沿着第1轴进行操作，即对每一行进行操作。
属性说明
ndarray.ndim秩，即轴的数量或维度的数量
ndarray.shape数组的维度，对于矩阵，n 行 m 列
ndarray.size数组元素的总个数，相当于 .shape 中 n*m 的值
ndarray.dtypendarray 对象的元素类型
ndarray.itemsizendarray 对象中每个元素的大小，以字节为单位
ndarray.flagsndarray 对象的内存信息
ndarray.realndarray元素的实部
ndarray.imagndarray 元素的虚部
ndarray.data包含实际数组元素的缓冲区，由于一般通过数组的索引获取元素，所以通常不需要使用这个属性。


2.3np数组的构造
NumPy创建数组有5种常规机制：

（1）从其他Python结构（例如，列表，元组）转换

（2）numpy原生数组的创建（例如，arange、ones、zeros等）

（3）从磁盘读取数组，无论是标准格式还是自定义格式

（4）通过使用字符串或缓冲区从原始字节创建数组

（5）使用特殊库函数（例如，random）

下面介绍的主要是NumPy原生数组的创建：

2.3.1一般生成方法

    • 形式：numpy.array(object, dtype = None, copy = True, order = None, subok = False, ndmin = 0)

    • 参数

      • ndmin 指定生成数组的最小维度

      • subok 默认返回一个与基类类型一致的数组

      • order 创建数组的样式，C为行方向，F为列方向，A为任意方向（默认）

      • copy 对象是否需要复制，可选

      • dtype 数组元素的数据类型，可选

      • object 数组或嵌套的数列

    • 实例

      • np.array([1,2,3])  输出array([1, 2, 3])

2.3.2设置数值范围生成数组

    • ‍numpy.arange

      • numpy 包中的使用 arange 函数创建数值范围并返回 ndarray 对象

      • 函数格式：numpy.arange(start, stop, step, dtype)

      • 参数

        • dtype 返回ndarray的数据类型，如果没有提供，则会使用输入数据的类型。

        • step 步长，默认为1

        • stop 终止值（不包含）

        • start 起始值，默认为0

      • 例：np.arange(1,5,2) # 起始、终止（不包含）、步长 输出为：array([1,3])

         

    • 等差数列

      • numpy.linspace 函数用于创建一个一维数组，数组由等差数列构成

      • 格式：np.linspace(start, stop, num=50, endpoint=True, retstep=False, dtype=None)

      • 参数：

        • dtype ndarray 的数据类型

        • retstep 如果为 True 时，生成的数组中会显示间距，反之不显示。

        • endpoint 该值为 true 时，数列中包含stop值，反之不包含，默认是True。

        • num 要生成的等步长的样本数量，默认为50

        • stop 序列的终止值，如果endpoint为true，该值包含于数列中

        • start 序列的起始值

      • 例：np.linspace(1,5,11) # 起始、终止（包含）、样本个数 输出:array([1. , 1.4, 1.8, 2.2, 2.6, 3. , 3.4, 3.8, 4.2, 4.6, 5. ])

    • 等比数列

      • numpy.logspace 函数用于创建一个于等比数列。

      • 格式：np.logspace(start, stop, num=50, endpoint=True, base=10.0, dtype=None)

      • 参数：

      • dtype ndarray 的数据类型

      • base 对数 log 的底数（下标）。

      • endpoint 该值为 true 时，数列中中包含stop值，反之不包含，默认是True。

      • num 要生成的等步长的样本数量，默认为50

      • stop 序列的终止值为：base ** stop。如果endpoint为true，该值包含于数列中

      • start 序列的起始值为：base ** start

      • 例：np.logspace(0,9,10,base=2) 输出：array([ 1.   2.   4.   8.  16.  32.  64. 128. 256. 512.])


2.3.2生成特殊数组

    • numpy.full

      • 功能：返回一个给定形状和类型的新数组，用fill_value填充。

      • 形式：numpy.full(shape, fill_value, dtype=None, order='C')

      • 参数：

        • order{‘C’, ‘F’}, optional  Whether to store multidimensional data in C- or Fortran-contiguous (row- or column-wise) order in memory.

        • dtype  data-type, optional The desired data-type for the array The default, None, means np.array(fill_value).dtype.

        • fill_value scalar or array_like  Fill value.

        • shape  int or sequence of ints   Shape of the new array, e.g., (2, 3) or 2.

      • 返回结果：ndarray  Array of fill_value with the given shape, dtype, and order.

      • 例：np.full((2, 2), [1, 2])


    • numpy.eye

      • 功能：返回一个对角线上为1，其他地方为0的二维数组。

      • 形式：numpy.eye(N, M=None, k=0, dtype=<class 'float'>, order='C')

      • 参数：

        • order{‘C’, ‘F’}, optional   Whether the output should be stored in row-major (C-style) or column-major (Fortran-style) order in memory.

        • dtype  data-type, optional Data-type of the returned array.

        • k  int, optional Index of the diagonal: 0 (the default) refers to the main diagonal, a positive value refers to an upper diagonal, and a negative value to a lower diagonal.

        • M  int, optional  Number of columns in the output. If None, defaults to N.

        • N  int  Number of rows in the output.

        • 例：

        • np.eye(3, k=1) # 偏移主对角线1个单位的伪单位矩阵    输出：array([[0., 1., 0.],       [0., 0., 1.],       [0., 0., 0.]])

        • np.eye(3) # 3*3的单位矩阵  输出：array([[1., 0., 0.],       [0., 1., 0.],       [0., 0., 1.]])

    • numpy.ones

      • 功能：创建指定形状的数组，数组元素以 1 来填充

      • 形式：numpy.ones(shape, dtype = None, order = 'C')

      • 参数

        • order 'C' 用于 C 的行数组，或者 'F' 用于 FORTRAN 的列数组

        • dtype 数据类型，可选

        • shape 数组形状

        例：# 自定义类型x = np.ones([2,2], dtype = int)   print(x)  

    • numpy.zeros

      • 创建指定大小的数组，数组元素以 0 来填充：numpy.zeros(shape, dtype = float, order = 'C')

      • 参数

      • order 'C' 用于 C 的行数组，或者 'F' 用于 FORTRAN 的列数组

      • dtype 数据类型，可选

      • shape 数组形状

      • 例：

      • np.zeros((2,3)) # 传入元组表示各维度大小   输出：[[0. 0.0. ]

      • #可以指定类型  z = np.zeros((2,2), dtype = [('x', 'i4'), ('y', 'i4')])    print(z)   其中i4指 4 字节整数

      • # 设置类型为整数 y = np.zeros((5,), dtype = np.int) print(y)   输出 [0 0 0 0 0]

      • # 默认为浮点数 x = np.zeros(5) print(x)     输出[0. 0. 0. 0. 0.]


2.3.3生成随机矩阵

numpy.random通过生成器来产生符合统计分布的伪随机数序列。看官网的介绍，使用位生成器的组合来创建序列，并使用生成器来使用这些序列从不同的统计分布取样。

最常用的随机生成函数为 rand, randn, randint, choice ，它们分别表示0-1均匀分布的随机数组、标准正态的随机数组、随机整数组和随机列表抽样。
可以通过随机种子固定随机数的输出结果。如np.random.seed(0)设置后产生的随机数就固定了。



  • np.random.rand

    • 功能：按照指定数组形状，生成0-1均匀分布的随机值数组

    • 形式：numpy.random.rand(d0, d1, ..., dn)

    • 返回：ndarray, shape (d0, d1, ..., dn) Random values（0-1）.

    • 例



    • 对于服从区间 a到 b上的均匀分布生成：(b - a) * np.random.rand(3) + a

  • np.random.randint

    • 功能：可以指定生成随机整数的最小值最大值（不包含）和维度大小  Return random integers from the “discrete uniform” distribution of the specified dtype in the “half-open” interval [low, high). If high is None (the default), then results are from [0, low).

    • 形式：numpy.random.randint(low, high=None, size=None, dtype=int)

    • ‍参数

      • low int or array-like of ints      Lowest (signed) integers to be drawn from the distribution (unless high=None, in which case this parameter is one above the highest such integer).

      • high  int or array-like of ints, optional  If provided, one above the largest (signed) integer to be drawn from the distribution (see above for behavior if high=None). If array-like, must contain integer values

      • size int or tuple of ints, optional Output shape. If the given shape is, e.g., (m, n, k), then m * n * k samples are drawn. Default is None, in which case a single value is returned.

      • dtype dtype, optional Desired dtype of the result. Byteorder must be native. The default value is int.

    • 例：


  • np.random.randn

    • 功能：生成标准正态分布数组 Return a sample (or samples) from the “standard normal” distribution.

    • 形式：numpy.random.randn(d0, d1, ..., dn)

    • 服从方差为σ2均值为 μ的一元正态分布表示为sigma * np.random.randn(...) + mu

      当mu=0,sigma=1时，正态分布就成为标准正态分布

    • 例：np.random.randn(2, 2)

    • 例：Two-by-four array of samples from N(3, 6.25):

    • 3 + 2.5 * np.random.randn(2, 4)

  •  np.random.choice

  • 功能：choice 可以从给定的列表中，以一定概率和方式抽取结果，当不指定概率时为均匀采样，默认抽取方式为有放回抽样

  • 形式：numpy.random.choice(a, size=None, replace=True, p=None）

  • 参数：

    • p 1-D array-like, optional ，The probabilities associated with each entry in a. If not given the sample assumes a uniform distribution over all entries in a.

    • replace boolean, optional ，Whether the sample is with or without replacement

    • size int or tuple of ints, optional Output shape. If the given shape is, e.g., (m, n, k), then m * n * k samples are drawn. Default is None, in which case a single value is returned.

    • a 1-D array-like or int ，If an ndarray, a random sample is generated from its elements. If an int, the random sample is generated as if a were np.arange(a)

  • 例：p中各个概率值相加要为1，replace是布尔类型(True替换原列表，否则不替换).

  • 注意：dtype='<U1'是numpy中表示长度为1位的unicode类型数据。dtype='<U16'就表示长度为16位了

  • 在choice()方法将replace设为False的前提下，当返回个数等于数组长度时（无放回抽样时）等价于permutation()方法，即打散 np.random.permutation(my_list)
