3.Pandas

3.1Pandas是什么

实话说，我一直以为Pandas的名字是来源于咱们国宝。。。
但其实Pandas是python+data+analysis的组合缩写，是python中基于numpy和matplotlib的第三方数据分析库。pandas numpy matplotlib俗称数据分析三剑客，和数据打交道不得不学呀！
pandas官网：https://pandas.pydata.org/

要全面了解pandas，文档最全面了，看这里https://pandas.pydata.org/docs/pandas.pdf

3.2环境配置

官网推荐通过Anaconda安装和配置pandas环境。当然其他的安装途径（如PyPI, ActivePython, various Linux distributions, development version）也支持。在这里也强烈推荐。还有别忘了装好Jupyter。


pandas1.1.5支持python版本：

Offificially Python 3.6.1 and above, 3.7, 3.8, and 3.9

目前pandas的最新版本是1.1.5，我查了下自己的版本只有1.0.5，看来需要升级了。

三种方法可行：

1.pip install --upgrade pandas更新

2.卸载重装

3.conda install -c conda-forge pandas 更新


下面是卸载重装的步骤

pip uninstall pandas

pip install pandas==1.1.5 或者 conda install padas==1.1.5

查看pandas版本可以用pip list查看，也可以在python环境中查看

import pandas as pd pd.__version__
