1.列表推导式


列表推导式（又称列表解析式）提供了一种简明扼要的方法来创建列表。
列表推导式形式：　　
[表达式 for 变量 in 列表]    或者  [表达式 for 变量 in 列表 if 条件]
它的结构是在一个中括号里包含一个表达式，然后是一个for语句，然后是 0 个或多个 for 或者 if 语句。表达式可以是任意的，意思是你可以在列表中放入任意类型的对象。返回结果将是一个新的列表，在这个以 if 和 for 语句为上下文的表达式运行完成之后产生。
列表推导式的执行顺序：各语句之间是嵌套关系，左边第二个语句是最外层，依次往右进一层，左边第一条语句是最后一层。如下面的例子：
[x*y for x in range(1,5) if x > 2 for y in range(1,4) if y < 3]
实际执行顺序是:
for x in range(1,5)        if x > 2               for y in range(1,4)                       if y < 3                              x*y
举例：
L = []def my_func(x):     return 2*xfor i in range(5):     L.append(my_func(i))
输出L结果是：[0, 2, 4, 6, 8]
利用列表推导式进行写法上的简化： [* for i in *] 。其中，第一个 * 为映射函数，其输入为后面 i 指代的内容，第二个 * 表示迭代的对象。
[myfunc(i) for i in range(5)]
列表表达式还支持多层嵌套，如下面的例子中第一个 for 为外层循环，第二个为内层循环：
[m+'_'+n for m in ['a', 'b'] for n in ['c', 'd']]
输出为：['a_c', 'a_d', 'b_c', 'b_d']
补充：其实推导式是python独特的结构，可以将代码压缩到1行，不光列表可以用推导式，字典、集合也是可以这样用的。
字典推导式
# 字典推导式(用花括号{}包围起来)
dict = {x: x*x for x in [1, 2, 3]}
# 输出
    {1: 1, 2: 4, 3: 9}

集合推导式

# 集合推导式(也是用花括号包围，和字典推导式区别只是在for语句的前面表达式不一样，没有：)
s = {x for x in 'agjsgnjkjg' if x not in 'sgjkajhag'}print(s)
输出：{'n'}
举个例子：把列表L中的数值做修剪，使得大于5的数值被clip
(参考下pandas的clip功能)
L = [1, 2, 3, 4, 5, 6, 7][i if i <= 5 else 5 for i in L]
输出: [1, 2, 3, 4, 5, 5, 5]

2.条件赋值

Python赋值语句，有一种带条件判断的语法，将赋值和条件判断融为一行代码，使需要条件判断的赋值代码写起来更加简练高效。这种赋值语句中的条件判断，可以是if判断，也可以是or和and判断。当然还是if判断更为常用。

if条件赋值形式为 value = a if condition else b ：
举例：
value = 'cat' if 2>1 else 'dog'value

输出将是'cat'


3.匿名函数和map方法

3.1匿名函数

匿名函数没有显示地定义函数名，使用【lambda + 参数 +表达式】的方式，即：

lambda [arg1 [,arg2, ... argN]] : expression
也就是说，lambda用来表示匿名函数，可以传入多个参数，但只能有一个表达式。
比如这个例子3.1
[(lambda x: 2*x)(i) for i in range(5)]
lambda x:2*x就是一个匿名函数，i作为它的参数。输出就是
[0, 2, 4, 6, 8]
那为啥一定要用匿名函数呢？

比较下一般函数和匿名函数：

一般函数用【def + 函数名+参数】的方式定义函数，即：
def function_name(parameters):        ...
这样的函数拥有函数名，调用函数只需要
function_name(input_parameter）
lambda是一个表达式而不是一个语句。它能够出现在Python语法不允许def出现的地方。作为表达式，lambda返回一个值（即一个新的函数），lambda用来编写简单的函数，而def用来处理更强大的任务。
匿名函数的优缺点很明显：优点是代码简洁，跟python的map()、filter()、reduce()结合使用很方便；
缺点就是代码的可读性差，对于新手难于理解。

3.2map函数

例3.1是典型的列表推导式匿名函数映射。python中提供了map()函数可以方便的实现这个功能。

map( )函数接收两个参数，一个是函数，一个是Iterable，map将传入的函数依次作用到序列的每一个元素，并把结果作为新的Iterable返回。

其语法格式为：map(function，iterable...)。

其中function为函数名，iterable为一个或多个序列。

map(lambda x: 2*x, range(5))

上面这条语句的意思，就相当于例3.1，是不是感觉简洁一些了。

map作为高阶函数，事实上它把运算规则抽象了，我们可以用这种方式计算任意复杂的函数。

map函数的返回值要注意，这个值在python2中是列表，到了python3中返回的是一个迭代器。这个结果不是我们想要的,所以还得用list做一个转换。


In:map(lambda x: 2*x, range(5))Out:<map at 0x167c9f8c940>In:list(map(lambda x: 2*x, range(5)))Out:[0, 2, 4, 6, 8]

对于多个输入值的函数映射，可以通过追加迭代对象实现：

list(map(lambda x, y: str(x)+'_'+y, range(5), list('abcde')))

这条语句的输出是：

['0_a', '1_b', '2_c', '3_d', '4_e']
那我们改造一下变成三个参数呢？
list(map(lambda x, y,z: str(x)+'_'+y+'_'+z, range(5), list('abcde'),list('nihao')))
输出就是：
['0_a_n', '1_b_i', '2_c_h', '3_d_a', '4_e_o']


4. zip与enumerate函数


zip函数能够把多个可迭代对象打包成一个元组构成的可迭代对象，它返回了一个 zip 对象。

zip(iter1 [,iter2 [...]]) —> zip object


先直观的看下zip()函数在Python中的工作方式：

ZIP函数返回一个元组迭代器，其中第i个元组包含每个参数序列或可迭代对象中的第i个元素。当最短的可迭代输入耗尽时，迭代器将停止。使用单个可迭代参数，它将返回1元组的迭代器。没有参数，它将返回一个空的迭代器。

In：L1, L2, L3 = list('abc'), list('def'), list('hij')zip(L1, L2, L3)Out：<zip at 0x167cc114f00>
通过 tuple, list函数转换可以得到相应的打包结果。
In：list(zip(L1, L2, L3))Out：(('a', 'd', 'h'), ('b', 'e', 'i'), ('c', 'f', 'j'))In：tuple(zip(L1, L2, L3))Out：(('a', 'd', 'h'), ('b', 'e', 'i'), ('c', 'f', 'j'))
循环迭代的时候经常用到zip函数。
L1, L2, L3 = list('abc'), list('def'), list('hij')for i, j, k in zip(L1, L2, L3):     print(i, j, k)

输出为：

a d h
b e i
c f  j
将zip（）对象转换成字典
当需要对两个列表建立字典映射时，可以利用zip函数：
In:dict(zip(L1, L2))out: {'a': 'd', 'b': 'e', 'c': 'f'}
解压列表
在某些情况下，我们需要执行相反的操作——解压迭代器。解压操作涉及将压缩后的元素恢复为其原始状态。为此，我们添加*运算符到函数调用中。例：
a = [1, 2, 3]b = [4, 5, 6]zipped = zip(a, b)list(zipped)
a2, b2 = zip(*zip(a, b))#a2,b2分别就是解压后的a,bprint(a == list(a2) and b == list(b2))
这个例子输出是True

enumerate函数

enumerate( )是python的内置函数。enumerate在字面上是枚举、列举的意思。对于一个可迭代的（iterable）/可遍历的对象（如列表、字符串），enumerate将其组成一个索引序列，利用它可以同时获得索引和值
enumerate多用于在for循环中得到计数。
例如对于一个seq，得到：
(0, seq[0]), (1, seq[1]), (2, seq[2])
enumerate()返回的是一个enumerate对象。
L = list('abcd')for index, value in enumerate(L):     print(index, value)

输出为：

0 a
1 b
2 c
3 d
用ZIP函数也可以实现一样的功能
for index, value in zip(range(len(L)), L):    print(index, value)
