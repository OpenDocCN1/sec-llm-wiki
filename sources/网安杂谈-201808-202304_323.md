# 山东大学高性能计算云平台初体验

最近有点焦头烂额，因为一头扎进的机器学习这个坑，努力爬坑中……不得不说，机器学习算法很有想象力和创造力，但有个最大的缺点，那是真费资源。这几天跟BERT较劲，更深刻的体会到这点。BERT什么都好，人必称BERT，就真的是吃显存。说起来惭愧，我一直觉得还在初学阶段，没必要配置专门的机器学习服务器，有个带一块GPU的笔记本，我还觉得满可以了，先过渡一下好了，等我功力修炼的差不多再说。然而现实打醒了我，在跑BERT原生程序的时候，直接无情的警告我：“哥，显存不够！”然而，查了查配置参数，动辄几万，几十万起的报价，都怪我太天真，难道穷人真的不能享受研究的快乐？就在纠结无奈的时候，很幸运受邀参与了山东大学高性能计算云平台的试用，真心感受到母校对科研资源的巨大投入和重视。下面就记录下我的体验过程以及环境配置步骤，给同样在爬坑的同学们参考。![](../Images/2859c819e6e369d59e40cd7faa340b84.png)山大高性能计算云平台完全基于互联网访问操作的公共计算系统，全校师生都具有独立的工作环境。已提供十余种通用的计算和分析软件的容器模板和编程环境模板，用户可以通过模板自助创建并自定义的计算实例,可实现容器集群应用。云平台背后有约 160 台各型计算节点，320 个 x86 处理器，理论计算能力不小于 300TFLOPS。32 个Tesla V100 32GB计算加速卡，统一的专用人工智能软件平台。100Gbps 核心交换网络，校园网互联。1PB 磁盘存储空间。据说已投入1500万，看看他们长下面这样：![](../Images/3d7f3a0f09042e9036bb1090286e4d9e.png)

外表挺帅的，我们再来感受一下内在。云平台功能极简，易用，用起来很顺手。 ![](../Images/df760a208a3b867402af78ab54ef92bb.png)  
平台登录进来以后，先申请资源，有这么多模板可选创建实例。![](../Images/f92e1f1d0be1cf232263343b12292123.png)既然是来体验，我就选一个看起来最好的吧。一会我们来瞧瞧土豪家到底是啥配置。在这个界面你可能还感受不到什么。![](../Images/219a585bd9658e1d3c3dce2a321fa290.png)实例创建成功以后，用远程桌面连接，一个新的世界将要开启。![](../Images/19524bda692f78dadfaa05f1f7a5bf4e.png)先用nvidia-smi命令查一下gpu显卡到底是啥。WOW Tesla V100-SXM2,这个看起来挺牛的样子。![](../Images/7798068dbe74c65f4515d707db05cd05.png)就简单搜了一下。![](../Images/161cc4e9eff7d9b2787e43dadaa196f3.png)什么是世一大，什么是C9……这就是了！ 另外平台数据上传也很方便，我在外网速度也是相当不错了。![](../Images/2849a97227e3908bcceb58d1ed9210db.png)  
 ![](../Images/4636e2c47a65b7b5bd5c8a16b178304e.png)  
感叹过后，还得继续向前进，到了我最头疼的环境配置环节。我配过的环境，少说也有三五十回，不是少这个，就是缺那个，不是版本不配套，就是哪里设置有问题，总之，每次太顺利我都感觉到十分不真实。不过这次还确实挺顺的了，显卡驱动什么的都给弄好了，省了不少事。 说到这里就得说机器学习两大框架Tensorflow,Pytorch,要学习人家的代码就都得装起来，不同版本总得有不同的环境依赖，要用GPU，还得小心挑选CUDA和CUCNN版本，哪个环节不对付，就得撂挑子，简直是如履薄冰啊。好在有Anaconda可以对环境可以统一管理,可省了大事了。以我多年失败经验总结一点环境配置步骤供参考：1.系统还是用linux吧，windows有一些莫名其妙的坑。系统版本也要注意一下，有时候版本太高了还要降级。我创建的实例系统是centos7.8(2003)足够用了。![](../Images/6c8ca2807eccf9c36250ff0858e12b29.png)2.先把anaconda装好，方便管理环境。装好后第一件事就是创建虚拟环境，起好名，好管理。![](../Images/583e2abcaefa19194147634a99ba3ab7.png)3.虚拟环境建好以后，我们要用GPU,还要装CUDA(由NVIDIA推出的通用并行计算架构)和cuDNN(NVIDIA cuDNN是用于深度神经网络的GPU加速库)。以前这块没少踩坑，一定要注意机器学习框架版本和CUDA、cuDNN的对应关系。这里强烈推荐conda安装机器学习框架，可以自动安装对应的CUDA、cuDNN版本。比如我要跑BERT的Google版程序（https://github.com/google-research/bert）最好还是用tensorflow1.11。安装的时候直接用conda安装（如conda install tensorflow-gpu==1.11），方便还不容易出错。真的强烈强烈建议！4.然后Jupyter notebook,Pycharm等也是必备开发环境了，这个只要按部就班一般没啥大事。Jupyter notebook需要配置一下初始路径，以及解决一下看不到虚拟环境的问题。 当BERT终于欢快的跑起来，我不禁流下了无知的泪水。再次膜拜Tesla V100-SXM2-32G显卡，再次膜拜山东大学高性能计算云平台。![](../Images/82b3ba16ce12d0ada1b8c73c63f80151.png)   
最后感慨几句，从母校毕业好多年，自己也成了一名老师，我常想大学到底带给学生的是什么？好的大学到底好在哪里？这个标准很多，考核也很多。我想当学生想探索世界，学校可以给他提供引导，提供资源，这就是好的标准之一吧。祝山大高性能计算云平台越来越牛！
