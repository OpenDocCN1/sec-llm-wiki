**选择正确的工具**

鉴于有许多选项，要选择适合您需要的正确工具并不容易。以下是在做决定时需要考虑的一些方面。

**技术水平**

在选择数字取证工具时，技术水平是一个重要的因素。一些工具只需要基本的技能，而另一些可能需要高级的知识。一个好的经验法则是评估你所拥有的技能和该工具所需要的技能，这样你就可以选择你有能力操作的最强大的工具。

**输出**

工具的构建并不相同，因此即使在相同的类别中，输出也会有所不同。一些工具只返回原始数据，而另一些工具将输出完整的报告，可以立即与非技术人员共享。在某些情况下，仅使用原始数据就足够了，因为您的信息可能必须经过更多的处理，而在其他情况下，使用格式化的报表可以使您的工作更容易。

**成本**

不用说，成本是一个重要的因素，因为大多数部门都有预算限制。这里需要记住的一点是，最便宜的工具可能不具备你想要的所有特性，因为这是开发人员保持低成本的方法。不要仅仅根据成本来选择工具，在做出选择时考虑在成本和特性之间取得平衡。

**焦点**

另一个关键方面是工具的焦点区域，因为不同的任务通常需要不同的工具。例如，用于检查数据库的工具与用于检查网络的工具非常不同。最佳实践是在购买之前创建一个完整的特性需求列表。如前所述，一些工具可以在一个工具包中涵盖多个功能，这比为每个任务寻找单独的工具要好得多。

**额外的配件**

有些工具可能需要额外的附件来操作，这也是需要考虑的。例如，一些网络取证工具可能需要特定的硬件或软件引导的介质。所以在购买之前一定要检查硬件和软件的要求。

![](../Images/d01c3464f6a3631d58aab28563a52874.png)

  

提示:可以从http://sourceforge.net/projects/dc3dd/获得一个修改版的dd——dc3dd包括专门为数字取证获取任务添加的其他特性。

要使用dd，只需打开一个终端窗口，输入dd，然后输入一组命令参数(这些命令参数显然取决于您想要做什么)。磁盘清理的基本dd语法是:

dd if=/dev/zeroof=/dev/sdb1 bs=1024

where if =输入文件，of =输出文件，bs =字节大小

注意:将/dev/sdb1替换为您想要进行反向擦除的驱动器名称，将1024替换为您想要写入的字节块大小。

创建一个驱动器的镜像的基本dd语法是:

dd if = / dev /sdb1 = / home / andrew / newimage。dd b = 512 conv = noerror同步

where if =输入文件(或在本例中驱动器)，of =输出文件，bs =字节大小，conv =转换选项

提示:要获得更多的使用信息，在终端窗口中，输入不带引号的“man dd”，就会弹出dd命令的帮助手册。

关键特性

•跨文件、设备、分区和卷重复数据。

•支持主引导记录备份和恢复。
