iLEAPP


自从在 2019 年 12 月公开发布以来，Alexis Brignoni 就在不断努力更新iLEAPP，并在最近推出了最新的 1.2 版本。iOS 日志、事件和属性解析器，或简称为 iLEAPP，是指集中到同一工具中进行解析的不同独立脚本的组合，解析的对象包括移动安装日志、iOS 通知内容等众多档。iLEAPP 还会解析在 iOS KnowledgeC.db 中发现的 bplist，以及 KnowledgeC 字段，其中包括： 

  • 应用程序使用情况 

  • 应用程序焦点 

  • 应用程序活动 

  • 电池电量 

  • 已安装的应用程序 

  • 已解锁的设备 

  • 已插入的设备 


去年，Alexis 异常忙碌，而现在，他被提名成为多个 Forensic 4:cast Awards 奖项的候选人，包括：年度 DFIR 优秀文章—《iLEAPP：iOS 日志、事件和属性解析器》、年度 DFIR 社交媒体贡献者、iLEAPP 领域年度 DFIR 突破性研究、年度 DFIR 非商业工具，以及最后的年度杰出数字取证调查员！

磁盘仲裁器


多年以来，在获取 Mac 终端节点时，调查员一直使用“目标磁盘模式”(TDM) 作为一种选项。在最近推出的采用 T2 芯片的 Mac 中，该做法变得更为普遍，因为这些 Mac 的安全性得到增强，在预设情况下不允许从外部设备/镜像启动。当通过类似 TDM 等选项连接到目标终端节点时，我们需要想办法避免挂载到系统读写，从而保护我们的证据。  



其创建者—Aaron Burghardt，在他的 github 中表示：“磁盘仲裁器对于磁盘仲裁框架而言基本上算是一种用户接口，它使程序能够参与块存储设备的管理，包括文件系统的自动挂载等。一旦启用，磁盘仲裁器将阻止文件系统挂载，以避免读写挂载与破坏证据的完整性。”您可以在此处的 Aaron 的 Github 上找到磁盘仲裁器。https://github.com/aburgh/Disk-Arbitrator


mac_apt


由 Yogesh Khatri 开发，mac_apt 是用于解析 macOS 痕迹的基于 python 的框架。我很荣幸能在 Magnet Virtual Summit 上参加了 Yogesh 的演示报告，了解 mac_apt 在实际工作中的用途。如果您错过他的首次报告，可以在【上优酷，观看 Magnet Virtual Summit 演讲视频】点播观看。 


借助于众多插件，它的跨平台功能以及兼容 .E01、DMG 和 .AFF4 镜像的能力，使其成为功能十分强大的平台。我们将在本文的后半部分讨论如何与 AXIOM 以及我们的免费工具搭配使用 mac_apt，首先我非常感谢 Yogesh 在 mac_apt 中提供的 SQLite 输出。从 v0.5-beta 版本开始，mac_apt 还支持带独立系统和数据卷的 macOS 10.15 (Catalina)。（您可以转至 Yogesh 的网站以了解更多信息）https://www.swiftforensics.com/


除了 mac_apt，Yogesh 还开发了串并转换器，以便用于处理 macOS 和 iOS PList。串并转换器会将 NSKeyedArchive Plist 转换成为可被轻松读取的普通反串行化档。在此处他的 Github 上了解关于此资源的更多信息。

https://github.com/ydkhatri/MacForensics/blob/master/Deserializer/README.md

Magnet Custom Artifact Generator (MCAG)


在上个月的 Magnet’s Virtual Summit 上推出，该免费的 Magnet Custom Artifact Generator (MCAG) 简化了在 AXIOM 中使用的全新自定义痕迹的创建工作。MCAG 接受 CSV/分隔文件和 SQLite 数据库，以用于生成新痕迹。查看 Jessica Hyde 的文章，了解如何搭配包括 Alexis Brignoni 的 iLEAPP 或 Yogesh Khatri 的 Mac Apt 等在内的工具使用 MCAG。  

https://www.magnetforensics.com/blog/how-to-use-the-magnet-custom-artifact-generator/


现在我们不提供原生支持在 AXIOM 中显示来自 APFS 数据集的统一日志，但我们还是会在处理过程中用到很多痕迹，它们来自从统一日志中提取的信息。这是因为若完全处理，统一日志会将大量的痕迹添加到 AXIOM 案件文件中（额外增加数百万要检查的痕迹）。 


对于调查员需要进一步查看统一日志的调查，现在有一种将此类档加载到 AXIOM 的简单方式。首先，利用 Yogesh 的 mac_apt 导出包含统一日志的 SQLite 数据库。然后转至我们的免费工具页面下载 MCAG。

https://www.magnetforensics.com/resources/?cat=Free%20Tool


下载完成以后，您要将 MCAG 指向已经通过 Mac Apt 创建的 Sqlite.db，然后对 MCAG 进行配置以创建用于解析（统一日志的）数据库的自定义痕迹。最后，打开 AXIOM Process，将包含统一日志的 SQLite 数据库加载到 AXIOM（计算机>Mac>文件和文件夹），然后确保您的自定义痕迹已加载到 AXIOM。在处理完成以后，您将可以直接在 AXIOM 中检查这些日志。 


归档工具



它们不是取证工具，不过，在您的实验室中使用 Mac 意味着您将需要解压/打开各种来源的基于不同格式的归档文件。虽然 Mac 标准自带 Archive Utility.app，但用户可能在尝试用它打开特殊文件时遇到问题。我建议您可以了解一下 The Unarchiver 应用程序，或 Keka。两者都具有出色的功能，能够打开标准 Archive Utility 难以处理的各种来源的归档文件。就个人而言，我使用的是 Keka，它提供不同的默认压缩格式，甚至可被设定为在混合终端节点环境中排除 macOS 资源 fork (ex: .DS_Store)。Keka 还支持基于 7zip 的归档文件。 

The Unarchiver 详情：https://theunarchiver.com/

KeKa 详情：https://www.keka.io/en/
