# 投票：黑色产业链上游、中游、下游是如何划分的？你的看法是？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMTMzMDUwNg==&mid=2650881372&idx=1&sn=265b9885227fc695217d0cee059edfee&chksm=812ec179b659486fed65cdcdff22f7b3c958e9be9f012f6d618715b2957e198ebcaa7aebc308&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwMTMzMDUwNg==&mid=2650881372&idx=1&sn=265b9885227fc695217d0cee059edfee&chksm=812ec179b659486fed65cdcdff22f7b3c958e9be9f012f6d618715b2957e198ebcaa7aebc308&scene=27#wechat_redirect)

昨天在后台发起了一个讨论：讨论网络黑色产业链上游、中游、下游是如何划分的。结果很有意思啊！很多同行们理解各不相同。当然，如何划分，不影响实际工作，但我想概念的统一，是大家统一认识的基础，也是法律法规应该予以清晰明确的。选了几个有代表性看法大家参考：  

1.  上游犯罪为下游犯罪提供工具、技术和数据等方面的支持；中游就是上下游的中介；下游犯罪为诈骗等犯罪实施阶段。
    
      
    
2.  上游：提供技术服务、数据服务等，是指就是提供资源工具之类的；中游：使用上游提供的资源工具使用自己的方式进行变现；下游：将变现的资金进行清洗，也就是洗钱。
    
      
    
3.  产业链的上游应该是供应商，中游是制造商，而下游应该就是销售商了。在黑灰产业链中应该也是如此划分的吧，以电信诈骗为例，提供公民身份信息的“菜商”，提供诈骗用伪造平台，提供电话卡，提供银行卡等人应该为上游产业，中间实施诈骗的犯罪嫌疑人应该为中游产业，当然实施诈骗过程中也有不同身份的分工，但应该都归于中游。最后诈骗成功了，诈骗所得的资金需要通过水房，境外赌博网站，地下钱庄等进行洗钱活动甚至于负责取款的车手，这些角色应该都属于下游的产业，因为他们都是将中游制造商提供的物品变现的一个作用，只是在诈骗活动中，制造商提供的物品也是货币，不能直接使用，或者有风险的货币。
    
      
    
4.  犯罪预备阶段的是上游，比如开办不实名卡，购买小qq；犯罪实施阶段的是中游，比如开办诈骗网站赌博网站等；犯罪结果阶段的是下游，比如洗钱通道，马仔取款等。
    
      
    
5.  上游是为黑灰产做准备的一些犯罪，如侵犯公民信息、妨害信用卡管理、买卖国家证件。中游是实施黑灰产的一些犯罪，如破坏计算机系统、帮助网络信息犯罪活动、非法经营、洗钱。下游是黑灰产牵连出来的一些犯罪，如诈骗、开设赌场、传销、非法吸收公众存款、传播淫秽物品、敲诈等
    
      
    
6.  这是相对论的话题。某个犯罪的上游可能是其他犯罪的下游。
    
      
    
7.  主要犯罪算源头，为主要犯罪提供服务的是下游；源头算上游，为源头提供服务是下游，为下游服务的是下下游，所以上下游要针对哪一环节来看啊。
