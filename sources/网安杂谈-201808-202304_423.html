一、爬虫

要用爬虫下载，就得找到pdf文件真正链接。还好，ICLR的论文下载链接比较好找。浏览器打开https://openreview.net/group?id=ICLR.cc/2020/Conference, F12看网络访问日志，响应中能看到Jason文件，里面有论文全部的相关信息，下载地址等。

仔细分析下链接：https://openreview.net/notes?invitation=ICLR.cc%2F2020%2FConference%2F-%2FBlind_Submission&details=replyCount%2Coriginal&includeCount=true&offset=0&limit=50

其中offset代表的是页数，limit代表每页显示论文条数。这么算下来，一共52页，每页50篇，那就是一共提交了2600篇论文。

def getFile(url,file_name):#下载文件

    try:

        u = urllib.request.urlopen(url, timeout=1000)

    #u = urllib.request.urlopen(url)

        data = u.read()

        print("downloading")

        with open(file_name, "wb") as code:

            code.write(data)

        print ("Sucessful to download" + " " + file_name)

    except socket.timeout as e:

        data.close()

    except HTTPError as e:

        print('The server couldn\'t fulfill the request.')

        print('Error code: ', e.code)

    except URLError as e:

        print('We failed to reach a server.')

        print('Reason: ', e.reason)

    else:

        print('OK')

二、分析热门关键词


（一）词云

构建词云需要先有文章等原料，然后进行分词，分词形成列表，通过词云工具进行构建，可以将可视化结果存储下来。中文分词需要jieba，构建词云要用wordcloud模块。因为我们这里是英文语料，并且JSON中都给我们处理好了关键词，所以不需要分词。需要安装wordcloud模块。

从前面JSON文件转成的csv文件中，我们只留下keywords一列。

def statistics():#进行数据处理，统计词频

    word_list=[]

    freq_list=[]

    with open('keywords.txt','r',encoding='utf-8') as text:

        words = [raw_word.strip(string.punctuation).lower() for raw_word in text.read().split(',')]#用逗号分割关键词

        words_index = set(words)

        words_count = {index:words.count(index) for index in words_index}

    for  word in sorted(words_count ,key=lambda x:words_count[x],reverse=False):

        print('{} {}'.format(word,words_count[word]))

        word_list.append(word)

        freq_list.append(words_count[word])

    result=pd.DataFrame({"word":word_list,"freq":freq_list})

    result.to_csv('bb.csv',index=False)#统计结果存为csv文件


def drawbar():

    plt.style.use('seaborn-darkgrid')#使用默认样式

    colors = plt.rcParams['axes.prop_cycle'].by_key()['color']   #样式美化，提取样式中的颜色设置

    num_keyword = 50

    dfkeywords= pd.read_csv('bb.csv').tail(num_keyword)#取从后面数50个

    fig, ax = plt.subplots(figsize=(15, 20))#设置绘图区域大小

    plt.xticks(fontsize=18)#设置字体大小

    plt.yticks(fontsize=18)#设置字体大小

    ax.barh(dfkeywords["word"],dfkeywords["freq"],color=colors,ec = 'gray',ls = '--',lw = 1)#设置柱状图条的边为虚线

    ax.set_xlabel("Frequncy",fontsize=20)  #设置x轴标签

    ax.set_ylabel("Keywords",fontsize=20)  #设置y轴标签

    ax.set_title("ICLR2020 KEYWORDS TOP 50", fontsize=30)  #设置标题

    for y, x in enumerate(dfkeywords["freq"].values):#设置数据标签

        plt.text(x+10, y-0.2, "%s" %x,fontsize=15)

    plt.tight_layout()

    plt.show()  #显示图像

    fig = ax.get_figure()#解决图片显示不全的问题

    fig.savefig('ICLR2020.png', dpi=200)#绘制结果存为图片

    plt.close()   #关闭matplotlib
