# 奇葩！小偷凌晨五点光顾桂林米粉店竟然偷走300个碗…

**现在的小偷简直了，真是不懂他们的世界啊，竟然会偷粉店300个碗去卖十多块钱。偷300个碗真的不容易被发现吗？**

  

![](../Images/64b3cfd60cfb0feff6320d3c523bd100.png)  

  

　　一到年底，小偷这一“工种”就开始加班加点的干！堪称“劳模”。这“劳模”偷的东西也是千奇百怪，堪称奇葩。12月12日凌晨，民主路上一家米粉店就被小偷光顾了，被偷走了几百个碗，这让老板是哭笑不得。小偷偷走的就是我们平时吃米粉的不锈钢消毒碗！而且这一幕还被监控拍得一清二楚！

  

　　被盗店主表示，每掉一个碗要赔给消毒公司4块钱，你如果按300个碗算就是1200，但是如果是卖废品，只能是卖十几、二十块钱 。醉了！偷这个碗也就能卖个十几块钱，小偷可以说是“饥不择食”啊！还是凌晨5点来的，真是“勤劳”。

  

![](../Images/596bbf628c216fb958f92d057e34bcaf.png)  

  

**小偷凌晨五点偷碗**

　　刘先生在民主路上经营一家煮粉店，他的店是24小时营业，12日凌晨5点多，店员在交接班的时候发现，店里的消毒碗居然不翼而飞了。

  

　　煮粉店老板 刘先生：“一般我们一天有一千多个碗吧，然后我们24小时营业的，早上我们6点钟接班，服务员过来上班的时候，就发现那个碗都不见了。”

  

![](../Images/4e55070115fe032b8a5e46297a655f9b.png)  

  

　　发现碗不见了之后，店里的工作人员立马调取了监控录像查看。通过监控看到，当天凌晨5点多，店里陆陆续续有客人光顾，大约5点半左右，一名男子慢慢靠近店门口堆放碗的地方，见没人注意就将碗偷走了。

**商家损失不少**

　　煮粉店老板 刘先生：“碗就是放在这里面，这里每天都有差不多四、五百个碗收回去，每天他又送新碗过来，基本上我们用过的碗就是放在这里面。但是从这件事之后，每天晚上我们的碗就要拿到里面去了，不敢放到外面了。”

  

　　刘先生告诉记者，他共有三家店，其他店偶尔也被人偷过碗，但数量不多，他也就没有在意。这次被偷了几百个碗，让他损失不少。

  

![](../Images/1a2798b48170cbba72cf1a4cd61864e3.png)  

  

　　煮粉店老板 刘先生：“那个碗本来是不值钱，但是我们赔给消毒公司的钱那就多了，因为他要求我们，每掉一个碗是赔4块钱的，你如果按300个碗算就是1200，如果他是卖废品，只能是卖十几、二十块钱 。”

**奇葩小偷啥都要**

　　刘先生说，偷钱偷电脑偷贵重物品的小偷他都听说过，但偷碗贼还真的是第一次碰到，这也让他哭笑不得。

  

![](../Images/c0675b4055ac6052ac8b627028f765a5.png)  

  

　　煮粉店老板 刘先生：“可能是接近过年了，这个小偷碗都要偷，我真想不透，想不明白这个事情，所以我就想爆料一下，然后给这旁边的，还有给广大的我们同样做生意的提个醒，注意防患。毕竟来说，他卖不出钱但是我们去买就值钱了。”

  

![](../Images/3f4a7843fdc088c9332cf0264f34b4c3.png)  

  

　　在这里，我们也提醒广大市民，将近年关，大家一定要多加防患。
