# 

# **            那坡彝族开路经成功列入自治区非遗保护名录**  

在自治区政府信息公开统一平台了解到，自治区人民政府批准确定广西第六批自治区级非物质文化遗产代表性项目名录（共137项），那坡彝族开路经（民间文学类）、那坡壮剧（传统戏剧类）、那坡舞春牛（民俗类）等入列。

  

![](../Images/85ef4629e2a3cc4c6852d6cec2392c85.png)

  

据了解，近年来该县认真贯彻落实国家和自治区出台的非物质文化遗产保护有关政策，以“保护为主、抢救第一，合理利用、传承发展”的工作方针，做好县域内民间民族文化的传承和保护工作。经过积极申报，先后有那坡壮族民歌（国家级）、龙合花炮节、那坡彝族跳弓节、那坡彝族祈雨节等列入自治区级以上非遗保护名录。2016年，该县列入自治区第六批非物质文化遗产代表性项目名录的有那坡彝族开路经（民间文学类）、那坡壮剧（传统戏剧类）、那坡舞春牛（民俗类）等，区级非遗保护名录由3项增加至6项。

凌云县

# **凌云1—11月旅游总收入超9亿元**

今年以来，凌云县委、县政府高度重视旅游业发展工作，以开展创建“广西特色旅游名县”为抓手，着力在旅游项目建设、打造特色产品等方面下工夫，并依托美丽的自然风光和得天独厚的旅游文化资源优势，深入实施“借红推绿”旅游发展战略，加快发展“生态度假游、商务休闲游、乡村民俗游”等多元化旅游产品；强化旅游市场监督和管理，进一步提高旅游综合服务质量；大力开展旅游宣传促销和旅游文化活动，不断吸引区内外游客到凌云县观光旅游，促进全县旅游业保持快速发展态势。据统计，1—11月，该县共接待游客116.86万人次，同比增长26.9%；实现旅游总收入9.32亿元，同比增长39.8%。
