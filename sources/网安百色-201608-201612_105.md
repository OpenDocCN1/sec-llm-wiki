# ATM转账24小时内可撤销，做生意的百色人可要留心了（附新规总结）

以后到银行或支付机构转账时，你需在以下**三种转账方式中选择一种：实时到账、普通到账、次日到账。**

  

但是，如果是在ATM机上转账的话，不管是转给别人还是转到自己的其他银行账户里都要在**24小时后才能到账**。**在24小时内，假如你反悔了或者转错账户了，可以向银行申请撤销转款。**

  

不过，做生意的人可要小心啦！**以后如果在生意上有资金的往来，一定要在24小时收到钱款后，才把货物给对方！**不然要小心赔了夫人又折兵啦。

  

![](../Images/0ddc910da0710593614f655ca533700a.png)

  

**新规内容很多，总结如下（来源：上海房产专业律师）：**

  

1、从2016年12月1日开始，一个人在一家银行，只能办一张储蓄卡（一个Ⅰ类账户）。你现在如果已经有XX银行的储蓄卡了，那12月以后，就不可以再在XX银行办卡。不分同城异地。

  

2、因为每家银行全国只能用一张卡，央行也顺势取消了同行异地存取款、转账的手续费。年底之前执行。（这个新规的效果相当于，手机服务商，取消了漫游费。一张储蓄卡，就可以跑遍全国了。）

  

3、此外，央行还给在ATM机、手机、网银上转账，设置了「障碍」

比如：

（1）、你的银行卡如果超过6个月没用，就无法在银行柜台之外的地方使用了，需要到银行来「解冻」。

（2）、转账时要你选是实时到账、普通到账、还是次日到账；

（3）、在ATM机上转账，不管是给别人、还是给自己的其它银行账户，都要24小时后才能到账；

（4）、一天内转账超过5万元，一定要用key、或者密码器、令牌。像之前凭短信验证码就能转几十万的，12月以后，都不行了；

（5）、个人转账一天内超过30万，公司超过100万，银行会进行一个提醒，确认了之后才能成功。
