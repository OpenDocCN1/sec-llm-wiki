# 伸出援手，帮帮田阳县的这个孩子吧。

来自网友的求助

求助社会爱心人士捐赠，让我儿能重返学校 尊敬的社会爱心人士，你们好！我叫黄海平，家住广西壮族自治区田阳县五村镇百谷村甲屯，育有两个儿子，大儿子黄珊今年7岁半，在百谷小学就读二年级，二儿子黄岩今年两岁多。

当我们跟大家一样过着平凡而快乐生活的时候，可偏偏天有不测风云，二儿子在2015年5月份（那时才9个月大）从床上意外摔下地，当时即送百色市人民医院重症监护室抢救，本来就不富裕的家庭为了给儿子治病，用尽所有积蓄，借尽所有亲戚朋友扔欠下不少外债，做了全程的治疗，最后还是植物人(落下终身残疾，吃喝拉撒无法自理)，现已放弃治疗。

可偏偏屋漏偏逢连夜雨，于2016年11月5日大儿子黄珊跟67岁的爷爷骑摩托车右脚不小心被车轮卡伤，现住百色市人民医院治疗，情况很不乐观，这次更让我们走在雪上加霜的冰路上，眼看要进行几个阶段的手术，这下我们更像热锅上的蚂蚁，生活犹如掉进了万丈深渊，本就负债累累的家庭，去哪凑这昂贵的治疗费用呢？

在万般无奈之下，我求社会有爱心人士，请你们伸出援助之手，帮我度过这个难关，我将一生感激不尽，祝各位好心人士阖家幸福，一生平安！本人电话13558060280，捐款账号6217003450001966900，户名:黄海平，开户行:中国建设银行
