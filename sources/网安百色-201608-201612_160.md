# 小狗被大狗咬伤，大狗主人不赔偿道歉，还咒人家不得好死！！！

来自网友的消息

事情的经过就是11月19号下午三点左右我和我朋友拿车去澳尔玛汽车维修店保养，当时并没有发现店里有大狗。六点半我们去拿车，当时天色已晚，店已经关门了，我们就喊了几声“有没有人？”。

我们的小狗当时是放在地上，没有抱着，这时前方突然冲出来一条大狗，什么品种我也不知道，总之比我们的小狗大了好多倍。大狗的速度非常快，在我们还没有反应过来采取措施的时候，它已经把我们的小狗咬住了。咬了一次之后我们在旁边边赶边大叫，大狗松了一口之后又继续追着咬，这时店里的工作人员才过去抓住他们的狗。

我们去他店里消费狗狗还被咬了，他不赔钱我们自认倒霉，可是他非但没有一句道歉，态度还非常恶劣，他是老板有钱当然了不起，我们斗不过他但是觉得有必要让大家知道事情的真相。

![](../Images/3eade860c5c3280c922b05524030ed9a.png "undefined")

这是我朋友的狗，11月19号那天去城北二路三中坡中间的澳尔玛汽车维修店消费，然后就被那家店的大狗给咬了。

  

![](../Images/97c137276b07d9d142c9e51b89e01494.png "undefined")

老板不但不赔偿，态度还十分恶劣，昨天早上去找他协商，我朋友的妈妈也一起去，竟然当着我朋友的妈妈的面诅咒她妈妈早点死。
