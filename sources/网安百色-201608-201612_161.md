# 广西壮族自治区检察院依法决定对陶荣铅立案侦查

![](../Images/83f397d4cf298cf1332fb26c00dbbdea.png)

日前，广西壮族自治区人民检察院经审查决定，依法对广西壮族自治区百色市人民政府原副市长陶荣铅（副厅级）以涉嫌受贿罪立案侦查，并采取强制措施。案件侦查工作正在进行中。

![](../Images/26d8a3a47b0c0ceeb0858896134fb7a8.png)

陶荣铅，男，汉族，1961年3月生，广西合浦人，1983年8月参加工作，1992年11月加入中国共产党，清华大学热能工程系热能工程专业，大学工学学士。

1978.10－1983.08 清华大学热能工程系热能工程专业学习

1983.08－1985.11 广西电力勘测设计院火电室技术干部、团支书（兼）

1985.11－1990.12 广西防城港区经济发展总公司法律顾问、投资洽谈部副经理、发展部经理、团支书（兼）（1985.04－1987.06在中华全国律师函授中心学习，1989.06取得律师资格）

1990.12－1991.12 广西防城港区计经委规划室副主任

1991.12－1992.04 广西防城港区计经委规划室主任

1992.04－1993.07 广西防城港区计委规划室主任

1993.07－1993.09 广西防城港市计委规划室临时负责人

1993.09－1994.06 广西防城港市计委副主任

1994.06－1998.04 广西防城港市计委副主任、党组成员

1998.04－1998.08 广西防城港市经贸委主任、党委副书记

1998.08－2000.01 广西防城港市经贸委主任、党委书记

2000.01－2002.04 广西防城港市政府副秘书长（正处级）

2002.04－2002.12 广西防城港市政府副秘书长、政府办副主任（正处级）

2002.12－2004.07 广西防城港市发展计划委员会主任、党组书记、西部开发办公室主任

2004.07－2005.06 广西防城港市发改委主任、党组书记、西部开发办公室主任、企沙.东湾工业区管委会主任（兼）

2005.06－2006.06 广西防城港市政府副秘书长、办公室副主任（正处级）

2006.06－2008.12 广西防城港市科技局局长、党组书记、知识产权局局长（兼）

2008.12－2009.02 广西防城港市防城区委员会书记

2009.02－2010.12 广西防城港市防城区委书记、区人大常委会主任

2010年12月任百色市人民政府副市长。

2016.06 涉嫌严重违纪，接受调查
