# 不管在哪儿上班，记住这7个字没坏处

　　态度第一，

　　只有先改变自己的人生态度，人生才能有高度；

　　只有先改变自己的工作态度，事业才能有发展。

  

![](../Images/9185a37ff24bc7110e5b8706ce4ff3c0.png)

  

![](../Images/46cdfd624240b1369d31c96ddc172880.png)

  

　　时刻保持危机感，

　　工作不养闲人，团队不养懒人，

　　当你觉得备受煎熬时，说明你正在成长。

  

![](../Images/506a50285dcf512bd9e7ee53f544a60c.png)

  

![](../Images/a48501ee24bda9b5d290f54feb59d330.png)

  

　　让自己升值，

　　入一行，先别惦记着步步高升，

　　让自己越来越有价值，定会有好位子等着你。

  

![](../Images/6983dd6211f43bbd2de2a7fcf744284a.png)

  

![](../Images/9ef92c5545644632257e681d11999828.png)

  

　　保持积极乐观，

　　没有哪个公司是完美的，没有哪个岗位是轻松的，

　　不管在什么环境，都要主动寻求成长和突破。

  

![](../Images/2955a60c79f56cb3ea6f47b45bc5d73a.png)

  

![](../Images/dc62b29a38ae71a878fa3d146dbbc34e.png)

  

　　豁达处世，别怕受气，

　　干工作，没有哪个是顺利的，受点气是正常的，

　　多思考，如何改变格局和行为，以后不再受气。

  

![](../Images/8d5b765fd2637665b6c85dbc3d5466be.png)

  

![](../Images/438c2ada87515509525f6d621969dbf6.png)

  

　　眼光不要放在钱上，才能赚到钱，

　　赚知识，赚经历，赠阅历，

　　以上都赠到了，想不赠到钱都难。

  

![](../Images/d6c3f3b6bbf489cb4b36a3f5ad745124.png)

  

![](../Images/ec586d330567baa043924ca567084ee2.png)

  

　　让人迷茫的原因只有一个——

　　那就是，本该拼博的年纪，却想太多，做太少，

　　不管你在哪里上班，至少记住一个字——干！

  

  

（来源：励志语录）
