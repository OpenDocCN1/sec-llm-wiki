# 丈夫发现妻子是失足女 诉请离婚获支持

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NzE4ODk1Mw==&mid=2652083195&idx=1&sn=a75cd599c3bda381e6dd929b95a971f3&chksm=f254ef4dc523665b91db39fa3dfeb64259fd8cc8bbb887a8dcb9fd9f33aa56722c8595bfad02&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0NzE4ODk1Mw==&mid=2652083195&idx=1&sn=a75cd599c3bda381e6dd929b95a971f3&chksm=f254ef4dc523665b91db39fa3dfeb64259fd8cc8bbb887a8dcb9fd9f33aa56722c8595bfad02&scene=27#wechat_redirect)

一女子本已为人妻、为人母，但却弃年幼的小孩于不顾，以务工为由长期在外沦为失足女。知道真相的丈夫一纸诉状诉至法庭要求离婚，但女子却称自己是在外是为了挣钱养家，拒绝离婚。日前，经百色市两级法院裁判，判决原告王小明（化名）与被告李小花（化名）离婚，孩子跟随原告生活。

王小明与李小花于2009年登记结婚，次年生育一男孩。此后李小花就长期在外，双方生育的小孩主要跟随王小明生活。王小明向法庭提交了证实李小花沦落为失足女的证据。王小明认为李小花的行为严重伤害夫妻感情，导致夫妻感情破裂。李小花则表示自己之所以沦为失足女，完全是为了养家糊口，自己挣的钱都打给王小明养家，自己对王小明和小孩有着深厚的感情，希望能与王小明继续生活。如果王小明坚持要求离婚，李小花则坚持要求抚养小孩。

王小明与李小花长期未共同生活在一起，王小明亦提交了证实夫妻感情破裂的证据，故法院判决准予两人离婚。小孩出生后长期由王小明照顾抚养，李小花对小孩的生活、教育、医疗等情况过问少，缺少家庭责任和母亲责任，如突然改变生活环境，对小孩成长不利。故法院依法作出上述判决。
