# 德保：狡猾毒贩利用“猪血肠”贩毒获刑

  

近日，广西德保县人民法院公开宣判了一起贩卖毒品案，判处被告人黄某某犯贩卖毒品罪，判处其有期徒刑六个月，并处罚金二千元。

2015年6月，被告人黄某某在德保县一卖猪血肠摊位旁，将藏在猪血肠中毒品出售给吸毒人员时，被公安机关当场抓获。民警在猪血肠中缴获两小包疑似毒品海络因和毒资90元人民币，经计量毒品净重0.13克。

被告人黄某某违反国家毒品管理法规，明知是毒品而非法销售，其行为已构成贩卖毒品罪。根据被告人黄某某的犯罪事实、犯罪情节和对社会危害程度，法院遂作出以上判决。
