# 【本地】德保警方：打掉一赌场 抓获16名嫌疑人

2月21日凌晨4时许，德保县公安局紧急集结70多名警力，对该县城关镇百陇屯涉赌违法犯罪嫌疑人开展集中抓捕行动，共抓获黄某等16名涉赌违法犯罪嫌疑人员，缴获赌具一批，管制刀具1把，有力地震慑了赌博违法犯罪活动，净化了社会风气。
