# 【新闻】广西14岁男孩打110开口就说：“今晚给我嫖一下”！结果……

最近，隆安一名14岁男孩因寻求刺激，连续恶意拨打110、119和122报警电话，侮辱接警人员，严重扰乱警方的正常工作，被警方行政拘留。

  

**接警员:**

你好!有什么事?请说

  

**报警人:**

今晚给我嫖一下

  

今年2月4日，隆安县公安局指挥中心110报警服务台，连续接到一名男子打来的电话，可对方并不是正常的报警，而是用淫秽语言侮辱接警人员。  

  

![](../Images/137215a0f01f205204b10bd5958e7fa4.png)

  

据了解,当地接警人员对他 ，进行了严正的警告，但是他仍然不听劝阻 ，多次拨打110、119 、122进行骚扰 ,每次时间都持续一两分钟。

  

![](../Images/808d67aefcce472ed4acbcda5db27c9e.png)

  

接警员发现，对方是在恶意报警，于是一边拷贝报警录音固定证据，一边根据来电显示，指派派出所民警跟踪调查。很快，这名恶意报警者被警方找到，让警方大吃一惊的是，嫌疑人马某某年仅14岁，还是一名在校学生，而他**拨打报警电话的目的，是为了寻求刺激。**

  

![](../Images/b1ce7013b5e8675ce93ffd5cf5ec95fd.png)

  

警方提醒，市民应树立正确的报警意识，不要假报警、恶意报警，因为恶意拨打110电话，这不仅影响公安机关的正常处警，还会因长时间占用公共资源，导致真正需要报警求助的电话无法打入，延误警情处理。

  

![](../Images/53c3e8e65ae963190f53c88727fdcf55.png)

  

最后，公安机关以扰乱公共秩序对马某某处于行政拘留8日的处罚，因马某某系未成年人,派出所决定对马某某，拘留不执行，同时责令马某某的监护人，对其严加管教。

  

**小编提醒大家，恶意骚扰110是属于违法行为，对拨打110取乐，滋扰公安机关工作秩序， 扰乱公共秩序，或报假警等行为，公安机关将依法严肃处理，对构成犯罪的依法追究刑事责任。**
