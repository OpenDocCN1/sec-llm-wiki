> > > ![](../Images/de15ae43a59fa464ac0332b2889f85d4.png)  
> > > 
> > > 人＝吃饭＋睡觉＋上班＋玩,
> > > 
> > > 猪＝吃饭＋睡觉,
> > > 
> > > 代入：人＝猪＋上班＋玩,
> > > 
> > > 即：人－玩＝猪＋上班.
> > > 
> > > 结论：不懂玩的人＝会上班的猪
> > > 
> > > ![](../Images/6a73400ea8a9e9e4ad66e6f08702410e.png)
> > > 
> > > 男人＝吃饭＋ 睡觉＋赚钱
> > > 
> > > 猪＝吃饭＋ 睡觉
> > > 
> > > 代入：男人＝猪＋赚钱
> > > 
> > > 即：猪＝男人－赚钱
> > > 
> > > 结论：男人不赚钱等于猪。
> > > 
> > > ![](../Images/7728a5856a05cdc9f5e7373cf13c1324.png)
> > > 
> > > 女人＝吃饭＋ 睡觉＋花钱。
> > > 
> > > 猪 ＝吃饭＋ 睡觉。
> > > 
> > > 代入：女人＝猪＋花钱
> > > 
> > > 即：女人－花钱＝猪。
> > > 
> > > 结论：女人不花钱的都是猪。
> > > 
> > > ![](../Images/2dc8eda4b8390a82f728ee3e25c0ba05.png)
> > > 
> > > 综上：
> > > 
> > > 男人为了让女人不变成猪而赚钱！
> > > 
> > > 女人为了让男人不变成猪而花钱！
> > > 
> > > ![](../Images/3443d2085d8d69ebeaa4f2e048a020bf.png)
> > > 
> > > 结论：
> > > 
> > > 男人＋女人＝(猪＋赚钱)＋(猪＋花钱)＝两头猪！！！
