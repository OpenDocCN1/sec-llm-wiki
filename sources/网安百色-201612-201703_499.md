# 捡到加油卡后套现 男子涉嫌盗窃被起诉

靖西男子吴某志捡到一张不设密的加油卡后，将卡内9357.5元的油盗出变卖套现，涉嫌盗窃被公诉。12月16日，靖西市人民法院正式受理了该起盗窃案。

2016年3月17日，吴某志驾驶皮卡车来到靖西市新靖镇一加油站时，在加油机前捡到一张油卡，他随即将该卡插到加油机上查看，发现该卡没设密，且卡内有9000多元余额。环顾左右，见没人发现，吴某志遂起贪念，于当日先后在多个加油站将该卡内9357.5元的油盗走。次日，吴某志将一部分油低价转卖他人，一部分加到自己的车辆上使用，剩余1367公斤柴油装入塑料桶，存放于自家鱼塘内。

过后，失主发现油卡丢失，经查询发现卡已被盗刷，遂报警。很快，警方将吴某志抓获并予以刑事拘留，非法持有的1367公斤柴油依法扣押并发还给失主。

目前，吴某志家属退赔失主的全部经济损失，取得了对方的谅解。此案正在进一步审理中。
