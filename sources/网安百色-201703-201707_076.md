# 电风扇上加个木架子，赶跑蚊子妥妥的……

夏天最让人讨厌的事情

就是蚊子无处不在

不仅嗡嗡嗡的扰人清梦  

还用它那又尖又长的嘴巴叮人皮肤

简直是痒死了  

怎样才能有效防蚊呢

![](../Images/ee3e2d1f0a7c58a9bfc53c9182effc26.png)

苦思冥想、绞尽脑汁

终于想到了一个绝佳的好办法

把普通风扇改造成特效驱蚊风扇  

一起来看看吧

  

**驱蚊水**![](../Images/24739739e0c96d8df6c2033e899c83b5.png)

![](../Images/b1c72c98c8b4b6587716d16eb4afafdd.png)

首先  

在杯子中倒入半杯驱蚊水  

然后把木夹子放入杯子中

  

![](../Images/387195cb19e645b7c0801e89a8924bac.png)

浸泡五分钟左右后取出  

夹在电风扇的铁丝网上

伴随着清爽的凉风

驱蚊水的味道也散发开来

蚊子自然不敢再靠近啦

  

**风油精**

![](../Images/20b40504a8e1f4b9d7f38ebd6a688711.png)

也可以把风油精滴在木夹上  

待风油精渗入木夹后  

把它夹在风扇上

就可以安享好眠啦

  

![](../Images/dc5cddbb726365b04ca41921cabc2d2a.png)

还可以把浸泡过驱蚊水或风油精的木夹子

夹在车载的空调口处

或者在用完了的车载香水内倒入驱蚊水  

这样就不用担心蚊子在开车时骚扰你了

  

![](../Images/8febea40255683abb02ee9616535ca3b.png)

把夹子夹在衣服领口或下摆处

也能有效防蚊哟

  

![](../Images/eaebaa58bb20de14de0591983e728b96.png)

木夹子和风扇结合之所以可以有效驱蚊

是因为木头材质可以吸收液体

而且不易快速挥发

即使不开风扇也可以小范围驱蚊

再配合风扇的气流  

就可以扩大驱蚊范围和驱蚊效果啦

  

好了，本编有预感，这个夹子会不会就此网红！
