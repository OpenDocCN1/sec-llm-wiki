# 南宁市第一批网约车驾驶员证出炉啦！它有什么用呢？

**![](../Images/455b8ac7095d5c67a29b4f571ca8902b.png)**

**第一批网约车驾驶员领取从业资格证**

昨日上午，南宁市行政审批大厅交通运输窗口正式核发南宁市第一批网约车驾驶员从业资格证。

  

据悉，这批驾驶员是在通过了7月3日由市城市客运交通管理处组织实施的首批网约车驾驶员从业资格考试后取得该证的。

  

7月3日，南宁市城市客运交通管理处共组织了2场网约车驾驶员从业资格考试，共133名驾驶员参加了全国公共科目和区域科目（含应用能力考试）两科考试，其中通过全国公共科目考试64人（通过率为48%），区域科目理论考试71人（通过率为53%），区域科目应用能力考试130人（通过率为97%），共47名驾驶员通过全部科目考试，首日考试通过率为35%。考试合格成绩有效期为3年。

**![](../Images/1b962aa18c3e2471af90efa110b32b14.png)**

**网约车从业资格证**

市城市客运交通管理处相关负责人表示，南宁市第一批具有合法从业资格证的网约车驾驶员诞生，是南宁市网约车政策落地以来多方努力取得的工作成效，对于规范发展网约车，加强出租汽车行业管理具有积极意义。

  

据介绍，网络预约出租汽车驾驶员证是从事网约车服务的必要条件之一，注册有效期为3年。驾驶员取得证件后，平时从事网约车经营业务时，需要随身携带证件，持证上岗。

  

针对网约车公司

  

![](../Images/9d76662a10e0736283d7a67db3f0f94b.png)

要求

在网约车平台公司的准入方面，南宁版新规提出，非本市注册的企业法人应当在本市设立分支机构，网络服务平台数据接入市交通行政管理部门的行业监管平台，在本市有与注册车辆数和驾驶员人数相适应的办公场所、服务网点和管理人员。

流程

● 行政审批窗口受理申请后，对申请人提交的材料进行审核。其中，对注册地为本市的企业进行线上和线下服务能力审核；对注册地非本市的企业进行线下服务能力审核。

  

● 审批决定行政审批窗口在得到线上、线下能力审核认定结果反馈后，通报给行业监管机构并征求意见，最后报市交通运输局业务审批会审核通过，做出行政审批决定。

  

● 经市交通运输局行政审批通过后，行政审批窗口向申请人核发“网络预约出租汽车经营许可证”。

  

网络预约出租汽车经营许可办结时限为20个工作日（20个工作日内不能做出决定的，经本行政机关负责人批准，可以延长10个工作日）。

针对车辆

  

![](../Images/729062591e20cb22d7daee6a1b8bb7b0.png)  

要求

除符合交通运输部等部门印发的《网络预约出租汽车经营服务管理暂行办法》要求之外，还必须取得本市公安部门核发的机动车牌照和登记为预约出租客运的行驶证，车辆初始登记日期至申请时未超过3年。

  

新能源汽车轴距要达到2600毫米以上或综合工况续航里程达到250千米以上，非新能源汽车轴距要达到2650毫米以上且排气量大于1.6升（含1.6升）。同时，车辆应在内部明显位置张贴或放置网约车专用标识，并按规定进行车辆年审、二级维护及技术等级评定，符合一级技术等级要求；车辆所有者为个人的，应先取得本市网约车驾驶员从业资格，且名下无尚在经营使用期内的网约车。

流程

网络预约出租汽车运输证核发办结时限为15个工作日。

  

● 受理申请人提交材料、交验车辆5个工作日内，将审核结果告知申请人。

  

● 经审核符合条件车辆的所有人到车管部门申请办理将车辆使用性质登记或变更，符合条件的在受理申请5个工作日内，将车辆使用性质登记或变更为“预约出租客运”。

  

● 行政审批窗口接到车管部门反馈信息后5个工作日内，对使用性质已登记为“预约出租客运”的车辆发放“网络预约出租汽车运输证”。
