# 惨痛！广西一客车突然翻下水库，2人死亡19人受伤！这到底怎么回事！？

**前天（6月15日）上午，桂林全州县境内发生一起客车翻至水库浅水区的道路交通事故。事故造成2人死亡，19人受伤！这到底怎么回事？希望尽快查清楚……**

  

![](../Images/7824474283caf9a957abec0bbd407c0b.png)

  

6月15日10时39分，全州县公安局交警大队接警后，迅速出警赶往现场处置，并通知急救、消防等部门救援。

  

兴安消防官兵赶到现场后，穿戴好水域救援防护装备展开救援，但中巴车在水中无法固定，给救援工作带来不小的难度。根据现场情况，当地政府协调相关部门调集吊车赶赴现场固定事故车辆，以便于展开救援。

  

12时5分，救出1名被困人员。13时25分，吊车到达现场并将事故车辆吊离水面，经过搜寻车内未发现被困人员。消防官兵利用挠钩对涉事水域进行搜寻。13时45分，搜救到1人，经医护人员确认，该名被困人员已无生命迹象。

经现场初步勘察，驾驶员蒋某驾驶桂C319XX客车从资源县往全州方向行驶。当其行驶至全州县境内百资线10KM处，**客车翻于石枧水库浅水区。**

  

![](../Images/3b4b1edaf3c9731629cf13a3ac0c1b39.png)

![](../Images/485db653add6cf075586a09e2e8cc909.png)

  

事故造成现场**死亡2人，伤19人**，其中13人受轻微伤，6人受一般伤。伤员已被送往医院救治。

  

![](../Images/658391d1061a491e20584ef4d5009a60.png)

![](../Images/6c39877e69e7b9c4ed0731726333e186.png)

  

经初步核查，涉事客车车号为桂C319XX，车辆所有人为桂林市骏达运输股份有限公司资源汽车总站，该车核定载客24人，目前查实21人。

  

![](../Images/1c320059b786608d57328524bf80ca22.png)

  

事故发生后，桂林市公安局、全州县政府、全州县公安局、市交警支队、全州县咸水乡政府等相关部门组成的工作组赶至事故现场进行救援和善后。交警、消防、医疗等相关部门也第一时间赶至现场进行处置。

  

现场车辆已经吊装上岸，车内未发现死伤人员。事故正在进一步调查中。
