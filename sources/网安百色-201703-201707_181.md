# 防不胜防！桂林男子颜值太低相亲屡失败，冒用帅哥头像骗女网友裸照……

**找个男朋友怎么就那么难了，陷阱那么多，防不胜防啊！**

![](../Images/fc35d7fb05fb9398ad19ac8a81a90647.png)

30岁的周某有本科学历又有正经工作，按理来说找女朋友不难，结果却因颜值太低，相亲屡屡失败。周某心理十分不平衡，于是心生邪念，盗用帅哥照片，在网上疯狂“撩拐”，最后还发展到骗裸照、诈钱财。昨天，记者从秀峰区法院了解到，周某犯敲诈勒索罪，被判处有期徒刑八个月，并处罚金五千元。  

  

周某是灵川人，生于1986年，本科学历，有一份正当的技术性职业。眼看步入而立之年，周某却一直没找到女朋友，原因就是颜值太低。2016年，周某迫切想解决个人问题，但参加多次相亲，依然因颜值而失败。

![](../Images/17401bc01cf84aba45fb0df060e1876e.png)

心理很不平衡的周某便想出了一个歪点子，把自己打造成帅哥，上网去与女网友周旋。2016年9月，周某在网上下载了一名英俊男子的工作及生活照，用于自己的微信头像和个人网络相册中，然后加进网上的单身群中，很快吸引了多名女子。

  

资源女子美美(化名)就被“变身”后的周某吸引。在周某的甜言蜜语诱惑下，美美拍了几张裸照发送给周某。2016年10月，美美终于见到周某“真身”，发现被骗后，美美扭头就要走。周某企图挽留未遂，威胁美美要将裸照发到网上，还向美美要了600元钱。

![](../Images/3f42b96c66a4dff435a4fdec0c222a0a.png)

在与美美纠缠的同时，周某还以同样的手段骗到了一名柳州美女婷婷(化名)的裸照，并问婷婷要了500元钱，随后还用裸照威胁婷婷来桂林见面。2016年11月5日，婷婷来到桂林。不过在赴约前，聪明的婷婷先去报了案。为了删除自己的裸照，婷婷给了周某3000元，民警见机上前将周某抓获。

  

据周某交代，除了美美和婷婷，他同时还交了另外两名女网友。

  

秀峰法院认为，周某以非法占有为目的，对被害人使用公开隐私相威胁的方法，勒索钱财，数额较大，其行为触犯《中华人民共和国刑法》之规定，构成敲诈勒索罪。

![](../Images/01de96c98dde6904f26c6eeb271873f9.png)

由于周某当庭认罪，有坦白情节，其家属代为退赔被害人损失，酌情对其从轻处罚。最后，秀峰法院依法对其作出判决，判决周某犯敲诈勒索罪，判处有期徒刑八个月，并处罚金五千元;周某退出的赃款六百元返还被害人美美。
