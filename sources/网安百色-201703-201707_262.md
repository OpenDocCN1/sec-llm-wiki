# 你还敢放心的吃吃吃吗？暗访曝光！柳州这些米粉加工厂太脏了……

**最近柳州螺蛳粉大热，各地的人都爱上了这风味独特的粉，然而有些米粉加工厂却没有严格遵守食品生产卫生规范生产。你还敢放心的吃吗？**

![](../Images/8093df32961ff40c30c12f079cb16c39.png)

挂“恒康”厂牌企业的工人，在生产环境相当肮脏的生产线上烘米粉，现场无“三防”设施

  

米粉一直是柳州人喜欢的美食，米粉原料的制作加工是否卫生安全也备受关注。近日，有读者向今报反映，称柳州市柳南区太阳村镇山头村的几家米粉加工企业，存在露天晾晒、生产环境“三防”（防鼠、防虫、防蝇）不达标等问题。记者对此进行了暗访调查。

  

4月15日，记者来到瑞龙路西侧山头村“双眼塘”一带的中小企业集中区。据知情人介绍，该处有多家米粉加工厂，一些厂家虽然已取得了食品生产行政许可手续，但却没有严格遵守食品生产卫生规范生产：不但生产环境杂乱肮脏，甚至存在为了追求产品“卖相”而用硫磺熏烤米粉等现象。

![](../Images/c6a25182c3ef788995540fc8ba60711b.png)

当日，记者在山头村看到，这些米粉加工企业很多都是大门紧闭，从外面很难窥见厂里的真实情况。不过，记者用技术手段从空中查看，发现其中有一些厂家存在露天晾晒米粉的问题。

  

采访过程中，一家加工厂开了门，记者进入该厂实地探访，看到该厂的一条米粉烘干生产线旁，几名工人正在忙着对米粉进行烘干作业，但生产现场没有“三防”设施，生产线地面布满尘土、油污及杂乱工具，生产环境十分肮脏。此外，该厂还有一片露天区域，地面上还平铺晾晒着大量的米粉边角料，有些工人甚至直接在这些边角料上走来走去。

![](../Images/9f696b1bb781abb0041efefc62adcddd.png)

记者现场暗访之后，将情况反映给了柳南区食药监局。4月24日，该局对山头村“双眼塘”一带多家米粉加工企业进行了突击检查。据柳南区食药监局稽查大队大队长黄健光介绍，检查中发现一些问题，已现场责令有关企业整改。

  

据黄介绍，在当地一家挂着“鑫研”厂牌的米粉加工企业里，执法人员检查发现，“三防”设施有瑕疵，该企业生产出来的干米粉，有些放在操作台上，有些则直接摆在地上，不符合食品生产卫生规范的行为，被责令立马整改。一家挂“恒康”厂牌的企业，在检查当天并未开机生产。执法人员检查发现，该厂的生产区无“三防”设施，生产环境的确比较脏乱。黄称，他们在两周之前就向该厂下发过整改通知，目前该厂正在进行扩建，但是有时也会开机生产。对于“粉头”等边角料被平铺在地面上晾晒的问题，经营者称系用于牲畜饲料，并非“回锅”加工米粉。在一家叫“宏捷”的米粉加工企业里，执法人员发现了有米粉露天晾晒问题。对此，经营者称是因遇停电，厂内无法使用烤房烤粉，露天晾晒是一种应急措施。

![](../Images/888e2950dd706244a2fd49207609d423.png)

执法人员还对相关企业的米粉样品进行了现场快检，均没有发现非法添加吊白块、硼砂等有毒有害物质的情况，也没有发现硫磺熏烤的残留成分。但对这些企业存在的问题，均限期要求整改。
