# 用一根牙签去萝卜皮，只要10秒就搞定！

厨房小白每次切菜花的时间比炒菜还长，

今天馆长就教你几招简单方便有易学的方法，

让你做菜变神速~

**![](../Images/8b70edc030dab6fc145e1f8b71502e19.png)**

![](../Images/9e8c2f9ed6c31b12b161cd10a0afafce.png)

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 包 菜**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼包菜的梗不好取出？照着我这样做，轻轻在砧板上一敲，瞧！马上脱落。

  

![](../Images/e9548d2077edde32307797709a13145c.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 萝 卜**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼萝卜去皮，只要用刀在侧边划一个口，再用牙签划深一点，然后就可以轻松将萝卜皮去除。

  

![](../Images/e5aae128761c87011845958efd47e934.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 山 药**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼山药表面总是布满了泥土，只需用揉成团的锡纸摩擦山药的表面，泥土和山药皮就一起剥落了，马上变得光秃秃。

  

![](../Images/7ca2192dcb12d9755a29136efa1fca30.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 莲 藕**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼用揉成团的锡纸来清洗莲藕，泥娃娃洗白白就是瞬间的事~

  

![](../Images/218a724a2d6cf7ee2b3f645c495fe42d.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 青 椒**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼平时都用刀把青椒切成两半再去梗？下次别了，直接用你强有力的大拇指把青椒梗往里按压，一下就剥落了。

  

![](../Images/567255b6d558b6ac422ac32b0dc22e8c.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 洋 葱**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼如果你愿意一层一层一层地剥开我的心...NO!我不愿意，我只想扒了你的皮。剥洋葱皮时，将洋葱顶端先切下，外面的一层皮就可以轻易剥落了。

  

![](../Images/d184ec190a300f95d28790bc3ca42a9a.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 玉 米 粒**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼将一整条玉米变成玉米粒是一件麻烦事？将厨房用纸巾浸湿，然后包住玉米。

  

![](../Images/d1c7f6b19048214adb3b9fc08f8fd3e0.png)

  

▼放入微波炉叮4-5分钟，然后切成三段，再立起来将玉米粒切下。

  

![](../Images/7bf4fd0d72c91878c0d3011c4d169780.png)

  

![](../Images/0bf8e11333e2fc26cc455938610de721.png)** 南 瓜**![](../Images/c315a42b8d68fbc6aada0552ece027ed.png)

  

▼处理南瓜，用刀先把南瓜顶部撬出来，然后再对半切开，挖出中间的南瓜籽。

  

![](../Images/6ff2c286741c431d541f05da06a69d0a.png)

  

▼将南瓜放入电饭煲蒸熟，就可以直接切开食用了。简单粗暴，适合喜欢把南瓜当主食吃的人。

  

![](../Images/c46ff309b3f6b877109b4d2e1b34062a.png)
