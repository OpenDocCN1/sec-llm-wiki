# 惊魂！桂林女子出门十多分钟买个菜，回家2岁女孩竟然不见了……

**妈妈出去买个菜把孩子留给90多岁的曾祖父照看，没想到孩子找妈妈跑出去，老人跟不上，孩子就走丢了，幸亏遇上好心人，父母们要引以为戒啊。**

  

![](../Images/4b82af676c5ebe503012e22991ab93df.png)

近日，一名两岁半小女孩走失后，在胜利路铁路菜市闯进了机动车道，幸而遇到好心人，将她送往附近的派出所。

  

随后，在不到一个小时的时间里，帮小姑娘找家人的相关寻人启事刷爆了桂林人的朋友圈……在众人的帮助下，女孩父母顺利将她接回了家。

![](../Images/51f984e538d261444458a4d1e42cbb34.png)

两岁半女孩独自闯入机动车道

“本人今天上午11:35在胜利路铁路菜市场附近捡到一小女孩，两岁半左右，现在路边的电动车修理店，请朋友们扩散一下。谢谢。”近日，一则寻人启事出现在了不少桂林人的朋友圈，启事下方的图片中，一名穿着红色上衣，黑色长裤，个头十分娇小的女孩神色慌张，不知所措，独自穿行在机动车道上。

  

发布启事的热心人姓伍，上午11点35分，开车路过胜利路，发现了在路边彷徨无措的小女孩。

  

伍先生回忆，当时车辆较多，车速很慢，他分神看了一眼路边，发现了走在人行道上的小女孩。“就只有她一个人，附近也没有大人跟着，看到这个情况，我就多留意了一下。”伍先生说，等到车流又开始动起来时，小女孩竟从人行道走到了机动车道上!伍先生见状，赶紧打亮“双闪”，徒步朝女孩走过去。在这过程中，伍先生拿手机录下了一小段视频。从视频中可以看到，女孩的手拿着玩具，独自走在车来车往的大路中间，对身处的危险浑然不觉。

  

伍先生走上前去一把抱住女孩，带到了路边。“我担心女孩父母在附近，以为我是坏人，就把孩子带到附近的一家维修店。”伍先生说，和店主商量之后，决定在原地等一下女孩父母，但10分钟后仍不见踪影。几人决定报警，将女孩送到了水塔派出所。

![](../Images/33ce85eeadf9842686d291d9d4c84d3c.png)

寻人启事刷爆朋友圈

将女孩抱到路边之后，伍先生便试图通过朋友圈找到女孩的父母。“一开始发了几张女孩走在马路上的视频截图，还有我们等待她父母的那家路边修理店的照片。希望他们看到后能直接找过来。”伍先生说，但等待无果后，他们还是决定先把女孩送到派出所更为妥当。  

  

接着，在警察将女孩接走后，伍先生又拍了几张送女孩上警车的照片，希望女孩家人看到后能放心。并留下了自己的联系方式，“为人父母，发现女儿丢了，肯定很担心了。我也是希望他们看到后能立刻有人联系，可以放下心。”伍先生说。

  

市民杨女士在朋友圈也看到了这则寻人启事。“大中午的，点开朋友圈看到好多人在转发。这么小的孩子，走丢了父母多担心啊，且不说被拐卖什么的，走在路上要是被磕到碰到，父母都不知道要心疼多久。”杨女士说，举手之劳，她也将这则消息发到了几个百人的大群中。随后，很多人都转发到了自己的朋友圈。

  

黎先生是一名城管工作人员，看到这则寻人消息是在城管工作的微信群中。“我们人手多，力量大，最开始也不知道是哪个同事发出来的，很快大家都注意到了这件事，通知在附近工作的同事注意帮忙寻找，希望能帮助小女孩找到家人。”黎先生说。

![](../Images/21365e3a9b320578ae1324145060f19f.png)

暖!丢失一小时父母找回女儿

幸运的是，在女孩送到派出所不到一个小时后，好消息传来，女孩父母找到了。  

  

那么，一个两岁半的小女孩为什么会独自走在机动车道上?女孩的妈妈廖女士告诉了记者事情的原委。

  

原来，廖女士一家就住在铁路菜市附近，昨日上午11点左右，她独自一人出门买菜，将女儿托付给家中90多岁的曾祖父照看。“来回也就十多分钟，没想到会发生这样的事。”廖女士说，在她离开后，女儿哭着吵着要找妈妈，曾祖父只好带着小女孩从家中出来，连电视和房门都没来得及关。然而，老人腿脚不太利索，小女孩找妈妈心切，路上走得飞快，就这么走着走着，两个人就走散了。

  

廖女士回到家中看到房门没关，电视也开着，却空无一人。预感到事情不妙，立马回头在家附近找了两圈，“所有邻居都问遍了，就是没看到一老一小两个人。”廖女士说，随后，她只得又回到菜市去，却只找到了满脸焦急的老人。弄清事情原委后，廖女士立刻拨打了110报警电话。

  

“本来心急死了，没想到电话一打通，接线员告诉我水塔派出所刚送过去一个走丢的小女孩，让我过去确认一下。”廖女士说，一家人开着车连忙赶往派出所，进门一看，正是自家走丢的女儿。

  

“实在是太感谢伍先生这样的热心人了，否则发生了什么意外，后果不堪设想。”廖女士说。随后，伍先生也赶回了派出所，和一家人见上了面。“孩子没事就好，年纪这么小还是时时刻刻要盯牢。”伍先生叮嘱廖女士，廖女士则连连称是。

  

水塔派出所的民警提醒市民，不要将年幼的孩子和老人(尤其是行动不便的老人)独自留在家中，孩子的人身安全时刻要警惕，以免发生意外。
