# 杭州师范大学“2元盖浇饭”坚持12年

在杭州师范大学有一种“2元盖浇饭”，已经推出了12年，从未间断，也从未涨价。“2元盖浇饭”特色窗口的饭菜品质、分量和其他窗口是一样的。10多年来，杭州师范大学多次搬迁，但学校到哪里，“2元盖浇饭”特色窗口就开到哪里。
