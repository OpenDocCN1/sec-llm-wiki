# \[震惊\]5700万用户信息被盗，这家网约车公司竟给黑客10万美元“封口费”！

麻烦缠身的美国网约车服务商优步，最近又爆出一起丑闻。

　　当地时间21号，优步承认2016年底，曾有黑客盗取了5700万名乘客和司机的个人数据。当时优步并未公布这一数据泄露事件，而是向黑客支付了10万美元的“封口费”。

　　21号，优步公司首次向美国联邦贸易委员会告知了这一黑客入侵事件。并开除了掩盖这一黑客入侵事件的 优步首席安全官 乔·沙利文 以及他的一位副手。

![](../Images/b68d8de3a38623209d7bfa65e69769fe.png)

　　优步表示，该事件发生在2016年底，当时，公司储存的全球5700万用户和司机的个人信息被黑客盗取，涉及的具体个人信息包括姓名、电子邮箱以及电话号码。其中，有60万司机驾驶执照细节也一并暴露。为了隐瞒此事，优步向黑客支付了10万美元，以使其删除这些数据。

![](../Images/871bd6107174e5970e8121809206b4d6.png)

　　8月底刚上任的 优步首席执行官 霍斯罗沙希 称，事件发生后，优步立即采取措施保护数据的安全，并进一步关闭了个人未经授权访问系统的入口。

![](../Images/d3f0b6b0ee300a9303628ca29781f4cd.png)

　　优步计划向用户发布一份声明，表示没有证据显示与这起事件相关的数据被用于欺诈或滥用。霍斯罗沙希强调，优步将从中吸取教训。他的目标是改变优步的做事方式。

![](../Images/65f8e706a1924a52eb3b1d617b45d16c.png)

　　这已是优步公司本周内爆出的第二个丑闻。有媒体报道，21号，优步因涉嫌聘请多名不符合资格的司机，而被美国科罗拉多州监管部门重罚890万美元。

![](../Images/2acbcad318e3949d5071eba7e0be0262.png)

　　消息称，优步在过去一年聘请了57名问题司机，当中12人有严重犯罪纪录，17人曾犯下重大交通违规，亦有人因醉驾等问题被吊销驾照，至今仍在没有相关证件的情况下开车。

　　优步称，近日发现在科罗拉多州调查司机背景的程序中出现错误，已开始纠正问题。
