# 百色小媳妇用了这招儿，衣服不管染上什么都能洗掉！必须收藏！

新买的衣服沾上了酱汁？

裤子被溅到果汁？

赶紧学起来，一招就能洗掉它们！

白　醋

  

  

![](../Images/066ac4a15e1f925d39bcefdede27e01a.png)  

白衬衫的领口最容易发黄，用洗衣粉也搓不干净。还有些放在衣柜久了，拿出来有一股旧颜色。  

![](../Images/89607bf13dcafc1d2fea71d0d1f726ed.png)  

和洗衣液一起，倒入一小杯白醋，静置15分钟。

![](../Images/e9376f3b2bb3c4a8140a834d6fab6780.png)  

再洗，你会发现白得和新衣服一模一样！  

![](../Images/705b9bd0571fa67f44af191cbd08f40a.png "3d4e00c5-9371-491b-b0dc-622df7f4dd80.jpg")  

![](../Images/b016b988427c4ab587890da00f372800.png)  

  

  

柠　檬

  

  

![](../Images/57d08fbecda93bc99d674dd34c957f81.png)  

有一些顽固的污渍，不论你多费力去搓洗都还是在那里，有时候一不小心就让衣服发霉留下霉渍，柠檬加水就可以帮你解决。  

![](../Images/db6395ec98ed36893e3f4030551f1a5e.png "fa250a634353fbfe5a2d272415ba0ece.jpg")

将柠檬切片放入水中煮开，然后把衣服浸泡在柠檬水中15分钟。  

![](../Images/941462de8b3bbffd12de13b4ce55f39f.png)  

拿出来后衣服不仅白净如新，还带着一阵柠檬清香！

![](../Images/feee47e309584520bd1c20160a3a13d7.png "Lemon-Dust-Cloths-7.jpg")  

  

  

食　盐

  

  

![](../Images/c7e049fbb2490293170fc79a4ec1fc72.png "LaundryScentBooster.jpg")  

盐除了是调味品之外，还是一种超强污渍清洁剂。特别是油腻腻的饭菜印，一招就能搞定。

![](../Images/f545a97d3462fcd80c520470f1ee47a6.png "d93f6825b96ca551_P1160504.preview.jpg")  

把盐覆盖到油脂上，等待盐把油脂吸收掉，然后轻轻刷掉盐，领口焕然一新。

![](../Images/4c128903ee4d1273ed57adac6926927d.png "b8aa66c19f004e1cb4088a4f89c39761.jpg")

  

  

牛　奶

  

  

![](../Images/97948cd44052eed000552e1d46ed8b90.png)  

上学上班的人，总是会遇到衣服被圆珠笔、钢笔画到的情况。这个时候，牛奶便可以发挥它的作用~

![](../Images/f3bf324d77953f4a30a2852cb8ac5672.png "d48c6ceded5a84670ef8908ecef6ff6f.jpg")

牛奶加热烧开，用棉花擦拭就可以除去衣服上的笔迹渍。

![](../Images/378cba8f29c349eb39b75d31c85ebcc8.png)  

![](../Images/75090b1a61dc8ea7a145f60287ce0fdc.png "12627c3ed7b7ff59d4ad5845aec93742.jpg")

淡淡的奶香，配合干净衣服，身心舒爽。  

![](../Images/f9a0ff676979615fbe179c6232a28b3b.png)  

  

  

洗洁精

  

  

![](../Images/ba476f9e239733af732c81a383468841.png)  

洗洁精具有乳化油污的作用，在去除油垢方面比洗衣粉来得管用！  

![](../Images/6d47f80e11af72789bf8f6eb27d856cc.png "02dca11314519aeec7e6ef3782f7006b.jpg")  

衬衣穿久了，在发黄的地方抹一层洗洁精。  

![](../Images/4c7d4ae52ca836be0bc2e2bffa4c5897.png "02dca11314519aeec7e6ef3782f7006ba.jpg")  

洗衣粉一般很难完全清洗掉，但是拿洗洁精一揉搓就能干净！  

![](../Images/a9a1d51c97d5ff8af02673a286a81f42.png)  

  

  

鸡　蛋

  

  

![](../Images/8b8db52a01ca1d99a8df67b852282572.png "1130772173d6dd2fefl.jpg")

粘上口香糖的时候，巧用鸡蛋，就不会再对口香糖污渍束手无策。

![](../Images/164d38e1c703a8322123168a0b18cd80.png "601d29a04f7890669a5fd29b3d9f8111.jpg")  

需要用到的材料是鸡蛋清。取蛋清抹在口香糖遗迹上使其松散，再擦净。

![](../Images/7150060388aa8952d49df2bb0a6cc96c.png "m3F8A16D1568D4BCD6512CE3B92BC0ECC.jpg")  

此外，用鸡蛋壳浸泡过的热水洗衣服，衣物会格外白净~  

![](../Images/ac39ac77c63959e81a12e1222e2a8ce4.png)  

  

  

大　米

  

  

![](../Images/d8e93d77ac70ad0caa9b2571466d0de4.png "b90da29d355b32ff1d372f63910da28d.jpg")  

用大米来洗涤衣物，是一种古老的叫做浆洗的方法，用这种方法洗出来的衣服据说会更加洁白~  

![](../Images/1c92733d4eb08a85db9ac293df97bc51.png)  

把饭粒和洗涤剂调匀，涂在污处搓洗，最后用清水洗净。  

![](../Images/62f87ad8befcd76991ce369c8c8704fa.png "9c30175511af1042b366a0c885e5a0b4.jpg")

淘米水也是污渍的克星。将洗米水放入锅内煮沸，再放入发黄的衣服，就可以令衣服恢复洁白！

  

  

牙　膏

  

  

![](../Images/3b6eece9bb2ba0e68e66c2e31eb27096.png "How-to-remove-water-stains-with-toothpaste-4.jpg")  

牙膏具有去除油腻、污渍等效果。  

![](../Images/2e64c9734942561282f675592d0abacf.png "Oily-Stains-7.jpg")  

衣服被污渍染上后，挤上一点牙膏，来回揉搓几次。

![](../Images/79a672456b2f6bcf034e6caba3ce6092.png "453108b6024983d3_P1160507.preview.jpg")  

衣物上的茶渍、咖啡渍也可以使用上面的办法，来使衣服恢复崭新~  

![](../Images/7fef392e49ea8e6459e1af529b582e4b.png)
