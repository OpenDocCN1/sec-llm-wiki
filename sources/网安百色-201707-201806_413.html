 01 / 退休金上涨 / 

对象：今年调整的人员范围是2016年12月31日前已按规定办理退休手续并按月领取基本养老金的退休人员（含在2016年12月按规定核定基本养老金并从2017年1月起按月发放的人员）。

补贴：今年总体调整水平为2016年退休人员月人均基本养老金的5.5%左右。预计将有191万多企业退休人员、56万多机关事业单位退休人员受益，共将惠及247万多退休人员。


 02 / 职业资格证书补贴 / 

人才资源和社会保障部、财政部发布了一个振奋人心的通知：所有取得职业资格证书或职业技能等级证书的企业职工，最高可以申请领取2400元的技能提升补贴！

申领标准：

一、职工取得初级（五级）职业资格证书或职业技能等级证书的，补贴1000元；

二、职工取得中级（四级）职业资格证书或职业技能等级证书的，补贴1500元；

三、职工取得高级（三级）职业资格证书或职业技能等级证书的，补贴2000元

四、符合我区紧缺急需职业（工种）的，技能提升补贴标准在一般职业（工种）对应等级的补贴标准基础上提高20%，最高可达2400元。

*同一职业（工种）同一等级只能申请并享受一次技能提升补贴。

申领条件：

一、依法参加失业保险，累计缴纳失业保险费36个月（含36个月）以上；

二、自2017年1月1日起取得初级（五级）、中级（四级）、高级（三级）职业资格证书或职业技能等级证书。



 03 / 高龄津贴免费统一发放 / 

对象：全区80周岁（含80周岁）以上老年人，可享受高龄津贴待遇。

补贴：均可享受高龄津贴待遇。其中，百岁及以上老年人长寿营养补贴，每人每月不低于300元；除此之外，我市民政部门每年还开展各式各样的敬老爱老活动，如重阳节前后慰问百岁老人，并发放慰问金等。

申领流程

申请：符合条件的老年人由本人（其子女或委托他人）携带老人第二代身份证、户口簿向户籍所在地的社区、村委提出申请，填写“南宁市高龄补助申请表”一式3份。

受理、公示：社区、村委负责对申请人的材料进行调查核实，并在本辖区内张榜公示7天。

复审：乡镇人民政府（街道办）根据社区、村委报来的材料进行复审。

审核：各县（区）民政部门、开发区管委会根据乡镇人民政府（街道办）报来的材料进行审核。


 04 / 养老床位补贴 / 

对象 1：非营利性民办养老服务机构一次性开办补助和床位运营补贴。

补贴：用房属自建、购置房屋的，每张新增床位补贴5000元；租赁房屋且租期含5年以上的，每张新增床位补贴3000元。

对象 2：公建民营养老设施，房屋等基础设施由政府投资，运营方投入装修或设施设备。

补贴：补贴标准是3000元。

运营补贴：与养老机构星级、老年人能力等级评定结果挂钩，区分15个档次，给予每人每月60～160元不等的补贴，此运营补贴办法在全国属首创。


 05 / 新能源汽车补贴 / 

对象 1：广西对各市新能源汽车推广应用实行“以奖代补”政策，从2017年1月1日起，对在我市销售、登记上牌的新能源汽车，市财政补贴标准为当年中央财政单车补贴额的40%，对各市进行奖励，奖励资金可用于补充新能源汽车推广应用补贴资金。

对象 2：私家车、出租车、商贸物流配送车、环卫车等，市财政按中央财政补贴额的30%予以补贴。


 06 / 职工医疗互助升级最高15万 / 

《广西职工医疗互助保障试行办法》正式施行，与过去相比，《试行办法》在活动主体、参与对象、操作办法等方面进行了较大调整！


补助标准：在保障期内，参保会员住院自付部分医疗费，住院补助按照不同额度分别以15%、25%、35%的比例给予补助，每个互助保障期限内补助金合计总额最高为15万元；参保会员因意外或疾病身故的可一次性获5000元补助。


 07 / 上调公务员、事业单位工资 / 

公务员中最低级别的办事员，基本工资标准是由630元提至1320元；事业单位中最低级别的工人、专业技术人员、管理人员，基本工资标准分别由610元、630元、3150元，提升至1280元、1320元、6940元。

中小学教师、医院护士的基本工资标准提高10%。此外，不同级别的机关事业单位人员的退休费也都有提高。


 08 / 七大群体激励计划 / 

国务院印发的《关于激发重点群体活力带动城乡居民增收的实施意见》，提出实施七大群体激励计划。


这七大群体包括：技能人才、新型职业农民、科研人员、小微企业创业者、企业经营管理人员、基层干部队伍、有劳动能力的困难群体。


 09 / 取消14项行政收费 / 

1、取消驾校证件、道路货物运单、货运输驾驶员从业资格证工本费；

2、取消医疗机构校验、评审费、医师资格认定费；

3、取消定点医疗机构标牌费和定点医疗零售标牌费、技工学校招生录取费；

4、取消中考招生录取费、各类成人学校毕业证书费、成人高校预科班收费、成人中专学校推荐生实习班费、硕士研究生课程进修班学费、学位论文答辩费。


 10 / 高层次人才补贴 / 

广西将对高层次人才实行分类认定制度(具体办法另行制定)，按照标准分为五个层次，并按照认定的人才层次，在岗位津贴、住房补贴、科研补助、人才激励等方面给予相应支持。

岗位津贴方面：最高每年100万元，连续发放五年

住房补贴方面：最高可享受200万元一次性税后住房补贴

科研补助经费方面：最高一次性补助1000万元

人才激励方面：最高一次性奖励50万元


 11 / 毕业生就业创业补贴 / 

广西壮族自治区教育厅将积极配合人社部门落实对建档立卡毕业生就业创业补贴资金发放，并提高补贴资金标准，补贴资金发放由去年每生960元提高至每生1120元。


 12 / 小排量汽车减少购置税 / 

自2017年1月1日起至12月31日止，对购置1.6升及以下排量的乘用车，继续减免，按7.5%的税率征收车辆购置税。

自2018年1月1日起，恢复按10%的法定税率征收车辆购置税。


 13 / 首套房契税降低 / 

对象1：对个人购买家庭唯一住房(家庭成员范围包括购房人、配偶以及未成年子女，下同)，面积为90平以下的，减按1%的税率征收契税；面积为90平以上的，减按1.5%的税率征收契税。

对象2：对个人购买家庭第二套改善性住房，面积为90平及以下的，减按1%的税率征收契税；面积为90平方米以上的，减按2%的税率征收契税。


 14 / 孕前优生健康检查免费 / 

对象：已婚怀孕妇女


夫妻双方持身份证和结婚证原件到社区审核并开具《免费孕前优生健康检查服务卡》盖章交检查对象，持服务卡即可到各区妇幼保健中心享受免费检查！


 15 / 下调不动产登记收费标准 / 

减半收取登记费：包括不动产更正登记、异议登记；不动产权利人姓名、名称、身份证明类型等发生变更申请变更登记；同一权利人因分割、合并不动产申请变更登记等4种情形。

免收登记费：包括小微企业（含个体工商户）申请不动产登记；申请与房屋配套的车库、车位、储藏室等登记，不单独核发不动产权属证书等8种情形。

只收取证书工本费，每本10元：包括申请宅基地使用权及地上房屋所有权登记；单独申请宅基地使用权登记；夫妻间不动产权利人变更，申请登记等4种情形。


 16 / 首次办理居住证免费 / 

首次申领居住证，不再收证件工本费，办理签注手续也不再收取费用。这样算下来一年能少花不少钱了！


 17 / 轮船票遗失补办免费 / 

2017年1月10日起，《水路旅客运输实名制管理规定》指出，旅客遗失船票，经核对身份后，补办船票免费。


 18 / 宝宝免费接种疫苗 / 

免费疫苗(第一类疫苗)是国家规定纳入免疫规划的疫苗，是儿童必须进行接种的。在本地居住的15岁以下儿童，不论户籍都可以到附近预防接种门诊免费接种第一类疫苗。

接种时请家长带上预防接种证，无证者要及时到预防接种门诊办理。


 19 / 取消公积金贷款收费 / 

根据住建部等部门联合下发的通知，取消住房公积金个人住房贷款保险、公证、新房评估和强制性机构担保等收费项目。


 20 / 降低进口商品关税 / 

我国将对进出口关税进行部分调整，降低金枪鱼、北极虾、蔓越橘等特色食品和雕塑品原件等文化消费品的进口关税。

降低生产抗癌药所需的红豆杉皮和枝叶、治疗糖尿病药所需阿卡波糖水合物的进口关税。


 21 / 普通食盐价格或下降 / 

国务院公布的《盐业体制改革方案》要求，放开所有盐产品价格，取消食盐准运证，允许现有食盐定点生产企业进入流通销售领域，食盐批发企业可开展跨区域经营。

多家机构的研究报告认为，预计普通食盐的价格会由于各方抢占市场出现下降。


 22 / 航班延误享受免费食宿 / 

根据规定，由于天气、突发事件、空中交通管制、安检以及旅客等非承运人原因，造成航班在始发地出港延误或者取消，承运人应当协助旅客安排餐食和住宿，费用由旅客自理。

对象：发生以下三种情况旅客可享受免费食宿服务：由于机务维护、航班调配、机组等承运人自身原因，造成航班在始发地出港延误或者取消；国内航班在经停地延误或者取消；国内航班发生备降。


 23 / 信用卡违约金代替滞纳金 / 

中国人民银行发布的《中国人民银行关于信用卡业务有关事项的通知》将于2017年1月1日起施行。ATM预借现金提现限额从原来的每卡每日累计取现2000元提高至1万元。

银行虽然不再强制收取滞纳金，但还是要对逾期未还的持卡人收取一定数额的违约金，而违约金的数额将“可商量”。


 24 / 身份证异地办理将全面实施 / 

2017年，异地办理身份证将更加方便快捷。按照部署，2017年7月1日，全面实施居民身份证异地受理、挂失申报和丢失招领工作。
