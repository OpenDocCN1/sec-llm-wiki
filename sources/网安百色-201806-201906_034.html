1      最新安全漏洞

1.1 IBMInfoSphere Information Server on Cloud和IBM Watson Knowledge Catalog 加密问题漏洞

漏洞标题：IBM InfoSphere Information Server on Cloud和IBM Watson  Knowledge Catalog 加密问题漏洞

提交时间：2019-05-30

披露/发现时间：

漏洞等级：高危

CVE-ID：CVE-2019-4220

漏洞类别：加密问题漏洞

CNNVD-ID：CNNVD-201905-1092

影响组件: IBM  Watson Knowledge Catalog (with Information Server)11.7.1.0版本和InfoSphere  Information Server on Cloud 11.7.1.0版本

漏洞描述：IBM InfoSphere  Information Server on Cloud和IBM  Watson Knowledge Catalog都是美国IBM公司的产品。IBM  InfoSphere Information Server on Cloud是一套基于云的数据整合平台。IBM  Watson Knowledge Catalog是一套统一的数据目录系统。该系统主要用于快速查找、分类和共享数据等。IBM  Watson Knowledge Catalog (with Information Server)11.7.1.0版本和InfoSphere  Information Server on Cloud 11.7.1.0版本中存在加密问题漏洞。该漏洞源于网络系统或产品未正确使用相关密码算法，导致内容未正确加密、弱加密、明文存储敏感信息等。

安全建议：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://www-01.ibm.com/support/docview.wss?uid=ibm10881197

1.2 Android资源管理错误漏洞

漏洞标题：Android 资源管理错误漏洞

提交时间：2019-05-30

披露/发现时间：

漏洞等级：高危

CVE-ID：CVE-2019-10529

漏洞类别：资源管理错误漏洞

CNNVD-ID：CNNVD-201905-1089

影响组件：Android kernel

漏洞描述：Android是美国谷歌（Google）和开放手持设备联盟（简称OHA）的一套以Linux为基础的开源操作系统。Android  kernel中存在资源管理错误漏洞。该漏洞源于网络系统或产品对系统资源（如内存、磁盘空间、文件等）的管理不当。

安全建议：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：https://www.android.com/

1.3 ZimbraCollaboration Suite mailboxd组件跨站脚本漏洞

漏洞标题：Zimbra Collaboration Suite mailboxd组件跨站脚本漏洞

提交时间：2019-05-30

披露/发现时间：

漏洞等级：高危

CVE-ID：CVE-2018-18631

漏洞类别：跨站脚本漏洞

CNNVD-ID：CNNVD-201905-1088

影响组件：Zimbra ZCS 8.7.11  Patch 7之前的8.6 8.7版本和8.8.10  Patch 2之前的8.8版本

漏洞描述：Zimbra  Collaboration Suite（ZCS）是美国Zimbra公司的一款开源协同办公套件。该产品包括WebMail、日历、通信录等。mailboxd是其中的一个电子邮件组件。Zimbra  ZCS 8.7.11 Patch 7之前的8.6 8.7版本和8.8.10  Patch 2之前的8.8版本中的mailboxd组件存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

安全建议：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：https://wiki.zimbra.com/wiki/Zimbra_Security_Advisories

2      安全资讯

2.1 北约终于忍不住了：面对网络威胁，将采取更积极的方式回应！

小编来报：北约秘书长表示，应对网络攻击的方法不局限于防御，且反击不仅限于网络空间。

据外媒报道，北约秘书长JensStoltenberg在伦敦举行的网络防御承诺会议上介绍了北约应对网络威胁的方案。

JensStoltenberg称，北约正在推进在网络空间所能做的极限，并将对网络攻击采取更积极的方式。北约应对网络攻击的方法不局限于防御，且反击不仅限于网络空间。北约盟国已经同意将国家网络能力或进攻性网络纳入联盟的行动和任务。

北约秘书长称，网络攻击和传统攻击一样具有破坏性。网络攻击可能会瘫痪关键的基础设施、破坏民主，并给经济造成数十亿美元的损失，且网络攻击变得越来越频繁、复杂和更具破坏性，但北约应对网络攻击的条件仍未正式确定。

联盟目前正在建设网络司令部，将在2023年全面运作，该司令部将协调和执行联盟的所有进攻性网络行动。美国网络司令部表示，北约司令部全面运作之前，北约或将依靠盟友进行进攻。

2.2 世界上最危险的笔记本电脑价值多少？134.5万美元！

小编来报：一台装有6个最危险恶意软件的笔记本电脑在拍卖会上售出，该笔记本电脑中的恶意软件造成了总计950亿美元的经济损失。

据外媒报道，被拍卖的笔记本被称为Persistenceof Chaos，是一台10.2英寸的三星NC10-14GB笔记本电脑，运行WindowsXP （SP3）操作系统，是目前世界上运行着Windows XP的最危险的计算机。这台世界上最危险的笔记本电脑最终以134.5万美元的价格成交。

Persistence of Chaos是由艺术家Guo O Dong和网络安全公司DeepInstinct合作创作，公司提供恶意软件和专业技术，在一个安全的环境中创造了这个“艺术品”。GuoO Dong在接受采访时表示，这款笔记本电脑将数字世界带来的抽象威胁转化成为现实。

你可以看到这台笔记本电脑的实时运行状态，但它与互联网隔离，以防止恶意软件传播。只要不连接到Wi-Fi或插入USB，它非常安全。

笔记本电脑中的六大恶意软件

ILOVEYOU

1

ILOVEYOU

2000年，ILOVEYOU，也被称为Love Bug，把自己伪装成情书，利用人性，欺骗收件人打开。仅仅几个小时后，全世界的计算机系统就被这种病毒所感染，造成了约150亿美元的损失。

2

SoBig

2003年8月，SoBig病毒出现，感染了全世界数百万台电脑，造成371亿美元的损失。SoBig还演变了好几次，很难被控制。

3

MyDoom

MyDoom（又称Novarg）病毒是一种蠕虫，它可以在受害者计算机的操作系统中创建后门。最初的MyDoom病毒有两个触发器，其中一个触发器导致病毒从2004年2月1日开始DoS攻击。

4

WannaCry

WannaCry勒索软件在世界各地的许多国家爆发，俄罗斯、乌克兰、印度在内的国家都受到了Wanncry勒索软件的严重打击。

5

BlackEnergy

BlackEnergy使用了注入技术、加密技术和被称为“dropper”的模块化架构，对乌克兰进行了网络攻击。

6

DarkTequila

这款恶意软件以窃取银行凭证和公司数据而闻名，即使数据是离线的，它也会对数百万用户造成损失。
