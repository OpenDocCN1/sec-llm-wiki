今日CNNVD共发布安全漏洞41个。主要影响厂商为美国IBM（3个）、美国NVIDIA（3个）。主要影响产品为IBM Financial Transaction Manager for Corporate Payment Services金融事务管理器（1个）、NVIDIA Windows GPU Display Driver驱动程序（3个）。

**今日需关注的典型漏洞如下:**

**【漏洞名称】******IBM Financial Transaction Manager for Corporate Payment Services 跨站请求伪造漏洞****

**【漏洞编号】******CNNVD-201905-214********（CVE-2018-1790）****

**【漏洞详情】**IBM Financial Transaction Manager for Corporate Payment Services是美国IBM公司的一款用于企业付款服务的金融事务管理器。

IBM Financial Transaction Manager for Corporate Payment Services 3.0.2.0版本至3.0.2.1版本中存在跨站请求伪造漏洞。该漏洞源于WEB应用未充分验证请求是否来自可信用户。攻击者可利用该漏洞通过受影响客户端向服务器发送非预期的请求。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www-01.ibm.com/support/docview.wss?uid=ibm10731607

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-214

  

**【漏洞名称】**************NVIDIA Windows GPU Display Driver 安全漏洞************  

**【漏洞编号】**********CNNVD-201905-231********（CVE-2019-5677）********

**【漏洞详情】**NVIDIA Windows GPU Display Driver是美国英伟达（NVIDIA）公司的一款专用于Windows平台的图形处理器（GPU）显卡驱动程序。kernel mode layer (nvlddmkm.sys) handler是其中的一个内核模式层处理程序。

NVIDIA Windows GPU Display Driver中的kernel mode layer (nvlddmkm.sys) handler（用于DeviceIoControl）存在安全漏洞。攻击者可利用该漏洞造成拒绝服务。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.nvidia.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-231

  

**【漏洞名称】******EnGenius Technologies EWS660AP 安全漏洞****

**【漏洞编号】**********CNNVD-201905-223**************（CVE-2019-11353）******

**【漏洞详情】**EnGenius Technologies EWS660AP是美国EnGenius Technologies公司的一款无线接入点设备。

使用2.0.284版本固件的EnGenius Technologies EWS660AP中存在安全漏洞。攻击者可利用该漏洞执行任意命令。

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.engeniustech.com/

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-223

  

**【漏洞名称】********Synology Calendar 信任管理问题漏洞******

**【****漏洞****编号****】********CNNVD-201905-220（**CVE-2019-11820）****

**【漏洞详情】**Synology Calendar是中国台湾群晖科技（Synology）公司的一款运行在Synology NAS（网络存储服务器）设备上的文件保护程序。

Synology Calendar 2.3.3-0620之前版本中存在信任管理问题漏洞。该漏洞源于网络系统或产品中缺乏有效的信任管理机制。攻击者可利用默认密码或者硬编码密码、硬编码证书等攻击受影响组件。

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://www.synology.com/security/advisory/Synology\_SA\_19\_21

**【漏洞链接】**

http://www.cnnvd.org.cn/web/xxk/ldxqById.tag?CNNVD=CNNVD-201905-220
