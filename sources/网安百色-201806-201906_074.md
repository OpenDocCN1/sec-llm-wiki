# 南宁网安破获全国首例利用自制软件非法获取信息的新型网络案件！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NzE4ODk1Mw==&mid=2652088396&idx=1&sn=62c101574db3e8e547fb0bb9ae75961b&chksm=f254d4fac5235dec972c7592d0a947c3e44c4bc1d1bb9d48c0d33441f94d914810ed8874f0e5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0NzE4ODk1Mw==&mid=2652088396&idx=1&sn=62c101574db3e8e547fb0bb9ae75961b&chksm=f254d4fac5235dec972c7592d0a947c3e44c4bc1d1bb9d48c0d33441f94d914810ed8874f0e5&scene=27#wechat_redirect)

近期，南宁网安破获全国首例利用自制软件非法获取并贩卖公民个人信息的新型网络案件。该案主要犯罪嫌疑人韦某利用自制软件非法获取公民个人信息，并向宾阳县内的电信网络诈骗犯罪团伙大量出售，一年获利近50万元。

![](../Images/6bd9a90eab836fc2470c34420127ce4f.png)

  

2018年11月，南宁市公安局网安支队针对近期案件高发的**冒充学生诈骗学生家长培训费**类型诈骗开展深入调查。经过数月的线索摸排和证据整合,发现近期被打击的诈骗窝点嫌疑人均向一名为“客服X”的QQ购买学生家长QQ群资料用于冒充学生诈骗家长培训费。

  

经进一步调查发现，韦某利用自编程软件“某某大师”，非法获取公民个人信息，并将信息向宾阳县辖区内的电信网络诈骗犯罪团伙分销，用以作案。其妻子顾某则以“客服X”为名，与宾阳的电信网络诈骗犯罪团伙联系，进行售卖。

  

网安支队立即组成专案小组,围绕主要嫌疑人韦某展开调查。经过长期的走访调查，发现**嫌疑人韦某原从事编程工作供职于某互联网公司，有自主开发软件能力，其于2017年被裁员下岗。之后便利用自己编写的“某某大师”软件进行木马植入用于盗取QQ群成员信息并进行贩卖。**

  

通过审讯涉嫌诈骗的嫌疑人得知，**韦某通过QQ与从事冒充学生诈骗嫌疑人联系，贩卖学生家长QQ群资料信息**，嫌疑人韦某收到订单后从软件后台的数据库中整理学生家长QQ群资料进行交易。

  

为了锁定嫌疑人和防止嫌疑人销毁证据，专案组成员开展了长达几天几夜的摸排，等待抓捕时机的成熟。2019年3月26日8时许，南宁市公安局网安支队联合相关单位在南宁市青秀区某小区抓获侵犯公民信息嫌疑人韦某、顾某夫妇，现场查获作案使用台式电脑一台，作案手机三部，涉案银行卡一批。

  

![](../Images/666bf08bb078c6b8fdf651ec152197e7.png)

  

在抓捕现场，嫌疑人韦某对其制作木马用于盗取客户Q群信息以及出售QQ群成员信息的违法行为供认不讳。并供述其与顾某主要通过三个QQ号开展业务，为宾阳网络诈骗犯罪团伙所需的软件应用服务类型提供分类定制服务。

  

![](../Images/603c6aafdc6d3334acf3b685e6cfc41d.png)

![](../Images/2aba13f148f073512809e8f96d880b37.png)

  

经对嫌疑人韦某、顾某夫妇涉及的下线网络诈骗犯罪团伙进行调查，发现共有13个宾阳籍网络诈骗犯罪团伙向其购买QQ群资料。专案组于 2018年12月3日开展打击、收网行动，至2019年3月26日已陆续捣毁25个电信网络诈骗窝点，抓获犯罪嫌疑人42名，均已另案处理。缴获作案笔记本电脑38台、作案手机75台，银行卡、无线上网卡一批。

  

**南宁网警在此提醒广大市民朋友，在日常生活中要加强对个人信息保护，防止意识不强导致信息泄露。**

  

**预防个人信息泄露，应该注意以下几点：**

（1）网上购物尽量到正规、大型网站，并仔细检查网址，不轻易接收和安装不明软件，不随便点击聊天中对方所发来的链接，填写银行帐户和密码时要十分谨慎，防止个人信息泄露；

![](../Images/8000e85fffafb05d0da5b65f922d1917.png)

  

（2）填写个人简历只写必要信息，尽量不要写的太过详细，同时还要注意查看求职平台和企业是否正规；

![](../Images/a4bfc1fba44272d65753fd8fe2b21887.png)

  

（3）身份证等证件复印时一定要写明用途，防止被他人利用；

![](../Images/d744f7e6d004b5b0a23410c5a0e18766.png)

  

（4）妥善保管、处理好包含个人信息的票据，如快递单、火车票、飞机票、保险单等；

![](../Images/4b105e6cd0a18290736c0d1857caa337.png)

  

（5）不要贪图小便宜，避免在网上或者街头参加一些需要填写真实身份、手机号码等个人信息的抽奖、竞猜、促销送礼品等活动；

  

（6）尽量不要在朋友圈通过视频、照片、文字等形式暴露自己的真实身份、家庭住处、单位地址、子女情况等信息，不添加不明身份的好友；在与陌生人聊天时，特别注意保护好自己的个人信息，不要轻易提供；

  

（7）进行网上支付时，尽量避免使用不安全的WIFI网络，可使用流量或者经过公安备案的安全wifi以确保支付安全；

![](../Images/4c650643602e7b0c7c41c655f0864b70.png)

  

（8）不要在各类网上网下平台、商场随意留下自己的联系方式等个人信息，避免可能产生的大量骚扰电话而影响你的正常工作；

![](../Images/3542b5c7b472948177cd28eea60cc4e7.png)

  

（9）不要随意丢弃或出售未经处理包含个人信息的手机。

![](../Images/de6df7c84da9df776ccb9d7a8177e5ad.png)
