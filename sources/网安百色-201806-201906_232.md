# **1\. ****摩拜：“裁员30%”传闻严重不实，部分岗位还在招聘**

针对“裁员30%”的报道，摩拜单车回应：信息严重不实，公司对此保留追究法律责任的权利。针对裁员传闻，摩拜称，此举属正常业务调整，部分岗位仍在招聘中，“在与美团合并后，把绝大部分精力放在修炼基本功，更加重视用户体验，和对资产盘点、运营、维护的有效性。”

# **2\. ****日本将允许高度自动驾驶车上路，或于2020年上半年开始**

日本国家警察厅公布了一项法案草案，将允许具高度自动驾驶功能的车辆在公共道路上行驶，并且计划于2020年上半年实施该法案。该法案将允许政府归类为3级自动驾驶的车辆在公共道路上行驶。在早期阶段，日本政府可能只会在公路发生交通堵塞期间，允许使用3级自动驾驶技术。

# **3.百度百盈开卖基金，首批上线5款产品**

近日，百度旗下度小满理财平台正式上线5款基金产品，包括两只股票型基金和三只混合型基金。度小满理财官网显示，首批上线的基金包括广发百发大数据价值混合E、广发中证百发100E、广发百发大数据E 、广发中证500交易型开放式指数联接基金、嘉实沪深300ETF联接基金。11月29日，百度取得经营证券期货业务许可证。

**4\. ****百度网盘：若未来一年不登录，2TB空间将减到100G**

百度网盘发布通知称，2018年12月25日至2019年12月31日期间，未登录过百度网盘帐号的用户，已获得的2T免费存储空间将从2020年1月1日开始调整为100G；若存储文件超过100G，将仅支持下载和访问已存储文件，无法存入新文件。

# **5\. ****阿里健康近2亿元入股德生堂**  

阿里健康宣布，与甘肃德生堂订立增资协议。据此，阿里健康（中国）将向德生堂注入现金人民币1.88亿元，增资协议交割后，阿里健康将持有目标公司10%权益；双方将共同为德生堂的地区药房探索和扩展新零售模式，全渠道触及医药零售市场更多消费者。今年以来，阿里健康已陆续参投山东漱玉平民、安徽华人健康、贵州一树等区域连锁龙头药店。

# **6. ****音乐社交App“音遇”获数千万美元融资**

音乐社交App“音遇”已完成数千万美元融资。据接近此次交易投资人的消息称，本轮融资由红杉资本和高榕资本共同领投，投后估值超过2亿美元。音遇于今年11月正式上线，上线以来，一路攀升至App Store社交榜第一名、总榜第二名。据QuestMobile提供的数据，截至12月16日，音遇的DAU已达85万。

# **7.**** Alphabet剥离能源存储项目Malta，获马云参投基金投资**  

诞生在Alphabet旗下X部门的可再生能源存储项目Malta，剥离为一家独立公司，获得2600万美元的A轮投资，领投投资方是由马云参与投资成立的突破能源基金，参与投资方还包括Concord新能源集团和Alfa Laval。Malta将利用募集的资金与业界合作伙伴合作，建造其第一个试验性系统。

# **8.调查：中国对自动驾驶接受程度最高**

汽车供应商大陆集团近日公布的一项对不同国家自动驾驶汽车接受度的调查显示，中国对自动驾驶技术的接受度最高，美国和德国对该技术的接受度反而较低。数据显示，89%的中国调查对象表示支持自动驾驶技术，德国和美国调查对象分别为53%和50%。

# **9\. ****蚂蚁金服设立5亿元教育专项基金**

蚂蚁金服近日在官方微博上宣布，花呗启动年轻人成长计划，与商家共同设立5亿元教育专项基金，2019年将面向45岁以下的成年用户，提供用于职业培训课程的分期免息服务。这一教育专项基金计划全年服务1000万人次。
