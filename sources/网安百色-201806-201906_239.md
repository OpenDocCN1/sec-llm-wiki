# **1. **苹果供应商反诉高通案明年开庭 索赔90亿美元****

苹果与高通在中国“交战”之际，苹果的4家供应商在美国本土也和高通进行着“另一场战争”。  明年春季，苹果的供应商在美国提起的一项反垄断诉讼即将开庭，要求赔偿金额为90亿美元。负责该案的律师对记者表示，根据美国法律该案的判罚金额可以达到三倍，即270亿美元。  2017年7月18日，苹果四大供应商纬创、仁宝、和硕和富士康母公司鸿海精密把高通告上了法庭，声称高通违反了反垄断法。具体而言，这些公司指责高通违反了《谢尔曼反垄断法》（ShermanAct），这是美国在1890年通过的一项联邦法，“旨在将自由竞争作为贸易的基本规则”。

# **2. ********云丁科技完成6亿D轮融资 发布高端门锁新品 售5188元******  

今天，云丁科技在京举办新品和战略发布会，正式宣布获得由百度领投，顺为、SIG、险峰等跟投的D轮6亿元融资；同时发布了高端旗舰款新产品Touch2 Pro，售价5188元。  云丁科技CEO陈彬表示，融资主要用于积累实力，云丁并不是一直在烧钱，2017年云丁就已经实现了盈利，2018年全年盈利。  在产品方面，云丁科技创始人兼总裁张东胜表示，Touch2 Pro将触控屏融合进智能门锁产品，安全性上，触控屏可随机变换数字排列位置，操作上，用户可以通过触控屏进行本地可视化设置；个性化体验上，可根据自己喜好定制专属个性化主题、解锁动画、短视频留言等。

# **3. ****谷歌宣布斥资10亿美元在纽约建新园区**  

谷歌已经证实了在纽约市的主要扩张计划，准备投资逾10亿美元。这是其更广泛扩张计划的一部分，谷歌希望在未来10年将其在纽约的员工数量增加一倍。谷歌表示，该公司已在下曼哈顿地区（Lower Manhattan）哈德逊大街315号和345号签署了租赁协议，此外还签署了收购华盛顿街550号附近一处房产的意向书。

# **4. ****Nuro推出全球首个面向大众的无人驾驶汽车送货服务**

2018年12月18日，硅谷无人驾驶公司Nuro与生鲜连锁超市Kroger宣布，推出全球首个面向大众的无人驾驶汽车送货服务。  自今年8月起，Nuro和Kroger在亚利桑那州的斯科茨代尔市开始了无人驾驶送货服务的试运营，提供服务的是有安全操作员乘坐的普锐斯自动驾驶车队，至今已完成了约一千次的配送服务。今天推出的是全无人驾驶汽车送货服务，Nuro的自动驾驶车队将会逐渐增加Nuro设计制造的无人驾驶配送车R1，在公共道路上行驶的R1将没有司机、没有乘客，只有运输的货物。
