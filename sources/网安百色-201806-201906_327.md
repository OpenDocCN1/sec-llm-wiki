# **GPG邮件更新竟跳转为付费软件**

  

![](../Images/86e7fd7dc7315849c8e23f8148087ba5.png)

  

近日，Mac用户在升级GPG邮件时惊讶发现已改用付费套餐。原来，在升级到GPG Mail 3后，这款应用的服务不再是免费的，30天试用期结束后，需要支付30美元购买全部功能。这一升级让大量用户感到意外，均指责开发人员未能提前告知。GPGTools应该发布说明是付费软件，而不是将其包装为定期更新，并将有关付费计划的信息放在一个不显眼的位置。*\[来源：bleepingcomputer\]*

# **思科视频监控软件发现严重漏洞**

  

![](../Images/5a2ed78b9fe3cd0bbf596feabea0af54.png)

思科视频监控管理软件的被爆严重漏洞，该漏洞可让未经身份验证的远程攻击者在目标系统上执行任意命令。思科在上周发布的咨询报告中表示:“该漏洞是由于在某些系统上存在受感染软件的根帐户的默认静态用户凭证，攻击者可以利用这个漏洞，通过使用帐户登录到受影响的系统。”目前还没有解决这一漏洞的办法，但思科在最新版本的软件中发布了补丁。*\[来源：threatpost\]*

# **Adwind木马绕过反病毒软件感染用户电脑**

# 

  

![](../Images/6cbe8b7aeef313370bb5524724456f36.png)

  

周一，来自Cisco Talos的网络安全研究人员共同公布了对Adwind木马最新活动的调查结果。Adwind是一款远程访问木马(RAT病毒)，之前曾被用于攻击世界各地的工业，现在它又带着一个新的工具包回来了，这个工具包设计用来欺骗反病毒程序，让恶意软件利用系统。Adwind木马是一种恶意软件变体，包含了各种各样的“技能”，包括：收集电脑信息和按键、窃取通过网络表单提交的凭证和数据、录制视频、篡改系统文件和传输内容。考虑到加密货币这一有利可图的领域，Adwind现在也可以尝试窃取密码密钥，以访问受感染系统上的加密货币钱包。*\[来源：threatpost\]*

**超过20亿台设备仍易遭受BlueBorne攻击**

  

![](../Images/0e67abf8ad0ed764c09c8aa6f8ec7ef0.png)

Armis Labs的研究人员发现新型攻击技术BlueBorne，其将目标瞄向包括运行Android、iOS、Windows和Linux在内的移动设备、桌面设备和物联网设备。BlueBorne将这些设备暴露在新型远程攻击当中，甚至无需借助用户交互和配对。实施BlueBorne攻击的条件是目标系统须启用蓝牙功能。据研究人员透露，在继发现蓝牙漏洞BlueBorne一年之后，仍有超过20亿台设备易遭遇此类攻击。*\[来源：E安全\]*

**日本加密货币交易所遭黑客攻击，损失6000万美元**

  

![](../Images/3ed0c8330b3b810d313f86c139804880.png)

  

近日，日本加密货币交易所Zaif遭到黑客攻击。在持续了两个小时的攻击当中，攻击者窃取了价值6000多万美元的加密货币，黑客攻击中被盗的加密货币包括比特币和Monacoin。据悉，该交易所已下线进行调查。*\[来源：securityweek\]*

# **外媒：特朗普的国家网络战略获专家称赞**

  

![](../Images/3028d48b88b015a975daa661d0eeb7fe.png)

  

特朗普于9月20日公布了新的国家网络安全战略，该战略得到了政界、业界各方赞扬。政界认为此次出台的国家网络战略表明，特朗普的网络战略正在成型，即美国治网向着更“主动”的方向转变。企业界认为这是有史以来发布的最全面的网络安全战略文件，坚定地阐述了美国通过合作或武力手段确保网络安全的愿景。*\[来源：Fifthdomain\]*

**美众议员提出新法案以解决网络安全人才不足**  
  

![](../Images/e03a710ce9d6bd71409dc9708b84c30e.png)

  

网络安全劳动力短缺问题严峻，美国对该问题的关注度不减。近日，美国众议员提出一项网络劳动力法案，其旨在通过资助学徒计划，解决网络安全劳动力短缺的问题。这项新的立法将帮助在美国劳工部内设立一个资助项目，以便在竞争的基础上向劳动力中介提供资助，其目标在于创建、实施并拓宽网络安全学徒计划。*\[来源：E安全\]*
