# 西安单身妈妈网恋陷赌博网站骗局与友被骗60余万

      单身妈妈张澜（化名）最近摊上了大事，她在5天时间里被自己的网络“男友”骗走了9万余元，她的朋友也因陷入这场骗局损失了58万余元。

  

      张澜告诉记者，她在6月14中旬经网友介绍，通过微信认识了一名自称李某的男子，二人很快确认了恋爱关系。李某自称做IT行业，并称他在工作过程中发现一家网站存在漏洞，可以从中赚取“零花钱”。张澜按照李某要求帮他操作一个账户，该账户很快便赚了4万余元。

  

张澜称，此后，她与朋友陆续在该网站充值60余万元，但这些钱最终因为李某失联、网站关闭而没了踪影。

  

7月11日，西安市公安局莲湖分局相关负责人告诉澎湃新闻，接到张澜报案后该局枣园派出所已经立案，案件目前正在侦办当中。

  

微信认识IT“男友”

称能利用网站漏洞赚钱

![](../Images/beb8ee6a60ce347af37f0bc62a0c417f.png)

  

张澜家住西安市莲湖区，自2016年离婚后，她一直独自一人带着孩子。她告诉澎湃新闻，今年6月14日，他的一名网友突然联系她称想给她介绍对象，“我因为自己带孩子非常辛苦，也迫切希望能尽快组建新的家庭，便接受了网友的好意。”

  

经这名网友介绍，张澜认识了一名自称李某的男子，二人经过聊天熟识后很快确认了恋爱关系，“他在微信中告诉我他是西安人，做IT行业的，目前正在广东出差，很快就能回来见面。”

  

张澜说，在与李某认识的最初几天两人交流非常愉快，李某也对她非常关心，偶尔会视频聊天，“但视频时，他那边光线始终很暗，看不清脸。”

  

6月20日，李某突然要求张澜在手机上下载一个2345浏览器，并发给她一个网站，希望她能帮他操作一下账户。张澜说，获取到李某的账户及密码后，她登陆到这家网站后发现，网页上显示“太阳城集团”几个大字，下面有重庆时时彩、快乐十分钟等链接，“李某说他在负责给这家网站做维护，发现其中存在漏洞，让我按照他的指示操作账户。大概四五十分钟之后，他的账户上就多了4万多元。”

  

和朋友陆续充值60余万元

“男友”失联网站关闭

![](../Images/beb8ee6a60ce347af37f0bc62a0c417f.png)

  

      张澜说，在6月20日那次操作后，李某建议她可以自己申请一个账户，利用网站漏洞赚些零花钱。她担心网站充钱不可靠，曾尝试用李某的账户提现，发现该网站确实可以实现余额体现，“速度很快，几乎是瞬间到账，我就自己创建账号并充了9000元，充值成功后，我还尝试用自己的账户提现，也成功了。”

  

之后几天，张澜陆续向这家网站中投入97000元。在张澜利用“网站漏洞”操作账户“赚钱”期间，她的朋友张先生看到后，也加入其中。张先生在该网站的充值记录截图显示，他在6月22日到6月23日两天时间里，先后分14次在网站充值共计896700元，另分两次提现了31万元。张澜说，到6月25日时，她的账户中显示的余额已有177000元，而她朋友账户中剩余的586700元已经超过百万。但此时，他们在网站中申请提现时网页却始终显示“申请中”，并没有资金到账。

  

“一直等不到钱到账，我就打电话给李某想问问怎么回事，但这时候他的电话已经打不通了，几天之后，连这个网站也关闭了。”张澜说，发现这些问题后，她与朋友立刻向公安机关报警，“事后，经过民警提醒，我才知道那个网站是一个网络赌博网站，重庆时时彩这些都是网络赌博项目。”（陈雷柱）
