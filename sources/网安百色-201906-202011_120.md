# NSA/CISA联合报告警告关键工业系统以防遭到攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NzE4ODk1Mw==&mid=2652088897&idx=1&sn=607d8c2482655216881d864335c2aeb7&chksm=f254d6f7c5235fe1a525389eaf831d02252fcad4a85a32d4247d7241bc2a3edd2952495911dc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0NzE4ODk1Mw==&mid=2652088897&idx=1&sn=607d8c2482655216881d864335c2aeb7&chksm=f254d6f7c5235fe1a525389eaf831d02252fcad4a85a32d4247d7241bc2a3edd2952495911dc&scene=27#wechat_redirect)

美国国家安全局（NSA）和网络安全与基础设施安全局（CISA）发出警报，警告针对整个美国关键基础设施的网络攻击。

  

NSA / CISA发表的联合咨询报告说：“近几个月来，网络参与者表明了他们继续通过利用可访问互联网的运营技术（OT）资产对关键基础设施（CI）进行恶意网络活动的意愿。”星期四。“由于对手能力和活动的增加，对美国国家安全和生活方式的重要性以及旧约系统的脆弱性，民用基础设施为外国大国提供了有吸引力的目标，这些外国大国企图损害美国利益或报复美国的侵略行为。”

  

美国机构敦促关键基础架构的所有者和运营商采取必要措施，以提高关键环境中使用的美国系统的弹性和安全性。美国国家安全局（NSA）和CISA建议，所有国防部，国家安全局（NSS），国防情报局（DIB）和美国关键基础设施应立即采取行动，以保护其OT资产。

  

攻击者针对的是特定设备，即Triconex TriStation和Triconex Tricon通信模块，这些模块广泛用于工业环境中，例如发电厂，工厂，石油和天然气精炼厂。

  

在单独的安全公告中，ICS-CERT警告施耐德电气Triconex TriStation和Tricon通信模块中存在严重的安全错误。

  

这并不是野外威胁者首次将这些系统作为攻击目标。

  

2017年12月，FireEye的研究人员发现了一种名为Triton恶意软件（又名Trisis）的新恶意代码，该恶意代码专门针对工业控制系统（ICS）系统设计。

  

CyberX的安全专家对恶意软件的样本进行了分析，提供了有关攻击的更多详细信息，并揭示了Triton可能是伊朗开发的，并曾经针对沙特阿拉伯的组织。

  

Triton恶意软件旨在针对Schneider Electric的Triconex安全仪表系统（SIS）控制器，该控制器用于工业环境中，以监视过程状态并将其恢复为安全状态，或者在参数表明存在潜在危险情况时将其安全关闭。

  

TRITON设计为使用未公开记录的专有TriStation协议进行通信，这意味着攻击者对协议进行了反向工程以进行攻击。

  

不幸的是，工业环境中使用的大多数OT系统从未设计为可以连接到Internet，这意味着它们特别容易受到网络攻击。

  

来自CISA和NSA的专家观察到在美国关键基础设施中，针对这些系统使用了多种技术。攻击链始于鱼叉式信息，一旦攻击者获得了组织的IT网络的访问权限，他们就会尝试横向移动以OT网络为目标。

  

咨询中提供的最近观察到的战术，技术和程序列表下方。

  

伪装\[T1192\]，以便在转向OT网络之前获得对该组织信息技术（IT）网络的初始访问权限。

部署了商品勒索软件以对两个网络上的数据进行加密以产生影响\[T1486\]。

连接到不需要Internet访问权限的PLC \[T883\]，不需要进行初始访问的身份验证。

利用常用端口\[T885\]和标准应用层协议\[T869\]与控制器通信并下载修改后的控制逻辑。

使用供应商工程软件和程序下载\[T843\]。

在PLC上修改控制逻辑\[T833\]和参数\[T836\]。

NSA / CISA警报中详细描述的错误之一是Triconex SIS中的一个严重漏洞，跟踪为CVE-2020-7491，在CvSS漏洞严重度等级上被评为10。

  

CVE-2020-7491缺陷是不当的访问控制缺陷。

  

“在Tricon系统版本10.2.0至10.5.3中安装的TCM中的旧调试端口帐户在网络上可见，并且可能允许不当访问。”

  

对安全仪表系统（SIS）控制器的成功攻击可以使攻击者查看网络上的明文数据，触发拒绝服务条件或允许不正确的访问。

  

该通报中列出的漏洞影响在Windows NT，Windows XP或Windows 7上运行的TriStation 1131，v1.0.0至v4.9.0，v4.10.0和4.12.0；安装在Tricon v10.0至v10.5.3系统中的Tricon通信模块（TCM）4351、4352、4351A / B和4352A / B。

  

好消息是这些SIS的最新版本不受这些漏洞的影响。
