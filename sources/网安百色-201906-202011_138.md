****![](../Images/56cd048bb99714cbb57c14cb3155bcf8.png "分割线")******1.微软预告Win10新功能：不怕恶意软件、攻击等行为**

对于Windows 10用户来说，微软已经提前预告了新功能，其将迎来“内核数据保护”（KDP），旨在阻止恶意软件 / 恶意威胁攻击者修改或破坏操作系统的内存数据。微软基础内核团队今日表示：“当攻击者利用经过签名、但相当脆弱的驱动程序攻击策略，来破坏数据结构并安装恶意的未签名驱动程序时，KDP可确保数据结构不会被篡改，以减轻此类攻击的影响”。微软还考虑到了新技术对其它软件的影响，比如反作弊和数字版权管理（DRM）应用程序。除了提升操作系统的整体安全性，KDP还具有其它优点，比如可减轻验证组件的负担，无需定期验证已被施加写保护的数据变量；改善基于虚拟化的安全兼容性，并提高生态系统中相关技术的采用率以及更加轻松诊断非安全漏洞类型的内存出错问题。

![](../Images/c547ef2fcd8505ceb3be9f12886d54c3.png)**2.Android 11 将允许用户设置特定的 Wi-Fi 不自动连接**7月9日消息，Android 11 在 Wi-Fi 网络的设置面板中新增了一个名为 “自动连接”的按钮，当用户选择关闭时，设备就不会自动连接到当前环境中特定的WI-FI网络。该功能是安卓11最近两个Beta版中新增的特性。在生活中，用户偶尔会遇到一些公共 WI-FI 或者不需要连接 WI-FI 的情况，尤其是当 5G 网络已经处于大面积可用的今天，而用户在在开启 WIFI 网络但不想要连接到 WI-FI 却又希望将 Wi-Fi 保存在设备上的时候，用户便可以使用该功能，将对应的 WIFI 网络设置中 “自动连接”开关关闭即可。**3.Joker恶意软件再次被发现利用Play商店绕过安全检测**由Check Point研究机构发布的一份报告中提及，该恶意软件（Joker或Bread））被发现另一个绕过Google Play商店保护的技巧：将应用程序内部的恶意DEX可执行文件模糊化为Base64编码的字符串，然后对其进行解码和加载到受感染设备上。**4.因出售全球数百家企业网络访问权，Fxmsp黑客遭起诉**正所谓，网络安全无国界。据悉，美国司法部起诉名为 “Fxmsp”的黑客，因其入侵全球三百多家企业，并在网上出售这些公司的网络访问权。在最新披露的起诉书中，司法部指控一名哈萨克斯坦公民Andrey Turchin，又称为“Fxmsp”，涉嫌多项罪名包含串谋计算机入侵罪、两项计算机诈骗和滥用（黑客）罪、有线欺诈和访问设备欺诈罪。起诉书中尚未明确Turchin是否已经被逮捕，但据相关知情人士，目前此人已被哈萨克斯坦当局逮捕。根据起诉书，Turchin通过网络钓鱼攻击和暴破远程桌面服务器密码来访问企业专用网络。一旦入侵成功，就立即部署窃密木马和远程访问木马（RAT），然后凭此获取系统永久性访问权。 **5.TikTok被指违反儿童隐私保护协议 美机构调查**7月8日消息，当地时间周二，美国联邦贸易委员会(FTC)和美国司法部开始联手调查流行应用TikTok，指控其未能履行2019年旨在保护儿童隐私的协议。马萨诸塞州某科技政策组织的一名工作人员和另一位消息人士表示，他们分别与FTC和司法部官员举行了电话会议，讨论对TikTok未能履行2019年2月所公布协议的指控。  今年5月份，数字民主中心、无商业化童年运动和其他组织要求FTC调查他们提出的指控，即TikTok未能按照协议删除13岁及以下用户的视频和个人信息，并且存在其他违规行为。不过，目前尚无法确定这两家机构是否会对TikTok采取任何行动。 **6.美能源部将中俄两国列为大容量电力系统的最大威胁**美国近日发布的总统行政命令称，大容量电力系统（BPS）是寻求对美国政府和民众进行恶意网络攻击活动的目标，电力系统设备的供应链安全对美国国防、外交、经济和社会生活构成严重威胁，因此将禁止美国购买对国家安全造成风险的国外电力设备，要求将外国敌对国家供应商提供的关键电力设备从电网中移除。作为对总统行政令的响应，美能源部7月8日发布RFI（信息请求），公开向社会征求意见建议，以建立一个分阶段的流程，使能源部能够按功能和对整个BPS公司的影响，优先审查BPS公司的电力设备。**7.谷歌开源漏洞扫描器“海啸”：专为大型企业设计**近日，谷歌开源了一款漏洞扫描器，名为“海啸 (Tsunami)”，专用于由数千个甚至是数百万个联网系统组成的大型企业网络。  该漏洞扫描器最初在谷歌内部使用，上个月在 GitHub 上开源。虽然“海啸”将不会成为官方谷歌产品，但将由开源社区负责维护，和Kubernetes 的情况类似。**8.德国硅晶圆厂商X-FAB遭网络攻击，6个生产基地被迫关闭**7月8日消息，作为全球领先的晶圆大厂X-FAB遭受病毒攻击，将暂时关闭旗下6座晶圆厂，全球半导体晶圆制造产业恐受冲击。X-FAB发布公告称，X-FAB集团受到网络攻击。根据X-FAB聘请的领先安全专家的建议，所有IT系统均已立即停止。作为一项额外的预防措施，所有6个生产基地的生产都已停止。目前X-FAB已迅速与有关当局接触，以调查这一史无前例的事件。此外，内部和外部安全专家团队已经成立，以解决问题并恢复所有系统。X-FAB还决定立即开始临时关闭制造工厂的计划，该计划最初计划在X-FAB的Covid-19节省成本计划的背景下于第三季度晚些时候进行。**9.拥有230万粉丝的网红被指控进行网络诈骗**即使你是一位拥有230万Instagram粉丝的网红也无法阻止联邦调查局对你的搜查。
