1. Windows修复组策略漏洞 该漏洞让攻击者获得管理特权

微软已经修复了当前所有Windows版本中允许攻击者利用Windows组策略功能来完全控制计算机的漏洞。此漏洞影响自Windows Server 2008以来的所有Windows版本。这个漏洞是由网络安全公司CyberArk发现的，该公司发现了一种符号链接攻击，攻击对象是通过更新组策略以获得更高权限的文件。“此漏洞允许域环境中的非特权用户执行文件系统攻击，从而让恶意用户规避反恶意软件解决方案，绕过加强安全措施，并可能导致组织网络的严重破坏。”

2. Python 和 Go 成为年度最受欢迎的黑客工具榜首

网络安全公司 Imperva Cloud WAF 近期分享了其在 2019 年一年内针对网络安全事件的观察。对数据进行聚类分析后，他们得到了如下结论：

按工具来分类，Python 依旧是大多数黑客的首选武器，紧接着是使用量增长迅速的 Go 语言；再其次是 WinHttp 库，该库主要由 Windows 上运行的 .net 和 CPP 使用；Shell 工具（如 cURL、wget 等）也榜上有名。浏览器也是常用的攻击工具。


根据 GitHut 2.0 给出的统计信息，Python 和 Go 都在 2019 年的前五大语言中占有一席之地。于是，Imperva 公司又将目光聚焦到了 GitHub 上的网络安全项目。GitHub 虽然未对存储库进行直接分类，但 Security 主题下拥有超过 8,500 个与安全相关的库，而这些库中的主要语言分别为：长期排在第一位的 Python，其次是 Java、JavaScript 和 PHP，最后是 Go。前四位毫不令人意外，而 Go 是在 2019 年首次取代了基于 Shell 的代码，进入 top 榜。

3. 澳大利亚储备银行将建立一个“数据仓”以提高其核心系统弹性

澳大利亚储备银行将建立一个“数据仓“，以提高其核心系统的弹性。澳大利亚中央银行周二（6月9日）向市场寻求系统集成商设计和实施数据仓，以“隔离”或分割某些数据，以在发生另一次故障时保护支付系统。数据“由于位于银行悉尼总部的主要数据中心存储损坏而无法访问”，也被认为是威胁所选业务应用程序弹性的一个关键风险。虽然停电对银行来说并不多见，但2018年8月，该行总部和数据中心发生内部供电故障，导致其关键储备银行信息和传输系统(RITS)部分瘫痪3小时。为了避免重蹈覆辙，澳大利亚央行预计，数据仓库将“增强(其)关键业务技术服务在数据丢失或损坏的情况下的弹性”，并最终“提高支付系统的弹性”。“储备银行需要提供‘持续可用’和高度可用的‘外部技术服务，以支持澳大利亚的支付系统，这突出了扩大关键服务弹性的必要性，”该银行说。澳大利亚央行已经开始开发这个数据掩体，预计将在2021年2月投入使用，预计它将“为选定的储备银行服务提供备用的在线副本和离线备份数据”。

4. 饮料制造商Lion经历网络攻击事件后关闭其IT系统

快速消费品巨头雄狮在周二发生“网络事件”后关闭了其IT系统。《悉尼先驱晨报》(Sydney Morning Herald)首先报道了此次攻击，称攻击“中断”了制造和远程访问系统。该公司在其网站上的一份简短声明中表示，他们确实经历了一次网络事件，已采取预防措施关闭了其IT系统，目前正在与专家顾问合作解决这个问题，并且已向当局发出警告，正努力将对客户和供应商的影响降至最低。

5. Nefilim勒索软件打击了Fisher＆Paykel设备

Fisher & Paykel电器是最新一个被勒索软件摧毁的大品牌，在攻击后恢复运营后关闭了业务。这家白色产品制造商的发言人Andrew Luxmoore向iTnews证实了这次袭击，称袭击发生在上周初。他说:“这个尝试很快就被发现了，因此，我们立即锁定了我们的IT生态系统。”“我们目前正与第三方专家合作，恢复我们的系统，恢复我们接受和履行订单的能力，并引入额外的安全措施。”Luxmoore说，攻击影响了F&P电器的生产和分销，其设施在处理勒索软件攻击时关闭。

6. 开源软件漏洞统计：2019年近千漏洞披露，15个武器化

风险管理公司RiskSense在分析了54个开源项目后发现，在2015年到2020年之间，总共有近2,700个漏洞被上报。总体来看，Jenkins自动服务器和MySQL在这段时间里被发现的漏洞最多，每个都有超过600个漏洞；其中，两者分别都有15个漏洞被利用进行攻击。

对于部分项目，如Vagrant、Alfresco与Artifactory等，只有少数漏洞，但是被武器化比例较高。比如Vagrant与Alfresco，都只有9个漏洞被发现，但是分别有6个与3个漏洞被武器化。

RiskSense也统计了这些漏洞被加入NVD的速度。平均而言，一个漏洞从被发现到加入NVD大约花费54天，但是有119个CVE过了超过一年才被加入NVD。而一个影响到PostgreSQL的严重漏洞，在1,817天以后才被加入NVD，是RiskSense发现的加入耗时最长的漏洞。而对于2019年的数据，RiskSense发现CVE数量为968个，相比2018年的421个CVE增加了130%。不过，去年被披露的漏洞中，只有15个被武器化了。2020年第一季度总共有179个漏洞被披露，其中有5个被武器化。

7. 新版Windows 10的外设Bug：重启后找不到USB打印机端口

微软近日警告，运行Windows 10版本1903或更高版本的设备的客户如果在关闭计算机时断开打印机的连接，将无法使用USB打印机端口。

再次启动Windows 10设备后，USB打印机端口将从打印机端口列表中消失，并且需要它的所有任务都会失败。

微软在今天发布的支持文档中解释：如果您将USB打印机连接到Windows 10 1903或更高版本，然后关闭Windows，断开或关闭打印机，当您再次启动Windows USB打印机端口将不会在打印机端口列表中可用，Windows将无法完成需要该USB打的任印端口何任务。

8. 2020年全球DNS威胁报告：DNS攻击平均损失高达92万美元

根据EfficientIP的统计，有79％的组织遭受了DNS攻击，每次攻击的平均成本在924,000美元左右。

与IDC合作完成的《2020年全球DNS威胁报告》显示，今年所有行业的组织平均遭受9.5次DNS攻击。这些数据说明了DNS在网络安全防御中的重要性，DNS不仅仅是黑客攻击的目标，同时也可以成为黑客实施攻击的重要手段。

在DNS攻击对区域造成的损失方面，北美地区以平均每次攻击损失107万美元领先。与去年同期相比，损失下降了约1.36％。尽管美国的DNS攻击损失减少了近4％，但它仍然是全球DNS攻击损失最高的国家，平均每次攻击损失108万美元。

DNS攻击者越来越多地将目标对准云计算。随着托管在混合云环境中的关键业务应用程序数量的增加，网络罪犯的攻击面也有所增加。该报告显示，遭受云服务停机影响的公司从2019年的41％增长到2020年的50％，大幅增长了近22％。在全球新冠肺炎大流行期间，云服务的采用不断增加，使云计算对攻击者更具吸引力。

DNS攻击导致内部应用程序停机占比仍然非常高：今年为62％，而去年为63％。总体而言，无论是内部还是云中的应用程序停机，仍然是DNS攻击的最主要结果；在接受调查的公司中，有82％的公司表示他们经历过某种形式的应用程序停机。

该报告已进入第六年，显示了DNS攻击方式的广泛性以及从洪水式到低信号（low signal）的攻击流行趋势变化。今年，网络钓鱼成为流行攻击方式（39％的公司遭遇网络钓鱼），其次是基于恶意软件的攻击（34％）和传统的DDoS（27％）。至关重要的是，DDoS攻击的规模也在增加，几乎三分之二（64％）的攻击带宽超过5Gbit/s。

9. 本田遭勒索软件重创，全球多地业务陷入停顿

本田公司本周二在一份简短声明中确认：勒索软件攻击在其日本总部以外多国工厂造成了生产停顿问题。

与本田的轻描淡写不同，BBC的报道显示本田过去48小时遭遇了极为惨烈的勒索软件攻击：勒索软件已经传播到本田的整个网络，影响了本田的计算机服务器、电子邮件以及其他内网功能，目前本田正在努力将影响降到最低，并恢复生产、销售和开发活动的全部功能。根据本田客服推特账号的通告，本田客户服务和本田金融服务遇到技术难题，无法使用。

目前流出的攻击细节信息很少，但较早的报告表明，Snake勒索软件可能是罪魁祸首。像其他文件加密恶意软件一样，Snake对文件和文档进行加密并勒索加密货币赎金。但是本田表示，没有证据表明数据已经被窃取，这是新型勒索软件所采用的一种常见策略。本田表示，受影响的工厂有望最早在今天(周四)恢复生产。
