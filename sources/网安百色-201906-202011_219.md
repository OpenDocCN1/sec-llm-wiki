从各论坛反应来看，大部分安全软件无法查杀和阻止该勒索病毒，360和火绒利用MD5进行文件信誉的收集，使用者升级最新的库后可以阻止部分感染文档进行传播，但并不能阻止新感染文件，不能从根本阻止加密行为。我获得的信息是目前受到影响的仅限于win10用户，而win7不受影响。因此联想到了3月中旬微软爆出的CVE-2020-0796漏洞（后面附有处理方法）。截止2020年4月7日4点，还不能证实wannaren的传播方式。希望大家第一时间修复处理CVE-2020-0796漏洞，同时做好备份工作。特别是**Windows Server 版本 1903**的用户。  

此外，已经把wannaren加密样本上传到卡巴斯基实验室，相关工作人员表示尝试7日内对已经加密的文件能够进行解密。期待好消息。

Microsoft 服务器消息块 3.1.1 (SMBv3) 协议处理某些请求的方式中存在远程执行代码漏洞。成功利用此漏洞的攻击者可以获取在目标服务器或客户端上执行代码的能力。要利用针对服务器的漏洞，未经身份验证的攻击者可以将特制数据包发送到目标 SMBv3 服务器。要利用针对客户端的漏洞，未经身份验证的攻击者将需要配置恶意的SMBv3 服务器，并说服用户连接到该服务器。**此安全更新通过更正 SMBv3 协议处理这些特制请求的方式来修复此漏洞。**

Microsoft 尚未发现此漏洞的任何缓解因素。

## **常见问题**

  

**我可以采取什么步骤来保护我的网络？**

**1.在企业边界防火墙处阻止 TCP 端口 445**

TCP 端口 445 用于启动与受影响组件的连接。在网络边界防火墙处阻止此端口将有助于防止位于防火墙后面的系统尝试利用此漏洞。这有助于防止网络遭受来自企业边界之外的攻击。在企业边界阻止受影响的端口是帮助避免基于 Internet 的攻击的最佳防御措施。**然而，系统仍然可能容易受到来自其企业边界内的攻击。  
**

  

**2.遵循 Microsoft 指南，以防 SMB 流量形成横向连接进入或离开网络**

防止 SMB 流量形成横向连接进入或离开网络

**Windows 的早期版本（“安全更新”表中列出的版本除外）是否受此漏洞影响？**

否，该漏洞存在于 Windows 10 版本 1903 中添加的一项新功能中。Windows 的早期版本不支持 SMBv3.1.1 压缩并且不受影响。

**Windows Server 版本 1903（Server Core 安装程序）和 Windows Server 版本 1909（Server Core 安装程序）在“安全更新表”中。不属于 Server Core 安装程序的 Windows Server 版本 1903 和 Windows Server 版本 1909 是否受此漏洞影响？**

否。Windows Server 版本 1903 和 1909 均在半年频道 (SAC) 下发布。因此，仅 Server Core 安装程序可用。
