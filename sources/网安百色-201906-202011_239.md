# Microsoft Windows SMBv3远程执行代码漏洞

**引言**

  

在3月10日发布的补丁程序中，微软披露了SMB 3.1.1（v3）协议中的一个远程代码执行漏洞。尽管在星期二的补丁程序初始发行版未提及此漏洞，该问题的初步通告(CVE-2020-0796）还是发布在另一安全厂商的博客上，目前还没查明该漏洞为何被泄露。意外泄露此漏洞后，Microsoft 很快发布了安全公告ADV200005  和技术指南。

 

2020年3月12日更新：Microsoft更新了ADV200005和CVE-2020-0796，并发布了受影响的Windows系统的修补程序。

  

*   **风险级别：** 高
    
*   **漏洞编号: ** CVE-2020-0796
    

**漏洞简介**

Microsoft Server Message Block 3.1.1协议处理某些请求的方式中存在一个严重的远程执行代码漏洞。该漏洞是由于存在漏洞的软件在处理恶意制作的压缩数据包时发生错误所导致的。未经身份验证的远程攻击者可以利用该漏洞在应用程序的上下文执行任意代码。

为了利用针对SMB服务器的漏洞，未经身份验证的攻击者可以通过将特制数据包发送到目标SMBv3服务器。若要利用针对SMB客户端的漏洞，未经身份验证的攻击者将需要配置恶意的SMBv3服务器，并诱使用户连接到该服务器。

  

**影响范围**

*   Windows  10 Version 1903 for 32-bit Systems                                   
    
*   Windows  10 Version 1903 for ARM64-based Systems                     
    
*   Windows  10 Version 1903 for x64-based Systems                   
    
*   Windows  10 Version 1909 for 32-bit Systems                                   
    
*   Windows  10 Version 1909 for ARM64-based Systems                     
    
*   Windows  10 Version 1909 for x64-based Systems                   
    
*   Windows  Server, version 1903 (Server Core installation)       
    
*   Windows  Server, version 1909 (Server Core installation)  
    

  

**修复方案**

  

**1\. 微软已发布此漏洞的安全补丁**

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-0796

**强烈建议立即进行补丁的安装，若无法进行安装，可以参考以下临时缓解方式：**

2. **禁用SMBv3压缩**

您可以使用以下PowerShell命令禁用压缩功能以阻止未经身份验证的攻击者针对SMBv3服务器利用此漏洞–

  

Set-ItemProperty -Path“ HKLM：\\ SYSTEM \\ CurrentControlSet \\ Services \\ LanmanServer \\ Parameters” DisableCompression -Type DWORD -Value 1 –Force

  

**注意：**

a. 进行更改后，无需重新启动。

b. 此解决方法不能防止利用SMB客户端。

c. Windows或Windows Server尚未使用SMB压缩，并禁用SMB压缩不会对性能产生负面影响。

您可以使用下面的PowerShell命令禁用替代方法。

Set-ItemProperty -Path "HKLM:\\SYSTEM\\CurrentControlSet\\Services\\LanmanServer\\Parameters" DisableCompression -Type DWORD -Value 0 -Force

禁用替代方法后，无需重新启动。

 

  

3. ****在企业外围防火墙处阻止TCP端口445****

TCP端口445用于启动与受影响组件的连接。在网络外围防火墙处阻止此端口将有助于保护位于防火墙后面的系统免受尝试利用此漏洞的攻击。
