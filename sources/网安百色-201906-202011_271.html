1. 摘要

1.1 报告数据来源

恒安嘉新水滴安全实验室为了更深入的研究僵尸网络（Botnet），于2018年设立了僵尸网络主动监测系统，可采集Botnet实时指令以及关联各种威胁线索。

水滴安全实验室在全球十多个国家部署了蜜罐节点，以低交互和高交互蜜罐为主，蜜罐系统为Botnet主动监测系统贡献了较多的活跃样本以及相关威胁情报。

1.2 报告摘要

2019年，随着监控僵尸网络的能力逐步增强，我们发现Botnet在代码结构、运维方式、盈利模式等多个层次有较为明显的特征。主要为：

1. Botnet程序代码结构呈现高度模块化特征，家族或组织之间的恶意代码模块互相利用，其恶意行为在支持DDoS的基础上，往往还支持漏洞传播、远控、挖矿等多元化功能。

2. IoT平台备受黑产团伙青睐，家族利用漏洞模块传播已经成为常态。Windows平台老版本家族活跃度一般，但相对隐蔽性更强。

3. Botnet有明显的集中于成熟且开源的家族的趋势，并且C&C服务器更多的集中于互联网基础设施发达的地区。

4. Botnet存在BaaS（Botnet as a Service）模式，在Instagram、Discord等社交软件上有DDoS服务租赁和僵尸网络节点租赁等黑产服务。

 最后，本报告的第二章为2019年DDoS攻击态势概览。在第三章中，本报告从攻击次数、攻击类型、攻击时间、攻击地域等多个维度，以及从攻击资源和僵尸网络两个视角，力求全面阐述2019年的DDoS的攻击态势，确定需要防御的资产以及可能的攻击方式，以便更主动地净化网络空间。第四章为本报告的总结。

 

2. 2019年DDoS攻击态势概览

2.1 2019 vs 2018

1. 月均攻击次数增加51.2%(2018年11月开始监控)，攻击方式仍以UDP Flood和SYN Flood为主

2. 国内，香港升级为主要攻击目标和主要被控节点地区

3. 物联网设备DDoS攻击的参与度逐年提升

4. IoT家族的漏洞利用载荷更新换代，主要针对包括华为在内的多个厂商的路由器设备

2.2 年度观点

1．物联网：IoT平台家族攻击占比进一步扩大，越来越多的家族支持IoT平台，Gafgyt家族贡献了大部分攻击行为。

2．利益：攻击者获利方式多样化，包括DDoS攻击、出售攻击服务、出售攻击节点、与其他恶意软件合作等活动。

3．组织：2019年DDoS攻击中，13%的攻击者承担了79%的攻击事件，并且存在多个C&C属于同一个组织，这类有组织的惯犯行为值得持续关注。

4. 地域：美国和中国是受控的重灾区，但同时也是C&C主要分布地区。

5. 恶意家族：Botnet恶意家族代码模块复用情况明显，黑产团伙更趋向于直接利用成熟、开源的代码模块。

3. 2019年DDoS攻击分析

3.1 DDoS攻击次数和攻击类型分析

3.1.1 DDoS攻击次数

2019年（2019年9月- 2019年12月），我们监控到DDoS攻击次数为17.84万次。与2018年监控数据相比，攻击次数明显增长。下图展示了僵尸网络家族的攻击数量情况。

 

从2019年数据来看，DDoS攻击整体浮动在一定范围且在十月份后有一定上升趋势。我们观察到十月份后Xor家族变得活跃起来，贡献了较多的攻击数据。

3.1.2 DDoS攻击类型

2019年，主要的攻击类型为SYN Flood，UDP Flood，TCP Flood，这三大类攻击占了总攻击次数的94％。和2018年相比，这三类攻击类型占比略有上升。

 


监测中发现，有一定的攻击事件利用了混合型攻击的手法，攻击者根据目标系统特性进行灵活组合，可发起更有效的攻击行为。以Gafgyt为例，专门针对游戏服务器类型的攻击，其中一种以VSE命名，其实是对运行Valve Source Engine的引擎游戏服务器发起攻击，这种利用协议或者系统缺陷的做法，表明了黑产团伙不择手段为利益的攻势。

3.2 DDoS攻击时间刻画

我们监测到在一天内，在服务商业务高峰时段（早8点-晚20点），是攻击者进行DDoS 攻击的高峰期，约占整体攻击的88%。攻击者应该是以此来提升攻击的效果和影响。

 

同时我们发现，攻击时长在10分钟内的DDoS攻击占了全部攻击的80%，这样短时间的攻击方式说明攻击者一方面为了降低攻击资源被发现的机率，另一方面说明攻击者倾向于实现短时间内通过瞬时高流量攻击造成服务不稳定。这也是僵尸网络租赁服务和DDoS服务流行的主要原因之一，用户只需付款几美金到几十美金就可以在短时间内发起大规模攻击。

3.3.1 主控地域分布

从世界范围来看，DDoS控制端主要分布地区为美国、中国、法国和荷兰，四国的控制端数目占68.77%。显然这和国家的互联网经济发达程度有较强的关系。

3.4 DDoS攻击资源行为分析

在攻击源活跃时间的监测中发现，近93%的攻击源存活时间小于10天。一方面是由于攻击者为了防止暴露资源；另一方面也侧面说明了公共互联网存在安全隐患的IP资源分布广泛，攻击者的获取成本极低且易行。

 

同时，我们对C&C服务器的活跃程度进行了统计，发现62.31%d的C&C活跃在4天以内，这也反映了黑产团伙此举为了降低C&C被发现的可能性。但是我们跟踪发现，多数C&C在关闭端口半个月左右，又会开启监听状态。

 

 

3.5  僵尸网络监测分析

2019年，水滴实验室跟踪的僵尸网络家族达到24个（不包含变种），覆盖了主流DDoS活跃家族。相比于2018年，捕获到的攻击数据明显提升。

DDoS攻击大都由僵尸网络家族发起攻击，2019年，水滴实验室监控的僵尸网络家族活跃情况如下：（按攻击次数计算活跃度）

 

相比较于2018年，活跃的家族集中于Gafgyt和Billgates家族，而Gafgyt家族贡献了40%的攻击数据，十分活跃。

3.5.1 热点家族Gafgyt

Gafgyt家族得益于代码开源且代码模块成熟，近年来一直是很常见的僵尸网络家族。

在2019年下半年，Gafgyt漏洞利用载荷针对多家厂商路由器，以ZYXEL P660HN-T1A—CVE-2017-18368、Huawei HG532—CVE-2017-17215、Realtek RTL81XX Chipset—CVE-2014-8361为主。可以看到镶嵌漏扫模块已成为常用的传播手段。

另外，我们在Gafgyt通信流量中发现多条聊天记录，聊天内容也侧面证明Gafgyt家族主要攻击目标之一是游戏服务器。同时，越来越多的黑产团伙使用移动端下发攻击指令，由于这样的便利性，也降低了其攻击成本。

 

我们在Instagram、Discord等社交软件上可以轻易找到出售攻击服务或肉鸡的黑产团伙，以与Gafgyt和mirai为主，并且展示了使用界面。

 

本年度，Gafgyt主要攻击北美、欧洲和澳洲等地区，DDoS攻击指令数量明显增长，攻击方式以UDP泛洪攻击为主，覆盖了HTTP服务的80与443、游戏服务的3074、30000、30100、32000等端口。

3.5.2 热点家族Billgates

Billgates相比2018年，活跃度略有下降，但依然属于活跃家族。我们对Billgates进行了同源性分析，结合网上开源的资料，我们发现Chinaz组织开发了该恶意样本，并且开发了其他的知名恶意家族。Xor、dofloo这些常见的家族也是该组织进行开发。

该组织的Dofloo家族，攻击目标常为黑产组织的页面服务，通常为博彩、色情行业。有较明显的黑吃黑行为。

4. 总结

时至今日，DDoS这种直接的攻击方式依然活跃在黑产团伙的手里，这得益于Botnet多样化的获利方式。或与远控合作，或与挖矿合作，或出售攻击服务，完全为了利益最大化而不择手段，这也让维护网络安全的传统方式愈发难见成效。
