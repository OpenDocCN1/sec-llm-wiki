1      最新安全漏洞

1.1 Fuji Electric Alpha5 Smart Loader缓冲区错误漏洞

漏洞标题：Fuji  Electric Alpha5 Smart Loader 缓冲区错误漏洞

提交时间：2019-08-15

披露/发现时间：

漏洞等级：高危

CVE-ID：CVE-2019-13520

漏洞类别：缓冲区错误

CNNVD-ID：CNNVD-201908-1135

影响组件：Fuji Electric Alpha5  Smart Loader 4.2之前版本中存在缓冲区错误漏洞

漏洞描述：Fuji Electric Alpha5  Smart Loader是日本富士电机（Fuji Electric）公司的一套伺服系统。该系统具有智能调节、智能设计和智能操作等功能。Fuji Electric Alpha5  Smart Loader 4.2之前版本中存在缓冲区错误漏洞。攻击者可借助特制的项目文件利用该漏洞以该应用程序权限执行代码。

安全建议：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://www.fujielectric.co.jp/

1.2 OSPAS-SARSAT 安全漏洞

漏洞标题：OSPAS-SARSAT  安全漏洞

提交时间：2019-08-15

披露/发现时间：

漏洞等级：低危

CVE-ID： CVE-2018-14062

漏洞类别：其他

CNNVD-ID：CNNVD-201908-1132

影响组件：COSPAS-SARSAT协议中存在安全漏洞

漏洞描述：COSPAS-SARSAT是一套基于卫星的搜索、救援（SAR）信息系统。COSPAS-SARSAT协议中存在安全漏洞。远程攻击者可利用该漏洞伪造消息，回复加密消息，造成拒绝服务并发送私人消息。

安全建议：目前厂商暂未发布修复措施解决此安全问题，建议使用此软件的用户随时关注厂商主页或参考网址以获取解决办法：

https://cospas-sarsat.int/

1.3 ClickHouse MySQL client 安全漏洞

漏洞标题：ClickHouse  MySQL client 安全漏洞

提交时间：2019-08-15

披露/发现时间：

漏洞等级：低危

CVE-ID：CVE-2018-14669

漏洞类别：其他

CNNVD-ID：CNNVD-201908-1127

影响组件：ClickHouse MySQL client  1.1.54390之前版本中存在安全漏洞

漏洞描述：Yandex ClickHouse是俄罗斯Yandex公司的一套用于在线分析处理的开源列式数据库。ClickHouse MySQL client  1.1.54390之前版本中存在安全漏洞。在‘LOAD DATA LOCAL INFILE’功能被启用时，攻击者可借助恶意的MySQL数据库利用该漏洞从所连接的ClickHouse服务器读取任意文件。

安全建议：目前厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://clickhouse.yandex/docs/en/security_changelog/

1.4 stb_vorbis 安全漏洞

漏洞标题：stb_vorbis 安全漏洞

提交时间：2019-08-15

披露/发现时间：

漏洞等级：低危

CVE-ID：CVE-2019-13223

漏洞类别：其他

CNNVD-ID：CNNVD-201908-1125

影响组件：stb_vorbis 2019-03-04及之前版本中的‘lookup1_values’函数中存在安全漏洞

漏洞描述：stb_vorbis是一款开源的用于解码ogg vorbis文件的音频解码器。stb_vorbis 2019-03-04及之前版本中的‘lookup1_values’函数中存在安全漏洞。攻击者可借助特制的Ogg Vorbis文件利用该漏洞造成拒绝服务。

安全建议：目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页：

https://github.com/nothings/stb/commit/98fdfc6df88b1e34a736d5e126e6c8139c8de1a6

2      安全资讯

2.1 微软：暂不会停止对Skype和Cortana对话的人工审查

ViceMotherboard网站上的一份报告显示，微软正在通过人工承包商来监听Skype翻译和Cortana的语音对话。虽然微软并不是唯一一家使用人工承包商来改进语音识别技术的公司，但问题是这家公司没有在其隐私文件中明确指明这点。

2.2 美设立新任务小组以应对俄罗斯对2020年大选的干预问题

NSA局长、美国网络司令部司令保罗·中曾根(PaulNakasone)于当地时间周三表示，为了重点应对俄罗斯对该国2020年美国大选的干预问题他们已经成立了一个特别工作组–RussiaSmall Group。
