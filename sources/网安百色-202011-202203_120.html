内容摘要

这是ENISA威胁态势（ETL）报告的第九版，这是一份关于网络安全威胁态势的年度报告，其中确定了主要的威胁、在威胁方面观察到的主要趋势、威胁行为者和攻击技术，还描述了相关的缓解措施。在不断改进我们开发威胁景观的方法过程中，今年的工作得到了新格式的ENISA网络安全威胁景观（CTL）特设工作组的支持。ETL 2021报告的时间跨度为2020年4月至2021年7月，在整个报告中被称为 "报告期"。在报告期内，确定的主要威胁包括：

/ 勒索软件

/ 恶意软件

/ 密码劫持

/ 与电子邮件有关的威胁

/ 针对数据的威胁

/ 对可用性和完整性的威胁

/ 虚假信息--错误信息

/ 非恶意的威胁

/ 供应链攻击

在本报告中，我们讨论了前8个网络安全威胁类别。供应链威胁是第9个类别，由于其特别突出，在ENISA的专门报告 "ENISA供应链攻击的威胁景观 "中进行了详细分析。
