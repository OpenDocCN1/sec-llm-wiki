尽快更新 Windows 的 71 个理由

在最新的补丁星期二中，微软一共修补了 71 个漏洞。其中最危险的是一个叫CVE-2021-40449 的漏洞，其是一个已经被网络罪犯利用的 Win32k 驱动释放后重用漏洞。


除此之外，微软修补了三个已经被外界知晓的严重漏洞。目前，微软专家认为它们被利用的概率为  "不太可能"。然而，安全专家正积极讨论着这些漏洞，且概念验证已经出现在了互联网上，因此，有人可能会尝试使用它们。


█  微软 Windows 内核漏洞


CVE-2021-41335，三个漏洞中最危险的那个，在通用漏洞评分系统上评了 7.8 分。它嵌在在微软 Windows 内核中，允许潜在的恶意进程提权。


█  绕过 Windows AppContainer


第二个漏洞叫CVE-2021-41338，涉及绕过 Windows 中能保护应用程序和进程的AppContainer 环境的限制。如果满足了某些条件，由于默认 Windows 过滤平台的规则，未经授权的人就可以利用它。因此，它可以提权。


谷歌“Project Zero”的成员在七月份发现了这个漏洞并报告给了微软，给了它 90天的期限来修复这个漏洞，并最终在公共领域发布了概念验证。通用漏洞评分系统评分，5.5 分。


█  Windows DNS 服务器漏洞


CVE-2021-40469 漏洞仅存在于作为 DNS 服务器运行的微软 Windows 设备。然而，目前所有 Windows 服务器版本，从 Server 2008 开始，直到最近发布的Server 2022，都存在这个漏洞。CVE-2021-40469 允许在服务器上进行远程代码执远程代码执行，通用漏洞评分系统评分为 7.2 分


█  如何保护你的公司


我们事件响应部门的同事制作的 2021 年事件响应分析师报告结果表明，漏洞仍然是主流的初始攻击载体。此外，这些漏洞不一定是最新的，这里的主要威胁不是零日漏洞，而是通常情况下延迟安装的更新。因此，我们总是建议尽快在所有连接的设备上安装更新。更新对于操作系统、浏览器和安全解决方案等关键应用程序尤为重要。
