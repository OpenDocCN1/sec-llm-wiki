# 新疆维吾尔自治区互联网信息办公室等部门公开十四起网上违法违规行为典型案例

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NzE4ODk1Mw==&mid=2652089637&idx=2&sn=487bebb9b2d53c7aea884a58c32a6ec9&chksm=f254d193c52358853f9e0f4b4146f93a516ccb8293b95aa9bdefc153c2682cf011a2a283b7ce&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0NzE4ODk1Mw==&mid=2652089637&idx=2&sn=487bebb9b2d53c7aea884a58c32a6ec9&chksm=f254d193c52358853f9e0f4b4146f93a516ccb8293b95aa9bdefc153c2682cf011a2a283b7ce&scene=27#wechat_redirect)

近日，新疆维吾尔自治区互联网信息办公室、自治区公安厅根据举报线索，依法查处并曝光十四起网上违法违规行为典型案例。经查，相关网络信息内容生产者制作、复制、发布谣言、淫秽、赌博等违反《中华人民共和国刑法》《中华人民共和国网络安全法》《网络信息内容生态治理规定》等法律法规明确禁止的信息，扰乱经济社会秩序，破坏网络生态环境，网信部门、公安机关已对相关人员及账号依法予以查处。

**案例一、克孜勒苏柯尔克孜自治州网民阿某煽动民族仇恨案**

2021年1月14日，网民举报阿某利用即时通讯工具大量传播煽动民族仇恨、破坏民族团结等音频信息。经核实，并根据有关法律法规，公安机关依法对阿某予以刑事拘留。

**案例二、四川省网民张某网络诈骗案**

2021年1月14日，网民举报张某在网上以支付劳动仲裁费用为由，对新疆网民实施诈骗，涉案金额共计38万余元。经核实，并根据有关法律法规，公安机关依法对张某予以刑事拘留。

**案例三、克拉玛依市网民加某宣扬极端主义案**

2021年2月9日，网民举报加某利用即时通讯工具发布宣扬宗教极端思想、煽动民族歧视、民族仇恨等言论。经核实，并根据有关法律法规，公安机关依法对加某予以刑事拘留。

**案例四、阿克苏地区网民吐某网络诈骗案**

2021年2月10日，网民举报吐某以网上办理贷款为由，对他人实施诈骗，涉案金额共计4500余元。经核实，并根据有关法律法规，公安机关依法对吐某采取刑事强制措施。

**案例五、甘肃省网民庄某网络诈骗案**

2021年3月7日，网民举报庄某在网上以帮助处理不良记录为由，对新疆网民实施网络诈骗，涉案金额共计1万余元。经核实，并根据有关法律法规，公安机关依法对庄某采取刑事强制措施。

**案例六、喀什地区网民艾某宣扬极端主义案**

2021年1月7日，网民举报艾某利用即时通讯工具传播宣扬宗教极端思想的歌曲。经核实，并根据有关法律法规，公安机关依法对艾某予以行政拘留并处罚款。

**案例七、阿克苏地区网民阿某网络诈骗案**

2021年1月14日，网民举报阿某利用即时通讯工具以办理贷款收取手续费为由实施诈骗。经核实，并根据有关法律法规，公安机关依法对阿某予以行政拘留并处罚款。

**案例八、阿克苏地区网民艾某传播淫秽信息案**

2021年2月4日，网民举报艾某利用即时通讯工具传播多部淫秽色情视频。经核实，并根据有关法律法规，公安机关依法对艾某予以行政拘留并处罚款。

**案例九、乌鲁木齐市网民杜某煽动民族歧视案**

2021年3月5日，网民举报杜某利用即时通讯工具传播煽动民族歧视、破坏民族团结的电子书。经核实，并根据有关法律法规，公安机关依法对杜某予以行政拘留。

**案例十、巴音郭楞蒙古自治州网民吕某散布谣言案**

2021年3月9日，网民举报网民吕某利用即时通讯工具传播“新疆封城了”的谣言信息。经核实，并根据有关法律法规，公安机关依法对吕某予以行政拘留。

**案例十一、“sabi yurak”等43个QQ账号发布违规信息案**

近期，网民举报“sabi yurak”“ahsa王子”“nur”等43个QQ账号以文字、视频等形式在QQ空间传播淫秽色情信息，对网络生态造成不良影响。经核实，并根据有关法律法规，网信部门依法对上述43个QQ账号予以关闭。

**案例十二、“xax kino ba”等40个快手视频账号发布违规信息案**

近期，网民举报“xax kino ba”“Xax kino”等40个快手视频账号发布招嫖及售卖淫秽视频广告等信息，对网络生态造成不良影响。经核实，并根据有关法律法规，网信部门依法对上述40个快手视频账号予以关闭。

**案例十三、“janim8”等11个微信公众号发布违规信息案**

近期，网民举报“janim8”“keler”“gh\_c2df56f1fb4d”等11个微信公众号发布低俗媚俗等信息，对网络生态环境造成不良影响。经核实，并根据有关法律法规，网信部门依法对上述11个微信公众号主办人进行了约谈，并责令注销账号。

**案例十四、“Lihirlihir”等3个微信公众号发布违规信息案**

近期，网民举报“Lihirlihir”“mahliatv”等3个微信公众号发布低俗媚俗等信息，对网络生态环境造成不良影响。经核实，并根据有关法律法规，网信部门依法对上述微信公众号主办人进行了约谈，并责令暂停信息更新。

网信部门、公安机关提示，网络空间不是法外之地，各网站平台要切实履行主体责任、依法办网，培育积极健康、向上向善的网络文化。广大自媒体和网民要依法用网、文明上网，共同维护良好网络生态、清朗网络空间。欢迎广大网民据实举报网上各类违法违规行为，对举报有功人员将予以奖励。
