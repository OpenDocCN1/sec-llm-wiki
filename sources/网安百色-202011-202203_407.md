# **0x02 **漏洞概述****

Apache Solr是一个开源的搜索服务，使用Java语言开发。Apache Solr的某些功能存在过滤不严格，在Apache Solr未开启认证的情况下，攻击者可直接构造特定请求开启特定配置，并最终造成SSRF或文件读取漏洞。目前互联网已公开漏洞POC。

![](../Images/48016d4ff0210d12b359a1236f84e126.png)

  

**0x0**3 影响版本****

*   Apache Solr 所有版本
    

  

****0x04 修复建议****

官方表示暂不修复，建议采取以下措施：

*   增加身份验证/授权，可参考官方文档，地址如下：
    

https://solr.apache.org/guide/8\_6/authentication-and-authorization-plugins.html

*   禁止Solr API 以及管理 UI 直接对公网开放。
