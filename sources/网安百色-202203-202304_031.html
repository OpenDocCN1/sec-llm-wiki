一个名为“acropalypse”的严重隐私漏洞会影响 Windows 截图工具，允许人们部分恢复从图像中编辑出来的内容。

上周，安全研究人员发现 Google Pixel 标记工具中的一个错误导致原始图像数据即使被编辑或裁剪也能保留下来。

此缺陷会引起严重的隐私问题，因为如果用户共享图片（例如带有编辑号码的信用卡或面部被移除的照片），则可能会部分恢复原始照片。

为了说明这个错误，研究人员启动了一个在线 acropalypse 屏幕截图恢复实用程序 ，该实用程序将尝试恢复在 Google Pixel 上创建的编辑图像。

Windows 11 截图工具也受到影响

今天，软件工程师证实，“acropalypse”隐私漏洞也影响了 Windows 11 截图工具。

在 Windows 11 截图工具中打开文件并覆盖现有文件时，它不会截断任何未使用的数据，而是留下未使用的数据，从而可以部分恢复这些数据。

漏洞专家也确认了Windows 11 Snipping Tool 漏洞。

为了对此进行测试，我们在 Windows 11 截图工具中打开了一个现有的 PNG 文件，将其裁剪（也可以对其进行编辑或标记），然后将更改保存到原始文件中。

虽然裁剪图像现在包含的数据比原始图像少得多，但原始图像文件 (office-screenshot-original.png) 和裁剪图像文件 (office-screenshot.png) 的文件大小相同，如下所示：

PNG 文件规范要求 PNG 图像文件始终以“IEND”数据块结尾，图像编辑器和查看器忽略之后添加的任何数据。

下面是我们截取的 Microsoft 网站的原始屏幕截图。如您所见，该文件以 IEND 结尾并且其后不包含任何数据。

原始 PNG 图像末尾的 IEND 块

但是，使用 Windows 11 截图工具用裁剪后的版本覆盖原始图像时，程序没有正确截断未使用的数据，它保留在 IEND 数据块之后。

IEND 数据块后的未截断数据

在图像查看器中打开文件只会显示裁剪后的图像，因为第一个 IEND 之后的任何内容都将被忽略。

但是，此未截断的数据可用于部分重建原始图像，从而可能会泄露敏感部分。

虽然研究人员的在线acropalypse 屏幕截图恢复应用程序目前无法处理 Windows 文件，但我们共享了一个可用于恢复 Windows 文件的 Python 脚本。

这不是原始图像的完整恢复，您可能想知道为什么这是隐私风险。

想象一下，您截取了敏感电子表格、机密文件甚至裸照的屏幕截图，并裁剪掉了敏感信息或部分图像。

即使您无法完全恢复原始图像，也有人可以恢复您不想公开的敏感信息。

还应注意，并非所有 PNG 文件（例如优化的 PNG）都受此缺陷影响。

你的原始 PNG 是用一个 zlib 块保存的（“优化的”PNG 很常见），但实际的屏幕截图是用多个 zlib 块保存的（我的漏洞利用需要这样做）。

我们还发现，如果你在图像编辑器（如 Photoshop）中打开一个未截断的 PNG 文件，并将其保存到另一个文件中，最后未使用的数据将被剥离，使其无法再恢复。

最后，Windows 11 截图工具也对 JPG 文件执行相同的行为，如果被覆盖，数据不会被截断。

然而，漏洞利用目前不适用于 JPG，但有可能实现。

微软称他们知道这些报告并正在调查。并将根据需要采取行动来帮助保护客户。
