# 中央网信办举报中心推出“今日辟谣”专栏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NzE4ODk1Mw==&mid=2652092096&idx=2&sn=c8decf251172b8b3f6aa66f36a8bd0fc&chksm=f254ca76c5234360900e90e113d0ba6838b211bb4ed51ebdf5539ba6ad341f18d73b643481b5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI0NzE4ODk1Mw==&mid=2652092096&idx=2&sn=c8decf251172b8b3f6aa66f36a8bd0fc&chksm=f254ca76c5234360900e90e113d0ba6838b211bb4ed51ebdf5539ba6ad341f18d73b643481b5&scene=27#wechat_redirect)

![](../Images/278d409c22c4a7fd4719cf8a8fec8cac.png)

  

为进一步打击网络谣言，营造清朗网络空间，自2月1日起，中央网信办举报中心通过中国互联网联合辟谣平台推出“今日辟谣”专栏。

![](../Images/35cd2124b38c2c2e4b96518e2a910660.png)

“今日辟谣榜”旨在传递事实真相，传播科学知识，帮助公众获得权威、准确的真实信息。栏目设置“今日辟谣”“今日科普”及“今日提示”三大版块，每日聚焦群众关心关切的重要辟谣内容，对涉及公共政策、突发事件、医疗健康等领域的网络谣言及时回应。

![](../Images/4df0b9e69ef7474a4f40670ac33e0509.png "图片2.png")

发布涉公共政策、突发事件、民生热点等领域的重要辟谣信息。

![](../Images/cbe6444784ce791306c7f22ae3821dd1.png "图片3.png")

发布与群众生活息息相关、有助于提升公众防谣防骗能力的科普内容。

![](../Images/c66dcb328ca8c7074f7f1295950eca4b.png "图片4.png")

通报打击造谣传谣违法行为或当期相关法律常识、公益提示等。

欢迎广大网友关注中国互联网联合辟谣平台“今日辟谣榜”，积极提供谣言线索，共同阻断谣言传播链条，净化网络环境，营造文明和谐的网络家园。“谣言线索提交”通道https://www.piyao.org.cn/xxjbrk.htm
