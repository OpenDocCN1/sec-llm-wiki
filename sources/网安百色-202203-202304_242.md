### **0x01 漏洞详情**

Microsoft Endpoint Configuration Manager（MECM） 是一个针对 Windows 端点的管理平台，提供清单、软件分发、操作系统映像、设置和安全管理等功能。9月20日，Microsoft发布带外安全更新，修复了Microsoft Endpoint Configuration Manager中的一个欺骗漏洞（CVE-2022-37972），该漏洞的CVSSv3评分为7.5。该漏洞影响了Microsoft Endpoint Configuration Manager 版本2103-2207，成功利用此漏洞可能导致敏感信息泄露，目前已经公开披露。  
**影响范围**Microsoft Endpoint Configuration Manager 版本 2103-2207

  

### **0x02 安全建议**

目前微软已经发布了此漏洞的安全更新（KB15498768：当禁用“允许连接回退到 NTLM”选项时，该更新可防止对客户端推送安装进行 NTLM 身份验证的任何尝试 ）。对于运行 Microsoft 端点配置管理器 2103 -2207 版本的客户，该更新将在配置管理器控制台的更新和服务节点中列出，受影响用户可及时安装。补丁参考链接：https://learn.microsoft.com/zh-cn/mem/configmgr/hotfix/2207/15498768
