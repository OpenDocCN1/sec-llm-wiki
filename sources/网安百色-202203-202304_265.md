# Google 发布紧急 Chrome 更新以修补新的零日漏洞

谷歌上周五发布了紧急修复程序，以解决Chrome网络浏览器中存在的一个安全漏洞，该漏洞表示正在被积极利用。该问题被分配了标识符CVE-2022-3075，涉及Mojo中数据验证不足的情况，Mojo指的是为进程间通信（IPC）提供与平台无关的机制的运行时库的集合。

一位匿名研究人员被认为在2022年8月30日报告了这一高严重缺陷。“谷歌意识到有报道称，CVE-2022-3075的漏洞利用存在，”该公司表示，但没有深入研究有关攻击性质的其他细节，以防止其他威胁行为者利用该漏洞。

建议基于Chromium的浏览器（如Microsoft Edge，Brave，Opera和Vivaldi）的用户在修复程序可用时应用这些修复程序。
