漏洞名称：

DirtyPipe内核提权漏洞（CVE-2022-0847）

组件名称：Kernel

影响范围：5.8＜=linux内核版本＜5.16.11/5.15.25/5.10.102

漏洞类型：本地权限提升

漏洞编号：CVE-2022-0847

利用条件：无

综合评价：

<利用难度>：低

<威胁等级>：高危


#1 漏洞描述

在pipe操作中，pipe->bufs写入后对应的buf->flags没有清除，导致下次对pipe写操作会copy数据到buf->page（对应只读打开的文件page），使得以只读方式打开的文件被写入数据。

#2 解决方案

升级 Linux 内核
Linux 内核 >= 5.16.11
Linux 内核 >= 5.15.25
Linux 内核 >= 5.10.102
