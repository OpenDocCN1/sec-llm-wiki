一、简介

  DoubleAgent是一种新的零日技术，用于在机器上注入代码和维护持久性（即自动运行）。这是一个由Cybellum公司在5年以前公开的漏洞。

DoubleAgent 利用了 15 年前的 Windows 合法功能，因此无法修补。

DoubleAgent 使攻击者能够将任何 DLL 注入任何进程。代码注入发生在受害者进程启动的极早阶段，使攻击者可以完全控制进程，并且进程无法保护自己。代码注入技术是如此独特，以至于任何防病毒软件都无法检测或阻止它。


二、利用版本

每个 Windows 版本（Windows XP 到 Windows 10）

每个 Windows 架构（x86 和 x64）

每个 Windows 用户（系统/管理员/等）

每个目标进程，包括特权进程（操作系统/防病毒/等）


三、持久性

DoubleAgent 可以在重新启动后继续注入代码，使其成为“生存”重新启动/更新/重新安装/补丁/等的完美持久性技术。一旦攻击者决定将 DLL 注入到进程中，它们就会永远被强制绑定。即使受害者完全卸载并重新安装其程序，攻击者的 DLL 仍然会在每次进程执行时被注入。
