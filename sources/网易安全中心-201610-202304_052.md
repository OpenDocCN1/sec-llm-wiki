一、什么是Python供应链攻击

向python公共仓库或私有仓库投递精心构造包名且包含恶意代码的python库，在setup.py文件中植入，则安装时会执行恶意代码，在\_\_init\_\_.py或其它文件中植入，则导入、使用库时会执行恶意代码。

二、攻击方式有哪些

python供应链攻击有很多种方式，可以广撒网，当海王，也可以目标专一，精准打击。  

**1.**企业内部私有包抢注****  

  

企业内部拥有私有化部署的python仓库，以及内部开发的python库。如果内部python库的名字泄露，攻击者就可以通过在官方仓库注册私有库，对目标企业进行定向攻击。  
  
  
  

中招场景

  
  
  
  

（1）公司员工直接使用pip install internal\_package\_name的方式从pypi.org安装私有库；

（2）公司员工已配置默认从私有仓库安装，但使用--extra-index-url参数指定额外的仓库。这种情况下pip会同时查找私有库和额外指定的仓库，选择高版本进行安装。

**三、官方缓解机制**

1.  检测空包，并删除；
    
2.  禁止注册python内置包名；
    
3.  禁止注册requirements类似包；
    
4.  第三方检测恶意包，并通知官方，官方会将包名加入黑名单，禁止上传包被上传后，世界各地的官方镜像仓库会进行同步，会出现官方仓库将恶意包删除后，镜像仓库仍然存在恶意包的情况。
    

**四、如何防御和检测**

1.  基于内部包名检测官方仓库是否存在相同或相似包名，对于命中包进行分析；
    
2.  从正规仓库进行安装，遵循官方包安装文档，检查是否存在输入错误；
    
3.  统一使用内部源，发生供应链攻击时，可以迅速删除恶意包，切断传播；
    
4.  内部源从官方同步时，沙箱实时检测；
    
5.  监测pip进程的网络连接行为。
