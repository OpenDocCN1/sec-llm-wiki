# 实验室韩光洁教授入选全球顶尖前10万科学家排名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1MTQwMjYwNA==&mid=2247489147&idx=1&sn=616b42bf538d66415e7d76e551609cac&chksm=e9f2d678de855f6e31a054138367df5cd70c0ea4b5bc6da5987bb9dce48a7ffc646683d9a919&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1MTQwMjYwNA==&mid=2247489147&idx=1&sn=616b42bf538d66415e7d76e551609cac&chksm=e9f2d678de855f6e31a054138367df5cd70c0ea4b5bc6da5987bb9dce48a7ffc646683d9a919&scene=27#wechat_redirect)

近期，国内全球学者库网站公布了“全球顶尖前10万科学家排名”，实验室韩光洁教授入选，祝贺！

 “全球顶尖前10万科学家排名”是北京同舟云网络信息技术有限公司基于其研发的全球学者库亿级海量文献数据基础上，运用强大的AI信息处理与数据挖掘技术，依据其独创的先进科技文献质量评估计分规则与方法对全球所有学科的学者文献进行集中处理和计算后得出的全球顶尖前10万科学家排名表。

本排名表旨在帮助全球学者，特别是中国学者了解各个学科领域的专家和领军人物，追踪学科领域的研究前沿。在排名表研制过程中，始终秉持开放的原则，所有数据来源均真实可靠，并可追溯核实，排名不受任何外界环境和经济因素所影响，坚持公平公正的原则。本排名表中的内容会随着新文献数据的加入以及学者学科归属的校正处于动态变化当中。上述排名采集时间为2022年1月14日 22：00。

  

  

专家简介

  

  

![](../Images/d81b52984d2484ac82e2c5d03550ace8.png)

韩光洁

![](../Images/d81b52984d2484ac82e2c5d03550ace8.png)  

![](../Images/7310f8593036e80bc461405ad996ac6f.png)

  

韩光洁，博士，教授/博导。全国工业机械电气系统标准化技术委员会SAC/TC231/SC3委员、IET Fellow、EAI Fellow、IEEE高级会员、CCF杰出会员、ACM会员、中国计算机学会物联网专委会常务委员和计算机应用专委会委员，中国自动化学会边缘计算专委会委员和人工智能与工业应用专委会委员、中国仿真学会机器人系统仿真专委会委员、中国人工智能学会智能信息网络专业委员会委员、江苏省计算机学会理事。2009.06成为河海大学优秀创新人才；2009.12 成为常州市“831高层次创新创业人才培养工程”首批中青年骨干人才；2012.12成为常州市“龙城英才计划”创新创业领军人才；2014.01成为溧阳市专业技术拔尖人才；2014.04成为江苏省高校青蓝工程学术带头人；2015.10成为江苏省双创人才称号（企业副总）；2016.10成为江苏省六大人才高峰高层次人才；2018.03成为辽宁省高等学校创新人才；2018.04成为全国专业标准化技术委员会委员；2018.09成为河海大学大禹学者（第二层次）；2018.12成为闽江学者讲座教授；2019.04常州市五一奖章荣誉称号；2020.07成为江苏省有突出贡献的中青年专家；2021.07获得常州市推进“五大明星城”建设（科技创新）先进个人荣誉称号。主要研究方向为物联网，人工智能，水下通信与组网、网络安全等。近年来在IEEE COMST, IEEE JSAC, IEEE TMC, IEEE TWC, IEEE TIE, IEEE TPDS, IEEE TCC, IEEE TIFS, IEEE TII, IEEE IoT Journal, IEEE Systems, IEEE Wireless Communications, IEEE Communications和IEEE Network等国际期刊及国际学术会议上发表SCI/EI检索论文487篇，SCI期刊论文318篇（其中IEEE/ACM Transactions系列汇刊70+篇，第一/通信作者SCI期刊论文270篇，SCI一区118篇，SCI二区128篇，IF＞3的SCI期刊论文228篇，IF＞9的SCI期刊论文59篇，ESI热点论文1篇，ESI高被引论文23篇，第一/通讯作者ESI高被引论文21篇），到目前为止Google Scholar引用次数10000+次，H-index为51。连续3年（2019-2021）入选全球排名前2%的科学家 (Stanford University List of World's Top 2% Scientists) 榜单，包括“终身科学影响力排行榜”（1960-2021）和“科学影响力排行榜”两个榜单；入选爱思唯尔2020年10万科学家终身科学影响力排行榜（Career Scientific Impact）榜单；入选爱思唯尔2020年中国高被引学者（Highly Cited Chinese Researchers）榜单。已出版专著2部、译著1部。主持/参与包括国家重点研发计划、国家重大科技专项及国家自然科学基金重点项目在内的60余项科研项目，其中国家级/省部级以上项目共40余项。授权国家发明专利106件（第一发明人74件，转让14件），PCT美国、加拿大、日本、澳大利亚、韩国授权专利各1项。获得中国商业联合会科学技术奖二等奖1项（排名第一）、江苏省科学技术奖三等奖1项（排名第一），江苏省教育教学与研究成果奖二等奖2项（排名第一），辽宁省科技进步二等奖1项，IEEE Systems Journal 2020最佳论文奖（排名第一）。目前任20多种国际期刊（其中包括IEEE JSAC, IEEE TII, IEEE TNSE, IEEE TGCN, IEEE Communications, IEEE Wireless Communications, IEEE Network, IEEE Systems, IEEE Sensors, IEEE/CCA JAS, IEEE ACCESS, Computer Networks, Sensors, Telecommunication Systems, WCMC, IJAHUC, TIIS, JIT, SCN, IJDSN等）编委或客座主编。国家重点研发计划、国家自然科学基金、国家火炬计划、教育部博士点基金、江苏省科技计划、山东省科技计划、浙江省科技计划、黑龙江省科技计划、河北省科技计划、重庆市科技计划等项目评审专家。
