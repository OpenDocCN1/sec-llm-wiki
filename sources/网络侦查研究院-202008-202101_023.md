**4 提权/维权**

前面得知这个机器是 windows server 2008，尝试用土豆提权（MS16-075）

![](../Images/99f99fd9a73c619a65f9b41d56b12ebf.png)

执行后稍等了一会儿，比较幸运，这个机器没打补丁，一次就提权成功，拿到 system 权限，开始为所欲为

![](../Images/21d4755dbd345cb6ee7cf4e0bbe5db9f.png)

进入文件管理，能看到前面信息收集时的 test.html 文件

![](../Images/105fbf8c95e196ccda6c30f451115bf3.png)

netstat -ano 看一下端口开放情况，3389 没有开

![](../Images/4def57e2903d8819497b8443d62b9a30.png)

手动开启一下

![](../Images/f535d95a4a208eef5ef6bb279f99a642.png)

可以访问远程桌面了

![](../Images/ea8e921553a8c8c31c5f73d59b9ca83d.png)

![](../Images/af7c3a944f402bd91e007d2fe0af4da7.png)

  

![](../Images/4c2608bcae757503190a8dec2c8c5c8d.png)

![](../Images/573a63c0b24afba7b39df19f7749c2ba.png)

在 cs 上运行上传的马

![](../Images/90d5b4bd0baff256c6144d7ad91f772b.png)

![](../Images/985d66deef68256d81f4fe6433731150.png)

![](../Images/422533e764199e9548f0e9b29e02dbae.png)

到在线破解哈希的网站查一下 administrator 的密码，密码不算复杂，几秒钟就查到了
