# Depix

\--------------  

Depix是用于从马赛克屏幕快照中恢复密码的工具。  
此实现适用于使用线性框滤镜创建的马赛克图像。在本文中，我将介绍有关马赛克和类似研究的背景信息。

## Algorithm

\---------------------  

该算法利用了线性盒式滤波器分别处理每个块的事实。对于每个块，它将对搜索图像中的所有块进行马赛克以检查直接匹配。  
对于大多数马赛克图像，Depix设法找到单匹配结果。假设这些是正确的。然后，将周围的多匹配块的匹配进行比较，以在几何上与马赛克图像中的距离相同的距离进行比较。匹配也被视为正确。重复此过程几次。  
正确的块不再具有几何匹配之后，它将直接输出所有正确的块。对于多匹配块，它输出所有匹配的平均值。

## 什么是马赛克？

\-------------------------  

马赛克描述了部分降低图像分辨率以检查信息的过程。我算法的实现攻击了普通的线性盒滤波器。线性框滤镜采用一个像素框，然后用该框中所有像素的平均值覆盖像素。它的实现非常简单，并且可以快速运行，因为它可以并行处理多个块。下图显示了线性盒式滤波器的示例。表情符号的图像分为四个块。块的平均颜色会覆盖块的像素，从而产生最终的马赛克图释。由于原始信息丢失，因此无法直接反转过滤器。
