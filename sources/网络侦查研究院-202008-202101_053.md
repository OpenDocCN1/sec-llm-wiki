**圈套诱因**  

# 

近年来，虚拟货币越来越流行，各种与虚拟货币相关的平台层出不穷。当然，陷阱也在我们身边不同层面出现过。最近接到一个电话，声称能让我一夜暴富。为了找到答案，我开始了一段旅程。

![](../Images/ba418f953b54faa7166e9bddaa3ff862.png)

通过电话指导，一个叫客服的人加了我的微信，把我拖进了一个微信群。我们可以看到这一组人数不少，但不知道有多少人进入了这场局。

![](../Images/958a0f8c101bd938c723a34de4558311.png)

进入群内，有各种自称是币圈大佬老玩家的人物，活跃在群内。至于他们的身份是真是假，我不敢说也不敢问。但没过几天，群主声称某平台的客服开始出现，并推出了虚拟货币游戏。福利非常诱人，也引起了我的兴趣。

![](../Images/69bf1ac560d4c3fc0e002dbaa4c75f30.png)

![](../Images/2c303d4697aca944a130157143ad45ff.png)

这个亮眼的标题，诱人的回报，让我成为一个农民工，也正是这个夸张的宣传，暴露了这个平台不靠谱的感觉。于是，为了揭开这个游戏的完整套路，我们开始了艺术之旅。

**权限提升**

![](../Images/ec60823d417ff0cba406e8fa37164adf.png)

**狙击黑手的准备（一）**

# 

![](../Images/cd8e1cc7d9fe0f54de086ec9e05eacd6.png)

下载地址：

https://github.com/outflanknl/EvilClippy/releases

首先利用CobaltStrike生成Office宏病毒，单击“CobaltStrike”->“监听器”，在下方选择“Add”，随便输入名字，如“Office”,HTTPHosts为CobaltStrike服务端的IP，这里我架设到公网上了，随意设置监听端口，如“8888”。

![](../Images/f0347de996f94a4f135b08e0ccdfcc94.png)

选择“攻击”->“生成后门”->“MS OfficeMacro”开始生成Office宏代码，监听器选择刚刚我们开启的。

![](../Images/08925b947ed88825323d10edf2d257b2.png)

选择监听器后，单击“Generate”。

![](../Images/2b5acb0a0cdd275d122b7fbe42dabddf.png)

单击“CopyMacro”将这段利用CobaltStrike生成的恶意代码复制下来，接下来打开Word，我这里根据实际情况认真写了点东西，毕竟一切为了钓鱼成功嘛。先保存为启用宏的文档。

![](../Images/67c3328d5ec711fe0f2f320e553af620.png)

然后单击“视图”->“宏”,然后宏名任意设置，宏的位置为当前文档，再单击“创建”先将原有的代码清掉，这里注意一定要删掉再粘贴之前CobaltStrike生成的代码，我也不太清楚为什么，不清掉直接覆盖有时候就不好使（玄学疑惑）。

![](../Images/4c96b061a380b2f2fedd89d6d1e246f7.png)

保存完后，利用virscan进行一波检测，地址：https://www.virscan.org/

![](../Images/8291789702b36057363d9b24d5029d10.png)

这显然不行，这下就用到了我们之前提到的工具EvilClippy1-1.3，该工具使用很简单，首先准备一个正常的VBA代码，test.vba代码如下

*   
*   
*   
*   
*   

```
Sub test()'' 该vb代码没有任何功能，用于迷惑杀软。'End Sub
```

  

没有错代码就是这么骚气，然后执行命令EvilClippy.exe -s test.vba计划报表.docm，出现下图所示即为成功，同时生成一个新得docm文件

![](../Images/7720869ce2011a091d47fac04830d080.png)

![](../Images/aa38b423d8b7eec6bdba1e94cf3cee64.png)

再次将该文件放到virscan进行查杀，这回就有一个检测出来了，静态免杀基本就完成了。

![](../Images/5f89d40b800e6aeb1265f81b06dd964c.png)

然后测试通过。

测试成功上线CS，露出了欣慰的笑容。

**狙击黑手的准备（二）**

测试连通性：

swaks --to xxxx@qq.com

![](../Images/faa8690050fd6447d4c7df7cef359f77.png)

*   
*   
*   

```
swaks --to xxx\@qq.com --from110\@police.com --body hacking --header "Subject: hello" --attach xxxxx.docm--server mail.smtp2go.com -p 25 –au <USER> -ap <PASSS>
```
