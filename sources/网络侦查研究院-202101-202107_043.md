# 为不法分子洗白3000余万 一网络工作室6人被捕

电信网络诈骗犯罪活动，严重危害群众的财产安全。7月4日，北青-北京头条记者从黑龙江警方获悉，黑龙江省双鸭山市公安局以“零容忍”态度重拳出击，于近日成功抓获6名帮助信息网络犯罪嫌疑人，冻结银行卡120余张。

![](../Images/a1a64626136562fc14f2abaec71710ec.png)

6月初，尖山公安分局刑侦大队陆续接到李某成等6人的“断卡”线索，随即开展侦查。经调查发现，6人之间相互关联，涉嫌利用某网上工作室进行洗钱等犯罪行为。  

6月21日，尖山公安分局所队联动，分别在尖山区金龙小区、南市区等地将犯罪嫌嫌疑人李某成等人抓获。

经讯问，以李某成为首的6名犯罪嫌疑人，对其利用某网络工作室网站为不法份子洗钱3000余万元，共计获利10余万元的犯罪事实供认不讳。

目前，李某成等人已被依法采取刑事强制措施，案件正在进一步侦办中。
