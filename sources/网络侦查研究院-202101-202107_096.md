# 上海严厉打击网络违法犯罪活动，筑牢网络安全线

6月17日，上海市公安局召开新闻发布会，介绍上海警方维护网络安全措施成效，通报典型案例。

  

**一、严厉打击网络违法犯罪行为**

![](../Images/72dd19ac27d672fadbb4ca96599699dc.png)

  

随着互联网的发展，传统犯罪加速向互联网蔓延转移，融合互联网非接触的特征，催生了日益多样化、体系化的网络黑灰产业。从源码搭建、售卖信息到资金转账，网络黑灰产业助力电信网络诈骗、网络黄赌毒等违法犯罪活动，严重损害网民切身利益，危害网络空间安全有序。

  

对此，上海公安网警部门多措并举、集中打击，持续开展“净网”专项行动，全力遏制网络黑灰产业，2020年以来，**累计侦破黑灰产类案件1300余起。**

  

01．阻断“技术链” 

  

警方开展“断卡、断号、断设备、断软件”的“四断”专项行动，严厉打击为犯罪分子提供技术、账号、平台等源头性软硬件设备和服务的违法犯罪行为。

  

近期，警方发现了一种名为“暗雷”的新型黑产技术，通过搭建含有木马病毒的不法APP，帮助不法分子获取非法利益，已经**连续捣毁2个利用此项技术实施诈骗行为的犯罪团伙。**

  

02．深查“资金链” 

  

紧盯网络违法犯罪的资金流向和通道转变，重点侦查打击大量购买空壳公司、批量注册第三方支付商户和个人账户等异常行为。今年以来，**连续破获为网络赌博、裸聊敲诈勒索等犯罪提供资金结算、搭设网站、网络刷赞刷粉等案件近400起。**

  

03．打击“生态链” 

  

建立打击网络黑灰产定期联席会议及情况通报工作机制，**研析网络黑灰产新手法、新特点，构建网络黑灰产数据库，加强数据分析研判**，形成定期预测、预警、预防发布机制。针对账号买卖、搭建违法犯罪网站和APP等问题，联合行业主管部门、监管单位建立网络安全防护网，及时消除行业风险漏洞，努力铲除黑灰产“生存土壤”。

  

**二、全力建设网络空间防控体系**

  

![](../Images/70bab038146922455f5aade3e31f4e92.png)

  

上海公安网警部门以守护城市网络安全为目标，全力建设网络空间防控体系，为数字城市建设提供有力保障。

  

01．持续提升安全防护能力 

  

将云计算、物联网、移动互联、工业控制系统、大数据等新技术、新应用全部纳入保护范畴。联网单位覆盖面由传统上网场所扩展到网络新生业态，**涵盖了本市10大类3000余个重要信息系统以及30余万个网站与APP。**

  

近年来，**共开展网络安全监督检查1.6万余家次，对于不履行网络安全保护义务的800余家单位依法予以行政处罚**，确保本市重要行业领域信息系统总体安全。

  

02．持续提高隐患发现能力 

  

注重主动防御、动态防御、整体防护和精准防护，督促网络运营者做好**网页防篡改、服务防中断、数据防泄漏、网站防病毒的“四防保障”**，对病毒防范不完善、监测预警机制不健全等问题，第一时间指导和督促整改。

  

在浦东新区先行先试，建立辖区网络安全管理平台，实时监测本辖区网络安全态势，期间监测发现4家单位网络终端遭病毒感染、木马植入，及时开展有效整改，将风险隐患扼杀在萌芽之中。

  

03．持续助力智慧城市发展

  

针对线上教学、网上医疗服务需求增多情况，与市卫健委、市教委共同启动网络安全联防联控机制，对全市教育类APP和网课平台、互联网医疗机构的信息系统开展监督检查，及时发现、整改系统安全隐患。

  

**三、积极构建和谐清朗网络空间**

  

![](../Images/622755df4436c9a1551e9a7f9b818fae.png)

  

上海公安网警部门强化落实本市涉网主体网络安全责任，集中整治网络生态乱象，依法查处网上违法违规行为，促进本市互联网业态健康发展。

  

01．强化网络主播准入机制 

  

落实主播用户实名制，不允许未满18周岁的用户进行网络直播。对于直播过程中出现衣着暴露、抽烟喝酒、语言粗俗等违规行为予以扣分，直至暂停其直播活动。一旦发现利用网络直播平台传播、散布违法有害信息或者实施诈骗、黄赌等违法犯罪活动，即依法查处并予以全市通报、全网禁播。自2020年以来，**累计禁播网络主播40名。**

  

02．建立“一站一策”青少年上网保护机制 

  

指导网络直播、网络音视频类平台**建立风纪委员会**，指导论坛、社交平台，**完善青少年用户认证**，对于不良价值观引导、教唆青少年犯罪等有害信息进行内容审核与清理；指导网络游戏平台实行“适龄提示”，**建立防沉迷系统**，并将游戏与抗疫、防诈等结合，寓教于乐。

  

03．建全网上违法信息处置机制 

  

开展全天候网上巡查，持续深入整治清理网络有害信息，及时发现、澄清网络谣言，有力维护风清气正的良好舆论环境，提升网民法治意识。同时，全方位多渠道开展辟谣宣传，通过公安新媒体矩阵公开辟谣、依法处罚案例，形成良好社会警示效应。
