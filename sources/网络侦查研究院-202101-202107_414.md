# **开始**

接到任务，分析一恶意APP，涉嫌盗取用户通讯录、短信、定位信息，并对中招用户进行勒索。

# **代码审计**

  

网站整体代码质量不高，使用D盾扫了下危险函数，发现一处上传文件的代码。![](../Images/50539148729b3cf3fa7a6236ef4675d1.png "89209-etrmfnbiti.png")找到了fileupload.php文件,开始进行本地审计测试。![](../Images/1ed195e931480c7ab60d48de7057822c.png "21946-o89zgrodv5.png")这段代码并未校验cookie，同时需要传递一个name参数，作为文件名，之后一路向下![](../Images/412a2e75e042518a7d72b5eef274c2ac.png "68951-tv09d4j3sdp.png")只要不满足那一堆if就可以到达文件上传处，很明显正常传文件也不是那么容易满足这堆条件，因此写POC直接上传即可。
