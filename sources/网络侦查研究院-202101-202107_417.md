# 166万人被骗3000万元！最近全网刷屏的网红游戏翻车了？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxOTM2MDYwNg==&mid=2247501813&idx=3&sn=a8711eb700f9f618339801edecf5ea5d&chksm=97defbc4a0a972d232a2e477cdde6f19f69b293705cdcbb585802dece0ca49eb7731c3fa28d0&scene=126&sessionid=1681402178#rd](http://mp.weixin.qq.com/s?__biz=MzIxOTM2MDYwNg==&mid=2247501813&idx=3&sn=a8711eb700f9f618339801edecf5ea5d&chksm=97defbc4a0a972d232a2e477cdde6f19f69b293705cdcbb585802dece0ca49eb7731c3fa28d0&scene=126&sessionid=1681402178#rd)

“有的人熬夜写论文，有的人4点不睡合成大西瓜，他们都有光明的未来。”

  

“有人相爱，有人夜里看海，有人合成大西瓜一整天合不出来。”

  

要说今年中国最火爆的游戏，合成大西瓜绝对能算一个，甚至不少人在周末为了它熬了一个通宵。

  

根据制作方微伞游戏的数据，截止到2月7日中午，合成大西瓜的玩家数已经接近9000万。

  

![](../Images/a59f3adcf49f8b039673ef0187e31aca.png)

  

然而万万没想到，就在这两天，合成大西瓜又上热搜了。

  

只不过，这次不再是因为让无数人玩得上头，而是因为这款2021年现象级游戏翻车了。

  

这还要从游戏界面右上角的宝箱说起。

  

![](../Images/a87a4f2e949d29b207feac9d6e26cfd0.png)

  

近期，许多网友发现，这款小游戏背后隐藏着深深的“套路”：点击游戏界面右上角的宝箱图标，就会跳转出抽奖大转盘的页面。

  

每次点击大转盘后，几乎都会显示抽中“100元手机话费券”等礼品。

  

此外，每轮游戏结束后，也会弹出“红包大派送”、“刮奖”、“抽奖转盘”等五花八门的所谓“中奖”活动。

  

奖品有时是保额一万元的保险，有时是联通流量包，有时是手机靓号。

  

![](../Images/871175b7070b26b4db8cd1cbc233f1ca.png)

  

点击领取奖品后，界面就会提示需要用户预先支付9.9元~19.9元，而且显示“领不到话费，全额退款”。

  

很多网友走到这一步，想想19.9元换100元话费也值得，于是便支付了。

  

而当用户支付后，才发现话费无法兑现，也不能退款。

  

![](../Images/dd42e1bfd717d19702a1b66e8c4a17bc.png)

  

还有网友表示，“那个广告不是一般的多，属于稍不留心就点进广告页面里的多。每次我都是看都不看很烦躁的关闭以后继续我的游戏。”

  

据了解，被抽奖广告哄骗的多为长辈，有用户表示觉得游戏挺好玩发到了家庭群，结果就有家人上当受骗。

  

还有人称，其实那个19.9的下面有一行特别特别小的字，意思是19元为会员费，不仔细看根本看不到。

  

![](../Images/4200c15a15d6e3d74988209528a353bf.png)

![](../Images/c2d0a7d191cb0f25cb1a8c35478e0818.png)

  

根据中新网的报道，按照当时的中奖界面截图来看，已有超166万人领取了这样的话费券。

  

如果按每个人支付19.9元来计算，涉及的总金额已超3000万元。

  

在黑猫投诉上，也已经有很多网友反映合成大西瓜的“中奖”骗局：“申请退款迟迟收不到退款”，“在公众号申请客服也没有回应”。

  

![](../Images/68593c36c0530f0302eccb20d4cabe29.png)

  

目前，抽奖服务背后的几家公司与微伞游戏之间关系还不明朗。

  

根据黑猫投诉平台上的信息显示，这一骗局不仅牵扯到合成大西瓜这款游戏，其他平台上也大量出现过类似的套路。

  

根据投诉信息，快手、黑牛购、哈罗出行上均弹出过类似的19.9元换100元话费的购买信息。

  

![](../Images/73fe29fde3820a9c9d475fe06174eae6.png)

  

![](../Images/886eaba12455b03a45fa219b0af269d5.png)

  

实际上，近年来，此类网络抽奖套路事件并不少见。

  

部分消费者被奖品信息吸引，最后才发现被骗，甚至是被套取个人隐私。

  

大量玩家被骗已是事实，仅一个话费券的小骗局就圈住了166万人，这款引起全民狂欢的小游戏，属实不一般。

  

截止撰稿时，实测发现，如今游戏中的宝箱图标及相关广告链接已经消失。  

  

![](../Images/db48ed663683493eb5b2020d281522b7.png)

  

对此，北京云亭律师事务所律师魏广林表示，该行为属于典型的以非法占有为目的，隐瞒事实真相，使玩家陷入错误认识，骗取财物的诈骗行为，诈骗数额较大的，应当以诈骗罪追究刑事责任。

  

不过，合成大西瓜虽然翻车了，大家也不用替它感到可惜。

  

因为合成大西瓜的源代码已经在GitHub上开源，网友只需要进行简单的修改，就能做出各种新的版本。

  

![](../Images/f5b96cd7ea367525fe62a7257eea3aab.png)

  

总之，各种版本的合成大西瓜只有你想不到，没有程序员做不到。

  

在衍生版本的加持下，“合成XXX”游戏俨然越来越火爆。

  

最后，再次提醒广大网友：天上不会掉馅饼，先找你要钱的中奖信息，千万别信！
