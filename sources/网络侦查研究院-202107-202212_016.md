# 涉案资金2.5亿！警方将跨省网络赌博犯罪团伙“一锅端”

利用玩游戏、交友等名头做幌子，APP内设置的竟是一个又一个的小赌场。玩家购买游戏币后，通过“砸金蛋”“打地鼠”等游戏方式赌博。更让人没想到的是，制作APP并开设赌场的犯罪团伙成员大多年龄只有20岁出头，而参与赌博的赌客竟涉及全国20多个省市，数量达7万余人。近日，内蒙古自治区包头市公安局直属侦查三分局成功侦破了这起跨省网络赌博案。

# APP内开赌场

2021年5月，包头市公安局直属侦查三分局民警发现一网络游戏APP背后竟隐藏着赌博陷阱。经初步调查，以王某为首的犯罪团伙进入警方视野。

随后，警方经摸排发现，王某等人通过一款APP不断拉人参与赌博。APP内看似是一个个游戏房间，实则是一个又一个的小赌厅。和以往“诈金花”“打麻将”不同的是，这款APP是通过“砸金蛋”“打地鼠”等以小博大的游戏方式进行赌博，赌资少则几元、多则几千元甚至上万元。

警方在随后的调查中发现，整个犯罪团伙分工明确，有专门负责APP维护同时操纵赔率的技术人员，有专门运营网厅兑换游戏币的客服，还有专人通过各种网络平台引流，诱惑更多的人参与到赌博中来。

同时，民警注意到，该团伙成员都是年轻人，其中年纪最大的36岁，最小的刚20岁。他们不仅懂网络、懂技术，而且警觉性很高，制作的APP最多使用20天便会彻底销毁，所有数据全部清除。随后再制作一款新的APP，犯罪行踪很难被发现。

# 跨省出击一举抓获

案件发生后，警方不放过任何蛛丝马迹，通过一点一点摸排调查，最终将犯罪网络逐渐捋清。据办案民警介绍，参与该起网络赌博案的赌客涉及20多个省市，每天资金流水量达1000万余元，所涉赌博平台总流水高达2.5亿余元。而犯罪嫌疑人也分布在多个城市，彼此之间大多都不相识，平日里以网名相称，多是通过网络招揽后进入到该犯罪团伙。

为了尽快将犯罪嫌疑人抓捕归案，民警加班加点收集证据，将每一个环节落实完善。就在收集相关证据的过程中，民警发现犯罪团伙似乎有了警觉，开始频繁更换赌博平台，并有了加快转移资金的迹象。2022年5月，分局党委果断决定立刻出击，将犯罪团伙一网打尽。

在固定相关证据后，直属侦查三分局局长李志宇指挥，派一路由副局长郭晓童带队的抓捕组前往广东省广州市，与前往江苏省南通市和留守包头的另两路民警同时开展收网行动。经过前期大量工作，专案组对于犯罪嫌疑人的身份特征、落脚点和出行习惯早已熟知。

5月28日凌晨至5月29日，抓捕组分别在广州、包头、南通三地同时收网。其中，广州抓捕组在该团伙位于广州天河区的公司内，成功抓获主要成员王某、刘某某等人以及专门负责为赌博网站推广引流的客服人员共计50余人，现场查获工作电脑100余台、手机100余部。

![](../Images/494c41725c53479b6c8b1d397f8bb2e8.png)

  

5月31日，专案组在两天高强度的抓捕和审讯之后，乘坐火车奔波2000多公里，历时40余小时将全部犯罪嫌疑人顺利押解回包头。目前，该案已被自治区公安厅列为2022年十大专案之一进行督办。

# 从玩到做巨额获利

在随后的审讯过程中，犯罪嫌疑人详细讲述了自己是如何“入坑”的。据主犯王某供述，他们当中大多都是二十多岁刚毕业还没正式工作的年轻人，大家在网络上相识，通过网络交友平台一起玩游戏，也在游戏中输掉了一些钱。由于不甘心输钱，几人便商量也要通过同样的方式把这些钱“赚”回来，没想到却越陷越深。

“像‘砸金蛋’这种以小博大的赌博游戏，我们也是从网络上了解到的，觉得没有什么技术含量，加上周围有好多懂网络技术的朋友，所以大家就商量着一起做这件事情。”犯罪嫌疑人王某交代，“一开始就是想着把输掉的钱赢回来，最后越‘赚’越多，也就越陷越深了。”

犯罪嫌疑人刘某某交代，自己擅长APP技术维护，由于一开始就认识王某，所以很相信他，没想到最终会触犯法律。

记者了解到，参与赌博过程中，赌客们大多是输多赢少，只要一直玩下去大多都是输，少则几千元，多则上万元。而犯罪嫌疑人们“入行”后，高额的获利让他们逐渐沉迷于“灯红酒绿”之中，频繁的高额消费让他们难以自拔，于是便抱着侥幸心理，认为非法获利可以通过“洗白”逃避法律，然而最终还是难逃法网。

嫌疑人王某表示很后悔：“虽然赚了很多钱，但在20多岁就失去了自由，我真的很后悔，也希望借此提醒所有年轻人，不要因为一时冲动走上歪路，20岁应该是最美好的年纪，一定要珍惜。”

# 警方提示

在使用互联网的过程中，一定要擦亮眼睛，对这种以小博大的伪装“游戏”要有所警觉，不要一时冲动，触犯了法律红线，终将受到法律的制裁。

目前，该案件仍在进一步侦办中。
