# 涉案数千万元！芜湖警方成功打掉一个帮助信息网络犯罪“跑分”团伙

![](../Images/f7bc1944199964ea3737c13d60b04057.png)**网络侦查研究院** 服务全国情报侦查人员，培养网络情报思维，提高网络情报侦查能力。公众号该公众号已被封禁

据平安芜湖消息，曾因涉嫌“帮信”犯罪被警方依法处理。回归社会后，却仍想利用“跑分发财”。因担心自己“出面”被公安机关查获，遂做起“幕后指挥”……7月13日，芜湖市公安局镜湖分局结合夏季治安打击整治“百日行动”，成功打掉一个帮助信息网络犯罪“跑分”团伙，主犯李某及8名同伙被缉拿归案，收缴一批作案工具，查明涉案金额数千万元。

![](../Images/f9bf1e5b8b3f12380a1663bda32095fd.png)

今年5月中旬，镜湖分局犯罪侦查大队接到省公安厅推送线索：一个“跑分”团伙在芜湖、福建、湖北等地大肆办理银行卡。大队立即组织民警开展侦查，通过近两个月的研判摸排，锁定该犯罪团伙主要人员李某及同伙身份信息。

时机成熟！镜湖分局结合夏季治安打击整治“百日行动”，决定开展集中收网行动。

7月5日上午，分局组织30余名警力分别在嫌疑人活动区域布控。

正值炎炎酷暑，芜湖市持续高温。办案民警克服考验，冒着酷暑经过一昼夜紧张行动，共抓获赵某、夏某等6名涉案人员，收缴一批电脑、银行卡等作案工具及涉案现金。然而，主犯李某却下落不明。民警乘胜追击，对其加大追查。7月13日，终于将李某及两名同伙张某、童某缉拿归案。

![](../Images/b03980bd1491955eb71d72c121ba0d2a.png)

经审查，李某是名80后，芜湖市人。几年前，其因涉嫌“帮信”犯罪被犯罪侦查大队抓获并依法处理。回归社会后，其仍想利用“跑分发财”，但又担心自己“出面”被公安机关查获，思来想去，干脆做个“幕后指挥”。于是，今年5月以来，李某邀集张某、许某、成某等人寻找下线，再指使这伙人使用自己的银行卡为犯罪分子提供资金结算，从中获得非法利益。短短不到两个月，涉案金额高达数千万。

![](../Images/0dd0c11b6427964f4d3baaa6e3a5ac58.png)

目前，李某等9名犯罪嫌疑人均被依法采取刑事强制措施，案件正在进一步办理中。
