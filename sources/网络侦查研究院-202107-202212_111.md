# 涉案资金流水8000余万！23名涉案人员落网 “跑分”团伙覆灭记

肇源县一小伙儿，为赚快钱，竟干起“跑分”洗钱勾当，沦为网络赌博犯罪团伙的帮凶。这小伙儿不但自己不务正业，还拉拢了俩朋友，并各自发展下线，组团干起了“跑分”洗钱。他们每天不论白天黑夜，经常坐在电脑旁，登录网站上的平台，按照境外客服的指引，一笔笔转账洗钱。

  

动动手指就赚了钱，这伙人沾沾自喜，以为神不知鬼不觉，却想不到他们早已被警方盯上。去年12月18日，市公安局网警分局联合肇源县公安局，在肇源县、龙凤区、萨尔图区集中收网，一举打掉了这个“跑分”洗钱团伙，抓获涉案人员23名，涉案资金流水8000余万元……

  

![](../Images/b303a49bec7451220dc9cf7f2d4360d3.png)

　　

**不务正业**

  

霍某，30多岁，家住肇源县，没固定工作，一直想找赚快钱的道儿。

  

“要不你跟我干吧，肯定赚钱!”一次偶然机会，身在南方某城市的一位亲戚联系上了霍某。“让你干的事其实很简单，只需要电脑、手机、银行卡，在平台上帮别人转转账就行，就是动动手指。”听了亲戚的介绍，霍某觉得不太靠谱，再加上自己又没啥本钱，就没同意，也没再多问。

  

没过多久，霍某着急用钱，便想起了曾给他介绍“财路”的那位亲戚，并主动与亲戚取得了联系。“干这活儿，你得先向平台交保证金，因为平台会给你银行卡里打钱，让你帮忙转账。每转一笔钱，平台就会给你提成，多转多赚。信我的，你肯定亏不了。”听完亲戚的介绍，霍某动了心。但保证金需要几万块钱，自己又没那么多钱，于是，霍某打起了身边朋友的主意……

  

![](../Images/a8fb617eedc1f258600144e93b27144d.png)

　　

助纣为虐

  

“我有一个赚钱的活儿，干不干?”霍某找到朋友陈某，把亲戚给他介绍的工作又添油加醋地说了一遍。最终，成功拉陈某入了伙。两人随后又联系了朋友纪某，跟他们一起“赚大钱”。

  

通过亲戚介绍，霍某与境外一个跑分洗钱网站取得了联系。网站客服一步步教会了霍某等人如何“工作”。

  

首先，三人需要准备手机、电脑、银行卡，并向网站交5万元保证金。保证金额多少，决定每次洗钱数额，交5万元，每次单笔洗钱金额不会超过5万元。

  

接下来，就是具体跑分洗钱操作。通过客服提供的一个网址，登录跑分洗钱网站，每次登录必须通过客服提供的验证码。在网站上绑定银行卡后，对方会往银行卡内打钱，然后由网站自动匹配，霍某等人将钱转到指定账户，整个跑分洗钱流程完成。每完成一笔转账，霍某等人就会从中获得4‰-8‰的提成作为佣金。

  

在霍某三人心中，这个“工作”简直就是天上掉馅饼。于是，三人不论白天晚上，都开着电脑。不停地帮助转账……

  

![](../Images/edfd0706e2d34c1369736b22ba7e523d.png)

　　

**发展下线**

  

霍某等三人越干越起劲儿。看他们越来越“上道”，跑分洗钱网站客服又开始给他们“指路”：“你们可以发展下线了，发展的下线越多，你们就会赚得更多。”

  

“网站给霍某的提成是4‰-8‰，如果霍某发展下线，那么下线人员每成功转账一笔，霍某还会获得提成，而且都是在网站上自动生成。”据肇源县公安局反诈大队队长李伟东介绍，霍某等三人起初是合伙干，可到了后来，三人纷纷开始发展自己的下线，使得这一跑分团伙迅速扩张。于是，以三人为首的跑分团伙，发展了20余名成员。这些人有的在自己家“工作”，有的在宾馆和日租房“工作”。

  

警方将这一团伙捣毁后，竟发现在一年多的时间里，该团伙帮网络赌博犯罪团伙洗钱，涉案资金流水达8000余万元，团伙成员从中获利近50万元。

  

**集中收网**

  

就在这伙人沾沾自喜，以为自己神不知鬼不觉“发大财”时，其实民警已经盯上了他们。

  

“这个团伙涉案人员较多，窝点分散，为了规避公安机关审查，团伙成员作案时均使用境外聊天通讯工具进行交流，手段十分隐蔽。”针对这起案件，肇源县公安局高度重视，由市局网警分局、肇源县局反诈队、刑侦大队、网安大队共计50余名警力组成了专案组。经过进一步深入调查，确定了以陈某、霍某、纪某为首的主要犯罪嫌疑人身份及涉案人员在肇源县内的藏匿地点。

  

“别动，警察!”去年12月18日，肇源县副县长、县公安局党委书记、局长梁华赴一线督战，指挥案件收网工作。

  

专案组兵分数路进行集中收网，经过24小时连夜奋战，在肇源县内抓获涉案人员23人，扣押手机30部，查扣各类银行卡148张，涉案笔记本电脑6台。

  

警方已将其中15名犯罪嫌疑人采取刑事强制措施，2人被行政处罚，6人被教育惩戒。

  

自此，这个跑分洗钱团伙彻底覆灭。

  

目前，该案件正在深挖侦办中。
