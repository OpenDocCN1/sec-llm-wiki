# 如何恢复微信聊天记录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxOTM2MDYwNg==&mid=2247509423&idx=1&sn=b612f939a093613ac26ec63c9f2e473a&chksm=97de999ea0a91088660e328b670bf1783a2e7f06ed86552b21375dea770119055c59580aeaa7&scene=126&sessionid=1681402148#rd](http://mp.weixin.qq.com/s?__biz=MzIxOTM2MDYwNg==&mid=2247509423&idx=1&sn=b612f939a093613ac26ec63c9f2e473a&chksm=97de999ea0a91088660e328b670bf1783a2e7f06ed86552b21375dea770119055c59580aeaa7&scene=126&sessionid=1681402148#rd)

在侦查破案中，执法人员往往需要拨打目标的微信聊天记录进行案件分析或举证，经常会遇到被调查人删除手机中的聊天记录，需要进行数据恢复的情况。

  

通常建议侦查人员寻找专门负责电子取证的专业技术人员，如网安、技术、情报等，利用专业的数据恢复设备恢复手机上的数据和电子取证，从而获取相关证据。之前也给大家介绍过一些电子取证的相关企业：

(  http://mp.weixin.qq.com/s?\_\_biz=MzIxOTM2MDYwNg==&mid=100025707&idx=1&sn=42ead0b8e5d8bf5392995efef92dbdef&chksm=17de995a20a9104ca861e20caea90fc62242ebc6d850130505dde9ed94c3a8bb6e03d9341938#rd)  

如果没有专业的电子取证设备，我们又急需获取被调查目标手机中已删除的微信聊天记录，怎么办呢？  

我们可以使用微信自带的“修复聊天记录”功能，尝试恢复聊天记录。当然，也不是所有的聊天记录都能恢复，这要看手机存储被覆盖的情况。因此，非必要，还是建议使用专业设备和软件进行电子取证。  

一、微信自带的恢复功能

　第一种方法：

　1、开启微信，点击【我】-【设置】-【帮助与反馈】这个选项，点击右上角的小工具图标；

　　2、弹出一个界面，点击【故障修复】功能，点击聊天记录功能项，弹出菜单点击【确定】，就可以恢复聊天记录；

第二种方法：

1、打开微信顶部的搜索框。  

![](../Images/155c4c1b036cd68b1d22be3ad48f1a80.png "【技巧】如何恢复微信聊天记录")

2、在搜索框中输入“：recover”，也可以输入“：up”，即可调出微信修复工具。  

![](../Images/176e80fe73fea0b5b69222c1671b49da.png "【技巧】如何恢复微信聊天记录")

3、选择修复聊天记录功能。  

![](../Images/edcd01c54b7d535758a02175a0a2ae5f.png "【技巧】如何恢复微信聊天记录")
