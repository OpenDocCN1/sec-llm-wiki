FIN7 网络犯罪团伙创建虚假网络安全公司以招募渗透测试人员进行勒索软件攻击

FIN7 黑客组织创建了虚假的网络安全公司来聘请专家并让他们参与勒索软件攻击，以欺骗他们进行渗透测试。

FIN7 黑客组织正试图涉足勒索软件业务，并采用了一种有趣的技术。帮派空间创建了虚假的网络安全公司，聘请专家要求他们以渗透测试活动为幌子进行渗透测试攻击。


FIN7 是一个俄罗斯犯罪集团，自 2015 年年中以来一直活跃，它专注于美国的餐馆、赌博和酒店业，以收集用于攻击或在网络犯罪市场上出售的财务信息。


网络犯罪组织为此目的创建的公司之一是 Combi Security，但 Gemini Advisory 的研究人员通过分析另一家名为 Bastion Security 的虚假网络安全公司的网站，发现了其他类似的组织。


Bastion Secure 网站托管在俄罗斯域名注册商 Beget 上，该网站在俄罗斯网络犯罪社区很受欢迎。该站点的大多数子菜单返回俄语 HTTP 404 错误，这种情况表明站点创建者是讲俄语的人。在报告时，一些 HTTP 404 错误仍未修复。


该网站是 Convergent Network Solutions Ltd 网站的克隆，Bastion Secure 的“关于”页面指出这是合法网络安全公司的衍生产品，无论如何与犯罪团伙无关。


FIN7 以 Bastion Secure 为幌子，为程序员（PHP、C++、Python）、系统管理员和逆向工程师发布工作机会。IT 专家职位的工作机会在每月 800 美元到 1,200 美元之间，这对于后苏联国家这类职位来说是一笔不错的薪水。


该团伙正在寻找管理员来绘制受感染公司的网络并定位敏感数据，包括备份。对目标组织的初始访问是通过网络钓鱼攻击或通过在暗网论坛上购买访问权限获得的。


一旦获得对目标网络的访问权限，威胁行为者就可以投放恶意软件和勒索软件。


“Bastion Secure 向 Gemini 来源提供了一份工作机会，并在此过程中向该来源提供了分析人员后来确定用于后开发工具 Carbanak 和 Lizar/Tirion 的文件。这两个工具之前都归于 FIN7 并在 Bastion Secure 和 FIN7 之间建立了联系。”阅读 Gemini Advisory 的分析。“由 FIN7 分配给 Gemini 源的任务——在 Bastion Secure 的幌子下运行——与准备勒索软件攻击所采取的步骤相匹配，进一步证明 FIN7 继续扩展到勒索软件领域。”


Gemini 的一位消息人士申请了一个工作职位并被聘用，该团伙让他可以使用一套已知存在于 FIN7 武器库中的后开发工具，例如 Carbanak 和 Lizar/Tirion。该组织通过分配给 Bastion Secure 的虚假渗透测试活动，提供了对目标公司网络的访问权限。


“Bastion Secure 提供给源的文件包含一个名为“Command Manager”的软件组件的文件，该软件组件实际上是 Carbanak 客户端组件的伪装版本（见图 12）。Gemini 通过分析软件的功能确定了这一点，并得出结论，它是先前确定的 Carbanak 版本的更新版本。”专家继续说道。“Carbanak 命令管理器的主要功能是收集有关受感染计算机的信息并获得对受感染计算机的远程访问。这些文件包含一个经过混淆的 PowerShell 脚本，该脚本最终会启动 Lizar/Tirion 注入器和负载。“


他们要求受雇的渗透测试人员进行侦察并收集可能允许他们进行攻击的信息，例如用户和管理员帐户的凭据以及备份。

“虽然网络犯罪分子在合法的工作网站上寻找不知情的同伙并不是什么新鲜事，但 FIN7 的运作规模和公然行为继续超过其他网络犯罪组织所表现出的行为。FIN7 不仅在合法的工作网站上寻找不知情的受害者，而且还试图通过一个基本上合法的网站、专业的招聘信息和公司信息页面创建一个虚假的网络存在来混淆其作为一个多产的网络犯罪和勒索软件组织的真实身份在俄语业务发展网站上。”报告结束。
