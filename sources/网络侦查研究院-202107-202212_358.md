# 教科书式操作！女子遭遇“杀猪盘”被骗8万，民警巧施反间计全部追回

“我感觉上当了！”9月24日，曾女士慌慌张张地跑进重庆沙坪坝区井口派出所报警，称自己被骗了8万元。  

  

![](../Images/ab6f673a513b1e19a6be3003591edf78.png)  

前段时间，曾女士自己通过网络社交平台结识了一个微信名叫**“幸福的开始”的男网友，很快陷入了“热恋”中**。“男友”告诉她，他在国外一个叫**“全球数字货币交易平台”上炒外围股指期货**，而公司不让内部员工炒，希望曾女士帮他操作。

  

![](../Images/baf891f30cfb73cd0dd1d692606da16b.png)

![](../Images/fa1b278c60defaf62efd1a35fe5ea7ca.png)

  

起初，曾女士没想过自己投资，但在帮助“男友”操作过程中，看到高额的收益，不由心动。不久，“男友”便以“为了两人以后的幸福生活”蛊惑曾女士跟着他投资赚钱。

  

曾女士东拼西凑了8万元，**按着“男友”的指示，将钱转进交易平台**，很快盈利5000多元。但是，过了几个小时，曾女士发现“男友”提供的网址打不开，自己的账号也无法登录。“男友”告诉她，这是系统维护，还说现在行情不错，让曾女士再找些钱来投资，并且要求她不要告诉其他人。

  
  

![](../Images/2af667c63e615438a046a94301933f12.png)

  

曾女士怀疑遭遇了诈骗，匆匆忙忙跑到井口派出所报警。

  

民警了解情况后告诉曾女士，“男友”既然还让曾女士继续投资，**必然还想“钓大鱼”，可以巧设一计追回钱款。**

  

9月25日下午4时，民警让曾女士联系骗子，称自己在找弟弟借钱的时候不小心说漏嘴了，弟弟觉得收益很大也要投资。

  

为了取得对方的信任，民警让曾女士告诉“男友”，已经将自已和“男友”的关系告诉了弟弟，还说“男友”很快就会来重庆买房一起生活，并向弟弟保证投资真实可靠，保证可以提现。弟弟打消了顾虑，愿意拿出20万来试一下。

  

![](../Images/122d5e0bd5d2c001ebb44704030a2ea4.png)

  

随后，“男友”让曾女士等一等。过了一会儿，“男友”告诉曾女士，**“全球数字货币交易平台”**系统已经维护好了，但不是之前的网址，又重新给了曾女士一个网址。曾女士登录“平台”马上申请提现，并继续和“男友”聊天，说弟弟现在就在旁边，也很心动，如果提现成功，弟弟马上也要投资。

  

一顿操作猛如虎，“男友”信以为真，**把8万元加盈利3000多元（扣除了手续费）一起返回给了曾女士。**

  

在民警的指导下，曾女士被骗走的8万元悉数返还，随即将“男友”拉黑并删除。曾女士激动地告诉民警，“这个方法太管用了，8万元失而复得很幸运”。
