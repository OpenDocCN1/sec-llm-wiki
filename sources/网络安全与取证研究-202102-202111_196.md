# 第十届全国电子数据取证技术研讨会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NTU3NTY0Nw==&mid=2247483935&idx=1&sn=db5b774a0d6b25f799768a8223cfcccd&chksm=cf3e222ff849ab393a0883c1134a4624c8546576ad5277bd96d7beadd84c7a2aca363321d105&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3NTU3NTY0Nw==&mid=2247483935&idx=1&sn=db5b774a0d6b25f799768a8223cfcccd&chksm=cf3e222ff849ab393a0883c1134a4624c8546576ad5277bd96d7beadd84c7a2aca363321d105&scene=27#wechat_redirect)

第十届全国计算机取证技术研讨会由中国网络空间安全协会作为指导单位，中国电子学会计算机取证专家委员会、中国图象图形学学会数字媒体取证与安全专业委员会主办，江苏警官学院承办，中国科学院软件研究所、公安部第一研究所、公安部第三研究所、广州中国科学院软件技术研究所电子数据取证实验室、广东中科司法鉴定所协办。

会议于2021年5月8-9日在南京举行。会议将重点就智能设备取证、人工智能与取证、云取证、大数据与取证、暗网和区块链与电子数据取证、新型网络犯罪与电子数据取证、电子数据取证人才培养以及电子数据证据运用等相关法律和技术议题进行深入探讨。

本届会议将同期举办第三届全国电子数据取证挑战赛—“中科实数杯”电子数据取证挑战赛，旨在推动电子数据取证实战技术的提高和国产自主可控取证产品的优化和提高。

在此，诚挚地邀请您参加此次国内电子数据取证领域的学术盛会，共同交流探讨电子数据取证技术及其相关领域的最新研究成果，拜会老朋友，结识新朋友，体验美食、美景、人文历史。同时，邀请您组织高水平选手参加国内面向所有实战领域和厂商的取证挑战赛。

我们在美丽的文化古城南京期待您的光临！
