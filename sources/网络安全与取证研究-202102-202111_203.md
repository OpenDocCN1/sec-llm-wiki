# 2020年司法鉴定机构和鉴定人统计

**统筹推进全面依法治国工作开启新篇章。**坚决贯彻落实党中央决策部署，顺利完成司法部重新组建和中央全面依法治国委员会办公室筹备工作。重新组建的司法部以履行中央全面依法治国委员会办公室职责为统领，推动立法、执法、司法、守法普法各环节全面贯通。全力筹备中央全面依法治国工作会议，会议明确提出习近平法治思想，确立了习近平法治思想在全面依法治国中的指导地位。推动出台《法治中国建设规划（2020-2025年）》《法治社会建设实施纲要（2020-2025年）》，全面依法治国顶层设计进一步健全完善。坚持依法防控疫情，参与制定疫情防控重大政策，推动涉疫法律法规制定修订，规范相关执法司法政策和标准，为统筹推进疫情防控和经济社会发展工作提供有力法治保障。坚持法治先行，推动出台服务和保障雄安新区建设、海南全面深化改革开放等国家重大战略的指导意见，围绕服务保障乡村振兴战略加强法治乡村建设。聚焦人民群众反映强烈的突出问题，组织开展食品药品监管执法司法督察和保护民营企业发展执法司法督察，依法保障人民群众舌尖上的安全，推动优化法治化营商环境。加快涉外法治工作战略布局，积极推进我国法域外适用法律体系建设，有效维护国家主权、安全、发展利益。

**行政立法工作取得新成果。**五年来，持续加强重要领域立法，完成一大批党中央关心、人民群众关注、社会实践亟需的重大立法项目。为推动高质量发展，起草审查完成外商投资法草案、外商投资法实施条例、优化营商环境条例等项目。为保障和改善民生，审查完成疫苗管理法草案、保障农民工工资支付条例等项目。为弘扬社会主义核心价值观，审查完成著作权法修订草案等项目。为建设美丽中国，审查完成大气污染防治法修订草案、固体废物污染环境防治法修订草案等项目。为加强政府自身建设，审查完成重大行政决策程序暂行条例、政府信息公开条例（修订）等项目。为保障重大改革顺利进行，先后开展多批次法律法规清理工作。各地司法厅（局）结合当地实际，起草审查了一大批富有特色、针对性强的地方立法，为地方经济社会发展提供了有力法治保障。

**依法行政实现新突破。**全面贯彻落实法治政府建设实施纲要，开展全国第一批法治政府建设示范创建活动，对全国64个示范创建地区和项目进行命名。先后组织开展党政主要负责人履行推进法治建设第一责任人职责督察、法治政府建设全面督察、行政执法专项监督等，进一步压实法治政府建设主体责任。深入推进行政执法体制改革，推动行政执法体制机制不断完善。全面推行行政执法“三项制度”，统一执法证件标准样式、执法服装和标志式样，严格规范公正文明执法水平显著提升。持续推进“减证便民”，企业和群众办证多、办事难等现象明显改观。推动上海、汕头等地开展行政裁决试点工作，有效发挥行政裁决化解民事纠纷“分流阀”作用。制定《关于加强党政机关法律顾问工作的意见》，充分发挥法律顾问在党政机关决策中的作用。严格办理行政复议案件、监督行政机关依法行政，加快推进法治政府建设。2016年至2020年，全国各级行政复议机关共办理行政复议案件约109万件，办结105万件。办结的立案受理案件中，约有14万件以撤销、变更、确认违法或者责令履行等方式结案，纠错率15.4%。深化行政复议体制改革，推动出台《行政复议体制改革方案》并严格督促地方落实，切实解决制约行政复议发展的深层次体制机制问题。

**助推平安中国建设能力有了新提升。**坚持党对监狱工作的绝对领导，坚守安全底线，践行改造宗旨。2019年、2020年监狱实现连续两年“零脱逃”。推动罪犯文化教育和职业技能培训纳入地方政府规划。圆满完成对一批监狱罪犯的特赦任务。社区矫正制度不断健全完善，社区矫正法顺利出台，会同有关部门制定社区矫正法实施办法。刑罚执行一体化建设深入推进。矫正期间社区矫正对象再犯率一直控制在0.2%以下较低水平，取得了良好的法律效果和社会效果。司法行政戒毒工作实现由转型到定型，全国统一司法行政戒毒工作基本模式全面推开，戒毒工作规范化科学化现代化水平大幅提高，教育戒治质量显著提升。积极推进刑满释放人员安置帮教工作，鼓励引导他们顺利融入社会。

**普法依法治理工作取得新突破。**深入开展习近平法治思想学习宣传，“七五”普法顺利实施完成，全社会法治观念明显增强，社会治理法治化水平明显提高。制定《青少年法治教育大纲》，把法治教育纳入了国民教育体系，截至2021年3月，全国共建立青少年法治教育实践基地3万余个。“谁执法谁普法”普法责任制普遍实行。建立国家工作人员旁听庭审活动工作机制。社会主义法治文化蓬勃发展，截至2021年3月，全国共设立法治文化主题公园3500余个、广场1.2万余个、长廊3.4万余个，法治乡村建设有序推进，命名了第七批、第八批全国民主法治示范村（社区）。积极构建新时代大调解工作格局，开展坚持发展“枫桥经验”实现矛盾不上交三年行动，人民调解工作基础性作用进一步强化。“十三五”期间，全国人民调解组织每年调解矛盾纠纷达900万余件。司法所职能作用得到有效发挥，目前全国共有司法所近4万个，全国司法所工作人员达到14万余人。改革完善人民陪审员、人民监督员制度，推动出台人民陪审员法。“十三五”时期，司法行政机关新选任人民陪审员24万余人。截至2020年底，全国共有人民监督员2.3万余人。

**公共法律服务体系建设迈上新台阶。**推进公共法律服务实体、热线、网络三大平台融合发展，截至2020年底，全国共建立省、市、县、乡、村五级公共法律服务实体平台56.6万个。2020年各级公共法律服务实体平台共提供各类服务1800万余件次，热线平台接听咨询电话877万通，中国法律服务网、各省级法网累计访问量1.2亿余次。为全国60余万个村（社区）配备了法律顾问。法律援助制度不断完善，出台刑事和民事行政法律援助服务规范、法律援助值班律师工作办法。“十三五”期间，全国办理法律援助案件近640万件，受援人达800万余人次。公证改革持续深化。截至2020年底，全国共有公证员1.3万余人，公证机构2800余家。健全完善司法鉴定管理体制机制，依法严格登记管理，着力推进“四类外”机构清理工作。**截至2020年底，全国共有司法鉴定机构3100余家，司法鉴定人3.8万余名。**“十三五”期间共完成鉴定业务1167万余件。支持国际商事仲裁中心建设，推进互联网仲裁和信息化建设，开展仲裁行业发展秩序清理整顿专项行动。“十三五”期间，全国260余家仲裁委员会共处理案件188万余件，案件标的额3万多亿元。建立实施国家统一法律资格考试制度，制定出台国家统一法律职业资格考试实施办法、法律职业资格管理办法等规章及规范性文件。2016至2020年，共有313万余人报名参加法律职业资格考试（司法考试），已有42万余人通过考试取得法律职业资格。

**律师事业取得新发展。**律师行业党的建设全面加强，全行业基层党组织达到13900余个，基本实现全覆盖。全国律师每年办理各类法律事务超过1000万件，为70余万家党政机关、企事业单位担任法律顾问。刑事案件律师辩护全覆盖、律师调解、律师专业水平评价试点积极推进。积极发展涉外法律服务、培养涉外律师人才，成功举办世界律师大会，发起成立“一带一路”律师联盟。组织实施“援藏律师服务团”活动，选派优秀志愿律师到西藏无律师县提供法律援助和公益法律服务。截至2020年底，律师事务所达到3.4万余家，律师队伍发展到约52万人。

**司法行政保障能力实现新提高。**司法行政改革取得新成绩，助力全面建成小康社会，制定全面深化司法行政改革纲要，召开深化全国司法行政改革推进会，部署加快推进司法行政执法司法制约监督体系改革和建设工作，改革亮点工作取得新成效。司法行政科技信息化支撑能力显著增强，初步形成覆盖行政立法、行政执法、刑事执行、公共法律服务四大职能的“大平台、大系统、大数据”，网络安全防御能力显著提高，标准化工作取得新进展。

**司法行政队伍建设取得新成绩。**坚持政治统领，严格落实政治轮训制度，在全系统掀起大学习大培训热潮。扎实开展司法行政队伍教育整顿试点工作和专项警示教育，深入开展警务督察活动，进一步提升监狱戒毒人民警察依法履职守纪的政治自觉和行动自觉。“十三五”期间，全国司法行政系统进一步加大教育培训力度，司法行政队伍能力素质进一步增强。建立健全司法行政机关人民警察招录机制。深入推进人民警察职级序列改革，推动监狱戒毒场所执法勤务职级职数调整。推动出台司法行政机关人民警察伤亡特殊补助金、优抚对象子女教育优待等政策措施，切实解决干警实际困难。加大表彰奖励工作力度，激励广大司法行政干警和法律服务工作者奋发有为。
