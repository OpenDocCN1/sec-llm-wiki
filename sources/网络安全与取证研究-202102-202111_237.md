# GOIP设备取证技术探究

      近年发生的电信诈骗案中，使用GOIP设备进行电话诈骗成为犯罪分子诈骗的一个新动向，GOIP设备能够将传统电话信号转为网络信号，不法分子可以通过网络远程（甚至在境外）操控设备，从而起到隐藏真实身份逃避打击的目的。  

![](../Images/1de73b66430b73e4d24dea14673e2c9a.png)

GOIP是网络通信的一种硬件设备，通过通信嵌入式软件，可以接入GSM、CDMA、WCDMA、LTE频段的手机卡，支持SIP协议，也可以对接到AI机器人交互系统。对于GOIP网关设备的取证，通过数据提取，可以获取到设备上的SIM号码、IMEI、IMSI、远程服务器网络IP地址、设备日志等数据信息。  

GOIP设备的取证方法比较简单，可以使用专用的取证设备进行数据提取，也可以通过设备自身提供的接口提取到关键的证据信息。下面介绍常见的取证方法：

（1）通过web页面取证。GOIP设备通常都提供了web配置页面，通过web配置页面可以提取到有关配置信息。使用该方法的局限性有两个方面，一是要获取到设备的IP地址，或者是分配给设备一个IP地址。二是登录配置页面需要知道用户名和密码。在没有用户名和密码的情况下只能通过暴力破解的方法获取到登录账号信息。

（2）通过TTL串口取证。通过console串口登录设备，通过命令行的方式查看设备的相关信息。通过console串口登录设备的优点是不需要获取设备的IP地址，直接通过串口线连接设备，缺点是通常情况下也需要知道登录的用户名和密码。

（3）通过专业的取证软件进行取证。通过专业的取证软件（比如美亚柏科的物联取证大师等）可以比较完整的获得到设备中存储的信息。除了SIM号码、IMEI、IMSI、远程服务器网络IP地址、设备日志等数据信息以外，还可以获取到登录的账号信息等。通过专业的取证软件进行信息提取的不足之处是部分设备型号取证软件可能不支持，导致无法完成数据提取。
