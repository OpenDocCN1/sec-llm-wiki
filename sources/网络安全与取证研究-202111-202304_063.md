# 硬盘出现坏道的数据恢复方案

经常使用电脑和移动硬盘的用户，如果察觉到电脑运行速度变得很慢，即使做了磁盘整理和系统重装操作后速度还是没有恢复到正常状态，这个时候就要小心是硬盘盘片出现坏道了。  

  

如果这个时候用硬盘检测软件扫描硬盘就会发现扫描界面上出现很多绿块，也有可能出现褐色或红色的色块，这就表明硬盘已经或即将出现坏道，那么什么是硬盘坏道？

  

百度百科给出的定义：硬盘使用久了就可能出现各种各样的问题，而硬盘“坏道”便是这其中最常见的问题。硬盘出现坏道除了硬盘本身质量以及老化的原因外，主要是平时在使用上不能善待硬盘，比如内存太少以致应用软件对硬盘频繁访问，对硬盘过分频繁地整理碎片，不适当的超频，电源质量不好，温度过高，防尘不良，震动，强制关机等。

  

  

  

  

  

  

![](../Images/d7a747a1decd4a41724ff1daa6bd890f.png)

  

硬盘出现坏道除了硬盘本身质量以及老化的原因外，有很大程度上是由于平时使用不当造成的。硬盘坏道根据其性质可以分为逻辑坏道和物理坏道两种：逻辑坏道是由于一些软件或者使用不当造成的，这种坏道可以使用软件修复；  

  

而物理坏道则是硬盘盘片本身的磁介质出现问题，例如盘片有物理损伤，这类故障通常使用软件也无法修复。所以无论是逻辑坏道还是物理坏道都会导致电脑或移动硬盘使用不正常，严重时导致硬盘不识别，数据无法读取，如果电脑或移动硬盘出现坏道了该怎么办？

  

  

  

  

  

  

![](../Images/9def76ba7fe240cf28b95ad56a7ae114.png)

  

***硬盘检测出坏道***

  

达思数据恢复中心个人业务部门几乎每天都会接到因为坏道导致的数据丢失或硬盘读不出来的咨询，用户提到的故障表现基本上就是：“硬盘提示要格式化”、“不能访问某个文件或者文件夹了”、“昨天还用的很好，没正常退出直接拔了一次，第二天移动硬盘就无法识别了”等。这些故障表现其实就是固件损坏或出现坏道了。

  

  

  

  

  

  

  

![](../Images/31dc68412f781572db67067cd302ec7b.png)

  

如果硬盘里没有重要的数据文件，就建议换硬盘了；如果硬盘里有重要的数据就需要到正规专业的数据恢复公司做数据恢复了。硬盘的坏道和固件问题是无法通过在网上找几个所谓的数据恢复软件就能解决问题的，需要价格昂贵的专业设备来恢复数据，比如ACE公司的PC3000和MRT实验室公司的MRT设备。

  

为什么硬盘会出现坏道？其实硬盘在出厂的时候就已经有坏道，只不过被写入了固件中的P表和G表里，所以用户在使用的时候或用软件测试的时候感觉不到有坏道，但当固件模块损坏或盘片出现磁性弱化，坏道就会被释放，硬盘就不能正常工作了。

  

***硬盘出现坏道的解决方法***

  

一、少量坏道：

  

如果发现电脑或移动硬盘拷贝文件速度明显变慢或者偶尔报错。这个时候就需要赶紧去备份重要文件并及时更换硬盘，不要等到硬盘无法识别或文件彻底无法打开才想到去备份数据或换硬盘。

  

  

  

  

  

  

![](../Images/136cb3ff7e24d4421ddf9cab6c3bb19f.png)

  

二、硬盘不识别或拷贝数据明显变慢的：

  

如果出现这些现象，问题就已经比较严重了。如果硬盘里面没有重要数据就直接换新盘，如果有重要的数据，就尽量少加电尝试，尽快找正规专业的数据恢复公司处理。如果坏道不严重，有很高的概率恢复全部或者绝大部分数据，如果出现大量的坏道，可能数据就不敢保证完整度了，恢复50%的可能性也很大的。

  

三、硬盘出现异响，时认时不认：

  

出现这类故障多数情况下是因为硬盘使用年限过长，磁头组件老化、轻微的摔磕碰撞等，如果这类问题严重到磁头损坏，盘片划伤，数据也就无法恢复了。

  

  

  

  

  

  

![](../Images/96fb176c329f338f7a3ae3aa0bd0762e.png)

  

达思数据恢复工程师提示您：坏道是硬盘最常见的故障之一，并不可怕，但用户的一些不当操作会对硬盘造成二次破坏，也有可能是致命的破坏，这时不仅硬盘不能使用，数据也无法恢复。所以一旦出现上述问题请找正规专业的数据恢复公司咨询，保证数据不会被二次破坏，造成无法弥补的遗憾和损失。
