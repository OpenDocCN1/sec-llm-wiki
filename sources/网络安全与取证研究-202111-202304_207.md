      Docker是一个开源的应用容器引擎，让开发者可以打包他们的应用以及依赖包到一个可移植的镜像中，然后发布到任何流行的Linux或Windows操作系统的机器上。

![](../Images/d04dedbc36bebb84acef267cfd35f0e6.png)

      Docker三要素：镜像、容器、仓库。镜像是一个只读模板，使用部署完毕的操作系统和应用程序制作；容器是运行起来镜像实例，类似vmware虚拟机；仓库用来保存镜像，分为公开仓库和私有仓库两种形式，你可以上传自己的服务器镜像到私有仓库，然后从其他地方下载，运行为容器，对外开放服务。

![](../Images/4c6a69b411acfce8df0e73b11b738e6f.png)

**Docker的勘验**

Centos 7.9系统

  

以Centos 7.9系统为例，Docker的勘验思路如下：

**查看服务器中是否安装有Docker软件**

输入命令:docker version

![](../Images/9019964aa7cf3226a4b830a4fb502828.png)

**查看Docker运行状态**

输入命令:systemctl status docker.service

![](../Images/8089e9973d80f21464840137e57973fc.png)

**查看Docker镜像**

输入命令:docker images

![](../Images/1a87754a1e434d98c6838a9456b8610b.png)

**查看Docker容器状态**

输入命令docker ps

（1）容器未启动

![](../Images/733eddc8d81ae200ec16af6f38207068.png)

以本机为例，输入命令：docker run -i -t centos:lastet /bin/bash

![](../Images/e3c0ee5dc6d272e76c6b4d1e5c4dc401.png)

（2）容器已启动

![](../Images/0904521753fa58d4e24bac1fab713d95.png)

以本机为例，输入命令docker exec -it 37cf /bin/bash

![](../Images/e63cbbb5636ba3af56f41f41f398699d.png)

**容器端口映射**

以本机为例，输入命令：docker run -itd -p 8022:22 centos

![](../Images/a1db74a43b867a41d729c7f6c1cf6c7e.png)
