# 公众号一周年随笔

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3NTU3NTY0Nw==&mid=2247484587&idx=1&sn=f0318e478d00656c43bf64e8a93ffe19&chksm=cf3e249bf849ad8dbaba87abe78dcff5c6edd4a2e2c9cdfc9729a60355a30ee05429e2a79081&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=Mzg3NTU3NTY0Nw==&mid=2247484587&idx=1&sn=f0318e478d00656c43bf64e8a93ffe19&chksm=cf3e249bf849ad8dbaba87abe78dcff5c6edd4a2e2c9cdfc9729a60355a30ee05429e2a79081&scene=27#wechat_redirect)

一直以来，都想创办一个公众号可以分享各类技术或法律规范，一起提高进步，但却受限条件或懒惰没有成行。

近年来，开始大量关注各类公众号和技术贴内容，并且适时转发收藏，一方面可以多多分享他人，另一方面自己也可以回头查找复习相关技术内容。但是随着分享内容增多，发现查询的一些内容却不再显示，要是从朋友圈去逐条查找却又费时费力，但是公众号却不存在这个问题，可以随时搜索，尤其是标题合理的情况下，可以尽快找到想要的内容。所以下定决心要创办并经营一个公众号。

2021年2月1日，正式创办并开始发帖。刚又翻回第一篇文章，感慨万千，首都网安人的称谓真的是任重道远。

![](../Images/39361179c4d112d7e09d616398140ea6.png)一年来，我还是比较用心在做技术分享，坚持的也不错，公众号的发帖分享几乎从未断过，截止今天，一年的发帖数是358篇（这篇和明天一篇），基本全年无休，仅有的几天空白印象上大概率也是周末工作加班导致，未来一年争取保持住，要能覆盖全年那当然是更加值得称赞的事情。![](../Images/33e03b016055c7c09c3ad6c5ab7b1bac.png)还有两天就是虎年春节了，正好赶上公众号创号一周年。希望在新的一年周期​里，能继续给大家分享有灵魂的想法，有内容的知识，有观点的分析，也欢迎朋友们能多多支持，欢迎随时投稿。最后，预祝大家新春快乐，虎年虎虎生风，身体健康，万事如意。![](../Images/3cc9a9ff266936bbc8748d35a3219eb1.png)​
