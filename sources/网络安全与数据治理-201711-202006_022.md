# 工业和信息化部办公厅关于公布2020年大数据产业发展试点示范项目名单的通知

**工信厅信发函〔2020〕47号**

   
各省、自治区、直辖市及计划单列市、副省级省会城市、新疆生产建设兵团工业和信息化主管部门（大数据产业主管部门），各有关单位：  
 

为贯彻落实《国务院关于印发促进大数据发展行动纲要的通知》（国发〔2015〕50号）和《大数据产业发展规划（2016\-2020年）》（工信部规〔2016〕412号），按照《工业和信息化部办公厅关于组织开展2020年大数据产业发展试点示范项目申报工作的通知》（工信厅信软函〔2019〕243号）要求，经各单位推荐、专家组评审、网上公示，确定“中色非洲矿业有限公司基于大数据的金属矿山智能管控新模式”等200个项目为2020年大数据产业发展试点示范项目，现予以公布。  
 

有条件的地方和单位要在政策、资金、资源配套等方面加大支持力度，积极推动试点示范项目应用推广。

**主题：****人工智能技术研究**（5月刊、6月刊）  
包括但不限于以下分主题范围：1.智能传感器、神经网络芯片研究；2.自然语言处理技术研究；3.语音识别技术研究；4.视觉与图像识别技术；5.智能无人驾驶、无人机技术；6.工业智能机器人技术；7.智能制造关键技术。截稿日期：4月10日  
  
**主题：区块链技术研究（7月、8月） **  
包括但不限于以下分主题范围：   
1.区块链高性能关键技术（包括联盟链共识算法、智能合约引擎，新型共识机制等）；   
2.区块链软硬件协同优化技术；   
3.区块链安全隐私防护关键技术；   
4.区块链数据协同技术（包括安全密码学协议、可编程计算引擎、数据分发协议技术等）；   
5.区块链监管技术（包括联盟链穿透式监管技术、公链主动发现与探测技术、监管体系结构及标准等）。   
截稿日期：5月31日
