# 公布！2020年大数据产业发展试点示范项目名单

2月26日，根据《工业和信息化部办公厅关于组织开展2020年大数据产业发展试点示范项目申报工作的通知》（工信厅信软函〔2019〕243号）要求，工业和信息化部组织开展了相关申报和评审工作。工业和信息化部信息技术发展司将2020年大数据产业发展试点示范项目名单进行公示，现请社会各界监督。 

  

公示时间：2020年2月26日-2020年3月3日
