# SP3版本发布！银河麒麟桌面操作系统有哪些提升？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247485798&idx=1&sn=36d6994a0177e02e5cec819c47821474&chksm=e9302c77de47a5615ff45cb6332d80b3765ae24e224c5b5f5ca1b82d83e6c654228c648b3725&scene=126&sessionid=1681270750#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247485798&idx=1&sn=36d6994a0177e02e5cec819c47821474&chksm=e9302c77de47a5615ff45cb6332d80b3765ae24e224c5b5f5ca1b82d83e6c654228c648b3725&scene=126&sessionid=1681270750#rd)

2019年9月19日，天津麒麟信息技术有限公司正式发布银河麒麟桌面操作系统最新版本——Kylin-4.0.2-sp3桌面版。该版本基于Kylin-4.0.2-sp2迭代，同时支持飞腾1500A和飞腾新一代桌面处理器FT-2000/4，在生态、性能、安全和体验等方面都有全新提升。同时，Kylin-4.0.2-sp3版本仅实现新特性和bug修复，底层系统库基本保持不变，能实现对Kylin-4.0.2、Kylin-4.0.2-sp1以及Kylin-4.0.2-sp2版本核外应用的完美兼容（特殊应用和内核模块重新编译即可兼容）。进入2019年以来，已经有数百家公司的近千款产品通过银河麒麟操作系统的产品兼容性互认证测试。麒麟操作系统携手麒麟飞腾生态圈内上下游软硬件及应用厂商一起构建自主安全信息技术体系，共同守护国家信息安全。  

  

**生态**

麒麟SP3版本同时支持飞腾1500A和飞腾新一代桌面处理器FT-2000/4、同时支持高低端显卡以及国产显卡；默认集成安卓兼容2.0版本，支持海量安卓应用原生运行。

![](../Images/c3f79b129ea5835ab8e3a560190e6b5a.png)

[飞腾新一代桌面处理器FT-2000/4](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247485790&idx=1&sn=37e85cc5d8c646e21d78859fa236253a&chksm=e9302c4fde47a5599c352dac70f31b64a03e36a018011b48f2fe7c64b5d959413e258a77b22b&scene=21#wechat_redirect)

安卓兼容**1\. 新四核适配：**1) 同时支持飞腾1500A和FT-2000/4、同时支持高低端显卡；2) 双内核，满足飞腾1500A生态兼容需求；3) 支持ACPI电源管理框架，实现电源管理功能，支持S3、S4电源管理以及处理器的动态调频能力；4) 支持标准UEFI固件,支持ACPI table引导；5）支持国产显卡、国产ZX-200桥片、国产SSD、国产网卡等国产设备；6) 支持RTC、GMAC、HDA音频、SDC、I2C、LPC、GPIO等FT-2000/4芯片内置设备控制器；7）支持监控功能，实现对处理器内部温度传感器的动态实时监控；8）支持多款FT-2000/4台式机、笔记本及一体机平台。**2\. 显示升级：**1) 支持SM768显卡视频硬解；2) 支持景嘉微JM7200、709GP101/102等国产显卡；3) 支持 R5 235、R5 230、R9 270、R9 380、RX550、RX580等AMD显卡；4) 针对GCN显示，2D性能在FT1500A平台提升30%以上；5) 2D、3D性能较FT1500A平台提升60%以上；6）核外显示驱动升级，支持多版本OpenGL API。**3\. 安卓兼容2.0：**1) 支持海量Android应用原生运行；2) 升级麒麟软件商店，新增安卓分类，软件下载即用；3) 麒麟和安卓应用本地级数据互通；4) 开始菜单提供单独安卓兼容分类，方便使用；5) 安卓兼容运行后自动休眠、唤醒。

**安全**

![](../Images/7c252673babff29ecd8f1d80a91d6a6e.png)

安全管理工具

![](../Images/f8d7d444ab3753e109e8554c21714cfa.png)

生物识别**1\. 内核安全提升：**  
1) 内核升级至4.4.131，修复低版本的Bug和CVE漏洞；2) 上游patch集成，提升安全性、可靠性和稳定性；3) 丰富麒麟安全框架，进一步加强内核级安全防护；4) 内核安全机制优化，提高安全执行性能。**2\. 丰富安全管理：**1) 提供图形化麒麟安全管理工具、PＡＭ配置工具；2) 提供简单易用的安全配置界面，一键式切换安全；3) 提供丰富简明的用户认证、密码控制等图形配置；4) 提供执行控制、文件保护、内核防护等安全配置；5) 集成生物识别框架：支持指纹、指静脉、虹膜等多种生物特征的识别，支持串口、USB、PCIE等多种接口的上百款生物特征识别设备；6) 提供生物识别管理工具，提供全系统基于pam的生物识别认证。

**体验**

体验方面，任务栏、开始菜单、主题、登录、锁屏等UKUI组件全面升级，同时升级系统基础组件，支持显示切换、文件内容搜索等新特性。

![](../Images/9dd2fbca0808999162d342e0c588120c.png)

**1\. UKUI组件功能升级：**1) 新增全新的黑色主题做为默认主题，重绘大量系统图标，支持开始菜单、任务栏等组件透明效果；2) 文件浏览器：支持右键格式化U盘、支持桌面图标排序、提升稳定性、文件内容搜索等实用功能；3) 开始菜单：提供设置功能，支持设置分类菜单、透明度等功能；新增文件历史打开记录功能，支持查看wps、文本编辑器、文档查看器等打开的历史文件；4) 控制面板：新增锁屏背景设置、支持主题切换、新增显示设置，支持性能模式和兼容模式，满足不同性能显卡显示需求；5) 任务栏：提供设置功能，支持任务栏高度设置、工作区设置、任务栏锁定设置等功能；支持用户自定义显示通知区域图标；6) 全新的登录、锁屏界面：支持密码明文显示、全新实现键盘功能、支持生物识别认证；登录支持设置语言，锁屏支持选择图片文件夹；；7) 优化安全模式下的用户交互体验；8) 新增桌面排序、文件内容搜索、U盘格式化等实用功能。**2\. 系统基础组件升级：**1) 窗口管理器支持自动切换，同时满足高端和低端显卡需求；2) 升级控制面板，支持用户自定义显示模式；3) 升级麒麟影音，提升高清视频的播放体验；4) 升级麒麟备份还原，优化grub备份和在线备份功能。

银河麒麟桌面操作系统是易用性和兼容性良好兼容的国产桌面操作系统，主要面向电子办公、指控平台、定制设备等场景，目前已成功应用于国防、政务、电力、金融、能源、教育等行业，并成为我国自主安全信息系统的核心技术应用。

SP3版本升级及软件源下载方式1、SP3系统补丁升级：用户可以从4.0.2、4.0.2-sp1或者4.0.2-sp2升级到SP3。提供以下两种升级方式：1) 本地安装：在终端中使用 sudo dpkg -i 命令安装补丁升级包进行升级;2) 在线升级：SP2补丁升级包放入升级源中后，系统中的升级管理器（kylin-update-manager）会自动识别并提示安装。2、银河麒麟软件源：银河麒麟操作系统V4桌面版已开放外网软件源，支持通过软件中心进行软件安装和升级，可以参照如下方式进行设置访问：在系统的/etc/apt/sources.list文件中，根据不同版本填入以下内容：4.0.2桌面版本:deb http://archive.kylinos.cn/kylin/KYLIN-ALL 4.0.2-desktop main restricted universe multiverse4.0.2-sp1桌面版本:deb http://archive.kylinos.cn/kylin/KYLIN-ALL 4.0.2sp1-desktop main restricted universe multiverse4.0.2-sp2桌面版本:deb http://archive.kylinos.cn/kylin/KYLIN-ALL 4.0.2sp2-desktop main restricted universe multiverse4.0.2-sp3桌面版本:deb http://archive.kylinos.cn/kylin/KYLIN-ALL 4.0.2sp3-desktop main restricted universe multiverse![](../Images/2a57cd06e045f4c302d644421f458298.png)*                                                 (来源：天津麒麟微信公众号）*
