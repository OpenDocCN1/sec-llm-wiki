# 启明星辰 l 两会三提案：安全制衡、人工智能、数据法治

3月3日、3月5日，全国政协十三届二次会议、十三届全国人大二次会议先后开幕，中国进入两会时间。2019年两会代表委员的议案提案备受各方关注。与往年相比，今年两会议案提案涉及人工智能、网络安全等多个网信热点领域。其中，作为数字经济发展的要素，人工智能成为高频热点，不仅出现在政府工作报告中，在代表委员的议案提案中也多有体现。除了人工智能，数据安全保护，特别是个人信息保护再次成为有识之士的关注热点。其中，全国政协委员、启明星辰董事长严望佳共提交了三份提案，分别聚焦网络安全制衡能力建设、人工智能安全发展、数据法治建设三个领域提出提案建议，现将提案建议要点摘要发布，相信安全作为“一体两翼、驱动双轮”的重要方面会越来越引起全社会的重视和投入。

  

  

  

![](../Images/34feb5a9ed80b9c38e97e66039ae4481.png)

**提案一：****《关于增强大数据时代中网络安全制衡能力的提案》**

**鉴于当前我国很多企事业单位“**重信息化建设，轻网络安全建设**”的现状，提案建议在信息化建设过程中，处理网络安全和信息化关系时，将网络安全放在一个平等独立的第三方位置，而非附属地位，方能体现“一体两翼、驱动双轮”的方针定位。提案具体建议摘要如下：**

**1****）制定政策配套细则，提高网络安全制衡能力。**诸如包括在关键信息基础设施建设中制定网络安全管理办法、设立网络安全的“一票否决权”、设定项目网络安全预算最低比例要求（如8%-12%）、规范网络安全独立审计制度等。 

**2****）强调网络安全独立性，落实网络安全保障职责。**出台管理措施，要求在涉及智慧城市、关键信息基础设施等项目的规划、建设和运营中，联合具有网络安全资质的单位进行；信息化部分和网络安全部分须由不同责任主体承担；鼓励建设独立于信息系统运营的网络安全运营中心，强化网络安全事件独立处理能力和网络安全保障效果。 

**3****）实施国家网络安全重大工程，强化网络安全可控水平。**通过实施国家层面的网络安全重大工程，建设统一的威胁情报、态势感知和数据安全预警系统等，加快构建关键信息基础设施安全防御体系，提高对智慧城市和关键信息基础设施的安全管控能力，切实维护国家网络空间主权和发展利益。

**提案二：****《关于规范人工智能安全健康发展的提案》**

  

鉴于人工智能领域快速发展存在的潜在风险和安全隐患，为确保其成为驱动社会经济发展和人民生活水平提升的可靠战略性力量，提案建议建立、健全人工智能安全发展的法规、体制、机制。提案具体建议摘要如下：  

**1****）加快开展人工智能安全应用法规和伦理道德的研究。**具体的安全规范机制包括研究出台相关法律法规，界定人工智能应用的法律主体及相应的权利和义务；开展人工智能伦理道德的探讨，约束人工智能研究与实际应用的范围界限。 

**2****）建立关键领域内的人工智能应用安全审查机制。**在关系国计民生和公共安全的关键领域，建议建立人工智能应用的准入审查机制，加强人工智能算法及应用的安全性、可控性和透明性的审查。 

**3****）展开人工智能安全评估技术研究，健全完善测评机制。**建议通过产业政策引导和组织管理措施，一方面引导加快研究人工智能产品和应用的安全评估评测技术，逐步积累安全检测样例库、测试样本库等知识资源和研发测试工具集，提高人工智能产品和应用的安全评估评测能力；另一方面推动人工智能安全相关的国家标准和行业标准的制定工作，明确相关安全评估指标、方法和要求，建立安全测评流程和管理规范，健全人工智能产品和应用安全测评机制。

**提案三：****《关于加快完善数字经济时代数据法治建设的提案》**

  

数字经济快速发展对我国现有法律法规体系提出新的挑战，数字经济核心生产要素是数据，数据安全保护需要通过制定针对性的法律法规来引领，当前数据安全受到不同程度的威胁，如何平衡好社会数字经济发展需求与国家主权数据、商业数据和个人数据隐私安全保护之间的关系，需要以法治方式来实现数据确权、合法收集、安全使用，为数字中国、智慧社会的建设保驾护航。提案具体建议摘要如下：

**1****）建议加快数字经济时代的数据保护立法工作。**为落实习近平总书记 “要制定数据资源确权、开放、流通、交易相关制度，完善数据产权保护制度”的要求， 针对2018年我国人大已纳入立法计划之中的《数据安全法》，建议加快其研究与立法工作。 

**2) ****建议加快推进我国个人数据保护立法工作。**我国至今还未制定个人信息保护法等专门法律，个人数据经常可能在云服务--管道--终端的每一个环节未经数据主体授权就被不当收集、储存、利用，甚至用来非法交易，成了数字经济下的社会“毒瘤”。针对在2018年我国人大已纳入立法计划之中的《个人信息法》，建议加快推进我国个人数据保护--《个人信息法》立法与研究工作。 

**3) ****建议及时完善数字经济数据要素相关法律法规。**建议加强研究并做好以数据为核心生产要素的数字经济法律法规治理体系的顶层设计，根据数字经济发展形势和需要，及时调整完善现行相关法律法规，明确数据市场监管主体、负面清单、参与主体权责以及相关法律责任，为我国数字经济持续健康发展和国际竞争力的提升营造良好法治环境。
