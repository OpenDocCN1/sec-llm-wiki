# CIIA安委会2018年会暨第八期网络安全创新发展论坛即将在京召开

为贯彻落实国务院《关于深化“互联网+先进制造业”发展工业互联网的指导意见》、《工业互联网发展行动计划（2018-2020年）》等相关政策要求，加快建设和发展工业互联网，发展先进制造业，共同解决国际社会共同面临的工业互联网安全难题，在国家发展和改革委员会高技术产业司、公安部网络安全保卫局与国家信息中心的指导下，中国信息协会信息安全专业委员会及国家信息中心国信卫士网络空间安全研究院拟定于11月29日共同举办中国信息协会信息安全专业委员会2018年会暨第八期网络安全创新发展高端论坛。

活动将以“**安全工业互联网之新形势 新机遇 新挑战**”为主题，邀请中国工程院院士、发展和改革委员会领导、公安部领导、工业和信息化部领导、国家重点实验室专家、国内外知名企业高管和学者等围绕工业互联网安全的态势、威胁风险、应对措施、架构设计、应用创新、能力建设等内容，共同研讨与交流。

**会议主题**：安全工业互联网之新形势、新机遇、新挑战

**会议时间**：2018年11月29日 13：30-17：45

**会议地点**：北京新世纪日航饭店世纪厅

**指导单位**：国家发展和改革委员会高技术产业司、公安部网络安全保卫局、国家信息中心

**主办单位**：中国信息协会信息安全专业委员会、国家信息中心国信卫士网络空间安全研究院

**协办单位**：北京立思辰信息安全集团、工业控制系统信息安全技术国家工程实验室、工业控制系统安全技术国家工程实验室、中国电子商会网信生态建设专委会、北京信息化和工业化融合服务联盟
