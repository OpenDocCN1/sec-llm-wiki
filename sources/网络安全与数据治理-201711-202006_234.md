# 《2018中国区块链产业白皮书》发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247484186&idx=1&sn=cf3070264063807909101c18d2b6cd81&chksm=e930260bde47af1dcbc058937117d80e63c9d11f4e29eedc59e4f48185fe9fdde404c7a4acce&scene=126&sessionid=1681270803#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247484186&idx=1&sn=cf3070264063807909101c18d2b6cd81&chksm=e930260bde47af1dcbc058937117d80e63c9d11f4e29eedc59e4f48185fe9fdde404c7a4acce&scene=126&sessionid=1681270803#rd)

  

2018年5月20日，工业和信息化部信息中心在2018中国区块链产业高峰论坛上发布了《2018中国区块链产业白皮书》。白皮书系统展示了我国区块链产业发展现状，对当前区块链产业的特点和发展进行了总结与分析，对于区块链技术在相关领域的应用进行了研究探讨，列举区块链应用和产业实践的典型模式和案例，最后对产业发展趋势进行了预测与展望。现将全文转发如下。
