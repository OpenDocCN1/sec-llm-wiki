# 中国（大湾区）工业互联网发展与安全峰会在深圳成功召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247494249&idx=1&sn=361484cefb8c8a4905beacccecde045d&chksm=e933cf78de44466eac642a2593a25f5b465034a9d4f72ae0f2e4f34cc4028a7b3fe9b617d86b&scene=126&sessionid=1681270506#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247494249&idx=1&sn=361484cefb8c8a4905beacccecde045d&chksm=e933cf78de44466eac642a2593a25f5b465034a9d4f72ae0f2e4f34cc4028a7b3fe9b617d86b&scene=126&sessionid=1681270506#rd)

2023年4月8日，中国（大湾区）工业互联网发展与安全峰会在深圳成功召开。本次峰会与第十一届中国电子信息博览会同期举办，由中国电子信息产业集团有限公司主办，中国电子信息产业集团有限公司第六研究所、工业控制系统信息安全技术国家工程研究中心、中电会展与信息传播有限公司承办，来自线上线下2000余位行业专家和技术人员收看本次峰会。

# 

  
![](../Images/82dd893c8efd510e488f19de572c7b19.png)中国电子信息博览会组委会秘书长、电子元器件和集成电路国际交易中心总经理陈雯海在致辞中表示，当前我国工业互联网创新发展正处于从起步探索转向规模发展的关键期，粤港澳大湾区拥有良好的数字产业基础和优势制造产业集群，行业集中度较高，产业生态健全，在中国经济发展方面一直起引领示范作用。 进一步推进大湾区工业互联网基础设施、服务体系、生态体系建设，对促进工业制造业企业数字化转型、实现高质量发展，具有十分重要的意义。

![](../Images/ab562e9c6acd3cbde2866fec09158508.png)中国电子信息产业集团有限公司总经理助理、中电工业互联网有限公司董事长朱立锋代表主办方在致辞中表示，工业互联网作为新一代信息技术与工业经济深度融合的关键基础设施，正以体系化发展方式推动中国制造业迈向高质量发展。中国电子深入贯彻党的二十大精神，主动服务国家战略，持续优化产业结构，南迁深圳以来，中国电子把握大变局、融入大湾区，全面加强网信领域战略科技创新，着力攻克关键核心技术，大力推动信息技术应用创新产业发展，为大湾区建设发展作出了积极贡献。中国电子将围绕以数字技术支撑国家治理体系和治理能力现代化、服务数字经济高质量发展、保障国家网络安全三大核心任务，着力发展计算产业、集成电路、网络安全、数据应用、高新电子、工业互联网等重点业务，打造国家网信事业核心战略科技力量。![](../Images/ed604ca8f2461fa6540a19d64c7d415d.png)中国科学院院士、通信网络领域专家尹浩在题为《把握工业信息安全发展态势，合力应对工业信息安全挑战》主旨演讲中着重讲解了工业信息安全面临的新形势和安全风险应对举措。尹院士认为工业信息安全是制造强国、网络强国的基石，全球工业经济正加速数字化转型，工业数据流动范围不断延展，工业信息安全已经成为国际竞合、国际规则制定的核心议题和重要领域。为此，他提出从工业和网络两个层面开展工作，提出应从工业设备安全、传输网络安全、控制系统安全、应用服务安全、工业数据安全五个维度来构建工业信息安全保障体系。![](../Images/46253625287eeaf71fb22cc077964f12.png)工业和信息化部网络安全产业发展中心副处长郭威在题为《工业互联网数据安全发展机遇与挑战》的视频致辞中指出，工业互联网面临安全事件频发、安全建设同步不够、安全意识亟待加强、应急响应体系有待完善等主要问题，在工业经济向数字经济转型过程中，工业互联网呈现关键技术加速融合、行业应用持续深化、能力建设逐渐成熟等特点。围绕工业互联网安全管理需求，应以“原生安全、密码应用、纵深防御、测评加固、功防演练、统一管理”为重点方向，构建工业企业安全综合防护体系。![](../Images/e0fa8a04e06b8963cc245d7fd565b818.png)北京航空航天大学网络空间安全学院副教授，博士生导师洪晟在题为《新时期工业互联网基础设施建设的内涵与发展机遇》的致辞中指出，工业互联网作为新基建的重要组成部分，正加速成为中国经济发展的主推力量。传统行业需要加快拥抱工业互联网，通过部署个性化工控系统，实现自动化控制、管理、安防等工作，顺应工业信息化趋势，同时使自身利益最大化。通过加强市场引导、加强投入、形成产业集群、推动技术创新等措施解决我国现阶段工业互联网发展过程中面临的问题，使工业互联网更好地服务于各行业。![](../Images/f394f96344019accec57c8c5bf1628be.png)北京惠而特科技有限公司总经理谭曙光在题为《做好工业互联网融合安全》的演讲中，提出了以融合安全解决工业安全的思想，做好工业互联网安全的最后一公里。指出融合安全的关键是认知的打通和技术的融合，只有深度理解工业场景，将网络安全防御技术恰当的部署到工业环境，才能形成一体化的网络安全防御体系。同时应该做好四个方面的工作：一是人才融合，打通认知和理解的边界；二是管理融合，把多年来生产安全的实践和管理手段与网络安全管理的实践和管理手段相结合；三是技术融合，将工业自动化技术、工控协议解析技术、工艺流程、工业数据安全等相结合；四是场景融合，理解工业场景的现状和实际问题，形成接地气的、场景化和可落地的个性化融合防御体系。![](../Images/666e18fab19e83387b534af44c5d615b.png)是德科技(中国)有限公司资深解决方案工程师莫小龙作了题为《从终端到网络---Keysight 助力 5G工业物联网设备性能安全》的演讲，从网络硬件节点性能以及网络部署的角度，介绍了如何运用各种测试、模拟和网络优化工具打造稳定的基于5G技术的工业物联网“底座”，为工业物联网的安全保驾护航，从而帮助企业提高工业物联网的运营效率，降低企业的运营成本。

![](../Images/d9b4d9bb70a4faf6e8df863a4edb5532.png)中电鹏程智能装备有限公司副董事长、首席科学家李仁博士在题为《中电云网助力数字化转型》的演讲中指出，中电云网是中国电子基于集团完整信息技术产业链打造的唯一工业互联网平台，介绍了中电云网的平台技术架构、平台创新、可靠性和安全防护能力，以及介绍赋能“平台+园区”的转型成效和行业应用案例，指出“自动化改造+数字化工业技术+工业互联网技术”是工业互联网赋能数字化转型的成功路径。![](../Images/f595ae7551ac55e31b8e563577bd5acc.png)润联智能科技股份有限公司高级技术专家余斌在题为《工业互联网创新模式赋能制造业创新发展》的演讲中指出，工业互联网与智能制造转型的核心，取决于先进信息技术、先进制造技术与工业在不断迭代升级中结合应用场景进行深入融合，其本质是以人为本，通过精益化、自动化、数智化三个阶段，结合“IE + IT + AI”等技术，逐步实现从人治到辅治，再到混治和机治。![](../Images/9b0c97eba02adfb576ef4abe8074b1ac.png)蘑菇物联技术（深圳）有限公司总裁助理张铭作题为《AI技术如何助力工业实现双碳》，指出当前已处在实现“双碳”目标与工业制造业数字化转型相交汇的时代节点，如何为通用工业设备行业提供新一代基于工业互联网的AIoT SaaS服务，实现“通用设备数智化”和“公辅车间数智化”，将为工业设备产业链创造可测量的价值。![](../Images/221273aedade6e98583d438d8884fd51.png)峰会现场还举办了工业元宇宙、工业互联网及安全主题圆桌论坛，论坛由工业控制系统信息安全技术国家工程研究中心总体室主任申志伟主持，覆盖产学研用各领域的嘉宾经过热烈讨论，一致认为工业元宇宙具有可落地的应用场景，核心技术会不断得到攻克，是工业互联网演进的未来形态，安全系统性解决方案会逐步形成。![](../Images/acb4234a57784500f7aab2899f86c9b0.png)本次中国（大湾区）工业互联网发展与安全峰会聚焦工业制造业数字化转型，搭建高端合作交流平台，汇聚政产学研用各领域资源，通过政策解读、案例分享、行业前瞻等研讨环节，探讨大湾区制造业数字化转型的机遇与挑战，为加速推进工业互联网赋能制造业数字化转型升级，实现制造业高质量发展贡献力量。
