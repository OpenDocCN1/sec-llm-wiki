# “政产学研用”互促互进，为大湾区工业互联网发展与安全助力

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247494197&idx=1&sn=87ff8ad7d7bf6b066232826564cdd277&chksm=e933cf24de4446329a7da604ff5a15ac47fc08d23cbcb6f2a46c099e546ef332efd0e6962fc5&scene=126&sessionid=1681270506#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247494197&idx=1&sn=87ff8ad7d7bf6b066232826564cdd277&chksm=e933cf24de4446329a7da604ff5a15ac47fc08d23cbcb6f2a46c099e546ef332efd0e6962fc5&scene=126&sessionid=1681270506#rd)

**“2023中国（大湾区）工业互联网发展与安全峰会”召开在即**，本次峰会由中国电子信息产业集团有限公司主办，中国电子信息产业集团有限公司第六研究所、工业控制系统信息安全技术国家工程研究中心、中电会展与信息传播有限公司联合承办，期望在更高水平上聚焦制造业数字化转型，打造覆盖“政产学研用”的高端合作交流平台，为加速推进工业互联网赋能制造业转型升级，实现制造业高质量发展助力。

# 

  

工业互联网是第四次工业革命的重要基石。当前，我国工业互联网创新发展取得初步成果，正处于从起步探索转向规模发展的关键期。粤港澳大湾区拥有良好的数字产业基础，拥有一批电子信息、家电、汽车、医药、化工、智能装备与机器人、超高清视频显示等优势制造产业集群，行业集中度较高，产业生态健全，在中国经济发展方面起引领示范带动作用。

为此，第十一届深圳电子博览会在2021、2022 年两届“工业互联网发展与安全峰会”成功举办的基础之上，今年峰会正式更名升级为“2023中国（大湾区）工业互联网发展与安全峰会”。

为做好中国（大湾区）工业互联网发展与安全的前期预热工作，峰会宣传组联合《网络安全与数据治理》杂志社、《电子技术应用》杂志社等专业媒体，开展“工业互联网·百家谈”等采访报道工作，从专业视角对时下工业互联网的发展动向进行宣传报道，为峰会的召开进行预热。

“大力发展智能制造与工业互联网是发展先进制造业的核心，其关键是实现制造业设计、生产、管理、服务等产品全生命周期的数字化、网络化和智能化。”中国电子总经理助理、中电工业互联网有限公司（简称中电互联）党委书记、董事长朱立锋在接受采访时表示，“作为中国电子发展工业互联网的核心支撑单位，中电互联自主研发中电云网——国家级跨行业跨领域工业互联网平台，并建成国内首个电子信息行业工业互联网标识二级节点，在‘5G+数字化工厂’、‘平台+园区’、智能装备、智能终端、工业软件、工程机械等多个领域打造了一批智改数转示范标杆，不断突破先进制造重点领域、关键环节、核心产品的‘卡脖子’问题。”

“工业互联网本身就是数字浪潮下工业体系和互联网体系深度融合的产物，已经成为促进我国供给侧结构性改革、加快新旧动能转换的关键抓手。”中关村新兴领域专题赛专家委副主任、中国国防工业企业协会自主可控工作专家委员、信息安全与通信保密理事会原理事长郭守祥在接受采访时表示，“基础IT软硬件以及各类生产控制系统、核心业务系统和管理信息化系统是国家安全和产业安全运营的重要支撑和保障。因此工业互联网特别是‘5G+工业互联网’建设过程中，必须坚定地推进融合发展原则，实现与国家基础软硬件生态建设融合发展，才是高质量发展的必由之路。”

工业制造业数字化转型不再是单一业务环节上应用和业务系统间的综合集成，而是以数据为驱动的战略目标的实现和发展模式的创新。因此，数据工作是推进数字中国建设，推动数字经济高质量发展的必要之举。北京国际数字经济治理研究院院长、清华中国电子数据治理工程研究院院长孟庆国认为，“由于数据要素自身的诸多特性，如无形性、非消耗性、接近零成本复制，也包括非竞争性、非排他性等因素，数据在流通、交易中尚存在确权难、定价难、互信难、监管难等难题，对大规模地释放数据价值和实现数字经济发展目标带来巨大挑战。”孟庆国认为，“数据二十条”是落实党中央关于数据作为关键性新型生产要素的一系列部署而发布实施的，实际上是希望通过市场机制来配置数据资源，快速融入生产、分配、流通、消费等各环节，深刻改变着生产方式、生活方式和社会治理方式。

“随着万物互联、万物计算的数字时代的到来，传统工业互联网‘定制芯片+闭源操作系统+专用互联体系’的垂直封闭烟囱模式已不适应工业互联网产业的加速发展。”据中国电子信息产业集团有限公司第六研究所副总工程师、工业控制系统信息安全技术国家工程研究中心副主任吴云峰介绍，“应借鉴IT领域成功经验，以开放CPU和开源操作系统为切入点，基础芯片向超高性能、超低功耗、场景定制方向发展，基础软件向原生开放、泛在协同、智能感知方向发展，网络技术向泛在链接、智能管控、高速弹性方向发展，网络信息安全向智能防御、统一管控、软件定义方向发展，打造工业互联网基础软硬件新生态根基。”

党的二十大报告指出，坚持把发展经济的着力点放在实体经济上，推进新型工业化，加快建设制造强国、网络强国，为工业互联网的发展指明了前进方向，提供了根本遵循。十四五期间，国家将以“链主”企业数字化转型为牵引，进一步强化链式发展，通过建设工业互联网平台带动全链数字化改造和上云上平台进程不断加快。

即将召开的中国（大湾区）工业互联网发展与安全峰会将围绕“数字驱动，智造未来”这一主题，开展跨越“政、产、学、研、用”交流碰撞，为赋能工业制造业转型升级，实现大湾区高质量发展助力！让我们共同期待！
