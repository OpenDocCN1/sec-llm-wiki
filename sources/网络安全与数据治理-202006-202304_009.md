# 云南省首个！《大理州数据治理工程—数据安全与数据要素化工程总体方案》通过专家论证

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247494191&idx=1&sn=bc5867db5877e4760e1cbd7f6dead6ec&chksm=e933cf3ede4446288357a7b97cc6f408e5ac150c03b05fe0653b930852b7cc68da4e529efc9e&scene=126&sessionid=1681270506#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247494191&idx=1&sn=bc5867db5877e4760e1cbd7f6dead6ec&chksm=e933cf3ede4446288357a7b97cc6f408e5ac150c03b05fe0653b930852b7cc68da4e529efc9e&scene=126&sessionid=1681270506#rd)

3月30日，由中国电子、中电数创联合大理州数字经济办组织召开的“大理州数据治理工程—数据安全与数据要素化工程总体方案专家论证会”在大理成功举行。由中国电子牵头完成的《大理州数据治理工程—数据安全与数据要素化工程总体方案》（以下简称《总体方案》）通过专家论证，标志着大理州数据要素化试点迈出重要一步，为数字大理的发展夯实基础。作为云南省首个立足区域实际的数据治理工程方案，《总体方案》也为探索云南省数据要素市场化配置改革树立了标杆。

  

![](../Images/34c77850626a4b767580a409242f2e0f.png)

# 

  

此次论证会由中国经济体制改革研究会副秘书长、中国经济改革研究基金会秘书长石明磊担任专家组组长，成员由来自中国经济体制改革研究会、云南省通信学会、北京大学、清华大学、昆明理工大学、建设数字云南领导小组专家组等机构的权威专家组成。

![](../Images/b950511333f3a7c4cd23a72f838b2601.png)

  
  
中国电子数据治理工程指挥部向专家组汇报了《总体方案》的核心内容。专家组就《总体方案》进行充分质询与讨论，认为该方案在深入调研分析基础上，紧扣国家和省级政策要求，结合大理实际，从工程设计、制度文件、标准规范、产业服务四个方面系统谋划了大理州数据要素发展路径，符合国家、省关于数据要素市场化配置改革的总体要求和发展思路。同时，《总体方案》强调在数据安全合规前提下，建立健全完善的数据要素制度体系、技术体系、市场体系，思路清晰、结构合理，具有较强的前瞻性和可操作性，对加快数据要素市场化配置改革、培育与完善数据要素市场具有重要的指导意义。会上，专家组一致同意通过论证。下一步，中国电子数据治理工程指挥部将与大理州共同推进《总体方案》的全方位落地，并在文旅、能源、环保等几个重点领域先试先行，积极稳妥推进数据治理工程试点，激发数据要素价值。![](../Images/751fd89d2f95a856b9b2957d62098d1c.png)大理州委书记杨国宗表示：当下，探索数据合规高效流通，激发数据要素价值，已经成为推动经济高质量发展的新引擎。大理州抢抓数据要素发展先机，与中国电子携手在云南省内率先发起城市数据治理工程相关研究，致力于为云南省数据要素市场化配置改革探索出一条安全、高效、可行的实践方案，打造数字时代的“大理样板”。下一步，大理州将坚决贯彻落实《中共中央、国务院关于构建数据基础制度更好发挥数据要素作用的意见》（简称“数据二十条”），立足国家、省数据要素市场化配置改革的战略要求，基于《总体方案》，形成完备的数据要素统筹协调机制，加快数据基础制度构建和数据要素市场培育，将大理州建设成为云南首个、全国领先的数据要素市场化改革试点城市，全面激活数字经济发展动能，抢占数字经济发展制高点。![](../Images/7b0a88a7f98d3b11584109daf89a3710.png)

  

中国电子所属桑达股份高级副总裁、中电数创总经理王晓亮表示：《总体方案》是继2021年中国电子与大理州签署“共建数据要素市场化试点城市合作协议”之后的重要合作成果，将助推大理州数据要素市场化配置改革迈上新台阶。未来双方将进一步推动“制度+技术+市场”三位一体的总体实施架构在大理州顺利落地，有效破解当前数据安全和数据要素市场化痛点和难点，盘活数据资源，释放数据价值、培育数据产业，助推“数字大理”和“数字云南”建设，为数据要素市场化配置改革贡献力量。大理州委常委、大理市委书记字德海，副州长鲁旭俊等政府领导，桑达股份副总裁周崇毅，助理总裁乔亲旺，中国电子数据治理工程指挥部相关负责人，数字大理建设运营有限公司等领导参加本次论证会。
