# 2023春季中国数字经济发展和治理学术年会即将开幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247493990&idx=1&sn=2e173ed4d8b913041fe7931e2d025edc&chksm=e933cc77de4445610d72e95d180dc8a18caf6dde8ba272477bc4e5f3f13d15e4ab62488d607b&scene=126&sessionid=1681270541#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247493990&idx=1&sn=2e173ed4d8b913041fe7931e2d025edc&chksm=e933cc77de4445610d72e95d180dc8a18caf6dde8ba272477bc4e5f3f13d15e4ab62488d607b&scene=126&sessionid=1681270541#rd)

**首届“中国数字经济发展和治理学术年会”将于2023年2月18日在京召开，邀请国内领先科研组织和顶尖专家学者开展基础性、理论性和前瞻性交流研讨，**就数字时代经济发展规律、推进路径、治理思路等进行多学科对话与跨领域共享，进一步提升我国数字经济发展学术研究水平，培养数字经济领域专项人才，为我国数字经济建设提供可靠支撑。

为贯彻落实习近平总书记关于“加强数字经济发展的理论研究”的重要指示要求，全球数字经济大会组委会联合国内外著名高校、科研院所和业界重要研究机构，共同发起设立“中国数字经济发展和治理学术年会”，旨在更好把握数字经济发展趋势和规律，探讨和完善数字经济治理体系，进一步加强数字经济理论研究与交流。

  

![](../Images/13bd0e48ef2a94f0c8e404e36fea38a9.png)

**时间：**2023年2月18日 9:00 — 18:35

  

**地点：**清华大学经管学院建华楼

  

**指导单位：**全球数字经济大会组委会

  

**共同发起单位：**清华大学、北京大学、中国人民大学、复旦大学、上海交通大学、西安交通大学、哈尔滨工业大学、浙江大学、南京大学、南开大学、中山大学、中国科学院大学、中国社会科学院大学、中国国际金融股份有限公司

  

**主办单位：**清华大学

  

**承办单位：**清华大学经济管理学院、清华大学公共管理学院、教育部哲学社会科学实验室-清华大学计算社会科学与国家治理实验室

  

**协办单位：**北京国际数字经济治理研究院、清华大学服务经济与数字治理研究院
