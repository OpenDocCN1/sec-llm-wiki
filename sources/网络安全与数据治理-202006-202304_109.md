# 数字经济健康发展全国深度行（首站）·深圳站——数据治理论坛在深圳市龙华区成功举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247493122&idx=2&sn=8b9e1cba1d5bb321b47604302a7e7f9c&chksm=e933c313de444a050ed7f3cf2334071c6187f9f174b62d330c6c3d8528f40cbb4d502e53f1fd&scene=126&sessionid=1681270562#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247493122&idx=2&sn=8b9e1cba1d5bb321b47604302a7e7f9c&chksm=e933c313de444a050ed7f3cf2334071c6187f9f174b62d330c6c3d8528f40cbb4d502e53f1fd&scene=126&sessionid=1681270562#rd)

![](../Images/e2991686d65433efb057226265e924e6.png)

党的二十大报告指出，要“加快发展数字经济，促进数字经济和实体经济深度融合”。作为新型生产要素, “数据”已成为数字经济发展的“工业石油”，数据治理面临着前所未有的机遇和挑战。为加快打造数据治理的高端合作平台，进一步激活和释放数据要素潜能，**11月8日下午，数字经济健康发展全国深度行（首站）·深圳站——数据治理论坛在深圳市龙华区隆重举行。**来自国家主管部门、深圳市、中央企业、生态联盟等各界人士和代表济济一堂，共同探讨交流数据治理的最新指导政策、理论研究及实践经验等重大问题，凝聚共识、汇聚力量，共迎数据安全治理新时代，推动我国数字经济持续健康发展。  

![](../Images/f19922bd4f2551a2979bea51c0d97bbc.png)

**深圳市人大常委会副主任、党组成员彭海斌**在致辞中表示：数据作为新型生产要素，是数字经济发展的核心引擎。一直以来，深圳是数字经济的先行者。深圳在“十四五”规划纲要中也提出了“打造全球数字先锋城市”的目标，明确要“抢抓数字技术产业变革机遇，以数字产业化和产业数字化为主攻方向，建设数字政府、智慧城市、数字生态，促进数字化转型，引领数字新生活”。 

  

![](../Images/938cbd7d0ff4830a9a3afa46ce115ace.png)

**深圳市龙华区委副书记、政法委书记皮勇华**致辞表示：龙华区立足数字经济产业基础优势和先发优势，将积极争取各级政策支持和资源布局，创造良好营商环境，有效落实数字经济专项产业政策，充分发挥“1+N+S”数字经济政策体系对产业引导和促进作用，确保各项产业支持政策落到实处。欢迎各界来到龙华、扎根龙华，共同激活和释放数据要素潜能、服务深圳数字城市建设。

  

![](../Images/61bd5c38072f0bacd7a0bf42d1218a9d.png)

**国家工业信息安全发展研究中心副主任何小龙**表示：近些年我国高度重视推进数据要素市场化配置，充分发挥了数据要素对产业发展的牵引作用，形成了数据要素价值加速释放的良好局面。下一步，我们要以推动数字经济和实体经济深度融合为重点，从安全、开放、效能三方面入手，加快构建数据治理体系，充分释放数据要素价值。

  

![](../Images/3c3ad064a0d3ac858b5c821c8c81b29c.png)

**中国电子信息产业集团有限公司总经理助理、数字办常务副主任朱立锋**表示：为充分释放数据要素价值，发挥好数据在数字经济发展中的基础性和支撑性作用，中国电子先后联合清华大学、中国经济体制改革研究会成立数据治理工程联合研究院、数据要素市场化配置综合改革研究院，围绕机制体制改革、数据新型基础设施、数据产业培育等方面开展专项攻关，率先取得数据要素跨学科研究实质性突破，在国内首次提出以“数据元件”和“数据金库”为核心的数据安全和数据要素化工程总体方案，为城市数据治理工作提供理论参考和实践指引。

  

![](../Images/b7494d1ac04d994a2c4b363c9a7557ad.png)

主旨演讲环节，政产学研各届嘉宾分别展开精彩分享。**中国科学院外籍院士、深圳计算科学研究院首席科学家樊文飞**发表主旨演讲。他认为，数据治理面临的一项严峻挑战是数据质量和数据分析。深圳计算科学研究院从大数据基础软件创新入手，研发了采石矶、钓鱼城等国际领先的数据质量和分析工具，在不同行业拥有巨大的应用场景和潜力，未来希望与中国电子开展产业场景的合作，将有利于进一步提升数据治理水平、真正实现数据价值。  

  

![](../Images/cf96a14ae833380ac5c977c68b263f48.png)

**中国经济体制改革研究会副秘书长、中国经济改革研究基金会秘书长石明磊**表示：数据不同于传统生产要素，需要全新的制度建设和地方试点共同推动要素化市场配置改革；要用工程化、技术化路径推动有关制度落地实施。中国电子联合清华大学提出的整体解决方案很好的解决了数据要素化和数据安全的核心问题，真正让数据安全可控的前提下释放到市场中参与要素化流通。  

  

![](../Images/9737f4f213efc52e90ff1afc53222a89.png)

**中国系统助理总裁、数据治理工程指挥部技术部主任国丽**介绍了中国电子数据安全与数据要素化工程方案内容。中国电子在数据安全与数据要素方面积累了丰富的理论研究和实践经验，率先在理论创新、技术创新和制度创新等方面取得重大突破，为我国数据要素市场化配置改革探索了一条行之有效的成功路径。  

  

![](../Images/81249038df1c6411a697ece731a8faf4.png)

**四川德阳市政协副主席, 市政务服务和大数据管理局局长刘泽球**表示：德阳从资源、制度、流通、价值、应用五方面探索破题数据要素市场化配置改革，在中国电子的合作支持下，作为全国试点工作的首个体系性、标杆性工程试点，德阳成功验证了中国电子数据安全与数据要素化工程理论体系，在全国地级城市中率先发布数据要素改革制度体系、完成数据元件开发并赋能应用场景、布局建设数据要素产业园。验收专家一致认为德阳实践取得了较好的经济社会效益，整体处于国际先进水平，具有示范引领效应。  

  

![](../Images/86937ab1aae67e0309dd0ae07aded768.png)

**丰图科技副总裁李帅**分享了丰图数据资源体系，以及数据要素助力物流、运输等产业数字化转型的领先实施经验。  

  

![](../Images/7c8357832ed7b9d9803f0f5409eac1b2.png)

**京信数科副总经理周建雄**介绍了京信数科利用数据价值驱动构建数据体系、形成数据资产形成、分析产业发展和运营数据资产等数字政府和数字经济相关服务经验。

  

![](../Images/a43db2247dbc31fb3da24de13d8151c3.png)

圆桌对话环节由朱立锋主持。**国家工业信息安全发展研究中心数字经济研究室主任殷利梅、深圳市商汤科技有限公司副总经理李廷波、深圳云天励飞技术股份有限公司副总裁郑文先、深圳数据交易所副总经理王腾、深圳计算科学研究院数据质量&数据分析CTO马海寅**五位嘉宾参与，围绕“公共数据和企业数据的融合” “数据安全与流通”两个问题充分讨论交流。

  

![](../Images/a90d3757a07ed39e8f63b336b50725ca.png)

本次论坛是由深圳市政府指导，深圳市工信局、龙华区政府、国家工业信息安全发展研究中心、中国电子信息产业集团有限公司数字办联合主办，数字广东网络建设有限公司、赛昇数字经济研究中心联合承办。本次活动的举办将有利于引导政府、企业、学界等共同联动，打造数字经济、数据要素新业态，为全国城市数字经济发展模式提供重要参考和借鉴。
