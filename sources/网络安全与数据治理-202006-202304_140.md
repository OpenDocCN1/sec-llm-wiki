# 数据安全与数据要素化工程课题研讨会在京举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247492721&idx=1&sn=c3305fc1d024c65d520e9296b4339b66&chksm=e933c160de4448761578085e252fb020d95c05f571c0890c981ec3702f1da425d4d367acf346&scene=126&sessionid=1681270578#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247492721&idx=1&sn=c3305fc1d024c65d520e9296b4339b66&chksm=e933c160de4448761578085e252fb020d95c05f571c0890c981ec3702f1da425d4d367acf346&scene=126&sessionid=1681270578#rd)

9月24日，由清华中国电子数据治理工程研究院（简称研究院）主办的“数据安全与数据要素化工程课题研讨会”在奇安信安全中心举行。研究院管委会主任，中国电子副总经理、党组成员陆志鹏，研究院院长、清华大学公共管理学院教授孟庆国出席。  

  

会议分别听取了数据安全与数据要素化工程最新进展情况、工程总体框架以及联合研究工作分工方案的专题汇报。围绕数据估值定价机制，数据治理的发展脉络、内涵与特征等话题，会议展开了热烈讨论，并形成一致意见。会议指出，当下信息技术正在向数据技术转变，要把数据技术的研究成果与理论实践紧密结合，不断深化课题研究并形成学术成果，从而引领数据技术发展，占领数据技术的制高点。

  

![](../Images/0108f1e14b1a539b692d5285b5606756.png)

陆志鹏对本次会议给予高度评价，并对研究院下一步工作提出三点希望：一是将最新的理论实践和研究成果进一步融合、提升，形成学术专著；二是制定有效工作机制，推动课题任务分工协作，年内实现成果落地；三是近期围绕工程方案、案例实践及年度课题计划，组织开展深入研讨。  

  

清华大学有关院系，中国电子数字办、中国电子数据治理工程指挥部相关人员参加研讨交流。
