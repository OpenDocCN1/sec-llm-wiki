# 数据金库安全系统研讨会在京举行

9月24日，中国电子数字办、数据治理工程指挥部（简称指挥部）组织中国系统、电子六所、奇安信三家企业，围绕数据金库安全系统的设计和测试方案，举行专题闭门研讨，并对下一步协同攻关、方案完善工作进行部署。中国电子副总经理、党组成员陆志鹏，总经理助理、数字办常务副主任朱立锋、奇安信董事长齐向东、电子六所所长张尼等出席会议，相关技术专家和工程人员参加研讨交流。
