# 数据要素市场化配置综合改革研究院揭牌成立

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODk1NzY5NA==&mid=2247491086&idx=1&sn=a52da29d98af7daeca355b9fc8ee87f4&chksm=e9303b1fde47b209fcc981b656c4cdfc517361f5f955794a22913adad927b1f8fd2beb0aa3d0&scene=126&sessionid=1681270602#rd](http://mp.weixin.qq.com/s?__biz=MzIzODk1NzY5NA==&mid=2247491086&idx=1&sn=a52da29d98af7daeca355b9fc8ee87f4&chksm=e9303b1fde47b209fcc981b656c4cdfc517361f5f955794a22913adad927b1f8fd2beb0aa3d0&scene=126&sessionid=1681270602#rd)

![](../Images/94324c0b510975a7f00c719808dc4321.png)

  

6月20日，城市群、都市圈及中心城市数据要素市场化综合改革试点方案研讨会在京举办，**由中国电子、中国经济体制改革研究会、中国经济改革研究基金会三方联合成立的“数据要素市场化配置综合改革研究院”正式揭牌。**中国电子党组书记、董事长芮晓武，国家发改委原副主任、中国经济体制改革研究会会长彭森致辞。中国科学院院士、北京大数据研究院院长鄂维南，中国电子党组成员、副总经理陆志鹏，工业和信息化部信息技术发展司副司长（主持工作）王建伟，国家工业信息安全发展研究中心副主任何小龙，清华大学公共管理学院教授、清华中国电子联合研究院院长孟庆国，中国经济体制改革研究会副秘书长、中国经济改革研究基金会秘书长石明磊等专家领导参加活动。

  

![](../Images/9c6cc23c6ede12a49032cc2ec090f9ce.png)

![](../Images/d3b3bda6bef551f0f9d70bca30952941.png)

  

会上，**中国电子分别与北京大数据研究院、中国经济体制改革研究会、中国经济改革研究基金会签署战略合作协议。**各方将致力于数据要素领域，充分发挥各自优势，在科研创新、产业转化、智库咨询、人才培养等方面展开深入合作。

  
![](../Images/92be6679254fc56150aac7a5de8d69dd.png)

  

芮晓武表示，中国电子正加快打造国家网信产业核心力量和组织平台，在“数字中国”建设、数字经济发展和数据要素市场化配置综合改革领域开展理论研究和地方实践，取得了阶段性成果。研究院的成立将共同推进数据要素市场化配置综合改革试点和推广，搭建数据要素市场化改革公共交流平台，为各省级城市、都市圈、城市群等数据要素一体化建设贡献智慧和力量，为我国数字经济的新发展做出新贡献。  

  

![](../Images/a3410558a6f66cf9ff48c383f66a6d2d.png)

  

彭森表示，数字化转型是经济社会发展的必由之路。由数据作为基本生产要素并强力驱动的数字经济正在蓬勃兴起。此次与中国电子共建联合研究院，将聚焦数据要素市场的重点难点堵点问题，在确保数据安全和隐私保护的前提下，推进公共数据归集和安全存储，推动符合条件的数据和数据元件流通应用，为数据要素市场化配置改革探索实施路径贡献体制机制设计方案，助推我国数字经济高质量发展。

  

![](../Images/fd09d50b91b245c9912b04fd44273f0e.png)

  

中国经济体制改革研究会副秘书长、中国经济改革研究基金会秘书长石明磊高度评价了中国电子在中国网信产业和数字城市建设领域所做出的重要贡献和引领作用，并围绕数据要素市场化配置改革的重要内容、推进方式以及政策方向进行深入解读，认为数据要素市场化配置综合改革是一项制度性的建设工作，将充分激活数据要素的活力，为数据科技的发展保驾护航。

  

![](../Images/0ba3e2e5a4dff1c57d93f26dbfa607ef.png)

  

中国科学院院士、北京大数据研究院院长鄂维南围绕人工智能与现代化治理体系作主旨演讲，并对现代化治理体系中存在的核心问题，从机制体制层面和技术层面做了深入剖析，强调建设过程中存在的数据孤岛、模型孤岛、技术门槛、应用门槛问题，提出相关建议。

  

![](../Images/0b611357d406b75d898f1c59db967eac.png)

  

清华大学公共管理学院教授、清华中国电子联合研究院院长孟庆国表示，当前探索数据要素市场化综合改革，需要重点关注公共数据的安全高效开发利用、从应用场景角度推动数据要素资源的市场化配置、数据要素市场化改革中制度创新和探索等问题。

  

![](../Images/e4e8aa7cab02f197116e76b7e7e8bd0a.png)

  

中国系统助理总裁、数据治理工程指挥部技术部主任国丽介绍了中国电子城市群、都市圈及中心城市数据要素市场化综合改革试点方案。

  

![](../Images/75025a073fb807110b54cc112b5abaea.png)

  

会议由中国电子总经理助理、数字办常务副主任朱立锋主持，集团总部规划科技部，中国电子所属中国系统、中电数据、奇安信等相关负责人参加会议。
