# 专访 l 孔令武：与时俱进 赋能工业数据治理

【编者按】近年，国际上针对工业、制造业领域的网络攻击、勒索攻击频现，工信部近期两次公开征求对《工业和信息化领域数据安全管理办法（试行）》的意见，如何开展工业、制造业领域的数据共享与利用，如何做好数据安全和数据治理规划，已经成为全社会关注的焦点。没有网络安全就没有国家安全，没有数据安全就没有网络安全。数据作为新的生产要素，在数字社会发展中起到基础性和支撑性关键作用。围绕工业数据空间治理的最新发展趋势和“十四五”工业互联网发展要求，我国出台了《关键信息基础设施安全保护条例》《数据安全法》《网络安全法》《个人信息保护法》《国家安全法》《民法典》等一系列法律法规，让网络空间、数据空间治理更加纲举目张。《信息技术与网络安全》期刊对珞安科技CTO孔令武进行专访，希望进一步为读者剖析廓清工业数据空间治理与数据安全技术发展的方向。  
 ![](../Images/60e3d062fc4e66b449d016d97b27351b.png)北京珞安科技有限责任公司CTO 孔令武 | 珞安科技  
**工信部近期两次公开征求对《工业和信息化领域数据安全管理办法（试行）》的意见，您认为目前国内工业领域数据安全整体形势是否已经迫在眉睫？**孔令武：随着工业领域数字化、智能化进程的逐步深入，工业互联网平台应用已成为发展的大趋势，导致大量研发设计、生产制造、经营管理、运维服务的相关数据实现互联互通，在大幅提升经济社会效益的同时，海量数据的集中也势必导致数据安全问题越发凸显。  
今年是“十四五”规划的第二年，工业领域和智能制造领域大规模的数字化建设将逐步开展，数据由分散的节点集中到平台化数据中心的进程将加快。如果平台和中心的安全性出现问题，会导致以往需要通过复杂方式、花费大量精力才能收集获得的数据，被轻而易举地一次性获取。数据安全面临的挑战因平台中心化而变得更加严峻。近期，工信部再次对《工业和信息化领域数据安全管理办法（试行）》公开征求意见，已经充分说明数据安全问题到了必须予以重视和妥善解决的阶段。 **与网络安全等级保护相类似，《工业和信息化领域数据安全管理办法（试行）》中要求对数据进行分类管理，制定行业重要数据和核心数据具体目录，并实施动态管理。请您介绍一下，工业领域重要数据和核心数据包括哪些？对这些数据实施全生命周期管理的重要性何在？**  
孔令武：工业数据领域的显著特点是行业的差别比较大。从生产经营角度，包括研发数据、设计数据、生产数据、经营数据、运营数据，甚至包括工业互联网平台企业的资产运行监控数据、工业APP应用数据等，但具体到不同行业、不同应用场景，工业数据安全防护又存在不同的侧重点，所以对数据做好分类管理十分必要。  
传统产业数字化转型以前，企业对各类生产数据缺少价值认知，同时缺乏相应的数据安全概念。进入工业互联网时代后，新的生产方式和新业态逐步出现，数据作为价值金库的作用逐渐凸显。首先，数据分类非常重要，在数据分类的基础上，企业可根据不同专业、不同场景设置不同应用，合理利用相关数据，从而实现数据的价值化。从数据治理的角度出发，不同数据需匹配不同的安全策略，例如，研发数据的管理更侧重于企业内部使用，但设备运维数据可能需要与第三方的运维厂商和设备厂商共享。如果数据分类工作不到位，大量数据混杂在一起，既不利于数据利用也不利于数据治理，所以数据分类是数据利用和数据治理的前提。  
其次，数据安全不同于网络安全，数据的生命周期管理工作非常重要。企业产品从设计到最后交付运营，过程中会产生各式各样的数据，从数据的采集、处理、存储、使用到最后的销毁，在全流程中只有做到可视化、可控化，才能够实现数据的全生命周期管理。例如，电力企业用电量的数据对金融行业具有很直观的参考意义。那么，如何保证相关数据被合法合规地使用，保证其使用范围可控，就显得极为重要。所以，需要对数据的整个生命周期进行管理和审计，把数据关在“盒子”里，保证数据在阳光下使用。 **工业互联网领域被视作数字经济时代的一座金矿，开展工业数据安全治理是否会影响工业企业的效率和效益？**   
孔令武：从长远角度而言，开展工业数据安全治理工作是提升工业企业生产效率和效益的前提条件。从工业2.0、工业3.0到如今的工业4.0，企业生产效率获得大幅提升，工艺流程获得改进，甚至带来生产组织方式和业态的根本性变革。通过数据的梳理分类、审计使用、关联分析，并通过建立数据中心、构建数据中台，为不同的场景提供有针对性的数据，有利于提升企业的管理效能，促成各个业务单位的协同生产，把数据变成了一座可供挖掘的“金矿”。当然，海量分散的数据集中化以后，无论是使用还是保护都需要数据治理作为保障。 **2016年成立至今，正是工业互联网快速发展的时期，珞安科技技术路线和技术理念先后经历了哪些变化？**   
孔令武：珞安科技是重点从事工业互联网安全业务的国家高新技术企业。成立六年来，与工业互联网的发展携手共进。成立之初，珞安科技主要专注于工业控制系统安全，并在2018年开始侧重于工业控制系统的网络业务安全。从2020年开始，聚焦工业互联网安全。从底层控制系统安全到业务层网络安全，再到上层的工业互联网平台安全，我们的业务范围随之向上延伸。  
从技术领域来看，珞安科技从最初侧重于协议安全、终端安全、行为安全，进一步延伸到边缘计算安全和设备安全，再到工业互联网平台安全，这其中就包括数据安全。珞安科技的技术路线是伴随国内工业领域的技术发展路线共同发展起来的，这也体现了网络安全的伴生性质。 **开展工业数据空间治理将对国内网络安全市场产生什么样的影响？ 珞安科技为此进行了哪些布局？**孔令武：开展工业数据安全空间治理，势必会对企业的数据价值化起到极大的推动和促进作用，将给数据分析、数据平台的业务带来大量的商业机会。在赋予数据价值的同时，其安全性的重要价值也体现出来，数据安全市场的投入势必会相应增加，对整个国内安全市场也将产生新的增量业务领域。  
珞安科技从成立之初高度重视自主研发，针对近年来工业数据安全发展的新形势，结合自身优势和特点，从云、边、端和平台分别做了超前布局。在端侧，主要针对工业数据的采集进行技术布局；在边缘侧，针对数据边缘计算、数据协议转换和数据分析做了相应的技术储备，而且已经在电网行业应用；在平台侧，对数据的态势感知、智能化应用，数据安全的智能化分析等领域也做了针对性的技术研发。技术牵引，有备无患，目前珞安科技的业务已覆盖电力、电网、石油、化工、轨道交通、智能制造等20多个工业领域，并结合市场需求不断迭代发展。 **随着信创产业的崛起，如何根植国产化产品来构建新的安全能力显得十分重要，珞安科技为此开展哪些方面的工作？**孔令武：在赋能信创产业方面，珞安科技始终走在行业前列，近些年的主要工作可以从三个层面进行总结：  
一是加强与国产化系统的适配，特别是与国产化操作系统和硬件平台的适配。国产的硬件平台方面，适配合作的厂商包括飞腾、鲲鹏、海光、兆芯等；国产操作系统方面，适配合作的厂商包括麒麟、统信、凝思等，这些主流的国产软硬件平台都做了适应性开发和兼容性测试。  
二是加强安全产品自身的国产化。工业互联网安全产品多为软硬一体的形态，自身也面临国产化的问题。在硬件方面，公司产品无论从硬件选型的芯片、内存、存储，到主板组件，再到整体产品，均不遗余力地实现国产化。在软件方面，从操作系统、基础软件、数据库的选型，再到工业防火墙、工控审计和工业互联网平台产品，都推出了相应的国产化型号和版本。  
三是国产化整体解决方案。随着国产化替代加速，不仅是工控安全产品面临着国产化，比如发电行业的DCS系统、油气行业的SCADA系统等工业控制系统自身，也都在稳步推进国产化替代。如何保障新建设的国产化工业控制系统的安全，珞安科技选择与相应的国产化系统供应商一起，做国产化工控系统的整体解决方案，让国产工控系统自带安全基因。  
虽然，现在大量的工业数据本身是不透明的，但工控设备、工控系统的厂商往往清楚企业会产生怎样的数据。数据治理就是把工控设备厂商、安全厂商以及工业互联网平台公司结合起来，携手利用数据来创造新的价值，实现工业、制造业领域弯道超车的目标，而不是始终跟在别人后面。  ![](../Images/0cec1c3a5e4cfe9af059302ea29f7c58.png)
