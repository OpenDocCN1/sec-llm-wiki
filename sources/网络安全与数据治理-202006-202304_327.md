【编者按】  

2021年，我国网络安全法律法规密集出台，监管力度不断强化。与此同时，国际国内网络勒索事件、数据安全事件频发。网络安全形势日益严峻的局面下，网络安全行业发展机遇与挑战并存，未来一年的发展趋势成为各界关注的重中之重。因此，本刊特组织“2021年网络安全行业发展回顾与展望”系列采访，邀请多家企业的资深专家对2021年网络安全政策进行解读，对爆发的网络安全大事件进行回顾，对行业发展的脉络进行剖析，并对2022年行业发展的趋势进行展望。

 

**本期受访嘉宾：江民科技首席执行官 聂永春**

**【观点提炼】**

// 无论是网络安全领域还是信息安全领域，永恒不变的话题是“技术创新”；

// 新兴技术日新月异，人工智能、量子计算等新技术在推动信息技术产业变革的同时，也存在被黑客利用的风险；

// 只要在技术上有足够的创新，团队工作高效有序，就有很大可能把困难点转化为机会点；

// 新技术的大规模应用让越来越多的数字资产和员工位于传统企业基础设施边界之外，安全厂商在技术、理念上需要不断创新，跑赢市面上攻击者技术的更新速度；

// 终端是发起攻击的源头，也是被攻击的末端。掌握好终端的正向资源，可以从整体上提升安全系数;

// 网络安全供应商的整合可能会是未来的发展方向；

// 2022年行业会进一步爆发，预计中国网络安全市场规模十四五期间将突破千亿级。

 

在聂永春看来，**2021年是网络安全行业一个机遇与挑战并存的新起点**：“回顾这一年，一方面全球网络安全形势依旧严峻，勒索攻击、数据泄露、APT攻击频率同比增长惊人，影响日益严重，危及关键基础设施。另一方面，随着网络安全法、等保2.0、数据安全法、关键基础信息设施安全保护条例、个人信息保护法等法律条例先后出台,网络安全的法律保障体系不断完善，网络安全越来越受重视，政府和企业对网络安全投入在信息化建设中的占比大幅提高，市场规模将持续扩大。”聂永春认为，**无论是网络安全领域还是信息安全领域，永恒不变的话题应该是技术领域的创新。“新兴技术日新月异，安全防护的边界正在超越 IT系统本身，安全产品的防御面正在持续扩大，攻击者的攻击手段都在与时俱进，人工智能、量子计算等新技术在推动信息技术产业变革的同时，也存在被黑客利用的风险。**攻守形势转换太快，不创新就会落后挨打，形势倒逼我们要比攻击者跑得快。”他解释道。

 

受新冠疫情影响，全球经济运行遭受一定冲击，后疫情时代，资本市场不确定性风险加强。聂永春坦言，其自身在2021年着实遇到了不小的挑战：“后疫情时代，很多行业不景气，预算紧张，受疫情影响部分既定项目延期交付，应收款无法到位，企业现金流相对紧张，在这种情况下，作为管理者既要考虑扩大销售业绩、提高市场占有率，同时还要让企业顺利运转，让员工保持积极性，给予他们稳定的薪酬，做到鱼和熊掌兼得。”谈及2021年最大的收获，聂永春认为是在相对艰苦的大环境下，公司团队历经磨砺变得更加紧密结合，上下一心，战斗力高昂。技术创新是企业核心竞争力建立的关键，团队协作则是一切事业成功的基础。据了解，**本年度江民科技业绩持续向好，整体业绩上涨80%**，“风险与机遇总是共存的，克服了风险就是机遇。**只要在技术上有足够的创新，团队工作高效有序，就有很大的可能把困难点转化为机会点。**”聂永春表示。他同时指出，**在看到机会点后再投入往往是来不及的，而是需要提前站在风口等风来**。“早在两三年前，我们就注意到了几个风口，包括反病毒企业在端点安全上的优势以及勒索病毒隐蔽、复杂、强劲的进化能力，提前布局了相应的产品线。终端是网络的神经末梢，处在网络安全防御的第一线。早在今年2月，江民科技董事长郭昌盛在接受《信息技术与网络安全》专访时就指出：“任何的攻击和入侵，最终都要落在终端上。终端是发起攻击的源头，也是被攻击的末端。掌握好终端的正向资源，可以从整体上提升安全系数。”聂永春告诉记者，**今年江民科技全新发布了信创环境下的杀毒软件、专门防御勒索病毒的“赤豹防勒索系统”，产品线更加完善，市场竞争力得到提升。**据了解，“信创杀毒软件”采用了江民自主研发的新一代反病毒引擎，拥有完全自主知识产权，源代码100%自主可控，具有超强平台兼容性和全面脱壳能力，可实现对已知及未知恶意软件的识别和快速响应；“赤豹防勒索系统”以江民在反病毒领域数十年的技术积累，融合了首创的“金钟罩”、“幽影诱捕”、“AI学习”、“溯源取证”等创新技术，可做到全面防御各类已知和未知的勒索病毒。“我们的产品获得了政府、军队、能源、金融等客户的广泛认可，这也从侧面印证了技术上的投入与创新是一个使业务实现逆势增长的“武器”。”聂永春总结。据悉，**江民科技在明年会继续发力终端安全领域，实现多产品融合化、功能简便化，研制防病毒EDR桌面管理及数据防泄漏（DLP）一体化的产品，对标国外先进技术，形成国内技术高点。**“明年我们依旧会拿出70%的营收作为研发的投入，**在深耕终端安全的同时配合国内各大厂商，让他们快速实现终端能力，以此构建整个终端安全生态，这是我们一个经营方向。**”他表示。

 

受疫情影响，远程办公、远程教育等线上生产生活方式发展迅速，网络用户快速增长，网络攻击事件同比增加。2020年，勒索病毒仍是最常见的威胁之一，严重影响网络安全、产业安全以及基础设施安全。**“大数据时代，勒索软件和网络攻击已成为数字世界的“新冠病毒”，且愈演愈烈。新技术的大规模应用让越来越多的数字资产和员工位于传统企业基础设施边界之外，安全厂商在技术、理念上都要不断创新，跑赢市面上攻击者技术的更新速度。”**聂永春指出。另外，从用户方维度来看，很多中大型企业CIO为了应对攻击，使用大量不同厂商的安全设备，导致安全操作复杂，运维人员数量、成本增加，效果却甚微。“个人认为，**未来几年网络安全供应商的整合或许是一个方向。**”他分析。

 

相比全球市场，我国网络安全市场虽然起步较晚，但是近年来在政策、法规、数字经济、市场需求等因素加持下，中国网络安全市场迎来高速发展期，增速领跑全球。“过去一年法规密集出台和落地，国家对于网络安全的重视可见一斑。**在带来更多合规压力的同时，也推动产业技术和规模快速升级，赛道竞争更激烈。2022年行业会进一步爆发，预计中国网络安全市场规模十四五期间将突破千亿级。**”聂永春在最后总结。
