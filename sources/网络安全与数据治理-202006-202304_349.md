# 中国电子：筑牢自主计算底座，为做强做优做大数字经济贡献力量！

近日，2021国际数字科技展暨天翼智能生态博览会在广州召开，天翼智能生态高峰论坛同期举行。中国电子董事长、党组书记芮晓武，副总经理、党组成员陈锡明参加活动。  
![](../Images/580537610ecd246ef61cb28c40b2fb13.png)  
在主论坛活动上，芮晓武围绕“构建安全先进绿色的计算底座”作主题演讲。  
芮晓武表示，数字时代，云植根于计算底座、专注于资源配置，支撑数字生态、提供共性服务，是基础设施的实现形式，也是信息活动的承载平台。依托于云，生长出了一大批以“虚拟化、移动化、容器化、微服务”为代表的数字化云应用，加速了网络空间与人类社会的深度融合。过去十年，中国电子通过自主创新，形成了安全先进绿色的PKS自主计算体系（P代表飞腾CPU，K代表麒麟操作系统，S代表安全防护链），为“PKS原生”云平台及所承载的各类应用提供牢固支撑。经过多年的探索实践，PKS体系已在政务、能源、金融等领域得到广泛应用，成为事实上的我国自主安全计算机信息系统的核心底座。未来，中国电子愿与中国电信一道，抢抓数字时代发展机遇，坚定自主创新，不断深化布局，整合双方优势资源，持续深化合作，共同推进中国电子 “坚底强链”战略与中国电信“云改数转”战略的有机融合，筑牢网络和信息安全底座，努力构建数字经济发展基石，为做强做优做大数字经济贡献力量。  
![](../Images/e382761a17624108bf705fff1a2cfb33.png)  

博览会期间，中国电子旗下成员企业中国长城、飞腾、麒麟软件、迈普、蓝信分别与中国电信旗下天翼云签署战略合作协议，携手推进网信领域创新合作，共建行业生态。

  

中国电子总工程师周进军，所属企业负责人参加活动。
