# 专访 l 姚羽:《关键信息基础设施安全保护条例》解读

《关键信息基础设施安全保护条例》颁布以来，引发产学研各界广泛关注。本刊对工业控制线系统信息安全技术国家工程实验室、网络安全企业、高校、研究院所专家进行了系列采访，就共同关心的问题开展解读。

  

本期受访者：

东北大学教授 姚羽

  

关键信息基础设施保护与等级保护有何关联与区别？

**01**

不论关键信息基础设施保护，还是等级保护都旨在建立信息安全保护制度，不过它们的侧重点不同，关键信息基础设施保护为了保障涉及国家安全、国计民生、公共利益的重要网络设施、信息系统的安全，而等级保护则是通过对信息和信息载体按照重要性等级分级别进行保护，包括定级、备案、安全建设和整改、信息安全等级测评、信息安全检查。可以说关键信息基础设施保护是等级保护的具体实践，而且是具备较高水平的实践，等级保护则为关键信息基础设施保护提供了具体操作方法和手段。因此相关单位应该在关键信息基础设施保护条例的指导下，对关键信息基础设施进行认定，参考等级保护相关条例的具体要求，对关键信息基础设施进行安全建设和安全测评等工作。

  

条例中为何指出国家要采取措施，优先保障能源、电信等关键信息基础设施安全运行？

**02**

习近平总书记曾指出：“金融、能源、电力、通信、交通等领域的关键信息基础设施是经济社会运行的神经中枢，是网络安全的重中之重，也是可能遭到重点攻击的目标。”，只有保障了能源、电信等关键信息基础设施的安全运行，才能从根本上保障国家安全、国计民生、公共利益。这些关键信息基础设施关系国计民生，其运营者通常是国有企业，需要国家采取措施，对网络安全事件应急处置与网络功能恢复提供电力供应、网络通信、交通运输等方面的重点保障和支持，优先保障这些关键信息基础设施的安全运行。

  

目前已经被列入关键信息基础设施的网络设施会不会随着数字化转型而动态调整？

**03**

向数字化转型已经成了政府和企业特别重视的一项变革行动，随着数字化进程的深入，关键信息基础设施的网络设施必然会随之动态调整。数字技术使得市场竞争更加激烈，2020年5月，国家发展改革委官网发布“数字化转型伙伴行动”倡议，提出政府和社会各界联合起来，共同构建“政府引导—平台赋能—龙头引领—机构支撑—多元服务”的联合推进机制，以带动中小微企业数字化转型为重点，形成“数字引领、抗击疫情、携手创新、普惠共赢”的数字化生态共同体，支撑经济高质量发展。适应中小微企业的数字化转型必然会有新的网络设施被列入关键信息基础设施，而原有的关键信息基础设施也会有所增减。

  

如何做到关键信息基础设施的供应链安全？关键信息基础设施认定对信创产业发展有何影响？

**04**

为了保障关键信息基础设施的供应链安全，首先要从政府层面在立法上规定我国关键信息基础设施供应链的安全审查基本制度架构，然后需要生产者，采购者，使用者，维护者四个角色围绕关键信息基础设施的各个环节展开安全保障，以确保供应链安全。

  

信创产业是数据安全、网络安全的基础，也是关键信息基础设施的重要支柱产业，与前述提到的四个角色息息相关，关键信息基础设施的认定必然会对信创产业发展起到导向性的作用，也决定着信创产业未来的发展发向和步伐。

  

条例明确禁止未经授权或批准的个人和组织不得对关键信息基础设施实施漏洞探测、渗透性测试等活动，那么对关键基础设施潜在漏洞的挖掘将采用何种方式或手段？

**05**

从关键信息基础设施的定义，我们知道，这类的设施一旦遭到破坏、丧失功能或者数据泄露，可能严重危害国家安全、国计民生、公共利益，因此条例明确禁止未经授权或批准对其实施漏洞探测、渗透性测试等活动。按照条例第十七条规定，运营者应当自行或者委托网络安全服务机构对关键信息基础设施每年至少进行一次网络安全检测和风险评估，对发现的安全问题及时整改，并按照保护工作部门要求报送情况。在对关键基础设施潜在漏洞的发掘过程中，应当注意信息资产的界定、一致性、动态管理等问题，同时不但要重视漏洞发掘，也要重视漏洞治理，制定一系列漏洞修复的相关机制，切实确保关键基础设施的安全。

  

条例的颁布为网安企业带来了哪些机遇与挑战？

**06**

条例第十九条“运营者应当优先采购安全可信的网络产品和服务；采购网络产品和服务可能影响国家安全的，应当按照国家网络安全规定通过安全审查。”。这些运营者都是能源、交通、水利、金融、公共服务、电子政务、国防科技工业等行业巨头，对于网安企业来说，他们为关键信息基础实施采购相关的网络产品和服务，意味着广阔的市场机遇和巨大的经济效益，但是因为运营者在优先采购安全可信的网络产品和服务之前，要预判该产品和服务投入使用后可能带来的国家安全风险，因此对于网安企业来说，存在着技术上的挑战，如何能让自身的网络产品和服务能够通过审查，并在同类产品和服务中成为其中的佼佼者，则是网安企业需要思考的。为确保关键信息基础设施供应链安全，国家出台了多个政策，包括《网络关键设备和网络安全专用产品目录(第一批)》、《网络安全审查办法》以及强制性国标GB40050-2021《网络关键设备安全通用要求》等，这些政策都是相关网安企业必须要遵循的，网安企业应该从增强产品开发能力出发，提高自身竞争力，才能积极应对条例带来的机遇与挑战。
