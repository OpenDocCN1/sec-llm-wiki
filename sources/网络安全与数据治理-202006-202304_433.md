# 两会聚焦车联网：新一代智能移动终端引关注

**车联网成为两会焦点议题**

  
  
汽车产业当前面临三个变革相交织的局面，传统能源向新能源变革、单车智能化向智能车联网变革、供应链从对外依赖向自主化变革。在刚刚结束的今年两会上，车联网引发热议，成为两会议案焦点。

**为何车联网突然成为两会关注焦点？**

**原因一**

随着全球气候治理问题的紧迫性超出预期，汽车产业新旧能源转换大幅提速，尤其在拜登政府上台后，气候治理难能可贵地成为目前在联合国范围内能够达成的少数国际共识之一。我国提出2030年前碳达峰和2060年前实现碳中和，汽车产业绿色转型与发展任务十分繁重，工信部2020年11月发布《新能源汽车产业发展规划（2021—2035年）》，瞄准“电动化、网联化、智能化”方向，推动汽车强国建设。其中明确“2025年我国新能源汽车销量要达到新车销售总量的20%左右，到2035年纯电动汽车将成为新销售车辆的主流”。今年《政府工作报告》已经将关注重点转向新能源汽车的配套服务领域。据统计，国内新能源汽车累计销量截至目前已超过550万辆，预计2021年将销售180万辆。增加换电站、充电桩等设施，加快建设动力电池回收利用体系等配套工作刻不容缓。需要注意的是，新能源汽车发展红利期与智能车联网发展交叉叠加，即意味着既要完成新旧动能转换，也要完成产业内在逻辑的转换，即绿色发展理念与产业数字化转型同步。

**原因二**

自住建部2012年发布《关于开展国家智慧城市试点工作的通知》以来，截至2020年4月，住建部公布的全国智慧城市试点数量已达290个，智慧城市建设进入纵深阶段。在无人驾驶和智能网联汽车技术突破的加持下，单车智能化向智能车联网转变，智能出行和智能物流将极大地改变人们的生活方式和城市业态，即所谓V2C（人车交互）、V2V（车车交互）向V2X（万物互联）的转变。为此，全国人大代表，广汽集团党委书记、董事长曾庆洪在两会上建议，要尽快完善现行交通安全法规，确认“机器驾驶人”的法律主体资格；加快自动驾驶相关技术标准的编制和发布；保障现有 “单车智能”技术路线的同时，更多支持 “车端智能 + 网联共享”相结合的技术路线，引导资本从基础消费领域转投智能网联等领域转向。从安全角度，智能车联网将几乎面临全谱系的现实网络安全威胁，为此，全国政协委员、360公司创始人周鸿祎建议，把网络安全系统像“安全带”一样列为智能汽车的标配，并将城市级网络安全基础设施作为智慧城市的标配。新冠肺炎疫情下，智慧城市通过数字孪生等技术，建设城市大脑，加强对人流、物流、空间的掌控已经成为共识。2021年1月4日、5日，上海、深圳分别发布了《关于全面推进上海城市数字化转型的意见》和《深圳市人民政府关于加快智慧城市和数字政府建设的若干意见》，深圳更是提出将打造具有深度学习能力的城市智能体。智能车联网在两会上被热议，脱离不开智慧城市的应用背景，某种程度上也预示着新型智慧城市建设的高潮即将来临。

**原因三**

供应链安全问题开始在全球汽车市场凸显。有数据预测，因芯片供给不足，2021年全球汽车制造商一季度将少销售100万辆汽车，全年预计损失610亿美元的营收。去年下半年国内汽车销售市场的率先反弹，更使得汽车芯片短缺雪上加霜，汽车芯片市场供需失衡问题变得越发严重。而在科技战背景下，防断供也成为国内车企广泛的关注。据腾讯网报道，中国汽车芯片目前自研率仅有10％，90％的芯片都必须依赖进口，荷兰恩智浦、日本瑞萨电子、德国英飞凌、意法半导体、德国博世、德州仪器等前十大供应商，掌控了全球车载半导体市场的80％以上的市场份额。虽然这一轮汽车“芯片荒”主要是疫情下供需失衡导致的，但却不得不让人警惕“卡脖子”的供应链风险问题。全国人大代表、上汽集团党委书记、董事长陈虹建议加大对车规级芯片行业的扶持力度，使整车和零部件企业“愿意用、敢于用、主动用”。奇瑞汽车股份有限公司党委书记、董事长尹同跃建议，制定国产车载芯片技术路线发展纲要，成立芯片创新发展平台，并强化产业生态融合。车规级与消费级芯片在架构、设计、工艺、材料等方面都有很大不同，面对个人移动终端市场的前车之鉴，不得不让人对新一代智能移动终端-车联网顿起未雨绸缪之心，越早建立具有韧性的汽车芯片供应链自主能力，越能保障国内汽车行业的永续发展。
