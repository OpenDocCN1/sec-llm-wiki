# 电子六所盛大出席“2020年工业互联网安全成果展”

2020年11月4-6日，2020年工业互联网安全成果展在南京国际博览中心举行。电子六所作为工业互联网安全领域的重点企业应邀参展。

![](../Images/5bd09149143ba95d3e4b5f466eed5f63.png)

**工业互联网安全成果展电子六所展位**

以“**牢记网络强国使命，打造网信核心竞争力**”主题，电子六所携近年在工控安全、网络安全、智能制造、信息服务等领域改革发展成果精彩亮相。作为曾研制出具有极高商誉的我国第一台微型计算机长城0520B、第一套汉字操作系统CCDOS和第一套分布式控制系统、火电站/核电站监控系统的国家工业控制领域的重点研究院所，电子六所工控与网络安全成果广泛地应用于我国金融、轨道交通、电力电网、核工业、石油化工、水利工程等行业。  

![](../Images/748707b289bf8730e3d3b3ca6f436915.png)

**工业和信息化部党组成员、副部长刘烈宏**

**参观指导工作**

“电子六所紧密围绕国家工业控制安全战略需求，围绕关键信息基础设施保护、深度安全防护、自主核心产品、安全训练平台等方面，构建多层次、自主化的工业安全保障体系，实现工业控制系统‘**可发现、可防范、可替代、可验证**’的安全目标。”所长张尼向各级领导介绍。

![](../Images/066dadc11ea9493697595601a15784aa.png)

**电子六所所长张尼向工业和信息化部党组成员、****副部长刘烈宏介绍展品**  
自2014年起，电子六所历时三年打造了满足工业控制安全需求的PLC产品—超御N系列PLC，产品性能指标对标国际先进产品，可靠性指标符合国家标准，可实现对全系列国外PLC产品的原位功能替代，其关键技术创国内工业互联网安全之先河，填补了国内空白，完美阐释“打造网信核心竞争力”的内涵。

  

  

  **独行速，众行远。**

  

**依托工业控制系统信息安全技术国家工程实验室，电子六所与10家行业企业成立联合实验室，拥有147家理事单位和174名技术专家委员**，全面布局电力、核电、石油石化、轨道交通、先进智能制造等重点产业，已经成为我国工业控制系统及信息安全领域的重要支撑力量，为数字中国建设做出新的贡献。

  

同时，**将工业互联网安全建立在基础软硬件生态之上，实现本质安全、过程安全、产业安全的完美统一。**基于“**PK体系**”全国产软硬件生态，融合可信、可管、可控、可测多元安全能力（S），不断拓展“**PKS体系**”的内涵和外延，全方位提升国家关键信息基础设施网络安全防护能力。

  

在工控信息安全人才培养方面，电子六所承担了人力和社会资源保障部的“**工控信息安全培训**”项目，先后为行业内领军企业培训了数量可观的工控安全运维人员，有力地支撑了工业互联网安全行业的快速发展。

  

**2020年工业互联网成果展是由中国信息通信研究院、工业互联网产业联盟和中国互联网协会共同主办的行业盛会，重点围绕工业互联网等新型基础设施建设领域，突出大数据、人工智能、5G等新技术在工业互联网安全领域的应用实践，促进汽车、航空航天、石油化工、机械制造、轻工家电等典型行业领域安全体系建设。**
