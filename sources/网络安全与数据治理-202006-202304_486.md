# 第三届“信网杯”正式启动!

为贯彻新发展理念，实现经济高质量发展，中央今年提出“[新基建](http://www.chinaaet.com/tags/%E6%96%B0%E5%9F%BA%E5%BB%BA)”重要战略举措。作为名副其实的“新基建”，[信创产业](http://www.chinaaet.com/tags/%E4%BF%A1%E5%88%9B%E4%BA%A7%E4%B8%9A)已经成为国家经济数字化转型、完善产业链发展的关键，也是当下国家经济转型发展的新动能。2020年是信创产业全面发展的新起点，未来三到五年，信创产业将迎来黄金发展期。作为涵盖从IT底层基础软硬件到上层应用软件的全产业链技术创新领域，信息技术创新应用从技术体系、基础能力、产业生态等全方位着手，带动传统信息产业转型，勾画新时代数字中国的蓝图。第三届“信网杯”聚焦“新基建”和“信息技术创新应用”的主题，开展优秀科技论文征集评选活动，希望展现信创产业实践与理论成果，加速经济社会的数字化转型，不断满足人民群众对美好生活日益增长的需求，共同服务国家战略和经济社会发展。

**********征文主题>>**********

**信息技术创新应用赋能“新基建”**

************征文范围>>************

1.**基础硬件技术研究**：CPU/GPU芯片、固件、存储、服务器、PC、交换芯片等；

2.**基础软件技术研究**：操作系统、数据库、中间件、防病毒软件、主机安全防护等；

3.**应用软件技术研究**：OA、ERP、办公软件、财务软件、政务软件等；

4.**网络安全技术研究**：边界安全、入侵检测与防御、应用安全网关、安全隔离与信息交换等；

5.信创产品在5G 基站建设、大数据中心、人工智能、工业互联网、特高压、城际交通等新基建领域应用的**整体解决方案**。**********征文要求>>**********
