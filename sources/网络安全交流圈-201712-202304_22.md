# 一次失败的内网渗透

客户给了WEB地址，我们打了一会发现自己打不进去，没找到大的漏洞（本人比较菜），于是我用漏洞扫描工具扫了一下，NESSUS报端口有java反序列化，使用反序列化工具进行利用。但是服务器好像有问题，刚开始还无法利用，会报错，但是在本菜鸟坚持不懈的点击获取信息下，服务器心动了，给了我回应，i了i了。  

  

![](../Images/cf4410e57a82d18a328cbcbd603fa017.png)

  

执行命令获取system权限

  

![](../Images/fa9eb45ef3163a49ec23c351f85e7f8c.png)

  

开启kali来接收反弹shell。  

  

![](../Images/d0eff589bcc650988aef7f8ff289e37c.png)

  

反弹shell，该服务器上有防护软件，但是不知道为什么执行成功了，本来还打算用另外的方式（省略）。

 

反弹成功之后我创建了一个账户并加入了管理员组，进行远程登陆。

  

![](../Images/3bf5a6963421476a2198d2dd337e023b.png)

  

登陆成功。

 

登陆服务器发现是windows server 2008，随后给安全软件（某信）加了一个白名单文件夹，接下来就是传mimikatz获取明文密码。

 

![](../Images/9ec451436d18b295e5d199710ea974c4.png)

  

  

获取到密码之后，在本次测试的其他服务器进行远程登陆，有几个服务器密码错误，接下来就挺简单了，因为内网菜，我们就只能寻找配置文件，希望里面有其他（数据库，FTP等密码），找了好一会，搜索conf文件等，在一台服务器上寻找到了一个java的配置文件，里面包含oracle数据库的账号和密码，使用Navicat进行连接。

 

![](../Images/a0a7be5f3c21a39ba07905acca6bc188.png)

连接成功，另外几台也连接成功。

 

DSHELL进行命令执行，但是会一直卡死，然后使用了其他办法但是因为很麻烦，就找大大大大大大佬，大大大大大大佬给了我一个工具，有一说一，工具真给力，身为脚本小子的我可太爱了。

![](../Images/25df67ecbca08388f513738f715a6003.png)

接下来就不用说了，直接执行命令反弹shell或者创建超级管理员即可，因为一般貌似数据库权限都是管理员开启的，所以执行命令就很简单，不必要为了权限而烦恼，真好。

![](../Images/ba09088fdcd67fa42e6fd03f72bc12b6.png)

  

  

大佬的软件对我这个小白真的太有好了。

  

![](../Images/fea3cd1fd277f1d0e5ab6460609f2115.png)

  

  

登录成功。   

 

有个问题就是该服务器为server 2012，把hash导出之后无法解析，因为我也属于管理员组，无法破解我就在想是不是权限的原因，之后我把软件放在了别的盘符，然后又使用数据库进行命令执行来提取hash值，但是同样的结果。然后想到了CS上线，我把生成的shellcode加白了却没办法运行，直接会杀死，就很奇怪，然后我想关闭他们的杀软，因为总感觉是杀软的原因（他们服务器两个杀软，某电脑管家和某信），但是没想到关闭它，还得要密码，吐了。然后打算饶过一下，但是因为节日的原因，心早都放飞了，也就草草结束了，准备节后找一个server 2012在重新试一下。
