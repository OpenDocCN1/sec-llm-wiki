# AD域信息收集小工具分享

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1MDk3NDc5Mg==&mid=2247484113&idx=1&sn=fc2dfd3b7c61648a76917f56fcfb48d6&chksm=e9fb45f6de8ccce0ffce6320af0c8a10aa28e0d9908b65d62cc6b1d01cff3c203b8fd2b5b02a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1MDk3NDc5Mg==&mid=2247484113&idx=1&sn=fc2dfd3b7c61648a76917f56fcfb48d6&chksm=e9fb45f6de8ccce0ffce6320af0c8a10aa28e0d9908b65d62cc6b1d01cff3c203b8fd2b5b02a&scene=27#wechat_redirect)

介绍一款国外的工具，ADCollector 是一种轻量级工具，可枚举 Active Directory 环境以识别可能的攻击媒介。它将让您对环境的配置/部署有一个基本的了解作为起点。

  

**枚举**

*   当前域/林信息
    
*   当前林中的域（带有域 SID）
    
*   当前域中的域控制器 \[GC/RODC\]（带有 ~~IP、OS Site 和 ~~Roles）
    
*   域/林信任以及受信任的域对象\[SID 过滤状态\]
    
*   特权用户（目前在 DA 和 EA 组中）
    
*   无约束委派账户（不包括DC）
    
*   约束委派（S4U2Self、S4U2Proxy、基于资源的约束委派）
    
*   MSSQL/Exchange/RDP/PS 远程 SPN 帐户
    
*   设置了 SPN 和密码的用户帐户不会过期
    
*   机密属性 ()
    
*   ASREQROAST（DontRequirePreAuth 帐户）
    
*   AdminSDHolder 保护帐户
    
*   域属性（MAQ、minPwdLength、maxPwdAge lockoutThreshold、gpLink\[链接到当前域对象的组策略\]）
    
*   LDAP 基本信息（支持的 LDAP 版本、支持的 SASLM 机制、域/森林/DC 功能）
    
*   Kerberos 策略
    
*   域对象上的有趣 ACL，解析 GUID（未来用户定义的对象）
    
*   不寻常的 DCSync 帐户
    
*   GPO 上有趣的 ACL
    
*   关于用户对象的有趣描述
    
*   敏感且非委托账户
    
*   SYSVOL/Cache 中的组策略首选项密码
    
*   当前用户/计算机上的有效 GPO
    
*   受限群体
    
*   嵌套组成员资格
