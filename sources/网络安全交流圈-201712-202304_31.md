一、Exchange 2013 安装准备

![](../Images/7ddc297b6158a08533c7707acd3dfe1e.png)

  

  

1.1 下载并安装.NET Framework 4.7.2

下载地址：https://download.microsoft.com/download/6/E/4/6E48E8AB-DC00-419E-9704-06DD46E5F81D/NDP472-KB4054530-x86-x64-AllOS-ENU.exe

  

安装完成要重新启动一下  

  

![](../Images/f848e5a29866bd9b680d41ed877078ce.png)

  

1.2 在PowerShell上安装远程工具管理包

Install-WindowsFeature RSAT-ADDS

![](../Images/ad0049612ff9850b7f5e051f8bf26303.png)

  

1.3 在PowerShell上安装必需的 Windows 组件

Install-WindowsFeature AS-HTTP-Activation, Desktop-Experience, NET-Framework-45-Features, RPC-over-HTTP-proxy, RSAT-Clustering, RSAT-Clustering-CmdInterface, RSAT-Clustering-Mgmt, RSAT-Clustering-PowerShell, Web-Mgmt-Console, WAS-Process-Model, Web-Asp-Net45, Web-Basic-Auth, Web-Client-Auth, Web-Digest-Auth, Web-Dir-Browsing, Web-Dyn-Compression, Web-Http-Errors, Web-Http-Logging, Web-Http-Redirect, Web-Http-Tracing, Web-ISAPI-Ext, Web-ISAPI-Filter, Web-Lgcy-Mgmt-Console, Web-Metabase, Web-Mgmt-Console, Web-Mgmt-Service, Web-Net-Ext45, Web-Request-Monitor, Web-Server, Web-Stat-Compression, Web-Static-Content, Web-Windows-Auth, Web-WMI, Windows-Identity-Foundation, RSAT-ADDS

  

安装完成要重新启动一下

  

![](../Images/c00fa75985462c629595393232cf5e0e.png)

  

1.4 下载并安装Microsoft Unified Communications Managed API 4.0 Core Runtime（64 位）

下载链接：https://download.microsoft.com/download/2/C/4/2C47A5C1-A1F3-4843-B9FE-84C0032C61EC/UcmaRuntimeSetup.exe  

  

![](../Images/511eda44c45e282096305d7f23718c76.png)

  

1.5 下载并安装Visual C++ Redistributable for Visual Studio 2012 Update 4

  

下载链接：https://download.microsoft.com/download/9/C/D/9CD480DC-0301-41B0-AAAB-FE9AC1F60237/VSU4/vcredist\_x64.exe

  

![](../Images/3c959e8c6bf0d4638198b2ddc0ce0e63.png)

  

1.6 下载并安装Visual C++ Redistributable Packages for Visual Studio 2013

  

下载链接：https://download.microsoft.com/download/F/3/5/F3500770-8A08-488E-94B6-17A1E1DD526F/vcredist\_x64.exe

  

![](../Images/e5179502118612236a90b35c33facc33.png)
