（二）、利用MSSQL-CLR梭哈

CLR 即公共语言运行库

SQL CLR (SQL Common Language Runtime) 是自 SQL Server 2005 才出现的新功能，它将.NET Framework中的程序注入到 SQL Server 的对象存储中，让 SQL Server 的部分数据库对象可以使用 .NET Framework 的编程语言开发（只支持VB.NET和C#）

利用流程

dll文件(含有执行shellcode的各功能函数)-->HEX编码-->CLR方式导入HEX编码的dll-->执行导入对象dll中的函数-->CS直接上线
