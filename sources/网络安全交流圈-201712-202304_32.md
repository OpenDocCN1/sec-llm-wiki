3、采用type\_name函数爆出数据库版本信息，这里为MSSQL2008。类似这种可以用来报错的函数很多，主要是利用了MSSQL注入中变量类型不一致的转换来报错，type\_name()函数默认接受int类型的变量，如果接受了string类型就会报错，这里总结如下：

（二）、利用MSSQL-CLR梭哈

CLR 即公共语言运行库

SQL CLR (SQL Common Language Runtime) 是自 SQL Server 2005 才出现的新功能，它将.NET Framework中的程序注入到 SQL Server 的对象存储中，让 SQL Server 的部分数据库对象可以使用 .NET Framework 的编程语言开发（只支持VB.NET和C#）

利用流程

dll文件(含有执行shellcode的各功能函数)-->HEX编码-->CLR方式导入HEX编码的dll-->执行导入对象dll中的函数-->CS直接上线

程序打包

以下涉及到的程序，请返回知识星球另一篇主题文章中下载

1、有了上面的利用流程，首先我们需要来编写DLL文件，C#中采用APC注入的方式来启动notepad.exe，shellcode加载方式采用bin格式转base64远程加载，dll的.net版本这个需要根据目标系统来选择，SQLSERVER2008 采用.net2.0编译，SQLSERVER2012采用.net 3.5 编译，SQLSERVER2016采用.net4.0编译。源码中的load\_base64函数直接加载CS生成的bin格式转base64的shellcode，Loadhttp函数远程加载WEB中保存的base64数据文件。
