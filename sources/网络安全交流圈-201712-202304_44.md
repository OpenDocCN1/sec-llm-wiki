# Lanproxy 任意文件读取漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1MDk3NDc5Mg==&mid=2247483893&idx=1&sn=beda34e8137e39bd7030eca4048eb16c&chksm=e9fb46d2de8ccfc41cfde3c85c6644b444b91554cb52b9c346516264d45d2745dc7741e6c369&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1MDk3NDc5Mg==&mid=2247483893&idx=1&sn=beda34e8137e39bd7030eca4048eb16c&chksm=e9fb46d2de8ccfc41cfde3c85c6644b444b91554cb52b9c346516264d45d2745dc7741e6c369&scene=27#wechat_redirect)

漏洞描述：

Lanproxy是一个将局域网个人电脑、服务器代理到公网的内网穿透工具，支持tcp流量转发，可支持任何tcp上层协议（访问内网网站、本地支付接口调试、ssh访问、远程桌面等等）本次Lanproxy路径遍历漏洞(CVE-

2021-3019)通过../绕过读取任意文件。该漏洞允许目录遍历读取/../conf/config.properties来获取到内部网连接的凭据。  

  

过程如下：

  

通过关键词Lanproxy找到漏洞站点

  

![](../Images/8034a57e91970cdd6997cd6914508e2e.png)

  

```

/../conf/config.properties  # 获取配置文件
```
