# 春节期间十大科技新闻回顾

       今年春节科技圈一点也没有闲着，大事小事接连发生，无论是国内还是国外，几乎天天都有重要的消息传出。今年是节后上班第一天，让我们迅速来回顾一下在这个中国人举国同庆的新春佳节里，究竟科技圈都发生了一些什么事情？

**一、联想29亿美元收购谷歌(微博)旗下摩托罗拉移动**

       1月30日，联想宣布和谷歌达成交易，以29亿美元收购摩托罗拉移动业务。根据协议，联想将获得摩托罗拉品牌、Moto X 和Moto G以及DROIDTM超级系列产品等智能手机产品组合以及2000项专利。需要说明的是，谷歌在收购摩托罗拉移动时，曾获得后者的1.7万个全球专利。联想未收购的1.5万个专利将作为其与谷歌长期合作关系的一部分，以授权许可证的形式使用。

       收购摩托罗拉移动有益于联想缩短其与苹果和三星在智能手机市场的份额差距，并能填补其全球市场的空白，提升联想产品研发能力，补充专利技术。而谷歌之所以选择出售，一是该业务财务表现不佳，二是平衡安卓阵营的生态，在收购摩托罗拉手机硬件业务后，谷歌一直面临如何处理自身业务和其他安卓厂商之间关系的难题。

**二、微软CEO终于出炉**

       鲍尔默去年宣布辞去CEO之职以后，微软下一任CEO人选一直没有定论。2月4日晚间，微软宣布将由萨提亚•纳德拉（Satya- Nadella）担任该公司新任CEO，这位1992年加入微软的印度裔高管也成为微软继比尔•盖茨和鲍尔默之后的第三任CEO，他此前担任微软云计算和企业部门执行副总裁。

       微软还宣布，比尔•盖茨将不再担任董事长，由前赛门铁克CEO约翰•汤普森（John Thompson）接任。同时在新任CEO纳德拉的要求下，盖茨将以技术顾问的新身份在董事会中任职，并将用更多的时间为公司提供技术和产品方面的咨询。

       作为微软云技术出身的纳德拉来说，未来如何发展好微软在消费者层面的业务将是其需要考虑的问题。但其很难改变此前盖茨和鲍尔默的既定路线，改革空间有限，未来其与盖茨的关系也很微妙。

**三、京东提交了上市申请书**

       过去一年里，京东上市的传言不断流出，终于在2014年初的除夕之夜得到了验证。京东当天向SEC递交了招股说明书，计划在美上市，融资规模将在15亿美元左右。

       招股书显示，京东2011年、2012年净营收分别为211.3亿元、413.8亿元，净亏损分别为12.84亿元、17.29亿元。

       京东2013年前三季度净营收492.16亿元，较上年度同期的288.07亿元上涨70%。前三季度，京东实现盈利6000万元，净利率为0.1%.

       不过，京东在2013年前三季度主营B2C业务亏损3.61亿元。京东的盈利主要依靠利息收入、政府退税等其他收入。

**四、索尼将出售PC业务**

       索尼公司在2月6日发布2013年财年第三财季业绩时宣布，将把PC业务和VAIO品牌出售给日本投资基金Japan IndustrialPartners(JIP)，目前正处于尽职调查阶段，最终协议将于2014年3月签署。该公司还将调整电视业务，在2014年6月前将其分拆为独立实体。

       索尼表示，将不再设计和开发PC产品，而最后一批VAIO产品在全球发布后，其生产和销售工作也将停止。该公司决定重点开发“后PC”时代的各种产品，包括智能手机和平板电脑。

       索尼2013财年第三财季移动业务营收实现同比增长，但该公司仍然预计全年亏损1100亿日元(约合11亿美元)，他们此前预计全年盈利300亿日元。之所以出现这一疲软业绩，主要是因为该公司正在努力调整的各项业务所致。

       索尼公司今天还宣布下调2013财年业绩预期，净利润由此前的盈利300亿日元（约合人民币17.8亿元）下调至亏损1100亿日元。

**五、Facebook靓丽业绩庆祝十周年**

       Facebook春节前公布的第四季度财报显示，其营收同比增长63%，净利润增长大于7倍，这一结果远远高于市场预期，Facebook财报公布以后，股价大涨。

       2013年第三季度，Facebook移动广告在营收总额中所占比重为49%，第二季度和第一季度的比重分别为41%和30%。现在，53%的营收来自移动广告。在财报发布后的电话会议上，Facebook表示这是该公司季度移动广告营收第一次突破10亿美元大关，而且当季度移动广告营收几乎相当于上年同期移动和桌面广告营收的总和。

       而这一份漂亮的财报着实为其2月4日的十周年庆祝添上了一笔靓丽的色彩。Facebook在经历超级明星般的高调IPO后，沉沉浮浮，终于在这十周年之际得意收获一份肯定。

       此外，在春节期间，Facebook还发布了一款新的新闻阅读应用Paper，将大量社交信息荣誉新闻阅读其中，是不同于Flipboard等产品的一种全新阅读体验。

**六、微信红包“火”遍春节**

       数据显示，从除夕到大年初一下午16点，参与抢红包的用户超过500万，总计抢到红包7500万次以上，领取到的红包总计超过2000万个，平均每分钟有9412个红包被领取。

       为什么微信红包会一夜之间红遍大江南北？首先微信抢红包的功能设计简单好用，再者微信非常恰当地利用了其庞大的熟人网络，是的用户参与度大大提高。

       微信抢红包除了提高微信活跃度意外，最重要的是引爆了微信支付。在增加支付功能，绑定了用户银行卡之后，微信具有了变现的能力。

**七、Twitter上市后首份财报糟糕**

       Twitter2月6日发布去年11月份上市后首个季度财报，其中用户增长幅度和活跃度出现下滑成为财报最大问题。

       财报数据显示，Twitter月平均活跃用户为2.41亿，较去年同期增长30%。但在上季度，该增长率是39%。

       第四季度营收为2.43亿美元，同比增长116%。净亏损达到5.11亿美元，去年同期则为870万美元。该亏损幅度超出了分析师此前预计的2.5亿美元。

       早在财报发布前，投资人对于此次财报的表现就极为关注。因为，自Twitter上市后，其股价相较于26美元的发行价早已翻了一番，且最高值曾达到74.73美元。Twitter的营收能力是否能支撑该估值？这是市场普遍关心的问题。

       从最新的财报成绩来看，Twitter并未给出让人对其未来增长潜力更有信心的答案。当天的盘后交易，Twitter股价大跌近17%。

**八、雅虎重启搜索**

       雅虎内部的多位消息人士透露，雅虎CEO玛丽莎•梅耶尔已经悄悄启动了两个项目，搜索算法和搜索广告业务，目的是尽快结束与微软的搜索业务合作，让雅虎重返搜索界。

       这项计划的其中一个目的就是加快结束与微软的搜索和广告长期合作。目前，雅虎只拥有对搜索体验的控制权，但梅耶尔希望对这项业务有更大的管理范围。

       梅耶尔希望在三到四个月的时间里，建立起完整的搜索引擎，而且可能更加重视移动，而不是过去雅虎曾占据重要地位的桌面搜索。

       互联网流量统计机构comScore的最新数据显示，去年12月，雅虎在美国搜索市场的份额已经下滑到10.8%，比上个月下降0.4%。与此同时，谷歌(微博)的市场份额增长到67.3%，微软份额为18.2%。

       而雅虎在最近的一份监管文件中披露，31%的营收来自于这份搜索协议，远高于过去投资者的预期。

**九、苏宁国美(微博)获得第二批虚拟运营商牌照**

       1月30日，工信部向8家民营企业发放第二批虚拟运营商牌照，其中，首批无缘入选的苏宁云商和国美电器(微博)此次如愿获牌。其他6家企业分别是：爱施德、厦门三五互联、苏州蜗牛数字、中期集团、长江时代通信、远特（北京）通信技术有限公司。

**十、麦考林被收购**

       1月30日，麦考林公告称，位于南京的商圈网以3900万美元价格收购了麦考林63.7%股份。商圈网是南京宏图三胞集团参股控制的一家企业。如果交易完成，那么意味着麦考林控制权将转移。预计这一收购和出售交易将于2014年第二季度完成。
