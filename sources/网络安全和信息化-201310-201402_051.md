# 法庭推翻“网络中立”：坏事但并非完全糟糕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=10013385&idx=2&sn=1b2819a6bc27bde029115feece774266&chksm=23f543d51482cac37f353d08ad1233137d5ff34473af2f346b056b8b128e382f45d6e650d78e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=10013385&idx=2&sn=1b2819a6bc27bde029115feece774266&chksm=23f543d51482cac37f353d08ad1233137d5ff34473af2f346b056b8b128e382f45d6e650d78e&scene=27#wechat_redirect)

       互联网的未来变得暗淡：一个华盛顿特区的上诉法庭在周二裁定Verizon胜诉，推翻联邦通信委员会（FCC）颇具争议的“网络中立”规定。这个裁定可能为互联网服务提供商打开一扇门，让他们因提供更快的网络连接，对网站和其他内容提供商进行收费。

       法庭在裁定中写道：“由于FCC未能证明，这项反歧视、反封锁规定本身并没有施加普遍的运营商义务，因而我们裁定撤销《开放互联网法令》（Open Internet Order）这部分规定。”

       实际上，其意思是法庭并不认为互联网服务提供商具有普遍义务——手机公司必须允许任何类型的流量在他们的网络上存在。这个裁定对于Verzion等互联网服务提供商来说是好事情，该公司认为自己有权决定如何支配其宽带。对于内容提供商，这意味着互联网运动场可能不再处于同一水平面——如果时代华纳有线希望向使用HBO Go的客户提供优质服务，不过同时也希望放缓Netflix用户的速度，该公司现在可以这样做而无需顾忌FCC的处罚。对于美国人来说，这个裁决可能导致需要支付更多资金，才能获得跟以前不变的服务，因为内容提供商将成本转嫁给用户；此外也可能面临网络上的自由言论被扼杀——至少这是一个担心的地方。

       互联网权利团体Free Press总裁兼首席执行官克雷格·阿隆（Craig Aaron）表示：“我们对于法庭达成这样的裁定感到失望。这个裁定意味着，互联网用户将与最大的手机和有线电视公司对抗，并且对此不存在任何监管，这些公司现在可以随意封锁和歧视客户的通讯。”

       尽管网络中立支持者感到失望，这个裁决对他们来说也非巨大失败。法庭可能撤销FCC《开放互联网法令》的部分规定，不过也再次确认FCC对于监管宽带的权力。

       消费者权利倡议团体Public Knowledge高级副总裁哈罗德·菲尔德（Harold Feld）表示：“当然，我们对于今天的裁定感到失望。法庭夺走了重要的FCC灵活性，其意见可能使FCC的努力变得白费。但是，法庭也认为FCC有权监管宽带。如果要执行这种权力，FCC必须打破那些不符合全面成熟的运营商规则的互联网保护。”

       换言之，FCC尝试施加的规则被撤销了。不过由于法庭确认其有权监管宽带，因而该机构现在可以重新修订其开放互联网规定，从长期看这点可以加强网络中立规定。

       互联网行业倡议团体美国宽带（Broadband for America）表示，法庭的裁定并没有改变其成员对开放互联网的承诺。

       该团体在一份声明中表示：“我们以开放为基础打造我们的互联网服务。今天的裁定并没有改变这个承诺。我们深信开放互联网，我们的客户有权随时随地访问所有合法的网站和信息。”

       当然，斗争还没有结束。FCC董事长托马斯·维勒承诺努力确保互联网继续保持开放并使内容、服务提供商与消费者处于同一水平线，有可能会对周二的裁定进行上诉。

       维勒在一份声明里表示：“我致力于维持我们的网络作为经济增长的引擎，作为创新服务和产品的试验台，以及作为各种受第一修正案保护的所有言论形式的表达渠道。我们将考虑所有可选方案，包括进行上述，以确保着这些网络继续为创新和意见表达提供开放和免费的平台，并且其运作符合所有美国人的利益。”
