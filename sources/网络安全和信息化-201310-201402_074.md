# 【热点】展望2014年云和虚拟化发展趋势

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5MzMwMDU5NQ==&appmsgid=10013206&itemidx=1&sign=fa40c5f457c0b8669b72f016241dcc00&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5MzMwMDU5NQ==&appmsgid=10013206&itemidx=1&sign=fa40c5f457c0b8669b72f016241dcc00&scene=27#wechat_redirect)

       2013年，Kusnetzky Group的分析师采访了超过300家从事虚拟化、云计算相关产品和服务的公司，从中总结出了2013年这两个领域的特点，并作出了一些预测：

　　桌面计算不再是传统PC和笔记本电脑的专利，桌面虚拟化同样能够做到。桌面虚拟化虽然并不适合所有的桌面计算负载，但是对大多数负载来说，它能够提供更高的安全水平，降低管理成本、运营成本、硬件成本和能耗成本。思杰、思科、戴尔、惠普、IBM、微软、红帽、VMware等很多厂商都在提供桌面虚拟化的产品。

　　桌面即服务更加受到关注，更多的企业愿意部署BYOD策略，得以更加灵活的办公，并更好地实施桌面设备的管控。

　　基于早期Windows环境的开发，比如WindowsXP和Windows Server 2003，能够运行在虚拟化环境中，这让企业能够继续使用早期的开发环境，或者支持早期的产品，能有足够的时间去进行迁移或替换。目前AppZero、思杰、微软和VMware都在提供这类产品。

　　企业正在认识到虚拟机软件并不能解决所有的问题，而其他形式的虚拟处理软件，比如操作系统虚拟化和分区要更有效率。惠普、IBM、Parallels等公司在提供这类产品。此外，企业更加重视数据的灵活性，采用flash或DRAM缓存能够增加存储性能并降低存储成本。戴尔、EMC、Fusion-IO、HDS和NetApp等公司都在寻求更好的方法来存储数据。

　　云平台的竞争会愈演愈烈，尽管CloudStack和OpenStack被更广泛的接受，但云计算市场最大的赢家还将是将Amazon及其合作伙伴。

　　2014年，在云计算的IaaS层面，IaaS的访问控制将会进步。IaaS主要根据用户的需求提供计算资源，但目前云服务器提供的计费方式还不够灵活。更灵活的计费方法是一个发展方向，比如根据组织的架构来计费，能够让IaaS更适用于不同组织的用户。第二个方向是虚拟机类型的多样性，用户更希望自定义虚拟机的CPU内核和内存等参数，而不是预先设定的特定组合。

　　在SaaS方面，2013年已经有了很多成功的SaaS提供商，比如SalesForce，通过这些SaaS服务商，用户不需要再购买软件，通过Web即可获得服务。在2014年，这种趋势还会增强，更多的企业级软件会被放到云上，因为SaaS简化了软件分发的供应链，并且让软件变得和平台无关。
