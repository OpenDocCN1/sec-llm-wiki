# 【视点•VMware】DaaS时代终于来临？

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5MzMwMDU5NQ==&appmsgid=10012167&itemidx=3&sign=822012867b08d8aab9697cb623ec9476&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5MzMwMDU5NQ==&appmsgid=10012167&itemidx=3&sign=822012867b08d8aab9697cb623ec9476&scene=27#wechat_redirect)

    虚拟桌面即将帮助企业摆脱其目前的桌面基础设施？尽管池化桌面映像，集中存储库，基于云的服务的所有优势被一再宣传，甚至是移动客户端访问即将带来，很多组织仍然固执地坚持老旧的做事方式，使用“昂贵的、低效的”传统桌面。

　　最新的消息来自于VMware，该公司最近收购了桌面即服务(DaaS)的先驱Desktone，着眼于将Desktone平台整合到自己的Horizon View系统。虽然细节仍不清晰，大体上Desktone将作为服务提供商端的一个多租户架构，而Horizon将保留其企业端解决方案的地位。通过整合这两者到总体的云基础设施(vSphere)之中，VMware希望企业很快将考察桌面即服务的实现，无论是在公共云、私有云或混合云上。

    这将很好地适合VMware的整体云战略，即把几乎所有的企业运营都放在一个使用广泛的商品硬件的虚拟基础平台之上。随着Desktone的收购，该公司已宣布了一批新的自动化和管理系统，旨在促进全透明的内部和第三方的服务架构之间的互操作性。随着按需访问任何数量的应用程序和服务，企业将最终能够摆脱数据基础设施的建设和维护的责任，再利用其IT服务经纪业务，而不是作为数据和基础设施的看门人。

　　这一愿景的硬件组件已经初具雏形。戴尔最近宣布了一个新的PowerEdge VRTX平台，设计以支持Horizon View和vSphere融合基础设施，使用英特尔新的Ivy Bridge处理器。其目标是允许企业增加VDI架构的密度(它已经交付了超过60%的用户密度增长，通过Windows 8映像测试)，它增强了图形用户界面的性能，并为统一通信提供支持，先进的客户端功能和其他工具的设计，提供比传统的桌面基础设施更好的用户体验。此外，该平台已经内建Desktone的支持。

　　所有这一切可能导致思杰有些惊愕，它的Xen虚拟平台长期以来针对VDI，而不是通用的虚拟化。但Citrix也不是没有它的支持者。东芝就是其中的一个，其新的DaaS平台虚拟桌面服务(VDS，Virtual Desktop Service)，对思杰和VMware都提供了支持，该公司希望VDS平台获得牵引力，作为企业摆脱其Windows XP的基础。唯一的缺点是，无论你选择哪一个VDI或DaaS平台，都必须在东芝自己的Desktop Manager栈下管理，然后让用户通过一个东芝网关从任何的系统来访问Windows映像，包括iOS，Windows、Mac OS、Linux或者Android客户端。

　　最后一个被证明的难题，可能是很多企业将处于必须接受单一供应商摆布的位置，以允许他们的员工访问虚拟桌面。话又说回来，同样的情况存在于一个纯粹的VMware或纯Citrix桌面基础设施，而单一供应商集成的解决方案，如果有什么差错，你知道给谁打电话解决它。

　　当然，仍不确定任何这些是否足够最终推出企业主流以为的标准桌面。毕竟，当涉及到沟通和社会化协作，移动设备正在迅速成为首选的解决方案，传统桌面则作为劳动力密集型任务(如数据库管理和文字处理)的平台。

　　此刻的目标似乎是以单一的桌面架构桥接这两个世界，但这最终可能是一个超越。在不同的平台之间共享文件的需求是肯定的，但你并不需要一个集成的桌面映像来做到这一点。正如Windows 7和Windows 8的用户已经发现的，移动桌面功能在传统桌面不能很好地工作，而桌面映像对于智能手机太过笨重。

　　虚拟桌面对于许多应用可能被证明是有效的，但它们不是每一种需求的解决方案。
