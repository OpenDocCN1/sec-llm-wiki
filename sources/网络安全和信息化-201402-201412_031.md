# BMC在华召开用户大会，发布“Living IT”新战略

全球领先的IT管理公司BMC软件公司在北京召开了2014 BMC IT管理峰会暨中国用户大会。本次大会以“重塑数字未来”为主题，吸引了超过300名业内人士参加。BMC公司副总裁兼首席技术官（亚太区） Suhas Kelkar、大中华区总经理苏玉龙先生等业界权威人士与BMC高层出席了会议，发布及介绍了BMC全新的 “Living IT”战略及相关新产品。

BMC软件大中华区总经理的苏玉龙先生表示：“在当前市场环境下，企业只有迅速改变业务模式和技术系统才能更好地参与竞争，而人是这种转变的核心。在数字化潮流下，BMC发布“Living IT”最新战略计划及相关产品，以帮助客户快速创新、提高自动化水平，更好地管理动态环境下难以预测的成本和复杂性。”  
![](../Images/3eec84dcb861a4e1b1207df8f3b72adf.png)

在本次峰会暨用户大会上，BMC展现了其创新和研发IT解决方案的能力，发布了一系列针对以人为中心，关怀用户体验的数字化管理解决方案。业界普遍认为BMC提出的这种发展趋势，是行业发展的主流转变，而这种先觉性和有效的解决方案提出，也是BMC始终处于行业领先地位的根本原因。

为支持这项新计划，BMC宣布推出一系列新产品和新方法。前台消费化、后台工业化是支持企业实现数字化转型的未来趋势。BMC引领潮流趋势基于“Living IT”战略发布了前端顶尖产品Smart IT和MyIT最新版。

![](../Images/e2767d301f5677b267ee40e2f76aa09d.png)

BMC于去年二月推出的创新应用软件MyIT 2.0，目前已经有100多万企业员工在使用，使他们得以通过高度直观的、协同移动和社交界面管理自己的IT需求。如今，随着Smart IT的推出，BMC进一步完善了IT转型的后台系统，这些直观的解决方案结合在一起，为IT人员和IT用户提供最佳用户体验。  
BMC公司副总裁兼首席技术官（亚太区） Suhas Kelkar表示：“最近几年许多企业采用新的技术和模式进行转型——我们称之为数字化企业转型。有些先进企业已经聘用首席数字官或利用移动设备、云计算、社交媒体等新技术开发新的数字服务。BMC的战略就是利用我们的创新技术，帮助IT部门推动数字化转型。我们共同推动新一代IT的发展。”

2014 BMC IT管理峰会暨中国用户大会共有25场精彩演讲，中国农业银行、国家电网公司、中国光大银行、中国银联、华晨宝马等14家典型客户亲临现场分享其IT管理经验。BMC展示了旗下多个产品的最新发展与路线图，优利等多家合作伙伴与BMC欢聚一堂，共襄盛举。
