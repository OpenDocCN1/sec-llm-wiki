【热点关注】Windows 10更多信息安全和应用管理功能曝光

微软Windows 10的技术预览版已经可供下载测试，因此用户已经可以看到这一操作系统的更多新功能。

10月1日，微软在官方博客中简单介绍了可能会引起企业用户感兴趣的新功能。不过，微软当时并未详细介绍这些功能。

本周，微软发布了Windows 10的两个版本，技术预览版和企业技术预览版。后者包括了许多专注于企业用户的功能，例如Windows To Go、DirectAccess、BranchCache和AppLocker等。这些功能并未出现在普通的技术预览版之中。

微软Windows和信息安全核心应用开发经理奥利佛·尼胡斯(Oliver Niehus)10月1日在MSDN博客中刊文，介绍了Windows 10在信息安全、隐私保护和管理方面的功能。这篇文章于10月2日被删除。

根据尼胡斯的说法，微软正在Windows 10的信息安全功能方面进行大量开发。用户可以使用Azure Active Directory的帐号去登录设备，并获得一系列相关服务。企业用户也可以使用当前的Active Directory帐号。此外，Windows 10集成了“下一代用户认证”，例如密码切换功能等。

尼胡斯同时表示：“Windows 10使数据保护变得更自然，并从平台层面集成了数据保护功能。”此外，这一系统还支持按应用启用VPN的功能，即用户可以指定某些应用启用VPN。管理员可以限制对某些应用或某些IP/端口的远程访问。例如，企业IT部门可以被允许通过VPN进行访问，但这一访问将被限制在某些端口或IP地址。

微软的人士本周曾表示，在Windows 10中，Windows、Windows Phone和Xbox One的应用商店将得到统一。而根据尼胡斯透露的信息，这一统一的Windows商店也将得到一系列调整和优化。

尼胡斯表示：“新的Windows Store商店将不仅支持Modern应用，也将支持桌面应用及其他类型的数字内容。我们将提供多种方式为应用付费。在公共的Windows Store内部，我们还将向企业提供一个在线商店。企业可以在其中显示员工所需的订制的公共应用，以及企业的专用应用。”

微软正在设计一种新的大批量采购项目，帮助企业用户一次性购买大量应用，并完成应用的部署和授权管理，而当员工离职时可以收回这些授权并重新分配给他人使用。微软将支持企业用户通过Azure Active Directory来获得企业应用，以及个人用户通过Microsoft Accounts获得个人应用。

企业将可以使用Intune等移动设备管理服务(MDM)。这样的MDM服务将可以与“大批量采购项目”进行通信，这意味着Windows Store可以帮助用户安装应用及获得授权。

Windows 10其他专注于企业市场的功能还包括快速升级等。在一种被锁定的系统版本中，企业用户可以通过Windows Server Update Services迅速获得Windows 10的普通升级。
