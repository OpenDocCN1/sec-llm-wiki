# 【新功能！】Windows 9虚拟桌面有点眼熟

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=201116894&idx=2&sn=1c943458bf11dcf288a151ca292e19f2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=201116894&idx=2&sn=1c943458bf11dcf288a151ca292e19f2&scene=27#wechat_redirect)

 随着近期微软宣布本月底将发布全新Windows 9操作系统后，更多谍照曝光，之前的种种传闻即将水落石出，而相信如何摆平Windows 移动设备与传统PC设备间用户的使用习惯将是Windows 9的最大挑战。

![](../Images/7fb75f03295cde0983c3bf236b64db70.png)

![](../Images/f4063b58f2d74b47d079b86735eb241a.png)

 之前，虚拟桌面一直是Linux、Mac OS X独占，轻松帮助桌面用户处理多任务、扩展桌面等功能。现在这项“虚拟桌面”功能终于登陆Win 9平台，从形式上看并非大家印象中的那样复杂，更像是多窗口应用。。

![](../Images/d7eb58f6fb83431803f92d7b15837fc6.png)  

 对于Windows普通用户来说，虚拟桌面很显然过于复杂，甚至类似虚拟机等行业软件的功能，为此WiN9将简化“虚拟桌面”的入门使用要求。例如桌面用户可以通过Alt Tab调出、切换至WiN9“虚拟桌面”，即可轻松新建虚拟桌面或者切换当前任务。
