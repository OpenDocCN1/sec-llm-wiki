# 华尔街日报：苹果支付将用安全拯救NFC困局

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=201108150&idx=1&sn=1c3c05aed33111ab4a4e52f94a290a0b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=201108150&idx=1&sn=1c3c05aed33111ab4a4e52f94a290a0b&scene=27#wechat_redirect)

9日，苹果推出了“苹果支付”(Apple Pay)，进入了一个拥挤不堪的移动支付市场。美国《华尔街日报》指出，依靠苹果强大的市场影响力，再加上和指纹身份认证的结合，苹果将给NFC支付带来极大的推动，但是苹果和其他支付厂商，仍然需要付出多年的努力，才能够让更多的消费者用手机而不是钱包里的信用卡来支付。  
  
和市面上的NFC支付一样，依托苹果手机和智能手表的苹果支付，可以让消费者在款台面前挥一挥iPhone，即可完成支付。苹果表示，通过加速商户款台的支付过程，最终能够让消费者抛弃口袋中的钱包，用智能手机主导支付。  
  
在9日的发布会上，苹果掌门人库克发出豪言壮语：“苹果支付将会永远改变我们购买商品的方式。”  
  
当然，通过进入移动支付，苹果也将获得一个新的营收来源。据消息人士透露，几大信用卡公司已经和苹果达成协议，持卡用户通过iPhone完成支付，信用卡公司将会向苹果支付一笔手续费。而通过每次支付，信用卡公司目前会向商户收取一笔费用。  
  
苹果表示，和今天的信用卡支付相比，苹果支付将更加安全。最近，美国的塔吉特等多家百货公司后台被黑客攻破，消费者大量信用卡账号被盗，支付安全，无疑将成为苹果支付的一个卖点。  
  
和传统的NFC支付不同的是，苹果将会要求消费者进行指纹身份验证，这样，即使手机被盗，盗贼也无法用该手机付款买货。另外，苹果智能表也将支持支付，但如何验证身份目前还不得而知。  
  
手机支付的普及，面临着一场和传统信用卡、借记卡支付之间的“战争”。据悉，在美国市场，从2003年以来，信用卡借记卡的支付规模，已经超过了更高的现金和支票，刷卡支付因其便捷性，获得了普通大众的青睐。  
  
一直以来，实体商户、移动支付厂商以及公共交通服务行业，都希望NFC支付技术，能够让交易和支付过程更加快速。对于实体零售商而言，他们希望通过移动支付，获取消费者购物、支付的更多数据，更好的管理进货存货、制定优惠券计划。这也是亚马逊等网络零售商，一直让实体百货公司羡慕的地方。  
  
然而对于普通大众而言，他们并不愿意从信用卡切换到手机NFC支付，不仅因为信用卡支付已经足够方便，而且许多商户根本不支持NFC支付。不过苹果此次一同发布了新手机和智能手表，这将让NFC支付变得更酷更时髦。  
  
维萨公司负责战略伙伴计划的高级副总裁Matt Dill表示，当苹果这样的一家公司提供一种新体验(+微信关注网络世界)，他们带来的市场冲击是巨大的。  
  
不过，当下的NFC市场，举步维艰。之前，谷歌在谷歌钱包项目上投入了巨资，目的就是在实体商户实现NFC碰触式支付。不过由于只有Sprint公司的智能手机支持，再加上加入NFC支付的零售商数量寥寥，谷歌钱包计划，发展远远未达预期。  
  
其他移动支付厂商，比如eBay旗下的PayPal、Square，以及美国移动通信行业联手成立的Softcard，其支付业务发展水平有高有低。  
  
苹果进入移动支付的优势，是获得了美国维萨、万事达卡和美国运通这几大信用卡公司的支持，此外还包括麦当劳、梅西百货等一大批知名的实体商家。  
  
Wedbush证券公司的分析师Gil Lauria表示，智能手机进入支付领域，是水到渠成的事情，比如可以设想一下，一个消费者正在梅西百货选购商品，突然她的手机上将会接收到一个八五折的优惠促销信息，她只需要前去购买，然后在款台挥一挥手机，即可享受到这个打折优惠。  
  
不过在一些支付行业的观察人士看来，消费者抛弃手中的钱包，完全过渡到手机支付，还需要很多年的时间。  
  
根据科技市场研究公司Gartner的预测，今年底，NFC支付的金额将达到82亿美元，但是在移动支付中的比例，仅有微小的2.5%。  
  
支付安全成为苹果支付的重中之重。除了NFC技术和指纹身份认证之外，苹果还将在手机中整合一种新技术，用户的信用卡账户信息(比如帐号、失效期)在手机内部将以一个唯一的序列号所取代。这样，即使用户支付过的一个商户或零售商的后台系统被黑客攻破，单靠这些序列号，黑客仍然无法获取持卡用户的真实信息。
