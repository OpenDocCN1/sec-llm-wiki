# 【业内报告】Gartner 2014年IT服务管理工具魔力象限出炉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200984662&idx=2&sn=2e2ef2b8f1b56e33ae9981c3cc4b0aa1&chksm=2897414a1fe0c85c565419adb387db2a6ceb0b15b0c51063c32a862637992d2fb3c67ee66bda&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200984662&idx=2&sn=2e2ef2b8f1b56e33ae9981c3cc4b0aa1&chksm=2897414a1fe0c85c565419adb387db2a6ceb0b15b0c51063c32a862637992d2fb3c67ee66bda&scene=27#wechat_redirect)

 近日，全球领先的实时IT管理解决方案提供商，卓豪ManageEngine宣布旗下IT服务管理解决方案\-ServiceDesk Plus继2013年之后，再次被知名分析机构Gartner列入2014 年IT服务支持管理(IT Service Support Management，简称ITSSM)工具魔力象限报告。这份报告基于愿景完整性和执行能力对14家供应商进行了评估。

 Gartner的分析师认为，与同类厂商相比，ManageEngine ServiceDeskPlus具有以下优势：

 - 出色的性价比，非常适用于中型或小型规模的企业。

 - 可以与ManageEngine网络性能管理、应用性能管理工具集成，组成完整的IT管理方案。

 - 免费版帮助台软件的营销策略执行使得ManageEngine大受欢迎。

 相比去年，Gartner今年对ITSSM工具供应商的筛选更为严格，要求提供的产品必须满足以下条件：

 1. 必须包含IT事件管理、问题管理、变更管理、配置管理、发布管理、用户自助服务、知识库管理、IT服务支持分析报告、SLA管理等功能。

 2. 可以在移动设备上使用。

 3. 产品年销售额不低于1200万美金。

 4. 至少在三个区域拥有办事机构或合作伙伴网络：北美、南美、EMEA（欧洲、中东及非洲）、亚太、澳大利亚。

 5. 提供10个优质客户情况（至少使用5个功能模块，员工规模5000人以上、至少有三个分支机构）。

 Gartner在报告中指出，IT服务支持管理（ITSSM）工具能够使IT运营部门，特别是基础设施和运维管理经理更好地支持企业生产环境。ITSSM工具通过自动化处理任务和自定义工作流有助于为企业业务交付高效可靠的IT服务。
