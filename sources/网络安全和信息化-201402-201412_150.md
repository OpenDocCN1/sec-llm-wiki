# 【爆料】微软将停止Windows 7主流计划！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200475647&idx=1&sn=14eeffb8d6cc0852c1e031febb767fac&chksm=289e8ae31fe903f5a0cb3df94285b5bf63c640ef6bdd9a1d9644ce3da1bcc85c395eaf198fb7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200475647&idx=1&sn=14eeffb8d6cc0852c1e031febb767fac&chksm=289e8ae31fe903f5a0cb3df94285b5bf63c640ef6bdd9a1d9644ce3da1bcc85c395eaf198fb7&scene=27#wechat_redirect)

微软将全力支持Windows 8。尽管约三分之一的用户仍然在使用Windows XP，但今年早些时候微软仍然决定停止为这款操作系统提供安全补丁。现在，微软又公布了停止为Windows 7提供“主流支持”的计划。市场研究公司Netmarketshare的数据显示，逾50%的Windows用户使用Windows 7。

  

Windows 7主流支持将于2015年1月13日“戛然而止”。这听起来似乎有些可怕——貌似微软将彻底抛弃Windows 7用户，任由黑客入侵用户的计算机。实际上，主流支持的结束只是Windows 7“退场”的开始。

  

微软可能希望使消费者认为他们需要升级到Windows 8.1，否则他们的计算机将面临受到攻击的风险——这种情况要到2020年1月14日才会成为现实，届时Windows 7的扩展支持期将会结束。

  

操作系统支持期限有两个的概念似乎是一种法律用语。微软尝试在其网站上解释这一问题，但似乎是“越描越黑”。微软称，“支持结束指的是微软不再提供补丁、升级包和在线技术支持。失去微软的支持，用户将不再能获得安全升级包，安全升级包有助于保护PC不会受到恶意病毒、间谍件和其他恶意软件的侵扰。”

  

实际上，Windows 7的主流支持期结束“天不会塌下来”，只有扩展期支持结束才会出现微软描述的景象。这意味着Windows 7用户5年后才需要担心上述情景出现。

  

令人关注的不是微软将最终放弃对Windows 7的支持，而是它对Windows 8有如此之高的自信，甚至宁愿放弃用户多得多的Windows 7。Netmarketshare数据显示，截至6月份，Windows 8和8.1市场份额之和接近13%，Windows 7市场份额由去年10月份的46.4%上升至50.6%。

  

新版操作系统通常会蚕食旧版操作系统的市场份额。但Windows 8却推动了Windows 7市场份额的增长。微软一直在为Windows 8增添更多与Windows 7相似的功能，尝试解决这些问题。

  

微软试图通过在Windows 8.1中塞进一种版本的Windows 7，做到鱼与熊掌兼得。但迄今为止，这一策略并未奏效。

  

敲定Windows 7的支持截止时间可能会成为拉动Windows 8.x普及的催化剂，也可能把以前的Windows用户推到苹果Mac或谷歌Chrome/安卓阵营。

  

** 微软的风险**

  

Windows仍然是微软一项规模很大的业务。微软2013年的年报显示，尽管Windows 8普及速度比较慢，但在过去的3年，微软Windows业务部门每年营收超过180亿美元。微软在季度财报中不单列Windows业务的数据，但微软在第三财季财报中称，“在Windows OEM Pro业务营收增长19%的有力推动下，Windows OEM业务营收增长4%。”

  

Windows业务营收增长的部分原因是Windows XP停服。微软此举迫使企业放弃Windows XP，促进了新版Windows销售的快速增长。但是，在放弃Windows XP的企业中，只有部分用户升级到了Windows 8，其他用户要么选择了Windows 7，要么彻底放弃了微软的产品。

  

微软已经通报零售商，Windows 7将于今年10月30日停止销售。微软尚未披露停止向OEM合作伙伴销售Windows 7的时间。微软可能等到发布一个真正受到企业客户喜欢的Windows 8版本后，才会中止向OEM合作伙伴销售Windows 7。

  

** Windows 8并非那么优秀**

  

由于与之前版本的Windows有很大不同之处，Windows 8遭到用户抵制。Windows 8提供了一种适合触控屏的全新界面，可问题在于，大多数Windows 8用户都不使用触控屏设备。

  

在没有配置触控屏的计算机上，Windows 8至少被认为缺乏吸引力，甚至被认为令人感到困惑。

  

Windows 8.1通过恢复部分传统功能解决了一些问题，新版本的Windows在这方面会走得更远，微软有关“未来所有个人计算设备都配置触控屏”的观点是正确的。对于针对触控屏设备优化的操作系统，只有在触控屏设备上运行时才能充分发挥其潜力。触控屏设备的销售增长很快。

  

由于触控屏Windows 8笔记本的售价已低于300美元，因此购买触控屏笔记本的用户将越来越多。如果触控屏计算设备到2020年没有大规模普及，微软就押错宝了。平板电脑和混合本的增长，以及越来越多的PC配置触控屏，使得这种情况似乎是不可能出现的。

  

随着用户购买配置触控屏的PC，他们将会运行Windows 8，从而加快Windows 8的普及，也使Windows 7停服显得没有那么可怕。
