# 【业界动态】微软核心战略转移 由设备转向云计算

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200475647&idx=2&sn=aac4237615febc147091747041250fa4&chksm=289e8ae31fe903f5daef4b9aaa45b780d276d38cb16a2650f46ff3961368cd9b7e9701636aee&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200475647&idx=2&sn=aac4237615febc147091747041250fa4&chksm=289e8ae31fe903f5daef4b9aaa45b780d276d38cb16a2650f46ff3961368cd9b7e9701636aee&scene=27#wechat_redirect)

据国外媒体报道，今天微软CEO萨蒂亚 纳德拉在发给全体员工的电子邮件中表示，新的一年微软最重要的事情就是重塑微软的“核心”。纳德拉认为前任CEO史蒂夫·鲍尔默的“设备和服务”理念对于公司的运营是有帮助的，但是他认为“我们现在需要我们自己独特的战略。”这一独特的战略就是专注于移动和云计算。

  

虽然纳德拉可能会放弃“设备和服务”的核心战略，但这不会对硬件产品产生影响。Xbox、Surface平板和Windows Phone并不会受到战略调整的影响。“我们很幸运，拥有Xbox这个平台去完成独特而大胆的创新。底线是，我们将继续壮大我们的Xbox用户群，创造更多的商业价值。”

  

而对于Surface，纳德拉表示Surface Pro 3将作为微软的旗舰硬件，来丰富Windows的生态系统。 “这意味着，未来我们会开发新的（硬件）类别，就像以前对Surface做的那样。这也意味着我们将以负责任的态度令市场接受Windows Phone，这也是我们收购诺基亚设备和服务的目标。”

  

纳德拉还计划重塑微软的各个产品团队和设计流程，致力于完成以“客户为基准、数据为驱动、速度为导向、质量为中心”的目标。这一动作部分是为了简化流程，让更少的员工专注于决策；还有就是为了改善各工程组数据和应用科学资源的培训和投资情况。也就是说，纳德拉希望帮助微软加快软件开发流程，同时保证微软的软件产品质量。微软在过去几年猛然发现像谷歌一样的竞争对手，可以用比微软更快的速度开发产品和释出更新。

  

纳德拉给微软员工的信中也承认，公司未来面临挑战。“我认为我们面前的工作需要我们比以往任何时候都要大胆，都要更加雄心勃勃。”纳德拉鼓励微软员工一起建立一种新的文化，以促进公司未来的发展。纳德拉表示：“没有什么是不可以的，只要它对于我们转变文化并实现这一核心战略有帮助”。纳德拉显然已经准备好挑战和改变微软的旧有文化，唤醒他的员工并重新启动微软，拥抱全新的战略和愿景。就像纳德拉说的那样，“我们将共同改变这个公司，抓住大好机会吧。”
