# 【思想聚焦】马克.赫德：企业CEO青睐云的五个原因

今天的企业领导人正面临着艰巨的挑战：他们既要想方设法找到新的路径，以投资面向客户的创新技术与交互模式，又要权衡利弊，在剥离非生产性成本上找到平衡。

  

　　云计算是解决上述挑战、打开机遇之门的一把钥匙。凭借不断增强的性能和日益成熟可靠的模式，云计算可以在帮助CEO们获取这种微妙平衡上发挥重要作用。因为云已经从一个技术性概念，发展成为一种主流的战略性商业模式。云在从企业人力资源管理、营销、销售、财务等重要领域的广泛应用已经说明了这一点。

然而就在几年前，很多企业还尚未把部署云列为一项关键任务，为什么企业对于云的态度发生了如此巨大的转变？我认为有三个主要原因：

  

　　首先，客户告诉我们，甲骨文的云产品在性能、安全性和可靠性上完全满足甚至超越了他们的需求。

  

　　其次，各类企业，特别是大型企业，对于动辄花费数百万美元，甚至有时高达几亿美元的投资，去集成那些并不匹配的应用、系统和网络，已经焦头烂额。他们相信云计算可以帮助其减少那些投入产出比较低的投资。

  

　　第三，在瞬息万变的商业环境里，企业需要更快、更好地响应快速变化的客户需求，他们相信我们的云技术可以帮助其加速业务。因此许多客户在数周内，就已经安装并使用新的云应用了。

  

　　因此，今天的企业领导者将有机会重新改变企业部署IT技术的方式，从而将更多的IT预算投入到面向客户的业务机会上，同时减少对于复杂且昂贵的企业内部IT环境的投资，因为这类IT环境无法满足企业发展现代化业务的需求。

  

　　在与全球CEO们的沟通中，我听到很多这样的反馈，“我们在IT上花了很多钱，却没花对地方。” 他们对于IT预算都很慷慨，但问题在于他们在旧有系统和应用上花费过多，更不要说对于大规模集成项目的花费了。这些旧有系统不够灵活，维护费用也昂贵，而旧有应用则无法应对社交或移动方面的需求。投入似乎永不见底，但却无法获得相应的商业价值和洞察力。

  

　　而云是破解此类问题的一剂良药，它可以帮助CEO们更深入地了解既有客户和潜在客户，抓住稍纵即逝的市场机会，加快新产品开发，并吸引到最优秀的人才，以实现企业成功转型发展。

  

　　此外，较早采用云计算的商业领袖已经意识到，拥有一个可靠的云服务提供商非常重要，而不是复制传统的IT方法，即从几十个，甚至数百个IT供应商那里购买组件，然后花费大量的时间和金钱去集成这些分散的组件。通过与一个主要供应商合作，CEO们期待能够更高的效率和更少的花费，并且最终简化系统和流程。

　　综上所述，企业CEO们青睐云技术的原因可以归结为以下五点：

  

　　1. 简化IT。在传统方式下的IT行业产生了上千个分散的部件，迫使用户在IT集成链中花费几个月甚至几年时间，需要成百上千名IT人员来完成评估、购买、组装、配置及监测升级等所有的流程。我们认为IT行业应该承担责任来生产更具协同性的产品，让IT更便捷，更智能、更高效。

  

　　2. 更优化的IT投资回报。在传统方式下，70%-80%的总体IT预算都被消耗在那些复杂却价值不高的工作中，而一些更具创新性的需求却得不到足够的资金支持。而云计算能够为企业领导人提供更优化的选择，使其将关注点放在核心业务和优先项目上，而非IT管理。云技术帮助CEO们以更经济有效的方式投资于那些面向客户的创新项目，这在今天的移动互联世界是十分重要的核心竞争力。

  

　　3. 加快和优化业务流程。现在的很多企业仍然在运行他们在20年甚至25年前安装的核心应用。虽然那些老旧的应用仍然能够发挥余热，但是问题是它们已经不能应对过去几年中出现的创新需求了，而这些创新需求在今天已被视为标准化的需求，包括丰富的社交体验、移动为先的消费模式、易用的用户界面、视频、结构化和非结构化数据的即时搜索以及经常性地和无干扰的升级。相反，现代SaaS应用就是为了利用所有最新的创新和功能而定制的，这些创新功能几乎涉及员工们的所有工作。

  

　　4. 推动创新。使用云计算解决方案可以帮助企业领导者重新规划IT预算的分配，将IT劳动力从昂贵而又毫无价值的整合工作中解放出来。例如：通过移动设备向销售团队提供实时情报：统一需求链和供应链;缩短陈旧流程的滞后时间;在新产品和服务中加入智能感应器和软件，以便在互联程度越来越高的世界里使用。

  

　　5. 享受世界一流的安全和合规性服务。企业领导者希望云计算服务商能够提供世界级的安全和合规性服务。对于仍在使用传统IT解决方案的企业领导者来说，这些问题会加重核心业务的压力。但是对于甲骨文来说，那绝对是我们最优先的任务，我们在上面投入了大量的资源并为之建立了世界一流的团队和流程。

  

　　在过去的12个月里，各行各业的企业领导者都在期待或开始使用云计算解决方案，因为这不仅是IT行业的最新成果，也是真正的兼具战略性和革命性的技术，这些技术可以帮助他们削减非生产性成本，将珍贵的IT预算用到更重要、面向客户的创新性项目中。

  

　　CEO们对于云计算寄予了很多期望，期待云能为企业内部，除HR以及营销部门以外的其他职能部门也注入更多创新的动力。我们已经开始看到很多大型企业利用云计算解决方案提高了核心生产系统的绩效，比如财务规划、供应链、客户服务等等。

  

　　对于想要简化IT、推动创新、提高IT投资回报率，并加快业务流程的企业领导者来说，云计算的时代已经到来了。
