# 【业界关注】x86收购案近尾声：惠普抢夺客户 IBM积极安抚

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200304959&idx=2&sn=bfff0007867beb3a6d3b9d17c95b92ef&chksm=289de0231fea6935009be6b0160ef38f20c6b6b8ff9eb4f653ffa89fdf43eef5d8b41a696939&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200304959&idx=2&sn=bfff0007867beb3a6d3b9d17c95b92ef&chksm=289de0231fea6935009be6b0160ef38f20c6b6b8ff9eb4f653ffa89fdf43eef5d8b41a696939&scene=27#wechat_redirect)

IBM与联想关于x86架构服务器业务的收购接近尾声。惠普公然打响客户抢夺战，IBM则努力安抚客户。X86全球总经理Adalio Sanchez表示，客户们应该坚持下去。

IBM旗下的x86部门正在被联想收购，近日IBM的新网页上也贴出了X86全球总经理Adalio Sanchez的视频。“IBM将继续致力于发展企业系统和存储业务，专注于提高研发，以为我们的客户提供相应技术，”他说，“联想拥有大规模、高运营效率和广泛的销售渠道，加上IBM在x86的创新，这将进一步推动x86的成功。这也就意味着客户们可以充满信心的投资，IBM和联想都承诺将会获得成功。”

不过，在IBM和联想试图安抚客户焦虑的同时，惠普首席执行官梅格·惠特曼(Meg Whitman)正试图从中获利。近日惠特曼告诉记者，在四个月内，惠普已经从IBM手上赢得了600多个订单，利润每天都在增长。

惠普正在积极采取多种措施争取IBM x86的客户，如与100位IBM重点客户展开合作以拓展其与惠普的业务，此外在本周的Discover大会上，惠普也招待了数十名IBM优先级客户。

客户抢夺战已打响。目前，联想和IBM正试图让其交易通过监管机构的审核，一旦交易完成，联想将会搬入曾属于爱立信的三角研究园中。
