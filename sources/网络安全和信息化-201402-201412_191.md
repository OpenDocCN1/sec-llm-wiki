# 【乐学IT】乔布斯教会了他如何说服一个固执的人

**你在生活中有没有遇到过非常固执的人呢？你又是如何应对的呢？下面是皮克斯动画工作室的联合创始人和迪士尼公司总裁艾德-卡姆尔（Ed Catmull）分享的重要经验。**

**他与以固执著称的史蒂夫-乔布斯（Steve Jobs）共事了26年，乔布斯也是皮克斯动画工作室的创始人之一。乔布斯曾对他说，当别人与他不能达成一致意见时，他的解决办法就是“反复向他们解释，直到他们理解。”**

**在最近召开的“斯坦福企业家之角”论坛上，卡姆尔说他发现了既能充分表达自己观点，又不至于让沟通演变成白热化争吵的有效办法。在会上，卡姆尔还推销了自己的新书《创意公司》（Creativity Inc.），该书记录了有关****苹果****已故CEO乔布斯的很多逸闻趣事。**

卡姆尔有自己的应付乔布斯的方法：

***“在与乔布斯共事的26年中，我和乔布斯从来没有发生过面红耳赤的争吵，我的性格也不允许我这样做。但是，我们确实在很多事情上产生过不同的意见。每当我向他谈到我的观点时，他就会立马予以驳斥，因为他的脑子转得比我快。于是，我会等上一周时间，然而再给他打电话，反驳他说过的话，他又立即开始驳斥我的观点。于是，我会再等上一周时间找机会跟他表达我的观点。如此反复，有时候会持续好几个月的时间。但是最终，事情的结果无外乎这三种：其一，乔布斯说，‘好的，我明白了，你是对的。’其二，我会对同事说，‘我想，他的观点是对的。’其三，我们最终也没有达成一致意见，但是乔布斯允许我按照自己的方法做事，而且不再予以干涉了。”***

**总之，这就是应付固执之人的有效办法****：耐心、虚心、愿意犯错，经过努力仍然无法达成一致意见之后，仍然愿意继续前行。**
