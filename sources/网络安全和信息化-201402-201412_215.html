【导读】作者单位需要升级内部网络并要求配置VPN，计划升级更换一直使用的Cisco 2811路由器。经笔者询问厂商技术支持后，发现该路由器在硬件上就支持VPN、防火墙、IPS。因而出于成本的考虑就没有必要更换该台路由器，但是由于出厂时厂商只安装了Cisco IOS Software, 2800 Software（C2800NM-IPBASE-M）， Version 12.4（3i）的默认系统，所以路由器的VPN、防火墙、IPS功能均未启用。于是笔者在网上找了一份c2800nm-advsecurityk9-mz.124-22.T.bin的IOS版本并对路由器成功升级，为单位节约了一笔网络设备的开支。


备份失败

笔者打算利用TFTP服务器备份路由器原来的IOS系统，而后再升级下载的高版本ISO系统。先在计算机上运行思科TFTP服务软件，将TFTP服务器的地址设为：192.168.101.11，并在路由器网口上配置好网关地址：192.168.101.254，这里要注意的是路由器的网关地址和TFTP服务器地址要在同一网段内，否则无法备份和升级路由器系统。在路由器全局模式下输入命令：Router#copy flash: c2800nm-advsecurityk9-mz.124-22.T.bin tftp:// 192.168.101.11。此时在TF TP Server会出现一连串“#”字号，表明开始传输数据，本来以为可以顺利地备份好路由器软件系统，但就要传完的时候，系统却提示出错：“timeout! Write error!”，显示备份路由器软件系统失败。根据系统提示的信息笔者排除了网络不正常和计算机磁盘空间不足等因素，再次执行传输命令却发现故障依旧，依然无法备份路由器ISO系统。考虑到有可能因为TFTP的软件导致的问题，笔者又从网上下载了一个第三方的TFTP server，一试结果还是那样。又找来3Com的TFTP Server，这次效果更差，传到16MB的时候就断开了，系统提示还是超时和写入错误。最后仔细分析才发现了问题关键所在，前面两次开始都能正常传输，只是到最后系统才提示出现问题，所以敢肯定不是传输线路问题，查找相关资料才发现，原来TFTP（Trivial File Transfer Protocol）普通文件传输协议最大就支持传输32MB的文件，所以想利用TFTP服务器来备份超过32M的路由器ISO系统方法是行不通的。


成功备份

于是笔者采用了第二种方法：就是利用微软Windows自带IIS中的FTP组件建立 FTP服务器备份系统ISO文件，先将FTP服务器的地址设置为：192.168.101.11，在FTP服务器中添加一个用户名为123的用户，并设置密码为123，并开启FTP服务器的写入权限。使用超级终端进入路由器配置界面，键入如下命令：

Router# configure terminal

//进入路由器配置模式

Router(config)# ip ftp username 123　　

//设置FTP的访问用户名

Router(config)# ip ftp password 123　　

//设置登录FTP的密码

Router (config)#exit

//结束，退出

Router#copy flash: c2800nm-advsecurity k9-mz.124-22.T.bin ftp://123:123@192. 168.101.11

//执行FTP传输命令，传输文件为c2800nm-advsecurityk9-mz.124-22.T.bin，已经建立好的FTP服务器地址为192.168.101.11。

输入以上命令后，传输更新IOS后文件复制正常，等待了几分钟后，系统提示“successful!”，ISO系统备份成功。


升级路由器ISO系统

将IOS成功备份到FTP上后，最后将新的用于升级的IOS进行上传到路由器ROM中。进入2811配置模式使用如下命令进行操作：

Router# configure terminal

//进入配置模式

Router(config)#ip ftp username 123

//设置登录FTP的用户名

Router(config)#ip ftp password 123

//设置登录FTP的密码

Router(config)#exit

//退出设置

Router#copy　ftp:// 123:123@192. 168.101.11 / c2800nm-advsecurityk9-mz.124-22.T.bin flash:

//复制c2800nm-adv securityk9-mz.124-22.T.bin新版IOS到2811

键入以上命令后开始上传要升级的ISO文件，升级完成后输入以下命令，指定要启动的系统ISO文件，最后保存后重新启动路由器即可完成整个ISO系统文件的升级。

router(config)#boot system flash:c2800nm-advsecurityk9-mz.124-17.bin

router#copy running-config startup-config


总结

在升级硬件设备时也需要考虑软件的版本问题，其实有时候根本没有必要升级硬件设备，只需要将软件升级就可以满足需求了，白白节约了一大笔升级硬件的资金，何乐而不为呢。
