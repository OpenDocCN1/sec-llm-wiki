# 【实用文章】小技巧：关闭windows 8的部分功能

**导读：微软在4月8日终止了对Windows XP的更新，很多微软用户选择Windows 8操作系统。但是Windows 8的一些功能有时会让我们感觉有些尴尬，如何根据自己的需要关闭一些功能呢？本文为您介绍了关闭一些功能的方法，您可以根据您的需要进行选择！**

从4月8号起微软公司已经停止为Windows XP用户提供后续支持服务，因而越来越多的用户不得已投入到Windows 8系统的怀抱。值得一提的是在Windows 8系统中，微软给用户提供了更多更为合理贴心的服务和功能，这些服务和功能在绝大多数情况下都可以为用户带来很多方便和安全。但实际应用过程中，部分用户感觉到也有一部分看似贴心的功能和服务却还是不那么让人满意，其实用户自己可以关闭这些让人“尴尬”的功能和服务提高系统的反应速度和腾出部分磁盘空间。

  

** 关闭快不了的“快速启动”功能**

Windows 8系统的快速启动功能的作用就是一项让电脑在关机之后下次可以更快启动的设置，是通过关机前将系统信息保存到一个文件夹中实现的。在系统中默认情况下该功能是处于启动状态的。部分笔记本用户使用后发现，启动该功能后系统的启动速度并没有快多少，在关闭该功能后系统启动速度也没有慢多少，感觉到该功能在普通笔记本电脑上显得很鸡肋，关闭后反而为笔记本那可怜的SSD硬盘腾出了不少空间。如果用户感觉到该功能用处不大则可以关闭该功能。关闭该功能的方法也比较简单：打开系统控制面板窗口，依次选择“硬件和声音”→“电源选项”→“选择电源按钮的功能”→“更改当前不可用的设置”的文字链接，在“关机设置”中看到有“启动快速启动（推荐）”的选项，取消选择并单击“保存修改”按钮即可关闭系统的快速启动功能，如图1所示。

** 关闭占空间的“系统休眠”功能**

休眠功能是Windows 系统提供的一项较为贴心的功能，系统主要就是将内存中的所有数据保存到一个休眠文件中，这个休眠文件也就是增加的休眠数据几乎等同于电脑的全部内存容量。对于不少普通用户来说很少会用到系统的休眠功能，比如在家里使用电脑时考虑到节能一般都是使用完毕后直接关机，很少将电脑设置为待机或休眠状态。这种情况下用户就可以关闭系统的休眠功能为节约存储空间同时还响应了节能的号召。关闭的方法也比较简单，按“WIN+X”组合键，选择命令提示符，在这里要使用管理员权限身份运行命令提示符，在命令提示符窗口中执行“powercfg /h off”命令即可关闭系统休眠功能。

在这里要提醒用户的是系统在关闭休眠功能后，会清除系统中休眠文件，此时Windows 8的内核会话也将无法写入硬盘，从而导致快速启动失效。但系统的睡眠功能将继续有效，当系统在睡眠期间遭遇断电时睡眠文件无法转换成休眠文件，就会出现数据无法保存造成丢失的问题，因而在一般情况下还是不建议用户关闭系统的休眠功能。

  

** 取消没必要的个人开机密码**

在默认情况下，Windows 8的开机登录是要输入密码的。对于那种没有连接互联网或者家庭使用的电脑时，用户只要确保环境的安全就可以取消系统开机的登录密码，没有必要每次开机时都去输入系统登录密码。取消开机登录密码的方法也比较简单。使用“WIN+R”键打开运行对话框，在运行对话框中输入“control userpasswords2”命令，在弹出的“用户帐户”管理窗口中清除“要使用本机，用户必须输入用户名和密码”复选框的选中状态，设置完毕后，在下次启动系统时，系统就会以此前设置的帐户密码自动登录系统，如图2所示。但是如果说用户使用环境比较复杂，为了安全还是建议用户不要采用密码静默登录模式。

** 关闭不省心的系统“自动更新”功能**

与第三方系统自动更新软件相比，Windows 8系统中自带的自动更新工具就显得有点鸡肋了，就拿用户平常使用的360安全卫士来比较，360安全卫士的系统更新会提示哪些补丁一定要更新，哪些补丁可选择更新，哪些补丁更新后会造成什么影响等，使用起来比较人性化，而系统自带的更新功能只是提醒用户更新或者自动更新，不会提示更新了什么内容等消息。因此如果选择了第三方自动更新软件的话系统自带的更新就没有那么必要了，而且使用系统自带的更新还会占有了大量的存储空间。关闭系统自带更新方法如下：使用“WIN+X”组合键，打开控制面板窗口，选择 “系统和安全”→“Windows 更新”→“启用或关闭自动更新”的文字链接，在弹出的“更改设置”窗口中选择“从不检查更新”选项，点击“确定”按钮关闭自动更新，如图3所示。然后点击任务栏操作中心的小旗帜图标，选择“更改操作中心设置”，打开操作中心，去掉对“Windows 更新”选项的选择，单击“确定”按钮关闭系统自动更新功能。

![](../Images/b54608e1ec1aa5d6192b99f008f9a488.png)

图3 关闭不省心的系统“自动更新”功能

  

** 关闭占有系统资源的自动维护功能**

Windows 8系统的自动维护功能在运行状态下会占有比较高的系统资源，从而让配置较低的电脑变得异常缓慢，甚至会出现无响应和死机等状况，此时用户可以关闭系统自动维护功能，而后借助第三方工具来定时对系统进行维护。要关闭系统自动维护功能的方法是：和上面的方法一样，打开“控制面板”窗口，选择“管理工具”—“任务计划程序”，在窗口中找到“\\Microsoft\\Windows \\TaskScheduler”，禁用其中“Idle Maintenance”和“Regular Maintenance”两项任务即可禁用自动维护功能，如图4所示。这里要提醒大家的是在“操作中心”关闭“自动维护”选项只能起到关闭消息提示，而不能从根本上关闭系统自动维护的功能，需要大家注意。

![](../Images/56784a0c7473c2055f9a4dc287b34ab8.png)

图4 关闭占有系统资源的自动维护功能

  

** 关闭“泄密”的跳转列表**

Windows 8系统中的任务程序跳转列表看起来很适用，但如果用户在公司或者公共环境下使用计算机的话，一个很严重的问题就是可能会在不经意间泄露用户的行踪和隐私。出于安全的考虑在使用公共计算机的用户很有必要将这一个跳转列表记忆功能关闭掉。方法就是通过任务栏右键菜单，选择“属性”—“跳转列表”，取消对“隐私”下的“存储最近打开的程序”和“在跳转列表中存储并显示最近打开的项目”两项的选择，单击“确定”按钮即可关闭跳转，如图5所示。
