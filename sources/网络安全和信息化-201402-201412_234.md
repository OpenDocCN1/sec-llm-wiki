# 【实用文章】企业网管眼中的Windows 8

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200216229&idx=2&sn=3346cca1afaa8d82427c97cdc914416b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200216229&idx=2&sn=3346cca1afaa8d82427c97cdc914416b&scene=27#wechat_redirect)

**【导读】Windows 8慢慢成为办公的主流操作系统，那么Windows 8的哪些功能适合哪些企业呢？本文笔者通过自己的实际工作经历，从一个企业网管的角度，带您了解Windows 8的几个功能模块，希望对您的工作有所帮助！**

  

因为是企业网站管理员，笔者对于Windows 8 Enterprise所感兴趣的内容自然与本职相关的一些功能，本人将其概括为以下五项功能。

  

**首先是AppLocker**

AppLocker即所谓的“应用程序控制策略”，该方案最早出现在Windows 7中，利用AppLocker管理员可以非常方便地进行配置，以实现用户可在计算机上可运行哪些程序、安装哪些文件、运行哪些脚本。由于AppLocker是基于组策略管理和配置的，因此我们可以非常方便地将其部署到整个网络环境中，可谓一劳永逸。新的 Windows 8 Applocker可以同时管理传统的桌面应用程序和新的Metro apps。

  

**其次是DirectAccess/ BranchCache**

它们主要用于改善网络性能，主要服务对象是远程分支机构。过去十年，虚拟私人网络机制能够让用户远程连接到企业网络；尽管这种网络能够实现该功能，但远不是理想的选择，为此Windows 8 DirectAcess应运而生。

从终端用户角度，虚拟私人网络（VPN）最大的问题是终端用户不得不初始化连接，然后登录到公司网络，就像从外围网络登录一样；虽然VPN在让用户远程访问Windows方面确实做的不错，但是反向连接绝不可能，换句话说，管理员不能够使用VPN初始化一个到远程用户的连接，总是由远程用户确定连接，这无疑使远程系统的管理复杂化了。

在Windows 7和Windows Server 2008 R2中，已经引进了DirectAccess来弥补VPN的缺点，用户任何时候连接到网络，DirectAcess会自动确定与公司网络的连接；终端用户不需要初始化连接，这大大提升了管理员远程计算机的管理,如图1所示。

在Windows 8中，为了让DirectAccess部署更实用，实现了两个重大变化。第一，安装和初始化设置过程比以前更简单了，一旦将远程访问角色添加到Windows 2012服务器，就能建立DirectAccess。

当然，大型企业仍然具有定制DirectAccess部署的能力。大企业通常为DirectAccess服务器使用网络负载平衡，小企业就不会这么做；另外一个重要提升就是DirectAccess可以通过网络地址转换（NAT）设备使用，这个变化是至关重要的，使DirectAccess能够访问较小组织。这些组织经常使用NAT防火墙。

Windows 7 DirectAccess的一个缺点是，当连接失败时，不为终端用户提供有用的信息。Windows 8增加了一个连接助理下载，为终端用户提供Windows远程访问状态指示。

BranchCache使用服务器通过广域网 (WAN) 连接传送内容，允许组织将内容和应用程序存储在远程数据中心。Web服务器、文件服务器以及应用程序服务器不断从总公司移至远程位置，因此员工依靠WAN连接访问其重要数据。BranchCache可以有两种运行模式：（1）托管缓存模式：如办公地点中有运行Windows Server“8”的服务器，则会以托管缓存模式配置BranchCache客户端计算机，并且该服务器称为托管缓存服务器；（2）分布式缓存模式：如办公地点中没有可以部署为托管缓存服务器的服务器，则可在客户端上将 BranchCache配置为分布式缓存模式。在此模式中，客户端计算机会缓存已下载的内容并与办公地点中的其他计算机共享该内容。BranchCache可以部署文件服务器、Web服务器、应用程序服务器三种类型的内容服务器。

  

**第三个是NFS(Network File System)**

它的功能是通过网络让不同机器、不同操作系统能彼此分享数据，让应用程序在客户端通过网络访问位于服务器磁盘中的数据，是在系统间实现磁盘文件共享的一种方法。NFS的基本原则是“容许不同客户端及服务端通过一组RPC分享相同文件系统”，它独立于操作系统，容许不同硬件及操作系统共同进行文件分享。NFS在非Windows OS早已广泛应用，如Linux, UNIX,FreeNAS等。终于在Windows 8 Enterprise中我们看到了NFS！

  

**第四个是Windows To Go**

可使Windows 8从USB驱动器中启动并运行，不必考虑机器上运行的操作系统，Windows To Go为有效使用备用的工作场所方案资源提供有力支持。对于陷入BYOD困境的企业来说，可以选择Windows 8系统中的Windows To Go来应对BYOD带来的难题。简单说，Windows To Go可以让企业创建个性化和封闭的Windows 8副本，并把它装进U盘里，员工可以插上U盘，在自己电脑上使用这个安全和便携的企业Windows“工作区”。

  

**第五是虚拟桌面基础结构VDI（Virtual Desktop Infrastructure）有改进。**

VDI允许用户从任何设备无缝地访问在数据中心中运行的丰富而完全保真 Windows环境，VDI借助 Windows Server 2012中的远程桌面服务 (RDS) 和 Hyper-V，主要优势包括：其一，Windows Server 2012 通过单独平台提供所有类型托管桌面，使部署简单，易于管理；其二，RemoteFX提供一致的丰富用户体验，而无关正在访问虚拟桌面类型，或者用户访问桌面的位置；其三，RDS可以托管基于会话的桌面、集中虚拟机或个人虚拟机，因此，客户可以从一个单独平台灵活为用户部署正确类型的VDI桌面。Windows 8 VDI功能的提升，主要包括：支持用户播放3D图像，使用USB接口并使用触摸屏设备通过LAN或是WAN网络来观看VDI情节。

总之，Windows 8企业版在公司网络系统运维中，在对PC管理部署、安全性、虚拟化、新移动场景等方面的功能都在试图展现出令人期待的发展方向。
