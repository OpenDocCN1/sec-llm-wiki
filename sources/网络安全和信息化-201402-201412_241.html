【导读】目前很多国内大多数DBA还停留在Oracle 9i或者10g，究其原因有可能是Oracle 11g的价格问题影响到了其没有得到广泛应用。但有少数使用过Oracle 11g的用户反应在Windows 7系统下安装新版本Oracle 11g会出现兼容性问题，无法正常安装数据库系统，而在其它系统中比如window2008中就不会安装过程就不会出现兼容性问题。


目前很多国内大多数DBA还停留在Oracle 9i或者10g，究其原因有可能是Oracle 11g的价格问题影响到了其没有得到广泛应用。但有少数使用过Oracle 11g的用户反应在Windows 7系统下安装新版本Oracle 11g会出现兼容性问题，无法正常安装数据库系统，而在其它系统中比如Window 2008中就不会安装过程就不会出现兼容性问题。最近笔者也遇到这样的问题，笔者查找了相关官方资料和进行多次试验，成功地在Windows 7中安装了Oracle 11g数据库系统，下面就和大家共同分享在Windows 7下安装Oracle 11g系统的有关解决问题的心得，也希望大家能从中了解到Oracle 11g的一些新技术特点。


解决操作系统版本兼容性

在Window 7系统下，和以往安装Oracle版本一样运行安装程序，启动安装向导。向导第一步就是运行安装环境先决条件检查，自检后却提示系统不兼容问题，弹出一个错误对话框，提示“一些必需的先决条件检查失败，请先确保系统满足所有要求，然后继续安装。”根据安装环境先决条件的检查结果显示为：“要求的操作系统为5.0,5.1,5.2,6.0之一，而实际结果为6.1”，安装向导不能继Oracle续数据库（如图1）。

图1

笔者查阅了相关Oracle官方资料后得知，该环境检查报告表示该版本的Oracle和当前的操作系统版本有兼容性问题，官方给出的建议是升级服务器操作系统版本就可以解决该问题。既然因为操作系统版本的问题导致了数据库无法安装，笔者想到肯定在环境先决条件检查前可以用修改操作系统版本特征和类型来欺骗Oracle安装向导的检查，而后就可以正常安装Oracle数据库，并且也不会影响到使用。经过多次试验，方法就是在Oracle 11g的安装在路径：“\Oracle Enterprise_Standard Edition_11.1.0.7\database\stage\prereq\db\refhost.xml”中找到”refhost.xml“文件，用记事本的方式打开该文件，打开之后可以找到如下节点：

{

<!--Microsoft Windows Vista-->

<OPERATING_SYSTEM >

<VERSION VALUE="6 .0"/>

}

把上述节点的内容修改为以下为以下信息：

{

<!--Microsoft Windows 7-->

<OPERATING_SYSTEM >

<VERSION VALUE="6 .1"/>

</OPERATING_SYSTE M>

}

修改完成后，保存文件并退出。接下来运行“setup.ex”安装Oracle 11g，在进入到”产品特定的先觉条件检查“的安装界面时，安装向导仍然会和前面安装过程一样提示“一些建议的先决性条件检查失败，系统的兼容性检查不通过”，与前面不同的是向导会弹出的是“警告”窗口，如图2所示，而不是先前的“错误”窗口，在“警告”窗口上单击“是”按钮，然后点击”下一步“继续安装，接下来安装程序就进入到下一个安装程序。

图2

此后的安装步骤就比较简单，和安装Oracle 10步骤一样，点击”下一步“继续，进入Oracle的安装界面，如图3所示。

图3

安装到这里整个Oracle安装程序可以说安装成功只是时间问题而已了，安装系统默认设置继续点击“安装”按钮进行Oracle的安装，这时Oracle安装程序将会配置和启动先前所选的组件，而后继续按照系统默认设置进行安装。在等待Configuration Assistant配置完毕后，就会将数据库系统正式安装到我们的计算机硬盘上，而后进入到Oracle数据库的启动和创建界面，在Oracle数据库创建完之后就完成了对Oracle数据库的安装，一直按照系统默认设置安装到最后的Oracle的完成安装界面，表示已经彻底完成了安装好了Oracle 11g数据库。这里要注意的是，要在该安装界面窗口上修改“scott”账户口令，因为在新版本的Oracle 11g中，“scott”账户默认是锁定的，如果想像以前一样使用"scott"账户进行登录的话，就必须在完成安装界面上单击”口令管理“按钮对“scott”账户进行解锁。解锁过程也比较简单，单击完成安装界面上有“口令管理”的按钮，在解锁界面上的“是否锁定账户？”选项选中，在口令设置中输入新的口令，点击“确定”按钮，完成对Oracle的安装和账户的解锁。

在安装程序完成后，就可以运行Oracle 11g。但在初次运行数据库时，首先必须传入java运行文件“java.exe”，如果没有安装JDK请到sun公司的官网下载对应的JDK文件，这里就不进行描述。在成功传入“java.exe”运行文件后，就可以到登录页面，以系统管理员账号登录后就进入到Oracle 11g的界面，到此Oracle 11g的安装程序就全部完成。


写在最后

笔者经过查找相关资料和多次试验在终于在Windows 7笔记本电脑上成功装上了Oracle 11g企业版。解决方法也比较简单，只是简单地将Oracle的安装文件中有关先决条件检查文件进行修改，让其适应Windows 7旗舰版系统，就能继续安装Oracle 11g数据库。希望本文中用到的解决方法对大家有所提示和帮助。
