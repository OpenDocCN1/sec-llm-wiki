# 【IT没有圈】硅谷“人渣”遭解雇 称前女友不忠

在刚刚过去的这个周末，美国广告技术公司RadiumOne首席执行官兼董事长古尔巴什·查哈尔（Gurbaksh Chahal）被这家他亲自创立的公司解雇。查哈尔在承认家庭暴力和殴打指控之后，RadiumOne董事会决定解雇他。此前他曾经被指控117次殴打他的女友，而且部分指控有视频为证。

查哈尔辩称，尽管他有时候会对前女友朱丽叶·卡基什（Juliet Kakish）发脾气，但他并没有117次殴打她。查哈尔还表示，当得知她“为了钱与其他人发生性关系后”，他非常生气。

在这起争议事件中，卡基什没有公开发表任何声明。在周末发表的一篇博客文章中，查哈尔声称“她被警方提出的虚假指控吓住了”。最终，查哈尔避免了牢狱之灾，所有45项重罪指控都没有成立。

卡基什是一名美容师，她在洛杉矶有一个美容沙龙。她没有就查哈尔的指责发表声明。

这并不是查哈尔唯一一次与人对薄公堂。去年夏天，查哈尔起诉了他的助理拉菲尔·罗哈斯（Rafael Rojas）和司机厄尔多根·艾克苏（Erdogan Aksu），指控他们从自己手中挪用了大笔资金，并且诽谤他参与不道德行为。

不过到8月份，查哈尔要求放弃诉讼，说明这起事件出现了和解的可能。不过在诉讼期间，提交到法庭的一些文件相当有趣。一份由查哈尔提供的文件显示，罗哈斯曾经警告董事会称，这位RadiumOne CEO参与了包括卖淫在内的诸多“违法行为”。

这份邮件于2013年6月9日发送到了RadiumOne董事会成员比尔·罗纳根（Bill Lonergan），后者现在已经是这家公司的CEO。下面是这封邮件的内容节选：

“如你们所知，古尔巴什过去曾经越过红线，尤其是卖淫。但现在我要告诉你们的是，他还参与了毒品使用，包括曾经试图让我服用安非他命和其他非法药物。他还试图让我给女孩使用毒品（在她们不知情的情况下），确保她们不会怀孕。”

查哈尔对这些指责全部予以否认，他对法庭表示：“这封电子邮件里的内容，尤其是关于非法毒品使用、卖淫和盗窃知识产权的内容，不仅是虚假的，而且试图掩盖资金的流向。这些内容同时也构成了诽谤，希望攻击我在公司和其他地方的信誉和声望。”

这起诉讼，与去年夏天晚些时候朱丽叶·卡基什发起的诉讼之间是否有什么关系，这一点尚不清楚。去年夏天查哈尔被捕的时候，卡基什曾对警方说，查哈尔在8月5日被捕前曾经殴打她，并且在2013年7月4日粘住了她的嘴。针对罗哈斯和艾克苏的民事诉讼似乎已经于2013年7月5日结束。
