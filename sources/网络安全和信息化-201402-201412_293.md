# 【实用文章】“双网互通”轻松搞定

**【导读】为了提高企业内部网络的安全性，各单位总部和分公司之间构建业务专网，已成为当前的一种发展趋势。本文以作者单位为例，详细地讲述了配置静态路由实现双网互通的操作方法。**

  

企业网络在接入网络时，分为外网和专网。外网主要用于员工访问互联网，业务专网则用于公司内部办公系统。员工PC首先接入到交换机上，再由交换机分出两条线路分别连接外网和专网路由器。网络拓扑如图1所示。

外网和业务专网在用户PC端均采用配置固定IP地址、子网掩码、网关等相关参数的方法接入。要接入双网最直接的方法是在PC上安装两块网卡，配置各自的网络参数，专网和外网分别接入。但员工的PC一般只配置一张网卡，再添加新网卡不仅需要相关经费，而且还要拆箱安装，也不方便维护。那么在不改变原有网络结构的基础上，一张网卡能不能同时接入外网和专网，并且能同时使用呢？

我们知道，一张网卡是可以同时配置两个IP地址、网关以及DNS的，这也是我最初想到的方法，我们不妨一试。实际配置却发现，最终只能有一个网关在起作用。这也不难明白，因为PC一般情况下只能和一个默认网关进行通信。那么有没有办法使PC也能和另一个网关通信呢？方法还是有的，我们可以在PC上添加静态路由来实现。我是这样做的。首先，根据当前的网络结构，外网路由器和专网路由器都同时接到用户交换机上，两个设备的内网口地址，也就是PC的两个网关和PC都处于同一网段。比如外网路由器的网关地址为：192.168.1.1专网路由器的网关地址为192.168.1.254子网掩码都一样 255.255.255.0在PC上 我保持原来的外网参数配置不变，以我自己的PC为例，IP:192.168.1.23子网掩码：255.255.255.0网关：192.168.1.1（还保持原来的外网路由器的网关地址）DNS:X.X.X.X这样做暂时还只能上外网。接下来，在命令行里面，我可以通过添加静态路由，使要访问专网的业务系统通过静态路由接入专网路由器，连接到业务专网上去。静态路由配置方法如下：

route -p add 192.168.2.0 mask 255.255.255.0 192. 168.1.254

route -p add 192.168.3.0 mask 255.255.255.0 192. 168.1.254

route -p add 192.168.4.0 mask 255.255.255.0 192. 168.1.254 

在这里使用“-p”参数 可以使添加的静态路由永久保存到PC中，即使PC重启后，路由条目仍然存在。由于单位员工的PC数量比较多，一台台添加起来比较耗时间，而且可能出错，我们可以做一个批处理程序 批处理脚本如下：

@Echo Off

route -p add 192.168.2.0 mask 255.255.255.0 192. 168.1.254

route -p add 192.168.3.0 mask 255.255.255.0 192. 168.1.254

route -p add 192.168.4.0 mask 255.255.255.0 192. 168.1.254

先用记事本写入，最后保存成后缀名为.bat的脚本文件，放到共享服务器上，供员工下载执行。这样做既能提高工作效率，也减轻了网络管理员负担。最后经过实际测试，两网都可以同时访问。

经过这次实践，我发现在一般情况下PC都是通过默认网关与外界进行通信的，但是当用户PC需要访问专网时，PC便会查找当前存在的路由信息条目进行转发。这一点我们可以在命令行下面键入“netstat–rn”查看有哪些可用的路由条目。这样在不改变当前网络结构的前提下，只要我们在用户PC上稍作修改，一台PC就可以同时接入两个不同的网络里。可见有些问题虽然表面上不好解决，但只要我们肯开动脑筋，理论结合实际，还是可以迎刃而解的。
