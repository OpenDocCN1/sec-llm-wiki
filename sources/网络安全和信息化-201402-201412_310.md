# 【实用文章】巧用iSCIS为服务器扩容

**【导读】很多单位在使用服务器主机做大存储服务器（如VOD点播服务器、资源管理服务器）时，往往会因存放资源过多而导致服务器空间不足。这样如果不删减资源，就只能增加硬盘了。我们都知道，服务器上的硬盘价格昂贵，对于小型企业来说是一份不小的开支。如果单位有多台服务器并且有富裕的硬盘空间，或者单位内有一些淘汰的主机或服务器，这些设备如果处于闲置状态，我们可以将这些主机的磁盘集中起来为服务器扩容。**

  

在这里我们讲的磁盘扩展，是通过iSCSI技术来实现主机磁盘的集中管理，这样，可以将不同位置主机上的部分磁盘空间，通过虚拟磁盘的方式挂载到指定的服务器上，来实现服务器磁盘扩容（如图1）。

![](../Images/b893f532d389d88691003a07c11b1414.png)

图1

在这里，我们将为VOD服务器提供虚拟空间的主机称为ISCSI服务器。而扩容的服务器（如VOD服务器）称为ISCSI客户端。要实现iSCSI技术磁盘扩容，我们先确保服务器端和客户端都处于同一局域网内。下面我们来了解一下具体操作。

  

** 安装iSCSI服务器**

iSCSI服务器端可以安装到Windows Vista及其以上的系统中，可以登录到微软网站去下载，程序名称为Microsoft iSCSI Software Target。程序分32位和64位两个版本。

目前新发布的Windows Server 2012系统集成了iSCSI服务器功能，我们可以直接安装即可。本文就以最新操作系统Windows Server 2012（以下简称ws2012）为例来了解一下操作过程。

启动ws2012系统，打开“服务器管理器”界面，在“仪表盘”界面中选择“添加角色和功能”命令。打开“添加角色和功能向导”对话框，在默认状态下单击“下一步”按钮，进入到“服务器角色”列表中，在此展开“文件和iSCSI服务”，并勾选下面的“iSCSI目标服务器”，如图（如图2）。

![](../Images/49979250632fb95dbd358e519a9f06f0.png)

图2

随后连续单击“下一步”按钮即可完成安装。

  

**创建iSCSI虚拟磁盘**

iSCSI服务器添加完成后，我们就可以在iSCSI服务器上创建虚拟磁盘了。启动“服务器管理器”，单击服务器管理器界面左侧“文件和存储服务”，打开“服务器”窗口，在此点选“iSCSI”打开“iSCSI虚拟磁盘”界面。在该界面中，我们就可以创建虚拟磁盘了。

单击界面中的“要创建iSCSI虚拟磁盘，请启动新建iSCSI虚拟磁盘向导”链接，打开“新建iSCSI虚拟磁盘向导”窗口。

在“iSCSI虚拟磁盘位置”界面选择“虚拟磁盘”保存的分区，如D盘。单击“下一步”按钮，在此输入创建虚拟磁盘的名称，随后在下面的“路径”中我们可以看到该虚拟磁盘的文件后缀为VHD。

单击“下一步”按钮，在打开的界面中指定虚拟磁盘的大小，在此系统给出了当前分区的大小，在此我们可以根据需要输入即可。

接着单击“下一步”按钮，进入到“创建iSCSI目标”界面，在此点选“新建iSCSI目标”选项，随后继续点击“下一步”按钮，在“指定目标名称”中自行输入一个目标名称。

单击“下一步”按钮，进入到“指定访问服务器”界面，在该界面中单击下面的“添加”按钮，打开“选择用于标识发起程序的方法”对话框（如图3），在此点选“输入选定类型的值”选项，并在类型中选择“IP地址”，随后在右侧的文本框中输入iSCIS客户端IP地址。

![](../Images/4fd80defca4e14e5bf74ccd594565311.png)

图3

添加后单击“确定”按钮，随后单击两次“下一步”按钮后，在“选择确定”界面单击“创建”按钮，完成创建向导，在此我们可以查看到创建结果（如图4）。

![](../Images/c31b98bfbf32c4b7279328403fcf3a8b.png)

图4

根据需要我们可以在不同的iSCSI服务器端创建其他虚拟磁盘。

  

** 挂载虚拟磁盘**

在iSCSI服务器端虚拟磁盘创建完成后，接下来我们就可以在iSCSI客户端挂载虚拟磁盘了。下面为了区分操作，iSCSI客户端我们以Windows 8系统为例，在Windows系统安装后系统会自动在“控制面板”的“管理工具”中集成了一个“iSCSI 发起程序”，通过这个程序我们就可以为服务器端挂载虚拟磁盘。

  

提示：Windows Server 2012系统中的“iSCSI 发起程序”位于“服务器管理器”界面下的“工具列表中。”

  

默认情况下,“iSCSI发起程序”没有被启动，双击“iSCSI发起程序”系统会提示启动该程序，在此单击“是”按钮即可启动。

随后打开“iSCSI发起程序”对话框，在“目标”项下的“目标”文本框中输入刚刚创建的虚拟磁盘的IP地址，随后单击右侧的“快速连接”按钮即可将该主机的虚拟磁盘信息添加到“已发现的目标”列表中，在此可以添加多个虚拟磁盘（如图5）。

![](../Images/5e50deec4acbfd5fe541e949cf78752a.png)

图5

如若以后断开某个主机的虚拟磁盘，在该列表中选择目标名称并单击“断开连接”按钮即可。

切换到“卷和设备”界面中，单击“自动配置”按钮，iSCSI发起程序对添加的虚拟磁盘进行自动绑定，这样以后重启系统也不会丢失当前虚拟磁盘。随后，单击“确定”按钮退出设置。

通过上面的操作，虚拟磁盘已经在iSCSI客户端挂载成功。随后我们在桌面右键单击“计算机”图标并选择“管理”命令，在打开的“计算机管理”界面中单击左侧的“存储→磁盘管理”选项，打开磁盘管理对话框，在此我们可以看到我们刚刚添加的两块虚拟磁盘已经显示在磁盘管理列表中，在此对其进行格式化、分区等操作即可使用了（如图6）。

![](../Images/5d025b1e9de8d7d94e0205b3121b8cdd.png)

图6

通过上面的操作，实现了服务器扩容，这样我们就可以确保大存储服务器正常运行了。iSCIS技术实现的主机扩容，实际上就是一个基于IP环境下的资源分散管理模式，也就是说，通过主机挂载虚拟磁盘后，该主机的资源可以分散保存到其他主机磁盘中，这样即实现磁盘扩展功能，还实现了数据的分散管理，一旦某一个主机宕机或磁盘损坏，它只会影响该虚拟磁盘中的数据，其他主机可以继续工作，确保了数据的安全。
