# 【焦点关注】临死再捞一把：XP仍能给微软带来巨额收入

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200146524&idx=2&sn=3df9a26c6f82a11d1914a7d0b5eb4af2&chksm=288077401ff7fe56c91924912ff1c91bf9dfe2b0ab373898a0626c440a5663c9820f16330fc5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200146524&idx=2&sn=3df9a26c6f82a11d1914a7d0b5eb4af2&chksm=288077401ff7fe56c91924912ff1c91bf9dfe2b0ab373898a0626c440a5663c9820f16330fc5&scene=27#wechat_redirect)

虽然微软早在2010年便终止销售Windows XP操作系统（以下简称“XP系统”），并在今年4月8日正式停止对进行该款操作系统进行技术支持，不再修补XP系统的安全漏洞，但是XP系统依然给微软能够带来巨额的收入。

这是因为根据移动设备管理公司Fiberlink的统计，大约44%的企业用户依然在使用XP系统。通过与微软签署的客户支持合同，微软仍将会向签订协议的企业用户提供XP系统的安全漏洞补丁。不过这些企业用户必须付费来获得安全补丁。市场调研公司Gartner分析师迈克尔·西尔弗（Michael Silver）表示，微软此前向企业用户在第一年收取20万美元，便可以获得其支持合同。

但是在XP后时代，微软上调了收费标准，目前向每台设备收取大约200美元的费用；而且在第二年和第三年，客户支持合同的价码会大幅上涨。西尔弗表示，微软的一位拥有5000台PC的企业客户透露，该公司今年向微软支付了100万美元的支持费用，明年价码将提升至200万美元，第三年将提升至500万美元。

微软早已签订了一些客户支持大单。其中，英国政府与微软签订了一份大约为920万美元的协议，让该公司继续支持所有英国公共领域客户的XP系统、Office 2003和Exchange 2003；荷兰政府与微软签订了一份数百万欧元的合同，支持该国政府的超过3万台计算机；美国国税局与微软签订了一份不低于50万美元的协议，支持该机构大约5.8万台XP系统设备；全球的许多银行均与微软签订了协议，以支持他们的XP自动取款机

虽然微软仍获得了大量的支持协议，但是这些对该公司当前的旗舰操作系统Windows 8而言并不是什么好消息。有趣的是，微软把客户支持合同视为对客户的“最后手段”。微软就此发布声明称，“客户支持主要提供给在2014年4月8日之前仍在使用XP系统的企业客户。它只是一种临时手段，用于帮助大型客户完成复杂的操作系统转换工作。它应当被视为对客户从XP系统转向现代系统的最后手段。”
