# 【十点速递】解决方案：“心脏出血”来袭 普通的我们能做些啥？

最近“心脏出血”这个名词冲上了诸多媒体的头条，中央电视台的新闻1+1节目专门做了一期关于“心脏出血”的详细报道，一时间在网民之间引发恐慌。虽然绝大多数的人对“心脏出血”的技术原理并不清楚，更多来源是来自于煤体的介绍，恐慌的根因是因为自己所有隐私包括登陆网站的用户名/密码，网上银行帐户/密码等可能都将变得不安全。“心脏出血”的原名叫“Heartbleed bug”，也有人叫“击穿心脏”，是来自OpenSSL的紧急安全漏洞警告。采用这样的名字也是为了说明这个漏洞的严重性，因为“心脏出血”已经被认为是互联网历史上最为严重的网络安全漏洞。OpenSSL是一个强大的安全套接自层密码库，是一种开源软件包，囊括了主要的密码算法、常用的密码和证书封装管理功能以及SSL协议，是一种网络加密安全协议，在各大网银、在线支付、网站、电子邮箱、网络设备加密等方面有着广泛使用。这次“心脏出血”是OpenSSL存在的一个软件BUG，当攻击者构造一个特殊的数据包，满足用户心跳包中无法提供足够多的数据就会导致Memcpy把 SSLv3记录之后的数据直接输出，这样攻击者可以远程读取服务器内存中长达64K的数据，这个数据获取到的是随机的，不一定是隐私信息，所以只有反复获取才能拿到自己想要的数据。这个软件BUG在OpenSSL两年前发布的软件版本中已经存在了，使用OpenSSL新版本的服务器和网络设备都存在这个问题。

  

在4月9日“心脏出血”爆出以来，各大网站、电商、银行就开始对涉及BUG的服务器进行修复，而广大的网民除了担心还是担心，束手无策。其实，“心脏出血”的确问题严重，但也不至于如此，更多的还是来自安全厂商和媒体的过度宣扬，安全厂商这样做无非是人为制造恐慌气氛，达到推广安全产品的目的，这是一次推广自己产品的好机会，而媒体更是通过大肆报道主要目的是为了吸引眼球，这样人为制造紧张气氛，增加受关注的程度。实际上，几乎天天都会出现一些系统安全漏洞，在网络运营企业基本都形成了发现漏洞、系统升级、补丁修补等一系列完整的流程，经常要进行漏洞的修补。当发现漏洞时第一时间进行修复，消除影响。“心脏出血”只是影响面更广一些，涉及到银行帐户、密码等敏感数据的泄露。但也不是知道这个漏洞就一定有能力来获取到数据，这要求利用漏洞的人要具备较深的技术水平才能从泄露的数据中获取到隐私数据。OpenSSL的漏洞已经存在了两年，直到今天才被公布，从这两年的时间看并没有大量数据的异常泄露，显然并没有人提前发现这个漏洞，或者就算知道并没有利用这个漏洞去获取隐私数据和破坏数据。当OpenSSL公布漏洞后，各大网站、银行都在积极修复，所以应该不会对普通网民造成什么影响，不必过分担忧。

  

**那么作为普通网民我们还能做什么呢**，难道只能碰运气，坐等？当然不是，只有我们主动的访问了这些存在漏洞网站、设备，才会将隐私登陆信息临时存放到服务器的缓存中，在网站修复之前信息泄露随时都存在。服务器如果曾经发生做过重起，或者业务变更，这些保存在内存中的临时数据也会消失。所以首先要回忆一下最新是否使用过这些网站使用过交易，时间越久则风险就越低。如果频繁使用网上支付，建议直接到银行营业厅将网银密码修改，帐户转移，检查帐户资金是否安全，密切关注自己经常访问的网站的公告。

  

要养成良好的上网习惯，不了解的网站不进行访问。不随意点击网站弹出的各种广告，不随便安装各种恶意软件。在“心脏出血”爆出后，很多正规大型的门户网站都会及时更新软件，消除漏洞。但是对于一些小型网站，由于其自身技术能力有限，无法及时更新软件，导致长时间修复，此时访问这些网站就容易将自己的隐私信息暴露给别人。

  

在http://filippo.io/Heartbleed/网站可以对各个网站是否存在“心脏出血”漏洞进行测试，验证自己访问过的网站，这里指使用自己注册帐户登陆的网站，如果显示为红色就说明存在风险，暂时不要进行任何的访问。同时要关注这些网站发布的安全漏洞消息，还可以直接致电网站支持人员，以确保自己的帐户信息安全。

  

要及时修改访问密码，对密码进行重新设定，根据行业默认的标准，对于任何的帐户密码应该每6个月更换一次，而且禁止是否简单的数字来设定密码，这样将大大降低帐户被攻破的可能性。

  

由于网上银行交易都强制要求客户安装U盾，这是使用商业级的SSL加密设备，而不是OpenSSL 这种开源软件，所以不存在这类问题，所以使用银行卡进行网上支付的大可放心。还有很多实力比较强的网站也采用商业的加密技术，比如支付宝，所以也不存在这类问题，听到这样的消息是不是心里稍许可以平静些了。不过一些网站上注册的个人信息就可能存在泄露的风险，这个“心脏出血”暴出后，“黑客”和“白帽”你盗我堵都在的疯狂赛跑，广大网民的信息能否保得住就看这些“白帽”的了，这个普通网民只能做观龙虎斗，干着急出不上力气了。

  

自古以来，邪不胜正，相信这是第一次互联网行业面临的全面危机，本来网络安全就饱受质疑，此次危机能否处理得好，将关系着互联网的未来。在这场危机面前我们普通的网民既是无辜的受害者又是弱视群体，希望这些互联网的企业能够及时修复漏洞，不要在网民的伤口上撒盐。
