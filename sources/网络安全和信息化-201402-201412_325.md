# 【十点速递】Windows 8.1难以撼动Windows XP地位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200137320&idx=1&sn=1191049272ca02240bc0d10b5106e2aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200137320&idx=1&sn=1191049272ca02240bc0d10b5106e2aa&scene=27#wechat_redirect)

4月11日消息，据国外媒体报道，Windows 8.1的触屏风格与其桌面界面并不和谐。虽然这一版本升级发布在微软宣布停止支持Windows XP的同一天，但如果升级的目的是想让人们不再使用Windows XP，那么很明显微软失败了。

Windows 8.1 Update增加了一些实用的新功能，以求在触屏风格开始屏幕，Metro应用程序，以及适用于传统键鼠的桌面之间达到统一。如今，Metro应用程序能够出现在任务栏上，并且被固定。而任务栏同时也可以出现在开始屏幕上。

对习惯使用键鼠的用户来说，Windows 8.1 Update的这些变化使其具有比以往更好的界面。但这不足以使Windows XP用户选择升级。首先，许多XP用户很明显并不喜欢改变，因为其已经使用了这款操作系统太长的时间。即使Windows 8.1 Update的界面看起来更统一，但其开始屏幕（Start screen）和Metro应用程序与XP相比仍然大相径庭。

其次，能够运行Windows XP的电脑不一定跑得动Windows 8.1。从技术层面上来说，XP时代的电脑已经落后如今的电脑许多代了。

有许多原因使得用户不愿意放弃XP，即使这款操作系统不再得到微软的支持服务了。主要原因在于，Windows XP能够满足用户工作的需要，而Windows 8.1 Update并没有使用户产生别的需要，因此用户依然愿意选择XP。

微软在Windows 8.1 Update上做得很好，但Windows XP用户根本毫不在意。
