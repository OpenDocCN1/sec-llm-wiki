1. Windows Phone 8.1 正式发布， WP 粉吐气扬眉。微软举行的 Build 2014 开发者大会，发布了人们期待已久的 Windows Phone 8.1 系统，新增 Cortana 语音助手、Action Center 通知中心等多项功能。同时微软还发布了 3 款运行 WP8.1 系统的 Lumia 手机，分别是 Lumia 930、Lumia 630 以及 Lumia 635。


2. Windows 向 9 英寸以下设备免费授权，Windows 跨平台应用开发。Build 2014 开发者大会，微软同样宣布 Windows 系统将向 9 英寸以下的设备开放免费授权，同时推出多平台开发标准 Windows Universal App、触摸板 Office 以及 Kinect V2 for Windows。


3. 亚马逊发布 Amazon Fire TV：既是机顶盒也是游戏机。亚马逊（Amazon）也发布了最新的流媒体机顶盒 Amazon Fire TV，电视机顶盒市场又多了一个强劲的参与者。针对 Amazn Fire TV，亚马逊同时推出了一个游戏手柄，售价 39.99 美元，附送 1000 个 Amazon coins，用于购买游戏。亚马逊表示，目前付费游戏的平均价格仅为 1.85 美元，超过 1000 款游戏免费提供。


4. 中移动回应香港 68 港币套餐质疑，便宜未必吃香。中移动在香港推出的 68 港币通话套餐最近引起争议，中移动回应称，这款套餐只能称为限速套餐，相比只有香港现有 3G 网络网速的百分之一。同时，相比该套餐诸多限制，香港其他电信营运商推出的类似 3G 限速套餐则很少限制，因此中移动香港的套餐对港人而言未必吃香。


5. 网络信号预计半年后覆盖公交车，坐公交可免费上网。深圳广电新媒体中心日前举行新闻发布会，正式宣布新一代智能公交 Wi-Fi 机顶盒面世。预计半年后，深圳巴士集团的公交车将完成覆盖免费网络信号，为乘客提供免费上网的环境。
