# 【解决方案】Windows XP寿终正寝 我们还剩下哪些选择？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200120314&idx=2&sn=763282bac94425949c7c3613d28a21fd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200120314&idx=2&sn=763282bac94425949c7c3613d28a21fd&scene=27#wechat_redirect)

        最早于2001年推出的Windows XP操作系统终于即将“退休”。微软此前已经明确表示，公司将在2014年4月8日后不再为XP操作系统提供新的安全升级、非安全性补丁、免费或付费辅助支持及在线技术文档更新。

  

        虽然这一于上世纪90年代就开始研发的操作系统已经14岁高龄，微软也在此后推出了数款更新的操作系统，但该系统却依旧占据了全球高达10%的系统份额。而且，在Windows XP巅峰的时候，全球共计有超过4亿人在使用该操作系统。

  

        日前，美国科技媒体就为还坚守在XP平台的传统用户提供了几个在XP退休之后的解决方案。

  

**1、继续坚守**

  

        虽然微软会在4月8日停止为XP提供更新，但这并不意味着该操作系统就会在一夜间消失。如果你愿意的话，也大可以忽略微软发布的安全警告和潜在风险而继续使用这一系统。

  

        但需要指出的是，如果用户选择这一方案的话，电脑可能将无力抵抗新型病毒的入侵。因此，我们建议用户至少也要使用Windows XP的最新版本,即Windows XP Service Pack 3。

![](../Images/ce8bc7341fcabe2192128b1e9d9e4fc7.png)

      

        **2、升级Windows 8**

  

        当然，用户也可以如微软所愿将操作系统升级至Windows 8，但这一方案也并非完美无暇。第一，你所使用的老旧Windows XP可能没有足够的空间、运算能力运行Windows 8。第二，你可能无法完全适应采用了全新操作风格的Windows 8。尽管你可以通过设置的方式尽可能避免使用Windows 8主推的磁贴界面，但这一界面还是会时不时的出现在用户面前。

![](../Images/0ae6c95fef683532d0502810db9eb313.png)

        

        **3、转投Linux**

  

        素有“极客系统”之称的Linux以其稳定性、免费和处理速度著称。更为出色的是，Linux系统将完全可以基于用户老旧的Windows XP设备之上运行，其运行速度相比Windows 8也会更加出色。

  

        但是，“极客系统”自然不会是浪得虚名，因为用户许多常用的Windows软件都无法在这一系统上运行。所以，我们仅仅推荐拥有一定编程知识的用户尝试这一系统。

![](../Images/3d6678e0b682735f04c57e228c42cf16.png)

        

        **4、转投Chromebook**

  

        以网页为中心的Chromebook售价适中、拥有众多在线应用，且内置了非常人性化的分享机制。但是，Chromebook在日常使用中严重依赖于网络连接才能够正常使用，该平台的大部分应用也都无法离线运行。而且，诸如Photosho、Quicken、iTunes这些Windows平台常用应用都无法兼容Chromebook。因此，现阶段的Chromebook还无法完全替代Mac和Windows。

![](../Images/ccbac3b360607d607a720e0dcb0d63f7.png)

        

        **5、升级至Windows 7**

  

        早于Windows 8之前问世的Windows 7的确是一款非常出色的操作系统，该系统非常稳定，且同Windows XP之间有着非常类似的操作方式。不过，就操作系统需求而言，Windows 7所需要的计算机硬件性能甚至比Windows 8还更加高一些。

  

        但可以肯定的是，微软方面肯定是更加希望用户选用Windows 8，因为该公司发言人曾不止一次的表示，“Windows 8相比Windows 7更加安全、快速，也更加节能”。

![](../Images/457ac8de87888beedd8af11adf261801.png)

        

        **6、转投Mac**

  

        颇为讽刺的是，如果一定要Windows XP系统用户转而使用更新系统的话，我们相信Mac OS X相比Windows 8.1会是一个更好的选择。就操作方式而言，Mac OS X相比Windows 8.1更加类似于Windows XP，因此用户可以更快的适应这一系统。此外，大多数Windows平台应用如今都推出了对应的Mac版本，因此用户也完全不必担心软件方面的问题。如果说这一方案存在任何问题的话，Mac设备较高的市场售价或将成为许多消费者的门槛。

  

        目前，Mac系列中最便宜的Mac Mini售价为600美元（用户需要自备鼠标、键盘和显示器），而入门级别笔记本和台式机的售价则分别高达1000和1300美元，远远超过如今Windows PC设备300-600美元的普遍售价。
