# 【科技不怕问】Windows在PC端份额下滑已不可逆转？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=200092520&idx=2&sn=f53f89983ba3db0fc4614a838e5917a1&chksm=2880a2741ff72b62e003bda49760a4ae15129d1bd51703b5c30306561087468daa052c9b8fd3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=200092520&idx=2&sn=f53f89983ba3db0fc4614a838e5917a1&chksm=2880a2741ff72b62e003bda49760a4ae15129d1bd51703b5c30306561087468daa052c9b8fd3&scene=27#wechat_redirect)

**        网友“优优哥”：**

        不知是不是我太落伍，我上月新装的台式机，还是用的Windows操作系统。但今天看到说微软在台式机操作系统份额跌破90%，还挺意外，难道我选错了？

  

        **回答：**

  

        选什么操作系统，完全是按你个人喜好和习惯而定。但微软操作系统在台式机市场份额破90%，至少说明消费者开始青睐其他品牌的操作系统产品。

  

        传统的台式机市场会把笔记本算在内。按Net Marketshare的统计数据显示，微软今年3月份在台式机操作系统市场的份额为89.96%；StatCounter的统计数据则显示微软的份额为89.22%。而在2008年时，Windows操作系统在个人设备市场的份额高达95%。

  

        造成微软在台式机操作系统市场的份额下滑的原因是多方面的，但主要原因还是微软操作系统在笔记本和台式机市场的流行正在逐步衰退。

  

**        苹果谷歌(微博)增速快**

        如果看Net Marketshare的数据统计：苹果Mac操作系统的市场份额，自2000年以来增长一倍以上，从2000年10月的2.84%，升至2014年3月的8.34%。

  

        这组数据相较微软尽管仍是大巫见小巫，但至少可以说明，苹果公司在移动端强势品牌推广下，带动了原有的PC业务，导致了苹果操作系统Mac OS X被更多人使用。

  

        随着移动端和PC端的界限正在模糊，Mac OS X和手机iOS之间还具有良好的协同性和云共享功能。从实用角度出发，不难理解为何用户会倾向于选择Mac OS X。

  

        也正是这一点，让谷歌开始在PC市场尝到了甜头。Net Marketshare的数据统计，同期Linux操作系统的市场份额同期也从0.62%升至1.76%。要知道现在Linux操作系统在PC领域的最大玩家是谷歌Chromebook笔记本，包括联想、惠普、三星、宏碁等厂商都推出了Chromebook。

  

        针对入门级PC市场的Chromebook，其最大特点是，在联网环境下实现页面浏览、在线文档处理、使用社交网络及跨平台应用等等。但这款上网本在单纯的硬件配置上并不具有优势，且强烈依赖网络环境。因而谷歌为此与电信运营商合作，给Chromebook设计移动流量套餐捆绑，这样的驱动下，让运营商实现了效益。另一方面也满足了行业用户的基本需求：上网浏览、聊天视频、基本办公处理、简单游戏操作等。且能与移动端系统打通，协同作业。

  

        如果从出货量来看：NPD集团的数据显示，Chromebook在商用领域的出货量从2012年的40万台翻了四番，达到2013年的176万台。截止2013年末，Chromebook在商用领域的占有率已经达到9.6%。尽管Chromebook OS在IDC统计中，仅占1%的市场份额，但它在教育、中小企业行业的青睐，也说明需求市场正不断扩大。当然200多美元的价格，也确实有竞争优势。

  

      **  Windows 8体验不佳**

        回过头来，我们看看微软在操作系统的地位为何会被动摇。首先是大环境所致，近些年来桌面和笔记本市场长期萎靡不振，虽然2013年下半年在欧美等部分市场出现了回暖；但整体颓势并未得到根本性的改变。

  

        Windows 8是一款适用于平板+PC的操作系统，如果你自己用过windows 8是不是也有这样的体会？比如没有菜单功能，界面切换生硬、主要功能隐藏太深，使用不流畅等等。Windows 8虽然在去年8月市场份额一度超过苹果（从5.4%飙升到7.41%），往后并没有保持这样势头，在11月下跌了0.87个百分点。

  

        下跌的原因是，用户对选择Windows 8持谨慎态度，且手机与平板电脑又分流了一部分用户。尽管微软增大了Windows8预装市场推广力度，但效果乏力。Net Applications截止3月的统计数据显示，Windows 8跌了0.25个百分点（从6.63%跌到了6.38%）。简而言之，windows8不受市场青睐，一方面是它产品设计并未充分考虑用户体验，产品推广力度不见效。

   

        当然微软去年10月推出的Windows 8.1弥补了Windows 8产品体验上的尴尬，比如在产品上增加了“菜单”设计，以移动端为特色等等。但PC操作系统与移动端WP系统打通依旧进展缓慢，虽然微软已经开始为部分手机厂商免去授权费等，用免费策略推动Windows8.1等，但整体增速差强人意。

  

        不过好消息是，截止今年3月，Windows8.1则增长了0.35个百分点（从3.95%增长到了4.30%）。

  

        简而言之，在未来的操作系统大战中不再有PC、移动的割裂之说，硬件的优秀并不意味着受到用户的垂青。“快速联网、永远在线”的电子消费产品，首要想到的是如何提供给用户高效快捷轻便的产品与服务。微软现在仍是操作系统霸主地位，但已经不能坐以待毙。
