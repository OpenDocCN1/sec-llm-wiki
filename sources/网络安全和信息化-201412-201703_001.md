# 智简•全覆盖：D-Link发布全新品牌主张

进入2017年，刚刚度过而立之年的D-Link携全新品牌主张“Covr——智简·全覆盖”强势归来，以全新品牌主张和产品矩阵，为全球用户提供更加高效、便捷、智慧的互联网体验。进一步彰显“以人为本”的品牌价值观。

 

**勇于创新：而立之年打造全新面貌**

 

据了解，自1986年创立以来，D-Link始终致力于为用户提供专业品质、安全便捷的互联网体验，通过自己敏锐的行业洞察力、丰富的经验、不断革新的技术，在领先技术和优秀性价比间达到完美平衡，通过不断进步改变网络局限性，让全球更多用户更加轻松便捷地体验互联网时代的变革。

进入2017年，D-Link携全新品牌主张及产品出现在公众面前。据了解，D-Link将全新品牌定位为“智简·全覆盖”，旨在通过设备更智能、使用更简单的“智简”和无线覆盖效果更好的“全覆盖”体验，为用户提供更加和谐简单的人机互动逻辑，这一全新品牌主张着力在家用与商用方向双重发力，用“智简·全覆盖”的态度，为追求简约、轻奢的新中产家庭及追求网络性能及卓越性价比的中小企业赋予新时代价值。

D-Link通过在创新性、国际化、全覆盖等方面的革新与坚守，打造“New D-Link”价值——在创新性方面，D-Link坚持以前沿技术为创新根本，根据用户实际需求，持续创新研发网络科技技术，紧跟全球市场最新节奏，不断为智能家庭和商业应用创造新的可能；在国际化方面，依托全球180多个国家和地区的分支机构优势，广泛研究全球用户对智能家居和网络科技的需求，在刚刚过去的2016年，D-Link成为苹果智能家居平台“HomeKit”首批合作品牌，其产品将在2017年的全球舞台大放异彩；在全覆盖方面，D-Link将着力打造“智简·全覆盖”理念，依托全新的“Covr”系列产品及新7系列企业路由等产品，打造高效、便捷、以人为本的全新网络体验。

 

**科技改变生活：让用户体验“智慧家庭”**

 

除上述全新品牌定位之外，D-Link还推出全新“Covr”系列产品为品牌护航。据了解，COVR系列产品包括基于无线路由器+扩展器的Covr Wi-Fi Kit（DKT-883）和基于电力猫的Covr PowerLine Wi-Fi Kit（DHP-W732AV），并与D-Link现有的高端产品形成矩阵，帮助消费者实现家居更智慧、更便利、更时尚、更安全的核心诉求，彰显品牌实力与价值。

在实际应用场景中，“Covr”系列产品及其他家用级产品主打的“智简·全覆盖”理念被彰显得淋漓尽致，所有产品功能都以用户实际应用时的便捷体验为核心。

如“自动学习”功能，在第一次设置时简化流程，并自动学习旧路由器的账号、密码等；“智能连接”功能，11ac双频路由器可以自动连接合适频段，无需用户配置；“语音联动”功能，可以让用户与产品进行语音沟通，一句“我回来了”或“我走了”，各种网络、电器设备就可以自动自动或关闭；“人脸识别”和“视频分析”功能，将家庭安保提高到新的高度，通过人脸识别，一旦发现陌生人进入，将自动进行告警并启动监控录像，而视频分析功能则可以实现视频压缩，为用户节省80%以上的时间；“智能信号”能够主动寻找设备，让用户在家中自由活动而无需担心信号死角；不同产品间可以智慧沟通，实现信号自动无缝连接；

 

**深耕SMB：用技术升级为中小企业赋能**

 

而在D-Link始终深耕的SMB领域，“智简·全覆盖”的优势同样明显，通过DWC系列、新7系Pro系列、CWM系列等旗舰产品，为SMB企业提供“智管理，简运维”的智简体验和全覆盖的整网网络建设解决方案，全面解决中小企业实际需求。

在实际应用中，“智简·全覆盖”的企业级应用，可以提供智能流控、APP管理、多种上网准入方式、微信管理、智慧云平台等一系列智能且实用的功能，帮助SMB企业轻松实现互联网转型，并获得最佳性价比。

如今，面临“智能家居”浪潮不断汹涌，各大互联网硬件厂商纷纷推陈出新，响应时代的变革，而严重的同质化由此也带来了市场的白热化竞争。而通过全新的产品矩阵和品牌主张，不难看出，D-Link正在通过实际行动，用智能、简约、以人为本的品牌理念，吸引新一代消费人群，相信这也将成为D-Link品牌再掀高潮的重要一课。
