# 业务云化下的六大新安全技术

安全状况频出，数据泄露也并非稀奇。可近日，网络安全专家兼微软区域主管Troy Hunt在博客上披露了他收到的一份多达52GB的数据库资料可谓是出奇的有料：近3400万美国人的个人身份信息（PII），且覆盖种类多样——从姓名、职位，邮箱、电话到公司盈利情况，甚至还有国防部下辖军人档案信息！据调查这批数据的来源是世界商业信息服务公司巨头——Dun&Bradstreet。本次泄露的数据库，就是其2015年以1.25亿美元收购的服务于各大机构提供B2B数据管理的NetProspex的交易的一部分。一家公司查看50万条记录约需要花费20万美元，而这次泄漏的内容里单单不同的邮件地址就包含近3380万条！正可谓是真金白银的损失！

  

云化趋势下，IT系统日趋复杂多样，业务云化进程亦日渐加剧，传统硬件边界防护逐步失效，更多不可视的威胁已涌现。

  

  

**1、云联接安全技术**

  

网站流行采用HTTPS加密，威胁对于传统防火墙变得不可见。据Alexa网站统计**TOP100万网站中已经有30%左右采用HTTPS加密；云App也开始流行。**

据调查，2016年平均每个企业使用4.6个合法公有云服务。除了授权的合法应用，还有未经过企业IT部门认证的非授权应用。这个时候，可无论哪一种业务应用，**其业务数据的访问路径都不在本地网络，而是要经过本地和云端的一次或多次交互来完成某项工作。**

这种访问路径的变化表明传统的本地网络安全设备可能是透明的，**IT部门甚至无法了解和控制用户行为。**CASB（Cloud Access Security Brokers）产品出现了，用来对企业内部的流量出口进行控制。

  

  
**2、云应用安全技术**

  

大量的云App推动服务器的安全需求，WAF （Web Application Firewall）作为提供Web应用实时深度防御、Web应用加速、敏感信息防泄露、网页防篡改等功能的安全防护产品，**能够抵御各类针对Web应用的外来攻击，最大限度的保障网站运行安全，成为今天CSO建设云数据中心时的重要选择。**

WAF将具备应用沙箱技术，面向应用程序的安全检测能力RASP（Runtime Application Self-Protection）利用虚拟化（Virtualization）技术，保护Web App服务器。同时，LANGSEC（Language Security）也属于RASP，用于防护XSS（Cross-Site Scripting）、SQLi（SQL Injection）、CSRF（Cross-Site Request Forgery）、命令行注入。  

  

  
**3、安全服务化**

  

全面云化后，安全服务化SECaaS（Security As A Service，安全即服务）首先要将传统的安全产品，比如Anti-DDoS，NGFW以虚拟化的方式部署到云里去，然后最重要的是**针对客户在云化环境里的业务流量变化，既需要解决传统的存量流量安全业务，同时还能为增量流量业务提供安全防护。**

  

  
**4、虚拟化与沙箱的未来**

  

针对利用加壳，加密，加混淆技术的攻击，**传统的基于签名的检测技术是无能为力。**传统的AV软件思路的利用局部模拟执行。

但是随着虚拟化技术和沙箱技术的出现，**通过Quick EMUlator来模拟执行整个操作系统和病毒进程已经被证明是可行的。**

此外，利用虚拟化层Hypervisor，通过在VM（Virtual Machine，虚拟机）里直接运行病毒样本，自动跳过病毒的加壳加密加混淆，**通过观察病毒的动态行为做威胁检测，最后成功识别威胁。**

  

  
**5、大数据分析让未知威胁无处可藏**

  

针对APT、定向威胁、勒索软件的流行，传统的直路部属实时检测的方案，检测时间段，无法深度检测。转移到旁路的检测时间更长的非实时深度检测，**反而因实现深度的检测而增强了安全性。**

  

**◆ 沙箱拥有动态行为检测的能力，是单点威胁检测的重要一环。**云端沙箱，可以和客户本地的NGFW或者本地沙箱进行联动。

  

**◆ 大数据和机器学习在关联分析、威胁建模、威胁判断将发挥关键作用。**CIS（Cybersecurity Intelligence System）大数据智能分析平台可实时分析导入的流量、文件、日志等信息，并实现APT检测、预警和清除。 

  

  
**6、云威胁信息中心协作才能保护**

  

针对终端安全，通过加入安全联盟、与领域安全领先厂商合作及与平台厂商合作，构筑云管端全面安全能力，满足企业全方位的防护需求。同时，**加强安全运维的能力，构建强大的云端威胁信息中心，让安全逐步具备造血功能。**利用华为已有的ICT资源优势，从整个安全解决方案的视野布局，通过集成与被集成，为企业提供无处不在的安全防护。

 

华为全面云化网络架构即将在德国汉诺威CeBIT发布，它为企业客户打造的是极致体验、敏捷创新、安全无处不在的使能数字化转型的基础架构。
