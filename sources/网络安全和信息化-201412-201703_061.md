# 荣之联自有产品APEX软件荣获2016中国IT运维管理最佳产品奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649138608&idx=2&sn=490f1f04a9750fa355632d99e33dc822&chksm=be8b2cac89fca5baa4989ad5e49f95d199b862c09e8f730666b6659bab1c673c3378c2943744&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649138608&idx=2&sn=490f1f04a9750fa355632d99e33dc822&chksm=be8b2cac89fca5baa4989ad5e49f95d199b862c09e8f730666b6659bab1c673c3378c2943744&scene=27#wechat_redirect)

2016年11月1日，由中国电子信息产业发展研究院主办，IT运维网、《网络安全和信息化》杂志社承办的2016（第七届）中国IT运维大会在京隆重举行。

本届大会以“智能管理，高效运维”为主题，旨在激励IT运维发展的同时，发出中国IT运维领域最具权威的声音,分享中国IT运维市场的优秀经验。北京荣之联科技股份有限公司作为获奖单位受邀参加，与来自政府、制造、金融、互联网、能源、教育、交通、医疗等行业的企业用户和业内专家，共同解读IT运维发展的趋势。  

![](../Images/eafedfa8e5ae1b8a549e8dd81d566d42.png)2016（第七届）中国IT运维大会现场  
**APEX运维管理软件荣获“2016中国****IT运维管理最佳产品奖”**![](../Images/db4e9f7948492a5d59d9c809b65ae4fc.png)

大会现场公布并表彰了通过会前IT运维网调查，同时结合相关专家的评审意见，评选出的极具含金量的2016中国IT运维奖项。凭借业内领先的IT运维管理模块、高效稳定的产品性能，以及多年的客户口碑，荣之联自有产品APEX运维管理软件荣获“2016中国IT运维管理最佳产品奖”。

在云计算、大数据、移动互联等新技术的驱动下，各单位的IT环境变得比以往任何时候都更加复杂，新产品、新应用不断投入使用，对各单位的IT运维带来了新的挑战。

因此，荣之联企业云计算事业部APEX运维产品总监滑飞以“云时代的APEX运维管理解决方案”为题进行了精彩的演讲，同与会嘉宾分享了如何基于APEX运维管理系统搭建高效稳定的云监控平台和服务管理平台。根据SOA的设计思想，规范内部接口，降低耦合度，方便各模块将来的延伸和扩展，进一步保障用户云平台的可靠性和可扩展性。
