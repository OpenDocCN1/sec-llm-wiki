# 1.17亿用户信息被“贱卖”！企业需要数据泄露智能防护系统

       当今社会，你可能连自己邻居姓什么都不知道，却有接不完的“熟人”来电。这些人大多是电话销售和诈骗犯，他们对你姓什么、叫什么、家住哪里、邮箱多少了如指掌，能像报菜名一样脱口而出。在不胜其烦之余，你肯定也会疑惑，自己的信息究竟是从哪里泄露出去的？  

  

![](../Images/2d8d8137305523dc9dec8dd9b73db2fc.png)  

  

       填写一张活动报名表、注册一个网站会员、开通一项手机优惠服务甚至办理一张商场打折卡，用户信息在以各种形式向外输出，而接收方可不一定都能“守口如瓶”，多数情况下，他们中的某些人更愿意把用户信息当做“商品”出售来赚取外快。

 

       不过，黑客显然对这种通过“合法收集+整理分类+暗地出售”赚到的“辛苦钱”感到不屑，他们更喜欢通过网络攻击或利用漏洞直接窃取企业的用户信息，然后再将海量数据低价出售，甚至直接公布在网络上。

 ![](../Images/d355c4ef58dcb45c0565048363f70599.png)  

  

       近日，一位名为“和平”的黑客作价5比特币(约合2200美元)出售1.17亿条LinkedIn（领英）的用户登录凭证。这家全球最大的职业社交网站最近两年在中国也积累了大量用户，而中国网民是出了名的不爱换密码且热衷“一码走天下”的，可能引发的信息安全风险就可想而知了。

  

![](../Images/33f267ff1fb1cbffd75beb340854c4dd.png)  
![](../Images/f7ee1e69983e616cf48f811abac64ad4.png)  

  

       不管是内部主动泄密还是外部攻击窃密，也不论出于金钱还是“兴趣”，当前信息泄露的频率、规模和影响范围都在不断上升。此外，数据泄露不仅仅对个人用户造成威胁，对泄露数据的企业带来的麻烦会更大！因为企业不仅会泄露用户数据，还会泄露企业自身的经营数据和其他机密信息，由此带来的便不再是声誉损害，更可能造成巨大经济损失。

 

       通常情况，企业会针对内网安全的问题通常会有针对性部署防火墙、IPS、邮件网关等安全设施，但这些手段通常都是针对某个局部位置或者特定风险而采取的，而内网泄密通道远不止一个，建立一个综合一体、全面细粒度的管控系统则是应对以上问题的最佳途径。

  

![](../Images/b7004755815915c44cb1f0ff6918eaa3.png)  

       北信源安全专家指出，作为用户信息的持有者，企业有责任也有必要通过技术手段对用户信息进行保护！同时，对于企业CIO和管理层而言，如何防止内部重要数据、隐私信息泄露到竞争对手、恶意者及网络中已成为当务之急，选用一款可靠的综合性防泄露系统则成为此项工作的重点。

  

![](../Images/7d5b72569fc376643897edbdfab6f821.png)  
产品体系架构

  

       北信源数据泄露智能防护系统（北信源DLP）是针对大数据时代而推出的数据泄露防护全新体系架构，该系统以内容智能识别为核心，以企业内网为范围，以终端、网络、邮件的数据防护为目标，以检测、控制、警告、分析为手段，对企业内数据实行精准分析，知晓数据分布和风险，保护数据资产。同时。系统会监控用户访问记录并自动分析，依据安全策略对终端、网络、邮件等泄露风险自动响应，并生成安全事件报表。

 

       与其它安全产品相比，北信源DLP的防护面积更加广泛。它不仅针对结构化和非结构化数据，同时在防护手段上，它能够覆盖终端所有的泄密通道以及可能的网络泄密通道，从而构成了一个以企业网络出口为边界的防护体系。可以说，北信源DLP为用户在数据安全方面提供了一个全面而又强大的选择。

 

       北信源安全专家提醒广大用户，技术层面的保护十分重要，但也不要忽视个人安全意识的提升，良好的日常操作习惯亦不可少，比如定期修改登录密码，避免使用弱口令，各系统登录密码不要重复或混用。
