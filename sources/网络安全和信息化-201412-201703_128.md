# 监控易携手日志易挑战海量监控

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649138270&idx=1&sn=377a2a2f04d8a6b7fc0af394857543bf&chksm=be8b2d4289fca454b402d87eafbcfa4193c10e53249c8a5e4ca46005083174e2f7aecdb63448&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649138270&idx=1&sn=377a2a2f04d8a6b7fc0af394857543bf&chksm=be8b2d4289fca454b402d87eafbcfa4193c10e53249c8a5e4ca46005083174e2f7aecdb63448&scene=27#wechat_redirect)

近日，监控易和日志易宣布结成战略合作联盟，双方将在市场宣传、业务拓展、客户服务等领域展开紧密合作，为客户IT设施的可靠性和业务成长提供坚实的保障。

![](../Images/fb71334ddcb428fcd3419e9780171dd9.png)

监控易是国内ITOM（IT Operation Management,IT 运维管理）市场领先的基础设施监控产品供应商；日志易是国内ITOA（IT Operation Analytics，IT运维分析）领域领先的日志分析产品供应商。

此次强强合作，对整个IT运维市场和双方的客户来说都是一个巨大的福音，意味着客户可以享受到整个IT基础设施范围内从故障发现到性能分析、从设备层面到应用程序代码层面、从运维保障到安全防护等全方位的立体式解决方案。

客户可以通过一个界面实现数据的深入钻取，充分享受到监控易丰富的视图报表和日志易深入的数据分析带来的震撼感受；从整体视图出发，一步一步深入到IT系统内部，洞察业务数据的瞬息变化；真正告别过去多部门、多工具的竖井式管理，实现IT运维部门、应用程序开发部门和安全保障部门的信息联动，提高数据的共享效率。

这次双方的合作背后，既有技术极客们的互相欣赏，也有两个公司商业目标的一致利益诉求。监控易和日志易背景有太多的共同之处，例如：

 

*   两个公司的创始人都生于70年代；
    
*   业务都聚焦企业服务领域基础设施管理自动化、智能化；
    
*   技术团队都是各自领域最专业、最顶尖的人才；
    
*   共同的天使投资人：真格基金；
    
*   中国SaaS投资第一人李剑威分别是两家公司的董事。
    

 

作为国内IT服务领域拥有顶尖技术的两个公司，监控易和日志易为此次合作树立了共同的目标：初级目标是5年内达到上市公司的业务体量；高级目标是共同走向海外，实现“Designed by China”。

监控易CEO胡建强表示，监控易和日志易的合作，长期来看将为中国公司的合作树立了典范，双方各自专注于自身的优势技术，在满足用户需求的前提下适度融合，为用户提供一体化的解决方案。

日志易CEO陈军表示，日志易和监控易的合作，将大大促进各自的业务发展，加快中国企业服务市场巨头的诞生速度，有利于缩短国内基础原创技术与世界先进水平的差距。
