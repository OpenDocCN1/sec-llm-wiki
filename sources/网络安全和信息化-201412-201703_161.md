# 【十点速递】将在2016年内占统治地位的十一项云发展趋势

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=401159756&idx=1&sn=0cc011f9bcaaf2942f1350b99f7a566a&chksm=3484bf5003f33646d530dc3f08e683a1ad4f9aa9bf1b4973e5be9b9ddfa0f9cf7f91cf960e63&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=401159756&idx=1&sn=0cc011f9bcaaf2942f1350b99f7a566a&chksm=3484bf5003f33646d530dc3f08e683a1ad4f9aa9bf1b4973e5be9b9ddfa0f9cf7f91cf960e63&scene=27#wechat_redirect)

除了社交、媒体与分析，云技术与模型也已经成为如今这个数字化时代的核心颠覆者。过去几年以来，云市场除了日益成熟之外，同时也开始与快速发展当中的数据与分析领域产生交集，这意味着2016年当中云计算还将迎来更多极具革命性的发展机遇。2016年刚刚开始，五位业内人士从自己的视角出发审视了云将在新的历史阶段带来怎样的影响。

  

来自商务智能与分析企业Tableau Software公司的产品营销高级经理Dustin SMith预测称：

  

· 这是一场数据层面的疆土争夺战。这场争夺的目标在于大家的数据，Smith表示。从Salesforce到Amazon Web Services，各大主流云服务厂商都希望全球各地的企业能够将自身数据迁移至它们的生态系统当中——而不仅仅是传统的内部数据集。Workday以及Zendesk等网络平台中的数据，乃至由设备及机器产生的数据现在都已经成为各云巨头的首要目标。“我们是否对此感到意外?其实并不意外，”Smith指出。“数据资产现在对于企业而言已经如同石油资源之于各个国家。这意味着任何一家云服务供应商都希望将全部企业数据囊括在自家云环境当中并加以处理，从而保证自身成为企业客户日常运营中不可或缺的助力。将企业数据湖汇总至云环境下的思路已经出现并投入实现。这种处理方式在与云服务厂商提供的低成本存储服务以及零前期投入托管解决方案相结合之后，呈现出极为可观的客户吸引力。那些已经开始将自身数据仓库迁移至云环境中的企业客户，势必会在新的一年中将更多非传统(重要性较高)的数据源迁移至几乎能够实现无限规模扩张的云平台上。这种状况也将涵盖与物联网资产及社交网络指标相关的一切——其核心诉求就是建立起一套与企业资源及客户相关的、关联更国紧密的分析体系。”

  

· 大企业将通过大举措进军云环境。“引爆点取决于我们，”Smith表示。“云部署已经不再像过去那样单纯属于初创企业的专业了。立足于各个行业的大型企业也在奋力将其全套基础设施及数据生态系统转移向云端。为了交付各类水平更高的客户服务并提升业务流程中的固有优势，来自几乎各个传统及变革性行业的企业都达成了同样的共识：云技术战略是一种绝对不容错过的成本削减与风险控制手段。特别是在未来五年当中，云计划的大规模持续性普及将成为各位CIO们必须接受的现实——无论是否情愿。”

  

· 云分析机制助力IT工作。关注云部署成本水平及其容量的快速扩张，将帮助IT领导者更多地依赖于能够随时掌握的强大分析解决方案，Smith表示。“如果云技术战略的主要卖点在于降低成本并提高资源利用效率，那么CIO们必须对这些收益进行亲身验证。云分析解决方案能够将挖掘结论与计费数据相结合，帮助IT领导者快速发现潜在的高成本服务并防止预算超支。他们甚至能够在开会过程中通过移动设备完成上述任务。

  

· 面向云环境的数据移动方式更接近于复制/粘贴。自助服务数据迁移与数据准备解决方案已经在2015年当中风靡一时，但2016年将有更为便捷的途径出炉，帮助我们将来自企业乃至Web平台的数据推送至云数据生态系统当中，Smith指出。“在自助服务型云分析与数据准备方案已经变成现实的条件下，相信不久的未来我们将能够轻松快捷地将数据移动至云生态系统当中(而无需具备任何技术背景)，”他表示。“简单的解决方案将能够显著对数据集成、分段以及转换等高复杂性因素剥离出去，帮助我们专注于将企业用户的涓滴数据汇聚在合适的云数据库及仓库当中。”

  

· 混合云战略的实现难度进一步降低。“想一脚踏足云环境，一脚站在内部体系?从技术路线图的角度看，这种几乎不可能实现的‘二者兼得’方式恰恰是一部分企业的最佳或者说最易接受选项，”Smith表示。“由此带来的结果是，用于支持此类模式的解决方案与服务呈现出极为旺盛的发展态势。一切都处于过渡阶段，即使是那些希望‘全面’投入云环境怀抱的企业，有时候也会发现自己的全云策略不一定能够实现。遗留解决方案、合规性要求以及一系列其它问题很可能导致IT发展路线图无法真正抛弃内部体系。另外，也有一些企业本身就倾向于选择混合型方式。如今各大云厂商已经不再像过去那样强调所谓‘如果不全面拥抱云环境，你就错了’这类极端发言，而开始以开放的态度为混合型部署方案构建支持性实践。这反过来也证明小型解决方案供应商有能力在市场上满足客户需求，并无疑将鼓励更多企业选择这条道路。不过请别误会，这并不是说企业已经开始全面迈过指向云环境的变革拐点，这只能证明托管基础设施巨头们开始以较为和缓的态度审视混合型实现方式，并开始对其建立起一定程度的信心。”

  

**企业云应用安全专业企业Netskope公司创始从兼CEO Sanjay Beri对云在2016年中的发展趋势做出以下三项预测：**

  

· IT部门可能会成为创新中介者角色。“云采纳水平将迎来峰值，并将IT部门的角色由系统修复者转变为创新中介者——因为IT专家将负责开发新的生产力工具与积极政策以帮助企业运用云资源，”Beri表示。

  

· 云访问安全中间商将迎来发展的黄金时代。“云访问安全中间商(简称CASB)市场即将成为最为热门的企业级IT细化市场，其在刚刚过去的2015年下半年已经迎来了总值接近10亿美元的收购与合并交易，”他补充称。

  

**云安全自动化专业厂商Palerra公司创始人兼CEO Rohit Gupta预测称：**

  

· 供应商将按需提供API。“我们预计各云供应商将出售API并将其作为新的营收来源，”Gupta表示。“各SaaS、PaaS与IaaS供应商将承受着交付大量丰富API选项的压力，从而帮助安全供应商及应用程序供应商提供具备附加值的服务方案。”

  

**B2B移动销售自动化厂商Pepperi公司CISO Tomer Okavi预测称：**

  

· 云安全标准即将出现。“随着越来越多企业开始依托于云服务实现自身业务，2016年将有大量云安全标准出台，从而帮助客户更好地向云进行迁移同时以更令人信服的方式鼓励企业将云服务集成至自身IT资源当中，”Okavi表示。

  

**专门利用云与移动平台交付企业应用程序的Avi Networks公司CEO Amit Pandey预测称：**

  

· 企业将能够在自有数据中心内部实现“类似于公有云”的灵活性、敏捷性与规模性。“低成本计算基础设施、无缝化应用程序规模伸缩以及便捷的开发实践集成能力已经成为Amazon AWS等公有云服务的最大卖点与依托，”Pandey表示。“而随着OpenStack实现方案、容器工具/实现方案(例如Mesosphere、Docker以及CoreOS)再加上软件定义网络的兴起将引导企业在内部环境中实现与云类似的能力。”

  

· 云环境下的网络攻击与数据泄露事故将由预期转为现实。“云弹性国际工作组已经对云服务的停机与安全风险进行了监控，”Pandey表示。“截至目前，还没有任何真正成规模的安全事故或者可用性问题影响到云方案。不过在考虑将计算负载迁移至云端时，安全性一直是困扰着诸多企业的大难题。目前这种担心在很大程度上仍然源自与事实无关的猜测与预期，但随着越来越多企业采用云服务并将大量数据及应用交予其打理，安全挑战(包括DDoS攻击或者其它网络攻击)、数据丢失乃至潜在停机状况将一一出现。”
