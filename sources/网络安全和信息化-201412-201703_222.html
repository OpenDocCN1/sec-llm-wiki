很多人怀着不同的心情看微软的新操作系统 Windows 10，有些人继续批评它没有革命性的变化，有的则认为这就是他们真正想要的操作系统。也就是说，Windows 10 或多或少都有让人升级或安装的理由，因此该新一代操作系统的市场份额也正在不断的增长当中。最新统计数据显示，每个月都有越来越多的用户选择 Windows 10 作为其主要的桌面操作系统。

　　12月2日消息，日前，权威市场调研机构 StatCounter 发布了一份最新桌面操作系统份额的报告。根据报告显示，Windows 10 正式发布以来，上个月全球市场份额首次突破 10%，成为当前第三大最受欢迎的桌面操作系统。

　　或许很多人认为 10% 并不算什么，这个市场份额数字太小了，但考虑到 Windows 10 仅正式推出四个月的时间就已取得如此重要的成果，对比 Windows 8 可谓飞跃式的突破，微软在不久前的财报会议上也表示 Windows 10 的增长超过了他们的预期。

　　系统份额具体数据方面，Windows 7 当前的市场份额高达 49.31%，几乎占据半壁江山。排在它后面的是 Windows 8.1 操作系统，市场份额为 13.05%，Windows 10 的市场份额上升到了 10.18%。第三和第四名是大约都占据了 9% 市场份额的 Mac OS X 和 Windows XP ，与 Windows 10 的市场占有率大致保持相同。


历经四月 Windows 10终于超越Windows XP！

　　超越 Windows XP，但 Windows 7 仍然是王道。

　　目前来看，得益于 Windows 7 和 Windows 8/8.1 用户可以在一年时间内免费升级的优惠，Windows 10 利用 4 个月的时间超过苹果的 Mac OS X 和 Windows XP，取得了十分了不起的成就，但是摆在它面前的最大挑战仍然是 Windows 7，这个版本是目前桌面操作系统的霸主。

　　不过， 尽管 Windows 7 是头号系统，但事实上其市场份额已经没有继续保持增长了，其中一部分原因在于微软提前发出预警称，Windows 7 的支持服务将于 2020 年底结束，目的是避免出现类似 Windows XP 退市那一刻的尴尬。当然，作为用户，每一个人都有拒绝升级的理由和权利，不过也有不少用户考虑到安全问题选择了最新的平台。

　　不得不说，Windows 10完全有机会挑战 Windows 7，既然 Windows 7 第一次出现市场份额低于 50% 的情况，那么这就是一个表明它已经无法在市场上创造影响力的信号。另外，或许考虑到Windows XP 不具备免费升级 Windows 10 的优惠，很多用户之所以选择了如今已经十分实惠的 Windows 7，其目的很可能是为了未来升级 Windows 10 做准备，至于现在仍不选择升级，则是因为需要时间来观察。

　　总之，Windows 10对微软的未来至关重要，微软能否在三年时间里创造 10 亿 Windows 10 用户呢?我们拭目以待。
