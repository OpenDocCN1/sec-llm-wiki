# 听真格李剑威聊一聊投资监控易的那些事儿

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=400539354&idx=1&sn=1ac6794ab53a073ce83c2d25733f52cd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=400539354&idx=1&sn=1ac6794ab53a073ce83c2d25733f52cd&scene=27#wechat_redirect)

2015年11月6日，由真格基金投资的监控易——国内领先的IT监控SaaS平台服务商，在北京建国饭店成功召开了“2015分享交流会”。来自IBM、HP、华为、神州数码、华胜天成等监控易的合作伙伴悉数到场，总参、中石油、蓝色光标等重要客户和多家媒体也现场参与。

当天的会议中，真格基金合伙人李剑威应邀出席，并分享了投资监控易的历程和对其未来发展的期待，以下为演讲内容分享。

　　在投资监控易之前，我看的比较多的就是大数据、云计算和企业服务，另外一方面就是智能硬件，包括很多、很好玩的东西，比如前段时间发布的Ninebot——全球最轻、最小的平衡车，还有小米手环等项目。

　　我花了很多时间和精力在研究企业服务，算上我在真格和红杉的时间，大概投资了10家这方面的公司，他们目前发展的还不错，这其中有一家叫销售易，是做CRM的，还有做猎头SaaS软件的，有做OpenStack的。

　　从整体情况看，我个人认为中国的企业服务市场与美国相比，还有5年的差距，在某些领域甚至更长一点。

　　过去很少有人关注企业服务这个领域，但是如今外部条件在发生变化。前段时间我在一个IT峰会上也做了一个演讲，主题就是企业服务。我们也看到，中国企业在继续快速向前发展，很多外部条件都在成熟，比如人员的工资在提高。于是很多企业主就有了提高运营效率的需求，而这其中一个最有效的手段就是用系统来代替人力。比如说在监控这个领域，就需要用软件来代替相当部分的监控人力。当然，我认为有经验的运维人员还是很有必要的。但如果有一个很好的软件，会让运维人员如鱼得水。

　　另外，云计算正在蓬勃发展。虽然中国云计算的规模与美国、与全球相比还比较小，但是我们也很清晰地看到，在过去的三年，中国的SaaS软件、基础云计算软件，其增长速度非常快。很多公司虽然技术仍处在发展中，但在过去三年的增长率达到了100倍，这个速率是非常惊人的。从这个角度来看，是企业服务一个很大的利好。当然还有一些外部环境影响，比如手机的普及。

　　许多企业主的观念也在改变，以前可能不接受SaaS，大家都希望把数据存储在自己的服务器里，但是后来发现，存储在自己服务器里面也并不安全，如果有运维人员不小心改掉了一些代码，可能会导致整个系统瘫痪。因此，自己管理还不如放在云服务商那更安全，因为他们其实有很高的SLA。从这些关键要素来看，我觉得中国企业服务起飞的时刻已经到来。今年很多投资人，包括经纬、红杉、启明等机构，逐渐花更多的时间在企业服务方面。所以，我们对企业服务包括云化在中国的发展非常看好。

　　我个人投资的公司中，涉及到企业服务的公司都在很快地成长。

　　所以，总体趋势很好，市场很好，这是我们投资监控易的重要前提。

　　其实我跟胡总（监控易董事长胡建强，编者注）两年之前就见过，我当时问他一个问题：你们现在的产品形态是什么？他说还是一个套装软件卖给用户。其实这家公司活的还不错，已经有一些现金流。但是沟通下来，我的观点还是比较明确：如果不做SaaS，不做远程的部署，不能显著地降低用户使用门槛，可能没有前途，最多就是一个赚钱的公司。

　　令我没想到的是，这个团队还是很听得进去意见。这两年他们也看清楚了整个行业的发展趋势，然后在今年就把这个SaaS平台发布出来。我们看过以后，觉得产品做的相当不错，在ITOM这个领域应该是最好的，这也是我们投资监控易很重要的一点。

　　另外，如果从IT运维产业来看，我觉得中国还有更多的机会。在美国，IT运维经历了很多个阶段，诞生了包括最早的HP OpenView 、IBM Tivoli等产品。IT运维是一个很大的市场，因为只要你有IT设备，就需要监控；即使是把IT系统放到云计算上面，虚拟机也是需要监控的。所以这是一个普适性的需求，是客观存在的，我相信大家都有亲身体会。

　　但是为什么没有一个很好的国产产品？我感觉这里面有一个很好的发展空间，只要我们的产品做到位，交付形式跟上云计算、SaaS的发展，相信被压抑的需求会很快爆发出来。

　　当我在今年7月份再见到胡总的时候，他拿出最新的产品给我们看，我们感觉这个点慢慢地找到了。当然还有一个原因，我们看市场、看产品，更重要的是看团队。监控易的这三位联合创始人背景非常不一般，他们已经在一起工作了很长时间，非常非常默契，对产品的每一个细节也相当熟悉，对未来的规划也有非常清晰的想法。这是我们比较喜欢的团队，因为这样的团队值得信赖。而且产品的路线图很清楚，接下来一年做什么、两年做什么、三年做什么，都有很成型的想法。

　　企业客户在产品选型的时候，最害怕的就是这个产品没有后续服务，或者是个小公司长不大。但我相信，监控易不会出现这种情况，因为他们把未来五年的产品形态都想得很清楚，接下来的工作就是在有资本的情况下，不断地去完善。然后听取更多的客户需求，赶上甚至超越国外的产品，让它更加本土化。从这个角度来看，我觉得这个团队是非常不错的。

　　所以，看到市场，看到产品，看到团队，我们就投资了。我们投资完之后，有很多后续的投资也非常感兴趣，因为他们看到了真格和达内。达内是我们非常好的一个战略合作伙伴，他们在IT培训领域肯定是全国毫无争议的第一名，与所有的竞争对手都拉开了距离。正因为有了达内的加入，我们的信心更足。因为监控、IT运维都需要IT专业人才，如果在专业的IT人群里面，有一个这样的投资人给我们做背书，并且去给我们做推广，这点我觉得是至关重要的。

　　所以，我们投资监控易是一个很快的过程，三周所有工作就全都结束了。我们也很高兴，有机会同达内共同投资监控易。我们对监控易的未来非常看好，也希望监控易能不断地去完善产品，不断吸纳精英人才，成为中国IT监控领域一个响当当的品牌。

　　未来这个产品还有机会走出去，走到国外去，跟美国的领先公司，比如Solarwinds、ServiceNow这种百亿美元的公司去直面竞争。我认为中国的创业企业，到目前这个阶段，他们已经在很多方面具备了在全球竞争的素质，当然我们还要引入国际化人才。

　　这就是我们投资监控易的一个简单回顾，我们对监控易的未来充满信心。
