# 【十点速递】微软宣布将停止提供免费试用版Office 365

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=209435144&idx=1&sn=ae617194f20f6f9eaf267fe1173ddc19&chksm=2f1633141861ba02284c457eb88124177776b34ba5c7a54a51dd40d9ac7a6e4b7727390f2d2f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=209435144&idx=1&sn=ae617194f20f6f9eaf267fe1173ddc19&chksm=2f1633141861ba02284c457eb88124177776b34ba5c7a54a51dd40d9ac7a6e4b7727390f2d2f&scene=27#wechat_redirect)

北京时间8月17日早间消息，过去一年左右时间里，微软与PC厂商合作，在一些笔记本和平板电脑中提供了试用版Office 365。微软即将改变这一做法。微软近期宣布，将停止提供免费的Office 365试用版。

　　此前，在获得Office 365试用版之后，用户可以在一年时间里，在Windows、Mac OS X、平板电脑和智能手机等设备上免费使用Office 365。这一试用版还提供了1TB的One Drive云存储空间，以及每月60分钟的Skype通话分钟数。这吸引了用户去购买新电脑。

　　然而，在一年试用期结束后，用户如果希望继续使用Office 365，那么必须付费。这意味着，用户将无法免费使用Office 365以及云存储服务，而付费服务的价格为每年70美元。

　　Windows 10中的“通用应用”版Office在评估授权过期之后仍将免费，但这些应用不会提供与Office 365同样的功能。
