上周三国内的PC用户陆续收到Windows 10的更新推送，当晚微软也举行了大型的Windows 10的发布活动。我一个月前已经按照提示“预约”了Windows 10的更新，不过系统更新记录一直显示“Windows 10 Pro更新失败”，后来辗转试了几次"wuauclt.exe /updatenow"命令，终于成功。后来也在MSN中文网上发现了一个官方Windows 10的下载入口，既可以制作安装介质，又可以直接触发安装，链接地址：https://www.microsoft.com/zh-cn/software-download/windows10（复制该链接进浏览器地址栏）。

升级过程我没做太多记录。大致首先是个下载的过程，视网速而定不过一般时间会很长，所以提示可以继续使用电脑后台下载。然后安装之前会让你选几个“是”以及“同意”还有“下一步”等等，点完了之后又是一个小时的多次重启和等待。Mac的通常做法是该让你点的一开始都让你点完操作完，然后下载安装全自动，这一点Windows的确更闹心，不过想来Windows 10或许是微软最后一次这样大动干戈的更新，也就不再计较。

更新结束时试了一下Edge浏览器，从窗口切换，到页面载入都十分顺畅。不过，随后发现全部的第三方应用（包括之前下载的几个桌面主题）都被清空了(⊙o⊙)… 于是接下来的数个小时都在下载安装（比如Photoshop这种）= =…回想起安装过程某处有一个选择有三个选项，其一为保留所有设置和文件，这个选项不知何故是灰色；第二个选项是保留用户文件；第三个选项是全新安装。不 懂微软此次为何在升级安装中还要做这种区分。所以结论是，就算升级安装也有可能带来程序和设置丢失。

Edge浏览器

好吧！尽管有槽点，新系统还是要开开心心的用起来。Windows 10的一些视觉效果做的可圈可点：比如我此前设置了桌面壁纸定时更换，系统的颜色主题也会随着壁纸更换而变换红黄蓝绿，如果你习惯用系统默认输入法，就会有明显的感受；另一处则是Windows Vista/7中久违的Aero玻璃特效回归了，不过并没有那么“玻璃”，主要在侧边的通知栏（很像OS X有没有），以及桌面窗口预览。

Windows 10中最具科技感的还是Cortana的搜索栏，尽管我询问的大部分问题都会直接跳转浏览器打开Bing搜索给出一堆结果（没错，感觉就是然并卵）。我最期待的小冰也“遇到了一些问题”而无法呼出，而原因未知。而我测试的另一台 ThinkPad S5 Yoga升级完毕则可以正常使用小娜和小冰。我想如果我用的是Windows Phone，工作日历用的是Outlook（很遗憾我用的iCloud日历），Cortana的作用会大很多，而且现在我也没有使用Cortana的习惯 ——如果只是当做一个搜索框，就太屈才了，尽管找应用的时候可以当做Windows的一个Spotlight搜索（注：Spotlight是iOS的全局 搜索）。

此前在预览版中Windows 10在任务栏增加了虚拟桌面和预览。不过目前并没有发现快捷键，需要用鼠标点击的，而且也不要指望笔记本触摸板能支持什么快速的手势了——至少现在还没，以后也说不准。此前我们（看完后面觉得这里应该写“我”）一直熟悉的 Alt+Tab的后台窗口切换组合键，据微软官方的调研显示知道这个快捷键使用率低至个位数。

Windows 10中能显著提高效率的一个功能点应该是窗口重排，现在增加了拖拽窗口触碰屏幕角落时窗口自动变成四分之一的特性。让我不禁觉得Windows还是擅长鼠标键盘的办公环境，毕竟对于Mac用户来说，窗口切换要么是通过切换虚拟桌面来完成，要么是借助触摸板直接预览各个窗口完成的。

Windows 10的兼容性应该是到现在为止应该是最不用担忧的一个版本。毕竟从去年“公测”到现在，日常上网，以及办公的应用程序都一样跑，像Photoshop/Dreamweaver CS6我个人感觉反而跑得比Windows 8.1更快一些。其余的像什么QQ、电脑管家以及浏览器等等全都运行良好没出现过什么问题。不过还是提醒PC游戏玩家谨慎对待Windows 10，因为你电脑里的游戏可能目前还不支持最新的DX12，升级完毕导致完全玩不了也是正常的（没错，你应该买个Xbox One >.<~）。

我目前遇到的唯一一个bug就是某些程序的窗口最小化之后重新回复放大时无法排到最前面。比如我在看网页，需要打开某个文件夹窗口，或者打开QQ聊天窗口，点击任务栏上对应的窗口图标，想要的窗口却始终弹不出来（后来发现，其实弹出来了，但是弹到了现在窗口的背面= =）。

Windows Hello。这个功能我在我的旧电脑上是没办法用的。需要有双摄像头，并且支持虹膜探测的，支持英特尔RealSense实感技术的电脑才可以用上Windows Hello这么酷炫的功能（WinTel这一对CP还在一起）。因此我用了另一台支持Windows Hello的电脑来进行测试，识别率和识别速度比市面上任何一台手机的指纹解锁功能都更为迅速。在测试过程中我也发现，面部距离摄像头大约30-40公分的位置，并且最好不要让摄像头逆光拍摄，识别成功率较高，并且设置中也提供了选项进行多次预识别进行机器学习，如果发觉准确率不满意可以进行改善。

必须有相应的硬件和驱动，Windows Hello的选项才会出现

尽管写到现在你会发现我对Windows 10的抱怨并不少，然而我还是喜欢新系统的。如果你对电脑只是一般需求，问我要不要升级，我的答案是：升升升，赶紧升。
