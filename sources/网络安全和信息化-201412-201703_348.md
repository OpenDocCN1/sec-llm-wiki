# 【十点速递】想第一时间更新Windows 10？这9点你必须要清楚！

Windows 8上市以来，受到了太多的责难。用户挑剔指责不说（本来就很难用好嘛！），系统本身也不够完善，在这样的背景下，微软快马加鞭地推出了Windows 10，指望重新赢得用户好脸色。在距离正式版发布还剩半个月的时候，小编梳理了有关Windows 10的所有信息点，想要第一时间更新Windows 10的用户提前了解下。

**1.何时能升级？银子要多少？**

Windows 10计划于7月29日正式发布，对Windows 7和Windows 8.1用户免费一年。若用户操作系统还停留在XP等古董阶段，得花钱买更新了，Windows 10家庭版价格为119美元，专业版199美元。

目前，Windows 7和Windows 8用户应该已经收到了微软的推送通知，提醒用户预定免费的Windows 10。一旦用户选择预定更新，Windows 10发布时设备端将推送信息，提醒用户安装。

**2.台式机或平板用户，如果考虑买Windows操作系统的手机，用Windows 10有什么好处？**

司马昭之心路人皆知，微软正努力在各个设备上实现Windows 10的跨平台操作，Continuum技术是背后的大功臣。根据设备的实际情况，比如使用键盘鼠标还是触摸板，Windows 10会转变成相应的交互界面。Windows 10能根据用户是使用鼠标加键盘的组合还是使用触摸板，并作出相应的反应。使用键盘鼠标的用户将面对常见的操作界面，使用平板的用户将面对触屏操作系统。那么Surface Pro 3呢？Windows 10还能从台式机模式平滑过渡到平板模式。

智能手机那边的情况就不太一样了，因为Windows 10 mobile会有些许不同。虽然微软曾为公众展示将接了键盘鼠标的手机转变成电脑的把戏，目前还说不好这项技术何时能真正投入应用。![](../Images/9992a0584ab7ba1b7f218aa8f97b178e.png)

** 3.应用程序呢？**

微软当然希望用户在Windows Store上购买app，并能跨平台使用。Office软件就是个很好的例子，实现了跨平台使用，虽然手机上看起来有点怪怪的。不推荐大家在智能手机上编辑Excel表格，但手机的确可以使用Excel，PowerPoint，还有Word等Office程序。

**4.Windows 8上的那些全屏程序简直是一坨屎，Windows 10上还有吗？**

这些支持触屏的全屏程序又称大都会风格或现代风格，将成为可选项保留在Windows 10中。如果为Surface Pro 3接入外接键盘，操作界面会转变为传统界面，移除键盘后，操作系统就会切换到触屏模式。

**5.萝卜青菜各有所爱，我就很喜欢大全屏的应用程序啊，还买了些呢，它们还能用吗？**

还是因为Continuum技术，现有的应用在Windows 10上不会有太大问题。一句话，用平板的时候应用转成平板模式，支持触摸屏；用电脑的时候就变成传统的样子了。 ![](../Images/2028a33f12b9bf3a48872b5525906a7e.png)

**6.这次的开始菜单长什么样？**

讨厌Windows 8全屏开始菜单的用户有福了，Windows 10的开始菜单将回归正常，在屏幕左下角乖乖的躺着，还是熟悉的模样。喜欢动态磁贴用户也能继续使用磁贴，因为新菜单整合了磁贴功能，用户可自定义菜单。

**7.界面操作都是浮云，Windows 10系统运行效率是否有提速？**

Snap功能得到增强，Snap能快速将正在运行的程序窗口一字排开，不仅如此，还新增了程序窗口的四边形排列方案。这次的更新还提供了对多个虚拟桌面的支持，用户可以把所有工作程序放在一个桌面上，所有娱乐应用放在另一个桌面上，老板一走开，就可以第一时间切换到娱乐版啦。Windows 10在任务栏上增加了 任务预览按钮，点击可查看所有已打开的文件，窗口和桌面。

另外，Cortana语音助手从手机端走到了电脑上。打开语音识别功能后对电脑说“你好，Cortana”，可以通过语音来操作电脑，比如查找路线或者查天气预报。Cortana还能发送邮件，给联系人发信息。目前预览版还没有这项功能。 ![](../Images/740e4a6d748fcd3db0d791e1678a9735.png)

**8.IE浏览器还在吗?**

在，但是不再。处于对兼容性和用户习惯的考量，**Windows 10不会摒弃IE浏览器，但Microsoft Edge浏览器替代将在上网功能方面起主要作用。**Edge浏览器满足了对现代浏览器的所有幻想，支持扩展，精简网页功能的阅读模式，全新渲染引擎等。

虚拟助手Cortana为用户提供搜索建议，将重要信息（商业和饭店等）整合进侧边栏。点击Web Note按钮可将用户的浏览内容和笔记发送邮件给他人。许多功能还没有完全准备好，但这款新浏览器非常令人期待。

**9.Windows 10对于硬件配置会有怎样的要求?**

只要电脑能使用Windows 7或8.1系统，运行Windows 10应该没有问题。官方最低配置要求是1GHz处理器，最少1GB内存和16GB硬盘。

根据用户现在的Windows版本是家用还是专业，微软会下载相应版本的Windows 10。更多信息可移步官方网站查看更多详情，为下载Windows 10做好准备。
