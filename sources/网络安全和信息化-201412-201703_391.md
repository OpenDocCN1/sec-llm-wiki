# 【十点速递】说好的“统一”呢？Win10至少有7个版本

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=206787831&idx=1&sn=d8136eb8d224ad432a80708db49a1313&chksm=2f3eddeb184954fd5fc68fd2daf5a560baa5fbc30202c7657f68a2952479ef04afbf8e36fa1e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=206787831&idx=1&sn=d8136eb8d224ad432a80708db49a1313&chksm=2f3eddeb184954fd5fc68fd2daf5a560baa5fbc30202c7657f68a2952479ef04afbf8e36fa1e&scene=27#wechat_redirect)

微软宣布Windows 10至少会推出7个版本，包括家庭版、移动版、专业版、企业版、教育版、移动企业版和物联网核心版。

  

　　但微软再次强调，Windows 10将针对各种设备优化，包括PC、平板电脑、手机、物联网、Xbox One、HoloLens、Surface Hub等。尽管版本众多，但该公司还是承诺用户将获得“统一的Windows Store”，在其中寻找、尝试和购买统一的Windows应用。

  

　　以下是各个版本的简介：

  

　　1、家庭版针对PC、平板电脑和二合一设备，它将具备我们目前看到的主要Windows 10功能：Cortana数字助理（部分市场）、微软Edge浏览器、Continuum平板电脑模式，Windows Hello人脸、虹膜和指纹登录、Xbox One流媒体游戏、微软官方通用Windows应用（照片、地图、邮件、日历、音乐和视频）。

  

　　2、移动版针对的是智能手机和小型平板电脑等体积较小的移动触屏设备，它将拥有与家庭版相同的通用Windows应用，还将预装新的触屏版Office。部分新设备可以使用Continuum，所以用户可以在与大屏幕连接后把手机当成PC使用。

  

　　3、专业版专供商务级PC、平板电脑和二合一设备使用。除了家庭版的功能外，它还允许用户管理设备和应用，保护敏感企业数据，支持远程和移动生产力场景，而且会充分利用云技术。它还提供企业版Windows Update，微软承诺这项功能可以降低管理成本，控制更新部署，而且可以更快的获取安全更新。

  

　　4、企业版以专业版为基础，增加了大中型组织使用的先进功能，用以对抗设备、身份、应用和敏感公司信息面临的现代化安全威胁。它还将提供给微软的批量授权客户(作为现有的软件保险福利，Active Software Assurance客户也可升级)，他们还可以自主选择采用新技术的步骤，包括使用企业版Windows Update。Windows 10企业版将提供长期服务分支(Long Term Servicing Branch)作为部署选项。

  

  

　　5、教育版基于企业版开发，主要面向学校教职员工和学生，它将通过学术批量授权服务提供给用户，而各大学校也都可以升级Windows 10家庭版和专业版设备。

  

　　6、移动企业版是为企业客户开发的移动版，它可以提供给批量授权客户使用，但增加了一些功能，方便企业管理更新，并尽快获得最新功能和安全更新。

  

　　7、物联网核心版面向小型低价设备。微软预计，一些更加强大的设备将使用企业版或移动企业版，包括ATM机、POS机、手持终端和工业机器人。

  

　　微软尚未披露Windows 10的发布日期，但预计将在今年夏天面向190个国家或地区推出。但我们知道，由于将Windows作为一项服务来推广，因此这将是一个缓慢的过程：Windows 10将首先面向PC推出，之后是手机，然后是Surface Hub和HoloLens设备。

  

　　Windows 8.1、Windows Phone 8.1和一年内的Windows 7系统可以免费升级，分别对应Windows 10专业版、移动版和家庭版。
