# 干货！教你如何成功构建开源私有云

对于企业而言，开源产品对于构建私有云来说是一个便宜的选择，但前提是IT团队拥有能够操作私有云的先进技能。

如果你正在构建私有云，你就有两种选择，一是购买商业的软硬件，二是寻找开源的选项。如果你决定是否要构建一个开源的私有云时，你需要首先考虑以下方面：

有效性：让我们面对现实吧，开源与否，你选择的工具必须有效可靠的工作，让你能够指望他们。无论是开源的私有云或商业的替代方案都必须被仔细评估来决定他们是否能够满足你的业务挑战。在任何情况下，不要指望未来的升级，因为时间也许会被拖延并且增加新功能的优先级也有可能会调整。一开始就应该寻找合适的工具来完成工作，而不是执着于开源或商业。

成本：私有云的开源工具可以很便宜或者免费可以获得，但是长远来看有很多不确定性。将你的IT人员的时间和精力花在定制和支持开源工具可以远远超过购买商业的开箱即用，并且附有技术支持和维护的软件所需的成本。尽你所能对几种选择进行在长期运行的条件上所需要的投入水平的评估，并寻找该解决方案寿命内效益最好的场景。

长久性：开源存储选项依赖社区的支持来保证它们的活跃度和生存。使用那些不被更新的软件在最好的情况下就是被卡在一组很有限的功能上，最糟的状况也许会需要一个昂贵和复杂的替代方案。当然商业选择也有可能因为收购或者只是简单的厂商方面的一个战略上的改变而被中断，所以不要假设这种风险在这两个情形上都一定不会发生。

稳定性：商业或者开源工具可以高度可靠，但是随着功能和版本的增加，他们就会变得越复杂，所带来的风险也就越大。对于“多分支”发布的开源工具尤其要注意，如果多个开发版本分支并行，不同的版本也许会包含不同的功能，这会让运行和兼容性成为一个真正的挑战。

兼容性：使用开源的方式构建私有云的一大潜在优点是，各式各样可供选择的硬件和软件所带来的可使用性。既然开源工具不是特定厂商的，他们能够提供从许多竞争厂商那里丰富的选择方案中得到兼容性。有显着势头和获得广泛厂商支持的开源工具会成为最佳的支持一个异构环境的选择之一。话虽如此，要仔细检查所有厂商和使用的版本的兼容性是很重要的，不要想当然认为你在各种情形下都会获得完整的功能支持。

正如任何变革性的技术变化，投资私有云是一个复杂的过程，需要慎重考虑。记得总是从你的业务目标出发，清晰的定义你的需求，然后评估能够支持这些目标达成的技术。列出几种解决问题的方式场景，并分析每种方案在未来几年内的成本和运营影响。一旦你已经评估并审核了几种方案的准确性，那么你可以选择最适合你的需要和预算的那种方案。
