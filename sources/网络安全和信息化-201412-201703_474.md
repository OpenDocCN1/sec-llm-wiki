# 传IBM将迎来史上最大规模裁员：清退约11万人

IBM的员工或将在下个月面对该公司史上最大规模的裁员行动。如果没有其他因素影响，IBM将在第一季度支付一笔巨额的遣送费。

有消息称，IBM将在下个月裁员幅度将达26%，约为11万人，其原因或与管理不善有关。截至发稿时，IBM尚未对腾讯科技的询问作出回应。

可以看到的是，一方面，IBM臃肿的组织架构已经很难满足沃森所代表的新的商业化时代所需要的动力，因此削减阻碍的中间部分。另一方面，IBM的硬件业务已经缩减到了10%左右，而其占绝大部分营收的服务业务也处于衰减的趋势。

对于2015年2月可能的裁员，主要源于IBM已经连续数个季度收入下降和客户流失。事实上，裁员的消息近年来一直影响着这个IT行业的“蓝色巨人”。

2013年第三季度的财报电话会议中，IBM前CFO Mark Loughridge表示，有三分之二的硬件业务下滑是由于在发展中国市场表现不佳，而其中二分之一又主要受中国市场业务下滑影响。于是，2014年中国区大裁员就顺理成章提上了议案。

最早的动作来自于联想对IBM X86 PC服务器业务的收购。该生产线工人因不满被转移至联想，在2014年举行了长达2周的抗议。此时，已有一些在IBM工作超过10年甚至15年的老员工离开。

不仅如此，IBM还在中国各个部门都制定了不同程度的裁员计划，其中包括三个在华研发机构，甚至有个别地区的销售团队集体被裁员。

有前员工表示，IBM这几年其实一直在裁员，只不过中国作为业绩增长最好的市场，躲过了之前的裁员。但是他没想过的是这样的裁员只是前奏，IBM在印度班加罗尔等地的分支机构随后也同样受到波及。2014年2月26日，IBM宣布启动“阿波罗计划”，裁员人数约为1.3万人，而其希望借此节省约10亿美元的开支。

然而，就在这项计划的结果尚未明朗时，更新一轮的大规模裁员或将再度公布。
