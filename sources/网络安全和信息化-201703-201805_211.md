# 为AI打Cal！ 海云捷迅成为“2018数博会全球AI大赛”支撑平台

1月19日，《2018数博会人工智能全球大赛启动暨开放创新平台上线新闻发布会》于北京召开，海云捷迅作为“2018数博会人工智能全球大赛”的支撑平台之一，积极响应并全力配合本次盛会。本次盛会向与会者公布了人工智能大赛的赛程、人工智能创新平台的价值，并对外宣布了人工智能大赛的报名标准及方式方法，意向企业及团队敬请关注赛事发展。

 

![](../Images/46f51d83a87f3cf31f61ea88ac8eac2b.png)

大会现场

 

自从AlphaGo战胜了李世石，人工智能便跃到众人眼前，这是人工智能里程碑式的胜利。人们强烈的感受到了人工智能的强大力量。自此人工智能开始潜入人们的生活、工作中的方方面面。不可否认，人工智能行业未来的发展的空间是广阔的。为了带动人工智能快速发展，2018年数博会以“大数据与实体经济深度融合”为年度主题，通过“同期两会、一展、一赛、论坛及系列活动”。其中，“一赛”即“2018中国国际大数据融合创新•人工智能大赛”。

 

该场大赛定位为国家级、国际化赛事，通过加强与国内外人工智能领军企业合作，招募优秀创新发展团队，搭建国际化人工智能交流平台，推动大数据融合创新生态圈建设，为推动互联网、大数据、人工智能和实体经济深度融合注入新动能。

![](../Images/b4bb5911c3ce404eab3fbe0e7324b0f1.png)

平台框架  

 

海云捷迅作为本届大赛的参与支持团队之一，将协助英特尔、数博会组委会等合作伙伴，积极做好大赛的幕后工作。并为大赛提供稳定、适用的人工智能专用云平台，力求能够助力大赛顺利进行。在2018年，海云捷迅将与合作伙伴一起，通过举办“两会”、“一展”、“一赛”、论坛等一系列活动，在人工智能领域相关技术研究、产业化创新应用、人才培养与成长等方向同时发力，打造出中国人工智能领域产、学、研紧密结合的高端前沿交流平台。

 

对于人工智能领域的快速崛起，海云捷迅与时俱进，作为云计算提供商，海云捷迅更为关心的是如何让人工智能像云计算、大数据一样快速落地，遍地开花。早在2017年初，海云捷迅便参与了英特尔人工智能基础平台建设项目，为未来中国人工智能的发展提供完善的计算机基础设施服务。为人工智能产业发展提供了源源不断的动力，推动行业向更远、更深层次壮大。

 

在未来，国内会有一大批公司积极投入人工智能领域，带动国内人工智能快速发展。海云捷迅将与众多合作伙伴一起，打造实用各种类型人工智能公司的IT基础设施平台，促进人工智能企业快速发展。
