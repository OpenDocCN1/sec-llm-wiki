# 2017(第十五届)中国信息技术创新大会在京圆满召开！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649139558&idx=1&sn=71b95f59708d142aba3aee0460023a27&chksm=be8b207a89fca96c5863596ea91e0fe001180527650d9c99ebc1c3de15e6c1569d9a8d2bd60f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649139558&idx=1&sn=71b95f59708d142aba3aee0460023a27&chksm=be8b207a89fca96c5863596ea91e0fe001180527650d9c99ebc1c3de15e6c1569d9a8d2bd60f&scene=27#wechat_redirect)

12月20日，由中国电子信息产业发展研究院（暨赛迪集团）主办，IT运维网，《网络安全和信息化》杂志社承办的2017（第十五届）中国信息技术创新大会在北京新世纪日航酒店成功举行。

![](../Images/17ea08883ee989a53c6bf690b7700c3a.png)

本届大会以“智能驱动未来”为主题，邀请各行业（政府、制造，金融，互联网，能源，制造业，教育，交通，医疗等）信息化主管、企业代表、业内专家，旨在从应用角度出发，全面阐述以人工智能为代表的创新技术，在提速企业数据化、行业信息化发展方面所带来的深远影响。

![](../Images/53018733d5707dfe26c4b16a9e3b300a.png)

在大会举办之前，通过IT运维网调查，同时结合相关专家的评审意见，评选出了具有含金量的“2017中国信息技术创新大会”的各项奖项，这些奖项在大会现场进行了表彰和公布。

具体获奖情况如下，公司排名不分先后：

  

获得2017年度中国信息技术创新 顶尖大数据服务奖的是：

北京兰云科技有限公司

  

获得2017年度中国信息技术创新  优秀云服务奖的是：

北京智恒网安科技有限公司

北京兰云科技有限公司

  

获得2017年度中国信息技术创新  网络安全优秀解决方案的是：

北京久安世纪科技有限公司

北京兰云科技有限公司

  

获得2017年度中国信息技术创新  中小企业网络行业优秀解决方案的是：

友讯电子设备（上海）有限公司  智简无线方案

  

获得2017年度中国信息技术创新  最值得信赖网络产品奖的是：

浪潮高性能数据中心核心交换机CN12700系列

  

获得2017年度中国信息技术创新  最值得信赖的IT服务众包平台的是：

中软国际解放号

  

获得2017年度中国信息技术创新  最值得推荐产品奖的是：

天融信数据防泄漏系统

北京杰思安全科技有限公司  猎鹰主机入侵防御系统

广州市立活龙智能设备有限公司  防癌科普阅读及预警手表

ATEN宏正便携式USB笔记本控制端转换器CV211

  

获得2017年度中国信息技术创新  最值得推荐防火墙产品奖的是：

SonicWall NSA 2650

  

获得2017年度中国信息技术创新  密盾数据防泄密（DLP）领域首选品牌的是：
