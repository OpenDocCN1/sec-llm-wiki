# 业界丨天融信注资火绒 终端安全再成焦点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649139392&idx=2&sn=fe6a89f6a114d057fbfdaef926e72a12&chksm=be8b21dc89fca8ca61babac34608811cba2a219c48752a6d4dcd6af9165c110d56d9c6746f8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649139392&idx=2&sn=fe6a89f6a114d057fbfdaef926e72a12&chksm=be8b21dc89fca8ca61babac34608811cba2a219c48752a6d4dcd6af9165c110d56d9c6746f8d&scene=27#wechat_redirect)

近日，北京火绒网络科技有限公司宣布，已完成Pre-A轮融资。老牌安全厂商北京天融信公司向其注资1,500万元人民币，并签署了战略合作协议。火绒将利用其技术优势，帮助天融信打造终端安全产品，完善其下一代网络安全架构体系，携手进军企业终端安全市场。

成立于2011年的火绒，是安全创业公司中的另类，不畏360、腾讯管家等强大对手，以“独立、纯粹”的姿态，执着耕耘在PC安全领域，经过长达6年的沉寂前行才逐渐浮出水面。火绒拥有新一代反病毒引擎等多项核心技术，被认为是终端安全领域的新锐，其倡导的“情报驱动安全”新理念也日渐被同行所认可。

火绒安全CEO刘刚表示：“感谢天融信的认可和帮助，我们有相同的理念，坚持以客户需求为产品核心，这是达成合作的重要原因。这轮融资对火绒意义很大，在获得投资的同时，还将通过技术合作，获得长期、稳定的商业收入“。

目前，政府、企业的办公电脑、服务器等终端设备的安全防护需求，日益受到关注，被认为是安全市场的新增长点，天融信、绿盟、深信服、启明星辰等一线安全厂商纷纷开始布局。通过6年时间完成了技术积累的火绒，可以说是恰逢其时。除天融信外，深信服、绿盟以及PC巨头联想，都已经和火绒展开技术合作，在相关产品中使用火绒的引擎和功能模块。

火绒并不满足于成为行业最大的技术输出者，即将推出自己的企业级产品“火绒企业安全软件1.0版”。针对个人用户的“火绒安全软件”已积累了数百万粉丝用户，许多IT从业者和企业网管都是火绒的拥趸。目前火绒正在组建销售团队，试图凭借其在重度技术用户中的优质口碑，撬动企业市场。

天融信CEO于海波认为，“随着各行业信息化水平的不断提升以及安全意识的增强，企业用户对于终端安全防护的需求不断增长，终端安全市场前景广阔，极有可能成为安全领域的风口，之所以和火绒合作，是非常看好火绒的技术实力。此次投资火绒，并达成深度战略合作,是期望借助火绒的技术为客户提供更加安全、快速的服务。”

  

**关于火绒**

火绒成立于2011年，长期专注于终端安全领域，潜心研发引擎等底层技术，秉承“情报驱动安全”理念，率先构建完成EDR（终端、检测和响应）运营体系，逐渐开始领跑终端安全领域。火绒安全2012年发布的“火绒安全软件”是一款免费个人电脑安全软件，经过数年口碑相传，积累了以技术人员、专业人士、意见领袖为主的数百万用户。被认为是最纯粹的安全软件，以功能强悍、无流氓行为、占用资源少赢得了良好的口碑。火绒将于近期推出第一款商业化产品“火绒企业安全软件1.0版”，正式进军企业级市场。

  

**关于天融信**

天融信成立于1995年，是中国领先的网络安全、大数据与安全云服务提供商。作为国家规划布局内重点软件企业，累计出货量330,000+套，在线运行产品160,000+套，行业客户覆盖100,000+家，遍布政府、军队、金融、电信、教育、医疗、制造等各行各业。曾被评为中国电子政务100强企业、德勤亚太高成长100强企业、《福布斯》中国最具潜力非上市企业等。
