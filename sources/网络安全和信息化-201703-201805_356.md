1.远程终端管理工具**Xshell**被**植入后门代码**  
  
近日，非常流行的远程终端Xshell被发现被植入了后门代码，用户如果使用了特洛伊化的Xshell工具版本可能导致所敏感信息被泄露到攻击者所控制的机器。以下版本受影响，Xshell5.0 Build 1322、Xshell 5.0 Build 1325、Xmanager Enterprise 5.0 Build 1232、Xmanager5.0 Build 1045、Xftp 5.0 Build 1218、Xlpd 5.0 Build 1220。

2.研究者发现针对**美国国防**承包商**攻击活动**  
安全厂商Palo Alto Networks的安全研究团队Unit 42发现针对美国国防承包商的攻击活动，并且表示自从上一次报告（2017年4月）以来，攻击组织没有停止攻击一直持续到2017年7月。在最近的活动中，攻击者使用类似的TTP，例如将武器化office文档，并将韩语转为英语。值得注意的是，诱饵文件主题中出现美国国防承包商的工作角色描述和一些内部政策。

  

![](../Images/7571cb52ab5bf5bae1a3824471de5db7.png)

  

 

3.安全厂商发现利用**0199漏洞**新型恶意样本  
  
安全厂商趋势科技最近观察到一个新的恶意样本，该样本使用**0day远程代码执行漏洞（CVE-2017-0199），**在开始阶段使用鱼叉式钓鱼攻击投递恶意的PPSX文件，主题内容显示“CVE-2017-8570”，但是实际利用的是并不是该漏洞。通过执行脚本文件得到RATMAN.EXE可执行文件，该文件是 REMCOS远控工具，部署安装后实现后续攻击。由于CVE-2017-0199的多数检测方法都是集中在RTF文件的检测，所以使用新的PPSX矢量文件可以逃避反病毒检测。

 

4.**银行木马**将用户重定向到有**证书伪造网站**  
研究人员发现**Trickbot银行木马**通过邮件钓鱼活动，将受害者重定向到一个与真实银行无法区分的假登录页面，并且具有数字证书。一旦受害者中招，攻击者就可以获取受害者的网上银行凭据和账户密码。

5.全球威胁情报中心发布Q2的威胁情报报告  
  
GTIC Q2威胁**情报报告**介绍了NTT Security研究人员、安全专家以及分析师在过去三个月的研究成果。除了各种各样的开源智能工具和蜜罐外，GTIC-威胁研究（TR）还分析了全球**NTT Security**管理安全服务（MSS）平台的数据，为研究人员更深入地了解整体威胁形势提供数据支持。
