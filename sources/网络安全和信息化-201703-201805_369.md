# 2017中国网络主管论坛西安站成功举行，8月10日武汉再见！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649139102&idx=1&sn=148a5c183966647bf08118a21d09183c&chksm=be8b2e8289fca79465f35c110c9f58aa8f4897b4f52b096e804efd2d5ec4af321b646ece0da4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649139102&idx=1&sn=148a5c183966647bf08118a21d09183c&chksm=be8b2e8289fca79465f35c110c9f58aa8f4897b4f52b096e804efd2d5ec4af321b646ece0da4&scene=27#wechat_redirect)

由中国电子信息产业发展研究院（暨：赛迪集团）主办，《网络安全和信息化》杂志社和IT运维网承办，中国计算机用户协会提供支持，赛迪网独家门户支持的**2017（第十三届）中国网络主管论坛西安站**在西安古都新世界大酒店成功举行，会议现场气氛热烈。
