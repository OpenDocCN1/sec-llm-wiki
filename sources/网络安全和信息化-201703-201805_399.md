卡巴斯基发布报告称，从500万路由器到60亿物联网设备，物联网恶意软件急剧增加；24小时内，蜜罐遭遇的攻击，大多是视频监控系统设备在进行攻击；这些攻击中有19.68%的IP地址来自中国大陆和台湾。

2016年发生了一些事件，让人们对 物联网或 "智能" 设备安全 的兴趣不断增加。其中包括一些破记录的DDoS攻击，比如对法国主机供应商托管 ovh ，以及美国 dns 提供商托管 dyn 攻击事件 。众所周知, 这些攻击是在一个由路由器、ip 摄像机、打印机和其他设备组成的大型僵尸网络的帮助下发起的。

## 从500万路由器到60亿物联网设备 物联网恶意软件急剧增加

去年, 全球形成了一个巨大的僵尸网络, 由近500万路由器组成。黑客利用这些路由器攻击了 德国电信巨头, 运营商的客户使用的设备感染了Mirai物联网恶意软件。黑客并没有在网络硬件上停止，在 miele 智能洗碗机中也发现了安全问题。"icing on the cake" 是 BrickerBot 蠕虫, 它不会像大多数 "同行" 那样感染脆弱的设备, 但却使它们完全无法操作。

![](../Images/a7c0bb985f14e26b8bd31941815e2374.png)

根据 gartner 的数据, 目前地球上有60亿多台设备。这种巨大数量的潜在易受攻击的小东西，不可能被网络攻击者所忽视。截至 2017年5月, 卡巴斯基实验室中收集了数千个不同的恶意软件样本, 其中大约一半是在2017年检测到的。

![](../Images/ed9c50cd6e59ea7d503a79d5c39fa3f4.png)

我们建立了几个蜜罐 (陷阱), 模仿各种运行 linux 的设备, 并让他们连接到互联网,暴露在外， 看看发生了什么事。结果在短短几秒钟后, 我们看到了第一次尝试连接到开放的 telnet 端口。在24小时内, 有数万个来自唯一 ip 地址的尝试连接。

## 大多是视频监控系统设备在进行攻击

试图连接到我们蜜罐的大多数 ip 地址，都响应 http 请求。通常, 每个 ip 地址会有几个设备使用(使用了nat 技术)。响应 http 请求的设备，并不总是攻击我们的蜜罐的设备, 尽管通常情况如此。

## 物联网设备与物联网恶意软件 都在快速增长

针对大量设备和相关安全事件的恶意软件程序越来越多, 这说明智能设备安全问题的严重性。2016已经表明, 这些威胁不仅是概念上的, 而且实际上是非常真实的。现有的 ddos 市场竞争，驱使网络寻找新的资源来发动越来越强大的攻击。Mirai僵尸网络已经表明, 智能设备可用于此目的，今天, 有数十亿个这些设备在全球, 根据分析师的预测,到 2020年, 他们的数量将增长到20-50 亿台设备。

最后, 我们提供了一些建议, 可以帮助保护您的设备免受感染:

*   除非您特别需要使用您的设备，不要允许从本地网络外部访问您的设备；
    
*   禁用使用设备所有不需要的网络服务；
    
*   如果设备有预配置的或默认的密码, 而您无法更改它, 或者您无法停用的预配置帐户, 则禁用它们所使用的网络服务, 或禁止从本地网络以外的范围访问它们。
    
*   在开始使用设备之前, 请更改默认密码并设置新的强密码。
    
*   定期将设备固件更新为最新版本 (当有此类更新可用时)。
    

如果你遵循这些简单的建议, 你会保护自己从现有的很多恶意软件的大部分。
