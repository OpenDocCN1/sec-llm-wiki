安华金和出席第三届Big Data Security on Cloud国际学术研讨会

2017年5月27日，由目前全球最大的非营利性知名国际学术机构IEEE倡导发起的第三届Big Data Security on Cloud国际学术研讨会，在北京大学英杰交流中心举办，安华金和与北京大学、美国纽约佩斯大学等众多国际学术机构一同主办了这场国际学术盛会，安华金和创始人兼CEO刘晓韬博士，受邀进行《Big Data Security Governance》主题学术报告，与国际安全学者共话数据安全。

第三届IEEE国际学术研讨会现场

 

近年来数据存储技术、通讯技术及高通量数据采集技术的进步使得收集和存储海量数据成为可能，从而为在各领域进行大数据分析、提供了前所未有的机遇。但随着海量数据的汇集及信息技术的发展，信息安全已成为制约大数据快速发展的瓶颈。为解决这个难题，刘晓韬博士率先在中国提出了数据安全治理理念，不久前，并以安华金和为倡导发起单位，邀请业界20余家致力于数据安全产业相关的生态伙伴，一起成立了中国首家数据安全治理工作组，刘总单位工作组组长。

安华金和刘晓韬在本次国际学术论坛发表主题演讲

 

安华金和刘晓韬分享大数据安全治理报告

本次研讨会，向国际学术领域的专家学者分享大数据安全治理报告。刘晓韬指出，大数据安全治理是以数据的安全使用为目的的综合管理理念。大数据安全治理核心内容，在于来自对数据的有效理解和分析，这里不仅包含结构性数据，也包括非结构化数据，对各类形态的数据进行不同类别和密级的划分；根据数据的类别和密级制定不同的管理和使用原则，尽可能对数据做到有差别和针对性的防护，实现在适当安全保护下的数据自由流动。

国际学术机构IEEE为安华金和颁发感谢状

本次大会，国际学术机构IEEE分别为安华金和以及CEO刘晓韬先生颁发感谢状，感谢产业代表安华金和在学术研究方面的不懈追求和投入，这份感谢状也让安华金和意识到学术界作为理论支撑有意愿与产业界实践结合共同推动学术研究的热情，作为产业界数据库安全领域领先企业，我们有责任不断吸收学术界的技术研究精髓，让产业与学术高度融合，促进安华金和未来的技术研究创新，带领产业走向更高精尖的发展道路。

 

国际学术机构IEEE颁发给安华金和感谢状


国际信息技术研究和分析机构Gartner，2017年在原有信息安全治理基础之上，提出了数据安全治理概念和全模型，安华金和刘晓韬曾多次与Gartner该领域分析师进行交流和探讨，双方就数据安全治理模型及技术支撑保障、产品演进落地等问题进行了深入意见交换。安华金和作为DSG工作组组长单位，也希望能够与产业生态伙伴，一同推进理念的落地，并在用户实践中赢得信赖，让理论在市场中得到价值检验。
