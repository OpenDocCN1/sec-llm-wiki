# 2019世界计算机大会举办在即：12名院士精彩亮相

2019世界计算机大会将于今年9月9日至11日在湖南长沙梅溪湖国际文化艺术中心和长沙梅溪湖金茂酒店举办。随着大会的日益临近，大会论坛相关细节正陆续公布，敬请期待!

![](../Images/a9b37ccc73c20ecfb83e9e88ebc974be.png)

  

本届世界计算机大会由开幕式、主论坛及九大主题论坛组成。围绕本届大会的“计算万物 湘约未来”主题，侧重于高端化、国际化、专业化的综合性定位，参会的演讲嘉宾包括国际组织代表、国内外顶级科学家，以及国内外计算机领域龙头企业领袖。

**丨群贤毕至，12名院士精彩亮相丨**

![](../Images/a04d55f1effeeecf6129471a04ed21b7.png)

  

  

目前，本届大会已有超过百位演讲嘉宾确认参会，其中包括12名国内外计算机领域知名院士。

**丨开幕式异彩纷呈 主论坛名家荟萃丨**

本届大会将于9月10日上午举办大会开幕式，由政府领导、学界代表和知名企业家的演讲构成，将通过对大会主题的全面诠释，传递中国将以开放胸怀与世界共享计算机领域发展机遇的态度决心和责任使命，构建人类命运共同体。

下午举办的大会主论坛将继续围绕主题，从计算领域硬件技术、软件技术、信息安全技术、网络通信技术、新兴产业应用等多个维度，围绕产业政策、技术创新、商业模式、应用实践等方面展开深入探讨与交流。

**丨主题论坛：聚焦热点•恰逢其时丨**

值得一提的是，九大主题论坛也将同期举行，主题汇集丰富、形式多样，内容涉及当今计算领域的多个热点问题，如计算机生态、万物互联、5G、网络安全、计算芯片、人机连接、AI算法、超高清、数字经济等。届时来自学术界高端学者与企业界重磅嘉宾将在论坛中各显身手，分享个人观点，充分研讨，对具体问题进行分析、辩论。从国际化视角，探讨如何将利用计算机领域的变革发展继续影响全球发展，锚定产业未来发展方向，共同勾勒行业发展蓝图。
