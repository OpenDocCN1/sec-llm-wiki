# 【网络安全五大样板工程】卓豪：漳龙集团桌面及服务台管理

福建漳龙集团有限公司（以下简称“漳龙集团”），是漳州市属国有重点企业之一，经过十几年的发展，漳龙集团形成了供应链运营、建工建材、产业投资、花木景观、资产物业五大板块，布局工程建设、产业发展、花木景观、电商物流、工商贸易、资产运营、物业服务、金融控股、医养健康九大产业，完成了众多省、市重点项目建设，为漳州市的经济和社会腾飞作出了突出贡献。

  

  

**面临问题**

  

随着公司业务的不断扩张，单位规模逐渐扩大，作为单位的信息化服务部门，运维人员的工作量也显著增加，几乎每天都会面对以下问题。

  

**1\. 对外服务**

  

*   没有统一的终端桌面资产管理平台；
    

  

*   无法对用户提出的桌面系统故障进行快速处理；
    
      
    
*   无法实现企业内部桌面系统的补丁和漏洞的统一管理；
    
      
    
*   无法对用户进行有效的远程协助。
    
      
    

**2\. 对内管理**

  

*   无法对用户提出的请求和问题进行自动分配与快速反应；
    

  

*   无法对每个运维人员的工作量进行有效统计。
    

  

  

**解决方案**

  

漳龙集团通过认真细致的测试选型，最终选择了卓豪的Desktop Central和ServiceDesk Plus来对单位内的桌面系统以及服务流程进行管理。

  

首先，Desktop Central可以实现对桌面系统的PC机资产的统一管理。

  

其次，系统还可以对所有的桌面机进行补丁自动安装，有效解决企业内的安全漏洞防护问题。  

  

另外，系统还支持对桌面PC进行安全策略下发、软件自动安装，以及对用户桌面PC的远程访问，很大程度上提高了运维人员的工作效率，并实现了对单位内桌面系统一些常见问题的自动化管理。 

  

![](../Images/6d9597000f1993433ca974dfe7847938.png)

![](../Images/7b455fa82cabb4ec2b6956545e06f101.png)

  

此外，利用ServiceDesk Plus，漳龙集团快速创建了自已的IT运维服务体系，并对单位内用户提出相应的服务目录。原本的电话响应式服务转变成了用户的自助式服务，用户可以根据自身需求在门户网站上选择所需的服务内容，系统会自动将这些服务请求分发给相应的运维管理人员。

  

漳龙集团还实现了对运维管理人员的工作量统计，动态掌握所有运维人员的工作情况，并为提高运维服务质量和满意度提供了很好的数据支持。

  

  

**项目实施效果**

  

使用ManageEngine的Desktop Central和ServiceDesk Plus管理软件可以无缝集成，终端用户可直接提交请求工单至帮助台，进入IT服务流程。

  

因为所有功能完全基于Web功能，可以在任何地方访问系统和移动设备，提供了无与伦比的灵活性，这使得相对落后的运维管理方式变得更加现代化。

  

系统在正式上线使用后大大解放了运维人员的双手，尤其是Desktop Central与ServiceDesk Plus的整合，使用管理软件就能让整个部门的工作效率有了非常明显的提升，基本摒弃了原本的运维管理方式。

  

另外，通过ServiceDesk Plus建立的起来的运维服务流程体系也使运维服务效率和满意度得到了很大的提升，而对工作人员的工作量统计功能更是对企业管理工作大有帮助。

  

ManageEngine Desktop Central和ManageEngine ServiceDesk Plus管理软件是企业信息化运维管理领域非常实用的软件。
