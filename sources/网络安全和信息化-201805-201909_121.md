# Windows再曝高危远程漏洞 建议用户尽快更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649141036&idx=1&sn=4499d7a5443237c300ee57646f1eded0&chksm=be8b263089fcaf2608de9d64164c3fe4d15383a826d123f78f20c1ee65d49c2fd83c20fd1c40&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649141036&idx=1&sn=4499d7a5443237c300ee57646f1eded0&chksm=be8b263089fcaf2608de9d64164c3fe4d15383a826d123f78f20c1ee65d49c2fd83c20fd1c40&scene=27#wechat_redirect)

当地时间5月14日，微软发布了针对远程桌面服务（Remote Desktop Services）的高危远程代码执行漏洞CVE-2019-0708的修复补丁，该漏洞影响了为数众多旧版本的Windows。由于该漏洞属于预身份验证，无需用户交互，这意味着恶意软件可能利用此漏洞实施攻击，与2017年所爆发的WannaCry恶意软件传播方式方式类似，可从一台受攻击的计算机轻易传播到其他易受攻击的计算机。恶意攻击者极有可能利用该漏洞与恶意软件结合实施攻击。

 

**受影响的版本**

*   Windows 7
    
*   Windows Server 2008 R2
    
*   Windows Server 2008
    
*   Windows Server 2003
    
*   Windows XP
    

 

其中Windows Server 2003以及Windows XP已经不再受支持，但此次仍会在KB4500705中为其提供漏洞补丁。

 

Windows 8和Windows 10不受该漏洞的影响。

 

受影响系统上启用网络级身份验证（Network Level Authentication，NLA）可进行部分缓解可能利用该漏洞实施的恶意软件威胁，因为NLA在触发漏洞之前需要进行身份验证。但如果攻击者已经取得了可用于成功进行身份验证的有效凭据，则受影响系统仍易受到远程代码执行攻击。

 

Windows 7和Windows Server 2008可通过系统更新安装补丁，停止支持的Windows 2003和Windows XP可通过https://support.microsoft.com/zh-cn/help/4500705/customer-guidance-for-cve-2019-0708下载安装补丁。建议受影响用户尽快下载补丁升级进行防护。
