# 数据保护护航IT转型——戴尔易安信数据保护解决方案

企业IT环境随业务的变化而需要随时做出改变，当环境和数据保护需求不断演进、或者越来越多的数据需要迁移到云端时，对数据保护的需求也随之而来。

  

在数据保护方面，随需而变尤为重要，戴尔易安信数据保护设备可随客户数据的增长而不断扩展，为客户提供其所需的灵活性。

  

1.  端到端全面数据保护。戴尔易安信数据保护产品组合满足几乎所有数据保护需求，通过可降低成本、增加敏捷性且支持云的数据保护解决方案，帮助客户实现 IT 转型。其中DD3300专为中小型企业和拥有远程办公室的大型企业而设计，用于实现经济高效的备份、归档和灾难恢复；DP4400面向中小型企业的全新集成式数据保护应用装置，提供集备份、重复数据删除、复制与恢复以及基于云的灾难恢复和长期数据保留功能于一体的数据保护；戴尔易安信数据保护软件为各种备份和恢复环境、任务关键型应用程序、虚拟环境、归档数据等提供全面的专用保护。
    
      
    
2.  高效的数据缩减。戴尔易安信的数据保护使用了可变长技术，数据在通过网络发送前就已在客户端完成了唯一段的压缩和重复数据删除，使得网络使用减少了95%，所需存储空间也减少了95％。重复数据删除只存储唯一变化的数据块，让客户能够以更小的空间存储更多数据，可将WAN带宽需求降低95％。
    
      
    
3.  安全性。戴尔易安信数据保护系统支持安全多租户、飞行加密、静态加密，并与多个关键管理系统集成。该系统还支持带有管理或合规性版本的保留锁定，以满足严格的数据保护和监管标准。
    
      
    
4.  云集成。为帮助客户简化和自动化其云路径，戴尔易安信数据保护提供了云分层技术，能够在降低TCO的同时获得云优势。在云灾难恢复方面，允许企业通过编排和自动化灾难恢复测试，将受保护的VM从本地存储复制到公有云，并在灾难情况下提供简单的DR故障转移和第2层工作负载与云之间的切换。
    
      
    

在“2019中国企业级数据中心智慧运营高峰论坛”上， 戴尔易安信数据保护解决方案荣获“绿色数据中心优秀产品奖”。
