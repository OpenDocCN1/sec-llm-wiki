# RSA 2019最热门的网络安全创新产品

今年的 RSA 大会是安全厂商展示其最新网络安全产品的重要场所。 以下介绍一些非常有趣的安全工具。

**简**

**介**

  

**Arecabay：Force Field**

  

![](../Images/1777cac379efd4ed8152d19547c35e6d.png)

Force Field 允许开发人员或安全团队部署充当网络嗅探器的软件微传感器。 Arecabay统称为网络引擎。 它们不需要在运行时对应用程序进行代码更改。 部署后，企业可以执行三步流程以确保 API 完整性：发现/测试，监控和保护所有 API。

 

**Arxan：快速保护和威胁检测**

![](../Images/403dbe49458b466616959eb27aa4d623.png)

Arxan 在其移动、混合和 Web 应用程序保护解决方案中增加了新的快速保护和威胁检测功能。 这种新功能允许代码保护和威胁检测传感器在代码开发后的 DevOps 过程中注入应用程序。

  

**Attivo Networks：The Informer**

  

![](../Images/23d89e347c777c1ebabbd5febeb420fc.png)

Informer是一种基于欺骗的实时取证收集产品，扩展了 Attivo 的 ThreatDefend 检测和响应平台。 该新工具提供了攻击者活动的视图，可加速情报驱动的响应和补救，增强快速收集、理解和传播攻击情报的能力。

  

**Bloombase：StoreSafe智能存储防火墙4.0**

  

![](../Images/624d14f447439d6b1f229310e067949d.png)

这一最新版本的 StoreSafe 智能存储防火墙可以为传统存储系统和下一代云存储服务提供企业有价值资产的自动发现和分类。 它提供应用程序透明加密保护和静态数据自动重定制。 这使组织能够锁定存储上的数字资产，从而减轻数据泄漏威胁。

  

**Cognigo：dataSense**

  

![](../Images/a40650b1584ce41c61c0d39604a0c21f.png)

DataSense 是一个基于人工智能的平台，用于企业数据保护和合规性。  Cognigo 声称产品的自然语言处理（NLP）语境化功能可以根据语言上下文区分敏感数据和非敏感数据，这对于自动发现受 GDPR 等数据保护法规保护的数据非常有用。

  

**Comodo Cybersecurity：MDR**

  

![](../Images/e2001adb2dc8266254fee5231b3be9a3.png)

comodo 管理检测与响应（MDR）属于安全运营中心即服务（SOCaaS），它提供了一个安全研究团队，他们监控IT系统是否存在妥协迹象并寻找漏洞。 该服务依赖于 Comodo 的 SIEM 和端点管理技术，以及 Comodo 威胁实验室的威胁情报。MDR 服务可与企业合作，确定问题的优先级和补救问题。

  

**Cyxtera：AppGate SDP物联网连接器**

  

![](../Images/b01818ae26ec65e4a3262e8914ebfd14.png)

AppGate SDP loT 连接器通过使用零信任原则，限制内网漫游和减少企业的攻击面来帮助保护未受管设备。 作为 Cyxtera 的 AppGate 平台的一部分， loT Connector 可以精确控制设备连接到网络的方式和时间，以及其连接的网络资源。

  

**DataLocker：PortBocker**

  

![](../Images/510e86d738fe740d70ee30f634718f8c.png)

PortBlocker 是一种端点保护代理，可通过 USB 端口防止数据泄露或恶意软件传输，从而帮助保护用户工作站上的 USB 设备。 它与 DataLocker 的SafeConsole 中央管理平台集成，可远程部署和管理。PortBlocker 仅允许安装白名单 USB 设备，它还记录 USB 活动并报告给 SafeConsole 管理服务器以进行审核。

  

**Eclypsium：Eclypsium Platform v1.0**

  

![](../Images/704d77365f9e1f108843d35416ff1c2d.png)

Eclypsium 平台监控那些存在已知和未知威胁的固件，以及供应链中设备篡改的迹象，它还有助于管理 PC 、服务器和网络设备上的固件风险和更新。 Eclypsium 平台支持云和本地部署模型。

  

**FireMon：Lumeta 云可见性**

  

![](../Images/5708751c0f0c453d913e99b6edc3a860.png)

Lumeta 云可见性提供实时基础架构可见性，包括针对混合企业的安全异常检测。 它建立在其前身 Lumeta Spectrea 网络和端点发现解决方案的基础之上。FireMon 声称，借助 Lumeta  云可见性，无论云平台如何，企业都可以在云迁移的任何阶段执行变更监控和泄漏路径检测，适用于物理、虚拟、软件定义、内部部署和混合环境。

 

**Idaptive：下一代接入云**

  

![](../Images/da163738759f312a75caf9edd3273cf8.png)

ldaptive 的下一代接入云旨在支持企业零信任的身份识别与访问管理（IAM），它可以在不断学习和适应数百万个风险因素的同时，验证和确认人员、设备和服务。Idaptive 声称下一代接入云是唯一的结合了单点登录自适应多因素身份验证、端点和移动环境以及行为分析和机器学习的解决方案。

  

**ImageWare Systems：数字身份平台**

  

![](../Images/c84f8f6ebb37e80c14f26c9f768b7088.png)

ImageWare 的数字身份平台提供端到端的数字身份证明、身份验证和生命周期管理解决方案。 它可用于云 SaaS 和本地系统，该平台有多种选择，其中 APls 允许定制解决方案。身份验证允许企业验证个人的数字身份，身份验证提供了广泛的生物识别和其他多因素身份验证方法。 该平台还提供了跨企业开发数字身份生态系统的框架。

  

**Nominet：Nominet NTX**

  

![](../Images/2675a37241243b61c9128f5dc6f06d56.png)

Nominet NTX 监控 DNS 级别的网络威胁，这是网络犯罪分子经常利用的主要盲点。 Nominet 表示，它使用声学领域的概念来发现 DNS 流量噪声中的异常。 NTX 实时分析数十亿个数据包，以查明并消除恶意活动。

  

**Owl Cyber Defense：Recon1U**

  

![](../Images/463dec9afb38b15daf63fe41371a22ef.png)

Owl ReCon1U 是一种数据驱动的网络安全解决方案，旨在需要双向通信的情况下减少企业的攻击面。 该公司声称它提供比传统防火墙更高的安全保障。  ReCon1U 将硬件强制网络安全解决方案的安全优势与安全的往返双向通信相结合。

  

**PasswordPing：PasswordPing活动目录**

  

![](../Images/a529e0af46607e45bd9f1aee436d3381.png)

PasswordPing 活动目录是一种检测受损凭据的工具：其活动目录服务通过筛选已知受损凭据的用户帐户来保护企业活动目录网络免受未经授权的访问和欺诈，从而将其阻断。

  

**SaltStack：SaltStack SecOps**

  

![](../Images/174feeef901535b79725cdb819b46215.png)

SaltStack SecOps 允许安全专业人员和IT运营团队一同定义合规性策略，以扫描所有系统及检测和修复问题。 它依赖于 SaltStack 的事件驱动自动化。 SaltStack SecOps 包括访问主要 Unix 和 Windows 操作系统以及运行 Docker 和 Kubernetes 的容器化环境的标准合规性配置文件存储库。

  

**SecBI：自动化威胁检测和响应**

  

![](../Images/e6ee0f80466f8cd704df707d646bd540.png)

SecBI 的自动化威胁检测和响应是针对托管安全服务提供商（MSSPs）的解决方案，其通过分析网络流量和破坏响应来自动化检测威胁。 该服务通过将警报、事件和日志组合到一起来创建每个事件的综合视图，其显示所有受影响的记录和 kill chain。

  

**SureCloud：第三方风险管理（TPRM）**

  

![](../Images/6b0a82318ba7b042de83ca768dee3237.png)

TPRM 可将第三方风险管理流程自动化，并与更广泛的IT风险管理流程和数据隐私计划集成。 它有助于创建第三方的集中注册、构建并自动发送多个评估，并整合所有响应。控制面板和报告框架提供了跨供应商的全面视图以及其可能给企业带来的风险。

  

**Unisys：Stealth 4.0**

  

![](../Images/8d43e3a393a1d670b51eaf34cfce8d30.png)

Stealth 4.0 在应对与云、移动和物联网相关的不断上升的威胁方面具有增强功能，它与 LogRhythm 公司的安全事件和事件管理（SIEM）系统的集成，为 Stealth 4.0 提供了 “动态隔离”功能，可在出现威胁时第一时间快速隔离设备或用户。

  

**Unisys：Stealth（身份）**

  

![](../Images/87828dadf0ee1a85c4efdb92b21131e1.png)

Unisys Stealth（身份）是一种生物识别身份管理软件，可自动进行大规模生物识别登记处理。它支持指纹、面部、语音和虹膜识别以及行为生物识别。 Stealth（身份）提供可配置的API接口，用于跨物理和数字通道（包括移动设备）集成生物识别身份验证。

  

**Vade Secure：Vade Secure for Office 365**

  

![](../Images/ac7defc9d9ca79980172e229d610b5cb.png)

 Vade Secure for Office 365 可检测高级网络钓鱼、鱼叉式网络钓鱼和恶意软件攻击。 它与您的电子邮件环境集成，并通过基于 Al 的预测电子邮件防御增强 Office 365 安全性。 该工具不需要员工培训或其他附加界面。

  

**Veridium：基于 VeridiumID 的****Veridium InMotion**

  

![](../Images/c86a996459f13477aebbdcde36a44933.png)

基于 VeridiumID 的 Veridium InMotion 是一个用于移动生物识别身份验证的软件平台， Veridium 的用户行为分析（UBA）框架可识别人类行为模式并对其进行分析，以检测可能表明存在威胁的异常情况。 将智能手机上捕获的行为数据与用户的生物识别技术进行匹配可以提高身份验证的可靠性，使恶意行为者更难以欺骗他们的指纹或面孔以获取对公司帐户的访问权限。

  

**Xton Technologies：XTAM混合接入安全代理**

  

![](../Images/559be09022171a7804591f3bb2ce2292.png)

XTAM 混合接入安全代理是用于企业网络和云基础架构的访问控制软件，一旦在防火墙后面的系统被攻入，企业就可以通过 XTAM 混合接入安全代理来限制只能使用活动目录登录、单点登录（SSO）或多因素身份验证（MFA）访问受信任的人员。 它还提供审计和合规性所需的监控、视频录制和通知。
