# 山石网科罗东平：秉持工匠精神，勇挑产业担当，携手扬帆起航

作为亚太地区最受瞩目的网络安全年度盛会 ISC （互联网安全大会）已经迎来了第六个年头。今年的ISC大会以“安全从0开始”为主题，在为期三天的时间里共召开3场峰会、25场行业论坛及5大特色活动。

![](../Images/ae107fd1f6d37644ce0db04861b9d558.png)

大会第二日，**山石网科CEO罗东平先生受邀参加由ISC主办方联合相关协会、联盟共同举办的第二届《中国网络安全产业担当与发展高峰论坛》****，并发表了题为“网络安全长板合力2.0”的主题演讲**，和与会嘉宾共同谈到我国网络安全产业的变革发展之道。  

 

在去年的ISC大会上，罗东平先生就曾分享过关于中国网络安全企业“走出去”的国际化战略构想。国内的网络安全厂商与其受制于技术能力的不足，拥挤在国内市场，面对广大的海外市场望洋生叹，不如把各自最具优势的核心技术做到卓越甚至世界级领先水平，各个企业之间长板合力。这样不仅能够促进国内网信安全生态的和谐发展，更有助于提升国内网络安全企业在国际市场的影响力和竞争力，进而使我国在全球的网络经济领域甚至全方面维度拥有更重要的地位和话语权。

![](../Images/c908063bb05e0ea087303ea290b47a3f.png)

   

今年，大会再一次请到罗东平先生，发表题为“网络安全长板合力2.0”的演讲。2018发生了不少事情，国内大众对我国的高科技能力从乐观转变为担忧。罗东平表示任何事情都需要认真客观地去分析，过度乐观和过度悲观都不可取。会上，罗东平先生分享了一组数据，对比了中外安全厂商的营收、研发投入占比及投入绝对值。看过这几组对比，再回过头来看Gartner的魔力象限，便不难理解，为什么国内的网络安全厂商基本都分布于左下角的第三象限。最直接的一个原因就是**国内安全厂商在研发上面的投入严重不足**。

![](../Images/bc4e753f815db8c45a8123a773c1e251.png)

Gartner的魔力象限中的第三象限被叫做“Niche Player”，是指厂商在细分领域有一定的优势。如果这样的优势体现技术和产品维度，这不是坏的事情，反而是好的事情。简单说，就是你的某几项技术和产品在全球范围内是具有竞争力的，那么潜台词可能是你有能力拥有全球市场。但是，我们国内的厂家目前所处在这个“Niche Player”象限，更大的原因是我们可能是在区域细分市场上面有优势。说简单点，可能就是**我们在中国还不错，但是出了国门可能没有什么竞争力**。罗东平说：“**在我们网络安全行业，网络攻击是没有区域之分的。只是在国内市场游刃有余是完全不够的。**我们这样就像是在塑料大棚里愉快地生长，但是一阵大风可能就把大棚整个掀翻。”所以，当前在国际舞台上，国内网络安全厂商既没有占据领导地位，也没有占据创新者的地位。

![](../Images/8318d2d30a7f220b21e3d952e940cf80.png)

**但，我们真的一无是处吗？**

 

在提出这一问题后，罗东平先生也提及了包括山石网科，安天，华为等几个在技术上面投入得相对比较多的厂商所取得的一些成绩亮点。比如安天，虽然目前规模还小，但在安全能力方面积极地拓展，申报专利数量接近900项，有200多项专利获批。

 

2016年，一个不被国人熟知却是在世界范围内最受认可的第三方实验室**NSS Labs**的报告闯入了国内网络安全圈儿的视野。因为山石网科和华为双双在最为严苛的测试中取得非常优异的成绩。这个严苛的测试只接收设备，测试过程中厂商人员完全无法参与。你的设备要能扛过连续30天24小时不间断的饱和攻击，才能通过测试。 

2018年年初，在法国举办了**欧盟电信NFV标准互联通测试**。此次测试是基于未来5G的标准，这些标准也是云计算厂家借鉴的方向。在ETSI的测试中，国内外的很多电信商都在场，国内安全厂家只有山石网科参加。在现场，得益于我们对标准认真、透彻的理解，得益于我们在云计算行业的领先实践，山石网科成为现场不少厂家追逐的对象，因为大家都希望先和我们的设备互通成功，来找到自己可能存在的理解差异。

![](../Images/ff25791a7326de001a8ceea79b7cf90e.png)

这些恰恰说明了，即使我们在Gartner魔力象限上的位置并不太好，但我们并非一无是处。**只要我们秉持工匠精神，****在擅长的领域投入更多，认认真真地发展自己的技术和产品，我们就能把核心技术和产品做得更强大！**作为国内领先的网络安全厂商，山石网科始终专注于网络安全领域前沿技术的创新。山石网科现有900余名员工，其中研发人员占了40%以上，这更说明了**山石网科对于技术研发不遗余力的投入。**

 

网络威胁和网络安全是全球性的，国内网络安全厂商的产品和服务需要充分参与到全球的市场竞争当中去，通过竞争我们才能够了解到自身水平和能力，从而更好地优化国有品牌的综合实力、提升中国企业的技术创新动力。同时，网络安全是一个庞大的、包罗万象的技术体系，全世界范围内也没有一家网络安全厂商可以覆盖这个体系的全部，更不用讲把体系中各个技术门类都做得很优秀。

 

“这好比建造一艘能走出国门乘风破浪的大船，虽然目前并不是我们这些网络安全企业可以做到的，但如果我们的每一块木板都是脆弱不堪，何以抵抗大风大浪？只有我们先把自己的船板一块一款都建造结实，待时机成熟时，才能合力建造出一艘坚实的大船，载国内的网络安全产业走上国际舞台”罗东平先生说。

![](../Images/243eff4d86c918dc2e37ce4091434c02.png)

**网络安全企业的担当**

 

那么，作为一个企业，我们如何打造这块船板？如何去担当？罗东平先生讲到：**“第一，为了我们客户的安全要竭尽全力；第二，真心实意地在技术上面进行投入，认认真真地做好自己的产品；第三，是我认为非常重要的，就是要善待自己的员工，因为你的产品是靠这些优秀的头脑做出来的。善待员工才能有好的产品，才能为我们的客户的安全竭尽全力。”**

 

同时，产业政策及行业协会、联盟也都是实现产业担当的重要推动力。最近山石网科加入了由新华社经济参考报发起的国家网信安全生态建设联盟，在联盟的带动下，实现创新链+产品链+服务链的深度融合，把需求方和产品技术两方面直接结合起来，让技术和创新有正确的方向，同时也让需求得以落地。

 

演讲最后，罗东平先生说：“我坚信10年之后，我们会有一些网络安全企业能够跻身于领导者的行列。”

关于山石网科

山石网科是中国网络安全行业的领军企业，自2006年成立以来即专注于网络安全领域前沿技术的创新，致力于为用户提供全方位、更智能、零打扰的网络安全解决方案。山石网科的业务涵盖云计算安全、边界安全、内网安全、数据安全、安全运维以及安全服务，为来自政府、金融、运营商、互联网、教育等行业的超过15000家客户提供高效、稳定的安全防护。山石网科在中国北京、苏州和美国硅谷均设有研发和技术支持中心，业务版图已经覆盖了全球50多个国家。
