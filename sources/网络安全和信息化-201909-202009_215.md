**产品介绍**

豪越自主研发的HYDO智能运维大数据管理平台，开创性实现了大规模数据中心的统一集中管理、高效实时监控和远程自动化运维。在远程运维方面，可实现以下3个方面功能：远程监控：远程查看、监控设备运行状态；预警、告警：设备远程故障预警、告警；远程故障诊断：通过远程诊断方式解决设备出现的问题，快速维修且降低维护成本。  

  

HYDO涵盖IT基础设施、IT硬件设备、软件业务系统等，实现多类型指标的精准管理和可视化呈现；具有故障自愈功能，开启全天候无人值守模式；开创移动运维解决方案，大幅降低运维成本；基于大数据平台的分析与挖掘，构建AI平台助力用户实现智能化运维。

  

**远程在线监控**

传统运维方式，设备运行状态一无所知，存在线下运维服务成本高、服务不及时等问题。通过远程运维方式，服务器、网络设备、应用系统等一目了然。远程运维既能满足远程设备运维、设备维护、设备管理等需求，也为企业用户提供了更科学高效的管理工具。

  

远程运维在雪亮工程、平安城市等视频运维监控方面，尤其明显。通过HYDO智能运维管理平台，可以检测摄像机故障及视频相关设备故障，监控视频链路可用性及视频质量；能够检测视频编码设备硬盘状态、前端编码设备录像状态等；可以检测摄像机、编码设备是否正常工作；可以在视频设备出现故障时进行告警。

  

**配置管理**

HYDO提供面向运维人员的IT对象配置管理，覆盖数据中心的动力环境设备，网络和服务器设备，软件与业务系统等众多被管对象。平台提供设备基础信息、进程服务、拓扑关系等资源的配置管理功能，支持自动发现和配置，并具备丰富的API接口。

  

**监控告警**

HYDO实现了数据中心基础设备到业务系统的全面监控，提供网络与主机设备、应用服务、平台系统等多维度/多指标的全方位监控告警服务。HYDO采用灵活、高效、支持多模态的告警引擎，经过多年的应用和改进，具有完善的预警策略和处置机制；支持动态阈值、自动合并以及自定义告警设置，同时提供多种告警方式，包括微信、邮件、短信、声光等。

  

**远程运维**

HYDO平台实现主动式问题处理，通过采集层，对IT被管对象的状态信息进行实时收集与主动监控，在发生异常后极大缩短问题处理整体时间，保证业务恢复快速，同时自动工单推送机制确保问题处理过程实时可查。

  

HYDO平台提出创新的远程运维模式，制定标准SLA，提供线上/线下、驻场/远程等多种运维服务模式作为客户团队的延伸，有效解决客户运维能力不足，新技术上线困难、运维团队成本高，管理不便等问题。同时将豪越积累的运维经验以知识库方式进行分享，提供更专业运维服务内容。

  

**可视化呈现**

HYDO平台实现了数据中心各环节和资源整体运行状态的统一、集中可视化呈现。通过数据大屏实时监测数据中心运行数据，了解数据动态变化趋势和异常状态。数据驾驶舱掌控全局，助力企业智能高效决策。

HYDO平台依托自身多年运维经验，从客户真实需求出发，科学全面梳理数据逻辑，深入挖掘数据价值，以可视化方式动态呈现，让数据的价值看得见，提供，更直观更智能的决策场景体验。

  

**数据分析**

HYDO平台专注于智能运维领域的大数据平台建设与数据挖掘分析，通过数据采集、清洗、分析到直观实时的数据可视化，以海量数据采集、实时/离线分析计算、数据可视化、大容量存储等技术优势，结合多年深耕运维领域的经验，专注打造专业的运维数据分析与运营解决方案，实现从敏捷分析到智能决策，构建企业决策大脑。

  

**优势特色**

**远程解决问题更便捷、畅通：**用户通过统一入口可图文并茂地提交运维需求，运维部门即可根据具体情况选派相应运维人员进行远程服务。运维人员随时随地处理服务工单，远程服务效率大幅提升。

  

**远程运维成本更低：**通过远程运维定位诊断，减少无效的线下运维，节省时间成本和经济成本。支持远程调试和远程升级，快速便捷解决问题。

  

**面向自动化、智能化的发展：**以技术融合为驱动，HYDO平台结合云计算、大数据、人工智能等新兴技术，帮助客户快速适应新的应用模式，充分发挥用户自身和我们的专业能力。

  

**突破机制体制实现数据融合：**以数据融合为驱动，HYDO致力于帮助客户突破机制体制的壁垒，实现数据的融合，深入挖掘数据的潜在价值。

**解决方案**

  

**方案理念**

IT 运维管理是一种以服务为中心、以流程为基础、以客户满意和服务品质为核心的管理体系，具有通用性、客观性和实用性的 IT 管理方法，能让 IT 资源发挥最大效能，并协助企业 IT 部门由传统的操作导向升级为服务导向。

  

针对企业的 IT 支持和管理部门实际需求， IT 服务管理思想，结合在网络管理领域的丰富经验，HYDO智能运维管理系统整合了资源获取、网络监控、系统监控、应用监控、工作流引擎等多种技术手段，提出了一套完整的远程运维解决方案，如下图所示：

![](../Images/317de37adcf2629e91cbf7c6165254b3.png)

HYDO智能运维管理系统以实体化的工具产品作为完善的技术手段，从整合资产、面向应用的综合监控、固化管理体系的服务流程、保障安全运行四个方面用来全面监管企业IT 环境中各种各样的 IT 资源，把人员、技术工具组成一个有机的整体，根据实践情况进行流程优化，持续提升企业 IT 管理水平。

  

**技术先进性**

  

HYDO智能运维管理系统采用国际工业标准，遵循 IETF RFC 规范与被管对象进行标准化的、开放化的通信管理。

  

**1.一站式解决方案**

IT 运维管理系统采用先进的集成化、定制化、性能优化的安装部署方式。操作系统、应用软件、数据库等系统组件均一体化封装到一个Docker中。IT 运维管理系统的部署采用容器安装方式部署，在裸服务器上直接一步安装操作系统、应用软件、应用服务器、数据库等全部软件。操作系统安装过程中就自动安装完毕所有所需的软件，并自动进行最佳配置调优，并完成安全更新，安全加固。

  

**2.无代理采集**

HYDO智能运维管理系统无需在被管对象设备上部署数据采集代理；IT 运维管理系统采用标准的管理协议（如SNMP、TELNET、SSH、Syslog、IPMI、XML、CORBA 等）与被管对象进行数据采集通讯。

  

**3.被管对象广泛支持**

IT 运维管理系统支持主流标准的被管对象。除已知被管系统可以直接支持以外，还可以根据用户环境特殊情况，单独按需接入其他被管对象。充分满足客户需求。

  

**4.数据开放性**

IT 运维管理系统支持将采集监控数据通过标准化接口开放给第三方进行读取。

  

**5.先进的拓扑发现算法**

HYDO智能运维管理系统采用自主发明的先进的拓扑发现算法进行全面的拓扑发现和自动计算。被管对象无需是统一厂家的设备，各类厂家的各类设备只要在网络中存在真实连接关系，IT运维管理系统均能利用自身先进的拓扑发现算法采集发现网络的设备并自动计算生成完整的拓扑图。

  

**6.设备真实面板技术**

HYDO智能运维管理系统采用先进的矢量技术，将被管设备的物理面板外形通过系统界面展示给用户。接口信息、告警信息均可图形化的展示给用户，方面用户在系统中直接定位设备有关接口、位置、机柜、机房等位置属性信息，一目了然。
