# 关注复产复工丨犀思云科学复工助发展

受到新型冠状病毒肺炎疫情的影响，很多企业为了更好地服务客户，不断加大线上业务的比例。犀思云网内业务数据产生了更多的峰值需求。凭借犀思云稳固的SDN技术架构和预置丰富的网络资源，再加上经验丰富的7x24小时服务的技术团队，可以安全、敏捷和稳固地满足网内近千家客户的服务要求。

 

春节后，随着国家部分关键行业岗位的复工，学校停课不停学的网上开学，很多企业需要新增网络资源。为了更好方便服务客户，犀思云也积极科学复工，共克疫情。

 

目前，犀思云已全员复工。为遵从政府的隔离要求，保障员工的安全健康，犀思云做了充分的保障工作：多方检测，将疫情拒之门外；运维团队一如既往稳定地

为平台用户提供7x24小时实时网络监控；提供远程技术支持服务等。

 

犀思云项目团队加班加点满足新客户快速增长的“云专线”需求。特别是针对远程医疗、远程教育、远程办公等行业客户，提供优质、便捷、安全的云连接需求。

 

**7x24监控：**根据用户需求对整个云交换系统提供全方位的监控，包括网络资源监控、边缘云资源的监控(CPU、内存、磁盘空间)、应用加速应用质量的监控等，依托CXP云交换平台丰富的监控工具实时为客户的网络运营保驾护航。

 

**7x24故障处理：**当用户系统出现故障时，1号位总是第一时间配合客户了解故障状态，并尽快依靠平台技术能力和丰富的排错经验，快速解决客户遇到的问题，将不利影响降到最低。

 

**新需求的快速响应：**当用户系统出现性能问题时，例如网站访问慢、处理速度慢等，使用系统进行故障排错，同时适当扩大资源的限制，给客户一定的时间来处理内部流程。

 

快速免费提供企业网络咨询和定制化解决方案：尽管疫情仍在持续，但是企业业务需要持续运营。在疫情期间，犀思云依靠丰富的方案咨询经验为客户提供“免费”的企业网络方案咨询和定制化解决方案，在疫情期间快速提供网内资源在一定时间内的免费测试，并为新老客户提供商务流程的绿色通道，共同服务好客户日益增长的网络连接需求。
