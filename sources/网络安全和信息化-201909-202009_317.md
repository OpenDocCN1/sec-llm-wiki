# 推动我国AI医疗发展的两点建议

人口老龄化和医疗健康消费升级成为推动医疗支出持续增长的两大推动力。目前医疗需求存在明显的地域医疗资源分配失衡和结构不合理现象，供求存在数量上和结构上的双重维度失配。面对以上问题，提升医疗品质、优化资源配置正在成为医疗行业发展趋势，而AI技术与医疗的融合将赋能整个医疗行业个性化、智能化、高效化升级，成为未来医疗行业发展的重要方向之一。

**一、AI医疗带来的几点改变**

  

**缓解供需矛盾，提升用户体验**

  

AI将助推医疗服务的线上线下一体化，推动各级医疗机构资源整合共享，结合5G、云计算、大数据等技术可以实现远程医疗，大大缓解了医疗资源区域分布不均衡压力。同时个人医疗信息的数字化、智能化使得个人医疗信息流通变得更加方便，可以显著节省医疗成本，提升患者的就医体验。

  

**推动临床诊断精准化，提升诊断效率**  

  

在基层医院方面，基于自然语言处理和知识图谱的AI辅助诊疗系统能够有效降低医生误诊、漏诊风险，提升医生决策水平。在三甲医院方面，AI可以基于海量的医疗数据储备进一步推动诊疗更加规范合理，提升医生诊断效率。

  

**推动医疗生态健康化，提升资源配置效率**

  

在新药研发阶段，AI技术的引入有望缩短新药研发周期、降低研发成本、提高研发成功率。同时更加快速的新药开发效率将助推精准医疗、定制化医疗场景的落地；在医疗支付阶段，AI将实现医保控费、智能风控、防范欺诈等功能，促进医药和器械设备资源配置最优化。

  

  

  

**二、AI医疗发展的两点建议**

  

**夯实高质量数据基础，推动AI与医疗场景融合**  

  

推动医疗数据结构化、标准化，打通不同医疗机构之间数据流通壁垒，构建个人医疗数据全生命周期管理系统，完善大数据平台建设。加快自然语言处理和医学知识图谱与医疗场景融合的广度和深度，在辅助决策、影像诊断、医保控费等领域充分发挥AI技术的高效和精准优势，发挥AI在新药研制阶段的高效率，推动医疗全生态体系智能化、精准化升级。

  

**完善AI医疗人才培养体系，构建和推广典型案例库**  

  

加强医疗人才与科技人才交流互动，探索医疗、科技复合型人才培养，构建完善的AI医疗人才培养体系。面向多维度医疗需求场景，培养从技术、产品、服务到运营的全流程人才梯队。推动医疗机构与AI巨头共同攻关AI医疗解决方案，形成一批有代表性的AI医疗典型案例库，推动案例库推广实行。
