Windows 7 “大限已至”，多数公司仍在使用

2020 年1月14日，微软宣布结束对Windows 7系统的支持，同时也包括结束对Windows Server 2008和Windows Server 2008 R2的技术支持。这意味着，使用Windows 7系统的用户将不会再收到免费安全更新，今后用户无疑将面临严重的安全威胁。


当然，用户电脑仍将可以继续运行Windows 7系统，只是将不会再接收到微软官方提供的相关任何问题的技术支持、软件更新、安全更新或修复等服务。



来自Kollective的调查显示，2/3的英国企业和2/5的美国企业仍在运行Windows 7。


而Netmarketshare的市场报告显示，截止去年11月，全球Windows 7系统用户依旧占据26.64%的市场份额。在中国，Windows 7使用占比更高，目前，国内企业网络环境中Windows 7占比达到了60%，而在政府机关、卫生教育等事业单位甚至超过70%。


相关研究人员表示，那些未能升级操作系统或购买微软昂贵的扩展支持的企业组织将不会再被推送补丁，从而将使自己面临许多不必要的网络风险。


从Windows  XP升级到Windows 7花了很多企业长达三年的时间，可以预期，同样升级到Windows 10的时间也差不多。Kollective的解决方案架构师Jon O'Connor认为，虽然许多公司大部分操作系统已经不再使用Windows 7，但这个“大部分”显然做的还不够。


少数不安全的设备也会带来全面的网络攻击，因此，即使在您的网络上有一台或两台Windows 7电脑，也可能会带来严重的风险。企业IT部门需要确保网络上的每一台设备都脱离了Windows 7，但事实是，大多数人根本不了解情况。


似乎微软也注意到了那些不受支持的操作系统版本的潜在风险，有消息称，微软发布了一个修补程序，修复了核心Windows组件中的一个关键缺陷，而如果不及时修补该漏洞，可能会产生广泛的严重后果。


相关安全专家也敦促各企业组织确保拥有第三方安全工具，以帮助屏蔽潜在的威胁。


国内也有许多安全厂商宣称将继续提供对Windows 7系统的相关技术支持和安全更新。


随着企业组织将IT架构转移到云上，类似这样的遗留支持问题在未来10到15年内可能会成为过去，但由于Windows 7系统仍在许多组织中被广泛使用，目前人们应该意识到，由于不再受官方支持，该操作系统将面临更大的漏洞风险。


如果组织继续使用不受支持的操作系统，那么确保拥有良好的网络环境和备用IT设施，以及及时建立和更新安全防护解决方案，就变得更加重要。


为保护不受支持和未修补的操作系统，虚拟补丁或入侵防御技术在这些情况下也是有帮助的。


Kollective销售副总裁Ross Baker表示，在Windows Server 2008支持于2020年1月14日结束后，有大量企业准备采取观望态度，这非常令人担忧。“这相当于极端形式的对赌，我们绝对不推荐这种做法。”


如果某些组织IT系统与关键业务应用存在兼容性问题，或者如果某个制造商已将Windows系统嵌入到OT系统中，那么它们可能无法升级到新的OS版本。
