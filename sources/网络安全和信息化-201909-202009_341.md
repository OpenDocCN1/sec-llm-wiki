# Gartner：您需要了解的区块链事实

一般情况下，想要开餐厅的人都需要去多个政府机构开具必要的证明。比如，根据餐厅类型，经营者需要有卫生许可证、员工薪资证明或酒类营业执照。每种执照要求经营者提供的文件基本相同。

  

为了方便市民，在加拿大的不列颠哥伦比亚省，维多利亚市政府决定建立一个区块链平台。该平台提供所有餐厅经营者的信息，为每名经营者创建了一本“餐厅护照”。

  

维多利亚市政府并没有自己控制所有数据，而是开发了一个去中心化的系统。也就是说，经营者控制着自己的所有信息，决定权被交到了个人的手中。政府机构可以在之后对这些信息进行验证，经营者则可以决定谁在多长时间内可以访问信息。此外，该系统还具有便携性，经营者可以使用同样的信息在另一座城市开餐厅。

  

这种被称为增强型区块链（blockchain enhanced）的区块链在提高效率的同时，继续推动经济增长。但对于其他企业机构而言，区块链可以被应用于哪些方面？

  

维多利亚市政府的这次概念验证（POC）定义清晰且范围较小。而首席信息官需要了解什么是区块链以及它可以做什么。更重要的是，他们必须了解如何向企业解释它的价值。

  

**区分区块链的泡沫与现实**

  

  

2019年首席信息官调查显示，尽管60%的首席信息官期望在未来三年部署某种区块链，但他们没有将这项工作作为重点；只有5%的首席信息官将区块链列为企业机构的变革驱动力。

  

大多数企业机构只在小而狭隘的概念验证范围内探索区块链。但领先的企业机构已经在考虑如何将这项技术与人工智能、物联网等具有互补性的技术相结合，从而创造全新的业务模式。

  

虽然目前的技术水平还未先进到可以马上开始这项行动，首席信息官仍应该开始挖掘这些潜力并争取获得领导团队的支持。

  

一切的关键在于首席信息官必须首先解释区块链的组成。真正的区块链包含五个组成部分。

  

![](../Images/ebc5c0b3b7ee62ff8250e3deb7f46261.png)

  

  
  

**分布式（Distribution）：**区块链参与者身在不同的地方并且通过网络连接在一起。每名操作一个完整节点的参与者都保留了一份账本的完整副本并且会在新的交易发生时更新。

  

**加密（Encryption）：**区块链使用公钥和私钥等技术将数据安全、半匿名（参与者使用假名）地记录在区块中。参与者可以控制自己的身份和其他个人信息并且仅分享在交易中需要的信息。

  

**不可篡改（Immutability）：**交易必须带有加密签名、时间戳并按照顺序添加到账本中才能完成。无法删除或更改记录，除非参与者同意需要这样做。

  

**通证化（Tokenization）：**区块链中的交易和其他交互涉及安全的价值交换。区块链以通证表示价值，而通证可以表示从金融资产到数据再到有形资产等一切有价物。参与者还可通过通证控制他们的个人数据，这是推动区块链商业应用的基本驱动力。

  

**去中心化（Decentralization）：**由于区块链采取的是共识机制，网络信息与网络运行规则均由分布式网络上的节点维护。去中心化实际上意味着没有任何一个实体能够单独控制所有计算机或信息或者制定规则。

  
  

  

了解每个组成部分以及它们如何组合成真正的区块链是首席信息官向高管解释这项技术并消除误解的基础。

  

**Gartner区块链演进**

  

  

为了帮助首席信息官了解区块链的现状及其未来的演变，Gartner此前分享了区块链演进（Blockchain Spectrum）并探讨了区块链将在整个2030年如何演变。

  

![](../Images/ff25738f49df048eb6fa40591ae272fc.png)

  

  
  

**区块链赋能阶段（Blockchain enabling technologies）：2009年至2020年**

这一区块链实验初期阶段建立在现有系统的基础之上，其目标是减少私人、专属活动中的成本和摩擦。这一阶段的区块链只能为企业内部或企业之间的少量节点分配有限的能力。

  
  

**区块链创新阶段（Blockchain-inspired solutions）：2016年至2023年**

目前区块链正处于创新阶段。通常，这一阶段致力于解决具体的运营问题，其中最常见的问题是企业机构间流程或记账的低效率。这一阶段的解决方案一般包含五个组成部分中的三个：分布式、加密和不可篡改。

  
  

**区块链完善阶段（Blockchain complete solutions）：2020年代**

区块链完善阶段从2020年代开始。该阶段将出现包括去中心化和通证化在内的所有五个组成部分，从而实现区块链的全部价值主张。

  
  

**区块链增强阶段（Blockchain enhanced solutions）：2025年后**

区块链增强阶段解决方案具有所有五个组成部分并将它们与人工智能或物联网等具有互补性的技术相结合。

  

**业务模式将发生改变**

  

  

考虑到区块链完善阶段和创新阶段解决方案的前景，您应对各种用途的假设持谨慎态度。您需要认真思考区块链的潜在用途以及如何将区块链融入到您所在企业机构的风险状况和投资方案中。此外，在考虑概念验证时，务必思考各项特征将如何提高业务价值。每当评估厂商技术时，务必牢记这五个组成部分。

  

在探索区块链的应用时，请提出以下问题：

  

  
  

*   谁将在区块链中？
    
      
    
*   如果这是一个联盟，您愿意与您的竞争对手协作吗？
    
      
    
*   您能使用现有的技术吗？
    
      
    
*   谁将成为您的客户？机器？汽车？
    
      
    
*   谁来控制为这些新型客户提供的服务模式？
    
      
    
*   会对实时交易环境中的定价和现金流产生什么影响？
