# 2021数据安全“护脸”样板工程｜全息网御：某企业敏感数据审计和追溯

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649145912&idx=1&sn=650b47930b23f0bc9cedab292a89b2fa&chksm=be8b4b2489fcc232d7cf92d7e2215a4ca1d84d61d9e1123533ca7e16e694bdd6db2a71a09040&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649145912&idx=1&sn=650b47930b23f0bc9cedab292a89b2fa&chksm=be8b4b2489fcc232d7cf92d7e2215a4ca1d84d61d9e1123533ca7e16e694bdd6db2a71a09040&scene=27#wechat_redirect)

  

**背景**

  

某企业承接了几十个重要的冶金、有色、矿山工程，以及大量民用基建项目。改革开放以来，该企业开始进军海外，承建了众多大型工业和市政工程，涉及大量设计、施工、安装文档和数据，其中许多涉及重点项目相关的数据尤为重要。此外，该企业的生产、运营、管理数据关系到自身以及供应商和客户的商业利益，因此，迫切需要实施数据安全治理。

  

  

**方案应用情况**

  

全息数据安全风险感知平台（OnFire）在帮助该企业实施数据安全治理过程中发挥了重要作用。平台分为三部分：

  

1.  数据采集器：采集网络数据，抽取与用户、设备、应用、数据相关的信息，发送给分析平台。
    
      
    
2.  分析系统：分析平台主要负责数据分析，实现画像、关联、分析、可视化等工作。
    
      
    
3.  管理UI：用户使用Web浏览器登录，不需要安装管理软件。

**方案实施目标**

  

全息数据安全风险感知平台（OnFire）实施完成后，达成以下目标：

  

1.  实现对该企业信息系统的刻画：能够长期监控该企业用户、设备行为、敏感数据活动（内部流动和外发）。
    
      
    
2.  实现全部数据并不局限于敏感数据的追溯：以敏感数据为核心，对访问敏感数据的用户、设备、应用以及数据传送的位置等，实现追溯取证。
    
      
    
3.  实现内部威胁和违规风险的发现：提供数据安全威胁预警、告警功能。OnFire系统通过对数据追溯、挖掘，对用户行为和设备行为追溯以及特征分析，发现潜在的内部威胁和违规风险。
    

  

  

**创新性**

  

1.创造性地发展了UEBA（用户与实体行为分析）技术，在传统定义的基础上融入全息网御的专利技术，创新地实现了流动数据与其使用者之间互动关系的实时展现，在网络中实现了物理空间的“监控摄像头”功能，使保护网络中的数据资产和保护实体世界中的物理资产一样简单直观。

  

2.根据行为分析和数据安全的需要，实现“定制化”网络数据的采集和元数据提取，大规模缩减日志数量，使分析的高效性和实时性成为可能，从而实现实时分析和告警。

  

3.市场上流行的网络流量采集器处理的是网络三层的IP数据包，从中提取3层到7层网络和应用协议层的信息，对数据包中的内容并不做关联处理，而全息流量采集器不仅覆盖了网络2层到7层数据包的采集，而且将相关联的数据包重组还原（例如文件），实现了对第“8”层内容的采集，提取用户账号信息，并对网页和文件内容扫描，对数据内容分类分级，识别敏感信息。

  

4.分析平台实时对用户、设备、应用、数据进行画像，并按时间序列关联这4个维度信息，感知“何人、何设备、何时、何地，通过何应用，访问了何数据”，构建以用户行为驱动，以数据为核心的全息关联画像。

  

  

**实用性和可推广性**

  

1.全息数据安全风险感知平台融合边缘计算、分布式计算、机器学习等技术，以独特的用户及实体行为分析手段实现对数据安全治理关键环节的支撑：

  

（1）**数据发现、分级、分类：**数据描述、业务描述、安全描述。

（2）**数据溯源与审计：**每一条数据都可查询其使用者及其渊源。在数据的传输、处理、交换环节中，从用户、设备、应用的视角审计这些实体的行为，实时追踪数据的来龙去脉，为数据安全事件提供溯源、取证。

（3）**数据监控与保护：**监控数据的行为，关联敏感业务数据与用户的互动，根据行为基线监测异常行为，提供数据安全威胁告警。

  

2.简化实施和运维：运用AI、机器学习技术，实现数据自动采集和处理，自动画像，关联分析，异常分析，威胁定位，降低了实施和运维难度和工作量。

  

3.平台具有很强的通用性，已在金融、电信、制造和医疗等行业有成熟案例，有利于系统性推广。

  

  

**方案实施效果**

  

该企业部署了全息数据安全风险感知平台，帮助其在公司内部开展、落实数据安全治理工作，效果如下：

  

1.  **数据分类分级：**通过流量采集的方式对该企业数据分类分级，贯彻工信部《工业数据分类分级指南（试行）》，为客户构建敏感数据地图，实现数据安全可视化。
    
      
    
2.  **风险评估：**通过全息画像实现敏感数据和业务的关联，帮助该企业评估敏感数据的安全风险，制定有效的数据安全策略。
    
      
    
3.  **持续监控：**7×24小时监控数据活动（源头、访问者、流向、路径），解决用户关注的敏感数据出境和数据违规的问题。
    
      
    
4.  **审计和追溯：**可以对数据生命周期安全事件进行长周期和全证据链的审计和追溯，发现数据安全漏洞，取证和追责。
    

  

**编辑点评**

全息数据安全风险感知平台（OnFire）通过业界首创的集数据防泄密（DLP）、用户实体行为分析（UEBA）、安全信息和事件管理（SIEM）、云服务安全代理（CASB）等核心技术为一体，依托专利技术，发现并实时重构网络中流动的、不可见的“数据、用户、设备、应用”四个安全维度的互动关系，生成以数据为核心的用户实体行为全息图。结合机器学习，全息数据安全风险感知平台（OnFire）将这种内在关系梳理、画像、建模，评估事件异常程度，对高风险数据、用户及其他实体进行事前预警、事中报警、事后溯源。
