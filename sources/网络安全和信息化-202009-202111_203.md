# 赛迪顾问发布《中国网络安全最具潜力十大创新方向》

由中国计算机学会计算机安全专委会与赛迪顾问股份有限公司联合主办的以“场景驱动创新、生态赋能安全”为主题的“2021年IT市场年会——网络安全高峰论坛”于2021年5月20日下午在北京隆重召开。作为2021年IT市场年会的重要主题论坛，本次高峰论坛邀请政府领导、企业领袖、行业用户等多位业界专家，共同为新形势下网络安全产业发展出谋划策，一起解读新政策、研讨新技术、探索新模式。  

![](../Images/67b8c9eb9903f1882919dfe116509431.png "6.png")

本次论坛上，赛迪顾问软件与信息服务业研究中心高级分析师桑元发表了以《中国网络安全最具潜力十大创新方向》发布的主题演讲。演讲首先从政策、事件、市场、投融资等角度全面解读中国网络安全产业的发展现状。预估了新时代下，中国网络安全随着数字经济的到来和新兴领域的演变呈现出的新的发展态势，赛迪顾问从新理念、新领域、新政策、新技术、新生态等方向全面梳理了网络安全产业的新变化。未来，在新基建和数字化浪潮的双重驱动下，中国网络安全行业进入门槛将不断提升，行业协作将日益紧密，赋能和生态将成为未来行业的发展主题。最后，赛迪顾问重点发布了中国网络安全最具潜力的十大创新方向，并且对十大方向进行了深入解读。

![](../Images/a91b5dbb7581ffd63336d927b8f4410c.png)

赛迪顾问将持续跟踪网络安全前沿技术发展动态，不定期发布网络安全相关研究报告，推动社会各界对网络安全领域深入了解，为安全企业及用户、投资人、政府决策提供参考和建议。本届网络安全高峰论坛的圆满举办，不仅提升了赛迪顾问在网络安全领域的行业影响力，也为中国网络安全产业发展搭建了合作交流的平台。
