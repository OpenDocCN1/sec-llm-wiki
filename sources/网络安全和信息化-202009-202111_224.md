# 征集｜2021年数据安全“护脸”样板工程征集进行中

**01**

**背景**

在今年的315晚会上，一桩桩数据安全和隐私泄露事件触目惊心。虽然数据安全和隐私保护已是老生常谈的话题，但是当前这些问题依旧未能得到有效解决。

  

此前，以315晚会为契机，《网络安全和信息化》杂志与IT运维网联合开展了以“护脸”为主题的宣传季。当然，“护脸”只是一种比喻，不仅个人的人脸信息需要得到保护，企业的“脸面”也同样需要保护。与前者有所不同，针对企业的“护脸”行动挑战更大，涉及的方面也更为广泛，不仅涉及企业各类IT系统和设备的数据资产，还有基于人（员工）的保护，不仅包括数据安全，还涉及身份管理、云安全、移动安全等场景，而近年来火热的零信任、SASE、XDR等安全理念和技术也为数据安全和隐私保护增添了新的助力。

  

针对企业的数据安全和隐私保护是一个系统工程，作为宣传季的重要组成部分，以“数据安全和隐私保护”为主题的成功案例或解决方案征集与评选也在同步推进，欢迎广大相关安全厂商参与。

  

**02**

**内容要求**

1.案例/解决方案的背景介绍，客户或行业面临的痛点。（500~800字）

2.案例部署实施过程，或解决方案的优势特色。（1000~1500字，可包含图片2~3张）

3.方案的最终实施效果、经验价值等。（500字左右）

4.创新点。（100-150字）

  

**03**

**权益**

优秀的案例文章将获得“‘护脸’样板工程”称号，可安排在《网络安全和信息化》杂志与IT运维网上刊登，同时也将在6月份举办的“2021 CIO信息安全高峰论坛”上予以展示。
