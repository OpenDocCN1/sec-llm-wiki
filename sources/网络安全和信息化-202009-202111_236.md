# 报名参会丨新政策下安全管理平台建设方案研讨会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649145556&idx=1&sn=4e78b57aaee9fd2b3d98a18dbb689272&chksm=be8b49c889fcc0de7c65689c16efa5f665e98ccdb72a25a63fc50f3ff35691edd2cc68b633c9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649145556&idx=1&sn=4e78b57aaee9fd2b3d98a18dbb689272&chksm=be8b49c889fcc0de7c65689c16efa5f665e98ccdb72a25a63fc50f3ff35691edd2cc68b633c9&scene=27#wechat_redirect)

数据时代，信息与数据共舞，科技与人文碰撞。信息化技术以及数字化转型已经日益深入到社会的方方面面。近年来，国家陆续出台了“网络安全法”“密码法”“等保2.0”等信息安全相关的法律法规及政策，对信息安全管理要求更高，监管更严。上讯信息认为IT智能安全运维与数据安全已经成为数字时代必答题。本次会议带来专业的信息安全新政策解读；同时，针对IT信息安全建设过程中所遇的问题或困境，结合行业新兴技术与客观专业分析给出指引方向和解决方案，希望能在用户的数字化建设过程中给出有效帮助。
