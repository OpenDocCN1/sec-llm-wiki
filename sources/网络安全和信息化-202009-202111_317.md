# 如何启动威胁搜寻程序

近年来，网络威胁发生频率比以往任何时候都要高，而且越来越复杂。当前，安全机制基于传统反应性方法，例如防病毒程序和防火墙只有在事件发生后才会做出反应。在这种情况下，入侵者就有机会部分或全部破坏用户网络。

  

为防止这种情况发生，网络安全人员就会启动威胁搜寻程序，将其作为安全运营中心（SOC）的重要组成部分。实际上，威胁搜寻是一种反复主动搜索对手发起威胁或高级持续性威胁（APT）的实践。与传统安全系统（如防病毒程序、防火墙或SIEM等）使用反应性方法应对威胁不同，威胁搜寻甚至在威胁组织的网络或IT基础架构之前，采用了主动方法应对威胁。与反应式方法相比，威胁搜寻甚至在事件发生之前就起作用，而不是在事件发生后才起作用。

  

威胁搜寻可以通过手动或自动两种方式执行。通过使用供应商工具包进行手动威胁搜寻。由于对端点的威胁指标（IoC）的扫描不佳以及搜索数据库的能力差，手动威胁搜寻方法缓慢且效率低下。另一方面，自动威胁搜索更加有效、快速和可靠，可以通过安全协调来执行。

本文主要介绍如何主动启动威胁搜寻程序，以更好地应对复杂网络攻击，避免单位合规性问题和财务损失。

**一、认真选择：在内部或外包威胁搜寻间进行选择**

威胁搜寻，顾名思义就是在网络空间中寻找威胁。威胁每天都在发生变化，因此，开发新技术防御和检测各种类型的威胁和攻击是我们的责任。威胁搜寻的核心可以理解为一个简单的事实，即没有系统可以被视为100%受保护。即使使用最好、最新的技术，也总是存在一些高级威胁能够逃避防御方案和设备，而这正是我们正在寻找的东西。

 

内部威胁搜寻是企业内部的自我管理功能，企业使用自己的资源，例如所需的技术和人力来进行内部威胁搜寻。

 

另一方面，外包威胁搜索涉及外部威胁搜索服务提供商的服务。组织无需在内部威胁搜寻程序上花费大量预算，而是可以从外部第三方外包此功能。一旦确定内部威胁搜寻还是外包威胁搜寻，就可以继续进行下一步行动。

  

**二、全面规划：威胁搜寻的核心**

规划是威胁搜寻活动的重要因素之一。规划涉及以下必须回答的关键问题：在威胁搜寻程序期间将执行哪些过程？有哪些可用资源？什么基础设施将受到保护？预算多少？用户无法保护自己没有的东西，也不能雇用超出预算范围的更多人力或部署更多技术。适当的计划可以使用户保持在自己的范围之内，并有助于避免将来出现麻烦。

 

威胁搜寻的一个关键部分是与公司的主要IT人员进行有效和高效的沟通。这意味着威胁猎手应该以不同的方式与端点工程师、应用程序开发人员、服务台和系统工程师协同工作。威胁猎手实际上需要与他们进行有效沟通，以便了解关键系统和应用程序的操作。在搜索敌人时，猎人会发现网络、系统和应用程序的设计和实施中的漏洞。威胁猎手和关键IT人员之间的信任关系是不可或缺的。最重要的是，在响应事件时，用户需要他们的协作。只有通过确保相互信任，用户才能够在环境中的弱点和漏洞面前一起正确诊断恶意活动并执行补救。

  

**三、提出假设：发展和检验假设**

提出假设，有助于分析人员确定从威胁搜寻程序中获得的预期结果。例如，针对一项无文件恶意软件的搜寻活动，分析师将找出使用PowerShell和WMI工具进行攻击的对手。无文件恶意软件涉及攻击RAM而非硬盘的恶意代码。此外，测试每个PowerShell进程也不是明智的方法。相反，这是一项耗时且艰巨的任务。分析人员仅应提取与实际攻击有关的信息。想象一下，你是一个攻击者，一个好的威胁搜寻活动要求威胁猎手像攻击者一样思考。通常情况下，威胁猎手的任务是主动追击对手，并结束入侵的可能性。但是，如果发生了攻击，他们需要减轻其影响以减少伤害。

  

然而，总是寻找入侵的迹象并不是一个很好的方法。相反，威胁猎手应该努力预测攻击者的下一步行动。一旦威胁猎手知道攻击者可能会做什么，他们应该设置一些触发器，一旦攻击者执行此移动就应该被触发。威胁搜寻工具可用于确定攻击者的行动。请记住：没有任何组织总是拥有完美的安全措施，而且攻击者现在也会使用非常复杂的技术来绕过公司的监控工具和大多数安全措施。因此，威胁猎手应该超越对手的期望，以防止攻击成为自己的噩梦。

  

**四、数据很重要：了解安全环境，广泛收集信息**

审查假设的结果需要用户收集一些其他信息，可以通过以下方式收集信息：网络日志（例如防火墙、VPN、路由器）、基于主机的日志（例如操作系统日志、端点检测响应）、虚拟机管理程序、活动目录、域名解析、代理、服务或应用程序日志。威胁搜寻旨在发现异常活动，否则可能会对公司造成严重损害。了解环境中的正常活动是理解非正常活动的先决条件。如果您了解正常的操作活动，那么任何异常都应该突出并注意到。因此，威胁猎手应该花费大量时间来了解他们环境中的正常和日常事件。

  

此外，分析师必须了解包括系统、应用程序和网络在内的完整体系结构，以便他们能够发现可能为攻击者提供机会的弱点和漏洞，并与IT内外的关键人员建立良好关系。事实上，这些人可以帮助威胁猎手区分异常活动和正常活动。例如，威胁猎手发现的每个问题并不总是攻击。相反，它可能只是一种不安全的做法。为了改善组织的安全态势，威胁猎手必须充当有效的 “变革推动者”，如果没有与他人的信任关系，这是不可能的。

  

**五、发挥工具优势：认真整理数据，充分使用资源**

一旦正确收集了所有必需的信息和数据，下一步就是组织和分析该数据以获得有意义的结果。为此，安全分析人员使用各种工具，包括SIEM中的报告工具、分析工具、使用Excel整理数据或生成数据透视表。有组织的数据形式可帮助分析人员确定预计在不久的将来会发生的潜在威胁。利用这些数据，安全分析人员可以修复其网络中的安全漏洞并增强其安全状况。通过使用足够的资源，威胁狩猎被认为是当今最好的安全解决方案之一。

  

但是，投入足够的资源，包括人员、系统和工具，对于有效地进行威胁搜寻是不可或缺的。人员是指威胁猎手，他们必须具备操作系统(OS)和子系统的深入知识，例如应用程序服务器、Web服务器、数据库服务器及数据库管理系统，更重要的是网络、Wi-Fi系统和Internet。

  

**六、应对威胁：制定OODA战略，保护端点安全**

在前面的步骤中，安全分析人员收集了足够的数据来回答他们的假设。可能发生两种情况：找到真正的威胁或检测到漏洞。在这种情况下，安全分析人员都必须采取行动。一旦发现真正的威胁，安全分析人员必须立即做出反应。但是，如果存在任何漏洞，应该在此成为一场噩梦之前解决这些问题。

 

首先，制定OODA（Obser ve、Orient、Decide、Act）战略。军事人员在进行战斗行动时应用OODA。同样，威胁猎手在网络战期间使用OODA。在威胁搜寻背景下，OODA的工作原理如下。

 

通过观察，第一阶段涉及从端点进行常规数据收集Orient，彻底了解收集的数据，将此信息与其他收集的信息相结合，以帮助理解其含义。

 

之后，分析是否发生了对流量的命令和控制(C&C)的标志或检测到任何攻击迹象决定，一旦分析了信息，就需要确定行动方案。如果事件发生，威胁猎手将执行事件响应策略行动，最后阶段涉及执行计划以结束入侵并增强公司的安全态势。采取进一步措施，以防止将来发生同类型的攻击。

 

端点安全是客户端、服务器信息安全方法，用于通过监视端点，其活动、软件、身份验证和授权来保护公司的网络。保护所有端点至关重要，因为疏忽可能会给对手留下空白点。通常，除了位于每个端点上的客户端安全软件之外，还通过安装在网络中集中管理的服务器或网关上的安全软件确保端点安全性。仅使用防病毒程序无法阻止APT，因此应该部署端点保护解决方案。

  

**七、时刻准备着：保持刀锋锋利，采取最终行动**

一旦安全分析人员识别出威胁或漏洞，事件响应团队就会负责执行补救过程，决定采取什么资源可以实施最终行动。任何延迟都可能对组织造成严重损害或声誉损失。因此，事件响应应及时进行。

 

保持刀锋锋利。即使最好的武器也会生锈，除非它得到照顾。为了有效地开展工作，威胁猎手需要做好准备，并始终对可疑活动保持警惕。由于网络犯罪分子正在寻找数十种新方法来渗透安全系统，因此威胁猎手需要不断学习和发展他们的技能，以便让自己能够应对挑战。每个职业威胁猎手都必须花时间接受技术培训。

  

**八、以人为中心：部署自动化，实现可视化**

自动化是安全运营中心（SOC）的关键组件之一。用户的安全工具（例如SIEM）每天会生成数千个警报。此外，安全分析人员每天还会执行许多重复性任务。手动处理警报和重复性任务是具有挑战性的任务，这就是为什么实现安全自动化的原因。

  

此外，由于预算限制，许多组织无法负担雇用的人力成本。企业寻求自动化工具是作为最后的手段。自动化工具可以检查事件是否涉及妥协指示（IOC）。

  

尽管自动化工具至关重要，但我们不能低估人力的重要性。根据Gartner的观点，威胁搜寻程序是以人为中心的，而不是以工具为中心的。安全分析人员的角色对于主动应对威胁至关重要。这是因为分析师对预期的未来事件具有预测能力。

  

网络可见性是关键。除了在所有端点上部署威胁搜索工具之外，还必须深入了解网络环境中的攻击模式和活动。用户可以通过使用具有网络可见性的工具来实现此目的。用户在设置高级端点工具时，应使用入侵检测系统(IDS)、入侵防御系统(IPS)、NetFlow、Web过滤器、防火墙和数据丢失防护系统(DLP)等工具。用户通过这种方式，可实现验证攻击并收集有关可能表示违规的异常流量模式的宝贵知识。

  

**九、记录备案：创建文档记录，向所有利益相关者报告**

威胁或漏洞的所有详细信息都必须记录备案。实际上，文档可帮助用户保留先前事件的记录。使用此记录，安全分析人员可以检查新事件是否与先前事件有任何联系。向所有利益相关者报告该事件也至关重要。例如，您可能有与您的组织相关联的业务合作伙伴，外包商或其他安全经理。如果事件成功发生，它们同样受到影响。例如，由于不合规导致的GDPR罚款可能适用于属于安全体系结构的所有利益相关方。

 

优秀的威胁猎手不仅试图遏制或消除恶意入侵，还记录他们在IT环境中执行的每一次威胁搜索。用户不仅需要详细说明每个案例的技术信息，更重要的是，还需要记录与公司相关的业务知识，例如寻找原因。但如果没有合理收集数据，好的文档就不值得。用户必须选择一种可以帮助组织威胁搜寻活动的工具，以便在怀疑反复入侵并与其他方分享知识时重新审视自身的步骤。可用于组织数据的工具可能包括报告工具、分析工具甚至 Microsoft Excel。

  

**十、紧跟形势：总结经验教训，了解现代攻击趋势**

完整的威胁搜寻程序使安全领导者可以从以前的事件中汲取教训。无法从先前的事件中学习经常会导致大型事件。了解先前事件的根本原因，有助于分析师避免即将发生的事件。它还可以帮助发现当前安全状况中的漏洞，增强安全防御能力以阻止未来的事件。

 

及时了解现代攻击趋势。在不断发展的技术世界中，威胁行为者每天都在开发新的攻击。网络犯罪分子具有创造性，他们正在利用这种创造力不断发明新的犯罪方法。威胁猎手需要跟上不断变化的网络攻击格局。根据 Alert Logic威胁搜索报告，安全专家将55%的高级威胁检测作为SOC的首要挑战。43%的安保人员缺乏足够的技能来缓解这些威胁，36%的自动化工具严重缺乏威胁性能力。为了防止入侵，威胁猎手必须自己掌握现代威胁形势和犯罪分子发现进行攻击的复杂技术。

  

  

**结语**

在本文中，我们阐述了如何启动威胁搜寻程序，主动寻找威胁和漏洞要比做出反应好得多。简而言之，更好地防止事件发生，而不是在事件发生后做出响应。如果在SOC中启动威胁搜寻程序，则是可能的。威胁搜寻可以为网络安全策略提供重要价值。在没有系统100%安全的前提下，有经验的威胁猎手可以主动检测并阻止潜在的攻击者。

 

创建有效的威胁搜寻程序需要不断努力，在实施特定策略之前，拥有合适的专业人员和必要的工具是至关重要的。一个好的方法是首先定义将为公司提供实际价值的成熟度级别，确认现有资源是否足够，并创建经验丰富的专业人员、数据收集、处理工具和可行的情报的正确组合。
