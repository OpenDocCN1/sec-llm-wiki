# 张健洲：“十四五”时期我国人工智能产业高质量发展的几点建议

党的十九届五中全会审议通过《中共中央关于制定国民经济和社会发展第十四个五年规划和二〇三五年远景目标的建议》，提出要瞄准人工智能等前沿领域，实施一批具有前瞻性、战略性的国家重大科技项目；要发展战略性新兴产业，推动人工智能等同各产业深度融合。“十四五”时期是我国开启全面建设社会主义现代化国家新征程的第一个五年，同时也是我国人工智能产业滚石上山、爬坡过坎的重要战略机遇期。目前，我国人工智能产业发展取得长足进步，产业规模持续扩大，关键技术不断取得突破，与实体经济融合应用日益深入。同时，还存在着计算资源短缺、算法偏见、数据安全、伦理道德风险等诸多问题，建议从以下三个方面推动我国人工智能产业发展。  
  
一是推进数字基础设施建设。在新基建的大背景下，我国需要大力推进5G基站、数据中心、人工智能应用服务平台等数字基础设施的全面部署，建设存储多元、算力开放、算法多样的存算一体化基础设施，大幅度提高数据采集、数据传输与数据计算能力，为人工智能产业的发展打造坚实的泛在计算基础。  
  
二是加强网络数据安全防护。我国在推动人工智能技术应用落地的同时，需要高度重视数据安全问题，增强网络运营者对数据管控的意识，加快开发数据安全管理技术，构建数据防泄漏综合防护体系，从国家层面推进全国人工智能数据安全应对机制和治理机制。  
  
三是完善“引育用留”人才制度体系。我国需要拓展人工智能相关海外高层次人才引进渠道，大力引进专业的高端人才；制定科学的人才培育计划，确保青年高潜力人才获得足够的成长；构建高效的人才配置平台，精准合理的发挥人才优势；建立优渥的人才保障机制，留住核心骨干高层次人才。
