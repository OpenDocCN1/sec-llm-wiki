# 5G时代边缘计算发展趋势

随着物联网、5G等技术的飞速发展，可穿戴设备、移动智能终端、智能网联汽车、机器人等设备产生海量的数据，并且普遍要求数据处理的低时延和高可靠性，云计算集中式的大数据处理模式有时候不能完全满足需求，在某些领域边缘计算的运行效率可能更高。边缘计算使数据能够在最近端进行处理，减少云、端间的数据传输，极大提升效率，很适合高交互、大带宽的5G时代。此外，在各国对数据采集和传输日益敏感的环境下，边缘计算本地化处理数据为企业安全合规带来很大便利。据CB Insight预测，2022年全球边缘计算市场规模将达到67.2亿美元。  
  
近年基于云的边缘计算产品显示公有云、私有云和边缘计算之间的界限正在模糊。公有云供应商正在与电信公司、基础架构提供商等合作将其云平台、容器、业务流程和服务带到边缘数据中心和通信端点。微软基于Azure Stack Edge 将Azure计算和服务带到边缘。微软与AT&T合作，在亚特兰大、洛杉矶等地为运营商提供Azure端区。亚马逊AWS提供了一组类似的产品，可将AWS服务分到边缘数据中心和电信网络。AWS Wavelength 专为5G设备上运行的低延迟应用程序而设计，包括联网汽车、AR/VR应用程序、智能工厂等。谷歌与AT&T开展5G 连接方面的合作，发布了谷歌移动边缘云，丰富了其混合和多云应用程序现代化平台。阿里云在2019年云栖大会提出了边缘计算即城市计算的定义，其核心理念是以城市为单位逐步部署边缘节点服务，并与阿里公有云基础设施和生态应用打通，重点为本地消费应用和产业计算服务。目前阿里云的工业互联网平台、CDN系统、云游戏等很多PaaS平台及应用已经部署和运行在边缘节点。  
  
不止云服务商，通信企业、服务器和芯片供应商，例如GE、英特尔、戴尔、IBM、思科、惠普、微软、SAP SE和AT&T等，也开始布局边缘计算。英伟达提出要“重新定义将高级AI从云端扩展到边缘的可能性”。2019年，英伟达推出EGX加速计算平台，能够帮助企业在边缘实现低延迟的人工智能，即基于5G基站、仓库、零售商店、工厂及其他站点之间的连续的数据流实现实时感知、理解和执行。  
  
在5G时代，云、边、端逐步呈现一体化发展趋势，将为新型基础设施领域带来更多发展机遇。
