# **2022年1-5月份互联网和相关服务业运行情况**

  

1-5月份，互联网业务收入保持增长，利润总额降幅收窄，研发费用稳步增长。

  

**一、总体运行情况**

**互联网业务收入保持增长**。1-5月份，我国规模以上互联网和相关服务企业（以下简称互联网企业）完成互联网业务收入5850亿元，同比增长1.8%，增速较1-4月份回落0.9个百分点。

  

![](../Images/b19642c9c25deb36a0da67edd224ca88.png)

**图  互联网业务收入累计增长情况（%）**

  

**利润总额降幅收窄**。1-5月份，我国规模以上互联网企业营业成本同比增长5.7%，增速较1-4月份回落1.3个百分点。实现利润总额495.2亿元，同比下降14.8%，降幅较1-4月份收窄10.6个百分点。

  

**研发经费规模稳步增加**。1-5月份，我国规模以上互联网企业共投入研发经费311.2亿元，同比增长9.1%，增速较1-4月份回落1.3个百分点。

  

**二、分领域运行情况**

**（一）信息服务领域企业收入增长加快**。1-5月份，以信息服务为主的企业（包括新闻资讯、搜索、社交、游戏、音乐视频等）业务收入同比增长9.1%，增速较一季度、1-4月份分别提高2个和0.9个百分点，高于全行业整体增速7.3个百分点。

  

**（二）生活服务领域企业收入降幅扩大**。1-5月份，以提供生活服务为主的平台企业（包括本地生活、租车约车、旅游出行、金融服务、汽车、房屋住宅等）业务收入同比下降20.6%，降幅较一季度、1-4月份分别扩大3.2个和0.4个百分点。

  

**（三）互联网数据服务收入保持高速增长**。1-5月份，互联网数据服务（包括云服务、大数据服务等）收入701.1亿元，同比增长30.7%，增速较1-4月份提高0.3个百分点，高于全行业整体增速28.9个百分点。

  

**三、分地区运行情况**

**东部地区互联网业务收入加快增长，东北地区增势突出**。1-5月份，东部地区完成互联网业务收入5329亿元，同比增长3.6%，增速较1-4月份提高1.1个百分点，占全国互联网业务收入的比重为91.1%。中部地区完成互联网业务收入202.4亿元，同比下降13.9%，降幅较1-4月份扩大0.4个百分点。西部地区完成互联网业务收入293.5亿元，同比下降15.7%。东北地区完成互联网业务收入24.9亿元，同比增长26.5%，增速较1-4月份提高0.1个百分点。

  

**主要大省发展态势分化**。1-5月份，互联网业务累计收入居前5名的北京（增长11.1%）、广东（下降0.1%）、上海（增长10.8%）、浙江（下降0.2%）和天津（下降33%）共完成业务收入5009亿元，同比增长4.1%，占全国比重达85.6%。全国互联网业务收入增速实现正增长的省市有14个，较4月份减少3个，其中湖北、西藏、辽宁增速超过50%，天津、河南、云南降幅超30%。

  

**四、我国移动应用程序（APP）发展情况**

**移动应用程序（APP）总量小幅增长**。截至5月末，我国国内市场上监测到的APP数量为232万款，5月当月净增1万款。移动应用开发者数量达101.7万个，5月当月净减1.6万个；第三方应用商店在架应用累计下载量达21543亿次，5月当月净增379亿次。

  

附注：

1.规模以上互联网和相关服务企业口径由上年互联网和相关服务收入500万元以上调整为2000万元及以上，文中所有同比增速均按可比口径计算。

  

2.今年将跨地区企业按注册地划分至各个地区。

  

3.移动应用程序总量是指报告期内我国市场在架（通过审核，可在第三方手机应用商店中查找到）的智能手机第三方应用程序的总个数，计算方法是根据对国内超过20个主流市场在架移动应用（包括苹果及安卓两类商店）加总去重后获得。

  

4.移动应用开发者数量包括企业移动应用开发者数量和团体（个人）移动应用开发者数量。其中，企业移动应用开发者数量是指报告期内我国市场在架移动应用的所有企业开发者总量，此处企业开发者指完成工商注册登记取得营业执照的开发者。团体（个人）移动应用开发者数量是指报告期内我国市场在架移动应用的团队或个人开发者总量，此处团队或个人开发者指尚未在工商注册登记的团队和个人开发者。

  

5.为更精准反应移动应用市场动态，监测数据由“累计方法（即统计数据采用累计计算方法）”改为“在架方法（即统计数据仅针对在架应用计算，剔除下架应用）”。
