# CNCERT发布关于Mirai变种Miori僵尸网络大规模传播的风险提示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649149713&idx=3&sn=174454389e87eed669ca52307032cabc&chksm=be8b580d89fcd11b2774a0626bc996db84f44899f19ce894450bc998d99f720f8edcfc3ce4a9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649149713&idx=3&sn=174454389e87eed669ca52307032cabc&chksm=be8b580d89fcd11b2774a0626bc996db84f44899f19ce894450bc998d99f720f8edcfc3ce4a9&scene=27#wechat_redirect)

近期，国家互联网应急中心（CNCERT）与奇安信共同发布关于Mirai变种Miori僵尸网络大规模传播的风险提示的报告。据悉，该DDoS僵尸网络每日上线境内肉鸡数（以IP数计算）最多已超过1万，给用户带来较大风险。CNCERT给出相关防范建议，在此提醒用户警惕该类威胁。
