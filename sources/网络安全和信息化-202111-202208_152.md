# 盘点RSAC 2022最热门的网络安全新产品

**RSAC 2022**

  

![](../Images/9f83d10b24c7c066c58c600247b0b517.png)

  

作为全球网络安全风向标，一年一度的RSA大会于当地时间6月6日在美国旧金山召开。以下列举了RSAC 2022上展示的部分网络安全新产品。

  

今年的RSAC主题为**Transform**（转型），大会所展示的部分安全新产品主要以身份和访问安全、SaaS服务和安全运营中心 (SOC) 增强功能为主。  

  

**AppGate: SDP 6.0**

SDP 6.0是AppGate公司零信任网络访问 (ZTNA) 解决方案的最新版本。该产品具有新的风险模型功能，旨在让用户扩展其现有企业安全工具的价值和范围，以简化和加速其零信任部署。Appgate SDP 6.0的新风险模型功能能够帮助客户特定的工作负载和资源划定高/中/低敏感度级别，它旨在为公司提供一种简单、灵活的方法来衡量登录时的用户/设备风险。风险模型通过其已有的安全工具，根据访问资源敏感性和风险评分，动态调整用户访问权限。

  

**DNSFilter: Data Export**

DNSFilter的Data Export（数据导出）工具能够让安全团队加快整体威胁检测和响应策略。它可以自动将DNSFilter查询日志数据导出到SIEM（安全信息和事件管理）和安全监控解决方案，以便通过多个数据源进行聚合、分析和操作。这将有助于减少用户的手动任务并提供对DNS的可见性，从而为用户创建完整的安全图景。

  

**Hunters: Hunters SOC**

Hunters SOC平台推出新的升级，以推进和简化安全运营工作流程。新功能包括整个安全运营工作流程的自动化、引入风险评分的威胁优先级、数据规范化以及对无限制数据注入的降噪支持。该SOC的自动化功能将使数据工程师和安全工程师能够专注于更高价值和特定的威胁。

  

**RSA: ID Plus, DS100**

ID Plus是一种基于SaaS的身份和访问管理 (IAM) 解决方案，为客户提供云、本地和混合部署的选择。ID plus是内置于DS100的新工具，这是RSA的新硬件验证器，专为服务RSA的零信任客户而设计。DS100是一种无密码身份验证器，它使用FIDO（快速在线身份验证）协议和一次性密码解决方案。
