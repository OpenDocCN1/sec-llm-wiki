# 数据泄漏事件频发，DLP是解决数据泄露问题的灵丹妙药吗？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649147892&idx=1&sn=c3756ea3f2c3f99e013bc4b0c80e79d9&chksm=be8b40e889fcc9fe30158dab8303c7705fc50cefaacf3debeff3776d8df105b58f3c8244dfce&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649147892&idx=1&sn=c3756ea3f2c3f99e013bc4b0c80e79d9&chksm=be8b40e889fcc9fe30158dab8303c7705fc50cefaacf3debeff3776d8df105b58f3c8244dfce&scene=27#wechat_redirect)

近年来，数据泄露事件频频发生。IBM发布的《2021年数据泄露成本报告》显示，2020-2021年平均数据泄露总成本将增长10%，导致 5,000 万至 6,500 万条记录泄露的超大规模数据泄露的平均成本为 4.01 亿美元。

  

Verizon发布的《2021年数据泄露调查报告》指出，2021年数据泄露事件中85% 涉及人为因素。2021年数据泄露的主要原因是Web应用程序攻击、网络钓鱼和勒索软件。

  

事实证明，通过技术和管理相结合才是从根本上解决数据泄露问题的关键。

  

在从技术手段解决数据泄露问题上，数据防泄漏 (DLP) 系统起到了非常有效的作用。特别是在引入自动化、机器学习技术之后，并且服务器负载占用得到显著降低，此时DLP产品在数据安全市场中赢得了一席之地。

 

![](../Images/f064b93d7475a5120aca8328d610036e.png)

  

  

**DLP 的演进**

  

DLP 是一个成熟的数据安全产品，已经拥有约20年的历史。当银行和大公司开始考虑为敏感的客户数据增强数据防护能力时，数据防泄漏解决方案应运而生——这是企业端在防范外部攻击时对DLP的需求。来自相关部门的安全审查以及确保合规是另一方面需求。

  

同时，在加强企业内部防护方面，DLP通过监控内部网络通信，检测并阻断内网可疑活动，确保了企业内部数据资产的安全。因此，近年来企业对DLP的需求急剧增加。

  

DLP 系统主要用于解决以下数据安全问题：

  

*   故意泄密——内部人员的恶意行为。
    
*   无意泄漏——工作人员的失误操作。
    
*   合规性——确保在处理敏感数据时符合相关的法律法规及标准。
    
*   外部威胁——例如网络钓鱼、勒索软件攻击等。
    

 

  

**客观认识DLP**

  

了解 DLP保护机制非常重要，因为它可以让用户知道DLP能在什么方面起作用。用户需要知道，DLP在保护数据安全中不是万能的，因为安全是一个复杂的过程。DLP在保护数据通信、监测用户操作以及监控文件存储方面发挥了独特作用。但是，超出DLP管控范围的威胁，DLP将无济于事。

  

通过将DLP与以下几个因素相结合，企业可以构建整体的数据防泄漏策略。

  

*   信息安全——管控涉及敏感数据的所有事件和交易。
    
*   业务安全——管控和调查具体业务事件。
    
*   人员安全——监测员工可疑行为。
    

  

尽管DLP系统提供了优秀的数据防泄漏能力，但还不足以防止所有的数据泄露事件，还需要企业内部与数据相关的流程和程序的变革。

 

  

**DLP部署方式**

  

通常，DLP部署方式如下：

  

*   代理——网络代理（如服务器、网关）和主机代理；
    
*   云服务。
    

  

用户的IT基础设施是托管在云端还是在本地都无关紧要。无论哪种方式，对数据的保护都将集中在网络的核心。当DLP系统识别出云环境中的不安全文件时，它就会阻止此类访问操作并通知安全人员，以避免业务流程中断。

  

使用DLP敏感度标签作为支持工具非常重要。它可以按类别（内容、组等）设置个性化策略，然后在界面中标记哪些文件需要受保护。但是这种标签的方式有一个缺点：它们通常无法自动接管，如果文件被移动时可能会发生策略失效的问题。

 

  

**DLP新功能**

  

为应对新威胁，如今的DLP系统出现了许多创新特性和功能，例如：

  

*   聚合密码进行统一管理；
    
*   结合能够检测出可疑活动用户的 Web 隔离技术；
    
*   云访问安全代理(CASB) 功能；
    
*   针对分支机构的统一DLP 系统部署能力；
    
*   人员行为管控；
    
*   屏幕截图保护技术；
    
*   用户信誉过滤；
    
*   自动检测图形“指纹”（如管理者签名、公司印章等）。
    

  

有些专家认为，未来的DLP解决方案将逐渐吸纳许多CASB的功能；DLP供应商也越来越多地利用机器学习技术来提高处理速度并减少人工操作；通过增强用户行为分析 (UBA) 模块来预测和防止数据泄漏也成为DLP系统发展的一个重要趋势。

  

随着容器的发展，对编排环境和托管环境存储库的监控也成为一个重要的场景。在多语言支持方面，DLP系统在界面和程序代码中也会进行加强。

 

  

**如何选择 DLP 系统？**

  

用户必须了解他们希望使用DLP解决哪些问题。DLP供应商也有义务为用户指明一些方向，这是一个双方沟通与协作的问题。

  

以下清单可以帮助用户选择合适的DLP解决方案：

  

*   需要保护的场景；
    
*   部署和分发——实施解决方案的复杂性考量；
    
*   预配置模板——可用策略、规则和脚本集；
    
*   分类器的可用性；
    
*   与供应商的互动（技术支持、培训等）；
    
*   容错能力、资源和性能——硬件和软件要求，系统如何处理功能负载等；
    
*   自我支持和后续任务的自动化水平；
    
*   试用——在真正部署之前，可以先尝试试用版。
    

 

  

**DLP 发展趋势**

  

数字化产生了大量有价值的数据，但也带来了更高的风险。无论这些数据存储在哪里或传输到哪里，都需要受到保护。当前DLP系统面临的主要挑战是与业务流程的自动化和深度集成。

  

目前DLP与CASB是各自独立的解决方案，但未来二者融合可能是一个趋势。另一方面，CASB也在逐步拥有DLP的某些功能。云和本地解决方案的融合也将是发展趋势。安全专家认为，DLP的下一步发展可能将转变为防御更广泛威胁的系统。

 

  

**结语**

  

如今DLP系统已经发展成为一种强大的安全工具，可以解决与数据泄露相关的许多风险。但同时也要明白，DLP是一个更大的整体安全防护体系中的一个元素，而不是一个万能的解决方案。数据防泄漏是一项复杂的工作，不仅需要技术工具的支持，还包括企业内部建立完善的数据管理制度以及不同部门之间的良好协作。

  

目前 DLP产品发展的重要方向是自动化、与安全流程和云服务的深度集成、CASB 功能支持以及增强机器学习模块等，以实现预测威胁、增强整体产品的运行并减少硬件负载。
