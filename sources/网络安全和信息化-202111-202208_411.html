火爆的Web3 和元宇宙，有何区别与联系？

目前在信息技术领域有两个概念引起人们的强烈关注—— Web 3（或称为 Web 3.0）和元宇宙。这两个热点领域代表着未来数字世界发展新方向。从目前的一些报道来看，有人或许会认为它们指的是同一种东西，这也可以理解，毕竟这两种技术都处于概念阶段，很难有人将二者的定义解释的更为透彻。但实际上，尽管它们在一些重要方面是相关的，但它们有着不同的定义，因此二者也有许多区别。


什么是Web3 和元宇宙？

简单来说，Web3 是去中心化的互联网，建立在区块链和去中心化自治组织 (DAO) 等分布式技术基础之上，而不是像传统互联网集中在服务器上那样。


Web3的核心理念是创建一个更加“民主化”的互联网，没有任何一个实体能够控制信息流，整个网络也绝不会出现单点式的崩溃。从理论上讲，运行应用程序和存储数据的服务器、系统和网络都将归用户自己所有，每个用户将对现有的规则以及如何使用它们拥有投票权。为什么称之为Web3呢？因为人们认为它将是继万维网（Web1）和当前网络（Web2，或社交网络）之后互联网的第三次重大飞跃。


而谈到元宇宙，近期这一名称可谓火爆业界。元宇宙目前实际上是虚拟世界的含义，用户可以在其中交互并以更加身临其境（沉浸式）的方式与应用程序和服务互动。“元宇宙”一词最早出现在1992年美国科幻大师尼尔·斯蒂芬森的科幻小说《雪崩》中，它描述了一个虚拟现实世界。如今，随着科技的发展，科幻正在接近现实。爱立信进行的一项调查发现，7/10的受访者认为，到 2030 年，我们将能够进入看似完全真实的虚拟世界。更广义地说，元宇宙这个词今天用来指任何努力创造沉浸式环境的数字空间。所以像堡垒之夜这样的游戏已经被用作虚拟演唱会的场所，而Roblox则为企业提供了建立数字世界中品牌的机会，它也被认为是元宇宙体验。


Web3 和元宇宙不是一回事

出于以下几个原因，有时会让人感觉二者可能是同一种东西。


首先，很少有人真正理解二者的含义。许多人和组织都对二者的实现目标有不同的想法，并且两者都是在探索中。例如， Facebook公司更名Meta后宣称将进军元宇宙。但像Meta这样的大公司对元宇宙的愿景与那些认为元宇宙应该去中心化的人是大相径庭的。


其次，去中心化网络（Web3）和元宇宙都曾一度被称为“Web 3.0”——第三代互联网。但如今Web3这一概念则专指上文去中心化的互联网。也有人将 Web 3.0 描述为“沉浸式网络”，其主要区别在于其“沉浸式”，从这个角度讲，它又跟元宇宙紧密相关了。


最后，Web3和元宇宙以一些非常重要的方式相互交错：用于构建 Web3 的技术，包括区块链、比特币和以太坊等基于区块链的加密货币，以及基于密码技术确保其唯一性的加密代币NFTs，都是实现用于工作、娱乐、社交和学习的虚拟世界的重要技术支撑。

 

Web3 和元宇宙是殊途同归？

一个重要的内容是，加密货币可以构成元宇宙中经济和货币系统的基础。如果元宇宙是现实世界的数字等价物，那么人们很可能会想在那里购物、赚钱和创业。


加密货币为此提供了现成的平台，虚拟世界里不需要银行或交易所（传统意义上的）来让人们交易和投资他们拥有的货币。存储在用户计算机（或云中）的钱包将是用于建立虚拟经济生活的基础。


但也有人提出质疑，为什么要去购买虚幻的数字物品呢？其实，现在已经有可参照的实例，那就是网络游戏中的游戏物品和代币，这些“虚拟资产”已经拥有一个庞大的市场，据称 2020 年其总体价值达到 540 亿美元。其中大部分是游戏玩家在游戏中佩戴的装饰品，只是为了装饰虚拟形象，或者只是为了炫耀自己的权利。


这就是 NFTs存在的意义。Web3愿景的另一个关键要素是 NFTs。NFTs是基于密码技术确保其唯一性的加密代币，它使独特的物品可以存在于数字世界中。与构成互联网、社交媒体和虚拟现实的大多数数据不同，NFTs不能通过“复制和粘贴”来无限复制，因为它由加密区块链上的代币表示，拥有唯一性。


我们已经看到像耐克这样的公司创造了仅存在于数字世界中的由NFTs支持的鞋子和服装。人们在现实世界中花费数百上千元购买昂贵的运动鞋仅仅是因为它们是限量版，那么为什么他们在虚拟世界中同样有“价值”呢？


从技术专家的角度来看，Web3 提供了在去中心化平台上构建数字世界的可能性。例如，Decentraland 是一个建立在以太坊区块链上的虚拟现实平台。这意味着用户可以使用以太坊虚拟货币购买属于他们的“土地”，他们可以随着土地价值的上涨而获利（就像现实世界中的房地产一样），他们还可以制定规则来确定那里可以做什么或不可以做什么。在去中心化的虚拟世界中，治理可以通过智能合约进行，区块链中的规则被设计为自主执行，用户可以投票和行使民主权利来影响虚拟世界的运作方式。甚至可以不必遵守现实世界中的物理定律。我们随时可以进入，随时可以离开，这与现实世界中制定法律的集中化体制大为不同。


Web3和元宇宙的基本概述有着根本性的区别，但在许多方面又密切相关。更重要的是，Web3和元宇宙中都包含一些因素用来支持对方的发展，二者在技术和理念上的相互促进也推动了双方的发展。
