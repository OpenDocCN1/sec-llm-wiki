# 美欧数据安全主要举措对我国促进数据安全产业发展的启示

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649153743&idx=1&sn=fce048cc9c8d9b73a62d39c1465c81f6&chksm=be8b69d389fce0c5bf04101aee9e58710efee851fed2e917d5964360d070c5375e1d38fae7fb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649153743&idx=1&sn=fce048cc9c8d9b73a62d39c1465c81f6&chksm=be8b69d389fce0c5bf04101aee9e58710efee851fed2e917d5964360d070c5375e1d38fae7fb&scene=27#wechat_redirect)

数据安全攸关国家安全与经济社会发展，发展数据安全产业是提升各行业各领域数据安全保障能力、加速数据要素市场培育和价值释放的重要任务。赛迪研究院中国软件评测中心认为，面对日益严峻的数据安全风险挑战，美欧等国家和地区着力顶层设计、监管执法、科技创新、主体培育等方面，统筹推进数据安全保护和价值释放，对我国数据安全产业发展有重要借鉴意义。

  
![](../Images/7821d1a4ca32819ba4f05fadceb79fca.png)点击文末**“阅读全文”**可查看下载全文![](../Images/3b4cabd2fcf35646f6f03dcc7512846f.png)一、美欧数据安全主要举措

1、强化数据安全顶层设计，推动安全和发展良好互促。

2、加大数据安全监管执法，激发有效需求加速释放。

3、加强重点方向前瞻性布局，牵引强化高水平供给。

4、推动多元市场主体培育，规范优化产业供应生态。

![](../Images/3b4cabd2fcf35646f6f03dcc7512846f.png)二、启示与建议

1、加强安全和发展双引导，多措并举提升产业需求侧响应。

2、践行监管和服务两手抓，以有效需求牵引强化供给水平。

3、强化创新和市场双驱动，以高质量供给适应引领新需求。

4、促进主流和垂类双培育，资源集聚构建产业繁荣生态圈。

作者：中国软件评测中心 白利芳 杨晓琪 黄英男
