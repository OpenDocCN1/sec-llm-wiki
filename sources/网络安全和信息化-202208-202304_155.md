# 中央网信办举报中心推出“今日辟谣”专栏

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649153527&idx=2&sn=0835d6162966421d96ad8e8ce2733c83&chksm=be8b56eb89fcdffdb746f22cac6b9fd4cae55477221de761f001452170282c1b9e47b87c1a8e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649153527&idx=2&sn=0835d6162966421d96ad8e8ce2733c83&chksm=be8b56eb89fcdffdb746f22cac6b9fd4cae55477221de761f001452170282c1b9e47b87c1a8e&scene=27#wechat_redirect)

为进一步打击网络谣言，营造清朗网络空间，自2月1日起，中央网信办举报中心通过中国互联网联合辟谣平台推出“今日辟谣”专栏。

![](../Images/2a3a4c86902b17909813cae22e21dd48.png)

“今日辟谣榜”旨在传递事实真相，传播科学知识，帮助公众获得权威、准确的真实信息。栏目设置“今日辟谣”“今日科普”及“今日提示”三大版块，每日聚焦群众关心关切的重要辟谣内容，对涉及公共政策、突发事件、医疗健康等领域的网络谣言及时回应。

![](../Images/f8cfa9cb2409e3111e39c1e5dfa99359.png "图片2.png")

发布涉公共政策、突发事件、民生热点等领域的重要辟谣信息。

![](../Images/905f455c1b5db16303d2fa6b32a709f1.png "图片3.png")

发布与群众生活息息相关、有助于提升公众防谣防骗能力的科普内容。

![](../Images/e9c203ea42d5ee9d68b67970c0e22ca1.png "图片4.png")

通报打击造谣传谣违法行为或当期相关法律常识、公益提示等。

欢迎广大网友关注中国互联网联合辟谣平台“今日辟谣榜”，积极提供谣言线索，共同阻断谣言传播链条，净化网络环境，营造文明和谐的网络家园。“谣言线索提交”通道https://www.piyao.org.cn/xxjbrk.htm
