# 应用隐私计算技术实现数据安全

近年来，国家高度重视数据安全工作，逐步健全了相关的法律法规。有关部门也陆续发布相关政策对数据管理和安全工作进行指导。

  

2020年4月，中共中央、国务院发布《关于构建更加完善的要素市场化配置体制机制的意见》，将数据同土地、劳动力、资本、技术等传统生产要素并列，作为一种新型生产要素参与分配。2021年《中华人民共和国数据安全法》（以下简称《数据安全保法》）和《中华人民共和国个人信息保护法》（以下简称《个人信息保护法》）等网络安全法律的出台实施，标志着数据安全和个人信息的保护被提高到新的高度。如何规避数据安全风险，全面保障数据安全，健全数据交易管理制度，建立数据分类分级保护制度、数据安全审查制度等，在依法合规的情况下使用数据、共享数据，利用新的技术在数据的使用和管理过程中推动社会发展、开拓新的商业模式，成为新的课题。2022年1月，国务院办公厅印发《要素市场化配置综合改革试点总体方案》，提出探索“原始数据不出域、数据可用不可见”的交易范式。作为释放要素价值的关键环节，数据资源的开放共享、交换流通成为重要趋势，市场需求日益增加。2022 年4月，《中共中央 国务院关于加快建设全国统一大市场的意见》明确提出，加快培育数据要素市场，建立健全数据安全、权利保护、跨境传输管理、交易流通、开放共享、安全认证等基础制度和标准规范，深入开展数据资源调查，推动数据资源开发利用。

  

一系列有关数据及安全保护的法律法规及政策陆续发布，构筑了数据安全保护的基础性制度。随着数据的价值不断被认可，目前全国已经有多个省市公布了相关的数据使用条例，以促进数据利用和产业发展为基本定位，最大程度促进数据流通和开发利用，激发市场主体活力，促进数字经济和社会发展。截至2021年底，全国省级公共数据开放平台增至24 个，开放的有效数据集近25万个。各地积极探索数据治理规则，培育数据要素市场，促进数据流通交易和开发利用。

数据的安全问题不但需要制度保障，更需要技术推动。隐私计算是在实现保护数据拥有者的权益安全及个人隐私的前提下，实现数据的流通及数据价值深度挖掘的重要方法。隐私计算在保证不泄露原始数据的前提下，对数据进行处理和计算，完成数据价值挖掘，保障数据在流通和融合过程中的“可用不可见”，实现数据所有权和数据使用权之间的分离。简单地说，可以使用经过授权的数据达到所需的计算结果，但无法看到原始数据，在最大程度上保障了数据的安全。隐私计算未来有可能成为解决数据安全和个人信息保护这一挑战的核心技术。

  

当前数据安全和个人信息保护工作存在的主要矛盾：第一是**效率低**，当前在合规的数据安全机制下的数据的共享、流通效率还非常低，针对不同的数据共享场景同时要做到安全和可控，要做的工作非常繁琐和复杂；第二是**技术成本高**，数据安全管理可供选择的技术路线、技术方案不多，成本也较高；第三是**没有形成行业共识**，既要保障数据安全，又要做到数据可控共享，这样才能够解决数据质量低下、数据孤岛、流通不畅等问题。各单位出于数据安全、保密的顾虑而不愿共享数据，使得不同单位之间难以利用对方的数据进行联合分析或深入应用。

  

隐私计算技术的应用可以做到“原始数据不出域、数据可用不可见”，在保护个人隐私和确保数据安全的前提下，分级分类、分步有序推动部分领域数据流通应用。隐私计算本质上是促进数据安全流通的底层技术，是数据经济领域的一个基础设施，既和数据有关，也和安全有关，可以真正让数据安全地流动起来，改变各行业的运行逻辑，成为数字经济重要的“基石”。作为数据计算、分析及保障数据安全的核心技术之一，隐私计算技术将成为激活数据要素市场、引导可持续发展的“安全员”和“催化剂”，以及数字经济的底层基础设施，为多行业、多领域构筑坚实的数据应用基础和技术保障。

  

在政策驱动和市场需求同时作用下，隐私计算技术、产业、应用迅速发展，金融、政务、医疗、通信、互联网等行业率先开展隐私计算应用。除以上传统场景外，隐私计算在能源、车联网等场景中也逐步开始探索性应用。在政策驱动和市场需求同时作用下，隐私计算技术应用产业迅速发展，成为商业和资本竞争的热门赛道。预计到2025年，60%的大中型企业将使用一种或多种隐私计算技术。

  

隐私计算技术是“数据可用不可见”技术的集合，涵盖众多学科的交叉融合技术。主流的隐私计算技术主要包括**多方安全计算、联邦学习、可信执行环境**等，还有**同态加密、区块链、零知识证明、差分隐私**等辅助技术。不同的技术往往交叉、组合使用，在保证原始数据安全性和隐私性的同时，完成对数据的计算和分析任务。

  

**多方安全计算**是基于密码学的隐私计算技术，将一组相互不信任的独立数据所有者，基于密码学技术共同计算一个目标函数得出准确的运算结果，同时各方输入的数据信息不会暴露且不可还原。多个参与方，保证每一方仅获取自己的计算结果，无法通过计算过程中的交互数据推测出其他任意一方的输入和输出数据。通俗来说，就是指参与方每方都算一点，然后合在一起能够完成一个任务，可以做一些数据查询、统计等计算。多方安全计算技术能够满足人们利用隐私数据进行保密计算的需求，有效解决数据的保密性和共享性之间的矛盾。

  

**联邦学习**是人工智能与隐私保护技术融合的隐私计算技术，是一种分布式的“机器学习”，以中央服务器为中心节点，通过与多个参与方交换网络信息来实现人工智能模型的更新迭代。即多个参与方事先商定好分析模型，在数据不出各方“本地”的情况下，用各方数据对模型进行训练，而后得出结论供各方使用。在整个联邦学习的过程中，各参与方的数据始终保存在其本地服务器，降低了数据泄露的风险。联邦学习可以有效解决数据孤岛问题,让参与方在不共享数据的基础上联合建模，能从技术上打破数据孤岛,实现协作。各参与者的身份和地位相同，可建立共享数据策略。由于数据不发生转移，因此不会泄露用户隐私或影响数据规范，满足合法合规的要求，更适合目前人工智能的需求。

  

**可信执行环境**是基于可信硬件的隐私计算技术，用软硬件方法构建的安全区域与其他应用和操作系统隔离开，使得操作系统和其他应用无法访问或更改该安全区域中的代码和数据，从而达到保护敏感数据和代码效果的技术。可信执行环境加进了硬件的因素，是通过构建一个独立于各方，且受各方认可的安全硬件环境，在安全、机密的空间内进行计算。简单来说，就是通过硬件打造出来的一个安全环境，在这个安全环境里的所有操作是受保护的。多方的数据放入这个可执行环境中，然后在执行环节得出结果。

  

隐私计算中的“**同态加密**”技术就是不同的数据所有方，按照相同的方式将数据加密，然后再由模型程序进行计算，计算结果解密后和明文（未加密的数据）计算结果一致。利用这项技术，可以实现只能获知最后结果，而无法获得每一个数据，实现数据可用不可见，不分享原始数据，只输出数据价值，打造数据生态，降低数据利用门槛，对保护信息安全有重要意义，可以为各行业的数据资产提供安全计算和应用开放的解决方案。随着云计算、大数据时代的来临，各行业数据共享、流通交换即将告别明文时代，或将开启“数据加密时代”。《数据安全法》第十六条、第二十七条在数据开发利用、数据安全、保护措施等方面提出了安全要求；《个人信息保护法》第五十一条明确指出个人信息处理者应当防止未经授权的访问以及个人信息泄露、篡改、丢失，并需采取相应的加密、去标识化等安全技术措施。面对数据共享、流通使用和数据安全、个人信息保护的双重要求，数据共享的密态无疑是最好的选择。支持数据全程以密态方式流通的隐私计算在数据安全、隐私保护方面有着独特的优势，助力各行业正式迈向数据密态时代。

  

**区块链技术**应用于隐私计算是必然趋势。区块链技术可以在数据共享过程中有效保护个人信息，对数据的确权、真实性等问题提供可行的解决方案，实现数据流通共享全流程的可记录、可验证、可追溯、可审计。企业可以将自己的数据以加密的形式存在区块链上，当需要与其他人共享或交易数据时，可以直接用加密的形式提供数据。对方将得到的加密信息在区块链中进行验证，这样对方既能确保数据的真实性，又不会让数据在链上被公开。“隐私计算+区块链”的结合能够促进商业模式的重大改变，它意味着在多方合作中，合作各方愿意把那些本来不愿意上链共享的数据拿出来共享，促成合作。区块链隐私计算有非常广泛的应用场景， 未来将形成大规模数据流通网络，推动数据资产化的发展。目前，在区块链与隐私计算技术相结合的实践中，也呈现出了软硬件技术相结合、更多技术融合发展的趋势。

  

**零知识证明**是基于密码学原理的技术，证明者在不向验证者提供任何有用信息的情况下，使验证者相信某个论断是正确的。总而言之，要创建零知识证明，验证者需要让证明者执行一系列操作，而证明者只有在得知底层信息的情况下才能正确执行。如果证明者乱蒙一个结果，那么验证者极有可能在验证中发现并证明他的错误。零知识证明结合区块链技术，可以让用户和企业用隐私数据来执行智能合约，并且不透露具体的数据内容。

  

**差分隐私**是一种严格的、可量化的隐私计算技术，简而言之，就是利用一些随机化的方法，在两个邻近的数据集的查询结果中添加一些随机化的内容，使得攻击者无法通过查询结果的差异来推测其中存在的隐私信息。差分隐私技术的引入，一方面可以使得企业能够在不侵犯个人隐私的情况下，使用大量的敏感数据进行研究或商业化用途。另一方面，研究机构可以基于差分隐私来开发适合数据社区的敏感数据云共享技术，在不侵犯个人隐私的情况下，解决数据共享的问题。

  

隐私计算本质上并不算一个行业，而是一个基础技术，可能和各行各业发生关联，推动数字经济的发展。各行业的数据只有通过共享、流通才能发挥出更大的社会和经济价值。因此，未来跨企业、部门的数据协作将成为数字经济的新常态。各行业数字化转型最大挑战之一就是“数据安全”问题，隐私计算技术为安全合规地利用数据来支撑业务运营提供了解决方案。  

  

在各行业的数字化转型过程中，首先应根据企业内部管理的实际情况，在数据安全、数据隐私合规的要求下，尽可能对组织内部的数据进行整合。推进数据标准体系建设，规范数据采集、存储、处理管理，落实数据安全保护责任，在内部先行形成数据流动平台。其次利用隐私计算技术，在本行业内部形成数据流通使用机制，利用隐私计算技术规划行业标准，建立统一的本行业数据监管平台。打造行业级的隐私计算平台，实现政府、企业间的信息聚合和资源共享。在数据的共享、流通过程中，需要进行数据的确权和分类分级管理，在使用过程中实行专数专用制度，即数据不能随意跨主体跨业务场景使用。同时，利用区块链技术实现数据使用过程的审计和监管，确保数据使用管理全过程透明化。使用计算过程的记录可供审计和监管，充分挖掘数据成果的价值。 

  

**结语**

没有产业场景的技术是没有发展前途的，隐私计算也不例外。用技术创新寻求突破并非难事，但如何找到产业场景的沉淀，是摆在隐私计算企业面前的重要问题。从应用层面而言，目前隐私计算重点应用在互联网、金融、电信、电力、医疗和政府部门等领域。这些行业数据规范性较强，标准化程度较高，合规运用的效率较高。
