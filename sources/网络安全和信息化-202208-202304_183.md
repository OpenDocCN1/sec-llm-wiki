# 一年一等待丨云计算产品之星：中国电子云专属云平台（CECSTACK）

2022年年底，《网络安全和信息化》杂志社联合IT运维网在线上举办了“一年一等待——产品之星、解决方案之星结果公布”活动，针对数据中心/云计算、网络安全、IT运维三个科技重点领域，遴选出2022年度市场表现不俗、用户口碑良好、具有较高发展潜力的优秀产品及解决方案，希望可以通过此次盘点，洞悉2022年度企业技术创新发展的新趋势。

![](../Images/3676fabd80f73baf280790f361b5f236.png)

  

中国电子云采用具有时代特质的云原生先进技术，通过微服务、容器化、DevOps、持续交付等云原生技术能力，基于中国电子自主计算产业领先优势，快速构建起具备原生安全、超大规模、灵活扩展、绿色低碳的高安全数字基础设施。在技术与业务发展上，中国电子云不受传统云计算技术演进过程中遗留的堆砌式发展包袱影响，轻装上阵，充分发挥后发优势，提升服务效率与质量，持续技术迭代，为千行百业数字化场景提供具备安全、先进、绿色特性的云计算产品体系，不断将云的服务能力与服务边界进行扩展，为使用者与开发者带来自主计算与云技术充分融合的新体验。

  

中国电子云CECSTACK在构建过程中，无论是理念、技术、架构又或云服务模式，旨在打造具有国际领先水平的本地化信息技术应用创新产业云计算服务平台。

  

作为全本地化软硬件的信息技术应用创新产业云计算服务平台，中国电子云CECSTACK目前已通过央企数字化转型信息技术应用创新产业云的云评估，并成为网信办信息技术应用创新产业云建设的标杆。结合国家大力发展信息技术应用创新产业的政策指导，中国电子云CECSTACK技术方案从架构、生态、能力等任何维度来看，均处于行业领先地位，未来发展空间巨大。

  

目前，中国电子云CECSTACK已服务超过400家政府和企业客户，承建了天津西青数字底座、大理苍洱云平台、江西南昌市数字新建安全云底座、四川德阳智慧城市、四川遂宁市电子政务云平台、中国邮政储蓄银行云平台、中国人民保险PICC云平台、国家管网集团专属云平台、南方电网调度云、中国华电燃机智能运维云平台等项目，并入围中国政务云市场领导者象限。

  

  

**编辑点评**

中国电子云基于中国电子安全先进可信的本地化自主计算体系，结合分布式云原生技术，率先打造出适用于全栈分布式云计算产品的全自研云原生云操作系统。凭借此项技术而诞生的专属云CECSTACK产品，实现了信息技术应用创新产业云计算领域的五项技术突破：“云、管、端”全方位安全防护；基于场景的异构算力智能调度；统一管理异构资源池；构建超大规模信创云基础设施；统一的云原生应用开发平台。
