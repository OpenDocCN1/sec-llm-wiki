2022年年底，《网络安全和信息化》杂志社联合IT运维网在线上举办了“一年一等待——产品之星、解决方案之星结果公布”活动，针对数据中心/云计算、网络安全、IT运维三个科技重点领域，遴选出2022年度市场表现不俗、用户口碑良好、具有较高发展潜力的优秀产品及解决方案，希望可以通过此次盘点，洞悉2022年度企业技术创新发展的新趋势。 

  

**数据中心产品之星：Dell PowerEdge XR系列加固型服务器**

利用企业级计算功能在边缘收集和处理更多数据，这些计算功能可与用户数据一起移动，并提供前所未有的性能，XR系列服务器结构紧凑、坚固耐用，经过严格的测试，符合MIL STD、NEBS和Marine标准。在恶劣的边缘环境中（承受灰尘、极端温度、冲击和振动等各种挑战）大展身手。Dell PowerEdge XR服务器的长度不到传统服务器的一半。前置或后置连接使它们易于安装在基站的小型机柜中。XR12通过五个PCIe Gen4插槽提供灵活的I/O选择，包括支持两块最新的NVIDIA A800、A10或A40 GPU卡。

  

**云计算产品之星：戴尔科技云平台VMware Cloud Foundation 4.X on VxRail 7.X**

VMware Cloud Foundation 4.X on VxRail 7.X使用统一的功能完备的自动化平台，通过简单直接的途径交付云规模的Kubernetes服务。戴尔科技云平台VCF on VxRail将超融合基础架构层和VMware Cloud软件堆栈作为一个完整的自动化平台进行管理，提供现代化应用程序和混合云。VxRail 和 VMware Cloud Foundation 之间深度集成，提供功能完备的自动化平台，简单直接地交付混合云及云规模的Kubernetes服务。VMware SDDC Manager 和 VxRail Manager之间深度集成，客户可使用熟悉的VMware工具在混合云基础架构中部署和管理集群及工作负载，从而获得一致性运营体验。戴尔科技云平台VCF on VxRail还可让客户选择按需计费（Dell APEX FOD) ，按使用量付费的“轻资产”IT消费模式。  
**网络安全解决方案之星：Dell PowerProtect Cyber Recovery数据避风港**今天，企业的数据保护正面临着前所未有的新挑战——人为恶意删库跑路、勒索软件入侵等常常见诸报端。戴尔提供从备份到容灾到“数据避风港”的保护策略，通过 “三位一体”的数据保护策略和框架，让企业客户关键业务数据更安全。戴尔数据避风港提供历经验证的现代化保护解决方案，来保护关键数据免受勒索软件和毁灭性网络攻击的损害，该解决方案帮助客户提供抵御勒索软件和破坏性网络攻击的数据保护终极防线，戴尔数据避风港方案在全球已经有1700多家客户案例，帮助客户从破坏性网络攻击中获得补救和恢复，保障业务正常运营并保护公司声誉和敏感数据。  

  

**编辑点评**

围绕计算、数据保护和云平台，戴尔科技集团聚焦边缘计算处理能力、“三位一体”数据保护策略以及深度集成的自动化云交付功能，帮助用户充分发挥计算能力，挖掘数据价值，获得一致性的运营体验。
