国电南京自动化股份有限公司（简称“国电南自”）是国家电力系统中首家在上交所上市的高科技公司，被誉为中国电力高科技第一股，其产品主要包括电网自动化、电厂工业自动化、轨道交通、信息安全与电子板块，以建设行业领先、国际一流的高科技上市公司为目标。公司在南京拥有三个园区，现有5000名左右员工，年产值超过50亿元。国电南自现共有300余台网络设备为其提供业务保障。

遇到的挑战

国电南自有三个园区网络系统，有4000余位员工依赖网络服务，但专职网络维护的工程师只有一人。在网络维护人员不足且缺乏网络监控设备的情况下，网络故障处理变得十分被动，浪费了大量时间成本。当网络设备发生故障时，员工只能电话告知网络维护负责人，负责人在确认故障具体情况后进行实地排查和解决。“比如一个子机房里有五六台交换机，可能每台都需要看，看了之后再去现场排查，比较费事，对故障的定位也不准确。” 国电南自网络主管林朝晖说道。处理一个单点故障，顺利的情况下需要半小时，否则将耗费一到两小时。


林朝晖入职国电南自以来，公司一直没有可视化的监控工具，在面对网络稳定性问题时，主要通过增加骨干网络设备的冗余等硬件设施，以及人工定期巡检予以解决。但这种办法增加了人力成本，效率低下，并且不能及时发现某些问题。“比如说交换机的电源风扇报警、温度过高报警。我们在现场一般不能直接看到这些信息。”林朝晖解释道。


从内部员工管理系统、财务系统到办公系统，国电南自几乎完全依赖网络。单点故障会影响部分员工的正常工作，而骨干问题则会直接影响公司整体业务的进行。面对网络管理人员紧缺、故障解决被动滞后、故障恢复耗时较长等问题，网络维护亟需一套功能全、性能强、服务好的网络管理系统，以便及时发现网络故障、缩短故障恢复时间并简化网络维护管理。


解决方案

在选择解决方案时，作为网络主管，林朝晖主要关注公司整体网络运行的稳定性和可视化，首要需求是监控产品能够准确定位和定性网络问题，及时排除网络故障，更好地服务员工和客户的网络需求。同时，林朝晖表示：“以前非可视化时，网络的拥堵情况排查起来特别不容易。”因此，他期望监控产品还能够及时发现网络拥堵问题。


在此情况下，林朝晖开始寻找合适的网络监控产品。他对SolarWinds及其他品牌的产品进行了比较。因为SolarWinds产品的可视化功能可解决公司人力成本不足的问题，且信誉优良、服务到位，他最终选择使用了SolarWinds NetFlow Traffic Analyzer (NTA)、SolarWinds Network Configuration Manager (NCM)和SolarWinds Network Performance Monitor (NPM)产品。林朝晖表示：“SolarWinds的产品非常全面，应用用户也很多，出现问题能够及时处理，上门服务以及其他的服务配置体验也都非常好。”


获得的价值

部署SolarWinds产品后，能够通过可视化功能发现、定位和定性网络拥堵问题，这为网络维护带来了极大帮助。此后，国电南自因业务需要以及使用的网络应用增加，进行了网络扩容。林朝晖表示：“这次网络扩容增加了整个公司的无线网络，扩容后的网络规模比部署SolarWinds前扩大了至少三倍。以前每次扩容都会产生问题，但这次非常顺利，也没有因此增加网络维护人员。”


同时，SolarWinds帮助提升了公司网络的稳定性以及整体网络运维水平。林朝晖介绍道：“公司每年对网络可用性的要求达到99.5%，使用SolarWinds后能达到99.9%以上。”


SolarWinds产品通过可视化功能，能够清晰呈现网络状态，使网络维护人员准确、及时地发现和解决网络故障，甚至提前发现可能发生的故障并预先处理，由此减少了更多网络维护人员的投入，有效节省了人工成本。林朝晖对此分析道：“国电南自这样规模的公司，需要网络维护人员3~5人，有了可视化功能则能减少维护人员，按照一人20万元~30万元来计算，一年可节省人工成本60万元~150万元。”

重要引言

“SolarWinds提供了网络情况的可视化，维护成本价格非常低，每年都有相应的升级，对于管理大规模的网络实为最佳选择。” ——林朝晖，国电南自股份有限公司网络主管
