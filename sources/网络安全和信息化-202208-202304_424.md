# 《数据出境安全评估申报指南（第一版）》发布（附全文）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649151570&idx=3&sn=1f0daa3e3a7ae277c4737a24fcf598a6&chksm=be8b514e89fcd858998f4a84e2875ed325217a99e0c74ef8d8fa494661ef1b7ce1359509ce49&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649151570&idx=3&sn=1f0daa3e3a7ae277c4737a24fcf598a6&chksm=be8b514e89fcd858998f4a84e2875ed325217a99e0c74ef8d8fa494661ef1b7ce1359509ce49&scene=27#wechat_redirect)

为了指导和帮助数据处理者规范、有序申报数据出境安全评估，国家互联网信息办公室编制了《数据出境安全评估申报指南（第一版）》，对数据出境安全评估申报方式、申报流程、申报材料等具体要求作出了说明。

　　数据处理者因业务需要确需向境外提供数据，符合数据出境安全评估适用情形的，应当根据《数据出境安全评估办法》规定，按照申报指南申报数据出境安全评估。
