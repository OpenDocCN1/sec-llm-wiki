# 我国数字政府建设迈过“深水区”的四点建议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649151458&idx=3&sn=9c746dc230f6e2014145d6061dfa7f81&chksm=be8b5efe89fcd7e89926c399ec89f6b138cdc8d3104126b9aa861189fa495c3b81def2c0093f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649151458&idx=3&sn=9c746dc230f6e2014145d6061dfa7f81&chksm=be8b5efe89fcd7e89926c399ec89f6b138cdc8d3104126b9aa861189fa495c3b81def2c0093f&scene=27#wechat_redirect)

**内容提要**  

2022年6月，国务院发布《关于加强数字政府建设的指导意见》，要求将数字技术广泛应用于政府管理服务，推进政府治理流程优化、模式创新和履职能力提升，构建数字化、智能化的政府运行新形态，为推进国家治理体系和治理能力现代化提供有力支撑。当前，数字政府建设面临系统协同性建设仍有不足、区域和城乡政务服务发展存在差距、政府数据开放共享和应用力度有待加强，以及数据安全保护尚不完善等问题。赛迪顾问数字经济产业研究中心认为，随着数字政府建设迈入“深水区”，应注重加强数字政府跨地区跨部门协同建设、推进基层数字政府建设、完善数据管理机制、搭建数据安全责任制，从而提升数字政府治理能力，提高公共服务效率，推进经济高质量发展。
