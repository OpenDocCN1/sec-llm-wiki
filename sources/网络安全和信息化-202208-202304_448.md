# 云安全合规走向落地，亚马逊云科技的独特手段

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649151322&idx=2&sn=4dd46afb1b83d3156a27f0df02fff37a&chksm=be8b5e4689fcd7501ecc8f3f11b8c204a82a04df630a2db0bbee5a10c11172965fa45bab5e31&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649151322&idx=2&sn=4dd46afb1b83d3156a27f0df02fff37a&chksm=be8b5e4689fcd7501ecc8f3f11b8c204a82a04df630a2db0bbee5a10c11172965fa45bab5e31&scene=27#wechat_redirect)

随着云计算的发展以及相关安全技术的不断完善，云安全技术和产品已变得愈加成熟。如何从更深层次实现云安全的落地，成为包括云服务商和用户在内的各方的共同责任。

  
艾瑞咨询发布的《2021年中国云安全行业研究报告》指出，伴随产业互联网深化，云计算广泛渗透带动云安全产品布局加快。伴随企业上云走向“精耕细作”，法律政策与行业规范日渐完善，责任共担模型将更好地指导云厂商在推动“云+产业”结合的进程中，明确其安全责任。  
  

**让安全责任走深向实，亚马逊云科技有何“独门绝技”？**

亚马逊云科技大中华区产品部总经理陈晓建认为，云上安全合规有望成为企业可即时拥有的常态，它对企业不再意味着负担和阻碍，而是推动业务发展的合作力量。

  

![](../Images/e7e236daff7fc5acf8cacd6439edfcb5.png)

  

一方面，云平台及服务让企业无需再从零起步构建安全合规体系，那些基础而琐碎的基础设施安全合规问题，将成为云服务提供商的责任，不再需要企业为此投入前期成本。另一方面，服务于大量用户的云服务商利用规模化的安全服务带来更具可视化及自动化的服务，使用户以更少的成本和更精简的人力达成既定安全目标。  
  
“安全好比消防员，不仅需要在发生‘火灾’时及时救火，但更多时候需要做的是防患于未然。”这是亚马逊云科技云安全一直秉承的理念。  
  
要做到防患于未然，就要做到让安全深入人心。亚马逊云科技最早提出安全共担理念，对于安全理念和文化具有悠久的历史。在亚马逊云科技看来，保证公司的业务安全，要做的不是只把这个工作交给管理层或者交给安全团队来解决，而是公司每个人的责任。  
  
为实现将安全责任落实到每个人身上，亚马逊云科技将安全视为“Job Zero”，即将安全置于业务之上的优先级。具体来说，管理者会定期与业务负责人会面，以了解其需求，传递安全工作的价值。亚马逊云科技有个特殊机制，就是每周都会召开安全会议，该安全会议会由CEO亲自参加。该会议更是一个机制，它代表了亚马逊云科技对安全工作的高度认识。  
  
必须将安全融入产品或服务的开发生命周期和运营当中,这是如今许多安全厂商对“安全左移”的共识，亚马逊云科技同样遵循该理念。具体来说，亚马逊云科技还通过设置安全守护者小组，按照一定比例在产品团队中设置安全人员岗位，他们为产品和服务的所有安全负责，同时还设置了独立的应用安全审查流程，适用于所有产品的服务的更新与发布。  
  
陈晓建表示：“安全守护者是应用安全审查流程中的‘安全大使’，‘大使’这两个字意味着它并不是安全团队的人，而是被派驻到各个业务团队的安全代表。这是一个非常独特的机制，他们被放在各个研发团队和服务团队中，其工作是保证所派驻团队的产品和服务能够实现安全的责任。”  
  
为实现安全理念的落地，亚马逊云科技还采取可衡量的指标，让安全“可量化”。针对产品团队，衡量指标是他们是否提出了好的安全建议，促进了哪些安全功能的发布；针对安全团队，衡量指标是促进了多少新产品的发布，缩短了多少新产品上线的时间。  
  
“安全的工作不是为了去给业务团队设置障碍，而是帮助业务团队找到一条更安全、更高效的实现路径。” 陈晓建表示。  
  
为激发安全团队活力和创造性，安全团队成员需要保持多样性，最好具有不同的性格，甚至不同的背景或文化。“我们希望拥有来自各种不同背景和不同能力的安全成员，同时我们非常欢迎新员工的加入。因为新员工往往可以带来第三方的思维，也往往没有偏见，能够为团队带来更新的思考视角。” 陈晓建表示。  
  

**安全最佳实践，可以这样做**

从安全防护角度来说，有两个重要的因素：人和数据。在亚马逊云科技看来，将人和数据分开，两个维度的交叉形成的交集是一个更严谨的安全方案。  
  
针对人的安全管理，最重要也是最基础的手段是最小权限原则。不仅需要了解员工维持工作需要的最小权限，还要考虑其有效期，同时也要定期检查这些访问权限，以便随时间与业务的变化保持合理性。  
  
基于数据的防护，漏洞管理是重中之重。亚马逊云科技鼓励员工和客户发现并上报任何安全漏洞，而无需担心误报，亚马逊云科技后台的专业安全团队会评估和解决漏洞报告。特别是针对Log4J这一严重漏洞，必须做好以下措施：严格限制来自互联网的访问；拥有全面的软件清单及其使用方式；保持第三方产品更新到最新版本；深度防御；日志记录。  
  
勒索软件是近年数据安全的又一严重威胁。亚马逊云科技认为，防范勒索软件最重要的工作是提前演习，而不是在事后进行修补。亚马逊云科技提供了诸多安全工具防范勒索软件：Amazon Inspector可提前检测漏洞，Amazon GuardDuty可用于检测异常活动，Amazon Backup具备存储备份功能。  
  
历史经验一再表明，传统基于边界和单点的安全防御早已不适用于如今复杂多变的网络攻击环境，整个体系架构的安全性，是需要通过立体的、多层次的、相互配合的机制来完成。  
  
对此，亚马逊云科技一直倡导的是“云中安全必须是洋葱式的多层防护，而不是一个鸡蛋”。“鸡蛋”虽然有一个坚硬的外壳，但它的防护外壳一旦被突破，整个安全体系就崩塌了。而“洋葱”不同，“洋葱”是多层防护结构，不仅拥有层层递进的防护机制，而且不同层次之间还有互补机制。这是一个合理的安全机制所必须具备的。  
  
整个洋葱机制分为五层，涵盖威胁检测和事件响应、身份认证和访问控制、网络和基础设施安全、数据保护与隐私以及风险管控及合规五大领域，每层之间都能够实现互相递进的安全防护能力，任何安全防护都不能依托于某一个单点，它依赖的是各个安全层次之间的配合。  
  
为给客户带来更好的安全防护，亚马逊云科技不断根据客户需求持续丰富其安全服务及功能。Amazon Identity and Access Management (Amazon IAM) Roles Anywhere，能够将Amazon IAM对工作负载的管理能力扩展至客户的云环境之外；Amazon GuardDuty Malware Protection，可帮助客户检测运行在其云环境中的的恶意软件；Amazon Detective for Elastic Kubernetes Service(Amazon EKS)，可将Amazon Detective覆盖的数据源扩展至Amazon EKS；Marketplace Vendor Insights（预览版），可简化对供应商的安全合规评估并实现对风险的持续监测；等等。这些安全工具伴随亚马逊云科技的最佳实践，在2022 re:Inforce全球安全大会上得以呈现。  
  
陈晓建表示，随着创新技术的发展，越来越多企业云计算安全理念开始从限制业务发展向赋能增长转变。未来亚马逊云科技针对云安全的发展和定位有以下几个方向：一是基础能力的持续提升，例如数据的加密、数据威胁的检测等；二是合规自动化，企业必须在满足合规的框架下推进业务发展，如何将合规的需求以自动化的能力或者更智能的方式进行部署，以提升安全效能、减少人力，是赢得先机的必要条件；三是人工智能和机器学习在安全领域的应用，可以让安全变得更“聪明”。  
  
“通过我们的海量运营、通过我们去支持全球数百万客户的各种安全事件，然后把在一个客户中所取得的实践，能够复用到其他客户中来，从而取得规模效益。” 陈晓建表示。  
  
如今，亚马逊云科技的安全理念和最佳实践正随着合作伙伴网络的铺展而融入其中，让更多合作伙伴和客户享受到云上安全合规的红利。
