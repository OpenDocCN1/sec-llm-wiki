# 推动我国基础软件开源发展的几点建议

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649150990&idx=2&sn=15c1a5924d44a7ced1a45da3b3c81481&chksm=be8b5f1289fcd604000c981b78a56afa39dc0dc63c9de8217e55b5ad6eeb9759bf212c80c0c6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649150990&idx=2&sn=15c1a5924d44a7ced1a45da3b3c81481&chksm=be8b5f1289fcd604000c981b78a56afa39dc0dc63c9de8217e55b5ad6eeb9759bf212c80c0c6&scene=27#wechat_redirect)

  
**内容提要**  

近年来，以开源模式为主导的技术路线在全球基础软件领域影响力逐步增加，众多优秀的开源产品引领了新的技术潮流，成为推动基础软件产业发展的重要力量。2021年11月30日发布的——《“十四五”软件与信息技术服务业发展规划》正文中共42次提到“开源”，足以看出国家对开源发展的重视。赛迪顾问基于全球重要开源基础软件的发展历程，深入分析我国开源基础软件发展现状，并提出四条建议供产业发展借鉴，期望对有关部门及企业有所启示。
