# “双碳”两年：我国数据中心行业发展为哪般？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MzMwMDU5NQ==&mid=2649150926&idx=3&sn=1be4299b02b4f2d72426df63b087db8c&chksm=be8b5cd289fcd5c4ad0460411be394c9b4239085e9e3db6b3ffd60e84960ac0bb787afab180d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5MzMwMDU5NQ==&mid=2649150926&idx=3&sn=1be4299b02b4f2d72426df63b087db8c&chksm=be8b5cd289fcd5c4ad0460411be394c9b4239085e9e3db6b3ffd60e84960ac0bb787afab180d&scene=27#wechat_redirect)

**内容提要**  

2020年9月，我国在第七十五届联合国大会上郑重宣告“中国二氧化碳排放力争于2030年前达到峰值，努力争取2060年前实现碳中和”的目标。“双碳”目标对传统高耗能的数据中心行业提出了更高要求。如何加快弥补节能产品和可再生能源应用覆盖不足，在满足爆发式增长的数据处理需求的同时实现绿色化发展，成为摆在我国数据中心行业面前的一道难题。“双碳”两年，在国家政策的指导下，低碳节能新技术、新产品、新模式等不断涌现，助力数据中心行业探索绿色化发展的“破题之法”。赛迪顾问电子信息产业研究中心总结出了“双碳”目标提出后我国数据中心行业在产品结构、评价体系等方面发生的三大变化，并针对现有问题提出了几点建议，期望能为加快数据中心低碳绿色发展有所启迪，助力我国数据中心行业加快实现“双碳”目标。
