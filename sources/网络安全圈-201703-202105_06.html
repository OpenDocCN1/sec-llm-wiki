漏洞描述

Apache Druid 是用Java编写的面向列的开源分布式数据存储，旨在快速获取大量事件数据，并在数据之上提供低延迟查询。2021年3月30日，Apache Druid官方发布安全更新，修复了 CVE-2021-26919 Apache Druid 远程代码执行漏洞。请Apache Druid 用户尽快排查服务器是否受影响并采取安全措施阻止漏洞攻击。

漏洞编号

CVE-2021-26919

漏洞危害

由于Apache Druid 默认情况下缺乏授权认证，攻击者可直接构造恶意请求执行任意代码，控制服务器。

漏洞等级

高危

受影响版本

Apache Druid < 0.20.2

修复方案

1.升级至安全版本及其以上。

2.为Apache Druid 增加授权。
