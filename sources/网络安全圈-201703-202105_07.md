# 【漏洞预警】Apache OFBiz RMI反序列化任意代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2NjAyODAzMA==&mid=2247483796&idx=1&sn=b0ceadebab8d91c694b07c220beeba9c&chksm=fcb3f205cbc47b1391ab0ae7ec257674bf17b39ec54b6450a5e31297aa89fba4bae57b82067f&scene=126&sessionid=1681657880#rd](http://mp.weixin.qq.com/s?__biz=MzU2NjAyODAzMA==&mid=2247483796&idx=1&sn=b0ceadebab8d91c694b07c220beeba9c&chksm=fcb3f205cbc47b1391ab0ae7ec257674bf17b39ec54b6450a5e31297aa89fba4bae57b82067f&scene=126&sessionid=1681657880#rd)

**漏洞描述  
**

Apache OFBiz是一个电子商务平台，用于构建大中型企业级、跨平台、跨数据库、跨应用服务器的多层、分布式电子商务类应用系统。2021年3月22日 Apache OFBiz官方发布安全更新，修复了一处由RMI反序列化造成的远程代码执行漏洞。攻击者可构造恶意请求，触发反序列化，从而造成任意代码执行，控制服务器。请Apache OFBiz用户尽快采取安全措施阻止漏洞攻击。

**漏洞编号**

无

**漏洞危害**

攻击者可构造恶意请求，触发反序列化，从而造成任意代码执行，控制服务器。

**漏洞等级**

高危

**受影响版本**

Apache OFBiz < 17.12.06

**修复方案**

1.升级 Apache OFBiz 至安全版本。
