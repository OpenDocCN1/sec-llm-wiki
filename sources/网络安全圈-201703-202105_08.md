# 【漏洞预警】Apache Solr任意文件读取与SSRF漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2NjAyODAzMA==&mid=2247483791&idx=1&sn=9f8e93a07202763b6b9c0b3af5f704c7&chksm=fcb3f21ecbc47b08336cac72fe9c1dfefcc0604f1eda58c0cd8ed1403b6d69769f4bc5e118fd&scene=126&sessionid=1681657880#rd](http://mp.weixin.qq.com/s?__biz=MzU2NjAyODAzMA==&mid=2247483791&idx=1&sn=9f8e93a07202763b6b9c0b3af5f704c7&chksm=fcb3f21ecbc47b08336cac72fe9c1dfefcc0604f1eda58c0cd8ed1403b6d69769f4bc5e118fd&scene=126&sessionid=1681657880#rd)

**漏洞描述  
**

Apache Solr是一个开源的搜索服务，使用Java语言开发。Apache Solr的某些功能存在过滤不严格，在Apache Solr未开启认证的情况下，攻击者可直接构造特定请求开启特定配置，并最终造成SSRF或文件读取漏洞。目前漏洞PoC已公开，请Solr用户尽快采取安全措施阻止漏洞攻击。

**漏洞编号**

无

**漏洞危害**

攻击者利用此漏洞，可实现任意文件读取。

**漏洞等级**

中危

**受影响版本**

Apache Solr 所有版本

**修复方案**

1.增加身份验证/授权，可参考官方文档：https://lucene.apache.org/solr/guide/8\_6/authentication-and-authorization-plugins.html

2.禁止Solr API 以及管理 UI 直接对公网开放。设置防火墙，以便只允许受信任的计算机和人员访问。
