# 【漏洞预警】Gitlab markdown 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2NjAyODAzMA==&mid=2247483785&idx=1&sn=398a5790c616c5f7c8da4b77c122563d&chksm=fcb3f218cbc47b0ec6ab89f2221838a9d786b962309c41a6c3324c6c939b1cf7b3667fe7b02e&scene=126&sessionid=1681657880#rd](http://mp.weixin.qq.com/s?__biz=MzU2NjAyODAzMA==&mid=2247483785&idx=1&sn=398a5790c616c5f7c8da4b77c122563d&chksm=fcb3f218cbc47b0ec6ab89f2221838a9d786b962309c41a6c3324c6c939b1cf7b3667fe7b02e&scene=126&sessionid=1681657880#rd)

**漏洞描述**

Gitlab是一款基于Git 的完全集成的软件开发平台，且具有wiki以及在线编辑、issue跟踪功能、CI/CD 等功能。2021年3月18日Gitlab官方发布安全更新，修复了一处远程代码执行漏洞，攻击者可构造恶意请求，在Gitlab服务器上执行任意代码，控制服务器。因此，提醒Gitlab用户尽快采取安全措施阻止漏洞攻击。

**漏洞编号**

无

**漏洞危害**

未经授权但经过身份验证的用户，能够利用该漏洞在服务器上执行任意代码。

**漏洞等级**

高危

****受影响版本****

Gitlab CE/EE < 13.9.4

Gitlab CE/EE < 13.8.6

Gitlab CE/EE < 13.7.9

**修复方案**

1.升级Gitlab至安全版本。

2.将Gitlab服务器部署于内网，或通过设置安全组仅对可信地址开放。
