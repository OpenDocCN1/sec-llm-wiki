**一、基本情况**

| 

近日，监测发现Microsoft Windows Win32k权限提升漏洞的利用细节及PoC已被公开，该漏洞CVE编号：CVE-2021-1732。本地攻击者可利用此漏洞提升到system权限。建议受影响用户及时更新漏洞修复补丁进行防护，做好资产自查以及预防工作，以免遭受黑客攻击。

  


 |
| --- |

**二、漏洞描述**

| 

Microsoft Windows Win32k是美国微软（Microsoft）公司的一个操作系统。提供一个多任务的图形用户界面。

该漏洞是由于Windows内核模式驱动对内存对象处理不当导致，本地攻击者可利用此漏洞提升到system权限。

  


 |
| --- |
