**一、基本情况**

| 

3月2日，微软紧急发布了Exchange Server安全更新公告，此次更新修复的高危漏洞包括服务端请求伪造漏洞、反序列化漏洞、任意文件写入漏洞，相关漏洞CVE编号为CVE-2021-26855、CVE-2021-26857、CVE-2021-26858、CVE-2021-27065。因漏洞影响严重，已有在野攻击利用，微软官方建议及时更新漏洞修复补丁，做好资产自查以及预防工作，以免遭受黑客攻击。

**三、漏洞描述**

| 

Microsoft Exchange Server是美国微软（Microsoft）公司的一套电子邮件服务程序。它提供邮件存取、储存、转发，语音邮件，邮件过滤筛选等功能。

**1. Microsoft Exchange Server服务端请求伪造（SSRF）漏洞（CVE-2021-26855）**

成功利用该漏洞的攻击者能够发送任意HTTP请求并通过Exchange Server进行身份验证。

**2\. Microsoft Exchange Server反序列化漏洞（CVE-2021-26857）**

具有管理员权限的攻击者利用该漏洞在Exchange服务器上以SYSTEM身份运行代码。

**3\. Microsoft Exchange Server任意文件写入漏洞（CVE-2021-26858/CVE-2021-27065）**

攻击者通过Exchange服务器进行身份验证后，可利用该漏洞将文件写入服务器上的任何路径。该漏洞可以配合CVE-2021-26855服务端请求伪造（SSRF）漏洞进行组合攻击。
