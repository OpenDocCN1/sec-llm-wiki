**一、基本情况**

| 

2月10日，微软发布了2月安全更新公告，修复了.NET Core、.NET Framework、Microsoft Edge、Office、Visual Studio、Windows Defender、Windows TCP/IP、Microsoft Office SharePoint等多款产品组件和软件存在的56个漏洞的补丁，其中Microsoft Windows TCP/IP存在多个高危漏洞，相关CVE编号：CVE-2021-24074、CVE-2021-24094、CVE-2021-24086。攻击者可利用该漏洞在目标主机上执行任意代码或导致目标主机蓝屏。漏洞危害较大，且无需交互及身份验证即可触发漏洞。对此，建议广大用户及时下载并安装修复补丁进行防护，做好资产自查以及预防工作，以免遭受黑客攻击。

  


 |
| --- |

**二、漏洞描述**

| 

**1、Windows TCP/IP远程代码执行漏洞（CVE-2021-24074/CVE-2021-24094）**

Windows IPv4/IPv6协议栈存在远程代码执行漏洞，远程攻击者通过向目标主机发送精心构造数据包，成功利用该漏洞在目标主机上执行任意代码或导致目标主机系统宕机。

**2、Windows TCP/IP拒绝服务漏洞（CVE-2021-24086）**

Windows IPv6协议栈存在拒绝服务漏洞。远程攻击者通过向目标主机发送精心构造数据包，成功利用该漏洞导致目标系统拒绝服务（蓝屏）。

**四、安全建议**

| 

**1、官方建议**

目前微软官方已发布漏洞修复补丁，建议受影响用户及时更新补丁并安装。

https://msrc.microsoft.com/update-guide/releaseNote/2021-Feb

**2、临时缓解措施**

*   **CVE-2021-24074**
    

1）可通过以下命令（管理员权限）将sourceroutingbehavior 设置为"drop"：

netsh int ipv4 set global sourceroutingbehavior=drop

如需恢复默认设置，可使用以下命令：

netsh int ipv4 set global sourceroutingbehavior=dontforward

2）配置防火墙或负载平衡器以禁止源路由请求

*   **CVE-2021-24094/CVE-2021-24086**
    

1）可通过以下命令（管理员权限）将global reassemblylimit 设置为0：

以下命令将禁用数据包重组，乱序数据包将会被丢弃。建议在更新生产系统之前进行充分测试。

Netsh int ipv6 set global reassemblylimit=0

如需恢复默认设置，可使用以下命令：

Netsh int ipv6 set global reassemblylimit=267748640

2）配置防火墙或负载平衡器以禁止IPv6 UDP分段
