一、基本情况

1月19日，Oracle官方发布了1月份安全补丁更新公告，其中修复了一个Oracle Database Server堆栈溢出漏洞，对应CVE编号：CVE-2021-2035。该漏洞易被利用且风险较大。攻击者通过RDBMS Scheduler组件进行远程攻击，从而导致服务器崩溃。建议受影响用户及时更新修复补丁，做好资产自查以及预防工作，以免遭受黑客攻击。


二、漏洞等级

高危



三、漏洞描述

Oracle Database Server是美国甲骨文（Oracle）公司的一套关系数据库管理系统。该数据库管理系统提供数据管理、分布式处理等功能。

该漏洞存在于Oracle Database Server的RDBMS Scheduler component组件中，具有Export Full Database访问权限的远程攻击者通过Oracle Net进行远程攻击，从而破坏RDBMS Scheduler程序，导致服务器崩溃。


四、影响范围

  • Database Server 12.1.0.2

  • Database Server 12.2.0.1

  • Database Server 18c

  • Database Server 19c


五、安全建议

Oracle官方已更新安全补丁，建议用户尽快下载更新补丁并安装。

https://www.oracle.com/security-alerts/cpujan2021.html
