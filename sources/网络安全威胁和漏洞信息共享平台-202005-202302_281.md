**一、基本情况**

  
  

F5 BIG-IP 是美国F5公司一款集成流量管理、DNS、出入站规则、web应用防火墙、web网关、负载均衡等功能的应用交付平台。

近日，监测发现F5发布了F5 BIG-IP远程代码执行的风险通告，该漏洞编号为 CVE-2020-5902，在F5 BIG-IP产品的流量管理用户页面(TMUI)/配置实用程序的特定页面中存在一处远程代码执行漏洞。未授权的远程攻击者通过向漏洞页面发送特制的请求包，可以造成任意Java代码执行。进而控制F5 BIG-IP的全部功能，包括但不限于:执行任意系统命令、开启/禁用服务、创建/删除服务器端文件等。

建议广大用户及时安装最新补丁，做好资产自查以及预防工作，以免遭受黑客攻击。

**三、 处置建议**

  
  

|   
 || 

**（一）通用修复建议**

升级BIG-IP到已修复的最新版本即可修复该漏洞，各版本对应的修复版本为：

BIG-IP 15.x 升级至 15.1.0.4BIG-IP 14.x 升级至 14.1.2.6BIG-IP 13.x 升级至 13.1.3.4BIG-IP 12.x 升级至 12.1.5.2BIG-IP 11.x 升级至 11.6.5.2

访问该链接获取最新版相关组件：https://downloads.f5.com/esd/productlines.jsp

**（二）临时修补建议**

如果目前无法升级，官方建议可以通过以下步骤临时缓解影响。

**1．修改 httpd 配置  
**

要消除未经身份验证的攻击者利用此漏洞的可能，请将LocationMatch配置元素添加到httpd。

*   登陆 TMOS Shell（tmsh）执行：
    

Tmsh      

*   修改 httpd 配置信息：
    

edit /sys httpd all-properties    

*   找到 include 部分并添加以下内容：
    

include '       <LocationMatch ".\*\\.\\.;.\*">    Redirect 404 /     </LocationMatch>     '      

*   通过输入以下命令，将更改写入并保存到配置文件中：
    

Esc    :wq!    

*   通过输入以下命令来保存配置：
    

save /sys config    

*   通过输入以下命令来重新启动httpd服务：
    

restart sys service httpd     **注意：**经过身份验证的用户仍将能够利用此漏洞，而不必考虑其特权级别。

**2．更改IP配置 **

通过自身IP阻止对BIG-IP系统的TMUI的所有访问。

您可以将系统中每个IP 的“ Port Lockdown”设置更改为“ Allow None ”。如果必须打开端口，则应使用Allow Custom，注意禁止访问TMUI。默认情况下，TMUI侦听TCP端口443；但是，从BIG-IP 13.0.0开始，Single-NIC BIG-IP VE部署使用TCP端口8443。或者，可以配置自定义端口。

在更改IP的配置之前，请参考以下链接内容：

*   https://support.f5.com/csp/article/K17333
    
*   https://support.f5.com/csp/article/K13092
    
*   https://support.f5.com/csp/article/K31003634
    
*   https://support.f5.com/csp/article/K51358480
    

**注意：**此操作可以防止通过Self IP对TMUI / Configuration实用程序的所有访问。这些更改可能还会影响其他服务。

**3．访问设置**

为了减轻此漏洞对F5产品的影响，应只允许管理人员通过安全网络访问F5产品。

有关保护对BIG-IP系统的访问的更多信息，请参阅如下链接：

*   https://support.f5.com/csp/article/K13309
    
*   https://support.f5.com/csp/article/K13092
    

**注意：**在安装固定版本之前，访问TMUI的经过身份验证的用户将始终能够利用此漏洞。
