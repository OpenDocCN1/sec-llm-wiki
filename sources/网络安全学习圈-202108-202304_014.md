**方法一：**

测试环境 Windows 2003 server

查看开启的端口

![](../Images/25fbd1402cf765e8b4507e4390ec55f4.png)  

**没有开启 3389 端口**  

执行语句

```
wmic RDTOGGLE WHERE ServerName='%COMPUTERNAME%'
 call SetAllowTSConnections 1
```

执行结果

![](../Images/62ca762715fe8351b42399ee3fd62496.png)

在查看下端口

![](../Images/e1e02c666f272931c1b9e92e243aca08.png)  

3389已经被开启了  

  

**方法二：**

测试环境：Windows 2003 server

关闭之前开放的 3389 端口

![](../Images/4ede0f76950f0c76a61781eb5def564f.png)  

```
REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f
```

![](../Images/53ee10e4259b7b5bf0eed11a39858a84.png)

查看端口开放情况  

![](../Images/18a77ddf0c916ab65434a8552e549078.png)

3389端口开放成功
