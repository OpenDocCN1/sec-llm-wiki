# 黑客攻击相亲网站，228万条信息泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMTcyMjg2MA==&mid=2247486273&idx=1&sn=055e770485eb6b64ddfcaf699764b11c&chksm=9751bc42a0263554f982d54ba61ed357cb9b72b25fbc5629a83bb450376fee88dae24a2f5f76&scene=126&sessionid=1681667880#rd](http://mp.weixin.qq.com/s?__biz=MzIxMTcyMjg2MA==&mid=2247486273&idx=1&sn=055e770485eb6b64ddfcaf699764b11c&chksm=9751bc42a0263554f982d54ba61ed357cb9b72b25fbc5629a83bb450376fee88dae24a2f5f76&scene=126&sessionid=1681667880#rd)

在下方公众号后台回复：【网络安全】，可获取给你准备的最新网安教程全家桶。

据外媒 ZDNet 消息，有黑客近日攻击了美国知名相亲网站 MeetMindful。

获取了用户信息数据库并在一个黑客论坛上公开，可以免费下载。

![](../Images/e1e31a562ce48ab9c191e588d46a0861.png)

数据包含用户的真实姓名、电子邮箱、城市、性别、相亲偏好、出生日期、位置经纬度。

网络方面包含IP 地址、加密的账号密码、Facebook 用户 ID 等等。

据该公司称，社交账号的密码都是采用加密的方式存储，不会导致大规模密码泄露危机。

![](../Images/db9309c87b987ee1e33ba22bd1f9259b.png)这些用户数据共计 1.2GB ，包含228万条用户信息。

  

![](../Images/1058636c9e3df8f8b821fa1e23a216f8.png)

这些信息极有可能被利用来勒索，或实施诈骗等犯罪活动。

影响巨大。

![](../Images/0821a9b52e2238999b85564a06da24eb.png)不过也有网友猜测可能是内部员工所为，要不就是为了搞对象。

毕竟黑客为了钱都会攻击一些金融企业。

![](../Images/245f8dae7f564284904fc88e96fc9c56.png)

据传这名黑客此前也攻击过一家服装设计网站。

所以为了脱单的可能性不大......
