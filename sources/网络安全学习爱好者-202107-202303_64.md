靶机介绍

运行环境：  
靶机：网络连接方式设为自动桥接，IP地址：192.168.1.84  
攻击机：通网段下的kali linux，IP地址：192.168.1.37  
开始渗透  
运行靶机  
靶机运行之后就提示了IP地址

![](../Images/287bed02f5ceca16c3865a81b2487839.png)

扫描端口

![](../Images/09cb80df1d0176d9623aece92e80cb91.png)

看到有很多端口，先访问80看一下，是两张图片F12查看源代码也没有发现

![](../Images/b5bc069d4a03e7d5cd6c2076733f22e5.png)

  

![](../Images/9dc113512c33de00044f5f29f350a9c0.png)

扫一目录，看到了熟悉的wordpress和upload还有robots.txt 进行访问

![](../Images/56d3f5f76606e690924e0415cb4bbd9f.png)

robots.txt指向了wordpress

![](../Images/1c518c830b838f9cef154d3f43a9700d.png)

upload是一个目录  

使用工具扫描，网站确实存在wordpress漏洞

![](../Images/743c4f4418f919c87bd78deaecbe95b4.png)

使用Wordpress的专用扫描器 wpscan  
扫出来两个用户，进行爆破  
wpscan --url http://192.168.1.84/wordpress -e u

![](../Images/6ed9f4f4ee3c1c60ba4c817495680fa4.png)

爆破还是使用wpscan  
wpscan --url http://192.168.1.84/wordpress -P rockyou.txt -U admin

![](../Images/cbb93b73afb9a78812baecd29909467e.png)

获取密码admin，进入wordpress登录页面进行登录

![](../Images/ad6f2fd2054ebae06626ea25fd8e3e44.png)

![](../Images/6f69d1fde5df4092501380c92b5605a3.png)

  

登录成功.  
在Appearance选项里面找到了又404.php，index.php等页面  
将404页面添加一句话木马发现无法访问  
将index.php加上一句话中国菜刀和中国蚁剑连不上，把index.php原来的内容删掉改成反弹shell的代码

![](../Images/7ac52fed61bd4943951a8932561dd836.png)

开启监听，并访问 反弹shell成功

![](../Images/a27211aa65a2f494b7d512a59be14dfb.png)
