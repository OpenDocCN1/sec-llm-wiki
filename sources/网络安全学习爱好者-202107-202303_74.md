# Vulnhub靶机CK-00渗透

靶机介绍  
官方下载地址：http://www.vulnhub.com/entry/ck-00,444/  
难度是容易的，建议使用VirtualBox运行靶机

![](../Images/c21ad5c9a7b3a2ed3fc13381f83e1cbb.png)

运行环境  
靶机：网络设为桥接，IP地址：192.168.1.90  
攻击机：同网段下的kali linux，IP地址：192.168.1.37  
开始渗透  
将靶机运行起来

![](../Images/692fccf56c6f4a9b8f09034b3278a205.png)

靶机运行界面就已经告诉了IP地址，接下来就是扫描端口了

![](../Images/7c1da17280b9e1e96321b27080d2d8a2.png)

这里看到22端口是ssh服务，密钥的加密方式是rsa  
80端口的架构是wordpress  
使用wpscan对wordpress扫描，发现有一个用户admin

![](../Images/93d62dccaa3c77cec6fa8de9b141ea22.png)

![](../Images/658232becfc5fdc825147689b74000bb.png)

爆破admin用户的密码

![](../Images/125eac36fbad0c4864f9ce148cff196c.png)

  

![](../Images/59c3fc13295574c681af96cf183a2f7a.png)

爆破获取密码admin  
启动msfconsole，选择wordpress

![](../Images/bdef1ffcc2a281e2de20ae7e9f113b0c.png)

选择第53条，这个漏洞可以直接反弹shell

![](../Images/9161c5d1b66a729ec6cc185f6736cc42.png)

![](../Images/6b9e7402fb8d605784157721a5950be4.png)

查看配置

![](../Images/e3d213124e99754d79fbed4d0af9e019.png)

![](../Images/2216b54b2c0c6d39872a6ab176c1023c.png)

设置用户名，密码，IP地址使用run运行脚本  
输入shell，得到一个可以交互的shell

![](../Images/001a2ccfe5aa97b834d803d8fde339e0.png)

使用python打开一个终端

![](../Images/28ec5fb3b790b7d5a3e8239dbc354347.png)

在wordpress的配置文件当中找到了bla用户的密码

![](../Images/03531147ef52a9f865136f68b5f4b512.png)

为了方便使用ssh连接到bla用户

![](../Images/553ffef3d553ceae7dd53f85edff1530.png)

sudo -l发现bla1用户拥有scp的权限，这样就可以伪造bla1用户的密钥进行连接

scp使用方法参考连接：https://blog.51cto.com/703356/287947

ssh免密码登录方法参考链接：https://blog.csdn.net/xieziran784/article/details/91991087

![](../Images/590058ea63997afbb37483a6bf16cb2f.png)

使用ssh-keygen生成一个无密码的密钥

![](../Images/0c019acfb0c263a045b3879b301b919e.png)

使用scp将公钥放到bla1的.ssh的文件夹下面  

![](../Images/f8a0c9f5359fb7405e32354af48ee3e3.png)

使用ssh服务连接

![](../Images/c64cf8330ac84273023352f2a9905ef0.png)

看到已经获取了bla1用户的权限，继续使用sudo

![](../Images/73ee19b05f1db59194cddd031e685adf.png)

使用sudo提权到ck-00用户

![](../Images/d63253624b53a03e97b773b4bf229c8c.png)

继续使用sudo

![](../Images/e530bbbb741927888ef7d8d5e19b6d87.png)

使用工具查询dd提权的命令

![](../Images/ba0ab033c796f7d6c97bc8a84ffba966.png)

尝试之后提权失败  
查看当前目录生成了’\[file\]'里面的内容是DATA

![](../Images/bdc68018f6ced343641dd50d02c56d67.png)

这样的话可以在/etc/passwd文件中添加1个root权限账户，达到提权的目的  
首先在kali生成密文

![](../Images/e743d6e8f89fc9a45d4ceb19d1a923e0.png)

执行以下命令将passwd原先的内容写进去，在末尾加上一个新的用户名和密位还有赋予权限最后以“ | sudo dd of=$LFILE结束

![](../Images/c397c5138bb56ec4cd239ebd54237236.png)

查看passwd，jianhao用户已经加入进去了

![](../Images/19449975aca53669e3103c66ac425d13.png)

使用su切换到jianhao用户

![](../Images/871a2f7ae533c310540fc372e8479ec0.png)

成功提权到root，切换到root目录查看flag

![](../Images/32f88141a54547814c5f36db4d2ae4bb.png)

这个靶机渗透完成，难点就是在于最后的各种各样的提权！
