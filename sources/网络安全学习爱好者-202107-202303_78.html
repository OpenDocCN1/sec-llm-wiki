Windows 11正式版终于发布，最低配置要求来了

今天，微软开始正式推送Windows 11。


“让用户与之所爱，更近一步。”


这是微软日前官宣Windows 11正式推送日期时许下的愿景，并称Windows 11将给用户带来全新的体验。


实际上经过Windows 11 预览版镜像泄露事件，再加上各种新闻爆料，下一代Windows的新鲜神秘感早已所剩无几。


而且每次提及Windows操作系统，让很多用户又爱又恨。“痛恨”Windows用户主要恼火其时常自动更新且Bug不断，该问题在Windows 10系统上显得极为突出，以至于有些用户到现在还怀恋Win7甚至WinXP系统。


还有微软的反复无常，此前曾随意抬高升级Windows 11的硬件门槛，导致很多提前享用Windows 11预览版用户，或将不得不回退到Windows 10版本。


话不多说，接下来让我们感受一下Windows 11正式版本与预览版本的不同之处吧。


迭代的Windows 11预览版本

自从6月24日Windows 11官宣以来，Windows 11预览版也在用户的测试中不断迭代更新。尽管Windows 11用全新UI的设计，史上最完美游戏体验，支持Android软件等新功能，深深吸引了用户，却依旧无法阻碍人们对WIndows系统的疯狂吐槽。


首先被用户吐槽最多的是微软严苛的升级计划。微软公司曾经发布升级Windows 11硬件要求，使得很多用户都卡在TPM 2.0，或者CPU版本不符合硬件需求等门槛上。即便用户使用虚拟机也不能逃脱这种严格的升级要求，以至于很多用户不得不放弃升级Windows 11，或者使用不被微软官方认可且提供更新支持的Windows 11预览系统。


除此之外，还有用户调侃Windows 11 UI设计上有苹果的身影。Windows 11界面呈现出所谓的毛玻璃效果，以及图标圆角化且自带阴影等特点，皆类似于macOS，甚至Windows 11的侧边滑出小组件，也有一丝macOS的味道。据悉苹果的macOS 11（Big Sur）侧边滑出小组件在右边，令人尴尬的是Windows 11在左边。


在其它方面，Windows 11预览方面还支持明亮模式和暗黑模式。据悉Windows 11在UI许多新设计，都来源于Windows 10X的设计思路，尽管后者最终被微软取消。


总的来说，尽管Windows 11预览版本存在一些不足，但是刚刚推送的Windows 11正式版本不仅修复一些Bug，还为我们带来一些“小惊喜”，下面让我们一起来欣赏吧。


使用全新开始菜单和任务栏

Windows 11相比Windows 10最大的变化，就是其全新UI界面，原先用户最熟悉的开始菜单被重新设计—从左侧转移到中间。


而Windows 11正式版开始使用新的开始菜单和任务栏，从新系统的每一个声音、字体和图标，微软开发团队都深思熟虑地考虑了每一个像素和细节，希望为用户带来更现代、更新鲜、更美好的体验。


通过全新的开始菜单，用户可以快速访问自己关心的内容和应用程序，而且“开始”菜单利用云和Microsoft 365的强大功能，无论哪个平台或者设备上（即便是在 Android 或 iOS 设备），用户都可以在“开始”菜单上查看到最近文件。

（来源于微软官网）

全新的Widgets与Microsoft Teams

微软方面介绍，为了让用户更接近自己关心的内容和信息，Windows 11正式版推出了全新Widgets，这是一种由AI和网络提供支持的全新个性化订阅源。


当小部件像一块玻璃一样在屏幕上滑动时，通过单击或从左侧滑动来打开用户的个性化提要。无论是通过Outlook日历和待办事项列表集成浏览用户的一天，了解最新的头条新闻或明天的天气预报，还是查看用户最喜爱的OneDrive照片记忆，Widgets小部件能让用户喜欢的一切都触手可及。

（来源于微软官网）

WIndows 11正式版本中Microsoft Teams也给用户带来一种全新的体验。用户只需单击一下，就可以使用个人帐户与自己的朋友、家人和其他联系人进行聊天、语音或视频通话，无论他们使用的是哪种设备或平台——Windows、Mac、Android或iOS。Microsoft Teams不仅适用于拥有智能设备的人，还可以通过SMS文本消息加入对话。此外，用户也可以直接从Chat中打开Microsoft Teams，通过事件安排、快速投票、文件共享等功能实现自己的计划安排。

（来源于微软官网）


可激发创造力的生产力工具

Windows 11不仅具有强大的用户新体验，还可提高用户的工作效率并激发用户的创造力。


从多个显示器和浏览器选项卡到在Word或PowerPoint中编辑文档，Windows 11都可轻松地在PC上处理多项任务。在Windows 11正式版本中，Windows 11引入了全新的Snap布局、Snap组件和虚拟桌面功能，借助适用于更大屏幕的全新三栏布局，用户可以轻松地将所需的所有内容呈现在桌面上，从而帮助用户整理窗口和优化屏幕空间，尽量保证用户工作学习状态。

（来源于微软官网）


而且Windows 11在开发初始就考虑了一些残障人士的需求，并称Windows 11是有史以来最具包容性的Windows版本，操作与系统界面对残障人士极其友好。Windows 11提供了熟悉的辅助技术，例如讲述人、放大镜、隐藏式字幕和Windows语音识别，为不同类别的残障人士提供了支持和便利。


微软还改进了触摸体验，不仅在速度和效率方面得到提升，而且还优化了墨迹书写和语音体验。平板模式下，其页面布局没有完全改变，任务栏中的图标之间距离变大了，使用户更方便触摸图标、移动窗口或者调整图标大小。

（来源于微软官网）

Windows 11正式版将延期支持安卓App

此外，这次Windows 11正式版本中不再提供对Android应用程序支持，微软官方表示这项新功能将在今年晚些时候推送。尽管此前微软方面已经确认对Android应用程序支持不会在今天Windows 11正式版本中出现，但是还有部分粉丝用户期待会有奇迹发生。为此不少用户感慨：“微软这次说话难得‘靠谱’一些”。


微软称，为了实现了安卓App在Windows 11上本地运行的目标，微软一直与亚马逊和英特尔进行紧密合作，但是安卓App目前只能从新版Microsoft Store中的亚马逊Appstore上下载。由于目前国内不提供亚马逊Appstore服务，即便将来Windows 11发布对Android应用程序支持，国内用户也没办法使用这项功能。

（来源于微软官网）


据悉这些应用程序将由英特尔桥接技术提供支持，而且Android应用程序也可以固定到任务栏上。微软也没有使用Google Play系列服务支持，这意味着依赖Google Play服务集成的Play商店和Gmail等应用将无法运行。


根据微软官方介绍，鉴于Windows系统自动更新且安装包体积大的特点，这次Windows 11将为用户“解决”这个烦恼。Windows 11正式版本推出所谓“无缝更新”新功能，这项新功能不仅使新版Windows 11更新安装包体积比此前Windows 10减小40%，还可以优化Windows Update for Business等一系列系统服务，提高用户PC运行速度。


第三方应用商城入驻微软商店

与之前Windows 11预览版不同的是，Windows 11正式版本中微软商店（Microsoft Store）于9月29日宣布了一项重大更新：计划从亚马逊和Epic Games Store开始，将在Microsoft Store上提供第三方商店的应用程序。除此之外微软还允许在商店中上架第三方替代浏览器——Opera和Yandex浏览器，以上亮点在这次Windows 11正式版本推送中都实现了。


（来源于微软官网）

Windows 11专为游戏而生

Windows 11专为游戏而生，可将用户的PC游戏体验提升到一个新的水平。


此前微软在Windows 11首次发布会上宣称：这次带来史上最好的Windows PC游戏体验，Windows 11从画面体验、性能提升等多个方面都得到巨大的提升。


如果用户的PC具有支持HDR的显示器，Auto HDR将自动将1000多个DirectX 11和DirectX 12游戏升级到高动态范围，从而呈现更广泛的颜色和亮度。微软官方还认为游戏玩家的选择很重要，因此Windows 11提供打开或者关闭默认开启的HDR功能。


Windows 11还支持直通存储（DirectStorage）功能，这是首次在Xbox Series X和Xbox Series S控制台上引入的功能。当把NVMe固态驱动器和 DirectX 12 GPU搭配使用时，为游戏玩家带来更快的加载时间和更真实的游戏渲染环境。


Windows 11内置了Xbox 应用程序。用户通过Xbox应用程序，可以使用PC Game Pass（会员资格单独出售）浏览、下载100多种高质量PC游戏。


（来源于微软官网）

除了以上介绍的种种更新之外，Windows 11还提供面向未来的混合办公和学习环境。Windows 11是专为从芯片到云的安全防护而设计的，以此帮助用户应对新的工作环境及日后将会面临的挑战。



你想升级Windows 11吗？

据AdDuplex官方统计数据显示，Windows 11目前市场份额份额已达到1.3%，粗略估计使用Windows系统的PC在全球数量大约有20亿台左右，由此计算得知，这次Windows 11正式版本推送可能覆盖2000多万用户。

（来源于2021年9月的AdDuplex报告）

根据微软官方公布的最新Windows 11最低硬件要求显示，升级Windows 11依旧需要TPM 2.0以及符合要求的芯片处理器，因此很多想体验Windows 11系统的用户被此难住了

处理器：1GHz 或更快的支持64位的处理器（双核或多核）或系统单芯片 (SoC)

内存：4 GB RAM

存储：64 GB或更大的存储设备

系统固件：支持UEFI安全启动

TPM：受信任的平台模块 (TPM) 2.0版本

显卡：支持DirectX 12或更高版本，支持WDDM 2.0驱动程序

显示器：对角线长大于9英寸的高清 (720p) 显示屏，每个颜色通道为8位

对于硬件不支持升级Windows 11的用户而言，微软官方表示，对Windows 10的支持


对于硬件不支持升级Windows 11的用户而言，微软官方表示，对Windows 10的支持将持续到2025年10月14日，在此之前用户还是可以购买和安装Windows 10。还有传言称21H2应该在2021年10月推出，据悉21H2版本更新将是一个次要更新，并且只包含少数功能。


如果消费者和企业用户不想更新Windows 11，他们将如何阻止Windows 11呢？微软官方表示，Windows系统不会强迫普通用户或者企业用户更新新版WIndows 11系统，普通用户和企业用户都有自由选择更新系统的权利。

此外微软依旧不建议不符合Windows 11硬件门槛的用户升级Windows 11，因为在不受支持的硬件上运行Windows 11将无法获得微软官方提供的安全更新服务。微软官方警告用户，尽管通过使用媒体创建工具进行裸机或全新安装，用户可以“暂时”绕过硬件检查，暂时升级Windows 11，但这样做是十分危险的。

微软将支持Windows 11多长时间？据悉2021年10月5日是 Windows 11家庭版和专业24个月生命周期的开始，这也是企业版和教育版36个月支持窗口的开始，此外微软还计划每年只为更新Windows 11一个功能。

目前很多PC硬件厂商已经宣布旗下很多产品都支持升级WIndows 11新系统。所以，屏幕前的各位读者朋友是否已经成功安装Windows 11，还是准备购买新电脑体验Windows 11系统的乐趣呢？欢迎留言评论。
