**将sublime菜单栏汉化**

1.打开sublime

![](../Images/f8885788283eb3062d32a40e5e6a5122.png)

2. 选择菜单栏Tools下的 CommandPalette...

![](../Images/95c4c8a4e253ee32b9283d4a0dd858a6.png)

3. 然后在弹出框中输入install，选择跳出的Install Package Control，选中后要等一会这个过程稍微慢一点

![](../Images/7fc2b13d3a033428640921bcf68790a7.png)

4.  安装成功后会跳出成功界面，确定

![](../Images/5a320e1cb5fe903d39f9a6901f79eb9f.png)

5. 重复第3步进入Install Package Control

![](../Images/7de463fc779409594a6223d2c165c9ca.png)

载入成功的界面

![](../Images/ce420a29e4e7d76f7c59b9d6923329f0.png)

6. 载入后搜索chinese，选中第一个ChineseLocalizations，这个过程也会相对慢一些，坐等即可

![](../Images/e2d76ce6edbab353762131dd6706f761.png)

  

7. 安装成功后会自动跳出界面，等着会自动变为中文版，如果出现汉化成功提示后菜单栏还没有成为中文别急，等一会就好，汉化完成

![](../Images/99835fd0c1d2394e9951d7f4d3bb7a67.png)
