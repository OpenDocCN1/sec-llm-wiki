# Windows 10 系统 SQL server 2019 下载安装

    SQL Server 是Microsoft 公司推出的关系型数据库管理系统。具有使用方便可伸缩性好与相关软件集成程度高等优点，可跨越从运行Microsoft Windows 98 的膝上型电脑到运行Microsoft Windows 2012 的大型多处理器的服务器等多种平台使用。

    Microsoft SQL Server 是一个全面的数据库平台，使用集成的商业智能 (BI)工具提供了企业级的数据管理。Microsoft SQL Server 数据库引擎为关系型数据和结构化数据提供了更安全可靠的存储功能，使您可以构建和管理用于业务的高可用和高性能的数据应用程序。

  

下载安装

SQL server 2019下载可以到官网去下载  

官网地址：http://www.microsoft.com/zh-cn/sql-server/sql-server-downloads  

![](../Images/75cc9ac2700c1c355fbafd84b329d157.png)

  

这里是有两个版本的我这里选择的是Express版本的  

下载完之后双击运行  

![](../Images/e9bca4ef9c67c1c4c45f140b5c88d79b.png)

这里是有三个安装类型，可以根据自己的需要安装

我选择的是基本

![](../Images/062e62b8772270a1c4075461af1a949c.png)

  

  

这里选择语言类型\-\>点击接受

  

![](../Images/cfeedb5bbbae5ec2000d236a86ef5144.png)

  

这里选择安装的位置\->点击安装

![](../Images/5b41a18d8850c9eb8ffd9e1652d9fbbf.png)

  

接下来就是漫长的等待了.......

![](../Images/701d394532a39e5933b415b95370decf.png)

![](../Images/9a5be0f4c9f326a5e702b55575a50b45.png)

  

安装完成点击立即连接  

![](../Images/61a60a766c981cdf443cade7842b7868.png)

  

出现这个页面就说明安装成功了  

![](../Images/6f3b74dc38cc9025d6d72d627e8bb9ed.png)

  

返回这个页面点击安装SSMS

![](../Images/c6fad25ba9983f85160075cfd0ef4c8d.png)

  

从弹出来的浏览器页面下载SSMS，在可用语言那里可以选择不同语言的版本  

![](../Images/3df4768096bb3fc4b84899c8d4208622.png)

  

下载完之后双击运行程序

![](../Images/72b01d15633473a0e280ebfda36cf8f7.png)

  

选择安装的位置->点击安装  

![](../Images/8955305596203dd3687a35366626a7ea.png)

  

又是漫长的等待的时间........  

![](../Images/c2782e9f789116cfb7a2d72d42a33ee6.png)

![](../Images/fd9b5d436048e9f7de92f1e64569f5f5.png)

  

出现这个页面就代表安装成功了

![](../Images/17cea9cd31fe60d674ac39badb59294d.png)

  

在开始菜单里面找到 Microsoft SQL Server Management studio  打开  

![](../Images/363037dbc7636538c865a0369511e524.png)

  

这里输入本机名称->点击连接

![](../Images/ecb3491e6d2f696d61ba576f203e3026.png)

![](../Images/9ab0209f9b164a61846918ccc242c4b3.png)

  

连接成功之后 选择：文件 -->新建–>使用当前连接的查询  

![](../Images/162e337b85c5c7b127ddeb72b4f9fa8f.png)

  

在这里就可以输入指令执行了  

![](../Images/5c79f1af2614df09c1c0399928501b90.png)

  

到这里SQL server 2019就安装成功了！
