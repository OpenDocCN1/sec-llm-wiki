## 前言：

MISC经常遇到取证分析的，而且在实战中取证也是非常重要的，学习一下。

## 什么是活取证

> 在主机存活时发现系统被入侵,然后直接把机器的运行内存dump下来，对运行内存进行分析，还原一些进程的中的信息。

主要工作便是

*   抓取文件 `metadata`
    
*   创建时间线
    
*   命令历史
    
*   分析日志文件
    
*   哈希摘要
    
*   转存内存信息等
    

## 什么是死取证

> 对机器的磁盘做镜像之后进行分析，在关机后制作硬盘镜像，分析镜像（MBR硬盘分区,GPT全局分区表,LVM逻辑卷）是否存在病毒,木马等恶意程序。

不管是那种取证方式都应尽量避免破坏犯罪现场，例如通过内存转储工具对内存进行快照，通过磁盘克隆工具对磁盘进行克隆，方便后期的分析工作。

## Volatility

> Volatility是一款开源的，基于Python开发的内存取证工具集，可以分析内存中的各种数据。Volatility支持对32位或64位Wnidows、Linux、Mac、Android操作系统的RAM数据进行提取与分析。

这里列出一些常用命令，以方便之后自己查看

```
1.  `volatility -f xxx imageinfo`
    
2.  `#使用imageinfo插件来猜测dump文件的profile值`
    
3.  `volatility -f xxx --profile=xxx pslist`
    
4.  `#指定profile值,使用pslist去列举系统进程`
    
5.  `volatility cmdscan -f xxx --profile=xxx`
    
6.  `#查看历史命令`
    
7.  `volatility iehistory -f xxx --profile=xxx`
    
8.  `#查看IE历史信息`
    
9.  `volatility -f mem.raw --profile=Win7SP0x86 screenshot --dump-dir=./`
    
10.  `#查看截图`
     
```

| 命令 || 功能 |
| --- | --- |
| cmdline/cmdscan || 列出历史cmd命令 |
| --- | --- |
| filescan || 扫描文件，可配合grep使用 |
| pslist/psscan || 列出进程列表 |
| svcscan || 扫描windows服务列表 |
| memdump || 从内存dump进程的内存 |
| dumpfiles || 从内存dump文件 |

官方命令

了解几个文件后缀

```
1.  `vmem文件`
    
2.  `#表示虚拟内存文件，与pagefile.sys相同`
    
3.  `raw文件`
    
4.  `#raw文件是内存取证工具Dumpit提取内存生成的内存转储文件`
    
```

除此之外，还需要了解一下 `profile（配置文件）`

> `profile`是特定操作系统版本以及硬件体系结构(x86,x64,ARM)中VTypes,共用体,对象类型的集合.除了这些组件以外,profile还包括:元数据:操作系统的名称,内核版本,以及编译号. 系统调用信息:索引以及系统调用的名称 常量值:全局变量-在某些操作系统中能够在硬编码的地址处找到的全局变量 系统映射:关键全局变量和函数的地址(仅限Linux和Mac)

每个profile都有个一个唯一的名称,通常是由操作系统的名称,版本,服务包,系统结构等信息组成.

```
1.  `如:Win7SP1x64是64位的Windows 7 SP1系统配置文件的名称`
    
```

#### 0x01:内存取证赛题

**描述：**

> 一天下午小白出去吃饭，临走之前还不忘锁了电脑，这时同寝室的小黑想搞点事情，懂点黑客和社工知识的小黑经过多次尝试获得了密码成功进入电脑，于是便悄悄在电脑上动起手脚了，便在桌面上写着什么，想给小白一个惊喜，同时还传送着小白的机密文件，正巧这时小白刚好回来，两人都吓了一跳，小黑也不管自己在电脑上留下的操作急忙离开电脑，故作淡定的说：“我就是随便看看”。

**问题：**

```
1.  `1.小黑写的啥，据说是flag？`
    
2.  `2.那么问题来了，小白的密码是啥？`
    
3.  `3.小黑发送的机密文件里面到底是什么？ `
    
```

先来看一下文件的profile值

```
1.  `volatility -f mem.raw imageinfo`
    
```

![](../Images/9bc1dbea567d76b4ffb2de58e7399a1e.png)然后第一个问题提示的是**小黑写的啥，据说是flag？**，所有先查看一下进程

```
1.  `volatility -f mem.raw --profile=WinXPSP2x86 pslist`
    
```

然后发现了 `notepad.exe`进程，利用下editbox插件显示下编辑控件的信息

```
1.  `volatility -f mem.raw  --profile=WinXPSP2x86 editbox`
    
```

![](../Images/1e3cf2152e5339a7a42f3cbd0317beaa.png)因为这个是windows xp的镜像，所以也可以用插件notepad![](../Images/129c98d20ef8ea290f7bbb43f8c0a44d.png)发现这一段有点不正常，感觉像是base16,解一下发现flag![](../Images/4ffd1eb76460eefc4df687be715c782a.png)接下来就看第二问题，**小白的密码是啥？**

这个问题涉及到了密码，他的系统是Windows，就先使用命令找一下注册表，主要是为了找到 `SAM、system`文件，得到其virtual 地址。

```
1.  `volatility -f mem.raw --profile=WinXPSP2x86 hivelist`
    
```

![](../Images/30a864e30b30c9613a2068ad972bfa7e.png)接下来获取内存中的系统密码，使用 `hashdump` 将它提取出来

```
1.  `volatility -f mem.raw  --profile=WinXPSP2x86 hashdump -y 0xe10182f8 -s 0xe1492b60`
    
```

![](../Images/90c4978f55e877350c753f71883487a6.png)

```
1.  `用户名:RID:LM-HASH值:NT-HASH值`
    
```

知道了NT-HASH的值，在线破解下![](../Images/bdd6ec89fa7b51d624cc341dcdf2ff5b.png)但没破解成功，除下在线的还可以使用

```
1.  `Saminside字典破解`
    
2.  `Ophcrack加载彩虹表破解`
    
```

这两个工具进行破解一下，这里就不在演示了，主要是为了学习取证分析。

最后看一下第三个问题，**发送的机密文件里面到底是什么？**

描述中说的是传送着小白的机密文件，而且进程中有 `nc.exe`、有 `cmd.exe`,应该是使用cmd命令行的nc进行文件的传输。![](../Images/a8f51dd8d28e3d9c2cd2a159d309ffad.png)既然有操作就肯定会留下痕迹，可以看一下历史命令

```
1.  `volatility cmdscan -f  mem.raw --profile=WinXPSP2x86`
    
```

![](../Images/1d0de8d5f72d0d6dc711a54048f427e8.png)传输了一个zip文件，既然知道这个进程中做了这样的操作，就先将 `nc.exe`进程给dump下来

```
1.  `volatility -f mem.raw --profile=WinXPSP2x86  memdump -p 120 --dump-dir=./`
    
```

然后再foremost一下，提取出来(binwalk提取出来会损坏文件)![](../Images/de8b85bbcad305e1833a238fb9428f29.png)需要输入密码，而密码根据提示也很明显了，就是第二问破解出来的密码![](../Images/2c5359455368c59cf0ed423adb2543d0.png)最终得到flag
