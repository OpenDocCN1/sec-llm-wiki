# 一、综合环境——低难度

tip：emmm，与之前重复的内容这里就不再提了，主要记录下思路。


其中login.php是个登录页面。没有信息，先查看源码(其实我先尝试了弱口令，但是没有成功，还是乖乖的看源码) 在源码的最后发现了javascript的代码

```
1.  `function control(){`
    
2.  `    var user = document.getElementById("user").value;`
    
3.  `    var pwd = document.getElementById("pwd").value;`
    
4.  
    
5.  `    var str=user.substring(user.lastIndexOf("@")+1,user.length);`
    
6.  
    
7.  `    if((pwd == "'")){`
    
8.  `        alert("Hack Denemesi !!!");`
    
9.  
    
10.  `    }`
     
11.  `    else if (str!="btrisk.com"){`
     
12.  `        alert("Yanlis Kullanici Bilgisi Denemektesiniz");`
     
13.  
     
14.  `    }   `
     
15.  `    else{`
     
16.  
     
17.  `      document.loginform.submit();`
     
18.  `    }`
     
19.  `}`
     
```

审计这段代码：substring和lastIndexOf都是截取字符串的两个函数，首先来了解一下这两个函数。 `substring()` ![](../Images/d971a5f14c0ab33faa362d057b39f461.png) 注意：如果start传入的参数比stop的参数大的话，该函数会自动调换start和stop的位置。参数 start 与 stop 相等，那么该方法返回的就是一个空串（即长度为 0 的字符串）。下面是一个栗子：

```
1.  `    string start = null;`
    
2.  `    string stop = null;`
    
3.  `    string str = "abcdefg";`
    
4.  `    start = str.Substring(0, 1);//从第一个开始截取，共截取一位`
    
5.  `    stop = str.Substring(str.Length - 1, 1);//从最后一个开始截取，共截取一位`
    
6.  `    Response.Write(qian + "***" + hou);`
    
```

输出结果： `a***g` `lastIndexOf()` 作用：可返回一个指定的字符串值最后出现的位置，在一个字符串中的指定位置从后向前搜索 ![](../Images/2a757f6c69a4b300db2f64c592306000.png) 注意： `lastIndexOf()` 方法对大小写敏感！如果要检索的字符串值没有出现，则该方法返回 -1。

```
1.  `string str = "m0re";`
    
2.  `str = str.Substring(0, str.LastIndexOf("r"));`
    
3.  `Response.Write(str);`
    
```

截取r前面的字符串，输出为 `m0` OK，这下再看代码就可以理解了。1、首先 `lastIndexOf()`先在user中查询 `@`的位置，然后从其位置的后一位开始，到user的总长度这个范围内，substring函数起作用，截取字符串str。2、继续，pwd不等于 `'`，猜测可能是防万能密码的吧。或者是绕过SQL注入。3、str要等于btrisk.com ![](../Images/1c445d2ee5439cec95038de940a757e1.png) 然后进来一个页面，闹了半天没发现什么，最后才知道是姿势错了。不过也没白折腾。有学到新知识。 正确的姿势： 对登录框进行fuzz测试，kali的wordlists下有字典，可以直接利用，抓包发送到 Intruder模块 ![](../Images/021d6b5f8e0e2f1343125890a3184481.png) 载入字典进行fuzz测试 直接测试成功，看到response页面有内容，去字典中找到这个payload进行登录。 ![](../Images/fab7edc176ecf68ff553de932d5d4c86.png) 用户名： `@btrisk.com`密码： `' or 1=1#`

![](../Images/63726a68a3668737f0e0d2a15a99457a.png) 这才是正确的界面。然后就是文件上传，基础漏洞。进行测试，只能传图片。 ![](../Images/b3e0b446979d76dc9b6198f5dec3cb4b.png) 鉴于不知道是验证方式是什么，所以都测试一遍。先设置好代理，测试发现是前端检测。使用burpsuite绕过前端检测，或者使用 `%00`截断绕过。只需要简单的修改后缀就可以了，其他的验证就没有了。尝试可以进行绕过，就制作一个反弹shell，然后监听获取权限就OK了。重复步骤。然后得到一个www-data用户的权限，尝试提权，发现 `sudo-l`返回的是

```
1.  `sudo: unable to resolve host BTRsys1`
    
2.  `sudo: no tty present and no askpass program specified`
    
```

没见过这样的，先放在一边。但是可以查看配置文件，之前扫描出来一个 `config.php`，但是访问没有任何信息，这里可以cat一下源码。

```
1.  `<?php`
    
2.  `/////////////////////////////////////////////////////////////////////////////////////////`
    
3.  `$con=mysqli_connect("localhost","root","toor","deneme");`
    
4.  `if (mysqli_connect_errno())`
    
5.  `  {`
    
6.  `  echo "Mysql Bağlantı hatası!: " . mysqli_connect_error();`
    
7.  `  }`
    
8.  `/////////////////////////////////////////////////////////////////////////////////////////`
    
9.  `?>`
    
```

数据库root用户的密码是 `toor` 连接数据库前，先优化一下终端，因为数据库输入密码时，是读取键盘记录的，而shell是无法完成的，所以还是先进行优化一下终端。然后进入数据库，进行遍历，查看到用户名密码，尝试提权 `su-root` 使用密码 `asd123***`

# 二、综合环境——较高难度

这个其他没什么可记录的，就一点——内核提权

```
1.  `searchsploit ubuntu 4.4.0`
    
```

![](../Images/3bc12b87f157a46cb7a03b525963d5fe.png) 复制到桌面进行编译，

```
1.  `root@kali:~/Desktop# gcc 41458.c -o rootshell`
    
2.  `root@kali:~/Desktop# ls`
    
3.  `41458.c  rootshell`
    
```

然后利用meterpreter的upload命令将rootshell上传并加权，进行chmod命令时，需要在反弹shell中执行， 赋予rootshell以777权限后执行文件就可以提权成功了。

```
1.  `./rootshell`
    
```
