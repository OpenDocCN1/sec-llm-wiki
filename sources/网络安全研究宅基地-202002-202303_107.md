# Struts2漏洞系列之【S2-015】ActionName 配置了通配符时导致的OGNL表达式执行

漏洞信息：https://cwiki.apache.org/confluence/display/WW/S2-015

> Struts2 允许基于通配符定义 `Action` 映射，当 `ActionName` 配置了通配符 `*` 并将其作为动态值用于 `<result>` 结果中时，那么之后就会对该值进行 `OGNL` 表达式解析。

例如:

```
1.  `<package name="S2-015" extends="struts-default">`
    
2.  `    <action name="*" class="com.demo.action.PageAction">`
    
3.  `        <result>/{1}.jsp</result>`
    
4.  `    </action>`
    
5.  `</package>`
    
```

由于 `name` 值的位置比较特殊，一些特殊的字符如 `/ " \` 都无法使用（转义也不行），所以在利用该点进行远程命令执行时一些带有路径的命令可能无法执行成功。

在 Struts 2.3.14.1 - Struts 2.3.14.2 的更新内容中，删除了 `SecurityMemberAccess` 类中的 `setAllowStaticMethodAccess` 方法，因此在 2.3.14.2 版本以后都不能直接通过 `#_memberAccess['allowStaticMethodAccess']=true` 来修改其值达到重获静态方法调用的能力。不过可以借助java反射机制去间接修改：`#context['xwork.MethodAccessor.denyMethodExecution']=false,#m=#_memberAccess.getClass().getDeclaredField('allowStaticMethodAccess'),#m.setAccessible(true),#m.set(#_memberAccess,true)`

### 漏洞分析  

S2-015 与 S2-012的执行流程基本是一样的，依然是从 `DefaultActionInvocation.executeResult` 方法开始跟进

![](../Images/178ede37507cb323e384cb7eebf33599.png)

![](../Images/8c849ea3be2c3e1618009448a7438e7b.png)

`this.createResult();` 会根据 `action` 返回值获取对应的 `result` 标签配置，然后传入 `this.objectFactory.buildResult`

![](../Images/978644d9f5f263eef18a3ba8a04cc2cc.png)

同样的会把 `result` 标签中的值 `/{1}.jsp` 设置给 `org.apache.struts2.dispatcher.ServletDispatcherResult` 类的 `location` 属性，`{1}` 代表Struts2.xml 中的第一个通配符，也就是我们输入的 `action` 名称，如果一个请求的 `action` 在映射中不存在，那么就会去匹配通配符，根据请求的 `action` 名来加载对应的jsp文件。在之前我们的payload就已经替换掉了 `{1}` 。

![](../Images/7988a99ecc6e900b54d429c1f68d65d3.png)

然后返回 `ServletDispatcherResult` 对象，并执行其父类 `StrutsResultSupport` 的 `execute` 方法。接着又执行到了 `this.conditionalParse` 方法中的 `TextParseUtil.translateVariables` 方法

![](../Images/704f06985aa4e927a7d97c8c560c582f.png)

最后与S2-012不同的是，这里虽然同样能进行两次for循环从而进行二次表达式解析，不过由于之前就已经把我们的payload替换掉了 `{1}` ，因此第一次表达式解析就会直接执行我们 `${}` 中的payload。

![](../Images/ec4597181ce951df4830439b3f2f87dd.png)

![](../Images/4eea952f0bdb5448848679c98b96bdc8.png)

### 漏洞修复

用正则 `allowedActionNames = "[a-z]*[A-Z]*[0-9]*[.\\-_!/]*";` 对 `ActionName` 做了限制。

![](../Images/20eaa14a6daeea7b2730b0b146bdd6fa.png)
