# 9 安全建设管理 9.9等级测评

测评机构依据国家网络安全等级保护制度规定，按照有关管理规范和技术规范，对未涉及国家秘密的等级保护对象安全等级保护状况进行检测评估的活动。等级测评属符合性评判活动，即依据网络安全等级保护的国家标准或行业标准，按照特定方法对等级保护对象的安全防护能力进行科学公正的综合性评判过程。  

  

| **9.9.1 应定期进行等级测评，发现不符合相应等级保护标准要求的及时整改** |
| --- |
| 对等级保护对象进行等级测评是检验系统是否达到相应等级保护要求的主要途径，也是发现系统安全隐患的重要途径。通过选择有资质的测评机构对系统进行定期的测评，有助于系统发现问题并进行及时整改。就目前来说，第三级等级保护对象应当每年至少进行一次等级测评。【测评方法】1）访谈等级测评负责人是否每年定期开展安全等级测评。2）核查等级测评报告和整改记录。【预期结果】1）定期开展测评工作，且非首次，以往进行过几次测评，并根据测评结果进行相应的安全整改。2）具有**以往等级测评报告和安全整改方案**。【权重】1  
 |

| **9.9.2 应在发生重大变更或级别发生变化时进行等级测评** |
| --- |
| 系统在发生重大的网络结构调整或大范围的设备更换、应用系统功能有较大变化等变更时，应重新进行等级测评，并评估系统级别是否发生变化，若变化，则需按照最新的安全保护等级要求进行测评。【测评方法】1）访谈测评系统是否发生过重大变更或升级。2）核查重大升级变更或改造的文件。【预期结果】1）有过重大变更或级别发生过变化，若有，及时开展了等级测评。2）具有相应情况下的等级测评报告。【权重】1  
 |

| **9.9.3 应确保测评机构的选择符合国家有关规定。** |
| --- |
| 目前国家对等级保护测评机构的管理遵从测评机构名录管理要求，即在国家网络安全等级保护工作协调小组办公室推荐测评机构名单内的测评机构均可选择。【测评方法】1）访谈测评负责人是否选择了具有测评资质的测评机构。2）核查该机构是否符合要求。【预期结果】等级测评的测评单位具有国家相关等级测评资质的单位【权重】1 |
