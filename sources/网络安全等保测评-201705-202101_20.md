# 9 安全建设管理 9.1定级和备案

确定等级保护对象的安全保护等级，是建设符合安全等级保护要求的等级保护对象、实施网络安全等级保护的基础。等级保护对象运营、使用单位或者其他主管部门应当在等级保护对象安全保护**等级确定后30日内**，**到公安机关办理备案手续**。  

  

| **9.1.1应以书面的形式说明保护对象的安全保护等级及确定等级的方法和理由。** |
| --- |
| 《等级保护对象安全等级保护定级报告》是全国各类等级保护对象定级报告的通用模板, 使用网安部门提供的模板编制定级报告。【测评方法】1）核查定级文档是否明确测评系统的安全保护等级。2）核查是否给出了定级的方法和理由。【预期结果】具有明确描述定级方法理由和最终定级结果的定级报告书。 【权重】0.7 |

  

| **9.1.2应组织相关部门和有关安全技术专家对定级结果的合理性和正确性进行论证和审定。**  
 |
| --- |
| 定级结果的准确性需要安全技术专家论证评审。若初步定级结果为第二级、第三级，可组织本行业和网络安全行业专家进行评审；若为四级，则需请国家网络安全等级保护专家评审委员会专家进行评审。【测评方法】1）核查是否对测评系统组织相关部门或相关专家对定级结果进行了论证和审定。2）核查是否有定级结果的评审和论证记录文件。对第三级等级保护对象，其安全保护等级包括五种情况：![](../Images/e744c7551dfea6d9f3af7b4a15bb70e0.png)【预期结果】  
具有相关专家对定级结果论证意见。【权重】1  
  
 |

| **9.1.3应保证定级结果经过相关部门的批准。**  
 |
| --- |
| 定级结果需由上级部门或本单位相关部门的批准。【测评方法】1）核查是否获得了相关主管部门的批准。2）核查是否有定级结果的审批文件。【预期结果或主要证据】具有主管部门审批意见或本单位相关部门的审批意见。【权重】1  
  
 |

  

| **9.1.4 应将备案材料报主管部门和相应公安机关备案。** |
| --- |
| 有主管部门的，备案材料需向主管部门和公安机关备案；没有主管部门的，备案材料需向相应公安机关备案。【测评方法】1）核查是否向主管部门备案。2）核查是否有备案证明证书。【预期结果或主要证据】具有主管部门和公安机关的备案证明。【权重】1 |
