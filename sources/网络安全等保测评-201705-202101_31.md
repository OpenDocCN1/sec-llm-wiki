# 8 安全管理人员 8.2人员离岗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484012&idx=2&sn=0bb8f5f4dc234932b7adade2f3368fa8&chksm=eacc9532ddbb1c243d00fd49177206eb85d044780b50427612134fc26277f2d934c0e0e754c9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484012&idx=2&sn=0bb8f5f4dc234932b7adade2f3368fa8&chksm=eacc9532ddbb1c243d00fd49177206eb85d044780b50427612134fc26277f2d934c0e0e754c9&scene=27#wechat_redirect)

对离岗或调离人员，特别是因不适合安全管理要求被离岗的人员，必须严格办理离岗手续，进行离岗谈话，重申其调离后的保密义务，交回所有钥匙及证件，退还全部技术手册、软件及有关资料，更换系统口令和机要锁等。

| **8.2.1 应及时终止离岗人员的所有访问权限，取回各种身份证、钥匙、徽章等以及机构提供的软硬件设备。** |
| --- |
| 解雇、退休、辞职、合同到期或其他原因离开单位或离岗的人员在离开前都必须到相应管理部门办理严格的调离手续，包括交回其拥有的相关证件、徽章、密钥、访问控制标识、单位配给的设备等。  
【测评方法】

*   访谈人事负责人，询问是否及时终止离岗人员的所有访问权限，取回各种身份证件、钥匙、徽章等以及机构提供的软硬件设备。
    
*   核查人员离岗记录文档，是否具有离岗人员终止其访问权限、交还身份证件、软硬件设备等的登记记录。
    

  
【预期结果或主要证据】具有离岗人员交还各类资产的登记记录。  
【权重】0.7 |

  

| **8.2.2 应办理严格的调离手续，并承诺调离后的保密义务后方可离开。** |
| --- |
| 调离后的保密承诺可单独签署，或者在保密协议中有相关条款明确说明。  
【测评方法】

*   核查人员离岗的管理文档是否规定了人员调离手续和离岗要求等。
    
*   核查是否具有按照离岗程序办理调离手续的记录。
    
*   核查保密承诺文档是否有调离人员的签字。
    

  
【预期结果或主要证据】

*   具有相关规范人员调离手续要求的管理文档。
    
*   具有相关人员调离手续的记录。
    
*   具有调离人员签字的保密承诺文档。
    

  
【权重】1 |
