# Word中页码设置-第几页共几页1

相信大家在编制文档中经常需要对文档添加页码，本人常用的格式如上图所示，实战过几次都是问度娘，也确实解决了问题，但好久不用还是会忘记。正所谓好记性不如烂笔头，所以记录下来方便查找，也很乐意分享给有需要的朋友。大家在使用过程中有问题欢迎留言哈。  

  

在word页脚处双击进入编辑状态，输入“第页 共页”

1.  鼠标放置于“第页”之间，Alt-Q 进入word工具栏操作说明搜索，输入“插入域”，进行搜索，选择域，或者直接使用Alt-E
    
    ![](../Images/ccd9678b17dbf71e7937250239d1c7a0.png)
    
2.  在打开的域对话框中：
    
    “域名"选择“Page”，
    
    “格式”选择“1，2，3”，
    
    点击“确定”按钮
    
    这样当前页就设置好了。
    
    ![](../Images/69f97ab44b0062e96d31a1d7fc384178.png)
    
    ![](../Images/8ff8174808e29a2e22cf072c81d64ad2.png)
    
3.  将鼠标放置于“共页”之间，打开“域”对话框 （见步骤2）
    
    “类别”下拉框中选择“文档信息”
    
    ”域名“选择”NumPages“
    
    “格式”选择“1，2，3”
    
    点击“确认”
    

![](../Images/4ed469bceeb6acdf601b5886844f17a3.png)

  

![](../Images/908b3317a55a138b0bc6838a54294548.png)

5.如果对文档进行了分节操作，比如从目录之后的正文开始计为第一页，就会出现总页码超出页码的问题。出现这种问题，将鼠标放置于总页码上，右键选择“”切换域代码“，出现以下公式:

**     {NUMPAGES \\\*Arabic\\\*MERGEFORMAT}**

  

6\. 删除大括号中除NUMPAGES之外的所有字符，即保留以下字符，并保持光标在大括号内：

    **{NUMPAGES}**

  

7.然后按Ctrl+F9插入空域,就会多出一组大括号：

**     { ****{****NUMPAGES****}**** }**

8\. 在大括号前面加上一个等号，在后面加上减号和封面及目录的页数。比如正文之前一共有5页，公式如下：

**   {****\=****{NUMPAGES}**** -5****}**

  

9\. 鼠标右键”切换域代码“，公式会变成数字，如：  

   {=10-5}

  

10\. 鼠标右键”切换域代码“就会显示计算结果了。
