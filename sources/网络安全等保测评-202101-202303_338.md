# 13.4 物联网 感知节点设备安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484685&idx=5&sn=9aacefc51102e85a77171b0287d4d659&chksm=eacc9253ddbb1b453e654f2619d651a9297289df707767c70a2fdfea7ce67086afdca8b6151e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484685&idx=5&sn=9aacefc51102e85a77171b0287d4d659&chksm=eacc9253ddbb1b453e654f2619d651a9297289df707767c70a2fdfea7ce67086afdca8b6151e&scene=27#wechat_redirect)

感知节点设备安全是保证只有授权的用户可以对感知节点设备上的软件应用进行配置或变更，以及对其连接的网关节点设备（包括读卡器）和其他感知节点设备（包括路由节点）进行身份标识和鉴别。尽量降低或避免非授权用户对设备上的软件应用进行配置或变更，防止监测数据泄露或设备被非法关闭。

| **【安全要求】****应保证只有授权的用户可以对感知节点设备上的软件应用进行配置或变更。** |
| --- |
| 【要求解读】感知节点设备数量巨大，往往在线批量进行软件应用配置或变更，如果没有采取了一定的技术手段防止非授权用户对设备上的软件应用进行配置或变更，容易导致感知节点监测数据泄露或设备被非法关闭。【测评方法】1）核查感知节点设备是否采取了一定的技术手段防止非授权用户对设备上的软件应用进行配置或变更；2）通过试图接入和控制传感网访问未授权的资源，测试验证感知节点设备的访问控制措施对非法访问和非法使用感知节点设备资源的行为控制是否有效。【预期结果或主要证据】1）感知节点设备采取了一定的技术手段防止非授权用户对设备上的软件应用进行配置或变更。例如，给感知节点设备配置安全性强的用户名和登录密码。2）感知节点设备的访问控制措施对非法访问和非法使用感知节点设备资源的行为控制有效。 |

  

  

| **【安全要求】****应具有对其连接的网关节点设备（包括读卡器）进行身份标识和鉴别的能力。** |
| --- |
| 【要求解读】很多物联网感知节点是处在无人值守的位置，就给了攻击者可趁之机，便于从无人值守的设备中获得用户身份等的隐私信息，并以此设备对通信网络进行一些攻击，因此需要具有对其连接的网关节点设备（包括读卡器）进行身份标识和鉴别的能力。【测评方法】1）核查是否对连接的网关节点设备（包括读卡器）进行身份标识与鉴别，是否配置了符合安全策略的参数；2）测试验证是否不存在绕过身份标识与鉴别功能的方法。【预期结果或主要证据】1）连接的网关节点设备（包括读卡器）进行身份标识与鉴别，配置了符合安全策略的参数。2）不存在绕过身份标识与鉴别功能的方法。 |

  

  

| 【安全要求】应具有对其连接的其他感知节点设备（包括路由节点）进行身份标识和鉴别的能力。 |
| --- |
| 【要求解读】攻击者通过假冒网络中已有的感知节点或网关节点，可以监听传感网络中传输的信息，向传感网络中发布假的路由信息或传送假的数据信息、进行拒绝服务攻击等。需要具有对其连接的其他感知节点设备（包括路由节点）进行身份标识和鉴别的能力。【测评方法】1）核查是否对连接的其他感知节点设备（包括路由节点）设备进行身份标识与鉴别，是否配置了符合安全策略的参数；2）测试验证是否不存在绕过身份标识与鉴别功能的方法。【预期结果或主要证据】1）对连接的其他感知节点设备（包括路由节点）设备进行身份标识与鉴别，配置了符合安全策略的参数；2）不存在绕过身份标识与鉴别功能的方法。 |
