# 13.9 物联网 第四级增加或增强要求

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484683&idx=4&sn=d98d814d5924c5f245e7b9227597b880&chksm=eacc9255ddbb1b4332596b99345ecde3dd552e5024c4b776350ddc8f3461bedeb88a7b67d789&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484683&idx=4&sn=d98d814d5924c5f245e7b9227597b880&chksm=eacc9255ddbb1b4332596b99345ecde3dd552e5024c4b776350ddc8f3461bedeb88a7b67d789&scene=27#wechat_redirect)

| **【安全要求】****应对不同数据之间的依赖关系和制约关系等进行智能处理，如一类数据达到某个门限时可以影响对另一类数据采集终端的管理指令。** |
| --- |
| 【要求解读】可控性是物联网最为特殊的地方，要采取措施来保证物联网不会因为错误而带来控制方面的灾难，包括控制判断的冗余性、控制命令传输渠道的可生存性、控制结果的风险评估能力等。需要对不同数据之间的依赖关系和制约关系等进行智能处理，如一类数据达到某个门限时可以影响对另一类数据采集终端的管理指令。【测评方法】核查是否能够智能处理不同数据之间的依赖关系和制约关系。【预期结果或主要证据】物联网设备、服务或者系统对对信息和数据的及时性、安全和隐私保护等方面有特定要求的应用场景（如健康服务、监测系统和紧急服务等），能够从感知终端、存储的历史背景信息或设定的输入等获取到不同数据之间的依赖关系和制约关系等，并根据这些关系进行智能处理，如一类数据达到某个门限时可以影响对另一类数据采集终端的管理指令。
