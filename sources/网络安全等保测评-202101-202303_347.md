# 12.9 移动互联 配置管理

为防止非授权无线设备的接入，加强无线设备安全运维管理，需要建立无线设备配置库来识别非授权设备，保证无线设备运维过程中的安全。

| **【安全要求】****应建立合法无线接入设备和合法移动终端配置库，用于对非法无线接入设备和非法移动终端的识别。** |
| --- |
| 【要求解读】为保证无线接入设备和移动终端的安全接入，要求对无线接入设备和移动终端的设备情况进行登记和记录，形成合法设备配置库，当设备接入无线网络时进行比对，如不在配置库内则认为非法设备，不允许接入。【测评方法】应核查是否建立无线接入设备和合法移动终端配置库，并通过配置库识别非法设备。【预期结果或主要证据】1）建立无线接入设备和合法移动终端配置库，并可以进行比对识别；2）无线接入设备和合法移动终端配置库信息。 |
