# 12.8 移动互联 移动应用软件开发

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484652&idx=8&sn=ec16c62a73e08284a8c193f19c63753b&chksm=eacc93b2ddbb1aa40139576c6d8e5a46b72dfc18ca482feff339eb89343f952ba91866188a72&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484652&idx=8&sn=ec16c62a73e08284a8c193f19c63753b&chksm=eacc93b2ddbb1aa40139576c6d8e5a46b72dfc18ca482feff339eb89343f952ba91866188a72&scene=27#wechat_redirect)

为防止移动应用软件开发中带来的安全风险，需要对开发者的资格及签名证书的合法性等方面提出要求，保证移动应用软件开发的安全。

| **【安全要求】****应对移动业务应用软件开发者进行资格审查。** |
| --- |
| 【要求解读】为保证移动业务应用软件的安全性，要求对开发者进行基本的资格审查。比如：工作简历、技术能力、资格证书、项目实施情况等。【测评方法】应访谈系统建设负责人，是否对开发者进行资格审查。【预期结果或主要证据】1）移动应用开发者的资格符合要求；2）移动应用开发者资格审查记录或相关资质材料。 |

  

| **【安全要求】****应保证开发移动业务应用软件的签名证书合法性；** |
| --- |
| 【要求解读】为保证移动业务应用软件所采用的证书的合法性，要求采用国家移动业务应用软件的签名证书是否具有合法性。【测评方法】应核查开发移动业务应用软件的签名证书是否具有合法性。【预期结果或主要证据】1）移动业务应用软件的签名证书具有合法性；2）签名证书的签发机构。 |
