# 12.7 移动互联 移动应用软件采购

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484652&idx=7&sn=cb8dd19d446b51bba3280604664c76a6&chksm=eacc93b2ddbb1aa4374503e045ec8c66afb0b1c2b2c0b6bc78a63c1eef1920f04bc9958add33&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484652&idx=7&sn=cb8dd19d446b51bba3280604664c76a6&chksm=eacc93b2ddbb1aa4374503e045ec8c66afb0b1c2b2c0b6bc78a63c1eef1920f04bc9958add33&scene=27#wechat_redirect)

  

为防止移动应用软件采购、下载及使用中的安全风险，需要对移动应用软件采购中的软件来源和开发者进行要求，保证移动应用软件采购环节中的安全。

| **【安全要求】****应保证移动终端安装、运行的应用软件来自可靠分发渠道或使用可靠证书签名。** |
| --- |
| 【要求解读】要求移动终端安装、运行的应用软件应采用证书进行签名，保证应用软件的完整性，或者要求使用可靠的移动应用软件的分发渠道，降低移动应用软件安装带来的风险。【测评方法】应核查移动应用软件是否来自可靠分发渠道或使用可靠证书签名。【预期结果或主要证据】1）移动应用软件下载使用来自于官网或内部应用商店等可靠渠道；2）移动应用软件下载渠道；3）移动应用软件采用的签名证书。 |

  

| **【安全要求】****应保证移动终端安装、运行的应用软件由指定的开发者开发。** |
| --- |
| 【要求解读】为保证移动终端安装的移动应用软件的安全性，要求安装使用的移动应用软件需要由指定的开发者开发。比如：移动终端安装、运行的移动终端管理软件应明确开发单位/开发者等。【测评方法】应核查移动应用软件是否由指定的开发者开发。【预期结果或主要证据】1）移动应用软件由指定的开发者开发；2）移动应用软件开发者单位及开发者的相关信息。
