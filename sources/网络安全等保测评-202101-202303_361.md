# 11 云计算安全扩展要求 11.6安全管理中心

安全管理中心针对云计算环境提出了安全管理方面的技术控制扩展要求，通过技术手段实现云平合集中管理；涉及的安全控制点包括集中管控。本章将以三级等级保护对象为例，描述安全管理中心各个控制要求项的测评内容、方法、证据和案例等。11.6.1集中管控在企业的网络安全建设过程中，为了建设相对全面的防御体系，势必涉及到多种不同类型、不同长商的安全设备的部署。为解决不同厂商配置方法上的差异，实现多类型安全设备的统一日志管理和事件关联分析，云安全集中管控平台从资源管理、配置、监控、分析响应及部署全周期的一安全管理功能，最终为用户提供资源平台化、数据集中化的统一云安全管理。

| **【安全要求】  
****应能对物理资源和虚拟资源按照策略做统一管理调度与分配；** |
| --- |
| 【要求解读】云计算通过对物理资源的整合与再分配，提高了资源的利用率，一台物理机的资源可能被多个虚拟机所共享。对物理资源、虚拟资源的统一分配与调度，能够提高资源利用率。【测评方法】1）核查是否部署了资源调度平台或其他平台对物理资源、虚拟资源进行统一分配与调度；2）核查资源管理平台是否能够实现物理资源、虚拟资源统一分配与调度的。【预期结果或主要证据】提供资产管理系统的截图，提供物理资源、虚拟资源水位管理的系统的截图。 |

| **【安全要求】  
****应保证云计算平台管理流量与云服务客户业务流量分离；** |
| --- |
| 【要求解读】通过带外管理或策略配置的方式将网管流量和业务流量分开，为网管流量建立专属的通道，在这个通道中，只传输管理流量，管理流量与业务流量分离，可以提高网管的效率与可靠性，有利于提升管理流量的安全性。【测评方法】1）检查网络架构和配置策略核查云平台管理流量是香采用带外管理或策略配置等方式；2）核查并测云平台管理流量与云服务客户业务流量是否分离。【预期结果或要证据】云平台管理流量通过带处管理，云服务客户业务流量通过上层网络；管理流量网络层使用的是经典网络心和业务网络默隔离，云平台管理流量与业务流量完全分离。 |

| **【安全要求】  
****应根据云服务商和云服务客户的职责划分，收集各自控制部分的审计数据并实现各自的集中审计；** |
| --- |
| 【要求解读】在云运维方面，为缓解云服务商和云服务客户间的不信任，云服务商和云服务客户应进行明确的职责划分，各自收集各自部分的审计数据，并对审计数据进行集中审计，实现云计算平台全面的信息审计，实现云计算环境下合规性、业务连续性、数据安全性等方面的审计要求，有效控制审计数据在云中面临的风险。【测评方法】1）核查云服务商和云服务客户间是否进行职责划分；2）检查云平台是否支持云服务商和云服务客户收集各自的审计数据；3）检查云服务商和云服务客户是否部署集中审计平台支持各自收集审计数据的集中审计。【预期结果或主要证据】1）云平台运维侧及租户侧分别部署了不同的审计产品：云平台运维侧的日志，全部传给云盾（安全审计）；2）租户侧部署了租户的审计产品，负责采集租户侧的审计日志，并完成审计功能。 |

| **【安全要求】  
****应根据云服务商和云服务客户的职责划分，实现各自控制部分，包括虚拟化网络、虚拟机、虚拟化安全设备等的运行状况的集中监测。** |
| --- |
| 【要求解读】为便于云服务商和云服务客户能够及时掌控系统运行情况，云服务商和云服务客户的职责应明确划分，对各自控制部分的虚拟资源（虚拟化网络、虚拟机、虚拟化安全设备等）运行状况进行集中监测。【测评方法】1）核查云服务商和云服务客户间是否进行职责划分；2）检查云平台是否支持云服务商和云服务客户集中监测各自控制部分虚拟资源（虚拟化网络、虚拟机、虚拟化安全设备等）的运行状况。【预期结果或主要证据】1）云监控中心提供了资源实时监控、告警和通知服务，可以监控云服务器ECS、负载均衡SLB、云数据库RDS和对象存储OSS相关指标；2）云管平台能够对虚拟资源运行状况进行集中监测。 |
