# 1 安全物理环境 1.10电磁防护

为防止电磁辐射和干扰产生的损害，需要采取电源线和通信线缆隔离铺设、安装电磁屏蔽装置等有效措施，保证机房内设备、存储介质和线缆的安全。

| **【安全要求】****电源线和通信线缆应隔离铺设，避免互相干扰。** |
| --- |
| 【要求解读】机房内电源线和通信线缆需要隔离铺设在不同的管道或桥架内，防止电磁辐射和干扰对设备运转和系统运行产生的影响。【测评方法】核查机房内电源线缆和通信线缆是否隔离铺设。【预期结果或主要证据】机房内电源线缆和通信线缆隔离铺设，如通过线槽或桥架进行了隔离。 |

| **【安全要求】****应对关键设备实施电磁屏蔽。** |
| --- |
| 【要求解读】因自管级确。机房内关键设备需要安放在电磁屏蔽机柜内或电磁屏蔽区域内，防止电磁辐射和干扰对设备运转和系统运行产生的影响。【测评方法】核查机房内是否为关键设备配备电磁屏蔽装置。【预期结果或主要证据】为关键设备采取了电磁屏蔽措施，如配备了屏蔽机柜或屏蔽机房，关键设备如加密机。 |
