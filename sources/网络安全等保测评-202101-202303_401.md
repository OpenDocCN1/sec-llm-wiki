# 1 安全物理环境 1.4防雷击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484551&idx=4&sn=37f62f7941087362f98b44faef060374&chksm=eacc93d9ddbb1acfd6d88a671b263080b81f9d10e86514a7ca0f3668cab00905f936d148bc35&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484551&idx=4&sn=37f62f7941087362f98b44faef060374&chksm=eacc93d9ddbb1acfd6d88a671b263080b81f9d10e86514a7ca0f3668cab00905f936d148bc35&scene=27#wechat_redirect)

为防止雷击产生的损害，需要对机房所在建筑物及机房内设施和设备采取接地、安装防雷装置等有效措施，保证机房内设备、存储介质和线缆的安全。

| **【安全要求】****应将各类机柜、设施和设备等通过接地系统安全接地。** |
| --- |
| 【要求解读】在机房内对机柜、各类设施和设备采取接地措施，防止雷击对电子设备产生损害。【测评方法】核查机房内机柜、设施和设备等是否进行接地处理，通常黄绿色相间的电线为接地用线。【预期结果或主要证据】机房内所有机柜、设施和设备等均已采取了接地的控制措施。 |

  

| **【安全要求】应采取措施防止感应雷，例如设置防雷保安器或过压保护装置等** |
| --- |
| 【要求解读】  
在机房内安装防雷保安器或过压保护等装置，防止感应雷对电子设备产生损害。【测评方法】1）核查机房内是否设置防感应雷措施。2）核查防雷装置是否通过验收或国家有关部门的技术检测。【预期结果或主要证据】1）机房内设置了防感应雷措施，如设置了雷感应器、防浪涌插座等。2）防雷装置通过了国家有关部门的技术检测 |
