# 1 安全物理环境 1.6防水和防潮

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484551&idx=6&sn=175ddd232cd1ce64f964f3ec4b0a230e&chksm=eacc93d9ddbb1acf4de936bd7720f46693f9ccbb8026559a1bdc1bdc893d3675a238ffd86ead&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484551&idx=6&sn=175ddd232cd1ce64f964f3ec4b0a230e&chksm=eacc93d9ddbb1acf4de936bd7720f46693f9ccbb8026559a1bdc1bdc893d3675a238ffd86ead&scene=27#wechat_redirect)

为防止渗水、漏水、水蒸气结露等产生的损害，需要对机房采取防渗漏、防积水、安装水敏感检测报警系统等有效措施，保证机房内设备、存储介质和线缆的安全。

| **【安全要求】****应采取措施防止雨水通过机房窗户、屋顶和墙壁渗透。** |
| --- |
| 【要求解读】机房内需要采取防渗漏措施，防止窗户、屋顶和墙壁存在水渗透情况。【测评方法】核查窗户、屋顶和墙壁是否采取了防渗漏的措施。【预期结果或主要证据】机房采取了防雨水渗透的措施，如封锁了窗户并采取了防水、屋顶和墙壁均采取了防雨水渗透的措施。  
 |

| **【安全要求】****应采取措施防止机房内水蒸气结露和地下积水的转移与渗透。** |
| --- |
| 【要求解读】机房内需要采取结露和排水措施，防止水蒸气结露和地面产生积水。【测评方法】1）核查是否采取了防止水蒸气结露的措施。2）核查是否采取了排水措施，防止地面产生积水。【预期结果或主要证据】1）机房内配备了专用的精密空调来防止水蒸气结露的控制措施。2）机房内部署了漏水检测装置，可以对漏水进行监控报警。 |

| **【安全要求】****应安装对水敏感的检测仪表或元件，对机房进行防水检测和报警。** |
| --- |
| 【要求解读】机房内需要布设对水敏感的检测装置，对渗水、漏水情况进行检测和报警。【测评方法】1）核查是否安装了对水敏感的检测装置。2）核查防水检测和报警装置是否开启并正常运行。【预期结果或主要证据】1）机房内部署了漏水检测装置，如漏水检测绳等。2）检测和报警工作正常 |
