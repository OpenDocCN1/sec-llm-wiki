# 1 安全物理环境 1.7防静电

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3MDY0Nzg1Nw==&mid=2247484551&idx=7&sn=d0ffb051f476625d647f62507ad91b3c&chksm=eacc93d9ddbb1acfc5d028283396d242833d53dcdef154c7acfe3a507a0323cbb5893cb2fb56&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI3MDY0Nzg1Nw==&mid=2247484551&idx=7&sn=d0ffb051f476625d647f62507ad91b3c&chksm=eacc93d9ddbb1acfc5d028283396d242833d53dcdef154c7acfe3a507a0323cbb5893cb2fb56&scene=27#wechat_redirect)

为防止静电产生的损害，需要对机房采取安装防静电地板、配置防静电装置等有效措施，保证机房内设备、存储介质和线缆的安全。

| **【安全要求】****应采用防静电地板或地面并采用必要的接地防静电措施。** |
| --- |
| 【要求解读】机房内需要安装防静电地板或在地面采取必要的接地措施，防止静电的产生。【测评方法】1）核查是否安装了防静电地板。2）核查是否采用了防静电接地措施。【预期结果或主要证据】1）机房部署了防静电地板。2）机房采用了接地的防静电措施 |

  

| **【安全要求】****应采取措施防止静电的产生，例如采用静电消除器、佩戴防静电手环等。** |
| --- |
| 【要求解读】机房内需要配备静电消除器、佩戴防静电环等消除静电的设备。【测评方法】核查机房内是否配备了静电消除设备。【预期结果或主要证据】机房配备了防静电设备。 |
