## 一. 购买轻量应用服务器

轻量应用服务器（Light server）是一种内置应用型镜像或系统型镜像的小规格云服务器， 绑定适配大小的磁盘和带宽，为中小型企业和个人用户提供官网搭建、web应用搭建、云上学习和测试等场景的服务。

PS：大家可以关注服务器活动，在服务器活动期间购买特别便宜，腾讯云，阿里云，华为云等等云厂商购买方式和活动价格都差不多，大家根据自己的喜好进行购买即可。

此教程基于百度轻量应用服务器，百度的目前有一个好处是，他还没有安全组这个概念，也就是说所有的端口都是默认打开的，需要用到新端口的时候，不需要每次都到官网的控制台打开端口。

以百度为例，轻量应用服务器购买界面,点击立即购买即可

![](../Images/a7117c9dc515ea8a5d12a72c317cd5eb.png)

注意：为了保证后面顺利进行，大家在选择镜像的时候选择：centos7.6

### （1）登陆服务器

![](../Images/98e03d00619d8d4f0f55ce7d415b237d.png)

购买成功后，使用远程工具xshell登陆服务器

登陆的用户名是：root

![](../Images/a264009eb78c783f4b7bd7204c683a56.png)

## 二.安装宝塔面板

### （1）为什么要安装宝塔面板

很多网站程序都安装在服务器上，服务器用的是Linux系统，进行服务器维护需要记住很多linux的命令，这就很麻烦。

用面板的好处，就是通过一个交互界面就能完成服务器的维护工作，比如更新系统，添加网站，修改设置等等，以前需要记住各种命令，现在通过面板点点按钮就可以了，省时省力。

### （2）安装宝塔面板

进入宝塔面板的官网https://www.bt.cn/new/download.html，就会看到很多安装方式，我这里选择脚本安装

![](../Images/e312e9126fe106c855b750d69f599bc7.png)

本次教程系统使用的centos7,所以直接在xshell中输入 centos脚本的安装命令

```


yum install -y wget &amp;&amp; wget -O install.sh http://download.bt.cn/install/install_6.0.sh &amp;&amp; sh install.sh ed8484bec
```

宝塔面板安装成功

![](../Images/a264009eb78c783f4b7bd7204c683a56.png)

注意：记住自己的用户名和密码，复制面板的登陆外网登陆地址到浏览器即可进入宝塔

![](../Images/e05e2b16dc87bf48df2893518b6c0ce9.png)

宝塔面板登陆不成功

PS:百度轻量云服务器目前暂时没有安全组这个操作，默认所有端口都是开着的，不需要操作这一步.

以腾讯云为例：

如果你使用的是腾讯，阿里或者华为的轻量云服务器可能访问不成功，这时候你就需要登陆控制台去安全组把端口放开，这样才能打开宝塔面板。

其他一些端口也可提前放开

*   8888 宝塔默认面板端口
*   888 phpmyadmin端口
*   80 http（要想使用HTTP正常访问，则需放行80端口）
*   443 https（要想使用HTTPS正常访问，则需放行443端口）
*   21 ftp
*   20 ftp-data
*   39000 40000 ftp被动端口
*   3306 myql数据库端口
*   下面以在阿里云上开放8888端口为例：

### （3）安装LNMP网站环境

宝塔面板登陆成功后，会弹出推荐安装套件的窗口，点击一键安装即可。

![](../Images/44a1a86c2fb729e2e54d4a57cea8fcfb.png)

注意：如果你使用的是腾讯，阿里或者华为的轻量云服务器,在安装完成后点击安全 ，确保端口在安全组放开。

![](../Images/4fb1458c790da896820ce22efdd43ac6.png)

### （4）添加站点

打开宝塔面板点击网站网站，添加站点; 由于域名需要购买以及备案，我们暂且只演示用IP访问的方式。在域名中输入：test.xyz(这个可以随便输入，符合域名规则即可) 根目录保持默认

数据库选择MySQL 数据库账号和密码选择默认，也可自己创建。

![](../Images/60f217ee54962126a34a3b620476d3b1.png)

### （5）设置IP＋端口号访问

回到面板，选择左侧的网站，找到刚才创建的网站，点击右侧的设置

![](../Images/ceeec603aa5a52201c4741eb51bf0d3a.png)

在域名管理这里，添加地址,格式为：ip + 端口

这里的ip地址是你的云服务器公网ip地址，端口号自己随便写，不要与常见端口号重复（注意中间用应为的冒号隔开）,一般为80端口

![](../Images/45bd986a8b6abed23f6dfc17adb2e970.png)

这样，就可以用ip地址+端口号的方式在浏览器访问你的网站了。

## 三.安装Wordpress

WordPress是一个以PHP和MySQL为平台的自由开源的博客软件和内容管理系统。

WordPress具有插件架构和模板系统。Alexa排行前100万的网站中有超过16.7%的网站使用WordPress。到了2011年8月，约22%的新网站采用了WordPress。WordPress是目前因特网上最流行的博客系统。

它创建于2003年，并拥有超过20,000个插件来定制其功能。

### （1）下载Wordpress

访问https://cn.wordpress.org/download/,下载wordpress最新版

![](../Images/787cd0a2a0f1bd5ff07bace6280ea95a.png)

### （2）上传Wordpress

首先，将根目录下的文件全部删除

![](../Images/8114f1c24d9f9258b32b84549a426a20.png)

将下载完成后的Wordpress，通过宝塔面板或者xshell上传到域名的根目录下。

![](../Images/450dd9ec3033d2e94368a535aaa5f9b1.png)

### （3）解压Wordpress，并将其里面的内容移到域名的根目录下

![](../Images/7e30e1df32e0455cb6c355cf620a3369.png)

至此已经完成WordPress的基本安装，接下来在浏览器中输入服务器公网IP+端口号即可进入到WordPress的配置中心

## 四.配置WordPress

浏览器中输入服务器公网IP+端口号，即可出现下列画面，点击现在就开始

![](../Images/8e6a1bad35dbe0e57aa775a4b3c10199.png)

点击宝塔面板的数据库，将刚才创建站点生成的数据库名，用户名，密码填入，并点击提交

![](../Images/ced5e1964fbc30f75d86d3e71a76ccd0.png)

出现下图，点击运行安装程序

![](../Images/31bd1440e23a97efbf1a21fa90e13dc8.png)

设置站点名称，用户名，密码等信息

这些后面可以更改

![](../Images/0f020311300848fe6fd2d89edd77392c.png)
