学习数据库的时候，经常接触到 navicat 这个管理数据库的工具。下面介绍这个数据库管理工具的使用。

> 如果需要下载工具,可以在文章末尾获取云盘下载口令

### 一、 连接使用

#### 1.1 连接数据库

打开 navicat ，点击 连接 ，选择 数据库

![](../Images/13b31e2ea08fe94b878f1f1a7cff045b.png)

弹出以下界面 （以MySQL为例），熟悉各部分的作用![](../Images/94eb8cf0a8cc3dcdd5d0f5711aa81f8b.png)测试是否可以连接，有以下提示，点击确定开始使用数据库

![](../Images/7922ee0073c3043d84eda5465b008f01.png)双击 或 右键 打开连接，图标变亮表示已经打开连接

![](../Images/806265cba90b2f3dfbf92d1d3631b29c.png)

#### 1.2 操作数据库

右键 连接 ，点击 新建数据库

![](../Images/a36fab535b29cacb63071acd66c2cedd.png)

输入 数据库名 和 编码规则

![](../Images/ae12c87ef8965f72528cc8eb3d53e78a.png)

双击 或 右键 打开数据库（灰色图标变亮表示打开）

![](../Images/e71fe71ff39226840da6c88ecd036737.png)

### 二、 导入备份

打开 数据库 ，右键选择 运行SQL文件 ，备份数据库文件

![](../Images/7f894487a6a2bdd3bbf6723c5f022ddb.png)

选择文件导入

![](../Images/29fd26a15a7f0ecd9ac1bd578cfa3a2d.png)

导入成功如下

![](../Images/0e7be80a8d44997a6ea6d95529bf6830.png)

关闭数据库 ， 重新打开该数据库 ，可以看到刚刚导入的表 （对比上图，表那一项本来是空的，左边没有箭头）

![](../Images/3baf204262f4b01289050eb5c9d47f97.png)

### 三、 查询数据

查询方式：

1.  直接 鼠标点击 相应的表查询数据。1. 用 sql语句 查询。双击或右键打开 表 ，可以查看数据

![](../Images/dc1a0f957c352ff0de8e6f2568a3a8d0.png)

（以下是演示用sql语句查询）

点击 ① 或者 ② ，再点击 新建查询![](../Images/875541121d5a73a1a93741dc87d13ab9.png)

输入 sql语句

![](../Images/966d74a7e956710f572a8313d3650499.png)MySQL语句请查看另一篇文章：MySQL常用的语句

### 四、 修改用户信息

登录 mysql ，选择需要修改用户信息的 数据库

![](../Images/063e887ab2ebe288cba7674bca44d9c8.png)

点击上方的 用户

![](../Images/e2f9e3d8d8403e8129cf74b9b5b9f712.png)

选择需要修改的 用户名 ，再点击上方 编辑用户

![](../Images/b95b600797964f2e5cd939cd887eb9a6.png)

出现以下界面，修改你需要 修改的信息 ，再点击 保存

![](../Images/bd0556b93e0b6bd04841831713b66433.png)

### 五、 其他操作

#### 5.1 查看数据库版本

##### 5.1.1 终端查看

打开终端 （快捷键：Win+r，输入 cmd ），输入 mysql -V

![](../Images/3133085575d9ae9be29bb7358227c10b.png)

##### 5.1.2 sql语句查看

在查询界面输入 select version()![](../Images/d4fdbd1c4fd7cd54e71d5cdd1a8795c1.png)

#### 5.2 查看sql执行计划

使用 explain语句 去查看分析结果
