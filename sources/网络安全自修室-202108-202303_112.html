大家一定看过很多好莱坞大片中，那些只要在电脑上啪嗒啪嗒输入一连串代码后，就能一下子黑掉整个银行系统的人。
那时候看的话，估计觉得特别炫酷特别刺激，可能还有不少人梦想着自己也能成为“黑客”。据说，世界上“头号电脑黑客” 凯文·米特尼克只要给他一台收音机，就能用来连接网络，想想这技术得多牛逼。
这时候大家肯定会比较好奇，传说中的黑客到底是用什么操作系统呢？
在黑客最喜欢的操作系统排行榜中，Kali Linux常年来稳居第一，那它究竟是有什么厉害之处，让一个普通人直接成为传闻中的黑客

一、Kali Linux简介

Kali Linux 是专门用于渗透测试的Linux操作系统，Kali Linux 是linux其中一个发行版，基于Debian，前身是BackTrack（简称BT系统）。在整合了IWHAX、WHOPPIX和Auditor这三种渗透测试专用Live Linux后，BackTrack正式改名为Kali LInux
Kali Linux 系统内置大量渗透测试软件，黑客工具箱已不足以形容它，可以说是巨大的渗透系统，涵盖了多个领域，如无线网络、数字取证、服务器、密码、系统漏洞等等，为满足专业渗透测试和安全审核的要求而设计。它包含 600 多款工具软件，适用于各种信息安全和渗透测试研究，知名软件有：wireshark、aircrack-ng、nmap、hashcat、metasploit-framework等等,关键是开源，永久免费！

二、使用Kali Linux人群

如果使用 Kali操作系统是为了完成开发任务或者单纯就是体验一下 Linux 操作系统，那 Kali Linux Linux 并不适合，可以考虑使用 Ubuntu或 Linux mint 等,一般使用Kali Linux的人群主要如下：
  • 网络安全从业人员
  • 网络渗透测试及学习
  • .......
Kali Linux 上包含一系列对网络环境具有破坏能力的工具软件，除非取得对目标系统的渗透测试和攻击许可，不要轻易使用 Kali Linux 中的软件工具去扫描和攻击网络，否则等待你的只有法律的制裁
