职位需求

根据网上很多web安全工程师职位描述与要求，梳理初步的学习规划，仅供参考

第一阶段：安全渗透基础

1.认识并安装虚拟机

学习任务：安装一个虚拟机Windows server 2008 r2 sp1

2.Web通信原理

  • 了解基础知识（IP/域名/DNS/端口/MAC地址）

  • 网页浏览的流程

  • 常见Web服务器容器

  • 常见服务器系统

  • 常见动态语言

  • 快速搭建渗透测试环境（phpstudy）

  • 利用CMS快速搭建一个网站

学习任务：使用phpsyudy快速搭建渗透测试环境

3.Web前后端原理

（1）后端基础SQL数据库及SQL语法

  • 认识数据库

  • 常见数据库

  • 数据库的基本知识

  • PHP和数据库交互

学习任务：使用MySQL进行增删改查

（2） 后端基础SQL高级查询与子查询

  • MySQL的基础查询语句

  • 连接查询（内连接）

  • 联合查询

  • 子查询

  • 常用函数

学习任务：尝试内连接|子查询|联合查询

（3） 后端基础PHP及基本函数

  • 认识PHP

  • 基础语法

  • 运算符

  • 条件分支语句

  • 循环

  • PHP获取参数

  • PHP操作MySQL

  • 预防MySQL注入原理

学习任务：写一个网页版计算器且记录计算历史

（4）后端基础PHP-表单验证

  • 了解表单基础知识

  • 创建一个表单

  • 接受验证表单

  • 简单预防SQL注入 

学习任务：完成一个登录表单（有一定防注入功能）

（5）正则表达式

  • 了解正则表达式

  • 正则表达式的语法

  • PHP中的正则

  • 常见使用场景

学习任务：完成靶场正则的CTF题目 

第二阶段：信息搜集，信息分析

1.信息搜集的意义

  • 为什么要信息收集

  • 信息收集要收集什么

  • 利用网络空间搜索引擎

2.信息收集实战

  • whois信息收集

  • 端口扫描

  • 寻找旁站

  • 目录扫描

  • 指纹识别

  • 内容敏感信息泄露

学习任务：整理信息收集的收集方法

3.网络架构-信息收集

  • 了解域名

  • 子域名收集

  • 了解whois

  • 如何查询whois

学习任务：子域名和whois查询

4.前端-信息收集

  • 了解Google hacking

  • Google语法

  • Google语法的利用

  • 了解web指纹

  • 如何使用指纹识别收集信息

学习任务：谷歌语法和指纹识别

  • 了解端口

  • 认识Nmap

  • 使用Nmap探测端口信息

  • 使用 Nmap探测服务器信息

学习任务：使用Nmap进行探测

  • SQL注入本质

（2）了解渗透测试常用工具

（3）MySQL注入

  • DNSLOG的函数解析

  • DNSLOG的使用场景

学习任务：完成DNS-LOG注入靶场

（4）MSSQL注入

  • 反弹注入

  • MSSQL反弹注入使用场景

  • MSSQL显错注入

  • 搭建一个MSSQL环境（虚拟主机）

  • MSSQL反弹注入语句解析

学习任务：完成反弹注入靶场

（5）Oracle注入

  • 报错注入

  • 注入函数解析

  • 报错注入+联合查询

学习任务：完成Oracle报错注入靶场
