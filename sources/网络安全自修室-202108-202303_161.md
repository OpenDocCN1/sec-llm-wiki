### 平台介绍

**Hack The Box**是一个国外的靶机**在线平台**（官方网址：https://www.hackthebox.eu/），实验环境将实时更新并且需通过 VPN形式连接,允许您测试您的渗透测试技能，并与其他类似兴趣的成员交流想法和方法。正如其首页宣传的这是一个庞大的黑客游乐场，可以尽情享受实践渗透测试技能，网络安全学习必备实战平台！

![](../Images/3b82f94fb715c8e5c5488a6e1665f6a0.png)

### 注册条件

![](../Images/5c12490b6ebcc322f6433b7dd3443df5.png)

2.  **科学上网**
    
    需要获取Google提供的验证码，所以能够科学上网是必备的，建议VPS自搭节点。
    
3.  注册邮箱
    
    需要提供一个邮箱进行账号验证
    
4.  邀请码
    
    获取邀请码其实是该平台出的一个简单的Web题挑战**（2021年以来不需要挑战了）**，旨在设置注册门槛，考验注册者的技术水平。
    

### 邀请码获得

如果出现以下页面，则需要邀请码，得接受这个挑战靠自己获取。

![](../Images/50ceafbb4fe8369ce18e8bf460470a2a.png)

使用view-source:https://www.hackthebox.eu/invite，查看源代码

![](../Images/5835510a81d6d6e74ce2441540fd71f1.png)

  

发现提示

  

![](../Images/000aebf8048408c5acb6a8b2db448cd0.png)

发现可疑的js文件：/js/inviteapi.min.js，inviteapi使用邀请接口

  

![](../Images/3ed5d54e9a9570f487ece1d9d735e329.png)

  

查看该js文件内容

![](../Images/f52d55aae2a05c9321cc63a1fe475a71.png)

  

在控制台进行调用,给出了提示，有可能是base64编码也可能是ROT13编码

```
makeInviteCode()
```

  

![](../Images/2d0f920bf6a1f22c7f17ae96a95ca9ed.png)

![](../Images/1bddf8eb9b449542cb4db321d2bb8d42.png)

  

把base64解一下码得

```
In order to generate the invite code, make a POST request to /api/invite/generate

```

根据提示，使用POST方法，向下面的那个接口提交数据，我这里是使用火狐浏览器的hackbar插件，post提交数据

![](../Images/2e5c40bc03c16900e5a5e4f3316f3de5.png)

然后使用base64解密?得到邀请码

![](../Images/3b01f74b3025852bc88b04599f8dd177.png)

### 靶机创建

登录进去后，在labs中可以在starting point初始点中开启简单靶机，并开始渗透测试

![](../Images/1b93ebd6d8daeca675eca463eb8a2b20.png)

选择目标靶机，并生成环境

![](../Images/075bcab0df89f381b82cc0f8742da308.png)

生成靶机环境成功，将会显示目标IP

![](../Images/f06b3074a8454c4793237c9fbb4a72b0.png)

### 连接靶机

 以Starting Point靶机为例，进入Labs中的Starting Point，选择右上角的Connect to Staring Point

![](../Images/a7232fbdfa804c560ce3879467e5e198.png)

点击下载OpenVPN配置文件

![](../Images/565c1f5f7b6550cff5c50901b45589a2.png)

接着选择tcp协议然后Download Connection Pack在Kali中执行

```
openvpn xxxxxx.ovpn 
```

![](../Images/9ca1c9c1b0ba82a3c726f09d69dbd6d8.png)

当显示 `Initialization Sequence Completed` 时执行成功

![](../Images/3adc39e296737b4ccf3f7ac7e3f8775c.png)

再回到HackTheBox，发现已经成功连接了,此时可以对目标机器发起渗透测试了....

![](../Images/31c752ee89bdf538c73458c3c7f3873a.png)
