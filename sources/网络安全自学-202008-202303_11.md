移动安全之Android系统安全

       Android系统安全包括系统和内核安全。主要分为以下几个方面：

**一、Linux安全**

       Android平台的基础是Linux内核。Linux内核为Android 提供了如下的安全功能：

       1、进程隔离；

       2、基于用户的权限模式；

       3、用于实现安全IPC的可扩展机制；

       4、移除内核中不必要的和可能不安全的部分。

       Linux 内核可以防范用户资源之间的相互侵扰。比如防止用户A读取用户B的文件，确保用户A 不会占用用户B的内存、确保用户A不会占用用户B 的CPU资源、确保用户A不会占用用户B的GPS、蓝牙等设备。

**二、应用沙盒**

       Android的应用安全性是由应用沙盒强制实施的。应用沙盒可将不同的应用分隔开来，并保护应用和系统免受恶意应用的攻击。

**三、系统分区和安全模式**

       系统分区包含Android的内核，操作系统库、实时运行框架、应用框架和应用。系统分区为只读分区，当用户将设备启动到安全模式时，不会默认启动用户安装的第三方应用程序，只会加载只读的系统分区，以此实现隔离第三方应用程序可能带来的安全威胁的目的。

**四、文件系统权限**    

       在Android中，每个应用都以自己的用户身份运行。除非开发者明确地与其他应用共享文件，

否则一个应用不能读取或更改另一个应用创建的文件。

**五、安全增强型Linux**

       Android使用安全增强型Linux ，即SELinux，来实施访问控制策略并针对进程建立强制访问控制机制。以保证在不同进程中运行的应用之间的安全通信。

**六、启动时验证**

       Android 6.0 及更高版本支持启动时验证功能和device-mapper-verity机制。

       启动时验证功能旨在保证设备软件（从硬件信任根直到 system 分区）的完整性。在启动过程中，无论是在哪个阶段，都会在进入下一个阶段之前以加密形式先验证下一个阶段的完整性和正确性。

       Android 7.0 及更高版本支持严格强制执行的启动时验证，该验证使得设备遭到入侵后将无法启动。  

**七、加密**

       Android 提供了一系列加密 API 供应用使用，其中包括标准和常用加密基元（例如，AES、RSA、DSA 和 SHA）的实现。此外，Android 还提供了适用于更高级别协议（例如 SSL 和 HTTPS）的 API。

       从Android 4.0 版本开始，为方便应用使用系统凭据存储空间来存储私钥和证书链，引入了 KeyChain 类。

**八、获取设备的Root权限**

       在默认情况下，在 Android 上，只有内核和一小部分核心应用能够以 Root 权限运行。

       而Android 不会阻止具有 Root 权限的用户或应用修改操作系统、内核或任何其他应用。一般来说，Root 对所有应用和所有应用数据拥有完整访问权限。

       如果用户在 Android 设备上更改权限来向应用授予 Root 访问权限，那么在面对恶意应用以及潜在应用缺陷时，安全风险会更大。

       对于操作系统已Root的Android设备，如果设备丢失或被盗，Android 设备上的全文件系统加密功能会用设备密码来保护加密密钥，这样一来，修改启动加载程序或操作系统的做法将不足以在没有用户设备密码的情况下访问用户数据。

**九、用户安全功能**

       用户安全功能包括文件系统加密和密码保护两个方面。

**1、文件系统加密**

       Android 3.0 及更高版本提供全文件系统加密功能，因此所有用户数据都可以在内核中进行加密。

       Android 5.0 及更高版本支持全盘加密。全盘加密是使用单个密钥（由用户的设备密码加以保护）来保护设备的整个用户数据分区。在启动时，用户必须先提供其凭据，然后才能访问磁盘的任何部分。

       Android 7.0 及更高版本支持文件级加密。采用文件级加密时，可以使用不同的密钥对不同的文件进行加密，也可以对加密文件单独解密。 

**2、密码保护**

       可以将Android操作系统配置为先验证用户提供的密码，然后再提供对设备的访问权限。除了防止未经授权使用设备外，该密码还可以保护用于进行全文件系统加密的加密密钥。

**十、设备管理**

       Android 2.2 及更高版本提供Android Device Administration API，该API 在系统级别提供设备管理功能。例如，内置的Android电子邮件应用可以使用该API来改善Exchange支持。在此情况下，Exchange管理员可以跨设备强制执行密码政策（字母数字密码或数字 PIN 码都算作密码）。管理员还可以远程清除（即恢复出厂设置）丢失或被盗手机上的数据。

       除了 Android 系统自带的应用，提供设备管理解决方案的第三方也可使用Android Device Administration API。
