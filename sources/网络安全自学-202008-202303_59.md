常见端口攻击手段

     ✦文件共享服务端口：匿名上传、下载、爆破和嗅探。

     ✦远程连接服务端口：

     ssh远程连接：爆破、ssh隧道及内网代理转发、文件传输；

     Rdp远程桌面连接：shift后门（仅限 Windows server 2003以下版本的操作系统）、爆破。

     ✦Web应用服务端口：

     一、常见的web服务端口（80/443/8080）：爆破、利用服务器版本漏洞；

     二、WebLogic控制台：Java反序列化、弱口令；

     三、Jboss/Resin/Jetty/Jenkins:反序列化、控制台弱口令。

     ✦数据库服务端口：

     一、Mysql数据库:注入、提权、爆破；

     二、MSSQL数据库：注入、提权、SA弱口令、爆破；

     三、Oracle数据库：TNS爆破、注入、反弹shell;

     四、Redis数据库：未授权访问、弱口令。

     ✦邮件服务端口：邮件伪造。

     ✦网络常见协议端口之DNS域名系统：允许区域传送、DNS劫持、缓存投毒、欺骗。

     ✦特殊服务端口：

     一、Zookeeper服务：未授权访问；

     二、Zabbix服务：远程执行、SQL注入；

     三、Rsync远程数据同步工具：匿名访问、文件上传；

     四、Svn:Svn泄露、未授权访问。
