# 51talk、VIPKID谁能脱颖而出？（2017-03-28）

简单探讨一下新东方、学而思、51talk、VIPKID等教育公司成长的大逻辑。成功的细节也重要，但没有大方向大逻辑重要。

  

**新东方为什么成功？起步早，早期老师教学优秀且风趣。**主攻出国英语考试，品牌出来以后扩展到各类英语培训，之后再到其他学科，横向扩品类。

  

**学而思为什么成功？专注理科，以培优为主。**差生看好学生都去学而思了，并且成绩越来越nb，当然差生之后也就过去了。学而思现在也扩展到了语文、英语。

  

**为什么新东方没能阻止学而思的壮大？**

  

**一是新东方最开始的精力没在理科这块，**导致学而思迅速积累了一批核心用户群，形成了口碑。口碑这个东西在家长中是非常可怕的，一旦形成了口碑，会以光速在家长群中传播。**二是新东方时间长了管理上存在一些问题，内耗严重。**这也可以理解，毕竟新东方这么多年了，肯定有一些老同志在位置上不动，每天光想着怎么保住位置了。老俞估计没有任正非的勇气，清理34岁以下员工吧？而学而思有一定的后发优势，对地方学校管控能力很强，估计在管理上也吸取了一些新东方前期的教训。

  

还有没有其他比较成功的教育机构？当然有。很多人包括黄佳佳黄老板今天在雪球大会上说线下1v1规模不经济，不赚钱，而线上1v1不一样。其实不是这样。大家可能只盯着学大、龙文这样的，不知道北京有京翰，上海有精锐，深圳有邦德。学大连年亏损那是因为管理太差了，过分营销导向，教学质量难以保证。没有口碑、没有用户留存率，那怎么赚钱？而精锐这种管理不错的1v1公司是非常赚钱的，甩出现在不赚钱的几条街，顺利的话明年估计可以上市了。

  

**所以什么样的教育企业会成功？归根结底还是重视教学质量的公司。**孩子的成长只有一次机会，哪个家长愿意拿孩子当试验品呢？教学质量优秀，形成了口碑，营销成本一下就下来了，家长负责免费传播，续班率立马上去，老客带新客。那能不赚钱么？

  

**如何保证教学质量？**

  

这就要靠管理了。需要**（1）优秀的课程研发团队**（覆盖需要教授的知识点、寓教于乐，保证教学质量）、**（2）尽量标准化的教学流程**（做到整体高水平教学，同时尽量降低名师对公司整体的影响）、**（3）强大的后台数据支持**（能够收集不同学生在学生过程中不同的问题，针对每个学生制定具体的提高计划，当然现在可能还做不到，是未来在线教育的发展方向）、**（4）重视每一个学生的课程体验**（教学本质也是服务业）。这四点都是说起来容易做起来难。

  

**那么根据上面这个逻辑来看在线教育，51talk、VIPKID、VIPABC谁有可能脱颖而出呢？**

  

最近大家讨论比较多的51talk，未来也许可以成功，但至少目前是处于劣势的。

  

**第一、VIPKID主打美国老师，人家是在资本主义环境里长大，自带人人平等理念，上课气氛活跃，有很多肢体语言带动孩子学习。而51talk是菲律宾老师，上课比较死板，在带动孩子方面要略差一下。**同样的课程美国老师确实比其他国家的上的好，这一点只要去线下听听英孚的课就能体会出来了。所以在教学水平这方面，家长包括孩子的印象一定是VIPKID的好。当然，51talk现在也在布局美国老师了。

  

**第二，51talk原来是做成人英语的，一旦品牌给人形成印象以后，再想扭转不是不可能，但要花一定的力气。**成人英语和K12英语的本质区别在于，成人都是相对独立的个体，没有传播效应。而孩子上课是家长付钱的，家长自带传播光环，一旦形成口碑营销成本可以下降的很快。这也是为什么长期来看成人英语很难赚钱，而K12英语相对容易赚钱的原因。

  

**第三，教育这个市场很大，51talk凭借菲律宾老师低价也肯定会吸引一部分市场。**但就像原来大家穷，很多人上不起新东方，就去别的机构上上，满足基本要求。后来大家有钱了，都觉得新东方老师好，就都去新东方上了。从高端人群往低端人群做远远比从低端往高端容易，而且钱赚的爽，利润率高。

  

**第四，从投资方看，Kobe的基金投资了VIPKID，那么有可能会给它带来很多美国的合作资源。**这点也是比较重要的，带来的品牌效应就不说了。

  

所以这样看，51talk的路还很长，VIPKID目前估值贵也是有一定道理的。

  

除了在线英语，在线数学、语文等等有没有可能出新的公司？我觉得机会比较小。因为英语是需要找外教的，而在线英语公司在这方面比较有优势。但数学、语文不一样，教育资源都在传统的培训公司手中，只要新东方、学而思把自己的网校做好，其他公司机会是不大的。
