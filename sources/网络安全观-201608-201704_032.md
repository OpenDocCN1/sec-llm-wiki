“幻境” 智能动态防御打造“网络迷雾”

  

![](../Images/86dfbf5fde1474c709dfdf34e0508065.png)

VEDA ——网络因我们更安全。

       军事上所谓的“战争迷雾”概念给了网络安全专家很多启发，它是指士兵与指挥官在军事行动当中身处不确定情境下而产生的认知能力快速下降的状况。美国陆军研究实验室的三位计算机科学家们将“战争迷雾”视为指导性思想，并希望借此建立起新的强大数字安全实现形式。他们将这种实现形式称为“网络迷雾（Cyberfog）”。这样的效果对于安全保护工作而言极为重要。  

      “网络迷雾”的作法是当恶意人士入侵正常网络时，雾化机制的不确定性会增加攻击者的行事难度。“由于混淆信息的类别众多，因此其存在多种解释方法，从而通过欺骗性方式经由错误解释阻止敌方行动，”陆军研究人员们写道。“混淆与欺骗效果可以通过多种方式加以实现，例如提供误导性的网络拓扑结构、流量以及行为观察结果等。”

       Veda Security “幻境”智能动态防御系统与这种理念完美契合，通过IDD（智能动态防御）技术营造出一个动态的、随机变幻的内网环境，打造真正意义上的“网络迷雾”。

       Veda Security “幻境”智能动态防御系统的主要思想是：通过网络的主动跳变快速迁移实现动态环境，构建一个动态的、不断变化的系统。破坏网络攻击能够实施的基础条件，主动改变网络防御策略，从根本上阻止网络攻击的发生。

       Veda Security “幻境”智能动态防御系统在现有网络安全防御的基础上，从内网安全防御的角度，通过以下安全手段来进一步诠释“网络迷雾”：

**1.全息伪装**

将不同网络节点数字化描述，全息虚拟大量动态变换的伪装节点，动态随机的改变网络节点属性；

**2.动态变化**

       网络身份不断随机变化，让攻击者无法有效识别目标节点，更不可能去锁定目标实施攻击，从根本上阻止网络攻击行为的发生；

**3\. 哨兵节点**

       极具诱惑力的虚拟节点，开放一些容易被黑客攻击的常用服务来诱捕攻击者；高仿真的虚拟节点，实时监测不符合动态变换规则的异常网络行为；

**4.内网微隔离**

       每个终端节点被单独定义为一个独立的逻辑网络，实现二层隔离的同时快速定义、封堵攻击；

**5.人工智能**

       根据客户网络特点机器学习形成行为记忆，能够有效甄别异常网络行为。

      Veda Security“智能动态防御技术”开创了全新的网络防御思路，颠覆了传统网络安全理念、改变了网络安全游戏规则，实现了变静态为动态，变被动为主动，开创了不依赖于先验知识的新型防御体系，扭转了传统网络防御的被动局面。

       北京卫达科技有限公司作为全球首创了“智能动态防御技术”的网络安全公司，同时成功研发出“幻境”智能动态防御系统、“幻影”WEB动态防御系统、“幻云”云平台一体化动态防御系统、“幻盾”DDOS动态防御系统、“幻界”工控网闸、“幻墙”智能边界防御系统等一系列面向多场景的智能动态网络安全防护产品，从根本上打破了传统的“静态被动防御”的格局。
