# 绩效管理变革不是一场OKR与KPI的拉锯战（2015-04-30）

俗话说，管理其实没有对错，只有适合不适合，而要达到这种“适合”，就需要打破常规管理思维，及时进行换位思考及管理创新。绩效管理而言亦是如此。

![](../Images/d295f82df09c39e634bd6fbff807369a.png)

绩效管理在观念上经历了从传统的绩效考核到全面的、战略的绩效管理的转变；在概念上经历了从结果导向到行为导向，再到潜能导向的转变；绩效管理的目标经历了从以改善员工绩效水平为目标到以提高员工工作投入为目标的转变；绩效管理工具和方法也经历了从财务转型管理工具到全面的、智能的管理工具的转变。然而，最近针对绩效管理变革最多的讨论被指向KPI，名曰以OKR颠覆KPI，殊不知，企业绩效管理变革不仅是绩效考核制度的革新与创新这么狭义，更不是一场OKR与KPI的拉锯战，企业需要全局角度思考绩效管理，让绩效管理变革产生质的升华，以下为在新形势下绩效管理变革的四大思路。

**操作思维：OKR与KPI的整合**

  

  

**KPI表示关键绩效指标，考核的本质是“要我做的事”，OKR表示目标和关键成果，考核的本质是“我要做的事”，二者都强调有目标，同时也需要有执行力。**OKR的思路是先制定目标，然后明确目标的结果，再对结果进行量化，最后考核完成情况。KPI 的思路也是先确定组织目标，然后对组织目标进行分解直到个人目标，然后对个人目标进行量化。因此，不同的企业、不同职位，对于OKR或者KPI的运用各有不同，而这不存在谁替代谁的情况，重要的是怎么在一个公司里更好地平衡OKR和KPI，把好刚用到刃上，这才是更有意义的思考角度。

**定量思维：弱化绩效评级与奖励之间的联系**

  

  

**绩效管理变革的另一条思路便是弱化绩效评级与奖励之间的联系。**虽然绩效通常都会是奖励的一项重要衡量因素，但是**绩效并不是唯一的驱动力**。而且，数字评级的作用也应该同步弱化，并选择新的方式给予员工反馈与建议，而不仅仅是一个”等级“的划分。因此，作为前瞻性的企业需要减少甚至割裂这二者之间的高幅度关联性，并且应该基于员工业绩、客户影响力、技能、职位本身的特性等来调整员工奖励制度等。前瞻性地分析，业绩评级与奖励之间的单项匹配关联性已经成为过去。

**实验思维：绩效管理工具迭代**

  

  

企业通常采用的绩效管理方法主要有目标管理法（MBO）、360度考核、关键绩效指标法（KPI）、平衡记分卡（BSC）、EVA价值管理等方法，具体到一个企业，因自身情况的不同，**每个企业采用的绩效管理的方法也是各具特色，但整体有一个共同点，即企业内部制定并实施考核与管理**。其实，企业可以做新的尝试，这种尝试除了企业内部的创新之外，也可以考虑外部有效的资源。例如，人力资源管理软件行业的升级与转型也为企业的绩效管理带来了新的思路。当前大量的人力资源软件服务商逐步加大对于绩效管理工具的开发，而且不少领先的供应商已经开发了部分操作性强、敏捷、低接触的绩效管理工具。企业可以将目光投向这些已有的、高价值的绩效管理工具，充分借助外部的力量与工具，再结合自身企业的特点找到最佳的服务商，使得企业绩效管理能够获得一套更为灵活、简单的解决方案，从而实现企业绩效管理的终极目标。

**创新思维：绩效支持与辅导**

  

  

多数企业绩效管理难见成效的通病在于过多地关注绩效管理的形式、程序以及任务本身，而忽略了最为关键的过程，缺乏全局管理的概念，而“绩效支持”与“绩效辅导”作为绩效管理过程中重要的环节，却没有被企业所重视。因此，**企业绩效变革需要关注过程，更需要重视“绩效支持”与“绩效辅导”**。

  

关于“绩效支持”的定义目前并无统一的说法，但综合来看，绩效支持主要是一种工具或资源，是指员工或团队在需要的时候提供完成工作所需的信息、知识或经验、工具与流程步骤等方面的支持，帮助其更快、更好地达成目标、提升绩效。绩效支持的最终目的是提供恰到好处的支持，为合适的人，在他刚好需要的时候。绩效辅导贯穿于绩效管理的始终，是管理者与员工讨论有关工作进展情况、潜在的障碍和问题、解决问题的办法措施、员工取得的成绩以及存在的问题以及如何帮助员工等的过程。其关键作用在前瞻性地发现问题并在问题出现之前解决，同时把管理者与员工紧密联系在一起。

  

**绩效支持与辅导可以被看作是绩效考核的生命线，一方面有效的绩效支持与辅导能确保企业绩效管理战略方向的正确性与推行的科学性。**众所周知，绩效管理有一种非常明显的风险，即战略方向不对、方法不科学的绩效管理将为企业带来巨大的损失，而有效的绩效支持与辅导可以确保这两种风险在源头上被化解；另一方面，有效的绩效支持与辅导还能够改变个体工作效率上升但组织的整体效率却是下降的现象。企业在推行绩效管理方法以后，由于部分个体仅关注与自己相关的指标，而忽视那些对企业整体表现很重要的内容，形成个体的工作效率上升但组织的整体效率却下降的现象，有效的绩效支持与辅导能够在绩效管理实施的过程中避免这种情况的出现。

  

总之，KPI与ORK都是绩效考核的方法，而绩效考核仅仅是企业绩效管理中的一个环节，因此，对于绩效管理的变革绝非定位为KPI与OKR的拉锯战这么简单，绩效管理变革的外延远大于此。切莫只看到了OKR与KPI的热闹，还需考量作为中间一环变动之后的整个企业绩效管理的变革。
