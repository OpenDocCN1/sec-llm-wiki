**前言**

  

2019年的RSAC带动了“零信任”的又一波新高潮，越来越多的企业意识到需要在企业内部和外部生态环境中营造信任。下一代互联网访问，零信任已成必然趋势。国内外踊跃的零信任安全厂商中，不乏有许多已经为终端用户部署落地的案例，当然也有更多拥护零信任但停留在构想阶段的。缔盟云实验室在研究了全球30多家领先的零信任安全公司后，列举有参考&学习价值的实践厂商。值得注意的是，我们不会对比各家的解决方案，更不会对其进行评分。

***01***

**从“吃自己的狗粮”到对外赋能的厂商代表**

吃自己的狗粮，简单理解就是：你自己做出的产品，要自己首先来使用，才能真真正正的从一个用户的角度来发现问题。零信任必然是一个长期目标，企业自身经过漫长的实践后对外推出解决方案，既是一种决心的体现，也为终端用户增加了一份信任。

Google

  
  
  
  
Google作为零信任解决方案供应商或许并不被人熟知，但是Google针对内部应用安全访问实施的BeyondCorp架构对业内人士并不陌生。如今Google的员工已经能实现：无论在家、咖啡厅、办公楼等任何地点访问公司应用，都是一样的体验。不再需要VPN，员工到应用的连接都进行了加密，访问控制权从边界转移到个人设备与用户上。最近，Google基于Beyond Corp安全模型，推出了“情境感知访问（Context-Aware Access for Enterprise）”平台，面向企业用户，提供更简单的权限访问，并实施精细的控制。情境感知访问权限建立在 Google Cloud 全球基础架构之上，与Google身份即服务 (IDaaS) 解决方案 Cloud Identity、Cloud Armor（DDoS防护） 集成。面向国内的版本目前正在测试中。

Akamai

  
  
  
  
  
作为为数不多的内部实践零信任的安全厂商，Akamai针对企业终端用户推出的Enterprise Application Access 2019年被Forrester wave列入零信任厂商领导者象限。  
Akamai Enterprise Application Access的特点：在边缘上交付自适应访问与威胁防护。给企业带来最直接的作用就是免去昂贵的设备投入，降低管理成本。Akamai的零信任产品经过独家设计，可以在实现最低权限访问、应用程序漏洞保护以及高级威胁防护的同时，提供更优化且安全的用户体验。此外，Akamai提供详细且具体的企业零信任实施教程，是基于实践的经验沉淀。  

***02***

**巨头厂商零信任布局**

对于零信任安全访问的未来，不是所有公司都有Google和Akamai这样的实力与决心，但并不影响各安全巨头用自己的方式开始布局，事实上他们已经走在前列了。例如：思科、派拓、赛门铁克、Unisys、Proofpoint这样的巨头玩家，多以收购的方式实现在零信任网络访问的纵深和业务的横向布局。  

思科

  
  
  
  
作为网络领域的佼佼者，思科在安全类目上一直鲜有明星产品。近年来，一系列的零信任布局收购：Duo Beyond、Tetration、SD-Access，让我们看到了其在安全领域卷土重来的决心。尤其是对Duo的收购：Duo的优势在于强大的身份验证和易操作性，通过收购Duo， 大大增强了思科安全产品的功能。此外，结合思科的网络和设备工具，针对分析和云负载的新产品以及Duo对用户和端点的关注，支持多组件、部署和易用性成为了整个产品组合的特点。  

赛门铁克

  
  
  
  
赛门铁克收购Luminate Security后推出Symantec Secure Access Cloud，平台中针对“零信任”的最有趣的功能是对风险结构系统的更新。这包括分析上下文以及在问题映射到行为和威胁活动时纠正问题的能力。  

Unisys

  
  
  
  
Unisys是一家非常特殊的零信任厂商，主要为美国联邦政府内某些受高度保护的机密组织提供零信任网络访问服务。一定程度上，也证明了本身的实力。代表产品：Stealth。Forrester这样评价：Stealth深入研究包括：发现，识别，映射和隐藏那些不应该被看到或访问的资产。此外，Unisys在协议级别设计并构建了自己的创新专有产品，实现了微隔离和零信任。  

Proofpoint

  
  
  
  
今年比较值得关注的一起零信任收购案例来自老牌网络安全公司Proofpoint，它于2019年5月以1.1亿美元现金收购零信任创业公司Meta Networks。Meta Networks利用云原生的全球骨干网，以用户为中心取代以站点为中心的网络安全，帮助企业实现人员、应用程序、云、数据中心和办公室的快速连接。通过收购，Meta Networks的ZTNA技术将与Proofpoint的CASB和Web隔离产品线集成，帮助其云安全产品和自适应控制得到进一步发展。  

派拓

  
  
  
  
  
派拓近年来也进行了多次收购，例如：PureSec, RedLock, Twistlock，以实现从网络到云和负载的拓展。2019年，与思科、Akamai一起入围Forrester Wave零信任供应商的领导者。  
以上，列举主要安全巨头的零信任布局。  
  

***03***

**零信任注定是巨头的游戏？**

一个已经多巨头林立的市场还有进入的机会吗？零信任最终也会变为巨头的游戏吗？我们研究了Gartner零信任网络访问市场指南中提及的几家独角兽创业公司，罗列了各家的业务发展优势和态势。

![](../Images/c014cfb571005b4ad974cadacba49f70.png)

不难看出，这些企业或多或少在以下领域曾有特定的积累：1.CASB：CASB的供应商，平台根植于云，员工/合作伙伴可以方便远程登录使用企业各种网络服务，不会导致企业的敏感信息泄露。有着天然的优势转型零信任。2\. WAF: WEB应用程序通过基于反向代理的WAF来提供服务，进行流量检查。同样具备演变零信任架构的基础。九层之台，起于垒土。当量变的积累遇上新的时代需求，所有的成就也就变得有迹可循。  

***04***

**那些敢为人先的零信任初创公司**

Gartner2019发布的Hype Cycle for Cloud Security指出：零信任网络访问距离进入成熟的平台期尚有5年左右的时间。对于初创公司，要在这个赛道冲出重围，机会窗口依旧存在。目前也有一些细分赛道的初创公司展露锋芒，本篇选择几家有落地案例的公司做参考（已被收购的参考上文，此处不再赘述）。

Cato Networks（以色列）

  
  
  
2015年成立，融资阶段：C轮5500万美金。**产品：**Cato Cloud（SASE）

![](../Images/bb735e010c41bb1c71e6e9160a00eb92.png)

图：来自Cato Networks官网  
**应用场景：**通过云原生托管的SD-WAN服务为企业提供随时随地的安全网络访问，将移动用户和云数据中心无缝集成到WAN中。**企业案例：**已服务零售、医药、制造等多个行业。11月，Cato Networks推出了面向合作伙伴的全球计划，包括总代理、子代理、VAR和MSP。  

InstaSafe（印度）  

  
  
  
2012年成立，融资阶段：A轮220万美金。**产品：**Instasafe®secure access

![](../Images/db01d032b46011d2990ede1336d1efe8.png)

图：来自InstaSafe官网  
**应用场景：**金融行业财务数据泄露，物流/零售网络黑客攻击。**企业案例：**超100家客户，接入终端48万。  

Cloudaemon（中国）

  
  
  
  
2017年成立，尚未融资已实现盈利。  
**产品：**ESZ™Cloudaemon零信任安全能力平台/太极盾![](../Images/55d43912d74663c5c33d2d2bc314433c.png)图：来自Cloudeamon官网  
**应用场景：**零信任抗D，改善灵活性、敏捷性和可伸缩性，使企业应用程序在运行时不再直接暴露于互联网。**企业案例：**主要为游戏公司，截止到2019年，订阅企业数超100家。  

Perimeter 81（以色列）

  
  
  
2018年成立，融资阶段：A轮1000万美金。  
**产品：**Software Defined Perimeter

![](../Images/878c5f84c99bc01765f8bf980b0ecfbd.png)

图：来自Perimeter 81 官网**应用场景：**替代VPN，帮助企业保护云环境、公司数据库。**企业案例：**面向金融、SaaS、零售行业等，未透露具体用户数量。  
零信任的浪潮已经到来，无论是供应商还是最终用户，零信任都是一个需要长期参与的旅程。本文基于有限的信息整理分析各代表性零信任玩家的特点，如有重要信息遗漏欢迎沟通指正。
