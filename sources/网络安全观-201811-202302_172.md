# ESG首席分析师：安全变革即将到来，四大趋势主导未来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNzUxNzA2NQ==&mid=2247492646&idx=3&sn=7f95d52696f6247bc7f6f18b7418a312&chksm=97fa3940a08db0569ae332e1141c774b2664bcd8a3c51b06c8f60b9280121a263f4557897ba9&scene=126&sessionid=1681323686#rd](http://mp.weixin.qq.com/s?__biz=MzIxNzUxNzA2NQ==&mid=2247492646&idx=3&sn=7f95d52696f6247bc7f6f18b7418a312&chksm=97fa3940a08db0569ae332e1141c774b2664bcd8a3c51b06c8f60b9280121a263f4557897ba9&scene=126&sessionid=1681323686#rd)

  

变革即将到来，它将比大多数人想象的更大、更快。近期，美国ESG首席分析师Jon Oltsik对安全领域 2020及未来10年的变化进行了预测。  

 

网络安全已成业务的关键，发展成极具动态性、可大规模扩展和高度专业化的学科。但安全行业仍在使用彼此割裂的工具，以及手动流程来处理安全问题，人员不足的困扰也依然存在。

 

在接下来的几年中，这些传统策略将会过时。大型机构将依靠基于以下四个平台的网络安全技术基础架构：

 

01**紧耦合的网络安全技术平台**

CISO将改变以往选择同类最佳工具的作法，转而采用包括五个紧密耦合组件的网络安全平台：**端点/云工作负载安全、网络安全、文件引爆沙箱、威胁情报、集成所有数据的高级分析工具**。

  

虽然有可能出现可以将各种不同工具整合的标准，但**许多大型机构将会选择单一的供应商平台**。产品高度集成、用户与供应商紧密合作，以及运营简化所带来的好处将超过各单点工具之间的增量优势。这意味着未来大型安全企业将会赢得更多机会。安全行业整合将会继续，小而美的安全公司备受考验。

02**分布式实施的云端集中管理平台**

  

随着不同安全“服务”在云端管理平台的整合，网络安全技术平台的概念也将会极大扩展。弹性云网关的概念就是这一新兴技术趋势的例子。

  

管理平面将会监管配置管理、策略管理、监控等活动。实际的安全控制将会分布在本地、网络边缘和公有云，并能够定制适用于单个应用、服务器或用户的极精细的策略实施规则。此时，安全技术背后的“大脑”将迁移到云端，而基于硬件和软件的实际安全控制将变成高性能的安全交换机。

03**大规模的SOAPA引擎**

  

在幕后，SIEM和其他安全分析工具将以大规模可扩展**安全运营和分析平台体系架构（SOAPA）**的形式进行整合。除了架构之外，我们还将看到SOC的范围和用途呈指数级变化。

  

机器数据收集和处理将会爆炸式增长。威胁和漏洞数据的关联将大大得到改善，从而更容易根据可利用漏洞和测试的漏洞做出安全决策。风险管理数据也将变得更加可视和容易使用，最终将业务和网络风险联系起来。

  

当然，机器学习算法将得到极大改进，并形成相互补充的嵌套算法，从而提高准确性。最后，SOC工具将开始从多年的可视化分析研究受益。用户界面可以定制，适用于VR、大型等离子屏幕和移动设备等显示器。

 

04**自动化和服务将融入产品中**

大多数繁琐的日常安全运营工作将实现自动化，使安全团队得以腾出时间来保护业务资产/流程，并专注于优先事件。这将包括基于用户、位置、网络流量或资产业务价值的策略自动化。一旦用户和设备通过强大的多因子身份验证获得访问权限，将会建议和/或强制从端到端实施最小特权/零信任，从而大大减少攻击面。

  

为了解决安全问题的复杂性，技术将配备高度智能的“助手应用”，而技术人员可以向网络安全人员寻找建议最佳实践、提出问题或寻求援助。

  

未来的架构并不是一个秘密。我一直在将它作为**SOAPA**的演变进行跟踪，而我的同事Dave Gruber则将其称为**XDR**。两者在发展和组建上略有差异，但整体相同。美国国防部/国土安全部和约翰霍普金斯大学的**集成自适应网络防御（IACD）**也提出了类似的愿景。

  

这种情况不会在一夜之间发生，但大型网络安全厂商，例如Check Point、Cisco、FireEye、Forcepoint、Fortinet、IBM、McAfee、Microsoft、Palo Alto Networks、Rapid7、Symantec（这个似乎应该去掉）和趋势科技，将具有明显的优势。像Amazon和Google等云计算供应商以及CrowdStrike、Cybereason、Zscaler等前瞻创新公司也将会进入这一领域。

  

在这种情况下，它将极大地集中网络安全技术的力量中心。初创企业只有有限的窗口证实自身价值，与大企业开展合作，然后被收购或消亡。

  

这些变化需要一段时间才会发生，但是技术和市场变化的步伐将比过去快得多。同时，新型威胁、大规模数据泄露和关键基础设施瘫痪，将鼓励CISO跳出传统思维模式，加快向大型架构的转移。

  

变革即将到来，它将比大多数人想象的更大、更快。明年，未来十年应该非常有趣。
