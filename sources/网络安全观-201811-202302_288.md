# 第四次 Ponemon 最新调研发现：6 成受访者认为增强网络弹性的新技术居然是它！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNzUxNzA2NQ==&mid=2247491923&idx=2&sn=9f3f46054349873b1c6ddd9801be1123&chksm=97fa3c35a08db52392bbac279ba3112a673419c3f2dbc6b11c68537a24e0fffbaf8ce61746ce&scene=126&sessionid=1681323721#rd](http://mp.weixin.qq.com/s?__biz=MzIxNzUxNzA2NQ==&mid=2247491923&idx=2&sn=9f3f46054349873b1c6ddd9801be1123&chksm=97fa3c35a08db52392bbac279ba3112a673419c3f2dbc6b11c68537a24e0fffbaf8ce61746ce&scene=126&sessionid=1681323721#rd)

近日，Ponemon Institute 与 IBM Resilient 联合发布了有关网络弹性组织的第四次年度调研结果。调研发现，大多数具有网络弹性的组织都会通过一系列习惯或实践来实现更高的网络弹性状态。其中一种实践就是快速采用新技术。

  

此次调研**将网络弹性定义为在针对网络攻击的管理、延缓和恢复方面，防范、检测和响应能力的连续性，**探究了网络弹性对于建立强大的安全态势有何重要意义。最具网络弹性的组织（即绩效卓越者）在受访者中的占比为 26%，其网络弹性水平总体提高了 18%。此外，这些组织还具备了以下特征：

  

🔹 更乐于采用自动化等新技术

🔹 专注于工具和流程的投资

🔹 信赖安全情报和威胁共享

🔹 会与高级管理人员和董事会进行沟通

🔹 优先制定和实施网络安全事件响应计划 (CSIRP)

🔹 了解整合隐私和网络安全功能的必要性

  

**此次调研第一次突出强调了自动化对网络弹性的重要性，也衡量出了自动化技术可以从哪些方面提高网络弹性：**

![](../Images/23ac8e2407de17ebf78b09c311fce1f7.png)

☑ 防范能力提高 **16%**

☑ 检测能力提高 **23%**

☑ 响应能力提高 **15%**

☑ 控制网络攻击的能力提高 **25%**

**什么是自动化？**

**为什么说自动化可以提高网络弹性？**

  

自动化是指有助于在网络攻击或数据泄露事件的识别与遏制过程中增强或替代人为干预的支持性安全技术。此类技术依赖于人工智能、机器学习、分析和统筹等等。调研显示，有 23% 的受访者认为其组织已经广泛采用了自动化技术，**在对他们进行分析后，我们得出了 6 个重要结论**：

  

**1**

**自动化能够降低出现数据泄露和网络安全事件的可能性**

  

自动化程度更高的组织，IT和业务流程的中断更少（在过去两年中，中断次数减少了 7%）。

![](../Images/02b89bff830c5590f0084ff70b41e4b2.png)

**2**

**自动化能够降低数据泄露和网络安全事件的出现频率**

  

通过防止安全事件的频繁发生，这些组织所遭遇的数据泄露事件更少（在过去两年中，遭遇多起网络安全事件的可能性降低了 6%）。

![](../Images/02b89bff830c5590f0084ff70b41e4b2.png)

**3**

**自动化能够帮助企业极大地提高网络弹性**

  

这些组织对其防范、检测、响应和遏制网络攻击的能力充满了信心（分别提高了提高了 16%， 23%，15% 和25%）。

![](../Images/02b89bff830c5590f0084ff70b41e4b2.png)

**4**

**自动化能够让企业更加认识到技能熟练的网络安全专员的重要性**

  

这些组织已认识到在其 CSIRP 中拥有网络安全专业人员的重要性（意识到这一重要性的受访者比例增加了 7%）。

![](../Images/02b89bff830c5590f0084ff70b41e4b2.png)

**5**

**广泛使用自动化的组织已开始最大限度地发掘威胁共享和高级技术带来的益处**

  

这些组织认为情报和威胁共享，DevOps 和安全软件开发生命周期流程，分析，以及人工智能在实现网络弹性方面最为有效（受访者比例分别增加了 7%， 10%， 12% 和 12%）。

![](../Images/02b89bff830c5590f0084ff70b41e4b2.png)

**6**

**自动化能够降低 IT 基础架构的复杂性**

  

这些组织表示，他们所拥有的安全解决方案和技术的数量比较合适，而且往往比自动化程度较低的公司更少（自信程度高 10%）。

![](../Images/ef63471fabf6b6b99e6a180176aa0e52.png)

**自动化有助于提升网络弹性，以及防范、检测、遏制和响应网络攻击的能力**

**如何才能实现自动化？**

  

在认识到自动化能够发挥作用之后，对于一些组织来说问题就在于：如何才能实现自动化？大多数受访者表示，自动化的实施就像是从爬行到步行再到跑步的练习过程。无论您处于网络安全成熟度的哪个阶段，我的入门建议都是选择一个重复的流程，将分析师的注意力从更多的关键任务上移开，使其专注于自动化。比如从其他安全系统请求信息以丰富案例这类基础性操作，都是非常适合实施自动化的活动。

  

自动化及相关工作流一直都是业务流程管理 (BPM) 的元素之一，而且从以往的情况来看，在具有明确定义的流程及一定程度控制的环境中，它们一直都能够发挥出最佳作用。然而对于 IT 安全专业人员来说，网络攻击和其实施者通常不会遵循相同的规则。攻击者会付出巨大的努力来攻克您的保护和流程，而他们自己则运用自动化来造成破坏并寻找战略中的弱点。

  

正因为此，我们在安全保护方面不仅要坚持防范，还要提升网络弹性。自动化是实现这一目标的重要工具之一，因此我们需要高效地运用这一工具。**此次 Ponemon Institute 调研结果显示，在准备方面充满信心、能够充分利用其技能熟练的网络安全专业人员和威胁情报，并在人工活动与自动化活动的协调方面取得平衡的组织，可以更好地防范安全事件和 IT 或业务中断。**
