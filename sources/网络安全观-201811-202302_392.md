# 微软网络安全参考体系结构（v3.1版）

**关键要点**：这是微软的网络安全参考体系结构（下载地址 https://aka.ms/MCRA），描述了微软的网络安全能力，以及它们如何与现有的安全架构和能力集成。  

此图的最新版本、相关演示视频（当前为v1版本）和补充网络安全参考策略可在**顶部的****链接**中找到。对于重要和复杂的计划，如保护特权访问、Office 365、防范攻击（如Petya/Wannacrypt）等，还包括到关键指南的链接。

此图是**交互式**的，您可以将鼠标悬停在任何功能上以查看快速描述，然后单击它以获取有关该功能的更多文档。  

此图原图为**动画版**，动画构建序列需要大约25次单击。下面是每次单击后的说明：

**CLICK 1****：**大多数企业组织都有Windows和Linux服务器（通常是**应用程序容器**）需要保护。大多数公司还在网络边缘/出口点，建立了一套基本的核心安全功能，以保护外网和内网资源。

**CLICK 2****：**我们还经常发现，企业还拥有一系列需要支持和保护的**客户机设备**（client devices），从企业发行的PC到BYOD个人拥有的移动设备。

**CLICK 3****：**许多企业组织已经建立了包括**漏洞管理**和**事件管理**在内的**运营安全能力**，通常由内部（on-premises）安全信息事件管理（**SIEM**，Security Information Event Management ）能力或托管安全服务提供商（**MSSP**，Managed Security Services Provider）提供。

**CLICK 4****：**许多公司还部署了端点**数据防泄漏**（DLP）功能，以帮助满足信息保护需求。

**CLICK 5****：**大多数大型组织都将**Active Directory**作为主要的**企业目录**（通常作为**身份系统**的一部分，该身份系统包括身份生命周期管理、凭证保险库（credential vaulting）和满足其他需求的其他功能）。

**CLICK 6****：**大多数企业资产包括**SaaS**（软件即服务），如Office365和其他流行服务。其中一些是由公司IT部门批准和配置的，而另一些则是业务部门和个人用户在公司IT部门未知悉或未认可的情况下采用的**“影子IT”**。

**CLICK 7****：**许多组织还运行传统的**工业控制系统**（ICS，IndustrialControl Systems），包括监控和数据采集（SCADA，Supervisory Control and Data Acquisition）技术。许多公司也在运营或计划采纳为内部系统和客户产品提供的**物联网（IOT）技术**。

**CLICK 8****：**此外，企业基础设施的范围已经发展成为一种**混合状态**，它将Microsoft Azure以及其他IAAS提供商提供的**IaaS**（基础设施即服务）和**PaaS**（平台即服务）结合在一起。这让大多数企业都有一个“混合一切”（hybridof everything）的财产需要管理和保护，这是非常具有挑战性的，鉴于网络安全威胁行动者的数量和复杂性稳步增加。

**CLICK 9****：**微软的云服务和产品的基础，是从我们对安全性和合规性的投资开始的，其中许多已经以某种形式提供给我们的客户：

**信任中心**（Trust Center ）：微软提供了一套任何云服务提供商可以提供的最全的合规性产品。我们透明地提供信息，说明我们如何在信任中心达到或超过那些标准。

**合规管理器**（Compliance Manager）：我们构建了一个功能来帮助您管理您的合规性需求，主要基于我们在管理我们的云服务合规性时学到的知识，例如跨标准的广泛控制映射（an extensive mapping of controls across standards）。

**安全开发生命周期**（Security Development Lifecycle）：我们还公开发布了行业领先的安全开发生命周期的文档，以帮助您保护应用程序。这最近演变成了一个Azure安全DevOps工具包（SecureDevOps toolkit for Azure），https://azsk.azurewebsites.net/；

**情报安全图**（Intelligence Security Graph）：在支持、运营和保护我们的云服务和Windows PC的过程中，微软积累了大量的第一方威胁情报（每天处理约6.5万亿(trillion)个信号），用于保护我们的云服务、IT环境和客户。本体系结构中的许多产品，都将情报和分析从安全图直接集成到了威胁检测和告警增强功能中。

**CLICK 10****：**在Azure市场（Azure Marketplace）中，常见供应商提供了熟悉的安全功能，使客户能够**将内部控制扩展到云**。此外，微软还构建了**Azure防火墙**，它是Azure中的一种本机“**防火墙即服务**”（Firewall as a Service）功能，包括几种先进技术，并大大简化了防火墙的部署和管理。

**CLICK 11****：**微软已经投资了**Azure安全中心**（ASC，Azure Security Center ），使您能够：

保护服务器和工作负载；

检测并纠正常见的错误配置问题，如：

直接暴露在互联网上的虚拟机；

缺少WAF保护Web应用程序；

过期的补丁和反恶意软件签名；

还有很多其他的；

利用Azure中类似于机器学习的尖端功能，来建议防火墙规则和应用程序白名单（允许/阻止哪些文件可以在服务器上运行）。

**CLICK 12****：**微软还对其他Azure安全功能进行了大量投资，如DDoS缓解、密钥管理、抗勒索软件备份档案、在处理数据时保护数据的机密计算功能等。

**CLICK 13****：**微软还继续投资于**Windows服务器**（包括屏蔽虚拟机（**Shielded VMs**））和**Azure Stack**（提供在本地数据中心运行Azure服务的能力）的本地安全功能。

**CLICK 14****：**微软也非常重视设备安全：

系统中心配置管理器（**System Center Configuration Manager**）和**Intune MDM/MAM**，用于跨Windows、Linux、Mac、iOS和Android平台的安全和管理；

Windows 10企业安全（Windows 10 Enterprise Security）：一套广泛的平台功能，可抵御不断演变的攻击；

**Windows Defender ATP**：高级端点检测和响应（EDR）功能，用于对攻击的快速检测和恢复，以及管理、监控和安全规划功能，用于保证设备健康和安全。

**CLICK 15****：**基于从凭证盗窃和类似攻击中吸取的经验教训，微软已投资于保护**特权访问**，包括特权访问管理、高级凭证/身份攻击检测、特权访问工作站（PAW）体系结构。我们的PAW投资包括：

**发布指南**（Windows 10 Enterprise Security）：我们已经为客户发布了详细的安装说明，以建立他们自己的PAW。

**平台安全**（Platform Security ）：我们通过完整的管理工作站程序（内部称为安全访问工作站或**SAW**）保护我们的IT环境和云服务。

**CLICK 16****：**由于身份对安全的重要性，微软在**保护和管理云和内部身份方面**投入了大量资金，包括多因素身份验证、生物特征识别、凭据的硬件保护（通过**基于TPM和虚拟化的安全**）、将威胁情报+机器学习应用于身份认证的尝试，等等。

**CLICK 17****：**身份对于**保护数据和操作可用性**也至关重要，因为它通常是现代物联网/移动/等设备和云服务中唯一可用的控制类型。组织应该集中精力构建一个**身份安全边界**，以加强对身份验证和访问控制的管理，并加强一致性。微软已经投资于**条件访问（Conditional Access）**，以实现对这个新边界的简单（和强大）可见性和策略控制。

**CLICK 18****：**微软已经投资于我们的工具，以实现与您的现有安全信息和事件管理（**SIEM**）解决方案的集成。

**CLICK 19****：**微软已经建立了**高级威胁保护（ATP）**技术，为现代资产的关键技术元素（端点、身份、电子邮件等）提供了深入的上下文，以快速检测和修复它们中存在的威胁。微软还提供专业服务，帮助您调查环境中的事件，并寻找潜在的已有威胁。这将使您能够使用**情报安全图**（幻灯片右下角）中的大量微软威胁情报，来转换SOC，并使用**图形安全API（GraphSecurity API）**将其与你的现有功能进行集成。

**CLICK 20****：**微软还在Azure中构建了**Azure Sentinel**（Azure哨兵？），这是一种云原生的**SIEM**和**SOAR**功能，它可以帮助您获得广泛的可视性，以便从您的整个企业资产范围（包括微软、AWS、其他云和内部资产）收集安全数据。Azure Sentinel使用机器学习来减少告警疲劳（alert fatigue ）（私人预览中高达90%）和本地云功能（如自动化），以简化数据收集、SIEM维护、事件调查+补救。

**CLICK 21****：**微软已经构建了若干**Office 365安全功能**，以增强您的**安全规划**（**Secure Score**（安全分）），在微软支持人员能够访问您的数据以解决支持问题（**Customer Lockbox**（客户保险箱））以及平台内置的数据保护技术之前，添加了其他明确的批准步骤。

**CLICK 22****：Azure信息保护**（Azure Information Protection）：保护文件本身的信息，以便**加密和策略控制**可以跟随文件，无论它们到哪里（云、设备、USB驱动器等）。

**CLICK 23****：**云应用安全（**Cloud App Security**）是一款微软云应用安全代理（**CASB**），它为SaaS提供了广泛的安全功能，包括影子IT风险管理、策略监控和执行、信息保护、事件检测/响应/恢复。

**CLICK 24****：**此外，微软还投资了**高级SQL数据安全**功能，以防止常见威胁，简化信息保护管理和策略。

**CLICK 25****：**微软也在大力投资**OT和IoT安全**，以帮助管理和保护现有（棕地（brownfield））平台，提供安全（绿地（greenfield））平台，并帮助制造商快速确定他们需要的安全级别，使他们能够快速轻松地实现这一目标。

**CLICK 26****：**我们理解这是一堆需要计划的众多功能，因此我们已经构建了几个规定路线图，帮助组织快速缓解来自关键和复杂网络安全挑战的风险。
