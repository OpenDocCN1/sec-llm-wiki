2.1 泄露的信息能用来做什么

  

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

泄露这么多内容对于攻击者来说可以做钓鱼、可以尝试爆破用户各种账号秘密，进而给受害者带了财产及其他方面的损失。此次数据泄露量巨大，不仅包含普通人，还可能包含企业高管、政府人员、军队国防相关人员，可以说是已经危害到国家安全了。

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

常见泄露字段利用：

```
姓名手机号出生日期身份证号银行卡号车牌号应用账号（如：QQ）公司名称关联人（家人姓名）
```

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

此类字段最常用的就是暴力破解，知道手机号后，就可以查到该手机号注册了哪些应用。常见关联推到如下：

                   ![](../Images/8351cfd076440afd85cc9660556c0841.png)  

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

很多人密码一般会取上述字段中拼音大小写+部分数字组合，当黑客获取到这些信息后就会根据上述信息生成密码字典，然后进行暴力破解。

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

此次泄露信息远不止这些，综合这些信息，攻击者更容易假扮政府部门对受害者进行钓鱼攻击，发送木马程序盗取更多个人信息，实施诈骗。

2.2 如何自救

  

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

破镜难重圆，就像泼出去的水无法收回一样，信息既然已经泄露，我们能做的只能有**能换尽换。**

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

**易更换的字段**

**手机号、应用账号，租房地址，收货地址、银行卡号这些能替换的尽量替换；各种系统，应用账号密码要设置复杂一些，使用字母大小写+数字+特殊字符，字母大小写和数字要避免使用手机号、应用账号、身份证、姓名里面的字母或连在一起的数字。**

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

**不常使用或者不在使用的应用账号，**能注销就注销，不能注销的建议更改为更加复杂的密码，账号内不要留存太多和自己相关的真实个人信息。

  

              ![](../Images/7c58eadb650822420e8e94ea5495a0ae.png) 

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

针对本次泄露的家庭住址，个人社会背景关系、报警记录、犯罪记录什么的，实在太详细了。总不能重新买房，迁户口换个地方吧，木已成舟，这个没有办法解决，只能个人提供警惕，不要点陌生链接，轻信陌生电话，提高个人防诈骗意识。

  

![](../Images/5a16128a5dd91675f490c84044cd5068.png)

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

对比其他类型信息泄露，这次的还多了个照片。也许去理发店重新设计个发型可以有效应对。

  

数据所有者（甲方）如何管理数据

![](../Images/60facacdc91de3f89baa141e68119024.png)![](../Images/ce70a92c14dadccccc859afb928bf251.png)

  

![](../Images/5d8e6c69ce3abeb857e54b88f4e28633.png)

1、对于保存大量个人信息数据的甲方来说，应当自觉维护信息 机密性（confidentiality）、完整性(integrity)、可用性(availability)；

  

2、做好人员安全策略和程序：在职人员应做到职责分离、最小特权、工作论换；人员录用严格审查，人员离职要收回相关权限，注销对应账号。严格管控第三方人员，做好第三方人员监控，在第三方合同条款中要增加保密要求。（此次泄露可能是系统相关开发人员，将OSS配置信息，访问密钥放到了CSDN上导致的）；

  

3、资产识别和分类：确定拥有的资产类型，按照敏感度将数据分类，采取分级控制策略。对不同状态的数据采取相应的保护措施；

  

4、区分数据的角色与责任：定义数据角色，建立全生命周期的数据所有权。对数据所有者、资产所有者、业务所有者、数据处理者、数据管理员、用户等不同角色赋予相应的权限，做到知所必需，最小权限的原则；

  

5、身份验证与访问控制：访问数据前进行身份验证，防范未授权访问。建立适当的访问控制模型，实施访问控制策略。如：自主访问控制模型、强制访问控制模型、基于角色访问控制模型、基于规则的访问控制模型等。

总结

  

![](../Images/734cf16e2f5e169c8697a79926cbfac6.png)  

在数字化的浪潮之下，你我都不可能是一座孤岛。频繁的网络诈骗、网络暴力、骚扰电话其背后本质都是信息泄露。对于防范信息泄露不是技术及管理手段达不到，根本原因是意识问题，普通民众意识不到个人信息泄露带来的危害，一副事不关己高高挂起的样子。相关管理机构不重视，不作为，认为把发现问题的人解决了问题就解决了。最终导致企业直接相互交换个人信息，网上各种渠道贩卖个人隐私。
