前言



针对中大型目标渗透过程中，非员工不能接入内网，这就给渗透测试人员测试带来了很大的难度。有线接入不了的情况下就考虑无线方式。





现在的路由器大多都默认用 WPA2-PSK 方式对无线网络进行加密了，不能再像 WEP 加密方式那样好破解。本篇文章主要介绍WPA2的两种破解方式。




简述原理




WPA2加密认证体系讲起来很复杂，涉及较多密码学内容，写了也没几个人看的懂,这里就写操作步骤，不写原理。
简单一句话总结破解原理：抓取认证过程中的密钥。

由于加密密钥用的是Hash算法，Hash加密使用的是单向加密函数，只能单向加密，不能逆向破解。如果感兴趣的可以网上搜一搜Hash加密。所以破解密码只有一种方式，就是碰撞，说白了就是穷举法暴力破解。

开启网卡监听模式




命令：airmon-ng start wlan0


wlan0 为插入的无线网卡





暴力破解



第一步：扫描周围网络


airodump-ng wlan0





简单介绍一下上面参数含义：


BSSID--无线AP（路由器）的MAC地址，如果你想破解哪个路由器的密码就把这个信息记下来备用。


PWR--这个值的大小反应信号的强弱，越大越好。很重要！！！


Beacons--准确的含义忘记了，大致就是反应客户端和AP的数据交换情况，通常此值不断变化。


#Data--这个值非常重要，直接影响到密码破解的时间长短，如果有用户正在下载文件或看电影等大量数据传输的话，此值增长较快。


CH--工作频道。


MB--连接速度


ENC--编码方式。通常有WEP、WPA、TKIP等方式，本文所介绍的方法在WEP下测试100%成功，其余方式本人 并未验证。


ESSID--可以简单的理解为局域网的名称，就是通常我们在搜索无线网络时看到的列表里面的各个网络的名称。




第二步：确定要攻击的WiFi，针对性抓包 (这里以Chinaunicom-小咪这个wifi为例)


airodump-ng -c  [信道号]  -w [保存抓包文件的名字]--ivs --bssid  [目标wifi的MAC地址]  wlan0




一般来说这个过程是抓不到握手包的，因为客户端和路由器已经连上了，不需要认证了。这就需要让客户端和路由器重新认证，我们在抓取数据包。




第三步：攻击目标wifi的客户端
这一步目的就是让目标wifi与wifi的客户端断连，然后重新连接，我们抓取连接过程中的握手包，密钥就在其中。

aireplay-ng -a [目标wifi的MAC地址]  -c [目标wifi客户端的MAC地址]  --deauth  [攻击次数] wlan0





攻击后我们可以看到抓到了握手包





第四步：破解wifi


aircrack-ng -w [字典路径]  [抓取的数据包]





这种方式能不能破解wifi取决于字典，这里给大家整理了一个弱口令字典100M+

跑pin破解



同样，原理不在介绍。这种方式就是耗时间，通过猜测pin码然后逆向计算出密码。pin码总共有8位，理论上只要跑完pin码就能逆向出密码。但实际上时间很长，我也没试过。如果知道pin码的话就可以直接计算出密码。




第一步：同样开启网卡监听模式


第二步：查找开启wps可以使用pin登录的WiFi


wash -i  wlan0





第四步：开始跑pin


reaver -i wlan0 -b [目标wifi的MAC地址] -vv





这里介绍一下reaver的参数




-i  无线网卡名称


-b  目标AP的mac地址


-a  自动检测目标AP最佳配置


-S  使用最小的DH key，可以提高破解速度


-vv  显示更多的非严重警告（注意这是 2 个小写字母 v）


-d  即delay每穷举一次的闲置时间 预设为1秒


-c  信道编号


-p  PIN码四位或八位  //可以用8位直接找到密码。





如果知道pin码，可以直接用pin码找密码；-d参数很重要，设置3-9秒可以防止路由器被Pin死，但是这也将大大延长我们破解wifi的时间。







写了这么多，实际上可以看出来，暴力破解都是很浪费时间的。我破解的快那是因为这个是我的wifi，我知道密码和pin码。WiFi万能钥匙可以分享连过的wifi密码，万能钥匙能解决的事，就不用kali这么麻烦了。
