【目的】

1) 了解Windows服务器的安全配置内容

【原理】

1) Windows服务器需保证其端口、账号、服务上的安全

【环境】

Windows Server 2003

【步骤】

一、端口配置

1.1 依次点击“开始”->“设置”->“网络连接”，打开“网络连接”窗口。

1.2 选择“本地连接”，右键单击，在快捷菜单中选择“属性”打开其属性窗口。

1.3 选中“Internet协议（TCP/IP）”，点击“属性”按钮，打开其属性对话框。

1.4 点击“高级”按钮，打开“高级 TCP/IP 设置”对话框并切换到“选项”便签下。

1.5 点击“属性”按钮，打开“TCP/IP筛选”对话框，勾选“启用TCP/IP筛选（所有适配器）”，“TCP端口”框中选择“只允许”单选按钮（假设该服务器为IIS服务器，仅允许80端口开放），点击“添加”按钮添加端口“80”。

1.6 在此“TCP/IP筛选”对话框中，也可对UDP端口及IP协议进行过滤设置，一般情况下，负载量不大的服务器仅允许对外提供服务的IP协议生效。

二、关闭不必要的系统服务

2.1 依次点击“开始”->;“程序”->“管理工具”->“服务”，打开“服务”窗口。

2.2 关闭服务“Terminal Services”，该服务允许用户以交互方式连接到远程计算机，双击服务打开其属性窗口，设置启动类型为禁用。

2.3 关闭服务“Remote Registry”，该服务使远程用户能修改计算机上的注册表设置，双击服务打开属性窗口，设置启动类型为禁用。

2.4 关闭服务“Telnet”，该服务允许远程用户登录到此计算机并运行程序（默认禁用）。

2.5 在日志内容上，每一条访问日志包括：访问时间、客户端IP、数据包提交方式、客户端访问URL、服务器响应状态码等信息。

三、账号安全设置

3.1 禁用Guest用户，更改管理员用户名，此处不再赘述。


3.2 依次点击“开始”->“程序”->“管理工具”->“本地安全策略”，打开“本地安全设置”窗口，依次展开“账户策略”->“密码策略”设置内容。

3.3 设置“账户锁定策略”。

四、安全日志配置

4.1 依次展开“本地安全设置”里的“本地策略”->“审核策略”->“审核系统事件”。

4.2 可根据实际情景，设置相关审核项，过多的审核内容会增加服务器负担及审核复杂性，过少的审核内容不利于对系统问题的排查及取证追踪。

五、其他相关安全设置

5.1 及时更新保证系统安全的补丁，但生产环境中进行补丁更新时需要提前在虚拟环境中测试补丁对于当前业务系统是否会产生影响，确保业务系统的安全及持续正常运行。

5.2 点击“开始”->“运行”，输入命令“regedit”打开注册表编辑器，依次展开“HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Lsa”，编辑“restrictanonymous”键值为“1”，关闭空连接。
