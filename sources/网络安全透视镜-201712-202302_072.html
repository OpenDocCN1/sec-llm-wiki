      使用Web Application Stress 进行压力测试


【原理】

1) Web Application Stress是一款专门用来进行网站压力测试的一套攻击，通过这套功能强大的压力测试攻击，可以使用少量的客户端模拟大量用户上线对网站服务可能造成的影响，它具备DoS（拒绝服务）攻击的功能

【环境】


操作机：192.168.1.2



【步骤】

一、简易设置

1.1打开软件。

1.2展开“Defaults”->;“Settings”，在设置中，“Stress level（threads）”可以指定程序在后台用多少线程进行请求，相当于模拟多少个客户机的连接，一般是500~1000，实际设置值应根据主机配置设置。如果少于100个用户，可以直接设置“Stress level”，多于100个用户时则必须设置Stress Multiplier，基本公式为：线程数（用户数）= Stress level * Stress Multiplier。

1.3“Test Run Time”为压力测试的持续时间，其余选项可默认。具体设置如下。

二、压力测试

2.1 点击工具栏中的第一个图标按钮“new script”创建一个压力测试任务，在弹出的对话框中选择“Manual”。

2.2 在“Server”中输入地址“http://192.168.1.3/test/”，下面输入需要测试的页面路径及请求方式。

2.3 选择“Settings”，设置“Stress level（threads）”为“1000”（不应设置过高，过高测试机会卡机），其他默认。

2.4 选中“New Script”，点击工具栏中的三角图标按钮“Run Script”开始测试任务。

2.5 出现告警信息，选择“Run Test”继续。

2.6 开始压力测试。

2.7 查看目标服务器性能。

2.8 等待压力测试完成，点击工具栏中的第三个图标按钮“Reports”可查看此次压力测试的报告。
