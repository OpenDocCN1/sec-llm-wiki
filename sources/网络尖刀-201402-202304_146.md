# 网络尖刀的这群年轻人。

我时常在想，2003年如果不是遇到了7tools，不是遇到了丫朵，现在的我应该是一个文艺青年，坚持去写情感碧如《泣城》一般的小说，亦或者去给一些音乐作品填词，也许在另外的一个领域里，我可能也会成为今天的“尖刀”。

  

离2018这个自然年的结束，还有两个月，不长也不短，但是总结了这一年的成果，到时心安理得了很多，毕竟在多元发展的这个决定下，我们算是勉强成功的。

  

为什么是勉强成功呢？因为有很多意外，这些意外的结果让我感觉到真切的欣喜，索性借着这些欣喜，我也借此装个无声哔~。

  

**成绩**

  

**安全线**

  

过往的不看，在4.9日正式宣布了《[网络尖刀团队2018年组织架构调整告知函](http://mp.weixin.qq.com/s?__biz=MjM5MDA3MzI0MA==&mid=2650089116&idx=1&sn=ca57c446fa08474380e1f0810d481f69&chksm=be4bee6b893c677d565382582cfc92079fb477a344b59f1a0bf947b1b149186609f2b6759df1&scene=21#wechat_redirect)》后，以EVA、y1ng、黑色键盘为首的新组织架构让我眼前一亮，招募了很多新的血液加入，我们在各大平台的覆盖也可以说是前所未有的爆发。

  

以前我们活跃其实还是集中在阿里、360平台，而今年算是良性发展要更爆发的多，我粗略的统计了一下。

  

百度安全应急响应中心

  

这是由黑色键盘首要负责的阵营，不止是在团队榜单上面包揽了第一、三、四的名次，2018年榜看过去，个人榜前十的仅有两位不是我们网络尖刀的成员。

  

![](../Images/bfd1e1d302b1757f0543cc2756b98bc2.png)

  

360安全应急响应中心

  

年榜目前第一仍然保持着，还是要说一下个人，前十我们仍然保持了第一、二、六的成绩。

  

![](../Images/a094dc97863bef6f263fe601d3f09772.png)

  

阿里安全应急响应中心

  

在阿里我们算是一直出了很多风头，特别感谢阿里对我们的支持，也感谢我们的兄弟们，16年我们拿了14块奖牌，17年我们拿了15块，作为一个民间组织分别在两年内拿到了16年唯一、17年与卡巴斯基并肩卓越生态合作伙伴的奖项。

  

今年后劲虽然不及以前，但是在前十个人榜单仍然保持着当前第一、第五的名次。

  

![](../Images/0701b508621997a6f21b7b0ea238a375.png)

  

其它的很多平台也是诸如此类，在今年注重发展的补天平台上，我们的Z小队和Z2小队也一样基本每个季度都杀入了前十，特别欣慰的是网络尖刀国际化的定位，抛开以前泳少、5up3rc拿到微软、苹果致谢不说，今年涌现的新成员Reckfulyx更是拿到了Twitch、PayPal、AT&T等平台的致谢。

  

我们正在考虑与海外的安全平台及互联网厂商进行合作接洽，国际化应该是我们2019年最重点的目标。

  

**文娱线**

  

媒体传播力不想多说，披露行业内容、以及收到的各种律师函、撤稿函这都变成了一种说不清楚的成绩，算是顶着压力把持底线努力前行着。

  

签约的嘻哈艺人“杨曜泽Kk”，今年刚好出了12首歌，感兴趣的可以在网易云音乐搜索杨曜泽KK，去了解一下。

  

众所周知因我爱宠安妮离开后，我们就没有再对“方脑壳安妮”这个IP进行维护，但是仍然在这之前我们的卡通IP单款表情包还是在微信表情平台得到了1.3万次的下载量。

  

虽然我个人参与客串了《天才J 2》戏份被剪掉了，但是天才J真的是一部很好的剧，以后可能我会在其它的内容中做一些努力。

  

**人工智能线**

  

这是我们今年干了最多的事儿吧，基于我们的爬虫引擎、NLP引擎，我们围绕情报这件事儿干了一系列的深入，现在还不是时候，日后这个环节我会单独用一篇长文介绍，此处除了心酸，就只剩下眼泪了。

  

NLP依然持续打磨着，除此之外目前我们情报智能化已经达到了60%、运营自动化除了写作还要人为干预，基本90%的工作都是交给机器人来做，包括后面很多营销及品牌辅助工具，也都是机器人。

  

我坚信只要是价值是对的，这些苦都不算什么。

  

**用户体验中心**

  

用户体验中心今年除了解决内部VI体系，一直都在努力赋能，不止于为自己解决问题，也在为别的平台赋能，今年4月26日推出的“AiDeep 英文字体”，目前不完全统计已经在近50个平台进行发行、累计下载量远超15万次，仅在字由平台就被使用了3.6万次。

  

后面我们也会再推出更有价值的字体，如果想要体验的可以通过http://ued.1aq.com/ 进行访问下载。

  

**责任**

  

价值观一直以来都是我在强调的事儿，通过我公众号应该也了解到，我今年真的是实打实的正面diss了很多公司，除了和媒体互动对一些“高大上技术”的大白话解答互动，我们也一直热衷于披露行业风险问题。

  

在安全这方面以及一小部分的公益方面，我们都很积极，之前宣布的进入犯罪情报领域，除了日常和相关部门互动贡献情报与犯罪分子斗智斗勇，平台已经打好了地基，基本定位的很清楚了，我们正在解决一些法律、法规以及行业合作的问题，我想这个平台会在19年和大家见面。

  

虽然我们是干着得罪人的事儿，总是开玩笑现在都要穿运动鞋出门，但是我想这就是我们的责任，有技术的人的三观一定要正，能力越大责任越大，但是它的破坏力也一样等同。

  

**价值**

  

千万不要低估一个安全爱好者的创造力及他的破坏力，你要知道目前大部分的安全从业者并不是有多高的学历、文化，大家都是依靠自己的兴趣，走到今天的，网络尖刀的成员我们做了一定的性格和智商测试，其实智商和自学能力都是特别强的。

  

自从注册“网络尖刀”的商标，我们就早有跨界去其它行业一起合作共赢的打算，人工智能团队再往下走一走，这个计划我们就会马上打开。

  

**未来**

  

我个人计划两本书，完结日期还没定，一本是已经构思好了的《泣城 2》，虽然节选了很多《泣城1》的情节，但也构造了另一套青春为主题比较虐的一个细节，目前已经写了一部分，字码的多一些在放出来怕大家不够看。

  

另外一本暂时定名叫做《拾黑》，这本书的主题是围绕我这么多年如何学习、如何跨界、如何计划达成目标、脑力的逻辑训练整理出的心得，里面会涵盖你们关注的安全领域、隐私、物理学、生物学、法律、行为心理学、推理等各种“跨界”内容。

  

从目前来讲《拾黑》会是我的优先项，以后的公众号仍然会定期分享内容，但是后面写作更多的精力，将会放在这上面要更多些。

  

感谢那些陪伴网络尖刀一路走下来的兄弟们，感谢在背后支持我们的你们，感谢那些信任并想要加入网络尖刀的年轻人，后面的舞台是属于这群年轻人的，而不止于我们。

  

已经计划继Z小队后再开放一个小队，规则会在近期推出，给更多的年轻人一些机会，我们一起做些有趣且能够共同成长的事儿，好嘛？
