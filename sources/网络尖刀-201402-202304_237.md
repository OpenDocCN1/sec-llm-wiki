# 网络尖刀2017新年贺词：世界需要更好的我们！

我知道你一定曾经计划过2016年要做很多事，计划着自己的未来，想着未来的好，亦或者担忧未来的坏，在空气生活环境日渐恶劣的苍穹下，夹杂着空气中的霾，开始对生活调侃、踌躇、甚至抱怨，可是不管怎样，今天我们还是迎来了2017。

大数据、区块链、精准扶贫！

站在风口上，猪都能飞起来！

2016年留给了我们很多词汇，创业潮的兴起、传统经济的不振，身边的每个行业都在洗牌，改革很痛，不改革更痛，科技越发智能的时候，幸福感却跟着慢慢流失了起来。

**在爷爷、奶奶的年代，能吃饱饭就是幸福！**

**在爸爸、妈妈的年代，全家人的梦想就是奔小康！**

而在今天，吃饱饭已经满足不了我们的诉求，每天思考的最多的事情就是中午吃什么？晚上吃什么？我们已经忘记了小康生活到底是什么样子，虽然在一线城市拿着一两万的薪水，但是还是为了买房而操心。

房贷、车贷！虽然拿着不错的薪水，但是我们始终无法停下来享受生活，大部分的年轻人如果一两个月不工作，后面的日子基本都是要吃土，工作的压力、社会的压力、猝死、抑郁症，职场病越发的再增加。

可是不管怎样，生活还是要继续，日子还得积极的过下去啊！

所以我们还是要继续向前看，不期望世界能为我们改变什么，能改变的只有我们自己，我知道关于工作你也许已经有了很多、很多的计划，可是我们还是得讲讲生活，给自己找一点兴趣，多给自己一些幸福感。

偶尔可以放下手机，适当的时候远离互联网，多和朋友出去走走转转，一起唱歌喝酒也好，戳麻将打牌也罢，计划计划自己的出行和旅游。

**带着正义感，坚守着自己的纯真，摆正自己的价值观，不羞不躁，世界需要更好的我们！**

2017，加油前行！

 

**曲子龙（****Quu）**

**网络尖刀团队创始人**
