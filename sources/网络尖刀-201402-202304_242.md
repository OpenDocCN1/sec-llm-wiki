# 爱尖刀与嘶吼RoarTalk达成内容紧密合作伙伴关系

2017年1月16日，爱尖刀与嘶吼RoarTalk正式达成内容战略合作伙伴关系，双方今后将在资源、高质量内容共享等方面展开紧密合作。在内容上相互分享，资源上相互补充，平台上相互助力，技术上相互支撑，共同推进互联网安全行业生态良性发展。

  

关于嘶吼RoarTalk

![](../Images/331fddb157f522e35189eb32a8f97f43.png)  

2017年1月1日，嘶吼RoarTalk(www.4hou.com)正式上线，用最纯粹的方式探寻最本质的信息安全。全媒体视角，传播最新鲜的动态资讯；权威的发声，云集圈内顶尖技术大牛；专业的态度，深度剖析最热门的技术话题；开放的平台，与全球顶尖发烧友互动沟通。嘶吼的出现将为信息安全领域带来更有力量的声音！希望我们的每一声嘶吼，都如雷贯耳；每一个步伐，都掷地有声！

  

关于爱尖刀

  

![](../Images/f93cf1ffe9bc9c6c6247736b12db9269.png)

  

【爱尖刀】（www.ijiandao.com）是国内非企互联网团队【网络尖刀】旗下媒体运营平台，以关注数据与安全、洞悉企业级服务市场为使命！爱尖刀致力于挖掘互联网与移动互联网行业发展规律及其数据价值；万法究竟，只在灵台，爱尖刀始终如一的站在创业者身后，不瘟、不骄、不燥的记录互联网科技的变革与企业级服务行业发展！
