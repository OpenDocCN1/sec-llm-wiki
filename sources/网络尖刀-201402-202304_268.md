# 人人都恨电脑病毒，我竟玩了一个下午

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MDA3MzI0MA==&mid=2650088463&idx=1&sn=6a47d2054a3e7df4180cc23c816b90db&chksm=be4becf8893c65ee131e3ee4df59d19bddb081f10eb8084b17fa8faefa92080e66cf7677ed0e&scene=126&sessionid=1681402277#rd](http://mp.weixin.qq.com/s?__biz=MjM5MDA3MzI0MA==&mid=2650088463&idx=1&sn=6a47d2054a3e7df4180cc23c816b90db&chksm=be4becf8893c65ee131e3ee4df59d19bddb081f10eb8084b17fa8faefa92080e66cf7677ed0e&scene=126&sessionid=1681402277#rd)

根本停不下来！电脑病毒竟然和小游戏一样好玩。在一个叫 The Malware Museum 的线上博物馆里，我发现了一批带有 “复古” 气息的电脑病毒。![](../Images/bdfc0ef5a5304097676c643c99f44ea3.png)（WALKER 病毒：大王叫我来寻你的电脑）有没有想起 32 位像素红白机？但其实它们的年纪，可能比你都要大。在体验中的某一刻，甚至觉得它们的 “萌”，超越了历史，不小心就击中了喜爱二次元的我。![](../Images/f952067e6165a332b685f24e7c999113.png)(ZHU 病毒：中国制造，这个配色很有特色）你可能好奇如何 “玩” 这些 DOS 时期的酷炫电脑病毒？电脑病毒博物馆专门将这些病毒 “搬上” 了网页版的 JavaScript 模拟器。使用网页交互，不同电脑、不同操作系统的人都可以体验到感染 DOS 时期病毒的场景。![](../Images/c8b30008921d2115e667431a72c5508d.png)有些病毒更像是一种波普风格的数字艺术，让人眼花缭乱却又不失美感。虽然它们时代遥远，但却有着一种浓浓的现代感。很好奇当年的程序员哥哥们是怎么做出这么有趣的病毒的。![](../Images/de6a201d8a291e07f44afac3ae256d29.png)  
（LSD 病毒：好像在显微镜中观察细胞）Q CASINO 病毒强迫用户在保存文档时 “赌” 上一局。如果输了，你的文档也就没了。![](../Images/064073d69c40ccfeb471f25a79b0f1d2.png)（LSD 病毒：好像在显微镜中观察细胞）大多数电脑病毒带有电子音背景。配合弹窗画面，怀旧感十足。![](../Images/2c958994b2843090dc96e929b9ff1494.png)（HYMN： 总有一种 Windows 电脑死机的错觉）当你看着这些 “魔性” 的中毒界面不能罢休，想要了解更多的知识却无从下手？专家们一点都没闲着。在这个线上博物馆还设有《电脑病毒的历史》讲座，让你知道这些神奇界面背后有趣的故事。![](../Images/850a2a9c9d7200243d4ee1800931fb7d.png)恶意软件博物馆是互联网档案馆（Internet Archive） 中的一个项目。互联网档案馆同样是一个 “神奇” 的网站，作为一个非盈利的数字博物馆，除了古老的电脑病毒，在这里有数百万可以免费下载的书籍、音乐、影片。但其中最有名的项目要属网页时光机（Wayback Machine）。从 1996 年开始，这个时光机就在给整个互联网做备份，输入网址后选择日期，就能 “穿越” 回去，找回消失或被修改过的网页。![](../Images/4f8a0738e5aaae97838e3ee24127c7b4.png)“玩” 了这么多病毒，不怕电脑瘫痪？![](../Images/1596cb1a7e70edbf9c1dba51a4ed4d2e.png)（MARKIZ 病毒：从没见过你这么嘚瑟的病毒）这个博物馆的 “馆长” 是网络安全专家米克 · 海波宁（Mikko Hypponen），想要成为优秀的网络安全专家，不研究一下病毒怎么行？海波宁已经研究了 20 多年电脑病毒历史，博物馆早期的病毒 “展品” 就是他提供的。**他修改了这些病毒的程序，剥离其中的 “感染源”，只留下好玩好看的 “展品” 供展示。**![](../Images/c0c811b8e5568fccc9ca82eda126c1e2.png)（ELVIRA.COM 病毒：这不就是星球大战的滚动字幕吗）早年的病毒只是出于黑客的兴趣，大部分病毒并无太大杀伤力，甚至有些还卖萌说：![](../Images/ffaa39c294b9bfa378ded1f75c90fd74.png)我其实是一个很温柔的病毒。![](../Images/1c1f6886d4f6466e388aaea3bb630dc8.png)（SKYNET 病毒: 作为一个病毒这样卖萌真的好吗?）1969 的 Cookie Monster 被认为是最早出现的病毒， 这个 “不务正业” 的病毒只会终止电脑的所有进程，只需输入 “Cookie” 就能破除魔咒。![](../Images/f9f4736d6c806720dff2cfecf22a3fbd.png)（MARINE 病毒：我小学一年级的画作也能拿来做病毒？）Techno 也是一个有趣的病毒，它会侵占电脑的命令文档，快速播放电子音科技感舞曲长达 110s，直到 TECHNO 字样布满整个电子屏幕，而在重启十次之后，它又会再放一遍。![](../Images/5f752edda30be72219e1e6b15bd6571d.png)（TECHNO 病毒：妈妈，就是这个病毒残害了我的耳朵。）![](../Images/4f8a0738e5aaae97838e3ee24127c7b4.png)别样的技术美学上世纪 90 年代末是病毒的繁荣期，其实，在当年的 DOS 系统下尚未出现图形交互界面，想要绘制出如此动感的画面，并不是一件很容易的事情。当时的先驱们为了一时的炫技，想必也是颇费了一番心思。![](../Images/78aeaab03ea6a5054a5fb287da32c9ec.png)（TECHNO 病毒：妈妈，就是这个病毒残害了我的耳朵。）在电脑病毒博物馆中绿叶、彩虹、波普风格的图案展示，为我们展现了去除 “致毒” 部分后留下的美学和信息价值。![](../Images/ebe721e1154135e8a5bceda5bcdc631b.png)（TECHNO 病毒：妈妈，就是这个病毒残害了我的耳朵。）由于系统的更新换代，这些古老的病毒们早已不再具备实际上的危害，甚至从现代技术眼光看来，有些病毒的编写显得颇为稚嫩粗糙。**病毒同样是时代的记忆，他们曾经在那个时代留下了影响。**如果没有电脑病毒博物馆，这曾经有趣的历史，就会不经意间，与你我彼此错过。![](../Images/7a8c5bc49e69cb8b6c78f8816127b9f2.png)[![](../Images/8b4a65d08bef882e080b4871eacd9f8e.png)](http://mp.weixin.qq.com/s?__biz=MjgzMTAwODI0MA==&mid=2651844654&idx=1&sn=7a3b9a6b42f76976c3747c4b8ddaceeb&scene=21#wechat_redirect)[![](../Images/7faea9e7031df49fd7c9ef5f7491412e.png)](http://mp.weixin.qq.com/s?__biz=MjgzMTAwODI0MA==&mid=2651844647&idx=2&sn=cac7e5163275a8462d84399920932e9b&scene=21#wechat_redirect)![](../Images/65c154c50c9c3a90b144c3c4022590b8.png)
