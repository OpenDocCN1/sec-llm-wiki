# Ping++ 支付全新升级，不止于「壹」

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MDA3MzI0MA==&mid=208780747&idx=1&sn=3c77e3c900ccec44ac91846bb57395fe&chksm=2fcf753c18b8fc2a7aac228c166fda47aeb6b0aecfbc58eb323e239cc2d546dca567e8374823&scene=126&sessionid=1681402293#rd](http://mp.weixin.qq.com/s?__biz=MjM5MDA3MzI0MA==&mid=208780747&idx=1&sn=3c77e3c900ccec44ac91846bb57395fe&chksm=2fcf753c18b8fc2a7aac228c166fda47aeb6b0aecfbc58eb323e239cc2d546dca567e8374823&scene=126&sessionid=1681402293#rd)

  

国内知名移动支付聚合平台Ping++ 于2015 年10 月10 日正式发布了全新的管理平台和支付渠道，主要包括应用内快捷支付及PC 端支付。  

 

「壹」屏到多屏，不再只是移动端

 

支付渠道方面，最重大的更新在于PC 端和线下支付场景的同步支持。Ping++ 这次在非移动端的支付渠道布局，是基于其在移动支付的行业积累做出的战略决策。

 

作为Ping++ PC 端支付的首批商户，小牛电动、得音首饰订制等已在第一时间成功接入支付宝和银联支付。同时，Ping++ 的扫码支付也为更多支付场景提供了可能——企业级容器云平台和解决方案提供商DaoCloud 在网页端提供了扫码支付功能，10 月8 日在杭州正式开业的丁香诊所将Ping++ 的支付二维码嵌入线下问诊场景中，形成线上至线下的产品闭环。

 

在互联网体验越发立体和多维的时代，Ping++ 将移动、PC 和线下支付渠道进行整合，帮助商家更高效地推进业务流程，全方位地开展立体营销。

 

「壹」卡到多卡，不再只有银联卡

 

Ping++应用内快捷支付一举囊括了世界前三的发卡组织，不仅银联支付得以在应用内无缝完成，更首度支持了外卡支付，让海内外的消费者凭任何一张带有Visa / MasterCard 的借记或信用卡，都可在App 内快速完成支付流程，实实在在地解决了跨境交易问题。针对特定领域的商户，Ping++ 还支持了代扣机制。绑定银行卡的用户，消费后无需进行任何操作，就能自动扣款。

 

值得一提的是，Ping++ 在安全层面也做了加重防护，采用银行卡检测中心认证的安全控件进行数据加密传输，进一步避免了消费者敏感信息的泄露，为支付体验的安全保驾护航。

 

  

「壹」角到多角，不再只给开发者

   

Ping++本次升级的第三大亮点在于管理平台新增的权限设置功能。从最初的“专为开发者打造的支付SDK”到现在，Ping++ 交易管理平台的使用人群已逐渐覆盖技术人员、运营人员、甚至财务人员等各类相关角色。

 

在新的管理平台中，账号的管理人员可以对当前账号下的每一个应用进行管理授权，不同职能的用户会看到与其职能相对应的交易数据信息，这可以在保证企业内部信息安全的同时，让不同职能的用户更高效地完成自己的工作。目前有三个职能角色开放邀请和管理，包括开发、运营和财务。

 

此外，全新的管理平台界面在设计和功能细节上也做了诸多完善，包括订单流失率、批量退款功能、一体化的渠道管理界面，以及针对系统负荷的实时监控功能，让不同职能角色都能通过管理平台更高效地工作。
