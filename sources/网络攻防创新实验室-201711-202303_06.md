# 实验室4名同学参加2022年江苏省大学生网络空间安全知识技能大赛获好成绩

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzNDcyMDM1MQ==&mid=2247483868&idx=1&sn=6b2d19d2c98eddb850998677759b858e&chksm=e8f35cecdf84d5fae76c73e8cd72a5c02631d5045eb4eb71af2ebcdf5ebc3b6bbdfa952e4130&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIzNDcyMDM1MQ==&mid=2247483868&idx=1&sn=6b2d19d2c98eddb850998677759b858e&chksm=e8f35cecdf84d5fae76c73e8cd72a5c02631d5045eb4eb71af2ebcdf5ebc3b6bbdfa952e4130&scene=27#wechat_redirect)

12月4日，由江苏省计算机学会、江苏省保密协会联合主办，中国矿业大学承办的“米好信安杯”2022年江苏省大学生网络空间安全知识技能大赛（本科组）在线上举办。本次大赛共有36支省内知名队伍参赛，包括来自南京航空航天大学、南京理工大学、中国矿大学、江苏大学、江苏科技大学、常州大学、金陵科技学院、南通大学、江苏师范大学、盐城师范学院、昆山开放大学、淮阴工学院、苏州大学、徐州工程学院、无锡学院等多所高校的知名战队。实验室选派4名学生杨胤、董劭达、陆澍洋、钱怡婕组成2支战队代表我校参赛，分别获得第9和第12名的好成绩。

![](../Images/51e74b841cc663f01c1157571b6bb054.png)

  

本次大赛内容包括Windows Server与Linux系统安全运营管理。包括系统安全运营、数据库安全运营、Web安全运营、数据完整性保护、应用安全运营、防护墙安全管理、事件监控、系统日志分析、进程分析、内存文件分析、木马病毒分析、程序逆向分析、移动应用程序代码分析、恶意脚本分析等。  
    比赛采用CTF夺旗形式，包括：Web 漏洞、密码学、安全杂项、隐写技术、溢出、渗透测试及其加固、操作系统及服务相关安全攻防等题目类型。
