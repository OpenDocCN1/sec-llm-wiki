# 社团4名同学参加第十四全国大学生信息安全竞赛创新实践赛华东北赛区线下赛

　　由教育部高等学校网络空间安全专业教学指导委员会主办的第十四届全国大学生信息安全竞赛，是高校网络空间安全类比赛中最高级别的赛事。今年的创新实践能力赛项从4月开始报名，全国分为八个赛区，我校位于实力最强的华东北赛区。本次竞赛全国共有1960个队伍报名参赛，于5月15至16日举行线上初赛。经过24小时不间断进行线上比赛，共有431个队伍初赛出线，占比仅22%，我校战队CSLG2排名230，位于前11%。华东北赛区共80支战队入围线下决赛，我校战队CSLG2排名50。  

　　我校CSLG2战队由网络安全社团4名成员：周欣、黄俊博、丁强、杨胤组成。在指导老师殷老师带队下，于６月18日至20日赴合肥国防科大电子对抗学院参加华东北赛区线下赛。线下赛采用AWD网络攻防对抗赛制，经过一队的激烈战斗，CSLG2战队获得52名的成绩。成功地防护了7道赛题中的3道Web题，修复了相关漏洞。

　　后续社团将根据比赛获得的经验和教训，进一步增加相关学习和培训，争取获得更好的成绩。
