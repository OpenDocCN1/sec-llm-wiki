# 名舰风采｜海军大阅兵盛况：055型导弹驱逐舰与辽宁号航母青岛汇合

经中央军委批准，中国人民解放军海军成立70周年多国海军活动将于4月下旬在青岛举行。届时，将举行高层研讨会、国际舰队检阅、联合军乐展示、文体交流等多项活动。截至目前，已有60余个国家表示将派海军代表团参加多国海军活动，多个国家将派舰艇参加国际舰队检阅。

 

这一次大型海上大阅兵多国活动，我国首艘国产航母“辽宁舰”和万吨驱逐舰“055型导弹驱逐舰”备受大家关注。中国055型导弹驱逐舰于3月30日从江南造船厂出发，在经过近两天的航行后于31日10点18分顺利抵达位于青岛的古镇口军港，目前已经与前期抵达的辽宁号航母汇合。

![](../Images/ed6fc70f20d565144428316873144a3c.png)

055舰首舰船号被标注为“货船”

  

资料显示，055舰体长180米、舰宽22米，满载排水量约1.2万吨，打破中国海军驱逐舰排水量的纪录。舰载武器方面，055型导弹驱逐舰採用与052D型相同的通用导弹垂直发射系统，发射单元数量达112个，可发射长剑-10巡航导弹，鹰击-12、鹰击-18、鹰击-83反舰导弹，以及海红旗-9、海红旗-16防空导弹，火力十分凶猛。

 

055是中国已下水的最先进导弹驱逐舰，同时也是目前中国建造的排水量最大的驱逐舰，其满载排水量超过1.2万吨（美国国家利益网站推测其满载排水量约为1.4万吨），其最大的特点是采用了全燃动力系统，具有启动速度快，加速速度快，动力系统体积小等诸多优点，相比传统蒸汽轮机性能有了大幅度的提高，而全燃动力也是世界顶尖驱逐舰的标准配置，在动力这一点我们已经领先各国。

![](../Images/aa05fa047cefb69d698526f18c4a6097.png)

055首舰已挂上彩旗准备服役仪式

  

055型导弹驱逐舰是新世纪中国海上作战力量的中坚。055的服役是中国海军转向蓝水海军的一个重要节点，弥补了052D型驱逐舰虽然导弹发射器兼容程度高，但是火力不足的缺点，全舰通用发射器高达122个。无论是发射器兼容性还是发射器尺寸，均超过了美国最新的MK-57垂直发射系统，成为世界上最先进的驱逐舰导弹通用发射单元。

 

另一方面，055的出现，代表了中国海军舰艇最高技术成果，也让世界见识了中国海军的发展速度。在1994年前，中国海军的主力舰艇依然是老旧的051型导弹驱逐舰，曾经在海军交流时被美国嘲笑称为古董。1994年随着第一艘052型导弹驱逐舰下水，标志着中国海军进入高速发展时期，为了赶超世界先进水平，数年一个型号，并且每个型号都有了跨越式发展。

 

2005年052C导弹驱逐舰服役，该舰是中国第一款采用有源相控阵雷达的驱逐舰，到了052D服役时导弹发射系统换成了通用导弹发射器（VLS）。而到了055导弹驱逐舰，我们可以很自豪的说，055的出现直接改写了当前军舰的作战模式，在作战能力上当属世界第一。

 

据悉，首艘055型导弹驱逐舰命名为拉萨号，而这也是拉萨市首次被用在主力作战舰艇的命名上，相信在4月23日国际海军阅舰仪式上，055庞大的身躯会给世界各国留下一个深刻的印象。

 

此次海军阅舰仪式另一个焦点是“辽宁舰”航母。无论何时，我国国民对辽宁舰的关注度都从未减少，去年辽宁舰担任的是领头旗舰，而据猜测，今年国际阅舰式上辽宁舰航母或将担任首长检阅舰。

![](../Images/f98f0d2edd60e845f9d43b4c1cbe502c.png)

  

前段时间，国产航母已经完成第5次海试，各项工作进入了收尾阶段。如果辽宁舰作为首长检阅舰的话，国产航母参加阅舰式的可能性将大大增强。那么在此次阅舰式上，我们将有望看到中国的双航母舰队与万吨级055大驱。
