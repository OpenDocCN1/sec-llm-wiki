# 美国防情报局发布中国军力报告

2019年1月15日，美国国防情报局（DIA）发布报告，题为《中国的军事力量——打造一支能打仗打胜仗的部队》，阐述了中国的安全判断、解放军在国家安全中的角色、中国的军事战略，分析了中国的力量投送能力、太空能力和反太空能力、网络空间能力等核心能力。报告认为，未来几年里，解放军可能会变得技术上更先进，装备水平可能达到其他先进军队的水平。解放军将继续采购先进的战斗机、海军舰艇、导弹系统、太空和反太空资产，以消除远离中国本土的各种威胁。

![](../Images/98732b79134faec8348eb25ab04f00d6.png)

  

**一、中国国家军事概述**

**中国的安全判断。**本文称，中国认为自身正面临前所未有的安全风险。2015年5月，中国国务院新闻办公室发布了《中国的军事战略》白皮书，阐述了中国对全球安全环境的认识、中国在全球安全环境中的角色以及解放军如何支持这一角色。文件列举了解放军各军种的构想，阐述了新兴的各安全领域。文件认为，在中国的“战略机遇期”内，在可以看到的未来不会发生世界大战，但中国应做好应对局部战争的准备。中国认为自身面临的主要威胁包括领土主权威胁和国内安全，前者包括台海问题、钓鱼岛问题、中印领土争端等和南海主权问题等。此外，中国还认为美国在亚洲的军事存在、美国在亚洲牵头打造的安全体系限制了中国的崛起，干涉了中国的主权。  

  

**解放军在国家安全中的角色。**《中国的军事战略》列举了解放军必须做好准备执行的8种任务：保护国家领土主权；保护国家统一；保护中国在太空和网络空间等新兴领域的利益；保护中国的海外利益；保持战略威慑；参与国际安全合作；维护中国的政治安全和社会稳定；执行紧急救援、救灾和保护权益的任务。中国认为这些任务是中国取得大国地位所必须执行的任务。2017年，中国在《中国的亚太安全合作政策》白皮书中强调了上述任务中的几种，强调解放军需能执行远征作战和其他行动来保护中国越来越重要的海外利益。解放军与国家的执法部门、外交部和其他安全机构协调，执行各种军事相关活动，尤其是在中国境外执行这些活动。

  

**关于对外防务关系。**中国寻求与外军接触，展示自己日益强大的能力，提升战术技术与程序，改进中国在境外的形象和影响力，推进实现中国的外交目标。双边和多边演习为中国提供了政治利益，为解放军提供了提升反恐、机动作战和后勤能力的机会。高层互访与交流使中国有机会提升高级军官的国际知名度，向外国传达中国的立场。随着中国地区和国际利益的扩大，解放军大幅扩大了国际接触，尤其是在维和、反海盗、人道主义援助和救灾、多国演习等方面。

  

**关于国防预算。**2000年至2016年，中国的军事开支年均增长率为10%，在过去两年内降至年均5%-7%。过去10年内，官方公布的国防预算一直在GDP的1.2%至1.4%，这使得解放军能够有稳定的大量资金，装备等方面实现数量和质量的大幅提升。

**二、中国的军事条令与战略**

中国的军事目标是打造一支强大、高战力部队，能够打赢地区冲突并运用一体化的实时指挥与控制网络。支持这一战略的条令正在随着中国的军改而不断演变。例如，2017年，解放军开始执行修改后的军事训练规定，重点是针对现代化战争进行贴近现实的训练，为联合作战行动做准备。中国认为自己的军事战略是“主动防御”，即战略上采取防御性态势，但战役上采取进攻性态势。  

  

**对现代化冲突的认识。**解放军经常使用“信息化”一词来描述成为一支现代化军队的转变历程。这一概念与美国的“网络中心战”类似。解放军用“信息化战争”来描述获取、传输、处理和使用信息在陆海空天网及电磁频谱内开展联合军事行动这一过程。解放军将信息视为数字时代战争的关键使能力量，因此在情报监视与侦察装备、部队结构和联合网络的研发方面投入了大量资金。

  

**军事指挥与控制。**中国进行军改的一个关键动因是中国希望提升自身在现代化高科技战场上的能力。军改之前，解放军没有常设的指挥与控制机制。军改的一项重点就是改进解放军的指挥与控制体系。军改后，各军种负责部队管理，各战区负责指挥作战行动。指挥与控制改革的核心是：成立战区司令部，成立联合作战指挥中心，成立联合参谋部，打造现代化的联合指挥与控制体系。

![](../Images/fc20fcce94c00b040af43d4123623066.png)

  

**地区行动与全球行动。**虽然解放军的能力大幅提升，且已开始远离中国大陆开展军事行动，但中国仍认为要抓住战略机遇期，避免大规模军事冲突，为发展赢得时间。在这种理念指导下，中国在外部接触上采取了这样的战略：一方面提升中国的影响力和影响范围，同时又尽量不让国际社会担心中国的崛起，不去挑衅美国及其在亚太地区的盟友和伙伴，不与他们发生冲突。这在中国寻求东海和南海的领土与海洋主权时尤其如此。中国强调海洋主权和保护海外利益，这使得中国海军越来越多地在境外开展行动。中国在非洲的吉布提建立了首个海外军事基地，部署了一个连的陆战队和相关装备。中国可能还会在其他地区建立海外基地。未来，这些基地将提升中国通过军事力量进行威慑的能力，以及维持海外行动的能力。

  

**三、中国的核心军事能力**

解放军目前的能力还远不能在全球进行大规模常规力量部署，但中国发展了核能力、太空能力、网络空间能力和其他能力，能打击全球范围的潜在敌人。

![](../Images/3487c7a2e28c0f702ea560e34df2d99c.png)

  

**力量投送和远征作战。**中国军事现代化的一个主要动因就是打击台独，收复台湾。中国认为外部势力可能会干涉台海问题，因此研制了一系列系统来提升中国的力量投送实力，威慑外部势力干预。2016年，中国军方首次确认，解放军空军正在研发一种新型远程轰炸机，航程与能力都将大幅超过现役的轰-6轰炸机。除了陆基飞机外，中国目前还在生产自行设计研发的航母。首艘国产航母的主要目的是执行地区防御任务，以及在南海和印度洋进行力量投送。该航母已于2018年5月完成初始海试，将于2019年底前正式服役。此外，中国还积极参加联合国维和行动。中国的“和平方舟”号医院船定期在全球各地执行人道主义援助和救灾任务。

  

**核力量与核武器。**中国投入了大量资源来维持有限的、有一定生存能力的核力量，确保采取报复性核打击的能力。中国长期坚持“不首先使用核武器”的政策，称中国的核武器只用来回击针对中国的核打击。中国正在研发新一代机动导弹，这种导弹携带分导式多弹头，旨在确保战略威慑力量的可靠性。中国的火箭军与海军都有能够发射核武器的投送系统，此外，空军也在研发自己能够携带核弹的轰炸机。这种轰炸机研发成功后，解放军将拥有陆基、海基和空基三位一体核力量。

  

**生物战与化学战。**中国称从未研发、生产或拥有生物武器，而且也绝不会这样做。中国称只研发了用于防御的生物技术。中国于1984年加入了《禁止生物武器公约》，并自愿遵守该公约的有关规定。中国宣布自己曾实施过小规模的进攻性化学武器项目，但在1997年批准《禁止化学武器公约》前，已经取消了该项目，而且所有的化学制剂都已用完。中国可能具备技术能力生产化学战和生物战毒剂，而且中国有包括导弹和火箭在内的武器可以投送这些毒剂。

  

**太空能力和反太空能力。**解放军历史上一直负责管理中国的航天项目，而且也在继续投资以提升天基情报监视与侦察、卫星通信、卫星导航、气象、载人航天飞行等方面的能力。中国使用卫星和地面控制站等装备和设施来支持国家的民事、经济、政治和军事目标。解放军的战略家认为，使用天基系统的能力以及阻止敌人使用天基系统的能力，对现代信息化战争具有重要意义。因此，尽管解放军的公开立场是反对太空武器化，但解放军仍继续强化自己的军事航天能力。另一方面，中国继续开发多种反太空能力，以在危机或冲突中限制或阻止敌人使用天基资产。除研发并可能使用卫星干扰器和定向能武器外，中国还可能在动能反卫星武器（包括反卫星导弹系统）方面取得重大进展。

  

**网络空间力量。**解放军的权威著作认为，控制“信息领域”是现代化战争中获胜的先决条件，是在冲突中阻止外部势力干预的先决条件。解放军认为的信息领域包括网络、电磁频谱、心理领域、认知领域等。解放军可能利益网络战能力支援三个关键领域内的军事行动：第一，利用网络侦察搜集技术和作战数据；第二，利用网络攻击能力在冲突早期阶段建立信息优势；第三，将网络战能力与常规能力结合使用，作为力量倍增器。

  

**拒止与欺骗。**解放军利用军事欺骗来降低敌人侦察活动的有效性，使敌人无法掌握其作战意图、行动和主要目标。解放军很注重使用欺骗战术来获取非对称优势。

  

**后勤与国防工业现代化。**20世纪90年代以来，解放军开始重视发展“信息化”条件下联合作战所需的各种能力。过去二十年来，解放军投入了大量资源来提升作战保障能力。与此同时，解放军采取行动对国防工业基础进行现代化改造，以确保解放军发展所需能力来满足未来任务需求。关键领域包括军民融合、支援联合作战行动、高端武器研发等。

  

**四、未来展望**

中国的军事现代化是中国综合国力发展的一部分。未来几年里，解放军可能会变得技术上更先进，装备水平达到其他先进国家军队水平。解放军将继续采购先进的战斗机、海军舰艇、导弹系统、太空和反太空资产，以解决远离中国本土的21世纪威胁。
