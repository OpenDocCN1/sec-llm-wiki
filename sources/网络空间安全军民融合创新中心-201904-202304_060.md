# 美军为什么不应该创建新的网络军种？

美国企业研究所外交和国防政策部门访问研究员杰森·布莱辛博士撰文称，美国军方不应该成立独立的网络军种，而应专注于利用现有的网络部队实现更高的效率。

  

原因一：成立新的网络军种将造成美国网络司令部未来角色定位难题。文章指出，创建新的网络军种将导致美国网络司令部的最终解散或重新定义其与其他作战司令部的关系。如果美国网络司令部解散，现有的网络司令部和国家安全局“双帽制”将受到冲击，导致两种不良后果：一是国家安全局注重支持新网络军种的战斗职能，而不是整个美军的优先事项；二是给消除军事和情报运行的网络行动冲突设置了更大障碍，造成网络空间中民事和军事利益冲突。如果新的网络军种如网络司令部并存，将导致两个突出官僚问题：一是给面临预算停滞或缩减的美军带来不应有的负担；二是重新定义网络任务部队可能扰乱其他作战司令部，并在各军种间造成不必要的烟囱效应和内讧。

  

原因二：成立新的网络军种将抹煞现有军种在网络空间方面取得的重要进展。一方面，网络空间是现代作战的一个关键维度，网络空间并非独立于空中、陆地、海洋和太空的“领域”，其与军队的其他作战环境有着复杂的交叉和相互依存关系。鉴于数字世界和物理世界的融合，将网络空间规划隔离在新军种中几乎没有意义，将战略规划集中在专业军种中可能会导致“只见树木不见森林”。另一方面，网络空间从根本上以空中和太空所没有的方式与其他作战环境交互，网络部队更类似于特种部队，不能以建立独立的空军和太空军的方式来应对网络空间挑战。

  

文章指出，创建新的网络军种类似于用20世纪方案来解决21世纪问题，美国现有的网络部队结构为有效执行网络任务提供了坚实基础，美国应该专注于通过当前的网络部队结构实现更高的效率。优先事项包括：政策制定者应考虑如何让网络任务部队整合太空部队的新网络人员；美国网络司令部可以制定更具体的指标来评估结果和定义网络空间“成功”的构成要素；美国官员应该投入时间和资源促进民用情报和军事网络行动的协调和去冲突。

**建立更有效的网络部队而非更多官僚机制**

  

我们训练很刻苦，但似乎每次我们开始组队时，我们都会被重组。… \[我们\]作为一个国家，我们倾向于通过重组来应对任何新情况；这是一种很好的方法，可以用来制造进步的幻觉，同时产生混乱、低效率和士气低落。

——查尔顿·奥格本

  

什么时候需要进行军事重组，什么时候为了重组而重组？查尔顿·奥格本在二战期间担任麦瑞尔突击队通讯官期间对重组不利之处的观察，可作为今天的警示故事。

  

大卫·巴诺和诺拉·本萨赫尔最近呼吁美国建立一支与陆军、海军、空军、海军陆战队、海岸警卫队和太空部队相当的独立网络部队。这个建议并不新鲜，并且它提供了一定的优势。在战略层面，支持者认为网络军种将加速学说和能力创新。摆脱了现有军种狭隘主义的束缚，新军种中整合的专长可以使其将网络视为自身使命，而不仅仅是作为常规作战的推动者。从官僚角度看，它可以通过《美国法典》第10卷的授权解决网络人才缺口，根据与其他军种不同的标准和文化来组织、培训和装备人员。新军种的网络战士将像常规部队的人员一样融入联合作战和特遣部队，而其他军种将保留仅用于战术目的的网络人员和能力。

  

**尽管有这些好处，美国不应该为网络空间创建新的军种：这将是21世纪问题的20世纪解决方案。这可能会巩固网络空间独立于空中、陆地、海洋和太空的错误假设。实际上，对于网络空间而言，“领域”的概念更多是一种隐喻而不是实际描述，其与军队的其他作战环境有着复杂的交叉和相互依存关系。**正是由于这种动态，美国的部队结构应该反映将其数字能力与其动能能力相结合的需要。作为一个组织结构，美国网络司令部符合目标。**如果美国创建新的网络军种，美国决策者将面临关于网络司令部未来角色的严峻问题，并有可能忽视现有军种在网络空间方面取得的重要进展。虽然批评现有部队结构的要素如何协调和整合益处良多，建立新军种会浪费宝贵的时间、精力和金钱。相反，美国军方应该专注于利用现有的网络部队实现更高的效率。**

  

**有了新的网络军种，**

**美国网络司令部的命运是什么？**

  

作为一个统一的联合作战司令部，美国网络司令部从其陆军、海军、空军和海军陆战队军种组成司令部抽调人员。尽管美国网络司令部不能像军种那样直接招募、培训或装备人员，但它已经制定了联合标准，有助于协调军种管理和承包商提供的培训。与军种不同的是，美国网络司令部保留了作战权力，其作战努力的关键是网络任务部队（CMF），该司令部的“行动部门”。网络任务部队（CMF）由分为四类团队的军种组成部分构成：网络国家任务团队专注于识别和对抗对手；网络保护团队保卫国防部网络；网络作战任务团队开展行动以支持其他作战司令部；网络支持团队为其他团队提供分析和规划支持。

  

**任何关于独立网络军种的提议都会给美国的网络部队结构带来一个明显的问题：美国网络司令部会发生什么？建立新军种的倡导者通常没有解决这个问题。从逻辑上讲，创建新的网络军种将导致美国网络司令部的最终解散或重新定义其与其他作战司令部的关系。**

  

**第一种情况——美国网络司令部的解散——将面临“双帽制”（即美国网络司令部司令同时担任国家安全局局长）突然转变的风险。**这种安排促进了美国网络司令部《美国法典》第10卷军事网络能力和美国国家安全局《美国法典》第50卷网络情报能力的协调。通过将作战指挥官换成军种指挥官来重新配置与美国国家安全局的“双帽”关系，这将与美国网络司令部由不同军种的指挥官领导的方式形成鲜明对比。可以说，这种动态将经验和决策的多样性引入了战略和作战权衡中。**随着时间的推移，无论网络军种的“双帽”指挥官们是否有意，他们会塑造美国国家安全局的战斗支持功能，以适应军种级别的偏好，而不是军事范围的优先。**

  

在短期内，用网络军种取代网络司令部也会破坏军方获取驻留在美国国家安全局的基础设施和专长，而新军种则专注于建立自己的官僚机构。鉴于美国网络司令部本身没有满足国会关于与国家安全局分离的要求，这是不明智的。从长远来看，此举将赋予作战指挥官独立网络行动的作战权力，他们可能不熟悉其全部功能。虽然这最终可能会迫使其他作战司令部提高他们的网络能力，但也**可能为消除军事和情报运行的网络行动冲突设置更大的障碍。与传统战争相比，大多数网络冲突更类似于间谍活动，当前由美国网络司令部主导的“双帽制”充当了权衡网络空间中相互竞争的民事和军事利益的机制。没有它，作战指挥官间的网络作战权限分配将为军事和民间机构提供多种新的冲突途径。**

  

**在第二种更可能的情况下——与网络司令部一起建立网络军种，类似于目前的太空部队和太空司令部的设置——两个官僚问题显得很突出。首先，建立新军种及其各自官僚机构的间接成本会给仍在努力实现现代化并可能面临预算停滞或缩减时期的军队带来不应有的负担。**上述成本对于一个新军种而言是不可避免的，但鉴于网络司令部的持续发展也需要网络专用资源，因此在这种情况下会更加严重。即使降低启动成本的建议，例如将网络军种置于空军之下，也忽略了可能因创建新官僚机构而导致的机构过载。我们可以看看空军网络司令部（临时）的兴衰，这是一个临时司令部，于2006年在空军将其任务扩展到包括网络之后成立。时任空军部长迈克尔·韦恩责成第8航空队（以其远程核轰炸机而不是网络能力而闻名）成立该司令部。除了扩大第8航空队的职责外，空军领导层对网络任务几乎没有概念上的限制，对该司令部与其他军种和作战司令部的关系也几乎没有给出指导。空军也未能为该司令部分配任何新资金。这些挑战造成第8航空队负担过重并对其核任务造成损失，最终导致空军暂停该临时司令部。尽管第16航空队（空军网络部门），即空军对美国网络司令部的贡献，为今天剥离新的网络官僚机构提供了更合乎逻辑的基础，但先前努力凸显了在没有提供适当愿景和资源的情况下彻底改革组织结构的陷阱。这是一个重要的教训，尤其是在空军已经在分散其资源来支持太空军的情况下。

  

**其次，与美国网络司令部一起建立网络军种需要重新定义网络任务部队，更具体地说是重新定义分配给其他联合作战司令部的网络作战任务团队。**新网络军种的组成部分会取代当前的网络作战任务团队吗？或者这些团队是否会扩展，以与现有军种组成部分一道纳入新的网络军种要素？在这里，太空部队和太空司令部之间的关系提供了一些见解，因为这两个机构仍在理清与其他作战司令部的联系。**这****两种选择都有可能扰乱其他作战指挥部，并在各军种间造成不必要的烟囱效应和内讧。**

  

**网络部队结构应包括现有军种**

  

网络军种倡导者的一个共同假设是，现有军种对维护传统系统更感兴趣，而不是解决网络空间问题。虽然网络作战确实不是作战军种的主要功能，但这一假设忽略了军种历史上为将网络纳入其组织所做的大部分工作。此外，这些军种正在开发新的框架，以结合其他军事手段使用网络作战。例如，围绕“多域”作战学说的新想法一直是陆军陆军前瞻性学说发展的关键部分。这些军种可以而且当然应该做更多的事情来专注于建立具有网络意识的文化。然而，这并不是军队独有的，新的网络部队对于影响整个国防部的文化问题也不是灵丹妙药。

  

**正是因为网络空间是现代作战的一个关键维度，将战略规划集中在专业军种中可能会导致“只见树木不见森林”。特定于网络的军种提供的专长很可能比其他军种中所现有的专长更深入，但这样做的代价是更广泛的战略和作战范围。**美国网络司令部已经证明自己有能力开展独立作战和支持更传统的反恐工作的作战。在后者的情况下，战略司令部之下的联合特遣部队阿瑞斯开展了“发光交响乐行动”，这为网络空间作战与常规作战一体化提供了一个重要的先例。虽然美国网络司令部保留了对特遣部队的指挥控制，而不是战略司令部，但这次行动为常规部队提供了一些经验教训，并为未来网络部队与常规部队间的“协调火力”奠定了基础。**鉴于日益认可的数字世界和物理世界的融合，将网络空间规划隔离在新军种中几乎没有意义。**事实上，鉴于网络司令部不断增强的采购能力和可能的网络任务部队扩张，这将是能力整合的倒退。

  

许多独立网络部队的支持者指出，建立独立的空军和太空部队是建立以网络空间为重点的新军种的重要先例。这种类比具有误导性。**网络空间从根本上以空中和太空所没有的方式与其他作战环境相交。以军种结构应对网络空间的挑战，就好像它们与空中、陆地、海上和太空中的挑战属于同一类型。许多挑战并不是。**在这方面，组织网络部队的一个更恰当的类比是特种部队，该部队反映了一种跨环境运作且在功能上根深蒂固的力量。网络部队和特种部队之间存在一些重叠，该类比实际上在促进关于创建网络司令部的早期讨论中发挥了作用。

  

**需要改进的强大基础**

  

**美国应该专注于通过其当前的网络部队结构实现更高的效率。在优先事项中，政策制定者可以考虑如何让网络任务部队整合太空部队的新网络人员。**尽管太空部队处于构建其网络能力的早期阶段，但其仍然没有向美国网络司令部派遣团队的计划。

  

**更紧迫的是，美国网络司令部可以制定更具体的指标来评估结果和定义网络空间“成功”的构成要素。这将需要明确制定网络空间战略，定义其与其他作战努力的关系，详细说明其运作方式，并始终如一地衡量结果。**美国网络司令部已经制定了评估战备情况的可比较指标。然而，假设这些指标与效率度量相同是错误的。

  

**美国官员还应该为民用情报和军事网络行动的协调和去冲突投入时间和资源。**英国的国家网络部队提供了一种提高效率和减少官僚冲突的潜在模式。**追求更高的效率和与民用情报部门的合作可能不可避免地需要组织变革。但独立的网络军种不是答案。**

  

**美国现有的网络部队结构——由美国网络司令部及其当前的军种级别组成部分构成——为有效执行网络任务提供了坚实的基础。美国应该让这种部队结构更好地运作，而不是通过创建新的独立军种来破坏其进展。**

  

**网络空间安全军民融合创新中心**

奇安信集团网络空间安全军民融合创新中心，作为军地沟通、军地协同的网络空间安全产业发展平台，聚焦网络空间国防安全领域，探索建立网络国防安全建设创新发展模式，致力于打造网络空间安全领域的民间智库。
