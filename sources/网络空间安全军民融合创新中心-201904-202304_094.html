英国国防部于11月27日发布指导文件《陆军数字化：THEIA》，阐述陆军数字化计划THEIA总体情况、出台背景、整体目标和具体措施。文件提出，为在现代信息战环境中竞争并广泛整合各作战域效果和国家资源力量，陆军需要进行数字化转型，利用创新、研究和试验来更好地实现陆军使命任务。


THEIA计划长期目标定位于：一是紧跟世界技术演变，保持英国在新作战环境下的作战竞争力；二是确保英国陆军与合作伙伴、盟友之间保持互联互操作，并以数据为导向；三是缩短交付成果时间。短期目标定位于：一是改变数字文化和行为，使陆军人员掌握数字技能，并推广新的数字工作方式；二是提供数字骨干网和多域战术云，以集成来自各域、合作伙伴和盟友作战信息；三是提供更好的数据，以做出更好的决策并提高竞争力、效率和效力。


THEIA寻求对架构、设计权限、安全和标准采取更加协调一致的方法，为此陆军将开展五大举措：一是推动数字化格局的连贯性和集成性；二是打破陆军各部门的“数字孤岛”；三是与利益攸关方就数字化建设开展交流；四是通过数字计划来展示提升效率成果；五是统筹数字化整体计划。为推动THEIA数字化计划，陆军将开展四项努力：一是设计数字化运作模式；二是保持数字一致性；三是建设数字骨干网；四是研究端到端数字流程。为加速THEIA数字化计划，陆军将聚焦六大重点：一是数字资产；二是业务信息、整合和利用；三是装备信息利用；四是数字技能基础；五是野战部队数字化；六是数字陆军流程。

《陆军数字化：THEIA》


THEIA将通过以下方式加快陆军数字化转型的交付：促进连贯；加强项目间的整合；打破孤岛并提升效率。


2020年11月27日发布


THEIA将组织陆军数字化现代化的总体计划，以协调资金、问责和责任。


一、介绍


THEIA（“THAY-A”）是陆军数字化的名称，其利用数字化信息和数字技术来改善业务和社会流程。它是综合审查（IR，译注：全称为“安全、国防、发展和外交政策综合审查”，目前正由英国政府开展，计划于2021年发布审查结果）、英国陆军陆上作战概念（BALOC）和陆军作战模型（AOM）审查的核心，由陆军执行委员会（数字化ExCo）召开的一个专门季度会议进行管理，由副总参谋长主持。


数字化执行委员会认同数字化是每个人的事（不仅仅是陆军信息部）；它需要在陆军范围内进行大规模变革，着眼于已确定的数字助推器，并承诺为早期产出提供资源。


THEIA将跨陆军职能运作；“堤岸”（EMBANKMENT）是陆军对政府综合审查（IR）的投入和回应，因此正在寻求对架构、设计权限、安全和标准采取更加协调一致的方法。


为此，THEIA将：


#

推动连贯性和集成性

众多的变更计划和孤立治理使数字化格局变得混乱且不一致。EMBANKMENT和综合审查（IR）都寻求一种更加协调一致的方法，尤其是在体系结构、单一设计权限、安全性和通用数据标准方面。

#

打破孤岛

数字化需要通过在陆军各职能部门之间横向推广新的数字化工作和运营方式来改变文化和行为。这将注入陆军作战模型。

#

与利益攸关方交流进展与成功

既在陆军内部也在国防领域。

#

捕获效率

通过展示数字计划的部署及其对国防计划设想的变动来展示效率，从而证明初期和持续的获益。

#

统筹整体计划

专注于使资金、问责和责任保持一致的可操作活动。


二、THEIA（数字化）目的


  • 随着世界应对技术变化的演变，我们敌人的冲突方式以及我们的应对方式都需要以相同的速度演变；英国陆军必须保持竞争力，提高相关性，从而以这种新方式开展作战和战斗。我们将冲突视为“战略竞争”，从总部到战术端，我们必须更快速、更精简、更高效。


  • 确保英国陆军与合作伙伴、盟友之间保持互联互操作，并以数据为导向。


  • 在几个月而不是几年内交付效果。


三、THEIA（数字化）目标


  • 改变数字文化和行为，使我们的人员掌握数字技能，并推广新的数字工作方式。


  • 提供数字骨干网和多域战术云，以集成来自各域、合作伙伴和盟友的指挥控制、情报、传感器、操纵装备和平台的所有信息。


  • 提供更好的数据，以做出更好的决策以及更好的行动性和集体性竞争力、效率和效力。


四、背景


自冷战结束以来，综合审查（IR）是对英国外交、国防、安全与发展政策的最大规模审查。一个关键特征将是在维持一支特遣队与迅速采取行动以预先解决威胁之间的适当平衡方面进行政策讨论。如今可以证明效果的基于信息的能力，例如网络和信息作战，无论在进攻还是防御上都可能受到高度重视。此外，在持续竞争的时代，通过利用和整合细微的防御和安全选项来慑止、破坏和挫伤潜在对手的能力变得越来越重要。


俄罗斯特种部队的弗拉基米尔·克瓦契科夫在基尔·吉尔斯《俄罗斯信息战手册》中（罗马：北约国防学院，研究专著，2016年）宣称：


“出现了一种新型的战争，在这种战争中，武装战争已经将其在实现战争的军事和政治目标方面的决定性地位让位于另一种战争——信息战。”


显而易见的是，现代作战环境的需求以及综合审查（IR）要求国防部跨所有五个领域（陆、海、空、太空、信息）与其他军种、政府部门和盟友进行整合，并提供覆盖范围、响应速度和敏捷性。同样，也需要新的和最先进的技术来跟上对手步伐。但是，要在信息战中竞争并广泛整合效果，国防部需要做的不仅仅是购买新技术。其需要进行数字转变。


THEIA，陆军的数字化转型，将利用创新、研究和试验来更好地实现陆军保卫国家、保护我们的人民、投射影响力和促进繁荣的目的。它将利用“陆地环境战术通信和信息系统”（LE TacCIS）等新技术来构建，由强大的现成数据数字骨干网构成，并通过对上进人员的专家培训来增强。这是一种以用户为中心的数字文化，它使各个级别的领导人都能做出更知情、更好和有力的决策。但是，为了做出更好的决策，个人需要可信准确的个人和机构数据。同样，全军在“数字时代技能”上的投入将使我们的人员具备充分利用数字和数据功能的手段和思维。


五、助推器


陆军运作模式


我们将支持定义一个新战略中心；设计权威机构（Design Authority）的角色和组成、业务架构及其与数字架构的配合方式。


数据一致性


与国防部数字防御（Defence Digital）机构合作，开展企业数据治理并制订标准，同时推动陆军在战术端利用数据的需求；创建“数据学说”。定义我们在哪里存储数据以及如何交换数据（终端还是集中）；我们如何进行终端分析（增量存储）并回传更新。


数字骨干网


我们支持通过国防部门交付数字骨干网；帮助提高对BATCIS（战场和战术信息系统）及其交付内容的理解，实现最佳化，并使用易于获得的商业技术。


端到端流程（E2E）


作为目标架构审查的一部分，美国陆军将研究自己的端对端（E2E）流程，以将数据从“刺刀”获取到总部，并使用能力用例研究所有E2E流程，评估当前性能、可交付性、成本、能力、弹性和延迟。我们将了解计划相互依存关系，以增进“陆地环境战术通信和信息系统”（LE TacCIS/“信息监视目标获取与侦察”（ISTAR，译注：陆军的战场物联网项目）与“陆地网络”（Land Cyber）之间的理解，它们在网络上的如何分布，以及需要更新哪些设想。


六、加速器


我们已经确定了6个加速器；THEIA团队与陆军的职能领导一起，将有效地启动数字化水泵并取得早期成功。这些加速器将以赋能活动为基础：


#

数字财产

将由陆军基地和基础设施（DB＆I）部长领导，由陆军信息部长（D Info）支持，并由国防基础设施机构（DIO）启用。已经确定了三个组成部分：首先，可持续性和效率——收集分散的数据以创建一个整体的能源管理系统，以识别当前在能源花费上的节约资金以重新投资到资产上。其次，利用新的DIO拥有的未来国防基础设施服务（FDIS）合同——利用资产数据激励通过收益分享的更佳行为。最后，整体财产资产管理，与DIO创建一个通用数据环境，以创建资产监控的行业最佳实践级别。

#

业务信息、整合和利用

业务信息、整合和利用将由总参谋长助理领导。已经确定两个组成部分，用以提高我们访问业务信息以更好地为决策提供信息的能力。首先，识别并了解跨所有领域、来源和数据输入点所用当前系统的企业架构；其次，通过改进重复和数据定义来提高数据质量，以改善决策质量。

#

装备信息利用

将由陆军支援部长（D Sp）领导，并由国防装备与支持机构和行业合作伙伴推动。在当前活动的基础上，D Sp将进一步发展预测性维护以及从多个平台和库存系统提取数据的自动化，以准确地监视和计划陆军部队的维护。THEIA将审查所有系统的业务架构，以帮助减少维护部队的年度支出。

#

数字技能基础

将由陆军人事部长（D Pers）领导，并进入野战部队。THEIA将完成对数字技能的成熟度评估，最初将重点放在陆军总部，以提升我们的才华横溢的员工队伍技能，使其成为数字时代的领导者；这将确定所需的教育途径并确定数字培训的要点。THEIA也将进入野战部队，以帮助创建一支精通数字技术的劳动力，通过适当采用快速发展的技术来保持竞争力。

#

野战部队的数字化

 THEIA将发展迄今为止进行的出色工作，提供概念证明，并将“我的系列”（My Series）应用程序使用为有用的功能，以将信息集汇总在一起，并为野战部队司令/陆军作战司令部提供从个人训练到单元和编队状态的清晰战备感知，同时改善我们士兵的生活体验。

#

数字陆军流程

将由陆军内政司令部领导，并以陆军人事中心（APC）的成功工作为基础——陆军数字团队已经构建了陆军职业管理工具；将基于纸张的手动流程自动化到一套数字集成的工作流程中，例如晋升委员会和职位分配。进一步的工作将着眼于劳动力繁重流程的自动化，用于降低劳动力成本的企业服务现代化，以及用于完成管理任务并向更广泛人员传达关键信息的在线应用程序的开发和使用。


七、作为战略资产的数据


我们必须确保我们根除独立电子表格、孤立和重复信息的时代，并迎来一个所有人均可使用准确、可信和权威数据源的时代。其紧密联系并支持循证决策。历史上，许多决策者都依靠本能和经验来做出关键决策。但是，在数字数据时代，信息可以以毫秒为单位进行分析、评估和可视化。陆军数据分析小组（ADAT）现在拥有技术完成上述任务。THEIA将在预想直觉之上培育并嵌入一种寻找和使用数据的文化。


我们知道，可信内容必须易于使用并且对我们的人员具有吸引力。陆军数字服务机构（ADS）已创建My Series应用程序。现在，国防网关上托管的My Series应用程序使“任何设备”都可以访问重要的自助服务功能，例如请假应用程序、检查工资单或提交差旅或食品索款，而无需排队等待国防部网络（MODNet）终端。THEIA将寻找更多类似于My Series的机会，轻松、快速、准确地将数据送达给我们的人员。


八、整合是未来


陆军首席信息官（CIO）、信息部长乔纳森·科尔将军2020年3月10日在皇家三军联合研究所集成信息机动会议最后发言：


“让我们大胆一点：没有信息优势，就不会有综合行动。没有（联合）信息机会就没有信息优势。我们正在提供信息机动……这需要各种形式的集成：


  • 在陆地环境中结合联网、情报、影响、网络和反情报五个能力领域 

  • 在现实机动和信息机动之间

  • 在更广泛的联合、联盟和伙伴企业中

  • 通过培训、人员和文化

  • 拥有尖端数字技术的物理平台

  • 以数据为关键资产


集成是关键词。还有很长的路要走，但是我们正在路上。”
