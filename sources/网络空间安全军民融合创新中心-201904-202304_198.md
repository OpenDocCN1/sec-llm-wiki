# 美国联邦政府拟在未来3至5年完成IPv6过渡计划

美国联邦管理和预算办公室（OMB）3月2日发布IPv6过渡计划新草案指南。指南要求，**最晚4月底前,各联邦政府机构必须提交本部门的“下一代互联网协议（IPv6）”实施计划。**

  

01

**背景情况**

IPv6是英文“Internet Protocol Version 6”（互联网协议第6版）的缩写，是互联网工程任务组（IETF）设计的用于替代IPv4的下一代IP协议。

  

近年来，随着物联网、工业互联网和人工智能等产业飞速发展，IPv4地址资源日益枯竭。而IPv6地址长度为128位，是IPv4地址长度的4倍。IPv6的使用不仅能极大地增加网络地址资源数量，还能清除多种接入设备连入互联网的障碍。

  

互联网数字分配机构（IANA）曾在2016年向国际互联网工程任务组（IETF）提出建议，要求新制定的国际互联网标准只支持IPv6，不再兼容IPv4。

  

据APNIC等国外权威机构统计数据显示，近年来IPv6 部署在全球迅速推进，主要发达国家IPv6部署率持续稳步提升，部分发展中国家推进迅速。比利时、美国等国IPv6部署率已超过50%。

  

02

**美联邦政府加速推进IPv6计划**

  

美国政府一直高度重视IPv6发展，2012年发布《政府IPv6应用指南/规划路线图》全面推动IPv6的商用部署。

  

美国四大移动运营商在LTE网络建设中同步要求全面支持IPv6，其中AT&T Wireless、Sprint和Verizon Wireless LTE网络支持IPv4/IPv6双栈，T-Mobile USA LTE网络支持IPv6-Only单栈。在宽带网络方面，AT&T、Comcast以及Google Fiber网络都已支持IPv6，其中AT&T和Comcast的IPv6用户访问量分别占到58.21%和46.75%。

  

美国主流商业网站包括Facebook、Google、Tritter、Youtube、Linkin等全面支持IPv6，特别是Facebook数据中心内部已部署IPv6-Only的网络，90%的流量通过IPv6承载，通过IPv6网络访问Facebook的流量已经超过IPv4网络。Google全球IPv6用户访问占比已达25%，苹果应用商店要求APP必须支持IPv6-Only标准协议的规定也会推动在移动互联网领域提供更多的IPv6 用。

  

总的来说，通过近几年的快速发展，美国在IPv6商用化部署进程中已形成终端、网络和内容协同发展的良好局面，步入IPv6发展的市场化快车道。

  

美国联邦首席信息官苏泽特•肯特认为，全面过渡到IPv6是确保互联网技术和服务未来增长和创新的唯一可行选择。联邦政府应在前期努力的基础上，扩大和增强其向IPv6过渡的战略承诺。

  

03

**联邦政府未来3至5年的实施目标**

  

根据OMB新发布的IPv6实施计划草案指南，未来3至5年，联邦政府机构所有部门都必须明确本部门的举措，包括政府范围内和特定机构的行动。

  

新指南要求，各政府部门必须在4月底前提交本部门的IPv6实施计划，明确具体工作目标，其中包括：

  

*   在确定本部门IPv6实施计划后的45天内，成立本部门IPv6团队并为其配备相关人员；
    

  

*   在接到新指南通知后180天内，在网上发布包含路线图的IPv6政策，确保所有新部署的联邦系统在2023财年之前都启用IPv6；
    

  

*   在2021财年末，完成至少一个IPv6试验并向管理与预算办公室（OMB）报告；
    

  

*   在2021财年末之前，制定一个IPv6实施计划，以实现未来3至5年任务目标：**到2023财年末，联邦网络上使用IP的资产中使用IPv6的占比应达到至少20％；到2024年至少达到50％；到2025年至少80％。**
    

  

  
  

**网络空间安全军民融合创新中心**

  
  

作为我国首个军地沟通、军地协同的网络空间安全军民融合发展平台，中心聚焦网络空间国防安全领域，探索建立网络国防安全装备建设的军民深度融合创新发展模式，致力于打造成为我军装备发展网络空间安全领域的民间智库。
