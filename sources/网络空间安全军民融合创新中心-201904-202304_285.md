# 伊朗全国切断互联网

估计现在伊朗人民最期待钢铁侠马斯克的“星链”计划尽快实现了——在太空由约1.2万颗卫星组成的卫星网络，在全球任何一个地方都可以随时接入互联网。

  
切断不是屏蔽。屏蔽可以通过技术手段实现上网，而断网则是物理手段，根本连不了网。

  

**1**

  

据法新社的报道,伊朗多家网络运营商已于11月16日暂停服务,伊朗全国已处于断网状态。 

  

伊朗国家通讯社随后的报道说，伊朗政府最近关闭了全国范围内的互联网接入，伊朗全国所有民众的电脑和手机将无法正常上网，是为了制止报道在全国范围内爆发的抗议活动。

  

美国IT巨头甲骨文称之为“伊朗史上最大规模的断网事件”。 伊朗全国8000多万人口，超过60%的人口年龄在30岁以下，上网是他们日常生活中不可或缺的部分。

  

**2**

  

早在2012年4月，伊朗信息和通信技术部长曾宣布开展“清洁网络”计划，建立全国局域网。届时，伊朗将永久关闭国际互联网，和屏蔽所有国外的社交网站、搜索、资讯和邮箱等服务，由政府提供的服务来取代。 

  

伊朗“清洁网络”计划分两个阶段展开。第一个阶段，Google、Hotmail和Yahoo将会被屏蔽，由政府推出的局域网提供诸如此类的服务来取代，如“伊朗邮件”(Iran Mail)和“伊朗搜索”(Iran Search Engine)。所有政府提供的互联网服务并且全部实行实名制，注册只有在身份被证实后才能生效。

  

 第二阶段将，伊朗将永久关闭互联网。政府声明称，届时所有互联网服务只能由国内局域网提供。新系统类似于公司局域网，只允许管理员访问已批准的页面。国外网站不是完全不能访问。政府还将制定一份“白名单”，用户可以访问名单上的外国网站。

  

**3**

  

尽管“清洁网络”计划是伊朗政府2012年提出，但时至今日，在伊朗，被屏蔽的社交媒体脸谱和推特，却是最受年轻人欢迎的网络。

  

2013年9月国外媒体报道“伊朗国内已经完全解封Facebook和Twitter”，之后几小时Facebook和Twitter又被屏蔽。后来伊朗通信官员称，该国用户之所以可以短暂访问Facebook和Twitter是因为当地一些网络服务提供商出现了技术故障。 和我们喜欢用微信一样，伊朗人非常喜欢的社交app是WhatsApp和Telegram，这是伊朗人最流行的两款IM应用。在GooglePlay伊朗的热门榜上，这俩App长期占据首位。当谈论一些“敏感”话题的时候，WhatsApp里的伊朗好友会切到Telegram用隐私模式聊天。

**4**

  

受教育程度越高的人群，日常工作和生活对互联网依赖就越大。伊朗年轻人热衷互联网的背后也是如此。

  

伊朗全民识字率高达 98%，早在2012年伊朗适龄人群进入大学读书的比例已经超过55%。也就是，全国至少一半的年轻人都接受过大学教育，由此大大推动了对信息的渴望。 根据伊朗青年与体育部的报告，在伊朗数千万青年中，69.3%的人使用各种科技手段，如服务器和虚拟专用网络（VPN），来链接被屏蔽的海外网站。 目前，伊朗拥有中东地区最大的手机用户市场，伊朗的家庭宽带入户率近65%，移动电话普及率达到 136%，据估计有 8320 万手机用户，超过4000万使用智能手机。 尽管在互联网自由度排行榜上，伊朗被美国某些团队排在最后一名，可实际上伊朗人上网既便宜、又快捷（宗教学校的网速最快，因为宗教人员需通过网络布道，因此能优先使用光纤通讯电缆）。 

  

**5**

  

伊朗的全国抗议活动，始于政府计划将油价大幅上涨。伊朗拥有世界第四大原油储备，汽油廉价向来被伊朗公众视为与生俱来的优势。 尽管伊朗自1979年伊斯兰革命以来经历了数十年的经济困境，但外国游客的第一感受是，伊朗首都德黑兰的人过得并不艰难，一些有着洋气名字的高档购物中心正在建造，大街上不时有保时捷等豪车驶过。 看上去，“经济制裁没对伊朗的上层社会造成太多影响”，德国《明镜》周刊称。 而对于伊朗国民，数十年的制裁却让他们的储蓄在稀缺的工作岗位和本国货币里亚尔的崩溃中蒸发，石油大幅涨价只是这场抗议活动的导火索而已。

  

一位网友评论说，“任何以民生为敛财工具的，最终都会被人民抛弃。”

  

**6**

  

除了伊朗，很多国家也有断网先例。2017年8月，印度交通部发布新的详细规定，正式赋予印度各邦和中央政府断网的权力。  

  

报道称，自印度现任总理莫迪上台以来，印度近年来断网次数大幅增长。根据新德里“软件自由法律中心”的数据，仅在2017年1月至8月之间，印度政府就已经下令断网42次。而2014年莫迪上台时，全年断网次数仅为6次。2012年，印度只有1个邦断网，今年的断网范围已经扩大到11个邦。

![](../Images/7111b12a0600958676e67b19a4732508.png)

  

据英国广播公司（BBC）报道，俄罗斯政府2019年开始考虑部署“断网计划”，在重大事件发生时可以，断开国内网络用户和全球互联网的连接。俄罗斯官方称，这是“作为其网络防御性能测试的一部分”。去年，俄罗斯政府已向议会递交了相关的法律草案，草案中明确阐述了“断网”所需的互联网技术变革——这项名为“数字经济国家计划”的草案，要求俄罗斯的互联网服务提供商，可以确保自身在隔绝外国网站的情况下，仍然能够在线运作。
