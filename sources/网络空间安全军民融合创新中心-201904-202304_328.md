# 纵横捭阖 捍卫网空——第二届“纵横”网络空间安全创新论坛

按照中央网信委2019年度工作安排，定于**2019年10月28日**在安徽省合肥市天鹅湖大酒店召开**第二届“纵横”网络空间安全创新论坛**。

  

论坛主题为**“新技术、新挑战、新安全——军民共筑网络空间安全”**，由军事科学院系统工程研究院、国防科技大学电子对抗学院牵头，联合国家计算机网络应急技术处理协调中心、中国信息安全测评中心、安徽省委网信办等单位共同主办，依托信息系统安全技术重点实验室、中电科网络空间安全研究院、远望智库、中国电子六所、奇安信集团、中新网安、安天科技等军地有关单位联合承办。

  

本届论坛由**主论坛**，以及**“网络空间战略博弈”**、**“网络空间安全人才培养”**、**“前沿技术与网络空间安全”**、**“网络空间自主创新与安全生态”**四个分论坛组成。

  

主论坛邀请院士、知名专家、企业名人发表主题演讲，聚焦网络空间安全发展新趋势，探讨军民携手共筑网络空间安全的发展新思路。
