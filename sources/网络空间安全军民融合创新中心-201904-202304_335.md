# 探究未来智能化作战的基本样式

智能技术的广泛应用推动作战制胜机理发生重大变化：一是智能力超越火力、信息力成为决定战争胜负的首要因素；二是控制取代摧毁成为征服对手的首选途径；三是在作战体系中，集群的效果有可能超过集中兵力的效果。与之相适应，未来智能化战场上，敌对双方围绕智力展开角逐的“三算战”、围绕控制展开角逐的“三脑战”“三网战”、围绕集群展开角逐的“三群战”，以及基于新概念新机理衍生出的“全电战”，将会成为智能化作战的基本样式。

  

***1***

**“三算战”——算法战、算力战、算数战**

  

智能化作战的关键是夺取“制智权”，围绕“制智权”展开的系列作战行动，就成为智能化战场上的主要行动。首当其冲的就是贯穿全程的“三算战”：算法战、算力战和算数战。算法战，用于智能化战场上的各种源代码之战，体现着智力制胜的作战机理；算力战，用于智能化战场上的各种计算能力之战，体现着速度制胜的作战机理；算数战，用于智能化战场上的各种数据之战，体现着大数据制胜的作战机理。未来智能化作战，不仅是打出来的，更是算出来的。华为总裁任正非曾说过，华为手机照相功能不是拍出来的，而是算法算出来的，是将一束光线模仿人眼分解成千万个算点进行快速计算后形成的图像画面。谷歌公司研发的通用棋类人工智能“阿尔法·零”，采用优化算法和提升计算能力，只需数小时学习，就能战胜此前各种棋类的最强人工智能系统。算法、算力和算数是当前主流人工智能的三大要素，也将成为智能化作战激烈角逐的关键领域。

  

***2***

**“三脑战”——脑控战、控脑战、融脑战**

  

认知域是产生感知、认知和决策的作战域，随着纳米武器、生物科技、人脑认知、脑机融合等新兴技术的突破，必将使战场争夺焦点从物理域、信息域向认知域加速转移，基于脑控战、控脑战、融脑战的“三脑战”已具备实验验证和装备转化的技术基础。“脑控”主要是通过脑机接口，将大脑神经活动产生的脑电波，转化为可以被计算机识别的控制指令，实现基于意念的武器装备智能操控。经“脑控”技术物化形成的脑控武器，有望彻底颠覆武器装备操控手段，大幅减少人员伤亡。“控脑”主要是通过物理、化学等手段作用于人脑，达到影响人类思维、控制大脑活动的目的。使用无人平台搭载微型控脑武器，对敌关键指挥员进行意念控制，能彻底改变精确斩首作战样式，实现“不战而屈人之兵”的作战目的。“融脑”主要是运用人工智能技术将大脑与计算机进行高度融合，实现人脑逻辑思维和计算机高速计算的优势互补，用计算机模拟指挥员筹划作战活动、定下作战决心、处置突发情况等，并有望实现战役层面的智能化指挥控制。

  

***3***

**“三网战”——电信网战、工控网战、无线网战**

  

随着现实世界与网络世界融合程度不断加深，网络空间的博弈日趋激烈并映射到现实物理世界。基于电信网络空间、工控网络空间和无线网络空间等专业领域的斗争，已跃然于主战领域并将成为智能化网络战的典型样式。电信网战，主要指在国际通信网、长途通信网、移动通信网、城域网等国家骨干通信网络中发起的攻防斗争，多以P节点和PN节点路由器为主要攻击目标，达成广域范围内通信瘫痪、网络中断或数据窃秘等目的。工控网战，主要针对各类工商业属性的智能化设备密集的大型网络所发动的攻防作战，如国家电力网络、银行金融网络、水利工程网络等等。通过对工控网的核心接入设备实施专业化网络攻击，致使设备运行异常、失效等以实现对目标系统的整体瘫痪或损毁。自2019年3月起，委内瑞拉多次发生全国范围的大面积、长时间停电，背后原因疑似其核心电网、水利网同时遭受网络攻击所致。

  
无线网战，主要针对以无线电磁信号为主的信息网络（含战场无线组网）进行的攻防作战，是当前普遍运用的作战样式，也是未来战场上网络战的重要手段。通过暴力破译、密码入侵或伪装潜入等网络攻击方式，接入敌方开放式链路中的内部网，实现对其致瘫、窃密、阻塞、诱骗或干扰等目的。2019年6月，伊朗击落美军RQ-4C“海神”无人机后，两国由军事对垒升级为军事对抗。美国最终否决对伊朗发起常规打击，而是首选网络攻击战，致瘫伊朗部分控制火箭和导弹发射的计算机系统。伊朗则毫不示弱，于7月向世界公开其自主研发的“Sepehr-110”战场战术通信系统，声称该系统能够承受美军发起的网络战攻击，确保对部队实施有效指挥控制。

***4***

**“三群战”——雁群战、蜂群战、舰群战**

  

智能化集群装备可大幅突破传统部队在作战时间和空域方面的限制，正在改变战争面貌。随着无人装备自主程度提升和价格逐步降低，未来战争的“兵力”可以大批量地生产复制，部分传统人力装备的作战效能迅速“贬值”，攻防装备体系的平衡关系重新构建，大国在利益攸关区的博弈有可能实现“机器代理”。未来智能化作战，从自主平台的控制方式看，可分为传统的独狼式，以及正在发展的雁群式、蜂群式、航空母舰群式等。  

  
雁群式主要用于解决不同智能体的组合问题，大量不同功能的智能化无人作战系统混合编组，可形成集侦察探测、电子干扰、网络攻击、火力打击于一体的作战集群，从多方向或对同一目标或目标群实施多波次攻击，快速致其损毁瘫痪。蜂群式主要用于实现无中心群体效应，没有固定程式，自主协同攻击，通过密集数量优势发动“饱和式攻击”以战胜敌人。

  
航空母舰群式主要用于按需投放/回收的需要，可在更为广阔的战场区域进行集群覆盖式作战。每艘“航空母舰”扮演“武库机”角色，通过海上机动（或者空中机动）至作战防区一定距离后，发射无人艇群（或者无人机群）对目标实施攻击，母舰并不撤离，待无人艇群（或者无人机群）完成任务回收后再返回基地。美海军构想未来在25分钟内投放上万只低成本的微型无人机群，一次性可覆盖4800平方千米战场区域。在基于云环境支撑下，以雁群战、蜂群战、舰群战为代表的“三群战”，可实现自主式路径规划、分布式广域监视、序贯式积效攻击、饱和式全向杀伤，强力支撑未来全维立体式智能化作战。

  

***5***

**“全电战”——激光战、微波战、电磁炮战**

  

电能武器是继机械能武器、化学能武器之后，世界各国竞相研发的新一轮革命性武器平台。以激光、高功率微波、电磁炮为核心的全电能武器属于新概念武器范畴，具有高风险、高回报等特点，一旦实现关键技术突破，可能在装备性能和交战模式等方面带来颠覆性的变化。未来激光武器可集成到地面车辆或机载平台，KW级功率光电对抗装备可对××km内目标实施干扰，MW级功率高能激光武器系统可对××km距离目标实现硬毁伤，满足战术固体激光武器的实战化要求。高功率微波武器可应用于空间攻防对抗、反精确打击、信息对抗等领域，既具有战略威慑作用又具备战术应用价值，可以达成不同的作战目的。

  
如地基微波武器（固定或车载）可在××km范围内攻击集群无人机、电子战无人机等目标，空基微波武器（无人机或巡飞弹）可在××m范围内攻击无人机、智能装备、简易爆炸物等目标，也可作为防空反导武器在××km范围内拦截反辐射导弹、巡航导弹、制导炸弹等来袭目标。电磁轨道炮具有发射初速高、能量灵活可控的特点，既可对来袭空中目标进行拦截，又可对××km范围内陆、海目标进行远程火力打击。
