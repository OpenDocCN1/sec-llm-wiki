# 美国空军研究实验室成为首个国防部IBM量子计算网络中心

美国空军研究实验室（AFRL）宣布加入IBM量子计算网络（IBM Q Network）社区，成为其中一个IBM量子计算网络中心。此次合作将为美国空军带来量子技术的新能力，AFRL将借此致力于开发最新的通用型近似超导量子计算机。

![](../Images/9f7f389ef4a11a0034567e12ec81b000.png)

  

近日，AFRL宣布正式成为IBM Q Network中心，这是美国国防部首次与业界开展此类合作。IBM Q Network是一个由财富500强企业、学术机构、初创企业和国家研究实验室组成的联盟，该联盟与IBM合作推进量子计算发展。AFRL将通过IBM Q Network获得应用商用量子系统的机会，同时探索与空军相关的量子应用。  

![](../Images/4c4872657af1bba2e8206efe1f522eb4.png)

AFER

  

**AFRL量子计算网络中心计划**

AFRL信息理事会副主任Michael Hayduk表示，IBM在量子计算硬件和软件开发方面处于世界领先地位，AFRL很高兴能够与IBM合作，成为IBM Q Network中心。AFRL将与IBM的研究人员一起研究空军遇到的硬件相关问题，这些问题的解决将产生相对于传统计算的“量子优势”。**AFRL量子计算网络中心将致力于研究算法、机器学习、神经网络训练、风险/决策分析、分子和强相关系统的量子模拟、光子现象和特定生物系统中的量子应用。**

  

成为IBM Q Network的一员后，**AFRL中心的目标之一是创建一个广泛的研究人员社区，致力于开发最新的通用型近似超导量子计算机，推动量子硬件和软件的发展。**

  

**IBM Q Network概况**

作为世界首个推进量子计算、探索量子计算实际应用的企业和学术机构联盟，IBM Q Network成员包括阿贡国家实验室、欧洲核子研究中心、埃克森美孚、费米实验室和劳伦斯·伯克利国家实验室。IBM Q Network主要致力于以下三个领域：

  

**2.1 推进量子计算研究**

IBM Q Network授予成员组织所需的知识和工具，以便成员组织以合作或独立研究的方式推进量子计算领域的发展。

  

**2.2 开发商业应用程序**

IBM Q Network成员正在共同努力以期在量子领域形成优势。成员组织可以通过IBM云访问IBM最先进的量子系统，并可以访问专有的Qiskit扩展。Qiskit是一个开源、模块化和可扩展的量子编程框架。

  

**2.3 支持与培训**

为更好地利用量子计算能力，各行各业和学术界的专业人士都需要补充新的技能。IBM Q Network成员组织能够从IBM行业领先的技术专家那里获得支持和培训。

  

**意义分析**

美国军方认为，量子计算是能够颠覆太空战和信息战的技术。美国国防部已经将量子计算和应用列为研发投资的必选项，其最可能应用的领域为通信、导航和人工智能。

  

2018年，美国国会为国防部未来5年的量子项目规划了8亿美元预算。除经费外，美国在量子技术领域最大的问题是缺少能够应用量子技术的人员；缺少量子领域美国国内供应链和聚焦量子技术研究的测试实验室。美国空军近年来持续研究利用超高速计算机提高空军系统数据存储和传输的安全性。AFRL通过加入IBM Q Network，一是能够快速获取量子计算能力，一旦量子算法、对应的编程语言、量子云服务发展成熟，AFRL就有可能将它们纳入自己的解决方案中；二是AFRL能够获得IBM的量子技术培训与支持，对培养自己的专业量子人才大有益处。

  

IBM公司在量子技术领域进行了多年的持续投资和研究工作，2017年11月，IBM宣布实现了50个量子位的原型机，虽然该结果没有经过测试和同行评议，但不可否认IBM仍是最有可能制造出通用型量子计算机的公司。通过与IBM合作推进量子技术的应用，美国空军能够时刻掌握量子计算能力的发展，一旦量子技术得以突破便能够快速采用量子计算能力。
