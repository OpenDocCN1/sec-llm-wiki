攻击团伙情报


1.NewsBeef历史攻击技术演变分析

披露时间：2019年7月4日

情报来源：

https://securelist.com/twas-the-night-before/91599/


相关信息：

NewsBeef APT组织之前利用社交网络平台进行社工攻击，对之前NewsBeefAPT的分析表明，该APT组织主要针对沙特阿拉伯和西方目标却缺乏先进的攻击技术和开发能力。


自2016年夏天以来，该组织开始使用一个新的工具集，其中包括支持宏的Office文档，PowerSploit和Pupy后门。最近NewsBeef将此工具集与钓鱼邮件，通过社交媒体或通过私人消息传递以应用程序发送的链接以及利用受损网站（一些属于SA政府）的水坑攻击结合使用。该组织逐年改变了多个特征和攻击方法，策略性地将恶意JavaScript注入放置在受到破坏的网站上，以及命令和控制C2基础设施。其攻击过的目标包括政府财政和行政组织、政府卫生组织、工程技术组织、一个与英国劳务相关的政府组织、工业过程的能源服务、电信工程和实施服务、运输和物流、金属工程和制造业、信息技术服务以及水泥和建筑材料行业。


2.Silence APT组织的攻击已扩大至全球

披露时间：2019年7月3日

情报来源：

https://www.group-ib.com/media/silence-apt/

参考链接：

https://www.zdnet.com/article/silence-hackers-hit-banks-in-bangladesh-india-sri-lanka-and-kyrgyzstan/


相关信息：

自2019年2月以来，荷兰，孟加拉银行的外部IP的主机与Silence的C＆C进行了通信。在对荷兰，孟加拉银行的攻击中，攻击者可能使用了TrueBot木马，它可以隐蔽地执行远程命令并从受感染服务器下载文件。一旦TrueBot进入银行的基础设施，Silence就会进入下一阶段的攻击。已经证实，Silence是一家讲俄语的网络犯罪集团，曾导致300万美元被盗，报告的金额由当地媒体报道，被盗的实际金额可能要高得多。这是Silence最近的一次国际攻击之一，这表明该团伙已扩大其地理范围并已走向全球，现在专注于亚太市场。

1.Sea Turtle DNS劫持攻击活动

披露时间：2019年7月9日

情报来源：

https://blog.talosintelligence.com/2019/07/sea-turtle-keeps-on-swimming.html


相关信息：

思科Talos最近发现了Sea Turtle DNS劫持攻击活动。Sea Turtle攻击活动的背后攻击者在这一次攻击了希腊的ICS-Forth，这是一个管理希腊顶级域名国家代码.gr和.el的组织。ICS-Forth代表研究和技术基金会计算机科学研究所，于4月19日公开承认其被攻击，并且发送电子邮件给所有域名拥有者报告发生的安全事件。攻击者通过对NDS的劫持将指定目标的程序或Webmail重定向到攻击者的服务器，从而进行中间人攻击来拦截或是获取用户登录凭证，此攻击曾在中东和北非地区的政府组织中使用过。


2.针对克罗地亚政府的针对性攻击

披露时间：2019年7月5日

情报来源：

http://blog.ptsecurity.com/2019/07/ironpython-darkly-how-we-uncovered.html


相关信息：

在2019年4月初，PT ESC发现了对克罗地亚政府的针对性攻击。攻击者使用了一份Office钓鱼文档，当用户启用宏之后则会显示另一条迷惑用户的信息，其中包含克罗地亚邮政的徽标和包裹通知。宏代码会执行一段cmd命令，用来从服务器下载另一段VBS脚本。PT ESC发现得2分钓鱼文件中其中一份得脚本代码会设置为开机启动，但在随后捕获得样本中发现攻击者修改了执行流程，变为文档启动之后就执行。在后续阶段中使用得攻击载荷为SilentTrinity。


恶意代码情报


1.IcedID银行木马分析

披露时间：2019年7月9日

情报来源：

https://www.fortinet.com/blog/threat-research/icedid-malware-analysis-part-one.html


相关信息：

IcedID是一种银行木马，它在浏览器上执行Web注入，并充当代理来检查和控制流量，还会窃取受害者的信息，然后将被盗信息发送到远程服务器。

IcedID会启动多个进程，根据不同参数执行不同功能。其中启动的Svchost采用无参启动，由于Svchost在没有有效参数的情况下启动会自动退出，因此IcedID Hook了RtlExitUserProcess，在Svchost退出的时候来执行其攻击载荷。


2.GoBotKR恶意软件通过torrent传播

披露时间：2019年7月8日

情报来源：

https://www.welivesecurity.com/2019/07/08/south-korean-users-backdoor-torrents/


相关信息：

据ESET称GoBotKR自2018年3月以来一直活跃，目前受害者多达数百，其中韩国受影响最大占80%，其他受害地区包括中国以及中国台湾省。

GoBotKR是由GoBot2修改而来，对源代码的修改主要是为了规避韩国杀软的检测。GoBotKR通过伪装成电影、电视和游戏节目通过torrent网站传播。GoBotKR背后的攻击者正在建立一个肉鸡网络，然后可用于执行各种DDoS攻击（例如SYN Flood，UDPFlood或Slowloris）。因此，GoBotKR在执行后首先收集有关受感染计算机的系统信息，包括网络配置、操作系统版本信息、CPU、GPU版本以及已安装的杀毒软件列表。


3.Anubis Android服务器托管了超过17000个样本

披露时间：2019年7月8日

情报来源：

https://blog.trendmicro.com/trendlabs-security-intelligence/anubis-android-malware-returns-with-over-17000-samples/


相关信息：

自从Anubis首次出现以来，Anubis经历了一些变化，从用于网络间谍到被用于银行木马，结合了信息窃取和类似勒索软件的程序。在2019年1月中旬，趋势科技发现Anubis使用了基于运动的传感器来避开沙箱分析和窃取个人身份信息。最近趋势科技在跟踪Anubis的活动时发现两个相关的服务器包含17,490个样本。


趋势科技分析了一个Anubis变种，发现它的信息窃取功能包含截取受感染设备屏幕的屏幕截图、通过虚拟网络计算（VNC）远程控制设备、录制音频、发送，接收和删除短信、启用或配置设备管理设置、获取设备的运行任务、窃取设备的联系人列表、打开指定的URL、停用Google Play Protect、锁定设备的屏幕、启动或启动非结构化补充服务数据（USSD）、加密文件，包括存储在SD卡上的文件（如AnubisCrypt）、查找或查找文件、获取设备的位置以及从Twitter和Telegram等社交媒体渠道中检索远程控制命令。


Anubis总共有针对188个与银行和金融相关的应用程序，其中许多应用于波兰，澳大利亚，土耳其，德国，法国，意大利，西班牙，美国和印度。

1.CVE-2019-1132：Windows中Win32k.sys提权漏洞

披露时间：2019年7月10日

漏洞编号：CVE-2019-1132

情报来源：

https://www.welivesecurity.com/2019/07/10/windows-zero-day-cve-2019-1132-exploit/


相关信息：

2019年6月，ESET研究人员发现0day攻击被用于东欧的高度针对性攻击。攻击活动中利用了Windows中Win32k.sys提权漏洞CVE-2019-1132。目前微软已经发布漏洞补丁。


该漏洞会影响Windows 7for 32-bit Systems Service Pack 1、Windows 7 forx64-based Systems Service Pack 1、Windows Server 2008for 32-bit Systems Service Pack 2、Windows Server 2008for Itanium-Based Systems Service Pack 2、Windows Server2008 for x64-based Systems Service Pack 2、WindowsServer 2008 R2 for Itanium-Based Systems Service Pack 1和Windows Server 2008 R2 for x64-based Systems Service Pack 1。
