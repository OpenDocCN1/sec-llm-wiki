# 美专家解读中国新时期军事战略方针

**编者按**

  

近日，美国会所属美中经济与安全审查委员会围绕中国建设“世界一流军队”问题举行听证会。其间，麻省理工学院安全研究项目成员、亚瑟与鲁思·斯隆学院政治学教授、中国军事问题专家傅泰林（Taylor Fravel）对中国新时期军事战略方针进行了深入分析，建议美国会加大对中国外交与安全政策的研究力度，探讨采取“主动拒止”战略的可行性。其主要观点如下：

  

**一、解放军新时期军事战略方针的本质内涵**

解放军目前的军事战略方针于2014年7月通过，提出了“打赢信息化局部战争”的思想。该军事战略方针是对海湾战争后制定的1993年版军事战略方针的第二次调整，通常被称为“新时期军事战略方针”。在1993年版军事战略方针中，解放军强调高科技在作战中的作用，并开始向各军种联合作战转型；2015年出版的《中国的军事战略》白皮书则列举了解放军的战略任务：应对各种突发事件和军事威胁，有效维护中国领土、领空及领海的主权与安全；坚决捍卫祖国统一；维护中国在新型领域的安全与利益；维护海外利益安全；保持战略威慑并组织核反击行动；参与地区和国际安全合作，维护地区和世界和平；加强反渗透、反分裂、反恐怖斗争，维护国家政治安全和社会稳定；担负抢险救灾、维护权益、安保警戒，支援国家经济社会建设等任务。

  

**（一）2014版军事战略方针继承了之前军事战略方针的重要内容。**首先，2014版军事战略方针依然聚焦如何在涉及中国主权声索的周边地区的局部战争中赢得胜利，这一目标并未超出1993年和2004年版军事战略方针的范畴。其次，在局部战争背景下，主要战略方向，或者说解放军认为冲突最有可能发生的地区仍然是东南方向，主要作战对象仍然是台湾，以及为台湾提供某种程度防卫的美国；西南方向（中印边界）及南部方向（南海）仍是次要战略方向，或者说不是中国军事战略方针的首要任务。第三，解放军能够实施的主要作战样式仍然是联合作战，并将这种作战样式定义为“一体化联合作战”。第四，新版军事战略方针的指导思想依然强调危机预防、危机管控，以及战争爆发时的局势控制。最后，2014版的军事战略方针仍然以“积极防御”概念为前提。目前，解放军将“积极防御”定义为“采取积极主动的攻势行动来抵御敌人进攻”。

  

**（二）2014版军事战略方针方针与以往战略方针的不同之处。**首先，对军事斗争准备的基础进行了调整，注重信息化在战争中的作用。与2004版军事战略方针不同的是，2014版军事战略方针指出，信息化不仅是战争的条件，而且是战争的主要特征。简而言之，信息化是指全维搜集、处理和使用信息，以便实现各军种单个作战平台的实时、无缝连接，进而获得战场上的优势和主动权。其次，2014版军事战略方针的最大变化可能是对海上作战域的重视。具体而言，新的军事战略方针要求“重视海上军事斗争及海上军事斗争准备。”这标志着在战略方针及战略层面，首次明确了某种作战域。海上军事斗争并不仅仅指海上冲突，而是指在许多局部战争中，解放军可能需要在海上作战域实施作战，特别是在台海危机中，当然也包括东海及南海的海上争端。然而，该部分内容似乎仍在拟定过程中，自2014年以来，海上军事斗争准备一词在《解放军报》仅出现了34次；这或许是由于解放军2016年开始实施的军队体制改革所造成的。第三，新版军事战略方针将主要战略方向拓展至包括西太平洋的部分地区，因为这将涉及台海冲突，也许体现了所谓的“前沿防卫”理念，即试图使战线远离中国国境线。

  

**（三）中国于2014年调整军事战略方针主要基于两方面原因。**一方面也是最重要的原因是，为2016年实施的军队体制改革提供顶层指导。1993年版和2004年版军事战略方针要求解放军能够实施联合作战，但并未在组织上或其他方面进行相应的改革。调整军事战略方针及推进军队改革出现在2013年11月举行的中国共产党第十八届三中全会的“决定”中，全会号召“调整新时期的军事战略方针”及“实施军队领导体制改革”。这是中国首次同时宣布实施军队结构改革及调整军事战略方针，新的军事战略方针为这次改革提供了顶层指导。尽管2014年的指导方针没有设想以新的方式发动战争，但如果军事体制改革取得成功，那么它将对解放军的作战效能产生重大影响。另一方面的原因是，中国注意到海上作战域对中国的利益愈发重要。正如2015年出版的《中国的军事战略》白皮书指出，“维护海洋权益是中国的一项长期任务。”消息人士认为，在南海及台海冲突中，来自海上作战域的威胁日益增长，并对中国日益增长的海外利益构成潜在威胁。对海上作战域的重视也为中国实现“海洋大国”的愿望提供了保障。为此，中国海军的军种战略从仅仅关注“近海”，即捍卫中国在东亚的主权利益，逐步转向“近海防御”与“远海护卫”相结合，即关注中国在地区以外的利益。

  

**二、新的军事战略方针对解放军履行全球性使命的影响**

**（一）从地理上讲，解放军的兵力运用及作战仍主要集中在东亚地区（广义上包括西太平洋东部）。**原因在于，中国仍面临主权争端，这些争端最容易升级为武装冲突。为此，解放军在2015年的《中国的军事战略》白皮书中列出的前两项战略任务是“有效维护中国领土、领空及领海的主权与安全；坚决捍卫祖国统一”；“维护海外利益安全”及“参与地区和国际安全合作”等地区外活动与行动，则分别排在战略任务的第四位和第六位；这些任务并非不重要，但却不是解放军目前军事战略的重点。  

  

**（二）只要主权争端未能得到解决，特别是台湾问题，那么中国的军事战略将继续关注东亚地区。**这并不意味着解放军不会继续探索如何在其他地区开展行动，甚至不会提高在其他地区遂行作战的能力。实际上，2017年中国在吉布提建立军事基地就证明了这一点。然而，在主要主权争端得到解决或在这些争端中取得军事主导地位之前，解放军可能不会大幅拓展在东亚以外地区的活动。统一台湾仍然是中国宪法序言的一部分。然而，解放军在此类主权争端中取得军事主导地位恐将难以实现，特别是在台湾问题上，因为美国会根据《与台湾关系法》履行对台湾的安全承诺。

  

**（三）中美军事竞争的焦点也将集中在东亚地区。**自20世纪90年代末以来，解放军持续推进的军事现代化工作使其能够比以往任何时候都远离本国海岸线，对美军此前在东亚海上享有的庇护所构成了威胁。虽然距离给美国向东亚投送力量带来了挑战，但中国同样也面临将其力量投送到更远离其海岸的挑战，特别是当超出其防空系统及陆基战斗机的防护范围之外时。因此，中美间的竞争将集中在双方都有能力投送力量，但又无法掌握控制权的东亚冲突海域。尽管如此，中国目前的军事战略并不是要将美军排挤出东亚地区，也不是“寻求在近期实现对印太地区的主导权”（如美国《国防战略》所指出的那样）。当然，中国可能更乐见美国不是该地区的军事大国，但问题仍然是中国愿意以何种代价来实现这一目标。截至目前，中国一直致力于削弱美国在涉华主权争端中发挥决定性作用的能力。中国的军事战略所关注的依然是如何在主权争端中获胜，以及如果美国卷入这些争端，怎样才能获胜。

  

**（四）未来几十年中国在东亚以外地区的军事存在将持续扩大，但与其他军事大国相比，这种海外扩张可能相对温和。**美国目前在大约四十个国家拥有军事基地、作战准入权，通常在同一个国家拥有多处军事设施。法国和英国在大约11个国家建有海外基地，俄罗斯在大约9个国家建有海外军事基地。在吉布提建成首个海外军事基地后，接下来中国很可能跨越印度洋，在其他地区建立更多军事基地。和平时期，即使没有更多的海外基地，解放军在全球存在的日益增加将有助于美中间进一步开展合作。然而到了战时，在爆发中美冲突时，如果美国选择发动攻击，中国在东亚以外地区的基地将很有可能遭受美国的打击。

  

**三、政策建议**

（一）美国会应增加对涉华外交与安全政策问题开源情报分析的资金投入。通过报纸、军事期刊、军事教材、军事类书籍等各种公开来源可以获得大量中文信息，对这些信息进行系统搜集和分析，并将其翻译成英语供广大受众群体使用，可以从中获取很多有关中国如何处理战略问题的信息。然而，自冷战结束以来，对开源情报分析的支持以及尽可能地将这些信息推送给所有人员的努力明显减少，这些开源信息可能从未像今天这样重要。因此，国会应该考虑大幅增加对开源情报搜集的资金支持，并尽可能地把这些资金提供给更多部门和机构。  

  

（二）美国会应研究实施“积极拒止”战略的可能性与可行性，以应对中国军事现代化在东亚地区给美国带来的挑战。该战略将试图拒止中国通过使用武力而迅速取得胜利，并迫使其面临长期竞争的可能。通过这种方法，可以增加危机的稳定性及美国的威慑力，其核心是提高美国前沿部队的弹性和生存能力，注重发展应对中国地区力量投射的能力，并与盟国开展更紧密的合作。
