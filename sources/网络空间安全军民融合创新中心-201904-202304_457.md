# 量子计算机如何在8小时内破解2048位RSA加密

一项新的研究表明，量子技术将比预期更快地赶上今天的加密标准。这应该会让任何需要安全存储数据25年左右的人感到担忧。  

  

许多人担心量子计算机将能够破解用于发送安全消息的某些加密代码。这种所谓的加密代码使用“陷门(trapdoor)”函数加密数据，这种函数可以在一个方向上轻松执行，但在另一个方向上却不能。这使得加密数据变得容易，但如果没有特殊密钥的帮助，解码起来就非常困难。

  

这些加密系统从未被破坏过。相反，它们的安全性是基于经典计算机完成解码所需的大量时间而体现。现代加密方法是专门设计的，因此解码它们需要很长时间，可以说它们实际上是牢不可破的。

  

但量子计算机改变了这种想法。量子计算机远比传统计算机强大得多，应该能够轻松破解这些代码。  

  

这提出了一个重要问题——量子计算机什么时候才能足够强大到做到这一点呢？在此之后，受此加密形式保护的任何信息都会变得不安全。

  

因此，计算机科学家已经在尝试计算构建这样一台量子计算机可能需要的资源，以及建立这样一台机器需要多长时间。此前的答案一直是几十年。

  

然而现在，圣芭芭拉谷歌的Craig Gidney和瑞典斯德哥尔摩KTH皇家理工学院的Martin Ekerå的研究工作显示，这种想法需要被修正。这些研究人员已经找到了一种更有效的方法，可以让量子计算机执行代码破解计算，从而减少量子计算机所需的资源数量级。

因此，这些量子计算机比任何人想象的都更接近现实。这一结果将使政府、军队和安全机构、银行以及所有需要保护数据长达25年甚至更久的人感到不安。

  

早在1994年，美国数学家Peter Shor就发现了一种超越经典算法的量子算法。 Shor的算法因子很大，并且是破解基于陷门函数密码的关键因素。

  

陷门函数是基于乘法过程，这种过程很容易在一个方向上执行，但在反向中更难做到。例如，将两个数字相乘是很简单的：593乘以829是491,597。但是很难算出 491,597 是由哪两个质数相乘才能得到。

  

随着数字变大，它变得越来越困难。实际上，计算机科学家认为经典计算机几乎不可能分解出大于 2048 位的数字，而 2048 位是 RSA 加密最常用的基础形式。

  

Shor表明，一台足够强大的量子计算机可以轻松实现这一目标，这一结果给安全行业带来了冲击。

  

从那以后，量子计算机的功能不断增加。2012年，物理学家使用一台4个量子比特的量子计算机来分解143。然后在2014年，他们使用了类似的设备来分解56,153。

  

很容易想象，在这种进步速度下，量子计算机很快就能胜过最好的经典计算机。

  

但现实或许不是这样。事实证明，量子因式分解在实践中要比预期的要困难得多。原因是，噪声成为大型量子计算机的一个重要难题。目前解决噪声问题的最佳方法是使用纠错码，但纠错码本身需要大量额外的量子比特。

  

考虑到这一点会大大增加量子计算机分解2048位数字所需的资源。 2015年，研究人员估计，一台量子计算机需要10亿个量子比特才能可靠地完成这项工作。当今最先进的量子计算机只有 70 个量子位元，这是巨大的差距。

  

在此基础上，安全专家可能已经能够证明，用量子计算机破解 2048 位 RSA 加密的信息，还需要几十年的时间。

  

现在Gidney和Ekerå已经展示了量子计算机如何只用2000万个量子比特进行计算。实际上，他们表明这样的设备只需要8个小时就能完成计算。他们说：“\[这一结果\]，已经使得分解 2048 位 RSA 整数最多需要多少量子比特，下降了近两个数量级。”

  

他们的方法侧重于一种称为模幂运算(modular exponentiation)的更有效的方法来执行数学运算。幂模运算是在将数字提高到某个幂然后除以另一个数，找到余数的过程。

  

这个过程是Shor算法中计算量最大的操作。但是Gidney和Ekerå已经找到了各种优化方法，大大减少了运行算法所需的资源。

  

这是一项有趣的工作，对于所有为未来存储信息的人来说都具有重要的意义。一台2000万个量子比特的量子计算机在今天看来似乎是一个遥远的梦想。但是这些专家应该问自己的问题是，在他们想要保护信息的25年内，这样的设备是否可能成为实现。如果他们认为是，那么他们需要一种新的加密形式。

  

实际上，安全专家已经开发出了后量子代码，甚至量子计算机也无法破解。因此，现在可能已经有方法保护数据免受量子计算机未来的攻击。但这些代码尚未作为标准使用。

  

对普通人来说，被破解的风险很小。大多数人使用2048位加密或类似的方法来完成用互联网发送信用卡详细信息的任务。如果这些交易记录发生在今天，即使在 25 年内被破解，那么损失也会微乎其微。

  

但对政府来说，风险会更大。他们今天发送的信息——例如大使馆或军队之间的信息——在20年内可能很重要，因此值得保密。如果这些消息仍然通过2048位RSA加密或类似的方式发送，那么这些组织就应该开始担心了。
