1.漏洞概述
 2021年1月26号左右，Qualys研究小组发现了sudo中的堆溢出漏洞，该漏洞在Unix和Linux的操作系统上都可以使用。通过利用此漏洞，攻击者可以将任何普通用户提权至root权限。
 Sudo是一个功能强大的实用程序，绝大多数基于Unix和Linux的操作系统都默认装有Sudo。它允许用户使用其他用户的安全特权运行程序。该漏洞本身已经隐藏了将近十年。为何该漏洞隐藏十年之久没有被发现？
简单分析：
 我们知道，在Linux系统中创建一个命名带有空格的文件或目录，查看该文件或目录时需要使用反斜杠”\“转义，Sudo的漏洞正是产生在这个转义符号上。

4.漏洞复现
4.1 漏洞验证
 该Sudo漏洞的快速验证可以使用sudoedit指令。因为sudoedit指令调用的还是sudo命令。
主要有以下三种方法验证：
（1）sudoedit -s /
    以非root用户执行：sudoedit -s /，若返回以"sudoedit:"开头的信息，则极有可能存在漏洞。若返回以"usage:"开头的信息，则说明不存在该漏洞。
 但该方法有时在有的系统上执行不是返回报错信息，而是提示输入密码...

（2）sudoedit -s '\' `perl -e 'print "A" x 65536'`
 以非root用户执行：sudoedit -s '\' `perl -e 'print "A" x 65536'`，若返回信息为"Segmentation fault"，则极有可能存在漏洞。
若返回以"usage:"开头的信息，则说明不存在该漏洞。

（3）sudoedit -s '1234567890123456789012\'
 以非root用户执行：sudoedit -s '1234567890123456789012\'，若返回信息为"malloc(): memory"的报错信息，则极有可能存在漏洞。若返回以"usage:"开头的信息，则说明不存在该漏洞。

5.漏洞修复
5.1 临时缓解措施
        如不方便升级，可使用systemtap进行缓解，可使用以下步骤进行升级。
安装systemtap所需依赖：
yum -y install systemtap yum-utils kernel-devel-"$(uname -r)"

Rhel7使用以下命令安装内核debuginfo：
debuginfo-install -y kernel-"$(uname -r)"
Rhel8和Rhel6使用以下命令安装sudo debuginfo：
debuginfo-install -y sudo

创建systemtap script：
sudoedit-block.stap：
probe process("/usr/bin/sudo").function("main")  {        command = cmdline_args(0,0,"");        if (isinstr(command, "edit")) {                raise(9);        }}

运行sudoedit-block.stap：

nohup stap -g sudoedit-block.stap &
停止systemtap进程：
kill -s SIGTERM或者：kill -9
注意：以上是缓解措施，请勿删除sudoedit。
参考文章：https://access.redhat.com/security/vulnerabilities/RHSB-2021-002
