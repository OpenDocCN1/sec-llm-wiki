1.漏洞概述 2021年1月26号左右，Qualys研究小组发现了sudo中的堆溢出漏洞，该漏洞在Unix和Linux的操作系统上都可以使用。通过利用此漏洞，攻击者可以将任何普通用户提权至root权限。 Sudo是一个功能强大的实用程序，绝大多数基于Unix和Linux的操作系统都默认装有Sudo。它允许用户使用其他用户的安全特权运行程序。该漏洞本身已经隐藏了将近十年。为何该漏洞隐藏十年之久没有被发现？简单分析： 我们知道，在Linux系统中创建一个命名带有空格的文件或目录，查看该文件或目录时需要使用反斜杠”\\“转义，Sudo的漏洞正是产生在这个转义符号上。

4.漏洞复现4.1 漏洞验证 该Sudo漏洞的快速验证可以使用sudoedit指令。因为sudoedit指令调用的还是sudo命令。![](../Images/7ac2248979dc817946c7cd7131e80046.png)主要有以下三种方法验证：（1）sudoedit -s /    以非root用户执行：sudoedit -s /，若返回以"sudoedit:"开头的信息，则极有可能存在漏洞。若返回以"usage:"开头的信息，则说明不存在该漏洞。![](../Images/30e530bc4b90e84c7b149f23d4ecde7d.png) 但该方法有时在有的系统上执行不是返回报错信息，而是提示输入密码...  
（2）sudoedit -s '\\' \`perl -e 'print "A" x 65536'\` 以非root用户执行：sudoedit -s '\\' \`perl -e 'print "A" x 65536'\`，若返回信息为"Segmentation fault"，则极有可能存在漏洞。![](../Images/b4567aa99a2be49f1f9fb8f9a414db31.png)若返回以"usage:"开头的信息，则说明不存在该漏洞。![](../Images/a2484dea1e322d33a5e3de6ecf485ddf.png)  
（3）sudoedit -s '1234567890123456789012\\' 以非root用户执行：sudoedit -s '1234567890123456789012\\'，若返回信息为"malloc(): memory"的报错信息，则极有可能存在漏洞。若返回以"usage:"开头的信息，则说明不存在该漏洞。![](../Images/952e339127263085b9002758ccbb82f2.png)
