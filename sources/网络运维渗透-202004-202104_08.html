1.前言
 其实这篇文章正是接的内网存活网段探测的进一步操作(渗透)，拿到了内网的存活网段，接下来就是对该网段内的存活主机探测提取，然后再进一步对主机的端口、服务、操作系统等信息进行探测。这当然少不了我们的诸神之眼—Nmap。
                

2.nmap自带参数实现批量探测
探测内网存活IP信息并导出到文件：
C:\>nmap -sP 192.168.1.0/24 > c:\Users\Administrator\Desktop\livehost.txt

探测并检索出内网存活IP并导出到文件：
C:\>nmap -sP 192.168.1.0/24 |grep -E -o '[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}' > c:\Users\Administrator\Desktop\liveIP.txt   #windows需要安装grep命令工具

nmap从输入文件批量探测：
C:\>nmap -iL c:\Users\Administrator\Desktop\liveIP.txt -sV -O >c:\Users\Administrator\Desktop\nmapscan.txt   #探测并输出保存到文件


3.nmap批量探测bat脚本
 在实际的渗透环境中，nmap信息探测是必不可少的。大部分情况下，我们都是对某个网段进行探测(大部分情况是内网)，如果我们已经有了一个ip表，我们可以这样做。

（1）nmap自带参数实现
主机存活探测并检索IP保存到文件：
C:\>nmap -iL c:\Users\Administrator\Desktop\IP.txt -sP |grep -E -o '[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}' >c:\Users\Administrator\Desktop\live.txt

 接下来可以使用上述指令根据存活IP继续进行探测。

（2）bat脚本实现
 不使用nmap参数实现存活和输入文件，可以通过以下方法实现。不进行存活探测一行for循环代码就能实现。
nmap_scanOS.bat：
@echo offecho ---------------------------------------echo Author：afeiecho echo nmap正在批量探测目标系统echo ---------------------------------------
rem 不进行存活探测，直接使用nmap进行目标系统探测:: for /f %%i in (nmap_scanIP.txt) do nmap -O %%i >> nmap_system.txt
::设置延迟变量setlocal enabledelayedexpansionfor /f %%x in (nmap_scanIP.txt) do (  ping -w 1 -n 1 %%x |findstr "TTL=" >nul  if !errorlevel! equ 0 (    echo 正在探测目标%%x && nmap -O %%x >> nmap_system.txt) else (    echo %%x is not alive！))echo 批量探测完成！pause


（3）shell脚本实现
nmap_batchscan.sh：
#!/bin/bash# Author: afei
IP=$(cat iplist.txt)
for i in $IPdo  ping -w 1 -c 1 $i |grep "ttl=" > /dev/null 2>&1  if [ $? == 0 ];then    nmap -sV -O $i  else    echo $i is not alive！  fidone
