（2）bat脚本实现 不使用nmap参数实现存活和输入文件，可以通过以下方法实现。不进行存活探测一行for循环代码就能实现。nmap\_scanOS.bat：

```
@echo offecho ---------------------------------------echo Author：afeiecho echo nmap正在批量探测目标系统echo ---------------------------------------
rem 不进行存活探测，直接使用nmap进行目标系统探测:: for /f %%i in (nmap_scanIP.txt) do nmap -O %%i >> nmap_system.txt
::设置延迟变量setlocal enabledelayedexpansionfor /f %%x in (nmap_scanIP.txt) do (  ping -w 1 -n 1 %%x |findstr "TTL=" >nul  if !errorlevel! equ 0 (    echo 正在探测目标%%x && nmap -O %%x >> nmap_system.txt) else (    echo %%x is not alive！))echo 批量探测完成！pause
```

（3）shell脚本实现nmap\_batchscan.sh：

*   
*   
*   
*   
*   
*

*   
*   
*

```
#!/bin/bash# Author: afei
IP=$(cat iplist.txt)
for i in $IPdo  ping -w 1 -c 1 $i |grep "ttl=" > /dev/null 2>&1  if [ $? == 0 ];then    nmap -sV -O $i  else    echo $i is not alive！  fidone
```
