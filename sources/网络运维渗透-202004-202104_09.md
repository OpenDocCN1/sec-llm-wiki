1.前言 当拿下内网某台主机之后，可使用以下脚本对该内网主机网段进行盲打探测。如果是对较大内网进行渗透测试的话，这个脚本会很有帮助。判断了存活网段，就等于缩小了范围，接下来就能对该网段内的存活主机进行探测了。存活主机发现的越多，意味着掌握的信息量也就越大，发现漏洞和敏感资产的可能性也越大，有利于对目标进行全方位的渗透测试。  
 谁掌握的信息量越多，渗透测试的主导权就在谁手里。  
                       原创：Klion                        地址：https://mp.weixin.qq.com/s/AUgBlRjH\_USaZXgmMDYzSg  

* * *

  
 以下脚本的原理其实就是：使用ping命令发一个包去探测，并设置超时时间，如果发去的包响应正常则说明该网段内有主机存活，否则说明这个网段不是存活网段。  该脚本主要针对的是常规标准内网网段，非常规标准内网网段并未考虑，可根据自己需求进行修改。  
常规标准内网网段：A类：10.0.0.0-10.255.255.255B类：172.16.0.0-172.31.255.255C类：192.168.0.0-192.168.255.255

@echo off
rem 内网存活网段探测[Windows]rem Original：Klionrem Write by afeirem 2020/07/22
::以下使用goto语句进行多行注释goto start= 常规标准内网网段= A类：10.0.0.0-10.255.255.255= B类：172.16.0.0-172.31.255.255= C类：192.168.0.0-192.168.255.255:start
::设置延迟变量setlocal enabledelayedexpansion
goto start= %-w设置超时时间，-n设置发送数%= >nul会将结果输出重定向到一个空设备= 因为使用了延迟变量，复合变量errorlevel不能使用%errorlevel%= 将存活网段写入到alive_segment.txt文件:start
:: A类标准内网存活网段探测for /l %%i in (0,1,255) do (  for /l %%j in (0,1,255) do (    ping -w 1 -n 1 10.%%i.%%j.1 |findstr "TTL=" >nul || ping -w 1 -n 1 10.%%i.%%j.254 |findstr "TTL=" >nul    if !errorlevel! equ 0 (echo 10.%%i.%%j.0/24 is alive ! >> alive_segment.txt) else (echo 10.%%i.%%j.0/24 may be sleeping ! )  ))
:: B类标准内网存活网段探测for /l %%m in (16,1,31) do (  for /l %%n in (0,1,255) do (    ping -w 1 -n 1 172.%%m.%%n.1 |findstr "TTL=" >nul || ping -w 1 -n 1 172.%%m.%%n.254 |findstr "TTL=" >nul    if !errorlevel! equ 0 (echo 172.%%m.%%n.0/24 is alive ! >> alive_segment.txt) else (echo 172.%%m.%%n.0/24 may be sleeping ! )  ))
:: C类标准内网存活网段探测for /l %%z in (0,1,255) do (  ping -w 1 -n 1 192.168.%%z.1 |findstr "TTL=" >nul || ping -w 1 -n 1 192.168.%%z.254 |findstr "TTL=" >nul  if !errorlevel! equ 0 (echo 192.168.%%z.0/24 is alive ! >> alive_segment.txt) else (echo 192.168.%%z.0/24 may be sleeping ! ))
```

#!/bin/bash#-----------------------#内网存活网段探测[Linux]#Original：Klion#Write by afei#2020/0723#----------------------
# A类标准内网存活网段探测for i in {0..255}do  for j in {0..255}  do    ping -c 1 -w 1 10.$i.$j.1 |grep "ttl=" > /dev/null 2>&1 || ping -c 1 -w 1 10.$i.$j.254 |grep "ttl=">> /dev/null      if [ $? == 0 ];then      echo 10.$i.$j.0/24 is alive !  >> alive_segment.txt  else    echo 10.$i.$j.0/24 may be sleeping !  fi  donedone
# B类标准内网存活网段探测for m in {16..31}do  for n in {0..255}  do    ping -c 1 -w 1 172.$m.$n.1 |grep "ttl=" > /dev/null 2>&1 || ping -c 1 -w 1 172.$m.$n.254 |grep "ttl=">> /dev/null      if [ $? == 0 ];then      echo 172.$m.$n.0/24 is alive !  >> alive_segment.txt  else    echo 172.$m.$n.0/24 may be sleeping !  fi  donedone
# C类标准内网存活网段探测for z in {1..255}do   ping -c 1 -w 1 192.168.$z.1 |grep "ttl=" > /dev/null 2>&1 || ping -c 1 -w 1 192.168.$z.254 |grep "ttl=">> /dev/null      if [ $? == 0 ];then      echo 192.168.$z.0/24 is alive !  >> alive_segment.txt  else    echo 192.168.$z.0/24 may be sleeping !  fidone
```
