1.更新kali操作系统

root@kali:~# apt-get update && apt-get upgrade...   Processing triggers for dbus (1.12.12-1) ...Processing triggers for desktop-file-utils (0.23-4) ...root@kali:~#



2. apt-get安装kde桌面

root@kali:~# apt-get install kde-plasma-desktop -y

出现这个界面，直接回车：

Processing triggers for shared-mime-info (1.10-1) ...Processing triggers for desktop-file-utils (0.23-4) ...root@kali:~#

安装完成


3.重新登录kali验证

 注销当前用户重新登录，选择Plasma桌面模式。


可以看到桌面发生了变化
