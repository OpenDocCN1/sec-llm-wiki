# 360CRT发布：CVE-2020-16898: Windows TCP/IP远程执行代码漏洞通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MjMxODUwNg==&mid=2247484473&idx=1&sn=fb742501208a519dec0a390d2dd1d6c1&chksm=9f216f7ca856e66acc96092ebecdb1f80f775152e4e0efd860acebaa3ef413d7255ed65a61e0&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MjMxODUwNg==&mid=2247484473&idx=1&sn=fb742501208a519dec0a390d2dd1d6c1&chksm=9f216f7ca856e66acc96092ebecdb1f80f775152e4e0efd860acebaa3ef413d7255ed65a61e0&scene=27#wechat_redirect)

**漏洞概述：**  
      2020年10月16日，360CERT监测到网上公开了漏洞的相关分析和Poc，本次更新标识该漏洞的利用工具公开，该Poc可造成系统蓝屏奔溃（BSOD），并可能在短时间内出现攻击态势。  
**影响版本：**

*   microsoft:windows\_10:1709/1803/1903/1909/2004
    
*   microsoft:window\_server\_2019:\*
    
*   microsoft:window\_server:1903/1909/2004
    

**风险等级：**  

![](../Images/3e99d02926530682c8be9d8c73504a89.png)

  
**漏洞详情：**  
     Windows TCP/IP堆栈 在处理ICMPv6 Router Advertisement（路由通告）数据包时存在漏洞，远程攻击者通过 构造特制的ICMPv6 Router Advertisement（路由通告）数据包 ，并将其发送到远程Windows主机上，即可在目标主机上执行 任意代码 。  
**漏洞验证：**      待更新。  
  
**修复建议：**  
（1）微软已经发布CVE-2020-16898漏洞补丁：https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-16898  
请尽快更新。  
  
（2）临时解决办法：  
     关闭网卡IPV6功能。
