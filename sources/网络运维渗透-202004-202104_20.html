2.设置使用wsl 2

设置默认使用wsl 2：

C:\WINDOWS\system32>wsl --set-default-version 2 有关与 WSL 2 的主要区别的信息，请访问 https://aka.ms/wsl2



设置ubuntu默认使用wsl 2：

注意：Ubuntu的安装目录不能是压缩目录，不然无法进行转换。

Ubuntu安装目录：C:\Users\用户名

\AppData\Local\Packages\CanonicalGroupLimited.UbuntuonWindows_79rhkp1fndgsc

4.报错问题

报错问题1：

注意：BIOS需要启动虚拟化，不然会报以下错误。


解决办法参考：

https://docs.docker.com/docker-for-windows/troubleshoot/#virtualization


确认已开启Hyper-V：

步骤：控制面板—>程序和功能—>启用或关闭Windows功能


确认已开启虚拟化功能：


如果Hyper-V和虚拟化都已开启但依然报错，尝试以下方法解决：

（1）设置Hyper-V组件的守护进程自动运行

C:\>bcdedit /set hypervisorlaunchtype auto操作成功完成。
C:\>shutdown -r -t 0


设置Hyper-V组件的守护进程自动运行后，该报错问题已解决。


报错问题2：

以上报错的原因是由于：“参考的对象类型不支持操作”导致。

解决办法：CMD管理员身份重置winsock即可解决(Winsock是Windows下网络编程的规范，该规范是Windows下得到广泛应用的、开放的、支持多种协议的网络编程接口)。

C:\WINDOWS\system32>netsh winsock reset
成功地重置 Winsock 目录。你必须重新启动计算机才能完成重置。
C:\WINDOWS\system32>shutdown -r -t 0


重启之后，报错问题成功解决。


报错问题3：

error during connect: Get http://0.0.0.0:2375/v1.40/version: dial tcp 0.0.0.0:2375: connect: network is unreachable


解决办法：

（1）步骤：Settings—>Genera


（2）重新启动Hyper-V, 并预留一个2375端口

管理员身份运行禁用Hyper-V，并重启电脑：


dism.exe /Online /Disable-Feature:Microsoft-Hyper-V



预留2375端口:


netsh int ipv4 add excludedportrange protocol=tcp startport=2375 numberofports=1



启用Hyper-V，重启电脑：


dism.exe /Online /Enable-Feature:Microsoft-Hyper-V /All
