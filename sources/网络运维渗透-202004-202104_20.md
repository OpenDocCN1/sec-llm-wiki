4.报错问题

报错问题1：

注意：BIOS需要启动虚拟化，不然会报以下错误。

![](../Images/e2079065acdbadd33350e0213e7e61de.png)

  

解决办法参考：

https://docs.docker.com/docker-for-windows/troubleshoot/#virtualization

  

确认已开启Hyper-V：

步骤：控制面板—>程序和功能—>启用或关闭Windows功能

![](../Images/a286a19e82575f0e41a6573459371266.png)

  

确认已开启虚拟化功能：

![](../Images/d2bb525fe9cc94742af7bd0e11947135.png)

  

如果Hyper-V和虚拟化都已开启但依然报错，尝试以下方法解决：

（1）设置Hyper-V组件的守护进程自动运行

*   
*   
*   
*   

```
C:\>bcdedit /set hypervisorlaunchtype auto操作成功完成。
C:\>shutdown -r -t 0
```

  

设置Hyper-V组件的守护进程自动运行后，该报错问题已解决。

  

报错问题2：

![](../Images/c50be0cdb3b6cc5c49e9820784771b2a.png)

以上报错的原因是由于：“参考的对象类型不支持操作”导致。

解决办法：CMD管理员身份重置winsock即可解决(Winsock是Windows下网络编程的规范，该规范是Windows下得到广泛应用的、开放的、支持多种协议的网络编程接口)。

*   
*   
*   
*   
*   
*   

```
C:\WINDOWS\system32>netsh winsock reset
成功地重置 Winsock 目录。你必须重新启动计算机才能完成重置。
C:\WINDOWS\system32>shutdown -r -t 0
```

  

重启之后，报错问题成功解决。
