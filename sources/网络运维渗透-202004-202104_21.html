一、Linux on Windows简介

  Win10一周年版推出了用于Windows的Linux子系统这一功能。Linux子系统和Windows的结合真是有一种神互补。子系统可以挂载windows的文件系统，于是就可以在现有的文件系统下干一个完整的Linux环境所能干的事情。软件丰富更适合日常使用的Windows与开源且适合开发的Linux结合使得开发更加简便，不用再考虑双系统虚拟机这种效率不高的结合方式了，Linux on Windows用一种应用软件的方式实现了系统软件的功能，这一点可以说让人惊艳了。重要的是这样同时运行的两个系统并不是相互独立的，而是可以协作的，以后完全可以使用Windows下的工具进行编码，然后在Linux子系统进行Git提交，当然，它所能够发挥的作用远远不仅于此。




二、Windows 10使用子系统要求

        （1）windows 10 64位系统；

   （2）版本号14316以上。


三、windows 10安装kali Linux子系统

1.启用Linux on Windows功能

在管理员权限的CMD下输入：

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux

1

或者：控制面板---->程序和功能---->启用或关闭Windows功能

启用后会提示重启电脑


2.下载Windows子系统（kali）

说明开启成功，访问该网址下载：https://aka.ms/wslstore

3.安装kali工具

 虽然安装了kali子系统，但是所有的kali工具是没有安装的。

root@afeicomputer:~# apt-get install kali-linux-full -y   #这条命令几乎可以装全所有的kali工具



4.子系统kali安装桌面环境

root@afeicomputer:~# runlevel   #查看是否安装桌面组件unknown



kali桌面环境:

（1）XFCE桌面

安装：


apt-get install kali-defaults kali-root-login desktop-base xfce4 xfce4-places-plugin xfce4-goodies -y


卸载：


apt-get remove xfce4 xfce4-places-plugin xfce4-goodies -y



（2）LXDE桌面

安装：


apt-get install lxde-core lxde kali-defaults kali-root-login desktop-base -y


卸载：


apt-get remove lxde-core -y



（3）Cinnamon 桌面

安装：


apt-get install kali-defaults kali-root-login desktop-base cinnamon -y


卸载：


apt-get remove cinnamon -y



（4）I3WM桌面

安装：


apt-get install xorg dmenu conky i3 -y


卸载：

apt-get remove xorg dmenu conky i3 -y



（5）MATE桌面

MATE桌面没有在kali默认的源里，需要加一下源

echo "deb http://repo.mate-desktop.org/debian wheezy main" >> /etc/apt/sources.listapt-get updateapt-get --yes --quiet --allow-unauthenticated install mate-archive-keyring


安装：


apt-get install kali-defaults kali-root-login desktop-base mate-core mate-desktop-environment mate-desktop-environment-extra -y


安装MATE的好处是可以使用原始GNOME下的kail 工具菜单，这是其它桌面环境没有的，方法：


vim /etc/xdg/menus/mate-applications.menu


找到Internet 节点，在下面加入：



applications-merged/kali-applications.menu


保存，之后就可以在应用程序里看到“kali linux”的工具菜单了


卸载：


apt-get remove  mate-core mate-desktop-environment mate-desktop-environment-extra -y



（6）GNOME桌面（默认）

安装：


apt-get install gnome-core kali-defaults kali-root-login desktop-base -y


卸载：


apt-get remove gnome-core -y


注意：该桌面同样不支持Xrdp映射


（7）安装KDE桌面

root@afeicomputer:~# apt-get install kali-defaults kali-root-login desktop-base kde-full -y   #安装KDE标准版，注意磁盘空间，大小近4个G


卸载：


apt-get remove kde-full -y


注意：经过实验，该桌面能够以非root成功登录，但依然无法使用命令行

六、WSL上kali系统问题

1.Winodows Defender导致kali某些功能无法正常使用

安装完kali后，由于win10自带的Winodows Defender可能会导致kali某些功能无法正常使用。因此，需要将kali所在目录加入Defender的白名单。






2.kali上安装的工具无法使用

root@afeicomputer:~# nmap -v -sn 192.168.99.0/24Warning: Nmap may not work correctly on Windows Subsystem for Linux.For best performance and accuracy, use the native Windows build from https://nmap.org/download.html#windows.Starting Nmap 7.80 ( https://nmap.org ) at 2020-01-17 09:50 CSTInitiating ARP Ping Scan at 09:50dnet: Failed to open device wifi0QUITTING!


kali所需的工具都安装上了，但是连nmap都无法使用。原因是：WSL上的nmap暂时无法使用socket套接字。希望之后会完善。

https://github.com/nmap/nmap/issues/1287#issuecomment-412744085
