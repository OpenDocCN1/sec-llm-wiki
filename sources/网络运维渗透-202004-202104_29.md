1.前言

之前由于遭某人举报的PanDownload又复活了，而且下载速度还不赖，据说能达到60MB/s，咱也来测测。

  

![](../Images/f4857e2b0148a7644ea69e9723bc57d9.png)

 这是人家的测试，我测的时候没有这么高，可能是我带宽的原因。

  

  

PanDownloadLBW3.4下载地址：

https://github.com/PanDownloadServer/Server

  

![](../Images/be54dd6265b88facc0e81d3a89fdea48.png)

         PanDownloadLBW3.4运行可能会遇到问题，大家可以下载尝试。

PanDownloadLBW3.4可能会遇到下面的问题：

  

2.登录提示获取bdstoken失败

![](../Images/68014312569ad15030e03ac1817eeb4f.png)

  

解决方法一

（1）修改配置文件：\\PanData\\config.ini

 在proxy=后添加http://127.0.0.1:5678

![](../Images/90f553636552629d2959a739d893441b.png)

  

（2）下载pdproxy工具

 目前exe下载地址已失效。

github源码：https://github.com/TkzcM/pandownload-login

 下载pdproxy.py中的源码，使用python3运行

  

*   
*   
*   

```
pip install mitmproxypip install bs4python pdproxy.py.py
```

  

![](../Images/f1de97a069db5961424453285987c840.png)

 经测试，该方法已失效。

  

  

解决方法二

 下载fixpandown.exe修复工具。

  

下载地址：

https://www.yorozuyas.com/download/fixpandownload.exe

  

 下载解压到PanDownload的安装目录，点击运行，会自动进行修复。

![](../Images/fadb6c5207ce70ba55806d3eaacce160.png)

  

修复完成扫码登录：

  

![](../Images/0c35333983356e12dc92e9c7141a66fc.png)

  

![](../Images/fff28afaec34fabc28eb66d42381c205.png)

依然是获取bdstoken失败。

  

  

解决办法三

 下载KinhDown替代PanDownloadLBW3.4，之后3.5版本应该很快会出来。我用KinhDown测试时最高能到达10MB/s左右。

  

KinhDown下载地址：https://kinhdown.kinh.cc/
