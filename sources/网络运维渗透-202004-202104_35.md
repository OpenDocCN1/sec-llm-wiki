三、VMware安装macOS 10.13

1.首先停止VMware相关服务

![](../Images/7ecc9495f438c3470dc9385525f340d0.png)

![](../Images/2e6fb0102fdfabffba675056eeac6e8d.png)

  

2.将下载的Unlocker解压到VMware的安装目录

 进入Unlocker目录，以管理员身份运行win-install.cmd序。执行成功后会生成backup和tools两个文件夹。

![](../Images/d0d7f63323abdfbc33f2cba7b6462679.png)

![](../Images/a1c38b2f65638635f3b920bf78ba5e23.png)

![](../Images/4940bc66c555dfa15028ebf8c92e9b49.png)

  

3.VMware安装部署macOS

 打开VMware虚拟机，准备安装macOS。

![](../Images/180aceafe095f50f01cdeea46b2bc2a7.png)

![](../Images/9dd9a0357dc2072440c65e2ef79f3725.png)

![](../Images/9cba87356319877f6b8f20bf1c4facc7.png)

这里能出来macOS选项，说明Unlocker成功突破VM限制

![](../Images/f11c35306876a31f540de071c9150b38.png)

![](../Images/b210553f364be2688f9a8b9ed3f60358.png)

磁盘容量建议大小最低40G，不然会很卡

  

4.重启VMware相关服务

  启动刚刚停止的VMware服务，不然使用VMware会出问题。

![](../Images/fb560080425a1d5e71b5a473b5d78ff5.png)

  

5.修改VMware虚拟化引擎

  开启“虚拟化Intel VT -x/EPT”和“虚拟化IOMMU”。

![](../Images/e5a0870539634ea6c895a48a7dc141a3.png)

  

6.修改macOS的VM安装目录下的.vmx文件

  在smc.present = "TRUE"下面添加：smc.version = "0"；在末尾添加：cpuid.1.eax = "00000000000000010000011010100101"，不然的话安装macOS会无限重启。

![](../Images/ec7f77d6ab17b223018e3b427718a93c.png)

![](../Images/daac5b0aa57db1a8f3ca30f4b1388acb.png)

10.安装VMtools

![](../Images/f4b3b409165990187c608e51a9fce608.png)

发现无法连接VMware-tools无法安装

解决办法：挂载安装darwin.iso。darwin.iso主要适用于mac系统无法全屏显示的问题。

下载地址：

http://www.121down.com/soft/softview-96037.html#downaddress

（1）点击“Finder”,选择Preferences（偏好设置）

![](../Images/3690607350ca4fa70df387799cf99caa.png)

![](../Images/595c0e13b8d0a8040d44526ebd2234d9.png)

  

（2）退出桌面的虚拟磁盘

![](../Images/5fc43c34f029cc4e04cb394e31e8d94e.png)

（3）挂载darwin.iso镜像安装

![](../Images/1fd3c0e909fa28661445c88d4cd11cc7.png)

![](../Images/3d3cb282db3bb1bde01aef28cc619d2f.png)

![](../Images/905e3a221712fe99aa8a20fe1dc605b3.png)

![](../Images/6e2f9cf6d789fdbe1046bbf4ec458252.png)

![](../Images/0af7e0990784d7ae5173583eba2b77c6.png)

安装完成根据提示重启，但依然不能全屏，需要关闭macOS自带的SIP系统保护机制。

方法1：修改配置文件：

/Library/Preferences/Systemconfiguration/com.apple.Boot.plist

但我发现该配置文件在root用户下修改依然无法保存。经测试先要突破SIP限制才能修改macOS系统资源库文件。

![](../Images/40faf58d6ac3ae09566878d4f1919fb5.png)

  

方法2：重启系统进入终端修改，这样更改的配置保存到NVRAM中，对整台机器生效，重新启动即可。

（1）重新启动虚拟机中的操作系统

（2）按住Command（即对应Windows键） + R键，会进到安装界面

![](../Images/24958701ea6827644d71b38bb93ec349.png)

  

（3）输入：csrutil disable回车

![](../Images/1f9eb858361df0d30f5c415c08c92b8c.png)

成功全屏：

![](../Images/e0ee8b84d1faa9cef73850f434ffdc14.png)

四、碰到的问题

1.安装macOS High Sierra 10.13.cdr或10.12版本碰到问题：一直重启卡在如下界面：

![](../Images/3088237324bebb0bed191c0ea479c1e2.png)

解决办法：在.vmx文件末尾添加：cpuid.1.eax = "00000000000000010000011010100101"

  

2.在安装macOS Mojave 10.14.iso镜像到install macOS这一步骤时报错

![](../Images/923bcae30cfa375a44d08d516b43c0ab.png)

This copy of the Install macOS Mojave lapplication is damaged, and can't be used to install macos：此安装macOS Mojave lapplication的副本已损坏，不能用于安装macOS。

可能是该iso文件已经损坏了。
