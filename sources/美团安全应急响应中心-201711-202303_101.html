1.3  step3

admin.php是个很明显的phar反序列化，但有如下waf：
/^phar|smtp|compress|dict|zip|file|etc|root|filter|php|flag|ctf|hint|\.\.\//i

zlib:phar://
同时类secret的hint属性是可控的，先赋值成readfile读取hint（也可以利用前面的xxe来读），flag就在环境变量里，但如果将hint赋值成phpinfo，是不行的，会报错

eval('$flag_'.$what_you_want .'= create_function("",\'echo "flag{' . $what_you_want . '}";\');');

def train(filename,dataset):
    f = open(filename)
    trainingMat = np.zeros((dataset,4))

1.3  step3

然后再对图片进行处理，根据图片，我们可以发现，极有可能是v2的二维码，如图
我们对图片进行"模糊处理"，取每个小格的均值进行判断到底是黑还是白，再还原即可，v2的二维码有25格，加上两边的白边大概是27格，除以27得到一格的宽为多少像素
import numpy as np
from PIL import Image

path=r''
img=Image.open(path+'flag.png')
w,h=img.size[:2]
pixelsize=297//27
def replace(array,size):
    res=np.zeros((w,h))
    for n,a in enumerate(np.hsplit(array, size)):
        for m,b in enumerate(np.vsplit(a, size)):
            tmp=np.nanmean(b)
            if tmp>220:
                tmp=255
            elif tmp<=220:
                tmp=0
            for i in range(len(b)):
                for j in range(len(b[0])):
                    res[m*len(b)+i][n*len(b)+j] = tmp
    return res
img=Image.open(path+r'tmp.png').convert('L').resize((w,h))
imarray=np.array(img)
res=replace(imarray,w//pixelsize)
resimg=Image.fromarray(res)
resimg.show()
