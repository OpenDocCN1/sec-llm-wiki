# 聊一聊，如何让风控更贴近业务？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MDc4MTM3Mg==&mid=2247487132&idx=1&sn=e3fa23d9efb081d0e7fdc80db52dfd31&chksm=ec1bef4fdb6c665992273f644185588665da3a3133c7d5b51189ba7a8d7f007e0e8ac5fda80a&scene=126&sessionid=1681380457#rd](http://mp.weixin.qq.com/s?__biz=MzI5MDc4MTM3Mg==&mid=2247487132&idx=1&sn=e3fa23d9efb081d0e7fdc80db52dfd31&chksm=ec1bef4fdb6c665992273f644185588665da3a3133c7d5b51189ba7a8d7f007e0e8ac5fda80a&scene=126&sessionid=1681380457#rd)

3月31日，由永安在线联合美团安全、汽车之家举办的系列沙龙——**业务安全攻防实践沙龙**（北京站）成功举办。围绕本次沙龙的主题“不同业务场景下的风险问题及攻防实践”，美团信息安全部交易安全负责人李岩，为出席现场的各位嘉宾，带来了干货满满的议题分享，和各位行业伙伴聊了聊，美团安全团队在业务安全这个领域积累的一些方法与经验。

![](../Images/75d28b63c2b917b0ab6549bc24259a6a.png)

美团信息安全部交易安全负责人  李岩

线上流量造假、营销补贴作弊、虚假交易套利等问题时有发生，在激烈的攻防对抗下，如何挖掘未知问题、如何快速发现并定位风险、如何转变为主动对抗……面对这些问题带来的困扰，各大企业的风控安全团队之间，需要一个相互交流经验的机会，取长补短，共同引领行业进步。

![](../Images/70aae3441315278ed4fd98ca902d21c9.png)

沙龙现场

伴随美团业务的快速发展，美团信息安全部在业务安全保障上也投入了大量资源，建立了包含产品策略、技术研发、算法策略、风控运营等职能的专业团队。自主研发了风险实时防控系统，对平台上每天产生的千万级别订单、上百亿访问流量进行监控和分析，建设智能化决策，实时干预风险行为，减少违规违法现象发生。在成果上，除了有效治理平台风险，还向商家、第三方厂商等合作伙伴提供了安全保障。

  

受永安在线之邀，我们在本场沙龙中和业界伙伴们分享了美团在交易安全中，有关业务安全风险控制的分层经验，**《如何让风控更贴近业务——业务安全中的“分层管控”》**。

  

从业务安全的重要性出发，引入了业务安全分层管控的概念——对于不同业务的不同发展阶段、不同场景，业务安全团队需要先对业务有深入了解，从而提炼出支撑整个业务运转的“骨架”，然后再对应地描绘出业务安全团队需要去防控的“骨架”，思考在哪一层会形成哪些攻击，从而各个击破。

![](../Images/b9a535bed5d30b16887d690b8208d957.png)

区分层级后的“立体化”管控

除了理论上的解读，李岩在分享中也将美团在分层管控中的具体实践方式与方法做了介绍，抽象风控体系的搭建过程，区分风险层级，明确参与角色、落实政策要点、制定安全标准、主动做系统约束等，开展“立体化管控”，以此带来风险治理效率的提升。

![](../Images/ccb1df8d6e83df4438c610f6cfd037b0.png)

身处一个快速发展的互联网企业之中，做风险防控更多的是要主动参与，做规则的设计者。同时，作为一名风控从业人员，一定要有一颗“大心脏”，去正确面对突发事件，时刻用一颗对行业充满敬畏的心，去拥抱变化。

  

短暂相聚，真诚交流，在几位演讲嘉宾精彩的发言和互动环节之后，本次沙龙也来到了尾声，尽管对整个行业来说，这样坐在一起，交流学习只是一个开始，但对所有业务安全从业者来说，有了这个开始，我们就不再是孤军奋战，在与黑灰产对抗的路上，我们终会并肩前进！

  

最后，感谢永安在线本次的邀请与业界伙伴的支持与关注，也期待本系列沙龙其他站的精彩开幕！
