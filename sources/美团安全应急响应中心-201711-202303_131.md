# 以一场年终盛宴，送别2020！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MDc4MTM3Mg==&mid=2247486572&idx=1&sn=02cb6d746fadc67782680e3102bee107&chksm=ec1bedbfdb6c64a97d0dbd29f47942a75874b042f45f1078c3a668a8b1e4df5e277efa577e11&scene=126&sessionid=1681380462#rd](http://mp.weixin.qq.com/s?__biz=MzI5MDc4MTM3Mg==&mid=2247486572&idx=1&sn=02cb6d746fadc67782680e3102bee107&chksm=ec1bedbfdb6c64a97d0dbd29f47942a75874b042f45f1078c3a668a8b1e4df5e277efa577e11&scene=126&sessionid=1681380462#rd)

踩着岁末的“小尾巴”，赶赴一场安全圈的年终盛宴！2020年12月29日～30日，美团安全应急响应中心（以下简称MTSRC）来到上海，带着满满的期待与诚意十足的美团好礼，现身由FreeBuf、赛博研究院、上海市信息安全行业协会联合主办的 **CIS 2020网络安全创新大会 **（2020 Cyber Security Innovation Summit，以下简称CIS大会），与众多业界顶尖白帽、行业伙伴共赴盛典，送别2020！

![](../Images/8c5f2489935cd2c9b89b1da6e854cfac.png)

  

![](../Images/4eddddd359a5cc4d06c55d64b6142a9d.png)

**送别2020，我们有「礼」了！**

![](../Images/4eddddd359a5cc4d06c55d64b6142a9d.png)

  

![](../Images/d55e6cfba0d31dbff3d6bcd35c1d4b22.png)![](../Images/d955110e2c71d2b96a8377c20751e19e.png)![](../Images/d84ce725134d4da90283fc71ef736e20.png)![](../Images/85f647666c2687cb8510e02e73c9e263.png)![](../Images/bfa391a0afc34d56b5d16b84a9398913.png)

在本次CIS大会的互动活动展区，MTSRC展位依旧延续着自身**“****热血+热闹”**的参展氛围，用火热的线上、线下小游戏引爆了观众互动区的竞技热潮，再加上美团限量周边小礼物的魅力加持，赢得了在场诸多白帽子与行业伙伴的驻足参与和点赞肯定。  

![](../Images/1bee902d02fbc452bf543411a9fb5a08.png)

作为本次大会的参会厂商之一，在大会现场，我们不仅和多位行业伙伴面对面进行了业务上的经验交流，也遇到了许多“熟悉又陌生”的白帽子面孔，只要见了面就会拉近一些彼此间的距离，因此每一次这样的参展机会，对MTSRC来说都弥足珍贵。

![](../Images/e9158aabd2e041f1e4d7a4429f338be2.png)

  

![](../Images/4eddddd359a5cc4d06c55d64b6142a9d.png)

**送别2020，我们有「奖」拿！**

![](../Images/4eddddd359a5cc4d06c55d64b6142a9d.png)

  

对我们来说，本年度最大的惊喜，莫过于CIS大会颁发的**“年度安全SRC”**大奖，这个奖项的获得，是众多白帽子对我们一年以来工作的肯定，是行业同仁对MTSRC的支持与认可，更是我们团队每位成员未来前进的动力！

![](../Images/b673f7cac4dbc4179c85026511d16461.png)

**年度安全SRC**

![](../Images/63d56f62aec3355d0fa83186bc441ff3.png)

因为手握这份荣誉，我们有信心成为更好、更有潜力的SRC团队；也因为被赋予的这份责任，今后的日子里，MTSRC也将不忘初心，继续做好白帽子与企业间沟通对话的桥梁。  

  

展会现场，团队的运营小姐姐也通过现场直播，介绍了MTSRC的运营及奖励现状，解答了一些大家关心的挖洞问题，未来我们也会继续挖掘新形式，对话已入驻、未入驻MTSRC的白帽子们，让更多领域从业者看到、了解、加入我们。

![](../Images/bedf75a60e0aed587784327491f78add.png)

  

![](../Images/4eddddd359a5cc4d06c55d64b6142a9d.png)

**送别2020，我们有「话」说！**

![](../Images/4eddddd359a5cc4d06c55d64b6142a9d.png)

  

在30日下午的专场分享会上，来自美团安全团队的安全专家杨成明，也通过远程参会为现场听众带来了他的议题分享——《漏洞挖掘和检测在智能设备中的最佳实践》。

![](../Images/f432ae285b33a654eefd52b9ab422ea6.png)

通过结合实际的Android类智能设备，成明阐述了如何通过自动化漏洞检测平台，提升量产前和存量设备安全，以及怎样结合线上大数据平台进一步收敛各类风险，精彩的议题内容，引起了很多在场听众的留步与关注。

![](../Images/02dc893315f3fa6ae5422c6755605d9a.png)

也正如成明在分享中说的那样——我们的安全团队是一个氛围很好的团队，如果你也正在寻找新的发展机会，欢迎加入我们，共筑安全长城！

  

最后，在送别2020年的最后一天，MTSRC也在此祝愿所有白帽子们、安全行业的同仁们，新的一年平平安安，2021年，我们期待更多好事发生！

  

**再见！2020！我们在2021，等你！**
