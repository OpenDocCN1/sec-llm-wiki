## Gophish钓鱼：

Gophish是一款基于邮件钓鱼工具，它的主要功能便是：

*   • 克隆登录页面。
    
*   • 群发邮件。
    
*   • 监听目标是否触发事件。
    
*   • 监听目标提交的数据。
    
*   • 将目标重定向。
    

### 安装部署：

安装依赖：

```
>> apt install postfix
```

如有防火墙还需要开放指定端口，通常默认为25端口。更改配置文件：

```




>> vim /etc/postfix/main.cf
```

更改DNS解析记录：

![](../Images/f4ea8b8811b4519e2554d0f75ed56849.png)

为邮箱域名添加一个A记录的子域名，将其记录值指向服务器的IP地址，并添加一个MX记录，主机记录为自己的域名，记录值为邮箱域名全称。然后下载Gophish：

```
https://github.com/gophish/gophish/releases/tag/v0.11.0
```

将其部署到服务器上：

```
>> 
```

配置文件很简单：

```


─>> cat config.json
```

启动gophish，在第一次启动时，以下启动信息会包含一个用户名口令，因为我是第二次启动，已经更改过了，所以没有：

```

>> ./gophish
```

访问管理面板，输入账号密码即可，一目了然的功能界面：

![](../Images/2aa5b75ef5c31459d45ddba22a0cc010.png)

## 强制认证

### Execution via Hyperlink：

在微软的Office word 文档中，支持给特定文本部署超链接，

![](../Images/435efbe0f5d36bc40b115cbf49c08e3c.png)

遐想我现在处于一片内网环境中，我的IP为：

```



>> ifconfig         
```

我可以构造如下超链接：

![](../Images/89423777ed0941d32fc6b0fbc7eeefb6.png)

然后通过**responder**监听指定网卡：

```






>> sudo responder -I eth0
```

如果目标点击了office文章的超链接，会弹出一个框：

![](../Images/b91810664a77097304b7babccac00296.png)

这是微软安全中心的身份验证，如果目标输入了。就会被嗅探到目标的NTMLv2 的Hash，可暴力破解其明文口令：

```
>> hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt --force
```

![](../Images/4fdc10fe9358b39cc63abc5a82e8ec83.png)

但是有趣的是，如果是一个SMB协议的超链接：

![](../Images/fad91e54fde6a4e5c157318e4d46745d.png)

如果被人点击了，虽然也会弹出一个身份验证的输入框：

![](../Images/3abf266e2237b4ed100edf8dbfcd4407.png)

但是，应该很明显能够看到，拒绝访问的提示信息，是因为，在用户点击超链接时：

![](../Images/abdf52433e4b08432cc18815e8d61b1d.png)

Windows在用户输入账号密码前，会与访问目标发送多次流量信息，其中包含有一些哈希凭证，也就说在用户输入凭证前，操作系统已经使用本地存储的凭证与目标发生过一些凭证认证，但是失败了，所以Windows安全中心才会有**拒绝访问**的提示。

这也帮助了我一个大忙，因为即使用户没有输入任何口令凭证，我依然能捕获到该用户的哈希，然后对其进行暴力破解：

![](../Images/f58a7d8fec1f682b9ba0126049da26a6.png)

### SCF：

SCF文件利用的smb协议共享的缺陷，只需制作一个简单的SCF文件：

```




[Shell]
```

目标只要读取到这个文件，就会顺着我给定的IP发起访问链接，我就可以从网卡捕获到目标的哈希，所以这个文件中所包含的路径信息不重要，它包含的nc.ico文件到底存在不存在也不重要，重要的是让目标向我发起网络访问请求。我可以将文件命名为@hack.scf。因为在文件名前加一个@会在共享目录中拥有一个置顶的效果。然后启动SMB协议共享服务：

```




>> ./Tools/Impacket/examples/smbserver.py share .
```

好吧，启动不了，不知为何 SMB 与 responder 会发生端口冲突的问题，但是无所谓，可以请第三方入场：

```
C:\
```
