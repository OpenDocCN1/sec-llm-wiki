物联网安全之FirmAE固件模拟仿真


1

前言


FirmAE是一个完全自动化的IOT固件模拟仿真框架，可以进行仿真和漏洞分析。FirmAE通过五种仲裁技术大大提高了仿真成功率（从Firmadyne的16.28%到79.36%）。FirmAE成功模拟了来自前八名供应商的1,124个无线路由器和IP摄像头的固件。

FirmAE还开发了一个用于发现0day的动态分析工具，它根据目标固件的文件系统和内核日志推断出网络服务信息。通过在成功模拟的固件镜像上运行工具，共发现了12个新的0day，影响了23个设备。

模拟仿真环境搭建、使用及调试


(1) 前置环境配置

squashfs-tools 安装，安装依赖库文件，默认配置安装即可。

sudo apt-get install build-essential liblzma-dev liblzo2-dev zlib1g-dev

下载源代码：

git clone https://github.com/devttys0/sasquatch.git

源码编译：

cd sasquatch && ./build.sh

sasquatch build过程中会出现如下报错：

可以执行如下指令重新编译，能够解决错误。

git clone --quiet --depth 1 --branch "master" https://github.com/devttys0/sasquatch

cd sasquatch

wget https://github.com/devttys0/sasquatch/pull/51.patch && patch -p1 <51.patch

sudo ./build.sh

(2)下载并安装FirmAE工具

下载FirmAE固件模拟仿真工具：

git clone --recursive https://github.com/pr0v3rbs/FirmAE

cd到FirmAE目录下运行download.sh脚本，下载时间可能会比较久。

下载完成。

完成下载后执行安装脚本install.sh,在安装的过程中会进行多次的确认，默认配置安装即可。

(3)使用FirmAE模拟仿真固件

安装成功后执行初始化脚本init.sh

开始模拟仿真固件之前运行run.sh使用“-c”参数，执行分析模式对固件进行check, check模式会对固件进行仲裁仿真的各项操作，将设备运行后，检查网络连通性和服务可用性，最后仿真退出，保存相关的日志信息记录在缓存文件中。

./run.sh -c DIR /home/kali/Desktop/DIR-320A1_FW121WWb03.bin

分析模式运行完后，使用“-r”参数开始进行固件模拟仿真，run模式是根据check模式构建的各种处理信息进行仿真，在仿真程序时不会退出，在执行了check模式后再进行模拟仿真速度会更快。

./run.sh -r DIR /home/kali/Desktop/DIR-320A1_FW121WWb03.bin

(4)调试与分析

固件模拟仿真成功后会涉及到调试分析或文件传输等操作，FirmAE提供了调试脚本。

另起一个shell，cd进入到FirmAE目录并执行debug脚本。

python debug.py IID


4

总结


随着万物互联时代的到来，物联网安全变得越来越重要。固件是物联网设备的关键组成部分，固件决定了物联网设备的功能与性能，如果固件出现安全漏洞，就会对该物联网设备的使用带来严重的安全隐患，IOT固件安全也正因此而变得至关重要。

固件模拟仿真可以极大的方便研究者进行测试、调试和研究，但是由于设备真实环境和模拟仿真固件执行环境的差异化，使得模拟仿真的成功率极低，几乎没有一个工具能够模拟所有硬件设备。所以在固件研究过程中多了解相关模拟仿真工具的原理及可模拟仿真固件的情况后，才可以根据实际要求去选择合适的模拟仿真平台。
