# 利用Firmadyne进行固件模拟

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1ODk1MzI1NQ==&mid=2247486554&idx=1&sn=b87bc5bfa0c28e7b2eebfd75cb3035b0&chksm=fc1fea12cb6863040ef28e10037c1b073bfbd96eb820787fbe40c7801f67e6d517c5cd9cd0db&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1ODk1MzI1NQ==&mid=2247486554&idx=1&sn=b87bc5bfa0c28e7b2eebfd75cb3035b0&chksm=fc1fea12cb6863040ef28e10037c1b073bfbd96eb820787fbe40c7801f67e6d517c5cd9cd0db&scene=27#wechat_redirect)

**1**

**前言**

  

在安全研究过程中，当分析路由器固件的时候，手边没有实际设备，只能使用软件模拟，当前对于固件模拟比较好的解决方案就是 Firmadyne。Firmadyne是基于qemu，binwalk等开源工具的整合工具，可以真正做到全模拟固件。本篇文章介绍的是如何利用Firmadyne进行固件模拟。  

  

**2**

**虚拟机环境****ubuntu22.04.1 TLS**

  

**第一步，下载固件分析工具包。**

sudo git clone –recursive https://github.com/attify/firmware-analysis-toolkit.git

![](../Images/3370d13900c3ab38fa5949cf027489b9.png)

固件分析工具包就是firmware-analysis-toolkit

![](../Images/0ec8c1044e0067d5f0fa8155f7b20581.png)

**第二步，切换到管理员模式，然后执行安装文件setup.sh**

![](../Images/8e471b4c5110dd82d6d9e4ddd0b692aa.png)

为了模拟固件运行环境，需要安装的包括firmadyne，binwalk以及一些依赖包，这一步，需要等待一段时间。

**第三步，安装qemu，并检查binwalk及qemu安装情况**

1、安装qemu的命令

sudo apt-get install qemu 

sudo apt-get install qemu-user-static

sudo apt-get install qemu-system

2、检查binwalk的安装情况，常用于固件分析及提取文件系统。

固件扫描binwalk xxx.bin，可以看到一些基本信息，比如squashfs文件系统，小端字节序等。

![](../Images/1dc64b6528fc439716776f25230f5b8b.png)

固件提取binwalk -Me xxx.bin，得到的文件夹里边有一个标准的linux系统squashfs-root

![](../Images/378bc44d149780cf92417f32c3686d1b.png)

3、查看文件类型 file bin/busybox，可知是MIPS类型。

![](../Images/1b71c6fe49cab05c9a40c0b802a80867.png)

4、检查qemu安装情况

首先，需要根据文件的类型，复制相应的qemu 模块 cp /usr/bin/qemu-mipsel-static ./

![](../Images/2a725d6dc88ba22f8f37cb1095b47b57.png)

然后，通过以下命令运行qemu，如果出现如下情况，说明qemu安装成功。

sudo choot . ./qemu-mipsel-static /bin/busybox

![](../Images/ac74d439c81115b08b10ed332381130f.png)

**第四步，利用firmadyne进行路由器固件模拟**

本质上是利用firmware-analysis-toolkit里面的fat.py进行固件模拟。

1、修改配置文件fat.config，管理器权限的密码。

![](../Images/8a9d3bda4cf4296f56e8c181ed742107.png)

2、运行固件，这里要注意运行的是原始bin文件，注意写对bin文件路径。

sudo ./fat.py /home/yuwan/xxx.bin

这就运行固件模拟成功啦，并且得到了一个可以访问内部环境的web接口。

![](../Images/15b96825ba04ac5bb5ef9d7aefe54204.png)![](../Images/98f320ec2cbad2a0bc3995f424b88721.png)

3、可能出现的错误1，卡在了Extracting the firmware这步。

![](../Images/2b1f5070094a0c3e7be2cb126f120842.png)

解决办法：sudo ./reset.py 存在以前的工作区导致的问题

4、可能出现的错误2，卡在了network connection这步。

![](../Images/ae2125f7cdc37c2e9b9dc4243e2555a3.png)

解决方法：ubuntu20.04 使用firmadyne 的问题

将./firmadyne/scripts/makeImage.sh 文件中的第63行

TARBALL\_SIZE=$(tar ztvf "${TARBALL\_DIR}/${IID}.tar.gz" --totals 2>&1 |tail -1|cut -f4 -d'')

替换为

TARBALL\_SIZE=$(tar ztvf "${TARBALL\_DIR}/${IID}.tar.gz" --totals 2>&1 |tail -1|cut -f2 -d':'|cut -f2 -d' ')
