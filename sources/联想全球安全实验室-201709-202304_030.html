前言

我们在开发程序的过程中，会经常遇到如何去校验URL的场景。不管是WEB，还是APP，都会有这样类似的需求。但是这种需求如果处理不当，就会造成安全隐患。本文以PHP脚本语言为例，说明URL校验是如何被绕过的。


因为RFC中对URL的描述格式大概是下面这样的：

<protocol>://<user>:<password>@<host>:<port>/<url-path>

【此处参见：https://www.ietf.org/rfc/rfc1738.txt】

常见的URL协议大概就是http,https。


1

直接判断是否包含白名单域名

视开发语言不同，可能用到的代码有：contains，strpos，indexOf等等。


问题代码示例：

$url = $argv[1];

$white_list=array('lenovo.com','lenovo.com.cn','lenovo.cn');


function checkurl1($url){

       global $white_list;

       foreach($white_list as $k=>$v){

              if(strpos($url,$v) !== false){

                     echo "OK!White1!\n";

              }

       }

}


从整体上看，貌似没有问题，只要URL中包含列表中的几个域名就提示白名单。但是，这种是很容易绕过的，也是最容易绕过的。比如下面这种方式：

在URL的path中随便加个白名单字符，就可以绕过了。


2

判断第一个://和第一个/之间的字符串

上面的情况，都是通过在URL的后半部分做手脚，那我们只取://和/中间部分来判断，是否就可以了呢？


示例代码：

function checkurl2($url){

    global $white_list;

    $input = str_replace("://","^",$url);

    $domain = substr($input, strlen("^")+strpos($input, "^"),(strlen($input) - strpos($input, "/"))*(-1));

    echo "CHECK2:".$domain."\n";

    foreach($white_list as $k=>$v){

        if(strpos($domain,$v)){

            echo "OK!White2!\n";

        }

    }

}

这样看起来确实规避了通过path字段和传参来检测白名单域名的方式。但是，这种方式可以这么来绕过。

把白名单域名作为URL中的账号，就可以绕过了。


3

直接用parse函数取host字段

类似的JAVA代码为：

/*

示例代码：

function checkurl3($url){

    global $white_list;

    $tmp=parse_url($url);

    $domain=$tmp['host'];

    echo "CHECK3:".$domain."\n";

    foreach($white_list as $k=>$v){

        if(strpos($domain,$v) !== false){

            echo "OK!White3!\n";

        }

    }

}

4

直接取endwith来判断域名

比如某些场景下，我们允许*.lenovo.com。这个时候可能考虑到host以lenovo.com结尾，就可以认为是在我们的白名单里。


常见的思路大概是考虑先取出host字段，然后再判断以lenovo.com结尾。

示例代码如下：

function checkurl4($url){

       global $white_list;

       $tmp=parse_url($url);

       $domain=$tmp['host'];

       echo "CHECK4:".$domain."\n";

       foreach($white_list as $k=>$v){

              if(endsWith($domain,$v)){

                     echo "OK!White4!\n";

              }

       }

}


function endsWith( $haystack, $needle ) {

    $length = strlen( $needle );

    if( !$length ) {

        return true;

    }

    return substr( $haystack, -$length ) === $needle;

}


但是这样的代码，可以被前面的方式3绕过，也可以用下面的方式来绕过。

没错，只需要付出很小的成本，注册一个域名，以白名单的域名结尾即可绕过。


总结 • 正确的思路

1、取host字段；

2、判断正确域名结尾的时候，同时还要考虑根域名前面的”.”，即考虑以”.lenovo.com”结尾即可；

3、考虑到浏览器可能会把\自动转换成/，还要过滤掉URL中的\

示例代码：

function checkurl5($url){

    global $white_list;

    $tmp=parse_url($url);

    var_export($tmp);

    $domain=$tmp['host'];

    $domain = str_replace("\\","",$domain);

    echo "CHECK5:".$domain."\n";

    foreach($white_list as $k=>$v){

        if(endsWith($domain,".".$v)){

            echo "OK!White5!\n";

        }

    }

}
