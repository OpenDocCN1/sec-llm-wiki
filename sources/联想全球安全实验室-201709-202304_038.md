# 聊聊元宇宙的安全威胁（Security Threats in Metaverse）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1ODk1MzI1NQ==&mid=2247485995&idx=1&sn=1f09c399bea73e4c3593534923f6e629&chksm=fc1fec63cb68657589de06cee12da47737431e6742bdbe9106675bf2fe55e6af74b10a1c5ded&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1ODk1MzI1NQ==&mid=2247485995&idx=1&sn=1f09c399bea73e4c3593534923f6e629&chksm=fc1fec63cb68657589de06cee12da47737431e6742bdbe9106675bf2fe55e6af74b10a1c5ded&scene=27#wechat_redirect)

**2021年年末，联想围绕XR（混合现实）场景发布了智能眼镜（ThinkReality），安全实验室在该系统的研发过程中，参与了这个产品的安全威胁建模等工作。过程当中不仅接触到了如何通过3D UI技术构建元宇宙的架构设计，作为一个不算太新的新兴领域，这种新的人机交互模式，也带来了一些新安全问题。**

  

**举一个不太难懂的比喻，桌面PC时代，显示器给人们造了一扇窥探数字世界的窗户（“Windows”），智能便携终端（手机、pad、穿戴设备）给用户带来了一扇可以揣进口袋的窗，而元宇宙则是直接把这扇窗户打开，让我们可以伸出头，甚至可以说成为了一扇任意门，直接让我们走进了数字化世界。**

  

**而当我们真的可以直接大步迈进数字化世界，曾几何时只存在网络安全领域的刀光剑影，也变得更加具象化且影响直接。我总结了一些比较典型的安全问题在元宇宙下可能存在的风险，希望能给后续的元宇宙项目的安全防护带来一些启发。**

![](../Images/650d28facc33472b1871099e52552226.png)

  

**UI层攻击——点击劫持可能会成为最广泛的风险之一**

**Web 2.0时代下，点击劫持或许可以算作相对低危但却最为恼人的攻击向量了，我们在浏览一些不太正规的网站时，或多或少都体验过弹窗广告的问题，这背后其实存在着大量的风险，透明罩层引发的点击劫持作为一个常见的安全风险，或许在未来的元宇宙世界会变得更加难以捉摸。**

![](../Images/50ea8865cd2e09b4215e3f8eba37637e.png)

**我们看到浏览器厂商作出了大量努力以应对这种风险，通过限制原有组件上层罩层的渲染配置（X-Frame-Options）进行防护。但是这样的措施很可能会在三维坐标系中失效，一种潜在的防护方式是对可能执行特定行为的3D物件要求其在一定半径范围内的透明物件进行着色标记，并且在敏感行为执行前的告警，但这无疑会带来更差的用户体验，因此目前来看，基于UI的设计原理变化，原有二维平面的攻击会变得更加复杂且难以捉摸。**  

![](../Images/c7b440c85eec45ee1931065a6788aedf.png)

  

**更难察觉的恶意拷贝——钓鱼攻击变得更容易**

**钓鱼攻击过去在客户端软件中是重灾区，但是在Web领域，我们也可以看到浏览器厂商做了很多工作，例如建立钓鱼站点的黑名单机制、增加HTTPS的Enterprise验证，这些都帮助缓解了Web钓鱼网站的风险。**

![](../Images/0b4932b4d54d2536b6c7835757ef1cf2.png)

**但是放到VR空间中，我们却很难辨别用户自定义组件与某些“官方组件”的差异，例如当三台ATM机出现在你面前时，如何区分哪一台才是真正的ATM机或许会是个很让人头疼的问题（不过按理说，ATM机这种在数字化时代就已经快淘汰的东西压根就不应该在元宇宙世界存在了）。**

![](../Images/0d2b2ac010b50fbf2d0a0d8d218b9d79.png)

  

**用户自定义行为的引入——无处不在的注入风险**

**注入类攻击对于大部分软件系统而言，已经是一个无孔不入的话题了，不管是常见的SQL注入，还是XSS、Deserializer attack，甚至近期发生的JNDI注入（log4shell），任何允许用户自定义编码行为执行的系统，都难以幸免注入漏洞。而在元宇宙，我们可能需要面对的注入风险可能引发的问题会更多，例如VRchat中就提供用户自定义空间的编码行为，如果出现一些未经检验的用户输入携带篡改原有行为的恶意指令，则有可能会导致VR世界中的一些组件原有行为发生异常、甚至泄露用户的数据信息和资产。**

![](../Images/c3bf7526e85d7f5bfc1a6f24fb68b853.png)

  

**复杂的供应链风险更加严峻**

**大部分XR设备存在复杂的供应链关系，从硬件固件到操作系统，从系统服务到应用，再到应用内构建的元宇宙元素，毫无疑问，将用户输入输出也纳入了接近现实的一部分展现给其他用户的元宇宙，是个一层层的套娃，我们在ThinkReality项目中已经能观察到这种情况（高通的解决方案、Google的基础安卓系统、Unity的3D引擎、联想的软件整合团队），并且随着技术的发展，这些供应商也将进一步融合到完整的产品中，一体呈现，作为上层的产品品牌与应用开发者，都需要避免供应链引发的安全风险，这也是元宇宙下的安全难题。**

![](../Images/f550587fc6c1b1c64b6be24944efb40b.png)

  

**网络空间不是法外之地，元宇宙数字空间更不是**

**刚刚聊了非常多的网络安全进入元宇宙时代的安全风险，可以预见未来元宇宙也会像大多数新兴行业（例如大数据、区块链）一样面临严峻的合规问题。我们看到国家对“网络空间”的定义日渐成熟，也可以期待元宇宙这个代表了“数字空间”的许愿池，势必会引发大量的道德和法律层面的探讨。现阶段我们已经可以看到《网络安全法》、《数据安全法》、《个人信息保护法》等围绕一些安全话题进行了详细的法律约束，相信随着元宇宙逐渐成型，我们也可以看到相应的法规落地帮助用户更安全放心地享受这份足不出户纵横四海的技术变革盛宴。**
