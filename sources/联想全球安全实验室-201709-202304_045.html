简 介

Fastjson是阿里巴巴的开源JSON解析库，它可以解析JSON格式的字符串，支持将Java Bean序列化为JSON字符串，也可以从JSON字符串反序列化到JavaBean。


Fastjson 特性：

（1）提供服务器端、安卓客户端两种解析工具，性能表现较好。

（2）提供了 toJSONString() 和 parseObject() 方法来将 Java 对象与 JSON相互转换。调用toJSONString方 法即可将对象转换成 JSON 字符串，parseObject 方法则反过来将 JSON 字符串转换成对象。

（3）允许转换预先存在的无法修改的对象（只有class、无源代码）。

（4）Java泛型的广泛支持。

（5）允许对象的自定义表示、允许自定义序列化类。

（6）支持任意复杂对象（具有深厚的继承层次和广泛使用的泛型类型）。

由于Fastjson的部分特性，导致其存在严重的RCE漏洞。


受影响版本

Fastjson <= 1.2.68


Fastjson 1.2.47漏洞分析

Fastjson在开始解析json数据前会预先加载配置，位于com/alibaba/fastjson/util/TypeUtils.class中的addBaseClassMappings和loadClass方法将一些经常会用到的基础类和三方库存放到一个mappings对象中，类似于缓存机制。

配置加载完成后，运行程序首先进入了com/alibaba/fastjson/parser/ParserConfig.class的checkAutoType模块中，程序调用getClassFromMapping方法对typeName进行解析。

com/alibaba/fastjson/util/TypeUtils.class中的getClassFromMapping方法如下图所示，其中mappings的数据已经在解析json数据之前预先加载完成。

当我们构造的typeName不在mappings中时，getClassFromMapping方法返回null，程序进入下一个if分支，调用deserializers.findClass方法。

对findClass方法进行分析可以发现，程序会遍历buckets与我们构造的typeName进行比较，如果存在相同，则将clazz对象返回，即将我们构造的typeName返回。

在findClass方法执行完成后，程序进入到checkAutoType进行安全检测，安全检测完成后将typeName赋值给clazz。

CheckAutoType在将clazz返回后程序进入com/alibaba/fastjson/serializer/Mis

cCodec.class的deserialze方法中。

在deserialze方法中，有将任意类加载到mappings中的功能，如下图所示。

程序从输入的json字符串中获取val的值。

在loadClass()中，我们可以看到当cache参数为true时，会将clazz放入mappings中，即在同一次会话连接的过程中，如果同时传入两个json值，程序在解析第二个json值的之前可以将第一个json值中的恶意类加入到mappings中，从而绕过检测。

如下图所示，mappings中已经添加了恶意类：com.sun.rowset.JdbcRowSetImpl。

最后在处理第二个json值的过程中，由于mappings中已经存在恶意类，所以不会再进行checkAutoType安全检测，直接利用JNDI来进行RCE攻击。
