云服务已经成为一种趋势，这次让我们简单聊一聊云安全，了解一下云的一些基础概念、攻防手段等。

  

**基础概念**

![](../Images/8c844d4916e8fc0620188049cffe80de.png)

云计算按照商业模式的不同，一般分为三类：公有云、私有云以及混合云。按照服务模式的不同，也分为三类：基础设施即服务（IaaS）、平台即服务（PaaS）以及软件即服务（SaaS）。下面我们来了解一下这些模式的区别与联系。

  

1

//  **商业模式分类：**

**  1.1 公有云**

公有云，这是我们最常见到的云的形态。公有云通常是由第三方云服务提供商拥有和运营。所有的硬件、软件以及其他支持性的基础设施均为提供商所有和管理。常见的有阿里云、IBM Cloud、Microsoft Azure、AWS、Google云等。

![](../Images/477f847bc0d76f9028b3ff7c6abb0b67.png)

显而易见，公有云的优势：成本低（因为不需要我们单独购买硬件、软件）、无需维护、很好的缩放性以及高可用性等。

  

**  1.2 私有云**

私有云，更像一个定制化的云。他是专门为一个客户单独使用而构建的云计算资源。在私有云中，服务以及基础设施始终在私有网络中维护，这样使得组织更加方便的自定义资源，满足特定的需求，同时在数据以及安全性等方面都有了很大的保障。灵活性高、缩放性高、安全性高是私有云的优势。

  

**  1.3 混合云**

混合云，通常被认为是“两全其美”的云计算资源。顾名思义，他将本地基础设施（私有云）与公有云相结合，数据可以在私有云和公有云之间移动，更加的灵活。同时兼顾安全性的考虑，有更多的部署选项。比如：可以将电子邮件等低安全性需求的系统要求使用公有云，对财务报表等敏感性高以及对业务起关键性作用的高安全性需求的系统可以要求使用私有云。业务的所有敏感方面都可以通过由组织完全控制的私有云系统来处理。

  

混合云的优势就包括了控制性高、架构灵活、成本效益高、安全性高等。

  

2

//  **服务模式分类：**

接下来，我们聊一下三种不同的服务模式，也就是Iaas、Paas、Saas。为了更好的理解，我们引用IBM 的软件架构师 Albert Barron 的披萨比喻，来解释这个问题。

  

**2.1 laaS（基础设施即服务）**

IaaS表示由云服务提供商通过互联网连接来管理基础设施。他主要提供了包括服务器、存储、网络、负载均衡器等基础服务，并且负责处理中断、维修及硬件问题。诸如操作系统、中间件、应用等内容由用户进行管理。

依据Albert Barron 的披萨比喻，可以形象的理解为：他人提供厨房、炉子、煤气，用户使用这些基础设施，来烤自己的披萨。

  

![](../Images/063f7a3f8f9e9669e196b98d6f99db6d.png)

  

** 2.2 PaaS （平台即服务）**

PaaS表示由云服务提供商提供硬件和应用软件平台，包括：数据库、开发环境、Heroku(云平台开发环境)、CRM、Cloud Foundry、OpenStack等。用户主要负责平台上运行的应用以及应用所依赖的数据。

依据Albert Barron 的披萨比喻，可以形象的理解为：除了基础设施外，别人还提供披萨饼皮。用户只要把自己的配料洒在饼皮上，让他帮着烤出来就行了。换而言之，用户需要做的就是设计披萨的味道，他人提供平台服务，让用户把自己的设计实现。

  

![](../Images/45aac16a2b75431cc3fc61bbfe7749b8.png)

  

**  2.3 SaaS （软件即服务）**

SaaS是将云服务提供商管理的软件应用交付给用户的服务。SaaS应用是一些成型的用户可以通过浏览器访问的web应用或移动应用，他会为用户完成常规软件维护工作。

依据Albert Barron 的披萨比喻，可以形象的理解为：他人直接做好了披萨，不用用户的介入，到手的就是一个成品。用户要做的就是把它卖出去，最多再包装一下，印上用户自己的 Logo。

  

![](../Images/dc9ae4702697cd203c0ea41e5e3615db.png)

  

3

//  **常见云术语：**

● RDS：关系型数据库服务（Relational Database Service，简称 RDS）是一种稳定可靠、可弹性伸缩的在线数据库服务。采用即开即用方式，提供数据库在线扩容、备份回滚、性能监测 及分析功能。

● ECS：云服务器（Elastic Compute Service，简称ECS）。

● 安全组：一种虚拟防火墙，具备状态检测和数据包过滤功能，用于在云端划分安全域。同一安全组内的ECS实例之间默认内网网络互通。

● OSS：对象存储（Object Storage Service），是阿里云对外提供的海量、安全和高可靠的云存储服务。

● Bucket：OSS上的命名空间，也是计费、权限控制、日志记录等高级功能的管理实体。他有以下特点：1、全局唯一性，且不能修改；2、存储在OSS上的每个Object必须都包含在某个Bucket中；3、一个应用，例如图片分享网站，可以对应一个或多个Bucket。

   ■ 这里值得一提的是，Bucket的访问权限分为public-read-write、public-read、private。（对于存储在oss上的资源可以根据不同的需求进行最小权限设置，来提高相应的安全性）

   ■ public-read-write: 任何人都可以对该bucket中的object进行上传、下载和删除操作

   ■ public-read: 只有该bucket的创建者可以对该bucket内的Object进行写操作

   ■ private：只有该bucket的创建者才可以访问此Bukcet。其他人禁止对此Bucket做任何操作。

● Access Key身份验证凭证。这个密钥相当于账户的API调用凭据，具有账户完全的权限（一旦泄露，会遭受致命的打击）

   ■ 阿里云用户可以在管理控制台里自行创建 Access Key，Access Key是由AccessKey ID 和 AccessKey Secret 组成。

   ■ 其中 ID 是公开的，用于标识用户身份，Secret 是秘密的，用于用户鉴别。

  

**云渗透方法**

![](../Images/8c844d4916e8fc0620188049cffe80de.png)

黑客精神是迎难而上和精益求精的精神。其实云渗透和常规的渗透是没有任何区别的，只是词变了，本质是一样，也会存在常规的漏洞SQL注入、弱口令、文件上传、网站备份泄漏等等。

当然除了常规的Web漏洞也会有随着新技术带来新的风险例如AccessKey泄漏利用等。除此之外还可以通过特殊手段可以获取目标镜像，还原Vmware虚拟机或者通过Diskginus查看文件等等。
