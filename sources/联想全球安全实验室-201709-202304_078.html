基本概念

射频（RF）是RadioFrequency的缩写，表示可以辐射到空间的电磁频率，频率范围从300kHz～300GHz之间。射频就是射频电流，是一种高频交流变化电磁波的简称。每秒变化小于1000次的交流电称为低频电流，大于10000次的称为高频电流，而射频就是这样一种高频电流。

在电子学理论中，交变电流通过导体，导体周围会形成交变的电磁场，称为电磁波。在电磁波频率低于100kHz时，电磁波会被地表吸收，不能形成有效的传输，但电磁波频率高于100kHz时，电磁波可以在空气中传播，并经大气层外缘的电离层反射，形成远距离传输能力。我们把具有远距离传输能力的高频电磁波称为射频。射频技术在无线通信领域中被广泛使用，有线电视系统就是采用射频传输方式。

工具介绍

HackRF One是由Great Scott Gadgets创建和制造的软件定义无线电（SDR）半双工收发器。


软件定义无线电(Software Defined Radio，SDR) 是一种无线电广播通信技术，它基于软件定义的无线通信协议而非通过硬连线实现。频带、空中接口协议和功能可通过软件下载和更新来升级，而不用完全更换硬件。



 

它的创建者Michael Ossman 在2014年首次推出了名为HackRF（Jawbone）的项目。因其硬件和软件的开源，支持的操作范围涵盖了研究人员可能感兴趣的大量RF频谱，30MHz至6 GHz频段包括了AM无线电，航空无线电，导航，短波广播，电视，FM收音机，蓝牙，手机网络，GPS，Wi-Fi（2.4Ghz和5Ghz）以及各种卫星通信。此外，HackRF提供了传输该频段内的任何信号的能力，或者你也可以通过FCC访问未经许可的通信设备及频段，因而吸引了很多黑客，业余无线电爱好者和信息安全从业人员。

环境准备

介绍这么多，接下来就开工吧。在kali下安装HackRF的驱动和环境。
apt-get install hackrf libhackrf-dev libhackrf0

安装完成，插上设备，执行hackrf_info可以看到设备信息。

固件已经升级了，升级方式可以偷个懒，直接从https://github.com/mossmann/hackrf/releases里，把最新打好的包下载下解压，里面有firmware-bin目录，是已经编译好的固件。

更新Flash：

hackrf_spiflash -w hackrf_one_usb_rom_to_ram.bin

更新CPLD：

hackrf_cpldjtag -x hackrf_cpld_default.xsvf

遥控信号测试

接下来以电动车钥匙遥控为例，使用gqrx看一下电动车钥匙解锁时发送的无线电范围，可以通过搜索引擎获知大概的工作频段，然后调整gqrx到该频段监听，然后按下钥匙会看到明显的波峰。

使用hackrf_teansfer进行录制和重放无线电信号。

录制钥匙解锁时发送的无线电信号：

hackrf_transfer -r bike-open.raw -f 314800000 -g 16 -l32 -a 1 -s 8000000 -b 4000000



然后，把钥匙丢在一边，就可以使用HackRF开锁啦。

重放信号：

hackrf_transfer-t bike_open.raw -f 314800000 -x 47 -a 1 -s 8000000 -b 4000000
安全建议：
在电车钥匙的遥控信号中加入随机滚动码，使钥匙每次解锁发送的数据都不一样，即使重放解锁的无线电信号，也无法完成开锁。但如果厂商没有做这种配置，那还是配一把物理锁吧！

GPS劫持测试

我们使用开源项目gps-sdr-sim进行GPS劫持测试，对这个软件进行编译，生成可执行文件。命令如下：

git clone https://github.com/osqzss/gps-sdr-sim.git
cd gps-sdr-sim
gcc gpssim.c -lm -O3 -o gps-sdr-sim

那如何发现自己被劫持了呢？请注意劫持之后的卫星链接数，卫星三角定位至少需要伪造出来三个，而一般地来说，为了使得欺骗成功，伪造的GPS信号数目是越多越好的，所以如果GPS信号的数目突然增加了很多，那么很可能遭到了GPS欺骗。
