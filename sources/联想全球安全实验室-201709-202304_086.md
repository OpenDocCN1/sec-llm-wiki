## **0x00 前言**

## 安全研究人员在进行硬件安全测试时，经常会发现设备的PCB上会保留JTAG（JointTest Action Group）端口，用于程序下载和在线调试，安全研究人员也可以通过JTAG接口读取设备的固件，逆向分析设备的程序逻辑，发现设备的漏洞。

![](../Images/cc79bd4fa42579b5c2e40bd476272e7e.png)

图1 某路由设备PCB上的JTAG接口

由于JTAG标准本身并没有规定接口定义，这也是JATG header种类繁多的根源，比如你可能在各种不同的板子上中见到过10pin、14pin、20pin等各种各样的jtag header，而且各个引脚的功能和顺序也无法确定，这在安全研究工作中造成了很大的麻烦。传统的做法是通过逻辑分析仪做信号分析来解决，但是这样既费时费力又容易出错。于是很多优秀的安全专家设计了各种设备来自动化的解决这个问题，JTAGulator便是其中一个优秀的解决方案。JTAGulator是一款开源的硬件工具，可以帮助安全研究人员识别测试设备的JTAG引脚的定义，进而可以使用ATTIFY BAGDE正确的接线并读取固件。本文将针对JTAG规范、JTAGulator的制作进行详细讲述。JTAGulator的使用方法以及如何使用ATTIFY BAGDE读取固件，将在下一篇文章中详细讲述。

  

## **0x01  JTAG**

JTAG(Joint Test Action Group)是IEEE1149.1定义的标准测试访问端口和边界扫描结构标准，用于验证设计与测试生产出的印刷电路板功能。现在多数的高级器件都支持JTAG规范，如ARM、DSP、FPGA等。JTAG总共定义了5个信号接口TCK、TMS、TDI、TDO和TRST，其中4个是输入信号接口，另外1个是输出信号接口。JTAG最初是用来对芯片进行测试的，其基本原理是在器件内部定义一个TAP（Test Access Port）并规定TAP状态机的行为，通过专用的测试工具进行内部节点进行测试。JTAG测试允许多个器件通过JTAG接口串联在一起，形成一个JTAG链，能实现对各个器件分别测试。现在，JTAG接口还常用于实现ISP（In-System Programmable），对Flash等器件进行编程。下面，我们介绍一下这5个接口：

*   Test Clock Input (TCK)
    

TCK为TAP的操作提供了一个独立的、基本的时钟信号，TAP 的所有操作都是通过这个时钟信号来驱动的。

*   Test Mode SelectionInput (TMS)
    

TMS信号用来控制TAP状态机的转换。通过TMS信号，可以控制TAP在不同的状态间相互转换。TMS信号在TCK的上升沿有效。

*   Test Data Input (TDI)
    

TDI是数据输入的接口。所有要输入到特定寄存器的数据都是通过TDI接口一位一位串行输入的（由 TCK 驱动）。

*   Test Data Output (TDO)
    

TDO是数据输出的接口。所有要从特定的寄存器中输出的数据都是通过TDO接口一位一位串行输出的（由 TCK 驱动）。

*   Test Reset Input (TRST)
    

TRST可以用来对TAPController进行复位（初始化）。不过这个信号接口在IEEE 1149.1标准里是可选的，并不是强制要求的。因为通过 TMS 也可以对 TAP Controller 进行复位（初始化）。

虽然JTAG标准版本身没有定义接口，但平时常见接口的连接有三种标准，即10针、14针接口和20针接口，其定义分别如下所示。

![](../Images/0f729c5f2227c5e4a4f53a241f912ad8.png)

图2  各种标准JTAG接口引脚定义

由于JTAG经常使用排线连接，为了增强抗干扰能力，在每条信号线间加上地线，偶数针脚都是地信号。

  

## **0x02  JTAGulator 的制作**

JTAGulator是一款开源的硬件测试设备，主要用于定义JTAG接口的各个引脚，官方售价$169，某宝￥1500左右，自己制作的平均成本可以控制￥500以内，好用不贵，何乐而不为。

![](../Images/b7251a1a42b9450134528376579331fb.png)

图3 JTAGulator 官网截图

首先，可以在JTAGulator的网站(http://www.grandideastudio.com/jtagulator/)上下载原理图、PCB和BOM清单，设备的固件可以在GitHub上下载，感谢Joe Grand。

![](../Images/afda6c5828c4b899b35c01e977134eb1.png)

图4 JTAGulator 的设计文件和代码均可下载

我们可以下载JTAGulator的相关资料，制作PCB，购买元器件并进行焊接，但是在进行焊接的时候，问题来了，PCB上没有元器件标号，对于一些IC器件，可以通过观察封装的方式进行确定，贴片电阻可以通过读原版PCB上标注的阻值确定。但是对于贴片电容，器件上没有标注，也无法使用万用表直接测量，需要将电容从PCB上拆解下来才可以测量，这个过程十分麻烦。

![](../Images/648685a8d9c21cbc5881c5077ad488da.png)

图5 JTAGulator的PCB

我们根据原理图和PCB的布局经验，可以推测出绝大部分电容的容值，还有一小部分电容无法确定，将其从PCB上拆接下来，使用万用表测量确定，图6上标注了各个电容的容值，可供参考。

![](../Images/e00b23f36bcc9c11b8e3e48c74376fae.png)

图6 贴片电容的容值

这样，我们就可以愉快的进行PCB焊接了。焊接完成之后，需要进行硬件调试，在上电之前，需要仔细检查是否存在虚焊或者短路的情况，然后上电测试电源芯片输出的电压是否正常等。

![](../Images/b4b9aa9953bb9100282b673484450051.png)

图7 自制JTAGulator

硬件测试没有问题之后，接下来就要给设备烧录固件了。固件可以从GitHub下载最新版的，下载链接：

https://github.com/grandideastudio/jtagulator

我们使用的是最新版本1.6。

烧录固件需要安装Propeller Tool，安装完成之后，固件文件就可以使用该软件打开了。

![](../Images/09617b367a4d63812d0ce94e56299aa4.png)

图8 固件文件

将JTAGulator连接电脑，双击打开JTAGulator.eeprom文件，点击Load EEPROM就可以直接烧录固件了。

![](../Images/51f438e533df465382be20314defe8a2.png)

图9 固件烧录界面

烧录完成关掉窗口，可以直接使用串口调试助手打开JTAGulator对应的串口，波特率115200，发送‘?’，板子上的指示灯由红变绿，并通过串口返回数据，可以根据提示进行操作。

![](../Images/a26d8ee683d0e6e0de5123813d3419e3.png)

图10 串口返回数据
