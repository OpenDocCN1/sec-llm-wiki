0x00 前言

为了测试IoT设备与手机端的通信安全，需要将IoT设备和手机端连入同一可监控的局域网，方便分析其所有的通信流量，普通AP热点无法实现这个功能，下面介绍一种IoT设备流量分析测试环境的搭建方法。


0x01 准备

Ubuntu18.04

外置无线网卡


0x02 热点建立

将外置无线网卡连入Ubuntu，使用lsusb查看，确认接入。

在终端输入 nm-connection-editor

即可进入网络连接设置。

点击左下角“＋”添加，连接类型选择Wi-Fi。

然后开始配置Wi-Fi，输入连接名称、SSID，SSID就是连接时显示的名字，模式选择为热点。

Wi-Fi安全性设置为WPA及WAP2个人，设置至少8位密码。

IPv4设置中的方法，选择“与其他计算机共享”。

IPv6设置中方法选择“忽略”，保存。


0x03 使用热点

首先要确保虚拟机可以正常连接网络。点击Ubuntu主界面右上角网络连接，进入Wi-Fi设置。

选择连接隐藏的网络。

选择刚刚创建的Wi-Fi连接1，点击连接，就可以在手机上扫描到该Wi-Fi。

手机可以在WLAN中发现刚刚建立的TEST热点，输入密码连接热点，在APP中将IoT设备也连接进入网络，手机和设备端的通信都会在局域网内进行。


0x04 流量捕获

首先使用Nmap扫描局域网中所有设备的IP地址，确定手机和IoT设备的IP。

virtual-machine:~$ nmap -sP 10.42.0.0/24

Starting Nmap 7.80SVN ( https://nmap.org ) at 2019-12-11 18:05 CST

Nmap scan report for virtual-machine (10.42.0.1)

Host is up (0.00030s latency).

Nmap scan report for localhost (10.42.0.107)

Host is up (0.16s latency).

Nmap scan report for localhost (10.42.0.203)

Host is up (0.020s latency).

Nmap done: 256 IP addresses (3 hosts up) scanned in 3.90 seconds

一共有3台设备在线，手机、IoT设备和虚拟机。

虚拟机IP：10.42.0.1

手机IP：10.42.0.107

IoT设备IP：10.42.0.203

打开wireshark，选择外接网卡，进行流量捕获。

输入过滤条件

ip.src==10.42.0.107&ip.dst==10.42.0.203

就可以进行手机与设备端通信流量进行捕获、分析。

 

 

0x05 总结

IoT设备的通信安全十分重要，用户可以通过手机方便的控制家里的IoT设备，同样的，攻击者也可以模拟用户对IoT设备发送控制指令，如果设备对于控制指令没有加密、校验，或者加密算法较为简单的话，将会对IoT设备安全造成很大的隐患。
