# IoT设备流量分析测试环境搭建方法

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1ODk1MzI1NQ==&mid=2247484618&idx=1&sn=30bb71540c19c47ffe770815e45a63be&chksm=fc1fe282cb686b946df7ad141a52bcab2d41c297e575252da15e3bbea509f9b136834b4f5945&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1ODk1MzI1NQ==&mid=2247484618&idx=1&sn=30bb71540c19c47ffe770815e45a63be&chksm=fc1fe282cb686b946df7ad141a52bcab2d41c297e575252da15e3bbea509f9b136834b4f5945&scene=27#wechat_redirect)

**0x00 前言**

为了测试IoT设备与手机端的通信安全，需要将IoT设备和手机端连入同一可监控的局域网，方便分析其所有的通信流量，普通AP热点无法实现这个功能，下面介绍一种IoT设备流量分析测试环境的搭建方法。

  

**0x01 准备**

Ubuntu18.04

外置无线网卡

  

**0x02 热点建立**

![](../Images/70b5da7e4ba369d28b2b8b89fda3aa34.png)

将外置无线网卡连入Ubuntu，使用lsusb查看，确认接入。

![](../Images/3f458ad8f23fe30b79e6c51775ccfd27.png)

在终端输入 nm-connection-editor

即可进入网络连接设置。

![](../Images/cb6c99cbd797393af0aba9cabc415c42.png)

点击左下角“＋”添加，连接类型选择Wi-Fi。

![](../Images/37e7376b4cf7a57240e596a6419cb3ea.png)

然后开始配置Wi-Fi，输入连接名称、SSID，SSID就是连接时显示的名字，模式选择为热点。

![](../Images/d0a145a299b35a6e6e9dfc05fae2c393.png)

Wi-Fi安全性设置为WPA及WAP2个人，设置至少8位密码。

![](../Images/d6d98bf600b5dad240598984b2a48029.png)

IPv4设置中的方法，选择“与其他计算机共享”。

![](../Images/deaf785e31e5b3da8c63305a3b75cb20.png)

IPv6设置中方法选择“忽略”，保存。

![](../Images/d1b1977437ba9b7012bb0bcfafd0e2e0.png)

  

**0x03 使用热点**

首先要确保虚拟机可以正常连接网络。点击Ubuntu主界面右上角网络连接，进入Wi-Fi设置。

![](../Images/6837a117988a7d4983c385cd8d966598.png)

选择连接隐藏的网络。

![](../Images/4f38d3805be056643c2288898f3ceb9b.png)

选择刚刚创建的Wi-Fi连接1，点击连接，就可以在手机上扫描到该Wi-Fi。

![](../Images/46debfb0d29ce3aaddd69a3a968a2ade.png)

![](../Images/375b0f40b838f32a6f4097120f8442f5.png)

手机可以在WLAN中发现刚刚建立的TEST热点，输入密码连接热点，在APP中将IoT设备也连接进入网络，手机和设备端的通信都会在局域网内进行。

  

**0x04 流量捕获**

首先使用Nmap扫描局域网中所有设备的IP地址，确定手机和IoT设备的IP。

virtual-machine:~$ nmap -sP 10.42.0.0/24

Starting Nmap 7.80SVN ( https://nmap.org ) at 2019-12-11 18:05 CST

Nmap scan report for virtual-machine (10.42.0.1)

Host is up (0.00030s latency).

Nmap scan report for localhost (10.42.0.107)

Host is up (0.16s latency).

Nmap scan report for localhost (10.42.0.203)

Host is up (0.020s latency).

Nmap done: 256 IP addresses (3 hosts up) scanned in 3.90 seconds

一共有3台设备在线，手机、IoT设备和虚拟机。

虚拟机IP：10.42.0.1

手机IP：10.42.0.107

IoT设备IP：10.42.0.203

打开wireshark，选择外接网卡，进行流量捕获。![](../Images/d8236a89c64b2f88be133242f531d463.png)

输入过滤条件

ip.src==10.42.0.107&ip.dst==10.42.0.203

就可以进行手机与设备端通信流量进行捕获、分析。

 ![](../Images/7cb929f208025c84a778be62af5cb534.png)

 

**0x05 总结**

IoT设备的通信安全十分重要，用户可以通过手机方便的控制家里的IoT设备，同样的，攻击者也可以模拟用户对IoT设备发送控制指令，如果设备对于控制指令没有加密、校验，或者加密算法较为简单的话，将会对IoT设备安全造成很大的隐患。
