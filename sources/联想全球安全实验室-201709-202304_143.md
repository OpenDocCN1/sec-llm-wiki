# 贾朝晖：PC智能化，智能办公时代来临！

2018年9月26日至27日，一年一度的联想创新科技大会 (Lenovo Tech World 2018) 在北京雁栖湖畔举办。在本次大会上，联想集团高级副总裁、个人电脑和智能设备集团总裁贾朝晖先生向与会来宾展示了At Office智能应用场景。At Office延续联想在PC领域的领先优势，创造性地提出“智能PC”概念，此举将推广高效高能的智能化办公，并推动工作效率提升。

![](../Images/bd483b8e5c6ef89dfa826052b734d17c.png)

**智能PC推动智能办公职场精英变身“王牌特工”**

  

在会议现场，贾朝晖运用已上市的联想智能会议设备“ThinkSmart HUB500” 和正在研发中的联想智能会议系统，演示了办公常用场景——电话会议可以如何实现智能办公。联想正在开发的智能会议系统可以让用户收到自动会议提醒后，通过“刷脸”等生物识别认证进行登录与安全认证，进入到多方会议。会议期间，智能白板将会议内容同步到与会者的屏幕并能让参与者在智能白板上互动协作；会议结束后，系统形成智能会议纪要，并发送邮件给参会者。同时，智能会议系统还会进行任务跟踪，对于会议上提出的待办事宜，建立日程提醒，安排下次会议时间。值得一提的是，对于国际会议，智能设备与系统还可以进行实时翻译，参会人员可以说各自母语进行沟通。据贾朝晖介绍，目前联想的系统对于英语的优化已经近乎完美，其他多国语言的优化也正在进行中。

  

![](../Images/02b268452cfc8298199c7a881cb768a7.png)

  

本次创新大会上贾朝晖的演讲与演示，给人们的感觉犹如将电影《王牌特工》中的黑科技搬到了现实。来自世界各地的特工或精英，戴上AR眼镜之后，“坐”在一起进行重要会议，会议议题实时投影到虚拟大屏……如果说电影是对未来的想象，联想所展示的智能设备带来的办公场景，则是开启了从当下迈入智能办公时代的大门。

  

贾朝晖强调：智能设备是联系人和人工智能、不可或缺的关键纽带；没有智能设备，人工智能也就无法落地。“由此，我们甚至可以断言，智能设备将是所有实施人工智能战略的公司的必争之地！”

 

**抢占必争之地：联想第一代智能PC代表作亮相**

  

在大会上，贾朝晖宣布联想第一代“智能电脑”诞生。在当日亮相的几款智能PC，包括有联想ThinkPad X1系列和YOGA系列中的第一代联想智能PC代表产品。

  

ThinkPadX1 隐士是ThinkPadX1家族首款配备独立显卡的15.6英寸高性能超便携笔记本，是被ThinkPad粉丝称为“办公福音”。此外，移动性更强的YOGA Book 2，是全球最轻的双屏笔记本，重量仅为775克，其B面的液晶屏与C面的电子墨水屏相结合，在本月初的柏林IFA国际消费电子展上一经亮相，即成为展览上的“网红”作品，不啻为“在人工智能技术的支持下，奉献给时尚人士和极客用户、极其前卫的笔记本电脑新体验！”

  

![](../Images/e833f33ca40f0e0dde943ce174c08976.png)

  

根据贾朝晖的介绍，智能设备应当具备五大基本属性：永远在线，可以实时连接云，产生数据并执行云端下发的命令；可被远程管理，包括升级和维护，实时提供完美无瑕的工作状态；更加安全，并采取相关的数据隐私策略；具备自然语言交互能力，包括语音、手势、表情，未来甚至是人的思想意识；适合的计算力，根据设备所承担的工作内容，具备相应的边缘计算力。

  

联想的第一代智能PC代表作，全部具备智能设备的五大基本属性，也犹如王牌特工仓库中的各种神器，让办公室精英摇身一变成为“王牌特工”。

 

**以智能PC为支点撬动SIoT时代**

一年前，联想发布智能物联战略，而被亲切称呼为“老贾”的联想集团高级副总裁贾朝晖正是联想SIoT战略的领导者之一。

  

5G和AI技术已经和正在到来，这两个技术将极大的为AR的内容和性能提升提供基础保障。贾朝晖表示，要实现AR基础上的智能办公，一些关键技术亟待突破。空间感知、微型显示和轻巧化眼镜设计是三大关键技术。下一步，联想自身将聚焦在空间感知领域里的SLAM算法和轻巧化眼镜设计两个方面；而在微型显示和光学方面，将紧密关注技术发展方向，采取和业界领先公司进行战略合作的模式。则是统领联想开拓智能物联疆土。贾朝晖充满信心地表示，突破关键技术并非易事，需要三到十年的时间，“短则三到五年，长则五到十年；但我们相信，技术的车轮从不会停歇，AR智能办公一定会逐步地成为现实！”

  

贾朝晖的信心正来源于SIoT战略。以智能物联战略为起点，以智能PC为代表的智能设备为硬实力，以技术革新为软实力，联想为智能办公时代的来临组建了强大的发展框架，其触角已经延伸到全行业，并以“带头大哥”的身份，团结一切力量共同搭建智能办公应用环境。可以预见，联想将继续稳占业界龙头地位，并重新定义未来的智能办公时代。
