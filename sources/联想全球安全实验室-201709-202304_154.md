# 联想集团首届网络安全周活动集锦（一）

9月17日，2018年国家网络安全宣传周启动。与此同时，联想集团的首届网络安全周活动也在本周正式举行。从17日到21日，联想集团产品安全办公室和安全实验室团队在本周利用公司内网专题专区、公众号、邮件、培训日历、蓝色海洋现场活动等多种方式，向公司所有员工普及网络安全知识，增加产品安全意识。

 

作为首届网络安全宣传周活动，联想集团将聚焦于“**以确保产品安全为己任**”的主题，充分利用线上线下的方式，向集团所有员工普及网络安全知识、个人信息保护知识，揭露网络攻击常用手段和方法，提高集团员工公众防范网络诈骗意识与技能水平。同时，突出宣传集团的各个产品安全部门在推进确保技术发展、创造安全的产品的作用，增强集团员工对联想产品安全的信心。一直以来，联想集团高度重视产品安全工作，全力保障客户资金和个人信息安全。在产品上市前，各个安全团队依靠专业的技术能力解决了上百个高危漏洞，将相关风险控制在交付到客户之前。

 

**周一下午活动详情**

集团产品安全研讨会在西区召开，包括集团产品安全办公室、集团安全实验室、DCG安全团队、MBG安全团队、Legal隐私团队等各自分享和探讨了产品安全之道，多个集团部门超过40位安全专家和安全接口人参与到本次闭门会议中。在会议上，多位与会专家提到，产品安全不仅是产品本身，而是包含安全培训、供应链安全、安全开发、应急响应、隐私保护等在内的“全面安全”概念。集团各个产品部门的产品相关人员应该具备一定的产品安全意识，配合与之相适应的安全保障体系，确保全生命周期的产品安全。

**周二中午活动详情**

总部西区蓝色海洋举办的现场活动拉开帷幕。现场活动设置了安全攻防展区、安全知识竞赛专区、网络安全宣传主题专区，展示联想集团在产品安全方面的人才、项目和成果，宣传普及产品安全知识和技能。

![](../Images/98163e42583f8cb84c8befcf8e9733e1.png)图3-现场致辞

本次现场活动有数百位同事积极参与。其中，大家对安全知识竞赛和安全调研工作最为支持，同时，积极的参与到各类攻防展示活动中，进一步了解到身边的安全风险。
