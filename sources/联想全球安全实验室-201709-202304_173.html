一、摘要

物联网设备固件获取有很多方法，本文介绍其中一种，通过设备固件正常的升级过程，获取设备的固件。

二、原理

通过iptables规则，将IoT设备访问互联网云端的数据转发到本地的监听代理端口，如下可以将设备访问互联网的80、443端口的数据转发到Burpsuite。

iptables -t nat -A PREROUTING -i $wInf -p tcp --dport 80 -j REDIRECT--to-ports 9999

iptables -t nat -A PREROUTING -i $wInf -p tcp --dport 443 -jREDIRECT --to-ports 9999

同时使用wireshark抓包工具对网络流量进行嗅探，获取Burpsuite不能截断的流量数据，如FTP。

通过IoT-Security Proxy抓取设备升级过程，即使设备通过静默升级的方式来升级固件，也可以被工具截断，比单独使用抓包工具更方便，而且可以用来进行设备降级测试。
