# 颠覆智能电视产业格局，联想娱乐宝荣获CES中国创造奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1ODk1MzI1NQ==&mid=2247484438&idx=2&sn=9735a87803242e53afa034ea868b2676&chksm=fc1fe25ecb686b481b0a76eda692554a2e1000fb8223028e2e15526b71c771a52f96d4406ebc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1ODk1MzI1NQ==&mid=2247484438&idx=2&sn=9735a87803242e53afa034ea868b2676&chksm=fc1fe25ecb686b481b0a76eda692554a2e1000fb8223028e2e15526b71c771a52f96d4406ebc&scene=27#wechat_redirect)

以“智造，非凡明天”为主题的2018亚洲消费电子展（CES Asia 2018）于6月13日在上海新国际博览中心盛大举行。在CES Asia 2018第三届中国创造高峰论坛“中国创造年度产品”颁奖礼上，来自联想智能家庭的“联想娱乐宝（Smartbar）”获得组委会青睐，荣获“中国创造奖”。“联想娱乐宝”作为联想智能家庭推出的“家庭娱乐”布局新品，以颠覆的革命者姿态亮相CES！

![](../Images/08599bdd82d16e431bf198c36f9a4461.png)

联想智能家庭推出的“家庭娱乐”布局新品“联想娱乐宝”

  

此前，“联想娱乐宝”一直与联想智能电视旗舰产品65i3一同出现。65i3除了4K大屏、JBL发声单元、人工智能语音交互以及移动空鼠操作等特点外，最为引人注目的便是屏幕与智能主机分开的分体式设计。想必这也是第二代娱乐宝最终打动组委会的关键所在。  

  

作为联想智能电视新品的主机部分，“联想娱乐宝”第二代可以称得上是一款集合高端音响、智能音箱以及高端电视盒子的革命性产品，其强大的音响效果更让它在电视盒子之外有了更多可延展用途的想象。据悉，“联想娱乐宝”将会在未来单独发售，这款产品支持AV线连接、DCMI连接两种连接方式，基本支持大部分的传统电视。传统电视连接上“联想娱乐宝”将秒变智能电视，或许这将掀起一场电视领域的消费升级旋风。  

  

在展览现场，我们看到“联想娱乐宝”接入其他屏幕后依然能呈现出联想智能电视一贯的“三明治UI”界面，所有影音资源、游戏、APP等内容和服务依然可以正常使用，联想智能电视的标配——移动空鼠依然在屏幕上流畅移动，说上一句“你好！联想”，人工智能语音交互也实时响应。在不连接屏幕的情况下，它又像是一个增强、增大的智能音箱。连上蓝牙，他还是一台表现强劲的蓝牙音箱！

![](../Images/80432faa1a1f9bb75722d1ee81d98a29.png)

工作人员现场为观展嘉宾介绍“联想娱乐宝”

  

据现场工作人员介绍，娱乐宝的发声单元由JBL金耳朵团队历时3个月打造，8个喇叭将低音、中音、高音不同的声道表现的淋漓尽致，可媲美IMAX影院沉浸式音效。而且，其配置的DSP芯片可以有效提升喇叭性能，内嵌杜比音效技术，采用Dolby Pro Logic II虚拟5.1环绕立体声，可以让空间感更强。

  

据联想中国IoT设备业务部总经理魏晋介绍，作为联想智能家庭四大布局中“家庭娱乐”的重要一环，推出“联想娱乐宝”的初衷在于，为当即更换电视意愿不强烈的用户提供一个“客厅娱乐升级计划”，用户可以选择为现有的传统电视或是网络电视配上一个“最强大脑”，从而拥有一台“会聊天的智能电视”。而且这种将屏幕和主机拆分发售的方式能降低损坏率，避免屏幕破碎就要电视整修或整个更换的情况。智能主机的使用寿命其实比屏幕要长很多，这样做也能为用户一定程度上节省部分开支。

![](../Images/1121852878cf32c49fca26c4af6a2bae.png)

联想中国IoT设备业务部总经理魏晋在CES现场领奖

  

可以预见，联想娱乐宝将为更多家庭的客厅娱乐带来更多精彩的内容和更为合适的选择。看得出来，联想在产品打磨上拥有很灵活的策略，未来联想会推出55寸新品搭配娱乐宝二代共同发售，让我们期待联想更多更好的产品设计创意吧！
