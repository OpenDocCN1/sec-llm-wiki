**岗位职责：**

2.  负责相关业务线产品的安全测试、漏洞验证与审核并给出解决方案；
    
3.  负责对研发人员进行安全培训，提升安全人员安全开发意识；
    
4.  负责跟踪最新安全攻防动态，跟进研究最新0day及利用方式，并结合产品线业务状给出分析判断；

6.  负责产品安全应急响应处置及其它相关工作；

1.  5年以上安全从业经验，3年以上攻防渗透经验，熟练掌握各种工具和手法，对攻防渗透的思路有自己独到的见解；
    
2.  熟悉OWASP TOP10、精通各种渗透手法，能够对最新的攻击方式进行利用、跟踪并深入分析，对常见的安全漏洞的原理、危害、利用方式及解决方案有深入的理解，熟练掌握BS/CS程序的安全合规测试技术和渗透测试技术、具有丰富的攻防实战经验；
    
3.  熟悉不少于一种的C/C++/PHP/JAVA/Python语言，熟悉汇编，熟悉代码审计，具备代码级漏洞发现与利用能力，具备漏洞利用代码编写能力，对KALI、Metasploit等主流安全测试框架有丰富实践经验，能够独立进行黑盒/白盒安全测试；
    
4.  对安全审计、风险管理、产品安全体系建设有一定理解，有SDL工作经验者优先考虑，CISP/CISA/CISSP/CSSLP持有者优先考虑；
    
5.  具备良好的沟通能力和团队协同作战能力，有成功利用技术进行事件调查/追溯攻击者经历，威胁情报分析经历，IoT攻防经历，APT攻防经历者优先。
    
6.  能够持续保持安全从业人员职业操守及安全道德准则，无过往不良记录。
