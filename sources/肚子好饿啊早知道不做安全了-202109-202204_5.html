Apache HTTPd介绍


Apache HTTP 服务器项目致力于为现代操作系统（包括 UNIX 和 Windows）开发和维护开源 HTTP 服务器。该项目的目标是提供一个安全、高效且可扩展的服务器，该服务器提供与当前 HTTP 标准同步的 HTTP 服务。


漏洞描述：

发现 Apache HTTP Server 2.4.50 中针对 CVE-2021-41773 的修复不够充分。攻击者可以使用路径遍历攻击将 URL 映射到由类似别名的指令配置的目录之外的文件。如果这些目录之外的文件不受通常的默认配置“要求全部拒绝”的保护，则这些请求可能会成功。如果还为这些别名路径启用了 CGI 脚本，则这可能允许远程代码执行。


漏洞编号：CVE-2021-42013


漏洞影响范围: Apache 2.4.49 , Apache 2.4.50


漏洞类型：命令执行


CVSS漏洞评分：CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H






漏洞评分:9.8

危险等级:Critical

漏洞复现

 

漏洞环境项目地址：https://github.com/blasty/CVE-2021-41773

Docker部署命令：

git clonehttps://github.com/blasty/CVE-2021-41773.git


cd CVE-2021-41773/

sudo docker-compose build 

Sudo docker-compose up -d


注释：Apache再现n年前的经典漏洞模式不说，这里又来了一个经典的“补丁上面打补丁”  https://httpd.apache.org/security/vulnerabilities_24.html incomplete fix of CVE-2021-41773 --> CVE-2021-42013
