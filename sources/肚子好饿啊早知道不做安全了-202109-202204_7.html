 0x01 VMware vCenter Server介绍：
 
VMware vCenter Server 提供了一个可伸缩、可扩展的平台，为虚拟化管理奠定了基础。可集中管理VMware vSphere环境，与其他管理平台相比，极大地提高了 IT 管理员对虚拟环境的控制。
 
CVE编号：CVE-2021-22005
 
漏洞类型：文件上传
 
影响范围：
vCenter Server versions 6.7 and 7.0
Cloud Foundation (vCenter Server) 3.x, 4.x
 
漏洞评分：
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
 



CVSS漏洞评分:9.8,危险等级:Critical
 
 

0x02 漏洞影响面：
 
打开ZoomEye网空测绘平台,输入CVE编号CVE-2021-22005可以关联出该漏洞的ZoomEye dork,也可以直接输入app:"VMware_vCenter"显示收录的资产。
 



Dork链接：https://www.zoomeye.org/searchResult?q=app%3A%22VMware_vCenter%22
