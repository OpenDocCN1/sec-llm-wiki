** 0x01 ****VMware vCenter Server****介绍：** VMware vCenter Server 提供了一个可伸缩、可扩展的平台，为虚拟化管理奠定了基础。可集中管理VMware vSphere环境，与其他管理平台相比，极大地提高了 IT 管理员对虚拟环境的控制。 **CVE编号：**CVE-2021-22005 **漏洞类型：**文件上传 **影响范围：**vCenter Server versions 6.7 and 7.0Cloud Foundation (vCenter Server) 3.x, 4.x **漏洞评分：**CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H 

![](../Images/5d50fcd6a20bd43fbc92adc9141dd2f8.png)

  

  

CVSS漏洞评分:9.8,危险等级:Critical
