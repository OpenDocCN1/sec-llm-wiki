import random
from Crypto.Util.number import*

def Function(times,a,b):
    F = [2,a]
    for i in range(times):
        F.append( a * F[-1] - b * F[-2])
    return F

def Generate():
    a = 0b11011101110111110
    b = 0x11011101110
    s = (Function(77,a,b)[-1])
    while 1:
        if isPrime(s):
            break
        else:
            s = s >> 1
    tmp = (s << 64) + random.getrandbits(64)

    while 1:
        if isPrime(tmp):
            s = tmp
            break
        else:
            tmp = tmp + 1
    p = tmp
    q = getStrongPrime(1024)
    n = p * q
    return n

def Encrypt(m):
    n= Generate()
    g = random.randint(1,n**2)
    
    while 1:
        r = random.randrange(1,n)
        if GCD(r,n) == 1:
            break
    c =  (pow(g,m,n*n)*pow(r,n,n*n))%(n*n)
    return n , c , g

Analyse :

我们先来看这个task.py 里面用Lucas序列的v生成了一个函数，之后给出一个a,b都是已知的 ...我们发现我们能很容易就拿到这个 s . 接着通过把这个s左移64位，加上一个64位的随机数 之后判断是不是素数，不是就加1 直到生成的数为素数。接着再随机生成一个强素数 ，计算 $n = p*q$ ,于是这个n就是我们通过生成得到并且可以得知他的数是多少的值了.继续往下看

$$
g = random.randint(1,n^2)\\\\ r = random.randrange(1,n).(GCD(r,n) = 1)\\\\ c = (g^mr^n)\mod n^2
$$


而我们能拿到的是c,g,n  ，并且在其中的变量  p 的高位我们能够拿到，于是我们可以对其进行Coppersmith的攻击拿到p之后就分解掉了n

于是我们可以知道是pallier加密.那么接下去我们就直接对其用解密公式去解密就好了

$$
\lambda = (p-1)(q-1)\\\\ \mu = (\frac{g^\lambda \mod n^2}{n})^{-1}\mod n\\\\ m = \frac{(c^\lambda\mod n^2)-1}{n}*\mu\mod n
$$
