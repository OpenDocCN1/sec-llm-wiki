在叶子的推荐下，我玩了第一期擂台赛的misc题，名为Perseverance。这个名字是“毅力”的意思，还好我时常有关注一些国际新闻，美国毅力号火星车于今年2月18日在火星着陆，看来这个出题者还蛮紧追时事热点。

本misc题是一个如下的图片：


结合“毅力号”，这个图大概就是降落伞的图案，国内果壳网有过一篇报道《毅力号上有中文，你猜印在哪里了？》

根据文中所言，内3圈从连续的红色区域的右边起，每隔10个小格子可视为一个01串，其中白色为0，红色为1，转为十进制后，再对应到字母上，最后多余3个小白格不用管。老实说，直接数小格子好费眼，要是可以打印下来就简单多了。

整理好后编写脚本如下：

#!/usr/bin/env python2
# -*- coding:utf8 -*-
_author_ = 'pcat@chamd5.org'
import string

flags = [
    ['110','1100','1','111'],
    ['1101','1','11001','0','10','101'],
    ['1000','101','10010','101'],
]
chars = chr(0x20) + string.lowercase
for flag in flags:
    print ''.join([chars[int(i,2)] for i in flag])

得到内3圈的内容为flag may be here。而最外圈观看起来就有点麻烦，不过按照文中后面的图的规律，这个外圈的起点可以参照内圈连续红色区域前3个小白格处为起点，可以得到['111000','1110','1110110','1010','11110','10111','1011']，也就是[56, 14, 118, 10, 30, 23, 34, 11]，这样得到的结果还不准，还得移动2位，得到[34, 11, 56, 14, 118, 10, 30, 23]，再把14视为N，23视为W，得到经纬度34°11′56″N 118°10′30″W，这个值其实跟文中的经纬度相差不大。

不过我还是打开谷歌地图，访问https://www.google.com/maps，输入经纬度得到：

这里可以得到JPL Troop 509 Scouts BSA - La Canada Flintridge, CA

图片上的能看到的内容大致就这样，剩下的信息就使用图片隐写技术来解决。:)

使用binwalk可以发现图片后面有一个zip文件，使用binwalk -e或者foremost可以提取出该zip文件，文件被加密。

使用WinHex等工具可以在图片内容尾部藏有

password:\<B7=]2Q{;*5O%KH52e5<(dC517aPua03QgS517aPua03QiS52:QgS2S
Answer to the Ultimate Question of Life, the Universe, and Everything

其中第2句话在《银河系漫游指南》给出了答案为42，本以为是跟压缩包密码有关，结果试了几下后，发现直接拿第一句话中password的值就可以解开压缩包，得到一个code.py，内容是对flag串进行两次校验sha256值。

那么flag出现在哪里呢？第六感告诉我，跟诡异的

\<B7=]2Q{;*5O%KH52e5<(dC517aPua03QgS517aPua03QiS52:QgS2S有关，在进行简单的恺撒移位后，在移动42位的时候，出现了"flag"字样，但其他字符存在不可视字符。这时候得到42可能就是提示ROT42，可常见的只有ROT5/13/18/47，折腾了许久后，发现使用CyberChef在线数据处理神器很容易解码：

轻易得到(flag)\{GeT_yOur_\1_fR0m_[a-zA-Z]{3}_[a-zA-Z]{5}_\d{3}\}。这里我研究一会，其实不管ROT47，还是ROT42都是在可打印字符里的单表替换而已，编写脚本如下：

#!/usr/bin/env python2
# -*- coding:utf8 -*-
_author_ = 'pcat@chamd5.org'
def rot47(s):
    x = []
    for i in range(len(s)):
        j = ord(s[i])
        if j >= 33 and j <= 126:
            x.append(chr(33 + ((j + 14) % 94)))
        else:
            x.append(s[i])
    return ''.join(x)

def rot42(s):
    x = []
    for i in range(len(s)):
        j = ord(s[i])
        if j >= 33 and j <= 126:
            x.append(chr(33 + ((j + 9) % 94)))
        else:
            x.append(s[i])
    return ''.join(x)

如果熟悉python的string模块，也可以这样编写：

#!/usr/bin/env python2
# -*- coding:utf8 -*-
_author_ = 'pcat@chamd5.org'
import string
n = 42
s = '\<B7=]2Q{;*5O%KH52e5<(dC517aPua03QgS517aPua03QiS52:QgS2S'
fromstr = string.maketrans('', '')[33:126+1]
tostr = fromstr[n:len(fromstr)] + fromstr[:n]
table = string.maketrans(fromstr, tostr)
print string.translate(s, table)

言归正传，上面解码后是考验正则表达式，\1取得值是前面小括号捕获的"flag"串，化简下得到flag{GeT_yOur_flag_fR0m_[a-zA-Z]{3}_[a-zA-Z]{5}_\d{3}}，而code.py是要校验sha256值，如果按这个正则来匹配，最大需要(52**8)*(10**3)次，此路不通。需要减小爆破的空间，再回想一开始的坐标所在地JPL Troop 509 Scouts BSA - La Canada Flintridge, CA，前面的格式蛮贴合flag的格式，尝试flag{GeT_yOur_flag_fR0m_JPL_Troop_509}，可以通过code.py的第一个校验，而不能通过第二个校验，说明还得处理下JPLTroop每个字符的大小写。

编写脚本如下：

#!/usr/bin/env python3
_author_ = 'pcat@chamd5.org'
import itertools
from hashlib import sha256
flag_m = 'flag{{GeT_yOur_flag_fR0m_{}{}{}_{}{}{}{}{}_509}}'
s = 'JPLTroop'
lst = zip(s.lower(), s.upper())
for i in itertools.product(*lst):
    flag = flag_m.format(*i)
    b1 = sha256(bytes(flag.lower(), 'utf8')).hexdigest() == 'b9d893e313a35b541bf70bd2ca70e69d7579b79df3d6da7d4b373275e15992f8'
    b2 = sha256(bytes(flag, 'utf8')).hexdigest() == 'cbf28477ce64bf9e1bd268fd77ee32bc4196800e6a2ab29fa43c1cc173b14251'
    if b1 and b2:
        print(flag)
        exit()

得到flag为flag{GeT_yOur_flag_fR0m_JpL_tRooP_509}
