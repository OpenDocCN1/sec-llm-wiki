题目没有附件，需要先远程看出来题目是在干什么。

过了 proof_of_work 之后可以看到这个题目是一道长得像 Pwn 菜单题的密码学题目。

选择 hint 后输出 password 的密文和 e = 65537。选择 gift 需要输入 password。

Add 是添加一个 Content，show 可以打印对应 index 的 Content 和密文。

这里可以选择明文攻击。

Edit 可以修改对应 index 的密文，在 show 的时候 Content 就会输出修改后的密文的解密结果。

这里可以选择密文攻击。

容易想到这里可以把密文修改为 password 的密文，然后打印出 password，但是 show 中添加了对 password 密文的检查，不可行。

首先选择明文攻击得到 nc_2≡2^e  mod nc_4≡4^e  mod nc_8≡8^e  mod n

计算得到：c_2^2≡c_4  mod nc_2^3≡c_8  mod nc_2^2-c_4=knc_2^3-c_8=tn

求公约数可得到n，根据原理写出脚本

def chosen_plain():
  encrypt('\x02')
  encrypt('\x04')

  c2 = show(0)

  kn = c2**2-c4
  tn = c2**3-c8
  n = GCD(kn,tn)
  log.success('n = {}'.format(n))

return n

RSA parity oracle

存在一个oracle，解密给定密文，返回明文奇偶

n是奇数，(2^t m)〗^e是偶数，m<n，2m<2n

第一次发送c2^e≡(2m)^e  mod n，解密得到2m mod n的奇偶

若为奇数，则必有2m>n， 2m mod n减去了一个n，2m>n，n/2<m<n

若为偶数， 0<m<n/2

第二次发送(c2^e)2^e≡(2*2m)^e  mod n，同理

缩小上下限差距，直到上限等于下限，可求得m

根据原理写出脚本

def oracle(c):
  r.recvuntil('Input your m:')
  r.sendline(str(c))
  res = r.recvuntil('\nDone!',drop=True)
  if '1' in res:
    return 1
    elif '0' in res:
  return 0  

def partial():
  r.recvuntil('n = ')
  n = int(r.recvuntil('\n',drop=True).strip())
  r.recvuntil('e = ')
  e = int(r.recvuntil('\n',drop=True).strip())
  r.recvuntil('c = ')
  c = int(r.recvuntil('\n',drop=True).strip())
  k = n.bit_length()
  decimal.getcontext().prec = k
  l = decimal.Decimal(0)
  h = decimal.Decimal(n)
  for i in range(k):
    c = (c * pow(2, e, n)) % n
    if not oracle(c):#偶数
      h = (l + h) / 2
    else:#奇数
      l = (l + h) / 2
  ans = int(h)
  log.success(ans)
  log.success(long_to_bytes(ans))
