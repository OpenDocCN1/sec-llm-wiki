第三关：徽章我来了！

使用密钥对密文进行解密得到flag，密文为

6lWnfl55LJ&nLo5f6*lo4o5Kh7onK78fPw9K

这一关困扰了不少人了吧，因为它提供了密文、密钥，而不说明加密方法。

密钥是32位ASCII码，而AES支持128、192或256位二进制位的密钥长度，如果没有IV值，可以考虑AES的ECB模式。

但我没往这方面去试，直觉上来看就不太像现代密码学的加密，而且密文中的字符都是来自密钥中的字符集。何不考虑下古典密码学呢？古典密码学有需要32位密钥的吗？结合下单表代替密码和base编码，尝试替换下base32的alphabet，编写脚本如下：

import string
import base64
__author__='pcat.cc'
old_alphabet='ABCDEFGHIJKLMNOPQRSTUVWXYZ234567'
new_alphabet='01f#Pwn!4=L86TheKJvU&*World5Q79_'
cipher='6lWnfl55LJ&nLo5f6*lo4o5Kh7onK78fPw9K'
table=string.maketrans(new_alphabet,old_alphabet)
msg=string.translate(cipher,table)
print base64.b32decode(msg+'='*4)


运行得到flag：

flag{The_best_pwnhub!}

ps. 如果没带电脑的话，计算确实麻烦了点。
