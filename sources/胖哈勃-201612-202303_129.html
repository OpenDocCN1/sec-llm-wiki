>>> 前言<<<

Drupal是Drupal社区所维护的一套用PHP语言开发的免费、开源的内容管理系统。在3月份的时候报了CVE-2018-7600(drupalgeddon2)，影响范围覆盖6.x，7.x，8.x，在对漏洞进行复现时发现7.x版本相比于8.x版本更为复杂(8.x版本请参考RicterZ大佬的文章：https://paper.seebug.org/567/)，故在此记录一下整个EXP的构造过程。

跟入函数后搜索triggering_element，可以看到当_form_element_triggered_scripted_submission($element,$form_state)返回true的时候，可以使得$form_state['triggering_element']=$element，这时候的$element 中没有#executes_submit_callback，从而满足$form_state['triggering_element']['#executes_submit_callback']为空的要求。


_form_element_triggered_scripted_submission：

<?php
function _form_element_triggered_scripted_submission($element, &$form_state) {
  if (!empty($form_state['input']['_triggering_element_name']) && $element['#name'] == $form_state['input']['_triggering_element_name']) {
    if (empty($form_state['input']['_triggering_element_value']) || $form_state['input']['_triggering_element_value'] == $element['#value']) {
      return TRUE;
    }
  }
  return FALSE;
}
