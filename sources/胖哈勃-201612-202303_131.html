01

沙龙简介


上周六胖哈勃沙龙圆满结束了，我们有幸邀请到了来自Tea Deliverers、Blue-Lotus、Redbud、******（六星战队）、Eur3kA等知名CTF战队的大佬们来做分享。沙龙围绕CTF中的知识点，从参赛者和出题人的角度，通过议题分享与交流探讨的形式，为广大的网络安全及CTF爱好者搭建一个学习与沟通的平台。


02

议题回顾

《MITM——从ACM到密码学再到CTF》    iromise

本次演讲的第一位嘉宾是iromise，清华大学研究生，Tea Deliverers、Blue-Lotus、Redbud 成员，主要研究方向为 Binary 与 Crypto 。他为我们带来的分享是密码学中的“电灯泡“中间人相遇攻击。

演讲从ACM中的题目讲起，引出中间相遇的基本思想，进而介绍目前密码学中使用中间相遇攻击的一些算法，最后以 CTF 中的题目为例，进一步深入介绍中间相遇攻击思想。



《谈谈我的软件逆向工程方法论》    Atum

接下来是来自北京大学的Atum，他的研究方向涉及软件漏洞挖掘与利用、逆向工程等。是一名CTF二进制选手，蓝莲花战队成员，Eur3kA战队队长，带领战队成员多次闯入DEFCON。

本次议题他为我们带来了软件逆向工程实践中用到的一些方法和技巧，为逆向工程初学者、尤其是CTF PWN选手转逆向的同学提供了思路。



《namespace与沙箱安全》    explorer

第三位出场的是长亭科技的explorer，他是一名CTF选手，目前主要跟随Tea Deliverers战队参加世界型CTF比赛，在ISC2017上做过有关游戏引擎漏洞挖掘的议题演讲。

容器 Docker 是基于 Cgroup 和 namespace 实现，沙箱逃逸也是安全圈的⼀⼤关注热点，CTF中有关namespace相关的沙箱问题时有出现。本次沙龙explorer带大家全面的了解Linux中的namespace技术，以及通过namespace以及其他相关技术实现的linux沙箱的安全性问题和解决方案。



《侧信道及其在代码混淆上的应用》    酱油王@SoyaSauceKing

再接下来就是酱油王@SoyaSauceKing同学了，他本科就读于中国科技大学少年班学院, 研究生就读于中国科技大学计算机学院。熟悉逆向分析, 是Eur3ka、Tea Deliverers成员。参加过2nd@Plaid CTF、5th@TCTF、23rd@DEFCON QUALS、1st@看雪CTF2018等比赛。

前段时间，Spectre 漏洞的出现把人们的目光移向了 CPU 本身，处理器不再是一个黑盒,而是有着通用结构的一个计算部件。酱油王同学给大家带来了一些利用 CPU 架构进行代码混淆的尝试。



《DDCTF 2018出题心得与题解分享》    欧家俊

最后是来自DSRC的安全工程师欧家俊，也是复旦******（六星战队）成员，参加过不少国内外CTF比赛，目前研究方向为webshell检测与waf研究。

他分享了2018 DDCTF中部分题目的出题原则、trick及解题思路，其中涉及到线性代数/微积分、区块链、二进制等方面的基础知识。
