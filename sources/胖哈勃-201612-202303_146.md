又快到周末了呢，上个周末胖哥去了美丽的杭州，参加了**首届云栖2050大会**，我来和大家一起分享一下吧。

**云栖2050大会**是由杭州市云栖科技创新基金会与志愿者共同发起的非营利活动，首届大会于**2018年5月25日至27日**在**杭州云栖小镇**举行，大会的理念是：**让年轻人的思想影响世界**。大会为**100个团聚活动**提供支持，邀请全球最具创意的年青人创作**100个探索展区**，志愿出品人为与会者奉上**100场新生论坛**，更有**音乐节、逐日晨跑、科学影像剧场、云栖灯光秀**等丰富多彩的活动。2050还设置**草坪露营区**，提供约800顶帐篷作为参会期间的住宿选择。

**新生论坛之长亭专题系列**

![](../Images/2922d98b77081c898e7c16ca465c846e.png)

2050是一场没有设定议题的大会，年青人的声音在这里被世界听见。新生论坛共有100场主题论坛，话题涵盖不同的领域。长亭科技作为行业中比较年青的一支队伍，总是走在技术发展的前沿，本次大会**长亭科技**带来的主题论坛是：**信息安全攻防技术的进化之路**。论坛出品人**杨坤**，是长亭科技的创始人之一，清华大学博士，国内知名CTF战队蓝莲花的队长，活跃于国内外安全技术大赛。

**信息安全的本质就是攻防对抗**。攻击和防御技术在相互对抗过程中不断变化和发展，防护水平在提升的同时，攻击技术也同样取得了突破。攻防技术的研究任重道远，没有一劳永逸。伴随着移动互联网高速发展、大数据与人工智能技术得以应用，信息系统正逐渐变得庞大和复杂，攻防技术已经进入了综合、融合、协同、多维的发展阶段，AI安全、攻防自动化、移动安全等方向逐渐成为了热点。这一专题中，**长亭科技**邀请了信息安全领域在工业界、学术界引领技术创新的年轻技术专家们分享他们最新的成果，共同探讨攻防技术的未来。

![](../Images/869ee48f3199cf0b97580d8ae84b7b95.png)

**清华大学计算机系博士研究生陈建军**带来了关于** HTTP 协议多方不协调安全的研究**，以常见的 HTTP 协议为例，系统地讲解了在分布式网络中多方参与者在交互过程中出现的不协调导致的安全问题，这些问题将会影响到当前主流 HTTP 系统，例如 CDN，缓存，防火墙，浏览器等等。

![](../Images/97a1db371bf13bc1253cfdc6027b8ce4.png)

还有知名安全、微博大V专家**蒸米**带来的** iOS内核攻防小结**，和大家一起探讨**苹果“越狱“**问题，演讲会总结苹果在 iOS 9到 iOS 11中增加的那些内核防护机制，然后介绍每个版本中可利用的堆风水技巧，以及如何绕过这些防护机制并获取内核任意读写的方法。

![](../Images/0a760b3188b4f3b717f633d7c002b381.png)

 接着是 **COBO 安全专家李福**带来的**数字货币安全实践**，讲者通过自己丰富的从业经验并结合一些安全事件，讲述了如何保障数字货币资产的问题。

![](../Images/3da3a2a4577d23869e7602aa2bf0ea09.png)

区块链技术的快速发展为人类打开了又一扇新世界大门，而智能合约的出现加速了人类向新世界迈进的步伐。**长亭科技区块链安全研究员于晓航**带来了关于**智能合约安全问题**的思考，本次分享中，讲者结合真实攻击案例，解释合约攻防原理，探讨一些智能合约漏洞的技术细节以及相对的安全开发原则。

![](../Images/f7b21ff9ba5cc2acd2d9730cc45ff34c.png)

最后是腾讯安全**玄武实验室**的高级安全研究员**宋凯（@exp-sky）**带来的议题是 **Chakra 引擎的非 JIT 漏洞与利用**。在 **Pwn2Own **这样的国际性比赛中，不少参赛队伍都使用了Chakra JIT 相关漏洞，但并不代表 Chakra 脚本引擎中其它的逻辑就是安全的，本次议题中详细介绍一个了 Chakra 脚本引擎，非 JIT 相关的漏洞，以及这个漏洞利用的详细过程，通过多种组合技巧，成功实现在 Edge 浏览器中的任意代码执行，打破了当初认为的不可能。
