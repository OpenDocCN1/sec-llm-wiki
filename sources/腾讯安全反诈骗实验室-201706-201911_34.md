# EngineerMode 高通后门,未解锁即可获取ROOT权限

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2ODA1NzQxNg==&mid=2247484226&idx=2&sn=0dee1465b67e093eebccb2c3e25a2669&chksm=fc928865cbe5017360e5bda3b273245cf51fdab091e5d2f5e4b37d6b22f809b51fb5b9b0ddc0&scene=126&sessionid=1681668936#rd](http://mp.weixin.qq.com/s?__biz=MzU2ODA1NzQxNg==&mid=2247484226&idx=2&sn=0dee1465b67e093eebccb2c3e25a2669&chksm=fc928865cbe5017360e5bda3b273245cf51fdab091e5d2f5e4b37d6b22f809b51fb5b9b0ddc0&scene=126&sessionid=1681668936#rd)

腾讯反诈骗实验室监测到一例安全情报信息,国外安全研究人员发现一加的OnePlus 3、3T 和 5 等多种型号的手机安装了一个名叫 EngineerMode 的系统应用(高通开发,一加定制),该应用存在一个默认密码可用于 root 设备，可获取系统的 root 访问权限。

  

![](../Images/8adb9033c387977e8b534133ba61bb00.png)

  

**腾讯反诈骗实验室安全专家跟进结论如下:**

1. 厂商有内置该模块,影响用户量还不少

部分厂商内置的EngineerMode 的模块的确包含有相关ROOT检测代码,但是经过部分包含该组件的真机测试,未成功获得ADB ROOT权限

2 .需物理接触,实际影响较小

使用该功能需要物理接触到用户设备,并手工开启USB调试模式,正常情况下对用户的危害程度相对ROOT工具要低不少

**用户自己也可检查和应对：**

1 .用户也可以自行检测设备上是否存在此应用，打开设置-应用管理-所有应用，查看是否有工程模式这一应用(注意不是所有版本的工程模式都存在相关的ROOT接口的)

![](../Images/49931dbf312b84b98ed40beef94ef0b1.png)

  

 2. 担心存在遭到攻击的一加用户可以尝试adb shell环境下执行以下命令:

setproppersist.sys.adb.engineermode 0

setproppersist.sys.adbroot 0

或者通过拨打\*#8011# 停用设备上的root权限

**部分分析确认：**

安全专家对部分存在风险的模块进行了分析
