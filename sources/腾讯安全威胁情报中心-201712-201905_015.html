针对微软昨天（5.15）爆出的远程桌面服务漏洞CVE-2019-0708，腾讯电脑管家已率先发布漏洞检测修复工具，使用Windows XP、Windows Server 2003、Windows 7、Windows Server 2008及2008 R2系统的用户可下载使用，该工具可自动检测电脑是 安否存在远程桌面服务漏洞（CVE-2019-0708），发现漏洞后会提示用户进行修复，推荐未安装电脑管家的用户使用。已安装电脑管家的用户，直接使用管家工具箱中的漏洞修复功能即可。

远程桌面服务漏洞扫描修复工具下载地址：
http://dlied6.qq.com/invc/xfspeed/qqpcmgr/other/rdsvulfix_v1.exe
