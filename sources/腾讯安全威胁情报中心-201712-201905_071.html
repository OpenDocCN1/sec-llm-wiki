今天值得关注的威胁情报


1.挪威铝业巨头海德鲁公司受到了勒索病毒LockerGoga的攻击
世界上最大的铝生产商之一，Norsk Hydro已被迫转向部分手动操作，原因据称为勒索病毒攻击。该公司今天宣布，攻击影响了大多数业务领域的计算机系统。已有媒体表示，本次攻击可能导致全球铝价上涨。
情报来源：
https://www.bleepingcomputer.com/news/security/lockergoga-ransomware-sends-norsk-hydro-into-manual-mode/

2.Windows 7和8上的Microsoft反病毒软件出现崩溃错误0x800106ba
根据多个用户报告，Windows Defender Antivirus，Microsoft Endpoint Protection和Microsoft Security Essentials反恶意软件解决方案在运行Windows 7，Windows 8.1和Windows Server 2003，2008和2012的计算机上随机出现0x800106ba错误代码。

Microsoft确认这是一个全球性问题，并且正在努力根据提交支持案例的Windows用户开发修复程序  ，该问题将在下一个定义更新版本（1.289.1573.0）中修复，预计将在几个小时内提供。

情报来源：
https://www.bleepingcomputer.com/news/security/microsoft-antimalware-crashing-with-error-0x800106ba-on-windows-7-and-8/

3.新型SLUB backdoor使用GitHub连接到通信平台Slack   
研究人员表示，这是一个新的恶意软件，它是通过水坑攻击传播，这种技术涉及攻击者在向其添加代码之前破坏网站，导致访问者被重定向到感染代码。在这种情况下，每个访问者只被重定向一次。感染是通过利用CVE-2018-8174完成的，CVE-2018-8174是一个VBScript引擎漏洞，该漏洞由Microsoft在2018年5月修补。

情报来源：
https://blog.trendmicro.com/trendlabs-security-intelligence/new-slub-backdoor-uses-github-communicates-via-slack/
