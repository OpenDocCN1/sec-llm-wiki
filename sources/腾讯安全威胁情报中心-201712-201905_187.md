# PHP5将于年底停止更新，全球62%的用户面临安全风险，中国高达90%

网络技术应用研究公司 W3Techs 近日表示，根据所有网站使用 PHP 版本的情况，从2019年1月1日起，有近62％的网站将会因为无法获得安全更新，而受到恶意攻击。

  

国内网站的抽样分析数据来看，仅有6.15%使用了PHP7.0以上版本，近94%的PHP网站使用了旧版的PHP，远高于全球平均水平。其中医疗行业的PHP网站中PHP5.X占95%，略高于国内其他行业。  

![](../Images/f90c95e28af9e659319b37dab0dfcffd.png)

PHP网站版本分布（国内抽样）

  

从PHP 官方网站列出的支持版本及时刻表来看，PHP 5.6的安全支持将于2018年12月31日终止。意味着继续使用此版本的网站可能会暴露于未修补的安全漏洞，存在被黑客攻击的严重危险。  

![](../Images/74133416dfd97793e2c4ba220f1e8c28.png)

PHP 官方网站列出的支持版本及时刻表

  
黑客往往会利用各种漏洞对WEB服务进行渗透入侵，远程控制目标服务器，将挖矿、挂马、暗链等恶意代码插入目标网站。

  

另外一些企业网站会成为黑客渗透企业内网的跳板，黑客通过入侵企业网站，再将企业Web服务器作为跳板，渗透到内网，然后利用强大的局域网漏洞攻击工具对内网关键服务器进行横向渗透，窃取企业服务器敏感数据，或将服务器数据进行加密继而进行勒索。  

![](../Images/64f13c796da1c2e6744d35d234b97503.png)

黑客通过WEB服务器渗透内网示意图
