# 针对钢铁行业的定向攻击分析报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247485813&idx=1&sn=047388e6702cc9981c1c0064303d60cc&chksm=ec9cd006dbeb5910e9713bb8ee26f97ba26359e1930cc5df90a962651f6ac645cd9502a6dfb6&scene=126&sessionid=1681278617#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247485813&idx=1&sn=047388e6702cc9981c1c0064303d60cc&chksm=ec9cd006dbeb5910e9713bb8ee26f97ba26359e1930cc5df90a962651f6ac645cd9502a6dfb6&scene=126&sessionid=1681278617#rd)

![](../Images/88b9667c92778179ad318ceaf355b836.png)

7月份腾讯御见威胁情报中心在日常监测网络攻击行为时，发现了多起针对钢铁行业的邮件钓鱼攻击，黑客在攻击中大量使用钢铁行业相关的诱饵文档，比如销售合同、商品价位表、规格书及图片等等。这些诱饵文档实际上为CVE-2017-11882漏洞文档。

  

一旦运行这些诱饵文档，用户电脑会自动触发CVE-2017-11882漏洞，进而下载病毒文件。据统计，整个7月份网络上类似的邮件钓鱼高达10万余次，借此传播的远控木马类型多达10余种，包括RemcosRAT、NetWire、AgentTesla、LokiBot、HawkEye、Formbook等等。 

  

这些远控木马不仅会窃取用户的敏感信息，包括**键盘记录、窃取邮箱帐号密码和几乎所有浏览器记录的网站帐号密码**等，同时还**支持多平台远程控制****，根据黑客下发的指令下载和执行恶意程序**，控制受害者电脑，使之成为僵尸网络的组成部分。

  

受害用户主要是钢铁行业的海外业务拓展人员。出于业务拓展需要，不少用户习惯将联系邮箱等信息挂到各大社区网站或论坛。而黑客利用爬虫程序能够轻易收集到这些邮箱信息，并加以利用。

  

本轮钓鱼攻击的其中一例钓鱼邮件，是以“China Steel Offer”为主题，附件中带有名为“China Steel Pricelist.doc”的CVE-2017-11882 漏洞文档。漏洞文档被打开后，会从“uploadtops.is”下载和执行NetWire远控木马，从而使受害者沦为受黑客控制的“肉鸡”。以下为具体分析：

# **0x1 技术分析**

下载下来的样本为vb语言编写，vb程序中有一段加密的shellcode.

![](../Images/ff8273c187b6d052a8dcb713d0cd3cd2.png)

（vb程序入口点）

  

Shellcode会解密出一个pe，然后内存加载和执行此pe文件

![](../Images/f200a4b9c92aca39b0de860315508035.png)

（内存中的pe文件）

  

Dum出的pe中字符串信息如下，字符串明显被加密了。

![](../Images/236231bbaa25fece4dd67a63caf4b0f4.png)

（加密的字符串信息）  

  

![](../Images/7a866f2b033288044dd24f45a8889cab.png)

（解密后的部分明文字符串）

  

木马的配置信息都被加密存储了，解密后可以看到木马的c2地址。

![](../Images/c27bf6ef6b22d0172c9668c353609b1d.png)

（解密后的c2）

  

木马会调用RegisterRawInputDevices、GetRawInputData等api来实现键盘记录器的功能，收集硬盘信息等也是此木马的功能之一。

![](../Images/c58a3a7845c51496ccb9959149b4d734.png)

（键盘记录器代码）

  

![](../Images/01118e0a9691be7e178f8d7731e1b3c6.png)

（收集磁盘信息）

  

通过查阅此木马的用户使用手册可知该木马不仅支持windows平台，还支持Linux、Solaris、Mac OS等平台，通过此木马的生成器还能生成java或apk版的木马。木马主要功能有文件管理、系统管理、窃取存取在计算机上的密码、键盘记录、屏幕截取、远程shell、下载、反向代理等功能。

![](../Images/3f4722d289dc80cad1b140948a4a983d.png)

（NetWire用户手册）

  

该木马可以窃取Mozilla Firefox所有版本、Internet Explorer所有版本、Opera所有版本、Chrominum所有版本、SeaMonkey所有版本的网页浏览器中存储的密码，还可以窃取邮箱软件MozillaThunderbird和Outlook中存储的密码，也支持获取聊天工具Winds Live Messenger 和Pidgin的密码。  

  

# **0x2 关联分析**

在腾讯御见威胁情报系统中利用“uploadtops.is”域名进行反查，我们发现了较多的木马会从域名进行下载。

![](../Images/efe7be8f0ff92b7f693a6a542a26e742.png)

  

在地域分布方面，广东、江苏、浙江等地区被攻击较严重。

![](../Images/c892565fe60f11c3d46043f366e75bff.png)

  

通过对下载到的木马进行关联分析，我们还发现一批在漏洞文档中张贴工商银行票据当诱饵的攻击活动，同样是使用钓鱼邮件加CVE-2017-11882漏洞的攻击方式。

![](../Images/cb2095322ced07b9a12f1886d7439189.png)

（漏洞文档中的内容）

  

另外我们发现在本轮攻击活动中，使用的诱饵文档，不仅有钢铁相关的销售合同，还有直接其它需要钢铁的周边物件规格书（比如“脚手架”）、或者包含钢材相关的图片等。

![](../Images/80f7c8064ca60ad90ddcc7f308f1b9b4.png)

（脚手架材料漏洞文档）

 

![](../Images/922c0bf2382769c193b6852ce92decab.png)

（漏洞文档中的内容）

  

上述url中下载回来的木马都属于远控木马，大致功能与本文中的netwire相同，不再作进一步分析。

  

# **0x3 安全建议**

#   

# 1. 推荐使用腾讯御点终端安全管理系统（下载地址：https://s.tencent.com/product/yd/index.html），及时修复系统高危漏洞，防御病毒木马威胁。

![](../Images/0cfe4b70b1a67c34e4e54a7ddf80a06e.png)

  

# 2.  推荐使用御界防APT邮件网关（下载地址：https://s.tencent.com/product/yjwg/index.html），迅速识别APT攻击邮件、钓鱼邮件、病毒木马附件、漏洞利用附件等威胁，有效防范邮件安全风险，保护企业免受数据和财产损失。

  

# 3.  查阅邮件时要注意识别邮件发件人信息，不要轻易打开来历不明的邮件中的附件。

  

# 4.  企业网管可以为防火墙新增IOCs里ip和url的拦截。
