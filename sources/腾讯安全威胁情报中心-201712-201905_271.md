# 你的Chrome浏览器装广告拦截插件了吗？赶紧检查一下

腾讯御见威胁情报中心监控发现，一款在Chrome上十分流行的广告拦截插件Adblock Pro运行后会自动请求挖矿程序进行挖矿。只要用户在Chrome中安装并启用了Adblock Pro 4.3版插件，一旦启动Chrome浏览器就会导致电脑资源为100%占用，使电脑严重卡慢无法使用。  

![](../Images/94e1bf3f5c8f3e83340ce08232c80fd6.png)

请求的挖矿JS为：hxxp://t.hanstrackr.com/track.min.js

**影响范围：**

Chrome官方商店以及Chrome第三方插件网站下载的Adblock Pro 4.3。  
  
Adblock Pro是Google Chrome浏览器非常受欢迎的广告屏蔽扩展程序，在Google Chrome网上应用店中有超过270万用户和12500个正面评级。

  

目前，Chrome应用商店已将该插件下架。  

  

**安全建议：**  
如有安装4.3版本的Adblock Pro插件，立即将该插件从Chrome浏览器扩展程序中删除（检查Chrome设置菜单->更多工具->扩展程序，在列表中找到Adblock Pro插件），需要广告过滤功能的用户用其他同类程序代替，不要下载安装该插件。
