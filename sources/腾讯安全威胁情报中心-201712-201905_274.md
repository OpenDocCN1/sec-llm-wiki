# Apache strusts2漏洞一年未修复，致Web服务器被批量入侵挖矿

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247484661&idx=1&sn=f79e36eded818f8b931e4fed0f4c78c7&chksm=ec9cdd86dbeb5490a073b041bb014a2c1866a0f130bebb26b9ff850d841c653d7e2e446ce86d&scene=126&sessionid=1681278638#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247484661&idx=1&sn=f79e36eded818f8b931e4fed0f4c78c7&chksm=ec9cdd86dbeb5490a073b041bb014a2c1866a0f130bebb26b9ff850d841c653d7e2e446ce86d&scene=126&sessionid=1681278638#rd)

**0x1 概述**  
        腾讯御见威胁情报中心监控发现，近期有大批企业网站Web服务器遭入侵并植入挖矿木马。  
  
        安全人员分析发现这些被入侵的Web服务器多存在Apache Struts 2 Jakarta Multipart Parser远程代码执行（RCE）漏洞(S2-045,CVE-2017-5638)，该漏洞在2017年3月被报出，影响范围为Struts 2.3.5 - Struts 2.3.31、Struts 2.5 – Struts 2.5.10。黑客组织利用该漏洞批量攻击网站并植入了木马。  
  
**0x2 威胁等级（中度）**  
危害评估：★★★★☆  
        网站服务器已知漏洞未修复，致服务器被入侵，挖矿只是威胁之一，亦可导致严重的信息泄露事件。黑客还可以通过入侵Web服务器为跳板，继续向企业内网渗透攻击。

  

影响评估：★★★☆☆  
        影响范围较广  
  
技术评估：★★☆☆☆  
        已有成熟的批量攻击工具及漏洞修复方案  
  
**0x3 影响面**  
        Apache Struts 2.3.5 – Apache Struts 2.3.31  
        Apache Struts 2.5 – Apache Struts 2.5.10

**0x7 安全建议**  

1.   可查看web目录下/WEB-INF/lib/目录下的struts-core.x.x.jar 文件，如果这个版本在Struts2.3.5 到 Struts2.3.31 以及Struts2.5 到 Struts2.5.10之间则存在漏洞。  
    受影响用户可升级版本至Apache Struts 2.3.32 或 Apache Struts 2.5.10.1以消除漏洞影响。  
      
    
2.  使用腾讯企业安全“御知网络空间风险雷达”（网址：https://s.tencent.com/product/yuzhi/index.html）进行风险扫描和站点监控，及时修复Web服务器安全漏洞。  
      
    
3.  网站管理员可使用腾讯云网站管家智能防护平台，其具备web入侵防护，0Day漏洞补丁修复等多纬度防御策略，可全面保护网站系统。下载地址：https://cloud.tencent.com/product/waf
