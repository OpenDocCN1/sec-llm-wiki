# 腾讯御见：公式编辑器漏洞攻击样本新变种预警

**0x1 概述**  

2017年，微软office公式编辑器连续被曝出两个存留时间长达17年的高危漏洞（CVE\_2017-11882漏洞和由腾讯安全专家发现的CVE-2018-0802漏洞）。由于该系列漏洞利用方式简单稳定，腾讯御见威胁情报中心在漏洞曝光后持续监测其被利用进行大规模攻击（如针对外贸行业的“商贸信病毒”），并发布了多次预警。

近期，我们监测到其攻击载体文档出现新变种，其针对部分杀软检测进行了特征免杀处理，攻击成功后下载商业化木马FormBook执行，FormBook主要功能是窃取键盘记录、浏览器表单、本地密码、截屏、剪贴板、下载执行文件等。

  

**0x2 样本细节**

  

1、 新的存储结构CFBF（Compound File Binary Format）

该类漏洞样本将公式数据存放在一个CFBF结构中，该结构中存放一个“\\x1\\x0Ole10Native”字节流。CFBF结构如下图：

![](../Images/d186d1f42f26bc7df6b504345c67d55f.png)

  

此前发现的漏洞利用则是将公式数据存放在一个OLE Object中，如下图所示：![](../Images/bdb19e831f66832dc25ad523fbebcc90.png)

该Object中存放的是一个Equation Object:

![](../Images/795deedc642ecd5ee2b6371c4d3201d3.png)

 

2、 被修改的MTEF(MathType’s Equation Format) 

**Header**

“\\x1\\x0Ole10Native”字节流，头部四个字节是长度字段，剩下的则是字节流的内容。字节流的内容包括两部分，一部分是被修改的MTEF Header，另一部分则是MTEF Byte Stream。

![](../Images/d79f6208d1d38c9158c267143c56ce82.png)

**MTEF Header结构如下：**

![](../Images/b3d8ea03f785db80424e60f1b1e42915.png)

该类样本为躲避杀软的静态特征查杀故意将MTEF Header的特征数据修改为异常值，同时这并不影响漏洞的正常触发。

![](../Images/6fb34360d7f61e0e4f1c70c10df898dd.png) 

3、 关键代码分析

针对“\\x1\\x0Ole10Native”和Equation Native两种流分别处理，并且最后都调用sub\_42F8FF处理公式数据，最终触发漏洞。

![](../Images/95b363d8dfa23b8e0d130c7c15ec4147.png)

  

**0x3 解决方案和安全建议**

  

1\. 正常开启腾讯电脑管家/腾讯御点等安全软件，使用管家/御点安装所有系统高危补丁。

2\. 针对未安装或者不适合安装Office补丁的机器，腾讯电脑管家/腾讯御点推出独有的“女娲石”防御技术，无需升级病毒库即可有效拦截一切利用公式编辑器漏洞触发传播的病毒以及任意变种，铸造坚固的漏洞攻击防御体系。![](../Images/a39bad57d13a47f7b94f6aff1ce514db.png)
