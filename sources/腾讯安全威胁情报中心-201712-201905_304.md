# 腾讯御见：WannaMiner挖矿木马攻击事件通报

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247484085&idx=1&sn=468a0af5f10313b9987c08dc00b11c58&chksm=ec9cdbc6dbeb52d0acd8d27a4fcfecae392771d2a631cdd2253af3ecbe993b66ec90bcc66f19&scene=126&sessionid=1681278653#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247484085&idx=1&sn=468a0af5f10313b9987c08dc00b11c58&chksm=ec9cdbc6dbeb52d0acd8d27a4fcfecae392771d2a631cdd2253af3ecbe993b66ec90bcc66f19&scene=126&sessionid=1681278653#rd)

**0x1 概述**

  近期，腾讯御见威胁情报中心监控到有攻击者利用“永恒之蓝”漏洞，传播一种门罗币挖矿木马WannaMiner。值得关注的是，WannaMiner木马将染毒机器构建成一个健壮的僵尸网络，其支持内网自更新，并且以一种相对低调的获利方式“挖矿”来长期潜伏。

  尽管早在2017.5月WannaCry事件爆发时，很多机器已经在安全软件帮助下安装了相应补丁。但本次WannaMiner攻击事件揭示，仍有部分企事业单位未安装补丁或者部署防护类措施。由于其在内网传播过程中通过SMB进行内核攻击，可能造成企业内网大量机器出现蓝屏现象。

 

**0x2 事件分析**

样本总体感染流程如下图所示：

![](../Images/0e30874bcc426ae72a9d460291c05973.png)

本攻击可以分为3个部分：

 1. **扫描攻击阶段**：利用spoolsv.exe扫描目标机器445、26931端口，如果445端口处于打开状态，并且26931端口处于关闭状态，则利用永恒之蓝漏洞发起攻击。

 2. **安装阶段**：受害者主机被攻击者利用永恒之蓝漏洞攻击成功后，会释放主控模块srv为tpmagentservice.dll，然后将其添加到系统服务，实现开机自启。

 3. **攻击阶段**：tpmagentservice.dll主控模块加载后，会释放挖矿模块开始挖门罗币。同时会创建web服务用于实现内网更新功能（和僵尸网络的更新机制一致），并且和远程服务器进行通信。然后，会继续利用spoolsv.exe（3ABA72D1F87F4372162972B6A45ED8CD）感染更多机器。

 黑客攻击时首先通过spoolsv.exe扫描目标机器445端口，如果端口处于打开状态，则尝试通过永恒之蓝漏洞利用工具svchost.exe进行攻击，如果攻击成功，则受害者机器上会执行x86.dll/x64.dll（具体根据受害者系统不同进行选择），该DLL会通过创建系统服务的方式安装病毒的主控模块spoolsv/spoolsv64（具体根据受害者系统不同进行选择）。该模块加载后会执行挖矿程序hash/hash64，同时会向远程控制服务器发送受害者的基本信息，并尝试获取更新模块。并且主控模块会继续运行扫描模块spoolsv.exe尝试感染当前网络内的其他机器。此外，该模块还利用mongoose创建web服务，实现僵尸网络的内网更新功能。

 

下面对这些模块进行详细分析

 （1）攻击模块：spoolsv.exe该模块运行后先通过检查硬编码在样本中的的MutexName：{DA432CD54-A1C6-9015-C12B42B}，来确保当前系统仅有一个该模块处于运行状态。如果已经有该模块处于运行状态，则退出，否则继续执行后面的代码。

![](../Images/1d9e412054d93d9aaa25a2ae24869a71.png)

  

接着样本会创建2个负责攻击的线程

 线程1：负责扫描当前网段其他机器的445端口和26931端口，如果445端口处于打开状态并且26931端口处于关闭状态，则表示该机器是未被攻击的机器，将其信息保存到临界区中。这里扫描445端口是为了判断哪些机器可以尝试利用永恒之蓝漏洞进行攻击，而26931则是样本感染后会监听的一个端口，所以如果该端口已经处于打开状态，样本则认为该机器已经被感染过。

 线程2：负责感染其他机器。如果C:\\Windows\\System32\\MsraReportDataCache32.tlb文件存在，则提取里面的crypt，释放到C:\\Windows\\SecureBootThemes\\crypt,然后将刚刚释放的crypt解压到C:\\Windows\\SecureBootThemes\\Microsoft\\目录，然后删除C:\\Windows\\SecureBootThemes\\Cryp文件。工具释放完毕后，读取线程1获取到的目标机器地址信息，保存到C:\\Windows\\SecureBootThemes\\Microsoft\\spoolsv.xml中，然后执行spoolsv.exe继续感染其他机器。

（3）主控模块tpmagentservice.dll主要包括以下几个功能：

Ø感染功能

Ø挖矿功能

Ø内网更新功能

Ø外网通信

Ø卸载功能

 

 1.感染功能

 从MsraReportDataCache32.tlb文件提取spoolsv并释放到C:\\Windows\\SecureBootThemes\\spoolsv.exe，然后执行该程序负责继续感染其他机器。

 3.内网更新模块

 此样本除了会向远程服务器获取更新外，还会使用僵尸网络的更新方式，每一台感染的机器会利用mongoose创建一个web服务，用于保存病毒的最新模块文件，主控模块运行后会尝试连接26931端口获取更新模块，这样只要整个僵尸网络中有一台电脑能连接公网，其他不能连接公网的机器同样能获取最新模块。此处也解释前面扫描模块扫描端口时同样会检查26931端口是否打开，如果已经打开则表示该机器已经感染过了。

腾讯御见威胁情报中心依托安全大数据关联分析能力，可以有效挖掘出WannaMiner家族历史样本，以及本次攻击针对的行业感染分布情况。

  根据御见威胁情报中心数据，此类攻击从2018年初起呈上升趋势，截止目前国内已有数百家企业已经被攻击成功。其中医疗，教育等公共事业型单位一旦被攻击容易造成较大影响，相关单位应尽快部署防御措施。

 

**0x4 解决方案和安全建议**

1. 定位和隔离已中毒机器，可以通过扫描26931端口判断，如该端口开放则主机已被感染。

 2. 阻断木马访问外联地址rer.njaavfxcgk3.club和acs.njaavfxcgk3.club。

 3. 手动安装“永恒之蓝”漏洞补丁请访问以下页面

  https://technet.microsoft.com/zh-cn/library/security/ms17-010.aspx

  其中WinXP，Windows Server 2003用户请访问

  https://www.catalog.update.microsoft.com/Search.aspx?q=KB4012598

 4. 建议全网安装专业的终端安全管理软件，如腾讯御点（https://s.tencent.com/product/yd/index.html），由管理员批量杀毒和安装补丁，后续也可以及时更新各类系统高危补丁。
