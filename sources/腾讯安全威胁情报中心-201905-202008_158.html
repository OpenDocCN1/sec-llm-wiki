Apache IoTDB 错误配置JMX RMI远程代码执行漏洞（CVE-2020-1952）

【漏洞背景】
2020年4月27日，apache官网的一封邮件披露， Apache IoTDB在特定版本中，由于默认配置不当，导致31999上的JMX 端口被暴露出来。如果被攻击者访问到，可导致远程代码执行。

【漏洞等级】高危


【漏洞详情】
2020年4月27日，apache官网的一封邮件披露， Apache IoTDB在特定版本中，由于默认配置不当，导致31999上的JMX端口被暴露出来。


受影响的版本默认允许所有IP，且不需要身份认证可访问31999端口上的JMX服务，攻击者可通过JMX服务实现远程代码执行。

【漏洞复现】
使用受影响的版本验证，可复现

 

【影响版本】
0.9.0~0.9.1
0.8.0~0.8.2

【修复建议】
1.禁止31999端口对外开放
Linux用户修改/conf/iotdb-env.sh
将 JMX_LOCAL=no 改为 JMX_LOCAL=yes
Windows用户修改/conf/iotdb-env.bat
将 set LOCAL_JMX=no 改为 set LOCAL_JMX=yes


2.升级到最新的0.9.2版本。

【腾讯安全解决方案】
推荐企业用户部署腾讯T-Sec高级威胁检测系统（腾讯御界）对黑客利用漏洞的攻击行为进行检测。


腾讯T-Sec高级威胁检测系统，是基于腾讯安全能力、依托腾讯在云和端的海量数据，研发出的独特威胁情报和恶意检测模型系统，该系统可及时有效检测黑客对企业网络的各种入侵渗透攻击风险。参考链接：https://cloud.tencent.com/product/nta。
