# Apache IoTDB 错误配置JMX RMI远程代码执行漏洞（CVE-2020-1952）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247494666&idx=2&sn=dd80926b11372f80f322b2a7ace9e795&chksm=ec9f3579dbe8bc6f7b962a1a8c372ce2ba5667e8704754d6838d14276cc87d3b50473c18e6a5&scene=126&sessionid=1681278435#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247494666&idx=2&sn=dd80926b11372f80f322b2a7ace9e795&chksm=ec9f3579dbe8bc6f7b962a1a8c372ce2ba5667e8704754d6838d14276cc87d3b50473c18e6a5&scene=126&sessionid=1681278435#rd)

**【漏洞背景】**  
2020年4月27日，apache官网的一封邮件披露， Apache IoTDB在特定版本中，由于默认配置不当，导致31999上的JMX 端口被暴露出来。如果被攻击者访问到，可导致远程代码执行。  
  
**【漏洞等级】**高危

**【漏洞详情】**  
2020年4月27日，apache官网的一封邮件披露， Apache IoTDB在特定版本中，由于默认配置不当，导致31999上的JMX端口被暴露出来。  

  

受影响的版本默认允许所有IP，且不需要身份认证可访问31999端口上的JMX服务，攻击者可通过JMX服务实现远程代码执行。  
  
**【漏洞复现】**  
使用受影响的版本验证，可复现  

![](../Images/4abf60a93251e7f4a61f22ff828d513f.png)

   

![](../Images/cc112e85af9c435e24a3018653de53ae.png)

**【影响版本】**  
0.9.0~0.9.1  
0.8.0~0.8.2  
  
**【修复建议】**  
1.禁止31999端口对外开放  
Linux用户修改/conf/iotdb-env.sh  
将 JMX\_LOCAL=no 改为 JMX\_LOCAL=yes  
Windows用户修改/conf/iotdb-env.bat  
将 set LOCAL\_JMX=no 改为 set LOCAL\_JMX=yes  

  

2.升级到最新的0.9.2版本。  
  
**【腾讯安全解决方案】**  
推荐企业用户部署**腾讯T-Sec高级威胁检测系统（腾讯御界）**对黑客利用漏洞的攻击行为进行检测。  

  

**腾讯T-Sec高级威胁检测系统**，是基于腾讯安全能力、依托腾讯在云和端的海量数据，研发出的独特威胁情报和恶意检测模型系统，该系统可及时有效检测黑客对企业网络的各种入侵渗透攻击风险。参考链接：https://cloud.tencent.com/product/nta。
