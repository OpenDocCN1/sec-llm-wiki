本周值得关注的威胁情报

APT活动

**1.研究机构披露TA505近一年针对韩国金融部门的大规模网络攻击**  
  
研究人员周五表示，黑客组织在2019年的大部分时间里都在尝试利用网络钓鱼手段诱骗韩国金融，制造和医疗服务企业韩国。  
  
研究人员说，这个名为TA505的组织至少自2014年以来一直活跃，并且似乎与FIN7共享工具，技术和程序，FIN7是一个俄语国家组织，其全球损失超过10亿美元。连接FIN7和TA505是一项众所周知的艰巨任务，研究人员此前曾混淆过这些小组。  
  
**情报来源：**  
https://www.cyberscoop.com/ta505-south-korea-bank-phishing/

安全漏洞

  
**1.CVE-2020-8794: OpenSMTPD 远程命令执行漏洞通告**  
国外 qualys 研究团队已经公布 OpenSMTPD 的一枚远程命令执行漏洞的漏洞细节，漏洞编号为 CVE-2020-8794，影响 6.6.4 及之前的版本。该漏洞是一个越界读漏洞，在 2015年12月被引入 (commit id 80c6a60c)。  
  
该漏洞在默认安装 OpenSMTPD 情况下，即可攻击成功并执行任意命令。  
  
**情报来源：**  
https://cert.360.cn/warning/detail?id=5ed8d8cc121c223ac27d877f9e7b20b9  
  
**2.FasterXML/jackson-databind 远程代码执行漏洞通告**  
安全研究者 threedr3am，LFY 和 V1ZkRA向 FasterXML 提交了两个gadget，可用作jackson-databind的RCE（远程代码执行）。  
  
**情报来源：**  
https://mp.weixin.qq.com/s/Wv-NJPod4qPurH3r2q5kkA  
  
**3\. CVE-2019-15126漏洞将影响数十亿无线设备的加密模块**  
研究人员发现了一个以前未知的安全漏洞，使攻击者可以解密易受攻击的设备传输的一些无线网络数据包。  
  
此严重漏洞（指定为CVE-2019-15126）使易受攻击的设备使用全零加密密钥来加密用户通信的一部分。在成功的攻击中，这使对手可以解密易受攻击的设备传输的一些无线网络数据包。  
  
**情报来源：**  
https://blog.eset.ie/2020/03/02/krook-serious-vulnerability-affected-encryption-of-billion-wi‑fi-devices/  
  
**4.CVE-2020-0674: Internet Explorer远程代码执行漏洞PoC公开通告**  
CVE-2020-0674该漏洞出现在Internet Explorer脚本引擎 JScript.dll 中。该组件存在一个远程代码执行漏洞。  
  
该漏洞可以使攻击者在当前用户环境中执行任意代码。利用此漏洞的攻击者可以获得与当前用户相同的用户权限。  
  
**情报来源：**  
https://cert.360.cn/warning/detail?id=5f9242ea19585dd693f215768c4dfd2f  
  
**5.CVE-2020-6418: Chrome V8引擎远程代码执行漏洞通告**  
一枚Chrome远程代码执行漏洞细节已在互联网上公开，该漏洞编号为CVE-2020-6418。该漏洞是 Chrome V8 引擎中出现的一例类型混淆漏洞。攻击成功可导致远程代码执行。  
  
**情报来源：**  
https://cert.360.cn/warning/detail?id=cbf0642177c6dbb22481f82fcf2a0f1e

**2.Emsisoft发现了一种PwndLocker的解密方案**  
Emsisoft发现了一种解密PwndLocker勒索软件加密文件的方法，以便受害者无需支付赎金即可恢复其文件。该勒索病毒正在攻击世界各地，赎金从175,000美元到660,000美元以上不等。  
  
**情报来源：**  
https://www.bleepingcomputer.com/news/security/pwndlocker-ransomware-gets-pwned-decryption-now-available/

其他事件

  
**1.黑客可以使用超声波秘密控制语音助手设备**  
  
研究人员发现了一种新的方法，可以通过在固体材料中传播超声波来瞄准声控设备，从而在受害者不知情的情况下使用听不见的声控命令与声控设备进行交互和破坏。这种攻击称为“ SurferingAttack ”，利用了固体材料（例如桌子）中声音传输的独特特性，以“使声控设备与攻击者之间可以进行更长距离的多次交互”。  
  
**情报来源：**  
https://thehackernews.com/2020/03/voice-assistants-ultrasonic-waves.html  

  

**2.Guildma银行木马分析**  
这是一种非常流行的拉丁美洲银行木马，是用Delphi编写的针对巴西的特洛伊木马，具有一些创新的执行和攻击技术。文章描述最新版本，重点介绍自2019年中期以来发布的关于Guildma的大量文章以应对迄今为止最大规模的活动以来所做的最显着变化。  
  
**情报来源：**  
https://www.welivesecurity.com/2020/03/05/guildma-devil-drives-electric/
