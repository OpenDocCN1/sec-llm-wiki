# 【安全通告】Apache FreeMarker模板FusionAuth远程代码执行漏洞(CVE-2020-7799)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247493270&idx=1&sn=7fea65c7ff50fb5366be0b8f7c758e38&chksm=ec9f3fe5dbe8b6f364bbf66ddbe15d4ef373ecfe9382f5ce850ae48c0a60f481eafb3525dd8a&scene=126&sessionid=1681278466#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247493270&idx=1&sn=7fea65c7ff50fb5366be0b8f7c758e38&chksm=ec9f3fe5dbe8b6f364bbf66ddbe15d4ef373ecfe9382f5ce850ae48c0a60f481eafb3525dd8a&scene=126&sessionid=1681278466#rd)

**【背景】**  
近日，Apache FusionAuth 被曝光存在远程代码执行漏洞。该组件利用了Apache FreeMarker模板引擎，由于未对用户输入的数据做过滤，经过身份验证的用户在使用Apache FusionAuth进行模板编辑时，可利用freemarker.template.utility.Execute执行任意命令。  
  
**【漏洞详情】**  
Apache FusionAuth 组件利用了Apache FreeMarker模板引擎，由于未对用户输入的数据做过滤，经过身份验证的用户在使用Apache FusionAuth进行模板编辑时，可利用freemarker.template.utility.Execute执行任意命令，目前利用方式已经被公开。  
  
**【风险评级】**严重

**【影响版本】**  

Apache FusionAuth <= 1.10  
  
**【修复建议】**  
1.FusionAuth 1.11版本中已修复该漏洞，建议受影响的用户尽快更新，新版下载地址：  
https://fusionauth.io/direct-download  
  
2.腾讯御界可检测针对该漏洞的攻击
