# Oracle Weblogic远程代码执行漏洞安全通告（CVE-2020-2546、CVE-2020-2551）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247493210&idx=3&sn=3cd012755f5b7caabd5464e0b26ee36c&chksm=ec9f3f29dbe8b63f70a736e818365c2ba2873af3780436325cbbfbf3bebe86a2743039ae535f&scene=126&sessionid=1681278466#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247493210&idx=3&sn=3cd012755f5b7caabd5464e0b26ee36c&chksm=ec9f3f29dbe8b63f70a736e818365c2ba2873af3780436325cbbfbf3bebe86a2743039ae535f&scene=126&sessionid=1681278466#rd)

  

![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)**背景**![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)

2020年1月15日，Oracle发布一系列安全补丁，其中CVE-2020-2546和CVE-2020-2551编号的漏洞发生在Weblogic服务上，可在未认证的前提下，通过发送精心构造的恶意 HTTP 请求，执行远程代码。  
  
WebLogic是Oracle公司出品的一个application server，确切的说是一个基于JAVAEE架构的中间件，WebLogic是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。

![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)**漏洞详情**![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)

本次补丁包含Weblogic Server上 2个9.8分的漏洞和2个7.5分的漏洞，均可以在未授权的条件下远程利用：  

![](../Images/d44c08ddf46c6c902be566caa3fd8e95.png)

![](../Images/879cf97299af6b65c94c38988435af09.png)

![](../Images/3b62b8a3da0024f49bb8efaedd5610ec.png)

  
其中CVE-2020-2546和CVE-2020-2551的评分较高，均为9.8分，漏洞危害较大，利用难度要较低，建议尽快处理。

![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)**风险评级**![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)

![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)**修复建议**![](../Images/14e8fd6ab1f25b3c470f7317f288ca6d.png)

请登录 https://support.oracle.com 获取安装最新的安全补丁。  
若暂时无法下载，可在AdminServe -> 协议 -> IIOP 中关闭IIOP协议并保存。  

![](../Images/99048acb287731e505ca6707ddc8f814.png)

  
在<域名> ->  安全 -> 筛选器 中配置 受信任的源通过t3协议访问服务（需重启服务）：  

![](../Images/442b79f4a28dbc740bac8d6e88e5343a.png)

  
确保从外部无法访问t3协议：  

![](../Images/768f40ca262649d7e300a2c746fb9390.png)

  
以此来缓解漏洞的影响。
