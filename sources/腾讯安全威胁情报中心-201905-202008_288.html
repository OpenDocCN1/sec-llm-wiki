【安全通告更新】Citrix ADC和Citrix Gateway远程代码执行漏洞（CVE-2019-19781）

原文：http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247493115&idx=1&sn=883ecad58fa8cf0e9722bfe72d005b9b&chksm=ec9f3c88dbe8b59e8d9fa52a5e0693fbbaa2e9f1ac489eb37fb98da172770559b3af6784f809&scene=126&sessionid=1681278471#rd
【背景】
近日， Citrix公司的 ADC (Application Delivery Controller, 也叫NetScaler ADC) 和 Gateway (也叫 NetScaler Gateway) 被爆出存在目录遍历和远程代码执行的漏洞。

【漏洞详情】
早前推特mpgn(@mpgn_x64) 首先公开了部分Poc，可在受影响的版本上通过未授权的GET请求执行目录遍历。
GET /vpn/../vpns/services.html 
GET /vpn/../vpns/cfg/smb.conf

如果返回 HTTP/1.1 403 Forbidden 则已修复。

至于如何造成远程代码执行，其只公布了部分细节。但原本是目录遍历的漏洞，现在升级成为远程代码执行的漏洞，该漏洞远程代码执行的EXP已经被公开，目前官方暂未发布修复补丁，请有使用到Citrix的尽快采取缓解措施。

NVD评分9.8（严重）

【风险评级】严重

【漏洞验证】
直接使用公开的EXP验证


【影响版本】
影响目前所有的受支持的版本和平台，包括：
• Citrix ADC and Citrix Gateway version 13.0 all supported builds
• Citrix ADC and NetScaler Gateway version 12.1 all supported builds
• Citrix ADC and NetScaler Gateway version 12.0 all supported builds
• Citrix ADC and NetScaler Gateway version 11.1 all supported builds
• Citrix NetScaler ADC and NetScaler Gateway version 10.5 all supported builds

【修复建议】
根据官方提供的建议进行缓解：
