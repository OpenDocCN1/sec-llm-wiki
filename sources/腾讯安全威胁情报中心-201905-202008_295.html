勒索病毒

1.联邦调查局发布LockerGoga和MegaCortex勒索软件警报
FBI已向私营行业接受者发出警告，以提供有关LockerGoga和MegaCortex勒索软件的信息和指导。

LockerGoga和MegaCortex都是勒索软件感染，它们通过破坏网络然后尝试对所有设备进行加密来针对企业。

情报来源：
https://www.bleepingcomputer.com/news/security/fbi-issues-alert-for-lockergoga-and-megacortex-ransomware/

2.迷宫勒索软件（Maze Ransomware）放出2GB彭萨科拉市被加密的文件
彭萨科拉市遭受Maze勒索软件攻击，该勒索软件攻击影响了该市的电子邮件服务和某些电话服务，并导致他们关闭计算机系统。


攻击者称他们在加密网络之前窃取了数据，要求提供100万美元的赎金以解密其文件。迷宫勒索病毒释放了32GB文件中的2GB，以证实他们掌握的文件不止这些。

情报来源：
https://www.bleepingcomputer.com/news/security/maze-ransomware-releases-files-stolen-from-city-of-pensacola/

3.Ryuk Ransomware停止加密Linux文件夹
Ryuk 勒索软件发布新版本，该版本将有意避免对linux操作系统中常见的文件夹进行加密。

在新奥尔良市已确认被Ryuk 勒索软件感染，在分析了样本之后，安全研究员发现病毒不再加密与linux操作系统关联的文件夹。

情报来源：
https://www.bleepingcomputer.com/news/security/ryuk-ransomware-stops-encrypting-linux-folders/

远程控制及窃密木马

1.Waterbear又回来了，使用API挂钩来逃避安全产品检测
Waterbear已经开展了几年，它是一项使用模块化恶意软件的活动，该恶意软件能够远程包括其他功能。与网络间谍组织BlackTech有关，主要针对东亚的技术公司和政府机构。

在以前的活动中，我们已经看到Waterbear主要用于横向移动，通过其加载程序组件解密和触发有效载荷。在大多数情况下，有效负载是后门，可以接收和加载其他模块。但是，在其最近的一项活动中，我们发现了一个Waterbear负载，其目的是全新的：通过API挂钩技术将其网络行为从特定的安全产品中隐藏起来。

情报来源：
https://blog.trendmicro.com/trendlabs-security-intelligence/waterbear-is-back-uses-api-hooking-to-evade-security-product-detection/

2.不要回复这个节日派对：保护自己免受Emotet木马的侵害
Emotet特洛伊木马背后的网络罪犯一直针对用户发起新的垃圾邮件活动，该活动冒充圣诞节派对邀请。

恶意行为者精心制作了伪造的邀请函，其中包括主题行，例如“下周的圣诞节派对”，附件为“ Christmas party.doc”或“ Party menu.doc”。如果用户打开这些Word文档启用了宏代码，则会安装Emotet木马。完成此操作后，可以将受害者的设备用于更多恶意攻击。

情报来源：
https://securingtomorrow.mcafee.com/blogs/consumer/consumer-threat-notices/christmas-emotet-trojan/

3.法兰克福因感染Emotet恶意软件而关闭IT网络
法兰克福是世界上最大的金融中心之一，也是欧洲中央银行的所在地。在受到Emotet恶意软件感染后，法兰克福本周关闭了其IT网络。


从城市的网站到公共交通的票务服务，城市提供的一切与信息技术相关的服务目前都处于下线状态。

情报来源：
https://www.zdnet.com/article/frankfurt-shuts-down-it-network-following-emotet-infection/

4.垃圾邮件冒充瑞典活动家传播Emotet恶意软件
Proofpoint威胁洞察团队的专家发现了一个利用瑞典气候变化活动家Greta Thunberg作为诱饵，传播Emotet恶意软件的垃圾邮件运动。垃圾邮件附带一个名为“Support Greta Thunberg.doc”的Microsoft Word文档。当收件人打开邮件时，将安装Emotet木马程序。


这些攻击不仅针对全球，而且针对本国语言的诱饵也是如此。研究人员已经发现主题为西班牙，意大利，法国和波兰的恶意电子邮件。

情报来源：
https://securityaffairs.co/wordpress/95505/malware/greta-thunberg-emotet-spam.html

5.公共USB充电站的危害
根据来自洛杉矶县地方检察官的警报，罪犯正在将恶意软件加载到公共USB充电站上，以在对电子设备充电时恶意访问它们。该警报描述了通过肮脏的USB端口安装的恶意软件如何锁定设备或将个人数据和密码直接导出到犯罪者。犯罪分子可以使用该信息访问在线帐户或将其出售给其他不良行为者。

情报来源：
https://www.fcc.gov/juice-jacking-dangers-public-usb-charging-stations

6.在ISO电子邮件附件传递恶意软件中看到的Uptick
分析恶意垃圾邮件活动的安全研究人员注意到，以磁盘映像文件格式分发恶意软件的情况有所增加，.ISO最为普遍。

以这种方式提供的最受欢迎的威胁包括远程访问工具（NanoCore，Remcos）和LokiBot信息窃取者。

情报来源：
https://www.bleepingcomputer.com/news/security/uptick-seen-in-iso-email-attachments-delivering-malware/

7.伪装成银监会移动端的恶意APP分析
安全研究人员发现一款伪装名为“CBRC”的APP，CBRC应该是中国银监会或银监会的英文简称（ChinaBanking Regulatory Commission），此类仿冒监管机构的APP常用于电信诈骗行业获取受害人的银行账户密码信息；经分析发现此类伪装的APP还具有一双“千里眼”，时刻监控着受害者的一举一动并能及时作出反侦查行为；同时设置了APP运行超过7天时间后，关闭服务。

情报来源：
https://mp.weixin.qq.com/s/Arhgfv5AdaPR6mdihDhbQA

3.历时两年的网上诱骗活动冒充加拿大银行
加拿大银行正在通过大规模基础设施假冒针对个人和企业的网络钓鱼活动，该网络与先前的攻击可追溯到2017年，并指向相同的攻击者。这些针对加拿大的攻击背后的基础结构包括数百个仿冒网站，旨在模仿加拿大主要银行的网站，以作为从金融机构客户那里窃取用户凭据的工作的一部分。

安全研究人员在日常样本分析中发现一新型Android木马，根据其CC特点将其命名为SlideRAT，深入分析后发现该家族木马属于蔓灵花组织。2019年11初，我们发现SlideRAT攻击中国军工行业从事人员，11月中旬，该家族样本开始攻击中国驻巴基斯坦人员。

2.巴基斯坦数十名高官手机遭黑客攻击

所有可疑的黑客入侵都利用了WhatsApp应用软件中的漏洞，该漏洞允许恶意软件的用户访问目标手机上的消息和数据。

情报来源：

3.黑客组织 APT20 在最近的攻击中被发现能绕过二步验证
该组织的主要目标是政府机构和管理服务供应商。安全研究人员称，黑客使用 web server 作为进入目标系统的最初入口点，一个利用目标是大型企业和政府机构常用的企业级应用平台 JBoss。APT20 利用漏洞访问这些 web server，安装 web shells，然后逐渐渗透进系统。之后黑客会去寻找管理员账号，以及用于从外网访问内网的 VPN 账号。

安全研究人员发现，黑客能绕过 VPN 账号使用的二步认证，他们猜测可能是黑客窃取了 RSA SecurID 软件令牌，用它去生成有效的一次性代码。

情报来源：
https://weibo.com/1699526244/Im86lwni7

4.KONNI APT组织伪装韩国Android聊天应用的攻击活动剖析
安全研究人员发现多起疑似针对韩国地区Android用户的恶意代码攻击活动。攻击者通过将恶意安卓应用伪装成韩国常用移动应用，从而诱导受害者安装使用。经关联分析，研究人员发现此次攻击活动无论从攻击手法还是木马框架都与ESTsecurity披露的KONNI Android木马一致。

情报来源：
https://mp.weixin.qq.com/s/G1Cebamao-gigq7VsskLnQ

2.Citrix曝出高危漏洞，全球158个国家8万家企业受威胁

该漏洞影响包括Citrix ADC和Citrix Gateway 13.0，12.1，12.0，11.1和10.5的所有平台。Citrix用于连接工作站和关键业务系统。Citrix已发布解决方案，推荐用户尽快更新修补。
