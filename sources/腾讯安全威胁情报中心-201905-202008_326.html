1. 新型勒索病毒chchbuy横行
安全厂商发现一新增勒索病毒家族，并将其命名为chchbuy。溯源分析发现，该勒索病毒主要通过爆破远程桌面的方式进行手动投毒，且感染一台机器后会通过端口扫描工具，在内网进行横向扩散。

3.WhatsApp Vulnerability Allows Code Execution Via Malicious MP4 File
上周在WhatsApp中公开的一个安全漏洞可能被滥用以在受影响的设备上远程执行任意代码。

当应用程序解析MP4文件的基本流元数据时，就会发生缓冲区溢出。攻击者可以针对该安全漏洞来触发拒绝服务（DoS）或远程执行代码。通过发送被编程为在打开后执行代码的MP4文件，可以利用此漏洞将恶意应用程序安装到受害者的设备上。Facebook在其通报中指出，WhatsApp的消费者和企业版本均受到影响。

情报来源：
https://www.securityweek.com/whatsapp-vulnerability-allows-code-execution-malicious-mp4-file

4.ACBackdoor: Analysis of a New Multiplatform Backdoor
ACBackdoor: 一个多平台后门的分析

ACBackdoor提供了shell命令的任意执行，二进制程序的任意执行，持久性和更新功能。

在此博客文章中，安全研究人员将解释两种ACBackdoor变体的技术分析，并强调它们在实现上的差异。调查结果强烈表明，该恶意软件背后的组织先前具有针对Linux系统的经验，并且正在通过将ACBackdoor移植到Windows来扩大其覆盖范围。

情报来源：
https://www.intezer.com/blog-acbackdoor-analysis-of-a-new-multiplatform-backdoor/

Buran Ransomware通过Microsoft Excel 附件感染PC

情报来源：

6.美国东德克萨斯州学区遭勒索病毒攻击
得克萨斯州博蒙特附近的内切斯格洛夫斯港ISD在遭受勒索软件攻击后失去了对所有计算机系统文件的访问权限，勒索软件是一种导致文件无法使用然后需要金钱来恢复访问的网络攻击。

警长迈克·冈萨雷斯（Mike Gonzales）表示，攻击者要求“巨额资金”，一些地方执法机构和网络安全专家正在努力使计算机重新启动并运行。
