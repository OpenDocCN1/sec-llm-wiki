**漏洞描述**

2019年05月15日，微软公布RDP（远程桌面服务）远程代码执行漏洞（CVE-2019-0708）补丁。攻击者利用此漏洞可远程攻击存在漏洞的电脑，攻击过程无需用户参与，各安全厂商均判断该漏洞的影响为“严重”。  

  

截止目前，腾讯安全威胁情报中心监测数据表明，仍有相当比例的Windows电脑未修复该漏洞，安全厂商判断该漏洞存在蠕虫病毒传播风险。  

  

10月23日，安全研究人员发现已有黑客利用该漏洞入侵Windows系统并安装挖矿木马。腾讯安全曾多次发布有关（CVE-2019-0708）高危漏洞的预警，并向用户提供了完善的补丁修复方案。

 

**漏洞等级 **高危，严重级

 

**影响范围**

Windows 7、WindowsServer 2008 R2、Windows Server 2008、Windows 2003、Windows XP。  

  

Windows 8和Windows10及之后版本不受此漏洞影响。

  

**修复建议**

尽管BlueKeep（CVE-2019-0708）漏洞解决方案早已公布数月之久，但根据腾讯安全御知网络资产风险监测系统（简称：腾讯御知）提供的数据，目前受该漏洞影响的服务器数量仍有数十万台之多，我们再次呼吁企业用户尽快修复漏洞。

  

建议用户尽快安装操作系统补丁。可通过Windows Update，也可通过安全软件提供的漏洞修复功能安装。

 

联机版漏洞检测工具下载地址：http://dlied6.qq.com/invc/qqpcmgr/other/rdsvulfixol\_v3.exe

 

建议企业用户通过腾讯御点的漏洞修复功能安装补丁，网管也可采用腾讯御知全面检测企业内网系统是否受该漏洞影响。
