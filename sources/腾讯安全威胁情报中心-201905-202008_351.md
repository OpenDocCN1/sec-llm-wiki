**漏洞描述**

Nginx 上fastcgi\_split\_path\_info 在处理带有 %0a 的请求时，会因为遇到换行符 \\n 导致 PATH\_INFO 为空。而 php-fpm 在处理 PATH\_INFO 为空的情况下，存在逻辑缺陷。攻击者通过精心的构造和利用，可以导致远程代码执行。 

 

**漏洞等级 **高危，严重级

 

**影响范围**

Nginx + php-fpm 的服务器，在使用如下默认配置的情况下，都可能存在远程代码执行漏洞。

*   
*   
*   
*   
*   
*   
*   

```
location~ [^/]\.php(/|$) {        fastcgi_split_path_info^(.+?\.php)(/.*)$;        fastcgi_param PATH_INFO       $fastcgi_path_info;        fastcgi_pass   php:9000;        ...  }}
```

 

**修复建议**

删除 Nginx 配置文件中的如下配置：  

*   
*   

```
fastcgi_split_path_info ^(.+?\.php)(/.*)$;fastcgi_paramPATH_INFO       $fastcgi_path_info;
```
