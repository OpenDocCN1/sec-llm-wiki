2.Winnti Group’s skip 2.0: A Microsoft SQL Server backdoor
臭名昭著的网络间谍组织Winnti Group破坏了MSSQL

研究人员有一段时间以来一直在追踪Winnti Group的活动，该组织至少从2012年开始活跃，并负责针对视频游戏和软件行业的高知名度的供应链攻击。研究人员最近发现该组织有针对Microsoft SQL（MSSQL）未公开的后门程序，使攻击者能够入侵受到威胁的组织。该后门与WinReti  使用的另一种工具PortReuse后门有很多相似之处。

情报来源：
https://blog.eset.ie/2019/10/21/winnti-groups-skip‑2-0-a-microsoft-sql-server-backdoor/

4. Hackers Breach Avast Antivirus Network Through Insecure VPN Profile
黑客通过不安全的VPN配置文件破坏了Avast防病毒网络，黑客访问了捷克网络安全公司Avast的内部网络，可能旨在针对CCleaner进行供应链攻击。自9月25日检测到入侵以来，从5月14日开始进行入侵尝试。经过调查，防病毒制造商确定攻击者能够通过临时VPN帐户使用受感染的凭据来获得访问权限。

情报来源：
https://www.bleepingcomputer.com/news/security/hackers-breach-avast-antivirus-network-through-insecure-vpn-profile/
