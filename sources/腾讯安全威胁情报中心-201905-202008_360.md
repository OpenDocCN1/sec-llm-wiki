**2\. 一种虚假“短信通道商”黑产活动的揭露**  
安全研究人员发现了一种黑产基于僵尸网络的新型变现方式，该变现方式实现了黑客宣称的“能发送任意内容的营销短信“。黑客通过用户手机构建的僵尸网络，冒充“短信通道商”向广告主骗取短信营销费用，用户手机被控制，手机会在黑客的控制下，读取远程虚假短信内容，插入到短信收件箱，导致手机莫名奇妙收到很多“广告短信”的现象。  
  
**情报来源：**  
https://mp.weixin.qq.com/s/Vlv2MqI\_YG63KkLTg0zmjg  
  
**3\. 知名游戏成劫持木马新宿主**  
安全研究人员监测到有游戏下载网站打着《怪物猎人:世界》等多款知名游戏旗号进行传播劫持木马。经分析，该木马具备劫持浏览器主页及默认搜索页、获取浏览器历史记录、篡改浏览器收藏夹、添加浏览器扩展、修改浏览器Cookie等恶意行为。  

  

经过溯源发现：木马传播者对《孤岛惊魂5》、《怪物猎人：世界》、《极品飞车20》、《鬼泣5》、《边缘世界》等知名游戏进行二次打包并加入木马程序，然后通过游虎游戏网(hxxp://dj.dianjinghu.com)进行传播。  
  
**情报来源：**  
http://www.360.cn/n/11189.html  
  
**4\. Iranian Hackers Create Credible Phishing to Steal Library Access**  
伊朗黑客创建可信网络钓鱼来窃取信息

**情报来源：**  
https://www.bleepingcomputer.com/news/security/iranian-hackers-create-credible-phishing-to-steal-library-access/  
  
**5\. GootKit Malware Bypasses Windows Defender by Setting Path Exclusions**  
GootKit恶意软件通过设置路径排除来绕过Windows Defender  
  
随着Windows Defender的日趋成熟并紧密集成到Windows 10中，恶意软件编写者正在创建逃避其检测的技术。GootKit银行木马就是这种情况，该木马使用UAC旁路和WMIC命令将恶意软件可执行文件排除在Windows Defender Antivirus的扫描范围之外。  
  
GootKit是一个银行木马，它试图通过视频捕获来窃取受感染用户的在线银行凭据，并在攻击者的控制下重定向到伪造的银行站点。这种感染的一个有趣的方面是它是一个打包为可执行文件的Node JS应用程序。  
  
**情报来源：**  
https://www.bleepingcomputer.com/news/security/gootkit-malware-bypasses-windows-defender-by-setting-path-exclusions/

**7.CVE-2019-14287 sudo 配置不当-权限提升漏洞预警**  
sudo 官方在发布了 CVE-2019-14287 的漏洞预警。sudo 是所有 unix操作系统(BSD, MacOS, GNU/Linux) 基本集成的一个用户权限控制/切换程序。允许管理员控制服务器下用户能够切换的用户权限。  
  
CVE-2019-14287 是管理员在配置文件中用了 ALL 关键词后造成的。但默认的 sudo 配置文件不受影响。  
  
**情报来源：**  
https://cert.360.cn/warning/detail?id=52e5a71e0f1ffb1f50724344a7ef9998  
  
**8\. Threat Actor Profile: TA407, the Silent Librarian**  
沉默的图书管理员TA407  
  
像许多教育网络钓鱼攻击一样，与TA407相关的活动通常不是针对地理区域的，而是与特定的大学绑定的，网络钓鱼登陆页面是为图书馆和学生或教职员工访问门户开发的。尽管许多攻击都是针对美国的学校，但Proofpoint研究人员经常观察到主要影响北美和欧洲大学。  
  
2018年初，美国司法部起诉网络犯罪组织的9名成员涉嫌黑客攻击，电汇欺诈和身份盗窃。特别值得一提的是，该小组的原因是“获得对计算机系统的未经授权的访问，从这些系统中窃取专有数据，并将窃取的数据出售给包括伊朗政府和伊朗大学在内的伊朗客户。”  
  
**情报来源：**  
https://www.proofpoint.com/us/threat-insight/post/threat-actor-profile-ta407-silent-librarian
