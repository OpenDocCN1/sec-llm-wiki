1. 一个Stealth Falcon group组织使用的后门木马，该木马未被公开

隐形猎鹰是一个威胁组织，自2012年以来一直活跃，针对中东的政治活动家和记者。它是由一个专注于安全和人权的非营利组织公民实验室跟踪的，该组织在2016年公布了对特定网络攻击的分析。路透社于2019年1月发布了一份关于 Project Raven 的调查报告。前美国国家安全局的工作人员，目标是与隐形猎鹰相同类型的目标。

根据这两份涉及相同目标和攻击的报告，高级技术专家Claudio Guarnieri得出的结论是，Stealth Falcon和Project Raven实际上属于同一组。

情报来源：
https://www.welivesecurity.com/2019/09/09/backdoor-stealth-falcon-group/

美国网络司令部（USCYBERCOM）本周向VirusTotal发布了11个恶意软件样本，所有这些样本都与朝鲜APT组织Lazarus有关。

3. 一起通过钓鱼攻击，窃取用户PayPal信用卡信息的事件Heatstroke
该钓鱼攻击对其潜在受害者进行研究的方式值得注意。他们的目标是受害者的私人电子邮件地址，他们最有可能从受害者自己的地址列表中收集，其中还包括技术行业的经理和员工。

私人电子邮件地址更可能托管在免费电子邮件服务上，安全性和垃圾邮件过滤不严。它们通常还用作社交媒体和电子商务网站的验证，以及Gmail和企业帐户的备份。Gmail帐户特别有趣; 获取这些帐户访问权限的攻击者也可以访问受害者的Google云端硬盘，并且在某些情况下，可能会危及与该帐户关联的Android设备。

情报来源：
https://blog.trendmicro.com/trendlabs-security-intelligence/heatstroke-campaign-uses-multistage-phishing-attack-to-steal-paypal-and-credit-card-information

4. 恶意软件沙箱逃避策略的演变
恶意软件规避技术被广泛用于规避检测以及分析和理解。逃避的主要类别之一是反沙箱检测，仅仅是因为今天的沙箱正在成为概述威胁的最快和最简单的方法。许多公司使用这些类型的系统来引爆发现的恶意文件和URL，以获得更多的妥协指标，以扩展其防御并阻止其他相关的恶意活动。

情报来源：
https://securingtomorrow.mcafee.com/other-blogs/mcafee-labs/evolution-of-malware-sandbox-evasion-tactics-a-retrospective-study

5. Exploit Kits Target Windows Users with Ransomware and Trojans
四个不同的恶意广告活动已经将用户重定向到安装密码窃取特洛伊木马，勒索软件和剪贴板劫持者的漏洞利用工具包。所有这四个活动都是由漏洞利用工具包专家nao_sec发现的， 并通过恶意广告进行分发，将访问者重定向到漏洞利用工具包登陆页面。这些目标网页通常托管在被黑网站上。

用户访问该站点后，该工具包的脚本将尝试利用访问者浏览器中的漏洞，在用户不知情的情况下自动下载和安装恶意软件。

情报来源：
https://www.bleepingcomputer.com/news/security/exploit-kits-target-windows-users-with-ransomware-and-trojans/

7. Exim 远程代码执行漏洞（CVE-2019-15846）预警通告
Linux的邮件传输代理Exim被曝出存在一个远程代码执行漏洞（CVE-2019-15846）。当受影响版本的Exim服务器接受TLS连接时，可能会受此漏洞影响，导致被远程未经身份验证的攻击者以root权限执行任意代码。
