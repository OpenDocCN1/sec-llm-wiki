今天值得关注的威胁情报：

  

**1.Aspose Aspose.Cells 19.1.0版本中存在缓冲区错误漏洞(CVE-2019-5032)**  
Aspose Aspose.Cells 19.1.0库的LabelSst记录解析器中存在可利用的越界读取漏洞。特制的XLS文件可能导致越界读取，从而导致远程代码执行。攻击者需要向受害者提供格式错误的文件以触发漏洞。  
  
**情报来源：**  
https://www.talosintelligence.com/vulnerability\_reports/TALOS-2019-0794  
  
**2.Cisco Warns of Public Exploit Code for Critical Switch Flaws**  
思科更新了8月初修补的三个漏洞的安全建议，在影响思科小型企业220系列智能交换机的三个缺陷中，有两个是关键的远程代码执行（CVE-2019-1913）和身份验证绕过安全性（CVE-2019-1912）问题。  
  
未经身份验证的远程攻击者可以利用它们分别以root权限执行任意代码并上传任意文件。  
  
**情报来源：**  
https://www.bleepingcomputer.com/news/security/cisco-warns-of-public-exploit-code-for-critical-switch-flaws/  
  
**3.勒索软件攻击了22个德克萨斯城镇**  
休斯顿当局表示，德克萨斯州22个小城镇的计算机系统遭到勒索病毒攻击。官方发言人拒绝提供进一步的细节或公布受影响城镇的名称，因为“可能会有进一步的攻击”。  
  
**情报来源：**  
https://t.co/ULN77bAweC?amp=1  
  
**4.Valve修补了 Steam 的一个本地提权零日漏洞**  
Valve 刚刚修补了 Steam 的一个零日漏洞，但为了避免类似的事情再次发生，该公司还同步更新了 bug 赏金规则。该漏洞与本地特权提升（LPE）相关。  
  
**情报来源：**  
https://weibo.com/1699526244/I3x4c3ppX
