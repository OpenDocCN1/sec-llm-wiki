今天值得关注的威胁情报：

1、黑客利用虚假谷歌域名托管Magecart窃取脚本
研究人员联系了一位Magento网站所有者，该网站所有者已被列入黑名单并且正在体验McAfee SiteAdvisor“危险网站”警告。调查显示，该网站感染了一个信用卡收集器，其中包含来自恶意国际化域 google-analytîcs[。] com（或ASCII中的xn-google-analytcs-xpb [。] com）的JavaScript。

情报来源：
https://blog.sucuri.net/2019/07/fake-google-domains-used-in-evasive-magento-skimmer.html

2.安全研究人员发现新的Android勒索软件Android/Filecoder
在Android勒索软件遭遇两年的衰退之后，安全研究人员发现名为Android / Filecoder.C的勒索软件通过各种在线论坛分发。使用受害者的联系人列表，它通过带有恶意链接的短信进一步传播。

情报来源：
https://www.welivesecurity.com/2019/07/29/android-ransomware-back/

3.VxWorks RTOS存在漏洞，约20亿设备受影响
安全研究人员在VxWorks中发现了近十二个零日漏洞，VxWorks是嵌入式设备中使用最广泛的实时操作系统（RTOS）之一，为航空航天，国防，工业，医疗，汽车，消费电子等领域的20多亿台设备供电，网络和其他关键行业。

情报来源：
https://thehackernews.com/2019/07/vxworks-rtos-vulnerability.html

4. Java ATM Malware: The Insider Threat Phantom
安全研究人员注意到一个真正特别的恶意软件样本，这个样本很可能与最近针对银行业的网络犯罪行为有关。这个恶意代码就是所谓的“ATM恶意软件 ”：恶意工具的一部分，可以与自动柜员机进行交互。ATM恶意软件用于现代银行抢劫，因为它们能够访问自动提款机硬件。

情报来源：
https://blog.yoroi.company/research/java-amt-malware-the-insider-threat-phantom/
