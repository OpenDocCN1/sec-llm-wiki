# 成功经受住实战化演练考验 腾讯安全SOC+获重保单位认可

腾讯安全重保支持专家团队

腾讯安全 企业安全运营团队

  

10月下旬，某重保单位网络安全攻防演练活动闭幕。腾讯安全重保支持专家团队协助该单位的信息安全团队，以实战化的战绩，检验了SOC+安全运营体系的有效性，持续提升了SOC+安全运营体系实战化水平，并获得客户认可。  
  
本次攻防演练是覆盖该系统全领域的特大规模实网攻防演练，为确保演练始终围绕实战，以及全方位保障实际工作，督促形成更高效精准的数据安全防护解决机制，活动主管单位还将多个公共服务领域信息系统纳入演练范围。实际上，演练范围的扩大对参与演练的安全技术产品、安全专家服务团队提出了更高的要求。  
  
腾讯安全重保支持专家团队与重保单位成立联合运营团队，在项目建设中，采用了腾讯安全运营中心（SOC）、腾讯高级威胁检测系统、腾讯天幕安全算力算法PaaS、腾讯安全威胁情报、安全服务于一体的技术解决方案。将全网其他安全产品（覆盖各节点的EDR、NDR类安全产品，包括第三方厂商提供的Web应用防火墙、HIDS等等产品）的告警数据集中接入腾讯安全运营中心（SOC），构建了以资产为核心，以威胁情报为驱动，以安全事件统一管理为关键流程的安全运营体系。  

![](../Images/12f7aa53e32e7ff93d99121578a8ed75.png)

   
由腾讯安全运营中心作为整体安全演练的统一指挥平台，打通威胁告警接入、告警数据分析、威胁响应与处置等一系列安全运营任务，调度全网终端EDR节点、流量侧NDR节点，实现全局威胁检测、分析研判溯源、威胁通告预警、威胁响应处置等关键环节的闭环管理。  
   
联合运营团队根据业务分工，划分为综合协调组、监控预警组、分析判断组、风险通告组、应用响应组。联合运营团队根据腾讯安全运营中心（SOC）输出的事件告警数据，对具体的威胁事件进行响应、分析和处置。  

![](../Images/db8cd71e8693ac33bc18149b171d6af8.png)

  
通过实战演练，联合运营团队发现并向主管单位报告防守薄弱节点，并分析防护体系中存在的风险点，对存在风险的网络资产提出整改加固方案。演练期间，腾讯安全重保支持专家团队基于威胁情报的网络安全态势实况，及时有效梳理和优化攻防场景的检测规则、安全策略上百条，持续保障了安全防护运营体系的有效性。  
  
在安全演练过程中，基于腾讯安全运营中心（SOC）发现了万条威胁告警信息，其中通过SOAR自动化分析产生数千个威胁事件，联合运营团队响应并处置数百个事件工单，提交数十份高风险事件报告。通过贴近实战的安全演练，持续不断提升重保单位业务、数据、服务系统的整体安全防护能力，使人民群众享有便捷公共服务的同时，更有效保障数据安全。

**关于腾讯安全威胁情报中心**

  

腾讯安全威胁情报中心是一个涵盖全球多维数据的情报分析、威胁预警分析平台。依托顶尖安全专家团队支撑，帮助安全分析人员、安全运维人员快速、准确地对可疑威胁事件进行预警、处置和溯源分析。
