# 腾讯云主机安全有效拦截趋势科技披露的linux挖矿木马家族

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247499423&idx=1&sn=5420f50a6a3945847a4472ccfe72102d&chksm=ec9f27ecdbe8aefaf657499a64e1b392e6363fe5d54a5d775dcadb3633ef73ef7c1f5939ca29&scene=126&sessionid=1681278314#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247499423&idx=1&sn=5420f50a6a3945847a4472ccfe72102d&chksm=ec9f27ecdbe8aefaf657499a64e1b392e6363fe5d54a5d775dcadb3633ef73ef7c1f5939ca29&scene=126&sessionid=1681278314#rd)

本周，知名安全厂商趋势科技披露了一个针对中国某公有云服务商进行攻击的linux挖矿木马家族，研究人员称，该挖矿木马仅针对云环境，木马会删除其他竞品挖矿木马，并同时删除其他入侵者创建的用户。腾讯安全根据相关报道查明，该挖矿木马家族早在今年8月即被腾讯主机安全产品截获，被攻击的云主机数量仅几十个，整体影响较小。因攻击事件涉及中国某著名品牌，该事件在外网倍受关注。  

![](../Images/2f164ac3295015ff647e813e288d7ae6.png)

图片来源：趋势科技（https://www.bleepingcomputer.com/news/security/huawei-cloud-targeted-by-updated-cryptomining-malware/）  
   
攻击者会利用多个高危漏洞和弱口令爆破攻击入侵，包括：

*   SSH 弱口令爆破  
    
*   Oracle WebLogic Server 漏洞 (CVE-2020-14882)  
    
*   Redis 未授权访问漏洞或弱口令爆破  
    
*   PostgreSQL未授权访问漏洞或弱口令爆破  
    
*   SQLServer 弱口令爆破  
    
*   MongoDB 未授权访问漏洞或弱口令爆破  
    
*   FTP弱口令爆破
    

  

攻击成功后会在失陷主机添加SSH密钥留置后门方便登录，同时会添加具备root权限的管理员帐户以完全控制失陷系统。为避免被检测到，攻击者通过安装Tor代理服务，加密相关网络流量以实现匿名化。  
   
腾讯安全根据相关新闻提供的线索查明，该挖矿木马最早的攻击记录是2021年8月2日，累计被攻击的云主机数十个，均被**腾讯主机安全（云镜）**成功防御。腾讯主机安全已全面集成BinaryAI引擎，该引擎为腾讯安全科恩实验室联合腾讯安全威胁情报团队基于人工智能（AI）方法推出的全新挖矿木马检测解决方案，可大幅提升已知或未知挖矿木马检测率，该引擎已申请多项专利。  

![](../Images/2ec73feb9e67fe90d7632e6c8ff83760.png)

  
腾讯安全专家建议主机安全专业版客户开启“恶意文件自动隔离”功能，只须登录主机安全控制台，依次浏览到入侵检测->文件查杀-查杀设置，开启自动隔离，同时勾选“隔离并杀掉恶意文件相关进程”。
