**一、概述**

  
腾讯安全威胁情报中心检测到，一个新的挖矿木马正在快速传播。该挖矿木马具备蠕虫化攻击扩散能力，攻击成功后投递的最终载荷名为ntpclient，其主要目的为感染主机挖矿牟利，腾讯安全因此将其命名为NTP挖矿蠕虫。该挖矿木马在蠕虫化传播扩散过程中利用了至少12种高危漏洞攻击武器。  
  
根据腾讯安全云原生预警系统的检测数据，已观察到较多未安装任何防护系统的主机被入侵感染。我们建议企业安全运维人员提高警惕，积极修复安全漏洞，部署主机防护软件以应对NTP挖矿蠕虫的攻击，已部署腾讯云防火墙的主机可成功防御相关漏洞攻击。  

![](../Images/7c26a4420f3aefce44ab409f53b6a715.png)

腾讯安全云原生预警系统，是通过在公有云网络中部署大量流量探针、蜜罐系统，引诱捕捉攻击者对其进行扫描探测、入侵渗透、感染破坏等攻击活动，从而掌握攻击者的技术特点，再根据其攻击特点去精确判断全网受影响的情况，对所有受影响的主机进行威胁告警触达，指导受影响的客户采取必要措施进行威胁防护和处置。  

**二、腾讯安全解决方案  
**

  

攻击者所使用的NTP挖矿蠕虫木马相关威胁数据已加入**腾讯安全威胁情报**数据库，赋能给腾讯全系列安全产品，客户可以通过订阅腾讯安全威胁情报产品，让全网安全设备同步具备相应的威胁检测、防御、阻断能力。推荐政企客户在公有云中部署腾讯云防火墙、腾讯主机安全（云镜）、腾讯web应用防火墙等安全产品检测防御相关威胁。  
  
**腾讯主机安全（云镜）**可对攻击过程中产生得NTP挖矿木马落地文件进行自动检测，客户可登录腾讯云->主机安全控制台，检查病毒木马告警信息，将恶意木马文件一键隔离或删除。客户可通过腾讯主机安全的漏洞管理、基线管理功能对企业网络资产进行全面的安全漏洞和弱口令检测。  

![](../Images/3825fd3d9350405bd16e7aa21277b27b.png)

  

**腾讯云防火墙**支持对NTP挖矿蠕虫木马利用的多个漏洞攻击武器进行阻断拦截，腾讯云防火墙内置虚拟补丁防御机制，可积极防御某些高危且使用率很高的漏洞利用。下图为腾讯云防火墙拦截Mongo-express远程代码执行漏洞（CVE-2019-10758）的攻击利用。

![](../Images/df09dd78e103be7255c1859702c5f4fb.png)

  
私有云客户可通过旁路部署**腾讯高级威胁检测系统（NTA、御界）**进行流量检测分析，及时发现黑客团伙利用漏洞对企业私有云的攻击活动。腾讯高级威胁检测系统（御界）对NTP挖矿蠕虫木马利用的多个漏洞攻击武器进行检测告警。下图为腾讯御界检测到利用Mongo-express远程代码执行漏洞（CVE-2019-10758）发起的恶意攻击行为。  

![](../Images/b42dc6dd537175b25c508e1c88a94e64.png)

  

政企客户可通过旁路部署**腾讯天幕（NIPS）**实时拦截NTP挖矿蠕虫木马所利用的恶意网络连接，彻底封堵攻击流量。腾讯天幕（NIPS）基于腾讯自研安全算力算法PaaS优势，形成具备万亿级海量样本、毫秒级响应、自动智能、安全可视化等能力的网络边界协同防护体系。

**三、详细分析**

  
腾讯云防火墙检测到攻击者利用多个漏洞攻击云主机，例如：  
  
1.利用Drupal远程代码执行漏洞(CVE-2018-7600)攻击云主机。  

![](../Images/67fe13275348ec5ea03fce1a96c77b49.png)

  
2.利用mongo-express远程代码执行漏洞（CVE-2019-10758）攻击云主机  

![](../Images/8d76d917e052d31074b6f0ff8e8796ff.png)

  
3.利用Confluence未授权模板注入/代码执行(CVE-2019-3396)攻击云主机  

![](../Images/3da3ec5dc48de39b092488817587e545.png)

  
如果上述漏洞攻击成功，就会植入恶意脚本：  
脚本的主要功能为清理资源高占用进程，同时植入不同x86或x86\_64架构名为ntpclient的木马。  

![](../Images/2390de57c58c4a73a1ccb23b3c810252.png)

  
ntpclient文件已加壳保护以免自身被分析。  

![](../Images/10f5a4daba3dca59063ca76d71d26817.png)

  

ntpclient模块功能丰富，首先会创建多个随机名进程。分别执行蠕虫扩散功能和门罗币（XMR）挖矿功能。  
  
蠕虫功能会随机扫描多个应用组件暴露在互联网的端口，并尝试执行相关漏洞攻击利用，经分析，NTP挖矿蠕虫至少使用了12种热门流行漏洞攻击武器，包括：

*   Drupal远程代码执行漏洞 （CVE-2018-7600）  
    
*   Zeroshell 操作系统命令注入漏洞（CVE-2019-12725）  
    
*   Weblogic 组合漏洞攻击（CVE-2020-14882 &CVE-2020-14883）  
    
*   Confluence未授权模板注入/代码执行 （CVE-2019-3396）  
    
*   mongo-express 远程代码执行漏洞（CVE-2019-10758）  
    
*   Supervisord远程命令执行漏洞（CVE-2017-11610）  
    
*   XXL-Job未授权命令执行  
    
*   Hadoop Yarn REST API未授权命令执行漏洞  
    
*   Redis未授权写计划任务攻击  
    
*   Visual Tools DVR VX16 4.2.28.0 - OS 命令执行漏洞  
    
*   InoERP 0.7.2 - Remote Code Execution  
    
*   Klog Server 2.4.1 - 命令注入漏洞

经过分析观察，推测NTP挖矿蠕虫正在快速版本迭代中，从腾讯安全云原生预警数据看，NTP挖矿蠕虫疑似还会利用SSH服务（弱口令）攻击和SaltStack（CVE-2020-16846）漏洞攻击。  
  
当前版本看，其主要目的是攻击成功后控制云主机进行门罗币（XMR）挖矿，被攻击主机会产生随机进程，主机CPU资源被大量占用。  

![](../Images/0e90688369d130be95405f7d5e8ede49.png)

  

腾讯安全仍在密切关注该挖矿蠕虫的进一步活动。
