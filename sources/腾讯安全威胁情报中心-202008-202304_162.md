2021年8月11日，微软发布RDP Client 远程代码执行漏洞（CVE-2021-34535）风险通告，该漏洞发布补丁修复，腾讯安全专家建议Windows用户尽快升级安装。  

  

## 1**漏洞描述  
**

  
  
  
  
  

Windows官方客户端软件为Remote Desktop Connection（远程桌面连接），早期被称之为Terminal Services Client，对应的文件名一直是mstsc.exe。  
  
攻击者可以诱使受害者使用Windows自带的RDP客户端访问其服务器，并从服务器发送特殊的数据包触发客户端漏洞，该漏洞允许攻击者在RDP客户端系统中执行任意代码。  
  
Remote Desktop Protocol(RDP)是微软开发的一个可在图形化界面上连接远程主机的应用协议。  

  

## 2**漏洞编号  
**

  

CVE-2021-34535

  

## 3**漏洞等级**

  
  

**高危，CVSS评分8.8**

  

## 4**受影响的版本**

  

Windows 10 Version 1607/1809/1909/2004/20H2/21H1  
Windows 7 for 32/64-bit Systems Service Pack 1  
Windows Server 2008/2012/2016/2019  
Windows 8.1 for 32/64-bit systems  
Windows RT 8.1

  

## 5**补丁分析**

  

Multimedia Redirection（多媒体重定向）也叫做Video Redirection（视频重定向），是将同步的audio和video数据从server端传输到client端。本次漏洞出现在RDP client端对tsmf通道数据处理中。  
  

Client没有检查直接使用了Server发送的Sample数据，造成了uiNodeSize和uiSampleSize整形溢出漏洞，微软在本月安全补丁中更新了对uiNodeSize和uiSampleSize的相关安全检查：

![](../Images/dfd06c5c5188560f7c2eba58d9170ee0.png)

  

## 6**漏洞修复方案  
**

  

微软官方已发布针对CVE-2021-34535漏洞的安全补丁，腾讯安全专家建议用户尽快升级修复。个人用户推荐使用腾讯电脑管家和Windows更新，政企用户推荐使用腾讯零信任iOA的漏洞修复功能或Windows更新，政企机构运维人员全面部署安全补丁前，建议充分测试。
