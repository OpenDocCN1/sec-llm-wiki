威胁态势分析

3月份活跃的恶意木马家族呈明显上升趋势：


活跃病毒木马家族影响的地区分布如下图所示，深色部分为受病毒木马影响严重的区域。

最活跃的恶意病毒家族排行榜Top10：

十大恶意病毒家族中，Sality排第一位。Sality是指感染可执行文件的旧的大型病毒家族，最早出现于2003年。多年来，恶意软件已添加更多功能，以使其保持活动状态。新的Sality变体还可以充当后门，将受感染的计算机连接到僵尸网络。

排第2位的Mirai是恶名昭著的僵尸网络，主要影响物联网（IoT，Internet-Of-Things）设备，包括路由器、网络摄像头等，Mirai僵尸网络以这些设备作为节点发起大规模的DDoS攻击。

第4位XRed病毒是具备远程控制、信息窃取能力的感染型病毒，可以感染本地EXE文件及xlsx电子表格文件，病毒可通过文件分享和U盘、移动硬盘等媒介传播。

其他恶意病毒家族均与挖矿活动有关。

2021年3月勒索病毒感染情况

3月份勒索病毒攻击整体略降，月末又有所上升。本月内GlobeImposter，Crysis(Phobos)，Sodinokibi等勒索家族依然活跃。


新型勒索病毒yourdata勒索病毒对国内部分企业造成打击，该病毒由于加密文件后会留下名为yourdata@RecoveryGroup.at而得名，该勒索病毒主要通过爆破攻击方式传播。

3月份腾讯安全威胁情报中心发现有名为obloy的攻击者，使用组合工具包传播Medusalocker与GlobeImposter两种勒索病毒，工具包内包括数十款密码窃取工具，系统环境对抗工具，扫描探测工具，端口服务爆破工具等。由于Medusalocker与GlobeImposter当前均无免费解密渠道，如若被两款病毒同时加密，灾后恢复工作将困难重重。

2021年3月挖矿木马感染情况

3月份挖矿木马活跃情况有明显上升，这种趋势和虚拟币市场高涨密不可分。攻击者利用各种漏洞入侵企业云服务器，植入挖矿木马获利。

3月上旬，Sysrv-hello僵尸网络最新版新增5种攻击能力，Sysrv-hello僵尸网络攻击目标同时覆盖Linux和Windows操作系统，最终利用失陷主机挖矿，会大量消耗主机CPU资源，严重影响主机正常服务运行，该僵尸网络还会利用已失陷主机继续扫描攻击其他目标。GuardMiner挖矿木马团伙新的攻击活动，该团伙利用Elasticsearch远程代码执行漏洞（CVE-2015-1427）等9种漏洞武器针对云上主机发起攻击。根据检测数据推算，受害主机已过万台。

3月下旬，腾讯安全威胁情报中心捕获一起快速增长的挖矿木马NicoMiner，该木马通过Hadoop Yarn未授权访问漏洞、PostgreSQL未授权及提权代码执行漏洞（CVE-2019-9193）进行入侵攻击，会根据操作系统不同分别植入Windows和Linux平台的门罗币挖矿木马。Muhstik僵尸网络新变种利用Kubernetes kubelet API未授权访问漏洞和Docker Remote API未授权访问漏洞攻击云服务器，利用漏洞攻击得手之后，Muhstik会安装IRC后门对失陷系统进行远程控制。随后可下发任意命令执行，包括下载安装挖矿模块、执行DDoS攻击等。

(一) 企业安全威胁情报

1. Sysrv-hello僵尸网络新增5种攻击能力

https://mp.weixin.qq.com/s/p7s6aqxyznfZUQOnJavXsA
 
Sysrv-hello僵尸网络于2020年12月首次披露，腾讯安全曾在今年1月发现该团伙使用Weblogic远程代码执行漏洞（CVE-2020-14882）攻击传播，本月该团伙再次升级攻击手法：新增5种攻击武器，已观察到失陷主机数量呈上升趋势。
 
Sysrv-hello僵尸网络攻击目标同时覆盖Linux和Windows操作系统，最终利用失陷主机挖矿，会大量消耗主机CPU资源，严重影响主机正常服务运行，该僵尸网络还会利用已失陷主机继续扫描攻击其他目标。
 
仅仅一周之后，Sysrv-hello僵尸网络又多了14种漏洞武器。从当前捕获到的病毒版本来看，该僵尸网络蠕虫模块攻击方式由之前以爆破攻击为主、漏洞利用为辅转变为：更加依赖漏洞攻击。
 
新变种在极短时间内向蠕虫传播模块集成了14种新漏洞攻击方式，Sysrv-hello僵尸网络最早被安全厂商关注到的时间为2020年12月，该团伙对新漏洞武器的采用速度较快，已是目前技术更新最为频繁的僵尸网络之一，被其攻陷的主机系统有数万台之多。
 
腾讯安全全系列产品已支持对Sysrv-hello僵尸网络最新变种利用的14种漏洞武器进行检测和防御，包括：
1) Hadoop未授权漏洞利用
2) XXLjob未授权漏洞利用
3) Thinkphp 命令执行漏洞
4) Supervisord 命令执行漏洞（CVE-2017-11610）
5) Joomla 反序列化漏洞（CVE-2015-8562）
6) Phpunit 远程代码执行漏洞（CVE-2017-9841）
7) Apache Unomi远程代码执行漏洞 (CVE-2020-13942)
8) SaltStack 命令注入漏洞（CVE-2020-16846）

2. Immunity Canvas“军工级”武器库泄露，大幅降低攻击门槛，企业宜早做防范
https://mp.weixin.qq.com/s/F4SFUmOgtlXD1dCDPypbAw
 
2021年3月2日，有国外安全研究人员在社交媒体称，Immunity Canvas 7.26工具的源码遭到泄露，里面包含959个漏洞利用工具（已做排重处理）。值得注意的是，2018年公开的英特尔"幽灵"漏洞的利用工具也在泄露的武器库中。
 
腾讯安全团队对已泄露的工具包做了简单分析，判断这是个功能完整的红队工具包。本次泄露包括该工具的源码，可以直接在windows和linux直接安装。其中老漏洞比较多，新漏洞比较少，从有CVE标示的漏洞插件来看，2019年和2020的漏洞占比<5%，暂时未发现本次泄露的武器库中存在0day漏洞。
 
腾讯安全专家建议用户对正在运行的业务进行安全检查，及时扫描修复包括个人电脑 、企业服务器在内的各种安全漏洞，降低黑客入侵风险。
 
3. Ks3-Miner团伙利用Nexus 2 yum插件漏洞（CVE-2019-5475）攻击云主机
https://s.tencent.com/research/report/1264.html
 
腾讯安全威胁情报中心检测到Ks3-Miner挖矿木马团伙的攻击活动，该团伙利用Nexus 2 yum插件远程命令执行漏洞（CVE-2019-5475）对云上主机发起攻击。Ks3-Miner挖矿木马家族最早出现于2020年6月，早期依靠暴力破解ssh服务攻击传播。该团伙除通过挖矿牟利外，还会在系统预留后门登录配置项。

4. GuardMiner利用9种手法攻击传播
https://mp.weixin.qq.com/s/JkCGWq38g3EgUq9kqWW4MA
 
腾讯安全威胁情报中心检测到GuardMiner挖矿木马团伙新的攻击活动，该团伙利用Elasticsearch远程代码执行漏洞（CVE-2015-1427）等9种漏洞武器针对云上主机发起攻击。根据检测数据推算，受害主机已过万台，该挖矿木马会卸载云主机安装的安全软件。腾讯安全专家建议企业安全运维人员积极修复服务器组件漏洞，避免使用弱口令，防止云主机被该团伙使用的漏洞武器攻陷。
 
GuardMiner最早出现于2019年，至今已活跃超过2年，该挖矿木马通过Go语言编写的二进制程序针对Windows平台和Linux平台进行攻击传播，通过crontab定时任务以及安装SSH公钥后门进行持久化控制，并且还会利用比特币的交易记录来动态更新C2地址。

5. 新型Ryuk勒索软件变种具备自我传播能力
https://www.freebuf.com/news/264591.html
 
法国安全专家近日发现一种新型 Ryuk 勒索软件变种，该变种增加了蠕虫的功能，可以在本地网络中传播。研究报告显示：“除常见的功能外，新版本的 Ryuk 勒索软件增加了在本地网络上蠕虫式传播的功能”，“通过计划任务、恶意软件在 Windows 域内的机器间传播。一旦启动，该恶意软件将在 Windows RPC 可达的每台计算机上传播”。

6.黑灰产工具作者终走向木马开发（新挖矿木马NicoMiner）
https://mp.weixin.qq.com/s/qDbk0C1wrUprU8t_BmkgYQ
 
腾讯安全威胁情报中心捕获一起快速增长的挖矿木马NicoMiner，该木马通过Hadoop Yarn未授权访问漏洞、PostgreSQL未授权及提权代码执行漏洞（CVE-2019-9193）进行入侵攻击，会根据操作系统不同分别植入Windows和Linux平台的门罗币挖矿木马。
 
由于攻击者使用的域名和样本PDB信息中包含“nico jiang”的ID信息，腾讯安全威胁情报中心将该挖矿木马命名为NicoMiner。根据该挖矿木马使用的钱包算力推算，该木马在近一个月内感染量已翻倍，估计受害服务器已达3000台左右。

7. 多款商业木马正通过钓鱼邮件传播
https://mp.weixin.qq.com/s/h8F_v4isUTcxY_i_0Uz08w

商业木马主要由钓鱼邮件进行传播，邮件内容通常为热点话题或人们感兴趣的内容，邮件附件通常为带有恶意宏代码的office文档文件或漏洞利用的文档文件。邮件附件被受害者执行之后，通常会层层解密从攻击者的服务器下载后续，最终加载执行木马主体文件，实现对用户设备的远程控制或信息窃取。
 
8. 罗马尼亚黑客对企业云服务器的攻击

1. 网络诈骗之贷款类诈骗研究报告

https://www.anquanke.com/post/id/233448
 
揭露网络诈骗中的贷款类诈骗App，报告对贷款类诈骗app的特性做了分析。

贷款类App的基本套路，首先诈骗人员会发送诈骗短信到用户手机上，同时也会仿冒官方客服在微信、QQ等社交软件进行传播，欺骗受害者通过骗子提供的链接下载安装软件，再表单中提交贷款信息，会立即生成订单，之后会提示银行卡错误，然后以工本费、解冻费等名义进行诈骗。

2. Clast82恶意软件通过谷歌Play商店分发
https://thehackernews.com/2021/03/9-android-apps-on-google-play-caught.html
 
网络安全研究人员发现，通过Google Play商店分发的多达9个Android应用程序中都包含一个新的恶意软件，该恶意软件能够侵入受害者的财务帐户并对其设备进行完全控制。研究人员表示，这个称为Clast82的恶意软件利用了一系列技术来避免被Google Play保护检测所检测到。
 
该活动使用的应用程序包括Cake VPN，Pacific VPN，eVPN，BeatPlayer，QR /条形码扫描仪MAX，音乐播放器，tooltipnatorlibrary和QRecorder。

3. chm文档暗藏远控木马，通过聊天工具传播
https://mp.weixin.qq.com/s/TSGIm_qpIb7MEOBrxAinYw
 
有不法分子通过电脑聊天工具传播一个新的远控木马变种，该变种除具有获取系统信息、窃取文件、远程下发执行、截屏等常见的远控功能外，还增加了对聊天会话监控窃取功能，获取用户聊天记录中的大量个人信息。
 
该木马有两大主要传播方式：通过聊天工具发送钓鱼链接，诱惑用户点击链接下载恶意程序。通过聊天工具发送诱导性chm文件，如：“牛年发财.chm”、“我的持仓.chm”、“持仓图.chm”等。用户一旦运行接收到的chm文件，便会释放远控木马。
 
通过对木马传播数据分析发现，该木马攻击目标主要是股票、期货、基金等金融投资相关用户。而基金、股票投资正是近期网络热点，相关话题有大量投资者关注。
 
4. 仿软件、劫网站、插广告、窃隐私，还有什么不敢干的？
https://mp.weixin.qq.com/s/Ifn373Tdbx4-97q95sGsJQ
 
有网友反馈，在访问网站时被强行插入广告，且部分无法关闭。经分析发现，是一些浏览器恶意扩展在正常访问的网站中强插广告导致，进一步溯源发现，这些浏览器扩展来源主要是搜索推广的恶意下载器软件携带安装的。
 
国内安全研究人员对这些下载器分析，发现恶意下载器仿冒了超过3500款软件，涵盖办公、行业、设计、媒体等常见类型，其在启动后会静默向浏览器安装恶意扩展，该扩展通过云控在用户访问的其它网站中插入广告、劫持电商、导航、私服等超过6000个网站，此外扩展还会收集用户的上网数据甚至会收集用户在360论坛、QQ电脑管家论坛的发贴反馈情况；所有劫持规则均通过云端下发并使用AES、DES进行加密。

(三) 漏洞情报

3月份值得重点关注的漏洞情报：

1. 微软Exchange多个高危漏洞通告
https://mp.weixin.qq.com/s/kdXqtRcL1vovqT-z6F7oow
 
微软紧急发布了Exchange 多个高危漏洞的风险通告，攻击者可以利用相关漏洞在无需用户交互的情况下攻击指定Exchange服务器，执行任意代码。Exchange服务器被入侵者控制会导致十分严重的后果，包括但不限于：严重的信息泄露风险，以及后续导致的其他严重攻击事件。
 
如果企业使用Exchange Server作为邮件服务器，在存在漏洞的情况下，会被入侵者轻易攻破，入侵者可以绕开授权机制，提取该企业所有通信邮件，造成机密信息泄漏；攻击者还可以内部员工凭据发送钓鱼邮件（成功率极高），进一步入侵内网其他系统，或以此作为跳板入侵其他服务器。如果在安全演练场景下，则有很高的几率导致失分甚至直接出局。
 
按常规进度，该漏洞会在3月份的例行安全公告中发布，因漏洞影响严重，已有在野攻击利用，微软已提前发布漏洞补丁，微软提前发布安全补丁的事件十分少见，表明该漏洞的危险等级十分严重。
 
微软标记已有在野攻击利用，漏洞破坏力较大，腾讯安全专家建议受影响的政企用户尽快升级修复。

https://mp.weixin.qq.com/s/hx2_zDOqeNB2qEFNoKybug
 
3月15日，XStream官方发布十余个高危漏洞公告。漏洞可能导致拒绝服务、服务端请求伪造或远程代码执行。
 
XStream是Java类库，用来将对象序列化成XML （JSON）或反序列化为对象。XStream是自由软件，可以在BSD许可证的许可下分发。

GitLab官方发布了GitLab 远程代码执行漏洞风险通告。未经授权但经过身份验证的用户，能够利用该漏洞在服务器上执行任意代码。腾讯安全专家建议受影响的用户将GitLab升级到最新版本。

4. OpenSSL发布两个高危漏洞风险通告（CVE-2021-3449/3450）
https://s.tencent.com/research/bsafe/1281.html
 
3月25日，OpenSSL官方发布两个高危漏洞风险通告，漏洞风险等级为“高”，攻击者利用漏洞可导致拒绝服务和中间人攻击。
 
OpenSSL是一个开放源代码的软件库包，应用程序可以使用这个包来进行安全通信，避免窃听，同时确认另一端连线者的身份。这个包广泛被应用在互联网的网页服务器上，已是互联网最重要的基础设施之一。

针对本月主要威胁的安全解决方案

从3月威胁情报统计数据看出，挖矿木马、勒索病毒事件威胁依旧严重，这两类威胁事件大多是攻击者利用高危漏洞及弱口令风险入侵，攻击得手之后，就会进一步下载恶意载荷（包括挖矿木马程序、勒索病毒、蠕虫化扩散工具、远程控制木马等等）。


攻击者一旦利用漏洞或弱口令取得突破，就会在失陷网络中采用多种技术手段横向扩散扩大战果，通过篡改系统配置、在系统留置后门安装远程控制木马、创建管理员权限的帐户等手段对失陷系统进行持久化控制。

失陷系统不仅面临服务器资源被恶意利用挖矿，正常业务无法运行甚至业务崩溃的风险，入侵者还可能利用失陷主机资源对互联网的任意目标进行网络攻击，通过遍历失陷网络数据，盗窃关键数据后释放勒索软件实施勒索赎金。

鉴于上述理由，腾讯安全专家建议政企用户采取必要的安全措施，尽最大可能减少黑客入侵风险。

公有云系统

建议部署腾讯主机安全（云镜）对公有云资产进行安全漏洞检测，及时修复高危漏洞，查杀感染主机的病毒木马，通过主机安全产品内置的异常登录事件审计及时发现攻击者的爆破入侵活动。

腾讯主机安全（云镜）检测修复高危漏洞


腾讯主机安全（云镜）检测到恶意请求


建议部署腾讯云防火墙实时监测云上主机的失陷情况，可对恶意主动外联活动智能拦截。通过云防火墙入侵防御功能进行检测拦截高危漏洞攻击，腾讯云防火墙内置虚拟补丁技术，可实时检测防御最新流行的高危漏洞攻击，部分高危漏洞即使因为各种原因没有及时安装补丁，云防火墙也可阻断防御。


腾讯云防火墙拦截到恶意漏洞攻击


建议采用腾讯云Web应用防火墙（WAF）保护企业Web服务器，腾讯云 Web 应用防火墙（Web Application Firewall，WAF）可以帮助公有云用户应对各种 Web 攻击、入侵、漏洞利用、挂马、篡改、后门、爬虫、域名劫持等网站及 Web 业务安全防护等问题。

腾讯云Web应用防火墙（WAF）拦截到针对Web服务器的攻击活动


对于具备一定规模的云主机集群，建议政企机构同时部署腾讯云安全运行中心（SOC）。安全运营中心（Security Operation Center，SOC）是腾讯云原生的统一安全运营与管理平台，提供资产自动化盘点、合规风险评估、流量威胁感知、日志审计与检索调查、安全编排与自动化响应(SOAR)及安全可视等能力。安全运维人员可利用SOAR功能批量处理重大威胁事件，大幅提升威胁事件响应处置的效率。

私有云系统

政企机构的私有云系统，同样是勒索病毒、挖矿木马入侵的重灾区。

政企机构可以部署腾讯零信任无边界访问控制系统（iOA）解决上述风险，通过iOA系统集中进行漏洞扫描和病毒查杀。零信任的安全理念，彻底打破传统基于区域的授信控制方式；基于可信身份、可信设备、可信应用授予访问权限；对每一次会话请求进行安全状态检查和授权，全链路加密。可有效防止常因员工帐号密码泄露、远程办公等场景给企业网络安全造成的风险。

腾讯零信任策略中心开启弱密码检测


腾讯零信任iOA配置全网安全管理策略，消除恶意攻击在内网扩散的风险


使用腾讯零信任iOA修复终端安全漏洞


建议政企机构部署腾讯高级威胁检测系统（御界），及时对黑客攻击活动进行告警。御界通过镜像方式采集网络边界流量，集成探针、沙箱、分析平台一体化部署，结合威胁情报数据，运用数据模型、安全模型、感知算法模型识别网络攻击及高级威胁（APT）。对事件告警原始流量进行留存，方便事后追溯，可极大提升威胁感知能力。

安全运维人员通过御界告警的响应处置，可及时发现入侵者活动情况，针对入侵者的技术特点对私有云存在安全弱点进行强化加固。

订阅腾讯安全威胁情报产品

腾讯安全威胁情报数据是腾讯安全全系列安全产品的技术中台，汇集全球不同来源的威胁情报及网络基础设施数据，包括失陷检测 IoC、IP信誉、域名信誉、文件信誉、APT跟踪、历史活跃信息以及最为全面的开源威胁情报。

政企客户可订阅的威胁情报产品主要包括：腾讯T-Sec威胁情报云查服务（SaaS）、腾讯T-Sec网络空间风险云监测系统（CCMS）、腾讯T-Sec高级威胁追溯系统。

安全运维人员可通过上述威胁情报产品检索分析各种网络告警信息，了解各种威胁的技术特点，分析系统日志，进行威胁事件线索研判、追溯网络入侵源头。



关于腾讯安全威胁情报中心


腾讯安全威胁情报中心是一个涵盖全球多维数据的情报分析、威胁预警分析平台。依托顶尖安全专家团队支撑，帮助安全分析人员、安全运维人员快速、准确地对可疑威胁事件进行预警、处置和溯源分析。
