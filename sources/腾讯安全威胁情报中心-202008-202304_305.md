# 微软发布2021年1月安全更新

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247497366&idx=3&sn=8f7b2a2c26fbffd1fca00dc27feb224b&chksm=ec9f2fe5dbe8a6f39058eac754f56b99a5ec32463e57eb3d856890f444bf35b848b945bf8023&scene=126&sessionid=1681278364#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247497366&idx=3&sn=8f7b2a2c26fbffd1fca00dc27feb224b&chksm=ec9f2fe5dbe8a6f39058eac754f56b99a5ec32463e57eb3d856890f444bf35b848b945bf8023&scene=126&sessionid=1681278364#rd)

2021年1月13日，微软发布了2021年1月例行安全更新，本次发布包括以下软件的安全更新：

*   Microsoft Windows
    
*   Microsoft Edge（基于 EdgeHTML）  
    
*   Microsoft Office、Microsoft Office Services 和 Web 应用  
    
*   Microsoft Windows 编解码器库  
    
*   Visual Studio  
    
*   SQL Server  
    
*   Microsoft Malware Protection Engine  
    
*   .NET Core  
    
*   .NET Repository  
    
*   ASP .NET  
    
*   Azure

腾讯安全专家建议用户尽快升级修复，个人用户推荐使用Windows安全更新或腾讯电脑管家，企业用户可使用微软官方的补丁管理方案，亦可通过腾讯T-Sec终端安全管理系统进行漏洞扫描和补丁安装。建议企业用户在进行小范围兼容性测试的基础上，进行全网统一补丁安装。
