# “incaseformat”蠕虫病毒发作，硬盘文件被删除，SSD硬盘用户可能要哭了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247497366&idx=2&sn=687eab6af3adf0fca6ea3a46ac1dab73&chksm=ec9f2fe5dbe8a6f386180fc5b044311f95252d2df30a2b2646120d8d94a48c029188d1d6f667&scene=126&sessionid=1681278364#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247497366&idx=2&sn=687eab6af3adf0fca6ea3a46ac1dab73&chksm=ec9f2fe5dbe8a6f386180fc5b044311f95252d2df30a2b2646120d8d94a48c029188d1d6f667&scene=126&sessionid=1681278364#rd)

首先需要说明，昨天有不少人遇到“incaseformat”蠕虫病毒发作，将除C盘以外的所有文件删除，只在磁盘根目录留下一个incaseformat.log的0字节文件。是不是慌了？别慌，腾讯零信任无边界访问控制系统（iOA）、腾讯御点、腾讯电脑管家都可以查杀防御，不幸中招的用户被病删除的文件也有办法救回来。  

  

详情请参考昨天推送的文章：  

[被“incaseformat”蠕虫病毒删除文件？不要慌，腾讯iOA、御点、管家都能杀，文件也能恢复](https://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247497358&idx=1&sn=5aaa8fdc468d7176493a4b5ab935d150&scene=21#wechat_redirect)  

  

被删除的文件恢复成功的概率很大，即使中招的用户，也不需要太担心。但是，使用SSD硬盘存储数据的用户，如果遇到这个情况，就十分不妙了。  

   

我们都知道，在磁盘文件被删除之后，操作系统只是做了一个标记，标记文件被删除（即使磁盘被格式化，只不过是在文件分配表做了重新划分，创建了新表）。在硬盘的物理扇区，所有数据还在。只要物理扇区数据未被其他数据覆盖，使用文件反删除命令或反格式化命令，就能找回数据。围绕数据反删除反格式化，有很多工具软件可以选择。  
   
腾讯电脑管家的用户只需要在工具箱里，点击“文件恢复工具”（默认会装在C盘，不用担心覆盖其他分区）。启动电脑管家的文件恢复工具：  

![](../Images/c88bc7c0aa41d3df294613b4a630adce.png)

   
再单击恢复被删除的文件  

![](../Images/8faed5508c4837f06fea3f98d51a3afd.png)

   
把找回的文件另存在其他磁盘，数据就恢复成功了。  

![](../Images/d89e364a4719cab1ae7db8c1f7b1e87a.png)

   
这里需要指出的是，如果选择全盘恢复所有文件，用户需要一个可用的足够大的磁盘空间，可以外接移动硬盘，或网络共享映射空间，将所有文件保存就可以。恢复出来的文件中，可能会有被删除的病毒程序文件，只需要恢复完数据之后再杀毒就可以。  
   
但是，如果受害者是把数据存储在SSD固态硬盘上，同时没有用其他机械硬盘做备份。被删除后的文件，大多数情况下就很难找回来了。这是为什么呢？  
   
因为，SSD固态硬盘用了和机械硬盘完全不同的数据存储方式。  
   
SSD在新数据写入之前需要先进行文件擦除操作，为了保证SSD随时有可以写入的地方，会平均分配各个闪存模块的损耗，SSD闪存都有擦写次数限制。SSD设备控制芯片会平均分配存储位置，可以让所有存储空间平均分配读写次数，从而延长SSD硬盘整体使用寿命。  
   
为了让SSD更长寿，操作系统引入了Trim指令，操作系统删除数据时，会直接让SSD把数据清理掉腾地方，而不是像机械硬盘那样先空着，有新数据写进来时再覆盖，而是数据直接没了。  
   
Windows 10默认会开启Trim指令，想知道自己的SSD是否已经使用了Trim的话，可以用管理员模式启动命令提示符或powershell，输入“fsutil behavior QUERY DisableDeleteNotify”  
   
如果显示的是“DisableDeleteNotify = 0”就是开了，“1”就是没开。  

![](../Images/0796372f40d092676753d93199b02526.png)

   
如果土豪不在乎SSD硬盘的使用寿命，而在乎SSD硬盘的数据安全，可以将trim指令关闭。在命令提示符（管理员模式）或Powershell中输入“fsutil behavior set disabledeletenotify 1”，之后SSD硬盘被删除的数据，就有可能恢复。  

![](../Images/5750633154df21eccee193b193f66d74.png)

   
但是，**强烈不建议你这样做，这会让SSD硬盘的使用寿命大大缩短**，可能速度越来越慢，甚至几年就报废了。  
  
所以，上面操作测试之后，建议再输入“fsutil behavior set disabledeletenotify 0”重新启用Trim指令。  

![](../Images/66a9b335fc73fb293a34f1d5735655a3.png)

  
最后，**强烈建议不要在SSD硬盘上长期存储重要数据**，用来跑系统，装软件，提高系统性能就可以了。**为了数据安全，珍贵数据（照片、视频、论文、工作成果），建议及时备份到机械硬盘上长期保存。 **

  

因为：存放在SSD固态硬盘上的数据，默认情况下，只需要误操作一次删除，再清空一次回收站。或者，命令行里直接del操作，文件就会消失了。数据恢复软件找回来的，也只是一个空文件。  
   

SSD硬盘的存储安全，需要特别提醒用户注意。
