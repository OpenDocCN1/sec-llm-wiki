# Apache Struts远程代码执行漏洞（CVE-2020-17530）风险通告，腾讯安全支持全面检测

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5ODk3OTM1Ng==&mid=2247496922&idx=1&sn=007dbf1000d90fd16ded81e7fa3a00cc&chksm=ec9f2da9dbe8a4bf223b4f2e15efc62d165ee28780f674e4c49fa60c689b461a07e62d705a9f&scene=126&sessionid=1681278374#rd](http://mp.weixin.qq.com/s?__biz=MzI5ODk3OTM1Ng==&mid=2247496922&idx=1&sn=007dbf1000d90fd16ded81e7fa3a00cc&chksm=ec9f2da9dbe8a4bf223b4f2e15efc62d165ee28780f674e4c49fa60c689b461a07e62d705a9f&scene=126&sessionid=1681278374#rd)

  

## 1**漏洞描述  
**

  

Apache Struts 官方披露S2-061远程代码执行漏洞（CVE-2020-17530）。当开发人员强制使用OGNL解析时，某些特殊的TAG属性可能会被双重解析，进而导致远程代码执行。腾讯安全专家建议受影响的用户尽快升级修复该漏洞。

Apache Struts2框架是一个用于开发Java EE网络应用程序的Web框架。  

  

## **2****漏洞编号**

  

CVE-2020-17530  

  

## 3**漏洞等级**

  
  

高风险  

  

## 4**受影响的版本**

  
  
  
  
  

Apache Struts 2.0.0 - 2.5.25

  

## 5**安全版本**

  

Apache Struts >= 2.5.26

  

## 6**漏洞修复  
**

  

避免对不受信任的用户输入使用强制OGNL评估，或/和升级到2.5.26版，可修复该漏洞。腾讯安全专家建议受影响的用户将Apache Struts框架升级至最新版本。

  

## 7**腾讯安全解决方案**

  

1.**腾讯T-Sec主机安全（云镜）**漏洞库日期2020-12-8之后的版本，已支持对 Struts 远程代码执行漏洞（CVE-2020-17530）进行检测。  

2.****腾讯T-Sec云防火墙****内置的入侵防御功能支持对Struts远程代码执行漏洞（CVE-2020-17530）利用进行检测和拦截。
