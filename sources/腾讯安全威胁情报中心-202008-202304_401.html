01

安全运营工程师（腾讯云全资子公司）

招聘岗位：6名

工作地点：武汉


岗位职责：
1、负责SOC/零信任等产品的安全策略运营，提升产品安全能力；
2、协助客户进行安全策略配置实施，基于产品为客户定制有效安全解决方案；
3、协助客户解决入侵溯源、病毒木马处理、安全加固、勒索病毒应急等问题；
4、负责客户安全巡检、重保监测及研判溯源等工作，总结并完善安全运维体系；
5、梳理提炼客户建议和需求，推动研发落地，提高客户对产品的满意度。

注：此岗位为腾讯集团旗下全资子公司编制。


岗位要求：
1、熟悉网络攻防技术，熟悉主机/终端常见安全问题及处置方法；对SOC/IDPS/防火墙/零信任/终端安全等安全产品原理及防御方法有较深入理解；

2、熟悉常见安全攻防对抗手段，熟悉渗透测试流程及安全防护经验，熟悉常见安全漏洞及技术原理；

3、有激情有进取心，乐于持续学习，抗压性强，良好的服务意识和协调能力。工作积极主动，有很强的责任心和执行力；

4、善于沟通表达，思维缜密，有敏锐的洞察力；

5、本科及以上学历，计算机及相关专业，1年以上工作经验。

简历请发送至：gordoncheng@tencent.com

02

安全研发工程师（腾讯云全资子公司）

工作地点：武汉


工作职责：
1、负责安全产品的研发工作，包括安全场景的开发、运营；
2、负责构建智能化安全分析技术，提升安全产品的分析、检测能力；
3、参与客户技术交流和产品效果验证。

注：此岗位为腾讯集团旗下全资子公司编制

岗位要求：
1、熟练掌握至少一种编程语言：Go/Python/Java等；
2、熟悉常见的网络攻防场景、了解ATT&CK等安全知识库，能输出和开发安全检测、事件分析等安全场景；
3、工作积极主动，有进取心；具备较强的团队协作意识，良好的沟通表达能力以及逻辑思维能力；
4、2年以上安全产品研发经验或安全相关从业经验；
5、熟悉SOC/SIEM/态势感知、IDPS等产品，有安全产品场景开发经验者优先；
6、有机器学习、安全数据分析经验者优先。 


简历请发送至：abyliang@tencent.com

03

后台研发工程师（腾讯云全资子公司）

工作地点：武汉


工作职责：
1、负责安全产品的架构设计、模块设计、以及后台研发工作；
2、负责安全产品的维护和升级优化；
3、负责海量数据接入、存储和检索等带来的各种技术挑战攻关。

注：此岗位为腾讯集团旗下全资子公司编制

岗位要求：
1、精通一种或几种以下语言，Python / Go / Java / C++ 等等 ；
2、善于学习和运用新知识，具有良好的分析和解决问题能力；
3、熟悉hadoop、flink、es等大数据技术和存储系统、分布式检索系统；
4、了解服务器入侵检测、事件溯源、日志分析、大数据威胁检测等；
5、3年及以上安全相关从业经验，熟悉安全产品的工作原理及相关能力要求；
6、有NTA、SOC或者安全管理平台的开发经验者优先。

简历请发送至：abyliang@tencent.com
