1
漏洞描述


Node.js项目在2020年11月16日发布15.x，14.x和12.x的新版本，修复一个拒绝服务漏洞。Node.js应用程序允许攻击者为自己选择的主机触发DNS请求，通过使该应用程序解析具有大量响应的DNS记录来触发拒绝服务（DoS）。

 

Node.js 是能够在服务器端运行 JavaScript 的开放源代码、跨平台 JavaScript 运行环境。


2漏洞编号


CVE-2020-8277


3
漏洞等级


高危


4

Node.js 14.x系列：14.13.0-14.15.1

Node.js 15.x系列全部版本
