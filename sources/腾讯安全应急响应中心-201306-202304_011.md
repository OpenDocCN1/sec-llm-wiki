# 处理公告丨2022年10月腾讯外部安全报告处理公告

2022年10月，共65位安全专家通过安全问题反馈平台向腾讯报告安全问题，腾讯对这些安全专家表示感谢。

![](../Images/1ff7339eac10111b5e98d5ff4bedcf20.png)

  

依据腾讯《TSRC漏洞处理和评分标准》关于“严重漏洞额外现金奖”的规定，以下3位白帽子由于为腾讯核心业务或重点业务提供高质量严重漏洞报告，TSRC特别授予他们月度即时现金奖励，具体明细如下：

  

“我好了”获得税后奖励60,000元；

“tzrj”获得税后奖励20,000元；

“pytho1n”获得税后奖励10,000元；

  

*\**《TSRC漏洞处理和评分标准》全文详见

https://security.tencent.com/uploadimg\_dir/other/TSRC.pdf?v=3.1
