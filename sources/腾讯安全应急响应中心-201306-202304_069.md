# 你都不知道心疼人的

![](../Images/8422f45dcd3e6375491fa718fb54a910.png)

一进家门就听到爸妈在battle

我妈：“你都不知道心疼人的”

我爸：“你冷静一下……”

  

我耳朵马上竖了起来

爸！妈！你们在说啥？！！

  

![](../Images/d737cb229e1ff834a7f335521c95b3de.png)

  

我冲到八卦第一现场，结果被我妈喂了一记爆栗，她埋怨道——  

  

都7月底了，妇女节、母亲节、端午

多少个节过去了，你一点表示都没有

  

你说你天天忙啥，早出晚归的

见不到人，说不上话

特殊日子一点仪式感都没有

  

你和你爸一样，都不知道心疼人的……

  

![](../Images/b8b95f82c62a814b10cf865bf6c97ee9.png)

  

“等一下！”我赶紧插话，再不解释肯定要被按在地上摩擦  

  

我直起腰，故作淡定地说，

“我早有准备，你稍等一下”  

  

说着，我从怀中掏出了今天刚收到的快递，

忐忑地送给她——

  

![](../Images/a0d07c139a079591309eae8f8b893801.png)

*长这样*

  

我妈眼里写满了“就这”？？

在她爆发前，我抓紧机会抢白

  

“扫上面的码可以换礼品，有锅碗瓢盆、床上四件套，还有口红香水、珠宝首饰，种类多多，任选其一”

  

“这是我挖洞的奖励哟”，我一脸骄傲。

她傲娇地收下，我长吁一口气  

于是我又做回了她的宝宝

  

![](../Images/f7b4fc134c5fff7fa0254f50c5230905.png)

  

对了，你们的快递应该也快到了，这两天记得收。寄送范围我帮你们问了——
