2018年12月22日，腾讯安全应急响应中心（TSRC）2018年度峰会在东莞松山湖凯悦酒店拉开帷幕。

 

今年峰会的主题是“破界”。我们生活在一个界限清晰的世界，万物因为有了界限才能独立生长。但界限亦可破，学科领域之间因为破界有了突破，科技与现实之间因为破界有了创新。

 

今天我们齐聚一堂，也正是希望破开彼此之间的界限，用开放的心态探索安全的另一种可能，用合作的姿态迎接行业崭新的未来。

 


//

开场致辞：

新时代新机遇，“破界限”迎挑战

//


即将过去的2018年，我们碰到了很多以前没有遇见过的挑战，不变的是，这背后一直有一帮与我们并肩作战的安全精英默默地为腾讯的发展作出了伟大贡献，始终践行着守护亿万用户安全的责任与担当。

 

腾讯安全平台部负责人、腾讯安全学院副院长coolc（杨勇）在开场致辞中表示：万物互联时代，我们也看到了很多新的机会和可能。未来的日子，需要大家更多地去沉淀，积极夯实自己。而在这个时代，安全是一块最重要的压舱石。

 

coolc还提到，新的时代，意味着我们和业界的合作也到了一个新的开始。所以我们提“破界”，希望大家一起拥抱变化，携手并进，共同迎接未来挑战。


腾讯安全平台部负责人coolc：“新的时代，意味着我们和业界的合作也迎来了一个新的开始。”


//

回首·2018：

品牌新打法，合作建生态

//

 

2018是创新的一年，也是变革的一年。TSRC首次尝试了多家SRC联合运营，首度推出了腾讯xSRC开放平台，并进行了多种全新的品牌运营尝试。腾讯安全平台部总监、TSRC & Blade Team总负责人lake2表示，互联网连接一切的时代，网络安全需要更多的开放与合作，才能迎来更好的未来。TSRC发展到今天，与在场每一个人的支持和无私帮助息息相关。


腾讯安全平台部总监Lake2：TSRC后续会不断加大投入，回馈大家对我们的付出，共同建立更好的行业生态。


TSRC技术负责人小五在会上向大家介绍了腾讯安全应急的体系。小五也表示，腾讯十亿用户的安全和互联网生态的发展都离不开大家的共同努力。我们每年举办峰会，并不足以表达我们的感激之情。


TSRC技术负责人小五：有了大家的付出与合作，腾讯10亿用户才得以安全无忧地徜徉在互联网的海洋里。


//

年度颁奖：

感谢有你，一路同行

//

 

在过去的一年，无数白帽子积极为我们TSRC提交漏洞，保护腾讯业务免遭威胁，共同守护了亿万用户的信息与财产安全。本次TSRC年度峰会为All Might、Chora、落、Camaro、Loneyer、tzrj等6位本年度突出贡献者进行了颁奖。其中，TSRC奖励漏洞之王税前30万元现金，奖励神洞猎手税前20万元现金，奖励狙洞精英税前10万元现金。我们也要感谢帮助过我们的每一个人！我们的奖项，无法完全表达我们的的心意和感激。TSRC希望通过大家的共同努力，让白帽子的工作更有价值、赢得更多认同与尊重。


漏洞之王：All Might

神洞猎手：Chora、落、Camaro

狙洞精英：Loneyer、tzrj


除了这些技术精湛的安全精英，在过去一年，也有非常多优秀的合作伙伴与我们一起并肩作战，共同建设网络安全生态。在峰会上，TSRC为CNVD漏洞库、长亭科技、i春秋、看雪学院、四叶草安全、未来安全、网络尖刀、知道创宇颁发了TSRC·2018年度优秀合作伙伴奖。希望未来我们能继续携手并进，更好地建设行业生态。


TSRC技术负责人小五、TSRC运营负责人juju为2018年度TSRC优秀合作伙伴颁奖

 

//

分享show：

议题分享不间断，干货满满

//


在年度峰会上，唯品会安全经理方斌、以及看雪科技创始合伙人胡勇为大家带来了精彩的议题分享。

 

唯品会安全经理方斌为大家分享了他眼中的“SRC”，从不同的角度剖析了他对SRC建设的理解。方斌表示：国内的SRC也在不断成长，而成长需要一定的时间，希望白帽子给我们一点时间，大家共同进步。


方斌：SRC不仅仅是“桥梁”，更多是一份“责任”


看雪科技创始合伙人胡勇为大家带来演讲分享《SRC，共享经济下的安全》。胡勇称：xSRC帮助中小企业解决安全漏洞问题，省去了大量开发、运维的工作量，能够更好地专注于漏洞奖励和处置、鼓励白帽子报告漏洞等SRC运营工作，是对网络安全的积极贡献。


胡勇：xSRC是对中国互联网安全的重要贡献


本次峰会还邀请了圈内部分大牛进行圆桌会议分享，共同探讨SRC运行发展过程中，如何“破界”的问题。

在圆桌会议上，coolc回忆起了当初成立TSRC的艰难过程。lake2也提到了TSRC在过去的一年中做出的许多开放尝试，包括联合运营，xSRC开放平台等。美团安全总监职业欠钱也提到了作为新兴企业安全力量的代表，如何在风云变幻的新时代准确把握安全的脉搏。

 

在海外安全生态建设问题上，圆桌会议提到，不管是SRC还是白帽子都在积极进行海外的尝试。Tencent Blade Team此前发现了Google、亚马逊、苹果等国际知名厂商近百个漏洞，并在积极推动行业漏洞响应机制等建立与完善。


圆桌会议同时也分享了国内安全圈的发展变迁。Blade Team负责人张博和长亭科技的陈宇森都提到，国外的安全机制有许多值得我们借鉴的地方，但近年来国内安全圈也有了很大的发展，在很多方面甚至比国外的厂商都要更完善，更适合我们国家的具体情况。


 Tencent Blade Team负责人张博


“前辈”级别的大神冰河和作为主持人的呆神也从亲历者的角度出发，回忆了二十年来国内安全圈的发展历程，从当初的混沌到今日的秩序初现，背后凝聚的是多代安全人不懈的努力与付出。未来安全圈的发展也离不开所有安全人的共同努力，大家一起用开放的心态破开界限，合作共赢，共同探索安全的无限可能。
