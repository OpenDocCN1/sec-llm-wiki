# 即时现金奖励安全公告

2014年3月25日，腾讯安全应急响应中心（TSRC）收到平台白帽子Nicky反馈腾讯某业务高质量安全问题，并积极协助我们修复，避免了用户受到安全风险的威胁。我们向其崇高的白帽子精神表示敬意，并特别给予其即时现金奖励10000元，以表示我们深深的谢意。   

         
本次即时现金奖励也是TSRC第一次对外实施。后续对于优质安全问题的提交，除了常规的安全币奖励以外，我们还会给予额外的即时现金奖励。欢迎业界安全专家通过官方渠道给我们反馈安全问题，让我们携手捍卫亿万用户的安全。
