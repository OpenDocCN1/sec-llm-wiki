# 打击犯罪动态 | 去年9月至今年10月黑龙江省处理网络造谣传谣者近200人

生活报10月18日讯 “H7N9病毒肆虐，已有多人死亡”、“牡丹江火车站附近现恐怖分子，打砸警车”……此类信息相信大家在微信、微博上都曾见过。互联网在给我们带来信息、社交便利的同时，也给造、传谣者的滋生提供了温床。17日，记者从省公安厅网安部门了解到，自2013年9月，最高法和最高检《关于办理利用信息网络实施诽谤等刑事案件适用法律若干问题的解释》实施后至今年10月，我省共处理利用造、传谣实施犯罪的近200人。其中，造、传谣者以发泄不满情绪、报复社会目的的占到了总数的6成左右。

　　

省公安厅网安总队总队长孙耀武表示，网安部门作为维护网上秩序的主管单位，将继续在加强网络监管力度、净化网络环境、提高违法犯罪成本、阻击网络谣言等方面进行全方位出击。

　　

**谣言一：“龙江县医院一患者因H7N9死亡”**

　　

**来源：龙江县26岁男子酒后传谣处罚：被拘10天**

　　

2月21日，齐市龙江县公安局接到县人民医院相关人员的报案，称有人散布谣言。经查，该网络信息的内容为：“龙江县医院一患者昨天凌晨4点21分因H7N9死亡！年龄31岁，孩子还在妈妈的肚子里，参与抢救的医生已被隔离。紧急通知：刚刚中央二套电视新闻已播出，暂时别吃猪肉、鸡肉、鸭肉！因为齐齐哈尔市有5570头家禽已经感染了，黑龙江省刚开完紧急会议！龙江已有多人被感染，胜利有一个，黎明有一个，民主三个，收到后马上发给你关心的人，预防永远胜过治疗，这绝对不是传言，转给身边人，大家注意安全。”

　　

此信息一出，便被众多网民通过微信朋友圈转发，在当地引发了大范围的群众恐慌。接警后，齐市网安支队在龙江县公安局的配合下，展开侦查，最终锁定该信息首发人为26岁的龙江县人刘某某。而当公安机关依法对其讯问后，刘某某供认自己在醉酒后，将其微信好友发送的一条信息改头换面，捏造成了发生在龙江县医院的病毒事件，并在自己的朋友圈中散播，造成了谣言扩散。因刘某某的行为已触犯相关法例，当地警方对其进行了治安拘留10日的处罚。

　　

**谣言二：“牡丹江火车站现东突分子砸汽车”**

　　

**来源：6名传谣者捏造处罚：分别被拘留、警告**

　　

3月8日，牡丹江市发生的一起火车站执勤警车被砸事件，经过三人“演绎成谣”，造成了一定的社会恐慌。当时，事件原本是一名男子手持斧头砸坏了火车站附近5辆汽车后，在向火车站候车室方向逃跑时，被正在车站执勤的特警、武警当场制伏抓获。该事件的发生正值“两会”期间，特别是昆明火车站暴恐事件刚刚发生，当地人的朋友圈中就出现了“牡丹江火车站，抓住一个新疆人，这是我亲眼目睹的，在他身上翻出了一把手枪，还有一把斧头”、“牡丹江火车站现场发现东突恐怖分子，带一把手枪一把手斧，已被当场制伏，大家出门要小心点”的信息，此内容被疯狂转发，大家在议论纷纷的同时都感到害怕。

　　

随后，网安部门警方发现有人有意编造传播此虚假恐怖信息。网安部门经过调查，对传播虚假恐怖信息的付某、徐某等6人分别处以刑事拘留、行政拘留、警告教育等处罚。

　　

**网络谣言大致分7种**

　　

省公安厅网安总队总队长孙耀武告诉记者：“目前，常见的网络谣言的传播主要依靠两个渠道，其一，是贴吧、论坛类的交互式栏目；其二，是微信、陌陌、YY等即时通讯软件，而在我们身边，此类即时通讯软件有几十种之多。”

　　

谈及网络谣言的类型，孙耀武表示，粗略统计，大概有七种类型(见下表)：

　　

| 利用爱国情绪类 || "苹果手机地图钓鱼岛未划分在中国内南京大屠杀日本零票房" |
| --- | --- |
| 转发获利类 || "返利给会员或参与抽奖" |
| 食品安全类 || "大豆不发芽土豆不变黑的转基因""某餐企用的都是地沟油" |
| 人身安全类 || "夜店喝多后，被摘取肾脏等器官" |
| 利用同情心类 || "小孩在某地被拐骗" |
| 散播恐怖信息类 || "某地现新疆圣战"、"东突暴恐分子" |
| 重大事件散播虚假信息类 || 马航失联传播的多条信息 |

　　

造、传谣背后的成因是什么？省公安厅网安总队案件支队支队长刘岩峰表示：“网上造、传谣的成本低，拨弄手机按键就可编造、转发。对于造谣方，大概集中在恶意释放不满情绪、无法律意识地恶搞和有组织地传播的人。对于传谣方，因为微信朋友圈、微博等多是基于好友间的信任，而互相关注、转发，其中，很多个体容易盲目跟风，导致谣言迅速扩散。”

　　

**辨别网谣警方出5招**

　　

一看微信公众号名字，如果传播一个明显跟自己公众号类型无关的信息，其可信度无疑是很低的；

　　

二看文章语气，如果一篇文章里充斥着各种叹号、语气词、形容词，那写文章的人极可能是不了解自己说的这个问题；

　　

三看排版，一篇花里胡哨的文章，发布者的专业性就是非常值得存疑的；

　　

四看证据和专家，谣言帖是根本没有证据的，它只说XX是剧毒，没证据及具体专家职位、姓名等信息；

　　

五看结论严重度，结论越绝对、吓人，越会是谣言。
