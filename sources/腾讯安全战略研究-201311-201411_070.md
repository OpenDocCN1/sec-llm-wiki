# 打击犯罪动态 | 介绍卖淫网站 注册会员过百万

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=201470451&idx=2&sn=a65b2bc35b03c25bd377188ec8d2e926&chksm=2f4d1f2c183a963a6e6e21df64f920cd338bd79e684eb77164d1488f3719b6c5e889a273536a&scene=126&sessionid=1681324261#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=201470451&idx=2&sn=a65b2bc35b03c25bd377188ec8d2e926&chksm=2f4d1f2c183a963a6e6e21df64f920cd338bd79e684eb77164d1488f3719b6c5e889a273536a&scene=126&sessionid=1681324261#rd)

潍坊寒亭公安分局网安大队民警在工作中发现一个名为“寻芳录”的淫秽色情网站,该网站面向全省介绍卖淫嫖娼信息,注册会员超过百万人。寒亭警方赶赴四川将网站创办者抓获,同时潍坊一名版主也落网。10月14日,记者从寒亭警方获悉,目前本案已经移交寒亭检察院起诉。

　　

**色情网站里发布卖淫嫖娼信息**

　　

“我们的民警在日常网络巡逻工作时,发现了一个名为"寻芳录"的黄色网站,网站上面经常发布一些招嫖信息、淫秽信息。”寒亭公安分局网安大队办案民警告诉记者,这个网站通过发布性信息资源供求,吸引网民充值浏览。

　　

警方调查发现,网站划分详细,有六七个不同的版块,其中有一个版块专门发布招嫖心得体会的相关帖子。很多卖淫嫖娼的信息就藏在这些帖子中,通常这些信息注册会员看不到,只有充值的会员才能打开。

　　

该网站实行会员制,网民免费注册会员之后,可以通过银行账号充值的方式,升级为等级不同的会员,而且高等级会员身份也分为包月、包年、终身制等。不同级别的会员可以获取不同的权限,浏览不同的帖子。

　　

“我们在侦查过程中发现,网站的注册会员数量庞大,同时在线的会员多达5000余人。”办案民警告诉记者,他们获取这条线索后,看是进行侦查,并且将突破口放在潍坊版块比较活跃的发帖人和分区版主。

　　

**民警假扮会员获得破案线索**

　　

“我们通过相应的工作措施,对于潍坊分区版主和一些会员进行侦查,确定了嫌疑人的身份。”经查,分区版主是潍坊人王某,今年29岁,有正当职业,是一名企业工人,而且有着大专学历。

　　

2013年5月份,寒亭网安大队的民警就在王某家中将其抓获。据王某供述,他是平时上网浏览时,无意中发现了“寻芳录”网站,于是就注册了会员,并且发布了几篇帖子。之后,王某经常与网站管理者沟通交流。

　　

网站管理者觉得王某对于网站非常热心,于是封他为潍坊分区版主,对该板块的帖子进行审核把关。王某平时与网络管理者通过QQ联系。

　　

与此同时,寒亭公安分局将案情上报公安部,在全国范围内追查网站的创办者等主要犯罪人员。通过调查,该网站的服务器在美国境内。

　　

为了得到破案线索,民警在该网站注册了一个会员,并且联系客服询问。客服告知他需要充值才能获取权限,并且给出了一个银行账号。

　　

警方通过侦查,查到银行账号的申请地位于四川省。同时,警方调取了相关银行的提款监控录像。

　　

“去提款的是一名50多岁的男子张某,像他这种年龄熟悉网络并且开办网站的可能性非常小。我们分析他有可能是幕后老板,或者是创办者的直接亲属。”寒亭警方与四川警方取得联系,对张某的信息进行了解,发现张某的儿子张某某有重大嫌疑。

　　

**每月非法牟利最多达10万元**

　　

通过进一步调查,警方发现客服QQ的申请者正是张某某,并且初步判断张某某是“寻芳录”网站的创办人。警方随即在四川省内一个县城的酒店中,将张某某和他的女朋友抓获。随后,另外一名网站管理者被四川警方抓获归案。

　　

经过审讯,张某某供述,他中专毕业以后,曾与人合开网站,后来发现开办色情网站能够牟利,于是以每月2000多元的价格租用美国的服务器,自2011年建立“寻芳录”网站,并且雇佣其女友和另外一名嫌犯作为网站管理者。而他为了躲避打击,通常都是让其父亲去银行提取非法所得。

　　

经过初步统计,该网站的注册会员超过百万人。虽然其中仅有很少一部分人充值,但是庞大的基数使得充值会员总数也不少,张某某每个月最多能挣到10万多元。另外,警方顺带侦破了张某某创办的“群芳录”、“艾薇儿”两个淫秽色情网站,这两个网站主要面向的是四川和重庆。

　　

10月14日,记者从寒亭公安分局获悉,目前抓获的几名犯罪嫌疑人已经移送寒亭检察院起诉。
