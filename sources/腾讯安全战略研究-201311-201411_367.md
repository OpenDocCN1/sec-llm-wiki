# ○打击犯罪动态○ 唐河县检察院运用电子证据突破徇私枉法案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=200825676&idx=2&sn=48439be1ff20ee520ddff8322defc12b&chksm=28b775931fc0fc857813dbec115f43878b9d878ccce919c3ece9c5a2cc0dabd875564b6dc00f&scene=126&sessionid=1681324494#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=200825676&idx=2&sn=48439be1ff20ee520ddff8322defc12b&chksm=28b775931fc0fc857813dbec115f43878b9d878ccce919c3ece9c5a2cc0dabd875564b6dc00f&scene=126&sessionid=1681324494#rd)

南阳唐河县检察院检察技术部门积极探索运用新技术手段，协助业务部门分析、提取、固定电子证据，提高了办案效率，获得了良好效果。

今年4月，南阳唐河县检察院收到群众举报，反映某派出所所长高某多次为犯罪嫌疑人伪造假立功材料，并向犯罪嫌疑人家属索要贿赂。反渎部门介入调查后，面对反侦查能力较强的嫌疑人，侦查工作一度陷入困境。

在调查走访中，侦查人员听说高某曾经在城郊某文印室打印过文字材料，遂委托技术部门协助进行电子数据取证勘查。文印室共有3台电脑，根据作案时间，技术人员排除了一台新投入使用的电脑，对其他两台电脑的硬盘当场进行了扣押。

技术人员使用电子数据取证一体机和数据恢复工具，对两块硬盘数据进行了认真的筛选分析，最后从那台废弃电脑的80G硬盘中，成功提取出了嫌疑人伪造的讯问笔录27份，讯问笔录文档生成的时间与讯问时间相矛盾，和案情基本印证。铁的证据，成功突破了嫌疑人高某徇私枉法一案。

2012年以来，针对职务犯罪侦查难度增加、侦查方式落后，唐河县检察院及时提出更新侦查理念，加大技术装备投入，该院信息技术在办案中的应用得到了全面提升。该院检察技术部门通过检验鉴定、文证审查和技术协助，为办案业务部门分析、固定、审查和鉴别证据提供了有力的科技支撑，特别是对手机、电脑内电子数据的分析取证，为案件侦破提供了大量帮助。
