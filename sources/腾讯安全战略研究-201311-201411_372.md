# ○网络安全○ 郭启全：全力维护国家网络空间安全

**郭启全：加快国家网络与信息安全体制机制建设****全力维护国家网络空间安全**

《中共中央关于全面深化改革若干重大问题的决定》（以下简称《决定》）明确设立国家安全委员会，并加快完善互联网管理领导体制，是党中央根据国际国内形势，在全面深化改革开放的关键时期，安全与发展“双轮驱动”的重大战略部署。尤其是习近平主席强调“网络和信息安全牵涉到国家安全和社会稳定，是我们面临的新的综合性挑战。”这为我们加快开展网络和信息安全工作，维护网络空间安全提供了强大动力。结合当前网络安全态势和长期的实践探索，对如何加快完善互联网管理领导体制机制、维护网络空间国家安全和社会稳定，谈一点粗浅认识和看法。

**一、国家安全面临综合性威胁，网络和信息安全威胁日益凸显**

当前，我国家安全面临的突出威胁：

一是军事威胁，某些国家将我作为最大对手，加紧扩军备战和演习，对我国家安全构成了最直接威胁；

二是恐怖威胁，“东伊运”等恐怖组织和恐怖分子煽动、组织恐怖活动，对我国家安全、社会公共安全和人民生命财产造成了现实危害；

三是网络安全威胁，某些国家谋求网络空间霸权，加快建设网络战部队，研发网络武器，并以我为假想敌开展攻防演习，对我国家关键信息基础设施安全构成了重大威胁。

军事威胁、恐怖威胁和网络安全威胁并不是孤立的，三种威胁互相交织、互相关联。现代军事战争，必然伴随着网络战的爆发；恐怖活动必然会利用互联网组织、策划和实施恐怖活动，并极有可能针对关键信息基础设施实施网络攻击；网络安全威胁，是敌对势力、敌对分子、不法分子对我国基础信息网络和重要信息系统的网络战威胁、入侵攻击、窃密和实施网上盗窃等违法犯罪活动。

**二、网络空间大国博弈加剧，三中全会加强网络和信息安全切中要害**

近年来，一些大国在网络安全方面，加紧战略布局，调整体制机制，开展攻防演习，加快网络备战，建立网上统一战线，我网络空间安全受到了前所未有的威胁。与此同时，我国信息化快速发展，在有力支持我国社会发展的同时，也给我国家安全、社会稳定带来了严重挑战。

网络空间安全事关我政治安全、国防安全、经济安全、文化安全，以及社会公共安全和公民信息安全，涉及国家核心利益。可以预见，网络空间的控制与反控制、渗透与反渗透、颠覆与反颠覆的斗争将会更加激烈，在网络空间维护我国家安全、社会公共安全、关键信息基础设施安全和公民信息安全的任务将更加艰巨、繁重。

十八届三中全会决定设立国家安全委员会，是党中央、国务院作出的重大战略部署，体现了坚决维护国家安全的意志和决心，非常重要，非常果断，对有力应对我国家安全面临的军事威胁、恐怖威胁、网络安全威胁等传统安全威胁和非传统安全威胁具有重大战略意义。

《决定》确定了网络安全“坚持积极利用、科学发展、依法管理、确保安全的方针，加大依法管理网络力度，加快完善互联网管理领导体制，确保国家网络和信息安全”的大政方针和路线，为我们开展网络安全保障、保卫工作、全力维护国家网络空间安全明确了方向。我们应按照党中央、国务院的决策部署，切实增强维护国家网络空间安全的使命感和紧迫感，采取强有力措施，共同维护国家安全和社会稳定。

**三、基于长期的网络和信息安全实践，厘清必须解决的突出问题**

近十年来，党中央、国务院高度重视信息安全等级保护工作、网络与信息安全信息通报工作和网络安全检查工作，深入组织开展打击网络违法犯罪活动，加强互联网安全监督管理，有力维护了国家安全、关键信息基础设施安全和互联网安全，有力维护了网络社会秩序。

但从长期的实践检验，以及“棱镜门”事件来看，维护国家网络和信息安全需着手解决以下突出问题：

一是认识不清、重视不够。一些重要行业、部门对网络安全威胁、严峻形势认识不到位，责任意识和忧患意识不强，重视不够。

二是主动发现能力不强。缺乏必要的监测手段和措施，对境内外的网络入侵、攻击、窃密等活动，主动发现能力差，对网络和系统安全隐患和问题查找能力差。

三是主动防御能力不强。“重建设轻安全”的问题突出，缺少科学的安全规划和保护策略，管理制度不完善，责任制不落实，关键安全保护技术措施缺失。

四是管理体制机制还需要进一步完善。领导和统筹有待进一步强化，网络安全跨部门协调机制有缺失，网络发展与安全不协调。

五是基础保障能力不强。通报预警能力、应急处置能力、技术保障能力还不强，法律、人才、技术、产品等方面存在较大差距。

**四、以成立国家安全委员会为契机，强化国家网络和信息安全体制机制建设**

国家已成立了国家安全委员会，应在国安委的框架内进一步完善国家层面的网络安全工作机制，加强协调配合，加快解决突出问题，提高主动防御、基础保障等能力。

具体建议：一是在国家安全委员会的框架下，成立国家网络与信息安全领导小组，统领国家网络与信息安全工作。

二是完善网络与信息安全工作协调机制，在已有网络外交等机制基础上，建立国家安全与社会公共安全协调机制和网络发展与技术安全协调机制。

三是建设立体式的全国网络与信息安全信息通报预警体系，打通横向、纵向信息通报脉络，畅通通报预警渠道。

四是加强法律法规、政策标准、应急处置、安全服务、技术产品、人才培养等工作，为国家网络与信息安全提供强有力的基础保障。
