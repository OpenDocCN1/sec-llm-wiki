# 【网络犯罪动态】| 中国每年流往境外赌球赌资超6000亿元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=200526359&idx=1&sn=bcbcd1a9315b7a9d85e95ceb43fef954&chksm=28bce4c81fcb6dde1d074bb36ff013c002cb668f75b3b56b32dae76267b08dbfe75d15f6015f&scene=126&sessionid=1681324500#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=200526359&idx=1&sn=bcbcd1a9315b7a9d85e95ceb43fef954&chksm=28bce4c81fcb6dde1d074bb36ff013c002cb668f75b3b56b32dae76267b08dbfe75d15f6015f&scene=126&sessionid=1681324500#rd)

4年一次的世界杯“激战正酣”，与之相对应的是网络非法赌球活动的急剧增多。记者调查了解到，世界杯期间参赌人员成几何级数暴增，境外非法赌球网站也成倍出现。此类犯罪活动具有便捷、隐蔽等特点，组织者普遍采用“传销模式”高效运作，严重危害金融安全和社会稳定。

在我国，境外博彩和赌球属于非法行为。然而，随着世界杯的“开战”，网络跨境赌球活动泛滥，境外赌球网站甚至明目张胆招徕生意。

**下注简单“先赌后还”**

记者近日在搜索引擎输入关键字“赌球”，即显示出数十万条关于网络赌球的信息，其中大部分是境外的赌球网站。记者以赌客身份与一家境外赌球网站的客服人员取得联系，客服人员告诉记者，他们总部设在澳门，以现金网的形式稳定运行了八年之久。

重庆的段某某是一位曾经参与过网络赌球的人员，他介绍，网络赌球花样很多，除“胜平负”“比分”等四种一般的玩法外，还有猜定位球数、猜第一个换人的球队、猜第一张黄牌等十几种玩法，赔率远高于合法的体育彩票，有些爆冷的获胜球队，下注者甚至可以得到几十倍的返还，很符合赌徒的“暴富心理”，能轻易吸引很多人参与。

此外，网监警察告诉记者，管理者还通过预支信用额度套牢赌客，形成“不花钱就可以赌博赢钱”的假象。

“预支信用额度抓住了赌客的心理，让很多人心存空手套白狼的想法。”办案警察说。

“世界杯是赌球旺季，赌场一天挣的钱比以往十天甚至一个月的时间挣得都多。”办案民警说。

**大陆成赌场“金矿”**

对于境外赌球集团来说，人口庞大、尚未开放赌博业的中国内地是一座“金矿”。随着我国经济快速发展，居民收入增加，一些境外赌球集团也加大了对我国内地渗透的力度。方便快捷，安全性高，可以直达“客户”易于推广，网络赌球成为其“进军”我国的主要渠道之一。

在天津生活的小刘是一位“资深球迷”，参与网络赌球也有十多年的历史。他告诉记者，在2002年世界杯时，参与网络赌球的人并不多。到了2006年德国世界杯时，网络开始普及，而公安部门的打击力度并不强，非法网络赌球泛滥。今年的世界杯引起更多人的关注，智能手机、平板电脑都可以下注，不少人或“小赌怡情”，或“深度参与”。

北京大学中国公益彩票事业研究所调查显示，中国内地每年由于赌球而流到境外的赌资相当于全国彩票一年发行总额的15倍，超过6000亿元，亟待引起有关方面的重视。
