# 广东开展打击电信诈骗及银行卡犯罪第一次集中收网行动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=200405723&idx=5&sn=0dca3791e49c330db562eac2faf671b3&chksm=28bedc041fc955122d6e1da168dcd09f293f28e33ef96ecd2e1d54fd0accafed1da94b0be50d&scene=126&sessionid=1681324517#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=200405723&idx=5&sn=0dca3791e49c330db562eac2faf671b3&chksm=28bedc041fc955122d6e1da168dcd09f293f28e33ef96ecd2e1d54fd0accafed1da94b0be50d&scene=126&sessionid=1681324517#rd)

记者4日从广东省公安厅获悉，5月20日，广东省公安厅组织开展了打击电信诈骗、银行卡犯罪第一次集中收网行动。行动中，广东警方抓获电信诈骗犯罪嫌疑人92名，打掉窝点13个，缴获现金70余万元；侦破银行卡案156起，抓获犯罪嫌疑人286名，缴获涉案银行卡1616张、POS机133台、电脑63台、作案用手机约500部、转账用U盾100个及赃款70万元。

今年以来，广东省公安机关严厉打击各类电信诈骗及银行卡犯罪，取得显著战果。截至5月底，全省公安机关破获各类电信诈骗案件621起，同比上升28%；逮捕嫌疑人257名，同比上升93%。其中，东莞、珠海、广州、佛山、深圳等市分别破获电信案件111起、79起、71起、69起、68起。在打击银行卡犯罪方面，广东省公安机关创新工作思路，由经侦、网安等部门抽人组成工作专班，按照“边侦查、边扩线、边取证”的策略，以“海燕2号”伪卡案等重点案件为切入点，对银行卡犯罪实施全覆盖打击。1月至5月底，全省破获各类银行卡案件879起，同比上升75%；抓获犯罪嫌疑人962名，同比上升67%。

在强化打击的同时，广东省公安厅协调银行、银监局等部门推动“五大机制”建设，从制度层面夯实打击、防控电信诈骗及银行卡犯罪的基础。

一是推动建立打击银行卡犯罪奖励基金。

二是下发电信诈骗犯罪涉案资金应急处置办法，建立涉电信诈骗和银行卡犯罪账户快速查询冻结机制。

三是推动建立银行卡查询短信提醒机制。

四是建立黄金饰品等重点商户监管机制，要求黄金饰品、珠宝等重点商店安装摄像头记录POS机刷卡录像。

五是建立联合宣传机制，曝光典型案例，揭露作案手法，达到教育群众、震慑犯罪的目的。
