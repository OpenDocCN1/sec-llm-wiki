# 工业和信息化部积极推进打击治理移动互联网恶意程序专项行动

**工业和信息化部积极推进打击治理**

**移动互联网恶意程序专项行动**

《工业和信息化部公安部工商总局关于印发打击治理移动互联网恶意程序专项行动工作方案的通知》（工信部联保〔2014〕153号）印发后，工业和信息化部通信保障局迅速组织落实相关工作。近期先后组织各省、自治区、直辖市通信管理局，中国电信、中国移动、中国联通三家基础电信企业以及相关支撑单位召开会议，专题部署有关工作任务。通信保障局李学林副局长出席会议。

会议指出，开展专项行动是学习贯彻习近平总书记在中央网络安全与信息化领导小组第一会议上重要讲话精神的具体体现，是适应当前网络安全形势、保护人民群众切身利益、促进移动互联网健康发展、维护社会稳定和国家安全的迫切需要。

会议传达了国务院领导同志关于移动互联网安全问题的重要批示精神，通报了工业和信息化部关于加强移动互联网安全管理的总体思路，对专项行动的各项具体任务和实施方法进行了解读，并开展了移动互联网恶意程序监测处置、移动智能终端操作系统和安全标准、移动互联网应用程序检测方法等的宣贯和培训。

会议要求，各相关单位要充分认识开展专项行动的重要意义，切实增强移动互联网安全工作的责任感和紧迫感。各地通信管理局要认真履行属地管理职责，坚持主动作为，创造性地开展工作，主动加强与当地公安、工商部门的沟通协调，建立协作配合机制，形成工作合力。各基础电信企业要加强自有应用商店安全管理，完善移动互联网恶意程序监测处置手段和相关工作机制。各相关技术支撑单位要大力提升移动互联网恶意程序的发现能力，配合各级行业主管部门做好监管工作。各相关单位要做好专项行动信息上报，采取多种形式加强用户网络安全宣传教育。
