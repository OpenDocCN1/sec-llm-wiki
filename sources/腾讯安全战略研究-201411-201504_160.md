# 动态 | “改签退票”电信诈骗手段现升级版

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=204770574&idx=3&sn=fc8a8b6616e2aa9b7d10df82e8b5c1e5&chksm=2f7ba3d1180c2ac7611957885ca52a30d2e971766e13ffba8533937e13d86a7454fc7632b263&scene=126&sessionid=1681324045#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=204770574&idx=3&sn=fc8a8b6616e2aa9b7d10df82e8b5c1e5&chksm=2f7ba3d1180c2ac7611957885ca52a30d2e971766e13ffba8533937e13d86a7454fc7632b263&scene=126&sessionid=1681324045#rd)

通过向多家知名网络搜索引擎、社交网站以及手机发布“400改签退票”虚假信息进行诈骗,导致很多出行旅客无辜受害。近日,辽宁省大连市警方打掉一个“400改签退票”电信诈骗团伙。办案民警向《法制日报》记者表示,此类诈骗手段有了升级版,犯罪嫌疑人会向被害人卡内汇入少量金额,以达到套取巨额现金的不法目的。

  

**对比海量数据锁定嫌疑人**

  

2014年10月13日,大连市民王女士将机票退票后,银行卡内的4万余元被盗,王女士报警后得知,在大连的被害人不止她一人。

  

2014年5月以来,大连市发生多起“400改签退票”电信诈骗案件,此类案件的犯罪嫌疑人通过向手机发送海量虚假退票信息或在各知名搜索引擎置顶虚假机票订购链接为主要手段,使很多乘机出行的大连市民无辜受害。

  

侦查人员通过调查案件中的资金流向,确定了所有案件的套现取款地点均在海南。由于关键破案线索必须在海南当地调取,2014年12月14日,大连警方抽调刑侦支队、网安支队、技侦支队经验丰富的民警成立专案组,赶赴海南进行前期调查。

  

经过大量排查,一个大量转移资金的案件引起了专案组的注意,警方决定以此案件作切入点深入侦查。在随后的调查过程中,侦查人员走访了20余家银行,调取相关涉案银行卡的ATM取款录像。警方发现,一名戴着帽子、口罩的男性在所有取款录像里反复出现。经过海量数据比对和侦查,警方最终锁定了犯罪嫌疑人王某,并确定了位于海南省海口市的诈骗窝点。

  

**紧盯模糊身影擒获嫌疑人**

  

专案组在海南警方的配合下,于2015年1月14日17时开始收网行动。

  

王某的住所在海口市某大厦,其中人员分布密集、混杂,给侦查人员实施抓捕带来较大难度。就在侦查人员摸排时,一个“熟悉”的身影在侦查员眼前一晃而过,但此时天色已晚,侦查员未能完全看清此人的脸。侦查员齐勇亮、郎兴国顾不得呼叫其他抓捕成员,紧跟大步走进楼里的男子,并和这名男子进入同一电梯,这才确认该男子就是犯罪嫌疑人王某。侦查员随后将王某抓获。

  

经讯问得知,其余两名诈骗团伙成员也将马上回到住所,专案组成员和海南警方迅速在房间内进行布控,最终将犯罪嫌疑人王某、梁某、符某全部抓获归案,并查获作案笔记本电脑两台、涉案银行卡13张、手机6部、电话卡15张、无线上网卡两个、无线路由器1个。

  

经讯问,3名犯罪嫌疑人对2014年10月13日诈骗大连王女士4万余元的不法事实供认不讳,并供述了自2014年3月起,他们利用虚假网络游戏Q币、机票改签退票等手段诈骗作案60余起。

  

目前,犯罪嫌疑人已被刑事拘留,此案正在进一步查办中。

  

**侦查员详解诈骗作案流程**

  

“‘400改签退票’电信诈骗犯罪嫌疑人通过发布虚假的网络订购机票、退票信息为主要手段,诈骗乘飞机出行的乘客。”办案民警齐勇亮向记者披露此类案件作案手段时称,嫌疑人主要通过多家知名网络搜索引擎、社交网站在线发布海量虚假信息诱骗被害人上当。

  

办案民警郎兴国表示,犯罪嫌疑人有时会通过在网络上购买旅客信息,如航班号、姓名、身份证号码以及订票时所使用的手机号码,向旅客的手机发送包含真实乘机信息的诈骗短信,谎称航班不能正常起飞,若退票、改签则需与虚假“400客服”联系。

  

据介绍,诈骗团伙组织严密、分工明确。犯罪嫌疑人通常一个月就更换所用作案“400电话”等通讯工具,并转移作案窝点。整个诈骗团伙通常会有丰富经验、非常健谈的“客服”人员,他们根据诸如让乘机人订购特价、低价机票,退票、改签等多种理由,按照预先编好的诈骗剧本进行“专业”解答,诱使被害人在电脑登录网银或在ATM机上按照其提示操作。

  

警方称,目前,“400改签退票”电信诈骗手段又有了升级,嫌疑人为了凑齐所谓的激活码数字,在被害人不知情的情况下往被害人的涉案银行卡汇入尾数金额,使被害人容易上当受骗。

  

诈骗得手后,犯罪嫌疑人为了防止涉案账户被冻结,往往会进行多次转账,在“拆整为零”后立即派取现成员在ATM上取款或者用非法购买的POS机套现。

  

警方提醒,目前正值春运高峰,广大旅客要通过正规渠道办理订购机票、退改签机票等手续,接到疑似诈骗电话或短信时应立即报警核实,尤其是对方要求向指定账户汇款时,千万不要汇款。（韩宇 张国强）
