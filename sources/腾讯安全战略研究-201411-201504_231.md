# 案件 | 生产比特币可挣钱？数千网友被骗近千万元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=204101864&idx=1&sn=9c2eb6c8605aa44f794558e09f646727&chksm=2f6576371812ff21795a929e2aacdf7c76f9622736653b5664e7465c6d29b26ef2aa52213ff5&scene=126&sessionid=1681324087#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=204101864&idx=1&sn=9c2eb6c8605aa44f794558e09f646727&chksm=2f6576371812ff21795a929e2aacdf7c76f9622736653b5664e7465c6d29b26ef2aa52213ff5&scene=126&sessionid=1681324087#rd)

数千名加入某网络语音平台上名为“星火娱乐”频道的网友发现，他们跟随数月的“老板”，连同网友们上交的近千万巨款一同失联。

  

**幕后老板突然失联**

  

昨天中午，该聊天频道中，大量网友正在统计各自先前交纳的费用，并有人提醒大家尽快报警。记者了解到，22日下午，收取了网友大量钱款的频道所有者“火哥”突然失联，手机关机，也不再上线。

  

经多位网友证实，“星火娱乐”频道出现于去年10月初，频道所有者为大家提供一种名为“科比比特币网络工厂”的软件，“说是只要在家挂机，就能生产比特币，然后给大家佣金，”并鼓励大家积极发展新成员，给予相应的奖励。随着人数的不断增加，从去年10月18日开始，新成员必须缴纳会员费才能进入，“一开始是每个软件30，后来是50元。”

  

一名女性网友表示，按照运行该软件所产生的“段”数，“火哥”会支付一定的佣金，如果只交纳会员费，每“段”的佣金最低只有0.24元，“当如果付费晋级信誉的话，佣金可以达到2元。”为了多挣钱，自去年12月中旬以后，不少网友交纳了每套软件1000元和1800元不等的晋级费。

  

多名网友表示，在本月15日之前，他们每天都可以通过支付平台收到佣金，“但15号当天，有人通知大家，由每天支付佣金，改为每周三由专用支付软件提现。”北京网友何先生称，他于17日交纳了2套软件的会员晋级费，共计3600元。然而，本周三，他却发现软件根本没法成功提现，“频道里又说推迟到周四，可是22日下午，人就联系不上了。”

  

**钱款打入雇佣账户**

  

据了解，频道的日常事务，通常由一位网名为“格子”的女网友打理，网友付款也会打到她所提供的支付宝账号上。

  

随后，记者与该网友取得联系。她表示，去年9月末，她与“火哥”在网络上相识，对方提出希望她帮助推广这个软件，“当时每天都会打给我100元钱，而且感觉是一个很正规的工作程序。”频道建立后，日常的事务基本全部交由她打理。开收晋级费后，网友上交的费用依旧打到她所提供的账号上，但每隔一段时间，“火哥”就会要求把钱转到他的账户上，“当时我也没多想，根本没想到他会跑。”至于钱款的数目，“格子”仅表示，21日上午11点曾给“火哥”汇过13万，其他并不方便透露。

  

多名网友证实，“星火娱乐”的会员数已经超过3万人，来自全国各地，其中交纳了信誉晋级费的会员数在6000人以上，且不少会员缴纳过多份费用，“保守估计，接近1000万。”

  

目前，已经有多名网友，向各自属地公安机关报案。
