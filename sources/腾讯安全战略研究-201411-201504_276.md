# 视点 | 为什么要关停黑卡黑号？

**网友“阿杰”：**

  

看到一条新闻，说国家要对“黑手机卡”动手整治了。不实名的手机卡有什么危害吗？为何要关停？

  

互联网黑产观察员（追踪最新的互联网安全热点，揭开网络地下产业链条的神秘面纱。）：

  

所谓的“黑手机卡”，就是指在开卡时没有经过实名认证而放出的卡。部分经销商为追求利益，审核不严格而导致的手机卡不实名。

  

说的通俗一点，很多路边的报刊亭都存有大量的身份证复印件，大家去办卡的时候，即便没有身份证，也能在老板的协助下，使用别人的身份信息成功获得一张手机卡。据统计，目前市面上非实名的手机卡用户约有1.3亿。

  

**“黑手机卡”有什么危害？**

  

据统计，近期公安部门参与破获的58起犯罪案件中，有51起的犯罪嫌疑人使用了非实名的手机卡、上网卡。

  

不法分子可以利用黑手机卡获利。冒用别人的身份证复印件，能够获取到大量的手机卡，然后以欠费的方式开通或购买各种虚拟业务专卖获利，直到手机卡因欠费太多被暂停使用为止。

  

不少电信诈骗也是用黑卡来实现的。此前有报道不法分子冒充快递员诈骗，骗取大额的钱财。即使报案后，由于诈骗电话号码的使用者并非开卡身份证信息的所有者，所以无法继续追查。

  

如果“黑手机卡”大量流出，那么在发生巨额欠费，或者有人被骗的时候，这些损失则难以追回；如果这些手机卡传播欺诈、淫秽、暴力恐怖信息时，公安机关也很难追查。

  

除此之外，“黑手机卡”还会被用来批量注册帐号、发垃圾广告、恶意刷取厂商优惠资源等。

  

**谁是“黑手机卡”的受害者？**

  

其中一个受害者就是互联网公司。一方面，不法分子可以利用互联网公司与运营商之间结算不同步来实现低额手机卡开通业务。

  

另一方面是对网络帐号体系的影响。很多人为了刷活动、做营销，使用“黑手机卡”大量注册社交网络账号，对互联网公司的帐号体系会产生很恶劣的影响，极大地增加了运营成本。

  

另一个受害方则是用户。对用户来说，最显而易见的就是骚扰。由于“黑手机卡”横行，我们每天被各种短信平台的群发短信骚扰，烦不胜烦。

  

对于用户来说，还有一个很严重的问题就是信用记录。如果你的身份证被人冒用办卡欠了一笔钱，这个信用黑记录就会记在你头上。等你去贷款的时候就会发现自己名下莫名多出几张手机卡，个个大额欠费。然后你需要申诉、证明（此处省略一百个流程）。

  

**用户应该注意什么？**

  

**第一，**严格保护个人敏感信息，例如身份证、银行卡、工作单位、住址、电话等等。尽量不要在陌生小网站上填入以上信息，在与陌生人聊天的时候，也不要随意透露。

  

**第二，**收到中奖短信、各种积分兑换短信后，及时主动通过相关官方联系电话核实信息真实性。收到的链接，不要随意点击，小心手机木马；要通过官方渠道、可靠市场安装APP。

  

**第三，**谨慎通过不熟悉的渠道购买非官方服务，避免被卷款、受骗。
