# 动态 | 贴吧实名制被关注 网络上违法犯罪打击力度加强

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=203687121&idx=1&sn=8193b97dda79f02fe326eb4f5f2c5bfd&chksm=2f6b2a0e181ca318a20a5612dae318cc7f3da680d9f711f7da6aec05d521349a491f6fc89399&scene=126&sessionid=1681324090#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=203687121&idx=1&sn=8193b97dda79f02fe326eb4f5f2c5bfd&chksm=2f6b2a0e181ca318a20a5612dae318cc7f3da680d9f711f7da6aec05d521349a491f6fc89399&scene=126&sessionid=1681324090#rd)

国家网信办昨日召开新闻发布会宣布，今年国家网信办将全面推进网络真实身份信息的管理，以“后台实名、前台自愿”为原则，包括微博、贴吧等均实行实名制，对此将加大监督管理执法的力度。据悉这是官方首次提出贴吧实名制。

  

**贴吧实名制被关注**

  

由于实名制涉及互联网企业相关产品，昨日北京商报记者联系了百度贴吧等相关涉事方，但截至记者发稿时，均未收到回应。业内人士分析，由于对企业来说意味着监管的加强并非好事，企业不愿做更多回应也不难理解。  

  

随着互联网以及移动终端的迅速普及，以微博、微信、贴吧等为代表的社交工具得到爆发式发展。不过，由于网络空间的虚拟特性，一些借助微信等工具进行虚假信息传播、诈骗等违法行为也越发突出。

  

昨日国家网信办公布50家网站、频道（栏目）以及微信公众账号被依法关闭，包括24家网站、9个网站频道（栏目）和17个微信公众号。据介绍，这些网站、频道（栏目）、微信公众账号被关闭的原因包括：假冒党政机关或媒体名义发布虚假信息；发布涉赌博、诈骗等违法信息等。

  

事实上，网络实名制传言已久，但因种种原因被搁置。国家互联网信息办公室去年发布的《即时通信工具公众信息服务发展管理暂行规定》提出，即时通信工具服务提供者应当按照“后台实名、前台自愿”的原则，要求即时通信工具服务使用者通过真实身份信息认证后注册账号。虽然这项规定主要针对公众号，且由于微博是社交类媒体，不属于即时通信工具产品范畴，所以微博不在此次范围内。一些互联网服务也曾试行过一段时间的网络实名制，比如新浪微博就曾要求用户填写相关实名内容。

  

“微博、贴吧实行实名制便于政府部门查出网络上的违法犯罪行为，是很有必要的。”**北京大学社会学系教授夏学銮**说，“后台实名、前台自愿”意味着前台可以使用实名或是使用昵称，但是后台注册必须实名制认证。需要指出的是，如何从技术设计上解决个人隐私问题是关键，否则微博、贴吧等实行实名制就是一句空话。
