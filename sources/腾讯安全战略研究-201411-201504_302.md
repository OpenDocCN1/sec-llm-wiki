# 打击 | 宁波打击通讯网络诈骗案千余起 冻结赃款333万

网络诈骗，近年来已成为影响人民群众安全感的突出问题。6日，浙江省宁波市政府召开的新闻发布会上，宁波市公安局副局长、新闻发言人王伟标表示，截止2014年12月20日，宁波全市各级公安机关破获通讯(网络)诈骗案件1808起，抓获犯罪嫌疑人305人，冻结赃款333.29万元。

  

2014年4月6日，受害人杨某在阿里巴巴网站上看到一个名为“山东名匠”的投资公司从事投资房地产短期过桥业务，称投资10万元30天能获利74500元。于是事主联系并尝试购买3000元，很快就收到了预期回报。

  

信以为真的杨某在4月8日至15日期间，先后通过支付宝打入约34万元，又于当月16日通过网银汇款1万元到该公司帐户。但自4月17日起，事主发现公司不再返还本金和利息，该公司网页也无法打开，于是报警。公安机关经过三个月的连续奋战，多次赴广东、福建等地，成功掳获两名犯罪嫌疑人。

  

两人交代了为诈骗他人钱财，用假冒的身份信息注册了一家名为“山东名匠”公司网页，并放在阿里巴巴上，以高回报的信息诈骗客户购买其虚拟的理财产品，一开始先按照约定返利给客户，以取得信任，待客户将大笔现金打入后，两人将网站关闭，套取现金。通过此方法，共诈骗70余人，共计100多万。

  

宁波市公安副局长、新闻发言人王伟标表示，当前，通讯(网络)诈骗犯罪的类型呈现多种形式。主要有虚构子女等出事、冒充熟人虚构事实、利用银行卡转帐、发布虚假中奖信息、冒充电信，公安等工作人员以及盗取他人QQ号冒用身份等七种形式诈骗钱财。

  

群众在遇到诈骗的短信或者电话时，千万要保持头脑清醒。公安部门建议:不要轻信来历不明的电话和信息，犯罪嫌疑人通过软件可以任意设置来电号码，要及时挂掉电话，不回复短信，不给诈骗分子进一步设圈套机会。其次，无论什么情况，都不向对方透露自己及家人的身份信息、存款、银行等情况，避免上当受骗。

  

受害人如钱财已被骗，立即拨打诈骗帐号归属银行的客服电话或登陆归属银行的网址以重复输错5次密码的方式，将该诈骗帐号冻结，达到止损目的，给公安机关争取宝贵时间。

  

记者获悉，截止2014年12月20日，宁波全市各级公安机关破获通讯(网络)诈骗案件1808起，抓获犯罪嫌疑人305人，打掉犯罪团伙17个，冻结赃款333.29万元，紧急止损被骗资金人民币237.4万元、美金60.08万元，并封停诈骗电话号码800余个，拦截境外诈骗电话100余个。
