# 打击犯罪动态 | 晋中抵制网络谣言共建网络安全新格局

**共筑网络诚信**

随着互联网技术的快速发展,网络谣言也如幽灵一般出现在人们的生活中。近年来,从“抢盐风波”到“地震传言”,从“微波炉辐射会致癌”到“艾滋病人针管刺人传播病毒”,从“指甲月牙越多越健康”到“孕妇必须穿防辐射服”,从“皮革制奶粉”到“西瓜打针”等等,网络谣言屡屡“发作”,影响着人们的正常生活。甚至有些人对未经核实的风言风语轻易相信,通过微博、微信、论坛、QQ群等方式肆意散播,严重污染了网络环境,扰乱了社会秩序,加重了社会转型期公众的焦虑与不安,影响极为恶劣。

案例

2013年8月24日,网民“李俊鹏”在腾讯微博发布一条名为“举报”的微博称:“榆次区怀仁村盖楼房死亡40多人。东阳赶集一下午丢50多辆电动车。”经晋中市公安局网警支队查证,此消息为网民“李俊鹏”道听途说、未经求证、随意发布,造成不良的社会影响。根据《中华人民共和国治安管理处罚法》第二十五条规定,榆次区公安局对李某某以利用互联网传播制造谣言的违法行为给予行政拘留5日的处罚。

今年1月14日,晋中市公安局网警支队在工作中发现,一网民在“百度贴吧灵石吧”发表一篇题为《中纪委即将介入调查灵石地销惊天大案,严惩腐败,还人民一个公道》的虚假帖文,之后部分网民连续跟帖转发相关内容。经查,该网民系我市灵石县居民杨某,所发帖文是其根据互联网信息,加自己主观臆断进行文字加工后发布的。1月17日,灵石县公安局依法对其作出行政拘留5日的处罚。

5月25日,署名为“量贩式人生”的网民在腾讯微博发表 “榆次西荣村发现有人感染H7N9,在榆次区人民医院抢救,参与抢救的医生已被隔离”的信息,市公安局相关部门立即对该信息进行了细致核查,并最终确认此信息属网络谣言。该局迅速锁定并抓获违法嫌疑人安某某,给予其行政拘留5日的处罚。

**原因**

针对网络谣言,记者采访了市城区多位居民。有市民对于散布网络谣言表示难以理解。市民张志华说,根本没有的事怎么就敢在网上乱说?居民李梓琳则表示,很多网络谣言与人们生活密切相关,在无法辨别真假的情况下,“宁可信其有”。“就比如孕妇要穿防辐射服,大家都穿了,为了安全起见,我也花五六百块买了一件。明知没什么用处,但求一个心理踏实。还有出现禽流感的信息,没有官方渠道辟谣,我也去和同事一起买了10袋板蓝根。”

网络谣言的肆意传播有其根源,记者通过对近年查处的散布谣言案件分析,主要是由市民法治观念淡薄引起的。造谣者一是对现实不满,企图报复社会。一些网民因家庭或个人方面的问题长期得不到解决,从而产生积怨,遂在网上发帖宣泄,意在扰乱社会秩序;二是自我炒作,提高关注度。个别网民抓住大众猎奇心理,在网上肆意编造谣言,以此吸引更多网民评论转帖,提高自己的网络关注度;三是人云亦云,盲目跟从。捕风捉影、似是而非的网络传言,很容易引起人们的关注,鼠标轻轻一点即可转发,一些喜欢参与网络讨论、跟帖的网民在有意无意间就成了谣言的传播者。

**问责**

在采访中,不少市民表现出这样的疑问,“在网上随便发个言,这都会犯罪啊?”据了解,对于在网上散布谣言,许多市民都不知道是违法行为。还有些市民表示,网上发泄情绪,不就和生活中吵几句嘴骂几次街一样,怎么就违了法?

带着市民的不解,记者采访了山西正名律师事务所律师李娅红。李律师介绍,网络散布谣言肯定是要负法律责任的。一是民事责任,如果谣言侵犯了公民个人的名誉权,依据我国《民法通则》的规定,要承担停止侵害、恢复名誉、消除影响、赔礼道歉及赔偿损失的责任;二是行政责任,如果散布谣言,谎报险情、疫情、警情,尚不构成犯罪的,要依据《治安管理处罚法》的规定给予拘留、罚款等行政处罚;三是刑事责任,如果散布谣言构成犯罪,则要依据《刑法》追究刑事责任。

晋中市公安局网警支队负责人也表示,去年以来,公安部和国家互联网信息办相继部署开展了多次打击网络谣言专项行动,对净化网络空间起到了明显的作用。我市警方也高度重视对网络谣言等违法行为的打击,对于在我市范围内出现的引发公众关注、引起一定社会恐慌的虚假网络信息,一经查实,将给予严肃查处。

**启示**

网络需要规矩,文明需要秩序。习近平总书记在主持召开中央网络安全和信息化领导小组第一次会议时强调,“做好网上舆论工作是一项长期任务,要创新改进网上宣传,运用网络传播规律,弘扬主旋律,激发正能量,大力培育和践行社会主义核心价值观,把握好网上舆论引导的时、度、效,使网络空间清朗起来。”习近平总书记的讲话为净化网络空间、共建网络文明提供了行动指南。

“谣言止于智者”。首先,网民要提高法治意识,树立良好的社会道德,加强自律,不信谣、不传谣,对于有疑问、耸人听闻或者违背公共秩序的言论不轻易转发,不要成为网络谣言的推手,更不做网络谣言的制造者。其次,要依法管理网络,从源头遏制谣言。依法管网不仅要重视管好新闻信息源头的生产,还要重视传播流通过程的引导和维护。网站运营商必须设置专人对网络信息进行核实后,才能公开发布。第三,要严厉打击利用网络传播谣言的行为。谣言的泛滥成灾影响社会的安定团结,只有严厉打击,才能让一些居心叵测的人有所畏惧而不敢轻举妄动,也只有严厉打击,让违法者付出沉重的成本时,其不法行为方能收敛,从而还社会以安宁,还网络以清静。
