# 警惕 | 全是套路！告诉你多级分销欺诈的真相！

![](../Images/48a0ae13367236e01b1a2567287139ea.png)9月12日，微信公众平台发布了《关于整顿新型多级分销欺诈行为的公告》（以下简称“公告”），《公告》中明确指出，针对通过微信公众帐号、利用微信关系链发展下线分销进行盈利，或诱导用户关注、分享的行为，将对帐号采取限制功能、永久封号等处罚。 《公告》发出后，不少不明真相的吃瓜群众表示好紧张。那么问题来了，到底什么样的行为属于“新型多级分销欺诈行为”呢？ 这里，雷霆小哥给大家讲几个用户的真实故事，详细解读这一次的《公告》规则。看过你就知道，这里面满满的都是骗人的套路。  
**一**多层消费佣金返利，朋友圈多位好友“沦陷”  
成都张女士最近经常看到好友王小姐在朋友圈分享一个“XX云商”的商城链接，王小姐说自己在这个商城消费了398元买了一套床上用品，邀请张女士点击链接并关注。 ![](../Images/2c404f653725fc39ef6b36f8c5cf6ac1.png)  
王小姐说，只要张女士通过王小姐的ID消费了商品，王小姐就能获得10%的推广佣金，同理，张女士在消费后可以邀请其他好友通过自己的ID消费并获取相应佣金，而王小姐作为张女士的引路人，也将获得20%的佣金。 听起来，这好像是一个不仅能买买买，还能拉着好朋友一起赚钱的好机会。但其实，这背后就是“多级分销”的逻辑。这种消费后发展下线，多层返佣获利的模式，实质上就是收取“入门费”和“团队计酬”的特征，与非法传销是类似的。  
**二**网络金融互助，都是贪婪惹的祸  
北京的赵先生近期被朋友推荐关注了某国际金融互助平台的公众号，并花费200元购买了该平台的“注册激活码”，然后通过会员之间匹配打款的方式“相互帮助”，来实现金融资源的分享。大致规则如下图：  
![](../Images/788e74cc8086fb163673809aae0df5bf.png)  
  
然而，一个月后，这个平台的项目崩盘了，赵先生和朋友砸进去的20万全部打了水漂，他们想要维权，却发现对方已经跑路。 在这样的网络互助金融骗局中，投资用户所得利润是以新入场投资用户的资金为支撑，新入场投资用户“帮助”前人获得对应利润，实现投资增值。 这样的骗局不难识破，而用户往往因为贪婪而不能自拔，最后导致巨额财产损失。  
**三**大众创业，玩手机赚钱的谎言怎能信？  
![](../Images/e833778d8771e8c4f9b6818f4f65e26a.png)  
今年5月，徐州警方在腾讯安全团队的大力配合下，侦破“星火草原”特大网络传销案件，涉案资金2亿余元，涉及人数150多万。 参与者刘女士表示自己最初是被“玩手机赚钱”等激励口号引诱，一狠心支付600元成为“全国代理”，从而取得发展下线的资格。 此后，为获取高额提成，刘女士不断游说身边的亲友加入，并成为她的下线，每次均可按照一定的比例获取返利。接着刘女士的下线再通过传销团伙制定的规则发展其他下线，如此往复…… 可见，“星火草原”本质上就是建立在一套多层分销系统的基础上，大肆推广新型传销模式的违法犯罪行为。 因此，我们郑重地提醒大家，天上不会掉馅饼，面对所谓“低投入、高回报、会员招募”等内容的项目要尤其警惕，如果还涉及到“拉人头”“会员制”类似模式，一定要认清本质，千万不要加入。遇到可疑情况请及时投诉，避免更多人上当受骗；遭受侵害时，一定要及时向户籍地或涉嫌诈骗帐号主体所在地公安机关报案，通过法律途径维护权益。 对于不法分子利用微信平台从事多级分销欺诈、高额返现返利欺诈等违法违规活动的，腾讯也将持续加大打击力度，绝不留下任何可乘之机！  
附录微信公众平台关于整顿新型多级分销欺诈行为的公告近期，平台发现有用户利用微信关系链，通过微信公众帐号实施多级分销欺诈行为，发布分销信息诱导用户进行关注、分享或直接参与。此模式多数包装为新型商业模式、创新金融产品、互助扶贫、国家帮扶计划等，本质在于利用关系链发展人员，形成多级上下线关系，按照下线人数或者销售业绩计算盈利，与传销行为类似，一定程度上具有金字塔欺诈、庞氏骗局等特征。 对于上述欺诈行为，平台近期收到大量用户的投诉。为了维护广大用户的利益，维护公众平台的良好生态，依照《微信公众平台服务协议》、《微信公众平台运营规范》，一经发现存在此类行为的帐号，微信公众平台将对其进行限制帐号部分功能直至永久封号处理，并有权拒绝再向该运营主体提供服务。 群众遇到此类欺诈行为遭受侵害时，应当第一时间通过法律途径，向户籍地或涉嫌诈骗帐号主体所在地公安机关报案，腾讯将积极协助公安机关依法处理。违规示例1、通过发展人员形成上下线关系，依据下线人数、销售业绩等为依据计算和给付上线报酬。![](../Images/d0a70fc2c200f38f89e29be6cb46a7ee.png)2、以金融互助、贫困帮扶、代理权限等方式诱导用户滚动发展下级人员。![](../Images/e300596995150ebcf7e6b980bf680a84.png)3、下线人员交纳费用或以认购商品等方式变相交纳费用才能取得加入或者发展其他人员加入的资格。![](../Images/90c0d9b68c386b5489b7b5530a719dfa.png)
