# 警惕 | 公安部刑侦局：警方出动1100名警力，抓获253人，出了什么大事！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=2652699174&idx=2&sn=c1c27b9a4005c52d55ef20ea5b6a2c7c&chksm=bd53d4f98a245defa5c2d2406be85e74248b1600b8308f211339ea5902caea056fab4d145711&scene=126&sessionid=1681323659#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652699174&idx=2&sn=c1c27b9a4005c52d55ef20ea5b6a2c7c&chksm=bd53d4f98a245defa5c2d2406be85e74248b1600b8308f211339ea5902caea056fab4d145711&scene=126&sessionid=1681323659#rd)

2015年下半年以来，深圳警方陆续接到群众报警称被深圳的几家公司骗取钱财。深圳警方随即开展调查，经查，一个涉嫌网店代运营的特大诈骗犯罪团伙渐渐浮出水面。该诈骗团伙通过注册的深圳某信息公司等20余家公司在网络搜索引擎上投放网店代运营广告，并进行虚假宣传，对外谎称是多家成功网络电商的运营公司，并承高额收益，骗取一大批网店事主的信任。![](../Images/951a888bcac0386b0549f40389a4912e.png)之后，诱骗受害人签订事先设定好的诈骗合同，以首期服务费用作为主要诈骗目标，承诺帮助受害人进行网店代运营，受害人一旦签订合同并交纳首期费用后，诈骗团伙便采用多种手段故意拖延时间，并不断催促受害人继续缴纳下期服务费用，而事实上并不真正实施运营。待受害人发现被骗后索回款项时，该团伙便以各种理由拒绝，或者直接不与受害人联系。![](../Images/bf9faeb98b23225acaa9aae2b89bf03e.png)经过长达半年的侦查，今年6月13日上午9时，深圳警方果断出击，出动1100余名警力开抓捕行动。![](../Images/d479ec5400760f86d86a0269d6d10057.png)截至目前，警方已抓获以江某、熊某和顾某为首的253名犯罪嫌疑人，清查电脑872台，扣押合同、培训资料、业绩报表等一大批书证，冻结涉案账户85个，冻结涉案资金人民币2300余万元。![](../Images/0036cdb6f09ae1be71afce7025e905f2.png)  
案例深圳的刘先生是一名自由职业者，一天他在网上无意间搜索到一条消息，内容是轻松变成淘宝店主，他把电话留在了网站的消息栏里后，一名自称某某代运营公司的客户经理便打来电话，该经理鼓励刘先生投资开设淘宝店，刘先生表示，时间紧张不方便做，经理随后详细介绍了该公司的“过人之处”，她告诉刘先生只要交一定的费用后，该公司会全程帮刘先生进行打理，其中包括每天帮着看店里，帮他与顾客谈价钱帮卖东西，然后刘先生只管等着收钱就行。还包刘先生三皇冠，帮装修店铺、三个月装修一次，还有提供服务、提供货源等等“优惠政策”，刘先生听罢便动了心，交了1万元的第一季度费用后，双方开始合作，但几个礼拜过去了，刘先生根本联系不上该公司的经理，发现被骗的刘先生这才报了警。![](../Images/58e1d912014db7d77fb69d93a2b93906.png)包括刘先生在内的所谓“加盟商”，遍布全国各地，并且都有自己的本职工作，选择加盟的初衷，基本都是想利用闲暇时间，做一份兼职工作。但是，交了钱以后，对方的态度就发生了很大转变，有的要求继续投钱，有甚者就根本联系不上了。诈骗手法  
★第一步骗子在网上发布虚假投资广告或冒充美女客服与被害人取得联系，以投资的方式，引诱被害人开设网店，吸引受害人通过委托代运营公司投资开设网店。![](../Images/8085ec611074a4b3a0f69e69d6eaf9f7.png)  
  
第二步在取得了受害人的信任后，骗子先和受害人签约一定数额的销售额，收取服务费、货源费、技术费，并声称不达标就退款。一般约定的销售额很诱人，且以月、季度为标准进行收费。![](../Images/ef685a4b6c2f322750cd522268d50aae.png)  
  
第三步开始交费阶段， 首付、第一次续费、第二次续费、第三次续费……一年下来少的几万块，多的要几十万，很多小加盟商因为根本达不到预期的收益，到了第二、第三次续费就无力交付了，前面的钱也就不了了之了，更有甚者收款后，不提供任何代运营服务。![](../Images/8d7ce59f6163f56a21cffe391d27cc8b.png)  
这种投资就跟“无底洞”一样，只要受害人交了第一笔钱，就会被骗子牵着鼻子走，直到受害人付不起后期费用，自动放弃前面投进去的钱而结束。  
  
切记![](../Images/415ff12cdaf83db52fbdf764da0e05c3.png)**警察蜀黍提醒：**如何防止被骗识别办法一：看这家公司究竟有没有托管的成功事例。辨别公司真假，其实只要要求他们拿出真凭实据来证实就可以了。这里的真凭实据，不是可能PS过的截图，或者哪家公司随口说的案例，这种都是不可信的。而是要求这家公司实实在在的当着你的面打开后台(或者远程)，展示给你看的后台数据。凡是不敢给你看后台的，基本上都是骗子，因为他们的案例都是虚假吹嘘的。 识别方法二：看这家公司是否是官方合作商。做为与淘宝备案并且成为淘宝官方合作的服务商而言，必须严格按照规定办理备案流程，但是对于诈骗公司来讲，他们不会去进行繁琐的备案合作流程。
