# 案件 | 海南两女主播疑直播吸毒为好玩，该当何罪?

![](../Images/48594775b7cb3ccdb48f673a411fa73f.png)现在，各式各样的网络直播日益走红，于是也催生了一项新的职业———网络主播，这些以网络作为传播平台而进行直播活动的主播们，在互联网上也有着各自庞大的粉丝群体，而这些主播们所直播的内容，也是五花八门，有唱歌跳舞的，有吃饭睡觉的，还有各种搞怪逗乐的。而就在12日，有不少网友反映，他们在一款网络直播软件里观看直播时，竟然有一名网络主播，疑似在直播中吸食毒品。这到底是怎么回事？ 接到举报后，海口龙华警方十分重视，立即根据相关线索展开调查，并在6月14日上午掌握了视频当中1名女子的行动轨迹，确定了其居住地址，随即展开布控，在其房间内抓获2女1男，尿检结果显示3人均有吸食K粉的行为。 记者从海口警方获悉，视频中直播的两名女子之一已被警方控制，年仅19岁，自称直播时吸食的实为面粉，之所以谎称吸毒是气姐妹男友。![](../Images/e397af9b5a92a50834dbdfc83b8d8945.png)  
女子兼职多个平台视频直播“现在整个村子都知道我直播吸毒，父母也因此不理我，我觉得自己玩大了。”曾某说，她平时在酒吧负责销售工作，兼职在多个平台做视频直播，内容就是聊天，平时有空就做，最多的时候连续直播过两天，这样会给她每月带来一千多元的额外收入。平常直播时的观众大约100人，而“直播吸毒”当天的观众达到2000多人。 曾某称，自己确实有吸毒史，第一次吸毒是在酒吧给朋友过生日时体验的。而视频中的另外一名女子娇娇，是自己在三个月前给朋友过生日时认识的。 据警方介绍，曾某在今年一月份曾因吸食K粉被警方处罚过，这次她因再次吸食k粉，将被行政拘留15天并社区戒毒三年。 目前此案还在进一步侦办中。在网上直播吸毒行为，可能会受到什么处罚？ 吸毒是一种违法行为，吸食、注射毒品的，将受到以下处罚。 根据《中华人民共和国治安管理处罚法》： 第七十二条有下列行为之一的，处10日以上15日以下拘留，可以并处2000元以下罚款；情节较轻的，处5日以下拘留或者500元以下罚款： （一）非法持有鸦片不满200克、海洛因或者甲基苯丙胺不满10克或者其他少量毒品的；（二）向他人提供毒品的；（三）吸食、注射毒品的；（四）胁迫、欺骗医务人员开具麻醉药品、精神药品的。 根据《中华人民共和国禁毒法》： 第三十八条　吸毒成瘾人员有下列情形之一的，由县级以上人民政府公安机关作出强制隔离戒毒的决定： （一）拒绝接受社区戒毒的；（二）在社区戒毒期间吸食、注射毒品的；（三）严重违反社区戒毒协议的；（四）经社区戒毒、强制隔离戒毒后再次吸食、注射毒品的。 对于吸毒成瘾严重，通过社区戒毒难以戒除毒瘾的人员，公安机关可以直接作出强制隔离戒毒的决定。 吸毒成瘾人员自愿接受强制隔离戒毒的，经公安机关同意，可以进入强制隔离戒毒场所戒毒。  
网上直播吸毒，可能会构成引诱、教唆、欺骗他人吸毒违法犯罪行为，将受到以下处罚。 根据刑法第353条第1款之规定，犯本罪的，处三年以下有期徒刑、拘役或者管制，并处罚金；情节严重的，处三年以上七年以下有期徒刑，并处罚金。第3款规定，引诱、教唆、欺骗未成年人吸食、注射毒品的，从重处罚。
