# 动态 | 网络非法集资案层出不穷 群众损失惨重

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=2652699044&idx=3&sn=24a15a9e6c495d9459f3f47e17d5ce86&chksm=bd53d77b8a245e6dea092d6474d82b6e108475b92426aa27fc0b36da13bd9165c32be8ad19c8&scene=126&sessionid=1681323668#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652699044&idx=3&sn=24a15a9e6c495d9459f3f47e17d5ce86&chksm=bd53d77b8a245e6dea092d6474d82b6e108475b92426aa27fc0b36da13bd9165c32be8ad19c8&scene=126&sessionid=1681323668#rd)

网络非法集资案层出不穷群众损失惨重苏州警方搭建防控非法集资信息化平台时至今日，江苏苏州市民王先生仍难以理解，自己怎么会两度陷入非法集资的漩涡？一次是e租宝，一次是泛亚有色，原本盼望高息回报改善生活，如今却面临数十万元投资血本无归，“天上不会掉馅饼，说得真是一点没错”，他感慨道。 当前，非法集资案件高发多发，特别是以互联网金融、网上理财等为幌子进行的网络非法集资案件层出不穷。苏州作为经济较发达城市，长期以来都是不法分子非法集资的重点地区。 《法制日报》记者近日在苏州采访了解到，针对非法集资新形势新变化，苏州公安创新思路，主动应对，坚持打早打小，推动建立“涉众型经济违法犯罪案事件信息共享平台”，探索从业人员黑名单制度等，有力打击预防了此类犯罪，维护了人民群众合法权益。网络非法集资爆发式增长4名大学生，在苏州租了几间房，以开展电子商务为名设立“百家和购物网”，网站不卖产品，群众只要充值就可以成为会员，充值越多返利越高，最高年利率达76%。暴利的诱惑，在短时间内吸引了全国1万多人参与其中。 这是苏州公安4年前打掉的一起网络非法集资案件。此后，苏州网络非法集资案件呈现爆发式增长，目前已成为当地非法集资的主要形式。 为何非法集资纷纷触网？苏州市公安局经侦支队副支队长赵建中分析说，网络已成为人们生活的一部分，互联网金融又是当下热门产业，以此开展不法活动具有更大的传播效应，“传统非法集资案件受害者大多几十人、百把人，涉案金额上千万元已经很大了，而网络非法集资案件动辄成千上万人，涉案金额常以亿计”。 在市局经侦支队二大队教导员徐明看来，线上线下联动，更具欺骗性、迷惑性，不法分子打着金融创新的旗号，大打虚假广告，加上线下业务员的忽悠，很多老百姓特别是老年人极易上当受骗。 记者从苏州警方提供的已查处案件的证据材料看到，不法分子推销网络非法集资产品颇有“套路”：往往宣传产品有官方背景，比如某国有企业参与其中；聘请一些演艺明星为其站台；声称产品由担保公司担保或已投保险，资金万无一失。 让赵建中颇为担忧的是，除“百家和”等少数案例外，苏州绝大多数网络非法集资均为“侵入型”，即外地公司在苏州设立分公司或代理公司开展非法集资，资金直接打入外地公司，苏州警方核实其违法性非常困难，而一旦出现问题，警方即便立即查封分公司也难以冻结到资金。 “实践中，很多网络非法集资案件，群众的整体损失都在五六成以上，有的甚至高达九成。”赵建中说。做到早发现早预警早处置2014年5月，苏州工业园区公安分局在排查中发现，一家投资公司以网络理财的名义吸收公众存款，资金量最高峰时达3.6亿元。警方将此信息录入“涉众型经济违法犯罪案事件信息共享平台”，经相关部门核查，该投资公司名下没有像样的实体，吸收来的资金只投资了2套普通房产，有非法集资之嫌。 工业园区党委政府从“信息共享平台”中了解到情况后，立即采取了政府约谈规范、挤压缩小、勒令退赔等措施，成功将该投资公司吸收的资金从3亿余元缩减至800万元，同时监管账户冻结资金1000万元，将资金风险降到了零。 为防范和及时查处非法集资案件，最大限度避免群众财产损失，2013年，苏州市公安局和市金融办牵头搭建了“信息共享平台”，工商、税务、住建等18个政府部门入驻，实现对涉众型经济违法犯罪早发现、早预警、早处置。 “正常的互联网投资理财是法律所允许的，不能仅仅因为企业存在高息吸存就断定为非法集资，但如果等到资金链断裂再查处又为时太晚。”赵建中说，“信息共享平台”设立后，民警将搜集到的可疑信息录入平台，工商部门核查是否存在虚假广告，银监部门核查资金流向等，通过整合数据动态预警监测，一旦亮起“红灯”，立即采取挤压、打击等措施。 据了解，“信息共享平台”是一个由多个内外信息平台无缝对接的大数据平台，可通过内外数据碰撞对比预警，如与人民银行信息平台对接建立涉众型经济案件可疑资金模型，实现对企业资金的动态监控，防患于未然。 2014年的时候，苏州商铺售后包租现象突出，年租金为商铺售价的10%甚至更高，连续多家企业出现资金链断裂，群众反映强烈。苏州市公安局借助“信息共享平台”认真研判，拿出综合性解决方案上报市政府，最终促成相关部门出台规章要求售后包租企业必须自持30%的商铺并交纳一定的保证金，此后，再未出现新的因售后包租导致的非法集资案件。黑名单制度防止从操旧业徐明告诉记者，网络非法集资群众损失难挽回，很大程度上是因为资金被“层层剥皮”，从总公司到分公司，从业务经理到业务员都要分一杯羹，“群众投入10万元，经过各道提成，最终到账的可能只有七八万元了”。在苏州查处的多起网络非法集资案件中，业务员的提成是涉案公司的最大支出。 虽然非法集资的成功与否和这些业务员的“努力”密不可分，但司法实践中，业务员被惩处的却寥寥无几，他们通常以“不明知”为由推脱，“我们对e租宝苏州分公司不少人采取了强制措施，但最终进入司法程序的不会太多”，赵建中坦言，惩处力度不够，这些人很容易重操旧业。 为此，苏州公安目前正在探索建立非法集资从业人员黑名单制度，民警在调查过程中明确告知其行为涉嫌非法集资，收集相关信息录入黑名单库，对仍不收手的依法严厉打击惩处。 “这两年网络非法集资案件高发，与从事投资理财的公司注册过于简单、泛滥成灾有一定有关联。”徐明认为，这类公司不宜实行零资本注册，应提高准入门槛。 赵建中提出，对实施吸收公众存款行为的企业，应建立申报制度，企业定期向相关部门申报自己的财务状况，以及理财产品、债权、盈利能力等详细信息，相关部门根据申报进行核实。 “目前，苏州很多涉嫌网络非法集资的企业，由于其本部不在苏州，警方很难查证其宣称的理财产品、债权等是否真实存在，非常不利于及时打击预防。”赵建中说，应该完善相关法规来解决这一问题，或赋予相关部门调查核实的权限。 苏州姑苏公安分局经侦大队副中队长朱琛彦接触大量受害者发现，不少群众在参与非法集资前，已感觉到公司可能存在问题，但面对高额利息，仍然想搞短频快，刀口上舔血，最终懊悔莫及，“公安、银行、工商等部门应当进一步加强宣传，特别是针对容易上当受骗的老年人群体，提升对非法集资的辨别能力和危害的认识，消除侥幸心理”。  
法官说法：  
办案中做好受害群众安抚工作 刘玮（苏州市姑苏区人民法院刑二庭副庭长）：非法集资案件近年来呈现不断上升趋势，2013年以来，我院已受理此类案件30多件。此类案件往往涉案金额比较巨大，受害群众人数较多，我院审理的案件中，涉案金额最高的一起逾亿元，被害人达数百人。 司法实践中，审理此类案件存在多重困难： 

*   一是金额认定困难，一起案件的受害人较多，且每人少则几笔多则几十笔投资，每一笔投资都需要审判人员审核。
    
     
    
*   二是追赃困难，由于犯罪分子非法集资活动时间相对较长，且多为资金链断裂或无力还贷，特别是有的案件直到犯罪分子潜逃才案发，导致追回赃款难度极大，实践中追赃比例较低。
    
     
    
*   三是一些受害人对案件处理结果不理解不支持，有些受害人明确表示不希望司法机关查处犯罪分子，希望犯罪分子继续进行非法集资，从而有资金对自己还本付息；有的受害人在无法追回赃款的情况下，情绪激动，难以抚平，成为涉诉信访人群，影响社会安定。
    
     
    
*   四是案件难度高、办理周期长，一方面，涉案人员大多因其犯罪性质或到案时间不同分案处理，影响了审理效率；另一方面，由于非法集资犯罪形式复杂，特别是近年来随着国家对金融市场管控政策的不断调整以及互联网金融的快速发展，犯罪更具欺骗性、诱惑性，且部分涉案企业账目混乱，有的甚至没有账目，使得资金的流向查证与追缴难度高。
    

 为审理好此类案件，我建议：除了法院与相关部门的沟通协调外，加强地区之间司法机关的协调，非法集资案件往往跨地区，有的甚至是全国性的，各办案机关要在证据搜集、投资群众申报赃款、追缴打击尺度等方面统筹协调。办案法官要加强金融、统计、公司运作等专业知识的学习培训，准确区分非法集资涉案人员责任大小，对于集资诈骗的首犯从严从重打击，对一般业务员以其实际作用认定责任大小，体现宽严相济、罚当其罪、积极返还从轻、拒不返还从重原则。 要进一步做好追赃工作，最大程度挽回投资群众损失。集资诈骗罪取消死刑后，如何更好地体现罪刑相适应原则以及做好受害群众的安抚工作是当前人民法院和相关机关需要重点思考的问题。
