# 微评 | “风靡”2016年初的那些谣言 真相背后有何反思

新媒体时代，互联网成为人们表达情感、反映诉求及进行思想碰撞的舆论场，但网络谣言往往也浑水摸鱼，变身成为话题、新闻等形象被广为传播。下面这些曾“风靡”2016年初的谣言，在后续严谨地调查下均成泡影。这些谣言在被盛传的当时，很多人都曾见过、听过、信过甚至传播过、议论过。但真相揭开之后，反思往往更重要。缺乏事实依据凭空捏造类谣言   谣言1：“上海女孩逃离江西农村”

  

春节前夕，一位自称是上海女孩的网民在某网站发帖并配图《有点想分手了……》称：春节前去“男朋友”家乡江西过年，被“第一顿饭”吓得逃离。该网帖在春节期间迅速成为舆论热点被网友疯狂转发、评论。一时之间，关于城乡差异、贫富差距甚至是家庭伦理等问题都因此贴成为人们热议的话题。

 后经调查，“上海女孩逃离江西农村”事件从头至尾均为虚构。发帖者为上海周边某省人士，因在春节前与丈夫吵架，不愿回丈夫老家过年而发帖宣泄。  
   谣言2：《春节纪事：一个病情加重的东北村庄丨返乡日记》  
春节刚过，一篇以“媒体调查”为切入点的《春节纪事：一个病情加重的东北村庄》在微博及朋友圈被疯狂转发。文中描述诸如父亲濒死儿子却用低保金“行乐痛快”、农妇组团“约炮”、媳妇辱骂婆婆、低保夫妇不顾儿子常年酣战牌桌等一系列现象。文章发出后引发舆论一片哗然，文中对东北农村的描述让“东北”“农村”“婆媳”“留守”等话题成为人们茶余饭后的热点，将信将疑者有之，不以为意者有之，但对于此类话题的评论却趋向负面。 记者调查让真相浮出水面：返乡日记并非作者真的回乡调查，文中所有的“真相”均为作者虚构。乡亲们见到调查记者时第一句话就说：我们快委屈死了！  
微点评

  

这种无事实依据、无调查研究而凭空捏造的“原创类”谣言，无论是出于泄私愤而制造的话题，还是脱离调查的凭空捏造，伤害的不仅仅是文中提及的当事人及区域，还波及了与此相关或相似的群体。互联网为网民发表个人言论提供便利，但更需要网民在发表、传播言论时遵守相关的法律法规，加强道德建设、提高自律意识，自觉营造、维护良好的互联网言论空间，让情绪在理性、客观、真实的环境下进行表达。

基于社会突发性新闻而产生的谣言   谣言1：港澳高速岳阳段油罐车爆炸死78人伤66人

  

3月19日晚20时40分许，京港澳高速岳阳段一辆汽车发生爆炸，有网民在微博上散播消息称“京港澳高速岳阳段油罐车爆炸，死78人，伤66人”。经调查，文中所涉伤亡数字均为虚构。

  
   谣言2：男子谎称假疫苗流入某市引发恐慌  
3月初，陕西省男子罗某因对商洛某医院不满，在看到近期引起热议的疫苗事件后发布网贴称“3.6亿假疫苗流入陕西，商洛市商州区医院用量最大”，迅速引发多人关注，网民点击查看量达到1200多次，在一定范围内引起群众恐慌，造成很坏的社会影响。  
微点评

  

有大事，多谣言，这似乎成了定律。这类谣言出发点各不相同：或营造恐惧情绪、或渲染紧张气氛、或炮制重大伤亡筹集所谓“善款”等。该类谣言都有一个共同的特点：未经核实、无端夸大、歪曲事实甚至指鹿为马。谣言不仅无益于受众了解真相，更会在重大事件发生之后因信息误导、矛盾激化等问题给社会及人民群众带来次生伤害。

  

面对突发事件，政府和媒体要主动担负起社会职责，积极主动地发布权威信息公开真相，满足公众知情权；网民在转发重大突发事件相关消息时更要自觉自律，不造谣、不信谣、不传谣，有效维护良好的网上传播秩序。

基于大众关注的话题而产生的谣言   谣言1：北京2016年摇号新规定

  

2月17日，一则题为《北京2016年摇号新规定》的新闻刷爆“朋友圈”，稿件来源署名为：中国汽车流通协会。内容涉及多项北京市小客车摇号政策。

  随后中国汽车流通协会副秘书长罗磊表示：协会从未发布过类似消息。  
   谣言2：办理结婚证需缴纳二胎保证金

  

2月13日，网上有传言称“新人办理结婚证时，需缴纳二胎保证金，金额从5000元到8000元不等，生育二胎后再返还”。该微博引发热议，3小时内被转发近万次。

 随后该微博被删除，调查发现，文中所提“保证金”是从少数地区实施过的“不生二胎保证金”而来。国家卫计委相关工作人员表示，“收取二胎保证金一事纯属谣传，也并未出台任何相关政策。”  
微点评

  

小汽车摇号、“二孩”生育等政策制定与百姓生活密切相关。在政策调整之前，与此有关的谣言在各地开始甚嚣尘上。假借官方发布是造谣者制造并传播此类谣言的惯用手段。该类谣言不仅误导公众视听，同时对未来相关政策的制定及出台造成不利影响。

  

谣言成于无道者，传于轻信无察者，但终究止于智者和治者。网民在进行信息传播过程中，要确保关注信息发布来源可靠，不捕风捉影，共同营造健康、真实、透明的清朗网上空间。
