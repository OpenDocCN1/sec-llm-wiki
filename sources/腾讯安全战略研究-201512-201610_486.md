# 安全 | 吴沈括：NIS Directive(1):欧盟机构就网络与信息安全指令达成协议

## 吴沈括：北京师范大学法学院副教授、法学博士、硕士生导师。

## 鸣谢：意大利米兰大学法学院博士研究生董妍为本文写作提供境外一手文献资料。

  

**前言**

  

当地时间2015年12月7日晚间，比利时布鲁塞尔。欧洲议会（European Parliament）、欧盟理事会（EU Council）与欧盟委员会（EU Commission）就网络与信息安全指令（Network and Information Security Directive，下称NISD）诸项事宜达成政治协议，为后续出台网络安全领域第一部欧盟级别的统一规范铺平了道路。

  

## 一政治协议的背景

  

历史地看，欧盟地区一直是网络犯罪的重灾区之一：根据欧洲网络犯罪中心（EC3）2014年的统计数字，12%的欧盟居民曾遭受网络欺诈，而43%的欧盟居民曾因为网络攻击而无法及时获取在线服务。

  

鉴于此，欧盟通过2013网络安全战略（2013 EU Cybersecurity Strategy）就确保网络信息的安全以及数字化统一市场（DigitalSingle Market）的培育等一系列事项规划了未来的制度蓝图。在其基础上欧盟委员会于同年提交了关于在欧盟建设高水平网络信息安全的指令草案。2014年3月，欧洲议会就草案一读并完成投票程序，而欧盟理事会则于2015年12月4日在卢森堡轮值主席国期间通过了正式的机构磋商授权，欧盟三机构最终在本月形成了前述制度合意。

  

## 二指令影响的行业

  

基于该协议的效力，在形式上，NISD的规范文本即可等待欧洲议会与欧盟理事会的正式批准，一旦完成相关程序，经欧盟官方公报公布后即产生效力。后续而言，欧盟28成员国有义务在其内国法层面于21个月之内落实指令引入的各项制度设计，并且在27个月之内划定指令主要涉及的主体适用范围，也即所谓的“基本服务经营者”（Operators of Essential Services）。

  

除非意外因素介入，NISD条文会如期正式生效，欧盟地区统一的有关网络安全的顶层设计规范将在近期首次浮出水面，其制度价值自是不言而喻。概括而言，该指令的宗旨在于：（1）促进欧盟成员国的网络安全能力建设；（2）提升各成员国之间合作水平。

  

为此，在规范应用的主体层面，NISD将其适用的重心指向上述各类基本服务经营者，特别要求他们承担“采取合适的安全措施并且向其主管国家机关报告相关安全事件”的作为义务。从目前掌握的资料来看，我们认为至少下列8类“在一国经济社会中占据重要地位的”行业可能将受到直接的影响：

  

*   能源，包括电力、石油与天然气等；
    
*   运输，包括航空、铁路、水运与陆运等；
    
*   银行，包括信贷机构等；
    
*   金融市场基础设施，包括交易所与交易对手等；
    
*   医疗，包括医疗服务提供者等；
    
*   水务，包括饮用水供应与分销商等；
    
*   数字化基础设施，包括互联网交换基站、域名系统服务提供商与顶级域名登记等。
    
*   数字化服务提供商等。
    

  

此外，值得注意的是，NISD对于上述数字化服务提供商（Digital Service Providers,DSPs）做了进一步的细分，具体包括：（1）在线市场（OnlineMarketplaces）提供商；（2）云计算服务（Cloud Computing Services）提供商；以及（3）搜索引擎（SearchEngines）提供商等。

  

## 三制度设计的核心

  

如上所述，NISD各项规范的宗旨在于强化能力建设和提升合作水平，也正是这两点构成其制度设计的核心所在：

  

*   一方面，NISD要求欧盟各成员国在其内国法层面筹划颁行本国的网络与信息安全战略，并据此明确各国在网络安全领域的战略目标以及相应的规制政策与规范措施。此外，成员国还应当依据NISD指定一内国职能机关负责落实、执行指令的各项要求，同时组建计算机安全事件响应工作组（Computer Security Incident Response Teams, CSIRTs）负责具体处置各类安全事件与风险。
    
      
    
*   另一方面，NISD将在各成员国之间设立协同工作组（Cooperation Group，由欧盟委员会派驻秘书长）以支持和促进各成员国之间的合作与情报交换，提升各方的机制型信任水平。在此基础上，NISD进一步要求建设计算机安全事件响应工作组网络（CSIRTs Networks），由欧盟网络与信息安全中心（EU Agency for Network and Information Security, ENISA）派驻秘书长，从而在操作层面确保特定网络安全事件处置与风险情报共享环节迅捷、有效的双边或多边协作。
    

  

**结语**

  

综览欧盟机构12.7政治协议以及NISD文本，我们认为欧盟在网络安全领域的顶层设计以开放式合作和程序化规制为显著特征：

  

*   其一，强调建设欧盟机构之间、欧盟机构与成员国之间、成员国之间以及成员国职能机关之间的多层次立体合作框架；
    
      
    
*   其二，将网络与信息安全的流程化管理作为规范设计的逻辑脉络，注重明确网络安全各利益相关方的功能定位，在精细的利益平衡机制的基础上勾勒动态化干预机制。
