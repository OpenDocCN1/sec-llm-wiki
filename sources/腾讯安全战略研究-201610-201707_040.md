# 动态 | 苹果与腾讯手机管家联手防治iOS垃圾短信

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=2652700384&idx=1&sn=9643bb4b6a3a3e53505aabe5df192bc9&chksm=bd53d03f8a245929b346694dc62323fcee64950286e98eed3c65ab1810d80483182833da34fb&scene=126&sessionid=1681323592#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652700384&idx=1&sn=9643bb4b6a3a3e53505aabe5df192bc9&chksm=bd53d03f8a245929b346694dc62323fcee64950286e98eed3c65ab1810d80483182833da34fb&scene=126&sessionid=1681323592#rd)

北京时间6月6日凌晨1点，苹果开发者大会（WWDC2017）于美国加州圣何塞市正式开幕。作为大会重头戏，iOS11带来了优化的iMessage、更智能的Siri、重新排列的控制中心、Apple Music等重大更新。腾讯与苹果双方的合作也再度升级，用户可获得由腾讯安全提供的包括垃圾短信拦截、欺诈网址识别拦截等全场景防骚扰保护。

![](../Images/112d2385151f4f64a66e6a59bcc88d1c.png)

  

携手解决IOS骚扰短信

  

在发布会上，苹果公司表示在iOS 11版本中，iMessage可以在iOS和Mac等多设备同步，支持Apple Pay，还将搭配其他特殊功能。会后苹果官网更新显示，该功能为腾讯手机管家提供的“防骚扰及诈骗短信”（即防垃圾信息）。根据苹果官方网站对于此功能的介绍，“你可以下载腾讯手机管家等第三方 app 来侦测可能的垃圾信息，并将此类信息隔离在单独的文件夹里。”这意味着iOS11正式发布之后，用户将获得由腾讯安全提供的全场景防骚扰保护。这也是继去年腾讯手机管家骚扰诈骗电话拦截功能获苹果官方推荐之后，双方合作的再度升级。

 

据腾讯移动安全实验室发布的《2017年第一季度手机安全报告》显示，用户仅通过腾讯手机管家举报的垃圾短信就多达2.66亿条。腾讯手机管家针对Android用户的垃圾短信有效拦截率已经提升至99%以上，但苹果短信防骚扰功能一直未能实现。为了让亿万中国iPhone用户免受信息骚扰之苦，苹果很早就开始与腾讯进行沟通，希望借助其在安全领域多年积累的技术优势，实现短信防骚扰。继一年前苹果官方推荐使用腾讯手机管家拦截iPhone骚扰电话之后，腾讯手机管家骚扰诈骗电话拦截功能不但获得用户一致好评，实力也得到了苹果等合作伙伴的一致认可。

  

实现Safari浏览器欺诈网址识别

  

“此次联合苹果共同推出‘防骚扰及诈骗短信’功能的同时，我们还将腾讯安全云库的能力内置在Safari浏览器中，可以实现欺诈网址识别，用户无论是使用iPhone还是Mac都能受到有效保护，进一步保障了苹果用户的上网安全。”腾讯无线安全产品部总经理胡振东表示。当用户通过Safari输入、并预访问某网址，Safari就会通过腾讯安全反欺诈实验室提供的腾讯安全浏览服务，查验该网址是否属于欺诈网址，如果是欺诈网址，则safari会进行拦截，并提醒用户访问风险。

 

近年来，钓鱼欺诈网址造成的安全威胁愈加严重。据腾讯移动安全实验室近日发布的《2017年第一季度手机安全报告》显示，一季度腾讯安全实验室共检测钓鱼网址716.5万次。在苹果系统上，欺诈网址威胁同样不容忽视。调查报告显示，Safari浏览器同样容易受到URL欺骗，使iPhone用户遭遇钓鱼攻击。而通过此次苹果与腾讯安全联合实验室反诈骗实验室的合作，将腾讯安全云库的能力内置在Safari浏览器中，将实现欺诈网址识别，用户无论是使用iPhone还是Mac都能受到有效保护，进一步保障了苹果用户的上网安全。

 

据透露，苹果公司或将于9月份正式推送适用于iPhone设备的iOS11系统，届时，期待大家借助腾讯手机管家防骚扰及诈骗短信、骚扰诈骗电话拦截、日历广告清理以及Safari浏览器欺诈网址识别等功能，真正进入无骚扰、更智能的iPhone时代。

  

再合作凸显技术实力

  

在WWDC2016大会上，苹果宣布iOS10开放数据接口，官方推荐腾讯手机管家为iPhone防骚扰诈骗电话APP。在iOS系统来电提醒页面显示“Tencent Security Caller ID: Possible Spam”字样时，表示这是经过腾讯手机管家识别的“垃圾来电（苹果对骚扰、诈骗等不良电话的统称）”。9月14日随着苹果最新操作系统iOS10正式版的全面推送，最新的腾讯手机管家iPhone版同步在App Store上架，帮助亿万中国iPhone用户解决困扰已久的来电骚扰和诈骗难题。

 

今年是苹果与腾讯的再度合作。苹果之所以会选择与腾讯合作，除了腾讯手机管家超过2亿的月活跃用户，更是看重腾讯安全联合实验室领先的技术实力。去年7月，腾讯安全联合实验室正式发布，主要专注安全技术研究及安全攻防体系搭建,同时基于腾讯安全开放平台，对外输出技术和能力，与微软、谷歌、特斯拉等全球顶尖企业进行安全技术合作。腾讯作为最负社会责任的厂商，已成为协助警方打击诈骗犯罪的中坚力量，这也是苹果再度选择腾讯的重要原因之一。（韩元佳）
