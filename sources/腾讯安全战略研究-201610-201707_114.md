# 安全 | 2017年虚拟化的五大安全趋势

“ 

当人们谈论企业网络安全时，虚拟组件和环境是一个特别的挑战。以下是行业专家认为2017年虚拟化领域安全将有五大趋势。

”

  

1.  

虚拟化安全性重在整合

  

考虑到虚拟桌面基础架构(VDI)和虚拟化服务器的安全解决方案，专家预测企业将更加注意各种系统之间的顺利整合，而不是在彻底检查产品功能。

安全解决方案可以集成到虚拟化基础架构中，以便在早期阶段就能够发现网络攻击和将恶意活动信息传递给企业环境的组件，从而快速做出决策，以隔离和分析威胁，这是企业明智的选择。

  

2.  

企业投资更多的是混合云保护

  

未来五年，变得更加重要的一个新趋势是从私有云到混合云的过渡。到2020年，公共云基础设施的增长以及由此造成的基础设施和安全解决方案的成本，可能会比日前业内分析师所显示的增加2.5至3倍。全球主要云提供商将会继续在行业中领先，如微软Azure，亚马逊网络服务(AWS)和谷歌公司，并加强自己的市场地位，目前已远远领先于竞争对手。

  

3.  

更多的攻击和损害

  

今后，对企业的攻击次数将会持续增长。无论企业使用或不使用虚拟化(目前有超过75%的企业已实现虚拟化)，但问题是他们是否能了解与信息安全有关的基础架构中的所有流程。

  

由于大型企业基础设施的复杂性和其内部不同系统之间的复杂关系，攻击检测时间将随着损害的增多而增加。

  

4.  

网络勒索继续影响虚拟桌面基础架构(VDI)

  

网络勒索行为日益增长，值得一提的是，Crypto-locker和Crypto-malware这些加密的恶意软件威胁将成为VDI难以解决的麻烦。勒索软件可以攻击一个虚拟桌面以及物理工作站，但是对于VDI而言，这些风险明显更高。

  

5.  

移动性挑战呼吁统一安全

  

企业规模越大，需要实现的控制就越多，以确保用户与不同业务系统进行交互的安全。考虑到用户的移动性变得越来越多，需要从任何地方无缝访问业务服务和应用程序，许多公司将发现自己需要为数千个端点部署企业移动管理软件。这将需要资源有效的强大的安全解决方案与这些企业移动系统紧密集成。
