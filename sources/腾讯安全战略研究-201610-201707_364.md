# 动态 | 中国西班牙警方开展打击跨境电信网络诈骗犯罪联合行动

记者从公安部获悉，北京时间12月13日14时许，中国公安部联合西班牙国家警察总局在西班牙境内多个城市开展打击电信网络诈骗犯罪集中行动，成功捣毁十余个诈骗窝点，抓获一批电信网络诈骗犯罪嫌疑人。

 

近一段时间以来，一些电信网络诈骗犯罪团伙在西班牙境内设立犯罪窝点，通过电信网络，冒充我公检法等执法机关工作人员，疯狂对大陆地区多个省市群众实施诈骗。被骗群众损失惨重，社会反映十分强烈。对此，公安部高度重视，自今年7月以来，多次派出工作组赴西班牙，与西班牙警方开展联合调查。在我驻西班牙使馆的大力推动和西班牙警方的全力协助下，中西两国警方于12月13日开展联合收网行动，一举将上述犯罪团伙彻底摧毁。

 

下一步，中国公安机关将与西班牙执法部门密切合作，确保犯罪嫌疑人受到依法惩处。
