# 动态 | 从“电信诈骗重点整治区”到“打击电信诈骗经验输出地”

从“电信诈骗重点整治区”到“打击电信诈骗经验输出地”茂名电白警方与电诈嫌疑人“斗法”有绝招  
广东省茂名市电白区位于广东西南沿海，是粤西人口大区。近年来，电白籍犯罪嫌疑人屡屡在全国各地进行以“猜猜我是谁”“我是你领导”等冒充熟人的电信诈骗犯罪，社会影响恶劣。2015年11月，茂名电白被公安部列为全国打击治理电信网络新型违法犯罪“拔钉子”专项行动7个重点整治地区之一。 一年来，广东省公安机关下决心、下猛药、下狠招，全警动员，严打细控，探索形成了“上下联动、共同经营、异地侦控、辨别团伙、各个击破”的打击整治大格局，相继开展了“海燕”“飓风”等20余项集中式、全链条专项打击行动，打击整治成效显著。据统计，2015年11月至2016年10月，共刑拘电信诈骗犯罪嫌疑人281名。国务院打击治理电信网络新型违法犯罪工作部际联席会议工作简报刊发了茂名电白的经验做法。人民日报、新华社、中央电视台等媒体集中报道了茂名电白打击整治电信网络新型违法犯罪的先进经验。 短短一年，茂名电白就从“电信诈骗重点整治区”变为“打击电信诈骗经验输出地”。电白警方有哪些绝招、利器？近日，人民公安报记者深入茂名电白采访，记录下了电白警方与电信诈骗犯罪嫌疑人“斗法”的全过程。  
比实力三级公安机关整体联动PK电信诈骗团伙分工作案随着互联网的发展，电信网络新型违法犯罪开始走集团化、分工化、科技化路线，大大增加了公安机关的打击难度。为了全链条打击电信网络新型违法犯罪，广东省公安厅成立了茂名市电白区社会治安突出问题打击整治专项工作领导小组，副省长、公安厅厅长李春生担任领导小组组长。 今年1月初，广东省公安厅又成立了打击整治工作驻电白前方工作专班，从厅直各警种、茂名市公安局以及其他相关地市公安机关抽调业务骨干参加专班工作。 “工作专班有13名民警，下设综合协调组、专案打击组、信息组等3个专职小组。它既是协调指挥中心，又是打击整治尖刀力量。”省公安厅驻电白工作专班负责人谢志光说。 近年来，电信网络新型违法犯罪团伙分工越来越细。一个电信诈骗团伙一般分为5个小组：组织者、买卖公民信息组、购买银行卡组、话务组、取款组。 “以往，一个电信诈骗团伙有十几名犯罪嫌疑人。”谢志光说，“但现在，电信诈骗团伙的嫌疑人数量越来越多。我见过最大的一个电信诈骗团伙有近100名犯罪嫌疑人。” 面对日益庞大、分工明确的电信诈骗团伙，茂名公安机关也在不断创新打法、细化措施，对电信诈骗各个环节实施精准打击。 “在茂名市委市政府坚强领导下，在公安部和广东省公安厅强力支持下，我们在实践中创新了‘省市联合、共同经营、异地侦控、辨别团伙、各个击破’的20字打法，建立了‘省厅牵头、茂名主侦、各地配合、打合成战、打集群战、打歼灭战’的跨区域办案机制，实现了对电信网络诈骗犯罪的全链条打击。”茂名市副市长、公安局局长黄果说。 茂名警方不仅致力于全链条打击电信网络诈骗犯罪，还主动实施“走出去”“追出去”战略，创新建立与外省市立案地合作办案、共同追逃、异地收网等工作新机制。茂名市公安局牵头与北京、广西南宁、江苏南京、浙江杭州、福建厦门和泉州等地公安机关商洽建立打击电信网络新型违法犯罪工作机制，共同编织一张打击电信网络新型违法犯罪的天罗地网。 “在开展专项打击行动过程中，我们会根据犯罪团伙的窝点分布、嫌疑人数量，来动态调整警力数量。”谢志光说，“我们一般会出动8到10倍于嫌疑人的警力，力求实现一网打尽、全链条打击的目标。” 虽然电信诈骗团伙越来越大、分工越来越细，但电白警方在省厅、市局的支持下，不断创新打法，持续对犯罪团伙实施全链条打击。在比拼“实力”的过程中，电白警方攻下了打赢这场战争的关键环节。  
拼速度反诈中心快速止付冻结PK嫌疑人层层转移账户11月7日下午，记者来到茂名市反诈骗中心，大屏幕上实时滚动更新着反电信网络诈骗联动平台数据，茂名市公安局民警、中国银行、工商银行、建设银行、中国移动、中国联通等成员单位各司其职，紧张地忙碌着。 突然，反电信网络诈骗联动平台上出现一个新的警情。“杨某于2016年11月7日15时43分22秒被他人冒充领导称有危房补助诈骗7700元。涉案银行卡信息：×××××（中国银行）。”反诈骗中心民警立即和中国银行工作人员合作，第一时间启动止付、冻结手续，避免报警人杨某遭受损失。 据了解，9月30日，“茂名市反诈骗中心”试运行。10月8日，茂名市委书记、市人大常委会主任、市打击整治电信诈骗领导小组组长许光为中心揭牌。  
“虽然成立时间只有一个月，但反诈骗中心已经取得了初步战果。”茂名市公安局刑警支队三大队副大队长周明锋说，“截至目前，反诈骗中心已接警40起，涉案金额50余万元，封堵电话号码159个。” “争分夺秒”是警方与电信诈骗犯罪嫌疑人“拼速度”时的真实写照。一旦群众遭遇电信诈骗，嫌疑人得手后会第一时间分解账户，快速提现，然后消失于茫茫人海。电白警方与电信诈骗分子“拼速度”时最大的王牌就是“茂名市反诈骗中心”。借鉴茂名市反诈骗中心的成功经验，电白分局和工作专班也邀请银行和通信运营商进驻到专班办公室，和茂名市反诈骗中心直接对接。 “反诈骗中心是警方、银行、通信运营商合署办公。而且，通信运营商的快速封堵号码和银行的快速止付冻结等功能，反诈骗中心都具备。”周明锋说，“因此，只要群众在遭遇电信网络诈骗后第一时间报警，我们都有信心跑赢诈骗分子。”  
看基础综治单位攥指成拳夯实基础工作PK诈骗分子的狡猾“话术”每个电信网络诈骗团伙都会精心编排、组织“话术剧本”。而话务组是电信诈骗团伙中人数最多的一个小组。电信诈骗组织者会从全国各地招募话务组成员。招募的最基本条件是会说“乡音”。“嫌疑人会根据目标对象的籍贯来安排相应的话术员，企图用乡音迷惑目标对象，降低目标对象的防备心理。”茂名市公安局副局长、电白区副区长兼公安分局局长龙木兴说。 结合当地社情民情，茂名电白在325国道电白段建成了15公里的反诈骗宣传长廊，在麻岗、树仔两镇建成35条反诈宣传路。当地还成立了82个民间反诈骗同盟会，动用民间力量开展反电信网络诈骗工作。 “警力有限，民力无穷。开展反电信网络诈骗宣传，仅靠公安一家远远不够。区委、区政府派出综治各成员单位共同开展反电信网络诈骗宣传，取得了显著成效。”龙木兴说，“我们还建立了‘三眼’监控制度，充分发挥治安视频监控‘天眼’、治安信息员‘人眼’、公安民警‘警眼’的立体防控作用，全方位、多渠道震慑犯罪分子。” 记者行走在麻岗、树仔两镇，处处可见“勤劳致富光荣、电信诈骗可耻”“打击电信诈骗、创建平安电白”的宣传标语。记者来到马岗镇坑内村村委会。在村委会大院的宣传墙上，详细介绍了电白区社会治安重点整治驻村工作组的工作情况。原来，为了深化综合治理，电白区从全区60个综治成员单位抽调230余人组成驻村工作组进驻马岗、树仔两镇35个村（社区）。目前，已派出5批工作组。工作组深入开展劝投、管控、宣传、教育等工作。今年以来，驻村工作组成功劝返在逃人员34名。 “在宣传、教育、劝返等方面，驻村工作组给了公安机关非常大的帮助。”龙木兴说，“10月以来，电白警方联合驻村工作组开展各类宣传活动240余场次，制作分发扑克牌通缉令6万余盒。” 比实力，公安机关上下联动，对电信网络诈骗团伙实施了全链条打击；拼速度，依托反诈骗中心，警方、银行、通信运营商紧密合作，跑赢了诈骗分子；看基础，全民防诈、全民反诈让电信诈骗分子无处藏身、无计可施。可以看出，在茂名电白警方与电信诈骗嫌疑人“斗法”的过程中，茂名电白警方取得了实质性的胜利。 “我们将继续保持对电信网络新型违法犯罪的严打高压态势，继续出重拳、下重手，彻底拔掉电信网络诈骗‘钉子’，为建设平安电白、法治电白、美丽电白作出新的贡献。”黄果说。
