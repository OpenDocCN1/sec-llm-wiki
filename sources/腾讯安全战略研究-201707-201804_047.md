# 特朗普签署Cloud Act法案 使执法机构更容易访问存储在国外的数据

      据外媒CNET报道，当地时间周五美国总统特朗普正式签署了Cloud Act法案（《澄清境外数据的合法使用法案》），使执法机构更容易要求访问在线信息，而不管数据存储在哪个国家。周四众议院和参议院正式投票通过该法案。

  

      Cloud Act法案更新了执法人员查看存储在互联网上的电子邮件、文档和其他通信内容的规则。例如，现在执法人员将不会被阻止访问某人的Outlook帐户，微软恰好将用户的电子邮件存储在爱尔兰的服务器上。该法案还允许美国达成协议，将有关美国服务器的信息发送给其他国家的刑事调查人员，并对请求进行个案审查。

 

![](../Images/4e7a880e3d34b0ca3c2812b04b2fb8a2.png)![](../Images/81bcacf86abdb5c07f54220199b22d5b.png)

  

Cloud Act法案为当前在国家之间共享互联网用户信息的过程或多方司法互助条约提供了一种替代方案。执法机构和科技公司都表示，使用这样的条约来要求获得数据是麻烦而缓慢的。。微软等技术公司赞成这一变化。但隐私权倡导者称，它可以帮助外国政府通过帮助他们获取有关其公民的在线数据来滥用人权。

 

微软总裁兼首席法务官布拉德·史密斯(Brad Smith)周三在一份声明中表示，该法案是“一项强有力的法规和良好的妥协方案”，并补充道：“它使微软等高科技公司能够站出来为我们的客户在世界各地提供隐私权。”

 

来自犹他州的共和党参议员Orrin Hatch 在2月份表示，该法案平衡了用户的隐私，并需要一个更新的框架，为执法部门提供所需的信息。 Hatch认为：“Cloud Act法案弥合了执法部门和科技部门之间有时存在的分歧，为执法部门提供了获取全球数据所需的工具，同时创建了一个常识性框架来鼓励国际合作解决法律冲突。”

 

但是像美国公民自由联盟(ACLU)和电子前沿基金会(EFF)等组织的隐私倡导者批评了这一变化，称它允许执法机构绕过对不合理搜索的宪法保护。他们认为，这也可能导致美国向滥用公民人权的国家的警察发送用户数据。

 

倡导者表示，结果是科技公司将不得不决定是否遵守对用户信息的法律要求。美国公民自由联盟的代表周四致信立法者称，该法案“威胁到人权，危害美国境内个人的第四修正案权利，并且以牺牲国会权力为代价向行政部门提供了令人震惊的自由裁量权。”
