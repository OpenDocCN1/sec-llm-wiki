# 践行社会责任，从源头打击网络黑产，腾讯守护者计划全面升级

      “2017年全年，‘守护者计划’共协助公安机关破获网络大案160件，抓捕犯罪嫌疑人3800余人，涉案金额达32亿元，涉及非法获取公民个人信息100亿条以上。”1月14日，在2018年守护者计划大会上，腾讯“守护者计划”负责人朱劲松表示，面对网络黑产的新趋势，要坚持社会共治模式，加强黑产源头打击，高效遏制网络黑色产业链蔓延、发展。

  

自2016年4月成立以来，“守护者计划”从政企合作、犯罪打击、技术支持、用户教育等层面不断发力。尤其是2017年将网络黑产治理重心前移，加大威胁源打击力度，协助警方有效地打击了电信网络诈骗，并遏制了网络黑产的发展。作为企业社会责任平台，“守护者计划”树立起专业化标杆，同时让“社会共治”模式成为打击网络黑产的共识。也因此，2017年守护者计划蝉联“CCTV年度法治人物”称号。

  

![](../Images/a11704ee15566b136ab1d709e6bc647e.png)

腾讯“守护者计划”负责人  朱劲松

  

立体化打击网络黑产，

守护者计划践行“社会共治”模式

  

      目前我国网络犯罪已占犯罪总数近三分之一，且每年以近30%幅度上升。单打独斗无法阻止网络犯罪数量增长势头，社会共治、联合出击成为打击新型网络犯罪的主要模式。

 

2017年，“守护者计划”全面升级，将企业责任上升为社会责任，呼吁更多民众行动起来。朱劲松认为，面对愈演愈烈的电信网络诈骗，公众防范意识薄弱、被骗后选择“沉默”、面对诈骗信息“不作为”等公众的“冷漠”，往往形成了反电信网络诈骗矩阵中的“黑洞”，让诸多诈骗“病毒”借此滋生成长。

 

2017年第三季度，“守护者计划”发起以“守护家人，做反诈骗行动派”为主题的公益活动。该活动媒体曝光50亿次，约5500万用户参与，大幅提升公众对电信网络诈骗认知，直接促使2017年第三季度诈骗数量与金额环比双降。

 

2017年11月，腾讯公司与上海市反电信网络诈骗中心联合组建“腾讯上海反电信网络诈骗联合实验室”，这是“守护者计划”技术支持和政企合作的典型案例。“该项目将腾讯公司的大数据技术和海量用户经验，与上海警方打击治理新型网络违法犯罪的经验做法和工作机制结合，以机器学习、模型推演等方式，实现数据加工自动化、线索研判智能化、预警推送高效化。”朱劲松介绍称。

 

在政企合作共同研究和打击网络犯罪行为方面，腾讯公司还与国家工商行政管理总局竞争执法局联合成立网络传销监测治理基地，与深圳市公安局刑事侦查局共同建成“守护者计划（深圳）联合实验室”。

  

夯实企业社会责任，

“守护者计划”直击网络黑产威胁源

  

      “守护者计划”率先认识到，非法获取公民个人信息、木马病毒、恶意网址、DDoS攻击、黑客渗透、流量劫持、为黑客攻击提供技术支持等网络黑产威胁源，降低了网络违法犯罪成本，增加破案难度，成为网络黑产快速发展的关键要素，将打击工作前移，直面网络黑产威胁源，成为2017年“守护者计划”的重点工作之一。

 

在2018年守护者计划大会上，深圳警方分享了跨国打击国内影响力最大的DDoS黑客组织“暗夜攻击小组”的情况，山东新泰警方分享捣毁国内最大的色情云播平台“月光宝盒”的情况，安徽警方分享破获国内最大的非法获取、交易公民个人信息案的情况，三大案例背后，均有“守护者计划”技术支持的身影。

 

朱劲松在会上也分享了协助打击网络黑产的十大案例，并总结出当前网络黑产五大特征：

  

一是国际化，黑产团伙将部分人员转移至海外，利用国外政策法律漏洞跨境作案逃避打击；

  

二是智能化，网络黑产技术升级，人工智能等先进技术被黑产团伙关注并应用，进一步增强黑产的危害与破坏；

  

三是平台化，越来越多的上游提供技术支持，降低了下游实施犯罪的成本；

  

四是产业化，网络黑产披上科技公司的外衣，在灰色地带从事色情诱导诈骗等不法行为；

  

五是涉众化，如善心汇传销、民族资产解冻诈骗等在互联网场景下对人群的影响被放大，被欺骗和洗脑的公众数量变大。

 

“2018年腾讯守护者计划将从加强源头打击、区域犯罪治理、鼓励民众参与、更多技术支持等四个方面，助力对抗网络黑产。”朱劲松在大会上表示。
