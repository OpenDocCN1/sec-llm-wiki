# 广西破获特大网络贩枪案：枪支化整为零 快递运往"车间"组装

      日前，广西柳州警方通报了近期破获的一起特大网络贩枪案。新京报记者获悉，嫌疑人在国外购买枪支，拆解后走私入境，再用快递发货。警方办案历时大半年，共控制涉案人员66人，涉及16省份50地市，缴获制式枪支60支，气动力枪支33支，各式子弹近3万件。

  

![](../Images/7b53d8e029742f5589b0a6b385479f31.png)

枪支“化整为零”快递运往“车间”组装

  

      广西柳州市跃进路，一栋普通的居民楼内，几名青年男子搬着纸箱，朝着位于城郊的快递点而去。箱子挺沉，几名男子偶尔会沿路丢下一些金属构件。这不是普通的金属构件，而是枪支零部件。

 

日前，广西柳州警方通报了近期破获的一起特大网络贩枪案。新京报记者获悉，嫌疑人在国外购买枪支，拆解后走私入境，再用快递发货。警方办案历时大半年，共控制涉案人员66人，涉及16省份50地市，缴获制式枪支60支，气动力枪支33支，各式子弹近3万件。

  

![](../Images/7b53d8e029742f5589b0a6b385479f31.png)

可疑包裹内藏枪支零件

  

      今年1月18日，一行“来客”，走入广西壮族自治区柳州市公安局刑侦支队的办公室。来人是警界“同行”，来自深圳市公安局刑侦支队，此行则为一起疑似涉枪案件。

 

新京报记者从深圳警方获悉，去年9月初，深圳警方在抽检中，发现部分快递包裹内含金属构件，从外形上看，类似于枪支拆解后的零件。此后，陆续有一些同样的快递包裹被警方截获，这些包裹均由香港过关至深圳，再由深圳发往柳州，总数达到14件。此外，这些包裹的寄件人信息均为伪造，无法有效溯源。深圳警方推测，这些神秘包裹背后，可能暗藏一个枪支贩卖网络，为免打草惊蛇，警方并未截停可疑包裹，希望通过对收件人的监控侦破案件。

 

柳州市公安局刑侦支队随后对深圳发来的快递包裹进行排查，但情况并不乐观。经调查，14个可疑包裹全部被发往柳州境内乡镇、郊区代收点，这些快递分部大多由私人承包，没有监控系统和完整的取件记录，无法获得收件人图像信息。此外，由于快递单量大，警方走访的这些快递分部工作人员，对可疑包裹收件人没有深刻记忆，也无法提供有价值的信息。

 

于是，可疑包裹被人取走，而收件人如同“人间蒸发”。

  

![](../Images/7b53d8e029742f5589b0a6b385479f31.png)

警方排查300万份快递单

  

      连续的追踪排查，并非毫无进展。在对快递工作人员进行问询时，有人回忆起，目标包裹收件人应该是一名20岁出头的男子。此外，深圳警方的追踪，则大致理清了案件脉络：嫌疑人从境外购买包括军用制式枪支在内的枪支弹药、手雷以及枪械制造模具，以邮递方式进入中国香港地区，进行拆解后，借助往返于深港两地之间的“水客”，以人工带货方式出关，进入深圳境内，再通过快递包裹寄到柳州。

 

两地警方相信，柳州只是这一贩枪团伙在境内的中转站，大量枪支武器零部件将从柳州发往全国各地。快递工作人员口中“20岁出头的男子”，则在这一网络中承担重要角色。

 

通过排查深圳警方发现，在这个网络中，有两个银行账户在柳州交易频繁，并有多次取款记录。今年2月12日，深圳市公安局刑侦支队再次派员来到柳州专案组，将这一案情进行串并。按照此前掌握的信息，柳州警方调取银行监控录像，通过对画面分析，神秘取款人最终现身。

 

画面中的取款人，现身时均戴着口罩、帽子和假发。此外，警方发现，男子在取款时，往往换乘多种交通工具，并故意“绕路”。追踪其行动路线发现，这名取款人曾多次前往偏僻地带的快递分拣点。警方由此认定，这名取款人与之前“蒸发”的收件人，极有可能是同一人。

 

柳州警方采用了“笨办法”，对所有由柳州发出的快递单一一排查。最终，警方从总计超过300万件的快递单中，发现50余份可疑单据。通过对这些快递单的回溯，一个名叫吴明的年轻男子，进入警方视线。

  

![](../Images/dcf7e71273549276c0d3ff9c3c79285d.png)

  

![](../Images/7b53d8e029742f5589b0a6b385479f31.png)

组装“车间”藏身住宅

  

      警方对吴明并不陌生。2014年，因涉嫌非法持有枪支，时年27岁的吴明曾被广东珠海警方刑事拘留。柳州警方调查结果显示，吴明系广西灌阳人，租住在柳州市区解放南路一带。

 

通过对吴明的监控，柳州警方掌握其生活规律。办案人员发现，吴明时常进出柳州市跃进路的一个居民小区，并多次从该小区2栋1单元14楼取出包裹，再到快递网点寄出。与吴明一同进出这一单元的，还有一名余姓男青年。此外，吴明的亲戚唐戈和苏强，也时常在这一地带出现，并与吴明联系密切。

 

对于柳州警方来说，唐戈和苏强都是老面孔。此前，两人因为涉嫌非法贩卖枪支零部件，多次被公安机关传唤调查。此外，警方发现，上述人员在行动时，会丢弃一些金属构件，怀疑为枪支零部件。

 

连续多日监控后，深圳和柳州两地警方将案情上报，在得到公安部批准后，决定“收网”。广西壮族自治区公安厅副厅长李跃、公安厅刑侦总队总队长吕开旺带队来到柳州，部署对相关人员的抓捕。4月18日上午，警方发现吴明进入室内后，长时间没有外出，即准备实施抓捕。

 

当日中午12时许，吴明从目标1404房出来后，警方即将其控制。办案人员进入室内发现，这套三室两厅的住宅几乎是一个“组装车间”，到处是各种枪支零部件、制枪工具。经技术人员勘验，这些零件能组装出可以击发的国外军用制式步枪6支、使用压缩气体为动力的仿制枪支5支，各种枪击组件90套，另有枪支零件316个。

  

![](../Images/7b53d8e029742f5589b0a6b385479f31.png)

销售网络覆盖全国16省份

  

      在对吴明实施抓捕的同时，办案人员分别在柳州市北站路、北雀路、桂柳路抓获另外三名涉案人员，缴获以气体为动力的枪支共计5支，查获一个位于柳州市基隆开发区内的枪托制造点，缴获机床设备5台。

 

至此，一个制造、贩卖枪支的网络水落石出。吴明被捕后供述，2015年4月，其通过网络结识了两名身在欧洲的网友，两人“指点”吴明，通过购买枪支，转手销往国内牟利。具体方法为，境外枪支拆解后，通过香港“水客”走私入境，再以快递方式寄到柳州。吴明收货后，按照国内客户给出的地址寄送，从中收取佣金。看到获利可观，吴明便拉来另外三人，在柳州市境内建起了加工、储存枪支点，并发展国内买家，组建销售网络。

 

新京报记者从柳州警方获悉，根据吴明等人的供述及涉案物流信息、资金来往情况，警方梳理出涉嫌购买枪支的多名下家，涉及山东、江西、河北、福建等16个省区市的50个地市。在公安部专案指挥部统一指挥下，先后有32个缉枪追捕组，赴外省市开展抓捕和收缴工作。截至今年10月底，16个省区市警方共抓获涉案人员66人，缴获各种制式枪支60支，气动力枪支33支，各式子弹近3万件以及火药等涉案物品一批。

 

柳州警方表示，目前全部涉案人员中，警方已对41人实施逮捕、刑事拘留1人、取保候审3人、另有多人经过教育后释放。目前，该案仍在进一步调查中。（文中涉案人员均为化名  记者：王煜）
