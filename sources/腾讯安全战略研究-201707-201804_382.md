# 网络犯罪已成第一大犯罪类型 孟建柱：坚决把高发态势压下去

      9月19日，中共中央政治局委员、中央政法委书记、中央综治委主任孟建柱在全国社会治安综合治理表彰大会上指出，现在，网络犯罪已成为第一大犯罪类型。

  

“ 

“我们要打破以传统办法对付网络犯罪的思维定式，坚决把网络犯罪高发态势压下去。”孟建柱说。

”

  

孟建柱指出，要加大对网络黑灰产业有关信息、平台清理整治力度，最大限度挤压其生存空间。坚持开放共治，加强与互联网企业和有关部门、单位合作，实现行政监管与刑事打击无缝衔接。推动完善法律法规，出台司法解释，消除监管盲区。

 

在国内，新型网络传销、非法集资犯罪突出等严重损害人民群众切身利益，影响社会大局稳定。同时，网络安全在国际上也呈现出新特点，新变化。

 

孟建柱以此前世界150多个国家和地区网络用户遭勒索病毒攻击事件为例，他指出这是世界网络安全和网络战进入新阶段的标志。

 

与之相应，新的治理理念、治理方法十分必要。

 

孟建柱指出，要树立主动防御的理念，建立与国家关键信息基础设施面临威胁相适应的网络安全综合防御体系。要打破以往用传统办法对付网络犯罪的思维定式，完善全产业、全链条打击整治机制，以立体防控链条摧毁犯罪产业链，把网络犯罪高发态势压下去。同时，加强互联网企业和有关部门、单位合作，实现行政监管和与刑事打击无缝衔接。

 

值得一提的是，去年以来中国的网络犯罪治理通过综合治理方法取得了显著的成果。孟建柱指出，去年打击电信诈骗就是通过综合治理的方法，协同多部门参与，对犯罪分子进行专业化、全链条地打击和惩治，有效扼制了电信网络诈骗犯罪势头。

 

以北京为例，2016年以来，北京市公安局坚持以人民满意为第一追求的理念，紧紧围绕“两个中心”（公安部打击治理电信网络新型违法犯罪查控中心、北京市反电信网络诈骗中心）建设，立足北京，服务全国，形成了具有首都特色的“党委领导、刑侦主导、打防并举、部门配合、内外协作、堵源斩首”的打击防范电信网络诈骗犯罪工作体系。

 

统计数据显示，今年以来截止到8月底，北京市公安局在打击防范电信网络新型违法犯罪方面，发案、人民群众财产损失分别同比下降45.3%、43.9%，抓获犯罪嫌疑人、破获全国案件分别同比上升16.3%、52.1%。

 

在全国社会治安综合治理表彰大会上，孟建柱还表示，在风险社会中，事后处置固然重要，事先预防才是根本。社会治安综合治理的至高境界，就是实现对各类风险预测预警预防。他表示，暴力恐怖活动是对公共安全的最大现实威胁。要坚持系统治理、综合施策，促进反恐形势不断向好的方向发展。

 

同时，要敞开胸怀拥抱千变万化的世界，关注共享经济、寄递物流等新经济、新业态的潜在风险，高度重视经济金融风险的巨大危害性，研究把握规律，提高风险识别、预警、防控水平。对于严重损害人民群众切身利益、危害社会稳定的新型网络传销、非法集资以及金融操控、关联交易等涉众型经济犯罪，要创新防范打击机制，坚决遏制其高发势头。

 

孟建柱强调，党的十九大即将召开。为十九大胜利召开营造安全稳定的政治社会环境，是当前政法综治战线的头等大事。要把增强“四个意识”体现在实际行动上，集中精力细谋划，扑下身子抓落实，从严从实从细抓好保安全、护稳定工作，圆满完成党和人民交给的重大政治任务。
