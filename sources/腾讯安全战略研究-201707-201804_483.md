# 动态 | 全国扫黄打非办通报7起护苗典型案件

护苗

11日，全国“扫黄打非”办公室对外公布“护苗2017”专项行动第一批7起典型案件，其中网络案件4起，非法出版物案件3起。

  

全国“扫黄打非”办公室负责人指出，“护苗2017”专项行动开展以来，各地“扫黄打非”部门认真组织开展校园周边文化市场及涉未成年人网络环境专项整治，大力查缴含有淫秽色情、暴力、恐怖、迷信等内容以及非法出版、侵权盗版的少儿出版物，持续清理含有妨害少年儿童身心健康内容的网络音视频、游戏、小说、动漫等，深入查处各类案件，严厉打击制售传播非法有害少儿出版物及信息的单位和个人。

 

据统计，1至6月，全国共查缴盗版教材教辅及其他少儿类非法出版物97.9万余件。山西、山东、上海、浙江、甘肃等多地文化执法部门查办了一大批行政案件；江苏、浙江、安徽、湖北等地查办了多起“护苗”刑事案件，有效净化了少儿出版物市场环境。

  

据全国“扫黄打非”办公室负责人介绍，今天公布的7起案件案情简要如下：

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**一**

浙江丽水“12.26”特大传播淫秽物品牟利案。2016年年底，丽水开发区网警大队及文化执法部门巡查时发现一条淫秽网站线索，开始立案侦查。经查，张某甲、张某乙、张某丙通过在美国租用服务器，开设收费淫秽网站“91好福利”“91视频”等进行牟利，共获利100余万元。其上游网站“好多福利”“爱撸社区”等由王某某团伙开设。王某某团伙运营多个淫秽网站，获利超200余万元。涉案的淫秽网站会员数量数十万人，其中未成年人及在校学生数约一万。2017年5月3日，丽水警方赴安徽合肥将王某某抓获。5月16日，警方在北京、上海、杭州、武汉、长沙、绵阳等地对团伙其他成员开展集中收网抓捕。截至5月18日，共抓获犯罪嫌疑人14名，捣毁收费淫秽网站7个，扣押现金100余万元、奔驰轿车一台，电脑24台，手机21只，查扣淫秽视频10余万部、淫秽图片50余万张。目前，该案在进一步查办中。

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**二**

江苏南京“2·21”微信传播淫秽物品牟利案。2017年2月中旬，南京市公安局建邺分局根据群众举报，发现有人通过组建微信群传播淫秽色情视频。2月21日，公安机关成立专案组对案件进行立案侦查。4月12日，专案组在江苏南京、广西来宾、浙江绍兴、福建厦门、广东深圳5地同步开展抓捕行动，成功抓获包括主犯蒙某某在内的团伙成员14名，查扣电脑、手机等作案工具数十台、各类淫秽色情视频2万余部。经查，2016年2月至案发，蒙某某等人为牟取非法利益，通过微信组建十余个群，大肆拉人进群，群内成员超5000余人，在群成员交纳20元入群费和每月10元会费后，即可每天在群内观看、下载相关淫秽视频。这些群每天上传淫秽视频数百部。目前，蒙某某等12人已被依法刑事拘留，案件在进一步侦办中。

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**三**

浙江庆元QQ群传播淫秽物品牟利案。2017年3月24日，根据群众举报，庆元县公安、文化执法部门立案查处一起利用网络云盘传播淫秽物品案。经查，李某某于2015年8月至2017年4月在网上销售带有淫秽物品的云盘账号非法牟利，专门创建一个名为“aaz”的QQ群，群内有1800余人，已有100余人向其购买过云盘账号，涉案金额2万余元，涉及云盘账号300余个，仅单个云盘账号内就有淫秽视频6000余部。李某某的上家温某某通过QQ在网上发布广告招揽买家，销售含有大量淫秽视频的网盘账号。4月20日，李某某在河南省鄢陵县被抓获。5月27日，公安部门在江西南昌、宜春等地抓获涉嫌传播、贩卖淫秽视频的犯罪嫌疑人温某某、邬某某等5人，扣押涉案电脑1台、涉案手机4台、涉案金额近30万余元。目前，该案正进一步查办中。

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**四**

安徽六安汪某擅自从事网站经营活动案。2017年4月20日，根据举报线索，安徽省六安市文化执法部门对“www.8uuzg.com”（八悠悠战歌网）违法违规情况进行勘验。经查，该网主要提供歌曲、舞曲、视频录音、有声小说下载，其中骚麦诱惑、有声小说两个栏目的175个音频涉嫌宣扬淫秽；网站备案人丁某某，住址为安徽省霍邱县某镇某处。该网站未取得《网络文化经营许可证》等证照，涉嫌存在非法经营行为。5月5日，该案移交霍邱县公安局侦查。经进一步查明，汪某2016年10月用妻子丁某某身份信息注册网站，擅自从事经营性互联网文化活动，涉嫌提供含有违禁内容的互联网文化产品。公安机关对汪某进行立案查处，扣押2台电脑、1部手机。目前，该案在进一步侦办中。

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**五**

浙江海盐“3.11”销售侵权盗版出版物案。2017年3月11日，海盐县文广新部门接到群众举报，某中学门口有人向学生销售非法图书，派文化执法人员前往核查，现场查扣高仿盗版图书198类715册，经对当事人问询发现，他们通过QQ向在校学生推销图书并在线预订，通过物流运输从外地进货，由专门的区域销售人员提货，并送至学校交付并收款。案件涉及一个地下销售侵权盗版出版物网络。3月28日，海盐县公安局进行立案侦查。经查，犯罪嫌疑人孙某某、霍某在山东省聊城市某图书城内经营一家门店，自2012年开始至案发，长期销售侵权盗版出版物，所售出版物均以图书标价的2折至3.5折价格从北京进货，其上级批发商有5家，销售下家有8名。2016年11月至今，非法销售收入达50余万元。目前，两名犯罪嫌疑人已被刑事拘留，该案在进一步查办中。

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**六**

安徽六安楚某某擅自发行非法出版物案。2017年5月底，六安市“扫黄打非”部门依法查结楚某某擅自发行非法出版物案。经查，2015年9月至2016年4月，楚某某为获取利益，与江西善德科技有限公司法定代表人袁某某约定，以代理商身份为该公司销售“知行合一”经典听读机，多次组织销售团队在河南、河北、安徽等地邀请学生家长，举办所谓教育讲座，以购买听读机并赠送一套10本《经典诵读全书》的促销条件，销售听读机1300台，涉案经营额170万元，非法牟利20万元。“知行合一”经典听读机、《国学经典诵读全书》经安徽省新闻出版广电局鉴定均属非法出版物。六安市公安部门进行了立案侦查，后因未达到案件起诉条件和标准，将该案移送市文广新局进行行政处罚。5月17日，市文化市场综合执法大队依法给予楚某某没收全部涉案设备、工具，并罚款28.154万元的行政处罚。

  

![](../Images/c38d72727e7bdb73475ec56e10da36ac.png)

**七**

浙江绍兴李某某侵犯著作权案。2017年3月23日，绍兴市“扫黄打非”办公室接到群众举报反映，有人向嵊州市马寅初中学销售非法出版物。文化执法部门对该情况进行了核查。经查，该中学高三年级使用的《高中语基语用200练》一书无封面、扉页、版权页，且字迹模糊，印刷质量差。经新闻出版部门鉴定为非法出版物。2016年5月，李某某到学校推销，学校共购买了该书655本，每本15元，共计金额9825元。目前，该案已移交公安部门立案查处。
