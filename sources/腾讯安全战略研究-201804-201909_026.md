# 网络黑产的“黑吃黑”，苍天饶过谁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=2652704922&idx=1&sn=608f6222e2ce8a85635a6a8790ca9d43&chksm=bd523e458a25b75356d68b98365705d84a43fed45aa3729cef97552936c21eeedd7fa32f97fd&scene=126&sessionid=1681323449#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652704922&idx=1&sn=608f6222e2ce8a85635a6a8790ca9d43&chksm=bd523e458a25b75356d68b98365705d84a43fed45aa3729cef97552936c21eeedd7fa32f97fd&scene=126&sessionid=1681323449#rd)

大家好，我是鹅师傅。

  

作为一只每天和小伙伴一起跟网络黑产团伙斗智斗勇的鹅，今天想告诉大家一些关于黑产团伙的真相。

  

黑产团伙蹲守在互联网的各处，像吸血鬼一样忙碌着寻找暴利的项目。

  

而在这些日进斗金的黑产团伙背后，也有着另外一群群时刻准备从他们嘴里夺食，从他们身上薅羊毛的黑产。

  

这可以说是黑产界的无间道，黑吃黑。  
![](../Images/9eb625c41ff95b25b9ed42903b8aa4e4.png)（图片来自电影《无间道》）  
下面，鹅师傅和大家聊几种常见的网络黑产“黑吃黑”场景。  

![](../Images/7cfdc4d08a22ab1a5266b35f0987984f.png)  

  

**买卖公民个人信息**

  

在公民个人信息买卖的链条里，黑产团伙把包括身份证件、银行卡、手机卡、U盾的一套个人信息，称为“四件套”。  
![](../Images/722cc3f0af09d10c19498d33a08ba1ba.png)  
据鹅师傅了解，“四件套”在收购时一般每套 500-1000 元，在经过层层转手加价，最后到真正的买家手里最高可以卖到**每套 3000 元**。  

  

这些四件套可以被黑产用来冒充他人，做尽各种坏事儿。  
四件套，可以说是网络犯罪中游、下游团伙在犯罪时的必需品。

  

这些个人信息可以用来注册账号**薅羊毛**，也可以作为进行网络赌博等各类犯罪团伙**洗黑钱**的工具。

  

然而使用这些四件套的黑产，也会遇上黑吃黑的情况。

  

比如有人会**用这些四件套在风控差的高利贷平台上借款**。无论高利贷利息有多高，用的都是别人的身份，并且也不可能会换钱。  
这样一番操作，薅走的就是高利贷团伙的大羊腿了。

  

还有一种更加让人叫绝的黑吃黑套路：

  

比如卖家 A 把手里的四件套，卖给了赌博洗黑钱的 B，但是卖家 A 依然会以某种方式留有一份四件套资料。

  

B 把骗来的钱转进四件套里洗钱，A 看到账户里钱到了一定数量时，就会迅速把赌博黑产的钱卷走。  

![](../Images/52d87ee412afcdd39da3bdb964926f6d.png)

  
  

![](../Images/7cfdc4d08a22ab1a5266b35f0987984f.png)  

  
**P2P 高利贷**

  

P2P 高利贷黑吃黑，互相坑的套路可就多了。  

![](../Images/84b67aa302bd21a55c462d8c5d80bd4e.png)

  
先不说在论坛贴吧找水军散布谣言、中伤竞争对手，在新闻媒体上互相发黑稿、负面。

  

早些年，有第三方的数据公司专门收集用户的金融数据，然后把人群分为白名单用户和黑名单用户，再把这些名单卖给 P2P 高利贷公司。

  

然而，这些金融数据一般也是从高利贷公司手上买到的，这些高利贷公司当然不是善茬，怎么会把最重要的客户信息共享？  

![](../Images/2290fdf1ab7260e1360c41a6c2973b8e.png)

  
因此，一些黑户的资料通过篡改变成了白户，一些白户则被改成了欠钱不还的黑户，再卖给别人。

  

这样一番黑白颠倒操作下来，后果是什么呢？

  

**真 · 白户在其他高利贷平台都没法借款，于是成了某个平台的独家用户。**

  

**真 · 黑户在其他高利贷平台通行无阻，批款迅速，然而却是薅走平台钱款不还的老赖。**  

![](../Images/7cfdc4d08a22ab1a5266b35f0987984f.png)  

  

**色情网站**

  

2018 年，某 P 开头的全球最大的色情网站访问量高达 335 亿次。有人统计过，色情网站的流量超过全球网络的三分之一。  
![](../Images/fd0f70640155fa72ea83becca9dcd37b.png)

  

色情网站的流量相当惊人就是了。  
不过在我国，**色情网站是违法的存在**。

  

传播淫秽物品罪可以了解一下：

  

**犯本罪的，处二年以下有期徒刑、拘役或者管制。向不满十八周岁的未成年人传播淫秽物品的，从重处罚。****以牟利为目的，制作、复制、出版、贩卖、传播淫 秽物品的，处三年以下有期徒刑、拘役或者管制，并处罚金；情节严重的，处三年以上十年以下有期徒刑，并处罚金；情节特别严重的，处十年以上有期徒刑或者无期徒刑，并处罚金或者没收财产。**  
好了，法律学习完以后，我们来看下色情网站是怎么黑吃黑的。

  

首先，色情网站最重要资源就是视频。  
然而一些也想做色情网站的黑产，就会通过网络攻击、网络爬虫等各种手段复制对手的视频。

  

也就是说，**各个开色情网站的黑产，基本无时无刻都在打架**。  

![](../Images/10c06faa1f9d6af0d52ec3d690801f4d.png)

  

**要不是为了保护自己的非法视频资源而去攻击其他同行，要不就是为了拖视频而去攻击别人的服务器。**

  

后来，这种互捶的套路发生了演变，有非法资源的网站做了各种虚假外壳网站、钓鱼网站，用来套取流量或者入侵用户电脑进行获利。

  

鹅师傅在这里劝各位兄弟们，要理智呀，你在搜索网站里面找到那些貌似可以看小黄片的网站，**超过 90% 都是钓鱼网站**。  

![](../Images/7cfdc4d08a22ab1a5266b35f0987984f.png)  

  
**网络赌博**

  

上周，鹅师傅为大家揭露了[《380 人团伙在越南被端，跨境网络赌博是怎么坑人的？](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652704906&idx=1&sn=91bf2ed6a94e9e0266a6a0572183171c&chksm=bd523e558a25b743aaa4c484b5f34b03d70b5415d34ee3a07bf0cc5d662d10b15abc9c4cd866&scene=21#wechat_redirect)[》](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652704906&idx=1&sn=91bf2ed6a94e9e0266a6a0572183171c&chksm=bd523e558a25b743aaa4c484b5f34b03d70b5415d34ee3a07bf0cc5d662d10b15abc9c4cd866&scene=21#wechat_redirect)的套路。

  

其中就有提到，犯罪团伙在网络赌博平台的后台，**通过人为操作或者算法，直接更改下注结果等，进行诈骗**。

  

网络赌博的黑产，还会针对赌徒的心理进行操作。

  

**先让赌客赢点小钱**，都是为了放长线钓大鱼，让那些放松警惕、沾沾自喜的赌客在上瘾后，加大投入。网络赌博的黑产就会一把收割屠宰。

  

然后问题来了。  
**既然一些网络赌博会让赌徒先赢一些钱 ，于是就出现了一类黑产，专门去赢开始这几把小钱。**

  

赢小钱要想赚钱，就需要有足够的量，因此这些黑产就会用聊天机器人等自动脚本，去薅网络赌博平台的羊毛。

  

据鹅师傅了解，网络赌博平台已经开始使用机器人聊天，给赌徒发预设的话术、链接。

  

所以这种黑吃黑到头来，就演变成了网络赌博平台的机器人，和薅赌博平台羊毛的黑产机器人在对聊。

  

这种黑吃黑，精不精彩，魔幻不魔幻？  
  

![](../Images/7cfdc4d08a22ab1a5266b35f0987984f.png)  

  
**游戏私服**

  

**网游私服的本质是一种盗版，这些黑产在未经版权拥有者授权的情况下，通过非法获得服务器端安装程序后，进而设立非法网络服务器。**

  

一些私服会针对游戏玩家的心理，把升级做得更快，也可能会把自己包装宣传成大厂出品的游戏。经营私服的黑产团伙，往往赚得盆满钵满。

  

对于游戏玩家而言，上私服玩游戏要冒的风险是很大的，首先，这些私服可能会假装推出某个促销活动，让玩家充一大笔钱。

  

接下来的不用多说啦，就是**私服经营者看到鱼儿养不多够肥了，就开始收割，关服务器，删库卷款跑路**。

  

除了私服随时可能关停，损失钱财，游戏玩家往往也会成为黑产的肉鸡。

  

这就涉及到黑吃黑的情况了。

  

由于开设经营一个私服网站是需要使用大量工具的，也是需要租用服务器的。因此**一些黑产专门盯上了这些做私服的人，在私服网站的工具中注入木马**。  
如此一来，下载了客户端的玩家就变成了肉鸡，而私服网站不仅变成了**传递木马的中转站**，还有会被黑吃黑的团伙，**薅掉服务器资源**。  

  

![](../Images/7cfdc4d08a22ab1a5266b35f0987984f.png)  

  
**守住底线，远离黑产**  

  

黑产的业务范围繁多，盯上黑产业务的黑产更多。

  

买卖公民个人信息、P2P 高利贷、色情网站、网络赌博、游戏游戏私服，这几种是黑吃黑情况相对较多的场景。

  

其中可能涉及的犯罪包括**诈骗罪、侵犯公民个人信息罪、非法获取计算信息系统数据、非法控制计算机信息系统等计算机犯罪**。

  

天道有轮回，苍天饶过谁。

  

螳螂捕蝉黄雀在后，黑吃黑的团伙们，还有法律制裁等着你们呢。
