# 如果你的好友，他西装笔挺油光满面，张嘴亿万市场...

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=2652704804&idx=1&sn=7cbb7ed91f1e349628f7046641fd0f23&chksm=bd523efb8a25b7edc450743479492424eceef87f29ad40dd702f23a1affde01a3e318a9d958d&scene=126&sessionid=1681323452#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652704804&idx=1&sn=7cbb7ed91f1e349628f7046641fd0f23&chksm=bd523efb8a25b7edc450743479492424eceef87f29ad40dd702f23a1affde01a3e318a9d958d&scene=126&sessionid=1681323452#rd)

大家好，我是鹅师傅。

  

早前上海闵行区的打击非法金融活动领导小组办公室、闵行区法制宣传教育领导小组办公室，曾给市民发布过一个「**如何识别金融皮包公司**」的指南。

  

![](../Images/4193055b3b1bfbf53684c0f3578f2c72.png)

图片来自网络  

  

这个指南从**人员形象、微信特征、着装打扮、公司介绍、公司领导、产品介绍、沟通方式、官方网址、谈吐谈资**等九个方面，对正规公司和皮包公司进行了对比。

  

下面我们先来学习一下这个指南，感受正规军与骗子团这两者之间的巨大差别。

  

需要提醒的是，以下每个方面的辨认特征，“前者是正规公司，**后者是皮包公司”**，可千万别弄混了。

  

  

**1\. 人员形象**  

  

萎靡不振、眉头紧锁、张嘴就是监管政策，感叹最近可能要失业

  

![](../Images/40eb8db74ea5b527273da03c7440aaac.png)

**西装笔挺油光满面，张嘴国家政策、一带一路，动不动万亿市场**  

  

**2\. 微信特征**  

  

微信名没特点，朋友圈设置可见时间，回复经常很慢

  

**微信名前面加A，朋友圈全是嫌钱广告，称呼你不是哥就是姐**

**3\. 着装打扮**

  

背包多是瑞士军刀、Tumi

  

**腰上大H，背包多是Prada，Gucci**

  

**4\. 公司介绍**  

  

股东一笔带过，从不强调办公场所，所持金融牌照一行两会可查

  

**强调国企背景、上市公司（代码常常8开头）、强调办公地点在陆家嘴、CBD，上过央视**

**5\. 公司领导**  

  

一看就是职业经理人没股份，履历多在金融机构，从不晒合影

![](../Images/6532dac6592db1e878dab4eabf1b97e0.png)

**晒领导人及名人合影，学历不是清华北正大就是哈佛耶鲁，华尔街浸淫多年**

  

**6\. 产品介绍**  

  

不敢承诺，提示可能亏损，收益有不确

  

**拍胸脯保本保收益，强调公司实力，项目背景**

**7\. 沟通方式**  

  

请吃时扣扣索索偷偷摸摸，能开专票不开普票，金额大还得分几张

  

**旅游、请吃娱乐、桑拿一条龙**

  

  

**8\. 官方网站**  

  

制作精良、产品种类多但盈亏都有，党建团建滚动播放

  

**收益率标粗，所有产品都赚钱，24小时弹出美女客服问你要啥服务**

  

  

**9\. 谈吐谈资**  
  

熟悉资管新规，倒背八条底线

  

**熟悉海里的事儿，项目都是赵家的**

  

![](../Images/7c72ad7c34a532d01a776c34de6fdb36.png)

  

看着宣传单页上的强烈对比，鹅师傅突然有点心疼正规金融服务从业者的不容易。

  

同时也发现，金融骗子会针对公众的心理，通过夸大吹牛获取受害者的信任，从而骗取钱财。

  

**近年来，金融****理财、网贷等金融相关服务，也开始成为网络犯罪、网络诈骗的重灾区**。

  

毕竟诈骗套路都是千篇一律，不外乎编造故事，虚张声势。

  

受害者看中高收益的回报，骗子则是看中大家的本金。

  

上面这个识别金融皮包公司的方法，其实也可以用来识别网络上的金融诈骗。

  

网络上常见的金融骗局有这些：

  

**假银行假信托假基金：****骗子的胆很肥**

**虚拟货币庞氏玩法：****高收益、拉人有提成**

**外汇交易：****我国并未全面放开外汇交易**

**P2P跑路爆雷：****高收益实力坑人**  

**……**

  

这些骗子通过电话、社交平台、聊天群等方式，不断网罗受害者。当与骗子加上好友后，受害者往往会看到这些人具有上述“金融皮包公司从业者”的特征：

  

*   头像西装笔挺（**背后可能是团伙作案的抠脚大叔**）
    
*   聊天动不动就是某政策、亿万市场（**都是预先准备的剧本，复制粘贴即可**）
    
*   朋友圈里全是赚钱的截图（**有专门的工具，可以制作虚假截图**）
    
*   强调公司背景，晒名人合影（**朋友圈就是个立人设的地方，缺啥就晒啥**）
    

  

最常用的招数则是：

  

**拍着胸脯保证让你赚钱甚至本金翻好几倍，锤头顿足劝你不要错过暴富的机会。**

  

实际上：**嘿嘿嘿，我就等着傻子上当，把你的口袋掏空。**

  

总的来说，金融诈骗套路千万条，杜绝贪念第一条。

  

为了防止遭遇金融诈骗，有检察院公众号还为大家编了一个防骗口诀，可以说是来自检察官的防骗指南：

  

**广告冠名是噱头、巧辨名目是关键**

**迷惑人心是目的、一夜暴富是陷阱**

  

**网络借贷花样多、熟人介绍也谨慎**

**高息诱饵不动心、安全保本不可信**

  

**公募基金要资质、投资协议要弄清**

**任凭骗术千万变、不信不理不投钱**

  

**陌生电话需警惕、不贪小利和小贿**

**合伙经营非理财、了解核实莫大意**

  

总而言之，小心驶得万年船，牢记防骗口诀，警惕金融骗局，总能守护好口袋里的毛爷爷。
