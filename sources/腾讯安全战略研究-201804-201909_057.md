# TEDxSuzhou演讲：挖掘AI的善意和温度，向善而行

随着人工智能（AI）技术的不断发展，AI对于我们的生活，究竟是一道新的曙光，还是一个新的挑战？这是在科技高速发展的当下，人们高度关注的一个话题。

  

6月22日，在主题为“势，Momentum”的TEDxSuzhou 2019 年度大会上，腾讯“守护者计划”安全专家周正就“如何善用AI技术”做了主题演讲，用自己的实际经历告诉我们，AI的创新和应用需要我们做出更多善意的实践。

**用AI对抗网络诈骗，守护****百姓幸福**

  

AI等新技术的发展，在为人类的工作和生活带来方便的同时，也被不法分子利用，成为其盗取用户利益的新手段。面对日益严峻的网络安全态势挑战，如何缓解网络诈骗的高发态势、保护网络安全？

  

**腾讯创建了 “守护者计划”这个公益项目，联合政府、警方和互联网同行，一起探索如何治理网络诈骗和黑产，守护广大网民的用网安全。**过程中，腾讯守护者计划团队不断积累经验和能力，结合自身的科技优势，利用AI来对抗解决网络诈骗的恶意行为，摸索创新利用AI对抗黑产、保护网络安全的道路。

  

在探索和实践中，腾讯守护者计划利用AI赋能警企合作，协助政府和警方在诈骗发生的事前、事中、事后几个环节，共同做好识别预警、拦截阻断、打击治理、分析研究和用户教育，用AI去对抗网络诈骗，积极参与社会共治实践。

  

2018年“守护者计划”创新输出**AI反电信网络诈骗安全能力**，至今共协助各地政府和警方有效预警阻断电信网络诈骗超过**11万单**，保护8.5万人的网络和财产安全，预警金融风险**超604万次，覆盖152万人，共挽回经济损失约20亿**。

**AI解决传统社会难题，让科技更有温度**

  

“不给技术设限，引导它参与到社会问题的解决上，它能带给我们更多惊喜！”在演讲中周正说到。

  

在AI技术的创新及应用上，腾讯不断在传统社会难题方面进行探索实践。面对“如何找回被拐儿童” 这一传统社会难题，腾讯守护者计划利用AI技术寻人，协助警方寻找被拐孩子。

  

通过迭代设计5次、历经1000多次技术调整，持续优化AI精度至96%，协助警方不断缩小排查范围。至今年6月，腾讯打拐寻人联合团队用了近18个月，运用AI等多种技术方法，**协助警方成功找到多个拐卖儿童案件中的8名被拐超过10年的儿童**。

  

![](../Images/c8ab9aae48d2eeda034fb3f0d13d56e7.png)

  

不仅如此，作为中国最大的社交平台，腾讯关注到 “自杀抑郁”这个复杂的社会心理问题，内部多个团队联合发起“**微光行动**”，研究通过AI技术，提高自杀举报求助信息的识别能力，再结合人工比对校验，警企联动，来发现阻止网络自杀危害。“用爱的微光点亮内心的至暗时刻”，**微光行动发起近一年来，共协助警方在全国救助50人**。

**挖掘AI的善意和温度，向善而行**

  

“科技的温度，就是对一个又一个难题的不放弃，用新的思路去解决它的过程提升的。” 周正表示，一直以来，腾讯守护者计划团队秉承“科技向善”的信念，不断进行创新和探索，利用科技助力公益，让科技更有温度。在AI时代，腾讯守护者计划团队将更多的相信自身运用AI的能力和潜力，挖掘AI的善意和温度，善用科技，造福人类，共同努力去解决更多的社会难题。

**关于TEDxSuzhou城市大会**

TEDxSuzhou 于 2011 年获得 TED 总部审批，由苏州本地团队以非营利组织的方式独立运营。TEDxSuzhou 秉着“传播有价值的思想”的理念，着重关注于科技、教育和发展，致力整合线上和线下手段打造一个创新型社区。

  

本次2019城市大会的主题为“Momentum 势”，Momentum指那些推动万事万物发展和成功的力量，“势”源于老子的道家学派。中国人普遍相信追随势即遵循一种顺其自然的力量，更能获得成功。本次大会的演讲人就是各自领域的“势”，他们正在以他们的影响力推动社会进步。他们所相信和追寻的想法将激励当下和未来，引领更深刻和广泛的进步。
