# 色情网站被查牵出一条黑色产业链，创办人竟是19岁青年

      近日，江苏徐州警方经缜密侦查，捣毁了一个集线上网站、线下技术支持与资金结算的网络传播淫秽色情信息的黑色产业链，摧毁相关淫秽色情网站100多个，赴重庆、上海、青海、宁夏等12省区市抓获31名嫌疑人。

      今年1月，徐州市公安局新城分局网安大队在工作中发现一个网站涉嫌传播淫秽色情信息，且含有大量疑似儿童淫秽色情视频，网安大队向分局和市局网安支队汇报后。该局成立专案组，支队提供技术支持，经过深入侦查，民警发现该网站开办者竟然是一名活跃在上海的19岁青年徐某。专案民警赶赴上海将徐某抓获。

 

![](../Images/1f0db25fedef61acc055c48b591c84d8.png)

  

经查，该网站开办者竟然是19岁的上海青年徐某。为了彻底将该网站清除，民警前往上海将徐某抓获。据徐某交代，为了获得高额暴利，他利用自己掌握的互联网知识，建立一个通过会员充值的形式赚取钱财的色情网站。

 

运营一段时间后，徐某发现仅仅在PC端传播已不能满足他的消费需要。为了让这些淫秽视频传播得更多更快，徐某以每年1480元的价格，向一QQ昵称为“云转码”的网民购买了一款视频云转码软件，专门用于将淫秽视频文件上传转码。

 

![](../Images/6512df0fc0709c12d281d6fa2d943e31.png)

  

警方顺藤摸瓜，发现“云转码”涉嫌为多个淫秽色情网站提供视频转码软件的技术支持。软件作者还专门组建了几个QQ群，用来与购买过软件的网站站长进行技术交流。

 

“当时我们就分析认为，这背后肯定隐藏着一条特大淫秽色情犯罪产业链条，决定将其连根拔除。”办案民警说。

 

![](../Images/b040530b16120ec236530a04774c5fe6.png)

  

团伙成员分工明确

专案民警深度侦查掌握其组织脉络

![](../Images/cee9aaa8a9b409f12047ccde22207aa8.png)

  

      警方迅速查明，网名“云转码”真实身份为罗某某，他还注册成立了一家网络科技公司，通过QQ、淘宝等渠道销售云转码软件，供多家淫秽网站使用牟利。他还雇用两名技术人员，分别负责云转码软件编写设计和技术保障。

 

![](../Images/a5b90feb288b816dc55ab659efc14f15.png)

  

经查实，多个购买了云转码软件的人员开办了“X机论坛”“X船论坛”等百余个淫秽色情网站，会员数量高达几十万，非法牟利400余万元。经梳理，专案组明确了该团伙组织框架。

 

![](../Images/e8dd164814cf3cbc3f949370c891f3d5.png)

  

12省市统一收网

成功破获特大传播淫秽色情视频牟利案

![](../Images/cee9aaa8a9b409f12047ccde22207aa8.png)

  

      今年2月下旬，在掌握了大量证据后，徐州警方统一部署，调集100余名警力分赴重庆、上海、青海、宁夏、山西、吉林、湖南、湖北、北京、安徽、江苏、广东12个省区市开展抓捕工作，抓获包括罗某某在内的犯罪嫌疑人26名。3月28日，警方又在内蒙古自治区乌海市将涉嫌为淫秽色情网站提供支付通道、结算平台的5名犯罪嫌疑人抓获。至此，案件告破。
