# 国际禁毒日 腾讯严厉打击网络涉毒行为

      众所周知毒品的危害极大，一旦沾染，毁掉的不仅是个人，更是毁掉了家庭。今年的6月26日是第31个国际禁毒日，本届禁毒日，我国的主题为“健康人生、绿色无毒”。

      面对复杂的网络环境和与日俱增的网络风险，腾讯公司一直在高度重视相关的网络安全工作，并形成了一套集“技术防控-举报-打击-教育”为一体的互联网预防及打击涉毒机制。  

 

目前，腾讯安全团队已经建立了线上有害信息的防控体系，通过技术能力和风控模型加强防控，智能化识别涉毒等行为的特征。此外，腾讯安全团队也在安全审核过程中运用到各类新技术，如大数据、图片的识别能力等，不断提升平台上自动化巡查和处置的效率。2018年1-6月，腾讯安全团队通过技术措施配合严格核验，累计识别并关停违规“涉毒”公众帐号180余个，群组2800余个。

 

打击网络涉毒等违规行为是一个长期的系统工程，仅靠一个平台远远不够，还需要更多平台、政府机构参与，形成线上、线下联动的打击矩阵。腾讯安全团队针对当前互联网平台上发现的“涉毒”等违规行为进行打击的同时，积极配合各地公安机关进行对网络贩毒的线下打击工作。2018年以来，腾讯安全团队配合各地公安机关打击毒品犯罪案件3起，抓获从事网络贩毒违法犯罪人员共计90余人。

   

同时，我们呼吁广大网民提高自我保护意识，不给违规行为可乘之机。如果发现相关违规行为，可以通过腾讯安全服务平台110.qq.com等通道随时举报涉毒等非法信息。一旦发现违规行为，腾讯安全团队将第一时间进行严肃处理。

      此外，腾讯安全团队基于自身技术与渠道优势，不断进行网络禁毒社会宣导，树立网络空间不是法外之地的普遍共识。促进广大网民，尤其是青少年群体强化网络安全素养，规范自身网上行为，并自觉抵制网络毒品等违法犯罪行为的侵害。  

 

腾讯安全团队通过立体化打击违规行为，给制毒贩毒等黑产予以震慑，同时也希望网民、平台、政府机构群防群治，让网络违法、违规和不良信息无处遁形。
