# 苹果推出数据隐私网站 允许用户下载Apple ID数据

      为了响应欧盟的通用数据保护条例（GDPR），苹果推出数据隐私网站，作为该条例的一部分，苹果需要向欧洲地区用户提供能够查看、修改、下载和删除个人数据的方式。

  

      据国外媒体报道，苹果刚刚推出了一个全新的数据和隐私门户网站，可以让用户更方便的下载保存在公司服务器上的所有个人数据。同时用户还可以修改苹果收集的个人信息，或者选择彻底关闭或删除自己的账户。

 

![](../Images/d5d50780816635ebe8c60978495d58e4.png)

 

苹果该项数据与隐私网站计划最初在今年3月公布，本周三正式率先在欧洲地区上线。对所有想要获取自己被上传到苹果服务器信息的用户来说，这个网站提供了一站式的服务，可以允许iCloud和苹果其它服务的用户管理自己的个人数据，包括修改或者直接从苹果的服务器中删除。

  

其中最主要的功能是“获取你的数据备份”，包括了大量的用户个人信息，比如购买和应用的下载历史、以及用户允许储存在苹果服务上的数据。可供下载的数据类型包括Apple ID和设备数据、在线及苹果零售店活动、AppleCare支持历史和请求、游戏中心和苹果在线商店各种相关的活动。

  

同时用户还可以选择手动管理这些保存在iCloud上的数据，包括iCloud Drive、iCloud Mail以及iCloud Photos等。

  

苹果提醒，下载的内容不包括购买的应用、书籍、电影、电视节目和音乐，也不包括苹果在线商店的交易历史和营销传播历史记录，不过后两项内容可以通过其它方式请求获取。

 

![](../Images/a689c97f2cadc2531a50936d10e2d9a2.png)

 

苹果表示，在用户提出下载申请后，需要等待7天的时间来准备数据，同时苹果在这段时间内还会验证这一请求是来自于用户自身还是第三方。一旦确定，苹果会对用户发出通知，然后通过Apple ID的账户页面下载。

  

这些数据在下载后的14天内会被删除，之后用户如果想要再次请求下载数据，还需要重新等待7天的时间。

  

除了下载备份数据之外，该网站提供的另一个功能就是“更正修改数据”，用户可以随时更新自己的个人信息。尽管之前通过苹果商店和Apple ID页面也能直接修改用户资料，但如果用户需要更多的帮助，苹果还提供了与隐私团队直接沟通的链接。

  

新的数据和隐私网站是苹果为了响应欧盟的通用数据保护条例（GDPR）而推出，该条例将从5月25日起生效。作为该条例的一部分，苹果需要向欧洲地区用户提供能够查看、修改、下载和删除个人数据的方式。

  

目前该数据下载页面只适用于在欧盟地区注册的Apple ID，同时还包括冰岛、列支敦士登、挪威及瑞士。其它国家用户想要使用这项服务，还需要等到今年年底。

  

苹果公司发言人表示，欧盟新法律的实施也符合苹果的隐私价值观，并且给苹果提供了一个机会，能够让用户对自己的数据拥有更多的控制权。尽管之前也有很多在线工具等方式让用户获取、修改和删除数据，或者还可以直接通过AppleCare调取，但这个新网站为用户提供了一条龙的服务，将所有的内容都整合到了一起。（音希）
