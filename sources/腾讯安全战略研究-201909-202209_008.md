# 为及早发现老人摔倒，鹅厂程序员摔了上万次

摔倒，是一个听上去就很痛的词。 

  

走路看手机，一不留神踩坑里，摔

  

![](../Images/c2528a5f562fb8d63f6ed508a6ecb880.png)

  

空手投篮耍个帅，摔

  

![](../Images/e4a3c42d03144361ddad30e051c70b2b.png)

 

甚至，蹲坑久了腿麻......也摔

  

![](../Images/8c7279a91e01876a7dac397869128858.png)

  

这些“社死”的瞬间，大家都不希望被人看见，想赶紧起身逃离地球。   

 

唯独有一种摔倒，我们希望能及时发现，和快速救治。 

  

那就是独居的高龄老年人的意外摔倒。

世界卫生组织报告显示，跌倒已成为造成60岁以上老年人伤害死亡的首位原因。 

  

摔倒后，如果没有及时发现并救治，因摔伤导致的骨折、卧床的肺部感染等都是老年人致死的高风险事件。 

  

***1***

**家里来了一位“隐形护理员”**

  

怎么才能及时发现？ 

  

腾讯SSV银发科技实验室、安全平台部、微瓴团队、天籁实验室联合，升级了一款智慧养老AI守护产品——“隐形护理员”。

  

![](../Images/f27fd428576a7a62e725ff1e214a4043.png)

 

在家中，通过智能摄像头和AI算法，一旦检测到老年人跌倒或需要呼救时，就会主动发出警报，及时通知亲属。

  

![](../Images/dbfc76fced156103c041399b3a1c0abf.png) 

***2***

**能听懂“救命”的AI**

“隐形护理员”还有“呼救词检测”功能。   

 

在摄像头取景范围外，只要喊“救命救命”，也能触发AI发出警报。 

  

![](../Images/f2f7b9f352248bb539a79dd45b4a6271.png)

       

它还在逐步学习各类方言，争取能听懂老年人的各种“呼救词”。

  

此外，我们还给它配备了双向语音功能，方便老年人随时跟亲属语音对话，一键就通。

  

未来它还将跟社区服务打通，接入更多助老服务。   

  

今年内我们将联合深圳市老龄事业发展基金会，把这款产品捐赠给超过1000户老年人家庭，会优先选择高龄、空巢、独居且失能失智的老年人家庭。 

  

今年年底，我们还会把它送往广东、甘肃等省份。

  

***3***

**靠“假摔”训练出来的AI**

为了让AI精准分辨出摔倒，项目组小伙伴们开始了一次次的“假摔”。 

  

客厅里

  

![](../Images/3a593570882ebaaabe9d2f46ba508a6a.png)

  

走在路上

  

![](../Images/891c5307248cb0262afe3ec6518d3ff3.png)

 

办公室里

  

![](../Images/99101f6ec488348636d7ab02e2cbdecc.png)

  

甚至在餐厅里来个多角度、全方位、正反面摔

  

![](../Images/e282146ce22efecc152c8785f2da3ee0.png)

  

最终，在大家的不懈摔倒努力下，这位“隐形护理员”业务能力已相当成熟。

  

![](../Images/9f1488a85903813174eaa17d8e26084f.png)

  

2019年在深圳市养老护理院成功落地，AI识别准确率达到90%以上。

  

![](../Images/6fa27b928123befda403e925e9e8b4c4.png)

  

在深圳市民政局的共同推动下，我们将逐步在深圳市公办养老机构推广，以后还会到北京、广州、重庆等老龄化程度较高城市的机构和家庭中去。 

  

未来，我们将继续用共创的方法，用我们的科技和创新能力，探索更多可持续的解决方案。 

  

技术能帮我们解决老年人的很多痛点。   

 

但远方的惦念与AI的守护，终抵不过在身旁的照顾。 

  

希望大家有空常回家看看。
