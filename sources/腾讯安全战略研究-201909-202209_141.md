# 黑话四大规律独家总结，打击黑产进阶必备

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5MTA0NjU3Ng==&mid=2652714848&idx=1&sn=0a99b546627bdddac5b33247410de75e&chksm=bd5219bf8a2590a9bf336cc39beba9fdaa9a1f1b2482559396b5183b48ea39db99739958ee1a&scene=126&sessionid=1681323342#rd](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652714848&idx=1&sn=0a99b546627bdddac5b33247410de75e&chksm=bd5219bf8a2590a9bf336cc39beba9fdaa9a1f1b2482559396b5183b48ea39db99739958ee1a&scene=126&sessionid=1681323342#rd)

![](../Images/e07a715ccb45180dd9e5b6469edb4798.png)经常会有读者问鹅师傅，能不能搞一期黑灰产黑话入门？ 当然能！ 黑话肥，灰话肥，黑灰话肥……混迹黑灰产多年，鹅师傅除了擅长本家大厂黑话，黑灰产黑话也不在话下。 黑灰产领域门类繁杂，博大精深，为了躲避网络平台治理策略，个人信息黑产、网络账号黑产、色情、赌博等等，只要是见不得光的，都有一套话语体系。 任何话语，都是用来交流沟通的。像英语的格林法则、维尔纳定律一样，黑话也是有一定规律可循的。 为了帮助大家了解黑灰产的真面目，做到“知己知彼，百战不殆”，鹅师傅阅遍千万黑话，总结出一套独家黑话规律！  

***1***

**规律一：谐音梗**

  
黑灰产不能见光，但最终还得见人。没有“客户”的黑灰产无法存活下去。

  

正因如此，第一规律便是谐音梗。谐音在黑灰产领域颇受欢迎，尤其是需要大量引流揽客的色情、赌博行业。

  

借助谐音，很多黑话不用特别记忆，一看就会，躲避平台监管的同时，也不影响吸引更多潜在“客户”。

  

最为简单的，比如涩播，念出来你就会了，涩播=色播。  
![](../Images/1deb38da76e3bb381aa2be8b9a7c3e6b.png)  
不过，还有一些谐音在特定领域使用，不易理解。下面由鹅师傅带你梳理下重点难点。  
**1. 菠菜****释义：**博彩的谐音。菠菜当属黑话届元老级代表，至今盛行不衰。**场景：**常用于网络赌博吸引客户的各类场景。  
**2.碧玺****释义：**“必喜”、 “必洗”的谐音。也称 “必玺”。“必喜”意指交易成功率极高的坐台女。取“必定是客人喜欢的款”之意。“必洗”则有“必定能让客人洗澡”之意。  
![](../Images/e3f2c355d48f73d790a18aab93ab8e0a.png)  
**3．猪蹄****释义：**主推的谐音，专指赌博中介、赌博推广。多见于网络赌博领域。**变化：**和主推并列的，还有“狗推”。也是赌博推广业务员。不同的是，“狗推”不仅网络赌博推广业务员，其本身也是被人以高薪骗到国外的受害者。  

***2***

**规律二：缩写诀**

  
黑话也讲求成本与效率，而性价比最高的，当属缩写诀。

  

缩写诀主要分为三类，中文缩写、中文拼音缩写、英文缩写，其中拼音缩写数量最多。和谐音规则不同，缩写常见于比较专业或小众的黑产领域，个人信息贩卖、代孕黑产等。  
**中文缩写——**  
**1.二证****释义：**二代身份证，常见于个人信息贩卖黑产。  
![](../Images/a3358567af4ef2be4e8245882472e4bc.png)  
**2.银图生成器****释义：**特指手机银行截图生成器。  
![](../Images/9275db44016a23d8227f65c40dd4b19b.png)  
**场景：**常常被网络诈骗分子用来骗取钱财，多见于冒充领导诈骗。以领导身份特殊、转账不便为由，要求帮忙代为转账，领导为了证明已转账，会立即发送转账截图。  
![](../Images/cd8b7f209d68a326633e1eae78226488.png)  
**英文缩写——**  
**1.UID&IPCAM****释义：**UID 是“User Identification”（用户身份证明）的缩写,Ipcam则是“ip network camera”的缩写，意思就是网络摄像头。所以，意思UID就是网络摄像头监控软件的用户ID。**场景：**常见于资源贩卖群。  
**2.CVV料****释义：**CVV是“Card  Verification  Value”的缩写，是指被存储在磁条银行卡磁道中的信息，包括卡号、磁道主账号、发卡银行标志代码等。**场景：**常见于个人信息贩卖黑产，CVV料通常指信用卡卡号、姓名、安全码、到期日期四项信息。  
![](../Images/556d6e949e10b920d7e661b772a1a71d.png)  
**拼音缩写——**  
**1. SFZ****释义：**即身份证，行业内为避免打击，多使用拼音缩写。**引申：**手持SFZ。手持身份证照片或视频，常用于注册证件、账户等，也常见于账号解封圈子。  
![](../Images/76a3bd8f815ed9bb1edd35e4e6cc2af8.png)  
**2.WZ/JZ/BC****释义：**分别指网赚粉、兼职粉、博彩粉。**场景：**常见于售卖粉丝账号资源。  
![](../Images/a52a4b81fc63e1379528d71dd86356b7.png)  
**3.HX****释义：**后续的拼音缩写。一词多义，在网络诈骗指专门对接钓鱼的诈骗环节。也有洗钱之意，或称XK（洗卡），是洗钱圈子内常用代称。  
**4.KH****释义：**同客户拼音谐音。**变异：**KH被称为男同学。**场景：**常见于代孕黑灰产领域。  
![](../Images/42224a2fcfb0335a8d8e2746cbfe8600.png)  
**5. KPP****释义：**意为嗑炮。指双方以语音方式满足性幻想，包括聊“性行为”有关的内容等。**引申：**文爱/语爱/视频磕**造句：**有偿征萝莉语聊连麦KPP，视频磕加米**翻译：**付费找幼女语音连麦磕炮，愿意可视频磕炮的加钱  
![](../Images/8bebb32458da6d0835ea038468d101dd.png)  

***3***

**规律三：种子词衍生**

  
类似于英文的词根，黑产黑话也有很多核心字词，被称之为种子词，常见种子词如“料”、“信”、“雷”。  
**种子词：料****释义：有物料、信息之意。**  
![](../Images/b8fb13a020abae0f8b4e2f0a6a85f5c1.png)  
**1.下料****释义：**在盗刷圈子内特指违法收集盗取信用卡/储蓄卡四大件信息的行为。**引申：**专门从事该行为的人被称为下料人。  
**2\. 料主****释义：**又称菜商、卡商，一般指手中掌握大量银行卡、信用卡、各类个人信息的人。  
![](../Images/0ba8a61231760594f581266fc9667dfd.png)  
**3.内料/外料****释义：**根据物料来源不同分类，代指国内银行卡、国外银行卡。  
![](../Images/09afb3607e7e9c7b9ed7f3bc0087f8e0.png)  
**4.嗅料/盗S料****释义：**根据获取物料的手段不同分类。嗅料即通过嗅探技术获取的个人信息，盗S料即盗刷获取的个人信息。  
**5\. 菠菜料/轨道料****释义：**根据物料种类不同分类。菠菜料即从博彩网站上扒取的银行卡信息，轨道料特指银行卡的磁条信息。  
![](../Images/73dad39a090f061c4ad02f0a339ad322.png)  
**种子词：信****释义：源于信封号，泛指各类网络账号资源，围绕“信”衍生出关联黑话。**  
![](../Images/a37d60275c579f02e93cb5a7b8424951.png)  
**1\. 信使****释义：**指专门售卖信封号的号商。  
**2.一手信/二手信****释义：**一手信即被盗的账号没有做过任何业务，二手信指被盗账号已做过业务。  
**3.取信****释义：**通过各种手段盗取的网络账号和密码，以每万条为一个单位进行整理，拿到这些信息就被称为取信。  
**4.洗信****释义：**将信封号里面有价值的零钱、游戏装备等洗劫清空的过程。  
不过，伴随平台安全策略完善，被盗账号黑市已经逐渐萎缩，如今，更多的是[恶意注册、出租、解封网络账号](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652714505&idx=1&sn=ebe9f146beab257458f6e7a9c3630d71&chksm=bd5218d68a2591c01a151d770686531055862fd9cd6f969186538117cc57caf0ac3b7a9722c4&scene=21#wechat_redirect)等违法犯罪活动。  
有时候，种子词的衍生发展也反映了黑产的发展形势，比如**“农”**，源于“卡农”，指代**为电信网络诈骗分子提供银行账户搭建洗钱通道的人群**，但伴随“断卡行动”，电信诈骗团伙逐渐转向利用**二维码**、**虚拟货币**等通道洗钱，也就有了我们之前科普过的[码农、币农](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652714466&idx=1&sn=a6adb034b2ca7db4f93950da660ff8c9&chksm=bd521b3d8a25922b2b457ec4a74f72f43917f7ae9f637b225dd040d3570953379241cea380fc&scene=21#wechat_redirect)**[](http://mp.weixin.qq.com/s?__biz=MjM5MTA0NjU3Ng==&mid=2652714466&idx=1&sn=a6adb034b2ca7db4f93950da660ff8c9&chksm=bd521b3d8a25922b2b457ec4a74f72f43917f7ae9f637b225dd040d3570953379241cea380fc&scene=21#wechat_redirect)。** 

***4***

**规律四：火星文**

  
**火星文与火星无关，地球土特产。**火星文早期源于年轻网友特立独行的表达方式，由符号、繁体字、日文、韩文、冷僻字或汉字拆分后的部分等非正规化文字符号组合而成。根据对偏旁部首不同的解读方式，**可分为象形、混合、分离三种。**  
![](../Images/71dbc5c22a3c082eca89a7ec9258da87.png)  
**1.  5m爱好者****释义：**象形火星文。5m的5是s的象形数，也就是SM爱好者。（自行想象，不做解释） **2\. ④剣套**![](../Images/e4e55c3115bd7a54ff4561e0cc49be54.png)**释义：**混合火星文。收4件套，四件套包括身份证、银行卡、实名电话卡及网银卡盾四件能证明个人身份真实性的材料。**场景：**常被用于注册各类账号、薅羊毛、洗钱等违法犯罪活动。  
 **3. 木仓****释义：**分离火星文。枪的变异字体。**场景：**常见于非法交易枪支弹药等犯罪。  
**借助火星文，黑灰产业在规避监管与快速推广之间取得了平衡。火星文有专门的转换器，是唯一实现自动化输出的黑话规律，可谓十分方便。**
