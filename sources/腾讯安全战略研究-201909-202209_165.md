# 紧急预警！注意防范新一轮“疫苗诈骗”！

大家好，我是鹅师傅。  

  
过去几周，新冠疫情在国内有所反弹。随着本地病例的增多，原本不愿接种疫苗的居民，纷纷加入了接种疫苗的大军。在疫情相对严重的广东，甚至出现了**排长队、难预约**等情况。鹅师傅最近广深两地出差，也是瑟瑟发抖。  
![](../Images/53780962992c0723b4380898c4246748.png)  
略微抬头的疫情，放大了人们想要尽快接种疫苗，守护自己和家人健康的心理，骗子们也不甘寂寞，开始玩出各种“新花样”。 **以下几种利用新冠疫苗接种实施的诈骗行为在实践中已出现，鹅师傅在此提醒大家注意，并呼吁转发给身边亲友。** 

***1***

**群发“疫苗预约”短信，通过“钓鱼”获取个人信息**

在此类犯罪中，诈骗分子冒充疾管中心，以**“预约疫苗接种”**为由，发送含有**“钓鱼网站”**链接的短信（如下图所示）给用户，诱导用户点击链接。  
  
![](../Images/bd9b3a52bd65043b0e67aed37fc57c78.png)  
链接点进去后，是下图这样的：  
![](../Images/e1ef4e5ba8b69be0a848dee4b4661edc.png)  
此类群发短信类诈骗，除了获取公民个人信息之外，也是一种针对受害人的“海选”。毕竟诈骗手段如此拙劣，后续定向诈骗成功率很高。  

***2***

**“卧底”班级群，冒充班主任骗取接种费**

在此类犯罪中，骗子先是在QQ、微信检索“班级群”“通知群”等群聊信息，冒充学生家长混入群中潜伏。 作案时机往往选择在深夜或班主任下线之后，骗子立马会**将头像和昵称改成和班主任一样，冒充班主任发布收费通知、二维码等虚假信息**（如下图），收取费用后逃之夭夭。  
![](../Images/f37994bdfba72e8d30e068e9ca379c97.png)图片来源：人民日报  

***3***

**冒充疫情防控工作人员，设下各种圈套**

在此类犯罪中，骗子会伪造**国家疾控中心工作人员、疫苗接种员**等身份，在电话中**要求核对个人信息**，借机套取用户个人信息，下图便是一起真实案例。  
![](../Images/60d691e5a9160f9dd459f5ca87552f17.png)图片来源：潇湘晨报  
或者先添加用户微信，**将其拉进“疫苗接种群”后，后续在群中发布刷单、传销等诈骗信息。**  
![](../Images/4014e8f440fbeab9b2b96730e7e27e2d.png)图片来源：荔枝网  

***4***

**有偿代预约疫苗，收取费用后逃匿**

在此类犯罪中，骗子会谎称自己属于**“内部人士”**或者**“有关系”**，**只要支付一定的额外费用，就可以优先打到疫苗**，进而索取金钱或者个人信息。骗子先是主动加好友，**称可以有偿代预约疫苗名额，预约成功后会有短信提醒，预约失败则退钱。**  
此类诈骗往往发生在疫情反复区域，利用人们的恐慌心理作案。一旦收取了费用，骗子从此就失联了，**受害人****打疫苗的心情越是急迫，越容易着了骗子的道儿。**![](../Images/4093569a31a203f13b0e5df30cc3baf1.png)  
总而言之，骗子们永远不会放过任何一个“蹭热点”的机会。**尽管这些“花把式”无非是将电信网络诈骗的“老套路”换上新冠疫苗接种的“新皮”，但在当前国内疫情反弹的紧张形势下，有必要提起足够的警惕。**  
在此，鹅师傅提醒大家：  
**1.国家已一再强调接种新冠疫苗全民免费，只要疫苗接种和付费扯上关系，一定是假消息。**  
**2.疫苗接种消息的发布自始至终通过官方渠道进行，不要相信来路不明的截图信息。**  
**3.平时要注意保护个人信息，不在陌生网站输入自己的身份证号码、手机号码等信息。**  
**4.如果还是难以分辨，或者对是否属于诈骗心存疑虑，可以拨打全国反诈中心预警专号“96110”进行咨询。**  
**5.接种新冠疫苗是一项大工程，需要统筹安排。打疫苗总比不打好，只要是国药、科兴之类的正规疫苗，无须过度观望，尽快网上预约接种即可。**  
新冠疫苗要打，防骗“疫苗”也要跟上。鹅师傅坚信，在大家的共同努力下，看似猖獗的疫情很快就会再度得到控制，骗子们也不会有任何发“国难财”的机会。  
**最后一点，****转发让更多人知****道，不说了，鹅师傅预约疫苗去了。逃~**
