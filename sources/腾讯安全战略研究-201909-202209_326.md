不知道大家有没有听说过一种骗术，名叫「杀猪盘」。所谓杀猪盘，指的是诈骗团伙利用情感关系，把受害者「饲养」在自己的精神控制里，一步步骗取钱财。  
  
![](../Images/a14be5b25a0efceb3c09bfc8f0d892a1.png)  
今天这个故事的讲述者名叫 S。不久前，她经历了一场长达 13 天的「杀猪盘」骗局。  
  
  
  
  
  
  
**低配陈冠希**  
  
我是 S，目前生活在上海，在教育行业工作。  
去年，我在世纪佳缘注册了一个账号，在自己的个人资料里标明了职业、年龄、工作所在地，以及房产信息。几个月以来，我经常会收到平台推送来的各种搭讪信息，但其中大部分人没有让我产生进一步交流的兴趣。  
直到今年 4 月 9 日的下午，我发现平台给我推来了一条新的搭讪信息。发来信息的这位骗子……慢着，我暂时还不知道他是骗子，那我们就叫他 C 吧。  
C 的这条消息是那天上午发出的：「上午好，上午好，我叫徐震，可以认识一下吗？」  
在信息下方，世纪佳缘系统显示，这是一条「异地求偶」信息，对方所在地是香港。  
![](../Images/185904d5b593daa2acc82990156a1589.png)  
我点开了 C 的个人信息页面，感觉他各方面条件都不错，尤其是照片。说到这里，我还挺惭愧的，「颜控」真是要不得。如今回头来看，在很长一段时间里，我都是因为这几张照片而给他加上了一层滤镜——他有张自拍照乍一看很像年轻时的陈冠希。  
于是，我给他回复了消息：「你是不是在香港？」  
他说，「是的，但我下个月就要回内地来发展，我们公司在上海有分公司。」  

> 📝知识点：  
> S 在后来复盘的时候才发现，这位 C 在一开始的时候，就在不经意间使用了一条「杀猪盘」骗局的惯常套路。  
> 在骗局中，由于骗子所使用的个人信息，包括照片，全都是伪造的，他们往往会声称自己和受害人身在异地，无法见面；但与此同时，他们又会告诉对方，不久之后，自己就会因为搬家，或者是工作调动的原因，前往受害者所在的城市。这样一来，在情感骗局中，受害者会误认为自己很快就能和这位「网恋对象」奔现，这样一来，感情进程也会更快一些。

  
接下来，我和他简单聊了一下各自的工作和爱好。我告诉他，我平时非常喜欢听音乐，他立刻附和，说自己也喜欢，尤其喜欢陈奕迅。  
顺着这个话题，我们又随便聊了几句。然后，他便问我能不能交换联系方式。  
我问，「你有没有微信？」  
他说，「我加你 QQ 吧。」  
对话进行到这里，我心里微微有点奇怪，现在一般来说，我们认识新的朋友，不都是交换微信吗？但我也没多想，还是加了他的 QQ。  

> 📝知识点：  
> S 后来才发现，C 之所以用 QQ 和她联系，而不是微信，是有着非常实际的原因的。在微信平台上，一旦某位用户受到多次举报，当你试图添加他为好友时，系统会发来「此用户涉及违规行为，请谨慎联络」的提示信息。  
> 按照 S 的猜测，这位 C 的微信账号可能已经被好几位之前的受害者举报过了。因此，他才会使用一个「干净」的 QQ 账号，降低暴露的风险。

  
  
  
  
  
  
  
  
**「养猪」技巧一：避免「见光死」**  
  
进入聊天模式后，他介绍了一下自己的工作。按照他的说法，他是在「香港联合服务有限公司」工作。我还特意搜索了一下这个公司，发现确实存在一个官网。官网显示，这家公司是做数据服务的，在上海确实有一家分公司。  
我又问他，「你住在香港哪一带啊？」  
他立刻说出了一个很详细的地址，大约是香港某某商业楼。如今回想起来，这种说法也蛮奇怪的。正常情况下，面对一个新认识的人，难道不该说自己住在「中环」「湾仔」之类粗略的位置吗？但在当时，我也没多想。  

> 📝知识点：  
> 在 S 看来，从这个细节可以看出，C 的手中是有一份详尽的「剧本」的。  
> 在杀猪盘团伙中，除了像 C 这样负责出来迷惑受害人的「演员」，也就是所谓的「狗推」以外，他的其他同伙需要帮他设计剧本，他在行骗过程中的所有言行都必须被限定在「人设」当中。  
> 如今回头来看，C 在这个骗局里的人设很清晰，甚至可以说很有魅力。在剧本中，他就是一个年轻有为的香港 IT 高管。

  
C 接着告诉我，他来香港四年了。刚来香港的时候，同事把什么活儿活都丢给他，他觉得什么反正也没事，多做一点也没关系，后面慢慢的，老板也开始重用他了。  
顺着这个话题，他抛出了一个重要信息：「后来，我们副总推荐我去做了主管。不过同时，我也失去了和妈妈视频通话的机会。」  
我轻易地上钩了，好奇地问他是怎么一回事。他便告诉我，他们公司的员工配置的手机，「他们给我们这些高管的手机植入了代码，摄像头是黑的，就是说，视频时，我看得到我妈，但是我妈看不到我。」  
![](../Images/dd5592d7c23be0385e0c540b54a56691.png)  

> 📝知识点：  
> 为了掩饰自己的身份，「狗推」一般都会编造借口，避免和受害人视频聊天。C 所使用的是一种很常规的借口。  
> 在过往的社会新闻中，有的狗推会在这个环节编造更为离奇的借口。比方说，他们会谎称自己的某位前女友是在和他视频聊天时，遭遇车祸去世的，给他留下了心理阴影。  
> 在骗术中，这种看似愚蠢的借口也算是一种过滤机制。对骗子来说，如果受害者连这种蹩脚的借口都信，那么，他们交出钱财的几率也就更大了。

  

  
  
  
  
  
  
**「养猪」技巧二：灵魂伴侣，相见恨晚**  
从第二天开始，C 每天九点多钟都会像上班打卡一样来向我问候「早安」；下午两点半左右，他又会来问候「下午好」；晚上，他会聊得久一点，一般到了十二点左右，他说主动说「晚安」。  
差不多 2:30 左右这个时间段，他又会跟你说一下，他刚刚午睡睡醒了，然后再来跟你问一个好，  
晚上开始会跟你聊的，逐渐的多一点，  
然后一般情况下，如果你不主动说你要先睡觉，他如果主动提出跟你说的玩的话，差不多是 10 到 12 点左右这个时间。  
![](../Images/067a8164507deed7671e6233d87cc5f9.png)  

> 📝知识点：  
> C 刚刚所展示的，就是杀猪盘在初始阶段所使用的技巧之一，也就是「打卡式聊天」，这种方法能够帮助他们悄无声息地进入受害人的生活，从而建立信任和好感。  
> 而在聊天过程中，他们遵循的第二个技巧就是，迎合对方的一切想法和爱好。  
> 比方说，就像最开始说的，当 S 说自己喜欢音乐时，哪怕 C 对音乐知之甚少，他也要强行给自己披上一层「陈奕迅歌迷」的人设。而 S 在对话中表达出自己的某些价值观时，C 也会立即附和。  
> 长此以往，受骗者就会产生一种错觉，以为自己遇到了一个真正懂得自己的灵魂伴侣。

  
有一次，在聊天时，我特意问他，「你不会是骗财又骗色的骗子吧？怎么会有人和我这个怪人聊得这么好？」  
他说，「是你把自己隐藏的太好了，你不怪，你只是不愿意把时间浪费在自己不感兴趣的人和事上面。」  
  
  
  
  
  
  
**「养猪」技巧三：倾诉伤痛往事**  
有一次，他问我，「你的情感经历怎么样？」  
我给他简单说了一下，又问他，「你的情感经历怎么样？」  
过了一会儿，他给我发来了这么一大段：

他打这段文字的时候，中间没有任何的标点符号，只有空格键。  
第一眼看到的时候，我觉得有点奇怪。一般来说，谈到情感经历，一般人是不会说得这么详细的。但这个念头也就是一闪而过，毕竟，那个时候，我对他还是有好感的，甚至还因为他分享的这段经历感到有些同情，并增加了一些好感。  
  
  
  
  
  
  
  
**「养猪」技巧四：摸清她有多少钱可以骗**  
  
聊天的前五天，我对他没有丝毫防备，傻乎乎地把一些个人信息透露给了他，包括我的个人信息。他也时常旁敲侧击地打听我的工作细节，尤其是薪资的状况。  
比方说，他会问我，「你正式上课的时候，一天有几节课？」  
再比如说，他会问，「你平时会不会有什么外快？寒假暑假有没有补习班？」  
我也没警觉，只是告诉他，「补习是有风险的，万一举报什么的是要被开除掉的。」  
说完这句话，他就岔开话题了，没有再往下问了。  
我估计，一旦我在某一天，开始顺着这个话题和他聊起怎么才能赚外快，骗局的收网工作就正式开始了。  
  
  
  
  
  
  
**「养猪」技巧五：明确建立情侣关系**  
聊到第五天，他突然提出要和我明确情侣关系。  
当时情况是这样的，我和他聊到，我爸妈又在逼我相亲。然后，他开解了我几句，我便给他发了一句，「知心姐姐上线」。  
他说，「我可不是姐姐，我也不想做姐姐。」  
我就说，「那你想做什么？」  
他就说，「敷衍我，你不就是想做我的优乐美吗？捧在手心里的挚爱。」  
我说，「你这么笃定的吗？我们都没有见过面。」  
他说，「我要的不是瞬间绽放的烟火，而是伴在窗前的灯火。」  
我打了几句岔，他就直接告白了，「那你愿意去做我窗前的灯火吗？」

「如果以朋友的身份去相处的话，可能就不能深入的了解吧。虽然说我们没有打过照面，但是我们可以试着交往，然后在网络上相处着。肯定会碰到问题，如果都克服了的话，我们见面交往的时候是不是就会更简单一点了？」  
后来，我又打了几句岔，聊了点别的事。

当时的我还被蒙在鼓里的，听着还蛮受用的，以为自己真的找到了「真命天子」。  
但与此同时，我心里隐隐感到不安，觉得这一切都来得太快了。于是，我给一个好朋友讲了这件事，她建议我再去核查一下 C 的个人信息。  
我想起 C 曾经提过，他是杭州某科技大学毕业的。我朋友帮我查了一下，网络上搜不到他的名字与这个学校的关联。  
然后，我朋友问了一下她老公，她老公的第一反应是：是不是遇上骗子了。  
后来，我朋友给我发来了一些介绍「杀猪盘」的文章，我一看就发现，五天以来，我遇到的事情和文章里描述得一模一样。  
冷静下来后，我决定，暂时不要拆穿这个骗子。我打算继续和对方周旋下去，想看看他后面的行为符不符合杀猪盘的套路。  
果然，五天后，C 的下一步行动开始了。  
  
  
  
  
  
  
**图穷匕见，一个愚蠢的漏洞**  
我们认识的第 10 天，他突然提到，他表哥来了，他要出去找他。听到这话，我立刻反应了过来，这位「表哥」在他的「剧本」里，一定不会平白无故出场的。  
于是，我顺着话头问他，「你表哥是特地来香港看你的吗？」  
他说，「不是的，他是澳门的，娶了澳门的老婆，少奋斗20年。他老丈人在澳门有个娱乐城，占了 10% 的股份。我以为这次他来是找我玩的，其实他是找我做优化数据盘口的。没办法，刚来香港的时候，他帮了我很多。看来，这段时间我要熬夜了。」  
![](../Images/1db4601e68993027b59e0a0a93677915.png)  
很明显，他这位在澳门赌场有「门路」的表哥一定与他后面骗我的钱，也就是所谓的「杀猪」有关。他很有可能会声称，靠着表哥的这层关系，他知道一些澳门赌场的内幕，然后让我去投钱「赚外快」。  
第 11 天刚好是礼拜天。按照他以往的剧本，星期天是他的休息日。下午三点左右，他发来消息说，「开始忙了」。  
我便主动接茬，说，「你是在帮你表哥干活吗？」  
他说，「是的，今天不工作有时间，不然明天上班又要腾出自己时间来熬夜。」  
![](../Images/f1df20e8517177f6861711fef6cc2617.png)  
他告诉我，他在帮他表哥加班，做数据盘口优化的事情，还给我发来一张自己电脑界面的截图，似乎是想向我证明，自己真的有这样一个在澳门赌场有门路的表哥。但他没想到的是，这张截图让他露出了一个巨大的马脚。  
![](../Images/4828492d710e0751cbc086c6b1e5c086.png)  
相信比较细心的朋友已经看出来了：这张截图中，数据维护的界面用的是 Mac 系统，而 QQ 聊天的界面用的则是 Windows 系统。最好笑的是，为了刻意维护自己「陈奕迅粉丝」的人设，他的搜狗拼音输入法用的还是 Eason 的皮肤，当然，同样是 Windows 系统。  
后来，我拿着这张图去问了一个做 IT 的朋友。他说，「这个界面确实是做数据维护的，但我建议你去百度搜搜看，能不能找到一样的图。」  
果然，我没花多少力气，就用搜索引擎找到了一模一样的「数据维护界面截图」。  
那位朋友还提醒我，他们专业做这一行的人如果要给别人发送工作截图的话，一般会做一个「脱敏处理」，也就是说，给关键数据打马赛克。但是，C 给我发的这张图没有做任何脱敏处理。  
那些天，为了巩固我对他的信任，他还给我发来了更多关于自己人设的「证据」，但是，这些证据却暴露出了更多马脚。  
比如说，有一天，他给我发来了一张自己的全身照，说是去年拍的。但问题是，他之前和我提过，他的手机被植入了代码，无法发送实时图片。按照这个设定，他是没有办法给我发这张图片的。  
![](../Images/52c6ea75e81409fe9e0381966a18a36d.png)  
但我还是没有拆穿他，依然维持着自己「颜控」的人设，说，「那你现在发福了吗？你要是发福了，我会嫌弃你的。」  
  
  
  
  
  
  
**我装不下去了**  
随着聊天一步步的推进，我越来越无法忍受和 C 周旋的过程，因为他的情话简直一天比一天肉麻。  
![](../Images/ff25296d64d6570ecda96d6a7dc0e86f.png)  
在「杀猪盘」的套路中，这种「情话升级」的策略是十分普遍的。按照他们事先设计好的剧本，「狗推」会根据时间的推移，慢慢地加大情话的肉麻程度，伪造出一种陷入热恋的感觉。但是，因为我已经识破了对方的骗术，因此，这种情话攻势对我毫无效果，反而让我觉得，他似乎是想用情话来控制我。  
于是，这些天里，我开始试着去反向 PUA 他，试探他的底线。  
就这样，进行到第 13 天，那天下午，他照例来向我「打卡」，说，「醒来赚钱了」。  
我就说，「以前我们公司的老总一米 1 米 87 的大高个，长得还挺帅的，人家每天只睡四个小时，这种都实现财富自由的人了，还这么勤奋，你再看看你，睡个觉还要向我来炫耀。」  
就这样相互怼了几个回合，他似乎忍无可忍了，「我只是说了一句而已，你自己把它扩大了，而且我有每天和你说什么吗？醒来给的一句问候而已。你把我想成什么了？」  
然后，当我试图再去回复他的时候，聊天界面显示「发送失败，请先添加对方为好友」。  
他居然把我给删了。

**一些后怕**  
  
在被删除了好友之后，我在世纪佳缘和 QQ 两个平台上对 C 的账号做了举报。我发现，在世纪佳缘上，C 的账号已经被列入黑名单了。显然，在这个平台上，被 C 当成目标，并最终识破骗局的，并不只有我一个。  
事实上，在杀猪盘的团伙中，他们往往会撒网式寻找目标。遇到警惕性较高的受害者时，「狗推」就会立即收手。而一旦对方上当，「狗推」就会想方设法，榨干每一滴钱财。  
在我看到的那些警方侦破的过往案例中，很多受害者受到情感操控后，往往投入了数十万钱财，发现无法提现之后，才意识到自己上当受骗，而聊天界面后的那位恋人早已经销声匿迹了。  
我很庆幸自己早早识破了骗局。但这一事件给我带来的更大层面的伤害是，我发现自己丧失了对陌生人的信任。我无法接受，这个世界上竟然有人会利用女性在情感关系中所付出的信任去骗取钱财，更无法接受这种做法已经被不断复制，不断操练，并不断地「杀猪」成功。
