# 直击网络安全周：腾讯反诈骗智慧大脑首度亮相

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247484686&idx=1&sn=50b4679cb9c4d3683b8e19f50df77a5a&chksm=ea19a7f5dd6e2ee30c3f4f330a01e59aeef15768a31c8844b707055dc75a087c03c54f2991f5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247484686&idx=1&sn=50b4679cb9c4d3683b8e19f50df77a5a&chksm=ea19a7f5dd6e2ee30c3f4f330a01e59aeef15768a31c8844b707055dc75a087c03c54f2991f5&scene=27#wechat_redirect)

9月16日，以“网络安全为人民 网络安全靠人民”为主题的2017国家网络安全宣传周正式开幕。而从9月17日-9月20日在国家会展中心（上海）举办的的网络安全博览会暨网络安全成就展，系首次设立，重点展示十八大以来国家网络安全工作取得的显著成就。

![](../Images/a4107d92d00cf4a6c4d41ca6e21a5686.png)

据悉，本届网络安全周，共有86家网络安全相关单位参展，将重点向人民汇报和展示先进安全技术。而在全社会聚焦的反诈骗领域，腾讯安全今年再度推出反欺诈新利器——腾讯安全反诈骗实验室智慧大脑。这项基于人工智能技术研发，涵盖十余款反诈骗产品的智慧大脑，覆盖通讯、金融等领域的诈骗黑产作恶的各个环节，能够在诈骗的事前、事中以及案情分析等关键环节起到作用。在今年的网络安全周上，腾讯安全展出其中四款旗舰产品——鹰眼智能反电话诈骗盒子、麒麟伪基站定位系统、腾讯安全态势感知系统、神侦资金流查控系统。

![](../Images/689dc846cbec861b587b66562929f682.png)

                              

**四大反诈骗利器站台**

**腾讯安全“智慧大脑”狙击黑产诈骗**

  

2017年以来，随着人工智能“风口”的到来，人类已经一只脚迈入了人工智能时代的大门。而在安全领域，腾讯安全联合实验室反诈骗实验室在2016年就着手启动“智慧大脑”研究，基于人工智能技术进行黑产对抗模式研究，如今已研发出麒麟、鹰眼、神荼、神侦、神羊等十余款反诈骗产品。目前，这些反诈骗产品已共计落地全国20多个城市，多次协助公安、国家食品药品监督管理总局等相关部门破获诈骗案件。

此次展出的四款旗舰产品，其中鹰眼智能反电话诈骗盒子的主要作用，是基于对话单的大数据分析，在智能引擎的快速模型识别匹配下，实时检测出正在受骗的用户，并且通过和警方或者运营商合作对受骗用户进行实时劝阻，在第一时间保护用户的财产、甚至人身安全。而麒麟伪基站定位系统，则是利用大数据和LBS对伪基站进行定位，并从空间、时间维度利用地图直观呈现伪基站的聚类的传播区域和实时运动轨迹，帮助警方提高打击伪基站团伙的效率。

![](../Images/161a46b53b879793d5276f1267731a3c.png)

腾讯安全反诈骗实验室给出的数据显示，鹰眼反电话诈骗盒子推出以来，已累计挽回用户财产损失达10亿元，北京公安接入鹰眼反电话诈骗系统后，2017年1-5月对比2015年1-5月，用户资金损失下降67.7%；麒麟伪基站定位系统在深圳上线3个月内，即打掉伪基站犯罪团伙13 个，目前深圳市伪基站诈骗案发率已降低为零。

另外两款产品中，腾讯安全态势感知系统是基于腾讯十余年来在多业务线的网络安全对抗经验，打造的一款俯瞰全网安全态势的产品。通过可视化技术清晰呈现出安全事件关联、预警、追踪等业务逻辑。

![](../Images/4501b7d5eaa065029c4f89f62220aee4.png)

而神侦资金流查控系统则是由腾讯安全反诈骗实验室、北京市公安局和银行多方合作研发。该系统基于海量数据进行建模，可通过机器学习快速分析出用于诈骗的恶意银行卡，帮助警方在案发前追踪犯罪团伙活动区域及资金转移路径，从而冻结被诈骗资金，成功阻断诈骗链条中资金流的关键环节。

  

**AI驱动 腾讯安全反诈骗成效显著**

  

目前，腾讯安全反诈骗实验室基于多年来在反诈骗领域的深耕研究，目前已经形成一整套基于AI创新+能力开放的反欺诈评价新标准，形成有效的止损模式。深耕互联网安全领域已近18年的腾讯安全，掌握了亿级体量的黑产数据，进一步夯实了其计算力、算法、数据三方面能力，为大数据反欺诈过程中的AI创新提供了坚实基础。  

据腾讯安全反诈骗实验室负责人李旭阳介绍，目前腾讯安全联合实验室反诈骗实验室基于事件的风险判断准确率可以做到40%-95%。其中，电信诈骗的判断准确率可以达到95%。

李旭阳进一步指出，目前只要是电信诈骗案件，110将直接与上海市反电信网络诈骗中心平台对接，利用腾讯反诈骗智慧大脑分析判定并开启“三方通话”，由中心平台统一串并案件并进行分析，对类案统一侦查、抓捕。上半年期间，上海市反电信网络诈骗中心平台已成功冻结被骗资金人民币900万元、欧元464.6万元、美金395万元，成功劝阻潜在被害人1.1万余人次。有效将上海市各类电信网络诈骗案件同比下降12.1%，其中平均案值最高的冒充“公检法”人员诈骗案接报量下降47.2%，案值下降34.9%；而另一类影响广泛的伪基站类电信诈骗案接报量下降超90%，案值下降近98%。

随着人工智能技术在反诈骗领域显现出来的价值，腾讯安全也在积极的与政府、高校等各方在该领域展开研究合作。

对此，李旭阳表示，未来的互联网世界一定是围绕数据构建的，我们也将基于海量数据，深度挖掘大型社交网络中用户网络行为的内在关联，研制更精准的大数据融合关联分析系统，解决数据孤立性特征容易被绕过的问题。目前我国每年因网络安全问题造成的经济损失达数百亿美元，如果该研究成果能在相关行业和领域进行应用，尤其是通信、金融等关系管家安全的关键领域，能有效提高网络系统的应急响应能力、缓解网络攻击所造成的危害、发现潜在恶意的入侵行为、提高系统的反击能力，从而大大降低经济损失，具有很高的社会和经济效益。
