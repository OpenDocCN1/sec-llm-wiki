# 中国互联网安全领袖峰会即将召开，腾讯安全立体防御网络空间威胁

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247484571&idx=1&sn=2e1201e0311f3870560f86654c7f53e7&chksm=ea19a660dd6e2f761cb0ee7a0b7853dd81ead8e01a164caa9e52c4006acad356a0d9da65da94&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247484571&idx=1&sn=2e1201e0311f3870560f86654c7f53e7&chksm=ea19a660dd6e2f761cb0ee7a0b7853dd81ead8e01a164caa9e52c4006acad356a0d9da65da94&scene=27#wechat_redirect)

  

8月15日-16日，以“安全新秩序，连接新机遇”为主题的第三届中国互联网安全领袖峰会（Cyber Security Summit2017，简称“CSS2017”）将在北京国家会议中心举办。作为CSS安全领袖峰会的主办方，腾讯安全将携手500多家顶尖企业以及众多全球顶尖安全专家，多维度探讨当前网络空间威胁态势以及安全体系的搭建，分享时下前沿安全技术与研究成果，共议新秩序下的互联网安全之道。

  

![](../Images/10cfea3733972bdf33b3a5ea85706568.png)

（图：第三届中国互联网安全领袖峰会即将开幕）

  

近年来，网络攻击和电信网络诈骗事件频频发生，用户长期面临木马病毒、诈骗电话、钓鱼网址等多重安全威胁。今年5月份爆发的WannaCry勒索病毒无疑是全球性互联网灾难，该病毒波及150多个国家，影响金融、能源、医疗等众多行业。电信网络诈骗更是当前社会的巨大毒瘤，从“山东徐玉玉案”、到前不久曝光的“李文星求职被骗身亡”，用户因被骗遭遇的损失已经不止是金钱。

为了立体防御网络安全威胁，腾讯安全基于多年来积累的安全能力，坚持开放共享，与行业合作伙伴协同作战。2016年7月，腾讯成立了腾讯安全联合实验室，专注安全技术研究及安全攻防体系搭建，安全防范和保障范围覆盖了连接、系统、应用、信息、设备、云六大互联网关键领域。并推出鹰眼、麒麟系统，联合公安、银行、运营商等各方推出“守护者计划”，多次协助警方打击电信网络诈骗黑色产业链条。

同时，腾讯手机管家作为移动安全领域的第一道防线，依托业内最大的号码识别数据库，能够精准拦截骚扰诈骗电话，帮助用户远离电信网络诈骗。为了终结iPhone用户的骚扰诈骗难题，腾讯手机管家两次合作与苹果合作，推出了iOS恶意来电拦截和垃圾短信识别功能，打造iPhone全场景防骚扰体验。腾讯电脑管家通过不断革新、升级自身安全技术，有效抵御了“异鬼II”、“Poweliks远控木马”、“奔雷”等病毒木马的攻击，大大提升用户网络安全感，英文版被AV-C、赛可达、VB-100等业内多家国际权威评测机构的认可。

基于网络安全威胁多样化、频繁突发的特征，以及国内网络安全人才短缺的现状，腾讯通过打造腾讯安全联合实验室、腾讯安全云库、腾讯手机管家、腾讯电脑管家、腾讯WiFi管家、腾讯守护者计划等安全矩阵，并积极探索信息安全人才培养新机制，推出网络安全人才“百人计划”，及时有效地对网络时代的安全威胁实现了全方位、多场景防御和安全体系搭建。

值得一提的是，本届CSS2017将于8月16日设立腾讯安全探索论坛（TSec），该论坛由腾讯安全联合实验室主办，是一个全球前沿、尖端安全技术的首发平台。与会嘉宾将围绕“机器学习帮助网络安全演习，安卓内核UAF利用探秘、危机重重的移动终端VPN加密”等议题，分享最前沿的安全技术干货，打造一场汇聚全球安全领域的技术盛宴。

随着《网络安全法》的落地实施，网络安全将步入新秩序。新秩序下互联网行业面临什么样的挑战与机遇？有哪些安全领域最前沿、最尖端技术将面世？如何更好地保障互联网时代的用户安全？8月15-16日，北京国家会议中心，CSS2017敬请期待。
