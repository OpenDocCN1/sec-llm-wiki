# 腾讯安全联合实验室加速能力输出护航云安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247484517&idx=2&sn=4ee0a0a18cf3aa4d665d28e1e69c0fda&chksm=ea19a69edd6e2f884fe017f68d2c02ee8ff3cce680886bbac82bb5f527e4fe5cbbd87a74afb7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247484517&idx=2&sn=4ee0a0a18cf3aa4d665d28e1e69c0fda&chksm=ea19a69edd6e2f884fe017f68d2c02ee8ff3cce680886bbac82bb5f527e4fe5cbbd87a74afb7&scene=27#wechat_redirect)

伴随着云计算与人工智能的迅速崛起，互联网逐渐迈入新的云时代，整个社会经济操作系统和运作模式都在发生数字化的迭代，巨大的商业机会同时也伴随着巨大的挑战。上周的2017腾讯“云+未来”峰会上，腾讯公司董事长兼首席执行官马化腾在“云时代的新趋势”主题演讲中表示，在对抗电信诈骗、网络犯罪的过程中，需要积极利用云这一武器来对抗，只要把握了互联网信息、云技术和规律，未来这个高度互联的世界是可知、可管、可控的。

  

而为了让外界更加全面的了解腾讯在云安全领域的实力，6月22日的云安全专场上，腾讯云携手腾讯安全联合实验室旗下的科恩实验室、湛泸实验室、云鼎实验室、反诈骗实验室和反病毒实验室，基于各自安全研究方向，从产品、模式、布局等多个维度，系统阐述了实验室在护航云安全、反诈骗、内网安全等方面的实力。

  

**加速能力输出，腾讯安全联合实验室护航云安全**

  

2016年7月，腾讯安全联合实验室正式成立，一年来，其研究成果与能力输出已经加速驶入快车道。本届腾讯“云+未来”峰会期间，腾讯安全联合实验室反诈骗实验室携手腾讯云推出金融反欺诈解决方案，借助腾讯安全反诈骗实验室技术和数据能力、以及腾讯云在金融领域的深厚积淀，进一步提升了金融反欺诈的行业标准，最大限度帮助客户止损。

  

**同时，腾讯安全联合实验室云鼎实验室首次对外公布了基于机器学习的主机安全产品——云镜，通过AI技术的持续升级，帮助企业抵御病毒、漏洞攻击风险。在过去一个多月内，云镜成功帮助企业抵御了“WannaCry”勒索病毒和“暗云”变种木马攻击。**

  

另外，针对近期被各方高度关注的企业网络安全，腾讯电脑管家、腾讯安全联合实验室旗下反病毒实验室与湛泸实验室负责人方斌，也在云安全专场现场深度分享了腾讯安全基于安全体系优势、端云协同优势、丰富业务场景优势构筑的企业内网安全解决方案。

  

除此之外，峰会首日，蔚来汽车创始人、董事长李斌，在演讲中重点提到了和腾讯安全联合实验室科恩实验室在车联网领域的合作。该实验室曾凭借“全球首次远程无物理接触方式入侵特斯拉汽车”研究成果，被选入“特斯拉安全研究员名人堂”，并获得特斯拉首席执行官埃隆·马斯克的亲自致谢。

  

**开放能力  腾讯安全联合实验室积极构建安全新生态**

  

成立近一年，腾讯安全联合实验室在的力输出范围越来越广泛。在整个2016年，腾讯安全为微软、谷歌、苹果、Adobe提交了269个漏洞报告，而腾讯安全联合实验室贡献了其中的160个，持续协助厂商提升产品安全性能。

  

此外，腾讯安全联合实验室还基于自身的安全实力还在释放更多价值，携手社会各界共同构建安全新生态。过去一年中，腾讯联合公安、银行、运营商等反电信网络诈骗产业各方推出共同打造的“守护者计划”，在打击治理电信网络诈骗及黑产方面卓有成效。截至目前，腾讯安全反诈骗实验室已协助警方破获多起特大案件，协助破获案件金额超5亿元。

  

而在反病毒战场，腾讯安全联合实验室反病毒实验室、云鼎实验室，在帮助企业和用户抵御“WannaCry”勒索病毒与“暗云”变种木马攻击的过程中，已经逐渐建立起一套事前预警、事中查杀、事后尽可能帮助用户挽回损失的安全防御链条。

  

随着云计算的快速发展与 AI新技术的迭代，腾讯安全联合实验室仍旧在不断强化自身创新能力和人才建设、安全研究能力；未来，实验室也将持续向社会、政府、企业、用户输出更加强大的技术实力，为云安全、车联网安全、物联网安全、企业安全保驾护航。
