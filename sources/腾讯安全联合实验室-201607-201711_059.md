# 距离白帽黑客界的“高考”模拟考倒计时还有1天

还有5天一年一度的高考又将如期而至，高中最后一场战役的号角即将吹响。在走向高考的考场前，我们都会经历多次模拟考。通过模拟考试，在查漏补缺的同时，锻炼临场反应能力。

  

不仅高中学子会经历高考，“白帽黑客”也会经历属于他们的“高考”——每年7月在拉斯维加斯举办的**DEF CON CTF。**

  

![](../Images/64eb9199ae0b2d50c6750761b76698e9.png)

  

**“白帽黑客”界的“高考”**

作为国际上最为流行的黑客竞赛之一，CTF（夺旗赛）可以用来演示黑客之间的攻防竞技，CTF最早可追溯到1996年的DEF CON世界黑客大会。DEF CON CTF 是 CTF 的鼻祖，也是 CTF 中难度最高的比赛，相当于CTF界的“高考”，每年都会吸引国际无数顶尖安全战队参加，在DEF CON CTF上取得名次，也意味着其网络安全实力水平的高超。

  

**“高考”前的“模拟考”**

与高考不同的是，想要走进“白帽黑客”界的“高考”DEF CON CTF的考场，就需要过五关斩六将，在“模考”上拔得头筹。

  

最近的一次“模考”就是即将于明日拉开“白帽黑客”争霸大幕的**腾讯信息安全争霸赛（TCTF）**，TCTF分为**国际赛（0CTF）**和**新人邀请赛（Risingstar CTF）**。

  

国际赛（0CTF）是大陆唯一拥有DEF CON CTF外卡赛资格的赛事，其冠军可以直接晋级DEF CON CTF决赛。新人邀请赛的冠军（Risingstar CTF）也将获得由腾讯安全提供的DEF CON之旅。

  

**安全极客的“火箭班”**

为冲击高考，几乎每个学校都会设置“火箭班”“培优班”“尖子班”，将优秀学生集中在一个班级，并配备全校最优质师资力量的给予辅导。

  

TCTF同样设置了“火箭班”即“**百人计划**”，不仅是为了冲击“高考”DEF CON，更是旨在为行业培养一批优质人才。

  

“百人计划”由腾讯安全联合实验室7大掌门及数十位高校资深网络安全教师担任指导老师，并拥有“**政府、高校和企业提供的专业培训**”、“**与国际一流 CTF 战队交流**”“**观摩参与 DEF CON CTF 等国际顶尖赛事**”及“**世界顶尖安全极客的专业技术培训**”四大优势资源。

  

**“模拟考”倒计时1天**

历经数月，“白帽黑客”界的模拟考——首届腾讯信息安全争霸赛（TCTF）终于将在**明日**迎来决赛。来自7个国家和地区的12支顶尖战队披荆斩棘赶赴深圳争夺DEF CON CTF这唯一一张的入场券。届时首批入选“百人计划”的战队名单将于现场揭晓。

  

和选手一样值得期待的还有来自业内的资深前辈（高校老师）以及混迹安全圈多年的大牛（腾讯安全联合实验室7大掌门）所组成的全明星导师阵容亲临比赛现场指点风云，共商网络安全届的“大事”。

  

筹备半年，厚积薄发；DEF CON入场券，Las Vegas直通车；七个国家和地区，顶尖战阵容；百所高校，百人计划。所有的悬念和期待都将在明天首届腾讯信息安全争霸赛（TCTF）决赛的现场一一揭晓。
