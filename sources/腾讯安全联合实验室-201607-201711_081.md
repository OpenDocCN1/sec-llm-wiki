# 微软被爆远程操控漏洞！腾讯电脑管家已紧急修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247484218&idx=1&sn=bc384c82978f1d0046fd6ff1e1c201c9&chksm=ea19a1c1dd6e28d7ec289dbf641cf1868e9d6aa5967b2edd7211935f1d0a8b2bb5fcb1c72523&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247484218&idx=1&sn=bc384c82978f1d0046fd6ff1e1c201c9&chksm=ea19a1c1dd6e28d7ec289dbf641cf1868e9d6aa5967b2edd7211935f1d0a8b2bb5fcb1c72523&scene=27#wechat_redirect)

**事件起因：**北京时间14号晚上，国外爆出针对微软Windows系统的大量远程漏洞使用工具，影响了包括Windows xp、Windows 7以及大量Windows机器在内的全球约70%的机器，这些工具可以远程操作受害者电脑，获取所有权限。

由于此次爆出的漏洞众多，影响系统范围极大，同时工具已经公开大范围流传，对于大量高校、政府、银行甚至个人用户都产生了巨大的威胁。

  

此次的工具由“Shadow Brokers”黑客组织爆出，此组织声称入侵了据信是美国国家安全局NSA下属的“Equation Group”组织的机密文件，并在此前几个月内陆续爆出了多个机密的黑客工具、漏洞等内容。**从已公布的内容可以看到，已经有大量的中国公司成为了攻击的目标。**

  

**根据FOFA系统统计显示，全球可能受到本次攻击影响的机器超过750万台,中国可能有超过133万台机器受到影响。**同时，由于泄露的文件大部分是漏洞利用程序，攻击者拿到程序后，即使不了解攻击的原理，也可以突破系统的防线，造成远程代码执行等高危影响。

  

**据微软官方最新回应，此次微软被攻击的大部分漏洞中，在Win7及Win7以上系统均已有补丁支持，并建议Windows XP等失去支持的系统用户尽快升级到支持的系统。**  

  

![](../Images/51fe8d9148dc4d2b64cf737f72becaf6.png)

  

**腾讯安全专家表示：**目前，腾讯电脑管家已可修复该漏洞，广大用户下载并及时更新修复即可。
