# 第二批TCTF新人邀请赛（Risingstar CTF）受邀战队名单公布

继首批TCTF新人邀请赛（Risingstar CTF）受邀战队名单公布后，经TCTF组委会技术专家对高校新人邀请赛战队的解题得分和赛后提交的解题报告进行综合评估、讨论，第二批受邀战队名单揭晓。他们是：

  

![](../Images/062612c79e9f58a998bbe4c52ad89328.png)

  

一起来认识下本次入围TCTF新人邀请赛（Risingstar CTF）线下决赛的战队。

  

**Nu1L**

一支多校联合战队，队名源于英文单词"NULL"。队员由来自西华大学、北京理工大学、山东警察学院和郑州大学的，对信息安全以及CTF比赛有着浓厚兴趣的成员组成。Nu1L战队活跃在国内各大CTF竞赛中，并取得优异成绩，曾获SSCTF线上赛全国第三，SCTF线上赛全国第一，第三届NJCTF线上赛冠军。

  

**Lancet**

源自于北京航空航天大学的网络安全技术竞赛和研究团队，战队成立于2015年10月，指导老师是李舟军教授。自成立来获得2016年信息安全与对抗技术竞赛分组对抗赛全国一等奖、“安恒杯”全国高校网络安全技能竞赛第一名、“美亚柏科”大学生网络空间安全精英邀请赛第一名、2016信息安全铁人三项赛华北赛区“西普杯”数据赛第一名等多种奖项，实力不凡。

  

**Vidar**

来自杭州电子科技大学，是浙江高校最早建立的白帽黑客团队。由杭电信息安全协会（原HDUISA）和网络空间安全学院合并而成。曾获丝绸之路网络安全精英赛亚军，全国大学生电子设计竞赛邀请赛，动态演练组一等奖。除了参赛，Vidar还承办了杭州电子科技大学网络攻防大赛（HCTF），在全国信息安全竞赛中小有名气。

  

以上三支战队实力强劲，参战经验丰富。他们将于**6月2日**在**深圳**与其他入围TCTF新人邀请赛（Risingstar CTF）的战队展开新一轮的技术比拼。第三批邀请名单正在紧张核对中，敬请期待！
