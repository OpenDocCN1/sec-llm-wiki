# 最新战报！TCTF 2021预赛（国际赛）12强队伍出炉！

7月3日-5日，由腾讯安全发起，腾讯安全学院、腾讯安全联合实验室主办的2021 TCTF第五届腾讯信息安全争霸赛线上预选赛如期举行。本届大赛由去年 DEF CON CTF总冠军腾讯A\*0\*E联合战队的核心主力成员负责主要命题工作，兼顾前沿技术与安全热点，在竞技性与挑战性方面对参赛团队的能力提出了更高的要求。经过3天的激烈角逐，最终（国际赛）12支团队入围决赛。其中，**中国的NeSE战队以9203分的断层优势夺得第一，美国perfect blue战队与中国r3kapig战队分别获得7489分和6303分，位列第二、三名。**

***预赛三甲战队介绍***

**NeSE**

NeSE战队，来自中国科学院大学，全称为Never Stop Exploiting，队员全部由国科大网安学院研究生组成，近年来研究成果发表在Usenix Security、ACM CCS、WWW等国际顶级学术会议上。战队在2020年获得TCTF新星邀请赛的冠军、国际赛第7名，世界黑客大师赛WCTF亚军，是2021年0CTF/TCTF线上赛第1名。

**perfect blue**来自美国的天才少年战队，创建于2017年。2020年参与了36个CTF赛事，并获得12次冠军、6次亚军、5次季军，2020 CTFTIME全球排名第1。今年的CTFTIME全球排名中暂居第6。**r3kapig**成立于2018年，由老牌CTF战队Flappypig和强劲新锐战队Eur3ke联合组成。曾参加XCTF夺得四连冠，多次进入国际CTF赛事决赛，如HITCON CTF、Nuit du hack和Dragon CTF等，获得2019 0CTF/TCTF冠军。目前预赛阶段已告一段落，**TCTF决赛将于9月正式开启，届时所有入围队伍将再次集结，一决高下！**更加精彩的对决，最终桂冠花落谁手，让我们拭目以待。
