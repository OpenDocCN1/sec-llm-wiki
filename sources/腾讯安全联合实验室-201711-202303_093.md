# 2021，你需要关注的云安全趋势都在这里

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247489902&idx=1&sn=d73f5c205e87d3ea063067aa9c64f4b6&chksm=ea19bb95dd6e3283623680e90ae09c29ff047a3251faea09f2f0e1b04f8028cf40a122aed9d7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247489902&idx=1&sn=d73f5c205e87d3ea063067aa9c64f4b6&chksm=ea19bb95dd6e3283623680e90ae09c29ff047a3251faea09f2f0e1b04f8028cf40a122aed9d7&scene=27#wechat_redirect)

在新基建快速发展的浪潮之下，云成为承载企业数字化转型升级的核心基础设施之一，随着越来越多企业选择上云、大量企业数据、交易场景迁移至云端。**云安全与否，和未来数字经济能否安全发展息息相关**。在刚刚结束的GeekPwn2020国际安全极客大赛上，腾讯安全云鼎实验室基于对腾讯云平台自身安全建设的实践经验和对云安全领域的前瞻研究，重磅发布了“2021云安全九大趋势”，为产业云上安全建设和云安全技术发展方向提供新的指引。为进一步厘清产业上云面临的安全挑战，顺应云时代发展态势，10月26日，腾讯安全联合InfoQ共同举办以“**新基建快速发展，面临哪些新的安全挑战**”为主题的云安全趋势研讨会，并将在InfoQ官网和腾讯云大学播出。**中国信息通信研究院云大所云计算部副主任陈屹力，腾讯云安全总经理董志强，腾讯云安全副总经理李滨，数世咨询创始人李少鹏以及普华永道中国区信息安全与隐私保护合伙人万彬将共同出席会议**。研讨会汇聚来自科研院所、评测机构、行业头部企业的多位专家，从科研前瞻、行业分析、企业实践等多个角度，共话云安全未来重要的技术发展方向及攻防重点。除了行业热议的云原生安全，2021年企业上云还有哪些重要趋势值得关注？合规政策与法律法规对于数据安全有何影响？如何构建安全可信的软硬件供应链？从平台建设到租户安全运营，如何提升自动化编排程度，提高防护效率？远程办公兴起、多终端办公环境的情况下，如何完善云上身份认证体系？更多精彩话题和干货内容，请锁定**腾讯云大学和InfoQ官网直播间，今晚7:30，一探云上究竟**。![](../Images/3cc73b91a7c869ea1a4e36da49b85779.png)
