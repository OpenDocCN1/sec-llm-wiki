# CTF学霸在线解题，分享独门秘籍！ | TCTF2020 公开课

7月22日晚8点，**TCTF（腾讯信息安全争霸赛）2020线上公开课第三期开课。**![](../Images/84ddf656981acd99b59d658d12ac6ea0.png)在本期课程中，腾讯安全科恩实验室研究员兼0CTF/TCTF 2020命题组成员刘耕铭、尚红泽、王政和，以及复旦大学Whitzard战队队长谈心、复旦大学Whitzard战队主力逆向许海龙、Nu1L战队主力Pwner姚诚出席，从**命题者角度及个人经验**出发，为大家带来**本次TCTF2020线上预赛的系列赛题讲解。**  

**刘耕铭**  

![](../Images/5e047675c614909e4518f4c73e116b2d.png)第一位演讲嘉宾是**现任eee战队队长，A\*0\*E联队队长**刘耕铭，他在浏览器方向有多年的研究经验，还曾获 Chrome bounty program 最高级别奖励。![](../Images/58e846c39fe819a136233b57b439299c.png)在本期公开课中，刘耕铭带来了**Chrome系列赛题讲解，**并依次介绍了Chromium RCE、Chromium SBX、Chromium Fullchain的赛题分析以及解题思路。  

**尚红泽**  

![](../Images/baf1a96d731ec5717fcc698e49d26e59.png)尚红泽主要对**flash赛题进行了复盘，**并讲解了flash逆向题以及flash PWN题的解题思路。据他介绍，本次flash题目中直接给了两个可以用Chromium运行的固件的镜像，因此，只需要**对Chromium里的代码进行逆向，对混淆的代码进行解混淆，**成功后就能得到第一个flag。接下来，如果能够通过**输入去造成内存的破坏，实现任意代码执行，**就可以在固件的镜像里实现内存地址读，这样就能在内存里还原出第二个flag。  

**王政和**  

![](../Images/ec409823674dc2a155501fcc1eaf9efa.png)作为**BabyBypass赛题的命题人，**王政和的命题思路是想趁热打铁考察更加“原汁原味”的PHP堆漏洞利用。而在介绍解题思路时，王政和表示，选手们在看到题目的第一时间，应该先阅读题面，了解清楚题目的需求是什么，然后再仔细查看题目所给到的文件资料，并找到资料中的几个关键点。即，比赛时最新的PHP、名为pwnlib.so的扩展、php.ini配置文件、需要执行/readflag才可以获得flag。最后，王政和还**公开了这道BabyBypass题的源码，**感兴趣的同学可以去回顾直播内容了解一下～  

**谈心**  

![](../Images/7807e4bb208a08e744fe31b5f5ccbd38.png)不同于前三位嘉宾是从出题人的角度去介绍解题思路，谈心更多的是从**赛事参与者的角度**去讲解自己是如何一步步把题目解出来的。谈心主要带来了**gene逆向分析和gene密码学分析的讲解，**并介绍了逆向分析的几大难点以及解决思路，**一是openssl中的大数运算函数，二是一个巨大的循环展开构成的未知函数。**此外，谈心还对gene的解题思路进行了归纳。首先，发送两对随机的消息进行签名，然后根据返回的签名计算私钥，再利用私钥和公钥对服务器要求的消息进行签名，最后，将得到的正确签名发送给服务器，再通过服务器的检查逻辑后就能获得flag了。  

**许海龙**  

![](../Images/464c7f34e568188beb04909d5d99e510.png)同为复旦大学Whitzard战队成员的许海龙，曾**连续两年获得腾讯游戏安全竞赛一等奖，**并多次拿到国际CTF赛事题目一血。此次作为演讲嘉宾，许海龙也是从做题人的角度来分析Happy Tree赛题有哪些尝试的思路，以及自己当时在做题时撞了哪些坑，最后又是怎么做出来的。许海龙表示，这道Happy Tree是一道中等难度的逆向题目，同时也是一道比较有意思的题。根据常规逆向题的解题步骤，可以先看程序的架构平台。而这道题是一个32位ELF，运行一下可以发现是个很典型的flag track。此题有两个解题思路，**一是动态调试观察规律，尝试进行爆破；二是还原vm代码逻辑。**  

**姚诚**  

![](../Images/67cec9023f379dcbda5b7ce5d8cfb31c.png)本期公开课的最后一位嘉宾姚诚是**Nu1L战队主力Pwner，**今年正式加入腾讯安全科恩实验室，主要研究方向为**二进制漏洞挖掘和利用。**姚诚主要对echo emojis赛题中的simple\_echo server、eeemoji、eeeeeemoji三道题进行了详细讲解。据其本人“吐槽”，这是TCTF赛事里相对简单的三道题。
