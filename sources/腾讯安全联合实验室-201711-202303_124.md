# 全球974支战队酣战48小时，TCTF 2020预赛圆满收官！

6月29日，**第四届腾讯信息安全争霸赛（TCTF）线上预赛**正式落下帷幕。经过48小时酣战，最终，**来自韩国的koreanbadass战队以9178分的好成绩斩获预赛桂冠**，来自俄罗斯的More Smoked Leet Chicken战队及美国的perfect blue战队分别位列第二、三名。  

![](../Images/27de36e4c6ac857203ffcbc5cfa4ba95.png)

预赛（国际赛）战队排名

**集结！****全球****974支战队同场竞技**

腾讯信息安全争霸赛(TCTF)是**由腾讯安全发起，腾讯安全学院、腾讯安全联合实验室主办，腾讯安全科恩实验室承办、0ops安全团队协办的专业CTF赛事，举办至今已是第四届。**本届TCTF自报名启动以来便备受瞩目，截至报名结束，共吸引了来自全球的974支战队参赛。这些参赛战队，有的是叱咤于国内外CTF赛场的顶尖战队，有的是正在强势崛起的新锐战队。“受全球疫情影响，今年的TCTF相比往年晚了几个月，但我们也有了更多时间去设计赛题。**本届赛题在设计上兼顾了前沿科技和安全热点，大大增加了比赛的竞技性和挑战性**，今年赛事对抗情况整体相较往年有进一步提升。”本届TCTF赛事技术负责人、腾讯eee战队教练表示。为了给参赛选手们答疑解惑，在本届TCTF线上预赛开始前，腾讯安全还举办了两场TCTF2020线上公开课，包括**腾讯安全云鼎实验室负责人Killer董志强、腾讯安全平台部负责人杨勇**在内的多位信息安全领域的专家，带来了信息安全未来、TCTF赛事重点及安全人才就业现状等方面的精彩分享。  

**战斗！强强对决勇夺第一**

本届TCTF线上预赛在赛题设计方面也用心良苦，题型主要包括**Pwnable、Reverse、Web、Crypto和Misc五大类**，共计31道试题，其中不乏贴合前沿科技和安全热点的高质量内容。而参赛选手们实力爆发，不断调整策略、优化作战模式，将赛事频频推向白热化。比赛中，来自美国的Shellphish战队凭借在 Crypto类babyring试题中的精彩表现，夺得全场第一个一血。而韩国koreanbadass战队不仅解开了23道试题，还拿下了全场最多的五个一血，展现了全能实力。由于赛题设置，比赛刚开始的前10个小时，排名前十的战队还始终保持着“如胶似漆”的状态。然而，战况到第一天赛程结束时，已悄然转变。韩国koreanbadass战队率先向第一名发起冲击，先是如有神助般拿下好几个试题，将积分上涨到领先第二名近2000分，而后更是一路保持积分优势，最终以9178分的优异成绩拿下本届TCTF线上预赛的冠军。更戏剧性的是第二、三名战队，俄罗斯More Smoked Leet Chicken战队和美国perfect blue战队原本都在中下游徘徊，后双双奋起反击。perfect blue战队更是在短短5小时里，接连赶超6支战队。最终，两支战队分别以8206分和7677分的成绩获得了第二、三名。![](../Images/99fa69489b3df76a8f14fb2fb9d7fbda.png)第四届TCTF线上预赛得分趋势48小时的考验和磨砺暂时告一段落，期待在不远的TCTF决赛上能看到更精彩的交锋。
