什么是CTF？

CTF（Capture The Flag）中文一般译作夺旗赛，在网络安全领域中指的是网络安全技术人员之间进行技术竞技的一种比赛形式。CTF起源于1996年DEF CON全球黑客大会，以代替之前黑客们通过互相发起真实攻击进行技术比拼的方式。CTF发展至今，已经成为全球范围网络安全圈流行的竞赛形式，2013年全球举办了超过五十场国际性CTF赛事。

怎么样才能参加CTF？

知道了什么是CTF比赛之后，你是否想知道，若是没有基础知识的人，怎么样才能一步步成为网络安全大神呢？
对于想要投身于网安行业的新人们，建议大家首先要了解CTF的赛事制度、比赛题型、顶级赛事等相关资讯。其次，也需要增强自己的技能和知识储备，并通过CTF类的赛事平台进行验证，同时还要不断观察行业的时代本质，以此来提升自己适应时代发展的能力。
培养技术与能力可能需要“水滴石穿”的不断练习才可以达到，但了解CTF可以先从阅读以下CTF比赛的相关资料开始，一步步朝着成为CTF大神的目标前进吧！

CTF的赛事制度

先来聊一聊CTF的赛事制度。自1996年发端后，CTF比赛在二十多年的发展过程中逐渐形成了较为固定的赛制类型，最常见的有解题模式、攻防模式和混合模式。
1.解题模式（Jeopardy）
在解题模式中，参赛队伍可以通过在线上或者线下网络参与。这种模式的CTF比赛与ACM编程竞赛、信息学奥赛比较类似，通常用于在线选拔赛，以解决网络安全技术挑战题目的分值和时间来排名。
题目主要包含逆向、漏洞挖掘与利用、Web渗透、密码、取证、隐写、安全编程等等，难度不一，分值不一，越难的题目分值越多。
2.攻防模式（Attack-Defense）
在攻防模式的CTF赛制中，参赛队伍在网络空间互相进行攻击和防守，挖掘网络服务漏洞并攻击对手服务来得分，修补自身服务漏洞进行防御来避免丢分。
攻防模式可以实时通过得分反映出比赛情况，最终也以得分直接分出胜负，是一种竞争激烈，具有很强观赏性和高度透明性的网络安全赛制。在这种赛制中，不仅仅是比参赛队员的智力和技术，也比体力（因为比赛一般都会持续48小时及以上），同时也比团队之间的分工配合与合作。
3.混合模式(Mix)
混合模式是结合了解题模式与攻防模式的CTF赛制，比如参赛队伍通过解题可以获取一些初始分数，然后通过攻防对抗进行得分增减的零和游戏，最终以得分高低分出胜负。

CTF比赛的题型

参加CTF比赛，最重要的就是做题。但是CTF的题型可与在初高中学习生涯中遇到的考试试题不同哦！CTF比赛的题目类型主要有以下7类：包括MISC、PPC、CRYPTO、PWN、REVERSE、WEB、STEGA。
WEB

题目涉及常见的Web漏洞，诸如注入、XSS、文件包含、代码执行等等漏洞，这也是CTF中最常见的题型。

PPC

Professionally Program Coder，即编程类的题目，这类题目涉及编程算法，所以相比ACM（国际大学生程序设计竞赛）的题目更容易。

CRYPTO

Cryptography，即密码学，主要考察的是各种加（解）密技术，包括古典加密技术和现代加密技术，甚至有些出题者会自创加密技术。

PWN

PWN在黑客的俚语中代表着“攻破、取得权限”，多为数据溢出类题目。

REVERSE

即逆向工程，题目涉及到软件逆向、破解技术。

STEGA

Steganography，即隐写术。参赛者需要从视频，图片或音频中获取隐藏在其中的Flag。

MISC

Miscellaneous，称作“安全杂项”，题目涉及流量分析、电子取证、数据分析等多项内容。


CTF比赛中的明星战队

TCTF自举办以来，每年都会吸引国际无数顶尖安全战队参加。
来自波兰的Dragon Sector战队，非常擅长“逆向”领域的试题，解题思路非常特殊，其在世界范围内更是成名已久，不仅在CTFtime2018、2016、2015年度排名中位列第二，2014年度排名更是高居第一。在TCTF 2018决赛（国际赛）夺得冠军后，战队队员更是开心的在台上举“杯”庆祝。

来自俄罗斯的LCBC 战队，在极客圈非常受喜爱，他们比赛中往往会有脑洞大开的解题思路，不过就是”运气"差了一点。

在 TCTF 2018决赛中，LCBC 一度攀升到榜单第一，可惜最后还是Dragon Sector战队拿走了冠军。原来在比赛结束2 分钟后，LCBC 战队解出了 2 道题，如果这两道题提交了的话，得分刚好可以反超第一名，真是堪称“LCBC式的忧伤”。

小哥哥见得多，小姐姐可是 CTF 比赛里面的稀客。韩国的Cykor战队，不仅在TrendMicro CTF、Codegate 2017 prequals等诸多大赛中都曾摘得桂冠，队里的小姐姐选手也成了赛场中独特的风景线。

其中排在第三位的是来自腾讯的A*0*E战队，它是一支典型的联合中国互联网安全技术与中国高校顶尖安全人才的组合，战队成员大部分为90后，其中三分之一的队员是在校大学生。在组建的第一年，A*0*E就成功打入了DEF CON的总决赛。

TCTF




简介：TCTF是由腾讯安全发起、腾讯安全学院、腾讯安全联合实验室主办，腾讯安全科恩实验室承办，0ops安全团队协办的网络安全赛事平台。腾讯信息安全争霸赛力图建立国内首个网络安全的人才培养平台，旨在通过这个平台发掘、培养有志于安全事业的年轻人，帮助他们实现职业理想，走上世界舞台。

赛事特点：TCTF 从 2017 年举办以来，已经连续三届获得了DEF CON CTF外卡赛资格,连续两年获得CTFtime满分评价。使用的题目“既有广度、又有深度、还有难度”,是选拔优秀网络安全人才的有效途径。

腾讯安全持续以赛代练，深入产学研一体化探索，形成“发现—培养—转化”的人才培养生态链，倾力打造赛事与人才培养“双一流”的网络安全人才培养平台。

在TCTF赛事中表现优异的学生,将有机会获得腾讯安全联合实验室顶级极客的“言传身教”,参与DEF CON CTF等国际顶尖安全赛事,还能获得从学术研究到职业生涯发展的全方位指导与培养。
