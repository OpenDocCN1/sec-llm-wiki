破解Face ID、宝马汽车、智能手机WLAN…两大黑客盛会我们带来这11大议题

如果要问谁是这个世界上影响力最大的黑客？Jeff Moss，一定是第一个跳进许多人脑海中的名字。


（年轻时的Jeff Moss，妥妥有颜又有才的黑客男神）

1993年，“会玩”的黑客Jeff Moss在世界赌城拉斯维加斯发起了第一届DEF CON，以一己之力带起了举办黑客聚会的潮流。4年后，积累了一定声誉的Jeff Moss又在同一地点创办了更为正式和学术范的Black Hat黑帽大会。

20多年过去，两大盛会连同它们的举办地拉斯维加斯，已经稳居全世界极客们的“精神栖息地” 之首。每年的7、8月份，世界上最好的网络安全研究人员和黑客都会在这里集结，共同切磋“破解或攻破”的艺术。

Black Hat&DEF CON已经是信息安全行业公认的最高盛会，也是全球顶尖黑客大咖们炫技的舞台。作为鉴定极客技术的重要参照物，这两大安全会议的议题向来是全球一线安全公司及数以万计的安全研究人员的“必争之地”。

要成为安全行业顶端的Speakers并不容易，Black Hat & DEF CON对议题的筛选极其严苛：不仅要是在相关领域具有独到、深度的研究，还需要对安全行业的未来发展具有深入影响。能够带着自己的研究议题走上拉斯维加斯的讲坛，是很多网络安全从业者毕生追逐的成就。

然而，在今年的Black Hat & DEF CON大会上，来自腾讯安全的多名安全专家，一次性带来了涵盖车联网、生物识别、Chrome 浏览器安全、Windows服务系统、桌面应用、文件分享传输、移动硬件、基带安全、基础软件库开发等热门领域的十一大安全议题，不仅超过了去年国内企业入选议题的总和，也创造了国内企业入围的历史记录。详见下图↓↓↓

下面就来一一了解下这些含金量极高的前沿议题吧！（其中1个议题同时入选了两大盛会，此处不做重复解析，更多详情戳《重磅！腾讯安全十一大议题入选全球黑客顶级盛会》回顾）。

议题1

生物识别技术安全隐患揭秘

苹果FaceID注视检测可绕过

由于生物特征具有唯一性、不变性等特点，随着AI技术的发展，指纹、人脸、声纹等生物特征被广泛应用在认证、支付等领域。近年来，生物认证技术的安全性越来越引起人们的重视。

腾讯安全玄武实验室的安全研究员陈昱、马彬在《Biometric Authentication Under Threat: Liveness Detection Hacking》议题演讲中，介绍了通过软件无感知的方法注入生物特征从而绕过基于攻击介质的活体检测。依托Face ID注视检测在特定场景下的设计缺陷，并利用自制的X-Glasses攻击道具绕过了苹果Face ID的注视检测，从而在用户闭眼的状态下解锁手机。

（腾讯安全玄武实验室分享活体检测安全性议题）

议题2

远程攻击硬件解码器

揭秘智能手机安全“马其诺防线”

全世界的安全研究人员已经在Android智能手机的音频/视频编解码器中发现了许多漏洞，但这些漏洞都仅存在于安卓开放源代码项目（AOSP）软件实现的过程中。然而，几乎被所有智能手机芯片厂商用来提高芯片性能、减少电耗的硬件解码器，其存在的安全漏洞可能导致安防机制如同马其诺防线一样脆弱。

腾讯安全平台部Blade Team基于对搭载高通芯片的智能手机上，一款名为Venus的硬件解码器进行研究，揭开了硬件解码器的漏洞及漏洞利用攻击的工作原理，这一发现不仅深刻影响所有的智能手机芯片厂商及其产业链，更避免了不可估量的安全风险产生。

（腾讯安全平台部Blade Team分享硬件解码器议题）

议题3

披露Windows10服务系统漏洞攻击

开拓安全研究新思路

来自腾讯安全玄武实验室的吴文栩则以《Battle of Windows Service: A Silver Bullet to Discover File Privilege Escalation Bugs Automatically》为题，介绍了在Windows 10系统服务权限提升漏洞方面的研究成果。

（腾讯安全玄武实验室安全研究员吴文栩）

借助巧妙构建逻辑漏洞的自动发现和初步分析系统，团队在一周内发现了3个可以在Windows 10 1803/1809中成功执行本地权限提升的新漏洞，包括1个任意文件读取漏洞和2个任意文件DACL重写漏洞，令攻击者可以以系统权限在目标Windows 10系统中执行任意命令。

议题4

挑战“史上最安全浏览器”

4年研究重磅成果大放送

对于Google的Chrome浏览器的安全研究对未来在产业互联网基于万物互联时代下的信息安全能力构建具有极其重要的意义，也是在复杂的浏览器甚至未来的OS kernel上进行安全能力构建的基础。

来自腾讯安全科恩实验室的冯震、刘耕铭以《The Most Secure Browser? Pwning Chrome from 2016 to 2019》为题，分享了科恩实验室近4年来对 Chrome 浏览器漏洞的挖掘和利用研究。

针对这个令全世界的安全研究人员都热衷挑战的“史上最安全浏览器”，科恩实验室一次性分享了包括构建js fuzz攻击浏览器bug思路，v8利用技巧以及 Chrome 沙箱绕过等多种趣味破解方法，展现了中国安全极客团队的超强脑洞和技术实力。

（腾讯安全科恩实验室讲解Chrome 浏览器议题）

议题5

聚焦智能网联汽车安全

宝马汽车破解细节首度公开

在全球智能汽车领域不断取得新进展的同时，人们对于汽车联网安全的争议从未间断。从2016年全球首次以无物理接触的方式获取特斯拉汽车控制权，到2018年腾讯安全科恩实验室荣获宝马集团授予的首个“宝马集团数字化及IT研发技术奖”，腾讯安全以全球独家的技术实力与安全研究能力，为全球智能网联汽车品牌的数字化转型升级做出了不可替代的安全贡献。

本次大会上，腾讯安全科恩实验室安全研究员蔡智强、王奥辉、张文凯在题为《0-days & Mitigations: Roadways to Exploit and Secure Connected BMW Cars》的演讲中，首度公开了2018年对宝马多款车型的物理接触式和远程无接触式破解研究和技术细节，包括宝马车载娱乐系统、T-BOX模块以及网关模块的系统架构，并详细分析宝马车载诊断、导航升级、互联驾驶、配置更新、短信等服务中存在的多个安全漏洞，以及如何通过外部接口(USB、OBD、伪基站等)对这些服务漏洞进行攻击利用，从而完成对车载娱乐系统和T-BOX的本地和远程破解，甚至进一步实现车辆远程未授权诊断的攻击链。宝马集团的安全专家也一同登台，分享了与科恩实验室在漏洞披露处理上的良好合作以及漏洞修复方案。

（腾讯安全科恩实验室与宝马安全团队同台演讲）

议题6

首次披露SQLite和Curl组合漏洞

护航基础软件库开发安全

SQLite和Curl是当前使用最为广泛的软件数据库，其存在的安全漏洞将严重影响许多的智能设备和软件的安全。腾讯安全平台部Blade Team用新颖的研究方法发现了两大软件数据库中的关键漏洞，并将这两组漏洞命名为“麦哲伦（Magellan）”和“迪亚士（Dias）”。

大会现场，腾讯安全平台部Blade Team首次披露“麦哲伦”和“迪亚士”的漏洞细节，并重点介绍利用这两组漏洞发起攻击的新技术，涉及物联网设备（包括安装了谷歌浏览器的智能家居设备），使用最广泛的Web服务器之一（Apache + PHP）和最常用的开发者工具之一（Git）等诸多领域。

（腾讯安全平台部Blade Team披露软件数据库漏洞）

议题7

远程攻破高通WLAN及调制解调器

助力安卓设备提升安全性能

在高通平台上，子系统受安全启动功能（Secure Boot）保护，无法从外部侵入。腾讯安全平台部Blade Team基于在调制解调器中发现的漏洞，可以打破Secure Boot，并将权限提升至本地调制解调器，然后在基带上设置实时调试器进而入侵。

调制解调器和WLAN固件非常复杂，逆向工程尤为艰巨。在调试器的帮助下，腾讯安全平台部Blade Team确定了WLAN固件的系统架构、组件、程序流、数据流和攻击面。通过Blade Team分享的相关技术以及在攻击面上发现的零日漏洞（zero-day），又一个安卓设备的安全隐患被“悄然”解决了。值得一提的是，由于这一议题对智能手机安全具有重要意义、含金量极高，同时入选了Black Hat 和 DEF CON两大会议。

（腾讯安全平台部Blade Team分享高通WLAN议题）

议题8

首度揭秘攻击范围最广Web漏洞

常见桌面软件易“中招”

网络安全系统设计如若存在逻辑组合，极可能存在逻辑不全的缺陷，攻击者就会利用这个漏洞进行恶意攻击。对于一些广受欢迎的常用开发库，一旦被爆出安全漏洞，将导致数以千计的桌面应用程序面临风险。

在腾讯安全玄武实验室的安全研究员Salt、Hearmen和T0m4to合力呈现的《Web2Own: Attacking Desktop Apps From Web Security’s Perspective》议题中，首度分享了如何用Web的思路攻击桌面应用的研究，并披露了部分常用开发库中的安全漏洞。

（腾讯安全玄武实验室介绍Web2Own议题）

腾讯安全玄武实验室的安全研究员现场分享了桌面应用逻辑漏洞相关的攻击面，并结合实际案例，向观众展示针对逻辑漏洞的攻击思路，从而提出针对性的安全建议：在桌面软件的使用上，需要经常进行安全更新；避免DNS rebind攻击，不访问未知来源的链接；防止CSRF攻击，减少使用第三方插件等。对于桌面软件的开发者而言，需要注意不在开放端口上提供敏感功能；谨慎加载不可信的外部资源；此外，在使用部分开源框架和库时，也需要格外关注其漏洞，并及时跟进修复。

议题9

破解谷歌浏览器智能家居设备

揭示SQLite和Curl漏洞研究新方法

继在Black Hat上首次披露SQLite和Curl两大软件数据库中的关键漏洞“麦哲伦（Magellan）”和“迪亚士（Dias）”之后，腾讯安全平台部Blade Team又在DEF CON安全会议中带来了破解Google Home的详细解读。

（腾讯安全平台部Blade Team分享智能家居议题）

通过从硬件和软件层破解Google Home，腾讯安全平台部Blade Team获取并分析最新固件从而解决了这一安全隐患，并向观众介绍通过Fuzz和手动审计发现SQLite和Curl中的漏洞的新方法。

借助这些方法，Blade Team在SQLite发现了一组三堆缓冲区溢出和堆数据披露漏洞“麦哲伦Magellan”（CVE-2018-20346，CVE-2018-20505 CVE-2018-20506），在Curl中发现了两个远程内存泄漏和堆栈缓冲区溢出漏洞“迪亚士Dias”（CVE-2018-16890和CVE-2019-3822），这些漏洞会影响许多系统和软件。目前，Blade Team已经发布相关漏洞警报，通知所有可能受攻击的供应商发布补丁。

议题10

披露影响“超十亿”手机文件分享漏洞

助力应用厂商实现安全修复

腾讯安全玄武实验室的安全研究员张向前、刘惠明以《Your Secret Files Are Mine: Bug Finding And Exploit Techniques On File Transfer App Of All Top Android Vendors》为题，揭露了目前安卓手机厂商预装的各类文件分享应用中，存在的用户隐私数据泄露、文件被窃取、篡改、网络被劫持等安全问题。由于市面上大量第三方分享分享应用同样存在类似问题，其影响的用户数量或超过十亿。

（腾讯安全玄武实验室介绍文件传输漏洞议题）

对此，腾讯安全玄武实验室也提出了相应的漏洞修复方案，包括构建更安全的WiFi/WiFi-P2P密匙交换渠道和配置、使用TLS/HTTPS和预先交换公钥证书等升级加密传输以及使用以身份验证为基础的证书防止伪造等，并建议应用厂商在综合漏洞修复方案的基础上，建立一套兼具安全和便捷的文件分享安全方案，强化文件分享应用的连接确认、传输加密和防止伪造等功能，保障数亿用户的隐私和数据安全。

通过披露这一系列的前沿安全研究成果和漏洞发现，腾讯安全的研究员们希望借助技术的力量践行腾讯“科技向善”的愿景和使命，助力相关企业改善产品和服务，更好地维护公共利益与创造社会价值；并将致力于推动安全技术的各个领域的加速落地，助力各行各业高效、安全地实现产业升级和数字化转型。
