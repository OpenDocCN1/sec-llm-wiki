# 硬核极客X艺术范儿，我们在上海办了个很酷的会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247487192&idx=1&sn=110f54db615eac6cc07d7e5384222635&chksm=ea19ac23dd6e2535c3e201782dc13143fac37287b7a8d0fc2a85eb2e92a25913077be25a27f2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247487192&idx=1&sn=110f54db615eac6cc07d7e5384222635&chksm=ea19ac23dd6e2535c3e201782dc13143fac37287b7a8d0fc2a85eb2e92a25913077be25a27f2&scene=27#wechat_redirect)

国际顶尖极客与未来艺术地标相遇将碰撞出怎样的火花？6月11日，2019腾讯安全国际技术峰会（TenSec 2019），在上海西岸艺术中心正式拉开序幕。一群来自微软、ARM、腾讯等的国际顶尖安全极客，在上海滩掀起了怎样的安全新风向？

  

![](../Images/7a244c625d4b63132de33c0715d36bf1.png)

  

安全问题向来都不是独属于单个领域的难题。峰会开场，上海市徐汇区副区长晏波，腾讯安全平台部负责人、腾讯安全学院副院长杨勇以及腾讯安全科恩实验室总监吕一平等领导和嘉宾出席本次峰会，并针对新时代下的安全形势和应对策略发表了看法。

  

![](../Images/40830980b849c018d43a8887f713682e.png)

（腾讯安全平台部负责人、腾讯安全学院副院长 杨勇）

  

“

以前是大江大河，我们和激流搏斗；现在是汪洋大海，我们要面对惊涛骇浪的考验。腾讯将以更为开放的心态，与全社会共同构建安全新生态。

**——杨勇**

”

  

![](../Images/0a4ff2fab5778af775277a68f399cdf6.png)

（腾讯安全科恩实验室总监吕一平）

  

“

以前是虚拟世界的安全，现在的安全真的会对物理世界造成影响。TenSec将进一步发挥前沿安全技术交流平台的作用，持续输出安全能力助力行业升级。

**——吕一平**

”

  

精彩的开场后，国际顶级安全专家团轮番登台，硬核前沿的技术交流拉开序幕。 

  

![](../Images/86c9f8a245534a5f132f69915c7807f8.png)

  

****看点一：IoT安全“软硬”兼顾****

![](../Images/1d8ba517100fae6e958c98b328fc6670.png)

  

![](../Images/6317973008f5c348f7d89b94fe35db0c.png)

（ARM物联网设备线业务副总裁Asaf Shen）

  

其中，率先登台的ARM物联网设备线业务副总裁Asaf Shen指出，对于部署物联网的企业来说，安全是一个关键问题。他结合在IoT IP 安全产品研发和市场方面的经验，从一个芯片级漏洞的真实攻击案例入手，首次分享了ARM在物理网芯片安全和漏洞攻击破解方面的系统方法与思路。“时至今日，物联网安全仍像西部的荒野，但我相信我们正采取正确的步骤来驯服这头野兽。”

  

![](../Images/3f7dbc870632698e12b53e48bb2b3da5.png)

（欧盟知名CTF战队成员 Marius Muench）

  

不同于Asaf Shen聚焦物联网硬件安全的研究视角，欧盟知名CTF战队Tasteless的Marius Muench在议题演讲中，带来了Tasteless在动态安全分析等物联网软件层面的新尝试，并首次揭晓了基于python的avatar²框架的全新研究成果与版本更新，引发了现场专家和听众高度反响。

  

![](../Images/86c9f8a245534a5f132f69915c7807f8.png)

  

****看点二：虚拟化安全新范例亮相****

![](../Images/1d8ba517100fae6e958c98b328fc6670.png)

  

![](../Images/aa68f52ee409352d2719309a05ab4c0b.png)

（MSRC高级安全工程师金龙）

  

虚拟化技术的快速运用，使得虚拟化平台的安全性在Windows10出现以来成为业界关注的焦点。MSRC（微软安全应急响应中心）高级安全工程师金龙就以微软Hyper-V的安全防护探索为例，首度将观众引入虚拟机监控程序Hypervisor的安全防护系统，并感受全新Fuzzing程序——Hyperseed的运作理念与全新发现，为虚拟化安全的研究者提供了新范例。  

  

![](../Images/86c9f8a245534a5f132f69915c7807f8.png)

  

****看点三：系统安全攻防全解析****

![](../Images/1d8ba517100fae6e958c98b328fc6670.png)

  

![](../Images/49c8812b35633be031fc7a3716edca02.png)

（腾讯mac安全专家 王朝飞）

  

针对苹果桌面系统macOS恶意攻击激增的现状，基于“未知攻，焉知防”的理念，腾讯mac安全专家王朝飞对macOS系统遭遇到的恶意软件、APT以及漏洞等攻击进行了深度分析。他通过极具场景感和入侵者视角的macOS入侵攻击模拟，揭秘了攻击的典型手法，分享了检测方案和构建macOS EDR所需的数据源和获取手段。同时，他也揭示了一个理念，安全攻防之间的对抗根本上是人与人之间的对抗。

  

![](../Images/86c9f8a245534a5f132f69915c7807f8.png)

  

****看点四：企业安全入侵检测新思维****

![](../Images/1d8ba517100fae6e958c98b328fc6670.png)

  

![](../Images/4b3847fd2c9647f076624c0562d96f8e.png)

（美团基础安全负责人赵弼政）

  

生产和业务环境的变化，无疑重新定义了企业对安全的认知与思维。拥有百万级服务器入侵检测对抗实战经验的美团基础安全负责人赵弼政基于对企业入侵危害大、检测代价高以及方法论等现状的分析，提出企业的工程能力决定了入侵发现的效果。企业应从Web入侵、横向移动、终端安全等多方面着手，遵循数据采集、高运营标准下建模和迭代优化的思路，合理设计入侵安全方案，以避免不必要的企业损失。

  

![](../Images/cb7c617fd4414be8d9c3195245932a19.png)

**玩技术，也玩惊喜，明天将有六大硬核分享：**  

  

主办方腾讯安全平台部和腾讯安全科恩实验室在福利这件事上，无疑是诚意十足的。除了为“聪明的头脑”准备的彩蛋奖励外，上下午的议程都是以一台内存256G的iPhone X的幸运抽奖作为Ending。

  

6月12日，TenSec 2019将迎来更多精彩，由独立安全研究员Nikita Tarakanov和多位腾讯安全工程师组成的专家团将带来关于系统安全、云计算安全、企业安全和网络黑产的议题分享；腾讯安全科恩实验室的一项最新研究报告——《2018年Android应用安全白皮书》也将全球首发。

  

明天，主办方的幸运福利也将继续放送，更多奖品正期待它的主人。硬核而不失趣味，让我们一起期待腾讯安全国际技术峰会的次日精彩吧！
