# 权游8强势回归，它一定不想打破这个纪录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247486722&idx=1&sn=66b75819bfd2f7ffe4d437dc24378efd&chksm=ea19aff9dd6e26ef3b74154df80270406331dd251d43806a5d32b66770260f7a23458c38e320&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247486722&idx=1&sn=66b75819bfd2f7ffe4d437dc24378efd&chksm=ea19aff9dd6e26ef3b74154df80270406331dd251d43806a5d32b66770260f7a23458c38e320&scene=27#wechat_redirect)

  

时隔两年，神剧《权力的游戏》第八季终于在亿万剧迷的苦苦等待中回归。首播日即创新高，收视人数达1740万，打破了第七季最后一集1690万的纪录。  

  

对于《权游》来说，“纪录”就是用来打破的。它创造了电视剧史上主角死亡人数最高、最大规模电视剧同步联播、一季电视剧获艾美奖最多等等的诸多“战绩”，但最令人意想不到的是，**权游还成为了影视史上盗版数量最高的剧目之一**。

  

根据全球知名盗版监测公司Muso在2017年发布的统计数据，**《权力的游戏》第七季在全球的盗版下载量超过了10亿****。**而在2017年第七季刚刚完结时，第八季剧本就曾陷入泄露风波。如今第八季在剧迷们的翘首期盼中开播，“季末的狂欢”更是隐含着难以估量的盗版风险。

  

盗版问题一直是全球影视行业久治不愈的顽疾，业界对于版权保护方法的讨论和推进更是从来没有停止。

  

在本周举办的北京国际电影节上，世界知识产权组织（WIPO）中国办事处、北京市版权局、北京国际电影节组委会共同主办了“电影和版权：机遇与挑战并存”主题论坛。

  

WIPO副总干事王彬颖、中国国家版权局版权管理局局长于慈珂、北京市委宣传部副部长王野霏，以及相关影视版权专家学者、表演者代表、影视制作和传播企业代表，哈萨克斯坦、津巴布韦、吉尔吉斯斯坦等16个国家知识产权及文化官员齐聚于此，探讨版权保护的有效方式。

  

腾讯副总裁马斌受邀出席这次论坛，带来了腾讯在版权保护上的“**以身作则**”和“**技术输****出**”。

  

腾讯成立20年来，共申请全球专利超过28000件，商标累计申请32980件，累计注册18965件。版权方面，仅在影视领域，已积累40898部正版作品，2018年影视版权采购支出超过200亿元。

  

腾讯也一直致力于利用互联网技术打击知识产权侵权监控和维权，通过腾讯安全云、防盗链等特有技术手段，实现对侵权行为的第一时间发现、第一时间取证、第一时间阻断。比如，通过安全云底层技术，在腾讯全系产品（比如浏览器、电脑管家、微信等）中对猖狂盗版的小网站进行屏蔽，有效性达到90%以上。

  

此外，腾讯安全团队还研发了一只“神兽”——神鸮（音同“肖”，猫头鹰）大数据市场监管平台，能够对网络上未经授权传播文字、音乐、图片、视频作品的问题网站进行识别、拦截、固证；依托腾讯70亿个点和1000多亿条边领先的黑产知识图谱，以及腾讯安全20年护航自身业务场景的大数据能力，为相关企业提供高效率、全方位的知识产权保护。

  

基于腾讯安全神鸮大数据市场监管平台网络侵权监测系统，**监管方、发行方可以通过SaaS服务接入，添加版权保护对象，获得侵权链接实时预警和固证，侵权网站线索提取和影响范围分析**的服务。

  

此前《西虹市首富》热映时，腾讯还与深圳市稽查局就针对其被盗版侵权情况，从知识产权保护系统检索搜集侵权盗版链接12000多个，为电影合法权益公司挽回至少1.6亿元的损失。除此之外，神鸮已在广州、深圳、西安等10多个地区应用，为市场监督管理局、版权局等多个政府部门提供定制化多维度的网络风险监测。

  

针对目前大热的《权利的游戏》第八季，神鸮正在积极配合相关版权部门、片方进行盗版打击，致力于保护广受好评的权游季终剧的知识产权。
