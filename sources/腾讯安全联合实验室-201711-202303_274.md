**\[****什么是TCTF?****\]**

老生常谈一下：TCTF是由腾讯安全发起，腾讯安全学院、腾讯安全联合实验室主办，腾讯安全科恩实验室承办，0ops安全团队协办的专业CTF赛事，也是中国大陆连续三年且唯一拥有世界顶级黑客大赛DEF CON CTF外卡赛资格的赛事。

  
至此，TCTF已连续举办三届，每届都吸引了众多国际战队的参与。

  

//

**国际明星战队再聚首**

**千余支战队同台竞技**

//

  

本届TCTF的参赛队伍更是创历史新高，共计有1248支战队报名参加，参赛人数达到4425人，TCTF将迎来更多的朋友。

  

新朋友不断加入，老朋友也如期而至，其中不乏国际明星战队。例如CTFTIME2018排名第一，也是上届TCTF国际赛冠军的波兰Dragon Sector战队；以及连续参加了三届的俄罗斯LC↯BC战队、韩国CyKor战队以及中国台北217战队，都成功地闯入了线下决赛。

  

//

**战况胶着激烈**

**前三战队厮杀至“最后一秒”**

//

  

在最后一天的赛程中，第一梯队的波兰Dragon Sector战队、中国Tea Deliverers战队、中国台北217战队始终保持比分紧咬，比赛一度呈现胶着之势。

  

随后，Dragon Sector战队率先发力，将与217战队的比分优势扩大到近700分，却在此后的3个小时内迅速被217战队和Tea Deliverers战队赶上；长期领先的217战队，在最后5个小时被Tea Deliverers反超；直至比赛结束，前三名之间的分差都没有超过50分。

  

![](../Images/e91c5ea77ce51590682df81b200986e6.png)

(第三届TCTF国际赛预赛得分趋势)

  

其中来自中国台北的217战队，更是堪称“一血杀手”。一举拿下包括Pwnable类型的“Baby Heap 2019”、 “babyaegis”、“scanner”赛题等五个“一血”，并最终以第三名的成绩出线。

  

//

**试题设置激发选手潜力**

**参赛战队各展所长**

//

  

预赛中，中国台北的217战队获得了Pwnable类型最多的一血，展现了在溢出类的题目上的绝对优势；第十一名Bushwhackers战队则更擅长Reverse类，不仅解出了全部的四道题，还收获了其中两个一血，奠定了入围决赛的资格。

  

在此次比赛的23道试题中，有一道Pwnable类型的试题因无人解出，堪称本次比赛的“题王”，而Misc类型中的一道试题因被解出过多导致降为1分，成为本次比赛的“送分题”。

  

随着决赛入围名单的公布，TCTF2019的线下决赛也将于6月8日-9日在上海举行，入围决赛的12支国际赛战队将共同争夺8月在美国举办的DEF CON CTF决赛晋级名额。

  

届时腾讯安全还将举办国际前沿的安全技术分享——腾讯安全国际技术峰会（TenSec），为从TCTF平台走出来的年轻极客创造与顶级大咖的交流机会。

  

此外，TCTF导师团还将联合优秀战队，在北京、西安、上海、武汉、广州等多地举办TCTF公开课，带来CTF赛事环境、信息安全人才职业发展及前沿安全技术等方面的详细解读。
