# 黑客火锅惊艳成都，11月16日TFC 2018等你来战！

说起火锅，大家第一时间想到的肯定是成都。而说起黑客，你将想到什么？试问，如果把世界级黑客大赛放到火锅圣地成都举办，将会碰撞出什么样的火花？

 

11月16日-17日，“天府杯”2018国际网络安全大赛（TFC 2018）将在成都火热拉开帷幕。那么究竟是因为什么，能使得本次比赛像火锅一样用料十足、异常火辣？快来跟随小编来爆爆料！

**有料：汇聚国内外一线大厂，阵容豪华**

  

![](../Images/9fe14abd74ff7c5e3f5e79d481e0faf0.png)

  

本次比赛联合主办阵容包括百度、腾讯、阿里巴巴、360等国内顶尖互联网公司，还汇聚了清华大学、中科院信息工程研究所、亚信安全、永信至诚等国内一流信息安全专业组织。此外，谷歌、微软、苹果、Adobe等国际高富美都将亲临现场提供支持。阵容豪华、技术丰厚，堪比老油火锅，浓香有料。

  

**菜鲜：比赛内容对标国际，奖金池高达100万美金**

  

![](../Images/b89956efee8115a7b4aaf99fc80d8e51.png)

  

Microsoft Edge、Firefox、Chrome、Safari、Office、Adobe PDF Reader、iPhone X + iOS 12，这些世界级黑客大赛比赛内容将同样出现在本届天府杯上。此外，比赛内容还包括Xiaomi Mi8、OPPO R17、VIVO X23等3个国内主流手机机型。比赛形式分为PC端、手机端与服务器端三大项。国际顶级比赛内容配以丰富比赛形式，可谓火锅桌上最新鲜的食材。

  

**肉硬：5场分论坛干货满满，包你满意**

  

![](../Images/42cded9f0942c2a10818806c47935c1e.png)

  

相信看到这里大家已经垂涎欲滴了，别急，主办方还准备了5道硬菜。在大赛举办同时，还将有5场论坛悉数上桌，内容涉及漏洞挖掘、AI安全、云安全、网络空间态势感知、网络安全人才培养等热点话题。论坛上，来自腾讯、百度、阿里巴巴、360、清华大学、北京大学等知名机构的专家将为大家奉献网络安全领域的硬核认知。

  

在16日举行的开幕式和主论坛上，腾讯副总裁马斌将围绕网络安全人才培养发表主题演讲，分享腾讯安全拥抱产业互联网时代的人才培养理念与实践探索。  

  

在分论坛技术分享方面，腾讯安全将联合知道创宇主办“网络空间安全态势感知”分论坛，邀请政府相关部门领导与行业伙伴共同探讨态势感知技术应用经验；深耕IoT领域的腾讯安全移动安全实验室也将带来关于智能家居新型攻击面最新研究。

  

怎么样，这样一桌汤浓、菜鲜、肉硬的“黑客火锅”是不是已经让你按捺不住了？记住此次活动的时间地点如下，可别跑到火锅城去了！
