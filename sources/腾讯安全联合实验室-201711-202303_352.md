# 自动化攻击议题摘得突破奖！CSS 2018腾讯安全探索论坛获奖议题出炉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247486016&idx=1&sn=35cecac9d04003f94a1e26b91ec5442b&chksm=ea19a8bbdd6e21add774bd5e9b3fd878b281065ff8f662f2395bd7134fdbdfcd0f77fdfcbd89&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247486016&idx=1&sn=35cecac9d04003f94a1e26b91ec5442b&chksm=ea19a8bbdd6e21add774bd5e9b3fd878b281065ff8f662f2395bd7134fdbdfcd0f77fdfcbd89&scene=27#wechat_redirect)

8月28日，来自清华大学、中国科学院、绿盟科技、腾讯安全联合实验室等顶尖学府和知名厂商的信息安全研究者，齐聚第四届互联网安全领袖峰会（Cyber Security Summit2018，简称“CSS 2018”）腾讯安全探索论坛（TSec）的现场，针对**云安全、移动安全、物联网安全以及人工智能等多个领域，联袂带来八大信息安全前沿议题**，探讨全球信息安全领域前沿技术、研究成果及未来趋势。

  

经过百人品鉴团的评审之后，本届TSec的获奖议题新鲜出炉。清华大学副教授张超和中国科学院信息工程研究所博士王琰，合作带来的议题《迈向自动化攻击的一小步》获得最高奖项——突破奖。其余区块链、人工智能等多个精彩议题分别获得专业奖和技术奖。

**奖项怎么诞生？**

  

  

      本届TSec除了一如既往地坚持筛选高质量的议题之外，还开创性地打造了[**首个百人品鉴团**](https://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247485965&idx=1&sn=526eb7a1957d1c958e8d45a917e3a1d0&scene=21#wechat_redirect)，集结了重量级安全大咖、资深安全科技媒体主编，以及来自清华、北大、中科院等国内重点院校的相关专业学子，提升了高质量议题的能见度和专业观众的互动性。

  

**大师品鉴团·专家团**

![](../Images/f8fbc8f56d04a72cdb22705596b33640.png)

  

**大师品鉴团·媒体团**

      媒体团方面，邀请了《中国信息安全》、FreeBuf、黑骑士、安全牛、雷锋网等媒体主编和资深记者，同时也邀请到“浅黑科技”、“磐石之心”等知名科技自媒体。

  

**大师品鉴团·新锐团**

       品鉴团还创新性地吸纳了年轻极客力量的参与，来自清华大学、北京大学、吉林大学、南开大学、北京交通大学、北京邮电大学、北京航空航天大学、厦门大学、中国科学院信息工程研究所等全国顶尖学府信息安全相关专业学子组成新锐团，跟随安全界的“老司机”，一同参与了本次议题的品鉴。

  

      本届议题奖项的归属完全由品鉴团打分决定。他们根据演讲者的演讲风格、PPT呈现、专业性、创新性、技术难度、研究价值、社会价值、观众收获等多个维度评议，最后汇总所有成员分数的平均分得出最终得分。

 

      至此，CSS 2018腾讯安全探索论坛已经暂告一段落，作为互联网安全领袖峰会的重要组成部分，腾讯安全探索论坛全力打造了一个全球前沿、尖端安全技术的高质量安全信息交流平台，从全球范围精选而出的议题帮助我们用不同的视角洞悉最前沿的领域。
