       CSS 2018腾讯安全探索论坛（TSec）的[入围议题](https://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247485899&idx=1&sn=52a490c293aec89e20a970b8c5ddf929&scene=21#wechat_redirect)已经公布。

  

      我们发现这一届入围的分享嘉宾要重新定义未来世界的安全：

      数字钥匙比传统钥匙更安全吗？

      智能音箱更贴心吗？

      缓解措施不能绕过吗？

      区块链会让黑客一夜暴富吗？

      …..

      这些，都将在**8月28日**揭开谜底。

  

      但是，我们还发现了一个秘密，这些来自清华大学、中科院、上海交通大学、滴滴的安全专家，好像还要重新定义我们熟知谚语的含义！

 

      来，一起感受下这届TSec分享嘉宾的创造力！

  

1

**“以子之盾，攻子之盾”**

是不是写错了？

  

       并没有！

  

      来自绿盟科技的张云海就是这样提交的议题，《以子之盾，攻子之盾——利用缓解措施自身缺陷突破防线》。

  

      缓解措施是Windows防御体系中的重要环节，通过阻断漏洞利用技术来增加攻击的难度与成本，堪称是微软防御力最强的盾牌。但张云海即将告诉我们，由于设计上的疏漏，新的缓解措施也可能会影响已有的缓解措施，反而被用来突破整个防御体系。这时候，最强的盾牌反而变成了突破口，实现“以子之盾，攻子之盾”。

![](../Images/31f94a450b6bf9e1e49ef1fe33f7345e.png)

  

2

**“叹息之墙”**

坚不可破？

      在希腊神话中区分极乐净土和冥界的那块墙壁就叫叹息之墙，望着为之叹息，寓意坚不可破。

  

      在Win10的防御体系中，也有一个堪称“叹息之墙”的防御手段。

  

      作为Win10 之后推出的浏览器，微软在Edge上的安全保障投入巨大，不仅默认开启了相当于IE的所有防护手段，更是引入了安全沙盒模式。微软方面也曾在公开场合表示，Edge比目前浏览器领域最流行的谷歌 Chrome 以及 Mozilla Firefox 可提供更好的安全防护。尤其在启用win32k filter之后，Edge浏览器进一步加强了其沙盒的防御能力。

 

      但腾讯安全湛泸实验室的安全专家陈楠、Rancho Han却不这么认为，Win10的“叹息之墙”并非牢不可破。他们将在TSec的现场，分享团队如何利用发现的Windows内核漏洞突破Edge安全沙盒，打破这堵绝望的墙壁。

不是电影也可以

**“窃听风云”？**

  

      经典香港电影《窃听风云》向我们描绘了三名警察在利益诱惑下进行窃听交易并销毁证据，但最终难逃杀戮的悲情故事。从此，窃听风云一词也烙上了警匪交锋的场景。这代表着普罗大众与此无关？

  

      来自Tencent Blade Team的伍惠宇通过对当下畅销的智能音箱分析发现，善解人意的智能音箱存在多个高危漏洞，一旦被不法分子掌握，那么“窃听风云”将发生在每一位用户身上。

 

      **TIPS：**近日行业分析机构Canalys发布了一份最新的报告，该报告预测显示到2018年底，使用智能音箱的人数将达到1亿人，而在2017年，这个数字还没有超过4000万。每个家庭都拥有一台智能音箱的场景并不遥远。
