# DEF CON CTF 2018即将开幕！ 你想知道的都在这

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247485872&idx=1&sn=c927bc677f11c6bd899d5ec5dc2ffaca&chksm=ea19ab4bdd6e225d58927a0c9c1d6949a900ec266e85272cc541fe84d19c97faf7073c3c7fec&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247485872&idx=1&sn=c927bc677f11c6bd899d5ec5dc2ffaca&chksm=ea19ab4bdd6e225d58927a0c9c1d6949a900ec266e85272cc541fe84d19c97faf7073c3c7fec&scene=27#wechat_redirect)

      美国当地时间8月9日-12日，沙漠赌城拉斯维加斯将迎来一年一度的极客大Party，届时会有超过两万名来自全球的极客汇聚一堂，共同叩响顶尖极客殿堂DEF CON的大门。

      作为DEF CON中最重要的组成部分之一，**DEF CON CTF的角逐也吸引着全球信息安全爱好者的关注**。那么，今年的DEF CON CTF有什么看点呢？我们整理了大家最关心的问题，希望帮助大家更加清楚的了解赛事进展。

  

  

都有哪些战队入围了总决赛？

      DEF CON在极客群体当中的至高地位，以至于每年能获得DEF CON CTF总决赛的名额就已是实力的体现，而一层一层的筛选制度堪称是极客圈的“创造101”，DEF CON CTF 2018的竞争早在决赛资格争夺时就已如火如荼。**获得入围每年DEF CON CTF总决赛的资格有三种：上届冠军直接晋级、通过本年度DEF CON CTF的线上预赛以及外卡赛的冠军**。

      但DEF CON CTF 2018的外卡赛**由往届的7大外卡赛大幅缩减为4个**，这意味着入围今年总决赛名额的竞争更加激烈。最终来自全球的**25支战队**从TCTF 2018、HITCON CTF 2017、C3CTF 2017、Plaid CTF 2018以及DEF CON CTF 2018预赛脱颖而出，参加本年度最高荣誉的角逐。

（ DEF CON CTF 2018总决赛入围战队名单）

  

  

谁能得第一？

      能拿到决赛名额的战队都有着问鼎冠军的实力，虽然美国PPP战队、韩国DEFKOR战队等拿过冠军的强队今年同在竞争之列。但是从数据上看，今年的冠军争夺会更加地激烈。

      毫无疑问，上届冠军——美国PPP战队的实力强劲；而通过TCTF 2018国际赛拿到外卡赛资格的波兰Dragon Sector战队同样也不容小觑，要知道，在本年度的CTFTIME评级中，Dragon Sector战队是世界第一；而在今年DEF CON CTF预选赛中，Samurai战队异军突起获得第一，压制住PPP战队的风头（可能是想实战练兵，拥有晋级资格的PPP战队也参加了预选赛）。

![](../Images/3160e19a6200843e9b42182eb1167c20.png)

（CTFTIME 2018年度全球战队实力排名）

  

      三支近期拿过“第一”的战队究竟谁能笑到最后？还是新锐战队惊艳亮相？结果令人期待。

  

  

有哪些强队错过了DEF CON CTF 2018？

      CTF是残酷的，残酷在于晋级路上会让一些极客喜爱的战队止步总决赛门前，这当中，无疑要属俄罗斯LCBC战队最为忧伤。来自俄罗斯的LCBC战队在比赛过程中经常展现有脑洞大开的表现，备受极客圈喜爱。但在TCTF 2018的国际赛上，他们无疑是最大的遗憾者。虽然最终斩获了季军，但由于只有冠军才能获得直通DEF CON CTF的名额，LCBC无奈只得与这场世界顶级黑客大会失之交臂。更苦涩的是，LCBC已经连续两年被挡在DEF CON门外，堪称“LCBC式的忧伤”。

![](../Images/168246a361012a38238b74c459964fa7.png)

（LCBC战队在TCTF 2018国际赛上）

  

       一个心酸的细节是，赛后据媒体了解到：在TCTF 2018国际赛结束2分钟后，LCBC战队解出了2道题。根据计算，这两道题提交后，LCBC战队的得分刚好可以反超第一名波兰Dragon Sector战队。

  

  

中国极客有哪些期待？

       近年来中国战队已是世界顶尖安全峰会的常客了，此时正在美国召开的BlackHat大会上， 就将出现腾讯安全科恩实验室安全专家的身影，他们将带来三个前沿议题的分享（[iOS越狱、远程破解特斯拉…我们要在BlackHat2018上公开这些技术细节了](https://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247485854&idx=2&sn=36f40864b1a533d46ea2b018e24b2657&scene=21#wechat_redirect)）。今年的DEF CON CTF上同样有着中国极客力量，共有**四支中国战队入围总决赛**，其中，腾讯A\*0\*E联合战队在今年5月6日举行的DEF CON CTF外卡赛Plaid CTF上，力压世界前十大战队斩获冠军，成功拿到通往DEF CON CTF 2018总决赛的入场券，成为入围本届DEF CON CTF决赛的首支中国战队。

![](../Images/7f670103239970632c11fbcb5561dfaf.png)

（腾讯A\*0\*E联合战队标志）  

  

      这支联合战队由腾讯eee战队、浙大AAA战队、上海交大0ops战队、复旦\*\*\*\*\*\*(sixstars)战队共同组成。其中eee战队由腾讯内部多个安全团队组成、腾讯安全科恩实验室掌门人吴石担任导师，是腾讯安全联合实验室孵化培养的中国新一代网络安全人才计划的典型代表。而三支高校战队均是TCTF平台的优秀代表战队，曾在DEF CON CTF 2017、第二届强网杯等国内外多个专业比赛上获得优异成绩。

      中国极客力量将与世界顶级极客同场竞技，让我们拭目以待。
