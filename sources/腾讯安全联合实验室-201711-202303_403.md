# AsiaSecWest第二日亮点议题汇总

6月7日，AsiaSecWest国际安全技术峰会—亚洲站精彩继续。

  

**清华大学网络科学与网络空间研究院教授**

**段海新**

![](../Images/de586203c4637e43a0ff6c880b2bea2e.png)

首先登台的是来自清华大学网络科学与网络空间研究院的段海新教授。段教授为我们带来了关于“端到端通信中危险的中间盒子：祝福还是诅咒？”的分享。他表示，中间盒子在保护网络安全的同时，带来的安全隐患也不容忽视。同时，段教授也为该问题提出一些缓解方案，为网络安全设计者提供新的思路。

  

**Cisco安全研究员**

**Jonas Zaddach**

![](../Images/2ddb50943a0d271edae36761b5b192c0.png)

Cisco安全研究员Jonas Zaddach带来了关于特码自合特征码自动合成器的议题分享，他通过整合已有项目，打造出特码资自合，即特码自合特征码自动合成器。他表示，系统在控制流级别上通过二进制差异对比可以找出一类恶意软件样本之间的代码相似性，同时快速准确检测新威胁和变形恶意软件家族的现代反病毒行业来说，也是一个必不可少的框架。

  

**埃因霍芬理工大学硕士**

**Björn Ruytenberg**

![](../Images/996c7919d42c5d8710e8c3c9a558fded.png)

来自埃因霍芬理工大学硕士Björn Ruytenberg从Adobe Flash 漏洞利用的角度，为我们介绍了他最近发现的两个沙盒逃逸漏洞的故事，而这两个漏洞都导致Adobe Flash对其沿用了十年的沙盒设计做出重大修改。同时他表示，产生漏洞的根本原因是对于“远程”和“本地”的定义过于随意、路径验证不严谨以及和操作系统相关的未补漏洞，并对未来Flash漏洞的修补提供了建议与思路。

  

**CanSecWest创始人、北美黑客社区著名人物**

**Dragos Ruiu**

![](../Images/e3acd61a3d2fdc3a43eca0a31dc2a557.png)

CanSecWest创始人、北美黑客社区著名人物Dragos Ruiu带来精彩的“返场”演讲，为我们介绍一些主流厂商的一些WIFI芯片及其安全隐患，同时也为我们讲述了树莓派的发展及其在世界应用中的一些优势特点。

  

**MWR实验室安全研究员**

**Georgi Geshev**

![](../Images/cf742f709f4b6202d6211410489449c5.png)

MWR实验室安全研究员Georgi Geshev为现场观众带来利用逻辑漏洞构建漏洞利用链的议题分享，他为我们剖析了这类漏洞的局限性以及发掘这类漏洞的方法，并介绍了通过静态和动态分析工具加速和自动化这个过程的工作。

  

**IOActive高级安全顾问**

**Enrique Nissim**

![](../Images/8aa75e2b9d8a88418147a875dc0a5ea8.png)

IOActive高级安全顾问Enrique Nissim带来了关于KMDF 驱动程序的逆向工程和漏洞挖掘的议题，他通过许多例子讲解了KMDF及与其逆向相关的核心概念和功能。他在现场调侃道：“如果你掌握了这些知识，你也可以自己挖掘KMDF驱动程序的安全漏洞了。”

  

**Cisco Talos团队成员**

**Aleksandar Nikolic**

![](../Images/61dbc6fcc9afe3e7373fd507af67fc6e.png)

本届峰会的最后一位演讲嘉宾是来自Cisco Talos团队的成员Aleksandar Nikolic，在此次演讲中，他们为大家介绍了模糊测试与代码审计互相驱动的议题，揭秘风靡一时的模糊测试工具的奥秘。

  

耗时两天，经历了13位嘉宾的前沿分享，极客版“最强大脑”AsiaSecWest国际安全技术峰会—亚洲站完美落幕，为全球信息技术爱好者带来了一场高技术含量的顶级盛会。作为本次大会的战略合作伙伴，腾讯安全也将继续为搭建中西方安全技术交流平台而努力，为全球网络安全事业贡献更大的力量。
