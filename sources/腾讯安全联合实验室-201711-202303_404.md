# AsiaSecWest首日亮点议题汇总

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247485650&idx=2&sn=d691e451542d7b6a9769a37ec597bc08&chksm=ea19aa29dd6e233f70acbc007ae714eb786b725f80d9e15ce1224853049d6ff8f41bcc1a9fb4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247485650&idx=2&sn=d691e451542d7b6a9769a37ec597bc08&chksm=ea19aa29dd6e233f70acbc007ae714eb786b725f80d9e15ce1224853049d6ff8f41bcc1a9fb4&scene=27#wechat_redirect)

北京时间6月6日，极客版“最强大脑”的AsiaSecWest国际安全技术峰会—亚洲站，在中国香港正式召开。本届AsiaSecWest共历时2天，全球极客界“最强大脑”汇聚于此，带来最具前瞻性、最具含金量的技术议题。

  

聚焦峰会主会场，从进场开始，极具仪式感的中国风“签到题字”环节就吸引了众多与会嘉宾的眼球。

  

![](../Images/530f356e8f198f65db0671091ef03a15.png)

  

现场有充满中国特色的折扇礼品，还有资深书法大家现场挥毫，希望这些极客界“最强大脑”们可以体会到地道的中国风味。

  

**CanSecWest创始人**

**北美黑客社区著名人物**

**Dragos Ruiu**

CanSecWest创始人、北美黑客社区著名人物Dragos Ruiu发表开场致辞。Dragos对现场来宾及合作伙伴表示感谢，同时也希望此次峰会能够将全球极客精英汇聚于此，共探安全技术最具前沿性议题。  

  

![](../Images/f1a45a94fda52f00c70369448f2e9936.png)

**Adobe首席安全策略师 **

**Peleus Uhley**

![](../Images/26f7d3680bea143ba51ed498d2b90c8e.png)  

  

第一位演讲嘉宾是来自Adobe的首席安全策略师Peleus Uhley，本次演讲会他向我们介绍了那些历经不断变化的技术实现却仍然保持有效的概念性技术，以及那些我们仍需继续研究并完善的领域。同时他也表示，开发者应该从最开始就考虑到安全问题，理解安全行业的规律并把它应用到新的技术上，是目前最需要做的事情。

 **  SR Labs 首席科学家 **

**Karsten Nohl**

![](../Images/b35cb5fd918af5c760794bdac3a8b2d2.png)  

  

来自Security Research Labs 首席科学家Karsten Nohl在现场为我们深度剖析厂商们在修复安卓系统漏洞上的失误。经过三年研究，他通过新颖的分析方法查找函数特征，对漏打的安卓系统补丁进行调查和量化。巧合的是，腾讯安全玄武实验室1月份发布“应用克隆”攻击模型时也提到了这类问题。综合这两个研究来看，可见安卓手机厂商在修复漏洞问题上的失误不仅广泛存在，而且具有现实威胁。

**  腾讯安全玄武实验室安全研究员    **

**宋凯和秦策**

![](../Images/21819d3ddb6cb9f7a73a0307dc8b515f.png)*（腾讯安全玄武实验室 宋凯）*![](../Images/566f72f072c176b3cd8083e6824b144f.png)*（腾讯安全玄武实验室 秦策）*

来自腾讯安全玄武实验室的研究员宋凯和秦策带来备受瞩目的创新性安全议题。他们介绍了将Chakra漏洞转化为任意代码执行的新方法，并披露利用漏洞的技术细节。该议题从整体上将浏览器漏洞利用研究向前推进了一大步，向世界展示了中国网络安全团队在技术研究和攻防实战方面的绝对实力。

  

 **  NCC集团研究员 **

**Jeff Dileo**

![](../Images/66f1e3d90c2abf3a559cebd6f42cb067.png)  

  

“都已经 2018 年了，然而即使是没混淆过的 Java 虚拟机代码分析起来还是很痛苦。这还只是 Java 而已，以后恶意软件都用 Clojure 写了看你怎么办！”这位在舞台上向我们发起质问的是来自NCC集团的研究员Jeff Dileo。他向我们介绍一种高效的 Java 虚拟机函数挂钩设计和实现框架。他表示，该设计可以做到向后兼容、跨平台、支持 Java 9。

**美国软件开发工程师**

**Brandon Wilson**

![](../Images/cda9c55532e258d8f2f5ed5aa0290a50.png)  

  

今天的最后一位演讲嘉宾Brandon Wilson为我们讲述了USB 闪存盘固件逆向的最新进展。此次发言，他主要为我们分享了USB发展的技术细节、逆向工程USB闪存盘的现状及其安全影响，同时也畅想了USB闪存盘固件发展的美好未来，并鼓励所有安全人士以此为基础，不断改进USB技术，最终造福所有人。

  

随着最后一位嘉宾的演讲结束，AsiaSecWest国际安全技术峰会—亚洲站首日场已经完美落幕，想更多精彩议题，明日见！
