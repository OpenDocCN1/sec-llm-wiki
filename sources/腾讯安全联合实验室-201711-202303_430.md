# 反诈骗2018第一季报：电信网络诈骗近一半系购物诈骗

2018年第一季度反电信网络诈骗大数据报告，基于2018年1月到3月三个月的电话、短信、网络等风险、诈骗、病毒等发生情况进行综合分析，同时公布当季度诈骗热度指数，让人们更加直观了解当前电信网络诈骗等级，并且及时在家人朋友间作出提醒和防范。

  

新时代新型网络犯罪拥有“国际化、智能化、平台化、产业化、涉众化”五大特点，给警方和全社会带来新的命题、新的挑战，“单兵作战”、“简单的合作协同”能够发挥的效力逐步减弱。

  

在这样的背景下，2018年守护者计划以探索构建“网络安全共同体”为目标，采用**“新科技”**对抗新犯罪，深入网络黑产源头打击治理，占据网络安全制高点；扩充**“新联盟”**解决新问题，政企学研等联盟作战，形成合力；共建**“新生态”**防范新风险，希望更多机构和个人参与到社会生态治理当中，疏堵结合标本兼治。

  

**根据腾讯“守护者计划”2018年第一季度《反电信网络诈骗大数据报告》显示：**

  

*   **诈骗电话拨打次数、收到诈骗短信人数同比减少四分之三以上。**
    
*   **诈骗电话、诈骗短信标记数量双双下降。**诈骗电话标记数量同比下降23.6%，诈骗短信标记数量同比下降75.1%。
    
*   **每5个骚扰电话当中有1个诈骗电话，非法贷款是最大短信诈骗类型，**占比高达61.5%。
    
*   **电****信网络诈骗案件涉案金额下降28.3% ，单案件最高损失金额在连续三个季度攀升后（上个季度为1000万）骤降至200万。**
    
*   电信网络诈骗案件中，**网络诈骗类型占比最大，达73.2%**；**诈骗细分类型中近一半是网上购物诈骗。**
    
*   **社交软件关系链诈骗案件数量季度性趋稳，**代人付款类诈骗季度性下降，**直接借钱类诈骗季度性上升****，在本季度成最大诈骗类型**。
    
*   **支付病毒感染同比大幅下降61.4%，手机资源站是最大的病毒感染源；纯色情类病毒是感染最多类型病毒。**
    
*   **扩大恶意网址检测范围，****相比于2017年Q4恶意网址检测数量792万，增加到4735万。**本季度恶意网址数量在2月农历新年月达到高峰，钓鱼网站中恶意文件占比超过九成。
    
*   **公共Wi-Fi监测数量从2017年的3亿多增加到8亿多。**风险Wi-Fi随Wi-Fi总量增长而小幅缓增，**ARP攻击是风险Wi-Fi的主要类型**，**占比超过70%。**
    
*   **广东省是电信网络诈骗大省**，**诈骗电话、短信、病毒感染份额均排名第一**，但相比2017年已呈下降趋势。**广西省是社交软件关系链诈骗大省，社交软件关系链诈骗IP在TOP5 省份均小幅回升。**
    
*   **广州、深圳是电信诈骗高发城市，东北重点城市短信诈骗较多，大连、长春、吉林、沈阳均在TOP10**。
    
*   2018年第一季度**诈骗热度指数为51****，环比下降趋势明显。**
    
*   **近一年QQ/微信违法违规行为举报打击累计超过52万个，其中本季度占比56%****。**
    
*   **诈骗和黄赌毒是主要打击类型，诈骗打击类型中交易诈骗占四成。**
    
*   **已打击帐号IP地址地域分布相对集中，广东和江苏是占比较大省份。**
    
*   **协助警方破获首例“特大跨国网络组织卖淫案”，抓获违法犯罪嫌疑人349人，冻结扣押涉案资金及财物3000余万元**。
    
*   **本季度仿冒公检法类短信数量为2655个，相对于2017年季度平均数量大幅下滑70.9%；该类型案件数量环比下降62.5%。足见守护者计划安全策略及协助警方打击、广大公众防诈骗意识提升正在逐步奏效。**
