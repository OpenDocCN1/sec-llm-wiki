# 腾讯发布TRP-AI反病毒引擎 携手联发科亮相MWC2018

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1NzM0MTMzMg==&mid=2247485079&idx=1&sn=79f3a777bf2b8ce8e63f01ba87a7caec&chksm=ea19a46cdd6e2d7a3d95f93cce110fde8ca4d9ce95f96e55dd3a821c670f596cfdb5093b3bf5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1NzM0MTMzMg==&mid=2247485079&idx=1&sn=79f3a777bf2b8ce8e63f01ba87a7caec&chksm=ea19a46cdd6e2d7a3d95f93cce110fde8ca4d9ce95f96e55dd3a821c670f596cfdb5093b3bf5&scene=27#wechat_redirect)

全球移动通信领域的最高盛会之一——世界移动通信大会（MWC）今天在巴塞罗那正式开幕，集中展示来自全球众多厂商在移动领域的最新科技成果。腾讯公司与老牌IC设计厂商联发科联合参展本届大会，并宣布腾讯TRP-AI反病毒引擎正式发布，该引擎深度应用AI技术，可大幅提升病毒查杀效率。

*（腾讯TRP-AI反病毒引擎亮相MWC 2018）*

**携手联发科亮相MWC**

**促进“AI+移动安全”全面应用**

![](../Images/04f9d35e592ac1c45d3cd77647a64867.png)

在追逐众多手机厂商发布的最新款旗舰手机等硬件技术同时，移动领域的软件创新能力也成为大家关注的焦点，在保障手机用户上网安全已成刚需的时代背景下，反病毒技术的突破更是备受瞩目。

参展本届MWC大会的腾讯TRP-AI反病毒引擎，是基于腾讯先进的AI应用场景研究，结合腾讯安全团队长期对Android平台恶意代码检测、对抗的工作经验，设计的实时行为监测、抗免杀技术强、深度学习的AI反病毒引擎，可显著提升病毒对抗的综合能力。

承担该引擎研发的腾讯安全联合实验室反诈骗实验室负责人李旭阳表示，在TRP-AI反病毒引擎研发完成之后不久，就已与一些手机厂商达成合作。而此次与联发科在底层芯片层面达成合作，也将进一步提升TRP-AI反病毒引擎的病毒检出效率，抢占病毒对抗先机。

值得关注的是，这将是业界首次，移动安全与底层芯片在深度学习技术领域的紧密合作，无疑将进一步促进“AI＋安全”在移动终端侧的全面应用，并将推动移动安全能力的前置，提升对终端威胁的响应速度。

       有业内人士分析指出，腾讯此次与联发科的合作不仅是当下软硬件技术合作的典范，更意味着双方在芯片制造、反病毒、AI等多个领域的领先研究实力将有机结合，对于移动安全行业而言，这或许将开启一个AI应用在移动安全上的新时代。

![](../Images/30e8e424026792bf112efc0baaae3166.png)

**突破传统杀软困局**

**腾讯TRP-AI反病毒引擎克服三大挑战**

![](../Images/04f9d35e592ac1c45d3cd77647a64867.png)

值得强调的是，与联发科达成合作的腾讯TRP-AI反病毒引擎并非是一种满足技术想象的“概念引擎”。

“传统反病毒引擎的运行机制已经越来越不适应当下的病毒对抗形势，研发下一代反病毒引擎迫在眉睫”，据李旭阳介绍，当下的病毒形势呈现出新病毒不断涌现、病毒快速变种、病毒云端控制三大显著特点，传统反病毒引擎虽然可以及时响应并查杀病毒，配合现有成熟的云查技术更是可以将响应时间降低至一天甚至数小时内，但响应再及时依然无法阻止已感染用户遭受病毒威胁，阻断用户隐私泄漏、财产损失。

腾讯安全团队为应对未来严峻的安全挑战，配合腾讯高度成熟的AI技术，基于AI芯片的独立计算能力，自主研发了AI反病毒引擎——腾讯TRP-AI反病毒引擎。

该引擎首次引入基于APP行为特征的动态检测，并结合AI深度学习，对新病毒和变种病毒有更强的泛化检测能力，能够及时发现未知病毒，变异病毒，和及时发现病毒恶意代码云控加载，更为智能的保护用户手机安全。

       与此同时，腾讯TRP-AI反病毒引擎在国际和国内范围内都拥有海量病毒行为样本，可实时训练生成最新的AI模型用以保障前端用户AI引擎的模型更新；除此之外，腾讯TRP-AI反病毒引擎利用云端集群计算能力还能保障前端响应的实时性和低计算压力。

![](../Images/b3ec908bd740a3460de9b375b33acfdf.png)

*（腾讯TRP-AI反病毒引擎架构）*

在病毒形势日益严峻的态势下，以腾讯与联发科合作为代表的跨界正在成为趋势。在洽谈此次与联发科的合作之前，腾讯安全联合实验室反诈骗实验室已与国家食药总局、国家工商总局、北京市金融工作局、深圳市金融办达成战略合作，共同构建互联网食药大数据监管指数平台、可疑网络传销态势感知平台、大数据金融安全监管科技平台，开放能力赋能社会各个领域。可以预见的是，多领域进一步深度合作，形成合力共同打击病毒，构建更加智能安全的移动安全时代将变得未来可期。
