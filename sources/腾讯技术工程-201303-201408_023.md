# TEG“传递幸福，感恩母亲”现场活动

**朗科片区：**

活动地点：朗科2楼

活动时间：5月9日15:30~16:30

  

1. 甜蜜的礼物\----可以在专业烘焙师傅的指导下制作甜点，将**自己亲手制作的甜点**带回家送给妈妈。

  

2. 爱心花束\---可以现场**DIY果蔬花束**，制作创意礼品送给妈妈。

  

3. 特别的贺卡\---可以现场拍摄**母亲节专属照片**，写上祝福，作为最特别的母亲节贺卡，送给妈妈。

  

4. 充满爱心的围裙\---现场购买**母亲节定制围裙**，可在围裙上写祝福话语，包装后现场填写快递单，送给妈妈（有付出的爱才有意义，围裙和邮资费用自理哦！）。

**飞亚达片区：**

活动地点：飞亚达5楼“爱马哥”

活动时间：5月9日15:30~17:30

  

1.短信送祝福------鼓励员工**发祝福短信给母亲**，凭发送的信息参与此次活动！（需拿手机核对信息）

  

2.亲手DIY祝福------参与活动的同学可以亲手制作**祝福风铃和祝福卡片**，通过拍立得现场拍照纪念并悬挂到**许愿树**上。（前50名参与的同学还有精美礼物领取哟）

  

3.快递你的思念------活动结束之后，将统一将刚才拍摄的照片和祝福卡片用平信的方式**邮寄**给到员工指定的联系人。

  

4.长久的思念------员工制作的**风铃**可以带走挂到办公桌前，以寄托对母亲的思念。
