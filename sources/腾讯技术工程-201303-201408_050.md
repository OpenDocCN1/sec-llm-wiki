# 乘车安排

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYwMjI2MA==&mid=100026686&idx=4&sn=349e49ea19dd26f188d7aea85c694e72&chksm=26cada4511bd535310bdd11290c2bf68ce17ca0c17df679e86a341dff14c12a81e42f1e1ae3e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODYwMjI2MA==&mid=100026686&idx=4&sn=349e49ea19dd26f188d7aea85c694e72&chksm=26cada4511bd535310bdd11290c2bf68ce17ca0c17df679e86a341dff14c12a81e42f1e1ae3e&scene=27#wechat_redirect)

**1.**会务组安排了大巴前往西丽大学城体育中心，每辆车均标有车号及大会标识，将于**01月10日中午12:00**准时发车；**最后一班车12:40发车**；

**2.**本次大会不分车，每辆车**坐满即走**，请各位同事配合现场工作人员的安排，尽量选择靠前的大巴乘坐；

**3. **乘车地点：松日大厦、朗科大厦、飞亚达大厦班车停靠点。请各位同事务必瑞雪守时，集体乘车前往；

**4. **为加强团队融合，所有参会人员需统一乘坐大巴前往场馆，不允许自行驾车；

**5. **返程安排大巴**统一送回公司**，中途可停靠就近**地铁站（5号线环中线-大学城站）**。
