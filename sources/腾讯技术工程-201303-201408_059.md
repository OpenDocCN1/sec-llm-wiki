# 三、报名规则

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5ODYwMjI2MA==&appmsgid=100026349&itemidx=4&sign=61dbb5f0122decc983306b6c50a9d2e5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5ODYwMjI2MA==&appmsgid=100026349&itemidx=4&sign=61dbb5f0122decc983306b6c50a9d2e5&scene=27#wechat_redirect)

1、欢迎咱们TEG的运动员们踊跃报名，各部门报名接口人：**部门秘书。**

2、所有运动会比赛项目均为团队项目，以部门为单位。

3、由于大部分比赛都是同时进行的，所以各比赛项目成员避免重复。

4、每个项目每队必须指定1名队长，由队长负责制。
