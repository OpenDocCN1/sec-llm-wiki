# TEG首届男子篮球联赛圆满落幕，网平一队夺冠！

> 原文：[http://mp.weixin.qq.com/mp/appmsg/show?\_\_biz=MjM5ODYwMjI2MA==&appmsgid=10000292&itemidx=1&sign=d747eecfce437224b12268d4c03804f8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5ODYwMjI2MA==&appmsgid=10000292&itemidx=1&sign=d747eecfce437224b12268d4c03804f8&scene=27#wechat_redirect)

 

TEG首届男子篮球联赛在网平一队与安全平台队90分钟激烈的冠亚军角逐后圆满结束。网平一队凭借出色的中投和严密的防守，以64:54奏凯，摘得TEG首届男子篮球联赛的冠军。

 

![](../Images/8a60114ed2359477191d3ab3ec0122f4.png)

![](../Images/bb79aa14d61907227e5181b28e621eae.png)

 

在这块激动人心的场地上，同样也上演了一场扣人心弦的巅峰对决，客服一队把内线优势和快攻发挥得淋漓尽致，最终以77：51的比分力压企业IT队，夺得本届联赛的季军。

 

![](../Images/c974f81eeb412b5e0675b46c896b191d.png)

 

至此，为期二个月的TEG首届男子篮球联赛圆满落幕，本届比赛共吸引12只球队报名参赛，以及数以百计的啦啦队到现场加油助威。精彩花絮带你重回赛场：
