# 智能化网络运营时代何时到来？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYwMjI2MA==&mid=2649736767&idx=1&sn=371366f16fd724992c6953ca16a1cbc3&chksm=bed3554489a4dc52c5368dd4e5de355b787d9441188cdcd5ccb88e7e04c517b923ceb96dd05d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODYwMjI2MA==&mid=2649736767&idx=1&sn=371366f16fd724992c6953ca16a1cbc3&chksm=bed3554489a4dc52c5368dd4e5de355b787d9441188cdcd5ccb88e7e04c517b923ceb96dd05d&scene=27#wechat_redirect)

    2016年11月23日，由腾讯TEG网络平台部举办的第六届网平技术峰会如约而至，邀请了公司内外部7位嘉宾进行主题分享，现在就随现场小编一起来看看这场技术盛宴~

    本次技术峰会以当前极热的大数据+智能计算为内容主旨，从腾讯自身，从网络平台部自身出发，面临海量服务器+网络设备规模，从网络架构、网络研发、网管系统、服务器运营、网络运营等角度，阐述网平在大数据和智能化下的实战经验和挑战，以及在未来的发展趋势，以促进部门在大数据和智能化领域下的分享和交流。

![](../Images/245cf246b9e4e27a5a5082e5109a1a05.png)

腾讯副总裁tombie

    在开场致辞中，腾讯副总裁tombie表示面对海量业务，云的发展，快速变化的需求和挑战，我们的网络需要更加的灵活，需要走向自动化可自动编排的时代，海量运营需要也通过自动化、工具化和智能化来实现。

分享主题：认知计算

![](../Images/49c95be117226a088531a4a81bd4faa2.png)

分享嘉宾：IBM Dr. Martin Paterok

    Martin介绍了IBM的Watson和认知计算技术，Watson通过认知技术，能够对结构化和非结构化数据进行分析和理解，并通过数据洞察，进行推理演进和抽象模式和关系，寻求最高概率的解决方案，并能够通过不断的自我学习来优化认知能力。Martin还以Wechat chat机器人，Macys为例来讲解Watson和认知计算的应用。

![](../Images/33e0ea33b6aacd7f9b1f6ec20314ef05.png)

分享主题：大数据平台及人工智能

![](../Images/73342e8ed2247ea0fc51e1dfeeb26913.png)

 分享嘉宾：腾讯数据平台部andym

   Andy介绍了Alphago在围棋人机大战中使用的几个主要的智能学习方法，提出了目前高性能计算的三大挑战：更广、更深、更复杂。而后Andy结合腾讯在大数据平台自身的发展，向大家分享了目前主流的几大高性能计算平台：AngelPS、tGraphX、DeepOcean和TeslaML及各平台目前的主要技术特点。

分享主题：网络运营新趋势

![](../Images/3e4e36a49342dc028ca5900a0a25d4f1.png)

分享嘉宾：腾讯网络平台部webster

    Webster与大家分享了在大数据下网络运营的四大新趋势：糅合上下游、内外部团队运营能力；通过DevOps的运营新模式提升效率；推动快速建立网络软化场景的新分层运营模式；通过智能化手段进一步提升运营能力。

分享主题：服务器运营大数据实践

![](../Images/c88b9f4c86376c73c2f08ed4123dcbf5.png)

分享嘉宾：腾讯网络平台部sam

    面对海量的服务器运营，Sam以服务器硬件故障率最高的硬盘故障为例，通过大数据实现硬盘故障预判的过程：通过数据挖掘，机器学习，对服务器硬盘SMART数据进行管理和分析，再通过选取合适的算法和建模，最终落地验证来完成对服务器硬盘故障的预判。

分享主题：SDN在路上

![](../Images/500595a83298f6a7bc0f9eb62535ed8b.png)

分享嘉宾：腾讯网络平台部king

    King通过时间轴，阐述了腾讯从2012年早期开始，在SDN道路上至今的发展：从DCI的低利用率高成本，到国内首个广域网流量分级调度系统；从IDC大二层cluster网络到今天的Cloud VPC、黑石及可自动化业务编排的5.0V网络；从一个跟随者走向领先，预见未来，不如创造未来。

  

分享主题：网络自动化管理演进之路

![](../Images/93b7ed1d21bcd686461294f60ebe487a.png)

分享嘉宾：腾讯网络平台部cesc

    Cesc阐述，面对海量规模的腾讯网络，以往的工具化支撑的网络自动化运营已经面临场景“大爆炸”的瓶颈；腾讯网络自动化已经走向了以DevOps为基础的业务场景+开发编程的DIY平台化时代，而未来，我们将继续推动自动化，面向SDI（Software Data Intelligence）的智能化时代。

分享主题：如何构建网络大数据的基础

![](../Images/2cb7fd4026735ff7d68999f9a710e424.png)

分享嘉宾：腾讯网络平台部nemo

    Nemo从整个行业大数据的生态，向大家分享了网络大数据的基础：随着芯片技术发展、网络细节将越来越多的呈献给网络管理人员；高效、实时收集网络状态，迅速做出决策，控制网络行为；从传统的运维向精细运维、智能化运维转变；网络管理将从关注连接到关注用户业务状态。
