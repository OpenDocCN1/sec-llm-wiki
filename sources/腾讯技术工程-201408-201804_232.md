# 【重阳节】传说知多少？

今天是重阳节，各位TEGer记得给家中老人带去节日的问候哦！——好啦，当完孝顺的乖宝宝，现在让我们一起聊聊重阳节的传说！

相传在很久很久以前的东汉时期，发生了一件惊天动地的大事情....汝河有个瘟魔据说长这样→每年都会出来散布瘟疫，危害人间。所到之处，家家有人病倒，天天有人丧命，这一带的百姓受尽了瘟魔的蹂躏。![](../Images/d552a0c3656cde58ec63777b8a984eff.png)  
![](../Images/dc4c2666f02c3d27af44afb02fa169eb.png)←直到有一天，出现了一个叫做桓景的中年人...下决心要为民除魔，于是遍访名山高士，终于拜得一位仙长(姓甚名谁不详)为师，苦练降妖本领。直到有一天，仙长对恒景说：你艺已成，明天是九月初九，瘟魔又要出来作怪，你这就回家去为民除害吧。  
于是恒景回到家乡，在初九的清晨，按仙长的吩咐将乡亲们领到附近山上,传闻当时的场面是这样↓↓↓  
![](../Images/bfe944dbc9f632e886327685d7238898.png)  
恒景将仙长赠予的茱萸和菊花分给众人。中午时分，瘟魔冲出汝河。不料，马上被茱萸和菊花的香气震慑住了↓↓↓![](../Images/57965d4f8bd655d01133a5009ad4c955.png)

  

恒景手持降妖剑，几个回合就杀死了瘟魔，从此，九月初九登高避疫的习俗便年复一年地传了下来。所以说，瘟魔啊，你怕茱萸就算了，为何还要害怕菊花？？![](../Images/fed5730d89440cba0b13149e1bc9ef67.png)

  
  
在《易经》中，九是阳数，九月初九两九相重，故称重阳。↓↓↓  
![](../Images/dbe72b2117d4b680935a7dbd5c2d1276.png)  
到了唐代，重阳被正式定为民间节日，明代，更有了官民吃重阳花糕以及登高的风俗。  
唐代重阳喜乐会→每逢重阳节，百官休沐，皇帝赐宴曲江池，人们纷纷佩茱萸，聚会宴享，观赏菊花。![](../Images/351593a3a5451cc0d5c886409d16ccab.png)  
![](../Images/c961e956ba37b1d28ec5d5278fd3b744.png)←明代重阳登高会九月重阳，皇宫上下要一起吃花糕（具体长什么样，实在不详）以庆贺，皇帝要亲自到万岁山登高，以畅秋志。  
  
在新中国成立40周年后的1989年，重阳节又有了新的含义↓↓↓![](../Images/c4cc655e76af40a60083fb7e402c15db.png)  
我国把重阳节定为老人节，取九乃大数，寓意健康长久，将传统与现代结合，赋予重阳节敬老爱老的新内容。**所以，今天记得打电话回家问声好哦！**
