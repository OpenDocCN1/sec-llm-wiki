# 一本图书 一个愿望

2015年11月10日，TEG书香下午茶携手TEG志愿者协会开展《寄梦--一本图书，一个愿望》活动，向热爱公益的鹅们发出倡议，向新疆维吾尔自治区喀什地区疏附县吾库萨克乡木苏玛村小学、广西容县黎村镇六旺茅田分校、吉林省舒兰市法特镇黄鱼村小学三所贫困小学进行捐书活动，帮助这三所小学建立图书室，让这些图书点燃远方孩子的希望，照亮他们的未来！![](../Images/0273e14624d4a4a456769be38bd8ef58.png)倡议发出，即得到了充满爱心小伙伴们的积极参与，现场捐书一共**367本**，鹅们每捐出一本书，TEG志愿者都会为此再配一本新书，以捐赠员工的名义一起捐赠给孩子。![](../Images/bf80981985ea65dfa9614edc38323aa3.png)捐书现场热闹火爆，大家纷纷捐出适合孩子们阅读的书籍。![](../Images/f8d25f5e332007c79ebce6db3fd7d8b7.png)爱心留言，满满写下的都是对山区孩子的祝福！![](../Images/6a06b4481f5023d11f90100a650d3240.png)祝愿山区的孩子们每一天都开开心心，好好学习，天天向上！远在鹅厂的哥哥姐姐们为你们加油！![](../Images/3603f9dce3639dad43b9910a49a9afde.png)孩子们将自己心爱的书籍捐出，希望蓝天下所有的孩子都一样快乐！让我们一起听听参加捐书的孩子稚嫩而淳朴的语音：
