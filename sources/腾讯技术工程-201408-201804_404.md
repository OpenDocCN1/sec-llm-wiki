# 我和羽毛球哥哥有个约会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYwMjI2MA==&mid=212454297&idx=1&sn=01a27a4733ce333292b87ec0ceb31fd6&chksm=2f9558e218e2d1f4635021d91486b801b2dcad563f39686aa2ff3320dccfd6272f2d797f9db7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODYwMjI2MA==&mid=212454297&idx=1&sn=01a27a4733ce333292b87ec0ceb31fd6&chksm=2f9558e218e2d1f4635021d91486b801b2dcad563f39686aa2ff3320dccfd6272f2d797f9db7&scene=27#wechat_redirect)

大家好，照片里左边那个小胖妞就是我啦~

前几年我和爸爸妈妈来到深圳，现在住在南头社区。爸爸妈妈要去打工所以一直是早出晚归，连周末都很少休息。我就只能一个人在家里面，哪儿也去不了......看着别的小朋友和爸爸妈妈一起出去玩，我真的好羡慕。

有一天，几个大哥哥来到我们社区，教我们打羽毛球。听社工姐姐说，他们是来自鹅厂的志愿者。渐渐地，我开始期盼周末的到来，他们用小小的羽毛球为我开启了一次精彩的旅程。今天要和大家讲的 就是我和羽毛球哥哥的故事。

**Chapter 1. 初次见面，羽毛球哥哥好腼腆~**

![](../Images/ca2d43fceadf744110a7d8a5045252e3.png)

T恤+休闲裤+小眼镜，原来羽毛球哥哥长这个样子啊~

我和其他小伙伴叽叽喳喳问了他们好多问题，他们都很腼腆，一直微笑，但又不厌其烦地解答我们的问题，感觉好亲切的样子。

![](../Images/d356b3d08fe8134c92566e032321ec1d.png)  
开始教我们打球的姿势喽~羽毛球哥哥立马变身专业教练。

“手轻轻拖住球，右胳膊微微抬起。”

额......为什么我僵硬的像座雕塑。

![](../Images/7aadcab4024b6eb42d7bddd12565f284.png)  
其他的小伙伴也都操练起来，大家的姿势五花八门，实在是搞笑~

但是羽毛球哥哥一直很耐心教我们。

慢慢地，我觉得打羽毛球有点儿意思呢！

**Chapter 2. 满场飞舞的羽毛球~**

![](../Images/c400bbd9e5abbd816216a583300150ed.png)  
经过两堂课的学习，我们已经学会了羽毛球接发球的基本姿势。

至于姿势怎么样我就只能呵呵了。

“哥哥，你只教我们摆pose,什么时候才能打球啊？”

“不要捉急，我们先做热身运动哈~”

 

‍

![](../Images/011f39219f9686ce425c58e449f915ef.png)

先让我挥拍潇洒一回，走你！

“哎呀，羽毛球到哪里去了？”

 

![](../Images/209f80b59692fc966cccdbf26536d62e.png)

黯然销魂的身影，有没有帅到你啊？

 

![](../Images/0b677398c635d97406e285e22d4592c0.png)  
来场羽毛球的三对三比拼，你敢来战吗？

 

**Chapter 3. 我们都是调皮鬼~**

![](../Images/5bb9f4eeddac2a081f675a94b1289233.png)

和羽毛球哥哥相处久了，发现他其实并不沉默寡言，经常和我们玩闹，也会被我们这群淘气包捉弄的直摇头。

 

![](../Images/63e81efabbe5cb2b513018538e8238f0.png)

“跟着我右手左右一个慢动作，右手左手慢动作重播。”

“哥哥，你唱跑调了......"

“这首歌给你快乐，你有没有爱上我？”

我的内心是崩溃的......

 

 

**Chapter 4. 当我们灰心的时候**

![](../Images/3a1eb1c466efb40078291ff001ee6f6b.png)“社工姐姐，我发球老是过不了网，怎么样都做不好，我不想学了。”

“佳琪，不要灰心哈，再努力一下！”

![](../Images/0997ab93e1ee7558676fc659e290b780.png)  

“佳琪，比起你刚开始的时候，现在已经做的不错啦，不要着急，过来和我们一起练习吧！”

**Chapter 5. 出师喽~**

![](../Images/ed0b8e4652b28045bf0269270ffb07de.png)

![](../Images/85d7abd2f3dc1911fbdaffb016ef64a4.png)

其实我的内心正在想：对面的妹子看过来~

**~THE END~**

![](../Images/0a7bc84e9efa2f527034314cc3d2f1a3.png)

八节课上完了，但我还有很多动作不熟练，也没有打够，还想继续学。

我想问会不会开暑假班？

会不会有哥哥姐姐愿意一对一教我？

社工姐姐和志愿者阿姨说，只要有哥哥姐姐联系她们报名，我就可以继续学，好期待有人联系她们呀！
