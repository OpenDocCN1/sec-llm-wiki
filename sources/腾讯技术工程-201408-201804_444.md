# 给TEG鹅们的一封情书

**亲爱的TEG鹅们：**

白驹过隙，转眼我们已经迎来羊年。站在马年的年尾，趁着情人节这个日子，我们想用最特别的一封情书来感恩：感谢你们的支持，感谢你们陪伴TEG走过风风雨雨而又精彩纷呈的2014年。

这一年的光热路程，从彼时的不断摸索到如今的坚定前行，这一路的泥泞坎坷自不必赘述。每当挫折时，是你们用不眠的日夜和不断提升的技术，与TEG携手并进，在康庄大道上逆风前行。

这一年的光热旅程，被接纳、被信任、被托付、被依赖，我们收获了成长、荣耀、自信和责任。这份弥足珍贵的情谊包含了太多，成为鹅们一路向前的养分，赋予了TEG更崇高的意义和使命。

这一年的光热之路，在这个感恩的时刻，我们想说：“亲爱的TEG鹅们，专业合作伙伴，感谢有你。曾经的那些风雨兼程，永远镌刻在TEG的成长史上，曾经的那些共同经历的甘苦，都变成最闪耀的钻石，无比珍贵，历久弥新。”

走过马年，在即将迎来农历新年，我们的目标是为全公司提供更专业、更贴心、更全面的服务，竭尽所能，借助TEG员工的专业技术，与公司携手迈进更辉煌的明天。

亲爱的TEG鹅们，在未来的日子里，将以百万分的努力去回报你们的厚爱与支持；所以，在以后的日子里，让我们一起携手，更亲密，更贴近，更无间。 一路领先，感谢有你；感恩之余，携手同行。
