# TEG男篮击败劲旅互娱，闯进半决赛！

第十一届TBA篮球联赛小组赛于12月8日结束，TEG男篮击败号称“09黄金一代”劲旅互娱，以3胜1负的战绩挺进半决赛。

  

![](../Images/1bd05f991767a33496ad6d8c666b1754.png)

上图为TEG男篮掠影，右手边的哥们别看他站的像打酱油一样，他可是球队的主力得分手哦。

  

![](../Images/3f0ef9d4292cf04cfb619ced3c03082d.png)

本届TEG男篮加入不少了新鲜血液，更有“安平三巨头”的加盟。大伙儿信誓旦旦，誓要弥补去年决赛上与冠军擦肩而过的遗憾。

  

![](../Images/7e1edf230f601d3da2fa573b1af7b462.png)  

这场比赛如火星撞地球般异常激烈，因为这一场事实上是去年冠亚军比赛的重演！

  

![](../Images/2856a0162b2bd8c030c6afd1d092b7b0.png)

中场休息，教练重新布置战术，成了比赛的转折点，直至最终拿下比赛！

  

![](../Images/e3aab736967cc13244de00dd35e2ebef.png)

紧张的比赛中也不乏一些小清新的场景，瞧，上面这块制作精美的粉丝牌，想知道是专门为哪位帅哥加油的吗？

  

![](../Images/e8809056080fa2b19e636c816c9caa13.png)

他就是我们的主力前锋Datsdai(戴志豪)，江湖之上人称“豪哥”，豪哥不单球打得好，而且最让人羡慕的还有每次都有自己的专属啦啦队！

  

![](../Images/c3ebb2263ee327eaac4f8e8d93fc429a.png)

在对阵互娱的比赛上，豪哥最霸气的一句话是在罚球时说：“不用抢篮板，直接回防就好”，说完“嗖嗖”两声，两罚全中。这年头，有实力就是这么任性！
