**课程简介**

Python 是一种热门的编程语言，Serverless 是近年来迅速兴起的一个技术概念，基于Serverless架构能构建出多种应用场景，适用于各行各业。

本次课程将为大家详细讲解 Serverless 架构的处理规范与处理模型、典型的工作流程，以及 Serverless 工程化的难点与挑战。最后将结合 Python Flask + Serverless 的情人节表白页制作实例，展示如何用 Serverless 的方式进行 Python 编程，将热门 Python 框架利用 Serverless 快速上云。
