# 腾讯云黑石TStack一体机柜斩获2019数博会领先科技成果双重“优秀项目奖”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYwMjI2MA==&mid=2649742171&idx=2&sn=5f00108b66439cd4c303578565f8a523&chksm=bed3482089a4c13652876d124b0611d2031ad386da45028b183ec216f509f880b089def73b23&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODYwMjI2MA==&mid=2649742171&idx=2&sn=5f00108b66439cd4c303578565f8a523&chksm=bed3482089a4c13652876d124b0611d2031ad386da45028b183ec216f509f880b089def73b23&scene=27#wechat_redirect)

5月26日，2019年中国国际大数据产业博览会在贵阳召开，腾讯云黑石TStack一体机柜及其解决方案，分别获得了2019数博会领先科技成果奖中的产品“优秀项目”与解决方案“优秀项目”两项殊荣。

![](../Images/96c0e894a9df84aba27b166c50999ece.png)

  

腾讯云黑石TStack一体机柜基于一体式框架结构，内置腾讯云TStack云服务平台，软硬件一体化交付；聚焦私有云边缘场景，为中小型政企和网点状分布的组织机构提供交钥匙的解决方案，凭借敏捷部署、一站式交付和建设运维成本低廉的优势，为用户打造私有的轻量云数据中心，助力用户轻松上云。

  

在打磨一体机的过程中，腾讯云TStack始终追求设备的智能化、模块化，而不是简单地软硬件一体。

  

一体机柜内置监控模块、制冷模块、一体化PUE，在机柜内部实现专业机房环境；电源线及网络跳线等实现预安装，极大提高了交付效能；同时配备了机柜级监控模块，实现对机柜微环境参数监控，既满足数据监测，又能为远程运维提供技术支持。此外，腾讯云TStack还设计了温控色带，应急送排风，支持双路供电等功能。

![](../Images/6a9cb6810e1319723389594ad50abd2a.png)

腾讯云黑石TStack一体机柜

  

腾讯云TStack的先前案例，多以本地化部署的交付方式，为政务机构和企事业单位服务。对于中小型政企而言，本地化部署并不可行：建设数据中心要求严格，用户环境条件要求不满足；传统数据中心部署交付周期长、不稳定、上线慢；软件、硬件运维复杂，故障频发。通过一体机柜的交付方式，即可轻松化解以上难题。一体机柜无需专业机房环境，只要有一块平地即可适用；支持快速部署，一站式交付；配备腾讯三级运维体系，保障业务系统的稳定、高效运营。腾讯云TStack拓宽用户选择范围，中小型和多网点用户亦可快速构建安全稳定的云环境，助力传统产业完成数字化升级。

  

据悉，基于腾讯云黑石TStack一体机柜的政务一体机柜“星腾”，也于近日在腾讯全球数字生态大会上首次发布。

![](../Images/cf02f020963d70f7194000b0a93e5650.png)

  

腾讯云TStack致力于为用户提供完整的、模块化的、包含部署、运维服务的一体化解决方案，即腾讯云TStack私有全栈云解决方案，旨在助力政企构建稳定安全的云环境和健康的云生态。
