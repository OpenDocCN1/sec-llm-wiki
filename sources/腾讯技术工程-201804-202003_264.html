腾讯物联网开发者社区平台Tencent Things Network发布 让IoT应用开发快速安全

5月21-23日，由云南省人民政府指导，云南省文化和旅游厅、昆明市人民政府、腾讯公司共同主办，腾讯战略升级后打造的规格最高、规模最大的行业生态大会“全球数字生态大会”在昆明隆重举行。大会吸引了上百家顶级企业领袖助阵，上千家合作伙伴、近万名观众参会。


此次大会上，腾讯正式发布物联网开发者社区平台 – Tencent Things Network。

它通过全球开放的LoRaWAN网络连通物联设备和腾讯云IoT Hub、微信小程序，接入腾讯积累20年的安全防护能力，及强大的云计算、大数据和AI能力，帮助开发者快速安全地构建应用。

这是重点面向开发者提供IoT网络服务，及具有用户指南、开发教程、应用案例等丰富内容的社区门户，希望降低物联网行业应用开发门槛，同时聚拢合作伙伴的优秀物联网解决方案，助力物联网生态建设，降低物联网应用开发门槛。



面向以 LoRa 为代表的低功耗广域网络（LPWAN）物联网应用，腾讯与全球最大的 LoRa 开发者社区 The Things Network 合作，在中国推出Tencent Things Network开发者社区平台，旨在面向开发者提供开放的IoT网络服务，社区门户、以及微信小程序、IoT Explorer、IoT-Hub等服务集成能力，从而帮助开发者快速创建丰富的物联网行业应用。

The Things Network（TTN） 一直致力于搭建全球性的开放 LoRaWAN 网络，面向物联网开发者、应用工程师、设备制造商、云服务提供商和系统集成商等，提供一系列的物联网工具和服务，使开发人员能够快速上手并轻松地访问LoRaWAN网络。因为这种开放的模式，在过去的4年中，The Things Network 吸引了 7 万多名开发者，超过 7000 个 LoRaWAN 社区网关在平台上运行。

腾讯凭借在云计算领域积累的技术优势，以及强大的品牌影响力，结合 The Things Network 的开放模式及一系列简单易用的开发者工具，腾讯Things开发者社区平台将有助于加速中国物联网解决方案落地及商业化产品进程。

据介绍，腾讯 Things 开发者社区平台将面向开发者提供满足 LoRaWAN 国际标准的开放网络服务，其中节点端支持 LoRaWAN Class A、B、C，支持 LoRaWAN 1.0.x 以及 LoRaWAN 1.1 核心规范，网关端支持 UDP Packet Forwarder、Basic Station 接入协议，并且整个网络模型严格按照 LoRaWAN backend 标准来实现，为后续提供全球 LoRaWAN 运营的漫游服务提供可能。

在应用端，腾讯Things 开发者社区平台还提供微信小程序、IoT Explorer、以及 IoT Hub 等应用集成能力。腾讯云 IoT Explorer可为客户提供应用开发及场景服务能力，通过 APP 开发服务、设备告警、数据分析等服务，可提升客户在智能制造、智能家居、安防监控、智慧农业等行业应用的构建效率。

微信小程序轻便又随时可用的用户体验，腾讯云 IoT Hub 丰富的规则引擎，这些也都将帮助企业创建更具创新的应用解决方案。以下是腾讯合作伙伴基于Things开发者社区平台，快速创建的基于微信小程序的典型应用案例，其中包括室内外温度、湿度、气压、空气质量的实时监控，以及面向智能楼宇的能控、门控等应用案例。



腾讯Things开发者社区平台得到了Semtech、唯传科技、中兴克拉科技、瑞兴恒方、瑞科慧联、意法半导体、厦门四信、国民技术、成都博高信息、厦门大洋通信、光宝科技、云网通信、新华三、利尔达、美电国创等优秀合作伙伴的大力支持，接下来，腾讯还将陆续举办多场 IoT 技术峰会，邀请腾讯内部专家、社区开发者、合作伙伴进行技术、产品和方案分享，共同完善物联网产业生态。



腾讯TEG网络平台部总监 王亚晨 表示：

“连接一切是腾讯物联网的发展愿景，腾讯坚持以开放共赢的理念和广大合作伙伴一起推动中国物联网产业快速发展，我们希望通过与TTN的合作，利用腾讯Things开发者社区平台，为开发者提供一个灵活接入，敏捷开发、经验交流、案例共享的物联网开放社区，降低物联网应用的开发门槛，帮助合作伙伴快速提供物联网应用和服务。“

The Things Industries CEO，The Things Network 创始人 Wienke Giezeman 表示：

“我们很高兴与腾讯合作，将IoT开发者社区带到中国。通过建立强大的合作伙伴关系并提供便捷的开发者工具，我们可以加强LoRaWAN生态系统的建设并加速LoRaWAN的应用落地。”

Semtech副总裁兼无线及传感产品业务部，IoT副总裁Marc Pegulu表示：

“Semtech将一如既往的支持LoRa开发者生态的发展，为物联网解决方案供应商和系统集成商简化开发流程，加速上市时间。此次TTN与腾讯的强强合作将促进LPWAN生态发展，并为中国市场带来新的、令人兴奋的商业机遇。”
