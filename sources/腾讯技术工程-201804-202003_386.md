# 腾讯云助力中国信息通信研究院研发运维标准化体系建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5ODYwMjI2MA==&mid=2649740502&idx=2&sn=71a254639fc9476ed1db05a4a113e52e&chksm=bed347ad89a4cebbcc1f99fb3204b56e72a173579a75c7368a17c6b485c79c68333a61c4065e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5ODYwMjI2MA==&mid=2649740502&idx=2&sn=71a254639fc9476ed1db05a4a113e52e&chksm=bed347ad89a4cebbcc1f99fb3204b56e72a173579a75c7368a17c6b485c79c68333a61c4065e&scene=27#wechat_redirect)

![](../Images/a5f7daa9b67588196ff29e13b9d50be9.png)

  

  

  

研发运营一体化系列标准是由工信部信通院牵头，于中国通信标准化协会（CCSA）立项的系列标准。  

  

腾讯云作为受邀单位，同各行业内成员单位相互协作参加标准贡献，并组织了多位腾讯研发与运营专家一同参加标准建设。腾讯工蜂、腾讯织云、腾讯蓝鲸、腾讯WeTest、腾讯Tars、CodeCC、Tencent Hub、腾讯云安全等多个腾讯内部研发效能和运营支撑的关键产品应邀参与。

![](../Images/00f1a1b65853194868d3f44fde0bb9c9.png)

  

2018年11月2日上午，中国信息通信研究院云计算与大数据所运维工作组负责人牛晓玲于深圳发表标准的工作进展。

![](../Images/03ed6c953cb3a27709557df1fc421b9b.png)

  

中国信息通信研究院云计算与大数据研究所副所长张雪丽为参与单位授牌，腾讯云等单位出席了授牌仪式。

![](../Images/e4b15c5ed2c2c0b028a316a030ce83ad.png)

  

之后，作为AIOps白皮书核心专家，腾讯云副总裁赵建春对AIOps发展趋势做出专业解读。  

![](../Images/d528d4dbe6fbdcf772ba9afeac584d3a.png)

  

腾讯科技（深圳）有限公司获得国内首个研发运营一体化成熟度评测四级认证，图为腾讯蓝鲸负责人党受辉代表腾讯接受颁奖。

![](../Images/efd5bb94da9e0bbcc1fa714845689408.png)

  

前一天11月1日，研发运营一体化成熟度标准产品标准部分第二次专家线下会议在腾讯滨海大厦召开。

![](../Images/9f42eaed518bfe6dbbd672856367f99f.png)

  

来自信通院、腾讯云、华为云、中兴通讯、招商银行、平安银行、新华三、京东云、亚信科技、神舟泰岳、中原银行、烽火通信、优维科技、华佑科技等多家企业 DevOps 专家宾临腾讯开展标准讨论。

![](../Images/34e65fc84d56dbce973cbf7664e20e10.png)

  

据悉，云计算研发与运维一体化标准已在联合国下属国际电信联盟电信标准局ITU-T立项成功。

  

腾讯云作为国内领先的云计算厂商之一，立足于腾讯自身的优秀经验与实践，积极协助相关机构和单位，参与和投入到国家标准化建设工作中来。
