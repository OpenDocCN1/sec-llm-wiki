# 在鹅厂当程序媛是什么体验？

马上就到 3 月 8 日国际妇女节了，提前祝广大程序媛们：节日快乐，貌美如花，永远十八。  

借此良机，我们也随机采访了几位鹅厂程序媛，在她们身上发现了一些有意思的故事，一起来看看她们在鹅厂当程序员是什么体验。

  

**被删/basin****爱写文章、打篮球和撸猫的前端开发打工囡**

![](../Images/f36781b953d5fe6265489958f3ea6b89.png)

basin 是一位很有个性的程序媛，从网名就可以看出来。她 2017 年入职腾讯，前后加入过企鹅电竞、微信支付、腾讯文档等产品开发团队，目前在腾讯文档 Alloyteam 做一名前端开发工程师，主用 JavaScript/TypeScript。

#### Q：是怎么走上程序媛这一条路的？

我大学学的是光信息，毕业后进了华为，岗位是数通工程师。但内心其实一直对 Web 开发比较感兴趣，大学时上过一位 Web 物理引擎开发教授的课，他在课上演示了汽车透视结构图，当时觉得特别酷。所以，**工作半年后就离职开始自学前端开发，转行成为了一名程序媛。**

#### Q：主要工作内容是什么？

在腾讯，我做过微信支付生活缴费小程序、腾讯文档 Excel 开发、网络层设计等工作。

#### Q：做程序媛有什么好的地方？

工作方面，可能很多人认为女生做程序员不如男生，但也正因如此，当一个女程序员专业技术还不错的时候，往往会比男生更耀眼。

生活方面，我所在的部门男女比例是 10:1，女生很少，所以男同胞们对我们特别照顾，比如搬工位的时候让女生先挑座位、打篮球的时候愿意带上我。

#### Q：做程序媛有什么不好的地方？

女生在体质方面普遍不是太占优势，对于需要长时间加班甚至通宵的项目来说会比较难，为了避免赶不上团队工作进度，要更多地提升自己的工作效率才行。

![](../Images/7d1771598664e0bdaa6ac8e9d31d3f4e.png)

#### Q：平时有什么兴趣爱好？

**我喜欢写东西，坚持写了五年的技术博客，开源了一本电子书[《深入理解 Vue.js 实战》](https://godbasin.github.io/vue-ebook/)**（可以点击查看）。除了技术文，我还会在公众号写一些日常生活感悟。

写作之外，我还有三个爱好：打篮球、撸猫和画插画。经常会跟团队的汉子们一起打篮球，也算是主力得分手哈哈哈哈哈。我家里有养一只超级可爱的白橘猫，名字叫“牧羊猪”，还给他画了很多微信表情包。

#### Q：对未来的程序媛们有什么想说的？

多关注自己的内心，多做些尝试，找到真正喜欢做的事情。如果写代码是你热爱的，即使会很难，也不要轻言放弃。

  

**叶子/jingwen**

**爱工作也爱运动，脑细胞和卡路里总有一样在燃烧**

![](../Images/aede4b7b93d72ae555ee71ae1f60d62e.png)

叶子，2019 年从复旦大学毕业加入腾讯 Al 平台部，从事算法兼后端开发，主用 Python。

#### Q：是怎么走上程序媛这一条路的？

我本科是电子工程专业，研究生方向是图像与智能信号处理，成为一名程序媛应该算是顺其自然。

#### Q：主要工作内容是什么？

我目前在 AI 医疗团队，前期主要负责智能显微镜控制软件的维护和优化，目前正在支持数字病理云平台的开发工作。AI 医疗算是新兴领域，我们团队也处于创业阶段。作为团队里的一块砖，哪里需要我就往哪搬。从实习直到现在，我训过模型调过参，搞过客户端软件、Web 后端服务，还做过竞品调研写过产品设计文档。虽然干得活比较杂，但也很幸运能在组内大腿的指导下锻炼了“十八般武艺”，逐渐成长为一颗有点全局视野的螺丝钉。

#### Q：做程序媛有什么好的地方？

靠技术吃饭，踏实！

#### Q：做程序媛有什么不好的地方？

会变丑！程序员工友们的穿衣风格以舒适简约为主（一年四季文化衫）。**虽然他们能一眼看出你写的 bug，但却永远分不清你有没有换发型或者化过妆。**

在这样的环境下，你会开始逐渐放弃形象管理（真的不是懒）。日渐后移的发际线，还有日益膨胀的腰围，会很快打你消靠脸吃饭的妄想，只求再加一小时班，端稳技术的饭碗。

![](../Images/abc4bf86a242f1ee215b3d56e7694f2d.png)

#### Q：平时有什么兴趣爱好？

我喜欢爬山，周末经常约同事们一起去爬，特别是在工作发生了一些小摩擦之后（手动滑稽）。爬山不仅能锻炼身体，呼吸新鲜空气，对我而言也是很有效的解压方式。

**我还是一个戏精，剧本杀爱好者**。在学校就是戏剧社团的积极分子，现在也加入了公司的戏剧社，还有幸参加了公司BG新年晚会节目。

#### Q：对未来的程序媛们有什么想说的？

虽然身边程序媛的比例略低，但其实工作中我并没有感受到明显的性别劣势，公司里也有非常多优秀的女技术专家。如果你有志成为程序媛，我想说：腾讯大有可为！

对了，还想说句：少熬夜，脱发是不可逆的。

  

**默默**

**可能是最嫌弃自己头发多的程序员，一心走在变秃变强的路上**

![](../Images/70f204d6781d7238539c942d5cb74c39.png)

默默，毕业于加拿大 SFU 大学，2018年加入腾讯 IEG互娱业务部门，从事安全后台开发，主用 C++。

#### Q：是怎么走上程序媛这一条路的？

**我从小就对编程感兴趣，小学时在小霸王学习机上写过 BASIC**。后来四年级学校里开设了计算机课，开课第一天我当选了计算机课代表，不过是靠打字速度第一当选的哈哈哈。

#### Q：主要工作内容是什么？

刚毕业的时候做的是游戏客户端开发，对接的后台服务返回有 bug 时，就去看后台同事的代码找 bug。慢慢地，我觉得后台开发更有挑战性就转做了后台开发，主要负责维护游戏安全后台基础通信组件，为大家带来更好的游戏体验。

#### Q：做程序媛有什么好的地方？

最大的好处是，体力活随时可以找到壮丁帮忙。平时和汉子沟通也会更直接简单，不需要去揣测对方更深层的想法。**因为自己是团队里的独苗，唯一的女程序员，大家都会比较照顾。**

#### Q：做程序媛有什么不好的地方？

在职场里有过几次尴尬的境遇，比如**去面试结果被当成是 HR 哈哈哈**。内心淡定地告诉自己，放平心态，用代码和能力去证明自己。

掉头发不是我的困扰，反而是觉得自己头发太多打理起来很累。另外，对电脑久了，皮肤更爱出油。平日里属于等着公司发对象的状态，但转而一想周末的日子都是属于自己的，觉得也挺好。

![](../Images/aaa98e890f0fc2b47dd63f7dab9aa72b.png)

#### Q：平时有什么兴趣爱好？

我身体体质属于比较差的那种，加上加班也比较多，就慢慢喜欢上了健身，一周四到五练。希望可以活动起来来维持健康的状态，毕竟身体是加班的本钱啊哈哈。另外，我还有在自学画画，游戏圈里不是说不想当美术的开发不是好策划嘛。

#### Q：对未来的程序媛们有什么想说的？

不论前后端开发，遇到问题一定要深挖到底，不要停留在表面，决定差距的往往是细节。**变秃不会变强，但学习成长一定会让你更强。**

  

**彦哥**

**认真搬砖的深圳girl**

![](../Images/f675f9f9ba4d044fea9fa0ee5b2084af.png)

彦哥，其实是个靓妹。2019 年从武汉大学毕业后加入腾讯 CSIG 安全云部，成为一名自然语言处理和图像识别方向的人工智能工程师，做灵鲲监管。主用 Python 和 C++。调侃自己是兼任团队的 CFO，负责Q哥Q魅们的吃喝玩乐。

#### Q：是怎么走上程序媛这一条路的？

我是一名理工科妹纸，在学校时就喜欢逻辑性较强的学科，本科学的电子信息专业，然而家里人希望女孩子学金融，这样以后进到银行工作比较好。所以我“如愿以偿”转专业到经济学，结果发现不合胃口，又几经波折兜兜转转回归电信。**本科阶段跟着学校老师做科研项目时，初涉深度学习领域，发现自己对这块儿很感兴趣，后来硕士就研究了这个方向。**毕业之后希望把所学理论知识在工业界落地，于是毅然决然地走上了程序媛儿这条不归路。

#### Q：主要工作内容是什么？

我们主要负责研发品牌经营管家等灵鲲监管产品，利用大数据和人工智能技术来进行网络风险监测，包括违法电商广告的识别，APP 隐私合规监测，商标侵权、银行仿冒、赌博、贷款诈骗等网站的识别，比较具有社会责任感的工作哈哈哈。

#### Q：做程序媛有什么好的地方？

总体来说，其实没有什么特殊的，在团队里，大家也基本不会有这种男女性别上的区别对待，该干活干活，该加班加班。老板安排工作的时候也是根据团队每个人的潜力、特点去量才适用、人尽其才。

但是在工作中如果遇到一些难题，解决不了的 bug，周边的程序员GG 们都是很 nice 的，他们会非常耐心地帮忙定位找 bug 。**我们组里经常有四、五位GG围在工位给我指导，非常感恩与感动，可以说是工作中的幸福高光时刻了！**

#### Q：做程序媛有什么不好的地方？

工作时间相对较长，新技术发展迅速，新业务层出不穷，需要多花时间不断地学习来给自己充电，意味着需要舍弃一些自己的兴趣爱好，冷落一群八卦吐槽的小姐妹。再文艺的妹纸时间久了也会磨成汉纸！

然后化妆看心情，怎么简单、舒服怎么来，目前头发掉得还不明显（希望一直浓密）。虽然加班做业务的时候很爽（希望事情赶紧解决），但加完班想恢复体力需要一阵子。

![](../Images/b864753539b2f6794a894aeb4829a5c2.png)

#### Q：平时有什么兴趣爱好？

我有蛮多爱好的，比如摄影（“专业”探索每个城市的最佳守日落基地）、羽毛球（学校院队，与看似瘦弱的人设不太相符）、跑步、看书、DIY。

#### Q：对未来的程序媛们有什么想说的？

我觉得工作没有好坏之分，只有合适与否，“术业有专攻”，如果可以发挥自己的优势，又正好是自己的兴趣点，那再好不过。专心尽全力去做，不用太在乎别人怎么说怎么看。选择了这个行业就坚持下去，保持学习，不断给自己充电，相信一切都会水到渠成！
