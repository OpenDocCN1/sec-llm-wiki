在各行业爆发式增长的云时代，传统IT架构已无法满足企业需求。相比较于传统数据库，国产数据库技术取得了长足进步，也更适用于企业的生产环境和IT系统。

 

作为腾讯云最早的 MySQL 生态的云数据库，CDB (TencentDB for MySQL) 不仅是腾讯云上规模最大、最受欢迎的数据库产品，同时在腾讯集团内部也承担了微信红包、微信广告、QQ 空间等重量级业务的数据库访问服务。为了保证数据库服务质量，解决原生数据库内核存在的性能、功能、稳定性等方面的问题，CDB 维护了自己的 MySQL 内核分支 TXSQL，相比原生的 MySQL 分支，TXSQL 分支对主备复制、事务系统、锁系统、日志系统、优化器等模块做了大量的修改，在读写性能、强同步性能、只读性能方面全面超越了官方版本，同时提供了审计、加密、线程池、SQL 防火墙等企业级特性，并且极大缩减了内核 Bug 的修复时长，提升了线上的稳定性。

  

数据是企业最重要的资产，一旦丢失会导致企业无法运作，数据的备份和恢复至关重要。为数万用户提供服务的CDB备份系统九鼎，可以在兼顾备份效率、资源消耗和数据有效性的同时，支撑数十万节点的备份。

  

数据库性能是用户关注的重要指标之一，参数调优是提升数据库性能的重要手段。而对于云厂商来说，完全依赖数据库专家进行数据库参数调优代价昂贵且不现实。腾讯云CDB团队研发的云数据库自动性能优化系统 CDBTune，可以在缺少相关经验数据训练的情况下建立优化模型，性能调优结果首次全面超越数据库专家，[研究论文已经被国际数据库顶级会议 SIGMOD 收录](http://mp.weixin.qq.com/s?__biz=Mzg4NjA4NTAzNQ==&mid=2247485003&idx=1&sn=0a039cd9afdc567dca0963358462bfdd&chksm=cf9e428ff8e9cb99708b6355d4367b4027f1d8f8dc3810fc30292a583866626157b9a7bb6e48&scene=21#wechat_redirect)。CDBTune 主要的目标就是解决两个问题：降低学习门槛和提升调参效率。

  

为满足用户的更高要求，腾讯云CDB团队研发了云原生数据库2.0—CynosDB，在极致弹性、可用性、可靠性等方面都有很大提升，实现了OLTP数据库在存储、计算引擎核心代码的完全自研。

  

**5月30日 14:00-18:00，MySQL之父Monty、腾讯云CDB团队核心专家将在线联袂分享，围绕云原生、海量运营、自主可控和前沿探索，解密CDB/CynosDB计算引擎的核心技术，讲解云原生数据库的技术演进之路。**
