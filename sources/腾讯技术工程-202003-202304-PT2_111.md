# 5G领衔，十余名专家解析当下最火的“新基建”

当前，新一轮技术产业革命蓬勃发展，“新基建”成为社会关注热点。3月4日,中共中央政治局常务委员会召开会议, 指出要加快5G网络、数据中心等**新型基础设施建设**（简称“新基建”）进度。  
以**信息基础设施**为代表的“新基建”，不仅会降低成本、提升效率、创新商业模式，还将拉动新材料、新器件、新工艺和新技术的研发应用，促进制造业技术改造和设备更新，为新技术的发展，新产业、新模式和新业态的形成与大规模商业化提供必要支撑。  

“新基建”包括哪些范畴？它在经济发展中发挥什么作用？又面临着哪些机遇和挑战？对此，腾讯公司联合工信部通信科学技术委员会、中国航空工业集团、中国移动、中国工业互联网研究院、招商证券、太和智库、上海人工智能研究院、易观和深圳创新科（UIT）等多家单位一起，共同举办**《“新基建”如何助力实体经济》**系列沙龙。

![](../Images/46a32fee8419df04a68905ccd0715a14.png)  
本次沙龙围绕 **“5G与工业互联网”**、**“人工智能与数据中心”**、**“新能源充电桩与轨道交通”**三个议题展开，邀请十余位专家共同探讨，以专业的视角，全方位、深层次解读新基建带来的全新问题。  
沙龙将采用线上直播的形式，在腾讯新闻、腾讯云大学、腾讯云直播间、腾讯技术课多个平台进行直播。
