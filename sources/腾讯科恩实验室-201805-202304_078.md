# 腾讯安全科恩实验室二进制安全最新成果入选AAAI-20

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU1MjgwNzc4Ng==&mid=2247484178&idx=1&sn=e58f1623c5a44906356da3ddf9b6a5ba&chksm=fbfd3f17cc8ab6010637d28ffa5f9a4766885c1ad4ec97f503962765b8808d79d80440e7e7a7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU1MjgwNzc4Ng==&mid=2247484178&idx=1&sn=e58f1623c5a44906356da3ddf9b6a5ba&chksm=fbfd3f17cc8ab6010637d28ffa5f9a4766885c1ad4ec97f503962765b8808d79d80440e7e7a7&scene=27#wechat_redirect)

近日，腾讯安全科恩实验室《Order Matters: Semantic-Aware Neural Networks for Binary Code Similarity Detection》论文被人工智能顶级学术会议AAAI-20会议收录，成果聚焦利用AI算法解决传统二进制安全问题，是国内该领域被国际AI顶会收录的最新研究成果。**点击底部“阅读原文”即可查看完整论文。**

  

AAAI-20

AAAI早期由计算机科学和人工智能创始人Allen Newell， Marvin Minsky 和John McCarthy等人首创，是人工智能领域最重磅的会议之一，被中国计算机学会(CCF)推荐为A类会议。第34届会议\[1\]将于2020年2月7日-12日在美国纽约举行。

![](../Images/9a854b9aecaf096ecff5c046afd71165.png)

  

“安全+AI”最新成果

本次腾讯安全科恩实验室被会议收录的论文为《Order Matters: Semantic-Aware Neural Networks for Binary Code Similarity Detection》，核心是利用AI算法解决大规模二进制程序函数相似性分析的问题，这是二进制安全分析领域的一个经典场景。

![](../Images/44734489d9734e0bedeb83b7a7e1895a.png)

二进制安全分析是信息安全中重要研究领域之一，其中一类场景是在不访问源代码的情况下检测相似的二进制函数，也就是找到由同一份源代码所编译出的不同的二进制代码。但是同一份源代码在不同编译器，不同平台，不同优化选项的条件下所得到的二进制代码截然不同。传统算法使用图匹配算法解决此问题，但图匹配算法的速度慢，且准确率低。该论文提出了一个通用的深度学习框架学习程序控制流图(CFG)的结构信息和语义信息，生成向量化表示。我们在图节点部分引入了BERT预训练任务学习CFG图中节点的语义信息，并且在图向量表示时增加CNN模型以获取更多的结构信息。我们最终在函数相似性判定这个任务上取得了业内领先的效果，相比之前的SOTA算法准确率提升了10%。**与论文相关的技术内容解读将于近期在腾讯安全科恩实验室官方微信公众号进行披露**，敬请期待！

![](../Images/77233af88e93234cd2ce44112b5468b9.png)

  

科恩AI能力建设

自2018年起，腾讯安全科恩实验室积极布局人工智安全研究，并在"安全+AI"交叉领域结合应用场景研究探索。2019年3月，科恩实验室发表"[特斯拉Autopilot的实验性安全研究](http://mp.weixin.qq.com/s?__biz=MzU1MjgwNzc4Ng==&mid=2247483976&idx=1&sn=eec18849c0829b9600095e31ad6147fb&chksm=fbfd3e4dcc8ab75b238dde6a1682ee9e588f946af4c4af82b1e77de18488efffd4233d860fa3&scene=21#wechat_redirect)“\[2\]，即利用AI领域的对抗样本生成算法，精准误导特斯拉Autopilot的图像识别深度学习算法，成为首个实现对抗商用自动驾驶系统图像识别功能的研究案例。

  

    除了研究AI算法自身安全性上做出突破性成就，科恩更积极探索如何将AI算法应用到传统安全研究当中。2019年7月，科恩在腾讯公司高校合作项目的“CCF-腾讯犀牛鸟基金”\[3\]中发布《基于深度学习和低约束符号执行的海量二进制程序相似性分析技术》的研究课题，与香港科技大学展开深入合作。

  

结语

在人工智能技术发展如火如荼的今天，与AI结合，利用算法解决自身场景问题已成为计算机各细分领域的研究趋势。腾讯安全科恩实验室作为国际一流的信息安全团队，始终以积极的姿态拥抱人工智能，未来将不断探索“安全+AI”更多可能性，并进一步推动成果转化以解决产业痛点问题。护航各行业数字化变革，守护全网用户的信息安全是腾讯科恩实验室的使命。
