**AWVS安装**

AWVS我是装在Docker上的，在VPS中部署好Docker后，敲入以下命令

*   
*   

```
docker pull secfa/docker-awvs #拉取镜像docker run -it -d -p 8443:3443 secfa/docker-awvs #将Docker的3443端口映射到VPS的8443端口
```

访问https://VPS的IP:8443

![](../Images/0db68f23efc8df2c2bb4ddb757ca171d.png)

默认账号密码：

username: admin@admin.com

password: Admin123

登录进来是这样一个页面

![](../Images/5ebb98866a49a41536f75731c717db6a.png)

**扫描站点**

在目标中添加新的目标

![](../Images/ed0f0524469c712638f19a79cf790bd0.png)

填入扫描目的地址，保存

![](../Images/3f01e9d362afe66c740c08e764740f2e.png)

下面是我们的目标信息

*   
*   

```
业务关键性：有四个选项，低，正常，严重，高，根据业务的重要程度来选择默认扫描配置文件：全扫描，高风险，高/中风险，跨站脚本，SQL注入，弱密码，仅抓取，恶意软件扫描；根据你想着重检测哪一方面的漏洞来选择
```

![](../Images/42693b5a0175fe2ae1beb8dfe312ca5d.png)

网站登录，如果扫描网站需要测试登录表单，则填入账号密码

![](../Images/31a01ebd8d7e9f647e87666245c6f26b.png)

后面基本默认，当然有需要的话可以自行调整，点击右上角扫描

开始扫描

![](../Images/b84185648576ab188b528b12f8cb7223.png)

扫描完成

![](../Images/d6ddfa3c984d9345d4fe52d6159bdb31.png)

漏洞的严重性主要有高 中 低 信息这四个组成

![](../Images/68eb97de856946f6f0c9a7e92df3cce4.png)
