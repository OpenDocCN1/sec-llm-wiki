# 内网小技巧|cmd下获取rdp端口

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU2NzY5MzI5Ng==&mid=2247488034&idx=1&sn=b2486edcecc8d0ffdf1874d34e5ac134&chksm=fc9808bdcbef81abf08778707ee3e2daf97d5d4decff7be2d26f389fdfb4ae533f0c947ecc51&scene=126&sessionid=1681665815#rd](http://mp.weixin.qq.com/s?__biz=MzU2NzY5MzI5Ng==&mid=2247488034&idx=1&sn=b2486edcecc8d0ffdf1874d34e5ac134&chksm=fc9808bdcbef81abf08778707ee3e2daf97d5d4decff7be2d26f389fdfb4ae533f0c947ecc51&scene=126&sessionid=1681665815#rd)

Terminal下执行

> REG query HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server\\WinStations\\RDP-Tcp /v PortNumber

响应

> PortNumber REG\_DWORD 0xd3d
