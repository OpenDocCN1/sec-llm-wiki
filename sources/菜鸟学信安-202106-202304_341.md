# ipsourcebypass

此 Python 脚本可用于使用 HTTP 标头绕过 IP 源限制。

# 特点

17 个 HTTP 标头

多线程

JSON 导出与--json outputfile.json

自动检测最成功的绕过

# 用法

```

$ ./ipsourcebypass.py -hsource

 bypass using HTTP headers, v1.1test for IP source

 bypass using HTTP headershelp            show this help message and exit
help

 messagefor

 requests (e.g., http://localhost:8080)
```

自动检测最可能的结果

结果按长度排序，具有唯一响应长度的结果将在顶部，而具有相同内容长度的许多结果将在底部。
