如何使用 SSH 向本地 BURP 发送远程 VPS 请求

方法：

在连接到 VPS 的计算机上运行

```

ssh -R 8080:127.0.0.1:8080 root@VPS_IP -f -N 
```

在你的 VPS 中你可以运行

```

curl URL -x http://127.0.0.1:8080
```
