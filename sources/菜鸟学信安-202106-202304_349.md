域内信息搜集

目标：判断域环境，定位域控制器的IP地址，获取域内其他成员机器的信息

DOS命令

net time /domain 通过查询时间服务器判断是否存在域

![](../Images/f7b61477f9515a100f5ab8142276e603.png)

一般时间服务器就是域控机器，可以ping获取其IP

![](../Images/ee9d712c3578bfae935114a94a63bf4b.png)

ipconfig /all

通过DNS后缀判断是否存在域

![](../Images/22fbfa2c562f5b7051aec919b52f2e3e.png)

```

nltest /domain_trusts /all_trusts /v /server:<域控ip> //查询信任域
```

![](../Images/cb80c2a1035f78defc01cb7a81b2d45b.png)

```

nltest /dsgetdc:<域名> /server:<域控ip> //查询域详细信息
```

![](../Images/9148ad1c4ed09b8e129260b1d536f3a7.png)

```

查询域内各种资源服务器: setspn -T <域名> -Q */* | findstr <过滤字符串/可不加>
```

![](../Images/bd475f942bea8396a10df9535e3104b1.png)

net group "domain controllers" /domain //得到域控制器主机名

![](../Images/9c7273b76eacd421d25a4151e0d9daea.png)

net group "domain admins" /domain  //查询域管理用户

![](../Images/ca153c73e998d21dce9fb8372a2fbd5b.png)

net group "domain controllers" /domain  //查询域控制器

![](../Images/38231abf832a79d3c9d7bb651c50be6e.png)

net group "domain computers" /domain  /查询域机器

![](../Images/3d62f1846c818237247e72e9202da651.png)

net group /domain  //查询域里面的组

![](../Images/abbaf8a446b5ad1cf144f7ef87c1ef80.png)

net user /domain  //查询域用户列表

![](../Images/6823472d6c8cf1cdafa476fc79de956a.png)

net view   //查看当前域内机器列表

![](../Images/bb05ed5dfa37c6dc6d7747557a347532.png)

net view \\ip //查看某ip开启的共享

net view \\主机名 //查看主机的共享资源列表

只开启默认共享的情况下列表为空

![](../Images/4e8dfa7c6df3e76f412578d93417d57e.png)

net view /domain //查看内网存在多少个域

![](../Images/10a88f7fc147b541afbe46e0494c6661.png)

net view /domain:XXX //查看XXX域中的机器列表

![](../Images/9b7d015200406539f8420e27567b345d.png)

wmic useraccount get Caption,sid //获取域内所有用户sid

![](../Images/e0db2a676d47744b5042612a9a35408f.png)

csvde -setspn <域名> -f c:\\windows\\temp\\xxx.csv 导出域详细信息:(winserver 2008内置工具，安装了AD DS或者Active Directory轻型目录服务服务器角色则此功能可用) 外部工具

nbtscan.exe 192.168.10.0/24 //扫描内网存活机器，如果开启了防火墙无法被扫描到

![](../Images/da41e719f4586d7ed98bd2fcbacdedba.png)

dnsdump.exe -u <域名><用户名> -p <用户密码>  -r <域控主机名> //dump域内dns记录,导出文件名为record.scv

BLOODHOUND

https://github.com/BloodHoundAD/BloodHound/releases

BloodHound是一款域内信息收集分析工具，可以以图形化的方式将获取到的信息展示出来

以Mac的安装方式为例：其他系统可参考官方wiki

releases页面中可下载Mac的发布版本

![](../Images/46fb0e72800e4c0c0ac822981a46acfe.png)

下载neo4j数据库

https://neo4j.com/download-center/?ref=web-product-database/#community

解压后在bin目录执行启动程序

chmod +x neo4j ./neo4j start

![](../Images/ad1c615f13c71e4a751c39cc2309f612.png)

neo4j需要java11 才可运行，否则会出现Unable to find any JVMs matching version "11".

Mac同时安装JDK11和JDK8，JDK11将成为Jar Launcher默认使用的版本，导致burpsuite无法正常运行

可编辑 neo4j启动程序, 在文件头部添加下列代码来指定使用jdk11，参考这里来避免JDK11 成为Jar Launcher默认使用的java版本

JAVA\_HOME=/Library/Java/JavaVirtualMachines/jdk-11.0.5.jdk/Contents/Home JAVA=$JAVA\_HOME/bin/java 浏览器访问127.0.0.1:7474 修改默认密码（初始neo4j/neo4j）

![](../Images/01d5757ce46603747431553938bb8716.png)

修改完成后启动之前下载的BloodHound程序，输入用户名密码登录

![](../Images/a5e1da2fafc1bc07efde1394e942f022.png)

此时配置完成，下一步进行数据采集

下载数据采集器: https://github.com/BloodHoundAD/BloodHound/tree/master/Ingestors

以可执行程序版本SharpHound.exe为例

下载后复制到域内机器上执行SharpHound.exe -c all

![](../Images/53c2c6073218643b9075657b030ab3fd.png)

执行完成后会将所有信息打包成zip

![](../Images/b4a5b84f9f531a96301d30a7a9c71277.png)

SharpHound需要.net环境，这点很蛋疼，如果目标机器权限较低没有.net环境并且无法引入powershell模块，那SharpHound基本没用了

获取到数据后复制到装有BloodHound到机器上，点击upload 上传压缩包文件

![](../Images/3d62a6b5641ab01b76a3f7eeeb14e464.png)

完成后会显示上传的数据信息

![](../Images/e3bcfb9d7bc4136c63775b3b603bd60c.png)

点击queries进入查询模块

预置的查询条件有12个,分别为：

查询所有域管理员

查询到达域管的最短路径

寻找具有DCSync权限的主体

具有外部域组成员身份的用户

具有外部组成员身份的组

域信任地图

到达无约束委派系统的最短路径

到达Kerberoastable用户的最短路径

从Kerberoastable用户到域管理员的最短路径

到达自拥有主体的最短路径

从拥有的主体到域管理员的最短路径

到达高价值目标的最短路径

选择查询模块后会出现对应的拓扑图

点击拓扑图上的节点将出现节点的详细信息

![](../Images/4a7425eec7ded0f190d998e794ec1a24.png)
