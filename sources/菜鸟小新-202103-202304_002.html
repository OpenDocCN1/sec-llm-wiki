Zphisher是Shellphish的升级形式。主要源代码来自Shellphish。但是我没有完全复制它。我已经升级了它并清除了不必要的文件。Zphisher有37个网络钓鱼页面模板；包括Facebook，Twitter和Paypal等。它还具有4个端口转发工具。您可以在此处找到模板。



功能特性

  • 最新登录页面！

  • 新的Instagram自动关注页面！

  • 修正了所有错误！

  • 对初学者有用！

下载与安装

apt updateapt install git php openssh curl -ygit clone https://github.com/htr-tech/zphishercd zphisherchmod +x zphisher.shbash zphisher.sh

上面要分多个步骤完成，你衣可以使用一条命令完成全部操作，效果等同上边：

apt update && apt install git php curl openssh -y && git clone https://github.com/htr-tech/zphisher && cd zphisher && chmod +x zphisher.sh && bash zphisher.sh
