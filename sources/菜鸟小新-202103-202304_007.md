### 功能特征

*   完全无法检测到的 Win32 MSFVenom Payload (meterpreter/shell reverse tcp)
    
*   使用ngrok进行端口转发
    
*   已测试: Win7/Win10
    

### 要求

*   Metasploit/MSFVenom
    
*   mingw-w64: apt-get install mingw-w64
    

### 转发要求

*   Ngrok Authtoken (用于TCP隧道）：在以下位置注册：: https://ngrok.com/signup
    
*   您的身份验证令牌可在您的仪表板上使用： https://dashboard.ngrok.com
    
*   安装您的 auhtoken: ./ngrok authtoken <YOUR\_AUTHTOKEN>
