GetDroid

一个恶意Android APK生成器（反弹Shell），并通过Ngrok沟通。



要求（Android-SDK，APKSinger）

apt-get install android-sdk apksigner -y

安装与使用

git clone https://github.com/thelinuxchoice/getdroidcd getdroidbash getdroid.sh
