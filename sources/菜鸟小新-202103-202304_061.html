Linux上安装HACKTRONIAN

该渗透测试工具必须以ROOT身份运行


git clone https://github.com/thehackingsage/hacktronian.git
cd hacktronian
chmod +x install.sh
./install.sh

Android上安装HACKTRONIAN

Open Termux

pkg install git
pkg install python
git clone https://github.com/thehackingsage/hacktronian.git
cd hacktronian
chmod +x hacktronian.py
python2 hacktronian.py
