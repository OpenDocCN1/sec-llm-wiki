## **Linux上安装HACKTRONIAN**

该渗透测试工具必须以ROOT身份运行

  

*   
*   
*   
*   
*   
*   
*   

```
git clone https://github.com/thehackingsage/hacktronian.git
cd hacktronian
chmod +x install.sh
./install.sh
```
