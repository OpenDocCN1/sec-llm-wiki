PEpper PE文件分析

一个开源的PE文件恶意分析脚本，用于对PE执行恶意软件静态分析。PE（Portable Executable）格式，是微软环境可移植可执行文件(如exe、dll、vxd、sys和vdm等)的标准文件格式。



PEpper 安装

eva@paradise:~$ git clone https://github.com/Th3Hurrican3/PEpper/eva@paradise:~$ cd PEppereva@paradise:~$ pip3 install -r requirements.txteva@paradise:~$ python3 pepper.py ./malware_dir
