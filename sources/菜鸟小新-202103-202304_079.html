revshellgen反弹shell生成器

独立的python shell生成脚本，用于轻松生成反弹shell，并自动化无聊的东西，如URL编码命令和设置监听器等。

revshellgen安装与使用

安装

# 下载$ git clone https://github.com/t0thkr1s/revshellgen# 依赖安装$ python3 setup.py install

使用

$ ./revshellgen.py
