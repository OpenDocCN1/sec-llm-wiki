## LaZagne介绍

LaZagne是一个用于获取保存在本地计算机中帐户密码的项目。每个软件使用不同的技术（明文，API，自定义算法，数据库等）存储其密码，该工具的开发目的是为最常用的软件找到这些帐户密码。它可以在Windows和Linux主机上运行。

## LaZagne安装  

![](../Images/2c9365c69afdd73843111e761f26c07d.png)

LaZagne支持跨平台使用，不同平台的密码储存机制是不一样的：

1.  下载项目：`git clone https://github.com/AlessandroZ/LaZagne`
    
2.  安装依赖：`pip install -r requirements.txt`，选择你对应的系统版本进行使用
    
3.  如果你是Windows环境，也可以直接在Releases下载exe执行文件
