File Browser介绍

filebrowser是一个基于go的Web文件管理系统（网盘），支持在指定目录中创建文件管理功能，可用于上传，删除，预览，重命名和编辑文件。它允许创建多个用户，每个用户都可以拥有自己的目录，并且免费开源，截止发稿还在持续维护中。

File Browser安装与使用

File Browser是单个二进制文件，可以用作独立的可执行文件，是一个出色的Web服务器，默认启用HTTPS。它的安装非常简单，您可以在任何系统上使用它。

Unix

curl -fsSL https://filebrowser.xyz/get.sh | bashfilebrowser -r /path/to/your/files

Windows

iwr -useb https://filebrowser.xyz/get.ps1 | iexfilebrowser -r /path/to/your/files

完成！它会引导存储所有配置和用户数据库。之后，您可以在命令行上看到运行实例的地址。您只需要打开该URL并使用以下帐户：

  • 用户名： admin

  • 密码： admin

您必须更改密码，如果可以，还必须更改用户名以获得最佳安全性。更多功能请看wiki。
