FTPBruter FTP暴力破解

FTPBruter是一个简单的用于测试安全的FTP暴力破解工具脚本（Python），可通过预定义的安全字典对授权的特定FTP服务器进行测试。有时我们也称为弱口令安全检测。

它支持Linux、MAC、WINDOWS，基于Python3。

特点

  • 基于用户名（user.txt）密码（paswds.txt）字典进行破解

安装和使用

# 下载脚本$ git clone https://github.com/GitHackTools/FTPBruter$ cd FTPBruter
#使用$ python3 ftpbruter.py
