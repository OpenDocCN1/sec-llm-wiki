## ssh-scanner介绍

将nmap扫描器和hydra扫描器组合使用，先用nmap探测主机是否开放22端口；如开放，然后用hydra暴力破解ssh服务的密码。这里给出了top 100,1000,10000的常用密码本。

![](../Images/50d001e63e7f6a14f9f7fe56cb03f28f.png)

*   Ubuntu 18.04 64bit
    
*   sudo apt install nmap hydra
