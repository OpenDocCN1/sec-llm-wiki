userrecon-py安装与使用

安装

安装依赖 (Debian/Ubuntu):

sudo apt install python3 python3-pip

使用pip3安装

sudo -H pip3 install git+https://github.com/decoxviii/userrecon-py.gituserrecon-py --help

使用

首先运行userrecon-py --help打印可用的操作。然后，您可以执行以下测试：

userrecon-py --target decoxviii -o test_one
