ShellPhish介绍

ShellPhish是一个可定制的网络钓鱼工具，基于SocialFish。

支持以下社交平台：

  1. Instagram

  2. Facebook

  3. Twitter

  4. Snapchat

  5. Github

  6. Yahoo

  7. Protonmail

  8. Google

  9. Spotify

  10. Netflix

  11. Linkedin

  12. WordPress

  13. Origin

  14. Steam

  15. Microsoft

  16. InstaFollowers

  17. Pinterest

  18. 更多

使用Ngrok或Serveo进行端口转发

ShellPhish安装与使用

git clone https://github.com/thelinuxchoice/shellphishcd shellphishbash shellphish.sh
