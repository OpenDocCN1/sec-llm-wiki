## DarkScrape介绍

DarkScrape是一个公共资源情报工具，用于在Tor站点（暗网）中查找媒体链接。  

![](../Images/96628fa474bb1c33e7cf839825160bd1.png)

## DarkScrape测试过的系统

*   Kali Linux 2019.2
    
*   Ubuntu 18.04
    
*   Nethunter
    
*   Arc Linux
    

测试过表示可正常运行，但未测试的系统不代表不支持。

## DarkScrape安装

其实它就是一个正常的爬虫脚本

*   
*   

```
git clone https://github.com/itsmehacker/DarkScrape.gitpip3 install -r requirements.txt
```

## DarkScrape功能

*   下载媒体
    
*   从单个网址抓取
    
*   从文件中提取
    

*   Txt
    
*   Csv
    
*   Excel
