POC-T介绍

POC-T是一个脚本调用框架，用于渗透测试中采集|爬虫|爆破|批量POC等需要并发的任务。

特点

  • 支持多线程/Gevent两种并发模式

  • 极简式脚本编写，无需参考文档

  • 内置脚本扩展及常用POC函数

  • 支持第三方搜索引擎API(已完成ZoomEye/Shodan/Google/Fofa免费版)

依赖Python 2.7和pip

POC-T安装

git clone https://github.com/Xyntax/POC-Tpip install -r requirement.txtpython POC-T.py

结构

以下含@的目录表示用户可控区域，用户可根据需要增加|修改|调用其中的内容

目录说明
POC-T.py程序入口
script@脚本库
plugin@工具库
data@资源库
output默认输出位置
lib项目代码
doc文档及版权声明
thirdparty第三方库
api搜索引擎接口

使用本框架，用户只需做两件事：

  1. 编写一个函数

  2. 执行一条命令
