## POC-T介绍

POC-T是一个脚本调用框架，用于渗透测试中**采集|爬虫|爆破|批量POC**等需要并发的任务。

### 特点

*   支持多线程/Gevent两种并发模式
    
*   极简式脚本编写，无需参考文档
    
*   内置脚本扩展及常用POC函数
    
*   支持第三方搜索引擎API(已完成ZoomEye/Shodan/Google/Fofa免费版)
    

依赖Python 2.7和pip

### 结构

以下含@的目录表示用户可控区域，用户可根据需要*增加|修改|调用*其中的内容

| 目录 || 说明 |
| --- | --- |
| `POC-T.py` || 程序入口 |
| --- | --- |
| script || @脚本库 |
| plugin || @工具库 |
| data || @资源库 |
| output || 默认输出位置 |
| lib || 项目代码 |
| doc || 文档及版权声明 |
| thirdparty || 第三方库 |
| api || 搜索引擎接口 |

使用本框架，用户只需做两件事：

1.  编写一个函数
    
2.  执行一条命令
    

### 拥有内置脚本库

*   漏洞验证
    
*   爆破&扫描
    
*   爬虫&采集
