## **Crawlab介绍**

**Crawlab**是一款基于**Celery的爬虫分布式爬虫**管理平台，支持多种编程语言以及多种**爬虫框架**。

![](../Images/b8665a6dd2a7890af10f65a34421fa0d.png)

Crawlab的架构跟Celery非常相似，但是加入了包括前端、爬虫、Flower在内的额外模块，以支持爬虫管理的功能。  

![](../Images/9dc9b0f72cd92ae39ee31968163d5709.png)  

## **Crawlab安装**

*   
*   
*   
*   
*   
*   

```
# 安装后台类库pip install -r requirements.txt
# 安装前台类库cd frontendnpm install
```

更改配置文件`config.py`，配置API和数据库连接。

*   
*   

```
# 运行服务python manage.py serve
```
