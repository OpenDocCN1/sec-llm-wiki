nps是一款轻量级、高性能、功能强大的内网穿透反向代理服务器。目前支持tcp、udp流量转发，可支持任何tcp、udp上层协议（访问内网网站、本地支付接口调试、ssh访问、远程桌面，内网dns解析等等……），此外还支持内网http代理、内网socks5代理、p2p等，并带有功能强大的web管理端。

可用于

  1. 做微信公众号开发、小程序开发等----> 域名代理模式

  2. 想在外网通过ssh连接内网的机器，做云服务器到内网服务器端口的映射，----> tcp代理模式

  3. 在非内网环境下使用内网dns，或者需要通过udp访问内网机器等----> udp代理模式

  4. 在外网使用HTTP代理访问内网站点----> http代理模式

  5. 搭建一个内网穿透ss，在外网如同使用内网vpn一样访问内网资源或者设备----> socks5代理模式

  6. 直接点=>反向代理，类似frp

nps安装

由于是开源项目，你可以使用编译好的或是自己编译。

releases安装

https://github.com/ehang-io/nps/releases下载对应的系统版本即可，服务端和客户端是单独的

源码安装

# 源码go get -u github.com/cnlh/nps...
# 编译服务端/客户端go build cmd/nps/nps.gogo build cmd/npc/npc.go

nps使用

和一般的反向代理工具用法差不多，服务端先配置参数，运行监听，然后在需要反代的客户端运行对接，即可实现相关映射，具体直接看readme.md
