ImXSS是国内首套Java研发的Xss跨站脚本测试平台。ImXSS前身是XssAPP，秉承高效、快速、稳定、易用的原则。主要用于技术研究与交流。跨站脚本攻击（也称为XSS）指利用网站漏洞从用户那里恶意盗取信息。

ImXSS安装

  1. git clone https://gitee.com/liwanlei/imxss.git

  2. 请将本项目打包成War，放置Tomcat下运行

  3. 访问安装
