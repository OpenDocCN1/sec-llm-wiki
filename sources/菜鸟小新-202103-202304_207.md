## **dirmap介绍**

dirmap是一个高级web**目录扫描工具**，功能将会强于DirBuster、Dirsearch、cansina、御剑。  

![](../Images/a8d299c977d373736181c72dadc8764d.png)  

## **dirmap使用方法**

基于python3

*   
*   
*   
*   
*   
*   
*   

```
# 安装$ git clone https://github.com/H4ckForJob/dirmap.git && cd dirmap && python3 -m pip install -r requirement.txt
# 使用 单个目标$ python3 dirmap.py -iU https://site.com -lcf# 多个目标$ python3 dirmap.py -iF urls.txt -lcf
```
