Arpy是一个用python编写的arp嗅探工具，他只有短短的200多行代码，通过scapy进行arp攻击，也许在实战用的用处没有太多老牌arp工具好用，但是用来学习他工作模式是一个挺好的例子,其中一个亮点就是配合Gsource可以生成内网的dns查询记录。

### **主要功能**

*   
*   
*   

```
数据包嗅探DNS查询嗅探Gsource生成流量记录
```

### **需要模块**

*   
*   
*   
*   

```
Python 2.7GourceScapylibdnet
```
