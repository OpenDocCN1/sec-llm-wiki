**准备工作：**

首先你需要一个github账号，所有还没有的话先去注册吧！

https://github.com/

我们使用git需要先安装git工具，这里给出下载地址，下载后一路直接安装即可：

https://git-for-windows.github.io/

  

**1.进入Github首页，点击New repository新建一个项目**

![](../Images/9ee40041c0e3eb092c104eb9e8a140bb.png)

**2.填写相应信息后点击create即可**   

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
Repository name: 仓库名称
Description(可选): 仓库描述介绍
Public, Private : 仓库权限（公开共享，私有或指定合作者）
Initialize this repository with a README: 添加一个README.md
gitignore: 不需要进行版本管理的仓库类型，对应生成文件.gitignore
license: 证书类型，对应生成文件LICENSE
```

![](../Images/ad2a6e0a1df7368bd2256680772f679f.png)

**4.点击Clone or dowload会出现一个地址，copy这个地址备用。**

![](../Images/1bbcca4b6d23596bed69eec375d52331.png)

**5.接下来就到本地操作了，首先右键你的项目，如果你之前安装git成功的话，右键会出现两个新选项，分别为Git Gui Here,Git Bash Here,这里我们选择Git Bash Here，进入如下界面，Test\_Bluetooth即为我的项目名。**

![](../Images/2f9d1cead7938393ad7620712be5ca25.png)

**6.接下来输入如下代码（关键步骤），把github上面的仓库克隆到本地**

**git clone https://github.com/CKTim/BlueTooth.git（https://github.com/CKTim/BlueTooth.git替换成你之前复制的地址）**

![](../Images/491a02c202e567b8a3bf03fcfe116b2d.png)

** 7.这个步骤以后你的本地项目文件夹下面就会多出个文件夹，该文件夹名即为你github上面的项目名，如图我多出了个Test文件夹，我们把本地项目文件夹下的所有文件（除了新多出的那个文件夹不用），其余都复制到那个新多出的文件夹下。  
**

![](../Images/af76b23c6611bff68d086d15a69f0230.png)  

**8.接着继续输入命令 cd Test，进入Test文件夹**  

![](../Images/194a71fb6038646fe71cdb6b9e0100c2.png)

**9.接下来依次输入以下代码即可完成其他剩余操作：  
**

*   
*   
*   
*   
*   

```
git add .        （注：别忘记后面的.，此操作是把Test文件夹下面的文件都添加进来）
git commit  -m  "提交信息"  （注：“提交信息”里面换成你需要，如“first commit”）
git push -u origin master   （注：此操作目的是把本地仓库push到github上面，此步骤需要你输入帐号和密码）
```

**操作过程中报错解决方式：**  

**git错误1：**

fatal: unable to access 'https://github.com/xxxx/xxxx.git/': OpenSSL SSL\_read: Connection was reset, errno 10054

**解决方法：**  

*   
*   

```
#执行命令git config --global http.sslVerify "false"
```

**git错误2：**

# fatal: Authentication failed for 'https://github.com/xxx.git/'

（意思是使用密码登录这种方式已经在2021年8月13日失效了需要在 github 上生成token登录令牌替换掉密码来进行登录）

**解决方法：**

1.首先查看自己配置时设置的用户名和邮箱与github上的是否一致；

![](../Images/0e168db6decab390010dab4e808f0d88.png)

2.重新执行git config命令配置用户名和邮箱

*   
*   
*   

```
git config --global user.name "xxx"   git config --global user.email "xxx@xxx.com"  *--符号最好自己手动输入不要直接 copy
```

设置完成之后再一次去clone代码会让你输入username 和 password 这里的 password 不要真的去使用你的登陆的密码要使用刚刚你保存下来的 token 才可以不然还是报错。  

【github  token获取方式参考：https://blog.csdn.net/ltstud/article/details/75949726】
