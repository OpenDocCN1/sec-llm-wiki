# Struts2 S2-061(CVE-2020-17530)漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4OTI0MDk5MQ==&mid=2247484796&idx=1&sn=1e5c578656b8bb8401cb11698d8a1de6&chksm=cfefa98cf898209a6bb900359030fa1570880737974c6abf478e8b2d5ba197837afdc43a57b7&scene=126&sessionid=1681665627#rd](http://mp.weixin.qq.com/s?__biz=Mzg4OTI0MDk5MQ==&mid=2247484796&idx=1&sn=1e5c578656b8bb8401cb11698d8a1de6&chksm=cfefa98cf898209a6bb900359030fa1570880737974c6abf478e8b2d5ba197837afdc43a57b7&scene=126&sessionid=1681665627#rd)

**漏洞描述**

Struts2 会对某些标签属性(比如 \`id\`，其他属性有待寻找) 的属性值进行二次表达式解析，因此当这些标签属性中使用了 \`%{x}\` 且 \`x\` 的值用户可控时，用户再传入一个 \`%{payload}\` 即可造成OGNL表达式执行。S2-061是对S2-059沙盒进行的绕过。

**0x02 漏洞影响**

struts 2.0.0 - struts 2.5.25
