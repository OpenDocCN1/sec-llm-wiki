### **1.8u121的JAVA JDK下载地址：**

### 解压缩文件并移动至/opt

  

*   
*   
*   

```
tar -xzvf jdk-8u91-linux-x64.tar.gzmv jdk1.8.0_91 /optcd /opt/jdk1.8.0_91
```

  

### **设置环境变量**

执行 gedit ~/.bashrc ， 并添加下列内容  

*   
*   
*   
*   
*   
*   

```
# install JAVA JDKexport JAVA_HOME=/opt/jdk1.8.0_91export CLASSPATH=.:${JAVA_HOME}/libexport PATH=${JAVA_HOME}/bin:$PATH保存退出执行 source ~/.bashrc
```

### **安装并注册**

执行：

  

*   
*   
*   
*   

```
update-alternatives --install /usr/bin/java java /opt/jdk1.8.0_91/bin/java 1update-alternatives --install /usr/bin/javac javac /opt/jdk1.8.0_91/bin/javac 1update-alternatives --set java /opt/jdk1.8.0_91/bin/javaupdate-alternatives --set javac /opt/jdk1.8.0_91/bin/javac
```

  

查看结果：

  

*   
*   

```
update-alternatives --config javaupdate-alternatives --config javac
```
