AppScan，即 AppScanstandard edition。其安装在 Windows 操作系统上，可以对网站等 Web 应用进行自动化的应用安全扫描和测试。

Rational AppScan（简称 AppScan）其实是一个产品家族，包括众多的应用安全扫描产品，从开发阶段的源代码扫描的AppScansource edition，到针对 Web 应用进行快速扫描的 AppScan standard edition，以及进行安全管理和汇总整合的 AppScan enterprise Edition 等。

**【安装】**

1.安装时会自动检测是否有.NET framework 4.6.2配置,直接安装即可。

![](../Images/84c1951677ac559304827d2008398299.png)

2.同意---安装；  

![](../Images/05f3c543ff593feb8fb8b177e16e8f94.png)

**【使用】**  

3.安装成功后创建扫描任务：文件--新建扫描  

![](../Images/e494f8d846f172b90a0aee6c32a6eb9e.png)

4.一般选择常规扫描；

![](../Images/693a6e23f2b873e47c2d28ab206f48ff.png)

5.进入扫描配置导向后，默认选择Appscan（自动或手动）

![](../Images/22b8c8df4ff30759e602cd896cad35b5.png)

6.在起始url中输入目标url地址，会自动检测是否连接成功，然后默认选择区分大小写处理，点击下一步；  

![](../Images/a425e28517cffb36ea057040b65827bc.png)

7.进入下一步选择登入方式，这里选择‘无’，可根据具体环境具体选择；下一步  

![](../Images/1dda4275774a502766688ca56f380010.png)

8.选择“测试策略”，这里默认全扫，可根据具体环境具体选择，每种策略右侧都会有对应解释；点击下一步

![](../Images/cfb8d37ca14383a306bdfabb4b2c5ca3.png)

9.特注意：此软件要在授权的情况下使用！此软件要在授权的情况下使用！此软件要在授权的情况下使用！

![](../Images/420adf777b675a551042e2f7266c19ce.png)

10.弹窗，这里选“是”即可。

![](../Images/d217d778c1d7b77a9ccdd303bf84cd75.png)

11.开始进行扫描工作，等待扫描结果，可在右上角选择“问题”功能，查看扫描出的具体问题；

![](../Images/59d84157a5f620ceadb22f6df130a8e0.png)

12.扫描完后，可点击“报告”生成报告文档；

![](../Images/dc59bbb28b1f3fd085b0518855e51481.png)
