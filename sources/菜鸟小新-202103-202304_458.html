SSH服务是目前较可靠，专为远程登录服务器和其他网络服务提供安全性的协议，它默认使用22号端口。

SSH对我们主要的作用是：能够操作远程服务器系统。

配置流程：

1.使用编辑器打开ssh配置

dvim（或者使用leafpa命令） /etc/ssh/sshd_config

2.找到下面的参数并修改

#PasswordAuthentication yes  (去掉注释)#PermitRootLogin prohibit-password (去掉注释后面的并删除改为yes)     


3.使用命令行模式开启SSH服务

  service ssh start

4.查看服务开启状态

 service ssh  status

5.如果想设置开机自动启动，可以执行以下命令：

开机自动启动SSH服务：

update-rc.d ssh enable

关闭开机自动启动SSH服务：

update-rc.d ssh disabled

重启

sudo reboot
