# 当甲方听你汇报“进入Gartner象限”时........

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NDg5Nzk5MQ==&mid=2247484096&idx=1&sn=3406de1102aa0a952ea407c11c2ed45c&chksm=e9578368de200a7e327a8ae6d0f3103bd938f74b19dd3060fbe91c3c9e5e128a50ceb97e024e&scene=126&sessionid=1681660885#rd](http://mp.weixin.qq.com/s?__biz=MzI0NDg5Nzk5MQ==&mid=2247484096&idx=1&sn=3406de1102aa0a952ea407c11c2ed45c&chksm=e9578368de200a7e327a8ae6d0f3103bd938f74b19dd3060fbe91c3c9e5e128a50ceb97e024e&scene=126&sessionid=1681660885#rd)

作为销售或售前的实力欧巴/飒爽小姐姐，无论是去甲方拜访，还是邀请甲方到公司参观，都避免不了讲PPT，汇报公司的亮点、核心技术亮点、产品亮点、服务能力等。而作为信息安全公司，尤其是已经几百人到几千人规模的安全公司，大家的汇报PPT里，都会有那么张PPT，我司进入Gartner象限XX领域.....

![](../Images/c02c94974ab1ba79d6b46a5378f5ef78.png)

这张PPT一般有以下几种操作

*   把自家公司用红色圈圈标记  
    
*   把国内友商打码
    
*   解释所在四象限种的领域有多牛
    
*   说明国内就咱一家进入或率先进入
    

  

是的，当销售或售前讲完这张PPT时，他/她不露痕迹的微微环视了下，在坐甲方的领导和技术骨干，期待他们颔首露出些许肯定，那么有个眼神想延申了解下的意愿.......  

  

很不好意思，在大多数情况下，当甲方听你汇报“进入Gartner象限”后，看手机的依然在看手机，面无表情的依然没有波澜，当然，如果你马上说：我们公司掌握几个思科的0DAY漏洞，再看看现场效果......

  

是Gartner象限不香吗？才不是呢，看以下大厂，也会将Gartner象限放在首页。

![](../Images/a428d0f1f2c3604105074fd072eb1235.png)

![](../Images/51c42538d2466264aa079844493c27f9.png)

  

是什么原因让Gartner看上去很美，但甲方觉得不香呢？  

1、对Gartner不了解  

首先不少领导和专家对Gartner只是耳闻，并不是很熟

就算作为乙方的销售或售前，你能麻利的三句话概括出Gartner背景和价值吗

2、不了解就没有代入感

甲方在听汇报的时候，也会脑补汇报人言语和PPT间的画面  

一个黑白的魔力象限，甲方委实难想象出这个魔力象限能让我的安全变魔法

3、中国大多数厂商不是leader  

在分类的各个象限中，中国的安全厂商，很难做到leader象限中的Leader  

所以人们有种潜意思的认为你就是入围了而已（实际上入围也很难）
