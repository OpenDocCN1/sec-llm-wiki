# 0x00 前言

Kali Linux不用多说，知道的人都知道，国外的一个渗透测试系统，集成了很多的渗透工具，最近跟新了2019.4但是很多小伙伴安装后显示有中文乱码问题，这里教大家如何解决。

# 0x01 更换Kali 清华大学源

使用vim编辑器修改：vim /etc/apt/sources.list添加Kali 清华大学源使用mousepad编辑器修改：mousepad /etc/apt/sources.list添Kali 清华大学源

#清华大学 \[更新源\]

编辑结束保存文件，终端中输入下面的命令

> apt-get clean && apt-get update -y

![](../Images/db9da27579e4c8a641efa595c2d4e73c.png)

# 0x02 安装字体

在终端中输入下面的命令，安装开源的文泉驿微米黑和文泉驿正黑字体

> sudo apt-get install ttf-wqy-microhei ttf-wqy-zenhei xfonts-intl-chinese

![](../Images/7de59e440da56adf870b0b94ae71557f.png)

# 0x03 更改默认编码

在终端中输入`dpkg-reconfigure locales`

进入图形化界面之后，选中`1en_US.UTF-8 UTF-81`和`zh_CN.UTF-8 UTF-8`，空格是选择，`Tab`是切换，`*`是选中）

![](../Images/8712f9b5bed195fb96d25cfc46a337d6.png)

![](../Images/840c3e177584dfe214ba53a397e1d5b9.png)

确定后，将zh\_CN.UTF-8 UTF-8选为默认。

![](../Images/6fce764f3d49fa8a3022b159ed76fb46.png)

> dpkg-reconfigure locales

![](../Images/0ea5f9dde0a779e7319388bcbd964635.png)

# 0x04 重启

输入`reboot`命令，重启kali后，一切显示正常。

![](../Images/d028c1993deff6f425af0bd2c59aa9d6.png)
