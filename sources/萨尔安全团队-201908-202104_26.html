iStatistica Pro 1.1.1 PJB 实时显示Mac电脑CPU、内存、硬盘、网速、电量信息 已通过小编安装运行测试 100%可以使用。

iStatistica Pro 1.1.1 PJB 是一款Mac上优秀的系统监控工具，可以实时显示系统的状态，包括CPU、磁盘使用、内存使用，网速、电池等信息，支持菜单栏显示和通知中心工具。

iStatistica Pro提供Web访问，以通过局域网跟踪CPU，内存，磁盘和传感器的统计信息。只需在应用程序设置中启用Web访问，然后将浏览器指向Mac的地址即可。

专业版包括用于文件夹和驱动器可视化的专有模块，详细的应用程序监视以及更侧重于企业级安全性的远程访问。

功能列表：

●系统监控

-正常运行时间

-内存（已使用，免费，缓存，系统，每个应用）

-CPU使用率（每个内核，每个应用程序总计）

- 磁盘使用情况

-弹出外部驱动器

-电池信息（周期，健康状况，容量）

-网络活动

●存储可视化

-轻松查找和删除不需要的文件

●网络接口仪表板

●详细的应用统计信息

-CPU和内存使用的历史记录

●独特的菜单栏监视器

- 内存

- 中央处理器

- 磁盘

- 网络

●Web访问和API

-网络仪表板

-通过ip和密码限制访问

-带有JSON输出的REST API

●插件支持风扇，传感器和磁盘I / O监控
