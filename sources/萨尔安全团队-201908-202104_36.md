x00 前言

移动安全框架（MobSF）是一种自动化的一体化移动应用程序（Android /iOS /Windows）笔测试框架，能够执行静态，动态和恶意软件分析。它可用于Android，iOS和Windows移动应用程序的有效和快速安全分析，并支持二进制文件（APK，IPA和APPX）和压缩源代码。MobSF可以在运行时为Android应用程序进行动态应用程序测试，并具有由CapFuzz（一种特定于Web API的安全扫描程序）提供支持的Web API模糊测试功能。MobSF旨在使您的CI / CD或DevSecOps管道集成无缝。

# 0x01 开始安装

> 安装环境：
> 
> Kali Linux x64
> 
> Docker
> 
> Python3.6环境

| #使用python3环境 update-alternatives --config python |
| --- |

选择python3前面的编号

  

![](../Images/0fa3a5bfddfacfbaa97b35f228542dfb.png)

  

  

| #卸载docker，如何之前安装的话 apt-get purge docker.io |
| --- |

下载docker安装包

| wget https://download.docker.com/linux/debian/dists/jessie/pool/stable/amd64/docker-ce\_17.06.2~ce-0~debian\_amd64.deb |
| --- |

  

![](../Images/df96c65776f2ab1f5f00693e9be442f6.png)

  

  

安装docker

| dpkg -i docker-ce\_17.06.2~ce-0~debian\_amd64.deb |
| --- |

  

![](../Images/1faa4b36dd8a733318e4ad049bd76852.png)

  

  

启动docker服务

| service docker restart |
| --- |

docker一键部署framework-mobsf

| docker pull opensecurity/mobile-security-framework-mobsf |
| --- |

  

![](../Images/d09beb9d62ba0aa865a52a9b4391d4d4.png)

  

  

# 0x02 开始使用

| docker run -it -p 8000:8000 opensecurity/mobile-security-framework-mobsf:latest |
| --- |

然后在kali中使用获取浏览器访问：htpp://0.0.0.0:8000

  

![](../Images/2ad4efa407d824c9051ebc31d481d54d.png)

  

  

或者使用ifconfig命令查看kali的ip地址，然后使用http://kali的ip地址:8000访问
