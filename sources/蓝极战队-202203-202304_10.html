《简单的亦或》


要复刻一道题目，首先肯定要先把他解出来。

OK，那就先来一步步做一下这个题目！


分析一下PE，是c++编译的一个32位console程序

老规矩运行一下，又是老生常谈的东西，输入正确的flag验证


直接拖到32位IDA里面分析一下，在main函数伪代码里面看到了strcpy加密字符串赋值给v12，v13接收我们的输入，判断v13长度=38则开始运算我们输入的字符串，最后strcmp对比运算后的字符串和V12是否一模一样，也就是函数执行结果=0，如果一样，证明flag验证通过！


那么最重要的就是看他怎么运算我们输入的flag最后要等于"v}qvk\"&)(SQW!!(P$S$#SS$#U'&TQT!!) URRl"

一目了然，用了个do-while循环，很简单的一个奇数偶数的亦或，也就是奇数亦或0x10，偶数亦或0x11


直接C语言写一个小程序把flag解出来即可！当然你用python等等解释型语言更加快捷方便

例如:

str="v}qvk\"&)(SQW!!(P$S$#SS$#U'&TQT!!) URRl"r=""i=0for s in str:    if(1&i)!=0:        r+=chr(ord(s)^0x11)    else:        r+=chr(ord(s)^0x10)        i+=1print(r)


为了方便复刻，我们还是用C语言来编写解出flag

#include<stdio.h>int main(){  char stds[39]={"v}qvk\"&)(SQW!!(P$S$#SS$#U'&TQT!!) URRl"};  int i;  int j = strlen(stds);  for(i=1;i<j+1;i++){    if(i%2==0){      stds[i-1]=stds[i-1]^0x11;    }else{      stds[i-1]=stds[i-1]^0x10;    }  }  printf(stds);}

编译运行得到最终的flag

flag{3688BAF108A4B42CB42E66EAE1091ECB}

复刻我还是使用c语言，编译之后反编译出来也可以看看不同之处


代码如下：

#include<stdio.h>//flag{3688BAF108A4B42CB42E66EAE1091ECB}int main(){  char stdscan[39];  char stds[39]={"v}qvk\"&)(SQW!!(P$S$#SS$#U'&TQT!!) URRl"};  printf("请输入要验证的flag:");  scanf("%s",&stdscan);  int j=strlen(stds);  int i;  for(i=1;i<j+1;i++){    if(i%2==0){      stdscan[i-1]=stdscan[i-1]^0x11;    }else{      stdscan[i-1]=stdscan[i-1]^0x10;    }  }
  if(strcmp(stdscan,stds)==0){    printf("恭喜，flag验证正确！");  }else{    printf("flag验证错误！");  }
}


简单梳理一下代码的逻辑

1、定义一个stdscan长度39的char变量接收输入数据，定义stds长度39的char加密后的字符串（说明一下，我懒得再去截图改代码了，为什么明明38个字节的长度，要定义39呢？输入接收的变量可以定义是38，但是我们定义的比对字符串是39的长度，因为里面有一个双引号，我们需要用到转义符\，所以是39个字节长度）

2、接收输入的flag

3、直接for循环，循环次数是输入字符串的长度，这里我没有像原题还做了一个输入字符串长度的判断，如果你想做可以加一个 if(strlen(stdscan)==38){继续运算对比}。然后取余如果=0则是偶数就亦或0x11，否则就是奇数，则亦或0x10。

4、最终比对stdscan和stds是否一模一样，如果是则证明flag验证成功，反之失败！
