【课程名称】从零开始打造NodeJS博客



【课程简介】


使用 NodeJS、mongoDB、Express 开发多人博客系统，从零开始学习并掌握 NodeJS 生态圈的快速开发；每一个模块都依赖最新版本 API，带领你少走弯路，享受编码的快乐。


项目使用bootstrap 前端框架快速搭建样式优(bu)美(chou)的响应式页面；用nodeJS 搭建后台，使用最受欢迎的 web 框架 Express 快速搭建。


【开发步骤】


1.博客平台功能模块分析与设计

2.搭建开发环境

3.基于 nodeJS 和 Express 框架搭建路由模块

4.前端模板引擎

5.设计页面

6.使用 mongoDB 数据库

7.创建 session

8.扩展功能


【技术简介】


◆1、NodeJS


nodeJS 是基于 Chrome JavaScript 运行时建立的平台，用于方便地搭建响应速度快、易于扩展的网络应用。nodeJS 使用事件驱动，非阻塞 I/O 模型而得以轻量和高效。


◆2、Express


再来介绍一下深受 nodeJS 开发者欢迎的 web 开发框架 Express 。


Express 是一个基于 nodeJS 平台的极简、灵活的 web 应用开发框架，这好比如是 Flask 和 Python 的搭配一样。Express 拥有丰富的 HTTP 快捷方法和任意排列组合的 Connect 中间件，方便快速、简单地创建健壮、友好的 API


◆3、MongoDB


mongoDB 是一个基于分布式文件存储的非关系型数据库（NoSQL）的一种。它支持的数据结构非常松散，类似 json 的 bjson 格式。


mongoDB 没有关系型数据库中行和表的概念，但有类似文档 （document）和集合（collection）的概念。文档是 mongoDB 最基本的单位，集合是许多文档的总和，一个数据库可以有多个集合，一个集合可以有多个文档。


◆4、模板引擎


模板引擎是一个将页面模板和数据数据结合起来生成 HTML 页面的工具。通过模板引擎，我们可以在 HTML 文件中直接使用后台传递过来的数据，而不必再使用通过解析 json 数据，在拼接成字符串的形式渲染数据，大大提高了开发效率。
