# 程序员如何保持冷静地工作

作为一名从事IT工作的程序员，毫无疑问，你的烦恼和压力会成倍增加。这篇文章讨论了程序员如何保持冷静地工作的一些技巧。

  

## **深呼吸**

  

当我们在工作时不能平静下来的话，首先要做的事就是停下当前的工作，然后深深吸一口气。这会使我停下手上的工作，而将注意力集中到正在做的深呼吸上来。

  

深呼吸总能让我感觉更好，特别是当我对某事感到烦恼的时候。

  

所以，下次你感到压力很大、烦恼、或工作中烦人的事的时候，试试：

> *   停止做你正在做的事；
>     
> *   深深吸一口气；
>     
> *   全部呼出去；
>     
> *   继续做你正在做的事。
>     

  

整个过程可能只要大约10秒钟，但是，它可以让你变得沉静、更专注你正做的事情。

![](../Images/d6012ed37f02da3e4ad4abd3f898cbff.png)

  

## **保持大局观**

  

关于冷静地工作，另一个建议是你为什么要在那的工作的大局观。

  

如果你对某人感到很烦人，或是对他在对项目的功能设计上想法不一致，这时，你可以更多地为为大局考虑。

  

你们的总计划是什么？你们的共同目标是什么？

  

如果你对某事该怎样完成有不同的想法，这样你肯定对正在做的事情不认同，那就想想你们为什么要一起在项目组。

  

你是否尝试增加为客户新功能？是否想提高系统内部性能？或是从头开始开发一个新系统？

  

如果你能从更高角度去看待你们尝试做的事情，或是从别人的角度来审视，这样有助于你冷静地工作。

  

## **离开办公桌**

  

离开办公桌是我的另一个建议。

  

你可以试着去外面散下步。走出办公室呼吸点新鲜空气，到楼下公园、咖啡厅走走…到外面吸收点新鲜空气。

  

运动、新鲜空气、停下工作，都有助于你保持冷静地工作。更多的正能量。

  

如果因为什么原因，你无法去外面，比如下大雨，那么你可以到茶水间或其它地方走走。

  

你可以去喝杯咖啡、水或其它什么，这有助于你工作起来感觉更好，也能是你离开办公桌。

  

任何情况下，当你回到刚才的工作时，你应该会感到更冷静了。

  

## **找朋友发泄**

  

我们可以深呼吸、到我们想去的地方走走，但是有时候，这还是不够的。

  

我的意思是在大多数情况下，这些对我都有效，但是在过去几年里确实有几次我感到真的非常烦恼。

  

如果你也是一样，那么找个朋友倾诉下心情，吐槽吐槽。

  

你可以根据不同问题，去找你的伴侣、工作外的朋友、或家人，甚至项目组成员。

  

有时候，把它从你肩上释放会非常有帮助的，选择一个合适的方式找一个TA聊聊吧。

  

有一点，我不是非常建议，但是当你真的无法专注工作的时候，干脆去玩下游戏也是会有帮助的。
