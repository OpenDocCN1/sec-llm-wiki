Linux有很多有趣的命令，本文就总结了6个命令，可以试试，蛮好玩的~


sl 命令

你会看到一辆火车从屏幕右边开往左边……


安装

$ sudo apt-get install sl


运行

$ sl



cmatrix 命令


这个很酷！《黑客帝国》那种矩阵风格的动画效果。


安装

$ sudo apt-get install cmatrix


运行

$cmatrix


要关闭效果，按ctrl+c 结束。



oneko 命令


桌面上出现一只喵星人，跟着你的鼠标跑，你不动了它就睡觉。哈哈，这个挺不错!


安装

$sudo apt-get install oneko


运行

$oneko


要关掉这家伙，按ctrl+c 结束。



factor


分解因数，这个……可以帮家里的小学生解题


运行：

$factor60



aafire


在你的终端放一把火如何。


安装

$sudo apt-get install libaa-bin


运行

$aafire



rev


一行接一行地颠倒所输入的字符串。


运行：

$rev


如输入：shiyanlou

shiyanlou
