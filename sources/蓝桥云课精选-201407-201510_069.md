> **Linux有很多有趣的命令，本文就总结了6个命令，可以试试，蛮好玩的~**  

  

**sl 命令**

你会看到一辆火车从屏幕右边开往左边……

  

**安装**

> ```
> $ sudo apt-get install sl
> ```

  

**运行**

> ```
> $ sl
> ```

![](../Images/3ef07f586c55bbd57c952b2b20fd41cf.png)  

  

**cmatrix 命令**

  

这个很酷！《黑客帝国》那种矩阵风格的动画效果。

  

**安装**

> ```
> $ sudo apt-get install cmatrix
> ```

  

**运行**

> ```
> $cmatrix
> ```

  

要关闭效果，按ctrl+c 结束。

![](../Images/024eebfc45d5c4190657e0845a409bbd.png)  

  

**oneko 命令**

  

桌面上出现一只喵星人，跟着你的鼠标跑，你不动了它就睡觉。哈哈，这个挺不错!

  

**安装**

> ```
> $sudo apt-get install oneko
> ```

  

**运行**

> ```
> $oneko
> ```

  

要关掉这家伙，按ctrl+c 结束。

![](../Images/f26d54a960ff56396070c9e3c7262cd5.png)  

  

**factor**

  

分解因数，这个……可以帮家里的小学生解题

  

**运行：**

> ```
> $factor60
> ```

![](../Images/ac5a206280d51fe71cae1b8ef502c528.png)  

  

**aafire**

  

在你的终端放一把火如何。

  

**安装**

> ```
> $sudo apt-get install libaa-bin
> ```

  

**运行**

> ```
> $aafire
> ```

![](../Images/9827162d1856c7d3f6bd35798b8a735b.png)  

  

**rev**

  

一行接一行地颠倒所输入的字符串。

  

**运行：**

> ```
> $rev
> ```

  

**如输入：shiyanlou**

> ```
> shiyanlou
> ```
