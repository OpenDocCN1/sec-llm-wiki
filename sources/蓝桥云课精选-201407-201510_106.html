Linux新手必读：关于Linux的10个最常见问题

Linux 作为免费操作系统，与 Windows、OS x 齐名。比起后两者，Linux 显得很低调，低调得不少人都以为自己从未接触过 Linux。


而事实上，在手机应用方面你最常听到的“Android”系统就是由 Linux 提供技术支持的。Linux 的代码通用性非常好，几乎能满足任何用户的需求。


如果，你想尝试除了 Mac 和 Windows 以外的桌面系统， Linux 无疑应该成为你的首选。它不仅是免费的，而且是可定制的。类似于智能手机的 Android 系统，你也可以在 Linux 上定制你想要的东西。在你接触 Liunx 系统之前，你应当了解一些关于 Linux 的基本东西。


在这里，我们为你整理出了关于 Linux 操作系统的 10 个最常见问题。


1.什么是 Linux？


当有人问这个问题的时候，他所问及的 Linux 通常与另外一个名词附带在一起，比如 Fedora Linux，Ubuntu Linux，Android 的 Linux 技术支持等等，这样的例子不胜枚举。


那么，什么是 Linux 呢？“Linux”指的是 Linux 内核，是应用软件和计算机硬件之间的接口程序。前面说到的各种关于 Linux 的名词都有一个共同点，它们使用相同的内核作为硬件和软件之间的接口。因此，在计算机中“运行 Linux”的意思就是以 Linux 作为内核运行操作系统。



你可能碰到某些人坚持认为 Linux 应该被叫做 GNU / Linux。这指的是对于大部分的 Linux 操作系统，会使用很大一部分来自于 GNU 项目的代码，如果没有这些代码，Linux 内核自身便无法运行。因此，GNU / Linux 是对其结构的应有叫法。


为了简单起见，我们将所有使用 Linux 内核的操作系统称之为 Linux。


2. 为什么 Linux 会免费？


大多数人都知道 Linux 是免费的操作系统，这里的免费指代的是不花钱。是的，不仅如此，这个免费还包含了言论的自由，这意味着 Linux 的源代码可供大家观察、研究和修改，甚至可以复制你喜欢的代码进行分享。


对比 Windows 和 mac OS X，这两者现在还处于非开源的状态，这意味着你无法系统的学习它们并进行自由分配。Linux 的这种开放性的一个最主要原因是关于 Linux 操作系统的衍生早已取得了成功，早期的开源使许多个人和企业都建立了自己的衍生版本的 Linux。


3. 什么是 Linux 发行版？


发行版（distro）指的是 Linux 操作系统的一种配置方式，集团或公司通过解压它来构建 Linux。


目前比较流行的 Linux 发行版包括 Ubuntu，Fedora，OpenSUSE 等。虽然它们都使用 Linux 内核，但是它们所包含的软件配置是不同的。从默认的软件到用户界面以及经历来说，没有两个发行版是一样的。


每个发行版都能带来不同的东西，为特定的用户提供了特定的功能集。然而，对于一个初学者来说，最需要的是能够提供简单用户体验的发行版。在这里，我推荐 Ubuntu Linux 发行版，因为它的设置和使用相对容易，并且提供多种支持。


4. 我的硬件支持 Linux 吗？


在过去，硬件对 Linux 的支持是参差不齐的，很多组件和外围设备都无法正常工作。幸运的是，以前的大多数 Linux 发行版运行在现代的硬件上基本不会出问题，所以你不必太担心这个问题。


我说的“基本不会出问题”是因为你在运行它的时候仍有很小几率碰到个别的问题。虽然 Linux 社区做出了大量的工作来确保能让你当前的硬件运行 Linux 操作系统，但你仍有可能遇到意外。这个时候，你必须使用故障排除指南或者更换一个 Linux 专用的驱动程序硬件。


5. 在安装 Linux 以前我可以试用它吗？


大多数 Linux 发行版的伟大之处就是，你可以在安装它以前试用它。Linux 供应商为您提供一种简单的方法——Live CD 来试用操作系统。下载一个 ISO（光盘镜像文件），通过虚拟光驱运行，在那里你可以在安装发行版之前试用它。


如果你决定不安装 Linux，而是把它作为一个备用系统。（多准备一个系统，有备无患）你可以创建一个 Live USB。就象 Live CD 一样，Live USB 是一个可引导的 USB 驱动，可以在大多数计算机引导运行 Linux。这样你就可以在没有安装操作系统的经验时安装 Linux 了。


6. 什么是桌面环境？


当你看着所有不同的发行版时，正如你可能注意到的那样，并不是所有的 Linux 操作系统都有相同的外观。这是因为它们使用不同的桌面环境，比如，GNOME， KDE，Unity 等。这就如同 Windows 7 中的 Aero 和 OS X 中的 Aqua。桌面环境管理着操作系统的整体感官，感觉及使用方式，不同的桌面环境有着不同的特性和行动方式。


目前最受欢迎的桌面环境，在大多数发行版都附带的桌面环境主要有 GNOME 和 KDE。对于 Linux 内的所有东西，如果你不喜欢它，都可以进行自由改变。如果你选择的发行版预安装环境不适合你的口味，你也可以自由安装自己所选的风格。


7. 我可以在 Linux 上运行 Windows / Mac 的应用程序吗？


目前在 Linux 上无法运行 Mac 的应用程序，但有一种方法可以运行 Windows 上的一些应用程序。你可以使用一种被称之为 Wine 的程序，它能够让你的一些 Windows 的应用程序以原本或者接近原本的速度运行在 Linux 上。不过，不是所有的程序都能够运行，而且就算让它们运行，你也可能会遇到一些不兼容比如图形或功能故障，而导致无法工作。


Wine 可以免费下载和安装，但是对于初学者来说较难使用。在这种情况下，使用第三方的工具可以让 Wine 使用起来更加简单，并且它的预配置可以让在 Windows 运行的软件更光滑的运行在 Linux 上，CrossOver Linux 就是一个典型的例子。


8. 我如何获取 Linux 上的应用程序？


现在你已经有了一个新安装好的 Linux 操作系统，自然你会想看看它上面的应用程序会是什么样子。在 Linux 上安装应用程序与在 Windows 或 Mac 上会有不同的体验。与这两者不同的是，在 Windows 或 Mac 上你的应用程序应当是 EXE 或 DMG 结尾的文件，而在 Linux 上你必须使用发行版的存储库来搜寻你要找的东西。


大多数发行版通过 GUI 导航使搜寻查找变得容易，而 Ubuntu 则是通过创建自己的应用程序商店来达到这个效果。有时你可能无法在当前存储库中找到你需要寻找的东西，在这种情况下，你所要做的就是添加另一个包含你所希望项目的存储库。由于独特的存储库系统，应用程序的更新会变得更加容易，操作系统可以一口气完成查找和更新所有已安装的应用程序，而不是一次只做一件事情。


9. 我如何才能获得关于 Linux 的技术支持？


就象你第一次开始使用 Windows 或 OS X 一样，在你开始使用 Linux 的时候你会想要学习一些关于 Linux 的知识。对于Linux 如何安装和使用的问题是非常简单的，因为大多数发行版都非常重视最终用户的易用性。对于那些相对简单的计算任务，比如网页浏览、字(词)处理，你使用 Linux 将不会造成任何的困惑。


在你解决操作系统问题的时候可能会花费一些时间。但是，请不用担心，Linux 有大量粉丝和社区足以让你应对可能遇到的任何问题。在大多数情况下，Linux 的故障排除不会很难，很多问题可以通过社区的一步一步的帮助，键入命令行命令来解决。


10. 在安装了 Linux 之后，我还能运行以前的操作系统吗？


在你安装了 Linux 后，你会觉得这是一个很好的操作系统，你会发现当中的很多东西都会比前一个系统更好。但是，通常很多游戏以及其它应用不能运行在 Linux 或者 Wine 上。不要担心，你可以通过虚拟机或者双系统来让优秀的 Linux 和你喜欢的操作系统共存。



使用虚拟机，你可以鱼和熊掌兼得，让 Linux 和默认的操作系统同时运行。你可以在虚拟机上运行 Linux 或者你需要的操作系统，这取决于你使用哪种系统更多一些，这个方法很耗系统资源。


另外一种方法，使用双系统。在对系统完成重新启动后，可自由在两个系统中完成切换。这两种方法都是很好的，它能够帮助你无须面对两者只能选其一的艰难抉择。
