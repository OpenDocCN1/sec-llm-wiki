Win10在哪些方面做得比之前的版本更好？

原文：http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247503794&idx=1&sn=a512ba7c091961fea281d55743133a2e&chksm=c0c84e53f7bfc7459d52fe5afb02bc881d0aff574231111b2d5621ca1a5150bb721cef04a712&scene=126&sessionid=1681309796#rd

win10在7月29日的下午进行了发布，一时周围全是win10的话题，我们暂且先不讨论win10的各种特性，我们看看win10在哪些方面做得比win8要好~


PC市场走下坡路是因为Windows 8搞砸了吗？又或者Windows 8之所以搞砸是因为微软对于PC市场的疲软态势提供了过度的补偿？这似乎是一个类似于“先有鸡还是先有蛋”的问题，但是不管怎么说，有一点是肯定的：Windows 8确实把事情搞砸了。


另一方面，Windows 10的表现就好多了，特别是把它跟Windows 8放在一起对比的时候更为明显。它其实就是将Windows 7和Windows 8糅合在一起并且去芜存菁后的产物。诚然，Windows 10继续保留了Windows 8主页面上的“Windows应用与服务”主题，但是它同时尊重了传统桌面系统多年来积累下来的宝贵遗产。


Windows 10，我有多么喜爱你呢？下面就请随我一起来看看它在哪些方面做得比Windows 8更好。


◆1、开始菜单回来了


当然，Windows 10的开始菜单跟你过去使用了多年的开始菜单是肯定不一样的，它更像是Windows 7的开始菜单与Windows 8的开始屏幕结合在一起而生成的产物。我的同事马克·哈克曼（Mark Hachman）在撰写Windows 10系统预评报告时清楚地指出了这一点，他认为Windows 10的开始菜单更像是一个仪表板而不是一个出发点。但是不管怎么说，开始菜单回来了。


◆2、Windows商店的应用模仿了桌面系统中的应用程序


丢掉开始菜单只是Windows 8众多败笔中的一个而已。Windows商店里的应用则是另一个败笔。


这些怪物将桌面计算程序的优良传统都扔到了一边，将自己摆到了对触摸操控并不友好的圣坛上。这些应用被打开的时候，它们会填满整个屏幕，甚至把工作栏也覆盖住。更糟糕的是，它们以极低效率的方式占据了所有的空间，为了便于手指触控而留下大量无用的闲置空间，结果造成了信息密度大幅下降和鼠标滚动操作的大量增加。


但是Windows 10就不同了。微软在Windows 10中将Windows商店里的所有应用都放到了合适的、位置可移动的、大小可调整的桌面窗口中，这样用户就可以更方便、快捷和无缝地将它们整合到自己的工作流中。


隐藏式的图表菜单控制栏不见了，取而代之的是一款合适的菜单条。由于这些应用采用了最新的“通用”界面，因此它们在桌面上的感觉就更为自然了。


我将Windows商店应用完全从我的Windows 8工作流中清除了出去，全部换用Windows 10中的对等应用。集腋成裘，聚沙成塔，正是这一点一滴的进步构成了Windows的整体完善，伙计们，Windows又回来了。


◆3、“飞行模式”的整合性有所提升


在Windows 10系统中，飞行模式界面与系统的无缝整合效果更好了。


在Windows 8系统中，桌面界面和飞行界面给人一种格格不入或者说针锋相对的感觉。当你打开一个文件时，界面从桌面模式突然跳到全屏飞行模式的体验简直糟透了，但在Windows 10中就不同了，因为我们前面已经说过，Windows商店应用和开始菜单都完善了不少。完全消灭图表菜单栏则是微软在正确的方向上向前迈出的另一步。


现在，当你在桌面模式下需要使用到飞行模式的某些元素时，你不用切换模式就可以做到了。


◆4、因设备制宜的界面


如果你正在使用Windows 10手机或平板电脑的话，那就算了，因为这些设备使用的都是修改版本的Windows 10系统，这些修改版Windows可以更好地适应不同设备的不同尺寸的屏幕。实际上，Windows 10的平板电脑模式看起来就像Windows 8的开始页面一样糟糕。


微软试图将Windows 8系统打造成一款放之四海而皆准的操作系统，但是它在这么做的时候强制规定在不同设备上使用相同的界面。Windows 10改变了做法，它让PC、平板电脑各自回归本源，这种做法显然要好一些。


如果你购买了这些混合型设备中的某一种设备，那你可以试试Windows 10的Contimuum模式。由于Windows 10系统采用了共享核心和通用应用，基于Windows 10系统的手机在连接了合适的显示屏时才能更加神似Windows 10PC。


◆5、 DirectX 12


并非Windows 10系统的所有改善之处都集中在对Windows 8的设计进行修修补补上面。


微软希望吸引玩家们从Windows 7直接升级到整合了DirectX 12的Windows 10系统。与AMD的Mantle一样，DirectX 12可以大幅提升游戏模式下的CPU利用率，让开发者们能够更接近图形显示硬件。结果是：英特尔和微软宣称同样的应用在DX12下运行时的速率比它们在DX11下的速度加快了50%。


◆6、 虚拟桌面


Windows 8系统将Windows桌面看作是另一款应用，Windows 10系统则通过新增加的虚拟桌面给你提供更多的桌面，这项功能倍受Linux和OS X系统的喜爱。


只要硬件允许的话，Windows 10系统可以支持无数的虚拟桌面。个别桌面及其应用的管理是通过Windows 10系统的任务视图来实现的。


如果你没有配备多台显示器，那么使用虚拟桌面就显得非常方便。你可以将社交工具放在其中一个虚拟桌面上，而把工作应用放在另一个虚拟桌面上，同时对其他类型的应用比如游戏也都进行区别对待。


◆7、更强大的使用诀窍


微软显然希望通过开始菜单、DX12和虚拟桌面来吸引跳过了Windows 8系统的PC用户去使用Windows 10，而且它的手段显然不止这些。


Windows 10系统从安装开始就附加了更多技巧。从显示效果调整功能的改善到极大增强命令符功能等不一而足。如果说Windows 8是微软为了争取移动用户而进行的一次失败尝试的话，那么Windows 10就是给PC用户们写的一封道歉信。


◆8、操作中心


Windows 8系统的Windows商店应用在PC上使用时的体验一直不太好，但是它们也有自己的长处，那就是覆盖全部系统的通知功能。传统的桌面软件总想作独立仓库，Windows商店应用会在屏幕右上角弹出一条通知，比如你刚刚收到一份新邮件或收到一条来自Twitter的新消息。


对比而言，当在Windows 8系统下接到新通知消息时，这个通知会很快消息，甚至你可能根本就没看清楚，但是你再也不能把这条消息找出来看了。确实，从理论上来说你可以在相关应用的Live Tile上看到之前漏看的通知，但是又有多少人知道并这么去做呢？


Windows 10通过新推出的操作中心解决了这些问题。操作中心会出现在工作条的右边。它会将你漏掉的消息都放在这里，直到你最后去阅读它们。你还会发现一些快速行动按钮，它们可以让你快速去管理WiFi和蓝牙。


◆9、Cortana


Windows 8.1的搜索功能早就已经凭借必应的帮助实现了网页信息抓取，但是结果却不少很好，你必须转到开始屏幕操作。有一种办法可以不用第三方软件帮助迅速在桌面上搜索东西。


数字助手Cortana最早出现于Windows Phone 8.1系统，它可以取代Windows 10的搜索功能，提供了极佳搜索体验。首先，搜索工具条就在桌面任务栏的右边，这已经是一项重要的完善了。



Cortana也得到了必应的支持，但是利用机器习得技术来提供个性化的每日总结、上网记录和你可能会感兴趣的新闻。Cortana对语音指令的支持并不逊色于对文字指令的支持，而且它还能够接受自然语言指令。


◆10、Windows你好


Windows 8系统使用了多种传统认证方式，Pin码、密码和其他很多诸如此类的东西。换句话说，它各种认证方式都支持一点，但是表现就不尽如人意。


Windows 10增加了对两步认证和生物数据认证的支持，最好的例子就是Windows你好功能，该功能可以利用深度感应摄像头来帮助用户自动认证。
