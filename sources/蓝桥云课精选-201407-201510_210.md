# 对开发人员有用的15个Chrome扩展插件

使用Chrome的扩展插件使得我们的日常工作不再那么的乏味。虽然Chrome给我们提供了很多内置的扩展，似乎我们不再需要其他更多的工具了，但我们还是想向你介绍15个对WEB开发人员最佳的Chrome扩展插件。  

  

**1、Web Developer**

  

为Chrome的Web开发者扩展增加了一个不同的工具栏，提供了一些不同的工具。绝对是开发人员最有用的浏览器扩展之一。

![](../Images/43ceba303280d7e63f5278216c4eb343.png)  

**2\. Responsive Web Design Tester**

  

The Responsive Web Design Tester 是一个非常棒的浏览器扩展，使你可以快速的查看你的网站在不同设备和不同浏览器下的状态。

![](../Images/6f8544eb230a7adfb4be7277e80d17ff.png)  

**3\. Window Resizer**

  

Window Resizer 扩展允许您调整浏览器窗口。单击菜单栏中的图标会产生一个可以自定义窗口大小的下拉菜单。

![](../Images/2ada069f442de9f8e5cd2f7e58feb70c.png)  

**4\. ColorPick Eyedropper**

  

ColorPick Eyedropper 是一个简单的颜色选择器工具,允许您从任何web页面选择颜色值。

![](../Images/35b4b5e62a895c9f36ed7309da60987a.png)  

**5\. CSSViewer**

  

CSSViewer是一个简单的CSS属性查看器。它提供了一个浮动面板，该面板显示鼠标悬浮在的元素的标识，以及它的字体、文本、颜色、背景、框、定位和效果属性。CSSViewer提供你所需要的基本的CSS信息。

![](../Images/ab5adbb0438c47ba06f08a5dd9ca02e1.png)  

**6\. Lorem Ipsum generator**

  

The lorem ipsum 生成器所做的就像它的名字一样。它提供了一种简单快速的方式创建默认的文本。如果你需要一些默认的文本作为一个占位符的话，这绝对是一个好的选择。

![](../Images/be34738f8a8dc8302956da38c4665e7c.png)  

**7\. Ghostery**

  

Ghostery是一个Chrome扩展，可以在网站上检测追踪器,像素,和任何其他嵌入式代码片段。你立即看到你访问过的网页安装了哪些插件和追踪器。另外，Ghostery可以保护您的隐私，它不需要注册即可使用。

![](../Images/1d11dee0a9c7da635c618c52ace36782.png)  

**8\. Wappalyzer**

  

Wappalyzer同Ghostery一样的浏览器扩展,揭示了网站上使用的技术。它可以检测到内容管理系统、电子商务平台、web服务器、JavaScript框架,分析工具等等。

![](../Images/a0d253669d92aed3e7d6cf60917f710d.png)  

**9\. Usersnap**

  

![](../Images/d3ea286b338e7abe5070ab443b71e03a.png)  

**10\. IE Tab**

  

需要做一些IE测试又不想安装各种不同的IE版本吗？试试 IE Tab 这个Chrome扩展吧，它直接在Chrome中通过模拟IE渲染引擎来模拟IE浏览器。你可以直接在chrome浏览器测试你的网站对于IE6,IE7,IE8或IE9的显示情况。

  

不幸的是，该扩展目前只有Windows系统下可用。

![](../Images/34ee1a90aacccfc3656addc71847036a.png)  

**11\. Site Spider**

  

如果你需要找到你的网站的失效链接，想限制搜索一个特定的目录，你需要Site Spider。

![](../Images/a138eb1085be9fad0d09edc13670a00a.png)  

**12\. Session Manager**

  

当你做WEB开发工作的时候，浏览器标签管理是一个非常有用的技能。会话管理扩展可能是你需要的。它可以保存你的浏览状态并在以后重新打开。如果你需要重复打开某些页面的话，这个插件将是非常有用的。

![](../Images/e444bb78038dd09af271abfbceec04e3.png)  

**13\. Clear Cache**

  

这个非常有用的Chrome扩展可以让你从工具栏清除缓存。它的“幕后”的含义没有弹窗或确认对话框来分散你的注意力。这些数据是可定制的，包括应用程序缓存、下载、文件系统、表单数据，历史、本地存储、密码等等。

![](../Images/8344afd2b0a44d1c8d1805ca76a8bdec.png)  

**14\. JSONView**

  

作为一名使用RESTful api的开发人员,阅读原始JSON数据浏览器会很尴尬。JSONView这个Chrome扩展帮助您在浏览器中以树视图查看JSON文档，而不是在它的原始状态。

![](../Images/6c8e50c8bb6b631ae8506ec2d59d5570.png)  

**15\. Image Downloader**

  

想直接下载网站上的图片？我建议你看看 Image Downloader 这个插件。它让你批量下载所有图片。也可以过滤网页的图片宽度、高度、URL。

![](../Images/4e2b923c48b7563265de8e924adae0c9.png)
