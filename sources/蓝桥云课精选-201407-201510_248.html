Flask是一个轻量级的Web应用框架, 使用Python编写。基于 WerkzeugWSGI工具箱和 Jinja2模板引擎。使用 BSD 授权。Flask也被称为 “microframework” ，因为它使用简单的核心，用 extension 增加其他功能。Flask没有默认使用的数据库、窗体验证工具。然而，Flask保留了扩增的弹性，可以用Flask-extension加入这些功能：ORM、窗体验证工具、文件上传、各种开放式身份验证技术。

【Python Flask Web框架】课程从基础的理论知识到Flask小项目通过动手实践的方式来让学习者熟练掌握 Flask Web框架。

——[Flask介绍及安装]：想要学习Flask Web框架，当然首先得介绍Flask，以及virtualenv、全局安装的方法啦；

——[Flask运行及调试模式]：运行和调试是必须会的哦，因此这个实验介绍Flask运行及调试模式；

——[路由]：一个现代的Web应用程序，哪能少的了优雅的URLs呢，这个实验就是介绍路由、变量规则、构建URL、HTTP方法的使用；

——[静态文件及渲染模版]：动态的 web 应用同样需要静态文件便于业务逻辑和前端展现的分离，所以必须介绍静态文件及渲染模板；

——[接受请求数据]：对于 web 应用来说，对客户端发送给服务器的数据做出反应至关重要，所以这个实验主要讲解接受请求数据；

——[重定向、响应、会话和扩展]：接受客户端请求之后，服务端需内部做一些“小动作”来响应请求， 这个实验就是介绍重定向、响应、会话和一些扩展的“小动作”；

——[Flask项目实战]：当然必须需要一个实战项目；
