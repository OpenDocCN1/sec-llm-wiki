ini 配置文件


ini 配置文件是常用的配置文件，在许多应用中都有使用，一般用于设置各种配置信息。


ini 配置文件的格式非常简单，主要由节，键，值以及注释组成：


  • 注释使用分号 ; 表示，在分好后面的文字，知道改行结尾都全部为注释；

  • 键值对，也就是参数，使用形如 name=value 的形式，其中，name 是键名，value 是值；

  • 配置文件可以分节，节以 [section] 的形式指定，该节之后直到遇到下一节之前的内容都属于这一节；


解析器的设计


熟悉了 ini 配置文件的格式，设计解析器就比较简单了。


ini 配置文件，包含了多个节，而节包含了多个键值对，所以我们的解析器也可以这么设计，一个解析器解析出的 ini 配置文件对象，将包含多个节，而这些节又包含多个键值对。


如果我们需要访问某键值对，就需要先访问键值对属于的节，然后通过该节获取相应的键值对。


有了这些，我们就可以实现 ini 文件对象，节，以及键值对三种数据结构了，对应到 golang 中也就是三种 struct 。


实现


为了让解析器的实现结构上更加合理，我们将整个解析器分为几个文件分别实现：

  • ini.go 实现了 type file struct 结构体，代表 ini 配置文件对象，还实现了 Load() 方法，用于加载 ini 配置文件；

  • section.go 实现了 type Section struct 结构体，以及该结构体上的各种绑定的方法；

  • key.go 实现了 type Key struct 结构体，以及该结构体上的各种方法；

  • parser.go 包含了解析 ini 配置文件的具体实现，从字符串中解析出注释、节、键值对的方法都是在这个文件中实现的；
