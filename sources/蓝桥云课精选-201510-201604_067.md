很多学过 Java 的同学都是首先从记事本开始写起，然后就开始使用 Eclipse。而今天， 小编介绍一个项目课程，教你制作一个自己的 Java 编辑器，它拥有编辑和编译的功能。是不是很给力呢？项目非常的简单，只要有一点 Java 基础的同学都会看懂的！

  

**项目名称：**  

  

【自己的Java编辑器】

  

**项目简介：**

  

该项目使用 Eclipse 开发，配合 Java 语言完成一个 Java 编辑器。

  

它的主要功能：1、Java代码的编辑 ；2、编译及运行Java程序；

  

**涉及知识：**  

  

*   IO 流的操作（重点）
    
*   Runtime 类 （重点）
    
*   线程的使用 （重点）
    
*   GUI 布局 （不重要，简单理解即可）
