**附录—React简介：**

  

React 起源于 Facebook 的内部项目，于2013年5月开源，如今已然成为最热门的前度框架。

  

官方提出的React的几个特点：

  

*   **专注于 view 层**
    

  

对比传统的 MVC 框架，其实 React 更关注于 View 层。引入组件化的开发思想，即将具有独立功能的部分封装为 UI 组件，然后将小的组件通过组合或者嵌套的方式构成大的组件，最终完成整体的构建。

  

*   **虚拟 DOM**
    

  

当页面的数据产生变化的时候，需要将数据实时反应到 UI 上，这时就需要对 DOM 进行操作，当页面的复杂度达到一个阶段就会带来多种问题，比如性能上的降低。

  

React 引入了虚拟 DOM (Virtual DOM) 机制，所有的 DOM 操作都是在虚拟 DOM 上进行的。每当数据有变化时，React 都会重新创建一个 DOM 树，然后将当前的 DOM 树和上一次的 DOM 树进行对比，得到 DOM 结构的区别，最后只需要更改变化的 DOM 结构即可。

  

*   **单向数据绑定**
    

  

通过组件的方式，绑定页面中的数据，减少了重复的代码，让数据绑定更简单。
