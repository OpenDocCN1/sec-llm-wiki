Tornado 异步网络框架


各种开发语言，都有对异步开发的一定支持。在 Python 中有很多异步开发库可以使用，比较出名的有 Gevent, Tornado, Twisted 以及 Python 3 中引入的标准库 asyncio 等。 这些异步框架，在底层一般都是基于 epoll, kqueue 等机制实现的。


Tornado 框架作为一个流行的 Web 开发框架，同时也是一个异步开发框架，底层在 Linux 平台上基于 epoll 机制实现的。


Redis 协议分析


Redis是一个内存数据库，常用于各种 Web 项目中。既可以当做缓存使用，也可以用作 nosql 数据库。Redis 的通信协议是基于文本的，且以行为划分，每行以 \r\n 结束。
