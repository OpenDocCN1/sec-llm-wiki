# 承认吧：女性才是更好的开发人员！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwODM4NDM5OA==&mid=2247504011&idx=1&sn=9e6ef3ca20480cc7fb744072aa515e1f&chksm=c0c8516af7bfd87c347fbd2adcd86503604455c003950ee98d36b9befa7354c2eeb45422e76d&scene=126&sessionid=1681309772#rd](http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247504011&idx=1&sn=9e6ef3ca20480cc7fb744072aa515e1f&chksm=c0c8516af7bfd87c347fbd2adcd86503604455c003950ee98d36b9befa7354c2eeb45422e76d&scene=126&sessionid=1681309772#rd)

![](../Images/2dae71191d44a396318a7063db228d23.png)         关注一下又不会怀孕~

  

一组计算机科学专业的学生决定对软件开发社区中的性别歧视现象进行研究。在他们的假定中，开发人员往往会对由女性开发的程序持有偏见态度。

  

2013 年的一项调查显示，女性在软件开发者群体中所占据的比例非常低下，仅为 11.2%。

  

在软件开发这个由男性占据绝对主流的领域，各种各样的性别歧视现象可谓是屡见不鲜。

![](../Images/dd9e661b1ea84df61af3fc9cc906b2bf.png)

因此，当看到研究结果和自己的假定相违背时，研究人员对此感到惊讶万分：

实验结果表明，和由男性开发人员开发的程序相比，女性开发人员所编写的程序更可能得到专业人士的认可。但这样的结果存在一个前提，那就是审查人员并没有意识到他们所审查的代码出自女性之手。

  

**「我们的调查结果显示，尽管在 GitHub 上女性开发者显然更具竞争力，但性别歧视却依然存在。」**研究结果的撰写人如实写道，这个研究小组在不久前发布了自己的研究结果。他们对 GitHub（全球最大的开源软件社区）上开发人员的行为进行了观察。

  

成立于旧金山（San Francisco）的 GitHub 是一个体量庞大的代码知识库，其用户人数超过 1,200 万。GitHub 上的开发人员可以进行协同工作，也可以相互审查对方的开发作品，并就作品的提升方案以及问题的解决方式交换意见。

  

当一位开发者为他人的项目编写代码时，人们将其成为「牵引请求」（pull request）。项目所有者可以自行决定是否接受由他人所提供的代码。

  

研究人员对 GitHub 上超过 300 万个牵引请求进行了审查，最终发现**由女性开发者所编写的代码最终被项目所有人接受的比例要更高：**

其中女性开发者的作品被接受的比率为 78.6%，而男性则仅为 74.6%。

  

为了找出导致差异的原因，研究人员对几个不同的因子进行了检验，包括女性是否有对代码进行微调（检验后发现她们并没有）以及女性是否仅在特定类型的代码上比男性要优胜（检验后发现没有这个规律）。

  

**「尽管程度不一，但我们发现在首选的 10 种编程语言中女性的被接受比率都要优于男性。」**研究人员指出。

  

随后，研究人员还检验了研究对象是否受益于反向偏差效应（reverse bias），即审查人员是否会因为女性在开发者群体中处于弱势地位而有针对性地提高评价。

  

为了找出这个问题的答案，研究人员对女性开发人员的个人档案进行区分：部分女性开发者会在个人档案中明确自己的性别，而其他女性开发者的档案则显示为中立性别。

  

在进行区分后，研究人员得到了一个全新的发现：在性别未得到明确的情况下，女性开发者的作品要更容易被项目所有人接受；一旦性别得到明确，她们的作品被接受的比率甚至会比男性更低。

  

![](../Images/06aa8434e01874d59b8df32d988fedf9.png)

**随后研究人员和 GitHub 上面的一些女性开发者进行了会谈，并从中发现了在开源代码世界中性别歧视现象的复杂性。**

  

洛娜 · 简 · 米歇尔（Lorna Jane Mitchell）是一位软件开发人员，她的工作主要集中在 GitHub 平台。她认为一旦女性开发者的牵引需求被项目所有人拒绝，人们很难界定起因究竟是性别歧视还是其他因素。

  

米歇尔在 GitHub 上的资料明确表明她是一名女性。她表示不论这项研究的结果到底如何，她都不会选择隐藏自己的性别。

  

「我认为在个人资料上明确表明自己的性别是一个明智的行为，那对我很重要。」米歇尔在邮件中写道，「我希望人们记住和我一样的少数群体确实存在，我也希望和我一样的女性能够知道自己并不孤单。随着时间的推移，我相信这种情况将会得到改善。」

  

另一位开发者伊莎贝尔 · 德罗斯特 · 弗罗姆（Isabel Drost-Fromm）在 GitHub 上的头像则是一个女性卡通人物。她表示自己在 GitHub 上工作期间还没有遭受过性别歧视，她通常利用这个网站和一个团队协同推进一些项目的工作，而她所合作的团队一般都比较相熟。

  

英属哥伦比亚大学（University of British Columbia）的统计学教授珍妮 · 布莱恩（Jenny Bryan）在日常的教育和开发工作中也会使用 GitHub，她在个人资料上也明确表明了自己是一名女性。她表示自己对于开发工作上的性别歧视感到难以置信。

  

「我时常遇到的一种情况是男士们总会一再向我解释一些事情，但我对这些事情的理解显然比他们要内行得多。」她写道，「我在 GitHub 社区上会和一些男性互动，但他们知道我是谁。如果硬要说我的性别对他们有什么影响的话，我认为他们会因为我是女性而给我提供更多的支持，他们会尽量支持我的学习，以便我可以贡献更多的力量。」

  

在研究结果出来后，布莱恩对使用 GitHub 的女性数量表示关注。「女士们都到哪里啦？」她问道。她认为导致女性在 GitHub 上成为少数群体的罪魁祸首正是这个开源网站的开放性。

  

「在一个开源的网站上，没有人会因为社区的管理工作而获得酬劳。」她写道，「因此也没有人会关心社区的运营状况。」

‍

  

这对于 GitHub 而言无疑是一个严峻的问题。由于面临内部性别歧视的指控，GitHub 的联合创始人兼 CEO 汤姆 · 普勒斯顿 · 维尔纳（Tom Preston-Werner）在 2014 年提出辞职。

  

目前 GitHub 并没有对于这项研究发表评论。

  

在 2013 年，GitHub 在公司总部内放置了一块地毯，上面写着：「一个团结、崇尚英才管理制度的 GitHub 社区」。

  

但是在 2014 年，有女权主义评论员对 GitHub 社区发起了批评。他们认为英才管理制度确实无可厚非，但这并不能改善办公场合的多样性问题。不久后这块地毯就被移除了。

  

接任 CEO 的克里斯 · 万斯特拉斯（Chris Wanstrath）则发送推文称：「我们认为英才管理制度是开源社区的背后逻辑，但现在我们意识到了这种制度的缺陷。我们准备更换一块新的毛毯。」

  

正如研究人员所言：「我们理所当然地认为英才管理制度是开源社区的根本，现在我们需要对这种制度的合理性重新进行探讨。」
