小编今天介绍的项目是教你用Laravel实现一个多用户博客系统，对于PHP学习者来说是一个非常不错的动手实践项目。

  

**项目名称：**

  

【Laravel大型项目系列教程】

  

**项目简介：**

  

该项目使用Laravel4.2和AmazeUI实现一个多用户博客系统，分模块做实验，实现各个功能。需要一定的 PHP 基础知识。

  

**项目完成目标：**

  

使用Laravel和AmazeUI实现一个多用户博客系统，大概会包含如下内容：

  

> *   路由管理。
>     
> *   用户管理，如用户注册、修改信息、锁定用户等。
>     
> *   文章管理，如发表文章、修改文章等。
>     
> *   标签管理，文章会有一到多个标签。
>     
> *   数据库管理，如迁移、填充数据等。
>     
> *   Web表单验证。
>     
> *   Blade模版引擎。
>     
> *   分页处理。
>     
> *   安全处理。
>     
> *   单元测试。
>     
> *   部署到应用服务器Apache。
>
