2、即时通信软件


这个项目是实现一个简单的即时聊天工具的服务端和客户发端，学完该项目之后掌握的知识点如下：


  • 套接字工作原理及使用；

  • pipe管道使用方法；

  • epoll使用方法；

  • 进程的创建与使用；

  • 进程间的通信方式。


在实验过程中遇到的问题如下：


问题：服务端与客户端显示信息，出现信息覆盖现象？

问题分析： 服务端的缓冲区变量在接收信息前，未清空。

解决：

bzero(&message, MAXBUFF);       //清空缓冲区，
int n = recv(server_fd, message, MAXBUFF, 0);

- 初始化窗体函数：glutInit（）
- 显示函数：glBegin、glVertex3f、glEnd

- 回调函数：glutKeyboardFunc、glutTimerFunc(100,Update,0)、glutDisplayFunc(Display);

4、Web服务器


这个项目是实现一个WEB服务器，可以支持基础的HTTP操作，主要是学习C++的网络服务开发，做完项目后掌握了以下知识点：

  • C++ 网络编程socket

  • kqueue IO复用机制

  • HTTP 协议基础


在这个项目的学习过程中由于期末复习考试,断断续续,大概拖了一个月吧,才把这个实验做完.中间遇到了挺多问题的,忘得也差不多了.凭记忆写一些.


 1.问题:


最新的一个bug: 网页可以链接服务器,但是无法显示内容.


解决: 坑爹啊,前几周就出现这个问题了,无奈考试就没去调试了,今天闲来无事,正好调试.记得HTTP协议中说明报头与正文之间要空两行="\r\n\r\n".于是把response响应类中的数据显示出来看看,NND,果然这里显示有问题,成了"\r\nht",再看程序相关部分:

string str = "\r\n";
putBytes((byte*)&str,2);


当时为啥写成这样了,想不通,改为:

string str = "\r\n";
putBytes((byte*)str.c_str(),2);


效果立竿见影.


其他类似的问题遇到了好多, 就是蠢.有点懒不写了.
