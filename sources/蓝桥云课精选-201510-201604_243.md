日常生活中大家肯定都使用过 ATM 自助取款机，那么今天小编就介绍一个项目，教你用 C 语言编写个小程序来简单模仿 ATM 取款机的查询、存取款等功能。

  

**课程名称：**

  

【C语言模拟ATM自动取款机系统】

  

**项目简介：**

  

项目用 C 语言实现简单模拟 ATM 自动取款机的查询、存款、取款等功能。效果为在终端下的字符界面。

  

**主要功能：**

  

> *   账号及密码输入：允许用户输入账号、密码，对用户由于疏忽录入的非法数据，能够及时提示并更正。
>     
>       
>     
> *   登陆成功界面：共有四个选项，查询余额、取款、存款、退出分别对应1、2、3、4选项，若序号输入不正确会予以提示。
>     
>       
>     
> *   选定1后，进入查询余额界面； 选定2后，进入取款界面； 选定3后，进入存款界面； 选定4后，进入退出界面，系统会延迟3秒重新跳回登陆界面，供其他用户使用。
>
