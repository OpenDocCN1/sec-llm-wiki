现在许多网站都会在节假日或庆典的时候举行一些抽奖活动吸引用户。抽奖活动的类型有多种，有转盘抽奖，翻牌抽奖等等。实现方式大多都是由 flash 或 javascript 实现。

  

小编今天介绍一个教你实现转盘抽奖的课程，学完后你就可以自己做一个抽奖转盘做活动了O(∩\_∩)O~

  

**课程名称：**

  

【转盘抽奖】

  

**课程简介：**

  

该项目使用 javascript、html、css、jquery和 php 实现一个转盘抽奖，javascript 实现转盘转动效果，jquery 实现与后台异步通信，php 则实现后台的奖品抽奖。

**在线环境：**

![](../Images/685277206852d418b65f9de58dac8daa.png)  

  

如上图所示，该课程有课程文档引导你进行开发，还配有在线环境，可以随时动手操作，遇到问题也可以及时提问交流……  

  

在项目文档方面，课程从以下几个方面进行了引导开发：

  

*   HTML部分
    
*   CSS部分
    
*   javascript 实现转动效果
    
*   PHP 实现奖品抽奖
    
*   使用 ajax 与后端通信
    

  

当然你可以点击“阅读原文”，马上在线查看项目开发详细文档~

  

小编非常推荐你用PC访问实验楼网站，在线学习该课程，因为移动端只能阅读文档，而不能操作，用PC可以照着文档进行在线开发操作，这样可以更高效的掌握转盘抽奖的开发方法和写出代码。

  

最后留一个思考题吧：我们如何对用户身份进行识别，用户的抽奖机率怎样控制，用户的作弊防护怎么做，奖品的数据库读取……
