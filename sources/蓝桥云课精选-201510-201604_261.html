很多技术人员都有自己的博客，分享一些技术方法。同时开发博客呢，也成为了很多新手必练手的一个项目，小编今天介绍的课程就是教大家怎样开发一个多用户的博客系统。


所谓多用户呢，就是可以不同的人注册登录，并在上面发表文章，废话不多说了，接着看吧~


课程名称：


【用NodeJS打造一个简单的博客】


课程简介：


该项目使用 NodeJS + Express + mongodb + Amazeui 搭建一个多用户的博客系统。


其中用到的几样技术，主要简单介绍一下Express ，Express是一个简洁而灵活的 node.js Web 应用框架，它提供一系列强大特性帮助我们创建各种 Web 应用。


功能实现：


我们可以发现，只要有3样功能就可以实现一个最简单的多用户博客系统了，这3样功能分别是：注册、登陆、发表文章；


这也是这个课程主要教给大家的，关于其他什么文章分页啦，管理文章啦……之类的，你学完之后完全可以自己拓展开发滴，因此就不做介绍了。
