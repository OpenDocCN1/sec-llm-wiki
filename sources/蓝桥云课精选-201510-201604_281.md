# 2015十大新兴热门开源项目盘点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwODM4NDM5OA==&mid=2247503954&idx=1&sn=7d91d1c9410b22ca6b3f2b3a35c2981d&chksm=c0c851b3f7bfd8a54a17feb3791003b278bab3356a08d2dd71f1d0406169d6f6639da27fe44e&scene=126&sessionid=1681309779#rd](http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247503954&idx=1&sn=7d91d1c9410b22ca6b3f2b3a35c2981d&chksm=c0c851b3f7bfd8a54a17feb3791003b278bab3356a08d2dd71f1d0406169d6f6639da27fe44e&scene=126&sessionid=1681309779#rd)

开源已经成为全球数字经济的创新引擎，而开源项目的数量和投资金额近年来也创下历史新高。

  

2015是开源盛世的发端，而不是顶点，2015年开源运动所呈现的发展趋势牵动着整个IT业的神经。

  

近日开源软件平台Black Duck公司根据Open Hub网站上的开源项目统计数据给出了近年来诞生的十大热门开源项目TOP10榜单。Black Duck评选中使用的权重评分系统参考了开源项目的活跃度、进度等指标。

  

通过2015年热门开源项目排行榜，我们能了解全球开源社区的想法并预测未来趋势。我们一起来看下：

  

**一、DebOps**

  

![](../Images/efaec19b9916420f26fee1c0f3a21752.png "image")

  

DebOps 是 Ansible 方案集合，具备从从一个容器到整个数据中心的可伸缩性。 诞生于波特兰一所不知名大学的DebOps的创始人Maciej Delmanowski开源DebOps的目的是希望DebOps能够超越最初的工作环境，在贡献者的推动下进一步成长。

  

**二、CodeCombat**

  

![](../Images/dac32aedbd19c8609edfb9cfe049c648.png "code combat")

  

CodeCombat颠覆了传统的编程学习模式，把编程学习变成了一个多人在线游戏。

  

**三、Storj**

  

![](../Images/3121d545b631d2132380b8f82ec59a85.png "Storj.io")

  

Storj是一个去中心化的P2P的云存储网络，提供端到端加密，用户无需借助第三方或者中心服务器就能进行安全的数据传输和分享。Storj的核心技术基于比特币的块链技术和P2P网络协议，能提供安全、私有和加密的云存储服务。

  

**四、Neovim**

  

![](../Images/927e1dd2d6a45c947f1d0684e5fff624.png "Neovim")

  

1991年诞生以来，文本编辑器vim已经赢得了数以百万计的软件开发者用户，而Neovim正是vim的换代产品。

  

**五、CockroachDB**

  

![](../Images/84d8f291c1c13dcfabbe125fd8ad9ce8.png "cockroachDB")

  

前谷歌员工将谷歌的大规模数据库技术方案带到了开源世界，就是CockroachDB，一个可伸缩、支持异地备份的交易型数据库。

  

**六、Kubernetes**

  

![](../Images/f860157d4d6ab93c9bde2aae2f4b985c.png "kubernetes")

  

Kubernetes是谷歌去年六月推出的开源容器管理工具，可以用来加速开发并简化运营。

  

**七、Open Bazaar**

  

![](../Images/47f275ea92236e5eaa28d36064e0c634.png "Open Bazaar")

  

Open Bazaar是去中心化的使用比特币结算的网络集市。OpenBazaar大大提高的交易的透明度，有望引发现实世界中贸易和商务的革命。

  

**八、IPFS**

  

![](../Images/bb4bc5460df8f6de29603ffc3f161def.png "IPFS")

  

IPFS(InterPlanetary File System)是面向全球的点对点分布式版本文件系统，可替代HTTP的分布式网络协议。IPFS综合了Git、BitTorrent和HTTP的技术理念，为开放web提供了一个全新的数据基础架构传输协议。

  

**九、cAdvisor**

  

![](../Images/8cb0ccc3e07fe9f5e20d5e5786d9e01d.png "cAdvisor")

  

cAdvisor(Container Advisor)是一个用来分析运行中的Docker容器资源占用及性能特性的信息采集、聚合、处理和导出工具。

  

**十、Terraform**

  

![](../Images/b833531460b4273ede0c8fc2d3c57940.png "terraform")

  

Terraform为邮件和DNS服务商搭建包括物理和虚拟服务器的基础设施提供通用配置方案，无论企业级解决方案还是公有云平台都适用。Terraform适用高级配置语法描述基础设施，使得基础设施的配置信息可以像编程代码一样进行版本管理。

  

**总结：**

  

2015年与Docker容器技术相关的开源项目在新生开源项目中占据了压倒性的优势，同时也是企业级IT技术创新最激动人心的领域。
