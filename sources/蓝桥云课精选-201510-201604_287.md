**J2SE简介：**

  

Java 2平台包括：标准版（J2SE）、企业版（J2EE）和微缩版（J2ME）三个版本。J2SE即Java 2的标准版，主要用于桌面应用软件的开发。J2SE，全称为Java 2 Standard Edition。

  

**我们先看看J2SE与J2EE、J2ME之间的关系：**

![](../Images/93f933670488f938f6cbb49ac252f9e9.png)  

  

**再来看看J2SE的架构：**

  

它主要包含了UI、集成库、语言和工具基础库、其他基础库、Java虚拟机等组件。

![](../Images/d7c6cbd54fd7720cd20fab97c919bf9a.png)  

  

综上所述，将J2SE压缩一点再加上一些CLDC等方面的特性就是J2ME；将其扩充一点再增加一些EJB等企业应用方面的特性就是J2EE。

  

因此J2SE是J2EE的基础，建议从事Java的开发人员从J2SE开始学习。
