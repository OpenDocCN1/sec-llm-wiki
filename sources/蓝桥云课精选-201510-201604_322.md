# 18个基于 HTML5 Canvas 开发的图表库

如今，HTML5 可谓如众星捧月一般，受到许多业内巨头的青睐。很多Web开发者也尝试着用 HTML 5 来制作各种各样的富 Web 应用。

  

HTML 5 规范引进了很多新特性，其中之一就是 Canvas 元素。HTML 5 Canvas 提供了通过 JavaScript 绘制图形的方法，非常强大。

  

今天，本文收集了一些非常好的基于 HTML 5 Canvas 的图表方案推荐给大家。

  

![](../Images/f234474d71d3ef05b83b13ea323aa2a5.png)**1.Visualize**![](../Images/7fd335c4d5b0b35e1697501abc1487ee.png)

![](../Images/0bceba6379ff8dc8a093f910555cd5e5.png)  

  

Visualize通过Javascript从结构化的HTML表格获取数据并借助HTML5 Canvas把数据转换为可视化的图表。

  

![](../Images/f234474d71d3ef05b83b13ea323aa2a5.png)

## **2\. rGraph**

![](../Images/7fd335c4d5b0b35e1697501abc1487ee.png)

![](../Images/5e0669048cb55d5fdf550667921794be.png)

  

rGraph是一个基于HTML5 canvas的图表库。借助HTML5的特性可以生成各种类型的图表，例如饼图、条形图、圆环图、甘特图、雷达图等。

  

![](../Images/f234474d71d3ef05b83b13ea323aa2a5.png)

## **3\. iGrapher**

![](../Images/7fd335c4d5b0b35e1697501abc1487ee.png)

![](../Images/ebefc2863a82f0b89770060e6e573629.png)
