眼看2015马上就结束了，还记得年初的时候给自己的定的看书计划么？多半都忘记了，不过没关系，现在开始还来得及~


本文就给前端开发者推荐了一些前端经典书籍，较为全面，如果你正在为选择看什么书籍而苦恼，或许本文可以给你一些参考！

基础打牢，纵观全局

《跨终端web》



移动优先|响应式|HTML5|Hybrid


作者将自己在百度和天猫期间的跨终端Web的开发实践转化为书中的技术方案和实现，呈现给各位读者。讲解深入浅出，通畅易懂，适合有一定PC Web基础的读者。

《响应式web》


国内外专业Web设计师、开发者联袂力荐，响应式Web理论派转型实践派利器


书中实践源于多年生产环境的经验总结，绝不是赘述纯理论知识，而是教你在实践中如何开展响应式设计工作。

《移动Web手册（双色）》


前端国际大牛PPK最新力作，月影、Winter联袂推荐


彻底厘清移动Web开发与传统PC网站开发的本质区别， 从前端走向终端必不可少的大纲，告诉你哪些是移动前端真正要用的，打好基础才能明确方向。

《高性能网站建设指南：前端工程师技能精髓》


全面涵盖浏览器端性能问题的方方面面


结合Web 2.0以来Web开发领域的最新形势和特点，介绍了网站性能问题的现状、产生的原因，以及改善或解决性能问题的原则、技术技巧和最佳实践。

《高性能网站建设进阶指南：Web开发者性能优化最佳实践》


8位专家提供提升网站性能的最佳实践和实用建议


理解Ajax性能，编写高效的JavaScript，创建快速响应的应用程序和无阻塞加载脚本，跨域共享资源，无损压缩图片大小，使用块编码加快网页渲染,避免或取代iframe的方法，简化CSS选择符，以及其他技术。

《高性能JavaScript》


值得所有前端人员细细品读的经典，来自一线实践经验总结，提升JavaScript性能立竿见影。


揭示的技术和策略能帮助你在开发过程中消除性能瓶颈。

《超实用的HTML代码段》


300段代码一网打尽HTML技术


300余段代码能让你更轻松地学会HTML，更得心应手地应用HTML。

《响应式设计、改造与优化》


响应式移动设计从零到一，现有网站实现响应式改造


为了让我们的网站在各个终端上的用户体验都尽可能接近完美，我们需要采用响应式移动设计。

NodeJS实践指南书籍

《Node.js实战（第2季）》


为读者量身打造的Node.js实战热门案例，迅速开阔视野、提升技能及实力


通过7个实例分别讲解了Node.js在实战开发中的应用，着重讲解了每个实战案例所涉及的基础知识、思路和方法，并详细解释了源码的关键部分

《超实用的Node.js代码段》


实用的代码技能丨犀利的阅读体验丨五星的读者服务


精选300余段Node.js代码，涵盖了服务器端脚本开发中的绝大多数要点、技巧与方法，堪称史上最实用的Node.js框架开发方面的参考书籍。

《Node.js项目实践：构建可扩展的Web应用》

Node实战|组件|工具|模块库大全，搞定最复杂应用全面提升代码质量与开发效率


全球获好评最多的Node书籍，原著获数百人五星推荐；迈向产品级开发的实战入门，理解更深，技能翻番。

《Node.js+MongoDB+AngularJS Web开发》


MEAN全栈工程师首部实战书，基于JavaScript的Web应用程序权威指南，内容完整细致可直接用来入门任一技术。


Node.js、MongoDB、、AngularJS结合在一起使得Web程序员能够完全用JavaScript创建从服务器到客户端的高性能站点和应用程序。

React了解书籍

《React：引领未来的用户界面开发框架》


Facebook前端专家作序震撼前端世界的技术趋势，国内一线前端联合推荐


2014 年由Facebook 推出的开源框架React.js，基于Virtual DOM 重新定义了用户界面的开发方式，彻底革新了大家对前端框架的认识，将PHP 风格的开发方式迁移到客户端应用开发。

《React Native：用JavaScript开发移动应用》


移动应用开发从此进入新时代，已覆盖iOS与Android平台


React Native是当前移动端开发中的优秀解决方案。围绕着如何将一个完整App提交到App Store，讲解了使用React Native开发iOS应用所涉及的方方面面。

新技术学习

《用AngularJS开发下一代Web应用》


来自Google，最具潜力的JavaScript框架的优秀著作


这本手册将为你介绍AngularJS，它是一个开源的JavaScript框架，它使用MVC架构、数据绑定、客户端模板以及依赖注入等技术，从而为构建Web应用创建急需的结构。

《Web Component实战：探索PolymerJS、Mozilla Brick、Bosonic与ReactJS框架》


全面剖析面向未来的组件化思想及开发技术


Web Component 带来 UI 组件化的全新标准，帮助开发者在开发过程中创建稳定且可复用的组件。分离关注点，降低代码维护成本并提升开发效率，是前端发展必由之路。

《Polymer：面向未来的Web组件开发》

WebComponent技术书惊现曝光，Google Polymer这一代表变革趋势的组件技术


本书包含了构建常用JavaScript组件的基础知识，并通过实例带领你学习组件的概念化、设计和实施，后半部分则涵盖了封装、打包和部署的相关知识。
