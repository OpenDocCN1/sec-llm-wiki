我每天使用 Git ，但是很多命令记不住。

  

一般来说，日常使用只要记住下图6个命令，就可以了。但是熟练使用，恐怕要记住60～100个命令。

![](../Images/af820faf87706bd52893141a6c5c8169.png)

  

下面是我整理的常用 Git 命令清单。几个专用名词的译名如下。

*   Workspace：工作区
    
*   Index / Stage：暂存区
    
*   Repository：仓库区（或本地仓库）
    
*   Remote：远程仓库
