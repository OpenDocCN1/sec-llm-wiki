# 10个最好的 Node.js MVC 框架

Node.js 是最流行的 JavaScript 服务端平台，它允许建立可扩展的 Web 应用程序。

  

Node.js 包含不同类型的框架，如 MVC 框架、全栈框架、REST API 以及大量的服务器库，使它能够快速构建 Web 服务器，而无需使用外部软件（如 Apache 和 Lighttpd 等）。这些框架使得它更加用户友好，易于使用，还支持众多的特性和功能，只要按照几个步骤就可以开发出庞大的 Web 应用程序。

  

今天，我们挑选了10个最好的 Node.js MVC 框架分享给 Web 开发人员，它们能够帮助开发人员更轻松的创建 MVC 项目。

  

****1.Sails js****

  

Sails 是一款优秀的框架，可以很容易地开发定制的，企业级的和现代的 Node.js 应用程序，也适合于开发图表，仪表盘和游戏。

![](../Images/20635329af0707e1cdf33f69219c4b81.png)

  

****2.Total js****

  

Total.js 是另一个伟大的 Node.js 框架，帮助创建网页和网络应用程序，还支持 MVC 架构。这是一个开源的现代框架，使用 HTML，JavaScript 和 CSS 建设网站。

![](../Images/e0394e4f10719aef625be93a0bd2f005.png)

  

****3.Express js****

  

是目前最流行的 Node.js Web 开发框架，最受 Web 开发人员欢迎。使用其强大的功能，开发人员可以创建单页和多页，和混合模式的 Web 应用程序。

![](../Images/2e54719d1377f83e875f6b2b855b7f00.png)

  

****4.Koa js****

  

这款 Node.js 框架是由 Express 团队开发的。Kao.js 是下一代的工具，其目的是为 Web 应用程序和 API 打造更轻量，更具表现力，更坚实的基础。

![](../Images/b7f040921eb973f3323f68dd86aa88e2.png)

  

****5.Locomotive js****

  

Locomotive 支持 MVC 模式，REST 风格的路由也是基于 Express 构建的。这是最强大的 Node.js Web 框架，目前的强大功能有：

*   1）约定优于配置
    
*   2）路由助手
    
*   3）MVC 架构
    
*   4）连接到任何数据库。
    

![](../Images/25e73316415489175194e6b4ee809716.png)

  

****6.Partial.js****

  

另一款 Node.js MVC 框架，使用 HTML，CSS 和 JavaScript 的开发人员可以构建大型的 Web 应用程序和网站。功能和体系结构和 Total.js 类似。

![](../Images/7c373b90b6ccda1c47297c13e97c63a1.png)

  

****7.Flatiron js****

  

Flatiron.js 也是一个现代和下一代的 Web 框架，帮助建立令人印象深刻的 Web 应用程序。

![](../Images/df987d4f8d73751d08614d3b00a40379.png)

  

****8.Express-io****

  

Express.io 是一款实时的 Node.js Web 框架，支持创建 MVC 架构的 Web 应用程序。

![](../Images/98f20e861d036dd37b239b4bb6cb2beb.png)

  

****9.SocketStream****

  

Socket stream 具有快速和模块化的特性，致力于打造实时的单页面应用程序。

![](../Images/668f59e00c25c0d9790a560dd5161307.png)

  

****10.Geddy.js****

  

Geddy.js 是一款简单，结构化和原始的 Node.js MVC 开发框架，用于构建高级 Web 应用程序。

![](../Images/bc980c72a85907072f48adfdaed07800.png)
