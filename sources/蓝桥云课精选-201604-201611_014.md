# 做人不装逼，和咸鱼有什么区别——16个装逼又实用的网站（程序员向）

**关注「实验楼」，每天分享一个项目教程**   

> 做人如果不装逼，又和咸鱼有什么区别？作为国内领先的IT装逼教育公众号，我们又来教你装逼了。
> 
> 事实就是如此，作为一个程序员，不会装逼，不会甩锅，你还想晚上加个菜？干脆去做产品经理算了。
> 
> 本文依然来自一位知乎大神——**林梓**。他整理了16个又装逼又实用的网站，稳不稳你看完第一个就知道了。而这位大神和我们前几天介绍的大神有一个共同特点——都是实验楼的用户。
> 
> 那么问题来了，到底是实验楼让他们成为了大神，还是他们成为大神之后才用的实验楼呢？
> 
> 请每天在实验楼完成一个实验，100天后答案自现。

**1.****GEEKTyper.com**  

一个在线模拟黑客工作的虚拟桌面系统，提供多种黑客工作的场景，就像是我们在电影里看到的黑客是如何操作电脑和进行代码录入的。伪装成黑客的网站啊，不一定有用但肯定有趣，我想所有程序员都想试试吧，毕竟成为一个黑客还是很酷炫的啊。  

![](../Images/c547cd8637ddad1adf2f51a2fe579478.png)**2.****codewars**

Codewars是一个刷题网站，使用者可选择所学技术领域不断实战答题挑战，而且它的奖励系统激励程序员们像打游戏升级一样地做习题。  

![](../Images/6e6a874e33d3e72b429ba1baf4d6b9e4.png)

**3.动画展示各种路径搜索算法**  
  
我觉得还蛮有趣的，直观的感受路径搜索算法；  

![](../Images/e9c39f6a9d6853eee3d7d47f9b0c2565.png)

**4.****“Hello World”大全**

网站一共收集了大约481种“Hello World”程序，差不多涵盖了目前已知的所有编程语言，比较有趣好玩，很多语言可能都没有听过。  
![](../Images/4e8c46673e70145754d8afc9daae8179.png)

**5.Font Awesome Cheatsheet**

Font Awesome图标，不多说，开发和设计都会用到。  
![](../Images/b7c3b1ecf8f352c880f8ba0df42e992e.png)

**6.实验楼 - 国内领先的IT技术实训平台**

一个拥有在线开发环境的IT学习网站，现在已经有1000多个项目，不管是小白还是老司机都可以在里面找到惊喜。  
![](../Images/33ce775f8c60c9c3d444ecbd6ec4b276.png)

**7.Most Exclusive Website**

网站每次只允许一个人访问，而且只能访问网站60秒,已经有超多人排队了，你可以试试~当然这个可能并不一定实用，但是还觉得蛮好玩的。  
![](../Images/962bffbe17c3cd65d1abb3a2fdfe4e3b.png)

**8.IT eBooks - Free Download**  

可以下载IT电子书籍的网站，英文；  
![](../Images/5295bbb34dabf8a482caa3fe780ba08e.png)

**9.Collecting all the cheat sheets**

这个网站可以查询到所有与编程相关的各种技术，并给出详细的知识点；  
![](../Images/3329072d716dbfd1e712cc90b11eef9b.png)

**10.DevDocs API Documentation**

这是一份综合类的在线API列表，很全，方便查找。  
![](../Images/207dde57ace373006ba15630d2516abe.png)

  
**11.免费的计算机编程类中文书籍**

其实这个算不上小众，但是我认为非常有用，免费的中文书籍诶，随时可以看，所以也放进来了。  
![](../Images/735b004f78b8d2e20954c22d712006a5.png)  
这里还有英文的：  
  
**12.free-programming-books**  
  
分享了大量免费的编程书籍，比上面分享的中文版的编程书籍要全要多，不过都是英文的；  
![](../Images/d20ecaaf60b5a63cbadf374764f82bda.png)  
  
**13.The World's Most Exclusive Website**  
  
一个独特神秘的网站。基本上，该网站允许用户访问的级别是基于你在Twitter上的追随者有多少。它一共拥有10个房间。要进入“室1”，你需要是一个经过验证的Twitter用户。要进入“室2”，你需要有至少5000个追随者。级别越高，要求也就越高。也是世界上最容易被破解的。我们技术娴熟的一个读者甚至无需登录Twitter，只花费了不到60秒的时间便查看到该网站的所有页面。

![](../Images/17a47f3bf680c3cafb86db9d477bd6d0.png)

**14.oreilly Free Programming Ebooks**

ORielly 的免费电子书，有需要的童鞋可以免费下载，虽说免费的书籍文章前面已经有过介绍了，但是书籍嘛，还是免费的，是很有用的。  
![](../Images/aa3e981ccf57a999b5bd1988faa10037.png)

**15.The Python Challenge**

是一个基于Python语言的闯关挑战游戏，每一关给出一个Python相关的图片，闯关者需要解答问题之后才能跳转到下一个关卡，还蛮有趣的，Python学习者可以看看。

![](../Images/08560c06909f4a531ba065355c340779.png)

**16.Regexper**

一个正则表达式的可视化开源工具，直接输入正则表达式就能用可视化显示出来，只需要把你的表达式输入进去，就有可视化的图形。  
![](../Images/408c67f50b291640b1b76fc7243deb96.png)\---  
  
以上了就是我整理的16个相对来说比较小众，但是对程序员来说却有趣或者有用的网站，如果你还有其他相关网站，评论出来啊，我随时更新上来，大家共同学习嘛。
