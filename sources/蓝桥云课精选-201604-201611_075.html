生活中，很多人都对一样东西恨得咬牙切齿——验证码。特别是12306出现以后：



但如果验证码长成这个样子，你会不会对它有好感得多？

验证码是一种用于区分用户是计算机和人的程序，它的出现有助于保护网站免受垃圾信息、恶意注册的干扰，使网站运营更加安全。传统的验证方法是利用图形的视觉识别来进行验证，常用的方案有：图片字符验证，图片含义验证等。此类验证方法操作难度大，给正常用户带来很大的困扰。

而上图为Luosimao 创新开发的一种人机验证，免去了用户复杂的输入过程，使验证界面简单、精确且富于美感。

下面我们就来介绍如何调用luosimiao的API制作这样的人机验证系统。

项目名称：

【基于 luosimao 的人机验证服务】

项目简介：

本次实验实现了利用 Luosimao 提供的接口，为网站添加人机验证的服务。大家完成后，可以将该系统应用到其他方面，比如评论回复，杜绝机器人自动发帖；投票，防止机器人作弊刷票等等。

涉及知识点：

  • HTML

  • Bootstrap

  • Luosimao 提供的 API
