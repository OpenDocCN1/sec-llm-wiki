看到电子书三个字的时候，小编又想起了被无良老师支配的恐惧：Word2010出的时候教着Word2003，Ps CS6出的时候教着CS3。问其为什么不教新版本，答曰：老版本做出来的文件兼容度更好。好吧，我信你了，结果出来一问，全是这套路。

而且在h5大行其势的时候，教给学生的居然是销声匿迹多少年的制作电子杂志（.exe）！根本就是浪费光阴浪费学费好伐！


所以说想学习有用的东西，真的还要靠自学。平时没事上github翻翻代码，上实验楼做点实验，再写点实验报告或者技术博客什么的，基本上大学还没毕业，你就已经找到一份不错的工作了。说不定再开个脑洞，写个小程序出来，自己就秒变扎克伯格了，想想还有点小激动呢，是不是明天就可以对两位爸爸说：



好吧，先不扯那么远的。相信很多开发者都有写技术博客的习惯，也有很多初学者会写一些学习笔记等或知识梳理的文章。当文章积攒到一定数量时，你一定想用某种方式把他们整理出来，或自己回顾，或与别人分享。而且形式要简洁！要高大上！才能符合程序员（danshengou）高贵的形象，那么今天的课程就将介绍一款神器，可以帮你轻松做出如下图一样优雅、简洁的电子书，并且可以发布到 gitbook.com 或者 GitHub pages上。完成后，每次在 GitHub 上更新电子书，都会自动同步到gitbook.com，并且自动编译成电子书。


下面就让我们开始今天的课程。

项目名称：

【基于 Gitbook 制作电子书】

项目简介：

本次实验将带你掌握Gitbook的简单用法，学会制作电子书籍，并且发布到 gitbook.com 或者 GitHub pages 上面。

涉及知识点：

  • Markdown 书写

  • Git 使用

  • Gitbook 基本操作

  • Github pages
