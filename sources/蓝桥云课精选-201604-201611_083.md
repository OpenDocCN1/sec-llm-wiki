REST（Representational State Transfer）是一种轻量级的 Web Service 架构风格，可以翻译成“表述性状态转移”，实现和操作明显比 SOAP 和 XML-RPC 更为简洁，可以完全通过 HTTP 协议实现，还可以利用缓存 Cache 来提高响应速度，性能、效率和易用性上都优于 SOAP 协议。

环信成立于2013年4月，是一家全通讯能力云服务提供商，产品包括全球最大的即时通讯云 PaaS 平台——环信即时通讯云，以及首创的全媒体智能云客服平台——环信移动客服。

而环信的服务器提端接口都是通过 REST 服务方式供的，REST API 基于最简单的 HTTP 协议，在各个编程语言中都提供了良好的支持。

调用 REST API，本质就是发送 HTTP 请求，所以我们可以采用多种方式进行调用，比如 Curl、 浏览器或者程序调用。比较常用的 HTTP 请求包括 HTTP GET 和 HTTP POST，但是在 REST 里边还经常用到 HTTP PUT 和 HTTP DELETE。

需要注意的是，环信的 REST API 都是基于 JSON 的，所以在构造 HTTP 请求的时候，需要在 HTTP HEADER 中指明：

| Header\_name || Header\_value || Description |
| --- | --- | --- |
| Accept || application/json || 服务器端返回给客户端的数据类型 |
| --- | --- | --- |
| Content-Type || application/json || 客户端发送到服务器端的数据类型 |
