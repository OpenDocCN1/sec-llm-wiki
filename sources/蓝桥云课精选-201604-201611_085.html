项目名称：

【 基于 Flask 及爬虫实现微信娱乐机器人 】

项目简介：

基于 Flask Web 框架开发的娱乐级别的微信公众号后台，学习并实践 python 编程，Flask Web 开发以及微信公众平台开发机器人的基本步骤。

涉及知识点：

  • Python

  • flask

  • 正则匹配爬虫

项目流程：

  • 微信公众平台开发基础：学习代码的运行以及对微信公众平台后台的对接。

  • 支持逆序自动回复：学习将得到的微信服务器传过来的文本消息，逆序回给微信服务器。

  • 实现笑话爬虫并自动回复：实现一个爬虫，将糗百网站的笑话爬取过来，并把爬取的数据按照上一节实现的方式回复给用户。
