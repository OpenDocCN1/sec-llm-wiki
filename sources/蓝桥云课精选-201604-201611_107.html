为什么参加 Workshop？


当你在实验楼做实验的时候：


  • 是否曾经因为基础太差无从上手？

  • 是否曾经遇到痛苦的 BUG 不知所措？

  • 是否曾经感觉枯燥孤独半途而废？


欢迎参加实验楼第一次线下 Workshop ——


  • 在这里，你将发现动手实践会让你学习上瘾，

  • 在这里，你将获得实验楼工程师的现场指导，

  • 在这里，你将与19位伙伴一起完成三个实验项目；


紧张的一天中，你将收获：


  • 6小时实验助教的项目指导

  • 一份记录你收获的 Github Pages 在线简历

  • 300 行 Python 3 代码经验

  • 三个独立完成的 Github 代码仓库
