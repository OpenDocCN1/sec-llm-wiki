**为什么参加 Workshop？**

  

当你在实验楼做实验的时候：

  

*   是否曾经因为基础太差无从上手？
    
*   是否曾经遇到痛苦的 BUG 不知所措？

欢迎参加实验楼第一次线下 Workshop ——

  

*   在这里，你将发现动手实践会让你学习上瘾，
    
*   在这里，你将获得实验楼工程师的现场指导，

*   三个独立完成的 Github 代码仓库
