随着网站用户量和内容量的增加，一直使用动态语言会对服务器和数据库存在很大的压力，因此在大中型网站对于网站优化越来越看重，动态页面静态化就是网站优化的一个大的方向。


网站静态化分为伪静态和纯静态，在纯静态中又分为全部纯静态和局部纯静态。


小编今天介绍的项目就是教你将 PHP 动态页面生成静态页面。


项目名称：


【PHP 动态页面静态化实战】


项目简介：


这个项目使用 PHP 内置的输出缓存机制将 PHP 动态页面生成静态页面。


涉及知识点：


  • ob 系列函数

  • PHP 连接数据库

  • PHP 查询数据库并输出到页面
