本次 Workshop 是实验楼主导的首次线下活动，旨在通过线下活动的形式，让参加的实验楼学员在 1 天的时间中，由实验楼CEO和工程师现场指导完成3个实验楼在线项目。



01

活动主题：


Python爬取网页信息系列实验


02

为什么参加 Workshop？


当你在实验楼做实验的时候：


  • 是否曾经因为基础太差无从上手？

  • 是否曾经遇到痛苦的 BUG 不知所措？

  • 是否曾经感觉枯燥孤独半途而废？


欢迎参加实验楼第一次线下 Workshop ——


  • 在这里，你将发现动手实践会让你学习上瘾，

  • 在这里，你将获得实验楼工程师的现场指导，

  • 在这里，你将与19位伙伴一起完成三个实验项目；


紧张的一天中，你将收获：


  • 6小时实验助教的项目指导

  • 一份记录你收获的 Github Pages 在线简历

  • 300 行 Python 3 代码经验

  • 三个独立完成的 Github 代码仓库


03

活动时间：


2016年9月24日 10:00 ~ 17:00  


04

活动地点：


成都市天府软件园E区E2栋12楼 实验楼办公室


05

活动须知：


每人费用50元，限额20人，参加活动请自带笔记本电脑。


本次活动适合计算机入门阶段，按照实验楼教程独立完成在线实验有困难的朋友，参加活动请自带笔记本电脑，且需要了解 Python 语言语法，推荐预先学习实验楼课程 《Python3 简明教程》 前12节。


06

实验列表：


活动中将在实验助教的协助下完成以下实验：


  • 实验一 在Github Pages上部署自己的简历

  • 实验二 Python3 实现淘女郎照片爬虫

  • 实验三 Python3 实现火车票查询工具

  • 实验四 挑战：获取在座所有同学的简历信息


07

实验助教：


  • 石磊（石头山）：实验楼CEO，实验楼156楼

  • 刘文进（FrostSigh）：实验楼工程师，实验楼88楼


08

日程安排：


6小时的动手编程实践，少量技术讲解，按照实验教程做项目，实验助教随时解决问题，现场指导。
