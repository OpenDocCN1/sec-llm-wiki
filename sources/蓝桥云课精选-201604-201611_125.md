# 14门Linux课程，打通你Linux的任督二脉！

Linux有很多优点：安全、自主、开源……，也正是这些优点使得很多人都在学Linux。

  

虽说网上有大把的Linux课程资源，但是对很多小白来说网上的课程资源比较零散并不适合新手学习。

  

正因为此，总结了14门Linux课程，有基础入门的、有进阶提高的、有实战项目的……适合各种Linux学习需求。

  

![](../Images/15c412023cf1cbf6fce1a6b852e6b957.png)  

  

ps.点击课程名称，即可查看该课程介绍~

  

# **1、**[**Linux 基础入门**](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=213368767&idx=1&sn=439376433e14510936452b9018838af1&scene=21#wechat_redirect)

  

该课程从Linux基础介绍到 Linux 基本操作，shell 环境下的常用命令等多方面都做了详细的介绍和讲解，非常适合新手入门Linux学习。

  

# **2、****[Linux命令实例练习](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932194&idx=3&sn=6e781a42cebdbeef0b5ba58e3d80ae52&scene=21#wechat_redirect)**

  

教程对常用的一些Linux命令都做了介绍和讲解，还有小例子，适合学过Linux基础入门课程后的用户练习各种Linux命令。

  

# **3、****[高级Bash脚本编程指南](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932164&idx=3&sn=6b294b253d515ed7df17058ff5c052ee&scene=21#wechat_redirect)**

  

这个课程将带你深入学习 shell 脚本。

  

# **4、****[正则表达式基础](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932123&idx=3&sn=1ae8abacc9ac2e3c3f81e9b25f11b84a&scene=21#wechat_redirect)**

  

这个课程在Linux Shell环境中学习正则表达式基本概念，并实践如何使用正则表达式对文本字符串进行处理。

  

# **5、****[Linux系统监控实战](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932060&idx=3&sn=45bc3012350ac3107b4d6b2da9d40bd9&scene=21#wechat_redirect)**

  

这个课程是教你熟练掌握Linux系统监控的常用命令及工具，适合系统及网络管理员学习。

  

# **6、****[Linux Web运维（Nginx）实战](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=405805704&idx=3&sn=db79b6dcb90461c5d355877ceac7d4ed&scene=21#wechat_redirect)**

  

课程主要介绍Nginx的部署、配置、优化及案例实战。

  

# **7、****[LAMP部署及配置](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932062&idx=3&sn=ab7c7d7095010a3885b6eda47c80574e&scene=21#wechat_redirect)**

  

LAMP（Linux- Apache-MySQL-PHP）网站架构是目前国际流行的Web框架，这个课程就学习它的环境部署与配置。

  

# **8、Linux系统编程**

  

这个课程讲解了 Linux 下的编程体验，并且涉及文件IO以及多进程等等。

  

# **9、****[Linux 防火墙技术](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932564&idx=3&sn=bfb17445d236947759a6c8d2c7195a2f&scene=21#wechat_redirect)**

  

这个课程带你认识防火墙，了解 iptables，并学会灵活运用。最后以 SYN flood、CC 攻击实例带你见证 iptables 保护的强大力量。

  

上面9门课程是基础介绍类的教程，下面介绍5个实战项目教程；

这是一个项目课程，教你实现自己搭建一台 Git 服务器。

# **12、****[Shell 脚本实现 Linux 系统监控](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932534&idx=3&sn=44d17bbc564720ee71e256fe09e7326e&scene=21#wechat_redirect)**

  

这个项目课程实现一个包含各种不同参数的 Shell 脚本，用来获取和监控 Linux 系统信息，并将该脚本加入系统环境中。实现过程中学习和实践 Shell 脚本编程及 Linux 基本信息和资源使用率获取。

# **13、Linux 系统搭建及配置 DNS 服务器**

  

这个项目课程教你在 ubuntu 系统环境下搭建一个简易的 DNS 服务器，你可以通过它来管理局域网的 ip 地址，更加方便理解和记忆。通过构建私有 DNS 服务器，来学习 linux 的运维管理， 并从中了解到一些关于的DNS小知识。

# **14、****[构建 ELK(+Redis) 分布式 Nginx 日志分析系统](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932354&idx=3&sn=f188d72a1990fe8111588abe98b54446&scene=21#wechat_redirect)**

  

这个项目课程带你学习并搭建 ELKR ( = Elasticsearch + Logstash + Kibana + Redis ) 一套完整的 Nginx 日志分析技术栈。
