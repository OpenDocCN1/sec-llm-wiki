项目简介：


Docker 的本质是使用 LXC 实现类似虚拟机的功能，进而节省的硬件资源提供给用户更多的计算资源。本项目将 C++ 与 Linux 的 Namespace 及 Control Group 技术相结合，实现一个简易 Docker 容器。

每个实验简介：


1）使用 Namespace 进行资源隔离


这个实验使用了 Linux 中的 Namespace 技术，对子进程中的资源进行了简单的隔离，让我们子进程中的 『Docker』容器具备了自己的进程空间以及自己的文件系统。


2）向容器提供网络访问


本节进一步引入了 CLONE_NEWNET 这个 Namespace 参数，并通过配置 iptables 配置宿主机防火墙规则，让我们的容器具备了访问网络的能力。


3）使用 Control Group 限制容器资源


这一节完成了对 CPU 资源的限制。此外，我们还可以对内存进行限制。
