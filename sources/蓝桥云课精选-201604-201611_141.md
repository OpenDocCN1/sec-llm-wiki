# **1、****[C++ 实现太阳系行星系统](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932336&idx=3&sn=70156ee6819987be077c96e3ad3e1914&scene=21#wechat_redirect)**

  

项目使用 C++实现 OpenGL GLUT 实现一个简单的太阳系行星系统，将涉及一些三维图形技术的数学基础、OpenGL 里的三维坐标系、OpenGL 里的光照模型、GLUT 的键盘事件处理。

# **2、C++实现运动目标的追踪**

  

这个项目是在前面一个项目的后续项目，利用 OpenCV 来实现对视频中动态物体的追踪。

  

# **3、****[C++ 实现银行排队服务模拟](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932430&idx=3&sn=0334345e99e438f3649ed4d8f34e098b&scene=21#wechat_redirect)**

  

项目使用 C++对银行排队服务进行模拟，以事件驱动为核心思想，手动实现模板链式队列、随机数产生器等内容，进而学习概率编程等知识。作为可选进阶，这个模型同时还能稍加修改的应用到 CPU 资源争夺模型中。

  

# **4、****[1小时入门增强现实技术](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932444&idx=3&sn=48c1a99e586c32a85b1903e251fb6db9&scene=21#wechat_redirect)**

  

项目利用C+＋，基于OpenCV实现一个将3D模型显示在现实中的小例子，学习基于Marker的AR技术。

  

# **5、****[100 行 C++ 代码实现线程池](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932466&idx=3&sn=c823eb31b9a40ce1acb6e0c0a1775bbd&scene=21#wechat_redirect)**

  

项目使用 C++ 及大量 C++11新特性设计并实现一个线程池库。

  

# **6、****[C++实现第一人称射击游戏](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932455&idx=3&sn=1400b8c34f054a7005d09c64b822105a&scene=21#wechat_redirect)**

  

项目使用C++和 OpenGL 实现一个第一人称射击类游戏，涉及键盘鼠标的处理、三维视角变换处理、素材加载渲染等。

用三段 140 字符以内的代码生成一张 1024×1024 的图片。

# **8、****[C++ 开发 Web 服务框架](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932556&idx=3&sn=f3de2f1fddaaf5f148394797aa2cf0a6&scene=21#wechat_redirect)**

  

服务器开发中 Web 服务是一个基本的代码单元，将服务端的请求和响应部分的逻辑抽象出来形成框架，能够做到最高级别的框架级代码复用。项目将综合使用 C++11 及 Boost 中的 Asio 实现 HTTP 和 HTTPS 的服务器框架。

  

# **9、****[C++ 打造 Markdown 解析器](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932539&idx=3&sn=e78df8c4b4b390c964390cd16fd37746&scene=21#wechat_redirect)**

  

Markdown 几乎成为了程序员编写文档的标配，Markdown 的相关语法简单，解析 Markdown 文本能够加深日后编写编译器中词法分析的理解，本项目将使用 C++ 实现 Markdown 解析器，并将解析的内容生成为 HTML。

# **10、****[C++ 实现高性能内存池](http://mp.weixin.qq.com/s?__biz=MjM5OTMxMzA4NQ==&mid=2655932477&idx=3&sn=f9dd02f23843988bacb40c0e005bd226&scene=21#wechat_redirect)**

  

获得内存池所分配的内存速度高于从堆中获得分配的内存的速度，一个长期稳定运行的服务在追求极致的过程中，实现内存池是必不可少的。和标准库中的默认分配器一样，内存池本质上也是分配器，该项目将设计并使用 C++实现一个高性能内存池。
