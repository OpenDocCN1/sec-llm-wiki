C++11 的出现及C++14 对 C++11的重要补充，让 C++ 这门古老的语言注入了新的活力。如果你还在使用传统 C++，打着 C++ 的名号写出 C 语言代码，请停下来。

  

小编今天介绍的教程将带领你快速上手 C++11/14 的重要特性。

  

**课程名称：**

  

【C++11/14 高速上手教程】

  

**课程简介：**

  

本教程共9个实验，从实战出发，带领你熟悉C++11/14 的重要特性，让你可以快速在实际开发中上手应用。 

  

课程主要对C++11/14 的相关特性做了一个较为全面的介绍，读者可以自行根据下面的目录选取感兴趣的内容进行学习，快速熟悉需要了解的内容。

  

**课程列表：**

  

![](../Images/041a8bd7d6a4f398c0bb4cfab882be9a.png)  

以上每一节内容呢，又从多个方面进行了详细的介绍，这些特性并不需要全部掌握，只需针对特定的应用场景，学习、查阅最适合自己的新特性即可（但总结部分依然给出了建议学习的特性）。

  

值得一提的是，本教程在介绍这些特性的过程中，尽可能简单明了的介绍了这些特性产生的历史背景和技术需求，这为理解这些特性、运用这些特性提供了很大的帮助。

  

**课程适合：**

  

已经熟悉了传统 C++ ，至少在阅读传统 C++ 代码上不具备任何困难。
