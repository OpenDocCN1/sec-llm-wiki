**项目名称：**

  

【C 语言实现聊天室软件】

  

**项目简介：**

  

本项目在 Linux 环境下使用 C 语言实现聊天室软件，学习并实践基本的 Linux socket 通信的相关技术，加深对 TCP/IP 协议栈的理解。

  

**项目列表：**

  

*   1）首先介绍了套接字联网基本知识；
    
*   2）接着讲解了聊天室服务器端程序的实现方法；
    
*   3）最后讲解了聊天室客户端端程序的实现方法；
