GDB, 是 The GNU Project Debugger 的缩写, 是 Linux 下功能全面的调试工具。GDB 支持断点、单步执行、打印变量、观察变量、查看寄存器、查看堆栈等调试手段。


在 Linux 环境软件开发中，GDB 是主要的调试工具，用来调试 C 和 C++ 程序。


小编今天介绍的课程就是教你了解GDB。


课程名称：


【GDB 简明教程】


课程简介：


本课程通过动手实验学习 Linux 上 GDB 调试 C 语言程序的基本技巧。


首先讲解了 GDB 的常用命令，然后通过对有问题的链表程序的调试来逐步实践挖掘程序 BUG 的过程。


涉及知识点：


  • Linux 环境下 C 语言的程序调试过程；

  • GDB 调试程序的基本步骤；

  • 链表程序 BUG 调试实战；
