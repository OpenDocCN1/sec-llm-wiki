# 程序员无趣？才不是嘞！！

如果可以给程序员打标签的话，或许「孤傲」「不善言谈」「无趣」「宅男」会成为他们在大众眼中最普遍的形象，但我们的程序员真的是这样吗？

  

或许吧，不过那只是茫茫猿海中的一部分，他们中的大部分其实是非常有情怀和创造力的一群人。

  

下文中的案例就是实打实的物证了。

  

### 1.

![](../Images/27acfd31c7f648e6ec32d22aea6db0b7.png)

  

还记得她吗？虽然现在已经看不到了，但这位被程序员们隐藏在淘宝 2013 版源码中的设计妹纸曾几何时是多少猿人心中的女神。

  

### 2.

![](../Images/cb4edb161e4798ae7a5a2e4f443544fe.png)

  

老虎机式的 I’m Feeling Lucky，Google 是一家由程序员驱动的公司不假，但不代表他们是无趣的。

  

### 3.

![](../Images/f0d8462d4ddce1621fe6121299fd6285.png)

  

在源码里藏招聘很多程序员都干过，但还能写得如此文艺怕是就不多了。

  

### 4.

![](../Images/240a6bc96b95290f52d1ca9ea76b67b2.png)

  

大费周章只为在标签栏里加入这样一句无卵用的文案，要的就是一份情怀。

  

### 5.

![](../Images/485d364c68cf1236dd8e5ba82a7a419a.png)  

  

这帮外国哥们是有多爱我们的国宝，连图片文案都配得如此贴切。

  

### 6.

![](../Images/2e8f559d7bf2dce1264d8272719adcdb.png)

  

程序员没有几个是不喜欢 Markdown 的，但连介绍页都是一样的风格那就是真爱了。
