**前言：**

  

题目所说的肉鸡不是吃的那种，而是中了木马，或者被一些人留了后门，导致自己的电脑成为被远程操控的机器，很多人把有WEBSHELL 权限的机器也叫肉鸡。

  

肉鸡可以是各种系统，如windows,linux,unix等；更可以是一家公司、企业、学校甚至是政府军队的服务器，一般所说的肉鸡是一台开了3389端口的Win2000、win2003、winxp等服务器或电脑，所以3389端口没必要开时关上最好。  

  

当然谁都不希望自己的电脑被他人控制，但是很多人由于对电脑的不熟悉，往往就导致自己的电脑是几乎不设防的，这就很容易被远程攻击者完全控制。

  

你的电脑就因此成为别人砧板上的肉，别人想怎么吃就怎么吃，肉鸡(机)一名由此而来。

  

小编今天介绍的项目课程就是教你实现一个可以管理多个肉鸡的反向 Shell，了解反向Shell的基本实现思路。

  

**项目名称：**

  

【Python3 实现可控制肉鸡的反向Shell】

  

**项目简介：**

  

该项目带领大家用 Python 实现一个可以管理多个肉鸡的反向 Shell，为什么叫反向 Shell 呢？反向就是肉鸡作为 Client 主动连接到我们的 Server 端，以实现对多个远程主机的管理！

  

**涉及知识点：**

  

*   socket服务端程序的编写方法
    
*   socket客户端程序的编写方法
    
*   利用Python的subprocess模块执行Shell命令
    
*   反向Shell的基本实现思路
