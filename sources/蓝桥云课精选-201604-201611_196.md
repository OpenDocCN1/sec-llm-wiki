当内部主机和私有 IP 地址过多时，通过搭建私有的 DNS 服务器，你可以把国外的一些网站 ip 地址放到自己的 DNS 服务器中实现科学上网。

  

因此，小编今天介绍的项目就是教你如何搭建以及配置DNS服务器~

  

**项目名称：**

  

【Linux 系统搭建及配置 DNS 服务器】

  

**项目简介：**

  

该项目是在 ubuntu 系统环境下搭建一个简易的 DNS 服务器，你可以通过它来管理局域网的 ip 地址，更加方便理解和记忆。通过构建私有 DNS 服务器，来学习 linux 的运维管理， 并从中了解到一些关于的DNS小知识。

  

**涉及知识点：**

  

*   学习 linux 搭建和配置 DNS 服务器；
    
*   了解关于 DNS 的原理；
    
*   学习关于 BIND 软件的安装和使用；
