Markdown 几乎成为了程序员编写文档的标配，Markdown 的相关语法简单，因此实现一个Markdown 解析器也不失为一个练手好项目。


小编今天介绍的课程就是教你用C++来打造一个Markdown 解析器。


项目名称：


【C++ 打造 Markdown 解析器】


项目简介：


本项目将使用 C++ 实现 Markdown 解析器，并将解析的内容生成为 HTML。而且解析 Markdown 文本能够加深编写编译器中词法分析的理解。


涉及的知识点：


  • 词法分析技术

  • 语法树

  • DFS 深度优先搜索

  • C++11

  • 使用指针进行字符流处理
