项目名称：


【Shell 脚本实现 Linux 系统监控】


项目简介：


该项目实现一个包含各种不同参数的 Shell 脚本，用来获取和监控 Linux 系统信息，并将该脚本加入系统环境中。实现过程中学习和实践 Shell 脚本编程及 Linux 基本信息和资源使用率获取。


涉及知识点：


  • Bash 脚本编程；

  • 学习如何获取 Linux 系统信息；

  • 学习如何实时获取 Linux 资源使用率；


项目功能需求：


  • 通过脚本查看系统的使用情况，实现对linux的系统监控。

  • 将写好的脚本加入系统环境，开启终端即可使用

  • 给脚本添加参数，可以实现不同的操作。
