项目名称


【基于 Flask 及爬虫实现微信娱乐机器人】

项目简介


项目是基于 Flask 开发的微信公众号后台，提供机器人聊天功能，涉及到微信的公众平台开发知识。


学习本项目的童鞋们，需要去申请一个微信的公众平台，最好是在能有自己的微信公众平台和80端口正常的IP地址情况下进行，可以即时看到演示效果。

涉及知识点


  • 微信公众平台参数配置；

  • Python 的编程基础；

  • Flask 的基本知识（看懂官网的几个小例子）；

  • Http 的基本知识（GET和POST请求，80端口）；

  • Web 服务网络知识；
