对租房的童鞋来说啊，最大的悲哀莫过于没钱自己租一套房子，要去租单间，那真是可怕啊！！！

  

最幸运的是可以和好友一起合租，快乐的犯二的生活在一起，如我一样。

  

可是，可是问题就来了，房子租在哪里比较方便？

  

当初和好友一起合租，为了租在一个大家上下班都方便而且距离工作地点最多最多1小时车程的范围内的房子，给我们两个累的。因为对周围交通环境不熟悉，又舍不得花中介费，花了几周都没找好，最后只能将就的选择了一个房子！

  

所以啊，租房最麻烦的莫过于对交通环境不熟悉却想找到上下班方便的房子啊！！想想当初找房，都是血泪史啊……

  

找到房子后，我总结了一下对于交通环境不熟悉却想找到距离工作较近、交通方便的房子的方法：

*   （1）找中介，给高额的中介费，然后提出你的要求，他帮你找，但是中介费舍不得啊，当然有钱除外；
    
*   （2）自己翻遍赶集、58以及其他租房APP，花时间费力气，而且说不定最后找到的还是中介，想想就悲哀；
    

  

显然，前2种方法对于我这种没钱的家伙来说，肯定是不行的，给出去的都是命啊！

  

于是乎，我就想要是有个按钮，可以就这么一按就非常清晰的给我展示距离工作地点1小时的车程范围是多大，这个范围内有哪些可租的非中介房子，这个范围内的公交路线有哪些，那该多好，多省事啊！

**项目名称：**

  

【高德API+Python解决租房问题】

  

**项目简介：**

  

该项目编写Python脚本爬取某租房网站的房源信息，利用高德的 js API 在地图上标出房源地点，划出距离工作地点1小时内可到达的范围，附上公交路径规划功能。  

  

**项目将解决的问题：**

  

*   学习了技术，增长了知识，就能找到好工作，找到好工作就能有钱。
    
*   通勤范围在地图上圈出，解决了对交通路线不熟悉的问题；
    
*   课程是单人版的，但代码中只要删掉一个语句就能当多人用了（但是路径规划的功能是只能给一个人用）。如果是直接拿来多人用的话，还是开多个页面比较好。
