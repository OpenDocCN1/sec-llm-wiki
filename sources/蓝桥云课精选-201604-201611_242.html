脚本可以帮助我们快速的完成一些繁琐麻烦的事情，因此很多开发者都会编写一些实用的脚本来提高工作效率。小编今天介绍的项目课程就是教你用Python来编写一些实用的脚本。


项目名称：


【使用Python 3编写系列实用脚本】


项目简介：


该项目是教你使用 Python 3 来编写3个实用脚本，实验的过程中能熟悉 Python 3 的使用，学习使用各种功能强大的模块。


项目列表：


该课程总共教你编写3个实用的脚本，具体介绍如下：

（1）Markdown to HTML

这个课程教你如何使用 Python 3 编写一个转换 markdown 为 HTML 的脚本文件。这个脚本能够进行批量处理操作，可以自定义 HTML 的 CSS 样式（默认没有样式），可以自定义输出目录（默认为 markdown 文件所在目录）。


涉及知识点：

  • Python 3 的模块的安装

  • Python 3 基础知识

  • 使用 os 模块进行路径相关的操作

  • markdown 模块的使用

  • 使用 BeautifulSoup 模块格式化 HTML

  • 命令行选项的实现


（2）文本文件编码检测与转换

是否遇到这些问题：想检测文本编码信息却没有办法；打开文本文件却发现中文乱码。这个实验教你编写一个 Python3 脚本来解决这些问题！这个脚本不仅能批量检测文本文件的编码信息，还能批量转换到任意编码，再无乱码之忧。

在本实验中还会使用到 argparse 模块处理命令行参数，完成本实验后，argparse 模块将成为你的一把利器。


涉及知识点：

  • Python 3 的模块的安装

  • Python 3 基础知识

  • argparse 模块的使用

  • chardet 模块的使用


（3）文件校验

本实验将会编写一个文件校验工具，它利用 md5 和 sha1 摘要算法来比较文件，并且这个文件校验工具能完成文件与文件、文件与摘要字符串、摘要字符串与摘要字符串的比较。


涉及知识点：

  • Python 3 基础知识

  • hashlib 模块的使用
