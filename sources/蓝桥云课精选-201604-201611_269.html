场景引入：


端午节当天，某个银行从早上八点开始服务并只服务到中午十二点就停止营业。假设当天银行只提供了 w 个服务窗口进行服务，问：

  • 平均每分钟有多少个顾客抵达银行?

  • 平均每个顾客占用服务窗口的时间是多少？


那么，小编今天介绍的这个项目课程就可以带你解决以上两个问题！


项目名称：


【C++实现银行排队服务模拟】


项目简介：


准确的说该项目是：利用C++ 从实现银行排队服务到 CPU 资源争夺模拟——银行排队系统的设计与建模；


项目使用 C++对银行排队服务进行模拟，以事件驱动为核心思想，手动实现模板链式队列、随机数产生器等内容，进而学习概率编程等知识。作为可选进阶，这个模型同时还能稍加修改的应用到 CPU 资源争夺模型中。


课程列表：




涉及知识点：


  • OOP 编程思想

  • std::rand() 函数原理

  • 概率编程

  • 排队理论

  • 链式队列数据结构及其模板实现

  • 事件驱动的设计

  • 蒙特卡洛方法

  • C++ 动态内存管理和设计理念

  • CPU 资源争夺模型

  • 时间片轮转调度
