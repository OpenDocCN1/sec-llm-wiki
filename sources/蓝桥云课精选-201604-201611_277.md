一般在学完理论基础知识之后，都需要找一个项目把所学的知识加以应用。小编今天介绍的项目课程是教你用Java语言来实现一个电子通讯录，非常适合有Java基础的小伙伴。

  

**项目名称：**

  

【Java实现电子通讯录】

  

**项目简介：**

  

该项目采用简单的 MVC 框架开发一个 Java Web 通讯录应用，学习并实践如何使用 Vaadin 实现界面，及使用 Eclipse 进行 Java Web 开发的基本流程。可以实现对现有联系人信息的显示，实现增加新的联系人。

### **涉及知识点：**

  

通过该项目可以学习并实践以下知识点：

*   Java Web 开发基本流程
    
*   Eclipse 开发 Web 应用的操作方式
    
*   Vaadin Web 框架基本用法
    
*   Java容器
    
*   Java同步
    
*   异常处理
