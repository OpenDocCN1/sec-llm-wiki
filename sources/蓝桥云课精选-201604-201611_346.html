项目名称：


【Node.js实现私人笔记】


项目简介：


该项目通过使用 Node.js 及与其配合良好的 web 应用框架 Express 搭建服务端，配合 mongoDB 存储数据，使用 ejs 模板渲染前端页面的方式完成一个简单的私人笔记应用，每个注册用户可在自己的私密空间中书写自己的心情和感悟。


项目的主要功能：


  • 注册；

  • 登录；

  • 发布笔记；

  • 笔记列表；

  • 笔记详情；

  • 退出登录。


项目开发思路：


根据项目需求，我们明确了使用Node.js、Express搭建服务端，用mongoDB 存储数据，因此主要的开发思路就三步：


1）搭建框架并连接数据库；

2）逻辑功能的实现；

3）路由限制；
