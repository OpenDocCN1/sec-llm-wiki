Java 8是近年来一个Java编程语言发行版本，由Oracle 2014年3月发布。该版本为Java带来许多新特性，是一个具有重大改变的版本。 小编今天介绍的课程就是带你学习了解Java8的一些新特性。

  

**课程名称：**

  

【Java 8 新特性指南】

  

**课程简介：**

  

该课程分为4个实验，分别介绍了Java8中的一些新特性。

  

本课程适用于Java初学者或者是具有一定编程经验的开发者，学习该课为自己的技能升级打补丁。

  

**课程列表：**

  

*   **第一节讲解了如何使用Lambda表达式和方法引用。**Lambda大概是使用Java 8版本编程最常涉及到的一个技巧，建议在适用的场合多用它代替之前的习惯写法。
    
*   **第二节介绍函数式接口、默认方法、Optional三个新特性。**针对每个特性，我们都提供了一个例子供你学习。
    
*   **第三节讲解如何使用Stream。**Java 8 引入了Stream（流式操作），你可以通过该操作实现对集合的并行处理和函数式操作。Collection是一种静态的内存数据结构，而Stream是面向计算的。
    
*   **第四节讲解如何使用新的Data/Time API**，以及如何使用Java 8内置的Base64编码相关API。
