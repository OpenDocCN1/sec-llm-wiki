React是现在较热门的前端框架，起源于 Facebook 的内部项目，因为该公司对市场上所有 JavaScript MVC 框架，都不满意，就决定自己写一套，用来架设Instagram 的网站。做出来以后，发现这套东西很好用，就在2013年5月开源了。

  

由于 React 的设计思想极其独特，属于革命性创新，性能出众，代码逻辑却非常简单。所以，越来越多的人开始关注和使用，认为它可能是将来 Web 开发的主流工具。

  

很多小伙伴呢也想了解React框架，但是好的 React 教程却不容易找到，大都不太系统，或者没有好的项目可以用来实战React。

  

小编就介绍4门课程，有基础，有实战项目，主要是希望给那些想了解React的小伙伴一些学习参考。

  

![](../Images/a2672219bca31083dedaa90f4dc6ce4b.png)  

  

**课程名称：**

  

**【React 基础实例】**

  

该课程是React 的基础入门课程，介绍了基础知识点，最后结合各个知识点制作完成一个简单的 tab 组件。

  

**【Meteor+React实现Todo应用】**

  

该项目参考Meteor官方教程编写。通过Meteor和React实现一个Todo应用，学习Meteor基础和React基础。

  

**【基于Koa.js和React开发应用】**

  

该项目是Koa.js结合React开发Web应用。Koa.js提供API服务，React渲染UI组件，前端路由通过React-Router管理。工具方面，使用Babel支持ES6最新语法，使用Gulp和Webpack自动化编译JavaScript。

  

**【Meteor+React实现微博系统】**

  

该项目使用Meteor和React实现一个简单的微博系统。通过React构建UI组件，通过React-Router管理页面路由，Meteor提供数据处理服务。适合对Meteor和React有一定了解的同学学习。

  

**在线开发环境：**

  

以上4门课程都可以在实验楼上进行学习，不但提供了课程文档，而且提供了在线开发环境，因为我们深知动手对于技术学习的重要性！

  

左边是课程文档引导你进行技术学习，右边是在线开发环境，你可以边看边动手跟着文档操作学习，这样可以更牢固快速的掌握React的应用，能够尽快上手React相关项目。
