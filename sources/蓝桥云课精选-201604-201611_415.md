# 年薪12W升至25W美元的非科班码农之路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwODM4NDM5OA==&mid=2247504076&idx=1&sn=aeeee674f4fa94507210fcc31b47ab51&chksm=c0c8512df7bfd83b1c4a4ad42af65bb36452959a409075d4bb7a234e18cae68c438ef33e6a3f&scene=126&sessionid=1681309765#rd](http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247504076&idx=1&sn=aeeee674f4fa94507210fcc31b47ab51&chksm=c0c8512df7bfd83b1c4a4ad42af65bb36452959a409075d4bb7a234e18cae68c438ef33e6a3f&scene=126&sessionid=1681309765#rd)

![](../Images/3872b34002f2fbd4d12c82b2f7eda373.png)

  

Haseeb Qureshi 是 Airbnb 的一名工程人员，在上个月他吸引了众多目光，因为他在博文中解释了他是如何在仅仅数周之内通过谈判将年薪由 12 万美元提升到 25 万美元的。

  

他有一个十分有趣的背景——他之前是一位有着英语学位的专业扑克玩家。尽管被最初申请的 20 份工作拒绝，但是 Qureshi 通过学习如何推销自己的方式奋力向前，最终获得了 8 个工作机会，这其中就包括谷歌、优步和美国著名商户点评网站 Yelp。

  

![](../Images/a8c047dad25001abf14f254b1cfb527c.png)

  

这个月早些时候，Qureshi 更新了博文，博文的内容是关于如何获得面试机会和找到理想工作的方法。

  

在本文中，我们整理了其中的要点。

  

寻找工作和谋求面试机会是一个数字游戏。你需要尽可能多地见更多的人，并且申请更多的工作。Qureshi 说道：“数量越多，机会才越大。”

  

![](../Images/6d7ebf17e4c4cf3f357c9b73c9afbddb.png)

  

因为人际网络的存在，这使得你入门变得十分容易。如果你畏惧人际网，还有一个简单的方式。Qureshi 说道：“你请别人喝咖啡。”

  

![](../Images/ff8d59b4fbc5ccff81ec0a3e31c29f35.png)

  

这就是说你要给你在技术领域遇到的每一个人买咖啡，咖啡总量可能数以吨计。这样做的目的就是接触到尽可能多的人。

  

![](../Images/5765ceaf41ac381b7be1d04edaf5ac41.png)

  

见到技术领域核心人员的其他方式：参加一些会晤、当地会议或是研发人员会议，你甚至还可以通过邮件或信息联系这些人。

  

![](../Images/c0204671a0298c9115f8fc626af17e60.png)

  

找人并没有任何捷径可言。你可以将你知道的人列在一个表中。具体到每一个公司，你可以看看自己有什么个人关系。之后再联系相关个人。提出和相关人员约谈，并买咖啡请别人喝。

  

![](../Images/de991538c4faec9d500d1be1cd308d32.png)

  

一旦你见到了想要工作领域的相关人员，你要尽可能多地了解这个人，并且尽可能多地了解这个人所在的公司、行业和相关技术。

  

![](../Images/6ccc20ada784348faa05ba0093665652.png)

  

但是在这个时候不要提出寻求工作。你仅仅应该在这个机会中问更多关于工作本身的问题。Qureshi 将这些会谈称作“信息面试”。

  

![](../Images/b267e66415baba2818142d6a4d619c4d.png)

  

在你离开之前，你要问问：“您认为我还应该和谁聊聊？”这样做的目的是让每一次会谈都能引发至少一次更多的接触。

  

![](../Images/7112845486dc353742f9f4bf31ae1c97.png)

  

之后你要做的就是不断重复这样的周期：买更多咖啡，问更多问题，寻求更多的接触。不过切记在这些会谈中不要提及寻求工作或是推荐工作。 Qureshi 说道：“如果这一周期你重复的次数足够多，会有人最终提出为你引荐工作。”

  

![](../Images/93f428d414eef624efcea1a9fe3db6a9.png)

  

Qureshi 说：“这或许听起来很奇怪。但是研究表明这样做是获得工作最为有效的方式。并且最终这会是你获得关系网之外推荐的最为有效方式。”

  

这种方法之所以能够奏效是因为人们对寻求工作十分厌恶。Qureshi 把这称为“信息面试的力量”，在谈话过程中你谈论的不是自己，而是他们。人们喜欢谈论自己的事情，这会让他们自愿为你引荐工作。

  

![](../Images/051a7881ef1fad3c13af938204c7783f.png)

  

对于工作简历，记得有一页纸就足够了。你要确保在简历中重点突出一些专业性的东西。并且千万不要有拼写错误。

  

![](../Images/b97ba48a82076d73d6542abbae042952.png)

  

试试所有找工作的平台，譬如 Triplebyte、AngelList 或是 Hired。完善你的 LinkedIn 和 GitHub 简历。

  

![](../Images/86075083d6798f99d0592dfbbf3a0af8.png)

  

你每天都要向固定数量的公司提交申请。中小型企业更可能对你进行回复。这样做的目的是为你积攒尽可能多的面试经验，并且最理想的结果是得到一份工作。在你获得一份工作邀请后，你进入其它工作的机会就会大大增加。

  

![](../Images/1f3414942a0344159ef563bbd750884e.png)

  

努力学习。在博文中 Qureshi 分享了很多学习资源和工作技巧。Qureshi 表示：“你需要头悬梁，锥刺股。”

  

![](../Images/bd9224249fcf30cc1ac955fc32c76602.png)

  

谋求工作的过程会让人感到十分崩溃。所以你要确保你饮食健康并且睡眠充足，同时你需要耐心等待结果。Qureshi 说道：“耐心等待结果，同时更为重要的是照顾好自己。”

  

![](../Images/235b3457d3de3d52c360584d5fbafbbd.png)

  

把所有这一切都视为学习的机会，并设立具体的现实目标。

  

![](../Images/04432871f4a23e2886e93b9445df1017.png)

  

最后，记得要始终保持乐观积极的心态
