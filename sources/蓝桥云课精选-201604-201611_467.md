# 游戏中学会撸代码：这些编程学习网站不容错过

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwODM4NDM5OA==&mid=2247504059&idx=2&sn=f1ee979b8b36120b3eb0e51939dda2c8&chksm=c0c8515af7bfd84c59f9f8f00098d2ce0a7cfdb90ca157497e84fe9bbf7df9d1a5afe3d06af0&scene=126&sessionid=1681309766#rd](http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247504059&idx=2&sn=f1ee979b8b36120b3eb0e51939dda2c8&chksm=c0c8515af7bfd84c59f9f8f00098d2ce0a7cfdb90ca157497e84fe9bbf7df9d1a5afe3d06af0&scene=126&sessionid=1681309766#rd)

![](../Images/7cd6353527545ef4ff11e8d19ecadc8b.png)

  

下面这些网站是从200多个游戏编程网站选出的12个网站，你可以通过下面的网站在游戏中学习编程。

  

当然这些网站都是免费的，Mybridge A.I\[1\]也评估了这些，这些网站可以帮助喜欢编程的人员学习编程语言，如JavaScript、java、python，PHP，C #等。

  

### **CodinGame**\[2\]

  

在玩这款游戏时会遇到许多有趣的问题，支持诸多编程语言。

  

![](../Images/0addc434c72e6ce52296b8b85fb0cf88.png)

  

### **Code Combat**\[3\] 

  

Code Combat主要是面向在校学生的一个学习平台，同时也是一个社区项目，有很多志愿者来维护这个平台，在这里可以学到有关java、JavaScript、Python、Lua、CoffeeScript的相关知识。

  

![](../Images/588a3ad583d92fa989b90d372a622fcc.png)

###   

### **Streeps**\[4\]

  

玩这个游戏可以学习到有关 JavaScript知识，同时该游戏也是面向学习编程语言的人员的第一款MMO沙盘游戏。

  

![](../Images/9370418b147fd604767b9b2f82628594.png)

###   

### **Check iO**\[5\]

  

Check iO 是一款网页游戏，你需要利用Python来解决问题。

  

![](../Images/576e8993ea39aeca230776f30a84a141.png)

###   

### **Vim Adventures**\[6\] 

  

玩这款游戏可以学习到Vim相关知识。

  

![](../Images/59fc6c75b8a22a3e777675d21af754d8.png)

###   

### **Cyber DoJo**\[7\] 

  

这款游戏主要可以学习到有关JavaScript、java、python、PHP、Ruby知识。项目地址：点击我

  

![](../Images/19c7afd5611e4321d5e4625180621cd2.png)

###   

### **Code Monkey**\[8\]

  

这款游戏主要内容就是抓香蕉，在这个过程中可以学习到编程知识，可被用于教学使用（此部分收费）。

  

![](../Images/ac1678f719155b0efbf472d949fed331.png)

###   

### **Elevator Saga**\[9\] 

  

这款游戏的第一个挑战就是在15秒之内送走15个人，一起来试试吧。项目地址：http://github.com/magwo/elevatorsaga

  

![](../Images/7181f7864bd270bca95891ff7e949604.png)

###   

### **Codewars**\[10\]

  

一款编程挑战游戏，支持 JavaScript、 Python、 C#、 Java、 Python等语言。

  

![](../Images/2e03c461fa1a23ac8bfbd634f16a6470.png)

###   

### **Ruby Quiz**\[11\]

  

这款游戏主要适合Ruby编程语言挑战，目前这款游戏有156 个测试环节。

  

![](../Images/2843b79d9a6c19bbc035a9afefeffa81.png)

###   

### ** git-game**\[12\]  

  

这个游戏可以被看成是一个基于终端的游戏（ git scm），使用git命令找到“线索’,最后解决问题。

![](../Images/f5fde2bbcbdf0f1a3a5b32838532833a.png)

###   

### **Hacker Org**\[13\]

  

这款游戏可以被看成一系列的挑战，你需要破解一系列的密码才能最终翻版。

  

![](../Images/d1e65974b1ed00847d2d77089c8846f5.png)

  

那么感兴趣的小伙伴赶快去一试身手吧。。。。
