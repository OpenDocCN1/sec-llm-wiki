# “实验楼”在线实验平台在计算机教学中的应用分享

近两年计算机类MOOC发展迅速，很多高校推出优质的MOOC课程，或以SPOC模式做混合式教学，中文讲授的计算机类MOOC选修人数已超400万人次。但计算机是门实践学科，实验环节必不可少，如何在新的教学模式下，让学生能高效的实操练习，一直是老师所关注的。

为此，中国高校计算机教育MOOC联盟组织了一场“面向计算机类MOOC的大规模在线学习支撑工具”研讨会，实验楼联合创始人石伟在会上做了“计算机大规模在线实验”的主题报告，分享了“实验楼”网站在计算机教学中的应用，引起到场参会的200多位计算机教师的广泛关注。

![](../Images/997819634db7bb485a0f606c3198409c.png)

**实验楼是一个计算机在线实验平台，为学生及在职人员提供IT技术教程及在线实验环境，帮助用户通过在线实验的方式学习IT技术。实验楼网址：https://www.shiyanlou.com/**

  

网站上线一年多来，已有21万用户注册学习，公开的计算机实验课有1000多个实验，用户每个月的在线实验时间超过10万小时。

  

在服务好C端用户的同时，实验楼也在为高校教学、计算机MOOC提供在线实验服务，探索计算机教学模式的创新。

**为什么需要在线实验？**

  

企业招聘技术人员时考察的重点是项目实践经验和动手能力，上机实验已成为计算机教学的核心环节。

  

在高校传统实验教学中，学生需分时段在机房完成实验，实验环境互相影响，结果不易保留。老师无法监督学生实验过程，防止作弊，同时缺乏实验课件资源，很难引导学生实践最新技术，完成较大型的项目练习。如果学生本地搭建环境，费时费力，且信息安全、云计算大数据等热门技术，本地资源很难支撑。

  

**在线实验可以让学生随时随地动手实验，提高学习效率，开放的实验课程库也让学生实践最新技术更加便利。**

    

对于计算机MOOC，视频课程因缺乏在线的交互练习，学生完课率较低。实验作业环节，主要由学生线下完成，线上提交代码，教师组织学生互评或者通过脚本评测，无法保证过程和结果的真实性。

  

**在线实验结合计算机MOOC可以为学生提供完整的在线学习体验，老师可以获得真实学习效果反馈。**

    

**实验楼在线实验平台是如何设计的？**

  

实验楼为每个学生提供了免费的在线实验机，同时和高校教师、企业工程师一起制作全面的计算机实验课程库。

  

**学生在实验楼1秒即可启动一个已配置好实验软件的实验环境，省去本地搭建的麻烦，整个实验过程中的代码可以随时保存到云端代码库。**

  

系统会完整记录学生的实验过程，包括实验时间、敲代码的时间、实验截图、实验次数等数据，自动生成实验报告并评估实验过程的勤奋度，为老师评分做参考。

**在线实验应用：结合教学**

  

实验楼的在线实验课有公开课和私有课两种，对应着MOOC和SPOC教学形式。公开课所有用户都可学习，私有课一般由高校教师为自己的学生开设，加入需要邀请码。

  

教师可以发布私有课或使用公开课做翻转教学，在线管理学生代码、实验报告。发布课程只需制作实验文档，实验楼提供课程配套的在线环境。

    

截止2016年4月高校教师在实验楼发布的实验课已有312门，来自清华、中科大、哈工大、烟台大学、北京电子科技学院、辽宁师范等50多所高校。其中由SEED项目组授权制作的SEED系列信息安全在线实验，不到一年时间已有2万多名在校学生在线实验练习。

**在线实验应用：结合MOOC**

  

实验楼已为网易云课堂等MOOC平台的《操作系统原理与实践》、《Linux内核分析》、《软件工程》等课程提供了在线实验支持，学生在MOOC平台看视频，在实验楼完成实验练习，数据及实验报告会统一汇总给MOOC老师，帮助老师评分及改进课程内容。

  

在线实验环节的加入，也获得了MOOC师生的认可，曾有学生评价说：

我认为网易云课堂和实验楼系统的结合，对我的高级软件工程课程的学习起到了很大的帮助作用，不仅学到了相应的理论知识，而且也动手实践提高了代码的编写能力，希望这种模式能一直持续下去。

**在线实验应用：结合最新技术**

  

 IT技术更新快，关注和学习最新技术的学生在就业时会更有竞争力，实验楼联合企业工程师，一直在制作前沿技术实践课程，已上线Spark大数据、Docker、机器学习等技术。

  

2015年11月9号谷歌发布了TensorFlow人工智能学习系统，11月10号实验楼即同步上线了《TensorFlow入门课程》，介绍如何搭建TensorFlow实验环境并进行实践学习，提供配套实验环境，让国内用户可以第一时间实践新技术。

**未来：为IT人建设一座线上的实验楼**

  

随着技术的发展，计算机大规模在线实验的应用场景会越来越多，但在线实验作为一种新兴的实验教学方式，还有很多环节需要去完善，比如实验数据的挖掘分析、防止学生实验作弊、动手能力评估等领域需要更多的突破和创新。
