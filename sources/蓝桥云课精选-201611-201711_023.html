活动介绍

2017年已进入尾声，在咱们成都前端圈子，好像少了一些事情。对！大家应该是时候聚一聚，一起搞点事情了。搞什么呢？不用大家想了，我们已经准备好啦！

【2017成都WEB前端交流大会】 (https://web-conf.tk/) 是由freeCodeCamp 成都社区主办的一场大型前端技术交流大会，只要你对前端感兴趣，都可以免费参加哦。

(在过去的一年里，freeCodeCamp 成都社区已经成功举办了 30+ 次活动，受到大家的一致好评和热烈响应。)

这次活动是为了给成都的前端开发工程师、前端爱好者、技术爱好者以及用户提供一个开放、互动、免费的交流环境，给成都前端圈带来一场饕餮盛宴。在此，我们向您发出诚挚的邀请，此次盛会期待您的参与！

这次大会邀请嘉宾来自成都企鹅医生、ThoughtWorks、乐车邦、数联铭品、国双科技、麦麦养老、新蛋科技、东方天呈等一大批成都本地的优秀企业前端领域大咖，大会秉承高标准、高质量等特色，聚焦前端行业最前沿技术，碰撞切磋技术火花。

  • 活动时间：2017年11月19日，9：00 - 17：30

  • 活动地址：四川 成都 高新区天府五街200号菁蓉国际广场6栋A区1-2层

  • 报名地址：http://cn.mikecrm.com/rdVltvT

说明：

  • 活动免费，想要参加的小伙伴先填写表单报名即可，到时候入场是需要签到入场呢；

活动主题

本次活动共有7个主题分享，分别如下：

【一个Node模块的自我修养】

  • 分享嘉宾：陈洋彬

作为一个“全干”工程师，与你朝夕相处的Node模块，说简单可以简单到一个index.js和一个package.json，说复杂也可以复杂到必须引入工程化的理念来管理。本分享来一起探讨下一个开源Node模块，所应该考虑的目录结构、代码检查、单元测试、基准测试、持续集成、自动构建、版本发布、变更记录等等这些需求，如何高效、规范的去实现。

【轻量级 Web MVVM 引擎的实现】

  • 分享嘉宾：石垚

只依赖 HTML 5、JS (ES 5) 的纯异步加载、声明式的 MVVM 引擎，它的简洁用法与内部实现。

【h5跨平台代码解决方案】

  • 分享嘉宾：廖伟

乐车邦创业阶段，前端开发人数相对较少，但是平台众多，常用的如: 浏览器，乐车邦App,微信公众号网页版本，微信小程序。还有不计其数的定制化流量平台，如： 手淘，百度地图，汽车之家，百度糯米，58到家，新美大等等，虽然渠道众多，但是业务流程相对统一，如何利用一套h5代码解决多终端运行问题成了前端重中之重。

【Vue开发那些事】

  • 分享嘉宾：胡敏

通过对Vue项目开发中遇到的部分通用问题进行分解，探索特定问题或场景的解决方案。从目录结构划分、业务封装等方面来提升项目的可维护性。

【大数据可视化之美】

  • 分享嘉宾：董涛

如何让繁杂的数据以最简最直观的形式呈现在用户的眼前？数据可视化真的那么高不可攀吗？今天就让我们来聊聊大数据可视化的常用技巧和常用算法吧！

【React 组件化通用模式】

  • 分享嘉宾：卢林

通过 React 项目的开发过程以及多个框架的使用，提取组件化开发的通用思路，对组件化、组件容器化以及微服务前端开发方式的一点思考。

【Angular：挣脱舒适区的枷锁】

  • 分享嘉宾：余泽江

作为一个大而全的开发平台，Angular 团队提供了完善的开发环境：各类功能库、命令行工具、IDE 集成、移动端支持等等。然而，原生支持的完备性也为部分 Angular 开发者建立起了狭隘的舒适区，使得一些人放弃了探索，把官方支持当作了 Angular 的一切，自身沦落到日复一日调试 Component 和 Service 的搬砖工作中。其实，在 Angular 官方舒适区之外仍然存在很大的世界。比如我们可以使用 Webpack 之外的工具构建出比 jQuery 更小的完整应用，可以动态加载任意远程组件而无需统一打包，可以在 AOT 编译下实现运行时动态拼接视图...本次分享将会带来舒适区之外的无限可能。
