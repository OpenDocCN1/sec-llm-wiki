一、《Go语言开发在线商城》

课程作者：穿着女装写代码

课程简介：课程从搭建一个简单可用的例子开始，让你掌握go和react+redux等前后端主流技术。最终使用 Go 语言和React ，完整开发一个在线购物商城网站，包含用户、购物车、订单管理、评论与点赞、购买等功能模块；同时详解利用事件驱动模型，来解决秒杀活动中高并发库存锁定问题、防止api接口被非法调用、实现redux管理订单状态、cps编程模型实践等内容。框架完整，设计细节清晰，助你快速成为全栈工程师。

课程列表：

课程链接：https://www.shiyanlou.com/courses/896


二、《kafka代码实战--让你全面学习Kafka》

课程作者：李登峰

课程简介：本训练营目标是以Java代码实战的方式学习Kafka。包括Kafka的安装配置、Producer API的使用、Consumer API的使用以及与第三方框架(Flume、Spark Streaming)的集成开发。对在大数据项目中经常用到的Kafka关键知识点，进行全方位、源代码级别的学习，使学员深入理解Kafka的内部机制。

课程列表：

课程链接：https://www.shiyanlou.com/courses/859

一、《Spark 自定义 UDF 分析 Uber 数据》（限免中）

课程作者：yoCat

课程简介：在本课程中，你将了解如何利用 SQL Context 及相关的 API 进行统计分析。最后将通过一个Spark自定义 UDF 分析 Uber的实例，进一步学习如何利用 Spark SQL 分析数据。

本课程难度为一般，属于初级级别课程，适合具有 Spark 基础的用户，学习 Spark SQL 的基础知识。

知识点：

  • SQL Context

  • 自定义 UDF 函数

  • SQL 语句

课程链接：https://www.shiyanlou.com/courses/851


二、《R 语言实现股票数据的预处理及分析》（限免中）

课程作者：soorhp

课程简介：本实验是以几支股票数据作为分析背景，股票数据如何从雅虎财经板块上获取，并观察股票每日价格和成交量数据开始，接着计算某一支股票数据中比较重要的日度收益率。然后通过各种股票线图进行技术分析，最后在一支股票的基础上同时分析多支股票的成交量，涨幅时间点，最后得出它们之间的相关性等数据特征。

知识点：

  • 股票数据抓取

  • 股票数据线图绘制及技术分析

  • 股票日度收益率计算

  • 多支股票的相关性

课程链接：https://www.shiyanlou.com/courses/897


三、《基于R语言的多元线性回归--我国经济增长的定量研究 》（限免中）

课程作者：实验楼HPP

课程简介：经济增长一直以来都是我国宏观经济政策的目标之一，研究影响经济增长的因素对促进我国经济快速发展有着重要意义。本实验运用 R 语言编写代码拟合多元线性回归模型，对模型拟合结果进行诊断，即对假设前提进行检验，并选择最优模型，最终进行区间预测，定性的研究影响我国经济增长的因素。

知识点：

  • 多元回归模型的理论基础

  • 多元回归模型的拟合

  • 多元回归模型的诊断

  • 多元回归模型的最优选择

  • 多元回归方程的解释

课程链接：https://www.shiyanlou.com/courses/894


四、《python 二手房信息爬取与数据呈现》

课程作者：LOU810221730

课程简介：本课程以链家的二手房网站为目标，使用python爬取链家官网在售的二手房信息，并且使用matplotlib 绘图包对爬取的信息进行分析，绘制简单的图表。

知识点：

  • 爬虫的基本原理

  • BeautifulSoup 库的基本使用

  • csv 文件格式使用

课程链接：https://www.shiyanlou.com/courses/869


五、《python 实现简单邮件客户端》

课程作者：LOU810221730

课程简介：本课程将利用 python 标准库实现一个简单邮件客户端，实现对 qq 邮箱的登陆，发送格式简单的邮件，以及接收邮件。

知识点：

  • 邮件系统的组成

  • pop 协议

  • imap 协议

  • smtp 协议

课程链接：https://www.shiyanlou.com/courses/884
