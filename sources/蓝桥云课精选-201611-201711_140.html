一、《Github 快速上手实战教程》

课程作者：c0hb1rd

课程简介：本次课程讲的是在实验楼的在线实验室中，如何使用去管理在实验室中使用的代码、配置、资源等实验相关文件，怎样去添加、同步和下拉在远程仓库中的实验文件，以此来维持自身的实验进度。

知识点：

  • SSH 公私钥的基本使用

  • Github 的基本使用

  • Git 工具的基本使用

课程链接：https://www.shiyanlou.com/courses/868


二、《对英国房屋价格建模并预测 ---《量化金融R语言初级教程》》

课程来源：异步社区

课程简介：本实验将通过一些特定应用来介绍一些常用建模技术。首先，我们将考虑如何在 R 中存储和处理时间序列。接着，我们将展现如何将它用于建模和预测房屋价格。最后通过考虑长期趋势，使用协整的概念来改进基本的最小方差对冲比。本实验源来自异步社区的《量化金融R语言初级教程》第1章 ，感谢异步社区授权实验楼发布。

知识点：

  • 时间序列

  • ARMA 模型

  • 协整关系

  • 改进基本的最小方差对冲比

课程链接：https://www.shiyanlou.com/courses/882

一、《scikit-learn 实战之非监督学习》（限免中）

课程作者：huhuhang

课程简介：机器学习中，除了常见的监督学习（英语：Supervised learning）之外，还有一个非常重要的分支 —— 非监督学习（英语：Unsupervised learning）。本次实验将带你了解非监督学习，并学会使用 scikit-learn 解决非监督学习问题。

知识点：

  • 非监督学习概念

  • K-Means 聚类

  • 等等

课程链接：https://www.shiyanlou.com/courses/880


二、《决策树实战项目-鸢尾花分类》（限免中）

课程作者：huhuhang

课程简介：带你了解决策树的基本概念，学习决策树生成过程中的 ID3, C4.5 及 CART 算法及原理。最后通过 scikit-learn 提供的决策树算法完成鸢尾花分类实验。

知识点：

  • python2.7

  • Xfce 终端

  • ipython

课程链接：https://www.shiyanlou.com/courses/863
