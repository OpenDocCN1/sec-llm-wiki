**一、《Github 快速上手实战教程》**

![](../Images/d614ccc97a1d79181747ecf3567d7218.png)

**课程作者**：c0hb1rd

**课程简介：**本次课程讲的是在实验楼的在线实验室中，如何使用去管理在实验室中使用的代码、配置、资源等实验相关文件，怎样去添加、同步和下拉在远程仓库中的实验文件，以此来维持自身的实验进度。

**知识点：**

*   SSH 公私钥的基本使用
    
*   Github 的基本使用
    
*   Git 工具的基本使用
    

**课程链接：**https://www.shiyanlou.com/courses/868

  

**二、《对英国房屋价格建模并预测 ---《量化金融R语言初级教程》》**

![](../Images/7b7fa731c842be935440775b271421b0.png)

**课程来源**：异步社区

**课程简介：**本实验将通过一些特定应用来介绍一些常用建模技术。首先，我们将考虑如何在 R 中存储和处理时间序列。接着，我们将展现如何将它用于建模和预测房屋价格。最后通过考虑长期趋势，使用协整的概念来改进基本的最小方差对冲比。本实验源来自异步社区的《量化金融R语言初级教程》第1章 ，感谢异步社区授权实验楼发布。

**知识点：**

*   时间序列
    
*   ARMA 模型
    
*   协整关系
    
*   改进基本的最小方差对冲比
    

**课程链接：**https://www.shiyanlou.com/courses/882
