Python 实现轻量型 Web 框架

说到写框架的，大家脑海中第一个蹦出来的往往是“大牛”、“大神”这样的词汇，但写一个框架其实离我们并不遥远。这门训练营将手把手带你用Python实现一个轻量级的Web框架，造属于你的自己轮子，不仅装逼而且非常实用。

课程涉及一个 Web 框架的必备模块的设计到实现，包含 数据库模块，会话模块，异常处理模块，WSGI 模块，模版引擎模块，路由模块，视图模块，辅助模块。最后再使用实现的框架，开发一个 Web 应用程序来加深对 Web 框架 的理解和使用 Web 框架的开发流程，非常值得学习。


Flask + VueJS 全栈 Web 开发实战

本课程主要使用 Python 的 Flask 框架和 VueJS，通过两个实战项目——留言板项目和论坛应用的练习，让大家掌握 Flask + VueJS 进行 Web 开发的能力。其中论坛应用包含用户注册激活、后台管理、Markdown 支持、帖子分类以及前台的展示等功能。

课程作者是实验楼新晋网红——protream，同时也是实验楼的后端高级工程师和《 Python3 实现火车票查询工具》、《SQLAlchemy 基础教程》课程的作者。购买课程的人可以加入私有群，享受交流、答疑的服务，同时和这位小哥哥近距离接触~


kafka代码实战--带你深入理解Kafka

本训练营目标是以Java代码实战的方式学习Kafka。包括Kafka的安装配置、Producer API的使用、Consumer API的使用以及与第三方框架(Flume、Spark Streaming)的集成开发。对在大数据项目中经常用到的Kafka关键知识点，进行全方位、源代码级别的学习，使学员深入理解Kafka的内部机制。


Go语言开发在线商城

训练营主要使用 Go 语言和React 打造一个在线购物商城网站，将实现用户模块、购物车、订单管理、评论与点赞、购买等功能模块。同时还将详细讲解如何利用事件驱动模型来解决秒杀活动中高并发库存锁定问题和如何防止api接口被非法调用等设计与实现。

课程将从搭建一个简单可用的例子开始，逐步实现各个功能模块，让你同时学习go和react+redux前后端主流技术，培养架构思维，快速成为全栈工程师。


Vue.js+Koa.js+MongoDB打造“什么值得买”网站

本训练营使用 Vue.js+Koa.js+MongoDB 实现一个类似于“什么值得买”的网站。

前端页面使用 Vue.js 实现，主要学习 Vue.js 技术栈的使用，主要使用 vue+vue-router+vuex 等技术。服务器端使用 Node.js 实现的一个 web 框架 Koa.js，主要学习基于 Koa.js 的 Web 开发。同时使用 MongoDB 做数据存储。

实现的功能模块主要有：用户管理、商品分类管理、商品标签管理、商品管理等。


React+Express+MongoDB 实现网易云音乐

网易云音乐作为一款曲目齐全，操作方便，用户体验高的的音乐产品，越来越受欢迎。本训练营将使用 React 实现一个 网易云音乐，实现项目从设计到实现的完整流程。

项目包含 前端界面模块、Node模块、MongoDB模块，前端界面模块又包含React组件开发、React-Router路由配置、Redux状态管理等。通过这个前端+后端的完整项目，可以大大锻炼你对React全家桶的熟练度。


Python 数据分析入门与进阶

数据分析在这个时代有多重要、多值钱，相信不必多说了，这本训练营中，我们就将学习怎么样使用 Python 进行数据分析。课程将从数据分析基础开始，一步步深入讲解。从 Python 的基础用法到数据分析的各种算法，并结合各种实例，讲解数据分析过程中的方方面面。
