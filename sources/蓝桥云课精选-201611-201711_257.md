## 

本周最热的话题仍然是WannaCry。这个感染全球23万台电脑的勒索软件，到目前收取了多少不义之财呢？本文就用爬虫来分析一下。

（文章来自实验楼用户「minfun」的投稿，如果你也有好的文章，欢迎给我们投稿啊）  

本周最热话题当属WannaCry勒索病毒，先来了解一下WannaCry，这是是一种针对微软Windows操作系统的蠕虫勒索病毒。2017年5月12日，使用它的大规模网络攻击发起，在150个国家超过230000台电脑感染，勒索者要求在比特币支付赎金。该病毒通过多种方法攻击传播，包括网络钓鱼电子邮件，将未打补丁的系统作为计算机蠕虫。

那么回到正题，你想知道该作者收到了多少比特币吗？本文从scrapy说起，通过抓取作者比特币地址信息获取其比特币收入。

首先，我们从逆向大牛那里拿到作者比特币的收款地址，

```
\[ '12t9YDPgwueZ9NyMgw519p7AA8isjr6SMw'

```

拿到地址之后我们可以通过blockchain.info追踪比特币交易记录

```

https://blockchain.info/address
```

将地址拼接就可以看到作者收到的比特币数量，如下图：

![](../Images/8279d739a4e7e095b644501c44bc8a50.png)

然后，如何获取比特币数量值？我们通过scrapy抓取网页，解析出我们想要的数据。打开 chrome开发者工具，将元素定位到Total Received对应的BTC，如图：

![](../Images/a47f8d9b064d2e0834875a98dc6c72d1.png)

通过css selector提取网页信息，获得BTC数量：

```
'#total\_received > font > span::attr(data-c)'
```

通过访问API可以得到当前1美元兑BTC数量：

```
https://blockchain.info/tobtc?currency=USD&value=1
```

这样我们就获取到了全部的数据信息。

那么如何编写爬虫？使用scrapy框架新建一个项目

```
scrapy startproject scrapybitcoin
```
