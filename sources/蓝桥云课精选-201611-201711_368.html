Beginning

Laravel是一套简洁、优雅的PHP Web开发框架。它可以让你从面条一样杂乱的代码中解脱出来，帮你构建一个完美的 Web App，而且每行代码都可以简洁、富于表达力。

自2011年问世以来，Laravel就是PHP领域最受追捧的一颗明珠。

他是为艺术家创造的Web框架：每一行代码都整洁、易读、便于管理；

他也是为建筑家创造的框架：他使PHP不再局限于前端，而是一个强大、健壮、可测试的系统工程。

毫无疑问，Laravel 是当今最受欢迎、最火爆、也是最现代化的PHP框架。他具备了 Rails 敏捷开发等优秀特质，并结合了 PHP 强大的扩展包（Composer）生态与 PHP 开发者。不管你是PHP新手，想独立开发一个网站却不知道选择什么框架；还是一名PHP老手，难以忍受Think PHP等落后框架的折磨，Laravel都是你最好的选择。

但Laravel虽然有各种好，学起来却不算容易。经常看到新手因为没有一个好的入门学习，而遇到各种奇奇怪怪的问题，如使用 Windows 作为开发环境导致 .env 加载错乱花了一个多星期 DEBUG 到白头发多了好几根。有时候可以在他们贴出来的代码中看到非常糟糕的编码习惯，如把业务逻辑写在 routes.php 文件里。如果在学习的一开始，有好的入门课程，很多这些弯路都是可以避免。

因此，国内最大的Laravel社区——「 Laravel China 」的创始人Summer和管理员Aufree合作出版了《Laravel 入门教程》一书（https://laravel-china.org/laravel-tutorial/5.1/about）。该书从实际项目出发，教你一步步构建一个类似新浪微博的应用，一方面把控了技术话题的数量，很好地照顾了新手；另一方面也兼顾实用性，让读者能真正从实战中学到技能。

很荣幸，实验楼得到了这个国内最有影响力的Laravel社区的授权，将本书结合实验楼的在线环境进行了改变，推出了「 Laravel 项目实战：仿新浪微博Web应用 」训练营。可以让你结合在线开发环境，随时随地，快速掌握 Laravel 的系统知识。

这可能也是第一个有线上配套实验的Laravel教程。如果你想成为一名PHP Web 艺术家，那来实验楼就对了！
