> ****「 ********大数据带你看穿航班晚点的套路 ********」****

![](../Images/efb5b7d329b5abb4a7e101b69dd63362.png)

> “我们很抱歉地通知您，您乘坐的由XX飞往XX的XXXX航班延误。”

相信很多在机场等待飞行的旅客都不愿意听到这句话。随着乘坐飞机这种交通方式的逐渐普及，航延延误问题也一直困扰着我们。航班延误通常会造成两种结果，一种是航班取消，一种是航班晚点。

在本课程中，我们将通过Spark提供的 DataFrame、 SQL 和机器学习框架等工具，结合数据可视化技术，对航班起降的记录数据进行分析，尝试找出造成航班延误的原因，以及对航班延误情况进行预测。

项目效果如下，用鼠标指向每一个州，都能看到对应的详细信息。

![](../Images/ff958a76fcaf44fc0722e0e00d584726.png)

**课程简介：**

在本课程中，你可以通过Spark提供的 DataFrame、 SQL 和机器学习框架等工具，结合数据可视化技术，对航班起降的记录数据进行分析，尝试找出造成航班延误的原因，以及对航班延误情况进行预测。

**知识点：**

*   Spark DataFrame操作
    
*   Spark SQL常用操作
    
*   Spark MLlib 机器学习框架使用
    
*   d3.js 数据可视化 API 的使用
    
*   简单网页的编写
    

**链****接：**https://www.shiyanlou.com/courses/610

  

**「 ****大数据带你挖掘打车的秘籍 ****」**

![](../Images/0bf7185b81ba569e70f3a99649b720bb.png)

出租车是我们生活中经常乘坐的一种交通工具，但打车难的问题也限制了我们更好地利用这种交通方式。在哪些地方出租车更容易打到？在什么时候更容易打到出租车？本课程将基于某市的出租车行驶轨迹数据，带你学习如何应用Spark SQL和机器学习相关技巧，并且通过数据可视化手段展现分析结果。

![](../Images/3a7d80dd2bd31d7e47bf1cf313c1788a.png)

**课程简介：**

学习如何应用Spark SQL和机器学习相关技巧，并且通过数据可视化手段展现分析结果。

**知识点：**

*   Spark DataFrame操作
    
*   Spark SQL 的 API 查询
    
*   Spark MLlib 的 KMeans 算法应用
    
*   百度地图开放服务的使用
    
*   d3.js 数据可视化 API 的使用
    
*   简单网页的编写
    

**链****接：**https://www.shiyanlou.com/courses/736

  

# **「 ****ebay在线拍卖数据分析**** 」**

![](../Images/b480bd3f8812631c25b1d45b83a7b90b.png)

双十一、双十二，今年的你又给某宝剁了多少手。本节课程我们将介绍另外一个国际贸易门户--ebay，并利用历史拍卖数据预测拍卖结果。

在测试集上的测试结果：

**课程简介：**  

这节课程我们就是要利用ebay上的历史拍卖数据，用机器学习的方法来训练一个模型，以预测一项拍卖是否会成功，和成功的交易最终的成交价格。

**知识点：**

*   学习如何用scikit-learn的机器学习算法
    
*   scikit-learn 做数据分析
    
*   数据分析结果可视化
