> ****「 ********校花评比排名项目-PHP ********」****

![](../Images/9028ca72be87a94a0103bb0dcde94a63.png)  

相信很多人都看过《社交网络》这部电影。剧中扎克伯格被女友甩掉，愤怒之际，他盗取了校内所有女生的资料，并制作名为“Facemash”的网站，供同学们对辣妹评分。

本节课就将教你用PHP做一个这样的校花评比系统。

项目最终效果如下：

![](../Images/003acf6a4985ff43c681a4e068059948.png)

**课程简介：**

本次实验将带领大家完成一个有趣的 PHP 项目：校花评选。主要包含的知识点：前端页面布局，使用 Jquery 控制页面效果和操作 Cookie，使用 Ajax 方式与后台交互，PHP 操作 MySQL 完成数据查询，PHP 实现埃洛等级分系统算法。通过本次实验的操作，我们不仅可以欣赏并评选美丽的校花，也可以大大提升编程技术。

**知识点：**

*   LX终端（LXTerminal）: Linux命令行终端，打开后会进入Bash环境，可以使用Linux命令
    
*   Firefox：浏览器，用于前端页面展示
    
*   Sublime Text：非常好用且跨平台的文本编辑器。点击桌面左下角： 应用程序菜单/开发/sublime。
    
*   PHP环境. 实验楼给我们提供了一个很完美的快速学习平台。
    

**链****接：**https://www.shiyanlou.com/courses/321

  

**「 ****PHP 实现用户注册登录功能 ****」**

![](../Images/dfef0e4922e974bedfa8722d4ba4d196.png)

本课程通过使用 PHP 及 Web 前端技术实现一个网站注册登录入口页面，学习并实践 PHP 编程，GD库，MySQL 扩展，Bootstrap 响应式布局，Cookie/Session 及 Ajax 等知识点。

项目最终效果如下：

![](../Images/e9306030ec067fe99ab88d7615522360.png)

**课程简介：**

本次实验主要以前端制作为主要内容，使用纯前端知识制作用户注册登录的界面，为后续实验做铺垫。通过本实验的学习，我们可以轻松地制作类似的界面效果。由于这是 PHP 的项目课，所以我们并不需要一行一行的写 html 代码，本次课程的界面制作主要使用前端框架 bootstrap3 的模板和组件来快速搭建大方漂亮的界面，大家也会领略到 bootstrap 框架的方便之处。

**知识点：**

*   Bootstrap3
    
*   Jquery
    
*   Ajax
    

**链****接：**https://www.shiyanlou.com/courses/587  
  

# **「 ****PHP微信公众号接口开发**** 」**

![](../Images/36b6e2f6b8fc9f31f7b03276f7c5068c.png)

本课程将使用PHP开发一个简易的公众号SDK，封装常用的公众号API接口。通过代码编写，了解微信公众号运行流程，数据处理与交互，最后搭建一个属于自己的微信公众号。

完成后的效果如下：

![](../Images/ca8dd5e208f913fa785b7bde9fd60f07.png)

**课程简介：**

本课程将带领大家学习一门新的技术：PHP微信公众号接口开发。主要目的是让大家了解微信公众号接口开发技术，了解公众号和服务器的消息交互和处理。利用php开发一个简易的公众号SDK，封装一些常用的接口，最后通过测试并搭建一个自己的微信公众号，实现与粉丝的交互。
