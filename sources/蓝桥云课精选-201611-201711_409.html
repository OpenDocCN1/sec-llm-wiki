「 Java 实现记事本 」

这个课比较简单，用Java写一个记事本。但其中的内容又很丰富——既有基础的Java编程操作，又涵盖了Swing界面、文件读写等知识。

最终效果图如下，你可以在记事本中完成编辑内容、保存文件、以及按指定路径读取文件等功能：

课程简介：

本实验将主要讲解如何使用 Java 语言编写一个记事本应用，涉及到 Swing 界面编程、文件读写等知识点。

知识点：

  • Java Swing 界面编程

  • 文件读写

链接：https://www.shiyanlou.com/courses/154

「 自己的Java编辑器 」

用java开发一款编辑器，并拥有编译和运行Java程序的功能。这听起来貌似遥不可及，但只要你有一点Java基础，按照本课程的步骤，你就能将它实现。

完成后，你还可以思考如何丰富一些功能，如代码高亮、自动补全等，相信完成这个课程后，你将得到极大的成就感。

课程简介：

相信很多学过 Java 的同学都是首先从记事本开始写起，然后就开始使用 Eclipse。而今天，咱们就制作一个咱们自己的 Java 编辑器，它拥有编辑和编译的功能。是不是很给力呢？项目非常的简单，只要有一点 Java 基础的同学都会看懂的！

知识点：

  • IO 流的操作（重点）

  • Runtime 类 （重点）

  • 线程的使用 （重点）

  • GUI 布局 （不重要，简单理解即可）

链接：https://www.shiyanlou.com/courses/287

「 java 实现微信红包分配算法 」


程序员不开外挂，程序员负责写外挂。

抢了那么多红包，你想过红包分配的算法吗？

怎么写才能保证每个人都有份？如何杜绝一个人拿了大部分的钱？是不是偏后的人会拿到较少的金额？

如果你思考过这些问题，你一定能成为一个很厉害的程序员。

这节课就将带你用Java实现一个类似的微信红包算法。

课程简介：

大家都有玩过微信红包，都希望自己成为手气最佳，一般人就各种猜测，但是我们学计算机的人应该格物致知，自己学学其中的算法，来实现一下，说不定我们的手气也突然"变好"了。

知识点：

  • 随机数

  • 分配算法

链接：https://www.shiyanlou.com/courses/706
