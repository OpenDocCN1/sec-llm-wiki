**如果你也想学习Python，赶上人工智能和大数据时代的浪潮，提前明白以下的 5 件事，可以帮助你更好地学习：**

（1）学编程最好的方法就是「编程」

编程本身就是一门实践科学，就和篮球一样，你无法通过看书、看视频学会打篮球，你同样也无法通过看书、看视频学会编程，动手敲代码才是最好的学习方式。

（2）学习计算机基本知识

Linux、操作系统等基础知识，可以帮你更好地认识计算机世界；Git 和 Github 更是每个程序员的必修课，你有必要学习它们。

（3）明确想从事的方向

python 是一门无所不能的语言，目前 Python 的主要工作范围有：人工智能、数据分析、数据挖掘、Web开发、自动化。请选定一个方向，然后多留意该方向的项目和教程，多多练习。

（4）一专多能，技多不压身

如果还没有确定自己喜欢的方向，可以先对感兴趣的领域学习、了解一遍。实际上，在工作中也往往要求你一专多能，比如做数据分析的一般都会数据挖掘。

**（5）不要问怎么入门，直接上路就好了**

学编程最难的是开始，与其到处问“最好的教程”在哪里，不如选一个感兴趣的项目，直接开始，比如学着写个小游戏、小程序或爬虫，会比天天 print 要有趣得多。
