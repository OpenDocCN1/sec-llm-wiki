01
为什么要学编程


短短20年间，计算机和互联网以一种前所未有的速度，改变了我们的生活方式 。

我们使用 微信「交流」，使用 淘宝「购物」，使用 搜索引擎「获取信息」，随着Uber、滴滴、饿了么的进一步出现，我们的出行、吃饭都越来越离不开互联网。

而这些改变，都来源于 编程 。

如果说上个世纪是全球化的时代，掌握了英语，就能成为时代的宠儿；那么在语义识别和人工智能愈发成熟的今天，「人和人的沟通」不再是难题，「人和计算机的沟通」才是越来越重要的。

想象一下：

如果一个产品经理能通过编程，整理出万级数据的「用户画像」；

如果一个运营能「自动化获取网站、用户数据」，减少50%的人力劳动；

如果一个行政能「自动化完成员工考勤和工资核算」，将原来5天的工作量缩短到1个下午……

如果你是CEO，凭什么不给他们更高的薪资和地位？

因此，编程几乎成为现代人的一道必选题。即使你不想成为一名专业的程序员，编程也能让你的职业前景和生活乐趣大大提升。


02
   编程好学吗？


看到这里，你可能会想：“我也知道编程对职业发展和薪资提升帮助很大，但我 —— 已经27了/文科生/是女生，能学会编程吗？”

事实上，只要你愿意，从10岁的孩子，到82岁的老奶奶，都能学会编程。它不分性别，不分专业，不分国界，你在纽约也好，北京也好，铁岭也好，都没有问题。

（年龄最大的iOS开发者，82岁自学编程，开发了一款下载量4.2万次的App）

但说编程不难，又有点站着说话不腰疼。编程对很多人来说，都是一件从入门到放弃的事，这是因为，很多学习编程的人，都会遇到下面两个问题：

1. 无从下手

当决定开始学编程，很多人会面临一个问题：我该学哪门编程语言，C ？Java ？Python ？

C 大神告诉你，老一辈大学里都从 C 语言开始学，经典！

Java 大神告诉你，Java 目前市场占有率第一，靠谱！

Python 大神告诉你，Python 简单易学，又潜力无限，是未来的首选语言，学！

结果可能是，你买了本C语言的教材，看了几个Java的视频，读了几篇Python的文章，到头来还是什么都不会，索性弃坑吧。

2. 学习习惯

经过传统教育的“磨练”，我们大多数人都养成了一种 被动学习、被动灌输 的习惯，觉得看书、看视频就能学会编程。实际上，这种想法大错特错。

编程是一门手艺活，是一门实践学科 —— 就像你无法通过看书、看视频学会打篮球，编程也是一样。你必须要靠写代码、做项目的方式，来学好编程，否则一定会遇到“视频看完了，但还是不会写代码”的窘境。

所以，编程其实并不难，只要你确定一个方向，多写代码多思考，编程会比你想象的更有趣和轻松 😉
