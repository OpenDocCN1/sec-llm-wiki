**下面让我们来讲解如何实现第一步，自己亲手做一个网易云音乐。用啥技术来做呢？**

**React+Express+MongoDB**

不知道你们有没有看2019年Stack Overflow年度报告，其中最流行的框架排行榜中，React和Express都打进了前五名。MongoDB打进了最流行数据库前五。

![](../Images/0fcd167787b17ed3b9672394fd13999a.png)

  

从设计到实现的完整流程，包含 前端界面模块、Node 模块、MongoDB 模块。前端界面模块包含 React 组件开发、React-Router 路由配置、Redux 状态管理。完成开发需要你有以下技术：

*   webpack 基础配置
    
*   express 的使用
    
*   mongoDB 的基础知识及项目运用
