这个项目是是Java社区近几年来最有影响力的项目之一，也是下一代企业级应用开发的首选技术。

**Spring Boot “春靴”**

  

**Spring Boot **拥有良好的技术基因，它是伴随着 Spring 4 而产生的技术框架，在继承了 Spirng 框架所有优点的同时也为开发者带来了巨大的便利。

  

**1、 体格优秀**

与普通的 Spring 项目相比，Spring Boot 可以让项目的配置更简化、编码更简化、部署更方便，为开发者提供了开箱即用的良好体验，进一步提升了开发者的开发效率。

  

![](../Images/9948ca7e60b32b68290835914b90cf96.png)

  

Spring Boot 以其优雅简单的启动配置和便利的开发模式深受好评，开源社区也空前的活跃，项目在 GitHub 网站上已经有 **35454**个 Star 数和** 23467** 个 Fork 数，并且这个数量在不断的快速增长中，足见其受欢迎程度。

  

**2、钱途明朗**

通过各技术论坛关于Spring Boot 技术的讨论也能看出国内对于 Spring Boot 的技术热情越来越高，很多的国内技术团队在使用 Spring Boot 技术进行企业项目开发。

![](../Images/1d7997335330944b4a98279439246037.png)
