**但是但是但是，以下内容，杨超越粉请绕行。**

今天这篇，是写给非杨超越粉丝的。超越杯我们不稀罕，我们有更具挑战性、知识性、低娱乐化的编程比赛推荐给大家：

  

**1\. 实验楼楼赛**

对我不是吃里扒外的家伙，所以自家的楼赛必须放第一。并且，很鸡冻地跟大家讲啊，停赛半年的的楼赛，又要重新开赛啦！有趣、有奖、还有技术进步知识收货。

![](../Images/2216e7620e10af214605095e00f1359f.png)

**楼赛第22期正在开放报名中，3月19日开赛！胆小的请略过，好汉请点击文末“*****阅读原文*****”报名。  
**

  

  

**2\. TopCoder**

TopCoder是一家被上百万程序员喜爱的编程比赛网站。包括算法竞赛、组建设计竞赛、组建开发竞赛等。其算法竞赛在全球与ACM、Google Code Jam并称为三大赛事。

![](../Images/690e6fdc42af53155bacb713e9b8c47f.png)

比赛都会有真金白银的奖励。并且，倘若获奖，会是你简历上光彩的一笔。当然，难度也可想而知啦。

  

**3\. Codeforces**

虽然介绍到了，但提醒一句，Codeforces不是给凡人准备的。这个是神仙使用的编程比赛网站，大家知道下就好。

![](../Images/4b9f51810c45af31fadfaa883d76e653.png)

  

该网站画风简陋，UI奇丑，上个世纪遗留下来的一样。但是真的能测出天才噢？大多数人连题目都看不懂的，想找打击的可以去试试。

  

**4.CodeMonk**

CodeMonk是HackerEarth推出的系列挑战赛事，让程序员们全身心沉浸在自己编写的代码中，真正地专注于问题的解决，并获得自身突破。

![](../Images/cd950b57cdca3ebe43b5213d0af61cd3.png)

  

  

**5\. Project Euler**

欧拉计划也是全球人气最高的编程挑战项目之一，深受上百万程序员喜爱。但是和Codeforces不同，这些挑战并不是高不可攀到神仙才能解答，而是非常实用的，调动大家思考与解决问题的。

![](../Images/e4a1a39153ee0c48d1421faea1bc2c44.png)

  

  

**6\. Facebook Hacker Cup**

这是由Facebook举办的国际性编程大赛。参赛者需要在一段时间内解决一组算法题，可以使用任何编程语言来解决问题。

![](../Images/454c59a9d688f1e9eeeedc2424ff9430.png)

这也是Facebook招人的一个重要平台，用来选拔优秀的程序员。预选赛前25名将被邀请到Facebook总部参加决赛。获奖者可以获得丰厚奖金。  

  

  

**7\. ACM 国际大学生程序设计竞赛**

ACM是由美国计算机协会主办，现在已经是全球最具影响力的大学生编程比赛。该比赛会综合测试参赛者创新、团队能力以及高压编程、分析能力等。

  

  

**8\. Google Code Jam**

Google Code Jam是一项由Google主办的国际程序设计竞赛。该项赛事始于2003年，旨在帮助Google发掘潜在的工程领域顶级人才。比赛内容包括一系列的算法问题，参赛者必须在指定时间内解决。参赛者允许使用任意自选编程语言和开发环境来解答问题。

![](../Images/c518bd1d8bfab78132fdafff2acff793.png)
