Adapta Theme

一款自适应的 Gtk+ 主题，基于 Google Material 设计风格。

https://github.com/adapta-project/adapta-gtk-theme

★ star:3k+




Arc Theme

一款扁平化带有透明元素的主题。

https://github.com/horst3180/arc-theme

★ star:7k+




Conky

Conky 是一款专门为 X 视窗系统打造的免费、轻量级系统监视器，它可以在你的桌面上显示任何类型的信息。

https://github.com/brndnmtthws/conky

★ star:2k+



Flatabulous

这是一款为 Ubuntu 和其它基于 Gnome 的 Linux 系统打造的扁平化主题。

https://github.com/anmoljagetia/Flatabulous

★ star:3k+




Papirus Icon Theme

Ubuntu Linux 下最好的图标主题之一。

https://github.com/PapirusDevelopmentTeam/papirus-icon-theme

★ star:2k+




La Capitaine Icon Theme

一个受到 macOS 和 Material 设计风格启发的主题，适用于多数桌面环境。

https://github.com/keeferrourke/la-capitaine-icon-theme

★ star:1k+
