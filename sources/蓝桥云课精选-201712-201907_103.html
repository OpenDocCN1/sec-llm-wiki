以下优选 GitHub 上高 star 的指示加载状态的 JavaScript 库。另外这里还有适用于 JavaScript开发者的 12 款 VSCode 扩展工具给大家参考。



上期入口：一份数据分析学习清单.xls


Mprogress.js

创建谷歌 Material 设计风格的线性进度条。

GitHub：https://github.com/lightningtgc/MProgress.js


NProgress

在 Ajax’y 应用显示细长型进度条

官网：http://ricostacruz.com/nprogress/


Spin.js

一个旋转的进度指示器。

GitHub：https://github.com/fgnass/spin.js


progress.js

为页面任何对象创建和管理进度条。

GitHub：https://github.com/usablica/progress.js


progressbar.js

用 SVG path 动画制作的、漂亮和响应式的进度条。

GitHub：https://github.com/kimmobrunfeldt/progressbar.js


pace

自动向你的网站添加一个进度条。

GitHub：https://github.com/HubSpot/pace


topbar

小巧漂亮的、与网站同宽的进度指示器。

GitHub：https://github.com/buunguyen/topbar


nanobar

非常轻量的进度条。不依赖 jQuery。

GitHub：https://github.com/jacoborus/nanobar


PageLoadingEffects

使用 SVG 动画展现新内容的现代方式。

GitHub：https://github.com/codrops/PageLoadingEffects


SpinKit

运用 CSS 动画的加载指示器集合。

GitHub：https://github.com/tobiasahlin/SpinKit


Ladda

内置在按钮的加载指示器。

GitHub：https://github.com/hakimel/Ladda


css-loaders：

运用 CSS 动画的旋转加载指示器的集合。

GitHub：https://github.com/lukehaas/css-loaders
