Python本身提供了处理时间日期的功能，也就是datetime标准库。除此之外，还有很多优秀的第三方库可以用来转换日期格式，格式化，时区转化等等。今天就给大家分享10个这样的Python库。

  

![](../Images/77bca840c3a1fce2d76a7e970c591969.png)

## 1️⃣arrow

更好的 Python 日期时间操作类库。

*   ***官网：****https://arrow.readthedocs.io/en/latest/*
    

  

  

## 2️⃣Chronyk

Python 3 的类库，用于解析手写格式的时间和日期。

*   ***GitHub：****https://github.com/KoffeinFlummi/Chronyk*
    

  

  

## 3️⃣dateutil

Python datetime 模块的扩展。

*   ***GitHub：****https://github.com/dateutil/dateutil*
    

  

  

## 4️⃣delorean

解决 Python 中有关日期处理的棘手问题的库。

*   ***官网：****https://delorean.readthedocs.io/en/latest/*
    

  

  

## 5️⃣maya

人性化的时间处理库。

*   ***GitHub：****https://github.com/kennethreitz/maya*
    

  

  

## 6️⃣moment

一个用来处理时间和日期的 Python 库。灵感来自于 Moment.js。

*   ***GitHub：****https://github.com/zachwill/moment*
    

  

  

## 7️⃣pendulum

一个比 arrow 更具有明确的，可预测的行为的时间操作库。

*   ***官网：****https://github.com/sdispater/pendulum*
    

  

  

## 8️⃣PyTime

一个简单易用的 Python 模块，用于通过字符串来操作日期/时间。

*   ***GitHub：****https://github.com/shinux/PyTime*
    

  

  

## 9️⃣pytzwhere

现代以及历史版本的世界时区定义。将时区数据库引入 Python。

*   ***GitHub：****https://github.com/pegler/pytzwhere*
    

  

  

## 🔟when.py

提供用户友好的函数来帮助用户进行常用的日期和时间操作。

*   ***官网：****https://whenpy.readthedocs.io/en/latest/*
