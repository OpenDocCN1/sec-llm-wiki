## 1️⃣Animate.css  

CSS3 动画库，也是目前最通用的动画库。

*   **官网：**
    
    https://daneden.github.io/animate.css/
    
      
    

## 2️⃣Anime.js：

一个强大的、轻量级的用来制作动画的 Javascript 库

*   **官网：**
    
    https://www.shiyanlou.com/questions/102031
    

  

## 3️⃣Hover.css：

CSS hover 悬停效果，可以应用于链接、按钮、图片等等。

*   **GitHub：**
    
    https://github.com/IanLunn/Hover
    

  

## 4️⃣wow.js:

滚动展示动画

WOW.js 依赖 animate.css，所以它支持 animate.css 多达 60 多种的动画效果。

*   官网：https://www.delac.io/wow/
    

  

## 5️⃣scrollReveal.js：

类似 wow.js

*   官网：https://scrollrevealjs.org/
    

  

## 6️⃣Magic.css：

css3 animation 动画库

*   GitHub：https://github.com/miniMAC/magic
    

  

## 7️⃣Waves：

点击波纹效果

*   GitHub：https://github.com/fians/Waves
    

## 8️⃣move.js：

一个小型的 JavaScript 库，通过 JS 来控制一系列的 CSS 动画顺序执行，使 CSS3 动画变得非常简单和优雅。

*   GitHub：https://github.com/visionmedia/move.js
    

  

## 9️⃣Velocity.js：

一个功能齐全的 JavaScript 动画套件，包括诸如淡入淡出、滚动、滚动、停止、结束、翻转等动画效果。

*   官网：http://velocityjs.org/
