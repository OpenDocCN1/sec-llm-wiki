**课程简介**

今天给大家推荐的这门课程，是一个数据分析的入门与进阶课程，将从数据分析基础开始，一步步深入（***文末有骚操作呢***）。知识点如下：

  

*   Python 基本用法&数据分析包如 NumPy 和 Pandas等。
    
*   数据准备过程：数据清洗，异常值处理，可视化等。
    
*   数据建模：假设和检验，分类与预测，聚类分析等。
    
*   数据分析实例： KNN，K-means等。
    

  

从 Python 的基础用法到数据分析的各种算法，并结合各种实例，讲解数据分析过程中的方方面面。
