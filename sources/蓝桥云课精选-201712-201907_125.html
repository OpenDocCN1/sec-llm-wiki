有人今天在问：

老师有推荐的 windows 下的 markdown 编辑器吗？支持 latex 的？


这里推荐下 GitHub 出的 atom，我一直在用，完美支持 MD 和 TeX。并且 atom 是跨平台的。只需要简单配置一下。

1. File->Settings->Install 中搜索 markdown-preview-plus，点击 Install；

2. 安装后"Enable" 激活 markdown-preview-plus，"Disable" 停用 markdown-preview；

3. Crtl+Shift+m：分栏显示 Markdown 预览，但不编译 Latex 公式；Crtl+Shift+x：开启编译 Latex 公式；
