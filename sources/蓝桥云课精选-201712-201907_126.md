## 7\. django-compressor

将链接和内联的 JavaScript 或 CSS 压缩到一个单独的缓存文件中。 它支持 coffeescript，LESS 和 SASS等编译器，并且可以通过自定义处理步骤进行扩展。 Django Compressor 兼容 Django 1.11 及更新版本。

***官网：****https://django-compressor.readthedocs.io/en/stable/*

***Github：****https://github.com/django-compressor/django-compressor*

  

## 6\. django-storages

一个针对 Django 的自定义存储后端的工具集合。

***官网：****https://django-storages.readthedocs.io/en/latest/  
*

***Github：****https://github.com/jschneier/django-storages*

  

## 5\. fanstatic

打包、优化，并且把静态文件依赖作为 Python 的包来提供。

***官网：****http://www.fanstatic.org/en/latest/*

  

## 4\. File Conveyor

一个后台驻留的程序，用来发现和同步文件到 CDNs, S3 和 FTP。

***官网：****http://fileconveyor.org/*

  

## 3\. Flask-Assets

帮你将 web 资源整合到你的 Flask app 中。

***官网：****https://flask-assets.readthedocs.io/en/latest/*

***Github：****https://github.com/miracle2k/flask-assets*

  

## 2\. jinja-assets-compressor

一个 Jinja 扩展，用来编译和压缩你的资源。

***Github：****https://github.com/jaysonsantos/jinja-assets-compressor*

  

## 1\. webassets

为你的静态资源打包、优化和管理生成独一无二的缓存 URL。它可以合并和压缩您的 CSS 和 JavaScript 文件，支持各种不同的过滤器，并支持使用 CoffeeScript 或 Sass 等编译器。

***官网：****https://webassets.readthedocs.io/en/latest/*

***Github：****https://github.com/miracle2k/webassets*
