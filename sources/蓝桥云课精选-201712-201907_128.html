在很多人都在“迁徙”到Gitlab、Bitbucket等平台时，微软今日宣布了一个重磅消息：Github用户可无限免费使用私有仓库了！具体消息如下：

GitHub Free：包含无限制的私人代码库。有了 GitHub Free，开发人员可以将 GitHub 用于私有项目，每个存储库最多可以有三个协作者。

GitHub Enterprise：将 Enterprise Cloud和 Enterprise Server结合起来。 有些团队希望灵活地在云或自托管配置中使用 GitHub，现在他们只用一项服务的价格就可以使用两项服务了。


消息发宣布后，很多开发者都表示微软做了件大好事。这与之前人们对微软收购Github的态度截然相反。来看看大家都是怎么吹爆微软的吧：




大家是怎么看这件事的呢？这到底是福利，还是深不可测的套路呢？有网友是这样说的：

GitHub 是想获得尽可能多的源代码，我确定他们在尽量挖掘去发现这些源代码有什么。没有什么会是「免费」的。


也有人这样认为：


一旦你的项目有超过三个人，那么 GitHub 将会收费。这是微软/GitHub 一项明智的商业计划。之前，你可能需要使用另一项免费服务（如 BitBucket）来开始构建你的私有项目，因此微软选择扩展免费等级并不令人吃惊。用不着阴谋论。
