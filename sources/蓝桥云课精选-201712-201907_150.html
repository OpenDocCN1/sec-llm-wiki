没有1K以上的星星都不好意思推荐给大家！林子大了，啥项目都有，这里给大家搜罗了10个Github上有趣的项目。如果你就着辣椒食用本文，一定会激动的流下泪来......


1.一行代码没有 | 18k stars！

看看Issues，集体装逼盛宴！我印象里最奇葩的！

The best way to write secure and reliable applications. Write nothing; deploy nowhere.

https://github.com/kelseyhightower/nocode


2.程序员找工作黑名单 | 6.8k stars

程序猿跳槽防止入坑！

https://github.com/shengxinjing/programmer-job-blacklist


3. 代码转成图片 | 16K stars!

方便你在社交媒体分享代码，绝大部分 Twitter 上大神们分享代码片段都是这种方式。你也可以用在 PPT 或者 Word 里。还支持各种 IDE插件。

https://github.com/dawnlabs/carbon


4.最全中华古诗词 | 1.2k stars

唐宋两朝近一万四千古诗人, 接近5.5万首唐诗加26万宋诗. 两宋时期1564位词人，21050首词。

https://github.com/chinese-poetry/chinese-poetry


5.图像化展示 Github 账号的信息 | 1.8k stars

以丰富的可视化的方式来呈现 GitHub 账号的信息

https://github.com/tipsy/profile-summary-for-github


6.自动纠错的终端 | 3.9k stars

thefuck 是一个使用 Python 编写的开源小工具，它可以自动纠正前一个命令的拼写错误。这个工具非常酷，尤其对于常常使用命令行的童鞋。

https://github.com/nvbn/thefuck


7.世界上最简单的人脸识别库 | 19k stars

本项目号称世界上最简单的人脸识别库，可使用 Python 和命令行进行调用。该库使用 dlib 顶尖的深度学习人脸识别技术构建，在户外脸部检测数据库基准（Labeled Faces in the Wild benchmark）上的准确率高达 99.38%。

https://github.com/ageitgey/face_recognition


8.QuickLook | 2.4k stars

它允许 Windows 用户只需按空格键即可以快速地查看文件内容（类 macOS 的 Quick Look）

https://github.com/QL-Win/QuickLook


9. 500lines | 20k stars

用少于 500 行的 Python 代码，你可以写出什么东西？相信你看完这个项目，会学到很多（每个项目的作者都是业内大神写的）

英文：https://github.com/aosabook/500lines

中文翻译（未翻译完）：https://github.com/HT524/500LineorLess_CN


10.C++ 写的终端 2048 游戏 | 1.1k stars

C++ 版的 2048 来了！另外，在实验楼官网你还可以亲自上手学习其它版本的 2048，比如 C、Go、Python（https://www.shiyanlou.com/search?search=2048）。

https://github.com/plibither8/2048.cpp
