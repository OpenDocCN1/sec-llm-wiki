# 关于楼+课程特价关闭的通知。以及一点小惊喜......

**不知道你们有没有注意到一件事？**

我们的楼+课程价格，是有价格变动节点的，简单说就是：越早报名，价格越低；开课前才报名，价格最高。想必大家都明白这个道理，如同你买机票一样。

  

**楼+课程特价关闭通知：**

*   **楼+《数据分析与挖掘》**课将在**15小时**后关闭特价。
    
*   **楼+《Linux运维与DevOps实战》**课将在**2天**后关闭特价。
    
*   **楼+《6周成为机器学习工程师》**课将在**7天**后关闭特价。
    
*   **楼+《12周零基础到Python工程师》**课将在**8天**后关闭特价。
    

**咨询/报名**任意课程都请添加助教小姐姐微信sylmm002。

  

**昨天开会我被批评了，因为我把一些课程差评丢到了技术部的群里。公司程序员们看了评论很心寒。我做错了么？差评难道不应该反馈给大家么？**

老板说：差评是需要处理，但不是这样处理。你为什么不丢好评到技术群呢？一个课程，难保没差评，10条评论，两个差评，你把两个差评丢技术群，等于是否定了大家的工作，打击人的。

  

![](../Images/a61ad41cb1eafbc8bd721f354f91029d.png)

  

“晚上失眠睡不着，起来看用户评论，心里便踏实些了，觉得自己坚持的事，终究是有些意义的。”。创始人的这几句话，在我心里留下个印子。负能量无处不在，黑暗与光明还各占一半呢，我确实需要改变个角度看待东西。

  

![](../Images/e81ae20dc2a5252c64be7550a52c031a.png)

  

这倒不是说，不好的东西就不管了，要拿平常心的处理缺点，而不是盯着不放，硬把缺点放大了来看。北方有佳人，脸上有痣，若是老盯着痣看就完了，站远点，看整张脸：一笑倾人城，再笑倾人国。

  

实验楼是有缺点的，我之所以丢差评到技术群，就是想给大佬们看，怼他们一脸。但我毕竟是错了。人非圣贤，不可能不犯错，一群人做产品，错就更多了；我们当然可以拿上市公司的水准来要求自己，但这也改变不了我们是一个小创业团队的事实。

  

你们或许说，这家伙是在替自己的错误辩解呢！聪明的女孩子找男朋友，心里都有根准绳：喜不喜欢，看他做了什么，而不是说了什么。甜言蜜语、糖衣借口，听倒是可以听，毕竟好听，但听完了，最终还得看行动。我们这些员工，你们这些小可爱用户，谁都无法站到创始人石磊的角度去思考。让公司生存，然后让公司变好，Winter is coming。

  

**你们见过哪家网站，这么多年还没个签到功能的么？我们。**因为一直把精力放在课程优化和内容扩充上，很多细枝末节的功能都没时间去开发。直到这几天，才上线了签到功能。

![](../Images/305ea0f18005ff139288df93cfc20390.png)

  

功能很简单，在讨论区，点击签到，领取1个实验豆，就完了。有些话，说出来很不好意思，很对不住大家......作为一个学习网站，鼓励机制很重要，我们的积分系统却异常简陋。好在最近终于又做了点东西，算是给大家的一点小小的惊喜：**积分商城。**

![](../Images/a7b8bd7412f015c6fc2d8bbde66419d3.png)

除了可以兑换优惠券，还可以兑换实物呢！而且礼物会越来越丰富的。所以大家要多多积攒实验豆噢。

**零零散散说了这么些，不外乎是想表达：谢谢你们长久以来，对我们的包容跟耐心，尤其是使用实验楼多年的老用户们！谢谢。希望你们变得更好，然后来实验楼，让我们也变得更好。**
