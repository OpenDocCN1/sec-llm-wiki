教程介绍

对 Sanic 进行分析，一步步实现这个高并发的异步 Web  框架。涉及到了协程、异步I/O、服务器原理、HTTP协议、路由、视图、异常处理等知识点。

知识点

  1. 掌握 Python 协程原理

  2. 深入 HTTP 协议

  3. 加深对 MVC 模式的理解

  4. 对 Web 开发框架有清晰的认识
