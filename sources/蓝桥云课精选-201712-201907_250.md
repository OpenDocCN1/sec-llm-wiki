Vim，Light Table，Notpad++，Chocolat，Sublime等等。你用的哪个？**对于程序员来说，编辑器就像一个妹子。**刚认识的时候满是新鲜感，慢慢地相处多了，就开始跟你撒娇、闹；直到最后被你调教的服服帖帖很顺手啦。  

  

> **A hackable text editor for the 21st Century 面向21世纪的一款可定制化文本编辑器。**

  

**Atom就像个装扮淡雅的女孩子。**上面一句广告就基本已经体现出Atom编辑器的“卖点”是什么了。Hackable可不是能破解的意思，而是可编程、可修改的；面向21世纪是指界面、设计等元素比较现代化。根据网上的一些评论，这个编辑器总结下来优点主要有：

  

*   Mac，Windows，Linux都支持
    
*   界面美观简洁，超多漂亮Theme支持
    
*   Github打造的，社区讨论也多；相关教程很好找
    
*   原生Git支持，原生Markdown支持
    
*   海量功能强大的插件

肿么样？有木有恋爱的感觉啊？你看这些icon多好看啊，小巧精致的。但是如果你以为Atom妹子就只这点能耐，那你就大错特错啦。人家不仅颜值高，本事也多着呢。**10款必备的强大插件，让你的Atom妹子像天使一样飞起来：**

  

📹 [https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=v0710nvqcy1](https://v.qq.com/iframe/preview.html?width=500&height=375&auto=0&vid=v0710nvqcy1)

（以下插件的使用和安装视频中都有介绍；字幕为Google翻译，错误颇多请谅解；不过相信聪明如你一定能明白，同时也可以锻炼下英语。）  

*   Emmet
    
    Emmet的原来叫做Zen Coding，是一款非常强大的效率提升工具，能够实现HTML和CSS的速写，是前端开发者们必不可少的。  
    
*   File Icons
    
    根据你的文件类别显示不同的图标，非常方便你定位某个文件。视力不好的小哥哥尤其实用哈哈。  
    
*   Atom Live Server
    
    超级好用的Web server服务器插件。  
    
*   Todo
    
    Todo show可以让你给项目加上一些特殊的备注，比如Fixme，changed等等，你也可以添加自定义的备注。  
    
*   Mini-Map
    
    Minimap是Atom上超级流行的一款插件，可以显示整个代码的缩略图，让你快速定位到某个部分。就像玩游戏时的小地图一样。  
    
*   Pigments
    
    能够直接处理CSS的十六进制颜色码，并且在编辑器中直接显示。还能解析预处理变量，甚至颜色变化函数。  
    
*   Linter
    
    Linter是代码校验工具，可以在命令行直接运行，来帮助你发现错误。  
    
*   Atom Beautify
    
    代码格式化的插件，支持大多数语言。  
    
*   Ask Stack
    
    可以直接在Stackoverflow搜索答案或代码案例。  
    
*   Highlight Selected
    

高亮显示和当前选中代码相同的代码。  

  

怎么样，有了这些插件，你的Atom是不是飞起来啦？实际上，我们还可以在Github找到更多强大的插件。关于Atom的安装、使用教程等等，其实网上已经非常多、非常全面了；我这里就不再详细介绍啦（懒~），快去恋爱吧！
