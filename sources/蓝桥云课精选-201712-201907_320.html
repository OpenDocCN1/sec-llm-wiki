今天第一期的实验主题是 Python 生成个性二维码 

使用 Python 基于 MyQR 依次实现生成普通二维码、静态图片二维码以及我老婆的动态头像二维码


在实验楼的在线虚拟环境中我们通过终端来完成这一系列操作

最终的实现效果在 Firefox 中呈现。


首先我们进入code目录开启python3的环境

引入myqr后执行一个我们实验楼的网址

退出Python3环境

然后用火狐浏览器预览

就可以看到一张标准的二维码啦


光是二维码，是否太单调了呢？没关系，我们能加上我们想要的图片，使二维码更具辨识度！ 我们准备了实验楼的Logo：


我们将这张图加入到二维码中，加入过程需要在参数里指定Logo图片的地址，同时也要设置新图片的保存名，以免和上一张二维码图片冲突。

退出Python3环境

在火狐浏览器中预览

就可以看到一张有点儿个性的图片二维码啦


最后我们请上各位宅男的老婆

使用新垣结衣的GIF动图来生成一张动态二维码

其实操作同上也很简单，

只是要注意生成保存的文件也必须是GIF格式

否则老婆的微笑就动不起来了哟~
