效率神器：把 macOS 上爽到飞起的 Quick Look 带到 Windows

macOS 上有一个「Quick Look」功能，在文件或者文件夹上按下空格键，就可以快速预览到文件的内容或者资料了。在 Windows 上没有这种功能，虽然说资源管理器里还有其他类似的功能，但使用效率便捷性来说远远比不上这个。不过现在 Windows 下有 QuickLook 这个小工具，也一样可以实现上面的功能。



QuickLook 的用法也很简单，安装后运行就行了。接着在需要预览的文件或文件夹上，点击鼠标激活，然后再按下空格就可以了。


软件预览功能很好用，完全可以取代 Windows 的预览功能。相比之下还多了可以查看文件详细信息的效果。选中文件空格就可以查看。可以查看文件夹信息，图片信息，html 信息，pdf 信息，word 信息，视频信息，压缩包信息.下边附上使用效果图。
