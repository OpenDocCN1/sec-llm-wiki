你是不是有以下困惑？

  

身边总有神奇的同事，总是能分享一些很赞的资源，不好意思问他从哪里知道的。

  

打算学习一门新技术，怎么最快找到优质的资源（工具，第三方库，插件，文章，视频等）？

  

今天我分享给大家一个使用 GitHub 找优质资源的技巧：

  

使用 GitHub 的站内搜索，搜索： **Awesome + 你的关键字**
