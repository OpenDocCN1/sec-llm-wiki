硅谷从来不缺经典的创业故事，但那些白手起家、最终变成科技巨头的公司如何保持创新能力，却成了大问题。

于是，收购创新企业，就成了巨头们保持竞争力，应对挑战的重要手段。

昨天，科技巨头微软公司宣布了一项重大收购案——收购社交编程及代码托管网站 GitHub。

和比尔·盖茨一样，GitHub 的背后，又是一位非科班辍学生的创业故事。一位英文专业的大学生，逃课、自学编程，最终创建出一家价值 75 亿美元的科技企业。

从英文专业辍学生到自学成才的“码农”

美国当地时间本周一，微软官网发布了一则公告称，刚刚过完 10 岁生日的全球最大社交编程及代码托管网站 GitHub，以 75 亿美元（约合人民币 480 亿元）的价格正式卖身给微软。

收购完成后，GitHub 依然会独立运营，而微软的副总裁 Nat Friedman 将会担任 GitHub 公司 CEO，GitHub 公司的现任 CEO——Chris Wanstrath（以下简称“克里斯”），将会进入微软的技术团队。

和微软的创始人比尔·盖茨一样，GitHub 的创始人兼现任 CEO 克里斯也是一位大学辍学生。

在创业之前，1985 年出生的克里斯是在美国辛辛那提大学读英文专业。但在大学期间，他经常逃课，自己在宿舍里学习编程。2014 年，他回到母校演讲时表示，“我认为文凭并不重要，能力才是关键。”

在校期间，他学了几个 UC 编程的课程，甚至考虑转到计算机专业。不过，克里斯充分利用大学期间的自由时间自学。2005 年，他终于退学，来到旧金山，在 CNET 网络公司找到了一份工作。

既然喜欢计算机，为什么选择英文专业？2017 年，克里斯在接受《财富》杂志采访时表示，“我发现，无论我做什么，我都听说读写得用英语。”

2008 年，23 岁的克里斯和另外两位小伙伴创办了 GitHub。GitHub 是一个线上社区，程序员们可以分享和储存代码，其他人也可以利用这些代码进行软件开发。十年间，GitHub 已经成为全球最大的软件代码储存托管公司。

2008 年 3 月，克里斯在一篇博客中宣布，GitHub 已经有 2000 名用户了；到了第二年 6 月，这一数字增长到了 10 万。

目前，GitHub 已经拥有用户 2400 万。NASA、Airbnb、IBM、Spotify 等大企业都是它的客户。2017 年，GitHub 向美国媒体 CNBC 表示，公司年注册用户收入已经达到了 2 亿美元。在微软正式宣布收购之前，市场一直预测微软收购 GitHub 的交易价值是 50 亿美元。

2016 年，克里斯还入选了《福布斯》40 岁以下企业家富豪排行榜，以 3.6 亿美元的身家排名第 31 位。而当时，GitHub 的估值才 20 亿美元。

不过，身为“技术宅”，克里斯似乎在商业上并没有太大野心。他曾两次主动辞去公司 CEO 职位。第一次是在 2012 年。当时，联合创始人 Preston-Werner 代替了这个位置，但随后性骚扰丑闻让 Preston-Werner 被迫离职；另一次是在 2017 年，克里斯在接受《福布斯》采访时表示，“公司越做越大，需要更加合适的 CEO 人选”，而他自己将会专注产品。但直到被微软收购，这个人选都没找到，所以，微软的副总裁 Nat Friedman 将会担任 GitHub 的 CEO。

裁撤 Windows 部门，收购 GitHub，微软要干嘛？

这笔收购引人关注，不仅因为其背后“码农辍学生创业”的硅谷成功学故事，还因为它对微软公司的重大意义。

这笔收购案，是纳德拉坐上微软 CEO 位置 4 年来的第二大规模收购，两年前，微软斥资 262 亿美元收购领英。

更重要的是，GitHub 是一个开源社区，而长期以来，微软却被视为一家封闭的公司。在微软昨天发布的公告中，纳德拉表示，“微软是一家主张‘开发者第一’的公司，通过与 GitHub 合作，我们将给予开发者更大的创新空间和自由度。”

要知道，在纳德拉之前，微软的第二任 CEO 史蒂夫·鲍尔默一直反对将微软技术开源，他甚至将开源技术比喻为技术产权的癌症。

后来，微软推出的开源软件托管平台 CodePlex 被 GitHub 后来者居上，两家的关系一度也比较紧张。但是，“技术男”纳德拉出任微软的第三任 CEO 之后，微软开始表现出拥抱开源的姿态。

纳德拉 2014 年上任后，微软宣布开始在 GitHub 上建立账户。也是这一年的 10 月，微软宣布 NET 的开源。而今年的 2018 年 Build 大会上，微软还与 GitHub 达成进一步的合作，将微软的智能云 Azure 的能力开放出来。

值得一提的是，曾经反对开源软件开发的微软，现在已经成了 GitHub 的最大贡献者之一。

此外，上任以来，纳德拉正带领微软摆脱对 Windows 操作系统的完全依赖。据环球网报道，在今年 3 月 29 日致员工的电子邮件中，纳德拉宣布了微软的部门重组，将解散 Windows 工程师团队，Windows 业务团队领导也将离职，而云计算和高端人工智能将成为微软的中心任务。这也标志着微软 Windows 为王的时代正式成为历史。

据纽约时报报道称，解散后的 Windows 工程师团队，一部分将会并入微软云软件，其他的工程师将会去开发消费者应用，包括智能手机、平板、个人电脑和游戏机中的软件。而微软 Windows 与设备部门执行副总裁 Terry Myerson 将从岗位离职，他已经在微软工作 21 年。

分析师称，这一举措属于微软重组的一部分，为了加速微软在更新、更快增长的业务上的发力，如云计算和数据支撑的人工智能。自从纳德拉在 2014 年成为微软 CEO 之后，就已经在为这些改革铺路。

事实上，微软当时任命纳德拉出任 CEO 的决定一度让业界大呼出人意料。由于迟迟未能找到史蒂夫·鲍尔默的接班人，许多人认为微软会寻找外部人士来执掌微软，而不是当时已经在微软工作了 22 年却依然十分低调的纳德拉。

纳德拉接任微软 CEO 的时候，当时近 40 岁的微软已经略显疲态，如何让微软焕发青春是他上任后不得不面对的问题。

2015 年纳德拉曾经立下誓言要带领这家老迈的科技先锋重塑自我，优先发展云计算业务。他当时的承诺是把云计算营收扩大为当时的 3 倍，到 2018 年实现 200 亿美元的年化营收。

如今，纳德拉不仅提前兑现了 2018 年实现云计算业务 200 亿美元年化营收的承诺，云计算带来的业绩提升还助推微软市值不断攀升。今年，微软的市值一度反超谷歌母公司 Alphabet，截至目前，微软市值达到了 7744 亿美元。
