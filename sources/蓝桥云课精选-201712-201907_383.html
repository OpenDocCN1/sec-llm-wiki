推荐 7 种最适合入坑数据科学的编程语言！

正文共：4257 字 

预计阅读时间：11 分钟‍

数据科学是一个令人兴奋的领域，需要将先进的统计和定量技能与实际编程能力相结合。许多数据科学家会考虑专门研究多种潜在的编程语言。

▎R

R在1995年被开发出来，是基于S语言的一个GUN项目，R从此不断发展壮大。 目前由R Foundation for Statistical Computing支持。

优点

  • 出色的高质量，特定领域和开源软件包。 R几乎拥有所有可以想象的定量和统计应用的软件包。包括神经网络，非线性回归，系统发育，高级绘图和以及其他。

  • 基础安装配备了非常全面的内置统计功能和方法。R还有处理矩阵代数的强大能力。

  • 数据可视化是使用ggplot2等库的关键优势。

缺点

  • 性能。R不是一种快速的语言。

  • 域特异性。对于统计和数据科学目的来说R非常棒。但对于通用编程而言就有些乏力了。

  • R有几个不寻常的特性可能会让程序员选择其他语言。例如：从1索引，使用多个赋值操作符，非常规数据结构。

评价 –“ 在专门领域很出色”

R是一种功能强大的语言，擅长于各种各样的统计和数据可视化应用程序，而开放源代码则可以为非常活跃的贡献者社区提供支持。它最近受欢迎的程度就是最有效的证明。

▎Python

Guido van Rossum于1991年k开发了Python。它自此成为非常受欢迎的通用语言，并在数据科学界广泛使用。 主要版本目前是3.6和2.7。

优点

  • Python是一种非常流行的主流通用编程语言。 它有广泛的专用模块和社区支持。 许多在线服务提供Python API。

  • Python是一门易于学习的语言。 低入学门槛使其成为编程新手的第一理想语言。

  • 像pandas，scikit-learn和Tensorflow这样的软件包使得Python成为高级机器学习应用的最佳选择。

缺点

  • 类型安全性：Python是一种动态类型语言，这意味着您使用时必须非常小心。 类型错误（例如将字符串作为参数传递给期望为整数的方法）会经常出现。

  • 对于具体的统计和数据分析目的，R的各种软件包比Python更有优势。对于通用语言，Python有更快更安全的替代方案。

评价 - “优秀的多面手”

Python是数据科学语言的不错选择，而不仅仅是入门级。 大部分数据科学过程围绕ETL过程（提取 - 转换 - 加载）展开。 这使得Python的通用性非常适合。 像谷歌的Tensorflow库使得Python成为机器学习的一种非常令人兴奋的语言。

▎SQL

SQL（Structured Query Language，结构化查询语言）定义、管理和查询关系数据库。 该语言出现在1974年，并且经历了许多实现，但核心原则保持不变。

优点

  • 在查询、更新和操作关系数据库方面非常高效。

  • 声明式语法使SQL成为一种通常非常易读的语言。

  • SQL在各种应用程序中使用非常广泛，因此非常需要学习。 诸如SQLAlchemy之类的模块使SQL与其他语言直接集成。

缺点

  • SQL的分析能力相当有限 - 除了汇总和求和，计数和平均数据之外，其他功能是有限的。

  • SQL有许多不同的实现，例如PostgreSQL，SQLite，MariaDB。 它们之间的差异性很大 ，所以互操作性难度很大。

评价 - “永恒和高效”

SQL作为一种数据处理语言相对于高级分析工具更有用。很多数据科学过程取决于ETL，而SQL的长久性和高效性证明它是现代数据科学家非常有用的语言。

▎Java

Java是一种非常流行的通用语言，它在（JVM）Java虚拟机上运行。 这是一个抽象计算系统，可实现平台之间的无缝可移植性。 目前由Oracle公司支持。

优点

  • 普遍适用性。 许多现代系统和应用程序都建立在Java后端上。 拥有将数据科学方法直接集成到现有代码库中的能力。

  • 强类型。 Java在确保类型安全性方面毫不吝啬。 对于关键的大数据应用来说，这是非常重要的。

  • Java是一种通用的高性能编译语言。 这使得它适用于编写高效的ETL生产代码和计算密集型机器学习算法。

缺点

  • 对于临时分析和更专用的统计应用程序，Java的冗长性使其不太可能成为首选。 动态类型的脚本语言（如R和Python）可以提高生产力。

  • 与R等专用语言相比，Java中高级统计方法的可用库不多。

评价 - “数据科学的有力竞争者”

把Java作为首选的数据科学语言有很多需要说的。 许多公司都非常欣赏将数据科学生产代码无缝集成到其现有代码库的能力，Java的性能和类型安全性是真正的优势。不足之处是没有可用于其他语言的特定统计信息包的范围。

▎Scala

由Martin Odersky开发并于2004年发布，Scala是一种在JVM上运行的语言。 它是一种多范式语言，支持面向对象和功能方法。 集群计算框架Apache Spark就是用Scala编写的。

优点

  • Scala + Spark =高性能集群计算。 对于那些使用高容量数据集的人来说，Scala是语言的理想选择。

  • 多范式：Scala程序员可以同时使用面向对象和函数式编程范式。

  • Scala被编译为Java字节码并在JVM上运行。 这让它与Java语言本身之间具有互操作性，Scala因此成为非常强大的通用语言，同时也非常适合数据科学。

缺点

  • 对于新手来说Scala并不是一个简单易懂的语言。最好的选择是下载sbt并使用特定的Scala插件来设置Eclipse或IntelliJ等IDE。

  • 语法和类型系统复杂。

评价 -“ 适合大数据”

当谈到使用集群计算来处理大数据时，Scala + Spark是非常棒的解决方案。 如果你有使用Java和其他静态类型语言的经验，会欣赏Scala的这些功能。 然而，如果你的应用程序没有处理大量的数据，那么使用Scala会增加复杂性，使用R或Python等其他语言可以提高生产力。

▎Julia

就在5年前，Julia在数字计算领域给人留下了非常深刻的印象。由于许多主要组织(包括金融业的许多机构)的早期采用，它的知名度不断提高。

优点

  • Julia是一种JIT (just-in-time)编译语言，它可以提供良好的性能。它还提供了像Python这样简单、动态类型和脚本功能的解释语言。

  • Julia是专门为数值分析而设计的。它也能进行通用编程。

  • 可读性。许多语言使用者认为这是一个关键的优势。

缺点

  • 成熟度。 Julia作为一种新语言还有些不稳定。

  • 与已有的R和Python不同，Julia还没有选择包。

评价- “前景广阔”

作为最近发展起来的语言，它没有Python和R成熟。但是有充分的理由去密切关注它在未来的发展。

▎MATLAB

MATLAB是一种在学术界和工业界广泛使用的数字计算语言。 它是由MathWorks开发和授权的，MathWorks是1984年成立的一家公司，旨在将软件商业化。

优点

  • 专为数值计算而设计。 MATLAB非常适合具有复杂数学要求的定量应用，如信号处理，Fourier变换，矩阵代数和图像处理。

  • 数据可视化。 MATLAB具有一些很好的内置绘图功能。

  • MATLAB通常作为许多本科课程的一部分，包括物理学，工程学和应用数学等量化学科。 因此，它在这些领域被广泛使用。

缺点

  • 专有许可证。 根据你的使用情况（学术、个人或企业），可能需要付出昂贵的许可证。 有免费的替代品，如Octave。

  • 不是通用编程的第一选择。

评价 - “对数学密集型应用程序最好”

MATLAB广泛应用于整个行业和学术界的一系列定量和数字领域，使其成为数据科学的一个重要选择。当你的应用程序或日常角色需要密集的高级数学功能时MATLAB应该是最佳选择。

▎其他语言

▎C++

虽然C ++具有闪电般的性能和广泛的主流普及性，但它并不是数据科学的常见选择，可能是生产率与性能的问题。

“如果你正在编写代码来做一些可能只运行一次的临时分析，那么你宁愿花30分钟编写一个10秒内运行的程序，或者10分钟编写一个运行于1 分钟？”

然而，对于重大的生产级性能，C ++将是实现低级优化的机器学习算法的绝佳选择。

评价 - “不适用于日常工作，但如果表现很出色......”

▎JavaScript

随着近几年Node.js的兴起，JavaScript越来越成为一种重要的服务器端语言。 然而，它在数据科学和机器学习领域的应用迄今为止还是有限的（尽管checkout brain.js和synaptic.js）。 它有以下缺点：

  • 出现较晚（Node.js只有8岁！）

  • 很少有相关的数据库和模块可用。

Node的优势在于异步I/O，它的广泛使用以及编译为JavaScript的语言的存在。 因此数据科学和实时ETL处理的有用框架可以结合在一起。

评价 - “在JavaScript可以被视为一种严肃的数据科学语言之前，还有很多事情要做”

▎Perl

由于其作为通用脚本语言的多功能性，Perl被称为“瑞士军刀的编程语言”。 它与Python有许多共同点，是一种动态类型的脚本语言。 但是，它还没有Python在数据科学领域的普及程度。

鉴于其在量化领域如生物信息学中的使用，这有点令人惊讶。 在数据科学方面，Perl有几个关键的缺点。 它并不突出，语法也很不友好。 在开发数据科学特定库方面动力不足

评价 - “一种有用的通用脚本语言，但它不会为你的数据科学简历提供真正的优势”。

▎Ruby

Ruby是另一种通用的动态类型的解释型语言。但是它也没有像Python那样对于数据科学的适用性。

这可能是Python在学术界占主导地位的结果。 越多的人使用Python，开发的模块和框架越多，更多的人将转向Python。SciRuby项目旨在为Ruby提供科学计算功能，如矩阵代数。 但就目前而言，Python仍然占据主导地位。

评价 - “对于数据科学来说，它不是首要选择，但可以加分”。
