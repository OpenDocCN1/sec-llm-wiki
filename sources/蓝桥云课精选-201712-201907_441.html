一、《Python3 基于 Flask 框架搭建个人博客》

课程作者：poet

课程简介：本课程中，我们将使用 Python 语言及 Flask 框架开发一个简单的博客系统。涉及 Flask Web 开发，使用 Peewee 构建数据模型，简单的 Jinja2 模板， Pygments 模块实现代码语法高亮，MarkDown 格式编写博客， Micawber 实现多媒体播放。

效果截图：

知识点：

  • Python3 基础语法

  • Flask Web 开发

  • 数据库设计与实现

  • 简单的 Jinja 模板

课程链接：https://www.shiyanlou.com/courses/1047


二、《C++ 实现即时通信软件》

课程作者：轱辘咕噜

课程简介：本课程使用C++实现一个具备服务端和客户端的即时通信聊天室，涉及网络编程，C++面向对象程序设计等知识。

知识点：

  • C++语言基本语法

  • 基本的Makefile

  • C++面向对象程序设计

  • epoll 网络编程

课程链接：https://www.shiyanlou.com/courses/1043


三、《C 语言实现 web 服务器》（限免中）

课程作者：轱辘咕噜

课程简介：本课程使用 C++ 实现一个Web服务器。在这个课程中，你将会学习C++网络开发，kqueue IO复用机制，熟悉Linux下的C++程序编译方法，Makefile编写等技能。

知识点：

  • C语言基本语法

  • HTTP协议基础

  • 基本的Makefile

  • C语言网络编程

  • Makefile编写

  • Linux守护进程实现

  • 配置文件的实现方法

  • 日志系统的实现方法

课程链接：https://www.shiyanlou.com/courses/1053


四、《C++实现课程管理系统》

课程作者：轱辘咕噜

课程简介：本实验使用 C++ 实现一个课程管理系统，在这个过程中会介绍C++11的很多特性，同时可以熟悉Linux下的C++语言编译方法及简单的Makefile编写。

知识点：

  • C++语言基本语法；

  • 基本的Makefile；

  • C++面向对象程序设计，类，虚函数，继承，重载；

  • C++ 标准库；

  • C++11 的一些用法，例如auto。

课程链接：https://www.shiyanlou.com/courses/1052
