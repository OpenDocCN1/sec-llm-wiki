**课程作者：**书籍《Python游戏编程快速上手（第4版）》—异步社区

**课程简介：**Bagels是可以和朋友一起玩的一个推理游戏。本实验将会一步步地用 Python3 实现这个游戏。本课程会用到一些 Python3 的新特性。

## 三、《使用 Python 创建照片马赛克》

![](../Images/00188c8d93bb2ee77dbdddd5aaf960a4.png)

**课程作者：**书籍《Python极客项目编程》—异步社区

**课程简介：**我们将学习如何使用 Python 创建照片马赛克。我们将目标图像划分成较小图像的网格，并用适当的图像替换网格中的每一小块，创建原始图像的照片马赛克。

**效果截图：**

![](../Images/768a9ad3f031081e7c57aa603bab4537.png)

**知识点：**

*   用 Python 图像库（PIL）创建图像；
    
*   计算图像的平均 RGB 值；
    
*   剪切图像；
    
*   通过粘贴另一张图像来替代原图像的一部分；
    
*   利用平均距离测量来比较 RGB 值。
    

**课程链接：**https://www.shiyanlou.com/courses/1041
