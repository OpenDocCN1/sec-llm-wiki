****最新的学习领域，最全面的教学内容****

**Python是最适合初学者的编程语言，同时也是适用性最广泛的语言之一。很多国内外的高校，都开始选择Python，作为计算机系新生的入学学习语言。在北京等一些城市的高中会考中，也开始将Python编程列为考试科目。**

又因为Python在人工智能和大数据领域中的彪悍表现，可以说它是未来的学习编程的首选语言。

在楼+ ，你将在12周的时间里学习 Python 基础、前端基础、Python爬虫、Python数据分析、Flask Web 开发等技术领域；对学有余力的同学，我们还开设了「Python开发运维工具」、「Python开发微信公众号」两周的选学课程，完全免费。
