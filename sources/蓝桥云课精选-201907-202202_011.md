很多人因为公司不使用 Node.js 而放弃学习 Node.js，我认为还是挺可惜的。

  

Node.js 是一个基于 Chrome V8 引擎的 JavaScript 运行时”。Node.js 的项目需要使用** JavaScript **语言来写，而语言运行的时候需要在一个环境中运行。

  

学习过前端应该都知道，JavaScript 可以在浏览器中运行，浏览器就被称为 JavaScript 的一种运行时环境。

  

毕竟 Node.js 入门比较容易，如果你满足以下几种，一个月时间就可以**熟练**使用 Node.js 编写一些命令行工具、Web 应用用以辅助日常工作：

*   已经会了 Node.js 的语法；
    
*   计算机的相关专业出身；
    
*   对 Web、Server 本身有一定的了解。
    

  

**那为什么要学习 Node.js 呢？**

*   编写 Node.js 只要使用 JavaScript 语言，所以对于学习过前端的同学，你不需要重新学习一个语言的语法、原理，直接可以上手开发，**最大化减轻学习压力**；
    
*   使用 Node.js，前端和后端可以**共享一些代码**，比如表单校验、游戏逻辑中都会有相同的代码；
    
*   有一些** NoSQL 类型**的数据库，可以直接使用 JavaScript 语言进行操作，比如 MongoDB、CouchDB 这些数据库；
    
*   学习了之后，你可能成为一个**全栈工程师**，因为你前端、后端、数据库都能上手开发了。
    

  

**学习 Node.js 可以做什么呢？**

*   后台管理系统、实时交互系统、考试系统、小程序、购物软件、高并发量的 web 应用程序（淘宝、天猫、腾讯视频、阿里云、PayPal 支付、Netflix 网站）；
    
*   基于 web、canvas 的**多人联网游戏**（网易）；
    
*   基于 web 的多人实时聊天客户端、聊天室、图文直播（花瓣网、蘑菇街的聊天功能）；
    
*   操作数据库、为前端和移动端提供 **API 服务**（不胜枚举）；
    
*   **云原生**；
    
*   **构建工具**（Vue.js、React.js 都使用 Node.js 构建）。
    

  

**如何下载 Node.js?**

下载 Node.js 可以前往官网下载，每个系统都有对应的安装包。

  

下载界面会有两个版本，通常建议**下载 LTS 版本**，不要下载奇数版本（比如 v17.x、v15.x 等），**奇数版本为不稳定版**，可能含有过多 bug，对于初学者来说并**不友好**。

  

![](../Images/108471d0de960e6736796eb4b9dedd9c.png)

  

**REPL（交互式解释器）是什么?**

REPL 是一种在命令行里解释执行语言的工具，它的样子就像浏览器的控制台，可以在其中直接写代码，然后执行。

  

REPL 是学习 Node.js 基础知识最好的工具，所以同学们务必学会使用。

  

*   **进入 REPL**
    

只需要在命令行输入 node， 然后回车即可进入：

  

![](../Images/d2ad4b09d50fd68fd70177c6101034ab.png)

  

进入后会打印出两行信息，第一行是一句欢迎语，并打印出当前 Node.js 的版本号；第二行提示 ：输入“.help”获取更多信息。

  

*   **获取帮助信息**
    

就在光标的位置输入 .help 并回车来试试：

  

![](../Images/db8d92ba82dd06e1113eb5474ad0901a.png)

  

又打印出了几行命令以及解释，最后一行说“按 Ctrl+C 中止当前表达式，按 Ctrl+D 退出 REPL”。

  

打印出的这些命令不需要大家去熟记，大家只需要知道怎么调出来即可，需要的时候查阅便可以。

  

*   **退出 REPL**
    

退出 REPL 有三种方式：

*   输入 .exit；
    
*   按下 Ctrl+D；
    
*   按下两次 Ctrl+C。
    

  

下图演示使用第一种方式退出 REPL：

**全局对象和全局变量是什么？**

在浏览器环境中，全局对象是 window，其中包含自定义的全局变量、浏览器方法、文档信息等等。

  

在 Node.js 中，没有浏览器方法、文档信息，那么在 Node.js 中也就没有 window，但是有一个 global 对象，这是 Node.js 中的**全局对象**。

  

与浏览器一样，全局对象中的属性，就是**全局变量**。

  

![](../Images/cb057645a9c891d3da38f6088b6937be.png)
