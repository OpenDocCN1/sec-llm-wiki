Linux 是什么？

      

很多人都会问，Linux 到底是什么？其实，Linux 就是一个操作系统，这与大家熟悉的 Windows（xp、7、8） 、Mac OS 是一样的。

（ps：【操作系统】简称OS， 是管理计算机硬件与软件资源的计算机程序）


我先简单介绍一下，操作系统在整个计算机系统中的角色。计算机系统中有应用程序、系统调用、内核、硬件，而系统调用和内核，组成了操作系统。

     





Linux 是真正多用户、多任务的操作系统，它不仅具有良好的兼容性、可移值性和高度稳定性，还有漂亮的用户界面。

Linux 和Windows 到底有什么区别？


第一部分中我提到了Linux 、Windows，两者都是操作系统，那它们到底有什么区别呢？我主要从6个维度，来对比一下。







由表格中的收费情况、软件与支持、安全性等维度，我们可以看出，虽然 Linux 和Windows 都是操作系统，但还是有很大区别的，这里我再给大家总结一下他们缺点：


Windows 缺点

1）没有稳定的系统；

2）缺少安全性和漏洞的快速修补；

3）没有用户和用户组的规划；

4）不可定制剪裁；

5）没有可选择的多种图形用户界面，如GNOME、KDE。


Linux 缺点

1）没有特定的支持厂商；

2）没有足够的游戏娱乐、专业软件支持度。
