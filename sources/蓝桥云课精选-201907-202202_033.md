所谓 Web 开发指的是编写 Web 应用程序用于**处理 Web 请求**。而 Python 的语言特性使得自身编写 Web 框架极其容易，以至于现在有上百种 Python 编写的 Web 开发框架。

  

在用 Python 进行 Web 开发前，你需要**先掌握 Python 基础知识**，然后**学习 Python Web 框架**，最常用的 Web 开发框架有 Django 、 Flask 等。

  

不过，选择 Web 开发框架也有门道。那该如何选择呢？这里呢，我总结为 3 点：

*   **易用**：对初学者比较友好，且具有健全的文档、灵活开发部署，如 Flask；
    

*   **效率**：适合快速开发，注重开发效率，如 Django；
    
*   **性能**：能承载更大的请求压力，提高吞吐量，如 Falcon 。
    

  

对于初学者来说，选用 Web 开发框架的第一位是**易用性**，这里呢，我比较推荐 Flask 、Django 。

Flask 非常小，源码量并不多，**适合整体阅读**。麻雀虽小五脏俱全， Flask 可以实现的功能并不比其它框架少，因为它是一个**可扩展**的 Web 应用开发框架。

  

蓝桥云课训练营**《Python Web 实战系列 1：Flask 框架基础》**，能够深入了解 Flask 开发体系，提升熟练度。以下是作者整理的思维导图：

  

![](../Images/62257b0c0d653ce8d60e90e4fd82039e.png)

  

Flask 框架的设计思路使得程序可以获得所需功能而不必囊括不需要的功能，**需要什么功能就用什么插件**，达到精确满足项目需求的目的。

  

Flask 插件成百上千，在 Github 上可以找到它们。值得注意的是插件也是第三方库，它们的可靠性并非全部令人满意，在选择插件时，注意考量它的**使用量以及更新频率**。
