今天给你们可爱的 Linux 推荐6件超级好看的花花裙子，萝莉风、御姐型、科技感、纯朴风，看上哪件选哪件，开始启动程序员逛街模式吧！（文末有投票，扫码入群还有福利哦~）


一、Adapta Theme

一款自适应的 Gtk+ 主题，基于 Google Material 设计风格。

★ star:3k+


二、Arc Theme

一款扁平化带有透明元素的主题。

★ star:7k+


三、Conky

Conky 是一款专门为 X 视窗系统打造的免费、轻量级系统监视器，它可以在你的桌面上显示任何类型的信息。 

★ star:2k+


四、Flatabulous

这是一款为 Ubuntu 和其它基于 Gnome 的 Linux 系统打造的扁平化主题。

★ star:3k+


五、Papirus Icon Theme

Ubuntu Linux 下最好的图标主题之一。

★ star:2k+

六、La Capitaine Icon Theme

一个受到 macOS 和 Material 设计风格启发的主题，适用于多数桌面环境。

★ star:1k+
