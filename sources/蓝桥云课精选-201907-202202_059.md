应届毕业生的你，秋招没有拿到满意的 offer ？正在大三就读的你，想提前解锁大厂？在职工作一年甚至三年，想转岗尝试其他岗位？

  

对于很多计算机专业的同学来说， IT 行业是首选。那编程语言有那么多，程序员岗位那么多，又该如何选择呢？ 

  

从 TIOBE 编程语言排行榜来看， Java 的热度一直不减，稳居前二，由此可见，Java 仍然是 IT 行业最热门的编程语言。而且，很多人说，**Java 是连接未来的桥梁**。因为很多流行语言都是基于 Java 的，比如 Groovy 、Clojure 、Jython 等等。

  

![](../Images/19874ab84b04935c93d89c375b1acc28.png)

  

再看各大招聘网站、Quartz 报告，Java 开发是业内薪资最高的程序员之一。根据不完全统计，目前国内每年 IT 人才缺口达 20 万，而且无论是后端、 Web 还是安卓开发，都需要 Java 。

*   Java 基础知识必须扎实，理解 io 、多线程等基础框架；
    
*   熟悉 Spring 、ibatis 等开源框架；
    
*   掌握 Linux 操作系统和大型数据库（如 Oracle 、 MySql ）；
    
*   有一定 Java 开发经验；
    
*   ……
