9月，秋招如期而至。应届毕业生们，做好准备了吗？

是不是为了工作辗转失眠？是不是初入职场焦虑不知所措？是不是为了简历愁秃了头？……

在找工作，应聘大厂前，如果仅用关键词去对堆砌自己的简历，缺少实战，很容易在简历海中，直接被 pass 。


哪怕过了简历关，也难逃面试关。所以应届毕业生哪怕面试回应再从容，都抵不过优秀的项目实战经验。

如果想要进入互联网 IT 行业，如何增加职场竞争力呢？这里呢，我整理了 5 类 IT 课（包含后端开发类、 Linux 运维、云计算与大数据、数据库、Web 前端），供大家参考学习。



01
后端开发


1. Python 实现图片转字符画

https://www.lanqiao.cn/courses/370?utm_source=weixin


课程难度：初级

你将学到：用 50 行 Python 代码完成图片转字符画小工具，学习 Linux 命令行操作、 Python 基础、 pillow 库的使用、 argparse 库的使用。


2. Python3 简明教程

https://www.lanqiao.cn/courses/596?utm_source=weixin


课程难度：初级

你将学到：Python 3 基础知识、PEP8 、测试、项目结构等。


3. C 语言简明教程

https://www.lanqiao.cn/courses/57?utm_source=weixin


课程难度：初级

你将学到：引入大量的 C 语言程序案例，把算法和语法结合起来，学习C 语言语法、数组、模块化程序设计指针、文件的输入与输出等。


4.Java 设计模式详解

https://www.lanqiao.cn/courses/100?utm_source=weixin


课程难度：中级

你将学到：介绍常用的设计模式，并使用 Java 语言的完成实例练习，例如工厂模式、抽象工厂模式、单例模式、适配器模式、观察者模式、装饰者模式等。


5. Django 基础入门

https://www.lanqiao.cn/courses/1127?utm_source=weixin


课程难度：初级

你将学到：Django 框架的组成结构、MTV 模式、视图操作等。



02
Linux 运维


1. Linux 基础入门

https://www.lanqiao.cn/courses/1?utm_source=weixin


课程难度：初级

你将学到：Linux 常用命令、用户与权限管理、目录结构与文件操作、环境变量、管道与数据流重定向等基本知识点。


2. Vim 基础入门

https://www.lanqiao.cn/courses/2?utm_source=weixin


课程难度：初级

你将学到：使用强大的 Vim 编辑器，学习 Vim 六种基本模式、游标移动、删除文本、重复命令等。


3.Git 与 GitHub 入门实践

https://www.lanqiao.cn/courses/1035?utm_source=weixin


课程难度：初级

你将学到：在 GitHub 上创建仓库、克隆 GitHub 上的仓库到本地、添加修改到暂存区以及撤销修改、配置个人信息等。


4. Nginx 运维基础入门

https://www.lanqiao.cn/courses/95?utm_source=weixin


课程难度：初级

你将学到：Nginx 的部署、配置、优化及案例实战。



03
云计算与大数据


1.Hadoop 基础入门

https://www.lanqiao.cn/courses/237?utm_source=weixin


课程难度：初级

你将学到：大数据领域常见的组件，如 Hadoop、Mapreduce、HBase、Mahout等。


2.Scala 开发教程

https://www.lanqiao.cn/courses/490?utm_source=weixin


课程难度：初级

你将学到：Scala 的基础语法、类和对象、基本数据类型、控制语句以及函数等方面的知识。


3.HIVE 教程

https://www.lanqiao.cn/courses/38?utm_source=weixin


课程难度：初级

你将学到：可以将结构化的数据文件映射为一张数据库表，并提供简单的 sql 查询功能；还可以将 sql 语句转换为 MapReduce 任务运行。



04
数据库


1. MySQL 基础课程

https://www.lanqiao.cn/courses/9?utm_source=weixin


课程难度：初级

你将学到：在 MySQL 数据库中学习并实践了 SQL 常用语法及约束、索引、视图、SELECT 查询、修改与删除等基本操作。


2. MongoDB 基础教程

https://www.lanqiao.cn/courses/12?utm_source=weixin


课程难度：初级

你将学到：MongoDB 基本的集合操作、高级查询以及索引与聚合。



05
Web 前端


1.Python 识别登录验证码

https://www.lanqiao.cn/courses/364?utm_source=weixin


课程难度：中级

你将学到：通过一个简单的例子来实现登录验证码识别，学习到 Python 基本知识，PIL 模块的使用和破解验证码的原理。


2.HTML5 简明教程

https://www.lanqiao.cn/courses/43?utm_source=weixin


课程难度：初级

你将学到：从网站的基础概念开始，带你了解其运行机制，还会涉及 HTML5 的内容，这是 HTML 的最新标准，它添加了一些新的语法特征。


3. Python + 高德 API 实现地图找房

https://www.lanqiao.cn/courses/599?utm_source=weixin


课程难度：初级

你将学到：使用 Python 脚本演示爬取某租房网站的房源信息，利用高德的 API 在地图上标出房源地点，划出距离工作地点1小时内可到达的范围。
