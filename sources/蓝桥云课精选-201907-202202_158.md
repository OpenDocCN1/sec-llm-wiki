随着无人超市、人脸识别、无人驾驶，众多使用场景的普及，**【目标检测】**正成为计算机视觉最有前景的方向。

我们都知道，通过眼睛看世界对于人类来说，是一种与生俱来的本能，但是对于计算机来说，理解图片内容是非常困难的事情。

**而「目标检测」要做的，不止是理解图片内容，还要识别图片中的物体，并标出位置。**如下图所示，通过检测算法的帮助，计算机不仅能识别出图中的动物，还可以标记出其所处的位置。又比如在自动驾驶中，计算机需要识别车辆、行人、红绿灯、道路等信息，才能保证安全驾驶。

## 目标检测的历史  
  
**从传统到深度学习**  
  
**在过去 20 年中，目标检测大致可以分为「传统目标检测」和「深度学习」两个时期：**![](../Images/5b8d7a0871dc83d0cd2135a7dd5dbd47.png)

在 2014 年前，早期的目标检测大多基于手工特征构建。由于缺乏有效的图像表示，人们别无选择，只能设计复杂的特征表示及各种加速技术对有限的计算资源物尽其用。

随着深度学习的崛起，目标检测的发展和应用得以大大提速。如今，目标检测已经广泛的应用于我们的日常生活中，如自动驾驶、安保监控、医疗影像、机器视觉等领域。

基于深度学习的检测算法可分为两类，一类是使用基于候选区域（Region Proposal）的方法先找出图片中可能存在目标的区域，然后通过卷积神经网络对该·区域进行分类；另一类是直接使用卷积神经网络预测目标所属类别的概率和其在图片中的位置坐标。

### 在学习目标检测的相关知识之前，先给大家介绍一下需要用到的工具：  

`OpenCV` 是一个基于 C++ 编写的轻量级高效的开源许可发行的跨平台计算机视觉库，可运行在多种操作系统上：Windows、Mac OS、Linux、Android。由于其具有友好的可读性和运行的效率，故获得大量开发者的青睐，同时其还提供 Python、Ruby 等语言的接口方便开发者调用。`NumPy` 是一个支持处理多维度大型矩阵的 Python 科学计算包。在对图像进行处理时经常会用到 NumPy，OpenCV 中读取存储图片都是以 NumPy 形式完成的。利用 NumPy 我们可以轻松的以多维数据的形式呈现图片，并对图片进行重组、计算、数值分析等操作。`TensorFlow` 是一个开源的机器学习平台，其广泛应用于机器学习和深度学习算法实现上。其可运行在多种平台上，如 PC、移动和分布式平台。支持多种计算机语言：C++、Python、Java、Go 等。由于其灵活、便捷、高性能以及活跃的社区等因素使得 TensorFlow 成为目前最受欢迎的机器学习开源框架之一。`scikit-learn` 是基于 Python 的开源机器学习工具，其涵盖大部分机器学习算法，包括分类、回归、非监督分类、数据降维、数据预处理等，是一款高效的数据挖掘和分析的工具。其通过 NumPy、SciPy 和 Matplotlib 等实现多种算法并且可在各种环境中使用。`scikit-image` 是一个基于 Python 的开源图像处理工具，其将图片作为 NumPy 数组，并包括分割、几何变换、过滤等处理方法。
