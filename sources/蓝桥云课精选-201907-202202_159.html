《神雕侠侣》中，杨过断臂后摔下山崖，偶遇独孤求败剑冢和神雕，短时间内就从二流高手成长为金轮法王级别的顶级高手。

《七龙珠》里，孙悟空爬上卡林塔，在猫仙人的训练下，三天内战斗力爆增，打败了桃白白和比克大魔王。
类似的情节还有很多，鸣人到妙木山修炼仙术后打败佩恩；张无忌误入阳顶天的墓穴练就乾坤大挪移，打退六大门派等等……
每个少年都幻想过这样“十倍速修炼”的黄金时刻，短时间内功力倍增，神挡杀神，佛挡杀佛。
殊不知离我们最近的黄金时刻就有一个，那就是「毕业设计」。
毕业设计是整个大学四年的总结。在毕业设计中，你的学习能力、分析能力、沟通能力、抗压能力，都会经历一次质的飞跃。
一个好的毕业设计，不但能帮助你得奖、考研，更能让你在进入社会后的面试中，比别人更有底气。
今天给大家推荐 10 个适合做毕业设计的 Python 项目，分为游戏、网站开发、区块链、人工智能、爬虫几个类别，大家可以根据自己的兴趣进行选择。
最重要的是，这些项目都有很大的拓展空间，你可以发挥自己的创造力，在基础项目上加入更多功能，实现专属于你的作品。

一、Python 实现四子棋游戏（有 Ai 功能）

首先利用 Pygame 库构建四子棋游戏的界面和玩法。然后借助蒙特卡洛算法为游戏添加 AI，支持人机对战功能。难度系数越大，AI 搜索范围越广，它所能做出的决定越明智。

地址：https://www.lanqiao.cn/courses/746

二、Python 实现贪吃蛇和俄罗斯方块

基于 Pygame 开发贪吃蛇和俄罗斯方块，难度由浅入深，内容通俗易懂，可以在源代码基础上加入更多玩法。

地址：https://www.lanqiao.cn/courses/940

三、python 打造回合制战棋游戏

用 Python 实现一个仿英雄无敌的回合制战棋游戏，你将学到：

•Pygame 初始化和基本设置
•界面状态机的实现
•A Star 算法介绍与实现
•游戏生物管理组实现
•远程攻击火球实现
•游戏生物 AI 实现
•图形显示和事件处理
•界面按钮功能实现
•游戏生物行走和攻击实现
•Json 关卡地图配置文件设置
•攻击伤害显示
•游戏六边形地图实现
地址：https://www.lanqiao.cn/courses/1516

四、Python 构建自己的比特币系统

用 Python 实现自己的比特币系统，共 8 个版本层层递进，不断迭代、优化，你将学到：

•比特币的概念

•数字签名技术

•工作量证明

•UTXO 集

•散列算法

•区块链

•比特币交易

•比特币网络

地址：https://www.lanqiao.cn/courses/3056

五、Python 实现中文错别字高亮系统

用 python 实现一个错别字高亮系统，输入 MarkDown 文档，即可输出一个高亮过疑似错别字的 HTML 文件。
地址：https://www.lanqiao.cn/courses/828

六、Python 实现简易浏览器

使用 Python + PyQt 5 打造一个简单的浏览器，学习和使用 QT 各个组件的使用方法。
地址：https://www.lanqiao.cn/courses/705

七、基于 Flask 与 MySQL 实现番剧推荐系统

基于 Python 的 Flask 框架和 MySQL 实现番剧推荐系统。你将学到：
• Python 语言应用
• 数据库表的拆分与设计
• MySQL 的 Python 接口的使用
• HTML 与 CSS 基础
• http 请求的处理
• Virtualenv 虚拟环境搭建
• Flask 框架的使用
• 复杂查询语句的使用
• Jinja2 模板引擎的使用
• 推荐算法的简易设计
地址：https://www.lanqiao.cn/courses/633

八、Python 实现搜索引擎

从基础爬虫开始讲起，带你逐步了解「索引构建」「索引压缩」「排名算法」等核心知识，最后利用 sanic 框架构建后端，实现一个完整的垂直搜索引擎站点。
地址：https://www.lanqiao.cn/courses/1196

九、Python + 高德 API 实现地图找房

首先使用 Python 爬取租房网站的房源信息，再利用高德的 API 在地图上标出房源地点，划出距离工作地点 1 小时内可到达的范围。在项目实现的过程中学习 Requests 、BeautifulSoup、CSV 等库的使用。
地址：https://www.lanqiao.cn/courses/599

十、Django 实现在线作业管理系统

使用 Django 框架搭建一个完整的在线作业管理系统，该系统包含教师端和学生端，教师能够创建课程、发布作业、统计作业、对作业进行评论以及打分等；学生能够加入课程、查看作业并提交作业、对作业进行评论等；系统管理端则使用 Django 自带的 admin 后台对用户信息、作业信息进行管理。
地址：https://www.lanqiao.cn/courses/2622
