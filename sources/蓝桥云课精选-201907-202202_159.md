### 一、Python 实现四子棋游戏（有 Ai 功能）

![](../Images/887cca39424bf7536bef81e9f00493ed.png "null")

首先利用 Pygame 库构建四子棋游戏的界面和玩法。然后借助蒙特卡洛算法为游戏添加 AI，支持人机对战功能。难度系数越大，AI 搜索范围越广，它所能做出的决定越明智。

地址：https://www.lanqiao.cn/courses/746

### 二、Python 实现贪吃蛇和俄罗斯方块

![](../Images/62195cb65a5a367935395ddf1abef16e.png "null")

基于 Pygame 开发贪吃蛇和俄罗斯方块，难度由浅入深，内容通俗易懂，可以在源代码基础上加入更多玩法。

地址：https://www.lanqiao.cn/courses/940

### 三、python 打造回合制战棋游戏

![](../Images/a833dab1762dee7f349bd083b2c8cf44.png "null")

用 Python 实现一个仿英雄无敌的回合制战棋游戏，你将学到：

•Pygame 初始化和基本设置•界面状态机的实现•A Star 算法介绍与实现•游戏生物管理组实现•远程攻击火球实现•游戏生物 AI 实现•图形显示和事件处理•界面按钮功能实现•游戏生物行走和攻击实现•Json 关卡地图配置文件设置•攻击伤害显示•游戏六边形地图实现地址：https://www.lanqiao.cn/courses/1516

![](../Images/c29139cedc0b7bfa7a404fbe892e338b.png "null")

•数字签名技术

•工作量证明

•UTXO 集

•比特币交易

•比特币网络

地址：https://www.lanqiao.cn/courses/3056

### 五、Python 实现中文错别字高亮系统

![](../Images/2b9fc0a266e1ce977ccaeafe0bc989b2.png "null")

用 python 实现一个错别字高亮系统，输入 MarkDown 文档，即可输出一个高亮过疑似错别字的 HTML 文件。地址：https://www.lanqiao.cn/courses/828

### 六、Python 实现简易浏览器

![](../Images/9d884f4ede960c7a483d1aea2765dad2.png "null")

使用 Python + PyQt 5 打造一个简单的浏览器，学习和使用 QT 各个组件的使用方法。地址：https://www.lanqiao.cn/courses/705

### 七、基于 Flask 与 MySQL 实现番剧推荐系统

![](../Images/2ab967e907d993cc5939ce50e77fa1f1.png "null")

基于 Python 的 Flask 框架和 MySQL 实现番剧推荐系统。你将学到：• Python 语言应用• 数据库表的拆分与设计• MySQL 的 Python 接口的使用• HTML 与 CSS 基础• http 请求的处理• Virtualenv 虚拟环境搭建• Flask 框架的使用• 复杂查询语句的使用• Jinja2 模板引擎的使用• 推荐算法的简易设计地址：https://www.lanqiao.cn/courses/633

### 八、Python 实现搜索引擎

![](../Images/11715efb1ba76cf14b2cfa668713a7af.png "null")

从基础爬虫开始讲起，带你逐步了解「索引构建」「索引压缩」「排名算法」等核心知识，最后利用 sanic 框架构建后端，实现一个完整的垂直搜索引擎站点。地址：https://www.lanqiao.cn/courses/1196

### 九、Python + 高德 API 实现地图找房

![](../Images/db227311c603509e1b10b32b5df6ea68.png "null")

首先使用 Python 爬取租房网站的房源信息，再利用高德的 API 在地图上标出房源地点，划出距离工作地点 1 小时内可到达的范围。在项目实现的过程中学习 Requests 、BeautifulSoup、CSV 等库的使用。地址：https://www.lanqiao.cn/courses/599

### 十、Django 实现在线作业管理系统

![](../Images/2d0171e81314a5ee9e510df774683e0b.png "null")

使用 Django 框架搭建一个完整的在线作业管理系统，该系统包含教师端和学生端，教师能够创建课程、发布作业、统计作业、对作业进行评论以及打分等；学生能够加入课程、查看作业并提交作业、对作业进行评论等；系统管理端则使用 Django 自带的 admin 后台对用户信息、作业信息进行管理。地址：https://www.lanqiao.cn/courses/2622**祝大家都能顺利毕业，为大学时光划上一个完美的句号~**
