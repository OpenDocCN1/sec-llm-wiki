互联网的发展，加上云计算的出现，导致企业内外需要管理的服务器数量大幅增长。过去我们可能只需要管理内部的物理服务器机架，而现在要管理遍布世界各地的服务器，随之而来的是运维的难度、人数、成本的增加。
在这种情况下，自动化运维工具就派上了用场。在过去，我们需要对各个服务器进行配置调整，手动管理大量系统信息，难免会有各种各样的事故发生。有了自动化运维工具，用户可以极容易地配置和维护数百台乃至千台的服务器，即使是小公司，企业也可以用来简化和管理设施的配置和运行。
现在主流的自动化运维工具有：Ansible、SaltStack、Puppet 等。其中Puppet 由于语法复杂，且可移植性比较差，使用者已经慢慢变少；而 Ansible 和 SaltStack 使用 python 编写，具有良好的可移植性，成为目前最流行的自动化运维工具。

SaltStack


SaltStack 是一个全新的基础平台管理工具，部署轻松，只需要几分钟即可运行起来，扩展性足以支撑管理上万台服务器，数秒钟即可完成数据传递，经常被描述为 Func 的加强版 + Puppet 的精简版。

SaltStack 具备配置管理、远程执行、监控等功能，可以根据不同业务可以进行配置集中化管理、分发文件、采集服务器数据、系统操作及软件包管理等，是运维人员提高工作效率、规范业务配置与操作的利器。

SaltStack 最大的特点是「快」。SaltStack 使用号称世界上最快的消息队列 ZeroMQ 传输数据，从网上的数据来看，比 ansible 快大约 40 倍。另外它采用了 RSA Key 方式确认身份，传输采用 AES 加密，使得安全性也得到了保障。

最为重要的一点是，SaltStack 是开源的，而且使用 Python 实现。这意味着我们可以对其进行二次开发，在其基础上加入我们想要的功能。

正因为 SaltStack 强大的功能、便捷的操作、碾压的性能和可定制化的结构，让它被越来越多企业采用。在高级运维工程师的招聘中，SaltStack 几乎是一个必选项，是从普通运维成长为高级运维无法跳过的一环。
