1972-1973 年，美国贝尔实验室为了描述和实现 UNIX 操作系统（一个具有强大影响力的操作系统），改良了 B 语言，大名鼎鼎的 C 语言就这样诞生了。  

C 语言相当灵活，用于执行几乎所有计算机可以完成的任务，既可以用于编写应用程序，还可用于编写操作系统，Windows 和 Linux 操作系统的内核就是使用 C 语言开发的。C 语言包含了基本的编程元素，后来的很多语言（C++、Java 等）都参考了 C 语言，**说 C 语言是现代编程语言的开山鼻祖毫不夸张，它改变了编程世界。**

不但是开山鼻祖，更老当益壮。这门年近 50 的语言今天依然稳稳占据编程语言榜的前两名，时不时还会超越 Java，坐上第一的王座：

![](../Images/60d28d8099052452b1b12e502d70f229.png)

（TIOBE 编程语言榜）

下面这张图同样来自 TIOBE，大家可以发现从 2002 年至今，C 语言在编程中占有比例一直保持稳定，java 语言却呈现下跌态势。为什么 java 所占比例一直在下跌，而 C 语言却保持稳定呢？

![](../Images/b448fb86d1f32a65325a3d0e94a4ba85.png)

主要是因为能够代替 java 的语言不断涌现和上升（Python、Go 语言等等），而 C 语言能保持稳定，**是因为在很多领域 C 语言是唯一的选择。**比如说做操作系统、做嵌入式系统。

美国一位资深软件专家写了一篇文章，题为 “对计算机学生的建议”，可供参考。他说 “**大学生毕业前要学好 C 语言，C 语言是当前程序员共同的语言**，比你在大学学到的现代语言（比如 ML，java，python 或者其它流行的语言）都更接近机器”。他指出 “不管你懂多少延续、闭包、异常处理，只要你不能解释为什么 `while(*s++=*t++)` 的作用是复制字符串，那你就是在盲目无知的情况下编程，就像一个医生不懂最基本的解剖学就在开处方”。

**今天给大家推荐一本超系统的 C 语言教材 —— 《C 编程从入门到实践》。**全书共 25 章。不仅介绍了 C 语言的基础和核心知识（如开发工具、语法、运算符、表达式、输入 / 输出、流程控制、数组、字符串、函数），还讲解了 C 语言中的重点和难点（如指针、结构体、共用体和枚举、链表、位运算、预编译、文件操作、调试、内存管理、高级编程技术、算法、数据结构、网络编程技术等）。最后通过 4 个综合实例，介绍了 C 语言在综合项目中的应用，适合 C 语言的初学者，和有一定 C 语言基础的读者学习。
