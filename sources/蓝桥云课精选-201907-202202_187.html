对于 Java 程序员来讲，Spring、Maven 都是外在的武功招式，而 JVM 就是内在的内功心法。在 Java 的面试中，面试官几乎一定会问到 JVM 相关的问题，什么线程、内存模型、JVM 运行时内存、垃圾回收与算法、GC 垃圾收集器、JAVA IO/NIO 、JVM 类加载机制等等知识点，如果答不好，会直接影响薪酬的多少。

因此，对 JVM 的理解程度也是 Java 程序员水平高低的分水岭之一。

Java 的 JVM 性能调优不外乎以下几个知识点：

  • Java 内存溢出
  • 垃圾回收
  • 垃圾收集器
  • JVM参数
  • 生产环境排查
  • Java中的四种引用
