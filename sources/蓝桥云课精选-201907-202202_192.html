加班、996、辞职，已经成为了现代人的常态。就像之前一封很火的辞职信，一位杭州萧山的姑娘列出了自己的 7 条离职原因：

总结就是：上班时间紧、没时间交男友、没时间旅游、别人请假自己要加班。汇成一句话：没时间！
确实，很多岗位的工作都是低效重复的，根本没有坚持下去的动力。回忆一下，你是不是也曾遇到过这样的工作场景：
  • 每个月都要整理全公司员工的考勤、工资报表，对着 Excel 一条一条输入，几天下来看什么都有一道道的残影……
  • 老板需要某类型上市公司的全部资料，你输入股票代码 — 复制粘贴 — 放入 Excel 循环上千次，周末假期又打水飘……
  • 写论文、报告时要收集大量新闻素材，每个网页都要手动另存为文件；
  • 主管让你整理存了好几年数据的文件夹，按照类型和时间分组，同时每个文件按时间重新命名……
这些工作其实难度都不大，但它们有一个共同的特点，就是重复、枯燥、费时费力！实际上，我们换一种方法，就可以快速完成这些工作，节省数倍的时间。那就是通过 Python 来实现自动化办公，减少手动操作，从每天工作 8 小时进化为每天工作 10 分钟！
利用 Python 进行办公自动化是一种高效且智能的方式。即使你不是一个码农，不从事写代码相关的工作，学会 Python 办公自动化，也可以让你从日复一日的重复劳动中解放出来。
Python 的用法非常简洁、灵活，就像汉语、英语这类自然语言一样容易理解和使用。
同时 Python 也十分强大！丰富、完备的功能模块，可以帮助你批量操作文件夹、Word、Excel、PPT、PDF、网页等文件！
