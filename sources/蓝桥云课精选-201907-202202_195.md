Vue.js 是一个基于 JavaScript 的框架，在最近几年中发展迅速。这种增长背后的原因很多，包括框架的简单性、易于集成、用户友好性等等，这些都让 Vue 成为前沿开发中最热门的框架之一。

相比其他框架，Vue 最大的特点是「灵活性」。不论是大中小项目，都可以快速开发。而且 Vue 由国人开发，有中文文档，上手速度快，对新手极为友好，掌握几个基本的 API 就可以进行开发了。**所以对于初学者来说，用 Vue 快速开发一个毕业项目，或者实现一个创业想法再合适不过了。**

**随着 Vue3 的推出，Vue 更上一层楼。**在 Github、SegmentFault 等编程社区，Vue 的内容都异常火爆，包括饿了么、美团、天猫大厂也都在使用 Vue 进行开发和重构工作。 对于前端初学者， Vue 都是一门必修课，没有它你的求职会到处碰壁。

**今天给大家推荐一门人人都可以上手的 Vue3 课程——《Vue 3 记账本实战》。课程分为基础篇和实战篇两部分，基础篇带你学习Vue3 的语法和特性，实战篇则手把手带你开发一个移动端的记账本项目，非常适合应届生和求职者用来做面试的敲门砖～**
