**1995 年，Sun 微系统公司首次推出了 Java 语言。到今天 26 年过去了，Java 依然活着，并且活得相当好。**

**如今，80% 以上的企业都在使用 Java**，其中不乏 Amazon、Google、京东、阿里等大型互联网平台**。**在 TIOBE 的 2019 年度编程语言排行榜中，Java 独占榜首，有 17% 的开发者都在使用 Java。

![](../Images/8a8c291f537490adab3d4712dd365bd6.png)

不仅在编程语言排行榜上常年霸榜，Java 在综合就业方面也是独占鳌头。根据资深码农公布 2020 年中国语言排行榜，Java 语言的需求量依然第一，平均薪资高达 14470 元。

**为什么 Java 会如此流行？**可能是因为它：

**无处不在** —— 全世界超过 30 亿的设备都在运行 Java 代码；

**薪资可观** —— Quartz 报告显示，Java 是业内薪资最高的语言之一；

**市场紧缺** —— 国内每天 Java 人才缺口达 20 万；

**转岗方便** —— 无论是后端、Web 还是安卓开发，Java 都可以胜任；

**可以说，学好了 Java，不愁没有用武之地，未来的开发之路也会非常宽广。**

作为含金量极高的职位，很多人都希望能从事 Java 工程师的工作，那么怎样才能学好 Java 呢？这可能是每个刚接触 Java 语言的人都会问的一个问题。
