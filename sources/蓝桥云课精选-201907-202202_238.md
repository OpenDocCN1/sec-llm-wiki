**提起 Java 社区近几年来最有影响力的项目，也是 Java 企业级应用开发的首选技术，就不得不提今天的主角：**

**Spring Boot “春靴”**

![](../Images/a22e4813a39a652c3bec3f139480b187.png)狂奔的 Spring Boot

**Spring Boot 到底凭什么成为 Java 社区最具影响力的项目？**说直白点，他爹 Spring 本来就骁勇善战独霸一方，在 Java EE 项目中得到广泛使用。

但是，Spring 复杂、繁琐和臃肿的 XML 配置方式配置使得开发人员在实际使用过程中变得非常痛苦。

而 Spring Boot 几乎继承了所有 Spring 框架的优点，同时还可以让项目的配置更简化、编码更简化、部署更方便。开箱即用的极度舒适体验，大大提高了开发效率。  
**1\. 独步武林，万剑归宗**Spring Boot 嵌入了 Tomcat、Jetty 等容器，不需要打包成 war 即可部署到容器中，并且可以 jar 包独立运行。靠天靠地不如靠自己。![](../Images/bf9b13c07105df8be2b6abc6dc461e04.png)关系数据库和非关系数据库，支持！自动管理依赖，支持！自带应用监控，支持！各种 IDE，支持！秒速构建项目，支持！  
**2\. 良田千亩，富甲一方**无论从当前热度来看，还是从以后的市场前景，Spring Boot 就像 Java 本身一样屹立常青。国内越来越多的企业使用 Spring Boot，被评为 “最流行的 Java 框架”。![](../Images/2bf27b5bf00cc5be2371c4a9d7573869.png)并且这不像其他技术，火一段时间就凉了。依托 Java 的强大市场需求，Spring Boot 技术也会稳定地吃香。
