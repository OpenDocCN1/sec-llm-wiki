随着 To B 市场的大热，企业出现了各种「**管理系统需求」**。**而对于前端而言，最大的工作量就是各种表单和表格的实现。**虽然本身并没有什么技术含量，很多时间是复制粘贴，改改参数，做的时间长了不免觉得无聊。对于这类工作，我们当然是能简化就简化，最好用可视化的方式，妥妥拽拽就可以完成功能——这就是可视化表单诞生的最初原因。![](../Images/79b28b25181a67e7a2ce1e52459c8958.png)借助可视化表单，可以解决大量的重复劳动，采集的流程变成了：

*   首先可视化表单进行设计；
*   然后后端进行配置的存储；
*   最后再回显给用户；
*   采集数据。

**今天给大家介绍一个 Github 上热门的表单设计神器——「****f-render****」。****该项目已经收获了 1200 多 Star，****它是基于 ****vue-ele-form**** 开发的可视化表单设计工具，适用于各种流程引擎和动态表单项目，可以大大节省你的开发时间。**

## **它有以下特性：**

*   组件方式：以组件方式接入，1 分钟轻松接入；
    
*   体积小：Gzip 压缩后 100k 左右；
    
*   易扩展：可以在不更改源码的情况下增删改属性、组件；
    
      
    

## 如何使用？

## **只需要三步就可以快速接入**「****f-render****」：****

```

\# npm install vue-ele-form -S
\# npm install f-render -S
```
