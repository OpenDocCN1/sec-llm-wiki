一直以来程序员都给人高智商低情商的印象。

不懂浪漫不会哄女生。

心中的浪漫只有：编译原理，图形学，操作系统。

但有一个程序员却写下了这样的句子：

“你好哇，李银河。告诉你，一想到你，我这张丑脸上就泛起微笑。不管我本人多么平庸，我总觉得对你的爱很美。“

“我的灵魂有很多地方玩世不恭，对人傲慢无礼。但是它有一个核心，这个核心害怕黑暗，柔弱得像绵羊一样，只有顶平等的友爱才能使它得到安慰，你对我是属于这个核心的。”
—— 著名作家 & 第一代程序员王小波
如果你继续了解，就会发现程序员不但有创意，而且满满都是浪漫，他们甚至可以用代码写出最美的情诗：

// 我和你原本就是两个世界的人，一直都在不停的向前走。

// 直到有一天在某一刻相遇，我们才在彼此的世界里相拥。

// 然后追寻着各自的梦想，却又活在我们自己的天空下。

// 我要和你手牵着手共同的走下去，就像这跳不出的循环，直到永远。


// 你爱或者不爱我，爱就在那里，不增不减。


// 在你想念我的时候，我也想念着你。在你不想念我的时候，我也一直想念着你。


// 如果 “你若不离不弃” 这个条件为真

// 执行 “我必生死相依” 

// 否则执行 “后会无期”


// 陪伴是最长情的告白。

// 最浪漫的事，就是和你一起慢慢变老。


对程序员来说，代码不仅能让你拥有更好的生活，说不定还能收获一份爱情。

七夕之际，实验楼也为你准备了一份礼物，希望能让你下次说“我爱你”时更有底气。
