## HTML 基础结构

首先我们来创建如下目录结构：

![](../Images/3e6880f9987b877abaaa3698cba82ce3.png)

在 img 目录下获取地图图片，打开终端，执行以下命令：

```
1.  `$ cd img`
    
2.  `$ wget https://labfile.oss.aliyuncs.com/courses/2673/map_black_bg.png`
    
```

![](../Images/65012039a8fdab7075b7ee23849f0b1d.png)

在 `index.html` 文件中写入如下代码：

```
1.  `<!DOCTYPE html>`
    
2.  `<html lang="en">`
    
3.  `  <head>`
    
4.  `    <meta charset="UTF-8" />`
    
5.  `    <meta name="viewport" content="width=device-width, initial-scale=1.0" />`
    
6.  `    <title>热点地图</title>`
    
7.  `    <!-- 引入CSS -->`
    
8.  `    <link rel="stylesheet" href="./index.css" />`
    
9.  `  </head>`
    
10.  `  <body>`
     
11.  `    <!-- 地图 -->`
     
12.  `    <div class="china-map"></div>`
     
13.  `  </body>`
     
14.  `</html>`
     
```

为了让我们的城市能够显示在地图上，在这里我选择使用 CSS 相对定位与绝对定位的方式。

在 `index.css` 文件中写入如下代码：

```
1.  `/* CSS 通配符 * 号，表示所有的元素一开始默认的内外边距为 0 */`
    
2.  `* {`
    
3.  `  margin: 0;`
    
4.  `  padding: 0;`
    
5.  `}`
    
6.  
    
7.  `body {`
    
8.  `  /* 背景色 */`
    
9.  `  background: #31363a;`
    
10.  `}`
     
11.  
     
12.  `.china-map {`
     
13.  `  /* 给地图加上相对定位 */`
     
14.  `  position: relative;`
     
15.  `  /* 给地图设置宽高 */`
     
16.  `  width: 747px;`
     
17.  `  height: 617px;`
     
18.  `  /* 设置背景图片，指定为不重复，并且居中 */`
     
19.  `  background: url("./map_black_bg.png") no-repeat center;`
     
20.  `  /* 将地图设置为离顶部60px，左右居中 */`
     
21.  `  margin: 60px auto 0;`
     
22.  `}`
     
```

### 地点样式设置

地图成功显示后，我们需要在上面设置地点以及地点的样式。

在 `index.html` 中加入以下代码：

```
1.  `<div class="china-map">`
    
2.  `  <!-- 地点区域 -->`
    
3.  `  <div class="region">`
    
4.  `    <!-- 地点显示的小圆点 -->`
    
5.  `    <div class="dot"></div>`
    
6.  `    <!-- 向外扩散的圆圈 -->`
    
7.  `    <div class="place"></div>`
    
8.  `    <!-- 地名 -->`
    
9.  `    <div class="txt">青海</div>`
    
10.  `  </div>`
     
11.  `</div>`
     
```

在 `index.css` 中加入以下代码：

```
1.  `* {`
    
2.  `  margin: 0;`
    
3.  `  padding: 0;`
    
4.  `}`
    
5.  
    
6.  `body {`
    
7.  `  background: #31363a;`
    
8.  `}`
    
9.  `/* 地图 */`
    
10.  `.china-map {`
     
11.  `  position: relative;`
     
12.  `  width: 747px;`
     
13.  `  height: 617px;`
     
14.  `  background: url("./map_black_bg.png") no-repeat center;`
     
15.  `  margin: 60px auto 0;`
     
16.  `}`
     
17.  `/* 区域地点 */`
     
18.  `.region {`
     
19.  `  /* 绝对定位 */`
     
20.  `  position: absolute;`
     
21.  `}`
     
22.  `/* 小圆点 */`
     
23.  `.region .dot {`
     
24.  `  position: absolute;`
     
25.  `  top: 50%;`
     
26.  `  left: 50%;`
     
27.  `  margin: -5px 0 0 -5px;`
     
28.  `  width: 10px;`
     
29.  `  height: 10px;`
     
30.  `  background: #a2a9b4;`
     
31.  `  opacity: 1;`
     
32.  `  border-radius: 50%;`
     
33.  `}`
     
34.  `/* 向外扩散的圆圈 */`
     
35.  `.region .place {`
     
36.  `  position: absolute;`
     
37.  `  top: 50%;`
     
38.  `  left: 50%;`
     
39.  `  margin: -33px 0 0 -33px;`
     
40.  `  width: 66px;`
     
41.  `  height: 66px;`
     
42.  `  border: 2px solid #b7b7b7;`
     
43.  `  border-radius: 50%;`
     
44.  `  /* 透明度 */`
     
45.  `  opacity: 0.12;`
     
46.  `  /* 阴影 */`
     
47.  `  box-shadow: 0 0 4px #82878f inset;`
     
48.  `}`
     
49.  `/* 地名 */`
     
50.  `.region .txt {`
     
51.  `  position: absolute;`
     
52.  `  top: -20px;`
     
53.  `  left: 10px;`
     
54.  `  font-size: 14px;`
     
55.  `  color: #ccc;`
     
56.  `  width: 50px;`
     
57.  `}`
     
```

预览效果：

![](../Images/f344b3693168fafef9b3be3f37820c91.png)

如何将这个地点放置在相应位置上呢？这个时候就要使用 `left` 属性和 `top` 属性了，通过计算正确的偏移值，将地点放置在合适的位置上。

修改 `.region` 的样式：

```
1.  `.region {`
    
2.  `  position: absolute;`
    
3.  `  top: 302px;`
    
4.  `  left: 308px;`
    
5.  `}`
    
```

预览效果：

![](../Images/8fa0da09e219f79c39d1208c4f5f2517.png)

青海就已经显示在正确的地方上了。但是我们转念一想，如果我们还有一个城市，比如北京，这个时候是不是该这样：

```
1.  `.region2 {`
    
2.  `  position: absolute;`
    
3.  `  top: 229px;`
    
4.  `  left: 559px;`
    
5.  `}`
    
```

不过如此一来，每当创建一个城市，就要新写一个 CSS 类，并且每一个类中都会有同样的代码 `position:absolute`，如果大篇幅的重复会增加代码的冗余度。所以这个时候，我们可以专门新建一个类来放置每一个城市的偏移值，修改 `index.css` 文件，增加如下代码：

```
1.  `.region {`
    
2.  `  position: absolute;`
    
3.  `}`
    
4.  `/* 青海 */`
    
5.  `.region-qh {`
    
6.  `  top: 302px;`
    
7.  `  left: 308px;`
    
8.  `}`
    
9.  `/* 北京 */`
    
10.  `.region-bj {`
     
11.  `  top: 229px;`
     
12.  `  left: 559px;`
     
13.  `}`
     
```

修改 `index.html`：

```
1.  `<div class="china-map">`
    
2.  `  <!-- 青海 -->`
    
3.  `  <div class="region region-qh">`
    
4.  `    <div class="dot"></div>`
    
5.  `    <div class="place"></div>`
    
6.  `    <div class="txt">青海</div>`
    
7.  `  </div>`
    
8.  `  <!-- 北京 -->`
    
9.  `  <div class="region region-bj">`
    
10.  `    <div class="dot"></div>`
     
11.  `    <div class="place"></div>`
     
12.  `    <div class="txt">北京</div>`
     
13.  `  </div>`
     
14.  `</div>`
     
```

预览效果：

![](../Images/e6a6d067cc7bbd1d1da4f18bf4e2f47f.png)

同样的道理，如果我们想设置不同地点有不同颜色的显示，我们可以专门新建一个颜色类：

修改 `index.html`：

```
1.  `<!-- 北京 -->`
    
2.  `<div class="region region-bj blue">`
    
3.  `  <div class="dot"></div>`
    
4.  `  <div class="place"></div>`
    
5.  `  <div class="txt">北京</div>`
    
6.  `</div>`
    
```

在 `index.css` 中加入以下代码：

```
1.  `/* 颜色*/`
    
2.  `.region.blue .place {`
    
3.  `  width: 120px;`
    
4.  `  height: 120px;`
    
5.  `  margin: -64px 0 0 -64px;`
    
6.  `  border: 1px solid #009fd9;`
    
7.  `  box-shadow: 0 0 12px #009fd9 inset;`
    
8.  `}`
    
9.  
    
10.  `.region.blue .dot {`
     
11.  `  background: #0080d9;`
     
12.  `}`
     
```

预览效果：

![](../Images/12b703c746c4395191a583ba30d2662d.png)

如此一来，如果我们想给一些地点加上样式，只需要为它加上像 `.blue` 这样的颜色类就好了。现在我们将其他的地点以及样式增加上去。
