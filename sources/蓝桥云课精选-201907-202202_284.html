2020年初，一场新冠肺炎疫情肆虐全球，新冠肺炎被世界卫生组织命名为2019-nCoV。

新冠疫情的爆发席卷全世界各个国家，至今仍有许多国家确诊病例及死亡人数在不断的上升。作为世界发达国家之一的美国，在这场灾难面前表现尤为糟糕，成为确诊病例及死亡人数最多的国家。
许多观点认为，西方国家之所以应对疫情迟缓，是因为民众对于疫情风险的漠视，对于风险的评估和预期不到位。然而事实上，新冠疫情肆虐不仅对人身生命安全造成了威胁，也对经济造成了巨大的冲击，全球金融市场出现大动荡，美国股指甚至出现了前所未有的三次熔断，各国经济都遭受了不同程度的冲击。
此外，疫情对于主流舆论的影响也较为深远，抗击疫情成为了社会主流的舆论场。这场疫情给人类的生活和生产带来太多的教训和启示，也是一场难得的风险警示和教育课。
因此，我将从数据分析和挖掘的角度出发，展现疫情对于社会，舆论，经济等不同方面的影响，通过数据的展现更能警醒人们要重视疫情，疫情尚未结束，群防群控仍需继续进行。
本项目将对目前新冠疫情对社会造成的影响进行分析，主要从以下三部分进行：
一、对世界疫情现状进行可视化，来展现世界疫情目前的严峻性。
二、分析疫情对于新闻舆论的影响。
三、通过国内的经济数据来展现疫情对于经济社会的影响。

新冠疫情新闻分析

下面对新冠疫情期间，疫情的新闻情况进行简单的分析，我们对新闻标题进行汇总统计并通过结巴分词的方式进行分词，获取不同词的词频，根据词频产生词云。
import jieba
import re
from wordcloud import WordCloud

def word_cut(x): return jieba.lcut(x)             #进行结巴分词

news=[]
reg = "[^\u4e00-\u9fa5]"
for i in data_news['title']:
    if re.sub(reg, '', i)!='':                   #去掉英文数字和标点等无关字符，仅保留中文词组
        news.append(re.sub(reg, '', i))          #用news列表汇总处理后的新闻标题

words=[]
counts={}
for i in news:
    words.append(word_cut(i))                    #对所有新闻进行分词
for word in words:
    for a_word in word: 
        if len(a_word)==1:
            continue
        else:
            counts[a_word]=counts.get(a_word,0)+1  #用字典存储对应分词的词频
words_sort = list(counts.items())
words_sort.sort(key=lambda x: x[1], reverse=True)

newcloud=WordCloud(font_path="../input/myfont/MSYHL.TTC",background_color="white",width=600,height=300,max_words=50)  #生成词云
newcloud.generate_from_frequencies(counts)
image=newcloud.to_image()     #转换成图片
image

可以看出，如果不受疫情影响，2020第一季度的GDP应该会高出很多，第一季度的实际GDP仅有预测GDP值的83%。


疫情对工业影响也比较大，2020第一季度的工业增长值仅为预测增长值的84%。
疫情对制造业影响也较为明显，2020第一季度的制造业增长值为预测增长值的79%，这可能源于疫情期间工厂的停工。

由于疫情期间普遍居家无法出门，消费持续低迷，批发与零售业走低。

相比于传统行业来讲，金融业并没有受到明显影响，甚至比预测值还有小幅增加，一方面这是由于金融业流动性强，另一方面金融债务等影响比较长远，短期并不明显。


信息传输、软件和信息技术服务业也是为数不多在疫情中不减反增的行业，疫情的爆发催生了线上办公的崛起，信息技术在对抗疫情的过程中大放异彩，因此从预测数据上来分析，疫情对于信息技术产业并没有明显影响。

总体来看，疫情对于各行业经济均有所冲击，特别是实体行业，制造业和服务业一类，对于信息金融产业并没有造成太大的影响。除了行业特点之外，疫情及时得以控制也是重要的因素。得益于疫情的快速控制，国内经济总体向上的势头并没有改变，疫情对于各行业的影响也是较为短暂的，在疫情严苛的考验下，行业经济仍然保持了增长的势头，疫情的及时控制对于经济发展至关重要。



总结


上半年的疫情对所有人都造成了很大的影响，因此对于疫情的数据分析是非常有意义的。但是限于种种原因，很多东西并没有深入进行挖掘。初始的想法是通过收集病人数据根据不同症状来对病情严重性进行建模分析，然而临床数据通常保密性高，没有足够的数据能够支撑分析；另一个想法是对疫情的发展进行一个预测，但是一方面国内疫情已经进入散发期，无法预测，只能选择美国等国家进行预测，然而查阅相关资料发现不管是传染病SEIR模型，LSTM神经网络分析也好，现有的项目预测的准确率都非常低，不但拐点预测可能失败，增长趋势甚至都很难预测，个人猜想大概是因为不同国家防疫措施和民众的态度变化导致不可量化因素太多导致的。因此，最后还是选择了疫情对社会影响这一比较容易量化的主题来做。
完成了这个项目，收获也颇为丰厚。最大的体验感受就是知道该做什么有时候可能比知道如何做更难，这可能也正是老手与新手的区别吧。学习了很多分析和建模方法，却苦于想不到使用的途径，不知道怎么用合适，这也是今后需要关注的问题。整个项目从数据收集到分析到建模，也算完整的体验了一遍数据分析的流程，既有完成项目所带来的喜悦，也强化了学过的知识和技能，希望未来能在这一道路上越走越远。
