PHP 语言是一个短生命周期的 Web 编程语言，在大部分程序员印象中都是用来做 Web 网站的。它没有像 Python 的 Twisted、Tornado，Java 的 Netty、Mina，JavaScript 的 Node.js 这样的框架，无法实现异步网络通信程序，但 Swoole 的出现让一切发生了改变。

Swoole 是当前国内最受欢迎的 PHP 扩展之一，它为 PHP 提供了一系列异步 IO、事件驱动、并行数据结构功能，很多大厂如腾讯等都在核心业务中大规模使用 Swoole。Swoole 的出现让 PHP 的使用范围可以扩展到移动通信、云计算、网络游戏、物联网、车联网、智能家居等领域。

可以说，Swoole 已经成为新时代 PHPER 的必备技能，而能否熟练掌握 Swoole ，也似乎也越来越成了初中级 PHPER 与高级 PHPER 的分水岭。
实验楼上线了一门《基于 Swoole 开发 Web 框架》课程，从源码层面剖析 PHP 并发编程和 Swoole 框架，最后手把手带你从零设计并实现一个 Web 框架，让你知其然，更知其所以然。

课程特色

  • 注重原理的讲解，让读者的基础更加牢靠，在以后职场上走得更远。

  • 步骤详细，即便你没有过多的 PHP 编程经验，也能让你在实验中没有任何障碍。

  • 课程有深度，亦有广度，不会浅尝辄止，深入剖析源代码，把所有的技术细节都展现给读者。
