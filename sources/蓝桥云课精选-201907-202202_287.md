#### **在万物互联时代，所有的品牌都需要一个甚至 N 个线上购物网站！****即使是小公司也会选择在外包网站发布需求，帮自己的企业开发网络商城。**

#### **对于程序员来说，学会「开发网络商城」，可以实现从普通程序员 — 全栈工程师 — CTO的蜕变；****还能接一些私活，一个项目就可以顶别人几个月的收入。**

**今天给大家带来的就是一个全栈的线上商城项目，项目采用了 Vue.js + SpringBoot 两大热门技术，带你实现一个完整且纯正的前后端分离线上商城。**

**![](../Images/a85403ca3a3eae4aaa2e6f303e93abad.png)**

教程共分为 5 个部分，从基础知识讲起，层层递进，分别是：

*   前后端分离的概念
*   Spring Boot 基础教程
*   Vue 基础教程
*   商城后端 API 开发
*   商城移动端开发

项目以 Spring Boot 和 Vue 技术栈为主线，采用前后端分离架构。不管你是初入职场或即将进入职场，想深入学习和了解 Spring Boot 框架和 Vue 的话，这个课程都是很好的选择，对于提升动手能力是一个不错的帮助。同时，这种大型的商城项目也能够丰富你的项目经验，提升你的个人竞争力。
