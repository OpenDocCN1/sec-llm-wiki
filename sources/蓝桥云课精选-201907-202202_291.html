Vue.js、React、Angular 一直是国内前端的三大主流框架，但在 2019 年 Vue 一骑绝尘，荣登 Github Star 排名第一。Vue.js 由华人「尤雨溪」所写（知乎：尤雨溪），被广泛用于各大公司中（饿了么、苏宁、美团、天猫等等）。与其他框架相比，Vue 更加轻便简洁，它自身拥有开箱即用的生态开发包（Vuex,Vue-Router）等，复杂性低、学习成本低，是一门比较好入门的前端框架。
4 月 16 日，尤雨溪发布了 Vue.js 3 版本，总结起来就是：

  • 更快了

  • 更小了

  • 更易于维护

  • 更多的原生支持

  • 更易于开发使用

针对全新的 Vue.js 3 版本，实验楼上线了《Vue.js 3 基础入门实战》，帮助你快速上手 Vue.js 3：
课程前半部分将通过对比讲解 Vue.js 3 与 Vue.js 2，带领同学们学习 Vue.js 3 基础 API、生命周期、组件通信等基础知识。后半部分主要通过 3 个项目：计算器、新冠疫情地图、网站评论功能，带大家进一步熟悉 Vue.js 3 的语法。
