1994 年，为了给自己的简历网站加一个计数器，Rammus Lerdorf 发明了一种新语言 —— **PHP**。

2 年后，PHP 3 问世了，它一经推出大受欢迎，当时最大的网站雅虎也转向使用PHP，**这开启了 PHP 占领世界的第一步！**又过了几年，3 个重量级的 PHP 开源项目相继问世，分别是：

*   MEDIAWIKI（维基百科使用的系统）
    
*   DISCUZ！（应用最广泛的论坛系统）
    
*   WordPress（被6000万个网站使用的系统）
    

在很长的一段时间里，如果你想做一个网站，PHP 就是最好的选择。**甚至 2004 年Facebook 上线，使用的也是 PHP + MySQL。**在今天，全世界大约 80% 的网站都使用了 PHP 技术作为网站后台服务程序：

![](../Images/c6b748afcba9ae5430d3e65d4a658deb.png)

**PHP 因学习简单、开发快速、性能稳定**，而备受 Web 开发人员的青睐。无论是用 PHP 开发 Web 应用，还是学习 PHP 语言，上手都非常迅速。

用 PHP 开发网页总共分几步？三步！  

**一、**  

打开桌面上的 Sublime Text/gedit，输入以下内容并保存在目录 `/home/shiyanlou` 下，命名为 `hello.php`：

```
1.  `<?php`
    
2.  `echo 'Hello php';`
    
3.  `?>`
    
```

![](../Images/d6662da939c3e940efac120eb979ccec.png)

**二、**

打开 Xfce 终端，执行命令：

```
1.  `$ ls #查看是否有 hello.php 文件`
    
2.  `$ php hello.php`
    
```

![](../Images/2f905c44b9f5f98dd4c1798c604dd912.png)

#### **三、**

#### 使用 PHP 内置服务器

```
1.  `$ php -S localhost:8080 # 端口号 8080 可以自定义`
    
```

浏览器输入 `http://localhost:8080/hello.php`，一个网页就配置好了！![](../Images/f422b6684a618d55996aeb571de58ce0.png)
