# 云计算工程师职位多，薪资高，为什么学的人却那么少？

**云计算，是继个人计算机、互联网变革之后的第三次 IT 大潮。** 从最初的兴起到逐渐落地到各个行业，云计算经过了黄金发展的十年，一直保持着高速增长的趋势，并被视为 21 世纪最有前景的市场之一。因其便捷、灵活的部署和按需付费的模式，云计算成为了数字化时代的基础设施，几乎所有企业和政府都在把业务往云上迁移。**与此同时，云计算工程师的职位也变得炙手可热。**不久前，人社部发布 13 个新增职业，云计算工程技术人员位列其中。专家预测，这一职业未来两年的岗位需求在 130 万个左右，市场平均年薪可达 40 万元，是不折不扣的 “金饭碗”。![](../Images/8229bc56d1e6dc2d6d8c184456c7fe64.png)

![](../Images/fbd29c1b2e9c8aaf6f17083337bdaa5e.png)

**那么问题就来了，为什么云计算职位那么多，薪资又高，学的人还那么少呢 ？**  
**原因可能是：太贵了……**  
每一家云服务厂商都提供了丰富多样的产品，以应对企业、个人的不同需求，拿市场占有率第一的亚马逊云 AWS 来说，就提供了：

*   亚马逊弹性计算网云（Amazon EC2）
*   亚马逊简单储存服务（Amazon S3）
*   亚马逊简单数据库（Amazon SimpleDB）
*   亚马逊简单队列服务（Amazon Simple Queue Service）
*   Amazon CloudFront 等等 **200 种服务**……
