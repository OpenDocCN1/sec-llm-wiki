**面试官：你有项目经验吗？**

没有被 “人生六问” 折磨过的人，不足以谈人生……**特别是最后一个问题，对于毕业生来说，我们刚走出校园，还没有工作和项目经验。**当面试官问到项目经验的时候，我们只能拿出学校里练习做的“小游戏”或者“命令行程序”。

但是，这些项目并不符合现代编程的需要，现代编程需要：前后端分工合作、网络接入、图形化界面等……**如果你有类似的中大型项目经验，写入简历中或者放在自己的 GitHub 上，就等于拥有了一件求职大杀器。**

今天我们给大家整理了 103 个满满干货的实战项目，包含：前端、后端、Python、Java、机器学习、大数据等，**希望你能找到喜欢的项目，借助它找到满意的工作！**
