学 Python 难不难？

答案是，不难。Python 诞生之初就被誉为 “最容易上手的编程语言”，现在甚至进入了小学教材和会考科目。

但很多的 Python 教程和书籍，都是这样教 Python 的：
先从 Python 的发展历史开始，介绍 Python 的基本语法、数据结构，然后再介绍字符串处理和正则表达式，介绍文件等 IO 操作，一章一章地讲下去。
虽然这样的讲解很全面，但是单纯的理论说明经常很枯燥，让人越看越累，越累越不想看。
编程是一门实践学科，光知道「这个东西是什么」是不够的，我们还要知道这些知识「在什么场景使用、适应什么需求、有什么好处」，经过真实场景的项目实战，才能让你对知识本身有更深刻的理解。
