数据获取

想要对豆瓣电影评分数据进行分析，首先需要获取这些数据。遗憾的是，豆瓣原先提供的 开发者平台已经关闭，无法直接从官方申请权限来访问数据。还好，有人发现了一部分 豆瓣私有 API 可以使用。本次试验，我们将使用这些 API 来获取数据。
首先，尝试请求该 API 查看数据格式。
import json
import requests

access_key = '0df993c66c0c636e29ecbb5344252a4a'  # API KEY
headers = {
    "User-Agent": "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_0) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/79.0.3945.8 Safari/537.36"
}
res = requests.get(
    f'https://api.douban.com/v2/movie/top250?apikey={access_key}', headers=headers)
json.loads(res.content.decode('utf-8'))
可以看到，该 API 依次返回了部分 TOP 250 里面的电影数据。包括每部电影的名称，评分，主演等。我们接下来要通过指定 start 和 count 参数拿到全部 250 条数据。
import os
import time
from tqdm import tqdm_notebook

# 新建文件夹
if not os.path.exists('top250'):
    os.mkdir('top250')

# 每页 10 个，需要 25 页
for i in tqdm_notebook(range(25)):
    url = f'https://api.douban.com/v2/movie/top250?start={i*10}&count={10}&apikey={access_key}'
    json_file_path = os.path.join('top250', '{}.json'.format(i))
    if os.path.exists(json_file_path):  # 如果已经爬取
        continue
    while True:  # 一直尝试到成功
        try:
            response = requests.get(url, headers=headers, timeout=5)
            break
        except requests.exceptions.Timeout:
            time.sleep(1)
    with open(json_file_path, 'w') as f:  # 写入本地文件
        # indent 表明需要对齐，ensure_ascii=False 编码中文
        f.write(json.dumps(json.loads(response.content.decode('utf-8')),
                           indent=4, ensure_ascii=False))
使用 Linux 命令直接查看爬取的文件列表：
!ls top250/
接下来，我们将上面取得的 JSON 数据二次处理，合并为 top250.json 文件。在此过程中，我们按平均分降序排列电影。
import operator

movies = []
for json_file in tqdm_notebook(os.listdir('top250')):
    json_file_path = os.path.join('top250', json_file)
    with open(json_file_path) as f:
        movies += json.load(f)['subjects']
# 按平均分降序排列电影
movies = sorted(
    movies, key=lambda movie: movie['rating']['average'], reverse=True)
with open('top250.json', 'w') as f:  # 写入文件
    f.write(json.dumps({'subjects': movies}, indent=4, ensure_ascii=False))
至此，我们就拿到了 TOP 250 电影数据。
