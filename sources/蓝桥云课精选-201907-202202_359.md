# 2020 年 4 月编程语言排行榜：Scratch 首次进入前 20，C 语言重回王者？

TIOBE 公布了 4 月的编程语言排行榜，总体情况和上个月没有太大的变化，Java 仍然稳居榜首，Python 上升一名来到了第三的位置。  
但值得注意的是，**C 语言这门**诞生近 50 年的语言，以 16.72% 的比例占据了第二名，与 Java 仅相差 0.01% ！****不得不说你大哥还是你大哥，下面是前二十的具体排名：![](../Images/1f8bdd13ce7c92a87288011e0959b0f3.png)  
**Scratch**

基于图形化的编程语言 Scratch 首次进入了 TIOBE 的前 20 名。乍一看，一门旨在教孩子如何编程的语言，能取得这样的排名有些奇怪。但如果考虑到有超过 5000 万个项目被 Scratch “写” 出来，并且每个月都有 100 万个新的 Scratch 项目出现，就不能否认 Scratch 的流行度了。

![](../Images/0a0bdb04e6175e8bba728821bfaaec04.png)

既然计算机越来越成为生活中不可分割的一部分，教儿童编程的语言越来越流行实际上是合乎逻辑的。几年前，Scratch 和 Alice 之间展开了一场竞赛，看哪一种语言会成为新的 “Logo” 编程语言。Alice 现在位于 TIOBE 指数的第 90 位，所以谁赢了似乎很清楚。发生这种情况的原因可能是 Scratch 更容易学习 (这是该领域的一个关键成功因素)，而且 Scratch 是由谷歌和 Intel 等公司赞助的。

（TIOBE 编程社区指数是编程语言受欢迎程度的一个排名，每月更新一次。这些评级是基于全球熟练工程师、课程和第三方供应商的数量。流行的搜索引擎，如谷歌，必应，雅虎！、维基百科 (Wikipedia)、亚马逊 (Amazon)、YouTube 和百度被用来计算评分。）
