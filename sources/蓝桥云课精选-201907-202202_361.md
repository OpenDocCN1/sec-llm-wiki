#### Next.js 站特征

从上面几个例子可以看出，很多知名网站都是采用 Next.js 来进行开发的。可能有些人会问了，你说是 Next.js 开发的就是 Next.js 开发的？怎么才能识别出来一个网站是否是使用 Next.js 来进行开发的呢？一般来说可以通过如下几个特征来判断一个网站是否是由 Next.js 来进行开发的：

*   页面 `<body></body>` 标签内部会有一个 `<div id="__next"></div>` 的元素 —— 最主要特征。
*   页面可能会存在一个 `<script id="__NEXT_DATA__"></script>` 的标签。
*   页面 `<head></head>` 内部可能会存在 0 ～ 多个 `<meta next-head>`标签。

就以腾讯门户来检验一下，其他几个站点大家可以自行验证：![](../Images/9ab9d2b370db0d74423118caceab1ecd.png)

#### **第四步：添加入口文件**

Next.js 项目启动需要入口文件，Next.js 会默认把根目录的 `pages` 文件夹里面的`.js`文件解析成路由页，在 `hello-next` 目录下新建 `pages/index.js` 文件并写入如下内容：

> 什么是路由页后面课程会详细介绍。

```
// pages/index.js

export default () \=> <h1>Hello Next.js</h1>;
```

使用 `npm start` 命令进行启动，如果你看到控制台输出下面这段话就表示启动成功了：

```
`[ ready ] compiled successfully - ready on http://localhost:8080`
```

> 如果你是在本地创建的文件，则在浏览器访问地址 `localhost:8080` 即可。
