Kubernetes 是什么？
当你去搜索这个问题时，大概会得到类似这样的答案：
“Kubernetes 是一个开源的，用于管理云平台中多个主机上的容器化的应用巴拉巴拉……Kubernetes 的目标是让部署容器化的应用简单并且高效（powerful）巴拉巴拉巴拉……”
然后，你会把浏览器关掉，同时把 Kubernetes 拉黑掉。
现在，是时候对 Kubernetes 来一个短介绍了：
大名：Kubernetes
小名：K8S
中文翻译：船长（希腊语）
爸爸：谷歌
追求者：Microsoft、IBM、BAT、滴滴、京东、头条……
用途：如果说 Docker 的作用是把大象（系统环境）装冰箱，那么 Kubernetes 就是一艘船，用来统一调配、管理船上所有小动物的集装箱！
面向对象：想用一己之力管理 1000+ 节点集群的高级运维工程师！
薪资：最新数据 👇
“下一个十年是 Kubernetes 的十年”，可能你还没听过它，但它在高端技术圈早已无人不晓了。
作为一个自动化的容器操作平台，Kubernetes 已经成为国内外技术大厂探索的方向，国外的 Google，Amazon 都在布局，国内的阿里、腾讯、华为也一直在追逐它。如果你是个决心要在云计算领域深入发展的人，那熟悉 Kubernetes 非常有必要。
