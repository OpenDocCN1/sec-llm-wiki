2020 年真是不让人省心，在全球疫情、蝗虫闹得人心惶惶的时候，没人注意到有两位大神已经撕破衣服打了起来。
2 月 20 日，神舟电脑正式起诉京东拖欠其 3 亿多元货款，将京东告上了法庭：
不仅如此，神舟电脑还向媒体曝光了很多京东的潜规则条款，搞得京东好不尴尬。
京东也做出了反应：将神舟电脑全部下架，直接扫地出门！
由于剧情一直在反转，谁是谁非我们还无法判断，但曾经支撑京东游戏频道一半江山的神舟电脑，搞到现在对簿公堂的田地，让人唏嘘不已。
在大厂制定规则、高楼林立的互联网生态里，中小企业想要维权和保持尊严是很难的。在神舟的态度从声讨到控诉再到缓和的转变中，可以看到中国民族制造业的心酸，神舟电脑等中国制造企业已经开始审视和改变销售格局。
被掐断 30% 销售渠道的神舟如何应对？开发自己的网络商城！昨天下午，神舟宣布开始全方位高薪招聘人才，包括 CTO IT 负责人、项目经理、运维、站内运营、高级 PHP 开发工程师、Java 高级开发工程师、iOS 高级开发工程师等职位。

其实不只是神舟，在万物互联时代，所有的消费品牌都需要一个甚至 N 个线上购物网站！即使是小公司，无法负担程序员的薪资和开发成本，也会选择在外包网站发布需求，帮自己的企业开发网络商城。

对于程序员来说，学会「开发网络商城」，不仅能帮助企业快速成长，使自己朝 CTO 大佬的方向发展；还能接一些私活，一个项目就可以顶别人几个月的收入。

Spring Boot 企业级商城开发实战：https://www.shiyanlou.com/courses/1537

课程包含 36 节实验，6 大板块，会介绍 Spring Boot 在项目开发中的常用场景、整合方法、开发技巧，并手把手带你用 Spring Boot 开发一个大型的商城项目，不管你是在校大学生亦或者是已经有了一些工作经验的开发者，这个项目都会给你带来很好的提升。

课程使用 Spring Boot 开发。Spring Boot 是近几年来 Java 社区最有影响力的项目之一，也是下一代企业级应用开发的首选技术。很多的国内技术团队都在使用 Spring Boot 进行企业项目开发，这一点也可以通过 Java 开发工程师的招聘技能要求中看出来。

可以说，良好的技术热情 + 一片大好的招聘前景，Spring Boot 已经成为每一位 Java 开发者在技术道路上打怪升级所必要的技能包。

同时，作者也整理了现阶段大部分开发者以及应届生的一些需求。很多朋友都希望通过一些大型项目的开发实践，让自己有所提升，而商城项目就比较符合这个需求：

  • 首先线上商城系统具有很大市场潜力，不管是用于毕业设计或者补充项目经验，都比小型管理项目更有优势；

  • 其次商城系统复杂，涉及到丰富的知识点。开发一个电商系统，更能体现一个开发者的个人能力。

课程适合这些同学：

  • 从事 JavaWeb 开发的技术人员；

  • 对 Spring Boot 感兴趣、想要改变原有开发模式的开发人员；

  • 希望将 Spring Boot 技术实际运用到项目中的开发者；

  • 需要大型实战项目借鉴的应届生和求职者。

如果你正在找工作，或者正在为毕业设计发愁，那相信这个项目可以给你很多思路，并真正掌握用 Spring Boot 开发大型项目的能力！
