每年年初，我们都会给自己立各种各样的 Flag，最终，这些 Flag 又成为了明年的 Flag…… 见过京剧舞台上的老生吗？背后插满了旗子，像极了 90 后的你……

为什么会这样？

其实我们每次立 Flag 时，都在心里默默埋下了一个意识：这是一年的计划，不用马上完成。

于是，刚立下 Flag 时，你亢奋地像一只打满鸡血的公鸡；

3 个月后，突然想到计划还没开始，刚做两天，又被琐事缠身，你想 “过几天再做吧，不急”；

6 个月后，下半年了开始了，“得正式开始了，这次不能重蹈覆辙！”

12 个月后，“胡适之啊胡适之，你怎么能如此堕落！”

（胡适的日记，可见 Flag 是人类的共同大敌）

所以，当你立下 Flag 的那一刻起，你可能已经输了……


要行动，不要 Flag！

想一想，光「学会 Python」这个 Flag，你就立过多少遍了？

每年一到春招 / 毕业 / 秋招 / 年底，后台就会收到很多人问：

“想学 Python 转行，现在上车还来得及吗？”

答案是肯定的，不管你正在从事什么职位，学习 Python 都是一个很好的选择，它可以帮助你更快地完成工作，获取更好的发展机会。

 而且，只要粘上了Python，薪资就不会低 

在如产品、运营、市场、行政等职位的招聘信息中，也能经常看到 “熟悉 Python 优先” 这样的字眼，总结就是“Python 🐂🍺”、“Python 加分”！

道理我们都懂，“Hello World” 我们也写的滚瓜烂熟，但一年年下来，有多少人坚持学完了 Python？又有多少人收入翻番，最终找到满意的工作了呢？
