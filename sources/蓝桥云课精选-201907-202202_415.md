![](../Images/56df7c454ec2c06334714a1e18150b29.png)

  

******有了前面的 Vue 基础打底，我们就可以进阶到各种各样的项目实战中了。********2. Vue 进击实战：拖拽表单设计器****Vue 打造拖拽表单设计器这门课程使用现在流行的 Vue.js 和 ElementUI 从零开始开发一个可拖拽的表单设计器，项目使用 Vue CLI 3 搭建，你可以从中学习到如何快速创建一个 Vue 项目，如何实现拖拽，Vue 组件封装，Vue 高级特性用法，如何打包发布项目到 NPM 上等众多干货。****https://www.shiyanlou.com/courses/1355**

![](../Images/b11a7a5d8fa284006e4297cb90a336fd.png)

  

**3. 基于 Vue 和 Element UI 开发管理后台****本课程详细介绍了使用 vue-cli 脚手架工具创建一个 Vue 3 项目，并且引入 Element UI 来完成页面布局。作为一个前端开发工作者，Vue 这个轻量化框架应该掌握，ELement UI 更是前端开发工作者应该熟练使用的。****https://www.shiyanlou.com/courses/1411**

![](../Images/b000f2700cf4ff3e7c3062dbfb11dbb5.png)

  

****上面两个课程还是相对纯粹的使用 Vue ，帮助大家夯实 Vue 的知识，下面开始就会注重前后端的搭配，也许还会出现一些后端语言，别担心，相信你都能一一解决。******4. Vue+Express+MongoDB 实现饿了么 Web 应用****本课程使用 Vue + express + MongoDB 进行全栈移动端项目的开发。课程内容主要分为 3 个部分：前端页面展示与业务逻辑的实现、后台管理系统的实现、后端数据操作与路由配置的实现。涵盖有包含 ES6，webpack，Vue 全家桶，express，mongoose 在内的多个知识点。****https://www.shiyanlou.com/courses/1293**  

![](../Images/e81215d024a773acd5c23c11d840b106.png)

  

**5. Flask + VueJS 全栈 Web 开发实战****本训练营使用当前非常热门的两个技术——Python 和 VueJS 带领大家学习 Web 开发。通过两个实战项目的练习让大家掌握 Flask + VueJS 进行 Web 开发的能力。****https://www.shiyanlou.com/courses/878**

![](../Images/902b7e244b847500aaf0a09e647a3c3e.png)

  

**6. Go + Nuxt.js 搭建一个 BBS 系统****课程使用 Go 语言和 Nuxt.js 实现一个 BBS 论坛系统。Nuxt.js 是一个基于 Vue.js 的通用应用框架，可以让你更好的理解 Vue 。同时对 Go 语言有兴趣的同学也可以了解到 Go Web 开发的基本流程。****https://www.shiyanlou.com/courses/1436**

![](../Images/e8b1befa245003ed484bbbef17682821.png)

  

**7. 基于 Vue.js、Node.js 和 MongoDB 开发 DoraCMS****最后为大家推荐一门刚上的新课。****本课程基于 Vue.js、Node.js 和 MongoDB 开发一个 CMS 系统。课程将从环境搭建开始，一步一步来完成 CMS 系统所需组件，并最终构建一个完整的产品。****https://www.shiyanlou.com/courses/1473**
