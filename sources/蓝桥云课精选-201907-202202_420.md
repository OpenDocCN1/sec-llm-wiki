**数据爬取**

  
最近一年，大家都能感觉到猪肉涨的很厉害，微博以及其他社交平台上也经常会调侃吃不起猪肉。本文采集了农业农村部「猪肉-农产品批发价格数据」，时间为2018 年 1 月至 2019 年 12 月，下面是完整的分析过程。  
由于数据仅支持以表格的形式查看，不提供下载，故在网页检查时拷贝了table节点的所有标签元素组成了 Html 文件，供数据分析使用，由于接下来还需要解析好几份类似的 table 表格数据，故抽出了 readDataList 方法：  

```
1.  `from lxml import html`
    
2.  `from matplotlib import pyplot as plt`
    
3.  
    
4.  
    
5.  `from lxml import html`
    
6.  `from matplotlib import pyplot as plt`
    
7.  `from matplotlib.font_manager importFontProperties`
    
8.  
    
9.  `#下方所有图例使用中文字体`
    
10.  `font = FontProperties(fname=r"../input/fontresource/simhei.ttf")`
     
11.  
     
12.  `def readDataList(xmlPath,isMultiHead=False):`
     
13.  `    html_content = open(xmlPath, 'r', encoding="utf-8").read()`
     
14.  `    root = html.fromstring(html_content)`
     
15.  `    timeList = []`
     
16.  `    priceList = []`
     
17.  `if isMultiHead:`
     
18.  `        a=2`
     
19.  `else:`
     
20.  `        a=1`
     
21.  `    timeList.extend(root.xpath('//td[1]/span/text()')[a::][::-1])`
     
22.  `    priceList.extend(root.xpath('//td[2]/span/text()')[1::][::-1])`
     
23.  `for i, v in enumerate(priceList): priceList[i] = float(v)`
     
24.  `for i, v in enumerate(timeList): timeList[i] = str(v)`
     
25.  `return timeList,priceList`
     
26.  
     
27.  
     
28.  
     
29.  `pigTimeList,pigPriceList=readDataList('../input/dataset/homeporkprice.html')`
     
30.  
     
31.  `#设置画布大小`
     
32.  `fig, axes = plt.subplots(figsize=(16, 9), dpi=200)`
     
33.  `axes.plot(pigTimeList, pigPriceList, label='价格')`
     
34.  `axes.set_xlabel("2018年01年-2019年12月", fontproperties=font)`
     
35.  `axes.set_ylabel("猪肉价格 均价(元/公斤)", fontproperties=font)`
     
36.  `axes.set_title('猪肉价格趋势', fontproperties=font)`
     
37.  
     
38.  `plt.xticks(rotation=90, fontproperties=font)`
     
39.  `#设置刻度标记的大小`
     
40.  `plt.tick_params(axis='both',labelsize=10)`
     
41.  `#绘制每个价格点,显示价格坐标`
     
42.  `axes.scatter(pigTimeList, pigPriceList)`
     
43.  `for a, b in zip(pigTimeList, pigPriceList):`
     
44.  `    plt.text(a, b, (b),ha='center', va='bottom', fontsize=10)`
     
45.  `plt.legend(prop=font)`
     
46.  `plt.show()`
     
```

执行后，一份「猪肉价格趋势图」就出现了：**![](../Images/bda60444a9912303421b0eff902ba933.png)**从图片中可以看出 2018 年猪肉的价格是比较平稳的，最高的 2018 年 1 月也没有超过 25 元/公斤；2019 年年初猪肉的价格也还算稳定，但在4月后猪肉的价格开始疯狂上升，到 11 月达到了最高的批发价格 47.1 元/每公斤。  
  

**数据分析**

  
是否只有猪肉涨价，其他家畜类产品的价格有何变化呢？我们在批发价格数据里拷贝了猪肉、羊肉、羊肉以及鸡蛋的价格涨幅，绘制在一张表格里看一下数据对比：  
**代码：**

```
1.  `import  pandas as pd`
    
2.  
    
3.  `def plotXY(xList,yList):`
    
4.  `for a, b in zip(xList, yList):`
    
5.  `        plt.text(a, b, (b),ha='center', va='bottom', fontsize=10)`
    
6.  `    axes.scatter(xList, yList)`
    
7.  
    
8.  `cowTimeList,cowPriceList=readDataList('../input/dataset/cow_price.html')`
    
9.  `goatTimeList,goatPriceList=readDataList('../input/dataset/goat_price.html')`
    
10.  `eggTimeList,eggPriceList=readDataList('../input/dataset/egg_price.html')`
     
11.  `data = pd.read_csv("../input/dataset/province_data.csv", encoding='GBK')`
     
12.  `data.set_index('地区', drop=True, inplace=True)`
     
13.  `df2=data.stack()`
     
14.  `df3=df2.unstack(0)`
     
15.  `df3=df3.iloc[::-1]`
     
16.  `fig, axes = plt.subplots(figsize=(16, 9), dpi=300)`
     
17.  
     
18.  `axes.plot(pigTimeList, pigPriceList, label='猪肉')`
     
19.  `axes.plot(cowTimeList, cowPriceList, label='牛肉')`
     
20.  `axes.plot(goatTimeList, goatPriceList, label='羊肉')`
     
21.  `axes.plot(eggTimeList, eggPriceList, label='鸡蛋')`
     
22.  `axes.set_xlabel("2018年01年-2019年12月",fontproperties=font)`
     
23.  `axes.set_ylabel("价格 均价(元/公斤)",fontproperties=font)`
     
24.  `axes.set_title('价格趋势',fontproperties=font)`
     
25.  `plt.xticks(rotation=90,fontproperties=font)`
     
26.  
     
27.  `#绘制点坐标`
     
28.  
     
29.  `plotXY(pigTimeList, pigPriceList)`
     
30.  `plotXY(cowTimeList, cowPriceList)`
     
31.  `plotXY(goatTimeList, goatPriceList)`
     
32.  `plotXY(eggTimeList, eggPriceList)`
     
33.  `plt.legend(prop=font)`
     
34.  `plt.show()`
     
```

![](../Images/58d5396ceadd6d20afa60aa3a86a4d5b.png)从对比图可以看出，鸡蛋的价格趋势很平稳，羊肉、牛肉的价格虽然也上涨了，但也相对平稳，只有猪肉的上升幅度最大。**问题来了，猪肉价格的上涨对哪个省份的影响最大？**采集全国各省市的畜肉类消费指数，代码如下：

```
1.  `import  pandas as pd`
    
2.  
    
3.  `data = pd.read_csv("../input/dataset/province_data.csv", encoding='GBK')`
    
4.  `data.set_index('地区', drop=True, inplace=True)`
    
5.  `df2=data.stack()`
    
6.  `df3=df2.unstack(0)`
    
7.  `df3=df3.iloc[::-1]`
    
8.  
    
9.  `axes=df3.plot(figsize=(16,9))`
    
10.  `plt.legend(prop=font,loc=2)`
     
11.  `axes.set_xlabel("时间轴",fontproperties=font)`
     
12.  `axes.set_ylabel("消费价格指数",fontproperties=font)`
     
13.  `axes.set_title('畜肉类居民消费价格指数(上年同月=100)',fontproperties=font)`
     
14.  `plt.xticks(rotation=90,fontproperties=font)`
     
15.  
     
16.  `plt.show()`
     
```

![](../Images/7b15947dd0a01d4ac3b907141281d00c.png)可以看到，大部分省份的畜肉类消费指数都上涨较大，但也有些省份几乎没有受影响，比如西藏、新疆、宁夏（可能和牛羊肉为主的饮食习惯有关）。  
  

**舆情分析**

![](../Images/2dfb43dd8650503b00f984b9a61bea71.png)可以直观的看到，在“猪肉”相关的微博话题中，“冬至”、“饺子”、“白菜”、“好吃”、“允悲”、“美食”、“酸菜”等词被提到较多，小编已经脑补出了一场吃货大戏，可以看到，大家关于猪肉的心情都是“开心、喜欢、嘻嘻、期待”等词语；还可以看到一些关于猪肉搭配的蔬菜或菜肴，例如“饺子、酸菜、白菜、 烤肉”等；但是我们也看到了涨价、允悲、心疼等负面形容词。但是别担心！从 12 月中旬开始，商务部已陆续安排中央储备冻猪肉投放市场，目前已投放了 10 万多吨，后续还将进一步加大投放力度。而且，猪价的价格波动对牛羊肉的影响不大，从经济学角度，羊肉的性价比就很高了。过年回家，羊肉火锅可以涮起来了！![](../Images/e4df4b1993dfd26bb72cbcac1613773b.png)
