## **写一个方法，判断两个字符串是否互为“换位词”，可以理解为：两个字符串包含的不同字符的数量是否相同。**

这类问题的常用方法为：遍历两个字符串，统计其中各字符出现的频次，若不等则返回 `false`。有很多简单字符串类面试题都是此题的变形题。

### Python 代码

```
class Solution:
def anagram(self, s, t):
return collections.Counter(s) == collections.Counter(t)
```

### 源码分析

1.  两个字符串长度不等时必不可能为变位词 (需要注意题目条件灵活处理)。
2.  初始化含有 256 个字符的计数器数组。
3.  对字符串 s 自增，字符串 t 递减，再次遍历判断 `letterCount` 数组的值，小于 0 时返回 `false。`

### 复杂度分析

两次遍历字符串，时间复杂度最坏情况下为 `$$O(n)$$，`使用了额外的数组，空间复杂度为 `$$O(1)$$。``**（课程中还提供了C、Java、C++等多种解法，篇幅有限，欢迎登陆实验楼学习—— https://www.shiyanlou.com/courses/492 ）**``   `
