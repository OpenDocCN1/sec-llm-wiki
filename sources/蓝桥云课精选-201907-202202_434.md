**为什么你怕 Kubernetes ，是怕它不够火热，学了找不到好工作耽误时间吗？**  

  

根据 Cloud Native Computing Foudation 进行的一项调查，Kubernetes 是容器编排管理工具的市场领导者，在该项调查中，83% 的受访者正使用 Kubernetes，而其中 58% 的人在生成环境中使用它。  

  

在公司使用层面，可以参考 2019 年的 RightScale 云状态报告，Kubernetes 的使用率一路飙升。公司采用率从 2018 年的 27% 增加到 2019 年的 48%，过千人的大企业甚至达到 60%。

  

既然 Kubernetes 一路高歌，就业情况更是不用操心，从各个招聘平台也可以窥探一二。
