# 2020 职场 AI 技能排行榜：TensorFlow 热度飙升，Python 最火，市场部也在学

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwODM4NDM5OA==&mid=2247504981&idx=1&sn=4ad625d9b7c372f8476d77ce70719861&chksm=c0c855b4f7bfdca2c5b88b5d6c70d2fe71e08c2517c3b9e77a029e6ce89b5380b83548a9363a&scene=126&sessionid=1681309688#rd](http://mp.weixin.qq.com/s?__biz=MzkwODM4NDM5OA==&mid=2247504981&idx=1&sn=4ad625d9b7c372f8476d77ce70719861&chksm=c0c855b4f7bfdca2c5b88b5d6c70d2fe71e08c2517c3b9e77a029e6ce89b5380b83548a9363a&scene=126&sessionid=1681309688#rd)

还有一个月就是 2020 年了。近日，在线教育网站 Udemy 根据其学员的课程数据，制作了一份《2020 年职场学习趋势报告》，指出了哪些技能最受职场人关注。报告指出，AI 相关技能最受职场人青睐，Python 将会是明年最受关注的技术，市场部也开始重点学 Python。 尽管人们都知道，在下一个十年，数据分析和 AI 将会对我们的生活影响深远，但是现在什么 AI 技术最受学习者关注？AI 是否是「只闻楼梯响，不见人下来」的一纸空谈？近日在线教育机构 Udemy 根据其 4 千万学员的课程学习情况，对 2020 年的职场技能需求等进行了评估。报告总结了一些值得关注的新技术趋势，包括：

*   Python 将成为 2020 年最受职场人欢迎的技能；
    
*   软件工程师最爱 Python，市场部人员也热衷于学 Python;
    
*   过去三年，TensorFlow 技能热度上升最快；
    
*   web 开发势头不减，量子计算、物联网引人瞩目
    

……此外，报告还对明年的新兴技术趋势、雇主对 AI 技能的需求和企业应对 AI 的程度等方面信息做了梳理。**越来越多的工作岗位受到 AI 影响**![](../Images/72a026e075c5d44bb248d47015fb6ab6.png)报告显示，60% 以上的公司 / 组织受到了 AI 的影响，并对其雇员进行了技能培训。而 Udemy 的学习和发展团队 (L&D team) 中 60% 的成员 (一般为企业主等) 已对自己公司 10%-20% 的雇员进行了技能培训。而有 4 成的成员认为，现有的一些工作会被 AI 和自动化替代或改变。同时，报告指出，65% 的管理者认为人工智能和机器人技术是人力资源中非常值得重视的一部分，但面对这个已经显而易见的时代趋势，只有 26% 的企业表示他们已经准备好了。![](../Images/29b9d7b5b0c02f2edd012d77f48ce503.png)尽管 AI 这个词的热度居高不下，但大部分职场人还不具备从 AI 分析的数据结果中得出有效结论的能力。当被问及最优先培训及最短缺的技能时，过半数的管理者选择了机器学习、神经网络等 AI 相关领域以及 Python 等相关编程技能。此外，云计算方面的人才缺口也很大。 ![](../Images/f841fe63d0be8b7fb92065a3a86bca3e.png)**Python：****2020 年最受欢迎技能**Udemy 报告指出，Python、React (web)、Angular、机器学习和 Docker 将成为 2020 年最受欢迎的五大技能。我们现在所处的世界对 AI 和数据科学技能 (Python、机器学习、深度学习) 有着非常大的需求，但对 web 开发框架 (React、Angular)、云计算和其他 IT 技能 (AWS、CompTIA) 及 Docker 的需求也不容小觑。 ![](../Images/8bb0e3fd15d74b8e77cfed1e6c99fe89.png)这和前段时间美国求职公司 Indeed 发布的一份报告大体一致。该报告显示，Python、AWS 等技能在过去 5 年需求量激增，可能成为未来几年最受欢迎的技能。Docker 的热度在过去 5 年中也完成了「阶层跃升」，其热度上涨了 4162%。**软件工程师最爱 Python，市场部也爱**在 2020 年，Python、Java、AWS 和 web 开发框架 (React、Angular、Spring 和 Node.js) 将成为最受软件工程师欢迎的技能。![](../Images/56d3cb7c608792c27e2689fdf80b738e.png)2020 年最受软件工程师欢迎的 10 项技能 (Python 居首)。软件工程师最爱 Python 倒是并不令人意外，但营销相关工作者对 Python 的热爱还是令人眼前一亮。报告显示，市场工作者将 Python 技能排在了非常显眼的位置，仅次于传统的数字营销技能。![](../Images/be8f12fcb14ed6214b6b0cf7b794eea8.png)**TensorFlow：****热度上升最快的新技术**下表列出了从 2016 年到 2019 年排名变化最大的几项技能。结果显示，TensorFlow 热度上升最快，紧随其后的 Chatbot、OpenCV 等也大多与 AI 有关。 ![](../Images/dc21a0088e0bb728d0e08d01a2ebef67.png)从中我们可以看出，Tensorflow、Chatbot、OpenCV、神经网络等是很多数据科学家正在学习或精进的基本技能。掌握这些技能对于理解、开发 AI 应用及平台非常重要，有利于他们在基于 AI 的职业规划上走得更远。此外，微软的 Azure 排名上升也非常明显，这与 Indeed 的调查结果也是一致的。后者表明，在过去的五年中，Azure 在求职市场的热度上涨了 1107%。看来，微软 Azure 与亚马逊 AWS 的云计算之争将愈演愈烈。**web 开发势头不减，量子计算、物联网引人瞩目**在新兴技能方面，Udemy 列出了 10 项可能在 2020 年崛起的新技能。这些技能出现的时间不久，但在 2019 年颇受欢迎，涉及的领域包括网络开发、量子计算和物联网等。根据从 4 千万 Udemy 学员学习内容得到的统计结果，一项新的网络开发框架 ——Gatsby.js，正在迅速走红。此外，React Hook、Next.js 和 SwiftUI 等网络开发工具也受到了关注。 ![](../Images/8c7d287270d48dd258d522041614f4d0.png)2020 年十大新兴技能预测。**自动化进入办公场景**在 2020 年，SAP 企业软件知识、ISO/IEC 27001 标准知识、信息安全和微软 Dynamics 365 预计将成为工作场所增长最快的流程化和工具性技能。Udemy 学员还对机器人流程自动化 (Robotic Process Automation, RPA) 和业务流程管理 (Business Process Management, BPM) 表现出了强烈的兴趣。借助于 RPA，人类利用微软 Excel、数据库或网络应用等流行的生产力应用来执行日常办公室工作的方式可以由流程自动化工具来替代。此外，进入此榜单前 10 的还包括 Scrum 团队协作工具、Oracle SQL 结构化查询语言和风险管理。![](../Images/4eff7be23912c2c739ae02b624c8e8b5.png)2020 年工作场所增长最快的 10 项流程化和工具性技能。**Chef 软件将是 2020 年增速最快的 IT 技能**在 2020 年，Chef 软件专业知识、网络安全、渗透测试、Linux 安全和 AWS 认证云预计将成为 IT 从业者中增长最快的技能之一。Chef 软件在 IT 相关的公司中非常常见，是一款自动化服务器配置管理工具，如系统管理，安装软件等，主要用于简化配置以及云服务器的维护。从当下的情况观察来看，Chef 确实变得越来越热门，可见于许多热门的云平台以自动化配置的新计算机，包括 Rackspace、微软 Azure 和亚马逊 Elastic Compute Cloud (EC2)。在 2020 增速前十名的技能中，同样值得关注的有情商、设计思维、JMeter、 CompTIA Security + 和 API testing。 ![](../Images/08886f88ae406405bc88249fab4045f4.png)2020 年增长最快的 10 项 IT 技能。**2020 年微软 AZ-900 等软件技术服务技能迎来快速增长**在 2020 年，软件技术服务领域也会提升包括网络开发 (如 Express Framework 和 Google Flutter)、Agile 项目管理、微软 Azure 云技术和数字转型等一系列技能。如下图所示，微软 AZ-900、Express Framework (网络开发) 和专业 Scrum Master (Agile) 成为 2020 年增长最快的软件技术服务技能的前三甲。 ![](../Images/e79db0e2652d313be8a046306fba663c.png)2020 年增长最快的 10
