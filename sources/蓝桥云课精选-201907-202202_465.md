## 1\. Python 爬取网易严选妹子内衣信息，探究妹纸们的偏好

大佬利用爬虫技术获取了网易严选妹子内衣的商品数据，并且根据用户对于商品的评论进行数据分析，试图去探究妹纸们对于内衣的偏好。

## 2.色情图片识别

大佬使用 Python 的 PIL 图像处理库，编写算法来划分图像的皮肤区域。以达到可以去识别一张图片是否是色情图片。此项目在实验楼制作成了项目课，感兴趣的可以去看看。**课程链接：https://www.shiyanlou.com/courses/589**

## 3.利用 Python 分析 42 万字歌词，搞清楚了民谣都在唱什么？

王登科选取了大约 30 个覆盖从程序员，朋克，基佬到女权主义者，中国大妈，穆斯林的能够覆盖所有人群的民谣歌手和乐队，利用 Python 爬虫获取了他们所有歌的歌词，并针对获取的 42 万字歌词进行数据分析，最终搞明白了民谣都在唱什么？

项目博文：我用Python分析了42万字的歌词，为了搞清楚民谣歌手们在唱些什么

## 4.Python 进行字幕翻译

大佬在学习的时候，因为需要观看没有中文字幕的英文视频教程。于是就直接上手写了个 Python 代码，利用谷歌翻译将英文翻译成中英文双语字幕。

## 5.北京地区医院挂号

不晓得从什么时候开始，看病都需要抢号了！因为帝都有些医院号源紧张，放号瞬间被秒杀一空，然后大佬有需要进行挂号，于是就直接写了一个挂号的 Python 脚本。适用于北京地区的医院预约挂号，需要挂号看病的帝都同胞可以试试。Github：iBreaker/bjguahao
