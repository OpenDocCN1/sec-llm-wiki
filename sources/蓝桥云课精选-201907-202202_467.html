10 月的深度学习界都发生了哪些大事？ TensorFlow 2.0 的正式发布一定算得上一件。

时隔三年，这个全球用户最多的深度学习框架，终于迎来了 2.0 正式版本。Google 深度学习科学家、Keras 作者 François Chollet 表示：“TensorFlow 2.0 是一个来自未来的机器学习平台，它改变了一切”。
TensorFlow 2.0 最大的改变在于，它让深度学习应用的开发变得更容易了。以原生 Python 的方式执行函数，TensorFlow 2.0 让开发应用的体验变得更接近于原生 Python 开发，同时还可以通过使用 Volta 与 Turing GPU 混合精度，仅需几行代码，即可提升 3 倍训练性能！

在所有的主流深度学习框架中，TensorFlow 是最成熟的。目前，阿里、腾讯、京东、小米、网易、滴滴等国内知名互联网企业，和 Airbnb、Uber、Dropbox 等硅谷明星公司，都在大规模使用 TensorFlow。在谷歌内部，更有超过 80% 的软件项目采用了 TensorFlow。

越来越多的程序员都选择通过 TensorFlow 开始自己的深度学习之路。而随着 2.0 版本的发布， TensorFlow 变得更简单和易用，学习门槛降低，可以说：现在的 TensorFlow 对新人更友好了！
但 TensorFlow 的初学者往往会遇到一些问题：
1. 深度学习的环境配置相对复杂，即使是老司机，也很有可能折腾一下午也安装不好。很多人可能连门还没进去，就已经没信心了。
2. 网上的教程参差不齐，且大多是较老的版本，如果没选对课程，完全照做，难免会遇到各种奇怪问题，还浪费时间。（ TensorFlow 1.0 和 2.0 完全不同，不需要再把精力浪费在 1.0 的课程上了）
3. 深度学习的内容较为抽象，张量、微分、多项式……这些知识点大多是我们从未接触过的，理解起来比较困难；而市面上的课程又大多偏向理论，枯燥难懂，即使你能坚持学下去，也往往不知道该怎么应用，
