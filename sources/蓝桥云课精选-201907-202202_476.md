2016 年，**AlphaGo **战胜人类顶尖棋手，自此掀起了人工智能和机器学习的时代的风潮。转眼**三年过去了，人工智能的概念还那么火吗？****现在去学习以机器学习，还能找得到工作吗？**在过去几年，人工智能和机器学习工程师的就业市场就一直处于 “缺口”状态，“天价工资” 层出不穷，相关专业的毕业生甚至一毕业就能拿到 40 万的年薪。这几年随着越来越多的院校开设人工智能专业，这个趋势有改变吗？答案是：**并没有**。根据专业招聘网站 Indeed 发布的人工智能招聘报告来看，人工智能领域的空缺职位和求职者之间的差距依然存在，**短缺问题甚至还在加剧：**  

*   人工智能的工作岗位比去年增加了 29.1％。
    
*   机器学习工程师薪酬排名在 2018 年位居第三，而今年荣登榜首 —— 薪酬和排名都有所增长。
    
*   今年这个职位的平均年薪比去年高出 8409 美元，增幅为 5.8%。
    

![](../Images/02459864178672c0ddb6a6450014490e.png)![](../Images/4415db6d6aa0457e9b4b4cdd39136721.png)在竞争激烈的人工智能就业市场上，企业愿意花更多的钱来吸引人才到这些关键岗位上，这可能是导致这两个岗位薪酬上涨的原因。  
学习机器学习的三个建议**1\. 学习 Python 和机器学习基础概念**Python 是人工智能领域最好的入门语言。大量的机器学习工具（如：Pandas、Numpy、Matplotlib、Scikit-learn），和几乎所有主流的深度学习框架（TensorFlow 和 PyTorch）都构建在 Python 的基础上，所以学习 AI 技术，Python 是你绕不去的一关。而且 Python 的 Jupyter 和 Anaconda 等数据科学工具，可以让你很轻松地搭建环境，快速开始机器学习的学习。**2. 学习 Pandas、Numpy 等科学计算工具**掌握了 Python 基础后，你就需要学习如何处理和操作数据。为了实现这一目的，你需要学习 Pandas、Numpy 和 Matplotlib 的使用：

*   Pandas 可以帮助你处理二维数据，类似 Excel 文件里的信息表，这类数据被称为结构化数据。
    
*   Numpy 可以帮助你进行数值计算。机器学习把你能想到的所有东西都转化成数字，进而在这些数字中寻找规律。
    
*   Matplotlib 可以帮助你绘制图形和可视化数据。数字对人类来说可能难以理解，人类是视觉动物，更喜欢看到可视化的图标。美观的图标可以更好地传达你的发现。
    

**3. 在项目中学习机器学习的各种算法和框架**有了前面的基础之后，就可以正式学习机器学习了。机器学习其实并不难，而且很有趣，比如一个简单的识别英文字母的程序，花 1 个小时就能完成。**学习机器学习最好的方法就是在实战中学习。**每学习一个知识后，就用该知识完成一个项目，只有这样，你才能明白这个知识点到底有什么作用，得到更深刻的理解。而且，完成项目的正向反馈会推动你不断向前学习。知识点对应的项目可以参考这张图片：
