**“在运维领域，薪资永远和能力相对应”**在运维这一行，没有人一毕业就是大神。不同于其他行业，运维需要的不是 “天赋异禀” ，而是 **“经验丰富”**。不信的话请随便翻一下薪资20K以上的运维招聘JD：

> 熟悉 Docker、Kubernetes 等开源软件；熟悉常见应用配置及优化，如Nginx/Haproxy/MySQL/DNS/Redis/MongoDB等；熟悉常用的监控系统，如 Zabbix、Nagios 和 Ganglia 等；熟悉systemtap、perf、oprofile 等分析调试工具；很强的Troubleshooting能力、且能够推动业务问题改善和解决；

这里面大部分技术栈你可能见都没见过，学校里更是不可能教的，只有靠后天自学才能掌握。所以，当你羡慕别人当了两年运维，就能从薪资 3000 提升到 20000 时，不妨想想他在背后付出了多少努力。  
**“高级运维是无法替代的！”**

相对于开发来说，Linux 运维是比较容易入门的，一个经常在 Linux 下做开发的人就可以取代一个 Linux 初级运维人员。

但如果是高级运维，情况就颠倒过来了。**高级运维是一个非常专业职位，需要掌握相当多的知识，包括但不限于网络技术、系统编程、运维流程及思想、虚拟化、自动化运维体系构建、数据库管理，云计算平台应用，大数据等。**

一个高级运维很容易掌握开发人员的技术和思想，但让开发人员去学习高级运维常年积累下来的工作流程、思想和经验体系，就不是一朝一夕的事情了。你可以从招聘薪资中看出，市场对高级运维的需求有多么强烈：  

掌握云计算技能的运维工程师，薪资超越大数据和游戏行业，以 **40 万的年薪**高居榜首：

**“如何成为一名 Linux 高级运维”**

学就完了。

即使是计算机科班出身，学校里关于 Linux 的课程也少之又少，甚至很多人大学 4 年从来没使用过 Linux。所以想在运维的道路上越走越远，只有自学和在项目中实战这两条道路。

但好在，你学到的东西可以马上在实际的工作中应用，学习也会更加的有动力。当你每掌握一个工具后，都能得到 Boss 的加工资时，还有什么理由不更好地学习它呢？

在运维这个行业，只要你下定决心学习，并且有明确的学习计划，那么就算是零基础转行，也是可以迅速入门，月薪过万。根据目前互联网云计算技术的迅速发展，企业对掌握 Linux + 云计算的运维人才需求迫切，只要能熟练掌握运维技术，挑战年薪 30W 也是不在话下，甚至会更高！
