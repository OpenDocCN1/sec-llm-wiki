**不只是专业的开发岗位，其他如**产品、运营、市场、行政等职位的招聘信息中，也能经常看到 “**熟悉 Python 优先**” 这样的字眼。**Python 在爬虫、数据分析、自动化办公领域都有突出的表现，像自动抓取和分析数据、下载资料、分析数据这样的常见工作都能分分钟完成，好像给你的工作开了挂一样。![](../Images/f7398cbf4968b4c93510390d497ae9ad.png)![](../Images/c296bd5bdef3a232c4a96a738477e0ee.png)![](../Images/727eb984cf6691ed67e7284174ad720c.png)** 薪资那么高 **** 我能学会吗？能找到工作吗？**每个打算学，或者正在学Python的人，应该都会思考这个问题吧：**学完Python找不到工作怎么办？**  
毕竟下定决定学习一门语言，需要付出精力跟成本。没人希望学完之后一无所获、找不到工作。**但其实，这个问题多少有些问题。****学完Python？达到怎样的水平才算是学完呢？**入门基础知识算是学完？达到岗位招聘条件算是学完？**V站上有一个点击16000+的问题：**为什么纯 Python 的工作这么难找?从大家的回复中，可以总结出以下几点：**1. **Python整体上初学者较多，不好找的多是没有亮点的初学者。**2. **单纯以Python为工作，要么是基本功深厚的Python工程师，要么是AI和数据分析等当下热门的方向，相对会好一点。**3.  **已经有基础的程序员，花几个星期，就能达到初学者学几个月的水平，想单纯靠Python一门技能找工作，竞争力不够。![](../Images/189d9db61b38148762afae1ee2117f1e.png)所以坦白地说，这个问题有两个回答：  
**一、如果你不想成为Python程序员**，只想用Python辅助现在的工作，拓宽自己的职业前景 —— 那你可以花一两个月的时间，学一下Python，因为它真的很简单，写一个爬虫可能只用几行代码，却可以大大提升你的工作效率。**这可能是性价比最高的提升途径了，没有之一。**  
**二、如果你想成为专业的 Python 程序员**，想随便学一两个月Python，就靠它去为你赚钱的时代已经过去了，大家心里要有这个底。把Python学的很好，就如同英语里的高级翻译、同声传译等，能够单纯靠语言本身拿到较高难度，这种情况难度也较大。当然你还可以把 Python 当作基础工具，做数据分析、做机器学习等，如同英语中的商务英语、国际贸易等，也有不错的前景。学习编程是一件很公平的事，付出多少就会得到多少，没有例外。![](../Images/6fecb018778f2353254dad5bc4d576fa.png)** 怎么学习 Python？ **Python崛起并且风靡，因为优点多、应用领域广、被大牛们认可。学习 Python 门槛很低，但它的晋级路线很多，通过它你能进入机器学习、数据挖掘、大数据，CS等更加高级的领域。Python可以做网络应用，可以做科学计算，数据分析，可以做网络爬虫，可以做机器学习、自然语言处理、可以写游戏、可以做桌面应用...Python可以做的很多，你需要学好基础，再选择明确的方向。![](../Images/bd8f1802deb27fb786f5a0594e3cf508.png)**实验楼推出《楼+之 Python 实战》第 15 期，11 周的时间带你打通 Python 的任督二脉，从新手成为有实际工作能力的 Python 工程师。课程即将开课，名额****不多，想系统学习 Python 的同学了解一下：****1\. 一线大牛编写**课程由 **腾讯、Intel、IBM** 等一线互联公司的大牛编写，课程内容源自于真实的开发实践，让你一开始就养成良好的代码规范和编程习惯。**2\. 万元课程中才能见到的教学服务**课程提供了 ** 40 个编程实验 + 46 个挑战作业 + 186 个教学视频 + 2 次直播，**还有助教实时答疑、班主任督学、共享桌面辅导等服务，全面保证学习效果。![](../Images/a925a4550cafc7b1c29d8faf9715ee94.png)**3\. 知识涵盖面广**11 周的课程覆盖了 **Python 基础、Web 开发、Python 爬虫、数据分析、数据库、Flask Web 应用、运维开发 **等内容。选择楼 +，意味着选择每周 12 小时的汗水，和远超一般培训班的收获。![](../Images/0f59c40937790a6deb4b371246d99fef.png)无论你是计算机专业还是非计算机专业，都可以报名，前提只有一样：对Python学习感兴趣，并能坚持每周付出12小时的时间学习。
