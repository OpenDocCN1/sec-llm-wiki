英语不好能学Python吗？掌握下面这些单词就差不多了……

Python 相关  

**1\. Py \['paɪ\]**

Py 就是 Python 的缩写，Python文件的后缀也是 py。比如： py交易`HelloWorld.py`

**2\. Pythonic \[paɪ'θɒnɪk\] ：Python风格的**

\-ic 形容词后缀，表...的

Python + ic = Pythonic

**3\. Pythoneer \[paɪ'θɒnnɪə(r)\] ：Python开发者**

\-eer 名词后缀，表职业

Python + eer = Pythoneer

engine + eer = engineer 工程师

**4\. IPython**

一个增强型的Python shell，支持变量自动补全、自动缩进等。
