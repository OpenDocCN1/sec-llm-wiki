Django 是一个由 Python 编写的开放源代码的 Web 应用程序开发框架。它采用了 MVT 软件设计模式，即 Model 模型、View 视图和 Templates 模板。它最初被开发出来用于管理某新闻网站，于 2005 年在 BSD 许可下发布开源。这套框架是以比利时的吉普赛吉他手的名字命名的。


Django 的主要目标是使得开发 “流程复杂、依赖数据库的网站” 变得简单。Django 注重各个组件间的低耦合性，遵循 DRY 原则。


以在线作业管理系统为例，今天我们就一起来看一下如何运用 Django 来搭建在线作业管理系统。

如何运用Django搭建在线作业管理系统？

Part.1

需求描述

教师端：教师能够创建课程、发布作业、统计作业、对作业进行评论和打分等；

学生端：学生能够加入课程、查看作业并提交作业、对作业进行评论等；

系统管理端：使用 Django 自带的 admin 后台对用户信息、作业信息进行管理。

Part.2

项目逻辑

在运行项目前，我们首先要明白Django的运行逻辑。


用户在浏览器输入地址后，Django 会在 homework/homework/urls.py 中查找并匹配路由，接着跳转到该路由所指向的 homework/project/views.py 中的视图函数，每个视图函数会返回相关信息（比如 JSON 数据）或者一个界面，界面即 homework/project/templates 文件夹下的 HTML 文件并返回到浏览器端。

homework/project/views.py 中的视图函数在运行时会调用homework/project/forms.py 中的表单信息或者homework/project/models.py 中的数据库表信息。

Django 自带 admin 管理，需在 homework/project/admin.py 中添加配置信息即可看到相关界面。
