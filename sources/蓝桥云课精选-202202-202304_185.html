题目描述


本题为填空题，只需要算出结果后，在代码中使用输出语句将所填结果输出即可。


如果一个分数的分子和分母的最大公约数是 1，这个分数称为既约分数。


例如 3/4，1/8，7/1，都是既约分数。


请问，有多少个既约分数，分子和分母都是 1 到 2020 之间的整数（包括 1 和 2020）？


解题思路


本题使用的知识点为 枚举、gcd，涉及组别为第 11 届蓝桥杯软件类 C/C++ A/B 组、Java A 组。


这是一道简单模拟题。


分别从 1∼2020 枚举分子、分母，然后判断当前枚举到的分子和分母的 gcd 是否为 1，若为 1 则 ans++。（ ans 表示答案）


最后的答案为 2481215。


参考代码


1.Java

import java.util.*;public class Main {    public static void main(String[] args) {        int ans = 0;        for(int i = 1 ; i <= 2020 ; i ++){          for(int j = 1 ; j <= 2020 ; j ++){            if(gcd(i , j) == 1) ans ++;          }        }        System.out.println(ans);    }    static int gcd(int a,int b){      if(b == 0) return a;      else return gcd(b , a % b);    }}


2.C/C++（正确代码见留言置顶🔝）

#include<bits/stdc++.h>using namespace std;int get(int x){    int cnt = 0;    while(x){        if(x % 10 == 2) cnt ++ ;        x /= 10;    }    return cnt;}signed main(){    int ans = 0;    for(int i = 1 ; i <= 2020 ; i ++){        ans += get(i);    }    cout << ans << '\n';    return 0;}
