题目描述


本题为填空题，只需要算出结果后，在代码中使用输出语句将所填结果输出即可。


小蓝要为一条街的住户制作门牌号。


这条街一共有 2020 位住户，门牌号从 1 到 2020 编号。


小蓝制作门牌的方法是先制作 0 到 9 这几个数字字符，最后根据需要将字符粘贴到门牌上，例如门牌 1017 需要依次粘贴字符 1、0、1、7，即需要 1 个字符 0，2 个字符 1，1 个字符 7。


请问要制作所有的 1 到 2020 号门牌，总共需要多少个字符 2？


解题思路


本题使用的知识点为 枚举、模拟，涉及组别为第 11 届蓝桥杯软件类 C/C++ A/B/C 组、Java A/B 组、Python 组。


这是一道简单模拟题：


  • 枚举数字 1∼2020，把每个数按十进制分解，再统计 2 出现的次数即可；

  • 也可以将每个数字都转换为字符串，然后直接统计这些字符串总共有多少个字符 2。


最后的答案为 624。


参考代码


1.Java

public class Main {    public static void main(String[] args) {        int ans = 0;        for(int i = 1 ; i <= 2020 ; i ++) {            int x = i;            while(x != 0) {                if(x % 10 == 2) {                    ans ++;                }                x /= 10;            }        }        System.out.println(ans);    }}


2.C/C++

#include<bits/stdc++.h>using namespace std;int get(int x){    int cnt = 0;    while(x){        if(x % 10 == 2) cnt ++ ;        x /= 10;    }    return cnt;}signed main(){    int ans = 0;    for(int i = 1 ; i <= 2020 ; i ++){        ans += get(i);    }    cout << ans << '\n';    return 0;}
