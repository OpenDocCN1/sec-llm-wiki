2022 年 Stack Overflow 开发者调查报告来啦！这份报告超过 7 万名开发人员参与，告诉大家「他们如何学习和升级」、「他们正在使用哪些工具」以及「他们想要什么」。


在报告中显示，开发者们最常用的编程学习途径为：其他在线资源，如视频、博客等（70.91%）；学校（62.18%）；书籍（54.48%）；在线课程（46.63%）；在线培训（39.85%）……


（内容来源：2022 年 Stack Overflow 开发者调查）


我们可以看到，使用在线资源的用户最多。那大家在学习编程中，最依赖的在线资源是什么呢？


Stack Overflow 开发者调查报告中也给了一个很好的答案，技术文档独占鳌头，占比达到 88.13%。另外，Stack Overflow 的使用率也很高，达到 86.14%。


所以，拥有编写良好的技术文档以及在 Stack Overflow 上提供答案的活跃社区是多么重要！


当然了，学习编程的途径并不是只有技术文档，还有博客、操作教程视频、书面教程、在线挑战，编程游戏……


（内容来源：2022 年 Stack Overflow 开发者调查）


编程、脚本和标记语言

从 TIOBE 编程语言排行榜和 2022 IEEE 编程语言榜单中，我们可以知道，Python 均位列第一位。

如果没有看过这两个榜单的，请移步：
1.TIOBE 9 月编程语言排行榜｜Julia 有望挤进前 20！
2.Python 再度摘冠！2022 IEEE 编程语言榜单公开！

2022 年 Stack Overflow 开发者调查报告中最流行的编程语言与前两个编程语言排行榜（TIOBE、IEEE）不同，JavaScript 最受调查的开发者的欢迎。


这也标志着 JavaScript 连续第十年成为最常用的编程语言。

  • 如果从专业开发的角度来说，专业开发者们最常用的是：Javascript、HTML/CSS、SQL 和 Python；
  • 如果从学习编程的角度来说，编程学习者最常用的是：HTML/CSS、Javascript、Python 和 Java。

数据库

数据库，是目前较为热门的方向。用户最常使用的是：MySQL 和 PostgreSQL。


MongoDB 是学习编程者的第二受欢迎的数据库（仅次于 MySQL），这是有道理的，因为它支持大量的语言和应用程序开发平台。

（编程学习者最常用的数据库）

云平台

AWS 仍然是所有受访者和专业开发人员最常用的云平台。Azure 从谷歌云中获得第二名。

（专业开发者最常用的云平台）

学习编码的人对云平台的使用有很大不同，Heroku 是学习编程人员最常用的平台（35%），明显高于专业开发人员（18%）。

（编程学习者最常用的云平台）


Web 框架和技术


Web 其实我们每一个人都接触过，也就是我们常见的网页、网站。它有三种常见的形式：超文本、超媒体、超文本传输协议。

而平常听说的 Web 开发，其实也就是网站开发。网站由很多的网页组成，网页又由一行行的标签代码、数据代码组成。

在报告中我们可以看到，Node.js 和 React.js 是大家最常用的两种 Web 技术。
