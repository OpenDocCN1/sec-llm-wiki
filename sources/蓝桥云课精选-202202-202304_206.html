为什么要使用 Go 语言呢？


Go（又称 Golang）是 Google 开发的一种静态强类型、编译型、并发型，并具有垃圾回收功能的编程语言。


它有以下 5 个优点：

  • Go 语言容易上手（其实比 Java 难）；

  • Go 语言解决了并发编程和写底层应用开发效率的痛点；

  • Go 语言有 Google 这个世界一流的技术公司在后面；

  • Go 语言的杀手级应用是 Docker，而 Docker 的生态圈火爆程度，大家不言而喻。


因此，Go 语言的未来会有不错的发展。当然，Go 侵入很多 C、C++、Java 的项目。不过，Go 语言主要作用应该是中间层的项目，而不是底层或者业务层。

换句话说，Go 语言不会侵入底层到 C 和 C++ 项目，也不会侵入 Java 业务层的项目。

Go 的语法接近 C 语言，但对于变量的声明有所不同。Go 支持垃圾回收功能。


Go 的并行模型是以东尼·霍尔的通信顺序进程（CSP）为基础，采取类似模型的其他语言包括 Occam 和 Limbo，但它也具有 Pi 运算的特征，比如通道传输。


与 C++ 相比，Go 并不包括如枚举、异常处理、继承、泛型、断言、虚函数等功能，但增加了切片（Slice）型、并发、管道、垃圾回收、接口（Interface）等特性的语言级支持。


不同于 Java，Go 内嵌了关联数组（也称为哈希表（Hashes）或字典（Dictionaries）），就像字符串类型一样。
