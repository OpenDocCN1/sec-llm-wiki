我们都知道，工作效率对于一个打工人来说，十分重要！！这里，我提供几个我觉得让工作效率/体验提升了 n 个 level 的工具（如果你有其他合适的工具，也可以在下方留言哈～）：


1.Rufus：可能是最小的装系统神器仅900KB



Rufus 是一个可以帮助格式化和创建可引导 USB 闪存盘的工具，比如 USB 随身碟，记忆棒等等。


在如下场景中会非常有用：

  • 你需要把一些可引导的 ISO 格式的镜像（Windows，Linux，UEFI 等）创建成 USB 安装盘的时候；

  • 你需要使用一个还没有安装操作系统的设备的时候；

  • 你需要从 DOS 系统刷写 BIOS 或者其他固件的时候；

  • 你需要运行一个非常底层的工具的时候。



Rufus 麻雀虽小，五脏俱全，体积虽小，功能全面。一句话概括：开源，免费，小巧，多能！


2.好用上手的 Markdown 编辑器

1）Atom


GitHub 官方出品，支持实时预览，可以安装多种插件，并且跨平台，总之非常灵活！


2）Typora


Typora 可以实时预览写好的部分，完美地将书写与展示融为一体。有人说它可能是地球上最好用的 Markdown 编辑器了。


3）Mark Text


Mark Text 所输即所见，摒弃了众多 markdown 编辑器左边写作右边预览的写作方式，巧妙的将编辑和预览融为一体。


snabbdom 作为 Mark Text 的渲染引擎，保证了极速渲染编辑页面，带来流程的书写体验。


支持 CommonMark Spec 和 GitHub Flavored Markdown Spec 语法格式，生成的 Markdown 可以复制到任何支持 markdown 格式的社区、网站。段落及行内样式快捷键提升您的编辑效率。


4）Bear


拥有 Markdown 的长处，却又补上了短板。


感谢 iOS 键盘上的标记栏，让初学者可以完全忘了 Bear 实际是一款基于 Markdown 的编辑器。在上文我并没有提到这点，是因为用户可以通过像 Word 这类富文本编辑器一样，选中文字，点击编辑。


不过 Bear 的 Markdown 并没有停留在支持 Markdown 上，而是为了易用性做出了许多改进。


3.Listify：简单好用的 todo 应用


Listify 是一款简单的，拥有多个分类列表的 todo 应用。


4.CodeCharge Studio 5.1 :领先的软件开发工具


以最少的编码直观地创建数据库驱动的 Web 应用程序。对于那些不喜欢纠结太多代码的初学者来说，这是一个很棒的工具。


CodeCharge Studio 5.1是一个完整的 Web 开发解决方案，可以在 ASP，PHP，Perl，ColdFusion，JSP，http://ASP.NET  中生成无错误的网站。


5.Cloud9 IDE：100％ 在线编辑器


将在线编辑与 Docker UBUNTU 工作区相结合。修改后的语言工具可以处理 40 多种语言，包括Ruby，Python，JavaScript，Go 和 PHP。


可以在300多种浏览器组合上创建和测试 WordPress，Meteor，HTML5 和 Django 网站。


6.QuickLook ：完全可以取代 Windows 的预览功能


软件预览功能很好用，完全可以取代 Windows 的预览功能。相比之下还多了可以查看文件详细信息的效果。


选中文件空格就可以查看。可以查看文件夹信息，图片信息，html 信息，pdf 信息，word 信息，视频信息，压缩包信息。
