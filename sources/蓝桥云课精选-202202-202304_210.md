前几天，TIOBE 发布了 9 月编程语言排行榜。

  

就在 8 月，我们可以从编程语言排行榜中看到，Python 刷新了新高。更意外的是，Python 在 9 月，**再一次刷新了自己的市场占比**，以 4.07% 的增长率占据了 15.74% 的市场份额。

  

![](../Images/2d97861d8d92ed5cb72d534db7d86127.png)

（TIOBE 9 月编程语言排行榜 TOP1-10）

  

跟 8 月相比，前十的排名没有变化，但是市场占比由了较为明显的变动。

  

**1.C 语言、 Java、C++、C# 和 Visual Basic 的市场占比下降：**

*   C 语言从 14.59% 下降至 13.96%；
    
*   Java 从 12.4% 下降至 11.72%；
    
*   C++ 从 10.17% 下降至 9.76%；
    
*   C# 从 5.59% 下降至 4.88%；
    
*   Visual Basic 从 4.99% 下降至 4.39%。
    

  

**2.Python、JavaScript、Assembly language、SQL、PHP 的市场占比上升：**

*   Python 从 15.42% 上升至 15.74%；
    
*   JavaScript 从 2.33% 上升至 2.83%；
    
*   Assembly language 从 2.17% 上升至 2.49%；
    
*   SQL 从 1.70% 上升至 2.01%；
    
*   PHP 从 1.39% 上升至 2.01%。
    

![](../Images/49da5c7bf985a4259d02e3cfee398d24.png)

（TIOBE 8 月编程语言排行榜 TOP1-10）

  

Julia 编程语言距离前 20 名仅差 0.05%，它专为**数值分析和计算科学**而设计。该领域中有许多相互竞争的语言，比如 Python、R 语言等。

  

![](../Images/ef25e83b46030fc9897a402f5c642880.png)

（TIOBE 9 月编程语言排行榜 TOP11-20）

  

![](../Images/d76f2c4510913f265754be42c0a6b038.png)

（TIOBE 9 月编程语言排行榜 TOP21-23）

  

那是什么让 Julia 脱颖而出？

  

TIOBE 官方称：Julia 击败了 Matlab，因为 Julia **更现代**，并且可以**免费使用**。此外，Julia 击败了 Python 和 R，因为它更快。

  

由于数字运算和建模领域的**需求巨大**，Julia 在不久的将来有很大的机会进入前 20 名。

  

不过，反观往月，Julia 想进前 20 名并不会那么容易，从 Rust 就可以看出它的不易，反复徘徊在 TOP20 的边缘，没有一次是成功的。

  

至于 Julia 会不会打破常规，我们还是需要时间去证明，让我们拭目以待 Julia 的发展吧！
