什么是 RMQ？RMQ 是一个解决**多个区间最值查****询**的算法，即区间最值查询。  

  

RMQ 算法的目标就是**降低多区间最值查询问题的时间复杂度**。它是通过动态规划思想实现的，需要在 O(nlogn) 的时间复杂度内预处理出部分区间的最值，在 O(1) 的时间内获得一个区间的最值查询结果，总的时间复杂度被降到了 O(nlogn)。

  

它的主要方法和复杂度如下：

  

*   **朴素**（即搜索），O(n)-O(qn) online
    
*   **线段树**，O(n)-O(qlogn) online
    
*   **ST**（实质是动态规划），O(nlogn)-O(q) online
    
*   **RMQ 标准算****法**：先规约成 LCA（Lowest Common Ancestor），再规约成约束 RMQ，O(n)-O(q) online
    

  

今天的「算法学与练」主要讲的是 ST。

  

ST 表（Sparse Table，稀疏表）是一种简单的数据结构，主要用来**解决 RMQ**（Range Maximum/Minimum Query，区间最大/最小值查询）问题。

  

它主要应用倍增的思想，可以实现 O(nlog⁡n) 预处理、 O(1) 查询。  

  

**1.预处理**

在递推时，我们把子区间的长度成倍增加，于是我们就能轻轻松松得到下面的这个递推表达式：

根据这个思路，我们就可以写出预处理的代码（代码中用到了对数的换底公式），注意代码中的循环顺序一定是**先枚举倍增次数**，才能确保递推的正确性。

```
inline void prework(){  for(int i=1;i<=n;i++)f[i][0]=a[i];  int t=log(n)/log(2)+1;  for(int j=1;j<t;j++){    for(int i=1;i+(1<<j)-1<=n;i++){      f[i][j]=max(f[i][j-1],f[i+(1<<(j-1))][j-1]);    }  } }
```

```
inline int query(int l,int r){  int k=log(r-l+1)/log(2);  return max(f[l][k],f[r-(1<<k)+1][k])}
```
