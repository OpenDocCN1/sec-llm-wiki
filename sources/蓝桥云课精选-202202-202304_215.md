### 很多人会问，框架是什么？用生活上的事件来说，可能会更好理解。

### 

  

### 所有房子都有一个骨架，但是我们在建房子时都要重新建立一遍骨架，然后填砖，那么如果我们有现成的骨架了，只填砖是不是更快一些？

  

![](../Images/e5584e6ce08225f3ba18faa26a55eef0.png)

  

房子就好比一整套完整的应用程序，每个程序的具体业务要求不同，但每个基建是一样的，比如文件上传、数据查询等。

  

框架就是把这些东西已经做好了，打包成了一套工具，你拿来**直接调用**它的方法就好了。你只需要写你的具体业务部分，这样就免去了很多基础且重复的工作，既加快了开发速度，又提升了效率，这就是框架。

  

拿 web 开发的 MVC 模式举例，M 是模型，V 是视图（表现层），C 是控制层。

  

![](../Images/cc041d5e50c21afe5eb391d88ca67446.png)

（来源于网络）

  

**框架就是 M 层**，他把一套不涉及任何业务相关的东西都写好了包装起来，你去用就可以了；C 的控制层，他是没法写的，因为不同的系统有不同的业务逻辑，框架不可能帮你写完所有东西，包括业务逻辑的内容。

  

就好比盖房子的架子，他只能做到一个架子，不是因为他不能完全弄好，而是因为他没法去加，他也不知道你到底是需要什么颜色的瓦片、墙体颜色等等。

  

综上所述，框架可以理解为一个毛坯房，有了这个毛坯房你可以将他在短时间内，装修成自己想要的样子，而不需要再一砖一瓦的去盖房子。

  

那我们都需要学哪些框架呢？这里我推荐 3 个框架，供大家学习～

  

**1.爬虫框架**

如今，我们已经进入到一个大数据的时代，大数据中最重要的数据来源，很多都是**依赖爬虫技术**实现的。日常使用最多的搜索引擎，其实就是一个非常庞大的爬虫系统。

  

本实验为 Python 爬虫实战课程，我将通过** 11 个爬虫案例**，让你学会爬虫基础知识，顺利进入 Python 爬虫应用的世界。

  

![](../Images/47665200c78ed1ae81d6f7447745cccd.png)

  

**学习 Python 爬虫最好的办法，就是实验**，将爬虫程序应用到自己的工作与生活中。希望实验中的热搜采集器，点赞器，签到器对你有所启发～

  

**2.前端 vue.js 框架**

前端必须框架 Vue3，Vue 3 可以说是从 0 开始编写的，更加清晰和更易维护的架构，主要进行了性能的改进，更小的资源包、更好的类型支持（TypeScript）、提供了一大批新的 API，为框架的长期迭代奠定了基础。

  

![](../Images/26405048a146c2192ff07f2abd2c77c2.png)

  

此课程抢先了解前沿技术栈，你想学习的 Vue3 技能知识点，都在这里。幽默风趣的课堂氛围，真正的通俗易懂，课程**所学即真实企业级项目**中所用。

  

**3.后端 flask 框架**

Python 作为一门优秀的编程语言，在很多领域可以发挥其作用，其中一个广泛使用的领域就是 **Web 开发**。所谓 Web 开发指的是编写 Web 应用程序用于处理 Web 请求。

  

Python 的语言特性使得自身编写 Web 框架极其容易，以至于现在有上百种 Python 编写的 Web 开发框架，比如 flask 框架。

  

flask 框架**麻雀虽小，但五脏俱全**，Flask 可以实现的功能并不比其它框架少，因为它是一个可扩展的 Web 应用开发框架。

  

![](../Images/5481283c406abbaa3c7c8a926dbf58c3.png)

  

通过该本课程的学习，大家能够深入了解 Flask 开发体系，提升熟练度。
