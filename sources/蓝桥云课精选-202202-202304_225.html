接触过 Java 语言的你肯定知道，程序员所书写的是源代码，通过编译器可以生成字节码，然后通过解释器转换为机器码，这样，机器就能读懂程序员希望它干啥了。



从上图中我们可以看到，通过 javac 命令可以将源代码编译成字节码，然后通过 java 命令将字节码解释成机器码，没有问题机器就运行，这样我们就可以看到程序结果了。

本实验中已经提供给了大家一个 Test.java 源文件和 Person.class 字节码文件，如下图所示：



我们可以执行以下命令看一看效果：


javac Test.javajava Test



打开 Test.java 源代码：


public class Test {    public static void main(String[] args) {        Person p1 = new Person();        p1.setName("张三");        System.out.println(p1.displayInfo());        Person p2 = new Person("李四",1,10,true);        System.out.println(p2.displayInfo());    }}


从代码中可见，使用到了 Person 类调用了类中的方法进行数据操作，然而提供给大家的是 Person.class，字节码文件是无法直接打开的。



那么问题来了.class 字节码文件应该如何获取信息呢？


没错这里只提供了字节码文件 Person.class，接下来就来告诉大家如何通过字节码文件获取类中成员信息。


javap 命令

我们可以通过 javap 命令，来获取源文件中的基本信息，这叫反编译操作。


javap 命令是 JDK 自带的反汇编器，用来解析字节码文件。


语法格式：


javap [options] 类名|*.class


注意：使用 javap 查看字节码文件的内容，必须提供类名，或者使用 Xxx.class 也可以，当书写为 *.class 时，表示当前目录下的所有字节码文件。


查看 Person 类的信息：


javap Person



也可以查看 JDK 提供的 Object 类信息：


javap java.lang.Object



不使用选项参数的情况下可以查看到 public、protected 修饰的和默认情况下的属性和方法。


使用选项参数 -h

查看所有选项信息以及各自的作用，命令如下：


javap -h



使用选项参数 -version

查看编译器的版本信息，命令如下：


javap -version



使用选项参数 -p

查看 Person 类中所有定义的属性和方法，命令如下：


javap -p Person



使用选项参数 -sysinfo

查看 Person 类的系统信息，命令如下：


javap -sysinfo Person



选项参数就不一一讲解了，大家可以自己都去试试。


最后，说一下反编译后的内容我们也可以保存到指定的文件中，命令如下：


javap -p -sysinfo Person > Person.txt



相信大家对 javap 命令有了一定的认识，也会进行了简单的使用，这个命令挺有意思吧！


当然了，若 Person.class 文件是经过加密处理的，那么 javap 命令将没有用了哦~
