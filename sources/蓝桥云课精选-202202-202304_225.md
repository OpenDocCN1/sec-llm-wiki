接触过 Java 语言的你肯定知道，程序员所书写的是**源代码**，通过编译器可以生成字节码，然后通过解释器转换为机器码，这样，机器就能读懂程序员希望它干啥了。

  

![](../Images/fd0f5c461dbd7ff8c241ef522ab2ab9f.png)

  

从上图中我们可以看到，通过 javac 命令可以将源代码编译成字节码，然后通过 java 命令将字节码解释成机器码，没有问题机器就运行，这样我们就可以看到程序结果了。  
本实验中已经提供给了大家一个 Test.java 源文件和 Person.class 字节码文件，如下图所示：

  

![](../Images/1017632cfa420397ebd18ebc38b5a40e.png)

  

我们可以执行以下命令看一看效果：

  

*   
*   

```
javac Test.javajava Test
```

  

![](../Images/62d5f2d3ed60d742e213b1e41bb69f57.png)

  

打开 Test.java 源代码：

  

*   
*   
*   
*   
*   
*   
*   
*   
*   

```
public class Test {    public static void main(String[] args) {        Person p1 = new Person();        p1.setName("张三");        System.out.println(p1.displayInfo());        Person p2 = new Person("李四",1,10,true);        System.out.println(p2.displayInfo());    }}
```

  

从代码中可见，使用到了 Person 类调用了类中的方法进行数据操作，然而提供给大家的是 Person.class，字节码文件是无法直接打开的。

  

![](../Images/10e8a60fd4ce6b7638e3b966671ba57c.png)

没错这里只提供了字节码文件 Person.class，接下来就来告诉大家如何通过字节码文件获取类中成员信息。

  

# **javap 命令**

我们可以通过 javap 命令，来获取源文件中的基本信息，这叫**反编译**操作。

  

javap 命令是 JDK 自带的反汇编器，用来**解析字节码文件**。
