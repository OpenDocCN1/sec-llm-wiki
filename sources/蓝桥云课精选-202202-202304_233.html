JRebel 发布了 2022 年 Java 开发者生产力报告，这项调查从 2021 年 10 月开始收集数据，截止到 2022 年 1 月共收到来自世界各地共 876  名 Java 开发专业人员的回复。



该报告主要关注开发 Java 应用程序所使用的 Java 技术和方法，以及性能、微服务和 CI/CD 等相关问题。


■ 调查人群

  • 人员分布

本次调查针对全球各地的 Java 开发人员，在问卷的第一个问题，JRebel 要求参与调研的用户分享其所在公司总部的位置。

数据显示，美国和中国的受访者最多。


  • 人员职别
本次调研对象以 Java 开发相关岗位的从业人员为主，除了 Java 开发，其次占比较高的是 Java 架构师，还有约 20% 的技术领导人员。


  • 公司规模及团队规模
本次调研对象大多是大型企业公司的员工，公司规模超过 1000 人的受访者占 31% ，拥有 100-1000 名员工的中型公司位居第二，占 27% 。

小公司和初创公司的持股比例分别为 20% 和 12% 。


报告显示，受访者所在的开发团队多为 3-9 人，占比高达 47% 。其中 100+ 人员的开发团队占比仅为 4% 。 


■ Java 语言及编程趋势

  • 开发人员主要使用什么 JDK 编程语言进行开发？

报告显示，大多数开发人员仍然选用 Java 8 作为主要的应用程序开发语言，占比 37% ；Java 11 位居第二，占比 29% 。


有少数开发人员选择了 Kotlin、Groovy 及 Scala ，但是这三类语言总的占比仅为 17% 。



结合反馈者所在企业规模来看，员工少于 100 人的公司中，Java 8 和 Java 11 的使用率接近，其他更新版本的使用率有所增加。


与小型公司相比，员工 ≥ 100 人的公司更多使用 Java 8 。



  • 哪些因素会影响开发人员升级 JDK 版本？

大多数受访者表示，长期支持是升级 JDK 版本的主要因素。在 LTS （长期支持）之后，安全性和性能是最高的因素，分别为 23% 和 20% 。


新特性（18%）和法规遵从性（14%）是升级过程中最不受欢迎的因素。



结合企业规模来分析，报告发现不管是大型企业还是小型企业，长期支持都是他们选择是否升级 JDK 版本的主要因素。


  • JRE / JDK 分布

报告中，受访者分享了他们使用的 JRE/JDK 发行版。


在今年的受访者中，Oracle Java 的选择分布为 36% ，Generic OpenJDK 和 AppotOpenJDK/Adoptium 分别为 27% 和 16% 。


OpenJDK 的 OpenLogic 分布在调查对象中有 2.3% 的代表性。



■ Java 应用程序体系结构趋势

调查显示，基于微服务的应用程序最受欢迎为 32% ，而单片应用程序占 22% 。其次，模块化单片应用程序占响应的 13% ，而面向服务的体系结构占 12% 。


  • 微服务趋势
报告收集了用户当前微服务体系的使用状态、应用程序中微服务的使用数量、微服务框架选择等内容。

在微服务使用类型上，大多数组织要么拥有完全基于微服务的应用程序，要么目前正在过渡到微服务体系结构。


在基于微服务的应用程序中， 30% 的人表示有 1-5 个微服务，而 24% 的人表示有 5-10 个微服务。

在更高的使用规模里， 16% 的人表示有 10-20 个微服务， 22% 的人表示在其应用中有超过 20 个微服务。只有 8% 的人表示没有了解他们应用程序中使用的微服务的数量。


  • 微服务框架使用
调查显示，Springboot 框架仍然是主流，74% 的开发人员将其应用在项目里。Quarkus、Vert.X 、 DropWizard 等框架仅占 8% 。

其中有 18% 的用户选择了包含“其他”类别中的常见框架包括企业应用程序规范，如 Java EE 和 YagadaEE ，以及普通的 Spring 框架。

然而，最常见的“其他”响应是，他们根本没有使用微服务框架。


■ Java 技术趋势

  • Java 虚拟机平台

数据显示，Docker 和 Kubernetes 分别以 41% 和 26% 的使用率占据榜首的第二位，其次是 Vmware ，占比 16% 。


  • Java 框架配置
使用外部 xml 、 yaml 或类似文件的开发人员（43%）和在类、方法和字段上使用@注释的开发人员（42%）几乎持平。


  • Java PaaS 提供商
报告调查了开发人员所使用的云平台 / PaaS 服务，其中有 31% 的开发者反馈使用 AWS ，24% 的开发者表示未使用任何 PaaS 服务。

Azure 排名第三受欢迎，占比 14% ，其次是谷歌云平台，占比 11% 。


  • 应用程序服务器
报告调查了开发者在开发 Java 应用程序时使用的应用程序服务器的详细信息。

与前几年一样， Apache Tomcat 远远是最流行的 Java 应用服务器，占所有响应的 48% 。

其次是 JBoss/Wildfly（15%） 、 Jetty（13%） 、 WebLogic（7%） 、 WebSphere（5%) 和 Glassfish（4%） 。

在选择其他对象的受访者中， Payara（JavaEE 7 应用服务器） 最为常见。


  • 构建工具
Maven 在开发人员中最受欢迎，占 68% ，其次是 Gradle ，占比 23% ，Ant 占比 6%。

相较于 2021 年的数据（Maven 67% ，Gradle 20% ，Ant 11%)，开发人员在构建工具的选择上几乎没有什么变化。


  • Java IDE
2022 年，IntelliJ 再次成为开发 Java 应用程序最受欢迎的 IDE ，占比 48% ；其次是 Eclipse ，占比 24% ；VsCode 位于第三位，占比 18% 。
