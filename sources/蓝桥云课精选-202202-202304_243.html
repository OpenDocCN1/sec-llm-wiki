算法是备赛、找实习和工作中必然会考察的知识点，无论是蓝桥杯、ACM 等竞赛，还是大厂面试中，我们都能看到“算法”的踪迹。


其中，输入、输出看似很简单，其实十分重要！大家在刷题时，千万不能忽略！


输入都不正确，接下来的处理会更加麻烦；而输出不正确，即使算法得到了正确的答案，也不能拿到分数。


那什么是标准输入和输出呢？

  • C 语言的标准输入输出方法为 scanf() 和 printf()；

  • C++ 的标准输入输出方法为 cin 和 cout，或者使用 scanf() 和 printf()；

  • Java 的标准输入输出流为 System.in 和 System.out；

  • Python 的标准输入输出方法为 input() 和 print()。


了解了标准输入和输出，我们来结合算法题目进行练习。


本周的第一题是经典的 A+B 入门题，欢迎开启算法刷题的大门~


问题描述

输入两个正整数 A、B，请你计算 A+B，并输出。


题目解析

根据题目的描述，你需要做以下事情：

  • 编写一个程序，使用标准输入来输入整数 A 和 B；

  • 把 A+B 的结果使用标准输出来输出。
