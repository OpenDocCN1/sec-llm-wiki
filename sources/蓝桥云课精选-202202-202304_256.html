如何“创造”项目经验呢？


别急，我带着项目来啦！可以当作简历中的项目经验哦～今天，我们就来用 Vue 和 Spring Boot 开发一套大病保险管理系统。



基于 Vue 和 SpringBoot 的城乡居民大病保险管理系统，是一个经典的前后端分离的入门项目。


系统主要包含系统配置维护、系统参保管理、大病保险管理、大病登记管理、保险审核管理这五大模块。



本系统使用对象有三个，分别是医院医生、保险公司以及系统管理员。


  • 医院医生：主要负责对就医患者进行看病登记；

  • 保险公司：主要负责发布医保信息、维护参保人员档案，设置各类手术的报销比例、医保报销审核；

  • 系统管理员：主要负责医保卡充值、对医院医生和保险公司业务员的登入账号、角色、权限进行配置，系统操作日志、维护数据字典。


接口文档

了解完需求后，我们需要书写接口文档。接口文档的作用，就是约束和规范。


1.系统登录

  • 接口描述：系统登录

  • 数据格式：JSON

  • 请求方式：POST

  • 接口 URL：http://localhost:8080/zwz/login

  • 提示：系统登录接口无需 Token，其他接口需要在请求头中带上该接口返回的 Token。

2.获取登录验证码图片

  • 接口描述：获取登录验证码图片

  • 数据格式：JSON

  • 请求方式：GET

  • 接口 URL ：

    http://localhost:8081/zwz/common/captcha/draw



3.初始化验证码

  • 接口描述：初始化验证码

  • 数据格式：JSON

  • 请求方式：GET

  • 接口 URL ：http://localhost:8081/zwz/common/captcha/init


4.查询全部药物档案

  • 接口描述：查询全部药物档案

  • 数据格式：JSON

  • 请求方式：GET

  • 接口 URL ：http://localhost:8081/zwz/medicine/getAll

  • 提示：您需要在请求头中加入 accessToken，该接口无需请求数据


5.查询单个药物档案

  • 接口描述：查询全部药物档案

  • 数据格式：JSON

  • 请求方式：GET

  • 接口 URL ：http://localhost:8081/zwz/medicine/get/1337932650672951297

  • 提示：您需要在请求头中加入 accessToken，接口尾部跟上药物档案的 ID

项目开发

1.搭建前后端分离项目的技术

JSP + Servlet ==> SSM ==> Vue + SpringBoot


  • 什么是 Servlet？

    Servlet 其实就是一个遵循 Servlet 开发的 Java 类。Servlet 是由服务器调用的，运行在服务器端。

  • 什么是 JSP？

    JSP = Java + HTML。是一种基于文本的程序，其特点就是 HTML 和 Java 代码共同存在！

  • 什么是 SSM？

    Spring + SpringMVC + MyBatis
