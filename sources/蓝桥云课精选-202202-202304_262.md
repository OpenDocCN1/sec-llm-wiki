**第一步，产生随机数**

对，猜数我们就可以想到这个数字应该是随机产生的，而这个随机数还需要给出一个范围，不然这个数字就太难猜了。

  

在此我们指定的范围是 1 - 100 的随机整数，代码如下：

public void guessNum(){    //产生1-100之间的随机数    int a = (int) (Math.random()*100)+1;    System.out.println(a);}

## **第五步，我不是一次性的游戏**

    // 提示信息    System.out.println("请输入 1 - 100 随机数：");
    // 获取所猜的数字信息    String s = null;
    while(true){        // 内循环中的代码不变（这里省略）    }
    System.out.println("是否继续(Y/N):");    try {        s = br.readLine();    } catch (IOException e) {        e.printStackTrace();    }    if("n".equalsIgnoreCase(s)){        System.out.println("byebye");        break;    }}
