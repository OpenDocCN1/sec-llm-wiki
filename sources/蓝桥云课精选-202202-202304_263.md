**区间 DP**

区间 DP 就是**在区间上**进行动态规划，求解一段区间上的最优解。主要是通过合并小区间的最优解，进而得出整个大区间上最优解的 DP 算法。

  

在代码实现上，我们可以枚举区间长度为每次分割成的小区间长度（由短到长不断合并），内层枚举该长度下可以的起点，自然终点也就明了了。

  

然后在这个起点终点之间枚举分割点，求解这段小区间在某个分割点下的最优解。

  

*   
*   
*   
*   
*   
*   
*   
*   

```
for(int len = 1;len<=n;len++){//枚举长度        for(int j = 1;j+len<=n+1;j++){//枚举起点，ends<=n            int ends = j+len - 1;            for(int i = j;i<ends;i++){//枚举分割点，更新小区间最优解                dp[j][ends] = min(dp[j][ends],dp[j][i]+dp[i+1][ends]+something);            }        }    }
```

https://www.lanqiao.cn/problems/1233/learning/

  

**数位统计 DP**

数位统计 DP 指的是一种与每个数字的数位上有关的动态规划问题。其中，数位既可以是**基于十进制**，也可以**基于二进制**等等。

  

通常能解决的问题有这样大致的题意：给定一个区间 \[L,R\]，问在这个范围内能够使得给定条件 f ( i )  满足的个数。

  

不同的问题可能会有不同，不过如果满足上述问题时则可以尝试使用数位 DP 解决问题。

  

练习题：

https://www.lanqiao.cn/problems/1262/learning/

  

**状态压缩 DP**

状态压缩就是使用某种方法，简明扼要地以最小代价来表示某种状态，通常是用一串 01 数字（二进制数）来表示各个点的状态。

  

它有**两个基本特征**：

*   问题的数据规模特别小，2 的阶乘次可以通过。
    
*   题目通常都是选与不选两种选择，可以使用二进制串表示。

**树形 DP**

由于树具有递归的性质，因此树形 DP 一半都是用递归的方式进行的。大意是，选了父节点，那么它的直接子节点就不能被选择，求总的权值的最大值。

  

基环树，又叫环套树，就是树上加上一条边。如果把哪个环视为中心，可看成：有一个环，环上的每个点都有一棵子树的形式。

  

基环树要对两部分处理：**树处理**和**环处理**。

  

基环树问题的**处理方法**：

1.断开环上一条边，枚举边端点的情况，当作树来处理；

2.把环上挂着的树的信息都计算完，转换为序列 DP 或者环形DP。
