很多人会问，互联网行业中的 SDK 到底是什么？


SDK 一般指软件开发工具包，都是一些软件工程师为特定的软件包、软件框架、硬件平台、操作系统等建立应用软件时的开发工具的集合。


声网 Agora 的 SDK 已经赋能社交直播、在线教育、游戏电竞、IoT、AR/VR、金融、保险、医疗、企业协作等 10 余行业，共计 100 多种场景。




01
声网 SDK


首先，我们来介绍声网 SDK 的类型。


Agora SDK 主要包含以下几种类型（大家可以根据自行去声网官网下载）：


  • 音频 SDK（Voice SDK）

    基于 UDP 协议以及声网自研的音频编解码技术，提供可靠的实时音频服务。

  • 视频 SDK（Video SDK）

    基于 UDP 协议以及声网自研的音视频编解码技术，提供可靠的实时音视频服务。

  • 云信令 SDK（Real-time Messaging，RTM）

    提供了稳定可靠、高并发、全球化的消息云服务。

  • 互动白板 SDK

    帮助开发者快速、灵活地实现实时白板互动或白板回放。



  • 本地服务端录制 SDK

    是 Agora 针对音视频通话、直播研发的录制组件，帮助开发者快速、灵活地实现音视频通话或直播录制。



02
快速实现在线直播应用


Agora 互动直播（Interactive Live Streaming Premium）可以实现一对多，多对多的音视频互动直播。


本次，我们将集成声网 Agora RTC SDK，快速实现一个 Web 端的在线直播应用。


Agora RTC SDK 是声网提供的用于实现音视频实时通信的 SDK。通过集成 RTC SDK，开发者可以在项目中实现语音通话、视频通话、音频互动直播及视频互动直播等功能。


（Agora 互动直播的基本工作流程）


第一步：创建本地客户端

创建并初始化一个用于控制通话的客户端对象。


var client = AgoraRTC.createClient({ mode: "live", codec: "vp8" });


上述代码中，mode 用于设置频道场景。

  • 一对一或多人通话中，建议设为 "rtc"，使用通信场景；

  • 互动直播中，建议设为 "live"，使用直播场景。


codec 用于设置浏览器使用的编解码格式。如果你需要使用 Safari 12.1 及之前版本，将该参数设为 "h264"；其他情况推荐设为 "vp8"。


第二步：设置用户角色

直播频道有两种用户角色：主播（"host"）还是观众（"audience"），默认的角色为观众。主播既可发布轨道，也可订阅轨道；观众不能进行发布操作。


// role 的值可以是 "host" 或者 "audience".client.setClientRole(role);

第三步：加入频道

调用 join 方法加入一个 RTC 频道，你需要在该方法中传入 App ID 、频道名称、token、用户 ID（可选）。


client.join("App ID", "频道名称", "token", "用户ID");

第四步：创建并发布本地流

如果角色为主播，需要先调用 createMicrophoneAudioTrack 通过麦克风采集的音频创建本地音频轨道对象，调用 createCameraVideoTrack 通过摄像头采集的视频创建本地视频轨道对象。


然后调用 publish 方法，将这些本地音视频轨道对象当作参数即可将音视频发布到频道中。


if (options.role === "host") {  // 创建本地音频轨道对象  localTracks.audioTrack = await AgoraRTC.createMicrophoneAudioTrack();  // 创建本地视频轨道对象  localTracks.videoTrack = await AgoraRTC.createCameraVideoTrack();  // 发布到频道  await client.publish(Object.values(localTracks));  console.log("publish success");}


第五步：订阅远端流

当一个远端用户加入频道并发布音视频轨道时：

  • 监听 client.on("user-published") 事件。当 SDK 触发该事件时，在这个事件回调函数的参数中你可以获取远端用户 AgoraRTCRemoteUser 对象。

  • 调用 subscribe 方法订阅远端用户 AgoraRTCRemoteUser 对象，获取远端用户的远端音频轨道 RemoteAudioTrack 和远端视频轨道 RemoteVideoTrack 对象。

  • 调用 play 方法播放远端音视频轨道。


if (options.role === "audience") {  client.setClientRole(options.role, { level: options.audienceLatency });  // add event listener to play remote tracks when remote user publishs.  client.on("user-published", handleUserPublished);  client.on("user-unpublished", handleUserUnpublished);} else {  client.setClientRole(options.role);}


第六步：离开频道

离开频道即挂断/退出通话，调用 AgoraRTCClient.leave 可以离开当前频道。


该方法可以在任何时候调用，包括正在加入频道时或者正在重连时。


// leave the channelawait client.leave();
