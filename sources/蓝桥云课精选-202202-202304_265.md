很多人会问，互联网行业中的 SDK 到底是什么？

  

SDK 一般指**软件开发工具包**，都是一些软件工程师为特定的软件包、软件框架、硬件平台、操作系统等建立应用软件时的开发工具的**集合**。  

  

声网 Agora 的 SDK 已经赋能社交直播、在线教育、游戏电竞、IoT、AR/VR、金融、保险、医疗、企业协作等 10 余行业，共计 100 多种场景。

**0**1******声网 SDK**

  

首先，我们来介绍声网 SDK 的类型。

  

Agora SDK 主要包含以下几种类型（大家可以根据自行去声网官网下载）：

  

*   **音频 SDK（Voice SDK）**
    
    基于 UDP 协议以及声网自研的音频编解码技术，提供可靠的实时音频服务。
    
    ![](../Images/0f955312185792d798b20b2e13a9d6dc.png)
    
*   **视频 SDK（Video SDK）**
    
    基于 UDP 协议以及声网自研的音视频编解码技术，提供可靠的实时音视频服务。
    
    ![](../Images/4af693865dfd9f15f76c049fc5eb27b0.png)
    
*   **云信令 SDK（Real-time Messaging，RTM）**
    
    提供了稳定可靠、高并发、全球化的消息云服务。
    
*   **互动白板 SDK**
    
    帮助开发者快速、灵活地实现实时白板互动或白板回放。
    
      
    
    ![](../Images/e66c6b65adae8d9b4977b79ed49f7fab.png)
    
      
    
*   **本地服务端录制 SDK**
    
    是 Agora 针对音视频通话、直播研发的录制组件，帮助开发者快速、灵活地实现音视频通话或直播录制。
