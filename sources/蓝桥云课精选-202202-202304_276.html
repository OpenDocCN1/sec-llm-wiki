如果从编程语言初学者的角度来说，学习 C/C++ 更合适。因为这两种语言更接近底层，能够让你了解到程序的底层机制，对猴戏学习&理解整个计算机基础体系，都有很大的帮助。

  • C/C++ 的工作者相对来说没那么内卷，毕竟求职者也没那么多。

面对对象

1.类和对象的概念

  • 类是对一类事物的描述，是抽象的、概念上的定义。Java 中定义类的关键字是：class。

  • 具有相同特征和行为的对象抽象成类，类描述了这一类对象的属性和方法：


    public class Emp{    public String name;    public int age;    public double salary;    public void info(){        System.out.println(name+"=="+age+"=="+salary);    }}

    • 属性（成员变量）用于存储对象的状态，格式：修饰符 类型 属性名

    • 方法（成员方法）用于存储对象的行为，格式：修饰符 返回值 方法名（参数列表）{方法体}

  • 对象（实例）：对象是某个类的实例，是实际存在的某个类的个体。

  • Java 中通过类创建对象的关键字是：new。


Emp e1=new Emp();//创建对象


2.属性和方法

  • 属性是用来描述具体某个对象的特征。描述的是对象的状态信息，通常以变量的形式进行定义。

  • 方法描述类的行为，命名一般是动词，由方法三要素（返回值，方法名，参数列表）组成。

集合

当 Java 程序中需要存放数据的时候，通常会定义变量来实现数据的存储。


但是，当需要存储大量数据的时候该怎么办呢？


这时首先想到的是数组，但是数组只能存放同一类型的数据，而且其长度是固定的，那又该怎么办呢？集合便应运而生了。


集合具有以下特点：

  • 集合只能存放对象。比如将一个 int 型数据存入集合中时，它会自动转换成 Integer 类后存入集合（自动装箱操作），Java 中每一种基本数据类型都有对应的引用类型（封装类）。

  • 集合存放的都是对象的引用，而非对象本身，所以我们称集合中的对象就是集合中对象的引用。对象本身还是放在堆内存中。

  • 集合可以存放不同类型，不限数量的数据类型。


（Java 集合框架）


通过上面的图可以发现：

  • 集合主要分为 Collection 和 Map 两个接口；

  • Collection 接口依赖了 Iterator 接口；

  • Collection 又分别被 List 和 Set 继承；

  • List 被 AbstractList 实现，然后分为 3 个子类，ArrayList，LinkList 和 VectorList；

  • Set 被 AbstractSet 实现，又分为 2 个子类，HashSet 和 TreeSet；

  • Map 被 AbstractMap 实现，又分为 2 个子类，HashMap 和 TreeMap；

  • Map 被 Hashtable 实现。
