很多小伙伴在初触编程时，不知道该如何学习哪门编程语言，C 语言？还是 Python？还是 Java？……

那么，TIOBE 编程排行榜来啦！7 月份榜单，请注意查收！

**01****编程排行榜 TOP20**

  

TIOBE 7 月编程排行榜**与上个月基本一致**，排行榜 TOP3 一直都在 Python、C 和 Java 中变化。

  

![](../Images/2fcd773be65de716e433c13880aea856.png)

（TIOBE 7 月编程排行榜 TOP10）

  

![](../Images/3efad1a20d95500c1ef57d80a05b377e.png)

（TIOBE 6 月编程排行榜 TOP10）

  

前十榜单排名中，唯一变化的是 SQL 和 Assembly Language 对调，即 SQL 下跌一名，Assembly Language 上升一名。

  

我们在排行榜中，我们也可以看到，Python、C、Java 和 C++ 这四大语言，目前合计占有近 50% 的市场份额。所以学习 Python、C、Java 和 C++，**不容易被市场所淘汰**。

  

![](../Images/1a4092fe8499fddf9935b88ddba8e206.png)

（TIOBE 7 月编程排行榜 TOP11-20）

  

PHP 和 Go 均有所上涨，分别从第 13 位上升至第 11 位、第 15 位上升至第 12 位 。

  

除此之外， TOP11-20 中排名相较前一个月出现**上升**的还有：

*   Ruby（19→15 ）
    
*   Fortran （26→18）
    
*   Matlab （24→20）
    

  

**排名下降**的有：

*   Classic Visual Basic（11→13）
    
*   Delphi/Object Pascal（12→14）
    
*   Objective-C（14→16）
    
*   R（16→19）
    

  

Perl 依旧保持第 17 位的位置不变，被挤掉的 Lua 和 Prolog 则分别由上月的第 18、20 位跌至了 7 月的第 24、 25 位。

  

**![](../Images/8543e8abbca38f22d639c3048f2062ea.png)**  
**0**2******编程指数走势**

  

TIOBE 除了公布了榜单 TOP20 的名单外，还公布了 TOP 10 编程语言 TIOBE 指数走势。

  

![](../Images/2e2f6f08bb8b8c543cce320ec863d2bb.png)

（TOP 10 编程语言 TIOBE 指数走势）

  

其中，Python 从 2014 年开始，几乎一直都以平稳的趋势上升，于 2022 年 2 月达到目前的峰值，未来会以什么趋势成长，我们也难以预估。

  

![](../Images/93a237f5bc5046d71e5ee08f3fc9a7ff.png)

（Python TIOBE 指数走势）

  

TIOBE CEO Paul Jansen 还在 7 月编程排行榜中说道：“2022 年我们已经过了一半，2022 年 TIOBE 语言的最大候选语言是 Python、C、C++ 和 C#。我们没有预见到任何相对较新和热门的语言，如 Rust、Dart、Kotlin 或 TypeScript 会接近前20名。让我们期待8月份有更激动人心的消息。”
