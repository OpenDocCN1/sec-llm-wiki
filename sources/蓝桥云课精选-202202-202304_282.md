在蓝桥云课上，我们的课程内容都是使用 Markdown 进行编写的。

  

如果你也是个 Markdown 爱好者，那么你可能使用过 Typora、VS Code、MarkdownPad 等主流的桌面版 Markdown 编辑器，亦或者是 Arya 等在线 Markdown 编辑器。

  

![](../Images/4f0143359f625e60c342ac45f0dbef2a.png)  

###### （使用 VS Code 编辑 Markdown）

  

本次要为大家介绍的工具是 Glow，使用 Golang 编写，在 GitHub 上基于 MIT 协议开源，目前拥有 9K+ Star。

  

它并且不像上面介绍的那些程序一样，Glow 能够让你在终端里阅读 Markdown 文件。

  

当然，Glow 不是一个编辑器，你不能用它去编写 Markdown 文件。

  

![](../Images/894d6aa5ca3f4f3b3a200a2fe245e6a2.png)

  

你可能会说，难道我不能在终端里使用 cat、less 等 Linux 命令，甚至是像 Vim、Nano 之类的编辑器来阅读 Markdown 文件吗？

  

当然可以，但它们会按照原样展示所有的字符，来显示原始的 Markdown 文件，而不是显示正确的格式化文本。

  

![](../Images/3b985b31971327bf69e0a4a83522224c.png)

## **安装 Glow**

Glow 可以使用 pacman、brew 等多种包管理工具直接安装，当然你也可以访问 GitHub 仓库的 Release 页面自行下载对应的系统的版本的包进行安装或者从源码自行构建。

  

这里我们提供了一个下载好的包，可以直接在环境里获取。

  

*   
*   

```
wget https://labfile.oss-internal.aliyuncs.com/courses/1379/glow_1.4.1_linux_amd64.debsudo dpkg -i glow_1.4.1_linux_amd64.deb
```

Glow 可以直接使用，执行命令 glow --help 查看帮助信息。

  

![](../Images/f4fb4f8d509c31c7fc5a6bdfaf7bd285.png)

  

如果查看单个文件，那么直接执行 glow 加上文件名即可。

  

![](../Images/4fdb4612c258a5fdaa853c8af0a646d8.png)

  

如果一个文件太长，我们可以使用 \-p 参数，它的效果和 less 命令类似，可以使用  `j` 和 `k` 键进行上下滚动，或者使用空格键按页查看。

  

### **直接执行**

如果不添加参数直接执行 glow 命令，默认会搜索当前目录下的 Markdown 文件并展示。

  

你可以看到一共有三个标签页，分别是 local、stashed 和 news，local 是你当前执行命令的目录下的 Markdown 文件列表；stash 类似于书签，可以在选中文件后按下 `s` 键添加一个书签，按 `x` 键来移除书签；news 是 Glow 的相关新闻。

  

按下 `Enter` 键可以打开对应的文件；`/` 可以进行搜索；使用上下方向键可以滚动页面，左右方向键按照页数移动（如果存在）；`Esc` 键退出文件预览界面；`q` 键则是退出 Glow。

### **查看远程文件**

除了能够查看本地的 Markdown 文件，Glow 另一个高级功能是可以直接查看远程的 Markdown 文件，只需要指定远程文件或者目录的链接即可。

  

*   
*   

```
# 查看远程文件glow https://labfile.oss-internal.aliyuncs.com/courses/1379/git.md
```

  

除了上面介绍的功能，Glow 还可以自行指定页面宽度，风格等配置，可以自行访问仓库查看使用说明。
