# 全球程序员工资最高可达 11w 美元？

智能招聘平台 CodeSubmit 统计分析了 20 多个国家 2022 年软件工程领域的平均工资，其中美国的软件工程师薪资水平最高，超过了 **11w** 美元/年。

  

![](../Images/abbb0b3b58c0bc767fd1be52aa5e0a68.png)

  

位于第二名的瑞士的软件工程师年薪也超过了 **9w** 美元，其次是以色列、丹麦、加拿大、挪威、澳大利亚、英国、德国和瑞典，2022年年薪均超过了**5w** 美元。

  

爱尔兰、芬兰、荷兰、法国、新西兰、新加坡、阿根廷、日本等国家的软件工程师薪资位于第二梯队，平均年薪为 **36024 美元~48427 美元**。

  

![](../Images/29741f53a706dd2d6a2bf67b35530d0b.png)

  

根据排行榜显示，中国排在第**19** 位，平均薪资水平为 **23,790 美元 / 年**，与发达国家的平均薪资还有较大差距。

  

![](../Images/3054f4eb38f27531ab1128b162181eab.png)

  

从排行榜可以看到，尼日利亚的软件工程师在 2022 年的平均年薪仅为 7255 美元，处于垫底位置。其次，软件工程师平均薪资位于倒数第二名的印度，主要承接西方国家的技术外包工作，薪资为 7725 美元。

  

经济发展水平不同，在软件工程师薪资上有着显著的差异。就软件工程师行业而言，美国的薪资一骑绝尘，高居榜首。位于次位的是西欧国家，然后是新加坡、日本等发达国家，薪资最低的是发展中国家。

  

但整体而言，软件工程师在各个国家都是受欢迎且高薪的岗位，据 PageGroup 称，对软件开发人员需求最高的国家是加拿大、澳大利亚、俄罗斯、瑞典和新西兰。由于缺乏开发人员，工资也往往更高。

  

![](../Images/fdb1677e5ea4a53d3e0e327f0811792c.png)

  

### 虽然美国的软件工程师薪资水平最高，但不同职级和不同的编程语言之间的薪资也有明显差异。

  

**□ 职级差异：**美国软件开发人员的平均工资为每年 110,140 美元或每月 9,178 美元。

  

初级开发人员的平均工资为每年 69,354美元或每月 5,779 美元。另一方面，高级开发人员的平均工资为每年 104,188 美元或每月 8,682 美元。

  

![](../Images/1a2a39536e1ae6aa4a94d26600911c66.png)

  

**□ ****编程语言差异：**Go 和 Python 等流行的后端语言位居榜首。

  

● Go 是收入最高的语言，120,577 美元。

● Ruby 以 119,558 美元位居第二。

● Python 平均支付 114,904 美元。

● Java 的平均工资为 112,013 美元。

● JavaScript 通常在美国支付 111,922 美元。

● Android 开发者的平均收入为 109,377 美元。

● 与 Android 相比，iOS 的平均工资略低，为108,783 美元。

● Rust 紧随其后，为 108,744 美元。

● C 平均支付 101,734 美元。

● PHP 通常支付 92,867 美元。

● 在这些语言中，SQL 付出最少；85,845 美元。

  

榜单还对比了美国、以色列、瑞士、英国、德国、日本、法国、印度、菲律宾、尼日利亚等 10 个国家不同编程语言的薪资水平，发现 Golang 和 Ruby 往往是高薪语言，而 JavaScript 和 PHP 是薪水最低的语言。
