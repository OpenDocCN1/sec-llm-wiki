GitHub

copilot

2021年6月29日，微软与 OpenAI 共同推出 AI 编程工具 GitHub Copilot 。

2022年6月22日，Copilot 已正式上线，定价每月 10 美元（约 66.9 元人民币）或每年 100 美元（约 669 元人民币），对学生用户和流行开源项目的维护者免费提供。


过去写代码，编译器大多只带有自动补全和错误高亮功能，而 Copilot 使用 OpenAI Codex 能从代码编写和整体函数为开发者实时提供建议。


根据官网介绍，GitHub Copilot 采集了数十亿行代码数据进行演练，能为几十种语言提供语法和代码建议，包括微软自研的 Typescript 和 Python 、Go 语言、Ruby 等主流编程语言。


（ Copilot 自动编程 ）


除此以外，Copilot 还支持用户使用其喜欢的的编辑器进行编程，可以将 GitHub Copilot 直接集成到编辑器中，包括 Neovim、JetBrains IDE、Visual Studio 和 Visual Studio Code 。



Copilot 专业的编程建议和庞大的语言数据库是用户最为关注的点，不仅能帮助开发者减少创建样板和编写重复代码模式的时间，也让他们有机会对新的领域进行实践。
