大家知道吗？TIOBE 六月编程指数已经公开了！我也替大家扒拉了下来！

  

![](../Images/b77ecb52f86b50b3e8229dc1b8029a48.png)

TIOBE 编程指数

  

2020 年 4 月，Java 仍然是 TIOBE 指数的第一名。同月，Java 不得不将第一名让给 C。后来，在 2021 年，Python 势不可挡，也超越了 Java。

  

在这个月中，C++ 看起来是下一个超越 Java 的语言。

  

![](../Images/527d7a51d21b3f063aa9bc11e66ba81f.png)

TIOBE 编程指数

  

但 Java 真的是失败方吗？我觉得不然。

  

就目前的就业形式来看，Java 的**就业机会**比其他编程语言要多。

  

在《2022 年软件工程师报告》中，顶级后端工程师技能的榜首为 Java。

  

![](../Images/09811d3163f3f90f473c7d034fda8386.png)

【Hired】《2022年软件工程师报告》

  

在《2021 年 IT 行业项目管理调查报告》中，后端开发和项目经理均占了 20% 左右。

  

![](../Images/6546459fd5aca1c66f1cfc7f643d2537.png)

【禅道】《2021 年 IT 行业项目管理调查报告》

  

此份报告中，还写到了一个重要的内容：**后端常用开发语言依旧是 Java 和 JavaScript**。由此可见，后端开发师对于 Java 的喜爱程度是十分高的。

  

![](../Images/560d180a62823b7b91bea443ec9d7599.png)

【禅道】《2021 年 IT 行业项目管理调查报告》

  

再比如，我们打开招聘软件，搜索开发，一溜烟都在招聘 Java 后端开发。以 boss 直聘为例：

  

![](../Images/73b766b1408fb6ee319324545761c38e.png)

  

所以，你还会觉得 Java 是失败者吗？

  

当然，未来什么走向，我们都无法预测，看好眼前，学好新技术才是真正的目的。
