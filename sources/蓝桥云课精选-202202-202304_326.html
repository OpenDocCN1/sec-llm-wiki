TIOBE 编程指数


2020 年 4 月，Java 仍然是 TIOBE 指数的第一名。同月，Java 不得不将第一名让给 C。后来，在 2021 年，Python 势不可挡，也超越了 Java。


在这个月中，C++ 看起来是下一个超越 Java 的语言。

但 Java 真的是失败方吗？我觉得不然。


就目前的就业形式来看，Java 的就业机会比其他编程语言要多。


在《2022 年软件工程师报告》中，顶级后端工程师技能的榜首为 Java。


【Hired】《2022年软件工程师报告》


在《2021 年 IT 行业项目管理调查报告》中，后端开发和项目经理均占了 20% 左右。


【禅道】《2021 年 IT 行业项目管理调查报告》


此份报告中，还写到了一个重要的内容：后端常用开发语言依旧是 Java 和 JavaScript。由此可见，后端开发师对于 Java 的喜爱程度是十分高的。
