**04****fortune 命令**

  

Fortune Cookie，是一种元宝状的甜脆点心，空心内通常会藏着印有祝福或哲理的纸条，是美国中餐厅的一种餐后甜点。

  

![](../Images/23d7d391f250da53cac313c750212aa4.png)

  

在 Linux 中，我们可以通过简单的安装 fortune 命令来打印输出这种语句。

  

*   
*   

```
sudo apt install fortune -yfortune
```

  

默认只支持英文，运行效果如下：

![](../Images/4a68f9e8d9fabbb879ee85c8a3275549.png)

  

我们也可以安装中文语料包，然后就会输出中文内容了。

  

*   
*   

```
sudo apt install fortunes-zh -yfortune
```

  

运行效果如下：

![](../Images/361336ef02320f0721573a181e8ebf26.png)
