经常有同学会将前端框架和 UI 框架混淆了，前端框架通常是作为一套解决方案存在，涉及到前端的方方面面，如前端工程化、模块化、组件化等。



而前端 UI 框架则更为局限和具体一些，它通常是局限于某一框架而做的框架，例如 ElementUI 最早开发的目的是服务于 Vue 框架的。


用简单的比喻来说，前端框架就像 PPT ，它提供了做 PPT 用到的操作、功能等，你可以在设定好的规范下自由完成 PPT 的设计。而 UI 框架则相当于为你提供现成的 PPT 样式模板，它能简化我们的开发。


前端 UI 框架不同于前端框架，它的发展总是配合前端框架的发展，甚至会滞后发展。然而，不得不承认的是前端 UI 框架在前端发展史上扮演着重要的角色。


现在，我们总结了几款目前市场上主流的前端 UI 框架：



其中，左侧部分是移动端的前端 UI 框架，右侧部分则更多是用在 PC 端方面的前端 UI 框架。


Material-UI

目前它是最流行的 React UI 框架，遵循了谷歌的 Material Design 设计规范设计而成。目前，国内使用这个框架的大多是外企。



AntDesign

AntDesign 来自蚂蚁金服体验技术部，是一套类似于 Material Design 的 UI 设计体系。目前，主要是基于 React 进行设计的 UI 框架，面向的是 React 开发者。


Element-UI

ElementUI 是一款桌面端组件库，主要是基于 Vue2.x 版本。它是一款流行且经典的 Vue2.x 组件库，在 Vue 还未迈入 3.x 版本的时期，绝大多数开发者都是基于 ElementUI 进行 UI 组件的开发。



Vuetify

Vuetify 的诞生很传奇，它是由一名热爱编程的美军士兵退役后创作出来的。目前， Vuetify 是一个开源的 MIT 项目，它受到众多赞助商以及 Vue 社区志愿者们的支持。同时，它遵循谷歌 Material Design 规范。

这一次着重要讲的内容是 ElementUI。


它目前提供的组件主要分成 6 大类，分别是基础组件、表单组件、数据组件、提示组件、导航组件和其他类型组件。


作为 UI 组件库，提供这些丰富的组件已经能够基本覆盖大部分桌面端业务的开发需求。同时，倘若提供的组件无法满足需求，它还能进行扩展，进行二次开发，帮助开发者节约时间。



ElementUI 是一套设计组件，而 Vue 是用于构建 Web 界面的 Javascript 库，他们两者常常搭配使用。当然，配合使用的前提是 ElementUI 支持 Vue。


在介绍它们两者之间的联系之前，我们要先把 MVVM 这个概念弄明白。


MVVM 是一种架构模式，它由 Model， View 以及 ViewModel 三部分组成。其中：


  • Model 代表数据模型，你可以在 Model 中定义数据修改和操作的业务逻辑；

  • View 代表 UI 组件，它负责将数据模型转化成 UI，就是我们常说的 HTML 展现出来；

  • ViewModel 是一个同步 View 和 Model 的对象。
