**Step 1：安装依赖模块**

安装 Python 的开发库 `python3-dev` 和 `python3-setuptools` 。

```


$ sudo apt-get update![](../Images/09874d453ba91a8c548d38f114c0533d.png "copy")
```

安装 Pillow 依赖包。

```

$ sudo apt-get install libtiff5-dev libjpeg8-dev zlib1g-dev libfreetype6-dev liblcms2-dev libwebp-dev tcl8.6-dev tk8.6-dev python-tk![](../Images/09874d453ba91a8c548d38f114c0533d.png "copy")
```

最后安装 Pillow 。

```

$ sudo pip3 install Pillow![](../Images/09874d453ba91a8c548d38f114c0533d.png "copy")
```

安装 docopt 。

```

$ sudo pip3 install docopt![](../Images/09874d453ba91a8c548d38f114c0533d.png "copy")
```

> 补充：docopt 是 Python 的一个第三方参数解析库，可以根据使用者提供的文档描述自动生成解析器。因此使用者可以用它来定义交互参数与解析参数。  
> 参考：http://docopt.org/
