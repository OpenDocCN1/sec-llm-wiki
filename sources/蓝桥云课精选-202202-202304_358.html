cal 命令


cal 命令可以打印输出日历，Ubuntu 环境中已经预装，我们可以直接使用。


默认会打印当前月份的月份历

也可以指定月份和年份，注意月份在前，年份在后。

fortune 命令


Fortune Cookie，是一种元宝状的甜脆点心，空心内通常会藏着印有祝福或哲理的纸条，是美国中餐厅的一种餐后甜点。



在 Linux 中，我们可以通过简单的安装 fortune 命令来打印输出这种语句。


sudo apt install fortune -yfortune

cowsay 命令


cowsay 命令可以让一个小牛说一些话，首先也需要安装它。


sudo apt install cowsay -y


安装之后就可以使用了，这个命令对英文支持比较好，中文内容稍微有点问题。


cowsay hellocowsay hello world

我们也可以和之前的 fortune 命令通过管道符实现特殊的效果。
