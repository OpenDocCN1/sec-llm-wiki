那 Vue 3 相比 Vue 2 有什么区别呢？



  • 更快：初始渲染，更新速度提速一倍；

  • 类型更友好：完美拥抱 TypeScript；

  • 更小：Tree-shaking 友好；

  • 更好的警告信息；

  • 更好的 API 特性等等。
