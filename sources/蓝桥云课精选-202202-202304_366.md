那 Vue 3 相比 Vue 2 有什么区别呢？

  

![](../Images/92a712afaa39a6717d347eb931eb911e.png)

  

*   **更快**：初始渲染，更新速度提速一倍；
    
*   类型**更友好**：完美拥抱 TypeScript；
    
*   **更小**：Tree-shaking 友好；
    
*   **更好的警告信息**；
    
*   **更好的 API 特性**等等。
