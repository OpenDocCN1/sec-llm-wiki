Java 是编译型语言，在 Java 这门语言体系当中，最基础的部分就是 Java SE 部分，Java 的标准版本。

  

它包括** Java 最基础**的一些结构，包括面向对象的一些特性等等，同时它也是 Java 技术**基础和核心**。

  

在 Java SE 的基础之上，又分为了 Java EE（Java 的企业版），应用于大型企业级应用的开发。Java ME 主要用于嵌入式开发。

  

![](../Images/61f99aa654b68e3f25f407549e079956.png)

  

至于编程的学习方法——**边学边敲代码**，我想不用我多说了吧！

**0**1******Java 就业前景**

  

近几年，互联网热凶猛袭来，很多创业公司、小团队都进入了市场。市场对 Java、Web 等的需求量也越来越大，但现在**人才发展跟不上市场发展需求**。

  

正因为这样，优秀的 Java 开发人员开出的工资也越来越高，岗位也越来越多。当然，职级的提升不仅需要工作年限、工作经验，还要将自身的开发能力**与时俱进**。

  

![](../Images/270e68713d883d0918cf12d8fc48947a.png)

  

如果想要成为企业的中级管理层（如项目经理、总监等）或者企业 CTO ，那就要在加强技能的同时，具备良好的管理开发团队的能力、沟通能力等，这样才能带着团队，甚至是公司走向更好地发展。

  

Java 就业前景虽好，但掌握**核心的 Java 技能和项目经验**才是王道![](../Images/f87337ffe76b6bcee2aa2f04d798990b.png)！
