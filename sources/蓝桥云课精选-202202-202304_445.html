计算机二级 Python 考试大纲


在备考前，大家必须要熟悉计算机二级 Python 的考试大纲。只有了解清楚考试的内容和要求等，才更有把握拿到证书。


计算机二级 Python 的定位为程序员，考核的内容包括公共基础知识和程序设计。程序设计部分，主要考察对程序设计语言使用和编程调试等基本能力。


开头所说，计算机二级 Python 考试内容比较简单，但我还是建议大家切忌裸考！！而且计算机二级每年全国通过率在 30% 左右，如果不积极地提前备考，还是有很大几率会落榜。



考试题型

  • 单项选择题，40 题，40 分（含公共基础知识部分 10 分）；

  • 基本操作题，3 题，15 分；

  • 简单应用题，2 题，25 分；

  • 综合应用题，1 题，20 分。


基本要求

  • 掌握 Python 语言的基本语法规则；

  • 掌握不少于 2 个基本的 Python 标准库；

  • 掌握不少于 2 个 Python 第三方库，掌握获取并安装第三方库的方法；

  • 能够阅读和分析 Python 程序；

  • 熟练使用 IDLE 开发怀旧，能够将脚本程序转变为可执行程序；

  • 了解 Python 计算生态在以下方面（不限于）的主要第三方库名称：网络爬虫、数据分析、数据可视化、机器学习、Web 开发等。
