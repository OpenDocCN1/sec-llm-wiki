最近，我经常在后台看到有人问：零基础学 Python 有什么建议？怎么自学 Python？Python 课程推荐？……



今天，我就来分享一下我的经验总结！


Python 目前的应用领域比较广泛，目前 Python 的主要方向分为：后端开发、数据分析、网络爬虫、机器学习等。


为了不浪费时间，我们在开始学习之前，需要明确自己的学习目标，问问自己为什么要学习 Python？使用 Python 做什么？将所有精力集中在自己想要完成的事情上。



你是想要做一个自己的网站？写一个适合的工具？还是能够通过学校的考试就行？这些需求，都会影响学习 Python 的方法。


如果想做一个网站，你可以去学习 PHP，或者直接套网上的网站模板；如果想写一个工具，提高工作效率、提升职场竞争力等，你就一定要知道 Python 的优势；如果只想应付学校考试，你就必须将老师所讲的考试重难点熟练掌握。


明确好自己的学习目标后，我们就需要制定符合自己需求的学习计划。


这里，我整理了一个 Python 后端工程师学习路线，供大家参考。想要高清图，可以戳文末二维码领取哦~



最后，我们就必须按照自己制定的学习计划，坚持不懈地去学习，千万不能中途放弃！！


其实，学习 Python 并不难，Python 诞生之初就被誉为 “最容易上手的编程语言”，现在甚至进入了小学教材和会考科目。




但很多的 Python 教程和书籍，都是这样教 Python 的：先从 Python 的发展历史开始，介绍 Python 的基本语法、数据结构，然后再介绍字符串处理和正则表达式，介绍文件等 IO 操作，一章一章地讲下去。


虽然这样的讲解很全面，但是单纯的理论说明经常很枯燥，让人越看越累，越累越不想看。



还有，Python上手轻松，精通却很难。Python 将底层核心封装起来，屏蔽了很多底层细节，比如自动管理内存、线程和协程等等。


如果想成为一名高级 Python 工程师，了解这些底层核心知识是非常必要的。
