在 2022 年初，蓝桥云课进行了 2021 年度作者的评选，也将 2021 年度新上线的课程进行了总结评价。


为了让大家体验到更优质的课程，我整理了这 5 门年度优质编程课程，小心错过财富自由的大好机会（文末附超大福利，更有机会抽取免费学~）


01
Oeasy 教你玩转 Python

简明易懂的 Python3 课程，从零开始，在 Linux 环境中使用 Vim，一步步带你玩转脚本语言 Python，感受编程的乐趣。



此课程联合 B 站百万 UP 主 Oeasy 上线，共计 165 个章节实验。


课程内容以幽默风趣的大白话，并以举例、实验的形式帮助大家更好地理解 Python3，适合零基础入门。

02
从零入门 React 通关指北


本门课程将带你从 0 入门 React 开发，包括函数组件与 class 组件的使用、Hooks 系统基础、以及在实际开发过程中常用的第三方库和丰富的项目实例。



本课程将以项目实践的方式由浅入深带大家掌握最新版 React 17 的使用方法与相关生态。


在 React 基础讲解阶段，将选择【冰淇淋口味选择工具】作为基础项目贯穿，并通过不断学习，逐步进行项目的改造，从最初使用函数组件实现如下效果，到后期使用 class 组件进行实现。



课程链接

http://www.lanqiao.cn/course/4150


适合人群

  • 在职人群：刚刚接触 React ，想要快速熟悉 React 开发及相关生态；

  • 在校学生：对前端开发有兴趣的。


03
从源码带你上手 Vue 3


此课程从源码的角度一探前端必须框架 Vue 3，掌握 Vue 3 源码后具有实战开发能力，轻松搞定开发任务与面试。



这门课不仅仅是实战课程，更重要的是教大家看源码的方法，培养看源码的习惯，深入研究技术。


理解了源码后，将教大家从 0 搭建 Vue 3 项目，接着带大家做一个企业级的实战项目。用理论+实践的方法， 16 个实验带大家玩转 Vue 3，给大家不一样的学习体验。



课程链接

http://www.lanqiao.cn/course/3425


适合人群

  • 在职人群：前端初级工程师；

  • 在校学生：有 Vue 2 基础。


04
从传统算法到深度学习：目标检测入门实战


本课程将会从传统的目标检测算法开始讲解，逐步过渡到基于深度学习的检测算法。


其中课程中将会详细讲解目标检测中常用的一些方法以及如何训练自己的目标检测网络模型，同时还将讲解一些处理数据集的基本方法。



目标检测的发展可以分为两个阶段：传统检测算法和基于深度学习的检测算法。



课程链接

http://www.lanqiao.cn/course/3096


适合人群

  • 了解基本的 Python 语法；

  • 了解简单的 OpenCV 知识。


05
Linux 运维从入门到进阶


本课程将会结合作者 5 年 Linux 运维架构师经验，除了能让你了解 Linux 基础、Linux 命令格式等基础的入门知识，还会涉及一些复杂的工具，例如 vsftp，systemctl，samba 工具等。



这门课程主要通过以实际动手操作为主、理论为辅的教学方式。课程中有着大量的案例和教程，能够在学习过程中体验到真正的线上环境。



课程链接

http://www.lanqiao.cn/course/4838


适合人群

  • 熟悉 Linux，希望进一步学习系统相关内容配置。
