**02****从零入门 React 通关指北**

  

本门课程将带你**从 0 入门 React 开发**，包括函数组件与 class 组件的使用、Hooks 系统基础、以及在实际开发过程中常用的第三方库和丰富的项目实例。

  

![](../Images/e3dbb3882c34ca37f9f29bc1c52cb60a.png)

  

本课程将以**项目实践**的方式由浅入深带大家掌握最新版 React 17 的使用方法与相关生态。

  

在 React 基础讲解阶段，将选择**【冰淇淋口味选择工具】**作为基础项目贯穿，并通过不断学习，逐步进行项目的改造，从最初使用函数组件实现如下效果，到后期使用 class 组件进行实现。

  

![](../Images/ce944f85b0ade0487738e79297b2b3a5.png)

  

**课程链接**

http://www.lanqiao.cn/course/4150

  

**适合人群**

*   在职人群：刚刚接触 React ，想要快速熟悉 React 开发及相关生态；
    
*   在校学生：对前端开发有兴趣的。
    

  

**03****从源码带你上手 Vue 3**

  

此课程从**源码的角度**一探前端必须框架 Vue 3，掌握 Vue 3 源码后具有实战开发能力，轻松搞定开发任务与面试。  

  

![](../Images/e6943f9ced654b6d57d5bc62d5b9b417.png)

  

这门课不仅仅是实战课程，更重要的是教大家看源码的方法，培养看源码的习惯，深入研究技术。

  

理解了源码后，将教大家**从 0 搭建 Vue 3 项目**，接着带大家做一个企业级的实战项目。用理论+实践的方法，** 16 个实验**带大家玩转 Vue 3，给大家不一样的学习体验。

  

![](../Images/d4d165eca7d15c8d264af1efe2bfda6d.png)

  

**课程链接**

http://www.lanqiao.cn/course/3425

  

**适合人群**

*   在职人群：前端初级工程师；
    
*   在校学生：有 Vue 2 基础。
    

  

**04****从传统算法到深度学习：目标检测入门实战**

  

本课程将会从传统的目标检测算法开始讲解，逐步过渡到基于深度学习的检测算法。

  

其中课程中将会详细讲解**目标检测**中常用的一些方法以及如何训练自己的目标检测网络模型，同时还将讲解一些处理数据集的基本方法。

  

![](../Images/2104c60e908be4d9be259531dfb24148.png)

  

目标检测的发展可以分为**两个阶段**：传统检测算法和基于深度学习的检测算法。  

  

![](../Images/38619f2dd0bd8c196df029cfde2251bf.png)

  

**课程链接**

http://www.lanqiao.cn/course/3096

  

**适合人群**

*   了解基本的 Python 语法；
    
*   了解简单的 OpenCV 知识。  
    

  

**05****Linux 运维从入门到进阶**

  

本课程将会结合作者 **5 年 Linux 运维架构师经验**，除了能让你了解 Linux 基础、Linux 命令格式等基础的入门知识，还会涉及一些复杂的工具，例如 vsftp，systemctl，samba 工具等。

  

![](../Images/7f8c1ac9d0e3a6255c8ed9cbf9b6cf7d.png)

  

这门课程主要通过**以实际动手操作为主、理论为辅**的教学方式。课程中有着**大量的案例和教程**，能够在学习过程中体验到真正的线上环境。

  

![](../Images/8c6869e53b23378769f0e2a351948c17.png)

  

**课程链接**

http://www.lanqiao.cn/course/4838

  

**适合人群**
