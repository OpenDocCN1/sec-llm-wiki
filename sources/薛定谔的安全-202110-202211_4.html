Spring Framework/CVE-2022-22965

漏洞公告

Spring Framework存在远程代码执行漏洞（CVE-2022-22965），在 JDK 9 及以上版本环境下，远程攻击者可利用该漏洞写入恶意代码导致远程代码执行漏洞。

官方链接：https://spring.io/blog/2022/03/31/spring-framework-rce-early-announcement

漏洞ID: CVE-2022-22965/CNVD-2022-23942/QVD-2022-1691

复现环境

docker pull vulfocus/spring-core-rce-2022-03-29
docker run -dit -p 8080:8080 vulfocus/spring-core-rce-2022-03-29
python3 cve-2022-22965.py -u https://example.com/
python3 cve-2022-22965.py -f file.txt


漏洞利用

python3 cve-2022-22965.py -u http://example.com/


在第77行添加常见的路径

path = ['root',]

注意:

  • 此POC将不成功的http请求一起写入一个文件
  • 此POC会更改tomcat日志配置


漏洞修复

针对Spring RCE漏洞的WAF策略"class"关键字存在绕过风险，目前官方已发布spring-boot-2-2-6补丁


https://spring.io/blog/2022/03/31/spring-boot-2-6-6-available-now


检测脚本获取,公众号回复cve-2022-22965
