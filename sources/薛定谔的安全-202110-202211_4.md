Spring Framework/CVE-2022-22965

### 漏洞公告

Spring Framework存在远程代码执行漏洞（CVE-2022-22965），在 JDK 9 及以上版本环境下，远程攻击者可利用该漏洞写入恶意代码导致远程代码执行漏洞。

官方链接：https://spring.io/blog/2022/03/31/spring-framework-rce-early-announcement

漏洞ID: CVE-2022-22965/CNVD-2022-23942/QVD-2022-1691

### 复现环境

```


docker pull vulfocus/spring-core-rce-2022-03-29
```
