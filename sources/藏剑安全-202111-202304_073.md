### 过程

##### 在带有验证登录的地方，选择验证码，单独访问验证码地址，burp抓包，然后发送到captcha

![](../Images/076be196620ebb72bd728f60011beea5.png)

##### 点击获取

![](../Images/385d616e4f807a29d84655857ccccd74.png)

#### 接下来进行接口配置

```


接口配置分为两种:
```

#### 付费版

```

官方都有接口，复制接口。
```

##### 数据包如下

```


POST /base64 HTTP/1.1
```

#### 白嫖版

##### 毕竟都喜欢白嫖，上述没有太多的描述。

```


这里选择了本地进行模型训练。
```

![](../Images/1173c31aa47afb03bde406c184473c3b.png)

##### POST数据包修改host为自己本地即可

```


POST /api HTTP/1.1
```
