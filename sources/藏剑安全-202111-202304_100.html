简介

  • Shell 是一个用 C 语言编写的程序，它是用户使用 Linux 的桥梁。Shell 既是一种命令语言，又是一种程序设计语言。
  • Shell 是指一种应用程序，这个应用程序提供了一个界面，用户通过这个界面访问操作系统内核的服务。
  • 本文出现的 "shell编程" 都是指 shell 脚本编程，不是指开发 shell 自身
  • 本文使用的是 Bash，也就是 Bourne Again Shell（/bin/bash），由于易用和免费，Bash 在日常工作中被广泛使用。同时，Bash 也是大多数Linux 系统默认的 Shell

shell脚本的创建

shell脚本的扩展名为.sh（sh代表shell）（其实php什么的也可以写shell脚本，如果用php之类的语言写就用php当扩展名），可以用vi/vim/nano/touch等命令来创建文件

第一个shell脚本

#!/bin/bash
echo "hello world"

#! 是一个约定的标记，它告诉系统这个脚本需要什么解释器来执行，即使用哪一种 Shell。

echo 命令用于向窗口输出文本。

shell脚本的运行

  • 把脚本当成可执行程序
chmod +x ./test.sh  #使脚本具有执行权限
./test.sh  #执行脚本

注意，一定要写成 ./test.sh，而不是 test.sh，运行其它二进制的程序也一样，直接写 test.sh，linux 系统会去 PATH 里寻找有没有叫 test.sh 的（就像Windows命令行一样，只有把它配到环境变量里面才能直接使用），所以写成 test.sh 是会找不到命令的，要用  ./test.sh 告诉系统说，就在当前目录找（就像Windows在某个文件夹下打开命令行一样）。

  • 也可以把脚本作为解释器的参数，这种运行方式是，直接运行解释器，其参数就是 shell 脚本的文件名

这种方式运行的脚本，就没有必要在第一行指定解释器信息了，写了也不会生效。

输出命令

echo

echo "hello world" #显示字符串
echo helloworld #这里的双引号可以省略（但一般建议加上）
echo "\"hello world\"" #显示转义字符
echo -e "hello \n" #-e开启转义
echo -e "hello \c" #-e开启转义 \c不换行
echo "hello world"

printf

  • printf 命令模仿 C 程序库（library）里的 printf() 程序，所以用起来和printf很像。
  • printf 由 POSIX 标准所定义，因此使用 printf 的脚本比使用 echo 移植性好。
  • printf 使用引用文本或空格分隔的参数，外面可以在 printf 中使用格式化字符串，还可以制定字符串的宽度、左右对齐方式等。默认的 printf 不会像 echo 自动添加换行符，我们可以手动添加 \n。
printf "hello world\n"
printf "%d\n" 100 #%d整型输出
printf "%f\n" 100.001 #%f输出实数，以小数形式输出
printf "%s\n" 你好 #%s输出一个字符串
printf "%c\n" a #%c输出一个字符
printf "%-10s\n" yumu # 指一个宽度为 10 个字符（- 表示左对齐，没有则表示右对齐），任何字符都会被显示在 10 个字符宽的字符内，如果不足则自动以空格填充，超过也会将内容全部显示出来。
printf "%10s\n" yumu
printf "%.2f\n" 123.456 # .2 指保留2位小数

变量

变量定义

变量名规则

  • 命名只能使用英文字母，数字和下划线，首个字符不能以数字开头。
  • 中间不能有空格，可以使用下划线 _。
  • 不能使用标点符号。
  • 不能使用bash里的关键字（可用help命令查看保留关键字）。

注意，变量名和等号之间不能有空格，这和其他的编程语言不太一样

只读变量

使用 readonly 命令可以将变量定义为只读变量，只读变量的值不能被改变。

变量类型

  • 局部变量局部变量在脚本或命令中定义，仅在当前shell实例中有效，其他shell启动的程序不能访问局部变量。
  • 环境变量 所有的程序，包括shell启动的程序，都能访问环境变量，有些程序需要环境变量来保证其正常运行。必要的时候shell脚本也可以定义环境变量。
  • shell变量 shell变量是由shell程序设置的特殊变量。shell变量中有一部分是环境变量，有一部分是局部变量，这些变量保证了shell的正常运行

变量使用

使用一个定义过的变量，只要在变量名前面加美元符号$即可，变量名外面的花括号是可选的，加不加都行，加花括号是为了帮助解释器识别变量的边界。使用 unset 命令可以删除变量但不能删除只读变量。

实例

your_name1="Mack" #定义变量
echo $your_name1 #使用变量
echo ${your_name1}
echo "i am $your_name1hello" #这里不给变量加上花括号，解释器会把$your_name1hello当成一个变量，然后这里就会输出null，代码执行结果就不是我们期望的样子了
echo "i am ${your_name1}hello" #这样写就可以避免误会，推荐给所有变量加上花括号
myUncle="John"
echo $myUncle
readonly myUncle #将变量定义为只读变量
myUncle="Jack" # 尝试修改变量的值会报错
echo $myUncle #这个时候还是会输出John
unset your_name1 #删除变量
echo $your_name1 #这样输出会输出null

字符串可以用单引号，也可以用双引号，也可以不用引号。

单引号字符串的限制：

  • 单引号里的任何字符都会原样输出，单引号字符串中的变量是无效的；
  • 单引号字串中不能出现单独一个的单引号（对单引号使用转义符后也不行），但可成对出现，作为字符串拼接使用。

双引号的优点：

  • 双引号里可以有变量
  • 双引号里可以出现转义字符

传递参数

  • 我们可以在执行 Shell 脚本时，向脚本传递参数，脚本内获取参数的格式为：**$n。n** 代表一个数字，1 为执行脚本的第一个参数，2 为执行脚本的第二个参数，以此类推
  • $0 为执行的文件名（脚本的名字）（包含文件路径）

其他的几个特殊的处理字符的参数
$#传递到脚本的参数个数
$*以一个单字符串显示所有向脚本传递的参数。 如"1 n"的形式输出所有参数。
$$脚本运行的当前进程ID号
$!后台运行的最后一个进程的ID号
$@与*相同，但是使用时加引号，并在引号中返回每个参数。如"@"用「''」括起来的情况、以"$1""2”..."n"的形式输出所有参数。
$-显示Shell使用的当前选项，与set命令相同
$?显示最后命令的退出状态。0表示没有错误，其他任何值表明有错误。

实例

echo $1
echo $2
echo $0
echo $#
echo $*
for i in "$*";do
 echo $i
done
for j in "$@";do
 echo $j
done #为了对比$*和$@的区别
echo $$

注释

  • 以 # 开头的行就是注释，会被解释器忽略。
  • 通过每一行加一个 # 号设置多行注释，如果遇到大段代码需要注释，一行行打#大麻烦，可以考虑把这段代码用花括号括起来，定义成一个函数，反正不调用这个函数就不会执行这段代码，这就起到了和注释一样的作用

运算符

  • 原生bash不支持简单的数学运算，但是可以通过其他命令来实现，例如 awk 和 expr，expr 最常用。
  • expr 是一款表达式计算工具，使用它能完成表达式的求值操作。

算术运算符

使用expr工具进行常规的四则运算以及取模运算

a=100
b=200

res=`expr $a + $b`
echo $res

res=`expr $a - $b`
echo $res

res=`expr $a \* $b`
echo $res

res=`expr $a / $b`
echo $res

res=`expr $a % $b`
echo $res
  • 表达式和运算符之间要有空格
  • 表达式需要用反引号扩起来
  • 乘号*需要用\转义

关系运算符

  • -eq (equal) 检测两个数是否相等
  • -ne （not equal）检测两个数是否不相等
  • -gt （greater than）检测左边的数是否大于右边的
  • -lt （less than） 检测左边的数是否小于右边的
  • -ge （greater than or equal） 检测左边的数是否大于等于右边的
  • -le （less than or equal）检测左边的数是否小于等于右边的
a=100
b=200

if [ $a -eq $b ]
then
        echo "a等于b"
else
        echo "a不等于b"
fi

if [ $a -ne $b ]
then
        echo "a不等于b"
else
        echo "a等于b"
fi

if [ $a -gt $b ]
then
        echo "a大于b"
else
        echo "a不大于b"
fi

if [ $a -lt $b ]
then
        echo "a小于b"
else
        echo "a不小于b"
fi

if [ $a -ge $b ]
then
        echo "a大于等于b"
else
        echo "a不大于等于b"
fi

if [ $a -le $b ]
then
        echo "a小于等于b"
else
        echo "a不小于等于b"
fi

表达式需要用[]括起来

逻辑运算符

  • && 逻辑AND
  • || 逻辑OR
a=100
b=200
c=300
d=400

if [[ $a -gt $b && $d -gt $c ]]
then
        echo "a大于b且d大于c"
else
        echo "a大于b且d大于c不成立"
fi

if [[ $a -gt $b || $d -gt $c ]]
then
        echo "a大于b或d大于c"
else
        echo "a大于b或d大于c不成立"
fi

这里的表达式需要用两个中括号括起来

流程控制

if

shell编程时流程控制不可为空，如

if /条件/{

/内容/

}

else{

/这里为空是不可以的，如果else里面没有东西就不要写/

}

a=100
b=200
c=300
d=400

if [ $a -gt 300 ]
then
        echo "a"
elif [ $b -gt 300 ]
then
        echo "b"
elif [ $c -gt 300 ]
then
        echo "c"
else
        echo "d"
fi

if判断的末尾要写上fi

if 和 elif 的后面要跟then

for

for a in 1 2 3 4 5
do
        echo "a is $a"
done

有点python里面用for循环来输出迭代器的感觉了

do的后面要用done来结尾

while

a=1
while([ $a -le 5 ])
do
        echo "a is $a"
        let "a++"
done

let 命令是 BASH 中用于计算的工具，用于执行一个或多个表达式，变量计算中不需要加上 $ 来表示变量。如果表达式中包含了空格或其他特殊字符，则必须引起来。

break和continue

break用于跳出循环，continue用于跳出当前循环，立即进入下一次循环

while :
do
read a
if [ $a -gt 5 ]
then
        echo "a大于5,循环继续"
        continue
else
        echo "a不大于5，循环结束"
        break
fi
echo "这句话是不会被输出的"
done

while : 等价于while true 即无限循环

read用于读取输入的值

函数

可以用function fun() 来定义函数，也可以直接fun()来定义，用$n的形式来获取函数参数

function fun1(){
echo "i am fun1"
}

fun2(){
echo "i am fun2"
}

fun3(){
echo "第一个参数是 $1 "
echo "第二个参数是 $2 "
echo "第十个参数是 ${10} "
echo "参数的数目是 $# "
echo "所有参数为: $* "
}

fun1
fun2
fun3 1 2 3 4 5 6 7 8 9 00 312 243

当n>=10 时需要通过${n}的形式来获取参数
