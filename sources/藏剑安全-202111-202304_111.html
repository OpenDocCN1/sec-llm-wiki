python爬虫学习

-网易云音乐爬虫

思路

在之前某一次下歌中，发现使用网易云音乐客户端下载的歌曲，很多都是加密了的，不能用其他播放器播放，这让需要mp3格式的我很是头疼，所以就萌生了用爬虫去爬的想法，但是一开始使用爬虫去直接爬取网易云音乐热歌榜的源码，居然一直匹配不到我想要的内容。然后就去github上看了下大佬们的源码，最终完成了这个爬虫。

首先我们打开网易云音乐的热歌榜，他的url是

https://music.163.com/#/discover/toplist?id=3778678

而我们如果直接去使用这个url作为爬虫的url，那么我们是找不到任何我们我们需要的信息的，而我们使用爬虫想要获取歌单的信息时，需要去访问

https://music.163.com/discover/toplist?id=3778678

才能得到我们想要的歌曲id，名称等。

然后尝试删了些head中的内容，发现依旧能正常访问

好了，现在我们可以通过这样的方式，将我们的热歌榜的歌曲id及名称都爬取下来了。然后就是如何下载的问题。

网易云其实还是提供了一个接口供我们通过歌曲的id对歌曲进行下载的

http://music.163.com/song/media/outer/url?id=

那么我们只需要利用这个接口获取歌曲的内容，再将其写入到文件中就代表我们下载完成了。

代码

首先我们在主函数中，根据用户输入的内容，获取我们的url和文件的存储路径，这里需要注意的是，在获取用户输入的url的同时，我使用replace函数将url中的#/删除掉，让其以正确的可以获取信息的url在后面直接传入我们的参数。然后首先判断用户输入的路径或我们的默认路径存不存在，如果不存在则创建文件夹，然后首先使用get_music_data函数获取歌单的列表，然后再使用get函数将获取到的歌曲列表中的歌曲存入到用户输入的路径中去。

def main():
    url = ''
    output_path = './music'

    poc_head()

    try:
        opts, args = getopt.getopt(sys.argv[1:], 
        "hu:o:",
        ["help","url=","output="])
    except getopt.GetoptError as err:
        print(str(err))
        my_help()

    # 从opts中读取数据，o为参数,a为参数后带的值
    for o,a in opts:
        if o in ['-h','--help']:            
            my_help()
            return
        elif o in ['-u','--url']:
            url = a.replace("#/","")
        elif o in ['-o','--output']:
            output_path = a
    
    if not os.path.exists(output_path):
        os.makedirs(output_path)
    music_list = get_music_data(url)
    print('[+] 歌单获取成功！共计',len(music_list),'首歌曲！')
    get(music_list,output_path)

然后就是get_music_data函数，在这个函数中，我们利用breautifulSoup库，首先找到class名称为f-hide的ul标签，然后找到其中所有的a标签。这些a标签中的内容就是歌曲名称，href中的属性就是歌曲的id。

然后将href属性中的id值提取出来，与名称组成一个字典存入列表中，最后将这列表返回。

def get_music_data(url):
    """
        用于获取歌曲列表中的歌曲信息
    """
    headers = {'User-Agent':user_agent}
    webData = requests.get(url,headers=headers).text
    soup = BeautifulSoup(webData,'lxml')
    find_list = soup.find('ul',class_="f-hide").find_all('a')

    tempArr = []
    for a in find_list:
        music_id  = a['href'].replace('/song?id=','')
        music_name = a.text
        tempArr.append({'id':music_id,'name':music_name})
    return tempArr

然后在这里，首先提出歌曲名称中可能出现的一些影响名称的字符，然后去目标目录判断下这个文件是否存在，如果不存在，则将id加入到网易云的接口url中，使用save_file函数对其进行下载，如果报错则将其名称存入报错日志文件中。而我们获取的歌曲是二进制形式的数据，所以在save_file函数中我们要以wb的方式进行写入。

def get(values,output_path):
    """
        用于下载歌曲
    """
    downNum    = 0
    rstr = r"[\/\\\:\*\?\"\<\>\|]"  # '/ \ : * ? " < > |'
    for x in values:
        x['name'] = re.sub(rstr, "_", x['name'])# 替换字符串中的匹配项
        if not os.path.exists(output_path + os.sep + x['name'] + '.mp3'):
            print('[*] '+ x['name'] + '.mp3 Downloading...')
            url = 'http://music.163.com/song/media/outer/url?id=' + x['id'] + '.mp3'
            try: 
                save_file(url , output_path + os.sep  + x['name'] + '.mp3')
                downNum = downNum + 1
                print('[+] '+ x['name'] + '.mp3 Download complete !')
            except:
                print('[+] '+ x['name'] + '.mp3 Download error !')
                f = open('log_error.txt','a')
                f.write(x['name']+'\n')
                f.close()
    print('[+] Download complete ' + str(downNum) + ' files !')

def save_file(url,path):
    """
        用于保存歌曲文件
    """
    headers = {'User-Agent':user_agent,'Accept':'text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,image/apng,*/*;q=0.8','Upgrade-Insecure-Requests':'1'}
    response = requests.get(url,headers=headers)
    f = open(path, 'wb')
    f.write(response.content)
    f.flush()
