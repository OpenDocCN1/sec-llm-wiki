不知不觉，距离 [上一次两仪更新](http://mp.weixin.qq.com/s?__biz=MjM5Njg5ODU2NA==&mid=2257499651&idx=1&sn=0a547f3afdccb428afc9e6c27513081d&chksm=a598246892efad7edebaf935e0e3659f420f22538909ba270b37cc9cb6320a333595d9b6602d&scene=21#wechat_redirect) 已经过去半年多。可能有小伙子以为我弃坑了，其实并没有 :) 两仪涉及到 Android 系统的方方面面，维护它需要耗费巨大的时间和精力；有些 bug 一修就是个把月，而有的问题，可能永远也无法解决...  

不过，好消息是，在这几个月里，两仪还是有一些改进；比如说：

1.   GPU 直通做好了。之前使用两仪的时候，可能会觉得特别卡，帧率特别低，屏幕还可能会一闪一闪；这些跟显示系统相关的问题基本都解决了。而且，两仪内部也支持高刷新率了，实测 120Hz 没问题。
    
2.  支持了 OpenGL3。直观表现就是，之前有一些 App 内部打开 web 界面的时候，如果这个 App 是自带 webview 的，那么它大概率会打不开或者黑屏；这是因为它们使用的 webview 版本比较高，默认采用 OpenGL3 进行渲染。另外，OpenGL3 也改进了渲染的性能；总体来说，新版两仪的显示系统性能有了实打实的提升。
    
3.  支持了谷歌服务。如果你的真机无法使用 GMS，比如鸿蒙系统；那么你可以借助两仪，在两仪内部使用需要依赖 GMS 的 App。  
    
4.  修复了 WiFi 相关的问题。之前可能会出现 Wi-Fi 无法连接，或者两仪内部没有网络；现在这些情况应该不会再出现了。
    
5.  支持了移动网络。两仪内部完成了 SIM 卡的模拟，因此也可以显示移动网络相关信息了；依赖这些接口的 App 目前可以正常使用。
