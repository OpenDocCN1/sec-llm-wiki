顺便一提的是，距离 [两仪：新的开始](http://mp.weixin.qq.com/s?__biz=MjM5Njg5ODU2NA==&mid=2257499377&idx=1&sn=962efa80763126b16e2853b174c42e1a&chksm=a598269a92efaf8cfde56b5d4339a993a586ea0f878a8ec182354c91659d83e668c30a5303de&scene=21#wechat_redirect) 已经过去了两个多星期，在这两个星期里，我修复了不少问题，比如说：

  

*   实验性地支持了 ROOT。
    
*   大幅提升了 GPU 的稳定性。
    
*   支持了 split apk 的导入和安装。
    
*   修复了多语言切换、时区切换、开发者选项，屏幕解锁等等等各种 BUG。
    
*   使用 Rust 重写了 opengl 渲染端。
    

  

虽然离稳定还有较大的距离，特别是 GPU 方面还有很大的问题，不过比第一个版本已经好太多了；感兴趣的小伙伴们可以再次尝试一下。只需要在后台回复：两仪  即可。
