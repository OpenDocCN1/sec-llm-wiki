几天前，我的 MacBook 提示我系统有更新：  

  

![](../Images/0ad72e3898a0dac20b67fc7f7774f1f3.png)

  

我简单地去官网看了一下系统新特性，有几个功能还蛮喜欢的；不过在系统升级这方面，特别是主力开发机上，我一直是非常谨慎的；如果新系统某些编译工具链有问题，那个 Bug 查起来那真不是一般地费劲。

  

不过现在，我真正用本地编译工具的情况已经不多了，在处理 Android 系统相关的问题上，都是在服务器的 docker 上编译和修改代码，因此在经过一番思想斗争之后，我还是点了升级，毕竟我非常喜欢那个专注模式。

*   Alfred4
    
*   Sublime Text 4
    
*   Ghidra
    
*   010Editor
    
*   Dash
    
*   Charles
    
*   iTerm2
    
*   BetterZip
    
*   Sytax Hightlight
    
*   Beyond Compare
    
*   Clean My Mac
    
*   Rescure Time

*   Parallel Desktop 17
    
*   Yoink
    

  

另外，常见的 IDE 都可以正常使用，目前有几个软件有点小问题：  

  

*   微信：回到界面时，有时候会卡住，升级前没有出现。
    
*   IDA Pro 7.0 提示系统版本过低，未来可能无法使用；但实际使用貌似正常。
    
*   php 莫名其妙没有了；可能是 homebrew 的问题。
    

  

据某些朋友提醒，据说新系统兼容不了 Xcode 12，如果是 iOS 开发，一定谨慎升级！

  

**专注模式**  

  

新系统最吸引我的，就是它的专注模式，如果没有这个功能我可能会呆在 BigSur 很久。

  

专注力是一种非常非常重要的能力，在专注状态下我们可以进行深度思考和高效创作；我接触过很多优秀的人都非常擅长于专注和坚持。然而，在工作之后，保持专注状态其实是一件非常奢侈的事，我们经常会被各种各样的事情给打断；所以，每一个能帮助我保持专注的东西我都非常愿意去尝试。  

  

在见过一番鼓捣之后，我弄出了这么一个东西：

  

![](../Images/433ebdb3cf511705e7c3891990d12709.png)

  

它能实现的功能是：系统会我打开某些特定的软件（比如各种编程工具之后）自动进入某一种专注模式，在这种模式下，可以选择性地允许某些 App 发送通知，其他 App 的通知全部会被屏蔽；并且，如果你的手机是 iPhone，它还能给手机开启勿扰模式，白名单外的呼入来电会自动静音。

  

这个功能看起来不错，但是实际使用了两天之后，我发现还是有一些不爽的地方：

  

*   你的手机最好是 iPhone，否则它的功能会大打折扣！
    
*   打开 App 之后会立即进入专注模式，其实应该改为使用 App （不一定是同一个）持续若干分钟再进入此模式。否则我打开 IDE 写几行代码，退出 IDE 去打开浏览器，它就退出了；而我不希望打开浏览器的时候进入专注模式。
    
*   每次打开和进入系统会弹一个通知，但是这个通知目前貌似关不了（知道的告诉我大恩不言谢！）这就会导致你要是不停切换，它会不停弹通知，非常鸡肋！
    

  

如果这些问题能在后续更新中修复，这个模式可以极大地提升生产力；毕竟，程序员最反感的是自己在深入思考代码的时候被别人打断。  
  

**快速备忘录**  

  

备忘录其实也是一个很重要的功能，可惜之前的 macOS 不是很给力，我现在在用第三方的软件，已经形成用户习惯了；即使新系统做的再完善，已经很难再迁移回来了；看一下效果：  

  

![](../Images/ba970f738c2aa8a406fd02242043e029.png)

  

实际上就是有个可以快速呼出的悬浮窗，其他的地方并不完美；我只是简单地用了一下，有一些建议：  

  

*   自动归档；快速备忘录用途在于临时记事，但这种东西可能是有时效性的；写了之后应该能快速一键保存或者定期归档。
    
*   支持 Markdown 格式；无须多言。

**快捷指令和通用控制**

这一次更新，苹果把快捷指令移植到了  macOS 上；这个功能在 iPhone 和 iPad 上还是挺有用的；上次一位读者跟我分享了一个 ta 的 iPad 快捷指令：在断开电源时开启省电模式，在充电时关闭省电模式；这个功能简直太棒了，大大提升了 iPad 的续航，而且也不会发热。不过，我在使用了 macOS 的快捷指令之后，感觉目前还非常鸡肋。

  

为什么这么说呢？因为目前 macOS 能提供的指令很少，它能够实现的功能非常有限；与 iPhone、iPad 这种设备不同，在 mac 上，我们可以有更多更强大的方式实现类似功能；比如作为程序员我可以直接用 shell 或者 python 调用系统 API，或者 Alfred 的 workflow 也能实现此类功能。不过，我还是蛮看好这个功能的，对普通用户来说，相比写代码，快捷指令还是方便不少。

  

另外，Monterey 还宣称增强了一些通用控制的功能，特别是跨设备的能力；比如说，可以一套鼠标键盘在 iPad 和 mac 之间无缝使用，鼠标光标可以直接无缝拓展到其他设备；但是，这个功能目前还没有实装，过一段时间才能体验到。跨设备协作这一块其实华为走的更前面，不过我还是蛮期待苹果做出来的东西的。

**其他**

  

还有挺多更新内容，但大多数感知都不是很强烈；不过有两个功能我觉得值得一提：

  

*   低电量模式
    
*   Finder 增强
    

  

低电量模式可以让你在断电的时候续航时间更长，我没有实际测试过，据有的童鞋反馈，续航直接翻了一倍；如果再加上 M1 芯片的低功耗，那个续航时间估计是相当地夸张。

  

Finder 增强这个直接看图：

  

![](../Images/d7bb244f3afd87a4eca0c6428eb2e7bb.png)

  

虽然绝大多数时候用的是命令行，配合 autojump 和 starship 在目录间跳转已经非常自如了；但是之前一旦回到 Finder，cmd + shift + G 进入某个目录的时候，感觉是回到了原始社会：只有一个目录地址手动输入，不支持补全，也没有任何提示；现在，在 Finder 中跳转目录也比较舒服了。
