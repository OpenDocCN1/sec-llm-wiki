# 小米今天把我整崩溃了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njg5ODU2NA==&mid=2257499166&idx=1&sn=22b5e72503dd74d315021a382985e5f5&chksm=a598267592efaf633a072d3996dffd2593113a93b314c708ed01ce3b497495e0f4240d56e835&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njg5ODU2NA==&mid=2257499166&idx=1&sn=22b5e72503dd74d315021a382985e5f5&chksm=a598267592efaf633a072d3996dffd2593113a93b314c708ed01ce3b497495e0f4240d56e835&scene=27#wechat_redirect)

今天，我照常打开 Android Studio 打算写几行代码。  

  

正当我改好了打算把 App 装到手机上看看效果时，突然发现我常用的开发机没在身边；于是我习惯性地掏出了我的主力机小米11U，熟练地打开开发者选项和 USB 调试，插上 USB 线打算开始开发。

  

这时候，小米奇迹出现了。我的手机屏幕突然开始狂闪，不停滴弹 USB 调试的确认框，借用网友一句话那就是：“如果我把手机挂天花板上，就可以直接开始蹦迪了。”

*可能有童鞋不知道 USB 调试为何物，我简单解释一下：咱们手机里面那成千上万的 App 其实都是由各个开发者开发的，而 Android 系统为了方便开发者使用，提供了一个调试模式，在这种模式下，我们可以方便地进行调试工作，比如快速安装、查看日志等。*

最开始我发现调试模式启动不了的时候，我内心毫无波澜：俺什么大风大浪没见过，不就是个小小的调试模式，见怪不怪了，肯定是 USB 线没插好。于是我先是把线拔下来好好滴插了一下，结果不行，于是我就换成了手机自带的原装数据线，好家伙，还搁那闪！没事，小场面，我直接重启大法！！  

  

![](../Images/53e2d0b7ac6de828246e6b54b152ba67.png)

耐心等待手机重启完毕之后，我再次仔细地插上数据线，结果，问题依旧。这时候，场子有点兜不住了，我开始挨个尝试：  

  

1.  使用原装的双 type-c 数据线直接插 mac type-c 左边接口，失败。
    
2.  使用原装的双 type-c 数据线改插 mac 右边接口，失败。
    
3.  换其他红米手机带的数据线插拓展坞后面，失败。
    
4.  换其他红米手机带的数据线插拓展坞前面，失败。
    
5.  换小米无线充带的数据线分别挨个插拓展坞所有接口，失败。
    
6.  再重启一把手机，重复上述操作，失败。
    
7.  关闭 Android Studio，插上数据线操作，终于不闪了！于是我用命令行输入 adb devices，问题依旧。
    

  

这个时候，我已经开始慌了。因为我知道，我现在只剩最后一个杀手锏，那就是重启电脑。在操作这一步之前，我们想一下，数据线、电脑、手机，一定是这三者之一有问题，我们反复操作可以排除数据线的问题；那么，是电脑还是手机的问题呢？于是，我换了另外一台红米手机，结果，我电脑的任何一个接口配上任何一根数据线都不存在这个问题；几乎可以确定，是我这手机有毛病了。不过我心里还存在一丝希望，于是我重启了电脑。

  

电脑重启之后，小米11U 依然在那蹦迪，而红米确没任何问题；这时候我可以肯定，绝对是手机有问题。于是我录了个视频，生气地发到了 B 站。好家伙，这问题还不是个例！！

  

*PS. 我们的手机都是 MIUI 官方的稳定版系统，没有解锁、没有 root 更没有什么修改系统的比如 Xposed 模块等。*

我已经体验过了很多 MIUI 的bug 了，说实话之前那些 bug 问题都不是很大，顶多就是动画或者界面不对，再不济也能重启系统恢复；但是，今天这个 BUG 真是把我整崩溃了。调试模式用不了，意味着我没法拿这个手机做开发工作，从发现这个 Bug 到现在，已经过去了好几个小时，我一行代码也没有写成；更让人生气的是，我竟然在这种低级、弱智的问题上浪费了这么久。

  

从这问题，我想问一下@雷军，小米公司内部是否真的有人用小米手机？**如果你们连自己做的手机都不用，怎么做出让人激动人心的产品？**  

之前我看雷总在发布会上说它用小米 11U 玩原神，我不禁想“原来你也玩原神”。后来，在我用 MI11U 玩原神遇到各种 BUG 的时候，我不禁想，雷总可能只在发布会上玩了一把，**他要是自己经常用，这些 bug 不分分钟给修了？**

调试模式对开发者来说，是一个必不可少的功能；我可以这么说，但凡小米内部有工程师用我这手机的这版本系统加 mac 做开发调试，他一定会遇到这个问题，可惜的是，这 bug 依然被带到了线上。

  

我有一条谏言不知雷总能否听到：**强制小米集团所有员工必须使用小米手机**。如果这样，如果你们内网每天都被自己人骂垃圾 MIUI，我相信你们 MIUI 一定能做到世界第一。

  

好了下班回家吃饭，垃圾小米。
