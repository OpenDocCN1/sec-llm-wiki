昨天 Google 发布了 Android 11 的首个 beta 版。说实话，这个大版本没有什么吸引我的更新。很多系统上的改进在民间已经有了解决方案，甚至做的比官方更好。


比如说新增的一次性权限和后台位置权限，在国产某 UI 的权限管理面前，简直就是相形见绌。再比如说通知管理，且不说国产应用很可能都不理会你这个新的 API（对说的就是某信），女娲石和通知滤盒不知比官方做的好多少倍。还有什么无线调试，我的天 Android 都诞生十几个年头了，现在被官方支持；我简直无力吐槽。


其实，Android 11 最大的改动，是开始强制执行 Android 10 上定调的分区存储方案；总的来说我是非常看好这个特性的；如果没有分区存储，谈什么隐私都是扯淡。另外，Android 虚拟机也做出了一些改动，从 Android 10上允许 zygote 进行 jit 以来，Android 11上也对 jit 做出了一些调整；另外，jni 层面似乎可以支持对 method 执行 gc（未实现）；还有元反射方式绕过隐藏 API 被正式禁用，不过官方禁用的方式通过堆栈回溯，很容易被再次绕过，暂且不表。


太极阳一直在试验 ffi 的功能，这一次 Android 11 beta 版升级，已经可以通过动态生成代码的方式自动支持。不过由于虚拟机层面的一些小改动，app 还需要升级到 6.3.0 才可以在 Android 11 beta1 上正常使用。


另外，最近有一个小功能增加，那就是支持模块范围设置的导入和导出。618 临近，可能会有一些模块要开始作祟了。我强烈建议大家对模块设置一下生效范围，如果不知道如何使用，可以参考 关于太极的模块生效范围。要使用这个功能，需要升级到 6.2.0 以上的版本。需要最新版的话，在公众号后台回复 最新版 即可。


最后，祝大家周末愉快~
