最近有一台自用的闲置 MacBookPro 一直在吃灰，想想留着也没什么用，不如把它转手了。


这电脑是我刚毕业不久买的，它陪我度过了一千五百多个日日夜夜，迄今五年了；说实话我还挺舍不得的，过去这些年我用它学习了十几门编程语言，换过了好几家公司，辗转了好多个城市，去任何地方，只要带上它，我就可以开始工作。


对程序员来说，Mac 真的是一台省心的机器。整个系统流畅无比，类 Unix 系统配置起开发环境来格外容易，可以节省你无数的时间，让你专注于创造代码和解决问题。我曾在博客上专门发过文章，研究提升 Android Studio 的启动和编译速度的姿势，后来我发现，最好的办法是：换一台足够好的电脑，不要在这种东西上浪费时间。尤记得最初学 Java 的时候要装 IDE，那个环境变量配置的让人头大；后来我遇到了各种复杂的环境配置，macOS 从来都没有让我失望。如果过去的五年里我用的是 Windows 本，不知道要在环境配置、启动、编辑和编译上浪费多少时间（当然现在的 Windows 已经不可同日而语了）。


不过 Mac 什么都好，就是贵。当初买的时候，硬是花了我一个多月的工资。现在回想起来，这肯定是值得的。但是如果让我在读大学的时候去买，我肯定不敢想。因此如果你觉得买全新的 Mac 有点无法承受，又想体验 Mac 系统的便利，那不妨考虑一下我的这台旧 Mac，它的参数如下：


2015年中 MacBookPro

512G 固态硬盘

2.5 GHz Intel Core i7

16 GB 1600 MHz DDR3



到现在它依然很流畅，除了不充电的时候续航已经不到出厂时候的一半之外，其他场景没有任何问题；秒杀同类型的全新电脑不在话下。我尝试在苹果官网使用了旧物置换功能对这个电脑进行了估价：



当初应该是花了 1.8W 买的，现在的话官方估价是 4000；不过呢，我打算把价格再降200，3800 把这个电脑出了。有缘人可以在公众号我的微店中购买。

最后，祝大家节日快乐~
