# 重磅功能即将推出

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Njg5ODU2NA==&mid=2257498608&idx=1&sn=ebc98080dea39c26225a6738dcaff8d0&chksm=a598239b92efaa8d2be3bf82d825ca0ca07e3a1f8b3d44609703223e096fa61ab35964270539&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Njg5ODU2NA==&mid=2257498608&idx=1&sn=ebc98080dea39c26225a6738dcaff8d0&chksm=a598239b92efaa8d2be3bf82d825ca0ca07e3a1f8b3d44609703223e096fa61ab35964270539&scene=27#wechat_redirect)

继昨天 [初步支持 Android 11](http://mp.weixin.qq.com/s?__biz=MjM5Njg5ODU2NA==&mid=2257498601&idx=1&sn=e016d212654e059ec43df259f5e4ddef&chksm=a598238292efaa949c7d792e0995fbec177f18f1e865799faf3c19bfac3d6cedb554a448b12e&scene=21#wechat_redirect) 之后，我宣布，太极又将推出一系列重磅功能，这些新功能将彻底改变整个框架生态，废话不多说，请听我一一道来。  

  

1.  太极即将**支持 iOS 系统**。iOS 版本的太极暂时命名为 i太极，简称：爱太极。其实现方式也分为阴阳两种，爱太极·阳将采用传统的越狱方式实现，爱太极·阴则将在 iOS 中运行一个 Android 虚拟机，在虚拟机中实现 Android 版太极的部分功能。
    
2.  Android 版太极即将支持**免刷机实现太极·阳**。也就是传说中的「少阳」模式。在少阳模式下，即使不刷机，你也可以使用太极·阳的完整功能；比如说，不再需要卸载并重新创建应用。不过，目前这个模式只对魅族、华为和小米的部分机型能够生效，后续逐步完善中。
    
3.  太极将**内置双开**支持。内置双开之后，你可以直接在太极内部多开应用，无需采用系统双开或者 Island 之类的软件双开。当然，内置的双开也可以配合系统双开和 Island，这种情况下你可以额外获得一倍的多开能力。
    
4.  太极将支持**千人千面**的模式。具体来说，太极可以让任意一个用户安装的框架与其他用户均不相同，让每个人拥有自己独一无二的框架，从而彻底抹平框架的某些单一、固定特征。
