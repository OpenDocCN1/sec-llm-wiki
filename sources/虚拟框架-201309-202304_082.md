# 请扩散，湖北各地医院紧急求援

今天本是大年初一，此时外面的鞭炮声此起彼伏，人们都沉浸在新年的喜悦之中。但是，在疫情最前线的湖北各市县却是另外一番光景。  

  

我本人身处湖北省黄冈市，从身边的各种渠道了解到湖北省多家医院物资紧张，请求紧急支援；以下是目前收录到的一些医院名单和资料，基本上是各医院官方发布的，请大家帮忙扩散，略尽绵薄之力！

  

另外，恳请大家稍微关照一下县市级医院，武汉受到的关注度很高，其他县市有着同样的处境却没有同样的关注度！
