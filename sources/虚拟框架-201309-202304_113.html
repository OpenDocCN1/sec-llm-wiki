昨晚说过，有个新功能。想必大家已经知道了：全局模式。今晚如约而至。不过有一些说明：


  1. 这个全局模式仅仅对太极·阳有效，太极阴没有任何效果；UI在太极阴上展现是个意外。

  2. 现在系统服务进程（system_server) 和系统界面 (systemui) 默认都会加载插件；因此绝大部分情况下，所谓全局生效的模式不用开启全局模式就能生效；如无必要，不要开启全局模式。比如说：边缘手势 / PerfectColorBar / 重力工具箱以前需要手动添加 系统界面到太极，现在不需要了；你也无需开启全局模式它们就能生效。

  3. 全局模式的意思是：系统中的所有应用全都会加载你在模块管理中勾选的模块，这种工作模式类似原来的 Xposed。没有特殊需求不建议使用这种模式，但是它在某些场景很有用（比如开发者拿来调试）；另外有些小伙伴就是喜欢这样，所以我就加上了。

  4. 开启全局模式后，所有的应用都会被注入。有注入就有可能被检测，APP如果反感被注入，那可能就无法使用。所以使用这个模式的话，你自己要对自己负责。

  5. 全局模式开启之后是即时生效的。无需重启手机就能生效。所以如果你在全局模式下，某些应用如果打不开，可以临时关闭全局模式。


另外，Magisk 在5月1号之后，不再支持老的模块格式。Magisk 官方要求所有在 Magisk 仓库内的模块在此之前必须升级为新的格式。因此，太极模块 v4.9.0 将是最后一个支持 Magisk 18.1 以下的的版本。因此，请尽快升级你的 Magisk 版本，Magisk Manager 至少升级到 7.1.0，推荐升级到 7.1.1。Magisk 本体推荐升级到 18.1。


还有，v4.9.0 最高可以支持到 Android Q beta2（最新），不再像 v4.8.1 那样有版本区分。
