短短的一个多月，这个公众号已经快达成目标了。这里必须先感谢各位的大力支持，作为回报，太极 近期将会更新一些令人期待的新特性！具体更新什么内容以及什么时候更新，我先卖个关子；一直跟随我的小伙伴应该知道，我从不食言。


另外，最新版 4.3.8 已经发布了。关注本公众号，回复 最新版 即可获得下载地址。这其中，最最重要的更新是，普通版的用户应该再也不会遇到「EXposed 运行环境错误，正在退出...」或者「太极已经被系统杀死，请加入内存清理白名单」之类的错误提示了。当然，我还是建议普通版的用户把太极加入内存清理白名单，这样打开太极内部 APP 的速度会快很多。下面是详细的更新日志：


  1. 新模块：AD快消。

  2. 新模块：培训机构识别 VirtualXposed。

  3. 新模块：网易云音乐插件。

  4. 新模块: AIDE helper。

  5. 新模块: Wifi 模拟。以上模块 普通版 也可以使用。

  6. 新模块：Scene。经测试，这个模块在 MIUI 疑似无效，并且无法兼容所有系统，望周知。

  7. 新模块：无障碍 Daemon。这个模块需要把 系统设置 加入到太极。无法兼容所有系统，望周知。

  8. 新模块：MusicNotification。

  9. 模块更新：Q++ 1.22 / 3000 模组 / AD快消1.4.4 / 绿色守护 4.6.2 。

  10. 模块更新：畅玩微信 1.8.8.7 / 吃米2.2.22 / 微信红包/1.4.3 / 微群发模块7.0.3 

  11. 模块更新：大圣净化 1.8.3/Google App 助手 1.8.0.

  12. 添加 APP 时支持按照包名搜索。

  13. 解决 哔哩哔哩 开启 插件 1.5.6 版本以上卡在启动页的问题。

  14. 解决 EXposed 运行环境错误 的问题。 


然后还要悄悄告诉大家，太极已经开启了 Daily Build 模式，只要关注本公众号，然后回复 内测版 ，每天都可以体验到最新的版本哦~
