很久以前，在 太极 刚发布的时候，APP内部的标题显示的是 太极·阴。有很多小伙伴问过我，为什么要带一个“阴”呀，是不是会有一个“阳”的版本？


答案是肯定的，太极生两仪，有阴自然就必须有阳。


在我设计太极的时候已经考虑到了，虽然太极主要解决未Root、无法刷机的情况下使用 Xposed 模块的问题；但事实上，只要有合适的注入时机，太极也能修改系统，实现完整版 Xposed 框架的功能。在命名上，我将 免Root，免刷机的太极称之为太极·阴，能借助刷机实现完全体 Xposed 功能的太极称之为 太极·阳。


经过一段时间的开发，借助 Magisk 的加持，太极·阴可以通过一种自然的方式转化为太极·阳，实现阴阳合壁！


从今以后，如果你不想刷机，可以使用太极·阴体验强大的Xposed 模块；如果你愿意折腾，可以通过刷入一个 magisk 模块，太极·阴会自动转换为太极·阳（Magisk模式），享受更加丰富和完善的 Xposed 功能。


具体来说，太极·阳到底有哪些独有的特性，使得我有动力去折腾呢？


  1. 太极·阳 可以拦截系统，因此可以额外支持系统级别的 Xposed 模块；如边缘手势/核心破解/绿色守护/应用控制器等。

  2. 太极·阳 不需要修改 APP，因此可以做到 秒添加 APP；再也不用烦心地等待。

  3. 由于 太极·阳 不再需要修改 APP，因此 可以完美解决 微信/QQ 等应用无法被其他应用识别的问题。

  4. 太极·阳 有能力对系统做更多地控制，因此可以做到更加稳定。


与rovo89 的 Xposed 相比，太极·阳又有什么特点？


  1. 太极·阳 支持 Android 9.0 ，并且对9.0的支持比9.0以下更为完善。

  2. 太极·阳 不影响全局。可以只对特定的应用开启 Xposed 功能，无需使用 Xposed 的APP 运行起来就跟系统没有 Xposed 一样；完美契合某些金融/银行类APP。

  3. 太极·阳 针对APP的模块，无需重启即刻生效。

  4. 太极·阳 更不易被检测。太极的弱侵入特性不再修改 运行时，也不在全局环境中留下任何踪影；因此只要想要做到，可以轻松逃过各种代码类型的检测。


在继续往下说之前，我知道有一些小伙伴要坐不住了：我原本就是为了免Root、不愿意刷机才使用太极的，现在去开发什么magisk版，是要抛弃我们了嘛？


事实上，太极·阴（普通版、无需刷机的太极）与 太极·阳（Magisk版，需要刷机的太极）使用的是同一个安装包，我虽然把它们称之为不同的版本，但它们实际上是完全一样的！安装好太极之后，如果你没有刷机，他就以没有刷机的方式工作；如果你刷机，然后刷入 太极 提供的 magisk 模块，它将自动以 另一种方式工作；这一切你都无需关心！

说到这里，有很多小伙伴已经跃跃欲试了吧？不过我需要说明的是，虽然这段时间我日夜兼程，付出了很多额外的时间，但是目前的 太极·Magisk 版依然处于测试阶段；可能会出现各种异常情况。普通版的太极出现异常，顶多就是 APP 卡死或者闪退，magisk 版的太极如果有问题，那么就是 系统崩溃、无法开机等严重问题；因此，在你体验之前，一定要做好充分的心理准备。

准备工作


备份数据

我必须再强调一遍，无论如何，刷机有风险，数据无价。

在刷入 Magisk 以及太极模块之前，请一定要备份好数据。开发者不对任何因为刷机丢失数据负责。


如何自救？


一旦出现了异常情况，无法开机；如何处理呢？有两种办法：


这里推荐 MM管理器，这是 Magisk 的一个模块；需要在刷入 太极相关的模块之前先安装好。一旦刷入太极模块之后出现了任何异常，可以通过如下方式恢复：


1. 出现无法开启的情况后，长按音量下+电源键 10秒钟后进入fastboot模式，然后选择 recovery 模式重启。

2. 使用数据线连接电脑，使用 adb shell 进入命令行；或者直接使用 recovery 提供的命令行终端。

3. 输入 /data/media/mm 命令，选择 u 然后 输入 taichi 按两次回车键 重启即可。


使用方法


遗留清理

如果你装有普通版的太极，并且在太极中创建过APP，在使用 Magisk 版本之前，必须先把这些 APP 全部卸载。请注意这一步非常重要！（卸载之前注意备份数据）


安装太极

Magisk 版需要安装最新的安装包，请使用4.2.0.4 版本！！关注本公众号，然后回复 面具 即可获得下载链接。

 

刷入Magisk模块

下载好太极提供的 magisk 模块，然后在 Magisk Manager 中刷入即可。推荐使用 3.6-b。关注本公众号，然后回复 面具 即可获得下载链接。


内测激活

太极的 Magisk 模块刷入之后，重启手机；重新打开太极，会提示内测中，需要你输入内测码。内测码是通过你的设备标识码得到的，关注本公众号，直接复制你的设备码回复公众号，会立即给力发送一个内测码。输入 APP 内部的提示框就可以激活。

使用


万事俱备之后，下面就是使用方法：


1. 打开太极，添加你需要使用 Xposed 模块的APP，如 支付宝 到太极中。

2. 进入模块管理，勾选上你需要使用的 Xposed 模块，如 全部成为F。

3. 强制停止你需要观察效果的APP，如上面的 支付宝。

4. 打开 支付宝 观察效果。


注意：太极·Magisk版有一些使用方法与 Xposed 不同，请知悉：


1. 必须把 APP 添加到太极中，太极才会对这个 APP 启用Xposed 功能。

2. 不是作用于系统的模块，无需重启手机即可生效。

3. 模块重新安装之后，需要重新勾选。


关于第一点，与普通的太极不同的是，Magisk 版添加 APP 基本不执行任何操作，它所做的就是简单的把你选择的这个 APP 添加到一个名单；仅此而已。不会修改签名，也不会有任何影响。


另外，没有添加到太极中的 APP，它运行的时候没有任何 Xposed 环境，就跟安装在没有 Xposed 的手机上一样；因此银行类等检测Xposed 的APP，只需要开启 Magisk Hide 即可正常使用！
