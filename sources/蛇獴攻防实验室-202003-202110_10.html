 什么是shellcode

我们⻅到的shellcode是这样的

简单来说，shellcode就是⼀段可以获取权限的代码。复杂点说，shellcode是⼀段通过中断程序执⾏改写寄存器值⽽获取权限（系统调用）的机器码。

 分解⼀下这段话：

  1. shellcode 获取权限 （结果）

  2. 中断程序执⾏改写寄存器的值（功能实现过程）

不同位数的程序实现shellcode的⽅式不同 

 linux 32位 ：init0x80 中断实现execve系统调⽤

 linux 64位 ：syscall 中断实现execve系统调⽤

0x021 系统调⽤过程

⾸先我们来认识⼀下 int 0x80 (Intel CPU)程序为什么会执⾏我们所设定的系统调⽤呢？

程序在执⾏的过程中会有两种状态，⽤户态(User Mode) 和内核态(Kernel Mode)，⽽这两种状态的关系是怎么样的呢？我们拿⼀张图来说明。

名词解释：

System call Invocation in Application program : 在应⽤程序中调⽤系统调⽤ 

Wrapper routine In libc standard Library ：在libc标准库中封装例程 

System call handler ：系统调⽤处理程序 

System call Service routine ：系统调⽤服务例程


如上图，系统调⽤执⾏的流程如下： 

  1. 应⽤程序代码调⽤系统调⽤(xyz)，该函数是⼀个包装系统调⽤的 库函数；

  2. 库函数 ( xyz )负责准备向内核传递的参数，并触发软中断(int 0x80) 以切换到内核；

  3. CPU被软中断打断后，执行中断处理函数,即系统调⽤处理函数 (system_call)；

  4. 系统调⽤处理函数调⽤系统调⽤服务例程(sys_xyz)，真正开始处理该系统调⽤；


那么系统调⽤是如何区分系统调用函数的呢？

是通过系统调⽤号来区分的，不同位数的操作系统的系统调⽤号不同。系统调⽤号⼀般通过eax寄存器传递，⽤户进程传递系统调⽤号给系统调用处理函数以调⽤系统调⽤。
