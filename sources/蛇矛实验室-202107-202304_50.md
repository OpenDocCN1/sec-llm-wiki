01 CNNVD-202202-1351

漏洞描述：WordPress是WordPress（Wordpress）基金会的一套使用PHP语言开发的博客平台。该平台支持在PHP和MySQL的服务器上架设个人博客网站。WordPress plugin Error Log Viewer 存在安全漏洞，该漏洞源于WordPress错误日志查看器插件1.1.1有一个任意文件删除漏洞。攻击者可利用该漏洞删除任何命名文件的内部内容，而web服务器有权限修改这些文件。

  

CVE编号：CVE-2021-24966

  

漏洞等级：高危

  

参考链接：

http://vulhub.org.cn/vuln/VHN-383687

  

02  CNNVD-202202-1359

  

漏洞描述：DuxCms是一个开源内容管理系统。DuxCMS v3.1.3版本存在安全漏洞，攻击者可利用该漏洞通过组件s/tools/SendTpl/index执行SQL注入。

  

CVE编号：CVE-2021-3242

  

漏洞等级：高危

  

参考链接：  

http://vulhub.org.cn/vuln/VHN-384772

  

03  CNNVD-202202-1343

  

漏洞描述：Apple macOS是美国苹果（Apple）公司的一套专为Mac计算机所开发的专用操作系统。Apple macOS 存在安全漏洞，该漏洞源于ibFontParser 库用TTF字体制作的数据可能会触发超出已分配数据结构末尾的写操作。攻击者可利用该漏洞在当前进程的上下文中执行代码。

  

CVE编号：CVE-2021-30771

  

漏洞等级：高危

  

参考链接：

http://vulhub.org.cn/vuln/VHN-390504

  

04  CNNVD-202202-1356 

  

漏洞描述：netfilter是一款使用在Linux系统中的数据包过滤框架。netfilter 存在安全漏洞，该漏洞源于netfilter中存在一个网络连接的缺陷。攻击者可利用该漏洞推断openvpn连接端点信息，以便在传统的网络攻击中进一步使用。

  

CVE编号：CVE-2021-3773

  

漏洞等级：高危

  

漏洞类型：信息暴露

  

弱点列举：CWE-200

  

参考链接：

http://vulhub.org.cn/vuln/VHN-399440

      05  CNNVD-202202-1346

漏洞描述：Snow Software Snow Inventory Java Scanner是瑞典Snow Software公司的一个 Java 库存扫描器。Snow Software Snow Inventory Java Scanner 1.0 版本存在安全漏洞，该漏洞源于软件权限过滤存在问题。攻击者可利用该漏洞以更高级别的权限运行恶意代码。

  

CVE编号：CVE-2021-4106

  

漏洞等级：高危

  

漏洞类型： 特权管理不恰当

  

弱点列举：CWE-269

  

参考链接：

http://vulhub.org.cn/vuln/VHN-408417
