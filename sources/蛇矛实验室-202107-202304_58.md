1.漏洞描述

![](../Images/d91758f4ba2b8738d806395f1edcf179.png)

  

**    活动目录（Active Directory）是面向Windows Standard Server、Windows Enterprise Server以及 Windows Datacenter Server的目录服务，该服务也是Windows Server 操作系统平台的中心组件之一。**

****    根据微软11月的安全更新信息，Microsoft Windows Active Directory域服务存在权限提升漏洞（CVE-2021-42278********、CVE-2021-42287）。利用该漏洞可以将域内的普通用户权限提升到域管理员权限。由此造成********的风险和危害极大。****
