1.场景准备




· 场景名称

Apache Log4j 远程命令执行漏洞仿真复现场景




·  场景概述

Apache Log4j2 是一款优秀的java日志框架。是Log4j的升级版，由于Apache Log4j2某些功能存在递归解析功能，攻击者可在未授权的条件下直接构造恶意数据，对目标进行命令执行或获取最高权限，本场就就此漏洞在真实环境下的远程利用过程进行演示。



· 影响版本

Apache Log4j 2.x <= 2.14.1

4.防护方案



官方已经发布补丁，请尽快升级到最新版本：log4j-2.15.0-rc2

升级相关ApacheSolr、Apache Flink Apache Druid 等相关组件

配置日志等级及对本地及网络防火墙进行配置。

修改jvm参数 -Dlog4j2.formatMsgNolookups=true

修改配置log4j2.formatMsgNolookups=True

将系统环境变量FORMAT_MESSAGES_PATTERN_DISABLE_LOOKUPS 设置为true。
