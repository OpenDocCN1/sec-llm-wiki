# 【漏洞预警】Apache Log4j 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwMjI1NzY4Ng==&mid=2247500782&idx=1&sn=6c8715a049eac6132a0eab075b148197&chksm=c0aace97f7dd4781e0ab15d04bff46545e902b390979fd932bc26cea3f4be1321745475fa0b6&scene=126&sessionid=1681575497#rd](http://mp.weixin.qq.com/s?__biz=MzkwMjI1NzY4Ng==&mid=2247500782&idx=1&sn=6c8715a049eac6132a0eab075b148197&chksm=c0aace97f7dd4781e0ab15d04bff46545e902b390979fd932bc26cea3f4be1321745475fa0b6&scene=126&sessionid=1681575497#rd)

  

1.漏洞概述

  

Apache Log4j2是一款优秀的java日志框架。是Log4j的升级版，由于Apache Log4j2某些功能存在递归解析功能，攻击者可在未授权的条件下直接构造恶意数据，对目标进行命令执行或获取权限.

  

2.影响版本范围

Apache Log4j 2.x <= 2.14.1

  

3.修复建议

  

官方已经发布补丁，请尽快升级到最新版本：

https://github.com/apache/logging-log4j2/releases/tag/log4j-2.15.0-rc1

  

4.漏洞复现

  

蛇矛实验室第一时间在“火天网演”网络攻防靶场中进行了漏洞验证.
