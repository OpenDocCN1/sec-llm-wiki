本环境是蛇矛实验室基于"火天网演攻防演训靶场"进行搭建，通过火天网演中的环境构建模块，可以灵活的对目标网络进行设计和配置，并且可以快速进行场景搭建和复现工作。





背景



    在公司网络或者业务网络中，便于管理和共享，越来越多的用户选择使用域来代替工作组，在功能便捷的同时，也衍生出越来越多的关于域安全的相关问题。

    由于真实的域环境通常分布在多个物理地域，涉及到大量的服务器、终端，网络设备的配置，构建真实的域环境做实验难度较大，利用火天网境的NFV支持、路由协议支持和强大的虚拟化仿真能力，我们可以轻松的构建出大规模基于广域网的域环境进行攻防的效能评估以及安全问题的复现验证。

   本期文章主要说明骨干网络搭建以及关键节点搭建过程与方法。





环境准备



本场景模拟三个区域：上海、北京、广州，根据三个地方创建三个站点：上海、北京、广州。

上海站点子网：192.168.10.0/24

北京站点子网：192.168.20.0/24

广州站点子网：192.168.30.0/24

路由器设置



核心路由器设置

172.88.1.1/24，172.88.2.10/24，172.88.3.10/24三个网段





选择console协议进入

配置⽂件：进入



进入配置界⾯，双击回⻋



配置三个⽹⼝IP地址

Int g0/1；g0/2；g0/3进入⽹⼝ ip addr 添加IP地址，24位掩码 no sh 不关闭，就是打开⽹⼝配置完成后exit 推出当前⽹⼝

设置ospf



继续exit退出，查看IP配置



设置ospf ip段 区域0

net 172.88.1.1 0.0.0.255 area 0

net 172.88.2.10 0.0.0.255 area 0

net 172.88.3.10 0.0.0.255 area 0



net  network-address wildcard-mask area 0  network命令用来指定运行OSPF协议的接口和接口所属的区域，area命令用来创建OSPF区域,并进入OSPF区域视图

01

域林根域上海站点搭建-rangenet.



IP为192.168.10.2的服务器

第一步：关闭防火墙



第二步：域服务器IP须为固定，设置另外两个父域的IP为DNS，保证通信



第三步：添加角色-域服务



其它默认至安装



第四步：设置为域控制器





忽略DNS委派，直接下一步




其它默认下一步，直至安装



自动重启后完成安装



创建站点

第一步：打开DC1的"ActiveDirectory 站点和服务"，右键点击默认的站点，选择重命名"上海"




第二步：创建北京，广州站点

右键点击"Sites"，选择"新站点"




成功创建




添加子网

站点创建好后，需要为每个站点添加子网，因为每个站点是根据不同子网来划分范围的

右键点击"Subnets"，选择"新建子网"





创建完成



创建站点连接

站点链接用于不同站点同一个域的DC间的互相同步更新

展开"Inter-Site Transports"，右键点击"IP"，选择"新站点链接"






创建完成

若出现SID相同情况



在C://windows/system32/sysprep中点击sysprep

重新添加域，重启电脑后，成功加入rangenet.cn中
