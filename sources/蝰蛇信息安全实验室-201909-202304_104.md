　**php标签类型**　

**1\. XML 型标签**

```
<?php echo "In PHP Tag~"?>
```

  

  

注意：这个标签中的 php 的声明不是大小写敏感的，你可以 `<?PhP ... ?>` 也是完全可行的。

  

**2\. 短标签 （SGML 型标签）**

对于这种标签，个人把他们分成两类：

*   需要 PHP 配置支持的
    
*   不需要 PHP 配置支持的
    

下面具体来介绍：

需要配置支持：<? echo “In Tag!” ?>

  

```
<? echo "In Tag!" ?>
```

  

  

这种标签发挥作用，要取决于你的 PHP 配置是否开启了  `short_open_tag`

需要说明的是，一旦使用关闭了 short\_open\_tag ，`<? ... ?>` 的内容是不会显示在用户界面上的，也就是这些东西直接不见了，也不会执行。

  

不需要配置支持：<?=”In Tag!”?>

这个标签不需要开启 short\_open\_tag 就可以起作用，但是，缺点就是这个标签相当于一个 echo, 所以用法也相当受到限制：

```
输出一个字符串
```

```
<?='This short Tag just for echo~'?>
```

```
函数调用
```

```
<?=test()?>
```

  

  

**3\. ASP 风格标签**

  

```
<% echo 'IN TAG!' %>
```

  

如果想要使用这种风格的标签，需要确保 `asp_tags` 打开，并且一定要注意的是，这个和短标签的区别是：当短标签配置是关闭的时候，短标签（包括短标签内部）的东西是不会让用户看到的！然而如果 asp\_tags 关闭时，使用这种标签就会造成他的内容被用户看到，包括 ASP 风格标签和标签内部的内容。

  

**4\. Script 风格标签**

  

```
<script language=PhP>Echo 'In Tags'</script>
```

  

 `script` `language` `php` 的大小写随意转换，拿去做混淆自然挺不错的。

"admin"==0比较的时候，会将admin转化成数值，强制转化,由于admin是字符串，转化的结果是0。自然和0相等

"1admin"==1比较的时候会将1admin转化成数值,结果为1，而"admin1"==1 却等于错误，也就是”admin1”被转化成了0

"0e123456"=="0e456789"相互比较的时候，会将0e这类字符串识别为科学技术法的数字，0的无论多少次方都是零，所以相等

  

对于上述的问题 php手册 参考如下  

  

> 当一个字符串被当作一个数值来取值，其结果和类型如下:
> 
> 如果该字符串没有包含. e E 并且其数值值在整形的范围之内,该字符串被当作int来取值，其他所有情况下都被作为float来取值，该字符串的开始部分决定了它的值，如果该字符串以合法的数值开始，则使用该数值，否则其值为0。
