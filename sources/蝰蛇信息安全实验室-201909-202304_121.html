后端（后台）


如果说前端是网站的外貌，那么后端就像是网站的灵魂一样，后台的编写是真正的技术性考验。



01
什么是后端



后台，指网站后台，是指用于管理网站前台的一系列操作，如：产品、企业信息的增加、更新、删除等。


后端涉及的数据处理可以说是网站业务的核心了，不仅要考虑安全、还有存储和性能等多方面的因素。就个人的理解，现在网站后端主要由两部分组成——服务器和数据库。我们按顺序一个个讲。


02
 服务器



服务器，也称伺服器，是提供计算服务的设备。由于服务器需要响应服务请求，并进行处理，因此一般来说服务器应具备承担服务并且保障服务的能力。


服务器目前来说有物理和软件两种含义。

物理就是指的实体机器，也就是用作响应请求等这样的计算机；软件意义上的就是现在常说的Web服务器，实际上是指的一种计算机，能管理文件、进行数据操作等。

平时我们写的“后端”通俗意义上理解就是Web服务器，而平时玩游戏、逛网站时出现的服务器维护，也是指的Web服务器的维护，这里主要讲的也是服务器软件。



目前市面上主流的服务器


apache /əˈpætʃɪ/：中文名阿帕奇， 目前来说是世界上使用第一的Web服务器软件。稳定性高、效率高，最主要是开源免费，美中不足的是它本身仅提供html静态页面的功能，不能支持jsp、java servlet、asp等功能。


tomcat：汤姆猫，是阿帕奇基金软件会jarkata项目中的一个核心项目，开源免费不解释，和Java、jsp的相性比较好，运行时占用资源小，扩展性好，但是运行不稳定、并发连接数不高、html效率比不上阿帕奇。


jboss：开源，支持EJB，核心不含servlet和jsp的Web容器，但是有集合tomcat的版本，而且优化了tomcat。相当于是支持EJB等优化版tomcat。


weblogic：扩展性高，支持各种功能，服务稳定，但是，贵！可以免费试用，适合大型商业应用。


IIS：微软的服务器，全称Internet Information Service，虽然不开源，但是只要你买了Windows就可以免费使用，只支持Windows平台，一般来说都是做asp和aspx用。






推荐开发组合


“

1.如果操作系统是windows系统，且想使用asp，.net等应用，后台开发使用c#语言的，IIS；

2.如果仅需要展示html页面或者PHP，而不要其他功能，apache；

3.如果是在开发时使用或者是一般小型应用，需要支持jsp/servlet，而又不需要EJB的，tomcat；

4.需要支持jsp/servlet，不需要EJB，有希望提高服务器的效率和稳定性的，apache+tomcat；

5.需要支持jsp/servlet/EJB，而又想免费的，apache+jboss（包含tomcat的版本）；

6.需要支持jsp/servlet/EJB，又可以花点小钱的，resin（实在认为有必要，可以考虑resin+apache）；

7.大型商用，可以支付较高费用 weblogic（websphere可选）；

8.大型商用，可以支付较高费用，且有其他IBM相关功能服务的，websphere。



03
  数据库



数据库，简而言之可视为电子化的文件柜——存储电子文件的处所，用户可以对文件中的数据进行新增、查找、更新、删除等操作。


数据库也是有种类的，实际上数据库经历了三代演变：层次、网状数据库，现在最为常用的关系型数据库以及新一代（面向对象）数据库。




层次型数据库：使用起来限制较多，优点是查询效率高。


网状型数据库：像数据结构的图一样，数据类型作为结点，结点之间可以有多种联系方式。存取效率高，但是结构复杂，如果不了解结构的细节，就很难进行编程（访问的时候要选出适当的存取路径）。


关系型数据库：建立在关系模型的基础上，不论谁都是关系，它把所有的实体之间的联系用关系来进行表述，这种“数学系”操作使得数据库的操作变得很简单，编程变得简单很多，但是数据库管理系统这样的底层写起来就很复杂。


新一代数据库：不是指特定的某种类型，有很多种，很多新一代数据库本质上很难脱离关系数据库的影子。主要受面向对象的编程方式影响，还配合其他新兴技术的崛起，就有很多种像：分布式、并行、演绎、知识库、多媒体数据库等等。






市面上常见的数据库


MySQL：开源，关系型数据库，多平台，使用最广泛、流行度最高、可拓展（通过水平拆分扩大吞吐量）。

SQL Server：商业型、关系型数据库、微软、垂直升级（硬件升级）、适用微软体系。

Oracle：商业、关系型数据库、多平台、功能强、实用性高、垂直升级、学习难度最高。

Postgresql：开源、关系型数据库、多平台、功能最强的开源、Pyhton环境、图形监控弱、高可用、水平拓展（可以通过修改源码实现）。

Mongodb（芒果）：开源、文档型数据库、多平台、部署简易、部分功能付费、高可用、水平拓展、难以应付高事务性业务（SQL相性不好）。

Redis：开源、键值对型无sql数据库、Linux、稳定、快、适用于缓存。

Hbase：开源、列储存、Linux、无sql、海量数据、扩展性好。

结构化查询语言SQL



结构化查询语言(Structured Query Language)简称SQL(发音：/ˈes kjuː ˈel/ "S-Q-L")，是一种特殊目的的编程语言，是一种数据库查询和程序设计语言，用于存取数据以及查询、更新和管理关系数据库系统；同时也是数据库脚本文件的扩展名。


说到数据库，就不得不提结构化查询语言（SQL）。SQL最为常用的几种语法是：建表、插入、删除、更新、查询。值得一提的是：大多数情况下SQL语句大小写不敏感。

1.    建表


CREATE TABLE 

表名{

 列名1  数据类型  参数，
列名2  数据类型  参数，
…… }参数


这里的参数有：unique（不重复）、PrimarKey（主键）、unsigned（无符号）、FOREIGN KEY REFERENCES（设置外键）等等；


2.    插入

关键词是INSERT，主要有两种语句



INSERT INTO 表名称 VALUES (值1，值2，....)


INSERT INTO table_name(列1，列2，...) VALUES(值1，值2，...)


第二种语法泛用性更高，不需要用户插入的数据，交给数据库自己生成（时间戳之类的），而且配合外部的代码可以做是否要插入某个列的数据的筛选（比如Java的mybatis技术中mapper里利用if标签判断传入的对象对应参数是否为空然后动态生成对应的sql插入语句）；


3.    删除

关键词是DELETE


DELETE FROM 表名称 WHERE 列名称 = 值


这句话看起来很简单，但是SQL中只要有WHERE的句子都不简单，因为这其实是多级查询的开端



4.    更新

 关键词是UPDATE


UPDATE 表名称 SET 列名称 = 新值 WHERE 列名称 = 某值


5.    查询

 关键词是SELECT 


SELECT 列名称 FROM 表名称

SELECT * FROM 表名称


select 也可以使用：SELECT 列 FROM WHERE进行查询
