**一．****我们先认识了****解下Web是什么**

![](../Images/371b85bb609a1c215910b1fd3c35c289.png)

Web（World Wide Web）即全球广域网，也称为万维网，它是一种基于超文本和HTTP的、全球性的、动态交互的、跨平台的分布式图形信息系统。是建立在Internet上的一种网络服务，为浏览者在Internet上查找和浏览信息提供了图形化的、易于访问的直观界面，其中的文档及超链接将Internet上的信息节点组织成一个互为关联的网状结构。

![](../Images/371b85bb609a1c215910b1fd3c35c289.png)

  

![](../Images/3f6001aeb5b518c9aab6759531aac0f3.png)

**互联网（internet）包含因特网，因特网(Internet)包含万维网**（一点点小知识：开头I大写是专有名词因特网，小写的i开头就是互联网本身），如下图包含关系。凡是由能彼此通信的设备组成的网络就是互联网。除了因特网，互联网还有像是文件传输FTP、电子邮件E-mail、远程登陆telnet等等的基本服务。随教材改版，现在互联网也称因特网。

了解完网络家族，回到Web。

  

![](../Images/1c329246f0669417b33f24abf6c81bd8.png)

Web一开始是即时分享交流资料而提交的特殊网络协议的文档系统（这里的网络协议是计算机在网络中实现通信时必须遵守的协议，类似于人与人之间签约的合同），Web和其它网络有所不同的地方在于：允许Internet上任意一个用户都可以从许多文档服务计算机的数据库中搜索和获取文档。

  

为了实现任意用户检索，与之对应就配套形成了超链接，为了方便配合超链接定位资源，有了超文本（用超链接将不同空间的文字信息组织在一起的网状文本），超文本传输协议（HTTP）也就有了。访问资源的方式就是用户向服务器请求，服务器返回请求的文档到用户这里。对应也就有了用来访问万维网的浏览器，为了定位资源也就有了URL（统一资源定位符）。

  

![](../Images/2ad2dd1c8d4ca565eabb36e0a901c898.png)

**二、W****eb****前端**

![](../Images/371b85bb609a1c215910b1fd3c35c289.png)

前端即网站前台部分，运行在PC端，移动端等浏览器上展现给用户浏览的网页。随着互联网技术的发展HTML5，CSS3，以及前端框架的应用，使得现在的网页设计能够适应各种场景，实现更好的动画设计效果，给用户带来极高的用户体验。

![](../Images/371b85bb609a1c215910b1fd3c35c289.png)

  

我们通常所说的前端，就是Web用来展示给用户的东西，也就是常说的页面。前端的三大语言基石是HTML（定义网页内容）,CSS（规定网页布局）,JavaScript（对网页行为编程）。

  

让我们来一一了解吧  

  

**![](../Images/b18187b9539befa6542d686a1f814447.png)  **

  

![](../Images/076b108673678c8033372bb1b2d40b4f.png)

  

**HTML**

超文本标记语言，HTML 不是一种编程语言，而是一种标记语言 (markup language)，是网页制作所必备的，文件以.html或.htm为扩展名。HTML主要是由标签组成，标签内部拥有各自的属性，几乎所有标签都是成对存在的（也还是有单独的标签，最常见的就是换行标签br，以及和表单密切相关的input标签）几乎所有标签都比较常见，所以这里介绍几个不可缺少的的标签：

  

下表是一些基本的标签及其描述：  

  

| **标签** || **描述** |
| --- | --- |
| **<!DOCTYPE>** || 定义文档类型 |
| **<html></html>** || 定义HTML文档 |
| **<head></head>** || 定义文档标题 |
| **<body></body>** || 定义文档主题 |
| **<style></style>** || 定义样式标签 |
| **<script></script>** || 定义客户端脚本标签 |
| **<link>** || 定义文档与外部资源的关系 |
| **<input>** || 用于搜集用户信息 |
| **<a></a>** || 定义超链接，从一张页面链接到另一张 |
| **<div></div>** || 定义文档分区或节 |

  

  

**CSS**

层叠样式表(英文全称：Cascading Style Sheets)是一种用来表现HTML或XML（标准通用标记语言的一个子集）等文件样式的计算机语言。CSS不仅可以静态地修饰网页，还可以配合各种脚本语言动态地对网页各元素进行格式化。  

       css是外观设计这样的存在，可以理解为html的化妆师，现在常用的高版本html支持css混入html其中。这里主要介绍Web开发时css的作用：在开发页面的过程中，为了使得网页结构清晰、页面代码可读性良好，我们可以把CSS写在HTML页面的<head></head>标签中，或直接引入外部以.css为扩展名的文件到HTML页面。

  

  

  

**JavaScript**

  

JavaScript一种直译式脚本语言，是一种动态类型、弱类型、基于原型的语言，内置支持类型。它的解释器被称为JavaScript引擎，为浏览器的一部分，广泛用于客户端的脚本语言，最早是在HTML（标准通用标记语言下的一个应用）网页上使用，用来给HTML网页增加动态功能。

  

  

主要说一下使用的思路以及常见函数。  

首先是思路：

在前端中，JavaScript主要作用有几个方面：

  

![](../Images/b575d883cf12df4c58bd60964d8d47aa.png)1. 配合CSS来对网页进行修饰，可以让网页更加具有交互性，（正常情况下，css是不具备自己判断复杂条件的功能的，所以要配合js代码监听用户的事件像鼠标点击、移动、进入、离开等等来让网页里的元素获得对应样式或者动画）2. 进行前后端的数据进行交互，目前市面上主流的用法是Ajax（一种创建交互式动态网页应用的网页开发技术）配合json（一种轻量级的数据交换格式）传递数据，让后台获取用户操作数据或者对网页进行即时的数据更新
