（一）数据结构中的堆和栈

  

栈（stack）又名堆栈，它是一种**运算受限的线性表**。限定仅在表尾进行插入和删除操作的线性表。这一端被称为栈顶，相对地，把另一端称为栈底。向一个栈插入新元素又称作进栈、入栈或压栈，它是把新元素放到栈顶元素的上面，使之成为新的栈顶元素；从一个栈删除元素又称作出栈或退栈，它是把栈顶元素删除掉，使其相邻的元素成为新的栈顶元素，也就是**先进后出**。

  

![](../Images/f3c921cbec41623d4607071e4ebc46a2.png)

  

这张图片就是一个栈结构，栈结构由操作系统初始化，一般栈空间都是2M,主要用于存放函数的返回地址，参数，以及函数中的变量（非全局变量）

  

堆的基本结构一般是一颗**完全二叉树**，各种操作系统的堆结构基本一致，就是堆头不同（用来存储堆的信息），有时候各个版本堆头也不同，如果进行堆溢出要特别注意，因为有可能**版本**不一样，堆头不一样导致的错误是程序崩溃，c语言可以有malloc(),HeapCreate()等创建堆  

  

（二）堆和栈的理论知识

  

1.申请方式

栈：由系统自动分配（高级语言，汇编语言要程序员自己分配）

如main函数中的 **int a**

堆：由程序员自己分配，如 **char \*p** = **（char\*）malloc（8）**

 2.申请后系统的响应

栈：只要栈的剩余空间大于所申请空间，系统将为程序提供内存，否则将报异常提示栈溢出

堆：操作系统有**一个记录空余内存的链表**,当收到申请时，就会遍历链表，寻找到一个内存大于所申请堆需要的内存，然后将这个节点从空闲链表删除，再分配给程序，如果分配的内存空间大于申请的，系统会自动将空闲的那一部分加入空闲链表

3.存储速率

栈的存储速率远大于堆

4.   分配方式

堆都是动态分配的，没有静态分配的堆。栈有2种分配方式：**静态分配和动态分配**。静态分配是由**操作系统**完成的，比如局部变量的分配。动态分配由**alloca**函数进行分配，但是栈的动态分配和堆是不同的，他的动态分配是由操作系统进行释放，无需我们手工实现。

（动态：就是可以修改数据的值  静态：无法修改数据的值

比如 char \*a = “1234567890” a是可以修改的，所以是动态，但“1234567890”不可以被修改，是静态）

3.加密算法也很简单

先取出一个字符，减去48后再\*10 再加v2 \* 10 再赋值给v2

结束后再异或0x1234，同样没有给出来，只能在汇编看到

然后生成的值和用户名生成的值比较，如果**相等**就是正确的

解密脚本

User = 'ABCD'

  

key = 0

  

for i in User:

  

    if ord(i) >= 0x5A:

  

        i = chr(ord(i -** 32**))

  

    key = key + ord(i)

  

key = key ^ 0x1234 ^ 0x5678

  

print(key)
