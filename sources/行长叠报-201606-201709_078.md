# Windows 10系统源码泄露，真假难辨，一大波Windows漏洞即将到达战场...

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247485298&idx=1&sn=20ea502883253206a57c3ae1ab97a7c7&chksm=9bceb018acb9390e0f23d2a901ba66c44e496347416b2c5e32e09b4f912454f10fa1f4d98468&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247485298&idx=1&sn=20ea502883253206a57c3ae1ab97a7c7&chksm=9bceb018acb9390e0f23d2a901ba66c44e496347416b2c5e32e09b4f912454f10fa1f4d98468&scene=27#wechat_redirect)

![](../Images/dd781e0da7ef1f8cfe11e2654fb6f602.png)

  

6月23日，Windows 10系统约32TB的大量组建和核心源代码泄露，并且在BetaArchive网站上被公布。

  

该消息立刻引起了轩然大波。

  

根据微软日前公开的消息了解到，全球装载着windows 10 系统的月活跃用户已经超过了4亿台，**日活跃用户已经突破3亿人次。**

  

**Windows 10 操作系统的源码泄露，意味着所有人都可以查看这些核心代码，并且利用在底层代码中的漏洞，来破坏全球的windows系统，对所有windows 10系统的用户的信息安全造成严重威胁。**

  

**泄漏的代码是Microsoft的共享源代码工具包：**

> *   Windows 10硬件驱动程序的源码，
>     
> *   Redmond的PnP代码，
>     
> *   USB和Wi-Fi协议栈，
>     
> *   存储驱动程序
>     
> *   ARM特定的OneCore内核代码。
>     

  

有消息称，部分代码运行在操作系统的核心位置，信任级别极高。

![](../Images/0b53aae2d9c4c9955ba8b6c185c9d06f.png)

BetaArchives屏幕截图，添加Microsoft的机密源代码存档

  

除此之外，此次泄露的数据中还包括被列为最高机密的Windows10和Windows server 2016的架构。

  

**但是，BetaArchive现在已经从其服务器中删除了保密的“shared source Kit”。**

  

> “ 我们已经将“shared source Kit”文件夹从我们的FTP和列表中删除，进行进一步审查，以防内容遗漏。我们目前没有计划恢复这些文件，除非我们审核完成并确保这些文件不会违背我们的规则。”

![](../Images/af29c55840d1c971a28a7666eceb5ec4.png)

  

泄漏的文件还包含Microsoft的Windows 10移动适配工具包，由Microsoft设计的专用软件工具包旨在在移动设备上运行Windows 10操作系统。

  

到目前为止，尚不清楚谁是导致了这个大规模的数据泄漏，可能来自于微软的OEM合作伙伴之一。

  

**32TB源码泄露为不实消息**

  

被曝托管这批源代码文件BetaArchive FTP服务器的管理员Andy表示：

  

> 名为“Shared Source Kit”的源码目录确实曾存在于BetaArchive的FTP上，但远没有之前报道所称的32TB那么大。

  

Andy说：网站上存放的文件大小约1.2GB，包含12个版本，每个版本的大小约为100MB，至于The Register所报道的32TB为不实消息，并且由于这些文件太小的缘故，**因此这些代码不可能是所谓“核心源代码”。**

  

**微软未发声**

针对此事，微软方面暂时没有发表任何有关此事的说明。也没有发布任何有关此事的解决方法。

  

所以我们无法确认泄露的源码是否为“核心源码”。

  

但此次泄漏事件，不可避免的会再次造就一批针对windows 10 系统的攻击武器。

  

可以预见，在未来一段时间，或又会掀起一场有关信息安全的网络风暴。
