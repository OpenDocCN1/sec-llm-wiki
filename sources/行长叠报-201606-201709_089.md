# 【重大漏洞预警】Windows 远程代码执行漏洞曝光

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247485204&idx=1&sn=6aac2281142e74740f4f71352b3d1509&chksm=9bceb07eacb93968ce8fd173270b271831d54502e228afaf853090a3c860ebdfd0064fec9b04&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247485204&idx=1&sn=6aac2281142e74740f4f71352b3d1509&chksm=9bceb07eacb93968ce8fd173270b271831d54502e228afaf853090a3c860ebdfd0064fec9b04&scene=27#wechat_redirect)

6月13日，微软发布紧急补丁，修复两个危害级别严重的远程代码执行漏洞。它们分别是Windows Search远程代码执行漏洞(CVE-2017-8543)和LNK文件（快捷方式）远程代码执行漏洞(CVE-2017-8464)。  

  

**这两个漏洞或已经被不法分子利用，请尽快更新补丁，避免受到损害！**

![](../Images/76ba6795a74de455601d26b97ced1ea3.png)

  

**● 漏洞详情**  

  

**1. CVE-2017-8543 Windows Search远程代码执行漏洞**

![](../Images/5ba1063fa08834a36b789f4a507d9664.png)

  

**2\. CVE-2017-8464 LNK文件（快捷方式）远程代码执行漏洞**

![](../Images/f05a3ad4c64dc0d0e54ae8ae3c3344f3.png)

  

  

**● 修复方案及建议**  

  

**1\. 针对CVE-2017-8543修复建议**

  

针对Windows Search远程代码执行漏洞的修复建议

  

*   桌面系统Windows 10, 7, 8.1和Windows RT 8.1；服务器系统：Windows Server 2016，2012，2008，可以通过Windows Update自动更新微软补丁的方式进行修复。
    

  

*   Windows 8, Vista, Xp和Windows Server 2003 可以通过选择对应版本然后手动更新补丁的方式进行更新。
    

  

*   https://support.microsoft.com/zh-cn/help/4025687/microsoft-security-advisory-4025685-guidance-for-older-platforms （补丁下载地址参考）
    

  

**2\. 针对CVE-2017-8464修复建议**

  

针对LNK文件（快捷方式）远程代码执行漏洞的修复建议

  

*   桌面系统Windows 10,7,8.1和Windows RT 8.1；服务器系统：Windows Server 2016，2012，2008，可以通过Windows Update自动更新微软补丁的方式进行修复。
    

  

*   Windows 8, Vista可以通过选择对应版本然后手动更新补丁的方式进行更新。
    

  

*   https://support.microsoft.com/zh-cn/help/4025687/microsoft-security-advisory-4025685-guidance-for-older-platforms （补丁下载地址参考）
