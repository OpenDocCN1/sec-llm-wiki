永恒之蓝在被利用的几个小时内，安装WanaCrypt0r 勒索软件，在全球范围内造成严重破坏。

  

在这篇文章中我们**介绍一下WanaCrypt0r勒索软件的机制及其传播方式**。

  

  

**勒索软件主要功能**

  

WanaCrypt0r传播迅速，一方面是其会循环遍历系统上的每个开放RDP会话，并以该用户身份运行，同时**其初始组件是一个蠕虫，使用ETERNALBLUE SMB漏洞（MS17-010）来传播该勒索软件**。

  

勒索软件执行时，WinMain函数会尝试连接到网站：

www.iuqerfsodp9ifjaposdfjhgosurijfaewrwergwea.com

仅作尝试，实际上没有下载任何东西。**有意思的是，如果连接成功，二进制文件退出。**

  

目前该域名已经被注册。

![](../Images/12c5382c9990380a78c8635461dc632c.png)

▲ 图一  

  

**这可能是某种自毁开关或防沙箱技术。**目前该域名已经被控制，并被解析到一个网站，因此，任何新的运行可执行文件的系统都不会发生任何事情。这只适用于上面列出哈希的二进制文件，考虑到将来会有更多的变种会出现。  

![](../Images/9ff08a443676205d5f3ccb2d954ade09.png)

▲ 图二  

  

通过该检查后，蠕虫会检查启动参数数。 如果运行时传递的参数少于两个，它将安装一个名为mssecsvc2.0的服务，其显示名称为Microsoft Security Center（2.0）Service，启动该服务，打开蠕虫中的勒索软件，并运行。

如果它运行两个或更多的参数，**换句话说，如果它作为一个服务运行，最终会执行蠕虫功能。**

![](../Images/695b862d6ab30269e266b1817bb69bf2.png)

▲ 图三  

  

初始化函数首先调用WSAStartup()初始化网络，然后CryptAcquireContext()初始化crypto API，方便后续调用加密相关的伪随机数生成器。 之后调用一个函数，初始化两个缓冲区，用于存储蠕虫利用DLL，一个x86和一个x64。 **首先会从蠕虫的.data部分复制利用DLL，然后复制整个蠕虫二进制文件。**

![](../Images/29ad0614ec3a55e2ae1e53df5a2a146c.png)

▲ 图四  

  

每个利用DLL代码非常小，只获取资源内容（即蠕虫二进制文件）写到**C： WINDOWS  mssecsvc.exe**（此路径实际上是硬编码），并执行。

![](../Images/11cbba03aee69294c8d1c2bea12dc437.png)

▲ 图五  

  

  

**利用SMB 漏洞来传播勒索软件**

  

初始化蠕虫使用的功能后，会创建两个线程。第一个线程扫描LAN上的主机， 第二个线程创建128次，并扫描更多的Internet上的主机。

  

**第一个负责扫描LAN线程使用****GetAdaptersInfo()获取本地网络上的IP范围列表，然后创建一个ip数组，进行扫描。**

![](../Images/31af5c83909ec1116b723615c3a711ce.png)

▲ 图六  

  

LAN扫描本身是多线程的，并且有一些代码**可以防止一次在LAN上扫描超过10个IP地址**。

![](../Images/f01a62a67ee8e6203344f8d55df510e2.png)

▲ 图七  

  

扫描线程尝试连接到445端口，如果连接成功，则创建一个新线程尝试使用MS17-010 / EternalBlue来攻击系统。 **如果利用尝试时间超过10分钟，利用线程会终止。**

![](../Images/c6c77d98b155e3ff0f5439edd151b610.png)

▲ 图八  

  

**第二个进程**，扫描互联网的线程会使用先前初始化的伪随机数生成器，如果没有就使用较弱的伪随机数生成器来生成随机IP地址。 如果与该随机IP地址上的445端口连接成功，则扫描这个ip整个C段，如果有445端口开放，则进行利用尝试。**此时利用尝试时间限制为1小时。**

![](../Images/cd9d014d8c4c238e6286e367fbff85f0.png)

▲ 图九  

  

![](../Images/f6d19107ebd64999116bdc8e84afc813.png)

▲ 图十  

  

利用线程尝试使用两组不同的缓冲区（可能一组用于x86，一个用于x64）多次利用。 如果检测到DOUBLEPULSAR的存在，将使用DOUBLEPULSAR加载相关利用DLL。
