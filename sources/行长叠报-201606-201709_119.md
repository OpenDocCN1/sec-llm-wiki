**防御方案1**

在系统层做以下操作

打开系统自动更新，并检测更新最新补丁

开启系统防火墙

利用系统防火墙高级设置阻止向445端口进行访问

 

微软MS17-010补丁：

https://technet.microsoft.com/zh-cn/library/security/MS17-010

 

**预防方案2**

建议电脑用户使用360NSA武器库免疫工具

 

**简易防御方案**

第一步下载阅读原文中的文件，

第二部 按下列指示操作

  

**Win7、Win8、Win10的处理流程**

复制以下内容到txt中保存，并将文件后缀改成.bat

| netsh advfirewall set allprofiles state on netsh advfirewall firewall add rule name=block445 dir=in action=block protocol=TCP localport=445 netsh advfirewall firewall show rule name=block445 pause |
| --- |

 

以管理员权限运行该.bat文件

（该文件会自动打开防火墙，并屏蔽对445端口的访问）

 

![](../Images/8035d06ec5fdb5667b9117154c5ff579.png)

  

如果看到如下显示，说明执行成功

  

![](../Images/f234806856b40cb8900887bba98e083b.png)

 

**XP临时方案**

复制以下内容到txt中保存，并将文件后缀改成.bat

| netsh firewall set opmode mode=enablenet stop rdrnet stop srvnet stop netbtpause  |
| --- |

运行时选择Y，显示NetBios over Tcpip服务已成功停止，表示成功。

  

**如果你已中招社工破解的可能性尝试**

该内容来自知乎用户唐平

1:打开自己的那个勒索软件界面，点击copy. （复制黑客的比特币地址）  
2:把copy粘贴到btc.com （区块链查询器）  
3:在区块链查询器中找到黑客收款地址的交易记录，然后随意选择一个txid（交易哈希值）  
4:把txid 复制粘贴给 勒索软件界面按钮connect us.  
5:等黑客看到后 你再点击勒索软件上的check payment.   
6:再点击decrypt 解密文件即可。
