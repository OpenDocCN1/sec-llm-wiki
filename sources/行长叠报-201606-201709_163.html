紧急预警！Apache Struts2再爆高危漏洞，多个版本受波及

2017年3月6日，Apache官方再一次披露了编号为S2-045的漏洞信息（CVE-2017-5638,S02-45），将漏洞定级为高危漏洞。此漏洞涉及到Struts 2.3.5 - Struts 2.3.31，Struts 2.5 - Struts 2.5.10多个版本。请应用此环境的用户尽快升级。

 


Apache Struts 2是世界上最流行的Java Web服务器框架之一，每次漏洞公布都将引发黑产者的倾巢触动。2016年4月26日爆出Apache Struts S2-032漏洞（ CVE编号 CVE-2016-3081，在开启动态方法调用的情况下可以远程执行任意命令）几乎洗劫了整个中国互联网。

 

此次爆出的漏洞破坏力不逞多让，漏洞利用无任何条件限制，可绕过绝大多数的防护设备的通用防护策略，直接获取应用系统所在服务器的控制权限。漏洞银行信息安全专家建议提前做好该严重漏洞的应急准备工作，可将版本更新至Struts 2.3.32 或者 Struts 2.5.10.1 或 使用第三方的防护设备进行防护。 

 

附：

漏洞编号：CVE-2017-5638

漏洞等级：HIGH

漏洞名称：S2-045：Struts 2远程执行代码漏洞

漏洞影响：基于Jakarta Multipart解析器执行文件上传时可能的RCE

影响版本：Struts 2.3.5 - Struts 2.3.31

                  Struts 2.5 - Struts 2.5.10

修补方案：升级到Struts 2.3.32或Struts 2.5.10.1
