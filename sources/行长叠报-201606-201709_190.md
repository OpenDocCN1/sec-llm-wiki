# 警戒！只要打开JPEG、PEF文件，iPhone就可能被入侵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247484089&idx=1&sn=8ed7d2ec5ff01d613da52ce5462936b3&chksm=9bceb5d3acb93cc5df458029aefa633572846be7e626cfd7a243ae599c3c1d0910c5b07a68f5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247484089&idx=1&sn=8ed7d2ec5ff01d613da52ce5462936b3&chksm=9bceb5d3acb93cc5df458029aefa633572846be7e626cfd7a243ae599c3c1d0910c5b07a68f5&scene=27#wechat_redirect)

相当糟糕的一件事——点开看起来无公害的JPEG、PDF和字体文件，iPhone、iPad和iPod可能就被劫持了。

  

![](../Images/1056f2b4ced235095bb219c83c0f341b.png "警戒！只要打开JPEG、PEF文件，iPhone就可能被入侵")

  

是的，攻击者借着可以远程操控你的苹果ios设备的漏洞，他们需要做的只是骗你通过一个网站或一个邮件来查看一张被恶意制作的JPEG图像或是PDF文件，并因此使得你在自己的系统中执行它们的恶意代码。此漏洞为：CVE-2016-4673。

  

不过好消息是，苹果在最新的操作系统发布了更新——iOS10.1，因而iPhone和iPad可以访问这些远程代码执行漏洞，它们位于一组漏洞修复旁。

  

而现在，苹果公司推出了安全补丁，一些黑客很确信找到了有漏洞的苹果设备，可以利用这些漏洞并完全控制机器。

  

所以，运行老一点版本的**iOS用户**最好快点升级，升级后的移动设备版本iOS 10.1。

  

除了此远程代码执行漏洞之外，最新版的ios10.1 还包括一些安全更新，解决了共11项iPhone、iPad和iPod Touch的固件漏洞。

  

这些漏洞包括代码执行漏洞——WebKit中的一个远程代码执行漏洞：CVE-2016-4677，以及一个接触漏洞：CVE-2016-4686，它可能通过一个应用泄露已经被删除的地址簿细节。

  

**更新iOS设备的步骤：****设置**** → ****通用**** → ****软件更新。**

Mac也为苹果表和**AppleTV**发布了安全更新。所以，苹果建议用户更新他们的系统到Mac OS Sierra（10.12.1），其中包括16个 CVE漏洞的补丁修复。

  

这些漏洞带来的缺陷包括图形处理bug（CVE-2016-4673）、一个 Nvidia显卡驱动器的拒绝服务错误、一个暴露用户密码长度的漏洞，以及一个可通过文字文件和PDF文件触发的远程代码执行漏洞（RCE）。

  

同时，建议**苹果手表**用户更新他们的设备到watchOS 3.1，它其中包含了8处漏洞修复。这些楼洞里，有两个在砂箱配置文件，允许第三方app未经允许查看图像库和声音文件。

  

AppleTV用户也被建议尽快更新他们的设备至tvOS 10.0.1，这其中包含了10处漏洞，包括WebKit里的远程代码执行漏洞（沙箱文件漏洞），和CoreGraphics JPEG漏洞。

  

所以，在被黑客入侵之前，更新你的设备。
