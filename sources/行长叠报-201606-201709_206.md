# 5万8千厂商账户泄露——MongoDB数据库风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247484070&idx=2&sn=bce07e2290409cfc0350f0a0ba2a87e5&chksm=9bceb5ccacb93cda898a6cc2c9fbea1c051934811fc10844aea438e6f2a4370b021963a8e4ba&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247484070&idx=2&sn=bce07e2290409cfc0350f0a0ba2a87e5&chksm=9bceb5ccacb93cda898a6cc2c9fbea1c051934811fc10844aea438e6f2a4370b021963a8e4ba&scene=27#wechat_redirect)

不安全的MangoDB数据库致使对多达5千8百万的MBS公司的内部个人信息泄露。

  

著名的数据库主机和数据存储服务提供商公司——现代商业解决方案（MBS）已被身份未知的黑客入侵，该黑客曾设法从公司服务器盗取**MongoDB（巨杉）数据库**。

  

MongoDB是一个面向文档的数据库，目前由10gen开发并维护，它的功能丰富齐全，一定程度上可以替代MySQL。

  

据了解，此次黑客攻击背后的原因主要是MongoDB数据库防护措施不佳。也能够确定，**该数据库包含至关重要的用户信息，例如全名、IP地****址、****邮箱地址、职业、车辆信息以及出生日期。被盗数据涉及5千8百万用户。**

此次入侵的黑客身份不公开，但之前在Twitter上，他使用@ 0x2taylor且因高调的黑客与漏洞知识分享被人们关注。

 

![](../Images/75a195a309aa884057adb15bfbaf0854.png "5万8千厂商账户泄露——MongoDB数据库风险")

  

攻击者在Twitter公开了他盗取的数据，不只一次两次，而是多达三次！被入侵的公司持续地跟进对已共享数据库内容的删除。

  

报道称，Shodan搜索引擎被用来发现不受保护的数据库。代替向公司告知事实，攻击者直接将信息公布于网上。

  

**shodan搜索引擎简介：**该搜索引擎诞生于2009年的DEFCON，黑客约翰·马瑟利发布了一款名为“Shodan”的搜索引擎。Shodan名取自风靡一时的电脑游戏System Shock中的邪恶主机。

  

Shodan通过各种设备的HTTP header进行检索，Shodan能找到服务器、路由器、交换机、公共IP打印机、网络摄像头、加油站的泵、Voip电话和所有数据采集监控系统。能做的则包括搜索制定的项目、寻找端口并拦截数据、为拦截的数据设置索引、显示结果，甚至搜到在线物联网设备。可谓功能非常强大，被誉为**“黑客专用的搜索引擎”**。

  

![](../Images/10df7de7826002f61a44035b6de344e1.png "5万8千厂商账户泄露——MongoDB数据库风险")

Shodan的人工智能形象

  

截至目前，该公司还没有关于此次数据窃取黑客案件发布任何正式声明，但公司承自己没有做出努力保护不够安全的数据库。

  

泄露数据之后，MBS没能提供关于其保护不佳的数据库为何拥有与Hardwell数据客户端相关的信息。此数据库表格有前置代码：“hw\_”。Hardwell数据是被**美国网络安全公司——Risk Based Security检验**，此公司做出如下表态：

  

MBS用于数据管理的主要程序。

  

然而，数据漏洞的数量日益增长。Rish Based Security写下标注：“2016年截至目前，有2928个公开披露的数据漏洞，揭露记录超过22亿。

  

22亿着实是个巨大的数目，RBS研究表明，55%的漏洞发生在2016年前半年，曝光了可能多达1万条的记录。不幸的是，一些标注着“高危漏洞”的例外来自配置错误的数据库。

  

此前，1千3百万Mackeeper（苹果电脑清理软件）账户和几个其他的数据库也被Shodan搜索引擎发现。**所以假如你是一位安全研究员，****Shodan是检查数据库安全的好地方。**
