# 【PWN笔记】渗透实战某域名商

事情起因:我朋友让我帮他搭建博客，于是我大发善心去帮助了他;他用的是免费的tk域名，所以提供免费域名的域名商应该也不是什么大公司。然而,没想到竟然...

  

**![](../Images/29dfc2bd8f19fb46bc8ca3233e21795c.png "渗透实战某域名商")**

  

0x01（发现信息）  

  

我打开他给的域名商官网,发现不咋地。但是提供免费域名和主机也是不错的。

  

**![](../Images/d1e1bdb57537d3024c9b4baec1a5d08a.png "渗透实战某域名商")**

  

然后解析了域名了以后就等待生效,可是等了很长时间也没有生效。于是突来奇想- -想要渗透此网站- -没有探测网址环境信息..  

  

于是在网址后面加上/admin 看看默认的后台地址是否存在:

  

**![](../Images/af4fbd6275343ca85e71d7b088fde2d6.png "渗透实战某域名商")**

  

返回404但是我发现是kangle的配置,kangle...我先大家都懂。这时候忽然想到在春秋有一个帖子关于kangle的新姿势的。

  

![](../Images/1c1b46a7622af147d4a5ee64f6bad97c.png "渗透实战某域名商")

  

**![](../Images/7d23ea63a13540a8bbabf0ec9703bf5c.png "渗透实战某域名商")**

  

于是按照这个方法在网站后面加上:3313/mysql

  

**![](../Images/c82e5f17fe0fd7cdd21beb606b590b36.png "渗透实战某域名商")**

  

然后尝试各种弱口令,当然爆破就不要想了...然后失败...

  

# 0x02（查看虚拟主机控制面板）

  

因为我经常用kangle的系统,所以我知道在网站后面加上“:3312”的话就会直接访问kangle虚拟主机的控制面板。

  

**![](../Images/70af58f6dfc85f5e16681058ec7eaf28.png "渗透实战某域名商")**

于是我尝试各种弱口令，结果还是失败。因为我根本没怀希望能成功。

  

**![](../Images/d7fa4ef6559d738417d600620af7f4f0.png "渗透实战某域名商")**

于是最终还是失败

  

# 0x03（上传文件）

  

于是接下来我准备用御剑扫扫敏感目录，结果没有扫出后台，但是扫出来个surprise！

  

**![](../Images/38927c8eca19aa27d5f20bd8c0eba3e1.png "渗透实战某域名商")**

  

于是我尝试上传一个php一句话木马但是什么也没有什么返回，不过目前是不能判断上传是否成功。

  

**![](../Images/c9b2f1c2a00f9e252d544629122eda09.png "渗透实战某域名商")**

于是我尝试上传正常的图片，发现返回了上传的url，于是我初步判断应该是被拦截了。

  

# 0x04（Burp截断）

  

我掏出神器Burpsuite（漏洞银行的工具百科有这个工具的介绍）准备抓包~

  

**![](../Images/8433aa2d55fcc9c62e6ca30dd87f1d9a.png "渗透实战某域名商")**

于是果断把php.jpg更换为php.php

  

**![](../Images/8d218dfbdb73ac27e23e268605357096.png "渗透实战某域名商")**

**![](../Images/f398965510fa64b35010bd2346f25d32.png "渗透实战某域名商")**

**![](../Images/2829512e22499f13d4ab0d6eb69f68d5.png "渗透实战某域名商")**
