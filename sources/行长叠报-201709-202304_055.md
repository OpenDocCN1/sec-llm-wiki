# 漏洞银行获进博会官方双料感谢信

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247494923&idx=1&sn=3f257eec403f08932b5b6d9512d4a988&chksm=9bcd5a61acbad377d9f319db130bf7799bd2d8ef71e9fd21944e78c64ac0ad5fd7c0d32e0141&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247494923&idx=1&sn=3f257eec403f08932b5b6d9512d4a988&chksm=9bcd5a61acbad377d9f319db130bf7799bd2d8ef71e9fd21944e78c64ac0ad5fd7c0d32e0141&scene=27#wechat_redirect)

第四届中国国际进口博览会于2021年11月10日在上海国家会展中心圆满落下帷幕。**上海谋乐网络科技有限公司（简称：漏洞银行）作为CIIE2021官方指定网络安全支撑企业，为进博会的顺利开展保驾护航。**活动结束后，漏洞银行收到了来自上海市公安局驻国家会展中心前方安保指挥部及中国国际进口博览会的官方双料感谢信，以感谢漏洞银行为进博会成功举办作出的贡献。漏洞银行对进博会的安全技术支撑已走入第五个年头，漏洞银行将秉持初心，持续为国家网络安全建设尽绵薄之力。

![](../Images/4fa8842631711f6b906ec54123033cff.png)

  

漏洞银行的产品及服务已经被国内众多知名企业和机构认可，为数百家500强企业、上市公司、金融、互联网、物联网、政府、教育等行业客户提供优质服务、创新产品和解决方案，曾先后为上合组织峰会、国际进口博览会等多个国家重大活动做网络安全保障工作。它是上海市信息安全行业协会理事单位，上海市网络与信息安全监测预警共建威胁信息共享战略协作倡议发起单位，网络安全等级保护专业委员会成员单位，SHCERT网络安全应急服务支撑单位，CNNVD技术支撑单位。此外，它与上海市网络与信息安全应急管理事务中心及上海市政府达成战略合作，成为首家为国家提供城域漏洞安全的网络科技企业。漏洞银行自主研发产品“漏洞之眼”更是获得Cyber Defense Magazine《网络防御杂志》颁发的CyberDefense Global Awards奖项，是首次荣获该奖项的中国信息安全企业。同时漏洞银行的“网络大数据计算分析与安全可信关键技术及应用”项目荣获上海市技术发明一等奖。
