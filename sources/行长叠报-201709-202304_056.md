# 漏洞银行实力入选上海市最具投资潜力50佳创业企业榜

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247494923&idx=2&sn=5acb997b766e97934af48d4a9e81cf61&chksm=9bcd5a61acbad3775a2c2f159f62f7bb43867783014efc01f59818c2d504fbfd3d65c1e1c8bd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247494923&idx=2&sn=5acb997b766e97934af48d4a9e81cf61&chksm=9bcd5a61acbad3775a2c2f159f62f7bb43867783014efc01f59818c2d504fbfd3d65c1e1c8bd&scene=27#wechat_redirect)

**2021年11月24日，“上海市最具投资潜力50佳创业企业榜”评选结果出炉。上海谋乐网络科技有限公司（简称：漏洞银行）荣膺入榜企业。**

  

始于2016年，在上海市经济和信息化委员会指导下，由上海市促进中小企业发展协调办公室、上海市中小企业发展服务中心、上海市投资促进服务中心、上海市国际股权投资基金协会、上海股权投资协会、上海市创业投资行业协会以及阿里云创新中心等各方共同举办的沪上双创企业评选活动。

  

今年，评选增设汽车、智慧城市、5G应用、数智产业等6项专业赛，吸引近600家创业企业和创客团队报名，赛事精准性和影响力显著提升。11月下旬，“上海市最具投资潜力50佳创业企业”评选正式启动，预赛得分前101名入围候选。经过专家评委团的背靠背盲选、服务云“网络人气投票”，并特别邀请专业征信机构对企业及主要创始人诚信情况进行尽职调查，最终产生“2021年上海市最具投资潜力50佳创业企业榜单”。

  

![](../Images/f2b1857ef1bb2d58664115bd74ee10bd.png)

  

据悉，漏洞银行自2012年创立以来，一直坚持核心技术自主研发，已经位列中国网络安全百强企业，漏洞银行推出的产品及服务已为近千家500强企业、上市公司、金融、互联网、物联网、政府、教育等行业客户提供解决方案，更先后为上合组织峰会、国际进口博览会等国家重大活动做网络安全保障工作。它是上海市信息安全行业协会副会长单位，上海市网络与信息安全监测预警共建威胁信息共享战略协作倡议发起单位，网络安全等级保护专业委员会成员单位，SHCERT网络安全应急服务支撑单位，CNNVD技术支撑单位。此外，它还与上海市网络与信息安全应急管理事务中心及上海市政府达成战略合作，成为首家为国家提供城域漏洞安全的网络科技企业。漏洞银行自主研发产品“漏洞之眼”亦获得Cyber Defense Magazine《网络防御杂志》颁发的CyberDefense Global Awards奖项，为首次荣获该奖项的中国信息安全企业。同时漏洞银行的“网络大数据计算分析与安全可信关键技术及应用”项目荣获上海市技术发明一等奖。

未来，漏洞银行将继续与全球数万名网络安全专家协作，不断通过创新的产品应用，力求打造“先进威胁发现”第一品牌，助力企业在数字化转型中安全驰骋，为社会创造更多的价值。
