# 上海谋乐网络科技（漏洞银行）荣膺2021上海国资国企数字化转型创新大赛数字底座赛道一等奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247493571&idx=1&sn=c5dc9bf23c3380b453050d7cec150f0b&chksm=9bcd50a9acbad9bf590d9a0debe2eb2449cf52063a63c610db00881050bd19a5efac5de241be&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247493571&idx=1&sn=c5dc9bf23c3380b453050d7cec150f0b&chksm=9bcd50a9acbad9bf590d9a0debe2eb2449cf52063a63c610db00881050bd19a5efac5de241be&scene=27#wechat_redirect)

7月16日，由上海市国有资产监督管理委员会、上海市经济和信息化委员会和上海市科学技术委员会联合主办的“共创数字未来—2021上海国资国企数字化转型创新大赛”数字底座赛道成功结赛。

  
上海谋乐网络科技有限公司凭借“**基于先进威胁的智能检测与防御一体化安全平台**”项目，荣获本届大赛创新卓越奖（一等奖）。

![](../Images/624a490ede73e116cac029591a8f9e16.png)7月16日当天上海谋乐网络科技（漏洞银行）与上海市信息投资股份有限公司现场签约了上海顶尖国企数字城市转型战略合作协议，在城市数字化转型相关的数字新技术体系、数字新底座、数字新应用场景等领域形成生态合作伙伴关系，共同拓展发展空间，共创数字化转型美好未来。![](../Images/fc1786be2eed107a643ce0a01eade4c4.png)2021上海国资国企数字化转型创新大赛数字底座赛道聚焦网络和算力、数据和平台、数字信任3个领域场景，面向人工智能公共服务的算力资源基础架构、基于隐私保护的数据要素流通基础设施、基于区块链的数字信任应用等15个方向。本赛道比赛共吸引了来自全国近250个项目报名，囊括了不同地区、不同规模的国企、外企、科技型中小企业、科研院所等企业组织。  
![](../Images/7853897fa33525c02451b7d6fa5fed37.png)上海谋乐网络科技从250个项目中脱颖而出，与西门子中国、同济区块链研究院、平安智慧城市等20个项目团队共同挺进决赛，经过两天的决赛路演，最终获此殊荣。  

  

漏洞银行（BUGBANK）是上海谋乐网络科技有限公司旗下的知名网络安全品牌，也是“开放安全”理念的提出者和倡导者。漏洞银行产品线定位于“黑客社群与AI云安全”，与全球上万名网络安全专家协作，为全球企业提供充分的安全技术保障，包含前沿的AI入侵、AI免疫、城市蜜罐、零时差漏洞发现、黑客溯源、流量分析与应急响应等产品与服务，漏洞银行在业内率先提出的AI攻防科技和联合诊断服务，为企业提供成本与收益的最佳模型，助力企业基业长青。先后参与两会、十九大、上合组织峰会、国际进口博览会等国内重大活动的安全保障工作。为上海市信息安全行业协会理事单位，上海市网络与信息安全监测预警共建威胁信息共享战略协作倡议发起单位，网络安全等级保护专业委员会成员单位，SHCERT网络安全应急服务支撑单位，CNNVD技术支撑单位。2018年，公司自主研发产品“漏洞之眼（BUGEYES）”获得Cyber Defense Magazine《网络防御杂志》颁发的Cyber Defense Global Awards奖项，是首次荣获该奖项的中国信息安全企业。2019年公司自主研发产品“漏洞之眼（BUGEYES）”荣获Info Security Product Guide《信息安全产品指南》颁发的全球卓越奖金奖。
