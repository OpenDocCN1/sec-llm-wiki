# 漏洞银行入选“2020年度上海市网络与信息安全服务单位推荐名单”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247492565&idx=1&sn=66190d1501ec4eca9c77dd3b7237fa70&chksm=9bcd54bfacbadda91dbecae39508422063461b97e1ac9358d7403ce4fcffbb566b24194a1f2d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247492565&idx=1&sn=66190d1501ec4eca9c77dd3b7237fa70&chksm=9bcd54bfacbadda91dbecae39508422063461b97e1ac9358d7403ce4fcffbb566b24194a1f2d&scene=27#wechat_redirect)

为进一步加强行业自律，增强各网络与信息安全服务单位的服务能力，促进服务单位健康有序发展，上海市信息安全行业协会对外公布了**“2020年度上海市网络与信息安全服务单位推荐名单的通知”**。经多方专家严格评审，最终产生36家2020年度上海市网络与信息安全服务推荐单位。漏洞银行能够入选上海市网络与信息安全服务单位推荐名单，始终秉承“创造未知，惠及世界”的企业价值观，坚持以技术创新为企业发展核心，从网站安全评估、渗透性测试、安全咨询、等保整改咨询、信息安全建设解决方案、安全运维，安全培训与应急响应等多方面为行业客户提供专业的技术服务方案。能够获得此次殊荣，我们将不忘初心，不负业内以及广大客户的厚爱，再接再厉，为更多企业网络安全保驾护航。

**上海谋乐网络科技有限公司**成立于2012年7月，由一支充满激情与创造力，并有着丰富安全及互联网经验的团队成立，旗下拥有漏洞银行安全品牌，同年完成天使轮融资。公司总部设立在上海，服务全国，现主要服务于金融、证券、互联网、电商、政府等行业。2013-2015年成为全国创新创业大赛十强公司，ISG全国信安大赛技能赛第一名。2016年，与上海市网络与信息安全应急管理事务中心及上海市政府达成战略合作，作为公安部备案平台，成为为国家提供城域安全的网络科技公司。2018年，被美国顶级网络安全投资咨询机构 **Cybersecurity Ventures** 纳入“中国最热门最具创新力信息安全公司”榜单。

  

自创立以来，已获**上海高新技术企业**称号，**上海专精特新企业**称号，先后通过ISO9001，ISO27001资质认证，中国信息安全认证中心信息安全服务资质认证（信息安全应急处理服务），中国信息安全认证中心信息安全服务资质认证（信息安全服务风险评估），中国信息安全认证中心信息安全服务资质认证（信息系统安全集成服务），中国信息安全认证中心信息安全服务资质认证（信息系统安全运维）等多项网络安全服务资质。此外，一直积极参与国家重大活动安保，先后参与**两会**、**十九大**、**上合组织峰会**、**国际进口博览会**等国内重大活动的安全保障工作。

  

目前已经成为上海市信息安全行业协会理事单位，上海市网络与信息安全监测预警共建威胁信息共享战略协作倡议发起单位，网络安全等级保护专业委员会成员单位，SHCERT网络安全应急服务支撑单位，CNNVD技术支撑单位。2019年，公司自主研发产品“**漏洞之眼（BUGEYES）**”获得Cyber Defense Magazine《网络防御杂志》颁发的CyberDefense Global Awards奖项，是首次获得该奖项的中国信息安全企业。2019年获得Info Security Product Guide《信息安全产品指南》颁发的全球卓越奖金奖。

  

于2015年获得软银中国（SBCVC）A轮投资，2017年获得普华资本千万级别B轮融资。被选入福布斯中国非上市公司潜力企业榜，胡润百富2018中国最具投资价值新星企业百强榜，凭借1774%的三年增长率，入选**德勤中国高成长高科技企业50强**，2019年入选**微软加速器上海五期初创企业名单**。
