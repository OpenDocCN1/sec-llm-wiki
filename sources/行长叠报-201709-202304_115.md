# 漏洞银行创始人、CEO罗清篮获评“上海领军人才”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247492536&idx=1&sn=88c588ddb6a1c165e3e38be8379b166e&chksm=9bcd54d2acbaddc46b043eacfad82ba9afc3fbb8f53654d155720852ac63b0bf7eb0cd4ef3e5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247492536&idx=1&sn=88c588ddb6a1c165e3e38be8379b166e&chksm=9bcd54d2acbaddc46b043eacfad82ba9afc3fbb8f53654d155720852ac63b0bf7eb0cd4ef3e5&scene=27#wechat_redirect)

  

近日，上海市人社局公布2019年上海领军人才培养计划名单，经申报推荐、形式审查、专家评议、公示等环节，上海谋乐网络科技有限公司（漏洞银行）创始人、CEO罗清篮成功入选，并获评**“上海领军人才”称号**。

  
![](../Images/606eef0f891cdb5daa7b83a8a2bab4a3.png)

 ☉ 漏洞银行创始人、CEO罗清篮

  
  

![](../Images/97f08aba5762d3d8647e41cb283d759a.png)  
上海领军人才由上海市委组织部、上海市人力资源社会保障局组织开展，是上海着眼于未来建设创新型城市而实施的一项高层次人才和创新团队的培养计划。该计划集聚和培养一批站在各领域科技前沿、具有国际视野和产业化能力的领军人才，建设创新创业人才高地，激发全社会创新创造活力。列入培养计划的人员，各级党委、政府相关工作部门、行业主管部门和领军人才所在单位会根据领军人才的具体特点和实际需要，制定有针对性的培养目标和培养措施，为领军人才发挥作用、个人及团队成长创造更为有利的条件。  
此次上海领军人才评选拔需经过层层选拔，候选人企业市场潜力巨大，发展前景好，拥有多项发明专利或自主知识产权的创新成果，科研技术水平应处于国内外行业领先地位，并具有明显的持续创新能力或创新成果转化能力。  
漏洞银行成立于2012年，目前已发展成为国内最大的漏洞发现平台之一，目前企业入选**上海微软加速器**，线上服务企业数量超过**6000家**，累计发现高危漏洞超过**43000个**，其中高危漏洞检出率**超过57%**。在多态式安全防护(Polymorphic security)，人工智能漏洞挖掘与防御(AI vulnerability detection and defense)，云计算防护(Cloud computing protection)，反自动化攻击(Anti automation attack)，区块链安全技术(Block chain security technology)等多个前沿领域都有着创新性突破。2018年，漏洞银行被美国顶级网络安全投资咨询机构Cybersecurity Ventures评价为**“中国最热门最具创新力信息安全公司”**之一，凭借其高速成长，被德勤中国评选为**高成长高科技50强**，福布斯中国也将漏洞银行纳入**“中国非上市公司潜力企业”榜单**。快公司(Fast Company)给予了漏洞银行**中国最具创新公司50强荣誉**。2019年，在投资界有着“硅谷圣经”的科技期刊《Red Herring》将漏洞银行纳入**Red Herring Top 100 Asia**名单，对其创新价值和企业价值给予了肯定。漏洞银行将会持续迭代产品及商业模式，通过技术创新不断为我国的网安事业添砖加瓦。
