大家好，我是小编。


今日凌晨，微软RDP远程代码执行漏洞（CVE-2019-0708）的Metasploit利用模块被公开，其影响力巨大，对行业来说又是一场不小的“地震”。


2019年5月14日，微软应急响应中心发布一篇关于微软RDP（远程桌面服务）远程代码执行漏洞的预警，该漏洞威胁等级严重，该漏洞远是预身份验证且无需用户交互，破坏力巨大，如果利用稳定，可能构成蠕虫级安全威胁。


微软将该漏洞的破坏力拔高到2017年Wannacry 的高度：


In other words, the vulnerability is ‘wormable’, meaning that any future malware that exploits this vulnerability could propagate from vulnerable computer to vulnerable computer in a similar way as the WannaCry malware spread across the globe in 2017.
MSRC


2019年9月7日，GitHub上有开发者公开了该漏洞的Metasploit利用模块，随着工具的扩散，预计我国将有数百万设备受到该漏洞威胁，已明确构成蠕虫级安全威胁，破坏力或将匹敌甚至超越2017年的WannaCry勒索病毒。


漏洞主要影响的设备为Windows 7、Window Server 2008以及微软已不再支持的Windows 2003、Window XP操作系统。


据悉，我国依旧有大量设备正在使用上述操作系统，一旦该漏洞被稳定利用，其蠕虫级的破坏力将对我国数百万设备产生巨大威胁，受波及的个人和企业或面临巨大损失。


补丁修复：


目前微软已经发布了漏洞补丁，漏洞银行建议用户立即进行相关升级：


  • https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2019-0708#ID0EWIAC


  • https://support.microsoft.com/en-us/help/4500705/customer-guidance-for-cve-2019-0708


临时解决方案：


  1. 若用户不需要用到远程桌面服务，建议禁用该服务。


  2. 开启网络级别身份验证(NLA)


  3. 关闭TCP端口3389的连接，或对相关服务器做访问来源过滤，只允许可信IP连接。
