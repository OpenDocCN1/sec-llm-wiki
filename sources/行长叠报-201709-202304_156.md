# 章莹颖事件后，我们来聊一聊暗网的绑架

**01**

2019年7月18日，这是个让人感到无力的一天。  

长达两年多的章莹颖案，在经历了繁琐而漫长的司法程序后，终于宣判了。  

**绑架章莹颖并用极其残忍手致其死亡的罪犯，****最终免于死刑****，被判处终身监禁。**

**![](../Images/c69068ae4d65a5cb90f3a9102d14cf7a.png)**

图片来源：网络

章莹颖遇害的第769天后，12名陪审员，8个多小时的审议，2人反对，换来了这个让人苦涩的结果。  

陪审员对克里斯滕森的怜悯彰显了他们人性的光辉。

而杀人凶手从始至终，没有对章莹颖和她的家人说过一句对不起。

**得知判决结果时，他对母亲面露微笑，和自己的辩护律师拥抱。**

如今，庭审已经结束，克里斯滕森仍然拒绝说出章莹颖遗体的下落。

章莹颖父亲说：**如果你的灵魂中还残留任何人性，请帮助结束我们的煎熬，请让我们带章莹颖回家。**

章莹颖男朋友说：这一结果是在鼓励犯罪。它意味着，一个吸毒又酗酒的孤独的人，可以用一切残忍手段，想杀谁就杀谁，而不用付出生命的代价。

章莹颖的母亲由人搀扶着，一句话也讲不出。

![](../Images/8c8b30ffddcb7f54efcb5ea5785b8a8c.png)

图片来源：澎湃新闻  

我们回顾一下章莹颖案的整个时间线。

![](../Images/9de4ddfed0661a8e881ce005e2952763.png)图片来源：澎湃新闻

早在章莹颖失踪案调查的过程中，FBI在克里斯滕森的手机上追踪到他常浏览的一个“**变态社交网站**”。

这个网站是一个**以捆绑、虐恋、恋物癖和另类性癖爱好者聚集的社交网络**，有近600万名注册用户，分享了超过三千万张相关主题的图片和四十万段录像。

很多人纷纷猜测，克里斯滕森的犯罪是不是和**暗网**有着千丝万缕的联系。

![](../Images/3bb59997eba0b54c1430d243ca01bf81.png)

图片来源：网络  

**02**

**什么是暗网？**

暗网，又被叫 Dark Web，是一种用特殊软件授权访问的地下网络。暗网的特性就是“绝对隐形”，网站隐形，用户身份隐形，IP地址隐形。现如今的暗网上充斥着各种毒品、军火交易、走私、器官买卖、人口贩卖、杀手、 黑客、邪教、恐怖组织、儿童SE情、X变态 、金融犯罪、洗黑钱等。

暗网是一个真正无法无天的世界，他将人性的贪婪与恶展现的淋漓尽致。

实际上，人口贩卖，一直是暗网主营业务。

> 由联邦调查局(FBI)公布的NCIC报告显示，2016年共有**647435**个登记有案的失踪人口，比前年增加了约2%。
> 
> 此外，根据“失踪人口境遇”(The Missing Person Circumstances, 简称MPC)数据指出，2016年中曾报失踪的64万多件纪录中，MPC收录了其中315995件。

来源：中国新闻网

![](../Images/3f1d51b7bbf793122a2b3448f4a9fd9d.png)

（图片来源网络丨贩卖人口的用途数据）

《先驱太阳报》也曾报道，在澳洲的失踪人口中，

仅维州每年就有约9000人失踪，而全澳至少每年有3.5万人失踪。

这些人去哪了呢？

这让我想起了在暗网上发生的一起“**拍卖**”事件。

2017年7月16日，暗网上有一场拍卖正在进行。

而这个被拍卖的，**是当时年仅19岁的模特Chloe**。

7月初，Chloe她接到了一个拍片邀约。对方表示，工作室在意大利米兰，需要她过去一下，报销路费，而且安排好了住宿。

Chloe和经纪公司都没察觉出什么问题，于是到了约定好的时间，Chloe就直接去了米兰。

然而，当Chloe一进工作室，就有两个男的冲了上来。

一切发生的太快，她还没来得及做出任何反应。一个人已经从后捂住她的嘴巴，另一个戴蒙面头套的人同时在她右手臂注射了一针麻醉剂，接着Chloe被塞进麻袋，装进了汽车后备箱。

![](../Images/8185e38c0101d4e80b579c268632f295.png)

（警方还原Chloe被塞进行李箱的场景）

当我醒来时，我发现我在一辆车的后备箱里，手腕和脚踝都被拷着，胶带粘着我的嘴，我被塞在一个袋子里，只能通过一个小洞呼吸。

醒来时，她的嘴上封着胶带，手腕和脚踝都戴着铐镣。

![](../Images/c757beb653c1be3986303ee04cdf2041.png)

艾琳被带到意大利都灵省的一个偏僻村庄，这里被称为鬼城，有很多的度假屋，但是平时小镇的居民却很少。

绑架者把她关进了一间小屋，铐在一个衣柜旁边，还给她拍摄了各种照片。

![](../Images/fcdfb6a6a5523f680e744f173a8726d3.png)

（Chloe被关押的小屋）

一周后，她的图片出现在暗网上。

![](../Images/90289c6811f86d6ca05c396e5d3d933c.png)

而在后来披露出的拍卖信息中，卖家还有着一套成熟成型的说辞以及对于其“商品”的品质保证。

![](../Images/6fb57fd697d252d7527d8b32371528e8.png)

> “我们所有的女孩经过医生检验，不是变性人而且是非常纯种。”
> 
> “我们不出售有传染性疾病，有性病或者怀孕，年轻的妈妈。”
> 
> “我们的女孩可以全球托运，我们有专门的托运承包商。欧洲境内包邮。”
> 
> 甚至有更加骇人的一条信息：“如果你有需求，我们可以绑架特定的目标。这个价格比较贵，尤其是欧洲境外的。”

这个专门绑架少女，举行拍卖，而且负责托运的庞大的人口贩卖集团，叫做**黑死病集团（Black Death）**。 

最终黑死病集团没有将Chloe进行拍卖而是将其释放，原因是Chloe是一个两岁孩子的妈妈。于是在和其经纪人就赎金的事情谈妥之后，他们把Chloe运到英国驻米兰大使馆。

7月17日，绑匪将艾琳带到了英国驻米兰的大使馆，被埋伏着的警察逮个正着。

![](../Images/e3147b61bbfd0c221c08b2363d67e63f.png)

（嫌犯照片）

被解救的Chloe后来在电视上接受采访时称：

> “其中一个劫匪告诉我，在过去5年他就挣到超过1760万美元，大部分的女孩将出售到阿拉伯国家。当买家厌倦了这个女孩之后，可能会被拿去喂老虎。”

显然，一个嫌犯被抓获，并不能让我们放下心，像这样被绑架的女孩，可能还有更多未被发现。

![](../Images/f728ada497e4de38deb977f8e230e453.png)

![](../Images/1cdea3581cbda1f36e32cf012d412688.png)

**这些女孩像一件物品一样，被标上身高、体重、三围，国家、绑架地等信息，穿着裸露，在暗网上进行拍卖。**

而等待那些女性的，却是不容反抗、生不如死，极其变态的折磨。

**04**

在暗网笼罩的世界里，究竟还有多少丑恶，我们不知道。

我们甚至不知道那些他们把活人当作玩具的心理阴暗的变态，是不是就在我们身边。他们也许普普通通甚至光鲜亮丽，但在阳光照不到的角落，他们发泄着恶毒本性的魔鬼。

**最后：**

愿章莹颖的在天之灵能够安息。愿你保护好自己。

愿你看清了生活的真相之后,依然热爱生活。

****![](../Images/7dfb0d5754f6b1de4256c6f770a87973.png)****

“**要时刻保持警惕心**“，这句话怎么强调都不会过分。

1，不搭**陌生人**的车，不打黑的士；

2，上车时向好友**分享**行程；

3，下车后打电话**报平安**；

4，乘车途中尽可能与他人**保持联系**；

5，尽可能提及自己的**位置**；

6，不要孤身坐在**副驾驶位**，要坐司机后方位置；

7，在车上不要自顾自地**玩手机、听音乐甚至睡觉**；

8，可以打开手机导航，注意**观察司机的行驶路线**；

**如果你要出国游玩的话，请切记：**

1，出国玩，尤其穷乡僻壤，最好**抱团**。

2，住当地**好**一点的酒店，不要省钱住便宜的旅馆。

3，在国外，尽可能不要**夜晚**出门。

4，不要上**陌生人**的车，自称是**警察**的也要小心。

5，不被**陌生人**带路，不懂的话，去**警察局**问警察。

6，不要随意**喝**别人的东西。

7，呆在**人多**的地方。

8，晚上住酒店，**反锁**死门，不认识的人，打死不开门。

9，记住你护照上外交部的紧急求救电话，有情况不要怕麻烦**中国大使馆**。

10，熟人也要防，**同胞**不一定不会害你。
