# 远程患癌，代码杀人：是黑客还是死神？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247491755&idx=1&sn=ee0e13ff755b8fa8051b32389be9e175&chksm=9bcd57c1acbaded7bfa4dbb525812ff499a336bce8def23ebb6071324e3c848617228aa7876c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247491755&idx=1&sn=ee0e13ff755b8fa8051b32389be9e175&chksm=9bcd57c1acbaded7bfa4dbb525812ff499a336bce8def23ebb6071324e3c848617228aa7876c&scene=27#wechat_redirect)

  

提起黑客，大家会想到什么？  

会盗QQ号！  

他们可以入侵电脑，随意浏览私人信息、破解银行卡；

有的还可以入侵监控摄像头，偷拍甚至还上传到色情网站；（[防偷拍全靠消费者？我觉得没这个道理](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247491748&idx=1&sn=c27a5f4617242414f7962d43f5d454d4&chksm=9bcd57ceacbaded840ee810245de09a7520273f18c719313f04dc7e1b4d553f0d8e649bfcc8e&scene=21#wechat_redirect)）

有的甚至可以入侵五角大楼系统，让FBI毫无办法。

但是如果有人告诉你，**黑客可以“操控”一个人的生命**，你相信吗？  

让我们来看一看小明的故事。

**1，小明的心脏**

有一天，小明因为心脏功能障碍安装了**心脏起搏器**。医生告诉小明，这个小玩意儿通过脉冲发生器发放由电池提供能量的电脉冲，通过导线电极的传导，刺激电极所接触的心肌，使心脏激动和收缩，从而达到治疗由于某些心律失常所致的心脏功能障碍的目的。

简单来说，可以让小明继续活下去。  

![](../Images/0aed956ae8741f81460c6e38ae231beb.png)

但有一天，有一个黑客突然入侵了这个小装置。

他发现，他竟然可以**控制小明心脏起搏器的震颤频率，甚至能让其发出830v的高压电击。**  

小明生命掌握在他人手里，并且可能随时会被终结。而这一切，全部取决于入侵黑客的心情……

有一天，这个黑客吃到了一个肉粽子，这让他十分不爽。

于是这个黑客便控制小明的心脏起搏器发出830v的高压电击。

![](../Images/4508780468c4c4feb6834a0b772c520b.png)小明，卒。

听起来很可怕。

然而更可怕的是，这不是危言耸听。

如果你没有听说过一个叫**巴纳拜·杰克(Barnaby Jack)**的天才黑客，那至少也应该听说过他**让自动提款机疯狂吐钞票**的故事。

![](../Images/50da1345e1238d3905ff847faa87c122.png)

在2010年“白帽”黑客会议上，杰克利用他独创黑客技术令自动提款机狂吐钞票。这一事件让他一跃成为全球最牛的“明星黑客”。

然而我们今天所要讲的，是他的另一项技术—“**遥控杀人**”。

在破解自动取款机3年后，巴纳拜·杰克又宣称，他已经发现了多家厂商生产的**心脏起搏器的安全漏洞**。并且表示要在即将开幕的“白帽”黑客会议上，展示一项惊人的“黑客绝技”——**在9米之外入侵植入式心脏起搏器等无线医疗装置，然后向其发出一系列830V高压电击，从而实现“遥控杀人”。**

杰克解释称，近几年生产的心脏起搏器一般都设有无线接收装置，以便可以在10米至15米范围内进行遥控调节，这正好给了黑客可乘之机。

杰克发现，用无线输入特定命令之后，起搏器就会输出其序列号和型号，由此可以控制体内的起搏器。

杰克开发了一款名为“电鳗”的程序，可以扫描一定范围内所有的心脏起搏器并入侵。杰克甚至认为，**可以直接入侵生产商的软件服务器**，将“后门程序”植入他们生产的所有起搏器，并使其像病毒一样传播开来。

然而，就在巴纳拜·杰克就要展示这项绝技之前，他突然在美国旧金山的家中离奇死亡。

他的死亡引发了人们的各种猜想，也引起了人们对于医疗设备漏洞的关注。

**2，小明的静脉**

有一天，小明因为吃坏了肚子，需要去医院**输液**。

![](../Images/6d1dff94e8dc8d84e1743cdd823378bb.png)

医院专门给小明配备了最先进的**智能输液系统**，这套系统可实时监控各个病房内病人输液的容量、速度、剩余时间等等。并且还能根据设定，实时控制输液速度。同时，一旦出现输液异常等特殊情况，可以及时报警告知护士停止输液，最大化保护患者。

![](../Images/58d6a213d41ac6506f3c30026e4f54f5.png)

图片源自网络

小明一边听一边兴奋的点头，他觉得自己又见证了一项医疗发展史上的奇迹。

就在这个时候，这套系统就被一个黑客入侵了。

这个黑客惊奇的发现，他可以通过这个系统的某些漏洞，来**控制输液泵所分配的药物的剂量以及药物输液速度。**

由于这个黑客今天吃了一碗甜豆腐脑，这让他心情十分不爽。

于是这名黑客决定在这套智能输液系统里随机选择一个人，**改变他的药物剂量和输液速度……**

![](../Images/4508780468c4c4feb6834a0b772c520b.png)小明，卒。

听起来挺可怕吧？

然而更可怕的是，这不是危言耸听。事实证明，黑客可以远程访问和操纵在急性护理环境中使用的**注射器输液泵**，从而影响设备的操作。

美国政府在2019年6月13日透露，AlarisGateway医疗工作站中的两个安全漏洞可能被劫持。输液泵有可能被黑客通过医院网络侵入，**造成给药过量或不足**，从而可能对患者造成致命伤害。

其实早在2009年，杰罗姆·拉德克利夫（Jerome Radcliffe）在黑帽大会上便演示了如何攻击他自己的胰岛素泵和连续葡萄糖监测器。

攻击仅需知道泵的序列号，黑客利用射频技术的漏洞可以**用无线方式关掉胰岛素泵或加大胰岛素剂量令患者毙命。**

**除了能控制你的心脏起搏器之外，黑客还可以随心所欲的“控制”你的身体情况。**

**3，小明的肺**

有一年中秋节，抽烟多年的小明感觉肺部非常不舒服，于是便去医院做检查。医生二话没说，先让他去做了**CT扫描**。

就在这个时候，一个黑客入侵了小明的CT扫描机。这个黑客惊奇的发现，他竟然**修改3D医学扫描结果**。

由于这个黑客早上吃了一个咸月饼，这让他心情十分不爽。

于是他就删除了小明CT扫描结果中癌症的证据，最终导致了医生诊断失误：小明的肺部没有任何问题。

兴高采烈的小明回到家之后饱受病痛折磨，但却得不到相应的治疗。

![](../Images/4508780468c4c4feb6834a0b772c520b.png)最终，小明卒。

可怕的是，这些事情并非不可能发生。

据外媒报道，来自以色列本·古里安大学（Ben-GurionUniversity）和索卡大学医学中心研究人员已经证明：**黑客可以入侵相关医疗设备，来修改3D医学扫描结果。**并且可以从中添加或删除包括动脉瘤、心脏病、血块、感染、关节炎、软骨问题、韧带撕裂以及大脑、心脏或脊柱的肿瘤等各种疾病。

据研究人员称，一个问题是PACS和DICOM服务器经常**暴露在互联网上**。另一个问题是，在很多情况下，医疗图像数据**没有经过加密**就通过网络传输，这给中间人(man-in-the-middle, MitM)攻击和篡改数据提供了机会。

攻击者可以通过互联网访问PACS，直接对其进行攻击，或者他们可以先访问目标组织机构的网络，然后从那里发起攻击。

研究人员表示，攻击甚至在每项测试中都**骗过了最先进的肺癌筛查模型**。  

那么，为什么有人要发起这样的攻击呢？

研究人员列出了几种可能的动机和目标**。****他们认为修改某人的扫描结果并造成误诊可用于获得某人的工作、改变选举、破坏或伪造研究成果、控制数据获取钱财、保险欺诈，甚至进行谋杀或恐怖主义活动。**

例如，如果攻击者在政治候选人的CT扫描中添加癌症证据，他们就可以让目标个体退出竞选。同样的技术可以让某人放弃工作或领导角色。

想象如果有一天，小明要竞选美国总统。但当小明在占据压倒性优势马上就要赢得大选的时候，小明的对手突然拿出了他在医院的诊断报告，报告显示小明得了癌症……

![](../Images/4508780468c4c4feb6834a0b772c520b.png)不用想，小明总统的宝座肯定是保不住的。

![](../Images/a2efd8beee050d4e0cc0eb0a729513ca.png)

在最糟糕的情况下，黑客还可以删除严重疾病的证据，这可能导致该人因未接受适当治疗而死亡。

**最后：**

医疗设备为人类带来的好处是不容忽视的，它能为患者和医疗机构制定医治方案提供信息支撑。

但是，医疗机构必须意识到这些设备所带有的漏洞，如同人类身体携带的病菌给人带来健康威胁一样。

**为了让小明能够健康的活下去，医疗机构必须对其IT安全给与足够的重视。**
