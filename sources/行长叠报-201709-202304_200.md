# 惊爆！万豪旗下喜达屋约5亿用户数据泄露，数据库被“脱裤”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247491162&idx=1&sn=ee963e84d12c4323c0c5ec27c30263ad&chksm=9bcea930acb9202626fbce0ca462dd4f0fe5008de965d959e98a8a04786d6c683d5771b7d7f9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247491162&idx=1&sn=ee963e84d12c4323c0c5ec27c30263ad&chksm=9bcea930acb9202626fbce0ca462dd4f0fe5008de965d959e98a8a04786d6c683d5771b7d7f9&scene=27#wechat_redirect)

大家好，我是小编。  

  

今儿给大家说个大新闻，**继华住之后，万豪再爆遭数据泄露！**

![](../Images/c908a224db8d5b327411d8fa7a3aa7fc.png)

  

据CNBC报道，**万豪旗下，喜达屋5亿条数据泄露，数据库中宾客信息在未授权的情况下被访问。**

  

11月30日晚8:35，万豪官方微博发布声明，称2018年11月19日万豪国际调查发现，2018年9月10日及之前，喜达屋旗下酒店预订数据库中的宾客信息曾在未经授权的情况下被访问。  

![](../Images/a8407ae7b78494c5c3c993d2fb0391a8.png)

  

**简单来说，就是你的姓名，电话，身份证号等核心隐私数据已经被泄露。**  

  

喜达屋旗下酒店品牌包括：W 酒店、瑞吉酒店、喜来登酒店与度假村、威斯汀酒店与度假村、源宿酒店、雅乐轩酒店、豪华精选酒店、臻品之选酒店、艾美酒店与度假村、福朋喜来登酒店与设计酒店。（其中有你们住过的酒店吗？）

  

据万豪公布的信息数据来看，泄露数据包含2018年9月10日或之前所有在喜达屋预订的超过5亿名客人的隐私信息，其中3.27亿人的**姓名、邮寄地址、电话号码、电子邮件、护照号码、SPG俱乐部账户信息、出生年月日、性别、到达与离开信息、通信偏好等****核心隐私****可能被泄露。**

  

**甚至，对于个别客户，其支付卡号和支付卡有效期可能被泄露。**

  

虽然万豪方表示，支付卡号已通过高级加密标准（AES-128）加密，但是却无法保证是否有第三方已经掌握了解密的密钥。翻译一下，就是说万豪表示他们对支付卡号等数据加密了，但是不知道别人能不能解密。

  

万豪酒店在声明中表示，自2014年，就存在第三方对喜达屋进行未经授权的访问。在2018年9月份才发现被入侵的事实。也就是说整整4年，喜达屋的核心数据处于裸奔状态。  

  

受到该事件影响，万豪的股价已经受挫，跌幅近6%。
