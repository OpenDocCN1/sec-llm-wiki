# 高科技“奥斯卡”奖揭晓，漏洞银行入选德勤“中国高科技高成长50强”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247491127&idx=1&sn=5b249576c315a8d0e6db34d9a8259b91&chksm=9bcea95dacb9204b710c1c667166400568393c2bcaf49642737523f16abb4acb3dbe3add14cb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247491127&idx=1&sn=5b249576c315a8d0e6db34d9a8259b91&chksm=9bcea95dacb9204b710c1c667166400568393c2bcaf49642737523f16abb4acb3dbe3add14cb&scene=27#wechat_redirect)

2018年11月20日，德勤“2018中国高科技高成长50强暨明日之星颁奖盛典”在北京举行。**上海谋乐网络科技有限公司（漏洞银行）以1774%的三年收入增速位列“德勤2018中国高科技高成长50强”名单第38位。**  

![](../Images/c09e9600cb2f992de05a4415dbf652c3.png)

漏洞银行CEO罗清篮出席颁奖典礼

  

**漏洞银行**

**科技界颁奖盛典 见证中国网络安全新力量**

  

**德勤“高科技高成长50强评选”**是德勤主办的全球顶级成长企业评选。1995年起源于美国硅谷，历时23年，每年在美国、英国、日本、澳大利亚、中国等数十个国家同步举行。2005年进入中国后，现已成功举行十三届。这一评选因其指标的严格性以及对企业未来发展的精准预测价值，而被誉为**“发现未来独角兽的平台”**、**“全球高成长企业的标杆”**、**“高科技企业的奥斯卡”**，是全球范围内**最具权威性、投资指引价值的评选项目之一**。

  

德勤历届榜单中涌现出**苹果、谷歌、阿里巴巴、脸谱、腾讯、百度、**等一批领军企业。参选“德勤中国高科技高成长50强”企业的条件包括：拥有自主知识产权或专有技术，并且该项技术为公司带来显著的营业收入等。评选依据为企业过去三个财年的收入增长率。本次在与互联网众领域企业的竞争中入选本次名单，正是德勤对漏洞银行在网络安全领域技术创新能力及持续发展潜力的认可。

![](../Images/8f2331d48038ccc0a6ba9ac24e9df10b.png)

  

![](../Images/a2e6a0416bb51d1b033cb16d296a0445.png)

  

**漏洞银行**

  

**专注技术创新 打造完善安全生态**

  

自漏洞银行创立至今，已实现跨越式的增长速度，**三年营收增长率达至**1774%****，是本次名单中为数不多的网络安全企业。企业收入的增长源自企业对行业态势和自身实力的有效把握和着力提高。值此行业发展新潮涌起之际，为进一步推动行业发展、升级风潮，漏洞银行率先于业内提出“开放安全”理念，以此展开一系列自主创新产品战略部署。

![](../Images/6f7179b0b33298fb1af4b20dac440c7c.png)

  

基于“开放安全”一理念，漏洞银行引入人工智能、区块链等多项前沿技术，将既有安全技术产品与新兴技术适性结合，自主研发并正式推出了以漏洞之眼、CADC城域防御中心为核心的全方位立体防御矩阵产品线，将漏洞安全、城域安全、云安全等多个安全细分领域覆盖式纳入漏洞银行产品服务体系，形成一套有效针对多样化网络安全建设发展的安全服务生态闭环，迄今已为政府、企事业单位、医疗、教育等多个行业用户提供针对式安全产品闭环服务。由此漏洞银行得以进一步提高其在国内网络安全领域的市场份额，为下一步着眼国家网络安全建设推进、提升漏洞银行技术影响幅员起到良好的促进作用。

  

**漏洞银行**

**不变初衷 做优质安全服务**

  

长久以来漏洞银行一直以科技创新为企业发展核心。坚持发展核心，并大力提升技术服务能力，漏洞银行先后为上海合作组织峰会、党十九大会议、中国国家进口博览会等国家级重大会议活动提供网络安全保障服务单位，并圆满完成活动保障任务，安全技术能力及安全服务能力得到相关部门一致认可。为切实扩大用户网络安全受服务范围，漏洞银行先后与上海市网信办、高校联盟达成战略合作关系，让漏洞银行技术影响力、服务能力影响力深入到用户之间，进一步提高漏洞银行品牌辐射广度。

![](../Images/94f5f1c5f88c2ccf04db7fa0195b237d.png)  
![](../Images/ae077ba8d753027102b8e82a6fe3b1b9.png)

  

本次登入德勤2018中国高科技高成长50强名单，是漏洞银行继入列2018 Cyber Defense Global Award网络防御全球奖、2018 Cybersecurity Vventures最具创新性企业中国区榜单等荣誉之后，再次获得国际性荣誉，这是漏洞银行多年来坚持技术创新和实力沉淀的良好印证。在坚持技术创新的同时，漏洞银行还致力于安全服务能力的更新升级，为行业、为用户着重打造优秀的网络安全服务体验。在未来的发展路程中，漏洞银行希望通过进一步提升技术实力、技术服务实力，推动网络安全行业更深入发展，为国家网络安全防线建设贡献更多力量。
