# 任人收割？汽车车主隐私沦为“数据农场”

**蔚来汽车正大光明搜集车主隐私？小儿科，欧盟新规认定汽车数据本就归车企所有，不需要经过车主同意！智能化汽车隐私信息沦为“数据农场”。**

  

“奔驰车主爱火锅，宝马车主爱购物，凯迪拉克洗桑拿”，这是去年某软件流传出对名车的“调戏”，但是在这些戏言背后，却是透露出**可怕的隐私泄露事实**。

  

想象一下无论你去过什么地方都被记录在案，如果被某些人利用，专门在你经常去的地方设下诈骗陷阱，或者直接对你进行跟踪尾随，欲行不轨，还有的人直接找到你的家庭住址，生命财产危在旦夕......

  

奔驰车主喜欢去火锅店、飞机场、别墅等地点。

![](../Images/c6612c6d7c54a196f0cd706f7aba6b4e.png)

（图片来自网络，下同）

宝马车主喜欢去步行街、购物中心、商业园区等地点。  

![](../Images/a1864e5aaa4679cc6576c6c266110850.png)

  

沃尔沃车主比较文艺，喜欢去剧场、世界遗产、寺庙等地。  

![](../Images/ead565da17e8890ae8a639db00260c91.png)

  

汽车隐私泄露的新闻络绎不绝，不法分子为了窃取车辆的信息可谓无孔不入，从4s店获取信息，从车辆车架号、发动机号、车牌号等获取信息，**甚至汽车GPS定位信息都会泄露！**  

  

但是现在根本不用这么麻烦了，根据欧盟新规，不需要经过车主同意，**车企可以收集汽车产生的任何遥测数据，****并可以将其出售**给保险、营销人员和广告公司等。甚至，这些数据可能包含对车主定位的GPS信息。

![](../Images/b37bada983578247cbfe28ed6e183ae0.png)

  

也就是说，不法分子可以直接在车企官方处购买车主车辆的敏感信息，有些人会利用车主电话进行推销、打广告甚至是诈骗！**也****可能导致车主的车辆直接被盗窃，甚至威胁到车主自身与家庭的安全，之前就有车主泄露信息，被人找到家庭住址，直接导致入室抢劫的案件的发生！**

  

**“汽车数据属于车企”**

  

欧盟的新规设立的理由是，汽车的驾驶数据不是车主主观能动性创造的，而是由于客观存在的，因此不受新规版权保护，车企通过车辆的传感器可以收集任何汽车数据。

![](../Images/1ddd3ae59ae99732069b7c10806318e4.png)

 

而且对于车企来说，车企加工、整理了车辆的数据。这就属于创造性工作了，**因此这些数据属于车企的版权，车企有权利对这些数据进行买卖等等。**

  

**“不同意条款，你可以不买”**

  

这类“霸王条款”在国内汽车公司身上也有出现，像前段时间引发热议的，**“蔚来汽车用户毫无隐私”**事件就是典型案例。

![](../Images/555a957fbce19967d0fe8fe86b2142e3.png)

  

蔚来ES8作为“智能化”纯电动车，车上的10处摄像头（车外7个/车内3个），以及车内8个可以精准定位声源位置的隐藏式麦克风，车主在使用蔚来ES8的过程中所有**隐私都会毫无保留的上传**到蔚来中心。

![](../Images/0e29689ce022a8a9c1f303015b962b65.png)

  

这些数据包括车主的**车辆位置、行驶轨迹、车内和车外图像，外加车内所有的谈话，**甚至可以精确定位到哪位乘客说了哪句话。（也就是说，男人们再也不能在车里和情人约会了，再也不能在车里换衣服了......）  

  

蔚来声称这些数据可以帮助蔚来中心更好地了解车主车辆状态，更具针对性提供相关服务，但是如果这些数据发生泄漏后果不堪设想。

![](../Images/41148005bc1125445d6702d16da499ec.png)

  

比如蔚来汽车定位是中高阶层的社会精英，不排除会有用户在车里谈论商业机密，而这些用户的一言一行，乃至是他们的表情都会毫无遗漏地上传到蔚来中心，万一这些数据泄露，**被不法分子在黑市上买卖，造成严重的财产损失、身份被人冒用、还可能有人身危险。**

  

而蔚来汽车声称自己是“价值观驱动”的企业，**如果用户无法认同自己的价值观，那么为什么还要来购买蔚来汽车呢？****（？？？小美给一脚丫子）**![](../Images/590277ef242000bc99a5d9674a3458e2.png)

  

这些问题在智能化汽车出现之前，是没有必要担忧的，但是随着如今汽车越来越智能化，车主的隐私信息正一步步沦为任人宰割的**“大数据农场”**。  

  

你的汽车正静静看着你。
