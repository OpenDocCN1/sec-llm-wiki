# DEF CON China第一日精彩大拼盘！

**大家好，我是小编  
**

**今天是DEF CON China的第一日**

**小编漂洋过海**

**在现场发回了报道**  

  

早晨9点，小编准时到达DEF CON China的举办地点。

  

整个酒店还是十分气派的，在会场入口处，DEF CON标志性的绿色电路板已经树了起来。  

![](../Images/91ab0e6be7531f2ebe1528b5ddd5cc9f.png)

  

走进可以看到，一辆红色的汽车停在门口，如果不出小编所料，这应该就是car hacking village的实验小白鼠了。

![](../Images/4d9d8eec3f8ebc50359560a5851be6fb.png)

  

进入会场，DEF CON的style扑面而来。  

![](../Images/2d740dcbbad34cae7f7a9a4efd9c2f9a.png)

  

胸牌也是以电路板为核心设计元素，画出了一幅世界地图。帅气十足。  

![](../Images/ed2452be1722b2b34441e37e82d69d6b.png)

  

上到二楼，公共区域一共有3种玩具。可乐机，拳击器，游戏机。

  

可乐机已经在一大早就被各位黑阔破解了，**一毛钱买可乐不是梦。**

  

小编感到比较可惜的是，剩下的2款游戏机都没有接电，不然打完拳皇打拳击，应该是一种不错的体验。

![](../Images/c52e6e315122d492e4b41acccdfc2177.png)

  

因为议题在11点开始，这段时间小编也是抑制不住自己的好奇心，如脱缰的野马，开始在会场中狂奔。

  

此次DEF CON China的活动区域也是亮点多多，比如说**机器人斗殴**，用左右挥拳的方式，诠释最纯粹的暴力美学！  

![](../Images/351d6eb25ec4b10454c1a153133928b1.png)

  

你们以为下面的东西都是纸巾吗？**不好意思，这次还真不是。**

![](../Images/16bd156e5c36e7e46ba58976c62e07cf.png)

  

在分会场中，DEF CON China设置了焊铁区域，每个人都可以在这里焊接电路板，按照官方提供的说明书去制作一个小玩意儿。

![](../Images/fec740f6f2b3eb096225749365aed663.png)

  

黑客文化中非常重要的开锁文化也出现在了会场中，此次提供了四种类型的锁供大家体验，所以小编给他们来了一张全家福。

![](../Images/639f1b5bb778a99782799b1ddd45ee49.png)

  

在另一个区域，CTF大赛也开始进入准备的最后阶段，选手们已经入场，服务器的灯光一亮，总让人有一种迷幻的感觉。  

![](../Images/47f91cad77204bfc376968a90361b469.png)![](../Images/cd90ceb7565ef1f283527a84fdc8b21f.png)

  

在小编瞎逛的过程当中，还偶遇了**DEF CON的创****始人Jeff！**都说认真的男人最帅气，天知道小编是怎么在手抖的情况下拍出了这张不糊的照片的。  

![](../Images/60dc7e6cf5991a1d1ecac8d249bac5f7.png)

  

11点左右，小编来到主会场门口，人群已经聚集成了人墙，把入口塞的密不透风。小编这才发现完全低估了此次参会的人流量。为了主会场议题的正常进行，保安迫不得已开始限制进入。

  

小编也毫无意外的被拦在了外面。但是小编从万能的朋友圈中，找到了两张主会场的图，让大家一饱眼福。

![](../Images/6d4a640ac42991a5c0e872d21bc65957.png)![](../Images/7233c2c78b220a9cef8b34b4601f5c04.png)

  

下午，黑客集市开始慢慢热闹起来，DEF CON的文化衫，blingbling的胸牌开始陆续出现，一些黑科技也开始展现出他们的锋芒。比如这个奇形怪状的家伙，被称为**“WiFi仙人掌”**，它是一个被动无线监控设备，可以同时收听50个WIFI频道，并且能够捕获蓝牙无线数据。

![](../Images/02f7fa7797daf92692d9c054ace4d91e.png)

  

今天还是**“WiFi仙人掌”**的非完全体状态，它真正的形态据说是这样的，但是真正如何，还得等明天才能见分晓。

![](../Images/05d79c077091ce5e034aac2c479356ee.png)

  

由此可见，在DEF CON China接下来的两天日程中，一定不会缺乏精彩。漏洞银行小编，会及时通过直播和图文的形式，让大家了解最新信息。
