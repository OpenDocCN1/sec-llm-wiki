# 细数微软Patch Tuesday修补的十大漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247489345&idx=2&sn=4ce31466d22650a30ab24f34e033c6b2&chksm=9bcea02bacb9293dfc74ad595c2e58069a66514ed548702eacdf97784525d376142f62c37234&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247489345&idx=2&sn=4ce31466d22650a30ab24f34e033c6b2&chksm=9bcea02bacb9293dfc74ad595c2e58069a66514ed548702eacdf97784525d376142f62c37234&scene=27#wechat_redirect)

周二，微软和Adobe发布了一堆产品安全漏洞补丁，这些漏洞允许黑客绕过验证、窃取我们的个人信息等，下面就让我们来细数这次修补的十大关键漏洞。  

  

**01 ****Hyper-V：****CVE-2018-0959、CVE-2018-0961等**

![](../Images/6eb9e1d1d4462d054185df0f05d36161.png)

在Microsoft Hyper-V管理程序中的客户虚拟机中运行的应用程序可以转移到主机，并在其上执行恶意代码。这意味着运行在客户端虚拟机中的用户以及登录的用户可以接管其他虚拟机以及底层服务器。这些漏洞包含在CVE-2018-0959和CVE-2018-0961，后者涉及vSMB。这对于管理程序开发人员和管理员来说基本上是一场噩梦。

  

**02 ****Internet Explorer和Windows VBScript引擎：****CVE-2018-8174**

![](../Images/1f13befcf6091d2b26c39878f9a9866a.png)

VBScript引擎可以通过内存损坏在系统上执行任意恶意代码，为安装恶意软件铺平道路，包含在漏洞CVE-2018-8174中。

  

微软官方指出：

  

> “在基于Web的攻击情形中，攻击者可以托管一个旨在通过Internet Explorer利用此漏洞的特制网站，然后诱使用户查看该网站,或在Microsoft Office文档中嵌入标记为”安全初始化“的ActiveX控件。”

  

Edge中的Chakra脚本引擎也可以通过CVE-2018-0943利用邪恶的网页在访问所述页面的计算机上运行代码和恶意软件。

  

**03 ****Windows内核：****CVE-2018-8120、CVE-2018-8170等**

攻击者在易受攻击的系统上运行恶意软件，可以使用Windows内核（特别是Win32k组件）中的CVE-2018-8120错误获取管理员权限，以完全劫持设备。这只影响Windows 7和Server 2008。

  

但是，Windows 10受CVE-2018-8170（Windows图像处理系统中的权限升级）的影响，如果应用程序在内核中引发一个恶意攫取，它可以通过计算机获得管理员访问权限。

  

在各种版本的Windows中还存在其他内核级别的特权升级错误，例如CVE-2018-8897，CVE-2018-8134和CVE-2018-8124，可供应用程序和登录用户使用以获取管理员权限权利。

  

**04 ****Exchange和Office 365：****CVE-2018-8153**

![](../Images/762548c87ded3cce5a67f2c33da5bd6b.png)

Microsoft Exchange的CVE-2018-8153漏洞，允许利用Outlook Web Objects将用户引导到钓鱼网站，这些网站伪装成合法网站来窃取他们的登录密码和其他信息。这其中，攻击者必须通过电子邮件向受害者发送恶意链接，或者通过聊天消息来诱骗他们跟踪。

  

微软官方表示：

  

> “成功利用此漏洞的攻击者可以执行脚本或内容注入攻击，并试图欺骗用户披露敏感信息，攻击者还可能将用户重定向到恶意网站，该恶意网站可能会有欺骗内容或被用作攻击链接起来的枢纽。”

  

**05 ****网址过滤器(****URL filters)**

这方面的修复程序未解决Avanan本月报告的安全漏洞，我们可以通过将URL分割为电子邮件中的恶意网站来绕过Office 365的消息过滤器，或者在HTML邮件中使用<base>标记，以使干净链接实际指向恶意网站。

  

目前，对于利用Office 365中的这一弱点的电子邮件，没有任何已知的缓解措施。  

  

如果你依靠微软的云套件来阻止包含指向不良网站链接的邮件，请注意，不法分子正在使用此过滤器旁路功能将人员网址发送到钓鱼网站。

  

**06 ****Office和Excel：****CVE-2018-8162、CVE-2018-8158等**

![](../Images/19e554cb4bdeca843272cb21b7bdf32e.png)

在易受攻击的计算机上打开恶意Office文档（包括Excel电子表格）可能会触发恶意软件和间谍软件的执行。例如，Excel中的CVE-2018-8162和Office中的CVE-2018-8158、CVE-2018-8161，可以通过诱杀文件，利用系统上运行的间谍软件进行勒索。

  

同样，攻击者可以通过Microsoft COM for Windows中的CVE-2018-0824运行在电子邮件或网页中的任意代码。

  

**07 **Containers：CVE-2018-8115

![](../Images/4b16a92cc1e6c199e7e0e01f9b9a9d36.png)

如果可以诱骗管理员进入伪装的的容器映像，则可以利用Windows Host Compute Service Shim中的CVE-2018-8115来触发主机服务器上的恶意代码的执行。

  

**08 ****域帐户****：****CVE-2018-8136、CVE-2018-8168等**

使用域帐户可以利用CVE-2018-8136获得管理员权限。还有其他升级的特权漏洞，如Sharepoint（CVE-2018-8168），Windows通用日志文件系统驱动程序（CVE-2018-8167）和DirectX（CVE-2018-8165）。这些可用于从一般用户访问转到对易受攻击的安装，进而完全管理控制。

  

**09 ****物联网：****CVE-2018-8119**

Azure的物联网设备供应AMQP传输库，这是一种在小工具上运行的软件工具包，未正确验证从其云托管后端发送的安全证书。

  

该漏洞包含在CVE-2018-8119，意味着在中间人攻击中，歹徒可能伪装成网络上的Azure服务器，并在配置期间劫持和窃听来自物联网设备的所谓安全连接。

  

**10 ****Adobe**

![](../Images/d9847a3e527a88d0f2b7b9aac7a62f9a.png)

像之前一样，Adobe的软件筛选Flash Player需要在Windows，Mac和Linux系统上进行更新，以免恶意Flash文件劫持您的系统。

  

Adobe Connect还需要在所有平台上进行修补，以避免泄露敏感信息，而针对Windows和macOS的Creative Cloud Desktop应用程序也需要修复，以阻止通过软件套件升级权限的攻击。

  

**总结及建议**

用户需要尽快地应用补丁，以避免恶意分子获得系统和数据控制权，要知道，他们利用这些远程代码执行和特权升级漏洞，只需要受害者打开社交媒体或通过电子邮件发送的恶意文档或网页。
