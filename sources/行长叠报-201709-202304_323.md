**前言**

  

3月底，Drupal核心安全团队发布了安全咨询SA-CORE-2018-002，该安全咨询讨论了一个非常严重的漏洞CVE-2018-7600，该漏洞存在于众多Drupal版本中，本文将对该漏洞进行详细分析。

  

这个漏洞影响着超过一百万个Drupal用户和网站，它可以启用远程代码执行，并且可以在Drupal 7 Form API上进行不完整的输入验证。

  

攻击者可以使用此漏洞强制运行Drupal的服务器，并执行可能危害Drupal安装的恶意代码。根据具体配置的不同，这也很可能会危及到主机。

  

由于没有任何措施可以缓解对该漏洞的访问，所以这个漏洞显得尤为严重，这代表着匿名用户使用此漏洞远程执行代码而无需身份验证。

  

**脆弱性根源分析**

  

“可渲染数组（Renderable Arrays）”是在Drupal 7中正式引入的。这些结构由关联数组实现，并将键值对作为函数参数或表单数据传递，以便更好的呈现标记和UI元素。

  

标记元素属性具有以“＃”字符为前缀的键。以下是在普通PHP函数中使用的渲染数组的示例。

![](../Images/4fa28a80fbf90745dba801daa2916889.png)

图1.渲染数组键值对的Drupal核心示例

 

在对Drupal安全补丁的快速检查中发现了一个名为RequestSanitizer的分类。值得注意的是stripDangerousValues方法，该方法在另一个称为sanitize的方法中调用。

  

前面的函数从数组参数的索引零处去掉了一个控制字符“＃”。以下是补丁函数的一个片段。

![](../Images/08169636730ba31157713d52843e229d.png)

图2. Drupal补丁从参数化输入中剥离“＃”

 

基于Drupal安全团队的补丁内容以及Drupal Form API的分析，42位研究人员推断某些Form API函数能够执行任意代码，并且需要对通过前导“＃”字符传递参数的输入进行清理，以尝试和防止代码执行攻击。

  

为了利用此漏洞，攻击代码必须将恶意代码传递给Form API可执行函数之一的页面加载，或者传递给AJAX请求的呈现阶段。

  

我们确定可以用于远程代码执行的四种可利用的Form API函数是：

  

*   \[#post\_render\]
    
*   \[#pre\_render\]
    
*   \[#access\_callback\]
    
*   \[#lazy\_builder\]
    

 

**利用方法分析**

  

Drupal专家与安全研究人员协作的报告指出，默认配置在新用户注册页面中有一些字段，在Drupal补丁之前未正确清理。/ user / register中的默认页面可以被迫发送特定的AJAX请求，该请求可以针对各种表单字段，包括受漏洞影响的表单字段，从而执行攻击者的代码。

  

概念证明（POC）代码在2018年4月12日发布。初始POC使用#post\_render函数针对邮件数组执行PHP函数exec，后者执行底层操作系统函数Web服务器用户的上下文。

  

以下是在本地地址10.3.228.197处捕获到易受攻击的Drupal实例的流量。它使用的PHP命令是exec，有效载荷是一个简单的wget命令，用于外部IP地址172.217.6.36。

由于8.x和7.x版本上的/ user / register页面的默认配置，第一个公开可用的POC出现在脆弱的Drupal 8.x实例上才有效。

  

其他默认配置URI包括/ user / password页面，可以成功地利用7.x版本。这个特定的漏洞利用目标是\_triggering\_element\_name表单，并要求发送两个请求。

在进行这样的分析时，攻击者试图对恶意有效载荷调用wget，curl和其他第二阶段机制，以启动对Drupal站点的收购。就像任何远程代码执行漏洞一样，已经发现了包含反向shell，后门，僵尸网络，甚至加密矿工的武器化有效载荷。

  

**潜在的威胁**

  

几乎所有公开可用的POC样本都通过将\[#post\_render\] \[\]的渲染数组键与PHP函数exec的值一起传递给Drupal的易受攻击实例，紧接着是第二个键值对\[#markup\]，其值为操作系统函数由exec调用。

  

但是，其他成功的漏洞利用了上面列出的四个表单API函数（\[#post\_render\]，\[#pre\_render\]，\[#access\_callback\]和\[#lazy\_builder\]）。

  

我们在Palo Alto Networks覆盖利用这些API函数的流量，以及可能被利用的其他“危险”PHP函数。应该筛选的PHP函数包括：

  

*   Exec
    
*   \` (backtick)
    
*   $ (dollar)
    
*   system
    
*   popen
    
*   pcntl\_exec
    
*   eval
    
*   preg\_replace
    
*   create\_function
    
*   include
    
*   require
    
*   passthru
    
*   shell\_exec
    
*   proc\_open
    
*   assert
    
*   include\_once
    
*   require\_once
    
*   $\_GET
    
*   $\_POST
    
*   $\_SERVER
    
*   $\_FILES
    
*   $\_REQUEST
    
*   $\_SESSION
    
*   $\_ENV
    
*   $\_COOKIE
    

  

除exec外，恶意软件样本还包括系统、passthru和eval。可以肯定的是，更多攻击者将会制作利用这些功能的请求。

  

**结论和缓解**

  

CVE-2018-7600处于疯狂传播状态，未来很可能会继续被利用。具体措施请参照Drupal小组的说明：

  

https：//groups.drupal.org/security/faq-2018-002

  

Palo Alto Networks客户可以通过以下产品和服务免受此漏洞的侵害：

  

*   威胁防护签名40627，用于识别包含漏洞利用代码的HTTP请求
    
*   PAN-DB阻止攻击者的C＆C服务器IP和域
    
*   WildFire和Antivirus标识并阻止开发负载
