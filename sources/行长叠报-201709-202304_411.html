微信为了能够加密Client到Server的通信数据，开发了基于TLS1.3的MMTLS协议。


从防窃听，防篡改，防重放，防伪造等方面具备极高的安全性。


微信通信同时使用到了RSA公钥加密算法和AES对称加密算法。


通过对微信APP的研究，发现微信登录时使用RSA算法，和服务器进行通信，共同协商出一个AES密钥，后续聊天等通信会使用该密钥进行加解密。

com.tencent.mm.protocal.ac文件


通过对class.dex文件中的com.tencent.mm.sdk.platformtools.x的d函数进行hook，d函数如下：public static void d(String paramString1, String paramString2, Object... paramVarArgs)。


进行登录操作，可以看到上述函数被调用，以下显示了公钥的其中8个字符。


上诉字符串即为通信时使用的RSA2048位的公钥。


RSA属于非对称算法，公钥加密私钥解密，唯一的公钥对应唯一私钥。RSA加密算法的安全性与其密钥长度成正比关系。


微信目前使用的RSA2048位的密钥，破解难度极大，就算用目前世界上最强的超级电脑破解，也需要花费超过46亿年的时间。


理论上来说，微信的加密信息是很难被破解的。


但是，根据非对称加密算法的原理，使用公钥加密，私钥解密。如果得到了私钥，就可以从通信过程中截取数据包，利用私钥分析出加密的通信内容。


运营者本身拥有私钥，理论上可以解密所有加密的通信内容。所以李书福的担忧是否会成真，完全取决于运营者的道德水准。

世界上没有绝对安全的系统，同样也没有绝对安全的通信方式。


如何在这样的社会现实下，保障个人的信息安全？

从本质上说，是增加进攻成本，让进攻成本高于进攻收益，达到这个动态平衡的时候，个人的信息安全就被很好的保护了。


在过去的文章中，我们提到了很多人人可以使用的防范方法：


1.提高个人安全意识，密码最好三月一换，不同网站使用不同的密码。


2.需要留存自己个人信息的时候，可以选择性的留非真实信息，尽可能的少留信息


3.有条件的情况下，机密信息进行多次加密。


4.尽量从物理层面销毁个人数据，例如：撕毁快递单号以及外卖单号等。


总而言之，个人数据及个人隐私是十分宝贵的，其后涉及到极大的商业价值，提高个人的安全意识，了解基础的信息安全防护知识，才能有效避免自己与亲人受到损害。
