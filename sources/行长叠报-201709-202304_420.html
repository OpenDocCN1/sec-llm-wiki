右移操作符将二进制值1位的位数向右移动

示例如下

 

本方法可以用于盲注时获取一个字符值。如果该字符是在ASCII码表中，则最多不超过8个请求就可以获取到。


下面我们演示获取select user()返回内容的第一个字符值。



第一位


首先找到第一位的值：？???????，有两种可能：

  • 0（十进制值：0）// TRUE条件

  • 1（十进制值：1）// FALSE条件



SQL查询出现时间延迟，因此条件为TRUE，第一位为0


0 ???????



第二位


现在我们需要找到第二位的值，有两种可能：

  • 0 0（十进制值：0）// TRUE条件

  • 0 1（十进制值：1）// FALSE条件



SQL查询没有时间延迟，因此条件为FALSE，第二位为1


0 1 ??????



第三位


现在我们需要找到第三位的值，有两种可能：

  • 01 0（十进制值：2）// TRUE

  • 01 1（十进制值：3）// FALSE


SQL查询没有时间延迟，因此条件为FALSE，第三位为1


01 1 ?????



第四位


现在我们需要找到第四位的值，有两种可能：

  • 011 0（十进制：6）// TRUE

  • 011 1（十进制：7）// FALSE



SQL查询没有时间延迟，因此条件为FALSE，第四位为1


011 1 ????

 


第五位


现在我们需要找到第五位的值，有两种可能：

  • 0111 0（十进制：14）// TRUE

  • 0111 1（十进制：15）// FALSE



SQL查询出现时间延迟，因此条件为TRUE，第五位为0


0111 0 ???



第六位


现在我们需要找到第六位的值，有两种可能：

  • 01110 0（十进制：28）// TRUE

  • 01110 1（十进制：29）// FALSE


SQL查询出现时间延迟，因此条件为TRUE，第六位为0


01110 0 ??




第七位


现在我们需要找到第七位的值，有两种可能：

  • 011100 0（十进制：56）// TRUE

  • 011100 1（十进制：57）// FALSE



SQL查询没有时间延迟，因此条件为FALSE，第七位为1，第四位必须是1


011100 1？



第八位


现在我们需要找到第八位和最后一位的值，有两种可能：

  • 0111001 0（十进制：114）// TRUE

  • 0111001 1（十进制：115）// FALSE


SQL查询出现时间延迟，因此条件为TRUE，第8位为0


0111001 0
