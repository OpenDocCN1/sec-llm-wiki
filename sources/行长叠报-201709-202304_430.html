漏洞代号

CVE-2017-11937，CVE-2017-11940


影响范围

所有支持的Windows PC和服务器平台的Windows Defender，以及Windows Intune Endpoint Protection，Security Essentials，Forefront，Endpoint Protection以及Exchange Server 2013和2016


漏洞危害

成功利用此漏洞的攻击者可以在LocalSystem的权限下执行任意代码并完全控制目标计算机，然后攻击者可以安装程序，查看，更改或删除数据，或创建具有完整用户权限的新帐户。


漏洞浅析

该漏洞是一个内存损坏漏洞，严重影响到恶意软件保护引擎（MPE），在MPE扫描恶意代码的特制文件时触发。


Windows MPE默认启用，并且在其解决方案中实施的Microsoft防病毒和反恶意软件软件（包括Windows Defender和Microsoft Security Essentials以及Endpoint Protection，Forefront Endpoint Protection和Exchange Server 2013和2016）中使用该软件，从而影响Windows 7 ，Windows 8.1，Windows 10，Windows RT 8.1和Windows Server。


微软方面表示：


当Microsoft MPE未正确扫描特制文件时，存在远程执行代码漏洞，导致内存损坏。攻击者可通过多种方式将特制文件放在Microsoft MPE扫描的位置，例如：


  • 使用网站向受害者的系统发送特制文件，该文件在用户查看网站时会扫描该文件

  • 通过电子邮件发送特制文件

  • 利用Instant Messenger服务发送特制文件

  • 利用接受或托管用户提供内容的网站将特制文件上传，放置到由托管服务器上运行MPE扫描的共享位置


目前，微软已经发布了该漏洞的补丁。该修复自动升级，用户无需手动更新。
