Oracle发布了一个漏洞补丁，它影响了几个依赖专有协议的产品。ERPScan的专家将这5个漏洞命名为JoltandBleed。


最严重的漏洞的CVSS基础评分为9.9甚至10.0，它可以通过网络被利用而不需要有效的用户名和密码。


JoltandBleed问题会影响Oracle Tuxedo中的Jolt服务器，该服务器已被许多Oracle产品（包括Oracle PeopleSoft）使用。攻击者可利用这些漏洞获取对以下ERP系统中存储的所有数据的完全访问权限：


  • Oracle PeopleSoft校园解决方案

  • Oracle PeopleSoft人力资本管理

  • Oracle PeopleSoft财务管理

  • Oracle PeopleSoft供应链管理等


JoltandBleed漏洞列表：


CVE-2017-10272——内存泄露漏洞，可以远程读取服务器的内存。

CVE-2017-10267——栈溢出漏洞。

CVE-2017-10278——堆溢出漏洞。

CVE-2017-10266——允许攻击者对DomainPWD进行密码爆破。

CVE-2017-10269——影响Jolt协议的漏洞，它使攻击者能够损害整个PeopleSoft系统。


这个漏洞与Jolt Handler（JSH）处理一个操作码为0x32的命令有关。


ERPScan表示：


这个错误源于Jolt Handler如何处理一个操作码为0x32的命令。如果程序包结构不正确，程序员必须为Jolt客户端提供一定的Jolt响应，表明在通信过程中出现错误。


Oracle周二发布了Oracle Fusion中间件的补丁，以解决所有的漏洞。


该漏洞是由函数调用中的编码错误导致的，该函数调用负责打包数据以进行传输。


混淆了 jtohi 和 htoji 这两个函数。因此，一个被封装的常量包，原本的长度应该是0x40字节，而它的实际长度是0x40000000字节。


然后客户端开始传输0x40000000字节的数据。通过操作与客户端的通信，攻击者可以实现服务器端的稳定工作和敏感的数据泄漏。启动大量的连接，黑客被动地收集震动服务器的内部内存。


当用户通过PeopleSoft系统的Web界面输入证书时，漏洞会导致证书泄露。


从技术上来说，这个缺陷是类似于HeartBleed的内存泄漏漏洞，所以它可以用来检索用户密码和其他敏感数据。


除了盗窃员工数据之外，还有一种可能的攻击，就是学生们要对校园的解决方案进行黑客攻击，修改或删除他们的教育支付订单，或者获得经济援助。今天，在维也纳的DeepSec安全会议上，这次袭击以及其他细节都得到了证实。

据甲骨文称，CVE-2017-10272内存泄漏漏洞很容易被利用，并允许一个低权限的攻击者通过Jolt的网络访问来破坏Oracle Tuxedo。


Oracle融合中间件（子组件：Core）的Oracle Tuxedo组件中的漏洞。受影响的受支持版本是11.1.1，12.1.1，12.1.3和12.2.2。此漏洞允许低特权攻击者通过Jolt的网络访问来破坏Oracle Tuxedo。


虽然这个漏洞在Oracle Tuxedo中，但攻击可能会对其他产品产生重大影响。利用此漏洞可导致未经授权的创建，删除或修改访问关键数据或所有Oracle Tuxedo可访问的数据。
