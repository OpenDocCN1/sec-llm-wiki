# 维基解密：CIA不仅散布恶意软件，还把卡巴斯基拉下水

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxODg1MDMwOQ==&mid=2247486805&idx=1&sn=5a4bae919d81546fecc9cad7482386f5&chksm=9bceba3facb933299f421a7f47d6d7245b21ebfb56239df8bb817545c59c63517ad0a6659d2a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxODg1MDMwOQ==&mid=2247486805&idx=1&sn=5a4bae919d81546fecc9cad7482386f5&chksm=9bceba3facb933299f421a7f47d6d7245b21ebfb56239df8bb817545c59c63517ad0a6659d2a&scene=27#wechat_redirect)

![](../Images/7a9edf380e245ee9b2ec2836197d8bc0.png)

维基解密一直保持着对 Vault 系列的解密进度

  

两个月前，维基解密公布了CIA网络武器库的Vault 7 项目，其中包含了23种黑客工具的详细数据。

  

就在今天，维基解密在其网站上曝光了CIA另一个网络武器库项目 Vault 8，**其中不仅有CIA自主研发的网络武器的控制端源码，还包括其后端架构的机密信息。**

![](../Images/20e175ffba1fbe87921e5110f61f1be6.png)

维基解密官网上关于Vault 8的解密文件

  

维基解密首先在Vault 8上公布了**蜂巢项目（Project Hive）****的源代码和开发****日志。**

  

蜂巢项目是CIA计算机网络行动小组（COG）搭建的一个平台，用于在执行远程任务时协调工作人员之间的操作。

![](../Images/bcb3ac86e8bc88ceca366d5a922b878d.png)

  

 今年4月份，维基解密就公布了蜂巢项目的简略信息，并表示该项目的实体是一个命令和控制服务器（C&C Server），主要用于控制被感染设备上的恶意软件，与恶意软件进行通信。CIA特工可以向植入恶意软件的设备发送指令，同时接收来自目标设备上泄露出来的信息。

  

**蜂巢项目还是一个多用户、一体化系统，可以同时由多个CIA特工远程控制，向目标设备上的恶意软件发送不同的操作指令。**

![](../Images/fa61d0f7bc19ef7d2f5e33da24831a90.png)

蜂巢项目的基础架构

  

除此之外，蜂巢项目的基础架构经过了特殊设计，具有**隐藏归属地**的能力，可以防止被反追踪到真实IP，就连经过VPN多级通信后的的虚假IP都能隐藏。

  

如图所示，操作恶意软件的特工直接与假冒网站通信。该网站是在商业VPS（虚拟专用服务器）上运行的，所以当目标设备直接从浏览器上打开该网站时，并不能发现其与恶意软件之间的联系。

![](../Images/57f4a2602708c667c8c315abc92c496d.png)

精心设计的基础架构可以隐藏归属地

  

然而，经过后台验证可以发现，恶意软件实际上正在与网络服务器（托管的假冒网站）进行通信，然后通过安全的VPN连接，将恶意软件相关的流量转发到CIA名下被称为“Blot”的隐藏服务器。Blot服务器之后会将流量转发到一个名为**“蜂窝”（Honeycomb）**的植入操作员网关。

  

**有意思的是，为了逃避网络管理员的检测，CIA使用了假冒的卡巴斯基实验室的数字证书。**

![](../Images/ea7eae07611d43b79498cd8fa9991508.png)

不知道卡巴斯基的工作人员会作何感想

  

维基解密表示，恶意软件的数字证书是由中央情报局捏造的。** 据源代码中包含的示例显示，CIA以卡巴斯基实验室的名义捏造了假证书**，该证书的签发机构是是一家名叫Thawte Premium Server CA的数字证书公司。

  

维基解密还表示，Vault 8 中公布的源代码只包含在CIA服务器上运行的软件，并不会发布任何0-Day或类似的安全漏洞，以防他人滥用。

  

现在任何人都可以在维基解密网站上下载和查看此次泄露的 Vault 8 文件。

  

解密文件地址：https://wikileaks.org/vault8/#Hive
