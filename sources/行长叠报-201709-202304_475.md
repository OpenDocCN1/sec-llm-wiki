# 微软大呼头痛，这个20年前的黑客攻击耍了他们7个月

大家周一好

  

在小编犯周一综合征的时候

  

微软过得也不开心

  

它被二十年前的一个黑客攻击搞得晕头转向

  

小编今天就跟大家讲讲这个坑微软的攻击

  

![](../Images/51b75a3a6a0cf61a44e3acbef626a2c9.png)

**窃取Windows NTLM密码**

最近微软对一项危险的黑客攻击进行了修补，这项攻击中，攻击者**在没有任何用户交互的情况下就窃取了Windows NTLM密码。**

![](../Images/01ba16d22a29428a6faab0f789edfb1e.png "http://mmbiz.qpic.cn/mmbiz_jpg/ndicuTO22p6ibs9nSQRG9icV2OS8VYa6sC25yeTWsG1l9SLHgveKXgYhTjiaQlfTNs9c7mv81icZHx4c3T3X8Kk2JjA/0")

  

这项攻击很容易执行，不需要高级的技术技能就可以完成。

  

攻击者只需要将一个恶意的SCF文件放置在可公开访问的Windows文件夹中即可。

 

一旦文件被放在文件夹中，就会被一个神秘的bug执行。它会收集目标的NTLM密码散列，并将其发送到一个配置服务器中。

  

攻击者可以用软件破解NTLM密码散列，随后访问用户的计算机，这样的攻击允许攻击者与受害者的网络直接连接，对附近系统也能进行访问。

  

![](../Images/7a412fb79624115eaaec188ab0c0dc9e.png)

**共享文件需要用密码保护**

  

只要计算机中的**共享文件夹是用密码保护**的，那么这些计算机就是安全的。

  

由于密码保护是Windows中的默认选项，因此这些计算机不容易受到攻击。

 

尽管如此，在企业、学校和其他公共网络中，很多用户为了方便，使用的都是**不含密码护的共享文件夹**，这也导致了许多他们的系统被网络攻击。

![](../Images/bbbdc7518ab65cd3fa6bd1b19ddbcc6b.png "http://mmbiz.qpic.cn/mmbiz_jpg/ndicuTO22p6ibs9nSQRG9icV2OS8VYa6sC2ibKsQ5wrNnCHv6ic53kdzD75oMoyqwibiaIdR4TKZ668t5PZdiaKEwkpH5w/0")

  

![](../Images/7b81d8619df904826a97138435201d46.png)

**补丁仅适用于Windows 10和2016服务器**

  

这个攻击是由哥伦比亚安全研究员Juan Diego发现的，他于今年4月向微软报告了这个问题。

 

微软本月通过ADV170014安全公告，发布了补丁修补攻击向量，但**该补丁仅适用于Windows 10和Windows Server 2016用户**。

 

由于**注册表的修改与旧版的Windows防火墙不兼容**，旧版的Windows仍然容易受到攻击。

  

![](../Images/5fff76fe8b6cb2703a84651860693fa9.png)

**被微软保密的漏洞**  

  

Diego说：

  

> ADV170014阻止了他发现的黑客攻击，但他尚无法解释这个黑客攻击。

 

这项攻击通过一个恶意的SCF文件运行。SCF代表Shell命令文件，支持非常有限的Windows Explorer命令集。

  

例如：

  

> 打开Windows资源管理器窗口或显示桌面。我们日常使用的“显示桌面”快捷方式就是一个SCF文件。

 

攻击者只需要将SCF文件上传到易受攻击的文件夹，不需要用户交互。

 

以前的攻击只涉及受害者访问文件夹时执行的SCF文件。

  

但这一次Diego发现：

  

> SCF文件中包含的恶意命令就在攻击者将共享文件夹中的SCF文件上传之后运行，而无需等待用户查看该文件的内容。
> 
>   
> 
> 这个攻击是自动的，微软对此非常保密，触发攻击的根本原因还不得而知。

  

![](../Images/ff98aba3d99935035ea08b49511f5e7a.png)

**pass-the-hash攻击**

  

实际上**微软的补丁并没有解决SCF自动执行的问题**，但却试图修补一个20年前的被称为pass-the-hash的攻击。

  

pass-the-hash可与服务器之外的服务器自动共享NTLM散列用户的网络，这也是Diego在他的模拟攻击中使用的技术。

 

SCF自动执行的问题经常被用于各类Windows黑客攻击。

  

今年，一个Chrome和SCF文件结合的pass-the-hash攻击就攻击了用户的凭证。

 

微软提供的补丁阻止了攻击者欺骗本地用户，防止他们验证位于本地网络之外的服务器。

 

2017年3月，一位德国研究人员Stefan Kanthak向微软报告了类似的错误并得到了确认。

  

Kanthak认为：

  

> 微软确实做得很差，他们这个月发布的报告中只发现了6个错误中的两个，微软离修复这个长期的安全漏洞还差得远。

 

**如何防范**

虽然ADV170014是一个可选补丁，但我们强烈建议大家安装此更新，因为它被确认可以阻止危险黑客攻击。除此之外在使用公共网络传输文件时
