## CVE-2021-41773

当然肯定是CVE-2021-41773占头条了，漏洞在v2.4.50版本中进行了修复，并且只影响该版本。从Apache官方声明来看，攻击者可以使用路径遍历攻击将URL映射到预期文档根以外的文件。如果文档根目录以外的文件不受`require all denied`保护，则攻击者可以访问这些文件。

403 -> Server is vulnerable 

400 -> Server isn't vulnerable

## vCenter SAML Login Tool

项目:https://github.com/horizon3ai/vcenter\_saml\_login

非常的牛逼，利用之前vcenter文件上传的漏洞，然后通过一顿操作，获取到web端的cookie,实现登录web端的目的。

首先要获取data.mdb

*   Linux:
    
    ```
    /storage/db/vmware-vmdir/data.mdb
    ```
    
*   Windows
    
    ```
    C:\ProgramData\VMware\vCenterServer\data\vmdird\data.mdb
    ```
    

笔者也试了一个。运气比较差，没有成功。看代码他判断替换cookie之后的302，这里报错那就是确实登录不了。手工试了下替换生成的cookie，也是登录不了的。不是代码问题。
