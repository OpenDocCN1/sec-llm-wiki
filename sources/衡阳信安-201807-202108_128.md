# 华为全面下架腾讯游戏，腾讯最新回应

新年刚过，手机游戏圈就发生了件大事：两大巨头华为、腾讯干起来了。  
12月31日凌晨，华为游戏社区发布了“致华为游戏中心腾讯游戏用户”公告称：腾讯游戏单方面就双方合作做出重大变更，导致双方的继续合作产生重大障碍。经过我司法务的谨慎评估，我们不得不依照腾讯单方面要求暂停相关合作，将腾讯游戏从华为平台下架。![](../Images/2d31832d6258f77051e42b141bac34b6.png)腾讯游戏方面回应称，因华为手机游戏平台与其《手机游戏推广项目协议》未能如期续约，导致今天凌晨腾讯游戏的相关产品被突然下架。目前腾讯游戏正积极与华为手机游戏平台沟通协商，争取尽快恢复。**01****华为突然全面下架腾讯游戏**今天凌晨，华为游戏社区突然发出下架腾讯游戏的公告，原文如下。致华为游戏中心腾讯游戏用户：  
首先，华为游戏中心衷心祝3年来陪伴我们共同成长的各位用户新年快乐！感谢3年以来大家的支持、包容与陪伴。感谢3年来每一份真诚，每一份欢喜，每一份热情与每一份信赖。![](../Images/b06d58f096bac7d1d352bca78b027a04.png)3年来，我们积极携手腾讯游戏，秉持着为各位用户提供极致手游娱乐体验的理念砥砺前行。但腾讯游戏于2020年12月31日17点57分单方面就双方合作做出重大变更，导致双方的继续合作产生重大障碍。经过我司法务的谨慎评估，我们不得不依照腾讯单方面要求暂停相关合作，将腾讯游戏从华为平台下架。对此我们深表遗憾。我们敬佩腾讯游戏在行业内取得的成就和绝对的市场地位，虽然不赞同但也理解腾讯基于此提出的要求。感谢腾讯游戏以往的支持。希望未来双方有机会再次携手合作，为广大华为用户提供优质的游戏内容服务。最后，华为游戏中心真诚向所有受此次下架影响的用户致歉。也祝大家新年快乐，万事如意！有网友发现，目前华为应用市场已经搜不到腾讯相关游戏。**02****市场传闻抽成比例未谈拢****腾讯最新回应来了**腾讯游戏方面回应称，因华为手机游戏平台与我们的《手机游戏推广项目协议》未能如期续约，导致今天凌晨腾讯游戏的相关产品被突然下架。目前我们正积极与华为手机游戏平台沟通协商，争取尽快恢复。给各位用户带来的不便，我们深表歉意。![](../Images/1d54c1c0732f56cd40286f372a65c992.png)腾讯游戏跟华为闹掰并非无迹可循。据GameLook报道，近期因为《使命召唤手游》的国内市场发布，腾讯与华为公司曾暗自进行了一番较量，12月25日游戏发布当天，因只剩下华为未与腾讯达成这款手游的分成比调整协议，腾讯一度未将《使命召唤手游》的游戏安装包提供给华为公司，在双方僵持了数小时后，腾讯最后提供了安装包，但华为下线了原本为《使命召唤手游》配套的商店推广资源，这为今日腾讯与华为彻底闹掰摊牌埋下了伏笔。知情人士称，当时腾讯游戏希望能够将分成比例提升至3：7，但双方没有谈拢。除了腾讯外，此前，米哈游《原神》、莉莉丝《万国觉醒》相继发布公告称，不上线华为、小米等传统安卓渠道。2020年11月12日，腾讯财报分析师电话会议上，腾讯首席战略官詹姆斯·米歇尔对《原神》《万国觉醒》等游戏绕过渠道发行获得了成功，给予了高度赞赏。“分成比例其实体现了一种平等的合作关系，平台也确实由于为游戏公司提供了价值而获得收入，这也是谈判中最需要注意的，比较复杂和细节的部分。”米歇尔表示。他强调，如果平台可以为游戏公司带来更多的新用户，那么他们的服务就具有很大的价值，反之价值就不大。渠道发行行业的未来会出现更多的细化，这对所有人都更为有利。**03****渠道地位很强势****但正在被挑战**据公众号**@竞核**统计，2014年8月，由华为、OPPO、VIVO等组成的硬核联盟成立。2015年Q1硬核联盟中国移动游戏渠道玩家覆盖率占比达到19.8%，排名第四，与360手机助手相差0.2%，小米占比为9.8%。一年之后，硬核联盟将这一占比提升到1/3，第三方安卓渠道逐渐衰落。得益于智能手机市场的高速发展，截至2019年硬核联盟在安卓手游渠道里渗透率高达65.7%，排名第一。在国外谷歌、苹果游戏抽成比例为30%，在国内安卓渠道强渗透率之下，这个比例被国产安卓渠道提升到了50%。  
   
那为什游戏厂商还要坚守国产安卓渠道？原因很简单：人多。根据IDC报告显示，2019年安卓手机占据中国市场份额高达87%。  
   
另一方面，对于手机厂商来说，他们也不会轻易放弃手游联运这颗摇钱树。2019年，小米互联网服务业务（主要是广告和游戏联运等）的毛利率则高达64.6%，而智能手机业务毛利率仅有7.2%。因为分成比例问题，强势渠道和优质内容之间的矛盾一直存在。早在9月23日，即将从PC端备战手游的《原神》，却在上线前夕意外发公告，称因为未能与小米、华为等渠道达成合作条款，《原神》将无法准时上架到华为、小米的游戏商店之中。  
彼时，官方给出的原因非常含糊，没有过多的解释，只是给了书面的告示与注意事项。这和今日凌晨华为下架腾讯游戏极为相似。球友**@互联网怪盗团**形容那一天为：一个注定要载入中国游戏行业乃至整个互联网行业史册的日子。那一天，米哈游和莉莉丝同时宣布它们最新的拳头产品——《原神》和《万国觉醒》，不会上架华为游戏应用商店；《原神》还宣布不会上架小米应用商店。为什么今年国庆档呼声最高的两款新手游都不愿意上架国产安卓应用商店？原因有两个：第一是安卓手机厂商收取的分账太高，高达总流水的50%（还要加上几个百分点的支付渠道费），实在是骇人听闻。相比之下，iOS App Store、Google Play和Steam都只收取30%，Epic Game Store更是只收取12%。第二是安卓渠道会给CP很多限制，例如使用渠道账号体系，从而使CP无法及时获得第一手用户信息；驱使CP做更多活动，让CP无法按照自己的节奏走。如果安卓应用商店仅仅甘于做“渠道”，那也就罢了；现在的问题是它们经常对CP横加干预，稍有自主追求的CP就不愿意忍耐下去。针对“渠道为王”的理论，**@互联网怪盗团**表示：在文化内容产业，“渠道为王”是一个非常邪恶的理论，它会导致内容质量变差、用户体验变差、整个行业盘子变小。“渠道为王”不仅不利于CP、不利于发行商，也不利于渠道自己——因为没有人能从内容质量下降这件事情当中受益。所以，“渠道为王”理念在光天化日之下的总破灭，以及“优质内容为王”理念得到广泛承认，是中国游戏行业的特大利好，将驱动整个行业继续健康发展下去。**04****内容为王的时代即将到来？**内容和渠道的这场博弈非常现实：如果你的内容足够优质，那你就是王，渠道是你的仆人；如果你的内容不够优质，那渠道就是你的王，你必须小心翼翼地吃他们剩下来的汤。

  

比如索尼PS与《最终幻想》系列的关系史，就是一出渠道的颠覆史。2000年，史克威尔产品发布会上，一口气推出《最终幻想10》《最终幻想11》《最终幻想12》三款产品。

当时的日本主机市场，索尼与任天堂、世嘉激战正酣。而索尼的崛起，或多或少与史克威尔当年的发布的三款产品有关，因为《最终幻想10—12》全部为PS平台独占游戏，索尼成功将世嘉踢出主机“饭局”。 

而随着国产优质内容的逐渐产生，内容为王的时代也很可能会在未来到来。

  

国信证券认为，《原神》拒绝上架华为等渠道，代表着优质内容与传统渠道矛盾日益激烈，“天下苦分成模式久矣”。一方面渠道分成比例高，安卓渠道联运一般5:5分成，另一方面缺乏自主权，缺乏自主权，联运直接关系到渠道公司收入，导致大推氪金游戏，“劣币驱逐良币”。随着移动互联网发展进入深水区，用户行为从“搜索”到“推荐”，传统应用商店受到用户和优质研发商双方面挤压，头部游戏的示范效应或推动更多内容方的“反抗”，优质内容的议价能力将持续提升。民生证券认为，在买量、TapTap等新型渠道模式兴起且云游戏蓄势待发的背景下，传统渠道方的议价能力将进一步减弱，游戏行业有望进入“内容为王”的新时代。文章综合自：竞核、互联网怪盗团、每日经济新闻、华尔街见闻等
