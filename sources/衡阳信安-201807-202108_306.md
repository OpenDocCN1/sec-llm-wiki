# 微信的隐藏功能有很多，不止7个，我整理了一下，把我觉得几个比较实用的，介绍一下。  

# 一、语音消息转文字

对于在一些比较嘈杂或者不太方便听语音的场合，有一两条语音急需回复，可以使用这个语音转文字的功能，轻松化解语音困扰。

![](../Images/df4cc60242dab62be2a83dd3e7180b8c.png)

# 二、语音取消

语音录入过程中，突然想重新说一句，这种时候可直接手指上滑，取消语音。

![](../Images/be9adb8741ac1611f89d78263907246a.png)

# 三、自动推荐表情

微信斗图绝对是一种乐趣，但在表情越存越多的情况下，每次都要自己去找对应的表情，即费时也容易错过发图的时间点，但如果你在对话框中输入对应的句子，微信会自动为你推荐表情。

![](../Images/6261edc4383fb3700d2de6c9d0e58c17.png)

# 四、放大文字

临时放大文字，可双击聊天窗口文字。或在设置-通用-字体大小中进行设置。

![](../Images/4ad0bf2175e713844bf8907d0d4944e0.png)

# 五、图片集

对于那些我们曾今看过的图片，想要重新查看，可以通过任意图片，右上角的图片进入过往图片集。

![](../Images/11695198f4202cf83331dd46baea1a73.png)

# 六、声音锁

声音锁主要是用于，当你双手暂时没空，又想打开微信的时候，使用的功能。

![](../Images/1338e917ba8ac7ecb134b9ce595ea6a4.png)

# 七、单方面删除好友，再神不知鬼不觉加回来

总会有些好友你觉得应该不会再联系了，爽快的删掉人家，随后又后悔了，也不好让朋友发现你删除过他。打开微信放大镜搜索栏，在搜索栏输入好友的微信名称，这时候就会跳出来你们曾经共同参与的群，点击进去找到好友，再点击好友的微信图案，添加到通讯录即可。

![](../Images/e2dab085fb7a46b2b607f07c8c3e8c59.png)
