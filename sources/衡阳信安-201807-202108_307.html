这不，前些天朋友正为找房子的事烦心着呢！他没想到找房子居然比找工作还难，用他原话说，就是房子没找到，头发都是一抓一大把。

Python？一提到这个词，想必有不少小伙伴就会望而却步了。这也正常，毕竟在早些年，程序猿必须要懂得机器语言才能让电脑听话干活，而机器语言的晦涩难懂相当反人类。而如今，随着开发语言的迭代升级，掌握一门编程语言再不像往日那么高不可攀了。

比如说 Python，完成同一个任务，C 语言要写 1000 行代码，Java 只需要写 100 行，而 Python 可能只要 20 行。

所以说 Python 是一种相当高级的语言，尤其适合初学者用来完成普通任务，非常简单易用。

这么说吧，如果你对编程一窍不通完全是个小白，只记得初中数学学的方程式和一点点代数知识，但是却想从一门语言入门学习编程，甚至将来想成为一名软件架构师，那么 Python 毫无疑问是你眼下的最佳选择。
