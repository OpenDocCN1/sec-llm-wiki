一直以来，网上给大家推荐了许许多多好用的“神器”，还是会有小伙伴在后台留言问我：浪哥，你有没有因为“搜一下”烦恼过？

但是有很多信息不是单靠搜索引擎就可以搞定的，搜索引擎只能解决单条信息，而对于批量信息的采集来说，如果只靠手工操作，那就太费劲了。

所以，还得另外找对应的工具来解决。

这不，前些天朋友正为找房子的事烦心着呢！他没想到找房子居然比找工作还难，用他原话说，就是房子没找到，头发都是一抓一大把。

昨天，他突然给我发了条信息，看完令我叹为观止。

他用 Python 脚本爬取租房网站的房源信息，利用高德的 js API 在地图上标出房源地点，规定距离上班地点 1 小时内可到达的范围。

不到半个小时就找到了一个满意的房子！

![](../Images/d7e334a9ddc8d23105a0ae4dfe7f1e67.png)

这操作也太酷炫了吧！关键是拿到了一手房源，省钱！

以前找房子费时又耗力，还要谨防被黑中介或二手房东坑一把。现在键盘敲敲几下，就能用 Python 找到房子，简直太牛了。

Python？一提到这个词，想必有不少小伙伴就会望而却步了。这也正常，毕竟在早些年，程序猿必须要懂得机器语言才能让电脑听话干活，而机器语言的晦涩难懂相当反人类。而如今，随着开发语言的迭代升级，掌握一门编程语言再不像往日那么高不可攀了。

![](../Images/dd20e15001d0e839a325a05c3749d94d.png)

比如说 Python，完成同一个任务，C 语言要写 1000 行代码，Java 只需要写 100 行，而 Python 可能只要 20 行。

所以说 Python 是一种相当高级的语言，尤其适合初学者用来完成普通任务，非常简单易用。

这么说吧，如果你对编程一窍不通完全是个小白，只记得初中数学学的方程式和一点点代数知识，但是却想从一门语言入门学习编程，甚至将来想成为一名软件架构师，那么 Python 毫无疑问是你眼下的最佳选择。

可能又会有小伙伴发问了，如果 Python 这么容易上手，那是不是能干的事都比较简单呢？

当然不是，实际上 Python 非常强大，几乎所有东西都可以用 Python 创建，这就是为什么它被 YouTube，Instagram，Netflix 甚至 Quora 使用的原因。

什么？这些你都没用过？那豆瓣你总用过吧，同样也是 Python 写出来的。
