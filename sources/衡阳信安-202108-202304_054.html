我们思考一个问题，这个偏导本质上是什么？是梯度方向，如果抽象到一维，这个方向就是斜率方向，我们现在需要的是什么？我们需要L越来越小，即我们希望逆着梯度方向，假设原本的w和b为 w0，b0，那么进行如下操作

注意梯度方向，本来的含义是，随着自变量越来越大，函数值会怎么变，如果梯度为正（确切的说不会存在所谓的正负，这里只是方便理解）那么L会越来越大，现在我们减去一个梯度，那么L就会越来越小，如果梯度为负，那么随着自变量越来越大，L会越来越小，现在减去一个梯度，就会使得L越来越大，最终目的是错误集为空，在这种情况下，我们的函数需要满足一个特性，即凸函数，如果没有这个特性，我们可能只会找到一个局部最优解，简单看一下，以两个函数为例

而如果是x^2的话，就不存在这个问题，可以直接找到最值点

class Perceptron:
    x, y = [], []
    omega, b = 0, 0
    eta = 0

    def __init__(self):
        pass

    def eta(self, eta):
        self.eta = eta

    def fit(self, x, y):
        if len(x) != len(y):
            raise Exception("x and y has different rows")
        if len(x) == 0:
            raise Exception("can use a empty dataset")
        self.x = x
        self.y = y

        self._train()
    
    def _sign(self, v):
        return 1 if v > 0 else -1
    
    def _get_wrong_dataset(self):
        x, y = [], []
        for i in range(len(self.x)):
            if self._sign(self.omega * self.x[i] + self.b) != self.y[i]:
                x.append(self.x[i])
                y.append(self.y[i])

        return x, y
    
    def _get_result(self):
        return self.omega, self.b
    
    def _train(self):
        #initial of basic parameter η0, b0
        self.omega = 0
        self.b = 0

        while True:
            wrong_x, wrong_y = self._get_wrong_dataset()
            if len(wrong_x) == 0:
                return
            
            sum_w, sum_b = 0, 0
            for i in range(len(wrong_x)):
                sum_w += wrong_x[i] * wrong_y[i]
                sum_b += wrong_y[i]

            self.omega += self.eta * sum_w
            self.b += self.eta * sum_b

if __name__ == "__main__":
    datasets = [1, 2, 3, 4, 5, 6, 7]

import numbers

class Vector:
    def __init__(self, data):
        self._list = []
        for i in data:
            self._list.append(i)

    def __add__(self, b):
        def cb(i, v):
            result.set(i, result.get(i) + v)
        
        if self.dimension() != b.dimension():
            raise Exception("vector add method requires the same dimension")
        result = Vector(self._list)
        b.walk(cb)
        return result
    
    def __mul__(self, b):
        if isinstance(b, numbers.Real):
            return Vector([self.get(i) * b for i in range(self.dimension())])

        if self.dimension() != b.dimension():
            raise Exception("vector add method requires the same dimension")
        result = 0
        for i in range(self.dimension()):
            result += self.get(i) * b.get(i)

        return result
    
    def dimension(self):
        return len(self._list)
    
    def walk(self, cb):
        for i in range(len(self._list)):
            cb(i, self._list[i])

    def get(self, idx):
        if idx >= self.dimension():
            raise Exception("idx out of bound")
        return self._list[idx]
    
    def set(self, idx, val):
        if idx >= self.dimension():
            raise Exception("idx out of bound")
        self._list[idx] = val
    
    def to_array(self):
        return [i for i in self._list]
