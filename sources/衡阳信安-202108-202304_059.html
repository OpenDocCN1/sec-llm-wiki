function encrypto( str, xor, hex ) {  
  if ( typeof str !== 'string' || typeof xor !== 'number' || typeof hex !== 'number') {

  let resultList = [];

说说 尸检工具

赛后在和队友和其他队伍的成员交流的时候， 发现大家都基本在使用 或者一些二进制编辑器，甚至听说有用 WinHex 嗯做来解这道题的。相反对于一些国外的优秀工具了解并不是很多，于是我一合计就有了这篇文章。VOL取证大师strings

在 Autopsy 的帮助下，我基本不需要担心搜素字符串不全或者很慢的问题，这些内容都交给工具自动处理了。尸检 不仅非常的贴心的在关键字的搜索中有专门的正则搜索，而且还会额外帮你匹配大小写不敏感的搜索，也可以匹配到诸如 的字符串。所以我的脑袋基本聚集于根据获取的结果进一步推理相关内容去解题的过程中。S\x00T\x00R\x00I\x00N\x00G\x00

此外 Windows 版本使用流程和 web 版本的基本一致，如果你是使用该版本来解决这道题，你可以直接提取出来镜像里所有的文件。关键字搜索也很方便，他可以直接识别出来 go 文件。但是定位代码相关上下文就非常的困难，就是 data unit 相关的功能有一点点欠缺，不过问题不大。
