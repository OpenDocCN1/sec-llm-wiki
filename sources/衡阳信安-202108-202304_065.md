# 各种比赛“眼花缭乱”，学编程的孩子究竟该怎么选？

“学Scratch是不是没啥用”、“Scratch的比赛咋就不值得参加”等问题。其实，这些问题的回答并没有那么绝对。学习 Scratch 培养思维能力、参加 Scratch 的比赛提升孩子的成就感都是合理的。作为家长，在孩子年龄较小的时候，确实需要考虑如何通过多样的方式提升孩子的文本理解、语言表达、抽象理解、过程拆解等能力。这些能力决定了孩子进入小学中高年级后的认知水平，也会影响到他学习更复杂知识的效果。![](../Images/e2fe4774386fcdd376311c0708a8ad62.png)用 Scratch 去创作动画、小游戏，用 Python Turtle 画图并不是提升这些能力、让孩子产生自我效能感的唯一选择。像是学习围棋、数独、搭积木、玩 Minecraft 甚至跟着父母学做饭都能达到同样、甚至更好的效果。  
而在小学三年级、甚至更早的时候过度强化参赛、竞争，反而导致孩子忘记初心、失去兴趣，甚至引导孩子尝试走获奖的捷径、养成不良的学习习惯。

![](../Images/ab0c1c3b14ba3d10fe1fe54d05cd1369.png)

随着孩子年龄的提升，他的文本理解能力、抽象思维能力往往会在四年级到五年级的时候表表现出从量变到质变的现象。在这个时间点后，家长就不能放任孩子陷在仅仅“有趣”的事情里了。

这时候，为孩子选择课程要更多考虑如何引导孩子的兴趣从“有趣”到“有用”转变。这时候了解如何简化和规范理解问题，学习 C++ 语言并用它去解决这些问题就变成了很值得引导孩子去做的事情。

与此同时，家长朋友往往还会需要结合孩子升学和未来职业安排去进行规划。选择在信息社会中有长远收益的学习方向；有严密判题和排名规则、公平性被大众认可多年的信息学奥林匹克比赛活动成为选择也就顺理成章了。

而到了高中之后，除了每年信息学奥赛的成绩将 50 人送入清华大学、北京大学之外，有信息学成绩的同学在通过强基计划、综合评价招生进入名校时也都会获得极大优势。

据小浪观察，真正能最后把信息学成绩稳步提升、用于升学的同学，普遍都是在一开始 C++ 语言基础打得好的同学。所以，不管在给孩子规划学信息学时是什么原因，都一定要让孩子在刚开始打好 C++ 语言的基础，这样才能在之后做到厚积薄发。

另外，“对于升学有帮助”这一有一定功利性的想法，家长朋友还是要注意不要过多对孩子传递。让孩子保持初心，在钻研信息学、求解算法问题的过程中找到持续动力。只有这样，孩子才有可能在信息学学习的道路上走得更远、走得更扎实。
