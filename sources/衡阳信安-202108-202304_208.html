分析镜像

分析的镜像为ubuntu的官方，首先选择尊重，保存为ubuntu.tar

sudo docker pull ubuntusudo docker save -o ubuntu.tar ubuntu

为了方便分析，这里将ubuntu.tar在windows解压，可以找到ubuntu镜像一共包含三个文件和一个文件夹。


首先查看manifest.json的内容，和可以该文件一共包含了三个字段，Config、。RepoTagesLayers

  • Config的镜像配置文件的json文件，对应825d55fb6340083b06e69e02e823a02918f3ffb575ed2a87026d4645a7fd9e1b.json；

  • RepoTages为镜像的名称和标签；

  • Layers 每一个元素都包含有哪些层，代表一个层目录，由此可见 ubuntu 包含一个层，8f7ee37aa1d53dcded9b5c22b0a57d8bb8d35d9f42273651668e7aca23bd7581/layer.tar。

打开8f7ee37aa1d53dcded9b5c22b0a57d8bb8d35d9f42273651668e7aca23bd7581文件夹，该文件夹包含三个文件播放。

VERSIONjsonlayer.tar

代表ubuntuVERSION的，合为1.0；json的很多内容都是重的layer.tar。中，一些文件存在于usr/bin目录中，有 ubuntu 系统的常见命令，如 ls、apt-get 等。

使用 DIVE 能够更好地查看每一层的功能，以及各比上级的功能调整，下图为潜水分析 ubuntu 的功能。DIVE 主要内容有以下主要内容：

  • 左上角提供镜像层列表以及每个镜像层的大小。

  • 提供相关的服务效率（当前值）、潜在的空间占用以及信息的总大小的一般统计。

  • 为每一个文件的显示层，右边会显示出每个文件夹大小的数据。

潜水使用的一些选择：

  • Ctrl+空格键- 控制面板切换

  • 空格键- 打开/关闭目录树，

  • Ctrl+A - 显示/关闭添加的文件，

  • Ctrl+R - 显示/关闭移除的文件，

  • Ctrl+M - 显示/修改文件，

  • Ctrl+U - 显示/关闭未修改的文件，

  • Ctrl+L - 显示镜像层，

  • Ctrl++ - 过滤文件，

  • Ctrl+C - 退出。

其他工具

下面分享一些对套工具进行分析的网站或

  1. 包含，一个支持在线分析容器的网站。

  2. trivy，镜像扫描工具，可以检测问题、镜像系统、git存储库的漏洞以及配置

  3. Clair，静态分析镜像中的漏洞

  4. 锚点，用于分析docker镜像，镜像容器和文件系统中的漏洞。

  5. Dagda木，用于对docker镜像和容器中的、吸附等已知漏洞进行静态软件、分析。

  6. Aqua Security，保护容器等云铝技术制造的应用程序。
