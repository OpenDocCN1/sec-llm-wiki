Windows 0day漏洞影响所有windows版本

原文：http://mp.weixin.qq.com/s?__biz=MzU2NDY2OTU4Nw==&mid=2247491985&idx=1&sn=8f26a5c95e3897ca2f5c3efcb37bdcfc&chksm=fc45dc6dcb32557be947cbe6d063597ff2f885e7ad32abc3e976feff3e26e2c382cbada2fd82&scene=126&sessionid=1681406730#rd

    一位安全研究人员披露了 Windows 0day特权提升漏洞和PoC漏洞的技术细节，该漏洞在特定条件下授予 system权限。公开的 (PoC) 漏洞利用和未修补的 windows 0day特权提升漏洞的技术细节已被披露，该漏洞允许用户在特定条件下获得系统特权。

    好消息是，该漏洞利用需要威胁参与者知道另一个用户的用户名和密码才能触发该漏洞，因此它可能不会在攻击中被广泛滥用。坏消息是它会影响所有版本的 Windows，包括 Windows 10、Windows 11 和 Windows Server 2022。

研究人员发布绕过补丁漏洞

    8 月，Microsoft 发布了针对“Windows 用户配置文件服务特权提升漏洞”的安全更新，其编号为 CVE-2021-34484。检查修复程序后，安全员Naceri 发现补丁不够充分，从而 GitHub 上发布的新漏洞绕过它。“从技术上讲，在上一份报告 CVE-2021-34484中。我描述了一个错误，您可以滥用用户配置文件服务来创建第二个连接点，”Naceria 在有关该漏洞和新绕过的技术文章中解释道。

“但正如我从 ZDI 公告和 Microsoft 补丁中看到的那样，该错误被视为任意目录删除错误。”

“微软没有修补报告中提供的内容，而是修补了 PoC 的影响。由于我之前编写的 PoC 很糟糕，它只能重现目录删除错误。”

Naceri 说，由于他们只修复了他的错误报告的症状，而不是真正的原因，他可以修改他的漏洞利用，在其他地方建立一个连接，并仍然实现特权提升.所以微软只是修复了该漏洞的表象，仍能通过修改之前的PoC漏洞利用还可以进行提权提升。此漏洞将导致在显示用户帐户控制 (UAC) 提示时启动具有 SYSTEM 权限的提升命令提示符。CERT/CC 的漏洞分析师Will Dormann对该漏洞进行了测试，发现该漏洞虽然有效，但它是易变的，并不总是创建提升的命令提示符。

    重点是该漏洞的利用需要攻击者知道另一个用户的用户名和密码才能触发，因此它不会像我们最近看到的其他特权提升漏洞（例如PrintNightmare 零日漏洞）那样被严重滥用。但它仍然应该是需要关注的问题。

微软表示他们已经意识到这个问题并正在调查中。 

“我们知道该报告，并将采取适当措施保护客户。” ——微软发言人
