## 漏洞原理

在tomcat8环境下默认进入后台的密码为tomcat/tomcat，未修改造成未授权即可进入后台

## 漏洞复现

进入`tomcat8`的docker环境

![](../Images/4ad4feb5075675ea3ce0ba15ac6cdb14.png)

  

访问后台管理地址，使用tomcat/tomcat进入后台

```
http://192.168.1.8:8080//manager/html
```

![](../Images/b19fee8c3524b61e8171af4911a1c80a.png)

  

进入到了后台的页面

![](../Images/293081e426ca20756f4c72a123880597.png)

  

看到这里有一个上传war包的地方，这里很多java的中间件都可以用war远程部署来拿shell，tomcat也不例外

![](../Images/feeff2058b4b61e8e4bce83a00acb644.png)

  

首先将ice.jsp打包成test.war

```
jar -cvf test.war .
```

![](../Images/a6f0a936dc28dd11354d95091f9ada72.png)

  

点击上传即可看到上传的test.war已经部署成功

![](../Images/3e410db9a2364b5bca2ccaada7775241.png)

  

访问一下没有报错404那么应该已经上传成功

![](../Images/1beb2b64f9d3d5d50750ceba9dca5be9.png)

  

使用冰蝎连接即可得到shell

![](../Images/48406067ffd6e55da3cb8324d48f1ceb.png)

  

这里也可以用msf里面的`exploit/multi/http/tomcat_mgr_upload`模块

```





use exploit/multi/http/tomcat_mgr_upload
```

![](../Images/4f18ec77a883a8ad8fe1e194a917b122.png)

  

运行即可得到一个meterpreter

  

![](../Images/347d81459489d3c8b3c3a5871f29a90a.png)

  

# manager App暴力破解

## 漏洞原理

后台密码用base64编码传输，抓包解密即可得到后台密码，也可以进行爆破

## 漏洞复现

这里访问`http://192.168.1.8:8000/manager/html`进行抓包，在没有输入帐号密码的时候是没有什么数据的

![](../Images/957fa64f3dc80a5902ea1cfa7dfaf6b5.png)

  

把这个包放过去，会请求输入用户名和密码，再进行抓包

  

![](../Images/751dad2eda4f12e23cf5878451041ea9.png)

  

就可以得到`Authorization`这个字段，这个字段有一个`Basic`，就是base64加密的意思

![](../Images/3d31880a07438f7d1d9e19ef3225e009.png)

  

进入后台之后再次抓包可以看到有一个cookie，但是没有了`Authorization`这个字段

  

![](../Images/726421b2accdf69b1b08eaae115f72c3.png)

  

我们可以对字段进行爆破，加上`Authorization`即可

  

![](../Images/38555ccacd9c27a2afe6086d719a721e.png)

  

去掉自带的编码

  

![](../Images/ee0e9de7e1bab42b415ab81d26f5c528.png)

  

攻击即可拿到账号密码

  

![](../Images/792c534fe4d9af5b27c27a3e53140c98.png)
