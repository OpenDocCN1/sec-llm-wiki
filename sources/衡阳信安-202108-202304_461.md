# **一、内网穿透**

使用`Ngrok`内网穿透：ngrok 是一个反向代理，通过在公共的端点和本地运行的 Web 服务器之间建立一个安全的通道。ngrok 可捕获和分析所有通道上的流量，便于后期分析和重放。Ngork官网注册账号：https://www.ngrok.cc开通隧道，选择一个免费的，当前你有钱可以买。
