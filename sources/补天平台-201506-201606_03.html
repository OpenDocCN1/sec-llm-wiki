前几个月有人放出了2012年的LinkedIn密码数据库，TrustedSec获取了一份拷贝用于做研究的目的，我的朋友 Korelogic （https://blog.korelogic.com/blog/2016/05/19/linkedin_passwords_2016）已经张贴了一个优秀的文章说明最常用的密码，以及其他的统计。LinkedIN的泄露给我们一个机会让我们可以共享一些针对大量数据泄露事件的密码破解的方法，并且这些破解出来的密码将会很有价值的，因为渗透测试人员可以对不同的社交媒体进行密码重用攻击。我们希望现在所有人都修改了自己的密码。并且不再其他的服务中使用LInkedin中2012年的密码。这次LinkedIN共泄露了167,370,909个无盐的sha1哈希，我们去除空行和重复的hash列后，共有117,205,871唯一的哈西需要破解。

 

我们使用Sagitta[https://sagitta.pw/]的密码破解服务，它有能力让我们一次一再整个1亿多的hash进行破解，然而并不是每个人都有能力处理一次处理这么大的数据量，你可以根据自己的硬件条件来载入破解的数量。


我这里使用split按照一千万来划分的每个文件

root@kracker:~/LINKEDIN_WORKING/cudaHashcat/HASHFILES# split -dl10000000 --additional-suffix=.txt linkedin.hash link

root@kracker:~/LINKEDIN_WORKING/cudaHashcat/HASHFILES# ls

link00.txt  link00.txt.new  link01.txt link02.txt  link03.txt  link04.txt  link05.txt link06.txt  link07.txt  link08.txt  link09.txt link10.txt  link11.txt  linkedin.hash

 

总共划分了11个文件。

 

我这里使用Cudahashcat来破解，首先需要识别密码哈希类型，可以通过-h参数查看Cudahashcat支持的哈希类型 

 

我们看到sha1的是100，接下来确定采用哪种破解方式



我首先采用暴力破解1-6位的字符，Cudahashcat可以将每位密码分配一个变量，如下


接下来破解

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked -i -a 3 ?a?a?a?a?a?a

 

–remove = ：表示如果哈希破解出来，就从文件中移除

-o =    ：表示将破解出的哈希保存为linkedin.cracked

-i =     : 表示递增模式，先破解1位然后一次递增

-a 3 =    : 表示采用暴力破解的方法

?a?a?a?a?a?a =  ：表示要破解6位，包含大小英文，数字，特殊字符

 

我使用下面这个bash脚本来批量破解这11个文件



如果我们不指定-a参数，将默认采用字典攻击，这是最基础的破解方式，破解成功率依赖你的字典质量。我们这里采用的是rockyou字典

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked /wordlists/rockyou.txt

 

Cudahashcat牛逼的地方是你可以通过*来指定一个目录下的所有文件当字典，而不用指定一个单独的大字典，例子如下：

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked  /wordlists/*

 

同样的，可以使用下面这个bash脚本来批量破解这11个文件



还有一种破解方式是采用基于规则的破解方式，Cudahashcat的规则可以参考其主站的wiki站点。当然Cudahashcat自己也在安装目录带了一些规则文件，可以通过-r参数来指定

./cudaHashcat64.bin -m 100 --remove HASHFILES/link01.txt -olinkedin.cracked -r rules/best64.rule /wordlists/*

 

最后介绍一种破解方式，混合破解

 6 = Hybrid dict + mask

7 = Hybrid mask + dict

 

我们可以通过-a参数来指定，比如下面的例子，就是用字典+掩码的破解方式

 

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked -i -a 6 /wordlists/rockyou.txt  ?a?a?a?a 


下面是掩码 + 字典的破解方式：

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked -i -a 7 ?a?a?a?a /wordlists/rockyou.txt

 

可以看到这种破解方式破出的密码


最后我们看看，有多少密码破解了

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# wc -l linkedin.cracked

61033579 linkedin.cracked

 

通过简单的破解，我们就发现已经有50%的密码破解了

 

接下来我们分析下破解出的明文密码(或者字典文件），有好几种工具可以做这个，但是我比较喜欢使用PACK(https://thesprawl.org/projects/pack/)

 

首先我们将明文密码提取出来

cut -d : -f 2 linkedin.cracked > linkedin.analyze

 

然后我使用 statsgen.py 工具获取top 20的掩码(mask) 

 

我们将这个文件保存成以.hcmask为扩展的文件，然后使用这个掩码文件配合Cudahashcat来暴力破解下。

 

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked -a 3 linkedin.hcmask

 

我们也可以通过其他明文密码文件来提取掩码，比如通过rockyou.txt的明文字典

 

root@kracker:~/LINKEDIN_WORKING/cudaHashcat/tools/PACK# pythonstatsgen.py /wordlists/rockyou.txt -o rockyou.masks

 

我们可以根据并发，复杂性，optindex和目标的破解时间来优化掩码文件 

现在我们结合这3个掩码文件进一个文件，移除重复的。破解６位密码

root@kracker:~/LINKEDIN_WORKING/cudaHashcat/tools/PACK# catrockyou-optindex.hcmask rockyou- complexity.hcmask rockyou- occurrence.hcmask |cut –d , -f 1 | sed -r '/^.{,12}$/d' | sort -u > rockyou.hcmask

然后我用这个掩码文件再次破解linkedin的哈希

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/link01.txt -o linkedin.cracked -a 3 rockyou.hcmask

 

可以看到这次我们破解出的数量多了很多

 

现在把剩余没有破解的哈希合并成一个

root@kracker:~/LINKEDIN_WORKING/cudaHashcat/HASHFILES# cat *.txt| sort -u > linkedin.remaining

 

然后用刚才新建的rockyou.hcmask，批量跑下

 

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/linkedin.remaining -o linkedin.cracked  -a 3rockyou.masks

整理字典的还有一个小工具叫 hashcat-utils （https://hashcat.net/wiki/doku.php?id=hashcat_utils），他能够根据单词来拆解字典 

我们这里使用已经破解出的linkedIN的明文密码来拆解出更小的单词字典，命令如下

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# cat linkedin.cracked| cut -d : -f 2 > linkedin.dic

root@kracker:~/LINKEDIN_WORKING/cudaHashcat/tools/hashcat-utils#./expander.bin < ../../linkedin.dic | sort -u > ../../linkedin.exp

 

用拆解出来的字典再次破解下

root@kracker:~/LINKEDIN_WORKING/cudaHashcat# ./cudaHashcat64.bin-m 100 --remove HASHFILES/linkedin.remaining -o linkedin.cracked  -a 1linkedin.exp linkedin.exp

 

最后我们通过种种暴力破解组合，总共破解了85%的明文密码
