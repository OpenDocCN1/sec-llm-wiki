**一、【新增功能】****标签检索与过滤**  

HUNTER上线至今，资产标签一直是平台的独家定制内容，深受铁子们的喜爱，常常会有粉丝宝宝在用户群反馈希望标签检索功能提上日程。

HUNTER一路走来，始终把用户的诉求放在第一位，得益于一线项目团队的呕心沥血，资产标签检索在经历千呼万唤之后终于上线啦！

  

![](../Images/968b994dedd93fe31ba5bfc3ecba406c.png)

  

在此次**v2.1.1版本中，新增了资产标签检索与IP标签过滤功能，数据后台的资产标签积累了100个以上**哦~

回到平台的具体操作上，铁子们不仅可以在【IP标签过滤】栏选择“是”过滤掉标记为云厂商、CDN、疑似蜜罐的IP~

还能选择web服务资产后，在【资产标签】栏选择展示诸如登录页面、OA、CMS等任意标签类型的资产，通过IP标签过滤和资产标签选择相结合的方式快速定位目标资产。

  

![](../Images/f9c94efd0b697556fc4b56a598a9c472.png)

  

**小猎手温馨提示**

  

![](../Images/636fece17183ae80f3fbd13106f7de6a.png "小猎手头像.jpg")  
  

1）标签过滤是HUNTER为【付费用户】开辟的专属功能，包含web.tag和ip.tag两种专属语法，web.tag目前仅支持web服务资产使用哦！

2）除了标签语法外，相似语法类目的web.similar、 web.similar\_icon和web.similar\_id也是【付费用户】的专属语法~

3）资产标签支持语法检索，但API不能使用哦~

  

  

  

  

  

![](../Images/f8908c7f9ad82f2e12b60e1b68b5fcb3.png)

  

**二、【新增功能】****导出全部资产**  

查询到想要的资产列表以后，HUNTER旧版本只能选择按条数或者按页码导出，即使铁子们荷包鼓鼓，想要导出所有资产仍旧需要手动输入导出条数……

所以**HUNTER v2.1.1版本推出了全部导出功能，积分充裕的铁子们完成筛选以后，可以一键导出当前列表的全部检索结果啦！**

  

![](../Images/42edb809162204b5ee1573e9543262f6.png)

  

虽然单条语法目前的导出上限还是1w条，但产品经理已经在设计方案优化该问题啦~

  

**小猎手温馨提示**

  

![](../Images/636fece17183ae80f3fbd13106f7de6a.png "小猎手头像.jpg")  
  

从HUNTER v2.1.1版本开始：

1）平台检索的扣分规则修改为：每条语法检索结果第一页的前5条资产免费赠送，后5条资产扣除5分

2）无论使用平台还是API检索，若查询结果中资产为0，则按照单次检索扣除1分

  

  

**三、【新增功能】****域名排行**  

在v2.1.1版本中，我们**新增了域名排行功能**。铁子们输入检索语句后，进入资产列表页即**可看到基于检索结果聚合的TOP10域名排行,还可单选或多选任意域名下钻检索。**

配合线下小工具简直爽翻，懂的都懂~

![](../Images/10ac5ac0bae24aedd5b3a55b3d27a0da.png)

  

![](../Images/b38e816007e33f39f934cfc7b1984fcf.png)

  

  

**四、【优化功能】****详情页证书信息**  

HUNTER v2.1.1版本在IP详情页新增了证书的【基础信息】模块，展示证书原始信息解析后的内容，提升了证书信息的可读性。

**证书基础信息中，将直接展示证书的可信或不可信状态，且****SHA-1、SHA-256、SHA-MD5、使用者(CN)、备案名称(O)、组织机构(OU)、颁发者、颁发机构等信息都支持点击下钻检索。**

  

![](../Images/3b1499cf4f2a85d8260f4e8df0cb4810.png)

  

企业详情页中的【证书概况】原先只做了企业证书版本、颁发者、使用者、使用组织、有效期和状态的基础展示。

HUNTER v2.1.1版本**新增了企业证书的使用域名数，优化了企业所关联证书的匹配状态、可信状态，还增加了证书详情的下钻功能。**

  

![](../Images/9057b332126ac6b86ed37c8d89ce6141.png)

  

在上图的【证书详情】栏点击”查看”，即可进入下面的证书详情页！

  

![](../Images/3e6bb3b8dd73b3f2f51ee54e28990167.png)

  

敲黑板，划重点啦！小编在此帮铁子们做个总结~**HUNTER平台目前支持的证书语法一共有11条**，具体如下：

  

| **证书语法** || **语法说明** |
| --- | --- |
| cert || 证书信息文本检索 |
| cert.subject || 证书使用者检索 |
| cert.subject\_org || 证书使用者组织检索 |
| cert.issuer || 证书颁发者检索 |
| cert.issuer\_org || 证书颁发者组织检索 |
| cert.sha-1 || 证书SHA-1检索 |
| cert.sha-256 || 证书SHA-256检索 |
| cert.sha-md5 || 证书SHA-MD5检索 |
| cert.serial\_number || 证书序列号检索 |
| cert.is\_expired || 证书是否过期检索 |
| cert.is\_trust || 证书是否可信检索 |

  

anyway,证书相关的那点事儿，算是都被HUNTER挑出来整明白啦！

  

  

**五、【优化功能】****备案相关检索联想**  

HUNTER v2.1.1版本推出了**企业名称和备案号的【猜你想搜】联想框~**  

具体操作步骤如下：第一步，输入基础语法“icp.name或icp.number”

  

![](../Images/23d2a05f225070120fe29519fa9dedc6.png)

  

第二步，选择icp.name或者icp.number 语法，并在双引号内输入企业名称或备案号信息，查询语法下方将会弹出【猜你想搜】联想框

  

![](../Images/0e8e9f879a0859f31e646a2a0cc5dcd7.png)

  

第三步，待企业名称或备案号名称输入完毕后，可直接下钻选择目标企业或备案号的相关资产

  

![](../Images/c240d3ed19da78958440603c6d8f096e.png)

  

  

**六、优化功能****一些优化集合**  

**1、 登录页新增注册入口**

平台旧版本注册入口和登录入口是分开的， 这就导致有时候进了登录页发现没有注册账号，还得退出来重新到首页找注册入口…….

HUNTER v2.1.1版本**在登录页增加了注册入口**，铁子们可以直接选择【马上注册】跳转至注册页，再也不用回到首页来回切换啦！

  

![](../Images/21077def526dfcc7bab6bf91e79cb69c.png)

  

**2、登录注册后携带筛选条件**

HUNTER从这一版本开始将会**保留用户未登录状态下的检索和筛选条件~**

也就是说，即使新手宝宝们在未注册或未登录状态下查询了资产，登录平台后继续使用就能直接跳转到上次未登录时的检索界面啦~

  

![](../Images/e4414031761a35881c3207ff5006498e.png)

  

**3、 查询语法分类**

HUNTER平台在年前迭代版本做了语法体系重构的一整个大动作，不仅对新旧语法做了兼容，还将平台语法的组成规则统一为：分类.语法=“查询内容”

  

![](../Images/f4eaae046aa973475be2ffb981b9b43a.png)

  

为了方便铁子们快速查找语法， v2.1.1版本继续优化，**在首页“查询语法”语法内容左侧新增一栏【语法分类】~**

不管是想找ip还是domain、header，查询语法一览无余，快快去首页体验吧~

  

![](../Images/f79640998fe04ff271d7c83595d7f921.png)
