0x00 前言

近期拿到了某邮件系统的一套源码，看到是YII框架编写的，本着学习YII框架出发，顺带对该套系统进行了审计。

0x01 YII框架路由初识

YII框架支持两种URL构造格式，分别为默认的格式和漂亮格式，漂亮格式使用额外的路径跟在入口脚本名之后，来展现路由和相关参数，默认格式/index.php?r=post/view&id=100 的路由为post/view和参数id为100，使用漂亮格式则简化成/index.php/post/100。

YII框架使用MVC模式进行开发，如果不了解MVC模式可以参考链接，不再赘述：https://www.yiichina.com/doc/guide/1.1/basics.mvc

想访问API目录下的controller 目录中的abccontroller.php内的public function add()方法，可如下构造

http://127.0.0.1/api/index.php?r=abc/add

0x02 漏洞挖掘-任意登录

在api/controllers/PostController.php中存在一个模拟登陆方法：

接下来跟到上文中提到的验证的位置，该位置为所有API方法调用时必须校验的方法：

api/classes/ApiController.php

  1. private function checkServerTypeParams() {
  2.    if (! in_array( ClientUtils::getClientIP(), Config::getApiAllowUserIps() )) {
  3.       $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_IP_SOURCE );
  4.    }
  5.    $id = $this->getParamFromRequest( 'id' );
  6.    $time = $this->getParamFromRequest( 'otime' );
  7.    if (! ParameterChecker::checkLength( $time, 20 )) {
  8.       $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECK_PARAM );
  9.    }
  10.    if (! ParameterChecker::checkIsDate( $time )) {
  11.       $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECK_PARAM );
  12.    }
  13.    $checkSum = $this->getParamFromRequest( 'ochecksum' );
  14.    if (! ParameterChecker::checkLength( $checkSum, 32 )) {
  15.       $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECK_PARAM );
  16.    }
  17.    $md5String = md5( $id . $time . Config::API_CHECKSUM_KEY );
  18.    if ($md5String != $checkSum) {
  19.       $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECKSUM );
  20.    }
  21. }

可以看到该接口需要获取IP，并且与可允许的IP进行匹配，如果为同一个IP则进入该方法。进入该验证方法以后前端传入ID,OTIME与ONCHECKSUM进行验证，其中ID为固定ID，为模拟登陆模式，time为日期形式可以是随便一个日期只要符合条件就行，ONCHECKSUM则与ID,OTIME和API_CHECKSUM_KEY三者拼接起来的md5校验是否一致，最终校验通过以后验证通过，可以执行后续方法。
