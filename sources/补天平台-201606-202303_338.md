人民教育出版社始终致力于基础教育教材和其他各级各类教材及教育图书的研究、编写、出版和发行工作。建立安全应急响应中心（PEP Security Response Center），旨在联合众多安全专家共同发现企业潜在安全威胁，实现对企业安全守护的目标。希望安全领域的专家、白帽子、社会团体反馈人民教育出版社产品和业务相关的安全漏洞，共同守护用户的安全。

  

**漏洞接收地址：**

    https://pep.butian.net/

  

**漏洞奖励规则：**

    高危漏洞：1000-2000

    中危漏洞：300-500

    低危漏洞：30-100

  

**特别声明：**

    希望您不要公开和传播任何与我们有关的漏洞信息。对于您提交的漏洞报告，我们会安排安全人员进行审核、跟进并及时反馈最新的处理结果，并会依据情况，按照“漏洞奖励方案”对您的付出表示感谢。

补天平台帮助企业建立专属的安全应急响应中心（Security Response Center），通过在线发布漏洞奖励计划，享受来自补天平台注册认证的数万名白帽专家7\*24小时安全测试服务。

采用“竞争优先”和“风险最小化”原则，多角度、全方位、高度积极地发现和报告漏洞。

补天的安全众包模式发挥白帽专家主观能动性，漏洞奖励全部发放给贡献者，实现精益管理。

专属SRC主要有以下两种服务类型

100%效果付费，无漏洞不收费，消费透明；企业可自定义漏洞奖励标准与漏洞奖励价格，自主控制测试范围。采取漏洞奖金预充值的方式。  

  

![](../Images/dc03e511e2b13c67b45bec4e65548597.png)包年版![](../Images/44760bb8433220be9d4e6a1b00bfba46.png)
