看到了熟悉的\_\_wakeup魔术方法，自然而然的想到了PHP对象注入，

发现下面果然是用到了unserialize反序列化函数。

 

$s =$\_POST\['5e2859d3dd1538c586dfeda8343e64a5'\];

    $s = unserialize($s);

 

这里获取了5e2859d3dd1538c586dfeda8343e64a5参数，并且进行反序列化

 

I only know thekey is in file 5e2859d3dd1538c586dfeda8343e64a5.php
