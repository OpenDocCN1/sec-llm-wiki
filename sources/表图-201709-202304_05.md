# 硅谷银行被接管事件（跟踪报道第二发）

硅谷银行从爆出被迫低价卖出证券以获得流动性支持并寻找股权融资到10号被联邦储蓄保险公司FDIC接管只用了2天，详情可参考上一篇公众号文章。

事情发展得非常迅速，3月12日，美国财政部、美联储和FDIC发表联合声明：

一是宣布全额保证硅谷银行和另一家出险银行Signature Bank（这家纽约银行有1100亿美元资产，周日被FDIC接管）的所有存款。救助不需要纳税人买单， 两家银行的股权持有人和某些无担保的债务人将不会得到保护， 可能的剩余成本由FDIC 的存款保险基金承担，通过一次特别评估由所有美国银行共同分摊。两家银行的储户都可以在周一早上完全取款。

二是在美联储建立一个新的贷款机制，称为银行定期融资计划BTFP。将允许银行将国债、抵押贷款支持证券 (MBSS) 和其他合格资产作为抵押品以获得价值与其抵押证券面值相等的一年期贷款。该现金的借款利率将固定为“一年期隔夜指数掉期”，即联邦基准利率加 0.1%。这些条款非常慷慨，国债和MBSS 通常以低于面值的价格交易，尤其是在利率上升时，10个基点的惩罚性利率几乎是象征性的。

这些行动是否等同于政府救助？很难说。FDIC通过踢出股东和部分债券持有者，以及可能通过向银行体系征收费用来完全偿还存款人。这表明，其他银行而不是纳税人，可能会承担硅谷银行和Signature Bank错误行为的成本。

尽管FDIC公司仅为25万美元以下的银行存款提供保险，但联邦银行法中的一项规定赋予他们保护未投保存款的权力，如果他们认为不这样做会对更广泛的金融系统构成系统性风险。在这种情况下，未投保的存款可以得到保险基金的支持，即由整个美国银行业承担成本。系统性风险的判断必须得到美联储理事会三分之二的理事和FDIC董事会以及财政部长珍妮特\-耶伦的支持。

但同时很明显的，政府在支持银行系统方面的作用已经扩大，因为银行可以用优质资产换取现金的条件很宽松。

《经济学人》杂志的前主编沃尔特\-巴盖特（Walter Bagehot）在1873年写道，中央银行的关键作用是充当银行系统的最后贷款人—以良好的抵押品和惩罚性利率放贷。这使中央银行能够稳定金融系统，防止流动性不足的银行导致其他有偿付能力银行的消亡。美联储已经有一个贷款机制，称为贴现窗口，银行可以用他们的抵押品按公允价值借款。新方案不仅保护银行不受流动性问题的影响，还能使它们免受利率风险的影响。这可能会拯救硅谷银行，因为硅谷银行陷入现在的窘境和过去一年美联储大幅上调利率关联很大，但也可能会鼓励其他人更多的鲁莽行为。

3月13日，汇丰银行宣布将以1英镑的价格收购硅谷银行的英国子公司。英国财政大臣亨特在社交媒体披露，是英国政府和英国央行促成了此项交易。他强调英国的纳税人不会为此埋单。

银行被挤兑破产曾经很常见，美国大萧条期间，1929年有650家银行倒闭，1930年有1300多家；总共有9000多家银行倒闭。最终阻止蔓延的是1933年FDIC的成立，FDIC由成员银行出资，为每个账户投保2500美元。

在上周美联储主席鲍威尔的鹰派发言后，周五时芝商所的FedWatch Tool显示有近5成可能22号美联储会加息50个基点，今天看加息50个基点的可能性已经直降到0了，而不加息的可能性则从0增加到了36.5%。

美国监管机构的果断决策和行动，基本已经消除了恐慌性挤兑向整个银行业蔓延的可能性，加密货币市场今天也反弹惊人。我估计硅谷银行和Signature银行最后很可能会被整体收购，看起来他们的资产质量并不差，这次挤兑还是流动性危机。以后碰到名字里带S和B的银行就绕着走吧。
