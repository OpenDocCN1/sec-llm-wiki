# 如何输出应用软件漏洞分析报告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzOTI4NDQ3NA==&mid=2247483745&idx=1&sn=8871fc6e656ec2c38c9fb66f590688f3&chksm=facb87f4cdbc0ee254a0a72039eefdde3b54447ede7d1283c87adbe77f6980ad6fe095ecf4dc&scene=126&sessionid=1681322192#rd](http://mp.weixin.qq.com/s?__biz=MzUzOTI4NDQ3NA==&mid=2247483745&idx=1&sn=8871fc6e656ec2c38c9fb66f590688f3&chksm=facb87f4cdbc0ee254a0a72039eefdde3b54447ede7d1283c87adbe77f6980ad6fe095ecf4dc&scene=126&sessionid=1681322192#rd)

\[应用场景\]:需要对已知或未公开漏洞进行人工分析交付时，包括内部分析报告/漏洞分析分享/技术文章

\[格式呈现\]:WORD/PDF/技术文章

\[重点内容\]:

  漏洞名称 #官方对该漏洞的客观命名，通常包含CVE编号

漏洞成因描述  #描述产生漏洞的缺陷处理机制和位置。

影响范围  #描述该漏洞对应用软件的影响版本，包括受影响的版本、不受影响的版本

利用场景  # 描述该漏洞可被利用的攻击方式或场景

漏洞详细分析  #描述该漏洞被触发的详细过程及具体操作方法、函数、指令等内容

修复建议  #对该漏洞进行修复的官方处置措施建议，通常包括临时性解决方案、通用解决方案

声明  #对漏洞分析报告可能引发的第三方责任进行免责说明

\[辅助内容\]:

漏洞等级  #描述该漏洞的风险等级

利用难度系数  #描述利用该漏洞的技术难度水平的说明

漏洞分析测试环境  #对该漏洞分析所搭建的环境描述

漏洞验证  #描述证明该漏洞的POC代码，或验证图片

漏洞利用演示  #对具体漏洞验证过程的操作演示，如视频录像等

参考链接  #与该分析报告有关的官方或公开参考信息资源列表

\[特殊说明\]:漏洞等级仅从该漏洞造成的破坏影响进行描述，落实到具体企业应用环境，还要结合资产价值、修复难度、已有保障措施等综合评判

\[交付模板\]:略
