# CVE-2021-43703：ZZCMS绕过登录漏洞通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3NjU1MzU3Nw==&mid=2247484202&idx=1&sn=dd2673621ed3be5f114f0686029d1480&chksm=9f5ecf2ca829463a3e344aa45600d4b460a010ffd5d189f00d177f53ff4db052f5270e0a617b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3NjU1MzU3Nw==&mid=2247484202&idx=1&sn=dd2673621ed3be5f114f0686029d1480&chksm=9f5ecf2ca829463a3e344aa45600d4b460a010ffd5d189f00d177f53ff4db052f5270e0a617b&scene=27#wechat_redirect)

  

近期，西安邮电大学网络空间安全学院2021级研究生刘正波、刘宇航同学，在冯景瑜副教授的悉心指导下，对开源的内容管理系统（content management system，CMS）进行漏洞挖掘，发现其中的ZZCMS存在一个未授权访问漏洞。全球知名漏洞披露平台“Common Vulnerabilities & Exposures”对其编号为CVE-2021-43703，同时该漏洞被国家信息安全漏洞库收录公布。

**简介**

![](../Images/e21e47aba64545e3f9cdc3a025877b3f.png)

  

![](../Images/f2fd840e9359fef5608079784f3914e9.png)

  

由于ZZCMS（版本<=2019）只使用JavaScript限制未授权用户访问后台，当未授权用户禁用浏览器的JavaScript后可以直接访问网站后台。

漏洞编号：CVE-2021-43703

漏洞类型：未授权访问

程序：ZZCMS（版本<=2019）

源码地址：https://github.com/forget-code/zzcms

**漏洞分析**

admin/admin.php 是 Web 应用程序管理员身份验证页面。正常情况下，当身份认证失败时，会跳转到登录页面。看到admin/admin.php第15行的跳转代码，页面通过 JavaScript 重定向后并没有通过die()函数来阻止程序执行。所以禁用 JavaScript 后，可以直接访问后台。![](../Images/d5e4f1f25ae928f36b5c802878949080.png)

**漏洞复现**

下载源码，在本地部署后访问直接网站后台：192.168.119.213/admin/index.php，发现网站自动跳转到了登陆页面。![](../Images/2c968e78d46ed26808bb2b9787c449cc.png)接下来尝试禁用js后进入后台。在火狐浏览器的地址栏输入 about:config，然后搜索JavaScript，点击 javascript.enabled后面的按钮，让 javascript.enabled的值变为 false。![](../Images/69dd07e78b018090497df7f952788213.png)然后再次进入后台：http://192.168.119.213/admin/index.php，现在可以在后台任意操作了。  
![](../Images/850c90c29e1b1a16504415e0f508f0bf.png)

**修复方案**

更新到最新版本或者在该系统文件admin/admin.php第16行添加exit()或die()。![](../Images/33ef29e821b69ff71e26eaff4c058a0e.png)
