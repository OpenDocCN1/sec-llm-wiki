# 【电脑清洁】清洁电脑必知的6大要点

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk4MDE2MA==&mid=206366897&idx=2&sn=4a7ff7e8321abc2b870f72e19fc70107&chksm=2e8b755e19fcfc48bb5c252c82f75bef1c06f59669f5ec41dcee15f1e62558f6d5af4b0ae6c2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=206366897&idx=2&sn=4a7ff7e8321abc2b870f72e19fc70107&chksm=2e8b755e19fcfc48bb5c252c82f75bef1c06f59669f5ec41dcee15f1e62558f6d5af4b0ae6c2&scene=27#wechat_redirect)

**1.屏幕清洁**

众所周知，长时间面对电脑辐射，皮肤便会出现长痘、长斑、暗淡出油等不适症状![](../Images/6c92c1ba555f73dfeba8bd534f7d4e55.png)，如电脑屏幕没有定期进行清洁，附着在上面的灰尘等微小颗粒更会加大辐射量哟！

而电脑屏幕作为电脑最娇贵的部件，其成本占到了整机的30%，是由多层反光板、滤光板、保护膜组合等脆弱材料组成，因此清洁时切勿用纸巾、清水、酒精擦拭，以免造成屏幕出现模糊、水波纹。

![](../Images/91a733adc1a2ab09d95f0f33d43036ca.png)  

**2.键盘清洁**

键盘是笔记本电脑里最容易堆积灰尘的部件（看到这，建议乡亲们看看自己的键盘是否油光发亮呢）![](../Images/0b446d426bb71ec42001b556334b7399.png)，过多的灰尘会加速键盘导电橡胶的腐蚀最后造成键盘失灵。

更重要的是，键盘是与我们接触最直接的部件，灰尘的聚集必然会导致细菌的滋生，从而使我们出现莫名的皮炎、呼吸道疾病等。

清洁时，可使用皮吹，毛刷进行键盘缝隙大颗粒灰尘的清洁，然后把清洁液喷洒在清洁布上再进行键盘擦拭（切忌不可直接喷洒在键盘上）。

![](../Images/df684d353ac97bc91e62e28bca783414.png)  

**3.散热器清洁**

电脑使用一段时间后，便会出现卡慢、热、噪音大症状，这很可能是因为灰尘聚集在散热器，堵住出风口的原因哟。

散热器上的风扇、散热片等均需要开机清洁，所以必须要小心行事哟，以免拆得开，装不上哟！![](../Images/2ae8b42429df0db53a60a73c0db321ab.png)

![](../Images/564057da40eac60292f78747b5382305.png)

**4.释放静电**

静电属于高压电，电压可能高达10多万伏，随时可能造成电容击穿、电脑主板故障等问题，最后不如不清洁呢！![](../Images/6c92c1ba555f73dfeba8bd534f7d4e55.png)

所以，在进行电脑清洁前务必断开电源、卸掉电池，完全释放完静电再进行拆机操作。

![](../Images/9b541c5e2ac4686e4c868c7cf57ab1a2.png)  

**5.清洁液的选择**

清洁电脑时，务必使用正规厂家的电脑清洁专用剂，切勿使用含有丙酮（Acetone）、甲苯（Toluene）、乙醛（EthylAcid）、氨（Ammonia）或甲基氯（MethylChloride）等化学试剂液体，以免造成电脑部件腐蚀，产生不可修复的破坏。![](../Images/049d8969a3e645438e61b7382e8c7cfe.png)

**6.开机**

电脑清洁完毕后，务必确保所有部件都已经晾干才能打开电脑，否则可能出现短路、腐蚀等电脑故障哟！
