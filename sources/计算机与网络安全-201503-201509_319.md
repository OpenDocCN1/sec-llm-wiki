# 【宽带】揭露“假宽带”：谁偷了咱们的带宽？

近日，测速网SpeedTest.cn发布的用户网速满意度调查显示，在参与调查的9400多名用户中，感觉非常失望的用户超过了半数，近八成的用户对网速不满意。虽然“宽带提速”的声音已经喊了好久，但时至今日，因带宽问题影响到用户体验的现象依旧十分普遍，那么，究竟是谁动了我们的带宽呢？

  

**带宽都去哪儿了?**

“我们承诺的带宽与用户实际使用的相差甚远是普遍现象，这就是所谓的假宽带。”一位不愿透露姓名的网络运营商技术主管透露，宽带速度受到诸多因素影响，一般都达不到运营商承诺的速度。造成这种现象除了一小部分因为线路质量等造成的物理损耗外（例如ADSL如果距离机房较远会导致信号衰减较大），更多的原因是因为上网拥塞。

  

目前，所有运营商宽带接入大体分为两种：ADSL和LAN（歌华有线亦属此类）。严格来说，这两种方式都是共享网络，只是共享范围不一样，ADSL和LAN的区别主要是最后1000米，ADSL最后一公里使用的是电话线，由于铜质电话线带宽有限，用户必须升级到入户光纤才能达到8M、20M甚至100M的带宽接入。

  

和ADSL不同的是，LAN往往是二级运营商采用的宽带接入方式，也就是说，这类运营商先向上一级运营商购买一定带宽的宽带，然后再分给各个用户。一般情况下，为了充分利用宽带资源、增加宽带收益和减少成本，运营商会计算出一个上网在线比率，并会在标准配置基础上增多配置用户。

  

上述技术主管强调称，“在线比率没有国家统一规定，运营商往往根据自身情况确定，因此一些小的运营商为抢占更多业务，往往不顾在线比率或提高设备扩容，导致宽带不足，从而对消费者造成欺骗。”

  

某宽带业内人员透露，他在包了100兆宽带之后，开始往外分发。如果每人分10兆，可以分给10个人；而如果每人1兆的话，就可以分给100个人。当这100个人中只有10个人在上网的时候，它可以保证质量，但如果这100个人都在上网，那这个速度就达不到了。

  

**电信业也有“黑势力” ?**

除了所谓的“假带宽”之外，宽带垄断现象也在许多小区中普遍存在。“他们（小区宽带运营商）都和物业串通好了，整个小区的宽带业务都被他们垄断了，别家根本进不来，但是我们总不能因此而搬家吧？”某小区宽带用户诉苦道。“物业对进入小区的其他宽带运营商都要收取高额的入场费，每户200块钱，而这个拥有1800住户的小区，入场费就高达36万！”据某小区网管员透露，即便是一些比较开放的小区，宽带运营商之间的竞争也是非常激烈的，除了价格战外，剪断对方线路、关闭对方设备的电源等现象也频频出现，造成的影响更为恶劣。

  

另外，要解决上网用户不断增加、带宽需求不断加大的问题，只有不断大量地增加投入资金，用于网络设备等设施建设维护以及带宽升级。但现实中，为了保障收益，运营商的基础建设和带宽往往跟不上用户的需求，宽带提速也就出现困难。

  

**如何告别“假宽带”?**

专家表示，在宽带运营商选择方面，用户要根据自身需要和经济收入选择相应网速及资费，不要只图网速高而花冤枉钱，毕竟“一分钱一分货”的道理任何时候都是适用的。但要想从根本上杜绝“假宽带”，相关部门要执行“两手抓、两手都要硬”，不仅要在基础带宽上有所保证并降低资费，更要严厉打击小区垄断、过高在线率以及不正当竞争等行为。

  

据悉，我国国家发改委、财政部、工信部、科技部、国务院国资委等多个部门已成立工作小组，将共同组织宽带中国战略研究。在战略性新兴产业和信息产业两个“十二五”规划中，也分别提到实现宽带中国战略和启动宽带中国工程，国家宽带战略已经呼之欲出。但是从长远来看，告别“假宽带”依然任重而道远。
