# 【隐私】如何永久性地删除硬盘数据？

**如**果你打算出售自己的计算机或硬盘，删除当中存储的资料数据显然是非常必要的措施。但当你使用Windows标准方法删除数据时，硬盘当中的文件其实并未真正被删除，它们只不过变成了不可见状态，并被随后添加的新数据所覆盖。因此，即便数据从硬盘中被删除，你（或者其他人）依然可以使用数据恢复工具重新看到被删除的内容。那我们要如何才能永久性地删除硬盘数据呢？  

**方法一：手动删除数据**

如果你想要删除部分数据，并确保其他数据的安全，手动删除是一种理想的方式。但需要注意的是，如果你的硬盘当中存储着大量的个人数据，这种方式可能会产生遗漏。

  
想要永久性地删除数据，你需要下载专用的工具。本文当中所用到的工具名叫File Shredder，它是目前最为流行的文件粉碎软件，不仅非常易于使用，且完全免费。

  
![](../Images/a6c57db60a7fbe6ba4e780e385340eef.png)  

File Shredder提供了两种删除数据的基本选项，分别是“添加文件”或“添加文件夹”。前者可用于删除视频、图片或文档等独立的文件，后者可以彻底删除某个文件夹中的所有文件。

![](../Images/cacaad9de4b1baccb8722f12f913d3bb.png)

![](../Images/3214ab77952a8cdab81040eba27c410c.png)

![](../Images/8ca7d3a3f6b1d103bcad9968adae633d.png)

选定文件之后，它们会被添加到文件粉碎的队列当中，随后你可以点击窗口底部的“现在粉碎”来将它们彻底删除。需要注意的是，窗口左侧的“移除选定”和“移除所有”并非针对文件本身，而是用于将文件从粉粹队列当中移除。

![](../Images/e7210b48930bfcfd7fc1a9e81f923410.png)  

在安装了File Shredder之后，它会在系统右键菜单当中加入相关的操作选项。如果你想要删除某个文件或文件夹，并不需要开启该软件，只需右击该文件/文件夹，并选择File Shredder所提供的选项。

![](../Images/82200b4b7bb85619290769f0e53358d6.png)

![](../Images/8b64fdfaf75123587d8cc2fbfcf74d00.png)

点击右键菜单当中的“安全删除文件”之后，系统便会弹出确认操作的对话框。再次点击确认，这些文件便会被彻底删除。

File Shredder还有一个非常实用的功能，它可以让你删除所有之前使用Windows标准方式删除的数据。正如上文所提到的，虽然你无法查看这些被删除的文件，但它们的确依然存在于硬盘当中，并可被数据恢复工具所恢复。而File Shredder可以帮助你彻底将其删除。

![](../Images/f7f36f57b3fb39c0c604ace01b9fa9c3.png)  

想要执行这一操作，你只需开启File Shredder，然后点击“粉碎可用磁盘空间”即可。

**方法二：彻底擦除硬盘**

如果你打算把硬盘赠予或出售给其他人，彻底擦除当中的所有数据是个更加保险的方法。执行这一操作之后，硬盘会被完全擦除，且没有任何方法可以恢复之前的数据。不过在此之前，你应该确保当中的所有重要数据都得到了备份。

想要彻底删除所有数据，你需要一款名为DBAN的工具，它会使用伪随机数字在硬盘上进行数据的重新写入，以确保之前的数据无法被恢复。DBAN可免费使用，但高级功能需要付费。

![](../Images/ac3ae3c1d32abec017d54251780537e4.png)  

这款工具并不能在Windows下运行，你需要将其复制到U盘或光盘当中，然后在系统启动时将其加载。随后，你就可以根据界面当中的文字说明进行硬盘的彻底擦除了。整个擦除过程可能需要数个小时。

**方法三：物理摧毁硬盘**

这种方式可能有些极端，可如果你不想要长时间等待数据擦除，也不打算再使用当前这块硬盘，那你可以索性将其彻底销毁。如果方法正确，那这块硬盘当中的数据是无论如何也不可能被再次提取了。

![](../Images/38de62149ea284da11c009bb3d8b0504.png)  

摧毁一块硬盘的方法有很多，包括碾磨、粉粹、熔融、焚烧和崩解，但这些都需要正确的机器或工具才能实现。如果你打算自己将其摧毁，可以使用电钻或尖锐物体将其穿刺，只要确保硬盘的圆盘部分被正确摧毁就行。需要注意的是，请不要以焚烧的方式或使用腐蚀性液体摧毁硬盘，这些方法可能会危及自身安全。

![](../Images/410b7826adf24e8c2c3f557b01d141a6.png)  

如果是固态硬盘，你必须正确摧毁其存储芯。
