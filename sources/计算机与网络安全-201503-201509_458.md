# 【网络】Win8系统如何共享无线，实现手机上网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk4MDE2MA==&mid=204499032&idx=3&sn=d294943912a3b79a460d26529732be65&chksm=2ef7f5b719807ca13cf8295e3a2cf28afafcb0d01b7ba45912f67f7289a607a33cab78639b38&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=204499032&idx=3&sn=d294943912a3b79a460d26529732be65&chksm=2ef7f5b719807ca13cf8295e3a2cf28afafcb0d01b7ba45912f67f7289a607a33cab78639b38&scene=27#wechat_redirect)

![](../Images/a382587325fdcf306d11c379286e892f.png)

****操****作步骤:  
1\. 首先确认无线网卡开关开启，驱动程序已成功安装，无线网络功能可正常使用。  
打开 控制面板---查看网络状态和任务，点击左侧的“更改适配器设置”，确认这里有“Wi-Fi”网络连接。如下图所示：‍

![](../Images/f24db14b1c35b00c8f27310364b4e98f.png)

在桌面“计算机”图标右击选择“设置”，点击“设备管理器”，或直接按“Windows”键和“X”键，选择“设备管理器”，确认“网络适配器”下无带叹号设备，存在无线网卡设备和“Microsoft 内核调试网络适配器 ”，如下图所示(不同品牌不同型号无线网卡名字略有差异,下图以Atheros AR9285为例)。若无这两个设备，请将现有无线网卡驱动程序全部卸载，重新安装联想网站提供无线网卡驱动程序尝试。

![](../Images/f63540699b346623bf93fd6a37d62d39.png)

若有向下箭头图标，请右击此设备选择开启。如下图：

![](../Images/b51c8fb81ef3ddb60bbbfa61e8b6feb7.png)

若有“wan微型端口”带有叹号，请参考备注说明处理。

![](../Images/a2a0f0d9bbcdf0fd4c23845eb6b3528e.png)

鼠标点击右下角任务栏网络图标，若出现周围其他网络信号，无线网卡即为可用状态。

![](../Images/c42edfb2929afe2b38adc93eaad3bcb0.png)

2\. 确定网络共享相关服务是否开启。  
可右击桌面“计算机”图标，依次打开“管理”---“服务和应用程序”---“服务”（或同时按下“windows键和R键”，输入“services.msc”，点击确定打开“服务管理器”），查看“Internet Connection Sharing (ICS)”和“Remote Procedure Call (RPC)”服务是否启用。若“手动”未“正在运行”，在相应服务右击选“启动”；若“禁用”，相应服务处右击选“属性”，“启动方式”设置为“自动”，点击“应用”按钮，点击“启动”，再点击“确定”，完成设置。

![](../Images/25c7faa8a577f0c739a89913c61f4d66.png)

3\. 设置承载网络。  
同时按下Windows键和X键，选择“命令提示符（管理员）”。

![](../Images/311a64b4e33ce410a80a279451d55ce1.png)

输入netsh wlan set hostednetwork mode=allow ssid=您想建立的网络名字（英文格式） key=您想设置的密码（至少8位）按下Enter键，设置ssid和密码。（例如 netsh wlan set hostednetwork mode=allow ssid=mywlan key=12345678。）

![](../Images/25d7b17ddc71b32d35b72b63defa8a18.png)

输入netsh wlan start hostednetwork，按下Enter键，开启承载网络。

![](../Images/fc63d5791f939cf3ae93c9f1687762f8.png)

4\. 设置网络共享  
依次打开 控制面板---查看网络状态和任务---更改适配器设置

![](../Images/372d107f731156fae982ed9e84728c4c.png)

若以上命令创建成功，会出现一个“本地连接\*”后面带数字的网络连接。并且中间部分会显示所设置无线网络名称。如下图所示：

![](../Images/ecb95a0ff481b46f409979f9eb5eeb81.png)

在“以太网”右击选择“属性”，点击“共享”，按下图所示设置，点击“确定”按钮保存设置。（若使用宽带连接拨号上网，请在“宽带连接”右击选择属性，设置共享）

![](../Images/55a96c0db4bae6aca3ee4e8656a9530a.png)

以上操作完成以后手机搜索创建的无线网络“mywlan”，使用密钥“12345678”连接测试。  
  
备注:  
若右下角网络图标打开以后“Wi-Fi”显示为“关”，可参考以下操作文档设置：  
2\. 设备管理器若出现“WAN微型端口（网络监视器）”黄色叹号

3\. 输入命令按enter键以后，发现“更改适配器设置”界面中没有“本地连接\*”，首先再次打开“设备管理器”，查看是否是有“Microsoft 托管网络虚拟适配器”被禁用，如下图所示。若被禁用，右击选择“启用”，然后再重新输入命令，创建无线网络。（注：此虚拟设备只有在创建承载网络以后出现，正常情况下是隐藏状态，不可见） 

![](../Images/1f25b3bc4cbe0cf2d2c5613f76343a62.png)

若以上操作完成，仍无法出现“本地连接\*”，请打开 “控制面板”-“系统和安全”-“Windows 防火墙”，点击左侧“允许程序或功能通过Windows防火墙”，找到“Windows Communication Foundation”项目，查看是否全部勾选，全部勾选以后点击确定，再尝试重新创建无线网络。 

![](../Images/726520e4b4c36545672db101b9a75e5c.png)

若手机已连接所创建无线网网络，但无法打开网页，首先将电脑所安装所有防护软件暂时关闭或暂时停止防护，再打开“控制面板”---“系统和安全”---“Windows 防火墙”，点击左侧“打开或关闭Windows防火墙”，这里暂时都设置为关闭，然后手机再重新打开网页尝试。   
![](../Images/c6394b520a9ac6ccae9d90b224c0b47e.png)若手机端QQ可以收发消息，但是无法打开网页，其他应用不能联网，可能电脑系统DNS服务功能异常，可在“更改适配器设置”中的“以太网”或“宽带连接”（具体情况视所使用联网方式）右击选择“状态”，点击“详细信息”，记录下“IPv4 DNS”信息，手机网络设置里手动设置“DNS服务器”（域名）地址。具体设置方法详见手机厂商提供的使用说明。

![](../Images/d19f8cf434ca85d377c5288b0c719247.png)

也可咨询当地网络运营商咨询所用DNS服务器地址。以下公共NDS服务器地址可以参考使用： 114DNS(114.114.114.114,114.114.115.115)、Google Public DNS (8.8.8.8, 8.8.4.4)、 OpenDNS (208.67.222.222, 208.67.220.220)。附件为网络上收集目前为止全国常用DNS服务器IP地址，可根据所在地区及使用网络运营商就近选择。
