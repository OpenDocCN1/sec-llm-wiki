# 【Linux】命令行查看硬件信息

**在** Linux 中，可用于检查和查看硬件信息的命令有很多。其中某些命令可以输出特定硬件和信息，例如：CPU 和内存等。本教程列出一些 Linux 上查看硬件信息的常用命令，以帮助大家快速输出硬件的配置细节。

**1、lscpu**

lscpu 可以查看 Linux 中有关 CPU 和处理单元的信息，直接使用即可，它没有多余的选项和功能。

> lscpu 

执行之后，你会看到如下输出：

![](../Images/76dfc3e2bdabeae1eaf4e4fd8fa91a41.png)

**2、lspci**

lspci 是 Linux 中查看硬件信息的另一个常用工具，它可以列出所有连接到 PCI 总线的详细信息，例如：显卡、网卡、USB 接口及 SATA 控制器等设备。

> lspci 

直接使用该命令的输出如下：

![](../Images/5da0a8c1f5b5c9888b92116b33e09593.png)

当然，你也可以使用类似如下的命令来过滤出特定的设备信息：

> lspci -v | grep "VGA" -A 12 

![](../Images/81ee338be8c24620f17ecbb8a0523cf8.png)

**3、lshw**

lshw 是一个通用工具，该工具可以执行多个硬件如：CPU、内存、USB 控制器及磁盘等详细信息。lshw 在执行之后会自动提取不同“/proc”文件中的信息。

**命令执行之后的输出，类似如下：**

![](../Images/d063f543eb7bdb3a6186ab4d34b9e288.png) 

**4、lsusb**

lsusb 命令可以显示连接到此计算机 USB 控制器的详细信息，默认情况下 lsusb 命令只会输出简要的摘要信息。你可以使用 -v 选项来输出每个 USB 端口的详细信息：

> lsusb 

**默认输出如下：**

![](../Images/fa0d8bdd4eac3a11a355982513f03832.png) 

**5、Inxi**

Inxi 是一个可以获取多项目硬件信息的脚本工具，它可以为用户输入一个详细的硬件报告。默认情况下，Inxi 并未安装到 Ubuntu 系统当中，我们可以使用如下命令进行安装：

> sudo apt-get install inxi 

**安装好之后，可以直接使用如下命令来输出硬件报告：**

> inxi –Fx 

 ![](../Images/b09b09a4f607bd208e67a2e9c865fa62.png)

**6、df**

df 命令可以输出当前 Linux 系统中的各种分区及其挂载点，并显示每个分区的可用空间摘要信息，我们可以使用 -H 参数进行使用。

> df –H 

![](../Images/cc1e8de6caaefb4819b8b965e2657e74.png)

**7、free**

使用 free 命令可以查看当前系统的内存信息，要查看内存的总数和空闲空间时，大家可使用 free 命令：

> free –m 

![](../Images/ad242b6deba404991d35ef9d37ef410c.png)  

**8、dmidecode**

dmidecode 命令与 Linux 中其它查看硬件信息的小工具的工作方式有所不同，它主要通过读取 DMI 表中的数据来提取硬件信息。

要使用 dmidecode 命令查看 CPU 信息，可以使用：

> sudo dmidecode -t processor 

![](../Images/da0eeb78c168d3a7cfccaf396f5ca2cc.png)

**查看“内存”信息可以使用：**

> sudo dmidecode -t memory 

![](../Images/3035476c69a0ed1e078551fb3d0dd735.png)

**要查看“BIOS”信息，可以运行：**

> sudo dmidecode -t bios 

![](../Images/7b2e9d98ed9610273a5e9f714f502963.png)

**9、hdparm**

hdparm 命令可以输出关于 SATA 设备(例如硬盘)的相关信息：

> sudo hdparm 

**命令执行后，输出类似如下：**
