在很多人眼里，黑客是一群异类。而这些怪咖生来的使命就要找到同类。


每年夏天，全世界的黑客都会像潮水一样涌向赌城拉斯维加斯。加入一场盛大的黑客狂欢——DEF CON。


从1993年的第一次小规模地下聚会开始，直到今年正是第24年。老司机称之为“DEF CON 24”。由于采用完全匿名制的现场现金购票，所以还无法确切统计今年这个地下聚会的参加者人数，不过目测来看，已经超过了一万人。


【DEF CON 24 现场】


当然这一万多人并不都是那么黑的黑客，其中有不少是“票友”，甚至有很多只是提着酒瓶来猎奇的游客。这么大的规模，让 DEF CON 似乎没有办法再继续保持如此小众和另类，不过你依然能在聚会中找到邪性的主题和魔性的黑客。



| 野性的主题村


自由和分享是黑客们的情怀，DEF CON 创始人 Jeff Moss 在今年的开幕演讲特别介绍，不同的黑客们结成的帮派——“主题村”是 DEF CON 这么有活力的原因。


“溜门撬锁”是黑客们最喜欢的项目之一。这种攻击给人带来的精神和视觉愉悦普通大众都能够理解——听到锁簧弹开的一瞬间，感觉世界都臣服在脚下了有木有。

【他们在研究如何毫无痕迹地打开快递封口胶条】



另一个村子里主要聚集了“抓包黑客”，他们主要研究的是网络通信中的包信息。通过这些流量数据搞定入侵。



下面是一个无线电村，黑客门在此分享对所有无线传输信号的破解心得。



在大厅的角落里，还有一个汽车破解村。黑客们把汽车开进了会场，甚至把车机和面板都拆了下来，现场破解。



| 朝圣和布道


当然，除了偏门的黑客主题，还有一些主流的技术分享。来自世界的顶级黑客在三个硕大无朋的礼堂里，向所有的技术信徒布道。



【DEF CON创始人 Jeff Moss 和 L0st 在为现场观众展示炫酷的胸牌】


很多人从世界各地赶来，正是为了朝圣这些“精神领袖”们。



在布道者中，也有来自中国的黑客，例如：来自360的单好奇和张婉桥将在现场分享如何破解 4G LTE；同样来自360的黑客刘健皓会在现场讲解攻击特斯拉汽车的自动驾驶系统。


| 战斗的黑客们


不战斗，怎么能叫黑客呢？


历届 DEF CON 上，都会划出很大的一片区域作为黑客的“战场”。


【DEF CON 24 对抗区域】


这些黑客在紧张地制造一些常人所不能理解的东西，最终组委会将会评定出一些特别的奖项。



当然，还有更为激烈的对抗，那就是每年 DEF CON 的重头戏 CTF（Capture The Flag）。


来自世界的顶级黑客战队会在这里进行攻防厮杀。简单来说，就是要不断破解一个虚拟网络架构中的诸多堡垒，用这些堡垒作为据点攻击对手。一旦比对手优先拿下堡垒，就意味着你可能掌握了绝对的主动权。所以对于攻击的制高点，所有队伍都是分秒必争的。


【b1o0p联合战队在 DEF CON CTF 现场】


值得一提的是，这个 DEF CON 上最受关注的游戏，也是中国的强项之一。2015年，来自中国的 HITCON、蓝莲花、0ops 三支战队分别拿下了比赛的4-6名。不过，这个成绩并不能让他们满意，今年蓝莲花和 0ops 两只战队合体为：b1o0p联合战队，并且加入了腾讯科恩实验室的诸多黑客大牛。比赛将会进行两天两夜，这种高强度的玩命对抗，正好刺激了黑客们爆棚的肾上腺素。


另外，这次 DEF CON CTF 首次引入了机器战队。这支战队会完全通过人工智能的方式，和所有黑客展开决战。


DEF CON 专题 | 溜门撬锁，暗黑市集，带你看世界最大的黑客狂欢所以这次 CTF 对于各位黑客来说，不仅是捍卫自己的荣誉，他们还要联合起来捍卫人类的荣光。

马上要上战场了，必须先来个朋克头和黑客胡须，外表是黑客精神的重要体现。
