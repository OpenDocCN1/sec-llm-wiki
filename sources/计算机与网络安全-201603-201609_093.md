**在很多人眼里，黑客是一群异类。而这些怪咖生来的使命就要找到同类。**  

  

**每年夏天，全世界的黑客都会像潮水一样涌向赌城拉斯维加斯。加入一场盛大的黑客狂欢——DEF CON。**

  

从1993年的第一次小规模地下聚会开始，直到今年正是第24年。老司机称之为“DEF CON 24”。由于采用完全匿名制的现场现金购票，所以还无法确切统计今年这个地下聚会的参加者人数，不过目测来看，已经超过了一万人。

  

![](../Images/009d2af62295c5faddb7ab93991817fd.png)

【DEF CON 24 现场】

  

当然这一万多人并不都是那么黑的黑客，其中有不少是“票友”，甚至有很多只是提着酒瓶来猎奇的游客。这么大的规模，让 DEF CON 似乎没有办法再继续保持如此小众和另类，不过你依然能在聚会中找到邪性的主题和魔性的黑客。

  

![](../Images/61aba9e2c2bb61db479a1ee5105ee7d7.png)

  

**************************| ****************************野性的主题村**

  

自由和分享是黑客们的情怀，DEF CON 创始人 Jeff Moss 在今年的开幕演讲特别介绍，不同的黑客们结成的帮派——“主题村”是 DEF CON 这么有活力的原因。

  

“溜门撬锁”是黑客们最喜欢的项目之一。这种攻击给人带来的精神和视觉愉悦普通大众都能够理解——听到锁簧弹开的一瞬间，感觉世界都臣服在脚下了有木有。

  

![](../Images/e6c1b35174fef2c9c2b8aca68c969114.png)

【萌叔在认真开锁】

  

![](../Images/7ef5dfc075b078509a2dccc9c099a6d6.png)

【这些黑客在破解扎带，就是我们俗称的“一拉紧”】

  

![](../Images/5f0a309c41516f9b587a85ad164f91e9.png)

【他们在研究如何毫无痕迹地打开快递封口胶条】

  

![](../Images/fafb684ffe5573440a5d6c774a414b2b.png)

  

另一个村子里主要聚集了“抓包黑客”，他们主要研究的是网络通信中的包信息。通过这些流量数据搞定入侵。

  

![](../Images/cb9c42cf3edb2afcea6384ff1dd5bdaf.png)

![](../Images/83b90d93844924365a8025124da74cc9.png)

  

下面是一个无线电村，黑客门在此分享对所有无线传输信号的破解心得。

  

![](../Images/779854f9e4587fe40582b1baac2eb8da.png)

  

在大厅的角落里，还有一个汽车破解村。黑客们把汽车开进了会场，甚至把车机和面板都拆了下来，现场破解。

  

![](../Images/2d4c64e73dd5bbbb4c272dc2d94ab66c.png)

![](../Images/02ab0b47bcff721ace685a754345f3df.png)

  

**************************| ****************************朝圣和布道**

  

当然，除了偏门的黑客主题，还有一些主流的技术分享。来自世界的顶级黑客在三个硕大无朋的礼堂里，向所有的技术信徒布道。

  

![](../Images/fde96c08744649ecb379118bdae42906.png)

  

![](../Images/17a116b9d10d3a982bdcc871fb8d8d52.png)

【DEF CON创始人 Jeff Moss 和 L0st 在为现场观众展示炫酷的胸牌】

  

很多人从世界各地赶来，正是为了朝圣这些“精神领袖”们。

  

![](../Images/08efeab4dd57060bc505fbdaf522c71a.png)

  

在布道者中，也有来自中国的黑客，例如：来自360的单好奇和张婉桥将在现场分享如何破解 4G LTE；同样来自360的黑客刘健皓会在现场讲解攻击特斯拉汽车的自动驾驶系统。

  

**************************| ****************************战斗的黑客们**

  

不战斗，怎么能叫黑客呢？

  

历届 DEF CON 上，都会划出很大的一片区域作为黑客的“战场”。

  

![](../Images/3b400e176e7a2d0ee5c867e531cf595a.png)

【DEF CON 24 对抗区域】

  

这些黑客在紧张地制造一些常人所不能理解的东西，最终组委会将会评定出一些特别的奖项。

  

![](../Images/9ebf6ae4649afca0009c01aa256967cd.png)

![](../Images/b779d3a00ca06d77803ad5dd3d66f498.png)

  

当然，还有更为激烈的对抗，那就是每年 DEF CON 的重头戏 CTF（Capture The Flag）。

  

来自世界的顶级黑客战队会在这里进行攻防厮杀。简单来说，就是要不断破解一个虚拟网络架构中的诸多堡垒，用这些堡垒作为据点攻击对手。一旦比对手优先拿下堡垒，就意味着你可能掌握了绝对的主动权。所以对于攻击的制高点，所有队伍都是分秒必争的。

  

![](../Images/52f28573619c13a9a838260d6fe5dec3.png)

【b1o0p联合战队在 DEF CON CTF 现场】

  

值得一提的是，这个 DEF CON 上最受关注的游戏，也是中国的强项之一。2015年，来自中国的 HITCON、蓝莲花、0ops 三支战队分别拿下了比赛的4-6名。不过，这个成绩并不能让他们满意，今年蓝莲花和 0ops 两只战队合体为：b1o0p联合战队，并且加入了腾讯科恩实验室的诸多黑客大牛。比赛将会进行两天两夜，这种高强度的玩命对抗，正好刺激了黑客们爆棚的肾上腺素。

  

另外，这次 DEF CON CTF 首次引入了机器战队。这支战队会完全通过人工智能的方式，和所有黑客展开决战。

  

DEF CON 专题 | 溜门撬锁，暗黑市集，带你看世界最大的黑客狂欢所以这次 CTF 对于各位黑客来说，不仅是捍卫自己的荣誉，他们还要联合起来捍卫人类的荣光。

  

![](../Images/89230d00b8994b869c3f290ec73bc546.png)

【截至发稿，b1o0p 联合战队暂列第三】

  

马上要上战场了，必须先来个朋克头和黑客胡须，外表是黑客精神的重要体现。

  

![](../Images/330309fd6b1259bd7ddf4045ad5b4c39.png)

  

**************************| ****************************暗黑市集**

  

这么多黑客聚集起来，显然是个做生意的好机会。在这个集市上，能够满足你的所有暗黑梦想。

  

这里售卖各种攻击工具，比如之前看到的开锁套装。

  

![](../Images/028c9598d1c949eed6f6a507579e23f7.png)

![](../Images/d02e2809ac4e69b7cd1c7c89a6931871.png)

  

来自360的独角兽团队，也在这里练摊。他们卖的是自己开发的安全无线电工具。

  

![](../Images/eb7ca7d5a67de82623998bf3adf4d965.png)

![](../Images/f1c7568214acd60f7117d3b75b9545f0.png)

  

当然，如果你完全不懂黑客技术，至少可以买一件 T恤或者一枚徽章。。。

  

![](../Images/2c445b447e3cf666c40a8ccbc0910b85.png)

![](../Images/d955d63dfbe1cd6256678837515d6d88.png)

  

DEF CON 24，这个盛大的黑客 Party，至此已经完全拉开帷幕。这些自认为能改变世界的黑客们，没准一不小心，真的会改变世界。

  

我们拭目以待。
