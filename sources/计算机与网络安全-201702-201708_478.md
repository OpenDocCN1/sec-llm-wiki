# 公安部：打击侵犯公民个人信息违法犯罪 摧毁窝点6个 刑拘138人

在公安部的指挥下，2月2日，广东省公安机关组织警力，在广东、湖南、山东等20个省份同步开展打击侵犯公民个人信息违法犯罪“飓风一号”行动，取得显著战果。  

2016年年底，广州市公安局摧毁了一个买卖公民个人信息的团伙，经过扩线经营，又排查出6个涉嫌侵犯公民个人信息犯罪团伙。

**广州市公安局刑警支队副支队长刘坚：**（他们）互为上下家，通过网络上来买卖各种信息，目前是涉及了有十八类信息，有银行方面的，还有交通，还有机场，还有一些开房（信息）等等。

广州市公安局在侦办中发现，这些违法犯罪团伙大都以公司化运营的模式，声称可为他人讨债、为银行等金融机构清理呆账、坏账等。而在实际操作中，他们以不法手段获取公民个人信息，进行买卖，提供给各种违法犯罪人员。

由于案情重大且牵扯多地，公安部将此案列为部督案件。广州警方派出1千多名警力，赴各涉案地开展侦控和抓捕工作。27号早上7点抓捕行动开始，各路警力迅速出击。

**办案民警：**位于广州市东风东路的这个公司是一个资产管理公司，专门负责去追收一些不良资产，但是就是说聘请的业务员就不择手段，通过一些非法手段，去获取一些公民的信息，然后就通过他们这些手段，达到找到他们债务人（的目的）。

进入现场之后，里面的员工正在忙碌着为人追债。墙上的白板上写着每名员工追债的业绩，有的桌上还放着催债话术和一些公民信息。

警方对这个公司的部分涉案人员带回做进一步审查。截止目前，整个行动成功摧毁侵犯公民个人信息犯罪团伙6个,捣毁犯罪窝点14个, 共带回审查涉案人员500多名，其中已经刑事拘留138名，缴获银行卡2000多张和电脑、手机、存储卡等涉案物品一大批,以及公民个人信息近亿条。
