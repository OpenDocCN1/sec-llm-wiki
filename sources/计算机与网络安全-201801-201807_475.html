尽管新语言经常出现，但掌握核心，传统语言对于开发者来说是最重要的。总的来说，现在的开发语言趋势是：JavaScript，Java，Python，C ++和C。


当下最受欢迎的语言如下：


总体排名趋势图


不同编程语言在不用行业中的受欢迎程度是大不相同的，下面一起来看看不同领域中，最受欢迎的编程语言分别是哪些：


汽车 & 运输行业



在汽车 & 运输行业，JavaScript 排行第一、Java 第二、Python 第三、C++ 第四、C# 第五。


计算机硬件



在计算机硬件行业，C语言明显高于其他语言，C和C++两者差距微乎其微，C由于其性能，直接的低级硬件API以及跨多个平台的编译器的可用性而主导硬件。排行前三的分别为C、C++、Python。

金融服务行业



在金融服务行业，排行前三的分别为Java、JavaScript和Python，其中，Java在金融服务领域已经流行了很多年。


政府部门



政府部门依然更青睐Java和JavaScript，相较于其他语言，C＃在政府机构中更为普遍，排行第三，算是相当不错的成绩。


卫生保健行业



JavaScript排行第一、Java第二、Python第三、C#第四。


媒体/娱乐/游戏



JavaScript排行第一，Java第二，Python第三，PHP第四。


零售 & 电商



Java 排行第一、JavaScript 第二、Python 第三。


安全领域



Java 第一、Python 第二、JavaScript 第三、C++ 第四、C 第五。


技术



Java 第一、JavaScript 第二、Python 第三、C++ 第四、C 第五；


综上排行，我们可以发现不同行业不同编程语言的受欢迎程度各有不同，但无论哪个行业，Java，JavaScript，C和C ++以及Python都是开发人员的首选编程语言。


最值得注意的是，无论在哪个行业，Python基本排行前三名内，Python以其简单性，可读性和科学图书馆的巨大可能性而闻名，同时还是计算机科学入门课程的一部分。相信Python的将来会更加强劲发展。
