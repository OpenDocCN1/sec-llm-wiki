# 净网2019：破获网络传播淫秽视频案，涉及儿童色情

付费会员分级销售，传播淫秽视频300余万部，记者从江苏省南通市公安局获悉，经过10个多月的缜密侦查，在“净网2019”专项行动中，南通警方成功侦破一起[公安部](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129746&idx=3&sn=d5040d38e863cab36a670a36b632f1b4&chksm=bc858d7d8bf2046b0048fdda6c78fb73329334added1f9f4f673a5671a567a35d92005831098&scene=21#wechat_redirect)挂牌督办的“1.20”特大网络传播淫秽物品牟利案，在广东、福建、甘肃、天津等省市抓获犯罪嫌疑人6名，查获淫秽视频300余万部，追缴违法所得200余万元。

  

据介绍，这是迄今为止南通警方破获的最大规模的网络传播淫秽物品犯罪团伙案件。目前，该案已被移送起诉。

![](../Images/73aa84c39088a11abc758bd4b377418c.png)

**团伙网络兜售大量淫秽视频获利**

  

2018年上半年，南通市公安局网安支队在工作中发现，如东一网民刘某在[互联网](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130656&idx=3&sn=5e24d5c1f45b3a4850ac2ff4623bbadf&chksm=bc8589cf8bf200d9034d12651182a30456e90e39577dbcfa6285e8755cccadc72fb2518960b7&scene=21#wechat_redirect)上购买淫秽视频。经初查，卖家通过[QQ](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127653&idx=3&sn=e54fd5479003f9480f8a00bce7023731&chksm=bc85958a8bf21c9c42abd595f1b2f8d28b4f05eb71155c9ae1c126f19ea67b4196f1b4fbca5e&scene=21#wechat_redirect)大肆兜售储存在某公司网盘的淫秽视频，数量特别巨大。

  

南通市公安局网安支队随后联合如东县公安局成立“1.20”专案组，展开侦查。

![](../Images/01f39d4feb3da87139cdb60ef9f70220.png)

民警在对涉黄网盘进行取证的同时，又围绕卖家的身份进行综合研判分析。很快，专案组锁定这名犯罪嫌疑人的真实身份——广东廉江人叶某。

  

据叶某交代，自己从2015年开始就在网上购买、收集淫秽视频，存放在网盘里，再通过贴吧发布广告，利用[QQ](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127653&idx=3&sn=e54fd5479003f9480f8a00bce7023731&chksm=bc85958a8bf21c9c42abd595f1b2f8d28b4f05eb71155c9ae1c126f19ea67b4196f1b4fbca5e&scene=21#wechat_redirect)与买家联系，以29至299元不等的价格卖给刘某等人。这些年，他先后向5000余人出售并获利15万余元。淫秽视频的主要来源，是一个网名叫“龙哥”的人。

  

而“龙哥”背后，则有一个专门的传播淫秽物品的犯罪团伙。在一些[QQ群](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120189&idx=1&sn=24017e52d411c39c7c5fcb8321290f23&chksm=bc8676d28bf1ffc46aebf2c6a4014ffdaeb46100e2a5f0e25573ba861cfb270140c589154881&scene=21#wechat_redirect)和论坛里，时常能看到他们的身影。由于案情重大，[公安部](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129746&idx=3&sn=d5040d38e863cab36a670a36b632f1b4&chksm=bc858d7d8bf2046b0048fdda6c78fb73329334added1f9f4f673a5671a567a35d92005831098&scene=21#wechat_redirect)、江苏省公安厅先后将该案列为挂牌督办案件。

  

在逐步挖掘摸清了这一犯罪团伙的组织架构后，专案组派员分赴福建、甘肃、天津、陕西等地，将6名主要犯罪嫌疑人全部抓获归案。

![](../Images/6a2168f76f02b162ce3edeff3abd6641.png)

**付费会员分级销售，还有中间商**

  

到案后，众人对出售淫秽视频牟利的犯罪实施供认不讳。

  

经查，41岁的苏某全即叶某所说的“龙哥”。据苏某全交代，自己在2016年9月加入该犯罪团伙，并担任组织管理员，平时负责发展会员并向会员传播淫秽视频，所得会员费与另一名负责的苏某五五分成。

苏某，38岁，陕西铜川人，与何某先后组建了多个[QQ群](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120189&idx=1&sn=24017e52d411c39c7c5fcb8321290f23&chksm=bc8676d28bf1ffc46aebf2c6a4014ffdaeb46100e2a5f0e25573ba861cfb270140c589154881&scene=21#wechat_redirect)，用于出售淫秽视频。为实现大容量淫秽视频的快速传播，苏某与何某等人在[互联网](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130656&idx=3&sn=5e24d5c1f45b3a4850ac2ff4623bbadf&chksm=bc8589cf8bf200d9034d12651182a30456e90e39577dbcfa6285e8755cccadc72fb2518960b7&scene=21#wechat_redirect)上通过不特定[QQ群](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120189&idx=1&sn=24017e52d411c39c7c5fcb8321290f23&chksm=bc8676d28bf1ffc46aebf2c6a4014ffdaeb46100e2a5f0e25573ba861cfb270140c589154881&scene=21#wechat_redirect)和论坛打广告，吸引网友进入[QQ群](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120189&idx=1&sn=24017e52d411c39c7c5fcb8321290f23&chksm=bc8676d28bf1ffc46aebf2c6a4014ffdaeb46100e2a5f0e25573ba861cfb270140c589154881&scene=21#wechat_redirect)交流。[QQ群](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120189&idx=1&sn=24017e52d411c39c7c5fcb8321290f23&chksm=bc8676d28bf1ffc46aebf2c6a4014ffdaeb46100e2a5f0e25573ba861cfb270140c589154881&scene=21#wechat_redirect)又分为“外群”“内群”“私密群”。

  

据如东县公安局介绍，外群为普通聊天群，用于发展会员，内群成员则是已经购买或者有意向购买的人，私密群是从内群中作进一步筛选，不仅是会员，还有中间商。

  

警方查明，该犯罪团伙采用付费会员分级销售的模式作案，成员职责分工明确，网盘会员管理、云卡销售和淫秽视频资源传输均由专人负责，客户来源、视频资源来源互不交叉，由不同的人、不同的账号进行操作和交易，以逃避公安机关打击。

  

据南通市公安局介绍，这是迄今为止南通警方破获的最大规模的网络传播淫秽物品犯罪团伙案件。

  

尽管民警只发现了为数不多的几个网盘账号，但其中储存的淫秽视频数量多达300余万部。

  

苏某全落网时，民警在其网盘内发现了容量达1.3PB（注：1PB = 1024TB）的文件，内有90余万部淫秽视频和97万张淫秽图片。苏某网盘里的涉黄文件更多得多，共有近200万部淫秽视频和88.2万张淫秽图片。而其他犯罪嫌疑人传播的淫秽视频，数量最少的也有数万部。其中，还有部分涉及儿童色情的淫秽视频。

  

截至案发，该犯罪团伙共发展会员近700人，其中很多跟叶某类似，充当中间商的角色，在[互联网](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130656&idx=3&sn=5e24d5c1f45b3a4850ac2ff4623bbadf&chksm=bc8589cf8bf200d9034d12651182a30456e90e39577dbcfa6285e8755cccadc72fb2518960b7&scene=21#wechat_redirect)上以较为低廉的价格对外兜售淫秽视频。

  

目前，该案已被移送起诉至当地人民法院。
