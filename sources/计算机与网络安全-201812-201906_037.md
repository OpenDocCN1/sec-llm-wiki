# C 语言是一门面向过程的计算机[编程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128726&idx=3&sn=6bbfafcc4786966456c6ec9fd0ef37a8&chksm=bc8591798bf2186f7df0c0558b10945b9c71cf8dae01be5a80844bd7e6480ff5febe4a7ecfe6&scene=21#wechat_redirect)语言，与 [C++](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130846&idx=3&sn=d070ffff8ab17fb847d61a0b1b285382&chksm=bc8589318bf20027111627e81cd5989b26f1b1bf05131d56503506137274d3929adf0121ebba&scene=21#wechat_redirect)、[Java](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126454&idx=2&sn=557011719b133ca475091aff43ab8fa2&chksm=bc859e598bf2174fb4ff6f53b571368cd87ef3a120bfdc0384289c7f0ace0bb648a3498451e0&scene=21#wechat_redirect) 等面向对象[编程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128726&idx=3&sn=6bbfafcc4786966456c6ec9fd0ef37a8&chksm=bc8591798bf2186f7df0c0558b10945b9c71cf8dae01be5a80844bd7e6480ff5febe4a7ecfe6&scene=21#wechat_redirect)语言有所不同。C 语言的设计目标是提供一种能以简易的方式编译、处理低级存储器、仅产生少量的机器码以及不需要任何运行环境支持便能运行的[编程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128726&idx=3&sn=6bbfafcc4786966456c6ec9fd0ef37a8&chksm=bc8591798bf2186f7df0c0558b10945b9c71cf8dae01be5a80844bd7e6480ff5febe4a7ecfe6&scene=21#wechat_redirect)语言。C 语言描述问题比[汇编语言](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130595&idx=3&sn=286d73c539d290710890ea96a73a0bdb&chksm=bc858e0c8bf2071a56c52df98623092c5b5defa5cda26c862d737070f8e38b0a7dd3cfa0c42e&scene=21#wechat_redirect)迅速，工作量小、可读性好，易于调试、修改和移植，而代码质量与[汇编语言](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130595&idx=3&sn=286d73c539d290710890ea96a73a0bdb&chksm=bc858e0c8bf2071a56c52df98623092c5b5defa5cda26c862d737070f8e38b0a7dd3cfa0c42e&scene=21#wechat_redirect)相当。C 语言一般只比[汇编语言](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130595&idx=3&sn=286d73c539d290710890ea96a73a0bdb&chksm=bc858e0c8bf2071a56c52df98623092c5b5defa5cda26c862d737070f8e38b0a7dd3cfa0c42e&scene=21#wechat_redirect)代码生成的目标程序效率低10%～20%。因此，C 语言可以编写系统软件。
