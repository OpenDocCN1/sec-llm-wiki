WPA全称为Wi-Fi Protected Access，有WPA和WPA2两个标准。它是一种保护[无线网络](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127878&idx=3&sn=b8b6c3abeac9c1094bbd26ffad57d6c9&chksm=bc8594a98bf21dbfb02de90b480c45015566dfe4da4becd2c2cf15ff7634baa404e612c3a546&scene=21#wechat_redirect)（Wi-Fi）安全的系统。该加密方式是由研究者在前一代的系统有线等效加密（WEP）中，找到的几个严重弱点而产生的。本文介绍WPA加密和破解。

  

**一、WPA加密简介**

  

WPA实现了大部分的IEEE802.11i标准，是在802.11i完备之前替代WEP的过渡方案。WPA的设计可以用在所有的无线网卡上，但未必能用在第一代的无线接入点上。WPA2实现了完整的标准，但不能在某些古老的网卡上运行。这两者都提供优良的安全能力。下面对WPA加密做一个简单的介绍。

  

**1、什么是WPA加密**

  

Wi-Fi联盟给出的WPA定义为：WPA=802.1x+EAP+TKIP+MIC。其中，802.1x是指IEEE的802.1x身份认证标准；EAP（Extensible Authentication Protocol）是一种扩展身份认证协议。这两者就是新添加的用户级身份认证方案。TKIP（Temporal Key Integrity Protocol）是一种密钥管理协议；MIC（Message IntegrityCode，消息完整性编码）是用来对消息进行完整性检查的，用来防止攻击者拦截、篡改，甚至重发数据封包。

  

WPA2是WPA的第二个版本，是对WPA在安全方面的改进版本。与第一版的WPA相比，主要改进的是所采用的加密标准，从WPA的TKIP/MIC改为AES-CCMP。所以，可以认为WPA2的加密方式为：WPA2=IEEE 802.11i=IEEE 802.11x/EAP + AES-CCMP。其中，两个版本的区别如表1所示。

表1  WPA和WPA2比较

从表1中可以看到，WPA2采用了加密性能更好、安全性更高的加密技术AES-CCMP（Advanced Encryption Standard-Counter mode with Cipher-block chaining Message authentication code Protocol，高级加密标准-计算器模式[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)区块链接消息身份验证代码协议），取代了原WPA中的TKIP/MIC加密协议。因为WPA中的TKIP虽然针对WEP的弱点做了重大的改进，但仍保留了RC4[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)和基本架构。也就是说，TKIP亦存在着RC4本身所隐含的弱点。

  

CCMP采用的是AES（Advanced Encryption Standard，高级加密标准）加密模块，AES既可以实现数据的机密性，又可以实现数据的完整性。

  

**2、WPA加密工作原理**

  

WPA包括暂时密钥完整性协议（Temporal Key Integrity Protocol，TKIP）和802.1x机制。TKIP与802.1x一起为移动客户机提供了动态密钥加密和相互认证功能。WPA通过定期为每台客户机生成唯一的加密密钥来阻止[黑客](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127259&idx=3&sn=c82f59076adf4123590301c9577f3c59&chksm=bc859b348bf21222ef281bc9aebb654a06582273fd7d9eb73ab84b56adbf383f74305efe3c3c&scene=21#wechat_redirect)入侵。

  

TKIP为WEP引入了新的[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)，这些[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)包括扩展的48位初始化向量与相关的序列规则、数据包密钥构建、密钥生成与分发功能和信息完整性码（也被称为Michael码）。

  

在应用中，WPA可以与利用802.1x和EAP（一种验证机制）的认证[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)（如远程认证拨入用户服务）连接。这台认证[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)用于保存用户证书。这种功能可以实现有效的认证控制，以及与已有信息系统的集成。由于WPA具有运行“预共享的密钥模式”的能力，SOHO环境中的WPA部署并不需要认证[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)。与WEP类似，一部客户机的预先共享的密钥必须与接入点中保存的预先共享密钥相匹配。接入点使用通行字进行认证，如果通行字相符合，客户机被允许访问接入点。该连接过程又被称为[四次握手](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120639&idx=2&sn=024dc841d4d2577c47625fafca916239&chksm=bc8671108bf1f8067f34f3ea1acabfafd9e913cbd3acb36bfc9e1ea84fc990ec98119a7d1d6c&scene=21#wechat_redirect)，其通信过程如图1所示。

**3、WPA弥补了WEP的安全问题**

  

简单地说，WPA就是WEP加密方式的升级版。WPA作为一种大大提高[无线网络](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127878&idx=3&sn=b8b6c3abeac9c1094bbd26ffad57d6c9&chksm=bc8594a98bf21dbfb02de90b480c45015566dfe4da4becd2c2cf15ff7634baa404e612c3a546&scene=21#wechat_redirect)的数据保护和接入控制的增强安全性级别，的确能够解决WEP加密所不能解决的问题。下面以表格的形式列出WPA2针对WEP不足的改进，如表2所示。

**二、设置WPA加密模式**

  

**1、WPA认证类型**

  

WPA用户认证是使用802.1x和扩展认证协议（Extensible Authentication Protocol，EAP）来实现的。WPA考虑到不同的用户和不同的应用安全需要。例如，企业用户需要很高的安全保护（企业级），否则可能会泄露非常重要的商业机密；而家庭用户往往只是使用网络来浏览Internet、收发E-mail、打印和共享文件，这些用户对安全的要求相对较低。为了满足用户的不同安全要求，WPA中规定了两种应用模式。

  

● 企业模式：通过使用认证[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)和复杂的安全认证机制，来保护[无线网络](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127878&idx=3&sn=b8b6c3abeac9c1094bbd26ffad57d6c9&chksm=bc8594a98bf21dbfb02de90b480c45015566dfe4da4becd2c2cf15ff7634baa404e612c3a546&scene=21#wechat_redirect)通信安全。

  

● 家庭模式（包括小型办公室）：在AP（或者无线[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)）以及连接[无线网络](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127878&idx=3&sn=b8b6c3abeac9c1094bbd26ffad57d6c9&chksm=bc8594a98bf21dbfb02de90b480c45015566dfe4da4becd2c2cf15ff7634baa404e612c3a546&scene=21#wechat_redirect)的无线终端上输入共享密钥，以保护无线链路的通信安全。

  

根据这两种不同的应用模式，WPA的认证也分别有两种不同的方式。对应大型企业的应用，常采用802.1x+EAP的方式，用户提供认证所需的凭证。但对于一些中小型的企业网络或者家庭用户，WPA也提供一种简化的模式，它不需要专门的认证[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)。这种模式叫做“WPA预共享密钥（WPA-PSK）”，它仅要求在每个WLAN节点（AP、无线[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)和网卡等）预先输入一个密钥即可实现。

  

在无线[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)的WPA加密方式中，默认提供了3种认证类型，分别是自动、WPA-PSK和WPA2-PSK。实际上这3种认证类型基本没区别，由于WPA加密包括WPA和WPA2两个标准，所以认证类型也有两个标准WPA-PSK和WPA2-PSK。

  

**2、加密算法**

  

在无线[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)的WPA加密模式中，默认提供了自动、TKIP和AES3种[加密算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655122060&idx=2&sn=9783dd961efb288c95e65fa5a895a3aa&chksm=bc866f638bf1e6751c94279fc53bbc81e569177fd0442bd1f816a16c15b42f44708e627ed7de&scene=21#wechat_redirect)。如果用户不了解[加密算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655122060&idx=2&sn=9783dd961efb288c95e65fa5a895a3aa&chksm=bc866f638bf1e6751c94279fc53bbc81e569177fd0442bd1f816a16c15b42f44708e627ed7de&scene=21#wechat_redirect)时，通常会选择“自动”选项。所以，下面对TKIP和AES[加密算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655122060&idx=2&sn=9783dd961efb288c95e65fa5a895a3aa&chksm=bc866f638bf1e6751c94279fc53bbc81e569177fd0442bd1f816a16c15b42f44708e627ed7de&scene=21#wechat_redirect)进行详细介绍，以帮助用户选择更安全的[加密算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655122060&idx=2&sn=9783dd961efb288c95e65fa5a895a3aa&chksm=bc866f638bf1e6751c94279fc53bbc81e569177fd0442bd1f816a16c15b42f44708e627ed7de&scene=21#wechat_redirect)。

  

**（1）TKIP加密算法**

  

TKIP（Temporal Key Integrity Protocol，暂时密钥集成协议）负责处理[无线安全](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126780&idx=2&sn=bd7e095504ac73676f47655a533b05c6&chksm=bc8599138bf210055eb4ef0f013763d051cf5775b79a6fea5a1f81636dcd2a63e6e6205d9252&scene=21#wechat_redirect)问题的加密部分，TKIP是包裹在已有WEP[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)外围的一层“外壳”。这种加密方式在尽可能使用WEP[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)的同时，消除了已知的WEP缺点。例如，WEP[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)使用的密钥长度为40位和128位，40位的密钥是非常容易破解的，而且同一[局域网](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127596&idx=3&sn=2b17fff793ef78538de02f7efa722d07&chksm=bc8595c38bf21cd534d05234f6b7fcf6ca8686efce3e93ae458e888c959af3de713dced11ad6&scene=21#wechat_redirect)内所有用户都共享一个密钥，如果一个用户丢失密钥将使整个网络不安全。而TKIP中[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)使用的密钥长度为128位，这就解决了WEP[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)使用的密钥长度过短的问题。

  

TTKIP另一个重要的特性就是变化每个数据包所使用的密钥，这就是它名称中“动态”的出处。密钥通过将多种因素混合在一起生成，包括基本密钥（即TKIP中所谓的成对瞬时密钥）、发射站的Mac地址以及，数据包的序列号。混合操作在设计上将对无线站和接入点的要求减少到最低程度，但仍具有足够的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)强度，使它不能被轻易破译。WEP的另一个缺点就是“重放攻击（replay attacks）”，而利用TKIP传送的每一个数据包都具有独有的48位序列号，由于48位序列号需要数千年时间才会出现重复，因此没有人可以重放来自无线连接的老数据包。由于序列号不正确，这些数据包将作为失序包被检测出来。

  

**（2）AES加密算法**

  

AES（Advanced Encryption Standard，高级加密标准）是[美国](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128142&idx=3&sn=7b8de69bbda3be653df725fdec9fc24a&chksm=bc8597a18bf21eb7f39f365987d171669e5868d0a43659b4fa35b9053cfc346b30c80e7c5e8a&scene=21#wechat_redirect)国家标准与技术研究所用于加密电子数据的规范，该[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)汇聚了设计简单、密钥安装快、需要的内存空间少、在所有的平台上运行良好、支持并行处理并且可以抵抗所有已知攻击等优点。AES是一个迭代的、对称密钥分组的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，它可以使用128、192和256位密钥，并且用128位（16字节）分组加密和解密数据。与公共密钥[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)使用密钥对不同，对称密钥[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)使用相同的密钥加密和解密数据。通过分组[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)返回的加密数据的位数与输入数据相同。迭代加密使用一个循环结构，在该循环中重复置换（permutations ）和替换（substitutions）输入数据。

  

总而言之，AES提供了比TKIP更加高级的加密技术，现在无线[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)都提供了这两种[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)，不过更倾向于AES。TKIP安全性不如AES，而且在使用TKIP[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)时，[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)的吞吐量会下降，并大大影响了[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)的性能。

**3、创建彩虹表**

  

彩虹表是一个庞大的，针对各种可能的字母组合预先计算好的哈希值的集合，不仅支持MD5[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)，还支持各种[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)。使用彩虹表可以快速的破解各类[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128965&idx=3&sn=b8b9a62359603244f96d47b39c0a094e&chksm=bc85906a8bf2197c862d73e7aa0b33d06465d5570713fd18493312f7c38da5c6b4b21f9895cf&scene=21#wechat_redirect)中，默认提供了一个工具RainbowCrack可以用来生成彩虹表。下面介绍使用RainbowCrack工具来创建彩虹表。

  

RainbowCrack工具包括3个程序，分别是rtgen、rtsort和rcrack。这3个程序的作用分别如下所示。

  

● rtgen：彩虹表生成工具，生成口令、散列值对照表。

● rtsort：排序彩虹表，为rcrack提供输入。

● rcrack：使用排好序的彩虹表进行口令破解。

  

使用rtgen程序创建彩虹表，其语法格式如下所示。

  

rtgen hash\_algorithm charset plaintext\_len\_min plaintext\_len\_max table\_index chain\_len

chain\_num part\_index

rtgen hash\_algorithm charset plaintext\_len\_min plaintext\_len\_max table\_index -bench

当用户设置好一个AP为WPA加密模式时，就可以尝试进行破解了。尽管WPA加密方式不太容易被破解出来，但是若有一个很好的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)字典，还是可以破解出来的。使用WPA加密的WiFi网络，只能使用暴力破解（字典或PIN码）的方法来实现。下面介绍如何破解WPA加密的[无线网络](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127878&idx=3&sn=b8b6c3abeac9c1094bbd26ffad57d6c9&chksm=bc8594a98bf21dbfb02de90b480c45015566dfe4da4becd2c2cf15ff7634baa404e612c3a546&scene=21#wechat_redirect)。

**五、WPA的安全措施**

  

如果有一个很好的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)字典，破解WPA加密的WiFi网络是一件轻而易举的事情。但是，可以采取一些措施，尽可能的保证用户网络的安全。在[无线网络](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127878&idx=3&sn=b8b6c3abeac9c1094bbd26ffad57d6c9&chksm=bc8594a98bf21dbfb02de90b480c45015566dfe4da4becd2c2cf15ff7634baa404e612c3a546&scene=21#wechat_redirect)设备中有多项设置虽不能起到绝对阻止攻击的作用，但正确的设置可增加攻击者的攻击难度。下面介绍几个应对WPA的安全措施。

  

（1）更改无线[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)默认设置。

（2）禁止SSID广播。

（3）防止被扫描搜索。

（4）关闭WPA/QSS。

（5）启用Mac地址过滤。

（6）设置比较复杂的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。
