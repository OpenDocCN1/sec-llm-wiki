本文通过一个案例来介绍一个[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)被[rootkit](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130679&idx=3&sn=a22e5fd727a8e775029845ad9c1faf1d&chksm=bc8589d88bf200ce5a05db74595640e59318968fd176ea909d197e194d8b50f7e68eb5eb3aea&scene=21#wechat_redirect)[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)后的处理思路和处理过程。[rootkit](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130679&idx=3&sn=a22e5fd727a8e775029845ad9c1faf1d&chksm=bc8589d88bf200ce5a05db74595640e59318968fd176ea909d197e194d8b50f7e68eb5eb3aea&scene=21#wechat_redirect)[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)是[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133968&idx=2&sn=2454fe58d155dec7738888c75a963aeb&chksm=bc85bcff8bf235e97db0692fa805d2eeecdcaaa1e2a26f03ab5112230e873a342fcaca0bdf4f&scene=21#wechat_redirect)系统下最常见的[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)手段和[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)方式。

  

**1、受攻击现象**

  

这是一台客户的门户网站[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)，托管在电信机房。客户接到电信的通知：由于此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)持续对外发送数据包，导致100MB带宽耗尽，于是电信切断了此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)的网络。此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)安装了CentOS 5.5版本的系统，对外开放了80、22端口。

  

从客户那里了解到，网站的访问量并不大，所以带宽占用也不会太高，而耗尽100MB的带宽是绝对不可能的，那么极有可能是[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)遭受了流量[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)，于是登录[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)做详细的检测。

  

**2、初步分析**

  

在电信人员的配合下通过[交换机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128257&idx=3&sn=4b46cf6a7be7396a95c7d64493cc81c9&chksm=bc85972e8bf21e389f60513d23a5a5fa4af5807a1b4532d03eda374d4890a5f5f13479f5a34e&scene=21#wechat_redirect)对该[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)的网络流量进行了检测，发现该[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)确实存在对外80端口的扫描流量，于是登录系统通过netstat -an命令对系统开启的端口进行检查。奇怪的是，没有发现任何与80端口相关的网络连接。接着使用ps -ef、top等命令也没有发现任何可疑的[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)。于是怀疑系统可能被植入了[rootkit](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130679&idx=3&sn=a22e5fd727a8e775029845ad9c1faf1d&chksm=bc8589d88bf200ce5a05db74595640e59318968fd176ea909d197e194d8b50f7e68eb5eb3aea&scene=21#wechat_redirect)。

  

为了验证系统是否被植入了[rootkit](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130679&idx=3&sn=a22e5fd727a8e775029845ad9c1faf1d&chksm=bc8589d88bf200ce5a05db74595640e59318968fd176ea909d197e194d8b50f7e68eb5eb3aea&scene=21#wechat_redirect)，我们将网站[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)下的ps、top等命令与之前备份的同版本可信操作系统命令进行md5sum校验，结果发现网站[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)下的这两个命令确实被修改过，由此断定，此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)已经被[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)、且安装了[rootkit](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130679&idx=3&sn=a22e5fd727a8e775029845ad9c1faf1d&chksm=bc8589d88bf200ce5a05db74595640e59318968fd176ea909d197e194d8b50f7e68eb5eb3aea&scene=21#wechat_redirect)级别的[后门](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129244&idx=3&sn=6df349d4b772425777487a77091f0f4d&chksm=bc8593738bf21a652bfc7213ea58a506986d7b1e6812c5132b33c598b7a8a210c10f13d7f900&scene=21#wechat_redirect)程序。

  

**3、断网分析系统**

  

由于[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)不停向外发包，因此，首先要做的就是将此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)断开网络，然后分析系统日志，寻找[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源。但是系统命令已经被替换，如果继续在该系统上执行操作将变得不可信。这里可以通过两种方法来避免这种情况，第一种方法是将此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)的硬盘取下来挂载到另外一台安全的[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)上进行分析，另一种方法是从一个同版本可信操作系统下复制所有命令到这台[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)下某个路径，然后在执行命令的时候指定此命令的完整路径即可。这里采用第二种方法。

  

首先查看系统的登录日志，查看是否有可疑登录信息，执行如下命令：

  

more /var/log/secure | grep Accepted

  

通过查看命令输出，有一条日志引起了我们的怀疑：

  

Oct 3 03:10:25 webserver sshd\[20701\]: Accepted password for mail from 62.17.163.186 port 53349 ssh2

  

这条日志显示在10月3日凌晨3点10分，有个mail账号从62.17.163.186这个IP成功登录了系统，mail是系统的内置账号，默认无法执行登录操作的，而经过查证62.17.163.186这个IP，是来自爱尔兰的一个地址。从mail账号登录的时间来看，早于此网站[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)遭受[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)的时间。

  

接着查看系统[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)文件/etc/shadow，又发现可疑信息：

  

mail:$1$kCEd3yD6$W1evaY5BMPQIqfTwTVJiX1:15400:0:99999:7:::

  

很明显，mail账号已经被设置了[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)，并且被修改为可[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)登录，之所以使用mail账号，猜想可能是因为[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)者想留下一个隐蔽的账号，以方便日后再次登录系统。

  

然后继续查看其他系统日志，如/var/log/messages、/var/log/wtmp等均为空文件，可见，[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)者已经清理了系统日志文件，至于为何没有清空/var/log/secure文件，就不得而知了。

**4、寻找攻击源**

  

到目前为止，我们所知道的情况是，有个mail账号曾经登录过系统，但是为何会导致此网站[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)持续对外发送数据包呢？必须找到对应的[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源，通过替换到此[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上的ps命令查看系统目前运行的[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)，又发现了新的可疑：

  

nobody 22765 1 6 Sep29 ? 4-00:11:58 .t

  

这个.t程序是什么呢？继续执行top命令，结果如下：

  

PID USER PR NI VIRT RES SHR S %CPU %MEM TIME+ COMMAND 22765 nobody 15 0 1740m  1362m 1228 S 98.3 91.5 2892:19 .t

这个脚本[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)挺可怕的，不过在Awstats官网上也早已给出了修补的方法。对于这个[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)，修复方法很简单，打开awstats.pl文件，找到如下信息：

  

if ($QueryString =~ /configdir=(\[^&\]+)/i) 

{ 

$DirConfig=&DecodeEncodedString("$1"); 

}

  

修改为如下即可：

  

if ($QueryString =~ /configdir=(\[^&\]+)/i) 

{ 

$DirConfig=&DecodeEncodedString("$1"); $DirConfig=~tr/a-z0-9\_-/./a-z0-9\_-/./cd; 

}
