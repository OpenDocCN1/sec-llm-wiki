**1、处理服务器遭受攻击的一般思路**

  

系统遭受[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)并不可怕，可怕的是面对[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)束手无策，下面介绍在[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)遭受攻击后的一般处理思路。

  

**（1）切断网络**

  

所有的[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)都来自于网络，因此，在得知系统正遭受[黑客](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127259&idx=3&sn=c82f59076adf4123590301c9577f3c59&chksm=bc859b348bf21222ef281bc9aebb654a06582273fd7d9eb73ab84b56adbf383f74305efe3c3c&scene=21#wechat_redirect)的[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)后，首先要做的就是断开[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)的网络连接，这样除了能切断[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源之外，也能保护[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)所在网络的其他[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)。

  

**（2）查找攻击源**

  

可以通过分析系统日志或登录日志文件，查看可疑信息，同时也要查看系统都打开了哪些端口，运行哪些[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)，并通过这些[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)分析哪些是可疑的程序。这个过程要根据经验和综合判断能力进行追查和分析。

  

**（3）分析入侵原因和途径**

  

既然系统遭到[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)，那么原因是多方面的，可能是系统[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)，也可能是程序[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)，一定要查清楚是哪个原因导致的，并且还要查清楚遭到[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)的途径，找到[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源，因为只有知道了遭受[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)的原因和途径，才能在删除[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源的同时进行[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)的修复。

  

**（4）备份用户数据**

  

在[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)遭受[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)后，需要立刻备份[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上的用户数据，同时也要查看这些数据中是否隐藏着[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源。如果[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源在用户数据中，一定要彻底删除，然后将用户数据备份到一个安全的地方。

  

**（5）重新安装系统**

  

永远不要认为自己能彻底清除[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源，因为没有人能比[黑客](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127290&idx=3&sn=04aaac7d1e20fd446929032cb45b6b38&chksm=bc859b158bf212032e5e2121f6066cd1ec171afc141be62e32ad671879a403ade7b3435495bb&scene=21#wechat_redirect)更了解[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)程序，在[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)遭到[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)后，最安全也最简单的方法就是重新安装系统，因为大部分[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)程序都会依附在系统文件或者内核中，所以重新安装系统才能彻底清除攻击源。

  

**（6）修复程序或系统漏洞**

  

在发现系统[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)或者应用程序[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)后，首先要做的就是修复系统[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)或者更改程序bug，只有将程序的[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)修复完毕才能正式在[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上运行。

  

**（7）恢复数据和连接网络**

  

将备份的数据重新复制到新安装的[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上，然后开启服务，最后将[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)的网络连接开启，对外提供服务。

  

**2、检查并锁定可疑用户**

  

在发现[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)遭受[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)后，首先要切断网络连接，但是在有些情况下，比如无法马上切断网络连接时，就必须登录系统查看是否有可疑用户，如果有可疑用户登录了系统，那么需要马上将这个用户锁定，然后中断此用户的[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)连接。

  

**（1）登录系统查看可疑用户**

  

通过root用户登录，然后执行“w”命令即可列出所有登录过系统的用户，如图1所示。

![](../Images/be518e478f9604f64c00c8883799048a.png)

图1  查看所有登录过系统的用户

  

通过这个输出可以检查是否有可疑或者不熟悉的用户登录，同时还可以根据用户名以及用户登录的源地址和它们正在运行的[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)来判断他们是否为非法用户。

  

**（2）锁定可疑用户**

  

一旦发现可疑用户，就要马上将其锁定，例如上面执行“w”命令后发现nobody用户应该是个可疑用户（因为nobody默认情况下是没有登录权限的），于是首先锁定此用户，执行如下操作：

  

\[root@server ~\]# passwd -l nobody  

  

锁定之后，有可能此用户还处于登录状态，因此还要将此用户踢下线，根据上面“w”命令的输出，即可获得此用户登录进行的pid值，操作如下：

  

\[root@server ~\]# ps -ef|grep @pts/3 

531 6051 6049 0 19:23 ? 00:00:00 sshd: nobody@pts/3

\[root@server ~\]# kill -9 6051

  

这样就将可疑用户nobody从线上踢下去了。如果此用户再次试图登录，此时他已经无法登录了。

  

**（3）通过last命令查看用户登录事件**

  

last命令记录着所有用户登录系统的日志，可以用来查找非授权用户的登录事件，而last命令的输出结果来源于/var/log/wtmp文件，稍有经验的[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)者都会删掉/var/log/wtmp以清除自己行踪，但还是会在此文件中露出蛛丝马迹的。

**3、查看系统日志**

  

查看系统日志是查找[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)源最好的方法，可查看的系统日志有/var/log/messages、/var/log/secure等，这两个日志文件可以记录软件的运行状态以及[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)用户的登录状态，还可以查看每个用户目录下的.bash\_history文件，特别是/root目录下的.bash\_history文件，这个文件中记录着用户执行的所有历史命令。

  

**4、检查并关闭系统可疑进程**

  

检查可疑[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)的命令很多，例如ps、top等，但是有时候只知道[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)的名称无法得知路径，此时可以通过如下方式查看。

  

首先通过pidof命令查找正在运行的[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)PID，例如，要查找sshd[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)的PID，执行如下命令：

  

\[root@server ~\]# pidof sshd 

13276 12942 4284

  

然后进入内存目录，查看对应PID目录下exe文件的信息：

  

\[root@server ~\]# ls -al /proc/13276/exe 

lrwxrwxrwx 1 root root 0 Oct 4 22:09 /proc/13276/exe -> /usr/sbin/sshd

  

这样就找到了[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)对应的完整执行路径。如果还有查看文件的句柄，可以查看如下目录：

  

\[root@server ~\]# ls -al /proc/13276/fd

  

通过这种方式基本可以找到任何[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)的完整执行信息，此外还有很多类似的命令可以帮助系统[运维](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127540&idx=3&sn=df473c90a503cb82fb276992233fb6e7&chksm=bc859a1b8bf2130d7020136d329d45df76667fbcc6b09b86db24ccd863ca6f14021a673b986f&scene=21#wechat_redirect)人员查找可疑[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)。例如，可以通过指定端口或者tcp、udp协议找到[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)PID，进而找到相关[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)：

  

\[root@server ~\]# fuser -n tcp 111

111/tcp: 1579

\[root@server ~\]# fuser -n tcp 25

25/tcp: 2037

\[root@server ~\]# ps -ef|grep 2037

root 2037 1 0 Sep23 ? 00:00:05 /usr/libexec/postfix/master

postfix 2046 2037 0 Sep23 ? 00:00:01 qmgr -l -t fifo -u

postfix 9612 2037 0 20:34 ? 00:00:00 pickup -l -t fifo -u

root 14927 12944 0 21:11 pts/1 00:00:00 grep 2037

  

有些时候，[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)者的程序隐藏很深，例如[rootkit](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130679&idx=3&sn=a22e5fd727a8e775029845ad9c1faf1d&chksm=bc8589d88bf200ce5a05db74595640e59318968fd176ea909d197e194d8b50f7e68eb5eb3aea&scene=21#wechat_redirect)[后门](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129244&idx=3&sn=6df349d4b772425777487a77091f0f4d&chksm=bc8593738bf21a652bfc7213ea58a506986d7b1e6812c5132b33c598b7a8a210c10f13d7f900&scene=21#wechat_redirect)程序，在这种情况下ps、top、netstat等命令也可能已经被替换，如果再通过系统自身的命令去检查可疑[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)就变得毫不可信，此时，就需要借助于第三方工具来检查系统可疑程序，例如chkrootkit、RKHunter等工具，通过这些工具可以很方便地发现系统被替换或篡改的程序。

  

**5、检查文件系统的完好性**

  

检查文件属性是否发生变化是验证文件系统完好性最简单、最直接的方法，例如，可以检查被[入侵](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132145&idx=3&sn=3a23fde20b5bda403b8bc61fa571ba7a&chksm=bc85841e8bf20d087eb627b3b43f5ac1e5737906c80b136c144a115e94a1977abcb8687810d3&scene=21#wechat_redirect)[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上/bin/ls文件的大小是否与正常系统上此文件的大小相同，以验证文件是否被替换，但是这种方法比较低级。此时可以借助于[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133968&idx=2&sn=2454fe58d155dec7738888c75a963aeb&chksm=bc85bcff8bf235e97db0692fa805d2eeecdcaaa1e2a26f03ab5112230e873a342fcaca0bdf4f&scene=21#wechat_redirect)下的RPM工具来完成验证，操作如下：

  

\[root@server ~\]# rpm -Va

....L... c /etc/pam.d/system-auth  
S.5..... c /etc/security/limits.conf  
S.5....T c /etc/sysctl.conf  
S.5....T /etc/sgml/docbook-simple.cat  
S.5....T c /etc/login.defs  
S.5..... c /etc/openldap/ldap.conf  
S.5....T c /etc/sudoers  
..5....T c /usr/lib64/security/classpath.security  
....L... c /etc/pam.d/system-auth  
S.5..... c /etc/security/limits.conf  
S.5..... c /etc/ldap.conf  
S.5....T c /etc/ssh/sshd\_config

  

对于输出中每个标记的含义介绍如下。

  

S表示文件长度发生了变化。

M表示文件的访问权限或文件类型发生了变化。

5表示MD5校验和发生了变化。

D表示设备节点的属性发生了变化。

L表示文件的符号链接发生了变化。

U表示文件/子目录/设备节点的owner发生了变化。

G表示文件/子目录/设备节点的group发生了变化。

T表示文件最后一次的修改时间发生了变化。

  

如果在输出结果中有“M”标记出现，那么对应的文件可能已经遭到篡改或替换，此时可以通过卸载这个RPM包重新安装来清除受[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)的文件。

  

不过这个命令有个局限性，那就是只能检查通过RPM包方式安装的所有文件，对于通过非RPM包方式安装的文件就无能为力了。同时，如果RPM工具也遭到替换，就不能使用这种方法了，此时可以从正常的系统上复制一个RPM工具进行检测。当然，对文件系统的检查也可以通过chkrootkit、RKHunter这两个工具来完成，上面介绍的命令或工具可以作为辅助或者补充。
