一、常用命令


001  ls-lh/var/log  列出/var/log/目录下的内容以及完整且用户友好的细节信息。


002  cd  本身将返回到您的home目录。


003  cp file1 newdir  将名为file1的文件复制到newdir目录。


004  mv file？/some/other/directory/  将包含字符串file及一个字符的所有文件移动到目标目录。


005  rm-r*  删除当前位置下的所有文件和目录。使用时要格外小心。


006  man sudo  打开关于使用sudo命令的man文档。


二、Linux虚拟化


007  apt install virtualbox  使用APT从远程软件仓库安装一个软件包。


008  dpkg-i skypeforlinux-64.deb  在Ubuntu机器上直接安装一个下载的Debian软件包。


009  wget https://example.com/document-to-download  使用wget命令程序下载文件。


010  dnf update、yum update或apt update  用在线软件仓库中的索引信息同步本地软件索引。


011  shasum ubuntu-16.04.2-server-amd64.iso  计算已下载文件的校验和，以确认其值与所提供的值相符。这意味着文件的内容在传输中没有损坏。


012  vboxmanage clonevm Kali-Linux-template--name newkali  使用vboxmanage工具克隆一个已存在的虚拟机。


013  lxc-start-d-n myContainer  启动一个已存在的LXC容器。


014  ip addr  显示系统各个网络接口上的信息（包括它们的IP地址）。


015  exit  离开shell会话而不关闭虚拟机。


三、远程连接


016  dpkg-s openssh-client  检查基于APT的软件包的状态。


017  systemctl status ssh  检查系统进程（systemd）的状态。


018  systemctl start ssh  启动一个服务。


019  ip addr  列出计算机上的所有网络接口。


020  ssh-keygen  生成一个新的SSH密钥对。


021  $cat.ssh/id_rsa.pub|ssh ubuntu@10.0.3.142"cat>>.ssh/authorized_keys"  将一个本地密钥复制并粘贴到远程的计算机。


022  ssh-copy-id-i.ssh/id_rsa.pub ubuntu@10.0.3.142  安全地复制加密密钥（建议的，也是标准的）。


023  ssh-i.ssh/mykey.pem ubuntu@10.0.3.142  指定一个特定的密钥对。


024  scp myfile ubuntu@10.0.3.142：/home/ubuntu/myfile  安全地将一个本地文件复制到一台远程计算机。


025  ssh-X ubuntu@10.0.3.142  允许以使能图形化的会话登录一台远程宿主计算机。


026  ps-ef|grep init  显示当前运行的所有系统进程，并用字符串init过滤结果。


027  pstree–p  以树形格式来显示当前运行的所有进程。


四、归档管理


028  df–h  显示当前的所有活动分区及用户可读格式的大小。


029  tar czvf archivename.tar.gz/home/myuser/Videos/*.mp4  在指定的目录树中创建一个视频文件的压缩归档文件。


030  split-b 1G archivename.tar.gz archivename.tar.gz.part  将一个大文件分割成一组最大大小固定的小文件。


031  find/var/www/-iname"*.mp4"-exec tar-rvf videos.tar{}\；  找出满足设定标准的文件并将这些文件的名称传递给tar命令，后者将这些文件纳入一个归档文件。


032  chmod o-r/bin/zcat  取消其他用户的读权限。


033  dd if=/dev/sda2 of=/home/username/partition2.img   创建sda2分区的映像，并将其保存到你的home目录下。


034  dd if=/dev/urandom of=/dev/sda1  用随机数覆盖一个分区，以模糊旧数据。

五、自动化管理


035  #！/bin/bash（即“shebang line”）  告知Linux将针对脚本使用哪个shell编译器。


036  ||  插入“或”条件到脚本中。可以认为这是“左边的命令成功执行”或“执行右边的命令”。


037  &&-  插入“且”条件到脚本中。可以认为这是“左边的命令成功执行”那么“执行右边的令”。


038  test-f/etc/filename  用来检测特定文件名或目录名是否存在。


039  chomd+x upgrade.sh  使脚本文件可以执行。


040  pip3 install--upgrade--user awscli  使用Python的pip包管理器安装AWS命令行界面。


041  aws s3 sync/home/username/dir2backup s3：//linux-bucket3040  使用特定的S3 bucket同步本地目录的内容。


042  21 5**1 root apt update&&apt upgrade（cron指令）  于每天早晨5：21执行两个apt命令。


043  NOW=$（date+“%m_%d_%Y”）  将当前日期赋值给脚本变量。


044  systemctl start site-backup.timer  启动systemd系统计时器。


六、应急工具


045  sha256sum systemrescuecd-x86-5.0.2.iso  计算.ISO文件的SHA256校验和。


046  isohybrid systemrescuecd-x86-5.0.2.iso  将USB友好的MBR添加到一个实时引导映像。


047  dd bs=4M if=systemrescuecd-x86-5.0.2.iso of=/dev/sdb&&sync  将一个实时引导映像写入空驱动器。


048  mount/dev/sdc1/run/temp-directory  将分区挂载到live文件系统上的目录。


049  ddrescue-d/dev/sdc1/run/usb-mount/sdc1-backup.img/run/usb-mount/sdc1-backup.logfile  将损坏分区上的文件保存到一个名为sdc1-backup.img的映像，并将事件写入日志文件。


050  chroot/run/mountdir/  在文件系统上打开root shell。


七、Web服务器


051  apt install lamp-server^  （单个Ubuntu命令）安装LAMP服务器的所有内容。


052  systemctl enable httpd  在每个系统引导时在CentOS机器上启动Apache。


053  firewall-cmd-add-service=http--permanent  允许HTTP浏览器信息/流量进入CentOS系统。


054  mysql_secure_installation  重置您的root密码并加固数据库安全。


055  mysql-u root-p  作为root用户登录到MySQL（或MariaDB）。


056  CREATE DATABASE newdbname  在MySQL（或MariaDB）中创建一个新的数据库。


057  yum search php-|grep mysql  在CentOS机器上搜索与PHP相关的可用包。


058  apt search mbstring  搜索与多字节字符串编码相关的可用包。


八、网络文件共享


059  a2enmod rewrite  启用重写模块，以使Apache可以在服务器和客户端间移动时编辑URL。


060  nano/etc/apache2/sites-available/nextcloud.conf  为Nextcloud创建或编辑Apache主机配置文件。


061  chown-R www-data：www-data/var/www/nextcloud/  将所有网站文件的用户和组的所有权改变为www-data用户。


062  sudo-u www-data php occ list  使用Nextcloud CLI列出可用的命令。


063  aws s3 ls s3：//nextcloud32327  列出一个S3 bucket中的内容。

九、保护Web服务器


064  firewall-cmd--permanent--add-port=80/tcp  打开80端口以接收HTTP访问流量，并配置其在引导时重新加载。


065  firewall-cmd--list-services  列出当前firewalld系统上的活跃规则。


066  ufw allow ssh  使用UncomplicatedFirewall（ufw）在Ubuntu系统上为SSH访问流量打开22端口。


067  ufw delete 2  删除ufw status命令列出的第二条ufw规则。


068  ssh-p53987 username@remote_IP_or_domain  使用非默认端口登录到一个SSH会话。


069  certbot--apache  配置一个Apache Web服务器来使用Let’s Encrypt加密证书。


070  selinux-activate  在Ubuntu机器上激活SELinux。


071  setenforce 1  在SELinux配置中切换为强制模式。


072  ls-Z/var/www/html/  显示特定目录中文件的安全情形。


073  usermod-aG app-data-group otheruser  将用户otheruser添加到系统组app-data-group。


074  netstat-npl  扫描服务器上打开的（监听的）网络端口。


十、保护网络连接


075  hostname OpenVPN-Server  设置命令提示符描述，以便保持对所登录服务器的跟踪。


076  cp-r/usr/share/easy-rsa//etc/openvpn  将Easy RSA脚本及环境配置文件复制到OpenVPN工作目录。


077  ./build-key-server server  用server名称生成一套RSA密钥对。


078  ./pkitool client  从已存在的RSA密钥基础设施中生成一套客户端密钥。


079  openvpn--tls-client--config/etc/openvpn/client.conf  使用client.conf文件中的设置在Linux上启动OpenVPN。


080  iptables-A FORWARD-i eth1-o eth2-m state--state NEW，ESTABLISHED，RELATED-j ACCEPT  允许在eth1与eth2两个网络接口之间进行数据传输。


081  man shorewall-rules  显示shorewall所使用的rules文件的文档。


082  systemctl start shorewall  启动shorewall防火墙工具。


083  vboxmanage natnetwork add--netname dmz--network"10.0.1.0/24"--enable--dhcp on  使用VirtualBox CLI（命令行接口）为一组VirtualBox虚拟机创建和配置一个DHCP模式的虚拟NAT网络。


084  vboxmanage natnetwork start--netname dmz  启动一个虚拟NAT网络。


085  dhclient enp0s3  从DHCP服务器为enp0s3接口请求一个IP地址。


十一、系统监控


086  Alt-F<n>  从非GUI shell中打开一个虚拟控制台。


087  Journalctl-n 20  显示日志文件中最近的20个日志条目。


088  journalctl--since 15：50：00--until 15：52：00  只显示since和until时间段内的事件。


089  systemd-tmpfiles--create--prefix/var/log/journal  指示systemd创建并维护一个持久性日志，而非每次启动时都被销毁的文件。


090  cat/var/log/auth.log|grep-B 1-A 1 failure  显示匹配行以及前置行和后续行。


091  cat/var/log/mysql/error.log|awk'$3~/[Warning]/'|wc  在MySQL错误日志中搜索被分类为警告的事件。


092  sed"s/^[0-9]//g"numbers.txt  删除文件中每行开头的数字。


093  tripwire–init  初始化一个Tripwire安装程序的数据库。


094  twadmin--create-cfgfile--site-keyfile site.key twcfg.txt  为Tripwire生成一个新的tw.cfg加密文件。

101  ln-s/nfs/home//home/username/Desktop/  创建一个符号链接，允许用户通过单击桌面图标轻松访问NFS共享。
