虚拟化是几乎所有服务和产品交付方式改进背后最重要的技术。这不仅使从云计算到自主驾驶汽车的所有产业成为可能，也更引人注目。


● Linux在虚拟空间占据绝对的主导地位。

● 虚拟化使得对任何技术的学习都变得更加简单。


本文介绍当前使用的主流企业虚拟化技术。使用虚拟化环境，可以安全地学习Linux管理技能。


1、什么是虚拟化


以前，当您想用一台新的服务器为公司或公司客户提供Web服务器或文档共享服务时，需要先进行研究、申请预算、协商、订购、安全安装和配置，之后启动一个崭新的计算机。从开始到结束的整个过程可能花费数月。当增加的服务需求远超过服务器的能力时，就要再次重复上述过程，并且希望最终能够平衡能力与需求。


常见的情形是，公司常常会提供多个相互依赖的服务，并将其部署在分布式的硬件上。试想部署一个有后端数据库的前端Web服务器。然而，当一切完成时，通常会发现，一台服务器未被充分利用而另一台服务器（通常在机柜中的一侧）却无法满足要求。但是，再来设想您可以在多个服务之间安全地共享一台高性能服务器的计算、内存、存储和网络资源。想象一下，通过在物理服务器上创建多个仅需分配所需资源的虚拟服务器实例，之后及时调整资源分配来满足不断变化的需求是多么方便。


现在，设想能够将一组运行多个操作系统的虚拟计算机有效地打包部署到一台裸机服务器上，由此，绝对不会存在任何浪费。再设想一下，当前面的物理服务器满负载时，虚拟机（Virtual Machine，VM）将会被自动部署到后续的其他物理服务器上。再来设想一下，杀死一个故障的或者需要更新的虚拟机是非常方便的，甚至快速地进行替代以致用户感知不到任何变化。在您的脑海中已经出现这样的情景了吗（希望如此，类似于图1所示的内容）？您正在设想的便是虚拟化（virtualization）。图1非常具有吸引力，现在已经成为企业计算领域的主流。本地服务器或基于云的服务器有许多负载剩余，它们没有运行在某种虚拟化技术上。而且，运行绝大多数虚拟负载的操作系统正是Linux。

图1  一台硬件主机上的多个虚拟机客户端，它们彼此连接并通过一个外部路由器连接到大的网络


亚马逊Web服务（Amazon Web Service，AWS）允许客户租用（Linux）服务器上的服务能力，这些服务器运行数百万计的虚拟机，而这些虚拟机则运行着无数的负载，包括诸多最流行的在线服务。图2给出了AWS弹性计算云（Elastic Compute Cloud，EC2）实例如何作为各种存储、数据库和网络化工具的服务枢纽。

图2  以亚马逊Web服务上AWS弹性云计算（EC2）虚拟机实例为中心的常见云计算负载


成功的虚拟化在物理计算机上使用了可以安装客体操作系统的某种隔离空间，并且客体操作系统误以为是在自己的计算机上独自存在。客体操作系统之间可以共享网络连接，从而使其管理员都可以远程登录，并且像在传统计算机上一样正确地完成工作。这些统一的共享网络连接允许使用虚拟机来提供网站等公共服务。总体而言，当前有两种虚拟化方法：


管理程序（Hypervisor，也称为虚拟机管理器）——在某种程度上控制宿主系统的硬件，为每个客户操作系统提供所需的资源（如图3所示）。客户计算机以系统进程的形式运行，但是可以虚拟地访问硬件资源。例如，AWS服务器早已构建在开源的Xen管理程序技术上。其他同样重要的管理程序平台还包括VMware ESXi、KVM和微软的Hyper-V。

图3  II型虚拟机管理器体系结构：每个客户机上都安装了完整的操作系统并将一些特殊的管理职责分配给了客户机1


容器（Containers）——非常轻量级的虚拟服务器，它们并不以完整操作系统的方式运行，而是共享宿主操作系统的底层内核（如图4所示）。容器可以由纯文本的脚本来构建，在数秒时间内完成创建并启动，并可以简单又可靠地在网络上进行共享。当前最有名的容器技术当属Docker。我们将要使用的Linux容器（LXC）项目就来源于Docker最初的灵感。

图4  呈现LXC环境以及Linux内核与硬件层间访问关系的LXC体系结构


像Xen和KVM这样完整的虚拟机管理器（通过像Libvirt这样的管理前端）通常用于企业级Linux虚拟机部署，涉及大量的Linux虚拟机。


VirtualBox（以及VMware Player）在采用现有操作系统进行测试和实验是很好的，一次一个或两个，且无须将其安装到实际的计算机上。但它们相对较高的上限使得它们并不适合于大多数产品环境。


像LXC和Docker这样的容器技术是轻量级的，且可以在数秒内完成配置和启动。LXC容器特别适合于运用新技术和安全地构建操作系统的软件栈。Docker是当前运行无数动态的、集成的容器集群的技术，它是大量微服务体系结构的一部分。


下面分别介绍两种虚拟化技术：VirtualBox（一个II型虚拟机）和LXC（一种容器管理器）。

2、VirtualBox


用Oracle的开源软件VirtualBox可以做很多事情。可以将其安装在任何操作系统（包括Windows）中，在台式机或笔记本电脑上运行，或者使用该软件在几乎所有的宿主操作系统上托管运行一组虚拟机实例。


在Windows计算机上安装VirtualBox，请前往VirtualBox的网站（https://www.virtualbox.org/wiki/Downloads）并下载可执行文件。点击已下载的文件，然后执行安装步骤。


VirtualBox提供了一个环境，可以在其中启动物理系统资源所能支持的尽可能多的虚拟机。同时，对于安全地测试和学习新的管理技能，它也是一个特别有用的工具。但在所有这些之前，需要知道如何在Linux系统中下载和安装软件。

（2）定义虚拟机


在VirtualBox界面中点击New（新建）按钮之后，可以给将要创建的虚拟机一个描述性名称。如图7所示，该软件应该能自动地为Type（类型）和Version（版本）字段填写正确的内容。这里所选的Type和Version并不会安装一个实际的操作系统，而是用于申请一些适当的硬件模拟设置。

图7  创建虚拟机对话框：VirtualBox会尝试推测你的操作系统及其版本，之后智能地提供默认选项


在下一个界面中，要给虚拟机分配RAM（内存）。除非计划做一些具有特殊要求的事情，如托管一个容器群或者运行一个重负载的Web服务器，否则默认容量（768 MB）应该就可以了。如有必要，当然可以分配更多的RAM，但不要忘了，要为宿主计算机及可能已经在其中运行的其他虚拟机留下足够的空间。如果宿主机只有4 GB的物理RAM，可能就不想将其中的一半分配给虚拟机了。


如果最终决定要一次运行多个虚拟机就要注意这些限制，即使每个虚拟机都仅使用默认的内存容量，两三个虚拟机也可能会逐渐消耗掉宿主机正常操作所需的RAM。


接下来，VirtualBox设置过程会询问是否要为虚拟机创建新的虚拟硬盘或者使用已存在的虚拟硬盘（如图8）。没有硬盘驱动器的计算机会是什么样的？有时可能希望在两个虚拟机之间共享一个硬盘，但是对于这个练习，会希望从头开始。选择“Create a Virtual Hard Disk Now”（现在创建一个虚拟硬盘）。

图8  硬盘配置界面。请注意，在这种情况下，选择非默认的“Use an Existing Virtual Hard Disk File”（使用一个已存在的虚拟硬盘文件）单选按钮


下一个界面（如图9所示）选择即将要创建的硬盘文件类型格式。除非正在计划将该盘最终导出并用于其他虚拟环境，否则，默认的VirtualBox硬盘映像（VirtualBox Disk Image，VDI）格式就可以很好地工作。

图9  可以使用多种形式创建虚拟硬盘。VDI是仅用于VirtualBox中虚拟机的格式


从未后悔过使用默认的动态分区选项（如图10所示）作为虚拟驱动器消耗主机硬盘空间的方式。这里，动态（dynamic）意味着主机存储盘上的空间将仅在需要时分配给虚拟机。如果虚拟机硬盘的使用率很低，那么将会为其分配更少的宿主机空间。

图10  动态分配的虚拟硬盘将仅消耗所需数量的宿主机空间


另一方面，无论实际使用多少空间，一个固定大小的虚拟硬盘都会被立即分配最大的空间容量。固定大小的唯一优势是应用的性能。因为通常只使用VirtualBox虚拟机进行测试和实验，所以很好地避免了这种情况。


因为环境知道运行的是Linux，并且Linux对存储空间的利用非常高效，因此，VirtualBox在下一个界面中将可能只提供总计8 GB的硬盘大小（如图11所示）。除非对虚拟机有着不寻常的大计划（例如，将处理一些复杂的数据库操作），否则这应该是没有问题的。另一方面，如果已经选择了Windows操作系统，那么默认选项将会是25 GB——这是有充分理由的：Windows并不羞于索取大量的资源。这也很好地说明，Linux非常适合于虚拟环境。

图11  如果需要，虚拟盘可以达到2 TB或者是主机设备上的最大空闲空间


也可以在文件位置和空间大小（FileLocation and Size）界面为VirtualBox设置名字及其在硬盘上的位置。


当完成这些工作后，点击Create（创建），新建的虚拟机将会出现在VirtualBox管理器左侧的虚拟机列表中。但是，工作还没有完成：这只是一台虚拟机。现在，需要一个操作系统赋予这台虚拟机生命。

（4）克隆和共享VirtualBox虚拟机


 克隆虚拟机以快速启动 


使用虚拟机最为明显的优势之一就是能够快速访问一个新的、干净的操作系统环境。但是，如果访问这个环境需要经历完整的安装过程，那如果不采用克隆的方法，我们也感受不到它有多快。为什么不将原始虚拟机保持在安装后的干净状态，并在任何需要实际使用的时候创建一个相同的克隆呢？


这很简单。再来看看VirtualBox的应用程序。选择想用作主副本的（停机的）虚拟机，点击Machine菜单项，之后点击Clone按钮。要给克隆的虚拟机设定名称，接下来，在点击Next后，无论是要创建一个完全克隆（表示将为新建虚拟机创建完整的新文件副本）还是一个链接克隆（表示该新建虚拟机会共享主虚拟机的所有基础文件，但会独立地开始新工作）。


选择Linked选项将会执行得非常快速，同时占用硬盘上更少的空间。唯一的缺点在于，之后无法将这个特定的克隆移动到另一台计算机上。


现在，请点击Clone，在虚拟机面板中将出现一个新的虚拟机。以正常的方式启动该虚拟机，然后用主虚拟机上设置的认证信息登录该虚拟机。
