Pyspider[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)框架是一个由国人设计开发的[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)框架。与其他[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)框架不同的是Pyspider不需要任何编辑器或者IDE的支持。它直接在[Web](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130618&idx=3&sn=449f93385285290a85de33579f5e55bf&chksm=bc858e158bf20703b709bfb7ddf2adee4149765451b8281f45a741aee2c621c396b330f67af2&scene=21#wechat_redirect)界面，以浏览器来编写调试程序脚本。在浏览器上运行、起停、监控执行状态、查看活动历史、获取结果。Pyspider支持[MySQL](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126890&idx=3&sn=1cdab8e3953ef5db6b337a3e91a3dafd&chksm=bc8598858bf21193106359c3a1855175328ce1420020eada002972457ce1145f91b55d5da09d&scene=21#wechat_redirect)（MariaDB）、MongoDB、SQLite等主流[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)，支持对[JavaScript](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130915&idx=3&sn=ab1009f010fdfc8fad258e13e7f6f641&chksm=bc8588cc8bf201da7bc2fa3efb0ec1f466a1d4d48d57baa7bec2a6b0391cced70ab9f8539de2&scene=21#wechat_redirect)的页面抓取（也是靠的PhantomJS的支持），重要的是它还支持分布式[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)的部署，是一款功能非常强大的[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)框架。Pyspider上手比较简单，但想深入了解也是要花点工夫的。  
基于Pyspider纯正的[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)血统，安装Pyspider最简单的方法是用pip。如果需要最新版本的Pyspider可以到官网下载最新版本安装，或者用git来安装。  
**1、Windows下安装Pyspider**  
在[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)中安装Pyspider采用比较简单的pip安装，进入桌面后，单击左下角的开始按钮，在弹出菜单中单击“运行”，打开cmd.exe，执行命令：  
pip install pyspider  
  
一定要先配置好pip的源，否则安装会慢得令人难以接受。  
执行结果如图1所示。

Pyspider对[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)的支持不是非常好。如果条件允许，尽量避免在[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)下使用Pyspider框架。官方网站也对此做了说明。  
**2、Linux下安装Pyspider**  
在[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126956&idx=3&sn=237ee71fb1fc21ca3822e3d9d0202ed1&chksm=bc8598438bf21155d298f8b99f358cc572e21b627d967d5350aadc7bb838bd9d6689aca8fdb3&scene=21#wechat_redirect)下安装Pyspider可能会出现依赖性的问题。这里采用最安全的方法，使用Anaconda创建虚拟环境[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect) 3后，在虚拟环境下安装Pyspider，这样可以完美地解决依赖性的问题。执行命令：

**3、选择器pyquery测试**  
在Pyspider[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)中继续使用[CSS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118810&idx=2&sn=222973f12edefd4f55d87b152c3fce24&chksm=bc8678358bf1f123e6a13fd85ece75642031e33ae10ca2ad3e764f8d532aacc056cb198d066a&scene=21#wechat_redirect)和XPath也是可以的。但Pyspider框架自备了pyquery选择器（在安装Pyspider时pyquery会自动安装），并在框架中为pyquery准备了提示接口。pyquery选择器与[CSS](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655118810&idx=2&sn=222973f12edefd4f55d87b152c3fce24&chksm=bc8678358bf1f123e6a13fd85ece75642031e33ae10ca2ad3e764f8d532aacc056cb198d066a&scene=21#wechat_redirect)和XPath一样强大，同样支持嵌套[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126780&idx=3&sn=6c65767c93a0f3917d8992301cf94292&chksm=bc8599138bf210055e67c6ddc2f4e5f25980802975066830b0aea7073f7d8a495e4274265d78&scene=21#wechat_redirect)。在Pyspider框架中不妨试用一下pyquery，至于最终选择哪一个选择器，视个人习惯而定。  
pyquery选择器不仅仅可以选择过滤有效信息，还可以修改原文中的标签属性，但在[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)中只需要选择过滤这一功能就足够了。pyquery选择[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126780&idx=3&sn=6c65767c93a0f3917d8992301cf94292&chksm=bc8599138bf210055e67c6ddc2f4e5f25980802975066830b0aea7073f7d8a495e4274265d78&scene=21#wechat_redirect)非常简单，最常用的是通过标签配合标签属性和属性值[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126780&idx=3&sn=6c65767c93a0f3917d8992301cf94292&chksm=bc8599138bf210055e67c6ddc2f4e5f25980802975066830b0aea7073f7d8a495e4274265d78&scene=21#wechat_redirect)（一般来说通过标签[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126780&idx=3&sn=6c65767c93a0f3917d8992301cf94292&chksm=bc8599138bf210055e67c6ddc2f4e5f25980802975066830b0aea7073f7d8a495e4274265d78&scene=21#wechat_redirect)就足够了），偶尔也有直接通过标签属性或者标签属性值[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126780&idx=3&sn=6c65767c93a0f3917d8992301cf94292&chksm=bc8599138bf210055e67c6ddc2f4e5f25980802975066830b0aea7073f7d8a495e4274265d78&scene=21#wechat_redirect)的。

写一个简单的网页song.html做测试，song.html的[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)如下：
