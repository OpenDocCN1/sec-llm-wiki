Selenium和PhantomJS配合，可以模拟浏览器获取包括[JavaScript](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130915&idx=3&sn=ab1009f010fdfc8fad258e13e7f6f641&chksm=bc8588cc8bf201da7bc2fa3efb0ec1f466a1d4d48d57baa7bec2a6b0391cced70ab9f8539de2&scene=21#wechat_redirect)的数据。不单要获取网站数据，还需要过滤出“有效数据”。Selenium本身带有一套自己的[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)过滤[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)。它可以很方便地从网站返回的数据中过滤出所需的“有效数据”。  
**1、获取百度搜索结果**  
想知道[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)模块最详细的用法，直接用help[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)就可以了。鉴于Selenium.Webdriver的help文件太大，分屏显示又不那么方便，干脆将帮助文件保存到文件中慢慢查看。执行命令：  
python  
from selenium import webdriver  
import sys  
browser=webdriver.PhantomJS()out=sys.stdout  
sys.stdout=open('browserHelp.txt','w')help(browser)  
sys.stdout.close()sys.stdout=outbrowser.quit()exit()  
  
一定要加上browser.quit()，否则cmd.exe在执行exit时会无法退出。

想获取“有效信息”，第一步当然是网站获取返回数据，第二步就是[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)“有效数据”的位置，第三步就是从[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)中获取“有效数据”。  
以百度搜索为例，使用百度搜索“[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect) Selenium”，并保存第一页搜索结果的标题和链接。从[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)返回数据，由PhantomJS负责，获取返回的数据用Selenium.Webdriver自带的方法page\_source，例如：  
from selenium import webdriver  
browser=webdriver.PhantomJS()browser.get(URL)html=browser.page\_source

有两种方法可以得到搜索结果页面。第一种，百度主页还是使用get方式上传request。这里可以先找一个浏览器，打开百度后搜索关键词。再把返回来的搜索结果的URL保存下来用Selenium&PhantomJS打开，再获取返回的数据。第二种，直接用Selenium&PhantomJS打开百度的主页，然后模拟搜索关键词。直接从Selenium&PhantomJS中返回数据。这里使用第二种方法，可以很清楚地看到Selenium&PhantomJS获取数据的过程。  
第一步获取搜索结果。打开cmd.exe，准备好环境。执行命令：  
python  
from selenium import webdriverbrowser=webdriver.PhantomJS()browser.get('https://www.baidu.com')browser.implicitly\_wait(10)

这里要关注一个[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)implicitly\_wait()。使用Selenium&PhantomJS最大的优势是支持[JavaScript](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130915&idx=3&sn=ab1009f010fdfc8fad258e13e7f6f641&chksm=bc8588cc8bf201da7bc2fa3efb0ec1f466a1d4d48d57baa7bec2a6b0391cced70ab9f8539de2&scene=21#wechat_redirect)，而PhantomJS浏览器解释[JavaScript](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130915&idx=3&sn=ab1009f010fdfc8fad258e13e7f6f641&chksm=bc8588cc8bf201da7bc2fa3efb0ec1f466a1d4d48d57baa7bec2a6b0391cced70ab9f8539de2&scene=21#wechat_redirect)是需要时间的。这个时间是多少并不好确定，当然可以用time.sleep()强行休眠等待一个固定时间。可这个固定的时间定长了，浪费时间；定短了，又没能完整地解释[JavaScript](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130915&idx=3&sn=ab1009f010fdfc8fad258e13e7f6f641&chksm=bc8588cc8bf201da7bc2fa3efb0ec1f466a1d4d48d57baa7bec2a6b0391cced70ab9f8539de2&scene=21#wechat_redirect)。Implicitly\_wait[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)则完美地解决了这个问题，给implicitly\_wait一个时间参数。Implicitly\_wait会智能等待，只要解释完成了就进行下一步，完全没有浪费时间。下面从网页的框架中选取表单框，并输入搜索的关键词，完成搜索的过程。  
**2、获取搜索结果**  
第二步[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)表单框架或“有效数据”位置，可以用import导入bs4来完成，也可以用Selenium本身自带的[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)来完成。Selenium本身给出了18个[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)，总共8种方法从返回数据中[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)“有效数据”位置。这些[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)分别是：  
find\_element(self,by='id',value=None)  
find\_element\_by\_class\_name(self,name)find\_element\_by\_css\_selector(self,css\_selector)find\_element\_by\_id(self,id\_)find\_element\_by\_link\_text(self,link\_text)find\_element\_by\_name(self,name)find\_element\_by\_partial\_link\_text(self,link\_text)find\_element\_by\_tag\_name(self,name)find\_element\_by\_xpath(self,xpath)find\_elements(self,by='id',value=None)find\_elements\_by\_class\_name(self,name)find\_elements\_by\_css\_selector(self,css\_selector)find\_elements\_by\_id(self,id\_)find\_elements\_by\_link\_text(self,text)find\_elements\_by\_name(self,name)find\_elements\_by\_partial\_link\_text(self,link\_text)find\_elements\_by\_tag\_name(self,name)find\_elements\_by\_xpath(self,xpath)  
这18个[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)前面的9个带element的[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)将返回第一个符合参数要求的element，后面9个带elements的[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)将返回一个列表，列表中包含所有符合参数要求的element。命名是9个[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)，为什么只有8种方法呢？上面[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)中，不带by的[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)，配合参数可以替代其他的[函数](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131096&idx=3&sn=20e2c1ceb7bd5c698032bcfc997a1431&chksm=bc8588378bf2012150133917af2141895c000b21b53a0e272c5eb80835d7b56bf749a527aa14&scene=21#wechat_redirect)。例如：find\_element(by='id', value='abc')就可以替代find\_element\_by\_id('abc')。同理，find\_elements(by='id', value='abc')也可以替代find\_elements\_by\_id('abc')。

这8种[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)方法组合应用，灵活配合，可以获取[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)数据中的任何位置。在使用浏览器请求数据时，用find\_element\_by\_name、find\_element\_by\_class\_name、find\_element\_by\_id、find\_element\_by\_tag\_name会比较方便。一般的表单、元素都会有name、class、id，这样[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)会比较方便。如果仅仅是为了获取“有效数据”的位置，还是find\_element\_by\_xpath和find\_element\_by\_css比较方便。强烈推荐find\_element\_by\_xpath，真的是超级方便。  
先[定位](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132478&idx=3&sn=e1f269e93869552f9bc28106bc953c53&chksm=bc8586d18bf20fc71e48eab8d196d4495d034840574faf53e91fecf13ec05c86745bea80fbbe&scene=21#wechat_redirect)文本框，输入搜索关键词并向[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)发送数据。在Chrome中打开百度主页，查看源[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)页面（如果想全程无GUI，也可以直接在Selenium中用page\_source获取页面[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)，保存后再慢慢搜索，不过这样就比较麻烦了）。在源[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)页面搜索type=text，也就是查找页面使用的文本框，搜索结果如图3所示。

**4、从位置中获取有效数据**

element.text  
element.get\_attribute(name)  
回到Chrome浏览器搜索结果的源[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)页面，如图10所示。
