Mechanize是[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)的一个模块，用于模拟浏览器。Mechanize的易用性和实用性比较平衡，功能强大而又简单易用。

  

**1、安装Mechanize模块**

  

Mechanize在官网中给出了3种安装方法：easy\_install安装、源码安装和git安装。实际安装时根据平台特性选择最简单的安装方法即可。

  

**（1）Windows下安装Mechanize**

  

在[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect)中安装[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)的第三方模块，最简单的方法莫过于pip了（前提条件是已经配置过pip源了，使用初始源会比较慢）。打开cmd.exe，执行命令：

  

pip install mechanize

  

执行结果如图1所示。

**（2）Linux下安装Mechanize**

  

在[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126956&idx=3&sn=237ee71fb1fc21ca3822e3d9d0202ed1&chksm=bc8598438bf21155d298f8b99f358cc572e21b627d967d5350aadc7bb838bd9d6689aca8fdb3&scene=21#wechat_redirect)下找安装软件最简单的方法还是apt-get，感谢“万能”的Debian软件库，即使是[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)模块也可以用apt-get一键安装。不必介意Mechanize官网上的安装建议，怎么简单怎么来就可以了。执行命令：

  

apt-get install python-mechanize

**2、Mechanize测试**

  

Mechanize模块常用的命令、方法并不多，作为普通使用者，无须追求掌控所有细节，只需要能使用、会使用即可。它只是一个很简单的模块，多试几次就能熟练掌握。

**（1）Mechanize百度**

  

先试一下最简单的用法，以最常用的网站百度为例。使用Mechanize访问百度搜索站点，并使用百度搜索“[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)[网络爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)”得到返回结果。如果不使用Mechanize，就只能在浏览器中输入搜索的关键字，再观察URL的变化规律，最后将所有的URL注入列表中，一个个地返回结果爬取数据。下面演示如何使用Mechanize模拟浏览器，搜索关键字。

  

使用Putty连接到[Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126956&idx=3&sn=237ee71fb1fc21ca3822e3d9d0202ed1&chksm=bc8598438bf21155d298f8b99f358cc572e21b627d967d5350aadc7bb838bd9d6689aca8fdb3&scene=21#wechat_redirect)，运行[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)程序，并导入Mechanize模块，如图3所示。

**（2）Mechanize光猫F460**

  

Mechanize可以模拟登录，只是现在几乎所有的站点登录都需要输入[验证码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131672&idx=3&sn=5f25d006408aa11a3e4db5ce73993165&chksm=bc8585f78bf20ce1979903ba401093239253dd1008110b48504add50484d360b90705ba43e15&scene=21#wechat_redirect)。虽然也有开源的解决方案，可以解决[验证码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131672&idx=3&sn=5f25d006408aa11a3e4db5ce73993165&chksm=bc8585f78bf20ce1979903ba401093239253dd1008110b48504add50484d360b90705ba43e15&scene=21#wechat_redirect)什么的，但是有更简单的解决方案，没必要在这里与[验证码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131672&idx=3&sn=5f25d006408aa11a3e4db5ce73993165&chksm=bc8585f78bf20ce1979903ba401093239253dd1008110b48504add50484d360b90705ba43e15&scene=21#wechat_redirect)死磕。最简单的方法就是最合适的方法，宁愿多敲几行[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)，也要选择最简单的。

如今无须[验证码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131672&idx=3&sn=5f25d006408aa11a3e4db5ce73993165&chksm=bc8585f78bf20ce1979903ba401093239253dd1008110b48504add50484d360b90705ba43e15&scene=21#wechat_redirect)就可以登录的站点不好找。好在身边有一个现成的[Web](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130618&idx=3&sn=449f93385285290a85de33579f5e55bf&chksm=bc858e158bf20703b709bfb7ddf2adee4149765451b8281f45a741aee2c621c396b330f67af2&scene=21#wechat_redirect)[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)符合要求，F460光猫的配置页面，而且正好是动态回复数据的，简直是为Mechanize量身定做的。
