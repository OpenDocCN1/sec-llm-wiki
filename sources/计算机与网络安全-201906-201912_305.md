**2、数据存储到json**

  

前面完成了一个Scrapy[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)，并将其爬取的结果保存到了txt文件。但txt文件的优点仅仅是方便阅读，而程序阅读一般都是使用更方便的json、cvs等等格式。有时[程序员](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129762&idx=3&sn=ff93f3c7ab9c4f118cc540ca9613e9f8&chksm=bc858d4d8bf2045b98ec58aca816d0bdc223b0600f9808e34f7257c8c420c3b7ef9006a02814&scene=21#wechat_redirect)更加希望将爬取的结果保存到[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)中便于分析统计。下面继续讲解Scrapy[爬虫](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131400&idx=3&sn=f400239fa227306bc6364cb23e65bf41&chksm=bc858ae78bf203f17936791b10ace05bda429572f563b6bb269e960efc64937a43a3f06a94d2&scene=21#wechat_redirect)的保存方式，也就是继续对pipelines.py动手术。

  

这里以json格式为例，其他的格式都大同小异，您可自行摸索测试。既然是保存为json格式，当然就少不了[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)的json模块了。幸运的是json模块是[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)的标准模块，无须安装可直接使用。

  

保存爬取结果，那必定涉及了pipelines.py。我们可以直接修改这个文件，然后再修改一下settings.py中的ITEM\_PIPELINES项即可。但是仔细看看settings.py中的ITEM\_PIPELINES项，它是一个字典。字典是可以添加元素的。因此完全可以自行构造一个[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)文件，然后把这个文件添加到ITEM\_PIPELINES不就可以了吗？这个思路是否可行，测试一下就知道了。

  

为了“表明身份”，给这个新创建的[Python](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126409&idx=3&sn=7880b5cffc9b669e5548a0b522ee0fbd&chksm=bc859e668bf2177034e513527cc10ed27435a3f3aa7f7d862a98149f140d8cd21a179c1d017d&scene=21#wechat_redirect)文件取名为pipelines2json.py，这个名字简单明了，而且显示了与pipellines.py的关系。pipelines2.json的文件内容如下：

11

18             fp.write("%s \\r\\n" %jsonStr)

19         return item

10 class WeatherPipeline(object):

11     def process\_item(self, item, spider):

12         cityDate = item\['cityDate'\]

13         week = item\['week'\]

14         temperature = item\['temperature'\]

15         weather = item\['weather'\]

16         wind = item\['wind'\]

17

18         conn = pymysql.connect(

19                 host = 'localhost',

20                 port = 3306,

21                 user = 'crawlUSER',
