2019年网络安全态势报告


2019年，频繁的信息泄露、网络攻击事件，以及等保2.0国家标准等网络安全政策法规的发布，都使得网络安全在全国范围内获得相比往年更高的关注度。那么，在这一年里，中国的网络安全现状究竟如何？


深信服千里目安全实验室从恶意软件、网站安全、漏洞、APT攻击等方面分析整体网络安全态势情况，发布《2019年网络安全态势报告》（以下简称报告）。


1、网络安全态势综述


纵观 2019 年，整体网络安全态势平稳。其中，恶意软件攻击明显转向政企行业，网站攻击明显增加，可远程利用的高危漏洞持续爆出，APT攻击影响范围扩大。


与此同时，黑色产业（简称黑产）一直在开发针对性的新工具集和技术，目标包括针对存储在云上的基础架构、个人移动设备、可信赖的第三方供应商服务器等。互联网用户面对的攻击面不断扩张，攻击来源更加多样，攻击场景也进一步复杂化。


本报告基于深信服安全云脑 2019 年的数据，以及网络安全专家进行的初步研究，重点阐述恶意软件、网站安全、漏洞、APT攻击等方面的态势观察。


恶意软件方面，勒索病毒感染事件约占恶意软件总事件的 1%左右，但相比其他恶意软件破坏力更大，同时勒索软件目标逐步转向更有价值的企业或组织机构，并出现了新的“窃密”勒索模式，威胁受害者如果不交赎金则公开数据；挖矿软件的攻击并未缓减，类型上趋向隐蔽性更好的币种；供应链感染则是 2019 年木马远控病毒传播的重要特点；大量病毒蠕虫化，对企业或组织机构的网络安全造成更大的威胁。


网站安全态势方面，深信服授权监控的站点中检测到约有 10% 存在高危漏洞，2019 年下半年网站攻击尝试量增长了 59％，网站信息泄漏攻击、系统命令注入、弱密码是攻击者尝试的攻击手段；钓鱼邮件方面，利用混淆字符伪造成知名邮件服务商发件的钓鱼邮件、网络诈骗钓鱼邮件、伪造管理员邮件、BEC（商业欺诈邮件）等是当前较常见的钓鱼场景；网页篡改方面，博彩、色情、游戏类篡改是主流类型。


漏洞态势方面，漏洞收录较去年增加 14%，其中可被利用来实施远程攻击的漏洞占比 99.6%；2019 年爆发的重要漏洞包括 WinRAR 路径穿越漏洞、Chrome 0Day 漏洞、BlueKeep 漏洞等；漏洞利用的网络攻击流量在后半年有所缓解，但仍有较多高危漏洞持续爆出，容易被犯罪分子利用。


高级持续威胁方面，APT攻击影响范围进一步扩大，全国大部分地区都有受到影响；涉及的行业也不仅是政府单位，科研机构、大学、医疗、工业制造业以及国家基础建设相关的行业都成为 APT 组织的目标；与此同时，多平台的攻击能力已经成为大量 APT 组织的标配能力；0day 利用攻击依然是 APT 最有效的攻击方式。


2、恶意软件态势


深信服安全团队根据深信服安全云脑的威胁情报及病毒拦截日志，分析当下组织单位面临的的恶意软件风险及 2019 年恶意软件态势。


2.1 恶意软件概览


恶意软件在 2019 年表现非常活跃，深信服安全云脑检测到的活跃恶意程序拦截量为 181.07 亿次。从 2019 年全年数据和事件中，可以发现以下趋势：


（1）攻击者针对政企目标的攻击变得更加频繁，攻击手法逐渐偏向 APT；


（2）加密货币挖矿流量较去年增长约 100%，在类型上也趋向隐性更好的币种。


2.1.1 失陷主机状况


深信服通过客户端上网场景下的威胁检测发现企业/组织的失陷主机，并及时对恶意 C&C 通信进行阻断拦截。数据显示企业/组织的失陷主机在 2019 年持续上升，在 12 月达到最高峰，有 56 万台主机/服务器被感染。针对企业或组织机构的攻击变得更加频繁，更具有针对性，攻击者通常以经济利益为目的，在攻击场景上开始针对存储在云上的基础架构、个人移动设备、可信赖的第三方供应商服务器等。失陷主机状况如下：


2.1.2 恶意软件拦截类型


根据深信服安全云脑数据显示，2019 年约 25%的企业发生过恶意软件攻击事件。挖矿类恶意软件感染占比最多（占 58%），其次为远控类木马（占 14%），企业或组织内文件共享等机制也使得感染型病毒的比例在 9%左右，另外勒索软件的拦截次数虽然占比较低，但是一旦主机/服务器被攻陷，所造成的危害极大，建议企业或组织重点防范。


2.1.3 各行业拦截恶意软件类型


挖矿软件在各行业的拦截占比最高，此外后门远控木马和蠕虫病毒在教育、医疗的拦截比例也相对较高，而且往往都有较大的感染量，可能是由于用户对这类恶意软件的感知不是很明显导致没有及时清理杀毒。


2.2 勒索软件攻击分析


2019 年，勒索软件的攻击次数有所减少，但勒索软件对于企业、政府机构的攻势丝毫没有停歇的迹象，数百种病毒依旧异常活跃，每天全球各地都有不同的政府、企业、组织机构被勒索病毒攻击的新闻被曝光。2019 年勒索软件攻击趋势如下：


2.2.1 高发勒索家族


近年来新的勒索病毒仍然层出不穷，勒索病毒的威胁也有增无减。之所以勒索软件会快速发展，源于基于订阅的黑产模式-勒索即服务（RaaS）的兴起，该模式使得即使是新手的犯罪分子，也可以轻松发起勒索攻击，GandCrab、Sodinokibi 等均是该模式的代表。下图可以看到国内高发的勒索病毒类型较多，主要的家族有 WannaCry、GlobeImposter、GandCrab 等。


其中，WannaCry 虽然已经爆发许久，但根据深信服云端数据显示，每天依然有大量 WannaCry 攻击警报（部分被修改的 WannaCry 病毒不具备加密能力，但依然可以规模传播），源于依然有不少单位出于谨慎考虑避免安装 Windows 更新，尚未修复补丁。深信服建议企业或组织机构及时做好补丁更新以防止漏洞被恶意攻击者利用。


2.2.2 感染行业分布


根据深信服 EDR 终端软件病毒拦截数据显示，勒索病毒感染行业中政府和企业的占比达到了 45.77%。其中文件服务器、财务服务器等存储重要数据文件的服务器通常是勒索软件攻击者的首要目标。下图是勒索病毒感染行业分布情况：

2.2.4 勒索软件小结


（1）勒索软件目标从用户转向政企，赎金大幅涨价


现在的勒索病毒攻击目标，从广泛而浅层的普通用户，明显转向了中大型政企机构、行业组织。有安全报告表明，自 2018 年 6 月以来，全球针对 To B 的勒索攻击增加了 363%。


（2）勒索软件新模式-不支付赎金则公开数据，预期会有更多的犯罪团伙效仿


通常大家理解的勒索软件，会加密受害者的数据，需要通过支付赎金来换取解密密钥（实际中有些勒索软件攻击者也没有能力再恢复数据）。而近期一些勒索软件在进行攻击时会先窃取受害者的私密数据，如果受害者不支付赎金，攻击者就会公开或出售这些被盗数据。

过去勒索受害者只需要考虑如何恢复被勒索软件加密的文件数据或快速恢复业务，而现在受害者还要承担声誉、业务、法律诉讼等多重压力，这种压力无疑增加了受害者缴纳赎金的概率。未来主流勒索团伙很可能选择这种新的勒索攻击方式，并且在这一领域持续“创新”，攻击方式和手段将会变得更加复杂。


（3）使用合法的管理工具逃避检测


攻击者利用远程监视和管理（RMM）解决方案（例如 Kaseya、 ScreenConnect 和 Bomgar）中的漏洞来进行入侵。通过这种访问，他们可以轻松地将勒索软件从远程分发到网络中。RMM 解决方案通常以高特权运行，一旦遭到破坏，就会为远程攻击者提供“手动操作” 访问，从而导致数据劫持的发生。


例如，MegaCortex 勒索软件 killchain 使用合法的系统管理应用程序（例如 WMI）来分发恶意软件，用户却误以为是系统更新。


2.3 挖矿软件攻击分析


 挖矿软件攻击仍然流行，攻击数量位居恶意软件前列 


挖矿软件攻击使得黑客不必建立专用的加密矿计算机，而是直接从受害者的设备中窃取计算资源。与勒索软件相比，被捕获和识别的风险也要低得多。挖矿活动可以秘密运行，并且一般很长时间内都不会被发现，即使被发现，也很难追溯到源头，而且受害者没有追溯的动力，因为没有任何东西被盗或加密。

深信服在 DNS 层上观察到的与恶意加密货币挖矿相关的流量总量看来，加密货币挖矿在 2019 年的活动有一定的波动，但是由于进入门槛低和开销最小，恶意挖矿相关的病毒可能在未来一段时间内仍会保持热门，尤其是具备更好的隐藏机制并且所需算力较少的门罗币相关挖矿病毒。具体趋势如下：

2.3.4 挖矿软件小结


在所有病毒类型中，挖矿木马是企业服务器被攻陷后植入的主要木马类型。2019 年爆发的多个远程代码执行漏洞、N-day 漏洞都较快地被黑产加入到挖矿木马的武器库中，无文件挖矿也因其具备更好的隐蔽性特点而难以被杀毒软件检测并清除，这些都给企业或组织机构带来了严峻的考验。


2.4 木马远控攻击分析


2.4.1 木马远控各家族拦截情况


深信服安全云脑全国检测到木马远控病毒样本 10897 个，共拦截 5.57 亿次，远控木马拦截量具体分布数据如下图所示：


其中最活跃的木马远控家族是 Drivelife。该病毒为供应链传播木马。由于软件本身拥有巨大用户量，通过软件升级进行木马分发可在短时间内获得大量计算机资源，供应链感染因此深受黑产青睐。


部分终端失陷后，攻击者植入远控木马，并利用其作为跳板，部署漏洞攻击工具再次攻击内网其他终端，最终植入其他更多更严重的病毒。


2.4.2 木马远控病毒区域拦截情况


对全国区域木马远控病毒拦截量进行分析统计发现，恶意程序拦截成效最高的地区为广东省，占 TOP10 拦截量的 26.57%；其次为北京市（12.91%）、浙江省（12.36%）、广西壮族自治区（8.22%） 和湖南省（7.64%）。此外山东省、四川省、江苏省、上海市的木马远控拦截量也排在前列。


2.4.3 木马远控病毒行业感染情况


行业分布上，企业、教育及政府行业是木马远控病毒的主要攻击对象。由于其具有非常高的隐蔽性，接受远程指令执行信息窃取传输，下发文件上传等，对科技企业等信息敏感行业造成巨大伤害。


2.4.4 木马远控病毒趋势小结


供应链感染是 2019 年远控木马传播的一大特点。2019 年捕获到的驱动人生（Drivelife）木马等病毒多次变种，防御程度难，感染范围不断扩大，这些病毒可以大规模影响计算机，影响周期持续数月甚至数年。从黑客的角度来看，此方法至少具有明显的优势：他们依靠第三方供应商的良好声誉来扩大其流通渠道。


另外，目前开源开发框架普遍支持第三方组件的上传，却在组件审核方面缺乏监管。需要高度警惕黑产通过上传恶意代码到组件仓库的方式，攻击用户并窃取隐私数据。

从线性趋势线可以看出，蠕虫病毒活跃情况全年整体在波动中呈上升趋势。其中大多数攻击都来自于 Ramnit、Gamarue、Jenxcus、 Dorkbot、Faedevour、Morto、conficker 家族，这些家族占据了年度蠕虫病毒攻击的 94%，其中攻击态势最活跃的蠕虫病毒是 Gamarue，占蠕虫病毒总量的 44.99%。

从拦截地域上看，广东省地区的蠕虫病毒拦截量最大，其次为湖南省。


2.5.3 蠕虫病毒感染行业分布


从感染行业上看，企业、教育等行业受蠕虫病毒感染程度较为严重。


2.5.4 蠕虫趋势小结


近年来，恶意软件出现大量的蠕虫化，这对用户的网络造成了巨大威胁。而且蠕虫较难清理，且会不断尝试横向传播，有许多漏洞和媒介可以使蠕虫病毒进入网络或计算机或移动设备。因此，保持所有操作系统和应用程序更新及补丁的最新状态至关重要。另外，在下载或更新软件时也要注意，源头需要是可信赖的厂商。


2.6 恶意软件趋势小结


过去的 2019 年，恶意软件表现非常活跃，从大规模的数据泄露到勒索软件攻击，从企业业务系统中断到关键的基础架构瘫痪，恶意软件都在给互联网带来破坏力。犯罪团伙也展现了他们的“创新”，勒索即服务（RaaS）模式、勒索软件窃密威胁、不同恶意软件相互合作等正在使得恶意软件不断变得复杂。用户或者组织面对的威胁也上升到更高的层次。因此了解最新的恶意软件，了解它们的攻击方式以及这些攻击可能带来的影响，并定期更新防病毒软件、浏览器和操作系统变得更加重要，以便用户和组织最好地防御自己。

3、网站安全态势


深信服对全国境内得到授权的 8 万多个站点进行检测，并以此分析现在面临的一些网络威胁，及网站面临的风险因素和新兴趋势。


3.1 网站攻击趋势及类型分析


 网站攻击量持续增加，下半年攻击尝试量增长 59％ 


下图为 2019 年下半年网站安全攻击趋势情况，可以看出，攻击数量呈波动上升状态，下半年网站攻击尝试量增长了 59％：


通过对攻击日志的分析，发现 46%以上攻击流量来源于网站扫描，在大规模批量扫描中被嗅探到大量漏洞的 Web 站点更容易成为攻击者下手的对象。此外，网站信息泄漏攻击、系统命令注入、弱密码等也是攻击者尝试攻击的主要类型。


3.2 Web 站点漏洞状况


 Web 站点漏洞普遍存在，以 CSRF 跨站请求伪造居首 


对全国境内得到授权的 8 万多个站点进行漏洞检测，检测到其中高危漏洞超 86 万个，高危站点比例约为 10%。中高危的漏洞类型以 CSRF 跨站请求伪造、信息泄露、XSS 注入、目录列表和点击劫持等为主。具体类型分布如下：


CSRF 跨站请求伪造、跨站点脚本（XSS）漏洞位于前列源于 Web 应用程序既是攻击者可行的攻击媒介，且攻击门槛较低。此外，越来越明显的是，诸如 SQL 注入之类的漏洞虽然一直以来被利用并且造成严重破坏，但最终数量正在减少。


对数据集内的不同中高危级别漏洞进行分析后，深信服发现较多漏洞存在于淘汰或旧版软件中，这些漏洞容易被不法分子利用。企业可能出于合理的业务考量而保留旧版系统和软件。尤其是，Java 的版本依赖性造成了不少挑战。在这些情况中，建议分割易受攻击的系统，比如在虚拟系统上安装软件并仅按需启动。


从行业角度分析，科研教育、企业、政府单位的安全漏洞数分别占 20%、12%、12%，占发现安全漏洞的大部分；安全设施薄弱的教育和企业持续成为安全漏洞高发地，医疗卫生行业和服务业也普遍存在安全漏洞。


3.3 站点感染恶意软件分类


 垃圾邮件是网站最常见感染类型 


通过抽样调查了一部分感染恶意软件的站点，深信服分析发现垃圾邮件仍然是站点上最常见的感染。40％左右的站点被病毒感染后成为僵尸主机，并向外发送垃圾邮件，感染方式主要为 PHP、数据库注入等方式。


约有 17%的站点存在有钓鱼邮件，从拦截的钓鱼邮件中分析发现，利用混淆字符伪造成知名邮件服务商发件的钓鱼、比特币钓鱼诈骗邮件、伪造管理员邮件等是当前较多的钓鱼场景。


从上图可以看到，邮件诈骗类的钓鱼邮件较多。该种类型的邮件声称获取了用户电脑所有资料、控制权，甚至通过录屏记录了用户观看成人网站时的反应，利用人性的弱点进行诈骗。


而网站篡改虽然仅占 0.45%，但容易影响网站声誉，甚至导致业务中断，造成严重损失。


深信服在 2019 年上半年的篡改检测过程中发现，博彩、色情、游戏类篡改是的主流类型。恶意攻击者进行篡改网站的主要动机是谋求经济利益，因此网站篡改仍以经济利益目的搜索引擎优化（SEO） 类篡改为主。


此外，炫耀目的或政治动机也是部分恶意攻击者篡改网站的动机。以某黑客行为主义团体为例，从 2012 年 5 月到 2019 年底，该组织共篡改国内站点约 965 个，以下为其篡改攻击次数趋势：


3.5 网站安全态势小结


近年大规模、持续的恶意软件活动不断发展，攻击媒介已经发生了变化，攻击者利用流行的第三方组件中的漏洞来攻击网站。典型的网络犯罪分子的目标是获利，他们可能会破坏网站并下发勒索软件，或者他们可能尝试窃取数据，2019 年的网络犯罪行为表明信息是越来越有价值的商品。针对网站的攻击黑客依然选择能够快速赚钱的攻击方式，包括利用垃圾邮件和恶意软件、网页篡改、钓鱼邮件等方式。


此外，无论是否采取安全措施，Web 应用程序都是对各地任何规模组织安全性的重大威胁，这更加需要企业注意关注漏洞威胁情报。


4、漏洞态势


回顾 2019 年，漏洞利用攻击的网络安全事件高发，航空、医疗、保险、电信、酒店、零售等行业均受影响。漏洞的不断挖掘、曝光和修复实际上可以很大程度提升系统的安全性，但如果不能及时修复，会失去攻防大战的先机，处于被动的地位。


本章节通过以下几个方面展现漏洞的趋势，包含：漏洞收录情况、漏洞利用情况、TOP8 重要漏洞等。


4.1 漏洞收录情况


 漏洞新增收录数量呈现上升趋势 


根据 CNVD 监测数据显示，2019 年新增安全漏洞 14208 个，高危漏洞 4886 个，可被利用来实施远程攻击的漏洞 14151 个。同时，近年来 0Day 漏洞收录数量持续走高，在 2019 年上半年 CNVD 收录的通用型安全漏洞数量中，0Day 漏洞收录数量同比增长 34.0%， 因这些漏洞在披露时尚未发布补丁或相应的应急策略，一旦被恶意利用，将可能产生严重安全威胁。

4.4 漏洞态势小结


漏洞利用的网络攻击次数在后半年有所缓减，但是仍有较多高危严重漏洞持续爆出，这些漏洞一旦被成功利用，可能会造成严重后果。而有效的威胁和漏洞管理取决于网络与用户的规模和复杂性、所产生的漏洞数量、以及在通常环境中披露和恶意利用新漏洞的速度。当前组织单位比以往任何时候都更需要切实可行的漏洞情报。


5、高级持续威胁（APT）分析


APT 攻击作为一种有效的威胁手段不断在各类网络对抗中出现。尤其是 2019 年以来很多 APT 团伙的攻击数据集被泄露，使得高水平的工具/漏洞日益被普遍使用，对不同类型企业的网络安全也造成了很大的威胁。


据统计，2019 年全球安全厂商披露的高级威胁总报告数量较去年增长近 1/4，这意味着越来越多的 APT 团伙的攻击数据集被公开，也表明全球 APT 攻击增长态势较为猛烈。2019 年无论是 APT 组织数量，还是 APT 攻击频率都较以往有较大增加。


深信服安全云脑通过对高级威胁情报的收集和跟踪，结合深信服云脑数据梳理国内活跃的 APT 组织及国内 APT 攻击态势。


5.1 国内活跃的 APT 组织分析


 APT 组织主要攻击对象涵盖政府、教育行业以及基础性行业 


APT 组织，其攻击动机主要是长久性的情报刺探、收集和监控，也会实施如牟利和破坏为意图的攻击威胁，通常具有国家情报机构背景，或者专业网络间谍技术团队。APT 组织主要攻击的目标除政府、军队、外交、国防外，也覆盖科研、能源以及国家基础设施性质的行业和产业。


其中，明确针对中国境内进行攻击活动并且依然活跃的 APT 组织，有摩诃草、蓝宝菇、毒云藤、蔓灵花、海莲花、Darkhotel、Group 123、Sidewinder（响Ⰰ蛇）、肚脑虫等。

5.2 APT 攻击态势


 APT 主要攻击行业涵盖政府、教育行业以及基础性行业 


从深信服安全云脑数据来看，国内政府、科研教育、大型企业是 APT 攻击者的主要目标，这也与 APT 攻击的主要意图和目的有关，值得注意的是基础性行业也面临着高级威胁攻击的风险，如能源电力、工业制造业、医疗服务行业等。


而金融行业等也面临着一些成熟的网络犯罪团伙的攻击威胁，其组织化的成员结构和成熟的攻击工具实现对目标行业的规模化攻击。除了针对证券、银行等金融行业外，互联网企业、运营商等也是他们的攻击目标。

5.3 小结


数据表明，全国大部分地区都有受到 APT 攻击的影响，同时涉及的行业也不仅是政府单位，还有科研机构、大学、医疗机构、工业制造业以及国家基础建设相关的行业都成为 APT 组织的攻击目标。另外，多平台、多方式的攻击能力已经成为 APT 组织的标配能力，0Day 漏洞依然是最有效的攻击工具。


6、2020 年威胁趋势展望及应对建议


（1）大型数据泄露事件频发，数据安全越来越受到重视


根据 Risk Based Security 发布的数据泄露报告，2019 年上半年在被泄露的 41 亿条数据中，有 32 亿的数据泄露归咎于 8 起泄露事件，泄露数据占到了总数的 78%。


数据是企业的核心资产，如果数据被破坏或盗取，不仅仅给企业，同时也会给企业的客户会造成巨大的损失，只有保障数据安全，才能避免攻击带来的影响。建议组织单位构建全生命周期的数据安全体系，而非仅仅依赖 DLP。比如在数据产生过程中，确保数据源真实性，可追溯性。在数据传输过程中通过 VPN 技术确保数据传输完整性，保密性。在数据存储过程中，关注存储平台本身存在的漏洞或者安全配置缺陷等，及时进行脆弱性检测。在数据使用过程关注数据使用的规范，进行全量审计及细粒度权限控制。在数据转移共享过程中，确保数据脱敏不外泄。


（2）针对基础性行业和网络设施的 APT 攻击会增多


一些 APT 组织的攻击意图不再只是窃取情报，而是转为破坏关键民生基础设施，针对能源、电信等基础行业的攻击活动已经屡见不鲜，例如电力系统等。


由于 APT 攻击具备高隐蔽性及高持续性，难以通过单一产品进行防护。组织单位需要建立覆盖网络、端点、云端的纵深协同防御体系，并通过威胁情报结合有经验的安全专家构建持续对抗高级威胁的安全能力。


（3）加密货币的价值起伏，但挖矿软件的攻击未来仍会持续很长一段时间


与勒索软件相比，挖矿软件被捕获和识别的风险要低得多。当前恶意挖矿远未摆脱网络犯罪分子的注意，尽管总体活动未来可能会有所减少，但网络犯罪分子仍在这一领域进行“创新”。一旦一些网络犯罪分子发现他们仍然能够在这一领域赚钱，很可能恶意攻击者仍会在未来一段时间内继续推动恶意加密挖矿活动。


（4）针对工控企业的勒索病毒正在增加


2019 年针对工控企业的勒索病毒攻击越来越多，工控企业网络安全形势将越来越严峻。病毒攻击的主要目标是工业主机，然而根据中国国家信息安全漏洞共享平台统计显示，工业主机大多数处于裸奔状态，截止到 2019 年 12 月，CNVD 收录的与工业控制系统相关的漏洞高达 2306 个。


因此工控企业需要加强工控各层级的综合安全防护，包括工控漏洞管理、工控网边界隔离防护、工控态势感知、工控安全监测与审计等。


（5）攻击面扩张攻击场景更加复杂化


随着全国 IT 基础设施投资不断增加，传统的 PC、服务器已经远不能满足黑客胃口，攻击面早已从传统的网站及系统扩展到各类暴露于互联网的业务应用（WebApp、文件共享服务）、各类新的互联网业务（区块链等）、移动应用、电信基础设施等以及供应链的各个环节。已经监测到的攻击场景除传统的僵尸网络以及面向 Web 应用的各类漏洞利用攻击之外，新的场景如各种自动化的批量黑帽 SEO 篡改攻击、勒索病毒、数据窃取、钓鱼、挖矿、面向 IoT 的僵尸网络攻击（DDoS）等。


面对日益复杂化的攻击形势，组织单位的网络安全建设需要通过智能化来持续提升防御、检测、响应、运营能力，持续应对新的风险和挑战，保障信息资产的保密性、完整性、可用性达到预期要求。


（6）新基建给网络安全带来了新的挑战


新基建的实施对于网络安全是机遇，同时也带来了新的挑战。随着新型基础设施建设和应用的开展，相关业务安全风险、应用场景安全风险和关键技术安全风险将逐渐浮出水面。


以 5G 技术为例，5G 时代可以接入更多物联网设备，数量庞大的终端设备，带来了认证难、审查难、控制难等安全问题。5G 也使得互联网的数据实时吞吐量更大，泄露风险加剧。同样人工智能、工业互联等技术的发展也会引入各式各样的安全风险。


因此网络安全行业需要考虑更多的网络安全因素，来满足新基建带来的数字化、智能化时代的信息化安全保障需求。
