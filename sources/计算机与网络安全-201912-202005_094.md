**1、发送ICMP时间戳请求**

  

ICMP时间戳请求允许系统向另一个系统查询当前的时间，但不包含日期。返回的建议值是自午夜零点开始计算的时间（UTC）。ICMP时间戳请求与应答报文格式如图1所示。

![](../Images/9687528d4e2aafcc069b88dd90f5088e.png)

图1  时间戳数据包报文格式

  

在发送ICMP时间戳请求时，请求端填写发起时间戳，然后发送报文。应答系统收到请求报文时填写接收时间戳，在发送应答时填写发送时间戳。在请求和响应的交互过程中，当ICMP报文中的类型值为13、[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)值为0时，数据包为ICMP时间戳请求数据包；当ICMP报文中的类型值为14，[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)值为0时，数据包为ICMP时间戳应答数据包。[netwox](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136054&idx=2&sn=597b1336b8261f8c8e3c1b0dac907be9&chksm=bc85b4d98bf23dcf5d878649edfd3c32906c7ad556982769abcc0124d7b14d6f909fd6127fc2&scene=21#wechat_redirect)工具提供编号为81的模块，用于构建时间戳请求。

  

向目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.135发送ICMP时间戳请求，探测数据包传输的时间。

  

1）发送ICMP时间戳请求，执行命令如下：

  

root@daxueba:~# netwox 81 -i 192.168.59.135

  

输出信息如下：

  

0 0

  

输出信息表示目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)可达，如果目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)不可达，将显示信息如下：

  

No answer.

  

2）可以通过[Wireshark](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136075&idx=2&sn=4d94af5ae548d974a78865e4f348b09c&chksm=bc85b4a48bf23db2f9a217e9f33901ae58650497b3168e282489f7b4c48dc0852a5dbe3f5a29&scene=21#wechat_redirect)进行抓包，验证成功发送了时间戳请求，如图2所示。其中，第6个数据包为ICMP时间戳请求。在[Internet](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133950&idx=3&sn=5d4ada814af5cb06eda826506cdd4dc7&chksm=bc85bd118bf2340750db425c3b156a50e68008c51b409f6b2d2428df0471fc61450d35d5e8b5&scene=21#wechat_redirect) Control Message Protocol部分中，Type值为13，Code值为0，表示该数据包为ICMP时间戳请求。Originate timestamp的值表示数据包发起的起始时间，这里为0秒（午夜0点0秒）；Receive timestamp的值表示接收数据包的时间，这里为0秒；Transmit timestamp的值表示数据包的发送时间，这里为0秒。时间为0秒，是因为从午夜零点开始计算。

![](../Images/61b3ae8bf0a50bcaebadcea1f31b1f3c.png)

图2  ICMP时间戳请求

  

3）选择对应的响应包查看信息，如图3所示。其中，第7个数据包为ICMP时间戳应答。在[Internet](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133950&idx=3&sn=5d4ada814af5cb06eda826506cdd4dc7&chksm=bc85bd118bf2340750db425c3b156a50e68008c51b409f6b2d2428df0471fc61450d35d5e8b5&scene=21#wechat_redirect) Control Message Protocol部分中，Type值为14，Code值为0，表示该数据包为ICMP时间戳应答。Originate timestamp的值表示数据包发起的起始时间，这里为0秒（午夜零点后开始计算）；Receive timestamp的值表示接收数据包的时间，这里为午夜零点后8小时44分24.379秒；Transmit timestamp的值表示数据包的发送时间，这里为31464379秒，时间为午夜零点后8小时44分24.379秒。

![](../Images/a3c75ff542c306527578f8926d52c604.png)

**2、伪造请求超时ICMP数据包**

  

在网络传输IP数据报的过程中，如果IP数据包的TTL值逐渐递减为0时，需要丢弃数据报。这时，[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)需要向源发送方发送ICMP超时报文，表示传输过程中超时了。在超时ICMP数据包报文中，类型值为11，[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)值为0。用户可以通过[netwox](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136054&idx=2&sn=597b1336b8261f8c8e3c1b0dac907be9&chksm=bc85b4d98bf23dcf5d878649edfd3c32906c7ad556982769abcc0124d7b14d6f909fd6127fc2&scene=21#wechat_redirect)工具中编号为83的模块伪造请求超时ICMP数据包。

  

已知[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)A的[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.134，[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)B的[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.135，在[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)C上伪造请求超时ICMP数据包。

  

1）在[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)A上ping[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)B，执行命令如下：

  

root@daxueba:~# ping 192.168.59.135

  

输出信息如下：

  

PING 192.168.59.135 (192.168.59.135) 56(84) bytes of data.

64 bytes from 192.168.59.135: icmp\_seq=1 ttl=64 time=0.447 ms

64 bytes from 192.168.59.135: icmp\_seq=2 ttl=64 time=0.468 ms

64 bytes from 192.168.59.135: icmp\_seq=3 ttl=64 time=0.773 ms

64 bytes from 192.168.59.135: icmp\_seq=4 ttl=64 time=0.307 ms

  

上述输出信息表示[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)B是可达的，并且给出了传输的时间。例如，time=0.447ms，表示时间需要0.447毫秒。

2）在[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)C上伪造请求超时ICMP数据包，设置源[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.135，执行命令如下：

  

root@daxueba:~# netwox 83 -i 192.168.59.135

  

执行命令后没有任何输出信息，但是成功伪造了请求超时ICMP数据包。

  

3）再次在[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)A上ping[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)B，执行命令如下：

输出信息如下：

  

PING 192.168.59.135 (192.168.59.135) 56(84) bytes of data.

64 bytes from 192.168.59.135: icmp\_seq=6 ttl=64 time=0.336 ms

从上述输出信息可以看到，[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)A向[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.135发送了ping请求。部分请求没有收到响应信息，而显示了Time to live exceeded信息，表示时间超时。

**3、伪造目标不可达**

  

目标不可达包是指[路由器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128332&idx=3&sn=4f8d018cff0a3582f18d8148aa992d91&chksm=bc8596e38bf21ff5457749ea5ce4c173811d108f169c96bf028bb2580044317582937601c489&scene=21#wechat_redirect)无法将IP数据包发送给目标地址时，会给发送端[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)返回一个目标不可达的ICMP消息。在目标不可达报文中，类型值为3，[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)值为1。伪造这类数据包需要使用[netwox](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136054&idx=2&sn=597b1336b8261f8c8e3c1b0dac907be9&chksm=bc85b4d98bf23dcf5d878649edfd3c32906c7ad556982769abcc0124d7b14d6f909fd6127fc2&scene=21#wechat_redirect)工具中编号为82的模块。
