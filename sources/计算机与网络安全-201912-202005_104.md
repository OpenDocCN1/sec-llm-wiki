# Forrester将Bitdefender评为EDR领域的杰出表现者

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk4MDE2MA==&mid=2655136342&idx=1&sn=96005bda9abbf5a4e6f6ee93bc708a3c&chksm=bc85b7b98bf23eaf8a9533733e8c2dd24ee66aba3623f5f5eaea5332a957332ce036e4ab77b9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136342&idx=1&sn=96005bda9abbf5a4e6f6ee93bc708a3c&chksm=bc85b7b98bf23eaf8a9533733e8c2dd24ee66aba3623f5f5eaea5332a957332ce036e4ab77b9&scene=27#wechat_redirect)

最新的Forrester Wave for EDR报告已经发布，基于当前的产品，战略和市场占有率，Bitdefender被 Forrester评选为EDR领域的杰出表现者。

  

![](../Images/7e83bc2efaf1937b5e3890a085bba140.png)

  

Forrester在评估中写道：“ Bitdefender专注于预防早期杀伤链的事件，并在后执行阶段提供强大的自动修复功能。” “通过增值分销，MSP，联盟等策略，Bitdefender现在是全球最大的EDR供应商之一。”

  

20多年来，Bitdefender在检测技术领域一直处于世界领先地位。我们的安全技术已集成到全球超过38％的安全产品中，Bitdefender GravityZone Ultra的管理功能在本报告中同样受到好评。

  

就在不久前，Bitdefender还被AV-Comparatives 评选为“2019年度最佳防病毒软件”。AV-Test也评选Bitdefender为“最佳保护”，Bitdefender在EDR领域的领导地位被进一步确认 。
