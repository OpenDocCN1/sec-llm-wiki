如要向目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)发送数据包，首先需要确保目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)是启用的。[ICMP协议](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136313&idx=2&sn=f9d446310b7dcbffa185feef81b06ecd&chksm=bc85b7d68bf23ec0620ed1efece72087437287498b9ffc823e49af8c3d733c2c7493fcda7355&scene=21#wechat_redirect)可以用来探测[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)，以判断[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)是否启用。本文介绍如何进行探测[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)。

  

**1、使用ping命令**

  

ping命令就是借助ICMP[传输协议](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131847&idx=1&sn=c17fae2b0df7789fac36283680f93e7c&chksm=bc8585288bf20c3e5148bd7c5e8107577d5fdcb0912570d6f95df97a1f1e2dde2022ba2c9e6b&scene=21#wechat_redirect)，发出要求回应的Echo(ping)request消息。若远端[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的网络功能没有问题，就会回应Echo(ping)reply信息，因而得知该[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)运作正常。因此用户可以通过ping命令来判断目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)是否启用。

  

判断目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.135是否启用。

  

1）使用ping命令探测目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)，执行命令如下：

  

root@daxueba:~# ping 192.168.59.135

  

输出信息如下：

  

PING 192.168.59.135 (192.168.59.135) 56(84) bytes of data.

64 bytes from 192.168.59.135: icmp\_seq=1 ttl=64 time=0.683 ms

64 bytes from 192.168.59.135: icmp\_seq=2 ttl=64 time=2.10 ms

64 bytes from 192.168.59.135: icmp\_seq=3 ttl=64 time=0.291 ms

64 bytes from 192.168.59.135: icmp\_seq=4 ttl=64 time=0.283 ms

64 bytes from 192.168.59.135: icmp\_seq=5 ttl=64 time=0.339 ms

  

上述输出信息表示，成功向目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)发送了ping请求并得到了响应时间，这表示目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)已启用。如果目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)未启用将显示以下信息：

  

PING 192.168.59.135 (192.168.59.135) 56(84) bytes of data.

From 192.168.59.132 icmp\_seq=1 Destination Host Unreachable

From 192.168.59.132 icmp\_seq=2 Destination Host Unreachable

From 192.168.59.132 icmp\_seq=3 Destination Host Unreachable

From 192.168.59.132 icmp\_seq=4 Destination Host Unreachable

From 192.168.59.132 icmp\_seq=5 Destination Host Unreachable

  

2）通过[Wireshark](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136075&idx=2&sn=4d94af5ae548d974a78865e4f348b09c&chksm=bc85b4a48bf23db2f9a217e9f33901ae58650497b3168e282489f7b4c48dc0852a5dbe3f5a29&scene=21#wechat_redirect)捕获数据包，验证ping命令所产生的ICMP数据包，如图1所示。图中第10～25个数据包都为ICMP数据包。从图中还可以看到ping命令发出的ICMP请求Echo(ping)request与ICMP响应Echo(ping)reply。

**2、构造ICMP数据包**

  

[ICMP协议](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136313&idx=2&sn=f9d446310b7dcbffa185feef81b06ecd&chksm=bc85b7d68bf23ec0620ed1efece72087437287498b9ffc823e49af8c3d733c2c7493fcda7355&scene=21#wechat_redirect)可以用来对目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)发送ICMP数据包，判断目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)是否启用。正常情况下，ICMP请求包报文中的类型值为8，[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)值为0；ICMP响应包报文中的类型值为0，[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)值为0。用户可以使用[netwox](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136054&idx=2&sn=597b1336b8261f8c8e3c1b0dac907be9&chksm=bc85b4d98bf23dcf5d878649edfd3c32906c7ad556982769abcc0124d7b14d6f909fd6127fc2&scene=21#wechat_redirect)工具的编号65的模块构造ICMP数据包，并对目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)进行扫描。

  

在[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.132上，构造ICMP数据包，判断目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.135是否启用。

  

1）构造ICMP扫描，执行命令如下：

  

root@daxueba:~# netwox 65 -i 192.168.59.135

  

输出信息如下：

  

192.168.59.135 : reached

在输出信息中，reached表示目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)可达。这说明目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)是启用状态。如果目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)没有启用，则显示如下信息，其中，unreached表示不可达。

  

192.168.59.139 : unreached

  

2）为了验证以上构造的ICMP数据包，使用[Wireshark](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136075&idx=2&sn=4d94af5ae548d974a78865e4f348b09c&chksm=bc85b4a48bf23db2f9a217e9f33901ae58650497b3168e282489f7b4c48dc0852a5dbe3f5a29&scene=21#wechat_redirect)工具进行捕获数据包，如图2所示。其中，第1个数据包的源[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.132，目标[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.135，Info显示这是一个ICMP请求包。在[Internet](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133950&idx=3&sn=5d4ada814af5cb06eda826506cdd4dc7&chksm=bc85bd118bf2340750db425c3b156a50e68008c51b409f6b2d2428df0471fc61450d35d5e8b5&scene=21#wechat_redirect) Control Message Protocol部分中，Type的值为8，Code的值为0，表示该数据包为正常的ICMP请求包。

3）查看第2个数据包，如图3所示。该数据包的源[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.135，目标[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.132，这是第1个数据包的响应包。在[Internet](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133950&idx=3&sn=5d4ada814af5cb06eda826506cdd4dc7&chksm=bc85bd118bf2340750db425c3b156a50e68008c51b409f6b2d2428df0471fc61450d35d5e8b5&scene=21#wechat_redirect) Control Message Protocol部分中，Type的值为0，Code的值为0，表示该数据包为正常的ICMP响应包。

**3、伪造ICMP数据包**

  

使用前面介绍的方式进行ICMP扫描，容易被目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)发现。为了解决这个问题，可以使用[netwox](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136054&idx=2&sn=597b1336b8261f8c8e3c1b0dac907be9&chksm=bc85b4d98bf23dcf5d878649edfd3c32906c7ad556982769abcc0124d7b14d6f909fd6127fc2&scene=21#wechat_redirect)工具中编号为66的模块伪造ICMP数据包，如设置假的[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)和MAC地址。

  

在[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.132上实施ICMP数据包扫描，判断目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)192.168.59.135是否启用。

  

1）伪造[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.140，MAC地址为00：0c：29：ca：e4：99，执行命令如下：

  

root@daxueba:~#  netwox 66 -i 192.168.59.135 -E 00:0c:29:ca:e4:99 -I 192.168.59.140

  

输出信息如下：

  

192.168.59.135 : reached

  

2）验证伪造的ICMP数据包扫描，捕获数据包进行查看，如图4所示。其中，第4个数据包的源[IP地址](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655136180&idx=2&sn=904af978bb0594c8dcaba143cdaaef2a&chksm=bc85b45b8bf23d4d22582d999cd61d7dca3d2ab79c7b04655201d9bf24a60a29f404ce3c7255&scene=21#wechat_redirect)为192.168.59.140（伪造的），目标地址为192.168.59.135（目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)），该数据包为伪造的ICMP请求包。在Ethernet II部分的Source中可以看到MAC地址为00：0c：29：ca：e4：99，也是伪造的。
