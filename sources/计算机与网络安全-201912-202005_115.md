用户完成扫描配置和扫描目标创建后，就可以创建扫描任务了。然后，对指定的目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)实施扫描。本文介绍管理扫描任务的方法。

  

**1、创建任务**

  

在创建扫描任务之前，先查看现有任务。如果没有对应的任务，就新建一个任务。其中，查看现有扫描任务的语法格式如下：

  

openvas\_task\_list

  

查看现有的扫描任务。执行命令如下：

  

msf5 > openvas\_task\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of tasks

ID     Name    Comment        Status     Progress

\--     ----     ----     -----    -----

  

从输出的信息可以看到，目前还没有创建扫描任务。所以要创建扫描任务。

  

创建扫描任务的语法格式如下：

  

openvas\_task\_create <name> <comment> <config\_id> <target\_id>

  

在以上语法中，参数name表示扫描任务的名称；comment表示扫描任务的描述信息、config\_id表示扫描配置ID；target\_id表示目标ID。

  

创建扫描任务。执行命令如下：

  

msf5 > openvas\_task\_create "Local Scan" "Scan Network" daba56c8-73ec- 11df-a475-002264764cea 66229018-8172-43fa-a789-c3cb0e870d02

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] bd5884ff-c752-4799-84d0-a75a23529dd7

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of tasks

ID      Name      Comment     Status     Progress

\--------     -------      -------      ------      -------

bd5884ff-c752-4799-84d0-a75a23529dd7    Local Scan    Scan Network    New   \-1

  

以上输出信息表示已成功创建了一个扫描任务。在输出的信息中包括5列信息，分别为ID（扫描任务ID）、Name（扫描任务名称）、Comment（扫描任务描述信息）、Status（状态）和Progress（进度）。从显示的结果中可以看到，该扫描任务的状态为New，表示新创建的任务，还没有执行。

  

**2、执行任务**

  

用户创建好扫描任务后，即可执行该任务，对指定的目标实施扫描了。用户对新建的扫描任务可以实施启动、停止、暂停、恢复等操作。下面介绍执行任务的相关操作。

  

**（1）启动扫描任务**

  

如果要实施扫描，必须启动其扫描任务。其中，用于启动扫描任务的语法格式如下：

  

openvas\_task\_start <id>

  

在以上语法中，参数id表示启动的扫描任务的ID。

  

启动ID为bd5884ff-c752-4799-84d0-a75a23529dd7的扫描任务。执行命令如下：

  

msf5 > openvas\_task\_start bd5884ff-c752-4799-84d0-a75a23529dd7

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] <X><authenticate\_response status='200' status\_text='OK'><role>Admin </role><timezone>UTC</timezone><severity>nist</severity></authenticate\_response><start\_task\_response status='202' status\_text='OK, request submitted'> <report\_id>e7d6e1af-adb4-4116-973e-47392eccce9f</report\_id></start\_task\_response></X>

  

以上输出信息表示成功启动了扫描任务。为了确定该扫描任务是否已成功启动，用户可以使用openvas\_task\_list命令查看扫描任务状态，具体如下：

  

msf5 > openvas\_task\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\------        ----     ------    ------    -------

bd5884ff-c752-4799-84d0-a75a23529dd7  Local Scan    Scan Network  Running  67

  

从输出的信息可以看到，当前扫描任务的状态为Running，表示正在运行。而且，还可以看到该扫描任务的进度值为67（67%）。在扫描完成后，状态为Done，具体如下：

  

msf5 > openvas\_task\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

以上输出信息表示扫描已完成。

**（2）停止扫描任务**

  

如果用户不想要执行某进行中的扫描任务了，可以将其停止。停止扫描任务的语法格式如下：

  

openvas\_task\_stop <id>

  

在以上语法中，参数id表示停止的扫描任务的ID。

  

停止扫描任务。执行命令如下：

  

msf5 > openvas\_task\_stop bd5884ff-c752-4799-84d0-a75a23529dd7

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] <X><authenticate\_response status='200' status\_text='OK'><role>Admin </role><timezone>UTC</timezone><severity>nist</severity></authenticate\_response><stop\_task\_response status='202' status\_text='OK, request submitted'/> </X>

  

看到以上输出信息，表示已成功停止扫描任务。此时，用户同样可以使用openvas\_task\_list命令查看其状态，具体如下：

  

msf5 > openvas\_task\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of tasks

\-------       ------      -------    ------      ------

bd5884ff-c752-4799-84d0-a75a23529dd7    Local Scan    Scan Network    Stop Requested   -1

  

从输出的信息可以看到，当前扫描任务的状态为Stop Requested（停止请求），表示已停止扫描。

  

**（3）暂停扫描任务**  

  

暂停扫描任务只是停止一段时间，后期还可以恢复并继续扫描。如果停止扫描，则之前的扫描也将结束。暂停扫描任务的语法格式如下：

  

openvas\_task\_pause <id>

  

在以上语法中，参数id表示暂停的扫描任务的ID。

  

暂停扫描任务。执行命令如下：

  

msf5 > openvas\_task\_pause bd5884ff-c752-4799-84d0-a75a23529dd7

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] <X><authenticate\_response status='200' status\_text='OK'><role>Admin </role><timezone>UTC</timezone><severity>nist</severity></authenticate\_response><omp\_response status='400' status\_text='Bogus command name'/></X>

  

**（4）恢复扫描任务**

  

如果用户需要继续运行暂停的任务，也可以将其恢复。恢复扫描任务的语法格式如下所示：

  

openvas\_task\_resume <id>

  

**（5）恢复或启动扫描任务**  

  

用户还可以使用openvas\_task\_resume\_or\_start命令，恢复或启动扫描任务。其中，该命令的语法格式如下：

  

openvas\_task\_resume\_or\_start <id>

  

在上语法中，参数id表示恢复或启动的扫描任务的ID。

  

**3、删除任务**

  

当用户扫描并分析完成，不再需要某个扫描任务时，可以将其删除。删除扫描任务的语法格式如下：

  

openvas\_task\_delete <id> ok

  

删除ID为bd5884ff-c752-4799-84d0-a75a23529dd7的扫描任务。执行命令如下：

  

msf5 > openvas\_task\_delete bd5884ff-c752-4799-84d0-a75a23529dd7 ok

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] <X><authenticate\_response status='200' status\_text='OK'><role>Admin </role><timezone>UTC</timezone><severity>nist</severity></authenticate\_response><delete\_task\_response status='200' status\_text='OK'/></X>

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of tasks

ID      Name     Comment        Status    Progress

\-------    -------      -------       ------    --------

  

从输出的信息可以看到，当前的扫描任务列表为空。由此可以说明，扫描任务删除成功。
