在创建扫描任务之前，需要先创建扫描目标。本文介绍对目标进行管理，如创建目标、删除目标。

  

**1、创建目标**

  

在创建目标之前，用户可以先查看已有的目标，以确定是否需要创建目标。如果没有或者已有的目标不是用户需要的，则需要创建新的目标。查看已有目标的语法格式如下：

  

openvas\_target\_list

  

查看当前[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的目标列表。执行命令如下：

  

msf5 > openvas\_target\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of targets

ID    Name  Hosts   Max Hosts   In Use   Comment

\--       ----     -----      ---------     ------       -------

  

从输出的信息可以看到，当前[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)中还没有扫描目标。所以，用户需要创建新的目标。

  

创建扫描目标的语法格式如下：

  

openvas\_target\_create <name> <hosts> <comment>

  

在以上语法中，参数name表示扫描目标的名称；hosts表示扫描目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)地址；comment表示描述信息。

  

创建新的扫描目标。执行命令如下：

  

msf5 > openvas\_target\_create "Local Scan" 192.168.29.0/24 "Scan Network"

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] 0ac5b184-a6eb-4df6-8ed2-1441ceddd522

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of targets

ID    Name    Hosts   Max Hosts   In Use    Comment

\--      ----      -----     -----    ------    -------

44b27f22-60bc-4e00-8520-dd1fd1ec4335 Local Scan    192.168.29.0/24      254  0   Scan Network

  

从输出的信息可以看到，成功创建了一个目标。在输出的信息中，共包括6列，分别为ID（目标ID）、Name（目标名称）、Hosts（目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)地址）、Max hosts（最大[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)数）、In Use（是否正在使用）和Comment（注释）。通过分析以上信息，可以看到新创建的目标ID为44b27f22-60bc-4e00-8520-dd1fd1ec4335；名称为Local Scan；[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)地址为192.168.29.0/24等。其中，In Use列的值为1，则表示正在使用；值为0，表示没有使用。此时，用户可以使用openvas\_target\_list命令查看列表，以确定是否成功创建了目标。具体如下：

  

msf5 > openvas\_target\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

从输出的信息可以看到，已成功创建了名为Local Scan的扫描目标。

  

**2、删除目标**

  

当用户不需要某个扫描目标时，可以将其删除。删除目标的语法格式如下：

  

openvas\_target\_delete <target\_id>

  

在以上语法中，参数target\_id表示删除目标的ID。而且，指定的目标需要在没有使用的状态下才可以删除。

  

删除目标刚创建的目标，其ID为44b27f22-60bc-4e00-8520-dd1fd1ec4335。执行命令如下：

  

msf5 > openvas\_target\_delete 44b27f22-60bc-4e00-8520-dd1fd1ec4335

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[\*\] <X><authenticate\_response status='200' status\_text='OK'><role>Admin </role><timezone>UTC</timezone><severity>nist</severity></authenticate\_response><delete\_target\_response status='200' status\_text='OK'/></X>

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS list of targets

ID      Name      Hosts    Max Hosts    In Use    Comment

\--      ----     -----     ---------     ------    -------

  

从输出的结果，可以看到目标已经消失了。由此可以说明，目标已被成功删除。同样，用户可以使用openvas\_target\_list命令查看目标，以确定目标是否已成功删除。
