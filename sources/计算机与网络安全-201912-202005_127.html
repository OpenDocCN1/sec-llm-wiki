OpenVAS是一个开放式漏洞评估系统。它的核心部件是服务器，包括一套网络漏洞测试程序，可以检测远程系统和应用程序中的安全问题。Metasploit提供了OpenVAS插件，可以直接调用OpenVAS，以方便两个工具的衔接。当用户在Metasploit中加载该插件后，就可以使用该插件提供的命令来连接OpenVAS服务器，并以远程方式来实施漏洞扫描。


在Metasploit框架中，使用load命令加载OpenVAS插件后，即可访问OpenVAS服务器。在使用该服务器之前，需要先连接该服务器。本文介绍OpenVAS服务器的使用。


1、连接服务器


如果要使用OpenVAS服务器，则需要先连接到该服务器。其语法格式如下：


openvas_connect username password host port <ssl-confirm>


在以上语法中，参数username表示登录服务器的用户名；password表示登录服务器用户的密码；host指定OpenVAS服务器地址；port指定服务器的端口，这里将连接到OpenVAS的Manager端口，默认是9390；ssl-confirm表示确认是SSL连接，可以设置为OK，也可以不设置。


使用openvas_connect命令连接到OpenVAS服务器。执行命令如下：


msf5 > openvas_connect admin 123456 127.0.0.1 9390 ok

[*] Connecting to OpenVAS instance at 127.0.0.1:9390 with username admin...

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

[+] OpenVAS connection successful


从输出的最后一行信息可以看到，已成功连接到OpenVAS服务。


2、查看服务器信息


在用户成功连接到OpenVAS服务后，可以查看该服务的信息，如版本、配置。下面介绍查看服务器信息的方法。


（1）查看版本


用户可以使用openvas_version命令查看OpenVAS服务器的版本。该命令的语法格式如下：


openvas_version


查看当前服务器的版本信息。执行命令如下：


msf5 > openvas_version

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

[+] Using OMP version 7.0


从输出的信息可以看到，当前服务器的版本为7.0。


（2）查看扫描配置


所有的扫描任务都是基于扫描配置创建的。所以，如果要创建扫描任务，必须先了解现有的扫描配置。其中，OpenVAS服务默认提供了9个扫描配置。而且，用户也可以手动创建。下面使用openvas_config_list命令查看扫描配置。其语法格式如下：


openvas_config_list


查看当前的扫描配置列表。执行命令如下：


msf5 > openvas_config_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

[+] OpenVAS list of configs

ID                              Name

从输出的信息可以看到当前服务器中的扫描配置列表。以上信息显示了两列，分别表示ID（扫描配置ID）和Name（扫描配置名称）。在用户创建扫描任务时，则需要指定扫描配置ID。


3、断开连接


如果用户不再使用OpenVAS服务器，可以使用openvas_disconnect命令断开连接。该命令的语法格式如下：


openvas_disconnect


断开与OpenVAS服务的连接。执行命令如下：


msf5 > openvas_disconnect


执行以上命令后，将不再输出任何信息。
