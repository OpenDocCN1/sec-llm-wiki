OpenVAS是一个开放式[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)评估系统。它的核心部件是[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，包括一套网络[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)测试程序，可以检测[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)系统和应用程序中的安全问题。Metasploit提供了OpenVAS插件，可以直接调用OpenVAS，以方便两个工具的衔接。当用户在Metasploit中加载该插件后，就可以使用该插件提供的命令来连接OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，并以[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)方式来实施[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)扫描。

  

在Metasploit框架中，使用load命令加载OpenVAS插件后，即可访问OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。在使用该[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)之前，需要先连接该[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。本文介绍OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的使用。

  

**1、连接服务器**

  

如果要使用OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，则需要先连接到该[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。其语法格式如下：

  

openvas\_connect username password host port <ssl-confirm>

  

在以上语法中，参数username表示登录[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的用户名；password表示登录[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)用户的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)；host指定OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)地址；port指定[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的端口，这里将连接到OpenVAS的Manager端口，默认是9390；ssl-confirm表示确认是SSL连接，可以设置为OK，也可以不设置。

  

使用openvas\_connect命令连接到OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。执行命令如下：

  

msf5 > openvas\_connect admin 123456 127.0.0.1 9390 ok

\[\*\] Connecting to OpenVAS instance at 127.0.0.1:9390 with username admin...

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] OpenVAS connection successful

  

从输出的最后一行信息可以看到，已成功连接到OpenVAS服务。

  

**2、查看服务器信息**

  

在用户成功连接到OpenVAS服务后，可以查看该服务的信息，如版本、配置。下面介绍查看[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)信息的方法。

  

**（1）查看版本**

  

用户可以使用openvas\_version命令查看OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的版本。该命令的语法格式如下：

  

openvas\_version

  

查看当前[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的版本信息。执行命令如下：

  

msf5 > openvas\_version

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

\[+\] Using OMP version 7.0

  

从输出的信息可以看到，当前[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的版本为7.0。

  

**（2）查看扫描配置**

  

所有的扫描任务都是基于扫描配置创建的。所以，如果要创建扫描任务，必须先了解现有的扫描配置。其中，OpenVAS服务默认提供了9个扫描配置。而且，用户也可以手动创建。下面使用openvas\_config\_list命令查看扫描配置。其语法格式如下：

  

openvas\_config\_list

  

查看当前的扫描配置列表。执行命令如下：

  

msf5 > openvas\_config\_list

/opt/metasploit-framework/embedded/lib/ruby/gems/2.5.0/gems/openvas-omp-0.0.4/lib/openvas-omp.rb:201: warning: Object#timeout is deprecated, use Timeout.timeout instead.

从输出的信息可以看到当前[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)中的扫描配置列表。以上信息显示了两列，分别表示ID（扫描配置ID）和Name（扫描配置名称）。在用户创建扫描任务时，则需要指定扫描配置ID。

  

**3、断开连接**

  

如果用户不再使用OpenVAS[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，可以使用openvas\_disconnect命令断开连接。该命令的语法格式如下：

  

openvas\_disconnect

  

断开与OpenVAS服务的连接。执行命令如下：

  

msf5 > openvas\_disconnect

  

执行以上命令后，将不再输出任何信息。
