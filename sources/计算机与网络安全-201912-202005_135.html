对于一台服务器来说，通常会有许多用户来访问。所以，对用户进行管理也就成为一件非常重要的事了。本文介绍如何对用户进行管理。


1、查看现有用户


如果要对用户进行管理，则需要知道当前服务器中都有哪些用户。所以，这里先查看现有的用户。查看现有用户的命令及语法格式如下：


nessus_user_list


查看Nessus服务中已有的用户。执行命令如下：


msf5 > nessus_user_list

ID    Name    Username    Type    Email    Permissions

------     ----     -----      ----      -----      ------

2       admin      admin        local     128


以上的输出信息共包括6列，分别是ID（用户ID）、Name（名称）、Username（用户名）、Type（类型）、Email（邮件地址）和Permissions（权限）。Nessus服务器中目前有一个用户。名为admin。


2、修改用户密码


如果用户想要修改某用户密码，可以使用nessus_user_passwd命令修改。该命令的语法格式如下：


nessus_user_passwd <User ID> <New Password>


以上语法中的参数<User ID>用来指定用户ID，<New Password>用来指定修改的密码。


修改admin用户的名为daxueba。其中，该用户ID为2。执行命令如下：


msf5 > nessus_user_passwd 2 daxueba

[+] Password of account having user ID 2 changed successfully


看到以上输出信息，表示已成功修改了用户的密码。

3、添加/删除用户


默认情况下，Nessus服务器中只创建一个管理员用户。如果用户不希望所有客户端都以管理员身份登录Nessus服务器，则可以添加一个新的用户。在用户不需要某用户时，还可以将其删除。下面介绍添加/删除用户的方法。


（1）添加用户


当用户需要添加一个Nessus用户时，可以使用nessus_user_add命令来添加。该命令的语法格式如下：


nessus_user_add <username> <password> <permissions> <type>


以上语法中的参数<username>用来指定添加的用户名；<password>用来指定添加用户的密码；<permissions>用来指定该用户的权限，可指定的值为32、64和128；<type>用来指定用户类型，可指定的值为local或LDAP。


添加一个名为test的用户。执行命令如下：


msf5 > nessus_user_add test daxueba 32 local

[+] test created successfully


从输出的信息可以看到，已成功创建了一个test用户。用户还可以通过查看用户列表，来查看创建的用户。具体如下：


msf5 > nessus_user_list

D    Name     Username    Type    Email    Permissions

------      ----     -----      ----       -----     -----

2     admin        admin     local    128

4     test     test     local     32


从输出的信息可以看到刚创建的用户test。由此可以说明，用户添加成功。


（2）删除用户


如果用户要删除某用户，可以使用nessus_user_del命令来实现。该命令的语法格式如下所示：


nessus_user_del <User ID>


以上语法中的参数<User ID>表示指定用户ID。


删除ID为4的用户。执行命令如下：


msf5 > nessus_user_del 4

[+] User account having user ID 4 deleted successfully


从输出的信息可以看到，已成功删除了用户ID为4的用户账户。
