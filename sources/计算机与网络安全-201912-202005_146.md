**1、生成报告**

  

为了方便对扫描结果进行分析，最好的方法就是生成报告。其中，可以生成的报告格式有Nessus、HTML、PDF、CSV和DB这5种。在用户生成报告后，还可以查看其状态。下面介绍生成报告的方法。

  

**（1）生成扫描报告**

  

为了方便用户分析扫描结果，可以使用nessus\_scan\_export命令来导出扫描结果。该命令的语法格式如下：

  

nessus\_scan\_export <scan ID> <export format>

  

以上语法中的参数<scan ID>用来指定扫描ID；<export format>用来指定导出的报告格式。可指定的报告格式可以是Nessus、HTML、PDF、CSV或DB。

  

生成一个Nessus格式的扫描报告。执行命令如下：

  

msf5 > nessus\_scan\_export 12 Nessus

\[+\] The export file ID for scan ID 12 is 826068083 #导出文件ID

\*\] Checking export status...  #检测导出状态

\[\*\] Export status: loading  #正在加载导出状态

\[\*\] Export status: ready  #准备就绪

\[+\] The status of scan ID 12 export is ready

  

看到以上输出信息，表示已成功生成了扫描报告。其中，该扫描报告文件的ID为826068083。而且，该报告的状态为ready，表示导出成功。

  

**（2）查看导出任务的状态**

  

为了确定导出的扫描报告文件没有问题，可以使用nessus\_scan\_export\_status命令查看其状态。该命令的语法格式如下：

  

nessus\_scan\_export\_status <scan ID> <file ID>

  

以上语法中的参数<scan ID>用来指定扫描ID；<file ID>用来指定导出报告文件的ID。

  

查看导出任务的状态。执行命令如下：

  

msf5 > nessus\_scan\_export\_status 12 826068083

\[\*\] Export status: ready

\[\*\] The status of scan ID 12 export is ready

  

从输出的信息可以看到，导出任务的状态为ready。

  

**2、分析报告**

  

用户将扫描结果生成报告后，便可以分析该报告了。通过分析报告文件，即可获得存在[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)的[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)列表、[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)列表及指定[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的详细信息。下面介绍分析报告的方法。

**（2）获取漏洞列表**

nessus\_report\_vulns <scan ID>

  

以上语法中的参数<scan ID>用来指定扫描ID。

  

从扫描报告中获取[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)列表。执行命令如下：

  

msf5 > nessus\_report\_vulns 12

\---------    -----------       ----------      ----------

11002   DNS Server Detection   DNS      1

50686   IP Forwarding Enabled   Firewalls   1

  

在以上输出信息中共显示了4列，分别是Plugin ID（插件ID）、Plugin Name（插件名）、Plugin Family（插件家族名）和Vulnerability Count（[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)数）。通过对输出信息进行分析，可知目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)中存在3个[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)。

  

**（3）获取指定主机的详细信息**

  

如果分析扫描报告时发现有多台[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)，用户可以获取特定[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)详细信息，使用nessus\_report\_host\_details命令获取指定[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的详细信息。该命令的语法格式如下：

以上语法格式中的参数<scan ID>是指扫描ID，<host ID>用来指定[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)ID。

  

**3、导入报告**

  

用户还可以将生成的扫描报告导入Metasploit框架中。导入扫描报告，便于Metasploit直接使用这些信息。其中，用于导入报告的命令及语法格式如下：

  

nessus\_db\_import <scan ID>

  

以上语法中的参数<scan ID>用来指定扫描ID。

  

将Nessus扫描结果导入Metasploit的[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)中。执行命令如下：

  

msf5 > nessus\_db\_import 12

\[\*\] Exporting scan ID 12 is Nessus format...  #导出的扫描ID文件格式

\[+\] The export file ID for scan ID 12 is 1862207051 #导出文件的ID

\[\*\] Checking export status...  #检查导出状态

\[\*\] Export status: loading  #导出状态

\[\*\] Export status: ready

\[\*\] The status of scan ID 12 export is ready

\[\*\] Importing scan results to the database...  #导入扫描结果到数据库

\[\*\] Importing data of 192.168.29.2  #导入的数据

\[+\] Done   #完成

  

看到以上输出信息，表示已成功导入扫描结果到Metasploit的[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)。
