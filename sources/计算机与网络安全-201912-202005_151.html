在用户确定了当前Nessus服务器中的策略模板后，则可以使用其策略模板来创建扫描任务了。然后，运行扫描任务。


1、查看任务


如果要管理扫描任务，先需要知道当前服务器中是否运行了扫描任务。如果没有任何扫描任务，则可以创建扫描任务。如果存在扫描任务的话，可以查看该扫描任务的详细信息。下面介绍查看扫描任务的方法。


（1）列出所有扫描任务


使用nessus_scan_list命令可以列出当前Nessus服务器中的所有扫描任务。该命令的语法格式如下：


nessus_scan_list -S searchterm


以上语法中的-S选项，可以用来搜索指定的扫描任务。


列出所有扫描任务。执行命令如下：


msf5 > nessus_scan_list

Scan ID   Name   Owner   Started   Status    Folder

----    ----      -----     -----       ------       ------

6   Local Scan    admin    completed    3


从输出的信息可以看到，当前Nessus服务器中有一个扫描任务。输出的信息共显示了六列，分别是Scan ID（扫描ID）、Name（扫描名称）、Owner（所有者）、Started（启动时间）、Status（状态）和Folder（扫描配置目录ID）。通过对该扫描任务的分析，可知该扫描任务已扫描完成。其中，该扫描任务的ID为6；名称为Local Scan；所有者为admin；扫描配置目录ID为3。


（2）查看指定任务的详细信息


通过查看当前Nessus服务器中的扫描任务可以看到，有一个扫描任务。如果想要查看该扫描任务的详细信息，可以使用nessus_scan_details命令来实现。该命令的语法格式如下：


scan_details <scan ID> <category> -S searchterm


以上语法中的参数scan ID表示扫描ID；category表示扫描种类。其中，可指定的扫描种类值有Info（详细信息）、hosts（主机）、vulnerabilities（漏洞）和history（历史）。-S选项用来搜索指定的扫描任务详细信息。


查看扫描ID为6的扫描任务的详细信息。执行命令如下：


msf5 > nessus_scan_details 6 info

Status  Policy  Scan Name  Scan Targets  Scan Start Time  Scan End Time

------     ------    ------    -------    -------    ------

completed  Advanced Scan  Local Scan  192.168.29.0/24  1553684023 1553684401


输出信息包括6列，分别是Status（状态）、Policy（使用的策略模板）、Scan Name（扫描名称）、Scan Targets（扫描目标）、Scan Start Time（扫描起始时间）和Scan End Time（扫描结束时间）。通过对以上信息进行分析，可知该扫描任务使用的策略模板为Advanced Scan；扫描的目标为192.168.29.0/24；扫描名称为Local Scan等。


查看扫描任务的漏洞详细信息。执行命令如下：


msf5 > nessus_scan_details 6 vulnerabilities

Plugin ID    Plugin Name   Plugin Family   Count

---------      ---------     --------           -----

11002     DNS Server Detection   DNS  1

19506     Nessus Scan Information    Settings  1

50686     IP Forwarding Enabled   Firewalls  1


以上输出信息共显示了4列信息，分别是Plugin ID（插件ID）、Plugin Name（插件名）、Plugin Family（插件族）和Count（个数）。从显示的结果中可以看到，当前扫描任务中共扫描出3个漏洞，使用的插件为DNS Server Detection、Nessus Scan Information和IP Forwarding Enabled。


2、创建扫描任务


如果当前还没有扫描任务，或者要执行一个新的扫描任务，可以手动进行创建。用户可以使用3种方式来创建扫描任务。下面分别介绍具体的创建方法。


（1）创建新任务


创建新任务最简单的方法，就是使用nessus_scan_new命令。该命令的语法格式如下：


nessus_scan_new <UUID of Policy> <Scan name> <Description> <Targets>


以上语法中的参数<UUID of Policy>用来指定自定义策略模板的UUID；<Scan name>用来指定扫描名称；<Description>用来指定扫描任务的描述信息；Targets用来指定扫描目标。


创建一个新的扫描任务。执行命令如下：


msf5 > nessus_scan_new ad629e16-03b6-8c1d-cef6-ef8c9dd3c658d24bd260ef5f 9e66 "Network Scan" "Local Network Scan" 192.168.29.0/24

[*] Creating scan from policy number ad629e16-03b6-8c1d-cef6-ef8c9dd3c658d 24bd260ef5f9e66, called Network Scan - Local Network Scan and scanning 192.168.29.0/24

[*] New scan added   #添加新的扫描任务

[*] Use nessus_scan_launch 12 to launch the scan  #启动该扫描任务

Scan ID   Scanner ID  Policy ID   Targets  Owner

-------     -------       -------      -------       -----

12      1    11    192.168.29.0/24    admin


从以上输出的信息可以看到，创建了一个名称为Network Scan的扫描任务。其中，该扫描任务的ID为12，扫描者ID为1，策略ID为11，扫描目标为192.168.29.0/24。如果要启动该扫描任务，执行nessus_scan_launch 12命令即可。


（2）基于db_hosts表创建扫描任务


用户还可以使用nessus_db_scan命令，它基于db_hosts表中所有IP地址来创建扫描任务。该命令及语法格式如下：


nessus_db_scan <policy ID> <scan name> <scan description>


以上语法中的参数<policy ID>用来指定策略ID；<Scan name>用来指定扫描名称；<scan description>用来指定扫描描述信息。


（3）基于指定工作区的db_host表创建扫描任务


用户还可以使用nessus_db_scan_workspace命令，基于指定工作区的db_hosts表中所有IP地址来创建扫描任务。其中，该命令的语法格式如下：


nessus_db_scan_workspace <policy ID> <scan name> <scan description> <workspace>


以上语法中的参数<policy ID>用来指定策略ID；<scan name>用来指定扫描名称；<scan description>用来指定扫描描述信息；<workspace>用来指定使用的工作区。

3、运行扫描任务


当用户创建好扫描任务后，即可运行该扫描任务，以发现目标主机中的漏洞信息。下面介绍启动扫描任务的方法。


（1）启动任务


在创建好一个新的扫描任务后，用户必须手动启动才可以开始实施扫描。用于启动扫描任务的命令及其语法格式如下：


nessus_scan_launch <scan ID>


以上语法中的参数<scan ID>是用来指定要启动扫描任务的ID。


启动扫描ID为12的任务。执行命令如下：


msf5 > nessus_scan_launch 12

[+] Scan ID 12 successfully launched. The Scan UUID is fcf09458-df9d- c108-2306-594158ad7f212bfe86405807dd3e


从输出的信息可以看到，扫描ID为12的任务已成功启动。此时，用户可以查看其扫描状态，以确定该扫描任务确实启动成功。具体如下：


msf5 > nessus_scan_list

Scan ID   Name   Owner   Started   Status   Folder

-----        ----        -----    -------      ------      ------

6   Local Scan      admin        completed     3

12    Network Scan    admin      running    3


从输出的信息可以看到，扫描ID为12的扫描任务状态为running。由此可以说明，它已成功启动了该扫描任务。


（2）暂停任务


在用户同时启动多个扫描任务时候，可能会发现速度非常慢。此时，用户可以先暂停某个任务，选择只运行一个。或者，在想要执行某个任务时，也可以将其暂停。下面介绍暂停扫描任务的方法。


1）暂停任务


暂停任务仅用来暂停一个扫描任务。用于暂停任务的命令及语法格式如下：


nessus_scan_pause <scan id>


以上语法中的参数<scan id>是用来指定将要暂停的扫描任务ID。


暂停扫描ID为12的扫描任务。执行命令如下：


msf5 > nessus_scan_pause 12

[*] 12 has been paused


从输出的信息可以看到，扫描任务已暂停。此时，用户也可以查看该扫描任务的状态。具体如下：


msf5 > nessus_scan_list

Scan ID    Name    Owner    Started    Status   Folder

-----      ----      -----     ----      ------      ------

6   Local Scan   admin   completed   3

12   Network Scan   admin  paused   3


从输出的信息可以看到，扫描ID为12的扫描任务，当前状态为paused，则表示已成功暂停该扫描任务。


2）暂停所有任务


如果用户同时运行了多个扫描任务，想要都暂停的话，则需要使用nessus_scan_pause_all命令快速将其暂停。该命令的语法格式如下：


nessus_scan_pause_all


暂停所有扫描任务。执行命令如下：


msf5 > nessus_scan_pause_all

[*] All scans have been paused


从输出的信息可以看到，所有扫描任务都已暂停。


（3）停止任务


停止扫描任务后，表示该扫描任务将不可以再运行。如果用户只是暂停任务，还可以恢复该任务继续运行。下面分别介绍停止任务的方法。


1）停止任务


停止任务表示停止单个扫描任务。用于停止任务的命令及语法格式如下所示：


nessus_scan_stop <scan id>


以上语法中的参数<scan id>用来指定将停止任务的扫描ID。


停止扫描ID为12的扫描任务。执行命令如下：


msf5 > nessus_scan_stop 12

[*] 12 has been stopped


从输出的信息可以看到，扫描ID为12的扫描任务已被停止。查看其状态，以确定是否成功停止。具体如下：


msf5 > nessus_scan_list

Scan ID    Name    Owner    Started    Status    Folder

-----     ----      -----      -------      ------        ------

6   Local Scan     admin    completed   3

12    Network Scan    admin     canceled    3


2）停止所有扫描任务


停止所有扫描任务将会停止当前运行的所有扫描任务。如果要停止所有运行的扫描任务，则可以使用nessus_scan_stop_all命令快速停止所有扫描任务。该命令的语法格式如下：


msf5 > nessus_scan_stop_all

[*] All scans have been stopped


从输出的信息可以看到，所有的扫描任务都被停止。此时，查看扫描任务列表，将显示如下信息：


msf5 > nessus_scan_list

Scan ID   Name   Owner  Started  Status   Folder

-----     ----    -----     -------      ------      ------

6   Local Scan     admin   stopping   3

12    Network Scan     admin  stopping   3


从显示的结果可以看到，当前运行的两个扫描任务都被停止了（stopping）。


（4）恢复执行任务


如果用户将某个任务暂停，还可以恢复其扫描任务。下面介绍恢复暂停的扫描任务。


1）恢复暂停的任务


恢复暂停的任务只能恢复指定的扫描任务，即只能恢复一个暂停的扫描任务。用于恢复暂停任务的命令及语法格式如下：


nessus_scan_resume <scan id>


以上语法中的参数<scan id>用来指定将要恢复暂停的任务ID。


恢复扫描ID为12的扫描任务。执行命令如下：


msf5 > nessus_scan_resume 12

[*] 12 has been resumed


从输出的信息可以看到，扫描ID为12的扫描任务已恢复正常，即正在实施扫描。此时，查看其扫描任务列表。结果如下：


msf5 > nessus_scan_list

Scan ID    Name   Owner    Started    Status   Folder

-------      ----       -----     -------    ------    ------

6   Local Scan   admin  completed   3

12   Network Scan    admin   running  3


从输出的信息可以看到，扫描ID为12的扫描任务已恢复正常，状态为running（正在运行）。


2）恢复所有暂停的任务


如果用户想要将暂停的所有任务恢复执行，则可以使用nessus_scan_resume_all命令快速恢复所有暂停的任务。该命令语法格式如下：


msf5 > nessus_scan_resume_all

[*] All scans have been resumed


从输出的信息可以看到，所有扫描任务已被恢复。
