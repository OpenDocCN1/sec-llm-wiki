在Metasploit框架中，使用load命令加载Nessus插件后，即可访问Nessus服务器。在使用该服务器之前，需要先连接该服务器。本文介绍Nessus服务器的使用。


1、连接服务器


如果要使用Nessus服务器，则需要先连接到该服务器。用户可以使用常规模式和快速连接两种方式来连接Nessus服务器。下面分别介绍具体的连接方法。


（1）常规模式


常规模式是最常见的登录服务器的方式，通过用户名和密码，并指定服务器地址和端口来登录。其中，用于常规模式连接服务器的语法格式如下：


nessus_connect username:password@服务器IP 地址:8834


在以上语法中，参数username表示登录Nessus服务器的用户名；password表示登录Nessus服务器用户的密码；“@服务器IP地址：8834”表示指定Nessus服务器的IP地址，8834是Nessus服务默认监听的端口。


使用常规模式连接Nessus服务器。执行命令如下：


msf5 > nessus_connect admin:123456@192.168.29.136:8834

[*] Connecting to https://192.168.29.136:8834/ as admin

[*] User admin authenticated successfully.

msf5 >


从输出的信息可以看到，成功使用用户admin连接到了Nessus服务器。


（2）快速连接


快速连接的方式就是用户无须再输入用户名、密码及服务器地址等认证信息，即可快速连接到Nessus服务器。这种方式是通过常规模式连接到Nessus服务器后，使用nessus_save命令保存其认证信息。这样，下次直接执行nessus_connect命令就可以连接到服务器了。用户保存认证信息的命令及语法格式如下：


nessus_save


执行以上命令后，保存当前的登录信息到nessus.yaml文件。用户下次连接Nessus服务器时，直接执行nessus_connect命令即可。


使用快速连接方式连接Nessus服务器。


1）保存当前的登录认证信息。执行命令如下：


msf5 > nessus_save

[+] /root/.msf4/nessus.yaml created.


从输出的信息可以看到，成功地将当前的登录信息保存到/root/msf4/nessus.yaml文件中。这样，用户就可以使用快速连接方式来连接Nessus服务器了。


2）重新启动Metasploit框架，并加装Nessus插件。然后，执行nessus_connect命令快速连接到Nessus服务器。执行命令如下：


msf5 > nessus_connect

[*] Connecting to https://192.168.29.136:8834/ as admin

[*] User admin authenticated successfully.


看到以上输出信息，表示使用保存的认证快速连接到了Nessus服务器。


2、退出登录


如果用户不需要操作Nessus服务器，可以使用nessus_logut命令退出登录。该命令的语法格式如下：


nessus_logout


退出当前登录的用户。执行命令如下：


msf5 > nessus_logout

[+] User account logged out successfully


看到以上输出信息，则表示成功退出了Nessus服务器。

3、查看服务器状态


用户成功连接到Nessus服务器后，即可查看该服务器的相关状态信息。下面介绍查看服务器状态的相关命令及语法格式。


（1）显示Nessus服务器信息


用户可以使用nessus_server_properties命令查看Nessus服务器信息。该信息包括Nessus服务器的版本、类型、插件集和服务器UUID。用于查看Nessus服务器信息的语法格式如下：


nessus_server_properties


查看当前所连接的Nessus服务器信息。执行命令如下：


msf5 > nessus_server_properties

Feed     Type    Nessus Version    Nessus Web Version    Plugin Set    Server UUID

----     ----    --------------    ------------------    -----------    ----------

Nessus Home    6.12.0     6.12.0


从以上输出信息可以看到，当前的Nessus服务器类型为Nessus Home，使用的是家庭版。其版本为6.12.0。


（2）检查服务器状态


用户还可以查看服务器的状态，以确定该服务是否正在运行。用于检测服务器状态的命令及语法格式如下：


nessus_server_status


检测当前Nessus服务器状态。执行命令如下：


msf5 > nessus_server_status

Status      Progress

------      --------

ready


从输出的信息可以看到，当前服务器的状态为ready。


（3）检查用户是否为管理员


如果用户忘记当前登录Nessus服务的用户是否是管理员，可以使用nessus_admin命令检查。其语法格式如下：


nessus_admin


检查当前用户是否为管理员。执行命令如下：


msf5 > nessus_admin

[+] Your Nessus user is an admin


从输出的信息可以看到，当前的Nessus用户是一个admin，表示是管理员。


（4）列出服务器所有配置目录


当用户连接到Nessus服务器后，还可以查看该服务器中的所有配置目录。用于列出服务器所有配置目录的命令及语法格式如下：


nessus_folder_list


列出服务器所有配置目录。执行命令如下：


msf5 > nessus_folder_list

ID          Name           Type

--         ----           ----

2           Trash         trash

3           My Scans      main


从输出的信息可以看到，显示了3列信息，分别是ID（目录ID）、Name（目录名称）和Type（目录类型）。从显示的结果可以看到，当前Nessus服务中有两个配置目录，分别是Trash和My Scans。其中，Trash是一个回收站目录；My Scans是一个主配置目录。


（5）列出所有扫描器


用户还可以查看Nessus服务器中的所有扫描器。用户查看扫描器的命令及语法格式如下：


nessus_scanner_list
