**1、连接服务器**

  

如果要使用Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，则需要先连接到该[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。用户可以使用常规模式和快速连接两种方式来连接Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。下面分别介绍具体的连接方法。

  

**（1）常规模式**  

  

常规模式是最常见的登录[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的方式，通过用户名和[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)，并指定[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)地址和端口来登录。其中，用于常规模式连接[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的语法格式如下：

  

nessus\_connect username:password@服务器IP 地址:8834

  

在以上语法中，参数username表示登录Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的用户名；password表示登录Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)用户的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)；“@[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)IP地址：8834”表示指定Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的IP地址，8834是Nessus服务默认监听的端口。

  

使用常规模式连接Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。执行命令如下：

  

msf5 > nessus\_connect admin:123456@192.168.29.136:8834

\[\*\] Connecting to https://192.168.29.136:8834/ as admin

\[\*\] User admin authenticated successfully.

msf5 >

  

从输出的信息可以看到，成功使用用户admin连接到了Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。

  

**（2）快速连接**  

  

快速连接的方式就是用户无须再输入用户名、[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)及[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)地址等认证信息，即可快速连接到Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。这种方式是通过常规模式连接到Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)后，使用nessus\_save命令保存其认证信息。这样，下次直接执行nessus\_connect命令就可以连接到[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)了。用户保存认证信息的命令及语法格式如下：

  

nessus\_save

  

执行以上命令后，保存当前的登录信息到nessus.yaml文件。用户下次连接Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)时，直接执行nessus\_connect命令即可。

  

使用快速连接方式连接Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。

  

1）保存当前的登录认证信息。执行命令如下：

  

msf5 > nessus\_save

\[+\] /root/.msf4/nessus.yaml created.

  

从输出的信息可以看到，成功地将当前的登录信息保存到/root/msf4/nessus.yaml文件中。这样，用户就可以使用快速连接方式来连接Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)了。

  

2）重新启动Metasploit框架，并加装Nessus插件。然后，执行nessus\_connect命令快速连接到Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。执行命令如下：

  

msf5 > nessus\_connect

\[\*\] Connecting to https://192.168.29.136:8834/ as admin

\[\*\] User admin authenticated successfully.

  

看到以上输出信息，表示使用保存的认证快速连接到了Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。

  

**2、退出登录**

  

如果用户不需要操作Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，可以使用nessus\_logut命令退出登录。该命令的语法格式如下：

  

nessus\_logout

  

退出当前登录的用户。执行命令如下：

  

msf5 > nessus\_logout

\[+\] User account logged out successfully

  

看到以上输出信息，则表示成功退出了Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。

**3、查看服务器状态**

  

用户成功连接到Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)后，即可查看该[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的相关状态信息。下面介绍查看[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)状态的相关命令及语法格式。

  

**（1）显示Nessus服务器信息**

  

用户可以使用nessus\_server\_properties命令查看Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)信息。该信息包括Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的版本、类型、插件集和[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)UUID。用于查看Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)信息的语法格式如下：

  

nessus\_server\_properties

  

查看当前所连接的Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)信息。执行命令如下：

  

msf5 > nessus\_server\_properties

Feed     Type    Nessus Version    Nessus Web Version    Plugin Set    Server UUID

Nessus Home    6.12.0     6.12.0

  

从以上输出信息可以看到，当前的Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)类型为Nessus Home，使用的是家庭版。其版本为6.12.0。

  

**（2）检查服务器状态**

  

用户还可以查看[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的状态，以确定该服务是否正在运行。用于检测[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)状态的命令及语法格式如下：

  

nessus\_server\_status

  

检测当前Nessus[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)状态。执行命令如下：

  

msf5 > nessus\_server\_status

Status      Progress

\------      --------

ready

  

从输出的信息可以看到，当前[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)的状态为ready。

  

**（3）检查用户是否为管理员**

  

如果用户忘记当前登录Nessus服务的用户是否是管理员，可以使用nessus\_admin命令检查。其语法格式如下：

  

nessus\_admin

  

检查当前用户是否为管理员。执行命令如下：

  

msf5 > nessus\_admin

\[+\] Your Nessus user is an admin

  

从输出的信息可以看到，当前的Nessus用户是一个admin，表示是管理员。
