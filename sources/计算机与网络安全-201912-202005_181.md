sessions命令可以列出、进入交互或杀死大量的会话。该会话可以是Shells、Meterpreter会话和VNC等。session命令的语法格式如下：

  

sessions \[选项\]

  

或

  

sessions \[id\]

  

session命令支持的选项及含义如下：

  

\-C<opt>：运行一个Meterpreter命令。

  

\-K：保持所有终端会话。

  

\-c<opt>：运行一个命令。

  

\-h：显示帮助信息。

  

\-i<opt>：进入指定会话ID的交互模式。

  

\-k<opt>：结束指定会话的ID。

  

\-l：列出所有活跃会话。

  

\-q：安静模式。

  

\-r：重置会话的缓冲。

  

\-s<opt>：运行一个脚本。

  

\-t<opt>：设置一个响应超时值，默认是15。

  

\-u<opt>：升级一个[Shell](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127748&idx=3&sn=c1a3d178c1155c7613708f4f6384eb64&chksm=bc85952b8bf21c3d2d44139d072702367155b51c86221ea83618a580515205fc6dd139e1496c&scene=21#wechat_redirect)到Meterpreter会话。

  

\-v：列出会话详细信息。

  

\-x：显示扩展信息。

  

查看活跃的会话。执行命令如下：

  

msf5 exploit(3proxy) > sessions -l

Active sessions

\===============

Id      Description       Tunnel

\--      -----------      ------

1       Command shell     192.168.1.101:33191 -> 192.168.1.104:4444

  

从输出的信息中可以看到，有一个活跃的会话。如果要进入该会话交互模式，可以使用-i选项指定会话ID，具体如下：

  

msf5 exploit(3proxy) > sessions -i 1

\[\*\] Starting interaction with 1...

meterpreter >

  

从显示的信息中可以看到，命令行终端提示符变为meterpreter>。由此说明，已成功进入到会话的交互模式。
