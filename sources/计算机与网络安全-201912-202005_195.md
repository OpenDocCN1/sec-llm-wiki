在MSF终端提供了一个connect命令，通过指定一个IP地址和端口号，可以[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)连接到目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)。connect命令的语法格式如下：

  

connect \[选项\]

  

connect命令支持的选项及含义如下：

  

\-C：对于EOL序列尝试使用CRLF。

\-p<opt>：指定源端口。

\-s<opt>：指定源地址。

\-c<opt>：指定使用的Comm端口。

\-h：显示帮助信息。

\-i<opt>：发送一个文件的内容。

\-p<opt>：列出使用的代理。

\-s：使用SSL连接。

\-u：切换到一个UDP套接字。

\-w<opt>：指定连接超时值。

\-z：仅尝试连接。

  

[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)连接FTP[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)。执行命令如下：

  

msf5 > connect 192.168.195.131 21

\[\*\] Connected to 192.168.195.131:21

220 (vsFTPd 2.3.4)

  

从输出的信息中可以看到，已连接到目标[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的21号端口。接下来，用户使用USER和PASS命令即可登录目标[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134138&idx=2&sn=2da408a8f63d0e17aae10f56ee8bc3e3&chksm=bc85bc558bf23543bf9dd7d0df24588ada90c01b3b4f8d8d1d4404168ebb5a78ec3acaa6450e&scene=21#wechat_redirect)，具体如下：

  

USER ftp

331 Please specify the password.

PASS admin

230 Login successful.

  

从输出的信息中可以看到已经登录成功。如果用户不清楚能执行哪些操作，可以使用help命令查看帮助信息。

  

help

214-The following commands are recognized.

ABOR ACCT ALLO APPE CDUP CWD  DELE EPRT EPSV FEAT HELP LIST MDTM MKD

MODE NLST NOOP OPTS PASS PASV PORT PWD  QUIT REIN REST RETR RMD  RNFR

RNTO SITE SIZE SMNT STAT STOR STOU STRU SYST TYPE USER XCUP XCWD XMKD

XPWD XRMD

214 Help OK.

  

从输出的信息中可以看到支持的所有命令。此时可以根据自己的需要进行相应的操作。
