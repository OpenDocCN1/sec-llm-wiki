在Metasploit中，提供了一些用于扫描的通用辅助模块，如端口扫描、服务版本及服务弱口令扫描等。这些模块的使用与操作系统无关，下面介绍一些通用的漏洞利用模块。


1、端口扫描


在Metasploit中不仅能够使用第三方扫描器，而且在其辅助模块中也包含了几款内建的端口扫描器。这些内建的扫描器在很多方面与Metasploit框架进行了融合，在辅助进行渗透攻击方面更具有优势。下面介绍使用Metasploit中内建的扫描器模块对目标主机进行端口扫描。


对目标主机进行端口扫描。具体操作步骤如下：


1）搜索Metasploit框架提供的端口扫描工具。执行命令如下：


msf5 > search portscan

从输出的信息中可以看到，共搜索到8个端口扫描模块，用户可以实施TCP ACK防火墙扫描、FTP Bounce端口扫描、TCP SYN端口扫描及TCP端口扫描等。


2）例如，这里实施TCP SYN端口扫描，选择scanner/portscan/syn扫描模块，并查看需要的配置选项参数，具体如下：


msf5 > use auxiliary/scanner/portscan/syn

msf5 auxiliary(syn) > show options

THREADS  1  yes  The number of concurrent threads

从输出的信息中可以看到，RHOSTS选项参数还没有配置。另外，为了加快扫描速度，也可以重新配置THREADS参数。


3）配置选项参数，执行命令如下：


msf5 auxiliary(syn) > set RHOSTS 192.168.1.105

RHOSTS => 192.168.1.105

msf5 auxiliary(syn) > set THREADS 50

THREADS => 50


配置完以上选项参数后，即可开始实施扫描。


4）对指定的目标进行端口扫描。执行命令如下：


msf5 auxiliary(syn) > run

[*]  TCP OPEN 192.168.1.105:21

[*]  TCP OPEN 192.168.1.105:22

[*]  TCP OPEN 192.168.1.105:111

[*]  TCP OPEN 192.168.1.105:3306

[*]  TCP OPEN 192.168.1.105:8834

[*] Scanned 1 of 1 hosts (100% complete)

[*] Auxiliary module execution completed


从输出的信息中可以看到，目标主机上开放的端口有21、22、111、3306和8834。


2、服务版本扫描


为了加快渗透测试的速度，扫描目标主机系统中服务的版本也是非常有必要的。如果用户从第三方或官方网站获取到某版本的服务存在漏洞，这时候可直接使用对应的模块实施渗透攻击。下面介绍在Metasploit下，实施服务版本扫描的方法。


在Metasploit中提供了用于扫描服务版本的模块，如ftp_version、ssh_version、http_version等。下面以扫描FTP服务版本为例，演示具体的操作步骤。


1）查找模块的完整路径。执行命令如下：


msf5 > search ftp_version

Matching Modules

================

auxiliary/scanner/ftp/ftp_version  normal  Yes  FTP Version Scanner


2）使用ftp_version模块并查看该模块的选项参数，执行命令如下：


msf5 > use auxiliary/scanner/ftp/ftp_version

msf5 auxiliary(ftp_version) > show options

Module options (auxiliary/scanner/ftp/ftp_version):

Name      Current Setting      Required    Description

-----      --------------      ---------    -----------------------

THREADS   1  yes  The number of concurrent threads


3）配置RHOSTS参数。执行命令如下：


msf5 auxiliary(ftp_version) > set RHOSTS 192.168.1.101

RHOSTS => 192.168.1.101


4）实施扫描。执行命令如下：


msf5 auxiliary(ftp_version) > run

[*] 192.168.1.101:21 FTP Banner: '220 (vsFTPd 2.3.4)\x0d\x0a'

[*] Scanned 1 of 1 hosts (100% complete)

[*] Auxiliary module execution completed


从输出的信息中可以看到，目标主机运行的FTP服务版本为2.3.4。


其他服务器版本信息的扫描方法和扫描FTP服务版本的方法相同。并且，其他服务版本扫描模块与该服务的位置相同。当用户对其他服务版本实施扫描时，将ftp修改为想要扫描的服务名称即可。

3、扫描服务弱口令


大部分服务安装完成后，都有一个默认的用户名和密码。如果用户忘记修改默认密码，或者设置了弱口令的话，攻击者即可利用服务的弱口令远程登录其服务，进而对目标主机进行控制。在Metasploit中提供了一些用于扫描服务弱口令的模块。下面介绍扫描服务弱口令的方法。


以目标主机（Metasploitable2）中的PostgreSQL数据库服务为例，实施弱口令扫描。具体操作步骤如下：


1）搜索所有有效的PostgreSQL模块。执行命令如下：


msf5 > search postgresql
