成功执行以上命令后，表示已经成功创建了[Android](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128809&idx=3&sn=8657c5ae0c9af7477154b330b6f8323b&chksm=bc8591068bf21810baf64a7af0bd76aece63edb722c60363593a471c3ac21ba827e32e896a5c&scene=21#wechat_redirect)格式（APK）文件的有效载荷。但是，现在[Android](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128809&idx=3&sn=8657c5ae0c9af7477154b330b6f8323b&chksm=bc8591068bf21810baf64a7af0bd76aece63edb722c60363593a471c3ac21ba827e32e896a5c&scene=21#wechat_redirect)移动设备一般不允许安装没有相应签名证书的应用程序，只安装带有签署文件的APK。所以，[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)者需要使用3个工具（keytool、jarsigner和zipalign）进行手动签名，然后才可以在[Android](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128809&idx=3&sn=8657c5ae0c9af7477154b330b6f8323b&chksm=bc8591068bf21810baf64a7af0bd76aece63edb722c60363593a471c3ac21ba827e32e896a5c&scene=21#wechat_redirect)系统上安装应用程序。下面介绍手动签名的方法。

  

对创建的有效载荷文件android.apk文件进行手动签名。在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132692&idx=3&sn=9a6004474fc0fb18778adad6388d0f64&chksm=bc8581fb8bf208ed7ab4c414996ee7c2c487318106ab00e581ff5fbd1dc04b9fb69fa37a79da&scene=21#wechat_redirect)中，已经自带了keytool和jarsigner工具。虽然没有zipalign工具，但是提供了安装包，用户手动安装即可使用。下面这些操作将在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128965&idx=3&sn=b8b9a62359603244f96d47b39c0a094e&chksm=bc85906a8bf2197c862d73e7aa0b33d06465d5570713fd18493312f7c38da5c6b4b21f9895cf&scene=21#wechat_redirect)中进行。具体操作步骤如下：

  

1）安装zipalign工具。执行命令如下：

  

root@kali:~# apt-get install zipalign

  

执行以上命令后，如果没有报任何错误信息，则说明成功安装了zipalign。

  

2）使用keytool工具创建秘钥库。keytool工具的语法格式如下：

  

keytool \[选项\]

  

keytool工具的常用选项及含义如下：

  

\-genkey：在用户主目录中创建一个默认文件.keystore，还会产生一个mykey的别名。mykey中包含用户的公钥、私钥和证书。

  

\-alias：产生别名。

  

\-keystore：指定秘钥库的名称（产生的各类信息将不在.keystore文件中）。

  

\-keyalg：指定密钥的[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133583&idx=3&sn=cbc3236f19fdefbf135c858e9b4795b2&chksm=bc8582608bf20b765b760eda0342717dd6aba7045f3967f624adb1af0ab183bceef19126bf9e&scene=21#wechat_redirect)，如RSA、DSA。如果不指定的话，默认使用DSA。

  

\-validity：指定创建的证书有效期天数，默认为90天。

  

\-keysize：指定秘钥长度。

  

\-storepass：指定秘钥库的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)（获取keystore信息所需的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)）。

  

keypass：指定别名条目的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)（私钥的[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)）。

  

\-dname：指定证书拥有者信息。例如："CN=名字与姓氏，OU=组织单位名称，O=组织名称，L=城市或区域名称，ST=州或省份名称，C=单位的两字母国家代码"。

  

\-list：显示密钥库中的证书信息。

  

\-export：将指定的证书导出到文件中。

  

\-file：指定导出到文件的文件名。

  

\-delete：删除密钥库中的某个条目。

  

\-printcert：查看导出的证书信息。

  

\-keypasswd：修改密钥库中指定的条目口令。

  

\-storepasswd：修改keystore口令。

  

\-import：将已签名的[数字证书](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655134071&idx=2&sn=d254f62f7251f146a02b80c669475915&chksm=bc85bc988bf2358e422833991415e60b87209d9ad13375203b457179f5ca26f5544e6fa0609b&scene=21#wechat_redirect)导入密钥库。

  

接下来即可创建密钥库了，执行命令如下：

  

root@kali:~# keytool -genkey -v -keystore /root/key.keystore -alias android -keyalg RSA -keysize 2048 -validity 365 -storepass 123456 -dname "CN= Android,OU=Google,O=Google,L=IL,ST=NY,C=US"

  

正在为以下对象生成 2048 位RSA密钥对和自签名证书（SHA256withRSA）（有效期为 365 天）：

  

CN=Android, OU=Google, O=Google, L=IL, ST=NY, C=US

输入 <android> 的密钥口令   #为了方便记忆，直接回车

（如果和密钥库口令相同, 按回车）：

\[正在存储/root/key.keystore\]

  

从输出的信息中可以看到，密钥库被保存在/root/key.keystore文件中了。

  

3）使用JARsigner工具签名APK。语法格式如下：

  

jarsigner \[选项\] jar文件别名

  

JARsigner工具常用的选项及含义如下：

  

\-verbose：签名/验证时输出详细信息。

  

\-sigalg：签名[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133583&idx=3&sn=cbc3236f19fdefbf135c858e9b4795b2&chksm=bc8582608bf20b765b760eda0342717dd6aba7045f3967f624adb1af0ab183bceef19126bf9e&scene=21#wechat_redirect)的名称。

  

\-digestalg：摘要[算法](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655133583&idx=3&sn=cbc3236f19fdefbf135c858e9b4795b2&chksm=bc8582608bf20b765b760eda0342717dd6aba7045f3967f624adb1af0ab183bceef19126bf9e&scene=21#wechat_redirect)的名称。

  

\-keystore：秘钥库位置。

  

此时即可指定不同的选项对APK文件签名。执行命令如下：

  

root@kali:~# jarsigner -verbose -sigalg SHA1withRSA -digestalg SHA1 -keystore /root/key.keystore /root/android.apk android
