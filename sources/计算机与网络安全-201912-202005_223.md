Microsoft Windows系统是最常见的一种操作系统。随着计算机硬件和软件的不断升级，微软的Windows也在不断升级，从架构的16位、32位再到64位，系统版本从最初的Windows 1.0到现在已经发展到Windows 10。目前，对于一些服务器来说，通常使用Windows 2000/2003/2008操作系统，如果是普通用户，通常会使用Windows XP/7/8/10。但是在这些操作系统中存在各种漏洞，如果用户没有及时修复这些漏洞，渗透测试者就可能会利用存在的漏洞实施渗透攻击。本文介绍Windows系统中的漏洞利用渗透实例。

  

**1、Microsoft Windows远程溢出漏洞——CVE-2012-0002**

  

Microsoft Windows是一款流行的操作系统。CVE-2012-0002漏洞源于没有正确处理内存中的数据包。远程攻击者可通过发送特制RDP报文，来访问未初始化或未删除的对象来触发此漏洞。成功利用该漏洞后，可以在目标系统上执行任意代码，并以管理员权限安装程序，查看、更改、删除数据，或创建新账户。受该漏洞影响的系统如下：

  

Microsoft Windows XP；

Microsoft Windows Vista；

Microsoft Windows Server 2008；

Microsoft Windows Server 2003；

Microsoft Windows 7。

  

演示在Windows XP SP1上利用该漏洞实施渗透攻击。其中，目标主机的IP地址为192.168.1.106。具体操作步骤如下：

  

1）使用search命令搜索CVE-2012-0002漏洞的完整路径。执行命令如下：

  

msf5 > search CVE-2012-0002

Matching Modules

\================

\--------------    ---------------      -----      ---------------------

auxiliary/dos/windows/rdp/ms12\_020\_maxchannelids 2019-03-16  normal No MS12-020 Microsoft Remote Desktop Use-After-Free DoS

auxiliary/scanner/rdp/ms12\_020\_check normal Yes MS12-020 Microsoft Remote Desktop Checker

  

从输出的信息中可以看到，已搜索到两个可用于利用该漏洞的攻击模块。其中，第一个攻击模块可使目标造成拒绝服务攻击，第二个漏洞仅用于扫描检测。所以，这里选择第一个攻击模块实施渗透攻击。

  

2）选择渗透攻击模块，并查看该模块的配置选项参数。具体如下：

  

msf5 > use auxiliary/dos/windows/rdp/ms12\_020\_maxchannelids

3）为dos/windows/rdp/ms12\_020\_maxchannelids模块配置选项参数。执行命令如下：

**5、浏览器自动攻击模块**

  

在Metasploit中提供了一个浏览器自动攻击模块browser\_autopwn。当用户访问Web页面时，该模块将自动攻击目标主机的浏览器。在实施渗透攻击之前，broswer\_autopwn模块能够检测到用户使用的浏览器类型。也就是说，该模块只针对IE浏览器攻击。然后，broswer\_autopwn将根据浏览器的检测结果，自行部署最合适的exploit。下面介绍利用broswer\_autopwn模块实施浏览器自动攻击的方法。

  

利用broswer\_autopwn模块对目标主机（Windows XP IE6）实施浏览器自动攻击。具体操作步骤如下：

**7、扫描配置不当的Microsoft SQL Server**

  

配置不当的Microsoft SQL Server（MS SQL）通常是进入目标系统的第一个后门。实际上，很多系统管理员甚至不知道它们的工作站上安装有MS SQL服务器软件，因为它们经常作为其他常用软件（如Microsoft Visual Studio）安装的先决条件被自动地安装在系统上。在这些情况下安装的MS SQL服务器软件通常没有实际的用处，也很少安装补丁程序，甚至从未进行过配置，因此存在可利用的漏洞。

  

安装MS SQL后，默认监听在TCP端口1433上或使用随机动态的TCP端口。如果在随机的TCP端口上进行MS SQL监听，只需要简单地对UDP端口1433进行查询，便能获取这个随机的TCP端口号。当然，Metasploit中有一个模块mssql\_ping可以实现该操作。

  

下面演示使用mssql\_ping实施扫描方法。具体操作步骤如下：

  

1）搜索mssql\_ping模块的完整路径，具体如下：

  

msf5 > search mssql\_ping

Matching Modules

2）选择mssql\_ping模块，并查看该模块的选项参数，具体如下：

  

msf5 > use auxiliary/scanner/mssql/mssql\_ping

msf5 auxiliary(mssql\_ping) > show options

3）配置选项参数，具体如下：

  

msf5 auxiliary(mssql\_ping) > set RHOSTS 192.168.1.103

由于mssql\_ping使用UDP协议，在对大规模的子网进行扫描时，它的速度可能会很慢，这是因为要处理超时的问题。所以，这里通过设置线程为255来提高扫描速度。接下来即可实施扫描。
