每个模块都提供有对应的配置选项，如设置目标地址、端口和线程数等。通常情况下，一些配置项可以使用默认设置，但是一些配置项是必须配置的。


1、设置模块选项


渗透攻击选项是指设置模块的可配置选项参数。当用户选择某模块后，往往需要为该模块下的一些选项参数进行配置后才可以使用。后面的所有操作将以ms08_067_netapi模块为例进行操作。下面介绍设置渗透攻击选项的方法。


设置渗透攻击选项。具体操作方法如下：


1）查看渗透攻击选项。通常用户使用一个新的模块后，并不确定该模块都有哪些可设置选项，因此可以先查看有哪些渗透攻击选项。执行命令如下：


msf5 exploit(ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi): #模块选项

Name     Current Setting    Required    Description

-----    ---------------   --------     -------------

RHOSTS               yes       The target address range or CIDR identifier

RPORT    445         yes       The SMB service port （TCP）

SMBPIPE  BROWSER    yes       The pipe name to use (BROWSER, SRVSVC)

Exploit target:    #可利用目标

Id  Name

--  ----------------------------

0   Automatic Targeting


从输出的信息中可以看到，ms08_067_netapi模块下有3个可配置的选项。这3个选项分别表示目标主机的地址（RHOST）、目标服务端口（RPORT）和使用的管道名称（SMBPIPE）。输出的信息中共显示了4列信息，分别表示选项名称（Name）、当前设置（Current Setting）、要求（Required）和描述（Description）。如果Required列值是yes时，表示该选项必须设置；如果为no时，表示非必须设置选项。


2）从Required列可以看到，ms08_067_netapi模块的3个选项都必须配置选项参数。其中，默认已经设置了RPORT和SMBPIPE选项，所以这里还需要设置RHOST选项。配置选项的语法格式如下：


set [选项] [值]


本例中目标主机的IP地址为192.168.1.104。执行命令如下：


msf5 exploit(ms08_067_netapi) > set RHOSTS 192.168.1.104

RHOST => 192.168.1.104


从输出的信息中可以看到，已设置RHOST为192.168.1.104。为了确定设置的结果，可以再次使用show options命令查看。执行命令如下：


msf5 exploit(ms08_067_netapi) > show options

Module options (exploit/windows/smb/ms08_067_netapi):

Name     Current Setting    Required    Description

-----    ---------------   ---------   -------------

RHOSTS   192.168.1.104    yes    The target address range or CIDR

identifier

RPORT    445                yes    The SMB service port (TCP)

SMBPIPE  BROWSER           yes    The pipe name to use (BROWSER, SRVSVC)

Exploit target:

Id  Name

--  ------------------------------

0   Automatic Targeting


从显示的结果中可以看到，RHOST选项值已设置为192.168.1.104。

2、重置选项


当用户配置（使用set命令）错误或者需要重新配置模块选项时，可以使用unset命令来重置之前的配置。如果想要重置所有配置，则可以使用unset all命令来实现。


重置模块配置选项。具体操作如下：


1）使用set命令做一个全局配置。具体如下：


msf5 > set RHOSTS 192.168.1.0/24

RHOSTS => 192.168.1.0/24

msf5 > set THREADS 50

THREADS => 50

msf5 > set

Global

======

Name     Value

-------------- ---------------------

RHOSTS   192.168.1.0/24

THREADS  50


从输出的信息中可以看到，这里配置了两个全局选项，分别是RHOSTS（目标主机）和THREADS（线程）。如果用户想要重置某个选项，可以使用unset命令实现。


2）重置THREADS选项。执行命令如下：


msf5 > unset THREADS

Unsetting THREADS...


从输出的信息中可以看到，正在重置THREADS配置选项。如果想要重置所有配置选项，则执行命令如下：


msf5 > unset all #重置所有配置

Flushing datastore...

msf5 > set          #查看配置项

Global

======

No entries in data store.

msf5 >


从输出的结果中可以看到，目前没有任何的全局配置项。


3、设置全局选项


为了保存渗透测试期间大量的输入，可以使用setg命令来设置一个全局变量。一旦设置完成，就可以将它们使用在exploits和auxiliary模块中。为了方便下一次使用，还可以保存配置。如果不想要设置的全局选项时，可以使用unsetg命令取消全局变量。


设置全局选项。例如，这里定义3个全局变量，具体如下：


msf5 > setg LHOST 192.168.1.101     #设置本地主机地址

LHOST => 192.168.1.101

msf5 > setg RHOSTS 192.168.1.0/24 #设置目标主机范围

RHOSTS => 192.168.1.0/24

msf5 > setg RHOST 192.168.1.136     #设置目标主机地址

RHOST => 192.168.1.136


此时，定义的3个全局变量就设置好了。如果想要保存该配置，可以使用save命令。具体如下：


msf5 > save

Saved configuration to: /root/.msf4/config


从输出的信息中可以看到，已成功将以上配置保存到/root/.msf4/config文件中。
