**（1）分析模块的结构**

**（2）创建并使用自己的模块**

  

当对Metasploit模块的结构有一个清晰的认识后，也就可以尝试着编写自己的模块了。可以直接在网上找一些模块作为模板文件进行编写，如GitHub。或者，直接复制Metasploit默认的模块作为模板文件。

  

当创建好自己的模块后，将该块存放在Metasploit用户的辅助模块目录下，以便能够在Metasploit环境中使用它。其中，Metasploit默认将用户的模块位置设置为/root/.msf4/modules。不同[操作系统](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655122728&idx=2&sn=6b263bf85d6b8bd8bf1d3744a491a40c&chksm=bc8668c78bf1e1d1a0e813fcd7b41c7bc300c2c98eb269b77f92854c62f1fe5127a0e01c5574&scene=21#wechat_redirect)msf版本不同，则该文件夹的名称也不同。在一些系统中，可能是/root/.msf、/root/.msf3、/root/.msf4等。此时，可以根据模块的功能，创建一个完整路径来保存该模块。下面以foursquare模块为例，演示它的使用。下载获取foursquare模块的脚本文件。然后，创建模块存放位置。如下所示：

  

root@kali:~# cd /root/.msf4/modules/

root@kali:~/.msf4/modules# mkdir -p auxiliary/admin/random

  

接下来，将下载的模块文件复制到auxiliary/admin/random目录中。如下所示：

  

root@kali:~/.msf4/modules# cp /root/foursquare.rb /root/.msf4/modules/

auxiliary/admin/random/

  

接下来，重新启动Metasploit即可加载自己创建的模块。在使用该模块之前，如果不记得该模块的完整路径，则可以先使用search命令进行查找。如下所示：

**3、动态加载模块**

  

动态加载模块是指根据需要，临时加载指定的模块。这样可以避免永久性大量加载第三方模块，造成Metasploit启动缓慢等问题。在MSF终端，提供了一些命令，用来动态加载模块。下面介绍使用这些命令动态加载模块的方法。

  

**（1）指定加载路径**

  

loadpath命令用来从一个路径中搜索并加载第三方模块。其中，指定的模块类型可以是exploits（[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)利用）、encoders（编码器）、payloads（有效载荷）等。该命令的语法格式如下：

  

loadpath \[模块路径\]

  

指定从/home/secret/modules路径中搜索并加载模块。执行命令如下：

  

msf5 > loadpath /home/secret/modules

Loaded 0 modules:

  

看到以上输出信息，说明已从用户指定的路径中搜索模块了，但是没有找到可加载的模块。

  

**（2）加载模块**

  

load命令用于从Metasploit的模块目录中加载一个模块。如果用户没有指定绝对路径，则首先查找用户的模块目录~/.msf4/plugins，然后查找框架的主模块目录/usr/share/metasploit-framework/plugins。其中，语法格式如下所示：

  

load \[var=val var=val ...\]

  

使用load命令加载模块。执行命令如下：

  

msf5 > load pcap\_log

\[\*\] PcapLog plugin loaded.

\[\*\] Successfully loaded plugin: pcap\_log

  

从输出的信息中可以看到，已成功加载了pcap\_log模块。

  

**（3）卸载模块**

  

unload命令用来卸载前面加载的模块或删除任何扩展命令。其中，语法格式如下：

  

unload \[模块名\]

  

卸载pcap\_log模块。执行命令如下：

  

msf5 > unload pcap\_log

Unloading plugin pcap\_log...unloaded.

  

从输出的信息中可以看出，pcap\_log模块已被卸载。
