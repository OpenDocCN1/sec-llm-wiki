模块是指Metasploit框架中所使用的一段软件[代码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131576&idx=3&sn=e6f82839a1e2ae419a3882eb5e0fab36&chksm=bc858a578bf203410f36d848badab5f015dab135ca44a27abadc29e01d71576e60629954d991&scene=21#wechat_redirect)组件。Metasploit框架的核心就是由它支持的大量模块构成。并且，Metasploit将所有的模块进行了分类。Metasploit不仅自带了大量的模块，还支持导入第三方模块实施[渗透](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)。本文介绍Metasploit框架中各类模块的使用。

  

**1、模块分类**

  

Metasploit框架如此强大的核心所在，就是它支持的模块。其中，Metasploit将所有模块进行分类，分别是exploits、auxiliary、post、payloads、encoders和nops。这些模块类都以文件夹的形式保存在系统中，默认保存在Metasploit安装位置的modules目录下。在启动Metasploit时，可以看到每类模块的个数，具体如下：

search \[关键字\]

  

该命令可用的关键字如下：

  

app：指定client和server[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)的模块。

author：通过模块作者名称进行查找。

bid：根据Bugtraq ID来查询模块。

cve：根据CVE ID来查询模块。

edb：根据Exploit-DB ID来查询模块。

name：根据名称来查询模块。

osvdb：根据OSVDB ID来查询模块。

platform：根据模块级别来查询，缩小查询范围。

ref：根据ref来查询模块。

type：根据类型来查询模块。如类型为exploit、auxiliary或post。

**3、辅助模块（Auxiliary）**

  

辅助模块主要用来执行一些诸如扫描或系统查询的[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)动作。辅助模块除了提供一些实用的侦查工具外，如端口扫描器、服务指纹截取器等，还包含类似mysql\_login的工具，它能够使用一个用户名和口令列表对整个网络上的[MySQL](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126890&idx=3&sn=1cdab8e3953ef5db6b337a3e91a3dafd&chksm=bc8598858bf21193106359c3a1855175328ce1420020eada002972457ce1145f91b55d5da09d&scene=21#wechat_redirect)服务进行暴力口令破解。此外还有一些协议Fuzz测试工具，如ftp\_pre\_post、http\_get\_uri\_long、ssh\_version\_corrupt等。[渗透测试](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)者可以对一些特定的目标服务执行这些Fuzz测试器，并很有可能会有一些意外收获。下面介绍辅助模块的使用。

  

同样，可以使用show auxiliary命令查看所有辅助模块。Metasploit的辅助模块和[渗透](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)模块的使用类似，只需要简单地输入use命令并跟上模块名字即可。例如，使用webdav\_scanner模块，则输入命令如下：

**8、插件（Plugins）**

  

Metasploit不仅提供了大量的模块，而且还支持一些插件的使用，如Nessus、OpenVAS、wmap等。下面介绍Metasploit中插件的使用方法。

  

在Metasploit的命令行终端（MSF）下运行load命令，即可查看加载插件的方法。具体如下：

  

msf5 > load

Usage: load <option> \[var=val var=val ...\]

Loads a plugin from the supplied path.

For a list of built-in plugins, do: load -l

For a list of loaded plugins, do: load -s

The optional var=val options are custom parameters that can be passed to plugins.

  

从输出的信息中可以看到加载插件的语法格式。这些插件都是一些可执行的Ruby脚本，默认保存在/usr/share/metasploit-framework/plugins下。还可以自己创建插件，或者从第三方获取，然后将这些插件脚本文件复制到/root/.msf4/plugins目录中，之后重新启动Metasploit即可使用新导入的插件。其中，Metasploit默认提供的一些插件如表3所示。

![](../Images/d6a37d848ec62aacbadaac11b0e18df6.png)

表3  默认插件

  

在加载插件之前，可以使用load-s命令查看其插件是否已经加载。如果已经加载的话，则不需要加载。如果没有加载，则使用load命令加载。执行命令如下：

  

msf5 > load -s Nessus

  

从输出的信息中可以看到，当前已经加载了Nessus插件。

  

下面介绍在Metasploit中使用[SQLmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120352&idx=2&sn=7e3c3cea650ddd418ea935d9e5dbd786&chksm=bc86760f8bf1ff195c2fa59de32a947d89a0999a4c7dba88420f0a5854eae5788c21c9c0ea13&scene=21#wechat_redirect)插件，实施[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128142&idx=2&sn=20952eabefce2d46e2f8c3b832dd4b19&chksm=bc8597a18bf21eb7520302c804e893a6ef58af66ad67c2689a15afed4182b3e91aaf44541ee9&scene=21#wechat_redirect)。具体操作步骤如下：

  

1）加载[SQLmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120352&idx=2&sn=7e3c3cea650ddd418ea935d9e5dbd786&chksm=bc86760f8bf1ff195c2fa59de32a947d89a0999a4c7dba88420f0a5854eae5788c21c9c0ea13&scene=21#wechat_redirect)插件。执行命令如下：

  

msf5 > load sqlmap

\[\*\] Sqlmap plugin loaded

\[\*\] Successfully loaded plugin: Sqlmap

  

从输出的信息中可以看到，成功加载了插件[SQLmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655120352&idx=2&sn=7e3c3cea650ddd418ea935d9e5dbd786&chksm=bc86760f8bf1ff195c2fa59de32a947d89a0999a4c7dba88420f0a5854eae5788c21c9c0ea13&scene=21#wechat_redirect)。在使用该插件之前，用户可以使用help sqlmap命令查看该插件支持的所有命令。具体如下：

  

msf5 > help sqlmap

Sqlmap Commands

sqlmap\_set\_option    Set an option for a task

sqlmap\_start\_task      Start the task

  

从以上输出信息可以看到，支持的所有命令。接下来介绍该插件的使用方法。

  

2）启动sqlmapapi。在Metasploit中的Sqlmap插件依赖于sqlmapapi.py，在使用Sqlmap插件之前，需要启动sqlmapapi。执行命令如下：

\[23:15:31\] \[INFO\] Running REST-JSON API server at '127.0.0.1:8775'..

以上输出信息表示成功启动了sqlmapapi，其监听地址为127.0.0.1：8775。接下来，就可以使用Sqlmap插件实施注入了。

  

3）使用sqlmap\_connect命令连接到sqlmapapi。执行命令如下：

  

msf5 > sqlmap\_connect 127.0.0.1

\[+\] Set connection settings for host 127.0.0.1 on port 8775

  

从输出的信息可以看到，已成功连接到运行sqlmapapi的[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)。

  

4）创建一个新的任务。执行命令如下：

  

msf5 > sqlmap\_new\_task

\[+\] Created task: 1

  

从输出的信息可以看到，已创建了一个任务，其ID号为1。

  

5）启动新建的任务。执行命令如下：

  

msf5 > sqlmap\_start\_task 1 'www.baidu.com'

\[\*\] Started task: true

  

从输出的信息可以看到，已成功启动了任务。为了确定其扫描任务是否成功执行，可以查看任务列表。执行命令如下：

  

msf5 > sqlmap\_list\_tasks

\[+\] Task ID: 1

  

从输出的信息可以看到，当前运行的任务ID为1。由此可以说明，已成功启动了扫描任务。此时，还可以查看扫描状态。执行命令如下：

  

msf5 > sqlmap\_get\_status 1

\[\*\] Status: terminated

  

从输出的信息可以看到，扫描状态为terminated，表示扫描完成。如果没有完成扫描的话，其状态显示为running（正在运行）。

  

6）获取扫描的[漏洞](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131786&idx=3&sn=215ae89e5806b5a1c89f7ac0a1bfc798&chksm=bc8585658bf20c7340c356fc4acfe8a757f76f65e98e431c561457a3dee2bcca64d4179e27a5&scene=21#wechat_redirect)信息。执行命令如下：

**9、规避模块（Evasion）**
