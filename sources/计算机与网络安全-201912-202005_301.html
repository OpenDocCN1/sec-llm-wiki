使用扫描/渗透工具对目标主机进行渗透攻击，通常会获取到很多相关信息，如主机IP地址信息、目标主机的服务信息、目标主机漏洞信息等。这些信息都会被保存到工作区中，这也是用户日后进行其他攻击所需的重要信息。在这些信息中，经常会存在一些无用信息。因此在渗透过程中，需要经常对这些信息进行整理。


1、管理目标主机


工作区的host项往往包含了大量的主机信息，这些主机都可以作为后期渗透的目标主机来使用。但不是每个主机都是渗透目标。因此，在使用前需要进行管理。这时，需要使用子命令hosts。其语法格式如下：


hosts [ options ] [addr1 addr2 ...]


其中，options表示选项，addr1和addr2都表示IP地址。其中选项及含义如下：


-a，--add：添加主机。


-d，--delete：删除主机。


-c<col1，col2>：列出指定的列。其中，col1和col2都表示列名，如果同时列出指定的多个列，之间使用逗号进行分隔。


-C<col1，col2>：列出指定的列，与-c选项含义相同，但是使用该选项后，如果不重启数据库，以后使用hosts命令将只列出-C指定的列。


-h，--help：显示帮助信息。


-u，--up：只显示开放的主机。


-o<file>：将结果保存到CSV格式的文件中。


-O<column>：按照指定列排序。


-R，--rhosts：将搜索的结果作为RHOSTS选项的值。


-S，--search：指定字符串进行搜索。


-i，--info：修改主机info信息。


-n，--name：修改name列的信息。


-m，--comment：修改comment列的信息。


-t，--tag：为主机信息添加标签。


hosts命令是针对工作区进行管理的，所以在当前工作区执行该命令只能管理当前工作区中的主机。下面介绍如何使用hosts命令来管理主机。

2、管理服务


工作区的services项往往包含了大量的服务信息，这些服务都有对应的主机。用户可以根据服务进行分类，批量进行渗透。由于不是每个服务都可以利用，所以需要进行筛选整理。这时，需要使用子命令services。其语法格式如下：


services [options] [addr1 addr2 ...]


其中，options表示选项，addr1和addr2都表示IP地址。用到的选项及含义如下：


-a，--add：添加服务。


-d，--delete：删除服务。


-c<col1，col2>：仅显示指定列的服务。其中，col1和col2都表示列名。如果同时列出指定的多个列，列名之间使用逗号进行分隔。


-h，--help：显示帮助信息。


-s<name1，name2>：指定服务名称进行搜索。其中，name1和name2都表示服务名称，如果同时指定多个，服务名之间使用逗号进行分隔。


-p<port1，port2>：指定端口号进行搜索。其中，port1和port2都表示端口号，如果同时指定多个，端口号之间使用逗号进行分隔。


-r<protocol>：只显示基于TCP/UDP协议的服务。


-u，--up：只显示开启的服务。


-o<file>：将结果保存到CSV格式的文件中。


-O<column>：按照指定列排序。


-R，--rhosts：将搜索的结果作为RHOSTS选项的值。


-S，--search：指定字符串进行搜索。

1）如果用户通过其他方式获取到新的认证信息，可以将其添加到工作区中。进行添加需要使用add选项，后面跟上添加的参数。用到的参数及含义如下：


user：用户名。

了解了各个参数含义以后就可以添加认证信息了。下面介绍每种认证信息的语法。


①添加用户、密码和域。语法格式如下：


creds add user:admin password: pass realm:workgroup


其中，user表示要添加的是用户，admin表示用户名名称；password表示要添加的是密码，pass表示密码；realm表示要添加的是域，workgroup表示域名。


②添加用户名、密码。语法格式如下：


creds add user:guest password:pass


其中，user表示要添加的是用户，guest表示用户名名称；password表示要添加的是密码，pass表示用户guest的密码。


③添加密码。语法格式如下：


creds add password:pass


其中，password表示要添加的是密码，pass表示密码。


④添加用户名和NTLM哈希值。语法格式如下：


creds add user:admin ntlm:NTML


其中，user表示要添加的是用户，admin表示用户名名称；ntml表示要添加的是NTML哈希值，NTML表示哈希值。


⑤添加NTLM哈希值。语法格式如下：


creds add ntlm:NTML


其中，ntml表示要添加的是NTML哈希值，NTML表示对应的值。


⑥添加用户名和ssh-key文件。语法格式如下：


creds add user:sshadmin ssh-key:/path/to/id_rsa


其中，user表示要添加的是用户，sshadmin表示用户名名称；ssh-key表示要添加的是ssh-key文件，/path/to/id_rsa表示添加的文件路径。


⑦添加用户名和不可重放哈希值。语法格式如下：


creds add user:other hash:HASH


其中，user表示要添加的是用户，other表示用户名名称；hash表示要添加的是不可重放哈希值，HASH表示对应的值。


⑧添加不可重放哈希值。语法格式如下：


creds add hash:HASH


其中，hash表示要添加的是不可重放哈希值，HASH表示对应的值。


2）通过上述方法就可以在数据库中添加认证信息了。例如，添加用户名为user，不可重放哈希值为d19c32489b870735b5f587d76b934283。执行命令如下：

其中，regex表示匹配密码的正则表达式。


②根据端口过滤。语法格式如下：

⑤根据类型进行过滤。语法格式如下：


-t,--type <type>


其中，type表示类型，如password、ntlm、hash。


⑥根据起源过滤。语法格式如下：


-O,--origins < origins >


其中，origins表示起源。

6、查看漏洞信息


在对目标进行漏洞扫描时，如果获取到主机对应的漏洞信息，这些信息将会被保存到工作区中。查看漏洞信息需要使用vulns命令，其语法格式如下：


vulns [options] [addr range]


其中，options表示选项，addr表示IP地址，range表示IP地址范围。用到的选项及含义如下：


-o<file>：将输出信息保存到CSV格式文件中。


-p，--port<portspec>：显示指定端口的漏洞信息。


-s<svc names>：显示指定服务名称的漏洞信息。


-R，--rhosts：将搜索到的结果主机设置为RHOSTS的选项值。


-S，--search：指定字符串进行过滤。


-i，--info：显示info列的信息。


-h，--help：显示帮助信息
