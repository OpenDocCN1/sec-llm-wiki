OpenVAS（开放式漏洞评估系统）是一个客户端/服务器架构，它常用来评估目标主机上的漏洞。OpenVAS是Nessus项目的一个分支，它提供的产品是完全免费的。本文介绍使用OpenVAS来获取漏洞信息的方法。


1、安装及初始化OpenVAS


要使用OpenVAS，需要先安装。下面介绍安装及初始化OpenVAS服务的方法。


（1）获取OpenVAS的安装包


OpenVAS安装包的下载地址：


http://www.openvas.org/download.html


在浏览器的地址栏中输入该地址后，打开如图1所示的界面。

图1  下载OpenVAS安装包


该界面提供了3种安装OpenVAS的包，分别是Livedemo（Live模式）、Virtual Appliance（虚拟应用程序）和Source Packages（源码包）。可以选择下载任意一种安装包。例如，选择下载源码包，将显示如图2所示的界面。

图2  OpenVAS的源码包


从该界面可以看到提供的源码包。


（2）安装OpenVAS服务


下面以Kali Linux系统为例，介绍安装OpenVAS服务的方法。在Kali Linux提供的软件源中，已经提供了OpenVAS的安装包。所以，可以直接使用apt-get命令安装。执行命令如下：


root@kali:~# apt-get update && apt-get install openvas*  -y


开始安装OpenVAS服务。如果在安装过程中没有报错，则表明OpenVAS服务安装成功。

2、登录及配置OpenVAS


当成功安装OpenVAS后，即可登录并使用该工具实施漏洞扫描。但是，成功登录OpenVAS服务后，还需要进行简单的配置才可以实施漏洞扫描。


（1）登录OpenVAS服务


登录OpenVAS服务。具体操作步骤如下：


1）在浏览器中输入https://127.0.0.1:9392，显示如图3所示的界面。

图3  不可信任的链接


2）该界面显示浏览器中访问的链接不可信任。这是因为该链接使用的是https协议，必须要确定安全可靠才可访问。单击Advanced按钮，显示如图4所示的界面。

图4  风险信息


3）该界面显示了访问该链接存在的风险。如果确认访问的链接没问题，则单击Add Exception按钮添加例外，如图5所示。

图5  添加例外


4）该界面显示了要添加例外的链接信息。此时，单击Confirm Security Execption按钮，显示如图6所示的界面。

图6  OpenVAS登录界面


5）该界面是OpenVAS服务的登录界面，输入用户名和密码即可登录该服务。这里的用户名就是前面配置OpenVAS时，自动创建的admin用户，密码为password。输入用户名和密码后，单击Login按钮，显示如图7所示的界面。

图7  OpenVAS主界面


6）看到该界面显示的内容，则表示已成功登录OpenVAS服务。


在重新启动系统后，如果要使用OpenVAS工具，则需要重新启动服务。否则，无法登录服务器。如果在启动服务时，出现错误，则使用openvas-setup命令重新同步下数据库，同时它自动启动相关服务。


（2）创建扫描配置

图9  Scan Configs界面

图10  新建扫描配置


3）在该界面中设置扫描的名称，这里设置为Local Vulnerabilities。对于Base选择Empty，static and fast复选框，该选项表示允许从零开始创建自己的配置。单击Create按钮进行创建。显示如图11所示的界面。

图11  编辑扫描配置


图11中选择的是插件的类别。其中，每一类又包括好多个插件，从NVTs selected列可以看到。系统默认勾选类别后，将选择使用该类中的所有扫描插件。如果想要手动选择扫描插件，单击Actions列的图标，即可看到所有的插件，如图12所示。

图12  Debian Local Security Check类的所有插件

图13  新建的扫描配置


5）该界面显示了新建的扫描配置Local Vulnerabilities。从该界面可以看到，新建的扫描配置共选择了9个插件族，共4409个插件。如果希望编辑该扫描配置重新设置插件时，单击Actions列的图标，打开扫描编辑配置界面。在该界面单击扫描配置名称，即可查看其详细信息，如图14所示。

在创建好扫描配置后，就需要创建扫描目标了。扫描目标就是用来指定扫描目标主机的地址、扫描端口及使用的扫描方式。

图17  新建目标的详细信息

3、实施漏洞扫描


通过前面一系列的操作，可以开始对指定的目标实施漏洞扫描了。


以前面创建的扫描任务为例，实施漏洞扫描。具体操作步骤如下：

1）创建的扫描任务如图21所示。


2）从该界面可以看到前面新建的任务Windows XP。此时，单击（Start）图标，开始漏洞扫描。在启动该扫描任务后，按钮图标将变为（Pause），单击该按钮可以暂停扫描。也可以单击（Stop）图标停止扫描。扫描完成后，New将变为Done，在扫描过程中显示为Requested。


通常情况下，用户启动扫描后，都会发现扫描速度很慢，状态列几乎不发生变化。但是，实际上一直在对目标进行扫描。由于这是在浏览器显示的内容，需要手动刷新一下页面才可以看到状态的变化。也可以设置为，每隔几分钟自动刷新一次。默认OpenVAS设置的是不自动刷新，如图22所示。

图22  设置自动刷新

图23  选择自动刷新时间

4、分析并导出漏洞扫描报告


当对目标主机实施扫描后，即可从扫描结果中获取其目标主机的漏洞信息。同样，为了方便分析其扫描结果，OpenVAS也支持将漏洞信息以不同报告格式导出。


（1）分析漏洞扫描结果


以上例中的扫描结果为例，对其进行分析。具体操作步骤如下：


1）上例中的扫描结果如图24所示。


2）从该界面可以看到目标系统中有非常严重的漏洞，安全级别为10.0（High）。此时可以单击状态下面的Done命令，查看漏洞扫描的详细信息，如图25所示。

图25  漏洞扫描报告


3）从该界面的Severity列显示的情况，可以看到这些漏洞的严重情况。其中，10.0是安全问题最严重的漏洞。例如，查看该界面显示的第一个漏洞的详细信息，如图26所示。

图26  漏洞详细消息


4）该界面显示了目标主机上拒绝服务攻击漏洞详细信息。其中，漏洞信息包括目标主机所开放的端口、漏洞导致的结果及漏洞解决方法等。这里记下该漏洞的CVE编号非常重要。在以上References部分即可看到相关的漏洞CVE编号及可参考的链接。在这些参考网页中，可了解该漏洞的详细信息，以及具体的漏洞编号等。然后，根据该漏洞CVE编号查找对应的攻击载荷，并实施攻击。


（2）导出漏洞扫描报告


为了方便进行分析，可以将漏洞信息以报告的形式导出。其中，OpenVAS支持15种文件格式的报告，如PDF、XML、CXV、HTML和TXT等。


将漏洞扫描结果以PDF格式导出。其操作步骤如下：


1）打开漏洞扫描列表界面，如图27所示。

图27  所有漏洞信息
