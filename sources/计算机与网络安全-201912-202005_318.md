**1、安装及初始化OpenVAS**

  

要使用OpenVAS，需要先安装。下面介绍安装及初始化OpenVAS服务的方法。

  

**（1）获取OpenVAS的安装包**  

  

OpenVAS安装包的下载地址：

  

http://www.openvas.org/download.html

  

在浏览器的地址栏中输入该地址后，打开如图1所示的界面。

![](../Images/3ba2cdddc2e1bfc05a0a94aef7edef87.png)

图1  下载OpenVAS安装包

  

该界面提供了3种安装OpenVAS的包，分别是Livedemo（Live模式）、Virtual Appliance（虚拟应用程序）和Source Packages（源码包）。可以选择下载任意一种安装包。例如，选择下载源码包，将显示如图2所示的界面。

![](../Images/53e5b31c1cf6ce853c5505eea0d346cf.png)

图2  OpenVAS的源码包

  

从该界面可以看到提供的源码包。

  

**（2）安装OpenVAS服务**  

  

下面以[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128965&idx=3&sn=b8b9a62359603244f96d47b39c0a094e&chksm=bc85906a8bf2197c862d73e7aa0b33d06465d5570713fd18493312f7c38da5c6b4b21f9895cf&scene=21#wechat_redirect)系统为例，介绍安装OpenVAS服务的方法。在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132692&idx=3&sn=9a6004474fc0fb18778adad6388d0f64&chksm=bc8581fb8bf208ed7ab4c414996ee7c2c487318106ab00e581ff5fbd1dc04b9fb69fa37a79da&scene=21#wechat_redirect)提供的软件源中，已经提供了OpenVAS的安装包。所以，可以直接使用apt-get命令安装。执行命令如下：

  

root@kali:~# apt-get update && apt-get install openvas\*  -y

  

开始安装OpenVAS服务。如果在安装过程中没有报错，则表明OpenVAS服务安装成功。

**（2）创建扫描配置**

  

扫描配置就是用来指定扫描目标时所需要的插件。使用OpenVAS工具扫描时，需要通过一个扫描任务来实现。但是，扫描任务是由一个扫描配置和一个目标组成的。所以，在实施扫描之前，必须先创建扫描配置和扫描目标才可以。

  

新建扫描配置。具体操作步骤如下：
