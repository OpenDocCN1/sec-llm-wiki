通过数据抽取脚本从Ganglia中抽取数据，然后通过脚本的判断最终实现在Centreon上的报警通知。这个过程看似很完美，其实隐藏着一些问题，比如，从给出的两个数据抽取文件中，脚本每次只能检测一台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的一个服务状态，如果要检测多台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的多个服务状态，就需要多次重复执行这个脚本。例如，要检测100台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的磁盘最大占用率，脚本就要重复执行100次，同理，要检测100台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)中的10个服务状态，脚本就要执行1000次，在Centreon平台中，脚本检测是定期执行的，如果每小时执行一次检测，那么每小时就要执行脚本1000次。由此可知，这种脚本执行方式效率低下，严重浪费[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)资源，在监控[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)较少的环境中，监控效率还勉强能够接受，但是当监控的[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)超过500台或更多，监控的服务超过100或更多时，监控效率将更加低下，监控脚本从Ganglia抽取数据的时间也将变得很长，可能还会发生获取监控数据超时的情况，对于要求监控精度很高、报警及时性强的监控报警平台来说，这是不可容忍的。

  

如果能减少监控脚本重复执行检查的次数，或者让脚本一次检查多台[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)的多个服务状态，那么脚本的执行效率将大大提升。通过读取Ganglia [Web](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130618&idx=3&sn=449f93385285290a85de33579f5e55bf&chksm=bc858e158bf20703b709bfb7ddf2adee4149765451b8281f45a741aee2c621c396b330f67af2&scene=21#wechat_redirect)的页面信息可以获取监控数据，既然通过此脚本能一次获取某台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的信息，那么也能一次获取多台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的数据。Ganglia本身已经实现了这个功能。在Ganglia [Web](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130618&idx=3&sn=449f93385285290a85de33579f5e55bf&chksm=bc858e158bf20703b709bfb7ddf2adee4149765451b8281f45a741aee2c621c396b330f67af2&scene=21#wechat_redirect)的程序目录下有一个nagios目录，其中有多个[shell](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655127748&idx=3&sn=c1a3d178c1155c7613708f4f6384eb64&chksm=bc85952b8bf21c3d2d44139d072702367155b51c86221ea83618a580515205fc6dd139e1496c&scene=21#wechat_redirect)脚本和[PHP](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130803&idx=3&sn=32cc58b76d89e2ba3f9d132628ea3200&chksm=bc85895c8bf2004a26b780597e0b78206119e6b311d936b856b95ae2dbfdf4574840e4068298&scene=21#wechat_redirect)脚本，这里重点介绍下check\_host\_regex.sh和check\_host\_regex.php这两个脚本，其他脚本的使用方法与此类似。

下面介绍check\_host\_regex.sh脚本的用法。

  

直接在命令行执行check\_host\_regex.sh脚本，即可显示详细用法，例如：

  

\[root@centreonserver plugins\]# ./check\_host\_regex.sh  
Sample invocation ./check\_host\_regex.sh hreg=Hostname checks=load\_one,more,1:load\_five,more,2 ignore\_unknowns=0  
Set ignore\_unknowns=1 if you want to ignore hosts that don't posses a particular metric. 

  

下面介绍其中各个参数的意义。

  

**hreg：**后面跟[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)名或[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)名标识。这个参数的含义与check\_ganglia\_metric.php脚本中“hostname”参数的含义相同，但用法稍有不同。如果在hreg后面指定一个完整的[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)名，那么就收集这台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的状态信息。同时，hreg参数还支持[正则表达式](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655116756&idx=2&sn=1fd7b5653b212df66d47d01e3187bf78&chksm=bc86403b8bf1c92db698874de49dba4c7ec1f1daf2130b7810d63cc5aef492f05debc6e92297&scene=21#wechat_redirect)，只需提供一个[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)名的标识，就可以批量检测包含此标识的所有[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)，例如，有800台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)，[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)名都包含有“bestjob”这个字符，那么只需设置“hreg=bestjob”即可实现一个脚本一次检查800台[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的服务状态。

  

**checks：**后面跟检测服务的指标值、检查条件和告警阈值。常见的服务指标有load\_one、disk\_free、swap\_free、part\_max\_used等，检查条件有more（大于）、less（小于）、equal（等于）、notequal（不等于）四种，告警阈值根据实际应用环境来设置。这个参数还有个功能就是可以一次设置多个服务状态，每个服务之间用“：”进行分割即可。有了这个功能，就可以通过一个脚本一次检测多个服务的运行状态，大大提高了脚本检测的效率。

**ignore\_unknowns：**此参数用来设置是否忽略UNKNOWN状态的服务。设置此参数为1表示忽略UNKNOWN状态的服务，反之，设置为0表示不忽略。
