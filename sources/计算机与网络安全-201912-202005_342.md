Metasploit框架为其基础功能提供了多个用户接口，包括终端、命令行和图像界面等。在最新的版本中，命令行接口已被废弃，其功能都被整合到了MSF终端接口中。除了这些接口，功能程序则提供了对Metasploit框架中内部功能的直接访问。

  

**1、图形界面接口 Armitage**

  

Armitage组件是Metasploit框架中一个完全交互式的图形化用户接口，由Raphael Mudge所开发。Armitage工具包含Metasploit控制台，通过使用其标签特性，可以看到多个Metasploit控制台或多个Meterpreter会话。这里只讲解和分析Metasploit的输入和输出。只要了解了Metasploit框架的实际工作原理，那么这个图形界面工具的使用就很容易了。下面简单介绍Armitage接口的使用。

  

在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128965&idx=3&sn=b8b9a62359603244f96d47b39c0a094e&chksm=bc85906a8bf2197c862d73e7aa0b33d06465d5570713fd18493312f7c38da5c6b4b21f9895cf&scene=21#wechat_redirect)中使用Armitage。其中，该工具已经默认安装在[Kali Linux](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132692&idx=3&sn=9a6004474fc0fb18778adad6388d0f64&chksm=bc8581fb8bf208ed7ab4c414996ee7c2c487318106ab00e581ff5fbd1dc04b9fb69fa37a79da&scene=21#wechat_redirect)中，所以可以直接使用。具体操作步骤如下：

  

1）启动Postgresql[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)服务。在使用Armitage工具前，必须启动Postgresql[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)服务，并且还需要初始化[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)。否则，将无法运行Armitage工具。因为Armitage需要连接到PostgreSQL服务，才可以启动。执行命令如下：

  

root@Kali:~# service postgresql start #启动PostgreSQL数据库服务

root@Kali:~# msfdb init #初始化数据库

Creating database user 'msf'

  

为新角色输入的口令：

  

再输入一遍：

  

Creating databases 'msf' and 'msf\_test'

Creating configuration file in /usr/share/metasploit-framework/config/database.yml

Creating initial database schema

  

从以上输出信息中，可以看到已经自动创建了msf和msf\_test[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)。如果没有初始化[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)，启动Armitage工具后将弹出如图1所示的消息框。

**2、终端接口 Msfconsole**

  

MSF终端（Msfconsole）是目前Metasploit框架最为流行的用户接口，而且MSF终端是Metasploit框架中最灵活、功能最丰富及支持最好的工具之一。MSF终端提供了一站式的接口，能设置Metasploit框架中几乎每一个选项和配置。用户可以使用MSF终端做任何事情，包括发起一次[渗透](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)、装载辅助模块、实施查点、创建监听器，或是对整个网络进行自动化[渗透](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131857&idx=3&sn=f05704b1a33a118f5974dc1e0e3d8fde&chksm=bc85853e8bf20c282a388c76d4472ec1e0c54b97c6f96ce0179e0c75f9d0922a988125c9881d&scene=21#wechat_redirect)[攻击](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132417&idx=3&sn=47c1d21230bf18b89e7b587c912c9f4b&chksm=bc8586ee8bf20ff871fd6248ddaed9ef07d50c752ef7e9b1b60916bf673c1ff4b0c578202c15&scene=21#wechat_redirect)等。
