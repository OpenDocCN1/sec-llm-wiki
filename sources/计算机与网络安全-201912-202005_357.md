支持分布式监控是Centreon系统核心的功能，本文对分布式监控进行详细阐述。

  

**1、分布式监控架构与实现原理**

  

在介绍分布式监控之前，先介绍一下我们要实现的分布式监控的架构，如图1所示。

![](../Images/9a4d7f6ba66e268756f73b6a6c80b368.png)

图1  典型的Centreon分布式监控架构

  

从图1可以看出，Centreon的分布式监控是由多个Poller和一个Central构成的。在Centreon分布式监控中，[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)的扩展节点称为Poller，而本地的中心[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)称为Central，在通常情况下，[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)的Poller[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上仅需要安装nagios监控引擎及ndoutils模块，而Central[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上需要安装nagios、nagios-plugins、ndoutils、[MySQL](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126890&idx=3&sn=1cdab8e3953ef5db6b337a3e91a3dafd&chksm=bc8598858bf21193106359c3a1855175328ce1420020eada002972457ce1145f91b55d5da09d&scene=21#wechat_redirect)、Centreon和Centreon [Web](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655130618&idx=3&sn=449f93385285290a85de33579f5e55bf&chksm=bc858e158bf20703b709bfb7ddf2adee4149765451b8281f45a741aee2c621c396b330f67af2&scene=21#wechat_redirect)等。

  

远端的Poller[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)通过自身安装的ndomod模块与Central[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上的Ndo2DB进行通信，最终将监控状态写入[MySQL](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126890&idx=3&sn=1cdab8e3953ef5db6b337a3e91a3dafd&chksm=bc8598858bf21193106359c3a1855175328ce1420020eada002972457ce1145f91b55d5da09d&scene=21#wechat_redirect)[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)，以供Centreon调用。

  

**2、分布式监控搭建环境介绍**

  

下面我们将通过一个实例详细介绍Centreon分布式监控的搭建过程，搭建环境如图2所示。

![](../Images/c64e9b4f70e371fccb98e97c923f8c8e.png)

图2  两个节点的Centreon分布式监控

  

本实例环境是一个中心[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)（Central server）和一个[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)扩展节点（Poller server）组成的分布式监控系统，相关IP信息如下：

  

Central server : 192.168.12.200

Poller server : 192.168.12.188

  

在介绍安装之前，简单说明分布式监控的运作流程：在分布式监控中，所有的配置都在中心[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)也就是Central server上完成，配置完成后，生成的配置文件由Central server上，然后Central server还会[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)重启Poller server上面的nagios服务，以使[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)扩展节点上面的nagios配置生效，最后，Poller server会通过nagios监控自己本地所在的服务或[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)，并将监控状态实时写入中心[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上的[MySQL](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655126890&idx=3&sn=1cdab8e3953ef5db6b337a3e91a3dafd&chksm=bc8598858bf21193106359c3a1855175328ce1420020eada002972457ce1145f91b55d5da09d&scene=21#wechat_redirect)[数据库](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655129320&idx=3&sn=e5b2f0721ffd54f8891e633fbc280f4b&chksm=bc8593078bf21a1184c1596a84ce0604e00b716de6081c5b27ea0311d1df5e2b5024ba752979&scene=21#wechat_redirect)中，以实现中心[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)对所有分布式[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)的集中监控和展现。

  

下面详细介绍整个配置过程。

  

**3、监控软件的安装**

  

监控软件的安装分为两个部分：首先是Central server端的安装，主要安装有nagios、nagios-plugins、ndoutils、nrpe、Centreon等软件，最后是Poller server端的安装，在Poller server端的安装非常简单，仅需要安装nagios和ndoutils两个部分，如果需要nrpe服务，还可以安装nrpe。

  

在Poller server端安装完nagios后，默认的配置文件路径为/etc/nagios，以后从Central server上推送过来的配置文件，默认也会放到这个路径下，因此要保证/etc/nagios目录对Central server有读写权限，需要在Poller server上做如下授权：

  

\[root@Poller server ~\]# chown -R centreon:centreon /etc/nagios

  

接着，还需要在Poller server上启动nagios和ndoutils服务，操作如下：

  

\[root@Poller server ~\]# /etc/init.d/nagios start

\[root@Poller server ~\]# /etc/init.d/ndoutils start

  

最后一步，为了简单起见，建议把Central server上的所有nagios插件（默认路径为/usr/lib64/nagios/plugins）复制到Poller server上对应的nagios插件路径下。

**4、配置节点间SSH信任登录**

  

为了让Central server上生成的配置文件能自动分发到Poller server上，需要在Central server和Poller server之间进行[SSH](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131079&idx=3&sn=794779c5c517f42260167e098ee06322&chksm=bc8588288bf2013ebd40fb2b944291585012bf1af14e1198e987a745b0ed2b95eb882984db5a&scene=21#wechat_redirect)单向信任，在进行用户信任登录之前，需要了解下Centreon分布式监控系统中几个重要的用户。

  

在Centreon分布式监控系统中，主要有两个[进程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131174&idx=3&sn=d79178100819b07634684563e1c10d38&chksm=bc858bc98bf202df4587cc903821ca88564b45742475b53bb542b44926dfacc0ca50d004240e&scene=21#wechat_redirect)用户，分别是nagios和Centreon，nagios用户主要完成nagios监控引擎中[主机](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655121891&idx=3&sn=b561a81bf303f985ec557f80f563b467&chksm=bc866c0c8bf1e51a40e42cee625ef8e4eb144cfb899422ed59749dd1f708a46ee54fdd083337&scene=21#wechat_redirect)或者服务的主动监控，而Centreon用户主要用来管理Centstorage和Centcore服务，而Centcore服务就是用于配置文件的推送，因此，这里要执行的[SSH](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131079&idx=3&sn=794779c5c517f42260167e098ee06322&chksm=bc8588288bf2013ebd40fb2b944291585012bf1af14e1198e987a745b0ed2b95eb882984db5a&scene=21#wechat_redirect)登录信任用户是Centreon，而非nagios，这点需要特别注意。

  

配置[SSH](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131079&idx=3&sn=794779c5c517f42260167e098ee06322&chksm=bc8588288bf2013ebd40fb2b944291585012bf1af14e1198e987a745b0ed2b95eb882984db5a&scene=21#wechat_redirect)登录信任的方式很简单，由于只需配置从Central server到Poller server之间的单向信任，因此，需要首先在Poller server上创建一个Centreon用户并设置[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)，然后在Central server[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上执行如下操作即可：

  

\[root@centreon-server /\]# su - centreon

\[centreon@centreon-server ~\]$ ssh-keygen # 依次按回车键即可

\[centreon@centreon-server ~\]$ ssh-copy-id -i ~/.ssh/id\_rsa.pub

centreon@192.168.12.188 # 根据提示，输入 192.168.12.188 服务器Centreon 用户的密码即可

\[centreon@centreon-server ~\]$ ssh 192.168.12.188 date # 验证SSH信任登录是否成功

 

接下来，为了能让Poller server上的Centreon用户管理nagios服务，还需要在Poller server上进行sudo配置，其实也就是在/etc/sudoer文件的最后添加如下内容：

  

centreon ALL=NOPASSWD: /etc/init.d/nagios restart

centreon ALL=NOPASSWD: /etc/init.d/nagios stop

centreon ALL=NOPASSWD: /etc/init.d/nagios start

centreon ALL=NOPASSWD: /etc/init.d/nagios reload

centreon ALL=NOPASSWD: /usr/bin/nagiostats

centreon ALL=NOPASSWD: /usr/bin/nagios \*

centreon ALL=NOPASSWD: /etc/init.d/ndoutils \*

  

这样配置以后，Central server上面的Centreon用户就可以通过无[密码](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132761&idx=3&sn=f92cd4f0624a6fb17cdad04596f92154&chksm=bc8581b68bf208a0d0d807e1aff38dd630003803a07db514e78f17d8fa46d903b46fa8da9fea&scene=21#wechat_redirect)的方式登录到Poller server上[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)管理nagios服务，实现Central server对Poller server的分布式[远程](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655132894&idx=3&sn=17847f10c973b834be00cec9b8b3cde6&chksm=bc8581318bf2082794a0d3f9796303983a6550c4865bc5ad0d1f210fc41d18a2828b8a90fc51&scene=21#wechat_redirect)监控。

  

修改完成后，在Central server的Centreon用户下执行ssh sudo命令来测试设置是否正确，操作如下：

  

\[nagios@Centreon server ~\]$ ssh 192.168.12.188 sudo /etc/init.d/nagios restart

  

第一次执行可能会出现如下错误：

  

sudo: sorry, you must have a tty to run sudo

  

解决方法非常简单，修改Poller server[服务器](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128495&idx=3&sn=c1bf8a28be100a23ba990869e705ee2a&chksm=bc8596408bf21f5663ebe52e53d2e062f5a7f2149c642a2a9332c17b864f7a5f8758253d7e3f&scene=21#wechat_redirect)上的/etc/sudoers文件，注释掉如下属性：

  

Defaults requiretty

  

再次执行上面的命令，应该就能顺利执行了。

  

**5、在Central server上添加分布式监控配置**

  

**（1）添加一个Poller**

  

选择“Configuration→Centreon→Pollers”，单击“Add”添加一个新的Poller，为了方便起见，也可以直接复制一个默认的Poller，然后进行简单修改即可。图3展示的是复制的默认名为Central的Poller。

![](../Images/821852084766156ec6ec5d183d36223a.png)

图3  添加一个名为myCentral的Poller

  

这里重点关注三个选项：“Poller Name”是指定一个Poller名称，这里是“myCentral”，可以随意指定；“IP Address”就是Poller server的IP地址，这里输入“192.168.12.188”；最后一个是“[SSH](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655131079&idx=3&sn=794779c5c517f42260167e098ee06322&chksm=bc8588288bf2013ebd40fb2b944291585012bf1af14e1198e987a745b0ed2b95eb882984db5a&scene=21#wechat_redirect) port”，默认是22端口，可根据情况修改。其他配置无须改动，在配置完成后，保存退出即可。

  

**（2）为Poller添加ndomod配置**

  

ndomod配置就是指定Poller server所要连接到Central server的信息，包括Central server的IP地址、通信端口等设置。

  

选择“Configuration→Centreon→ndomod.cfg”，单击“Add”添加myCentral的ndomod.cfg配置。同理，为了方便，可以直接复制默认的ndomod.cfg配置Central-mod，修改后的结果如图4所示。

![](../Images/a3ddba3505075a6ddf8195ab8e4f1170.png)

图4  添加myCentral的ndomod.cfg配置

  

这里重点关注方框中的5个选项：在“Description”中输入的“myndomod”是添加的ndomod配置的名称；在“Instance Name”中选择刚刚添加的名为myCentral的Poller；将“Status”标记为“Enabled”状态；在“Interface Type”中一定要选择“tcpsocket”；最后一个“Output”选项非常重要，它表示将监控状态输出到哪个节点，这里一定要填写Central server的IP地址，即为“192.168.12.200”。后面还有几个选项，按照默认的配置即可，无须修改。

**（3）为Poller添加ndo2db配置**

  

ndo2db服务只在Central server上存在，选择“Configuration→Centreon→ndo2db.cfg”单击“Add”添加myCentral的ndo2db.cfg配置，这里同样直接复制默认的ndo2db.cfg配置Principal，修改后的结果如图5所示。
