SQL注入工具主要是针对Web服务器后台数据库的注入，其主要目的是获取数据库中的数据。以前常用的SQL注入工具有啊D注入工具及Domain（明小子注入工具），现在常用的SQL注入工具有HackBar、[SQLMap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139597&idx=2&sn=9739b5614c2b3aa6d1a0316ac85c89ea&chksm=bc85aae28bf223f4280bbdef8e64b0c1c9019e743ab76a8227c3057b15117d172f276f6fc7f9&scene=21#wechat_redirect)、Pangolin、Havij、Safe3 SQL injector及超级[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139811&idx=2&sn=33253ac2139356adb2df4c70c0162b2e&chksm=bc85aa0c8bf2231a1aacca0f69fe018e8e541b402d7661455f43fa0128651ffaf9a943b707ef&scene=21#wechat_redirect)工具等。

[sqlmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139597&idx=2&sn=9739b5614c2b3aa6d1a0316ac85c89ea&chksm=bc85aae28bf223f4280bbdef8e64b0c1c9019e743ab76a8227c3057b15117d172f276f6fc7f9&scene=21#wechat_redirect)是一个[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139811&idx=2&sn=33253ac2139356adb2df4c70c0162b2e&chksm=bc85aa0c8bf2231a1aacca0f69fe018e8e541b402d7661455f43fa0128651ffaf9a943b707ef&scene=21#wechat_redirect)的工具，类似于啊D注入工具及Pangolin注入工具。在ASP网站盛行的年代，一般是用啊D注入工具实现[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655143617&idx=2&sn=51e28443262dc8478803e91bed1332f0&chksm=bc85db2e8bf2523880ca7dc33b52ced6f7c1be0e68df979abb4e3f64d922fd5d694d4f32bf74&scene=21#wechat_redirect)；在PHP网站盛行的年代，一般是用Pangolin注入工具实现[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139872&idx=2&sn=b6c6f656fd474f7db7c7da1c01deb748&chksm=bc85a5cf8bf22cd96acd87c023c0098d26cab673012a9c41a6569489f88b9ce77e5d014ccd96&scene=21#wechat_redirect)；在JSP盛行的年代，[sqlmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139597&idx=2&sn=9739b5614c2b3aa6d1a0316ac85c89ea&chksm=bc85aae28bf223f4280bbdef8e64b0c1c9019e743ab76a8227c3057b15117d172f276f6fc7f9&scene=21#wechat_redirect)流行起来，直接统一了[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655128142&idx=2&sn=20952eabefce2d46e2f8c3b832dd4b19&chksm=bc8597a18bf21eb7520302c804e893a6ef58af66ad67c2689a15afed4182b3e91aaf44541ee9&scene=21#wechat_redirect)工具。[sqlmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139597&idx=2&sn=9739b5614c2b3aa6d1a0316ac85c89ea&chksm=bc85aae28bf223f4280bbdef8e64b0c1c9019e743ab76a8227c3057b15117d172f276f6fc7f9&scene=21#wechat_redirect)可以做其他所有[SQL注入](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655141445&idx=2&sn=050d3492835a8435d0e18745f654564b&chksm=bc85a3aa8bf22abc2cdd9b3e8cdf21d9210f7fd54765946bbf26d4c51b0132ef5afd93d2c295&scene=21#wechat_redirect)工具能做的事，甚至做得更好。这便是[sqlmap](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655139597&idx=2&sn=9739b5 **3、Pangolin**

  

Pangolin是一个在PHP盛行的年代十分流行的SQL注入工具。相对于啊D注入工具而言，Pangolin注入工具对PHP的支持非常好。Pangolin的中文意思是“穿山甲”，穿山甲为何物？穿山甲是一种能够穿山打洞的生物！SQL注入的本质就是“穿山打洞”！Pangolin如图3所示。

![](../Images/7e10d959ae79a90b79a11b8fd0e32c9b.png)

图3  Pangolin

  

**4、Havij**

  

Havij是一个SQL注入工具，与Pangolin类似。Havij与其他的SQL注入工具的差异在于其强大的SQL注入方式。使用Havij攻击脆弱应用的成功率不低于百分之九十。Havij的图形界面非常美观，如图4所示。

![](../Images/5b6ca5e14efd559fdc3a3ab17d9d2a3b.png)

图4  Havij

  

**5、Safe3 SQL injector**

  

Safe3 SQL injector也是一个SQL注入工具，它与Pangolin类似。Safe3 SQL injector是最强大也是最容易使用的渗透测试工具之一，它可以自动检测与利用SQL注入漏洞并接管数据库服务器，如图5所示。

![](../Images/05f4db33e4621490a15d44033a1c5911.png)

图5  Safe3 SQL injector

  

**6、超级SQL注入工具**

  

超级SQL注入工具是一款基于HTTP自组包的SQL注入工具，它支持出现在HTTP任意位置的SQL注入，支持各种类型的SQL注入，支持HTTPS模式注入。超级SQL注入工具目前支持bool型盲注、错误显示注入及union注入，支持Access、MySQL、Mssql及Oracle等数据库的注入，适合在渗透测试实战时使用。超级SQL注入工具如图6所示。

![](../Images/79e78fbb59605300b9e5cb53bd236af4.png)

图6  超级SQL注入工具

  

**7、啊D注入工具**

  

啊D注入工具是一款针对ASP及Access较好的SQL注入工具。在过去黑客工具稀有的年代，啊D注入工具有着十分重要的地位，其流行程度相当于现在的sqlmap，啊D注入工具如图7所示。
