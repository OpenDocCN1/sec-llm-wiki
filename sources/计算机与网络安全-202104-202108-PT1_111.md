Kismet是一个基于Linux的无线网络扫描程序。这是一个非常方便的工具，通过监测周围的无线信号，可以扫描到附近所有可用的AP及所使用的信道等。本文介绍使用Kismet工具扫描无线网络的方法。  
使用Kismet工具扫描无线网络。具体操作步骤如下：  
（1）启动Kismet工具。执行命令如下：  
root@daxueba:~# kismet  
执行以上命令后，将显示如图1所示的界面。![](../Images/70386de111bbd0b15205f72ac532cd13.png)图1  终端颜色  
（2）在图1中可以设置是否使用终端默认的颜色。因为Kismet默认颜色是灰色，可能一些终端不能显示。这里不使用默认的颜色，所以单击No按钮，将进入如图2所示的界面。![](../Images/cd9d9cb03b823f9adaf1a85dea61cce6.png)图2  使用root用户运行Kismet  
（3）图2中提示正在使用root用户运行Kismet工具，并且显示的字体颜色不是灰色，而是白色的。此时，单击OK按钮，将进入如图3所示的界面。![](../Images/771a30e610950a41f0953da6141d5bc5.png)图3  自动启动Kismet服务  
（4）图3中提示是否要自动启动Kismet服务。这里选择Yes，将进入如图4所示的界面。![](../Images/5e5145e8abdafe97a34ae50a07b42959.png)图4  启动Kismet服务  
（5）此时要求设置Kismet服务的一些信息。这里使用默认设置，单击Start按钮，将进入如图5所示的界面。![](../Images/d1e5e208c87b88f39a8bc9167f6df6bd.png)图5  添加包资源（6）在图5中询问是否现在添加没有被定义的包资源。这里选择Yes，将进入如图6所示的界面。![](../Images/95b1328e97763ef6f38248453c038d31.png)图6  添加资源  
（7）在图6中指定无线网卡接口和描述信息。在Intf文本框中，输入无线网卡接口。如果无线网卡已处于监听模式，可以输入wlan0或wlan0mon。其他配置信息可以不用设置。单击Add按钮，将进入如图7所示的界面。![](../Images/75b83ad6e831b53970180083de936fad.png)图7  关闭控制台窗口  
（8）在其中单击Close Console Window按钮，将进入如图8所示的界面。![](../Images/bcca1a07f4d435e7a385b65e08aa902d.png)图8  扫描到的Wi-Fi信号  
（9）从图8中可以看到捕获到的AP信息。其中包括3部分，第一部分显示AP信息，第二部分显示客户端信息，第三部分显示警告信息。在其右侧显示了捕获包的时间、扫描到的网络数和包数等。从第一部分可以看到扫描到的所有AP。例如，开放的无线网络由Meizu、Test和Tenda\_5D2B90等。如果不需要再进行网络扫描的话，则需要手动停止扫描。在Kismet的菜单栏中依次选择Kismet|Quit命令，如图9所示。![](../Images/91e46363e65828702c7614b9475ca132.png)图9  退出Kismet  
（10）此时将弹出如图10所示的对话框。![](../Images/5b4e9974edb8f602ed6bdcaac53d8598.png)图10  停止Kismet服务  
（11）在图10中有两个按钮，分别是Background（后台运行）按钮和Kill（结束服务）按钮。这里单击Kill按钮，将停止Kismet服务并退出终端模式。此时，终端将会显示一些日志信息，具体如下：  
\*\*\* KISMET CLIENT IS SHUTTING DOWN \*\*\*\[SERVER\] INFO: Stopped source 'wlan0mon'\[SERVER\]\[SERVER\] \*\*\* KISMET IS SHUTTING DOWN \*\*\*\[SERVER\] ERROR: TCP server client read() ended for 127.0.0.1\[SERVER\] INFO: Closed pcapdump log file 'Kismet-20210715-17-15-33-1.pcapdump', 7557\[SERVER\]  logged.\[SERVER\] INFO: Closed netxml log file 'Kismet-20210715-17-15-33-1.netxml', 11\[SERVER\]   logged.\[SERVER\] INFO: Closed nettxt log file 'Kismet-20210715-17-15-33-1.nettxt', 11\[SERVER\]  logged.\[SERVER\] INFO: Closed gpsxml log file 'Kismet-20210715-17-15-33-1.gpsxml',0 logged.\[SERVER\] INFO: Closed alert log file 'Kismet-20210715-17-15-33-1.alert',1 logged.\[SERVER\] INFO: Shutting down plugins...\[SERVER\] Shutting down log files...\[SERVER\] ERROR: Not creating a VIF for wlan0mon even though one was requested,since the\[SERVER\] interface is already in monitor mode.  Perhaps an existingmonitor mode\[SERVER\] VIF was specified.  To override this and create a new monitormode VIF\[SERVER\]  no matter what, use the forcevif=true source option\[SERVER\] WARNING: Kismet changes the configuration of network devices.\[SERVER\]   In most cases you will need to restart networking for\[SERVER\]   your interface (varies per distribution/OS, but\[SERVER\]   usually:  /etc/init.d/networking restart\[SERVER\]\[SERVER\] Kismet exiting.Spawned Kismet server has exited\*\*\* KISMET CLIENT SHUTTING DOWN.  \*\*\*Kismet client exiting.  
从以上信息的KISMET IS SHUTTING DOWN部分中可以看到关闭了几个日志文件。这些日志文件，默认保存在/root/目录下。在这些日志文件中，显示了生成日志的时间。当运行Kismet很多次或运行了几天时，可以根据这些日志的时间快速判断出哪个日志文件是最近生成的。
