# 2021网民网络安全感满意度“网络安全法治社会建设”专题调查报告

党的十八大以来，在习近平总书记网络强国重要思想和精神文明建设重要论 述指引下，我国扎实推进网络文明建设。2021年8月，由全国135家网络安全 行业协会及相关社会组织共同发起的“2021网民网络安全感满意度调查活动” 正式上线。全国采集有效样本量从2019年的22万份，到2020年的150万份， 再到2021的284.5万份，取得数量级增长。其中，“网络安全法治社会建设”专 题调查聚焦立法需求、普法效果、协同治理、社会组织作用等领域提出十项问题，从多角度了解网民关注、期望与治理评价。

  

基于调查所得数据，公安部第三研究所网络安全法律中心通过《2021网民网络安全感满意度“网络安全法治社会建设”专题调查报告》展现我国网络安全法治社会建设的立体图景。其中，总览部分，精准把握我国2021年网络安全立 法、执法与普法态势，在系统梳理重要政策与事件的基础上进行分析，起到提纲挈领之作用；调查分析部分，围绕“网络安全法治社会建设”专题与网络安全法治社会建设其他调查问题，分析得出十项结论，揭示网民关注点和痛点；调查展望部分，通过进一步观察研判，探讨网络安全法治社会建设现状、路径与未来，具有较为深远的现实意义。

  

本报告指出，2021年，我国网民网络安全感有所提升，网络安全法治社会建设满意度较高，主流媒体普法教育作用显著，《网络安全法》社会普及率超八 成，向服务商或平台投诉已成为网民解决网络纠纷首选途径，网络安全监管和执法工作也获认可，但网络空间安全威胁仍较为严峻，违法有害信息内容、侵犯个人信息、网络诈骗犯罪以及网络入侵问题突出。为此，我国应立足人民群众核心诉求，围绕加强网络空间思想引领、加大个人信息保护力度、深化网络犯罪源头治理、健全网络综合治理体系等方面持续推动网络空间治理。

党的十九大报告指出，“打造共建共治共享的社会治理格局”，这是对以往社会治理理念的进一步升华，为推进网络安全多元治理指明方向。网民网络安全感 满意度调查显示，过半数公众满意当前社会组织参与网络安全领域治理的状况，近半数公众认为基层组织负责人通常能够较好地代表网民利益说话。为此，社会多元主体应共享治理资源，共担治理责任，共建治理规则，发挥各自在网络社会 治理资源上的相对优势，进而推动网络社会“碎片化”管理向整体性治理转变。

  

有效凝聚网络综合治理共识，培育网络社会共建主体。对政府部门而言，要 充分发挥其在网络综合治理中的主导功能和核心作用，树立全局意识，着力倡导构建“合理分工、过程调适、齐抓共管、优势互补”的网络综合治理运行机制；对基层组织负责人、人大代表、政协委员而言，其具有本土特征，与当地群众最为贴近，应密切与网民的联系，在了解民情基础上更好地履行自己的职责，为民代言；对网络运营者、个人信息处理者、网络信息内容服务平台、互联网服务提供者、移动互联网应用程序平台等企业主体而言，应积极履行网络安全保护义务与网络治理社会责任，建立动态高效的网络安全风控机制，共享网络安全情报；对行业组织而言，应建立完善行业自律机制，开展教育培训和宣传引导工作，增强全社会共同参与网络生态治理意识；对广大网民而言，应增强数字化个体参与网络社会治理的意识，既要自律，也要充分发挥社会监督作用，共同维护网络社会秩序。

  

面对世纪疫情和百年变局交织的严峻形势，面对开启新征程的繁重任务，要 深刻认识党的百年奋斗的主题主线和重大成就，进一步增强中国特色社会主义道路自信、理论自信、制度自信、文化自信，深入学习党的十九届六中全会精神及《中共中央关于党的百年奋斗重大成就和历史经验的决议》，从百年党史中淬炼政治能力、汲取奋进力量、砥砺初心使命、增强斗争本领、锤炼纪律作风，奋力谱写网络强国建设新篇章。在网络安全领域，“共建”即共同参与网络社会建设，“共治”即共同参与网络社会治理，“共享”即共同享有治理成果。网络综合治理体系是宏大的社会系统工程，应充分整合政府、企业、社会组织、网民的力量，共同推动网络空间共建共治共享，推进国家治理体系和治理能力现代化，营造风清气正的网络空间，让广大人民群众在共享网络发展成果时有更多获得感、安全感与幸福感。系是宏大的社会系统工程，应充分整合政府、企业、社会组织、网民的力量，共同推动网络空间共建共治共享，推进国家治理体系和治理能力现代化，营造风清气正的网络空间，让广大人民群众在共享网络发展成果时有更多获得感、安全感与幸福感。
