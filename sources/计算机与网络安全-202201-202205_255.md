# 电力监控系统网络安全监测装置技术规范

本文件规定了电力监控系统**网络安全**监测装置的技术要求、外观接口、功能要求、性能要求、安全要求、版本管理要求以及标志包装要求等。本文件适用于电力监控系统**网络安全**监测装置的设计、研发、生产和应用。  
按照“监测对象自身感知、**网络安全**监测装置分布采集、**网络安全**管理平台统一管控”的原则，构建电力监控系统**网络安全**监视与管理体系，实现网络空间安全实时监控和有效管理。  
a）监测对象采用自身感知技术，产生所需网络安全事件并提供给**网络安全**监测装置，同时接受**网络安全**监测装置对其的命令控制；  
b）**网络安全**监测装置分布部署于调度机构、变电站、发电厂等地，实现对本地电力监控系统内监测对象的数据采集与处理，同时把处理的结果上送至调度机构部署的**网络安全**管理平台；  
c）**网络安全**管理平台部署于调度主站，负责收集所管辖范围内所有**网络安全**监测装置的上报事件信息，进行高级分析处理，同时调用**网络安全**监测装置提供的服务实现远程的控制与管理。  
**网络安全**监测装置应满足如下要求：  
a）宜采用非x86低功耗工业级硬件架构设计；b）采用经安全加固的操作系统；c）在故障、重启的过程中不引起数据重发、误发、漏发；d）有明显的接地标志；e）有安全警示标识；f）II型**网络安全**监测装置具备装置故障告警信号输出接点，装置运行灯灭时导通装置故障接点；g）II型**网络安全**监测装置采用无风扇、无旋转部件硬件设计。  
**网络安全**监测装置自身应具备基本的安全性，应满足如下要求：  
a）不得内置后门、不存在缓冲区溢出等安全漏洞；b）具备检测并抵御各种常见网络攻击的能力及抵御渗透攻击的能力；c）关闭通用的网络服务及端口；d）不使用http、https协议进行通信；e）采用基于调度数字证书的认证技术保证基线核查、命令控制、配置管理、软件升级等服务代理功能的安全性，详见附录E.3.2 。
