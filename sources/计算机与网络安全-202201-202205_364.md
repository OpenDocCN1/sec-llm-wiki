# 国资监管数据全生命周期安全管理研究报告

数据的生命周期可以分为数据采集、数据传输、数据存储、数据处理、数据交换和数据 销毁等6个阶段。  
一方面，国资监管业务涉及国资委机关、中央企业和地方国资委等组织机构。各组织机构均可自主建设内部系统和网络，自主管理内部数据的完整生命周期。而组织间的数据交换与共享行为又导致数据副本的所有权转移，在目标系统中产生新的数据生命周期。  
另一方面，国资监管业务的发展和完善使相关系统和网络不断演进。以国资委机关为例，在集中建设国资国企在线监管系统之前，各厅局已建成多套相对独立的业务系统，自主管理内部数据生命周期。建设国资国企在线监管系统的目 的之一就是：统一管理所有国资监管数据的各个生命周期环节，提高数据使用效率。因此，在国资监管系统的建设过程中，会出现业务自主管理和系统统一管理两种模式并存的过渡状态，进一步增加了数据生命周期的复杂性。  
国资监管信息化建设的时间跨度较大，不同历史时期、技术背景、业务需求条件下的业务系统存在较大差异，其所承载数据生命周期状态也不尽相同。  
随着国资国企在线监管系统的持续建设，国资委端和企业端的业务系统不断 演进，所承载数据的生命周期状态也随之变化。  
国资监管数据安全管理的总体目标是：整合和完善既有的网络和信息安全建设成果，建立资产价值导向的数据安全管理体系，综合运用各种技术及管理手段，形成与系统建设阶段相匹配的安全保护能力及可重复执行的标准过程，防控各种内外部数据安全风险，保证全生命周期数据价值利用的合规、可控，为国资监管业务的发展，提供有序、动态、可持续的数据安全保障。
