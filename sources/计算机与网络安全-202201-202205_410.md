# 零信任（综述、关键技术、应用场景、技术前瞻）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5OTk4MDE2MA==&mid=2655170135&idx=3&sn=17ea3bc9de76ad5fabeb0b70cfe30281&chksm=bc8533b88bf2baaef7ad171d53831b6a7fc00cd8e7593f8974270a6ef916dee13fb271f7a4d4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655170135&idx=3&sn=17ea3bc9de76ad5fabeb0b70cfe30281&chksm=bc8533b88bf2baaef7ad171d53831b6a7fc00cd8e7593f8974270a6ef916dee13fb271f7a4d4&scene=27#wechat_redirect)

零信任是近两年网络安全行业最热的名词之一，国外Palo Alto Networks、思科、Microsoft、ZScaler等公司推出零信任模型的产品或解决方案，美国总统拜登在2021年5月12日发布的《关于改善国家网络安全的行政命令》中明确要求美国联邦政府的网络安全”向零信任架构迈进” ，美国国防部在2021年4月份发布了ZTRA零信任参考架构模型（Zero Trust Reference Architecture），国内也有不下30家公司推出零信任产品或解决方案。

  

零信任模型提出的背景是云计算的兴起。云计算和移动办公重新定义了安全边界，员工和合作伙伴使用自己的设备远程工作，在企业网络之外访问企业数据。企业应用程序和数据从本地环境转移到云环境，新的边界不是由企业的物理位置定义的，而是扩展到承载应用程序、存储数据或访问企业资源的每个节点。

  

网络边界的泛化，使得传统的基于边界防御的思路已难以实现，我们就必须要改变安全防护的思想。零信任模型不相信防火墙之后的企业网络是安全的，假设存在漏洞，并验证每个资源请求，就像它来自不受控制的网络一样。无论请求来自何处或访问什么资源，零信任都采取“从不信任，始终验证”的原则。在零信任模型中，每个访问请求都经过强身份验证，在授予访问权限之前检查访问背景（上下文）和异常情况，在策略约束范围内授权。从用户身份到应用程序运行环境的所有相关信息都是用于防止违规的上下文。

  

从网络攻防实践来看，零信任模型也是更科学的安全防护思想，毕竟身份凭证窃取还是最常用的攻击方法，入侵用户终端，以经过身份验证的终端为跳板发动攻击也是最常见的攻击手段。

  

将零信任模型作为一种基本的安全理念应用到整个生产环境，这是通过对身份、终端、网络、计算、应用、数据六个基本要素实施零信任控制来实现，这六个基本要素每一个都是传感器、策略执行点和需要防御的关键资源。其中身份认证和授权活动在整个业务环境的多个关键位置进行，这些关键位置是零信任的策略执行点，包括用户、终端、网络、计算设施、应用程序和数据控制。各个执行点将日志发送至威胁事件管理平台，进行分析确定置信水平，以支撑执行策略，如果终端或用户的置信度得分高于分析控制的阈值，则有权查看请求的数据或使用所请求的功能。

  

软件定义边界SDP、增强的身份管理IAM、 微隔离MSG这三个零信任模型的基本技术之外，动态访问控制平面也是至关重要的组件，它是零信任架构中的 “大脑” ，也是目前业内提供的零信任产品或解决方案中最需要加强的部分。

  

零信任模型做为一种更先进的网络安全防护思想，在业内已基本达成共识，传统的安全产品和解决方案会经历一轮零信任思想的改造，VPN类产品首当其冲。密切贴合用户的使用场景，拥抱零信任，推动网络安全防护工作更上一层楼，是网络安全公司的不二选择。
