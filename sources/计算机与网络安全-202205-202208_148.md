# 网络安全态势观察白皮书

从威胁的角度分析了网络攻击态势，从信息资产角度分析了安全漏洞的变化，结合全球网络安全热点事件与重点案例进行了深度剖析。并提出了做好我国网络安全保护工作的建。针对2021年全国网络安全事件进行了全面分析，对了解我国网络安全态势及发展有很好的参考价值。也能够让安全企业更好了解网络安全的市场方向，让科研机构找到企业的安全需求；让负责领导看到改进的主要领域；也为管理者制定 网络安全战略和政策提供了很好的依据。通过分析发现，由于企业内部员工安全意识淡薄，缺乏安全防护意识，轻信网上虚假信息，打开不明链接导致用户信息泄露，被植入病毒木马等安全事件时有发生，企业可以通过定期进行安全意识培训、应急演练等方式，提高员工安全意识，保护自身及企业安全，减少因人为因素导致安全事件的发生。勒索攻击近年来比较猖獗，通过勒索病毒加密客户重要数据导致无法解密，或者需要支付超过企业支付能力水平的赎金才能解密数据。因此定期做好数据备份，避免因勒索攻击而导致重要数据丢失显得十分重要。备份可以是本机、异机或异地（云端）备份，通常勒索病毒会遍历所有磁盘并加密文件，同时删除Windows 的阴影卷，删除备份历史快照，所以本机备份恢复的可能性很低。异机备份如果是通过本地磁盘到共享磁盘进行文件或者数据拷贝的方式实现，勒索病毒同样有可能加密了备份文件。与感染病毒的主机不在同—局域网内的异地备份系统最能在此时发挥作用。企业或个人日常进行合理的数据备份，是最有效的灾难恢复方法。网络攻击时效性与安全漏洞爆发越来越紧密，—个漏洞爆发通常会在很短的时间内被黑产利用。因此企业需要制定详细的漏洞管理流程，尤其在企业有庞大数量的主机需要管理时，需要具备完善的安全管理系统完成漏洞修复工作。同时定期通过黑灰盒对相关资产进行排查，及时发现安全隐患。网络中的泄密、攻击、病毒等攻击行为主要通过网络边界实现，通过分析多起事件发现，攻击者通过网络空间搜索引擎发现网络边界资产，并以此为切入点获取相关权限进行横向攻击，最终导致大量资产失陷。因此边界资产防护需要重视，企业需要制定完善的安全策略，划分安全域，根据不同安全域部署不同的防护设备。
