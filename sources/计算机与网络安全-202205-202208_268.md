# 广东省新型数据中心发展白皮书（2022年）

数字经济的发展离不开数据中心的同步配套，数据中心是海量数据的承载实体，是实现数字信息的集中计算处理、传输交换以及存储管理的物理空间。广东省数字经济快速发展对数据中心需求不断加大的同时，数据的安全问题也随之而来。  
广东省通信管理局持续开展电信和互联网行业**网络安全**及**数据安全**专项检查工作，对省内各基础电信企业、互联网企业、域名从业机构、移动应用商店、工业互联网平台和标识解析节点企业、相关网络运行单位开展**网络安全**及**数据安全**专项检查。要求相关存在风险企业完成整改及反馈，对于逾期不整改、不反馈的相关企业采取相应行政处罚措施。不断提升相关企业网络**信息安全**意识，增强问题发现和整改能力提高技术水平切实提升**网络安全**防护及保障能力。2022年2月工业和信息化部发布的《国家新型数据中心典型案例名单（2021）》中，广东省深圳宝安云计算数据中心入选 “国家新型数据中心（安全可靠）” 类，成为广东省首个获得次殊荣的数据中心。  
作为关键基础设施的支持系统，广东省数据中心及其采用的核心机电设备应满足[**《中华人民共和国网络安全法》**](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655113238&idx=4&sn=7a6aeba5889cedfd8cd21ca949ce6dbb&chksm=bc864df98bf1c4efdc987d135c7571718de3351fdd3c22ba266e90e0f2162ee811ee420143f4&scene=21#wechat_redirect)的相关要求，达到 [**《关键信息基础设施安全保护条例》**](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655165233&idx=6&sn=db2bc77f9cb411f211bd6754194f20c7&chksm=bc8506de8bf28fc83ce9c2440b93d3863955457d3504f89ccbcf2bd63b051abd2c513ea07d6e&scene=21#wechat_redirect)的基本要求，并进行相关的安全认证。数据中心基础设施应满足国家[**《网络安全法》**](http://mp.weixin.qq.com/s?__biz=MjM5OTk4MDE2MA==&mid=2655154609&idx=1&sn=36d7124b6cd12b799ff3d38d1f43cb1c&chksm=bc85ec5e8bf26548f2e00e164a4eeb83f4eff758ef49cf186d3a45ebfadfd72c599aacc12d41&scene=21#wechat_redirect)相关**网络安全**，系统自身应进行有关**网络安全**设计。智能硬件设备应至少通过利用**防火墙技术，远程访问使用VPN加密通道，防暴力破解、 防DDoS攻击，安全协议加密通道**等手段，实现网络拦截。系统应采用高安全设计，对操作系统、数据库、管理软件进行加固，管理软件与采集器之间传输通道须采用加密传输，对于敏感数据和密码等应加密保护。系统应该对硬件或软件的敏感数据进行保护，数据进行加密保护、加密传输，并不存储在应用程序的内存中。系统应使用业界公认标准安全的协议来登录后台服务器或访问设备，安全协议参考SSHv2、HTTPS、FTPS、 SNMPv3、TLSv1.1、TLSv1.2。系统的安全事件、系统情况、操作指令应做到可追溯，可查，可诊。系统应对**网络安全**特性进行测试提供中国国家认证认可监督管理委员会批准的相关机构的测试合格报告。并使用至少三种主流杀毒软件对系统进行病毒扫描。另外，数据中心作为数字经济发展的基石，对于我国生产总值拉动作用巨大，信息技术应用创新发展作为国家战略，保障核心技术自主可控，从本质上解决安全问题。
