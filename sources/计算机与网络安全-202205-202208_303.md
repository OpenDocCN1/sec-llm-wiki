NFT 是 Non-Fungible Tokens 的缩写，翻译为非同质化通证。关于非同质化通证的大多数讨论都是从引入可替换性（fungibility）开始，非同质化通证是相对于可替换的、同质化通证（同质化的通证也叫代币）而言 的。人们熟悉的基于区块链记账的比特币 BTC、以太币 ETH 等虚拟货币（同加 密货币），就是同质化代币（Fungible Tokens，FT）。两枚比特币可以相互替 代，本质上是一样的，而两枚 NFT 则不可以相互替代，它们就像民法中种类物 与特定物的区别。NFT 与 FT 都是区块链技术上的两类应用。NFT 起源于以太坊 ERC-721 通证 标准，目前仍然是最常见的 NFT 通证标准。除此之外还有其他 NFT 通证标准， 如 Enjin 开发的基于以太坊建构的 ERC-1155，ERC-1155 是电子游戏通证新标 准。NFT 可以存储在合适的加密钱包中，可以通过交易市场进行发行和交易。
