# 普京下令确保俄信息安全：“不友好”国家防护设备将被禁用

据塔斯社莫斯科5月1日报道，俄罗斯总统普京签署了一项关于为确保俄信息安全而采取额外措施的法令，法令旨在“提高俄联邦信息资源运行的稳定与安全”。

  

报道称，普京责成联邦行政机关、国家基金、国有企业和战略企业领导人赋予二把手保证信息安全的权力，包括监测、预防计算机攻击、消除相关后果和应对相关事件的权力。各机关（机构）领导人对所在单位信息安全保障负有个人责任。此外，上述机关（机构）还应设立信息安保部门。

  

普京要求，“保证联邦安全局官员通过使用互联网电信网络的方式，顺利获取各机关（机构）拥有或使用的信息资源”。若联邦安全局或联邦技术和出口管制局认为有必要采取措施保证信息安全，必须保证这些措施立即得到执行。

  

普京责成政府“确定须评估信息系统防护水平的机关（机构）名单，负责评估的机构要具备联邦安全局或联邦技术和出口管制局认证的相关资质”。名单中所列的机关（机构）必须评估自身信息系统的安全性，并在2022年7月1日前向政府递交报告。

  

报道称，该法令指出，俄联邦安全局应对检测、预防计算机攻击和消除相关后果的各个国家系统中心进行认证。

  

报道还称，普京特别指出，“自2025年1月1日起，禁止各机关（机构）使用对俄法人和自然人采取不友好行动的国家生产或制造商直接或间接受其控制的信息防护设备”。
