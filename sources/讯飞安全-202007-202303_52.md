# sysupdateminer挖矿木马分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMDE5NDg1MA==&mid=2247485154&idx=1&sn=639eb31a84165ec2ab9886840b434abb&chksm=9681a8afa1f621b972a124463717bebc3c96409ccd0991287301c99fdc2a186417d59d5973a2&scene=126&sessionid=1681381474#rd](http://mp.weixin.qq.com/s?__biz=MzIwMDE5NDg1MA==&mid=2247485154&idx=1&sn=639eb31a84165ec2ab9886840b434abb&chksm=9681a8afa1f621b972a124463717bebc3c96409ccd0991287301c99fdc2a186417d59d5973a2&scene=126&sessionid=1681381474#rd)

  

**01**

概要

  

近期讯飞安全团队检测到一起sysupdateminer挖矿木马。该挖矿木马会利用SSH免密登录/爆破、REDIS未授权访问/爆破在内网进行扩散，

同时还会随机性扫描公网的redis端口利用redis未授权/爆破方式获取公网机器的redis权限，进而在公网进行扩散。

![](../Images/ffc8069ce668fe6c479878e7dd6edae3.png)

受感染机器扩散形式图

  

当机器被感染后会卸载阿里云安骑士和腾讯云镜，同时还会关闭主机的selinux和防火墙，拒绝非127.0.0.1以外的机器连接redis。

  

为避免恶意程序被发现会替换掉ps、top等程序，过滤挖矿程序和扫描程序；同时为了实现持久化控制还会在多个位置写入计划任务实时的从控制端获取最新脚本，以及在主机写入ssh免认证登录密钥。

**04**

处置过程

  

通过上机排查和对样本分析，需要对受感染的机器执行如下处置恢复操作。

PS：可能存在处置项不存在的情况，每个机器上产生的文件可能不完全一样，下面仅供参考

  

**1，删除文件：**

修改恢复文件可编辑属性

./busybox chattr -ia /etc/zzh

./busybox chattr -ia /etc/newinit.sh

./busybox chattr -ia /etc/init.sh

./busybox chattr -ia /etc/is.sh

./busybox chattr -ia /etc/rs.sh

./busybox chattr -ia /root/.ssh/authorized\_keys

删除下载的文件和脚本

find / -name call.txt | xargs rm –rf

rm -rf /etc/newinit.sh

rm -rf /tmp/newinit.sh

rm -rf /etc/init.sh

rm -rf /etc/is.sh

rm -rf /etc/rs.sh

rm -rf /etc/zzhs

rm -rf /tmp/zzhs

rm -rf /etc/zzh

rm -rf /tmp/zzh

恢复被修改的操作系统命令

mv /bin/ps.original /bin/ps

mv /bin/top.original /bin/top

mv /bin/pstree.original /bin/pstree

删除过程中产生的文件

rm –rf /tmp/.ice-unix

rm –rf /var/tmp/.ice-unix

rm -rf /tmp/ipss

rm -rf /tmp/hxx

rm -rf /tmp/ps

rm -rf /root/.tmp00/bash

rm -rf /var/tmp/kinsing

rm -rf /tmp/kdevtmpfsi

  

**2，杀死进程：**

./busybox ps -ef | grep zzh | xargs kill -9

./busybox ps -ef | grep masscan | xargs kill -9

./busybox ps -ef | grep pnscan | xargs kill -9

./busybox ps -ef | grep hxx | xargs kill -9

  

**3，清理的计划任务：**

echo " " > /var/spool/cron/"$USER"

echo " " > /etc/cron.d/zzh

echo " " > /etc/crontab

echo " " > /var/spool/cron/root

echo " " > /var/spool/cron/crontabs

  

**4，修改hosts解析：**

chattr -ia /etc/hosts

清理/etc/hosts文件中的异常绑定内容

  

**5，清理免密登录：**

echo "" >> /root/.ssh/authorized\_keys

  

**6，恢复主机selinux和防火墙：**

ufw enable

setenforce 1

echo SELINUX=enable >/etc/selinux/config

  

**05**

加固方式

  

1，修改系统可登录账户的密码

2，增加redis认证机制、修改redis密码、白名单限制

3，开启ssh登录认证机制，限制白名单登录

4，增加登录失败锁定限制
