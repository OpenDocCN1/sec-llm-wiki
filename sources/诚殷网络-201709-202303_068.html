二（2）. 培训内容介绍

 

本次培训为期3个月总共学习5篇内容，其中分为：

 

u 基础篇

u 技能篇

u 系统篇

u 防御篇

u 应急篇

 

基础篇内容主要讲解关于学习网络安全所需要的基本知识，例如：

1. 如何搭建一个网站？

2. IP地址基础知识

3. 端口基础知识

4. 状态码+Cookie信息收集

5. 等等等等等知识

 

基础知识是在学习过程中非常重要的内容，学员必须经过基础培训才能进入到其他篇章。

 

技能篇是在基础篇学习完毕后的一个新篇章，该篇章主要讲解了各种漏洞的挖掘与利用，例如：

 

l 越权攻击漏洞

l URL跳转漏洞

l 弱口令攻击漏洞

l 逻辑漏洞

l CSRF跨站攻击漏洞

l XSS攻击漏洞

l XSRF组合攻击漏洞

l SSRF攻击漏洞

l 未授权访问与设计缺陷漏洞

l 逻辑之支付漏洞

l SQL注入攻击漏洞

l 任意文件上传漏洞

l 命令执行漏洞

l 云WAF + 软WAF讲解

 

以上技能则会在1个月以内给学员讲解如何挖掘，以及深入利用的思路，例如：

1. XSS存储Httponly又该如何渗透？

2. 越权攻击面对多种类型网站那些地方是最容易出现漏洞的？

3. 弱口令又分为那两类？存在验证码又该如何爆破（非打码）？

4. Csrf+XSS的联合利用？

5. 等等等各种思路。

 

系统篇也叫后渗透篇，是需要学员学习完技能并且能独立挖洞的进阶篇章，该篇章主要讲解：

 

l CMD命令讲解

l 权限继承讲解

l 系统权限讲解

l Exp提权讲解

l 1433+3306提权讲解

l 过软WAF提权

l 提权经验介绍

l JS脚本维持

l 脚本维持

l 系统后门维持

l 权限分配

l 防火墙讲解

l 危险函数

l 危险组件

l 木马查杀

l 后门查找

l 日志分析

 

总的来说既是让学员知道黑客是如何通过网页入侵到你的服务器或者电脑主机。

 

代码篇文能 ”文能提笔安天下 武能上马定乾坤” 作为一名合格的安全研究人员代码是必不可少的学习内容，我们可以通过PHP代码写出一套商城或者一套BBS更加能让我们知道漏洞产生的原因，以及修复的方法，Python则能帮助我们写出简便快捷的工具，减少人力劳动的输出。

 

高阶篇也叫做内网篇，该篇章需要学员在完成了技能篇+系统篇+代码篇才能进入的新篇章，该篇章从 远程控制-->>木马免杀-->>系统漏洞-->>社会工程学-->>内网渗透。

 

《如果所有篇章学完并且学的都不错，恭喜你已经踏入基础的大门。》
