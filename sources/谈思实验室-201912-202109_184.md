# 《智能网联汽车预期功能安全场景库建设报告》正式发布

**为建立完善且合理的预期功能安全测试场景库，实现对智能网联汽车预期功能安全的系统、有效、快速测试，由中国智能网联汽车产业创新联盟预期功能安全工作组发起，清华大学与国汽（北京）智能网联汽车研究院有限公司牵头编制的《智能网联汽车预期功能安全场景库建设报告》（以下简称“报告”）于近期正式发布。**

  

报告由工作组联合行业37家单位的共同编制。报告通过对智能驾驶现有感知技术、定位技术、决策方法、控制方法、人机交互、通信技术等进行调研与局限性分析，得出对应的智能驾驶预期功能安全测试需求；并基于以上测试需求，设计了面向智能驾驶预期功能安全测试的“7层架构”格式的虚拟场景框架。  

  

![](../Images/6b643b075e6abeb6d8797dc9ceee5c5a.png)

框架综合考虑了现有智能驾驶系统设备功能局限、算法缺陷以及人员误用等问题，并参考Pegasus项目，覆盖了传统智能网联汽车道路、交通设施、道路和设施临时改变、交通参与者、气候环境、通信信息这六层结构，为适应预期功能安全场景测试需求，在已有基础上增加了智慧交通设备，如路侧传感器、路侧通信设备、路侧信息处理单元等元素，同时，该框架添加了第7层智能驾驶层，包含智能驾驶移动平台即车辆，车载设备，驾驶员等元素，用以构建智能网联汽车预期功能安全场景。

![](../Images/1e82f8eb494018c7be8dbbd01744ad77.png)

![](../Images/d4760f4bda576b08d59838e1b60d4924.png)

报告聚焦智能驾驶预期功能安全虚拟仿真场景研究与设计，可为智能驾驶预期功能安全测试内容的制定和测试用例的设计提供参考，还可用于智能驾驶系统运行设计域边界的量化描述。

智能网联汽车预期功能安全工作组（以下简称：工作组），由汽车工程学会、中国智能网联汽车产业创新联盟、清华大学、公安全部道路交通安全研究中心、公安部交通管理科学研究所、国汽（北京）智能网联汽车研究院有限公司等24家单位联合发起成立，中国工程院院士、清华大学教授李骏先生担任该工作组组长。工作组组织智能网联汽车产业优质企业及相关机构，充分利用行业丰富资源，推动我国预期功能安全技术研究与创新；促进我国预期功能安全测试评价体系的构建；组织并推进我国认证体系和测评能力的建设，协同推进中国智能网联汽车预期功能安全技术的研究、创新、发展、推广及应用。关注公众号，回复“智能网联”，即可获得PDF全文。来源：智能网联汽车产业创新联盟
