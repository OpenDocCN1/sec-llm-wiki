  华为智能汽车解决方案 - HI


发布时间：2020年10月30日


HI LOGO的设计者：华为米兰美学研究所担纲设计


HI的寓意：以"Mirror（镜像）"为设计理念，体现人类生活与领先科技相互映照，科技赋能的品牌内涵。

 

HI的愿景：既代表华为在智能汽车领域的技术创新，也代表了商业模式的创新，同时，华为致力于把极智、愉悦、信赖的出行体验带给消费者，HI承载着"把数字世界带入每一辆车"的美好愿景。

图1. 华为智能汽车解决方案LOGO

HI包含的内容：1个计算与通信架构/5大智能系统/30+智能化部件


2
  1个计算与通信架构


1个计算与通信与通信架构包含：三大计算平台+三大操作系统
实现：软件定义 / 持续进化/ 常用常新

图2. 计算与通信架构（CCA）


三大计算平台：

  • 智能驾驶计算平台（MDC）

  • 智能座舱计算平台（CDC）

  • 智能车控计算平台（VDC）
三大操作系统：

  • 智能驾驶操作系统（AOS）

  • 智能座舱操作系统（HOS）

  • 智能车控操作系统（VOS）

华为提出计算与通信架构（CCA）+跨域集成软件堆栈（VehicleStack）构建数字系统。该系统包含两层，最下面一层是基于区域的架构硬件层。在硬件和架构层面之上，华为定义了VehicleStack(整车级软件框架)，采用微服务和微插件，并基于服务理念而构造，为车企搭建可持续的盈利模式。

图3. 华为CCA + VehicleStack


3
  5大智能系统


5大智能系统包含：智能车云、智能网联、智能座舱、智能驾驶、智能电动

华为智能汽车延续“云-管-端”架构：

  • 云：智能车云

  • 管：智能网联

  • 端：智能驾驶、智能座舱、智能电动


3.1 智能车云

智能车云服务2.0（IVCS 2.0）包括四大子服务方案：自动驾驶云服务（HUAWEI Octopus）、高精地图云服务、车联网云服务和V2X云服务。


自动驾驶云服务：提供数据服务、训练服务、仿真服务
高精地图云服务：打造全国高精度动态地图聚合平台，华为并不打算自己来搭建高清地图。而是通过这一聚合平台，让提供高精地图的企业都在这个云服务上呈现。

车联网云服务：可以实现三电、智能驾驶、智能座舱等数字化部件的状态数据和故障数据的采集和存储，形成统一的智能车辆数据资源池，再基于云端强大的AI和大数据能力，深挖数据价值，实现数据资产货币化。

V2X云服务：除提供基础的V2X联接功能、设备管理、事件管理、数据管理等能力之外，还会为无人驾驶车队提供车队协同、路径规划、统筹调度等能力，实现了全域感知和全局策略控制。


图4. 智能车云系统

3.2 智能网联

打造智能网联解决方案 : 车内、车外高速连接;

  • 打造开放的端、云智能网联解决方案，让每一辆车永远在线，服务直达

  • 全球首款2G/3G/4G/5G全制式的V2X开放车载模组，使能伙伴开发专业产品

  • OceanConnect车联网联接管理云服务，全球接入，支持千万级车辆同时在线

  • 基于领先网络技术，打造车内1GE~10GE以上以太网络


图5. 智能网联解决方案


3.3  智能座舱

智能座舱解决方案包含三大平台：智能座舱计算平台(CDC)+鸿蒙座舱操作此贴（HOS）+ 智能硬件平台。


智能硬件平台，包括座舱模组、车载智慧屏和AR-HUD（增强现实-抬头显示）。


拥有的功能：强大的视觉识别能力、语义理解能力和AI技术，可以用自然语言交流，看懂用户的手势和表情，智能地为用户服务。ARHUD 可以把普通的挡风玻璃，变成一个70寸高清大屏，结合7.1环绕立体声，用户可以看电影、打游戏、开视频会议，打开智慧新视界。


图6. 智能座舱系统


3.4 智能驾驶
智能驾驶解决方案：智能驾驶计算平台MDC + 智能驾驶操作系统AOS + 激光雷达等感知层硬件

MDC平台搭档AOS系统，构造智能驾驶大脑；整合了支持服务框架、设备管理、工具链、信息安全、功能安全等平台层服务，为客户提供最优性价比的智能驾驶平台和方便、快捷的开发环境，供车企依据自身需求，灵活整合TierX或自研应用软件。

华为智能驾驶解决方案战略的三个维度：
  • 商业路线：从低到高循序渐进 - 按照场景，成熟一个，落地一个
  • 技术路线：以终为始统一架构 - 加速激光雷达和高算力平台的商用

  • 产业路线：作为增量部件供应商，与产业共赢

华为的高阶自动驾驶ADS不强调级别，强调场景功能：
1）高阶自动驾驶ADS采用了以终为始的设计思路，致力于打造中国道路场景下最好的高阶自动驾驶系统；

图7. 以终为始的统一架构

2）以L4级自动驾驶架构为基础，提供面向L4~L2+级自动驾驶全栈解决方案，传感器、中央超算、算法全面领先。
3）基于机器自我学习技术，每时每刻都在自我学习、自我进化，越开越聪明，成为消费者的专属好司机。

图8. 智能驾驶系统

3.5 智能电动

1）聚焦电动汽车，打造VDC智能电动平台，使能车企面向不同的用户偏好，创造差异化用户体验。

2）将网络能源产业链和技术优势引进智能电动汽车，打造mPower多形态电驱、高效车载充电产品。

3）华为 mPower 智能电动主要包括 BMS 电池管理系统、 MCU 电机控制系统、车载充电系统及车下充电模块。 

  • 基于PDDP电动数字化开发平台多物理场耦合AI仿真寻优算法，打造智能油冷散热技术。其核心动力部件采用浸入式油冷散热方式，高车速下冷却效果更优，提供更强的动力输出；

  • 提供业内独家全系800V高压快充解决方案，充电10分钟即可续航200公里，能够极大提升用户的充电体验。

  • 双电驱系统联动控制、冗余备份，可确保动力不丢失，保障驾驶安全；

  • 同时，通过AI及大数据分析，可实现电池异常提前预警，进一步提升用车安全。


图9. 智能电动解决方案
