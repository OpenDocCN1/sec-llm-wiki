 大众– VW.OS平台

1）2019年6月，大众集团公开宣布正式成立“Car.Software”车载软件开发部门，该部门将开发“VW.OS”汽车操作系统，同时负责推进软件开发平台战略；
2）为了使其客户无缝集成到大众的数字生态系统中，大众汽车正在增强其软件能力建设。
图1. 未来的软件能力需求
3）VW.OS 和新的EE架构将成为互联车辆的关键核心部分。

‍图2.未来互联网车辆的关键核心‍

4）VW.OS 有助于大众数字化品牌生态系统的建立，其目标是实现车辆、客户和服务统一的数字化平台（ODP）。
5）ODP（ODP，One Digital Platform）基于云技术，将生态系统中的外部合作伙伴与大众汽车的IT架构相连接。

 特斯拉– Version


1）特斯拉的操作系统Version基于Linux内核深度改造而成；
2）基于Kafka开源流实时数据处理平台，可支持信息娱乐系统（IVI）和驾驶辅助系统（ADAS）；
3）特斯拉使用Linux系统中的内核模块：安全增强型Linux，通过“访问权限控制”增加了操作系统的安全性。

‍

‍图4. 特斯拉操作系统Version迭代升级历程‍

‍


4）由于Version是采用开源Linux独立开发的OS，因此特斯拉不再依赖于软件供应商，而是由自己完全掌握软件堆栈；
5）自 2014 年首次在 Model S 上使用 Version 5 以来，特斯拉已通过 OTA 技术对其操作系统进行了多次重大升级 。

3
谷歌–  Android Automotive OS


1）谷歌先后以车机互联 APP - Android Auto 和 Android Automotive OS 入局汽车 OS 领域；
2）谷歌 2014 年开始布局汽车领域，并于当年发布车载系统 Android Auto。
3）2019年谷歌发布 Android Automotive OS， 此系统可直接应用于车载影音娱乐系统。

图6. 谷歌车载操作系统发展历程


Android Automotive OS是在原手机 Android 的系统架构基础上替换为与车相关的模块。主要包括包括：
1） Car App：包括 OEM 和第三方开发的 App；2） Car API 提供给汽车 App 特有的接口；3）Car Service：系统中与车相关的服务；4）Vehicle Network Service：汽车的网络服务；5） Vehicle HAL：汽车的硬件抽象层描述。
