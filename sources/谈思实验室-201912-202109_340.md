人工智能（AI） 作为全球科技和产业变革的关键驱动力，依靠强大的技术积累与创新，正进一步释放巨大能量。在各国政策的支持引导下，以谷歌、微软及百度等大型人工智能厂商为主导，人工智能持续与各种应用场景深度融合，催生出了大量的新技术、新业态与新模式。

  

近日，知名咨询企业沙利文公司发布了《 2019中美人工智能产业及厂商评估 》，重点分析了中美两国头部的AI厂商，并从AI技术储备、技术布局、技术生态与AI应用四大维度对各厂商进行综合评价。此外，本报告深度分析了中美人工智能产业技术、人才、政策等方面的近期动态，归纳出人工智能产业的最新发展趋势。

![](../Images/0dbd655174175587927448924ac81319.png)

# **中美人工智能产业概况**  

人工智能产业发展60余年，技术日趋成熟，产业布局和生态建设逐步完善，当前已进入深化产业赋能阶段，中美两国领衔发展 。

![](../Images/95faeae5bb6ccf92d6960c303be74cd2.png)▲人工智能产业发展历程

中国起步晚，但应用环境较好，人工智能正深度驱动中国经济智能化转型；美国在技术储备与布局领先，通过政策驱动保持全球领先地位 。

![](../Images/de8b2d8b537530fee974d9e5842532af.png)▲中美人工智能产业发展历程及特点

美国政府引导各界开展人工智能技术研究，但其隐私政策对数据使用带来限制，间接对美国人工智能产业发展造成一定消极影响 。

![](../Images/52549c8e2c8034eb3d59b17867d0f535.png)▲国家层面相关政策及影响

中国人工智能产业政策 ：国家政策从人工智能产业规划、创新平台建设及技术应用等方面引导产业健康、有序发展，推动中国人工智能应用环境及产业发展持续向好 。

![](../Images/792ec97ffac8458fc78f6eb0b41fa5b1.png)▲国家层面相关政策及影响

地方政策侧重于引导现代优势产业集群与人工智能技术能力的融合，形成多元AI生态，营造有利的人工智能创新及发展环境。

美国人工智能厂商较多，软硬实力兼具，大型厂商多综合布局AI产业，创业公司遍布基础层、技术层和应用层 。

![](../Images/3369df23d26d438df3a3c59cf8e606d0.png)▲美国人工智能厂商

中国人工智能企业以AI“国家队”和创业独角兽为主，其中“国家队”多综合布局技术与应用领域，创业独角兽多深耕垂直技术与应用市场 。

![](../Images/fa81bcbd985e0a6375fb9a957f8b719e.png)▲中国人工智能厂商

中美均从国家顶层设计整体推进人工智能发展，中国侧重资金和技术扶持，美国注重项目合作；美国整体技术实力全球领先，中国部分AI技术实力突出 。

![](../Images/374a6ea35c6d6475ce10e2fa436d4853.png)▲中美人工智能产业环境与技术基础

美国人工智能企业数量位居全球首位，中国位居第二；全球人工智能企业数量TOP10城市中，北京位列第一 。

![](../Images/e3700e1725f2862b4399c922f8820928.png)▲中美人工智能企业数量全球占比及数量（2018年中）

![](../Images/d08c343238c71e9fc7a520e569ec0fa6.png)▲全球人工智能企业数量TOP10城市分布（2018年中）

中美领衔全球人工智能领域人才分布，中国在人才总量、杰出人才数量与占比上均落后于美国，在人才培养上有明显差距，但人才吸引力正在增长 。

![](../Images/3946faa6d8480c08b0344d2b7b2a8635.png)▲中美人工智能人才质量对比

中国人工智能论文近五年在产出量和增速上大幅领先美国，整体论文质量仍有差距，但顶尖论文水平正逐步接近 。

![](../Images/a23c26b73b7b385ffa16e91792478d25.png)▲中美人工智能论文对比

中国人工智能专利申请数量大于美国，但国际专利较少，百度与微软分列中美第一，展现一定头部效应 。

![](../Images/79bda4adb983d739820b99d15ffcaddb.png)▲中美人工智能专利累计申请量对比

人工智能是中美一级市场热门投资领域，中国人工智能细分领域投资方向广于美国，投资轮次正在后移 。

![](../Images/ec3d65323b529256bbf99b7e59f346d9.png)▲中美人工智能投资额与投资笔数（百万美元）

![](../Images/77158050a5d1040394f1e6125f36771f.png)▲ 中美人工智能投资方向对比（2019）

![](../Images/ac9794047bf2190d379d9df42bde3d91.png)▲ 中美人工智能投融资A轮及以前比例（2019）

美国AI产业整体领先，中国紧随其后。中国AI整体发展相对偏弱，但部分领域的顶尖技术已能与美国对齐，且国产化趋势明显 。

![](../Images/53b192b92948da3110b5eb24551dadf2.png)▲中美AI产业差异

![](../Images/afe95645c40144b0cc464e8c1547c269.png)

# ** 中美主要大型人工智能厂商**  

百度在中国厂商中一马当先，并在全球市场位于前四名，谷歌稳居全球AI厂商首位 。

![](../Images/65e79f6732c0b402776ea8e49a4d9151.png)▲中美人工智能厂商实力对比

技术储备、技术布局、技术生态与AI应用基本概括了企业人工智能布局的所有维度，能够全面体现头部企业的AI实力 。

![](../Images/9413f4b046f94b8c13e5588db0cde3c3.png)▲中美人工智能厂商对比评价模型

中美人工智能厂商实力仍存一定差距，美国厂商普遍在技术储备、布局与应用层面实力强，中国厂商在应用层面实力突出 。

![](../Images/a27741425fd828d7c78b483502e5911b.png)▲中美AI厂商实力对比

谷歌稳居第一，微软亚马逊紧随其后，而脸书与IBM分别由于生态与技术深度的欠缺稍显落后 。

![](../Images/4a3e9e9ae3a5dcb84978163c06d77205.png)▲美国AI厂商

## **1、美国AI厂商**

谷歌拥有世界顶尖科学家团队，重视基础科学研究，使其技术储备优势较大，同时创新能力出众，使其在技术布局上全球领先 。

![](../Images/6a7467f9fbd75e10206d5df343b357e4.png)▲谷歌综合技术水平

众多的优秀开源项目与活跃的一级市场投资使谷歌拥有繁荣的AI生态；谷歌以“AI+硬件+软件“的形式实现较高的AI商业化水平 。

![](../Images/bf59521e0d09fc869b7d520db74b9eed.png)▲谷歌AI布局

卓越的人才储备及专利储备使微软在技术储备名列前茅，也促使其在技术布局的广度与深度均有领先 。

![](../Images/8be5132fd66bf38d60f21f1b765e49a3.png)▲微软综合技术水平

微软以智能云为核心实现AI赋能，为企业或组织数字化、智能化转型提供解决方案，同时构建繁荣度较高的AI生态 。

![](../Images/2e22817c958d44d04eb0fd83029f3dfb.png)▲微软AI布局

亚马逊的研发投入居全球首位，为AI技术储备奠定较好基础；在AI技术布局方面， AI芯片技术实力突出，具有较强的竞争优势 。

![](../Images/32acf82370995f6d7e7806cabae13c0d.png)▲亚马逊综合技术水平

亚马逊在生态建设上以云计算为核心， 以Alexa为AI服务入口，对内外赋能，未来将专注人工智能云，促使AWS应用服务更加全面、智能化 。

![](../Images/b7ab7e2287f73c4d90b3cb564b169b59.png)▲亚马逊AI布局

IBM是人工智能发展的先驱，得益于自身软件积累和基础科学研究， AI技术储备较为完备，并围绕Watson全面布局AI技术 。

![](../Images/7477a68be56ed676b4acfb5fc6121612.png)▲IBM综合技术水平

IBM拥有众多合作伙伴，提升AI生态繁荣度，应用层面已深耕医疗与金融领域，并基于行业实践积累企业服务优势，未来将持续赋能各行业 。

![](../Images/b41c66a20850f3b8f2ee20bfcf37be36.png)▲IBM AI布局

脸书技术储备相比其他厂商较少，但由于图片与文本数据积累较大，在计算机视觉与自然语言处理等技术优势明显 。

![](../Images/29fd7898f60ad24cd38247b64c97eea4.png)▲脸书综合技术水平

脸书由于云服务的缺失，较其他美国厂商在生态上稍显不足，但AI赋能自身业务程度较高，且数据积累较多， AI应用落地潜力大。

![](../Images/366ef50eddc6fe9b375d6d13f4fd538f.png)▲脸书AI布局

## **2、中国AI厂商**

作为中国首家布局人工智能的企业，凭借AI技术储备和技术布局的先发优势，百度一马当先，携手阿里、华为、腾讯等共同推动中国AI产业发展 。

![](../Images/caaab816b9268d3d6100fc69a7d282cd.png)▲中国AI厂商

百度凭借扎实的AI技术储备，全面布局AI技术，打造软硬一体的人工智能大生产平台，是中国人工智能技术领域的先行者，综合技术实力排名第一 。

![](../Images/7dd8823511629a1f23fd8f1b3bcbe2d5.png)▲百度AI综合技术水平

百度AI生态繁荣度高， AI开放平台不断完善；AI应用方面凭借布局深度与广度实现较高综合商业落地水平，未来持续推动产业变革 。

![](../Images/87cbef4f3473bc104bec02172c79e976.png)▲百度AI布局

阿里巴巴在研发人员占比、研发金额等方面突出，为AI技术储备提供基础；AI技术布局层面，在语音识别、边缘侧芯片等技术领域具有一定优势 。

![](../Images/be47920633c39384b82cc6913a7e7afb.png)▲阿里巴巴AI综合技术水平

阿里以云计算为基础，完善AI开放平台，并积极对外投资繁荣AI生态；在应用层面以ET大脑为核心，拓展至IoT各领域，实现“AI+IoT”全面落地 。

![](../Images/4ca6f412b23aeb62882340a408078fab.png)▲阿里巴巴AI布局

华为的人才资源、研发实力为其AI技术储备提供潜在发展基础；技术层面，华为在机器学习框架方面持续发力，自研AI芯片算力强 。

![](../Images/07f2314fe908daa923e470beb87fbc61.png)▲华为AI综合技术水平

华为基于在ICT领域与智能硬件领域的积累，拥有丰富的B端、 C端与G端客户资源，利于其丰富AI生态、实现AI全栈全场景落地 。

![](../Images/d867d9186dffda27652fb6e2d9cd08a8.png)▲华为AI布局

腾讯AI顶会表现活跃、 AI专利数量丰富；在技术布局层面有三大实验室加持，专注视觉与语音研究 。

![](../Images/94b26855d76aeb5b937a6c61979b17e0.png)▲腾讯AI综合技术水平

腾讯主要开放视觉和语音AI能力，依托云服务进行生态拓展；应用层面以智能家居和泛娱乐为主要落地领域，未来将进一步基于自有生态拓展落地场景 。

![](../Images/4ce1231af675aef56ee0cf20d7ac1df0.png)▲腾讯AI布局

![](../Images/85b041b5ca2108e8ab8bf0bb14e6b91c.png)

# ** 人工智能产业趋势洞察**  

** 趋势一：人工智能底层核心要素算力提升、数据处理方式优化 。**

未来人工智能芯片将从通用芯片向专用芯片发展，数据处理方式继续优化，由人机协作向全面机器化演变，处理更为高效

![](../Images/ca478362d4a7a2d50ecd2daa6ccbeb4a.png)▲AI产业趋势1

**趋势二：人工智能技术使用门槛大幅降低 。**

自动化机器学习将降低AI技术使用门槛， AI技术的潜力得到释放，企业AI部署将呈现自动化、便捷化，“普惠AI”时代来临 。

![](../Images/b5bb439f8d7b7a79d4d622e49decbf7d.png)▲AI产业趋势2

**趋势三：人工智能边缘应用将进一步拓展 。**

5G、物联网、边缘计算技术及AI的协同发展将推动AI能力从云端数据中心移动到边缘位置，未来AI边缘计算需求增加，数据边缘端处理将成为趋势 。

![](../Images/6369efc8f9edf159d51a9d54f2e81f31.png)▲AI产业趋势3

**趋势四：人工智能在部分数据量庞大的应用场景渗透加快 。**

目前AI已在诸多场景中应用，未来会在金融、安防、制造、医疗、交通等数据量巨大的领域加速渗透，这一趋势在拥有海量数据资源的中国将尤为明显** 。**

![](../Images/f52437e08e13e7edfaca8784182c4865.png)▲AI产业趋势4

**趋势五：人工智能厂商的安全意识与自主能力大幅提升 。**

随着对技术自主可控意识的持续提升，未来中国AI厂商将更加注重自主研发，以实现AI应用领域安全发展，百度等厂商推动作用明显 。
