# 对话李斌：蔚来中国总部落户合肥 对双方都是很合理的选择

2月25日，蔚来智能电动轿跑SUV EC6量产项目在合肥江淮蔚来先进制造基地启动。智能电动轿跑SUV EC6是蔚来在合肥江淮蔚来先进制造基地进行量产的第三款车型，于2019年NIO Day首次亮相，预计于2020年7月公布价格和配置，9月开启交付。  

  

![](../Images/afdeea3f0ae4da9500a53629e3ba4622.png)

  

**当天早些时候，在位于江淮蔚来先进制造基地里的蔚来中心（NIO House），蔚来与合肥市政府签署了蔚来中国总部落户合肥的框架协议。**此后安徽省与合肥市领导一行还观看了蔚来换电站现场演示，并参观了EC6 量产项目生产线。  

  

  

根据官方披露，蔚来中国总部项目计划在合肥建设蔚来中国总部及研发、生产基地，打造以合肥为中心的中国总部运营体系。合肥政府将通过指定的投资公司并联合市场化投资人对蔚来中国总部项目进行投资，预计投资总额将超百亿。

  

![](../Images/7421cf3597dea02eda43e16517f7c18f.png)

  

关于此次与合肥市政府签署的框架协议，蔚来创始人、董事长、CEO李斌在与《一线》独家对话时说，蔚来与合肥的接触有一段时间，真正比较快的启动是元旦之后的事情，到今天就正式签署框架协议，速度确实很快。  

  

李斌表示，**此次签署的是框架协议，项目的具体细节还在洽谈制定中，双方计划在2个月内完成最终的投资协议签署。**

  

李斌表示，此次合作将会是一个双赢的局面。4年来，蔚来在合肥基地投入了大量资源，对地方社会经济发展做出贡献，带动了合肥上下游产业链同步发展。合肥选择蔚来做为重点支持企业，是合肥产业布局的合理选择。智能电动汽车是国家战略新兴产业，也是合肥正在进行战略布局的重要产业，蔚来的落户将成为安徽省汽车产业转型升级的名片, “互联网+先进制造”的标杆。

  

![](../Images/b9c2fdfc4bd387dc55db8c64e064f132.png)

“经过近20年的发展，安徽已经成为汽车制造行业的重镇。也正是因为安徽省有非常好的产业基础，促成此次合作框架协议的签署。合肥在长三角一体化的区域经济优势，有利于蔚来在长三角高效进行产业布局。同时，这里开放的营商环境也很适合蔚来的长期发展。”

  

李斌认为，江淮蔚来先进制造基地的良好运作为蔚来在合肥的发展奠定了基础。**蔚来已在合肥进行了深度的产业布局，蔚来中国总部落户合肥有利于运营效率的提升，以及长期的稳定发展。**

  

对于此前有媒体报道吉利将入股蔚来一事，李斌回应称，不知道是哪里来的传闻，不对此做评论。

  

  

![](../Images/1b8c8ce7154430c9e8ea49cdb9d7ed06.png)

  

**以下是《一线》独家对话李斌的主要内容：**  

  

**提问：****这次合作洽谈是从什么时候开始的？**

  

**李斌：**蔚来与合肥的接触有一段时间，真正比较快的启动是元旦之后的事情，到今天就正式签署框架协议，速度确实很快。

  

**提问：****疫情有对这次协议达成造成影响吗？**

  

**李斌：**毕竟是讨论协议，不像是复工，因此我们远程讨论和交流也非常方便，并没有太受疫情影响。安徽省的领导、合肥市的领导，他们对这件事都很重视，工作团队也非常专业、高效，所以达成协议也很快。一手抓疫情防控，一手抓经济，他们办事效率确实很高。

  

**提问：****为什么是合肥？****选择落地合肥对你们有什么好处？**

  

**李斌：**选择合肥，对双方都是非常合理的事，我们主要的团队在华东，合肥本身这几年在长三角的发展都非常好，合肥GDP接近1万亿元人民币，整个安徽的经济也发展得非常好。

  

我们这几年本身通过江淮蔚来先进制造基地已经在合肥有很深的布局了，我们有200多同事本身就常驻在合肥。合肥有自己的人才优势，不光是汽车相关的，包括人工智能、软件等各个方面，人才聚集优势都比较明显。

  

我们如果去别处，就会涉及到我们在合肥的工厂产能还没有用满的情况下，过早地去开工建设别的工厂，也不合理。

  

我们这几年与安徽省和合肥市的政府部门打交道，发现安徽和合肥的整个营商环境非常好，他们的工作作风比较高效、务实、充满创新意识，合肥其实在很多方面都已经是隐形冠军了。

  

经过近20年的发展，安徽已经成为汽车制造行业的重镇。也正是因为安徽省有非常好的产业基础，促成此次合作框架协议的签署。合肥在长三角一体化的区域经济优势，有利于蔚来在长三角高效进行产业布局。同时，这里开放的营商环境也很适合蔚来的长期发展。从蔚来角度来讲，多方面的考虑，合肥都是非常合理的选择。

  

![](../Images/681228ec49418f325df1c79fa5881841.png)

**提问：****反过来，对于合肥市来讲，为什么要选择蔚来作为重点支持企业？**

  

**李斌：**支持蔚来，让蔚来中国总部落户合肥，对合肥也是非常合理的事，蔚来应该说是目前中国相对来讲最有竞争力的高端电动汽车品牌。如果去别的地方落户，也必然涉及到一些产业的转移、资源分散等。对于合肥来讲，在这个基础上，在这个时候支持蔚来，肯定是投入产出比最高的时候。

  

今天这个合作签署仪式，安徽省包括省委书记、省长等在内的6位常委都来到现场，对这件事确实非常重视和支持。基于他们对蔚来的了解，以及他们对产业布局战略发展的需要，双方确实谈得比较快，对双方都是特别合理的选择。

  

我觉得此次合作将会是一个双赢的局面。4年来，蔚来在合肥基地投入了大量资源，对地方社会经济发展做出贡献，带动了合肥上下游产业链同步发展。合肥选择蔚来做为重点支持企业，是合肥产业布局的合理选择。智能电动汽车是国家战略新兴产业，也是合肥正在进行战略布局的重要产业，蔚来的落户将成为安徽省汽车产业转型升级的名片, “互联网+先进制造”的标杆。

  

**提问：****此次签署的协议还是框架协议，最终协议预计要什么时候签署？****达成后会对现有业务布局进行调整吗？**

  

**李斌：**项目的具体细节确实还在洽谈制定中，双方计划在2个月内完成最终的投资协议签署，一切以最终合作协议为准。因为目前还是框架协议，后续产业布局的安排、调整，会根据最终协议以及公司发展的实际需要，来进行一个综合的考虑。

  

**提问：****这次框架协议提到的蔚来中国，与蔚来上市公司主体是什么关系？**

  

**李斌：**是上市公司的子公司。

  

**提问：****此次落地完成后，蔚来是否还需要引入新的投资方？**

  

**李斌：**从我们来讲，融资会是一个持续的过程。蔚来会通过各种方式进行持续的融资，美元融资我们会通过上市公司来做，蔚来中国打通人民币融资通道也是我们计划中的事，总体来讲我们还会有持续的融资计划来支持研发和用户服务体系的建设。
