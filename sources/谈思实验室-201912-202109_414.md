# 2030十大科技消费趋势：感知联网翻转数字感官体验

爱立信日前公布「2030年十大消费者趋势」呈现消费者对未来科技趋势的看法与预测，期望人类视觉、听觉、味觉、嗅觉以及触觉等感官互动的连接技术将对生活带来帮助，并且于现实生活实现崭新感官体验。

  

![](../Images/703d95e220e9195c64c12a0a4c7ce210.png)

  

爱立信消费者行为暨工业研究室负责人Pernilla Jonsson表示，该公司讨论目前智能手机网络连接沉浸式体验的转变，而这种体验正源于感官实现连接。这份报告以AR眼镜作为切入点，探索转变对消费者来说意味着什么。消费者预期人工智能(AI)、虚拟现实(VR)、增强现实(AR)、5G以及自动化技术实现的感知联网会对人们的日常生活带来巨大变化。  
   
消费者预测的2030年十大热门消费趋势包含：意念触发、声如其人、随心调味、数位气息、实感触觉、融合现实、去伪存真、后隐私时代消费者、联网服务催化永续发展，以及全感知服务。而感知联网的主要驱动因素包括沉浸式娱乐和在线购物、气候危机以及尽可能降低气候影响的相关需求。  
   
59%的消费者认为，未来只要想象出目的地，就能透过VR眼镜看到地图路径；67%的受访消费者认为将能够透过麦克风逼真模仿任何人的声音，甚至可以骗过家人。至于44%的消费者预期，未来将有装置能对食物进行数字强化，让任何食物尝起来都是最喜爱的味道；约60%的消费者希望能透过数字技术畅游森林或乡村，包括体验这些地方的所有自然气息。  
   
同时超过60%的消费者希望按下智能手机的数字图标及按钮时，屏幕能同时传达形状及质感；70%的受访者预期，至2030年时VR游戏世界将与现实真假难辨。此外，「假新闻」可望被终结—半数受访消费者表示，2030年提供全面事实审核的新闻报导服务功能将普及；半数受访消费者认为自己属于「后隐私时代消费者」，期望隐私问题能被解决。  
   
另一方面，60%的受访者认为感知联网发展将更易催化环境永续性；45%的消费者预期未来将会出现新购物体验，除了以往视觉，还能有运用听觉、味觉、嗅觉、及触觉甚至五种感官并用的数字购物商场。  
   
该报告为爱立信消费者研究室在全球范围内为期24年多的研究活动，主要参考2019年10月针对全球15个城市的进阶因特网用户所进行的一次在线调查结果。
