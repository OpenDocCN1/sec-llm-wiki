# 如何基于应用场景开展V2X仿真验证？

V2X作为智能网联汽车中的信息交互关键技术，同时也是汽车、电子、信息通信和交通管理等行业深度融合的新型产业形态。V2X技术通过将“人-车-路-云”交通参与要素有机地联系在一起，不仅可以支撑车辆获得比单车感知更多的信息，例如解决非视距感或容易受恶劣环境影响等情况，促进自动驾驶技术的成熟；另一方面还有利于构建智慧交通体系，例如解决车辆优先级管理、交通优化控制等情况，促进汽车和交通服务的新模式新形态发展。

  

车联网V2X仿真验证是车联网功能开发与路测传感器融合感知系统开发的关键环节，能在道路试验前对控制器功能进行验证，缩短产品开发周期。但是在实际交通环境中进行测试受到各种因素限制，**如何能够更为有效地开展V2X仿真验证呢？**

 

**![](../Images/da4a7d72b3b0022bd829fb6239927b8a.png)**

**开展基础：V2X应用场景相关标准**  

  

V2X仿真验证开展的基础是应用场景。目前V2X仿真应用场景主要参考由中国汽车工程学会发布的**《合作式智能运输系统 车用通信系统应用层及应用数据交互标准》**。该标准是国内第一个针对V2X应用层的团体标准，第一阶段(DAY 1)划分了17个测试项目，并对17个项目进行描述；第二阶段(DAY 2)在第一阶段的标准基础上，结合了V2X技术迭代与行业需求演进，定义了第二阶段的12个应用场景和9个新交互消息，进一步丰富了V2X应用场景，加速了V2X车联网商用落地。

V2X仿真测试不仅需要保证蜂窝通信模块的通信性能，同时需要保证V2X模块作为车辆“传感器”之一，高效且稳定的运行。所以，需要运用不同的测试方法和手段保证其有效性，包括射频性能测试、通信协议测试与硬件在环测试。V2X仿真测试系统可用于终端通信协议一致性测试、预警功能开环测试、闭环测试和HIL测试等研究，通过在实验室对真实场景再现，实现研发、测试与体验的互通互联。

  

中汽数据V2X仿真验证方案包括罗德施瓦茨、NI、是德等多种市面主流厂商设备，本文以基于NI设备的解决方案为例进行介绍。整套平台系统包括场景仿真软件、应用层数据协议栈及基于NI设备的平台系统。其中底层基于NI射频收发设备构建射频环境仿真功能，系统主要包括PXI机箱与控制器、GNSS模拟及接收模块、V2X信号仿真分析等模块。

**1.场景仿真软件**

  

基于成熟的场景仿真软件平台，比如Prescan、VTD、CarMaker等，实现基于DAY1及DAY2中描述的V2X典型场景（可以根据客户需求自定义场景），场景设计元素包含自车、远车车辆、其他交通参与者等模型，以及道路、环境及交通车流等。目前针对V2X仿真测试场景库一阶段16大类和二阶段12大类应用场景，已建成V2X仿真测试场景库：V2X仿真测试场景200多个，测试用例上万条。

  

![](../Images/0813cc249b4f31a628c5aee1d264ccbd.png)

图2 场景仿真软件及示意图  

  

**2.应用层数据协议栈**

中国汽车工程学会应用层标准遵循“消息集-数据帧-数据元素”三层嵌套式结构规则对应用层数据集进行制定；采用了ASN.1抽象语法进行定义，实现了跨平台和不同编程语言的兼容；考虑到射频性能，数据集交互的编解码方式遵循非对齐压缩编码规则UPER（Unaligned Encoding Rules），有效压缩空口通信数据包的大小。在第一阶段标准中定义了五大类基础消息集：BSM、RSI、RSM、SPAT、MAP；第二阶段在原有基础上进行拓展和提出新的消息体。中汽数据能够实现五类消息体协议栈的转化，方便设备间的通信与适配。

**4\. 仿真验证平台系统**

  

![](../Images/07207e796ab6285143c90af698db788d.png)

![](../Images/240f7c8ac24b0af2657a778e734b4ea0.png)  

图3 基于NI的平台系统  

 

V2X仿真验证系统通过将相关配套软件与NI PXI和USRP软件无线电（SDR）硬件相结合，在V2X控制器上向射频（RF）和全球卫星导航系统（GNSS）信道发送和接收真实信号，并通过网线连接交换机实现仿真数据传输。

  

V2X仿真验证设备硬件接口主要由网口、USB、时钟同步口、GPS 天线口、DP等接口组成。通过对接口进行设置，可实现空口与直连两种测试模式。

  

基于NI的硬件平台系统主要在PXIe机箱的框架上进行搭建，数据由USRP软件无线电设备采集后经多机箱扩展模块接口汇聚到PXIe机箱中，PXIe机箱上配置了PXIe高性能嵌入式控制器。定时和同步对于任何一个需要部署无线电设备的系统来说都是至关重要的，PXIe-66xx定时与同步模块可生成一个非常稳定且精确的参考时钟并提供一个数字触发信号，用于时钟和触发信号的分发，从而确保了整个系统的系统级同步，各个无线电设备同步进行数据采集和生成。另外通过使用PXIe-85XX模块实现了OBU等待测件与系统CAN信息的交互，形成完整的测试闭环链路。

 

**![](../Images/798dcd8396e0444cc646229062c58057.png)**** V2X仿真测试原理**  
  

V2X仿真测试系统通过场景仿真软件中构建三维虚拟交通场景测试用例，实时地显示测试场景中的三维信息及测试用例状态。同时场景中生成的数据经由协议栈实时传输至硬件部分，并动态生成 V2X信号。待测件主车的V2X车载单元接收到信号后综合自身信息(CAN信号)，V2X和GPS信息给出反馈和预警，完成硬件在环测试。**该系统具有以下亮点**：

  

**1.  全面性**：芯片-模组-OBU/RSU整个生命周期测试V2X方案；方案可扩展性强，从底层到顶层都开放API接口，相同的系统可实现性能仿真与指标测试，室内测试，外场测试和外场电磁环境分析。

  

**2.  灵活性**：方案基于软件定义无线电平台，从而支持后续协议升级；根据客户需求和测试项目可自定义测试系统，在灵活性和性价比上相比台式仪表和传统方案具备优势；并可支持多个OBU模拟与数据包拥塞模拟；并且支持软件平滑升级到5G-V2X。

  

**3.  通用性**：可与国内外多家上层场景仿真软件相结合，可在不同协议层做故障注入，内嵌高性能FPGA，支持高度软件自定义，可快速集成到不同开环/闭环测试系统中，提供预设定测试应用场景。

 

中汽数据V2X仿真测试系统根据最新的车路协同互联互通协议，提供基于实验室环境中验证符合3GPP Rel.14的物理层(符合GCF验证标准)以及面向中国标准的C-V2X网络层、V5接口安全和消息层的自动化协议一致性测试及GNSS模拟器测试、V2X虚拟仿真HIL测试等解决方案。  

  

![](../Images/8b0f94246e8ae282d0001d2ed5f229e3.png)

  

图4 V2X仿真验证系统测试功能

  

V2X终端产品在规模化商用之前，需要基于V2X应用场景对其功能、性能、稳定性等方面进行测试验证。通过仿真测试手段可大幅度节省开发成本，在加快产品开发迭代速度的同时，也保证了产品的质量。

  

**中汽数据具有完整的V2X仿真测试设备及解决方案**，已与行业内多家企业展开相关合作与研究，包括V2X仿真测试场景库建设、V2X消息预处理模块开发、V2X仿真硬件在环台架测试联调、V2X仿真自动化测试及协议一致性等内容，助力V2X技术应用落地。
