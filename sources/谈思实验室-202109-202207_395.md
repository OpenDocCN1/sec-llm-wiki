# 历史性时刻！德国允许L3自动驾驶上路，买奔驰明年就能用

**本田和奔驰先行一步，L3自动驾驶要复苏了？****作者 |  **James  
**编辑 |  **晓寒L3级自动驾驶可以在德国上路了，奔驰成为首个拿到批准的车企！车东西12月10日消息，就在几天前，德国联邦汽车运输管理局 (KBA) 批准了奔驰的L3级自动驾驶系统，意味着奔驰L3级自动驾驶车辆能够上路，甚至能远销海外市场，这一消息在北京时间今天正式对外宣布。这是继今年本田限量量产全球首款L3自动驾驶汽车后，L3级自动驾驶领域的又一大突破——实现了规模量产，多国销售。根据奔驰的规划，旗下S级和EQS两款旗舰轿车将率先配备L3级自动驾驶系统，普通消费者明年上半年就能提车上路。在德国高速路上行驶时，如遇拥堵路段，车辆可以完全接管所有驾驶动作，并以最高60km/h的速度行驶，驾驶员则可以做与驾驶无关的事，例如看个视频、轻度办公或者在线购物等。目前，德国境内已经有1.3万公里的高速路支持奔驰的L3级自动驾驶，并且奔驰在中、美两国正进行大量测试，未来有可能向中美消费者供货。2017年奥迪发布新款旗舰轿车A8时就大肆宣传其将支持L3级自动驾驶技术，在全球引起了一轮L3的研发热潮，车企和自动驾驶公司积极性都很高。但因为L3的接管悖论，以及一些技术困难，L3级自动驾驶迟迟无法落地，比如奥迪在2020年低调取消了A8的L3研发计划，导致这一代A8将永远无法真正实现L3。奥迪的退出给L3的研发带来了巨大的挫折，众多自动驾驶公司和车企纷纷对L3闭口不谈，转而大力发展L2和L4技术。L2方面，在特斯拉的带领下，全球目前正在快速普及自动导航辅助驾驶系统，并且即将在2022年迎来城市点到点L2的关键突破——在功能上接近L4的使用体验。而就是在这样一个大背景下，仍然有一些传统车企在死磕L3，今年本田限量生产了100台L3自动驾驶车型，并在日本租售给用户（租期只有3年），可在东京的制定道路上行驶，算是在全球开启了L3落地的先河。但本质上说，100台租赁车辆在路上跑与自动驾驶公司进行路测区别不大。而德国此次从法律层面允许L3自动驾驶车辆销售和上路，看起来则显然是更大规模的一种许可。如果明年普通民众都能买到L3并且在公路上进行使用，那么这确实是量产自动驾驶技术的一次重大突破。***01******.*****奔驰L3系统获批 德国已有1.3万公里高速能用**

根据国际安全要求UN-R157《自动车道保持系统》，德国联邦汽车运输管理局认为奔驰的L3级自动驾驶系统符合规定，批准上路。2020年通过的UN-R157中规定，在高速公路拥堵路段，可以使用L2级自动驾驶系统，如果速度不超过60km/h，驾驶员可以进行非驾驶活动，此时就开启了L3级自动驾驶。不过，一旦车辆提示驾驶员接管，驾驶员需要在规定时间内接管车辆驾驶。

![](../Images/076a07a0c4a93c1821dbdc6067260f6c.png)

▲德国KBA批准奔驰的L3级自动驾驶系统

并且，根据SAE对L3级自动驾驶的定义，L3级自动驾驶开启时，车企将对驾驶负责。如果出现意外事故，驾驶员不需要负责，而是车企对此负责。目前，UN-R157法规的缔约国有欧盟国家、英国、日本、韩国、澳大利亚等，也正因为如此，奔驰的L3级自动驾驶车辆都可以在这些国家销售。奔驰的L3级自动驾驶系统名为Drive Pilot，目前已经规划的车型共有两款，分别是S级和EQS，这两款车都是奔驰旗下的旗舰级轿车。当驾驶员驶上高速公路，但出现拥堵情况时，Drive Pilot可以接管所有驾驶动作。此时，驾驶员握住方向盘，按下其左右大拇指的位置的任意一个按钮，就能激活L3级自动驾驶系统。在功能上，车辆能够识别车道线、交通状况，同时还能识别交通标志。奔驰的L3级自动驾驶系统还能识别道路上的意外交通状况，根据具体情况L3级自动驾驶系统能够在车道内规避风险或者制动停车。

![](../Images/c8d62d77de2505d43849911ac6553a8b.png)

▲配备L3级自动驾驶系统的奔驰S级方向盘

在进入L3级自动驾驶状态后，驾驶员可以解放双手双脚，并且双眼也能离开道路。奔驰允许驾驶员看中控屏幕，可以在屏幕上使用车载办公室、浏览器或者看视频。一些在手动驾驶条件下被限制使用的应用程序，可以在L3级自动驾驶过程中开启。不过，如果在车内看书看报、玩手机还不被允许。由于UN-R157法规规定，L3级自动驾驶的最高速度为60km/h，因此超过这一速度后，车辆将退回为L2级自动驾驶。同时，L3级自动驾驶无法处理全部驾驶动作，一旦无法继续运行，车辆将提前预警，并提示驾驶员接管。此前公布的信息显示，奔驰可以给驾驶员10秒时间接管车辆。从车辆开始提示接管的10秒钟之内，驾驶员随时可以接管，但接管前车辆仍需要处于L3级自动驾驶状态。

![](../Images/3326ef888382261808e6f6ffb6495fed.png)

▲奔驰测试L3级自动驾驶系统

如果驾驶员始终未能接管车辆（例如出现身体不适），车辆会逐渐减速，直至停车。停车之后，车辆会自动紧急呼叫，并解锁门窗，方便救援。

![](../Images/8369ca96cd6131a1b624baf54faff0e3.png)

▲支持奔驰L3级自动驾驶的德国高速路

搭载奔驰L3级自动驾驶的S级和EQS两款车将在明年上半年开启交付。在交付之前，奔驰宣布，在德国已经有13191公里的高速公路能够使用Drive Pilot L3级自动驾驶功能。并且，Drive Pilot也正在中国、美国广泛测试。一旦全球其他市场开放L3级自动驾驶，奔驰在当地道路建立的L3级自动驾驶算法以及研发完成的L3级自动驾驶硬件能够实现大规模复制。***02******.*****配备26个传感器 与本田方案有明显区别**

配备Drive Pilot L3级自动驾驶系统的奔驰S级拥有大量传感器，包括摄像头、激光雷达、毫米波雷达、超声波雷达等共26个传感器。在奔驰S级前格栅中央，分布着三个传感器，体积不算小，走近车头就能明显感知到。其中上方中央的传感器为毫米波雷达，其水平感知角度为90度，垂直感知角度为9度。下方左侧为环视摄像头，右侧为感知角度为120度的激光雷达。

![](../Images/79b6604412d647b896f26dc4fb8845d8.png)

▲前格栅处的传感器

在前挡风玻璃处，配备双目前视摄像头，视场角达到70度。在车身四角，配备另外四个毫米波雷达，其感知角度分别能达到130度。车身两个后视镜、后备箱中部加上前格栅，共有4枚360度环视摄像头。此外，还有环绕车身头部和尾部的12个超声波雷达。

![](../Images/8be4ccc694b356981ab3f0c0011a335e.png)

▲奔驰Drive Pilot传感器配置

在后风挡上方，集成了奔驰的高精定位模块。后风挡左侧，集成一枚斜向摄像头，这枚摄像头能够感知后方交通状况，如果有警车、救护车通过，L3级自动驾驶系统会主动避让。在车辆左前轮后部，还有一枚雨水传感器。此前的报道显示，奔驰的L3级自动驾驶系统在下雨或者道路湿滑状况下不能开启。进入车内，在车内仪表位置，集成了一枚驾驶员监测摄像头，用于监测驾驶员的驾驶状态。以上共25个传感器，组成了奔驰L3级自动驾驶系统的感知模组，但奔驰没有公布其计算模组的详细信息。今年3月，全球首款L3级自动驾驶车型——本田Legend Hybrid EX实现量产，这款车和奔驰的L3方案有哪些区别呢？在传感器配置上，本田Legend Hybrid EX拥有5个激光雷达、5个毫米波雷达、双目前视摄像头和12个超声波雷达。

![](../Images/f77e4f2c63bf5f255c7175e63e9f9c95.png)

▲本田Legend Hybrid EX传感器配置

二者毫米波雷达配置几乎相同，采用前向+四角的模式，但两辆车激光雷达的配置完全不同。本田采用四角+后向激光雷达的配置，没有前向激光雷达，而奔驰只有一枚前向激光雷达。本田堆料虽然非常强，但5个激光雷达的量产成本也非常高昂，这就导致本田的L3级自动驾驶车租售价格达到1100万日元（约合65.97万元人民币），限量生产100台，并且租期只有3年。奔驰则是更倾向规模量产，基于旗舰豪车打造L3级自动驾驶系统，成本和售价带来的压力会小很多。因此，当明年上半年奔驰交付L3级自动驾驶的S级和EQS车型时，也就能够实现L3级自动驾驶的规模量产。***03******.*****结语：传统车企仍不容小觑**

特斯拉等车企的快速崛起，人们给老牌车企扣上了“传统”的帽子。有观点认为这些车型的智能化水准较为落后，尤其是自动驾驶和智能座舱技术。而作为老牌车企的代表，本田和奔驰在2021年一个实现了L3级自动驾驶量产，另一个实现了L3级自动驾驶获准落地，让传统车企再次站在了台前。在未来几十年的智能汽车大战中，传统车企仍然不容小觑，其智能化水平不断提升，加上深厚的造车经验，仍然能够得到消费者喜爱。
