# 国家网络安全宣传周“智能网联汽车网络安全专题”活动在上海举行

8月26日，2022年国家网络安全宣传周上海特色主题日宣传活动在智能电动汽车核心研发区“上海汽车创新港”和时尚地标 “天安千树”同时举行。本场活动以“智能网联汽车网络安全”为主题，在中共上海市委网络安全和信息化委员会办公室的指导下，由上汽集团、智己汽车和上汽培训中心联合主办，上海市信息网络安全管理协会、上海市智能网联汽车网络安全产业协同创新中心共同协办。

上汽集团一直将安全工作视作企业的“生命线”，面向智能网联汽车时代，更是将网络和数据安全视作智能网联汽车的基石，并将网络安全能力作为集团智能网联五大核心能力之一，上升到集团战略的高度，上下、左右协同共建，大力夯实网络安全底座，并在整车企业和各级供应商中探索“生态链网络安全责任共担”机制，共创共赢，逐步提升电动智能网联汽车产业链整体的网络及数据安全水平。

![](../Images/abd08404223ca5d408303f845172cf74.png)

  

随着电动智能网联汽车渗透率的不断提升，围绕智能汽车的网络和数据安全也日渐成为热点话题。本次“智能汽车网络安全主题活动”采用创新的宣传形式，通过外场“走进商场、面向市民用户”、内场“高端专业论坛”联线互动的方式，让大家愿意看、看得懂、记得住智能汽车的网络安全相关重点内容。  

![](../Images/b6733ebbbaaed8f03afb997eba58bac5.png)

  

![](../Images/85cd33337cc639ec3353443472adc88a.png)

![](../Images/03ee5044f9dbb88aef3e14b8438d3b5e.png)

  

主题日期间，上汽集团&智己汽车针对智能汽车网络安全、数据安全方面的工作方法及实践成果作了分享和探讨。车企从网络安全组织架构、汽车网络安全整体纵深防御框架、数据安全与个人信息保护、车主用车安全等多个维度，采用现场产品展示、功能宣讲和视频演绎等多种形式，通过创新宣传形式，突出重点焦点，以通俗易懂、喜闻乐见的形式，宣传网络安全理念、营造全民参与的良好氛围，帮助现场观众融入智能汽车网络安全的应用场景。

![](../Images/bef4a8301db0aa04d0d024656a537acb.png)

  

上汽集团将在相关委办局的指导下，在生态伙伴的支持下，不断提升自身网络及数据安全水平，构筑起牢固的智能网联汽车网络安全屏障，为用户带去安全的电动智能网联汽车产品。
