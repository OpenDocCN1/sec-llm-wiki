Karamba Security 成立于2016年，是一家总部位于以色列特拉维夫的信息安全初创企业。


Karamba Security 为互联系统提供行业领先、屡获殊荣的嵌入式网络安全解决方案。



Karamba的网络安全解决方案自动集成到系统软件中，并不断检查系统的运行时完整性。当检测到系统有异常行为时，系统会自动阻止；以零误报和可忽略的性能影响防止零日网络攻击。


汽车行业、工业 4.0、物联网和企业边缘网络的产品制造商依赖于 Karamba 的自动化运行时完整性软件。使用 Karamba 的软件，设备可以自我保护免受网络攻击，无需任何开发更改或安全更新。供应商利用 Karamba Security 的软件来提高他们的品牌竞争力并保护他们的客户免受网络攻击。

#  安全性分析

3

CVE


CVE(Common Vulnerabilities and Exposures) 是在固件上的软件库和应用程序中发现的公开披露的安全漏洞。此扫描程序搜索固件中常用的流行库的易受攻击版本。比如基于漏洞的无文件内存攻击，使攻击者能够操纵二进制文件的运行时程序流。

2

内核特性


此功能有助于防止某些类型的网络攻击或使攻击更加困难的内核配置选项。您可以启用这些选项来创建更安全的系统，从而减少操作系统内核的攻击面。

3

不安全的BIN文件


构建固件过程中提供了各种编译器、链接器和操作系统安全功能，它们添加了运行时检查和保护机制，从而减少了内存中的攻击面。此扫描功能突出显示部分或全部这些功能的风险配置。


弱口令


强壮的密码是连接系统的重要第一道防线，包括自动和手动远程访问。VCode 的扫描器分析常见的密码并识别安全漏洞。

3

文件权限


Linux 操作系统的权限模型，用于区分用户和组的文件权限。配置不当的权限的文件可能会被攻击者修改或滥用，以使用更高的权限（例如，作为“root”）运行，并修改系统配置。扫描程序会识别配置不当的文件。例如，它查明没有 SUID 标志的应用程序，这将阻止攻击者以更高的权限运行它们。



#  软件物料清单 (SBOM)


VCode 的一个重要组成部分是 SBOM - 符合UN R155法规要求。此工具提供有关文件系统和固件中每个组件的详细信息，包括第三方软件：位置、CVE计数、CVE的最高严重性、依赖关系以及（如果可用）库版本号和相关的许可证类型。


易于使用的过滤机制允许对SBOM的详细数据进行分析并制定进一步的决策。
