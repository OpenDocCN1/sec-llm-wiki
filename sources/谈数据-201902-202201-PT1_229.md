# 企业数字化转型：关于转型技术的思考！

Hi，大家好！

我们继续聊企业数字化转型这个事儿。

企业数字化转型主要有两大驱动因素，一个是需求的拉动，一是技术的推动。  

“需求的拉动”我们在之前的文章中没少聊，今天我们就来聊一聊数字化转型的另一个驱动因素——数字化技术。  
*01. *“数字化”是什么，它与“IT”的区别？

人们在谈论数字化转型时，总会提到“数字化”与“IT”的区别？有一个区别很简单：数字化是形容词，而 IT 是名词![](../Images/babd8d3ea9a073197c09fed0ef579af0.png)![](../Images/babd8d3ea9a073197c09fed0ef579af0.png)![](../Images/babd8d3ea9a073197c09fed0ef579af0.png)。

IT（信息化），我的理解是“业务流程化、流程数据化”。

通过IT技术实现企业的生产过程、采购过程、销售过程、客户服务、事务处理、现金流动等业务流程的在信息化世界的流转，并记录相关业务数据的过程。

**特点是 —— 流程驱动业务。**

“数字化”，我的理解是“业务数字化、数据业务化”。

第一，将 IT 更广泛嵌入到企业的各项业务、产品、服务和相关交付渠道中。

第二，将长期积累下来的数据进行最大化利用，充分释放数据的价值。通过数据发现问题、发现规律、发现商机，用数据优化业务组合，优化业务流程、优化经营模式，实现企业的持续运营、持续创新、持续发展。

**重点强调 —— 数据驱动业务。**  
*02. *“数字化”是全新技术还是“IT”的延伸？关于“数字化技术”的讨论，似乎总会回到IT上来。可见，数字化“与IT有关”。

也有专业认为，数字化被认为是信息化的延伸，是“重要的IT”，但我想知道什么是不重要的IT？。

笔者理解：数字化是信息化发展到高级阶段必然产物，而这个所谓的“高级阶段”重点并不在于IT技术的某些内在质量是否更高级，更多的是关于企业如何使用这些技术。就如上一篇文章所讲，数字化战略就是能够“战略性地”使用“IT”和数据。请参考《[企业数字化转型：数字化转型战略！](http://mp.weixin.qq.com/s?__biz=MzI1NzYwNTMzNw==&mid=2247489950&idx=1&sn=071594af5a1c05907f8108ad0eaa4e83&chksm=ea15b228dd623b3efe1b259682d5afefbd146c61c26c8a9740cad9ed0367b6eb99d55f2678c1&scene=21#wechat_redirect)》

我们现在提数字化转型，也就是说我们之前并没有“战略性的使用IT和数据”。

当企业将IT“战略性”的应用在企业各项经营和生产活动中，当这些应用足够深入时，企业就会逐步从信息化进化为数字化企业。在这个进化过程，随着“IT”应用的不断深入，这些技术也会不断地发生内在的进化，例如：IT架构的演进，就经历了单体架构、SOA架构、微服务架构、云原生架构等阶段。

因此，信息化与数字化虽然在技术层面并没有明确的界限。所谓“数字化技术”，也一定是被广泛使用、更加与时俱进的，对企业业务产生更大影响的“信息化技术”。

  

*03. *用了最新的技术，就能成功转型吗？

技术会随着应用的深入而不断进化，先进的技术正在推动各行各业的数字转型。

但是，数字化转型并不是技术转型，即使使用了最新的数字化技术，也不能说明实现了数字化转型。

数字化技术不是仙丹妙药，任何人服用都能“飞升成仙”。数字化技术更像一把宝剑，要发挥其威力，主要看使用者，“武功大侠”用它能仗剑天涯，所向披靡。“普通人”用它也只能烧火砍柴，砍瓜切菜。

**这里的“武功大侠”，一定是对数字化有着高度认知，并在业务过程中不断提升“IT”应用能力和技术水平的人和企业。**

但，“武功大侠”也并非是某个人或某些企业的专利。

对个人来讲，你需要持续学习、不断提升数字化认知和技术能力，迟早一天你也能成为武功高强的专业数字化人才。

对企业来讲，你需要将“IT”提升到战略层面，用数字化的视角找到企业业务中的痛点、盲点和断点，然后一点点地优化，一项项地提升。每一个优化和每一步提升，对企业都是一个“微创新”，当这些“微创新”不断积累、不断增多，就会由量变引起质变，企业的数字化转型就成了！  

*04. *盘点，推动企业转型的数字化技术

技术升级不等于数字化转型。但没有数字化技术谈数字化转型也是行不通的。接下来，我们将盘点一下企业数字化转型中，可能用到哪些数字化技术。以下为笔者个人角度的思考，不足之处欢迎各位大佬批评指正、补充完善，留言区希望看到你的理解。

1、网站（web技术）

一定会有人问：啥？这也叫数字化技术，这玩意太“老”了吧。

的确，从技术角度讲，网站算是最早的信息化了，笔者刚工作的前两年也是搞网站开发的（那时候我的MSN签名是“搞自己的站，让别人开发软件去吧！”哈哈，有机会后边给大家讲讲这段经历）。

web技术虽然很老，却是当今人们访问互联网的最常见的方式之一，它不仅为我们提供了各种信息，也逐渐成为了我们与客户沟通和联系的最佳方式。不论是传统的信息门户、电商网站，还是现在的快手、抖音，其本质都是网站或网站的深化应用。

当下，一些行业头部企业，都在试图通过构建水平或垂直的网站，来聚合生态、连接客商，从而推进企业的数字化转型进程。

2、智能手机

要说近10多年来，对我们的生活影响最深的，那一定是智能手机。

智能手机已经成为了我们身体的延伸，它不仅改变了我们的购物、出行、拍照、看书、游戏等生活方式，让我们看到了一个更大的世界。

从技术角度讲，智能手机是融合了通讯技术、成像技术、图处理技术、智能语音技术等多种数字化技术的综合体。

在数字技术发展的进程中，作为承载体——智能手机对于企业的数字化转型将发挥越来越大的作用，企业应当利用好“它”。

3、大数据技术

如果说“信息化”阶段是对数据的积累，那“数字化”阶段就一定是对数据的应用。数据被认为是数字化时代的“新石油”、“新货币”，因为数据中隐藏着巨大的商业价值。

大数据之所以“大”，不仅在于其能够存储的数据体量之大，更多体现在对于大体量、多样式的数据的分析和挖掘能力之强。

基于大数据的智能分析，能够帮助企业从“数据宝库”中，提取价值，重塑企业的业务决策模式，帮助企业实现数字化转型。

4、云计算技术

云计算是将计算任务分布在大量计算机构成的共享资源池上，使各种应用系统能够根据需要获取计算力、存储空间和各种软件服务。

云计算承载着大数据，是企业通向数字化的关键，为企业数字化转型提供算力支撑。IaaS、PaaS、SaaS、DaaS……，云计算技术正一步步改变着企业的数字化应用环境。

5、物联网技术

物联网，顾名思义“万物皆可联网”，通过信息传感设备，按约定的协议，将任何物体与网络相连接，物体通过信息传播媒介进行信息交换和通信，以实现智能化识别、定位、跟踪、监管等功能。

如今的智能家具、智能汽车、智能医疗、智能制造、智能农业、智能交通等数字化应用场景中都离不开物联网技术。

物联网以万物互联为起点驱动数据智能，连接数据孤岛，赋能企业的数字化转型。

6、人工智能技术

人工智能技术主要包含三个层面：

第一个是感知，计算机视觉和图像处理，给计算机装上“眼睛”，就像我们人类一样可以理解图像，对图像数据可以进行识别和分类处理，让计算机能够感知周围的环境。

第二个是理解，自然语言处理和人机对话，让计算机具备和人语音对话的能力。

第三个是行动，机器学习，基于海量数据训练，优化机器学习算法，使得计算机具备帮助人们做决策的能力。语音助理、RPA、COR等都是人工智能在企业转型中的典型应用。

未来，在企业的数字化转型中，人工智能将发挥越来越大的作用。

7、5G网络技术

5G网络是就有大带宽、高容量、低时延、高安全的新一代无线网络系统，为更多的智能设备连接提供了更好、更智能、更快、更稳定的网络支撑，让我们的数字化世界变得更加丰富。

利用好5G网络能够促进物联网的全面发展，拓展人工智能的应用边界，推动产业互联网的发展，为企业数字化转型赋能。

8、区块链技术

区块链技术是一种数据存储架构，它在通过点对点连接的系统中将人们的交易记录（也称为块）分布式的存储在各种记录中（称为“链”）。通常，这种存储也被称为“分布式数字帐本”，具有“不可伪造”、“全程留痕”、“可以追溯”“、公开透明”、“集体维护”等特征。此分类帐中的每笔交易均由持有人的数字签名进行认证，从而验证交易并保护其免受损坏。

因此，数字账本所包含的数据是非常安全的。基于区块链的连通性、安全性、智能合约让企业的数字化交易更加安全，帮助企业构建数字化生态。

9、数字孪生技术

数字孪生就是利用数字化技术将物理世界的对象在数字世界做一个“镜像”。这个“镜像”的本质是数字化模型，该模型通过传感器随时获取真实物体的数据，并随之一起演变、成熟甚至衰老。

可见，数字孪生技术是一个集数据建模、IoT技术、数字化仿真等技术为一体的多学科技术。目前数字孪生技术主要还在理论研究和应用探索，还未形成大规模的应用。

有专家预测，数字孪生技术一定是企业数字化转型的核心技术，将对产品设计、智能制造、医学分析、工程建设等领域带来重大影响和改变。

10、机器人技术

在企业数字化转型中，数字机器人技术的应用更加经典和常用。在生产制造企业中，能够找到很多设备机器人，它们代替或协助人们完成各种繁重的、枯燥的、危险的、有毒的、有害的工作。除了制造行业外，机器人还广泛应用在资源勘探、能源开发、救灾排险、物流服务、航空航天等领域。技术人员还在研究微型纳米机器人，可以将其插入人体进行医学研究和测量。

  

写在最后的话

1\. 企业数字化转型，重点在“转型”，强调的是“战略性”的使用“IT”，而不简单是IT系统的升级或改善。

2. 不要把数字化技术，当做能够颠覆式创新的工具，也没有哪家企业依靠新技术、新工具就能成功转型的。

3. 对于传统企业而言，最要紧的是尽快补齐“信息化”的课，可以尝试基于现有的技术做一些“微创新”。一场大的变革，来自于多个“微创新”的累积。

4. 从来就没有“一步到位”的数字化转型技术和工具，说有的，十有八九是骗子。

5. 企业数字化转型，没有最好的技术，只有用的好或不好的技术，别被技术所绑架。

以上是我对数字化转型技术的理解，一定会有认知的不足和理解的片面性。请大家一定不吝赐教~
