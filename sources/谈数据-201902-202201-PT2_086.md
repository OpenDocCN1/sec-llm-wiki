# 【漫画连载】某农商行数据治理的实施策略

> 2018年5月，中国银行保险监督管理委员会发布《银行业金融机构数据治理指引》，为引导银行业金融机构加强数据治理，提高数据质量，充分发挥数据价值，提升经营管理水平。有助于推动银行业由高速增长向高质量发展转变，拓展新业务，挖掘新动能，提升服务能力，提高经营管理质效。

**数据治理的目标**  

根据监管当局发布的《银行业金融机构数据治理指引》，结合省联社发展战略启动了数据治理工程。开展数据治理活动时将从数据治理体系建设、数据标准制定、数据质量综合提升多方面切入，结合数据管控平台的落地，以提升省联社数据管控水平，同时满足监管要求。数据治理活动从数据层面为山西农信经营管理、风险控制、发展改革提供助力。

**数据治理的实施路径**

数据治理实施路径一般包括：数据治理体系设计、数据治理项目实施、数据治理平台搭建、数据治理培训宣贯。

1.  数据治理体系设计，包含了数据战略、组织人员、制度流程、考核评估、标准规范、工具平台六大核心要素，这六大要素也是影响数据治理成功的关键，详见文末的数据治理成功要素篇。
    
2.  数据治理项目实施，数据治理项目的实施可遵循笔者一向推荐的“理数据、建标准、接服务、抓运营、重实效”15字方针。详见笔者发布的《小数据治理靠“人工”，大数据治理靠“智能”》。
    
3.  数据治理平台搭建，工欲善其事必先利其器，强大的数据治理平台将对企业的数据治理起到事半功倍的效果。数据治理平台一般来说包括以下功能：元数据管理、数据质量管理、数据标准管理、数据安全管理、主数据管理等。
    
4.  数据治理培训宣贯，是将数据治理的理念、思路、方法、技术、价值在企业内部进行宣传，让更多的人掌握数据治理知识，建立数据思维，以数据说话、以数据思考、以数据决策。

**结语：**从理论或行业的实践上讲，厘清数据资产清单，提高数据资产的规范性、可用性。数据治理能够保证数据标准及质量、提升数据管控水平、发挥数据价值。数据治理绝对不是一个一次性建成的项目，需要按照数据治理“大处着眼、小处着手”的原则，持续完善，在全行范围内形成统一的数据治理认知，认清数据治理的责任与义务，明确数据治理管理办法和工作要求，形成长效数据治理的运营机制。
