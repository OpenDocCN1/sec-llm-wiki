# 制造业数字化转型的五大法则！

![](../Images/f562de9d3c3658a8bfebaef3287ef539.png)

  
  
  

  

谭建荣院士在演讲中提到：改革开放以来，制造业对国民经济的贡献以及对人民追求幸福生活的贡献功不可没。虽然制造业取得了有目共睹的成绩，但是也存在很多问题，**尤其是近年来，制造业企业普遍感到压力很大，困难重重，究其根本原因是市场需求发生了变化。**

  

**— 01 —**

**市场需求的四大变化**

![](../Images/e6209c953e23f02f01cf3eaef4e4f810.png)

  

*   一是由批量化生产，向定制化的方向发展；
    
*   二是由单一化的产品，向多品种的方向发展；
    
*   三是由过去的产品周期长，到现在的产品更新快；
    
*   四是由大众化的产品需求，向高端化的产品需求转变。
    

  

在此背景下，新一代信息技术和智能制造技术取得了快速发展。**谭建荣院士指出，新一代信息技术具有四大显著特征：**

  

*   第一个特征是由互联网技术发展到物联网技术；
    
*   第二个特征是由虚拟现实技术，发展到增强现实技术；
    
*   第三个特征是由网格计算技术，发展到云计算技术；
    
*   第四个特征是由机器学习技术发展到深度学习技术。
    

  

这些技术形成了几个典型的综合交叉领域，**其中包括智能制造、混合现实、大数据和人工智能。**

  

**制造业向高质量发展，政府如何推动？专家如何引导？企业如何实施？这三个问题到目前为止尚未完全解决。**谭建荣院士提到：“制造业要高质量发展，就要生产高质量的产品；生产高质量的产品，需要高质量的技术；要掌握高质量的技术，必须要有高质量的管理和高质量的人才。现在，很多制造企业存在研发能力不足，设计能力不足，创新能力不足，高端制造能力同样不足的情况。我们要实行高质量的发展，必需要实现数字化的产品。很**多企业都渴望进行转型，但是怎么转？如何转？用哪些方法转？还是比较迷惑。”**

  

**— 02 —**

**制造业数字化转型的五大法则**

![](../Images/e6209c953e23f02f01cf3eaef4e4f810.png)

  
为此，谭建荣院士提出了制造业企业数字化转型的五大法则。他认为，打造中国制造业升级版，**要顺应“智能制造”的发展趋势。**根据官方媒体报道，**许多企业应用智能制造后，企业效率会提升约20%，成本可下降20%，节能减排可下降10%。未来20年，中国智能制造发展至少可带来3万亿美元左右的GDP增量。**  
**01**** / 第一条、智能制造+创新设计**  

  

作为“世界工厂”的中国，制造业一直是优势产业。但是过去几年，中国部分企业创造价值的能力正在下降，有些企业甚至面临种种困境，**面对“中国制造”，部分企业逐渐呈现后劲不足的疲弱态势。**  
谭建荣院士指出：我们要推广智能制造，使制造业向数字化、网络化、智能化的方向发展。在这个过程中，一定要以创新设计为牵引，离开了创新设计，有些企业智能制造可能变成新一轮的产能扩大，我们要研发、设计、创新出新一代的产品，高附加值的产品，高技术含量的产品，**必须要有创新设计的发展思维，用创新设计来引领智能制造，使企业不断增强研发的能力，设计的能力，创新的能力。**

  

**02**** / 第二条、智能制造+工艺提升**  

  

**智能制造要与工艺提升相结合。企业的智能制造会用到机器人、自动化、数字化和网络化，**但是如果智能制造不与工艺相结合，将收效甚微。谭建荣院士强调：衡量企业智能制造做得好不好，有两个非常重要的层次，第一个层次是能否与行业、产品制造的工艺深度融合；第二个层次是利用人工智能、数字化、网络化的手段来提升、优化、重组传统工艺，将劳动密集型的制造工艺转化成数字化、网络化、智能化的制造工艺。 **以海尔正在打造的“互联网工厂”为例，目前，海尔开始从大规模制造向大规模定制转变，**用户下订单，订单上生产线，生产线通过系统可以形成一个大的系统，实现大批量定制。此外，海尔还在探索将消费者与生产机器人互联，比如，有些消费者想把图片印在饮料瓶上，信息便可以通过网络传给生产线机器人，机器人获取图片后就可以将其印在瓶子上。  
**03**** / 第三条、智能制造+强化质量**  

  

**通过智能制造要强化产品的质量。**据统计，我国制造业在两百五十多个工业领域出现了中低端产品产能过剩的问题，生产的产品与发达国家的同类产品相比，**在质量、可靠性、可用性方面还存在一定差距。** 中国的制造业企业要顺应“智能制造”的发展趋势，以信息化与工业化深度融合为主线，强化工业基础能力，提高工艺水平和产品质量，推进智能制造、绿色制造。促进生产性服务业与制造业融合发展，提升制造业层次和核心竞争力。 制造企业要通过数字化转型，通过智能制造强化产品质量。谭建荣院士提到：70年代，**日本丰田公司就进行了全面质量管理，产品的质量与企业的每个员工、每个岗位、每个时段都息息相关，智能制造要跟6S管理、精益生产有机结合起来。**  
**04**** / 第四条、智能制造+延伸服务**  

  

通过智能制造延伸服务，也就是将制造业延伸到制造服务业，通过制造服务来获取利润。谭建荣院士提到，制造服务有两个基本原则：**第一个是高技术的服务，第二个是高附加值的服务，只有通过高技术和高附加值的服务，才能真正把制造业转移到制造服务业上来。** **例如，预防性维护保养解决方案是智能工厂必备的重要功能。**通过对制造型企业的设备监控，可预先掌握设备性能状态，根据企业实际情况以及维修人员安排出最为灵活、高效的设备维保计划，对可能出现问题或可能需要维修保养的部分，有针对性、有计划的进行维保。某公司预防性维保解决方案帮助欧洲风力发电企业降低维保成本，**节省资源的同时提高了风力发电机组的性能和工作绩效，属于典型的智能制造延伸服务。**  
**05**** / 第五条、智能制造+拓展市场**  

  

通过智能制造来拓展市场，将高质量、高技术的产品推向全球。“现在，中央提出内循环和外循环两种循环，我们要高度融合，互相促进，不断拓展我们的市场，把产品、技术和服务推广到一带一路国家，推广到欧美发达国家。”谭建荣院士如是说。他以济南二机床为例，**其高速自动冲压线销往美国福特公司，这充分说明济南二机床的技术含量得到了国际同行的认可。**

  

**— 03 —**

**数字经济与转型升级**

![](../Images/e6209c953e23f02f01cf3eaef4e4f810.png)

  
在数字经济高速发展的今天，数字经济与实体经济高度融合，对于制造业的企业来说，需要进行数字化转型，通过智能制造+创新设计、智能制造+工艺提升、智能制造+强化质量、智能制造+延伸服务、智能制造+拓展市场这五个方面的努力，**将传统制造转型到数字化的制造、网络化的制造、智能化的制造，从而实现企业的数字化转型。**

  

**— 04 —**

**数字设计与****智能制造的典型应用**

![](../Images/e6209c953e23f02f01cf3eaef4e4f810.png)

  
最后，谭建荣院士列举了他和他的团队在**数字设计和智能制造领域应用数字化、网络化、智能化技术帮助企业提升产品质量、实现转型升级的研究与技术实践。**包括：  

*   超大型低能耗空分装备设计制造基础研究；
    
*   高档数控机床数字化设计的关键技术；
    
*   大吨位深拉伸液压装备设计制造关键技术；
    
*   一类高端龙门加工中心创新设计关键技术；
    
*   电梯产品大批量定制与数字化智能化设计技术；
    
*   数控机床远程监控、诊断与虚拟维修技术；
    
*   大型舰船分段制造作业流程模拟与优化技术；
    
*   机器人作业布局规划及其智能制造应用技术；
    
*   重大装备多学科设计、计算与仿真技术；
    
*   数字化装备关键技术及在航天产品中的应用。
