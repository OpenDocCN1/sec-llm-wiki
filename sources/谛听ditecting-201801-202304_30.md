# 谛听|“工业互联网安全实验室”合作签约仪式成功举行

    2020年11月11日，东北大学“谛听”实验室与辽宁省网络空间安全实验室、360公司签订战略合作协议，共同开展“工业互联网安全实验室”建设，在工业互联网网络安全监控预警、应急保障、检测评估和人才培养等方向进行深度合作。

    “网络空间安全实验室”是在中共辽宁省委网信办的领导下，由辽宁省先进装备制造业基地建设工程中心下属的辽宁省信息安全与软件测评认证中心与国家计算机网络应急技术处理协调中心辽宁分中心联合组建的。实验室以网络安全保障技术研发为核心，以合作引进优秀解决方案为手段，以积累本地化的网络安全服务资源为目标，通过自主研发、合作引进、联合共建等方式，在工业互联网应用、测评评估、应急保障、漏洞挖掘、新技术新应用等领域形成切实有效的网络安全解决方案，面向全省关键信息基础设施运营单位提供专业服务，为我省网络安全保障体系建设提供有力支撑。

**签约仪式**

    签约仪式上，签约单位代表就全省工业网络安全保障和实验室工作推进相关议题进行了座谈；省委网信办、省工信厅领导出席并讲话，对实验室的工作给予充分肯定，并对下一步工作提出了宝贵意见。

![](../Images/66f08f0da8b6ba7f68b2bb714d07788c.png)![](../Images/42a12bec5e0871daca7b96a265b4acd2.png)![](../Images/66f08f0da8b6ba7f68b2bb714d07788c.png)

    “工业互联网安全实验室”的签约组建，是习近平总书记提出“全天候全方位感知网络安全态势”要求的具体落实，是技术机构、企业、高校间强强联合共同支撑产业发展的直接体现。实验室将在构建辽宁工业互联网安全保障体系，提升工业互联网安全保障能力，助力辽宁工业互联网高质量发展中发挥重要作用。

![](../Images/66f08f0da8b6ba7f68b2bb714d07788c.png)![](../Images/299ff760c9f8dd201140c1a69d5ea709.png)![](../Images/66f08f0da8b6ba7f68b2bb714d07788c.png)

    签约仪式后，参会的中共辽宁省委网信办、辽宁省工信厅、辽宁省先进装备制造业基地建设工程中心的领导和签约嘉宾参观了实验室的平台展厅，并讨论了进一步发挥签约单位自身技术优势，为辽宁网络安全保障体系建设提供支撑能力的具体举措。东北大学“谛听”实验室将不断提升科研水平，为辽宁工业互联网安全保障工作提供创新动能。

![](../Images/530902be361dcb686065e741a9e3079c.png)![](../Images/3322fe5428367da7f85c88167d1301b8.png)

**“谛听”团队简介**

    “谛听”网络安全团队，由东北大学姚羽教授带领课题组师生组建，依托复杂网络系统安全保障技术教育部工程研究中心，被辽宁省工信委授予“辽宁省工业信息安全支撑单位（首批）”，包括3名博士，9名博士研究生，22名硕士研究生。团队的研究方向为工业互联网安全，重点研究内容主要包括工业网络空间测绘、工业蜜罐、威胁情报、工控网络探针、网络空间安全态势感知等。课题组发表学术论文40余篇，专利5项，软件著作权2项，主编国内第一部工业信息安全专著《工控网络安全技术与实践》，获辽宁省科技进步二等奖、辽宁省自然科学学术成果一等奖、ChinaVis数据可视化分析挑战赛一等奖等，参与制定国家标准《信息安全技术 智慧城市网络安全评价方法标准草案》，编写《2019年工业控制网络安全态势白皮书》等10余篇。
