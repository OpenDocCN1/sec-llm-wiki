# 谛听||复杂网络系统安全保障技术教育部工程研究中心通过验收，“谛听”团队为其重要支撑

        2018年7月20日，受教育部科技司委托，东北大学组织专家在国际学术交流中心召开复杂网络系统安全保障技术教育部工程研究中心（下称“中心”）建设项目验收会。北京电子科技学院副院长封化民教授、北京奇虎科技有限公司高级副总裁谭晓生等9位验收专家出席会议。**东北大学“谛听”网络安全团队作为中心的重要支撑部分，负责人姚羽教授也出席了此次会议。**

        会上，东北大学科学技术研究院相关负责人致欢迎辞，介绍了学校发展情况和中心建设情况。中心相关负责人**姚羽教授**向专家组详细介绍了中心建设计划执行情况、组织管理模式、近中期目标与经营战略等。

![](../Images/48f01e90600361432bde13cab1764307.png)

        通过听取汇报、审查材料以及质询和评议，验收专家组认为，中心围绕复杂网络系统安全保障技术，在研究开发、产品创新、技术辐射和成果产业化等方面开展了卓有成效的工作，构建了研发平台及“复杂网络系统安全保障技术教育部工程研究中心成果转化基地”；组建了一支规模适中，结构合理，具有较强工程化、产业化开发能力的多学科交叉的科研团队，能够满足中心的建设和发展需求；承担了国家863计划、国家自然科学基金、省部级项目等近百项，科技经费超亿元；研发了具有自主知识产权的高性能异常流量分析过滤监控系统、云数据安全追责与管控、网络威胁防御管理系统、高性能UTM、**“谛听”工控网络安全态势感知平台**等；积极开展了成果产业化工作，取得了明显的经济效益和社会效益。专家组一致同意通过验收，并建议依托单位继续加大对中心的投入力度，与东软集团进一步强化合作共建机制。

        据悉，复杂网络系统安全保障技术教育部工程研究中心于2007年由教育部批准建设，经过十余年的建设历程，中心已成为我校科技创新体系的重要组成，推动了学校计算机科学与技术、软件工程、信息与通信工程等学科的交叉融合发展，为学校一流大学建设和国家网络与信息安全领域的技术进步提供了重要支撑。
