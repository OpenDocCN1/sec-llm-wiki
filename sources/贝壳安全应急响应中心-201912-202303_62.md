# 贝壳找房安全工程师龙猛进：零信任在产业互联网中的落地

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA5MjA0OTAwOQ==&mid=2247484089&idx=1&sn=03af0f535e4b42c37fc4375f5a4d967d&chksm=907259a7a705d0b10bf7c792b74ee7847e4409b51717a20ef2c7241dc8a5465f02b334a8e6d2&scene=126&sessionid=1681404966#rd](http://mp.weixin.qq.com/s?__biz=MzA5MjA0OTAwOQ==&mid=2247484089&idx=1&sn=03af0f535e4b42c37fc4375f5a4d967d&chksm=907259a7a705d0b10bf7c792b74ee7847e4409b51717a20ef2c7241dc8a5465f02b334a8e6d2&scene=126&sessionid=1681404966#rd)

10月14日，华山论剑·2020网络安全大会暨第三届全国信息安全企业家高峰论坛在西安举办，贝壳找房-资深安全工程师龙猛进受邀出席本次大会并做主旨演讲。本次大会以“数字新基建·安全新未来”为主题，由中国信息安全测评中心、中共陕西省委网信办、陕西省公安厅指导，西安市人民政府主办。

![](../Images/385db32c8613abf5b2f2853aff95dc5e.png)

贝壳找房\-资深安全工程师龙猛进在本次峰会的主题分享内容为“零信任在产业互联网中的落地”。本次议题分别从安全威胁挑战现状出发，延伸到贝壳的实践落地方案到贝壳对零信任未来展望对零信任的落地进行深度分析：

从当前行业所面临的安全威胁和挑战出发，贝壳为什么将零信任架构作为未来的发展方向。

1、当前行业所面临的安全威胁和挑战：传统边界式防护面临失效，企业内外部威胁和攻击事件愈演愈烈。

![](../Images/141ca396aaa9502c44489541f7aa64e9.png)  

![](../Images/63d64301521076f1ed449ceefecdeeaf.png)

2、贝壳网络安全架构选型依据：

当前贝壳平台覆盖超过110个城市和地区，连接超过250个新经纪品牌，4万家线下门店和超过40万的直营和加盟经纪人。面对这样复杂的网络环境和人员组成，传统的网络架构已经越来越不能适合贝壳现有的网络和安全需求。因此，贝壳选择将零信任网络安全架构作为未来的发展方向，结合自身环境去实现适合贝壳本身的零信任网络安全方案。

![](../Images/2a7fe650e85315666d70dac80a3f1065.png)

详细介绍了贝壳零信任一期的落地方案：一期主要实现了区域之间的web服务访问统一收敛到零信任网关，并基于零信任网关实现统一的认证鉴权和审计能力。

具体分为四个阶段进行落地：搭建阶段、接入阶段、收敛阶段、权限管理。

![](../Images/8b30728bb9185519326141d515fde3fa.png)

1、搭建阶段主要包含资产平台打通、授权策略设计、统一认证对接三部分内容。

1） 首先需要搭建零信任管理后台，并将内部的资产平台信息与零信任管理后台进行打通，实现业务信息、服务信息、IP信息和用户信息的同步。  

2）授权策略主要分为授权主体（Subject）、执行动作（Action）、资源对象（Resource）、条件环境（Environment）；授权原则为：S CAN DO A ON R IF E；  

3） 统一认证对接分为用户认证（SSO、企微/微信）、设备认证（证书、设备指纹）和服务认证（加签的AK/SK）。

![](../Images/455d68619f46176e12ad1a41e0033f13.png)  

![](../Images/09945859a12eae566fbe1f41a9569c73.png)

![](../Images/cf37ee77499ea3d4f00c5e3bcdd7a70e.png)

2、接入阶段主要目标是将web服务平滑、快速的接入到零信任网关之中，具体分为负载均衡业务和自运维业务接入。

1）负载均衡业务：通过在LB上嵌入策略执行插件，同策略中心进行通信获取授权，实现无改造接入零信任网关。  

2）自运维业务：通过DNS将域名CNAME解析至Ksg网关，并通过一键接入功能实现业务信息后台配置，实现自运维业务的快速接入。

![](../Images/d3e6b278fd361acf6f6fee0f013daa1a.png)

3、流量收敛阶段主要目标是将区域间的web流量入口统一收敛到零信任网关，从而基于零信任网关实现web服务的统一认证鉴权和审计能力。  

![](../Images/81c654ce4ad899bec815460a60d9d2e5.png)

![](../Images/ca27a5649da080b0dd25878d501c993b.png)

4、 权限管理是零信任方案中非常重要的一环，如何实现权限的统一的安全审批和审计，并对接内部各个分散的权限系统是贝壳零信任方案\-权限管理的主要目标。

![](../Images/5a8feea9edee63767ae9a67392808af5.png)

最后主要是对贝壳零信任未来的展望：贝壳的零信任网络安全建设整体目标、落地计划和零信任架构方案。

贝壳零信任主要分为三期进行落地：

一期主要通过网关实现了web服务的统一认证和权限管理，二期我们计划支持其他协议，并推动建立设备认证&终端准入的能力，并实现基于身份信息的授权，以及将终端安全能力与零信任方案进行联动，从而实现将内部作业系统安全的开放到互联网，支持门店去VPN化改造。三期我们计划结合内部风控能力，并支持人脸和指纹的认证能力，并通过微隔离方案打破内外部边界，实现真正的无边界网络。

![](../Images/3a50f55a81007fe78e0dcb35608fd33a.png)  

![](../Images/7149a3b03986fad97492ce8e8b8e941c.png)

总结：

贝壳的零信任网络架构核心包括接入网关、账号、分级认证、统一审计、动态权限管控、终端可信等模块。统一的业务接入网关保障了所有的流量都统一可以通过代理网关进行转发，这给业务系统的统一细粒度权限控制、梯度认证等提供了基础设施的保障。之后我们会通过终端风险识别、访问行为审计等方式，对每一次用户的访问行为进行风险的判定，结合判定的结果动态调整每一次用户访问的权限和所需的梯度认证策略（比如手机验证码、人脸验证等加强的验证方式）。在实现的了统一的认证鉴权审计和动态风控能力以后，我们会逐步将内部的作业系统通过零信任网关发布到公网，从而实现去VPN化和无边界的办公环境。
