# 橘子总结——斗鱼安全团队经验分享

      12月8日下午，斗鱼安全应急响应中心安全专家为同学们带来了关于安全运营的介绍讲座。这次活动中，同学们近距离接触了企业中的安全运营场景，对安全领域现状的了解更加全面。

**讲座内容回顾**

      当前，随着技术不断的更新迭代，各种安全攻击手段花样百出，有时一些被认为安全的解决方案在几个月时间内就被破解。这就要求企业持续、动态地建设自身的安全体系，以适应安全技术的革新浪潮。

![](../Images/474644d524abbfe4a0e05efaa05ced8c.png)

  

      当前斗鱼在基础平台建设方面下了很大的功夫。在线上建立了安全中台、攻击感知、统一秘密管理等平台，在线下也具备了内网漏洞扫描、风险资产端口监控、DDoS监控、蜜罐、攻击感知、安全日志审计、危险命令告警等安全工具。在此基础上，形成了由架构安全、应用安全、服务器安全、内网安全组成的核心业务体系。

![](../Images/da2826e2927f2beaca567b75c6e2b671.png)

      SDL作为一种根本性的应用安全解决方案，其所倡导的安全赋能、安全早期介入等理念在业界影响深远，但传统的SDL思想难以适应当前互联网企业敏捷开发、快速迭代的节奏。斗鱼在传统的SDL模型上定制了自己的安全开发流程，保证了软件开发的安全性。

![](../Images/eb11764b32d3541c6904c13e3e99895c.png)

      安全团队能力的建设也是安全运营中的重要一环。斗鱼安全团队定期开展系统性安全培训，增强内部安全意识，提升安全防御的思想和方法；也一直积极向外部安全力量学习和交流，多维度提升安全能力，并不断通过比赛检验自身水平，发现并改进自身不足。

![](../Images/0c82eb785f14b2b7a12ce67c44c26e57.png)![](../Images/1d6e1252429a041e7f50b2518dda5ef6.png)

      这次讲座中，无论是网络安全领域的一些常见的概念，还是企业中的安全体系建设、安全业务组成、安全运营方式等知识，都让大家对企业中安全团队的使命有了清晰的认识。大家在拓宽知识面的同时，也更加了解了行业对我们的要求。

![](../Images/ef0e832158ac9347234a1a5411d90d30.png)

**Q&A环节**

       讲座结束后，同学们积极地提问，专家对大家的问题进行了详细的解答。

**抽奖环节**
