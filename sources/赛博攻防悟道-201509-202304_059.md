# 微软掩盖安全漏洞～让全球用户处于危险之中…

***背景***

* * *

近日，美国Tenable公司董事长兼CEO - *Amit Yoran *撰文抨击微软，称微软在响应Tenable公司提交的2个严重安全漏洞时，没有及时沟通，并且想隐瞒安全问题，让所有人都处于未知的危险之中...  
太空战队剧集讽刺微软安全补丁的片段***原文***  

* * *

网络安全缺乏透明度，使我们所有人都处于危险之中。  
  
以我拥有超过25年的网络安全经验和声誉背书，我认为这个问题太重要了，不能保持沉默。我只能想象有多少安全专业人士和研究人员被律师要求噤声，或者没有平台让他们的声音可以被听到。   
正如您看到的那样，Tenable公司在漏洞研究方面有非常多的产出，在最近一年的时间里，我们可能会与一百多家软件供应商合作，以识别和解决新漏洞。  
今年3 月，我们在 Microsoft 的 Azure 平台中发现了两个漏洞，我们认为其中一个漏洞极其严重！任何使用Azure的人都可以利用这两个漏洞。在评估情况后，微软决定默默修补其中一个问题，淡化风险。直到告知微软我们要公开漏洞的情况，微软的说法才有所改变......在我们最初通知微软漏洞的第89天后，他们才私下承认安全问题的严重性。到目前为止，微软的客户还没有得到任何通知。 

![](../Images/b2909dfa5976531d5190bb246b73747d.png)

Tenable报告给微软的两个漏洞  
这是微软一种习惯行为，多家安全公司都撰文写过他们向微软提交漏洞的糟糕沟通过程，以及微软对漏洞给用户带来风险的那种不屑一顾态度。比如最近，Orca Security、Wiz、Positive Security和Fortinet公司发布的一些主要漏洞响应示例，包括了近期被称为“Follina”（MSDT 0day）的漏洞，这是一场安全灾难。   

![](../Images/5bdd5e18eb13519bd43ca230129d0b8c.png)

安全社区自行发布微软不愿意修复的0day漏洞补丁  
对于不透明的IT基础设施提供商或云服务提供商而言，风险会成倍增加。如果没有及时和详细的披露，用户不知道他们是否容易受到攻击……或者他们是否在漏洞被修补之前成为攻击的受害者。不通知用户有安全漏洞，会剥夺他们寻找被黑的证据，证明他们受到或没有受到攻击损害的机会，这是一种非常不负责任的做法。  
当公司披露自身的被黑安全事件时，FireEye/Mandiant 提供了一个负责任披露的规范表率，该公司甚至在2020年SolarWinds安全事件的取证过程中，就披露了相关事件。

![](../Images/fa7e8ea4aca281db49ee0096b2fc1aec.png)

SolarWinds安全事件细节

  

这些问题的答案不能只是要求供应商做得更好，而是要让云厂商或技术提供商遵守标准，同时谨慎和透明度是必不可少的，对 IT 基础设施和云服务提供商的独立审计和评估应该是强制性的。这是一个狐狸正在看守鸡舍的故事，信任需要验证，这是我们从小学开始学的启蒙课程，这个故事仍然适用于网络空间安全。
