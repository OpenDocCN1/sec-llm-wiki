北斗神拳这种传承了几千年的暗杀术，招式厉害无比！漫画说其背后的秘密是三国时期的杀手掌握了人体的秘穴，戳中秘穴就能杀人于无形！这些秘穴是如何发现的？细思极恐，想来北斗神拳的祖师没有少研究人类的身体，必是尸山血海堆出的杀人术！

  

二次元的三国暗杀术如此厉害，那在赛博世界/网络世界这种虚拟次元是否有同等级别的禁招？答案是有，毫不夸张，那就是apt攻击所使用的0day！安全厂商应该是谈0day色变，试问有多少安全厂商说自己能防护住0day，俱往矣只有安全厂商声称捕获了0day，并对0day攻击做事后分析，所有的对外宣称都是人家被攻击后没有擦好屁股，被发现了。抑或你抓住的只是一个残局，人家早已功成身退，从来没有厂商敢说我从头至尾阻止了一次0day攻击！

  

虚拟次元中的0day到底是什么，0day攻的是什么？我们可以看看国外zerodium公司收购0day漏洞所列的一张表。

  

![](../Images/133e40a642fe02bdb8b83598314eb762.png)  

  

**操作系统：**win 10/8.x/7，苹果mac os 10.11/10.10，linux（包括ubuntu/centos等）  

  

**浏览器：**chrome，ie，火狐，safari。chrome和safari都不限平台，包括安卓和ios。

  

**媒体播放器或阅读器：**flash，office，adobe pdf reader，第三方的pdf阅读软件  

  

**手机：**安卓6.x/5.x ，iphone ios 9.x ，win10手机，黑莓

  

**网页服务器及其扩展：**apache，iis10/8.x/7.x ，nginx ，openssl，mod\_ssl, php  

  

**邮件服务器及其扩展：**微软的exchange，dovecot，postfix， sendmail

  

**web程序：**wordpress/joomla/Drupal , phpbb/vBulletin/mybb , ip.Suite/IP.board, Roundcube/ horde

  

**其他攻击技术：**mitgation bypass（系统安全缓解措施绕过）比如绕过地址随机化防护，tor的去匿名化追踪技术 ，手机的基带远程代码执行，杀毒软件的远程代码执行和本地提权

  

ok，zerodium的这个收购0day漏洞的列表，基本上把虚拟次元中究极暗杀术能使用的招式都介绍出来啦！

  

我觉得安全厂商看完后会要背后一凉，安全圈有句玩笑话，100个漏洞你防护住了99个，剩下的1个你没有防护住，你的工作就白干了。而且敝人觉得最搞笑的是收购最后一个漏洞类型，杀毒软件的远程代码执行和本地提权，杀毒软件自己也无法避免安全漏洞，这种例子多不胜数，我印象深刻的一个project zero演示nod32的远程代码执行漏洞，把我都吓尿了，乙方安全厂商面对0day漏洞也硬气不起来～

  

说过了究极暗杀术的招式，那秘穴何在，如何爆的西瓜瓤？我们可以看看zerodium列出来主流点穴手法：

  

LPE: Local Privilege Escalation 本地提权

MTB: Mitigation Bypass 安全缓解措施绕过

RCE: Remote Code Execution 远程代码执行

RJB: Remote Jaibreak 哈哈和JB无关,远程越狱～

SBX: Sandbox Escape 沙盒逃逸

VME: Virtual Machine Escape 虚拟机逃逸

  

我这里着重说说RJB，远程越狱漏洞，zerodium公司花了100万美金悬赏，这种0day漏洞必须是组合漏洞，简单点说就是LPE+MTB+RCE+SBX的大集合，说白了有个有效荷载如网页渲染，网络连接等就可以拿到你手机的最高权限，像我之前描叙过的苹果手机的airdrop漏洞也只能算是RCE,和RJB不是一个量级！
