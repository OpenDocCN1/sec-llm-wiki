# 西湖论剑：赛博研究院将联合发布白皮书

2019西湖论剑•网络安全大会将于4月19日至21日在杭州国际博览中心举行，大会主题为“安全：赋能数字新时代”。届时，**赛博研究院将与安恒信息在“数据安全治理和个人信息保护分论坛”上联合发布数据安全白皮书。**

  

**一、论坛背景**

  

![](../Images/23e33bedc8ea8d569501a41fd70572ad.png)

  

在2019年十三届全国人大二次会议新闻发布会上，国家表示在2019年将推进《数据安全法》立法工作，借此《数据安全法》的立法已经走上快车道。数据安全所需要的是网络开放环境下，动态的安全，且这种安全是相对的。通过《数据安全法》保护数据安全，是为了更好地利用数据，而非让数据处于封闭的状态追求绝对安全。

  

**2019西湖论剑网络安全大会数据安全治理和个人信息保护分论坛****，为本次大会“最炙热话题”。****来自杭州安恒信息、杭州市数据资源管理局、中国科学院信息工程研究所、阿里巴巴集团、浙江大学、上海社科院互联网研究中心、浙江省知识产权法学研究会、上海赛博研究院**等专家和学者，围绕数据安全相关内容，从法律、战略、治理、技术、解决方案等角度分享各自的研究成果和最佳实践。旨在为数据安全领域专业人士和企业提供行业前沿资讯、热点动态以及合作交流平台，促进数据安全行业的安全技术发展和应用。

  

**二、论坛主题**

*   **数据安全治理和个人信息保护**
    
      
    

**三、时间地点**

  

*   **举办时间：2018年4月21日下午**
    
*   **举办地点：杭州国际博览中心 三层会议区**
    
      
    

**四、组织架构 **

  

*   **主办单位：**
    
    **杭州数据资源管理局**
    
*   **承办单位：**
    
    **杭州安恒信息技术股份有限公司**
    
      
    

**五、参会人员及规模**

  

*   **人数规模：250人**
    
      
    

**六、论坛亮点**

  

*   **赛博研究院联合安恒信息发布数据安全白皮书**
    
*   **数据脱敏、加密和云化新品发布**
