**一、企业简介**

![](../Images/ee7ead4545ee814d384ab061883e955a.png)

Tenable是总部位于美国哥伦比亚的一家网络安全公司。十年前Tenable作为漏洞扫描软件Nessus的开发者，一马当先开创了 IT 漏洞管理市场，时至今日，Nessus已成为世界上部署最广泛的 IT 漏洞评估解决方案。如今，随着云、物联网、移动技术带来的数字化转型使得网络攻击面不断扩大，Tenable再一次走到创新前沿，以新兴 Cyber Exposure 市场先锋之姿，助力各种规模的组织重新审视自身如何保障现代数字化企业的安全。

  

Tenable近年来保持高速增长，2015年从Accel和Insight Venture Partners的投资者那里获得2.5亿美元B轮融资，创下业界融资纪录。2018年Tenable在美国纳斯达克上市。

**三、企业发展历程**

*   1998年，17岁的Renaud Deraison发起了"Nessus"计划，目的是为互联网社区提供免费的远程安全扫描器。
    
*   2002年，Renaud Deraison与 Ron Gula、Jack Huffard共同创办了Tenable Network Security。
    
*   2012年，Tenable与In-Q-tel建立战略合作伙伴关系，并获得5000万美元A轮融资。
    
*   2015年，Tenable获得2.5亿美元B轮投资，投资方是Insight Venture Partners和Accel。
    
*   2016年12月，Ron Gula卸任公司CEO，前RSA总裁Amit Yoran成为新任CEO。
    
*   2018年7月，Tenable在美国纳斯达克上市。
    

  

**四、企业团队及背景**

![](../Images/b2b8fa92d8d0fd7e47e01f5974e5633f.png)

主席兼首席执行官：Amit Yoran

Amit于2017年开始担任Tenable公司的CEO。之前他曾在 RSA 公司担任总裁。Amit随 NetWitness 公司（Amit创立的一家网络取证公司）的收购而加入 RSA。此前，Amit 曾在美国国土安全部担任US-CERT的负责人。

Renaud Deraison 是 Tenable 的首席技术官。在联合创办 Tenable 之前，Renaud 通过开发Nessus 重新定义了漏洞管理市场，Nessus 是世界上部署最广泛的漏洞扫描器，下载量超过一百万次。

**五、主要产品及竞争对手**

主要产品

*   Tenable Cyber Exposure 平台：是业内首个能够跨攻击面进行网络风险整体评估、管理与衡量的解决方案。这一平台能针对 IT、云端、IoT 和 OT 环境中的网络风险提供广泛的可见性并进行深度的分析，进而从商业角度衡量并沟通网络风险，最终实现战略决策优化。  
    
*   Tenable.io：是 Tenable Cyber Exposure 平台中的一款组件，采用云端管理，能快速准确地识别、调查 IT 环境中的漏洞和错误配置，并对漏洞和错误配置进行严重级别排序。
    
*   Tenable.sc：准确识别、研究漏洞并对漏洞进行严重级别排序，采用本地管理。
    
*   Nessus：漏洞评估解决方案的行业标准，能够帮助安全专家快速轻松识别并修复漏洞，包括软件缺陷、未安装补丁、恶意软件和配置错误，涵盖多款操作系统、设备和应用。
    
*   Tenable.io Container Security：将安全整合到 DevOps 中，在开发和运营过程中保护容器安全。
    
*   Tenable.io PCI ASV：利用 Tenable.io Vulnerability Management 扫描来简化 ASV 流程，包括遵循 PCI 11.2.2 要求运行扫描、解决争议和准备合规扫描报告。
    
*   Tenable.io Web Application Scanning：对现代和传统 Web 框架进行自动 Web 应用程序扫描。
    
*   Tenable Industrial Security：面向关键基础架构和OT资产，准确识别、研究漏洞并进行优先级分析。

**十一、外部评价及获奖**

*   2019年：Tenable 公司的云漏洞管理产品Tenable.io被SC杂志评为“2019最佳漏洞管理解决方案”；
    
*   2019年：Nessus被SC杂志评为过去30年最重要的产品之一；
    
*   2019年：Tenable的工控安全产品获得ICS/SCADA安全细分领域的银奖（2019 Cybersecurity Excellence Awards）；
    
*   2019年：云漏洞管理产品Tenable.io获得漏洞管理细分领域的银奖（2019 Cybersecurity Excellence Awards）。
    

  

**十二、近期热点新闻**

*   2019/2/19：Tenable推出业界首个集成的网络暴露解决方案，以提供从企业应用到工业控制系统的跨越IT和OT的网络风险的统一视图；
