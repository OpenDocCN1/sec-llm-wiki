# 【投资】安全独角兽Illumio受资本市场热捧，再获6500万美元E轮融资

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247484566&idx=1&sn=5f1173adfa60088d4f64fbbb79fabe02&chksm=fad5bcb4cda235a2ac499a6239620e352ef4fcb99b0cfd4d7edfed2ccc03ce114e171878b53f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247484566&idx=1&sn=5f1173adfa60088d4f64fbbb79fabe02&chksm=fad5bcb4cda235a2ac499a6239620e352ef4fcb99b0cfd4d7edfed2ccc03ce114e171878b53f&scene=27#wechat_redirect)

![](../Images/9ca1e1a6bfe52f02da8f6d02f22382de.png)

**2月11日，美国网络安全企业Illumio再次获6500万美元E轮融资，**新资金将用于开拓市场，尽快帮助公司业务进入欧洲、中东和非洲。**此轮融资是由摩根大通资产管理公司领投**，这也是摩根大通资产管理公司第二次领投，体现出对Illumio高度认可。**截至目前，Illumio共获得17家投资机构，5轮融资，总金额超3.3亿美元**。早在2017年，Illumio获得D轮融资，其估值已经达到10亿美元，成为名副其实的**独角兽初创企业**。

![](../Images/882614cc5510b1c1c60374b7a80e03cd.png)

**一、公司介绍**

Illumio创立于2013年，总部位于美国加州森尼维尔市，由多位网络安全专家创立，是一家专注于动态数据中心和云平台安全的初创公司。

  

Illumio通过构建独特的自适应安全架构，可自内而外地安全监控和防护每个工作单元或应用，而不是基于传统的边界防护，如防火墙。公司主要利用自适应微分隔技术（adaptive micro-segmentation）防止泄露在数据中心和云中扩散。Illumio不仅是全球资本的宠儿，更是说服企业放弃提供临时保护的外围防御系统、升级到能够持续监控系统以发现漏洞的产品的新一代创业公司。

  

目前公司客户有100多家，主要分布在美国、法国、以色列等国家。Illumio的竞争者也有很多，包括Bromium和Tanium，这两家企业同时也是Andreessen Horowitz的投资企业，其他竞争对手还包括凯鹏华盈投资的Shape Security和Ionic Security。

**二、产品优势**

Illumio的核心产品就是其自适应安全平台，可帮助企业分隔网络和用户。该平台含有一个策略计算引擎(PCE)，作为设置网络和用户最佳实践及安全策略的主控节点。此外，还有嵌入工作负载里的虚拟执行节点，确保工作负载遵从PCE定义和管理的策略。

![](../Images/8fbf1a7cd9b9401c9a2d366d8d07add8.png)

自适应安全平台架构

  

Illumio平台的另一主要元素是Illumination功能，提供环境内运行的各种服务的可见性。Illumination会建立一张动态应用依赖映射表，供公司企业查看网络中流转的不同服务。2016年2月，Illumio在该平台中加入了自适应用户分隔功能，让非授权用户看不到也连接不上应用。

  

Illumio开创的安全技术领域叫做自适应安全，主要用于数据安全，即使数据遭黑客攻击后仍可以获得保护。Illumio所采用的技术为自适应微分隔技术，该种技术使用策略驱动的防火墙或者网络加密技术来隔离数据中心、公有云IaaS和容器中的工作负载、应用和进程。自适应微分隔技术打破传统防火墙技术，利用统一的管理和AI技术可以管理具有大规模网络节点的数据中心网络。同时，自适应微分隔技术还能形成网络中的可视化流量，更利于管理员整体把控大规模网络的情况。

![](../Images/10f6a754a910da34f6757b450cdf2691.png)

此外，它还可以为客户呈现 X 光式的数据中心/云服务内部运作视图，使 DevOps、安全、运维人员都可以非常方便地了解安全态势并进行高效操作。同时，Illumio与多家厂商集成以延伸其足迹，包括与F5负载均衡器、思科及Arista交换机协作。如今，Illumio正协商与AWS和微软Azure这样的云平台集成，期望该平台能与云提供商内部的原生安全控制通信。  

  

作为产品背后的理念，illumio提出了面向动态数据中心和云平台的**5大安全准则**：

1）不能依赖基础设施 

2）如果不能理解应用场景就不能有效地安全防护 

3）安全策略自适应的调整可用自然语言来编写 

4）安全可见性必须覆盖到防火墙之后 

5）安全执行可实现自动化

**四、历年融资情况**

  

自2013年以来，Illumio就一直获得资本市场的认可。短短的六年时间内，**公司已经获得5次融资，总金额超3.3亿美元，囊括了17家大中型投资机构**，包括知名科技大佬微软董事长John W.Thompson、Salesforce.com CEO Marc Benioff、 Yahoo创始人杨致远、企业存储明星企业Box CEO Aaron Levie和硅谷风头正劲的四家VC——AndreesenHorowit（著名的“软件吃掉世界”提出者），Formation 8合伙人Joe Lonsdale、Data Collective（投了数家商业分析初创公司）合伙人Matthew Ocko、General Catalyst合伙人（前VMware CTO）Steve Herrod，另外还有新加入的两大巨头：全球最大上市投资管理集团BlackRock和五大VC之一Accel Parners。其中摩根大通资产管理公司和Data Collective (DCVC)参投次数最多，也是说明了资本市场对Illumio的高度认可。

  

**五、事件点评**

**1、准确定位安全细分市场差异化竞争，全渠道覆盖精细化运营**  

Illumio自成立之初，率先推出自适应安全平台，名为“自适应微分段”。该技术实际上借鉴了网络分段的传统做法，使用流量过滤技术在整个公司网络（包括公有云）上实施安全策略，该产品在全球处于领先水平，准确把控住了网络安全细分市场。由此，该公司被评为2017年CNBC颠覆者50强之一。随着融资规模的上升，公司在全力扩大销售，进行品牌传播，加快向欧洲、亚洲拓展的步伐，争取实现全渠道覆盖精细化运营。

  

**2、优秀的管理团队，专注研发和自主创新**

Illumio的管理团队主要来自于安全和计算领域、风投领域的龙头公司，包括Cisco、Juniper、VMware、Nicira、McAfee、Fortify和Riverbed。并且他们基本上精通技术和融资，先后在大型网络安全、风险投资等机构担任过重要职位，成为Illumio发展云和数据中心安全的基石和保障。**从近5次的融资来看，Illumio主要将其募集的资金用于研发和市场销售，大力度投入研发，保持其自适应安全平台的优越性和先进性。**

  

**3、一举成为独角兽，上市指日可待**

早在2015年，Illumio完成C轮融资，其估值已达到10亿美元，成为网络安全独角兽企业，此时距公司走出隐身状态（2014年底）才6个月不到，距A轮融资仅27个月时间。**近期公司将引入业内资深人士Anup Singh担任首席财务官，波音前高管John Hinshaw加入董事会，扩充整个管理层团队。值得注意的是，Anup Singh作为首席财务官的任命意味着Illumio可能将进行IPO方面的尝试。**Singh之前也在上市公司Anaplan、Nimble Storage和Clearwell Systems（被赛门铁克收购）担任类似的职位。优秀产品加管理人才，使得Illumio上市的步伐将进一步加快。
