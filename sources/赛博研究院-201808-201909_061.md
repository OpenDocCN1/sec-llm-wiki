# 【报告】国际货币基金组织：中国数字经济的机遇和风险

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247484516&idx=1&sn=92a8a1a9fb9f494ac32e07490815b4ea&chksm=fad5bc46cda23550eacdface6b6143a5297f475085b0f1961f85a95de10a40091a386c86fc0d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247484516&idx=1&sn=92a8a1a9fb9f494ac32e07490815b4ea&chksm=fad5bc46cda23550eacdface6b6143a5297f475085b0f1961f85a95de10a40091a386c86fc0d&scene=27#wechat_redirect)

![](../Images/6e72fee91c6cd2330e6b43904cc73eb4.png)

国际货币基金组织（IMF）近期报告《中国数字经济：机遇和风险》认为，近年来，中国数字经济快速发展，但经济数字化的平均水平仍不及发达经济体。同时，政府应当发挥主导作用，最大化数字化好处的同时减少有关风险，诸如潜在的劳动力中断、隐私侵犯、新兴寡头垄断，以及金融风险等。

  

数字经济的**狭义定义**仅涉及ICT行业，包括电信、互联网、IT服务、硬件和软件等。**广义定义**不仅包括ICT行业，还囊括了融合数字技术的传统行业。G20基于这一广泛的概念，将数字经济定义为“广泛的经济活动，包括使用数字化信息和知识作为关键生产因素，并将现代信息网络作为重要的活动空间”。

  

![](../Images/a7b3d82bc6765f1c272a93e865835b4d.png)

左：OECD数字经济指数；右：中国信通院数字经济指数

  

不同的定义导致数字经济衡量结果的不同，但无论哪种衡量方法，**中国的整体数字化处于全球中等水平**。经合组织（OECD）的数字经济指数采用狭义定义，显示数字经济占中国GDP的6％，而日韩占据8-10%。中国信息通信技术研究院（CAICT）基于广义定义的衡量结果是，中国数字经济规模约为GDP的30％，自2008年以来翻了一番。美国的规模则是59%。此外，一些混合指数的显示结果也大致相同，比如在世界银行数字采用指数中，中国在131个国家中排名第50位，在世界经济论坛指数中，中国在139个国家中排名第59位。

![](../Images/464214e065ae1e6ce1e64dabae2507c6.png)

左：电子商务占总零售比重；右：支付交易的处理能力

  

在一些重要的数字产业中，中国已成为全球领导者，包括1）**电子商务**：中国占全球交易量的40％以上，电子商务的渗透率（电子商务占零售总额的百分比）现在为15％，而美国为10％。2）**金融科技**：中国公司占全球总估值的70％以上。2016年中国个人消费的移动支付价值总计为7,900亿美元，是美国的11倍。此外，**中国在支付、云计算、ICT产品出口等领域开始扩大全球影响力。**

  

**中国是关键数字技术的全球领先投资者**。根据麦肯锡的估计，中国的风险投资总额已从2011—2013年的12亿美元（占全球总额的6％）激增至2014—2016年的770亿美元（占全球总额的19％），海外投资额为380亿美元。吸引风险投资的主要行业包括大数据、人工智能和金融科技。目前，中国在关键数字技术风险投资者中处于全球前三位。

![](../Images/ba7a2813855e5106e5ab593d5eac0f10.png)

左：宽带渗透率；右：互联网总用户数

  

中国新数字产业的发展离不开政府政策的支持、规模优势和消费者组成的关键驱动力，以及“BAT”（百度、阿里巴巴和腾讯）科技巨头形成的生态系统等因素。近年来，中国经历了快速的数字化。数字经济的规模从2008年的15％飙升至2017年的33％，这主要得益于信息通信技术与传统行业的整合。尽管出现了各种新的ICT行业，但它们的整体规模仍然很小，而且基本稳定在GDP的7％左右。另一方面，数字化传统行业的规模已从2008年的10％扩大到2017年的25％。

![](../Images/7f5d79eae79fe3b4c8e1fc6c04dea267.png)

中国数字行业和数字化传统行业占GDP的比重

  

**各省的数字化程度各不相同。**例如，北京和上海的数字经济接近其GDP的45％，与日本的水平相似；而在河南省中部，数字化规模仅占全省GDP的15％。此外，**数字化程度因行业而异**。总体而言，服务业是数字化程度最高的，信息通信技术占2017年该行业增加值的33％。工业部门滞后，信息通信技术占其增值的17％。农业部门是数字化程度最低的，只有7％的数字化。

![](../Images/e40bca0a304828f6535673e9b7dd4874.png)

左：行业数字化概况；右：省份数字化概况

  

**预计中国将继续快速数字化**。凭借其庞大的互联网用户群，完善的在线生态系统，改善的数字基础设施，由消费者驱动的数字化预计将持续进行。此外，**下一波数字化将更多地来自商业领域，并且生产过程将与ICT更广泛地结合**。如果数字化持续保持高速，那么到2025年中国数字经济的规模可能将达到GDP的近50％，类似于今天日本的水平。

![](../Images/32a5c5278a280a6b2f5ff08799e25fc8.png)

中国数字化展望

  

尽管数字化使效率提升，但随着经济发展逐渐成熟，中国经济的潜在增长将放缓。自2012年以来，中国已经开始从工业到服务业的结构性转变，预计这种转变在未来几十年内将继续。由于服务生产率远低于中国的工业生产率，这种转变将不可避免地给潜在的经济增长带来下行压力。**数字化可以通过提高特定行业的生产率来缓解经济的放缓，特别是如果能够维持当前的高速数字化，但不太可能扭转下行趋势**。

![](../Images/653391f37f4b1dda39f0ed0137998af0.png)

数字化抵冲下行趋势

  

**数字化可能会减少工业岗位，但对劳动力的整体影响不会过大。**中国目前工业领域的机器人强度为5％，而美国为18％，韩国为60％。随着中国经历产业升级，自动化将继续取代低技能工人。不过，中国有能力应对这种冲击，因为预计向服务业的结构性转变将创造数百万个新的就业机会。

  

![](../Images/1f1efbbbd9e15f52eb051d77cf25f847.png)

左：机器人劳动力密度；右：各行业雇佣数

  

**数字化也可能导致劳动力市场两极分化**。中等技术工作的性质使其易于被ICT自动化的精确程序所替代；高技能劳动力执行的任务可对ICT进行补充；由低技能劳动力执行的任务（例如看护服务）被认为不会过多地受到影响。因此，数字化可能导致劳动力市场两极分化，过去在发达经济体中已经广泛观察到这一点（上图显示了美国的经验）。随着中国进入更先进的数字化阶段，这种两极分化也会增加。

  

![](../Images/c84f11e1172fa69d4c0428e05c14af89.png)

各职业群体就业的复合年增长率

  

如果大规模应用人工智能，就会出现就业风险。目前AI仍处于应用的早期阶段，但发展迅速。机器学习是人工智能的一个子集，已经应用并且越来越多，特别是在金融领域。世界银行（2016）估计，中国77％的就业机会易受自动化影响。

  

数字化为经济带来了巨大的利益，同时也带来了风险。数字化可以提高生产力，促进再平衡，并在新的领域创造就业机会。另一方面，数字化可能会破坏传统行业，导致失业。同样，虽然金融科技提高了服务效率，扩大了金融包容性，但也引发了金融稳定性问题，并为监管提出了新的挑战。政府可以发挥关键作用，最大限度地提高数字化的效益，同时将风险降至最低。**主要措施包括**：

*   出台积极的劳动力市场政策
    
*   加强社会保障
    
*   促进竞争并鼓励企业间数据共享
    
*   实行全面的金融科技监管
    
*   数据隐私和消费者保护
    
*   推行电子政务提高公共服务的效率
    
*   继续支持数字基础设施
    
*   注重信息通信技术教育
    
*   在制定全球标准方面发挥更积极的作用
