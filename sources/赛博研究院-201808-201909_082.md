# 【企业】Carbon Black：将端安全做到极致

**一、企业简介**

![](../Images/35e2df23098050c96dd8d185cdc1f148.png)

Carbon Black是2018年在纳斯达克上市的三家网络安全公司之一，成立于2002年，已在端安全领域深耕十几年，并且业务非常专注，只做端安全。其在2014年之前都采用Bit9这个名字，2014年收购安全初创公司Carbon Black后采用“Bit9 + Carbon Black”，直到2016年2月才将公司名称正式改为Carbon Black。

  

其最早期的端防护产品依托“白名单机制”，在技术上采用了与当时市面上的端防护产品截然不同的思路，在网络安全领域做的风生水起。但2013年遭受的黑客攻击事件成为Carbon Black公司的重大转折点，暴露了其产品在端检测和事件响应方面的功能缺陷，正因如此，公司收购了在端检测与事件响应方面具有独特技术的Carbon Black。随后几年，公司在客户数量、营收规模等方面增长迅速，还收购了另外几家公司。目前，Carbon Black主打“下一代端安全”概念，主推其基于大数据分析的云交付安全平台CB Predictive Security Cloud。Carbon Black还与100多家事件响应公司（如Kroll和安永），以及IBM和VMware建立了合作伙伴关系，为其在扩展销售渠道方面带来了重要的竞争优势。

  

2018年，公司自己预测的营收将超过2亿美元，客户数量和营收规模仍保持高速增长，并保持高比例的研发投入占比。作为单一业务厂商，Carbon Black选择了广泛合作的发展战略，是其保持持续增长的重要原因，预计未来几年仍具有增长潜力。

**三、企业发展历程**

*   Carbon Black由Todd Brennan、Allen Hillery、和John Hanratty创立于2002年，当时的公司名称为Bit9；
    
*   2007年任命Patrick Morley为CEO；
    
*   2010年，Bit9获得Goverment Security News颁发的国土安全奖最佳反恶意程序解决方案奖；
    
*   2013年，Bit9收到客户投诉，称其企业内部发现恶意程序，随后Bit9宣布其内部网络被恶意攻击者入侵，Bit9的代码签名证书被黑客盗取；
    
*   2014年2月，Bit9收购了初创安全公司Carbon Black，同时公司获得3825万美元E轮融资，使Bit9的风险投资总额达到约1.2亿美元；
    
*   2015年8月，Bit9宣布收购数据分析公司Visitrend，并在波士顿建立技术开发中心。一个月后，公司宣布将与SecureWorks、安永、Kroll、Trustwave和Rapid7合作，提供安全托管和事件响应服务。
    
*   2016年2月，Bit9将公司名称改为Carbon Black；
    
*   2016年7月，Carbon Black宣布收购下一代杀毒软件提供商Confer；
    
*   2018年5月4日，Carbon Black在纳斯达克交易所上市，以12.5亿美元的估值筹集到约1.52亿美元。
    
      
    

**四、企业团队及背景**

![](../Images/415ac004a773d316876e2d858f2a570d.png)

 CEO：Patrick Morley

在2007年加入Carbon Black之前，Patrick Morley曾在身份与访问管理提供商Imprivata 公司担任CEO和主席。他还曾在六家软件公司担任过高级领导职务，其中三家公司已成功IPO。作为Corel公司的首席运营官，他曾负责该公司在美洲、欧洲和亚洲的全球销售、营销和运营，并在该公司的扭亏为盈、收购策略以及最终的IPO过程中发挥了重要的领导作用。Morley还在Macromedia、Allaire、Rational Software和SQA公司担任过高级管理职务。

  

Scott Lundgren是Carbon Black的首席技术官和首席架构师，也是前Carbon Black创始团队的成员。他拥有丰富的安全技术经验，并在多个公司担任过技术领导职务，包括微软、 AVID Technologies、 Northrop Grumman、 ManTech、 JASK等。

业务开发高级副总裁：Tom Barsi

Tom Barsi于2013年加入Carbon Black。在此之前，他曾于2010-2013年担任网络安全公司Proofpoint的业务开发副总裁；2009-2010年担任VeriSign认证业务部门的业务开发副总裁；此外，Barsi也是Consensus Networks公司的创始CEO, VINA Technologies公司的联合创始人兼业务开发副总裁，并在该公司的IPO中扮演了关键角色。

  

**五、企业优势及竞争对手**

主要产品及服务

云平台：

*   CB Predictive Security Cloud：通过云提供安全性的终端保护平台。
    

云服务：

*   CB Defense：下一代反病毒和终端检测与响应；
    
*   CB ThreatHunter：威胁追踪和事件响应；
    
*   CB ThreatSight：警报监控托管和分类；
    
*   CB Defense for VMware：虚拟数据中心安全。
    

特定环境保护：

*   CB Response：针对SOC的威胁追踪和事件响应；
    
*   CB Protection：应用控制和基础设施保护。
    

  

产品优势

*   **差异化的技术**：Carbon Black的预测性安全方法能持续捕获未过滤的端点活动，并使用事件流处理、动态和静态行为分析、机器学习和信誉分析以及评分等分析技术进行实时和回顾性分析；
    
*   **可扩展的下一代安全云平台**：Carbon Black云平台的可扩展架构可使其产品功能得到增强和扩展，以满足不断变化的客户需求；
    
*   **应用程序控制的先驱**：Carbon Black在其应用程序控制解决方案CB Protection中开创性的开发了零信任模型；
    
*   **基于未过滤的终端数据和开放平台的强大生态系统；**
    
*   **与IBM和VMware建立了战略合作伙伴关系。**
    

  

竞争对手

*   反病毒解决方案提供商，如McAfee、Symantec；
    
*   网络（Network）安全供应商，如Palo Alto Networks、FireEye、Cisco；
    
*   其他非上市公司，如Crowdstrike、Cylance等。
    

  

主要客户及区域范围

Carbon Black在全球拥有4625家客户，包括全球财富100强中的35家企业，遍布互联网搜索、社交媒体、交通运输、酒店业、金融、制造、零售等行业和政府部门。Carbon Black的客户数量增长非常迅速，年复合增长率达45%。知名客户包括三星、飞利浦、美国职棒大联盟、美国国家冰球联盟、Medibank私人保险等。
