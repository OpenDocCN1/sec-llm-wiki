# 2018网络安全产业创新（上海）论坛即将盛大召开

仲冬望日，上海将迎来年度网络安全大会——**2018网络安全产业创新（上海）论坛**。

**会议概况**

随着互联网飞速发展，网络安全威胁日益复杂严峻，成为了各国新的重大战略议题，网络安全产业也迎来了重大发展机遇。12月19日，**2018网络安全产业创新（上海）论坛**将隆重召开。届时，论坛将广邀学界大咖和业界精英，把握网络安全产业机遇，创新网络安全产业思路，**打造产研投用协同创新生态，助力上海网络安全产业腾飞**。

![](../Images/e6b79d06e73101411e914e911fc5e849.png)

**鼎力支持**

本次论坛在上海市经济和信息化委员会、上海市普陀区人民政府指导下，由上海赛博网络安全产业创新研究院和上海工业控制安全科技创新有限公司主办，上海市信息安全行业协会和《信息安全与通讯保密》杂志社协办。安恒信息、观安信息、优刻得和上海控安等国内知名网络安全企业将在论坛分享最佳实践。
