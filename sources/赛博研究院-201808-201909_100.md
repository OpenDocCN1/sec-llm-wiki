# 新闻 | AI安全与透明化：IBM推出技术集成平台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247483973&idx=2&sn=5d7d4849ff04aba601858f53241cf3a2&chksm=fad5ba67cda233712a269075c720c9ad1041135670a5a0e73bed3c542210376f9ea1446671d4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247483973&idx=2&sn=5d7d4849ff04aba601858f53241cf3a2&chksm=fad5ba67cda233712a269075c720c9ad1041135670a5a0e73bed3c542210376f9ea1446671d4&scene=27#wechat_redirect)

10月15日，IBM同时推出3款技术集成平台，即IBM AI OpenScale、Multi-cloud Manager、IBM Security Connect。这3款平台旨在**帮助企业组织更高效地对不同供应商开发的AI技术、云技术和网络安全技术进行集成**，节省时间和金钱成本。这些平台将先后于今年年底至明年年初投入商业运营， 贯彻IBM公司致力于打造AI、多重云、网络安全集成商的战略。

  

![](../Images/e262d665f8c3a77137286ca34be238dc.png)

  

**一、AI OpenScale：集成各家AI程序，**

**打破AI黑盒**

  

AI OpenScale平台以IBM 云和IBM云服务（Cloud Private）两个产品为基础，用于运行及调试AI程序，包括算法偏见的检测。该平台支持Watson、Tensorflow、Keras、SparkML、AWS SageMaker、Azure ML等框架下开发的AI程序。

  

IBM公司的“**神经网络综合引擎**”（NeuNetS）是AI OpenScale的重要组件之一，它可以用于创建AI并使其自动运行。IBM公司Watson AI总经理贝斯·史密斯（Beth Smith）指出，NeuNetS可以节省数据科学家的时间，并且弥补企业在AI开发方面的技能空白。  

  

AI OpenScale具有以下功能：（1）解释AI推荐的决策结果是如何得出来的；（2）通过某种技术，自动防止偏见；（3）通过NeuNetS组件，使企业快速、自动地创建神经网络；（4）可使用开源的机器学习或深度学习模型，如Tensorflow、Scikitlearn、Keras 、SparkML，也可使用在公共环境中训练、部署的程序和模型，如IBM Watson、IBM PowerAI、Seldon、AWS SageMaker、AzureML等。

  

**二、Multi-cloud Manager：集成各家**

**云程序**

  

Multi-cloud Manager是一个基于Kubernetes的业务平台，运行于IBM Cloud Private上，该平台所使用的控制面板可以集成和管理Amazon Web Services、Red Hat、Microsoft等云端应用。

  

Multi-cloud Manager的特点包括：（1）业务小组和开发小组**通过单个控制面板，就可以清楚地查看多种云和集群上的Kubernetes程序和组件**。（2）使用综合的规则引擎，确保Kubernetes程序适应其规则政策和安全标准。（3）简化IT和app业务管理，同时增加灵活性，可以一键管理Kubernetes环境。

  

**三、IBM Security Connect：集成各家**

**网络安全程序**

  

IBM公司指出，企业中网络安全小组通常使用多达40个供应商总计过80种不同的网络安全工具。然而，**这些纷繁多样的网络安全工具所配备的许多功能其实都派不上用场，同时这些应用软件的集成也是个大问题。**

  

IBM Security Connect计划以单一的平台，集成IBM公司和其他网络安全厂商的技术，可集成的厂商包括Cisco、Capgemini、Carbon Black、EY、ForeScout、Forcepoint、Fortinet、McAfee、Qualys、Smarttech、Symantec、Trend Micro、VMware。

  

上述公司已经在IBM Security App Exchange上开发了数百种程序，它们也承诺为该平台开发其他集成应用。而新推出的IBM Security Connect平台，完全融合IBM Security App Exchange及其中所有的安全程序。值得一提的是，**新平台将由AI来驱动**，IBM也将开放该平台的框架、微服务、软件开发组件和编程接口。
