# 新闻 | 美参议院讨论使用区块链保障电网安全

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247483800&idx=1&sn=7623fc9b091f1871f2daaf5ab30fc6da&chksm=fad5b9bacda230ac17a798ce47cd3167293561d9683b9b2a241660b47ea97de62cef035b1592&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247483800&idx=1&sn=7623fc9b091f1871f2daaf5ab30fc6da&chksm=fad5b9bacda230ac17a798ce47cd3167293561d9683b9b2a241660b47ea97de62cef035b1592&scene=27#wechat_redirect)

![](../Images/ff1ebb3720b018b6a9f414ad0f988bcf.png)

8月21日，美国参议院能源与自然资源委员会举行关于“区块链及类似技术能效”的听证会。该听证会主要讨论了下述问题：**1）由于区块链带来的电力需求上涨，是否应当提升电力价格？2）区块链及类似技术在将来是否可以提升能源供应计算系统的网络安全？**此次听证会由参议院能源与自然资源委员会主席丽萨·穆尔科斯基（Lisa Murkowski）、首席成员玛利亚·坎特韦尔（Maria Cantwell）做开场白，与会者包括太平洋西北国家实验室（PNNL）、电力研究所（EPRI）、能源网络基金会、普林斯顿大学等机构的专家等。

  

  

![](../Images/fa33139af2e8091954708fba7e1ecaa4.png)

  

**一、比特币应用的突出问题：能耗大**

  

丽萨·穆尔科斯基在开场白发言中指出，比特币系统需要“挖矿”行业夜以继日地维持运行，矿工们负责验证区块链的可信度，因而这个新行业需要大量电力。矿工蜂拥至电价最低的地方，对当地公共事业造成严重压力并且对电网造成影响，引发了新的研究议题。玛利亚·坎特韦尔也表示，区块链给政府能源机构带来挑战，用于挖矿的电力正在增加，1枚比特币发生交易需要耗费一个荷兰家庭1个月的电量。

  

**二、区块链的其他应用：电网安全**

  

坎特韦尔指出，区块链具有其他可观的应用前景，可以保障现有能源电力系统的网络安全、促进清洁能源公司发展，越来越多的清洁能源公司正在使用区块链应用。能源网络基金会（Energy Web Foundation）常务董事克莱尔·亨利（Claire Henly）指出，在比特币系统中，区块链被用来建立一个安全的分布式账本；而在电网系统中，区块链可以用来建立一个分布式电力网络，它如同一台“分布式计算机”，不再是中央控制的，在灾害面前更具适应能力。

  

** 三、能源公司开始关注区块链应用**

  

目前，太平洋西北国家实验室（PNLL）在能源部“能源传输系统网络安全”项目的支持下，正在探索将区块链用于电网的网络安全。一些能源公司也准备进入该领域，电力研究所（EPRI）近期召集了40家能源公司，组成“公共事业区块链兴趣小组”（Utility Blockchain Interest Group），探讨研究成果、技术情报、前期试验结果等。

  

**四、探寻区块链应用出路**

  

目前，比特币过大的能耗是一个突出的问题，除了比特币以外，还有其他数以百计的区块链应用，都面临能耗问题。能耗过大，源于比特币使用的PoW算法。克莱尔·亨利指出，改进的PoS、PoA算法可以使区块链更加节能，但也需要不少功耗。

  

PNLL首席网络安全官保罗·斯卡勒（Paul Skare）认为，比特币采矿对能源的影响多见于媒体报道而鲜有定量研究，应正确理解加密数字货币的需求弹性，认识加密数字货币对美国电网的长期影响。他还指出区块链应用存在的其他问题，比如不需要的数据若保存在区块链中，则很难更改，除非控制51%的节点。

  

此外，参加听证会的普林斯顿大学教授阿尔温得·纳拉亚南（Arvind Narayanan）指出，区块链仅仅只是解决电网安全问题的路径之一，实现电网安全的方案并非一定需要采用区块链技术，应当具体问题具体分析，选用最佳的工具解决问题。
