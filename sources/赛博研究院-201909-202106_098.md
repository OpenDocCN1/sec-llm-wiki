# 【培训】CISP-PIP认证培训（上海第01期）成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247488256&idx=1&sn=9211056cf63b0f0b30d0f65015847835&chksm=fad5ab22cda2223468eb51777617025f37eb6fb21bb47b62ae0d1ca90df2777e5f034b7ce43a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247488256&idx=1&sn=9211056cf63b0f0b30d0f65015847835&chksm=fad5ab22cda2223468eb51777617025f37eb6fb21bb47b62ae0d1ca90df2777e5f034b7ce43a&scene=27#wechat_redirect)

近日，赛博研究院成功举办CISP-PIP认证培训（上海第01期）。本次培训采用线上授课、线下答疑和考试的方式，充分保障学员健康，同时，线上授课教师与学员积极互动。课程体系以个人信息安全保护为主线，以落实政策、衔接国际、注重实效为基本原则，兼具理论性和实操性。授课老师均为参与国家网络安全顶层设计的行业大咖。

**1**  

**CISP-PIP认证**

  

CISP-PIP（Certified Information Security Professional - Personal Information Protection）注册个人信息保护专员，是国家级个人信息保护专业人员资质评定。该认证主要面向数据保护、信息审计、法律合规、风险管理、安全监管等领域的专业人员，旨在帮助组织全面构筑个人信息保护的专业队伍和专业能力，有效提升数字经济时代各类组织数据合规和治理水平。  

  

**2**

**CISP-PIP培训认证课程体系**

  

CISP-PIP知识体系分为通用知识与数据安全知识两部分。通用知识部分在继承CISP体系大纲基础上重新设计，包括国家网络安全顶层设计、网络安全体系结构、安全管理与工程共3个知识域；数据安全知识部分包括数据安全基础、个人信息安全规范、个人信息保护实践、个人信息安全标准体系、行业个人信息保护共5个知识域。
