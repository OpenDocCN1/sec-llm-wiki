# 【资讯】美国国家人工智能安全委员会（NSCAI）批准了71条建议以促进美国AI战略

Meritalk网站10月9日消息，美国家人工智能安全委员会（NSCAI）当日批准了71项与人工智能相关的建议（草案）。NSCAI的最终报告定于2021年3月发布。

  

NSCAI的建议、临时报告以及批准草案的会议都集中在下述六个“努力方向”上，旨在支持美国确定相应路线，在国际AI竞争中保持领先地位：

![](../Images/d17c78adb24cb1c1143a8769386b9a68.png)

●  在AI研究与开发方面，加强学术、政府和产业的三角联盟；  

●  将AI应用于国家安全任务；

●  培训和招聘AI人才；

●  保护和利用美国技术优势；

●  引领全球AI合作；

●  符合伦理的可信AI。

  

此次更新与委员会第二季度报告中的努力路线相同，是NSCAI在2019年发布初始报告之后的第二份中期报告。
