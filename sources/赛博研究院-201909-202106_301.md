# 首本论述人工智能等新兴技术赋能公共安全专著在沪预发布

7月10日，2020世界人工智能安全高端对话在上海世博中心成功举办。论坛上，**赛博研究院和腾讯安全战略研究部联合预发布了《人工智能时代公共安全风险治理》最新图书。**腾讯秉承“科技向善”的愿景和使命不断打造数字化产品，赛博研究院则致力于全球数字转型时期护航产业健康发展。此次双方结合疫情背景，围绕科技赋能公共安全治理开展深入研究，是应对全球公共安全风险治理难题的一次极具意义的探索实践。

  

![](../Images/8a55f750d8d32d1e11a77838ccf2f05f.png)

  

该书呈现六大亮点，一是立意高远，面向新时代国家治理体系和治理能力现代化建设；二是贴合现实，全面总结新冠疫情背景下科技抗疫全球实践；三是选题新颖，这是首本论述人工智能等新兴技术赋能公共安全的专著；四是理念创新，以科技与人文融合视角探索科技善治的前沿思想；五是案例翔实，汇聚国内外科技助力公共安全治理最新最全实践案例；六是数据支撑，基于多维度大数据的公共安全风险治理实证观测。

  

![](../Images/beaa1419334ee9d1b600342e383e979f.png)

  

***风险社会下“黑天鹅”事件频发***

  

21世纪第二个十年，全球加速迈入人工智能时代，然而科技进步和经济发展并没有让人类告别各类风险。从非典到新冠疫情，在“黑天鹅”事件频发、世界联系日益紧密的大背景下，全球面临一系列公共安全风险治理考验。该书从西方视野和本土视角观察了现代风险社会的理论脉络，重点介绍了自然灾害、故事灾难、公共卫生安全、社会安全等四大类风险类型，总结出风险社会下公共安全事件存在高度全球性、复杂交织性、突出人为性、泛化的不确定性等特征。

  

***全球加强新兴技术赋能公共安全***

  

人工智能时代，新兴技术向着集成化、智能化、综合性、普适性、实时性的方向发展。对此，全球各个国家和地区普遍重视人工智能等在公共安全领域的巨大潜力。美国公共安全科技政策体系完备、重视新兴技术研发，应用领域广泛，同时解锁政府数据，打造双向人工智能生态系统。欧盟强化统一协调的民防机制科技应用，高度重视科技应用带来的数据和隐私保护等安全问题。中国则深度挖掘人工智能、大数据、物联网、5G等新兴技术在公共安全领域的应用，并在垂直领域出台多项政策，全面提升中国公共安全风险治理能力。此外，新加坡、英国、法国、韩国等多国通过打造技术新引擎，积极强化人工智能在公共安全领域的应用。

  

***科技企业践行公共风险治理之举***

  

当前，相关公共安全科技应用正在从识别性应用、描述性应用逐渐向分析性应用、预测性应用、决策性应用等阶段发展。该书汇聚了国内外科技企业在自然灾害、事故灾难、社会安全和公共卫生安全等诸多领域的创新实践。如在新冠肺炎疫情期间，包括人工智能、大数据在内的新技术被广泛应用于智能诊断、健康码、线教育、智能配送、无人工厂等领域。这背后离不开国内外如腾讯、谷歌、脸书等知名科技企业开发支撑的“黑科技”应用。数据显示，腾讯防疫健康码累计亮码130亿人次，覆盖20多个省400多个市县，并率先提出了“码上城市，一码通行”的疫后新图景。

  

***重塑我国公共安全风险治理能力***

  

该书认为，人工智能时代公共安全治理体系和治理能力现代化，应从战略统筹、法治建设、技术引领、产业协同、人才支撑、文化培养等方面，充分发挥政府、科技企业、民间的协同力量，打造公共安全风险预警感知和有效应对的完善体系。同时，也需秉持以人为本、科技向善的原则理念，加强信息公开与数据开放、个人隐私保护，避免算法歧视、强化数字包容，实现公共安全风险治理中科技与人文的互动融合。
