# 【资讯】美中经济与安全评估委员会发布有关中国智慧城市的报告

美中经济与安全评估委员会（U.S.-China Economic and Security Review Commission）4月29日发布报告《中国智慧城市发展》（China’s Smart Cities Development）。报告探讨了智慧城市在中国的发展情况，主要分析了以下内容：中国的智慧城市政策、中国智慧城市的发展趋势、智慧城市相关技术作为中国监测系统的一部分得到实施、中国在国外推广智慧城市相关技术、中美关系背景下的智慧城市发展。最后，报告总结了美国与中国智慧城市发展能力，并评估了中国智慧城市相关技术在美国关键基础设施中广泛部署可能带来的国家安全风险。

  

![](../Images/649f850eb6e59ce38641c03e0aa11faa.png)

  

为确保美国在海外智慧城市市场中的全球竞争力、国家安全利益以及美国公民的隐私，报告提出：

  

1）为了更好地量化外国智慧城市相关技术在美国国内系统中的部署，鼓励建立本地和区域监督工作组，收集更准确的数据，确定外国对本国基础设施投资的潜在风险，并构建完善信息共享机制。

  

2）为减轻中国智慧城市相关技术的全球影响力，需支持美国在国际智慧城市市场上发挥竞争力。

  

3）支持美国参与国外的标准制定和智慧城市相关技术采用。

  

4）优先考虑“五眼”国家/地区、条约盟友和美国拥有军事基地的国家/地区，以确定这些国家/地区的政府机构和关键基础设施中是否存在因使用中国产品而产生的漏洞。

  

5）通过立法明确关键基础设施类别，保护基础设施免受对立/侵略性情报收集国家的供应链渗透。
