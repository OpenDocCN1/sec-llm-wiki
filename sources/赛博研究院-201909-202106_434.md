# 【资讯】智能化数据保护公司SECURITI.ai荣获RSAC2020创新沙盒冠军

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247485814&idx=2&sn=743907a2bcf7d2e2b5439d1f35ac92c1&chksm=fad5b154cda238420aa1524d57a59001217086d3d1c7317dbcc1c3fd325a6c9b2ed812dd35d2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247485814&idx=2&sn=743907a2bcf7d2e2b5439d1f35ac92c1&chksm=fad5b154cda238420aa1524d57a59001217086d3d1c7317dbcc1c3fd325a6c9b2ed812dd35d2&scene=27#wechat_redirect)

RSAC2020官网2月24日消息，SECURITI.ai公司荣获2020年RSAC创新沙盒的冠军。Securiti.ai公司成立于2018年，是由AI驱动的PrivacyOps平台的领导者，通过使用机器人自动化和自然语言界面执行并简化隐私合规性，使企业可以赋予人们相关的数据权利，成为数据负责任的保管人并遵守《通用数据保护条例》（GDPR）、《加州消费者隐私法》（CCPA）等全球隐私法规。

  

![](../Images/5dcfc2eea1b8739653972f1e83ee8b4d.png)

  

十强初创企业中，应用安全相关企业占半数，其次是云安全，此外还包括安全意识教育、隐私保护及邮件安全领域的初创企业。RSAC2020创新沙盒大赛的其他九家决赛入围企业简介如下：  

**AppOmni**

AppOmni成立于2018年，其解决方案主要针对SaaS应用提供数据访问的可见性、安全性、合规性，平台组件包括安全自动化、合规控制以及IT管理。AppOmni目前支持扫描各类SaaS产品，并借此找到包含各类个人身份信息的数据类型。

  

**BluBracket**  

BluBracket成立于2019年，提供企业级代码安全解决方案，能够发现并保护开发者的代码环节，提升开发效率。BluBracket代码安全解决方案提供两个组件，CodeInsights实现代码环境可见性，支持代码分类，满足合规性需求；CodeSecure能够识别、防止代码从企业中意外或恶意的泄露，并对代码进行风险评估响应。

   

**Elevate Security  
**

Elevate Security成立于2017年，主要利用四大组件对企业内部人为因素开展管理：Reflex负责运行基准评估，并对员工活动进行指标分析；Vision允许安全管理员对员工行为及相关风险做出分析；Pulse负责为员工提供培训，帮助他们改善自己的高风险行为；Hacker’s Mind则是一种游戏化培训方案，旨在增强员工个人乃至团队的整体安全意识。

  

**ForAllSecure**  

ForAllSecure公司成立于2012年，专注于通过提升代码质量解决安全问题。该公司的Mayhem产品利用“下一代模糊测试”持续检测代码当中是否存在安全缺陷。ForAllSecure与BluBrcacket公司的解决方案都是致力于保障应用开发环境的安全，前者是聚焦于模糊测试，后者是侧重在代码安全。

  

**Inky Technology**

Inky公司成立于2008年，主要提供Cloud-base邮件安全解决方案，除了针对恶意软件，垃圾邮件防护之外，还利用人工智能技术和机器学习对网络钓鱼邮件进行提前识别与阻止。

  

**Obsidian Security**  

Obsidian Security公司成立于2017年，最关注的是SaaS应用架构，凭借独有的Web服务加固企业SAAS账号，保护账号不被接管和未经批准的第三方应用访问数据，暴露新的威胁并检测内部威胁，并提供安全响应工具来应对威胁。

  

**Sqreen**  

Sqreen公司成立于2018年，其解决方案聚焦于应用程序安全防护。对于应用开发和安全运营的场景，Sqreen平台的模块包括RASP（Runtime Application Self-Protection）、 In-App WAF、Security Header以及通过虚拟补丁防止应用程序漏洞被利用，为开发人员提供了从应用程序收集到的安全漏洞信息及响应措施。

  

**Tala Security**

Tala Security公司建立于2016年，为Web应用程序带来更加可靠的安全层，旨在保护服务器及其应用程序免受各类客户端威胁的影响。其系统能够抵御包括Magecart、域名劫持、会话重新定向在内的多种具体威胁。

  

**Vulcan Cyber**  

Vulcan Cyber公司成立于2018年，聚焦于新一代的漏洞管理。Vulcan提供一套用于自动化管理修复流程的平台，帮助企业降低安全漏洞带来的影响。该平台使用应用程序与安全基础设施API，从而实现安全工具与所保护产品乃至与上报目标端的顺畅集成。
