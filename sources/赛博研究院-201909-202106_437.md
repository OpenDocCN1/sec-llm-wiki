# 【报告】欧盟委员会：欧洲数据战略

**【编者按】**2020年2月19日，欧盟委员会发布《欧洲数据战略》（A European Strategy for data），全文包括背景介绍、关键点、愿景、问题、战略、国际路径、结论以及附录（欧洲战略部门和公共利益领域公共数据空间创建计划）等八个部分。该战略在尊重欧洲核心价值观基础上，通过建立跨部门治理框架、加强数据基础设施投资、提升个体的数据权利和技能、打造公共欧洲数据空间等战略措施，抓住新一轮数字化转型的契机，将欧洲打造成世界上最具吸引力、最安全和最具活力的数据敏捷经济体（data-agile economy）。

**1**  

  

**背景介绍**

  

  

数据技术已经改变了欧洲经济和社会发展模式，数据驱动型创新将为公民带来巨大利益。同时欧洲非个人数据和公共数据的高速增长，以及数据存储和处理技术变化也是数据创新的潜在来源。欧盟应当赋予每个公民利用非个人数据进行决策的权利，这将有助于经济社会的创新和竞争，并确保每个公民从数据中获利。**数字化欧洲应该反映出欧洲最好的状态，即开放、公平、多样、民主、自信。**

  

欧盟希望成为商业领域和公共部门中利用数据进行决策的榜样。为了实现这一愿景，欧盟必须建立一个强大的、覆盖各个行业及企业内部竞争市场的立法框架。**该数据战略概述了欧盟未来五年实现数据经济所需的政策措施和投资策略。**在这一战略的基础上，委员会就采取哪些具体措施使欧盟立足于数据敏捷型经济的最前沿，同时尊重并促进欧洲社会价值观展开了全面磋商。

  

**2**  

  

**面临的风险**

  

  

**数据海量增长，技术日新月异：**在未来5年，数据存储和处理的方式将发生巨大变化。如今，80%的数据处理和分析发生在数据中心和集中式计算设施中，只有20％发生在智能连接对象（汽车、机器人等）和边缘计算网络中。但是到2025年，这一比例可能会发生反转。这一趋势除了经济发展和可持续性优势外，还为企业开发新型工具提高数据控制力提供了更多机会。

  

**数据对经济和社会发展的重要性：**数据是经济发展的命脉，对于初创企业和中小型企业而言，它是开发产品和服务的重要资源。数据的可用性是训练人工智能系统的关键要素，此外开放更多的数据并改善数据使用方式对于应对社会、气候和环境方面的挑战，建立更健康、更繁荣和更可持续的社会至关重要。

  

**欧盟为应对未来数据经济发展做好准备：**当前，少数几家科技巨头拥有全球大部分数据。这将阻碍欧盟数据经济的兴起、发展和创新。但是未来大部分数据将来自工业和专业应用，公众关注的领域或日常生活中的物联网应用等欧盟实力雄厚的领域。**今天的赢家不一定是明天的赢家，欧盟具备发展成为数据敏捷型经济体潜力。**欧盟拥有专业知识、技术以及高质量劳动力。但是中国和美国等竞争对手已经迅速开始了数据创新，并在全球范围内推广其数据获取和使用的概念。为了释放欧洲的发展潜力，**委员会必须找到欧洲式道路，平衡数据流动和广泛使用，同时建立高度的隐私保护机制、数据安全措施和道德标准。**自2014年以来，欧盟委员会已采取了许多措施。通过《一般数据保护条例》（GDPR）,欧盟为数字信任创建了坚实的框架，此外促进数据经济发展的其他举措还包括《关于非个人数据自由流通的规定》（FFD），《网络安全法》（CSA）和《开放数据指令》（Open Data Directive）。欧盟委员会还参与了数字外交，承认13个国家为个人数据提供了同等水平的保护。

 

**3**  

  

**未来愿景**

  

  

![](../Images/39412ad831bce63e3414c11c2cb5d268.png)

  

欧盟委员会未来愿景建立在欧洲价值观和公民基本权利之上，以及对以人为本核心信念的深信不疑。

  

欧盟委员会深信，基于数据来制定更好的决策以增强欧盟企业和公共部门的能力。

  

欧盟应该创造一个有吸引力的政策环境，到2030年，欧盟在全球数据经济中的市场份额至少与其经济实力相对应。

  

欧盟委员会的目标是创建一个**单一数据空间——一个真正的数据单一市场且面向世界开放，其中个人和非个人数据（包括敏感的业务数据）都是安全的，企业也可以轻松访问无限的高质量工业数据，并利用数据促进经济增长、创造价值，同时最大程度地减少人为碳排放和环境破坏。在此数据空间中，欧盟法律可以有效执行，所有数据驱动型产品和服务都应符合欧盟数据单一市场的相关规范。**

  

**4**  

  

**现存问题**

  

  

欧盟成员国之间的碎片化是建设公共欧洲数据空间以及进一步实现真正数据单一市场所面临的重大挑战。许多成员国开始调整其法律框架，其中的差异突出了采取共同行动以发展内部市场的重要性，在以下问题上将需要共同取得进展：

  

●** 数据的可用性：**数据的价值在于使用和复用。当前没有足够的数据可用于创新性的重复使用，包括用于人工智能数据开发。

● **市场能力失衡：**除了云服务和数据基础设施供给市场的高度集中，数据访问和使用方面也存在市场失衡。“数据优势”带来的高度市场支配力使得国际大型科技企业可以在平台上设置规则，单方面为数据的访问和使用设限，或者在开发新服务时利用这种“能力优势”拓展新市场。

●  **数据的互操作性和质量：**数据的互操作性、质量、结构、真实性和完整性都是开发数据价值的关键，特别是在人工智能应用背景下。数据生产者和数据使用者已经发现了重大的互操作性问题，这些问题阻碍了部门内部以及部门之间不同来源数据的组合。

●  **数据治理：**为了使这些数据空间能够有效运作，需要立足于现有的法律框架，选择合适的组织方式和治理架构，以实现数据驱动型创新。

●  **数据基础设施和技术：**欧盟经济数字化转型取决于数据中心和边缘网络数据的安全性和能效，以及高质量数据的处理能力、数据可用性和可获取性，欧盟需要减少战略基础设施中的技术依赖性。

●  **赋予数据主体行使数据权力的能力：**消费者在使用物联网设备和数字服务时会生成越来越多的数据，因此可能面临算法歧视、不公平做法和“锁定”效应等风险。需要为个人提供工具和手段，以在更加精细的颗粒级别上决定如何处理其数据；提供无障碍的公共和私人服务访问权限；提高对个人数据的更大监督力度和透明度。

●  **数据技能和素养：**当前，大数据及其分析邻域关键技能短缺。2017年，欧盟在大数据及其分析领域大约有496000个空缺职位，劳动力和人口总体数据素养相对较低。

●  **网络安全：**新的数据发展范式将更少的数据存储在数据中心，更多的数据将处于边缘网络，这给网络安全带来了全新的挑战。

 

**5**

  

**数据战略**

  

  

![](../Images/bd2e3644e342ca4ce65a82bf31dccb2f.png)

  

欧盟数据战略旨在建立真正的单一数据市场，每一项新的立法措施都将在完全符合“更好监管”（Better Regulation）原则下进行准备和评估。新的立法措施将基于以下四大支柱：

  

**A、 面向数据访问和使用的跨部门治理框架**

欧盟委员会旨在通过构建一个监管框架，从而促进具有活力的数据生态系统的发展。委员会放弃过分详细、过分严苛的事前监管，而倾向于采用敏捷型数据治理方法，例如试验（监管沙箱）、迭代和差异化。

  

首先，**基于敏捷数据治理原则，首要任务是为欧盟数据空间治理建立一个有效的立法框架（2020年第四季度）**。该框架将加强欧盟成员国之间的协同性体系建设，促进特定部门或特定领域的产业创新，解决以下一个或多个问题：加强欧盟和成员国与跨部门数据使用以及公共部门数据空间的治理机制；基于GDPR，帮助决定哪些数据可以使用，如何使用、由谁基于何种目的使用；基于GDPR，让有“数据利他主义”（data altruism）意愿的个人更方便地将他们产生的数据用于公共产品。

  

其次，**欧盟委员会将促进更多高质量公共部门数据得以重新利用，特别是对中小企业发展的潜在影响。**基于开放数据指令（Open Data Directive）,委员会将尽快通过《高价值数据集应用法案》（2021第1季度），使这些数据集在整个欧盟范围内以机器可读的方式，通过标准化应用程序接口（API）免费开放。委员会将着手研究各种机制，以满足中小企业特殊需求。它还将帮助成员国在2021年7月17日之前顺利适应开放数据指令的新规则。

  

再者，**委员会将就影响数据敏捷型经济体系中各主体关系议题探讨立法行动的必要性，以此促进跨部门的数据共享。**计划2021通过《数据法》（Data Act）解决以下一个或多个问题：促进企业与政府的数据共享；支持企业对企业的数据共享（尤其是共生数据，例如物联网生成的数据）；以公平、合理、透明的方式支持数据的可访问性；评估知识产权框架，进一步加强数据的访问和使用。此外，委员会将评估有关建立数据池（用于数据分析和机器学习）等一系列措施。

  

最后，**委员会将加强对数字经济中数据作用的探索研究。**网络平台经济观察站正在分析科技巨头积累的海量数据、数据在创新或导致议价能力失衡方面的作用以及这些公司跨部门使用和共享数据的方式。在事实调查基础上，欧盟委员会将考虑如何最好地解决有关平台和数据的系统性问题，包括在适当时通过事前监管确保市场开放和公平。

 

**B、 推动因素：面向数据、增强欧洲能力和基础设施的投资**

  

基于欧洲蓬勃发展的数字生态系统，欧盟数据战略将从数据中汲取能量以创造经济和社会价值。欧盟将提供一个发展环境，以支持数据驱动型创新，并刺激以数据作为重要生产要素的产品和服务需求。

  

●  **投资高影响力项目：欧洲数据空间和联邦云设施。**

**委员会计划资助战略部门开展欧盟范围内互操作性数据空间建设。**该数据空间旨在通过组合必要的工具和基础架构以解决信任问题，例如：通过制定数据空间通用规则，克服跨组织共享数据的法律和技术障碍。这些项目将致力于：部署数据共享工具和平台；建立数据治理框架；针对特定领域和跨部门提高数据可用性、质量和互操作性。资金还将用于支持成员国开放高价值数据集，以便在不同的公共数据空间中重复使用。

  

**联邦云基础架构将促进云上集中式的数据基础架构与高度分散式的边缘智能数据处理架构的平衡发展。**该项目关注边缘计算能力，支持对高端、高性能计算机的访问及其与主流数据处理服务的集成，使得公共、工业和科学领域的数据空间增长速度和利用范围最大化。

  

● ** 确保具有竞争性、安全性和公平性欧洲云服务**

为保护欧盟公司和公民的权益，委员会在成员国的支持下，将特别注意云服务商在欧盟市场的合规性运营，并适时考虑通过自我/共同监管机制以及提高信任度的手段来落实监管。**委员会将在2022年第二季度之前以“云规则手册”（cloud rulebook）的形式，围绕云服务的不同适用规则（包括自我监管）建立统一框架。云规则手册将提供有关安全、能效、服务质量、数据保护和数据可移植性的现有云行为准则和认证概要。**委员会将促进制定“欧洲通用标准”和“数据处理服务公共采购要求”。这将使欧盟及其成员国各级公共部门成为新的欧盟数据处理能力提升的推动者，而不仅仅是受益者。尽管许多成员国已经在国家层面上制定了类似的市场计划，但欧盟层面的云服务市场计划具有两方面的优势：可以解决当前市场的不对称性；可以提高云服务合规的清晰度。

  

● ** 支持数据技术发展**

欧洲地平线计划（Horizon Europe）将继续支持下一阶段发展数据经济的关键技术，例如隐私保护技术、工业和个人数据空间的支撑技术，还包括人工智能、数据科学、机器人技术以及欧洲开放科学云，该计划将有助于引导该领域的投资。

  

![](../Images/fbe885f3a5cad390f1ac5fe75d3ac4fb.png)

  

**C、 能力：个人授权、投资技能和中小企业**

● ** 对涉及用户数据的个人授权**

委员会支持用户个人行使其数据权利，提供相应工具和手段授权数据主体控制其个人数据，从而在更加精细级别上决定处理个人数据的方式（个人数据空间，personal data spaces）。委员会可以通过增强GDPR第20条个人数据可移植性权利执法力度来予以支持，并通过更严格的交互要求控制谁可以存取和使用机读数据（例如可穿戴设备等）。此外，需要考虑制定针对个人数据APP提供商或新型数据中介（例如个人数据空间提供商）的规则，以确保其作为经纪人的中立作用，“数字欧洲”计划也将支持“个人数据空间”的开发和推广。

  

● ** 投资个人技能和通用数据素养**

“数字欧洲”计划将扩大数字人才库，使大约25万人能够在欧盟企业中部署最新技术。到2025年，欧盟和成员国计划将目前100万数字专家的缺口减少一半，其中着重提高妇女参与度。进一步探索跨越数据密集型组织（企业和政府公共部门）的数据管理网络。

  

在通用数据素养方面，强化欧盟公民数据技能将提上议程，欧盟和成员国计划将具有基本数字技能的欧盟人口比例从目前的57％增长到2025年的65％。大数据和数据分析技能为获取、分析和使用数据以改善教育和培训体系提供了新的机会。更新版《数字教育行动计划》将优化对数据的访问和使用，使教育和培训机构适应数字时代并具备做出更好决策和提高技能的能力。

  

●  **中小企业专业能力建设**

即将出台的《欧洲中小型企业战略》将致力于提高中小型企业和初创企业发展能力。欧洲地平线计划、数字欧洲计划以及结构性的投资基金将为中小企业发展提供机会，使其能够更好地访问数据并基于数据开发新的服务和应用。

 

**D、战略领域和公共领域中公共欧洲数据空间（a common European data space）**

  

作为对横向框架的补充，以及对上述A、B、C项下的个人数据技能和赋权的资助，欧盟委员会将促进战略性经济部门和公共领域中公共欧洲数据空间的发展。

  

这将导致这些部门和领域中的大量数据可被利用，以及在数据使用和交换过程中发展数据技术并构建治理机制。数据空间治理需要通过促进数据使用和数据服务需求而进行。基于欧洲开放科学云在研究界的经验积累，委员会还将支持建立以下9种的公共欧洲数据空间：工业制造数据空间、环保交易数据空间、交通数据空间、医疗数据空间、金融数据空间、能源数据空间、农业数据空间、公共管理数据空间、技能数据空间。

 

**6**  

  

**开放而积极的国际合作**

  

  

建立公共欧洲数据空间意味着委员会将基于欧盟价值观对国际数据流动采取开放且积极的方法。

  

在促进国际数据流动方面，欧盟将继续提高其战略能力。为此，委员会将建立一个用以预测数据流的欧洲分析框架（2021年第4季度）。这将是一个持久的框架，为持续分析数据流和欧盟数据处理行业的经济发展提供分析工具、经济估值，以及数据流收集机制。它将有助于更好地了解欧盟内部以及欧盟与世界其他地区之间的数据流动和战略重点，并在必要时成为委员会采取适当政策的基础。它还将推动投资，以克服可能阻止数据流动基础架构建设的影响因素。因此，委员会将在适当时候就数据流动测量框架寻求与金融和国际组织（例如欧洲投资银行，欧洲复兴开发银行，经合组织，国际货币基金组织）的合作。

 

**7**  

  

**总结**

  

  

委员会希望将欧盟建设成为世界上最具吸引力、最安全和最具活力的数据敏捷经济体，以提高决策制定能力并改善全体公民的生活。但是，实现这一愿景的挑战很大，欧盟未来的技术发展取决于它是否有能力利用自身优势在不断发展的数据经济中抓住机会。欧洲数据处理模式将确保在尊重和分享欧洲共同价值观的基础上，开放更多数据以应对社会挑战，促进其在经济发展中的应用。为了确保数字经济发展，欧盟必须抓住数据经济浪潮中的机会之窗。
