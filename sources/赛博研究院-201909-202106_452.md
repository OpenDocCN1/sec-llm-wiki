# 【资讯】推特为深度伪造和其他欺骗性媒体内容贴上标签

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247485638&idx=2&sn=ea0ed8d9f280dda1c08aeca95e99918a&chksm=fad5b0e4cda239f2cc19c5398c5a5c0d84604308a548f5396dab61b95835d296fbeac18631d7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247485638&idx=2&sn=ea0ed8d9f280dda1c08aeca95e99918a&chksm=fad5b0e4cda239f2cc19c5398c5a5c0d84604308a548f5396dab61b95835d296fbeac18631d7&scene=27#wechat_redirect)

路透社2月5日消息，Twitter表示，**若推文包含经过合成或欺骗性编辑的媒体内容，将对其贴标签**，点击标签将显示可信的消息来源——对剪辑的真实性提出质疑的新闻报道或推文。该公司还表示，将删除任何可能造成伤害、受到操纵、具有故意误导性的媒体内容，包括可能威胁人身安全、导致广泛内乱、压制选民权利或产生隐私风险的内容。选择性编辑将被视为操纵信息，但是该内容是否被删除将取决于视频是否可能“造成伤害”。此外，欺诈性分享经编辑视频的有关账户也将被禁止。

  

社交媒体平台一直面临着深造伪造视频的威胁，并为2020年总统大选之前可能出现的错误信息冲击做准备。**YouTube在本周早些时候表示，****将删除任何经过技术操纵或篡改并可能构成“严重伤害风险”的内容**。**Facebook上个月表示，将从其网站上删除深度伪造和其他受操纵的视频，但将保留讽刺性内容，以及仅将编辑用于“省略内容或更改单词顺序”的视频。**
