# 2023年Web3.0五大发展趋势：NFT将投入更实际的用途

12月7日，The Recursive发布了“2023年Web3.0的五大趋势”（5 Web3.0 Trends That Will Go Big in 2023 According to Experts）。该报告介绍了2023年Web3.0在**零知识证明理论、游戏和VR、NFT更实际的用途、资产的保管和再生金融**五个领域的发展趋势。

**摘译 |** 林心雨/赛博研究院实习研究员

**来源 | **The Recursive

**预计到2030年，Web3.0的市场规模将达到810亿美元**，它的行业前景看起来很光明，因为世界各地的公司都正在努力推出新的产品和解决方案。

2022年Web3.0的发展面临了许多挑战，特别是与区块链和加密货币相关的项目。对于这些相关技术而言，明年可能将是至关重要的一年。

专家认为，**目前的Web3.0周期可能比以前更长，这不仅是由于内部因素，也是由于全球经济的整体状况。**而该行业中的一些大公司由于深陷关键基础设施项目而倒闭，导致目前的行业动态变得更加复杂。

**但这也可以促进市场中的优胜劣汰**——清理那些只受炒作吸引的圈钱项目，留下的将是会长期存在的、努力建造更好基础设施的企业，这有助于创造一个更好的行业环境。

因此，2023年很可能会促进Web3.0更广泛的应用，因为许多人开始意识到它会提供比传统系统更多的好处，如**增加安全性和透明度、降低成本、加快交易以及更有效的存储空间**。

  
零知识证明理论  

了解Web3.0的未来的关键是首先要了解该行业目前的趋势。

一个正在发生并有望在2023年期间产生巨大影响的趋势是零知识证明的出现。该技术**允许一方证明他们拥有某种数据而不透露任何相关信息**。这使得在使用区块链技术时，可以更好地保障隐私安全。

一家区块链开发机构的CTO表示，**了解零知识证明理论或有实践经验的人才随之也变得非常抢手**。

  
游戏和VR  
  

专家预测，**将Web3.0机制引入游戏和VR的趋势也将延续到2023年**。Web3.0中的游戏也将寻求利用区块链技术作为一个关键组成部分。

作为大规模采用的关键驱动因素之一，游戏与VR的引入将迫使Web3.0的UI/UX改进激增。此外，**较小的资本规模促使项目将代币不只是视为一种融资工具，而更像是支撑内部经济的产品的关键元素**。这将有利于更深思熟虑的产品经济的创造和现有产品经济的再平衡。

  
NFT更实际的用途  

2023年也可能会是关键的一年，**届时将看到NFT会有更多的实际用途，而不再是一个被过度炒作的对象。**

可以看见的是，人们对NFT的看法从过度炒作的必备品转变为知识产权管理的有效工具。由于与艺术相关的NFT和元宇宙领域不再有先发优势，越来越多的虚拟身份NFT项目将涌现，随之出现的是与特定网站和品牌相关的、具有针对性的3D体验。

  
资产的保管  

另一个正在出现的趋势是托管，或者说是谁将负责在区块链网络上持有个体的资产和数据？有几种不同的保管类型，但在**未来最常见的类型是分散的保管解决方案，即没有一个实体控制个体的资产**。

2023年Web3.0和区块链的新兴趋势将集中在**可采用性、可扩展性、托管和监管**方面，特别是在2022年的FTX事件之后。2023年的趋势将包括2022年整体趋势的延续，如第二层的可扩展性选项、区块链游戏、VR以及元宇宙。

此外，专家认为，人们也会对加大对加密货币的投资。正如大家所看到的，即使是世界上第二大加密货币交易所——FTX交易公司，也存在着严重的安全漏洞，其印制的代币没有抵押品，最重要的是它没有受到美国以外的监管。当人们失去了他们的储蓄，对冲基金就失去了投资，导致了许多项目的崩溃，最终使得熊市进一步深化。但是，从积极的一面来看，**人们将变得更加积极地进行投资，Web3.0团队也就不得不变得更加负责和透明**。

  
再生金融（ReFi）  

根据区块链专家的说法，ReFi将成为2023年Web3.0的又一个新兴趋势。

自我保管、区块链上的社交媒体和信息传递——Lens协议，以及绿色和可持续的再生金融将是2023年的Web3.0趋势之一。**ReFi的主要重点是建立一个系统，能够恢复和保护物质资源，并减轻碳排放的影响。**因此，它有望在**Web3.0创新和寻求实现积极环境影响的项目**中发挥重要的作用。
