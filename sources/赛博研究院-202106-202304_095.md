# 上海通管局副局长王天广带队赴赛博研究院调研数据安全工作

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247497565&idx=1&sn=bc4e52f6838f38cc0e968aa93e102998&chksm=fad64f7fcda1c6695e70957cdb84f107f40e0272acc3bf225c6cf4a037ee0a1f40113edcf109&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247497565&idx=1&sn=bc4e52f6838f38cc0e968aa93e102998&chksm=fad64f7fcda1c6695e70957cdb84f107f40e0272acc3bf225c6cf4a037ee0a1f40113edcf109&scene=27#wechat_redirect)

10月25日下午，上海市通信管理局（简称“上海通管局”）副局长王天广带队赴上海赛博网络安全产业创新研究院（简称“赛博研究院”）进行调研和指导。  

![](../Images/0b5f77876811f429109e4dec9a74946d.png)

王天广副局长听取了赛博研究院发展历程尤其在数据安全领域的研究基础和工作情况，对赛博研究院作为首批入选数据安全评估服务机构表示高度肯定和感谢。  

王天广副局长指出，数据安全是上海通管局当前和未来的重点工作，接下来将在试点基础上，进一步在全市范围推开电信领域数据安全监管工作，重点开展包括电信领域重要数据目录管理、数据安全风险评估、数据安全通报等。希望赛博研究院依托数据安全领域的研究咨询和平台技术能力，全面支撑好上海通管局数据安全监管工作，推动本市电信领域数据安全能力整体提升，更好地推动本市数字化转型，维护好国家安全和人民利益。

上海通管局互联网管理处处长施昌书、张胤、谢可珍一起参加了调研交流。

赛博研究院：入选“数据安全评估服务机构”  
上海赛博网络安全产业创新研究院（简称“赛博研究院”）是上海市经信委指导下的民办非企业单位，与中央网信办、中国信息安全测评中心、上海市委网信办、上海市经信委等部门建立稳定的政策咨询渠道。2022年6月6日，上海赛博网络安全产业创新研究成功入选上海市通信管理局第一批**电信和互联网行业数据安全评估服务机构****。**
