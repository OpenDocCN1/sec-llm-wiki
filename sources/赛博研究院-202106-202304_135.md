# 议程嘉宾抢先看！2022世界人工智能大会安全高端对话即将开幕

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247496684&idx=1&sn=fc5c3fc46e4c42da4286e3427659c7e4&chksm=fad64bcecda1c2d82b8e93f5f46cc042060974e51af53482994b33d2f9f8771665337570865b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247496684&idx=1&sn=fc5c3fc46e4c42da4286e3427659c7e4&chksm=fad64bcecda1c2d82b8e93f5f46cc042060974e51af53482994b33d2f9f8771665337570865b&scene=27#wechat_redirect)

9月3日下午，**2022世界人工智能安全高端对话将于上海世博中心正式举行。**以“**智绘宇宙，元起安全**”为主题，聚焦**元宇宙安全风险分析及其对策建议**，**涵盖人工智能安全、数据安全、隐私保护等深度议题**，旨在更好地推动元宇宙等人工智能体系发展，助力构建与城市数字化转型相适应的安全与治理格局。

**指导单位**：世界人工智能大会组委会办公室

**主办单位**：上海赛博网络安全产业创新研究院

**专业指导**：国家计算机网络应急技术处理协调中心上海分中心、上海市人工智能与社会发展研究会、联合国人工智能与机器人中心

**协办单位**：上海观安信息技术股份有限公司、上海艾策通讯科技股份有限公司、汇纳科技股份有限公司、众安信息技术服务有限公司、英国标准协会（BSI）

**支持单位**：杭州安恒信息技术股份有限公司、上海斗象信息科技有限公司、上海英斯盾信息技术有限公司
