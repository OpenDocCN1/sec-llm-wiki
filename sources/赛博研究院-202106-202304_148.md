# 加快数字经济发展先行先试！长三角示范区出台20条举措

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247496492&idx=1&sn=db1bf6f47663abb56aff8d3858e164be&chksm=fad64b0ecda1c218cf9205a2dce6dd1315df5d97a7271c02bae98e0e0ab6721738110fade571&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247496492&idx=1&sn=db1bf6f47663abb56aff8d3858e164be&chksm=fad64b0ecda1c218cf9205a2dce6dd1315df5d97a7271c02bae98e0e0ab6721738110fade571&scene=27#wechat_redirect)

近期，长三角一体化示范区执委会会同相关部门联合印发**《关于在长三角生态绿色一体化发展示范区加快数字经济发展推进先行先试的若干举措》**，从积极推进新型信息基础设施一体化建设、加快推动数字产业化等5个方面推出20条举措，共同推进示范区数字经济领域创新举措率先落地，加快推动示范区产业数字化和数字产业化，以应用场景牵引技术创新，培育数字经济新技术、新业态和新模式，打造数字化转型发展先行区。
