# 赛博研究院入选上海市通信管理局2022年数据安全评估服务机构

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247495656&idx=2&sn=81fa456be1436cfceae6e852254ab865&chksm=fad657cacda1dedc6f5012085b93159a59ae3be13e581107e946c8ace10fbfaf3ff7172edf2f&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247495656&idx=2&sn=81fa456be1436cfceae6e852254ab865&chksm=fad657cacda1dedc6f5012085b93159a59ae3be13e581107e946c8ace10fbfaf3ff7172edf2f&scene=27#wechat_redirect)

# 6月6日，上海市通信管理局公布2022年数据安全评估服务机构选拔工作评选结果，**上海赛博网络安全产业创新研究院入选第一批数据安全评估服务机构。**

# 此次遴选是上海市通信管理局为落实《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》等法律法规及工业和信息化领域数据安全管理的有关要求，推动加强企业数据安全评估工作，从而选拔一批**在数据安全评估领域实力强、社会责任感强、能够有效支撑数据安全评估工作的单位。**

# 根据《关于试点开展上海市电信和互联网行业数据安全评估服务机构遴选工作的通告》有关安排，经自主申请和材料评审等环节，上海市通信管理局遴选产生上海市电信和互联网行业第一批数据安全评估服务机构7家。赛博研究院成功入选。

# ![](../Images/eb69e2cb9cc3b205ef9df0c1e85a5243.png)

  
赛博研究院  

上海赛博网络安全产业创新研究院（简称“赛博研究院”）是上海市经信委指导下的民办非企业单位，是国内专业从事网络安全产业研究、数据合规咨询及培训的第三方独立机构。  

# 当前，赛博研究院秉持专业、诚信、创新、合作的精神，为各级党政部门和各类企事业单位提供高质量的研究咨询与综合服务，打造网络空间政、产、学、研、用、投的协同创新平台，推动我国数字经济发展和网络强国建设。此外，赛博研究院联合英斯盾数据合规与风险治理中心，进一步推动数据隐私专业治理研究与行业工具迭代，为提升各类企业数据安全合规能力、构建企业完善的隐私治理体系贡献行业力量。

  
PIS-中国数据安全合规评估  

# ![](../Images/b676f53d567d673cf1caf57f9641882a.png)

「中国数据安全合规评估」是英斯盾数据合规与风险治理中心推出的系列评估工具之一。该工具适用于中国大陆（内地）的组织/企业开展自身数据安全评估工作，也适用于第三方机构对组织/企业的数据安全保障能力进行审查和评估，全面覆盖数据安全评估实施流程和数据安全相关管理及技术措施的评估要点。

![](../Images/f9da460e4cfd3597e91d9ff4b4bab350.png)
