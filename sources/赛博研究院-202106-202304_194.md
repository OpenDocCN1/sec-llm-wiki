# 下一代互联网范式，Web3.0的争议与未来

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247495231&idx=1&sn=fcf94901832c1684ab9d3c3006e15a9f&chksm=fad6561dcda1df0b07caa04133973459a6446d0b436e00f9995e9874c9d65b52cf106717ae6a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247495231&idx=1&sn=fcf94901832c1684ab9d3c3006e15a9f&chksm=fad6561dcda1df0b07caa04133973459a6446d0b436e00f9995e9874c9d65b52cf106717ae6a&scene=27#wechat_redirect)

Web3.0意味着互联网发展的新阶段。它基于Web2.0，同时能有效解决Web2.0面临的一些困境，进一步激发互联网的价值。而区块链则是Web3.0的技术驱动力。

![](../Images/51a0ecff929269cb7078d01d828422fa.png)

**Web1.0：只读信息**  

**Web2.0：读取+书写信息**

**Web3.0：读、写&拥有信息**

未来，Web3.0有望像个人电脑和智能手机一样，极大地改变人们的上网体验。在Web3.0时代中，用户在他们所属的网络社区中将拥有经济利益和更多控制权。

从理论上讲，基于区块链的网络可以打破谁控制信息、谁赚钱，甚至网络和公司如何运作的垄断局面。倡导者认为，**Web3.0将创造新的经济、新的产品类别和新的在线服务，使民主回归网络，并定义互联网的下一个时代。**

与此同时，精力、金钱和人才正在涌入Web3.0项目，但改造Web依旧是一项艰巨的任务。尽管区块链的前景不错，但仍然**有越来越多的怀疑论者指出：Web3.0充斥着投机、盗窃和隐私问题，中心化的吸引与新中介数量的激增已经破坏了去中心化网络的乌托邦式的宣传。**

**什么是Web3.0？**  

1991年，当科学家W. Scott Stornetta和Stuart Haber推出第一个区块链——一个为数字文档添加时间戳的项目时，就埋下了Web3.0的种子。但这个想法直到2009年才真正扎根。在金融危机之后，化名Satoshi Nakamoto的发明者推出了比特币。简单地说，**Web3.0是加密货币的延伸，以新的方式将区块链用于新的目的。**

2014年，以太坊的伍德写了一篇基础博文，其中概述了他对新时代的看法。他说，Web3.0是“对我们已经使用网络进行的各种事物的重新构想，但对于各方之间的交互有一个根本不同的模式”。“**我们认为是公开的信息，我们就发布。我们假设已达成一致的信息，我们将其放在一个共识账本上。我们认为是隐私的信息，我们保守秘密，绝不泄露。**”在这个愿景中，所有通信都是加密的，身份也是匿名的。“简而言之，由于不能合理地信任任何组织，我们设计的系统就要精确执行我们先前的假设。”

从那时起，新的Web3.0用例开始出现了。

*Web3.0流媒体服务Sound.xyz承诺为艺术家提供更好的交易；*

*基于区块链的游戏，如Pokémon风格的Axie Infinity，让用户在玩游戏中赚钱；*

*所谓的“稳定币”（具有“锚定”属性的加密货币，其目标是锚定某一链下资产，并与其保持相同的价值），被认为是全球金融体系的升级；*

*此外，加密货币作为跨境支付的解决方案也获得了青睐，尤其是对于处于动荡环境中的用户而言。*

迄今，对于Web3.0的评价仍然是两极分化的。在许多不同的观点中，主要的分歧存在于那些相信Web3.0会有美好前景的人，和那些聚焦困扰着Web3.0的许多问题的批评者。

**Web3.0存在的争议**  

一项技术的早期是一个令人兴奋的时期。乐观主义者认为，可能性是无穷无尽的，人们关注的是它能做什么或将做什么。随着 Web3.0的必然性和盈利性的光环赢得了皈依者时，重要的是要考虑可能出现的问题，并认识到已经出现的问题。

**该技术不够实用且价格昂贵。**关于Web3.0或者区块链作为定义网络新纪元的技术是否有意义的问题比比皆是。IBM研究院软件工程首席科学家Grady Booch说：“无论你是否同意加密货币背后的哲学/经济学，它们都是一场正在形成的软件架构灾难。”Booch在Twitter Spaces对话中解释说，所有技术都需要权衡取舍，而“去信任”系统的代价是效率非常低，每分钟只能处理几笔交易——与亚马逊网络服务等集中式系统相比，处理的数据量很小。去中心化使技术更加复杂，对于基本用户来说，不是更简单、更容易获得，而是更加遥不可及。

区块链的低效率同时还伴随着高昂的成本。比特币和以太坊的交易成本从几美元到几百美元不等，而在**区块链分布式账本上存储一兆字节的数据可能会花费数千甚至数万美元**。如果用户购买了NFT图像，那么链上表明所有权的代码中就包含了一个地址，即图像存储位置。然而这也意味着一旦相关的服务器出现故障（停止运行），用户所高额购买的NFT也就荡然无存。

**该技术可能会侵犯个人数据权利。**尽管理论上加密钱包具有匿名性，但交易是公开的，也就是说，仍旧能够追溯到个人。与此同时，基于区块链的数据也无法被删除。这一特性也可能给 Web3.0带来合规性问题，**譬如欧盟的《通用数据保护条例》（GDPR）规定了删除个人数据的权利。**

**该技术会对环境产生较大的影响。**运行一个依靠超级计算机解决复杂方程的网络，每当个体想在区块链上保存数据时，都需要巨大的能源。它还会产生电子垃圾——根据Rosenthal的说法，随着矿工循环使用大量寿命短的计算机硬件，比特币“平均每笔‘具有经济意义的’交易会产生一整台MacBook Air的电子垃圾”。Rosenthal的研究发现，比特币每年产生的电子垃圾与荷兰这一国家产生的电子垃圾数量相当。

**Web3.0的未来**W

那么，Web3.0究竟将走向何方？以太坊联合创始人Vitalik Buteri虽然保持一定担忧，但**仍对Web3.0抱有信心——坚持认为去中心化网络正在迎头赶上，而且相当迅速**。

一方面，与使用大量能源的比特币挖矿不同，依靠用户的买入或是对股份的占有来支持交易成为流行趋势。以太坊估计，股权证明的更新将使其能源使用量减少99.95%，同时使该平台更快、更有效。以较新的区块链Solana为例，使用股权证明和“历史证明”（一个依靠时间戳的机制）时，每秒可以处理65000笔交易（相比之下，以太坊目前的速度是每秒15笔，比特币是每秒7笔），其使用的能源仅仅大约是两次谷歌搜索的能量。

一些公司正在**对区块链采用混合模型**。混合模型还可以帮助公司应对GDPR和其他法规，Cindy Compert、Maurizio Luinetti和Bertrand Portier在IBM白皮书中解释：“为了保护数据删除权，个人数据应在‘链外’数据存储中保持与区块链的私密性，只有其证据（加密哈希）暴露在链中。”这样一来，就可以根据GDPR删除个人数据，而不会影响链上的其他数据。

无论好坏，**监管正在慢慢到来，且它将定义Web3.0的未来**。欧洲正在考虑制定环境法规，以遏制或禁止工作证明区块链。在美国，拜登政府在3月发布了一项行政命令，指示联邦政府研究对加密货币的监管。

由于Web3.0的许多内容仍在讨论中，它仍然是一个高风险、高回报的领域。某些公司和行业可以去碰碰运气。不过，对于Web3.0高调宣称——它将“接管互联网，颠覆金融体系，重新分配财富，并让网络再次民主”，我们应该持保留态度。
