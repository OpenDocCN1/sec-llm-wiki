# 白宫为联邦机构发布新的网络安全战略，加快转向零信任模式

# 近日，白宫发布了一项最新网络安全战略，要求联邦政府机构收紧网络安全控制，并计划引入“零信任”概念，对组织内外任何计算机或用户都不予以固有信任。计划列出了联邦机构在未来两年内需要采取的数十项措施，以保护系统并降低安全事件的风险。网络安全和基础设施安全局（CISA）局长Jen Easterly表示，零信任是现代化和加强政府防御的关键因素，必须继续从根本上改变对联邦网络安全的态度来应对对手继续寻求创新的方式来破坏基础设施。CISA将继续为各机构提供技术支持和运营专业知识，努力实现共同的成熟度基线。目前，许多组织站出来支持此举，指出联邦政府需要更新其安全态势，并采取更多措施来锁定某些系统。

# 中央网信办：开展“清朗・2022年春节网络环境整治”专项行动

# 日前，中央网信办印发《关于开展“清朗·2022年春节网络环境整治”专项行动的通知》，决定即日起开展为期1个月的“清朗·2022年春节网络环境整治”专项行动。通知指出，专项行动的工作目标聚焦春节期间网民使用频率较高的平台环节和服务类型，聚焦解决影响上网观感、群众反映强烈的网络生态问题，坚决清理一批违法违规信息，处置一批账号和平台，整治网络不良行为乱象，遏制不良文化传播势头，大力净化网络生态，为广大网民尤其是未成年人营造健康、喜庆、祥和的春节网络环境。此次专项行动开展时间为即日起至2月下旬。

# 美政府发布“工业控制系统网络安全倡议：水部门百日行动计划”

# 2022年1月27日，拜登政府宣布将一项针对电力部门和管道的基本控制系统的自愿网络安全计划扩展到美国各地的供水行业。根据该倡议，政府正在推动参与的水务部门设施采用检测技术，以监测对工业控制系统(ICS) 的网络威胁，从而实现水处理、储存和配送等流程的自动化和安全性。该倡议还敦促水行业更快地与美国政府共享威胁情报信息。具体倡议的落实将由白宫、环境保护署 (EPA) 和网络安全与基础设施安全局 (CISA) 联合，以改善美国供水系统的网络安全。该计划将创建一个由水务行业领导者组成的工作组，启动事故监测试点计划，改善信息共享，并为需要帮助的水系统提供技术支持。

# 英国政府发布《国家网络安全战略：2022-2030年》

2022年1月25日，英国政府正式发布《国家网络安全战略》（Government Cyber Security Strategy:2022 to 2030）文件。文件对英国政府如何确保公共部门有效应对网络威胁进行了阐释，并描绘了战略愿景，即确保政府核心功能对网络攻击具有韧性，强化英国作为主权国家地位，提升影响力，打造一个民主、负责任的网络强国。新版网络安全战略共分九章，分别从背景、方法、网络安全风险管理、网络攻击防御、网络安全事件检测、网络安全事件影响控制、网络安全知识技能及文化培养、成果评估、战略执行等方面对英国网络安全战略进行了全面描述。

# 调查显示：勒索软件团伙加大力度招募内部人员来协助攻击

最近，Hitachi ID对100家大型（超过5000名员工）北美IT公司的调查显示，勒索软件行为者正在做出更大努力以招募目标公司的内部人员来协助攻击。该公司在2021年11月进行了类似的研究。跟上一次调查相比，提供金钱以协助对其雇主进行勒索软件攻击的员工数量增加了17%。其中，65%的调查对象表示，在2021年12月7日和2022年1月4日之间，其被雇佣帮助黑客建立初始访问。威胁行为者一般使用电子邮件和社交媒体来联系员工，但27%的工作是通过电话进行的。关于报酬，大多数人收到的报价低于50万美元，但有些在100万美元以上。这表明，一旦一个公司成为勒索软件攻击的候选者，剩下的就是探索潜在的方法，从而使渗透更容易并更不可能被发现。

# 上海市首份《企业数据合规指引》发布

近日上海市杨浦区检察院联合市信息服务业行业协会、市数据合规与安全产业发展专家工作组、区工商业联合会制定发布全市首份《企业数据合规指引》（以下简称《指引》）。据介绍，《指引》共有三十八条，按照合规架构与风险识别处理的逻辑划分为六章，从数据合规管理体系、数据风险识别、数据风险评估与处置、数据合规运行与保障等方面引导企业加强数据合规管理。《指引》列举了一些常见的数据风险。例如：数据处理者开展影响或者可能影响国家安全的数据处理活动，应当按照国家有关规定，申报网络安全审查等。《指引》还特别对数据刑事风险进行了提示。数据处理者在数据处理活动中可能因为存在某些行为被追究包括侵犯公民个人信息罪、破坏计算机信息系统罪、非法侵入计算机信息系统罪等刑事责任。

深圳放宽市场准入若干特别措施正式出台，聚焦数据要素交易和跨境数据业务等领域  

近期，国家发展改革委牵头，会同商务部、广东省、深圳市等研究制定《关于深圳建设中国特色社会主义先行示范区放宽市场准入若干特别措施的意见》（以下简称《特别措施》），并于1月26日正式对外公布。1月26日上午，国家发展改革委召开专题新闻发布会，国家发展改革委体改司副司长蒋毅在会上表示，《特别措施》涉及部门多、波及面广，推动落实是一项庞大的系统工程，国家发展改革委将持续完善配套保障，主要通过建立健全工作机制来确保各项措施落地见效。根据《特别措施》中关于“放宽和优化先进技术应用和产业发展领域市场准入”的介绍，重点提及放宽数据要素交易和跨境数据业务等相关领域市场准入，涵盖数据要素交易、数据资源产权、公共数据开放、数据安全等内容。

# 银保监会发布2022年2号文：加强数据安全和隐私保护

近日，中国银保监会办公厅印发《关于银行业保险业数字化转型的指导意见》（银保监办发〔2022〕2号）（以下简称《指导意见》）。《指导意见》共七个部分，三十条，包括总体要求、战略规划与组织流程建设、业务经营管理数字化、数据能力建设、科技能力建设、风险防范、组织保障和监督管理等。《指导意见》指出，加强数据安全和隐私保护。完善数据安全管理体系，建立数据分级分类管理制度，明确保护策略，落实技术和管理措施。《指导意见》还指出，强化网络安全防护。构建云环境、分布式架构下的技术安全防护体系，加强互联网资产管理，完善纵深防御体系，做好网络安全边界延展的安全控制。加强金融生态安全防护，强化与外部合作的网络安全风险监测与隔离。

# 网信系统全年下架移动应用程序1007款，积极开展数据安全等领域执法

2021年，全国网信系统进一步加大执法力度，依法查处各类违法违规案件，取得显著成效。据统计，全国网信系统全年共依法约谈网站平台5654家，警告4445家，罚款处罚401家，暂停功能或更新3008家，下架移动应用程序1007款，会同电信主管部门取消网站许可或备案、关闭违法网站17456家，移送相关案件线索4728件。依法严处网上各类违法违规行为，维护清朗网络空间；重点查处严重违法违规平台，形成有效震慑；积极开展数据安全、个人信息保护等领域执法，切实保障人民群众合法权益。随着《数据安全法》《个人信息保护法》相继实施，各级网信部门依法开展数据安全、个人信息保护等领域执法。

# 谷歌被华盛顿特区起诉“侵犯用户隐私”，另有三个州也准备起诉

1月24日，华盛顿特区总检察长卡尔・拉辛（Karl Racine）以“欺骗性位置跟踪行为”侵犯用户隐私为由起诉谷歌。拉辛的办公室在一份声明中还称，另外三个州的总检察长也计划对谷歌提起诉讼。谷歌错误地让消费者相信，改变其账户和设备设置，就可以保护自己的隐私，对谷歌可以访问的个人数据进行控制。谷歌使用各种手段不断追踪用户的位置，而该诉讼是对公然侵犯隐私权和州法律的行为应该采取的执法行动。诉讼指出，谷歌部署了“黑暗模式”（dark pattern），为了反复推动或施压人们提供越来越多的位置数据而设计一些“技巧”，能以对谷歌有利的方式、潜移默化地影响用户决策。谷歌的这种行为至少从2014年就已经开始。这违反了各州和华盛顿的消费者保护法。
