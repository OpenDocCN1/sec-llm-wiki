# 纽约电力局与亚马逊等企业合作，加强电网安全防御能力  

纽约电力局(NYPA)宣布与网络安全公司IronNet和亚马逊网络服务公司达成一项新协议，该协议还将帮助州公共组织加强其网络安全防御，使该组织可以实时检测和缓解攻击。借助IronNet和AWS提供的技术，NYPA供应链生态系统中的IT和电力基础设施可以收集和共享匿名的网络威胁信息，这样可以共同保护企业的网络。NYPA这一做法使协作应对网络攻击成为可能。该协议将允许纽约的市政公用组织及其合作伙伴创建一个动态的、类似雷达的攻击环境视图，从而对该州整个电网的威胁范围有更广泛、更深入的了解。纽约的IT和电力基础设施保卫者将收到与美国能源部门的其他集体防御参与者相关的异常网络行为的警报。在发生协调攻击的情况下，IronNet安全运营中心的顶级网络安全专家还会进行相应的指导。

# 美国：ITI向DoC发布关于保护ICT的建议  

2022年1月11日，信息技术产业委员会（ITI）宣布已向美国政府，特别是美国商务部（DoC）提出了一系列建议，以应对互联软件交易对全球ICT供应链造成的风险。ITI特别指出，DoC的拟议规则依赖于《确保信息和通信技术及服务供应链安全》规则中概述的流程，但该规则仍然过于宽泛，无法实际实施。因此，ITI提出了一系列建议，包括：确定导致国家安全问题的ICT交易类别;考虑将遵守全球公认的国际标准作为缓解措施;进一步缩小联网软件应用程序的定义，将重点放在软件应用程序处理的数据类型上;阐明互联软件应用程序规则是否适用于软件分发和使用链中的部分或全部利益相关者等。

# 新加坡就国家支持实体的网络攻击预防措施进行回复

# 2022年1月11日，就议会提出的有关国家行为者和国家支持的实体如何应对网络攻击的问题，新加坡通信和信息部（MCI）进行答复。MCI指出，新加坡网络安全局（CSA）已采取措施解决关键信息基础设施和企业中发生的事件和漏洞，例如发布技术细节，缓解解决方案和工具包，加强对异常活动的监控并鼓励组织采用"零信任"方法，例如组织不应在没有验证的情况下信任其网络上的任何活动，应确保持续监控和警惕可疑活动；MCI概述了一些良好的网络实践，包括定期更新软件和系统，以及实施事件响应和业务连续性计划。

# 美国：NIST发布关于工程可信安全系统的草案

# 2022年1月11日，美国国家标准与技术研究院（NIST）发布了工程可信安全系统重大修订草案，面向社会公开征求意见。NIST强调，该草案主要针对参与开发可信安全系统和系统组件的工程师、建筑师、设计师及相关人员。该草案侧重于：1.将系统安全工程（SSE）定位为系统工程（SE）的子学科；2.使SSE实践与处理资产损失和资产损失后果的安全实践和其他学科保持一致;3.侧重于保障系统安全能力的准确性，实现授权行为和预期结果，并且有效控制不利影响和损失；4.使系统安全工程工作符合国际标准。

# 欧盟将组织聚焦供应链网络安全性的大规模演练活动

欧盟计划于本周晚些时候启动一项聚焦供应链网络安全性的大规模演练活动，这项为期六周的演练将以“欧盟若干个成员国的供应链遭网络攻击并损害受攻击国家之社会经济”为模拟场景，对欧盟在相关领域的强韧性进行压力测试，推动欧盟各成员国就增强供应链网络安全性深化合作，并提升联合应对攻击的效能。此次大规模演练活动由从2022年1月1日起担任欧盟轮值主席国的法国所提议，预计将在下个月的欧盟成员国外长会议期间落幕。虽然欧盟已掌握用于应对和制裁网络攻击活动的若干手段，但其至今未建立一个可有效协调其成员国联合响应大规模网络攻击活动的机制框架。欧盟计划以过去曾发生过的供应链网络攻击活动为模板，围绕“地缘政治危机逐步升级”这一主题，组织此次大规模演练活动。

# 微信安卓版更新：新增个人信息收集清单功能

此前腾讯微信团队发布了微信安卓8.0.18内测版，在微信8.0.18更新中，隐私权限进一步明确，除了之前的个人信息与权限查询之外，还新增了个人信息收集清单、第三方信息共享清单的选项。其中在个人信息收集清单中，用户可以查阅微信对其个人信息的收集情况，包括用户基本信息、设备属性信息、用户使用过程信息、联系人信息等。继微信隐私指引条款更新，增加了个人信息浏览和导出机制，设置系统权限和应用授权管理入口；信息共享披露更新，披露了为优化广告效果如何与第三方共享经去标识化或匿名化后处理的信息，并增加披露了为确保部分独立功能的实现所接入的第三方 SDK 情况，再到此次V8.0.16 的内测更新中增加个人信息收集清单，数据合规和隐私保护是企业亟需探索和解决的重要问题。

# 上海市通管局关于“回头看”的通报：仍有32款App侵害用户权益

近期，上海市通信管理局针对前阶段通报的App侵害用户权益、通信网络安全防护管理等问题，对相关涉事单位及其应用系统开展了“回头看”，发现仍有订餐小秘书、蜜罐管家、力扣等32款App及其应用系统存在问题整改不彻底、侵害用户权益行为和通信网络安全管理义务未落实等情况。这32款App和应用系统应在2022年2月12日前落实整改工作。逾期不整改的，上海市通信管理局将依法依规组织开展处置工作。

# EDPS要求欧洲刑警组织删除与犯罪活动无关的个人数据

2022年1月3日，EDPS要求欧洲刑警组织删除其收集的与犯罪活动没有关联的个人数据。2019年4月，EDPS开始对欧洲刑警组织处理敏感数据的活动进行调查，并指出，在没有对数据对象进行分类的情况下存储大量数据，会对个人的基本权利构成风险，相当于大规模监控。尽管欧洲刑警组织已经采取了一些措施，但其并未完全遵守EDPS的要求。鉴于上述情况，EDPS决定使用其纠正权并对欧洲刑警组织实施6个月的保留期，使其能够过滤和提取大型数据集中的个人数据。目前，EDPS给欧洲刑警组织12个月的时间来处理在该决定发布之前已经收集的数据集，通过审查其数据库，删除与刑事调查无关的个人数据。

# 东亚银行拿到2022年首张千万级罚单，已连续两年被罚超千万

2022年1月10日，东亚银行因违反信用信息采集规定被罚。东亚银行主要违法违规事实（案由）为违反信用信息采集、提供、查询及相关管理规定。对于上述违法违规行为，中国人民银行上海分行对东亚银行处以罚款人民币1674万元，责令限期改正。事实上，这并非东亚银行近年首次领千万级罚单。值得一提的是，这是2022开年以来央行系统开出的第一张千万级别银行罚单，作出行政处罚决定的日期2022年1月6日。而违反信用信息采集、提供、查询及相关管理规定的违法违规行为，正成为监管重点，多家银行因此受罚。

# 《信息安全技术 重要数据识别指南》征求意见稿发布

2022年1月13日，《信息安全技术 重要数据识别指南》征求意见稿发布，该标准由全国信息安全标准化技术委员会（SAC/TC260）根据《全国信息安全标准化技术委员会标准制修订工作程序》要求提出并归口，委员会将标准征求意见稿面向社会公开征求意见。标准相关材料已发布在信安标委网站，如有意见或建议可于2022年3月13日24:00前反馈秘书处。该《指南》提出了重要数据的特征，明确了识别重要数据的基本流程以及对重要数据的描述格式，为重要数据安全保护工作提供支撑。
