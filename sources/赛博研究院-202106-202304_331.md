# 《上海数据条例》背景下“政企数据融通与安全合规”主题论坛圆满举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzODYyMDIzNw==&mid=2247492624&idx=2&sn=ba52739cabd80bcdbd0e197266d32f1e&chksm=fad65c32cda1d524a96517da4a98d18b68c69d7ca6fd1fa88e03463e71b2cae635c0e273b505&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUzODYyMDIzNw==&mid=2247492624&idx=2&sn=ba52739cabd80bcdbd0e197266d32f1e&chksm=fad65c32cda1d524a96517da4a98d18b68c69d7ca6fd1fa88e03463e71b2cae635c0e273b505&scene=27#wechat_redirect)

2021年12月31日上午，《上海数据条例》背景下“政企数据融通与安全合规”主题论坛于上海市浦东新区成功举办。本次论坛由**上海数字治理研究院、上海赛博网络安全产业创新研究院、上海市信息服务业行业协会主办，上海数据合规与安全产业发展专家工作组提供专业指导。**

《上海市数据条例》于2021年11月25日在上海市人民代表大会常务委员会会议表决通过，并将于2022年1月1日起正式施行。《上海市数据条例》紧扣以规范促发展、以保护促利用的立法主线，从数据的权益保障、流通利用和安全管理三大核心环节做出明确规定，**旨在促进数据依法有序自由流动，保障数据安全，加快数据要素市场培育，推动数字经济更好服务和融入新发展格局，为上海全面推进城市数字化转型提供基础性制度保障。**

![](../Images/ca39592f7b9c4add1914cb81e380a381.png)

上海市信息服务业行业协会秘书长陆雷主持会议并指出，在此背景下，本次主题论坛有两个关键词，**第一个是“发展”**。数据的融通、流通、有效使用将是上海未来发展的核心要素和核心驱动力之一；**第二个是“合规”**。如何在发展和合规中找到平衡发展之道，是召开此次主题论坛的重要意义。

![](../Images/bf6ec42aaa814cbe44d2a1d9af9d0ec6.png)

上海市大数据股份有限公司总裁、上海数字治理研究院院长刘九评致欢迎辞。刘九评指出，本次论坛是上海数字治理研究院举办的第100场论坛，在2021年最后一天举行，极具纪念意义。《上海市数据条例》的颁布，为下一步业务开展打下了良好基础。但是，很多机构、企业还是有不少困惑。一方面，在监管框架下，如何保证合规，合乎政府主管部门、数据安全以及个人隐私保护的要求。另一方面，怎样能够充分发挥公共数据的商业化价值，以及与商业化数据进行融合。**因此，此次主题论坛希望能够通过政府主管部门领导以及各行业专家的讨论，探讨如何在确保安全合规的前提下，快速推动大数据产业的发展。**

![](../Images/8c9be1ae6d0164052bbc1882e9081455.png)

上海市人大财经委立法监督处处长张震带来了**在法制框架内推动数据的开发和应用**的分享。第一，以法治手段激发数据生产要素活力，其总结了目前法律的“一个中心两个基本点”，分别是数据权益、公共数据开发应用（授权运营）、市场数据开发应用（数据交易）。第二，明确数据权益是数据开发应用的前提，指出数据权益的立法基石。第三，在公共数据共享、开放和授权运营规则部分，深度剖析了公共数据授权运营。第四，开展了数据要素市场建设与数据交易的分享。包括从主体培育、数据资产评估以及数字信任体系角度分析数据要素市场未来的重点方向；从数据交易服务体系、数据交易内容和交易定价等方面阐释了数据交易制度。张震指出，**只有加快数据法制化建设，才能将数据纳入有序、快速发展的轨道。**

![](../Images/5cb3f2c09595a7860a713fe13a60f293.png)

上海社科院互联网研究中心主任、研究员惠志斌带来了关于**公共数据授权运营的模式机制与风险治理**思考。基于公共数据市场化开发利用的现状与趋势，对国内外的整体政策做出对比思考。其次，探讨了公共数据授权运营体制机制和模式路径，并且从数据信托的角度进行分析，分享了成都公共数据授权运营和广东公共数据资产化的案例。最后，从公共数据授权运营风险识别和安全监管出发，对我国数据隐私相关法律法规和标准体系建设，公共数据授权运营全流程监管的原则以及具体的风险面、风险点进行了分享。此外，探讨了隐私计算、区块链技术的应用现状与困局。

![](../Images/c178a24d42a0665534e1c1d3cc709687.png)

安永大中华区网络安全与隐私保护咨询服务主管合伙人高轶峰在会上发布了安永与赛博研究院联合编写的**《2021年全球数据合规与隐私科技发展报告》**。报告全面梳理了国内外数据合规，尤其是数据隐私的合规体系，并通过对近百家头部企业进行问卷调研，覆盖金融、科技、媒体与通信、消费品、生命科学等行业，客观总结企业数据合规的现状与隐私科技的需求，为国内外企业数据合规实践提供创新思路，供业内参考。

![](../Images/9edae545f773e4c76749c023fec30cfb.png)

在圆桌讨论环节，以**“公共数据授权运营的价值与挑战”**为主题，惠志斌主持，上海市政府办公厅数据发展管理办公室副主任殷仍、上海市经济和信息化委员会信息化推进处干部薛威、上海市信息投资股份有限公司总工程师章玉宇、上海市新能源汽车公共数据采集与监测研究中心副主任钟鸣荟、中国太平洋保险金融科技有限公司数据服务事业群总经理陈峰共同参与讨论。

殷仍指出，《上海市数据条例》研究的是整个城市的全口径数据，公共数据设立专章且篇幅极大，凸显了公共数据在城市数据资源体系的核心地位。前几年的工作大部分基于政府内部视角，研究数据如何在政府内部高效流转、怎样服务政府业务开展、怎样支撑跨部门、跨系统的综合性改革。这两年开始，上海乃至全国都已经进入了城市数字化转型，尤其是数据要素市场构建的新趋势和新环境。在数据要素的环境下，要回答的命题是数据怎样高效流转、怎样为数据市场提供更多的供需匹配。数据要素市场中，需求方的作用会更加凸显，授权运营制度就是在这样的背景下产生的。**重点有三个问题：**第一，摸清市场需求，市场到底需要哪些公共数据；第二，抓取数据供给，触摸到公共数据的源头端；第三，做供需匹配。需要大量的人力和技术投入，把原始的公共数据变成下游主体可以直接利用的数据产品和服务。政府需要判断需求场景的合规性；对可以提供的公共数据范围做严格把关；在交付产品时，做出口把关。

薛威指出了**公共数据授权运营的三个关键词，分别是“认知”、“创造”和“流通”。**从“认知”来说，在微观层面，人们的认知有比较大的差距，尤其是政府部门和市场之间对应的关系方面。授权运营主体的引入可以对其进行有效补充，将数据开放和授权运营两种体系有效结合，互补不足，才能把公共数据的价值真正开发出来。从“创造”来说，很多数据出厂之前缺乏关注，政府部门在治理数据、提供数据的过程当中也没有获得感。但一旦激发了市场的活力，发现市场需求，就能够有效助力社会经济的发展，政府部门的积极性、社会主体参与的积极性也会大大提高，期待后续更多创造这样的价值，发现更多的需求和场景。从“流通”来说，上海的定位独特，对于数据的认知需要跳出传统思维，不仅要善于配置上海的数据，同样也要善于配置长三角数据、全国的数据乃至国际数据，期待上海下一步在数据领域，全国统一的大市场当中共同努力。

章玉宇提出了**四个关键词****。****第一是“活力”**，信投希望在新一轮数字转型和公共数据授权运营当中，投资更多的企业，发挥更大的活力，把数据作为市场要素的价值充分发挥出来。**第二是“布局”**，上海信投在整个数字化转型和公共数据授权运营当中的布局比较快，同时也布局智能平台。在公共数据授权运营当中力争成为最先的、合格的受认证的供应商，这是一个主体定位。**第三是“技术”**，在新一轮发展当中，首先就是基于泛在算力的新型网络架构，支撑数字的交易、数据的授权运营，包括未来分布式的人工智能对接算力的调度。**第四是“场景”**，不仅包括政务数据，还要包括金融等场景。

钟鸣荟表示，上海新能源汽车的地方监管平台的职责定位主要依托国家和上海市的行业主管部门的要求，对新能源汽车的数据实施采集和安全监管方面的工作。首先，**数据开放的形式**是成果出去，不接触到数据，今年可以实现云端远程开放。其次，**数据开放的内容**中，安全合规是第一位的，原始数据不做开放，相关应用场景基本都服务于公共管理方面。此外，**数据开放的对象**最支持的是全国高校、科研院所，因为其代表了未来的创新能力所在。最后，在**数据开放的过程**当中，安全方面的考虑是不断更新的。

陈峰指出，从场景来说，现在的保险基本都是大数法则来定义的，基于使用量的保险，可以在检测行为上做差异化的服务和定价，从总体来说，可以降低保险的成本。保险行业天生需要数据，来支撑业务的发展。在过往业务发展中，很早就已经有各方在做数据的交易，也会遇到定价、安全等问题。**期待政府或公共方等得到大家广泛信任的主体去做这件事情，这样减轻了交易负担，也少了合规风险。**

最后，大家一致希望，在新的一年里，公共数据授权运营能够尽快落地，数据价值的认定和确权问题能够被重点关注，**努力实现汇天下数据而通之，聚天下数据而用之，通过条例护航时代，数据驱动未来，把上海打造为“国内的数据资源集聚地和国际国内数据要素流转枢纽”。**
