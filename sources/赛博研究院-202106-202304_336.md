工信部：APP弹窗信息关不掉等问题基本清零

在12月23日中国信息通信研究院主办的2022年ICT深度观察报告会上，工业和信息化部总工程师表示，今年以来，APP“弹窗信息关不掉”等问题基本清零，互联网应用改造取得阶段性成果。具体指出，网络建设量质并进；融合赋能作用彰显；市场秩序规范有序，今年已累计检测192万台APP，企业违规行为得到有效治理，累计建成开通5G基站超过139万个，完成207家网站和APP的改造；服务民生，精准降费深化落实，提前超额完成降费任务。

《上海市建设网络安全产业创新高地行动计划（2021-2023）》发布  

# 近日，《上海市建设网络安全产业创新高地行动计划（2021-2023年）》全文发布。《行动计划》共提出4项主要目标，3大建设高地，10项建设任务，以及7项保障措施。

《行动计划》提出，强化国家战略科技力量，围绕下一代通信安全、数据安全、云计算安全、生物识别安全、漏洞智能治理等领域，开展网络安全核心技术攻关，争取承担国家重大工程项目，推进协同创新和成果转化。发挥上海市密码产业优势，开展后量子密码、同态密码、轻量级密码等理论研究，引导密码算法、密码协议、专用芯片、通信模块等关键技术突破和产品研制。支持5G、工业互联网等新型基础设施供应链和核心技术设备制造的自主可控发展等。

# 地方国资监管部门：首部针对数据合规专项领域的操作指南

广州市国资委12月20日印发了《广州市国资委监管企业数据安全合规管理指南（试行2021年版）》（《指南》）。作为全国首个数据安全合规指南的地方标准，《指南》的出台是广州市对今年9月实施的《数据安全法》和11月实施的《个人信息保护法》等上位法在国有企业合规领域的“专项”实操指导性文件。

《指南》要求明确数据采集渠道、格式和流程；划分数据传输的网络系统安全域，明确域内、域间等不同数据传输场景的操作规程；梳理数据出境业务，建立内部出境合规审查流程和规范；提升数据储存介质的安全加密管理，评估第三方平台数据储存和下载行为的安全性；不同类别、级别数据使用制定脱敏处理原则并进行风险评估；建立数据共享的申请及授权审批的流程及权限设置。

中央网信办部署打击流量造假、黑公关、网络水军乱象

中央网信办全国网信系统视频会议于12月22日召开，部署开展“清朗·打击流量造假、黑公关、网络水军”专项行动。会议指出，当前，流量造假、黑公关、网络水军问题相互勾连、互为策应，损害网民合法权益，扰乱网络舆论环境，破坏公平竞争的市场秩序，人民群众深恶痛绝、反映强烈。对此，中央网信办决定在全国范围内开展为期2个月的专项行动。

# 雅安农商行因“未经同意查询个人信息等”遭处责

## 中国人民银行雅安市中心支行11月25日公布的一则行政处罚信息显示，雅安农村商业银行因存在违反征信安全管理要求、未经同意查询个人信息等违法行为，被警告，并被罚款188.1万元。据罚单显示，对征信相关责任人郑淦处以罚款0.4万元；对反洗钱相关责任人王小丽处以罚款3.5万元；对反洗钱相关责任人周博处以罚款1万元。

## 工信部就数据安全风险信息报送与共享工作指引草案公开征求意见  

工信部于12月22日公开征求对《工业和信息化领域数据安全风险信息报送与共享工作指引（试行）（征求意见稿）》的意见，拟以规范性文件形式印发，现面向社会公开征求意见。根据征求意见稿，工信部（网安局）鼓励部系统各单位、安全企业、数据处理者、科研院所、行业组织等单位开展风险信息报送，遴选支撑服务能力强、技术水平高、报送信息质量优的单位建立风险直报单位名录，并实施名录动态管理。

# 英国执法机构与Have I Been Pwned共享5.85亿泄露密码

在FBI之后，英国执法机构国家犯罪调查局与Have I Been Pwned共享它在调查中发现的5.85亿泄露密码。Have I Been Pwned维护者Troy Hunt表示，其中2.25亿个密码是唯一的，即此前未泄露过。国家犯罪调查局是在英国一家云存储设施的一个账户内发现泄露的密码以及对应的电邮账号，它无法判断泄露的密码和电邮来自哪个平台或哪家公司。目前Have I Been Pwned包含55亿个条目，其中8.47亿是唯一的，所有密码都可以免费下载，可以下载到本地后对照是否密码泄露，无需通过该网站。

# 美国：HHS发布有关HIPAA隐私规则和EPRO法律的指南

# 美国卫生与公众服务部（HHS）于今年12月20日发布指南，用以解决1996年健康保险可携性和责任法案（HIPAA）隐私规则中与极端风险保护令（ERPO）法律相关的涵盖医疗保健提供者的要求。HHS指出ERPO是一项法院命令，要求受保护的医疗保健提供者可以在未经个人授权的情况下披露有关个人的受保护健康信息（PHI）,以此来支持针对该个人的ERPO申请。HIPAA隐私规则中的“最低必要”标准要求所涵盖的实体和商业伙伴做出合理的努力，将大多数使用、披露和请求限制在所需的最低PHI范围内，实现预期目的。上述标准通常适用于与ERPO法律相关的PHI的使用和披露。

# 便利蜂“偷拍”北京10万条视频，侵犯大量个体隐私

日前，据《南方周末》报道，连锁经营便利店“便利蜂”自2017年起，在长达5年的时间里，采集公共区域数十万条拍摄数据。每一个便利蜂的目标店铺附近都会遭到一轮录像，店里覆盖全方位无死角摄像头，通过人工和AI自动识别店内的画面。顾客们的一举一动也会被收集起来，成为系统的决策依据。事实上，互联网时代的企业，大多会涉及开发和使用大数据信息采集、算法系统等，这就容易在公民个人信息的过度收集方面产生一些问题。
