# 创新引领CTF竞赛发展新趋势——第七届XCTF国际联赛总决赛创新赛制回顾！

![](../Images/63fb7f94f1db35ebaa9f2f8a1d100cc8.png)

2023年3月30日，第七届XCTF国际网络攻防联赛总决赛于江苏南京正式落幕。本届大赛由XCTF国际网络攻防联赛组委会发起，国家创新与发展战略研究会主办，赛宁网安承办并提供技术支撑，r3kapig战队命题。

  

第七届XCTF国际联赛总决赛在大赛赛制与竞技模式上大胆创新，在冠亚季军争夺环节采用了创新性的**KOH（King of Hill）巅峰对决赛制**，并在面向其他队伍的**Dota x CTF**环节采取了结合Dota2电竞游戏场景的**AI智能攻防赛制**，引发参赛选手及广大网络安全爱好者的热烈反响，为国际CTF竞赛发展注入了新的活力，也给国内外网络安全竞赛的举办提供了新的思路与参考。

***01***

**继往开来**

**第七届XCTF国际联赛总决赛赛制创新**

**01**

**KOH巅峰对决：**

**1VS1淘汰制在国际性CTF赛事的首次正式应用**

大赛第二日，由首日解题赛晋级的四支队伍参与KOH巅峰对决赛争夺冠亚季军。**KOH巅峰对决赛制突破了传统AD攻防赛的多队伍混战模式，****首次在国际性CTF竞赛正式赛程中使用1VS1淘汰制**，规避了多队伍混战中参赛队伍难以定位到主要对手并进行针对性攻防操作，而对于全场其他较弱队伍的持续“收割”能力往往决定排名等影响冠亚季军名次争夺的偶发性因素，并实时展现对决双方影响比赛局势的关键操作，在保障赛事公平性的同时具有更高的观赏性和选手对决感。

  

![](../Images/dae093b60365f7841994898c93afadc4.png)

KOH巅峰对决赛态势展示  

  

在**赛题设计**上，对决队伍必须由SpeedRace（极限竞速）独立环境赛题进入KOH共享环境赛题争夺控制权的流程设定，**模拟出了对决双方对网络空间中核心阵地的激烈争夺过程，并在两至三个小时的紧张赛程中考验对决双方的技术能力与团队协作**；每回合更新Patch的Flag得分翻倍的**积分规则设计**则**对应着****核心阵地争夺战的终极目标为最终对“Hill”阵地的占领而非攻防过程优势的现实场景**，大大增加了竞赛的激烈程度。

  

**02**

**Dota x CTF：Dota2游戏场景下的AI智能攻防**

Dota x CTF环节采用AI智能攻防赛制，选手们提交自己开发的AI智能脚本在Dota2电竞游戏中进行分组混战，在每回合的游戏中通过AI智能控制英雄进行多人对战（“收割人头”），最终存活者即胜出。

与传统的AD攻防赛制主要考验选手在仿真网络靶场中的攻防技术能力不同，该赛制**侧重检验选手们在电竞游戏场景中AI智能攻防的战术思维、设计与编程开发能力**。本届大赛引入这一环节，也是继2017年第三届XCTF国际联赛总决赛在国内首次尝试AI人机协同攻防之后，再次涉足AI攻防领域。**期望能够在游戏化场景中引导选手们关注思考AI的协同与对抗，以及更进一步人机共舞时代的和谐相处问题。**

***02***

**大赛设计初衷：**

**回归纯粹的技术竞技**

XCTF国际联赛发起人、大赛裁判长诸葛建伟博士表示，本届XCTF国际联赛总决赛赛制设计的初衷是想**尝试改变CTF赛制发展过程中不符合竞技赛事特点的一些“传统”或“另类”的因素**，比如从1996年DEF CON CTF中沿用至今的AD攻防赛制，虽在国内经历了各种“旧瓶装新酒”式创新以及计分规则、攻击防御实施方式等方面的细微调整，但其本质仍是全场战队之间混战模式的互攻互守；又比如在有限的赛事时间内“堆积木”式的赛制混搭，很多情况下其出发点就已经超出了公平竞技的原则。

  

诸葛建伟博士认为，集体竞技类的赛事活动，包括体育球类赛事、脑力棋类竞赛、电竞游戏等各种领域长期以来的实践经验证明，**只有将1VS1对决与淘汰赛制相结合才是最具公平性、最具观赏性的竞赛形式。**CTF竞赛在其最初出现时未采用此类赛制，完全是因为当时比赛组织者可投入的平台支持、人力组织不足以满足需求。**在XCTF国际联赛已经步入第七届，为联赛提供靶场平台支持的赛宁网安已成立十年的时间节点，尝试过渡到集体竞技类最具优势且最易理解的赛制模式，可以说是势在必行的理性“回归”。**

  

同时，对于像Dota x CTF这类的“娱乐”赛，诸葛建伟博士表示，组委会秉承着**Hacking for Fun**的设计理念，希望能通过该类环节设计**鼓励参赛选手找回CTF竞赛的乐趣和带着娱乐精神探索新兴领域的动力**。同时，Dota x CTF也将会进一步朝着在电竞游戏场景中升华AI智能攻防这一方向发展与完善，相信选手们也可以随着XCTF国际联赛的共同努力，发掘出自身在AI人机共舞时代的技术价值。**大赛组委会也希望这样的共同愿景与行动能带动国内CTF圈子拒绝不良风气侵袭，回归CTFer通过竞技磨练技能健康成长的初心。**

***03***

**赛宁网安：**

**十年如一日的技术坚守**

**作为XCTF国际网络攻防联赛总体承办方，赛宁网安始终在为XCTF国际联赛的赛制革新提供强有力的技术支撑。**

  

从2014年XCTF国际联赛的前身BCTF 2014开始引入AD攻防对抗赛制；2017年第三届总决赛在国内首次引入AI人机协同攻防赛制；2018年第四届总决赛采用Jeopardy解题与AD攻防赛制并行的JAD混合赛制；2021年第六届总决赛引入CoolDown竞技模式；再到本届总决赛首创KOH巅峰对决赛制，并采用结合Dota2电竞游戏场景的AI智能攻防赛制。**赛宁网安依托安全研究团队在信息安全领域的技术积累，以专业的竞赛平台和丰富的赛事经验，持续支撑着XCTF国际联赛先进赛事理念的落地，不断满足大赛网络安全人才发掘与培养的需求，为XCTF国际联赛的成功举办保驾护航。**

  

保障国家网络空间安全，筑牢人才根基是关键。加强网络安全攻防实战人才的培养已成为行业共识，赛宁网安十年来一直积极投身于网络安全竞赛支撑，助力培养高水平实战型网络安全人才，为保障数字经济腾飞积蓄人才力量。
