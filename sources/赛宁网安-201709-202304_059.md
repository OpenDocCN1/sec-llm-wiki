# 聚焦创新丨赛宁网安亮相2022未来网络发展大会成果展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Mjk5NjU3MA==&mid=2455477018&idx=1&sn=4ecba9e2a0a070bb8e4cc1168f59d599&chksm=8852072fbf258e39238b9a47ab5736090441a1133fcbd19e101b14c78453a0afac37853892eb&scene=126&sessionid=1681373531#rd](http://mp.weixin.qq.com/s?__biz=MzA4Mjk5NjU3MA==&mid=2455477018&idx=1&sn=4ecba9e2a0a070bb8e4cc1168f59d599&chksm=8852072fbf258e39238b9a47ab5736090441a1133fcbd19e101b14c78453a0afac37853892eb&scene=126&sessionid=1681373531#rd)

8月24日至8月25日，第六届未来网络发展大会在南京上秦淮国际文化交流中心举办，大会以“网络全球 决胜未来”为主题，旨在打造具有全球影响力的未来网络技术与产业顶级交流平台，构建未来网络产业集群高地。赛宁网安携两项创新产品亮相同期举办的“2022未来网络创新技术与成果展”。

  

  

本次成果展涵盖近年来在网络通信与安全领域的重大原创成果、国家重大项目、行业领先科技、深度应用融合等类型，技术范围涉及确定性网络、算力网络、B5G/6G、内生安全、云网融合、开放网络、工业互联网等多方面前沿技术。

  

![](../Images/40855c23b056a24a9250ebd0b5728650.png)

  

赛宁网安展出**主动防御系统**与**工控安全解决方案**两项创新成果：

  

**主动防御系统**

  

新型网络攻击方式层出不穷，传统Web应用防护产品已经无法有效抵御新兴攻击行为。赛宁网安在此基础上推出了赛宁主动防御系统，提出“以攻制攻，主动防御”的新一代防御理念和以数据驱动为核心的防护技术，为各行业用户提供一站式Web综合防护能力。  

  

**3大特色优势**

**一站式防护**

全面守护Web应用安全，对工具攻击、数据爬取、零日漏洞、API滥用等新兴和高级攻击手段进行有效阻拦。  

  

**多维度溯源**

对攻击者和攻击流量进行多维度的挖掘分析，支持攻击者画像生成和攻击场景复现还原。  

  

**轻量化管理**

部署运维方便，无需修改任何应用服务器代码或业务逻辑，无需部署客户端。  

  

**工控安全解决方案**

  

赛宁网安深耕工控安全领域，通过模拟攻击行为和防御措施，展现攻击效果、验证防护措施的有效性。工控产品广泛服务于石油石化、电力能源、智能制造等行业客户，为用户提供全场景仿真环境攻防演练，帮助工业企业提升综合防护能力。  

  

**6大创新亮点**

  

**虚实结合网络攻防全仿真技术**  

**专业工控软硬件活体漏洞工具库**  

**工控行业全层级、全业务流程仿真技术**

  

**融合IT\\OT工控实战对抗攻防演练**

  

**提升工业领域网络安全人员技术能力**

  

**提供主动防御系统实现综合防护能力**

  

  

作为专注数字化靶场的攻防专家，赛宁网安将持续推动技术与产品创新，不断扩大生态合作，与各行业同仁共同推进未来网络建设，助推产业升级发展。
