# 斩获“强网杯”一等奖！赛宁网安SN-天虞战队扬帆起航再出发

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Mjk5NjU3MA==&mid=2455476887&idx=1&sn=7b947a7d191aa88d9f34e85cea84ee08&chksm=885206a2bf258fb4f9011c82a1157975a3feca43ab8256d5b7f84b40b90594400b8a0d807d33&scene=126&sessionid=1681373531#rd](http://mp.weixin.qq.com/s?__biz=MzA4Mjk5NjU3MA==&mid=2455476887&idx=1&sn=7b947a7d191aa88d9f34e85cea84ee08&chksm=885206a2bf258fb4f9011c82a1157975a3feca43ab8256d5b7f84b40b90594400b8a0d807d33&scene=126&sessionid=1681373531#rd)

![](../Images/b1da961b641e2dca8c534e1e94211ebb.png)  

近日，为期两天的第六届“强网杯”全国网络安全挑战赛线下赛圆满落幕。由赛宁网安技术专家组成的“SN-天虞”战队高歌猛进，在线上赛2358支战队、10147名选手中脱颖而出，与来自企业、高校以及民间的31支战队齐聚“强网杯”展开激烈比拼。最终，SN-天虞战队以攻防对抗赛（KOH）与实战解题（Realworld）双领先的优势斩获一等奖！

  

![](../Images/7bc6d16ead6296a2892c7c746fc61c36.png)

  

**人员技能**多维度比拼****

  

“强网杯”致力于为网络安全从业人员、技术爱好者、院校学生、青少年等各类群体打造技术实践与展示自我的平台，从国家最顶尖的安全力量到冉冉兴起的未来网安之星，全面助力人才培养和技术创新，为网络强国建设和数字中国建设提供有力支撑。  

  

本次大赛创新采取攻防对抗（KOH）+实战解题（Realworld）混合赛制，赛题场景涵盖二进制程序漏洞挖掘利用、Web应用漏洞挖掘利用、设备固件漏洞挖掘利用、物联网设备现场破解等方向，并涉及物联网设备现场破解、人工智能安全应用等新技术场景，多维度、全方位考验选手的攻防实战能力。

  

![](../Images/86378c78a1dbaa6e1111c995ba8ca2b2.png)

  

在题目复杂、高手如云的高强度竞争下斩获一等奖，离不开SN-天虞战队的高水平发挥以及坚持不懈的拼搏精神。  

  

SN-天虞战队队员全部来自赛宁网安旗下专业技术团队天虞实验室。实验室汇集北京、南京、成都三地30余位专业安全研究员，囊括渗透测试、安全开发、IOT安全、工控安全等网络安全研究领域的精英人才。今年，天虞实验室不断在国际舞台展露头角：在日前刚刚落幕的DEFCON CTF 2022中，与国际知名CTF战队r3kapig联合冲击总决赛；研究成果入选世界顶级信息安全峰会Blackhat议题。

  

**赛宁助力网络安全人才培养**

  

赛宁网安自2013年创办以来，长期致力于网络安全攻防人才培养。

  

在专业赛事运营方面，赛宁在2014年创办的XCTF国际网络攻防联赛已成功举办至第七届，吸引世界范围内的网络安全人才广泛参与。截至目前，参赛国家地区超过140个，参与人次超过17万，已打造成为亚洲第一，世界第二的全球知名网络安全联赛品牌。  

  

**赛宁由联赛运营出发，以攻防对抗为核心，秉承“以赛促学”“以赛促练”的人才培养理念，目前已研发并成功落地应用多项配套产品及服务：**

**实训靶场平台**

集训、练、赛、评一体化设计的网络安全实战训练靶场。基于高度仿真的虚拟网络，模拟物理世界组网，提供网络安全攻防知识培训及实操解题练习，支持在线夺旗考试，并形成完整的人才能力评价体系。此外，赛宁还提供一套全面的培训课程知识体系，覆盖全行业上百个安全方向，可以针对不同的客户提供高度定制化的培训内容。

  

**竞赛靶场平台**

包含CTF夺旗赛、运维赛、攻防赛、理论赛、渗透赛等多样比赛模式。满足各行业用户信息安全人才培养、网络安全大赛平台搭建以及实战对抗演练的需求。平台支持快速部署，操作便捷，多种防作弊机制保证竞赛公平公正。

  

**网络安全竞赛服务**

支持国内外主流竞赛模式，包含理论赛、CTF解题赛、AD攻防赛、渗透赛、运维赛及各类型创新赛事，可根据用户实际需求进行定制化交付。构建以线下赛定制化交付，线上赛SaaS化标准交付为基础的竞赛服务矩阵，为用户提供多维度，全方位的竞赛服务，满足用户标准化、专业化、定制化、个性化竞赛服务需要。

  

目前，赛宁网安产品及服务已经在政府、公安、金融、能源、教育、电信运营商等各行业领域深入应用，获得用户广泛认可与好评。未来，赛宁将持续以网络安全人才培养为己任，面向更多行业领域需求，为用户提供更加优质的产品及服务。
