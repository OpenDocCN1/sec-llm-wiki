# 客户认可丨赛宁网安荣获国贸集团2022网络安全演练活动“优秀保障奖”

近日，浙江省国际贸易集团有限公司（以下简称“国贸集团”）开展了为期5天的网络安全演练活动，由赛宁网安使用红方管控平台产品提供演练平台支撑。

  

本次演练活动中，7家单位共21名选手组成攻击组，以国贸集团各单位网站和系统为目标，进行网络安全检测和实战渗透攻击，重在发现国贸集团各单位存在的网络安全风险与隐患。

  

作为本次演练的支撑单位，赛宁网安凭借多年网络安全攻防演练服务经验，在技术保障方面提供有利支撑，护航演练任务圆满完成，获得国贸集团的充分认可，荣获“优秀保障奖”。

  

![](../Images/14fcae5fddc167ecd108dfe25bc96935.png)

  

演练中，攻击组通过使用标准化渗透测试手段，发现弱口令、数据库漏洞、Web系统漏洞等网络安全高危风险漏洞，并形成攻防演练评估报告，有针对性提出安全防范措施，达到以演练促整改、以演练堵漏洞、以演练防风险的预期目的。  

  

![](../Images/f843944522f2387126fcb9332fc47f20.png)  
  
![](../Images/1f5b34e92bbdd932cede8da4d8303a13.png)![](../Images/fab6c019ddc79737b4d504234734a53d.png)  

  

网络威胁态势愈加复杂严峻，重点行业单位警钟长鸣，金融、能源、电信运营商等关基单位陆续开展旨在“以练筑防”“以练备战”的攻防演练活动。

  

赛宁网安长期深耕网络安全领域，持续专注数字化靶场建设，积累了丰富的行业经验和成功案例。基于靶场环境研发的**自动化渗透平台、红方管控平台、主动防御系统等产品**成功服务于各项攻防演练活动。

  

  

**自动化渗透平台**

平台拥有丰富、持续更新的攻击模块资源库，确保真实漏洞可以得到全面验证，支持用户导入自定义攻击模块，根据业务内容调整渗透强度，避免影响重要业务系统的正常运行，为攻防演练前的企业网络测试评估提供专业、可定制的“体检工具”。  

  

**红方管控平台**

作为攻击的唯一入口，通过大屏展示，对红方不定时攻击进行全面管控、记录、溯源；支持7\*24小时在线运行的私有云部署、也支持SaaS化快速响应的云端部署，不受时间和空间的制约，保障演练“常态化”。  

  

**主动防御系统**

针对0day、DDOS、爬虫等常见网络攻击手段，为防守方提供一站式WEB综合防护能力。基于主动防御、动态对抗、AI识别三大驱动引擎，把守网站安全与数据安全关卡，助力防守方将各类攻击“拒之门外”。  

  

截至目前，赛宁网安已成功支撑北京、辽宁、江苏、上海、广东等各省市以及金融、能源、电信运营商等各行业领域举办的攻防演练活动，提供包括红队、蓝队、裁判等在内的各项演练服务。
