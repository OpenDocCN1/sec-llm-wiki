# 赛宁网安-r3kapig联合战队冲击DEF CON CTF 2022总决赛

1993年，DEF CON黑客大会正式创办，第一届DEF CON CTF则始于1996年，是全球同类赛事中最具影响力的赛事之一，在圈内有着“黑客世界杯”的美誉。  

✦

✦

DEF CON CTF 2022决赛即将于北京时间8月13日凌晨01:00正式打响！国际著名战队r3kapig再次杀入DEF CON CTF总决赛。  

  

赛宁网安旗下技术研究团队天虞实验室将作为本赛赛事的合作方，联手r3kapig共同出征“黑客世界杯”，与来自全球的15支顶尖CTF战队同台竞技。  

  

![](../Images/9f599bb051534b4ed47004f11db01f26.png)

  

DEF CON 2022黑客大会将于8月11-8月14日举办，其中的CTF比赛环节自2018年起，由主办单位Order-of-the-Overflow负责出题，今年则改由新团队Nautilus Institute负责出题。

  

![](../Images/927cf11d24dee2a385934749981067a7.png)

**r3kapig战队：**成立于2018年，由老牌CTF战队Flappypig和强劲新锐战队Eur3ke联合组成，曾斩获各类CTF赛事奖项数十项，包括TCTF冠军、XCTF冠军、BCTF冠军、WCTF季军等各类顶级赛事冠亚季军十余项，连续五年闯入Defcon总决赛。  

  

**天虞实验室：**赛宁网安旗下专业技术团队，重点攻关公司业务相关信息安全前沿技术，汇集来自北京、南京、成都三地30余位专业安全研究员，专注于渗透测试、安全开发、IOT安全、工控安全等方面。今年6月，团队研究成果《WASM真的安全吗？》入选“黑客奥斯卡”BlackHat USA 议题。

  

如今，不断涌现的中国CTF新势力正在共同谱写下一篇精彩华章，而此次赛宁网安天虞实验室与r3kapig联合亮相DEFCON CTF 2022也将继续向世界展现新生代中国网络安全力量，让我们一起祝愿“赛宁网安-r3kapig“能够取得理想成绩！
