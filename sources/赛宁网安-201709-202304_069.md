# 客户认可丨持之以恒守护关基安全 赛宁网安收到浙能集团感谢信

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Mjk5NjU3MA==&mid=2455475410&idx=1&sn=740107e1044b251ef98f7eacc2bb6d63&chksm=885208e7bf2581f143c4cfd6d82dc68a36349e3d3cae9a58041bd3ec2c5b628eb066f698968e&scene=126&sessionid=1681373536#rd](http://mp.weixin.qq.com/s?__biz=MzA4Mjk5NjU3MA==&mid=2455475410&idx=1&sn=740107e1044b251ef98f7eacc2bb6d63&chksm=885208e7bf2581f143c4cfd6d82dc68a36349e3d3cae9a58041bd3ec2c5b628eb066f698968e&scene=126&sessionid=1681373536#rd)

近日，浙江省能源集团有限公司（以下简称“浙能集团”）向赛宁网安发来感谢信，对公司在7月举办的浙江省省部属企事业网络与信息安全管理员职业技能竞赛中的支撑工作予以肯定。

  

![](../Images/87b23531f4cc4119bd1662915be8fa15.png)

  

![](../Images/4201e68490d1e897cf161bfcc75ac942.png)

  

  

此次竞赛由浙江省省部属企事业工会主办，浙江省能源集团有限公司承办，旨在以保障信息系统安全稳定运行为原则，从政策法规标准和网络安全风险评估、安全防护、安全应急、响应技术等方面，全方位考核从业职工的网络安全综合能力。  

  

![](../Images/62d4dbd0229b0847f0711eed4c70a7a5.png)

比赛现场激烈比拼  

![](../Images/c4b98c8c37993491b12eced8657bc687.png)

竞赛靶场大屏展示

  

赛宁网安作为本次竞赛的技术支持方，根据能源行业网络安全人才培养需求，协助浙能集团搭建基于夺旗赛和运维赛的竞赛靶场平台。  

  //  

  

![](../Images/69b57ee5f7cc774bfb01652dd2de6e0a.png)

  

作为业内首创的网络安全竞赛模式，运维赛模拟工作人员实际防御情况，内置攻击事件监测、突发事件响应、场景隐患修复、虚拟服务器漏洞挖掘等安全运维操作等多样题目类型，能够有效锻炼运维人员应急处置能力。

  

未来，赛宁网安将与浙能集团加强沟通交流，为客户提供更加贴合真实需求的定制化产品及服务。  

  

目前，赛宁竞赛靶场平台已成功服务于XCTF联赛、强网杯挑战赛、强网拟态防御国际精英挑战赛、电力行业网络安全攻防邀请赛、全国电信和互联网行业网络安全管理职业技能竞赛、各项省级网络安全大赛等国内知名赛事。  

  

赛宁网安将持续追踪网络安全事件动态，加强行业需求洞察力，以实践经验反哺技术与产品，加快竞赛靶场平台迭代升级，为用户提供紧跟时代脉搏的创新产品。
