# 攻防演练丨赛宁红方管控平台走进广东三地 助力数字政府网络安全建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Mjk5NjU3MA==&mid=2455475055&idx=1&sn=120a22c418229799941070edd4996873&chksm=88520f5abf25864c28881a35e7ed3c7367ead6bfa6add6c0ce769dab1f4826f8b50f20bca635&scene=126&sessionid=1681373541#rd](http://mp.weixin.qq.com/s?__biz=MzA4Mjk5NjU3MA==&mid=2455475055&idx=1&sn=120a22c418229799941070edd4996873&chksm=88520f5abf25864c28881a35e7ed3c7367ead6bfa6add6c0ce769dab1f4826f8b50f20bca635&scene=126&sessionid=1681373541#rd)

![](../Images/b1da961b641e2dca8c534e1e94211ebb.png)  

  

在一阵阵清脆的键盘敲击声中，红方管控平台一双“慧眼”监控着每一次攻击、捕捉着每一处网络漏洞，为攻防演练安全性、公正性提供保障，同时帮助参演单位全面知晓自身网络隐患。

  

  

7月，赛宁网安红方管控平台走进广东，陆续支撑肇庆、佛山、阳江三地市政府举办的攻防演练比赛，为数字政府网络安全建设提供有力技术支撑。  

  

佛山

**连续两年开展“飞鸿杯”网络安全大赛**

佛山市“飞鸿杯”网络安全大赛采用实战攻防演练形式，共吸引粤港澳大湾区28支队伍参赛。全域覆盖佛山市网络IP，其中包括全市200家重点攻击单位。演练期间，攻击队累计提交有效攻击成果报告399份，对221个单位实施了攻击。

  

![](../Images/77116ed9136a42c4eef786380b67fef4.png)![](../Images/e95d015844c431218cb4c8c3652114ea.png)

  

佛山市互联网协会主办的佛山市网络安全事件应急演练暨“飞鸿杯”网络安全大赛已连续举办两年，今年也是赛宁网安红方管控平台第二次为大赛提供技术保障。  

  

  //  

![](../Images/ab12ac8441e7a4e69356ddbfe3a10df7.png)

  

凭借过硬的产品实力以及领先的服务水平，在今年的大赛闭幕式上，赛宁网安正式成为佛山市互联网协会战略合作伙伴。

  

肇庆 阳江

**数字政府建设呼唤网络安全保障**

  

肇庆、阳江陆续举办以“攻防实战见真招，筑牢安全保发展”为主题的数字政府网络安全攻防演练。

  

![](../Images/b0304c6256ed40a8b7d2e38c6f7ebae6.png)![](../Images/aeeb567c3e9f3aa96d4c73d35ba97aab.png)

  

肇庆共组织国内6支攻击团队，对全市各级政务信息系统进行实战化攻击。攻击队累计发起网络安全攻击12万余次，累计提交攻击成果报告72份，其中有效攻击成果报告55份。

  

阳江共组成7支攻击队伍，设立70个重点靶标，对全市政务信息系统进行渗透测试。

  

数字政府建设推动政务信息化、云化加速，涉及的敏感信息和数据暴露面增加，提升网络安全管理能力成为各地政府日常工作的“必选项”。

  

近年，各地政府积极举办“以攻促防”的演练活动，赛宁的红方管控平台已成功支撑北京、辽宁、江苏、上海、广东等各省市举办的攻防演练活动，产品和服务获得客户广泛认可。

  

红方管控平台是具备网络安全管理能力的可视化产品，未来将走进更多城市，为数字政府网络安全建设贡献力量。
