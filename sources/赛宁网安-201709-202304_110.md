# 荣誉上榜丨赛宁网安再次入选数说安全《中国网络安全市场全景图》

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Mjk5NjU3MA==&mid=2455469331&idx=2&sn=1dfe754f5cc84f6c256791b45d162c25&chksm=8852e126bf25683047081db49f85e77488deb65f5f5ce7ddc86888830a65e5287ca3ea2686ed&scene=126&sessionid=1681373557#rd](http://mp.weixin.qq.com/s?__biz=MzA4Mjk5NjU3MA==&mid=2455469331&idx=2&sn=1dfe754f5cc84f6c256791b45d162c25&chksm=8852e126bf25683047081db49f85e77488deb65f5f5ce7ddc86888830a65e5287ca3ea2686ed&scene=126&sessionid=1681373557#rd)

4月27日，数说安全发布《2022年中国网络安全市场全景图（第五版）》（以下简称《全景图》），赛宁网安成功入选“十大安全服务”类别下的“工控靶场”和“攻防实训/靶场”两大细分市场目录。

  

![](../Images/3df03a963b52d603090e015dd512138e.png)

  

![](../Images/c568e828fdc99abc90d8ef40d79d77a5.png)

  

数说安全通过对产品、解决方案、应用场景、安全服务4个维度做进一步细分和梳理，最终统计得出，2022年我国网络安全产品与服务市场共分为12个一级分类、79个二级分类，并以此为基础，绘制了《全景图》，最终实际收录热点品牌共计1146项，甄选出380家国内优秀的网络安全企业。

  

![](../Images/5e992b120904a405f7156282423a4e64.png)

  

《全景图》中半数以上分类、品牌收录均以国家权威机构与行业主管部门颁发的产品和服务资质作为主要考量标准，参考国家质量监督检验检疫总局、国家标准化管理委员会发布的18项国家标准和公安部发布的27项行业标准。

  

**赛宁产品**

**工控网络靶场**

工控网络靶场是赛宁网安在2021年推出的新型工控安全仿真及应用平台产品。该产品是为工控安全体系化建设打造的**“关键基础设施”**。

  

![](../Images/9f03bf6070862c182ea50e245e5c6e3a.png)图为攻防赛画面

  

在超逼真的工控仿真环境中，通过体系化教学培训、多模式比武竞赛、高烈度攻防演练、全方位测试验证等多种典型业务应用，能够迅速强化个人能力水平、大幅提升团队整体能力、锤炼锻造实战策略运用、深入挖掘系统潜在风险，响应各行各业对于工控安全仿真的多种应用需求。

  

**适用行业：**火力发电、水力发电、石油石化、智能制造、风电、煤炭、市政、轨道交通等。
