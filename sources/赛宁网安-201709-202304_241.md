# 赛宁网安支持XCTF高校网络安全专题挑战赛线上赛圆满结束！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Mjk5NjU3MA==&mid=2455458367&idx=1&sn=feff2ff2ecc4f839161a65c55ab761f9&chksm=8852ce0abf25471c9fe31b335c9d9d60e16af44879f06e0f4795cc029f803209ae9cacca0527&scene=126&sessionid=1681373617#rd](http://mp.weixin.qq.com/s?__biz=MzA4Mjk5NjU3MA==&mid=2455458367&idx=1&sn=feff2ff2ecc4f839161a65c55ab761f9&chksm=8852ce0abf25471c9fe31b335c9d9d60e16af44879f06e0f4795cc029f803209ae9cacca0527&scene=126&sessionid=1681373617#rd)

![](../Images/cc4c5455866f38118e1a55fee41e76a8.png)

  
近日，由XCTF国际联赛主办，**赛宁网安承办**，华为终端安全、华为云安全、华为鲲鹏计算安全赞助的**XCTF高校网络安全专题挑战赛**线上初赛圆满结束。大赛围绕**“华为云”、“鲲鹏计算”业务、**华为“HarmonyOS和HMS”****为赛事主题，将校园知识和业内实践经验进行打磨融合，为高校网络安全人才提供展示自我、磨砺技能、技术交流的平台。  
大赛共吸引来自全国各大高校的**652支**战队、**2420位**网络安全精英选手报名参赛。其中不乏有来自清华大学、复旦大学、上海交通大学等国内顶尖网安高校的学子，还吸引了来自**长沙市雅礼中学**的高中生参与竞技。大赛设有三场线上专场选拔赛，一场线下总决赛。通过不同赛道的设计及综合性的赛题设计，全面考量参赛选手的综合水平。  
本次竞赛由赛宁网安**竞赛靶场平台**提供技术支持，赛宁网安天虞实验室团队及运维技术团队为大赛提供保障，单站分场赛冠军战队可直接获得“XCTF高校网络安全专题挑战赛”决赛入场券及XCTF finals 2020入场券。

**01**

**华为云专场**

  
![](../Images/0d9f193e013b29ff78dd9351568cf9a9.png)华为云专场，赛题围绕“华为云”为赛事主题，由赛宁网安天虞实验室联手华为云安全技术专家共同打造，赛题方向涉及云环境渗透、Qemu、Docker、区块链、云核心组件安全、云安全机制绕过、共享文件云数据存储安全等华为云安全的真实场景，同时在赛题设计上采用CTF模式，创造了真实云环境下的解题赛。

  

来自**杭州电子科技大学的Vidar-Team**成功解出12道赛题获取华为云专场赛事排名第一，来自北京邮电大学的天枢Dubhe以190分之差惜败，排名第二、来自东南大学的SUS战队以2道赛题一血的成绩排名第三、联合高校Nu1L战队及来自华中科技大学的L3H\_Sec战队分别排名第四、第五。  
  

**02**

**鲲鹏计算专场**

![](../Images/148afd879c9a8cf14b8b7f9cc400eb2f.png)鲲鹏计算专场赛题围绕“鲲鹏计算”为赛事主题，赛题方向涉及芯片meltdown等类型漏洞挖掘与利用、并行计算框架、芯片侧信道攻击、高性能计算算法研究与安全缺陷、高性能计算语言漏洞等。  
来自**上海交通大学0ops战队**得分10060居于第一，浙江大学AAA战队得分8062排名第二，华中科技大学L3H\_Sec战队得分7667排名第三，清华大学Redbud战队得分6853排名第四，北京邮电大学天枢Dubhe战队得分6607排名第五。  

**03**

******HarmonyOS和HMS专场******

![](../Images/095ce75b0f38e70fad9bc7024ed2c53b.png)  
HarmonyOS和HMS专场赛题围绕“HarmonyOS和HMS”为赛事主题，赛题方向涉及操作系统应用破解和漏洞挖掘，IOT逆向和漏洞挖掘、操作系统内核漏洞挖掘与利用等。

  

**复旦白泽战队**一路过关斩将，在本场赛事中排名第一！Nu1L战队成功解出14道赛题，得分8203排名第二；新世纪宅男战士战队解出14道赛题以微小的差距紧随其后，获得排名第三；哪有什么战队\_从来都是一个人以一己之力解出13道赛题，得分7317排名第四；Sloth战队解出13道赛题，得分6993排名第五。  
![](../Images/b347147e49d2f8319f3713fe6580f1ca.png)![](../Images/c44fb98326f29b56f1672ff33d045f27.png)三场线上赛结束积分总榜经过三场专题挑战赛的激烈选拔，最终将会有20支战队晋级线下决赛，线下总决赛将提供**35万元**专项奖励基金全面支持优秀高校人才的提升与培养，赛事优胜者除了获得**华为盖章认证**的荣誉证书，还会获得华为校招面试绿卡及**实习offer**。  
线下总决赛也将继续由赛宁网安团队提供技术服务支持，具体时间及赛程安排请关注“XCTF联赛”公众号官方通知。
