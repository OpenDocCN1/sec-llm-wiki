# 强强联合 | 赛宁网安携手山石网科 加速推进网安人才培养

9月22日，**山石网科通信技术有限公司**（以下简称“**山石网科**”）和南京赛宁信息技术有限公司（以下简称“赛宁网安”）**战略合作签约仪式**在苏州山石网科大厦顺利举行。山石网科高级副总裁、首席技术专家、安全技术研究院院长**杨庆华先生**与赛宁网安常务副总**高庆官先生**代表双方正式签订战略合作协议。未来，双方将强强联手，加快网络安全技术人员培养的脚步，推进网络安全专业技术人员培养解决方案体系的建设。  
![](../Images/5e458656101502cf6ab8e685d7d3fa57.png)图注：山石网科杨庆华与赛宁网安高庆官签订战略合作协议

  

山石网科中国区TAC客户服务资深总监宋军、市场资深总监荣钰、认证培训资深经理张自良、赛宁网安合作总监刘佳良、技术方案总监包华宇出席了此次活动。

 

当前，网络空间已经成为继陆、海、空、天之外的“第五大主权领域空间”，国际上围绕网络安全的斗争日趋激烈，维护网络空间安全成为维护国家安全新的战略制高点。网络空间的竞争，归根到底是人才竞争。据统计数据显示，2020年，网络空间安全人才数量缺口预计将超140万，大力培养网络安全专业技术储备人才势在必行。一直以来，赛宁网安都以**为国家发现和培养安全人才**为使命，秉承“人才是网络安全第一资源”理念，基于国家网络空间安全战略发展需求，以“**从人才培养到实战应用的最佳实践**”为业务脉络，致力于打造以人才为核心、以业务演训为支撑、以实战应用为目标的全场景网络安全体系。

  

多年来，山石网科利用自身在网络安全领域的前瞻性技术优势，通过对上万个真实客户案例经验萃取提炼，不断地致力于为网络安全人培养贡献自己的力量，为国家网络安全人才培养体系的建设添砖加瓦。山石网科高级副总裁、首席技术专家、安全技术研究院院长杨庆华表示，**网络安全的本质是攻防对抗，攻防对抗的本质是人，网络安全就是人与人之间的对抗**，实践是检验真理的唯一标准。此次与赛宁网安合作，进一步拓展了山石网科整体解决方案，尤其在网络安全实训领域，为客户网络安全人才培养提供了闭环支持。山石网科和赛宁网安将充分发挥自身在各自领域的作用，共同完成网络人才的培养。

  

赛宁网安常务副总高庆官表示，实训靶场的合作只是一个起点，赛宁网安希望进一步探索，在网络靶场中构建超逼真的业务环境方面深度融合，结合双方的优势，**打造出市场认可的一流产品**。赛宁网安对于此次合作给予高度重视，将在人力及资源配置上予以最大的支持。

没有网络安全，就没有国家安全。此次赛宁网安与山石网科的强强联合具有重大意义，标志着双方将持续推进紧密合作，发挥各自的优势，共同助力网络安全专业技术人员的培养，加速搭建网络空间安全保障体系，双方也将以此合作为契机，全方位开展更广泛的合作，取得长期共同发展。  

  

**关于山石网科**  

  
山石网科是中国网络安全行业的技术创新领导厂商，自成立以来一直专注于网络安全领域前沿技术的创新，提供包括边界安全、云安全、数据安全、内网安全在内的网络安全产品及服务，致力于为用户提供全方位、更智能、零打扰的网络安全解决方案。

  

山石网科为金融、政府、运营商、互联网、教育、医疗卫生等行业累计超过18,000家用户提供高效、稳定的安全防护。山石网科在苏州、北京和美国硅谷均设有研发中心，业务已经覆盖了中国、美洲、欧洲、东南亚、中东等50多个国家和地区。  
  

  

**关于赛宁网安**  
  

赛宁网安，以守护网络空间安全为己任，聚焦网络空间攻防实战，定位专业网络靶场提供商，致力于为国家发现和培养网络安全人才，是集产品研发、安全联赛运营为一体的高科技网络安全企业。赛宁网安业务体系围绕攻防对抗核心技术，以“从人才培养到实战应用的最佳实践”为业务脉络，致力于打造以人才为核心、以业务演训为支撑、以实战应用为目标的全场景网络安全体系。
