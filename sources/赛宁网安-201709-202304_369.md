# 明天见 | 第三届“强网杯”全国网络安全挑战赛

**6月15-16日，第三届“强网杯”全国网络安全挑战赛将在郑州高新区开幕，除了大赛，第二届强网论坛、网络空间安全先进技术展为主体的“一赛、一会、一展”多维立体活动将同期举办，还将首次组织“强网”系列科普宣教活动。跟随小编一起，提前了解系列活动，感受网络强国的磅礴力量。**

  

**Part1**

  

**“一赛”**

**第三届“强网杯”全国网络安全挑战赛**

  

     第三届“强网杯”全国网络安全挑战赛由中央网信办网络安全协调局作为指导单位，由河南省互联网信息办公室、郑州市人民政府、信息工程大学主办，教育部高等学校网络空间安全专业教学指导委员会协办，**赛宁网安网络靶场平台**提供技术支持。

  

     从线上初赛脱颖而出的24支优胜队伍明天将亮相线下赛场，其中不乏腾讯“eee”战队、北京大学“mini\_r3kapig”战队、长亭科技“0X300”战队、复旦大学“白泽”战队、上海交通大学“0ops”战队等知名战队，他们齐聚中原，共同争取强网宝鼎。

**Part2**

  

**“一会”**

**“强网论坛”**

  

     以“新时代、新空间、新路径”为主题的第二届强网论坛将于15-16日在郑州高新区光华大酒店举办，论坛分为全体会议、主论坛和分论坛三个阶段，分论坛设置“强网论道”“强网论剑”两大版块，邀请国内网络安全和信息化领域17位院士，近千名业内专家、学者、企业和政府人员等业内人士齐聚一堂，共同研究探讨网络安全和信息化领域前沿问题、难点问题和痛点问题。其中，“强网论道”侧重网络安全战略研究，“强网论剑”侧重网络安全技术创新，设14个分论坛组织研讨。

**Part3**

  

**“一展”**

**网络空间安全先进技术展**

  

     网络空间安全先进技术展览，聚焦网络空间安全高新技术发展，分内生安全、系统安全、网络安全、网络密码、数据安全、态势感知等6大版块、共30余家企业集中展示最新高新成果。**赛宁网安**也作为安全企业受邀参展，将在郑州光华大酒店体育中心一号馆T1区展出**CP-CR网络靶场平台**系列产品，网络靶场平台也将全程为本次“强网杯”全国网络安全挑战赛提供技术支持。
