# XCTF&华为联合实训基地签约仪式举行

11月30日下午，华为终端安全奖励计划大会在北京举行，安全行业大咖嘉宾齐聚现场，会上，华为PSIRT(华为安全应急响应中心)对2018年华为安全奖励计划进行了总结及展望，并为奖励计划的优秀个人获得者颁奖。

  

![](../Images/b8f414463deca787f28a9617434181b7.png)

  

大会邀请了安全行业的同仁共同分享各家漏洞奖励计划的经验及相关精彩议题分享，XCTF与华为联合实训基地的签约仪式也在大会上举行，XCTF联赛创始人、清华大学网研院副研究员、蓝莲花领队诸葛建伟博士,华为终端软件部总裁王成录作为代表出席签约仪式。

  

![](../Images/4da5926174ebc5123a213dc38f31a773.png)

  

![](../Images/58b28602e9c9483aff032eb2381e2316.png)

  

近年来，华为一直关注安全生态，注重网安人才的培养，这与XCTF联赛发现及培养网安人才的理念不谋而合，双方连续合作了首届“极客出发”XMan冬令营及第三届XMan夏令营，华为还为第四届及第五届XCTF联赛提供了极大的支持，华为高度认可CTF赛事在选拔与培养网络安全人才上的重要作用，同时也期望更进一步地建立与安全社区的联系，吸引志同道合的网络安全人才。

  

![](../Images/35d8bca291b16981a55abb68ca08bd9d.png)

  

![](../Images/5a38c9b3e4ff222db2b718d16150088a.png)

  

XCTF-华为联合实训基地建成后，双方将继续在优秀网络安全人才孵化、科研项目合作及CTF赛事方面深化合作，XCTF联赛将发挥人才培养优势，华为也将为国内优秀的网安人才提供更多的实践和实习机会，双方共同推动国内高校学科建设，共建网安生态环境。
