# 【护网2018】赛宁网安为宁夏60大庆攻防演练提供保障

8月4日上午9点，由宁夏自治区网络安全等级保护工作领导小组办公室牵头，自治区公安厅、国家安全厅、人力资源和社会保障厅、通信管理局、国家保密局、密码管理局、中国人民银行银川中心支行、国网宁夏电力公司等8家单位联合举办的宁夏“护网2018”——第二届“新潮杯”网络安全攻防演习大赛预选赛正式拉开序幕，赛宁网安攻防竞赛平台为本次大赛提供保障。

![](../Images/2d8114154409ac45fd71a9c943204f8a.png)

来自金融、税务、人社、司法、公安、电力、基础电信运营单位、银行、高校、能源（神华宁煤）、信息技术企业及网民个人等26家单位的近100名参赛选手，凭借扎实的知识储备和较高的技术能力进入预决赛，展开了激烈较量和角逐。

大赛发挥以赛带练，以赛促学，以赛为用的办赛宗旨。前期由赛宁网安攻防实验室输出讲师，通过网络安全攻防基础培训和提升培训，以竞赛为抓手，全面提升全区网络安全从业人员的技术水平，通过有针对性的培养，为自治区网络安全保障发现和选拔优秀人才。

支持本次赛事的是**赛宁网安**“CP-AD网络安全攻防实战竞赛平台”****，这一次的竞赛平台支持，虽然任务量巨大，但是赛宁网安只用了两台标准2U设备就全程支持了比赛的顺利进行。赛宁网安攻防竞赛平台集“练、测、赛”一体化设计，提供理论赛、CTF竞赛、A&D竞赛、工具库、漏洞库，是国内各行业信息安全人才考核和选拔的首选产品。大赛决赛将于8月6号进行，敬请关注！

**关于赛宁网安**

  

赛宁网安成立于2013年，2015年成立全资子公司北京赛宁网安科技有限公司。基于国家网络空间安全战略发展需求，聚焦网络安全攻防实训，是集安全产品、安全服务、安全培训、人才培养为一体的高科技网络安全企业。
