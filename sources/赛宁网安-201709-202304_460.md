# 完美落幕！赛宁网安助力江苏省大学生网络空间安全精英邀请赛

![](../Images/b1d3e9845d03191b729088a81ef3d676.png)2018年3月31号，由东南大学网络空间安全学院指导，东南大学网络安全联盟主办，赛宁网安提供赞助支持的江苏省大学生网络空间安全精英邀请赛在东南大学九龙湖校区完美落幕。本次比赛邀请了江苏省各高校的新一届队员来到东南大学一起竞技切磋，也意在为东南大学网络安全联盟CTF战队招新，面向全校招募新一届的队员，借此机会选拔出真正对网安感兴趣的优秀后备人才。

  

![](../Images/675279dda376594b124c187a93952b52.png)

比赛现场

  

本次比赛一共有22支队伍，8支来自东南大学的战队，14支江苏省其他高校的战队，并分别排行。经过8小时的厮杀拼搏，最终，江江江战队以10682.39分名列总排行榜第一位！BXS战队以10072.18分位列总排行榜第二名，Tooyoung以分9840.6位列总排行榜第三，来自东南大学的4g0n.young H位列校内第一。

  

![](../Images/0a4faaaeba9e2750cc84e7a7c6543301.png)

总排行榜

  

**江江江战队独揽本次总排行第一**

  

江江江战队解出15道题，得分10682.39，以领先将近1000分的优势将冠军宝座收入囊中，本次比赛他们从起初的遥遥落后，到最后的背水一战，一次次打破记录，攻破无数难关，引来现场呼声不断，最终，超越 Tooyoung战队夺得冠军宝座。

下午五点，江苏省大学生网络空间安全精英邀请赛完美落幕，在东南大学举行颁奖典礼，校内组及校外组获奖战队上台领奖。获奖战队表示，感谢赛宁网安对本次大赛的支持，并将在接下来的学习中再接再厉。

  

![](../Images/b862713aa2c5b24c5eaa40928cfeadeb.png)

 领奖现场

  
**赛宁网安竞赛平台完美支持赛事**

  

支持本次竞赛的产品是赛宁网安“CP-AD网络安全攻防实战竞赛平台”，在持续几个小时的比赛中，赛宁平台以流畅酷炫的展示迎来现场参赛战队及老师的一众好评。该平台集“练、测、赛”一体化设计，提供理论赛、CTF竞赛、A&D竞赛、工具库、漏洞库，是国内各行业信息安全人才考核和选拔的首选产品，支持了三届XCTF联赛各站攻防对抗比赛近百场、白帽联盟会员高校校赛、江苏省网络空间安全攻防对抗赛、河南省网络空间安全技能挑战赛、中国移动全国网络安全运维技能赛、赛博地球杯工业互联网安全大赛等赛事。

  

![](../Images/8c8a2a28b08b4eb8def2870e16ea0669.png)

赛宁攻防竞赛平台展示赛况

  

江苏省大学生网络空间安全精英邀请赛的顺利举办，吸引了众多省内关注网络安全攻防的高校人才参与赛事，参加比赛的小伙伴也表示对CTF这种检验技能水平的方式很感兴趣，并坦言正是因为赛宁网安提供的平台和机会，让他们更加坚定自己对网络安全这一方面的信心。

  

**关于赛宁网安**

  

赛宁网安于2013年底在南京成立，2015年成立北京全资子公司，并于2016年获得千万级的Pre-A轮融资，进入业务发展快车道。基于国家网络空间安全战略发展需求，聚焦网络安全攻防实训，是集安全产品、安全服务、安全培训、人才培养为一体的高科技网络安全企业。

  

近年赛宁网安取得国家高新技术企业、双软、科技民营企业、国军标、CNCERT应急响应服务支撑单位、国家漏洞库技术支撑单位等多项资质和荣誉，入围全国网络安全领域最具发展潜力的20家初创企业、ISC网络安全创客汇全国十强企业、中国区域方案商百强企业。
