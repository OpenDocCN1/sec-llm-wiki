# 赛宁网安牵手南京未来科技城，共建网络安全人才及创新基地

为贯彻党的十九大精神和习近平新时代中国特色社会主义思想，加快推进省委“两聚一高”新实践，全面落实南京市集聚名企名家，加快新型研发机构和科技成果转化落地，构建一流创新生态体系，推动具有全球影响力的创新名城建设。3月13日，赛宁网安与南京未来科技城签署网络安全人才及创新基地战略合作协议，签约仪式在北京日坛宾馆举行。

  

![](../Images/877758050485fa4389a1066f35e35b32.png)

赛宁网安CEO谢峥（左）与黄垠中副主任（右）

      
近年来，南京正全力打造创新名城建设，南京未来科技城作为全市创新驱动发展的引领区和示范区，正着力集聚名企名家，加快新型研发机构和科技成果转化落地，全力构建一流创新生态体系。目前，未来科技城引入科技创新型项目1103个，其中未来网络类企业545家；智能制造类企业326家；科技服务类企业232家。引进500万以上总部型、成熟型项目436个，其中1000万以上250个，1亿元以上项目19个；引进院士4名，万人千人计划专家10名，省市各类创新创业人才59名，集聚海归人才和硕士以上学历人才2500余人，创业人口2.8万余人。园区已基本形成优质项目集聚、高层人才荟萃的创新创业格局。

南京赛宁创建于2013年，2015年成立北京全资子公司。赛宁网安南京总部也正是坐落于南京未来科技城未来网络小镇，基于国家网络空间安全战略发展需求，赛宁网安聚焦网络安全攻防实战，集产品、安全服务、人才培养为一体。主营业务是网络安全培训、网络安全服务，以及相应的一系列产品如实训平台、攻防竞赛平台、网络安全攻防实验室、网络靶场等。

  

![](../Images/360b4728036dbd0deec1e2872bddcd51.png)

  

近年来，赛宁网安依托自身网络安全技术能力，运用人才培养软硬件体系，加强网络安全人才建设和培养，坚持创新，不断变革，为行业提供高水准的产品及服务，不断探索网络安全人才培养的方式方法，通过推动政府、企业、院校等全方位合作，为国家发现和培养互联网安全领域未来领军人才。

  

发展至今，赛宁网安不仅成为国内网络安全实训领域的领头军，还承办了国内影响力最大的XCTF国际网络攻防联赛、运维国内最大的CTF交流平台XCTF社区，经过三届赛事的发展，目前已成为亚洲第一的网络攻防赛事品牌，吸引近100个国家地区的3万多队次、近6万人才参加联赛。

  

![](../Images/a8cc4ef9a84e6c235153a276cf0f7dec.png)

  

此次，网络人才及创新基地的战略落地将为南京以及江苏省提供产业发展所需的网络安全人才，在产业高速发展的同时，提供有利的人才保障。网络安全人才培训基地将是战略合作后首批落地项目，双方将通过产业聚集、资本推动、技术引导、体系建设等核心优势推动网络安全人才及创新基地的快速落地。

  
**关于赛宁网安**

  

南京赛宁信息技术有限公司成立于2013年，2015年成立全资子公司北京赛宁网安科技有限公司。基于国家网络空间安全战略发展需求，聚焦网络安全攻防实训，是集安全产品、安全服务、安全培训、人才培养为一体的高科技网络安全企业。
