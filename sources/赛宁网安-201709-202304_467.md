# 赛宁网安CP-AD竞赛平台支撑江苏警官学院团队选拔考核赛

3月3日，江苏警官学院网络空间安全团队（CST）学生团队选拔考核暨校队选拔赛在现教楼206室成功举行。此次比赛持续6个小时，由网安系和网安系学生大队主办，赛宁网安承办，赛宁网安CP-AD网络安全攻防实战竞赛平台提供技术支撑。

  

![](../Images/69e04da3e655b19e3eec78b67f3f9d1e.png)  
![](../Images/b297ce1801ac56ecb0571ce0a6766964.png)

  

‍本次比赛的赛制采用类似国际比赛CTF的夺旗制度，题目分数采用动态积分的方式，根据解出赛题的选手数量，动态调整选手在该题的得分。赛题分为基础项目和专业项目两个部分。  
**（一）基础项目**主要考察编程能力、代码阅读能力和网络取证。**（二）专业项目**1、WEB安全：主要考察常见WEB漏洞利用与PHP代码审计能力。其中常见漏洞包括注入类漏洞、文件上传与文件包含漏洞和会话管理漏洞。2、二进制安全：主要考察程序逆向分析能力和溢出类漏洞挖掘利用能力。‍

  

![](../Images/d82836419cd6875b9273e62230086024.png)  
  
比赛刚开始不到半分钟，就由陈档同学率先拿下签到题一血。随后其他参赛成员也纷纷拿到“一血二血三血”。上午的比赛转瞬即逝，最终由胡春涛和蒋宇翔同学占据首位。下午WEB安全与二进制安全进行分别竞赛。经过三个半小时的激烈角逐，WEB安全方向陈档同学夺得第一名，最终得分3791分；二进制安全方向蒋宇翔同学获得第一名，最终得分6216分。17网安一刘华锋在本次比赛中表现优异，取得WEB方向第二名的好成绩。

  

![](../Images/ebc2bfec73cf8d7a765a64daa9ad94ce.png)

  
网安系主任**王群**希望同学们能向优秀学长学习，在电子数据取证、网络攻防和大数据分析等方面不断培养学习兴趣，提升专业技术和实战能力。学生大队负责人**许林茂**希望能将CST学生团队管理与警务化管理密切结合，实行特殊、规范的管理制度，加强学生团队思想引领。  
![](../Images/588132ac8b58fba20d819c0d203543dd.png)

  

  

  

![](../Images/a694ccfc8cd4082444e14cc1901710b9.png)  

  

赛宁网安定位于“网络攻防实训专家”，聚焦于网络安全攻防实战，集产品、安全服务、人才培养为一体。支持本次竞赛的产品是赛宁网安“CP-AD网络安全攻防实战竞赛平台”，该平台集“练、测、赛”一体化设计，提供理论赛、CTF竞赛、A&D竞赛、工具库、漏洞库，是国内各行业信息安全人才考核和选拔的首选产品，支持了三届XCTF联赛各站攻防对抗比赛近百场、白帽联盟会员高校校赛、江苏省网络空间安全攻防对抗赛、河南省网络空间安全技能挑战赛、中国移动全国网络安全运维技能赛、赛博地球杯工业互联网安全大赛等赛事。

  

  
**关于赛宁网安**

  

南京赛宁信息技术有限公司成立于2013年，2015年成立全资子公司北京赛宁网安科技有限公司。基于国家网络空间安全战略发展需求，聚焦网络安全攻防实训，是集安全产品、安全服务、安全培训、人才培养为一体的高科技网络安全企业。
