# 辽宁·“工业互联网安全实验室”合作签约仪式成功举行

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwMzg5MjAwOQ==&mid=2247485052&idx=1&sn=9467111bb4151baf776f549259b2c09e&chksm=9b35703aac42f92c17e8922e386b6537da0c99717360c221e3ee92eb4d430c6927d7810331b7&scene=126&sessionid=1681575460#rd](http://mp.weixin.qq.com/s?__biz=MzAwMzg5MjAwOQ==&mid=2247485052&idx=1&sn=9467111bb4151baf776f549259b2c09e&chksm=9b35703aac42f92c17e8922e386b6537da0c99717360c221e3ee92eb4d430c6927d7810331b7&scene=126&sessionid=1681575460#rd)

**为加快构建辽宁工业互联网安全保障体系，提升工业互联网安全保障能力，促进工业互联网高质量发展，更好的支撑和推进我省“网络空间安全实验室”工作开展，2020年11月11日，网络空间安全实验室与360公司、东北大学“谛听”实验室签订战略合作协议，在工业互联网网络安全监控预警、应急保障、检测评估和人才培养等方向进行深度合作，共同开展“工业互联网安全实验室”建设。**

![](../Images/41d3a86a2722861c5e009fb6c98b5ec4.png)

**签约仪式上，签约单位代表就全省工业网络安全保障和实验室工作推进相关议题进行了座谈；省委网信办、省工信厅领导出席并讲话，对实验室的工作给予充分肯定，并对下一步工作提出了宝贵意见。**

![](../Images/1e8d73f5fda6a9fd5658599135ec06f4.png)

**“工业互联网安全实验室”的签约组建，是习近平总书记提出“全天候全方位感知网络安全态势”要求的具体落实，是技术机构、企业、高校间强强联合共同支撑产业发展的直接体现，是构建我省工业互联网和工业控制系统网络安全保障体系的重要举措。**

![](../Images/15ba1cf60492c9abda91bb812d22d442.png)

**下一步，实验室将充分利用自身技术优势，在全省的网络安全保障体系建设中不断发挥效能，为政府做好支撑，为企业做好服务，为推进产业发展做好保障。**
