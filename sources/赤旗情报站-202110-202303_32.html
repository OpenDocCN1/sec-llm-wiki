一键清理磁盘

docker system df #docker查看占用的空间
 
TYPE 列出了使用磁盘的 4 种类型：
  • Images：所有镜像占用的空间，包括拉取下来的镜像，和本地构建的。
  • Containers：运行的容器占用的空间，表示每个容器的读写层的空间。
  • Local Volumes：容器挂载本地数据卷的空间。
  • Build Cache：镜像构建过程中产生的缓存空间（只有在使用 BuildKit 时才有，Docker 18.09 以后可用）。
  • 最后的 RECLAIMABLE 是可回收大小。

    每次创建一个容器时，都会有一些文件和目录被创建，例如：
  • /var/lib/docker/containers/ID目录，如果容器使用了默认的日志模式，所有日志都会以JSON形式保存到此目录下。
  • /var/lib/docker/overlay2 目录下含有容器的读写层，如果容器使用自己的文件系统保存了数据，那么就会写到此目录下。
容器、镜像、数据卷都提供了prune这个子命令，来回收空间。可以一键清理没用的空间：
docker system prune

修改图标&title

准备工作，有三个图标替换的位置，分别为：

  • 登录页面logo

    • 准备透明背景的登录图片，格式为png，命名为logo.png

  • 首页logo

    • 准备透明背景首页logo图片，格式为png，命名为logo_text.png

  • 浏览器tab标签

    • 准备透明背景tab标签图片，格式为png，命名为favicon.png 

方法如下：

  • 登录页面logo:

    • 将logo图片上传至/root/docker目录下，执行以下命令：

cd /dockerdocker ps #查看opencti/platform:5.2.1的容器IDdocker cp /root/docker/logo.png 容器ID:/opt/opencti/public/static/mediadocker exec -it 容器ID /bin/sh #进入opencti/platform:5.2.1容器cd /opt/opencti/public/static/mediamv logo-VMWMLGQG.png logo-VMWMLGQG.png.bak #原图备份mv logo.png logo-VMWMLGQG.pngexit

  • 首页logo:

    • 将logo_text图片上传至/root/docker目录下，执行以下命令：

docker cp /root/docker/logo_text.png 容器ID:/opt/opencti/public/static/

  • 浏览器tab标签

    • 将favicon.png图片上传至/root/docker目录下，执行以下命令：

docker cp /root/docker/favicon.png 容器ID:/opt/opencti/public/static/
