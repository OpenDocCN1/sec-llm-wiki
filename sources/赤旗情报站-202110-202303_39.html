Atomic Red Team简介

Atomic Red Team最开始是Red Canary的一个项目，安全团队可以用其中的内容进行测试。Atomic Red Team各测试用例之间没有强依赖关系，并且以Yaml、markdown等格式提供。


https://github.com/redcanaryco/atomic-red-team


目标：通过测试保证安全设备检测有效性及ATT&CK覆盖率


目前的Atomic Red Team已经发展为以Atomic Red Team为核心的一系列项目


主要的项目有三个：


  • Invoke-Atomic是一个通过powershell批量执行Atomic Red Team测试用例的项目

  • AtomicTestHarnesses是一个基于powershell用于模拟单技术多变体的项目

  • Chain Reactor则是用于在Linux测试检测响应覆盖率的项目


本文的Atomic Red Team均指最初的Atomic Red Team，此外还会涉及到Invoke-Atomic项目。


在Atomic Red Team的每个技术目录中包含以下内容：


  • YAML 测试文件

  • 一个人类可读的 Markdown 测试文件

  • 源文件依赖项的src目录（可能）

  • 二进制依赖项的bin目录（可能）


以下是T1003.001（OS Credential Dumping: LSASS Memory）的markdown文件及yaml文件




Markdown文件确保人类可读，YAML作为一款现代数据序列化的语言也方便了计算机可读，从而让Invoke-Atomic等自动化项目成为可能。


作为ATT&CK相关项目，Atomic Red Team也对ATT&CK其他项目进行了集成，比如Attack Navigator


把json 文件导入Attack Navigator右键点击view atomic就可以查看对应的技术在Atomic Red Team中的测试case，这点主要是因为Atomic Red Team不能覆盖到所有的ATT&CK测试用例。



https://github.com/redcanaryco/atomic-red-team/tree/master/atomics/Indexes/Attack-Navigator-Layers


Invoke-Atomic简介


上面提到了Atomic Red Team有比较完备的ATT&CK测试用例，但是真要测试不太可能一个个复制粘贴执行，毕竟现在流行的是自动化测试，最好是以结构化的形式重复执行。


Invoke-atomicredteam就是一个 PowerShell 模块，用于执行Atomic Red Team 项目的atomics 文件夹中定义的测试用例。


https://github.com/redcanaryco/invoke-atomicredteam


注意事项


● 非生产环境测试

● 测试过程，机器可能会新增账号服务等持久化

● 对Invoke-atomicredteam项目添加排除项，防止项目落地被杀无法执行


Invoke-Atomic安装


Invoke-Atomic要求的powershell最低支持版本为5.0，所以低版本Windows最好升级一下powershell版本，另外网络环境需要保证，因为有些时候会从GitHub拉取Invoke-atomicredteam中的部分工具。


下载Invoke-atomicredteam项目，解压，下载atomic-red-team解压，把atomic-red-team的atomics复制进去


在Invoke-atomicredteam项目根目录参考如下命令进行安装

Set-ExecutionPolicy UnrestrictedImport-Module "C:\Users\xxx\Desktop\invoke-atomicredteam-master\invoke-atomicredteam-master\Invoke-AtomicRedTeam.psd1" -Force$PSDefaultParameterValues = @{"Invoke-AtomicTest:PathToAtomicsFolder"="C:\Users\xxx\Desktop\invoke-atomicredteam-master\invoke-atomicredteam-master\atomics"}Invoke-AtomicTest All -ShowDetailsBrief


Invoke-Atomic的使用


官方建议在开始使用前最好列出所有支持的测试，确保正确安装


Invoke-AtomicTest All -ShowDetailsBrief



执行所有测试用例，全部用例执行要很长时间，请谨慎执行

Invoke-AtomicTest All

然后就可以对比安全设备的检测和告警情况了


项目维护情况


Atomic Red Team目前维护较积极并且slack也比较活跃，微软在去年也支持了Atomic Red Team评估的支持。





小结


ATT&CK不仅仅是一张映射图，而是需要在实际环境中进行动态改进的过程，这个过程需要甲乙方一起努力。


例如，一次攻防演练后，甲方就可以根据攻击队提交报告中提取TTP并映射到ATT&CK框架的具体case，并使用Atomic Red Team进行一系列的模拟，从而提高自身的检测和响应能力。
