# 【网络安全】Linux 本地提权漏洞 CVE-2021-4034

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NzA5Nzg2Nw==&mid=2247484394&idx=1&sn=402a011396cbfbfc38146abf3b0868f9&chksm=fdf0718eca87f898d3feca67f55d90c0f1405dfc0fd9040807f73e4e0ca2e0d7f25fcc2e99b7&scene=126&sessionid=1681273628#rd](http://mp.weixin.qq.com/s?__biz=MzU4NzA5Nzg2Nw==&mid=2247484394&idx=1&sn=402a011396cbfbfc38146abf3b0868f9&chksm=fdf0718eca87f898d3feca67f55d90c0f1405dfc0fd9040807f73e4e0ca2e0d7f25fcc2e99b7&scene=126&sessionid=1681273628#rd)

Qualys 在 Polkit（默认安装在 Linux 主流发行版上）的 pkexec 发现了一个漏洞，可以使非特权用户获得主机的 root 权限。这个漏洞在 2009 年 pkexec 的第一个版本就已经存在，今日被正式标记为 CVE。  

成功利用此漏洞，任何非特权用户都可以在易受攻击的主机上获得 root 用户权限。Qualys安全研究人员已经能够独立验证漏洞，开发漏洞，并获得Ubuntu，Debian，Fedora和CentOS默认安装的完全root权限。其他 Linux 发行版可能易受攻击，也可能被利用。此漏洞已经隐藏在众目睽睽之下 12 年以上，并且自 2009 年 5 月 pkexec 的第一个版本（提交 c8c3d83，"添加 pkexec（1） 命令"）以来，它影响了所有版本的 pkexec。

成功利用此漏洞允许任何非特权用户在易受攻击的主机上获得根特权。Qualys 的安全研究人员已经能够独立验证 Ubuntu、 Debian、 Fedora 和 CentOS 的缺省安装漏洞、开发漏洞并获得完全 root 权限。其他的 Linux 发行版很可能是脆弱的，也可能是可利用的。这个漏洞已经隐藏在显而易见的地方超过12年了，并且自从2009年5月第一个版本（commit c8c3d83，" Add a pkexec （1） command"）以来影响了 pkexec 的所有版本。

一旦我们的研究团队确认了该漏洞，Qualys就参与了负责任的漏洞披露，并与供应商和开源发行版协调以宣布该漏洞。

一旦我们的研究小组确认漏洞，Qualys 参与了负责任的漏洞披露，并与供应商和开放源代码发行版协调，以宣布该漏洞。
