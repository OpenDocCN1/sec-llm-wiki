前言

本文主要为获取主机权限后的手动信息收集。

注意事项：

常见的杀软都会对CMD、PS命令进行记录

使用了命令混淆，命令对应二进制文件的参数可能还是真实的参数


用户/组信息

查看当前用户

whoami

查看当前主机名

hostname

查看本机的配置信息，这里就会显示当前域

net config Workstation

查看主机账号

net user

获取本地管理员信息

net  localgroup   administrators

列出会话

net session

查看在线用户

quser    # 查看在线用户，注意管理员是否在线query user || qwinsta   # 查看当前在线的用户

查看当前保存的登陆凭证

cmdkey /l  # 查看当前保存的登陆凭证


网络信息

IP信息

可以用来判断是否有域，或者是否存在双网卡

ipconfig /allGet-NetIPConfiguration | ft InterfaceAlias,InterfaceDescription,IPv4AddressGet-DnsClientServerAddress -AddressFamily IPv4 | ft

内网有价值的arp通信记录

arp -aGet-NetNeighbor -AddressFamily IPv4 | ft ifIndex,IPAddress,L

路由表

route print      # 查看路由表Get-NetRoute -AddressFamily IPv4 | ft DestinationPrefix,NextHop,RouteMetric,ifIndex

DNS服务

nslookup   #DNS服务器ipconfig /displaydns #DNS缓存

网络连接状态

netstat -nao   # 查看网络连接状态，判断IP段，出网限制端口

获取本机连接过的WiFi密码

for /f  "skip=9 tokens=1,2 delims=:" %i in ('netsh wlan show profiles')  do  @echo %j | findstr -i -v echo |  netsh wlan show profiles %j key=clear


系统信息

查询操作系统和版本信息

systeminfowmic OS get Caption,CSDVersion,OSArchitecture,Version  使用 wmic 命令查询


[System.Environment]::OSVersion.Version

查看系统信息以及补丁情况

systeminfo# 查看系统信息以及补丁情况，是否有域wmic qfe get Caption,Description,HotFixID,InstalledOn   
Get-WmiObject -query 'select * from win32_quickfixengineering' | foreach {$_.hotfixid}Get-Hotfix -description "Security update"

根据补丁查找exp（注意更新时间） http://bugs.hacking8.com/tiquan/


使用wmic 命令查看安装的软件和版本、路径

wmic product get name,version,InstallLocation
powershell  "GET-WmiObject -class Win32_product  | Select-Object -Property name,version"

查询本机服务信息

wmic service  list  brief

查看host文件

type c:\Windows\system32\drivers\etc\hosts

查询进程

 tasklist /svc wmic process  list  brief

常见杀软进程

https://github.com/StudyCat404/WhatAV/blob/master/av.json


查看启动程序

wmic startup  get command,captionREG QUERY HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\RunREG QUERY HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

查询安装的程序

reg query HKEY_LOCAL_MACHINE\SOFTWARE dir /a "C:\Program Files"dir /a "C:\Program Files (x86)"

查看计划任务

schtasks   /query

查看开机时间

net  statistics  workstation

查看主机的共享信息

net  sharewmic  share  get name,path,status

查看环境变量

setpowershell命令查看 env 环境变量dir env:Get-ChildItem Env: | ft Key,Value


查看防火墙配置

netsh advfirewall show allprofilesnetsh  firewall  show config

查看RDP服务

REG QUERY "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections  # 查看RDP服务是否开启: 1关闭, 0开启

查看驱动器的信息

wmic logicaldisk get caption || fsutil fsinfo driveswmic logicaldisk get caption,description,providername
Get-PSDrive | where {$_.Provider -like "Microsoft.PowerShell.Core\FileSystem"}| ft Name,Root

查看域内密码策略

net accounts


域信息


查看域名

echo %USERDNSDOMAIN%

查看域控机器名

echo %logonserver%set logonserverset lognet time /domainnet group "domain controllers" /domain

列出域内组

net groups /domain

列出域控

nltest /dclist:域名


列出连接域的机器

net group "domain computers"

列出域管

net group "domain admins" /domain

列出企业管理组

net group "enterprise admins" /domain

列出域用户

net user /domainwmic useraccount get /all

列出域用户的信息

net user 域账户 /domain

列出域信任关系

nltest /domain_trust
