Windows日志分析基础

Windows日志基础知识

Windows Server 2003以上的日志位置：%SystemRoot%\System32\winevt\logs

默认情况就是C:\Windows\System32\winevt\Logs

日志扩展名：低版本.evt；2003以上则是.evtx

Windows server 2003以前的版本主要只有三种日志类型，03以后逐渐增多。

日志分析思路

日志分析主要可以按照以下思路展开


  1. 定位关键线索（一般来自安全设备的告警，首先把日志和告警关联起来）


  • 木马、恶意dll文件名

  • 可疑进程

  • 失陷IP地址、机器名

  • 已失陷账户


  1. 定位到关键线索位置后，可以从以下几个角度进行分析，从而将线索关联起来


  • 攻击者的最开始的入侵方式

  • 攻击者恶意进程相关用户名

  • 攻击者的入侵时间

  • 攻击者后渗透阶段的进程、创建/删除的文件

  • 是否进行了横向移动、持久化


导出安全日志


wevtutil epl Security c:\windows\temp\sample.evtx

Windows日志分析工具

上节提到的都是分析的基础，生产环境一台机器一天日志量基本都是十万起步，噪音非常大，这时候单纯依赖人工进行筛选就很不现实。

如果生产环境有日志接收服务器，并购买了splunk、ELK等设备会很方便，如果没有购买，可以使用下面的工具进行辅助分析。

FullEventLogView

  • 介绍

下载地址：https://www.nirsoft.net/utils/full_event_log_view.html

特点：免安装，开箱即用，搜索能力强，多语言

  • 使用

导入外部日志：文件--选择数据源--选择导出的Windows日志目录

然后就可以查看日志，简单对比一下Windows自带的事件查看器界面

上图是FullEventLogView的界面，下图是Windows自带的事件查看器界面


可以通过快速过滤功能，筛选出需要的日志

注意：默认只筛选7天内日志，如果分析时间较老的日志需要关掉这个设置


此外FullEventLogView支持的导出格式比较多：text/csv/json/html/xml


所以可以导出Windows日志到其他格式供其他工具比如Timeline Explorer、Excel分析。下图就是导出为csv格式，并在Timeline Explorer中查看


Timeline Explorer

  • 背景

现在的安全事件，比如入侵也一般是一个过程，而不是孤立的事件。在分析安全事件时，基于时间线的工具就可以更方便的帮助分析人员把各类事件线索联系在一起。

  • 介绍

Timeline Explorer是一款SANS推荐的时间线分析工具，也是SANS评选出的2021年年度十大受欢迎开源工具。

下载地址：https://www.sans.org/tools/timeline-explorer/

  • 使用

支持分析的文件格式：excel、csv

因此可以使用之前的FullEventLogView导出excel格式的文件供分析，不过Timeline Explorer对excel格式只能看第一个sheet

双击单元格可以单独查看因为一行过长影响查看效果的字段


支持即时过滤，复杂过滤，搜索等功能，而且筛选功能是即时生效的。

下图是分组聚合功能，方便分析哪些事件噪音比较大，从而寻找异常迹象

又比如这里的日志清除

相比excel，更适合安全人员根据时间线进行分析，而且基本覆盖了excel的安全场景，缺点就是只能复制、标记，但是不能编辑。

LogonTracer

  • 介绍

可视化解析Windows登录日志，后端数据库和bloodhound一样，用的是Neo4j图数据库。

项目地址：https://github.com/JPCERTCC/LogonTracer

  • 安装

这里支持采用docker方式，注意虚拟机的配置要高点，另外因为页面没有任何访问控制，不要在公网部署，注意敏感信息泄露

sudo docker run \--detach \--publish=7474:7474 --publish=7687:7687 --publish=8080:8080 \-e LTHOSTNAME=your-ip \-e TZ=Asia/Shanghai \jpcertcc/docker-logontracer

  • 使用

访问http://your-ip:8080即可，没有登录页面

上传日志需要注意选择东八区

输入用户名，点击search，即可生成图


图中每个节点颜色的含义如下：

红色：SYSTEM权限账户

蓝色：标准用户帐户

绿色：主机/IP 地址


左侧可以根据一些预制规则对一些事件进行筛选，比如新增账号、DCSync

左下方的Create Timeline可以创建时间线进行分析



这个界面有点像常见的SIEM的UEBA提供的时间线分析界面。

chainsaw

  • 介绍

相较上面的工具，这款工具更偏识别Windows日志中的威胁信息。

项目地址：https://github.com/countercept/chainsaw/

  • 安装

linux 下需要安装一下GLIBC

yum install gcc -ycurl -O http://ftp.gnu.org/gnu/glibc/glibc-2.18.tar.gztar zxf glibc-2.18.tar.gz cd glibc-2.18/mkdir buildcd build/../configure --prefix=/usrmake -j2make install

然后下载项目执行chainsaw可执行文件即可

  • 使用

./chainsaw hunt /root/security.evtx


将当前日志映射到sigma检测规则

./chainsaw hunt evtx_attack_samples/ --rules sigma_rules/ --mapping mapping_files/sigma-mapping.yml

总结

数据无价，小心日志被清掉。
