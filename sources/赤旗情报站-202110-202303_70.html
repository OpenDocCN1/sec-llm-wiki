问答环节


TASK 1 What dose the acronym VM stand for？

Virtual Machine


小知识：什么是虚拟机：一个 虚拟机 （VM）是一个计算资源使用软件，而不是一个物理计算机上运行程序和部署应用程序。一台或多台虚拟“访客”机器在物理“主机”机器上运行。每个虚拟机都运行自己的操作系统并独立于其他虚拟机运行，即使它们都运行在同一主机上。这意味着，例如，虚拟 MacOS 虚拟机可以在物理 PC 上运行。


TASK 2  What tool do we use to interact with the operating system in order to start our VPN connection?

terminal


小知识：什么是终端？终端简单来说就是为了连接交互界面和内核而推出的应用程序，通过用户指令间接控制系统内核。



TASK 3

What service do we use to form our VPN connection?

openvpn




TASK 4

What is the abreviated name for a tunnel interface in the output of your VPN boot-up sequence output?

tun




TASK 5

What tool do we use to test our connection to the target?


ping

小知识：ping用于确定本地主机是否能与另一台主机成功交换(发送与接收)数据包，再根据返回的信息，就可以推断TCP/IP参数是否设置正确，以及运行是否正常、网络是否通畅等。

TTL 字段值可以帮助我们识别操作系统类型：

UNIX 及类 UNIX 操作系统 ICMP 回显应答的 TTL 字段值为 255；

Compaq Tru64 5.0 Windows XP ICMP 回显应答的 TTL 字段值为 64；

微软 Windows NT/2K操作系统 ICMP 回显应答的 TTL 字段值为 128；

微软 Windows 95 操作系统 ICMP 回显应答的 TTL 字段值为 32。



TASK 6

What is the name of the tool we use to scan the target's ports?


nmap



TASK 7

What service do we identify on port 23/tcp during our scans?


telnet

小知识：Telnet协议是TCP/IP协议族中的一员，是Internet远程登录服务的标准协议和主要方式。这玩意最大的安全隐患就是明文传输。



TASK 8

What username ultimately works with the remote management login prompt for the target?

root

小知识：root是Linux系统中的超级管理员用户帐户，该帐户拥有整个系统的最高权限，可方便地对于系统的部件进行删除或更改。
