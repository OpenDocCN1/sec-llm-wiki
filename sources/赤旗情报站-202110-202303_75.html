“世界上的每个人，都会有一部手机，在中国，大部分人都至少有一个以上的手机号码。手机号码是一个进入网络的媒介，是我们每天都用来社交的数字资产。所以，手机号码是信息收集工作中，非常重要和最易收集的资源之一。”









简介

今天介绍的是OSINT框架下的一个信息收集的侦察工具。OSINT就是open-source intelligence的缩写，译为开源情报；

GitHub地址
https://github.com/sundowndev/PhoneInfoga
 
Phonenfoga 是先进的信息收集工具之一，支持自行搭建服务后，就可以收集手机号码信息，可以对任何国际手机号码以较高的准确度，进行下列信息收集：
  • 标准信息
    • 国家
    • 地区
    • 运营商
    • 线路类型
  • 内置Google hacking搜索互联网痕迹
  • 定位网络手机服务的运营商
 

功能

  • 检查手机号码是否真实存在
  • 收集标准信息，如国家，线路类型和运营商
  • 利用外部 api，内置Google hack，通过搜索引擎寻找互联网痕迹
  • 查看社交媒体关系网络、一次性号码识别等
  • 支持批量扫描若干手机号码
  • 可自行搭建服务
 

注意

  • 不需要提供相关或验证的数据，它只是一个收集工具运行
  • 不能实时“追踪”手机或者精确定位的手机位置
  • 不允许非法入侵手机
  • 需要使用国家代码，比如美国的国家代码为+1，中国的国家代码为+86


部署方法


  • 使用Docker拉取镜像
    docker pull sundowndev/phoneinfoga:latest
  • 通过8080端口映射，您可以访问本地的8080端口进入网页
docker run -it -p 8080:8080 sundowndev/phoneinfoga  serve -p 8080

总结



对手机号进行信息收集时，要清晰明白以下三点：


第一，手机号构成：


手机号可以分为三段，都有不同的编码含义：


  • 前3位是网络识别号

  • 4-7位是地区编码（HLR归属位置寄存器）

  • 8-11位是用户号码（随机分配）


第二，工具的有机构成：


  • 专业的扫描工具

  • 强大的社工数据库

  • 各类工具构成有机组合
