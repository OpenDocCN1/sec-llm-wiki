# 【安全快讯】Windows Installer 权限提升漏洞（0day）

安全研究员 Abdelhamid Naceri 发现 Microsoft Windows Installer 的修复补丁 CVE-2021-41379 带来了另一个特权提升漏洞。

  

Naceri 在 GitHub 发布了程序样本和说明，它 “通过覆盖 Edge 的提权服务 DACL，将自身复制到 elevation\_service.exe 并执行，以获得提升的权限”。该漏洞影响 Windows 10， Windows 11 和 Windows Server 2022。

  

SYSTEM 权限是 Windows 用户可用的最高用户权限，可以执行任何操作系统命令。

  

通过利用这种零日漏洞，对受感染系统具有有限访问权限的攻击者可以轻松提升其特权，以帮助在受害者网络中横向传播。

  

BleepingComputer 已经测试了 Naceri 的漏洞，并使用它从具有低级别“标准”权限的帐户成功打开具有 SYSTEM 权限的命令提示符。

  

“由于此漏洞的复杂性，在撰写本文时可用的最佳解决方法是等待 Microsoft 发布安全补丁，”Naceri 解释说。“任何直接修补二进制文件的尝试都会破坏 Windows 安装程序。所以你最好等待，看看微软将如何再次破解补丁。”

  

微软目前尚未发布补丁。腾讯安全团队给出的临时缓解方法为：关闭 MicrosoftEdgeElevationService 服务（Ctrl + Q 搜索 “服务”，然后禁用上述服务）。建议谨慎处理不明程序或文档，小心中招。
