# Goby一周年谈安全工具的生态

时光荏苒，距离去年这个时间点我们很兴奋的发布了Goby测试版刚好一周年，一年下来我们收获丰厚，这种收获并不是经济利益，而是一种认可一种尊重，毕竟我们是要“做一家技术导向的受人尊敬的顶级网络安全公司”。

  

前一段时间恰逢某重要攻防演练活动，于是乎Goby的下载量激增，每天的日活也达到了一个历史新高，让我有种回到当年Pangolin刚开发出来时的那种感觉。一个典型的事件就是在我们推出红队专版的时候，一大波人想要进群，包含地方的红队和各种披着红队外衣的蓝队成员准备混水摸鱼，最夸张的就是大家前仆后继地提供自己的真实身份信息，让我们嗔目结舌。后来连公司内部的市场人员要求提供版本，我去找产品经理求情，也被无情地拒绝了，内部一片讨伐声，我倒是认为产品经理是对的。

  

于是大家很兴奋地跟我沟通做得多好如何如何，我前十秒是兴奋的，然后很自然变得心情沉重。毫无疑问，国际形势和国内的大趋势使然，网络安全未来会变成一个主战场，大家对一个好的网络安全工具的需求达到了历史顶峰。这是一个改革的前夜，一种积压已久的沉默会通过来自不同角色的呐喊声发泄出来，就有如第一次工业革命的爆发。你压抑，但是你不知道为什么压抑，你知道有个点会引爆，但是你又不能准确地说出来是哪个点以及什么时候引爆。在这个过程中，你会是一个旁观者还是一个参与者？甚至是一个领导者？

  

国内好用的网络安全工具屈指可数，十年前大家讨论pangolin和caidao居多，现在大家讨论最多的是我们的goby和长亭出品的xray（点个赞）。这是一种认可，也是一种极大的悲哀，越认可越悲哀，因为目前的goby和xray发展至今也只是一个单点工具，技术壁垒不高，生态没有形成，相比于国外的nmap/metasploit/burp还存在几个鸿沟要去迈过，咱们就想想连cs那种极其难用的语法国内一批安全人员也积极地去贡献去适配，你就能明白咱们在网络安全工具上是多么的荒芜。国内的安全氛围相比国外而言更加封闭，没有国外那么开放，同时在单点事物上也很难像国外那样长期聚焦和坚持（以十年算的话国内几乎就没有了）。

  

Goby做的很烂，这不是谦虚，是真的很烂，从两点可以很明显的看出来：一是至今Goby只是一个beta版本，一年了都不敢转正；二是至今我们团队给不出Goby一个精准的slogan。它到底是个什么玩意？漏洞扫描器你漏洞不多啊。资产管理平台？你根本没有业务属性啊。自动化攻击机器人？你连任务编排的功能都没有啊。所以大家不要问我Goby到底是什么，在我个人的认知上还有不短的路要走，我也不知道它是什么。每次大家这么问我，我都假装洒脱地说你爱怎么理解怎么理解。就好像你生了一个娃，怀胎十月生下来有jj的叫男孩，没有jj的叫女孩，那怀胎三年六个月生下来的三头六臂到底是怪胎还是叫哪吒三太子，你只有等他长大了才知道。

  

我们国家的群体智慧是非常非常强大的，大到了足以在任何一个领域做到世界最强之一。无论从文化还是科技方面，做研发国内的年轻人跑到国际上都是金牌，做漏洞挖掘咱们随便分一个队出去都是冠军。数学和人工智能我们怕过谁？我们说卡脖子的到底是单点技术还是生态？我们做不出芯片是不存在的，做不出操作系统也是不存在的，做不出任何软件都是不存在的。你做出来了缺少生态那是真存在的大问题，生态不是一朝一夕能出来的，芯片对应的系统你有吗？系统对应的软件你有吗？这些没有你就得等十年。我们很愿意绕开根基去做上层建筑，因为建地基成本高时间长见效慢，大家都想“取个巧”，殊不知哪一天就被釜底抽薪。微软的操作系统系统未必那么难，但上层的生态你切不走，谷歌的安卓系统未必那么难，同样的上层生态你也切不走。为什么大家对华为的鸿蒙又爱又骂，骂它是骗子的是因为你迟迟不出来，爱他的是大家都把建地基的工作望着大厂，看着国家，我们自己也无法投入去做地基，总得有个依托。一批开发者嗷嗷待哺，这就是历史最困难的时候，也是机遇最好的时候。

  

我们做不来系统，但是我们做安全工具绝对在国内当仁不让的第一梯队啊，无论是Pangolin/JSky/Fofa/Goby，每一个我们都能做出成就感，虽然我们知道距离国际还有一定的距离，但是我们已经代表了国内最好的水平。我跟我们负责商务的联合创始人说，你们必须通过商务把goby团队再养两年，两年内我们没有收入不知道方向，我们就是在摸索一个方向，也许我们不幸成为了工业革命前夕的先烈，但也许我们就成为了引导工业革命的领航者。我们不要去做容易做的但是错误的事情，我们要去做难做的但是正确的事情。

  

今年有个事情我觉得很值得一提。猪猪侠同学在去年的攻防活动中一战成名（嗯，他已经多次一战成名），今年凭借着他搭建的系统再一次吊打其他对手。因为他把一个最小化的MVP走通了，尽管我能想象到每个点他们都做得有很大的改进空间，尽管如此，在一堆的小迷弟面前，已经是叹为观止惊为天人。我觉得既兴奋又惋惜，兴奋的是终于有人把流程跑通了，在那么小的范围也能发挥巨大的威力，这对我而言无疑是一个很大的信心（因为我比他开发系统的能力更强嘛），惋惜的是那是一个封闭式的环境，缺少了一个生态来补齐和改进，人在系统好用，人不在系统也就不好用了，同时他再好跟你也没有关系，对行业产生“可远观不可亵玩”的效果。于是一堆人拼了命的往自动化攻击机器人的方向重复的造轮子，这些轮子多少年了都没有变过：域名爆破、端口扫描、2.0爬虫、密码字典、漏洞扫描与利用、信息提取、任务编排、权限维持、钓鱼模版、外部情报、社工库……

  

今年还有一个事情值得一提，那就是攻防对抗确实技术有一些升级了，不只是攻击技术升级了，防守技术比如被动的蜜罐抓案例，甚至是主动的蜜罐做反制都有效果。除此之外，大家终于知道怎么做信息采集和做攻击预判了，不得不说是一个很大的提升。与之而来的就是，测试类工具如何更加智能更加轻量，能够绕过这些防护手段。我可以预见的是，未来的工具肯定是分布式的来解决告警和拦截的问题，肯定是能够准确识别或者干扰蜜罐的（不用那么准确，在非战时没这么多人盯着告警，即便有也会被大量的垃圾告警给累死），肯定是端到端把整个体系走通的……这么说起来，大家就明白了，每一个点都需要长期投入做精做深，所以有人搭建框架，有人提供模块，它最可能成长起来的模式就是生态化平台化。因为即便是我，每一个细分的点不去沉淀个几个月几年，想要做精都难。很多人曾经说fofa很简单，我也认为很简单，就这破东西做了我5年，事情越做越多，投入越来越大，我这才发现这不是一个开发的活，是一个拼耐力的活。我回过头看那些嘲笑我们的人，后来都没有声音了，因为他们又去嘲笑别人去了。

  

我们感觉压力很大，因为我知道有太多的big feature我们定了下来，但是还没有来得及做。一方面是没钱没人，另一方面是你就算有钱了有人了，你也做不完，要把一件事做好做大了，光靠我们自己是不行的。我们属于不自量力型的瞎折腾，这一年下来，我们把一些文化坚持下来了，能够得到大家的认可我还是非常感动的。大家知道前途是光明的，过程再曲折希望都在那。当我们做了插件市场，也得到了各位大佬们的支持，深深的感激。谁说国内就做不出最好的安全工具是吧？我们偏不信邪，记录没被打破之前，大家还都觉得遥不可及，最后呢？记录存在的唯一目的难道不就是为了被人打破吗？

  

Goby未来的一年内能不能转正我也不好说，生态也没这么快，我总结下来大家的核心问题还是在于：首先白帽子对自己的能力缺少自信心；其次是英文真的普遍刚入门。一批能力顶尖的不屑于在你的地基上贡献，所以国内一堆的地基，还有一批人又总觉得技术不行不太敢跑这个地基上来玩，躲在墙角远远的看着。

  

我们很庆幸的一点是，我们并没有向所有干扰妥协，我们能够坚持自己的方向，任你海浪滔天我自巍然不动。比如我们就这么几号人，但是依然坚持要把设计做好，有主题还能做成插件，这事一些朋友说你们是不是工作量不饱和？居然不把精力花在做核心功能上。这事我们不是这么理解的，一个好的生态依托于一个好的地基，好的地基一定不能丑，能漂亮就最好不过。这就能解释安卓系统，vscode为什么很早期就给出主题自定义。一个充满艺术感的工具让人的体验是很美好的，你看那一批程序员，装好一个工具，一定先把编辑器改成极具个人色彩的样式，不然他心里不舒服。后续我们对主题还有更好的设计，大家到时候可以感受感受，一个我们每天使用的工具，怎么能丑呢，那不是给自己找难受吗。另外还有，大家吐槽很多的就是漏洞少，这一点我们也都理解，只是我们坚持只做靶标漏洞，而且我们的目标是漏洞必须有exp，在exp方面我们也很强调艺术性，用最少的代码做最稳定的输出。漏洞扫描是我们一个很重要的模块没错，但是它并不是大头。即便我们做的尝试最后输出了一个怪胎，大家依然持续支持用户持续增长，说明我们总的方向还是对的。

  

这就是现状，大家痛并快乐着：方向是对的，时机是好的，潜能是巨大的。goby还刚刚开始，距离成功还为时尚早，我们只是比大多数要走的快那么一点。曾经我做了太多的努力都帮他人做了嫁衣，种地是我摘果子未必是我，我倒也不担心，看着一片荒地被大家种出了一片绿洲，也是很令人开心的事情。至于这个方向最终做成什么样，我说了不算，靠大家来聚沙成塔。

  

桃李不言，下自成蹊！
