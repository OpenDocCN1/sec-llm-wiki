# 圣殿

最近收到了一些朋友的反馈，大意是我的产品或者文章给了大家一些启发和帮助，过来鼓励鼓励我。这倒是我没有想到的，就我这八股文般说教式的文字，也能有自己的受众群，实在让我受宠若惊。

  

实话说，我目前这个阶段不太在意大家说了什么，无论是骂也好夸也好，我都一笑处之。当然我对大家的肯定心存感激，另一方面我很清楚我们距离设想的美好未来还有一段路程，我们并没有把之前预定的动作都做完，所以人家质疑你没有结果是对的，人家肯定你的努力也没毛病。但是我们自己得清楚，最好的未来还没有来，只是还在持续的到来的过程中，这个阶段一定要埋头把自己的事情做好。

  

我看过一个故事，大意是这样的：从前有一座美丽的城堡，城堡里正在修建一座规模宏大的教堂。在教堂的搭建场地里，其中有三位正在砌墙的工人。这时，来了一位教夫。他分别问三个工人同一问题：你在做什么？第一位工人说：你没有看到呀，我在做苦力。第二位工人说：我在砌教堂的墙。第三位工人说：我在建一座教堂，一座让世人仰慕的圣殿。

  

我们就想做一个圣殿，别人看不见它，但是它无比清晰的存在我们的脑海里，就好像把美景升华后存在梵高脑海中的艺术世界那样，不同的是我不希望收获他那样悲惨的结局。选达芬奇的人生比梵高要好，选爱迪生的人生也比特斯拉要好。一种在有生之年都没能看到自己卓越的价值和影响力只是默默地死去，一种则是存在一些小小的争议然而能够持续的发展，最后结果都是被人记住与尊重。我说的小争议就是向世俗低头，太理想主义的人不受嗟来之食，结果可能把自己给饿死了。

  

一本书一幅画可以单枪匹马来完成，拼的是创意和一个人的笔头功夫，而一个建筑（比如教堂）或者软件开发这方面，我越来越觉得一个人干不过来，不是没能力，实在是没精力。像Justo Gallego Martínez老爷子这样的，一个没有专业知识的人，花50年徒手建了一座教堂，每一块砖都亲力亲为，也算另一种奇迹，世界上也就他这一人了吧。所以正常情况下，你要有很多牛人来帮你一起实现，请这么些人你就得花钱，你就要想办法拿到这么些钱，你看一下就世俗了，开始出去谈客户找投资。灵魂还是你的，一段时间内肉体不属于你了，这倒也说的过去，总比灵魂都不是你的要好。随着事情的推进，我终于把肉体拿回来了一点，但凡有时间，我都想把那个圣殿再砌一块砖。

  

每个人都有自己的圣殿，我们可以理解为每个人自己的作品。可以是艺术品，可以是软件，可以是一个创业的公司，可以是科学公式，也可以是把脚步留在每一片土地的行为。不一定流芳百世，但是你们感染到一批人，让大家有所帮助，这些就够了。我们常常高估了外界对能力的要求，又常常低估了自己的能力，所以很多时候我们往往不太敢迈出那一步。一旦你走出去了，你就完成了一半。

  

一个好的作品，需要有一些条件。比如首先要回答你是给谁做？有些人是为了赚别人的钱给别人做，自己不使用不兴奋，这种最多叫产品，不能叫作品。我曾经问过一个朋友，他的公司上了世，每年很好的净利润，我问的问题是你是怎么想到做这个的，因为我知道你不是这个领域的专家，之前也很少有接触。他回答说创业前做过“哪个行业最赚钱”的调研，选择了这个方向，后来毫无疑问证明他是对的，只是我隐隐约约觉得哪里不太对。我听说今日头条的老板不用今日头条，如果传闻是真的，我也会觉得不太对，或者我理解不了那种思考方式。我一直信奉的是做自己喜欢的东西，那种东西先不说别人能有多喜欢，一定是我先喜欢，所以类似于我这种细分领域的同类人群肯定也会喜欢。这是不是也能说明为什么我适合做网络安全。

  

其次我觉得需要保持专注以及坚持。在《庄子》有一篇说佝偻丈人承蜩的故事，他说“虽天地之大，万物之多，而唯蜩翼之知。吾不反不侧，不以万物易蜩之翼，何为而不得！”，孔夫子点评说“用志不分，乃凝于神”。除了我们现在说的工匠精神，你还得有一种信念在里面，这是一种根深蒂固的价值观，一种积极的文化。传说干将莫邪铸剑，最后莫邪投入熔炉，最终练出宝剑，科学技术上并没有指导意义，传递的是一种作品的灵性，一种物质之外的生命力，一种画龙点睛的效果。这种东西，别人可以不信，但你不能没有，你要没有世界观就崩塌了，你也就快疯掉了。说战士就应当死在战场，你信不信有人真这么想？我相信是有的。

  

一个品牌logo有没有生命力？它可能只有32\*32像素，流水线作业的外包公司只能做到“不丑就行”，当你问设计师，你是怎么想的，他们可能只是敷衍式地说一下颜色布局。一个图标还能有啥想法。所以，你做的是工作，输出的是交付件，你从一开始就没有意识到它是你的一个作品。你也就理解不了那几十像素的里面承载的文化，也理解不了为什么很多人会花费数百万去请人设计。大芬油画村有很多人经过快速地培训，能够合格地临摹蒙娜丽莎，技巧娴熟，挥笔即来。临摹的时候他们可能啃着馒头，跟人聊着天，这只是人生阶段赖以生存的一个动作而已，先活下来一点也不丢人。这也能解释为什么你临摹的再好，跟原作相差数千倍的价格。因为你并没有思考到区别，你更加没有想到这个作品你注入了什么理念和文化价值。

  

很多人会觉得大部分人理解不了，哪怕你有多么真诚的投入，呕心沥血。这倒是真的，大部分人感受不到，因为价值观上有差异，对产品的理解有差异，甚至是单纯地因为长相上看不惯。总之，世界上可能有99%的人认为你矫情，认为你是可以做作，但是总是有那1%的人跟你有相同的经历，相同的价值观，他们是认可的，他们跟你一样精益求精，追求的是一个价值体验。

  

每个人都有着自己对这个世界不同的理解，没有人不是从温饱需求开始的，但是我相信没有人是以温饱作为自己人生终点时的理想。同样一件事，有人只是为了交差，有人做成了艺术，其中的差别相隔天地。我经常说最佩服的人是想明白了的人，想明白怎么活的人内心无比强大，不以物喜不以己悲，他们会专注于某件事，直到大成。当然不指混吃混喝啃老那种想明白，而是指带着创新精神，想要做出一个作品拿在手上欣喜把玩的那种，想明白活着的意义的人。

  

都说四十不惑，可能在提醒我快四十了吧，所以慢慢也给自己定了性，我就得在网络安全领域做点东西，做出让自己兴奋的东西，让大家认可的东西。赚钱那是一定要的，那仅仅给自己给大家一个交代而已，让大家觉得能够开心和有成就感的事情，至于市值百亿千亿实在不值一提。最关键的当然是作出别人没有想过，不敢想的高度。每次想到这，就又充满了能量。

  

最近大家伙在给Goby设计主题功能，当设计师把设计规范发出来给大家看时，我比较感慨，里面详细定义了每一个色号每一个像素每一个位置，对于一个小小的网络安全工具而言，似乎有点不务正业。用户还有很多功能呼声你不做，先弄这些虚头八脑的是不是本末倒置。连我们内部的兄弟也问过我说，我们是不是把“艺术性”先放一放。当然不，我们要做圣殿，有了这点小东西不代表就是圣殿了，但是我觉得圣殿就一定得有这些小装饰。
