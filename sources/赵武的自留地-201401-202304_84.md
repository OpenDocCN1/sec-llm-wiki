# 糊涂比清醒更幸福

这个世界，有些事情不知道比知道要好，比如类似于你长得丑这种事，再比如说你信息被泄露这种事。

昨天一个关于账号密码泄漏的微博没想到引起了轩然大波，各个朋友（尤其是甲方信息安全的负责人）通过各种渠道问我是谁，我说不能说的情况下，问“那你能告诉我是不是我们”。我非常不好意思的把大家都给拒绝了，于是各甲方又开始往自己头上套。

各位粉丝也开始了娱乐，有说xx最近不能登录，是被黑客攻击了之类的；有说xxx取消了支付密码之类的；也有说公司加起来是10的公司，他们库早就被拖了之类的。恰好，一些观众真能拿出证据证明自己近期账号被黑了，于是大家就开始了无限制的脑洞大开。

这种情况的发生，就好比某位纪检的领导对外宣称“有干部涉及违规，近期会被立案调查”，于是一大批干部开始自我反思“我X，会不会是哪个狗日的把我供出来了？”，是一个意思。这背后有两层含义：一是权益方对自己的问题其实挺心知肚明的，也知道安全这事啊只能说尽可能做保险一点，关键谁也不能保证绝对的安全，所以哪一天出问题也很正常，紧张总是应该的，有则想办法补救，无则提高警惕意识；二是大家对这类事其实也挺习以为常了（无奈之举），绝大多数人也没法自证是直接受害者，呵呵过后也就洗洗睡了。

鉴于我知道网络安全就是一个假象，尤其在自己账号多次被黑的前提下，我对于信息安全从来都是悲观的。不管厂商多么努力，我交给厂商的任何信息都要假设已经丢了。所以，我认为安全的形式就是尽可能用不同的马甲，将自己隐匿于互联网泱泱流量中去，将账号分级管理，定期修改密码，如果能用随机生成无含义的密码就最好了。当然不用网络是最安全的，只是你出门就要打车就要吃饭，就要用微信支付或者支付宝，为了证明你不是远古人类你就接受了这种现状。而每家企业都恨不得把你祖宗八代的信息都收集和存下来，哪一天搞不好给你发个信息“你祖上曾国藩今天2000年诞辰，作为孙子的孙子的孙子的～～～的孙子，我们推荐你购买《曾国藩文集》纪念版……”。

两年前tk告诉我他还在用一台非常古老的机器（还能运行win98吗？），如果我没记错的话他也不用网银，不知道现在是否还是如此。不过我不用网银，而且至今没用上支付宝这事是真的。我知道我的账号一定有超过10个黑客拿走了，保不齐我在码这些文字的时候，网络的那一头就有一个“黑客”朋友嘿嘿傻笑的在看着。

这是一个新时代，新时代总会带来一些很无奈的副作用，大家改密码改到奔溃，有人说“我改的实在是记不住了”，也有人说“想新密码已经文思枯竭”。这种无奈还会继续下去，这会或者已经进入一个恶性循环：一些网站的数据库泄露，个人账号丢失，黑客利用已经泄露的信息足够让他们再把这个人（员工）所在的企业黑进去，于是又拿出来这个企业用户的账号信息，如此往复。

安全从业人员知道了有漏洞和社工库的存在，于是我们生活在无奈和痛苦之中，所以我们不幸福；而其他大多数人不信或者说不知道，你们就是幸福的。我们假设一个场景，如果你是黑客帝国中的主人公尼奥，当墨菲斯手里拿着红色和蓝色药丸让你选择：红色代表真相，蓝色代表享受当下，你会如何选择？
