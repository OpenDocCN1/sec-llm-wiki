> https://lingwu111.github.io/端口敲门技术.html

找到了一篇文章，讲解了端口敲门的原理

简单的说，就是我们得依次访问 571、290、911 这三个端口，然后达成一个叩叩叩敲门的效果，然后防火墙就会来开门，把 22 端口向我们开放

```
for x in 571 290 911 ; do nmap -Pn --host-timeout 201 --max-retries 0 -p $x 10.10.10.43; done

```
