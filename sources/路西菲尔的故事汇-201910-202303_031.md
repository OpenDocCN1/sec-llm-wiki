## 漏洞利用

使用snmpwalk扫描一下pandora.htb

```

snmpwalk -v 2c pandora.htb -c public > nmap
```

```

```

得到了一个账号密码


```

┌──(root💀kali)-[~/Desktop]# ssh daniel@pandora.htb

```
