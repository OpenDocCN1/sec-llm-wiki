# 权限提升

```

notch@Blocky:~$ sudo -lfor
 notch: for
 notch on Blocky:local/sbin\:/usr/local

/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin
```

查看一下 sudo -l，我们的 NOTCH 账户拥有所有权限，那直接提权吧

```

notch@Blocky:~$ sudo su# whoami&&id


```

成功提权到 root 权限

```
root@Blocky:/home/notch# cat /root/root.txt 


```

成功拿到 root 权限的 flag 文件
