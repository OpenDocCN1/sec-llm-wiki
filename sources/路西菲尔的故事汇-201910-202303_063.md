## 权限提升

### User权限

```




zabbix@shibboleth:/$ cat /etc/passwd | grep bash
```

首先查看一下有bash权限的账户，有一个ipmi-svc，看来咱们必须得提权到它

我们需要登录到ipmi-svc账户，密码与网站后台密码是一样的

```


zabbix@shibboleth:/etc/zabbix$ su ipmi-svc
```

```
ipmi-svc@shibboleth:/tmp$ 
```

成功获得user权限的flag文件
