# 关于开展车联网安全攻防挑战赛试题编写征集活动的通知

根据习近平总书记关于“没有网络安全，就没有国家安全”及“安全是发展的前提”的重要指示精神，贯彻落实国家制造强国、网络强国建设战略和《中国制造2025》行动纲领，应对日益严峻的车联网信息安全形势，国家互联网应急中心长期致力于互联网安全的监测、应急和处置，提升车联网安全防护技术能力，并拟于2019年面向国内安全研究机构、高校、科研院所、汽车制造企业、汽车零部件供应商和网络安全厂商等。举办覆盖“云、管、端”多维风险点的专业性车联网安全攻防挑战赛。为确保比赛的公平公正，维持赛题的多样性、合理性和创新性，促进本次赛事迈向新台阶，拟建立车联网安全攻防挑战赛题库，现公开面向社会征集挑战赛试题。

**一、征集题目类型及要求**

本次活动征集赛题形式不限，可参照CTF夺旗赛形式，亦可是具有极大自由发挥空间的漏洞挖掘题型。

题目范围涵盖CAN总线、车机、TBOX、APP、TSP平台等方面，内容包括但不限于总线分析、网络通信分析、无线分析、APP应用分析、WEB应用分析、固件提取和逆向分析等。

**二、征集时间及规则**

*   **征集时间：**从公告发布之日起至2019年12月31日；
    
*   **征集规则：**赛题应为原创,此前未以任何形式发表,不得剽窃、抄袭、模仿或侵害第三方合法权益，如发生纠纷由应征者承担相关法律责任。应征者须对赛题本身及其解答严格履行保密义务。被采用赛题的全部知识产权归征集者独家所有,征集者有权对相关内容参数进行修改 。
    

**三、投稿方式**

应征者请以电子邮件方式进行投稿，应征赛题请发送至邮箱 lab@cert.org.cn，标题请采用“挑战赛试题+单位名称”格式，并于正文中添加作者信息基本信息（姓名、性别、年龄、职业、联系电话、电子邮箱）。我们将对应征赛题进行筛选、修改以及优化后选择性纳入车联网安全攻防挑战赛题库，并给予被采纳者相应奖励。
