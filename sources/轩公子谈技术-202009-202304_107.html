所以今天就来使用docker 安装kali系统 


安装docker的步骤直接略过，基础搭建或者深入学习看看下面的博客就可以了。

Docker 容器     （centos系统 教程 ）


#1  搜索kali的镜像

docker search kali

 

#2  拉取镜像 慢慢等待即可

docker pull  docker.io/booyaabes/kali-linux-full


#3  查看镜像是否下载成功

docker images


#4 启动kali  参数p 端口映射 下面操作会详细说明 

docker run -it -p81:81 3c201651c014

看到这个界面 就说明成功进来了


kali到手，不做点事情   是不是对不起自己半天的辛苦
