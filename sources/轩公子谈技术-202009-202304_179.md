## 创建5.6 和 8.0 的多实例

### 上传软件并解压、软连接

*   
*   

```
ln -s mysql-5.6.46-linux-glibc2.12-x86_64 mysql56ln -s mysql-8.0.18-linux-glibc2.12-x86_64 mysql80
```

‍  

如果是新的机器，下载操作可忽略（之前已经安装mysql服务）
