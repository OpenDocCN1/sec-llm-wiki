主要命令    spawn 新建一个进程  这个进程是由expect控制    send  发送字符串给expect控制的进程    set   设置变量   set user root    exp_continue 重新执行expect分支    set timeout -1 设置超时时间 永远等待    set timeout 10 设置超时时间 10秒    interact 将脚本的控制权交给用户,用户继续使用shell执行命令
