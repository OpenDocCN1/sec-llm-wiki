一、概述
对于高级自动驾驶汽车(AV)，定位是高度安全的，并且定位对于AV安全也是至关重要的，对它的一个直接威胁是GPS欺骗，但幸运的是，今天的AV系统主要使用多传感器融合(MSF)算法，这些算法通常被认为有可能实际上击败GPS欺骗。然而，在之前的工作还没有研究今天的MSF算法在GPS欺骗下是否确实足够安全，特别是在AV环境下。作者进行了第一个研究来填补这一关键的空白。作为第一项研究，该文关注一个具有设计和实现水平代表性的生产级MSF，并确定了两个AV特定的攻击目标——离开道路攻击和路线错误攻击（off-road and wrong-way attacks）。
 为了系统地理解AV系统中的MSF算法的安全特性，该文的作者首先分析了上限攻击（upper-bound attack）的有效性，发现了一种接管效应（take-over effect），这种接管效应甚至能够完全违背MSF算法的设计原则，在这种接管效应下，AV系统显现出它的脆弱性，使得攻击者在此时有机可乘，攻击者如果能利用好这种接管效应，便有可能实现理想的攻击目标。
 该文的作者对这种接管效应背后的原因进行了详细的研究和分析，然后发现这种接管效应的出现是随机和不确定的，利用这一见解，该文的作者设计出了一种新的通用攻击方法——FusionRipper,并在6个真实世界的传感器轨迹上对其进行了评估，发现FusionRipper在离开道路攻击和路线错误攻击的所有轨迹中分别能达到至少97%和91.3%的成功率。为了提高实用性，该文的作者进一步设计了一种离线方法，可以有效地识别两个攻击目标的平均成功率均超过80%的攻击参数，成本最多为半天。

二、背景
•自动驾驶定位和多传感器融合
  在现实高水平的自动驾驶(AD)系统设计中，定位模块是一个至关重要的模块，它需要基于传感器输入的位置来计算在地图上自动驾驶汽车的位置，它的输出会被用于众多模块，如感知模块用来探测障碍，规划模块用来做驾驶决策，控制模块用来执行决策；这种对自动驾驶中各种关键决策步骤的直接影响，使得定位输出需要被高度保护和定位输出的安全至关重要。
  为了确保安全正确驾驶，AD定位不仅需要以厘米级的精度定位在交通车道，而且在各种道路和天气条件下具有较高的鲁棒性。因此，基于多传感器融合(MSF)的设计已经成为学术界和工业界的主流，因为它可以融合来自多个独立定位传感器的结果，通常是GPS、IMU和激光雷达，从而产生整体更高精度和鲁棒性的结果，而在基于MSF的AD系统定位算法中，基于KF的MSF（KF-based MSF）在学术界和工业界的应用最为广泛。
•卡尔曼滤波（Kalman Filter）
  卡尔曼滤波（KF）是一种贝叶斯滤波器，它从传感器测量分布中计算出不确定度最低的最优状态分布，在AD定位的背景下，状态由车辆的位置、速度和姿态(PVA)及其不确定性（或协方差或方差矩阵）组成，具体来说，KF迭代地应用了两个步骤：预测和更新。
                                        
                                        
 def KF_calculation(F,H,Q,R,Z,P_0,X_hat_0):   #KF计算过程
    X_EST_set = []
    iters =len(Z)
    X_hat_pre = X_hat_0
    P_pre = P_0
    for k inrange(0,iters):
        #预测
        X_prior_hat = np.dot(F,X_hat_pre)
        P_prior = np.dot( np.dot(F,P_pre) ,np.transpose(F))+Q

        #矫正
        K = np.dot( np.dot(P_prior ,np.transpose(H) ) ,
                    np.linalg.inv(np.dot( np.dot( H,P_prior ) , np.transpose(H))
                        + R)
                    )
        X_hat = X_prior_hat + np.dot(K,
                                     (Z[k] - np.dot(H,X_prior_hat))
                                     )
        #更新
        P_pre = P_prior - np.dot(K,np.dot(H,P_prior))
        X_hat_pre = X_hat
        #存储结果
        X_EST_set.append(X_hat)
        # print(X_hat)
        pass
    pass
 
•离群值检测（Outlier Detection）
  为了防止KF状态很容易地被现实世界中噪声太大的偶然测量值所破坏，KF更新通常被一个离群值检测器所限制，卡方检验（Chi-squared test ）是KF中最广泛使用的离群值检测器之一，当卡方检验值大于统计显著性阈值（通常为3.841）时，它将测量值视为离群值。离群值测量可以丢弃或部分更新。
                                                


三、攻击模型和问题形式化
•攻击场景和攻击目标
  在该文中，针对的攻击场景是攻击车辆尾随受害者AV而启动GPS欺骗攻击，在这种场景中下，攻击目标是对受害者AV的定位输出引入较大的横向偏差，即向左或向右的偏差，由于所有车辆都需要在其指定的道路车道内行驶以获得安全保护，因此这种横向偏差可能会对道路安全构成直接威胁。
  特别地，该文考虑了针对AV环境的两个具体攻击目标：离开道路攻击和路线错误攻击，如图1所示，前者的目标是向左或向右行驶，直到受害人开车离开路面，而后者的目标是向左偏离，直到受害人在对面的车道上行驶。

•攻击者能力和自动驾驶控制设定
  在该文中，假设的攻击者可以启动GPS欺骗来传输与自然GPS信号相似的信号，控制受害GPS接收者的GPS定位，并且该攻击者还可以在现实世界中跟踪目标自动驾驶汽车的位置并且尾随它；还假设了自动驾驶系统被设计为保持行驶在道路中央，并且持续修正任何远离道路中央的偏差，这意味着，当攻击者引入一个对MSF输出的偏差时(例如，在图1中的右边)，受害自动驾驶汽车会积极纠正它，从而导致其物理世界位置有相同数量的偏差，但方向相反。

 对于这个结果，作者观察到，尽管很少的攻击能够达到理想的攻击效果，甚至大部分攻击造成的偏差都达不到所需最少的偏差距离，然而仍存在14%的攻击能够实现超过2米以上的偏差距离，这已经远远达到攻击目标了，因此作者对于这一部分攻击进行了详细的研究，发现这些攻击能够导致指数级增长的偏差，如图3所示，左边的曲线与右边扁平的曲线大大不同，作者在该文中把这种能引起偏差指数级增长的现象称为接管效应。

 为了分析接管效应的原因，作者首先通过一个简易但通用的模型（如图5所示）来进行理论分析和实验验证，确定可能的促成因素，然后使用相关分析来确定分析得到的促使接管效应产生的最重要因素，具体分析过程就不在这里详细叙述，最后的结果如表1所示，可以看见，参数和与接管效应的关系最大，参数是初始MSF状态不确定性，而参数是激光雷达传感器噪声，前者反映的是在攻击的开端对KF状态缺乏信心，后者反映的是在攻击窗口期间缺对基于激光雷达的定位算法缺乏信心，两者都是不可控的，它们来自于现实因素，如算法不准确和传感器噪声，所以在无噪声的仿真条件下观察才不到接管效应的出现。在现实中，即使在自动驾驶汽车中使用到的最先进的传感器，这些不准确和噪声已经足够大而且足够频繁，以至于能被GPS欺骗者来利用，从而做到击溃MSF。
六、利用接管效应设计新的攻击方法——FusionRipper
 在前面的工作基础上，作者进一步研究，利用对于接管效应的见解设计出了一种新的攻击方法——FusionRipper,这种攻击方法分为两个阶段：
•阶段一：脆弱性分析。在这个阶段，攻击者会保持持续的欺骗，并将设定为一个常量,攻击者在这一阶段会保持潜伏，等待受害者脆弱时期的出现，这一时期出现的标志表现为受害者车辆发生偏离的距离大于预设的阀值（文中设为0.295m）,当这一时期出现的时候，意味着攻击者可以进入下一阶段。
•阶段二:积极欺骗。在这一阶段，攻击者会对受害者车辆进行猛烈的攻击，欺骗的力度会加大，欺骗距离按照 指数级增长，其中指数基是在每个欺骗点上累积乘以之前的欺骗距离，是攻击欺骗输入的次序。

八、个人总结
 这篇论文对于基于多传感器融合的自动驾驶系统的全球定位的安全性进行了详尽的研究，发现了该系统的脆弱性，并寻找到了一种切实可行的攻击方法进行了实验，结果显示，这种攻击会使得受害自动驾驶汽车偏离正确的路线。这篇论文的研究成果表明现有的商业级自动驾驶汽车存在着比较大的安全隐患，需要对自动驾驶汽车的安全性进行更深入的改善。
