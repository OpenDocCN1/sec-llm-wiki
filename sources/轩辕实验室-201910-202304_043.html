一. 小波变换技术介绍

首先，加速度计和GPS接收器测量的时间序列是非平稳现象，这意味着它们不会随着时间的推移而重复。使用小波分析时间序列的优势在于，它们能够估计作为时间函数的频谱特征，虽然傅里叶变换可以用来研究时间序列的周期性，但时间信息丢失了。窗口傅里叶变换(WFT)是一种恢复一些时间依赖信息的尝试，但在选择最佳窗口长度时可能会出现复杂情况，这使得WFT难以为一般问题实现。此外，傅里叶变换仅限于由正弦和余弦定义的基，而理论上有无限的基可用于小波分析。


Anyway ，使用小波变换可以来做什么这是我们最想关心的，那么使用小波变换可以做什么呢？可以用来分析加速度计和GPS接收器测量的时间序列的频谱特征，可以分析这两个时间序列的频域和时域上的相似性，以这种相似性作为我们提取到的数据特征，用来支持欺骗检测。

二. 实验数据集

我们的实验使用了comma2k19数据集，这个数据记录了在加州280高速公路上通勤超过33小时，这指20公里路段上2019个路段，每个路段长1分钟加利福尼亚州圣何塞和圣荷西之间的高速公路弗朗西斯科，详细信息请参考文章：A Commute in Data: The comma2k19 Dataset.

三.实验过程

01.坐标系轴对齐

comma2k19数据集提供的GPS定位坐标系是ECEF坐标系，要将GPS测量的坐标转换到汽车车身坐标系，comma2k19数据集为我们提供了从ECEF坐标系转换到汽车车身坐标系的四元数，使用四元数可以直接计算。

# get speed by transform frame_velocities
euler_angles_ned_deg = (180/np.pi)*orient.ned_euler_from_ecef(frame_velocities[0], orient.euler_from_quat(frame_orientations))

04.欺骗检测

通过前面的小波相关性计算，我们可以看到在无欺骗和有欺骗条件下的小波相关性差异比较明显，这说明通过小波相关性来检测欺骗攻击具有可行性，对于具体如何利用小波相关性来进行欺骗检测，在  Uncoupled Accelerometer Based GNSS Spoof Detection for Automobiles using Statistic and Wavelet Based Tests 这篇论文中没有提到，但是我们觉得存在很多方法，其中最简单的一种是从统计学的思路出发，首先设置窗口，把一个窗口内的GPS和IMU产生的加速度时间序列进行小波相关性分析，得出一个窗口内小波相关性高于我们预设的阈值（wcoherence_threshold）的面积占总面积的比例，我们把这个占比姑且叫作相似度，同时这个阈值是一个参数，可以通过控制变量比较得出较优值，其次，通过预先收集到的数据来生成在无欺骗和有欺骗条件下的相似度，评估出一个最优的相似度阈值，使得在无欺骗条件下的相似度总高于这个阈值，在有欺骗条件下的相似度总低于这个阈值。
对于上面提到的这种基本检测方法，我们进行了实验，最后得出如下的结果，可以看到在无欺骗条件下的相似度与有欺骗条件下的相似度差异明显，中间那条橙色的线代表阈值，可以完好的分割开两条曲线。

三.接下的工作（未完待续。。。）

上一节最后的实验结果达到了比较理想的效果，但还需要进行更多的工作，来验证利用小波变换进行欺骗检测的正确性和可行性，我们接下来短期的目标和工作如下：
1.在comma2k19数据集上，利用小波变换尝试更多的欺骗检测方法，最重要的是寻找到一种能实际应用并且有效的方法；
2.在轴对齐方面我们还遗留了一个小问题，如果解决了这个问题那么可以使得IMU产生的加速度数据更加准确，这个问题就是如何完全消去重力加速度，我们当前只是在汽车坐标系中的向下方向简单地加上重力加速度；
3.在另一个数据集上面进行实验进行验证；
4.完成第1个工作后，我们要使用真实小车来收集我们自己的数据，进行实验，这是既去验证第1个工作提出的方法，又是去验证这个检测欺骗方法的在实际中的可应用性，同时也是由于我们在实验中，发现在处理数据这一步会难度较大，我们自己做实验收集数据可以帮助我们掌握如何处理好数据，为我们提供一个更加清晰的视角来看待我们正在处理的问题；
5.变换攻击方式后的检测效果。
