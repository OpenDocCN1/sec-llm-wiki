pytorch读取本地数据集并搭建简单的神经网络

Pytorch作为一个新的深度学习框架自2017年提出，便受到了深度学习爱好者的追捧，和知名的tensorflow以及keras等深度框架相比，pytorch的语法风格更Pythonic，其以面向对象的方式进行构建神经网络。近几年，pytorch在学术圈的欢迎度陡增，并有超越tensorflow之势。本文主要是通过使用pytorch进行读取本地的kdd入侵检测数据并进行相应的处理以及通过搭建简单的神经网络对其进行训练。

  

1． csv数据的读取和装载

对训练的数据集进行训练之前，需要装载数据集。Pytorch作为一个深度学习框架自带有很多数据集合，比如MINIST手写字数据集合。如果直接使用pytorch自带的数据集进行模型训练直接调用相应的模块即可，但是如果要是使用自己本地的数据集的话，在pytorch中装载数据集，需要进行编写自己的dataset类，其继承了Dataset类。该类的架构主要如下:

class DatasetFromCSV(Dataset):  
    def \_\_init\_\_(self):  
    def \_\_getitem\_\_(self):  
    def \_\_len\_\_(self):  
   该类主要需要实现三个方法，其中\_\_init\_\_魔法方法可以用来根据文件路径进行读取文件并做相应的数据处理，\_\_getitem\_\_魔法方法主要是用来返回训练的数据和数据的标签，\_\_len\_\_主要是返回当前数据集合的长度，满足训练的迭代功能。

下面以处理好的kdd入侵检测的CSV数据为例，实现训练数据的装载。Kdd的前五行数据集如下:

![](../Images/dc58b971b42268a8608182c272ff872a.png)

该数据集合有42个特征类，其中前41列是数据的特征列，最后一列是数据的标签列。装载该数据集的主要目的就是将前41列作为特征列装载进data中，最后一列装载进label中。

导入的库如下:

import numpy as np

import pandas as pd

import torch # 导入torch库  
import torch.nn.functional as F  # 激励函数的库  
import torchvision.transforms as transforms from torch.utils.data import Dataset, DataLoader # 方便数据的装载和加载  
from sklearn.preprocessing import MinMaxScaler #对numpy数据进行标准化

主要的代码如下:

class DatasetFromCSV(Dataset):  
    def \_\_init\_\_(self, csv\_path, transforms=None):  
        data = pd.read\_csv(csv\_path) # 读取csv数据  
        self.labels = data.iloc\[:, -1\] # 读取最后一列标签列，装载标签  
        data = data.iloc\[:, :-1\] # 读取数据列  
        data = np.array(data)  
        scaler = MinMaxScaler()  
        data = scaler.fit\_transform(data) # 对数据的每列进行标准化(映射到0\-1)  
        self.data = data # 装载数据  
        self.transforms = transforms  
  
    def \_\_getitem\_\_(self, index):  
        single\_data\_label = self.labels\[index\]  
        data\_as\_np = self.data\[index\]  
        data\_as\_tensor = torch.from\_numpy(data\_as\_np).float()  
        return (data\_as\_tensor, single\_data\_label)  
  
    def \_\_len\_\_(self):  
        return len(self.labels.index)

  

2． 多层感知机网络(MLP)

以多层感知机网络为例通过构建多个线性层搭建一个简单的神经网络。

首先查看该数据集合的特征列，共有41个特征，因此网络的输入结点应该有41个神经元结点，查看lable标签入侵攻击和正常的分类总共有23个，因此对于一个多分类的神经网络，其输出结点为23。

![](../Images/a2f7c7f3a912bc814f8ab5d6fe7ce077.png)

class MLP(torch.nn.Module):  # 继承 torch 的 Module  
    def \_\_init\_\_(self):  
        super(MLP, self).\_\_init\_\_()  #  
        # 初始化四层神经网络 三个全连接的隐藏层，一个输出层  
        self.fc1 = torch.nn.Linear(41, 512)  # 第一个隐含层  
        self.fc2 = torch.nn.Linear(512, 128)  # 第二个隐含层  
        self.fc3 = torch.nn.Linear(128, 64)  # 第二个隐含层  
        self.fc4 = torch.nn.Linear(64, 23)  # 输出层  
  
    def forward(self, din):  
        dout = F.relu(self.fc1(din))  # 使用 relu 激活函数  
        dout = F.relu(self.fc2(dout))  
        dout = F.relu(self.fc3(dout))  
        dout = F.softmax(self.fc4(dout), dim=1)  # 输出层使用 softmax 激活函数  
        return dout

总结:

1\. 加载自己的数据集合需要进行编写自己的dataset类，并实现相应的方法。

2\. 构建神经网络以面向对象的方式，这点和keras等略有不同。

3\. 多分类问题一般使用交叉熵损失函数，并且，交叉熵损失函数的对于原始的标签数据不需要进行one-hot处理，即原始输入直接就是类别值，其内部会自动处理。对于pytorch的CrossEntropyLoss交叉熵损失的输入x，y分别是未经过softmax的特征和未经one-hot的标签信息。也就是说CrossEntropyLoss交叉熵损失即会自动进行softmax处理，也对原始数据的标签进行onehot。对于交叉熵损失函数的参数顺序一般不可调换，第一个参数是模型输出，第二个参数是验证集原始数据标签。
