# 自动驾驶中基于信任评估的入侵检测与强化学习

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI1MTkwODMxMQ==&mid=2247483763&idx=1&sn=78e5058ee5ed356a667be6d4b918413a&chksm=e9ea98cbde9d11dd68b7ba7c5820094b212bf2d4e97fafc341767d10e74631e603d47c0480ca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzI1MTkwODMxMQ==&mid=2247483763&idx=1&sn=78e5058ee5ed356a667be6d4b918413a&chksm=e9ea98cbde9d11dd68b7ba7c5820094b212bf2d4e97fafc341767d10e74631e603d47c0480ca&scene=27#wechat_redirect)

伴随着自动驾驶汽车数量的增加，安全问题在自动驾驶车联网络中显得尤为重要。基于加密的一些安全系统虽然能够处理一些攻击，但是并不能解决来自自动驾驶车联网络中的妥协或者错误操作(如误发警报)的内部攻击。拥有高度自动性的车辆由于其自身配备的一些自动组件因此更容易受到一些内部的攻击。基于信任的入侵检测系统能够有效地减轻内部攻击的威胁。在智能化的车联网络中一辆自驾车在发现某一事故或者是攻击之后可以通过信息共享，以协作地方式构建一个智能网联入侵检测系统。

  

自动驾驶汽车 (autonomous  driving  vehicles) 作为一个物理信息系统 (cyber physical system )，其具备很多功能，比如自动控制、信息收集、缓存处理、自动通信等。一些自动驾驶厂商比如通用汽车(General Motors)、丰田(Toyota)、谷歌(Google), 以及大众(Volkswa-gen)等都已经宣称第一代自动驾驶汽车将于2020年发布，预计到2035年自动驾驶汽车将会占路上车辆的25%。在没有人类的干预下，一辆配备多种车载传感器与雷达的自动驾驶汽车作为一个智能设备能够收集周围环境的信息并做出安全正确的决策。然而，随着目前交通环境的迅速变化，一辆自驾车不能及时而准确地探测到路边环境的一些异常状况，比如在天气比较差的情况下车载摄像头或者传感器可能会因工作异常而做出一些错误的操作，从而引发一些紧急事故的发生。因此多辆自动驾驶汽车应当能够联系起来使得当某一辆车辆工作异常时，一些关键的路况信息仍然可以被捕捉。多辆自动驾驶汽车能够通过连接从而构建智能的自动驾驶车联网络。

  

安全和隐私在自动驾驶汽车中起着至关重要的作用，因为任何攻击都可能导致重大损失。作为一个物理信息系统，自动驾驶汽车面临许多漏洞和潜在的网络攻击。尽管常规密码系统可以帮助应对某些攻击，但它们无法消除所有攻击。例如，合法的自动驾驶汽车可能会遭到破坏，并发送虚假信息（例如虚假警告）以破坏自动驾驶汽车的正常运行。此外，带有故障组件的合法自动驾驶汽车也可能传播错误的信息。由于车载有各种自动化组件，它们是攻击者的目标，因此高度自动化级别的自动驾驶汽车更容易受到攻击。例如，摄像头(盲目)和全球定位系统欺骗/干扰是自动驾驶网联车的两大威胁。高亮度红外激光或红外发光在道路上很容易被部署，但其也很容易使摄像机失灵。实施全球定位系统干扰攻击也很容易，这可能会干扰和错误引导自驾车的决策判断。

因此，除了传统的密码系统外，自动驾驶汽车中还需要一种智能的入侵检测机制，以识别一些自动驾驶车辆的异常行为并降低其对其他车辆的影响。但是，设计入侵检测机制存在很多挑战。

  

**入侵检测目前面临的挑战**  

1.  自动驾驶车辆之间的低效率通信
    

当一辆车辆捕捉到攻击或者事故的时候，其他的车辆应该能够及时地接收到该警告，然而当两辆车辆距离比较远的时候，两辆汽车的通信应当通过路边单元RSU作为媒介进行通信

   2. 缺乏可信的警告探测机制

自动驾驶汽车可能无法区分所有异常现象以做出安全性适当的决定。因此，应为车辆建立可信赖的警告检测框架，以保证车辆的行驶安全。

   3. 缺乏合适的激励机制

在传统的车辆网络中，总是鼓励车辆通过执行分布在网络中的分配任务来提高其信任值。这些机制依赖于驾驶员的独立意识，这不适用于自动驾驶汽车。

  

本文提出了一种基于信任评估和强化学习的自主异构车辆网络中入侵检测新框架。首先建立信任模型，其中RSU在远程云服务器的帮助下集成了有关自动驾驶汽车(ADV)的所有信任评估信息，建立信任评估不仅基于RSU覆盖范围内收集的信息，还基于来自不同RSU的信息。接下来，为自动驾驶车辆建立一个两级入侵检测框架。此外，本系统还建立了基于强化学习的激励机制，以激励自动驾驶车辆协同发出警告。

**一. 信任评估模型**  

针对一辆自驾车的多方评估结果被用来聚合产生该自驾车的信任值。以下将自动驾驶汽车称作ADV(autonomous driving vehicle)。具体过程如下: 每个ADV在与ADV[v]进行交互之后都会评估其信任值。 令S =（1, …, s, ..., S）表示评估ADV[v]的信任值的ADVs(autonomous driving vehicles)集合。集合S中的ADV[s]将向最近的RSU报告ADV[v]的信任信息。 但是，由于RSU无法完全验证此类信任信息，因此也应考虑ADVs的信任值。 因此，由ADVs发送的信任信息包应包括以下信息：RSU用于计算此信息的可靠性的ADV[s]的ID和由ADVs评估的ADV[v]的信任值。然后，RSU相互交换S组中ADV[s]发送的信任信息。 （E[1,][v,]E[2,][v,]…,E[s,v]）表示集合S中ADV[s]所形成的信任值集合，它由ADV的信任值E[v]（0 <E[v] <1）组成。

**二. 双层(two-level)入侵检测框架**  

      一个事故或者是攻击的警告的真实性不仅建立在一个RSU之内的多辆车的共同评估，还建立在多个RSU通过云服务器进行信息交换与评估。该双层评估共同构建一个可信的入侵检测框架。

      在第一级中，如上图所示，RSU[r]覆盖范围内的ADV分为两种类型：I =（1, …, i, …I）表示向RSU[r]报告警告a的ADV集合。 J =（1, …, j, …J）表示不报告警告的ADV集合。 在上述信任评估模型中，集合I和J中ADV的信任值（由E[I]和E[J]表示）将用于计算RSU[r]覆盖范围内的警告a的信任度，由G[r,][a]表示。  

     在第二级中，如下图所示，为了进一步增强安全性，一种RSU之间警告a的信任评估机制被提出。 N =（1,…,n,…,N）表示在第一级中接收警告a的RSU集合（包括RSU[r]）。集合N中的每个RSU与RSU[r]交换第一级警告a的信任值。 然后，RSU[r]通过考虑以下信息来计算第二级警告a的信任值，用L[r][，a]表示：集合N中警告a的第一级信任值，用（G[1,][a，]…, G[n,][a, ]…G[N,][a]），以及RSU[r]和其他RSU之间先前警告的检测结果的相似性，表示为（Z[r][，1,]…,Z[r][，n,]…Z[r][，N]）。根据以上分析，由RSU[r]评估的警告a的可信度为：T[r,][a] = a \* G[r,][a] + b \* L[r,][a]，其中a和b为调整因子，a + b = 1。 我们将T[r,][a]与预定阈值T[r,][s]进行比较。 如果T[r,][a]\> T [r,][s]，则RSU[r]成功检测到警告。 最后，RSU[r]向网络广播警告。

**三. 基于强化学习的激励机制**  

       一个基于强化学习(Q-Learning)的激励机制去激励网联自驾车去报告发生的事故或者攻击。ADV可能不愿意将有关警告的完整信息发送给RSU(例如，出于隐私考虑)。现将警告报告的完整性量化为L级。ADV[v]可以选择在时隙t上报告警告a的级别，表示为l^t[v,a ]\[0,L\]，其中l^t[v,a]是整数，t 属于{1,2,…,T}。l^t[v,a]越大，ADV[v]的隐私就越容易泄露。从RSU的角度来看，刺激ADV发送更高级别的警告可以提高系统性能。为此，当接收到来自RSU的警告时，RSU将通过增加其信任值来对其进行奖励，这可以积极影响ADV在车辆网络中消费服务时的优先级。RSU[r]给ADV[v]的奖励用P[r,v(]l^t[v,a)]表示，它与l^t[v,a]正相关，而与RSU[r]收到的有关警告a的报告数量成负相关。根据以上分析，ADV可以选择级别l^t[v,a]实现ADV的最佳效用，利用强化学习，可以帮助选择最佳决策。设计一个基于强化学习的激励机制在每一个时间片去训练自驾车的行为。在强化学习中，Q函数作为一个行为效用(action-utility)函数可以被用来评估在某一个状态下，车辆采取的某一种行为的表现如何。定义Q(e[v,]l^t[v,][a])表示预期的Q函数。e[v]是\[0，9\]中的整数，表示ADV[v]的信任值级别；例如，e[v] = 0表示E[v]\[0，0.1\]，而e[v] = 9表示E[v 属于 ]\[0.9，1\]。
