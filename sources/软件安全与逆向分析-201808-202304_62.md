# Android网络共享神器推荐

网络共享是一个老生长谈的话题。在还没有全智能的塞班手机的时代，就有共享手机modem拨号上网的玩法，后来Android手机的流行，在1.6版本时代，就兴起了「**mobile tethering**」（手机网络共享）的热潮。

今天要给大家推荐的是「**反向网络共享**」（reverse tethering）用到的工具。啥叫“反向网络共享”？通过手机设备给PC或其他设备共享网络叫手机网络共享，反过来，通过PC给手机设备共享网络就叫**反向网络共享**。这个时候，有人会说360与小米WIFI发射器，当然，你要用这些硬方法就当我没说，今天要讲的是如何“软”着陆，完成手机共享上网。

今天推荐的神器-`Gnirehtet`，这个东西是`Genymobile`公司开发并开源的一个产品。该公司就是大名鼎鼎的`Genymotion`模拟器的东家，除了开发的`Genymotion`模拟器产品外，它们还会时不时的放出一个开源的神器，`Gnirehtet`就是其中一个。

看看怎么用。首先，它的项目地址是：https://github.com/Genymobile/gnirehtet。可以自己下载代码编译，或者到Release页面下载发布的版本。

`Gnirehtet`分为Java与Rust两个语言编写的版本，Rust编译的打包成了二进制更方便操作。这个神器支持多个平台，这里以macOS为例，下载gnirehtet-rust-macos64-v2.2.1.zip文件并解压。

然后在使用USB线连上电脑与手机，**并保证`adb`可以正常通信PC与手机，即手机要在开发者选项中开启USB调试**。确定好后，执行如下命令即可：

```
$ ./gnirehtet run
```
