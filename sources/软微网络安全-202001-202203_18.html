21. Shop


题目描述


  • 用少于100的金额购物成功

  • 题目合约代码如下：

 1pragma solidity ^0.6.0;
 2
 3interface Buyer {
 4  function price() external view returns (uint);
 5}
 6
 7contract Shop {
 8  uint public price = 100;
 9  bool public isSold;
10
11  function buy() public {
12    Buyer _buyer = Buyer(msg.sender);
13
14    if (_buyer.price.gas(3300)() >= price && !isSold) {
15      isSold = true;
16      price = _buyer.price.gas(3300)();
17    }
18  }
19}



解题步骤

需注意的一点是，只能使用少于3300的gas，如果要利用 storage 直接修改price值的话，修改变量就需要 5000 gas。

换一个思路，因为题目提供了Buyer接口，所以我们可以在实现price()函数的时候，利用 isSold值进行判定，isSold为false的时候，返回大于等于 100 的值；isSold为true的时候，返回小于 100 的值即可。

  1. 部署新合约，实现price函数两次返回不同的值

  2. 调用题目合约的buy函数即可



解题代码
