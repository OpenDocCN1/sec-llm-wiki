14. Gatekeeper Two


题目描述


  • 通过gateOne、gateTwo、gateThree三个条件限制

  • 题目合约代码如下：

 1pragma solidity ^0.6.0;
 2
 3contract GatekeeperTwo {
 4
 5  address public entrant;
 6
 7  modifier gateOne() {
 8    require(msg.sender != tx.origin);
 9    _;
10  }
11
12  modifier gateTwo() {
13    uint x;
14    assembly { x := extcodesize(caller()) }
15    require(x == 0);
16    _;
17  }
18
19  modifier gateThree(bytes8 _gateKey) {
20    require(uint64(bytes8(keccak256(abi.encodePacked(msg.sender)))) ^ uint64(_gateKey) == uint64(0) - 1);
21    _;
22  }
23
24  function enter(bytes8 _gateKey) public gateOne gateTwo gateThree(_gateKey) returns (bool) {
25    entrant = tx.origin;
26    return true;
27  }
28}



解题步骤


gateOne如前所述，只需部署一个新合约做跳板即可

gateTwo是本题重点， 使用了内联汇编，其中

  • caller : 获取调用者地址

  • extcodesize : 获取指定地址合约代码大小

意思为：要使调用合约的代码区大小为零。

突破点是在extcodesize ，因为如果你的函数依赖于调用extcodesize，你可以让另一个合约从他们的构造函数中调用这个函数，在部署攻击合约并调用构造函数时，该阶段的合约地址仍然没有附加任何字节码，因此extcodesize将返回0。

故我们只需在新部署合约的构造函数中，调用题目合约中的 enter()函数即可

gateThree 中^符号是位逻辑运算符里的按位异或，只有在两个比较的位不同时结果是1，否则为0。因此，直接异或逆运算_gateKey =bytes8((uint64(0) - 1) ^ uint64(bytes8(keccak256(abi.encodePacked(this)))))即可。

  1. 编写新合约，攻击步骤写在构造函数中

  2. 部署该合约，创建时输入题目合约地址即可通关
