13. Gatekeeper One

题目描述


  • 通过gateOne、gateTwo、gateThree三个条件限制

  • 题目合约代码如下：

     1pragma solidity ^0.6.0;
     2
     3import '@openzeppelin/contracts/math/SafeMath.sol';
     4
     5contract GatekeeperOne {
     6
     7  using SafeMath for uint256;
     8  address public entrant;
     9
    10  modifier gateOne() {
    11    require(msg.sender != tx.origin);
    12    _;
    13  }
    14
    15  modifier gateTwo() {
    16    require(gasleft().mod(8191) == 0);
    17    _;
    18  }
    19
    20  modifier gateThree(bytes8 _gateKey) {
    21      require(uint32(uint64(_gateKey)) == uint16(uint64(_gateKey)), "GatekeeperOne: invalid gateThree part one");
    22      require(uint32(uint64(_gateKey)) != uint64(_gateKey), "GatekeeperOne: invalid gateThree part two");
    23      require(uint32(uint64(_gateKey)) == uint16(tx.origin), "GatekeeperOne: invalid gateThree part three");
    24    _;
    25  }
    26
    27  function enter(bytes8 _gateKey) public gateOne gateTwo gateThree(_gateKey) returns (bool) {
    28    entrant = tx.origin;
    29    return true;
    30  }
    31}



解题步骤

  • 知识点一：

    gateOne如前所述，只需部署一个新合约做跳板即可

  • 知识点二：

    gateTwo是本题难点， 需要满足 msg.gas % 8191 == 0。个人建议的方式是：

    经过查看，本人的gas消耗值是254，故调用时传入的gas数为8191的倍数+254。

  1. 可以先执行一次攻击函数（即使失败也没关系）

  2. 然后在Etherscan上打开交易明细，点击Geth Debug Trace进入

  3. 在Gas栏中检索GAS操作码

  4. 计算调用题目合约函数前（进入 enter前）与GAS之间的差值，加上 gas 本身消耗的2即可

  • 知识点三：

    与上一题相反，无符号整数之间的转化中：

    uint32 a = 0x12345678;
    uint16 b = uint16(a); // b = 0x5678
    uint16 a = 0x1234;
    uint32 b = uint32(a); // b = 0x00001234
    bytes2 a = 0x1234;
    uint32 b = uint16(a); // b = 0x00001234
    uint32 c = uint32(bytes4(a)); // c = 0x12340000
    uint8 d = uint8(uint16(a)); // d = 0x34
    uint8 e = uint8(bytes1(a)); // e = 0x12

    因此，为满足gateThree ，只需将 tx.origin 倒数三四字节清零 ，同时确保高位地址非全0即可

    • 额外补充一点，只有当字节类型和int类型大小相同时，才可以进行转换。

    • 转换成更小的类型，会丢失高位。例如

  • 知识点四：

    • 与运算/AND（操作符为"&"）：两个变量中都是1的位，其与计算/AND结果位才是1，否则都是0。

    • 或运算/OR（操作符为"|"）:在计算或操作结果的某一位时，只要任何一个输入变量的对应位是1， 那么结果都是1。

    • 异或运算/XOR（操作符为"^"）:在计算异或运算结果的某一位时，只有当两个输入变量的对应位不一致时，结果才是1。

    1. 部署新合约，创建时输入题目合约的地址

    2. 调用新合约的攻击函数即可通关

    27}

    29contract MyAgent {
