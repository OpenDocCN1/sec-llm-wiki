**解题步骤**

> *   知识点一：
>     
>      突破点与第8题一样，区块链上的所有信息是公开的，可以用 `web3` 的 `getStorageAt` 来访问合约里变量的值
>     
>     `await web3.eth.getStorageAt(instance,0)`可访问变量locked值（布尔类型占一个字节，但因为紧随其后是uint256（32个字节），单独占一个插槽，故此处的locked值也只能单独占一个插槽）
>     
>     `await web3.eth.getStorageAt(instance,1)`可访问变量ID值（uint256）
>     
>     `await web3.eth.getStorageAt(instance,2)`可访问变量flattening（uint8） 、denomination （uint8）、awkwardness（uint16） 值
>     
>     `await web3.eth.getStorageAt(instance,3)`可访问变量data数组的第1个值
>     
>     `await web3.eth.getStorageAt(instance,4)`可访问变量data数组的第2个值
>     
>     `await web3.eth.getStorageAt(instance,5)`可访问变量data数组的第3个值
>     
> 
> *   `uint8 private flattening = 10` 占 `1` 字节 -> `0a`
>     
> *   `uint8 private denomination = 255` 占 `1` 字节 -> `ff`
>     
> *   `uint16 private awkwardness = uint16(now)` 占 `2` 字节 -> (根据时间改变)
>     
> 
> *   知识点二：
>     
>      固定大小字节数组可以通过 bytes1, bytes2, bytes3, …, bytes32来进行声明。
>     
> 
> *   byte即byte1。
>     
> *   bytes1只能存储一个字节，也就是二进制8位的内容。
>     
> *   bytes2只能存储两个字节，也就是二进制16位的内容。
>     
> *   bytes3只能存储三个字节，也就是二进制24位的内容。
>     
>     ……
>     
> *   bytes32能存储三十二个字节，也就是二进制32 \* 8 = 256 位的内容。
>     
> 
> *   知识点三：
>     
>     ```
>     bytes2 a = 0x1234;
>     bytes1 b = bytes1(a); // b = 0x12
>     ```
>     
>     ```
>     bytes2 a = 0x1234;
>     bytes4 b = bytes4(a); // b = 0x12340000
>     ```
>     
>

>
