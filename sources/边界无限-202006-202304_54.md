# 入选数世咨询“专精特新”百强 边界无限RASP备受青睐

6月18日，国内数字化产业第三方调研与咨询机构数世咨询正式发布《2022年中国数字安全百强报告》（以下简称百强报告）。北京边界无限科技有限公司凭借其在RASP领域的创新表现，成功入选**“专精特新”百强企业**，意味着边界无限在应用安全技术领域的创新能力再获肯定。

  

►►►

**创新能力与市场能力并重**  

  
本次，百强报告调研了国内700余家经营网络安全业务的企业，基于2021年度的上百项评价指标结合多种角度、不同维度的企业相关数据进行梳理和评价。其中“专精特新”百强企业的推荐，目的在于突出业务规模目前较小，但在网络安全技术创新能力方面表现优秀的企业。本次大会还发布了“数字安全百强”，通过品牌影响力和企业规模二大维度，以数轴点阵图的形式予以展现。报告吸取了国家监管部门、业内资深专家和广大安全厂商的建议，聚焦国内安全厂商的技术创新力和市场执行力，遴选出真正优秀的安全企业。此外，数世咨询作为相关机构与部门的研究支撑单位，百强报告中的内容将成为网络安全领域的监管与政策扶持、产业与市场研究的重要参考资料。  
![](../Images/576801c9b9ee396ae61ebdd0fb2e25dc.png)  
数世咨询创始人李少鹏曾说，“在计算机安全、信息安全、网络空间安全之后，是数字安全时代的来临……安全不再割裂，所有的安全问题都可归结于数字安全问题。” 在发布了多年的网络安全百强之后，数世咨询核心团队作为 “网络安全三元论“的首创者，和数字安全时代的首倡者，首次发布“数字安全百强报告”，数字安全的概念已经开始得到业内共识。  

►►►

**“免疫血清”RASP开始发力**  

  
网络安全一直是信息世界的主旋律，确保应用系统安全又是重要的一环。作为运行时安全技术的典型代表，RASP有着天然的优势，是云原生时代加强应用安全防护的更优解决方案，甚至可能带来颠覆性的影响。在应用安全的构建中，RASP技术弥补了传统防御工具、手段的缺失，以探针的形式，将保护引擎注入到应用服务中，就像“免疫血清”一样，随应用程序在本地、云、虚拟环境或容器中进行部署，为应用程序提供安全特性。这种特性使RASP掌握了内部所有动作的“上下文联系”，而不只是“入口流量”。这样可以构建应用安全程序的深度防御体系，尤其是在面临未知漏洞的前提下，也将是较优的选择，弥补了当前市场在产品应用层的空白。  
基于自主研发的技术和丰富的实战经验，边界无限成功推出了靖云甲·RASP全栈式云安全防护平台。靖云甲·RASP是针对应用运行时安全防护的颠覆性解决方案，更是边界无限打造云原生应用整体防护平台的起点和战略支点，为云时代应用安全提供实时保障。通过对请求调用的关键函数进监听，结合应用上下文情景分析能力和强大的AI攻击检测引擎，可捕捉并拦截各种绕过流量检测的威胁攻击，来应对无处不在的应用漏洞与网络威胁，从而为应用程序提供全生命周期的动态安全保护。  
靖云甲·RASP主要由微探针(Agent)、AI攻击检测引擎、管理平台三部分构成，来提供灵活的、稳定的、精准的核心能力支持。它通过将Agent注入到应用中间件，对被保护应用程序的访问请求进行持续监控和分析，使得应用程序在遭受攻击时，能够实现自我防御。同时，靖云甲·RASP产品体系采用模块化的组织形式，实现了各核心功能的智能集成和协同联动。  

►►►

**“灵动智御”开拓应用安全新时代**  

  
边界无限成立于2019年，作为RASP、云原生安全、应用安全“灵动智御”理念创领者，目前已获得天使轮融资超千万元，在云原生应用安全与应用运行时安全（RASP）市场备受认可。截至目前，边界无限已与政府、金融、能源、云服务厂商、电商、互联网等领域数十家客户达成业务合作，为其构建稳定、高效的安全防护。  
今后，边界无限将继续从应用切入，以RASP技术作为突破点，在API安全、容器安全、数据安全等领域开拓创新，持续提升优化产品及服务，完善产品体系及行业解决方案，紧密跟随国际、国内技术发展趋势和市场需求，以更加优秀的安全成果和丰富的攻防实战经验为安全服务领域贡献力量，发挥“专精特新”百强企业的影响力，坚实履行安全行业的社会责任，为我国网络安全事业添砖加瓦。
