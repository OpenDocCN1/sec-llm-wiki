前言:今天在整理屋子的时候发现一台尘封已久的韭讯K2，上次经过我魔改之后就一直躺在房间的角落，当我再次看到它的时候不经想起了伤心往事，于是我准备把它刷了。

1.刷openwrt固件

为什么要选择openwrt呢？

首先别人封装好的固件，大家懂得，多少用得有点不放心。

其次openwrt的扩展性兼容都还行。

https://downloads.openwrt.org/releases/19.07.7/targets/x86/64/openwrt-19.07.7-x86-64-generic-rootfs.tar.gz

1.1进入breed页面(首先你得之前有刷)

长按韭讯K2的菊花（重置键），拔插电源，静待重启。通过页面进入breed界面。

1.2.上传固件

别问我为什么我可以传大于15M的固件，也别问我后面我的韭讯K2为什么有硬盘，问就是自己接的，静待升级后。通过ssh登陆openwrt，初始地址为192.168.1.1。


1.3.配通网络

vi /etc/config/network

默认地址为static，192.168.1.1。根据自身情况配置可用静态IP或者DHCP。


2.openwrt扩容

本身openwrt的软件空间只有25M左右，背后想扩展一些东西，完全就不够用呀。

首先更新软件包源。

opkg update

然后下载扩展需要用到的软件

opkg install cfdiskopkg install block-mount

通过cfdisk把剩余空间全部全部格式化并新建分区/dev/sda3（做的时候忘记截图了，偷个网图）

new→write→yse

格式化后重启：

mkfs.ext4 /dev/sda3reboot

通过web页面，找到system下的挂载，不熟悉英文的黑粉们可以先下载个中文包

opkg install luci-18n-base-zh-cn

选中挂载之后，选中新分区，设置为外部overlay使用。

然后reboot，再次重启后你就会发现，软件包的剩余空间就有好多好多，可以存贼多种子。

3.抓包

当小姐姐接入你的WIFI的时候，你就可以通过路由器抓包了。最简单的装一个tcpdump。这样你就可以知道，小姐姐们喜欢逛什么网站，有什么爱好，有什么秘密。让她们爱上你，崇拜你，对你欲罢不能。

opkg install tcpdump


具体抓包命令就不说了，实在不会物理手段挂硬盘，可以尝试通过内网SMB，之后把抓包数据也存在SMB共享里也行。
