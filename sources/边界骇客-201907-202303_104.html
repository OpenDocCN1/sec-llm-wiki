安全运营岗位JD
岗位名称：安全工程师

岗位职责
1. 日常值班负责集团安全告警运营工作；
2. 参与安全事件分析、溯源、应急响应工作；
3. 根据规则，协助集团安全基线监控、入侵检测监控的编写工作；

岗位要求
1. 熟悉常见的攻击手法和基本的渗透思路；
2. 熟悉系统日志，可对各类日志进行分析、溯源，能进行入侵事件的调查及取证工作；
3. 熟悉 Python/Golang 至少一门语言，可以编写常用脚本；
4. 有应急响应经验；
5. 吃苦耐劳，抗压能力强；

加分项
1. 有内网渗透经验者优先；
2. 有标准化安全运营经验者优先；

基础安全岗位JD

高级/资深安全工程师（反入侵方向）
岗位职责：
  1. 负责日常安全事件的发现、分析、应急响应；
  2. 负责日常漏洞分析、渗透分析和入侵检测，及时发现安全隐患并制定相关入侵检测规则；
  3. 深入网络入侵行为的方法的研究和跟进，强化公司对于最新威胁的安全防御；

岗位要求：
  1. 相关安全工作经验，对安全攻防有深入理解；了解常见漏洞原理，攻击手段和检测方法；
  2. 具备网络攻防及应急响应的经验，具备较强的数据分析能力；
  3. 熟悉入侵检测相关知识，有入侵检测规则制定经验者优先；
  4. 熟悉 Linux、Windows 或者 macOS 系统，了解系统相关原理和基础知识；
  5. 有一定的安全事件应急响应经验；
  6. 有一定编程能力，熟悉一门以上常用语言（Pyhton/Go/Scala/Java），可辅助日常工作；

安全测试岗位JD

岗位名称：安全工程师
岗位职责：
1. 负责上线安全测试、例行安全检查、渗透测试工作；
2. 负责优化应急响应流程和突发事件的应急响应；
3. 负责最新安全漏洞研究、跟进工作。
岗位要求：
1. 熟练掌握常见 web、系统安全漏洞原理、利用方式以及对解决方案有较深入理解；
2. 精通 web 攻击方法，能独立研究发现新的漏洞；
3. 熟悉脚本语言，可以将重复性的工作转换成自动或半自动化脚本实现；
4. 对工作有热情，耐心、责任心强，具备沟通能力和团队意识。
5. 熟悉或了解一门编程语言。
6. 有SRC排名

业务安全方向JD

岗位名称：安全工程师

1. 有常见的黑灰产对抗经验；
2. 具备基本的代码能力，熟悉 Python/SQL/Scala 语言；
3. 具有优秀的团队合作和沟通协作能力，善于学习，能承受较大的工作压力；
4. 参与过有关风控系统设计、风控规则制定和优化者优先；
