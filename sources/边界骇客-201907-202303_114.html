1.SMBV3协议新增

之前文章以抓包的形式分析过SMBV1+SMBV2。这里不不累赘了，直接说SMBV3吧。SMBV3区别于V2，为了提高性能新增了以下特性：


Windows 8和Windows Server 2012引入了SMB 3.0（以前称为SMB 2.2）。带来了几项重大更改，旨在增加功能并改善SMB2性能，在虚拟化数据中心中尤为如此：

SMB直接协议（通过远程直接内存访问 [RDMA]的SMB ）SMB多通道（每个SMB会话多个连接）SMB透明故障转移它还引入了一些安全性增强功能，例如端到端加密和新的基于AES的签名算法。

其他都很好理解，其中什么是RDMA呢？


1.1Remote direct memory access（远程内存访问）

RDMA通过使网络适配器能够将数据从线路直接传输到应用程序内存或从应用程序内存直接传输到线路，从而支持零拷贝联网，而无需在应用程序内存和操作系统中的数据缓冲区之间复制数据。这样的传输不需要CPU，缓存或上下文切换器完成任何工作，并且传输与其他系统操作并行进行。这减少了消息传输中的延迟。

简而言之，直接内存到网络，无需CPU，快的一批。


2.CVE-2020-0796漏洞分析

SMB 3.1.1协议中处理压缩消息时，对其中数据没有经过安全检查，直接使用会引发缓冲区溢出，可能被攻击者利用远程执行任意代码。


SMBV3在通信过程中默认启动压缩/解压缩机制。如下图所示，攻击者在SMB压缩转换包的协议头中对OriginalSize值可控，这样OriginalSize以一个极大的值，写入固定的缓冲区中，造成缓冲区溢出。精心构造后可执行恶意命令。也就是压缩时所申请的内存大小小于解压后的大小，造成缓冲区溢出。详情可以浏览：
