**Part 1 学妹的求助**  

    学妹微信联系我，说她写真照莫名出现在某征婚站上。感觉电脑鼠标有时会自己会动。What什么鬼，鼠标自己会动？难不成见我家学妹太漂亮了？

![](../Images/b6f0aca3bd6f1f32df32fa368dc681f7.png)

    见学妹如此描述，八成是真中毒了，于是要求远程过去看一下。  

**Part 2 远程查因**  

    QQ远程上去后就开始了我的查因之旅，因为顾着查因了都没顾上截图，下面就大致将查因过程简述一下：

   1、查看计划任务，发现了端倪。触发器为：Regsvr32 C:\\ProgramData\\xxxx.dll。programdata目录真是木马的温床啊！大致断定这是木马持久化方式了。  

    2、同时在该目录下还发现了一个file.rar压缩包，创建时间为2019年11月21号晚上9点13分。打开一看我的乖乖都是学妹的写真照及一堆的word、excel文档。  

    3、赶紧结束木马进程，删除计划任务，清理programdata目录文件。  

    4、为保证没有任何遗漏，下载了个PCHunter认真看了一下各个进程，未发现其他异常。

    5、利用cmd 查看2019年11月21日前学妹电脑创建的目录。

*   
*   

```
命令：dir /s | findstr "2019/11/21"命令：dir /s | findstr "2019/11/20"
```

     6、查找结果有点多，所以懒得去分析，直接语音学妹询问其该时间前有没操作过不寻常的操作。比如：安装软件、访问的网页异常提示或者打开不明的文档......

     7、最后学妹告知，因其接了份家教兼职，想录制点教学视频供学生学习使用。所以在网上下了某视频录制程序的绿色版！

    8、查找那个软件，运行了一下。程序正常运行，但计划任务被添加了，C:\\ProgramData也有多出来一个xxxx.dll

     9、再次清理进程、计划任务和木马dll文件。并将软件拷贝了一份。

**Part 4 攻击手法分析**

    此手法为典型的利用dll劫持，配合社会工程学实现种马的操作。利用dll劫持实现种马，这是什么操作？？  

    dll劫持常用的是缺省dll，所谓缺省dll指程序运行过程中那些找不到的dll，也叫缺失的dll。那么我们只需要将恶意dll的名字换成缺省dll的名字并放在对应目录，当程序一运行恶意dll也将会被执行。【注：此方法也可以用于windows提权】 

    以劫持strtool.exe工具为例子：  

    1、利用Procmon.exe监听某进程strtool.exe

```

```

    2、设置过滤只查看缺省dll  

*   
*   

```
过滤规则1：path ends with .dll过滤规则2：result contains NOT FOUND
```

    3、通过创建规则过滤出缺省的dll，修改恶意dll（以弹出计算器为例）名为缺省dll名并拷贝到对应目录  

    4、重新打开strtool.exe，成功加载恶意dll并弹出计算器

**Part 5 总结**

    1、下载软件最好到官网下载，不要轻易使用绿色版软件  

    2、他人给的软件使用需谨慎  

    3、实际运用中dll劫持寻找的缺省dll最好不要影响程序功能，或者自己编写dll衔接整个程序。
