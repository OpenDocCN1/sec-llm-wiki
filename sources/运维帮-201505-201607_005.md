# 国外大牛为什么要参加这个在中国首办的技术大会？

全球技术咨询公司Gartner曾在报告中指出，应用性能管理APM（Application PerformanceManagement）市场在近几年增长迅速，2014年达到26亿美元(其中69%来自魔力象限里的15家厂商)。更不可思议的是，APM市场从2011到2014之间的复合年增长率是12.3%，超过广义IT运维管理市场(ITOM)总和两倍之多，使APM成为ITOM增长最快的部分。预计到2020年，将有60%的APM方案买家来自非IT企业，而目前这一比例仅为不足35%，未来不可限量，据统计，营业额超过20亿美元的传统大型企业中，有70%在一定程度上使用了APM，每个行业使用程度不同。

  

![](../Images/bd37874f2c6243a15b05b0d70cac1dc3.png)  

  

**传统全球APM格局被中国公司打破**

 

火热的市场背后拥有更深层的意义，距今APM在全球IT领域发展超过10年，随着互联网特别是移动互联网进程的大跨步迈进，传统企业不断互联网化，越来越多的企业会先把自己的营销体系搬到互联网上，以保障、提升用户体验为中心的性能管理得到越来越多的重视，再加上企业逐步向双模式运维转型(传统运维模式+以业务为导向的敏捷模式运维)，APM已经在中国市场迎来了更大的关注度与全面爆发。

  

![](../Images/7742ffaec57d50279a3806d7102585a2.png)  

  

15年底Gartner公布的2015 Gartner APM魔力象限(Magic Quadrant for ApplicationPerformance Monitoring Suites )中，听云作为唯一的中国公司荣登该魔力象限，这也是中国APM厂商第一次成功入选。中国APM领域玩家的进入打破了APM魔力象限长期被欧美玩家独霸的格局，据预测中国APM市场市值可超过100亿，且才刚刚进入市场发展初期，从长期看，这一领域在国内的发展空间不可限量。

 

**国内APM领域火爆引来国际大牛关注**

 

火爆的不仅仅是市场，今年APM行业将引来属于自己的盛会。8月18－19日，由听云和极客邦、InfoQ联合主办的APMCon2016将在北京新云南皇冠假日酒店召开。作为全球首届APM领域垂直峰会，大会已经吸引了海内外行业大牛的关注，来自美国的Java/JVM 性能咨询专家Monica Beckwith、LinkedIn StaffSoftware Engineer庄振运、AppDynamics首席数据科学家赵宇辰等多位国际APM领域专家已经确认出席本次盛会！

  

![](../Images/6d148126fc81273c6295575ccffaf370.png)  

MonicaBeckwith：

Java/JVM性能咨询专家，前Oracle G1垃圾收集器性能团队Leader。Monica Beckwith目前是一位独立咨询师，专注于企业级应用中Java虚拟机和垃圾收集器的优化。她发表过很多垃圾收集器和Java内存模型方面的文章。之前就职于Oracle，带领G1垃圾收集器性能团队。2013年JavaOne大会明星讲师。

 

MonicaBeckwith 有 10 多年的 Java 平台使用和调优经验，也曾担任 Oracle HotSpot G1 收集器性能优化团队的负责人。在本次演讲中，她将谈谈Java性能监控和性能调优的内容，除了OS、JVM层面的知识，还会结合自己的经验介绍性能优化的注意事项，一些性能优化的模式，旨在为参会者在以后的工作中做性能优化提供帮助。

  

![](../Images/b54f702bdac468c23605ccd667fbb126.png)  

庄振运：

LinkedIn Staff Software Engineer，现在美国加州LinkedIn（领英）任职，从事性能优化的工作。曾在Oracle、Salesforce、Internap和德国电信等公司实习和工作。曾获得佐治亚理工学院计算机硕士和博士，清华大学计算机硕士和北京邮电大学信息工程学士学位。长期从事计算机性能方面的学术研究和工程技术优化，在互联网、无线网络、分布式系统、Java、操作系统和存储系统等多个领域发表过30余篇国际论文，拥有10多个国际专利。他将分享《容器里面乾坤大：采用容器部署应用的性能考虑》。

 

随着云计算的普及，越来越多的服务在容器(比如Docker)里面部署。相对于传统的非容器环境，容器部署对APM提出了新的要求。一方面容器的运行需要监控新的性能参数，比如容器的虚拟内存地址空间使用(Virtual Address Space)和守护进程的资源使用。另一方面容器的特殊机制会导致各个容器间在很多情况下互相影响性能(比如有内存压力时)。在APM部署应用时需要尽量避免这些情况。如果容器中的应用发生性能问题，APM可以针对容器的特点帮助诊断。

 

本次演讲会分享LinkedIn使用容器部署中的一些经验。重点介绍容器部署中几种影响性能的场景，比如内存压力场景，JVM在容器内运行的场景，不同容器互相干扰的场景等。这些经验对如何适当部署，有效监控和快速诊断容器里面的应用性能会很有帮助。

  

![](../Images/eee123d74314b8598ffee2556e65dbbe.png)  

赵宇辰：

AppDynamics首席数据科学家。赵宇辰博士自2014年担任AppDynamics首席数据科学家，主导和负责下一代大规模数据挖掘、机器学习、异常检测和分析的APM产品构架和研发工作。他自2013年担任顶级数据科学会议KDD的委员会委员，还曾任General Assembly的首席数据科学讲师，同时在Sumo Logic，Linkedin，eBay，IBM Research有相关的工作经历。并且还在KDD，ICDM，ICDE，CIKM等国际顶级会议发表论文十余篇，在APM和log领域拥有多项国际专利。他将分享《下一代数据驱动的智能APM：痛点，趋势及解决方案》。

 

随着“Software is eating the world”的发展趋势，越来越多的行业正依赖于软件维护企业的基本运营。如何保证软件能稳定、正常、高效的运行已经成为每个企业不容小觑的问题。另一方面，传统的APM软件已逐渐不能满足现代软件架构和大数据时代的要求。

 

本次演讲将结合AppDynamics近三年在APM领域的实践、教训和心得，分享我们认为目前在DevOps遇到的主要痛点和企业用户案例，以及我们如何利用数据和机器学习来提供更精准、更有效的下一代APM解决方案。

 

来自大会组委会的最新消息， JClarity 的Co-Founder， MartijnVerburg先生也将加入本次峰会的国际讲师阵容中，期待他的精彩演讲，相信国外大牛的不同视角的分享会给我们带来更深层次的启发，正如大会主题：驱动应用架构优化与创新，让我们一同见证行业的聚变吧。
