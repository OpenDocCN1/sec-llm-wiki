# UPYUN Open Talk NO.22 直播技术架构的演进及实践

**活动介绍——**  

  

随着流媒体技术的发展，视频直播凭借新颖的即时性、便捷性及互动性强的特点，被越来越多的网民追捧。在全民直播时代，各种类型的直播平台应运而生。动辄百万级的大并发、毫秒响应和高码率的要求，使视频直播对其背后的技术架构支持有了更高的要求。  

本期 Open Talk NO.22 沙龙，我们邀请到秒拍高级研发总监邓铮、又拍云首席布道师羊能卿、红点直播 CTO 王宇航老师，分享他们在实践项目中的技术经验。

  

UPYUN Open Talk 是由又拍云（UPYUN）发起的系列主题分享沙龙。秉承又拍云帮助企业提升发展速度的初衷，UPYUN Open Talk 将用全干货的形态，为互联网从业人员呈现以技术为主，同时涵盖产品、营销、融资等各个方面的专业知识，帮助企业成员不断的提升自身专业技能，以推动企业更快的发展。
