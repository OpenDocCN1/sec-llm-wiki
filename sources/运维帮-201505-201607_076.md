# Google公开了网络负载均衡器Maglev

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=403494869&idx=3&sn=d5b998fb05e6c893f0a37e7243fb5cf6&chksm=02f403f035838ae60765b97af5b66cb120a4d5e490062c2e424ce40b625a6cdf65f73f6cd078&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=403494869&idx=3&sn=d5b998fb05e6c893f0a37e7243fb5cf6&chksm=02f403f035838ae60765b97af5b66cb120a4d5e490062c2e424ce40b625a6cdf65f73f6cd078&scene=27#wechat_redirect)

> 转自：http://www.solidot.org/story?sid=47529

  

Maglev是一个运行在Linux服务器上的大型分布式软件系统，不同于传统的硬件网络负载均衡设备，它的部署不需要特定物理机架，可以很方便的通过添加或移除服务器进行调整。

  

Maglev被Google的云计算平台Google Compute Engine使用，不需要预热就能应付每秒100万次请求。它使用 Equal-Cost Multi-Path routing (ECMP)将进入的数据包分散到所有Maglev机器上。
