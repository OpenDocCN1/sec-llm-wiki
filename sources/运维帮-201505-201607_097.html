说起汽车，大家都清楚，三大件是发动机、底盘和变速箱。


发动机和变速箱可以归为动力系统，底盘则与车辆操控与行驶表现息息相关。

那么，在企业级存储领域，尤其是兵家必争的中端存储(Mid-range Storage)市场，主要的衡量指标有哪些？

针对市场中主流的产品解决方案，Gartner根据不同的使用场景表现和关键能力给出综合评价，用例包括：总体(Overall Use Case)、整合(Consolidation Use Case)、OLTP (OLTP Use Case)、服务器虚拟化和虚拟桌面基础架构 (Server Virtualization and VDI Use Case )、分析( Analytics Use Case) 、云(Cloud Use Case)。

关键能力则包括可管理性(Manageability)、RAS、性能(Performance)、快照和复制(Snapshot and Replication)、可扩展性(Scalability)、生态系统(Ecosystem)、多租户和安全(Multi-tenancy and Security)和存储效率(Storage Efficiency)。

发现没，所有关键能力几乎都可以归为三类：硬件架构、软件功能、硬件架构+软件功能。


与Gartner的企业存储关键能力报告相比，DCIG 2015-16企业中端存储购买指南(DCIG 2015-16 Enterprise Midrange Array Buyer’s Guide)的评价似乎更“简单粗暴”一些，通过硬件(Hardware)、软件(Software)、管理(Management)、虚拟化(Virtualization)、支持(Support)等五方面，对不同产品解决方案进行综合评价。


评价等级分为五个级别(从高到低)：同类最佳(Best-In-Class)、值得推荐(Recommended)、优秀(Excellent)、良好(Good)、基本(Basic)。


关键洞察
未来3-5年，双控制器架构将继续主导中端存储市场，即便有全新的四控制器横向扩展阵列加入市场竞争。

服务器虚拟化、桌面虚拟化、大数据分析、云存储、不受限的数据增长，这些方面正重新划分产品吸引力传统度量方式的优先顺序。

供应商锁定减少，迁移和转换成本的重要性降低，相比较而言，供应商的声誉、支持能力、产品性能、可靠性和可扩展性更重要。
Recommendations
采用自上而下的方法设计基础设施，确定高影响度(high-impact)的工作负载，进行工作负载分析(workload profiling)，设立服务水平目标(service-level objectives)，量化未来的增长率，并探讨与存储服务和灾难恢复供应商合同的影响。

聚焦产品吸引力的衡量指标(例如IOPS、吞吐量、响应时间)，而非Cache、SSD或HDD配置的区别。
企业内部构建一个多功能团队，包括用户、开发者、运营、财务、法规和高级管理，为规划的应用部署和业务需求的变化提供洞察，让相关利益者的潜在诉求都能浮出水面。

进行“如果…会怎样”(what-if)分析，确定组织数据增长率和规划服务的变化将如何影响不同产品方案的吸引力。
以上Gartner的分析和建议，简单说，从客户层面看，就是“因地制宜”四个字，从产品层面看，就是“综合实力”四个字。

Gartner同时指出，非产品性因素，例如供应商关系、售前和售后支持能力等，是产品方案选型时重要的考虑因素。
下面是一些有趣的发现：Gartner报告中，与硬件有关的描述(controller, architecture, cache, capacity,density, core, flash, network, redundant, hardware等)共计出现100频次，软件相关的描述(replication, protocol, snapshot, tier, compression,encryption, thin provisioning, data service, software等)共计出现133频次。

某种程度上，可以说，企业级中端存储的市场竞争中，软件功能和特性能顶“半边天”。传统高端阵列市场的技术下放至中端存储领域，传统中端存储的技术惠泽入门级市场，这是大势所趋。

例如，异步和同步复制、自动分层、虚拟化、自动精简配置等，这些软件功能早已不是高端市场的“特供”，中端存储现在不仅有，而且还能玩儿的好。

DCIG报告中，获“值得推荐(Recommended)”及以上的产品方案共有四款：HP 3PAR StoreServ 7400系列、EMC VNX5000/7000/8000系列、NetApp FAS8000系列、HDS Unified Storage VM。其中，在软件一项中，VNX的评价是“同类最佳”(Best-in-class)。
除了强大的软件功能，“通吃”各种类型的数据服务，VNX还拥有非常丰富的管理特性和虚拟化支持能力。

关于VNX，Gartner的报告则着重提到了这些：基于控制器的静态数据加密，FAST VP和FAST Cache带来优异的性能表现，广泛深入的生态系统(支持业界领先的OS，主要的ISV，Citrix、Microsoft、Red Hat和VMware的管理程序)。

当然，还有与虚拟化环境数据保护利器RecoverPoint、双活虚拟化平台VPLEX的集成，通过Unisphere与VMware(VSI)环境、Microsoft(MESM)环境结合等。
