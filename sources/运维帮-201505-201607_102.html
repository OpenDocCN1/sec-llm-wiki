应用运维工程师（SRE）

工作职责：

  1. 负责小米产品后端的日常运维，包括MILIAO消息、应用商店、MICLOUD等，做好日常排查、故障预案、优化、评估等工作，做到7*24快速响应

  2. 与DEVS共同设计产品后端架构， 实现分布式、集群化运维，确保集群可用性，稳定性，制定并实施相关运维技术方案，确保服务高效、稳定的运行

  3. 负责设计实现与运维相关的自动化工具或系统，减少人工干预，实现运维系统管理业务系统

  4. 通过技术手段进行成本控制及优化，通过工具化及流程提升服务管理效率


职位要求：

  1. 熟悉LAMP架构，特点及架构，有网站运维、集群设计和实施经验者优先

  2. 1、熟练BASH编程，熟练PHP/PYTHON/PERL/RUBY中的任意一门语言

  3. 在计算机技术领域拥有扎实的技术功底，尤其在数据结构、算法和代码、软件设计方面功力深厚；

  4. 熟悉分布式计算、网络系统设计，数据库设计和大规模存储系统，娴熟的C/C 编程技巧；

  5. 熟悉HTTP协议，开发基于HTTP协议的应用；有联网应用、联网游戏开发经验者优先；

  6. 具备Web service/Ajax/JavaScript/Apache/Tomcat/Struts/iBatis/Spring/PHP/JSP/Python等方面经验者优先考虑；

  7. 熟悉TCP/IP协议，熟悉socket和多线程开发，具备高访问量网络开发工作经验


数据库管理员（DBA）

工作职责：

  1. 维护小米数据库服务的正常运行和应急响应

  2. 制定和改进应急预案、策略和流程,提高服务运行质量

  3. 优化数据库服务，提升可靠性、性能

  4. 开发数据库自动化运维平台


职位要求：

  1. 熟悉MySQL的运行机制和体系架构

  2. 精通/熟悉SQL，精通数据库设计与优化

  3. 熟悉Linux/Unix操作系统

  4. 至少熟悉一门所列编程语言golang/python/php/perl/bash

  5. 抗压能力强，有强烈的责任心，良好的沟通能力

  6. 有专职DBA工作经验优先


软件开发工程师-运维平台

岗位职责：

  1. 负责公司运维基础设施开发，包括监控系统，运维平台，自动化部署系统，AppEngine等。

  2. 负责维护公司运维基础设施的正常运行

  3. 为开发工程师，SRE工程师提供运维技术支持

  4. 研究运维新技术和新方向，提高生产力


职位要求：

  1. 熟悉Linux操作系统，计算机网络等，基础知识扎实

  2. 精通Linux系统下C、C++、golang或Python、Ruby、Shell等脚本语言开发

  3. 有前端开发知识储备，熟悉Javascript、CSS，HTML，了解常用的前端框架，包括不限于Bootstrap，jQuery等

  4. 学习能力强，肯钻研，认真踏实

  5. 有良好的时间观念，能很好的沟通交流，乐于分享

  6. 重度github用户优先


系统工程师（基础设施）

岗位职责：

  1. 研发系统基础平台和服务组件，解决共性需求

  2. 大数据的分析和处理，建立量化指标，用数据指导优化

岗位要求：

  1. 3-5年的大规模服务器基础设施的运维开发经验，独立或参与到运维平台（WEB+DB）的工具开发经验；

  2. 熟练掌握Shell和Python， 熟悉Django、js 与css 者优先考虑

  3. 熟悉大规模网站服务器架构（LoadBalance，LAMP，CDN等），了解分布式系统的设计；

  4. 有基于Linux/Unix的服务器搭建/运维的能力；

  5. 熟悉linux下的C/C++软件开发和调试优先。

  6. 有良好的网络、存储、安全、计算机体系结构方面的知识；

  7. 具备良好的英语文档阅读能力；

  8. 在团队环境中协调作业的能力；
