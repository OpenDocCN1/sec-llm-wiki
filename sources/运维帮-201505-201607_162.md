# AWS re:Invert 2015 大会现场+新服务发布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=208574430&idx=1&sn=95f2efac6fe12a0d2181e8348c54ef91&chksm=169643fb21e1caedbdb3f27568bf33ff10c48ff585ede711144d530c7107d0c0106c39e02620&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=208574430&idx=1&sn=95f2efac6fe12a0d2181e8348c54ef91&chksm=169643fb21e1caedbdb3f27568bf33ff10c48ff585ede711144d530c7107d0c0106c39e02620&scene=27#wechat_redirect)

  

> 云计算已经给企业的IT基础架构带来了重大变革，并要求企业用全新的角度去建设和管理云计算环境，在全新的环境中，构建开放统一化的基础平台将显得至关重要。作为全球瞩目的云计算技术盛会，AWS re:Invent 2015将于2015年10月6-9日在拉斯维加斯威尼斯人酒店（The Venetian）拉开大幕。
> 
>   
> 
> 作为AWS的顶级盛事，AWS re:Invent大会每次举行都能吸引成千上万的人参与（据称2014年有超过13000人参与，而今年将会有超过18000人）。在此次大会上将对多个议题进行讨论，着重聚焦云技术、云服务模式、云安全、大数据、技术架构、企业应用、应用程序部署和管理、开发工具、教育、金融服务、游戏等核心议题。主办方亚马逊将邀请顶尖云计算专家和众多国际重量级嘉宾参与主题演讲。在为期一周的日程安排中，共有300多场分时会议、70场动手实验室（Hands-on Labs）、研讨会、互动讨论、案例分析、专题培训、编程马拉松等，将围绕云计算的热门应用及最新发展趋势，关注全球市场，让观众了解国际最前沿的技术资讯。(文字转自CSDN)
