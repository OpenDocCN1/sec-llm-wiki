今天要说的是fackbook新开源的工具WDT，软件坐标

https://github.com/facebook/wdt 

  

介绍是这么写的：

Warp speed Data Transfer (WDT) is an embeddedable library (and command line tool) aiming to transfer data between 2 systems as fast as possible over multiple TCP paths. https://www.facebook.com/WdtOpenSource 

  

WDT是一个嵌入式函数库并且也是一个命令行工具，通过多TCP通道可以在2个系统快速传送传送数据。  

warp speed的中文翻译是：曲速；变化速度；曲速航行速度；速度是以超过光速的曲速。

敢起这种名字，足以证明facebook对这款命令行工具的自信，说句实话，我也是第一次听说还有曲速这回事，又学习了。
