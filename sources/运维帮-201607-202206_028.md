# wLogger，一款Web日志管理工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=2651300871&idx=1&sn=108011c19ce40b70fdc4988258d7dede&chksm=84ff7022b388f9341c853dbef734e52a72b897446be7eaf3a7c4cc79928bd389085fd17fd15e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=2651300871&idx=1&sn=108011c19ce40b70fdc4988258d7dede&chksm=84ff7022b388f9341c853dbef734e52a72b897446be7eaf3a7c4cc79928bd389085fd17fd15e&scene=27#wechat_redirect)

wLogger，一款集日志采集、日志解析持久化存储、Web 流量实时监控，三位一体的 Web 服务流量监控应用。

  

三大功能模块均可独立部署启用互不干扰，目前已内置 nginx 和 apache 的日志解析存储器，简单配置一下，开箱即用。
