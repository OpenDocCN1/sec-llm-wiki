项目介绍


我们的 DevOps 项目开源啦！该项目以 vue + element-ui 为前端，提供用户的常规操作；以 Python 和 Go 为后端提供 API 业务功能。开源的只是一个 DevOps 产品的开始，希望开源的项目可以帮助大家打开思路作为一个参考精进技术能力，同时也欢迎行业内的精英们为我们的项目提出建设性意见/贡献，2021年我们会继续大力持续迭代。

项目名称：Lightning


开源地址：https://github.com/zhengyansheng

特点：部署快，和运维业务关联快

项目描述


该项目 2021-01-11 立项，由5位热爱编码的小伙伴利用业余时间开发。以业务服务为中心 打造的一款通用/易用 DevOps 产品是我们的诉求，我们正在用自已的经验和能力在开发这款产品。

Lightning 该项目有三部分组成，1个前端（Vue + element-ui 框架做 `lightning` 的 WEB 前端） + 2个后端, 分别对应三个仓库，每个仓库中都有与之对应的项目介绍和安装流程，请知悉。

  • WEB 前端

  • Python 后端

  • Go 后端


至于我们的项目为什么后端要有 Python 和 Go 两种语言？
起初的原因是5位成员中，对编码语言喜爱不同。另外一个原因是：在 DevOps领域中，可以准确的说是先 Python 统领，然后再有 Go，这2种语言都是大趋势，若同时使用效果会更佳。

该项目以 业务服务树 为中心，联动

  • SSH 登陆权限

  • CMDB

  • 作业平台

  • 多云管理

  • 流量调度

  • 发布系统

  • 域名管理

  • 监控管理

  • 配置管理


项目 demo 地址：http://www.aiops724.com/login?redirect=%2F

Python 后端


以 `Python` 语言，采用 django-rest-framework API 框架实现后端模块的功能开发。


环境版本依赖

  • Python 3.6+
  • Django 3.1+
  • MySQL 5.7+
  • Redis 3.2+
