![](../Images/a33184d7e460d20582252e1fc956d2cc.png)项目描述![](../Images/a33184d7e460d20582252e1fc956d2cc.png)

  

该项目 2021-01-11 立项，由5位热爱编码的小伙伴利用业余时间开发。**以业务服务为中心** 打造的一款通用/易用 DevOps 产品是我们的诉求，我们正在用自已的经验和能力在开发这款产品。  

**Lightning 该项目有三部分组成，1个前端**（Vue + element-ui 框架做 \`lightning\` 的 WEB 前端）** + 2个后端**, 分别对应三个仓库，每个仓库中都有与之对应的项目介绍和安装流程，请知悉。

*   WEB 前端
    
*   Python 后端
    
*   Go 后端
    

  
至于我们的项目为什么后端要有 Python 和 Go 两种语言？起初的原因是5位成员中，对编码语言喜爱不同。另外一个原因是：在 DevOps领域中，可以准确的说是先 Python 统领，然后再有 Go，这2种语言都是大趋势，若同时使用效果会更佳。  
**该项目以 ****业务服务树 ****为中心，联动**

*   SSH 登陆权限
    
*   CMDB
    
*   作业平台
    
*   多云管理
    
*   流量调度
    
*   发布系统
    
*   域名管理
    
*   监控管理
    
*   配置管理
