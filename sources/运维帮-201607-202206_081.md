# 没赶上互联网，也没赶上移动互联网，微软到底赶上了什么？？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=2651300082&idx=1&sn=df6caff7d638bbe8d77e8661d5b798ee&chksm=84ff74d7b388fdc1b781cd9e6807c739424e224cef80a73e02c65e674982ebdd1e9925b2470c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=2651300082&idx=1&sn=df6caff7d638bbe8d77e8661d5b798ee&chksm=84ff74d7b388fdc1b781cd9e6807c739424e224cef80a73e02c65e674982ebdd1e9925b2470c&scene=27#wechat_redirect)

提到微软，一般用户的印象可能就是 Windows 操作系统和由 Word+Excel+PPT 所组成的 Office；对于开发者来说，印象可能就是 VSCode、Azure、Windows Server 以及 SQLServer，没准还能想起那个 Windows Phone。但要再往深处去想，可能也就想不到了。总结一下，可能就是下面这 3 点：

  

*   互联网前期没打过雅虎后期没打过谷歌...
    
*   移动互联网又没干过 iOS 和 Android...
    
*   云计算面对前有 AWS 后有 Google Cloud 这种前有追兵后有围堵的局面...
    
*   ......
    

  

微软这些年里到底在忙个啥？？？

  

但其实，虽然在 Web 互联网没有坐到头把交椅，但是微软通过自研和并购，把互联网领域下的浏览器、搜索引擎、邮箱服务、社交网络等业务都集齐了，这为微软的数字化转型提供了最强有力的技术支撑。

  

此后虽然在移动互联网上又慢了一拍，但是微软收购了 NOKIA 智能手机硬件，还拥有 XBOX、Kinnect、HoloLens 等一系列的智能硬件设备。软硬一体化智能体系并搭载有应用商店+内容的商业模式，也生生的为微软在智能终端领域趟出了一条路子。

  

再进入到云计算时代，微软的 Azure 总算是及时拍马赶到，并提供了云服务器、云存储的订阅租用服务以及云数据库+云数据仓库+云可视化工具等软硬一体化的业务，为微软掌握云上生态话语权提供了坚实的后端能力。

  

这次疫情，给了微软一个向行业解释的机会。

  

**互联网行业不尊重传统，只尊重创新**

  

“这个行业不尊重传统，只尊重创新。”--萨提亚·纳德拉

  

从过去的软件时代到现在的云时代，微软都在持续进行着刷新。尤其是过去几年中微软在其 CEO 萨提亚 纳德拉的影响下，通过在技术层面的持续创新，微软在业务层面已经实现了快速增长。

  

微软 CEO 萨提亚纳德拉在接受媒体采访时谈到关于微软如何实现快速增长时也曾提到，**数字技术是微软所拥有的最具有可塑性的一种资源，既可以成为工具，也可以成为武器。**

  

而数字技术，却正是当下国内众多企业所缺少的东西。一场疫情让数字化对于国内企业的重要性被无限放大，让国内几乎所有企业都认识到了数字化对于企业生存发展的必要性。然而摆在面前的，却是不知道该如何下手转型的迫切局面。

  

作为一家专注做平台的公司，微软希望能够为广大开发者提供完善的智能云、开发工具以及转型经验，这样才能让开发者更加聚焦在数字化转型的业务端，才能有更多的精力去做更重要的事情。因此微软想要把自己在新数字生态下所积攒的经验分享出来，联同各界合作伙伴，以期共同加速国内企业的数字化进程。而这，也是微软将要举办 Microsoft Online Tech Forum 微软在线技术峰会的原因。

  

这次疫情，给了微软一个解释的机会，也终于在数字生态下建立了明显的领先优势。
