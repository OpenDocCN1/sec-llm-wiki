# 重置MySQL自增长列，从1开始计数

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=2651299561&idx=1&sn=2586469240124243ad62bd658c9eefe4&chksm=84ff4accb388c3da680bb17b3dfc2285f5e98dcf2b66ea4c22dae7ef6385968018c81d6ddfb2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=2651299561&idx=1&sn=2586469240124243ad62bd658c9eefe4&chksm=84ff4accb388c3da680bb17b3dfc2285f5e98dcf2b66ea4c22dae7ef6385968018c81d6ddfb2&scene=27#wechat_redirect)

经过叶大师指点，特记录一下。

  

MySQL使用了自增长的id，如果经常做测试，有频繁的增加和删除操作，id会变得非常大，并且不连续。

  

比如：

![](../Images/148d078b2c1bf8d773a8b240d3079cd4.png)

  

**第一步：**

这时候想重置一下这个顺序，从1开始，需要先取消id的主键和自增长

![](../Images/30250449a91b5d961ee95f16c79b1b90.png)

  

**第二步：把id都设置为0**  

update table（表名） set id = '0';

  

**第三步：**

然后在重新设置id的主键和Auto increment，就可以了

  

注意：

1、操作前备份。

2、如果这个id有关联别的表，要同步修改，否则就会悲剧。
