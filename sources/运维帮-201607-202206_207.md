# 用Accesshub轻松解决多云互通互联的难题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=2651299079&idx=1&sn=bef1c4387422b2aed590eceb8bec2d4c&chksm=84ff4922b388c03489a92d18cab8da7a6810d85253f401e889ed0e304edf69a2cf69842db51d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=2651299079&idx=1&sn=bef1c4387422b2aed590eceb8bec2d4c&chksm=84ff4922b388c03489a92d18cab8da7a6810d85253f401e889ed0e304edf69a2cf69842db51d&scene=27#wechat_redirect)

公有云时代的到来，多云管理成了一大难题。  

  

网络互连问题尤为突出：多云之间内网如何互连？多云和办公网内网如何互连？下面让我们来看一个案例。

  

假设你有如下网络环境：

  

|   
 || 位置 || 用途 |
| --- | --- | --- |
| 办公网 || 北京XX大厦30层 || 办公 |
| 阿里云 || 北京 || 开发，测试 |
| AWS || 新加坡 || 业务 |

  

互连需求：

1.  阿里云和AWS网络互通
    
2.  办公网和阿里云网络互通
    
3.  在阿里云部署用户接入VPN网关，使得用户可远程接入混合云网络
    

  

你可以考虑使用以下解决方案：

在accesshub.cn注册账号，运行accesshub提供的docker镜像，在WEB控制台选择要互通的网络，后端自动完成配置，实现网络互通。

  

![](../Images/860099bb5552a4ef807a21a110070223.png)

  

**方案对比：**

  

| **传统混合云互通方案** || **Accesshub** |
| --- | --- |
| 拼凑使用多种VPN产品，大量手工操作 || 一套SDN软件，全点击式操作 |
| 复杂度高 || 消除复杂度，不需要网络工程师，任何人都可以运行 |
| 需要几天或几周解决 || 在几分钟内解决 |
| 基于单个网络设计，网关非常笨重 || 基于混合云网络设计，网关为轻量化容器，可在本地网络，AWS，阿里云，腾讯云，百度云，华为云运行 |
| 远程接入需要安装VPN客户端，且兼容的操作系统有限 || 不需要安装客户端，使用macOS，Windows，iOS，Android，Linux原生VPN客户端即可接入 |
| 按套购买产品 || 按使用量计费，支持弹性扩展，成本更优 |
| 后期维护成本高 || 对接云厂商API，自动化运维，后期免维护 |
| 没有服务 || SaaS服务产品，7X12服务，内置工单系统 |
