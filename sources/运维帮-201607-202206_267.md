zabbixnotifier是一个基于Google Chrome的Zabbix扩展通知程序

![](../Images/7e2635b3c0bd15e566e26b05532d56f8.png)

**功能：**

通过此扩展，Zabbix监控系统的当前状态消息可以直接显示在浏览器中。故障和问题检测可以做到迅速和可靠，还可以配置声音通知。由于浏览器安全栏中的图标颜色不断变化，所监控的系统和服务的概览一目了然。

  

**详细信息：**

*   用Zabbix 2.0.x测试
    
*   使用Zabbix API
    
*   用户名，密码，URL，端口和更新间隔都是可配置的
    

  

**更新日志：**

*   1.1.3 - 修复与Zabbix 2.0.4相关的登录问题
    
*   1.2 - 错误修复（更新问题），图标中显示问题数量
    
*   1.3 - 错误修正（错误的图标，当没有通知）
    
*   1.4 - 依赖性检查（skipDependent：'1'）
    
*   1.5 - 隐藏已确认事件（config.hideAck：'true'）＆重新激活简单通知弹出窗口
    
*   1.6 - Bugfix Zabbix 2.4认证
    
*   1.6.1 - 按组添加要素过滤器
    
*   1.7 - 增加对zabbix 3.4的支持，显示系统名称
