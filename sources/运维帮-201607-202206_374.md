**关于新东方教育科技集团（NYSE：EDU）**

  

由1993年11月16日成立的北京新东方学校发展壮大而来，集团以培训为核心，拥有满天星幼儿园、泡泡少儿教育、优能中学教育、基础英语培训、大学英语及考研培训、出国考试培训、多语种培训等多个培训体系，同时在基础教育、职业教育、教育研发、出国咨询、文化产业等方面取得了骄人的成绩。作为中国著名私立教育机构，新东方教育科技集团于2006年9月7日在美国纽约证券交易所成功上市。

  

截止2014年5月，新东方已经在全国50座城市设立了56所学校、31家书店以及703家学习中心。自成立以来，新东方累计面授学员2000万人次。新东方品牌在世界品牌价值实验室（World Brand ValueLab）编制的2010年度《中国品牌500强》排行榜中排名第94位，品牌价值已达64.23亿元。

**我们希望您：**

    1、本科 或 以上学历，3 年(含)以上互联网运维工作经验；

    2、熟练掌握 Linux（尤其是CentOS 发行版）的常见命令和配置；

    3、熟练掌握 Shell 以及Perl/PHP/Python 中1+门开发语言；

    4、熟悉 OSI 模型以及TCP/IP, HTTP 等常见协议的基本原理；

    5、熟悉常见Web及负载均衡软件（如 Nginx、LVS、Keepalived）以及常见数据库/缓存软件（如 MySQL/Redis/Rabbitmq 等）的应用场景和配置；

    6、熟悉虚拟化、容器化，包括Openstack平台、Docker、kvm 等常见技术栈；

    7、熟悉Ceph、Glusterfs、Moosefs等常见的SDS分布式存储的应用场景和配置管理；

    8、熟悉阿里云产品线，并可以根据业务线需求，来规划构建所需的云服务；

 

**团队工作内容：**

    1、负责 IDC、DC 、云平台服务器设备的规划建设、高可用、配置、维护、监控；

    2、负责操作系统以及基础服务（如 dns/监控/ntp/分布式存储 等）的规划建设、高可用架构构建、配置、维护、监控；

    3、负责 负载均衡、高速缓存平台、消息队列服务平台 的规划建设、高可用架构构建、配置、维护、监控；

    4、负责基于 Web 日志和应用日志的数据分析、统计、监控报警以及数据后台的开发；

    5、负责处理线上故障，分析原因，设计解决方案和应急预案，并整理到知识库；

    6、负责 Oracle、MySQL、SQLserver 数据库的规划建设、高可用架构构建、配置、维护、监控；

    7、负责 虚拟化、容器管理平台的规划建设、高可用架构构建、配置、维护、监控；

    8、负责自动化运维平台工作的规划、构建、优化；
