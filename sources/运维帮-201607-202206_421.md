**公司简介**

猎豹移动（NYSE: CMCM）,于2010年10月由金山安全和可牛影像合并而成，继承了金山16年的安全技术积累和可牛影像的互联网基因，是Google Play全球工具类榜单排名第一的移动应用开发商。致力于为全球的移动用户提供更快速，更易用，更安全的移动互联网体验。

  

**招聘职位**

**【DBA经理】**

**工作职责:**

1.  利用现有系统平台，对大规模数据库（Mysql、Redis、MongoDB等）进行日常的维护、管理、扩展等工作；
    
2.  跟进业务需求，参与数据库架构设计、数据结构优化，并予以实施；
    
3.  快速响应线上突发事件，彻底解决数据库相关问题；
    
4.  根据实际情况，提出现有系统平台的改进建议，并配合实施。
    
5.  带领DBA团队完善数据库周边的平台化、自动化建设。
    

  

**任职要求:**

1.  对主流数据库（MySQL、Redis）有深入研究，并有五年以上DBA实际工作经验，两年以上运维相关工作经验；
    
2.  精通sql语言，精通mysql常用技术原理，如Replication、Binlog、Grant、Index、Explain，并可熟练操作；
    
3.  有一定的脚本语言编程能力，可自行开发工具类脚本，熟练使用Python、Perl语言者优先；
    
4.  有良好的沟通、抗压能力，对待事务认真、负责。对数据库相关技术有强烈的兴趣和热情，有数据库自动化运维实践经验优先。
    
5.  熟悉公有云（AWS、金山云、腾讯云）服务环境优先。
    

 

**【运维架构师】**

**工作职责:**

1、带领运维基础架构组负责线上业务系统部署架构设计，并持续进行优化

2、负责网络架构、业务系统集群部署、配置管理等运维自动化平台的技术方案设计及实施；

3、主导解决运维工作中的重大故障，性能瓶颈等相关疑难的运维问题；

4、敏锐的关注互联网运维等前沿技术的发展，不断的改进运维架构，提升运维管理效率；

5、配合完成相应制度规范、工作流程、应急预案等，提升服务运行质量；

6、总结沉淀运维经验，推动运维流程规范建设，减少故障的同时提高效率。

 

**任职要求:**

1.  计算机相关专业大学本科以上学历，具有扎实的计算机基础理论知识;
    
2.  5年以上系统管理经验，或从事系统架构师/运维架构师相关职业三年以上;
    
3.  具有大规模运维的部署经验，精于容量规划、架构设计、性能优化;
    
4.  深入理解Linux系统，TCP/IP以及具有丰富的网络知识，熟练使用shell、python、php等脚本编程语言;
    
5.  思维缜密、思路清晰，较好的逻辑分析能力，具有很强的故障排查能力，重视流程规范，有很好的技术敏感度;
    
6.  熟悉互联网公有云服务（AWS、金山云、腾讯云），对Docker、虚拟化等技术有深入的研究；
    
7.  积极主动，勤于思考，善于实践，具备很好的总结，归纳和创新能力;
    
8.  良好的敬业精神和职业素养良好的沟通能力、文档撰写能力以及英文读写能力，善于团队协作;
    

 

 **【云平台项目经理】**

**岗位职责：**

1. 负责自动化运维平台项目的项目管理工作：项目的进度跟踪，沟通协调，问题管理，测试，培训推广，文档等。

2. 协助自动化运维平台产品规划设计工作：需求调研，产品设计，产品运营

3. 梳理自动化运维流程，制定相关规范。

 

**任职资格：**

1. 大学本科及以上学历，互联网企业1年以上项目经理或产品经理等经验。

2. 有较强的数据分析能力，了解常用的数据分析方法，有较好的理解能力。

3. 严谨的逻辑思维能力及分析问题解决问题的能力，注重实施和结果，注重细节，执行力强，抗压能力强。

4. 具备一定的沟通能力、项目管理能力、产品设计能力、团队协作能力、组织协调能力。

5. 具有积极的工作态度和良好的学习能力，高度的自我驱动能力，做事结果导向。

7. PMP资格认证优先。

 

**【云平台内控经理】**

**岗位职责：**

1.  管控部门费用、财务统计、采购、预算、费用报销。
    
2.  管理安排部门各种会务，组织部门各种活动。
    
3.  定期收集汇总部门各组工作报告，重要文件备份归档。
    
4.  优化部门各业务环节流程制度，支撑部门的高效运作。与相关职能部门和供应商沟通，确保跨部门的工作有序开展。
    
5.  作为核心用户参与部门流程与财务软件系统开发的项目需求、测试、推动等工作，推动部门工作数据化、信息化。
    
6.  负责部门内部控制，完善部门制度体系，定期对部门流程运行效率和执行情况进行监控、评估和分析，提出流程优化策略和建议，形成良好的内控环境。
    
7.  负责公司的各类通知、规定的宣导和培训。
    

 

**任职资格：**

1.  大学本科及以上学历。
    
2.  有大型互联网企业3年以上内控、采购管理、项目管理等经验优先。

4.  熟练使用Office系列办公软件，熟练掌握Excel、Visio优先。

 **【大数据运维工程师】**

**工作职责：**

1.  负责公司大数据基础平台的规划、部署、管理和优化，保障平台稳定可靠高效运行；

4.  开发大数据自动化运维、监控、故障处理工具。
    

  

**任职资格：**

1.  本科学历以上, 计算机或相关专业；2年以上相关经验；
    
2.  强烈的责任感和强大的抗压能力；

5.  熟悉Hadoop相关大数据生态圈包括但不限于：YARN/HDFS/Hive/Oozie/Spark/Druid等，一年以上Hadoop相关运维开发经验；
    
6.  熟悉Shell，并熟练掌握一门脚本语言包括但不限于：Python/Perl/Ruby等。
    

  

**优先条件**：
