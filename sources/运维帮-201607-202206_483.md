# 聚美优品、咕咚、ThoughtWorks齐聚成都，共论DevOps与持续交付实践|UPYUN Open Talk NO.25报名

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA3MzYwNjQ3NA==&mid=2651297113&idx=2&sn=99e70b73094c895480bc90022e840ddc&chksm=84ff417cb388c86ae4c04a0f854adc584f68cf9d7551b29ca2dde9caea2c30ed545c411787e1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA3MzYwNjQ3NA==&mid=2651297113&idx=2&sn=99e70b73094c895480bc90022e840ddc&chksm=84ff417cb388c86ae4c04a0f854adc584f68cf9d7551b29ca2dde9caea2c30ed545c411787e1&scene=27#wechat_redirect)

  

成都在互联网领域一直亮点频频，是中国互联网版图上不可或缺的一座城市：这里和沿海城市一样，聚集了大量的互联网企业、程序猿、攻城狮，诞生了诸如咕咚、Camera360、Tower、tap4fun等优秀的互联网企业。

去年，UPYUN Open Talk No.7就进入了成都，组织了探讨了“iOS开发与前端技术分享”，大受欢迎！

今年，UPYUN Open Talk No.25选择重回成都，邀请聚美优品、咕咚、ThoughtWorks等知名企业的技术大拿，探讨“DevOps与持续交付实践”。

在运维界被称为“南王北萧”的王津银（优维科技创始人、CEO），曾在又拍云的另一场活动上，对DevOps的要求做过一场精彩的分享，认为“DevOps取的是Dev、Test、Ops三个团队的交集部分，要求大家的思维、目标都需要达到绝对的一致”，引起广泛共鸣，可见DevOps的受关注程度。（又拍云公众号后台回复“王津银”，获取王津银分享全文）

9月10日，聚美优品高级运维工程师胡骏、ThoughtWorks咨询师刘梓懿、咕咚DBA李锐等三位嘉宾，将出席UPYUN Open Talk No.25，带来关于自动化运维、DevOps等话题的精彩分享！

除了关于自动化运维、DevOps的知识盛宴，亲临UPYUN Open Talk No.25现场的听众，还有机会获得近期大热的《高性能Docker》（奖品由博文视点赞助）。

  

  

UPYUN Open Talk 是由又拍云主办的系列主题分享沙龙，秉承了又拍云帮助企业提升发展速度的初衷，用全干货分享的形态，为互联网从业人员呈现先进的IT技术、理念，帮助与会者不断的提升自身专业技能，推动企业更快发展。
