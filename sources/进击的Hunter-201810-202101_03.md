##  0x01 翻译 

**`fy`** 如果你只是想简单得查查单词，它或许会是你最好的选择。这是一款中英文互译工具，自动判断语言并拼读单词，通过 `npm install fanyi -g` 安装。

![](../Images/549139a6e609e08d086e2b76d41494f0.png)

**`trans`** 这是一款多语言互译工具，可整句翻译、调用多种引擎、功能齐全且跨平台。Mac下可通过`brew install translate-shell`安装

![](../Images/89c6ed4b9a980d344425c70ae80a869a.png)

##  0x02 命令 

**`tldr`** 当你不了解某个命令的用法，并不想查看`--help`的时候，它的作用就显而易见了。

![](../Images/766b4310759a29205cdcef4fa510ae79.png)

**`cht.sh`** 或许你渴望更全面的语法案例，那就选它。个人认为的唯一缺点就是结果高亮效果较差。访问 https://github.com/chubin/cheat.sh#installation 以安装

![](../Images/db3ffa82d12d8cb8071dd35df57abd91.png)

##  0x03 搜索 

**`googler`** 可直接返回谷歌搜索结果，免去了打开浏览器的过程(查看详情的时候还是要的)

![](../Images/ed8e24a9ba0f93bec93ef1c2b498c956.png)

**`ag`** 简简单单的一条语句却能让内容搜索变得如此高效，更支持正则及二进制查找。那么例如我要搜索所有包含有facebook的文件及所在行，只需这样

![](../Images/c2327425f6db56f4899895a0b68932f2.png)

**`fd`** 相比前一位，它更擅长的是文件搜索，支持正则、指定文件类型及隐藏目录查找。

![](../Images/deb62d79fbf8d9f2e48b8c73e8ee6d22.png)

##  0x04 预览 

**`bat`** 都看到了这里，那想必大家一定熟悉`cat`吧，更有甚者也了解 `ccat` 等等。它们是不是都很伤眼睛，是的话那就下载它吧。

![](../Images/41d71c6c6a774d5df24e4105c482694d.png)

**`imgcat`** 每当我们查找到了图片，又想快速得查看，那就用它了。通过 `pip install imgcat` 进行安装。

![](../Images/6bad0bad9b9aecf8852326a02fc99107.png)

  

以上未注明安装方式的在mac下均可通过 `brew install xxx` 直接安装，解锁快乐
