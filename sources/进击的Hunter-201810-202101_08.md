## HTTP状态码五大分类

HTTP 响应状态代码指示特定 HTTP 请求是否已成功完成，其中响应分为五类。

*   信息响应 1xx
*   成功响应 2xx
*   重定向 3xx
*   客户端错误 4xx
*   服务器错误 5xx

## 1xx 信息响应

请求已经收到将继续处理

### 100 Continue

![](../Images/4f881d17c5c9babba10544c316df28bb.png)这个临时响应表明，迄今为止的所有内容都是可行的，客户端应该继续请求，如果已经完成，则忽略它。

### 101 Switching Protocol

![](../Images/9733c325e614eab6c197a5e55d92d68f.png)

该代码是响应客户端的 Upgrade 标头发送的，表示服务器正在切换的协议。  

## 2xx 成功响应

请求已成功接收，并被接受

### 200 OK

![](../Images/4cbce4cf9fb96249fc0f80dd8337f22d.png)请求成功。成功的含义取决于HTTP方法：

*   GET：资源已被提取并在消息正文中传输。
*   HEAD：实体标头位于消息正文中。
*   POST：描述动作结果的资源在消息体中传输。
*   TRACE：消息正文包含服务器收到的请求消息

### 201 Created

![](../Images/a8119478f7e569f43db7809cda3e65df.png)

该请求已成功，并因此创建了一个新的资源。通常源于POST或某些PUT请求。  

### 202 Accepted

![](../Images/07dd1b7936516b7172aeaea52f3bae73.png)

该请求已被接受进行处理，但是处理尚未完成。最终有可能会被处理也可能不会。  

### 204 No Content

![](../Images/e45c55f035dd5614f8721b9095926422.png)

服务器成功处理了请求，但响应体中不会有任何内容。  

### 206 Partial Content

![](../Images/9b55894640890a6f1188c79add67ec7e.png)

服务器已经成功处理了部分 GET 请求。例如迅雷的断点续传或分段同时下载就是利用了该类响应。该请求必须包含 Range 头信息来指示客户端希望得到的内容范围，并且可能包含 If-Range 来作为请求条件。  

### 207 Multi-Status

![](../Images/52979ca4dc5b5427bad305897bd616ec.png)

代表之后的消息体将是一个XML消息，很可能包含了后续的多段响应。  

## 3xx 重定向

为了完成请求，需要采取进一步的措施

### 300 Multiple Choice

![](../Images/4ce3849b90e6abb3cca0b7f6daab6b76.png)

被请求的资源有一系列可供选择的回馈信息，每个都有自己特定的地址和浏览器驱动的商议信息。用户或浏览器能够自行选择一个首选的地址进行重定向。  

### 301 Moved Permanently

![](../Images/11bee036079742489438b772405236d3.png)

永久性定向，被请求的资源已永久移动到新位置，并且将来任何对此资源的引用都应该使用本响应返回的若干个 URI 之一。  

### 302 Found

![](../Images/b8bcf7deb703f7eee55a61cfa82436af.png)

临时性重定向，请求的资源现在临时从不同的 URI 响应请求。由于这样的重定向是临时的，客户端应当继续向原有地址发送以后的请求。只有在Cache-Control或Expires中进行了指定的情况下，这个响应才是可缓存的。  

### 303 See Other

![](../Images/7e6501342a52d79872dd1d6bc1a20efa.png)

服务器正在将用户代理重定向到其他资源，如通过Location标头，旨在提供对原始请求的间接响应。  

### 304 Not Modified

![](../Images/376884318c561c33e86d7dc518706160.png)

客户端发送了一定的GET或HEAD请求，但需要获取的目标资源未改变。  

### 305 Use Proxy

![](../Images/c236f5e923d2fec86459e28bf1ddf0d5.png)

被请求的资源必须通过指定的代理才能被访问。Location 域中将给出指定的代理所在的 URI 信息，接收者需要重复发送一个单独的请求，通过这个代理才能访问相应资源。  

### 307 Temporary Redirect

![](../Images/2e6b24af6225d57dbabe4f7a4a643758.png)

与302相似，但禁止自动重定向，除非获得用户的确认  

## 4xx 客户端错误

该请求包含错误的语法或无法满足条件

### 400 Bad Request  

![](../Images/3dee121f23fe144f12ef19620d9e18ab.png)

1.  语义有误，当前请求无法被服务器理解。
2.  请求参数有误。

### 401 Unauthorized

![](../Images/71aa14a94f9fc16e5f6f4a6542aa27f0.png)

当前请求需要用户验证。该响应必须包含一个适用于被请求资源的 WWW-Authenticate 信息头用以询问用户信息。  

### 402 Payment Required

![](../Images/6e68d0f80c3028357233cadd53766296.png)

此响应码保留以便将来使用，创造此响应码的最初目的是用于数字支付系统，然而现在并未使用  

### 403 Forbidden

![](../Images/ff05ff93553d519a74d3341afcde0b15.png)

服务器理解了该请求，但拒绝对其进行授权。  

### 404 Not Found

![](../Images/a7d7a6068fe8bf38da2c0d10c6ff4530.png)

服务器未找到该资源，或不愿透露该资源的存在。  

### 405 Method Not Allowed

![](../Images/a38a66532841652311122bd1aae44558.png)

请求行中指定的请求方法不能被用于请求相应的资源。该响应必须返回一个Allow 头信息用以表示出当前资源能够接受的请求方法的列表。  

### 406 Not Acceptable

![](../Images/fd8acf8678db9661388d0a43b64ab5bc.png)

请求的资源的内容特性无法满足请求头中的条件，因而无法生成响应实体。  

### 408 Request Timeout

![](../Images/c5e3479276eeadb7ac5ad610f430746f.png)

请求超时。客户端没有在服务器预备等待的时间内完成一个请求的发送。  

### 409 Conflict

![](../Images/e3786f391afa9a6e583d2d99ac6b838f.png)

由于和被请求的资源的当前状态之间存在冲突，请求无法完成。  

### 410 Gone

![](../Images/abe7c8287399136c3d92fc6b1dad1a29.png)

被请求的资源在服务器上已经不再可用，这样的状况一般是永久性的。  

### 411 Length Required

![](../Images/45b8051b79f4d16bc9e559ee195be328.png)

服务器拒绝在没有定义 Content-Length 头的情况下接受请求。  

### 412 Precondition Failed

![](../Images/0ad01f1605ef02d0448f0ab1facbef40.png)

服务器在验证在请求的头字段中给出先决条件时，没能满足其中的一个或多个。  

### 413 Payload Too Large

![](../Images/a6c3c3b68a7dc9ed57a23590f543ba3a.png)

请求体过大导致服务器拒绝处理当前请求。  

### 414 URI Too Long

![](../Images/f8a131a51133dc6d45af5519d2231fee.png)

请求的URI过长导致服务器拒绝对该请求提供服务。  

### 415 Unsupported Media Type

![](../Images/270e9a77b473f641abcf62210ec85fac.png)

对于当前请求的方法和所请求的资源，请求中提交的实体并不是服务器中所支持的格式，因此请求被拒绝。  

### 416 Requested Range Not Satisfiable

![](../Images/481d581f6f9d0d8616ac10ee83732811.png)

如果请求中包含了 Range 请求头，并且 Range 中指定的任何数据范围都与当前资源的可用范围不重合，同时请求中又没有定义 If-Range 请求头，那么服务器就应当返回416状态码。  

### 417 Expectation Failed

![](../Images/7bc51fcd71c8e977916794d2daaf6cce.png)

此响应代码意味着服务器无法满足 Expect 请求标头字段指示的期望值。  

### 418 I'm a teapot

![](../Images/135db7a38c06acf5d2cb1112fad98f70.png)

服务器拒绝冲泡咖啡,因为他是一盏茶壶。。。这是一个1998年的愚人节笑话。  

### 420 Enhance Your Calm

![](../Images/11e44aae536a0cbb55caadb3a4e47a10.png)

twitter接口专用的限速代码  

### 421 Misdirected Request

![](../Images/7dc96d04a8d818e66ea4cc9908255a0e.png)

该请求针对的是无法产生响应的服务器。且它可以由该服务器发送。  

### 422 Unprocessable Entity (WebDAV)

![](../Images/8101c536f00a13373bcd6f8957abc800.png)

请求格式良好，但由于语义错误而无法遵循。  

### 423 Locked (WebDAV)

![](../Images/c993faa9182cd772aeab1cb65e601e0a.png)

正在访问的资源被锁定。  

### 424 Failed Dependency (WebDAV)

![](../Images/c14af36f3aa1f1623675898d0aa6304e.png)

由于先前的请求失败，所以此次请求失败。  

### 425 Too Early

![](../Images/2f87186b87f57178775db26315daa9ee.png)

服务器不愿意冒着风险去处理可能重播的请求。  

### 426 Upgrade Required

![](../Images/a83db3cc2ee905bd43f124780f42afcf.png)

服务器拒绝使用当前协议执行请求。  

### 429 Too Many Requests

![](../Images/2c6b35ed5bef27b8db030dbb645a0f06.png)

用户在给定的时间内发送了太多请求。  

### 431 Request Header Fields Too Large

![](../Images/bbdf4a4180e6d6cb63fc19b0f80211aa.png)

请求头字段太大导致服务器不愿意处理请求。  

### 444 No Response

![](../Images/f7d15edd48df63f922326f31f24c23de.png)

在内部使用指示服务器不向客户端返回任何信息并立即关闭连接。  

### 450 Blocked by Windows Parental Controls

![](../Images/ce491116b2a3e855e79e41a4f6bc0db4.png)

微软家长控制已打开，且成功阻止了访问该网页的请求。  

### 451 Unavailable For Legal Reasons

![](../Images/50c03cdd5c436b37c2e672bede147da1.png)

用户请求了非法资源。  

## 5xx 服务端错误

服务器无法处理有效的请求

### 500 Internal Server Error

![](../Images/deef618a364e30b9dea5436423329a94.png)

服务器遇到了不知道如何处理的情况。

### 501 Not Implemented

![](../Images/e09340dc8d8d39e9d9fa4aaf6a540d3d.png)

此请求方法不被服务器支持且无法被处理。只有GET和HEAD是要求服务器支持的，它们必定不会返回此错误代码。  

### 502 Bad Gateway

![](../Images/07b100e6f608856ecb3a4a6120c6a7e1.png)

此错误响应表明服务器作为网关需要得到一个处理这个请求的响应，但是得到一个错误的响应。  

### 503 Service Unavailable

![](../Images/980e827b4916970c38ca5772643637d3.png)

服务器没有准备好处理请求，一般是服务器维护或重载而停机。

### 504 Gateway Timeout

![](../Images/10a2ab50f4fbfd680555b9310815cc2d.png)

当服务器作为网关，不能及时得到响应时返回此错误代码。  

### 506 Variant Also Negotiates

![](../Images/007245a2b6a5260d033a29819f0d96ff.png)

服务器有一个内部配置错误：对请求的透明内容协商导致循环引用。

### 507 Insufficient Storage

![](../Images/ae28b90cfcdd5f3520d21f21c17764b0.png)

服务器有内部配置错误：所选的变体资源被配置为参与透明内容协商本身，因此不是协商过程中的适当端点。  

### 508 Loop Detected (WebDAV)

![](../Images/0431b7b0cb0a405ccc5bb700d9fbc5f0.png)

服务器在处理请求时检测到无限循环。  

### 509 Bandwidth Limit Exceeded

![](../Images/e8977d084dabff7cb2b0ff87ac0472d0.png)

服务器已超出服务器管理员指定的带宽；共享托管服务提供商通常使用它来限制客户的带宽。

### 510 Not Extended

![](../Images/8c12ceef267e77d6fdf79d2bb0ec48b3.png)

客户端需要对请求进一步扩展，服务器才能实现它。服务器会回复客户端发出扩展请求所需的所有信息。  

### 511 Network Authentication Required

![](../Images/f7949d7cd9237535a5ee82e3d608fe98.png)

511 状态码指示客户端需要进行身份验证才能获得网络访问权限。  

### 599 Network Connect Timeout Error

![](../Images/b67d13568c8222b7536e11e7a1ffca6e.png)

此状态代码未在任何RFC中指定，但是某些HTTP代理使用此状态代码向代理之前的客户端发送信号，以指示代理后面的网络连接超时。
