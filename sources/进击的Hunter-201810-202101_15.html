Sherlock是一个命令行工具，亦是一个强大的社工工具，可用于查找各类社交网络中的用户名。它需要Python 3.6或更高版本，适用于MacOS，Linux和Windows。于是在某些时候，我们就有机会用得上它了。

0x00 环境依赖

首先我们要确定电脑上已成功安装python3.6，推荐使用 anaconda 集成环境。

0x01 下载 

# 我们将项目克隆至本地
$ git clone https://github.com/sherlock-project/sherlock.git

# 进入目录
$ cd sherlock

# 通过如下命令安装好第三方包
$ python3 -m pip install -r requirements.txt

0x03 使用

我们通过python3 sherlock.py [用户名1] [用户名2] 来开始进行搜索。可以看到下图操作已经搜索到了一大堆的账号。

命令行参数

  • -d 显示调试信息

  • --print-found 隐藏失败结果

  • -r 根据rank排名调整搜索顺序

  • -fo path 多用户搜索时，结果将被保存至path

  • -o path 单用户搜索时，结果保存至path文件夹

  • -t 将通过洋葱网络进行爬取，前提是，记得把tor装上

  • -u 每次爬取后，都会更换tor线路，防反向追踪

  • --csv 生成csv

  • --site name 只爬取罗列的站点

  • -p uri 请求通过代理爬取

  • -j name 这个真不知道干啥用的- -!!

  • -pl uri1 uri2 设定代理池，每次请求随机发送
