## lru\_cache 

这是一个可以为函数提供缓存功能的装饰器，在下次以相同参数调用时直接返回上一次的结果。用以节约高开销或I/O函数的调用时间。

例如我们可以用以高效计算斐波那契数列。

```

















from functools import lru_cache
```

在未加上`@lru_cache(maxsize=None)`时使用了 1.91秒, 而在加上之后只花费了 0.06秒。
