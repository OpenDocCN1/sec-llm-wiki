Celery 是一个简单、灵活且可靠的，处理大量消息的分布式系统，并且提供维护这样一个系统的必需工具。今天我们通过一个案例简单的讲一下celery的快速应用。

环境及模块依赖

  • python3 语言环境

  • sqlite3 数据池，临时方案下代替 redis

  • requests_html 测试模块

  • celery 异步任务

预设任务方法 task.py

通过设定 broker参数为 sqla+sqlite:///xxx来已连接sqlite的方式实例化 Celery

  1. import sqlite3
  2. from requests_html import HTMLSession
  3. from celery import Celery

  5. celery_db = "db"  # db名称
  6. sqlite3.connect(celery_db)  # 新建或连接库
  7. app = Celery("demo", broker=f"sqla+sqlite:///{celery_db}")  # 设定celery
  8. app.conf.update(
  9.     task_serializer="pickle", result_serializer="pickle", accept_content=["pickle"]
  10. )  # 设定为可以传输对象


  13. @app.task()  # celery任务
  14. def check_poc(index,url):
  15.     resp = HTMLSession().get(url) # 测试
  16.     print(f"[{index}]{url}: {resp.html.find('title', first=True).text}") # 打印日志

发布任务执行

我们通过若干个网址作为 payload来做测试

  1. from task import check_poc

  3. urls = ["http://qq.com", "http://baidu.com", "http://freebuf.com"] # 测试案例站点

  5. for index,url in enumerate(urls):
  6.     check_poc.delay(index,url) # 异步调用
