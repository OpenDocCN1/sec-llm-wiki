# 关于代理匿名等级检测

现在市面上我们可以了解到的代理类型分别为 `TRANSPARENT`、 `ANONYMOUS`、 `DISTORTING`、 `ELITE`四种。今天，我们就来简单聊聊如何根据请求 `Header`进行代理的匿名检测。

### 定义匿名类

为了方便区分，除了以上4种代理，我们还加入了**无代理**及**未知代理**。

```
1.  `from enum import Enum, unique`
    
2.  
    
3.  `@unique`
    
4.  `class PROXIES(Enum):`
    
5.  `    NONE = "无代理"`
    
6.  `    TRANSPARENT = "透明代理"`
    
7.  `    ANONYMOUS = "匿名代理"`
    
8.  `    DISTORTING = "欺骗性代理"`
    
9.  `    ELITE = "高匿代理"`
    
10.  `    UNKNOW = "未知代理"`
     
```

### 判断原理

*   `Remote_Addr` 末端代理服务器IP地址
    
*   `Via` 通过的代理服务器(ip或名称)
    
*   `X_ForWarded_For` 经过的代理IP地址集合(可伪造)
    

> 假设您的地址为1.2.3.4 并通过了A代理来连接站点

1.  **TRANSPARENT**
    

*   `Remote_Addr` 为 `A`
    
*   `X_ForWarded_For` 为 `1.2.3.4, A`
    
*   存在 `Via`
    

*   **ANONYMOUS**
    

*   `Remote_Addr` 为 `C`
    
*   `X_ForWarded_For` 为 `A,B,C`
    
*   存在 `Via`
    

*   **DISTORTING**
    

*   `Remote_Addr` 可能为 `A` 或 `B` 或 `C`
    
*   `X_ForWarded_For` 为不可预期的结果
    
*   存在 `Via`
    

*   **ELITE**  
    

*   `Remote_Addr` 可能为 `B` 或 `C`
    
*   `X_ForWarded_For` 为空
    
*   **不存在 `Via`**

### 服务器准备

为了快速开发，我们这里使用Caddy作为反向代理，以保障获取到 `X-Forwarded-for`

```
1.  `0.0.0.0:80`
    
2.  `gzip`
    
3.  `proxy / 127.0.0.1:12888 {`
    
4.  `    header_upstream X-Forwarded-Port {server_port}`
    
5.  `    header_upstream X-Forwarded-Proto {scheme}`
    
6.  `    header_upstream X-Real-IP {remote}`
    
7.  `}`
    
```

### 逻辑呈现

我们使用tornado作为服务来进行判断，并且，请求所经过代理的请求附带提交**真实客户端IP**及使用的**代理IP**

##### Server端

```
1.  `class Main(tornado.web.RequestHandler):`
    
2.  `    async def get(self):`
    
3.  `        client_real_ip = self.get_argument("client", "").split(":")[0].strip() # 起始客户端提供IP`
    
4.  `        proxy_ip = self.get_argument("proxy", None)  # 起始客户端提供代理IP`
    
5.  
    
6.  `        x_real_ip = self.request.remote_ip  # 最后一级客户端IP`
    
7.  `        x_forwarded_for = self.request.headers.get("X-Forwarded-For", "")`
    
8.  `        x_forwarded_for_ip = x_forwarded_for.split(",")[0].strip()  # 第一个代理IP地址`
    
9.  `        http_via = self.request.headers.get("Via")`
    
10.  
     
11.  `        types = PROXIES.UNKNOW.value # 默认代理类型`
     
12.  `        if is_ip(client_real_ip):  # 是否有给定真实地址`
     
13.  `            if http_via:  # 是否有via`
     
14.  `                if proxy_ip and is_ip(proxy_ip):  # 是否有指明代理`
     
15.  `                    if x_forwarded_for_ip == client_real_ip and x_real_ip == proxy_ip:  # 透明代理`
     
16.  `                        types = PROXIES.TRANSPARENT.value`
     
17.  `                    elif x_real_ip == proxy_ip and x_forwarded_for_ip != client_real_ip:  # 匿名代理`
     
18.  `                        types = PROXIES.ANONYMOUS.value`
     
19.  `                    elif x_forwarded_for_ip != proxy_ip and x_forwarded_for_ip:  # 随机代理`
     
20.  `                        types = PROXIES.DISTORTING.value`
     
21.  `            else:`
     
22.  `                if client_real_ip != x_real_ip:`
     
23.  `                    types = PROXIES.ELITE.value  # 高匿代理`
     
24.  `                else:`
     
25.  `                    types = PROXIES.NONE.value  # 未使用代理`
     
26.  `            self.write({"status": True, "msg": "ok", "types": types, "end_ip": x_real_ip})`
     
27.  `        else:`
     
28.  `            self.write({"status": False,"msg": "check your client ip","types": types,"end_ip": x_real_ip})`
     
```

##### Client端

我们编写如下脚本进行批量测试

```
1.  `from enum import Enum`
    
2.  `import requests`
    
3.  
    
4.  `SERVER_NET_PORT = 80`
    
5.  
    
6.  `class IPs(Enum):`
    
7.  `    CLIENT = "33.44.55.66"`
    
8.  `    SERVER = "12.13.14.15"`
    
9.  
    
10.  `def checker(ip,port=80,protocol='http'):`
     
11.  `    proxy_uri = f"{protocol}://{ip}:{port}" # 代理地址`
     
12.  `    proxies = {"http": proxy_uri, "https": proxy_uri} # 代理地址字典`
     
13.  `    server_url =f"http://{IPs.SERVER.value}:{SERVER_NET_PORT}?client={IPs.CLIENT.value}&proxy={ip}" # 组合地址`
     
14.  `    resp = requests.get(server_url,proxies=proxies,timeout=TEST_TIMEOUT) # 发送请求`
     
15.  `    return {proxy_uri: resp.json()}`
     
16.  
     
17.  
     
18.  `def main():`
     
19.  `    proxy_list = [("200.255.122.170",8080)]`
     
20.  `    datas = list(map(lambda item: checker(*item), proxy_list))`
     
21.  `    print(datas)`
     
```
