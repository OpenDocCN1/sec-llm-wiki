## Quick HTTP Inspector

Quick HTTP Inspector是一个能够快速导出网页请求流并转换成基于python-requests脚本的优秀工具，让你不费吹灰之力就可以快速生成payload。当然，此插件适用于有一定基础的同学，不推荐初学者使用。

![](../Images/7317c2c45e464fa5cb3dc1173218fd25.png)

#### 安装方式

打开chrome，点击应用商店，搜索 `QuickHTTPInspector`后安装即可。

  

## go-sniffer

go-sniffer可以抓取并截取项目中的数据库请求并解析成相应的语句。支持指定特定网络出口。这也算是sql调试的一大福音，免去了开发者在代码中插入各种针对调试sql的print和log。

![](../Images/62e475248521d83078d85676c090feff.png)

#### 环境安装

*     
    
    Centos
    
    ```
    
    yum\-y install libpcap-devel
    ```
    
*     
    
    Ubuntu
    
    ```
    apt\-getinstall libpcap\-dev
    ```
    

#### 运行

```
1.  `go get -v -u github.com/40t/go-sniffer`
    
2.  `cp -rf $(go env GOPATH)/bin/go-sniffer /usr/local/bin`
    
3.  `go-sniffer`
    
```

## pdir

你或许经常使用dir，但这里有一款或许更适合你的pdir2，以清晰得逻辑、带解释得来展示模块支持方法及属性。废话不多说，如下是效果图。

![](../Images/ea5ba8f9f0b49d0b2c2ca354220400ee.png)

安装方式

```
1.  `pip install pdir2`
    
```

#### 更好的应用方式

```
1.  `# 编辑 .bashrc 或者 .zshrc`
    
2.  `vi ~/.bashrc`
    
3.  
    
4.  `# 插入如下内容，在python启动时将自动导入pythonstartup的内容`
    
5.  `export PYTHONSTARTUP=$HOME/.pythonstartup`
    
6.  
    
7.  `# 编辑.pythonstartup`
    
8.  `vi ~/.pythonstartup`
    
9.  
    
10.  `# 将下面内容写入文件`
     
11.  `import pdir`
     
12.  
     
13.  `# 刷新配置，如此一来 pdir即可直接使用`
     
14.  `source ~/.bashrc`
     
```

## tldr

与pdir类似，tldr可以快速展示系统命令的基本用法并给出相应解释。且颜色分明的回显方式更具可读性。

![](../Images/266bc9f1fe5cad67dea02bf60c32af44.png)

#### 安装方式

```
1.  `npm install -g tldr`
    
```
