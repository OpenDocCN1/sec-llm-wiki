### 前言

暗网或许对大多数人来说都是一个陌生的名词，但对于一个安全人员却是必不可少的一样的东西。暗网之内鱼龙混杂，内含的活动内容也是参差不齐。

![](../Images/293b56cdddecbbcaa6a7c27391eb625f.png)

其中不乏各类的交易黑市，且交易内容也让人触目惊心。(护眼)

![](../Images/8e7d34e08e6f74754eb8d36487f62b8d.png)

于是我们针对 `deepmix2z2ayzi46.onion` 暗网中文网编写了一个监控爬虫作为实践案例。

### 功能简要

*   自动注册
    
*   自动登录
    
*   防封禁策略
    
*   ORM交互
    
*   事件详情/样本信息录入
    
*   事件提醒（telegram）

### 分析过程

下面我们简单讲一下该网站的业务逻辑，在进入该网站后网站以一个 `PHPSESSID`Cookie 作为用户整个生命周期的身份ID，过期时间为1小时，且不会自动延长。

![](../Images/a6ecacc20600132af06781910be4acff.png)

只有靠再次登录才能刷个新的身份。那么在这里，我们需要设定一个Session会话来自动处理这个cookie。并配置socks5代理，关于tor的安装不再赘述。

```
1.  `self.session = requests.Session()`
    
2.  `self.session.headers = {`
    
3.  `    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,image/apng,*/*;q=0.8",`
    
4.  `    "Accept-Encoding": "gzip, deflate",`
    
5.  `    "Accept-Language": "zh-CN,zh;q=0.9,en;q=0.8",`
    
6.  `    "Cache-Control": "max-age=0",`
    
7.  `    "Connection": "keep-alive",`
    
8.  `    "Referer": "http://bmp3qqimv55xdznb.onion/index.php",`
    
9.  `    "Upgrade-Insecure-Requests": "1",`
    
10.  `    "User-Agent": "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_13_4) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/69.0.3497.100 Safari/537.36"`
     
11.  `}`
     
12.  `self.proxy_url = 'socks5h://127.0.0.1:9150'`
     
13.  `self.session.proxies = {`
     
14.  `    'https': self.proxy_url,`
     
15.  `    'http': self.proxy_url`
     
16.  `}`
     
```

或许有同学会注意到这里使用的是 `socks5h://` 协议，那么 `Requests` 模块文档中有注解。因为常规DNS服务器并不能解析 `*.onion`地址而Tor网络可以。

![](../Images/63a2a3d0183cfc5af6c22afc83479c75.png)

而后我们需要注册，这里要注意的在正式进入注册界面之前需要先同意一个xxx协议，而这过程为一个Post请求。

![](../Images/638ab314b3585abcb3d67f92dd3c63c3.png)

并且根据多次测试得出，如果不先发送该请求，则无法进入注册界面。考虑到这里使用的为Form Data，那么源数据就直接存在于HTML中。

> 因后续注册，登录均使用Form，表单位置不再赘述

![](../Images/b74aa13ab0cf6e6158bea87ba6c8052f.png)

于是我们使用 `css selector`语法来取到各个字段，通过正则取到 `sid`

```
1.  `# 取到sid`
    
2.  `self.sid = re.findall('sid=(.*?)"', step1resp)[0]`
    
3.  
    
4.  `# 取到token`
    
5.  `token = step1('input[name="form_token"]').attr('value')`
    
6.  
    
7.  `# 取到creation_time`
    
8.  `creation_time = step1('input[name="creation_time"]').attr('value')`
    
9.  
    
10.  `# 生成URL`
     
11.  `url = f"http://{self.domain}/ucp.php?mode=register&sid={self.sid}"`
     
12.  
     
13.  `# 发送请求`
     
14.  `step2resp = self.session.post(url, data={`
     
15.  `    "agreed": "===好的,我已明白,请跳转到下一页继续注册====",`
     
16.  `    "change_lang": "",`
     
17.  `    "creation_time": creation_time,`
     
18.  `    "form_token": token`
     
19.  `}, headers=headers)`
     
```

接下来我们成功得进入到了注册界面，这里要注意的是用户名密码需要同时包含大小写字符及数字，范围6-20，于是我们准备一个随机密码生成器

```
1.  `@staticmethod`
    
2.  `def RandomKey(length=20):`
    
3.  `    return ''.join((random.choice(random.choice((string.ascii_uppercase, string.ascii_lowercase, ''.join(map(str, range(0, 9)))))) for i in range(1,  length)))`
    
```

并模拟注册过程。

```
1.  `# 获取第二步的resp内容`
    
2.  `step2 = jq(step2resp.text)`
    
3.  
    
4.  `# 取到新token`
    
5.  `token = step2('input[name="form_token"]').attr('value')`
    
6.  
    
7.  `# 取到创建时间`
    
8.  `creation_time = step2('input[name="creation_time"]').attr('value')`
    
9.  
    
10.  `# 随机账户`
     
11.  `self.usr = self.RandomKey()`
     
12.  `self.pwd = self.RandomKey()`
     
13.  
     
14.  `# 生成payload`
     
15.  `data = {`
     
16.  `    "username": self.usr,`
     
17.  `    "new_password": self.pwd,`
     
18.  `    "password_confirm": self.pwd,`
     
19.  `    "email": "xxxx@xxxx.xxx",`
     
20.  `    "lang": "zh_cmn_hans",`
     
21.  `    "tz_date": "UTC+08:00+-+Asia/Brunei+-+" + moment.now().format("DD+MM月+YYYY,+HH:mm"),`
     
22.  `    "tz": "Asia/Hong_Kong",`
     
23.  `    "agreed": "true",`
     
24.  `    "change_lang": "0",`
     
25.  `    "submit": " 用户名与密码已填好,+点此提交 ",`
     
26.  `    "creation_time": creation_time,`
     
27.  `    "form_token": token`
     
28.  `}`
     
29.  
     
30.  `# 发送注册请求`
     
31.  `resp = self.session.post(url, data=data, headers=headers)`
     
32.  
     
33.  `# 判断是否注册成功，失败则触发retry重新注册`
     
34.  `assert '感谢注册' in resp.text`
     
35.  
     
36.  `# 成功则保存账户`
     
37.  `DarkNet_User.create(**{`
     
38.  `    'user': self.usr,`
     
39.  `    'pwd': self.pwd`
     
40.  `})`
     
```

然后以下是实际注册效果。因为使用的是佛系注册策略，所以有那么多。。

![](../Images/4c0876ab74160471404818f44abc438d.png)

在注册完成之后我们需要开始进行登录操作。

```
1.  `# 登录URL`
    
2.  `url = f'http://{self.domain}/ucp.php?mode=login'`
    
3.  
    
4.  `# 封装payload`
    
5.  `data = {`
    
6.  `    "username": self.usr,`
    
7.  `    "password": self.pwd,`
    
8.  `    "login": "登录",`
    
9.  `    "redirect": f"./index.php&sid={self.sid}"`
    
10.  `}`
     
11.  
     
12.  `# 发送登录`
     
13.  `resp = self.session.post(url, data=data, verify=False, timeout=120)`
     
14.  
     
15.  `# 判断是否成功登录`
     
16.  `if self.usr not in resp.text:`
     
17.  
     
18.  `    # 如果被封禁则拉黑该账户并重新注册`
     
19.  `    if "已被封禁" in resp.text:`
     
20.  `        DarkNet_User.update({`
     
21.  `            "useful": False`
     
22.  `        }).where(DarkNet_User.user == self.usr).execute()`
     
23.  `    self.Reg()`
     
24.  
     
25.  `    # 注册完成触发retry`
     
26.  `    raise ValueError`
     
```

接下来我们就取到了登录后的响应界面也就是主页，这里我们可以看到栏目按 `.ad_div_b`来分布。

![](../Images/95091ac46a874f6690b34c4d39855431.png)

并且在查看更多选项为该栏目的详情首页。那么我通过如下代码获取全部的类型

```
1.  `self.types = {item('.index_list_title').attr('href').split('=')[1].split('&')[0]: item('tr:nth-child(1) > td').text().split()[0] for item in jq(resp.text)('.ad_table_b').items()}`
    
```

![](../Images/4c954f2d0825e218bb4b6c016fa47a1c.png)

然后我们迭代这些类型，并将其qeaid、页码page及其他参数代入模板URL，以抓取栏目最大页数及详细列表。

```
1.  `http://{self.domain}/pay/user_area.php?page_y1={page}&q_u_id=0&m_order=&q_ea_id={qeaid}&sid={self.sid}#page_y1`
    
```

![](../Images/557de6ca48b6eb30d81ff902e81118c7.png)

> 在获取页码的时候，我们需要将字符串做一个split+join操作以去除所有的分隔符。

根据分析界面结果得出 `table.m_area_a tr`路径下的每个 `div.length_400>a`元素的href不为空，则为一条数据。根据这样的规则我们编写如下代码，并获取部分基础数据。

```
1.  `for item in jqdata('table.m_area_a tr').items():`
    
2.  `    detailPath = item('div.length_400>a').attr('href')`
    
3.  `    if detailPath:`
    
4.  
    
5.  `        # 组合URL`
    
6.  `        detailsURL = urljoin(resp.url, detailPath)`
    
7.  `        self.GetDetails(detailsURL, {`
    
8.  
    
9.  `            # 保护期，默认一般都为15天`
    
10.  `            'lines':  FixNums(item('td:nth-child(7)').text().replace('天', '')),`
     
11.  
     
12.  `            # 热度，关注人数`
     
13.  `            'hot': FixNums(item('td:nth-child(8)').text()),`
     
14.  
     
15.  `            # 事件标题`
     
16.  `            'title': item('td:nth-child(5)').text(),`
     
17.  
     
18.  `            # 类型`
     
19.  `            'area': item('td:nth-child(3)').text()`
     
20.  `        })`
     
```

在获取箭头指示最大页数后，不断翻页迭代上面的过程以爬取全部页码及类型。

> 需要注意一点，我们获取到的不一定是真实最大页码-。-，在爬行的时候需要判断结果列表是否为空。如果为空则为到达尾页需break跳出

得到列表中的每条数据之后，为了获取详情，我们还需要进一步的其详情界面进行抓取。步骤依然为根据 `css selector`路径来取到数据，不再赘述。

![](../Images/f18798bca4e0447184a658b4385d69a7.png)

> 部分用户填写的出售数量大的超过了限制（过于夸张），这里我们需要默认一个最大值进行处理

当然在取到数据的同时，我们需要判断该数据是否为允许提醒范围内的数据，如果是则通过 `telebot`发送给 `channel`。

```
1.  `# 如果时间A 是在相对今天B天前的0点之前出现，则发送`
    
2.  `if moment.date(A) > moment.now().replace(hours=0, minutes=0, seconds=0).add(days=B):`
    
3.  `    telegram.delay(msg, sid, Config.darknetchannelID)`
    
```

然后我们的客户端就收到了及时的提醒，于是整个项目就完成的差不多了。

# ORM模型

首先我们通过pymysql连接数据库并查询是否存在该库，没有则创建，编码UTF8MB4。

```
1.  `try:`
    
2.  `    con = pymysql.connect(**Links)`
    
3.  `    with con.cursor() as cursor:`
    
4.  `        cursor.execute(`
    
5.  `            f'create database {Config.mysql_db} character set UTF8mb4 collate utf8mb4_bin')`
    
6.  `    con.close()`
    
7.  `except pymysql.err.ProgrammingError as e:`
    
8.  `    if '1007' in str(e):`
    
9.  `        pass`
    
10.  `except Exception as e:`
     
11.  `    raise e`
     
```

在完成创建后我们通过 `peewee`来ORM驱动生成相应表格，以下是相应表的简介。

*   `DarkNet_Saler` 售卖者信息
    
*   `DarkNet_User` 爬虫用户池
    
*   `DarkNet_IMGS` 数据说明信息 (鸡肋)
    
*   `DarkNet_Notice` 消息发送记录
    
*   `DarkNet_DataSale` 信息详情
