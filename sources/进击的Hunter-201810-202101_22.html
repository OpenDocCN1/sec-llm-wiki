查询限制

临时修改方式过于鸡肋这里暂不赘述

修改配置

在末尾添加的命令格式如下，详见 limits.conf

  1. <domain> <type> <item> <value>

  • domian 使用者

    • username 用户名

    • groupname 用户组

    • * 通配

    • ...

  • type 限制类型

    • hard 硬件限制

    • soft 软件

    • - 通配

  • item 配置项

    • core 限制核心文件大小

    • data 最大数据大小

    • fsize 最大文件大小

    • memlock 最大锁定内存

    • nofile 最大打开文件描述符数

    • rss

    • stack 最大堆栈

    • cpu 最大CPU时间

    • nproc 最大进程数

    • as

    • maxlogins 指定非root用户的最多登录次数

    • maxsyslogins 指定非root用户的最多登录总和次数

    • priority

    • locks 最大锁数

    • sigpending

    • msgqueue

    • nice

    • rtprio

  • value 设置值（ -1, unlimited, infinity 为无限制 ）

于是我们打开该文件并在末尾加上如下配置并重新打开终端。

  1. * - nofile 20480
