# 信安世纪&郑州工商学院2022学生实习线上启动会成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNTk2MDAwNA==&mid=2247486046&idx=1&sn=1dc933bc7254bc3fa7a23649ddeff693&chksm=9729ac75a05e25633a7dc7a19cd01f93426f5779049844ce987a725855eeff2a782f9f31677c&scene=126&sessionid=1681655807#rd](http://mp.weixin.qq.com/s?__biz=MzIwNTk2MDAwNA==&mid=2247486046&idx=1&sn=1dc933bc7254bc3fa7a23649ddeff693&chksm=9729ac75a05e25633a7dc7a19cd01f93426f5779049844ce987a725855eeff2a782f9f31677c&scene=126&sessionid=1681655807#rd)

![](../Images/f6651771190e0769f3dc85c9634cc06b.png)

2022年10月19日，郑州工商学院信息工程学院、信安世纪克服疫情等不利因素，共同举办实习生线上启动会，郑州工商学院信息工程学院汪金龙院长、网工系康利娟主任、河南信安世纪科技有限公司安全服务部总监符加龙、校企合作部总监常玉存、实习指导老师、实习生等二十余人出席活动。

![](../Images/03713d71d8de31d1ccf11dd46ea3ce29.png)

启动会上，符总介绍了本次实习的整体安排，包括岗位、实习薪资、工作内容、实习要求、公司企业文化等，重点提出实习期间个人身份要完成由学生到工程师、由学校到企业的转换。汪院长明确信安世纪是学校校企合作的优质客户，希望双方的合作能够进一步加强，同时对学生在实习期间的工作提出了若干要求：要将学校素质教育中的好习惯带到工作中，能够积极为企业做出贡献，同时要注意安全，遇见各种问题及时求助企业领导或学校老师等。

![](../Images/63286980c3caf2aff2f30c22d74fda51.png)

本期信安世纪共为学校毕业生提供10个安全服务实习岗位，基于疫情因素，相关学生实习工作将基于线上开展，后续校企双方将以实习基地建设作为抓手，在教师能力、学生实习、项目合作等方面进一步推动全方位、深入合作。
