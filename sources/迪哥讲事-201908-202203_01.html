背景

今天主要介绍两个有关gitlab的ci/cd相关的漏洞, 两个漏洞有点类似，故放在一起进行对比

登场的第一位小哥的名字叫做albatraoz,在2021年2月份的时候提交的这个漏洞,先概述一下这个漏洞:

当一个公共项目将分析设置设置为只有项目成员时，整个页面的分析部分对UI上的非成员是不可见的。但是由于graphql中的一些访问控制问题，非成员可以很容易地访问ci/cd和管道分析。

复现步骤

1.创建一个公共项目;

2.设置:项目设置>通用>可见性，项目功能，权限>仅将分析设置为项目成员( project settings > General > Visibility, project features, permissions > Set Analytics to only project members)。

3.打开另一个非会员帐户同时尝试访问上述项目的分析页面，你会看到404页面未找到。

可以尝试访问https://gitlab.com/adarshshetty18/analytics/-/pipelines/charts &你会看到一个404错误。

当然也可以使用graphql资源管理器更容易复现:

我只使用了两个字段来显示数据，我们就可以使用查询pipelineAnalytics下的所有字段。


query
{
  project(fullPath: "adarshshetty18/analytics")
  {
    pipelineAnalytics{weekPipelinesLabels weekPipelinesTotals}
  }
}

背景

第二位小哥的名字叫ashish_r_padelkar, 目前暂时在gitlab官方的bbp上面排名第一,这个漏洞和上面的那个漏洞有点类似:

根据用户权限方面的文档, Guest应该不能看到View CI/CD分析，但是Guest可以在私人项目中看到CI/CD分析。

复现

以guest的身份登录,那么在私人项目，你可以看到CI/CD分析选项，并可以浏览!
