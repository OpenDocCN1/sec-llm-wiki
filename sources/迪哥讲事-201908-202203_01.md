## 背景 

今天主要介绍两个有关gitlab的ci/cd相关的漏洞, 两个漏洞有点类似，故放在一起进行对比

登场的第一位小哥的名字叫做albatraoz,在2021年2月份的时候提交的这个漏洞,先概述一下这个漏洞:

当一个公共项目将分析设置设置为只有项目成员时，整个页面的分析部分对UI上的非成员是不可见的。但是由于graphql中的一些访问控制问题，非成员可以很容易地访问ci/cd和管道分析。

2.设置:项目设置>通用>可见性，项目功能，权限>仅将分析设置为项目成员(` project settings > General > Visibility, project features, permissions > Set Analytics to only project members`)。
