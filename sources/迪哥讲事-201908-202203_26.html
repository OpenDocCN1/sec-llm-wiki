前言

之前做开发的时候,由于部署的需要,经常会和Docker打交道,有的命令经常会用到,但是现在用Docker用的少了,经常会忘掉,特此记录一下,将常见的Docker命令记录一下.

常见的Docker命令汇总

镜像类常用操作


docker pull images  (拉取镜像)
docker images  (列出镜像)
docker rmi image-id (删除镜像)

容器类常见操作

docker ps  (查看容器)
docker run (创建并启动容器)
docker start contain-id (启动容器)
docker stop contain-id  (停止容器)
docker rm contain-id     (删除容器)

docker exec    (进入容器内部,这个命令很重要)


常见使用例子

eg1. 利用Docker开启服务

docker run -p 6379:6379 --name myredis -v  ~/docker/redis:/etc/redis/redis.conf -v ~/docker/redis/data:/data -d redis redis-server /etc/redis/redis.conf
各个参数说明:
docker run redis # 从redis镜像运行容器
-p 6379:6379 # 映射本地6379端口到容器6379端口，前为本地端口
--name redis # 设置容器名称为redis，方便以后使用docker ps进行管理
-v ~/docker/redis/redis.conf:/etc/redis/redis.conf # 关联本地~/docker/redis/redis.conf文件到容器中/etc/redis/redis.conf，同样，前为本地
-v  ~/docker/redis/data:/data # 关联本地~/docker/redis/data到容器内/data目录，此为存放redis数据的目录，为方便以后升级redis，而数据可以留存
-d # 后台启动，使用此方式启动，则redis.conf中daemonize必须设置为no，否则会无法启动
redis-server /etc/redis/redis.conf # 在容器内启动redis-server的命令，主要是为了加载配置

eg2:利用Docker进入指定容器内部

docker exec -it  <目标容器ID> <目标命令>
例如:
docker exec -it xxxyyxxx bash

eg3.利用docker启动MySQL

docker run --name wxshop_mysql -v `pwd`/mysql-data:/var/lib/mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=wxshop -d mysql

-d: 后台运行容器，并返回容器ID；
-e：容器运行的环境变量
注意:MYSQL_DATABASE指的是创建的数据库的名字,而非容器的名字！！！

运行完之后，发现开启了:

eg4.利用Docker部署一个Java应用

vi dockerfile
docker build . -t wxshop   （这里wxshop是一个应用名）
vi config/docker-application.yml//复制application.yml,将里面的localhost改成宿主机的
docker run -p 8082:8080 -v `pwd`/config/docker-application.yml:/app/config/application.yml -it wxshop

eg5.利用Docker进行nginx部署

vi config/nginx.conf//需要上nginx官网查询
docker run -p 80:80 -v `pwd`/config/nginx.conf:/etc/nginx/nginx.conf:ro -it nginx
