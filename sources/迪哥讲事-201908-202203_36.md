## clone 到本地 

利用 IDEA 可以将 fork 的分支 clone 到你的本地；

![](../Images/77839c610db5860ad2e40b5c76eeb57e.png)

如果用命令行的话就是`git clone xxxx`命令;

## 切换分支 

你想到修改人家的代码首先要自己创建一个分支同时切换到这个自己创建的分支上面; 这里介绍两种方法:

1.  直接利用 IDea 的图形界面：

![](../Images/94c6eed42c6502dc46730af34bd9f2e2.png)

2.  直接利用命令创建并切换到当前分支上面：（本人更喜欢这一种）

```


$git checkout -b anotherbranch
```
