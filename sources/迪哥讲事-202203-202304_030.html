申请 Azure OpenAI GPT-4

首先是如何申请 Azure OpenAI GPT-4。

简单来说，分三步走：

  1. 注册 Azure 订阅

  2. 申请 Azure OpenAI Service

  3. 申请 Azure OpenAI Service 的 GPT-4

注册 Azure 订阅

你需要注册的是国际版的 Azure。

可以访问这个链接进行注册（需要绑定国际信用卡）：

https://azure.microsoft.com/free/cognitive-services

如果你是学生的话，还可以尝试通过 Azure for Students 免费注册，且无需绑定信用卡：

https://azure.microsoft.com/zh-cn/free/students/

申请 Azure OpenAI Service

有了 Azure 订阅之后，就可以访问 https://aka.ms/oai/access ，填写表单来申请 Azure OpenAI Service 了。

注意：申请时候的邮箱需要填写公司邮箱而不是个人邮箱。

我申请的比较早，是一月份申请的，大概一周就申请成功了。最近申请的，据朋友说，可能要等待两周。

申请 Azure OpenAI Service 的 GPT-4

最后，就是申请 Azure OpenAI Service 的 GPT-4 了，访问链接进行申请：

https://aka.ms/oai/get-gpt4

我大概等了 10 天，收到邮件，申请成功！


使用 Azure OpenAI GPT-4

接下来，我们来看看如何使用 Azure OpenAI GPT-4 吧！

Azure OpenAI Service 提供了 Python SDK、C# SDK 和 REST API，为了照顾到不同技术栈的朋友，我们就以 REST API 为例吧！

我已经把源代码和详细步骤放在了：

https://github.com/formulahendry/openai-examples/tree/main/azure

大家可以关注这个 repo，查看更多 OpenAI 相关的代码示例：

https://github.com/formulahendry/openai-examples


首先，我们需要根据这个文档  ，创建一个 Azure OpenAI Service 并部署一个 GPT-4 的模型：

https://learn.microsoft.com/en-us/azure/cognitive-services/openai/how-to/create-resource


然后，我们就来看看如何运行 Azure OpenAI GPT-4 的代码。

1. 安装 Python

2. 下载源代码：

git clone https://github.com/formulahendry/openai-examples

3. 切换到 azure 目录

cd openai-examples/azure

4. 安装依赖：

pip install -r requirements.txt

5. 拷贝 .env 配置文件：

cp .env.example .env

6. 在 .env 文件中，设置 API_KEY、BASE_URL、DEPLOYMENT_NAME_GPT4。

7. 运行代码：

python gpt4.py


大功告成！
