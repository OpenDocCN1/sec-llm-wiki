## **申请 Azure OpenAI GPT-4**

首先是如何申请 Azure OpenAI GPT-4。

简单来说，分三步走：

1.  注册 Azure 订阅
    
2.  申请 Azure OpenAI Service
    
3.  申请 Azure OpenAI Service 的 GPT-4
    

### **注册 Azure 订阅**

你需要注册的是国际版的 Azure。

可以访问这个链接进行注册（需要绑定国际信用卡）：

https://azure.microsoft.com/free/cognitive-services

如果你是学生的话，还可以尝试通过 Azure for Students 免费注册，且无需绑定信用卡：

https://azure.microsoft.com/zh-cn/free/students/ 

### **申请 Azure OpenAI Service**

有了 Azure 订阅之后，就可以访问 https://aka.ms/oai/access ，填写表单来申请 Azure OpenAI Service 了。

![](../Images/955b54f827badcf15fc62f9ebec81893.png)

注意：申请时候的邮箱需要填写公司邮箱而不是个人邮箱。

我申请的比较早，是一月份申请的，大概一周就申请成功了。最近申请的，据朋友说，可能要等待两周。

### **申请 Azure OpenAI Service 的 GPT-4**

最后，就是申请 Azure OpenAI Service 的 GPT-4 了，访问链接进行申请：

https://aka.ms/oai/get-gpt4

![](../Images/360ca645e58e90dec00ba09df6fba68e.png)

我大概等了 10 天，收到邮件，申请成功！
