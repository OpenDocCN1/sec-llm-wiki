今天介绍两款 AI 工具

  • GitHub Copilot X：目前需要申请，估计不会免费

  • Bloop：不用申请，免费好用，也提供了收费版


GitHub Copilot X = GPT-4 + Copilot

这应该是今天 Hacker News 上最火的新闻了，一共有 988 个赞和 693 个评论。

目前的 Copilot 采用的是 OpenAI Codex 模型（属于 GPT-3 的后代），也是由微软和 OpenAI 合作开发的，而下一代的 Copilot X 不仅采用了OpenAI的最新 GPT-4 模型，还会引入了聊天和语音功能，并可以改善 pr、命令行和文档的体验。

举例来说：

你只需要选中代码，然后在聊天窗口中说：给我的代码改 bug。然后 Copilot X 就会分析你的代码并给出修改后的版本。

目前该功能可以深度集成到微软家的编辑器 VSC 和 VS 中（并不只是聊天这么简单），你可以打开下面的连接申请体验：

github.com/github-copilot/chat_waitlist_signup/join

另外，微软还透露 Copilot 可以自动在 GitHub 上面提交 pr，未来项目管理员只需要启用这一功能，人类不需要写代码了，只需要看 AI 炫技就行（其实就是 Code Review 啦）。


Bloop - 基于 AI 的代码搜索工具

目前免费，直接说怎么用它：

1. 下载客户端 github.com/BloopAI/bloop/releases

2. 选择 GitHub 仓库或者本地仓库（可能需要给 bloop.exe 开代理来加速）

3. 用英文提问。


以我的山竹记账项目为例（我把英文翻译成了中文）。

问：这个项目用的是什么语言？

答：使用了 TypeScript，JS 的超集。

问：这个项目在哪里处理了新增账目？

答：useCreateItemStore.tsx 文件中的 useCreateItemStore 函数处理了新增账目，它管理着新增账目的 data 和 error，并提供了 setData 和 setError 用来更新数据和错误。

问：What if I want to delete a tag?

答：可以看看 TagsEditPage 组件。当你点击 delete 按钮时会触发 onDelete 函数。该函数使用 useAjax 提供的 destroy 方法向 /api/v1/tags/${id} 发起请求以删除该标签。

问：你觉得 TagForm.tsx 的代码质量怎么样？

答：作为一名 AI，我没有观点，但我可以分析 TagForm.tsx 文件。它看起来结构良好、易读。代码使用 TypeScript、React hooks，并遵循处理表单提交、验证和错误处理的良好实践。然而，要进行更全面的分析，例如性能或可维护性方面，需要对整个代码库进行完整的审查。


我发现两个有意思的点：

  1.  它虽然不懂中文提问，但是却知道删除按钮上面的文字是 delete 的意思。 

  2. 我问它怎么评价我的整个代码仓库，它表示评价不了，必须指明文件名它才能评价。
