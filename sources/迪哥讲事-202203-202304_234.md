## useState想要保存函数的坑 

先要明确一个概念:

![](../Images/4620a8c5a9121c5ba0c28fd567495a1d.png)![](../Images/ceae7eeac613e8fcf9c9d7258a77becd.png)

useState右边括号中初始值为类似0这种类型的时候,其左边数组中初始值的类型也就为对应的number类型;

用一句简单的话来说,右边赋什么,左边就是什么,也就是说useState是能存储这些数据的,但是有一种类型除外,就是函数,见下图

![](../Images/918d460b17500135d80a2cad880bc8c7.png)

当右边为函数的时候,左边居然为void类型,怎么解决??

![](../Images/c3619df8fbb2c0fbda9dab70bb36550e.png)

只需将你想要保存的函数作为返回值即可!(其实这里利用了惰性加载,参见例a旁的注解)

```
  const [fn,setFn ] = React.useState(()=>()=>

{});
```

### 使用useRef的解决方案

使用useRef解决这个问题的坑:

```
import React from "react"
;import "./styles.css"

{const callbackRef = React.useRef(() =>
 {"I am init function"

 callback = callbackRef.currentconsole.log("callback: "

, callback);return

 (callbackRef.current=() => alert("update function"))}></button>
```

![](../Images/d8e6ad2bd65d13029261faab7996ddf6.png)

上面问题的原因是什么?

useRef不是state,用useRef定义的只是普通的变量,不是本组件的状态,useRef这个容器里保存的值改变的时候,state不会改变,故不会触发渲染;

故s12处的callback还是第一次渲染时的callback!怎么解决这个问题??

只要将改变之后的`callbackRef.current()`重新读取出来即可,而不是读取之前的那个值

```
import React from "react"
;import "./styles.css"

;export default function App4() 
{const callbackRef = React.useRef(() => alert("I am init function"

));const

 callback = callbackRef.current;console.log("callback: "

, callback);return
 (<div className="App">
<button
onClick={() =>

 (callbackRef.current = () => alert("update function"))}</button>

<button onClick={() => callbackRef.current()}> call callback </button>
<h1>Hello CodeSandbox</h1>
<h2>Start editing to see some magic happen!</h2>
</div>


```
