## 背景 

当创建一个RDoc wiki页面时，可以使用大量的html标签和属性，这些标签和属性通常是经过过滤的，当创建一个可链接的图片格式为`{<img src>}[link]`例如，可以在创建图像链接时指定一个class属性:

```


{
```

将产生以下内容:

```


<div class="md md-file">
```

这将放置一个链接接管整个页面并拦截任何点击，`atwhot -view select2-drop-mask pika-select`只是一些真正的类属性(class), 使链接的z-index值最大(注意:这个是css的知识,主要是使其处于最顶层)

目标属性也可以设置为\_blank，由于没有rel="noopener"，也可以使用反向选项卡。

另一种更可能奏效的攻击是在模式中创建一个表单，它可以用来提交用户名和密码:

```


a form
```
