## 背景 

ryhmnlfj小哥于2022年1月份提交了这个漏洞:

在Markdown中发现了存储型XSS; 在某些条件下,可以实现权限提升;

## 复现步骤 

受害者:

1.以受害者的身份登陆gitlab;

2.创建一个任何人都可以创建issue的公共项目;

3.在创建过issue之后，退出账号;

攻击者:

1.以攻击者的身份登陆gitlab;

2.创建一个私有项目;

3.在创建私有项目之后，从浏览器地址栏中显示的URL记录下\[FULL\_NAMESPACE\]。

![](../Images/9d0a4315dbc7c1a19d8633fc4e2ef6a5.png)

4.跳转至 `issue>Milestones`而后点击`New milestone`按钮;

5.用下面的标题创建一个里程碑:

```

New Milestone &lt;script&gt;alert(document.domain)&lt;/script&gt;
```

![](../Images/80628577a62302e0f1aab1105dd1ce2b.png)

图

6.跳转至受害者上面创建项目的 issue页面;

7.通过替换下面的字符串准备新问题(issue)的描述。用在攻击者第三步获取的值替换\[FULL\_NAMESPACE\]

```

[FULL_NAMESPACE]%"New Milestone &lt;script&gt;alert(document.domain)&lt;/script&gt;"
```

替换之后,用这个描述(就是上面一行的描述)创建一个新的issue:

![](../Images/80d87c5993e9ee63bbd4009fb4c38d52.png)

8.登出

victim:

1.再次以受害者的身份登入gitlab;

2.转到攻击者第7步创建的问题页面。XSS将自动执行。

![](../Images/3d76af3e13b4e01874993086614725c1.png)
