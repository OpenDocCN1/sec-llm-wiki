## 前言 

个人识别信息(PII)是任何可能识别特定个人的数据，例如用户名、用户id或任何其他个人信息。PII leak就是这类数据的泄露。

账户劫持是指黑客可以利用应用程序逻辑中的漏洞来完全控制用户的帐户。

## 相关细节 

白帽小哥是从测试重置密码功能开始的,`redacted.com`指的是目标网站, https://redacted.com/forgotpassword 会向注册的邮件地址发送一封电子邮件以更改密码。重置密码链接如下：

```

https://redacted.com/forgot_password/5f12cc7079f273.12051864/ 1597479504 / NTg4NTg4a2lsbGVyQGdtYWlsLmNvbWFzZGZnaGprbDkxODI3Mzc0NjUwMDA=+++NTg4NTg4a2lsbGVy+++NTg4NTg4
```

即使更改密码后链接也没有过期。有点奇怪！。再次请求重设密码给出了以下链接：

```

https://redacted.com/forgot_password/8ac79ccf2a33.12057854/ 1597486704 / NTg4NTg4a2lsbGVyQGdtYWlsLmNvbWFzZGZnaGprbDkxODI3Mzc0NjUwMDA=+++NTg4NTg4a2lsbGVy+++NTg4NTg4
```

需要注意的是，两个链接的 URL 的最后一部分是相同的。 分析一下,发现: 1597486704 → Unix 时间戳 url 的最后一部分是 base64，解码结果如下：`588588killer@gmail.comasdfghjkl9182737465000+++588588killer+++588588`588588 像是我的用户 ID，`killer@gmail.com `是我的电子邮件地址，但是`asdfghjkl9156837463000`看起来像是什么 ？

幸运的是: 只有 URL 的最后一部分，即用户 ID 正在被服务器验证以重置密码。

```

https://redacted.com/forgot_password/5f12cc7079f273.12051864/ 1597479504 / NTg4NTg4a2lsbGVyQGdtYWlsLmNvbWFzZGZnaGprbDkxODI3Mzc0NjUwMDA=+++NTg4NTg4a2lsbGVy+++[VALIDATED_PART]
```

所以现在，如果我知道任何用户的用户 ID，我可以轻松更改他的密码

经过几天的信息搜集，这哥们在一个 javascript 文件中的接口上找到一个 IDOR。该端点只需要 userID 参数，它泄露了许多敏感信息，例如用户名、电子邮件地址甚至属于的住所地址那个用户ID。

```

https://redacted.com/razor/verify_email ?rand= 588588 &request=wcq
```

现在我所要做的就是通过暴力枚举每个用户 ID 的电子邮件地址。\[注意: UserID 1 属于管理员 ;)\]

从端点枚举用户 ID 和电子邮件地址 → 重置密码 → 使用新密码登录 → 完全帐户接管
