### 插入节点

插入前：

```

<div><p>我是段落标签</p>
/div>
```

插入操作:

```
//插入: 在父级c节点下的子节点b之前插入a节点
var div = document.getElementsByTagName('div')[0
];var p = document.getElementsByTagName('p')[0
];var a = document.createElement('a'
);'www.baidu.com'
;//插入: 在父级div节点下的子节点p之前插入a节点


```

插入后:

```

<div><a href="www.baidu.com"></a>
<p>我是段落标签</p>
/div>
```
