## 背景 

根据https://docs.gitlab.com/ee/user/project/members/#import-users-from-another-project的文档,在下拉菜单中，只能看到维护者所在的项目。

一旦从这样的项目导入成员,guest可以看到所有使用email被邀请的pending的成员,但是这些成员还没加入这个项目,也就是说，guest将能够看到所有被管理员通过电子邮件邀请但尚未加入gitlab的成员的电子邮件id。

如果只是在UI界面中直接访问url，是不会看到这些还没有加入gitlab的成员的;

## 复现步骤 

1.作为项目的所有者(owner)，导航至`https://gitlab.com/<YourUserName>/<YourProject>/project_members/import`

2.当单击下拉菜单时，不仅会看到你所维护的项目，而且还会看到所有只担任Guest角色的项目。

3.选择具有Guest角色的项目，并单击Import project Members。

负责此任务的请求是:

```


POST /<YourUserName>/<YourProject>/project_members/apply_import HTTP/1.1  
```

4.可以用公共项目替换上面的`source_project_id`参数，它也会从公共项目导入

5.这将导入尚未加入所选项目的成员的电子邮件id，但是当你从UI界面导航到成员url时，你是看不到的

## POC
