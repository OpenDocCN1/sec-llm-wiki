gitlab漏洞系列-guest用户越权看到标签名称

声明：文章中涉及的程序(方法)可能带有攻击性，仅供安全研究与教学之用，读者将其信息做其他用途，由用户承担全部法律及连带责任，文章作者不承担任何法律及连带责任。

背景

白帽小哥izzsec于2020年3月份提交了这个漏洞:根据文档https://gitlab.com/help/user/permissions的说法，“Guest用户可以访问GitLab release来下载资源，但不允许下载源代码，也不允许看到像标签和提交这样的存储库信息。但是通过查询一个用户有访客访问权限的项目的release api，他们能够看到相关的JSON字段;

复现步骤

1.创建新的私有的项目;

2.添加一个guest用户;

3.跳转至https://gitlab.com///-/releases

4.点击New Release，输入任何标签名，然后点击create tag

5.guest用户转到https://gitlab.com/api/v4/projects/<project_id>/ Releases ?per_page=20发布api页面

6.检查JSON响应并查看_links.self下的标记名

7.使用客户用户令牌查询发布API

curl -X GET -H "Private-Token: <PRIVATE_TOKEN>" https://gitlab.com/api/v4/projects/<project_id>/releases 

8.带有 _links.self的json字段和标签名称:

"_links": {  
      "self": "https://gitlab.com/<group>/<project>/-/releases/<tag_name>"  
    }
