## 背景 

白帽小哥izzsec于2020年3月份提交了这个漏洞:根据文档`https://gitlab.com/help/user/permissions`的说法，“Guest用户可以访问GitLab release来下载资源，但不允许下载源代码，也不允许看到像标签和提交这样的存储库信息。但是通过查询一个用户有访客访问权限的项目的release api，他们能够看到相关的JSON字段;

## 复现步骤 

1.创建新的私有的项目;

2.添加一个guest用户;

3.跳转至`https://gitlab.com///-/releases`

4.点击New Release，输入任何标签名，然后点击create tag

5.guest用户转到`https://gitlab.com/api/v4/projects/<project_id>/ Releases ?per_page=20`发布api页面

6.检查JSON响应并查看`_links.self`下的标记名

7.使用客户用户令牌查询发布API

```
curl -X GET -H "Private-Token: <PRIVATE_TOKEN>"
 https://gitlab.com/api/v4/projects/<project_id>/releases 
```

8.带有 \_links.self的json字段和标签名称:

```
"_links"
: {  "self": "https://gitlab.com/<group>/<project>/-/releases/<tag_name>"

  
```
