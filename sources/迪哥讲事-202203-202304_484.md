## 背景

白帽小哥jafarakhondali在2021年12月份提交了这个漏洞,看到这个漏洞的时候，我的第一反应是: 就这？？是的，就这漏洞，gitlab官方也给了100美刀,可见国外对安全的重视,好了，下面来看看这个漏洞:使用官方文档安装Gitlab runner:`https://docs.gitlab.com/ee/ci/docker/using_docker_build.html#use-docker-socket-binding` 安装好之后,发现允许任何访问Gitlab CI的用户在Gitlab Runner服务器上拥有root权限。

## 复现

1.使用官方文档安装Gitlab-runner ，并运行Docker-in-Docker:

```




sudo gitlab-runner register -n \  
```

然后为runner设置“exploiter”标签，在有权限访问该runner的项目中，输入以下命令:

```

```
