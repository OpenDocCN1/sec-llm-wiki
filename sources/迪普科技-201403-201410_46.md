# 迪普科技负载均衡与安全产品助力国家电网坚强智能电网建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=200154531&idx=1&sn=ffb960182bd3416ea4ab6cff4003032a&chksm=1e279d822950149432a12d1cbad298b6ab08bcf467203a3643131dbfcaafbdcbafd97e83ff2c&scene=126&sessionid=1681369458#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=200154531&idx=1&sn=ffb960182bd3416ea4ab6cff4003032a&chksm=1e279d822950149432a12d1cbad298b6ab08bcf467203a3643131dbfcaafbdcbafd97e83ff2c&scene=126&sessionid=1681369458#rd)

﻿近日，国家电网公司完成2014年信息化技术支持项目专项采购，国内众多知名厂商参与此次投标，迪普科技凭借先进的技术、灵活的方案以及在电网广泛的应用经验，获得负载均衡、防火墙的万兆高端、千百兆款型、入侵检测产品全部份额，保持了迪普科技作为国家电网安全设备主流供应商的地位。

  
本次招标的负载均衡设备、高端万兆防火墙均是部署在生产数据中心、三地容灾中心以及服务器区域的核心位置，一旦出现异常，会产生不可预估的生产事故，国家电网对设备要求非常严格。凭借过硬的产品品质和强大的研发实力，迪普科技赢得了国家电网的青睐。截至2014年，迪普科技负载均衡、万兆应用防火墙、DPX8000深度业务交换网关等高端产品已经全面服务于国家电网核心业务系统，FW、IPS、IDS等全线产品连续四年入围国家电网公司的采购，助力国家电网坚强智能电网的建设。

  
国家电网选择的迪普科技ADX3000系列应用交付产品，集链路/服务器负载均衡和全局负载均衡，支持IPv4/IPv6和丰富路由特性，可满足国家电网的灵活组网方式。同时，迪普科技独创的CAAR（Context-Aware Application Recognition 上下文感知应用识别技术）为国家电网提供应用层专属调度方案，承载于高性能硬件平台和及时贴身服务，使应用交付产品与业务应用完美结合，保证国家电网业务永续。

迪普科技FW1000系列应用防火墙与IPS2000系列入侵检测等安全产品在国家电网已经有了大量部署，具有3.2Tbps的处理性能、丰富的MPLS VPN、IPV6等网络特性，长期稳定运行于国网生产中心、三地容灾中心、各网省电力公司与直属单位的广域网等信息边界，部署上万条策略，为国家电网提供了强大的安全防护。

  
在多年的应用积累中，迪普科技已经全面服务国家电网公司及下属的5个网省公司、27个省电力公司和20个家直属单位，全面参与电网公司的信息化建设。未来，迪普科技将为国家电网持续提供优质的产品、解决方案及服务，为国家电网的信息化和坚强智能电网建设保驾护航。
