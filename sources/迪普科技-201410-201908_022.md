# 迪普科技受邀亮相第十四届中国卫生信息技术/健康医疗大数据应用交流大会暨软硬件与健康医疗产品展览会

6月19日-6月21日，第十四届2019（14th）中国卫生信息技术/健康医疗大数据应用交流大会暨软硬件与健康医疗产品展览会在西安曲江国际会展中心如期举办。本次会议的开展目的旨在进一步落实国家卫生健康委各项工作要求，全力推进全民健康信息化建设与发展，加强健康医疗大数据应用发展，促进信息技术和医疗服务的深度融合。由此，迪普科技作为国内医疗行业网络安全研究的先驱性企业受邀出席了本次展会。

  

展会期间，迪普科技为现场嘉宾带来了自安全园区网解决方案、自安全智能分支机构解决方案、态势感知及安全运营平台、等保小程序等一系列迪普自主研发的解决方案与产品。吸引了大量与会嘉宾的驻足参观与讨论。

  

![](../Images/653ca974f9a6bfa44435bd34b000f3d6.png)![](../Images/8454749d8254ee4c7d0d49691a86e836.png)

6月21日下午三点，由迪普科技参与编写的《医院数据治理框架、技术与实现》于展会上进行了新书发布会，指出在大数据时代下，医疗行业掌握的数据量具备着价值高，保密度强等特点，而如何用好和掌握医疗数据成为了医疗行业发展中需要探讨的重要课题。作为在医疗行业以优秀的产品解决方案和贴近客户需求的服务积累下大量经验的迪普科技为本次书籍的攥写提出了大量的专业建议。

![](../Images/3109fcd48cac47020dba5d492759116d.png)![](../Images/8454749d8254ee4c7d0d49691a86e836.png)

发布会后，迪普科技自安全网络解决方案部部长黄铭恺于网络安全与隐私保护分论坛进行了名为《互联网+医疗健康下的网络安全建设》的演讲。演讲中黄铭恺指出，一方面由于业务需求，部分PC终端的软件管控、杀毒手段在落地使用上困难重重，面对病毒入侵和变种传播缺乏防御能力，另一方面医院放射科CT机、自助终端机等特殊终端甚至无法部署有效防护措施，极易成为内网“病灶”，使内网终端和核心业务暴露于威胁之下，这是医院信息科需要解决的难点之一。  

![](../Images/25a3a3f862cc2e89280d14339da004f1.png)

迪普科技自安全网络解决方案部部长黄铭恺发表名为《互联网+医疗健康下的网络安全建设》的演讲

  

而医院存在大量的异构的终端和业务系统，数量多且分布离散，终端接入管理及网络策略往往依靠信息科人员手动配置。随着“互联网+医疗健康”推进，医院信息科所承担角色的重要性在不断提升；但同时由于医院业务系统固有的复杂性，信息科还需要将大量人力投入在系统运维、网络运维、安全策略等方面，如何实现业务与效率并举是医院信息科需要解决的难点之二。

  

**迪普科技态势感知及安全运营平台**通过采集网络流量、计算环境、资产、业务应用、日志信息、运行状况、脆弱性、安全事件、威胁情报等数据，利用大数据、深度学习等技术，分析整网安全状态和变化趋势，有效识别医院网络中的各类病毒及其变种、入侵威胁、资产脆弱性，并对安全事件进行回溯，对整体网络安全态势全面呈现，为医院网络通报预警和及时响应提供决策支持。

![](../Images/152443e78c8cdd2a6e4606d53a227a8b.png)

**迪普科技自安全园区网解决方案**首先通过自安全交换机的病毒抑制能力，有效控制变种病毒传播，更进一步在医院内的核心业务科室和特殊业务场景提供“协议级”防护能力，针对CT机、CR机、自助终端等仅放通，在不影响医院业务连续性的前提下实现整网“带毒运行”。

 

除此之外，**迪普科技自安全园区网解决方案**为用户提供网络自动部署能力，用户通过自安全管理平台统一配置终端属性后，相应网络配置及策略均跟随终端部署，无需用户手动介入；同时网络自身内置 “互联网+医疗健康”业务模板，新业务上线一键安全互通、快速部署，免除复杂配置。此外，自安全网络管理平台还可以快速定位和处置内网中的ARP攻击、网络环路等常见问题，为管理员定位和处置问题提供有效支撑，实现网络快速排障。

![](../Images/fc0942326600b35e008c492e9961a820.png)

  

未来迪普科技仍将持续深入探索医疗行业应用和需求，不断强化自安全网络方案与业务的耦合关系，为医院用户建设更安全、可视、易运维的网络，为全民健康信息化的发展贡献力量！
