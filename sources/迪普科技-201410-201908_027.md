# 迪普科技荣获2019全国“雪亮工程”十大创新产品奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650330596&idx=1&sn=68706d3166ce07427f1138f96a2758f7&chksm=883155c5bf46dcd391be9b3e90af5aae54f7b369b0fea49dba3b1737db8f58b7e3397af33b07&scene=126&sessionid=1681369407#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650330596&idx=1&sn=68706d3166ce07427f1138f96a2758f7&chksm=883155c5bf46dcd391be9b3e90af5aae54f7b369b0fea49dba3b1737db8f58b7e3397af33b07&scene=126&sessionid=1681369407#rd)

2019年6月12日，经过为期近两个月的案例征集、综合投票、专家评审，由法制日报社主办的2019全国政法智能化建设创新案例征集活动结果揭晓，迪普科技凭借DAC（物联网应用安全控制系统）产品荣获“**2019全国政法智能化建设--雪亮工程十大创新产品**”！

  

![](../Images/6df32355f3fba20e921d5be7e9a33dfd.png)

近日法制日报社举办的“2019全国政法智能化建设创新案例征集活动”，旨在深化政法智能化建设，推动社会治理现代化，开创平安中国新境界，对新的科技应用和成熟方案进行成果展示，进一步调动科研单位、企业参与政法智能化建设的积极性，提供更好的方案和科技支撑，为政法单位、科技企业搭建一个经验交流、技术对接平台。活动共征集政法单位创新案例222个，企事业单位解决方案189个、创新产品151个，根据评审规则，综合投票、专家评审，评审出雪亮工程、智慧法院、智慧检务、智慧警务、智慧司法十大创新案例、十大解决方案提供商及十大创新产品。

  

在”雪亮工程“领域，迪普科技凭借DAC（物联网应用安全控制系统）产品荣获“**2019全国政法智能化建设--雪亮工程十大创新产品**”！

据安全牛于5月21日发布了《中国网络安全细分领域矩阵图》(Matrix 2019.05)，本次调查数据的时间区间为2018年全年，调查对象为国内市场上相应细分领域的网络安全公司。其中，视频监控安全矩阵（VMS, Video Monitoring Security Matrix）显示，在视频监控安全市场，**迪普科技影响力和市场规模均排名第一**。

作为“雪亮工程”整体安全体系建设的领导者，迄今为止，迪普科技已服务于全国200余个“雪亮工程”“平安城市”及“智能交通”项目建设，深受用户的信赖与肯定，我们将始终以“严控边界、纵深防御、主动监测、全面审计”为要求，持续创新，以最优秀的产品解决方案和服务，为社会公共安全建设贡献自己的力量。

  

![](../Images/3de60b9f7abebd976a23cea5bd02d984.png)

**预告**

7月3日至4日，全国政法智能化建设研讨会、全国政法智能化建设技术装备及成果展、首都公共安全防范建设应用成果展将在北京中国国际展览中心(静安庄馆)举办，迪普科技诚邀您莅临展会现场，见证迪普科技在雪亮工程及政法行业信息化建设中所取得的成就，探讨政法行业信息化建设的新方向。

  

**中国国际展览中心3号馆B19展位**，迪普科技与您不见不散！
