# 迪普科技IPv6一站式升级解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650329973&idx=1&sn=33bbe848205208cd8ec1e634c12e6a48&chksm=88315354bf46da4245c56d796daf76c8f5e95e0ff3b3d0ebd85385b9be6eadf0a44ea85cb596&scene=126&sessionid=1681369416#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650329973&idx=1&sn=33bbe848205208cd8ec1e634c12e6a48&chksm=88315354bf46da4245c56d796daf76c8f5e95e0ff3b3d0ebd85385b9be6eadf0a44ea85cb596&scene=126&sessionid=1681369416#rd)

由于互联网的飞速发展，IPv4地址即将面临耗尽，IPv6是下一代互联网部署的最佳解决方案。

  

2017年11月26日，中共中央办公厅、国务院办公厅印发了**《推进互联网协议第六版（IPv6）规模部署行动计划》**，明确针对互联网应用、网络基础设施、应用基础设施、网络安全、关键前沿技术等领域进行IPv6升级。

  

  

**建设目标及难点：**

  

针对企业用户IPv6的升级部署，首要目标是各网站及应用系统支持通过IPv6网络进行访问。然而，在部署过程中，用户将会遇到以下难题：

  

1、网络环境复杂，除了网络设备、安全设备需要升级为支持IPv6以外，用户的网站、应用程序、数据库等系统均是基于IPv4建设，要在短期内改造成同时支持IPv6和IPv4，难度非常大，建设成本较高；

2、将现网业务直接升级至IPv6，容易产品误操作，甚至导致业务中断，很难做到平滑、无缝的升级；

3、针对IPv6环境下的网络安全防护缺乏有效经验，原有安全产品支持IPv6安全防护效果较差。

  

  

**迪普解决方案：**

  

针对上述难点，迪普科技推出了**一站式IPv6升级过渡解决方案**，能够帮助用户实现快速升级、平稳过渡至IPv6。

  

迪普科技IPv6升级过渡解决方案，可帮助用户实现IPv6的快速、平滑、无缝升级，并从**IPv6链路**、**DNSv6服务器**、**NAT64地址转换**、**IPv6试点区域及迁移**、**IPv6环境下的安全防护**等多方面进行考虑，全面解决用户IPv6升级过程遇到的难题。

  

![](../Images/0231de9bd670cc2fd812b726ef5da4c5.png)

迪普科技IPv6升级过渡方案

  

  

**方案特色：**

  

**1、一站式方案，快速部署**

  

充分考虑到用户IPv6升级所需的所有关键环节，且无需改变现有IPv4网络及业务现状，即可支持基于IPv6的访问，投资成本低，部署简单快速。

![](../Images/d140a6a2015668dee156c86451277ccb.png)

  

**2、平滑升级，无缝对接**

  

建立了IPv6试点区域，可根据实际情况，逐步切换业务系统至IPv6环境，不会影响现有业务，最终实现IPv4到IPv6的平滑升级。

![](../Images/3a503b4ff070783b14daf729438f6e2d.png)

  

**3、基于用户的策略管理和日志分析**

  

由于IPv6地址长度为128位，因此相比以往IPv4“192.168.1.1”这样的地址格式较为复杂，理解起来也比较困难。迪普方案中，设备策略管理及日志分析时，基于用户名而非基于IPv6地址进行管理，将大大减轻用户的管理难度。

![](../Images/580fc754b5b43c487b955c3eb4820e38.png)

  

**4、全面的安全特性**

  

迪普科技各类安全产品，均已通过IPv6 Ready Phase-2认证，可全面支持各种IPv6环境下的安全防护，确保IPv6的网络安全。

![](../Images/0717bb0faeaa110c883c8dc281f97940.png)
