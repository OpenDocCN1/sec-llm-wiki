# \[漏洞预警\]思科网络设备爆出高危漏洞，被黑客利用进行攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650329847&idx=2&sn=34d24a2fd2269738bfbdb0dd4bcfb4f2&chksm=883152d6bf46dbc02a9ed28fb01a359916f208d11a2647aa885f9d9a374f6ccc4ef5c73fc98c&scene=126&sessionid=1681369417#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650329847&idx=2&sn=34d24a2fd2269738bfbdb0dd4bcfb4f2&chksm=883152d6bf46dbc02a9ed28fb01a359916f208d11a2647aa885f9d9a374f6ccc4ef5c73fc98c&scene=126&sessionid=1681369417#rd)

近期，迪普科技安全研究院监测到网络上出现大量针对思科设备（主要为路由器和交换机）的攻击行为，攻击利用到高危级别的Smart Install远程代码执行漏洞(CVE-2018-0171)，该漏洞可以造成执行任意代码、拒绝服务、未授权访问等攻击效果。包括俄罗斯、伊朗等多国网络设施已受到攻击，受攻击的设备无法正常工作，并且设备管理页面上会显示出美国国旗，近期国内网络设备也受到了该漏洞的攻击。

  

![](../Images/3b7b8f4e1b448e3bd1b1babb9755a25a.png)

  

  

**漏洞详情**

  

Smart Install是思科网络设备进行镜像管理和即插即用配置的模块，通过TCP 4786端口对外提供接口，Smart Install模块的代码存在缓冲区溢出漏洞，黑客可以向4786端口发送精心构造的数据包触发漏洞，绕过设备的身份验证机制，重载设备并造成设备无法正常工作的效果，甚至可能进一步进行任意代码执行攻击。

  

鉴于漏洞攻击代码已公开，并且网络上暴露4786端口的思科设备数量较多的情况，预计短期内将有更多黑客进行攻击试探，建议用户及时检查漏洞是否存在和安装补丁修补漏洞，消除安全隐患。

  

**漏洞自查**

  

Smart Install远程代码执行漏洞存在于安装了受漏洞影响的Cisco IOS 或者IOS XE软件版本、并且开启了Smart Install client特性的设备。可以采取远程或本地两种方式检查：

  

**远程检查**

  

① 检测内网所有开启了4786端口的设备，

    使用命令

**nmap -p T:4786 10.121.10.0/24**

  

② 对开启4786端口的设备，可采用脚本进一步检查，脚本地址为https://github.com/Cisco-Talos/smi\_check，下载到内网的计算机，

输入检测命令进行漏洞检查（其中10.121.10.254为待检查交换机ip地址）

**python smi\_check.py –i 10.121.10.254**

  

**本地检查**

  

① 登录设备输入show version命令，获取到Cisco IOS 或者IOS XE软件版本，

如下图版本号为**15.5(2)T1**

![](../Images/00c847dd7bbcce1fd04272ebcb40fff7.png)

访问：

https://tools.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-20180328-smi2，

页面的中下部分存在检测按钮。

![](../Images/b6c252c3a3bd8bb11e8ce7f984fcfd59.png)

输入软件版本号进行查询，点击check后会跳转到软件版本安全建议页面，若页面出现类似字样，说明软件版本受到此漏洞影响

**Cisco IOS and IOS XE Software Smart Install Remote Code Execution Vulnerability**

![](../Images/407a63b4ba8a897bbc69000a10b6524a.png)

  

② 对受漏洞影响的软件版本，需进一步在设备命令输入show vstack config命令，查看漏洞相关特性是否开启，

**switch1#show vstack config**

**Role: Client (SmartInstall enabled)**

若出现”SmartInstall enabled”字样，说明特性已开启，当前检查的设备受Smart Install远程代码执行漏洞影响。

  

**设备型号对比检查**

  

下表为已知的受漏洞影响的部分设备型号：

  

**Cisco Catalyst 4500 Supervisor Engines**

**Cisco Catalyst 3850/3750/3650/2960/2975 Series**

**Cisco IE 2000/3000/3010/4000/4010/5000**

**Cisco SM-ES2/SM-ES3/SM-X-ES3 SKUs**

**Cisco NME-16ES-1G-P**

  

**迪普科技解决方案**

  

迪普科技安全研究院监测到Smart Install远程代码执行漏洞后，迅速采取了应急措施。  

  

目前DPtech IPS2000、FW1000可对该漏洞进行有效防护，对应特征库版本号如下：  

◆产品系列：**IPS2000，FW1000**

◆漏洞库版本：**IPS-R2.1.201，IPS-R3.1.35**

  

DPtech Scanner1000可对该漏洞进行检测，帮助用户提前发现系统风险。对应漏扫库版本号如下：

◆产品系列：**Scanner1000**

◆漏扫库版本：** Scanner1000-R2.2.29**
