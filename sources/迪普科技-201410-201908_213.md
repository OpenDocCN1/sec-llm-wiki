# 与其纸上谈兵，不如有效行动 —迪普科技“永恒之蓝”应急处置案例分享

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650328967&idx=1&sn=809814f7ff457b8b2eaae62b3aa958c9&chksm=88314fa6bf46c6b0f8edb424b1ea54ad47723c4ef575feab089ccf2a7acb48b7682120ca2be0&scene=126&sessionid=1681369425#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650328967&idx=1&sn=809814f7ff457b8b2eaae62b3aa958c9&chksm=88314fa6bf46c6b0f8edb424b1ea54ad47723c4ef575feab089ccf2a7acb48b7682120ca2be0&scene=126&sessionid=1681369425#rd)

2017年5月15日下午5点，迪普科技安全研究院接到客户报告，某著名三甲医院发生重大信息安全问题，全院的大部分电脑只要接入医院内网就发生蓝屏，导致医院无法开展正常业务，急诊和手术也被迫暂停。

  

![](../Images/91e48f8b0fe9342f8c90a49035baeae9.png)

客户系统出现蓝屏画面

  

  

**迪普紧急响应**

接到该问题报告后，迪普科技安全服务专家迅速赶到客户现场，同时另有三家厂商也在现场一同进行定位分析。

  

迪普科技安全专家在现场了解到了以下情况：

  

医院大部分Windows XP、Win7系统开机不久就会蓝屏，而Win10则不受影响。蓝屏信息为srv.sys文件PAGE\_FAULT\_IN\_NONPAGED\_AREA，该信息与ms17-010漏洞对应的驱动文件符合度高，由此**迪普科技安全服务专家初步推测是勒索病毒远程执行代码失败导致**。

  

随后迪普科技安全专家对该医院的一台Win7电脑打补丁，补丁打完后不再发生蓝屏情况，同时在其内网进行抓包分析。在抓包分析期间，某杀毒软件厂商认为该问题可能是ARP病毒和冲击波病毒造成，而迪普科技通过分析内核dump文件确认蓝屏是由ms17-010漏洞所致(srv.sys驱动中SrvOs2FeaToNt的memmove拷贝数据越界)，而**ms17-010正是近期肆虐全球的“永恒之蓝”所利用的漏洞**。

  

![](../Images/481b488d4a6d849c45b8fa1a4e7fcd9c.png)

抓包分析图

  

完成问题定位后，迪普科技安全专家建议客户首先关闭445端口，然后进行补丁升级。在完成以上操作后，客户网络不再有蓝屏发生。由于客户的文件并未发现有被加密情况，**迪普科技最后分析认为此次攻击是利用“永恒之蓝”ms17-010漏洞进行攻击的蠕虫变种**。

  

在此次应急处置过程中，在客户现场共有四家网络及安全厂家，只有迪普科技的安全专家准确定位出问题，并提出了相应解决方案，客户也对迪普科技的安全服务能力表示高度认可和感谢。

  

在5月12日开始爆发出“永恒之蓝”勒索病毒事件后，迪普科技快速响应，第一时间提出了解决方案，而本次的应急处置事件也再次证明了迪普科技的专业安全能力。
