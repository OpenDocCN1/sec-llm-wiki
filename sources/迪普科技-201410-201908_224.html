预警


北京时间4月14日晚，黑客团体Shadow Brokers （影子经纪人）再次泄露了一份方程式黑客工具包 ，内含 23 个最新黑客工具，并包括大量Windows系统的高危漏洞。


“

漏洞说明


本次公开的黑客工具包包括大量Windows系统的高危漏洞：与SMB/RDP协议相关的远程代码漏洞，域控相关的内网渗透漏洞，权限提升漏洞等。


因国内外大量的服务器都在使用Windows系统，使得这份黑客工具包的威胁程度被无限放大。尤其是其中的远程代码执行高危漏洞，可以直接使Windows服务器沦陷，威力堪比当年的ms08-067。


目前已知受影响的Windows系统版本包括：

Windows NT、Windows 2000、Windows 2003、Windows XP、Windows Vista、Windows 7、Windows 8,、Windows Server 2008,、Windows Server 2008 R2、Windows Server 2012 SP0。


“

漏洞详情


本次公开的工具包中，SMB和RDP协议相关的漏洞威胁程度最为致命。SMB（Server Message Block）协议是微软和英特尔提出的一套共享协议，主要用于局域网内文件共享，打印机共享等服务；RDP（Remote Desktop Protocol）是远程连接其他计算机的协议，用户可以使用这个协议方便地操作远端电脑。


SMB协议和RDP协议前几年都出现过很多大量的高危漏洞，如ms08-067是SMB协议的缓冲区溢出漏洞，能造成远程代码执行漏洞，ms12-020为RDP协议漏洞，能造成拒绝服务漏洞。由于很多服务器都在使用Windows系统，并且会开启SMB服务和RDP服务，可以想象这两个协议的漏洞会造成大量服务器的沦陷。


“

迪普科技修复建议


◆关闭SMB服务（默认139，445端口），和RDP服务（默认3389端口），或者通过防火墙的白名单规则，限制连接ip。
