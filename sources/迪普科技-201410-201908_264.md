# 【聚焦】迪普科技亮相2016第二十届网络新技术与应用年会

2016年11月4日，中国计算机用户协会网络应用分会“第二十届网络新技术与应用年会”在杭州召开。**杭州迪普科技有限公司**（以下简称迪普科技）受邀参加本次会议，并在会议上将“**校园网云平台安全建设解决方案**”与各位与会嘉宾共同分享。  
本届大会以“大数据的创新”为主题，旨在进一步推进计算机网络技术的发展和应用，并为广大科技工作者搭建技术交流平台。  
会上，中国计算机用户协会秘书长唐群与网络应用分会理事长贾卓生首先分别致辞并讲话，中国信息通信研究院技术与标准研究所石友康所长发表了题为《工业互联网技术架构研究》的演讲。  
![](../Images/eb84ad739699a34988e4a8f8cb9a3a7a.png)![](../Images/2dc30f88b58ba0495aeb750fa975af21.png)  
  
迪普科技解决方案部部长任可也以《校园网云平台安全建设解决方案》为主题向各位与会嘉宾进行汇报并作深入探讨 。  
![](../Images/7eebce0f90304c05d4c408f97c30f034.png)

![](../Images/86cd6fa6a2de331386ab319ae094db46.png)

  

**校园网云平台安全建设解决方案**针对校园网云平台应用支撑多、用户服务难、运维工作繁、安全责任大的特点以及建设校园网云平台的四大难点：院系隔离、应用安全、运维管理、业务可用，迪普科技创新性的推出了校园网云平台安全建设解决方案。**该方案的主要特点是以安全为核心来构建校园网云平台，并通过多种核心技术解决校园网云平台的难点**，从而实现整个方案的价值，包括：  
1**运维工作化繁为简**通过**VSM技术**，将两个安全核心虚拟成为一个，通过一个IP对多种安全板卡进行管理，大大减少了核心运维的负荷；还支持**Openstack、Netconf云平台管理**的对接，动态完成安全资源的分配，从而实现各院系自助管理的目标。  
2**用户服务步步提升**应用**流定义技术**，让不同的应用流量流经不同的安全资源，来实现对不同应用的按需防护；**应用负载与虚拟化平台联动**，对报考系统、招生网、网上课堂等业务实现动态的智能感知；还通过与教务系统的深度耦合保证选课期间系统的可用性，大大提升学生对于校园应用的使用体验。  
3** 安全责任清晰可见**将**VxLAN技术**应用于校园网云平台安全建设，实现院系间的安全隔离。同时，通过**安全威胁监测平台**实时地将安全事件呈现给校方管理人员，从而让安全管理变得清晰可见。  
  
如今，迪普科技校园网云平台安全建设解决方案已在包括西南大学等多所985/211高校实现应用，为高校的信息化建设提供了有力的支撑。未来，迪普科技仍将秉持让网络更简单、智能、安全的愿景，持续为用户提供更加优质的服务。![](../Images/dca04d3a1b92174b655a9c8d5f9a53e4.png)
