# 迪普科技全标段中标移动抗DDoS设备集采！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650328583&idx=1&sn=581234af812e2d3fb63781e24db5dc04&chksm=88314e26bf46c730fe9d0c377abed9b2008d99dcc0db85a0b6dc66c27605e5231f58e50d1de2&scene=126&sessionid=1681369431#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650328583&idx=1&sn=581234af812e2d3fb63781e24db5dc04&chksm=88314e26bf46c730fe9d0c377abed9b2008d99dcc0db85a0b6dc66c27605e5231f58e50d1de2&scene=126&sessionid=1681369431#rd)

 日前，中国移动2016年度抗DDoS集中采购工作结束，本次采购共分为两个标段，第一标段为吞吐80Gbps和40Gbps的设备，第二标段为吞吐20Gbps和10Gbps的设备。**杭州迪普科技有限公司（以下简称“迪普科技”）成功中标两个标段，并独家中标第二标段全部份额！**  
随着近几年DDoS攻击频率、攻击流量大小以及攻击复杂度的不断提高，DDoS攻击已经成为最普遍和最难防御的攻击之一。中国移动作为全球领先的运营商，需要在DDoS威胁影响关键业务和应用之前，对流量进行检测并加以清洗，以确保网络正常稳定运行及业务正常开展。所以中国移动对此次集采非常重视，测试过程极为严苛。  
在如此严苛的测试环境下，**迪普科技Guard3000系列产品凭借全面的攻击防范能力和卓越的设备处理性能，顺利通过两个标段测试**。  
这是迪普科技继去年全标段中标之后的又一次全标段中标，凭借扎实的技术及良好的基础设施，迪普科技Guard3000系列产品在抗DDoS功能上有着很强的优势：  
1**异常流量监测**在异常流量监测方面支持深度包检测（DPI）技术、NetFlow/NetStream/nFlow流信息（DFI）等多种监测技术，从而可以对异常流量进行高效地监测，深入识别隐藏在背景流量中的攻击报文；2**攻击防护**通过静态漏洞攻击特征检查、动态规则过滤、异常流量限速、指纹防护等技术，实现多层次安全防护，精确检测并阻断各种网络层和应用层的DDoS攻击以及未知恶意流量，包括SYN Flood、UDP Flood、ICMP Flood、DNS Query Flood、HTTP Get Flood、CC等各种攻击方式；3**设备性能**Guard3000系列产品单台设备处理能力高达400Gbps。再配合灵活的部署模式、丰富的日志与报表，可以很好地适应各种网络，广泛地部署在了运营商的各个重要出口，有效保护网络免遭海量DDoS攻击。  
在今年由Frost&Sullivan刚刚发布的《中国DDoS&WAF独立市场研究报告》显示，**迪普科技以市场占有率32.3%的份额在国内DDoS市场排名第一**。  
在未来，迪普科技仍将秉持让网络更“简单、智能、安全”的愿景，为客户量身打造属于自己的解决方案。在面对未来不断变化的网络安全威胁时，为客户网络的稳定运行保驾护航！![](../Images/0d7a5ab16cae9e9d909854076b4770b8.png)
