# 迪普科技助力国资委、领航“一带一路”数据中心建设

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650328220&idx=1&sn=f004a77e97eade727e220b7118eb5683&chksm=88314cbdbf46c5ab777dc5448980e04d6ad7dbc91e3568838c42727419fc9f058640b128f2a9&scene=126&sessionid=1681369435#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650328220&idx=1&sn=f004a77e97eade727e220b7118eb5683&chksm=88314cbdbf46c5ab777dc5448980e04d6ad7dbc91e3568838c42727419fc9f058640b128f2a9&scene=126&sessionid=1681369435#rd)

![](../Images/a32b64e5cc4d6e0e6f136ec8d9b984d7.png)近日，迪普科技中标国资委“一带一路”数据中心建设项目。“一带一路”数据中心是由国资委新闻中心携手中国国际电子商务中心共同建设、运营维护的，用于承载中央企业各类核心业务。  

该数据中心为新建的大型数据中心，服务于数百家中央企业，对网络、安全设备要求具备高处理性能；对核心交换机等关键节点要求高稳定可靠，不因单点故障影响整网运行。

  

此外，随着后期业务发展及用户数增加，后期扩容需求较大；数据中心还需满足出口流量实时防护，高安全、低时延的要求。

  
![](../Images/9527cfae331feec9f8efdf8e02f3f2d9.png)  

迪普科技通过对“一带一路”数据中心业务的全面梳理、和对上述需求的分析，提供了包括新一代云级业务核心平台DPX 19000、高性能万兆交换机、万兆防火墙和万兆web应用防火墙等设备，分别部署于核心、接入、汇聚、安全边界等关键节点。

  

该方案为“一带一路“数据中心构建了一个功能丰富、性能强劲、安全稳定、自主可控的整体网络基础设施平台，全面保障了中央企业全流程舆情管理业务的高效可靠运行。
