# 迪普科技应邀参加第六届通信行业网络安全年会

2016年4月27日，**第六届通信行业网络安全年会**在四川成都开幕。  
本届会议以**【携手防护 共筑安全】**为宗旨，**“开放 共享——全面促进安全防护”**为主题，围绕“政府主管部门2016年度重点工作部署”、“互联网+时代下网络安全形势”、“网络安全立法及重点法律制度”、“基础电信运营企业安全防护现状、需求及解决办法”、“新技术新业务安全”、“互联网基础资源安全”、“移动应用安全”、“工业互联网安全产业发展”等八个议题进行深入的交流探讨。  
![](../Images/f285ec92b338042defd5b365ec005c1c.png)  
在开放共享的“互联网+”时代下，互联网与传统产业快速融合，网络安全风险迅速升高，网络安全问题日益凸显。  
基于当前的网络安全现状，政府、企业和社会组织在不断增进共识，进一步加强监管和自律，创新管理办法，拓展安全防护的广度和深度。  
为此，本届通信行业网络安全年会得到了政府主管部门的指导和支持，并汇集了政策、标准、技术、市场等相关信息，为政府部门、科研机构、电信运营商、安全企业等单位提供决策参考。  
![](../Images/aeabe956aafebb020e49a3e97a7c3706.png)  
会上，众多演讲嘉宾就网络安全议题发表演讲。其中，中国信息通信研究院网安部主任谢玮就2016年网络安全防护检查新标准进行了解读。  
针对网络安全防护，有嘉宾表示应通过大数据技术应用来防御新的安全威胁；也有嘉宾提出，在机遇与风险并存的互联网+时代，网络安全意识是实现网络安全的关键。![](../Images/0d96fb1619d4dd02ba1dc905e3c92265.png)  
杭州迪普科技应邀参加此次通信行业网络安全年会，对大数据、云计算环境下的网络安全创新性地提出了“云安全、硬实力”解决方案，将安全网关与VXLAN技术的结合，在实现虚机感知和安全隔离目标的同时，解决多租户的安全防护问题，并实现真正意义上的安全资源自动编排配置。![](../Images/8d32f4dff1fd9f57ac2475f349b7eac4.png)未来，迪普科技将继续迈着坚实的步伐，凭借自身富有优势的技术、产品以及坚毅的开拓创新精神，为客户创造更大价值！
