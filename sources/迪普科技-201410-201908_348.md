1.Windows Internet Explorer内存损坏漏洞

  

Internet Explorer是微软公司推出的一款网页浏览器，其7到11的多个版本存在漏洞，允许远程攻击者构造特殊网页，诱导用户访问，从而发起任意代码执行或者拒绝服务（DoS）攻击。该漏洞被称为Internet Explorer内存损坏漏洞。   
IE漏洞常被用于网页挂马和病毒传播，严重威胁用户的系统安全。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
https://technet.microsoft.com/zh-cn/library/security/ms15-106  
2.Adobe公司多款产品缓冲区释放后重用漏洞重用已释放数据漏洞（use-after-free）指的是软件使用到被释放的数据，导致未知错误的漏洞，黑客可以利用该漏洞执行任意代码。   
  
在多个Adobe公司产品中，攻击者可借助带有特制tabStops属性的TextFormat对象通过该漏洞执行任意代码和进行拒绝服务。  
其中Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
https://helpx.adobe.com/security/products/flash-player/apsb15-25.html  
3.Google Chrome Blink 权限绕过漏洞Google Chrome是谷歌公司开发的一款网页浏览器。DOM是文件对象模型的英文缩写，是W3C组织推荐的处理可扩展标志语言的标准编程接口，Blink是chrome中的一套浏览器DOM排版引擎（渲染引擎）。  
  
在Google Chrome 46.0.2490.71之前的版本，Blink源码core/dom/ContainerNode.cpp文件中的ContainerNode::parserInsertBefore函数存在安全漏洞，该漏洞允许远程攻击者借助特制的JavaScript代码绕过同源策略。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
http://googlechromereleases.blogspot.com/2015/10/stable-channel-update.html  
4\. Apple OS X Kernel 本地权限提升漏洞Apple Kernel是美国苹果（Apple）公司为MAC电脑开发的Apple OS X 操作系统中的一个内核组件。  
  
在Apple OS X的10.11.1版本之前的kernel中存在安全漏洞，由于源程序验证Mach任务时存在类型混淆问题，导致本地攻击者可利用该漏洞获取权限。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：https://support.apple.com/zh-cn/HT205375  
5.Microsoft脚本引擎内存崩溃漏洞当5.6到5.8版本的VBScript和JScript引擎在微软Internet Explorer 8至11中使用时存在漏洞，允许远程攻击者构造特殊网页执行任意代码。  
该漏洞源于程序没有正确处理内存中的对象，远程攻击者可利用该漏洞获得与当前用户相同的用户权限。  
  
IE漏洞常被用于网页挂马和病毒传播，严重威胁用户的系统安全。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
https://technet.microsoft.com/zh-cn/library/security/ms15-106  
https://technet.microsoft.com/zh-cn/library/security/ms15-108  
6\. Microsoft Office内存崩溃漏洞微软Office办公套件的多个版本、多款软件中存在漏洞，允许远程攻击者通过精心构造的文档，发起任意代码执行攻击。该漏洞又被称为“微软Office内存崩溃漏洞”。修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
http://technet.microsoft.com/security/bulletin/MS15-110  
7\. Java SE和Java SE Embedded Libraries子组件任意代码执行漏洞在Java SE和Java SE Embedded 多个版本的RMI子组件中存在安全漏洞，导致远程攻击者可利用该漏洞控制组件执行任意代码，影响相关数据的保密性和完整性。修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
http://www.oracle.com/technetwork/topics/security/alerts-086861.html  
8\. Google Android Stagefright 2.0 组件验证绕过漏洞移动设备操作系统Android（安卓）是一个以Linux为基础的开源项目，由Google成立的OHA（Open Handset Alliance，开放手持设备联盟）联盟开发与维护。  
  
Android系统的Stagefright库从Android 2.2 froyo版本开始引入一直使用至当前的Android 5.1 Lollipop版本，为该平台提供所有基于多媒体内容的服务。  
Stagefight 2.0中存在安全漏洞，远程攻击者可利用MP3和MP4文件中特制的数据结构触发该漏洞执行任意代码。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
https://groups.google.com/forum/#!topic/android-security-updates/\_Rm-lKnS2M8  
9\. Xen虚拟化平台虚拟机逃逸漏洞Xen 是由剑桥大学开发的一个开源虚拟机管理产品，Xen目前可以在X86的物理架构上稳定的运行多个虚拟机。   
  
该漏洞存在于Xen Hypervisor的内存管理机制中，基于安全的考虑Xen将页表页面映射为“不可写”，修改页表时只能通过一个严格的检查流程才可以进行操作。然而，为了优化检查步骤提高运行速度，Xen Hypervisor提供快速更新的选择。  
问题在于Xen快速更新的判断例程l2e\_has\_changed(ol2e, nl2e, \_PAGE\_PRESENT)中存在漏洞，导致攻击者最终可以绕过软硬件上的所有安全机制的限制在Xen Hypervisor上下文环境执行任意代码。  
修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
http://xenbits.xen.org/xsa/advisory-148.html  
10\. Google Android Media Projection屏幕录制组件验证绕过漏洞Media Projection是在Android 5.0系统版本新增的屏幕录制接口，正常情况下调用该接口会弹出“xx应用将开始截取您的屏幕上显示的所有内容”的提示框。  
但由于系统没有对提示框内的应用名长度做检查，导致应用名称足够长时，后面出现的“将开始截取您的屏幕上显示的所有内容”提示将消失于用户的可见范围之外，使恶意程序在用户不知情的情况下录制用户手机屏幕。修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：  
https://groups.google.com/forum/message/raw?msg=android-security-updates/\_Rm-lKnS2M8/dGTcilt0CAAJ
