1.Microsoft Windows OpenType Font Driver远程代码执行漏洞

atmfd.dll是Windows NT OpenType/Type 1 字体驱动。字体驱动是用来辅助操作系统显示不同字体的模块。

在Microsoft Windows多个版本系统的Adobe字体管理库atmfd.dll中存在缓冲区下溢漏洞。该漏洞允许远程攻击者利用OpenType字体发起任意代码执行攻击。该漏洞被称为“Microsoft Windows OpenType字体驱动漏洞”。

内核漏洞通常被黑客利用在受害者机器上执行恶意代码，获取机器的完整权限。
修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
https://technet.microsoft.com/zh-cn/library/security/ms15-078

2.Adobe Flash opaqueBackground缓冲区释放后重用漏洞
在Adobe Flash Player某些版本的ActionScript 3的实现中，DisplayObject类存在重用已释放数据（Use-after-free）漏洞。

该漏洞允许远程攻击者利用精心构造的Flash文件引发opaqueBackground属性的错误处理，发起任意代码执行或者拒绝服务（内存崩溃）攻击。

Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。

修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
https://helpx.adobe.com/security/products/flash-player/apsb15-18.html

3.Adobe Flash ActionScript 3 ByteArray缓冲区释放后重用漏洞
在Adobe Flash Player某些版本的ActionScript 3的实现中，ByteArray类存在重用已释放数据（Use-after-free）漏洞。

该漏洞允许远程攻击者借助Flash对象的valueof()基本函数覆盖默认的Flash内容，发起任意代码执行或者拒绝服务（内存崩溃）攻击。该漏洞挂马样本的大规模流出是在2015年7月Hacked Team被黑事件后出现。

Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。

修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
https://helpx.adobe.com/security/products/acrobat/apsb15-15.html

4.OpenSSL 证书验证安全限制绕过漏洞
在OpenSSL的多个版本crypto/x509/x509_vfy.c文件下的X509_verify_cert函数，在可替换证书链的验证过程中没有正确处理X.509的Basic Constraints cA的值，导致远程攻击者可以伪造CA，并通过一个有效的叶子证书绕过检查。
修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
https://www.openssl.org/news/secadv_20150709.txt

5.Cisco IOS和IOS XE Software 拒绝服务漏洞
Cisco IOS和IOS XE Software是思科公司为其网络设备开发的操作系统。

多个版本Cisco IOS和IOS XE Software系统中的TFTP服务器存在漏洞，当远程攻击者通过发送某些特殊构造的参数时，服务器程序处理该请求时没有正确管理内存，导致拒绝服务攻击。该漏洞的Bug ID为CSCuv11991。
修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
https://tools.cisco.com/bugsearch/bug/CSCuv11991

6. Microsoft Windows Remote Desktop Protocol 远程代码执行漏洞
远程桌面协议是从Windows 2000 Server开始由微软公司提供的远程管理计算机的通信协议。

在微软的Windows7 SP1、Windows8等多个版本的RDP(远程桌面协议)的实现中，RDP(终端)服务器在处理数据包时存在一个远程代码执行漏洞，该漏洞允许远程攻击者会话过程中通过发送精心构造的指令，发起拒绝服务和任意代码执行攻击。
修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
http://www.oracle.com/technetwork/topics/security/cpujul2015-2367936.html

7. Java SE和Java SE Embedded Libraries子组件任意代码执行漏洞
Java SE 是基于JDK和JRE用来开发桌面、服务器、嵌入式设备应用的Java平台标准版的简称。

Java SE Embedded则是一款单独针对嵌入式系统开发设计的Java平台。

在Java SE和Java SE Embedded 多个版本的Libraries子组件中存在安全漏洞，导致远程攻击者可利用该漏洞控制组件执行任意代码，影响相关数据的保密性和完整性。
修补建议

8.Google Stagefright Media Playback Engine多个远程代码执行漏洞
Android系统是一个以Linux为基础的开源项目，由Google成立的OHA（Open Handset Alliance，开放手持设备联盟）联盟开发与维护。

Android系统的Stagefright库从Android 2.2 froyo版本开始引入一直使用至当前Android 5.1 Lollipop版本，为该平台提供所有基于多媒体内容的服务。Stagefight中存在大约十几个问题，其中一半以上是由整数溢出引起的远程代码执行高危漏洞。可使远程攻击者在设备上执行任意代码、访问文件等。

9.ISC Bind拒绝服务漏洞
ISC Bind是由美国Internet Systems Consortium(ISC)公司开发和维护的DNS协议开源软件，是世界上最流行的DNS服务器软件之一。

此次在Bind句柄的TKEY查询中出现了一个bug，远程攻击者通过一个简单的UDP报文就可使服务器爆出“assertion failure”错误，让服务器上的DNS服务守护进程崩溃，导致拒绝服务漏洞。
修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
https://kb.isc.org/article/AA-01272

10.OpenSSH键盘交互验证暴力破解漏洞
OpenSSH是SSH协议的免费开源实现，是一款广泛用于Linux系统的安全远程访问软件。

OpenSSH服务器的键盘交互认证模式出现访问控制处理漏洞，由于键盘认证模式的登陆窗口会维持长达120秒并且不会限制尝试次数，可以让攻击者在良好的网络环境下在该段时间内进行上万次的登录尝试，而基于网络连接和受害Linux主机的情况，2分钟的时间内这几千次的密码猜解已经足够让攻击者使用密码字典成功破解一些低复杂度的密码。
修补建议
尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已发布升级补丁，链接：
http://cvsweb.openbsd.org/cgi-bin/cvsweb/src/usr.bin/ssh/auth2-chall.c
