# 迪普科技深度业务交换网关着力优化山东广电IDC与第三方链路出口

山东广电下辖16家市级分公司、1家直属分公司、5家子公司和122家县级分公司，拥有17000多名员工；  
已全面完成全省市、县、乡三级整合，总资产达137亿元，拥有32万公里传输干线和2000万户有线电视用户，用户数量和经营总量位居全国第一。

  

由于用户数量巨大，对网络带宽需求高等原因，山东广电网络时常出现故障。对此，迪普科技利用深度业务交换网关出口链路的负载分担功能，提高出口设备的有效利用率。   
迪普科技DPX8000设备开启智能路由调度功能，将链路和应用进行分类，将P2P、视频等对带宽要求较高且对上网用户不敏感的应用调度到稳定性较差链路；  
同时把游戏、金融、视频会议等对网络质量较敏感的应用调度到稳定性更高的链路，在出口开启网络质量分析功能，对宽带用户的上网质量进行统计分析，总结宽带用户的故障原因，更有针对性地解决山东广电的网络故障。  
  
此外，迪普科技还根据山东广电的实际情况配置丰富的策略，提高省网出口链路的有效利用率，进而提高宽带用户的上网体验。通过上网质量分析系统提高网络故障处理效率，简化网络管理、降低运维成本，实现智能管理。并为山东省全省宽带用户更加优质的互联网应用体验。  
四方面重点工作**智能路由调度。**迪普科技通过高性能专业设备帮助山东广电配置应用交付业务和深度数据分析业务功能，实现对数据流的深度分析与调度，合理利用现有的出口资源，降低出口成本，提升整体上网体验。  
  
**大容量精确溯源。**为保障山东广电用户通过省网出口统一访问互联网，迪普科技采用精确溯源系统，支持大容量NAT的精确溯源，通过为用户分配固定地址端口段的创新技术，大大节约了日志存储空间，并且能够与各项业务系统平滑对接，此外还支持用户精确溯源能力，通过提取各种应用层信息，实现用户认证信息+NAT日志+应用层访问信息的用户深层精确溯源。  
  
**智能的网络故障定位。**为更好地管理运维网络，迪普科技通过对故障进行深度分析、统计，输出数据报表，对山东广电后期网络管理和运维提供指导依据。  
  
**运营商级的可靠性。**迪普科技高性能设别拥有业界领先的全分布式FPGA +多核处理器+Crossbar体系架构，单块业务板即可支持近十万用户的NAT转换，单台设备即可满足百万级别用户的NAT需求，充分保证复杂业务环境下设备性能不受影响。迪普科技设备从运营商级冗余设计到板卡间、设备间的冗余备份技术，实现全方位的系统安全和可靠性，为山东广电网络提供99.999%运营商级可靠性。
