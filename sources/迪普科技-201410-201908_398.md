http.sys远程代码执行漏洞Microsoft Windows

http.sys是Windows操作系统的一个核心组件，能够让任何应用程序通过它提供的接口，以HTTP协议进行信息通讯。  
  
微软Windows操作系统的http.sys模块存在一个漏洞，能被恶意用户利用来攻击远程的IIS服务器。  
该漏洞的原因是在解析HTTP请求时存在错误（http.sys没有正确解析经特殊设计的HTTP请求），可以通过精心构造的数据包发起拒绝服务攻击，甚至有可能造成任意代码执行攻击。该漏洞的利用需要IIS开启内核缓存。  
IIS相关的漏洞经常被利用来攻击Windows网站服务器，严重威胁服务器的安全。

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：https://technet.microsoft.com/enus/library/security/MS15-034

重用已释放数据漏洞Adobe Flash Player

重用已释放数据漏洞（use-after-free)指的是软件使用到被释放的数据，导致未知错误的漏洞，黑客可以利用该漏洞执行任意代码。  
Windows，Linux，OS X系统上的Adobe Flash Player，有多个版本存在“重用已释放数据”漏洞，该漏洞允许攻击者通过构造未定义向量发起远程代码执行的攻击。  
Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。  

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：  
https://helpx.adobe.com/security/products/flash-player/apsb15-06.html

Internet Explorer 内存损坏漏洞Microsoft

微软Internet Explorer 9到11的多个版本存在漏洞，允许远程攻击者构造特殊网页，诱导用户访问，从而发起任意代码执行或者拒绝服务（DoS）攻击。该漏洞被称为Internet Explorer内存损坏漏洞。  
IE漏洞常被用于网页挂马和病毒传播，严重威胁用户的系统安全。  

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：  
https://technet.microsoft.com/security/bulletin/MS15-032

Java VM组件未知漏洞Oracle数据库服务器

Oracle数据库服务器的Java VM组件中存在未知漏洞，涉及到Oracle11和Oracle12的多个版本。该漏洞允许远程的未认证用户影响系统的机密性、完整性和可用性。

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：http://www.oracle.com/technetwork/topics/security/cpuapr2015-2365600.html

重用已释放数据漏洞微软Office组件

在微软Office 2007，Office 2010，Office 2013多个版本的多个应用中，存在“重用已释放数据”漏洞，该漏洞允许远程攻击者通过构造特殊的Office文档发起任意代码执行攻击。该漏洞被称为“微软Office组件重用已释放数据漏洞”。

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：  
http://technet.microsoft.com/security/bulletin/MS15-033

缓冲区溢出漏洞glibc stdio-common/vfscanf.c

glibc是GNU发布的C运行库，C运行库是Linux系统中最底层的函数库，其他的大部分运行库都依赖glibc。  
在GNU C库（即glibc或者libc6)2.21之前的版本中，stdio-common/vfscanf.c文件中的ADDW宏在内存分配时，没有正确地考虑数据类型的大小，从而允许攻击者利用wscanf调用中未正确处理的字符串，发起拒绝服务攻击（缓冲区溢出）或者造成其他的未知影响。  

修补建议尽快更新glibc：Centos/RHEL/Fedora系统：yum update glibcsudo restartDebian/Ubuntu系统：sudo apt-get updatesudo apt-get dist-upgradesudo restart

OpenStack任意shell命令执行漏洞Red Hat

OpenStack是一个开源的云计算管理平台项目，支持几乎所有类型的云环境，项目目标是提供实施简单、可大规模扩展、丰富、标准统一的云计算管理平台。  
红帽系统下，2014.2.13-2之前版本的openstack-puppet-modules中puppet部署文件使用了“CHANGEME”作为pcsd守护进程的默认密码。该漏洞允许远程攻击者通过未知向量执行任意的shell命令。  

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：http://rhn.redhat.com/errata/RHSA-2015-0791.html  

重用已释放数据漏洞FFmpeg

FFmpeg是一套可以用来记录、转换数字音频、视频，并能将其转化为流的开源计算机程序。它包含了非常先进的音频/视频编解码库libavcodec。在FFmpeg2.3.6之前的版本中，libavcodec/h264.c文件的ff\_h264\_free\_tables函数存在重用已释放数据漏洞。该漏洞允许远程攻击者利用MP4文件中精心构造的H.264数据，发起拒绝服务攻击或者造成其他影响。  

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：  
https://github.com/FFmpeg/FFmpeg/commit/e8714f6f93d1a32f4e4655209960afcf4c185214

多个版本未知漏洞Java SE

Java SE是由Sun Microsystems公司于1995年5月推出的Java程序设计语言和Java平台的总称。Sun公司已被Oracle公司收购。Oracle Java SE5-8的多个版本中存在未知漏洞，该漏洞允许远程攻击者通过2D相关的向量发起攻击，影响系统的机密性、完整性和可用性。  

修补建议尽快打上该漏洞官方补丁或者升级到最新稳定版本。补丁获取链接：  
http://www.oracle.com/technetwork/topics/security/cpuapr2015-2365600.html
