# 小迪话安全：三月最值得关注的八个安全漏洞

Microsoft Internet Explorer内存损坏漏洞

漏洞分析：  
微软Internet Explorer 6到11的多个版本存在漏洞，允许远程攻击者构造特殊网页，诱导用户访问，从而发起任意代码执行或者拒绝服务（DoS）攻击。该漏洞被称为Internet Explorer内存损坏漏洞。  
IE漏洞常被用于网页挂马和病毒传播，严重威胁用户的系统安全。  

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：https://technet.microsoft.com/en-us/library/security/ms15-018  

Adobe Flash Player重用已释放数据漏洞

漏洞分析：  
Windows，Linux，OS X系统上的Adobe Flash Player，有多个版本存在“重用已释放数据”漏洞，该漏洞允许攻击者通过构造未定义向量发起远程代码执行的攻击。  
Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。  

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：https://helpx.adobe.com/security/products/flash-player/apsb15-05.html  

IBM SDK Java Technology未知漏洞

漏洞分析：  
在IBM SDK的Java虚拟机中存在未确认的漏洞，涉及到Java Technology Edition的多个版本。  
该漏洞允许远程攻击者发送针对安全管理的未知向量逃逸Java沙箱，并可以执行任意代码。

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补 丁，补丁获取链接：http://www.ibm.com/developerworks/java/jdk/alerts/#IBM\_Security\_Update\_February\_2015  

Microsoft Windows远程桌面协议拒绝服务漏洞

漏洞分析：  
在微软的Windows7、Windows8、Windows Server2012等多个版本的RDP(远程桌面协议)的实现中，存在漏洞。  
该漏洞允许远程攻击者通过建立大量的、没有正确释放内存的RDP会话，引发拒绝服务攻击。该漏洞被称为“远程桌面协议拒绝服务漏洞”。

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁以修复此安全问题，补丁获取链接：http://technet.microsoft.com/security/bulletin/MS15-030

微软Office组件重用已释放数据漏洞

漏洞分析：  
在微软Office 2007，Office 2010，Office 2013多个版本的多个应用中，存在“重用已释放数据”漏洞，该漏洞允许远程攻击者通过构造特殊的Office文档发起任意代码执行攻击。该漏洞被称为“微软Office组件重用已释放数据漏洞”。

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：https://technet.microsoft.com/en-us/library/security/ms15-022  

OpenSSL EVP\_DecodeUpdate拒绝服务漏洞

漏洞分析：  
OpenSSL是一个强大的开源密码库，包括主要的密码学算法，常见的密钥和证书封装管理等功能。  
在OpenSSL的多个版本base64解码的实现中，crypto/evp/encode.c中的EVP\_DecodeUpdate存在整数下溢，该漏洞允许远程攻击者利用特殊的base64数据发起拒绝服务攻击（内存崩溃）或者可能造成其他的未知影响。

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：https://git.openssl.org/gitweb/?p=openssl.git;a=commit;h=d0666f289ac013094bbbf547bfbcd616199b7d2d  

PHP Calendar扩展拒绝服务漏洞

漏洞分析：  
在多个版本的PHP Calendar扩展中存在若干整数溢出漏洞。这些漏洞允许远程攻击者通过特殊的year值发起拒绝服务攻击或者可能造成其他的未知影响。  
漏洞存在于gregor.c的GregorianToSdn函数和julian.c中的JulianToSdn函数。

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：http://php.net/migration56

Apple Safari WebKit内存破坏漏洞

漏洞分析：  
在Apple Safari使用的WebKit的多个版本中，允许远程攻击者通过构造特殊网站页面，发起任意代码执行或者拒绝服务攻击。

解决方案尽快打上该漏洞官方补丁或者升级到最新稳定版本。目前厂商已经发布了升级补丁，补丁获取链接：https://support.apple.com/en-us/HT204560
