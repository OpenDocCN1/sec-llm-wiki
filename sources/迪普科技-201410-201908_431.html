小迪话安全：二月最值得关注的八个漏洞

迪普按
上期，小迪为您公布了迪普科技安全团队推出的2015年2月信息安全研究月报。

根据之前的对比分析可知，在2月知名厂商（产品）新增的漏洞分布中，微软Microsoft公司产品的漏洞数量较多，相对突出。

在今天为您筛选的二月特别值得关注的八个漏洞中，Microsoft独占三例，成为众多厂商中漏洞数量最多的厂商。

下面，让小迪为您仔细分析一下上月出现的八个值得关注漏洞。
Internet Explorer 内存损坏漏洞
Microsoft
微软Internet Explorer 6到11多个版本存在漏洞，允许远程攻击者构造特殊网页，诱导用户访问，从而发起任意代码执行或者拒绝服务（Dos）攻击。该漏洞被称为Internet Explorer内存损坏漏洞。

由于IE漏洞常被用于网页挂马和病毒传播，严重威胁用户的系统安全。

小迪建议尽快打上该漏洞官方补丁或者升级到最新稳定版本，地址： http://technet.microsoft.com/security/bulletin/MS15-009
Windows win32k.sys模块TrueType字体解析漏洞
Microsoft
微软Windows多个版本的操作系统中，内核模式下的win32k.sys驱动模块存在漏洞。该漏洞允许本地用户通过构造特殊的TrueType字体文件获得权限提升。

作为本月特别值得关注漏洞中两个本地漏洞之一，小迪建议有该漏洞的用户尽快打上该漏洞官方补丁或者升级到最新稳定版本，地址：http://technet.microsoft.com/security/bulletin/MS15-010
Internet Explorer ASLR 绕过漏洞
Microsoft
Microsoft Internet Explorer 9到11的多个版本存在漏洞，允许远程攻击者通过构造特殊的网页，绕过ASLR保护机制。

同样，小迪建议您尽快打上该漏洞官方补丁或者升级到最新稳定版本，地址：http://technet.microsoft.com/security/bulletin/MS15-009
Flash Player重用已释放数据漏洞
Adobe

重用已释放数据漏洞（use-after-free)指的是软件使用到被释放的数据，导致未知错误的漏洞，黑客可以利用该漏洞执行任意代码。


Windows，Linux，OS X系统上的Adobe Flash Player，有多个版本存在“重用已释放数据”漏洞，该漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。


小迪为您奉上Adobe公司发布的升级补丁地址： https://helpx.adobe.com/security/products/flash-player/apsb15-04.html
Flash Player内存损坏漏洞
Adobe
Windows、OS X和Linux系统上的某些Adobe Flash Player版本存在漏洞，允许远程攻击者通过未知向量发起任意代码执行或者拒绝服务 (Dos)攻击。

小迪建议您尽快升级至最新版本，地址：https://helpx.adobe.com/security/products/flash-player/apsb15-04.html
释放未初始化指针漏洞
Samba
Samba是在Linux和UNIX系统上实现SMB协议的一个免费软件，Windows系统也有相应实现。

在多个版本的Samba的网络登录服务器的实现中，对一个未初始化的栈指针进行了free操作，这将使得远程攻击者通过精心构造网络登录数据包，发起任意代码执行攻击。

目前Samba已经发布了升级补丁，请尽快更新：http://www.samba.org
DAP-1320代码注入漏洞
D-Link
D-Link是台湾的一家网络通讯公司。

D-Link DAP-1320 Rev Ax 固件版本低于1.21b01的设备存在漏洞。该漏洞允许攻击者通过未知向量发起任意代码执行攻击。

针对该漏洞，D-link已发布升级补丁，地址：http://support.dlink.com/ProductInfo.aspx?m=DAP-1320
ClamAV堆缓冲区溢出漏洞
Clam
Clam Anti Virus是一个类UNIX系统上使用的反病毒软件包。

在ClamAV0.98.6版本之前的产品中存在漏洞，允许远程攻击者通过构造特殊的包文件，发起任意代码执行攻击。该漏洞产生原因是边界条件的堆溢出。

该漏洞补丁已发布，地址：https://admin.fedoraproject.org/updates/clamav-0.98.6-1.el7
