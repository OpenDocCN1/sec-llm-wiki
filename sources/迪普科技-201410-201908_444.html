十大典型漏洞
小迪根据2015年1月漏洞影响范围、CVSS评分、危急程度等因素，挑选出本月特别值得关注的漏洞。
1
Linux幽灵漏洞
漏洞基本信息
CVE编号：CVE-2015-0235
CNNVD编号：CNNVD-201501-658
发布时间：2015-1-28
更新时间：2015-1-29
危害等级：高危
漏洞类型：缓冲区溢出
威胁类型：远程
受影响软件：2.2 <= glibc < 2.18
漏洞危害
glibc是GNU发布的C运行库，C运行库是Linux系统中最底层的函数库，其他的大部分运行库都依赖glibc。

在glibc 2.2至2.18以前的所有版本中__nss_hostname_digits_dots函数存在基于堆的缓冲区溢出漏洞，该漏洞允许攻击者利用gethostbyname和gethostbyname2函数，触发存在漏洞的函数，发起任意代码执行攻击。该漏洞又被称为幽灵（GHOST)漏洞。
TIps

尽快更新glibc
2
Windows Telnet服务缓冲区溢出漏洞
漏洞基本信息
CVE编号：CVE-2015-0014
CNNVD编号：CNNVD-201501-254
发布时间：2015-1-13
更新时间：2015-1-14
危害等级：高危
漏洞类型：缓冲区溢出
威胁类型：远程
受影响软件：
Microsoft Windows Server 2003 SP2
Microsoft Windows Vista SP2等
漏洞危害
在微软多个版本操作系统中，Telnet服务进程存在漏洞，允许远程攻击者通过构造特定的数据包，发起任意代码执行攻击，该漏洞被称为“Windows Telnet服务缓冲区溢出漏洞”。
Tips

尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：
http://technet.microsoft.com/security/bulletin/MS15-002
3
Adobe Flash Player和Adobe AIR堆缓冲区溢出漏洞
漏洞基本信息
CVE编号：CVE-2015-0304
CNNVD编号：CNNVD-201501-260
发布时间：2015-1-13
更新时间：2015-1-22
危害等级：高危
漏洞类型：缓冲区溢出
威胁类型：远程
受影响软件：
Adobe Flash Player 13 < 13.0.0.260
Adobe Flash Player 14.x等

漏洞危害
在Adobe Flash Player和Adobe AIR的多个版本中，存在基于堆的缓冲区溢出漏洞。该漏洞允许远程攻击者通过未知向量，发起任意代码执行攻击。
Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。
Tips

尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：
http://helpx.adobe.com/security/products/flash-player/apsb15-01.html

Samba AD域控制器权限提升漏洞
漏洞基本信息
CVE编号：CVE-2014-8143
CNNVD编号：CNNVD-201501-367
发布时间：2015-1-16
更新时间：2015-1-21
危害等级：高危
漏洞类型：权限提升
威胁类型：远程
受影响软件：
Samba <= 4.2.0
漏洞危害
Samba 4.2.0及其之前的若干版本存在权限提升漏洞。在配置了AD域控制器的网络上，该漏洞允许远程认证的普通用户，设置LDB userAccountControl的UF_ SERVER_ TRUST_ ACCOUNT位，创建特权账号或者提升已有帐号的权限。
Tips

尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：
http://www.samba.org

CNNVD编号：CNNVD-201501-251
发布时间：2015-1-13
更新时间：2015-1-17
危害等级：高危
漏洞类型：权限提升

Linux Kernel 'fragmentation.c'拒绝服务漏洞
漏洞基本信息
CVE编号：CVE-2014-9428
CNNVD编号：CNNVD-201501-056
发布时间：2015-1-2
更新时间：2015-1-5
危害等级：高危
漏洞类型：资源管理错误
威胁类型：远程
受影响软件：
Linux Kernel 3.18.1
漏洞危害
在3.18.1版本的Linux内核代码的net/batman-adv/fragmentation.c文件中，batadv_frag_merge_packets函数在计算内存数量的时候，使用了一个不正确的长度值，造成了这个漏洞。该漏洞允许远程攻击者通过发送特定的碎片数据包，发起拒绝服务攻击，从而造成系统崩溃。
Tips

尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：
https://git.kernel.org/cgit/linux/kernel/git/torvalds/linux.git/commit/?id=5b6698b0e4a37053de35cc24ee695b98a7eb712b

漏洞基本信息
CVE编号：CVE-2014-9510
CNNVD编号：CNNVD-201501-18
发布时间：2015-1-9
更新时间：2015-1-12
危害等级：高危
漏洞类型：跨站请求伪造
威胁类型：远程
受影响软件：
TP-Link TL-WR840N Router 3.13.27 Build 140714
漏洞危害
在TP-Link的TL-WR840N (V1)路由器3.13.27 build 141120及之前的版本存在跨站请求伪造漏洞。该漏洞允许攻击者劫持管理员的认证权限发出请求，通过导入配置文件来修改路由器设置。

http://service.tp-link.com.cn/

漏洞基本信息
CVE编号：CVE-2014-7929
CNNVD编号：CNNVD-201501-568
发布时间：2015-1-22
更新时间：2015-1-23
危害等级：高危
漏洞类型：拒绝服务
威胁类型：远程
受影响软件：
Google Chrome < 40.0.2214.91
漏洞危害
在Google Chrome 40.0.2214.91之前的版本，core/html/HTMLScriptElement.cpp文件中的HTMLScriptElement::didMoveToNewDocument存在重用已释放数据（use-after-free）漏洞。该漏洞允许远程攻击者通过构造畸形的脚本代码，发起拒绝服务及其他未知方式的攻击。
