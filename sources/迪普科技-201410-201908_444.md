十大典型漏洞

小迪根据2015年1月漏洞影响范围、CVSS评分、危急程度等因素，挑选出本月特别值得关注的漏洞。

1Linux幽灵漏洞

漏洞基本信息CVE编号：CVE-2015-0235CNNVD编号：CNNVD-201501-658发布时间：2015-1-28更新时间：2015-1-29危害等级：高危漏洞类型：缓冲区溢出威胁类型：远程受影响软件：2.2 <= glibc < 2.18 

漏洞危害glibc是GNU发布的C运行库，C运行库是Linux系统中最底层的函数库，其他的大部分运行库都依赖glibc。  
在glibc 2.2至2.18以前的所有版本中\_\_nss\_hostname\_digits\_dots函数存在基于堆的缓冲区溢出漏洞，该漏洞允许攻击者利用gethostbyname和gethostbyname2函数，触发存在漏洞的函数，发起任意代码执行攻击。该漏洞又被称为幽灵（GHOST)漏洞。

TIps  
尽快更新glibc

2Windows Telnet服务缓冲区溢出漏洞

漏洞基本信息CVE编号：CVE-2015-0014CNNVD编号：CNNVD-201501-254发布时间：2015-1-13更新时间：2015-1-14危害等级：高危漏洞类型：缓冲区溢出威胁类型：远程受影响软件：Microsoft Windows Server 2003 SP2Microsoft Windows Vista SP2等

漏洞危害在微软多个版本操作系统中，Telnet服务进程存在漏洞，允许远程攻击者通过构造特定的数据包，发起任意代码执行攻击，该漏洞被称为“Windows Telnet服务缓冲区溢出漏洞”。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：http://technet.microsoft.com/security/bulletin/MS15-002

3Adobe Flash Player和Adobe AIR堆缓冲区溢出漏洞

漏洞基本信息CVE编号：CVE-2015-0304CNNVD编号：CNNVD-201501-260发布时间：2015-1-13更新时间：2015-1-22危害等级：高危漏洞类型：缓冲区溢出威胁类型：远程受影响软件：Adobe Flash Player 13 < 13.0.0.260Adobe Flash Player 14.x等  

漏洞危害在Adobe Flash Player和Adobe AIR的多个版本中，存在基于堆的缓冲区溢出漏洞。该漏洞允许远程攻击者通过未知向量，发起任意代码执行攻击。Adobe Flash Player漏洞可以被用来进行网页挂马和病毒传播，通过浏览器打开畸形SWF文件会触发漏洞，威胁用户系统安全。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：http://helpx.adobe.com/security/products/flash-player/apsb15-01.html

4Samba AD域控制器权限提升漏洞

漏洞基本信息CVE编号：CVE-2014-8143CNNVD编号：CNNVD-201501-367发布时间：2015-1-16更新时间：2015-1-21危害等级：高危漏洞类型：权限提升威胁类型：远程受影响软件：Samba <= 4.2.0

漏洞危害Samba 4.2.0及其之前的若干版本存在权限提升漏洞。在配置了AD域控制器的网络上，该漏洞允许远程认证的普通用户，设置LDB userAccountControl的UF\_ SERVER\_ TRUST\_ ACCOUNT位，创建特权账号或者提升已有帐号的权限。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：  
http://www.samba.org

5Oracle Java SE远程安全漏洞

漏洞基本信息CVE编号：CVE-2014-6549CNNVD编号：CNNVD-201501-446发布时间：2015-1-21更新时间：2015-1-22危害等级：高危漏洞类型：其他威胁类型：远程受影响软件：Oracle Java SE 8u25  

漏洞危害漏洞影响部署了Java环境的客户端，Web Start应用程序和小应用程序（Applet）可以利用该漏洞来穿透Java沙箱保护。未经认证的远程攻击者能够利用多个协议，威胁受漏洞影响组件的机密性、完整性和可用性。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：  
http://www.oracle.com/technetwork/java/javase/downloads/index.html

6Microsoft Windows User Profile服务本地权限提升漏洞

漏洞基本信息CVE编号：CVE-2015-0004CNNVD编号：CNNVD-201501-251发布时间：2015-1-13更新时间：2015-1-17危害等级：高危漏洞类型：权限提升威胁类型：本地受影响软件：Microsoft Windows Server 2003 SP2Microsoft Windows Vista SP2等  

漏洞危害在微软多个版本操作系统中，User Profile服务存在漏洞，允许本地用户加载其他用户的UsrClass.dat注册表项，绕过系统的权限许可和访问控制检查，提升当前账户的权限。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：  
https://technet.microsoft.com/en-us/library/security/MS15-003

7Linux Kernel 'fragmentation.c'拒绝服务漏洞

漏洞基本信息CVE编号：CVE-2014-9428CNNVD编号：CNNVD-201501-056发布时间：2015-1-2更新时间：2015-1-5危害等级：高危漏洞类型：资源管理错误威胁类型：远程受影响软件：Linux Kernel 3.18.1

漏洞危害在3.18.1版本的Linux内核代码的net/batman-adv/fragmentation.c文件中，batadv\_frag\_merge\_packets函数在计算内存数量的时候，使用了一个不正确的长度值，造成了这个漏洞。该漏洞允许远程攻击者通过发送特定的碎片数据包，发起拒绝服务攻击，从而造成系统崩溃。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：  
https://git.kernel.org/cgit/linux/kernel/git/torvalds/linux.git/commit/?id=5b6698b0e4a37053de35cc24ee695b98a7eb712b(八)

8TP-Link TL-WR840N路由器跨站请求伪造漏洞

漏洞基本信息CVE编号：CVE-2014-9510CNNVD编号：CNNVD-201501-18发布时间：2015-1-9更新时间：2015-1-12危害等级：高危漏洞类型：跨站请求伪造威胁类型：远程受影响软件：TP-Link TL-WR840N Router 3.13.27 Build 140714

漏洞危害在TP-Link的TL-WR840N (V1)路由器3.13.27 build 141120及之前的版本存在跨站请求伪造漏洞。该漏洞允许攻击者劫持管理员的认证权限发出请求，通过导入配置文件来修改路由器设置。

Tips  
1、建议设置受信任IP或网段来进行路由器的管理；2、更换新设备，或到厂商的官网升级固件版本，官网链接：http://service.tp-link.com.cn/  

9Google Chrome DOM重用已释放数据漏洞

漏洞基本信息CVE编号：CVE-2014-7929CNNVD编号：CNNVD-201501-568发布时间：2015-1-22更新时间：2015-1-23危害等级：高危漏洞类型：拒绝服务威胁类型：远程受影响软件：Google Chrome < 40.0.2214.91

漏洞危害在Google Chrome 40.0.2214.91之前的版本，core/html/HTMLScriptElement.cpp文件中的HTMLScriptElement::didMoveToNewDocument存在重用已释放数据（use-after-free）漏洞。该漏洞允许远程攻击者通过构造畸形的脚本代码，发起拒绝服务及其他未知方式的攻击。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：  
http://googlechromereleases.blogspot.com/2015/01/stable-update.html

10Oracle MySQL Server远程安全漏洞

漏洞基本信息CVE编号：CVE-2015-0411CNNVD编号：CNNVD-201501-533发布时间：2015-1-21更新时间：2015-1-27危害等级：高危漏洞类型：无威胁类型：远程受影响软件：Oracle MySQL Server <=5.5.40Oracle MySQL Server <=5.6.21

漏洞危害Oracle MySQL Server是Oracle公司开发的轻量级关系型数据库系统。Oracle MySQL Server在5.5.40及之前版本，和5.6.21及之前版本中，存在未确定的漏洞。该漏洞允许远程攻击者通过发送未知的Server:Security:Encryption向量，威胁服务器的机密性，完整性和可用性。

Tips  
尽快打上该漏洞官方补丁或升级最新稳定版本。补丁获取链接：
