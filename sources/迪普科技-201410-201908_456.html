十大典型漏洞
小迪根据2014年12月漏洞影响范围、CVSS评分、危急程度等因素，挑选出上月特别值得关注的漏洞。
1
Windows IE 内存损坏漏洞
漏洞基本信息
CVE编号：CVE-2014-6374
CNNVD编号：CNNVD-201412-264
发布时间：2014-12-11
更新时间：2014-12-11
危害等级：高危
漏洞类型：缓冲区溢出
威胁类型：远程
受影响软件：
Microsoft Internet Explorer 6 - 11
漏洞危害
IE浏览器受影响的版本在处理内存对象时存在远程执行漏洞。黑客可以通过利用该漏洞，构造恶意的网页，从而远程执行任意代码或发起拒绝服务攻击(造成内存崩溃)。该漏洞也称为“IE内存崩溃漏洞”。
IE漏洞常被用于网页挂马和病毒传播，严重威胁用户的系统安全。
Tips：
请尽快打上该漏洞官方补丁或升级版本。
补丁链接：
http://technet.microsoft.com/security/bulletin/MS14-080
2
Allegro RomPager 安全认证限制绕过漏洞
漏洞基本信息
CVE编号：CVE-2014-9222
CNNVD编号：CNNVD-201412-484
发布时间：2014-12-24
更新时间：2014-12-29
危害等级：高危
漏洞类型：设计错误
威胁类型：远程
受影响软件：
Allegro RomPager <=4.34
漏洞危害
Allegro RomPager4.34及之前版本存在漏洞。这些软件被用于TP-Link、华为、D-Link、中兴等厂商的网关产品。
该漏洞允许远程攻击者通过构造特定Cookie造成内存崩溃，从而获得权限。该漏洞又被称为“厄运Cookie”漏洞。
它严重威胁到连接其网络的PC，手机，平板及其他设备的信息安全。
Tips:
设置受信任IP或网段来进行网关设备的管理；
更换新设备，或到网关产品厂商官网升级固件版本。
3
Apache Struts2 跨站请求伪造保护机制绕过漏洞
漏洞基本信息
CVE编号：CVE- 2014-7809
CNNVD编号：CNNVD-201412-196
发布时间：2014-12-11
更新时间：2014-12-11
危害等级：高危
漏洞类型：跨站请求伪造
威胁类型：远程
受影响软件：
Apache Struts2 <= 2.3.16.3
漏洞危害
Apache Struts 2.0.0到2.3.16.3的所有版本代码，使用可预测的<s:token/>值，这使得远程攻击者可以绕过跨站请求伪造的保护机制。
跨站请求伪造漏洞能在用户毫无知觉的情况下，盗用用户身份进行发送邮件，银行转账等危险操作。
Tips:
请尽快打上该漏洞官方补丁或者升级到最新稳定版本。
补丁获取链接：
http://struts.apache.org

ISC BIND远程拒绝服务漏洞
漏洞基本信息
CVE编号：CVE-2014-8500
CNNVD编号：CNNVD-201412-268
发布时间：2014-12-15
更新时间：2014-12-15
危害等级：高危
漏洞类型：拒绝服务
威胁类型：远程
受影响软件：
ISC BIND 9.0.x至9.8.x
ISC BIND 9.9.0至9.9.6
ISC BIND 9.10.0至9.10.1
漏洞危害
ISC BIND 9的多个子版本中存在没有限制授权链的漏洞。该漏洞允许攻击者利用大量或无限的引用链接，发起拒绝服务攻击（内存崩溃）。
远程拒绝服务漏洞通常会快速消耗服务器的资源，甚至直接造成服务器崩溃，严重危害服务器的正常运行。
Tips：
尽快打上该漏洞官方补丁或者升级到最新稳定版本。
补丁获取链接：
http://www.isc.org/downloads/

PHP 'process_nested_data()' 函数重用已释放数据漏洞
漏洞基本信息
CVE编号：CVE-2014-8142
CNNVD编号：CNNVD-201412-458
发布时间：2014-12-22
更新时间：2014-12-23
危害等级：高危
漏洞类型：远程代码执行
威胁类型：远程
受影响软件：
PHP 5.5.x
PHP 5.6.x
漏洞危害
PHP5.4到5.6的源代码中，ext/standard/var_unserializer.re文件的process_nested_data函数存在漏洞。攻击者可以通过构造非序列化调用，造成内存释放，继而通过var_push_dto函数重新访问已被释放的内存，造成重用已释放数据漏洞，从而发起远程任意代码执行的攻击。
Tips:
尽快打上该漏洞官方补丁或者升级到最新稳定版本。
补丁获取链接：
https://bugs.php.net/bug.php?id=68594
