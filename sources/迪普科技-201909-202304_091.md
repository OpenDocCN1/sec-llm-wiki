# 迪普科技受邀参加浙江省“十链百场万企”系列活动

![](../Images/b8ae3098792b19a2ee60cd400c3e41e9.png "微信图片_20220719181652.jpg")

7月18日，由浙江省经济和信息化厅、杭州市人民政府主办的浙江省“十链百场万企”系列对接活动之智能计算产业链专场在杭州城西科创大走廊举办。省经信厅厅长姚高员，杭州市人民政府党组成员、副市长孙旭东分别致辞发言，同时参会的还有智能计算产业重点企业、科研院所、行业客户、金融机构等400多位代表。

  

会上，由浙江省经济和信息化厅指导的浙江省智能计算产业联盟正式成立，迪普科技作为发起单位之一，成为联盟首批成员单位。

长期以来，迪普科技十分重视与智能计算企业、科研院所、行业客户与机构的发展合作，立足网络安全产业，助力各行各业数字化转型与安全运营体系建设。

  

![](../Images/b9785d1f24e7dfe17cff75ca66d4d4f0.png "1afa1980663ed8b32a67905286c7c40.jpg")

  

随着十四五国家信息化建设的稳步开展，数字经济的高速发展，网络空间安全需求的日益增长，迪普科技将继续发挥自身技术优势，形成具有竞争优势的国产化网络安全产品与解决方案，助力计算产业高质量、高可靠发展，为数字中国建设构筑坚实的网络安全防线。
