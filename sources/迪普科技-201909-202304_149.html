聚焦行业，充分耦合——迪普科技零信任解决方案应用报告（一）

近日，迪普科技零信任安全代理系统通过2022年度首批首家“Zero Trust Ready”SDP设备测试，针对不同行业应用场景提出具有针对性的解决方案及特色功能，助力用户进行零信任安全体系的建设。

面向 金融行业

2月9日，中国人民银行会同市场监管总局、银保监会、证监会，四部门联合印发《金融标准化“十四五”发展规划》，其中（十九）健全金融信息基础设施标准指出，将探索量子通信、零信任网络、无损网络等新技术应用标准。

根据金融行业特点，迪普科技零信任解决方案针对性推出了耦合用户需求的亮点功能。

✓

台账管理

将机房工位号与设备序列号对应录入，实现资产统一管理，用户精细化管控。

✓

登记簿审核

深度融合零信任体系与客户办公体系，业务处理线上化，提高办公效率。

✓

入网管理

基于用户登录地理位置、网络从属等情况进行精细化权限管控。

面向 电力行业

电力行业网络建设主要呈现终端分布范围广（管控难）、新业务横向交互频率高（效率低）、涉控业务外延（风险大）、针对性定制攻击手法多样（防护难）等特点，新业务安全接入涉及大量终端，且需求多样，部署复杂，现有安全防护措施难以保障系统、终端的安全、可控运行。

根据电力行业特点，迪普科技提出具有针对性的建设解决方案。

✓

智能终端

直接部署零信任终端安全软件，实现终端信息的收集上报、安全准入。

✓

非智能终端

与边缘物联代理设备进行适配，通过部署零信任终端安全软件实现数据安全上报。

✓

5G终端

通过5G硬切片与软切片两种方式接入零信任接入区。

面向 医疗行业

分析医疗行业业务现状，目前主要有以下问题：终端健康参差不齐，缺乏对应感知能力、传统远程接入方式安全问题凸显 、内部威胁严重。

迪普科技零信任解决方案从四大维度来解决医疗行业安全问题

✓

终端安全评估和保障

基于终端环境感知、用户行为分析进行持续的安全等级评估并动态调整访问策略。

✓

持续评估，动态授权

持续分析访问终端信息，基于终端信任等级和应用安全等级动态调整访问权限。

✓

网络隐身，减少资产暴露面

待机时管理平台仅开启监听端口，网关关闭所有端口，大幅减少端口扫描、DDOS攻击风险。

✓

行为审计

记录并上传访问行为，通过管控平台进行大数据分析并动态展示，直观了解全网终端环境安全概况，便于安全回溯。

迪普科技在常规零信任安全解决方案的基础上，结合自身安全能力优势，丰富零信任架构落地方案，推出了多平台统一安全接入、多因素智能身份认证、多方式双向安全加密、多维度动态更新授权、多软件无缝集中管控等功能于一体的ZTS零信任产品，并支持动态扩容和云管平台联动，为用户塑造更完善的网络安全生态。

未来，迪普科技将在网络安全、数据安全、领域持续钻研，不断迭代产品与解决方案，为用户创造更大价值。
