【漏洞风险通告】Spring Cloud Function SPEL表达式注入漏洞

一

背景描述

Spring Cloud Function是基于Spring Boot的函数计算框架，它抽象出所有传输细节和基础架构，允许开发人员保留所有熟悉的工具和流程，并专注于业务逻辑。

近日，迪普安全研究院团队监测到Spring Cloud官方发布了关于Spring Cloud Function SPEL表达式注入漏洞的修复代码。远程攻击者在无需认证的情况下，发送带有恶意命令的请求可以在目标服务器上执行任意代码。

目前该漏洞相关POC已在互联网公开，攻击复杂度低。迪普科技建议相关用户及时开展安全自查，及时进行修补更新，做好相关防护措施，避免被外部攻击者入侵。

二

严重等级

高危

三

漏洞描述

该漏洞源于Spring Cloud Function的RoutingFunction类的apply方法未能正确处理用户输入的数据。未经授权的远程攻击者可以利用该漏洞在请求header中加入spring.cloud.function.routing-expression参数及SPEL表达式，在目标服务器上执行任意代码。

四

影响范围

3.0.0.M3 ≤ 软件版本 ≤ 3.2.2

五

漏洞复现

1. 搭建受影响的版本并运行

2. 执行创建txt文件命令

3. 成功创建

六

解决方案

官方解决方案

官方已发布漏洞修复代码，但还没有发布正式版本，修复代码链接如下：

https://github.com/spring-cloud/spring-cloud-function/tree/0e89ee27b2e76138c16bcba6f4bca906c4f3744f

迪普科技解决方案

迪普科技安全研究院在监测到Spring Cloud Function SPEL表达式注入漏洞后，迅速采取了应急措施。

1

使用迪普慧眼检测平台检测现网环境中是否存在Spring Cloud Function SPEL表达式注入漏洞。

2

使用迪普态势感知平台检测现网环境中是否存在Spring Cloud Function SPEL表达式注入漏洞攻击行为。

◆ 态势感知特征库版本：2022030501

3

迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。

4

DPtech IPS2000、FW1000将在以下特征库版本中对Spring Cloud Function SPEL表达式注入漏洞进行有效防护。

◆ 漏洞库版本：IPS-R3.1.244

5

DPtech WAF3000将在以下特征库版本中对Spring Cloud Function SPEL表达式注入漏洞进行有效防护。

◆ 产品系列：WAF3000

◆ 漏洞库版本：WAF-R3.1.124、WAF-R2.1.124
