# 强强联合！迪普科技成为华为云（鲲鹏）生态合作伙伴

近日，迪普科技防火墙系统软件（简称：DPtech FW1000软件）通过了“华为云Stack 8.0（鲲鹏）”及“华为云鲲鹏云服务”的双兼容技术认证，获得了KUNPENG COMPATIBLE 证书，成为华为云（鲲鹏）生态合作伙伴，将与华为携手为用户提供更具价值的解决方案。

DPtech FW1000软件是迪普科技自主研发的、业界性能领先的防火墙产品。DPtech FW1000软件集成了入侵防御、病毒防护等功能，可按需扩展应用防火墙方案，简化网络架构，降低企业网络安全建设成本，同时支持VMware ESXI、Hyper-V、KVM、Citrix XenServer、OpenStack等主流的虚拟化平台，并可提供对外接口的API模块。

![](../Images/72a6740a1e0a2800d7a98e3244f34d7b.png)

华为云 Stack 8.0（鲲鹏）基于华为鲲鹏处理器的混合云解决方案，将华为云强大的算力和智能化底座以混合云的方式提供给政府和企业用户。通过实现高级服务能力跨云“0”时差无缝同步、多场景协同助力“一个企业一朵云”、支持华为鲲鹏 + 昇腾多样算力，为政企客户提供在云上和本地部署体验一致的云服务。

经测试，DPtech FW1000软件产品功能完善、性能优异、运行稳定，产品成熟性、开放性、兼容性均可满足需求，具备与鲲鹏国产化环境兼容能力。

![](../Images/a3fb1c500f31029c907b52c8c5ab5d02.png)![](../Images/f4c63451013564f764ba4527f23bc881.png)

  

基于鲲鹏架构的DPtech FW1000软件在原有的基于用户的应用访问控制、丰富的NAT功能之上，也融合了鲲鹏云服务的高性能、高算力、多元架构等优势，通过云服务，为企业上云提供更全面安全防护，满足客户多样化的应用和部署要求，从容面对下一代网络的各种挑战。

通过本次DPtech FW1000软件获得的华为云Stack和华为云鲲鹏云服务的双兼容技术认证，迪普科技产品将联合华为云“多核算力、端云协同、生态丰富、高性价比”的优势，为客户提供更优质的服务，也标志着迪普科技产品在国产化信创领域又迈出了重要一步。

未来，迪普科技将继续坚持自主研发、持续创新，携手更多行业合作伙伴，为各行业用户，提供更简单、智能、安全的国产化网络安全产品和解决方案。

**关于华为云**

华为云成立于2005年，隶属于华为公司，是华为公有云品牌，致力于提供专业的公有云服务，为用户提供一站式云计算基础设施服务，以“可信、开放、全球服务”三大核心优势服务全球用户。华为云立足于互联网领域，提供包括云主机、云托管、云存储等基础云服务、超算、内容分发与加速、视频托管与发布、企业IT、云电脑、云会议、游戏托管、应用托管等服务和解决方案。

**关于迪普科技**

杭州迪普科技股份有限公司以“让网络更简单、智能、安全”为使命，聚焦于网络安全及应用交付领域，是一家集研发、生产、销售于一体的高科技上市企业。迪普科技坚持技术创新，依托于安全研究团队十多年以来在攻防研究、漏洞挖掘、威胁情报分析、安全事件响应等技术积累，开发了具有自主知识产权的安全大数据处理引擎与AI智能分析引擎，结合主/被动安全检测、威胁情报、攻击建模等先进技术，为客户提供全场景网络安全解决方案。
