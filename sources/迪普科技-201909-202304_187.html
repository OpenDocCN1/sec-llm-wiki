【一】背景描述

微软（Microsoft）是全球最大的电脑软件提供商，其主要产品为Microsoft Windows操作系统、Microsoft Office系列软件、Microsoft Edge浏览器、Exchange Server邮件服务等，在全球被广泛应用。

近日，微软发布了2022年1月安全更新公告，本次更新包含97个CVE，涵盖Windows和Windows组件、Exchange Server、Office、.NET Framework、SharePoint等多项产品。有9个漏洞被标记为高危（Critical），88个漏洞被标记为重要（Important）。其中Windows HTTP协议栈远程代码执行漏洞（CVE-2022-21907）被标记为wormable。迪普科技建议相关用户及时更新版本，做好相关防护措施。

【二】漏洞描述

1、CVE-2022-21907：HTTP协议栈远程代码执行漏洞

HTTP协议，即超文本传输协议，是为Web浏览器与Web服务器之间的通信而设计的应用层协议。Windows HTTP协议栈（HTTP.sys）用于windows上的Web服务器通信，例如Internet Information Services(IIS)。

该漏洞源于HTTP Trailer Support功能存在边界错误，导致缓冲区溢出。未经身份验证的攻击者可利用HTTP协议栈向目标服务器发送特制HTTP数据包，触发缓冲区溢出，进而执行任意代码。由于HTTP协议栈的开放性导致该漏洞利用链具有蠕虫性，危害较大。

2、CVE-2022-21857：Active Directory域服务特权提升漏洞

Active Directory是微软Windows Server中负责架构中大型网路环境的集中式目录管理服务。

该漏洞需要攻击者具有一定权限，通过利用该漏洞可绕过Active Directory信任边界，实现权限提升。

3、CVE-2022-21840：Microsoft Office远程代码执行漏洞

Microsoft Office是Microsoft一款办公软件套件产品，常用组件包括Word、Excel、Access、Powerpoint、FrontPage等。

攻击者通过诱导用户打开特制的恶意office文件利用该漏洞，在受影响的目标系统上以用户权限执行任意代码。

【三】影响范围

Windows Server 2022、2019、2016、2012、2008

Windows 7、8.1、10、11

Windows RT 8.1

Microsoft .NET Framework

Microsoft Word 2016

Microsoft SharePoint

Microsoft Office 2013、2016、2019

Microsoft 365 Apps

HEVC Video Extensions

Remote Desktop client for Windows Desktop

Microsoft Edge
