# 【漏洞风险通告】Log4j2远程代码执行漏洞

***一、背景描述***

近日，迪普科技安全研究院团队监测到Apache Log4j官方发布了Log4j2的又一个CVE漏洞——Apache Log4j远程代码执行(RCE)漏洞（CVE-2021-44832）的安全通告。

该漏洞需要更改默认配置才能触发，整体利用难度较高。但由于目前Log4j相关漏洞的高热度下，迪普科技仍建议使用Apache Log4j2的用户及时修补，做好相关防护措施。

  

***二、严重等级***

**中危**

  

***三、漏洞描述***

Apache Log4j2 2.0-beta7到2.17.0（安全修复版本2.3.2和2.12.4不受影响）版本容易受到远程代码执行(RCE)漏洞攻击，该漏洞要求攻击者具有修改日志配置文件的权限，所以其利用复杂性高于CVE-2021-44228，有权修改日志配置文件的攻击者可以通过构建恶意配置将JDBC Appender与引用JNDI URI的数据源一起使用，从而导致JNDI URI可以执行远程代码。

***四、影响范围***

2.0-beta7 <= Apache Log4j <=2.17.0

注：2.12.4和2.3.2不受影响，且只有log4j-core jar文件受此漏洞影响。

  

***五、解决方案***

**/****/**** 官方解决方案**

将Apache Log4j2升级到2.17.1、2.12.4和2.3.2或更高版本，下载链接如下：https://github.com/apache/logging-log4j2/tags

**/****/****迪普科技解决方案**

迪普科技安全研究院在监测到Apache Log4j2远程代码执行漏洞后，迅速采取了应急措施。

1）使用迪普“慧眼检测平台”检测现网环境中是否存在Apache Log4j2远程代码执行漏洞。

2）使用迪普“态势感知平台”检测现网环境中是否存在Apache Log4j2远程代码执行漏洞攻击行为。

◆态势感知特征库版本：2022010101

3）迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。

4）DPtech IPS2000、FW1000将在以下特征库版本中对Apache Log4j2远程代码执行漏洞进行有效防护。

◆产品系列：IPS2000，FW1000

◆漏洞库版本：IPS-R3.1.232

5）DPtech WAF3000将在以下特征库版本中对Apache Log4j2远程代码执行漏洞进行有效防护。

◆产品系列：WAF3000

◆漏洞库版本：WAF-R3.1.119、WAF-R2.1.119
