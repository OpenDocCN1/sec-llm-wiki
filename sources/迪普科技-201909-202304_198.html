近日，迪普安全研究院团队监测到Apache Log4j官方发布了关于Apache Log4j2拒绝服务攻击漏洞(CVE-2021-45105)的安全通告。这是近期关于Apach Log4j2的第三次预警。前两次分别为“核弹级“漏洞Apache Log4j2远程代码执行漏洞(CVE-2021-44228)和Apache Log4j2远程代码执行漏洞(CVE-2021-45046)。

#1 背景描述

该漏洞需要更改默认配置才能触发，利用难度较高。但在目前Log4j2相关漏洞的高热度下，迪普科技仍建议使用Apache Log4j的用户及时修补，做好相关防护措施。

#2 严重等级

高危

#3 漏洞描述

该漏洞与系统日志的配置不当有关，当配置中带有Context Lookups的非默认Pattern Layout（例如$${ctx:loginId}）时，会导致自引用查找时的无限循环问题，从而使系统崩溃。

攻击者可以通过控制Thread Context Map (MDC)并构造包含递归查找的恶意输入数据，触发栈溢出，从而实现拒绝服务攻击。

#4 影响范围

Apache Log4j2 2.0-alpha1 - 2.16.0

#5 解决方案

官方解决方案

Java 8或更高版本用户可升级至Apache Log4j 2.17.0版本，下载链接如下：

https://logging.apache.org/log4j/2.x/download.html

其他解决方案

1）在日志配置的PatternLayout中，使用映射上下文模式查找（%X/%mdc/%MDX）替换上下文查找，否则删除配置中对上下文查找的引用，如 ${ctx:loginId}或$${ctx:loginId}。

2）Java 7的用户需要升级到Apache Log4j 2.12.3版本。

3）关注受影响应用互联网访问行为，做好自查及预防工作。

迪普科技解决方案

迪普科技安全研究院在监测到Apache Log4j2拒绝服务攻击漏洞（CVE-2021-45105）后，迅速采取了应急措施。

1）使用迪普“慧眼检测平台”检测现网环境中是否存在Apache Log4j2拒绝服务攻击漏洞。

2）使用迪普“态势感知平台”检测现网环境中是否存在Apache Log4j2拒绝服务攻击漏洞攻击行为。

  · 态势感知特征库版本：2021120401

3）迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。

4）DPtech IPS2000、FW1000将在以下特征库版本中对Apache Log4j2拒绝服务攻击漏洞进行有效防护：

  · 漏洞库版本：IPS-R3.1.231

5）WAF3000官网最新版本特征库已支持对Apache Log4j2拒绝服务攻击漏洞的有效防护。



迪普科技正在全力跟踪相关漏洞的最新进展，有疑问的客户也可联系迪普科技当地办事处售后人员或拨打客户服务热线电话（400-6100-598），进一步了解相关情况。
