# 【漏洞风险通告】Apache Log4j2拒绝服务攻击漏洞（CVE-2021-45046）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650337015&idx=1&sn=70e87a00f59094efe960025dedc95639&chksm=88316ed6bf46e7c01b9508d1e142d2f6abbf9c34746a9305b905720e3cd15052daba85563abd&scene=126&sessionid=1681369376#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650337015&idx=1&sn=70e87a00f59094efe960025dedc95639&chksm=88316ed6bf46e7c01b9508d1e142d2f6abbf9c34746a9305b905720e3cd15052daba85563abd&scene=126&sessionid=1681369376#rd)

**#1** **背景描述**

Apache Log4j2是Apache一款开源的Java日志框架，该工具重写了Log4j框架，并且引入了大量丰富的特性，用于跟踪、调试、维护程序。

继“核弹级”漏洞“Apache Log4j2远程代码执行漏洞”（漏洞编号为CVE-2021-44228）被披露后，迪普安全研究院团队监测到Apache Log4j官方又发布了关于Apache Log4j2拒绝服务攻击漏洞(CVE-2021-45046)的安全通告，该漏洞与非默认配置下对CVE-2021-44228修复措施不完善有关。

由于目前Log4j2相关漏洞热度很高，迪普科技建议使用Apache Log4j的用户及时修补，做好相关防护措施。

**#3** **漏洞描述**

该漏洞与Log4Shell有关，CVE-2021-44228爆发后，由于针对Log4Shell的修复在某些非默认配置中不完整，当配置使用非默认模式布局时，该漏洞可能允许通过线程上下文映射 (MDC) 输入数据进行攻击：上下文查找模式，例如：“$${ctx:loginId}”；线程上下文映射模式，例如：“%X”、“%mdc”或“%MDC”。

攻击者可以通过控制Thread Context Map (MDC)使用JNDI查找来制作恶意输入数据，从而导致拒绝服务攻击。

**#4** **影响范围**

Apache Log4j 2.0-beta9 - 2.12.1

Apache Log4j 2.13.0 - 2.15.0

**#5** **解决方案**

**官方解决方案**

目前官方已发布最新版本，请受影响用户尽快更新。

Java 8或更高版本用户可升级至Apache Log4j 2.16.0版本：

https://logging.apache.org/log4j/2.x/download.html

Java 7版本用户可升级至Apache Log4j 2.12.2版本：

https://github.com/apache/logging-log4j2/releases/tag/rel/2.12.2

**其他解决方案**

（1）移除log4j-core包中JndiLookup 类文件，并重启服务，命令：zip -q -d log4j-core-\*.jar org/apache/logging/log4j/core/lookup/JndiLookup.class

（2）禁用JNDI。如在spring.properties里添加spring.jndi.ignore=true；

（3）JDK使用11.0.1、8u191、7u201、6u211及以上的高版本；

（4）关注受影响应用互联网访问行为。

**迪普科技解决方案**

迪普科技安全研究院在监测到Apache Log4j2拒绝服务攻击漏洞后，迅速采取了应急措施。

1）使用迪普“慧眼检测平台”检测现网环境中是否存在Apache Log4j2拒绝服务攻击漏洞。

2）使用迪普“态势感知平台”检测现网环境中是否存在Apache Log4j2拒绝服务攻击漏洞攻击行为。

3）迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。

4）DPtech IPS2000、FW1000、WAF3000官网最新版本特征库已支持对Apache Log4j2拒绝服务攻击漏洞的有效防护。
