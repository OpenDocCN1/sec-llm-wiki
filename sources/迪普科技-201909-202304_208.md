# 【漏洞风险通告】Microsoft Exchange Server远程代码执行漏洞(CVE-2021-42321)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650336675&idx=1&sn=b0fec72eadaeb4310c3e14c9af4d6ba7&chksm=88316d82bf46e49453b0abf5088e92512bb292555fae8d558bebb289a75bc54cdb31f5779a2f&scene=126&sessionid=1681369377#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650336675&idx=1&sn=b0fec72eadaeb4310c3e14c9af4d6ba7&chksm=88316d82bf46e49453b0abf5088e92512bb292555fae8d558bebb289a75bc54cdb31f5779a2f&scene=126&sessionid=1681369377#rd)

***一、背景描述***

Exchange Server是一个微软公司设计完备的邮件服务器产品，提供了通常所需要的全部邮件服务功能，除了常规的SMTP/POP协议服务之外，它还支持IMAP4、LDAP和NNTP协议。

近日，迪普科技监测到有安全工作者公开了Microsoft Exchange Server远程代码执行漏洞的利用细节及POC，攻击者成功利用此漏洞可以在目标服务器上执行任意代码，虽然该漏洞在微软11月份发布的安全补丁中已经被修复，但此次漏洞细节及POC的公开仍然会使得该漏洞的威胁增加，所以迪普科技建议相关用户及时进行修补更新，做好相关防护措施。

  

***二、严重等级***

**高危**

  

***三、漏洞描述***

该漏洞是由于Microsoft Exchange Serve对command-let(cmdlet)参数没有进行正确的验证，导致远程攻击者可以通过发送精心构造的恶意数据到服务器，从而达到成功绕过身份验证的效果，进而可在受影响的机器上进行远程代码执行。此漏洞影响本地Exchange Server，包括用户在Exchange混合模式下使用的服务器。

  

***四、影响范围***

Microsoft Exchange Server 2016 Cumulative Update 21

Microsoft Exchange Server 2016 Cumulative Update 22

Microsoft Exchange Server 2019 Cumulative Update 10

Microsoft Exchange Server 2019 Cumulative Update 11

  

***五、解决方案***

****/****/****** 官方解决方案**

当前官方已发布安全补丁，建议受影响的用户及时下载更新。

更新地址：

https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-42321

****/****/******  迪普科技解决方案  **

迪普科技安全研究院监测到Microsoft Exchange Server远程代码执行漏洞后，迅速采取了应急措施。

1） 使用迪普“慧眼检测平台”检测现网环境中是否存在Microsoft Exchange Server远程代码执行漏洞。

2） 使用迪普“态势感知平台”检测现网环境中是否存在Microsoft Exchange Server远程代码执行行为。

　　◆态势感知特征库版本：2021110401

3） 迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。

4） DPtech IPS2000、FW1000将在以下特征库版本中对Microsoft Exchange Server远程代码执行漏洞进行有效防护：

　　◆产品系列：IPS2000，FW1000

　　◆漏洞库版本：IPS-R3.1.226

5） 使用DPtech WAF3000对Microsoft Exchange Server远程代码执行漏洞进行有效防护。

　　◆产品系列：WAF3000

　　◆漏洞库版本：WAF-R2.1.115、WAF-R3.1.115

6） 迪普科技官网特征库下载地址：https://www.dptech.com/index.php?m=content&c=index&a=lists&catid=57
