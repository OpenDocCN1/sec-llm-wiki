#1 背景描述

VMware是全球台式电脑及资料中心虚拟化解决方案的领导厂商。2021年9月21日，迪普科技监测到VMware官方发布安全通告，通告中共披露了19个VMware漏洞，影响主要涉及vCenter Server和Cloud Foundation组件，其中包含了多个高危漏洞。

目前漏洞详情暂未公开，迪普科技建议相关用户及时进行修补更新，做好相关防护措施。

#2 严重等级

高危

#3 漏洞描述

1、vCenter Server文件上传漏洞 (CVE-2021-22005)

该漏洞最高CVSSv3基本分数为9.8。利用该漏洞，具有vCenter Server服务443端口访问权限的攻击者通过上传精心构造的恶意文件，将导致vCenter Server上的任意代码执行。

2、vCenter Server本地提权漏洞 (CVE-2021-21991)

在vCenter Server主机上具有非管理用户访问权限的攻击者可以利用该漏洞将特权提升到vSphere Client (HTML5)或vCenter Server vSphere Web Client(FLEX/Flash)上的管理员权限。

3、vCenter Server反向代理绕过漏洞 (CVE-2021-22006)

该漏洞是由于端点处理URI的方式缺陷导致的，vCenter Server包含反向代理绕过漏洞，对vCenter Server上的端口443具有网络访问权限的攻击者可以利用该漏洞来访问受限端点。

4、vCenter Server未经身份验证的API端点漏洞 (CVE-2021-22011、CVE-2021-22012)

该漏洞是由于在vCenter Server内容库中包含一个未经身份验证的API端点漏洞。对vCenter Server上的端口443具有网络访问权限的攻击者可以利用该漏洞来执行未经身份验证的操作。

5、vCenter Server本地提权漏洞 (CVE-2021-22015)

该漏洞是源于文件和目录权限不当，具有非管理特权的经过身份验证的本地用户可能会利用该漏洞在vCenter Server Appliance上将其特权提升为root。

6、vCenter Server文件路径遍历漏洞 (CVE-2021-22013)

vCenter Server存在文件路径遍历漏洞，导致设备管理API中的信息泄露。对vCenter Server上的端口443具有网络访问权限的攻击者可以利用该漏洞来获取敏感信息。

7、vCenter Server反射型XSS漏洞 (CVE-2021-22016)

该漏洞是由于服务器未作输入校验导致的，利用该漏洞，攻击者可以诱使受害者点击恶意链接来执行恶意脚本。

#4 影响范围

vCenter Server 6.5系列 < 6.5 U3q

vCenter Server 6.7系列 < 6.7 U3o

vCenter Server 7.0系列 < 7.0 U2c

Cloud Foundation (vCenter Server) 3.x < 3.10.2.2

Cloud Foundation (vCenter Server) 4.x < 4.3.1

官方解决方案

VMware官方已经发布了解决上述漏洞的安全更新，建议受影响用户尽快升级，安全版本下载链接：

https://www.vmware.com/security/advisories/VMSA-2021-0020.html

安全版本:

VMware vCenter Server 7.0 U2c

VMware vCenter Server 6.7 U3o

VMware Cloud Foundation 4.3.1

VMware Cloud Foundation 3.10.2.2
