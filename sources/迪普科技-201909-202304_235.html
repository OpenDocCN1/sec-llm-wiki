#1 背景描述

Confluence是一个专业的企业知识管理与协同软件，也可以用于构建企业wiki，使用简单，但它强大的编辑和站点管理特征能够帮助团队成员之间共享信息、文档协作、集体讨论、信息推送。

近日，Atlassian 官方发布通告披露了Atlassian Confluence存在注入漏洞（CVE-2021-26084）。该漏洞是由于OGNL表达式存在注入漏洞，可导致远程攻击者在系统上执行任意代码，危害系统安全，影响较大。迪普科技提醒Atlassian Confluence相关用户尽快采取安全措施阻止该漏洞攻击。


#2 严重等级

高危


#3 漏洞描述

该漏洞与OGNL表达式解析有关，Atlassian Confluence中的OGNL未对用户输入数据进行验证，从而允许经过身份验证或某些情况下未经身份验证的用户通过OGNL进行注入，导致攻击者可以在Confluence服务器或数据中心执行任意代码。

#5 解决方案

官方解决方案

Atlassian 官方已修复了该漏洞，建议用户通过以下链接尽快升级至6.13.23、7.4.11、7.11.6、7.12.5、7.13.0版本：

https://www.atlassian.com/software/confluence/download-archives


其他解决方案

Linux：

1.关闭Confluence

2.下载cve-2021-26084-update.sh脚本：https://confluence.atlassian.com/doc/files/1077906215/1077916296/2/1629936383093/cve-2021-26084-update.sh

3.编辑该脚本，设置INSTALLATION_DIRECTORY为Confluence安装目录：INSTALLATION_DIRECTORY=/opt/atlassian/confluence

4.保存

5.赋予脚本执行权限：chmod 700 cve-2021-26084-update.sh

6.更改Confluence安装目录的拥有者和组：

$ ls -l /opt/atlassian/confluence | grep bindrwxr-xr-x 3 root root 4096 Aug 18 17:07 bin

# In this first example, we change to the 'root' user 

# to run the workaround script  $ sudo su root$ ls -l /opt/atlassian/confluence | grep bindrwxr-xr-x 3 confluence confluence 4096 Aug 18 17:07 bin

# In this second example, we need to change to the 'confluence' user # to run the workaround script

$ sudo su confluence

7.运行脚本：

$ ./cve-2021-26084-update.sh



Windows

1.关闭Confluence

2.下载cve-2021-26084-update.sh脚本：https://confluence.atlassian.com/doc/files/1077906215/1077916296/2/1629936383093/cve-2021-26084-update.sh

3.编辑该脚本，设置INSTALLATION_DIRECTORY为Confluence安装目录：INSTALLATION_DIRECTORY=/opt/atlassian/confluence

4.管理员权限打开PowerShell

5.执行脚本Get-Content .\cve-2021-26084-update.ps1 | powershell.exe -noprofile


参考链接：https://confluence.atlassian.com/doc/confluence-security-advisory-2021-08-25-1077906215.html
