# 合以致远丨迪普科技与紫金支点共谋金融行业网络安全发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4NzE5MzkzNA==&mid=2650334644&idx=2&sn=daaf010ba01a24c043671b5ad364e924&chksm=88316595bf46ec8389799c09cb50b1981883eb2a912cb44803a5578763b77d3393ba0d782ff5&scene=126&sessionid=1681369383#rd](http://mp.weixin.qq.com/s?__biz=MzA4NzE5MzkzNA==&mid=2650334644&idx=2&sn=daaf010ba01a24c043671b5ad364e924&chksm=88316595bf46ec8389799c09cb50b1981883eb2a912cb44803a5578763b77d3393ba0d782ff5&scene=126&sessionid=1681369383#rd)

4月8日，深圳市紫金支点技术股份有限公司（以下简称“紫金支点”）与杭州迪普科技股份有限公司（以下简称“迪普科技”股票代码：300768）行业战略合作签约仪式顺利举行，紫金支点总裁谢公辉、迪普科技董事长郑树生代表双方签署行业战略合作协议。

本着平等互利原则，经友好协商，双方一致同意在金融行业的数据中心、等保安全建设、IPV6升级改造、金融信创、应用交付产品推广等领域开展长期合作，通过双方的紧密合作，打造双赢、可持续发展的行业战略合作伙伴关系。

![](../Images/0c2ce262d9590b49096a832bfc35df87.png)

▲郑树生（左）与谢公辉（右）签字达成战略合作  

会前，紫金支点谢总一行参观了迪普科技解决方案体验中心，全面了解了迪普科技的发展历程、代表性的产品与解决方案、企业文化以及公司在金融、信创等领域发展情况，并听取了公司汇报。

![](../Images/a7582d6acc00406a626c624750c3e156.png)

▲迪普科技解决方案体验中心一角  

签约会上，迪普科技董事长郑总表示，迪普科技长期专注于网络安全领域，保持研发高投入，紫金支点也是专注服务金融行业40多年，深刻理解客户需求，双方的战略合作是优势互补的，迪普科技将高度关注战略合作伙伴的需求，把双方战略合作真正落到实处。

![](../Images/394ba9edf4af8cab324ac3b38661e558.png)

▲双方就战略合作内容积极探讨  

谢总在签约会上高度评价迪普科技当前的发展及所取得的成就，同时表示通过战略合作双方发挥各自在金融行业优势，共同推动信息产业发展，依照国家十四五规划要求落地，了解客户需求，做好客户服务，携手打造更加智能、安全的金融信息化服务，树立更多行业标杆。

![](../Images/46aaafb2cfb07a1b02346ef373a6ff31.png)

▲紫金支点来宾与迪普签约团队合影留念  

新时代发展格局下，双方将共同携手夯实金融行业网络安全基础，提升保障水平，不断深化技术，结合实际场景，为金融行业带来更专业的产品解决方案，为客户创造更大价值。

  

**双方信息**

![](../Images/6171ca99f290e6900b39e03cccca0834.png)![](../Images/76f793066b5c0ff0ba049af7c218c70e.png)

**深圳市紫金支点技术股份有限公司**成立于1992年，长期致力于中国金融电子化建设，是目前国内金融行业资深的系统集成商和整体解决方案提供商，同时也是国内金融自助设备最主要的供应商和服务商之一。

**杭州迪普科技股份有限公司**以“让网络更简单、智能、安全”为使命，聚焦于网络安全及应用交付领域，是一家集研发、生产、销售于一体的高科技上市企业。
