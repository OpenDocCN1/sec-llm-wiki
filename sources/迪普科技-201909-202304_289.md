# 迪普科技荣获“2020年度工业龙头企业”称号

**导语**

  

2月23日, 杭州高新区（滨江）区委常委、纪委书记黄利文一行走访迪普科技并授予公司 “2020年度工业龙头企业”称号。区人大副主任丁幼芳、区政府副区长陆文俊、区政协副主席周翔等领导陪同。迪普科技董事长兼总裁郑树生、常务副总裁邹禧典接待了黄书记一行。

![](../Images/32f0a3bcda0631698fc391956a57b963.png)

在迪普科技解决方案体验中心，黄书记详细了解了迪普科技去年的经营情况、今年的发展计划及未来规划。郑总表示，受疫情影响，整体市场环境发生了一些波动，但在区委区政府的关心支持下，迪普科技继续加大研发投入，在各个领域为客户提供优质的产品及解决方案，公司去年整体仍旧保持着稳定增长的发展趋势。

![](../Images/1bea14e4028ba7f6a01b4336dfd0705c.png)

黄书记对公司2020年所收获的成绩表示赞赏，并对公司坚持走技术创新的发展道路表示认同。

![](../Images/e5acfd862c3345c4f50ab7f458b70da8.png)

  

![](../Images/79e94714de05a2d4449e79fcd16f7d6e.png)

  

迪普科技自成立以来，一直保持着稳定快速的发展态势，这都离不开区政府的大力扶持。十年树木，百年树人。迪普科技坚信，在滨江区这片沃土上，公司将会继续茁壮成长，争取为高新区（滨江）的发展做出更大的贡献！
