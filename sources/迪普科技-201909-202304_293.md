# 【漏洞风险提示】Apache Druid 远程代码执行漏洞 (CVE-2021-25646)

**背景描述**

Apache Druid是一个用Java编写的高性能实时分析型数据库，可以在获取大量事件数据的同时提供低延迟查询，支持从Kafka、Amazon Kinesis等消息总线中流式的消费数据，也同时支持从HDFS、Amazon S3等存储服务中批量的加载数据文件，可轻松与现有的数据管道进行集成。

  

近日，Apache Druid官方发布安全更新，通报了一个远程代码执行漏洞，漏洞编号CVE-2021-25646，该漏洞允许经过身份验证的用户强制Druid运行用户提供的JavaScript代码，并执行服务器进程特权的代码。

  

目前网上已出现了利用脚本，由于脚本利用难度低且危险度高，迪普科技建议用户及时修补，做好相关防护措施。

  

**严重等级**

高危

  

**漏洞描述**

Apache Druid在高信任度环境下能够执行用户提供的嵌入各种请求中的JavaScript代码，默认情况下处于禁用状态。但是，Druid 漏洞版本中缺乏授权认证，经过身份验证的用户可以发送特制请求，用户可以强制Druid为该请求运行用户提供的JavaScript代码，而不管服务器配置如何，也就是说，用户可以利用Druid服务器进程中的特权在目标计算机上执行任意代码。

  

**漏洞验证**

1、搭建漏洞环境，可通过8888默认端口访问Apache Druid服务

![](../Images/808ecd21f348078d0cfb5213da8a9eca.png)

2、发送含有payload的特制请求

![](../Images/067a9ffdeadf695696991ef85e8e0d90.png)

该payload可以将受害服务器的shell脚本反弹到攻击者监听的端口上，直接在攻击者的终端上进行代码执行。

  

**解决方案**

**临时解决方案**

官方发布的最新版本已经修复了此漏洞，请受影响的用户升级 Apache Druid版本。

下载地址：https://lists.apache.org/thread.html/rfda8a3aa6ac06a80c5cbfdeae0fc85f88a5984e32ea05e6dda46f866%40%3Cdev.druid.apache.org%3E

  

**迪普科技解决方案**

迪普科技安全研究院监测到Apache Druid远程代码执行漏洞后，迅速采取了应急措施。

1） 使用迪普科技“**网络安全风险管控平台**”检测现网环境中是否存在Apache Druid远程代码执行漏洞。  

  

2） 使用迪普科技“**网络安全威胁感知大数据平台**”检测现网环境中是否存在Apache Druid远程代码执行漏洞攻击行为。

  

3） 迪普科技安全服务团队可协助客户完成现网Apache Druid服务的安全风险评估及安全加固等工作。如客户服务器疑似被入侵，迪普科技可安排安全服务专家帮助客户进行分析和应急响应，并尽快帮助恢复系统，指导完善安全防护措施。

  

4） DPtech IPS2000、FW1000将在以下特征库版本中对Apache Druid远程代码执行漏洞进行有效防护：

◆产品系列：IPS2000，FW1000

◆漏洞库版本：IPS-R3.1.185

  

5） WAF3000已在以下特征库版本中对Apache Druid远程代码执行漏洞进行有效防护：

◆ 产品系列：WAF3000

◆ 漏洞库版本：WAF-R3.1.102
