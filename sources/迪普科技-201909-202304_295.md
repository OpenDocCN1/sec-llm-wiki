# 【漏洞风险通告】Linux sudo权限提升漏洞（CVE-2021-3156）

**背景描述**

sudo是一个功能强大的实用程序，大多数基于Unix和Linux的操作系统都包含sudo，它允许用户使用其他用户的安全特权运行程序。

**严重等级**

高危

**漏洞描述**

2021年1月26日，sudo官方发布安全通告，通告中修复了一个类Unix操作系统在命令参数中转义反斜杠时存在基于堆的缓冲区溢出漏洞。操作者利用此漏洞可使普通用户权限提升。

  

该漏洞与使用sudoedit时-s或 -i标志未转义有关。当sudo通过-s或-i命令行选项在shell模式下运行命令时，它将在命令参数中使用反斜杠转义特殊字符，但使用-s或 -i标志运行sudoedit时，实际上并未进行转义，从而可能导致堆溢出漏洞。只要存在sudoers文件（通常是 /etc/sudoers），攻击者就可以利用本地用户通过sudo无需密码的情况，获得系统root权限。

  

**影响范围**

sudo 1.8.2 - 1.8.31p2

sudo 1.9.0 - 1.9.5p1

  

**解决方案**

** 官方解决方案**

sudo官方已修复了该漏洞，建议用户在做好数据备份的情况下通过以下链接尽快升级更高版本：

https://www.sudo.ws/download.html

  

**其他解决方案**

使用 systemtap 执行以下命令进行临时缓解：

1、通过以下语句安装所需的 systemtap 软件包和依赖项：

systemtap yum-utils kernel-devel-"$(uname -r)"

RHEL7：使用以下命令安装kernel debuginfo：

debuginfo-install -y kernel-"$(uname -r)"。

RHEL8：使用以下命令安装sudo debuginfo：

debuginfo-install sudo。

  

2、创建以下 systemtap 脚本，并将文件命名为 sudoedit-block.stap:

probe process("/usr/bin/sudo").function("main") {                                   

              command = cmdline\_args(0,0,""); 

              if (strpos(command, "edit") >= 0) {           

                         raise(9);     

             }   

}

  

3、使用root权限通过以下命令安装脚本：

nohup stap -g sudoedit-block.stap &

**注意**

该脚本将使得易受攻击的sudoedit二进制文件停止工作。sudo命令仍将照常工作。上述更改在重启后失效，必须在每次重启后重新应用。

  

4、安装完补丁程序后，就可以通过类似以下命令来取消systemtap进程，删除systemtap脚本：

kill -s SIGTERM 7590 (其中7590是systemtap进程的PID)
