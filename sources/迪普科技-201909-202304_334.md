背景描述

网络文件系统(Network File System，NFS)，是由SUN公司研制的UNIX表示层协议(presentation layer protocol)，其主要功能是通过网络（一般是局域网）让不同的主机系统之间可以实现文件或目录共享。NFS包括服务端（servlet）及客户端（client）两部分。客户端主机可以访问服务器端文件，并且其过程与访问本地存储的文件时一样。

  

2020年11月微软修复了两个NFS漏洞：CVE-2020-17051为远程代码执行漏洞，CVE-2020-17056为信息泄露漏洞。迪普科技建议用户及时修补漏洞，并做好相关防护措施。

严重等级

高危

漏洞描述

**CVE-2020-17051**：Windows NFS远程代码执行漏洞。该漏洞存在于Windows NFS V3服务器中。nfssvr.sys文件中进行ANSI到UNICODE转换的函数调用了memcpy，从而造成了缓冲区溢出。攻击者通过发送恶意的NFS数据包，可以在目标Windows中的NFS造成内存堆溢出，进而实现远程代码执行。

  

**CVE-2020-17056**：Windows NFS信息泄露漏洞。该漏洞是由nfssvr.sys驱动中的远程越界读取导致的。nfssvr处理READ程序时存在越界读取，从而导致ASLR（地址空间布局随机化）被绕过。攻击者利用该漏洞可获取用户敏感信息。

  

如果同时利用这两个漏洞，攻击者可以先获取用户的敏感信息，然后远程获取Windows主机的权限，进而实现任意代码执行。漏洞危害大、影响广泛，迪普科技建议相关用户及时修补，做好相关防护措施。

解决方案

■ **官方解决方案**

微软官方已修复了该漏洞，建议用户通过以下链接尽快升级：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2020-17051

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2020-17056

注：由于网络、计算机环境等原因，Windows Update的补丁更新可能会失败。用户在安装补丁后，应及时检查补丁是否成功更新。检查方法如下：

  

右键点击Windows图标，选择“设置(N)”，选择“更新和安全”-“Windows更新”，查看该页面上的提示信息，也可通过点击“查看更新历史记录”查看历史更新情况。

  

针对未成功更新的情况，可点击更新名称跳转到微软官方下载页面。建议用户点击该页面上的链接，转到“Microsoft更新目录”网站下载独立程序包并安装。

  

■ **迪普科技解决方案**

迪普科技安全服务团队可协助客户梳理现网使用Windows网络文件系统的信息资产，指导补丁升级以及配置禁用NFS服务等安全加固工作。如服务器疑似被入侵，迪普科技可安排安全服务专家分析和应急响应，并尽快帮助恢复系统，指导完善安全防护措施。

 

该漏洞目前尚未披露具体的漏洞信息，整体安全风险可控。迪普科技正在全力跟踪相关漏洞的最新进展，请启动设备自动更新特征库功能，有疑问的客户也可联系迪普科技当地办事处售后人员或拨打客户服务热线电话（400-6100-598）进一步了解相关情况。
