背景描述

WebLogic是美国Oracle公司出品的一个application server，确切地说是一个基于JAVAEE架构的中间件：是用于开发、集成、部署和管理大型分布式Web应用、网络应用和数据库应用的Java应用服务器。


2020年10月Oracle官方发布的关键补丁更新公告披露了Weblogic Console HTTP 协议远程代码执行漏洞（CVE-2020-14882/CVE-2020-14883）。这两个漏洞允许未经身份验证的远程攻击者利用构造的特殊HTTP请求，在受影响的WebLogic Server版本上执行任意代码。鉴于目前网络上已经流传该漏洞的POC，迪普科技建议用户及时修补，做好相关防护措施。

严重等级

高危

影响范围

Oracle Weblogic Server 10.3.6.0.0

Oracle Weblogic Server 12.1.3.0.0

Oracle Weblogic Server 12.2.1.3.0

Oracle Weblogic Server 12.2.1.4.0

Oracle Weblogic Server 14.1.1.0.0

漏洞描述

该漏洞与Weblogic ConSole控制台组件未过滤url中的危险字符有关。未经身份认证的攻击者可结合这两个漏洞，构造特殊的HTTP GET请求，利用特殊字符的url二次编码，在登录页面进行登录绕过，可直接管理WebLogic Server Console，并可以利用漏洞绕过管理控制台登录页面获取权限，运行任意恶意代码或者程序，危害系统安全。

解决方案

■ 目前官方已发布升级补丁，请受影响的用户尽快下载补丁进行防护：

https://www.oracle.com/security-alerts/cpuoct2020.html


■ 迪普科技解决方案

1）使用迪普科技“慧眼检测平台”检测现网环境中是否存在 Weblogic Console HTTP 协议远程代码执行漏洞。


2）使用迪普科技“态势感知大数据平台”检测现网环境中是否存在Weblogic Console HTTP 协议远程代码执行漏洞攻击行为。


3）迪普科技安全服务团队可协助客户完成现网Weblogic服务的安全风险评估及安全加固等工作。如客户服务器疑似被入侵，迪普科技可安排安全服务专家分析和应急响应，并尽快帮助恢复系统，指导完善安全防护措施。


4）DPtech IPS2000、FW1000、WAF3000将在以下特征库版本中对Weblogic Console HTTP 协议远程代码执行漏洞进行有效防护：

◆产品系列：IPS2000、FW1000

◆漏洞库版本：IPS-R3.1.171

◆产品系列：WAF3000

◆漏洞库版本：WAF-R2.1.100、WAF-R3.1.100

5）迪普科技官网特征库下载地址：http://www.dptech.com/index.php?m=content&c=index&a=lists&catid=57
