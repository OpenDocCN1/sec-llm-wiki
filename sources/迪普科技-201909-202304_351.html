【漏洞风险通告】Windows TCP/IP远程执行代码漏洞（CVE-2020-16898）

背景描述

2020年10月13日Microsoft官网披露了Windows TCP/IP远程执行代码漏洞（CVE-2020-16898）。该漏洞是Windows IPv6协议栈漏洞。根据其特性，攻击者可以构造特制的数据包并发送到目标远程Windows主机上，即可在目标主机上执行任意代码。该漏洞危害极大，迪普科技提醒相关用户尽快采取安全措施阻止漏洞攻击。

严重等级

高危

漏洞描述

该漏洞与Windows TCP/IP堆栈无法正确处理特制IMCPv6 Router Advertisement（路由通告）数据包有关。远程攻击者通过构造特制的ICMPv6 Router Advertisement（路由通告）数据包，无须接触目标计算机也不需要相应权限，只需要将其发送到目标主机上，即可在目标主机上执行任意代码。

影响范围

Windows server:2019/1903/1909/2004

Windows10:1709/1803/1809/1903/1909/2004

解决方案

■ 官方解决方案：

目前官方已发布补丁，请受影响的用户尽快下载对应操作系统版本补丁进行防护，官方下载链接：

https://portal.msrc.microsoft.com/en-US/security-guidance/advisory/CVE-2020-16898


■ 临时解决方案：

可以禁用ICMPv6 RDNSS来缓解风险。使用以下PowerShell命令禁用ICMPv6 RDNSS，以防止攻击者利用此漏洞。此解决方法仅适用于Windows 1709及更高版本。进行更改后，无需重新启动。

netsh int ipv6 set int *INTERFACENUMBER*

 rabaseddnsconfig=disable 

可通过以下命令撤销上述的禁用命令。

netsh int ipv6 set int*INTERFACENUMBER* 

rabaseddnsconfig=enable


■迪普科技解决方案：

迪普科技安全服务团队可协助客户完成现网Windows10和Windows server系统的安全风险评估及安全加固等工作。如服务器疑似被入侵，迪普科技安全服务团队可安排安全服务专家对相关现象进行分析和应急响应，并尽快帮助恢复系统，指导完善安全防护措施。

迪普科技正在全力跟踪相关漏洞的最新进展，请启动设备自动更新特征库功能，有疑问的客户也可联系迪普科技当地办事处售后人员或拨打客户服务热线电话（400-6100-598）进一步了解相关情况。
