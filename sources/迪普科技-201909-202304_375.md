# 【漏洞风险通告】Apache Struts2远程代码执行漏洞（CVE-2019-0230）

背景描述

Apache Struts2框架是一个用于开发Java EE网络应用程序的Web框架，它利用并延伸了Java Servlet API。2020年8月13日Apache Struts披露了S2-059 Struts2远程代码执行漏洞（CVE-2019-0230）。框架中的某些tag可能存在OGNL表达式注入漏洞，从而造成远程代码执行，危害系统安全，影响较大。迪普科技提醒Apache Struts2相关用户尽快采取安全措施阻止漏洞攻击。

  
  

严重等级

高危

  
  

漏洞描述

该漏洞与OGNL表达式解析有关，开发者使用Apache Struts2框架时，框架会对某些标签属性（比如 id）的属性值进行二次表达式解析，以至于当Struts2使用“%{...} or ${...}”语法对标签内属性强制进行OGNL表达式解析时，远程攻击者利用特制的代码可能导致远程代码执行漏洞。

  
  

影响范围

2.0.0 < Apache Struts2 < 2.5.20

  
  

解决方案

■  ** 官方解决方案**

Apache Struts官方已修复了该漏洞，建议用户通过以下链接尽快升级至2.5.22或更高版本：

https://struts.apache.org/download.cgi#struts2522

  

■  **其他解决方案**

对传入的每个值进行适当的验证，避免使用“%{...} or ${...}”语法对标签属性进行强制解析。

  

■  **迪普科技解决方案**

迪普科技安全研究院在首次监测到Apache Struts2远程代码执行漏洞后，就迅速采取了应急措施。

1）使用迪普科技“慧眼检测平台”检测现网环境中是否存在Apache Struts2远程代码执行漏洞。

  

2）使用迪普科技“态势感知大数据平台”检测现网环境中是否存在Apache Struts2远程代码执行漏洞攻击行为。

  

3）迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。
