背景描述

F5 BIG-IP是美国F5公司的一款集成网络流量管理，应用程序安全管理，负载均衡等功能的应用交付平台。


近日，F5公司发布了F5 BIG-IP TMUI（流量管理用户界面）存在未授权远程代码执行漏洞公告（CVE-2020-5902）。该公告表明此漏洞允许未经身份验证的攻击者或经过身份验证的用户通过BIG-IP管理端口或自身IP对TMUI进行网络访问，从而执行任意系统命令，创建或删除文件，禁用服务或执行任意Java代码。


目前该漏洞的利用方式已公开，致使该漏洞被利用的概率大大增加，由于该漏洞无需身份验证即可被远程利用，危害较大，迪普科技建议用户及时修补，做好相关防护措施。

漏洞详情

F5 BIG-IP TMUI配置实用程序的某页面中存在一处远程代码执行漏洞。允许未授权的远程攻击者通过向该页面发送特制的请求包，造成任意Java代码执行，进而控制F5 BIG-IP的全部功能，包括执行任意系统命令、开启/禁用服务、创建/删除服务器端文件等。



解决方案

■ 官方解决方案

一、 F5官方已修复了该漏洞，建议用户通过以下链接尽快安装补丁程序：

https://support.f5.com/csp/article/K52145254


二、 官网建议也可以通过以下措施缓解漏洞造成的影响:

1、通过输入以下命令登录到TMOS shell

Tmsh

2、通过输入以下命令编辑httpd属性

edit /sys httpd all-properties 

3、将文件中<include>部分改为以下内容

include '

<LocationMatch ".*\.\.;.*">

Redirect 404 /

</LocationMatch>

'

4、保存退出

Esc

:wq!

5、重启httpd服务

restart sys service httpd


■ 迪普科技解决方案

1、使用迪普“慧眼检测平台”检测现网环境中是否存在F5 BIG-IP TMUI远程代码执行漏洞。


2、使用迪普“态势感知平台”检测现网环境中是否存在F5 BIG-IP TMUI远程代码执行漏洞攻击行为。


3、DPtech IPS2000、FW1000将在以下特征库版本中对F5 BIG-IP TMUI远程代码执行漏洞进行有效防护：

◆产品系列：IPS2000，FW1000

◆漏洞库版本：IPS-R2.1.319、IPS-R3.1.153


4、迪普科技安全服务团队可协助客户梳理现网使用的F5 BIG-IP TMUI信息资产，指导客户安装补丁程序等安全加固工作。如服务器疑似被入侵，可安排安全服务专家分析和应急响应，并尽快帮助恢复系统，指导完善安全防护措施。
