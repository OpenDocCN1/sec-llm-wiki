背景描述

Dubbo是阿里巴巴公司开源的一个高性能优秀的服务框架，使得应用可通过高性能的 RPC 实现服务的输出和输入功能，可以和Spring框架无缝集成。主要核心部件：Remoting：网络通信框架，实现了sync-over-async和 request-response消息机制；RPC：一个远程过程调用的抽象，支持负载均衡、容灾和集群功能；Registry：服务目录框架用于服务的注册和服务事件发布和订阅。


2020年6月23日，Apache Dubbo官方发布了安全通告，表示Provider反序列化存在远程代码执行漏洞，攻击者利用恶意请求，可以发送带有无法识别的服务名、方法名及某些恶意参数负载的RPC请求，当恶意参数被反序列化时将导致代码执行。



严重等级

高危



影响范围

Apache Dubbo 2.7.0 - 2.7.6

Apache Dubbo 2.6.0 - 2.6.7

Apache Dubbo 2.5.x

注：Apache Dubbo 2.5.x 官方已不支持。



漏洞版本自查

■ 在Web日志界面查看当前使用的Dubbo版本号。

■ 可在项目pom.xml文件中查看当前使用的Dubbo版本号。



漏洞复现

■ 开启dubbo服务，作为靶机服务器。

■ 开启ldap远程连接class文件用来攻击dubbo。

■ 运行poc，弹出计算器。



解决方案

 ■ 官方解决方案

Apache Dubbo官方已修复了该漏洞，建议用户通过以下链接尽快安装补丁程序：

https://github.com/apache/dubbo/releases/tag/dubbo-2.7.7


 ■ 迪普科技解决方案

1、使用迪普“慧眼检测平台”检测现网环境中是否存在Apache Dubbo Provider反序列化远程代码执行漏洞。

2、使用迪普“态势感知平台”检测现网环境中是否存在Apache Dubbo Provider反序列化远程代码执行漏洞攻击行为。

3、迪普科技安全服务团队可协助客户梳理现网使用Apache Dubbo的信息资产，指导客户安装补丁程序等安全加固工作。如服务器疑似被入侵，可安排安全服务专家分析和应急响应，并尽快帮助恢复系统，指导完善安全防护措施。
