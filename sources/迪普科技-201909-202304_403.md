背景描述

SMB是一个网络文件共享传输协议，它允许应用程序和终端用户从远端的文件服务器访问文件资源，SMB协议使用客户身份验证的方式来保障文件安全传输，客户端需要向服务器端发送验证密码获取文件传输的权限。Microsoft Windows SMBv3是SMB的version 3版本。

  

2020年3月10日，微软官方发布了一则禁用SMBv3压缩的通告，通告中描述了SMBv3协议在处理某些请求时存在远程代码执行漏洞(CVE-2020-0796)，远程攻击者可通过发送特制的数据包在未授权的情况下执行任意代码，甚至获取整台服务器的控制权限。

  

2020年6月2日，有国外安全研究人员在github上公开了该漏洞的利用源码，致使该漏洞被利用的概率大大增加，由于该漏洞无需身份验证即可被远程利用，可能会形成蠕虫级漏洞，迪普科技建议用户及时修补，做好相关防护措施。

  
  

严重等级

高危

  
  

漏洞描述

此次漏洞主要是由于受影响版本中Windows驱动srv2.sys处理SMBv3信息时，压缩数据包的解压函数Srv2DecompressData未严格校验数据包中OriginalCompressedSegmentSize

和Offset/Length字段的合法性，导致函数Srv2DecompressData中内存分配函数在分配内存时出现了错误，攻击者利用该漏洞制作特殊的数据包可以触发此漏洞并进行任意代码执行。

  
  

影响范围

Windows 10 Version 1903 for 32-bit Systems

Windows 10 Version 1903 for x64-based Systems

Windows 10 Version 1903 for ARM64-based Systems

Windows Server, version 1903 (Server Core installation)

Windows 10 Version 1909 for 32-bit Systems

Windows 10 Version 1909 for x64-based Systems

Windows 10 Version 1909 for ARM64-based Systems

Windows Server, version 1909 (Server Core installation)

  
  

解决方案

■** 官方解决方案**

微软官方已修复了该漏洞，建议用户通过以下链接尽快安装补丁程序：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2020-0796

  

■ **其他解决方案**

1、使用以下Powershell命令禁用压缩以阻止未授权的攻击者利用SMBv3服务器漏洞，该命令不能防御SMB客户端漏洞的利用。

Set-ItemProperty -Path "HKLM:\\SYSTEM\\CurrentControlSet\\Services\\LanmanServer\\Parameters" DisableCompression -Type DWORD -Value 1 -Force

  

2、关闭TCP 445端口。

  

■ **迪普解决方案**

迪普科技安全研究院在首次监测到Windows SMBv3远程代码执行漏洞后，就迅速采取了应急措施。

  

1、使用迪普“**慧眼检测平台**”检测现网环境中是否存在Windows SMBv3远程代码执行漏洞。

  

2、使用迪普“**态势感知平台**”检测现网环境中是否存在Windows SMBv3远程代码执行漏洞攻击行为。

  

3、迪普科技安全服务团队可协助客户完成现网安全风险评估，针对网络安全入侵事件，提供快速应急响应支撑服务以及专业的安全建设建议。
