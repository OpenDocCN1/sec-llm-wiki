# 脚踏实地，创新致远——浙江省企业发明专利授权量迪普科技位居第二！

内容提要  

近日，杭州市滨江区权威信息发布平台“滨江发布”发布了相关报道：根据《浙江省市场监督管理局关于印发2019年全省专利申请量和授权量等统计数据的通知》，全区发明专利授权量2939件，发明专利授权量增长48.36%，占杭州市的25.02%，企业发明专利授权量位居全省第一。在本次统计中，迪普科技入围2019年浙江省发明专利授权量前十强企业名单，并取得了第二名的好成绩。同时，迪普科技也位列国家知识产权示范企业名单。

![](../Images/6f5fc733502b880d6d7d666fdbe5030a.png)![](../Images/ab8b96b50c6efa9a9834eddcf8c467fa.png)

作为国家知识产权优势企业、国家高新技术企业，迪普科技一直深知自主创新对企业综合实力与市场竞争力的重要性。迪普科技在北京、杭州设有研发中心，拥有专业的软件开发及硬件逻辑开发团队，公司拥有一系列具有自主知识产权的核心技术。截止2019年底，迪普科技已总计申请技术专利1500余项，其中93%为发明专利。目前，迪普科技已获得中国专利优秀奖、教育部高校科研成果二等奖、浙江省技术发明一等奖、浙江省科技进步三等奖等荣誉。

  

基于自主知识产权的核心技术，迪普科技推出了包括自安全园区网解决方案、自安全分支机构解决方案、自安全物联感知网解决方案、“云安全 硬实力”云数据中心安全解决方案、”融·慧·管·通“互联网出口解决方案在内的一系列面向典型用户使用场景的场景化解决方案并获得了市场的广泛认可。

  

未来，迪普科技将坚持自主创新的发展道路，为客户提供更优质的产品及解决方案！
