# 杭州市常务副市长戴建平一行考察迪普科技

内容提要

1月3日,杭州市委常委、常务副市长戴建平一行莅临迪普科技考察调研，市政府秘书长丁狄刚、副秘书长姚吉锋、鲍一飞，滨江区委常委、常务副区长姜永柱、滨江区经信局副局长姜黎等领导陪同。杭州迪普科技股份有限公司董事、常务副总裁邹禧典及市场部领导接待了戴市长一行。邹禧典介绍了公司整体发展情况及迪普科技代表性的产品与解决方案，戴市长对迪普科技的企业文化及解决方案表达了认同，并充分肯定了迪普科技在国内网络安全领域的领导地位。

  
![](../Images/a273c3ac1d4d3171d534bbae2280f7c7.png)

戴市长参观了迪普科技解决方案体验中心，了解到迪普科技的自安全物联感知网解决方案能够通过“白名单”机制，并可对整个物联感知网前端 IP 设备和传输的流量进行精确管控，他对该方案价值表达高度的认可。在得知该方案在近期已规模应用于杭州市地铁建设相关项目中，他更是表示到：“迪普科技能为杭州地铁公安视频监控系统保驾护航，正是自身价值得到了充分的体现，相关单位也应大力的支持本地优质产品的应用。”

![](../Images/d62964c053ef5bd35aa3afe50e82c578.png)

除此之外，在得知迪普在网络安全设备和应用交付产品已经连续多年获得了国内市场排名前三的好成绩时，戴市长充分肯定了公司在专业领域获得的成就，他提到：“迪普能在国内的网络安全市场取得领先的地位，与自身坚持走自主创新的道路和始终将客户需求放在第一位的服务目标是分不开的，杭州市政府相关部门也会一直加大对高新技术产业的扶持，助力企业成长。”

![](../Images/02b6afc41edb43685462800bfa0bf09b.png)  

迪普科技自成立以来，一直以研发创新为企业核心发展推动力，目前，迪普科技已申请技术专利1500余项，其中93%为发明专利。已获得中国专利优秀奖、教育部高校科研成果二等奖、浙江省技术发明一等奖、浙江省科技进步三等奖等荣誉。未来，迪普科技将继续坚持自主创新的发展道路，为客户提供更优质的产品及解决方案！
