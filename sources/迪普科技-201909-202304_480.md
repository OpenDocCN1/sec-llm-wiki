# \[漏洞预警\] Nginx+ PHP-FPM远程代码执行漏洞

PHP(Hypertext Preprocessor)是一款运行在服务器端的开源免费的脚本语言，主要用于在WEB开发过程中创建动态交互性站点，由于其成本低、速度快、可移植性好等众多优点，使其成为目前最流行的编程语言。

  

**背景描述**

近日，PHP官方发布了一则漏洞公告，在Nginx和PHP-FPM的服务器环境中的特殊配置下，由于未对fpm\_main.c文件中env\_path\_info的前缀进行有效检查，攻击者可通过发送特制的URL请求，导致远程代码执行。

目前网上已出现了利用脚本，而大部分使用Nginx和PHP-FPM的网站都还没及时修补，迪普科技建议用户及时修补，做好相关防护措施。

  

**严重等级**

**高危**

  

**漏洞描述**

此次漏洞主要由于PHP-FPM中sapi/ fpm/ fpm/ fpm\_main.c文件内的env\_path\_info下溢导致，攻击者可以使用换行符%0a破坏Nginx中fastcgi\_split\_path\_info对应的正则表达式，导致传递给PHP-FPM的PATH\_INFO值为空，从而触发该漏洞，通过发送特制的URL请求，在一些特殊的配置情况下会导致任意代码执行。

  

**影响范围**

Nginx + PHP-FPM环境：

PHP 5.6

PHP 7.0 

PHP 7.1 

PHP 7.2 

PHP 7.3
