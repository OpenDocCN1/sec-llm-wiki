# 前言

昨天乌克兰安全研究员`Yurii Sanin`公开了漏洞`CVE-2022-45025`的漏洞细节，这里来个简单的复现。该漏洞是利用了`VScode`/`Atom`的`Markdown Preview Enhanced for VSCode`插件中的代码漏洞从而实现命令注入。

![](../Images/01a3d567bddecf1ee24c68b1f99d18fb.png)
