# 十一、DOM

`DOM`的全称是`Document Object Model`，即文档对象模型；而我们浏览器页面这里的叫做`BOM`，即浏览器对象模型。

对于`BOM`来说，是基于`window`的，例如之前我们代码里面的`alert()`，实际上是`window.alert()`，并且弹出来的窗口也是和浏览器相绑定的。
