一、数组

  1. 现在有no1%no2%no3%no4%no5这样一串字符串，我们想以%为分隔符，然后把剪切后的字符串的内容放到数组里面，并进行遍历。我们先用for循环写一个：
<?php
$str = 'no1%no2%no3%no4%no5';
$arr = explode('%',$str);
print_r($arr);
echo '<br/>';
for($i=0;$i<count($arr);$i++){
    echo $arr[$i].'<br/>';
}
?>

再用while循环写一个：

<?php
$str = 'no1%no2%no3%no4%no5';
$arr = explode('%',$str);
print_r($arr);
echo '<br/>';
$i=0;
while($i<count($arr)){
    echo $arr[$i].'<br/>';
    $i++;
}
?>

最后用do...while 语句写一个：

<?php
$str = 'no1%no2%no3%no4%no5';
$arr = explode('%',$str);
print_r($arr);
echo '<br/>';
$i=0;
do{
    echo $arr[$i].'<br/>';
    $i++;
}
while($i<count($arr));
?>

更进一步，我们要通过:和%去分隔我们的字符串no1:no2%no3:no4%no5，我们可以这么写：

<?php
$str1 = 'no1:no2%no3:no4%no5';
$arr1 = explode('%',$str1);
$str2 = implode('<br/>',$arr1);
$arr2 = explode(':',$str2);
$i = 0;
do{
    echo $arr2[$i].'<br/>';
    $i++;
}
while($i < count($arr2));
?>

我们学到了一个新操作：使用 implode() 函数将数组转换为字符串。从上述例子中我们可以认识到，第一个参数是隔开的字符，第二个就是所转换的对象。

  1. 冒泡排序法

如果我们想对一个数组里面的内容进行从小到大排序，我们可以这么写：

<?php
$arr = array(31,52,63,98,76,45,12,25,36);
$temp = 0;
for($i=0;$i<count($arr)-1;$i++){
    for($j=0;$j<count($arr)-1-$i;$j++){
        if($arr[$j]>$arr[$j+1]){
            $temp = $arr[$j];
            $arr[$j] = $arr[$j+1];
            $arr[$j+1] = $temp;
        }
    }
}
print_r($arr)
?>

采用的是经典的”冒泡排序法“，由于我们只需要比较到倒数第二个即可，所以是count($arr)-1；外循环的意思是挨个遍历出要进行大类比较的次数，内循环让要比较的数和后面要被比较的数进行比较，如果前面比后面的大，就把前面的放后面，依次下去，得到从小到大的顺序。

为了后续便于使用，我们把它打包成一个函数from_min_to_max()：

<?php
function from_min_to_max($arr){
    for($i=0;$i<count($arr)-1;$i++){
        for($j=0;$j<count($arr)-1-$i;$j++){
            if($arr[$j]>$arr[$j+1]){
                $temp = $arr[$j];
                $arr[$j] = $arr[$j+1];
                $arr[$j+1] = $temp;
            }
        }
    }
    print_r($arr);
}
$arr = array(31,52,63,98,76,45,12,25,36);
$temp = 0;
from_min_to_max($arr);
?>

现在我们的九个数以及可以实现从小到大排序了，但是如果我们此时在最末尾再执行print_r($arr);，我们会发现它仅仅是把原来数组里面的内容打印了出来。因为我们虽然执行了调用函数的操作，但是我们并没有对$arr的内存地址对应的数据进行任何操作。如果我们想让函数调用时，$arr也跟着变化，我们可以这么写：

<?php
function from_min_to_max(&$arr){
    for($i=0;$i<count($arr)-1;$i++){
        for($j=0;$j<count($arr)-1-$i;$j++){
            if($arr[$j]>$arr[$j+1]){
                $temp = $arr[$j];
                $arr[$j] = $arr[$j+1];
                $arr[$j+1] = $temp;
            }
        }
    }
    print_r($arr);
}
$arr = array(31,52,63,98,76,45,12,25,36);
$temp = 0;
from_min_to_max($arr);
print_r($arr);
?>

没错，仅仅是加了一个取地址符&。

如果我们想知道计算机在遍历的时候每一步具体做了些啥，我们可以这么写：

  1. 选择排序法

直接上代码：

<?php
function select_min_to_max(&$arr){
    $temp = 0;
    for($i=0;$i<count($arr)-1;$i++){
        //假设$i是最小的
        $minval = $arr[$i];
        //记录最小数的下标
        $minindex = $i;
        for($j=$i+1;$j<count($arr);$j++){
            if($minval>$arr[$j]){
                //说明我们认为的最小值不是最小
                $minval = $arr[$j];
                $minindex = $j;
            }
        }
        //最后进行交换
        $temp = $arr[$i];
        $arr[$i] = $arr[$minindex];
        $arr[$minindex] = $temp;
        print_r($arr);
        echo '<br/>';
    }
    print_r($arr);
}
$arr = array(31,52,63,98,76,45,12,25,36);
$temp = 0;
select_min_to_max($arr);
?>

  1. 接下来我们说插入排序法
<?php
function insert_min_to_max(&$arr){
    $temp = 0;
    for($i=1;$i<count($arr);$i++) {
        //用$insertval表示准备插入的数
        $insertval = $arr[$i];
        //和谁先比较
        $insertIndex = $i - 1;
        //如果该条件满足，说明还没找到合适的位置
        while ($insertIndex >= 0 && $insertval < $arr[$insertIndex]) {
            //把数往后移
            $arr[$insertIndex + 1] = $arr[$insertIndex];
            $insertIndex--;
        }
        //如果找到了，直接进行插入
        $arr[$insertIndex + 1] = $insertval;
    }
}
$arr = array(31,52,63,98,76,45,12,25,36);
insert_min_to_max($arr);
print_r($arr);
?>

先把第一个数拉下来，再把第二个数拉下来，接着让第二个数和第一个数对比，发现52确实比31大，所以继续拉取第三个数、第四个数，都是依次递增的，所以都是不用调动位置的；当拉下来第5个数76的时候，76比31、52、63都要大，但是比98小，所以把76插在63和98之间；继续拉第六个数45，发现45比31大，比52小，所以插在31和52之间；继续拉第七个数12发现他比目前排在第一个的31还要小，所以插在31前面；继续拉第八个数25，发现它比12大，但是比31小，所以插在12和31之间；继续拉第九个数36，发现它比12、25、31都要大，比45小，所以插在31和45之间。

  1. 二分法查找

前面我们让数从无序变成了有序，以便于我们查找数据，接下来我们说说如何应用二分法帮助我们查找数据。

二分法应用的前提是，数组内元素已经有序。

<?php
function binary_search(&$arr,$findval,$leftindex,$rightindex){
    //当$rightindex<$leftindex
    if($rightindex<$leftindex){
        echo '找不到QAQ';
        return ;
    }
    //找到中间数
    $middleindex = round(($leftindex+$rightindex)/2);
    //如果大于就往后面找，小于就往前面找
    if($findval>$arr[$middleindex]){
        binary_search($arr,$findval,$middleindex+1,$rightindex);
    }elseif ($findval<$arr[$middleindex]){
        binary_search($arr,$findval,$leftindex,$middleindex-1);
    }else{
        echo '找到了嘿嘿嘿O(∩_∩)O，是第'.$middleindex+1 .'个数';
    }
}
$arr = array(6,66,666,6666,66666,666666);
binary_search($arr,666,0,5);
?>

成功找到，是第三个数。

round() 函数可以对浮点数进行四舍五入，关于其详细用法，可以参考：

十、final关键字

final修饰的类名/方法名称为最终类/方法；由于final表示最终，所以其修饰的类不可以被继承。

关于setcookie()的七个参数的问题，可以参考掘金上面的这篇文章：https://juejin.cn/post/6913859013008605198

我们这里作部分引用：

第一个：name,必选参数，这个是cookie的变量名，可以通过$_COOKIE['user']调用变量名为user的cookie.

第二：value,可选参数，这个cookie变量的值,比如说setcookie(“user”,”php”),我们通过调用$_COOKIE['user']可以得到php值;

第三个：expire,可选参数，这个是用来设置cookie变量保存的时间，注意是我们设置的的UNIX时间戳减去当前的UNIX时间戳才是 cookie变量保存的时间。（UNIX时间戳：是从1970年1月1日（UTC/GMT的午夜）开始所经过的秒数) ，一般我们可以通过time()函数获取当前的UNIX时间戳，再加上我们要保存的时间（单位为秒）比如 说，setcookie(“user”,”php”,time()+3600),这样我们就可以保存user这个cookie变量的时间为3600秒。另 外我们可以通过设置的时间戳小于当前的时间戳来删除cookie变量，比如说setcookie(“user”,”php”,time()-1)这样我们 就删除了user这个cookie变量了。

第四个：path,cookie的有效范围，这个参数是下一个参数domain基础上的有效范围，如果path设置为”/”，那就是在整个 domain都有效，比如setcookie(“user”,”php”,time()+3600,”/”),这样我们domain下的任何目录，任何文 件都可以通过COOKIE[′user′]来调用这个cookie变量的值。如果path设置为”/test”,那么只在domain下的/test目录及子目录才有效，比如domain下有两个目录:test1,test2,我们设置为setcookie(“user”,”php,time()+3600,”/test1″)，那么只有test1目录下才能通过_COOKIE['user']来调用这个cookie变量的值。如果path设置为”/test”,那么只在domain下的/test 目录及子目录才有效，比如domain下有两个目录: test1,test2,我们设置为setcookie(“user”,”php,time()+3600,”/test1″)，那么只有test1目录 下才能通过COOKIE[′user′]来调用这个cookie变量的值。如果path设置为”/test”,那么只在domain下的/test目录及子目录才有效，比如domain下有两个目录:test1,test2,我们设置为setcookie(“user”,”php,time()+3600,”/test1″)，那么只有test1目录下才能通过_COOKIE['user']调用user这个cookie变量的值，test2目录下获取不到。

第五个：domain,cookie有效的域名，如果domain,设置为googlephp.cn，那么在googlephp.cn下的所有子域都有 效。假设googlephp.cn有两个子域，php.googlephp.cn，css.googlephp.cn，我们设置为 setcookie(“user”,”php”,time()+3600,”/”,”php.googlephp.cn”),那么只有在 php.googlephp.cn这个子域下才能获取user这个cookie变量的值. 再举一个例子：setcookie(“user”,”php”,time()+3600,”/test”,”php.googlephp.cn”),那么 只有在php.googlephp.cn这个子域下的test目录下才能获取user这个cookie变量的值.

第六个：secure，值cookie是否仅通过安全的https,值为0或1，如果值为1，则cookie只能在https连接上有效，默认值为 0，表示cookie在http和https连接上都有效。
