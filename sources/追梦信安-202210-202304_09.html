一、为什么需要搭建私密搜索引擎

众所周知，我们上一秒刚在百度上面搜索一件物品，下一秒我们打开淘宝的时候，搜索栏里面大概率会出现这个东西，甚至几天后能在我们的其他社交软件上面出现相应的广告，这让我们感到十分担忧。

1. 无痕浏览器，它真的无痕吗？

随便找个新闻：

Google to Face $5B Lawsuit Over Tracking Users in Incognito Mode

所谓无痕浏览器仅仅是个黑夜模式下的不对其他网站公开cookie的浏览器而已。

2. DuckDuckGo搜索引擎如何？

当我们浏览暗网的时候，需要用到Tor浏览器，他的默认搜索引擎便是DuckDuckGo，这款搜索引擎一直是以保护用户隐私闻名。但是DuckDuckGo和微软有很深的合作关系，比如说当你在DuckDuckGo中点击了微软的广告的时候，它会把你的ip告诉Microsoft Advertising。

DuckDuckGo has a ‘tracking deal’ with Microsoft and here's why no one is happy about it

所以觉得DuckDuckGo是个隐私浏览器是一个很扯淡的事情。

二、搭建一个自己的私人浏览器

综上所述，搭建自己的一个私人浏览器是一个很有必要的事情。

1. 安装环境、下载项目

我们通过在自己的服务器上面执行以下命令进行安装：

sudo apt update
sudo apt upgrade
sudo apt install git  # 安装完成之后需要进行配置
sudo apt install docker.io
sudo apt install docker-compose
cd /usr/local
git clone https://github.com/searxng/searxng-docker.git
cd searxng-docker
sed -i "s|ultrasecretkey|$(openssl rand -hex 32)|g" searxng/settings.yml

光这么做还不行，还需要vi docker-compose.yml，然后修改这里的127.0.0.1为0.0.0.0，否则外网是无法访问的。
