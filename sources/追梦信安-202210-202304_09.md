# 一、为什么需要搭建私密搜索引擎

众所周知，我们上一秒刚在百度上面搜索一件物品，下一秒我们打开淘宝的时候，搜索栏里面大概率会出现这个东西，甚至几天后能在我们的其他社交软件上面出现相应的广告，这让我们感到十分担忧。

## 1\. 无痕浏览器，它真的无痕吗？

随便找个新闻：

Google to Face $5B Lawsuit Over Tracking Users in Incognito Mode

![](../Images/07cc9508c6fc92387ca869dc9dcadf2a.png)

法院的结论是，谷歌没有通知用户，当用户处于私人浏览模式时，谷歌参与了所谓的数据收集。

所谓无痕浏览器仅仅是个黑夜模式下的不对其他网站公开`cookie`的浏览器而已。

## 2\. DuckDuckGo搜索引擎如何？

当我们浏览暗网的时候，需要用到`Tor`浏览器，他的默认搜索引擎便是`DuckDuckGo`，这款搜索引擎一直是以保护用户隐私闻名。但是`DuckDuckGo`和微软有很深的合作关系，比如说当你在`DuckDuckGo`中点击了微软的广告的时候，它会把你的`ip`告诉`Microsoft Advertising`。

DuckDuckGo has a ‘tracking deal’ with Microsoft and here's why no one is happy about it

![](../Images/360ae084cf181e3c3226c013221a8a13.png)

所以觉得`DuckDuckGo`是个隐私浏览器是一个很扯淡的事情。

# 二、搭建一个自己的私人浏览器

综上所述，搭建自己的一个私人浏览器是一个很有必要的事情。

## 1\. 安装环境、下载项目

我们通过在自己的服务器上面执行以下命令进行安装：

```


sudo apt update# 安装完成之后需要进行配置

cd /usr/local
clone
 https://github.com/searxng/searxng-docker.gitcd
 searxng-docker"s|ultrasecretkey|$(openssl rand -hex 32)|g"
 searxng/settings.yml
```

光这么做还不行，还需要`vi docker-compose.yml`，然后修改这里的`127.0.0.1`为`0.0.0.0`，否则外网是无法访问的。

![](../Images/26ca392b8aae40d6599525e8ff75f2c4.png)

## 2\. 启动SearXNG

接下来我们需要执行`docker-compose up -d`：

![](../Images/9fe3ff8e51f3a8eb1fed5ad218beb898.png)

然后我们访问`服务器ip:8080`即可看到搜索引擎的页面：

![](../Images/ee2c5630b806efc65ce4086102b89431.png)![](../Images/87b10c4638cf51354fc2785359a3be03.png)

如果我们觉得官方的默认设置不满意，我们可以这么做：

```

# 按esc并键入:wq进行保存
cd

```
