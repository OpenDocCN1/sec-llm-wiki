0x00 DNSStager简介

DNSStager 是一个开源工具，用于帮助 Pentesters/RedTeamers 在 DNS 中隐藏其有效负载并根据多个 DNS 记录解析它，例如 IPv6和 TXT然后将其注入内存并为您运行它。DNSStager 将为您创建一个虚假的 DNS 服务器，该服务器将根据 AAAA 和 TXT 记录解析域的虚假地址，这些地址呈现一部分有效负载编码/加密并可供代理使用。DNSStager 可以为您生成 C 或 GoLang 代理，您只需为 DNSStager 定义一些变量，它会为您处理整个过程。

DNSStager client.exe 将尝试解析 N 由 DNSStager 生成的 DNSStager 将对有效负载进行编码，将其拆分为块。

0x01 功能介绍

  • 隐藏和解析你的有效载荷 IPv6记录。

  • 隐藏和解析你的有效载荷 TXT记录。

  • XOR 编码器对有效载荷进行编码。

  • Base64 编码器对有效负载进行编码（仅适用于 TXT 记录）。

  • 一个纯代理写在 C具有自定义它的能力。

  • 一个纯代理写在 GoLang具有自定义它的能力。

0x02 安装流程

git clone https://github.com/mhaskar/DNSStager//下载
pip3 install -r requirements.txt//安装

需要 root 权限才能启动 DNSStager

0x03 DNS 设置

要使用 DNSStager，您需要将域指向 DNSStager 作为他的名称服务器“DNS 服务器”，以便解析和处理进入您域的任何 DNS 请求。

例如，正在控制一个名为 mydnsserver.live创建了一个名为的子域 test.mydnsserver.live并制作 mydnsserver.live“NS” – 名称服务器 test.mydnsserver.live在运行 DNSStager 之后 mydnsserver.live .
