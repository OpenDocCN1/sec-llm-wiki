零、起源

某些特殊场景下需要进行近源渗透测试，所以就需要使用手机连接wifi做一些小测试。所以就有了这么篇捣鼓的小短文。

一、准备工作

  1. （必须）一颗乐于折腾的心。（手机上安装kali的方法有很多，我这个应该是比较快的，参考比较了网上的各种教程）

  2. （必须）一台已经root的安卓设备，我的是小米9；（如果不root，kali的很多功能使用不了）

  3. （必须）在手机上安装termux，安装地址：

https://github.com/termux/termux-app/releases

  1. （可选）Vnc Viewer

链接: https://pan.baidu.com/s/1cOj5oolyevKfPuxDF4UjBQ?pwd=6666 提取码: 6666

二、安装kali

  1. 安装基础部分

在termux中执行（中间一旦遇到文件下不下来的问题，通通科学上网）：

pkg update
pkg upgrade
termux-setup-storage
git clone https://github.com/Hax4us/Nethunter-In-Termux
cd Nethunter-In-Termux
chmod 077 kalinethunter
./kalinethunter

可以看到，已经开始下载了：

安装完成之后，输入nh或者startkali -r都可以启动kali。

  1. （可选）使用图形界面

    执行以下命令：

    apt update && apt upgrade && apt dist-upgrade
    apt --fix-broken install
    apt-get install xorg desktop-base xfce4 xfce4-places-plugin
    vncsever

    启动vnc server：localhost:5901

即可看到图形化界面，配合蓝牙键盘使用感觉更佳~：
