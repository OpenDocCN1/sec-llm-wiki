# 零、起源

某些特殊场景下需要进行近源渗透测试，所以就需要使用手机连接`wifi`做一些小测试。所以就有了这么篇捣鼓的小短文。

![](../Images/82dca7f00c461d6750347ea1744f9f87.png)

# 一、准备工作

1.  （必须）一颗乐于折腾的心。（手机上安装kali的方法有很多，我这个应该是比较快的，参考比较了网上的各种教程）
    
2.  （必须）一台已经`root`的安卓设备，我的是小米`9`；（如果不`root`，`kali`的很多功能使用不了）
    
3.  （必须）在手机上安装`termux`，安装地址：
    

> https://github.com/termux/termux-app/releases

![](../Images/b16dd2207848a37158d707dd4ce6270f.png)

4.  （可选）`Vnc Viewer`

> 链接: https://pan.baidu.com/s/1cOj5oolyevKfPuxDF4UjBQ?pwd=6666 提取码: 6666

# 二、安装kali

1.  安装基础部分

在`termux`中执行（中间一旦遇到文件下不下来的问题，通通`科学上网`）：

```


pkg update
```

可以看到，已经开始下载了：

![](../Images/4714d845b0105218b968406c0c4a5737.png)

安装完成之后，输入`nh`或者`startkali -r`都可以启动`kali`。

![](../Images/59de3c1977af01b6b4c8cbd0232bf561.png)

2.  （可选）使用图形界面
    
    执行以下命令：
    
    ```
    
    
    apt update && apt upgrade && apt dist-upgrade
    ```
    
    启动`vnc server`：`localhost:5901`
    

![](../Images/fc1cde176787d9df5b0d2a27d6897492.png)

即可看到图形化界面，配合蓝牙键盘使用感觉更佳~：

![](../Images/f3a60df0629af678a0c3e281b6cce08b.png)
