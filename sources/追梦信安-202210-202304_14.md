# 零、起源：

最近做一些项目的时候，需要采集url并进行漏洞的快速扫描，但是网上的都不是很符合我的想法，于是决定自己做一个，用了一个中午，写了这么个工具，没什么含金量，但是自己用起来没什么问题，也挺顺手。  

# 一、项目地址：

> https://github.com/W01fh4cker/Fofa-url/

可以去`https://github.com/W01fh4cker/Fofa-url/releases/tag/v0.1.0-alpha`下下载打包好的程序，然后去`https://github.com/W01fh4cker/Fofa-url/blob/main/logo.ico`下载`logo`文件，这两个文件放在一个文件夹里面即可使用。

# 二、使用方法：

配置`fofa`——>把`fofa`语法进行`base64`加密——>输入加密后的语句和查询条数——>点击查询。
