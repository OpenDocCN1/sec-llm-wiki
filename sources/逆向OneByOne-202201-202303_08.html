三、frida_hook_java层入门

① 准备工作：下载frida-server文件，详见这篇文章：https://blog.csdn.net/weixin_43411585/article/details/122503411?spm=1001.2014.3001.5502


② 已经root的手机与电脑通过usb连接，在cmd窗口输入如下几行，开启frida服务，只有开启了frida服务才能进行frida hook，且保持这个cmd窗口不要关闭

adb shell
su
cd /data/local/tmp
./frida-server-15.1.14-android-arm64

③ 分析代码编写frida-hook脚本，如图我们知道sign值是Utils.MD5加密得到的，所以我们要hook的类名就是com.mylrc.mymusic.tool.Utils，要hook的方法就是MD5，传入参数一个，返回参数一个

④ 编写hook_fida脚本如下，打印输出明文，以及返回结果，该js文件命名为music_match.js

function hook_java(){
    // 目的：hook 类名：com.mylrc.mymusic.tool.Utils 下的 MD5 方法，查看输入明文组成结构
    Java.perform(function(){
        var utils = Java.use("com.mylrc.mymusic.tool.Utils");
        console.log(utils)
        utils.MD5.implementation = function(key){
            console.log("Utils.MD5_key", key);
            var result = this.MD5(key);
            console.log("Utils.MD5_result", result);
            return result
        }
    })

}

setImmediate(hook_java)


⑤ 在jadx的AndroidManifest.xml文件下查看app的包名是com.mylrc.mymusic

⑥ 另开一个cmd窗口输入frida -U -l music_match.js --no-pause -f com.mylrc.mymusic，此时敲个回车，然后在手机端app上搜索周杰伦，如图cmd打印出hook的内容，明文周杰伦1646545254800wyy_search，确实和我们前面看java代码的明文组成是一样的，hook成功，第一个案例结束

⑦ 以上整个步骤用到的cmd命令如下，usb连接root手机，frida服务开启，写注入的js

# 第一步：开一个cmd窗口先开frida服务
adb shell
su
cd /data/local/tmp
./frida-server-15.1.14-android-arm64
# 第二步：另开一个cmd窗口注入hook的js
frida -U -l music_match_hook.js --no-pause -f com.mylrc.mymusic

⑧ 总结：frida hook 函数方法，确定类名，确定方法名，然后传参个数，然后按如下格式填写即可hook；setImmediate用于执行给定的function，当从控制台进行hook时会调用相关的function

function hook_java(){
    // 目的：hook 类名：xxxxxxxx 下的 kkkk 方法
    Java.perform(function(){
        var utils = Java.use("待填写的类名");
        utils.待填写的方法名.implementation = function(key){
            待编写的逻辑
        }
    })

}
setImmediate(hook_java)
