网上看到好多关于内置frida-gadget的文章，今天也来实践下,故采用了两种方式，第一种通过lief工具把frida-gadget和目标app的so链接到一起，第二种修改AOSP源码内置frida-gadget，示例源码包android\_8.1.0\_r1，机型Google Nexus 5x。  

  

**一.利用lief工具把frida-gadget和目标app的so链接到一起**

       原理就是app在执行so的文件的时候，加载frida-gadget.so，大部分so文件，在运行的时候，都有一些依赖库。这一步就是把 frida gadget.so加入到apk 本身so的依赖库中,实现内置frida，因为app需要重打包，所以app检测签名验证就会失败，这里我借鉴了大佬的脚本然后自己修改了下，hook掉签名验证，解决了重打包签名效验的问题,一键重打包脚本地址奉上,frida版本根据自己的需求进行替换，具体使用方法请看说明

写好的frida\_script.js代码adb push /data/local/tmp 即可实现持久化功能，修改AOSP源码有二种方式

**1. **fork进程的时候dlopen frida-gadget给每个进程都加上frida。找    到frameworks/base/core/jni/com\_android\_internal\_os\_Zygote.cpp文件下com\_android\_internal\_os\_Zygote\_nativeForkAndSpecialize函数,增加代码如下

*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   
*   

```

// 加入头文件#include <dlfcn.h>if (pid == 0 ){    #if defined(__arm__) || defined(__aarch64__)        #if defined(__arm__)            #define FRIDA_LIB "/system/lib/libfrida-gadget-14.2.18-android-arm.so"        #else            #define FRIDA_LIB "/system/lib64/libfrida-gadget-14.2.18-android-arm64.so"        #endif        const char *name = env->GetStringUTFChars(se_name, 0);        void* frida = dlopen(FRIDA_LIB, RTLD_NOW);        if(NULL == frida) {            ALOGE("(%s) load frida-gadget(%s) failed, err= %d\n",name,  FRIDA_LIB, errno);        } else {            ALOGI("(%s) load frida-gadget(%s) success\n", name, FRIDA_LIB);        }        env->ReleaseStringUTFChars(se_name, name);   #endif}
```

编译成功后可以使用 adb logcat | grep frida 观察frida-gadget是否加载成功。

**2.**找到frameworks/base/core/java/android/app/ActivityThread.java文件下handleBindApplication函数增加代码如下

*   
*   

```
// 架构是64的，直接加载64位的frida-gadgetSystem.loadLibrary("frida-gadget-14.2.18-android-arm64");
```
