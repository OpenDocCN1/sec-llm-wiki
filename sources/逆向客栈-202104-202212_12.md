# 某app native层加密参数分析

首先使用AndroidNativeEmu项目调用so文件,不会的看上一篇文章，明文为

```
0123456789123456
```

下面请出今天的受害者:  

![](../Images/6d2fda4515353361b58a3e7b3d6de2cc.png)

从密文来看是base64,打开ida分析下整体逻辑，一共60行代码，还算简单  

![](../Images/1924b2049f49640c63b7a7971f9ed286.png)

从整理逻辑可以看出分为3部分,

1.将明文加上盐值,

2.进行md5加密,

3.对md5加密后的结果取偶数进行base64,

当然这只是静态分析的结论，不确定是否魔改，需要我们一步一步进行确定，先看第一部分

![](../Images/61957197bb6219953559b8f5c2903ff7.png)

从上图可以看出添加32个字节的盐值，因为这个盐值没有涉及到明文和随机数，应该可以确定固定不变的。

再看第二部分,下图是md5加密，从开头生成的4个固定常数,可以确定为md5加密,如果不确定可以使用findcrypt插件确定下即可

![](../Images/46e1d690af8ef4ade0dbdcb5fdabe492.png)

最后明文加盐后的结果保存在V4中，我们直接打印sub\_7A08函数(MD5\_update) r1寄存器的值, 取(前密文长度+32)=48个字节，就能确定加密前的参数了

![](../Images/c0cae813089c22eee5f95fccf936e176.png)

可以看出后32字节就是我们的盐值,确定了加密参数，我们hook下sub\_7A8函数(MD5\_dofinal) r1寄存器取16个字节,就能知道加密后的md5值了，  

![](../Images/262c89ebd3440ffebd45bc92e4f30637.png)

![](../Images/c8fc33e4fdc40f38e3df3231e738aa06.png)

有了加密参数和结果想确定下魔改没还不简单，在线加密下即可  

![](../Images/eeb9a1bf3cc65b1821023dbd60749465.png)

发现结果对上了，说明就是标准的md5。

在往下看第三部分

![](../Images/69d2f96cf52ce77305d902d111c2534d.png)

取md5结果后的偶数

![](../Images/690e08422a5ae282599a9bcd96cc8cb2.png)

进行base64,我们在线base64加密试试

![](../Images/375ab427843db1b2a20fb4ec4d156702.png)

和密文对比一致，说明都是标准的算法,文章仅供学习交流，请勿用于非法用途，如有侵犯到贵公司隐私或者利益，请联系我立马删除。
