# 问题描述

*已知*：  
N,e1,e2,c1,c2

N = p*q  
c1 = (2*p + 3*q)\*\*e1 mod N  
c2 = (5*p + 7\*q)\*\*e2 mod N

求p,q

# 解题思路

已知条件很简单，可以看出就是一道考数学知识的。我看到此题的时候感觉有点像共模攻击但是M不同，那两个式子化了半天也不行，后面在别人的提示下淦了一下午才解出来（痛苦），解题过程很巧妙直接看图吧。两种解法其实思路一样的。  
![](../Images/3d8b0d850b0d0d169a9cee876b52280d.png)

![](../Images/8700b2342e869b570cbd79657c14deb7.png)  
主要思想有3步：  
1，等式两边\*\* e1和\*\* e2  
2，解方程组（这里就是我卡住的地方，我一直在想在一个式子上乘一个数划掉一个未知数，后面居然是在两个式子上进行变换，高中数学忘完了hhh）  
3，p\*\* e1e2 与N的公因子就是p（自己可以理解哈）

总结：密码学与数学很相关，多多积累吧。
