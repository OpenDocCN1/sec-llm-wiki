还有它说

使用root用户建立名为cowrie的数据库并将该库中的所有表授权给cowrie

mysql -u root -pEnter password: ******* mysql>CREATE DATABASE cowrie;mysql> GRAN

这段其实很大的坑。大家还是按照我来的吧

mysql -u root -p

然后

CREATE DATABASE cowrie;

接着

GRANT ALL ON cowrie.* to root@localhost IDENTIFIED BY 'you password';

passWord一定要跟root密码一致。

往下看，将/opt/cowrie/ doc/sql/mysql.sql作为数据源即可制成多个表。这里你可以用phpmyadmin进行导入，具体个人爱好了。
