# 如何看待一项技术：技术的本质

技术很简单，技术不复杂。之所以大众觉得技术很复杂，要敬而远之，多半是因为两个原因，一是搞这项技术的人自己都没整明白，所以无法总结出简炼的语言；二是这项技术发展还很早期，所有人都还没整明白，所有人都在不知所云，比如十年前谈论云计算和大数据，都在不知所云。所以如果有个人给你讲技术听不懂，别担心，不是你的问题，是讲的那个人的问题。  

  

只要抓住了技术的本质，外行人也能一眼看穿技术，不被「专家」忽悠。技术不是科学，技术是很古老的存在，如果从轮子开始算起的话，有八千年以上的历史。而近代科学如果从伽利略开始算起，也不过几百年的历史。在此之前，技术都是由经验主导，而非由科学主导。科学大规模影响技术应该从工业革命开始算起，尤其是第二次工业革命，那算来也不过百多年的历史，这一历史认知远远超出大多数人的想象。  

  

那什么是技术？前文叙述过，技术是生产力，是新的能力，或新的体验。新生产力和新体验是不同的事情，以后再详细谈谈什么是新生产力，大家现在先记住，看待一项新技术，先看它提升了什么生产效率，如何提升的。也就是说先把这项技术的目标明确出来。所有做技术人的都是实用主义者，都着重于解决实际问题，这与科学的理论研究者是不同的，研究理论不需要明确解决了什么实际问题，但是技术需要。

  

前面几篇文章分别阐述了技术和商业的关系，阐述的目的，是为了让大家明白商业要什么，技术要什么，不要混为一谈。技术对商业帮助很大，商业对技术帮助也很大，但商业不是必须依赖于技术，技术也不是必须依赖于商业，不区分开的话问题很大，只是在当今时代这两者互为对方最强大的助力。事实上这一系列文章会谈到技术、商业、科学、解决方案、产品、商品等概念，这些都是很重要但是又不尽相同的概念，但大多数人在使用的时候经常混为一谈。理解不透彻的话，实际使用时就会做出错误的选择。只有认知了这些事物的本质，在做决策的时候才知道怎么选择。认知决定选择，选择决定命运。

  

技术很简单，我把技术的要素定义为：效率、成本、通用性、安全。其中效率是技术的主要价值目标，是一项新技术的出发点和根本。如果是以商业驱动的技术发展，则可以理解技术提高生产效率后，生产力增强，形成了可扩大投资规模的资本。未来会再讲讲军事驱动的技术，和政治驱动的技术，这两者和商业的重要区别在于不太计较ROI（投资回报）。

  

技术提升了效率，获得了新的能力。效率提升后，技术还需要进一步解决成本问题、通用性问题、安全问题，才能够扩大影响力和普及程度，形成生生不息的良性循环，进而改变世界。  

  

还是以工业革命举例，最早的纽科门蒸汽机是为了解决煤矿区的抽水泵的动力问题，这种蒸汽机是往复直线式的运动，功能很受局限，无法满足更多类型机械运动的要求。同时它消耗煤的成本也非常高。纽科门当时很聪明的选择了煤矿区的矿主们，对他们来说煤炭很便宜，而且纽科门蒸汽机使用煤矿的劣质废料也能燃烧。最早纽科门蒸汽机主要解决煤矿的抽水问题，这对煤矿来说是个刚需，因为渗水可能会引发矿难。但是这种蒸汽机的高耗煤成本，以及单一的往复直线式运动，都造成了纽科门蒸汽机无法推广到其他行业的场景。

  

这时候瓦特粉墨登场了。瓦特早期的主要改进，一是成本的优化，他发现了蒸汽机中80%的热量是消耗在维持汽缸的温度上，因为每一次活塞推动，汽缸里的蒸汽都要先冷凝，然后再加热进行下一次推动。瓦特采用了冷凝器和汽缸分离的设计，从而有效降低了成本；二是设计出了「曲柄传动」，将往复直线运动转化为了圆周运动，从而能够有效为大多数不同类型的机械装置提供动力。到了1785年，瓦特改良的多功能蒸汽机进入到了纺织行业，并得到广泛应用。而在此之前，这种多功能蒸汽机已经应用在采矿业、冶金业、造纸业等多个产业了。

 

但瓦特的主要贡献止步于此，他反对高压蒸汽的使用，因为高压蒸汽的不稳定可能带来爆炸，造成人员伤亡。但基于「大气作用力」原理的纽科门和瓦特的蒸汽机有着体积较大且重，而无法移动的缺点。在瓦特反对的同时，工程师威廉·默多克和理查德·特雷维西克则一直在研究高压蒸汽，并成功的解决了高压蒸汽的安全问题。在瓦特的专利过期后，特雷维西克将高压蒸汽机应用到了交通上，研制出了世界上最早的蒸汽机车和蒸汽船，从而开启了人类的新时代。

  
纵观每一次影响世界的技术革命，我们几乎都能看到类似的生命周期，一项新技术诞生之初，先解决效率问题，再依次解决成本、通用性和安全问题，最后新技术走向普及。

  

那么一项技术具体要怎么做呢？简单概括来讲，通过「结构与组合」的方式。如果玩过一款叫「文明」的游戏，就会理解「科技树」这个概念。科技树非常形象的表达了，一项新的科技的诞生，是以其他已有科技为基础的。那么技术的创造方式就在于，通过不同现有技术之间的组合，搭建出一种新的结构，去解决一个特定的问题。因此从某种意义上来说，技术即解决方案。

  

这里面的玄妙之处，在于如何搭建出一种的结构。不同的人会选用不同的原子技术，来搭建出不同的结构。而结构搭建的方式，则体现了各种各样的奇思妙想，或者背后有着某种理论指导。这是充满了知识和创意的地方。也是通过这样的结构搭建，才有效解决了效率、成本、通用性和安全的问题。因此原子技术很重要，结构也很重要。技术的创造方式，就是结构与组合。瓦特在改进纽科门蒸汽机时，做的两项设计改进：分离式的冷凝器，以及曲柄传动，就是典型的结构与组合的再设计，进而解决了纽科门蒸汽机的成本和通用性的问题。  

  

所有的技术扒开来看，都不神秘，都可以用很简单的原理和语言来描绘。

  

看完这篇文章，你明白该如何看待，以及如何规划一项新技术的发展了吗？
