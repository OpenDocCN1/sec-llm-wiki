# 认知决定选择

上篇文章谈到选择比努力重要，收到很多很好的留言，我觉得有必要再多讲讲。

  

选择比努力重要，这可能取决于人生、事物的不同的阶段，并非绝对的一句话。我并没有说努力不重要，我只是想表达选择比努力更重要。这可能与我的工作有关。我每天都在解决不确定性的问题，我的工作就是把不确定性变成确定性。一件工作如果到了靠团队加班就能解决问题的状态，对我来说是无比幸福的事情。如果大家很努力，但最后还是输了，则是最悲剧的事情。因此我每天想的是如何去结束一场战争，而不是让一场战争变成持续的消耗战。

  

Leader的工作是确保如何赢。这需要一个Leader有很多的思考，而不是简单的努力。在商业竞争中大多数时候是定位把竞争对手定死的，而不是靠销售和营销硬拼。你想吃掉别人的时候，别人也在想吃掉你，在同一个维度硬拼的结局往往是谁都吃不掉谁。定位对了，往往先赢了一半。

  

在红军长征途中，红一方面军与红四方面军会师后，发生路线冲突，红四方面军坚持南下发展，毛泽东坚持继续北上到陕北。事实上在当时的情况下，南下发展阻力太大，很难有活路。这是个认知上的问题。同样的，后来胡宗南的部队攻陷延安，共产党的部队选择把延安让出来，这是毛泽东的战略思想「不计较一城一地之得失，以消灭敌有生力量为主。」的重要体现。国民党得到了延安，但几年后反倒兵败如山倒。到了淮海战役的时候，粟裕提出不等平津战役出结果，要捕捉战机先吃掉黄百韬兵团，就是这一战略战术思想的重要体现，这也是粟裕对战局形式判断的认知极深，才能打这种别人不敢打的仗。

  

这些，都是认知问题。有了全面、深入的思考，才能做出这样的选择，才「敢」做出这样的选择。敢做别人不敢做的决定，还能一直赢下去，不是靠信息不对称决定的，是靠认知深度决定的。就像买股票一样，靠听消息买股票是不靠谱的，而巴菲特几十年如一日也就研究那么几只股票，对那几家公司和行业的认知深度甚至已经超过了这些公司的CEO，所以他在别人不敢买的时候敢买，别人都卖的时候他敢不卖。靠信息不对称赢来的是一时的，而靠认知深度赢来的是一世的。我学到另外一句话是：「靠运气赢来的东西，往往因为实力输掉。」
