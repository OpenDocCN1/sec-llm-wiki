# 技术是社会发展的动力

从今天开始，将用一系列短文，阐述一下我对于技术和商业的理解。  

  

回顾整个人类社会的发展历程，实际上是一部技术的发展史。再没有什么事物能够比技术给人类社会带来更加深远的影响了。技术深刻的影响了我们的经济，在经济发展史上没有英雄，如果有，那也是几次技术革命的技术贡献者。技术深刻的改造了社会形态，城市人口的大规模增长是工业革命的直接结果，同样技术催生了新的社会阶层，因此产生了新的社会道德准则。在两百多年前人们不需要上班，所有人都是以家庭为单位从事生产。而工业革命以后因为出现了规模庞大的大型机器，因此需要工人的大量聚集，劳动人民从家庭中走出来，到一个叫工厂的地方「上班」。工业革命后如雨后春笋般出现的有限责任公司，一方面成为经济发展的主力军，另一方面也让我们在现代社会难以平衡工作与生活的关系，甚至进一步的催生了「家庭主妇」的诞生。没有技术的发展，就没有新财富的诞生，资本的发展史，实际上就是技术的发展史。

 

但这一切只有短短二百余年的历史。瓦特在1765年改良了多功能蒸汽机，对其中的关键组件「冷凝器」做出了重大改进，最终瓦特在1784年生产出的新型蒸汽机比老式的纽科门蒸汽机的效率提高了5倍，拉开了人类历史上最波澜壮阔的工业革命的序幕。而我认为在随后的二百余年中，所有的技术革命都是工业革命的一种延续，因为每一次技术革命相隔不过数十年，有着类似的产生和传播条件，并互相影响，最终形成了我们今天的世界。在这份技术清单上我们可以罗列出一系列我们今天已经习以为常的技术：蒸汽机，铁路、火车头、蒸汽轮船、电报、电话、电气照明、电力基础设施、内燃机、汽车、石油化工、飞机、计算机、互联网、人工智能······因此工业革命这个说法也许并不准确，因为两百余年来的技术创新呈井喷态势，且有承上启下的连续性和相关性，一直到今天也不曾间断。每一个时期人类社会的经济、社会面貌、文化确实会大有不同，这些时代特征让我们可以对历史进行分段。因此不妨以重要技术来命名一个时代，比如蒸汽力时代、电力时代，因为时代的特征改变，追溯其根源，往往是这些技术突破所引起的。
