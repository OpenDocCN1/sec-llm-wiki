# A组的由来

昨天很多朋友发来消息问我什么是A组。A组是我团队的名字。在2019年7月我发的那篇《世界需要什么样的智能系统》最后提到了我组建A组的事情。在本公众号往前翻能够找到这篇很受欢迎的文章，这是我对智能系统思考的一个起点。

  

在这个背景下，经过组员共同探讨，形成了A组的使命是「以普惠AI技术让生活更美好」。普惠是我们的价值取向，AI技术是我们的实现路径。经历了一年多的发展，逐渐沉淀了自己的技术，未来会慢慢给大家汇报。

  

能叫A组这个名字，是我打赌赢回来了。当时我的老板不同意我给团队取名叫A组，说要叫孵化创新。我说叫劳什子孵化创新，一点特色都没有，我要叫A组。老板说那我们打个赌，你赢了就听你的。然后写下一个数字，让我猜奇偶。我赢了，所以这是上天注定我要叫A组。

  

至于为什么叫A组，有很多原因。其中一个原因是我很多年前读过的一本小说，其中有一个A组，都是身怀绝技保家卫国的人。我最喜欢的人物叫小妖，大家可以猜猜是哪本小说。  

  

A组是一群有着共同理想的年轻人组成，一年多来逐渐形成了自己的团队文化：感恩、敬畏、宽容和坚持。当然也有比较奇葩的团队文化，比如我要求我们的一道面试题为：「你相信外星人存在吗？」在后台留言想加入A组的朋友们可以先尝试回答一下这道题。
