# 我决定复活这个公众号

自从2014年回到阿里后，出于种种原因，这个号更新的频率越来越少，基本上是每年更新一篇。其中有客观原因，也有主观原因。  

  

思考了六年半以后，我终于想明白了还是该保持写作给大家看的终身习惯，而不用顾及他人的看法。我一直是一个不愿妥协的人，宁可不说，也不愿乱说，或者修改自己的说法。以后也将继续秉持这个原则写下去。至少保证这里的每一个字都是我本人写的。（可能很多人要紧张了:D）

  

我也是一个特别懒的人，不被鞭策，不会进步。立个flag就不好意思不写了。当然我也是一个压根不在乎别人看法的人，哪怕是好的看法，我也不在乎。所以才会抛弃了我的读者六年之久。

  

当然我也是一个不被人理解的人，这取决于认知深度，往往让我被误解、被代表。但那也没什么，因为我不曾妥协。最终我明白了写作才会是我最好的沟通方式。  

  

现在的信息太过嘈杂，我订阅了很多文章但是从来不看，我想读者们也有这个阅读的困扰。我们要读的东西不是太少，而是太多。因此除非特别情况，我会努力将每篇控制在500个字以内。这是巨大的挑战，必须惜字如金的将事情讲清楚。但这样我写着不累，你们读着也不累。我尽量做到每周五更。
