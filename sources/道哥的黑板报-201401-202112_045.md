# 先有鸡还是先有蛋？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA4ODc0MQ==&mid=201999449&idx=1&sn=71f14acfa8372d9366c3a00b3412fb12&chksm=2f21b8d3185631c58ee5fd8e940968a7839ea83a2d2184504a8d227363c947d724e8f36aa436&scene=126&sessionid=1681656719#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA4ODc0MQ==&mid=201999449&idx=1&sn=71f14acfa8372d9366c3a00b3412fb12&chksm=2f21b8d3185631c58ee5fd8e940968a7839ea83a2d2184504a8d227363c947d724e8f36aa436&scene=126&sessionid=1681656719#rd)

上篇文章发完后，有朋友问我新组建的团队怎么定目标，有些目标好像也没法量化，如果做不到怎么办？再加上最近我和团队沟通时，发现有些同学在设定目标时也存在一些问题，所以再单独讲一讲。

 

目标设定能体现出一个人的能力，如何设定目标，能反应出是否抓住了问题的关键或本质。

 

上篇文章里讲过要「目标清晰」，好的目标应该是可量化的而不是定性的。如果你量化不出来，要么是思考的不够深入和透彻，要么做的方向有问题。有空可以帮助大家量化一下目标，不过要收咨询费 :D

 

最近常会遇到的一个问题是，目标完不成怎么办？

 

阿里以前每年设定的业务目标都很吓人，大家都以为很难完成，结果每年都超额完成任务。记得在2012年双11的时候，淘宝销售额做到了191亿，这是第一次双11过百亿，马云问大家什么时候能到1000亿？大家都吓坏了，说可能要十年吧。马云说最多三到五年。2014年双11的销售额是571亿，按照增长速度离1000亿只是一两年的时间。

 

最近我给漏洞扫描团队定了个目标：「如果你们检测不出来漏洞，那么这个星球上就不应该有其他任何人能检测出来漏洞。」

 

团队看到这个目标的第一反应是吓尿了，这怎么可能？比如有人当场就提出如果我们刚检测完后过了一个小时用户就发布新业务上线，出了漏洞怎么办？等等类似的问题和挑战。

 

然后我很开心的告诉他们，这些挑战就是他们要去解决的问题。如果今天不提出这样的目标，团队可能永远都不会想到要去解决这样的问题。

 

这就是「先有结果，再设定目标」的思考方式。我要求团队的每个人都要习惯用这样的方式思考问题 — 先抛开所有困难和现实情况，去看看最终我们要的是什么结果，这个结果就是我们的目标。

 

这就是「先有蛋，后有鸡」，因为要这个结果，所以设定这样的目标。

 

一旦因果关系是「因为有了目标，所以得出了结果」，就是在给自己找退路，潜意识里就是在这么思考：「如果做不到怎么办？那就设定个简单点，能够做到的目标。」

 

所以以自身能力为出发点，去设定的目标，往往是不靠谱的。靠谱的做法是先根据最终要的结果设定目标，再一看自身能力可能做不到，才会要想办法去扩充自身的能力，或者是借助其他人的帮助来达到目标。

 

类似的思考方式还有「能力决定态度」，这也是我最近学习到的：「没有态度问题，都是能力问题。有多大的能力决定了一个人用什么样的态度去做事。」改天可以再写写。
