# 走自己的路，要让别人说

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA4ODc0MQ==&mid=200609158&idx=1&sn=2f3be4012daba42a2f348ca9127921b7&chksm=28def10c1fa9781a568adf1ae4be747675d79860bba666af2f9040c2b86616a34b224b460abd&scene=126&sessionid=1681656723#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA4ODc0MQ==&mid=200609158&idx=1&sn=2f3be4012daba42a2f348ca9127921b7&chksm=28def10c1fa9781a568adf1ae4be747675d79860bba666af2f9040c2b86616a34b224b460abd&scene=126&sessionid=1681656723#rd)

上周去了趟深圳，见到了很多朋友。很有趣的是我的中学和大学同学里有五个在腾讯工作，但是在阿里、百度、360、小米等大互联网公司的却似乎一个都没有。不知道这样的概率分布背后说明了什么。

 

在深圳我见到了阔别已久的老同学，吃饭时聊起过去的一些事情，老同学说我过去给他的印象是很「清高」。我有些意外，只好把「清高」当做贬义词来听了。然后我很感慨的说过去我就是一技术宅男，很多人情世故都不懂，通俗的来讲就是没什么人情味，更喜欢面对冰冷的屏幕胜过面对人。创业这两年对我来说有了一次脱胎换骨的变化，具体的表现是白头发多了好多，而且至少我开始懂得人情味儿了。

 

有意思的是，我发现在很多技术型公司或团队，像曾经的我一样的技术宅男并不在少数，而且他们和过去的我一样缺乏人情味，或多或少存在些沟通障碍。对于技术人才来说，智商高很常见，情商也高就不常见了。我理解的情商高，一个很重要的特点就是在说话做事的时候，能够感觉到别人的感受，从而在言语上能拿捏好分寸，或者做事恰到好处。有研究表明，一个人的成功，20%取决于智商，80%取决于情商。

 

人是社会化的动物，一个人在社会中成就的高低，往往并不取决于自己，而是在于社会对他的认可。

 

所以我最近一直在琢磨一句话：「走自己的路，让别人去说吧！」。这句来自但丁《神曲》中的诗句，看似豪迈，实则把人带到沟里去了。作为诗人可以这么洒脱，但是作为在团队里打拼事业的我们，则不可能做到无视他人的感受。

 

最简单的原因是，除非你做的是独立性极强的工作，比如写作或画画，否则只要存在分工与协同，就必须借助团队的力量达到目标，就必须与人打交道。而团队对你的支持力度，很大程度上又决定了最终的结果。多一个朋友就多一分力量，而人们总是乐于帮助有好感的人。

 

很久以前我认识一位A君，说话时总爱高谈阔论，和人在一起说话时总是引经据典。按理说这样的人应该让人折服于其渊博，但是因为A君每次说话的语气都非常的强势，而且只顾自说自话，开玩笑也没轻重，所以给周边人的感受却是，A君很爱炫耀自己的学识。

 

还认识一位B君，平时里总是愤世嫉俗，认为自己怀才不遇，换了几个主管但关系从没搞好过，好几次因为工作安排不如意当着所有同事的面拍桌子发脾气，渐渐的大家都不敢和他说话了。

 

A君和B君都是智商高、情商低的典型，他们在职业发展上也很容易遇到瓶颈。

 

最近我会跟团队小伙伴们讲的一句话是：「你们需要带给别人信心。」。背后的含义就是，想要做成一件事，光自己牛B是不行的，得要让别人也觉得你很牛B，这样才能「得道多助」，才能借力借势。

 

所以人不能只活在自己的世界中，平时多想想别人眼中的自己，也许很多问题就会找到答案，豁然开朗。

 

最后借用我一位朋友的话：「做人不可以圆滑，但需要圆润。」
