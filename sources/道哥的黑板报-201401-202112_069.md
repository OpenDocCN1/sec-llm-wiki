# 超过140个字的产品观

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA4ODc0MQ==&mid=200238178&idx=1&sn=8a3b4ea1009fd655bf737139bac1fe9b&chksm=28c498e81fb311fe510aa847cc868c87bd96551ac42b3f7e83a90b43629b6134d2f80f43fe2d&scene=126&sessionid=1681656727#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA4ODc0MQ==&mid=200238178&idx=1&sn=8a3b4ea1009fd655bf737139bac1fe9b&chksm=28c498e81fb311fe510aa847cc868c87bd96551ac42b3f7e83a90b43629b6134d2f80f43fe2d&scene=126&sessionid=1681656727#rd)

写了好些东西，然后被我老婆「和谐」了，现在咱家的内容审查比广电总局还严了~

 

所以写不下去了，发条140字的短消息吧：

 

最近老婆说她听了个UI方面的分享，讲手机的图标是怎么演化和迭代的。我说学学这些挺好，作为产品经理需要了解交互设计和视觉，但是不要过于沉迷，产品经理最重要的是思考产品对用户的核心价值，交互这些都是其次的东西。

 

然后我举了京东的例子，有次我和一位投资人聊天，他讲到当时刘强东要做物流但是所有投资人都反对，认为不应该把公司做的过重，但是刘强东非常坚持，所以投资人妥协了。现在看来刘强东是对的。有一次这位投资人碰到了亚马逊的贝索斯，贝索斯也认为京东做对了，并坦言要不是美国的物流公司已经那么的成熟，说不定亚马逊当年也会自己做物流。

 

今天看来，京东对用户最具吸引力的一点就是快速的物流，谁能说这不是产品的核心体验呢？

 

所以产品经理的工作不是设计一个网站，也不是整天盯着数据看优化了几个点的转化率。这些都没用，有用的是你做的东西到底给用户提供了什么价值。这也是我几乎不看数据的原因，看数据也只是用来验证自己的想法是不是对的。内心的感觉有时候会比数据更有用，因为数据有可能会欺骗你，过于依赖数据就等同于放弃了思考的能力。

 

我想这也是张小龙提到的「思辨胜于执行」的涵义。

 

一不小心超过140字了，那就发条图文消息吧，sigh~
