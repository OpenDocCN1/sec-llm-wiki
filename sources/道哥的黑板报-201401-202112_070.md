# 支付宝kungfu？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA4ODc0MQ==&mid=200234585&idx=1&sn=368f616102eb4bf6e026a951ac3f8b39&chksm=28c4aad31fb323c54b16db8ccefacd3da047560b3896e9fed23d985034420134cdab1151c153&scene=126&sessionid=1681656727#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA4ODc0MQ==&mid=200234585&idx=1&sn=368f616102eb4bf6e026a951ac3f8b39&chksm=28c4aad31fb323c54b16db8ccefacd3da047560b3896e9fed23d985034420134cdab1151c153&scene=126&sessionid=1681656727#rd)

这两天在朋友圈里和一些群里又在疯传「支付宝空付（kungfu）」的文章，大意是支付宝正在研发一种下一代的支付技术，在任何地方只需要摆个特定的姿势就能够支付了，其中用到了人脸识别、图像识别等技术，而且有一个非常酷的概念视频。有兴趣的朋友可以上网搜索一下「支付宝空付」。

 

好多小伙伴看了视频后都很激动的说「哇塞，酷毙了！」、「这才是创新！」。

 

最早这个视频是在4月1号愚人节出现的，我第一眼看到的时候也颇为震惊，然后马上就在朋友圈里转了，并附言：「这才是创新。」

 

但是5分钟后我马上就意识到不对劲，然后仔细的推敲了一下，发现我自己被忽悠了，从技术上来说使用人脸识别技术进行认证有非常严重的安全隐患。所以我马上在朋友圈里又补发了一条：「之前发的支付宝空付视频经我推测是愚人节的营销新闻。挺可惜的，支付宝如果胆子再大一点，再具有创新精神一点就好了。」

 

确实，这个视频描述的场景非常具有想象力，也许在未来的某一天能成为可能，但不是现在。支付宝吊起了我的胃口，可惜却只是营销，顿时让我有一种很失落、很惋惜的感觉。

 

从技术上来说，目前比较靠谱的是「声纹识别」，而且已经用于一些安全认证。国内做声纹识别方面的公司或团队就那么三四个，我曾有幸和几家公司的高管一起聊过天，了解过一些声纹识别技术的现状。所谓「声纹识别」，就是指每个人的声音特征其实都是独一无二的，通过将声音转化成数字信号，能够精准的识别出每一个人。

 

有的朋友也许很快能反应过来，电话公司可以从每天无数的通话中，通过「声纹识别」快速的定位出一个具体的个人。这对国家安全会有着重要的战略意义。

 

实际应用中，在使用「声纹识别」进行认证的时候，可以每次都让人随机的说一段不同的话，这样可以避免被人录音后再重放。而对比「人脸识别」如果被人拿个照片去骗过认证，风险就要小的多。

 

但是声纹识别也不是万能的，比如人如果感冒了，嗓音沙哑，也可能导致一定的出错率。而且声纹识别还做不到100%的准确，有极小的概率会产生误报，对于一些非常敏感的系统来说这种微小的误差也难以接受。因此声纹识别目前主要还是用于一些不太敏感的系统，或者是用于「双因素认证」，作为密码或其他手段的补充方式。

 

目前我了解到有的银行，甚至监狱等重要的系统，都有集成声纹识别用于认证，因此这项技术的工业化前景还是比较看好的。

 

支付宝在探索未来支付的方式上，应该会先推出基于语音的认证方式。因此未来的一两年内，我大胆推测「支付宝空付」应该是以声纹识别的方式出现，而非「人脸识别」。
