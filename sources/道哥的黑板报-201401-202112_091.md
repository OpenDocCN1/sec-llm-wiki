# 如何写一本书

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5NzA4ODc0MQ==&mid=200031664&idx=1&sn=80550eae0b87f823f5865bfe2a9da23b&chksm=28c7c13a1fb0482ccd4edb4ec2e4102282b309e2748deb34024d6e246ffaf4cf8fad57534829&scene=126&sessionid=1681656735#rd](http://mp.weixin.qq.com/s?__biz=MjM5NzA4ODc0MQ==&mid=200031664&idx=1&sn=80550eae0b87f823f5865bfe2a9da23b&chksm=28c7c13a1fb0482ccd4edb4ec2e4102282b309e2748deb34024d6e246ffaf4cf8fad57534829&scene=126&sessionid=1681656735#rd)

看到我的好朋友，微信公众号「MacTalk」的作者池建强的纸书《MacTalk 人生元编程》终于出版了，由衷为他感到高兴。

 

之所以要强调「纸书」二字，是因为他首先出的是多看里的电子版，然后再逆袭又出了纸版，拿到了ISBN号。一本书只有有了ISBN号才能算是正规的出版物，否则只是属于印刷品。

 

在老池决定要写书之初，我曾经认为这几乎是不可能完成的任务。因为我以前写过一本书，所以知道对于一个从事着苦逼的IT行业的人来说，利用业余时间写书究竟该有多苦。因此当老池告诉我，他每天晚上会零零碎碎的凑点时间来写书时，我其实心里觉得他这本书多半会和我知道的一些例子那样，最终夭折的。

 

单独一个人写书尤其如此。每天的工作已经非常繁重，回到家后很想休息，却要额外再抽出写书的时间。关键是还有书稿合同的截止期犹如压在心上的一块大石头，让人患得患失。而三天两头要处理意外的事情又会让写书的过程变得不连续，从而很容易中断。

 

如果是两个人写书，还能互相督促一下。比如我的另两个朋友余弦和heart就是两人合写一本书，因为他们还合租过一段时间，所以互相督促起来也很方便。但一个人写，又没人监督，是很难抑制住内心的各种负能量的。

 

因此在这种情况下能独立完成一本书的人，都是有大毅力的人。

 

要想写一本书，最重要的不是打提纲，不是找人提建议，而是能养成「固定的写作习惯」。一个优秀的作家，绝对不是靠每天癫狂式的激发自己的情绪和灵感来写作，而是坚持在固定的时间、固定的地点，坚持不懈的写下去，直到让写作变得像呼吸一样自然，变成一种本能。哪怕文思枯竭，也必须逼着自己写点什么，写到后来，就自然下笔如有神了。

 

而当一本书出版后，在中国的版税一般在8%-10%左右。说实话，作家是一个非常苦逼和屌丝的行业，真正光鲜者只有那最拔尖的屈指可数的几个。大多数作家的书印刷的数量都不会太大，如果市场反馈一般，一本书可能也就能赚个几万块钱。而且出版社还不是一次付清，一般会根据销量拖上一年的分期付款。对于一些本身收入较高的白领来说，也许还不够一个月薪水的，这与作者本身对此投入的大量精力是完全不对等的。

 

所以写完书后，千万别问人赚了多少钱，人艰不拆。更辛酸的是还有些很热心的读者，说你都写书了，能不能送我本啊。一两个还好说，但张三要，李四也要，架不住人多啊。一般出版社只会给个十本左右的样书给作者，再多的出版社也给不起了。这十本左右的样书，早就会被各路亲朋好友给瓜分掉：父母家人得送几本吧，领导同事得送几本吧，写序写推荐的人得送几本吧，这么送下来，说不定作者都还得倒贴不少。

 

当年我送给各路好基友书，大部分都是自掏腰包。很多人问我在作者这里买有没有折扣，很不好意思，身为作者我自己也得上网买，就是网上这个折扣了。

 

所以，真要支持作者，就别省这买包烟的钱，上网买一本，就是对作者最大的支持了。
