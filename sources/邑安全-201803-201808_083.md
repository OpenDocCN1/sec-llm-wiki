## 介绍

一个基于Phusion/baseimage的docker容器，用于CTF中的PWN类题目

## 使用

Docker hub地址：https://hub.docker.com/r/skysider/pwndocker/

```
docker pull skysider/pwndocker
docker run -it --rm -name testctf -v $(pwd):/ctf/work skysider/pwndocker
```
