# 电网安全：除了破坏基础设施，黑客还能干啥？

E安全3月31日讯 上周，黑客获得了印度 Uttar Haryana Bijli Vitran Nigam（简称 UHBVN）电力公司的计算机系统访问权，并窃取到大量客户计费数据。攻击者向该公司索取价值相当于15万美元的比特币，否则不予归还这些数据。

![](../Images/49d5d225d2baffe979e96744bfb28eaa.png "印度电力企业遭遇黑客入侵，计费数据赎金高达1000万卢比-E安全")

根据《印度快报》报道，黑客于3月21日午夜时分获得了计费系统的访问权。该公司员工于22日登录时，其计算机上显示出勒索信息，要求印度政府提价值15万美元的比特币以恢复相关数据。  

这些数据可通过来自日志及其它来源的输入内容进行恢复。计费数据的丢失，意味着该电力公司将无法向其客户发送准确的账单，用以核算当前消费额度以及此前欠下的未缴费用。

UHBVN 公司某管理者表示，已与外部专家进行了相关调查，确认数据库被加密，目前已经在利用加密数据库备份进行进一步检索。但他同时补充称，“账单数据不会丢失，账单消费者也不会因此受到影响。”
