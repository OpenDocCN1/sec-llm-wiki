**一波三折**

打开1.txt,发现是像素，想到还原图片

写一个python脚本转换一下

with open('1.txt','r') as f:

   pixel\_text=f.read().split(',')

 

col=0

with open('result.txt','w') as outf:

   for i in pixel\_text:

       outf.write(i)

       if col==2:

           outf.write('\\n')

           col=0

        else:

           outf.write(',')

           col=col+1

得到result.txt，发现共95477行

尝试分解，95477=307\*311

再还原图片

from PIL import Image

import re

 

x=307

y=311

 

photo=Image.new("RGB",(x,y))

 

with open('result.txt','r') as outf:

   for i in xrange(0,x):

       for j in xrange(0,y):

           lines=outf.readline().replace('\\n','')

           pixel=lines.split(',')

           photo.putpixel((i,j),(int(pixel\[0\]),int(pixel\[1\]),int(pixel\[2\])))

 

photo.save('photo.bmp','BMP')
