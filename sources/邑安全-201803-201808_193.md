设计您的URL

  一个干净优雅的URL方案是高质量Web应用程序中的一个重要细节。 Django鼓励优雅的URL设计，并且不会在URL中放置任何垃圾，例如.php或.asp。  
  要为应用程序设计URL，您需要创建一个名为URLconf的Python模块。 您的应用的内容列表，它包含URL模式和Python回调函数之间的简单映射。 URLconf也用于将URL与Python代码分离。

下面是URLconf例子：`Reporter`/`Article`

mysite/news/urls.py

```
from django.urls import pathfrom . 
 viewsurlpatterns \= \[
    path('articles/<int:year>/', views.year\_archive),
    path('articles/<int:year>/<int:month>/', views.month\_archive),
    path('articles/<int:year>/<int:month>/<int:pk>/', views.article\_detail),\]
```

  上面的代码将URL路径映射到Python回调函数（“视图”）。 路径字符串使用参数标签从URL中“捕获”值。 当用户请求一个页面时，Django按顺序遍历每个路径，并停在第一个匹配请求URL的地方。 （如果它们都不匹配，Django会调用特殊情况的404视图。）这非常快，因为路径在加载时被编译成正则表达式。

 一旦匹配成功，将返回例如URL：/articles/2005/05/39323/，Django也将会调用函数`news.views.article_detail(request,year=2005, month=5, pk=39323)`。

## 设计您的Views视图

  每个视图负责执行以下两项操作之一：返回包含请求页面内容的HttpResponse对象，或引发异常（如Http404）。 其余的由你决定。

通常，视图根据参数检索数据，加载模板并使用检索到的数据呈现模板。下面是上面`year_archive`的视图：

mysite/news/views.py

```
from django.shortcuts import renderfrom .models
 import Articledef year\_archive(request, year):
    a\_list \= Article.objects.filter(pub\_date\_\_year=year)
    context \= {'year': year, 'article\_list': a\_list}
    return render(request, 'news/year\_archive.html', context)
```

  这个例子使用Django的模板系统，它有几个强大的功能，但努力保持简单到非程序员使用。
