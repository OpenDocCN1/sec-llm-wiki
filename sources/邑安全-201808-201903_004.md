### Broken Chest

![](../Images/489524674c8532d3ca580bc37cafa291.png)

### Try

用 wireshark 打开数据包，**过滤出 HTTP 报文**，发现有两个文件可以提取出来。一个是 png，另外一个 zip

在相应的返回包上右键 -> 导出分组字节流

![](../Images/3b7f394699eef7f030046b296c46d299.png)

导出之后，发现图片没什么用，但是 zip 包还可以提取

![](../Images/1a800d1c96842b9fec4a40f925ed4455.png)

解压后的 password.txt 文件打开之后，后面的字符用 \* 号打码了，于是想到了掩码爆破（**直觉猜测应该都是数字**）

![](../Images/ab0eccfa70b8381c7dc68967e2a2d70e.png)

使用 **Ziperello** 打开压缩包文件 open-it.zip

破解模式选择基于模块的破解（也就是掩码爆破），按照左边的密码模板填完后，下一步

![](../Images/d548026fee285e7e716dc189ab8dcde4.png)

很快就会破解出来压缩包的密码

![](../Images/239e6f905b7d4f280e7476fa2f947b33.png)

用破解出来用密码解压出压缩包，**发现下面有张图片**

![](../Images/043e50ac5f6791b0df207033bbb2097d.png)

放到 winhex 中，发现图片里面还有一个 docx 文件。

![](../Images/e4e2a578ef537315c15cc091e5d400d6.png)

**用 foremost 提取出来是个压缩包**，解压发现需要密码，尝试伪加密的解密（在 winhex 中直接改控制位就行了）

成功解密出来 docx 文件。

![](../Images/21af7558c1d7256752a737b8e2e68a5f.png)

打开发现是空白，然后在 word 中把显示隐藏文字的选项打开，就可以看到 flag

![](../Images/456888644f482b73636336ec21ac748e.png)
