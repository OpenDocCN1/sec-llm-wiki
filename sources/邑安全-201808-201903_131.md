*   **file：查看文件类型**
    
    ```
    file	1.txt
    ```
    
*   **which：寻找执行文件位置**
    
    \-a 找出所有同名执行文件
    
    ```
    which	ifconfig				//找出第一个
    ```
    
*   **whereis：寻找特定文件**
    
    ```
    whereis		ifconfig
    ```
    
*   **locate：数据库中查找文件**
    
    \-i 忽略大小写
    
    \-r 正则表达式查找
    
    ```
    locate		password
    ```
    
*   **find：查找文件**
    
    \-name filename 查找文件名为filename的文件
    
    \-size \[-/+\]SIZE 查找比SIZE大或小的文件
    
    \-type TYPE 查找文件类型为TYPE的文件
    
    \-exec command -exec后可接其他命令来处理找到的结果
    
    ```
    find	/	  \-name "pass\*"	  \-exec echo "Find:{}" \\;	、//{}代表找到的结果//\\;代表其他命令的结束
    ```
    
*   **ln：链接文件（link）**
    
    ```
    ln		password		password\-hl
    ```
    
    原文件 硬链接
    
    ```
    ln		\-s	passwd	passwd\-sl
    ```
    
    原文件 软连接
    

*   硬链接：不会生成新的inode和bolck，内容与原来文件同步，删除原文件，硬链接内容不会被删除
    
*   软链接：类似快捷方式，当源文件被删除后，软连接会打不开
    
    \-s 创建软连接，若不添加参数则默认创建硬链接
    
    \-f 如果文件存在，则删除后再创建
    

*   **df：列出文件系统的整体磁盘使用量**
    
    \-a 列出所有文件系统文件
    
    \-h 计算文件大小
    
    \-i 以inode数量来显示
    
*   **du：评估文件系统的磁盘使用量**
    
    \-s 列出总数量
    
    \-h 计算文件大小
    
    \-a 列出所有文件与目录大小
    
*   **echo：输出字符串**
    
*   **history：历史命令**
    
    n 数字，列出最近n条命令
    
    \-c 将目前shell中所有的history内容全部清除
    
*   **！：执行history中命令**
    
    ！nubmer 执行第几条命令
    
    ！command 由最近的命令向前搜索command开头的命令，并执行
    
*   **|：管道命令（pipe）**
    
    ```
    ls	\-al	/etc|less\*\*su：切换为root身份\*\*
    ```
    
*   **su：切换为root身份**
    
    exit离su环境
    
*   **sudo：以其他用户的身份执行命令**
    
*   **man：显示操作说明**
    
    ```
    man ifconfig
    ```
    
*   **info：功能与man相似，将功能文件分成一个段落**
