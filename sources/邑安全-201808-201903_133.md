*   **ls：列出目录内容（list）**
    
    \-a 列出所有内容包括隐藏文件
    
    \-l 列出详细内容
    
    \-h 计算文件大小
    
*   **chgrp：改变文件所属用户组（cahnge group）**
    
    ```
    chgrp   users    1.txt
    ```
    
    用户组 文件名
    
*   **chown：改变文件所有者（change owner）**
    
    ```
    chown   user       1.txt
    ```
    
    用户名 文件名
    
    ```
    chown     root:root      1.txt                 //同时改变用户组和用户名
    ```
    
    用户组:用户名 文件名
    
*   **chmod：改变权限（change mode）**
    
    r:\[read\]=4 w:\[write\]=2 x:\[excute\]=1
    

*   数字型改变文件与目录权限
    
    ```
    chmod		777		1.txt
    ```
    
    数字型权限 文件名或目录
    
*   符号型改变文件与目录权限
    
    u:user（当前用户） g:group（当前用户组） o:others（其他用户） a:all（所有用户）
    
    +:加入权限 -:减去权限
    
    ```
    chmod		u=rwx,go=rw		1.txt
    ```
    
    符号型权限 文件名或目录
    
    ```
    chmod		u\-x			1.txt
    ```
    
    符号型权限 文件名或目录
    

*   **mkdir：新建新目录（make directory）**
    
    \-p 创建多层目录 -m 设置目录属性
    
    ```
    mkdir	test						//当前目录下创建test
    mkdir	\-p	/test/test1/test2		//当前目录下创建多层目录
    mkdir	\-m	711		test			//创建权限为711的目录
    ```
    
*   **rmdir：删除空目录（remove empty directory）**
    
    \-p 删除多层目录
    
    ```
    rmdir	testrmdir	\-p	/test/test1/test2
    ```
    
*   **cd：切换目录（change directory）**
    
    ```
    cd	~					//回到当目录主文件夹
    cd	./					//当前文件夹
    cd	../					//进入上层目录
    cd	\_					//回到刚才的目录
    ```
    
*   **pwd：显示目前所在的文件夹（print working directory）**
    
*   **cp：复制文件或目录（copy）**
    
    \-p 将文件属性一起复制
    
    \-r 复制文件夹
    
    \-s 复制成链接文件
    
    \-i 若目标文件夹已存在，问是否覆盖y/n
    
    \-a 属性权限完全复制
    
    ```
    cp			1.txt				2.txt
    ```
    
    要复制的文件夹或目录 复制到的目录及文件名
    
*   **rm：移除文件夹或目录（remove）** //有目录x权限才能删除文件
    
    \-r 删除目录
    
    \-f 忽略不存在的文件
    
    \-i 删除前询问
    
    ```
    rm		1.txt
    ```
    
    文件
    
    ```
    rm		\-r		/tmp/test/
    ```
    
    目录名
    
*   **mv：移动文件与目录或更民（move）**
    
    \-f 若文件已存在，直接覆盖
    
    \-i 若文件已存在，询问是否覆盖
    
    \-u 若文件已存在，则保留最新版本
    
    ```
    mv		/etc/services		/tmp/servicesmv		1.txt				2.txt			//同一文件夹下实现改名功能
    ```
    
*   **touch：创建空文件**
    
    ```
    touch		1.txt
    ```
    
    文件名
    
*   **cat：查看文件内容**
    

*   相识命令
    
    ```
    tac：从最后一行开始显示，cat的倒写
    nl：显示时候输出行行号
    more：一页一页地显示内容，不能往前翻页
    less：与more相似，可以往前翻页
    head：显示头家行（默认10行）
    tail：显示末尾几行（默认10行）
    od：以二进制方式读写
    ```
    
    \-n 打印出行号
    
    \-v 列出一些看不见的特殊符号
    
    ```
    cat		\-n		1.txt
    ```
    
    文件名
    
    \-n 显示n行（head，tail的参数）
    
    \-f 持续检测动态显示后面文件的内容（tail的参数）
    
    ```
    head	\-n 10	1.txt			//显示前10行
    tail	\-n 10	1.txt			//显示后10行
    tail	\-f		1.txt
    ```
