addslashes_deep 函数地址：ECTouch_v2.7.2_SC_UTF8\include\helpers\base_helper.php

/**
 * 递归方式的对变量中的特殊字符进行转义
 *
 * @access  public
 * @param   mix $value
 *
 * @return  mix
 */
function addslashes_deep($value)
{
    if (empty($value)) {
        return $value;
    } else {
        return is_array($value) ? array_map('addslashes_deep', $value) : addslashes($value);
    }
}

看到可以确定，他的过滤方式是使用了 addslashes 递归对 GET，POST，COOKIE，REQUEST 进行转义，这里也要注意一下，只对value 过滤了，没有对key进行过滤所以，如果有sql带入了key的话，是可能造成注入的

0x06 系统情况初步集合

一顿简单的突突突以后，就又可以确定一些基本的漏洞了。

首先是xss漏洞

储蓄xss：想找xss 那么就要看使用了 htmlspecialchars_decode 函数的地方，否则的话就只能查看类似这种点 <img src=# {{variate}}> variate 可控的情况

反射xss：还是有的希望的，因为全局过滤是针对sql注入的，所以找一处能输入输出的地方就有xss了

sql注入：key 没有过滤所以如果我能够控制 key 进入sql的话，那么就基本上百分之90有sql注入了，如果不行的话，也没关系，可以找找没有 '/" 引号包含的地方，那么同样有注入。

命令执行：这玩意跟变量就好了，不细讲
