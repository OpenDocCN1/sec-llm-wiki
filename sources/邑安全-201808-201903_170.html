虚拟网络编辑器的三种模式

  • 桥接模式 ：每台设备都有独立的出口IP，类似交换机功能。

  • NAT模式 ：
    所有设备只有一个出口IP，内网设备可以直接访问外网，外网不可以直接访问内网设备，类似路由功能。

  • 仅主机模式 ： 仅物理主机和虚拟机之间能直接相互访问。

## 2.配置UbuntuA和UbuntuC路由表

PS：网关为UbuntuB上与需配置虚拟机同网段的IP

UbuntuA配置

route add -net 192.168.126.0 gw 192.168.6.207 netmask 255.255.255.0 dev ens33

UbuntuB配置

route add -net 192.168.6.0 gw 192.168.126.128 netmask 255.255.255.0 dev ens33

3.开启UbuntuB转发功能和配置iptables

  • 开启转发

echo "1" > /proc/sys/net/ipv4/ip_forward  #开启内核路由转发参数
sysctl -p                                 #立即生效

  • 开启iptables nat转发

iptables -t nat -A POSTROUTING -s 192.168.126.0/24 -d 192.168.6.0/24 -o ens33 -j  MASQUERADE 

# 配置源地址126网段，目标地址6网段的地址转换，从ens33网卡出

iptables -t nat -A POSTROUTING -s 192.168.6.0/24 -d 192.168.126.0/24 -o ens38 -j  MASQUERADE

# 配置源地址6网段，目标地址126网段的地址转换，从ens38网卡出
