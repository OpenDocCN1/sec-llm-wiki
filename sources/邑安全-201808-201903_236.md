# UDF提权

nc模式下的shell不支持su交互，先利用python提升到伪终端。

```
$ python -c "import pty;pty.spawn('/bin/bash')"
```

然后登入mysql，交互正常。

 

![](../Images/e3b3e6441aa4155cc091a3fe21691a4e.png)
