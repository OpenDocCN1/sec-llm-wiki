# 中国机场和航司加大IT投资 网络安全成重中之重

民航资源网2018年11月21日消息：中国各大机场正加大技术投资，部署新机场和航站楼，满足不断增长的客运需求。据2018年SITA中国航空运输业IT洞察报告显示，中国航空客运量在过去一年增长了近13%，超过10亿人次。各大机场均加大IT投资力度，投资占比从2017年的5.6%增加至2018年的7.5%，高于全球平均水平（5.69%）。中国各大航空公司也加大投资，航司与机场都将网络安全视为投资重中之重。

　　94%的航空公司和机场正计划在未来三年内，部署重大网络安全计划或研发计划，着实令业界瞩目。2018年，航空公司计划将其IT预算的7%用于网络安全，而机场在该领域的投入预计将占IT预算的18%。SITA针对网络安全的九大领域进行分析，衡量实施率。中国航空公司和机场在这九大领域均领先全球竞争对手，可见中国航空运输业对网络安全重要性的认可和承诺。

　　SITA副总裁兼东亚区总经理周红梅女士表示： “中国航空公司和机场首先考虑的是数字化。我们的研究显示，100%的航空公司和95%的机场已经、正在或计划实施数字化转型。这一战略也印证了行业对网络安全的重视度，这两者齐头并进至关重要”。

　　行李管理是中国航空业的另一项重要投资。2019年，所有航空公司计划在超过50%的航线网络符合国际航协第753号决议，在旅行的每个环节都能有效追踪行李。为了实现这一目标，各利益相关方需要展开精诚合作，中国各大机场正加大对行李追踪的投入。2021年底前，所有机场将在四个行李追踪环节其中的两处部署行李追踪服务，即：准备区和装载环节。此外，94%的机场还将在转机和到达环节追踪行李。这一投资水平远远领先世界其他地区，对于中国航空运输业来说是个好兆头。

　　“今天，我们看到中国的航空公司和机场已着眼于改善行李管理环节。凭借这一举措的实施，中国将率先在全球实现行李流程的有效管理，降低成本并改善旅客行李体验”， 周红梅女士补充道。

　　SITA航空运输业IT洞察是全球公认的航空运输业基准研究成果。中国大陆地区70%的机场和64%的航空公司参与了2018年调研。
