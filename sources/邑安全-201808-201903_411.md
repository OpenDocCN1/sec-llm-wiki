
密文长度是明文的2倍，然后密文只有5个字母出现，本能想到多表加密，但是不知道表的边缘的排序方式

例如：

```

iklne

```


我们不难看出这题的难点应该在于generate\_passwd()了吧，加解密函数都给你写好了，调用就行，我们仔细观察这个generate\_passwd()

