# Windows 7生命周期结束：补丁停止几个月，仍有数百万人尚未升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247487336&idx=3&sn=db004c107af09377c00b20a7c63ed55b&chksm=fa394fb2cd4ec6a4657eec2608d37849d5b12cea90dad5f8cc573794df86db7d3f58559619f2&scene=126&sessionid=1681376233#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247487336&idx=3&sn=db004c107af09377c00b20a7c63ed55b&chksm=fa394fb2cd4ec6a4657eec2608d37849d5b12cea90dad5f8cc573794df86db7d3f58559619f2&scene=126&sessionid=1681376233#rd)

在微软停止发布针对Windows 7的免费补丁的短短不到五个月的时间里，仍有数百万台PC依赖它，让它们暴露在可能永远无法修补的新漏洞中。 

微软多年来一直唠叨Windows 7用户升级到Windows 10，但是大量的消费者和小型企业要么拒绝这些电话，要么错过了这些电话。 

在微软停止为Windows 7提供免费安全更新后，这些系统将成为2020年1月14日之后黑客的轻松目标。 

根据俄罗斯安全公司卡巴斯基的统计，大约47％的中小型企业仍在运行Windows 7，而38％的消费者和38％的小型办公室/家庭办公室PC都在Windows 7上运行。

Windows 7的是  窗户的WannaCry最广泛影响的版本，它锁定了约30万电脑在2017年5没有补丁的Windows 7将在未来会受到盲蝽象最近披露“蠕虫攻击” BlueKeep错误和几个微软补丁在八月。 

就BlueKeep而言，微软确实为Windows XP提供了补丁，尽管它不支持阻止另一次WannaCry爆发的机会。

并且不仅仅是拥有大量个人电脑的小型组织仍在Windows 7上。英国的全国健康服务受到了WannaCry的严重打击，它在7月份承认它有100万台PC在Windows 7上运行。 

大型企业当然可以在2020年1月之后申请延期支持合同，但每台设备每年至少要花费25美元。 

卡巴斯基的企业解决方案经理Alexey Pankratov说：“Windows 7的广泛使用令人担忧，因为距离该版本不受支持还有不到六个月的时间。” 

“更新操作系统滞后背后的原因取决于现有的软件，可能无法在最新的操作系统版本上运行，出于经济原因，甚至低于常规使用相同操作系统的舒适性。

“尽管如此，旧的未修补的操作系统存在网络安全风险，事故的成本可能远高于升级成本。这就是为什么我们建议客户迁移到支持的版本并确保在转换期间安装其他安全工具期。”

随着Windows 7截止日期的临近，微软本月启动了一项计划，帮助小型公司迁移到Windows 10. 正如Computerworld所报道的那样，“ Windows 10的FastTrack中心效益 ”适用于购买至少150个Office 365 ProPlus许可证的组织或Microsoft 365。   

对于选择协议的企业和教育客户，Microsoft 还提供Windows 7安全更新，在 2019年12月31日结束的特别促销活动中，一年内不收取额外费用。 

Windows 7优惠适用于拥有企业协议（EA）或企业协议订阅（EAS）且具有对Windows 10 E5，Microsoft 365 E5和Microsoft 365 E5安全的有效订阅的客户。
