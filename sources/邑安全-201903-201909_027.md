# Apple发布iOS 12.4.1修复了之前的越狱漏洞

Apple今天发布了iOS 12.4.1，以修复iOS 12.4版本重新引入的安全漏洞，并由安全研究人员Pwn20wnd用于开发和发布最新iOS设备的越狱工具。  

Apple今天修补的漏洞是免费跟踪的，因为CVE-2019-8605是  针对用于为iOS设备创建越狱工具的Sock Puppet漏洞攻击的目标。

这个漏洞是由Google Project Zero的Ned Williamson发现的，之前已被苹果公司从5月13日发布的iOS 12.3版本修补，现在在iOS 12.4.1中重新修补。

## Apple承认越狱开发者的贡献

正如Apple的支持文档描述iOS 12.4.1的安全性内容所述，该漏洞本可能被恶意应用程序滥用，而恶意应用程序可能“能够以系统权限执行任意代码”。

Apple解决了免费安全问题之后的使用，引入了改进的内存管理，从而阻止了恶意工具应用程序访问已经被释放的指针。  

![](../Images/a12284d553830a93f8a50a3dd4e88f53.png)

Apple 承认  Google Project Zero的Ned Williamson在寻找和解决这一安全问题方面的贡献，并为Pwn20wnd的帮助提供了额外的认可。

除了允许越狱开发人员添加对Apple最新iOS版本的支持外，Apple今天修复的漏洞也是一个关键漏洞，可以为针对该公司庞大的iOS用户群的攻击者敞开大门。

![](../Images/414c108e76667ba6534fe85559b4f298.png)

安全研究员Stefan Esser也警告iOS用户，一旦iOS 12.4被iOS越狱开发者开发，其他任何人也可以这样做，通过Apple App Store发布的恶意iOS应用也可能利用这个漏洞。

虽然这是Apple团队的一个巨大错误，但这次安全更新显示该公司还能够迅速应对严重威胁，从而使用户面临潜在的高度破坏性攻击。
