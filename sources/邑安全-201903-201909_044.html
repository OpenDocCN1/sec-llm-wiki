这篇文章将描述我如何利用CVE-2019-14378，这是QEMU网络后端的指针误算。当重新组装大型IPv4分段数据包进行处理时，会触发该错误。它是通过代码审计发现的。


漏洞详细信息

QEMU内部网络分为两部分：

  • 提供给客户的虚拟网络设备（例如PCI网卡）。

  • 与模拟NIC交互的网络后端（例如，将数据包放入主机的网络）。

默认情况下，QEMU将为guest虚拟机创建SLiRP用户网络后端和适当的虚拟网络设备（例如e1000 PCI卡）

在SLiRP中的数据包重组中发现了该错误。

IP碎片

mbuf结构用于存储接收的IP层信息。有两个缓冲区m_dat位于结构内部，m_ext如果m_dat不足以存储数据包，则在堆上分配。

对于NAT转换，如果传入的数据包是分段的，则应在编辑和重新传输之前重新组装它们。该重组由ip_reass(Slirp *slirp, struct ip *ip, struct ipq *fp)函数完成。ip包含当前IP分组数据，fp是包含分段分组的链路列表。

  • ip_reass执行以下操作：

    • 如果第一个片段到达（fp == NULL），则创建重组队列并插入ip此队列。

    • 检查片段是否与先前收到的片段重叠，然后丢弃它。

    • 如果收到所有分段的数据包，则重新组装它。通过修改第一个数据包的头部为新的ip数据包创建标头;

错误在于计算变量delta。该代码假定第一个分段数据包不会在外部缓冲区（m_ext）中分配。q - m->dat当分组数据在内部时mbuf->m_dat（q将在m_dat内），计算有效（q是包含片段和分组数据的链接列表的结构）。否则，如果m_ext分配了缓冲区，则q将在外部缓冲区内，并且计算delta将是错误的。

任意写

我的初始目标是覆盖该m_data字段，以便我们可以使用数据包重组m_cat()来获得任意写入，但由于某些对齐和偏移问题，这似乎是不可能的。

  • 发送id 0xdead和MF位设置的数据包（1）

  • 发送id 0xcafe和MF位设置的数据包（1）

  • 触发错误以覆盖m_len，0xcafe以便m_data + m_len指向0xdeadm_data

  • 发送带有id 0xcafe且MF位未设置（0）的数据包以触发重组并0xdead用目标地址覆盖m_data

  • 发送带有id 0xdead且MF位未设置（0）的数据包，该数据包将该数据包的内容写入m_data。

得到泄漏

我们需要泄漏来绕过ASLR和PIE。为此，我们需要一些方法将数据传回给访客。事实证明，有一个非常常见的服务与该描述完全匹配：ICMP回应请求。SLiRP网关响应ICMP回应请求，反映数据包的有效负载（在ICMP报头之后）不变。

我们有任意写，但是我们写在哪里，因为泄漏在这一点上是未知的？

我们可以m_data在堆上部分覆盖和写入数据。

泄漏：

  • 使用任意写入在堆上创建伪ICMP头

  • 发送MF位设置的ICMP请求（1）。

  • 部分覆盖m_data以指向堆上的假标头

  • 将MF位发送到0以结束ICMP请求。

  • 接收主机泄漏。

获得代码执行

定时器（更准确地说是QEMUTimers）提供了一种在经过一段时间间隔后调用给定例程（回调）的方法，将不透明指针传递给例程。


struct QEMUTimer {
    int64_t expire_time;        /* in nanoseconds */
    QEMUTimerList *timer_list;
    QEMUTimerCB *cb;
    void *opaque;
    QEMUTimer *next;
    int scale;
};

struct QEMUTimerList {
    QEMUClock *clock;
    QemuMutex active_timers_lock;
    QEMUTimer *active_timers;
    QLIST_ENTRY(QEMUTimerList) list;
    QEMUTimerListNotifyCB *notify_cb;
    void *notify_opaque;

};

main_loop_tlg是bss中的一个数组，包含QEMUTimerList与不同计时器相关联的数组。这些包含QEMUTimer结构列表。qemu循环遍历这些以检查它们中是否有任何已过期，如果是，cb则使用参数调用函数opaque。

RIP控制：

  • 创建假QEMUTimer，回调为系统，不透明为参数

  • 创建假QEMUTImerList，其中包含我们的假QEMUTimer

  • 使用伪QEMUTimerList覆盖main_loop_tlg条目
