# 巴西总统Telegram账号被入侵背后，攻击关键点竟是手机语音信箱

在说被入侵账号的事前，先说说这次攻击被扒出来的重要原因。

  

主要为巴西政坛“内幕”所致。

  

![](../Images/3eecedb39c719a341cdef4e2f8c43311.png)

  

而内幕大致就是，巴西联邦检方指前巴西总统特梅尔是一个“刑事犯罪团伙”的首脑，涉嫌参与洗钱、挪用款项、行贿受贿等行为，涉案金额约合31亿元人民币。

  

然后实际上，这次案件中的检察官手机在疑似遭违法入侵后，巴西前总统卢拉被法官和检察官联合搞下台的内幕，就这样泄露了出去，巧的是同样是Telegram账号被入侵。

  

![](../Images/dcaae1d76d6ce3fb6208deae5a10237a.png)

  

而所说的导火线就在这，巴西政府为了调查是如何遭到“泄密”，因此在排查后，发现了4名网络犯罪分子实施了另一起攻击  ：入侵了1000多个Telegram账号。。  

  

而关键是，这1000多个里面，包含了现**巴西总统博索纳洛**（Jair Bolsonaro），司法部长，经济部长等等政要。

因此，就成大事件咯。。  

  

而实际上，两起入侵Telegram账号的事件并不一致，The Intercept的创始人也对此进行了解释，声称并不一致，他是为了伸张正义带来真相。  
  

![](../Images/689cc6bc9c6569d5f4c730f38b39e532.png)

  

当然，出了大事情，如今外国总统追随某人的潮流，纷纷推特治国的年代，大家都会发发推特，稳稳情绪，因此现巴西总统博索纳洛表示“从未”使用过手机设备来处理国防或国家敏感问题。

新闻原文：  

本周巴西有四名嫌疑人因涉嫌黑客入侵1000多份电报账户被捕，其中包括一些巴西政府官员，如巴西总统Jair Bolsonaro，司法部长Sergio Moro和经济部长Paulo Guedes。

其他较低级别的政治家，如女议员乔伊斯·哈塞尔曼（Joice Hasselmann），他是布尔萨纳罗总统和莫罗部长的关键盟友，也声称本周早些时候已成为攻击目标。

根据法庭文件，四人使用了一个相对不为人知的黑客技巧，将受害者的电报账号绑定到他们的手机上。

据当地媒体报道，黑客利用访问帐户向用户的联系人发送带有恶意链接的垃圾邮件。然而，该组织似乎也瞄准并劫持了当地政客的账户，据信他们从那里获得了个人信息。

### TELEGRAM消息泄露后开始调查

巴西当局声称，在司法部长塞尔吉奥·莫罗（Sergio Moro）被黑客攻击之后，其中一些信息已经传到了截获记者的行列，他声称这是在6月5日发生的。

这个在线新闻网站与其他主要的当地新闻媒体合作，四天后开始发布一系列故事，这些故事基于摩洛与洗车行动检察官Deltan Dallagnol交换的电报信息，这是一项针对移民指控的持续刑事调查洗钱导致几名当地知名商人和政客被捕，其中最着名的是前总统路易斯·伊纳西奥·卢拉·达席尔瓦。

被一些人视为反腐无偏见的英雄，被其他人视为反左派的斗士，莫罗的信誉受到质疑，因为电报交换表明，他仍然是法官，在卢拉审判中指示检察官，这是反对的巴西法律。监狱判决将卢拉从去年的总统竞选中删除，之后Bolsonaro将摩洛任命为司法部长。

Moro正在进行洗车行动调查，他声称这些消息并没有显示出任何不当行为，而且只是对接管案件的检察官的建议。

无论哪种方式，刑事调查都已启动。本周宣布的四起逮捕事件是巴西政府调查这些泄密事件的结果。

被指控的四名黑客的名字是Danilo Cristiano Marquez（33岁），Walter Delgatti Neto（30岁），Judy Gustavo Henrique Elias Santos（28岁）和Suelen Priscilla de Oliveira（25岁） - 桑托斯的妻子。

这四人是在一项为期五天的临时逮捕令中被捕的，但未被正式指控。调查人员表示，他们在黑客的一个银行账户中发现了大约60万巴西雷亚尔（约160,000美元），嫌疑人根据他们的收入无法证明这一点。

针对逮捕行为，The Intercept的创始人*格伦格林沃尔德*向巴西杂志*Veja*提供了与他自己的消息来源的交换，他否认与Telegram语音邮件帐户劫持事件有任何关系。Greenwald告诉*Veja*，在Moro声称遭到黑客入侵之前一个月，第一次接触消息来源。

“我们不是新手黑客，\[语音邮件黑客\]与我们的运营方式不一致 - 我们访问Telegram的目的是提取对话并伸张正义，将真相带给人们，”它补充说。

这起攻击的关键正如题目所言:手机语音信箱  

攻击过程如下：  

  

First，当攻击者尝试登陆目标Telegram账户时，攻击者会要求使用语音验证码进行验证。(黑鸟测试了一下，应该是手机版)

![](../Images/2fb109fbc766cf81205785e6f1d30931.png)

  

If 账号所绑定手机号正在通话，或连续三次未接听，辣么验证码将会以留言的方式，发送到该手机号的语音信箱中。

  

接下来，攻击者通过使用Voip应用，来假冒该手机号。

  

VOIP即网络电话，Voice over Internet Protocol,将模拟的声音讯号引经过压缩与封包之后，以数据封包的形式在IP网络进行语音讯号的传输，通俗来说也就是互联网电话或IP电话。

  

而这里所使用的改号手段，实际上使用了一种非法经营的VOIP（网络电话）软件，这些软件通过修改IP数据包的主叫信息实现主叫号码的篡改。

![](../Images/0281ecd592797c067372e69415f5f589.png)

▲网上公开售卖  

  

下列为改号电话进入电话网的主要渠道:

一、通过VOIP媒体网关利用语音专线接入运营商交换机，将改号IP电话送入电话网

二、从境外运营商的网络通过国际出入口局进入境内电话网。

  

目前改号电话几乎全部来自境外，在这里黑鸟给个小提示，如果遇到改号电话记得回拨回去，如果有问题肯定打不回去。

  

回到正题，最后的关键来了，攻击者会使用此号码拨打指定电信运营商公司的语音信箱服务，并尝试输入语音信箱的默认密码（例如0000，1234）来进入此语音邮箱。

  

看到这，大概可以知道，巴西总统等人恐怕就是设置了默认密码了吧。。  

  

![](../Images/a62efa91dc5eb67b49e72b37f4da6fd2.png)

  

到最后就很简单了，进入语音信箱，听到留言的语音验证码，使用验证码登录目标账户，并绑定到攻击者设备上。

  

这一切，与报道一致，并且就是单纯为了获取历史消息记录，因此这也导致了与巴西的“内幕”的误解。

在泄露消息的影响下，当地报道称，Bolsonaro总统终于考虑使用巴西情报局（Abin）提供的加密手机。  

到目前为止，由于他们大量使用社交媒体，Bolsonaro和他的部长们一直在努力这样做，这对于Abin设备来说是不可能的。为了在其提供的设备的用户之间进行即时通信，该机构开发了应用程序Athena，其内容受便携式加密平台PCPv2的保护。

语音邮件劫持受欢迎的另一个地方是以色列，以色列国家网络安全局在2018年10月发出警告，提醒用户利用这种方法增加攻击，敦促用户更改语音邮件帐号密码，或禁用手机号码的语音邮件共。
