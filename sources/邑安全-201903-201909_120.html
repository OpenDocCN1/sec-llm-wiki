PHP反序列化介绍：

在PHP进行反序列化时，会将序列化中的变量传入类中，并且调用__destuct等魔法函数。

TestCode1:

<?php

class A{
    public $name = 'xxxx';
    
    function __destruct(){
        echo $this->name;
    }
}

echo serialize(new A());

?>

输出:

xxxxO:1:"A":1:{s:4:"name";s:4:"xxxx";}

TestCode2:

<?php

class A{
    public $name = 'xxxx';
    
    function __destruct(){
        echo $this->name;
    }
}

unserialize('O:1:"A":1:{s:4:"name";s:9:"wogaosuni";}');

?>

输出:

wogaosuni

可以发现原来的变量已经被我们替换了。
