# 美国公司出售武器化BlueKeep漏洞利用

一家美国网络安全公司正在出售武器化的BlueKeep漏洞，作为渗透测试实用程序的一部分。

BlueKeep，也称为CVE-2019-0708，是旧版Windows操作系统中包含的远程桌面协议（RDP）服务中的漏洞。

微软于5月14日发布了针对BlueKeep的补丁，并将其描述为一个“易受攻击”的漏洞，它可以以类似的方式自我传播EternalBlue如何帮助传播WannaCry勒索软件爆发。

该漏洞被认为非常危险。微软一再告诉用户应用补丁，甚至美国国家安全局（NSA），美国国土安全部，德国BSI网络安全机构，澳大利亚网络安全中心和英国国家网络安全中心都发布了安全措施警告敦促用户和公司修补旧版Windows。

在过去两个月中，安全研究人员一直保持着他们的集体广度，即恶意软件作者没有发现武器化BlueKeep的方法。

一些网络安全公司已经表示他们已经提出了全面运作的BlueKeep漏洞，但他们拒绝发布概念验证代码，因为他们担心它可能会被滥用并引发全球范围内另一波类似WannaCry的感染。

### BLUEKEEP漏洞利用了部分笔测试工具

但是在7月23日星期二，Immunity公司宣布它在公司的笔测试工具包CANVAS v7.23中包含了一个完全工作的BlueKeep漏洞。

在过去，GitHub上传了几个BlueKeep漏洞，如果他们有一个在线暴露的开放式RDP服务，可能会导致远程Windows系统崩溃。

Immunity的CANVAS BlueKeep模块可以实现远程代码执行 - 即在受感染的主机上打开shell。

虽然CANVAS许可证的成本在数千到数万美元之间，但黑客已经知道盗版或合法购买渗透测试工具（例如Cobalt Strike）。

这标志着第一次可以访问BlueKeep漏洞，尽管受众有限。但是，如果有人能负担得起这笔钱，那就是恶意软件运营和情报机构。

“这个漏洞是众所周知的，任何合理的漏洞利用作者都可以根据公开信息为它编写漏洞，”Cyxtera的首席网络安全官兼威胁管理和分析总经理Chris Day通过电子邮件告诉ZDNet。Cyxtera于2018年6月获得Immunity。

“免疫产品，Canvas，有800多个漏洞利用。包括BlueKeep在内的所有产品都有补丁，”Day补充道。“我们恰好是第一家将其纳入我们产品的商业公司，因此公司可以进行测试，看看他们暴露的支持RDP的系统是否真的可以抵御漏洞。

“此外，我们的版本不是自我传播的（蠕虫）。”

Immunity在同一天发布了其BlueKeep漏洞，网络安全分析师开始分享并研究迄今为止已知的BlueKeep漏洞的最详细报道。

然而，Immunity首席执行官Dave Aitel表示，他们的利用是他们自己研究的结果，而不是基于中国研究人员撰写并在上周末在中国举行的安全会议上发表的文章。

### 还有时间修补

在Immunity的BlueKeep利用泄漏之前，公司和用户仍有时间修补他们的系统。

众所周知，BlueeKeep会影响Windows XP，Windows Vista，Windows 7，Windows Server 2003和Windows Server 2008.所有人都可以使用补丁，还有缓解和解决方法 - 请参阅此处。现代Windows 10版本不受影响。

5月底，安全研究人员估计在大约100万个系统中易受BlueKeep攻击的Windows系统数量。

网络安全公司BitSight在7月初进行的一次扫描发现，易受攻击的主机数量已经下降，但仅略有下降，达到805,000左右。

### 奠定基础

虽然恶意软件组织还没有掌握武器化的BlueKeep漏洞，但这并没有阻止他们奠定基础。

5月下旬，隐藏在Tor节点后面的威胁行为者开始积极扫描互联网，因为Windows系统容易受到BlueKeep漏洞的影响。

从那以后，越来越多的恶意行为者也做了同样的事情，本周最新的加入者就是WatchBog僵尸网络。

根据Intezer Labs的安全研究员Paul Litvak的说法，WatchBog的操作员，一个涉及隐身加密操作的劫持Linux服务器的僵尸网络，最近在他们的恶意软件中增加了一个BlueKeep扫描器。

Litvak表示，“这表明WatchBog正在准备一份易受攻击的系统列表，以便在未来定位或出售给第三方供应商以获取利润。”

网络安全社区正在将BlueKeep视为核心世界末日时钟，这是有充分理由的。这是一个非常危险的安全漏洞，公司应该修补系统，以避免在时钟敲响午夜时被黑客攻击。
