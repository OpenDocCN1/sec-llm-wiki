# 研究发现黑客已渗透十多家运营商 必要时可切断通讯网络

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247486781&idx=1&sn=15853ee2e274fce76d601b6b3f3b8797&chksm=fa394de7cd4ec4f1856d2603a8003a15592b4db2b380872d9644d2d82bee16ef7d2a829393bd&scene=126&sessionid=1681376294#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247486781&idx=1&sn=15853ee2e274fce76d601b6b3f3b8797&chksm=fa394de7cd4ec4f1856d2603a8003a15592b4db2b380872d9644d2d82bee16ef7d2a829393bd&scene=126&sessionid=1681376294#rd)

黑客已经悄然渗透到全球十多家移动运营商，完全掌控了公司的通讯网络。根据总部位于波士顿的安全公司Cybereason近期发布的安全警告，在过去七年中黑客一直利用已经渗透的运营商网络来窃取敏感数据，甚至于在必要的时候可以完全关闭通讯网络。  

![](../Images/d5fb1c19ca419a3669520aa183d60c59.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
该公司的安全研究人员本周二表示，他们一直在调查名为Operation Softcell的黑客活动，攻击目标主要针对欧洲、亚洲、非洲和中东地区的移动运营商。自2012年开始不断有移动运营商被悄然渗透，获取完整的网络控制权限，并吸取了数百GB的用户数据。  
![](../Images/20c05580aa2a841fc291000c92fa1253.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")![](../Images/56cb89b9ce81e672cc9db3dd245f309c.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
Cybereason安全研究主管Amit Serper表示：“这些黑客拥有所有用户名和密码，并为自己创建了一系列特权，能够做任何他们想要做的事情。黑客拥有高级别的访问权限，如果愿意的话他们甚至可以关闭整个通讯网络。”  
![](../Images/8bd2f36c9ba0982c1eebc865c8de563f.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")![](../Images/6be9d6c3ab156126c7f8b6cef1aa47e6.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
Serper表示目前没有证据表明有美国运营商受到影响，但是这个黑客活动仍在持续活跃，甚至可能会衍生出更强大的病毒控制形态。Cybereason发现，虽然他们能够破坏网络信号，但黑客更关注间谍活动而不是中断。黑客窃取了数百GB的呼叫数据记录，其中包括敏感信息，如实时地理定位。  
![](../Images/9cf8bd2bde14ea3eb73c77a02dd0fe8c.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")![](../Images/fb23594d7fbdfcf1bb96e9079b4b7d28.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
在获得对移动运营商内部服务器的访问权限之后，黑客可以访问数亿客户的呼叫数据记录。这将提供诸如地理位置数据，呼叫日志和文本消息记录之类的信息。虽然黑客可以访问数百万人的数据，但他们只窃取了不到100名高度针对性的受害者的数据。Cybereason的安全实践副总裁Mor Levi表示，袭击者可能会成为政府和军方中高调受害者的目标。  
![](../Images/4300881ea0ae9a1f2bc8a84bfc492a2c.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")![](../Images/4e313d85acd85d69953bac4affd43208.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
Cybereason的研究人员发现，攻击者通过利用旧漏洞获取了对十几家移动运营商的访问权限，例如隐藏在Microsoft Word文件中的恶意软件或者找到属于该公司的公开服务器。  
![](../Images/5436e773b9d8619e2db593df1dbde6e4.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
![](../Images/14c10b0771ae767c29ed8dc4c9c62c8a.png "研究发现黑客已渗透十多家运营商 必要时可切断通讯网络")  
一旦他们进入，恶意软件就会通过搜索同一网络上的所有计算机进行传播，并尝试通过登录尝试来充斥他们。只要凭证有效，它就会继续传播，直到黑客到达呼叫者数据记录数据库。
