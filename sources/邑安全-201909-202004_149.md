# 大规模DDoS攻击导致伊朗25%的互联网连接中断

专家说，伊朗的基础设施受到了攻击，大规模的网络攻击使伊朗很大一部分的互联网访问速度下降，全国连接率下降到75％。

  

昨天（2019年2月8日）观察到该国与Internet的连接大量中断，该NetBlocks互联网观测站跟踪中断和关闭情况。

![](../Images/ac8f4393a737bd16b8ee4bc0d666836a.png)

  

据NetBlock称，在伊朗政府部署了“数字堡垒”（也称为D DEZHFA / Dejfa）之后，就发现了连通性问题。

  

NetBlocks发表的一篇文章说：“ NetBlocks Internet天文台的网络数据证实，2020年2月8日（星期六）上午，伊朗的电信网络遭到了广泛破坏。”

  

“网络数据显示，从当地时间上午11:45（世界标准时间08:15 UTC）开始，与伊朗多家领先网络运营商的连接性明显下降，从而影响了蜂窝和固定线路运营商。最初关闭一小时后，观察到部分恢复，但其他网络在事件发作后约七个小时返回。早上的一段时间内，全国连通性下降到普通水平的75％的低点。”

  

2019年12月，伊朗电信部长Mohammad Javad Azari Jahromi宣布，伊斯兰共和国最近挫败了针对其政府基础设施的“高度有组织的网络攻击”。

  

2019年10月，在卡塔尔举行的慕尼黑安全会议（MSC）网络安全峰会上，阿扎里·贾鲁米（Azari Jahromi）表示，该国的代号为“数字堡垒”（Digital Fortress（Dejfa））的网络安全项目在2018年阻止了3300万次网络攻击。

  

据专家称，伊朗昨天遭受的互联网中断影响了一些网络运营商。ICT部官员证实，数字堡垒系统消除了分布式拒绝服务（DDoS）攻击。

  

技术数据证实，该国的基础设施受到攻击时，网络已被禁用。

  

伊朗电信基础设施公司的发言人通过Twitter确认，通过“干预Dzhafa Shield”，DDoS攻击已“正常化”。

![](../Images/c177587d7a0584dcaee744536b60b4f1.png)

尽管NetBlocks指出，这一观察与有针对性的破坏相符，但《金融论坛报》透露，没有证据表明袭击是由民族国家行为者发起的。

“尚未发现袭击事件得到州政府赞助的迹象。” Bonabi告诉《金融论坛报》。

  

“攻击的来源和目的地高度分散。DDoS攻击使用了来自东亚和北美的欺骗性源IP，”

  

伊朗近几个月来面临多个网络中断，其中一些是由内部因素引起的。

  

12月，伊朗电信部长宣布，一周内第二次挫败了对其基础设施的网络攻击。

  

2019年11月，在政府宣布削减燃油补贴后，伊朗爆发了抗议活动，当局封锁了互联网访问权限，以防止新闻，视频和图像在线传播。
