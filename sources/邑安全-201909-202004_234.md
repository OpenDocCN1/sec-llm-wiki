# Citrix高危漏洞令8万家企业陷入潜在风险

**漏洞描述**  
一个新发现的影响Citrix Application Delivery Controller（NetScaler ADC）和Citrix Gateway（NetScaler Gateway）的漏洞可能会使超过80,000家公司的网络遭受黑客攻击。  
  
该漏洞编号为CVE-2019-19781（https://support.citrix.com/article/CTX267027），可能允许远程攻击者无需身份验证即可访问公司的内部网络。   
  
根据该漏洞的发现者，Positive Technologies公司的安全专家Mikhail Klyuchnikov的说法，如果被成功利用，它将导致任意代码执行。   
   
**漏洞等级** 高危  
   
**影响范围**  
CVE-2019-19781漏洞影响所有受支持的产品版本和所有受支持的平台。  
•Citrix ADC和Citrix Gateway V13.0  
•Citrix ADC和NetScaler Gateway V12.1  
•Citrix ADC和NetScaler Gateway V12.0  
•Citrix ADC和NetScaler Gateway V11.1  
•Citrix NetScaler ADC和NetScaler Gateway V10.5  
  
据评估，有80,000家公司可能面临风险。安全专家确定 “在158个国家至少80,000家公司可能受到威胁，而排名前5位的国家是美国、英国、德国、荷兰、澳大利亚。”  
  
**修复建议**  
Citrix尚未发布新固件来解决此安全问题，该公司已在知识库文章(https://support.citrix.com/article/CTX267679)中发布了一套针对独立系统和群集的缓解措施， 并强烈建议受影响的客户尽快应用。  

  
建议用户密切关注，当Citrix发布新固件时，及时更新。
