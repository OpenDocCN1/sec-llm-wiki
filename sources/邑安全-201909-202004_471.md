# Mozilla Firefox 69.0.1发布：修复诸多BUG

今天，Mozilla发布了Firefox 69的首个维护版本更新。在最新的Firefox 69.0.1中，重点解决了安全方面的问题，但是目前官方并未公布具体是哪方面的安全问题。本次更新阻止“在Firefox点击链接来加载的时候让外部程序在后台启动”的问题。

  

![](../Images/63e5386df12512b32cce0624829ad7c2.png)

  

Mozilla还修复了另外一个问题，当用户使用JAWS或者NVDA等屏幕阅读器的时候，无法使用向上、向下以及Tab键盘按键在扩展程序管理器中的所选扩展列表中使用的问题。发行说明将此称为“使用屏幕阅读器（bug 1567600）的用户对附加组件管理器的可用性改进”。

  

在登陆完成之后强制门户通知栏不会自动消失的问题Mozilla已经修复。Mozilla在Firefox 69中解决了与读者模式相关的问题，在某一点之后无法增加缩放级别，为解决这个问题，Firefox团队已经提升了“读取器模式下的最大字体大小以匹配默认字体大小的300％缩放” 。更改日志将此更改提及为“修复了放大后读取器模式中fons的最大大小（错误1578454）”。
