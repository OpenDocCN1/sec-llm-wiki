# 一、步骤

 使用Wireshark打开 misc4.pcap，大概粗略过一遍发现数据流量中存在tomcat服务，可以猜想该服务器是WEB服务器，那么使用http进行一步过滤，可以看到黑客痕迹，黑客找到了tomcat服务器管理页面，并使用弱口令tomcat:tomcat登陆进去了系统。  

![](../Images/372c03769d575a682a0d5d65905a5070.png)
