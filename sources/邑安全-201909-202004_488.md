# Windows PC可以通过快捷方式文件，网页实现恶意行为

**补丁周二**微软，Adobe和SAP今天发布了本月补丁周二的大量安全更新。  

对于Windows PC和服务器的管理员和用户来说，这将是忙碌的一天，因为微软已经发布了总共80个CVE列出的错误的更新。

本月解决的更严重问题包括CVE-2019-1215和CVE-2019-1214，这两个特权提升漏洞在野外受到主动攻击。

专家说，在这两种情况下，歹徒都会追逐旧机器。CVE-2019-1215捕获Winsock，特别是ws2ifsl.sys，这是一种自2007年以来一直被恶意软件攻击的服务，而CVE-2019-1214的漏洞利用主要是针对Windows 7盒子。这些漏洞可能会在机器管理员级别上提供恶意软件，从而劫持整个盒子。

“这是一个提醒你Windows 7距离支持结束不到六个月的好时机，这意味着你将不会在明年2月获得像这样的bug的更新，” Zero Day Initiative的Dustin Childs 说。

“修补您的系统，然后处理您的升级策略。”

在Microsoft归类为关键风险的漏洞中，有四个是Windows远程桌面中的远程代码执行漏洞。CVE-2019-0787和CVE-2019-0788，CVE-2019-1290和CVE-2019-1291都解决了恶意服务器利用其客户端连接后接管受害者PC的远程代码缺陷。

“攻击者无法强迫用户连接到恶意服务器，他们需要欺骗用户通过社交工程，DNS中毒或使用中间人（MITM）技术进行连接，”微软指出。

“攻击者还可以破坏合法服务器，在其上托管恶意代码，并等待用户连接。”

通常情况下，本月的大部分关键补丁都解决了微软浏览器脚本引擎的缺陷。Chakra，VBScript和IE脚本引擎占了八个关键修复方案。在每种情况下，都可以使用特制的网页在目标PC上远程执行代码。

运行Azure DevOps Server和Team Foundation Server的公司将要修补CVE-2019-1306，这是一个远程代码执行错误，当攻击者上传中毒文件然后被易受攻击的服务器索引时会触发该错误。

用于Windows中应用程序快捷方式的.lnk格式是CVE-2019-1280的焦点。该错误允许攻击者通过将其隐藏在可移动驱动器或远程共享上的.lnk文件后面来获取恶意应用程序（具有当前用户的权限）。

CVE-2019-1235，Windows文本服务框架中的一个特权提升漏洞和安全启动中的安全绕过CVE-2019-1294，也应该是补丁的优先级，因为它们已经公开但尚未被利用。

### 来自Adobe的两个Flash修补程序和一个Application Manager修补程序

本周二Adobe发布了一个相对安静的Patch，因为只发布了两个更新来解决总共3个CVE列出的缺陷。

对于仍在使用Flash Player的用户，此更新为CVE-2019-8070和CVE-2019-8069带来了修复，这是一对任意代码执行缺陷，可以在免费和相同的原始方法执行错误之后使用。到目前为止，两者都没有成为目标。

Adobe Application Manager（用于解压缩Adobe应用程序的安装程序工具）也收到了一个更新，以解决CVE-2019-8076，这是由于库的不安全处理导致的任意代码执行错误。然而，野外没有任何漏洞报道。

### 幸运的是，SAP还有13个补丁

不容忽视的是来自企业巨头SAP 的九月补丁包。

在发布的13个更新中，有两个针对HANA的修补程序，一个针对SAP Business Client，以及两个针对SAP诊断代理的更新。
