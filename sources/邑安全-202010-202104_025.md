# D-Link路由器漏洞研究分享

0x0 前言  
D-Link DIR-816 A2是中国台湾友讯（D-Link）公司的一款无线路由器。攻击者可借助‘datetime’参数中的shell元字符利用该漏洞在系统上执行任意命令。

0x1 准备  
固件版本 1.10B05：http://support.dlink.com.cn:9000/ProductInfo.aspx?m=DIR-816

漏洞存在的程序：goahead

![](../Images/f13492794c822456600ddba79ce917bd.png)

  

0x2 工具  
静态分析工具：IDA

系统文件获取：binwalk

动态调试工具：qemu、IDA

0x3 测试环境  
本人使用Ubuntu 16.04虚拟机测试环境，qemu模拟器模拟D-Link DIR-816 A2固件运行真实情景。

0x4 goahead程序调试  
使用binwalk进行固件解包(binwalk -Me DIR-816A2\_v1.10CNB03\_D77137.img)

![](../Images/46d18e7d4c3cd7256387208c7712f44c.png)

  

通过binwalk可以解包出如下图的文件，squashfs-root就是我们需要的文件系统。

![](../Images/76ecb916793cecf3e2941786e1c96607.png)

![](../Images/76e1dc496d98b6e54f9953a31d095546.png)

一般可以通过find -name "*index*" 可以搜索出web的根目录在哪个具体目录下。

![](../Images/bcdad9727f32ab5bb9a51934ca7c598b.png)

通过file ../../bin/goahead 命令(由于本人已经进入到根目录下面，所以是../../bin/goahead)，可以看出该系统是MIPS架构，则qemu模拟器需要使用MIPS方式的模拟器。

![](../Images/4252a7fcdf1daa708123741cc4ca0e38.png)

sudo qemu-mipsel -L ../../ -g 1234 ../../bin/goahead

\-g 使用qemu并将程序挂载在1234端口，等待调试。

\-L 是根目录的所在的位置。

可以使用IDA远程调试连接1234端口，进行调试，获取使用gdb也可以调试。

![](../Images/2598debb221448c8e53caf8592ea73a2.png)

如下图操作，IDA即可开启远程调试。

![](../Images/220350ef8e542e20330f37a26a669c41.png)

![](../Images/c6d057d1d22f9bb4b1d66ee527d01ea6.png)

![](../Images/7dc33462c29f919375e44dad57c7d23f.png)

经过测试，我们需要在0x45C728处下一个断点，因为此处的 bnez 会使程序退出，所以需要将V0寄存器的值修改为1。

![](../Images/ff58e0dbc1ab6d93c0831e47814784e3.png)

同理需要在0x45cdbc地址下断点，并将V0寄存器修改为0。

![](../Images/2a4bc7a5edd999262d8e672093ce541c.png)

两处地址都通过后，在网址中输入http://192.168.184.133/dir\_login.asp，即可访问到登录页面。

![](../Images/1b889e8fd35f58bf268c64137f8ffe5f.png)

想进入路由器web操作页面，就必须先登录，在web服务器程序中用户名为空，而web页面有JS校验，必须需要输入用户名才能进行登录校验，那么可以修改登录校验的寄存器，让其成功运行登录。

![](../Images/24839cbbdc6eeec65bb295044f9675f5.png)

在0x4570fc地址处下断点，修改V0寄存器的值为0。因为此处的V0是用户名的值，在登录页面中，我们是随意输入，所以肯定是不会正确的，那么就只有修改为0后才能跳转到正确的登录流程。

![](../Images/db4e1e84dfc6398fd791c3053ed919d3.png)

登录成功后，会出现页面错误。

![](../Images/fd86033ec9a848a81e614eca12dcc78e.png)

再在网址中输入http://192.168.184.133/d\_wizard\_step1\_start.asp，即可进入到登录成功后的页面。看到如下图，即可证明已经登录成功。

![](../Images/011b5fe3d77fd5d976b28a7c7a60a009.png)

登录认证后，点击维护，再点击时间与日期，最后点击应用，此处便是漏洞触发点。

![](../Images/41d26916c0c5dd827b30e33cc5f88fb7.png)

最终可以通过构造datetime的值，执行任意命令。

![](../Images/8af4b53896feee340c45ae116012878a.png)

0x5 总结  
这个固件可以锻炼qemu模拟器的使用以及IDA简单调试能力，在没有真实路由器的情况下qemu是非常好用的一款模拟工具，模拟很多款路由器。该程序还存在多个命令执行漏洞，非常适合练手。命令执行漏洞相对来说比较简单，但是杀伤力巨大，很适合新手入门。
