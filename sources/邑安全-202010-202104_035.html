VISA：黑客越来越多地使用Web Shell窃取信用卡

更多全球网络安全资讯尽在邑安全

全球支付处理商VISA警告说，威胁行动者正越来越多地在受感染的服务器上部署Web Shell，以泄露从在线商店客户窃取的信用卡信息。

Web Shell是威胁参与者部署的工具（脚本或程序），用于获取和/或维护对被入侵服务器的访问，远程执行任意代码或命令，在目标网络内横向移动或提供其他恶意有效载荷。

Web Shell用于泄露掠过的信息

在过去的一年中，VISA看到了越来越多的趋势，网络外壳被用于将基于信用卡的JavaScript脚本（称为信用卡撇取者）注入被盗的网上商店（也称为数字撇取，电子窃取或 Magecart）攻击中。

部署后，撇取者就可以让他们窃取受感染在线商店客户提交的付款和个人信息，并将其发送到他们控制下的服务器。

VISA表示：“到2020年，签证付款欺诈中断（PFD）识别出一种趋势，许多eSkimming攻击利用Web shell在攻击期间建立命令和控制（C2）。”

“ PFD在2020年确认至少使用网络外壳进行了45次eSkimming攻击，安全研究人员同样指出，在更广泛的信息安全威胁领域中，网络外壳的使用正在增加。”

正如VISA PFD所发现的那样，Magecart威胁参与者主要使用Web外壳对被入侵的在线商店服务器进行后门攻击，并建立了一个命令和控制基础结构，以使他们能够窃取被盗的信用卡信息。

攻击者使用多种方法来破坏在线商店的服务器，包括不安全的管理基础架构，与电子商务相关的应用程序/网站插件以及过时/未修补的电子商务平台中的漏洞。

Web Shell越来越多地用于后门服务器

今年2月，VISA的调查结果得到了Microsoft Defender高级威胁防护（ATP）小组的确认，该小组说，自去年以来，部署在受感染服务器上的Web Shell数量 几乎增加了一倍。

从2020年8月到2021年1月，该公司的安全研究人员每月平均在被黑客入侵的服务器上发现14万个此类恶意工具。

相比之下，微软在2020年的一份报告中 表示，根据从2019年7月至2019年12月之间从大约46,000个不同设备收集的数据，每月平均检测到77,000个Web Shell。 



美国国家安全局（NSA）在 与澳大利亚信号局（ASD）于2020年4月发布的联合报告中也警告说 ，威胁行为者会通过部署Web Shell将攻击扩展到后门易受攻击的服务器。

VISA补充说：“尽管上述策略，技术和过程并未详尽列出攻击者在这些Web Shell攻击中使用的各种方法和利用，但它们是确定的一些领先方法。”

“识别策略，例如使用网络外壳，还可以帮助识别在商家网站上未检测到eSkimmer时的危害。

“使用网络外壳来促进eSkimming攻击很可能会持续下去，特别是随着流行继续，围绕个人，实体交易的限制仍然存在。”
