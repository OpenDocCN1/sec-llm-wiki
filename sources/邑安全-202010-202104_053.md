### sys.modules

`sys.modules` 是一个字典，里面储存了加载过的模块信息,但是不能直接使用， sys.modules 中未经 import 加载的模块对当前空间是不可见的.

如果在

```
sys.modules['os'] = 'not allowed'
```

修改os库,会会导致import失败,

我们只要

```
del sys.modules['os']
```

即可导入
