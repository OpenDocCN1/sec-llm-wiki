微软Exchange服务器修复错误后依然遭受大量wannacry攻击

更多全球网络安全资讯尽在邑安全

Microsoft Exchange中最近修补的漏洞引起了网络犯罪分子的新兴趣，网络犯罪分子增加了针对该特定媒介的攻击量。

在过去六个月中，勒索软件攻击的频率有所增加，但网络安全公司Check Point上周注意到，针对Microsoft Exchange服务器的事件激增，这些漏洞易受所谓的ProxyLogon严重错误的影响。

即使补丁程序迅速发展，该公司仍发现未遂攻击在全球范围内激增了三倍，数以万计。

Microsoft Exchange仍然具有吸引力

根据Microsoft的数据，根据RiskIQ的数据，到3月14日，大约有82,000台易受攻击的Exchange服务器。大约一周后，该数量下降到大约30,000台暴露的计算机。

上周来自Check Point的遥测数据显示，全球发生了50,000多次攻击尝试，其中大多数针对政府/军事，制造业和银行/金融部门的组织。

与Check Point记录的事件少得多的其他国家（英国-5％，荷兰和德国-均为4％）相比，将近一半的攻击尝试发生在美国（49％），是最具吸引力的地区。

勒索软件攻击上升，WannaCry仍然是一个问题

在过去六个月中，该公司在全球范围内的勒索软件攻击上升了57％。令人担忧的是，自今年年初以来，每月稳定增长9％。

除了观察到的正常勒索软件病毒（迷宫，Ryuk，REvil）外，该公司还注意到受可蠕虫WannaCry勒索软件影响的组织数量激增了53％。

“事实上，CPR发现，与2020年10月相比，2021年3月受影响的组织是40倍。新样本仍使用EternalBlue漏洞进行传播-补丁的可用时间已超过4年”-Check Point

大约四年前，WannaCry爆发 通过NSA的Windows Server Message Block（SMB）永恒之蓝传播，仅在几天之内就造成了数亿美元的损失。

在安全研究员马库斯·哈钦斯（Marcus Hutchins）发现了一个杀伤开关并且微软发布了补丁程序之后，该病毒的传播受到了遏制。超过200,000台计算机受到了攻击的影响。

但是，该恶意软件尚未消除。即使是最近几天，安全公司仍在继续检测WannaCry。这些检测是针对原始WannaCry的变体，这些变体已被修改为忽略终止开关。此外，安全研究员Vesselin Bontchev表示，他从未发现带有有效勒索软件组件的样本。

一月份，这些WannaCry变体代表了趋势科技的顶级勒索软件检测。

大量数据背后的原因是WannaCry具有可感染性，并且数千个系统仍然容易受到EternalBlue的攻击，而EternalBlue可以通过公共Internet进行访问。

从2020年12月开始，Check Point观察到了相同的趋势，到2021年3月，攻击次数继续增加到超过12,000次。

数字显示了及时打补丁的重要性，否则组织仍然容易受到应该已经绝迹的攻击媒介的攻击。
