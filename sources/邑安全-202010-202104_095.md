# 智利银行监管机构在Microsoft Exchange遭到黑客攻击后共享入侵IOC

智利的墨西哥金融市场委员会（CMF）披露，其Microsoft Exchange服务器已因最近披露的ProxyLogon漏洞而受到威胁。

CMF在财政部下运作，是智利银行和金融机构的监管者和检查员。

本周，CMF披露，在威胁行动者利用其Microsoft Exchange服务器中最近披露的ProxyLogon漏洞安装Web Shell并试图窃取凭据之后，他们遭受了网络攻击。

“金融市场委员会（CMF）更新了昨天报告的由Microsoft Exchange电子邮件平台中的漏洞引起的运营事件的信息。”

“由CMF的信息安全和技术领域进行的分析，加上外部的专业支持，到目前为止，已经排除了勒索软件的存在，并表明该事件将仅限于Microsoft Exchange平台，”Comisiónpara透露。

CMF进一步指出，他们正在调查该违规行为，并已与财政部的计算机安全事件响应小组（CSIRT）联系。

  

## **CMF分享其攻击的IOC**

为了帮助安全专业人员和其他Microsoft Exchange管理员，CMF发布了Web Shell的IOC和在受感染服务器上找到的批处理文件。

*   0b15c14d0f7c3986744e83c208429a78769587b5：error\_page.aspx（China Chopper Web Shell）
*   bcb42014b8dd9d9068f23c573887bf1d5c2fc00e：supp0rt.aspx（China Chopper Web Shell）
*   0aa3cda37ab80bbe30fa73a803c984b334d73894：test.bat（转储lsass.exe的批处理文件）

尽管危害指标（IOC）对于每个受害者都有不同的文件哈希值，但是在许多攻击中，文件名都是相同的。

在许多ProxyLogon攻击中都使用了使用名称为“ error\_page.asp”和“ supp0rt.aspx”的Web Shell，并且大多数情况下都是相同的，仅针对受害者有几处更改。

这些文件是Microsoft Exchange脱机通讯簿（OAB），其ExternalUrl设置已更改为 China Chopper Web Shell。通过此Web Shell，威胁参与者可以通过访问ExternalURL设置中配置的URL，在受感染的Microsoft Exchange服务器上远程执行命令。

![](../Images/f21f76fe829574d6f240be921f09c2cd.png)

  

带有Web Shell的Microsoft Exchange脱机通讯簿（OAB）

  

批处理文件test.bat在ProxyLogon攻击中也很常见，用于转储LSASS进程的内存以获取Windows域凭据。批处理文件还会导出Windows域上的用户列表。

下面显示的命令将使用comsvcs.dll LOLBin将LSASS的内存转储到IIS服务器的wwwroot中的文件中。然后，它使用dsquery将Windows域中的用户列表导出到文件中。

然后将这些文件压缩到wwwroot中，以由威胁参与者远程下载。

![](../Images/f622e39109cc535f6cb42ec1e8d3e7d1.png)

  

转储LSASS进程的内存

  

尽管大多数Microsoft Exchange攻击一直在部署Web Shell，收集凭据和窃取邮箱，但有些攻击也正在安装 cryptominer，最近，  DearCry勒索软件 被利用了。

为了帮助管理员找到在这些攻击中丢失的恶意文件，Microsoft发布了一个脚本，该脚本在Microsoft Exchange日志中 搜索IOC  ，并 更新了其Microsoft安全扫描程序（MSERT） 以检测已知的Web Shell。
