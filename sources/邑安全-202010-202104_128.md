# 研究人员在Linux内核中发现5个高危漏洞

Positive Technologies的研究人员Alexander Popov在Linux内核中发现了五个高度严重的漏洞，这些漏洞可能导致本地特权提升。  
  
Linux内核漏洞是AF\_VSOCK实现中存在的竞争条件，它们于2019年11月隐含在提交c0cfa2d8a788fcf4和6a2c0962105ae8ce的内容中引入，这些内容添加了VSOCK多传输支持。  
一个 竞争条件是一个电子设备，软件或其他系统中的系统的实质性行为是依赖于其他无法控制的事件的顺序或时间的条件。当不希望有一种或多种可能的行为时，它将成为一个错误。  
竞争条件源于net / vmw\_vsock / af\_vsock.c中的错误锁定。  
*“ CONFIG\_VSOCKETS和CONFIG\_VIRTIO\_VSOCKETS在所有主要的GNU / Linux发行版中均作为内核模块提供。当您为AF\_VSOCK创建套接字时，会自动加载易受攻击的模块。这可用于非特权用户，并且不需要用户名称空间。这些漏洞是由于net / vmw\_vsock / af\_vsock.c中的错误锁定导致的竞争条件。” 波波夫写道。“比赛条件已在2019年11月隐含地引入到commits c0cfa2d8a788fcf4和6a2c0962105ae8ce中，其中增加了VSOCK多传输支持。这些提交已合并到Linux内核v5.5-rc1中。”*该问题统称为 CVE-2021-26708，已于2019年11月在5.5版内核中引入，它们的CVSS得分为7.0。  
专家成功开发了PoC漏洞，用于在Fedora 33 Server上提升本地权限，它可以绕过x86\_64平台保护，例如SMEP和SMAP。  
该 补丁已合并 到主线内核版本5.11-rc7中，并反向移植到受影响的稳定树中。  
Popov过去发现了其他Linux内核漏洞，包括CVE-2019-18683 和 CVE-2017-2636漏洞。
