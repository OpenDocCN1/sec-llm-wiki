# 俄罗斯黑客组织部署IronPython恶意软件加载程序

帕洛阿尔托的Unit42报道，作为新活动的一部分，俄罗斯黑客组织Turla正在部署一个基于IronPython的恶意软件加载器，称为“ IronNetInjector” 。

Unit42研究人员报告说，新的加载器通过利用IronPython直接使用.NET Framework API以及Python库的能力来提供ComRAT（一种远程访问木马）。

报告指出：“ IronNetInjector由IronPython脚本组成，该脚本包含一个.NET注入器和一个或多个有效负载。” “运行IronPython脚本时，将加载.NET注入程序，这又将有效负载注入其自身或远程进程中。”

据研究人员称，最新的加载器具有混淆恶意软件代码以及加密和解密NET注入器和有效载荷的功能。

### **装载机基础设施**

Unit42的研究人员确定了两个IronNetInjector变体，分别在2018年和2019年编译。它们都使用了成熟的便携式可执行注入工具集，这些工具集被部署用于在另一个进程内存中注入和运行代码。

尽管2018年的加载器是用更具体的方式编写的，但研究人员指出，2019年的加载器是通用的，并且具有将.NET程序集注入到非托管进程中的功能。

IronNetInjector在运行开源Python编程语言IronPython脚本时开始其功能。然后，将恶意代码加载到嵌入式.NET注入器中，该注入器然后对ComRAT木马进行解码和解密。

根据报告，一旦ComRAT被解密，.NET注入程序将控制进一步的执行，例如混淆和加密。

研究人员指出：“。NET注入器和引导程序包含干净的代码和有意义的函数/方法/变量名称，它们使用详细的日志/错误消息。仅对最初的IronPython脚本进行了模糊处理，以防止易于检测。”

安全公司KnowBe4的国防宣传人员Roger Grimes说，由于.NET框架主要仅在Windows平台上运行，因此这些工具的影响可能很小。

Grimes说：“在Microsoft Windows计算机上，它成为可能绕过或混淆反恶意软件预防和检测软件的众多选择中的另一种潜在方法。”

Grimes说，为了捍卫Windows用户，安全研究人员必须进行分析以检测任何可疑活动。

“反恶意软件软件必须意识到这种新的恶意软件注入技术，并能够以区分合法使用和恶意使用的方式进行处理和解析。在100多个恶意软件程序中，有一定比例的不会升级为检测这种技术，因此它可以帮助恶意软件开发人员。”

### **过去的活动**

据报道，Turla也被称为Belugasturgeon，Ouroboros，Snake，Venousous Bear和Waterbug，是俄罗斯FSB（前称KGB）的一部分，自2008年以来已针对至少35个国家/地区的政府和军事机构开展了一系列行动。

先进的持久性威胁小组已部署了一个大型恶意软件库，安全研究人员在过去几年中已对其进行了记录。该小组的黑客工具包括ComRAT网络渗透恶意软件和用于操纵Windows API以实现持久性的HyperStack后门程序。

这也不是该组织第一次将合法工具和服务用作其恶意基础架构的一部分。

2020年12月，安全公司ESET发现了Turla开展的网络间谍活动，该活动部署了一个名为“ Crutch”的后门，该后门使用Dropbox的资源来帮助收集被盗的数据。
