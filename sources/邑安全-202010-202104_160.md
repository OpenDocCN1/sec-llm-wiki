# 微软悄然推出“杀手补丁”：彻底封杀Flash Player

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247500002&idx=2&sn=788e2281938e1ad1f363ddfb42c27026&chksm=fa3a8038cd4d092e2ba5f8382d87a793ee5486d6f8f21a3472394aa639677d618b393de03a19&scene=126&sessionid=1681375837#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247500002&idx=2&sn=788e2281938e1ad1f363ddfb42c27026&chksm=fa3a8038cd4d092e2ba5f8382d87a793ee5486d6f8f21a3472394aa639677d618b393de03a19&scene=126&sessionid=1681375837#rd)

更多全球网络安全资讯尽在邑安全

Adobe 已经停止了对 Flash Player 的支持，并开始主动阻止内容在播放器中运行。Adobe 已经“强烈建议”所有用户立即卸载 Flash Player，以保护他们的设备和组织免受攻击。在近期更新的支持文档中，微软已经确认 Flash Player 杀手补丁已经可以作为“可选更新”供用户下载。

![](../Images/d11904f2d86987cb07cc758d29a644c9.png)

![](../Images/9976a0616136843606b153ab42c1b64d.png)

在 2 月 16 日微软悄然更新的支持文档中，微软表示：“作为结束对 Flash Player 支持的扫尾工作，KB4577586 现在作为可选更新从 Windows Update（WU）和 Windows Server Update Services（WSUS）渠道分发”。

虽然微软说这是个可选更新，但不少用户反馈会自动更新并删除 Flash Player。其他用户也观察到，Flash Player-killer 更新并不是作为可选补丁提供的，当用户点击 "检查更新 "时，它会自动下载。这说明微软也在测试一种 "分阶段的方法"，在未来几个月内，用户将看到不同配置的更新自动下载。

无论是通过Windows Update的 "可选更新 "部分还是自动安装，一旦安装该更新用户就无法再次使用 Flash Player，除非你重新安装旧版本的操作系统并暂停更新。
