# FonixCrypter勒索软件团伙发布主解密密钥

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247499426&idx=2&sn=433adc47c9d9e398cd062f8f2911fa8a&chksm=fa3abe78cd4d376e4e3fbf1c18f875ae849ebe7755fab447337f810fca71b86f4a467dd0dabe&scene=126&sessionid=1681375853#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247499426&idx=2&sn=433adc47c9d9e398cd062f8f2911fa8a&chksm=fa3abe78cd4d376e4e3fbf1c18f875ae849ebe7755fab447337f810fca71b86f4a467dd0dabe&scene=126&sessionid=1681375853#rd)

FonixCrypter勒索软件背后的网络犯罪组织今天在Twitter上宣布，他们已经删除了勒索软件的源代码，并计划关闭其运行。为了向过去的受害者表示好感，FonixCrypter团伙还 发布了一个软件包， 其中包含解密工具，使用说明和勒索软件的主解密密钥。以前被感染的用户可以使用这些文件免费解密和恢复其文件，而无需支付解密密钥。威胁情报公司Recorded Future的安全研究员Allan Liska今天早些时候测试了该解密器， 并验证了FonixCrypter应用程序，说明和主密钥工作是否如广告中所述。Liska： “ Fonix勒索软件背后的参与者提供的解密密钥似乎是合法的，因为它认为每个文件都必须单独解密 。”他补充说：“重要的是它们包含了主密钥，这将使某人能够构建更好的解密工具。”Emsisoft安全研究人员Michael Gillespie是专门研究破坏勒索软件加密的人，他在网上聊天表示，目前，Emsisoft正在开发一种更好的解密程序，并有望在下周发布 。建议用户等待Emsisoft解密器，而不要使用FonixCrypter帮派提供的解密器，该帮派可能很容易包含其他恶意软件，例如后门，最终受害者可能会在其系统上进行安装。

![](../Images/5f1fc2b80334a6849b8ee170e9240d26.png)

  
根据俄罗斯安全研究人员安德鲁·伊万诺夫（Andrew Ivanov）的说法，FonixCrypter勒索软件犯罪团伙至少在2020年6月就开始活动，直到今天关闭为止 。过去四年来，他一直在他的个人博客中跟踪勒索软件的攻击。伊万诺夫（Ivanov）的FonixCrypter博客条目 显示了FonixCrypt代码不断更新的历史，去年至少发布了七个不同的FonixCrypt变体。虽然勒索软件的源代码可能不是一流的，但勒索软件却在去年大放异彩并得到了广泛使用，使全世界的受害者都受了害。目前，所有迹象都表明，FonixCrypter团伙对他们的关闭计划很认真。利斯卡说，FonixCrypter团伙今天已经删除了其Telegram频道，他们通常在该频道上向其他犯罪集团宣传勒索软件，但Recorded Future分析家还指出，该组织还宣布了在不久的将来开设新频道的计划。但是，FonixCrypter团伙未指定此新的Telegram频道是否将重点放在提供新的和改进的勒索软件病毒上。根据在Twitter上发布的消息，该组织声称他们计划远离勒索软件，并以“积极的方式”使用其能力。
