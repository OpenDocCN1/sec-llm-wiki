# 拼多多天才黑客疑被开除 因拒绝做黑客攻击业务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247498924&idx=1&sn=ec4a15cffdd91f2281f0b4b95b0c4c92&chksm=fa3abc76cd4d3560d7ed2aed35b91dbb0544fdd826286aff2824ccbc3661c52d791a185393b6&scene=126&sessionid=1681375863#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247498924&idx=1&sn=ec4a15cffdd91f2281f0b4b95b0c4c92&chksm=fa3abc76cd4d3560d7ed2aed35b91dbb0544fdd826286aff2824ccbc3661c52d791a185393b6&scene=126&sessionid=1681375863#rd)

更多全球网络安全资讯尽在邑安全

近期，拼多多深陷舆论漩涡，并且风波是一个接着一个。被曝出员工猝死，跳楼自杀、开除员工、远程删除用户等一连串事件后，拼多多又被“砍刀”。

据称，前拼多多安全团队老大，15岁上浙大、22 岁获得世界黑客大赛冠军的黑客圈天才——Flanker，疑因拒接违法攻击被强制开除，或损失上亿股票。

![](../Images/640740e841c9586d8c00c80f29982e15.png)

1月12日，“如何看待天才黑客 Flanker疑因拒绝做黑客攻击业务，被拼多多强行辞退，错失上亿股票？”话题冲上知乎热搜第一。

![](../Images/de0cee482a11c984cd842736a764c081.png)

据话题显示， 拼多多被曝出在员工即将拿到公司股票时被拼多多开除。离职之际，Flanker入职拼多多即将满五年，被点出“或损失上亿股票”，这让不少人感到非常讽刺。

据显示，2020年12月22日Flanker在微博上发布声明称：“我已不在该司工作，我应得而该司抵赖不给的各种权益已委托律师处理。”随后有网友扒出文中的“该司”是指拼多多。

![](../Images/1dc3961bfb8454f4f2a217424f3a2692.png)

其本人近期在微博中多次提及“非法侵入计算机信息系统罪”：

![](../Images/a7163d34de3d73f065f712413070eeb7.png)

另外，默安科技创始人兼CTO、原阿里集团安全研究实验室总监云舒和信息安全专家sunwear等人纷纷转发微博支持 Flanker，也促使该事件进一步发酵。

![](../Images/e4fcfaf910a1890747811ad84d7d939b.png)

![](../Images/3f8648aecdef0d2f4670e7095f22845a.png)

资料显示，Flanker，本名何淇丹，毕业于浙江大学少年班和香港科技大学，知名互联网企业安全总监，曾获得世界顶级黑客大赛Pwn20wn Mobile和PC双料冠军，Google Android Security Top Researcher，BlachHat USA和DEFCON演讲者。26岁时，其加入拼多多，负责公司整体安全。
