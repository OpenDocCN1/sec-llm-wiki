##### 关于fixed\_array与fixed\_double\_array的不同

两者都是element部分

###### 对于fixed\_array，其中每一个都会向obj一样解析

![](../Images/1ba7c3087e26b39e98cdc84dd6805168.png)

哪怕像这样插入一个浮点数

```
spary[spary_size-1] = 1.1;
```

也会作为heapNumber对象，这样的话直接读取spary\[idx\]返回的是

```
,,,
```

因为这些idx位置都是 obj指针，如果返回就相当于泄露map值了

###### 对于fixed\_double\_array

其中的浮点数都是直接存储的

![](../Images/1b7471e03aa102b4365b3b452152ca9d.png)

可以直接通过idx访问
