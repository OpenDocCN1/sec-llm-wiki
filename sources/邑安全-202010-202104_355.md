# 扫描400万个Docker映像后发现51％存在严重缺陷

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247497326&idx=1&sn=f9bb0d0e2e4fc16dee9f6eca006e0240&chksm=fa3ab6b4cd4d3fa238bec8d45c72caa52b39d990dce6a7d00dbf1a5c41fd7d5924d7cc8374ab&scene=126&sessionid=1681375898#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247497326&idx=1&sn=f9bb0d0e2e4fc16dee9f6eca006e0240&chksm=fa3ab6b4cd4d3fa238bec8d45c72caa52b39d990dce6a7d00dbf1a5c41fd7d5924d7cc8374ab&scene=126&sessionid=1681375898#rd)

更多全球网络安全资讯尽在邑安全

容器安全公司Prevasio分析了Docker Hub上托管的400万个公共Docker容器映像，发现其中大多数具有严重漏洞。该网络安全公司使用其Prevasio Analyzer服务在800台计算机上运行了一个月。在400万张图像中，有51％包含具有至少一个严重缺陷的程序包或应用程序依赖项，而13％的图像具有严重级别的漏洞。*“动态分析还发现了6,432个恶意或潜在有害的容器映像，占Docker Hub上所有公共可用映像的0.16％。” 读取Prevasio发布的分析。“这份报告解释了我们所做的工作，我们的发现，发现的恶意软件类型以及发现的包含恶意软件或潜在有害软件的容器映像的几个典型示例。”*仅关注Linux容器映像的研究人员发现，由于仅针对Windows生成和/或没有针对Linux的生成，因此将近1％的映像排除在分析之外。研究人员还发现，有6,432张图像包含潜在的恶意软件，例如加密货币矿工（44％，2,842张图像和Pull计数：1.295亿），黑客工具（20％，1,269张图像和Pull计数：70M），恶意的npm软件包平面图-stream（23％，1482张图像，Pull计数：95M）和受污染的应用程序（木马WordPress插件，Apache Tomcat和Jenkins）。![](../Images/1608743c74cc517cc8fae02c673fcc63.png)恶意或潜在有害图像的总提取数量超过3亿。一些图像包含动态有效载荷，这些有效载荷在运行时正在下载加密货币矿工的源代码并执行它。专家指出，目前，映像中发现的大多数恶意软件都以Windows为目标。*报告总结说：“ Prevasio进行的调查表明，Linux操作系统，尤其是Linux容器不能幸免于安全风险。” “我们的研究表明，主要安全风险是由关键漏洞造成的。Docker Hub托管的所有容器映像中，有一半以上包含一个或多个严重漏洞，因此有可能被利用;另一个风险是，在400万个公共可用映像中，有6,432个被发现包含恶意或潜在漏洞。有害代码。”*原文来自:securityaffairs
