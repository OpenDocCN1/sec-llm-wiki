# Windows 10出现升级BUG：无法保留用户个人数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247496502&idx=1&sn=c204855b983f5cf9733a6542fb2ff4d4&chksm=fa3ab3eccd4d3afa645458e359cda9c1734db56e271c16ed2a1cf7a4484f67ec4baca2c8c0fe&scene=126&sessionid=1681375909#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247496502&idx=1&sn=c204855b983f5cf9733a6542fb2ff4d4&chksm=fa3ab3eccd4d3afa645458e359cda9c1734db56e271c16ed2a1cf7a4484f67ec4baca2c8c0fe&scene=126&sessionid=1681375909#rd)

如果你的设备在使用过程中出现某些故障，那么重新安装 Windows 10 或许是最简单、最有效的方式。微软允许用户通过媒体创建工具等丰富方式来重装系统，不过有个问题需要注意，就是安装 Windows 10 October 2020 功能更新之后将无法保存你的应用、设置和文件。

![](../Images/fbcb4f70bb7ac2644ec5a5b58b902380.png)

存在于 Windows 10 启用包中的 BUG 会禁用两个选项--保留个人文件和应用、保留个人文件，用户只能选择“Nothing”。如果选择“Nothing”，那么就意味着用户无法保留个人文件来重装系统或者就地升级 Windows 10 20H2。

![](../Images/70fbb350f57ad7af50c8a8478d7d9d76.png)

值得注意的是，如果从 Windows 10 Version 2004 功能更新上进行升级，媒体创建工具能够按照预期方式工作，但如果通过 Windows Update（启用包）方式，在升级过程中将强制用户选择“Nothing”选项，意味着你的个人文件将丢失。

幸运的是，目前有一个临时的解决方案

1\. 打开设置>更新和安全> Windows Update。

2\. 点击“查看更新历史记录”按钮。

3\. 点击“卸载更新”。

4\. 在“控制面板”窗口中，查找“ KB4562830”。

5\. 选择更新程序包，然后单击“卸载”

6\. 重新启动系统。

7\. 打开媒体创建工具，您现在可以选择用于保留文件的选项。

微软目前已经承认了这个问题，表示将会在下月补丁星期二活动日发布的累积更新中进行修复。
