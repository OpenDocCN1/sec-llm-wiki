# 挪威指责俄罗斯对其议会进行网络攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247495525&idx=2&sn=0f61eb77295df0f6e7cfc7343f5c24de&chksm=fa3aafbfcd4d26a961130a150ab4b450d2ffbcc7e883c54b50fda69c744359b898f8214d3ac7&scene=126&sessionid=1681375930#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247495525&idx=2&sn=0f61eb77295df0f6e7cfc7343f5c24de&chksm=fa3aafbfcd4d26a961130a150ab4b450d2ffbcc7e883c54b50fda69c744359b898f8214d3ac7&scene=126&sessionid=1681375930#rd)

更多全球网络安全资讯尽在邑安全

  

  

  

挪威政府将今年夏天针对该国议会电子邮件系统的网络攻击归咎于俄罗斯。

8月底，挪威议会Stortinget宣布，这是一次重大网络攻击的目标，网络攻击使黑客能够访问少数议会代表和雇员的电子邮件和数据。

*挪威议会发表声明说：“议会最近遭到了大规模的网络攻击，”。“一些议员和员工的电子邮件帐户遭到入侵。我们的分析表明，下载了数量不等的数据，”*

![](../Images/b4592578dd99c293fc5f0afa1b44e36d.png)

Stortinget总监Marianne Andreassen确认正在对该事件进行调查，因此，她没有提供有关攻击者可能来源的任何详细信息。

  

挪威情报机构在一条推文中确认了调查：

> PST与IT相关的新闻，请参阅Stortinget。NST PST har mottatt anmeldelsen vil vi vurdere om det er grunnlag可以用于初学者。https://t.co/UIuqeXgaea
> 
> — PST（@PSTnorge）2020年9月1日

该行政主管透露，议会的IT人员已在8月底发现了异常情况，并立即采取了必要的措施以应对这次袭击。

*“我们不知道背后是谁，”玛丽安·安德里亚森对记者说。*

据当地媒体报道，议会的IT人员关闭了其电子邮件服务，以防止黑客窃取敏感数据。

Stortinget立即将安全漏洞通知了受影响的代表和员工。

现在，挪威政府将网络攻击归因于与俄罗斯有联系的威胁行为者，但并未分享调查细节。

*外交部长埃内森·索里德（Ine Eriksen Soreide）**在一份声明中说： “根据政府掌握的信息，我们认为俄罗斯应对这些活动负责。” **“这是一个非常严重的事件，影响到我们最重要的民主制度。”*

政府专家建议组织遵循有关网络安全的准则，以减轻网络攻击的风险。

挪威的PST国内情报部门在年度威胁评估中警告说，黑客攻击代表着“对挪威的持续和长期威胁”。

在挪威，针对基础设施和实体的网络攻击并不常见。

2020年5月，挪威国家投资基金Norfund 遭受 了企业电子邮件泄露（BEC）攻击，黑客偷走了1000万美元。

2019年1月8日，东南医疗卫生组织RHF，这是管理挪威东南地区（Østfold，Akershus，奥斯陆，Hedmark，Oppland，Buskerud，Vestfold，Telemark，Aust-Agder和Vest-Agder的国家）的医院的医疗组织， 公开的安全漏洞 可能已经暴露属于超过一半的人口敏感数据。

挪威东南部地区卫生局HelseSør-Øst宣布了这一事件，该事件发现该地区计算机系统存在异常活动。管理局将事件通知了当地机构和 NorCERT。

2017年2月，挪威情报机构PST 证实 ，该国当局是俄罗斯APT 29小组发起的鱼叉式网络钓鱼攻击的目标之一。

据情报分析员称，自2014年俄罗斯吞并克里米亚以来，网络业务有所增加。
