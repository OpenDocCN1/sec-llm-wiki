黑客团伙创建假公司聘请渗透测试人员进行勒索软件攻击

更多全球网络安全资讯尽在邑安全

FIN7 黑客组织正试图通过创建假冒的网络安全公司来加入高利润的勒索软件领域，这些公司以渗透测试为幌子进行网络攻击。

FIN7（又名“Carbanak”）自 2015 年首次出现在网络犯罪领域以来就一直参与网络攻击和偷钱活动，包括 用支持 MITM 的恶意软件感染 ATM。

由于勒索软件已成为网络犯罪分子的一个有利可图的领域，并且之前有与“ Combi Security ”等虚假幌子公司合作的经验，因此该组织成立了一家新公司来吸引合法的 IT 专家。

Gemini Advisory的研究人员揭开了这个新公司实体合法性的薄薄面纱 ，他们发现一家名为 Bastion Security 的虚假网络安全公司的网站包含从其他网站窃取和重新编译的内容。

更具启发性的是，该公司声称他们位于英国以外，但该网站提供俄语 404 错误页面。

堡垒安全网站

Bastion Secure 的“关于”页面还声称是合法网络安全公司 Convergent Network Solutions Ltd 的衍生产品。
BleepingComputer 联系了 Convergent Network Solutions 以查看他们是否知道该站点但没有收到回复。
Gemini 研究人员发现，FIN7 每月提供 800 至 1,200 美元，以通过遵循匿名来源的提示招募 C++、PHP 和 Python 程序员、Windows 系统管理员和逆向工程专家。
在工作要求中，研究人员认为，黑客组织希望雇佣渗透测试人员，因为系统管理员还能够绘制受感染的公司系统、执行网络侦察以及定位备份服务器和文件。

所有这些技能都是勒索软件攻击的预加密阶段所必需的，因此看来这就是 FIN7 通过这些招聘轮次所追求的。

研究人员申请工作

Gemini 的消息来源向 Bastion Secure 发送了一份求职申请并被聘用，最终获得了使用内部工具的权限。
这些工具是著名的后开发工具 Carbanak 和 Lizar/Tirion，伪装成“命令管理器”。

Command Manager 的仪表板

因此，尽管其中一些工具的源代码在两年前公开泄露，但对 FIN7 的归因非常强 。
Carbanak 的分析样本似乎是更新版本，因此其他人使用泄露的工具对其进行进一步研究的可能性很小。
另一个证据是，该软件据称已授权给著名的以色列安全公司“CheckPoint Software Inc”，FIN7 已将其伪装成 最近的其他攻击。
招聘过程非常典型，包括面试、签订合同和保密协议以及基本培训。
但是，在执行实际任务时，很明显 Bastion Secure 正在寻找某人来进行网络犯罪活动。
他们提供对公司网络的访问，将其呈现为订购渗透测试服务的客户，并要求新员工收集与管理员帐户、备份等相关的信息。
然而，FIN7 没有为这次渗透测试活动提供任何法律文件，因此 Gemini 的消息来源意识到他们可能居住在一家受害公司内部，使用通过非法手段获得的访问权限。
通过创建虚假的网络安全公司来进行攻击，双子座认为这是一种雇用廉价劳动力的尝试，而不是与要求占任何已支付赎金 70-80% 的更大份额的附属公司合作。
