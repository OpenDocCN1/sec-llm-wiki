网络钓鱼活动使用数学符号来逃避检测

更多全球网络安全资讯尽在邑安全

网络钓鱼攻击者现在在冒充的公司徽标上使用数学符号来逃避反网络钓鱼系统的检测。

INKY 分析师发现的一个值得注意的案例涉及欺骗美国大型电信服务提供商 Verizon。

在这种情况下，参与者使用平方根符号、逻辑 NOR 运算符或复选标记符号本身，所有这些都有助于创建可能欺骗基于 AI 的垃圾邮件检测器的轻微光学差异 。

不过，对于许多没有跟上最新徽标更改的人来说，这些略有更改的徽标看起来已经足够好了，因此交付成功和用户参与率更有可能保持高位。

你有假语音信箱

所有三种欺骗类型都伪装成语音邮件通知，其中包含一个嵌入的“播放”按钮，单击该按钮后，会将用户带到一个看起来像 Verizon 网站的网络钓鱼门户。

登陆域名显然不是Verizon官方网站空间的一部分，报告中给出的一个例子是sd9-08[.]click。

演员打赌目标是粗心大意，否则，欺骗网站看起来很有说服力。此外，Inky 发现此网络钓鱼活动依赖于未报告的最近注册的域。

克隆站点上的徽标是真正的徽标，因为网络钓鱼者从真实的 Verizon 站点中窃取了大部分 HTML 和 CSS 元素。

在虚假页面上向下滚动，访问者将找到所谓的语音邮件，但只有在登录表单上提供其 Office365 帐户凭据时，才允许他们访问它。

第一次尝试将导致收到“密码不正确”消息，而第二次尝试会产生结束登录过程的虚假错误。

网络钓鱼者这样做是为了确保受害者在第一次尝试时没有输错密码，因此它本质上是一个“质量保证”步骤。

当您收到此类电子邮件时，适当的审查是避免成为这些骗局受害者的重要因素。切勿单击嵌入式按钮，始终验证您将要输入任何凭据的站点的 URL，最后，考虑情况的现实性。

在这种情况下，来自 Verizon 的消息敦促收件人输入他们的 Office365 凭据，这在这种情况下没有意义。如果电子邮件的内容无论出于何种原因都没有意义，通常是网络钓鱼，该电子邮件应该被丢弃。
