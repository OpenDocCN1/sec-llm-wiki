# LibreOffice漏洞可让黑客伪造文档签名

LibreOffice 和 OpenOffice 已推送更新以解决一个漏洞，该漏洞使攻击者有可能操纵文档显示为由可信来源签名。 

尽管缺陷的严重性被归类为中等，但其影响可能是可怕的。文档宏中使用的数字签名旨在帮助用户验证文档未被更改并且可以信任。 

“允许任何人自己签署带有宏的文档，并使它们看起来值得信赖，是诱使用户运行恶意代码的极好方法。

该漏洞被追踪为 OpenOffice 的CVE-2021-41832，是波鸿鲁尔大学四名研究人员的工作。 

同样的缺陷影响了 LibreOffice，它是十多年前从主项目衍生出来的 OpenOffice 的一个分支，并且他们的项目被跟踪为 CVE-2021-25635。 

## 应对风险

如果您正在使用任一开源办公套件，建议您立即升级到最新的可用版本。对于 OpenOffice，这将是 4.1.10 及更高版本，对于 LibreOffice，将是 7.0.5 或 7.1.1 及更高版本。 

由于这两个应用程序均不提供自动更新，您应该通过从各自的下载中心下载最新版本手动更新 - LibreOffice、  OpenOffice。 

如果您使用的是 Linux 并且上述版本在您的发行版的包管理器中尚不可用，建议您从下载中心下载“deb”或“rpm”包，或者从源代码构建 LibreOffice。 

如果由于任何原因无法更新到最新版本，您始终可以选择完全禁用办公套件上的宏功能，或避免信任任何包含宏的文档。 

要在 LibreOffice 上设置宏安全性，请转至工具 → 选项 → LibreOffice → 安全性，然后单击“宏安全性”。 

![](../Images/c8bbb4907db5233bf76a0bbee539f03d.png)

用于禁用宏的 LibreOffice 设置菜单

在新对话框中，您可以在四个不同的安全级别中进行选择，推荐选项为“高”或“非常高”。 

如果您仍在运行旧的易受攻击的版本，则不应依赖“受信任列表”功能，因为无效的签名算法仍可能使带有花边的文档看起来像是来自受信任的来源。
