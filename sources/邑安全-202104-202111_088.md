# 研究人员通过百度广告发现针对Mac用户的恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247507908&idx=2&sn=16a10fd285497ce182fbf6fa94cce807&chksm=fa3a9f1ecd4d1608cc282bf227243f632d3ada1ef0b6555846b7065494588f555b0a9caf448e&scene=126&sessionid=1681375683#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247507908&idx=2&sn=16a10fd285497ce182fbf6fa94cce807&chksm=fa3a9f1ecd4d1608cc282bf227243f632d3ada1ef0b6555846b7065494588f555b0a9caf448e&scene=126&sessionid=1681375683#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/807e7e955c1162c248c686fce76e417d.png)

一张百度搜索结果的照片，展示了指向钓鱼网站的广告（来源：知乎）  

中国安全研究员zhi发现了一种针对 Mac 用户的恶意软件，该恶意软件通过搜索引擎百度上的付费广告进行传播，以获取用户凭据。目前该广告已被撤下。

志说，当用户查询包含关键字“iTerm2”时，赞助商链接会出现在中文搜索引擎上，将用户引导至网络钓鱼网站。他说，然后会提示用户下载 iTerm2 应用程序，这实际上是伪装成 macOS 终端模拟器的恶意软件。

为 macOS 开发安全工具的帕特里克·沃德尔( Patrick Wardle)表示，百度的安全团队现已撤下赞助链接，而苹果已经撤销了恶意软件使用的代码签名证书。

百度和苹果没有立即回应信息安全媒体集团的置评请求。

根据Thomas Reed的博客文章，iTerm2 的受欢迎程度多年来一直在增长 - 特别是在开发人员和安全研究人员中 - 使其成为“木马化和感染可能访问开发系统，研究情报等的人的理想应用程序” ，网络安全公司 Malwarebytes 的 Mac 专家。

里德说，使用中文可能意味着恶意软件针对中国和其他东南亚国家，并补充说很难确认，因为“Malwarebytes 在该地区的安装基础相对较小”。

### **赞助广告诱饵**

9 月 8 日，他在百度上搜索 iTerm2 时首次观察到恶意广告链接。与搜索查询相关的赞助广告通常显示在搜索结果页面的顶部，然后是自然搜索结果。智说，这里的情况也不例外——百度在搜索结果页面的顶部显示了恶意广告链接。

他说，恶意链接使用域名 iTerm2\[.\]net 进行伪装，类似于最初的 iTerm2\[.\]com。“恶意站点伪装成合法站点这一事实并不令人意外，因为恶意软件的攻击媒介基于简单的诡计，”Wardle 说。

在钓鱼网站上点击下载选项后，从域 kaidingle\[.\]com 下载了一个 iTerm2.dmg 磁盘映像，Zhi 称之为“真正有毒的文件”。

Malwarebytes 的 Reed 说，这个磁盘映像应该是第一个危险信号。他补充说，真正的 iTerm2 以 zip 文件的形式分发。

“对于一个网站设计非常专业的app来说，磁盘镜像文件相当粗糙，还包含了一个中文名的应用程序文件夹的链接，这对于只有英文且不包含任何中文的app来说是不寻常的本地化文件，”里德说。

志的安全软件阻止了该文件的进一步执行，他说这提醒他可能存在恶意软件。越过安全块，他发现恶意软件连接到 47.75.123\[.\]111 地址，并在该地址执行名为 g\[.\]py 的文件。执行后，“\[来自用户机器\]的各种信息被收集并上传到与阿里云相关的服务器，”他说。

但志说，他的“能力有限”使他无法准确确认恶意软件代码在 \[.\]dmg 文件中的位置。

### **技术分析**

Wardle按照Zhi的步骤，发现下载的图像文件中的假iTerm应用程序是由某君碧（AQPZ6F3ASY）签名的，其代码签名证书现已被苹果公司吊销。他说，证书没有经过公证，这意味着苹果没有检查它是否存在恶意组件。

Wardle 补充说，合法的 iTerm2 应用程序由 George Nachman 签署并经过充分公证。

研究人员随后分析了文件，例如 iTerm2 应用程序合法和恶意版本的几个 Mach-O 二进制文件。他说他发现唯一的区别是一个名为 libcrypto\[.\]2\[.\]dylib 的文件，它在执行时连接到 47.75.123\[.\]111 地址，从那里下载了恶意 Python 文件和一个 mach-O 二进制文件.

Wardle 说，当时，这个 dylib 文件没有被反病毒引擎标记为恶意文件。他在 VirusTotal 上测试了签名，VirusTotal 是一个防病毒搜索引擎，可以检查多个防病毒软件中的签名。

分析 g\[.\]py 文件和名为 GoogleUpdate 的 mach-O 二进制文件，Wardle 说他发现前者是一个加载恶意软件的 Python 文件，二进制文件与 47\[.\]75\[.\]75\[ 上的 Cobalt Strike 服务器建立联系。.\]96\[.\]198\[:\]443。

Wardle 说他发现 Python 代码从受害者的计算机中窃取了重要信息，包括机器序列号、文档和文件夹、SSH 凭据、可能包含其他个人帐户凭据的受害者钥匙串，以及 SecureCRT 和 iTerm2 的配置文件，这些信息是两个终端模拟器程序。

“g\[.\]py 脚本的主要目标似乎是获取可用于组织内横向移动的凭据和其他数据。据推测，谷歌更新过程提供的后门将用于执行横向移动移动并感染其他机器，”里德说。

### **其他发现**

在研究期间，Wardle 说他发现 Microsoft 远程桌面 (com.microsoft.rdc.macos)、Secure CRT (SecureCRT.dmg) 和 Navicat Premium (Navicat15\_cn.dmg) 也使用相同的 libcrypto\[.\]2\[ 进行了木马化处理。\]dylib 文件。

知乎论坛上的一位用户说，百度的安全团队最初发布了一篇\[事件\]分析文章，但在同一天将其删除。另一位用户声称，发布赞助商链接的促销帐户的所有者以鸡西黑沃生态农业科技有限公司的名义注册。

虽然研究人员没有为此类恶意软件活动提供具体的补救措施，但知乎论坛用户建议使用广告拦截插件来拦截赞助广告和内容。
