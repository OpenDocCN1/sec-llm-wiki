## Zoho 敦促客户解决其 ManageEngine ADSelfService Plus 中的身份验证绕过漏洞，该漏洞被广泛利用。

Zoho 发布了一个安全补丁，以解决其 ManageEngine ADSelfService Plus 中的身份验证绕过漏洞，编号为 CVE-2021-40539。该公司还警告说，该漏洞已经在野外攻击中被利用。该漏洞存在于 ADSelfService Plus 的 REST API URL 中，可能导致远程代码执行 (RCE)。“我们已经解决了影响 ADSelfService Plus 中 REST API URL 的身份验证绕过漏洞。本文提供了有关该问题及其解决方法的更多信息。” 读咨询公司公布。“此漏洞允许攻击者通过发送特制请求，通过 REST API 端点获得对产品的未授权访问。这将允许攻击者进行后续攻击，导致 RCE。”“这是一个关键问题。我们注意到该漏洞被利用的迹象，”Zoho 补充道。该缺陷影响 ADSelfService Plus 6113 版本和之前的版本，该缺陷已在版本 6114 或更高版本中得到解决。为了确定安装是否存在漏洞，可以检查\\ManageEngine\\ADSelfService Plus\\logs 文件夹中可用的访问日志条目中是否存在以下字符串 ：

*   
*   

```
/RestAPI/登录自定义/RestAPI/连接
```

美国 CISA 还发布了关于 CVE-2021-40539 漏洞的安全公告。“Zoho 已针对影响 ManageEngine ADSelfService Plus 版本 6113 及更低版本的漏洞 (CVE-2021-40539) 发布了安全更新。已在野外攻击中检测到 CVE-2021-40539。远程攻击者可以利用此漏洞来控制受影响的系统。ManageEngine ADSelfService Plus 是适用于 Active Directory 和云应用程序的自助式密码管理和单点登录解决方案。” 阅读 CISA 的建议“此外，CISA 强烈敦促组织确保 ADSelfService Plus 不能直接从 Internet 访问。”
