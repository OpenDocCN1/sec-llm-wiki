# 美国海军发明了一种阻止人们说话的装置

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247507477&idx=4&sn=e61e16119b266e366217cd3b1cd0592a&chksm=fa3a9ecfcd4d17d904b56761d405d41e11bf5dfcc294eff2650aa91b349a7139ffca4e21d09a&scene=126&sessionid=1681375688#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247507477&idx=4&sn=e61e16119b266e366217cd3b1cd0592a&chksm=fa3a9ecfcd4d17d904b56761d405d41e11bf5dfcc294eff2650aa91b349a7139ffca4e21d09a&scene=126&sessionid=1681375688#rd)

美国海军发明了一种防止人们说话的新装置，这种手持式声学呼唤和干扰装置记录了一个人的讲话，并在几毫秒后将其再次播放出来，扰乱了他们的注意力，使他们不敢继续讲话。虽然这是一个有趣的、非常熟悉的概念，但这种技术不太可能在战场上使用。

手持式声学呼唤和干扰（AHAD）是由海军水面作战部Crane分部的工程师开发的，该分部是位于印第安纳州的海军研究和开发机构。据《新科学家》报道，这项专利是在2019年发布的，但今年才被发现。据公开的专利内容显示，目标人物的讲话被重复播放两次，一次是立即，一次是在短暂延迟后播放。

![](../Images/814afaddd7a6a01ef886f0e6760c6e23.png)

这种延迟产生了延迟听觉反馈（DAF），它改变了说话者对自己声音的正常感知。在正常的讲话中，讲话者听到自己的话语会有轻微的延迟，而且身体也习惯了这种反馈。通过引入另一个具有足够长延迟的音频反馈源，说话者的注意力被打乱，很难继续说话。

据称，使用该系统的政府机构可能用它来关闭暴乱或其他非法集会。专利内容显示，通过利用定向麦克风和扬声器，只有目标说话人的声音才能被系统接收到，而且只有目标说话人才能听到传输的音频。一个被AHAD锁定的人可能会被这项技术惊呆了，并对他们周围的人都听不到他们的声音而感到困惑。他们周围的人可能同样感到困惑的是，这个人似乎毫无理由地停止了说话。换句话说，它可以让你觉得自己是个疯子，并让你周围的人觉得你是个疯子。

![](../Images/9030bfcdfe3780e6f579a2f40362bf72.png)

如果机器重复的语音比说话人的语速慢一个音节，这种干扰技术效果最好。奇怪的是，它对一些人完全不起作用，实际上，它使另外一些人的演讲能力更强。这种效果并不稳定，不足以使这项技术在实验室之外值得继续研究。该技术还有一些其他应用。它可以被用作常规的声学呼唤装置，也许可以向另一艘船发出指令或启动对话。更耐人寻味的是，通过将AHAD系统对准墙壁或角落，AHAD系统还可以将声音投射到目标表面，使音频看起来来自于目标。

AHAD属于非致命性武器系统的范畴，这种武器旨在达到预期的效果而不造成永久性的损害。美国海军已经部署了其他非致命性声波武器，包括长距离声学装置，它能以非常高的分贝水平发射聚焦声波，造成疼痛。这种疼痛使人们逃离一个地区，并可能产生挥之不去的身体影响，包括偏头痛和耳鸣，时间长达一周。
