# 全新SideWalk后门攻击针对电脑零售业务

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247507191&idx=2&sn=b87fb755a9d0b409cc1bd150cda1728a&chksm=fa3a9c2dcd4d153b5567ebe9e6f28ed792b75ba432c17f82ddb3efd554f1445d6614642b2afa&scene=126&sessionid=1681375698#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247507191&idx=2&sn=b87fb755a9d0b409cc1bd150cda1728a&chksm=fa3a9c2dcd4d153b5567ebe9e6f28ed792b75ba432c17f82ddb3efd554f1445d6614642b2afa&scene=126&sessionid=1681375698#rd)

更多全球网络安全资讯尽在邑安全

一家电脑零售公司成为SideWalk攻击的目标，这种攻击以前从未被发现，是一个高级黑客组织最近开展的活动一部分，该组织主要以专门针对东亚和东南亚实体的网络攻击而闻名。

斯洛伐克网络安全公司ESET在持续跟踪名为SparklingGoblin的高级威胁过程当中发现了这个攻击，被认为与Winnti umbrella组织有关，并指出其与另一个被称为Crosswalk的后门相似，后者在2019年被同一黑客组织使用。

![](../Images/eb79ad92c689973d3d5c3dbde306510a.png)

SideWalk是一个模块化的后门，可以动态加载从其C&C命令和控制服务器发送的附加模块，利用Google Docs作为死循环解析器，以及Cloudflare作为C&C服务器，它还可以适当处理代理背后的通信。自2019年首次出现以来，SparklingGoblin与几个针对香港大学的攻击有关，使用Spyder和ShadowPad等后门，后者近年来已成为多个黑客集团的首选恶意软件。

在过去的一年里，这些集团袭击了世界各地的广泛组织和垂直行业，特别是位于巴林、加拿大、格鲁吉亚、印度、澳门、新加坡、韩国、台湾和美国的学术机构，其他目标实体包括媒体公司、宗教组织、电子商务平台、计算机和电子产品制造商以及地方政府。

SideWalk被描述为一个加密的壳代码，它通过一个.NET加载器部署，该加载器负责从磁盘上读取加密的壳代码，对其进行解密，并使用进程空心化技术将其注入合法进程。感染的下一阶段是SideWalk与C&C服务器建立通信，恶意软件从Google Docs文档中检索加密的IP地址。

除了使用HTTPS协议进行C&C通信外，SideWalk还被设计为加载从服务器发送的任意插件，积累有关运行进程的信息，并将结果外泄回远程服务器。SideWalk是SparklingGoblin APT组织使用的一个以前没有记录的后门。它很可能是由CROSSWALK背后的相同开发者制作的，它与CROSSWALK共享许多设计结构和实施细节。
