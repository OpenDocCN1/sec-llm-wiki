# 网络钓鱼活动使用 UPS.com XSS 漏洞来分发恶意软件

一个巧妙的 UPS 网络钓鱼活动利用 UPS.com 中的 XSS 漏洞来推送虚假和恶意的“发票”Word 文档。  

网络钓鱼骗局首先由安全研究人员Daniel Gallagher发现，  并假装是 UPS 发送的一封电子邮件，说明包裹有“异常”，需要由客户取走。

此次网络钓鱼攻击的突出之处在于，攻击者利用 UPS.com 中的 XSS 漏洞将站点的常规页面修改为合法下载页面。

此漏洞允许威胁行为者通过远程 Cloudflare 工作人员分发恶意文档，但使其看起来像是直接从 UPS.com 下载的。

## 剖析 UPS 网络钓鱼骗局

这封电子邮件充满了许多没有恶意行为的合法链接。但是，跟踪号是 UPS 网站的链接，其中包含一个 XSS 漏洞的利用，该漏洞在打开页面时将恶意 JavaScript 注入浏览器。

XSS漏洞注入的Cloudflare worker脚本会导致UPS网站显示下载页面，如下图。

  

![](../Images/d6bcebae40c93bc1b2734e84220d5bc9.png)

最终，该页面将从攻击者的 Cloudflare 项目中下载恶意 Word 文档 \[ VirusTotal \]。

这种网络钓鱼活动非常聪明，因为访问 URL 的用户会看到一个合法的 ups.com URL，提示下载发票。

这种策略可能会导致受害者打开发票而不那么怀疑，认为它是来自 UPS 的真实文件。

UPS.com XSS 漏洞已经根据 BleepingComputer 的测试得到修复。

BleepingComputer 已就此次攻击的问题联系 UPS，但目前尚未收到回复。

## 神秘的假“发票”文件

下载的文件名为“invoice\_1Z7301XR1412220178”，伪装成 UPS 的发货发票。

打开文档时，所有文本都将无法读取，并且文档会提示用户“启用内容”以正确查看它。

  

![](../Images/16eefcd9a46782e98649c471f3456a81.png)

恶意发票word文档

启用后，宏将尝试下载文件 https://divine-bar-3d75.visual-candy.workers.dev/blackhole.png。 

但是，此 URL 不再有效，因此无法查看有效负载。

![](../Images/0844bee7570083eb78387c342adbdbe6.png)

  

伪造的 UPS 发票中的宏 

这种网络钓鱼骗局说明了威胁行为者用来令人信服地分发恶意文件的创造性和不断发展的技术。

虽然电子邮件发件人清楚地显示了可疑域，但由于 XSS 漏洞允许 URL 和下载页面从 UPS 合法出现，许多人会陷入这种骗局。
