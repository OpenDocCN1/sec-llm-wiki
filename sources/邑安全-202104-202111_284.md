# 普京采用“非对称”战术 预示美国将遭受更多黑客攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247505372&idx=2&sn=a7d87f90d9915772bf3efb5af5bcb0fb&chksm=fa3a9506cd4d1c10f18766a59af35664c8dee9bd4a7ff582fc34846b283b98853b2fc5ef29a7&scene=126&sessionid=1681375734#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247505372&idx=2&sn=a7d87f90d9915772bf3efb5af5bcb0fb&chksm=fa3a9506cd4d1c10f18766a59af35664c8dee9bd4a7ff582fc34846b283b98853b2fc5ef29a7&scene=126&sessionid=1681375734#rd)

更多全球网络安全资讯尽在邑安全

美国总统拜登称，他在上月于日内瓦会晤俄罗斯总统普京时表达了需要阻止网络攻击的强硬信息。普京表示他完全同意。但据报道，不到一个月后，俄罗斯军事情报部门的黑客就入侵了美国共和党全国委员会的计算机系统。

![](../Images/6f2b4dd16f0d2ab76fc199dfb7281d8d.png)

克里姆林宫像过去一样否认参与了这次攻击，但这丝毫没有减轻批评人士对拜登修复与俄罗斯关系的批评。

前官员和分析人士称，网络武器只是俄罗斯在日益激烈的美俄对峙中使用的工具之一，首脑会晤上的热情对话不足以改变这种状况。

“黑客攻击是莫斯科可以部署的最简单的工具，”在普京上任头十年任克里姆林宫政治顾问的Gleb Pavlovsky表示。虽然破坏计算机安全的复杂操作需要时间来准备，“但可以事先做好准备，只待合适时机的行动命令。”

普京在6月30日指责美国在英国向黑海水域派驱逐舰HMS Defender的决定中发挥了作用。

“这次挑衅是全面的，不仅来自英国人，还有美国人，”普京在国家电视台上表示。

Pavlovsky称黑客攻击可能是一种报复。

就在上周，普京签署了一项新的国家安全战略，呼吁使用“非对称”战术来应对其他国家的“不友好行动”。今年早些时候俄罗斯通过的一部法律已将美国列为不友好国家。
