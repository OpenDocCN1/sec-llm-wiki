Linux Pling Store 应用程序中未修补的漏洞可能导致供应链攻击

更多全球网络安全资讯尽在邑安全

网络安全研究人员披露了一个影响 Linux 平台基于 Pling 的免费和开源软件 (FOSS) 市场的未修补的关键漏洞，该漏洞可能被滥用以进行供应链攻击并实现远程代码执行 (RCE)。

Positive Security 联合创始人 Fabian Bräunlein在今天发表的一篇技术文章中说： “基于 Pling 平台的 Linux 市场容易受到可蠕虫的 [跨站点脚本] 的攻击，有可能受到供应链攻击。” “本机 PlingStore 应用程序受到 RCE 漏洞的影响，该漏洞可以在应用程序运行时从任何网站触发。”

受该漏洞影响的基于 Pling 的应用商店包括——

appimagehub.comstore.kde.orggnome-look.orgxfce-look.orgpling.com

PlingStore 允许用户搜索和安装 Linux 软件、主题、图标和其他可能无法通过发行版软件中心下载的附加组件。

该漏洞源于商店的产品列表页面解析 HTML 或嵌入媒体字段的方式，从而可能允许攻击者注入恶意 JavaScript 代码，从而导致任意代码执行。

“这种存储的 XSS可用于修改活动列表，或在其他用户的上下文中在 Pling 商店上发布新列表，从而导致可蠕虫的 XSS，”Bräunlein 说。

更令人不安的是，这可能会导致供应链攻击 XSS 蠕虫，攻击者可以利用其中的 JavaScript 负载上传木马化版本的软件并调整受害者列表的元数据以包含和传播攻击代码。

由于 PlingStore 应用程序充当所有上述应用程序商店的单一数字店面，Positive Security 指出，XSS 漏洞可以从应用程序内部触发，当与沙箱绕过结合使用时，可能会导致远程代码执行。

“由于应用程序可以安装其他应用程序，它具有另一种内置机制来在 [操作系统] 级别执行代码，”Bräunlein 解释说。“事实证明，当 PlingStore 应用程序在后台打开时，任何网站都可以利用这种机制来运行任意本机代码。”

换句话说，当用户通过浏览器访问恶意网站时，Pling 应用程序在后台运行时会在其内部触发 XSS。网站中的 JavaScript 代码不仅可以与本地 WebSocket 服务器建立连接，用于侦听来自应用程序的消息，还可以通过下载和执行 .AppImage 包文件使用它来发送消息以执行任意本机代码。

更重要的是，在GNOME Shell 扩展市场中发现的一个类似的 XSS 缺陷可以通过向 Gnome Shell 集成浏览器扩展甚至后门发布的扩展发出恶意命令来攻击受害者的计算机。

这家总部位于柏林的网络安全公司指出，这些漏洞已于 2 月 24 日报告给各自的项目维护者，KDE 项目和 GNOME 安全公司在披露后针对这些问题发布了补丁。鉴于与 PlingStore 相关的 RCE 缺陷仍未解决这一事实，建议在修复到位之前不要运行 Electron 应用程序。

该报告是在几个流行的 Visual Studio Code 扩展中发现严重安全漏洞后不到一个月发布的，这些漏洞可能使攻击者能够通过开发人员的集成开发环境破坏本地计算机以及构建和部署系统，最终为供应链铺平道路攻击。

“[缺陷] 表明与此类市场相关的额外风险，”Bräunlein 说。“在这种环境下，即使是相对较小的漏洞（例如缺少来源检查）也可能导致严重后果（来自任何浏览器的 RCE，易受攻击的应用程序在后台运行）。此类应用程序的开发人员必须进行高度审查以确保他们的安全。”
