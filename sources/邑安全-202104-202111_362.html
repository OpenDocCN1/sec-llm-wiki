PuzzleMaker 黑客使用 Chrome 零日漏洞攻击 Windows 10

更多全球网络安全资讯尽在邑安全

卡巴斯基安全研究人员发现了一个名为PuzzleMaker的新威胁 参与者，该参与者 使用了一系列 Google Chrome 和 Windows 10 零日漏洞，对全球多家公司进行了针对性强的攻击。

据卡巴斯基称，由 PuzzleMaker 协调的攻击最早是在 4 月中旬发现的，当时第一批受害者的网络遭到破坏。

活动中部署的零日漏洞利用链利用 Google Chrome V8 JavaScript 引擎中的远程代码执行漏洞访问目标系统。

接下来，PuzzleMaker 威胁者利用定制的提权漏洞利用 Windows 内核中的信息泄露漏洞 ( CVE-2021-31955 ) 和 Windows NTFS 提权漏洞 ( CVE-2021 )危害最新的 Windows 10 版本-31956），两者都在六月补丁星期二中进行了修补。

使用系统权限部署的恶意软件

攻击者滥用 Windows 通知工具 (WNF) 和 CVE-2021-31956 漏洞，在受感染的 Windows 10 系统上执行具有系统权限的恶意软件模块。

“一旦攻击者都用了在Chrome和Windows利用在目标系统中站稳脚跟，在驿站模块下载和从远程服务器上执行更复杂的恶意软件滴管，”研究人员说。

“然后这个 dropper 会安装两个可执行文件，它们伪装成属于 Microsoft Windows 操作系统的合法文件。

“这两个可执行文件中的第二个是远程 shell 模块，它能够下载和上传文件、创建进程、休眠特定时间段以及从受感染的系统中删除自身。”

Chrome 和 Windows 零日漏洞

这不是近几个月来第一个在野外使用的 Chrome 零日漏洞利用链。

Google 的零日漏洞搜寻团队 Project Zero 公布了一项大规模行动， 一群黑客 在一年内使用 11 个零日漏洞攻击 Windows、iOS 和 Android 用户。

这些攻击发生在 2020 年 2 月和 10 月的两个独立活动中，至少有十几个网站托管了两个漏洞利用服务器，每个服务器都针对 iOS 和 Windows 或 Android 用户。

零项目研究人员从两个活动中使用的漏洞利用服务器收集了大量信息，包括：

  • 渲染器利用 Chrome 中的四个错误，其中一个在发现时仍为 0-day

  • 两个沙箱逃逸漏洞利用 Windows 中的三个 0day 漏洞

  • 一个“权限提升工具包”，由针对旧版 Android 的公开已知 n 天漏洞利用组成

  • 一个完整的漏洞利用链，目标是使用 Google Chrome 完全修补的 Windows 10

  • 两个部分链针对使用 Google Chrome 和三星浏览器运行 Android 10 的 2 个不同的完全修补的 Android 设备

  • 针对 iOS 11-13 的多个 RCE 漏洞和针对 iOS 13 的权限提升漏洞（利用漏洞一直存在到 iOS 14.1）

全球研究与分析团队 (GReAT) 的高级安全研究员鲍里斯·拉林 (Boris Larin) 补充说：“总的来说，最近，我们看到了几波由零日漏洞利用驱动的备受瞩目的威胁活动。”

“这提醒我们，零日仍然是感染目标的最有效方法。”

包括恶意软件样本哈希在内的入侵指标 (IOC) 可以在卡巴斯基报告的末尾找到。
