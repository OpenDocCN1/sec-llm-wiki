# FreakOut 蠕虫正在感染易受攻击的 VMware 服务器

一种针对 Windows 和 Linux 设备的基于 Python 的多平台恶意软件现已升级，可以通过蠕虫侵入未针对远程代码执行漏洞修补的暴露在互联网上的 VMware vCenter 服务器。

该恶意软件于 1 月被 CheckPoint 研究人员命名为FreakOut（又名 Necro 和 N3Cr0m0rPh），是一种经过混淆的 Python 脚本，旨在使用多态引擎和用户模式 rootkit 来逃避检测，该脚本可以隐藏在受感染系统上放置的恶意文件。

FreakOut 通过利用广泛的操作系统和应用程序漏洞以及通过 SSH 暴力破解密码来自我传播，将受感染的设备添加到由其主人控制的 IRC 僵尸网络。

该恶意软件的核心功能使运营商能够发起 DDoS 攻击、感染后门的系统、嗅探和窃取网络流量，并部署 XMRig 矿工来挖掘 Monero 加密货币。

## 使用新漏洞升级的恶意软件

正如 Cisco Talos 研究人员在今天发布的一份报告中所分享的那样，自 5 月初僵尸网络的活动突然增加以来，FreakOut 的开发人员一直在努力提高恶意软件的传播能力。

“尽管该机器人最初是在今年早些时候发现的，但最新活动显示该机器人发生了许多变化，包括不同的命令和控制 (C2) 通信以及增加了用于传播的新漏洞，最显着的是 VMWare vSphere、SCO OpenServer 中的漏洞、 Vesta 控制面板和基于 SMB 的漏洞在代码的早期迭代中不存在，”思科 Talos 安全研究员 Vanja Svajcer 说。

FreakOut 机器人通过随机生成网络范围或通过命令和控制服务器通过 IRC 发送的主机命令来扫描新系统以作为目标。

对于扫描列表中的每个 IP 地址，机器人将尝试使用其中一个内置漏洞或使用硬编码的 SSH 凭据列表登录。

数以千计的 VMware 服务器暴露在攻击之下  

VMware vCenter 漏洞 (CVE-2021-21972) 存在于 vRealize Operations (vROps) 的 vCenter 插件中，并且特别有趣，因为它会影响所有默认的 vCenter Server 安装。

如Shodan和BinaryEdge所示，目前可以通过 Internet 访问数千个未打补丁的 vCenter 服务器。

在安全研究人员发布概念验证 (PoC) 漏洞利用代码后，攻击者此前曾大规模扫描暴露在互联网上的易受攻击的 vCenter 服务器。

俄罗斯外国情报局 (SVR) 国家黑客也在2 月份将 CVE-2021-21972 漏洞利用添加到他们的武器库中，并在正在进行的活动中积极利用它们。

过去，针对企业网络的勒索软件攻击也曾利用 VMware 漏洞。正如 Cisco Talos 透露的那样，还看到 FreakOut 运营商部署了自定义勒索软件菌株，这表明他们正在积极试验新的恶意负载。

多个勒索软件团伙，包括 RansomExx、Babuk Locker 和 Darkside，以前使用 VMWare ESXi 预身份验证 RCE 漏洞来加密用作集中企业存储空间的虚拟硬盘。

“Necro Python bot 展示了一个跟踪各种 Web 应用程序上远程命令执行漏洞的最新发展的参与者，并将新漏洞包含在 bot 中。这增加了其传播和感染系统的机会，”Svajcer 补充道。

“用户需要确保定期将最新的安全更新应用于所有应用程序，而不仅仅是操作系统。”
