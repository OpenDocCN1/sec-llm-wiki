# 勒索软件爆炸式增长 去年价值超4亿美元加密货币用于支付赎金

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247503351&idx=2&sn=29c8d3bc9d7848ffb9bd915361a32057&chksm=fa3a8d2dcd4d043b1c55ec18df04e3b7477873629d2afcce84d58e6ce0b34ba5a89eac905649&scene=126&sessionid=1681375780#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247503351&idx=2&sn=29c8d3bc9d7848ffb9bd915361a32057&chksm=fa3a8d2dcd4d043b1c55ec18df04e3b7477873629d2afcce84d58e6ce0b34ba5a89eac905649&scene=126&sessionid=1681375780#rd)

更多全球网络安全资讯尽在邑安全

由于加密货币的隐匿性，导致其成为各种违法行为的主要交易途径。而随着勒索软件的爆炸式增长，去年加密货币用于支付赎金的金额也创造了新纪录。据媒体报道，来自区块链数据公司Chainalysis的数据显示，2020年勒索软件的攻击者至少收到了价值超过4亿美元赎金，是2019年的三倍还多。

![](../Images/104e3ef764fb5d95cc2c3c63d749ce4b.png)

近日，黑客组织“黑暗面”（DarkSide ransomware group）攻击了美国科洛尼尔管道运输公司一度引起全球关注，最终该公司以加密货币的方式，向黑客支付了近500万美元的巨额赎金，获得了解密工具。

当然，这只是众多黑客组织勒索行为的一个案例，几乎全球每天都有黑客组织利用勒索软件不断攻击企业以及个人，成功后要求以加密货币形式交付赎金。

Chainalysis表示，2020年是勒索软件爆炸式增长的一年，而加密货币用于支付的金额也创造了新的纪录，是2019年（92.94亿美元）的三倍还多。

来自区块链数据公司Chainalysis的最新数据显示，通过进一步对相关勒索软件进行统计后发现，2020年，勒索软件的受害者向攻击者支付了至少4.06亿美元（约合人民币26亿元）。

2021年，黑客组织靠勒索软件同样收入不菲。据不完全统计，在今年的前五个月中，已经有超过8100万美元加密货币用于支付勒索软件的赎金。
