## 二、pdf

![](../Images/60becb788bba7b46251ce9a877cac75e.png)

发现是一张.pdf为后缀的图片

![](../Images/40246cff83bbccfc8242258742325d5d.png)

方法一：在线pdf转word：https://app.xunjiepdf.com/pdf2word/

然后移开图片得到flag

![](../Images/58a68910a9dff66c3dfdf1d7f8d05b45.png)

方法二：将pdf转为txt就看到flag（kali中，无网环境/比赛环境）

```




pdftotext ad00be3652ac4301a71dedd2708f78b8.pdf 1.txt
```

## 六、gif

![](../Images/b8afb18a525e9a20bedf77cb8df40277.png)

下载下来一个zip压缩包，104张黑白图片，像极了二进制的0和1，二进制转十六进制？八个一组，大概13个（一个字母一个字节，一个字节八位）

法一：

一个一个手动来（黑白为01或10）

![](../Images/132d29dccbbc63e1a822ab2f0fb5f638.png)

思考：八个一组，大概13个，二进制转ascii，第一组为f,那么为01100110，也就是说，白为0，黑为1

![](../Images/79936b55be9c9705bbfa9d4d88e9fd57.png)

flag为flag{FuN\_giF}

法二：脚本跑（借鉴大佬的脚本）

![](../Images/c2e8ca82093bb05077fbb519c2c1077d.png)

flag为flag{FuN\_giF}

## 十、SimpleRAR

![](../Images/cde9c2c929f1564f611b4c5e47ccf2d9.png)

![](../Images/387be09a01a698c44152a28f8298a228.png)

## 十一、base64stego

![](../Images/a7a7e0df0961c98c71d83797a005ea45.png)

下载下来，表面看起来无法解密

搜索50 4B 01 02 ，把第九位，第十位改为0。保存，成功解压出stego.txt。

![](../Images/1cf470494284bb5bd0c18946545e1bf2.png)

```












# -*- coding: cp936 -*-
```

得到flag{Base\_sixty\_four\_point\_five}

## 十二、功夫再高也怕菜刀

![](../Images/956a5f343f12bd07edb20cf468f2f69f.png)

下载下来是一个wireshark的pcapng文件

使用wireshark打开流量包，查找flag，选择第1150个，右键，追踪流 -> TCP 流

![](../Images/98071de87db7193b018d52289635761b.png)

从 FFD8FF 开始到 FFD9 复制出来，保存为jpg格式，打开图片

```
flag{Th1s\_1s\_p4sswd\_!!!}
```
