# 威联通（Q NAP）删除NAS备份，灾难恢复应用程序中的后门帐户

QNAP确认Qlocker勒索软件已使用已删除的后门帐户入侵某些客户的NAS设备并对其文件进行加密。由于该漏洞，似乎有许多用户受到勒索软件（QLocker）的影响。请尽快更新您的HBS3版本

QNAP解决了一个严重漏洞，攻击者可以使用硬编码凭据来登录QNAP NAS（网络连接存储）设备。

总部位于台湾的ZUSO ART在 公司的灾难恢复和数据备份解决方案HBS 3 Hybrid Backup Sync中发现了跟踪为CVE-2021-28799的硬编码凭据漏洞。 

该公司表示，以下HBS版本已修复了该安全漏洞，并建议客户将软件更新为最新发布的版本：

*   QTS 4.5.2：HBS 3 Hybrid Backup Sync 16.0.0415及更高版本
    
*   QTS 4.3.6：HBS 3混合备份同步3.0.210412和更高版本
    
*   QuTS英雄h4.5.1：HBS 3 Hybrid Backup Sync 16.0.0419及更高版本
    
*   QuTScloud c4.5.1〜c4.5.4：HBS 3 Hybrid Backup Sync 16.0.0419及更高版本
    

要在NAS设备上更新HBS，您必须以管理员身份登录QTS或QuTS hero。接下来，在App Center中搜索“ HBS 3 Hybrid Backup Sync”  ，然后单击“更新”和“确定”以更新应用程序（如果HBS已经是最新的，则“更新”选项不可用。）

威联通（QNAP）发布了安全公告，宣布CVE-2021-28799已于今天修复，而该应用程序的版本16.0.0415的发行说明将其修正为将近一周前的4月16日。

QNAP发言人告诉BleepingComputer，披露延迟是由于释放QuTS hero和QuTScloud HBS版本补丁所需的额外时间（QTS的安全更新已于六天前发布）。

威联通（QNAP）还补充说，其PSIRT团队尚未找到在野外积极利用此漏洞的证据。

在同一天，QNAP修复了其他两个HBS命令注入漏洞，以及两个其他关键漏洞，即QTS和QuTS hero中的 命令注入错误 （CVE-2020-2509）以及多媒体控制台和媒体流中的 SQL注入漏洞。附加组件 （CVE-2020-36195），该组件可能使攻击者获得对NAS设备的完全访问权限。

## 针对QNAP用户的持续Qlocker勒索软件活动

诸如此类的严重安全漏洞使威胁参与者可以接管NAS设备，在某些情况下，还可以部署勒索软件来加密用户的文件，并要求高额勒索以获取解密器。

据CISA称，威胁参与者还可以接管NAS设备，并使用它们“代理连接以与放置在这些设备上的Web外壳进行交互”，并将其恶意活动隐藏在常规的远程工作流量中。

QNAP告诉BleepingComputer，他们相信一种名为Qlocker的新型勒索软件利用SQL注入漏洞（CVE-2020-36195）对易受攻击的设备上的数据进行加密。

至少从4月19日开始，这就是发生的情况。当时，在大规模行动后， 攻击者 部署了一种名为Qlocker的新勒索软件，开始将QNAP客户的文件移至受密码保护的7zip档案中并要求勒索。

在过去的四天内，BleepingComputer的勒索软件支持论坛进行了大量活动，ID-Ransomware记录了受害者提交的Qlocker样本数量激增的情况。

## 勒索软件之前针对的QNAP设备

Qlocker并不是第一个针对QNAP设备的勒索软件，因为它们通常用于存储敏感的个人文件，并且是迫使受害者支付赎金以解密其数据的完美手段。

2020年6月，QNAP 警告有关 针对Photo Station应用程序安全漏洞的eCh0raix勒索软件攻击。 

一年后，eCh0raix（又名QNAPCrypt）返回，试图通过利用已知的漏洞和弱密码强行破解帐户来访问QNAP设备。

威联通（QNAP）还在2020年9月向客户发出了一次AgeLocker勒索软件活动，该活动  通过利用较旧且易受攻击的Photo Station版本来针对公开暴露的NAS设备。

建议QNAP客户执行以下步骤来保护其NAS设备并检查恶意软件：

*   更改设备上所有帐户的所有密码
    
*   从设备中删除未知的用户帐户
    
*   确保设备固件是最新的，并且所有应用程序也已更新
    
*   从设备中删除未知或未使用的应用程序
    
*   通过App Center功能安装QNAP MalwareRemover应用程序
    
*   设置设备的访问控制列表（控制面板->安全->安全级别）
