Qbot 恶意软件现在使用 Windows MSDT 零日攻击进行网络钓鱼攻击

更多全球网络安全资讯尽在邑安全


一个关键的 Windows 零日漏洞，称为 Follina，仍在等待微软的官方修复，现在正被积极利用在持续的网络钓鱼攻击中，以用 Qbot 恶意软件感染收件人。

Proofpoint 周一首次报道称，同样的零日漏洞被用于针对美国和欧盟政府机构的网络钓鱼。

上周，这家企业安全公司还透露，中国 TA413 黑客组织 正在利用该漏洞攻击针对西藏侨民的攻击。

正如 Proofpoint 安全研究人员今天分享的那样，TA570 Qbot 附属机构现在已经开始使用恶意的 Microsoft Office .docx 文档来滥用Follina CVE-2022-30190 安全漏洞并用 Qbot 感染收件人。

攻击者使用带有 HTML 附件的劫持电子邮件线程消息，这些消息将下载包含 IMG 文件的 ZIP 档案。在 IMG 中，目标将找到 DLL、Word 和快捷方式文件。

虽然快捷方式文件直接加载已经存在于 IMG 磁盘映像中的 Qbot DLL 文件，但空白的 .docx 文档将连接到外部服务器以加载利用 Follina 漏洞运行 PowerShell 代码的 HTML 文件，该代码下载并执行不同的Qbot DLL 有效载荷。

可以在此处找到恶意软件分析师 ExecuteMalware 与此活动相关的一系列危害指标。

此网络钓鱼活动中使用的策略与之前的报告相匹配，该报告描述了 TA570之前如何使用电子邮件线程劫持来推送恶意附件。

TA570 决定使用两种不同的方法来感染潜在受害者，这暗示了网络犯罪威胁参与者可能会开展 A/B 测试活动，以评估哪种策略可以为他们的“努力”带来最佳结果。

这是 Qbot 附属公司今年为数不多的尝试改变攻击方法的情况之一，首先是在 2 月份转向使用称为 Squumbledoo 的旧技巧，使用 regsvr32.exe 通过 Microsoft Office 文档传播恶意软件。

4 月，在 Microsoft 开始向 Office for Windows 用户推出 VBA 宏自动阻止功能后，攻击者停止使用带有恶意宏的 Microsoft Office 文档，并转而使用带有恶意 MSI Windows Installer 包的受密码保护的 ZIP 存档附件。

Qbot是什么？

Qbot（又名Qakbot、Quakbot和Pinkslipbot）是一种模块化的 Windows 银行木马，具有蠕虫功能，可通过网络共享漏洞和针对 Active Directory 管理员帐户的高度攻击性暴力攻击来感染受感染网络上的更多设备。

这种信息窃取恶意软件至少从 2007 年开始就被用来收集银行凭证、个人信息和财务数据，以及后门受感染的计算机和部署 Cobalt Strike 信标。

与多个勒索软件即服务 (RaaS) 操作（包括 REvil、PwndLocker、Egregor、ProLock和MegaCortex）相关联的勒索软件附属机构也使用 Qbot 对企业网络进行初始访问。

微软于 2021 年 12 月发布了一份关于Qbot 攻击的多功能性的报告，这使得准确评估其感染范围变得更加困难。

DFIR 报告最近还揭示了 Qbot 光速攻击，其中恶意软件能够在初始感染后大约 30 分钟内窃取敏感的用户数据（包括 Windows 凭据和电子邮件）。
