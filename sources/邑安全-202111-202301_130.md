# 报告显示公司CEO和其他企业高管也在使用过于简单的密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247514542&idx=1&sn=c6ecfbae5df279eef91e307f175efd85&chksm=fa3af974cd4d70623130c8e83789313d5b971a50da366d8736b32e2fb8be77a6ddb47af1ede6&scene=126&sessionid=1681375565#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247514542&idx=1&sn=c6ecfbae5df279eef91e307f175efd85&chksm=fa3af974cd4d70623130c8e83789313d5b971a50da366d8736b32e2fb8be77a6ddb47af1ede6&scene=126&sessionid=1681375565#rd)

更多全球网络安全资讯尽在邑安全

众所周知，大多数人仍在使用简单的密码，但公司首席执行官、高级管理人员和企业主是否认为“123456 ”这样的密码可以保证他们的账户安全？根据一份新的报告，他们中的许多人确实这样认为。

![](../Images/f48506b1d39f2c80fbedef4a86e4441d.png)

密码管理器NordPass在网络安全研究人员的帮助下，分析了全球超过2.9亿次的数据泄露，整理出一份企业高管使用的密码清单。这些人包括公司CEO、CTO、CFO、企业主和管理层等。

事实证明，这些高管与普通人并无太大区别。“123456”和“password”（密码）分别是在最受欢迎的密码中分别排在第一和第二。第一个字符串也是去年日常用户中最常见的密码，估计被使用了超过1.03亿次。

似乎许多高层管理人员也喜欢在他们的密码中插入名字，其中“Tiffany”（100534次）、“Charlie”（33699次）和 “Michael”（10647次）最为流行。2月份的一份报告显示，名字是第二大被入侵的密码类别。

![](../Images/2ec9bf8f5d1c3603545dbda44e9281f5.png)

行政人员也喜欢在他们的密码中使用动物--真实的和神话的，其中“Dragon”（龙）被使用了11926次，“Monkey”（猴子）紧随其后（11675次）。动物是第三大被攻击的密码类别。

企业数据泄露事件时有发生。根据Verizon数据泄露调查报告（DBIR），其中80%是由弱密码和容易破解的密码造成的。而黑客进入高级行政人员的账户会给公司带来灾难。

其他导致数据泄露的主要原因也是可以避免的：重复使用和共享密码、网络钓鱼攻击和人为错误。它们也可能是由于公司的网络安全基础设施薄弱造成的。NordPass建议使用密码管理器，启用多因素认证，并引入更多员工培训，以帮助避免此类事件。
