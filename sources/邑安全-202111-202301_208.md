# 新型信息窃取恶意软件FFDroider窃取数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247513326&idx=2&sn=d0a255678048851ed01f0b2e2b0f1a7f&chksm=fa3af434cd4d7d221aaa3f2f4f65b93ae6115ba469b2036df3ca94d924d971b96858afd96b55&scene=126&sessionid=1681375585#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247513326&idx=2&sn=d0a255678048851ed01f0b2e2b0f1a7f&chksm=fa3af434cd4d7d221aaa3f2f4f65b93ae6115ba469b2036df3ca94d924d971b96858afd96b55&scene=126&sessionid=1681375585#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/5d6026b4803e6e8e5717fca6fe0477ce.png)

网络安全研究人员警告称，有两种不同的信息窃取恶意软件FFDroider和Lightning Stealer能够窃取数据并发起进一步的攻击。  

Zscaler ThreatLabz 的研究人员 Avinash Kumar 和 Niraj Shivtarkar在上周发布的一份报告中说：“FFDroider 旨在将被盗的凭据和 cookie 发送到命令与控制服务器，在受害者的机器上伪装自己看起来像即时消息应用程序‘Telegram’。”

顾名思义，信息窃取者可以从受感染的机器中收集敏感信息，例如击键、屏幕截图、文件、保存的密码和来自 Web 浏览器的 cookie，然后将这些信息传输到远程攻击者控制的域。

FFDroider 通过破解版的安装程序和免费软件进行分发，其主要目的是窃取与流行社交媒体和电子商务平台相关的 cookie 和凭据，并使用掠夺的数据登录帐户并获取其他与个人帐户相关的信息。

该恶意软件针对的 Web 浏览器包括 Google Chrome、Mozilla Firefox、Internet Explorer 和 Microsoft Edge。目标网站包括 Facebook、Instagram、Twitter、亚马逊、eBay 和 Etsy。

![](../Images/8922d8d9f10b24f3d5d65fc6f8a362c2.png)

研究人员说：“窃取者使用窃取的 cookie 登录受害者的社交媒体平台，并提取 Facebook Ads-manager 等帐户信息，以使用存储的支付方式运行恶意广告，并通过 API 窃取个人信息。”  

FFDroider 还带有一个下载器功能，可以使用来自更新服务器的新模块进行自我升级，从而使其能够随着时间的推移扩展其功能集，从而使恶意行为者能够滥用被盗数据作为初始访问目标的载体。

![](../Images/d3d6fadd7712ebca50bce3ab7d993652.png)

Lightning Stealer 以类似的方式运行，它可以从 30 多个基于 Firefox 和 Chromium 的浏览器中窃取 Discord 令牌、加密货币钱包中的数据以及与 cookie、密码、信用卡和搜索历史相关的详细信息，所有这些都被泄露以 JSON 格式发送到服务器。  

“信息窃取者正在采用新技术变得更加规避，”Cyble 研究人员说，并补充说“目睹了勒索软件组织利用信息窃取者获得初始网络访问权限，并最终窃取敏感数据。”

近几个月来，窃取恶意软件在不同的攻击活动中变得越来越普遍，部分原因是为了填补由于乌克兰持续战争而在 3 月下旬Raccoon Stealer 退出市场留下的空白。

2022 年 2 月，Cyble Research 披露了一种名为Jester Stealer的新兴威胁的详细信息，该威胁旨在窃取登录凭证、cookie、信用卡信息以及来自密码管理器、聊天信使、电子邮件客户端、加密钱包和游戏应用程序的数据，并将其传输到攻击者。

从那时起，至少出现了三种不同的信息窃取者，包括BlackGuard、Mars Stealer和META，其中最后一种被观察到通过恶意垃圾邮件活动收集敏感数据。
