# Axie Infinity 的 Ronin 网桥被盗 6.25 亿美元，这是有史以来最大的加密黑客攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247513075&idx=2&sn=7e0e5a17ae36ba466ecb3c13fb051162&chksm=fa3af329cd4d7a3f1c4b2a230d9af3b172c4192316a1959e0c31f409cb28adc6d61c04059201&scene=126&sessionid=1681375585#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247513075&idx=2&sn=7e0e5a17ae36ba466ecb3c13fb051162&chksm=fa3af329cd4d7a3f1c4b2a230d9af3b172c4192316a1959e0c31f409cb28adc6d61c04059201&scene=126&sessionid=1681375585#rd)

更多全球网络安全资讯尽在邑安全

威胁者从 Axie Infinity 的 Ronin 网桥中窃取了近 6.25 亿美元的以太坊和 USDC（与美元挂钩的稳定币）代币。攻击发生在 3 月 23 日，但在用户无法提取 5,000 以太币后，今天发现了网络抢劫。

Ronin 网络是用于区块链游戏 Axie Infinity 的以太坊链接侧链。

  

![](../Images/5896e653aad1dd8702eb81e124718dcf.png)

  

攻击者窃取了大约173,600 个以太币 和 2550 万美元的 USDC。袭击发生后，浪人桥和 Katana Dex 已停止使用。

Axie Infinity 通过官方 Discord 和 Twitter 帐户以及 Ronin Network 披露了安全漏洞。

*“Ronin Network 出现安全漏洞。今天早些时候，我们发现在 3 月 23 日，Sky Mavis 的 Ronin 验证器节点和 Axie DAO 验证器节点遭到入侵，导致 173,600 个以太坊和 25.5M USDC 在两笔交易（**1 和 2）中从 Ronin 桥中流失。” 宣读公司发表的 声明。“攻击者使用被黑的私钥来伪造假提款。今天早上，在用户报告无法从桥上提取 5k ETH 后，我们发现了这次攻击。”*

![](../Images/5d7a15fb3d418030c31e3d6178857d18.png)

被盗资金的数额使这次攻击成为历史上最大的加密黑客攻击，超过了2021 年 8 月对 DeFi 协议Poly Network的 6.11 亿美元的黑客攻击。

Sky Mavis 的 Ronin 链目前由 9 个验证节点组成。为了确认交易，需要九个验证者签名中的五个。威胁参与者设法控制了五个验证器签名、Sky Mavis 的四个 Ronin 验证器和一个由 Axie DAO 运行的第三方验证器。 

*“验证器密钥方案被设置为去中心化的，因此它限制了与此类似的攻击向量，但攻击者通过我们的无气体 RPC 节点发现了一个后门，他们滥用该后门来获取 Axie DAO 验证器的签名。” 继续声明。*

该公司通知了执法部门并聘请了一名法医密码学家来调查这一事件。

Axie Infinity 表示，它致力于确保所有耗尽的资金都能得到追回或报销。

*“截至目前，用户无法向 Ronin Network 提取或存入资金。Sky Mavis 致力于确保收回或偿还所有耗尽的资金。” 结束声明。*
