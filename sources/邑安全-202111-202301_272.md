# 美国网络安全局（CISA）发布免费安全工具和服务清单

更多全球网络安全资讯尽在邑安全

![](../Images/ba92b326f227cef49fc5ff5489bc1073.png)

美国网络安全和基础设施安全局 (CISA) 周五发布了一个免费工具和服务存储库，使组织能够有效缓解、检测和响应恶意攻击，并进一步改善其安全态势。  

“免费网络安全服务和工具”资源中心包含 CISA 提供的 101 项服务、开源实用程序以及网络安全社区中私营和公共部门组织提供的其他工具。

“许多公共和私人组织的目标是富人和资源贫乏，”CISA 主任 Jen Easterly 在一份声明中说。“此列表中的资源将帮助此类组织改善其安全态势，这在当前威胁加剧的环境中尤为重要。”

该工具目录是 CISA 发起的一系列举措中的最新举措，这些举措旨在打击网络威胁并帮助组织采取基本措施，通过修补软件中的安全漏洞、实施多因素身份验证和停止不良做法来最大限度地提高弹性。

为此，该机构推出了专门的门户网站，记录已知被利用的漏洞、“异常危险”的网络安全程序、抵御勒索软件感染的指南以及与恶意信息和影响操作相关的威胁。

本周早些时候，它还发起了一项“ Shields Up ”活动，通知美国的组织网络威胁带来的潜在风险，这些威胁可能会破坏对基本服务的访问，并可能对公共安全造成影响。

与此同时，该机构发布了一份警报，详细说明了关键基础设施实体可以采取的主动措施来评估和减轻与信息操纵相关的威胁，同时指出通信和网络系统的进步为利用创造了新的载体。

“恶意行为者可能会使用错误信息、虚假信息和恶意信息等策略来塑造公众舆论、破坏信任并扩大分歧，这可能会对多个部门的关键职能和服务造成影响，”CISA 说。
