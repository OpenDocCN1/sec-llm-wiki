零日漏洞利用代理 Zerodium 40万美元购买Outlook RCE

更多全球网络安全资讯尽在邑安全

漏洞利用经纪人 Zerodium 宣布，针对允许在 Microsoft Outlook 电子邮件客户端中远程执行代码 (RCE) 的零日漏洞，其薪酬将跃升至 400,000 美元。

该公司在一条简短的推文中表示，新的支付不是永久性的，但提交的结束日期仍有待披露。

预期零点击漏洞

Zerodium 对 Windows 版 Microsoft Outlook 中的 RCE 漏洞的常规赏金为 250,000 美元，预计将“伴随一个功能齐全且可靠的漏洞利用”。

以 400,000 美元的价格，Zerodium 正在等待一种在微软的电子邮件客户端接收或下载消息时无需任何交互即可实现远程代码执行的漏洞，即所谓的“零点击”。

“我们暂时将 Microsoft Outlook RCE 的支出从 250,000 美元增加到 400,000 美元。我们正在寻找在 Outlook 中接收/下载电子邮件时导致远程代码执行的零点击漏洞，而无需任何用户交互，例如阅读恶意电子邮件或打开附件” - Zerodium

该公司不排除需要打开或阅读电子邮件的漏洞的赏金，尽管提交者将获得较低的未公开支付。

Zerodium 还提醒说，它目前为在 Mozilla Thunderbird 中远程执行代码的漏洞提供高达 200,000 美元的资金，与 2019 年以来提供的金额相同。

与 Microsoft Outlook 相同的条件适用于 Mozilla Thunderbird 的漏洞利用支付。电子邮件客户端中的 RCE 将授予攻击者对所有可用帐户的访问权限。

虽然该公司没有指定提交零点击 Microsoft Outlook 漏洞利用的结束日期，但期限可能相当长。

2021 年 3 月 31 日，Zerodium 宣布暂时将 WordPress RCE 漏洞的赏金增加三倍，并且该报价至今仍然有效。

在最流行的开源内容管理系统 (CMS) 中利用漏洞的常规支出为 100.000 美元。

目前，只有 WordPress、Mozilla Thunderbird 和 Microsoft Outlook 在页面上被列为活动，并暂时增加了赏金。

最近过期的临时优惠包括 Google Chrome 中的 RCE 和沙盒逃逸（最高 400,000 美元），以及 VMware vCenter 服务器中的 RCE（最高 150,000 美元）。
