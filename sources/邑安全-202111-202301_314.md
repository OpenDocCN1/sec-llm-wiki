# 微软：黑客正利用与 Log4j 攻击相关的新 SolarWinds Serv-U 漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247511876&idx=1&sn=367ac640569994cb870cd6e7eb722dcd&chksm=fa3aef9ecd4d66888be98740d66ec732f293ce9be946e0c9aa8915246c0c03e5434f57d84b8a&scene=126&sessionid=1681375616#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247511876&idx=1&sn=367ac640569994cb870cd6e7eb722dcd&chksm=fa3aef9ecd4d66888be98740d66ec732f293ce9be946e0c9aa8915246c0c03e5434f57d84b8a&scene=126&sessionid=1681375616#rd)

微软周三披露了 SolarWinds Serv-U 软件中一个新安全漏洞的详细信息，并称该软件已被威胁行为者武器化，以传播利用 Log4j 漏洞危害目标的攻击。  

跟踪为CVE-2021-35247（CVSS 分数：5.3），该问题是一个“输入验证漏洞，它可能允许攻击者在给定一些输入的情况下构建查询，并在没有卫生设施的情况下通过网络发送该查询”，微软威胁情报中心（MSTIC） )说。

该漏洞由安全研究员 Jonathan Bar Or 发现，影响 Serv-U 版本 15.2.5 及之前的版本，并已在 Serv-U 版本 15.3 中得到解决。

“LDAP 身份验证的 Serv-U 网络登录屏幕允许未充分清理的字符，”SolarWinds在一份公告中说，并补充说它“更新了输入机制以执行额外的验证和清理。”

这家 IT 管理软件制造商还指出，“由于 LDAP 服务器忽略了不正确的字符，因此没有检测到下游影响。” 目前尚不清楚微软检测到的攻击是否仅仅是利用该漏洞的尝试，或者它们最终是否成功。

![](../Images/d39d2f941b3363dd6f62417e793f42bd.png)

随着多个威胁参与者继续利用Log4Shell 漏洞对易受攻击的网络进行大规模扫描和渗透，以部署后门、硬币矿工、勒索软件和远程 shell，从而为进一步的利用后活动提供持久访问权限，这一发展随之而来。

Akamai 研究人员在本周发布的一项分析中还发现了这些漏洞被滥用以通过针对Zyxel 网络设备来感染和协助 Mirai 僵尸网络使用的恶意软件扩散的证据。

最重要的是，之前观察到一个总部位于中国的黑客组织利用影响 SolarWinds Serv-U ( CVE-2021-35211 ) 的关键安全漏洞在受感染的计算机上安装恶意程序。
