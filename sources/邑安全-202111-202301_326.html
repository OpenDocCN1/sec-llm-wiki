威胁行为者滥用公共云服务来传播多种 RAT

更多全球网络安全资讯尽在邑安全

威胁参与者正在积极滥用亚马逊和微软的云服务来提供诸如 Nanocore、  Netwire和 AsyncRAT等 RAT 。

威胁参与者正在积极利用 Amazon 和 Microsoft 的公共云服务来传播 RAT，例如 Nanocore、  Netwire和 AsyncRAT ，用于从受感染的系统中窃取敏感信息。

该恶意软件活动于 2021 年 10 月被 Cisco Talos 发现，大多数受害者位于美国、意大利和新加坡。

威胁参与者利用 Azure 和 AWS 等云服务，因为它们可以通过最少的努力轻松设置，从而使防御者更难检测和缓解活动。

攻击者在下载脚本中使用了复杂的混淆技术。

攻击链从使用恶意 ZIP 附件的网络钓鱼电子邮件开始，该附件包含 ISO 映像和 JavaScript、Windows 批处理文件或 Visual Basic 脚本形式的加载程序。执行初始脚本后，受害者的机器从 C2 服务器下载下一阶段，该服务器可以托管在基于 Azure 云的 Windows 服务器或 AWS EC2 实例上。

“为了传递恶意软件负载，攻击者使用免费的动态 DNS 服务 DuckDNS 注册了几个恶意子域。与此活动相关的恶意软件系列是 Netwire、Nanocore 和 AsyncRAT 远程访问木马的变种。”阅读Talos 发布的分析。“组织应该检查与云计算服务的传出连接是否存在恶意流量。这篇文章中描述的活动表明，流行的云平台越来越多地用于托管恶意基础设施。”



一旦在目标系统上安装了恶意软件，它就可以用来窃取机密数据或传递额外的有效载荷，例如勒索软件攻击。威胁参与者还可以将访问权限出售给其他网络犯罪团伙，包括勒索软件附属机构。

“组织应部署全面的多层安全控制，以检测类似威胁并保护其资产。防御者应监控其组织的流量，并围绕其端点上的脚本执行策略实施强大的规则。对于组织而言，提高电子邮件安全性以检测和缓解恶意电子邮件并尽早打破感染链更为重要。” 该报告总结了还包括妥协指标 (IoC) 的报告。
