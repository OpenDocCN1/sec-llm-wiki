# Android 用户现在可以禁用 2G 来阻止 Stingray 攻击

谷歌终于在 Android 上推出了一个选项，允许用户禁用 2G 连接，这会带来许多蜂窝站点模拟器利用的隐私和安全问题。

EFF（电子前沿基金会）发现了该选项的添加，称该开发是隐私保护的胜利 。

## 被“Stingray”捕获

蜂窝基站模拟器，也称为“黄貂鱼”或 IMSI Catcher，是一种伪装成蜂窝塔的设备，迫使其范围内的手机连接到它。

这种连接使这些Stingray的运营商能够执行中间人攻击并拦截敏感的个人信息，例如： 

*   
*   
*   
*   

```
设备 IMSI（国际移动用户标识）呼叫元数据，例如已拨号码和持续时间短信和语音通话内容数据使用和网络浏览历史
```

![](../Images/40433fd0d1fb8da785eb4158660a2634.png)

Stingray拦截人们的通讯

不幸的是，在适用严格数据保护法的其他民主国家的和平抗议期间，执法当局一再不分青红皂白地部署这种数据拦截方法。

此外，近年来，私下部署“Stingray”的案情也层出不穷，因此滥用通信网络漏洞的情况十分普遍。

大多数这些漏洞已在 4G 中得到解决，但模拟基站有办法将附近的设备连接降级到 2G，基本上为利用旧漏洞奠定了基础。

在用户端有一种方法来防止这种情况是一个重大的发展，虽然停止 2G 连接并不能解决整个安全问题，但这无疑是一个好的开始。

## 在 Android 上禁用 2G

虽然 Google 已为 Android 用户提供了不允许在其设备上使用 2G 蜂窝网络连接的选项，但该设置默认处于打开状态。

如果您想将其关闭，您可以前往“设置 → 网络和 Internet → SIMs → 允许 2G ”。根据您的设备制造商和使用的 Android 皮肤，访问该设置的路径可能会有所不同。

![](../Images/b71f419e88db8213a4132deb13f4a4a0.png)

禁用 2G 的 Android 选项

请注意，此设置目前仅在 Android 12 上可用。Bleeping Computer 已经测试了 Android 11 和 Android 10，但该选项尚不可用。

我们已经要求谷歌澄清这个新选项是否也有硬件要求才能工作，他们告诉我们调制解调器需要支持 1.6 Radio HAL，它只在较新的设备上可用。

此外，重要的是要澄清，无论切换开关设置在什么位置，2G 作为紧急呼叫的备份仍然处于活动状态，因此无法完全禁用它。

最后，苹果并没有让 iPhone 用户选择仅将其设备锁定为 4G/5G 连接，但既然谷歌已经迈出了这一步，那么竞争很可能会随之而来。
