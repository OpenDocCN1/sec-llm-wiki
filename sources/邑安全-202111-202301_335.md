# Patchwork APT 黑客以分子医学和研究为重点目标

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247511671&idx=2&sn=4153455388e502b88e5ab07ac08ffbe2&chksm=fa3aeeadcd4d67bb44fb526b3cb04e49e56e5f760577d46bbf7de6fcf8c89c675cc7f6264825&scene=126&sessionid=1681375616#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247511671&idx=2&sn=4153455388e502b88e5ab07ac08ffbe2&chksm=fa3aeeadcd4d67bb44fb526b3cb04e49e56e5f760577d46bbf7de6fcf8c89c675cc7f6264825&scene=126&sessionid=1681375616#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/f161d3ca637511912dd4cbaf2ee75d01.png)

作为 2021 年 11 月下旬开始的新活动的一部分，威胁猎手揭示了一个名为 Patchwork 的印度裔黑客组织所采用的策略、技术和程序，目标是巴基斯坦政府实体和个人，其研究重点是分子医学和生物科学。  

“具有讽刺意味的是，我们收集的所有信息都是可能的，这要归功于威胁行为者用他们自己的 \[远程访问木马\] 感染自己，从而捕获了他们自己的计算机和虚拟机的击键和屏幕截图，”Malwarebytes 威胁情报团队在发布的一份报告中说在周五。

成功渗透的主要受害者包括巴基斯坦国防部、伊斯兰堡国防大学、拉合尔大学生物科学学院、国际化学与生物科学中心 (ICCBS)、HEJ 化学研究所和萨利姆哈比卜大学 (事业单位）。

自 2015 年以来一直活跃，Patchwork APT也被更广泛的网络安全社区跟踪，绰号为 Dropping Elephant、Chinastrats（卡巴斯基）、Quilted Tiger（CrowdStrike）、Monsoon（Forcepoint）、Zinc Emerson、TG-4410（SecureWorks）、和 APT-C-09（奇虎 360）。

该间谍组织主要以通过鱼叉式网络钓鱼活动打击巴基斯坦、中国、美国智库和其他位于印度次大陆的目标的外交和政府机构而闻名，其名称源于其恶意软件使用的大部分代码工具是从网络上公开的各种来源复制和粘贴的。

![](../Images/77e097c9714d58c9db7d03ba174bf8c1.png)

现已解散的以色列网络安全初创公司 Cymmetria的研究人员在 2016 年 7 月发布的调查结果中指出： “这个威胁参与者使用的代码是从各种在线论坛复制粘贴的，这让我们想起了拼凑被子。”

多年来，该演员发起的连续秘密行动试图删除并执行QuasarRAT以及名为BADNEWS的植入物，该植入物充当攻击者的后门，使他们能够完全控制受害机器。2021 年 1 月，还观察到威胁组织利用 Microsoft Office 中的远程代码执行漏洞 ( CVE-2017-0261 ) 在受害机器上传递有效载荷。

最新的活动没有什么不同，因为对手使用 RTF 文件来引诱潜在目标，这些文件冒充巴基斯坦当局，最终充当部署 BADNEWS 特洛伊木马新变种的渠道，称为 Ragnatela（意大利语中的意思是“蜘蛛网”），使运营商能够执行任意命令、捕获击键和屏幕截图、列出和上传文件以及下载其他恶意软件。

据称来自卡拉奇的巴基斯坦国防官员住房管理局 ( DHA )的新诱饵包含对 Microsoft Equation Editor 的利用，该漏洞被触发以破坏受害者的计算机并执行 Ragnatela 有效负载。

但是在 OpSec 失败的情况下，攻击者最终还用 RAT 感染了他们自己的开发机器，因为 Malwarebytes 能够揭露其许多策略，包括使用双键盘布局（英语和印度语）以及如采用虚拟机和 VPN（如 VPN Secure 和 CyberGhost）来隐藏其 IP 地址。

研究人员总结说：“虽然他们继续使用相同的诱饵和 RAT，但该小组对一种新的目标表现出兴趣。” “事实上，这是我们第一次观察到针对分子医学和生物科学研究人员的 Patchwork。”
