VMware 解决 Workstation、Fusion 和 ESXi 产品中堆溢出漏洞

VMware 解决了 Workstation、Fusion 和 CVE-2021-22045 产品中的堆溢出问题 (CVE-2021-22045)，该问题可能导致在管理程序上执行代码。

VMware 发布了安全更新以解决其 Workstation、Fusion 和 ESXi 产品中的堆溢出漏洞，该漏洞被跟踪为 CVE-2021-22045。VMware 已通过发布 ESXi670-202111101-SG、ESXi650-202110101-SG、Workstation 16.2.0 和 Fusion 12.2.0 解决了该漏洞。

据该公司称，上述产品的CD-ROM设备仿真功能存在安全漏洞。有权访问启用了 CD-ROM 设备模拟的虚拟机的攻击者可以将此漏洞与其他漏洞链接起来，以从虚拟机在管理程序上执行代码。

“VMware Workstation、Fusion 和 ESXi 中的 CD-ROM 设备模拟存在堆溢出漏洞。” 读咨询公司公布。“通过 CD-ROM 设备模拟访问虚拟机的恶意行为者可能能够利用此漏洞以及其他问题从虚拟机的管理程序上执行代码。”

该漏洞已私下报告给 VMware，CVSS 得分为 7.7。

这家虚拟化巨头还为此问题提供了缓解措施，包括禁用或断开所有正在运行的虚拟机上的 CD-ROM/DVD 设备。以下是分步过程：

1) 使用 vSphere Web Client 登录到 vCenter Server 系统。
2) 右键单击虚拟机，然后单击编辑设置。
3) 选择 CD/DVD 驱动器并取消选中“已连接”和“开机时连接”并删除所有附加的 ISO。

要列出连接了 CD-ROM/DVD 的虚拟机，管理员可以使用 Powercli。
以下命令将列出所有连接设备的虚拟机

Get-VM | Get-CDDrive | Where {$_.extensiondata.connectable.connected -eq $true} | Select Parent

要移除和断开连接的 CD-ROM/DVD 设备，请运行以下命令

Get-VM | Get-CDDrive | Where {$_.extensiondata.connectable.connected -eq $true} | Set-CDDrive -NoMedia -confirm:$false

受影响的产品包括 Workstation 16.x 和 Fusion 12.x、ESXi 6.5、6.7 和 7 版本，以及 VMware Cloud Foundation。

该公司建议客户尽快应用安全更新。
