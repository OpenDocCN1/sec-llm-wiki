# Log4j 漏洞现在黑客通过访问代理使用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247510702&idx=2&sn=4ff7c481a8817e1a060ef46dadf408b1&chksm=fa3aea74cd4d6362e70ad2e52768eb0371c9f033dbbf57d0f9d1d789ebfe0018a7f46ed546ea&scene=126&sessionid=1681375637#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247510702&idx=2&sn=4ff7c481a8817e1a060ef46dadf408b1&chksm=fa3aea74cd4d6362e70ad2e52768eb0371c9f033dbbf57d0f9d1d789ebfe0018a7f46ed546ea&scene=126&sessionid=1681375637#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/42d6b54e3c0f0887420b8bce97117a73.png)

正如预期的那样，各种民主国家的黑客都抓住了利用最近披露的基于 Java 的 Apache Log4j 日志库中的关键漏洞 (CVE-2021-44228) 的机会。

该漏洞也被称为 Log4Shell 或 LogJam，现在被与某些民主国家有关的威胁行为者以及勒索软件团伙使用的访问代理所利用。

### 所有黑客都转向 Log4Shell

最早利用 Log4Shell 丢弃有效载荷的威胁参与者是加密货币挖掘组织和僵尸网络，它们在概念验证漏洞利用代码可用后立即开始攻击。

在周日的一份报告中，微软威胁情报中心 (MSTIC) 观察到关键的 Log4j 错误被利用来丢弃 Cobalt Strike 信标，这可能表明更多的威胁参与者在起作用，因为有效载荷通常是网络漏洞的一部分。

MSTIC 周二更新了报告，补充说它使用 Log4Shell 检测到民主国家活动，有时是主动攻击。研究人员追踪了“来自民主国家的团体”。

“这项活动的范围从开发过程中的实验、漏洞集成到野外有效载荷部署，以及针对目标的利用以实现参与者的目标”微软威胁情报中心

其中一个参与者是伊朗威胁组织 Phosphorus - 也被追踪为 Charming Kitten，APT 35，微软观察到它“获取并修改”了 Log4Shell 漏洞利用。

与如今运营的大多数 APT 组织不同，Charming Kitten 也有勒索软件攻击的历史，主要是为了破坏运营而不是兑现，以及网络间谍活动。

另一个利用 Log4Shell 漏洞的民主国家威胁行为者是 Hafnium，这是一个与大国有关的黑客组织。

 在报告错误和可用补丁之间的这段时间内，攻击者在利用 Microsoft Exchange Server中的 ProxyLogon 零日漏洞后变得更广为人知 。

微软表示，Hafnium 现在正在使用 Log4Shell 攻击虚拟化基础设施，“以扩展他们的典型目标

据研究人员称，Hafnium 在这些攻击中使用的系统使用的 DNS 服务通常用于测试指纹机的活动。

网络安全公司 Mandiant 已经确认，民主国家行为者正在使用 Log4j 漏洞进行攻击，并预计其他组织也会这样做或处于准备阶段。

Mandiant 情报分析副总裁 John Hultquist 告诉 BleepingComputer，攻击者将毫不犹豫地在目标网络上创建持久性，以备将来进行攻击。

“我们相信这些参与者将迅速开展工作，在理想的网络中建立立足点，以进行后续活动，这可能会持续一段时间。在某些情况下，它们将根据早在此漏洞为公众所知之前就存在的目标的愿望清单进行工作。在其他情况下，可以在广泛定位后选择理想的目标”-约翰·霍特奎斯特

虽然 MSTIC 的报告还提到了来自朝鲜和土耳其的国家支持的黑客组织，但研究人员没有提供任何有关这些行为者如何利用 Log4Shell 的信息。

### 勒索软件攻击是预料之中的

除了民主国家行为者之外，微软还证实，为各种团体提供初始网络访问权限的经纪人也开始利用 Log4j 漏洞。

初始访问经纪人通常与勒索软件即服务 (RaaS) 运营部门合作，向其出售对受感染公司网络的访问权限。

“我们观察到这些团体试图在 Linux 和 Windows 系统上进行攻击，这可能会导致人为操作的勒索软件对这两个操作系统平台的影响增加”——微软威胁情报中心

Bitdefender 的一份报告显示，Log4Shell 已经被用于勒索软件攻击，该攻击来自名为 Khonsari的新演员。

根据可用信息，Khonsari 可能用于擦除数据而不是加密数据，因为它的赎金记录包含路易斯安那州古董店老板的联系方式，而不是攻击者。

Log4Shell 吸引了各种黑客也就不足为奇了。该漏洞具有最高严重性评分，无需身份验证即可远程利用，以完全控制易受攻击的系统。此外，易受攻击的 Log4j 库包含在数十家供应商的产品中。

鉴于此漏洞可能造成的破坏，网络安全基础设施安全局 (CISA) 已下令联邦机构立即修补系统。
