今天是微软 2021 年 12 月补丁星期二，修复了六个零日漏洞和总共 67 个缺陷。这些更新包括对恶意软件分发活动中使用的主动利用的 Windows Installer 漏洞的修复。

微软在今天的更新中修复了 55 个漏洞（不包括 Microsoft Edge），其中 7 个被归类为严重，60 个被归类为重要。

下面列出了每种类型的漏洞数量：

*   21 提权漏洞
    
*   26个远程代码执行漏洞
    
*   10个信息披露漏洞
    
*   3 拒绝服务漏洞
    
*   7 欺骗漏洞
    

有关非安全 Windows 更新的信息，您可以阅读今天发布的 Windows 10 KB5008212 和 KB5008206 更新。

## 修复了六个零日漏洞，其中两个被积极利用

12 月的星期二补丁修复了六个零日漏洞，其中一个是被积极利用的 Windows AppX 安装程序漏洞。

如果某个漏洞被公开披露或被积极利用而没有可用的官方修复程序，则 Microsoft 将其归类为零日漏洞。

主动利用的 Windows AppX 安装程序零日漏洞被跟踪为 CVE-2021-43890，并用于各种恶意软件分发活动，包括 Emotet、TrickBot 和 BazarLoader。

![](../Images/7b5d97ef16ad55fdc64c91bf7e419b6b.png)

Windows AppX Installer 被滥用来安装 Emotet

作为 2021 年 12 月补丁星期二的一部分，微软还修复了五个公开披露的零日漏洞，已知这些漏洞不会在攻击中被利用。

*   CVE-2021-43240 - NTFS 设置短名称特权提升漏洞
    
*   CVE-2021-41333 - Windows 打印后台处理程序特权提升漏洞
    
*   CVE-2021-43880 - Windows Mobile 设备管理特权提升漏洞
    
*   CVE-2021-43883 - Windows 安装程序特权提升漏洞
    
*   CVE-2021-43893 - Windows 加密文件系统 (EFS) 特权提升漏洞
    

## 其他公司的最新更新

其他在 11 月发布更新的供应商包括：

*   Android 的12 月安全更新已于上周发布。
    
*   Apache Log4j：针对席卷 Internet 的高度问题漏洞发布了许多安全公告。
    
*   Apple发布了适用于 iOS、iPadOS、macOS、tvOS 和 watchOS 的安全更新。
    
*   思科 本月发布了许多产品的安全更新，包括与其产品中的Log4j 漏洞相关的公告。
    
*   SAP发布了2021 年 12 月的安全更新。
    
*   VMWare的发布了一个咨询有关当前补丁在他们的产品Log4j的漏洞。
