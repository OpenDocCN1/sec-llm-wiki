攻击者可以通过使 Ubuntu 的 AccountsService 崩溃来获得 root

更多全球网络安全资讯尽在邑安全

一个本地提权安全漏洞可能允许攻击者通过利用 GNOME 的 AccountsService 组件中的双重释放内存损坏漏洞获得 Ubuntu 系统的 root 访问权限。

AccountsService 是一种 D-Bus 服务，可帮助操作和查询附加到设备上可用用户帐户的信息。

GitHub 安全研究员 Kevin Backhouse 在测试另一个 AccountsService 漏洞的漏洞利用演示时意外发现了安全漏洞（一个内存管理漏洞，跟踪为 CVE-2021-3939），该漏洞 也使得 在易受攻击的设备上将权限提升到 root 成为可能。

“如果 AccountsService 收到特制的命令，它可能会以管理员身份崩溃或运行程序，”Ubuntu 安全公告 解释说。

Backhouse 发现 AccountsService 在某些语言设置操作期间错误地处理了内存，本地攻击者可以利用该缺陷来提升权限。

该错误仅影响 Ubuntu 的 AccountsService 分支。受此漏洞影响的版本包括 Ubuntu 21.10、Ubuntu 21.04 和 Ubuntu 20.04 LTS。

这个提权漏洞 由 Canonical 于 11 月在 AccountsService 版本 0.6.55-0ubuntu12~20.04.5、0.6.55-0ubuntu13.3、0.6.55-0ubuntu14.1 发布时修复。应用更新后，您还需要重新启动计算机以应用更改。

不是最快的，但绝对可靠

正如他解释的那样，他的 CVE-2021-3939 概念验证漏洞利用 速度很慢（可能是几个小时），并且不会每次都有效。然而，这并不重要，因为它可以一直执行直到成功，看到双重释放错误允许根据需要多次崩溃 AccountsService。

成功利用此漏洞的唯一限制是 AccountsService 崩溃受 systemd 限制，每 10 秒阻止尝试重新启动它超过 5 次。

“它依赖于机会和事实，即我可以不断崩溃帐户服务直到它成功。但是攻击者会关心吗？它会为你提供一个 root shell，即使你必须等待几个小时，”Backhouse 说。

“对我来说，甚至可以利用这样一个小错误感觉就像魔法一样，特别是考虑到已添加的所有缓解措施使内存损坏漏洞更难以利用。有时，获得 root 所需的只是一些一厢情愿的想法！”

Backhouse 的 CVE-2021-3939 文章中提供了有关如何发现漏洞和开发漏洞的更多详细信息 。

今年早些时候，研究人员在 polkit Linux 系统服务中发现了一个身份验证绕过漏洞，该漏洞 使非特权攻击者能够在大多数现代发行版上获得 root shell。
