# MikroTik路由器被武器化，30万台设备易遭受远程漏洞攻击

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247510469&idx=1&sn=de583cafd3af090e2716e0286c39b26c&chksm=fa3ae91fcd4d6009a88a1e3718d181006e6ab2dd1874139ff7c294be49869255a9e25baf94d7&scene=126&sessionid=1681375637#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247510469&idx=1&sn=de583cafd3af090e2716e0286c39b26c&chksm=fa3ae91fcd4d6009a88a1e3718d181006e6ab2dd1874139ff7c294be49869255a9e25baf94d7&scene=126&sessionid=1681375637#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/413308f338e3b8a5fa07cef8726ee50d.png)

至少有 300,000 个与 MikroTik 设备相关的 IP 地址被发现容易受到多个可远程利用的安全漏洞的攻击，这些漏洞已被流行的路由器和无线 ISP 设备供应商修补。  

网络安全公司 Eclypsium 在与黑客新闻分享的一份报告中表示，受影响最严重的设备位于中国、巴西、俄罗斯、意大利、印度尼西亚，美国排在第八位。

“这些设备都是非常强大的，\[和\]往往非常脆弱，”研究人员指出。“这使得 MikroTik 设备成为威胁行为者的最爱，这些行为者征用了设备用于 DDoS 攻击、命令和控制（又名‘C2’）、流量隧道等等。”

MikroTik 设备是一个诱人的目标，尤其是因为全球部署了超过 200 万台设备，构成了一个巨大的攻击面，威胁参与者可以利用它来发起一系列入侵。

事实上，今年 9 月初，有报道称一个名为Mēris的新僵尸网络利用 Mikrotik 的网络设备作为攻击媒介，对俄罗斯互联网公司 Yandex 发起了破纪录的分布式拒绝服务 (DDoS) 攻击——解决了操作系统中的安全漏洞 ( CVE-2018-14847 )。

这不是 MikroTik 路由器第一次在现实世界的攻击中被武器化。2018 年，网络安全公司 Trustwave发现至少三起大规模恶意软件活动，利用数十万个未打补丁的 MikroTik 路由器在连接到它们的计算机上秘密安装加密货币矿工。同年，中国的 Netlab 360报告称，通过利用 CVE-2018-14847 窃听网络流量，数以千计易受攻击的 MikroTik 路由器被暗中整合到僵尸网络中。

![](../Images/23689e7e6be496ea343dfba7b2132c29.png)

CVE-2018-14847 也是过去三年中发现的四个未解决的漏洞之一，这些漏洞可以完全接管 MikroTik 设备 -

```
CVE-2019-3977（CVSS 评分：7.5）- MikroTik RouterOS 升级包来源验证不足，允许重置所有用户名和密码CVE-2019-3978（CVSS 评分：7.5）- MikroTik RouterOS 对关键资源的保护不足，导致缓存中毒CVE-2018-14847（CVSS 评分：9.1）- WinBox 界面中的 MikroTik RouterOS 目录遍历漏洞CVE-2018-7445（CVSS 评分：9.8）- MikroTik RouterOS SMB 缓冲区溢出漏洞
```

此外，Eclypsium 研究人员表示，他们发现了 20,000 个暴露的 MikroTik 设备，这些设备将加密货币挖掘脚本注入用户访问的网页。

研究人员说：“受感染路由器注入恶意内容、隧道、复制或重新路由流量的能力可以以多种极具破坏性的方式使用。” “DNS 中毒可能会将远程工作人员的连接重定向到恶意网站或引入中间机。”

![](../Images/f4a8a4ead3f5aa36603859c15cd89ee0.png)

“攻击者可以使用众所周知的技术和工具来潜在地捕获敏感信息，例如通过 WiFi 使用 SMS 从远程用户那里窃取MFA凭据。与之前的攻击一样，企业流量可以通过隧道传输到另一个位置或将恶意内容注入到有效流量中，”研究人员补充道。  

MikroTik 路由器并不是唯一被纳入僵尸网络的设备。Fortinet 的研究人员本周披露了Moobot 僵尸网络如何利用海康威视视频监控产品 ( CVE-2021-36260 ) 中已知的远程代码执行 (RCE) 漏洞来扩展其网络，并使用受感染的设备启动分布式拒绝 -服务 (DDoS) 攻击。

在另一份报告中，这家企业网络安全公司表示，名为 Manga aka Dark Mirai 的僵尸网络的运营商正在积极滥用最近披露的经过身份验证的远程代码执行漏洞 ( CVE-2021-41653 ) 来劫持 TP-Link 路由器和合作伙伴。- 将设备选择到受感染设备的网络。

## 更新

在与 The Hacker News 分享的一份声明中，这家拉脱维亚公司表示“RouterOS 中没有新的漏洞”，同时强调保持操作系统最新是“避免各种漏洞的必要步骤”。

“不幸的是，关闭旧漏洞并不能立即保护受影响的路由器。我们没有非法后门来更改用户密码并检查他们的防火墙或配置。这些步骤必须由用户自己完成，”该公司解释说。

“我们尽最大努力联系 RouterOS 的所有用户，提醒他们进行软件升级、使用安全密码、检查防火墙以限制对不熟悉方的远程访问，并寻找异常脚本。不幸的是，许多用户从未使用过与 MikroTik 联系，并没有积极监控他们的设备。我们与世界各地的各种机构合作，寻找其他解决方案。”
