# ALPHV BlackCat - 今年最复杂的勒索软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247510469&idx=3&sn=3ee877798b77730caa7fe559e9a1024b&chksm=fa3ae91fcd4d6009110c5229e6d4213d5d85e7a70236c8612a521b938287aede0629bd8d9b55&scene=126&sessionid=1681375637#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247510469&idx=3&sn=3ee877798b77730caa7fe559e9a1024b&chksm=fa3ae91fcd4d6009110c5229e6d4213d5d85e7a70236c8612a521b938287aede0629bd8d9b55&scene=126&sessionid=1681375637#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/2fcbed54b350f1ce5cdaea01e1d5e5c1.png)

新的 ALPHV 勒索软件操作，又名 BlackCat，于上个月启动，可能是今年最复杂的勒索软件，具有高度可定制的功能集，允许对各种企业环境进行攻击。

勒索软件可执行文件是用 Rust 编写的，这对于恶意软件开发人员来说并不常见，但由于其高性能和内存安全性，它的流行度正在缓慢增加。

MalwareHunterTeam 发现了新的勒索软件，并告诉 BleepingComputer，新操作的第一个 ID Ransomware 提交是在 11 月 21 日。

![](../Images/8e0a70d473aaca9f61ce913a9f33ecc3.png)

该勒索软件被开发人员命名为 ALPHV，并正在俄语黑客论坛上进行推广。

![](../Images/1ec6421edd771f92c57651979f75185f.png)

MalwareHunterTeam 将勒索软件 BlackCat 命名为 BlackCat，因为每个受害者的 Tor 支付站点都使用了相同的黑猫图标，而数据泄露站点使用了血腥的匕首，如下所示。

![](../Images/08f219b43b0c547132c97aabf46c344a.png)

与所有勒索软件即服务 (RaaS) 操作一样，ALPHV BlackCat 运营商招募附属机构来执行企业违规和加密设备。

作为回报，附属公司将根据赎金支付的大小获得不同的收入份额。例如，对于高达 150 万美元的赎金支付，联盟会员赚取 80%、高达 300 万美元的 85% 以及超过 300 万美元的 90%。

为了说明附属公司可以从这些 RaaS 计划中赚取的收入类型，据报道，CNA向俄罗斯黑客组织 Evil Corp支付了 4000 万美元的赎金。根据 ALPHV 的收入份额，这相当于支付给附属公司的 3600 万美元。

## 探索 ALPHV BlackCat 勒索软件的功能

ALPHV BlackCat 勒索软件包括众多高级功能，使其从其他勒索软件操作中脱颖而出。在本节中，我们将了解勒索软件及其运行方式，并演示来自与 BleepingComputer 共享的样本的测试加密。  

该勒索软件完全由命令行驱动、人工操作且高度可配置，能够使用不同的加密例程、在计算机之间传播、杀死虚拟机和 ESXi 虚拟机以及自动擦除 ESXi 快照以防止恢复。

可以使用`--help`命令行参数找到这些可配置选项，如下所示。

![](../Images/516328450ba78e4f1c35c7a89cbb9dd3.png)

每个 ALPHV 勒索软件可执行文件都包含一个 JSON 配置 ，允许自定义扩展名、勒索笔记、数据加密方式、排除的文件夹/文件/扩展名以及要自动终止的服务和进程。

根据威胁行为者的说法，勒索软件可以配置为使用四种不同的加密模式，如他们在暗网黑客论坛上的“招聘”帖子中所述。

该软件是从头开始编写的，没有使用任何模板或之前泄露的其他勒索软件的源代码。提供选择：  
4 种加密模式：  
\-Full - 全文件加密。最安全，最慢。  
\-Fast - 加密前 N 兆字节。不推荐使用，这是最不安全的可能解决方案，但速度最快。  
\-DotPattern - 通过 M 步加密 N 兆字节。如果配置不正确，Fast 的速度和加密强度都会更差。  
\-汽车。根据文件的类型和大小，储物柜（在 windows 和 \* nix / esxi 上）选择最优化的（在速度/安全性方面）处理文件的策略。

\-SmartPattern - 以百分比步长加密 N 兆字节。默认情况下，它从文件头开始每 10% 加密 10 MB。速度/密码强度比的最佳模式。  
2种加密算法：  
\-ChaCha20  
\-AES  
在自动模式下，软件检测的AES硬件支持的存在（在所有的现代处理器的存在），并使用它。如果没有 AES 支持，软件会加密文件 ChaCha20。

ALPHV BlackCat 还可以配置域凭据，用于传播勒索软件和加密网络上的其他设备。然后，可执行文件会将 PSExec 提取到 %Temp% 文件夹，并使用它将勒索软件复制到网络上的其他设备并执行它以加密远程 Windows 计算机。

在启动勒索软件时，附属公司可以使用基于控制台的用户界面，让他们能够监控攻击的进展。在下图中，您可以看到 BleepingComputer 使用修改后的可执行文件加密测试设备以附加 .bleepin 扩展名时显示的此界面。

![](../Images/c6243197ddf5e7a63c19f41da74ca24a.png)

在 BleepingComputer 测试的样本中，勒索软件会终止可能阻止文件被加密的进程和 Windows 服务。这些终止的进程包括 Veeam、备份软件、数据库服务器、Microsoft Exchange、Office 应用程序、邮件客户端，以及不会让游戏玩家离开的 Steam 进程。

在此“设置”过程中采取的其他操作包括清除回收站、删除卷影副本、扫描其他网络设备以及连接到 Microsoft 群集（如果存在）。

ALPHV BlackCat 还使用 Windows 重启管理器 API 来关闭进程或关闭 Windows 服务，在加密期间保持文件打开。

通常，在加密设备时，勒索软件会使用随机扩展名，该扩展名会附加到所有文件并包含在勒索信中。赎金票据以“ RECOVER-\[extension\]-FILES.txt”格式命名，在我们上面的例子中是RECOVER-bleepin-FILES.txt。

![](../Images/43779bb0cc19c09b26f6a78aab2ea2f4.png)

赎金票据由执行攻击的附属公司预先配置，并且对于每个受害者都是不同的。一些赎金记录包括被盗数据的类型以及指向 Tor 数据泄漏站点的链接，受害者可以在其中预览被盗数据。

每个受害者还有一个独特的 Tor 站点，有时还有一个独特的数据泄漏站点，允许附属机构进行自己的谈判。

最后，BlackCat 声称是跨平台的，支持多种操作系统。

> 跨平台软件，即如果您在 Linux 中安装 Windows 磁盘，反之亦然，解密器将能够解密文件。- ALPHV 操作员。

勒索软件专家和 ID 勒索软件创建者迈克尔·吉莱斯皮 (Michael Gillespie) 分析了勒索软件使用的加密程序，但遗憾的是，未能找到任何可以免费解密的弱点。

## 访问令牌功能使谈判保密

影响受害者和勒索软件操作的一个长期存在的问题是样本通常会通过恶意软件分析站点泄露，从而允许完全访问勒索软件团伙与其受害者之间的谈判聊天。

在某些情况下，这会导致无关方在聊天中发表评论并扰乱谈判。

为了防止这种情况发生，ALPHV BlackCat 勒索软件开发人员引入了`--access-token=[access_token]` 启动加密器时必须使用的 命令行参数。

此访问令牌用于创建在勒索软件团伙的 Tor 支付站点上进入谈判聊天所需的访问密钥。由于此令牌未包含在恶意软件样本中，因此即使将其上传到恶意软件分析站点，研究人员也不会在没有实际攻击的赎金通知的情况下使用它访问谈判站点。

## 赎金从 40 万美元到数百万美元不等

BleepingComputer 了解到，自去年 11 月以来，该勒索软件针对多个国家/地区（包括美国、澳大利亚和印度）的受害者。

赎金要求在 400,000 美元到 300 万美元之间，可以用比特币或门罗币支付。但是，如果受害者用比特币支付，赎金会额外收取 15% 的费用。

  

![](../Images/70ac2086d74f7e4bce1039d901ee6938.png)

  

然而，由于门罗币被认为是一种隐私币并且受到美国政府的反对，因此受害者并不容易获得它。

与其他勒索软件操作不同，如果雇用谈判公司，则威胁要擦除或发布数据，ALPHV 正在迎合勒索软件谈判人员的“中介”登录页面，以进行私人谈判。

![](../Images/e2d9916a7ec719214dff62093e35553e.png)

与其他较新的勒索软件团伙一样，ALPHV 使用三重勒索策略，他们在加密设备之前窃取数据，并威胁如果不支付赎金就发布数据。BleepingComputer 已经看到该操作的多个数据泄漏站点，其中已发布数据截图。

作为另一种勒索方法，威胁行为者威胁 DDoS 受害者，直到他们支付赎金。

总体而言，这是一种高度复杂的勒索软件，攻击者清楚地考虑了攻击的各个方面。

随着 BlackMatter 和 REvil 勒索软件操作在执法部门的压力下关闭，它留下了一个巨大的空白，等待另一个威胁行为者来填补。
