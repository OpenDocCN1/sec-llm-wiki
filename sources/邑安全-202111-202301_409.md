# 越南XE集团被曝出和黑客攻击、信用卡盗窃有关

一个自称为“XE Group”的相对不为人知的越南黑客组织与八年的营利性黑客攻击和信用卡窃取有关。

威胁行为者被认为是每天数千张信用卡被盗的罪魁祸首，主要来自餐馆、非营利组织、艺术和旅游平台。

攻击者使用公开可用的漏洞来破坏面向外部的服务，尤其是 Telerik UI 缺陷，以安装窃取恶意软件的凭据和支付信息。

一份 2020 年 Malwarebytes 报告首先概述了该组织的活动，但昨天 Volexity 发布了对该组织最近受到的危害的更深入分析。

## 更多细节浮出水面

Volexity 能够映射 XE Group 在过去三年中使用的基础设施，并在 GitHub 上共享所有技术细节和 IOC。

由于加载恶意 JavaScript 片段的常用技术，研究人员可以找到许多带有相同撇渣器的受感染站点。

“用于从该页面加载恶意 JavaScript 的代码表明，攻击者使用了一种有趣的技术：使用 JavaScript 关键字“对象”来填充域值，”研究人员在 Volexity 报告中分享道。

![](../Images/92616bca9b97f6ee457018c65e8c6aac.png)

这些类型的漏洞被归类为“Magecart”攻击，即威胁行为者入侵电子商务网站以添加恶意 JavaScript，在提交时收集客户和支付信息。然后，这些窃取的信息会上传到远程服务器以供攻击者收集。

这些攻击的长期成功取决于它们在不被安全产品检测到的情况下在网站上的隐藏程度。

将此撇渣器的样本上传到 VirusTotal 会返回完美的 0/57 检测分数，这意味着该组的 JavaScript 对 AV 检测非常隐蔽。

![](../Images/9f86aba676571fcf7c329903a7631c25.png)

总而言之，最新的撇渣器对去年的样本进行了细微的改进，并继续有效地获取受害者输入到加载恶意 JavaScript 的页面上的任何形式的数据。

## 展望 XE 集团

Volexity 将 XE Group 的活动归因于越南威胁行为者，因为用于命令和控制服务器的几个域名是由越南人注册的。

虽然域名注册信息可以伪造，但研究人员使用同名人创建的 XE 头像将注册人 Joe Nguyen 链接到 GitHub 存储库。

![](../Images/bf8f4ec2101bd8ad3dd01b83d599e7ec.png)

此外，与 GitHub 存储库相关联的昵称“xethanh”还在 crdclub\[.\]su 论坛上有一个帐户，他们提供了被盗信用卡信息。

研究人员在诸如cybercarders\[.\]su 和cardingforum\[.\]co 等其他梳理论坛上发现了类似的帐户，因此攻击者更喜欢出售卡片而不是使用它们。

“用于 GitHub 和 carding 帐户以及几个域的角色的历史可以追溯到 2013 年，这表明攻击者可能已经尝试了长达八年的类似攻击，只有一次重要的公开提及他们的活动，”解释说 Volexity

最后，在 VirusTotal 中发现的一些恶意软件文件似乎是由越南用户上传的。攻击者通常在发起活动之前使用 VirusTotal 来测试防病毒软件检测其恶意软件的能力。

防御者可以使用提供的网络指标阻止 XE Group 攻击或使用这些签名检测威胁。
