# 14种新型浏览器攻击出现，影响谷歌、微软、苹果和火狐浏览器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247510255&idx=2&sn=06053e047ee8b2abfe179292d49994d0&chksm=fa3ae835cd4d61236844b88bc83b27abcf5ab931a19555ac0c2140009de104093984399a0844&scene=126&sessionid=1681375637#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247510255&idx=2&sn=06053e047ee8b2abfe179292d49994d0&chksm=fa3ae835cd4d61236844b88bc83b27abcf5ab931a19555ac0c2140009de104093984399a0844&scene=126&sessionid=1681375637#rd)

更多全球网络安全资讯尽在邑安全

![](../Images/51f2bd3eb21eee673e7a2c6d045067f4.png)

来自波鸿鲁尔大学 (RUB) 和 Niederrhein 应用科学大学的 IT 安全研究人员发现了 14 种针对现代网络浏览器的新型“XS-Leak”跨站点泄漏攻击，包括 Google Chrome、Microsoft Edge、Safari 和 Mozilla火狐。这些类型的旁道攻击称为“XS-Leaks”，允许攻击绕过 Web 浏览器中的“同源”策略，以便恶意网站可以在后台从用户输入信息的受信任网站窃取信息.“XS-Leak 的原理是使用网络上可用的此类侧信道来揭示有关用户的敏感信息，例如他们在其他网络应用程序中的数据、有关其本地环境的详细信息或他们所连接的内部网络，”解释了 XS-Leaks 维基。例如，XS-Leak 攻击可以帮助后台站点从用于访问网络邮件的活动选项卡中窃取电子邮件收件箱内容。

![](../Images/0d6e6c309ad6df4d8533a2ebae2b8b28.png)

跨站点泄漏并不新鲜，但正如研究人员指出的那样，并非所有泄漏都已被识别并归类为 XS 泄漏，其根本原因尚不清楚。

他们的研究旨在系统地搜索新的 XS-Leaks，评估潜在的缓解措施，并更好地了解它们的工作原理。

## 寻找新的 XS-Leaks

研究人员首先确定了跨站点泄漏的三个特征，并评估了大量 Web 浏览器的所有包含方法和泄漏技术。所有 XS-Leaks 的三个主要成分是包含方法、泄漏技术和可检测的差异。在基于上述创建模型后，研究人员发现了 34 个 XS-Leaks，其中 14 个是新颖的（下面用加号标记）。

![](../Images/e779d8433cf1f009c6724e6aaf7b694d.png)

接下来，他们针对 56 种浏览器和操作系统组合测试了 34 个 XS-Leak，以确定每个组合的脆弱性。  

然后他们构建了一个名为 XSinator 的 Web 应用程序，由三个组件组成：

1.  充当攻击者页面的测试站点，实施已知和新颖的 X-Leaks
2.  一个易受攻击的 Web 应用程序，它模拟依赖于状态的资源的行为。
3.  包含所有先前测试结果的数据库。

您可以自己访问XSinator 页面并运行测试以查看您的 Web 浏览器和操作系统在 34 X-Leaks 中的表现。

如何防御 X-Leaks

浏览器开发人员需要解决缓解或解决这些侧信道攻击带来的风险。研究人员建议拒绝所有事件处理程序消息，尽量减少错误消息的发生，应用全局限制限制，并在发生重定向时创建新的历史属性。其他有效的缓解方法是使用 X-Frame-Options 来防止 iframe 元素加载 HTML 资源并实现 CORP 标头来控制页面是否可以嵌入资源。“COIU，也称为第一方隔离 (FPI)，是一项可选的安全功能，用户可以在 FF 的专家设置 (about:config) 中启用，最初是在 Tor 浏览器中引入的。” - 从纸上。参与的研究人员之一 Lukas Knittel 告诉 Bleeping Computer：

> “根据网站的不同，XS-Leaks 会对用户产生严重影响。用户可以使用允许他们禁用第三方 cookie 的最新浏览器。这可以防止大多数 XS-Leaks，即使网站没有实施新的缓解措施，如 COOP、CORP、SameSite Cookies 等。” - 针织衫。

研究人员还表示，他们将他们的发现告知了网络浏览器开发团队，他们现在正在解决各种问题。在某些情况下，这些问题已在当前可用版本中得到修复。至于未来的工作，团队认为新的浏览器功能会不断增加新的潜在 XS-Leak 机会，因此这是一个持续关注的空间。此外，Knittel 告诉我们，他们可能会探索网站扫描工具的开发，但就目前而言，他们希望专注于确定这些缺陷在现实世界网站中的普遍程度。
