# Emotet 现在通过伪造的 Adob e Windows 应用安装程序包进行传播

Emotet 恶意软件现在通过伪装成 Adobe PDF 软件的恶意 Windows 应用安装程序包进行分发。

Emotet 是一种臭名昭著的恶意软件感染，它通过网络钓鱼电子邮件和恶意附件进行传播。安装后，它将窃取受害者的电子邮件用于其他垃圾邮件活动并部署恶意软件，例如 TrickBot 和 Qbot，这通常会导致勒索软件攻击。

Emotet 背后的威胁行为者现在通过使用 Windows 10 和 Windows 11 的内置功能 App Installer 安装恶意软件包来感染系统。

研究人员之前曾看到这种相同的方法被用于分发 BazarLoader恶意软件，它安装了托管在 Microsoft Azure 上的恶意软件包。

## **滥用 Windows 应用安装程序**

BleepingComputer 使用 Emotet 跟踪组Cryptolaemus共享的 URL 和电子邮件样本，在下面演示了新的网络钓鱼电子邮件活动的攻击流程。

这个新的 Emotet 活动从被盗的回复链电子邮件开始，这些电子邮件显示为对现有对话的回复。

这些回复只是告诉收件人“请参阅附件”并包含指向与电子邮件对话相关的所谓 PDF 的链接。

![](../Images/1c81f216c46eed901f90b3fae173a1ea.png)

单击该链接后，用户将被带到一个虚假的 Google Drive 页面，提示他们单击一个按钮来预览 PDF 文档。

![](../Images/498ab548d34d39e01136bcf72ab30797.png)

此“预览 PDF”按钮是一个 ms-appinstaller URL，它尝试使用 \*.web.core.windows.net 上的 URL 打开托管在 Microsoft Azure 上的 appinstaller 文件。

例如，上述链接将在以下示例 URL 中打开一个应用安装程序包：ms-appinstaller:?source=https://xxx.z13.web.core.windows.net/abcdefghi.appinstaller。

appinstaller 文件只是一个 XML 文件，其中包含有关签名发布者的信息和将安装的 appbundle 的 URL。

![](../Images/2be9f0ce0d0a661a0fa601e156f0ad78.png)

尝试打开 .appinstaller 文件时，Windows 浏览器将提示您是否希望打开 Windows App Installer 程序继续。

一旦您同意，您将看到一个应用安装程序窗口，提示您安装“Adobe PDF 组件”。

![](../Images/6389082ee1f0822041977553ec453f26.png)

该恶意程序包看起来像一个合法的 Adobe 应用程序，因为它有一个合法的 Adobe PDF 图标、一个将其标记为“受信任的应用程序”的有效证书以及虚假的发布者信息。来自 Windows 的这种类型的验证足以让许多用户信任应用程序并安装它。

一旦用户单击“安装”按钮，App Installer 将下载并安装托管在 Microsoft Azure 上的恶意 appxbundle。这个appxbundle会在%Temp%文件夹中安装一个DLL并用rundll32.exe执行，如下图。

![](../Images/5cf882815caccc962e9ede0e78bc5480.png)

此过程还会将 DLL 复制为 %LocalAppData% 中随机命名的文件和文件夹，如下所示。

![](../Images/5100640d21f518bcbf552ca497709c4f.png)

最后，将在HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run下创建一个自动运行，以在用户登录 Windows 时自动启动 DLL。

![](../Images/40c4dfb4e5f421f6f04ad402dbb5f09c.png)

Emotet 是过去分布最广的恶意软件，直到执法行动关闭并没收了僵尸网络的基础设施。10 个月后，Emotet 在 TrickBot 木马的帮助下开始重建时复活了。

一天后，Emotet 垃圾邮件活动开始了，带有各种诱饵和安装了恶意软件的恶意文档的电子邮件进入用户的邮箱。

这些活动使 Emotet 能够迅速建立自己的影响力，并再次执行安装 TrickBot 和 Qbot 的大规模网络钓鱼活动。

Emotet 活动通常会导致勒索软件攻击。Windows 管理员必须掌握恶意软件分发方法，并培训员工发现 Emotet 活动。
