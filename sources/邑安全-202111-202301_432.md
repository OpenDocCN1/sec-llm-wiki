# APT黑客越来越多地使用 RTF 注入进行网络钓鱼

更多全球网络安全资讯尽在邑安全

![](../Images/8426cc217dc0a438d732e6fa43636648.png)

观察到来自 APT 黑客组织在最近的网络钓鱼活动中使用了一种新颖的 RTF（富文本格式）模板注入技术。

这种技术是一种从远程 URL 检索恶意内容的简单而有效的方法，威胁分析师预计它很快就会覆盖更广泛的威胁参与者。

研究人员在2021 年 3 月发现了第一批武器化 RTF 模板注入案例，从那时起，参与者一直在稳步优化该技术。

## **一种获取有效载荷的简单方法**

富文本格式 (RTF) 文件是由 Microsoft 创建的一种文档格式，可以使用 Microsoft Word、写字板和几乎所有操作系统上的其他应用程序打开。

创建 RTF 文件时，您可以包含一个 RTF 模板，用于指定文档中文本的格式。这些模板是在显示文件内容以正确格式化之前导入到 RTF 查看器的本地文件。

虽然 RTF 模板旨在本地托管，但威胁行为者现在正在滥用此合法功能来检索 URL 资源而不是本地文件资源。

这种替换允许威胁行为者将恶意负载加载到 Microsoft Word 等应用程序中，或 针对远程 URL 执行 NTLM 身份验证 以窃取 Windows 凭据。此外，由于这些文件作为 RTF 模板传输，因此它们更容易绕过检测网络钓鱼诱饵，因为它们最初不存在于 RTF 文件中。

创建远程 RTF 模板非常简单，因为威胁行为者所要做的就是`{\*\template URL}`使用十六进制编辑器将命令添加到 RTF 文件中，如下所示。

![](../Images/1764151ff09db55ed3b492690efc7317.png)

该方法也适用于在 Microsoft Word 中打开的 doc.rtf 文件，强制应用程序在将内容提供给受害者之前从指定的 URL 检索资源，如下所示。

![](../Images/2a337e4d789edf6fe6827794bc7c5be6.png)

## **在野使用案例**

研究人员已经在亲印度黑客组织 DoNot Team、与俄罗斯有关联的 Gamaredon 黑客组织和 TA423 威胁参与者的网络钓鱼活动中观察到了这种有效载荷检索方法。观察到的活动的时间表如下所示。

![](../Images/72f216df1008df3f418014e82e033725.png)

RTF 文件可以解析 16 位 Unicode 字符，因此威胁行为者一直使用 Unicode 而不是纯文本字符串作为注入的 URL 资源来逃避检测。

![](../Images/029e4cd6330da2945c3605ba39755767.png)

但是，在 DoNot Team 活动检索到的一些样本中，研究人员 注意到未能通过 Microsoft Word 的检查，导致有关远程源无效的错误消息。由于这些错误是在诱饵内容提供给目标之前生成的，因此 DoNot 的网络钓鱼尝试成功的机会显着下降。另一方面，TA423 没有混淆注入的 URL，将更高的检测和分析风险交换为在 Microsoft Word 上无错误加载。

![](../Images/85f885b0468533dbe2d4eedfe1799d01.png)

最后，在 Gamaredon 的案例中，研究人员抽取了 RTF 文件，这些文件冒充乌克兰政府组织将 MP3 文件作为远程资源提供。

![](../Images/1c34b40a132d148e6551af6cde16d743.png)

由于 RTF 模板注入可以使用十六进制编辑工具轻松完成，并且不会被防病毒扫描程序严重检测到，因此它们将被威胁行为者更广泛地使用。“基于 XML Office 的远程模板文档的可行性已经证明，当与作为初始交付载体的网络钓鱼结合使用时，这种类型的交付机制是一种持久有效的方法，”Proofpoint 在他们的报告中解释道。“虽然这种方法目前被有限数量的 APT 参与者使用，但具有一系列复杂性，但该技术的有效性与其易用性相结合，可能会进一步推动其在整个威胁领域的采用。”此外，由于恶意内容是从远程 URL 检索的，因此它允许威胁参与者实时动态修改其活动以使用新的有效负载或不同的恶意行为。为了抵御这种威胁，您应该避免下载和打开通过未经请求的电子邮件到达的 RTF 文件，使用 AV 扫描仪扫描它们，并通过应用最新的可用安全更新来使您的 Microsoft Office 保持最新状态。Proofpoint 还共享了 YARA 签名，管理员可以使用这些签名来检测修改为包含远程 RTF 模板的 RTF 文件。
