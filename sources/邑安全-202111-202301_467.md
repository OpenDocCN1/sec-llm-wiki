# 由于服务器错误，一些特斯拉车主无法解锁汽车

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247509640&idx=1&sn=180cf7b38bc3e636f48c347894e65e07&chksm=fa3ae652cd4d6f448f60408c7fbfb91867f08230397563cf456224480d80c710d68b4060ef89&scene=126&sessionid=1681375657#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247509640&idx=1&sn=180cf7b38bc3e636f48c347894e65e07&chksm=fa3ae652cd4d6f448f60408c7fbfb91867f08230397563cf456224480d80c710d68b4060ef89&scene=126&sessionid=1681375657#rd)

由于公司服务器中断，全球一些特斯拉车主无法使用该应用程序解锁或与他们的汽车通信。

从美国东部时间下午 4 点左右开始，特斯拉车主在社交媒体上报告称，特斯拉应用程序在尝试与汽车通信时返回“500 服务器错误”。

![](../Images/8120e5fbe749620b93bb15c4dc3fdfc6.png)

这种中断会阻止车主使用该应用程序进入汽车，并且它会报告汽车的错误位置。

业主已在推特上向埃隆马斯克报告了这个问题，马斯克表示他正在调查此事。

![](../Images/9656c6a2355ed4ab92ca5cffc7be6390.png)

Teslamotorsclub 论坛上的车主也遇到了问题，称他们无法通过应用程序访问或解锁汽车。

“在田纳西州也一样。500 服务器错误。汽车仍然在工作，但我回家了，”特斯拉汽车俱乐部成员发帖说。

这种中断似乎是全球性的，美国、韩国、澳大利亚和欧洲的用户报告了类似的问题。

虽然某些 Tesla 车型可以使用手机通过蓝牙、钥匙卡或遥控钥匙解锁，但其他车型没有“电话钥匙”功能，只能通过应用程序打开。

Teslamotorsclub 论坛上的另一位车主表示：“不适用于 Model s 或 x - 他们没有电话键功能……应该节省 60k 并购买 Model s。”

也有报告称，车主损坏了遥控钥匙，无法再换一辆，因此不得不求助于使用该应用程序作为解锁汽车的唯一选择。

“我的钥匙坏了。我试图在特斯拉网站上订购另一个，但他们没有。我别无选择，只能使用我的手机。而且我有一辆 2020 年性能的特斯拉车型 .. 120k 汽车并且 60k 的 Model 3 具有密钥卡功能，”Teslamotorsclub 论坛上的另一篇文章写道。

“我有一个遥控钥匙，但今天早上它停止工作，迫使我依靠该应用程序度过一天。完美的风暴，”另一篇文章解释道。

美国东部时间晚上 9 点 11 分，马斯克在推特上说，意外的“网络流量的增加”导致了中断，服务器正在重新上线。

![](../Images/b40934363b420e0fe5bcbd016ac960b3.png)

目前尚不清楚究竟发生了什么导致服务器离线。

BleepingComputer 已就停电事宜联系了特斯拉，但尚未收到回复。
