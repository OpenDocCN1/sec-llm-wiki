# 英特尔曝出多款处理器存在高危漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247509387&idx=1&sn=89d509728456098e4e06f3917529be26&chksm=fa3ae551cd4d6c472fd1ae1512bd28036aa86d2aebb07fc6d5404b4de7f43889904943cec7a5&scene=126&sessionid=1681375657#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247509387&idx=1&sn=89d509728456098e4e06f3917529be26&chksm=fa3ae551cd4d6c472fd1ae1512bd28036aa86d2aebb07fc6d5404b4de7f43889904943cec7a5&scene=126&sessionid=1681375657#rd)

英特尔披露了两个影响范围广泛的英特尔处理器系列的高危漏洞，允许威胁行为者和恶意软件在设备上获得更高的特权级别。

这些漏洞是由 SentinelOne 发现的，被跟踪为 CVE-2021-0157 和 CVE-2021-0158，两者的 CVSS v3 得分均为 8.2（高）。

前者涉及某些英特尔处理器的 BIOS 固件中的控制流管理不足，而后者则依赖于对同一组件的不正确输入验证。

这些漏洞可能会导致机器上的特权升级，但前提是攻击者可以物理访问易受攻击的设备。

英特尔尚未就这两个缺陷分享许多技术细节，但他们建议用户通过应用可用的 BIOS 更新来修补漏洞。

这尤其成问题，因为主板供应商不会经常发布 BIOS 更新，并且不会长期为他们的产品提供安全更新。

考虑到第 7 代英特尔酷睿处理器在 5 年前问世，MB 供应商是否仍在为它们发布安全 BIOS 更新值得怀疑。

因此，一些用户将无法解决上述缺陷。

不幸的是，设置 BIOS 密码并不能完全保护您免受这种攻击，因为如果攻击者在系统上有立足点，这些缺陷也可以被远程利用。

SentinelOne 的Assaf Carlsbad告诉 BleepingComputer：

> 我们发现的漏洞是 LPE 漏洞，允许攻击者将他们的权限提升到 SMM。SMM 代码被认为具有很高的特权，通常与“外部世界”隔离。为了实现这种隔离，SMM 代码从它自己的内存空间运行，称为 SMRAM，操作系统既不可读也不可写。
> 
> 利用我们发现的漏洞，以操作系统级别权限运行的攻击者可以以受控方式触发 SMRAM 内存损坏。通过利用内存损坏，他们最终可以安装 BIOS 级别的植入程序，从而在受感染的设备上获得非常稳定和隐蔽的持久性。

## 第三个漏洞影响汽车

英特尔在同一天发布了一个单独的公告的第三个缺陷是 CVE-2021-0146，也是一个高严重性 (CVSS 7.2) 特权提升缺陷。

> “硬件允许在运行时激活某些英特尔(R) 处理器的测试或调试逻辑，这可能允许未经身份验证的用户通过物理访问实现特权升级。” - 英特尔的建议

此错误影响以下产品：

![](../Images/5d8fd198448f4870d3c8561d2669b2d0.png)

受影响的英特尔产品

英特尔已发布固件更新以缓解此缺陷，用户将通过系统制造商提供的补丁获得它。

Positive Technologies 发现了该漏洞并将其报告给英特尔，称该漏洞可能允许攻击者访问高度敏感的信息。  
  
“真正威胁的一个例子是丢失或被盗的笔记本电脑，其中包含加密形式的机密信息，”马克·埃尔莫洛夫说。

“利用这个漏洞，攻击者可以提取加密密钥并访问笔记本电脑中的信息。该漏洞还可用于整个供应链的针对性攻击。”

“例如，理论上，英特尔处理器设备供应商的员工可以提取英特尔 CSME 固件密钥并部署安全软件无法检测到的间谍软件。”

Positive Technologies 表示，该缺陷还影响了使用英特尔凌动 E3900 的多款车型，包括特斯拉 Model 3。

用户应应用设备供应商提供的 BIOS 更新来解决此缺陷，因此请定期查看制造商的网站。

请记住，在应用任何这些补丁之前，最好在单独的系统或可移动媒体上备份您的数据，因为更新总是有可能出现问题。这些缺陷主要影响工业和企业环境中的系统。许多人的物理访问。

至于汽车，这应该只能由将访问车辆内部结构的服务点和汽车修理工利用。
