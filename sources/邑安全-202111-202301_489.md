## 作为 10 月份开始的正在进行的活动的一部分，TeamTNT 黑客正在瞄准配置不佳的 Docker 服务器。

趋势科技研究人员报告称，TeamTNT 黑客的目标是配置不当的 Docker 服务器，将 Docker REST API 暴露为 10 月份开始的正在进行的活动的一部分。

攻击者执行恶意脚本来部署 Monero 加密货币矿工，使用众所周知的技术执行容器到主机的逃逸，并扫描 Internet 以查找来自其他受感染容器的暴露端口。

![](../Images/cf4ec571948d57c3e3ccbf08ad87c348.png)

攻击链始于使用暴露的 Docker REST API 在易受攻击的主机上创建容器。然后在威胁参与者的控制下从 Docker Hub 帐户下载恶意图像。对攻击中执行的脚本和用于运送矿工的工具的分析使研究人员能够将活动与 TeamTNT 联系起来。趋势科技发现了 TeamTNT 积极使用的主要 Docker Hub 帐户之一（“alpineos”），并且总共有超过 150,000 个恶意图像拉取。“这个容器是从“alpine”操作系统的官方镜像创建的，并使用允许底层主机上的根级权限的标志执行，除了base64编码的字符串在解码后通过管道传输到“bash” 。” 阅读趋势科技发布的分析。创建容器后，它会执行 cronjobs 并获取各种后开发工具和横向移动工具、容器转义脚本、rootkit、凭据窃取程序和矿工。威胁参与者还会扫描网络上的端口 2375、2376、2377、4243、4244，并尝试收集服务器信息，例如操作系统类型、容器注册表、架构、CPU 内核数量和当前群参与状态。专家注意到，该活动中使用的 IP 地址 45\[.\]9\[.\]148\[.\]182 之前与 TeamTNT 集团的运营有关。“我们  2021 年 7 月对 TeamTNT 的研究表明，该组织以前使用过凭证窃取器，可以从配置文件中窃取凭证。这可能是 TeamTNT 获取用于此次攻击中受感染站点的信息的方式。” 继续分析。在蒂岑茨僵尸网络是一个加密的恶意软件采矿操作四月以来到2020年该指标泊坞窗将安装一直活跃。 安全公司 Trend Micro详细介绍了 TeamTNT 小组的活动 ，但在 2020 年 8 月，来自 Cado Security 的专家 发现 该僵尸网络也能够针对配置错误的 Kubernetes 安装。2021 年 1 月，网络犯罪团伙  使用Hildegard 恶意软件发起了一项针对 Kubernetes 环境的新活动 。Chimaera 活动针对多个操作系统（Windows、不同的 Linux 发行版，包括 Alpine（用于容器）、AWS、Docker 和 Kubernetes）和应用程序，威胁参与者使用了广泛的 shell/批处理脚本、新的开源工具、加密货币矿工、TeamTNT IRC 机器人等。该活动非常阴险，截至 2021 年 8 月 30 日，攻击者使用的许多恶意软件样本的 AV 软件检测率仍然为零 。该运动在短短几个月内就造成了全球数千例感染。TeamTNT 不断改进其技术，以针对易受攻击的 Docker 安装。“最近的这次攻击只是突显了暴露服务器的目标越来越复杂，尤其是像 TeamTNT 这样有能力的威胁行为者，他们使用受损的用户凭据来实现其恶意动机。” 报告结束。
