# 微软11月补丁星期二活动：共修复55个漏洞，包括两个活跃的0Day漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyMzczNzUyNQ==&mid=2247509256&idx=1&sn=85e72bb80f89793374a8514210006db8&chksm=fa3ae5d2cd4d6cc40788609e195187a5a2110649f3cd6cdfa5bda2c7e2d986767340da12b90e&scene=126&sessionid=1681375657#rd](http://mp.weixin.qq.com/s?__biz=MzUyMzczNzUyNQ==&mid=2247509256&idx=1&sn=85e72bb80f89793374a8514210006db8&chksm=fa3ae5d2cd4d6cc40788609e195187a5a2110649f3cd6cdfa5bda2c7e2d986767340da12b90e&scene=126&sessionid=1681375657#rd)

更多全球网络安全资讯尽在邑安全

2021年11月9日，微软11月补丁星期二活动日，微软发布了一系列的安全更新，一共修复了55个漏洞，还包括两个正在被黑客积极利用的0Day漏洞。

其中，提权型漏洞数量最多，有20个，远程代码执行漏洞15个，信息泄露漏洞10个，余下还有拒绝服务漏洞、欺骗型漏洞和安全功能绕过漏洞。![](../Images/cb69a96f5685f51cc12b0a32d5915b22.png)

本次安全更新补丁涉及的主要是以下产品和服务：

Microsoft Windows and Windows Components, Azure, Azure RTOS, Azure Sphere, Microsoft Dynamics, Microsoft Edge (Chromium-based), Exchange Server, Microsoft Office, Office Components, Windows Hyper-V, Windows Defender，Visual Studio

据微软发布的漏洞更新报告，“Microsoft Exchange Server 存在一个身份验证漏洞(编号CVE-2021-42321 )，有可能会被黑客利用进行有限的针对性攻击，因此建议企业立即安装新的补丁，保护系统环境安全。该漏洞会影响本地 Microsoft Exchange Server，包括用户在Exchange 混合模式下使用的服务器，但Exchange Online 不会收到影响，无需采取任何行动。”

在本次修复的55个漏洞中，有6个关键性漏洞，49个严重漏洞，其中有4个漏洞是通过 ZDI程序公开披露。

从以往数据来看，11月安全更新的补丁数量相对处于历史低位。2020年平均每月发布的安全补丁数量是2021年11月的2倍多，即使是在2018年，全年发布的漏洞补丁也达到了691个，平均每月补丁数量也比11月多。

此外，微软在漏洞更新报告中着重提醒，Microsoft Exchange Server 和 Microsoft Excel中的两个0Day漏洞目前正在被黑客积极利用，应引起企业高度重视。![](../Images/5420f69960b289eff29943e41cc7d3e7.png)

以下是两个漏洞的信息：

CVE-2021-42321，Microsoft Exchange Server 远程代码执行漏洞，该漏洞是因为cmdlet 参数验证不当而导致的远程代码执行问题，曾在2021年的天府杯大赛中被使用，黑客可利用该漏洞破解身份验证。

CVE-202 1-42292，Microsoft Excel 安全功能绕过漏洞。这个一个代码执行漏洞，被Microsoft 威胁情报中心发现，并被黑客积极用于恶意攻击。受害者使用受影响的Excel 版本打开特制文件就会触发该漏洞。

其他四个公开披露的漏洞：

CVE-2021-38631  – Windows 远程桌面协议 (RDP) 信息泄露漏洞

CVE-2021-41371  – Windows 远程桌面协议 (RDP) 信息泄露漏洞

CVE-2021-43208  – 3D 查看器远程代码执行漏洞

CVE-2021-43209  – 3D 查看器远程代码执行漏洞
