两个每周下载量达 2200 万次的 NPM 软件包被发现存在后门

更多全球网络安全资讯尽在邑安全

在另一个针对开源软件存储库的供应链攻击实例中，发现每周累计下载量接近 2200 万的两个流行的 NPM 软件包通过未经授权访问各自开发人员的帐户而受到恶意代码的攻击。

有问题的两个库是“ coa ”，一个命令行选项解析器和“ rc ”，一个配置加载器，这两个库都被身份不明的威胁行为者篡改，包括“相同”的密码窃取恶意软件。

2.0.3 及以上版本的所有 coa 版本——2.0.3、2.0.4、2.1.1、2.1.3、3.0.1 和 3.1.3——都受到影响，建议受影响版本的用户降级根据11 月 4 日发布的 GitHub公告，尽快更新到 2.0.2 并检查他们的系统是否存在可疑活动。同样，发现 rc 的 1.2.9、1.3.9 和 2.3.9 版本存在漏洞带有恶意软件，并带有独立警报，敦促用户降级到 1.2.8 版。

对丢弃的恶意软件样本的进一步分析表明，它是一个 DanaBot 变体，它是一种用于窃取凭据和密码的 Windows 恶意软件，与上个月发生的两起类似事件相呼应，这些事件导致UAParser.js 被攻陷，并发布了盗版盗版Roblox NPM 库。

“为了保护您的帐户和软件包免受类似攻击，我们强烈建议您在 NPM 帐户上启用 [双因素身份验证]，”NPM在一条推文中说。
