# 医疗保健提供商Novant发出数据泄露警告,泄露的数据可能包括患者的电子邮件地址、电话号码和设备IP地址

> 美国医疗保健提供商Novant Health警告患者，由于Facebook背后的公司的在线跟踪工具配置不正确，可能导致数据泄露。Novant在北卡罗来纳州经营着50多家医疗机构，该公司表示，它在其网站上放置了一段JavaScript代码，作为冠状病毒大流行初期促销活动的一部分。该代码适用于Meta Pixel，这是一种数字跟踪工具，组织可以使用它来帮助他们衡量Facebook营销活动的成功与否。然而，该公司表示，有问题的跟踪像素“配置不正确，可能允许某些私人信息从Novant Health网站和患者门户传输到Meta”。

![](../Images/5b2b0343acdf6f5339adf548c76d50f0.png)

  

在最近的一份隐私声明中，Novant Health表示，一旦发现它有能力将信息传输到Meta，它就会立即删除该像素。

经过进一步调查，这家医疗保健提供者表示，根据用户在Novant Health网站和MyChart门户中的活动，泄露的数据可能包括电子邮件地址、电话号码、计算机 IP 地址和医疗预约信息。

“这些信息不包括社会安全号码或其他财务信息，除非用户将其输入到自由文本框中，”Novant说。

该公司表示，在发现像素配置错误后，它已向“一些患者”邮寄了信件。据当地媒体报道，已通知超过130万人。

Novant的新汉诺威地区医疗中心的患者不受影响。然而，该事件可能会影响其他未注册Novant Health患者但在 Novant设施接受Covid-19疫苗的个人。

“根据我们的调查，我们没有任何证据表明Meta或任何其他第三方根据这些信息采取了行动，”Novant说。

“我们还围绕像素的使用实施了更多的结构、治理和政策，并承诺我们将采取适当的行动，确保这种情况不再发生。”
