# Apache CouchDB 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzk1NjExMw==&mid=2247484626&idx=1&sn=097b448ef289c6cc2a951da92587aa86&chksm=fa76e52ccd016c3a5af7b77ab47fd8c2a3331683f0b724d4729144fddf9d7ce86b9b6c58bccf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyNzk1NjExMw==&mid=2247484626&idx=1&sn=097b448ef289c6cc2a951da92587aa86&chksm=fa76e52ccd016c3a5af7b77ab47fd8c2a3331683f0b724d4729144fddf9d7ce86b9b6c58bccf&scene=27#wechat_redirect)

> 近日，我团队监测到一则 Apache CouchDB 组件存在远程代码执行漏洞的信息，漏洞编号：CVE-2022-24706，漏洞威胁等级：高危。该漏洞是由于 CouchDB 默认安装配置存在缺陷，攻击者可利用该漏洞在未授权的情况下，构造恶意数据执行远程代码执行攻击，最终获取服务器最高权限。

![](../Images/206dad52bca0db3f76dc482d771e9fda.png)

  

Apache CouchDB 是一个开源数据库。它是一个使用 JSON 作为存储格式，JavaScript 作为查询语言，MapReduce 和 HTTP作为 API 的面向文档的 NoSQL 数据库。

 

**影响版本：**

Apache CouchDB <= 3.2.1

 

**修复建议：**

当前官方已发布最新版本，建议受影响的用户及时更新升级到最新版本。链接如下：

https://github.com/apache/couchdb
