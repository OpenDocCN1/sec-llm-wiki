# Google启用多项关键政策变化以提高Android生态安全性

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzk1NjExMw==&mid=2247484549&idx=1&sn=a8114aade27faf10662e436e9a693c1e&chksm=fa76e57bcd016c6d1065a65db5544010adbfe2cbd656d73cec9c136f6f3ac64010a1f1d2546c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyNzk1NjExMw==&mid=2247484549&idx=1&sn=a8114aade27faf10662e436e9a693c1e&chksm=fa76e57bcd016c6d1065a65db5544010adbfe2cbd656d73cec9c136f6f3ac64010a1f1d2546c&scene=27#wechat_redirect)

> Google 近日发布了针对 Android 应用开发者的几个关键政策变化，这将提高用户、Google Play 和该服务提供的应用的安全性。这些新的开发者要求将在 2022 年 5 月 11 日至 11 月 1 日之间生效，给开发者足够的时间来适应新变化。

![](../Images/c9ed370a0eb5e86e488061bb592106fb.png)

 

Android是一种基于Linux内核（不包含GNU组件）的自由及开放源代码的操作系统。主要使用于移动设备，如智能手机和平板电脑，由美国Google公司和开放手机联盟领导及开发。Android操作系统最初由Andy Rubin开发，主要支持手机。

 

**在这些关键政策变化中，与网络安全和欺诈有关的最重要的变化包括：**

*    新的 API 级别目标要求
    
*   禁止年利率（APR）为 36% 或以上的贷款应用程序。
    
*   禁止滥用 Accessibility API
    
*   对从外部来源安装包的权限进行新的政策修改
    

 

**新的 API 级别目标**

从 2022 年 11 月 1 日起，所有新发布/出版的应用程序必须以最新的主要 Android 版本发布后一年内发布的 Android API 级别为目标。那些未能遵守这一要求的应用将被拒绝列入 Play Store。

![](../Images/438706956cc9281214f41be6554f5227.png)

这一变化旨在迫使应用程序开发人员采用更严格的API政策，这些政策是较新的Android版本的基础，通常是更好的权限管理和撤销，通知反劫持，数据隐私增强，网络钓鱼检测，启动画面限制，以及其他。

 

**启动画面限制和其他**

![](../Images/b429ae46eb5d29a86c90951da64668aa.png)

正如Google在关于新政策的博文中解释的那样：“拥有最新设备的用户或那些完全赶上了Android系统更新的用户，期望实现Android系统提供的所有隐私和安全保护的全部潜力”。需要更多时间迁移到更多当前API水平的应用程序开发人员可以申请延长六个月，尽管这并不保证对每个人都适用。
