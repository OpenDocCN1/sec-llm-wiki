# AMD等四家公司宣布加入AlmaLinux OS基金会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyNzk1NjExMw==&mid=2247484344&idx=1&sn=345733a6364f2649f742d9bf5c448e88&chksm=fa76e246cd016b50af6a0e3e5ca6e6dfa775a9e1a41ea61ac42aee174071c5f72f7dfb503e8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzUyNzk1NjExMw==&mid=2247484344&idx=1&sn=345733a6364f2649f742d9bf5c448e88&chksm=fa76e246cd016b50af6a0e3e5ca6e6dfa775a9e1a41ea61ac42aee174071c5f72f7dfb503e8d&scene=27#wechat_redirect)

> AlmaLinux OS 基金会宣布，AMD、BlackHOST 和 KnownHost 三家公司以银牌会员级别加入，而 Sine Nomine Associates 以金牌级别加入。基金会希望这些新成员的贡献能够帮助 AlmaLinux 拉近 RHEL 的行业影响力。

![](../Images/bd707ee87f598d1459b403694133ebd1.png)

  

AlmaLinux 是在去年成立的，当时 Red Hat 公司决定扼杀 CentOS 项目，并以 CentOS Stream 取而代之，这是一种对 RHEL 的预览，而不是安装包兼容的构建。该发行版本的定位是“源于社区，服务于社区的自由 Linux 操作系统”，产品首页介绍中写道：

  

> AlmaLinux OS 是一个开源、社区驱动的 Linux 操作系统，它填补了因 CentOS Linux 稳定版本停止而留下的空白。AlmaLinux OS 是 RHEL® 的 1:1 二进制兼容克隆。由社区引导和建设。
> 
> 作为一个独立的、完全免费的操作系统，AlmaLinux OS享有 CloudLinux Inc 每年 100 万美元的赞助和其他赞助商的支持。正在进行的开发工作由社区成员管理。
> 
> AlmaLinux OS基金会是一个 501(c)(6) 非营利组织，旨在为 AlmaLinux OS社区带来利益。

  

主席 Benny Vasquez 在欢迎新成员的声明中说：“我们成立AlmaLinux操作系统基金会的具体目标是创建一个CentOS的继任者，让那些与操作系统的未来息息相关的人也能有发言权”。

  

AMD 表示，它加入 AlmaLinux 操作系统基金会是为了维持对其产品的支持。该公司看到其Epyc处理器在企业和高性能计算（HPC）领域的应用越来越多，因此对确保生产级企业Linux发行版在其处理器上顺利运行有兴趣。

  

Sine Nomine Associates是一家定制工程和开发公司，为大学、政府、银行和金融部门提供咨询和支持服务。该公司声称自己是在IBM大型机系统上使用Linux的虚拟服务器场概念的先驱者。

  

KnownHost是一家管理型虚拟主机供应商，因此在免费和开源的企业级Linux中占有一席之地，其首席运营官Daniel Pearson在一份声明中解释道：“虚拟主机在Linux上运行，AlmaLinux提供了一个干净的CentOS迁移路径和强大的社区参与。通过加入AlmaLinux操作系统基金会，我们将继续为我们的客户提供最好的虚拟主机技术解决方案”。

  

BlackHOST为企业和爱好者提供一系列的IT服务，但声称专门提供从1Gbps到100Gbps的不计费网络硬件，利用世界各地的数据中心和网络点。BlackHOST首席技术官Thomas Nuchatel说，他已经将AlmaLinux作为寻求虚拟私人服务器和专用服务器的客户的默认选择。
