# 郑州市网络安全协会承办2019年“网安联·中国行” 第三站走进河南郑州

![](../Images/08e262d6c97fcc6fbcd3aafa4901f6b5.png)

　　2019年7月17—20日，“网安联·中国行”2019年第三站走进河南郑州，开展网民网络安全感满意度调查活动调研与宣讲会、团体标准研讨会、省级网络空间安全标准化技术委员会联合组工作会议、党建工作学习交流会等系列活动。

　　“网安联·中国行”郑州站系列活动由全国信息网络安全协会联盟（网安联）主办，郑州市网络安全协会承办。网安联秘书长黄丽玲，河南省郑州市公安局网监支队副支队长孙毅、管理大队大队长洪建涛，郑州市网络安全协会秘书长胡俊涛，河南省网络营销协会秘书长孙震，河南省网络文化协会秘书长王亚军，以及来自陕西、山西、重庆、广西、广州、成都、南宁、金华、渭南等省市的网安联成员单位、网安（信安）标委会的领导和代表参加了活动。

![](../Images/3903fcdebe0d8012ed3e39c56cecf987.png)　　全国信息网络安全协会联盟秘书长黄丽玲向承办单位——郑州市网络安全协会颁发了牌匾，感谢郑州网安协会对活动的精心组织和服务。

  

系列活动丰富多彩，精彩纷呈：

  

**网民网络安全感满意度调查活动之考察、宣讲、调研**

作为“网安联·中国行”郑州站系列活动的重头戏，2019网民网络安全感满意度调查活动的宣传及推广活动形式多样，效果明显，掀起了河南全网全民参与调查活动的热潮。  

![](../Images/76f686ffa8220702a24d4ce3a66698c3.png)

![](../Images/7ba25443e9e62fda1c4891b4ed0cec0d.png)

　　2019年7月18日，2019网民网络安全感满意度调查活动调研座谈会在河南省郑州市新华中州国际饭店举行。调查活动各发起单位齐聚一堂，围绕如何全面落实调查活动工作目标，推进调查活动各项工作进行研讨和部署。河南省郑州市公安局网监支队副支队长孙毅、管理大队大队长洪建涛，河南省郑州市网络安全协会秘书长胡俊涛，河南网络文化协会秘书长王亚军，河南省网络营销协会副秘书长刘振坡，以及组委会领导和发起单位代表、媒体代表近40人出席会议。

![](../Images/d358538ba8f3c88bb29d451cad8b63d4.png)

　　孙毅副支队长代表郑州市公安局网监支队对调研会在郑州举办表示欢迎和祝贺。他表示，郑州市公安局网监支队将全力支持和指导协会做好调查活动各项工作，保障调查活动在郑州顺利推进，努力实现样本数据采集量达到河南网民总数1%的目标。

![](../Images/bf1ad5e1f60aeb63d8498911fe5490f9.png)

　　洪建涛大队长围绕调查问卷的设置、调查活动的宣传形式等提出了很多宝贵的建设性意见，得到与会代表的共鸣。

![](../Images/83fda447adfcb3738316307b558a59f2.png)

![](../Images/3ba7563b7c68fbeed37d72074ae90812.png)

　　郑州市网络安全协会、河南省网络营销协会、河南省网络文化协会的领导在会上表态，河南省的网络社会组织将强强联合，形成合力，努力实现样本达到网民总数1%的目标，力争在全国起到带头模范作用。

![](../Images/888bd6b895fd598d9b510835dec1f396.png)

7月17日，河南省网络营销协会在郑州师范学院举办了实地考察和宣讲会，对调查活动进行大力宣传和推广，得到当地政府部门、高等院校、互联网企业和传媒的关注。  

  

调查活动组委会领导和成员，调查活动发起单位、郑州市惠济区商务局、郑州师范学院就业指导中心的有关领导以及河南省网络营销协会会员代表，河南省电子商务创业孵化基地企业代表，网民代表和媒体代表等近50人参加了活动。

![](../Images/7167658a9b8c3bd7260cb3ef9f93259a.png)

　　与会领导和嘉宾参观了河南省电子商务创业孵化基地，实地考察了基地的部分公司。河南省互联网行业的迅猛发展尤其是电子商务的活跃给与会领导和嘉宾留下了深刻的印象，对河南省实现样本采集数达到网民总数1%的目标更加增强了信心。

![](../Images/9030c56c02da365a20eb0781a3c21b52.png)　　宣讲会上，与会领导、专家和媒体代表纷纷发言，就调查问卷的设计、调查活动的宣传推广、样本数据的采集等问题进行了热烈讨论，对如何更好开展调查活动提出很多建议意见。大家一致表示，要通过线上线下多种方式积极参与调查活动，努力实现样本数据采集的大数据和高质量。

  

****《网络安全服务机构等级评定规范》团体标准研讨会****

  

2019年7月18日，正值“网安联·中国行”郑州站活动期间，《网络空间安全服务机构等级评定规范》团体标准编制组召开研讨会，对标准征集意见的处理等有关情况进行讨论，拟定了相关的事项。

![](../Images/0c2c4d8d63ccba67a9c97d14bf6ba117.png)

　　会议介绍了该团体标准的编制进度，通报了标准自5月份以来在全国公开征求意见的结果，以及中国计算机学会计算机安全专委会主任、公安部第一研究所原所长严明等专家对意见处理的建议和意见，听取了广东协会、成都协会对标准有关内容的说明。与会代表对标准征求意见汇总表做了认真研究，围绕如何对这些意见进行处理进行了详细讨论，提出了具体的处理意见。

  

********党建工作学习交流会暨红色教育基地参观活动********

  

“网安联·中国行”到哪里，党建工作就到哪里！这是“网安联·中国行”活动的一大特色。2019年7月19日，全国信息网络安全协会联盟组织全国部分网络社会组织负责人和党员，齐聚兰考焦裕禄纪念园，开展党建工作学习交流会暨红色教育基地参观活动，学习焦裕禄精神，不忘初心，牢记使命，共同做好网民网络安全感满意度调查等网络社会治理各项工作。  

![](../Images/ff481c101cd62cdb642b88e91a64e029.png)

　　郑州市网络安全协会、河南省网络营销协会、河南省电子商务创业孵化基地、以及来自北京、广东、重庆、成都、广西、陕西渭南等省、市网络社会组织的负责人和党员代表参加了学习活动。

![](../Images/5b97202dc09e2150928b91b5849e2a4a.png)

参加活动的全体人员向焦裕禄同志烈士陵墓敬献花圈，参观了焦裕禄同志纪念园和焦桐纪念园，听取了焦裕禄同志事迹讲解，深入学习焦裕禄同志亲民爱民、艰苦奋斗、科学求实、迎难而上、无私奉献的精神。与会的党员同志，在北京网络空间安全协会流动党员党支部书记黄汝锡的带领下，集体重温入党誓词。大家纷纷表示，一定要把学习焦裕禄精神贯彻到实际工作中，坚定信心，踏实工作。结合当前的工作，要以关切网民切身利益、提升网民安全感和满意度为出发点，切实做好2019网民网络安全感满意度调查活动的各项工作，为促进互联网健康发展、造福广大人民群众做出自己的贡献。

  

三天的“网安联·中国行”郑州站活动，给大家留下了美好而深刻的印象，活动圆满成功！
