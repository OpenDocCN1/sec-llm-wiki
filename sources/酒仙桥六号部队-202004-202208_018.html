栈溢出原理

程序内存栈是从高地址往低地址分配内存的，正因如此，当程序在栈中，某个变量写入的字节超过了这个变量本身所申请的字节数时，会改变其他相邻变量的值，轻则可以使程序崩溃，重则可以使攻击者控制程序执行流程。

利用

#include <stdio.h>void success() { printf("You Hava already controlled it."); }void vulnerable(){  int val = 0;  char s[10];  gets(s);  if (val == 1)    printf("hunzi\n");}int main(int argc, char **argv){  vulnerable();  return 0;}
