漏洞描述

近日，酒仙桥六号部队监测到开源堡垒机JumpServer发布更新，修复了一处远程命令执行漏洞。只要是由于JumpServer某些接口未做授权限制，攻击者可构造恶意请求获取敏感信息，或者执行相关操作控制其中所有机器，执行命令（系统有个批量命令执行的功能，会记录taskid到log中，利用前面读取log的漏洞可以获取taskid进行重放）。对此，建议广大用户做好资产自查以及预防工作，以免遭受黑客攻击。

影响版本


l JumpServer < v2.6.2

l JumpServer < v2.5.4

l JumpServer < v2.4.5

l JumpServer = v1.5.9

安全版本

JumpServer >= v2.6.2JumpServer >= v2.5.4JumpServer >= v2.4.5JumpServer = v1.5.9（版本号没变）

修复方案

1. 将JumpServer升级至安全版本.

2. 对当前产品的控制台登录IP地址进行白名单限制。
