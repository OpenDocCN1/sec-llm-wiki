内存监控命令之iotop命令
1
概述：

iotop命令 是一个用来监视磁盘I/O使用状况的top类工具。iotop具有与top相似的UI，其中包括PID、用户、I/O、进程等相关信息。Linux下的IO统计工具如iostat，nmon等大多数是只能统计到per设备的读写情况，如果你想知道每个进程是如何使用IO的就比较麻烦，使用iotop命令可以很方便的查看。



2
安装方法：
 Ubuntu  :
    apt-get install iotop 
CentOS  :
    yum install iotop



3
常用命令格式：

iotop（选项）


4
命令参数：
-o：只显示有io操作的进程 
-b：批量显示，无交互，主要用作记录到文件。 
-n NUM：显示NUM次，主要用于非交互式模式。 
-d SEC：间隔SEC秒显示一次。 
-p PID：监控的进程pid。 
-u USER：监控的进程用户。

5
使用实例：


01

实例：

直接执行iotop就可以看到效果了：

命令：

iotop

输出：


说明：
第一行READ和WRITE速率总计；
第二行：  
tid：线程id，按p可转换进程pid  
PRIO：优先级  
DISK READ：磁盘读取速率  
DISK WRITE：磁盘写取速率  
SWAPIN：swap交换百分比  
IO>：IO等待所占用百分比  
COMMAND：线程/进程详细信息

6
交互指令：
 
  1. 左右箭头：改变排序方式，默认是按IO排序。
  2. r：改变排序顺序。
  3. o：只显示有IO输出的进程。
  4. p：进程/线程的显示方式的切换。
  5. a：显示累积使用量。
  6. q：退出。
