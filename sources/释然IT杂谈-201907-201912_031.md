# 黑苹果安装教程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMTEyOTM2Ng==&mid=2247486443&idx=1&sn=b07c86d61d5fb53ae655c83fcbd39902&chksm=975b4e92a02cc784a60ae77d1426967d6fcf99f28b40b4e6a6967ad5e1f8efcbd71bd35463b2&scene=126&sessionid=1681667597#rd](http://mp.weixin.qq.com/s?__biz=MzIxMTEyOTM2Ng==&mid=2247486443&idx=1&sn=b07c86d61d5fb53ae655c83fcbd39902&chksm=975b4e92a02cc784a60ae77d1426967d6fcf99f28b40b4e6a6967ad5e1f8efcbd71bd35463b2&scene=126&sessionid=1681667597#rd)

![](../Images/986189fe2b621f8efe913493a3dc1ac8.png)

安装准备：

1：VMware Workstation Pro v15.0.0  
2：解锁工具Unlocker v3.0.0  
3：macOS Mojave 10.14懒人版

![](../Images/031cffb7d51b40c36bfd55c448ecfd0c.png)

1： 关闭所以与VMware相关的后台进程，为后续步骤做准备工作。

![](../Images/75330feb5193112023773e66e5d50154.png)

   
2：进入Unlocker v3.0.0解锁工具目录下，找见win-install.cmd右键以管理员身份运行，运行完毕后会自动关闭

![](../Images/7159b0a40a5445a25ccbac1e90b31818.png)

3：打开VMware软件，新建一个虚拟机，我这里选择的是“典型”安装方式。

![](../Images/dcca27983be2c872477fee879d7b8ebb.png)

4：安装来源选择已经下载好的macOS Mojave 10.14，注意浏览的时候文件类型要选择所有文件，不然找不到macOS Mojave 10.14 18A391 Lazy Installer.cdr 

![](../Images/cc7da6fc48f0c0515752162f81059526.png)

  

![](../Images/8ba1a84a2edd23fee52f50784d443f22.png)

5：这里如果没有以上的解锁操作，选项里是没有apple mac os可选的，这里系统版本选择macOS10.14

![](../Images/5e824d11dd1282e4adf8a093f794168a.png)

6：由于安装后系统配置文件比较大，所以我们把默认位置改成非系统盘的其他盘符。

![](../Images/193dfb893d230d9c3ce7c1870616a643.png)

7：开启虚拟机，等待进度加载完毕

![](../Images/090ccdf9301125800789f2647558fd2e.png)

8：系统语言选择简体中文，选择同意条款，继续安装。

![](../Images/ddfbcf0a6ef13ea22dd43c5ea21e8ad4.png)

![](../Images/c63108ca5c987739d5edc7e169cc1c4b.png)

9：这一步选择上面“实用工具”里的磁盘工具

![](../Images/b1f8a1603d4958bfc42e430d33f4525a.png)

10：单击左侧的vmware虚拟硬盘，然后找到上方的“编辑”-“抹掉”，名称就叫mac os吧 

![](../Images/71c3fe3f7058f6d2c8e7a12deb75bf71.png)

![](../Images/73fb1b8e4309c78769a653387d019954.png)

11：关闭磁盘工具，右侧会多出我们刚才分出来的一个磁盘，选择这个磁盘并继续。

![](../Images/0ee4f0233a346fa885d15536c4205444.png)

12：等安装完成后，地域选择中国，键盘选择简体中文，不传输信息，apple id 稍后设置，选择跳过，设置登陆的用户名和密码。

![](../Images/ad52e5280531c59fa7e7c94da024d0b6.png)

![](../Images/4b622bdc32fb775a46ff8e701288aab4.png)

![](../Images/09dd016a8ce80012346020466544fa83.png)

![](../Images/8ffd0dd171c96c0780d34eda0ace72e1.png)

![](../Images/5ef3192a0b8454aa52b27214e607875d.png)

13：全部设置完毕即可进入系统  

![](../Images/f39183c992b7792cc6f2df298b10bbd9.png)

14.调整分辨率问题，点击右下角设置，进入后选择辅助功能，选择显示器，打开显示器偏好设置，选择缩放，最后设置虚拟机显示器拉伸模式

![](../Images/f1a50d6b82a74dfd16d9b9f9a611b559.png)

![](../Images/581ece6889eb6d32eb5d80ffa0ed80f4.png)

![](../Images/a9f47fe1266b1f75cc840382145e3fd1.png)

![](../Images/9bc14d35eeb520c2201c6cbd6f3dddce.png)

![](../Images/cf7c6d0675dccca0153de15ac9bceb4e.png)

![](../Images/d022354b4c0230b4857fea970bd1a6bd.png)

![](../Images/80dc55cf8d3f748ee8b2ac495d4bce50.png)

15.设置黑苹果上网功能，初始状态无法上网，首先设置本地网卡共享上网，然后黑苹果内dhcp就可以自动获取上网了。  

![](../Images/972a8e544997740140d9be58820d1987.png)

![](../Images/8363978b2b4d5d6e1f5f0711ccbee4fa.png)

![](../Images/26a4b268cd55c56b644aa8e5057d4adc.png)
