# 越长大，越庸俗

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMTEyOTM2Ng==&mid=2247486304&idx=3&sn=3c7473201b3a4949587d2513feeb61e8&chksm=975b4e19a02cc70f91ccfcf716f847a6acb269e9a78e1cc52da5b2ac2d4aeed88e0763e7cbd7&scene=126&sessionid=1681667601#rd](http://mp.weixin.qq.com/s?__biz=MzIxMTEyOTM2Ng==&mid=2247486304&idx=3&sn=3c7473201b3a4949587d2513feeb61e8&chksm=975b4e19a02cc70f91ccfcf716f847a6acb269e9a78e1cc52da5b2ac2d4aeed88e0763e7cbd7&scene=126&sessionid=1681667601#rd)

![](../Images/81ec46da056079e8801f4400173e167b.png)![](../Images/67538aee5c6bc451b46da1c730398d60.png)不知道从什么时候开始，朋友圈已经远离了现实人。![](../Images/67538aee5c6bc451b46da1c730398d60.png)

  

今天无聊刷朋友圈，点进去翻了半小时，竟没有一条真正的情绪，大约都是些微商的广告、晒单、鸡汤。

  

记得之前刚注册微信的时候，一天都要发好几条朋友圈，拍自己走过的路、欣赏的景，说身边有趣的人、好玩的事，哪怕只是看到个笑话，都想要与大家一起分享。

  

那时候的我们，通过朋友圈，便可以知道对方的行程，心情。看他们发定位，拍照片，就知道是去了某地旅游玩耍；看他们晒美食，秀厨艺，就觉得很有生活气息；看他们发心情，讲笑话，就在下面留言评论哈哈哈嘎嘎嘎……

![](../Images/25ef35f6f390943c2aec870df3a27f33.png)![](../Images/63e50051a3ed6d47db4fd2902aebf2ce.png)![](../Images/33a2e806d422d2a20d2628a644ba68c6.png)

那一段时间，我们的朋友圈才是真正的朋友圈。我们相互评论，点赞，互动，转发，甚至还对看似无聊的圈人游戏青睐有加。

  

可现在，我们的朋友圈，除了微商，就是广告，还有那些被粉饰过的，特意保留下来，想展示给大家的东西。

  

可这还是我们想要的朋友圈吗？

  

![](../Images/81ec46da056079e8801f4400173e167b.png)![](../Images/67538aee5c6bc451b46da1c730398d60.png)我们的朋友圈，就要这样完蛋了吗？![](../Images/67538aee5c6bc451b46da1c730398d60.png)

  

通讯录中有一千多位好友，静静的在那里躺尸。

有一些没有备注的，甚至都不知道是谁。

想当年刚加上的时候，也是亲密无间的好友吧。

而现在，就连对方的名字也很难再想起来了。

**有些人，就这么悄无声息的，淡出了我们的世界。**

**猝不及防，却又顺理成章。**

  

想起了最近很流行的一句话：

不努力，你当初背井离乡干嘛？当卧底吗？

那我们的呢？

不联系，当初加好友干嘛？卖信息吗？

  

慢慢的，慢慢的，好像连我们自己也一样，在朋友圈不悲不喜，不骄不嗔，没有任何情绪，没有任何感想，甚至很久都没有一点更新。

  

因为微信和QQ不同，微信在线头像不会变亮，不会显示状态，朋友也收不到提醒。

  

所以很多时候，我们都不知道对方是否在线。

  

**所以很多时候，因为等不到回复，而逐渐凉了心。**

  

**所以很多时候，因为怕打扰所以不联系，又因为久不联系，更没有打扰的理由。**

  

**大概人和人之间的感情，就是这样慢慢变淡的吧。**

  

![](../Images/81ec46da056079e8801f4400173e167b.png)![](../Images/67538aee5c6bc451b46da1c730398d60.png)我们对过去的幼稚行为冷眼旁观，却也怀念不已。![](../Images/67538aee5c6bc451b46da1c730398d60.png)

  

**当初发朋友圈都是圈谁一起玩，可如今发朋友圈都是选谁可以看。**

  

**越来越多的三天可见，半年可见，越来越多的分组设置，群发屏蔽。**

  

**我们之间的关系，不知道怎么了。**

  

**也不知道从什么时候开始，每个人都越来越酷了。**

  

**冷酷的酷。**

  

![](../Images/de2fc81d19c7b59c32c22e3110bb9f6c.png)![](../Images/326f3d6c380f98bad20b3b7ccd9cb0fa.png)

  

我们把自己的世界上了锁，不许外人进来，也不许自己出去。

  

所以慢慢的，慢慢的，我们也习惯了这样的生活。

  

戴上面具之后，是另一个自己。

  

可长时间不撕掉面具，你还记得之前的自己什么样吗？

  

越长大，越庸俗。

  

寡言少语，心机深沉。

  

我不希望你也变成自己年轻时候，最讨厌的模样。
