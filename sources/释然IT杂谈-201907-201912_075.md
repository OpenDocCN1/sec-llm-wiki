# VMware之ESXI6.5安装部署

****【安装配置】****

**1****.**如果是服务器安装**，可以采用服务器的管理口进行安装，也可以用光盘、U盘甚至PXE等，然后选择响应的启动方式，截图如下：**

![](../Images/0cf1038064e7011282fa76b9d5a57a96.png)

**2.启动引导过程可以看到主机的配置，截图如下：**

![](../Images/7ca904df91ef94bdf7856afeed5eab19.png)

![](../Images/d8edb6c420af605806c29740d7c521e0.png)

**3.按回车继续，截图如下：**

![](../Images/d489970aaa9665d5e8622396baf9589a.png)

**4.按F11接受许可协议，截图如下：**

![](../Images/ea96a92c43bfd46501f8794399a244a7.png)

**5、选择磁盘信息，并按Enter键确认，截图如下：**

**![](../Images/8f68d7e52df03c63e35944a02050f67b.png)**

**6.选键盘类型，保持默认美式键盘，单击“回车”键确认，截图如下：**

**![](../Images/d6124bafd869d74b812cddb151e58fac.png)**

**7.设置ESXI控制台密码,密码要求7位以上，截图如下：**

![](../Images/eaecb9c5ac29f4a956568b72be093ec5.png)

**8.按F11键确认安装，截图如下：**

![](../Images/5fc7e857d43ff8a0323a22b9fd2c327d.png)

**9.安装进行，截图如下：**

![](../Images/3a98171a2f022cdfe647a0bf62c4de25.png)

**10.安装完成，按“回车”键重启进入ESXI6.5，截图如下：**

![](../Images/370eae9acf31581738677ccd23b54b9b.png)

**【设置ESXI网络信息】**

**1.重启以后默认是dhcp，需要根据需求更改IP地址，截图如下：**

![](../Images/134f79ed0825389dd54e49c54cd02a58.png)

**2.按F2键进入配置，截图如下：**

![](../Images/8de74fcb370e8ac8a4de9fd23506f637.png)

**3.切换至Configure Management Network，按“回车”键，截图如下：**

![](../Images/68388c20184d1208c743146789542aaa.png)

**选项说明：****Configure Password                         配置root密码****Configure Lockdown Mode              配置锁定模式。启用锁定模式后，除vpxuser以外的任何用户都没有身份验证权限，也无法直接对ESXi执行操作。锁定模式将强制所有操作都通过vCenter Server执行。****Configure Management Network      配置网络****Restart Management Network          重启网络****Test Management Network              使用Ping命令测试网络****Network Restore Options                 还原网络配置****Configure Keyboard                         配置键盘布局****Troubleshooting Options                  故障排除设置****View System Logs                            查看系统日志****View Support Information                 查看支持信息****Reset System Configuration              还原系统配置**

**4.选择IPv4 Configuration，按“回车”键，截图如下：**

![](../Images/7217a2004b2abd4930942305b2d54edf.png)  

**选项说明：****Network Adapters            网卡选择****VLAN（optional）            设置VLan****IPv4 Configuration           设置IPv4地址****IPv6 Configuration           设置IPv4地址****DNS Configuration           设置DNS地址****Custom DNS Suffixes        自定义DNS后缀**

**5.按上下键定位到第三项按空格键选中，设置静态IP地址、掩码、网关的信息，按“回车”键，截图如下：**

![](../Images/15cc436722434de72c3702f5abdecd4c.png)

**选项说明：****Disable IPv4 configuration for management network         禁用IPv4地址****Use dynamic IPv4 address and network configuration       配置动态IPv4地址****Set static IPv4 address and network configuration             配置静态IPv4地址**

******6.按“Exit”退出配置，提示网络配置信息变更，提示保存。************按“Y”保存，截图如下：******

![](../Images/226931ee3e3c8b27d3e9edd497f0719d.png)

**********【登陆与许可】**********

**********************1.登陆管理界面，并输入用户名和密码，截图如下：**********************

![](../Images/704671db54710e831583b6250310856c.png)

**2.登上去以后可以看到相关服务器信息，截图如下：**

![](../Images/1ebbeeae497968b55e97f9daf3ed3b23.png)

****3.定位到管理——许可——分配许可证，在弹出的窗口中输入KEY，单击检查许可证完成分配即可，截图如下：****

![](../Images/7a3e04b7110a1e513549ab22482d48b6.png)
