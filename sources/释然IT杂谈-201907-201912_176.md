**一、zabbix安装过程：**

**1、ls /etc/yum.repo.d //查看存在的源**

![](../Images/04046c60dc97cfb0bbfc0512369a8962.png)

  

**2、安装zabbix必须的应用 yum install mariadb-server httpd php **

![](../Images/786df1650d331a4eca96525cdc954462.png)

  

**3、安装前最好把所有的mysql和mariadb文件全部清除，不然可能会有无法启动数据库的问题**

**find / -name mariadb\*  **

**rm -rf ..........                  **

**find / -name mysql\*     **

**rm -rf ............               **

  

**配置mariadb（这里要注意当加入二进制日志或数据库引擎有可能mariadb无法启动的情况）**

  

**      编辑：/etc/my.cnf.d/server.cnf在mysql下增加如下内容**

![](../Images/17a7dd9019d2b19853935beb5b5473bc.png)

** \[mysqld\]**

** log.bin=master.log //配置数据库二进制日志，如果不开启数据库二进制日志，数据库不能使用热备份，只能使用冷备份**

** innodb\_file\_per\_table=ON //开启数据库引擎，让数据库的每个表单独一个文件存在**

** skip\_name\_resolve=ON //不去尝试解析主机名，不然客户端连接可能出现问题**

  

**4、安装zabbix：**

 **yum -y install zabbix-server-mysql zabbix-web-mysql zabbix-agent**

![](../Images/8b85eaf36acdd5675c3f9f0be927c783.png)

  

**5、创建zabbix数据库**

 **create database zabbix character set utf8 collate utf8\_bin;   //创建zabbix数据库并设置字符集为utf8**

** grant all privileges on zabbix.\* to zabbix@localhost identified by 'zabbix';  //创建用户并授权用户具有这个数据库的管理权限**

** grant all privileges on zabbix.\* to zabbix@'127.0.0.1' identified by 'zabbix';**

** grant all privileges on zabbix.\* to zabbix@'22.22.22.%' identified by 'zabbix'; //授权远程用户**

![](../Images/57cc0521a27917cee9dd5fbd01768f41.png)

  

**6、导入zabbix数据库表**

 **zcat /usr/share/doc/zabbix-server-mysql\*/create.sql.gz | mysql -uzabbix -p zabbix **

**          //在root目录下执行zabbix脚本导入数据库表**

![](../Images/a1d4cb2b1f6cae71a99d282d1895fe81.png)

  

**7、zabbix调用数据库**

 ** 编辑：/etc/zabbix/zabbix\_server.conf**

![](../Images/5e38f4b16c9e7f717731dc2004d66774.png)

** \# DBHost=localhost    //本地主机，数据库授权时已授权**

** DBPassword=zabbix     //密码**

**启动zabbix服务：systemctl start zabbix-server**

![](../Images/9ba2a5415ed23505458fe38939962fa3.png)

  

**8、修改httpd**

  **编辑：/etc/httpd/conf.d/zabbix.conf**

![](../Images/843ba4908d6853ad3f0f54154618b49d.png)

**php\_value date.timezone Asia/Shanghai  //把时期修改成上海即可**  

![](../Images/6f6ceeafbe94447c0aa1a8710919ffc3.png)

  ** 启动httpd服务：systemctp start httpd**

![](../Images/8285aab75510417c04bd4dba01702557.png)

  

**9、客户端（这里注意要数据库授权）**

 **编辑：/etc/zabbix/zabbix\_agentd.conf**

**![](../Images/307901fb0449211097fec8fa1d72c693.png)**

**Server=127.0.0.1 //改成服务器IP地址**

![](../Images/4b955fa76f737d88212e206c9acd64f5.png)

 **ServerActive=127.0.0.1 //主动监控修改为服务器IP地址即可**

![](../Images/306f19676db2171671cb820e0de702e6.png)

 **Hostname=Zabbix server //改成服务器主机名**![](../Images/d451bd152ca76543da702b7b319373fe.png)

**启动：systemctl start zabbix-agent.service  **

**//这个服务不必须启动，当服务器自己要监控自己时候要启动**

![](../Images/1964936b6573576f5770555f8695101f.png)
