作者 / 快乐的骚年，编辑 / sitinhttps://www.cnblogs.com/sukai/archive/2013/06/08/3127031.html本文作为知识分享，如有侵权，请后台留言删文**1\. sl 命令**  
你会看到一辆火车从屏幕右边开往左边……安装

```
$ sudo apt-get
 install sl
```

运行

```

$ sl
```

命令有 -a l F e 几个选项，

```
\-a An accident seems to happen. You ll feel pity for people who cry for help.

\-l shows little one.

\-F It flies.

\-e Allow interrupt by Ctrl+C.

```

  

![](../Images/1c08fc0beb3718b62ad890eb96adef9b.png "img")可以给别人来个恶作剧，他一敲ls，不知道的肯定很有效果

```
$alias ls=sl
```

**2\. fortune 命令**输出一句话，有笑话，名言什么的 (还有唐诗宋词sudo apt-get install fortune-zh)安装

```
$sudo
 apt-get install fortune
```

运行

```
$fortune
```

  
![](../Images/c83b9b3c6bf5b0ac73f243583f77d1b4.png "img")**3\. cowsay 命令**用ASCII字符打印牛，羊等动物，还有个cowthink，这个是奶牛想，那个是奶牛说，哈哈，差不多安装

```
$sudo
 apt-get install cowsay
```

运行

```
$cowsay "I am not a cow, hahaha"

```

  

![](../Images/6927514c67b0b4232d9b98d30a57807e.png "img")$cowsay -l 查看其它动物的名字，然后 -f 跟上动物名，如

```
$cowsay -f tux "坑爹啊"
```

  
![](../Images/35b638d225dfb9176077a0cf2686ec56.png "img")还可以让cowsay说出fortune的内容，就像这样：

```
$fortune
 | cowsay
```
