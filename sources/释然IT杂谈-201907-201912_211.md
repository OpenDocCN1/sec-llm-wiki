**网卡的命名规则**

![](../Images/41584af5dbdc1f6726fd05058e41848b.png)**在centos7中，en表示着：ethernet以太网，即现在所用的局域网，enX（X常见有以下3种类型）**

  

| 

**enX的三种类型**  


 |
| --- |
| 

**o**  


 || 

主板板载网卡，集成设备的设备索引号  


 |
| 

**p**

 || 

独立网卡，PCI网卡

 |
| 

**s**

 || 

支持热插拔网卡，usb之类，扩展槽的索引号

 |

  

**网卡后面的数字表示：MAC地址+主板信息计算得到的唯一序列**

  

  

**IP地址的临时修改（重启后失效）**

![](../Images/41584af5dbdc1f6726fd05058e41848b.png) 

1

**查看网络接口的状态**

  

**ifconfig**

  

![](../Images/0c2dbde8c6ed7758190b43ba05c52dc9.png)

2

**使用命令**

  

**ifconfig ens33 192.168.1.64 netmask 255.255.255.0 **

**#将ens33的IP改为192.168.1.64**

  

![](../Images/80f70772cb6cfc517acaa08c75143039.png)  

  

3

**重启网卡**

  

**service network restart #centos6的重启网卡的命令**

  

![](../Images/ece90332fb89c83a33699c54cf792709.png)

  

**systemctl network restart #centos7的网卡重启**

  

![](../Images/c1cf7553d16b9093020f59cbb8da0de2.png)  

**添加多个临时IP**

![](../Images/41584af5dbdc1f6726fd05058e41848b.png)

  

1

**增加临时IP命令**

  

**ifconfig ens33:0 192.168.1.64 netmask 255.255.255.0 up**

  

2

 **查看网卡信息**

  

**ifconfig**

  

3

**删除临时IP**

  

**ifconfig ens33:0 del 192.168.1.64，经过ifconfig，未发现ens33:0的信息**

  

![](../Images/feb5da68ba8435863d450bd33d7567ff.png)![](../Images/83a01196c3eb80d185be8e8e1b2da9d7.png)

  

**NeworkManager**

![](../Images/41584af5dbdc1f6726fd05058e41848b.png)  
  

**NeworkManager服务是管理和监控网络设置的守护进程，CENTOS7更加注重使用NetworkManager服务来实现网络的配置和管理，7.0以前是通过network服务管理网络，以后的版本，所有网络管理和设置统一由NetworkManager服务来维护。它是一个动态的，事件驱动的网络管理服务。**  

  

1

1

**启用编辑连接**

![](../Images/45bf7d54b314f63952fa644ff43bc9b8.png)

  

2

**选择合适的网卡，进入到对应的编辑模式**

![](../Images/1a0df1a76de8ef6e3c45d8be0507a298.png)

  

3

**修改自己的网卡信息**

![](../Images/ed7149d7199b963526782c02e65570f6.png)

  

4

**记得点击确定哦，然后一步步返回**

![](../Images/704021fe83dd7880a142cbed2fda1bcb.png)

  

**最后别忘了重启网卡服务：systemctl network restart**

  

**方法2：修改网卡的配置文件**

  

1

**输入命令**

  

**vim /etc/sysconfig/network-scripts/ifcfg-ens33**

  

![](../Images/5d9848fbabcf47a8ace42aa5a61664e0.png)  

  

2

**按下“ESC”，然后按下“wq!”,修改成功**

  

**最后别忘了重启网卡服务：systemctl network restart**

  

**关于上述配置文件的参数解释**  

  

| 

参数

 || 

解释

 |
| --- | --- |
| 

DEVICE

 || 

此配置文件应用到的设备

 |
| 

HWADDR

 || 

对应的设备的MAC地址

 |
| 

BOOTPROTO

 || 

激活此设备时使用的地址配置协议，常用的dhcp, static, none,bootp

 |
| 

NM\_CONTROLLED  


 || 

NM是NetworkManager的简写，此网卡是否接受NM控制；建议CentOS6为“no”    

 |
| 

ONBOOT

 || 

在系统引导时是否激活此设备    

 |
| 

TYPE

 || 

接口类型；常见有的Ethernet, Bridge    

 |
| 

UUID

 || 

设备的惟一标识    

 |
| 

IPADDR

 || 

指明IP地址    

 |
| 

NETMASK  


 || 

子网掩码    

 |
| 

GATEWAY

 || 

默认网关    

 |
| 

DNS1

 || 

第一个DNS服务器指向    

 |
| 

DNS2

 || 

第二个DNS服务器指向    

 |
| 

USERCTL

 || 

普通用户是否可控制此设备  

 |
| 

IPV4\_FAILURE\_FATAL  


 || 

如果为yes，则ipv4配置失败禁用设备    

 |
