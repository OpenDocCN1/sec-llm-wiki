# 省吾身，觅将来

“一问”

为什么还在迷茫?  
问自己?  
做好的规划呢?  
好长时间也没用心去努力了  
好多目标,各种计划  
还在坚持的就只有每天翻几页书  
却也是翻着,翻着,然后过会就忘了  
做好的学习计划呢?  
也是三分钟热度  
总也不能坚持太久  

  

“一省”

干活的时候  
又觉得好多事不屑去做  
却又不能往更高去进阶  
卡在半中间  
高不能,低不就  
却还总在抱怨  
抱怨自己  
抱怨自己不思进取  
然后匆匆三分钟热度  
然后就没有然后了  

  

“二省”

自认为自带信息  
却不知信息不对称  
信息闭塞，空洞  
自己还能做什么？  
不装系统？  
自己现在这么混乱不堪  
又怎能再去给予别人?  
自由协作？  
人际交往不在行  
不能很好的融入  
不懂得为人处事之道  
不明待人接物的圆滑  
自以为是  
躲在自己的空间  
又怎能谈得上自由协作？  

  

“三省”

这些年懒散惯了  
对各种事物的不屑  
盲目自大  
总还沾沾自喜  
看看以往  
看看现在  
路是自己一步一步走的  
坑也是自己慢慢挖的  
前面的路  
是荆棘,是坦途  
也不再重要  
都是自己选的  
是跌倒  
是翻身  
随遇而安就好  

  
“觅将来？”  

看看过去,看看现在  
也不是一直停留  
学会了安静  
不再玩世不恭  
学会了释怀  
不再耿耿于怀  
学会思考  
懂得了思考自己的以后  
以后?  
对的,以后  
不说如何如何  
最少现在学会了思考  
不奢望一鸣惊人  
能进步足矣  

  

未来!
