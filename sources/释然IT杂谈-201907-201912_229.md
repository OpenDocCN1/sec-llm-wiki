# 安卓手机安装Kali Linux

**必备条件：**

*   **手机已root，储存空间要大。**
    
*   **VNC 远程。**
    
*   **linux deploy // 在android设备上安装运行Linux操作系统的APP，遵循GPLv3协议。**
    
*   **juicessh     // 目前我用过的最好用的手机ssh工具。**
    
*   **busybox**
    

  

**0x00:**

**下载linux deploy，安装好，语言设置为中文。**

![](../Images/5a41dadd6411c960fdef6c413c0a2ec2.png)

  

**点击那三个点点，有个状态，选择。****会出来一些路径，记住这个红色框中的。**

![](../Images/ab1b03abfe5e4cdab8923561c11e03a9.png)

  

  

**然后点那个向下的箭头，发行版选择kali，版本sana，架构我是arm的，按照自己的手机选择，安装路径要注意，我在根目录建了一个名为kali的文件夹。****Linux.img是镜像，**

![](../Images/d62dbd2a250ea88f2067a0ecae7177a4.png)

  

**用户名android，密码changeme，，我没有改。****这里设置好之后然后点击安装开始linux安装，这个时候因为网络的原因下载镜像会出错（我找到了kali linux镜像，可以直接复制进去）然后关闭软件，把kali镜像文件复制进那个kali文件夹就行了。**  

  

  

  

**0x01:**

**打开linux deploy，启动，后台运行，然后打开****juicessh，新建立连接，名称android，地址127.0.0.1 ，类型ssh，端口22。****如图:**

![](../Images/9fcd2cdfe00362a781ad790c36daa8bb.png)

  

  

**SSH链接之后是这样的，若是密码就是ssh没设置对，Nmap,sqlmap,msf等都可以用**

![](../Images/1e11b28eeab998658ea33ed6f219ecf2.png)

![](../Images/0ee4e489476940c906cd262d0c1f5a5d.png)

  

  

**VNC链接就不在试了，，****同理，backtrack也是这样，这俩镜像一同分享出来，那几个软件可以百度直接下载的**
