■ 任务背景

大型企业网络的结构时常发生变化，OSPF路由器需运行SPF算法来重新计算路由信息，大量消耗路由器的CPU和内存资源，随着多条路径的增加，路由表变得越来越庞大，每一次路径的改变都使路由器不得不花大量的时间和资源去重新计算路由表，路由器变得越来越低效，且有可能使路由器的CPU和内存资源彻底耗尽，从而导致路由器的崩溃。
工程师对该企业的实际情况进行了分析，决定把OSPF大型区域划分成多个更易管理的小型区域，区域之间交换路由汇总信息，而不是每一个路由的细节，划分小型区域后可实现OSPF的工作更加流畅。

■ 相关知识

1、OSPF区域容量
划分多区域后，每个OSPF区域里到底可以容纳多少台路由器呢？单区域所支持的路由器的数量范围是30-200，考虑网络拓扑的稳定性、路由器的内存、CPU性能等参数的影响，区域内实际加入的路由器数量应能容纳的最大数量，一个区域里包含25台路由器可能都已经显得比较多了。
2、OSPF多区域的配置方法
OSPF路由器多区域与单区域配置方法相同，需要注意的是需分清路由器所属的区域。同一个设备的不同接口可能属于不同的区域，注意设置区域，配置方法如下：
首先配置骨干区域：
（1）启用OSPF协议，自定义进程号，比如： OSPF 1 
（2）指定OSPF的区域，骨干区域0。比如：area 0  
（3）在路由器的接口公布网段和反掩码。
然后配置其他区域，如区域1：
（1）启用OSPF协议，自定义进程号，比如： OSPF 1，不同区域进程号可以相同
（2）指定OSPF的区域，非骨干区域1。比如：area 1
（3）在路由器的接口公布网段和反掩码。
需要注意的是，所有区域必须与骨干区域直接相连，才能相互学习到路由信息。


■ 实施步骤


一、Cisco 设备实施步骤

1.实验拓扑：

2.基础配置与IP编址

给所有路由器配置IP地址和掩码。配置时注意所有的Loopback接口配置掩码均为24位，模拟成一个单独的网段。
R1:

Router>en
Router#conf t
Router(config)#host R1
R1(config)#int e0/0
R1(config-if)#ip add 10.0.0.1 255.255.255.0
R1(config-if)#no shut
R1(config-if)#int e0/1
R1(config-if)#ip add 10.0.1.1 255.255.255.252
R1(config-if)#no shut
R1(config-if)#int lo 0
R1(config-if)#ip add 1.1.1.1 255.255.255.0

R2:

Router>en
Router#conf t
Router(config)#host R2
R2(config)#int e0/0
R2(config-if)#ip add 10.0.0.2 255.255.255.0
R2(config-if)#no shut
R2(config-if)#int lo 0
R2(config-if)#ip add 2.2.2.2 255.255.255.0   

R3:

Router>en
Router#conf t
Router(config)#host R3
R3(config)#int e0/0
R3(config-if)#ip add 10.0.0.3 255.255.255.0
R3(config-if)#no shut
R3(config)#int lo 0
R3(config-if)#ip add 3.3.3.3 255.255.255.0


R4:

Router>en
Router#conf t
Router(config)#host R4
R4(config)#int e0/1
R4(config-if)#ip add 10.0.1.2 255.255.255.25
R4(config-if)#no shut
R4(config-if)#int e0/0
R4(config-if)#ip add 10.0.2.1 255.255.255.252
R4(config-if)#no shut
R4(config-if)#int lo 0
R4(config-if)#ip add 4.4.4.4 255.255.255.0

R5:

Router>en
Router#conf t
Router(config)#host R5
R5(config)#int e0/0
R5(config-if)#ip add 10.0.2.2 255.255.255.252
R5(config-if)#no shut
R5(config-if)#int lo 0
R5(config-if)#ip add 5.5.5.5 255.255.255.0

步骤二. 配置多区域OSPF


R1:


R1(config)#router ospf 1
R1(config-router)#network 10.0.0.0 0.0.0.255 area 1  //R1的e0/0口宣告进area 1区域
R1(config-router)#network 10.0.1.0 0.0.0.3 area 0   
R1(config-router)#network 1.1.1.0 0.0.0.255 area 0   //R1的e0/1和lo0口宣告进area 0 区域

R2:

R2(config)#router ospf 1
R2(config-router)#network 10.0.0.0 0.0.0.255 area 1
R2(config-router)#network 2.2.2.0 0.0.0.255 area 1
//R2的e0/0和lo0都宣告进area 1 区域


  R3:

R3(config)#router ospf 1
R3(config-router)#net 10.0.0.3 0.0.0.255 area 1
R3(config-router)#net 3.3.3.0 0.0.0.255 area 1
//R3的e0/0和lo0都宣告进area 1 区域

R4:

R4(config)#router ospf 1
R4(config-router)#net 10.0.1.0 0.0.0.3 area 0
R4(config-router)#net 4.4.4.0 0.0.0.255 area 0
R4(config-router)#net 10.0.2.0 0.0.0.3 area 2
//R4的e0/1和lo0宣告进area 0 区域， e0/0接口宣告进area 2 区域

R5：

R5(config)#router ospf 1
R5(config-router)#net 10.0.2.0 0.0.0.255 area 2
R5(config-router)#net 5.5.5.0 0.0.0.255 area 2
//R5的e0/0和lo0都宣告进area 2 区域


步骤三. 配置完成后测试

 1、R1上查看路由表

该路由器上已拥有全网所有的路由条目。

2.在R1使用show ip ospf neighbor命令查看路由器的OSPF邻居关系建立情况


3、在R1上测试到其他路由器Loopback接口的连通性。

至此实验完成  


二、华为设备实施步骤

1.实验拓扑：

2.基础配置与IP编址

给所有路由器配置IP地址和掩码。配置时注意所有的Loopback接口配置掩码均为24位，模拟成一个单独的网段。
AR1:

<Huawei>sys
[Huawei]sys AR1
[AR1]int g0/0/0
[AR1-GigabitEthernet0/0/0]ip add 123.0.0.1 24
[AR1-GigabitEthernet0/0/0]int g0/0/1
[AR1-GigabitEthernet0/0/1]ip add 14.0.0.1 30
[AR1-GigabitEthernet0/0/1]int lo 0
[AR1-LoopBack0]ip add 1.1.1.1 24

AR2:

<Huawei>sys
[Huawei]sys AR2
[AR2]int g0/0/0
[AR2-GigabitEthernet0/0/0]ip add 123.0.0.2 24
[AR2-GigabitEthernet0/0/0]int lo 0
[AR2-LoopBack0]ip add 2.2.2.2 24

AR3:

<Huawei>sys
[Huawei]sys AR3
[AR3]int g0/0/0
[AR3-GigabitEthernet0/0/0]ip add 123.0.0.3 24
[AR3-GigabitEthernet0/0/0]int lo 0
[AR3-LoopBack0]ip add 3.3.3.3 24


AR4:

<Huawei>sys
[Huawei]sys AR4
[AR4]int g0/0/0
[AR4-GigabitEthernet0/0/0]ip add 45.0.0.1 30
[AR4-GigabitEthernet0/0/0]int g0/0/1
[AR4-GigabitEthernet0/0/1]ip add 14.0.0.2 30

<Huawei>sys
[Huawei]sys AR5

[AR5-GigabitEthernet0/0/0]ip add 45.0.0.2 30
[AR5-GigabitEthernet0/0/0]int lo 0
[AR5-LoopBack0]ip add 5.5.5.5 24

步骤二. 配置多区域OSPF


AR1:

[AR1] ospf 1
[AR1-ospf-1]area 0
[AR1-ospf-1-area-0.0.0.0]net 14.0.0.0 0.0.0.3
[AR1-ospf-1-area-0.0.0.0]net 1.1.1.0 0.0.0.255
[AR1-ospf-1-area-0.0.0.0]q
[AR1-ospf-1]area 2
[AR1-ospf-1-area-0.0.0.2]net 123.0.0.0 0.0.0.255
//R1的g0/0/0口宣告进area 2区域
//R1的g0/0/1和lo0口宣告进area 0 区域

AR2:

[AR2]ospf 1
[AR2-ospf-1]area 2
[AR2-ospf-1-area-0.0.0.2]net 2.2.2.0 0.0.0.255
[AR2-ospf-1-area-0.0.0.2]net 123.0.0.0 0.0.0.255
//R2的g0/0/0和lo0都宣告进area 2 区域

  AR3:

[AR3]ospf 1
[AR3-ospf-1]area 2
[AR3-ospf-1-area-0.0.0.2]net 123.0.0.0 0.0.0.255
[AR3-ospf-1-area-0.0.0.2]net 3.3.3.0 0
//R3的g0/0/0和lo0都宣告进area 2 区域

AR4:

[AR4]ospf 1
[AR4-ospf-1]area 1
[AR4-ospf-1-area-0.0.0.1]net 45.0.0.0 0.0.0.3
[AR4-ospf-1-area-0.0.0.1]q
[AR4-ospf-1]area 0
[AR4-ospf-1-area-0.0.0.0]net 4.4.4.0 0.0.0.255
[AR4-ospf-1-area-0.0.0.0]net 14.0.0.0 0.0.0.3
//R4的g0/0/1和lo0宣告进area 0 区域，g0/0/0接口宣告进area 1 区域

AR5：

[AR5]ospf 1
[AR5-ospf-1]area 1
[AR5-ospf-1-area-0.0.0.1]net 5.5.5.0 0.0.0.255
[AR5-ospf-1-area-0.0.0.1]net 45.0.0.0 0.0.0.3
//R5的e0/0和lo0都宣告进area 1 区域


步骤三. 配置完成后测试

 1、AR1上查看路由表

该路由器上已拥有全网所有的路由条目。

2.在AR1使用dis ospf peer brief 令查看路由器的OSPF邻居关系建立情况

3、在AR1上测试到其他路由器Loopback接口的连通性。


至此实验完成
