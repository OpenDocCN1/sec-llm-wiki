# 实战社工之套路某群小姐姐

**文章来自粉丝安然投稿：**  

  

我已经不记得这是被多少人拉黑了,事情的起因是这样的,近来划水的我,无意间在群聊中看到一个妹子推荐一个妹子的卡片,听她说是在网上加的陌生好友,听说想找对象,于是单身的我听到这个消息便来了兴趣

![](../Images/0becf77526766b5f0eec10510c39380f.png)

  

打开妹子的名片一看,我直接一声好家伙,看她开着朋友圈,封面的海澜之家太显眼了,于是我马上进去翻了一遍朋友圈,发现她只开了只能查看一个月内的朋友圈

![](../Images/edab7231b6a99e59eb005f65f6e7e3c3.png)

  

心中一想,海澜之家,那不是男人的衣柜嘛,一个女孩子关注这个干啥,后来翻了记录才知道是帮她朋友整的,做推广而已

![](../Images/80f92117321b086d2380fca478daa1ac.png)

  

看了看朋友圈也没什么有价值的信息,于是我准备加她好友,看看她是不是网上那种绿茶来养鱼的

![](../Images/ff3fcd8cadf76fa738ca8a9f4c8adae2.png)

近来的网络诈骗和网恋杀猪盘也比较多,出于个人习惯,我一向对这方面比较敏感,心中一想不能这样,咋要做好准备和她对线.

![](../Images/3d7cc6f8b2ece10472c4913576aea49e.png)

很幸运,妹子同意添加我为好友,于是一场社工战役立马打响,这里我们用的是透明头像和昵称,我们要思考女生的心里,女孩子一般对于好玩的事物是比较感兴趣的,所以想要她对你感兴趣,首先你得让她提起兴趣,不知道她是不是没见过我这种透明的风格让她起了兴趣

![](../Images/ee50729041df1152051e735d20f08320.png)

我们成功的加到对方好友,一上来就是你好,好家伙,小姐姐还是挺热情的,难不成是射手座吗?

![](../Images/78a28864748f9ce69519995dcfec53f7.png)

嘿嘿嘿,怎么样,这个方法好使不,加到你列表里面如果不备注的话,不仔细看都发现不了你的存在,这样可以降低我们在目标列表的存在感,可以提高隐蔽性,同时也是为了吸引小姐姐的好奇心,下面咱们开始套话

![](../Images/51fe657ca13d3b7355109f2311e9f1a6.png)

  

![](../Images/05e5723d1cb6a4026b634f337b9c2de2.png)

小姐姐还是比较好撩的有没有,这里我们知道了她的小名,我们可以大胆的猜测下,这个小名会不会是姓或者名简洁的谐音字,我们继续套她的信息,这里先套一下她有没有对象什么的,工作是干嘛的,看看她是不是传说中的绿茶

![](../Images/d7c6ab30f2504c74494c8c45920f5f13.png)

  

这里我们知道了她好像还没有对象,但我也不确定,这里我想套她一下,有没有在网上的相亲网站上注册啥的,好套取她的用户名去搜素一番,但是很遗憾的是她没有注册啥相亲网站,不知道是有还是没有,我没有套出来,这里得知她去上班的时候,我们可以隔断时间去套话,这样才显得我们是正常加她聊天的,而不是去套路她的,网上再怎么样,人的警觉性还是有的,所以我们等到了她下班再套话

![](../Images/3f62a51323b57d05b25df1e2a3660a3d.png)

一开始我以为朋友圈的背景图片是网图,没怎么注意,但我也不确定是不是她的照片,不得不说,打扮打扮还是挺好看的,

![](../Images/c519f5b5d81c69ed2571ce91e097ed2d.png)

这里我们继续按情节走,这么点情报可不够整的,这里我们套了她是做什么的,她那边的一些基本情况,懂得都懂,这里我就不放图了,免得小姐姐的信息泄露被骚扰就不好了,这里我们基本的第一流程结束了,得到了小姐姐的基本信息和情况,看起来不像网上那些绿茶妹啊,一般绿茶妹都是想尽办法说情话让你沉迷于她,要不就是套路你为她花钱,做不到的立马会被拉黑,这里我们可以肯定小姐姐不是那种网上的绿茶,但是我出于好奇,继续套她话,也不太确定小姐姐到底是不是绿茶,心想万一她是装的呢?

![](../Images/a6dc7373c58149ff2e8386db83a65cc0.png)

这里我们知道了她生病了,直男的我于是去网上找了渣男语录,好好学习了一番,我们可以假借她生病可以多关心一下她,套近乎而已,让她慢慢放下对我们的警戒心,不过我发了几条,没回我,我.......

![](../Images/db4fd2722c2e0b23b5d0446a9e586383.png)

见她没回,便放下手机去整理收集的信息了,一开始咋们就知道她是哪里人,只是不知道具体的位置罢了,其实是看群里的妹子聊天说的,嘿,我可真是个小机灵鬼.

![](../Images/9a19e676c3791af664054ad83b1c9db9.png)

第二天一大早,我就发消息问她在干嘛,她回复我在公园散步,我一看立马精神了,终于回消息了,针对于现有的信息我根本不满足,实在是太模糊了,所以我又针对性的冲她喜欢玩这一点上下手

![](../Images/34edc1a11ea141d6eecc77c828a53a6e.png)

她说她在公园遇到了一个很丑的人让她很害怕,现在的女生都是颜控吗?直男落泪...

![](../Images/b0cd272b61b29951fc5e3573fbf5455d.png)

这里我就替男同胞感到不爽了,但是又不能说她颜控,所以我就假借说她照片长得像男人为理由,看看她到底有没有说谎,之前只是觉得是网图,不太像,但是我用ai识图也没有搜索出来,结果她拍了个.....emmm

![](../Images/55b203c87b26d314398d98fc563dddd7.png)

心里顿时一群cnm路过,...小姐姐还是有一定的警觉性的,于是我们套路她有没有玩过一些常见的娱乐软件。。。

![](../Images/41bcacda10e9b5e79543423de071fe85.png)

果然小姐姐都喜欢玩抖音,哈哈哈,这里我们套出了她的抖音号,我们又继续套路她还玩不玩其他的,比如qq,微博等等..

![](../Images/fe8b1634549d7f63588d46016de022c5.png)

这里得到了小姐姐得微博,我们立马去搜索了抖音号和微博,我们发现抖音号里面没有什么有价值的信息,不过头像和她朋友圈的照片好像,不过戴了一副眼镜,这难道是她真实的照片吗?我们又去翻了微博,我一看直呼一声好家伙,啥都有,照片,地址啥的,

![](../Images/66b13eeeb58da946ad2ef85b3caf779b.png)

怎么样,小姐姐好看不,嘿嘿嘿,希望小姐姐看到这篇文章不会顺着网线过来捶我,毕竟我这小身板可不抗揍,我们拿到了微博的uid之后我又去裤子里跑了一下..

![](../Images/eaeb553b60363bda748da44650f7eb47.png)

拿到了小姐姐的手机号了,我又去搜索了下微信,发现这个号码的确是她的手机号码,接着我们去支付宝搜索了一下

![](../Images/10a546a79ceb77269cdd91dd8597ace0.png)

往死了打码,毕竟小姐姐的信息不能泄露,不然小姐姐肯定会被骚扰的,然后我有盲猜了身份证信息,我又去找了个实名验证的接口跑了下,得到了全名和身份证信息,

![](../Images/de1e7dfa2c3b2ab123566b75980a9f98.png)

小姐姐还是忍不住问我是做什么的,但是我们已经拿到了她所有的信息,而她却浑然不知,这样的情况是非常危险的,万一被某些不法分子拿到的话那可真就不好了,于是我便善意的提醒了她

![](../Images/3a8ddfa8c3efd13778f7f3d1e78d4293.png)

小姐姐还表示不相信,于是我将我拿到的手机号码发给了她,结果.....

![](../Images/1eec7da447e9d0c5083989695632979a.png)

这是不是已经到了拉黑的边缘了。。我可是真是个作死小能手啊。哈哈。。

![](../Images/e2badd878d67402a017aa5d73a182d4c.png)

最后我还是和小姐姐说明了情况,告诉她这样很危险,但是结果令我万万没想到....

![](../Images/3128a17d20225b90be42569000d9007b.png)

不得不说这小姐姐还是挺有意思的,希望各位看官不要像我一样去社工或者套路妹子的个人信息,真的会被她讨厌的,经常被妹子拉黑的我已经习以为常了,没想到的是这个妹子竟然没有拉黑我,我可真是够幸运的,本人的社工方法也没有技术含量,还望各位大佬不要喷我,就当作一篇水文看看吧.
