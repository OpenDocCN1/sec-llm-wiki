## 2、目标：

将/home磁盘空间缩减  并将新的磁盘分区扩充到/根目录

卸载/home分区并压缩分区

卸载/home时 提示目标忙，`fuser -m /home`查看谁用`/home`时提示没有`fuser`命令

`[root@localhost zabbix]# umount /home      umount: /home：目标忙。   `

(有些情况下通过 lsof(8) 或 fuser(1) 可以找到有关使用该设备的进程的有用信息)

`[root@localhost zabbix]# fuser -m /home      -bash: fuser: 未找到命令   `

解决没有fuser命令的问题：

在CentOS/RHEL 7上找不到`fuser`命令

`-bash: fuser: command not found       yum install psmisc    `![](../Images/b208141d48067d02aa144e20499e4f74.png)`fuser -m /home   //继续查找谁在用/home   `![](../Images/765984509855802eacde9d0c75bf4d92.png)`kill -9 11757    //停止进程      umount /home    //卸载/home文件系统   `![](../Images/4e461e4be4a5325bc88653026d5a612b.png)

压缩分区：

`resize2fs -p /dev/mapper/centos-home 100G   `![](../Images/86b057a981f179c3965d8b2e3289695e.png)

确认是xfs格式系统

`cat /etc/fstab|grep centos-home   `![](../Images/9c651b1031d4c2482251e5d0b7c2caec.png)

xfs文件系统扩容必须安装`xfsdump`工具

`yum install xfsdump -y   `

减少`/home`空间到100GB，增大根目录，延伸/目录空间

![](../Images/e498eb686036d521c6807845e156e665.png)![](../Images/dfe2a3c81647203a6370abc2f2d42027.png)![](../Images/40ca07b6575c35e80c7643d649351445.png)

然后重新挂载`/home`

`[root@localhost ~]# mount /home      mount: /dev/mapper/centos-home：不能读超级块   `必须格式化/home分区，才能挂载----所以缩减/home分区之前必须备份/home的内容（切记！！！）![](../Images/4f1cf75d6d6944be40ec474bf21b58d6.png)
