二、华为单区域OSPF配置案例


实验拓扑：

采用ensp模拟实验

1.初始化设备，配置设置IP

【PC】

【R1】

<Huawei>sys

[Huawei]sys R1

[R1]int g0/0/2

[R1-GigabitEthernet0/0/2]ip add 172.16.1.254 24

[R1-GigabitEthernet0/0/2]int g0/0/1

[R1-GigabitEthernet0/0/1]ip add 172.16.20.1 24

[R1-GigabitEthernet0/0/1]int g0/0/0

[R1-GigabitEthernet0/0/0]ip add 172.16.10.1 24

【R2】

<Huawei>sys

[Huawei]sys R2

[R2]int g0/0/2

[R2-GigabitEthernet0/0/2]ip add 172.16.2.254 24

[R2-GigabitEthernet0/0/2]int g0/0/1

[R2-GigabitEthernet0/0/1]ip add 172.16.30.1 24

[R2-GigabitEthernet0/0/1]int g0/0/0

[R2-GigabitEthernet0/0/0]ip add 172.16.10.2 24

【R3】

<Huawei>sys

[Huawei]sys R3

[R3]int g0/0/2

[R3-GigabitEthernet0/0/2]ip add 172.16.3.254 24

[R3-GigabitEthernet0/0/2]int g0/0/1

[R3-GigabitEthernet0/0/1]ip add 172.16.30.2 24

[R3-GigabitEthernet0/0/1]int g0/0/0

[R3-GigabitEthernet0/0/0]ip add 172.16.20.2 24


2.全局下开启OSPF,定义OSPF进程号，定义Route ID,定义OSPF区域号,单区域必须是AREA 0

【R1】

[R1]ospf 1 router-id 1.1.1.1  

[R1-ospf-1]area 0

[R1-ospf-1-area-0.0.0.0]

【R2】

[R2]ospf 1 router-id  2.2.2.2

[R2-ospf-1]area 0

[R2-ospf-1-area-0.0.0.0]

【R3】

[R3]ospf 1 router-id  3.3.3.3

[R3-ospf-1]area 0

[R3-ospf-1-area-0.0.0.0]


3.宣告自己的直连网段

【R1】

采用标准的网段反掩码方式宣告


[R1-ospf-1-area-0.0.0.0]network  172.16.1.0 0.0.0.255

[R1-ospf-1-area-0.0.0.0]network 172.16.10.0 0.0.0.255

[R1-ospf-1-area-0.0.0.0]network 172.16.20.0 0.0.0.255

【R2】

采用精确的ip宣告，默认会把ip所属的网段宣告进去路由表


[R2-ospf-1-area-0.0.0.0]network 172.16.2.254 0.0.0.0

[R2-ospf-1-area-0.0.0.0]network 172.16.10.2 0.0.0.

[R2-ospf-1-area-0.0.0.0]network 172.16.30.1 0.0.0.0

【R3】

采用接口方式宣告，前提是全局必须创建ospf进程及区域


[R3]int g0/0/0

[R3-GigabitEthernet0/0/0]ospf enable 1 area 0

[R3-GigabitEthernet0/0/0]int g0/0/1

[R3-GigabitEthernet0/0/1]ospf enable 1 area 0

[R3-GigabitEthernet0/0/1]int g0/0/2

[R3-GigabitEthernet0/0/2]ospf enable 1 area 0
