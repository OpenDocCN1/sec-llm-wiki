开课吧的老师不仅教书教得溜，写书也是一把好手。
近日，开课吧与机械工业出版社联合出版的《数字化人才职场赋能系列丛书》已经开始上线发售了！

这套书籍是新职业教育领域首套针对数字化人才职场提升的专业出版物，也是开课吧联合优秀师资倾力打造出的首套公开出版物。现场究竟亮相了哪些书籍？让我们一睹为快吧！（悄悄告诉你，末尾有福利哦）


零基础玩转Python


初学者使用的Python入门书籍


📚书籍简介：

本书是用来辅助开课吧Python小课学员学习的搭配工具书籍。全书共19章，与开课吧Python小课章节一一对应。每一章都包含知识点结构思维导图和多道练习题，并在该章知识点的基础上，衍生与之相关联的编程知识。

配合课程内容，采用互动剧本＋社群互动的教学模式，用PC端沉浸式学习＋文字阅读学习＋移动端学习多维度学习方式，让学员更好的理解知识、练习知识、掌握知识，让学习不再枯燥，充满趣味性。

📚书籍亮点：

书籍每一章开始的部分都加入了思维导图，每张思维导图都与当前章的教学内容对应，帮助学员掌握结构性知识，构建知识体系，回顾本章知识内容，充当教学笔记。

同时扫描章节下方的二维码，即可弹出本章练习题，在手机上书写代码。通过识别题干中的符号，来匹配手机端练习题。


Python数据分析入门实战


初学者也能快速掌握的Python知识点


📚书籍简介：


本书从理论到实践系统的描述了如何利用Python语言进行数据分析。由浅入深的书写方式可以帮助读者轻松愉快的进入数据的世界。


从基础语法到高阶科学计算库，循序渐进系统讲解Python数据分析所需要学习的技能树。搭配项目实战帮助读者更好更快的掌握Python数据分析知识点。从入门到专精，流畅的讲解了数据分析的必知必会技能。


本书作者由多名当下互联网一线教育从业者编写，不仅适合零基础喜欢数据分析的读者。同样也适合数据分析从业者，从而进行技术的进阶。


📚书籍亮点：


从基础语法到高阶科学计算库，循序渐进系统讲解Python数据分析所需要学习的技能树。搭配项目实战帮助读者更好更快的掌握Python数据分析知识点。



Java编程入门-任务式学习指南


初学者根据任务线索轻松完成Java入门


📚书籍简介：


本书定位于Java程序逻辑训练，以任务方式引导读者一步步进行知识点线索的学习，最终完成任务验收。一个任务对应一个章节，以任务拆解学习过程，学习目的性更强。结构以“任务描述”->“目标”->“任务线索”->“任务实施”->“验收标准”->“问题总结”->“扩展阅读”进行展开。


线索学习成为任务完成的关键点，结合实际业务完成Java入门学习，除了收获知识还能了解业务内容，直观感受程序解决实际问题的过程。开发工具采用了目前业界使用率较高的IDEA。


📚书籍亮点：


1）以终为始，一个任务完成一个业务场景，学习目的性强；


2）学以致用，通过Java入门学习完成若干任务，除了收获Java基础知识还能收获业务内容；


3）提供了完成任务的线索知识点，具备步骤性和扩展性；


4）入门篇定位于程序逻辑训练，通过实战学习，建立扎实编程逻辑，为未来的进阶学习搭建基础；



Java修炼指南-高频源码解析


初学者就能轻松阅读的Java修炼指南



📚书籍简介：


无论在职场面试还是实际工作中，都离不开JavaJDK及并发编程。从而市场迫切需求掌握JDK源码以及并发编程的人才。本书通过图文结合的讲解方式帮助大家理解JDK源码，完成多线程并发编程从入门到实践的飞跃，全书分为7章：


第1章为Java基础类，主要讲解Java的基础类的源码实现；


第2章为Java集合类，主要剖析了面试及工作中常用的集合类的原理源码；


第3章讲解了常用原子类AtomicLong和LongAdder的用法和原理；


第4章剖析了JUC独占锁ReentrantLock的原理源码，ReentrantLock是学习其他并发类的基础；


第5章剖析了两种常用并发容器CopyOnWriteArrayList和ConcurrentHashMap的实现原理，重点讲解了ConcurrentHashMap的实现；


第6章讲解了阻塞队列的实现，着重讲解其代表类ArrayBlockingQueue和LinkedBlockingQueue的原理源码；


第7章剖析了线程池的原理源码。



本书适合Java初级、中高级研发工程师，对JDK源码或Java并发编程感兴趣，以及希望探索JUC包原理源码人员阅读。


📚书籍亮点：


1）本书通俗易懂，只要对Java有一定的基础就可以很容易的读懂。


2）本书从最基本的JDK常用类讲起，通过图文结合的方式降低了理解难度，并结合案例分析了这些常用类的使用和注意事项。这些基础部分的介绍，也是理解和学习后面并发编程的基础。


3）本书对并发编程中常用的原子类、阻塞队列、JUC锁、线程池等并发组件的原理进行了剖析，这些组件在面试当中出现的概率很高，希望可以帮助读者不仅了解底层原理，而且还能知道如何应用，从而避开读者避开面试和业务开发中常见的一些“坑”。



Java修炼指南-核心框架精讲


深入思考并获得属于自己的编程方法论



📚书籍简介：


通过分析java领域具有代表性的MyBatis、Dubbo、RocketMQ三个框架的源码带你走进源码的世界。


📚书籍亮点：


本书的目的不仅是介绍框架的原理，而是更希望通过一个成熟、优秀的代码库来向读者展示阅读源码的思路及编程方面的技巧。

希望读者可以深入思考并获得属于自己的一套编程方法论。这也是编写本书的一个初衷，授之以鱼不如授之以渔。



Flink与Kylin深度实战


轻松上手Flink的最佳实战指南


📚书籍简介：


flink作为当下最火热的大数据实时处理技术，其很多特性深受广大开发者所喜爱，特别是在实时处理方面。flink表现出了让人叹为观止的处理速度，并且提供了完整的各种数据处理机制，包括乱序数据、迟到数据、以及窗口等各种特性，完全能够轻松应对我们实际工作当中遇到的各种实时处理的问题。


并且其独特的设计理念，使用批流一体的设计思想，真正实现了批量处理以及实时处理的统一结合，让你通过TableAPI以及SQL即可轻松实现批量一体的统一数据处理，正是基于以上各种先进的设计理念，以及出色的数据处理特性，所以越来越多的公司在生产环境当中深度实践flink的各种特性。


📚书籍亮点：


本书由浅到深的逐层剖析讲解了flink的各个模块的实现原理，以及各种API的使用，是带你轻松上手flink的最佳实践的书籍。



React工程师修炼指南


让你迅速掌握React技术栈的学习指南


📚书籍简介：


本书包含  7 个章节，由浅入深系统介绍 React 技术栈相关内容。


第1章节介绍学习 React 之前要掌握的 ES6 知识。


第2章节讲解 React  API 详尽使用，包含最新的 hooks 使用。


第3章节讲解 redux 使用，并配合 react-redux 搭建一个 todo 应用。


第4章节讲解 React-Router 使用，以一个小型项目中的 Router 配置详细演练 Router 在项目中的作用。


第5章节基于前文内容讲解一个完整的商场开发。


第6章节详细探秘 React 源码，通过源码的学习，加深读者对 React各方面的理解，可以在实际工作更好的应用 React。React 源码阅读能力也区分与普通 React 工程师的核心竞争力。


第7章节基于 Webpack  为读者介绍项目中 React 的工作环境搭建，以及实际工作时的优化技巧。


📚书籍亮点：


1、覆盖全面，从 React 技术栈使用，到最佳项目实战方案，到源码解析，到工程化开发，适合各阶段前端开发者系统学习 React 知识。


2、理论讲解配合案例解析，清晰明了，通俗易懂。


3、基于目前的最新标准讲解，React 16.13.1、React Router 5.1.2、Redux 4.0.5、React Redux 7.2.0，包含新增各类 Hooks 以及 fiber 架构。



深度学习自然语言处理实战


带有最新的代码实例

更加重视读者的实际代码能力提升


📚书籍简介：


近年来，基于深度学习方法的自然语言处理已逐渐成为主流。本书是一本介绍自然语言处理任务中深度学习技术的编著，全书共计8章，包含深度学习概况、深度学习基础知识、卷积神经网络、循环神经网络、seq2seq模型及注意力机制、大规模预训练模型等，内容十分广泛，并收录了基于PyTorch深度学习框架的部分实践项目。


全书的论述过程由浅入深，将理论与实践紧密联系在一起，内容从深度学习基础理论到尖端技术应用，并在介绍理论知识的基础上给出了自然语言处理技术的高级应用和开发实例，便于读者在实践中获得提高。


本书不仅适合作为人工智能、计算机科学、电子信息工程、自动化等专业的本科生及研究生教材，也非常适合作为自然语言处理相关领域的研究人员和技术人员的参考资料。


📚书籍亮点：


本书由浅入深，从自然语言处理的语言模型基础到当下最流行的大规模预训练模型，包含的知识面广，成体系。不仅适合刚入门的新手，也适合从业者快速查找补充重点知识。全书带有最新的代码实例，更加重视读者的实际代码能力提升。
