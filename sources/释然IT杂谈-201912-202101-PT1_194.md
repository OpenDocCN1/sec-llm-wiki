**批量下发华为、思科设备配置**

  

通常我们对较多交换机进行配置变更的时候，都是通过人为 Login 设备，将需要变更的指令输入进去。这不仅效率低，容易出错，而且对做重复事情的厌恶情绪会直接影响变更的过程。  
由此本文将介绍如何使用 Python Netmiko 模块批量配置交换机的方法。  

* * *

 |

 || 3.0+ || netmiko getpass |

** Python3 安装**  
打开 Python 下载链接：https://www.python.org/downloads/release/python-373/  
选择对应版本的安装包，点击下载![](../Images/b401dbb112727eab71f4fa20c03b5e25.png)  
下载完成后，打开 Python 安装包  
安装步骤如下：  
 一、如图勾选下方的两个选项框，点击 Customize installation 进入下一步安装步骤：  
![](../Images/ab0f475a321eb5d2eb0d44b5ce6e438d.png)二、所有选项保持默认，点击 Next 进入下一步安装步骤：![](../Images/6d55b67357310217173631344570725f.png)三、如图勾选 Install for users 选项，点击 Install 开始安装：![](../Images/07985a3f9046a05c8428cd0ef49ad1e8.png)四、等待安装程序完成

**配置 Python 脚本  
****一、Cisco**

编辑文件，文件命名Cisco\_Autoconfig.py  

```


#!/usr/bin/python3
```

执行脚本  

```


C:\\Users\\Administrator> python Cisco\_Autoconfig.py
```

当主机出现不可达或者密码错误时，在执行过程中会自动创建以日期命名的 txt 文件，记录失败主机 IP 、时间和原因，如下：  

```


C:\\Users\\Administrator> more 20200709.txt
```
