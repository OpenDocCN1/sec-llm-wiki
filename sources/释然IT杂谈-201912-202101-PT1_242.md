#### 一、虚机主机的三种方式

**1、基于IP**

**2、基于IP+端口**

**3、基于域名**

**官网文档：http://httpd.apache.org/docs/2.4/**

#### 二、安装Apache

**1、系统环境**

![](../Images/66f1ffb943a6fa0e078420a82921e96f.png)

**2、yum安装**

![](../Images/d3e07e1485112e49bceeb04969d7cc27.png)

![](../Images/4304bf3ceadb77e72b1bbf4aa07ab1ee.png)

可以查看安装了内容

![](../Images/f3f8a390e5bb2cf7d3acb84077e9cbe0.png)

**3、配置Selinux文件，SELINUX=disabled。**

`[root@localhost ~]# vim /etc/selinux/config`SELINUX=disabled  
SELINUXTYPE=targeted

![](../Images/2702c9a7c147875043f8d6f0270df23d.png)

或者临时关闭`[root@localhost ~]# setenforce 0`

**4、关闭防火墙**

`[root@localhost ~]# systemctl stop firewalld   [root@localhost ~]# systemctl disable firewalld   Removed symlink /etc/systemd/system/dbus-org.fedoraproject.FirewallD1.service.   Removed symlink /etc/systemd/system/basic.target.wants/firewalld.service.`

**5、启动httpd服务，访问测试**

`[root@localhost ~]# systemctl start httpd   `

  

![](../Images/657e9263ec6b6f86537d5bbda7b0dbe8.png)

  

#### 三、修改主配置文件

**1、查看apache主配置文件，确保存在以下配置，因为等下需要在conf.d/创建虚机主机配置。**

`[root@localhost ~]# grep "conf.d" /etc/httpd/conf/httpd.conf   `

**IncludeOptional conf.d/\*.conf**  

![](../Images/39e1101a6b60489ccc727d572ca0097d.png)

**2、另外，把 Require all denied默认拒绝访问设置为允许访问：Require all granted，方便测试。**

`[root@localhost ~]# vim  /etc/httpd/conf/httpd.conf `

![](../Images/7607a975f99a293c770ded680722040b.png)

#### 四、新增虚拟主机配置文件

##### 1、添加虚拟主机

1）创建配置文件

`[root@localhost ~]# cd /etc/httpd/conf.d/   [root@localhost conf.d]# vim virtual.conf`

![](../Images/f05fd033d32e51f21b7713925f61d47e.png)

3）创建虚机主机www的主页面

![](../Images/3e9e1bf8937a88e88a1197a3bee1d7f2.png)

4）检查配置文件是否正常

`[root@localhost conf.d]# httpd -t   AH00558: httpd: Could not reliably determine the server's fully qualified domain name, using localhost.localdomain. Set the 'ServerName' directive globally to suppress this message   Syntax OK`

![](../Images/16dc78fab774a72553b36f9449a6058f.png)

5）重启httpd服务

`[root@localhost conf.d]# systemctl restart httpd`

![](../Images/a47aff947d1cca32d32d92aa1fd53153.png)

6）打开浏览器，查看结果

![](../Images/42080c573c3b1f95692a824a04c8f2c5.png)

  

##### 2、配置基于IP+端口的虚拟主机

1）创建配置文件

`[root@localhost ~]# cd /etc/httpd/conf.d/   [root@localhost conf.d]# vim virtual.conf`

![](../Images/a4e485e38456a911b55a506f9da5d2ba.png)

2）修改httpd主配置文件，在Listen 80下面添加一行监控8080端口

`[root@localhost conf.d]# vim /etc/httpd/conf/httpd.conf`

![](../Images/0c670fe42854c068cfb21ebbd019cbbc.png)

3）创建虚机主机a.com和b.com的主页面（如果前面已经创建就不用重复）

![](../Images/2d1150103b64a4d3db8cf0fd113184a0.png)

4）检查配置文件

`[root@localhost conf.d]# httpd -t   AH00558: httpd: Could not reliably determine the server's fully qualified domain name, using localhost.localdomain. Set the 'ServerName' directive globally to suppress this message   Syntax OK`

5）重启httpd服务

`[root@localhost conf.d]# systemctl restart httpd`

6）打开浏览器，查看结果

![](../Images/99ed4b1c1550105ebac7936e992297a5.png)

  

##### 3、基于域名的虚拟主机

1）创建配置文件

`[root@localhost ~]# cd /etc/httpd/conf.d/   [root@localhost conf.d]# vim virtual.conf`

![](../Images/2f1eae3c6ec770edfe370185de7ab8ec.png)

  

2）修改物理主机hosts文件（C:\\Windows\\System32\\drivers\\etc），因为这里是因为物理机去访问Apache服务器

添加：  

192.168.253.128 web.com

192.168.253.128 bbs.com

![](../Images/0ec939fa8bc1b2dad41b1ee06074f760.png)

3）物理主机ping域名测试

![](../Images/03816a4fb6d51533e875da9316006db5.png)

  

4）检查配置文件

`[root@localhost conf.d]# httpd -t   AH00558: httpd: Could not reliably determine the server's fully qualified domain name, using localhost.localdomain. Set the 'ServerName' directive globally to suppress this message   Syntax OK   `

  

5）重启httpd服务

`[root@localhost conf.d]# systemctl restart httpd   `

  

6）打开浏览器，查看结果

![](../Images/f4345cdd8eb07a27c0a6790303181572.png)
