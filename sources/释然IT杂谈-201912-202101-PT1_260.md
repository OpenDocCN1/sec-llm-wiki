#### Python-100-Days

这个项目是 Python - 100 天从新手到大师，目前获得了近 8.6W+ Star！那么这个项目主要都包含哪些内容呢？如下：

*   Day 01~15 - Python 语言基础
    
*   Day 16~20 - Python 语言进阶
    
*   Day 21~30 - Web 前端入门
    
*   Day 31~35 - 玩转 Linux 操作系统
    
*   Day 36~40 - 数据库基础和进阶
    
*   Day 56~60 - 实战 Flask
    
*   Day 61~65 - 实战 Tornado
    
*   Day 66~75 - 爬虫开发
    
*   Day 76~90 - 数据分析和机器学习
    
*   Day 91~100 - 团队项目开发
    

以上，是 100 天计划所学知识目录，下面是详细到每个目录中所包含的内容。

由此可见，这 100 天学习计划，还是有很大知识含量的，希望大家学完后，能有收获。
