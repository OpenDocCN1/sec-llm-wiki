# 客服开户岗

  

**【岗位职责】**

**1、负责客户服务电话的接听与处理；****2、负责开销户业务及相关临柜业务的办理；****3、负责完成客户回访工作；****4、负责客户档案的归档和管理；****5、配合完成其他相关客服工作；****6、完成上级领导交办的其他工作。**

**【任职要求】**

**1、大专及以上学历，专业不限；****2、具备期货从业资格；****3、形象气质佳，具备良好的语言表达能力，熟练掌握office等办公软件；****4、具有良好的客户服务和沟通能力，工作沉稳踏实、责任心强；****5、有团队合作精神、乐观积极。**

  

  

**🍭其他福利待遇：年底奖金，定期体检，五险一金，过节法定节假日过节费，带薪年假。**

  

**工作地点：郑州**

# 运维工程师 

  

  

**【岗位职责】**

**1、负责期货交易相关系统的运行维护，应用变更，性能优化；****2、负责系统运维的相关的文档编制，服务拓扑管理，灾备方案的建设和演练；****3、负责系统运维技术研究和应用，按要求对系统软硬件实施变更和管理；****4、负责对系统运行进行实时监控、运维，根据监控数据分析统计系统运行状态；负责对系统突发问题的应急响应，保障系统运行稳定；****5、完成上级领导交办的其他工作。**

**【任职要求】**

**1、计算机相关专业，****本科以上学历****，具有期货从业资格证；****2、精通Linux操作系统，精通命令行下的Linux系统管理；****3、熟悉TCP/IP,HTTP等协议；****4、熟悉Shell、Bat、Python中至少一种，能快速编写服务维护脚本；****5、熟练掌握F5、lvs、Keepalive等常见负载均衡实现的基本原理，能熟练进行配置部署维护；****6、熟悉Zabbix、Nginx、apache、tomcat、Saltstack等开源系统；****7、熟悉LXC，Docker等容器技术、熟悉VMware、Openstack等虚拟化技术的优先考虑；****8、具备良好的分析、解决问题能力及较高的团队合作精神；****9、具有良好的学习能力，对互联网的新技术有很强的求知欲望。**

  

**🍭其他福利待遇：年底奖金，定期体检，五险一金，过节法定节假日过节费，带薪年假。**

  

**工作地点：上海**
