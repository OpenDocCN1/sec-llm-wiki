软件
简介

JDK是 Java 语言的软件开发工具包，主要用于移动设备、嵌入式设备上的java应用程序。JDK是整个java开发的核心，它包含了JAVA的运行环境(JVM+Java系统类库)和JAVA工具。

Linux安装jdk

1.

首先通过xftp将jdk包放到服务器上面，路径为/opt/

2.

进入jdk压缩包所在目录（进入目录的命令:cd /opt），并进行解压压缩包：

命令如下：tar -zxvf  jdk-14_linux-x64_bin.tar


3.

修改配置文件，并在配置文件下面添加如下命令。
修改配置文件命令：vim /etc/profile
配置文件中添加的代码：

export JAVA_HOME=/opt/jdk-14

export PATH=$JAVA_HOME/bin:$PATH

export CLASSPATH=.:$JAVA_HOME/lib/dt.jar:$JAVA_HOME/lib/tools.jar

4.

立即生效配置文件，命令如下：source /etc/profile

5.
查看jdk环境配置是否成功，命令如此：java -version
如果出现如下所示的版本信息，就说明已经正确了。

安装到此就完成了


注意：
若JDK安装包为rpm格式，则在root用户下使用：
rpm -ivh jdk-14-linux-x64-.rpm
命令安装rpm程序包。随后重复以上3-5的内容完成环境变量的配置。
