软件简介

# JDK是 Java 语言的软件开发工具包，主要用于移动设备、嵌入式设备上的java应用程序。JDK是整个java开发的核心，它包含了JAVA的运行环境(JVM+Java系统类库)和JAVA工具。

  
软件下载

**首先找到www.sun.com进入网站首页，这是jdk下载的官方网站,网站为纯英文，可以根据以下步骤找到jdk下载页面：**

![](../Images/64c4262c1cf6f3725edf29c24cf0b879.png)

**向下滑动找到java：**

![](../Images/6f5beee2dc489c7b210613446f104394.png)

**在出现的页面下滑找到Dowload java for Developers，点击即可进入JDK各个版本的列表页面如下：**  

![](../Images/c8ea732769414ab7f48e4346c13e5e08.png)

  

**选择合适的版本，点击后面相应的Download按钮，即可来到版本选择页面，官网提供了包括Linux、Windows、MacOS在内的多个系统，可以选择自己所需要的系统对应版本进行下载，我这里选择Windows 64位JDK版本，下载前需要注意要接受一下网站条款才可以下载，界面如下：**

**

**上述下载安装JDK的流程算是一个官方正式流程，其实大多数Java开发人员用JDK并没有上述那么复杂，直接去网盘下载一个上图所示的JDK包即可使用，但是只有包并不能全局运行和使用java命令和JDK的工具,只能通过在命令行中cd到JDK安装包路径下的方式执行命令，这样是及其不方便的，而要想让系统在全局环境下直接自动找到JDK路径并执行，就需要配置JDK到系统的环境变量中，配置的步骤如下：**  
**1）、在计算机->系统属性中找到高级系统设置：**

![](../Images/e1794472d45a762bbcdae50019bdde33.png)

**2）、在此页面点击环境变量，在环境变量的系统变量部分，首先新建一个JAVA\_HOME,将值设置为JDK的安装路径，配置如下：**

![](../Images/c64d877e8e0969172f89d1f24b65f656.png)

![](../Images/60c2a0170c3b81dd4a0090b08234257c.png)

**3）、再将JAVA\_HOME配置到Path变量中，值为%JAVA\_HOME%\\bin，配置如下：  
**

![](../Images/561430165f5b2a1768dee202f72b4b58.png)

  

**4）、配置完成后，打开电脑的命令行窗口，检查javac、java命令，如果出现以下界面，恭喜您，环境变量配置成功。****javac命令：**

![](../Images/3a2f04dd1dbd11f80f2611c61bb9927b.png)

**java命令：**

![](../Images/f9c0f113fa9b8fa1169c3ea3576ffbce.png)

**安装到此就完成了**

**2**

**Linux安装jdk**  

**1.**  

**首先通过xftp将jdk包放到服务器上面，路径为/opt/**

![](../Images/73c5e7724e3dc0c37806725df65f8b9b.png)

**2.**  

**进入jdk压缩包所在目录（进入目录的命令:cd /opt），并进行解压压缩包：  
**

**命令如下：tar -zxvf  ****jdk-14\_linux-x64\_bin.tar**

![](../Images/e5cbf79967eadb8fe71f81fe53f9e911.png)

  

**3.**

**修改配置文件，并在配置文件下面添加如下命令。****修改配置文件命令：vim /etc/profile****配置文件中添加的代码：**

**export JAVA\_HOME=/opt/jdk-14**

**export PATH=$JAVA\_HOME/bin:$PATH**

**export CLASSPATH=.:$JAVA\_HOME/lib/dt.jar:$JAVA\_HOME/lib/tools.jar**

![](../Images/52822f2e5926a65106502f7ae4e59a3f.png)

**4.**

**立即生效配置文件，命令如下：source /etc/profile**

![](../Images/a78bc1a80decc914a7f087ee2d6e788b.png)

**5.****查看jdk环境配置是否成功，命令如此：java -version****如果出现如下所示的版本信息，就说明已经正确了。**

![](../Images/4a0f8254230d24b15f280e0b45537c41.png)

![](../Images/d2bea80243fe01058aa605060b4e2797.png)

**安装到此就完成了**  

  

**注意：****若JDK安装包为rpm格式，则在root用户下使用：****rpm -ivh jdk-14-linux-x64-.rpm****命令安装rpm程序包。随后重复以上3-5的内容完成环境变量的配置。**
