一、前述

  1. 外部因素——即接入宽带多大，影响WiFi网速

  2. 内部因素——路由器和路由器的部署，影响WiFi网速和信号

三、方案部署 

本文实测使用的路由器为华硕AC1300RT-AC88U，其他路由器设置步骤大致相同。

3.1 使用单一路由器

3.1.1 简介

我们在购买路由器时，看以下几点就能满足我们的基本需求：

  1. 处理器和内存。
    路由器硬件影响数据传输处理能力，从而影响网速；

  2. MU-MIMO。支持该功能的路由器能对多用户同时收发信号，但3R3T及以上才有实际意义；

  3. 端口。端口兆数高于家庭接入带宽基本就没啥问题。


3.1.2 部署配置

（下述默认WiFi名称等，请见各自产品手册）

  1. 把网线连接路由器的WAN口，接通新路由器电源；

  2. 每个新路由器都有各自默认的WiFi名称（SSID），用电脑连接该WiFi，输入默认帐号密码；（或用网线连接路由器的LAN口和电脑） 

  3. 连接成功后，浏览器打开默认的web管理界面；

    1. 配置WAN口。目前家庭常用的是ADSL接入网络，即选择PPPOE；填写运营商给的宽带账号密码，完成互联网接入； 

    2. 设置WiFi名称及密码。

    3. 设置LAN口。启用DHCP服务器。首先记录主路由器的IP，再设置IP池；

    4. 其他保持默认即可。

  4. 部署完毕。


3.1.3 适用环境

小平层（小于100平方），对边缘信号强度需求不高

 

3.1.4 路由器推荐

一般，单个路由器适用于普通家庭，性价比高，比如：

  • TP-LINK双千兆路由器 1900M无线家用

  • Redmi路由器AC2100


涉及到一些土豪玩家，可以选择高端的路由器，信号强，功能多，比如：

  • 华硕（ASUS）RT-AC5300

  • 华硕（ASUS）ROG GT-AX11000


3.2 有线级联-路由模式

3.2.1 简介

通过网线把多个路由器连接起来，扩大WiFi信号覆盖范围。


3.2.2 部署配置

使用多个路由器搭建无线网络

  1. 主路由器设置参考【使用单一路由器】;

  2. 接通副路由器的电源，用网线连接路由器的LAN口和电脑；

  3. 连接成功后，浏览器打开默认的web管理界面；

    1. 设置WAN口

      选择静态IP，IP地址选择主路由器IP池中的IP，子网掩码默认为255.255.255.0，默认网关为主路由器的IP，DNS为主路由器的IP；

    2. 设置WiFi名称及密码。

      建议设置不同的WiFi名称，用于区别新子网（区别主副路由器的WiFi）；

    3. 设置LAN口。启用DHCP。

      建议设置为与主路由器不同网段；

  4. 若家里已经有布置好的网线，则用网线连接主路由器的LAN口，另一端连接墙上的网线端口；再用另一根网线连接副路由器的WAN口；
    若家里没有提前部署好网线，则用一根长的网线连接主路由的LAN口和副路由器的WAN口；

    （部分型号副路由器需要重启）

  5. 部署完毕。


手机连接副路由器WiFi，查看主路由器web管理界面

手机连接副路由器WiFi，查看副路由器web管理界面

主路由器并不知道手机连接了副路由器，比较适合“蹭网”；（同样，副路由器也不知道手机连接了主路由器）


但电脑连接副路由器WiFi，可以访问主路由器和副路由器的web管理界面；


电脑连接主路由器WiFi，只能访问主路由器的web管理界面；


所以“借网”给邻居使用时，切记不能透露主路由的web管理界面登录账号密码。

    

3.2.3 适用环境

已经布好网线的环境，可用于接入邻居的网络

 

3.3 有线级联-桥接模式

3.3.1 简介

通过网线把多个路由器连接起来，扩大WiFi信号覆盖范围


3.3.2 部署配置

使用多个路由器搭建无线网络

  1. 主路由器设置参考【使用单一路由器】;

  2. 接通副路由器的电源，用网线连接路由器的LAN口和电脑；

  3. 连接成功后，浏览器打开默认的web管理界面；

    1. 停用DHCP。

    2. 设置WAN口。
      选择静态IP，IP地址选择主路由器IP池中的IP，子网掩码默认为255.255.255.0，默认网关为主路由器的IP，DNS为主路由器的IP；

    3. 设置WiFi名称及密码。
      避免不同设备无缝漫游差，建议设置不同的WiFi名称，手动连接连接距离近的WiFi。

    4. 设置LAN口。

  4. 若家里已经有布置好的网线，则用网线连接主路由器的LAN口，另一端连接墙上的网线端口；再用另一根网线连接副路由器的LAN口；
    若家里没有提前部署好网线，则用一根长的网线连接主路由的LAN口和副路由器的LAN口；
    （部分型号副路由器需要重启）


  5. 部署完毕。
    手机连接副路由器WiFi，查看主路由器web管理界面

    手机连接副路由器WiFi，查看副路由器web管理界面

        主路由器和副路由器的web管理界面都能查看到手机的WiFi连接。

        电脑连接任意一个WiFi，都能通过IP访问任意路由器的web管理界面。


3.3.3 适用环境

已经布好网线的环境，家庭内部WiFi信号扩展使用。

3.4 Mesh组网

3.4.1 简介

路由器间通过无线信号通信，动态进行网络配置，副路由器间能直接通信，能提供多条冗余的无线链路，动态选择最佳路径，但是由于路由器间无线通信，路由器间的距离不能太远、中间不能有太多墙阻碍信号传输。（路由器间也可以用有线通信）


3.4.2 部署配置

  1. 准备子节点（副路由器）
    接通电源，按下路由器的复位键直至电源LED指示灯闪烁，松开复位键，保持通电状态；（请将子节点与主节点距离1-3米放置）

  2. 设置主节点（主路由器）
    主路由器设置参考【更换高端路由器】

  3. Mesh组网

    1. 进入主路由器的web管理界面，在mesh功能界面，搜索子节点；

    2. 搜索到子节点，直接添加就好了，主节点自动下发配置到子节点；

    3. 之后断开子节点电源，把子节点放到主节点信号覆盖范围内（主节点web端查看）；

  4. 部署完毕。（部分mesh路由器支持外置按钮一键配置，不用手动添加节点）


所有路由器的SSID相同，无缝漫游好，能很好地自动切换到信号强的路由器

连接任意一个路由器的WiFi（即在任意WiFi覆盖范围内），都能直接登录到web管理界面主路由器和副路由器形成一个整体，web管理界面是同一个


主副路由器间的信号传递可以使用无线，也可以使用有线


使用无线（仅需电源接通），主副路由器不能相隔太远，之间不能有太多墙的阻挡


使用有线（需电源和网线接通），主副路由器的位置可以任意放置


3.4.3 适用环境

没有提前布线的环境，需要经常更换路由器位置的环境，需要所有路由器支持mesh

 

3.4.4 型号推荐

Mesh组网对品牌有一定的依赖，很多厂商都直接推出mesh组网路由器，可以实现一键配对，组网方便简单，比如：

  • TP-LINK 易展mesh分布路由器

  • 小米路由器Mesh

  • 华硕（ASUS）RT-AC68U Aimesh套包


3.5 AC/AP组网 

3.5.1 简介

AC和AP之间通过网线连接通信，AC可以简单理解为一个路由器并且集成AP管理，AP即为路由器额外的天线，可以接收发信号，从而扩大WiFi覆盖范围。


AC正常内置标准POE网线供电模块，仅需一根网线与AP相连，即可独立工作，无需额外电源，布线简单方便。


3.5.2 部署配置

  1. 部署如上图，AC的wan口连接Modem，然后通过拨号上网，【参考单一路由器配置】;

  2. AP放在希望扩展WiFi信号的地方；用网线连通AC的LAN口和AP的网线口；因为AC是POE供电，所以AP无需单独供电；

  3. AC的web管理界面上，有个AP管理页面，连接AP的LAN口一般配置trunk模式，连接AP后，会自动发现AP。

  4. 多个AP，一般会对信道配置，减少干扰，然后配置SSID和无线连接密码。

  5. AC/AP模式部署完成。


3.5.3 适用环境

已经布好网线的环境，大平层和别墅的组网

 3.5.4 型号推荐

AC/AP组网广泛应用于企业用户，但是很多大平层大别墅对网络的要求也越来越高，在家庭组网中，现在也比较流行，可以选择路由器集成AC套餐，比如：

  • TP-LINK TL-R470GP-AC/ TL-AP450I-PE

  • 华三（H3C）Mini M30/ Mini A21

3.6 HyFi组网 

3.6.1 简介 

HyFi也叫电力猫，和AC/AP组网相似，由路由器和扩展器组成，扩展器作为路由器的额外天线，亦可以接收发信号，但路由器和扩展器之间通过电线通信（也称主路由和子路由）。


3.6.2 部署配置 

  1. 主路由设置参考【使用单一路由器】

  2. 把子路由放在希望扩展WiFi信号的地方，接通电源

  3. HyFi组网

    1. 主路由web管理界面上，使用添加子路由功能，通过电线自动搜索子路由；

    2. 搜索到子路由，直接加入即可

  4. 部署完毕


由于通过电力传输数据，电力会对信号产生影响，但家庭使用影响不大。


3.6.3 适用环境 

没有提前布线的环境，家庭内部WiFi信号扩展使用。

3.6.4 型号推荐  

HyFi路由器组网，主要应用在家里装修完，对家庭网络不满意进行升级。该方案也比较普遍，主要依赖家里强电，对电力要求比较高，目前也有很多厂商推出相应设备，比如：

  • TP-LINK的TL-H29R TL-H29E


3.7 总结 

简单介绍了家庭组网的多种方案，整理不同方案的对比如下：

通过上面对比，我们对家庭网络要求高的，会选择多个路由器组网，路由和桥接模式是对传统的网络进行升级，操作操作简单，成本较低，但是需要提前预留网线，路由之前漫游不太稳定。


无线mesh分布式路由器是比较新型的家用无线组网，对家庭装修无需依赖，只需要注意各个mesh路由之间的距离和信号强度，就可以比较完美地实现家庭网络部署。


AC/AP模式主要应用企业和大家庭环境，是唯一一种可以无限扩展、无缝漫游的组网方案。


HiFi组网更适合家庭网络临时扩展，主要依靠强调，如果电器过多，功率超标，对网络有一定的影响。


各种组网方式各有优劣，选择哪种组网方式就看各自的情况啦~
