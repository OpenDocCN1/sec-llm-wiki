# **二.  简单配置**

## 1.    关闭selinux

\[root@localhost ~\]# vim /etc/selinux/config

![](../Images/c139a57c7220d62be747fefaf0b68788.png)

## 2.    关闭防火墙

\[root@localhost ~\]# systemctl stopfirewalld

\[root@localhost ~\]# systemctl disablefirewalld

![](../Images/a2fee8e6bcc34ced91b21572bf2de81e.png)

## 3.    配置IP地址

\[root@localhost ~\]# vim/etc/sysconfig/network-scripts/ifcfg-eno16780032

![](../Images/e0c3f1c6b5f5d6fcc5178a36935c4091.png)

重启网络服务

\[root@localhost ~\]# systemctl restart network.service
