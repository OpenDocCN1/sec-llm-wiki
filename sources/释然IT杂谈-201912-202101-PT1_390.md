# 前言

由于工作需要，处理的服务器大多是内网环境，无法连接外网，在安装部署mysql，jdk，tomcat的时候还可以使用离线包+tar命令解压使用，但是安装redis和nginx等等软件的时候，不是缺gcc就是缺少依赖，因此考虑在服务器搭建本地yum 仓库，使用yum安装解决依赖问题。

本文适合对linux有基础的人阅读，对知识点介绍很少，不喜勿喷。

# 环境介绍

1.Centos7服务器一台。

2.Centos7 iso镜像一个。

3.SSH终端工具Mobaxterm。

# 实现步骤

1.先从centos的阿里云下载点

http://mirrors.aliyun.com/centos/7.7.1908/isos/x86\_64/

下载.CentOS-7-x86\_64-DVD-1908.iso和CentOS-7-x86\_64-Minimal-1810.iso

两者的区别是DVD版集成较多的东西，Mininal只有最基本的命令行

  

![](../Images/49aa2d9a89e6bbc85c05070858c53bec.png)

我下载的iso镜像

2.使用Vmware虚拟机搭建Centos7服务器一台

  

![](../Images/5c1e0b26e44a1de0fe12dad42bc7a5d6.png)

我的虚拟机

3.使用mobaxterm远程连接虚拟机

  

![](../Images/c63da9eb9c9fc61c65ea877009e77c55.png)

  

*   执行命令 lsblk 查看磁盘信息
    

  

![](../Images/f2f6dafe44950b3e9fac66af40f2396a.png)

lsblk

*   执行命令mkdir /test 新建/test目录
    

*   在这里通过Mobaxterm上传CentOS-7-x86\_64-DVD-1908.iso到/test1目录上，mobaxterm有文件上传和下载的功能
    

  

![](../Images/233b4b8338912a3a95c79d944ce82b8b.png)

上传了iso镜像到/test目录

*   挂载iso镜像到服务器上
    

mkdir /iso

mount -o ro /test/CentOS-7-x86\_64-DVD-1908.iso /iso/

lsblk

  

![](../Images/59a23bff4114b93966c91cecb1e89baf.png)

命令执行过程

这里我们可以见到我们上传的iso镜像已经挂载到服务器上。

*   修改yum源信息
    

cd /etc/yum.repos.d

mkdir backup

mv Centos-\* backup/

vi local.repo

```
[local]name=xxxbaseurl=file:///isoenabled=1gpgcheck=0:wq保存退出
```

yum clean all

yum list

  

![](../Images/a9b94ae9e17d8dafa9bf190bdf69074d.png)

yum list命令

  

这个时候我们已经搭建了本地仓库，即使在没网络的时候也能使用yum 安装一些基本软件。

yum install gcc\*  -y

yum install vim  -y
