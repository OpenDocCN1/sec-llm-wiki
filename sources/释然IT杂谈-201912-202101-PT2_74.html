抢票时间：

1、testerSunshine

https://github.com/testerSunshine/12306
testerSunshine：这款开源 12306 智能刷票，订票项目是基于 Python 语言编写，可在 Windows 或者 Linux 操作系统下运行，其主要功能包括：自动登录、抢准点预售车票、捡漏票、智能候补票、邮件通知等

2、pjialin/py12306 购票助手

https://github.com/pjialin/py12306

pjialin/py12306 购票助手，相比较 testerSunshine 而言，所具备的功能会更加多一些。其主要包括：分布式、多账号、多任务购票、电话语音/邮件/微信消息通知、Docker/代理池支持、Web 管理页面等；

3、12306 Bypass

https://www.bypass.cn/

12306 Bypass：这就不像前两个说的那么复杂了，这款 Bypass 分流器通过在 Windows 操作系统安装登录自己的 12306 账户，按需选好就可以了。
