**https://github.com/testerSunshine/12306****testerSunshine：这款开源 12306 智能刷票，订票项目是基于 Python 语言编写，可在 Windows 或者 Linux 操作系统下运行，其主要功能包括：自动登录、抢准点预售车票、捡漏票、智能候补票、邮件通知等**

![](../Images/40bd9461c8d1f41c8bd31cf49c04ef0a.png)

## 2、pjialin/py12306 购票助手
