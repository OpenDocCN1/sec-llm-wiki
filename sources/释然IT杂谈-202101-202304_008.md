# 工具介绍

`GoVnc`是使用`go`+阿里云`oss`实现对屏幕（截屏）进行监控，截屏后进行实时上传操作，从而达到屏幕监控的效果。如果要长期监控可以加入到开启启动项，计划任务等；

# 项目地址
