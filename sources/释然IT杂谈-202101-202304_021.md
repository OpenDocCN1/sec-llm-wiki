如何利用chatgpt提高学习或工作效率呢？

**1.写周报**

写周报是很多打工人甚至研究深每周都要完成的任务，但是因为繁忙的工作任务，很多人都很难抽出时间来写周报。通过Chatgpt，我们可以快速生成周报，节省时间。

![](../Images/f1f3bdddbec32d42fcac55b725717042.png)

# 

# **2.问问题**

在工作中，很多时候我们需要询问一些问题，但不知道该如何提问。通过Chatgpt，我们可以轻松生成恰当的问题，提高沟通效率。

![](../Images/77dd2a6bfe2d10ef7ed78540470656a0.png)

# 

# **3.代写文档模板**

Word文章是我们每天都要使用的工具，但有时因为模板的格式不够专业，需要进行修改。通过Chatgpt，我们可以快速生成专业的文档模板，提高工作效率。

![](../Images/181432b298e2a8a50a5088c3c98eb790.png)

# **4.提供设计思路**

在学习和工作中，有时候我们需要提供设计思路，但常常苦于因为没有思路，不知道如何入手，浪费许多时间。通过Chatgpt，我们可以快速生成设计思路，帮助我们完成学习与工作任务。
