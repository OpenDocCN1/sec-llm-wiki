**一键安装脚本实现快速部署GrayLog Server 4.2.10单机版**

由于局点（分支机构）较多，为了快速部署GrayLog单机版 

所以简单整理了一下GrayLog的安装步骤脚本，来实现一键安装GrayLog Server 4.2.10单机版 

只需上传GraylogServer4.2.10\_install.tar.gz和GrayLogServer\_install.sh安装脚本并执行一键安装脚本即可完成GrayLog Server 4.2.10单机版的安装

### 说明：

1、GraylogServer4.2.10\_install.tar.gz中为GrayLogServer安装时所需的JDK+pwgen+MongoDB+elasticsearch+graylog-server的RPM包 使用createrepo方式打包制作成本地yum源来实现离线yum安装

![](../Images/716f2659caa26b73be382e07764bb578.png)

(图片可点击放大查看)

2、建议的资源配置如下操作系统：CentOS7.9CPU 8核内存建议8GB内存以上磁盘大小:建议单独一块数据盘，并挂载到/data目录3、其中ES和MongoDB未做加密认证，因为只监听在本地127.0.0.1不对外暴露，若需要安全加固，请自行配置

## GrayLogServer\_install.sh脚本

脚本内容如下

```
#!/bin/bash
#关闭SELINUX
's/enforcing/disabled/g'

 /etc/selinux/config#解压安装包

echo "priority=1"
 >> /etc/yum.repos.d/graylog_local.repo #安装JDK+pwgen

#安装mongodb-server服务

#启动mongodb-server服务

enable

 mongod.servicetype

=service --state=active | grep mongod#安装elasticsearch

#单独创建目录用于存放elasticsearch数据

#修改elasticsearch相关配置文件
"s@#cluster.name: my-application@cluster.name: graylog@g"
 /etc/elasticsearch/elasticsearch.yml"s#path.data: /var/lib/elasticsearch#path.data: /data/elasticsearch/data#g"
 /etc/elasticsearch/elasticsearch.yml"s#path.logs: /var/log/elasticsearch#path.logs: /data/elasticsearch/logs#g"
 /etc/elasticsearch/elasticsearch.yml#修改JVM内存大小
"s/-Xms1g/-Xms4g/g"
 /etc/elasticsearch/jvm.options"s/-Xmx1g/-Xmx4g/g"
 /etc/elasticsearch/jvm.options#启动elasticsearch服务

enable

 elasticsearch.service'http://127.0.0.1:9200/_cluster/health?pretty=true'
'http://127.0.0.1:9200/_cat/nodes?v'
#安装graylog-server服务

#修改graylog-server相关配置文件
"s/password_secret =/password_secret = 0pAHJtPdZZUb5yHAvFbBezbWAlQwh9CbRX1rshJEVxM0kV7t0SpIgY5q9tLpVEwWLElhG3EtbvQ03mTm9i0HuvWKwlWgWiIJ/g"
 /etc/graylog/server/server.conf"s/root_password_sha2 =/root_password_sha2 = 79a560ed561e6fc57b3d02a59335b7710fada90625e4c661fbb7b780fb92ceaa/g"
 /etc/graylog/server/server.conf"s@#root_timezone = UTC@root_timezone = Asia/Shanghai@g"
 /etc/graylog/server/server.conf"s@#http_bind_address = 127.0.0.1:9000@http_bind_address = 0.0.0.0:9000@g"
 /etc/graylog/server/server.conf"s/allow_highlighting = false/allow_highlighting = true/g"
 /etc/graylog/server/server.conf#修改graylog-server启动时JVM内存大小
"s/-Xms1g -Xmx1g/-Xms2g -Xmx2g/g"

 /etc/sysconfig/graylog-server#启动graylog-server服务

enable

 graylog-server
```
