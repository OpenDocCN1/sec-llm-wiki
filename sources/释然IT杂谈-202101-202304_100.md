## Linux更新

1.  停止Nessus服务

`systemctl stop nessusd  #停止Nessus服务   `

> 注意：如果您之前按照《关于Nessus\_Pro插件202205112225食用方法》升级，切记执行以下命令取消`plugins`目录下所有文件只读权限

`find /opt/nessus/lib/nessus/plugins/ -name "*.*" | xargs -i chattr -i {}   ##执行时间稍微有点长，因为插件数达14W+   `

否则会提示文件没权限操作，如下图所示

![](../Images/6235b19a8b72fee6ab58b095faf2b442.png)

提示操作不允许

2.  接下来就跟上次步骤一样，不啰嗦了

`/opt/nessus/sbin/nessuscli update all-2.0_202207130548.tar.gz #升级      chattr -i /opt/nessus/var/nessus/plugin_feed_info.inc #取消之前设置的只读      cp plugin_feed_info.inc /opt/nessus/var/nessus #替换新的inc      chattr +i /opt/nessus/var/nessus/plugin_feed_info.inc #设置只读      find /opt/nessus/lib/nessus/plugins/ -name "*.*" | xargs -i chattr +i {} #设置plugins全文件只读      chattr -i /opt/nessus/lib/nessus/plugins/plugin_feed_info.inc #取消该文件的只读      systemctl start nesssusd   `

## Windows更新

Window类似，就是换了个命令

`net stop "Tenable Nessus"       attrib -s -r -h "C:\ProgramData\Tenable\Nessus\nessus\plugin_feed_info.inc"  #取消之前设置的只读      attrib -s -r -h "C:\ProgramData\Tenable\Nessus\nessus\plugins\*.*"   #取消之前设置的只读      "C:\Program Files\Tenable\Nessus\nessuscli.exe" update "{your_path}\all-2.0_202207130548.tar.gz"  #升级      copy "{your_path}\plugin_feed_info.inc" "C:\ProgramData\Tenable\Nessus\nessus\plugins\" "C:\ProgramData\Tenable\Nessus\nessus\"   #替换新的inc      attrib +s +r +h "C:\ProgramData\Tenable\Nessus\nessus\plugin_feed_info.inc"   #设置只读      attrib +s +r +h "C:\ProgramData\Tenable\Nessus\nessus\plugins\*.*"   #设置plugins全文件只读      attrib -s -r -h "C:\ProgramData\Tenable\Nessus\nessus\plugins\plugin_feed_info.inc"   #取消该文件的只读      net start "Tenable Nessus"    `
