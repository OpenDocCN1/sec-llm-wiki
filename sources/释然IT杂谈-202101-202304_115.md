# 工具包已收集放网盘后台回复“ **远程工具** ”获取

1、Xshell：

xshell 是一个非常强大的安全终端模拟软件，它支持 SSH1, SSH2, 以及 Windows 平台的 TELNET 协议。Xshell 可以在 Windows 界面下用来访问远端不同系统下的服务器，从而比较好的达到远程控制终端的目的。

![](../Images/2655ef5a49aa28352f6bf6e35edc476f.png)

  

官网：

`https://www.netsarang.com/zh/xshell`2、MobaXterm：

mobaxterm 的功能非常全面，几乎提供了所有重要的远程网络工具（比如 SSH、X11、RDP、VNC、FTP、MOSH 等），以及 Windows 桌面上的 Unix 命令（bash、ls、cat、sed、grep、awk、rsync 等），登录之后默认开启 sftp 模式。

![](../Images/3857eabb804eb40773aacee88ecf37f3.png)

官网：❝大多企业运维都喜欢用它❞

`mobaxterm.mobatek.ne`3、secureCRT：

SecureCRT 支持 SSH，同时支持 Telnet 和 rlogin 协议。SecureCRT 是一款用于连接运行包括 Windows、UNIX 和 VMS 的理想工具。通过使用内含的 VCP 命令行程序可以进行加密文件的传输，网工应该很熟这个软件，经常使用它连接设备。

![](../Images/f6207e636e19c736313a1726a2ed517b.png)

  

官网：

`https://www.vandyke.co`4、PuTTY：

PuTTY 是 SSH 和 telnet 客户端，最初由 Simon Tatham 为 Windows 平台开发。用 MIT 许可证授权。包含的组件有：PuTTY, PuTTYgen,PSFTP, PuTTYtel, Plink, PSCP, Pageant, 默认登录协议是 SSH，默认的端口为 22。

![](../Images/697b00bd4e2453eda9b24ac93ba5b4a7.png)

官网：

`putty.org`5、FinalShell：

FinalShell 是一体化的服务器网络管理软件 (java 语言编写)，不仅是 ssh 客户端，FinalShell 还是功能强大的开发、运维工具，充分满足用户的开发运维需求。

![](../Images/5c3990bac224f1a5286767ec86d96052.png)

官网：❝可以直观的看出远程服务器的硬件运行情况❞

`http://www.hostbuf.com`6、winSCP：

WinSCP 是一个 Windows 环境下使用 SSH 的开源图形化 SFTP 工具客户端。同时支持 SCP 协议。它的主要功能就是在本地与远程计算机间安全的复制传输文件。

![](../Images/b969abc79030d92213e72eba148f6c0e.png)

  

官网：  

`https://winscp.net`7、Termius：

Termius是一款支持WINDOWS,MAC,和IOS平台的远程SSH工具，功能强大，且和teamviewer一样注册一个账号就可以在多个平台共享主机列表，一次配置后就可以跨平台使用，非常适合我们经常和云主机服务器打交道的朋友.

![](../Images/d2ed5ad4d4489b0f5ecf8610db77aed2.png)

  

官网：

`https://www.termius.com`8、JuiceSSH：

上面推荐的都是电脑上的SSH客户端，那么如果在外边，不方便用电脑，如何登陆服务器呢，在给大家推荐一个安卓手机的SSH客户端应用——JuiceSSH

![](../Images/037d2483065091106e1d9c56739e087f.png)
