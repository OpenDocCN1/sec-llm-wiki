# 具体安装部署步骤如下

## 一、调整相关的内核参数并关闭防火墙

```
sed -i 's/enable/disabled/g'

 /etc/selinux/configset
-hostname elastiflowecho "vm.max_map_count=262144"
 | sudo tee /etc/sysctl.d/70-elasticsearch.conf > /dev/nullecho -e "net.core.netdev_max_backlog=4096\nnet.core.rmem_default=262144\nnet.core.rmem_max=67108864\nnet.ipv4.udp_rmem_min=131072\nnet.ipv4.udp_mem=2097152 4194304 8388608"
 |  tee /etc/sysctl.d/60-net.conf > /dev/null'2097152 4194304 8388608'
disable
 firewalld.service
```
