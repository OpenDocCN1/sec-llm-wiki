前言：

**1.  美团买菜版本**

开发者发现了可以在安卓机上运行脚本的工具 Auto.js，写了个脚本用来抢菜。这个脚本适用于美团买菜 v5.32.0，具体开发步骤移步开源项目。

```
开源地址：https://github.com/qulingyuan/robVeg
```

**2. 买菜、抢菜助手**

支持美团买菜，可定时执行。该开源项目可以自动打开美团买菜 APP，重复执行购买流程，执行到支付流程，还包括响铃提示。

```
开源地址：https://github.com/universeindream/MaiCaiAssistant
```
