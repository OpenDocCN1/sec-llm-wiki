实验目的及拓扑

本实验的目的是在Packet Tracer上测试您使用 由 4 个交换机组成的小型网络上配置 VLAN 和 VTP 的能力。



配置说明

  • 将 VTP-SERVER 交换机配置为 VTP 服务器

  • 连接到其他 3 台交换机并将它们配置为 VTP 客户端。所有交换机互联的链路都必须配置为trunk模式。

  • 配置 VTP 域名为“TESTDOMAIN”，VTP 密码为“cisco”

  • 配置名称为“STUDENTS”的VLAN 10 和名称为“SERVERS”的 VLAN 50

  • 检查 VTP 域的所有交换机vlan传播情况。

VLAN和VTP实验配置步骤

1、将VTP-SERVER交换机配置为VTP服务器

VTP-SERVER(config)#vtp mode server

使用show vtp status命令验证 VTP 运行模式

  1. 连接到另外 3 台 Catalyst 交换机并将它们配置为 VTP 客户端。交换机之间的所有链路都必须配置为中继线。
VTP-CLIENT3(config)#vtp mode client


使用show vtp status命令验证交换机的 VTP 运行模式。在“VTP Operating Mode ” 可以看到。下面提供了使用 VTP-CLIENT3 交换机的示例。

VTP-CLIENT3#sh vtp status

VTP Pruning Mode                : Disabled
VTP V2 Mode                     : Disabled
VTP Traps Generation            : Disabled

使用switchport mode truink命令将交换机之间的每条链路配置为trunk模式

interface GigabitEthernet1/1
switchport mode trunk

interface GigabitEthernet1/2
switchport mode trunk


3、配置VTP域名为“TESTDOMAIN”，VTP密码为“cisco”

在 VTP 服务器 Catalyst 交换机上：

VTP-SERVER(config)#vtp domain TESTDOMAIN
VTP-SERVER(config)#vtp password cisco

在每个 VTP 客户端交换机上：

VTP-CLIENT1(config)#vtp password cisco
VTP-CLIENT1(config)#vtp domain TESTDOMAIN


  1. 配置名称为“STUDENTS”的 VLAN 10 和名称为“SERVERS”的 VLAN 50

在 VTP 服务器 Catalyst 2960 交换机上，配置以下命令以创建“STUDENTS”和“SERVERS”VLAN：

VTP-SERVER(config)#vlan 10
VTP-SERVER(config-vlan)#name STUDENTS
VTP-SERVER(config)#vlan 50
VTP-SERVER(config-vlan)#name SERVERS


  1. 在 VTP 域的所有 Catalyst 2960 网络交换机上检查“STUDENTS”和“SERVERS”vlan 的传播。

在每台交换机上使用show vlan Brief检查 2 个 VLAN 的传播情况。
