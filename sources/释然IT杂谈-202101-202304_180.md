# 实验目的及拓扑

本实验的目的是在Packet Tracer上测试您使用 由 4 个交换机组成的小型网络上配置 VLAN 和 VTP 的能力。

![](../Images/3ee053a566fb1e61c48e3d5137b703d9.png)

  

  

# 配置说明

*   将 VTP-SERVER 交换机配置为 VTP 服务器
    
*   连接到其他 3 台交换机并将它们配置为 VTP 客户端。所有交换机互联的链路[都必须配置为trunk模式](http://mp.weixin.qq.com/s?__biz=MjM5ODY3MTgxNw==&mid=2653963007&idx=1&sn=bfe43f41e7fbf83891ce5c7b515a5d5a&chksm=bd03c6598a744f4f3b9a5a5ca5d8760f0cf071a131a16cf81b081ff60bf7680669ee984fc4fe&scene=21#wechat_redirect)。
    
*   配置 VTP 域名为“TESTDOMAIN”，VTP 密码为“cisco”
    
*   配置名称为“STUDENTS”的VLAN 10 和名称为“SERVERS”的 VLAN 50
    
*   检查 VTP 域的所有交换机vlan传播情况。
    

# VLAN和VTP实验配置步骤

1、将VTP-SERVER交换机配置为VTP服务器

`VTP-SERVER(config)#vtp mode server   `

使用show vtp status命令验证 VTP 运行模式

`VTP-SERVER#show vtp status   VTP Version                     : 2   Configuration Revision          : 4   Maximum VLANs supported locally : 255   Number of existing VLANs        : 7   VTP Operating Mode              : Server   VTP Domain Name                 : TESTDOMAIN   VTP Pruning Mode                : Disabled   VTP V2 Mode                     : Disabled   VTP Traps Generation            : Disabled   MD5 digest                      : 0xAE 0x4F 0x3F 0xC5 0xD3 0x41 0x9C 0x11   Configuration last modified by 192.168.1.1 at 3-1-93 00:27:41   Local updater ID is 192.168.1.1 on interface Vl1 (lowest numbered VLAN interface found)   `

  

2.  连接到另外 3 台 Catalyst 交换机并将它们配置为 VTP 客户端。交换机之间的所有链路都必须配置为中继线。

`VTP-CLIENT3(config)#vtp mode client   `

  

使用[show vtp status](http://mp.weixin.qq.com/s?__biz=MjM5ODY3MTgxNw==&mid=2653963011&idx=1&sn=7a85cbbb5ecc85daa6f0bb21041bbeac&chksm=bd03c7a58a744eb326a86951ef4a537454df2dd1d6991e31077d97cfe6b15e563eb83373ccbf&scene=21#wechat_redirect)命令验证交换机的 VTP 运行模式。在“VTP Operating Mode ” 可以看到。下面提供了使用 VTP-CLIENT3 交换机的示例。

`VTP-CLIENT3#sh vtp status   VTP Version                     : 2   Configuration Revision          : 4   Maximum VLANs supported locally : 255   Number of existing VLANs        : 7   VTP Operating Mode              : Client   VTP Domain Name                 : TESTDOMAIN   VTP Pruning Mode                : Disabled   VTP V2 Mode                     : Disabled   VTP Traps Generation            : Disabled   MD5 digest                      : 0xAE 0x4F 0x3F 0xC5 0xD3 0x41 0x9C 0x11   Configuration last modified by 192.168.1.1 at 3-1-93 00:27:41   `

  

使用switchport mode truink命令将交换机之间的每条链路配置为trunk模式

`interface GigabitEthernet1/1   switchport mode trunk      interface GigabitEthernet1/2   switchport mode trunk   `

  

3、配置VTP域名为“TESTDOMAIN”，VTP密码为“cisco”

在 VTP 服务器 Catalyst 交换机上：

`VTP-SERVER(config)#vtp domain TESTDOMAIN   VTP-SERVER(config)#vtp password cisco   `

在每个 VTP 客户端交换机上：

`VTP-CLIENT1(config)#vtp password cisco   VTP-CLIENT1(config)#vtp domain TESTDOMAIN   `

  

4.  配置名称为“STUDENTS”的 VLAN 10 和名称为“SERVERS”的 VLAN 50

在 VTP 服务器 Catalyst 2960 交换机上，配置以下命令以创建“STUDENTS”和“SERVERS”VLAN：

`VTP-SERVER(config)#vlan 10   VTP-SERVER(config-vlan)#name STUDENTS   VTP-SERVER(config)#vlan 50   VTP-SERVER(config-vlan)#name SERVERS   `

  

5.  在 VTP 域的所有 Catalyst 2960 网络交换机上检查“STUDENTS”和“SERVERS”vlan 的传播。

在每台交换机上使用show vlan Brief检查 2 个 VLAN 的传播情况。

`VTP-SERVER#show vlan brief      VLAN Name                             Status    Ports   ---- -------------------------------- --------- -------------------------------   1    default                          active    Fa0/1, Fa0/2, Fa0/3, Fa0/4, [...]   10   STUDENTS                         active       50   SERVERS                          active       1002 fddi-default                     active       1003 token-ring-default               active       1004 fddinet-default                  active       1005 trnet-default                    active   `
