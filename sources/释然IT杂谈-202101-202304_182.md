# 交换机密码忘了，肿么办？

最近有个同事换了新手机，登录微信时，需要输入密码，试了几次密码都不对，最后通过手机验证码的方式成功登录微信。想想自己，也忘了微信密码。毕竟现在要记住的密码实在太多了，银行卡密码、邮箱密码、电脑开机密码、手机登录密码，还有种类繁多的 APP 登录密码。因此，个别密码遗忘成了稀松平常的事情，常见的补救措施有：重置密码、使用其它的验证方式登录、通过客服找回密码。  

作为网络工程师，还要记住网络设备的密码。举个栗子，交换机有 BOOT 密码、Console 口密码、Telnet 密码、SSH 密码和 Web 登录密码。假如忘记了交换机的某个密码，该肿么办呢？

  

#### 1、忘记 Web 登录密码

如果忘记了 Web 登录密码，可以通过 Console 口、Telnet 或 SSH 登录交换机，设置新的 Web 登录密码。比如：Web 登录用户名是 fox ，密码修改为 dog123 ，过程如下：

#### 2、忘记 Console 口登录密码

如果忘记了 Console 口登录密码，有两种方法可以恢复 Console 口密码：

*   通过 SSH/Telnet 登录设备修改 Console口 密码
    
*   在 BOOT 下清除 Console 口密码后，修改 Console 口密码
    

  

##### 方法一：通过 SSH/Telnet 登录设备修改 Console口 密码

如果有 SSH/Telnet 账号且具有管理员权限，就可以通过 SSH/Telnet 登录设备，修改 Console 口登录密码，然后保存配置。下面以 SSH 举例：

1.  使用 SSH 账号登录设备后，确认当前账号权限为 3 级或 3 级以上。使用 **display users** 命令查看当前设备所有登录用户。其中带 “ **+** ” 标记行表示为当前用户，记录对应的编号 VTY1 。
    

![](../Images/1e3fa45f52c84fd8a49868e498d7ee3d.png)

使用 **display user-interface** 命令可以显示用户的权限，确定 VTY1 对应的等级为15，有权限修改 Console 口登录密码。

![](../Images/ecaa0a374a0737f3609a8d5057cc73a1.png)

2.  修改 Console 口登录的密码为 fox123 。
    

![](../Images/34f829752ff789c5463aed31fc7e9c37.png)

3.  防止重启后配置丢失，保存配置。
    

![](../Images/e016ded9acc69f2b47826508eb426b25.png)

  

##### 方法二：在 BOOT 下清除 Console 口密码后，修改 Console 口密码

如果记得 BOOT 菜单密码，可以通过 BOOT 菜单清除 Console 口登录密码，并在交换机重新启动后设置新的 Console 口登录密码，再保存配置。

1.  通过 Console 口连接交换机。将 Console 通信电缆的 DB9（孔）插头插入 PC 机的 COM 口中，再将 RJ-45 插头端插入设备的 Console 口中。
    

![](../Images/35671f6ace2da6a7601ec04737452181.png)

2.  在 PC 上打开终端软件，新建连接，设置连接的接口，并配置通信参数。
    

*   波特率：9600
    
*   数据位：8
    
*   停止位：1
    
*   奇偶校验位：无
    
*   流控：无
    

3.  重启交换机。当界面出现下面的打印信息时，及时按下快捷键“ `Ctrl + B` ”或者“ `Ctrl + E` ”并输入 BOOT 密码，进入 BOOT 主菜单。
    

![](../Images/415ff23e256676fa0c82c3c7c9b454f8.png)

4.  在 BOOT 主菜单下选择 “ `Clear password for console user` ” 清除 Console 口登录密码。
    
5.  根据交换机的提示，在 BOOT 主菜单下选择 “ `Boot with default mode` ” 启动设备。注意这里不要选择 “ `Reboot` ” 选项，否则此次清除密码将失效。
    
6.  完成系统启动后，通过 Console 口登录时不需要认证，登录后按照系统提示配置验证密码。
    
7.  登录交换机后，您可以根据需要修改 Console 用户界面的认证方式及密码。
    
8.  防止重启后配置丢失，记得保存配置。
    

![](../Images/e016ded9acc69f2b47826508eb426b25.png)

  

#### 3、忘记 SSH/Telnet 登录密码

*   如果只是忘记某一个 SSH/Telnet 账号的登录密码，可以通过其它有管理员权限的账号登录，重新配置密码。
    
*   如果忘记了所有 SSH/Telnet 账号的登录密码，还可以通过 Console 口登录。
    

  

##### 方法一：通过其它有管理员权限的 SSH/Telnet 账号登录，重新配置密码

1.  通过有管理员权限的 SSH/Telnet 账号登录交换机。
    
2.  修改 SSH/Telnet 登录密码。以修改 SSH 登录密码为例：
    

![](../Images/197f73c11c81289e10a1f873651faff3.png)

  

##### 方法二：通过 Console 口登录，设置新的 SSH/Telnet 登录密码

1.  通过 Console 口连接交换机。
    
2.  在 PC 上打开终端软件，新建连接。
    
3.  点击 “ `Connect` ” ，根据提示输入/配置登录密码，完成 Console 口登录。
    
4.  修改 SSH/Telnet 登录密码。
    

  

#### 4、忘记 BOOT 菜单密码

如果忘记 BOOT 菜单密码，但是可以通过 SSH/Telnet 登录交换机，就能恢复 BOOT 密码为默认值。

#### 5、忘记默认密码

如果一直使用的是设备默认密码，没有改过密码，可以通过查询官方文档获取准确的默认账号和密码信息。下面是一些常见的默认账号和密码。

#### 6、修改了所有默认密码，还忘记了所有密码

如果把所有密码都做了修改，都不是默认密码了，还都忘记了，那么只能看下是否支持 **PNP 键**：

*   支持 PNP 键的交换机，可长按（ 6 秒以上）PNP 键，使交换机恢复出厂设置，并自动重新启动。
    
*   不支持 PNP 键的交换机，只能返厂维修。
    

![](../Images/c288dd088022987e6c155183ae1f6815.png)

  

虽说有一些交换机密码恢复的方法，但是恢复密码过程中，可能会需要交换机重启，甚至丢失交换机配置，肯定是会影响网络的。因此，平时一定要保管好交换机密码，避免出现交换机无法正常登录的情况。
