好了，本期梳理一些主流厂商的端口划分vlan的命令，供大家日常工作查阅，欢迎收藏！  
  

## 华为交换机

  

```
<HUAWEI> system-view
sysname SwitchA
vlan batch 2 3
  //创建VLAN 2、3interface gigabitethernet 0/0/1
port link-type access
port default vlan 2
  //把G0/0/1划分为vlan2quit
interface gigabitethernet 0/0/2
port link-type access
port default vlan 3 
 //把G0/0/2划分为vlan3quit

```

  

  

## 思科交换机

  

```
Switch# configure terminal
# vlan 2
# end
# vlan 3
# end
# interface gigabitethernet0/1
# switchport mode access
# switchport access vlan 2   //把G0/1划分为vlan2
# end
# interface gigabitethernet0/2
# switchport mode access
# switchport access vlan 3 //把G0/3划分为vlan2
# end


```

  

  

## 锐捷交换机

  

```
Ruijie#configure terminal
#vlan 2
#
exitRuijie(config)#vlan 3
#exit
enable
#config terminal
#interface gigabitEthernet 1/1
#switchport mode access
#switchport access vlan 2  //把G1/1划分为vlan2
#end
#interface gigabitEthernet 1/2
#switchport mode access
#switchport access vlan 3 //把G1/2划分为vlan2
#end

```

  

  

  

## Juniper交换机

  

```
user@host# set vlans along-v2 vlan-id 2
# set ge-0/0/1 unit 0 family ethernet-switching interface-mode access
# set ge-0/0/1 unit 0 family ethernet-switching vlan members along-v2 
# set vlans along-v3 vlan-id 3
# set ge-0/0/2 unit 0 family ethernet-switching interface-mode access
# set ge-0/0/2 unit 0 family ethernet-switching vlan members along-v3 

```

  

  

  

## 华三交换机

  

```
[H3C] vlan 2
quit
vlan 3
quit
interface gigabitethernet 1/0/1
port link-type access
port access vlan 2

interface gigabitethernet 1/0/2
port link-type access
port access vlan 3

```

  

  

  

## 迈普交换机

  

```
Maipu#configure terminal 
#vlan 2-3
#interface gigabitethernet 0/1
#switchport mode access   
#switchport access vlan 2
#exit
#interface gigabitethernet 0/2
#switchport mode access 
#switchport access vlan 3
#exit

```
