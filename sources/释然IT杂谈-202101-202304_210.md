## 有个服务器可以做什么

这里聊聊, 如果你有一台云服务器, 可以用来做什么?

1.  搭建一个博客站点, 推荐使用 Halo, 这是一款现代化的个人独立博客系统. 后端 Java + Spring Boot; 管理系统的前端采用 Vue + Ant Design; C 端的前端样式可以复用 Hexo 的主题.
    
2.  部署一个代码版本管理系统, 推荐使用 Gitea, 这是一个开源社区驱动的轻量级代码托管解决方案，后端采用 Go 编写，采用 MIT 许可证. 类似于 github, gitlab, 但需要的系统资源非常低.
    
3.  搞个图床, 写博客需要插入图片, 也可以在浏览网页时, 收集配图资源. 关于存储图片, 建议购买阿里云提供的**对象存储** (OSS), 价格非常便宜, 对于用量少的个人开发者, 价格可以忽略不计.
    
4.  搞个爬虫, 爬取自己关注的数据、热门资讯等, 方便自己查看. 我一个朋友很喜欢足球, 他爬取相关资讯, 然后做了一个网页版的移动端, 在上下班路上查看.
    
5.  搞个 QQ 机器人、微信机器人, 给自己或群聊定时推送一些消息, 比如天气、资讯、文章等.
    
6.  写点小工具, 比如生活小工具、开发小工具等, 方便你我他, 让生活工作更愉悦! 说不一定, 还可以赚点流量广告费哦!
