3、如何设置设备时间和时区

<R1>clock datetime 9:40:30 2021-09-13
//在用户视图下执行命令clock datetime hh:mm:ss yyyy-mm-dd，设置当前时间和日期

<R1>clock timezone GMT+8 add 8:00:00

//在用户试图下执行命令clock timezone time-zone-name { add | minus } offset，设置所在的时区
add将在UTC标准时间的基础上增加指定的时区偏移量。即，在系统默认的UTC时区的基础上，加上offset，就可以得到time-zone-name所标识的时区时间。
minus将在UTC标准时间的基础上减去指定的时区偏移量。即，在系统默认的UTC时区的基础上，减去offset，就可以得到time-zone-name所标识的时区时间。

5、配置接口IP地址
配置主IP地址：

<R1>system-view      //执行命令system-view，进入系统视图
[R1]interface g0/0/0   //执行命令interface interface-type interface-number，进入接口视图
[R1-GigabitEthernet0/0/0]ip address 10.1.1.1 255.255.255.0
//执行命令ip address ip-address { mask | mask-length }，配置接口的主IP地址

（看不全，试试左右滑动）


配置从IP地址：
<R1>system-view
[R1]interface g0/0/0
[R1-GigabitEthernet0/0/0]ip address 10.1.1.1 24 sub
//执行命令ip address ip-address { mask | mask-length } sub，配置接口的主IP地址

（看不全，试试左右滑动）


检查配置是否生效：
使用display ip interface [ interface-type interface-number ]命令，查看接口上的IP地址的相关配置信息
使用display ip interface brief [ interface-type [ interface-number ] ]命令，查看接口上IP地址的简要信息


说明：
  • 一个接口只能有一个主IP地址，当配置主IP地址时，如果接口上已经有主IP地址，则原主IP地址被删除，新配置的地址成为主IP地址
  • 如果用户需要为接口配置多个从IP地址，可以反复执行此步骤。每个接口最多可以配置31个从IP地址

7、ping命令的使用
ping命令用来检查IP网络连接及主机是否可达，下面简单介绍一下ping最常用的三种使用方式,
如拓扑图所示，R1的g0/0/0与R2的g0/0/0直连，R1的地址为10.1.1.1/24; R2的地址为10.1.1.2/24,配置如下：

R1：
<R1> system-view
[R1] interface g0/0/0
[R1-GigabitEthernet0/0/0] ip address 10.1.1.1 24

R2：
<R2> system-view
[R2] interface g0/0/0
[R2-GigabitEthernet0/0/0] ip address 10.1.1.2 24



从R2 ping 10.1.1.1地址，检查R1是否可达


从R2的10.1.1.2的源地址ping R1上的10.1.1.1目的地址，并且设置报文的发送次数为3次


从R2 ping 10.1.1.1地址，设置发送报文的长度为1M


说明：
  • 如果ping执行过程出现异常，可以使用同时按下CTRL＋C键中止ping命令
  • ping命令不允许用户向广播地址，如XX.XX.XX.255发送ping包


8、掌握基本的telnet
telnet基本功能演示，还是刚才的拓扑图，在完成接口IP地址配置后，来配置R1 telnet的登录方式。
<R1> system-view
[R1] interface g0/0/0
[R1-GigabitEthernet0/0/0] ip address 10.1.1.1 24
[R1] aaa //进入aaa视图
[R1-aaa] local-user along password cipher abc123   //创建一个用户，用户名为：admin 密码：123456
[R1-aaa] local-user along service-type telnet //设置admin这个用户只可以用telnet的方式登录
[R1-aaa] local-user along privilege level 15       //设置用户的权限等级为15
[R1-aaa] quit
[R1] user-interface vty 0 4    //进入VTY界面视图
[R1-ui-vty0-4] authentication-mode aaa
//设置telnet的登录验证方式为AAA模式，即用刚才所创建的admin用户登录

验证telnet是否可以登录：
<R2>telnet 10.1.1.1  //在用户试图下输入telnet 命令，会提示输入用户名


按提示，输入用户名：along 密码：abc123，即登陆成功



9、查看设备上的存储文件列表
<R1>dir   //在用户试图下，输入dir命令，显示目录中的文件和子目录的列表
//红色方框中显示的是配置文件


可以通过下面的命令对配置文件（vrpcfg.zip 为配置文件）进行复制、移动、重命名、删除等操作。
copy source-filename destination-filename，拷贝文件
move source-filename destination-filename，移动文件
rename source-filename destination-filename，重新命名文件
zip source-filename destination-filename，压缩文件
delete [ /unreserved ] [ /force ] { filename | device-name } [ all ]，删除文件
