**二、编写脚本**

  

使用 vim /opt/ping.sh 命令，进行创建sh后缀名的文件和编写脚本：

然后 键盘上按一下‘i’，进入编辑模式：  

```
[root@localhost ~]# vim /opt/ping.sh#!/bin/bash. /etc/init.d/functions
for var in
 {10..25};do
$var
$ip
 >/dev/null 2>&1if [ $? = 0 ];then
"$ip" /bin/true
else
"$ip" /bin/false
fi
done
```

  

脚本写完后，按一下键盘的“esc”，然后输入 ‘：wq’   即，保存退出。
