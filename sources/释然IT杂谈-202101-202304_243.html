一、Oracle 安装

安装环境：Windows 2012 R2 64

1、点击目录中 setup.exe文件

2、配置安全更新，取消安全更新，点击下一步按钮

3、Oracle会弹出提示，点击是

4、单选跳过软件更新，点击下一步

5、安装选项中，选择第一个创建和配置数据库，点击下一步

6、在系统类中可选择桌面类和服务器类，这里选择桌面类，点击下一步

7、典型安装中，进行Oracle数据库的基本配置，可自行选择Oracle安装及软件目录，这里只对全局数据库名及管理口令进行更改，其他默认，点击下一步

8、下一步后，进行先决条件检测

9、干净的环境下安装一般不会有什么问题，直接点击安装即可

10、安装过程耐心等待

11、数据库创建完成后，会显示数据库信息，点击口令管理

12、对需要的用户进行解锁或口令更改，一般会用到sys、system及scott用户，注意要将需要用到的用户进行解锁（是否锁定账户的勾去掉）

13、口令更改完成后，点击确定按钮，此时会提示oracle数据库已安装成功。

14、检验Oracle安装成功，浏览器中直接输入:https://localhost:1158/em，输入之前口令管理中sys设定的口令，身份选择sysdba,登录成功及表示oracle安装成功。


二、Oracle 客户端安装


这里是配置远程连接Oracle，客户端是安装到自己的个人电脑

1、点击目录中 setup.exe文件

2、安装类型选择管理员，点击下一步

3、产品语言，默认，点击下一步

4、选择安装位置，路径可自行选择，安装的路径最好记一下，便于后面的配置用到。路径选择好后，点击下一步按钮

5、先决条件检查，主要检测当前所选择的环境是否符合oracle最低的安装和配置要求

6、点击下一步后显示Oracle Client安装的设置信息，点击完成

7、安装过程会需要一段时间，待出现安装成功提示，则表示安装已完成。


三、配置Oracle客户端远程连接服务器端


1、Oracle Client文件夹下的Net Configuration Assistant

2、选择本地网络服务名配置，点击下一步

3、选择添加

4、Oracle 数据库的服务名通常是全局数据库名，输入后点击下一步

5、网络协议默认选择tcp

6、主机名为Oracle服务端所在的Ip地址，端口号使用标准号 1521，输入完成后，点击下一步

7、测试是否能正常链接到oracle数据库，选择是，进行测试后，点击下一步

8、测试连接，Oracle会调用默认的用户名和口令，点击更改登录按钮

9、重新输入设定的用户名和口令，点击确定，重新进行连接

10、输入正确的用户名和口令后，显示连接测试成功，点击下一步

11、选择否，直接下一步

12、网络服务名配置完毕，下一步后点击完成即可。

Oracle客户端的配置也可以直接在文档中进行

1、找到Oracle Client的安装目录，在client_1\network\admin目录下创建tnsnames.ora文件

2、使用记事本打开tnsnames.ora，贴上如下内容

HOST：Oracle服务器IP地址
SERVICE_NAME：数据库实例名

PORT：默认端口是1521

3、tnsnames.ora内容编辑无误后，保存关闭即可配置完成。


四、Plsql安装并远程连接Oracle


1、点击开始安装，选择安装路径，其他都不需要配置，直接按照默认安装就行。

2、选择同意

3、选择安装路径，这里保持默认

4、选择默认典型安装直接下一步，最后点击完成即可完成安装

5、安装完成后，打开桌面Plsql图标（默认为英文，该工具已汉化）

6、点击cancel按钮，菜单栏中选择工具—首选项

7、勾选检查连接，点击下拉框选择Oracle主目录路径OCI库，这两项是之前Oracle client安装的路径，无需自己填写，点击下拉框一般会自己显示，如果没有显示，可能是Client配置不当或安装失败

8、以上设置完毕后，点击应用，在点击确定按钮，关闭plsql。再重新打开，输入Oracle用户名，口令，选择数据库名，输入完毕后，点击确定按钮

9、登录之后就可以对数据库进行操作了


五、注意事项


最近突然发现plsql连不上，于是尝试telnet 1521端口，于是发现端口连接失败的问题。


1、进入oracle数据库的安装目录找到这个路径：C:\app\Administrator\product\11.2.0\dbhome_1\NETWORK\ADMIN，


修改文件：listener.ora和tnsnames.ora

listener.ora，修改如下，注意：HOST修改为本机的IP地址。


LISTENER =

(DESCRIPTION_LIST =

(DESCRIPTION =

(ADDRESS = (PROTOCOL = IPC)(KEY = EXTPROC1521))

(ADDRESS = (PROTOCOL = TCP)(HOST = 172.19.102.202)(PORT = 1521))


listener.ora 监听文件，没有自动添加选中的sid_name的设置，这点需要注意检查配置。

(SID_DESC=

      (GLOBAL_DBNAME=ORCL)

      (ORACLE_HOME=C:\app\Administrator\product\11.2.0\dbhome_1)

      (SID_NAME=orcl)

   )


tnsnames.ora修改如下，注意：HOST修改为本机IP地址。


ORCL =

(DESCRIPTION =

(ADDRESS = (PROTOCOL = TCP)(HOST = 172.19.102.202)(PORT = 1521))

(CONNECT_DATA =

(SERVER = DEDICATED)

(SERVICE_NAME = orcl)


2、环境变量配置，也很重要，这是我本地的配置，缺一不可

ORACLE_HOME :  C:\app\Administrator\product\11.2.0\dbhome_2

ORACLE_SID: ORCL(实例名)

PATH:  C:\app\Administrator\product\11.2.0\dbhome_2\BIN

TNS_ADMIN: C:\app\Administrator\product\11.2.0\dbhome_2\NETWORK\ADMIN
