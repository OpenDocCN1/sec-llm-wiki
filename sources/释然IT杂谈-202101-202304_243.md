# **一、Oracle 安装**

安装环境：Windows 2012 R2 64

1、点击目录中 setup.exe文件

![](../Images/088b2c6d843e1904da372ea27e1ce465.png)

![](../Images/ec547f39aaf6f2147da3b6f4b2ca87e1.png)

2、配置安全更新，取消安全更新，点击下一步按钮

![](../Images/a411cade6c10f1d7abe8c94a0ef15f3f.png)

3、Oracle会弹出提示，点击是

![](../Images/11f1455e58d2127145b9be7b68ef3d44.png)

4、单选跳过软件更新，点击下一步

![](../Images/c13eb9dcaedacbd001fbb99c7717268b.png)

5、安装选项中，选择第一个创建和配置数据库，点击下一步

![](../Images/21ee14b28da12dd2d81301a2f3098642.png)

6、在系统类中可选择桌面类和服务器类，这里选择桌面类，点击下一步

![](../Images/ef0e6520e04c25cbd9ac13138e41027f.png)

7、典型安装中，进行Oracle数据库的基本配置，可自行选择Oracle安装及软件目录，这里只对全局数据库名及管理口令进行更改，其他默认，点击下一步

![](../Images/6273bc8a6bd3da074d35e8f69d921d86.png)

8、下一步后，进行先决条件检测

![](../Images/6586249459ab0ff482c1199489a41735.png)

9、干净的环境下安装一般不会有什么问题，直接点击安装即可

![](../Images/77e4a62eebf6087424c311a6e9024089.png)

10、安装过程耐心等待

![](../Images/3929f09719483f6971facabf81e5141f.png)

![](../Images/478010d759c4fa1adcd3ecd7640bcf36.png)

11、数据库创建完成后，会显示数据库信息，点击口令管理

![](../Images/e9eaf3a625974bb390a2b0a1b2ec7f02.png)

12、对需要的用户进行解锁或口令更改，一般会用到sys、system及scott用户，注意要将需要用到的用户进行解锁（是否锁定账户的勾去掉）

![](../Images/6bc2fd004a7b124e4f8d72a403554a19.png)

![](../Images/0a230bdd1e34db3d91f916bee7a2e042.png)

13、口令更改完成后，点击确定按钮，此时会提示oracle数据库已安装成功。

![](../Images/4595bc7762ad28e901cc2fe1f4337a69.png)

![](../Images/20082e5178d61be1a38b460ee44372f5.png)

14、检验Oracle安装成功，浏览器中直接输入:https://localhost:1158/em，输入之前口令管理中sys设定的口令，身份选择sysdba,登录成功及表示oracle安装成功。

![](../Images/c457fa9e4460120645b08593e64ec1c0.png)

![](../Images/5176e14a1e923fe8cef97632fe474c50.png)

# **三、配置Oracle客户端远程连接服务器端**

## 

  

1、Oracle Client文件夹下的Net Configuration Assistant

![](../Images/2d433e25994b4c220d7190a193cddd48.png)

2、选择本地网络服务名配置，点击下一步

![](../Images/c7c0c0b3fec425b4d00a77b9c279b115.png)

3、选择添加

![](../Images/46cff4954ecb3715476f5053acc07080.png)

4、Oracle 数据库的服务名通常是全局数据库名，输入后点击下一步

![](../Images/edd8c276e189f628bbc827f57951389c.png)

5、网络协议默认选择tcp

![](../Images/a972da82628d4bb440d5079d56e846e8.png)

6、主机名为Oracle服务端所在的Ip地址，端口号使用标准号 1521，输入完成后，点击下一步

![](../Images/d477e62ce4c452b86a03f6ef24eaacd1.png)

7、测试是否能正常链接到oracle数据库，选择是，进行测试后，点击下一步  

![](../Images/e3825a8d515e62d6f7bfcc925a550474.png)

8、测试连接，Oracle会调用默认的用户名和口令，点击更改登录按钮

![](../Images/1cc0e0d6318b86348c6428b53018443b.png)

9、重新输入设定的用户名和口令，点击确定，重新进行连接

![](../Images/369b9b1cb56cb423972654948d81aeee.png)

10、输入正确的用户名和口令后，显示连接测试成功，点击下一步  

![](../Images/09a9fb1e1783ce60146a82313aee45c3.png)

11、选择否，直接下一步

![](../Images/8819a876f1c2f82965b0f30b055ec833.png)

12、网络服务名配置完毕，下一步后点击完成即可。

![](../Images/299affb7f583926b4da311895a5ebab6.png)

![](../Images/3008e0bcf459ee92c091612474f2b832.png)

**Oracle客户端的配置也可以直接在文档中进行**

1、找到Oracle Client的安装目录，在client\_1\\network\\admin目录下创建tnsnames.ora文件

![](../Images/5f326de33d6b7d604a1a17e140338af7.png)

2、使用记事本打开tnsnames.ora，贴上如下内容  

**HOST：Oracle服务器IP地址  
SERVICE\_NAME：数据库实例名**

**PORT：默认端口是1521**

![](../Images/6e75f846989060f3eaccba110f07bc3a.png)

3、tnsnames.ora内容编辑无误后，保存关闭即可配置完成。

# **四、Plsql安装并远程连接Oracle**

  

1、点击开始安装，选择安装路径，其他都不需要配置，直接按照默认安装就行。

![](../Images/4daad71fb3b0b72d3312de53eacf79c4.png)

2、选择同意

![](../Images/0e1838f804aecc2822ba639d2a2416bc.png)

3、选择安装路径，这里保持默认

![](../Images/ae2692a11a43e33f1dd96ca24b7a330b.png)

4、选择默认典型安装直接下一步，最后点击完成即可完成安装

![](../Images/706f41cbe7c5c9d60076d1b2d824f6de.png)

![](../Images/d28473f20eeed7756d86450da947c631.png)

![](../Images/743b8d00351b92e02740a2260cf08aab.png)

5、安装完成后，打开桌面Plsql图标（默认为英文，该工具已汉化）

![](../Images/89b933ac7cb81160568874ed1e9d69b7.png)

6、点击cancel按钮，菜单栏中选择工具—首选项

![](../Images/63eb3c0494cffcbfa913194128aa002a.png)

7、勾选检查连接，点击下拉框选择Oracle主目录路径OCI库，这两项是之前Oracle client安装的路径，无需自己填写，点击下拉框一般会自己显示，如果没有显示，可能是Client配置不当或安装失败

![](../Images/25da001d1a5f3868dc35de27bc340be0.png)

8、以上设置完毕后，点击应用，在点击确定按钮，关闭plsql。再重新打开，输入Oracle用户名，口令，选择数据库名，输入完毕后，点击确定按钮

![](../Images/496b84e2a12504bbe9f4885b84b69f96.png)

9、登录之后就可以对数据库进行操作了  

![](../Images/1a1427cfceea4eadc96d53b5074d2fc0.png)

  

# **五、注意事项**

  

## 最近突然发现plsql连不上，于是尝试telnet 1521端口，于是发现端口连接失败的问题。

  

1、进入oracle数据库的安装目录找到这个路径：C:\\app\\Administrator\\product\\11.2.0\\dbhome\_1\\NETWORK\\ADMIN，

  

修改文件：listener.ora和tnsnames.ora

listener.ora，修改如下，**注意：HOST修改为本机的IP地址。**  

  

LISTENER =

(DESCRIPTION\_LIST =

(DESCRIPTION =

(ADDRESS = (PROTOCOL = IPC)(KEY = EXTPROC1521))

(ADDRESS = (PROTOCOL = TCP)(**HOST = 172.19.102.202**)(PORT = 1521))

  

listener.ora 监听文件，没有自动添加选中的sid\_name的设置，这点需要注意检查配置。

(SID\_DESC=

      (GLOBAL\_DBNAME=ORCL)

      (ORACLE\_HOME=C:\\app\\Administrator\\product\\11.2.0\\dbhome\_1)

      (SID\_NAME=orcl)

   )

![](../Images/c81784bef58e6b0dc0085776549d7541.png)

  

tnsnames.ora修改如下，**注意：HOST修改为本机IP地址。**

  

ORCL =

(DESCRIPTION =

(ADDRESS = (PROTOCOL = TCP)**(HOST = 172.19.102.202**)(PORT = 1521))

(CONNECT\_DATA =

(SERVER = DEDICATED)

(SERVICE\_NAME = orcl)

  

2、环境变量配置，也很重要，这是我本地的配置，缺一不可

ORACLE\_HOME :  C:\\app\\Administrator\\product\\11.2.0\\dbhome\_2

ORACLE\_SID: ORCL(实例名)

PATH:  C:\\app\\Administrator\\product\\11.2.0\\dbhome\_2\\BIN

TNS\_ADMIN: C:\\app\\Administrator\\product\\11.2.0\\dbhome\_2\\NETWORK\\ADMIN

  

![](../Images/0169d0fc3e50d2221e0c6e8d21c71342.png)

![](../Images/b9b466c7fdcf77d38e1b178de78cdd35.png)
