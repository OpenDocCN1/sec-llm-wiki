 用法比较简单，直接通过pip安装即可
pip3 install myqr


安装完成之后，就可以生成你想要的二维码了。对！就是这么简单...
 
图片必须是gif。默认是黑白的，因此需要加上 -c


代码如下：
myqr http://weixin.qq.com/r/khy5oY7EN9NIrcrC90mA -p pig.gif -n Python3X.gif -c
