**一、搭建教程**

准备工作：

1、一台电脑，搭建网站的时候必须要有电脑，没有电脑可以去网吧。

2、域名，服务器，没有的话需要注册购买。

3、注册域名：

https://dnspod.cloud.tencent.com/（复制到浏览器打开）在腾讯云注册，比阿里云便宜几块钱，而且小程序是运行在微信的，我们的域名和服务器都在腾讯云购买，会方便一些。

注意：域名选.com的，名字最好是纯拼音，这样好记。比如我的，直接用的执成随笔的拼音，zhichengsuibi。买完域名会提示实名认证，一定要实名，不实名没法用。

4、购买云服务器：

https://curl.qcloud.com/h596AQde（复制到浏览器打开）选择99元/1年那个，1核2G，云服务器。

选择 centOS 系统7.6 64 位（有新版本就选择最新版本），广州上海随便。

5、备案：

前 2 步做完，就不用管了，等域名实名认证后第4 天（工作日），在微信小程序里找“腾讯云助手”，进入后，点最下面的中间，找到“网站备案”

![](../Images/791a39c0573cbea7918e8a98f83eb31e.png)

按照提示来操作，没什么难度，一般几个小时后，就会接到腾讯云的审核电话，会给你说哪里需要修改，你按照他说的，改一改再提交就行了。一两天后会收到短信，按照短信提示，去填个验证码。具体备案时间，各地都不一样，一般都是一到两周。从域名注册到备案成功，大概要2-3周，这段时间需要耐心等待。

6、搭建面板：

解析域名：就是把域名和服务器关联起来，通过域名就能访问你的网站了，注意备案成功之前不要关联，不然审核不通过。

登陆“腾讯云”，点击右上角“控制台”，搜索域名，点“我的域名”：

![](../Images/00d822dfc9a8ed6627cf3115b44962b0.png)①在域名列表处选择需要解析的域名，点击“解析”，进入记录管理界面:

②点“添加记录”：主机记录用2 级域名，填一个字母就行，比如“z”，记录

![](../Images/75258abadb505c703ad62723614c9a6f.png)

类型 A，线路默认，记录值在你买的云服务器里复制主 **IPv4 **地址（公），或者点击“关联云资源”，直接关联自己的腾讯云服务器；(图中填的是 www,不建议用这个)

解析完，就代表可以通过你的域名访问你的服务器了，这时候服务器里还什么都没有，就要搭建服务器后台程序了。

![](../Images/6e66218689ad03a6bda2e4f1c234fee2.png)

  
①登陆服务器：

②登录后，安装宝塔面板

输入命令：yum install -ywget && wget -O install.sh

http://download.bt.cn/install/install\_6.0.sh&& sh install.sh

在光标处，复制粘贴上面的英文(用右键粘贴)，按回车

![](../Images/2227770d91839349ef6fb5fde9cc0755.png)

过几秒，让选择y/n，输入y，按回车

![](../Images/2a3b7482c02f2f13371c07645b228734.png)

大概一分钟，出现这个页面就是安装好了，记得复制相关信息：宝塔登陆链接、用户名、密码。

![](../Images/4d3261f22c574b9ce6366d510a579519.png)

③登陆宝塔控制面板安装环境打开刚才复制的外网面板地址，登陆，会弹出安装套件，选择 LNMP(推荐)，这 3 个按这个设置：nginx1.15+MySQL5.6+php7.2，然后点一键安装，需要 10 分钟左右，具体设置可参考下图：  

![](../Images/547dc22e7fc197bc1c1ac5e56738dad1.png)

④安装好后，会提示登陆宝塔账号，注册一个就行了。然后就是添加站点：

1、

![](../Images/8930a9c3979ebe73ced0742bf27ca06c.png)

2、域名填上面解析的域名，数据库选MySQL，会自动创建，php选 7.2，其他的都不用动，然后点提交。如下图：

![](../Images/48792c20f2ff36f00a0ff384342dd6a9.png)

面板安装后，开始后台安装：

  

**1**、下载源码（文章最后有），解压后把后端**.zip **上传到网站根目录，然后解压。1、修改数据库文件

![](../Images/03261110bbd2b9903449b9c4504a209e.png)

1.把 Application\\Common\\Conf\\config.php这个文件修改里面的数据库信息，把数据库名称，账号，密码，改成自己的。

![](../Images/d4abb633b1bd5c3551eddd383d500dbb.png)

2.把源码里的数据库文件 mx.sql，导入你的数据库

![](../Images/6107ba5a6da217e06a6d5cb6284a9bb5.png)

4、  宝塔设置 thinkphp 的伪静态

5、  登陆后台，入口是域名/youni 默认账号密码 admin  1231236、  根目录下 Public\\Ueditor\\php\\config.json 修改 11行改成自己网址.进入后台，可以修改东西了，这个比较简单，就不介绍了。  

后台完成后，安装前端：

**1、**直接把源码里的前端文件夹，导入小程序开发者工具。

1).将 https://mx.zhichengsuibi.com修改自己的域名，一共2 个位置。

位置：mp-weixin/common/main.js 和 mp-weixin/pages/login/login.js。

2).搜索“聚能小课”，替换成自己的小程序名字，一共有两处，一搜就出来了。

**2、**然后就可以发布了。

注意：先写几篇正常的文章发布，获取方式，**2 **篇选免费的，**2 **篇选 **VIP **的。因为审核时，他们点开 **VIP**，里面没有内容，会审核不通过。

写文章时，资源地址一定要填，随便填个网址就行，不填的话，审核人员没法复制，会判断功能不全。
