## 前言

后台开发，netstat命令总是绕不过，不仅工作中经常用过，面试也是考的多。netstat命令，对应的选项比较多，功能比较强大。netstat 常用来查看，后台服务进程的相关状态。  
  
netstat 可以用来打印网络连接、路由表、连接的数据统计。下面我们来学习一下。

![](../Images/6ecb529814d3bc933af540e7e8473d4f.png)

  

## **打印所有连接**

使用 -a，列出所有连接。

```
[root
```

  

## **打印 TCP 或 UDP 连接**

使用 -t 选项列出 TCP 协议的连接。

```
[root
```

  

使用 -u 选项列出 UDP 协议的连接。

```
[root
```

  

## **禁用反向域名解析**

使用 -n 选项禁用域名解析功能，这样可以加快查找速度。

```
[root
```

  

## **显示对应的程序识别码和程序名称**

使用 -p 选项列出正在监听的套接字。

```
[root
```

  

## **打印监听中的连接**

使用 -l 选项列出正在监听的套接字。

```
[root
```

## **打印连接进程信息**

使用 -p 选项查看进程信息。

```
[root
```

  

## **打印网络工作信息统计表**

使用 -s 选项查看进程信息(只展示部分结果)。

```
[root
```

  

## **打印网络接口**

使用 -i 选项查看进程信息。

```
[root
```

  

## **持续输出信息**

使用 -c 选项查看进程信息。

```
[root
```

  

## **根据进程pid查端口**

利用 grep 命令，通过进程 pid 查出监听端口。

```
[root
```

  

## **根据端口查进程**

利用 grep 命令，通过监听端口查出进程 pid 。

```
[root
```

  

## **统计网络socket状态**

借助 awk 命令，统计socket状态对应的个数。

```
[test]# netstat -n | awk 
```
