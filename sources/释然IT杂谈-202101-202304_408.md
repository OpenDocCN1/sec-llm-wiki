大家好，我是 JackTian。

之前给大家分享了一篇《[适合程序员的精选面试题清单](https://mp.weixin.qq.com/s?__biz=MzAwMjg1NjY3Nw==&mid=2247492852&idx=1&sn=5c197193c3af7ae299f4ae555af9c6af&scene=21#wechat_redirect)》这份面试题清单主要包括内容：编程语言/框架/平台、数据库技术、缓存技术、操作系统、数据结构与算法、区块链、编码练习、综合清单、设计模式、网路、安全、数据科学等；

不知道是不是大家没在处于找工作或跳槽的阶段，还是大家平时在面临找工作前都没有刷题的习惯，反正那篇文章阅读量不是很理想。

但不管怎么样，内容还是非常超赞的。只要你面临着要开始找工作或即将跳槽，翻过头来查看这篇文章，相信你能从中找到适合自己领域的面试问题，也说不好你所刷到的面试题就是你在面试时对方所出题的范围之内。

这次闲逛 GitHub 网站时，发现了这个存储库，主要包含：Linux、Jenkins、AWS、SRE、Prometheus、Docker、Python、Ansible、Git、Kubernetes、Terraform、OpenStack、SQL、NoSQL、Azure、GCP、DNS、弹性、网络、虚拟化、DevOps 面试问题以及其他各种技术主题的问题和回答。

目前共有 1250 个问题，相对来说，这个开源项目更偏向于从事运维领域的读者朋友。

大家感兴趣的话，可以自行去查找弥补自己对某个知识点不足的相关问题。

除此之外，如果你正在寻找一种为考试做准备的方法，接下来的内容将是适合你的部分。

目前仅包括：**Cloud Practitioner（云实践者）、Certified Kubernetes Administrator (CKA) （Kubernetes认证管理员（CKA））** 两项。

通过如上两项内容找到目前适合自己的证书列表，每个证书都将会指向一个单独的文件，这些文件都是带有重点突出性的问题，可帮助你考试准备。
