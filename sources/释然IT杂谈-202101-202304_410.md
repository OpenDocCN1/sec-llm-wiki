**【干货】华为/思科命令对照表**

  

华为如今在许多中国人心中有着极高的地位，它的通信业务早就扩张到了全球许多个国家与地区，强如美国都为高速崛起的华为感到害怕，但其实华为在发展的过程中也不是顺风顺水，毕竟在国际上还是有许多强大的竞争对手，比如今天我们要讲的思科，它的市值曾经排名全球第一，超过微软与苹果，甚至可以说，没有曾经思科就没有今天的互联网。

  

那我们今天着重介绍一下，两大网络厂商路由交换设备基础配置命令对比：

  

| 思科 || 华为/H3C || 描述 |
| --- | --- | --- |
| no || undo || 取消、关闭、删除  配置 |
| no debug all || Ctrl + O（键盘按键） || 取消所有debug进程 |
| exit || quit || 从当前视图退回到较低级别视图，如果是用户视图，则退出系统 |
| end || return || 从除用户视图外的其它视图退回到用户视图 |
| delete || delete || 从用户视图删除指定文件 |
| reload || reboot || 通过命令远程重新启动设备 |
| write || save || 保存当前配置信息到系统默认的存储路径中 |
| hostname || sysneme || 设置设备的主机名 |
| enable，configure  terminal  || system-view || 从用户视图进入系统视图 |
| username || local-user || 创建本地用户，并配置本地用户的各项参数 |
| shutdown || shutdown || 禁止、关闭 |
| show || display || 查看、显示 配置 |
| show  logging || display  logbuffer || 查看日志 |
| startup-config || saved-configuration || 系统启动的配置 |
| running-config || current-configuration || 系统当前运行的配置 |
| show startup-config || display saved-configuration || 查看当前保存的配置 |
| show  running-config || display  current-configuration || 查看当前配置 |
| show peocesses || display cpu-usage || 查看CPU的状态信息 |
| erase  startup-config || reset  saved-configuration || 删除系统启动配置 |
| logging || info-center || 设置信息中心配置信息 |
| line || user-interface || 进入线路配置 |
| host || ip host || host名字和ip地址对应 |
| enable  password || set  authentication password simple || 配置明问密码 |
| interface vlan 1 || interface vlan 1 || 进入vlan 1接口配置 |
| interface  range gigabitEthernet 0/1 - 4 || interface  gigabitEthernet 0/1 to  gigabitEthernet 0/4 || 进入多个连续接口 |
| enable secret || super password || 设置特权口令 |
| duplex（half  | full | auto） || duplex（half  | full | auto） || 配置接口状态 |
| speed（10/100/1000） || speed（10/100/1000） || 配置端口速率 |
| switchport  mode access || port  link-type access || 配置接口模式为ACCESS |
| switchport access vlan ID || port default vlan ID/port access vlan ID || 配置接口为VLAN ID |
| valn  ID   /no vlan ID || vlan  ID   /undo vlan ID || 添加/删除vlan  ID |
| encapsulation  || link-protocol || 封装协议 |
| channel-group  1 mode on || port  link-aggregation group 1 || 链路聚合 |
| ip routing || 默认开启 || 开启三层交换机的路由功能 |
| no  switchport || 不支持 || 开启接口三层功能 |
| vtp || GVRP || 对跨以太网交换机的VLAN进行动态注册和删除 |
| ip  route 0.0.0.0 0.0.0.0 202.202.202.202 || ip  route-static 0.0.0.0 0.0.0.0 202.202.202.202 || 默认路由 |
| show ip route || display ip routing-table || 查看路由表 |
| router  rip || rip || 启用RIP协议 |
| no auto-summary || rip split-horizon || 取消自动汇总/配置水平分割 |

| show ip bgp summary || display bgp peer || 查看BGP邻居关系 |
| show  ip bgp all || display  bgp routing-table || 查看BGP路由表 |
