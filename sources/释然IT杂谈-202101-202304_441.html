非小编开课，推广而已

学习方式：

   小班教学（20人以内），直播面授

培训优势：

   很多人在从0自学的过程中，都会绕很多弯路、踩很多坑、浪费很多时间，最后还达不到预期的目标，我们采取直播面授的形式，手把手教学，系统化培训，严格控制每个班次人数，达到较好的培训效果。

目标人群：

   想学渗透测试，但是自学能力不强，基础相对薄弱的学员。

第一原则：

   不得滥用技术从事违法犯罪有关活动，参与培训人员必须明确表态。

培训时间：

   每周抽出三天晚上参与直播学习，每次为期3-4小时，周末根据安排另行通知，错过的可以看视频回放。


培训周期：

    三个月

课程安排（包括，不限于以下内容）：

 

前言：

    1.网络安全法普法教育

    2.web渗透测试整体行业介绍

纲要：

├─001基础入门

│      渗透思路讲解

│      网络安全相关基础知识铺垫


├─002信息收集

│     域名、子域名、真实IP

│     端口及目录后台探测

│     网站脆弱资产初判

│     社工技巧

├─003SQL注入

│     SQL注入原理

│     SQL注入流程及常用技巧

       靶场实操

├─004文件上传

│      文件上传原理

│      文件上传流程

│      文件上传技巧

│      文件上传绕过限制

├─005XSS漏洞

│      XSS漏洞原理及分类讲解

│      XSS漏洞怎么探测和利用

│      XSS挖掘工具

│      XSS绕过防护技巧

├─006其他不常见漏洞

├─007逻辑漏洞

│     登录界面逻辑漏洞

│     数据篡改逻辑漏洞

│     暴力破解相关

│     token及验证码绕过

│     手机及邮箱绑定绕过

├─008渗透测试工具使用

│  AWVS

│  NESSUS

│  SQLMAP

│  BURPSUITE

│  NMAP

│  其他工具

 

课程收费：

    3000元每人，无后续费用

课程效果：

三个月内完成入门，了解掌握web渗透测试的常用方法，熟悉渗透测试方法论，独立完成渗透测试。

注  意：

学习效果主要看个人努力，不能保证你能因此找到工作或者一定能学会，凡事要对自己负责。
