近日,一名粉丝急切的联系我们,说自己被一个商城网站骗了巨额现金，最主要的是自己偷刷了父母的卡，为维护未成年受害者及保护他的隐私--全程打码。

**来龙去脉**

### 我们首先询问粉丝受骗的具体经过，第一时间归总出大概流程如下：

1.骗子先找买卖二手手机的群。

2.给群主发广告费（用好处费锁定目标）让帮自己宣传。

3.骗子随便抓羊，开始诈骗，过程中群主给做担保。

4.骗子发给受害人假的商城网址，让其选购购买

5.付款成功，告辞 拉黑 遇到年轻的受害者也会一直套。。。。。

  

**网站分析**

1.网站服务器 : 美国 Linux

2.网站环境 : 宝塔 + php + nginx

3.网站源码 : shopxo 1.6

4.接下来，我只能用我小学学的计算机基础去试试了。

**及时止损**

翻到订单页看到好多刚下的订单，以及准备支付的受害者，为了能够告诉他们真相即时止损，我们不停的挨个打电话！意在把大家的损失降到最低，遗憾的是很多人挂掉了我们的电话，还有的打到了家长手机上，我承认，当我把这个消息告诉他家长时，这孩子心里应该有一万只草泥马在奔腾，但是为了维护更多人的利益，我们只能这么做！

**重拳出击**

过程比较曲折，我给大家直接做总结：

1.加上对方我直达主题，把被骗的信息都给他发过去，遭到对方删好友威胁

2.再次加上骗子，并严肃警告他，他的行为已经违法，把可能的结果告知于他让他自我判断利害

3.紧接着跟进。并谈判让他还钱

4.还钱到位，为粉们追回损失
