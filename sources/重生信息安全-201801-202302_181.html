ExploitOnCLI - 在终端中搜索漏洞的最佳工具

ExploitOnCLI或“EOC”是一个用PHP编写的用于Linux的工具，旨在搜索多个漏洞数据库中的漏洞（不会执行在线搜索，而是在本地文件中执行），数据库是：

  • 利用-DB

  • PacketStormSecurity

  • IEDB

  • Siph0n

  • CXSecurity

  • Exploit4Arab

显示的结果将被过滤，因此可能会发生数据库“覆盖”，具体取决于正在搜索的内容（字符串）。

在这个版本中，我们有以下选择：

简单搜索：root @ root〜＃php eoc.php --search / -s EX：root @ root〜＃php eoc.php --search / -s RobotCPA

简单的更新：root @ root〜＃php eoc.php --update

更新一个特定的数据库：root @ root〜＃php eoc.php --update =“DBS”EX：root @ root〜＃php eoc.php --update = iedb EX2：root @ root〜＃php eoc.php -更新= IEDB，PacketStorm的

寻求帮助：root @ root〜＃php eoc.php --help / -h

对于'about'：root @ root〜＃php eoc.php --about / -a

选择将结果下载到本地文件夹：root @ root〜＃php eoc.php --down / -d
