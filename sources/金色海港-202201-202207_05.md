Woocommerce程序到10万条就崩溃了，但是那个商店的商品个数能到十万呢？即使到十万（关键词到十万），谷歌收录能到多少呢？我的商店崩溃了，所以就没有机会观察到谷歌的收录情况。

现在只有一种选择：使用Python直接连接wordpress的mysql ，进行POST炒作。当然需要对wordpress的POST操作对数据库的上传进行模拟，这里核心代码就不粘贴了，就是Python 对mysql的炒作而已。

几天后，10万多页面上传完毕，提交谷歌，谷歌对新站的完全收录大概在一个月内完成；但是是按照比例进行的，虽然前十天收录的比较慢，但是半个月后会到一个高峰期。我的一个十万级的网站10天才收录一千个页面？什么意思吗？

人丑钱来凑，关键词我有，就是外链没有吗，那就写脚本发外链吧。第一个想到的平台是twitter,facebook,wordpress.com.

先拿Twitter练手吧，但是毕竟第一次发外链，也深知Twitter在外网的地位，反爬虫和反垃圾信息手段是一流的（这是后话），但是不试试，哪里知道水深浅呢？上playwright，等等，发外链需要文章题目与对应链接，我就去wordpress的mysql 看了有一下，什么鬼，mysql的展示链接与题目根本不对应，因为wordpress可以选择网页连接的几种形式，有id,有日期的，等等。。

哪怎么搞了？使用自动化去发外链肯定需要网页题目与对应的链接，只有一条路：使用scrapy去爬自己的网站？呵呵，真是个笑话，自己明明有数据库的控制权还要写爬虫去抓取。看来wordpress真的不适合我了，黑盒而已

![](../Images/7f3f1debbab135e0a7e5206e3d01c0c3.png)侦探了一下，幸亏数据量很小，一小时调完爬虫，两小时爬取完毕，题目与对应链接存到mysql中，上playwright

```
















browser = playwright.chromium.launch()
```

每条数据间隔20~40秒，因为我知道Twitter有高压线，但是不知道高压线在哪里。等发到900条附近的时候，playwright报错了，一登录才知道Twitter把我的账号封了，封的理由是发送垃圾信息。
