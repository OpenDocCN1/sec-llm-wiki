# 本机基础收集      

1、whoami /all 查看当前用户管理权限及一些信息

![](../Images/91a38207f25be630d04ab20a8da34514.png)

2、ipconfig /all 查看网络配置信息

![](../Images/ead9f718b8f9707f11bc34564038c96c.png)

3、route print 查看主机路由信息

![](../Images/df0792dfe4cf2c9ab54a191f29fd7186.png)

4、systeminfo 查看操作系统信息

systeminfo | findstr /B /C:"OS name" /C:"OS version" 指定

![](../Images/bfa4a7eb1f047c104473fef9b6b6f33a.png)

5、netstat -ano 查看端口连接信息

![](../Images/906dee8d6f4e4da9082d30c07643c1c8.png)

6、net session 查看当前会话列表

![](../Images/a1e7552fea0f009eccc508733b65058b.png)

7、net share 查看网络共享信息/共享文件夹

![](../Images/c02bffedd4b75f27eb9a4927c9836c74.png)

8、net use 查看已连接的网络共享

![](../Images/232b863c6795098db5f5bee756bab377.png)

9、tasklist 查看进程信息

也可以使用wmic进行指定查询某个进程的信息；

![](../Images/8fce7d9b9021c0dd8b328a6f7940df0a.png)

10、wmic process get Name, ProcessId, ExecutablePath

查询主机进程信息，并过滤出进程的路径、名称和PID

wmic process where Name=" msdtc.exe" get ExecutablePath

查询指定进程路径

![](../Images/a27b2aa566aac5a617257fec50e3f1a0.png)

11、wmic service get Caption, Name,PathName, StartName, State

当前服务信息

wmic service where Name="backdoor" get Caption, PathName, State

指定查看

![](../Images/6a19b624ad00f527f03cb54fc80161ef.png)

12、schtasks /query /v /fo list

查看计划任务信息

![](../Images/3576f023adf42b05c5c477956d8ef849.png)

13、wmic startup get Caption, Command, Location, User

查看自启程序信息

![](../Images/c5d3a355505ccaa5753e52474206ae33.png)

14、wmic qfe get Caption, CSName, Description， HotFixID，InstalledOn

查看布丁描述信息（指定查询）

wmic qfe 查询布丁信息

![](../Images/c7aa28452cfaf2dc9bf6c53babd6ff29.png)

15、wmic product get Caption,Version

查看应用安装信息

![](../Images/64ae6cf4981b443e04a5e7193a3808cb.png)

16、net user 查看本地用户/组信息

net user <名字> 查看指定用户详细信息

net localgroup administrators 查看管理员组

![](../Images/17f8fcdaf05c9f7d41c2ad52bf5b4eeb.png)

![](../Images/d5ea1b9d066f8a0c0d212899ee8c079c.png)

17、net user <用户名><密码> /add 创建本地用户

net localgroup administrators <用户名>/add 将用户加入本地管理员组

18、query user 查看当前登录的用户

win10中正常，win11中提示无命令

![](../Images/9b757030b17c849cea2400520dd5792d.png)

![](../Images/54705b840f5a7f2e43f9039594d2c4d4.png)
