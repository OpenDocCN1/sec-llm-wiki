# 【安全工具】内存中读取mysql的root密码

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUyODE3NzYxMw==&mid=2247484013&idx=1&sn=e7538725d2ba19fcf0511d63eddbc2d5&chksm=fa7502cfcd028bd9bb020566611b23f010f213ed5d69c9486ecd9a5cd39ff8830d3fcf6018a9&scene=126&sessionid=1681668043#rd](http://mp.weixin.qq.com/s?__biz=MzUyODE3NzYxMw==&mid=2247484013&idx=1&sn=e7538725d2ba19fcf0511d63eddbc2d5&chksm=fa7502cfcd028bd9bb020566611b23f010f213ed5d69c9486ecd9a5cd39ff8830d3fcf6018a9&scene=126&sessionid=1681668043#rd)

声明：请勿使用非法目的。  

利用条件目标是获取通过tty传递的密码，也可以获取从命令行（-pxxxxxx）传递的密码。  

  

**0x00 安装**  

安装：

1、git clone --recurse-submodules https://github.com/hc0d3r/mysql-magic 

2、cd mysql-magic 

3、make #编译

```
mysql-magic [options] <pid> -o <offset>   逗号分隔的内存地址列表例0x123,0x1234 -s            内存搜索密码 -d <dir>      写入内存目录 -l            监听Listen mode, wait for outgoing ipv4 connections on port 3306 -r <secs>     Sleep time (Default: 3 seconds) -p            Use process_vm_readv instead of /proc/pid/mem
```

/mysql-magic -s 

使用-s 在内存搜索密码
