# 人大代表：不能坐视黑客增速超过网安人才

    网络、计算和存储是大数据的三大基础设施。但很多人并不知道，除此以外，全球还有一个千亿美元级产业：网络安全。

  

![](../Images/afebc98919d6f35d10089028099a4bb1.png)

  

     市人大代表、万得信息技术股份有限公司董事长陆风说，可以说，网络安全已经成为大数据第四大基础产业。

  

      陆风说，当前，受全球网络安全攻击的地区分布主要集中在中美两国，在国内看，主要集中在江浙沪、广东和北京。“可见，越是经济发达地方，受攻击的可能越大，需保护需求越大。”

  

   与此同时，随着互联网的发展，各类软件层出不穷，保护网络安全的相关技术人员面临严重匮乏的局面。数据显示，2019年，全球网络安全人才缺口扩大到300万，且主要集中在亚洲，仅中国就存在150万缺口，占一半以上，以至于“网络犯罪人员的增长速度，比网络安全保护人员的增长快得多”。

  

   陆风认为，目前，上海在网络安全防范方面较为薄弱，网络安全技术人员缺乏，网络安全事件无法及时响应，造成极大损失。为此他呼吁，上海应加快网络安全立法的修改，扩大网络安全保护范围。

  

   “只要是联网的设备，哪怕是一个机床，一个话筒，都要有安全防控规范。”陆风说，“要把网络安全像消防安全一样重视起来，定期检查、演练。”

他同时建议，上海应该加快网络安全人才的引进培养，吸引更多人才到上海落户，并探索高校与网络安全公司合作培养相关人才。

  

    陆风表示，由于网络安全技术的敏感性，许多技术难以大范围公开传授，只能通过选择品学兼优的学生，在实践中教学。

  

   他还表示，上海应提升网络安全产业发展水平，包括安全服务、风险管理等领域，通过产业升级更好保护网络安全。

  

  陆风提醒，网络安全本身也是一项颇有发展潜力的产业。他介绍，目前中国网络安全产业规模很小，尚不到100亿美金；美国网络安全指出占信息科技支出4.78%，而中国仅占1.84%。
