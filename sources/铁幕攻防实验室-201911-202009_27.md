# xray与awvs联动让漏洞无处遁形

  xray社区版扫描器是从长亭洞鉴核心引擎中提取出的部分功能，目前支持主动、被动多种扫描方式，自备盲打平台、可以灵活定义 POC，功能丰富，调用简单，支持 Windows / macOS / Linux 多种操作系统，可以满足广大安全从业者的自动化 Web 漏洞探测需求。

  

  Acunetix Web Vulnerability Scanner（简称AWVS）是一款知名的网络漏洞扫描工具，它通过网络爬虫测试你的网站安全，检测流行安全漏洞。

  
  经过小编测试xray的爬虫能力较弱，无法较全的将web应用的url提取出来。这个时候官方给的解决方案是可以通过联动awvs来进行加强爬虫能力。

以 awvs 12 web 版为例，登入管理页后，点击 Targets, 然后点击 Add Target 添加扫描目标:

![](../Images/b201c6a78b55412cbd904f88475996ee.png)

然后切换到 HTTP 的部分，填写 xray 的 HTTP 代理。

![](../Images/d93b0c8aa25ad7c8defa480647178ffa.png)

地址需要根据实际情况填写，需要填写为 awvs 所在机器（容器）内能够访问到 xray 代理的地址。如果 xray 在外网，则填写为外网主机的 IP 地址。端口填写为上面启动时设置的端口号。

其他项可以按需调整或保持默认，然后点击 scan 按钮，按图示选择 Crawl Only 即仅使用爬虫，然后点击 Create Scan 就可以开始扫描了。

![](../Images/b4ccb90aefe91991a6ac298b7d8db01a.png)

检查 xray 的界面有没有在扫描，如果有类似下图的结果说明工作正常，等待扫描完成即可。

![](../Images/f76c647e6de3e6f19a81d679a109a03d.png)

扫描完成后可以查看 avws.html 查看漏洞详情。超级简单，赶快搞起来！！！
