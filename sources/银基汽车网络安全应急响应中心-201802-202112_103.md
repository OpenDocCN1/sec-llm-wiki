# SSC安全峰会预告：车联网安全技术干货，敬请期待

2018年第三届SSC安全峰会（CloverSec Security Conference）将于9月18日在西安召开。本次会议以“智御安全•洞鉴未来”为主题，同来自全国的网络安全专家、行业大咖、网络安全爱好者一起关注与分享“网络安全”。

![](../Images/10994966f44646f458b92974ab7139f8.png)

本届高峰论坛分为主论坛和分论坛，主论坛以引领安全新方向，探究安全新理念，共创安全新未来为主题；分论坛则以分享技术干论坛分货，交流前沿技术，共享研究成果为主要内容。

在白帽子技术论坛中，众多技术干货将呈现给大家。银基安全的Hackbar将以《车联网安全建设经验分享》为议题，通过介绍车联网“三位一体的新安全”模型，从车联网架构、安全需求、威胁建模等方面出发，分享建设车联网安全的经验，并结合CarSRC，同大家展示分享如何建设车联网安全生态圈及提高威胁感知能力。

![](../Images/f46b6b7c93ba3470123a0b000d32bf56.png)

在新能源与智能网联汽车产业发展的今天，车联网技术应用越来越广泛，车联网业务安全也越发受到重视。银基安全也将保持对安全行业新动态的洞察，同业界专家们探讨研究，探索安全发展新趋势，一同推动国家网络安全事业整体发展，助力网络强国建设。
