# 春秋云境Initial通关

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwNzI0MTQzOA==&mid=2247493137&idx=1&sn=e8f3c7abe7d9ddb23f819930a07d3ce0&chksm=c0de94a0f7a91db628e375d8006224b8c65310c4d9f4de46b7bc4cf3d3e0b3a32341dee37190&scene=126&sessionid=1681664581#rd](http://mp.weixin.qq.com/s?__biz=MzkwNzI0MTQzOA==&mid=2247493137&idx=1&sn=e8f3c7abe7d9ddb23f819930a07d3ce0&chksm=c0de94a0f7a91db628e375d8006224b8c65310c4d9f4de46b7bc4cf3d3e0b3a32341dee37190&scene=126&sessionid=1681664581#rd)

前言

![](../Images/9755b7916d0eacc31ce03ff37aa8aab7.png)

  

Initial是一套难度为简单的靶场环境，完成该挑战可以帮助玩家初步认识内网渗透的简单流程。该靶场只有一个flag，各部分位于不同的机器上。

![](../Images/464ee74358f35444fab213f93d62919d.png)

![](../Images/af99f8a80f68f98146192933d1c9611d.png)![](../Images/a40f8f909d27a43b002a18bb4366d682.png)

步骤

![](../Images/9755b7916d0eacc31ce03ff37aa8aab7.png)

  

入口处是一个电源管理系统，指纹识别可以得出是thinkphp框架，直接用工具扫描是否存在thinkphp漏洞。  

![](../Images/1a0275d787d790a9dba45abe355d9c0a.png)

  
确定有漏洞后就可以直接进行RCE。

![](../Images/288a3eb23fe0eeff90daa18558040a0e.png)

  

getshell后拿的权限是www-data权限，这里可以使用sudo提权来读取flag1:(sudo mysql -e '\\! cat /root/flag/flag01.txt')

![](../Images/5224a3ac5f73ed923d787c9dc08d7009.png)

![](../Images/d9ea964c0969509650725b7bfa32e906.png)

  

拿下第一个flag后用frp带代理扫描内网机器，扫描结果如下：

*   
*   
*   
*   

```
172.22.1.2（域控）172.22.1.15（边界机）172.22.1.18（信呼协同办公系统）172.22.1.21（永恒之蓝）
```

  

![](../Images/bb55e282f9d06505c5338ae05c4246f0.png)

  

首先使用永恒之蓝拿下172.22.1.21这台机器，这里可以使用msf的ms17-010模块进行攻击。

![](../Images/4b88fb27d46490eeca12487ba3c7b086.png)

![](../Images/ecbf0c7abd9268ea8fbb5330f6319c72.png)

  

但是在这台机器上并没有拿到第二个flag，根据提示可以利用DCSync进行下一步操作

![](../Images/3fbde02e95606d993666a24714e7e196.png)

  

使用kiwi模块读取域内用户hash后可以利用crackmapexec脚本获取域控权限并读取flag

![](../Images/1e9546a44d1e9f39aeabdff7d3451977.png)

这里读取到的是flag3，看来flag2在172.22.1.18这台机器上。

![](../Images/6a1221e45134b5be33146bc0358a4a57.png)

针对172.22.1.18这里提供三个方法获取权限，由于172.22.1.18也在域内，第一个方法可以直接利用上面的域管hash来读取flag。

![](../Images/f46dfe381f06efff64b105c6cc986ecc.png)

方法二是直接利用信呼OA漏洞进行文件上传来getshell

![](../Images/4db3940349ec977a4c0d435c07f7cce5.png)

网上有相关脚本，可以直接利用

![](../Images/c8523220890ea125f9878998ec23b298.png)

  

![](../Images/7485ab9887e04d5766e4a77a3bcfe10e.png)

方法三是利用172.22.1.18上开放的phpmyadmin进行写文件（账号密码root:root），这里不再进行演示。

![](../Images/835cb8f4dc1d29d436a27f81448ff696.png)

![](../Images/af99f8a80f68f98146192933d1c9611d.png)  
![](../Images/a40f8f909d27a43b002a18bb4366d682.png)

总结

![](../Images/9755b7916d0eacc31ce03ff37aa8aab7.png)

  

总结一下该靶场的相关流程：

首先使用thinkphp漏洞拿下边界机（flag1）→做代理利用ms17-010拿下域内机器→DCSync拿下域管理员权限（flag3）→使用域管理员权限读取flag2
