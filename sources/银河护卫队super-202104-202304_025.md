# 对一次钓鱼邮件攻击的简单溯源

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzkwNzI0MTQzOA==&mid=2247490835&idx=1&sn=2178b659a9075896e9138b3b5cd3a58a&chksm=c0dd6fa2f7aae6b437bb0a05921692b6c01d5c5274bca64e2f541b99c93b7cc91cb3feb0d661&scene=126&sessionid=1681664605#rd](http://mp.weixin.qq.com/s?__biz=MzkwNzI0MTQzOA==&mid=2247490835&idx=1&sn=2178b659a9075896e9138b3b5cd3a58a&chksm=c0dd6fa2f7aae6b437bb0a05921692b6c01d5c5274bca64e2f541b99c93b7cc91cb3feb0d661&scene=126&sessionid=1681664605#rd)

第二封：

![](../Images/f87fbe63f0f59bee5f7ee56a7aaa54e4.png)

  

**2**

**溯源**

邮件内容中，欺骗用户连接的URL地址也是一样的，都是：

*   

```

```

因此，可认定为同一个组织/个人实施的邮件欺骗攻击。

唉，怎么一不小心就成为攻击目标了，还一天两封，晕。

今天在outlook直接点击访问，发现360已经会进行拦阻，显示如下：

![](../Images/3f7d4aeb243a0678082257d015ce9125.png)

直接复制url：http://xiangwangshenghuo.cn/page.php进行浏览器访问，登陆界面如下：

![](../Images/f2cb12192bc7519d6850d4a0a469520a.png)

欺骗用户填写邮箱的账户和密码。

如果直接访问主页http://xiangwangshenghuo.cn，发现显示的也是邮件登陆系统，界面如下：

![](../Images/542be509b1fa3de2a0ba33aa946d8a6e.png)

随便输入虚拟的邮箱账户和密码，显示“密码错误”，如下。

![](../Images/4a32b8c1765cb001c62f485dc0002e05.png)

网站的结构大概如下：

![](../Images/6acf5e6c755ba6e792258a56e5bab0b4.png)

很明显，这就是赤裸裸的邮件钓鱼攻击，用于收集被攻击对象的邮箱账户和密码。

通过分析邮件头属性，发现攻击者没有对邮件头进行信息伪造，邮件实际发送者就是outlook邮箱中显示的发送者，分别是<market@jinglun.com.cn>和<wangren@micropoint.com.cn>，这两个域名是国内正常的两家公司，说明攻击者通过其他手段获取了这两个邮箱的控制权限，尤其是micropoint.com.cn这家公司，还是做网络安全业务的。

第1封邮件头如下：

![](../Images/d8c938b722abb2e2bbdb3b8eed1622f8.png)

从上图可知，该邮件是通过主机名为PC293的主机发送的，网关地址为：10.10.10.1。

第2封邮件头如下：

![](../Images/4638feae503e0637f0c49ba4d457e2dc.png)

从上面的邮件头可以看出，攻击者通过名为PC293的主机发送邮件，但是本次外部IP地址却明显显示在邮件头里面，该IP地址为：58.243.143.201，根据IP地址查询为安徽黄山的联通用户，因此我们可以猜测上面的10.10.10.1是否是联通内部的网关地址？

![](../Images/be05e9011931de085b1be83b635721ee.png)

再来看看欺骗域名的情况，xiangwangshenghuo.cn应该是汉字“向往生活”的拼音，不知道攻击者是希望过上怎样的生活，呵呵。

通过ping解析，域名指向的IP是156.234.27.228，位置在中国香港。

![](../Images/e99b1e6bc09320ebc35b627a9f0fbc95.png)

![](../Images/38f2e5595d1adddca70c4b25538d784e.png)

我们再来查看156.234.27.228上绑定的域名，查询结果如下，一看都是近几天才绑定的域名，汗，没想到邮箱竟直接成为首轮攻击对象。

![](../Images/23767ff4fcf0138752251146a062c99b.png)

通过直接访问 ousiman568.com、hwobuswangzhe.cn域名，发现登陆界面和xiangwangshenghuo是一样的，如下图：

![](../Images/15ecfcf546b84140b0d85d0beb6cf956.png)

因此，说明这三个域名都是攻击者注册并绑定的，可能用于不同的攻击对象。

再分别对三个域名进行注册信息查询，结果分别如下：

![](../Images/46438216887ead5dcd51ec10e912bf79.png)

![](../Images/98f2a3e9bcf53f78148de7bef9b68b80.png)

![](../Images/92219a1bfa5faf962e53b76cbf964164.png)

从上面可判断，上述三个域名都是通过浙江贰贰网络有限公司进行申请注册的，通过贰贰网络查询域名，结果如下：

![](../Images/c207844d2ee047f535c3d20904e342f3.png)

综上，我们可以初步判断攻击者的基本信息，包含域名注册的姓名、QQ号和所在的大概地理位置。
