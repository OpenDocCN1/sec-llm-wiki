**3.1 系统内核简单流程**

系统内核提权就是利用相关的系统漏洞来提升相关权限。

  

**系统漏洞提权流程**

获得目标机shell→查看目标机系统版本及补丁→寻找对应的EXP→使用对应的EXP进行提权。

exp.exe传输（通过webshell管理平台、通过命令写文件等）到目标机中，注意可写路径，如：c:/windows/temp。

  

**常见的EXP的执行和使用方式**

第一种：执行exp.exe就可以在当前终端

第二种：执行exp.exe能够直接添加管理员账号；

第三种：执行exp.exe 命令

第四种:登录到目标系统中(低权限),执行完exp后会弹出一个新的窗口,该窗口为system权限.连接webshell后查看当前用户的权限找到一个可以上传的目录，将提权EXP上传执行Exp，发现提权成功(第四种：需要登录)

04

数据库提权—MSSQL

  

  
  

**4.1利用条件**

1)必须获得sa的账号密码或者与sa相同给权限的账号密码，且mssql没有被降权；

2)必须可以以某种方式执行sql语句，例如：webshell或者1433端口连接。

  

**4.2获取sa的账号密的方法**

1)Webshell或源码获取

   一般在网站的配置文件中有存明文账号密码 ，常用的配置文件名如: conn.aspx、config.aspx、 config.php等

    一般格式如:

     server = localhost；UID= sa；PWD=ichunqiu；database=ichunqiu

2)源代码泄露

    网站源码泄露情况主要以程序员上传代码到git等开源平台或更新代码时末删除备份文件，以及运维人员打包源代码到网站服务器

3) 嗅探

    在局域网中使用Cain等工具进行arp嗅探的时候可以抓取到1433端口的数据库明文登录密码

4)口令暴力破解

    利用mssql暴力破解工具对mssq|进行破解，成功后会获得sa相应的权限

**4.3xp\_cmdshell提权概述**

1) 存储过程

    是存储在 SQLServer中预先定义好的"SQL语句集合",用来实现一些复杂操作

    简单的说使用T-SQL语言编写好的各种小脚本共同组成的集合体,我们称之为”存储过程",类似于udf

2) xp\_cmdshell脚本

    扩展存储过程的脚本,是危险性最高的小脚本”,可以执行操作系统的任何指令

3) 注意

    xp\_cmdshell默认在mssql2000中是开启的,在 mssql2005之后的版本中则默认禁止

    如果用户拥有管理员sa权限则可以用 sp\_configure重新开启它

**6.2DLL劫持绕过UAC**

    DLL文件:动态链接库文件，多数可执行文件并不是一个完整的文件，它被分为多个DLL文件，大多数EXE程序执行的时候均会调用DLL文件。当程序运行时调用DLL文件的过程: 

*   程序所在目录。
    
*   系统目录即SYSTEM32 目录。
    
*   位系统目录即SYSTEM目录。
    
*   Windows 目录。
    
*   加载DLL时所在的当前目录
    
*   PATH 环境变量中列出的目录 echo %path%
    

    可执行程序在调用DLL文件的过程中会在高优先级目录中查找^（ 首先查找程序所在目录） ，当无法找到时会依次在较低优先级的目录中查找，当程序在高优先级的目录中找到所需的DLL文件后，则不会在低优先级的目录中查找。

    可执行程序的提权执行:一些可执行文件在执行时会自动提权运行，而且不会触发UAC机制。这些应用程序清单中都有<autoElevate>元素。

    如何查看可执行文件清单中说会否有<autoElevate>元素：

*   findstr /C:"<autoElevate>true" xxx.exe
    
*   使用sigcheck（微软数字签名工具)
    
    https://docs.microsoft.com/zh-cn/sysinternals/downloads/sigcheck
