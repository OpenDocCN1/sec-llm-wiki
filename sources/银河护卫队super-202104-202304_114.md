** 漏洞介绍**

     7 月 20 日，微软确认了一个新的本地提权漏洞，该漏洞会影响 Windows 自 2018 年 10 月以来发布的版本，即 Windows 10 Version 1809 以后的版本。不过值得注意的是该漏洞不影响 Windows Server 版本。

  对于这个漏洞安全研究成员将其称为 HiveNightmare 或者 SeriousSAM ，该漏洞允许低权限的用户访问 Windows 系统文件，成功利用此漏洞的攻击者可以使用 SYSTEM 特权运行任意代码。

  根据微软的介绍，出现本地提权漏洞是由于多个系统文件（包括安全账户管理器数据库SAM）过度许可访问控制列表所导致。

  目前 POC 和 EXP 已经被公开，利用公开的 POC 可以低权限账号读取 SAM 等文件。

  

![](../Images/d72c17a123aeab77db7e84a5b3150f11.png)02

**复现**

1、安装nim和wingw-w64，下载之后进行编译，生成exe文件ShadowSteal；msf连接后使用upload上传这个exe，运行后，download将生成的zip文件下载到本地使用kali自带的pypykatz工具解hash，可以

得到administrator账户的hash，可以使用hash传递登陆

![](../Images/8c13a96fbc0c49bbf5291cdf27764274.png)  

**注意：因为这个程序是去读取windows的还原点缓存，所以没有开启windows系统保护中系统还原是没办法抓取hash的****，而且在windows10系统中，只能手动开启系统还原点**

2、读取hash之后，可以用psexec和wmiexec、smbexec来进行hash传递，因为我的目标机禁用了administrator这个账户，所以报错。

**防御**

1、限制对 %windir%system32config 内容的访问，以管理员身份打开命令提示符或 Windows PowerShell


2、删除卷影复制服务 (VSS) 卷影副本。删除限制访问 %windir%system32config 之前存在的任何系统还原点和卷影卷，创建一个新的系统还原点（如果需要）；再复现的过程中，发现如果administrator设置了密码或者启用了空密码的本地用户只允许的控制台登陆，都无法提权成功（虽然能拿到hash，但是无法获取会话）
