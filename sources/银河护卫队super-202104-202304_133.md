# dedecms 文件上传漏洞(CVE-2019-8933)

** 漏洞环境**

*   攻击机：`192.168.75.119`
    
*   目标：`sfnjf.com/`
    
*   工具：一句话木马，蚁剑
    
*   版本：dedecms v5.7 sp2\_utf-8
    

![](../Images/d72c17a123aeab77db7e84a5b3150f11.png)02

**漏洞介绍**

该漏洞通过制作模板，然后替换主页的html从而达到上传一句话，这个漏洞会把主页内容替换掉。

  

![](../Images/d72c17a123aeab77db7e84a5b3150f11.png)03

**影响范围**

dedecms v5.7 SP2

  

![](../Images/d72c17a123aeab77db7e84a5b3150f11.png)04

**漏洞原理**

在文件**dede/makehtml\_homepage.php**的第25行起，只是判断了文件名称，没有对文件内容进行过滤，导致成功上传木马文件。

![](../Images/b9bcdcde1eacbf800eefb681e7f69326.png)

  

![](../Images/d72c17a123aeab77db7e84a5b3150f11.png)05

**漏洞复现**

1、登陆网站后台。

*   
*   
*   

```
URL:`http://sfnjf.com/dede`账号：admin密码：admin01
```

2、点击模板-->默认模板管理---->新建模板

![](../Images/2327163228de08eb353363d075f1e28b.png)

3、新建一个带有一句话木马的文件。

*   

```

```

![](../Images/2f732fcb37f248b48a7a1f37d66959bc.png)

4、点击生成-->更新主页HTML,然后选中刚刚写的一句话木马文件，修改主页位置为php后缀名，首页模式选则生成静态。最后点击更新主页HTML。

![](../Images/6f61133eaf712ce79d223620bfaa6b71.png)

5、点击浏览，找到文件路径，然后使用蚁剑连接。
