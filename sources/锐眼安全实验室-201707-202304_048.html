--------引言-------

勒索病毒已成为当前全球性威胁最大的网络犯罪软件，从2006年初出茅庐后经历了恶作剧过程、爆发过程，现阶段勒索软件趋于针对性的高级威胁化，由勒索组织或团伙有针对性的植入、执行。
CNCERT给出了一副简单易懂的防范指南可供参阅，本文对取样的勒索软件关键行为进行统计、分析与破除，降低一定概率的勒索损失。

--------七种武器-------

图2 勒索软件辅助行为排名


第一名：删除卷影副本

在勒索软件助攻行为中排名第一的为删除卷影副本，有多种方法，例如使用vssadmin命令删除卷影副本、使用wmi删除卷影拷贝、使用相关APIs或IOCTL命令删除卷影副本等。
vssadmin  delete shadows /all /quietwmic SHADOWCOPY DELETE /nointeractive

第二名：删除系统备份

在勒索软件助攻行为中排名第二的为删除系统备份，通过下述方法删除备份与操作日志。
wbadmin  DELETE SYSTEMSTATEBACKUPwbadmin  delete catalog -quiet

第三名：禁用自动恢复

在勒索软件助攻行为中排名第三的为禁用自动恢复，是系统开机无法弹出自动恢复窗口。
bcdedit  /set {default} bootstatuspolicy ignoreallfailuresbcdedit  /set {default} recoveryenabled No

第四名：启用网络发现

在勒索软件助攻行为中排名第四的为启动网络发现，通过打开防火墙策略方式方便查找网络共享数据。
netsh advfirewall firewall set rule group="Network Discovery" new enable=Yes

第五名：清除系统日志

在勒索软件助攻行为中排名第五的为清除系统日志，这是一个入侵后的操作，目的为方式找到作案人员的蛛丝马迹。
wevtutil  cl applicationwevtutil  cl securitywevtutil  cl system

第六名：调整卷影大小

在勒索软件助攻行为中排名第六的为调整卷影大小，这是由第一名被广泛防御衍生而出，目的为缩小卷影副本，使其不好用。
vssadmin.exe Resize ShadowStorage /for=f: /on=f: /maxsize=xxx

第七名：开放所有权限

在勒索软件助攻行为中排名第七的为开发所有权限，这个用作于破除目录的NTFS安全权限所使用的。
icacls . /grant Everyone:F /T /C /Qicacls "X:\\*" /grant Everyone:F /T /C /Q

--------解决方案-------
上述七种方法对勒索后数据恢复或取证可谓杀伤力颇大，除netsh命令较常用外，其他均为冷门命令，可根据业务实际情况酌情对上述命令进行重命名，以便破坏勒索过程的中间环节，尽可能保留恢复数据的希望。下述命令可保存为批处理，管理员权限执行，被重命名的文件名可自定义，需要使用时可使用新的程序名执行命令，fastprox.dll的重命名可根据系统应用依赖选择性操作。
takeown /f  c:\windows\system32\bcdedit.exetakeown /f  c:\windows\system32\bcdedit.exetakeown /f  c:\windows\system32\vssadmin.exetakeown /f  c:\windows\system32\wbadmin.exetakeown /f  c:\windows\system32\wevtutil.exetakeown /f  c:\windows\system32\wbem\wmic.exetakeown /f  c:\windows\system32\icacls.exetakeown /f  c:\windows\system32\wbem\fastprox.dllicacls c:\windows\system32\bcdedit.exe /grant everyone:Ficacls c:\windows\system32\vssadmin.exe /grant everyone:Ficacls c:\windows\system32\wbadmin.exe /grant everyone:Ficacls c:\windows\system32\wevtutil.exe /grant everyone:Ficacls c:\windows\system32\wbem\wmic.exe /grant everyone:Ficacls c:\windows\system32\icacls.exe /grant everyone:Ficacls c:\windows\system32\wbem\fastprox.dll /grant everyone:Fmove c:\windows\system32\bcdedit.exe c:\windows\system32\bcdedit_backup.exemove c:\windows\system32\vssadmin.exe c:\windows\system32\vssadmin_backup.exemove c:\windows\system32\wbadmin.exe c:\windows\system32\wbadmin_backup.exemove c:\windows\system32\wevtutil.exe c:\windows\system32\wevtutil_backup.exemove c:\windows\system32\wbem\wmic.exe c:\windows\system32\wbem\wmic_backup.exemove c:\windows\system32\icacls.exe c:\windows\system32\icacls_backup.exerename c:\windows\system32\wbem\fastprox.dll fastprox_backup.dll
配置系统还原点（必须），根据实际业务情况配置卷影磁盘大小后，执行lockbit2.0，RansomExx、HelloKitty、STOP、BlackMatter、darkside、Sodinokibi等勒索软件，均可通过卷影拷贝进行数据恢复。
步骤一：使用杀毒软件清除病毒或使用autoruns工具清除病毒体自启动项后，重命名fastprox_backup.dll为fastprox.dll，执行系统还原，如遇到BlackMatter类的勒索软件将系统还原入口破坏，可以先重启计算机，开机按F8键执行最后一次正确配置（很关键），然后在system32目录下找到rstrui.exe，并使用管理员权限执行，即可使用系统还原功能；darkside与Sodinokibi这类勒索软件会破坏bootmgr文件，造成操作系统无法引导，需使用其他方式挂载磁盘或WinPE引导系统拷贝良好的文件进行替换，使得系统可以启动后进行上述操作。
