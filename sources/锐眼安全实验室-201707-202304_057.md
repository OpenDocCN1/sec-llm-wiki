# 以彼之道，还施彼身：一个在办公环境中防止被文档攻击的小妙招

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyOTczMjI2MQ==&mid=2247484691&idx=1&sn=9a03e37827c84b2d4f8653793f34bca4&chksm=e8bf7fd9dfc8f6cf3bb727bb6a386068baa3c8cae50be4bb67058fa0c6dd1a5c90956c684bb1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyOTczMjI2MQ==&mid=2247484691&idx=1&sn=9a03e37827c84b2d4f8653793f34bca4&chksm=e8bf7fd9dfc8f6cf3bb727bb6a386068baa3c8cae50be4bb67058fa0c6dd1a5c90956c684bb1&scene=27#wechat_redirect)

本文适用于办公环境、其他环节请结合具体应用酌情修改，HW亦可参考。  
文档类的恶意软件经常被用作于鱼叉攻击，是高级攻击中惯用的手段，本文分享一个应对文档攻击的小方法，抛砖引玉。本文技术点应用主要使用windows操作系统进程映像重定向功能，俗称映像劫持或IFEO，最早被应用在2005年美女游戏病毒上，后续被熊猫烧香等一众计算机病毒发扬光大，劫持杀毒软件进程无法启动、劫持安全分析工具无法运行，一时成为了一个臭名昭著的技术，同理，合理应用亦可要恶意的程序无法正常执行，故而，以彼之道还施彼身。

**2、创建进程映像重定向**  

通过对上述进程进行分析，理想的办公环境基本可对EQNEDT32.EXE、cmd.exe、powershell.exe、mshta.exe、cscript.exe、WMIC.exe、taskkill.exe、wscript.exe、bitsadmin.exe、findstr.exe、finger.exe、powercfg.exe、timeout.exe进行进程映像重定向，rundll32.exe、PING.EXE可根据实际环境进行参考是否进行重定向，如果暂时不考虑windows软件更新问题，可考虑将msiexec.exe也进行重定向。重定向方法为：打开注册表编辑器，找到HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Image File Execution Options项，在下面新建子项，命名为所需要重定向的进程名，右侧窗口新建字符串值，命名为debugger，双击输入要重定向程序的路径，例如数字签名验证程序，c:\\windows\\system32\\sigverif.exe，完成后效果如下：

![](../Images/c0b3f52da1e76f31c80aa6cd33835816.png)

*图1 验证环境可行性*

有趣的是重定向归纳可针对具体的参数进行限制性的压制，例如可对cmd.exe /c进行劫持，而执行cmd.exe命令不受影响，或是针对静默安装的msiexec.exe /i /qn进行压制，而非这个参数不受影响，例如：

![](../Images/c0059554550cfacaa5e72e94dcbb0e69.png)

*图2 cmd带参数与不带参数被劫持后现象*

![](../Images/66ac7a9c08a127ce5bceb90b15858195.png)

*图3 msi安装程序带正确被劫持参数与非正常参数被劫持后现象*  

需要强调的是reg.exe必须无条件劫持，使其不能够启动，避免注册表被修改的项目被恶意改回，其他进程也均可将其重定向到一个可弹窗并不常用的程序中，比如真的遇到文档类恶意程序，可弹窗示警，例如将其弹至签名验证的程序上：  

![](../Images/d5801c586315f9d5a81c3e79a7ece366.png)

*图4 劫持reg.exe使其不能执行*

此后，除了使用文档漏洞释放可执行文件直接执行，基本文档被恶意利用的程度就降低很多了，当然打补丁也是系统安全必不可少的工作，本文毕竟是取巧的手段。  
附批处理完成上述工作自动创建，复制粘贴代码部分的内容保存为ifeo.bat，执行即可。
