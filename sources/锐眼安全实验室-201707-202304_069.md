**前置知识**  

DXE：Driver Execution Environment，这个阶段主要负责CPU、芯片组以及相关组件的初始化。

EFI System Table：EFI环境下最重要的数据结构，EFI System Table的指针将会被作为入口地址的一部分参数传递给每一个EFI程序。EFI程序具备三种类型，application、boot service，runtime service。application退出释放内存，boot service则ExitBootServices()执行后释放，runtime service则常驻内存。

OS loader：UEFI bios模式下的系统引导程序，当完成前置的系统引导工作后，调用ExitBootServices()后，系统仅会驻留run-time类型的服务程序与驱动程序。

EFI支持Runtime驱动与Runtime服务从物理模式至虚拟模式的转换，故ExitBootServices()执行后依旧驻留操作系统，为操作系统提供服务。
