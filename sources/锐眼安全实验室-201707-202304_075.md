# Lucifer Spy-tool

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyOTczMjI2MQ==&mid=2247484369&idx=1&sn=38d0865be20291618844b7b842bf7cc7&chksm=e8bf791bdfc8f00d8e3f46ea1eb732bea1f41fd1e1fb4793cc78c9fb5c5647fdfc5a2b71d3f2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyOTczMjI2MQ==&mid=2247484369&idx=1&sn=38d0865be20291618844b7b842bf7cc7&chksm=e8bf791bdfc8f00d8e3f46ea1eb732bea1f41fd1e1fb4793cc78c9fb5c5647fdfc5a2b71d3f2&scene=27#wechat_redirect)

Lucifer Spy-tool是一款还未被恶意软件广泛应用的恶意文件加密工具，具备反检测与持久化能力，目前Lucifer Spy-tool已经被应用到了404keylogger与NanoCore中，Lucifer Spy-tool作者似乎出自俄国，在其工具中发现了大量的俄文信息  

![](../Images/7e9dd4283596e78242aae3fc20cc0145.png)

![](../Images/4ae5afe8d3426f475815105fc34cbfdb.png)

*作者相关信息*

Lucifer Spy-tool使用了较为复杂的持久化启动模式，首先在开始菜单中写入网页历史文件并将URL指向本地的路径，执行一段vbs代码，使用vbs执行被加密的exe文件

![](../Images/27fbeca1911ae126b0921693779c8222.png)

*Lucifer Spy-tool持久化**执行流程*

![](../Images/3f1e08baa6743c643e2b05af78be79c5.png)

*Lucifer Spy-tool**启动后将会在托盘中产生一个控制台程序的入口，然而并无真实作用，仅用于迷惑行为分析模型*  

Lucifer Spy-tool使用AU3编写，第一步动作在内存中动态执行一段解密代码通过查找特征方式对C2进行解密，特征值为UDCMPUBWTF

![](../Images/74c7133f7a173fcc4eb22bd1375a3e30.png)

*解密代码*  

![](../Images/16baba0d2f957671f4a6edde86f80ef7.png)

*解密后C2，由于载荷为404keylogger，涉及大量隐私数据，C2不公开，404keylogger下篇文章另述*

Lucifer Spy-tool内嵌的第二块shellcode是一个injecter，shellcode执行后首先对其导入函数进行填充、动态链接后，销毁内存中存在的部分API名称字符串，创建挂起进程，使用替换进程内存映像的方式对msbuild.exe进程进行注入执行。

对抽取的404keylogger分析，编译时间为2020年2月18日，窥探其窃取的数据多数为ru域名的数据，目前从上线至目前已盗取用户数据6000余条，传播能力可见一斑。
