引用freebuf上ESET对computrace的风险分析，里面详细的描述了UEFI rootkit的原理，详情见https://www.freebuf.com/news/185828.html

剿灭全过程：

1、联想电脑开机按F12进入bios操作菜单

2、按tab键进行切换，在setup上面进行回车

3、在anti-theft上面回车进入

4、接着回车进入computrace

5、如果偶尔还希望使用computrace“追踪”功能可以选择Disable关闭，如果希望彻底废弃功能则使用第6步

6、选择Permanently Disable，会弹出红色字体的对话框，一路选择yes后直到彻底废弃该功能，此处忘记拍照

7、如果没有网络唤醒需求的，切换至startup菜单，找到network boot，将其改为可引导系统的硬盘或其他

8、保存bios设置

9、进入操作系统后使用管理员权限修改host文件，按“Win+R”键打开运行，输入drivers，弹出窗口手动进入etc目录

10、双击hosts文件，选择用记事本打开

12、在文件尾加入下面八行

127.0.0.1 search.namequery.com
127.0.0.1 search.namequery.com
127.0.0.1 search2.namequery.com
127.0.0.1 search64.namequery.com
127.0.0.1 search.us.namequery.com
127.0.0.1 bh.namequery.com
127.0.0.1 namequery.nettrace.co.za
127.0.0.1 m229.absolute.com

13、按“Win+R”在运行对话框输入system32，查找rpcnet.exe、rpcnetp.exe、rpcnet.dll、rpcnetp.dll文件，找到后改名，待下次重启系统后再次进入目录删除，此处由于电脑比较庆幸，没有中此组件，无法截图

14、按“Win+R”输入regedit，弹出管理员权限确认，选择是。此处由于权限问题无法截图

15、依次点开注册表HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options，在Image File Execution Options上新建项，分别为命名为rpcnet.exe与rpcnetp.exe

16、点击rpcnet.exe，在右侧窗口新建字符串值，命名为debugger，双击后输入某路径下rpcnetp.exe，例如d:\rpcnetp.exe；点击rpcnetp.exe，在右侧窗口新建字符串值，命名为debugger，双击后输入某路径下rpcnet.exe，例如d:\rpcnet.exe

17、按“Win+R”在运行对话框中输入system32，复制两份notepad.exe到某路径下，分别命名为rpcnet.exe、rpcnetp.exe

18、本机无相关真实组件，测试在任意路径重命名一个可执行文件尾rpcnet.exe，如果不被使用原生或者未文档的api进行进程创建，双击效果如下，将会上演一场“狗咬狗”的好戏，非但一直不能够启动，最后还会被系统强制结束
