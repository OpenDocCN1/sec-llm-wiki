# 图解剿灭computrace全过程

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyOTczMjI2MQ==&mid=2247484097&idx=1&sn=551c8c7f08028647eb5ca5209c37c960&chksm=e8bf780bdfc8f11dd617bf8babffd39395dc693284080e4dce71ce2b2d389ced778a7e332f50&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyOTczMjI2MQ==&mid=2247484097&idx=1&sn=551c8c7f08028647eb5ca5209c37c960&chksm=e8bf780bdfc8f11dd617bf8babffd39395dc693284080e4dce71ce2b2d389ced778a7e332f50&scene=27#wechat_redirect)

引用freebuf上ESET对computrace的风险分析，里面详细的描述了UEFI rootkit的原理，详情见https://www.freebuf.com/news/185828.html

剿灭全过程：

1、联想电脑开机按F12进入bios操作菜单

![](../Images/62f4223e5126b4ffb325554591865e30.png)

2、按tab键进行切换，在setup上面进行回车

![](../Images/849deffa4f7f9661049733350da19495.png)

3、在anti-theft上面回车进入

![](../Images/e492d761c0eb8d6ffecb8d379330bfce.png)

4、接着回车进入computrace

![](../Images/7185f1e81751cf1f2da70192cd301c05.png)

5、如果偶尔还希望使用computrace“追踪”功能可以选择Disable关闭，如果希望彻底废弃功能则使用第6步

![](../Images/f06662e7a72feccdab6c05855cc613de.png)

6、选择Permanently Disable，会弹出红色字体的对话框，一路选择yes后直到彻底废弃该功能，此处忘记拍照

![](../Images/b10ce5a1e040d58fb9cfd9d8c8fe4d13.png)

7、如果没有网络唤醒需求的，切换至startup菜单，找到network boot，将其改为可引导系统的硬盘或其他

![](../Images/802f850444b80db09f27c7ca09c64468.png)

8、保存bios设置

![](../Images/cc50bd09f98587dcc72759a63f94ea62.png)

9、进入操作系统后使用管理员权限修改host文件，按“Win+R”键打开运行，输入drivers，弹出窗口手动进入etc目录

![](../Images/2394f71898c402403a9497510a69a311.png)

10、双击hosts文件，选择用记事本打开

![](../Images/517700f463ecc7c1b399b7f292e143fc.png)

12、在文件尾加入下面八行

127.0.0.1 search.namequery.com  
127.0.0.1 search.namequery.com  
127.0.0.1 search2.namequery.com  
127.0.0.1 search64.namequery.com  
127.0.0.1 search.us.namequery.com  
127.0.0.1 bh.namequery.com  
127.0.0.1 namequery.nettrace.co.za  
127.0.0.1 m229.absolute.com

13、按“Win+R”在运行对话框输入system32，查找rpcnet.exe、rpcnetp.exe、rpcnet.dll、rpcnetp.dll文件，找到后改名，待下次重启系统后再次进入目录删除，此处由于电脑比较庆幸，没有中此组件，无法截图

14、按“Win+R”输入regedit，弹出管理员权限确认，选择是。此处由于权限问题无法截图

15、依次点开注册表HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Image File Execution Options，在Image File Execution Options上新建项，分别为命名为rpcnet.exe与rpcnetp.exe

![](../Images/eb6d2324c5e61d71a5db7d06c5aabf78.png)

16、点击rpcnet.exe，在右侧窗口新建字符串值，命名为debugger，双击后输入某路径下rpcnetp.exe，例如d:\\rpcnetp.exe；点击rpcnetp.exe，在右侧窗口新建字符串值，命名为debugger，双击后输入某路径下rpcnet.exe，例如d:\\rpcnet.exe

17、按“Win+R”在运行对话框中输入system32，复制两份notepad.exe到某路径下，分别命名为rpcnet.exe、rpcnetp.exe

![](../Images/8a081e39772e362dcd93a4cd6490b738.png)

18、本机无相关真实组件，测试在任意路径重命名一个可执行文件尾rpcnet.exe，如果不被使用原生或者未文档的api进行进程创建，双击效果如下，将会上演一场“狗咬狗”的好戏，非但一直不能够启动，最后还会被系统强制结束

![](../Images/0e22cb8bd12d871cbd0da419fd1acf6b.png)
