# 实模式是否又将成为恶意代码必争之地？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyOTczMjI2MQ==&mid=2247483955&idx=1&sn=3fffd8c8d82cc7d832dcf6b640ff4895&chksm=e8bf78f9dfc8f1ef19b6052028d326d1f24f9db299cd3cc0e9accd89da6fefe93fa67c4bbff1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyOTczMjI2MQ==&mid=2247483955&idx=1&sn=3fffd8c8d82cc7d832dcf6b640ff4895&chksm=e8bf78f9dfc8f1ef19b6052028d326d1f24f9db299cd3cc0e9accd89da6fefe93fa67c4bbff1&scene=27#wechat_redirect)

  
早些年，分析DOS病毒的时候，引导扇区就是DOS病毒的必争之地，感染软盘、硬盘的引导扇区，修改中断处理程序进行驻留或反串防止检测与清除。然而当前计算机系统在EFI模式下虽然脱离了这种模式，但为了向下兼容，在boot manager环节支持了CSM模块的调度，并在compatibility16boot()里调用了int19,实现自举。无论是传统bios还是EFI bios相对于目前计算机硬件的发展均还处于过渡期，一是因为硬件的更新换代需要一定时间的生命周期，二则是操作系统的变更与使用者习惯是相辅相成的，这就意味着彻底淘汰MBR这种引导方式还需要很长的时间。

曾经拿到的第一个bootkit样本编译于2007年12月19日，于2008年1月11日被微点拦截捕获，有幸得以分析，相对目前已近十年，后续随着bootkit技术的公开，TDL、鬼影等系列的频繁变种，将其推向热潮，而流氓软件、勒索软件大规模流行的今天，bootkit基本变成了没有门卡儿的存在，在很早的一张片子里我将这种过程称为专利型病毒、技术型病毒、流行性病毒的趋势演变。

![](../Images/aa0ab0ff30ac72bc34e5abdab4a2ecdf.png)

了解过计算机病毒发展史的朋友们大概都了解，最古老的计算机病毒是因技术炫耀而大肆流行的，那时候只有单核CPU、实模式、DOS环境，计算机病毒对于其作者来说，编写流程较简单，非常灵活，但相对目前写入MBR中的bootkit代码来说，其难度似乎是目前bootkit的百倍而不止，那时候的计算机病毒作者喜欢炫耀技术，比如感染技术、传播技术、特征对抗技术，而现在盛行的bootkit中，并不存在过于复杂的技术应用，甚至在勒索病毒中开始量产化，百度一搜生成器还是有很多的，能不泛滥么？

![](../Images/860dab3fd920e50d0a98fd1d80135f0d.png)

‍  

看到这里，换位思考一下，对于那些写过上古DOS病毒的作者来说，这完全就是对于技术的玷污，这不就有上古时期的病毒开发者冒出来炫耀技术了，今天的主角，Nyan Cat病毒，来自某一病毒样本论坛。细分析起来，这个程序还不能定论为病毒，病毒作者在病毒运行前做了两次可选的执行提示，并告知了危害性，算是恶意程序技术的一种炫耀手段吧，具体传播量未知，编译于2016年7月11日。

![](../Images/56f7357ae5b923dd4a29e727c6980f8b.png)

![](../Images/bd4a4fdd24fd32c28b9db30174b01ccb.png)

如果尝试结束病毒进程，那么病毒看守进程存在一个轮询线程，当发现遭到病毒环境被破坏时，会直接通过技术手段制造蓝屏或重启，这里没有好看的图片只有代码

重启后，病毒作者为了进一步的炫耀，用MBR执行了他编写的com程序，一直循环执行，截了一个动图，共赏

![](../Images/3a99f7f2e143065dd5ed7e5dca819707.png)

通过搜图得知叫做Nyan Cat，还伴随这音乐，试听了一下Nyan Cat的相关音乐，病毒作者产生的音乐显得那么杂乱无章，看了下代码，是这样生成的，在这个每个电脑都配备了声卡的时代，作者还能够如此了解8254控制器，可见作者肯定要么是玩过DOS开发的，要么是做单片机开发的，结合作者开发了这个炸屏病毒并作运行前提示，我更相信前者。

最后，斗胆猜测一下病毒作者的想法，实模式可操作的东西有很多，无论是现在的bootkit还是Nyan Cat，仅仅是冰山一角而已。回到标题，实模式是否又会被沦为恶意代码的大型战场，无论是否，我们作为反病毒人员，都应早作技术储备。
