# 喜讯！锦行科技多款产品入选广东省名优高新技术产品名单！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTQxMjQyNg==&mid=2247490961&idx=1&sn=957a871a328cffcc6dbe6c710c7c5142&chksm=9799e634a0ee6f2288709d5ca6c2cbbea7d74e8754211e599e6f88563640167e9fb4704a8c9d&scene=126&sessionid=1681371355#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTQxMjQyNg==&mid=2247490961&idx=1&sn=957a871a328cffcc6dbe6c710c7c5142&chksm=9799e634a0ee6f2288709d5ca6c2cbbea7d74e8754211e599e6f88563640167e9fb4704a8c9d&scene=126&sessionid=1681371355#rd)

  
![](../Images/8c4a324ea37b68e915bf917ca8c3c2cb.png)

近日，广东省高新技术企业协会公布了《2022年广东省名优高新技术产品名单》，锦行科技**“特权账号管理运维系统——安权”、“智能安全管理平台——遁甲”**凭借持续创新力强、核心技术突出与产品质量过硬等优势成功入选。

  
![](../Images/04503c7ebec54f141fdd92ea27c98a78.png)  

广东省名优高新技术产品认证是原高新技术产品认证的延续和进一步升级，对高技术、高质量、市场前景有更高的要求，认定门槛显著提高，申报难度加大，遴选出的都是国内首创可替代进口、达到国内外先进水平的名优高新技术产品。2021年锦行科技“攻击欺骗诱捕防御软件—幻云”、“攻防对抗演练软件—天穹”以及“网络多维度安全巡检软件—大舜”三款产品已成功入选；**截至目前，锦行科技已有5款产品入选广东省名优高新技术产品名单。**

  
![](../Images/0d2529a10bd9db7ff218b92b8a167d39.png)**特权账号管理运维系统——安权**安权是锦行科技基于十余年的渗透测试和应急响应项目经验，结合核心团队在安全技术领域的持续研究，自主研发的一款基于CARTA以及零信任理念的特权账号自动化管理平台。平台以身份认证为基础，通过对账号全生命周期管理，动态访问控制，持续信任和风险评估等系列措施，实现对特权账号安全、高效的统一纳管，帮助用户搭建零信任网络架构，为用户的核心数据安全构建坚实堡垒。  
![](../Images/28f0bf64071405c839906e46d95a7b6a.png)**智能安全管理平台——遁甲**遁甲是锦行科技基于十余年的安全运维服务经验，针对安全运营过程中网络流量大，处置效率低、响应周期长、专业人才不足等痛点，打造的适用于各行业的智能安全运营平台。遁甲将安全、IT和人工深度结合，帮助用户建立应对日常运维以及特殊时期的自动化联动防御体系，为达到“三化六防”提供坚实的支撑。

  

面对严格的遴选条件，锦行科技五款产品脱颖而出，未来，锦行科技会继续根据行业痛点及对市场的前瞻性，不断推陈出新，坚持自主创新、培育新动能，孵化出更多新技术、新产品和新成果，以创新驱动企业的发展和突破，为网络安全产业链提供源源不断的创新力量。
