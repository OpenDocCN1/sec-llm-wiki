# 【喜报】锦行科技获中国人民解放军某部队感谢信

近日，锦行科技收到了中国人民解放军某部队寄来的感谢信，对锦行科技安全服务团队在本次重大任务攻防演练中，高度重视，组织专业力量，调动资源全面支撑，圆满完成任务的优质服务特予以表扬。

  

![](../Images/361862f5008a40d760e9e5a8996959ec.png)  

  

锦行科技依托专业的保障团队，整合锦行科技威胁情报运营能力、安全预警和处置能力、产品平台支撑保障能力以及应急响应和安全研究能力，紧密围绕行动任务，完成网络隐患安全排查、安全评估、系统安全加固等工作任务，为此次任务提供了强有力的技术支援保障。

  

锦行科技安全服务团队拥有近20年的国内外攻防渗透研究及实战经验，在高级持续性威胁防御、渗透测试和网站安全等多个领域达到国际顶尖的水平。先后承担了北京奥运会、广州亚运会、深圳大运会、中共十九大、青岛上合峰会、北京冬奥会等众多国家级重大安保项目的安全保障工作，专业水平及服务能力获得各级政企单位的一致好评。  
  
未来，锦行科技将秉承“使科技更可信，让世界更安全”之使命，奋力前进、持续创新，为加强国家网络安全保障体系和能力建设作出更大贡献。
