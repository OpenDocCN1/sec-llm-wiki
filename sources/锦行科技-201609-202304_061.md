# 【燃烧吧！天才程序员】—第二季完美收官，获奖名单出炉

近日，真实记录ATEC2021大赛线下赛的赛事节目——《燃烧吧！天才程序员》已完成全网放送，获得了广泛科技人群的高度好评。节目真实地还原了网络科技精英们在比赛环节中层层突围、为探索科技反诈而努力的场景，让公众近距离看到了科技的另一面，也让科技人才在大众心中的形象更立体更真实。**第二届ATEC科技精英赛线下赛获奖名单**![](../Images/378984134930b816ba6bd0223f04038e.png)  

整个大赛聚焦可信AI实战应用，由清华大学、上海交通大学、浙江大学、蚂蚁集团联合承办，多所国内外知名高校共同协办, 锦行科技提供技术支持。随着节目中冠军团队的揭晓，这场历时数月，数千科技从业者、学者的激烈比拼的大赛，也正式落下了帷幕。

**攻防赛题精彩回顾**

此前，我们分享了本届大赛攻防赛道的出题思路和赛题难点[《【燃烧吧！天才程序员】——看ATEC科技精英如何破解网络诈骗》](http://mp.weixin.qq.com/s?__biz=MzIxNTQxMjQyNg==&mid=2247489953&idx=1&sn=1af4cda3aded58e6897f483de95cf1fe&chksm=9799e204a0ee6b12fbceb97060e1ae83153d6643e43d806fbb67fa3be9f184573f72654e79b1&scene=21#wechat_redirect)。赛题中的重重关卡还是给参赛精英们带来了不少挑战。

![](../Images/3f16c69195b028d8026389949dc13ed4.png)

  

本次赛题的考核入口是通过获取SIP网络电话的IP地址进入的，比赛开场时，部分选手尝试了各种各样的方法去寻找赛题入口，如幽默的“开心就好”战队攻防选手攻击了本地WiFi无果后，转而选择其他方式进行突破。

  

清华大学教授张敏解说道：“本届赛题，攻防选手没有进入赛题入口之前，不知道攻击的是谁的网络，也不知道可能会拿到什么样的信息。”这也说明，在攻防过程中，需要选手通过敏锐的攻防感知能力去理性决策，选择合适的攻守视角，采取正确的攻守措施。  

![](../Images/242eb89389caa550f143a2c8ebdca1de.png)![](../Images/afe962760c28f1bcaeec3c1679aef9b5.png)

  

虽然赛题难度不小，但是选手还是不断给我们送上惊喜。“能靠实力但偏要拼颜值队”的攻防高手“腹黑”在找赛题入口时就果断地拔掉电话线后重启，顺利找到赛题入口并成功拿下“一血”。“开心就好”队也不甘示弱，发现了AD admin，快速拿下对应的flag。其他队伍也迅速跟上步伐，相继发现比赛入口并成功拿下flag。  

![](../Images/6cf84fa0af1715aecfb921e4fae2f921.png)![](../Images/157c235bd312b485231f677d52287412.png)

  

在内网环境渗透阶段，部分选手被卡在了A区的第四个Flag，如果通过密码爆破方式发现主机账号密码拿下Flag，那么这种方式会导致错过第三台主机上的解题线索。实际上，该阶段是考核选手在实战环境中通过用户Session，查看是否有管理用户挂载磁盘，以此来获取线索。

![](../Images/b8e34adda550074e443edbb4e292c911.png)![](../Images/a9bc92c2f24ed4916cbfd024bf4057b2.png)

  

《燃烧吧！天才程序员》的播出，展现了技术人才风趣幽默又充满智慧的立体形象。在帮助人们了解和认识科技力量的同时，充分体现科技人才对反诈工作的重要价值。

  

本次大赛，锦行科技以自主研发的攻防实战网络靶场为基础，为大赛定制和搭建诈骗仿真场景中的网络架构、系统设备、业务流程的运行状态及运行环境等，真正从实战的角度考察攻防选手在内网渗透、域渗透及逆向解密等应用能力。

  

此前，锦行科技在以往的各大赛事支撑中也展现了实战化高仿真靶场搭建技术、强大的数据采集分析能力、丰富的场景复现选择、知识与实战一体化的课程体系等众多优势，以多样化的攻防对抗工具为基础，向客户提供网络安全攻防实训、网络靶场实战演练、网络安全竞赛、网络靶标库等平台资源及专业化和定制化服务。锦行科技也希望通过这次比赛，可以帮助企事业单位培养实战化网络人才，让更多的有志青年投入网络安全建设中，以积极向上的能量回报社会。  

![](../Images/d2884b64969c39a1dda6afca6188cd67.png)![](../Images/6861ad0ee7e7e9741fc7a4b77fdd4ed3.png)![](../Images/f8d4950758e45a6a0e569e2d232dff19.png)

  

除了全力支撑第一届和第二届ATEC科技精英赛之外，锦行科技还为各领域政企用户定制了多场景的实战攻防赛事，如智慧金融城市攻防大赛、智能家居攻防对抗战、ISW企业内网安全攻防对抗赛等。作为公安部列装实战靶场，拥有攻防理论、攻防实训、攻防演练、应急演练、攻防竞赛等系列技术和服务能力，助力国家培养实战型攻防技术人才。截至目前，已经服务涵盖政务、公安、部队、金融、教育、电力、互联网、运营商等领域共计百余家政企单位。
