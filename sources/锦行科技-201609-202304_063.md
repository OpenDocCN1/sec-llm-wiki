# 【深度合作】锦行科技与公安部第三研究所网研基地签订合作协议，被授权为“广东省技术服务站”

**“广东省技术服务站”**

  

近日，锦行科技与公安部第三研究所网络空间安全技术研发基地签订网络安全业务合作协议，锦行科技正式成为公安部第三研究所网络空间安全技术研发基地在广东省内的技术服务站。双方将建立长期稳固的合作机制，在网络安全产品与技术、规划以及专业服务等业务开展合作。  

前期，公安部第三研究所网络空间安全技术研发基地和锦行科技在网络安全服务方面已经有一定的合作基础，随着合作深入和信任度提升，双方探索更多的合作模式，此次合作协议的签订以及“广东省技术服务站”的授权，也将成为双方深度合作的纽带，锦行科技将持续发挥和整合自身在广东省内的资源和技术优势，将公安部第三研究所网络空间安全技术研发基地安全服务能力体系化、属地化，成为深入服务广东省企事业单位网络安全建设的重要抓手。  

  

**关于公安部第三研究所**

  

公安部第三研究所作为公安部直属科研单位，主要从事网络安全与智慧警务科研创新与技术支撑。在警务信息智能感知、警务数据安全共享、违法犯罪监测预警等优势研究领域有着长期的积累，在网络安全、国产密码、电子取证、大数据分析、智能安防、毒品检测等领域着力部署，提供核心关键技术支撑与系统解决方案。公安部第三研究所网络空间安全技术研发基地以网络攻防、公安物联网、大数据、人工智能等领域为主要研究方向。
