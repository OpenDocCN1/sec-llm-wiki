# 【漏洞预警】Apache Shiro 身份认证绕过漏洞(CVE-2022-32532)安全风险通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTQxMjQyNg==&mid=2247489929&idx=2&sn=1088ff8ea645b927c482e423d94aba40&chksm=9799e22ca0ee6b3a93a62cfd72fd1f38df23933112c105e60cacd05198010b4ff9510abc85c1&scene=126&sessionid=1681371375#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTQxMjQyNg==&mid=2247489929&idx=2&sn=1088ff8ea645b927c482e423d94aba40&chksm=9799e22ca0ee6b3a93a62cfd72fd1f38df23933112c105e60cacd05198010b4ff9510abc85c1&scene=126&sessionid=1681371375#rd)

**漏洞名称：**

Apache Shiro 身份认证绕过漏洞

**影响范围：**  

Apache Shiro<1.9.1

**漏洞编号：**

CVE-2022-32532

**漏洞类型：**

身份认证绕过

**利用条件：**

无

**综合评价：**

<利用难度>：低

<威胁等级>：**中危 **

  

**#1 ****漏洞描述**

当Apache Shiro中使用RegexRequestMatcher进行权限配置，且正则表达式中携带"."时，未经授权的远程攻击者可通过构造恶意数据包绕过身份认证，导致配置的权限验证失效。

  

**#2 解决方案**

目前Apache官方已发布此漏洞修复版本，建议用户尽快升级至Apache Shiro 1.9.1及以上版本。https://github.com/apache/shiro/releases/tag/shiro-root-1.9.1
