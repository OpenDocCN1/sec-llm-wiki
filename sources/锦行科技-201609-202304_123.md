# 领导走访 | 区政协、农工党领导莅临锦行参观考察

2021年12月29日，广州市天河区政协副主席张海玉、农工党天河区基层委员会主委吴文章一行莅临锦行科技参观指导，锦行科技执行总裁黄海军、常务副总裁赵旺军出席接待。双方就企业科技创新、企业服务以及网络安全未来发展等话题进行交流讨论。

  

![](../Images/45ec4364a1994d46f0fc250e4727c283.png)![](../Images/5c863038461d375b95ca16798acca806.png)

*执行总裁黄海军、常务副总裁赵旺军陪同参观*

  

在锦行科技执行总裁黄海军、常务副总裁赵旺军的陪同下，天河区政协副主席张海玉、农工党天河区基层委员会主委吴文章参观企业科技展厅。在深入了解锦行科技的发展历程及多年来的创新成果和前沿技术后，对锦行科技在网络安全行业做出的贡献表示肯定，并且对锦行科技的发展前景非常看好。

  

锦行科技执行总裁黄海军对张海玉副主席及吴主委到访表示感谢，同时感谢政协及农工党一直以来对锦行发展的关注。并表示未来我们会继续在国家政策指引下，在地方政府机构、政协组织等的帮助下，依托自身的行业经验和技术能力，在网络安全领域踏实前进，为企业及政务单位提供专业的服务，始终坚持维护国家关键基础设施安全。

 

迄今为止，锦行科技也凭着过硬的技术和丰富的行业经验，为包括政务、公安、金融、电力、教育、运营商等行业提供网络安全服务，为地区科技、经济的发展贡献出属于自己的一份力量，助力国家关键基础设施安全体系建设。
