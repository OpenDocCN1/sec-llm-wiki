# 喜讯！锦行科技荣评 “2020年度天河区专利创造先进单位”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTQxMjQyNg==&mid=2247487145&idx=1&sn=c382b2248e97808eed13f7d87166a23e&chksm=9799f50ca0ee7c1ac57de111d22338e858e145e8e9da49cd7ed1e354d439773f6c4b7eeda71e&scene=126&sessionid=1681371425#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTQxMjQyNg==&mid=2247487145&idx=1&sn=c382b2248e97808eed13f7d87166a23e&chksm=9799f50ca0ee7c1ac57de111d22338e858e145e8e9da49cd7ed1e354d439773f6c4b7eeda71e&scene=126&sessionid=1681371425#rd)

![](../Images/001a45da4dcecd9271a61c97d99bd30f.png)

  

  

**3月18日，天河区市场监督管理局组织召开了知识产权****高质量发展业****务培训会。会上，广州锦行网络科技有限公司（以下简称“锦行科技”）凭借突出的知识产权管理业绩，荣获“2020年度天河区专利创造先进单位”荣誉称号。**

  

  

  

![](../Images/9c7b11c5879e50d38a3eb65b9fe3d60a.png)

  
![](../Images/e6014d0f9190eef5149b3edc3b0c4002.png)

锦行科技近年来十分重视技术创新和自主知识产权保护，**建立了成熟的专利管理制度，规范公司的专利工作**。**专利奖励制度的制定和实施**，激发了公司员工尤其是技术人员申请专利的积极性。此外，公司还**定时面向全体员工开展专利培训工作**，通过举办专利写作培训讲座等方式让员工了解专利工作的重要性，熟悉和掌握专利的申请、侵权、核心技术的保护和专利文献的应用。

  

通过这些举措，**锦行科技在专利创造、管理、申请和保护方面取得了显著成效**，知识产权工作已很好地融入到企业营运的整个过程，对支撑企业的核心竞争力起到积极的作用。**截至目前，公司拥有100余项技术发明专利，并顺利通过知识产权管理体系认证**。

  

  

![](../Images/76d0991f7f45db8ea974134f3c1ebb76.png)

此次荣评“2020年度天河区专利创造先进单位”，体现了广州市天河区产权联合协会对锦行科技知识产权工作的认可与鼓励。**锦行科技将以此次获奖为契机，继续坚持技术创新，不断满足行业的发展需求，为更多政企用户提供具有核心竞争力的网络安全解决方案，积极响应上级组织的号召，共同推动国家网络安全产业的创新与发展**。
