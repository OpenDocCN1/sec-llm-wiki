# 大舜多维度安全巡检平台喜获CNNVD兼容性服务认证

**大舜多维度安全巡检平台喜获CNNVD兼容性服务认证！**

受中国信息安全测评中心委托，根据《国家信息安全漏洞库（CNNVD）兼容性服务白皮书》相关规定，国家信息安全漏洞库（CNNVD）运行管理中心于2017年8月至12月期间对18家单位的28款产品进行了兼容性服务能力审核，并于1月10日召开评审会对18家单位及其产品进行评审。经专家组评议，并与相关单位沟通，确定以下厂商及产品获得CNNVD兼容性服务资质。其中，由广州锦行网络科技有限公司生产的大舜多维度安全巡检平台V4.2在此行列当中。

![](../Images/7ec5e7ae20d883596f84ced30ec186b2.png)

![](../Images/ca3ba14fbf96bf07940d3d993c43b467.png)相信不少业内人士皆知CNNVD ，但我还是要多嘴说一下。

中国国家信息安全漏洞库，英文名称"China National Vulnerability Database of Information Security"，简称"CNNVD"，是中国信息安全测评中心为切实履行漏洞分析和风险评估的职能，负责建设运维的国家信息安全漏洞库，为我国信息安全保障提供基础服务。

而CNNVD兼容性服务则是测评中心面向国内外信息安全从业单位，对其产品、系统、服务等涉及到的漏洞信息进行CNNVD兼容性审评估与认证的服务，并及时、 准确、广泛的开展涵盖以漏洞信息为核心的各类数据资源的合作与研究服务。

![](../Images/6d49f78320f507ffe1185ad8b61c1857.png)

作为由锦行安全专家自主研发的漏洞插件，大舜从攻击者视角出发，融入顶尖安全人才的渗透思维、丰富的渗透测试经验和漏洞挖掘实战经验，能够有效感知对客户网络系统构成重大安全威胁的漏洞和风险，实现缺陷的精准定位，提供具有针对性的专家修复方案，同时及时跟踪全球最新的安全威胁，提供实时安全漏洞预警及响应。

![](../Images/e36041b7ba1073c97a1ba1349781b8b8.png)此外，在“十九大”期间，大舜多维度安全巡检平台还配合了广州信息安全测评中心，开展了漏洞安全隐患的实时监控、准确发现、快速排除等工作，做出的贡献和成效获得了广东省信息安全测评中心的认可。![](../Images/a340f59d798c519d6765a94bae324e9a.png)  

  

![](../Images/87d0f409d65c6d1f57a143878e13b5bb.png "动态针分割线")感谢诸单位对锦行网络科技有限公司的认可和信赖，作为国内网络安全领域的创新型企业，锦行科技未来必定会与CNNVD平台通力合作，在漏洞挖掘、预警通报、安全情报分享等信息安全领域展开多方位的深度合作，不断探索维护网络信息安全的有效措施，积极参与国家网络安全建设，捍卫国家关键基础设施安全，保护企业核心信息资产，为推进信息安全行业的发展贡献自己的力量。
