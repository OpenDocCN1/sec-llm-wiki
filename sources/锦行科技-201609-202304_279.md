# 6月漏洞通报：缓冲区漏洞占比最高

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTQxMjQyNg==&mid=2247484283&idx=1&sn=4ff7858c733378a3d5ee0ef1f2481244&chksm=9799f8dea0ee71c8179350d57534f75de4736da35619f0b1e4463940e766c66b954e006a7405&scene=126&sessionid=1681371476#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTQxMjQyNg==&mid=2247484283&idx=1&sn=4ff7858c733378a3d5ee0ef1f2481244&chksm=9799f8dea0ee71c8179350d57534f75de4736da35619f0b1e4463940e766c66b954e006a7405&scene=126&sessionid=1681371476#rd)

今天，国家信息安全漏洞库（CNNVD）发布了7月的安全漏洞播报，2017年6月份采集安全漏洞共909个，Microsoft Windows 10成为黑客重要攻击目标。本月国内厂商漏洞数量共69个，修复率达到94.20%。

  

本月CNNVD接报漏洞共计1914个，其中信息技术产品漏洞（通用型漏洞）60个，网络信息系统漏洞（事件型漏洞）1854个。

  

根据CNNVD发布的统计信息显示，**锦行科技**作为向CNNVD提交漏洞的支持者与参与者，凭借96个漏洞位列本月提交漏洞总量**全国第三**，非平台类安全公司中排名**第一**。

  

![](../Images/8872b2cc95ae9004592b86636addd5c5.png)

  

以下是CNNVD本月所有提交漏洞的情况汇总信息：

 

根据CNNVD统计结果显示，2017年6月新增漏洞数量有所下降，共909个，与上月（1149个）相比下降了20.89%。根据近6个月来漏洞新增数量统计图，平均每月漏洞数量达到918个。

  

![](../Images/01ac086750fd26dda867d8e1c4ec040a.png)

  

漏洞类型分布

6月份发布的漏洞类型分布如下表所示，其中**缓冲区错误类漏洞所占比例最大**，约为14.08%。

  

![](../Images/5bded729ffc163c6aa20c59e80ba497a.png)

  

**漏洞危害等级分布**

根据漏洞的影响范围、利用方式、攻击后果等情况，从高到低可将其分为四个危害等级，即超危、高危、中危和低危级别。6月漏洞危害等级分布如图2所示，其中超危漏洞93条，占本月漏洞总数的10.23%。

  

![](../Images/698dab3753ad061eae60df786f242b5c.png)

  

 

**整体修复情况**

6月漏洞修复情况按危害等级进行统计见下图，其中超危漏洞修复率最高，达到91.40%，中危漏洞修复率最低，比例为65.91%，本月超危、中危、低危漏洞修复率均有所上升，高危漏洞修复率有所下降，导致本月整体修复率有所上升，由上月的70.06%上升至本月的74.81%，上升了4.75个百分点。

![](../Images/95c620bcacb3ec248b9c7a18d4f0815b.png)

  

安全从业者往往面对的最大挑战就是在正义和责任面前能够控制逐利的脚步，锦行科技将继续秉持企业文化，持续保持重大漏洞和重要安全事件的发现、分析、处置能力，进一步助力国家信息安全漏洞研究、事件解读，形成漏洞的收集、分析、处置、披露的良性机制，将安全能力服务于社会和行业，做一家让客户放心，让自己安心的安全企业。
