微软2月补丁日多个高危安全漏洞



2月15日，微软官方发布了本月的安全更新通告，对多个产品中的安全漏洞进行了修复：https://msrc.microsoft.com/update-guide/releaseNote/2023-Fe


此次安全更新中，微软共修复了76个漏洞，涉及的产品软件包括 Microsoft PEAP、Microsoft Word、Microsoft Exchange Server 等。所有这些漏洞中，有9个漏洞危害评级为严重、有66个漏洞危害评级为重要。


漏洞描述


此次安全更新中，微软修复的危害评级为严重的漏洞包括：


1、CVE-2023-21692/CVE-2023-21690/CVE-2023-21689: Microsoft PEAP 远程代码执行漏洞

Microsoft PEAP 是可扩展身份验证协议 (EAP) 的安全实现，它提供加密和经过身份验证的传输层安全 (TLS) 隧道。CVE-2023-21692、CVE-2023-21690 和 CVE-2023-21689 即为 PEAP 实现中存在的远程代码执行漏洞，攻击者在未经过身份验证的情况下可通过向 PEAP 服务端发送恶意构造的 PEAP 数据包来利用此漏洞，成功利用此漏洞会使得攻击者在目标服务端上执行任意恶意代码、获取系统权限。


2、CVE-2023-21716: Microsoft Word 远程代码执行漏洞

CVE-2023-21716 为 Microsoft Word 中的远程代码执行漏洞，攻击者可通过构造恶意的 RTF 文档诱使受害者点开（如发送邮件）来进行漏洞利用。CVE-2023-21716 也同时影响 Microsoft SharePoint 和 Microsoft Office 应用程序。该漏洞可用于“预览面板”中攻击。


3、CVE-2023-21718: Microsoft SQL ODBC 驱动程序远程代码执行漏洞

CVE-2023-21718 为 Microsoft SQL ODBC 驱动程序中的远程代码执行漏洞，当用户使用 ODBC 驱动连接到由攻击者控制的恶意的 SQL 服务器时，攻击者就可以利用此漏洞在用户 ODBC 客户端执行任意恶意代码。


4、CVE-2023-21808/CVE-2023-21815/CVE-2023-23381: .NET/Visual Studio 远程代码执行漏洞

用户在使用 Visual Studio 打开恶意项目文件时将可能触发漏洞，攻击者从而可在用户客户端执行任意恶意代码。


此次安全更新中，微软修复的已经出现在野利用的漏洞包括：


1、CVE-2023-21823: Windows Graphics 图形组件权限提升漏洞

Windows Graphics 图形组件中存在代码执行漏洞，本地低权限的攻击者通过利用此漏洞可权限提升至系统最高权限用户SYSTEM。


2、CVE-2023-21715: Microsoft Office 安全特性绕过漏洞

Microsoft Office 存在安全特性绕过漏洞，攻击者可通过利用此漏洞绕过用来阻拦恶意文件的 Office 宏策略。


3、CVE-2023-23376: Microsoft 通用日志文件系统驱动程序权限提升漏洞

Microsoft 通用日志文件系统（CLFS）驱动程序存在权限提升漏洞，本地低权限的攻击者通过利用此漏洞可权限提升至系统最高权限用户SYSTEM。


解决方案


微软官方已发布相应的补丁修复漏洞，Windows 系统用户可通过默认开启的安全更新检查进行漏洞修复更新，也可以访问以下链接手动安装相关的漏洞补丁：

https://msrc.microsoft.com/update-guide/releaseNote/2023-Fe
