# 漏洞风险提示 | Fortinet FortiOS SSLVPN 远程代码执行漏洞（CVE-2022-42475）

        长亭漏洞风险提示       

  

**Fortinet FortiOS SSLVPN **

**远程代码执行漏洞**

**（CVE-2022-42475）**

  

  

Fortinet FortiOS是美国飞塔（Fortinet）公司的一套专用于FortiGate网络安全平台上的安全操作系统。该系统为用户提供防火墙、防病毒、VPN、Web内容过滤和反垃圾邮件等多种安全功能。

  

Fortinet 官方在12月12日发布安全公告，声明修复了 sslvpnd 中的一处堆溢出漏洞CVE-2022-42475：

https://www.fortiguard.com/psirt/FG-IR-22-398

**漏洞描述**

  

CVE-2022-42475是 FortiOS SSLVPN 的 sslvpnd 中的一处堆溢出漏洞，远程且未经过授权认证的攻击者通过利用此漏洞可在服务端执行任意恶意代码，获取系统权限。

  

**CVE-2022-42475的CVSSv3评分为9.3，官方认定为高危**，且根据官方说法，此漏洞已经出现在野利用。受漏洞影响的用户需尽快进行安全更新升级。

  

**影响范围**

  

*   FortiOS 7.2.x <= 7.2.2
    
*   FortiOS 7.0.x <= 7.0.8
    
*   FortiOS 6.4.x <= 6.4.10
    
*   FortiOS 6.2.x <= 6.2.11
    
*   FortiOS-6K7K 7.0.x <= 7.0.7
    
*   FortiOS-6K7K 6.4.x <= 6.4.9
    
*   FortiOS-6K7K 6.2.x <= 6.2.11
    
*   FortiOS-6K7K 6.0.x <= 6.0.14
    

  

**解决方案**

  

Fortinet 官方已发布新版本进行漏洞修复，受影响的用户可升级到如下安全版本进行漏洞修复：

*   FortiOS 7.2.3
    
*   FortiOS 7.0.9
    
*   FortiOS 6.4.11
    
*   FortiOS 6.2.12
    
*   FortiOS-6K7K 7.0.8
    
*   FortiOS-6K7K 6.4.10
    
*   FortiOS-6K7K 6.2.12
    
*   FortiOS-6K7K 6.0.15
    

  

目前官方已发现此漏洞的在野利用，用户可根据官方给出的以下线索进行排查是否已被入侵：

  

**1) 检查是否存在以下多个日志记录：**

Logdesc="Application crashed" and msg="\[...\] application:sslvpnd,\[...\], Signal 11 received, Backtrace: \[...\]“

  

**2) 系统存在以下文件：**

/data/lib/libips.bak

/data/lib/libgif.so

/data/lib/libiptcp.so

/data/lib/libipudp.so

/data/lib/libjepg.so

/var/.sslvpnconfigbk

/data/etc/wxd.conf

/flash

  

**3) 从 FortiGate 连接到可疑 IP 地址：**

188.34.130.40:444

103.131.189.143:30080,30081,30443,20443

192.36.119.61:8443,444

172.247.168.153:8033
