        长亭漏洞风险提示       

  

**微软11月补丁日**

**多个高危安全漏洞**

  

  

11月9日，微软官方发布了本月的安全更新通告，针对存在于多个微软产品中的共计64 安全漏洞进行了修复，其中11个漏洞危害评级为严重，53个漏洞危害评级为重要：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Nov

  

**漏洞描述**

  

微软本次安全更新中值得重点关注的漏洞主要包括：

###### 

  

###### **CVE-2022-41040 Microsoft Exchange Server 服务端请求伪造漏洞**

  

CVE-2022-41040 为 Microsoft Exchange Server 中的 SSRF（服务端请求伪造）漏洞，CVSS 评分 8.8。该漏洞在此前已被公开披露过细节及相关的利用代码。此漏洞的利用需要攻击者经过身份认证。

###### 

  

###### **CVE-2022-41082 Microsoft Exchange Server 远程代码执行漏洞**

  

CVE-2022-41082 为 Microsoft Exchange Server 远程代码执行漏洞，CVSS 评分 8.8。攻击者可将 CVE-2022-41082 通过与 CVE-2022-41040 配合利用，最终可实现远程代码执行。此漏洞的利用需要攻击者经过身份认证，目前尚未有公开的漏洞细节，但 CVE-2022-41082 与 CVE-2022-41040 均已出现在野利用。

###### 

  

###### **CVE-2022-41128 Windows Scripting Languages (JScript9) 远程代码执行漏洞**

  

CVE-2022-41128 为 Windows Jscript9 远程代码执行漏洞，CVSS 评分 8.8。此漏洞的利用需要受害者交互，攻击者可通过诱导受害者访问恶意的网站或者服务共享来触发利用此漏洞。目前暂无此漏洞的利用细节公开，但此漏洞已出现在野利用。

###### 

  

###### **CVE-2022-41073 Windows Print Spooler 权限提升漏洞**

  

CVE-2022-41073 为 Windows Print Spooler 中的权限提升漏洞，CVSS 评分 7.8。攻击者通过利用此漏洞可实现本地提权，将普通权限的系统用户提升至最高 SYSTEM 权限。目前暂无此漏洞的利用细节公开，但此漏洞已出现在野利用。

###### 

  

###### **CVE-2022-41125 Windows CNG Key Isolation Service 权限提升漏洞**

  

CVE-2022-41125 为 Windows CNG Key Isolation Service 中的权限提升漏洞，CVSS 评分 7.8。攻击者通过利用此漏洞可实现本地提权，将普通权限的系统用户提升至最高 SYSTEM 权限。目前暂无此漏洞的利用细节公开，但此漏洞已出现在野利用。

**解决方案**

  

微软官方已发布相应的补丁修复漏洞，Windows 系统用户可通过默认开启的安全更新检查进行漏洞修复更新，也可以访问以下链接手动安装相关的漏洞补丁：

https://msrc.microsoft.com/update-guide/releaseNote/2022-Nov

  

**产品支持**

  

*   **牧云：**已发布漏洞检测升级包支持对上述漏洞进行检测，可前往升级平台发布下载更新；
    
*   **全悉：**默认支持对 CVE-2022-41040 Microsoft Exchange Server 服务端请求伪造漏洞扫描的检测。
