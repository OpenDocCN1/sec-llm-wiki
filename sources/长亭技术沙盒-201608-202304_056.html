“我们拒绝粗制滥造的大而全，也不愿止步小而美；我们研究最新的漏洞，探索最前沿的最高效的检测方法；我们一道披荆斩棘，点亮夜空，只为追赶瞬息万变的攻防节奏。而这一切，皆凝结于xray之中。”

——xray社区某位作者


2019年4月的某一天，一间很普通的会议室中，有个人在努力说服大家接受一件几乎是不可能的事情：结合一年多的扫描引擎实战研究，重构刚刚发布大半年的洞鉴扫描引擎。


这在当时创业仅三年，仍处于艰难成长的长亭科技来说、对于一个刚发布不到一年的新产品来说，几乎可以说是大胆且疯狂的。


但产品实战能力至上的思考和技术精益求精的坚持，与其等到不久将来面临各种扫描瓶颈的挑战，还不如基于现在一年多的实战研究经验，再次让事件归于简单：重构现有引擎，保证第一个发布的版本具备产品现有的全部扫描能力，同时会将该版本部分功能免费开放，让社区技术玩家来评判它的效果。


6月13日9点58分，一个多月的重构时间，github 上发布了这个工具的 0.1.0 版本，而这个工具便是后来被安全圈所熟知的 xray。


2022年6月，xray三周年了！  


这三年，在所有开发者和技术爱好者的努力下，xray开始慢慢变成所有人理想中的样子。




第一个全面实现无害化漏洞检测的工具                         

第一个将语义分析技术深入应用在扫描器中的工具

第一个实践基于 YAML 的漏洞检测并与社区共享大量高质量 POC

第一个同时支持基础爬虫、浏览器爬虫（rad）和被动代理的漏洞扫描工具

第一个深入融合社资源区并运转良好的安全工具




在19年阿里先知大会上，Koalr师傅曾说过希望xray能够抛砖引玉，也期待社区有更好的作品产生。回顾这三年，xray 也确实或直接或间接的对国内安全的发展起到了一些正向的推动作用。 




各类安全工具如春雨般涌现，goby, fscan, yakit 等陆续进入大家视野   

Go 语言在安全圈大流行，已经基本盖过 Python 的风采，安全开发水平也有了一些提高  

大量安全从业人员会在项目中使用 xray 帮助自己快速挖掘一些常见漏洞，提高了工作效率  

安全圈大佬更乐于分享自己的研究成果，且质量普遍较高




当有人用 xray 挖到10万元的漏洞时，当多次上榜 github trending 但本身只是半开源状态时，当在大批面试者的简历里看到 “熟练使用 burpsuite、xray 等工具” 的字样时，这大概便是 xray 社区的初心。


三周年重磅发布


新的征程，新的创新。


在三周年来临之际，xray再次迎来重大更新。


添加基于依赖注入的插件系统（该功能将会在预览版放出）


扫描器，或者说一个好的插件系统，需要解决的核心问题是怎么让水平参差不齐的开发者都写出具有一定水准的逻辑单元？


通过依赖注入框架，我们可以声明式的指定插件所依赖的模块，系统会自动的实例化好所需要的模块。


插件本身只需要关注逻辑，而不需要处理各个模块的初始化或者“如何获得某个模块的能力”的问题，只要插件声明它需要的东西，一切都准备就绪。


最简单的理解就是，你可以使用golang编写一个插件，在这个插件中获取xray在扫描过程中所能输出的所有内容，然后进行再处理，进行再发包，并且可以自定义编写好的插件的参数，来自定义输入等。那么也就意味着你可以实现非常多的功能：




专属于你自己的注入检测插件  

wordpress全版本漏洞扫描插件  

专属定制自己所需要的漏洞报告与漏洞提示形式  

在扫描过程中获取自己所需的所有信息，重新组织整理，例如获取IP归属地等  

针对想要扫描的每一个端口发送任何payload，不再局限于http  

一个精美的扫描过程的统计界面   

…




具体使用请打开stack.chaitin.com进入社区查看。


同时，还会有以下更新：

1. 开放主机扫描功能

2. burp的history导出的xml转yaml poc格式的功能

3. log4j2-rce的检测

4. 为自定义脚本(gamma)添加格式化时间戳函数、进制转换函数、sha，hmacsha函数、url全字符编码函数。


从三周年开始，xray将保持较高频率的持续更新，除了新功能迭代，还会及时合并最新的poc。


对外，xray还将与CT stack社区紧密合作：

1. 与CT stack共同打造完善的生态社区：基于依赖注入的插件系统不断完善xray功能

2. 将xray变得小巧，便捷且功能强大：可在线检索和下载社区已收录插件；

3. 打造在线的SaaS反连平台，一键启动：降低利用反连检测插件的使用难度，提升便捷性；

4. 成为网络安全行业入门级工具，助力人才培养：输出使用指导文档与教学视频，降低学习成本；

…


我们希望在未来，xray的定位将不仅仅是一个漏洞扫描工具，而是安全从业人员的引路人。自此以后，xray将更像一个乐高，只要愿意动手去拼，就有无限可能。它的下限可以很低，变成针对于某一个漏洞的专项扫描，但上限也可以很高，变成全自动漏洞管理平台，从发现到攻击到维持，无所不能。是林间小屋亦或是雄伟城堡，将全权掌握在使用者的手中。



三周年，愿与你共庆！
