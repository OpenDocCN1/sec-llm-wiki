Dirty Pipe - Linux 

内核本地提权漏洞



3 月 7 日，国外的安全研究员 Max Kellermann 发布博客，披露了一处存在于Linux 内核中的本地提权漏洞 CVE-2022-0847：

https://dirtypipe.cm4all.com/


漏洞描述


CVE-2022-0847 是存在于 Linux内核 5.8 及之后版本中的本地提权漏洞。攻击者通过利用此漏洞，可覆盖重写任意可读文件中的数据，从而可将普通权限的用户提升到特权 root。


CVE-2022-0847 的漏洞原理类似于 CVE-2016-5195 脏牛漏洞（Dirty Cow），但它更容易被利用。漏洞作者将此漏洞命名为“Dirty Pipe”。


影响范围


  • 5.8 <= Linux 内核版本 < 5.16.11 / 5.15.25 / 5.10.102


解决方案


更新升级 Linux 内核到以下安全版本：

  • Linux 内核 >= 5.16.11

  • Linux 内核 >= 5.15.25

  • Linux 内核 >= 5.10.102


产品支持


牧云主机安全管理平台无需更新，可快速排查该漏洞影响范围。具体内容请参考文末的牧云操作手册。

牧云操作手册


基于牧云快速感知高风险漏洞影响范围



查看内核版本


牧云主机安全管理平台无需更新，可快速排查该漏洞影响范围。牧云支持基于应用视角和主机视角两种模式进行排查。



基于应用视角查看内核版本


1、成功登录牧云管理端后，点击“资产清点”功能模块，点击“软件”按钮，进入软件页面，点击该页面中的操作系统内核按钮。




2、在数据清单视角切换选项中，选择软件版本号，就可快速查询到该内核版本部署范围与数量。点击主机数量，可查看具体资产清单。




基于主机视角查看内核版本


1、成功登录牧云管理端后，点击“资产清点”功能模块，在主机页面中点击右侧上方的数据视图按钮。



2、在主机资产数据清单视图，通过筛选器选择内核版本条件，输入需要查询的内核版本信息（支持模糊查询），符合内核版本条件的主机资产信息将会自动展现。



3、点击数据清单中的主机IP按钮，可查看该主机内核版本信息。
