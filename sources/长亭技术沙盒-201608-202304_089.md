        长亭漏洞风险提示       

  

   **MinIO 用户权限提升漏洞**

**（CVE-2021-43858）**

  

  

MinIO是一个用Golang开发的基于Apache License v2.0开源协议的对象存储服务。它兼容亚马逊S3云存储服务接口，非常适合于存储大容量非结构化的数据，例如图片、视频、日志文件、备份数据和容器/虚拟机镜像等，而一个对象文件可以是任意大小，从几kb到最大5T不等。

  

2021年12月28日，MinIO官方发布安全公告，修复了一处用户权限提升漏洞，**漏洞编号为 CVE-2021-43858，CVSS 评分 8.8 高危**：

https://github.com/minio/minio/security/advisories/GHSA-j6jc-jqqc-p6cx

  

**漏洞描述**

  

MinIO AddUser() admin API 主要用于创建用户或者修改用户密码。然而由于其代码实现存在安全缺陷， MinIO 普通用户可通过构造恶意数据包调用此 API，提升用户权限至管理员，接管 MinIO 管理功能。

  

此漏洞的利用需要攻击者有 MinIO 普通用户账户权限，但一旦攻击者成功利用此漏洞提权至管理员，通过利用管理员的某些高权限功能接口，攻击者不仅可接管 MinIO，获取或改写其存储的所有数据，某些场景下还可能达到远程代码执行的危害，获取服务器系统权限。

  

**影响范围**

  

*   MinIO RELEASE.2021-12-27T07-23-18Z 之前的版本
    

**解决方案**

  

厂商已发布新版本修复漏洞，可将 MinIO 升级至 RELEASE.2021-12-27T07-23-18Z 版本进行漏洞修复：https://github.com/minio/minio/releases
