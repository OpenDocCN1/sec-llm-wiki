        长亭漏洞风险提示       


     Fastjson 远程代码执行漏洞



5 月 28 日，长亭科技监测到漏洞情报，Fastjson <= 1.2.68 版本存在远程代码执行漏洞，漏洞若被成功利用，可直接获取服务器权限.


漏洞描述



Fastjson 是阿里巴巴的开源 JSON 解析库，它可以解析 JSON 格式的字符串，支持将 Java Bean 序列化为 JSON 字符串，也可以从 JSON 字符串反序列化到 JavaBean。


Fastjson 1.2.68 及之前的版本存在远程代码执行漏洞，autoType 开关的限制可以被绕过，链式的反序列化攻击者精心构造反序列化利用链，最终达成远程命令执行的后果。此漏洞本身无法绕过 Fastjson 的黑名单限制，需要配合不在黑名单中的反序列化利用链才能完成完整的漏洞利用。


影响范围


Fastjson 1.2.68 及之前的版本。


解决方案


截至目前，Fastjson 尚未发布新版对漏洞进行修复，漏洞详情信息也未公开。可以考虑先采取以下措施进行临时防护，并持续关注官方新版本发布信息：


(1) 升级 Fastjson 至 1.2.68 版本，并配置 safeMode


将 Fastjson 升级至 1.2.68 版本，该版本引入了一个 safeMode 的配置，配置 safeMode 后，无论白名单和黑名单，都不支持 autoType。


有多种方式可以配置 safeMode，具体步骤可参考：

https://github.com/alibaba/fastjson/wiki/fastjson_safemode


需要注意的是，开启 safeMode 会完全禁用 autoType 类型转换，请注意评估此项配置对业务的影响。


(2) 长远来看，建议使用 Gson 作为 Fastjson 的安全替换。
