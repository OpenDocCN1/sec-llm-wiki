 长亭漏洞风险提示

     

 Microsoft Exchange Server 远程代码执行漏洞（CVE-2020-0688）


2 月 25 日，ZDI 发表博客，公布了最近微软修复的 CVE-2020-0688 Exchange Server 远程代码执行漏洞的细节：
https://www.thezdi.com/blog/2020/2/24/cve-2020-0688-remote-code-execution-on-microsoft-exchange-server-through-fixed-cryptographic-keys


漏洞描述



此漏洞是由于所有的 Microsoft Exchange Server 均使用了同一个固定的 validationKey 和 decryptionKey。这些密钥的值本是用来保证 ViewState 的安全性，但由于现在这些密钥值相当于已经公开，因此经过认证的攻击者可以正确加密并构造出恶意的 ViewState 数据，而服务端在解析 ViewState 数据时将会触发反序列化，从而最终导致攻击者能够以 SYSTEM 权限在服务端执行任意恶意代码，获取系统权限。


影响范围


  • Microsoft Exchange Server 2010 Service Pack 3 Update Rollup 30

  • Microsoft Exchange Server 2013 Cumulative Update 23

  • Microsoft Exchange Server 2016 Cumulative Update 14

  • Microsoft Exchange Server 2016 Cumulative Update 15

  • Microsoft Exchange Server 2019 Cumulative Update 3

  • Microsoft Exchange Server 2019 Cumulative Update 4
