        长 亭 漏 洞 风 险 提 示       

  

WebLogic T3、IIOP 高危漏洞（CVE-2020-2546、CVE-2020-2551）

  

  

  

1 月 14 日，Oracle 官方发布严重补丁更新 CPU（Critical Patch Update），其中有 2 个针对 WebLogic Server 的高危漏洞 CVE-2020-2546、CVE-2020-2551，官方危害评级 9.8 分：

https://www.oracle.com/security-alerts/cpujan2020.html

  

  

漏洞描述

  

  

CVE-2020-2546 漏洞影响组件为 WebLogic Application Container，通过 T3 协议进行利用；CVE-2020-2551 漏洞影响组件为 WebLogic WLS 核心组件，通过 IIOP 协议进行利用。

这两个漏洞都是官方危害评级 9.8 分的高危漏洞，攻击者可以在远程且未授权的状态下进行利用。

  

影响范围

  

  

CVE-2020-2546 漏洞影响版本：

*   WebLogic Server 10.3.6.0.0
    
*   WebLogic Server 12.1.3.0.0
    

  

CVE-2020-2551 漏洞影响版本：

*   WebLogic Server 10.3.6.0.0
    
*   WebLogic Server 12.1.3.0.0
    
*   WebLogic Server 12.2.1.3.0
    
*   WebLogic Server 12.2.1.4.0
    

  

  

解决方案

  

使用 Oracle 官方安全补丁进行更新修复：

https://www.oracle.com/technetwork/security-advisory/cpuoct2018-4428296.html

  

作为临时缓解方案，可以考虑在不影响业务的情况下禁用 T3 及 IIOP 协议的使用：

  

**禁用 T3 协议：**

  

登入 WebLogic 控制台，在对应域设置中选择 “安全”-“筛选器” 选项卡：

  

![](../Images/b6562904e1ad0f14bfb910f3ead626f8.png)

  

在 “连接筛选器” 输入框中输入：

weblogic.security.net.ConnectionFilterImpl

  

在 “连接筛选器规则” 输入框中输入（即配置为仅允许本机使用 T3/T3S 协议通信，禁用除本机以外其他主机使用 T3/T3S 协议通信）：

127.0.0.1 \* \* allow t3 t3s

0.0.0.0/0 \* \* deny t3 t3s

输入后保存提交。

  

**禁用 IIOP 协议：**

  

登入 WebLogic 控制台，在对应域设置中选择 “监视”-“服务器” 选项卡，选择要管理的 server：

  

![](../Images/36a0e13732dc149e8cff9f0fcc2fcb7c.png)

  

进入 server 配置页面，选择 “协议”-“IIOP” 选项卡，取消 “启用 IIOP” 的勾选，保存提交，并重启 WebLogic，使配置生效：

  

![](../Images/3ab662655835f22cb5ca1b666bf289eb.png)

  

  

从长远来看，由于 WebLogic 本身架构设计上缺乏安全考虑，建议寻找替代 WebLogic 的方案。
