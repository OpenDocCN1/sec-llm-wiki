Harbor 多个高危漏洞




12 月 4 日，容器镜像管理平台 Harbor 官方发布安全更新通告，修复了包括权限提升、SQL 注入、用户枚举等多个高危漏洞：


https://github.com/goharbor/harbor/security/advisories



漏洞描述


此次 Harbor 安全更新通告一共涉及 5 个漏洞：

权限提升漏洞（CVE-2019-19023）

普通用户可以操作某些 API 接口来修改其他用户的邮箱地址，因此通过修改管理员账号的邮箱地址，然后再进行密码重置，即可获取管理员账号权限，达到权限提升的目的。


用户枚举漏洞（CVE-2019-3990）

用户信息查询的 API 接口由于限制不严，导致普通用户可以调用此接口，列举系统所有的用户名和用户 ID 等信息。


user-groups SQL 注入漏洞（CVE-2019-19029）

具有 Project-Admin 权限的用户可以触发此 SQL 注入漏洞，从而获取数据库数据信息或进行权限提升。


project quotas SQL 注入漏洞（CVE-2019-19026）

具有管理员权限的用户可以触发此 SQL 注入漏洞，从而获取数据库数据信息。


CSRF 漏洞（CVE-2019-19025）

由于 Harbor 的 Web 接口缺乏 CSRF 防御机制，因此攻击者通过诱导经过认证的受害者访问其恶意网站，即可以受害者的身份对平台系统进行任何相应的操作。



影响范围


· Harbor 1.7.*

· Harbor 1.8.* < 1.8.6

· Harbor 1.9.* < 1.9.3



解决方案


升级 Harbor 至 1.9.3 或 1.8.6。
