12 月 7-8 日，由长亭科技主办的 2019 Real World CTF 将在北京举办，同期，作为大赛特色项目之一的安全训练营将在12月7日隆重开营，这也是长亭科技首次对外开班授课。
凭借在攻防领域多年的实战积累和对安全竞赛的深入理解，长亭科技聚焦攻防，围绕 Real World CTF 推出全新实战攻防战术课程，汇聚全球顶尖安全大神及行业最精锐力量，将“虚拟化” “应用软件” “内核” “浏览器”四大主流内容，盘到彻底，盘出精彩。
安全训练营采取全日制、全景式封闭培训，深度融合真实破解案例和顶级国际赛题，为了无限缩短“听懂”和“做到”之间的距离，学员需全程自带电脑，上手实操。高频干货输出，直达攻防要点；提纲挈领式讲解，直击迷局关键。更有独家讲师一手心得分享，实属行业稀缺培训资源，可切实有效地提升安全实战能力。
顶级阵容  倾囊相授


课程一

带你玩转虚拟化安全：从 CTF 到实战


吞下这颗“红色药丸”，带你跨越真实和虚拟的界线，去探索不止于《黑客帝国》的虚拟机真相。


f1yyy 张焱宇，长亭科技高级安全研究员。曾在 2018 GeekPwn 国际安全极客大赛上成功挑战具有世界级难度的“虚拟机逃逸”项目，这是全球范围内首次针对 VMware ESXi 虚拟机逃逸的公开演示，获得 GeekPwn 最佳技术奖&名人堂成员；2019 DEF CON Final 季军；多次获得 Red Hat、VMware 等虚拟化大厂官方致谢。专注于虚拟化安全、漏洞挖掘与利用。 

本课程以主流虚拟化软件实现原理为起点，结合多个虚拟机逃逸的实战案例，重点讲授虚拟化软件漏洞发掘和利用技术。
▪  全视角讲解虚拟化技术的实现方式，独特角度来分析多种虚拟化技术之间的差异、特点、优缺；
▪  对 KVM 实现架构结合实例分析，现场实操巩固理解技术知识；
▪  Pwn2Own、Real World CTF 和强网杯题目讲解及真实漏洞分析，分享 POC 思路，EXP 的设计技巧；
▪  VMware 实现架构分析，实现架构结合实例分析，现场实操巩固理解技术知识；
▪  DEF CON CTF 题目剖析，感受国际顶级赛事的独特解题思路，提升硬实力。

课程二

Real World CTF中的通用漏洞利用方法论

将漏洞思路与漏洞利用串连起来，打通《盗梦空间》里的虚拟与真实，掌握 Real World CTF 正确解题方向。

Atum 李冠成，前蓝莲花战队核心成员，0CTF 2019 Final 冠军，r3kapig 战队队长，曾在 ACM CCS 等会议上发表论文，并为 Baidu CTF 等多个国际比赛组织命题。
本课程专注于讲解当面对不熟悉的应用软件 PWN 题时，如何去探索漏洞利用方法和方向，设计和编写漏洞利用代码。

▪  授人以渔，讲师总结的 Real World CTF 通用漏洞利用思想和方法论，使学员在面对任何不熟悉目标的题目时，都能够把握发力的方向；

▪  讲授主流平台的内存攻防技术发展，学习前沿内存破坏缓解机制和绕过思路；

▪  从国际知名的强网杯、0CTF、Real World CTF 等比赛中选取真实赛题，进行现场分析、思路总结；

▪  讲师现场带领学员进行漏洞利用的设计、编写和调试，在实战中学习最真实的漏洞利用设计和编写技巧；

▪  拒绝纸上谈兵，讲师将现场讲解真实的漏洞利用案例，对课程中所讲述的思想和方法论进行举例和印证。

课程三

Linux安全——内核漏洞调试与利用

破除操作系统内核中的漏洞攻击，远离《解除好友》式威胁，全方位提升网络攻防能力。

BrieflyX 裴中煜，就职于阿里安全，清华大学网络与信息安全实验室成员。曾任清华大学网络安全与技术协会会长，蓝莲花战队成员，2016 DEF CON CTF Final 亚军。擅长二进制漏洞利用。 
本课程主要着眼于 Linux 操作系统的内核实现，讲解 Linux 用户态程序与内核交互的方式，阐述内核漏洞利用的一般流程，通过列举一些内核漏洞的类型及危害，介绍内核漏洞的挖掘技术与相关研究。
▪  从用户态到内核态，系统经历了什么；
▪  掌握内核是如何管理计算机系统的，体验内核态编程；
▪  玩转 QEMU 配合 GDB 内核调试技术；
▪  将多年的漏洞驱动程序编写经验，从 0 到 1 的过程实例教授编写方法；
▪  从 CTF 题目出发，熟知内核漏洞利用的常见思路和缓解技术，提升内核安全认知。

课程四

浏览器安全——实战技术提升

抽丝剥茧，一起进入《网络迷踪》，探寻浏览器漏洞背后隐藏的真相。

scdeny 邓袁，蚂蚁金服光年实验室安全专家。蓝莲花战队早期核心队员，Black Hat 等著名国际安全会议演讲嘉宾，多次获得谷歌、苹果、微软公开致谢。专注于浏览器漏洞研究、沙盒研究等。

本课程专注于主流浏览器安全机制，及浏览器漏洞的挖掘和利用技术。
▪  浏览器安全架构，引导分析其攻击面；
▪  浏览器攻防对抗简史，了解每一项安全机制出炉前的千锤百炼；
▪  Pwn2Own 浏览器漏洞，感受顶级漏洞的技术深度；
▪  真实场景中发生的浏览器漏洞攻击，如何远程攻破数百款 App；
▪  国际 CTF 题目，感受顶级赛事与真实漏洞的碰撞与结合，快速提升综合实力；
▪  浏览器 fuzz 技术的发展历程及现状，感受 fuzz 领域的高手过招。
