        长 亭 漏 洞 预 警        

       

泛微 e-cology OA 系统 SQL 注入漏洞

  

  

10 月 10 日，国家信息安全漏洞共享平台（CNVD）发布安全公告，其中收录了泛微 e-cology OA 系统的一个 SQL 注入漏洞 (CNVD-2019-34241)。

  

漏洞描述

  

泛微 e-cology OA 系统的 WorkflowCenterTreeData 接口处使用 Oracle 数据库时，其内置的 SQL 语句拼接不严，攻击者可在未授权的情况下利用 SQL 注入获取 Oracle 数据库敏感信息。

  

目前泛微官方尚未发布相应的补丁。

  

影响范围

  

所有使用 Oracle  数据库的泛微 e-cology OA 系统。

  

解决方案

  

暂时下线有漏洞的应用和服务，等待官方发布补丁后及时更新。

  

**使用雷池 WAF 的客户无需升级即可防御此漏洞。**
