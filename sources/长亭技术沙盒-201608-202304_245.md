        长 亭 漏 洞 预 警        

       

IBM WebSphere 敏感信息泄漏

（CVE-2019-4505）  

  

  

9 月 17 日，IBM 官方发布 WebSphere 安全补丁，其中修复了一个敏感信息泄漏 (CVE-2019-4505)。  

  

![](../Images/6f091703f3659c209e09a5e325d7ef1b.png)

  

漏洞描述

  

IBM WebSphere 存在敏感信息泄漏，该漏洞存在于 MiddlewareAgentWebapp.war 文件中。攻击者可以向远程目标系统的 /MiddlewareAgentRPCService/noadmin/ 路径发送精心构造的 GET 请求，以此读取目标系统特定目录下的任意文件，造成敏感信息泄漏。

  

影响范围

  

· WebSphere Application Server Version 9.0

· WebSphere Application Server Version 8.5

· WebSphere Virtual Enterprise Version 8.0

· WebSphere Virtual Enterprise Version 7.0

  

解决方案

  

更新官方发布的最新补丁：

· 9.0.0.0 - 9.0.5.0 的版本升级到 9.0.5.1 之后的版本

· 8.5.0.0 - 8.5.5.16 版本升级到 8.5.5.17 之后的版本

· 9.0.0.0 - 9.0.5.0 版本升级到 9.0.5.1 之后的版本

  

对于WebSphere Virtual Enterprise Edition ：升级到最新版本。

  

官方已经不再支持WebSphere Virtual Enterprise V7 和 V8 ，建议将其升级到固定支持的版本。
