        长 亭 漏 洞 预 警        

  

**WebLogic wls9-async 反序列化漏洞**

  

  

  

事件来源

  

4 月 17 日，国家信息安全漏洞共享平台（CNVD）发布安全公告，指出 Oracle WebLogic Server 默认组件 wls9-async 中存在反序列化漏洞：

https://mp.weixin.qq.com/s/5-mDG2GcFUjEG00KdQgxvQ

  

漏洞描述

  

wls9-async 为 WebLogic 默认组件，为 WebLogic Server 提供异步通讯服务。该组件中存在反序列化漏洞，远程且未经授权的攻击者通过利用此漏洞，可以在服务端执行任意代码。

  

该漏洞由中国民生银行股份有限公司报送给 CNVD 进行收录，目前官方补丁尚未发布，漏洞细节未公开。

  

  

影响范围

  

WebLogic 10.x

WebLogic 12.1.3

  

  

解决方案

  

目前，Oracle官方暂未发布补丁，参考 CNVD 给出的临时解决方案：

  

• 删除 wls9-async war 包组件并重启webLogic

• 通过访问策略控制禁止 /\_async/\* 路径的 URL 访问
