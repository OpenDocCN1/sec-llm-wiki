        长 亭 漏 洞 预 警        

  

      Confluence 路径穿越漏洞

（CVE-2019-3398）

  

  

事件来源

  

`4 月 16 日，Atlassian Confluence 官方发布安全通告，修复了存在于 Confluence 中的一处路径穿越漏洞：`

`   `

`https://confluence.atlassian.com/doc/confluence-security-advisory-2019-04-17-968660855.html`

`   `

漏洞描述

  

Confluence Server 和 Data Center 在 downloadallattachments 资源中存在路径穿越漏洞。攻击者通过利用此漏洞，可以在服务器上任意目录上传文件从而达到远程代码执行的危害。

此漏洞的利用需要攻击者拥有以下权限之一：

• 能够向页面或博客添加附件

• 能够创建新的空间（space）

• 对某空间（space）有 Admin 权限

  

影响范围

  

以下版本范围内的 Confluence 受到漏洞影响：

• 2.0.0 <= version < 6.6.13

• 6.7.0 <= version < 6.12.4

• 6.13.0 <= version < 6.13.4

• 6.14.0 <= version < 6.14.3

• 6.15.0 <= version < 6.15.2

  

解决方案

  

升级 Confluence 到最新版本：

https://confluence.atlassian.com/doc/confluence-security-advisory-2019-04-17-968660855.html
