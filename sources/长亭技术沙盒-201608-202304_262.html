 Apache HTTP Server 提权漏洞

（CVE-2019-0211）



4 月 1 日，Apache 官方发布安全更新，其中修复了存在于 Apache HTTP Server 中的一个高危漏洞 CVE-2019-0211。


漏洞描述


Apache HTTP Server 在 2.4.17 - 2.4.38 这些版本里，拥有 MPM 事件、worker、prefork，或能在权限较低的子进程或线程（包括由进程内脚本解释器执行的脚本）中执行代码时，可以通过操纵 scoreboard 来进行权限提升，从而能够以父进程的权限（通常是 root）执行任意代码。


影响范围


Unix 系统下的 Apache HTTP Server 2.4.17 - 2.4.38。


解决方案


升级 Apache HTTP Server 到 2.4.39。
