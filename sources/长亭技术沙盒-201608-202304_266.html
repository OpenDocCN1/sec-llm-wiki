      Nexus Repository Manager 3 远程代码执行漏洞（CVE-2019-7238）



2019 年 2 月 5 日，Sonatype 官方发布安全通告，修复了存在于 Nexus Repository Manager 3 中的一个远程代码执行漏洞。此漏洞由腾讯云鼎实验室的安全研究员 Rico 和长亭科技的安全研究员 voidfyoo 共同发现提交。



漏洞描述

Sonatype Nexus 是一个 Maven 的仓库管理系统，它提供了强大的仓库管理、构件搜索等功能，并且可以用来搭建 Maven 仓库私服，在代理远程仓库的同时维护本地仓库，以节省带宽和时间。


在 Nexus Repository Manager OSS/Pro 3.15 之前的版本中，由于某处功能缺乏访问控制，且未能正确处理用户传入的数据，导致远程且未经授权认证的攻击者，仅通过一个恶意的 HTTP 请求，就可以在服务端执行任意 Java 代码，获取系统权限：




影响范围


Nexus Repository Manager OSS/Pro 3.x < 3.15



解决方案


升级 Nexus Repository Manager OSS/Pro 3 到 3.15 版本。
