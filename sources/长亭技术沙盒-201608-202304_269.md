        长 亭 漏 洞 预 警        

  

****Windows DHCP Client 远程代码执行漏洞******（CVE-2019-0547）**

  

  

事件来源

  

1 月 8 日，微软官方发布安全公告，针对 Windows DHCP Client 中存在的一处远程代码执行漏洞进行修复：

https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2019-0547

  

漏洞描述

  

Windows 10 和 Windows Server 1803 版本系统中的 DHCP 客户端在处理 DHCP 响应时存在内存破坏漏洞，攻击者通过向客户端发送精心构造的 DHCP 响应，可以在目标系统上执行任意代码。

注意此漏洞不影响之前版本的 Windows 系统，并且目前尚无公开的 PoC，受漏洞影响的用户可以在漏洞发酵之前尽快进行安全修复。

  

影响范围

  

Windows 10 Version 1803 for 32-bit Systems

Windows 10 Version 1803 for ARM64-based Systems

Windows 10 Version 1803 for x64-based Systems

Windows Server, version 1803 (Server Core Installation)
