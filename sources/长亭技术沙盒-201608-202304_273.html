 Jenkins 非预期方法调用漏洞 

（SECURITY-595）



事件来源


Jenkins 官方在 12 月 5 日发布了安全资讯，其中对一个严重漏洞做了安全通告:

https://jenkins.io/security/advisory/2018-12-05/


漏洞描述


Jenkins 使用 Stapler 框架来处理 HTTP 请求，Stapler 的基本前提是它使用反射访问的方式处理符合其命名规范的代码。例如，任何名称以 get 开头且具有 String、int、long 或没有参数的公有方法都可以通过这些方式调用其被允许访问的对象。这些命名规范与 Java 中的常见代码模式非常类似，攻击者通过访问精心构造过的 URL ，可以调用到非预期范围内的方法，从而可能造成敏感信息泄露、越权操作、代码执行等危害。


Stapler 框架已经通过扩展接口 Service Provider Interface （SPI）实现了在路由中对方法和字段的过滤。该接口在新的实现中又限制了 Stapler 框架对其方法和字段的调用。其中包括可以被 Stapler 调用的 getter 方法、do* 方法和相应的字段。


影响范围


Jenkins weekly 2.153 及之前版本

Jenkins LTS 2.138.3 及之前版本


解决方案


更新 Jenkins weekly 到 2.154 版本

更新 Jenkins LTS 到 2.138.4 版本或 2.150.1 版本
