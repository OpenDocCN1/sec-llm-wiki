Gogs、Gitea 远程代码执行漏洞



事件来源


来自腾讯玄武实验室的安全研究员 5alt 在 10 月 22 日分别向 Gogs、Gitea 项目提交安全 issue，指出它们都存在一个在原理上类似的远程代码执行漏洞，随后通过邮件的方式分别向两者官方报告了漏洞细节：


https://github.com/gogs/gogs/issues/5469

https://github.com/go-gitea/gitea/issues/5140


漏洞描述


Gogs 和 Gitea 都是用于搭建简单、稳定、可扩展的自助 Git 服务的平台，并都使用 Go 语言开发。


Gogs 和 Gitea 远程代码执行漏洞本质上是任意用户登录漏洞。由于对用户 session ID 处理不当，导致攻击者通过精心构造恶意的 HTTP 请求，即可登录到任意用户账号。


攻击者可以通过利用任意用户登录漏洞，进入到 admin 账号，从而进一步通过 git hooks 在服务端执行任意代码。


影响范围


Gogs 所有版本。

Gitea 在 2018 年 10 月 25 日 commit 更新前的所有版本。


解决方案


由于 Gogs 目前 master 分支尚未合并漏洞修复的 commit，只在 develop 分支进行了修复，故 Gogs 用户可以考虑切换升级到最新的 develop 分支版本。


Gitea 用户直接升级到最新版即可。
