Gitlab Wiki API 远程代码执行漏洞

（CVE-2018-18649）



事件来源


10 月 29 号，Gitlab 官方发布安全更新通告，其中针对一个远程代码执行漏洞进行了修复：


https://about.gitlab.com/2018/10/29/security-release-gitlab-11-dot-4-dot-3-released/


漏洞描述


Gitlab Wiki API 是一组用于对 Gitlab 项目 Wiki 页面进行创建、编辑、列表、删除等功能的接口。


长亭科技的安全研究员 nyangawa 发现，Gitlab Wiki API 在处理外部输入时存在过滤检查不当的问题，导致攻击者可以通过发送特定的请求数据包，在 Gitlab 服务端执行任意代码。


影响范围


Gitlab CE/EE 11.3 及之后的版本


解决方案


升级 Gilab 到最新版
