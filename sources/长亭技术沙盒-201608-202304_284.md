        长 亭 漏 洞 预 警        

  

**Git submodule RCE **

**(CVE-2018-17456)**

  

  

事件来源

  

国外安全研究员 joernchen 在 9 月 23 日向 git 官方报告了漏洞的相关细节。10 月 5 号，git 官方公开了漏洞信息，以及相应的版本更新：

  

https://blog.github.com/2018-10-05-git-submodule-vulnerability/

  

https://marc.info/?l=git&m=153875888916397&w=2

  

漏洞描述

  

Joernchen 发现，命令行工具 git clone 无法正确处理子模块的 url 。当用户运行 git clone --recurse-submodules 命令时，git 会解析项目中 .gitmodules 文件的 url 字段，并将其直接作为选项参数传递到 git clone 子进程。攻击者可以通过构造以符号 - 开头的字符串作为 url 字段，当其传入 git clone 子进程时会被解释为一个选项，最终通过选项注入执行任意命令。

  

­­

内置了旧版本 git 的相关软件，也有可能受到此漏洞的影响。如：GitHub Desktop、Atom等等。

  

影响范围

  

git < 2.14.5

2.15.x < 2.15.3  
2.16.x < 2.16.5  
2.17.x < 2.17.2  
2.18.x < 2.18.1  
2.19.x < 2.19.1

  

解决方案

  

将 git 命令行工具更新至 git 官方发布的最新版本。

  
Github Desktop 更新至 1.4.2、1.4.3-beta0 版本。

  
Atom 更新至 1.31.2、1.32.0-beta3 版本。
