Microsoft Windows 

本地提权漏洞



事件来源


8 月 27 日，国外安全研究员 SandboxEscaper 在推特上公布了 Windows 本地提权漏洞的相关信息和 PoC 。到目前为止，没有发现与此漏洞相关的补丁。


漏洞描述


Microsoft Windows 任务调度服务中 API 接口 SchRpcSetSecurity 在处理 ALPC（Advanced Local Procedure Call）过程中存在漏洞，攻击者在已获取任意本地低权限用户的情况下，可以通过调用该函数来获得系统敏感文件的写权限（比如特定的 dll 文件），从而进行权限提升，获取到 SYSTEM 权限。



目前放出的 PoC 适用于 64 位的 Windows 10 系统和 Windows Server 2016 系统。


影响范围


Windows 10 64位系统和 Windows Server 2016 系统。

但是根据此漏洞原理，可以通过进一步修改漏洞利用的代码，影响到 32 位的 Windows 10 系统，甚至是其他的 Windows 版本。
