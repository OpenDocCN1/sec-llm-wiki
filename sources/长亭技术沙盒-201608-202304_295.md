# ERC20代币合约新型漏洞预警及分析，可导致无限授权转账

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMDk1MjMyMg==&mid=2247484278&idx=1&sn=3445efaa758884071885012347219d0c&chksm=96f41c1ba183950d5c0b51d5b668ca35ddec4b22fc47dc17e9f79bd0c17e1fe415e787576685&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwMDk1MjMyMg==&mid=2247484278&idx=1&sn=3445efaa758884071885012347219d0c&chksm=96f41c1ba183950d5c0b51d5b668ca35ddec4b22fc47dc17e9f79bd0c17e1fe415e787576685&scene=27#wechat_redirect)

  

  

**长亭科技在以太坊智能合约审计过程中发现了LightCoin Token合约的受委托转账方法中存在新型漏洞。**攻击者利用该漏洞可强制使受害者无限授权给任意用户，**相当于攻击者能够将受害者账下代币无限转出。**长亭科技依据漏洞原理将此漏洞类型命名为**“不一致性检查”(check effect inconsistency)。**

漏洞细节

  

合约地址：0xd97579Cea3fE2473682a4C42648134BB982433B9，访问https://etherscan.io/address/0xd97579Cea3fE2473682a4C42648134BB982433B9#code可查看合约代码。

                                              ![](../Images/8944c512d1c21c7790fe2f785cebae73.png)

![](../Images/851de21a59e7e5bc05de8a71abfd2d77.png)

  

Lightcoin合约的transferFrom函数，即授权转账函数，**本应在检查授权值余额(第55行)之后更新对应授权金额，然而却写错了授权地址（第58行）**，把原本应该更新的allowed\[\_from\]\[msg.sender\]写成了allowed\[\_from\]\[\_to\]，导致出现漏洞。

  

此时如果allowed\[\_from\]\[msg.send\]有余额而allowed\[\_from\]\[\_to\]为0，则allowed\[\_from\]\[\_to\]会下溢为一个非常大的数（接近2256），使得\_to账户获得无限授权值，进而可以随意花费受害者账中代币。

  

**据悉，Lightcoin项目方已获知该漏洞并已完成合约升级工作，提醒广大持币用户不必恐慌，做好升级工作即可。**

  

目前问题合约已作废：0xd97579Cea3fE2473682a4C42648134BB982433B9

升级后新合约地址为：0x1295b55fA04FBAc6d9e7c351Ecb3486e88129027

  

![](../Images/a99f6642b0e6c8890d9a83c7a742dc68.png)

  

我们在与安比实验室的进一步讨论中发现，**该类型漏洞除了可能影响授权值外，也可直接影响余额值。**

  

**Mich Coin**（地址：0x15a23eee2988a54e1a6b326fd469c94bed98ae5a）与**CountryCoin**（地址：0x3b912fb1b5b9e07e50e43f0404fee038f9a0353c）代币合约中存在此种类型漏洞（地址均由安比实验室提供）。

  

以Mich Coin为例，其转账前检查的是msg.sender的余额，之后却更新的是\_from的余额，导致攻击者可以无限刷币。

  

![](../Images/f268342300e72f24db096142db96d473.png)

  

**这两个代币合约虽并未上线交易所，但证明此类漏洞可影响余额变量。**请交易所与各个项目方自查，智能合约安全容不得半点马虎。
