**          长 亭 漏 洞 预 警               **

  

**WebLogic WLS-WebServices组件反序列化漏洞被大范围利用！**

  

  

近期，WebLogic WLS-WebServices组件反序列化漏洞（CVE-2017-3506、CVE-2017-10352）被大范围利用，漏洞影响下列版本的所有用户：  

  

Oracle WebLogic Server 10.3.6.0.0

Oracle WebLogic Server 12.1.3.0.0

Oracle WebLogic Server 12.2.1.1.0

Oracle WebLogic Server 12.2.1.2.0

  

**漏洞描述**

WebLogic在部署过程中默认启用了WLS-WebServices组件，此组件使用了XMLDecoder来解析序列化数据，攻击者可以通过构造恶意的XML文件来实现远程命令执行。

用户可通过访问http://weblogic\_ip/wls-wsat/CoordinatorPortType11, 来确认此组件是否正在运行。现因POC已经大范围传播，因此需尽快修复此漏洞。

  

**解决方案**

  
临时解决方案

根据业务所有需求，考虑是否删除WLS-WebServices组件。包含此组件路径为：

Middleware/user\_projects/domains/base\_domain/servers/AdminServer/tmp/\_WL\_internal/wls-wsat

  

Middleware/user\_projects/domains/base\_domain/servers/AdminServer/tmp/.internal/wls-wsat.war

  

Middleware/wlserver\_10.3/server/lib/wls-wsat.war

  

以上路径都在WebLogic安装处。删除以上文件之后，需重启WebLogic。确认http://weblogic\_ip/wls-wsat/ 是否为404页面。
