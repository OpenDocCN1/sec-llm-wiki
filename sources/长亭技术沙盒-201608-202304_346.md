# 【安全预警】Xmanager 和 Xshell 多种产品源码被植入后门

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMDk1MjMyMg==&mid=2247483972&idx=1&sn=7c120ff7c4d119eeaa9ad6ad94e1303c&chksm=96f41d29a183943faf845e9fffe84f1f18932132df6d692a039954f76221cb557e0d4ba3aa8e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwMDk1MjMyMg==&mid=2247483972&idx=1&sn=7c120ff7c4d119eeaa9ad6ad94e1303c&chksm=96f41d29a183943faf845e9fffe84f1f18932132df6d692a039954f76221cb557e0d4ba3aa8e&scene=27#wechat_redirect)

![](../Images/c3d75b892f4dfa3f54f84e740e7df024.png)

Xshell 是一个强大的安全终端模拟软件，它支持 SSH1, SSH2, 以及 Microsoft Windows 平台的 telnet 协议。Xshell 通过互联网到远程主机的安全连接以及它创新性的设计和特色帮助用户在复杂的网络环境中享受他们的工作。

  

2017 年 8 月 7 日，netsarang 发布了安全公告 \[1\] 称，与其合作的安全厂商在 2017 年 7 月 18 日之后发布的多款产品中发现了“安全漏洞”。经过确认，“安全漏洞” 实际上为源码中被植入了后门代码，可能会将 Xshell 等客户端中保存的服务器密码回传给攻击者，进而进一步控制大量服务器。

  

![](../Images/f203ef0dd2b52d08524ae69c3b1aa9d4.png)**影响版本**

  

已确认以下版本的 Xshell, Xmanager 等产品中包含后门，请使用了受影响版本的用户尽快通过官方渠道升级。

  

• Xshell Build 5.0.1322 

• Xshell Build 5.0.1325 

• Xmanager Enterprise 5.0 Build 1232 

• Xmanager 5.0 Build 1045 

• Xftp 5.0 Build 1218 

• Xftp 5.0 Build 1221 

• Xlpd 5.0 Build 1220

  

![](../Images/dd22b66b89774af4eac5ff6235730ec5.png)

  

![](../Images/855fae7abb43c311be0abeb2f7d8e6fc.png)**修复方案**

  

!! 在以上版本中远程登录过的服务器，请及时修改相关 SSH 等服务的密码。   

  

通过官方网站更新 Xshell, Xmanager, Xftp, Xlpd 等软件 https://download.netsarang.com/ https://download.netsarang.co.kr/

更新到以下版本：

  

• Xmanager Enterprise Build 1236 

• Xmanager Build 1049 

• Xshell Build 1326 

• Xftp Build 1222 

• Xlpd Build 1224

  

需要注意的是，国内大量下载站提供的安装包仍然是未更新、存在后门的版本，请通过官方版本升级，或暂时使用其他远程管理软件。
