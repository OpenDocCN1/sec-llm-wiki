# 安全工作的新定位：业务的合作伙伴

对企业来说，网络信息安全究竟有没有价值，每年为此支付的大量人力财力是否值得？  

这个问题，答案似乎越来越明确。5.12肆虐全球的蠕虫病毒利用Windows漏洞形成的威力，让全世界人民都见识到了互联网安全的重要性。

**安全本是一笔债，不自己用掉，就被黑客花掉**。据美国知名网络经济研究机构Cybersecurity Ventures预测，未来5年全球网络安全消费累计将超1万亿美元，与之形成对比的是，到2021年全球网络犯罪造成的经济损失预计将达6万亿美元。

  

网络安全价值的难以形容之处在于，安全价值很大程度上体现在**止损**方面。如果损失没有发生，那么看起来安全部门就没有多大的存在必要，然而网络攻击事件一旦造成不良后果，又意味着安全工作无效。这样一来，企业既难以直观地观察到安全部门的价值，又很难将安全工作转化为实际可对应的收益，长此以往，安全部门没有话语权的痛点就不难理解了。 

![](../Images/a50939bc9819f1e59cfd1ef3eb678ed9.png)

  

当前许多公司的安全部门都挂在运维或其他部门下，从IT部门独立出来似乎只是一个遥远的梦想。而IT部门的现状是离业务远，离领导更远。**企业安全如何赢得话语权？**

  

此外，信息安全的建设与完善主要还是依靠攻击**事件驱动**的，但是反观国内现状，又有多少事件能够真实披露呢，当事件驱动也难以实现时，信息安全如何进步？难道只能走法律途径，靠颁布网络安全法来推动了吗？

  

想要澄清信息安全的价值，就需要从“**安全=止损**”的传统安全价值观，扭转为“**安全=利润**”的全新安全价值观，让安全主动成为业务的合作伙伴，进而成为企业价值创造的关键。

  

  

1安全工作价值几何

  

IT成本高是公认的事实，想要摘掉成本部门的帽子，就需要随着企业发展和外部环境的改变，重新思考部门定位，从企业信息化初期的系统建设者和支撑者，转变为业务产品运营更新的参与者，参与到企业业务发展中，并在价值创造中成为关键。想要为安全工作重新定位，首先要审视**安全到底能为业务做什么**。

  

从花钱到省钱，止损就是创收

  

       由于安全和业务贴合得更加紧密，能够止损就是创收的价值体现在**互联网金融行业**尤为明显。

    据不完全统计，小型银行每个账户IT成本100元，大型银行每个账户的IT成本20-30元，而如果采用海量服务分布式架构等优化技术，最终成本将下降80%。

    此外，在用户使用业务的过程中，每多设置一个步骤，就会造成一定比例的用户流失。通过网络技术的更新迭代，以前需要通过验证码的交易，现在通过人脸核身就可以，既提升了客户体验减少了客户流失，又节省了企业成本，如验证码费用大幅度降低。

       在互联网金融行业中，安全部门通过对各种已发生的安全事件所造成的损失出发建成风险库和模型，进而反驱动业务规则的优化，达到保护业务数据、识别欺诈行为、降低交易损失率的目的，主动提升业务的核心竞争力。

  

       主动有效的安全工作能够通过对业务能力的提升，**降低业务的潜在损失风险**，从而为企业省钱。

  

从保障到伙伴，在竞争中抢占先机

  

当安全部门完成从业务保障到业务伙伴的角色转变之后，就会随之从成本部门转型为**利润中心**，并在企业内部输出能力。如建立信息情报系统，完善业务方面的威胁情报分析，包括竞争对手行情、竞争产品情况、竞争项目布局等，让风控部门和业务部门成为安全部门的内部消费者，帮助企业业务在市场竞争中占得先机。

  

化繁为简，体验与效率同时提升

  

通过安全风险控制，对内外松绑，在提升工作效率与服务效率的同时，提升员工工作体验与用户使用体验。

  

通过安全系统的建设和完善，不但可以帮助员工自由登陆外网，还可以将八位密码缩短为六位，再加上智能预警感知威胁等系统，能够在很大程度上提升员工工作效率。通过人脸核身省去验证码核实环节，使用同人模型降低安全交互认证复杂度，可以对外改善用户体验，简洁流程提高效率。传统的金融业务流程中，所有服务均需要线下核实用户的生物特征，这不但是传统金融业务效率的最大卡点，同时也是制约其互联网化的关键节点。而使用在线人脸核身技术可以大幅减少银行的人力投入，也可以实现远程开户、大额转账等业务，提高用户的便利性。

2安全工作如何与业务手拉手

  

《人民的名义》里最多的一句台词就是“摆正自己的位置”，安全部门也应该先做好定位，根据公司类型、老板期望等来感知部门位置。向上做战略契合，向下先定位，首先确认安全在单位的性质和功能，是 **治理->安全 **还是 **治理->业务->IT->安全 **，然后再谈规划，确定目标，再做架构。

       在实际操作中，企业安全部门通常会根据在组织中的地位高低、预算丰富程度以及直线老板权力大小先定一个安全建设的**范畴基调**，然后各个击破主要矛盾，最终走向**系统化建设**。

  

根据时间长短，企业的安全工作有着不同的导向与目标。

  

短期：以问题为导向，旨在补漏救火，快速止血。

中期：以风险为导向，旨在完善机制体系建设，解决实际问题。

长期：以业务为导向，通过赚钱或省钱的方式，从战略层面影响公司发展。

  

总结：应急响应 -> 体系建设 -> 核心竞争力提升

  

  

安全规划应当与业务规划紧密联系。负责安全工作的领导层级越高，越应该从业务的角度考虑问题，并加强与领导和业务部门的沟通。要做好安全战略规划，就要**跳出安全的视角，明确企业战略，接触业务信息**，至少要站在CIO的视野上。

  

       相较于发达国家(9%)，中国安全在IT投入中占比仅在1%-2%，显然不足。故安全规划的意义，一方面是为安全工作指明方向，另一个方面是找老板落实预算、人力需求。

  

       因此需要从风评开始，进行风险刻画，总结公司当前的安全风险状况，总结当前痛点，推导出解决这些痛点需要做的事情，进而得出所需资源，并在说服组织投资的过程中以业务和风险为导向，具体：

  

1.  做安全，**借势**很重要。以《网络安全法》、网信办的相关制度为推手，重点解读国家对企业的要求、企业的责任、领导的罚款等。
    
2.  分析利弊，明确责任。说清利害关系，避免造成推卸责任、不愿干活的印象。
    
3.  **拿捏尺度**。可以制造事件应急模拟，也可以拿监管说事，但要注意尺度，评估公司资源配置情况，避免引起反感。
    
4.  考虑**对外输出**，包括安全技术输出和安全管理咨询输出等。安全商业化，是最好的输出成果。
    

  

借用华为的Global思路——**看同行，看业界，看友商，看自己**，然后提出问题，解决办法，要钱要粮，安全规划也如是。

3安全工作如何量化

  

安全价值难以表达的痛点在于：业务部门的收益是实打实的，而安全部门除非变成直接利润部门，否则在公司整体技术部门都不好将技术工作转化为收益对比的情况下，很难把安全工作转化为实际可对应的收益。由于信息技术带来的收益和风险的计量缺乏方法，所以尽管近二十年信息技术在银行业带来的影响是无法估量的，但IT还是被看作是成本部门。

  

基于此，有**四项指标（****ROI****，****TCO****，EVA和ALE）**可以帮助进行安全工作的价值传达。

  

1

ROI (投资回报率)

  

ROI是指**通过投资而应返回的****账面利润（净利润）**，从回报出发来衡量投资是否值得。但是如果应用ROI来量化安全支出，就会面临一个问题：如果投资安全措施就不会发生什么问题，但是如果本来就什么问题都不会发生呢？正如安全咨询公司Alliance Group Research的首席执行官罗斯·利奥（Ross Leo）所说的那样，“试图计算安全工具的投资回报率（的麻烦在于），仅仅是他们的工作就摧毁了自身工作效用的证明。”

  

因此，投资回报率已经变成了一种**宽松的衡量标准**，用于衡量收回安全投资成本的时间，且往往应用于事件后，因为此时成本趋于清晰。ROI不是一个完美的衡量标准，其本身也可能导致公司选择错误的技术来节省资金，这也许就是为什么它的使用率正在下降。

  

2

TCO (总拥有成本)

  

价值传达的另一种选择是计算安全投资的**总拥有成本（TCO）**，它能够帮助公司认识到他们正花费什么以及为了什么。这项措施的本质在于**注重成本**而非潜在回报，这与安全支出非常吻合。在实际工作中，可以通过对比新旧设备的使用与运营成本来决定是否投资。

  

但TCO的计算也存在着困难，尽管购买成本和正在进行的合同成本是明确的，但计算不那么明显的支出就很难了，如系统管理员的管理时间花费，因此TCO很难精确计算。不过虽然不精确，但如果能让管理层了解到安全问题会给公司造成的负担以及解决这个问题所带来的花费，已经足以让公司做出一个很好的决定了。

3

EVA（经济增加值）

  

EVA提供了衡量业务部门财务业绩的方法。通常在IT领域应用于检验一家公司在安全投资后是否获得了**预期的财务回报**。如进行防火墙购买这类实际没有产生价值的投资时，使用EVA有助于确定安全支出是否避免了诸如安全漏洞之类的问题，从而判断这项投资是否增加了公司的价值。

  

与TCO和ROI相比，虽然EVA也可以被捏造，但难度很高，它能够用较为**客观的数据**显示出企业不使用安全服务会招致什么成本后果，从而体现出安全支出的价值感。

  

4

ALE (年化损失预期)

  

ALE是衡量安全支出可能产生的影响的一种方法，计算年化损失预期可以帮助企业设定安全支出的**优先事项**。作为一种预测，其在诸如攻击和硬件盗窃方面的预测率是合理的，ALE着眼于一年的实际成本和建立损失预期的机会成本，然后用这笔潜在损失的成本来说明 “如果我要把这个保护到位，我愿意花多少钱来试图阻止损失发生或降低我的发生率？”，ALE主要解决的是“风险将会使我们损失多少，以及我们将要花费多少来解决它”的问题。

![](../Images/6ec103ab289094d36ebe76fd40326a78.png)

如果安全部门把信息安全风险进行计量后分别纳入声誉风险、法律和监管风险以及操作风险，再纳入非预期风险，按行业通行规定对预期风险进行资金拨备，对非预期风险以资本覆盖，并最终通过资金的使用情况来展示安全成效，便可以把安全工作转化为实际可对应的收益，帮助管理层与其他部门对安全工作的价值理解。

 

     

       破解缺乏话语权的困局，需要企业安全部门随着企业的发展和外部环境的变化及时调整自身定位，而与业务部门关系的转化结合，则是安全工作价值被认可的契机。

       安全部门与业务部门把后背留给对方，并肩作战，也将为企业描绘更加美好的蓝图。
