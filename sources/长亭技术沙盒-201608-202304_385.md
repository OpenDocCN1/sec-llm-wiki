# 长亭预警 | Linux内核提权漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwMDk1MjMyMg==&mid=2247483682&idx=1&sn=2f7015754af647fe1ab85a8447c83ac2&chksm=96f41e4fa1839759ea9ca4e16b30bf423682b85b2903da1582e7c305e0db4f87eedfb1830ec3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIwMDk1MjMyMg==&mid=2247483682&idx=1&sn=2f7015754af647fe1ab85a8447c83ac2&chksm=96f41e4fa1839759ea9ca4e16b30bf423682b85b2903da1582e7c305e0db4f87eedfb1830ec3&scene=27#wechat_redirect)

3 月 9 日上午，Seclist 上披露了一个 Linux Kernel 的提权漏洞，普通用户可以利用该漏洞获得特权用户的权限。

**CVE 编号为：CVE-2017-2636。**

  

**漏洞危害**

 

漏洞存在于 n\_hdlc 模块中，当发生 race condition 时会导致 double free，攻击者可利用该漏洞将普通用户权限提升至特权用户，即通过执行任意代码获取 root 权限。

  

**影响范围**

 

该漏洞影响所有 Linux Kernel >= 2.6.31 的版本。

2.6.31 是 2009 年发布的版本，也就是说这个漏洞几乎影响 2009年 以后的所有版本。

  

**漏洞临时修复（缓解）方案**

 

管理员首先需要执行 lsmod 命令来确认当前是否已加载 n\_hdlc 模块。  
如已加载需要及时执行 rmmod 命令来卸载该模块。  
如未加载则可以通过阻止 n\_hdlc 模块的自动加载来避免遭受该漏洞的影响。  
管理员可以通过修改 /etc/modprobe.d/ 来限制模块的加载。

  

**彻底修复方案**

 

各发行版等待上游更新修复后（有些已经更新）将内核更新至最新版本（有条件的可自己打补丁重新编译内核）。
