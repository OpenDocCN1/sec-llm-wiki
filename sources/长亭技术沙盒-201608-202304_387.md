Xen是一个开放源代码虚拟机监视器，由剑桥大学开发。它打算在单个计算机上运行多达128个有完全功能的操作系统。  

在旧（无虚拟硬件）的处理器上执行Xen，操作系统必须进行显式地修改（“移植”）以在Xen上运行（但是提供对用户应用的兼容性）。这使得Xen无需特殊硬件支持，就能达到高性能的虚拟化。

——来自维基百科

  

因为其优越的性能和开源性，Xen被认为是最有前途的虚拟化解决方案之一，也被广泛应用在云平台。例如亚马逊、Linode、Rackspace等。

  

  

9月8号，XEN 连续发布了四个补丁，相关漏洞可能引起任意代码执行、拒绝服务，各位使用到 XEN 的管理员们，请检查自己 XEN 的版本号，使用了响应版本的需要及时 patch。

  

**漏洞相关信息:**

**CVE ID:**

*   CVE-2016-7092
    
*   CVE-2016-7093 
    
*   CVE-2016-7094
    
*   CVE-2016-7154
    

**厂商: ** https://www.xenproject.org

**披露时间:** 2016-09-08

**影响版本:**

*   CVE-2016-7092 => 4.3 and earlier 64-bit hypervisor
    
*   CVE-2016-7093 => 4.7.0 and later && 4.6.3,4.5.3 (仅影响x86架构)
    
*   CVE-2016-7154 => 4.4
    
*   CVE-2016-7094 => All versions(仅影响x86架构)
    

  

**漏洞影响：**

**CVE-2016-7092**

使用PV模式的恶意用户可能发起特权提升攻击。

**CVE-2016-7093**

使用HVM模式的恶意用户可能发起特权提升攻击。

**CVE-2016-7094**

使用HVM模式的恶意用户可造成 XEN 的错误检查失效，导致主机拒绝服务

**CVE-2016-7154**

恶意用户可使宿主机拒绝服务，且有任意代码执行和敏感信息泄露的可能性

  

**修复方案：**

官方已发布补丁，请及时及时升级
