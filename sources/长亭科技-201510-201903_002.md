**产品运营**

Base:北京

**岗位职责：**

1\. **挖掘产品价值**，结合市场趋势和客户需求，生产、包装内容，向潜在客户传递；

2\. **负责产品推广活动的策划、推广、执行**，完成活动预期目标；

3\. 与销售团队配合，提升用户对产品的理解与应用，提供销售环节所需的产品材料；

4\. 分析行业市场格局，跟踪市场动态，协助完成行业调研工作。

  

**任职要求：**

1\. 熟悉科技行业，两年以上工作经验，对产品或市场有浓厚的兴趣；

2\. 具备主动学习能力和较强的理解能力，文字表达能力较好，能输出自我观点；

3\. 有责任心，具备良好的沟通、理解及表达能力，良好的团队协作精神；

4\. 熟悉PowerPoint、Excel、Office等办公软件操作；

5\. 有产品运营经验或信息安全行业背景者优先考虑。

**市场实习生**

Base:北京

  

1\. 希望你**思维活跃**，有独到见解，能为市场活动出谋划策；

2\. 希望你**善于沟通**，能协助组织和实施市场推广、宣传等活动；

3\. 希望你是**文案小能手**，能独立撰写材料；

4\. 希望你**踏实肯干、执行力强**，能辅助市场部门其他工作。

  

**任职要求：**

1\. 熟悉各类办公软件，能熟练使用Office、Excel、PPT等；

2\. 了解互联网中正在发生的趣事，善于发现新事物，乐于分享；

3\. 较强的理解、沟通及协调能力，态度积极，良好的团队协作精神。

**网络安全培训讲师**

Base:北京

**岗位职责：**

1\. **负责企业端网络安全相关课程工作**，包括但不限于制定授课大纲、编写教材、授课实施等；

2\. 负责参与公司内部人才培养及课程开发、培训实施等；

3\. 负责参与公司安全课程培训体系的搭建、迭代优化等；

  

**任职要求：**

1\. 本科及以上学历，3-5 年企业端培训经验，能够接受出差；

2\. 具备扎实的安全技术基础，精通 Web 安全、移动安全、逆向工程、安全开发等一个及以上方向的安全技术；

3\. 具备优秀的沟通能力和学习能力，有较强的责任心，并乐于进行分享、传授知识；

4\. 获得安全领域相关认证者优先，如 CISP、CISSP 等。 

**安全服务项目经理**

Base:北京

**岗位职责：**

1\. 负责与客户沟通并确认安全服务需求**（能够解决客户提出的安全技术相关问题）**；

2\. 负责客户**安全服务类需求方案输出**；

3\. 负责安全服务项目实施过程中的项目管理，解决项目中出现的技术和管理问题，保证项目的正常进行及交付。

  

**岗位要求：**

1\. 计算机及相关专业本科以上学历，2年以上安全相关工作经验；

2\. 具备较好的解决方案技术能力和沟通能力；

3\. 具有信息安全服务项目管理经验，能够独立承担安全服务项目经理的工作；

4\. 在各大src、漏洞盒子等平台排名靠前者优先。

**前端开发工程师**

Base：北京

  

**岗位职责：研发 & 维护公司对外产品**

  

**任职要求：**

1\. 熟悉 HTML / CSS / JavaScript，熟悉 ES2015+，熟悉 TypeScript；

2\. 有 SPA 开发经验, 掌握流行的框架(Vue/React/Angular 3选2)；

3\. 了解现代构建工具, 手动配置过 Webpack；

4\. 熟练使用 Git 等版本控制工具, 有使用 \*nix 系统的经验；

5\. 能够与设计师协作，会简单使用一些设计与产品工具。

  

**加分项：**

1\. 了解后端开发, 有 Python/Node/Go/C/C++ 等经验；

2\. 了解 Elm/Rust/Haskell 等语言；

3\. 有 OI / ACM / TopCoder / GCJ / Codeforces 等算法竞赛获奖经历；

4\. 深度参与/主导过开源项目；

5\. 有良好的英文阅读能力, 能够无障碍读写英文文档。

**后端开发工程师**

Base：北京

  

**岗位职责：负责公司 Web 相关产品与内部服务的后端开发工作，主要开发语言为 Python**

  

**任职要求：**

1、熟悉 Python / Go / Java 中至少一门编程语言；

2、有一定的 Web 后端开发经验，熟悉前后端分离的开发模式；

3、熟悉关系型数据库的使用与基本设计优化方法，了解常见的 NoSQL 数据库如MongoDB, Redis等；

4、良好的编码风格及测试习惯。

  

**加分项：**

1、有前端开发的经验；

2、个人在Github上有活跃的开源项目；

3、有DevOps实践经验。

**销售经理（金融行业）**

Base：北京、深圳

  

**岗位职责：**

1.负责公司全线产品在**金融行业客户**的销售工作开展，完成公司下达的任务指标；  
2.树立公司产品在该行业的品牌和产品优势地位负责公司产品的销售及推广；  
3.开拓新市场，发展新客户，增加产品销售范围；  
4.负责辖行业市场信息的收集及竞争对手的分析；  
5.负责标杆客户的关系拓展和维护，分析客户需求，寻找项目机会。

  

**任职要求：**

1.本科以上学历，信息安全，计算机或相关专业优先；  
2.三年以上销售工作经验，有良好的销售业绩；  
3.形象良好，语言表达和思维逻辑清晰、性格乐观、能承受压力；  
**4.有金融企业客户行业背景优先考虑；**  
5.熟悉信息安全行业、了解信息安全技术者优先考虑；  
6.熟知相关区域渠道市场现状，有良好渠道合作关系者优先考虑。
