2018年11月27日，Gartner发布WAF领域又一重量级报告：Asia/Pacific Context: ‘Magic Quadrant for Web Application Firewalls’，精选亚太区表现亮眼的十余家国际顶尖WAF厂商。**长亭科技雷池（SafeLine）因技术创新及客户调研中的良好口碑入选该报告，也是所有入围厂商中成立时间最短且唯一使用智能语义分析技术的选手，在大型金融机构的高能见度被认可。**

“Beijing Chaitin Technology is a Chinese vendor based in Beijing, China. Its portfolio includes web application security solutions centered on SafeLine, its WAF appliance. The vendor’s WAF core technology relies on a semantic and learning engine, combined with bot mitigation and API security modules.

  

Beijing Chaitin Technology owns support centers in China. Support is available in Cantonese, Mandarin and English.

  

The vendor has started its international expansion in the region, but remains mostly visible in China, especially with large financial institutions.”

WAF不是一款容易做好的产品。基于当前的网络安全环境，它需要具备“敏感”、精准、智能等基本要素；其部署位置的关键性，也决定了对企业机构的业务将产生直接影响，与此同时，它也是应用层安全的第一道防线。**雷池（SafeLine）作为一款上市2年多的产品，获得了Gartner的多次认可，自2017年起两次提名全球WAF魔力象限，并入选亚太区WAF魔力象限报告，离不开研发团队日夜心血和众多以金融和互联网为核心的企业用户的认可。**

同时，反观全球WAF大格局，2018年是Gartner刚刚说出WAF连续4年无技术创新后的变化年，从核心检测引擎的技术思路，到产品平台化（WAAP概念的提出），到云WAF解决方案的兴起，到全球解决方案的需求升级……年末，我们一起花点时间了解下变化中的WAF市场。

![](../Images/4ff56ff3d834c4aa68c1179109d034e4.png)

//WAF的变局//

市面上对WAF进行定义和评价的咨询机构有很多家，权威的也不少，本文从Gartner引入，核心也将从这个角度来展开。

Gartner对WAF的定义主要从三个方面来框定：

**防护范围**

·  保护公共和内部的web applications

·  保护应用和API，抵御多样的攻击

·  包括自动攻击（Bots），注入类攻击和应用层的DoS

  

**防护手段**

·  需要提供规则为基础的保护，也需要支持积极的安全模型（Positive security models）和一些不规则的异常检测

  

**部署方法**

·  部署在服务器前面

·  有硬件和虚拟交付，云端解决方案

·  反向代理是最常见的部署方式：为了更深的监测，大多使用反代部署；云的兴起，需要更多部署方式监控流量层安全，进一步加强反代使用

1**2018年，大厂进入赛道的一年** 

![](../Images/2c8969badb4c4e7a600cd7dfc295e536.png)

**今年的全球版WAF魔力象限名单中存在一些并非传统意义上“理所当然”的WAF厂商，比如Microsoft，比如Oracle。**前者想当然因为Azure云的安全需求衍生的产品，名字就是Azure WAF，使用的是基于开源引擎ModSecurity engine和二次开发的形式进入WAF市场，现阶段WAF的研发团队还很小，用API管理WAF的配置。后者使用的是“购买”的方式进入WAF市场，Oracle收购了Zenedge，一家使用机器学习进行风险评级为特征的WAF厂商，这场收购导入Oracle的流量，帮助训练机器学习算法，提升检测准确率。管中窥豹，多元的玩家进入市场，变化似乎是不可避免的了。

2**2018年，全球化和本地化差异明显**

![](../Images/ad0ad808e844751ebcd9fc5d47312940.png)

**今年的全球版WAF魔力象限，中国厂商全部掉落，Gartner确信全球语境中应该推荐更具备全球化解决方案能力的厂商。**这也的确显示出亚太市场，尤其中国市场，和全球市场在Web应用安全产品需求中存在的割裂，也正是亚太语境的魔力象限报告出现的意义。Globalization的相生词必定是Localization，WAF产品这一特殊性是一个值得研究的、有意思的现象。

3**WAAP概念提出，平台化趋势WAF解决方案**

·  Gartner的WAF领域主笔分析师Jeremy于今年年中提出一个新的概念**WAAP（Web application and API protection），集合WAF、抗D、抗Bot和API安全于一体的平台型解决方案，其被定义为一种提升安全情景的解决方案。**

安全的质量标准在变化，融合的企业生态很匮乏，报告中提到了几组数据或许可以提供参考。

·  84%的受访企业表示，目前使用WAF作为安全防护的方法

·  73%的用户认为，WAF是他们Top3最有效的防护

·  中等规模的企业，需要超简易部署和不用操心，云WAF能解决

·  2018年是WAF的反转之年，云WAF正式占据30%的整体市场，并稳稳增长

·  73%的应用和技术架构软件已经都花在云服务上

·  Cloud-native 应用安全解决思路大门打开

·  已经使用云服务的机构中，43%已经在使用云安全服务

用户已经开始转向更多元、多维度的丰富技术使用场景，而在近两年的WAF魔力象限调研的过程中，依然不可避免的发现：**架构基于某种技术，但操作起来都很笨重；WAF的强工作负载能力(Workload capacity) 欠缺，水平扩展操作上看起来很笨重。其中具体表现在Reporting和Monitoring dashboards这两项各家分值都很低。 **

4**雷池（SafeLine）应对变化之处**

**雷池（SafeLine）是全球首个基于智能语义分析算法的WAF产品，从计算机语言的角度进行攻击检测，区别于传统的基于特征库和黑白名单机制的拦截原理。**如果语言角度解决应用层攻击检测在2016年雷池（SafeLine）发布之初尚属“异类”的话，如今似乎已经被更广泛的接受和应用。从数次进入WAF魔力象限后被收购的法国安全公司DenyAll，到近两年异军突起的美国安全厂商Signal Sciences，无不是这一方法的践行者。**雷池（SafeLine）与其不同之处在于，不仅止步于词法、语法的语言维度，而更深入的完成了语义分析和威胁建模的过程，从而使检测的精准度和智能防护水平提升。**

**面对云端变化，雷池（SafeLine）云端解决方案无论应对私有云、公有云、混合云都有灵活应变的部署防护模式，帮助用户灵活配置网络环境。**目前云解决方案已服务于滴滴、拼多多、OPPO、VIVO、大型商业银行等众多企业用户。

紧随用户需求变化，快速实现迭代更新，是雷池（SafeLine）作为一款年轻产品，能不断超出客户预期，不断获得国际大型咨询机构认可的核心因素。未来，无论网络环境和攻击趋势如何变化，雷池（SafeLine）将以初心不变应万变。
