2\. 有 SPA 开发经验, 掌握流行的框架(Vue / React / Angular 3选2)

4\. 熟练使用 Git 等版本控制工具, 有使用 \*nix 系统的经验；

**后端开发工程师**

你要做的事情：

负责公司 Web 相关产品与内部服务的后端开发工作，主要开发语言为 Python。

1\. 熟悉 Python / Go / Java 中至少一门编程语言；

2\. 有一定的 Web 后端开发经验，熟悉前后端分离的开发模式；

3\. 熟悉关系型数据库的使用与基本设计优化方法，了解常见的 NoSQL 数据库如MongoDB, Redis等；

4\. 有良好的编码风格及测试习惯。

**如果你还有前端开发的经验；个人在Github上有活跃的开源项目；有DevOps实践经验，要的就是你～**

**品牌经理**

你要做的事情：

1\. 根据企业的发展战略以及市场调研情况进行企业品牌定位;

2\. 对企业资源进行规划，制定企业品牌规划方案;

3\. 负责企业品牌管理工作，对包括VIS在内的企业品牌使用进行规范;

4\. 制定企业品牌推广宣传方案，并负责组织人员进行媒体、公关以及其他推广宣传活动；负责媒体专访、相关软文写作、宣传片拍摄等，负责企业公众号运营；

5\. 协助市场其他部门制定企业新产品的开发、推广方案;

希望你具有市场营销、管理类、广告类或相关专业本科及以上学历，5年以上品牌策划及管理相关经验；文字功底扎实，有较强的策划、编辑、撰写能力;  具有独立承担品牌营销活动策划与项目管理能力； 具备敏锐的市场洞察力以及分析能力，熟悉产品价值提炼及竞争优势; 具备良好的沟通协调能力。**拥有智能科技行业、网络安全工作经验或4A公关公司背景的小伙伴加分哦。**

**法务经理**

你要做的事情：

1\. 起草、审核及修改公司各类法律文件，包括合同、规则制度等，确保达到公司利益最大化和风险最小化；

2\. 参与公司业务谈判及经营决策的法律论证，为公司提供法律合规保障；

3\. 协助公司进行知识产权维护及日常管理；

4\. 负责公司日常法律支持、咨询、宣传和法律培训等工作；

5\. 协助公司与政府部门沟通协调有关法律事务；

6\. 代表公司参与或协调外聘律师参与法律事务的协商、调解、诉讼与仲裁等活动。

希望你具有大学本科及以上学历；有5年以上的相关工作经验；能够协助公司领导正确执行国家法律法规，对公司的经营决策进行法律论证，出具法律意见；能够完成公司的合同管理（劳动合同除外），包括但不限于合同的谈判、拟定、审核、归档；具有良好、准确、有逻辑性的口头和书面沟通能力； 具备优秀的逻辑思维和抗压能力，具备良好的法律思维习惯；具备优秀的谈判和诉讼能力；同时也要精通公司法、合同法、劳动法、知识产权法等国家法律。
