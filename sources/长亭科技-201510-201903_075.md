**雷池（SafeLine）升级**

**适配多行业多场景需求**

雷池（SafeLine）在智能语义分析的基础上，又实现了新升级：**高度自定义和轻量级集群**。

**高度自定义体现在两方面：**

**1\. 对外开放所有的 API 接口，**可以和SoC、SIEM等等其他系统进行集成，使多个产品方便地进行联动；

  

**2\. 增加可编程扩展模块，**有研发能力的企业可以把WAF作为平台，通过编写自定义插件来实现自身业务逻辑的完善，最大程度让WAF与企业业务安全形成正向合力。

  

**轻量集群的重点：**

**1\. 完全不修改原有的网络拓扑，**或只需要修改一小部分网络拓扑，做到不影响业务的情况下实现部署和工作。

 

**2\. 可以应对大型网络、处理超大规模数据流量，**对国内蓬勃发展的互联网公司而言意义重大。

**谛听（D-Sensor）****稳定及可扩展性提升**

谛听（D-Sensor）作为一款欺骗伪装类产品，**升级后可以兼容更多的蜜罐类型，**并且根据感知到的威胁事件对攻击者进行建模，**深度还原黑客的攻击步骤，**此外，**在平台稳定性和可扩展性方面业已全面提升。**

在历经数月的新品调研过程中，长亭研发团队发现**漏洞扫描工具这款常见产品，却存在跟不上企业客户需求的问题，**成为客户频繁抱怨的焦点**。**常年征战顶级黑客赛事的长亭科技技术团队，在过去几年已服务国内数百家企业，对攻防双方的思路和需求都有着深刻的理解。

  

![](../Images/d3929221759caf4f2ea98d4d9da877e8.png)

洞鉴（X-Ray）即使针对一个简单的SQL注入漏洞，在扫描结果中除了明确显示该漏洞影响、危害、修复进度之外，还进一步从技术人员视角呈现该漏洞的技术细节及利用方式，让管理者能有效验证。

**牧云（ CloudWalker ）服务器安全平台**

私有云、公有云跨距叠加，日益增长的“多云”企业意味着更多的服务器工作负载建立在混合云数据中心的基础上。  

  

**云环境日渐复杂，**当企业实施了混合云数据中心，多层架构的工作负载环境让持续联动的安全更加困难，并**不可避免的走向难以管理，**这是牧云（ CloudWalker ）服务器安全平台所要解决的问题**。**

![](../Images/d3929221759caf4f2ea98d4d9da877e8.png)

云时代，安全如何不失控？

牧云（CloudWalker）提供给用户一个从服务器内部观察网络环境的安全视角，是典型的基于Agent的深度服务器工作负载安全平台，集资产管理、风险排查、入侵监控三大核心功能于一体，进行千万级资产管理的同时能有效防御入侵。

  

值得一提的是，**牧云（ CloudWalker ）延续了长亭研发创新算法解决安全问题的传统，将常见的、复杂的安全问题变得更简单智能。**

![](../Images/199fe298b33f938d9d1083c3c60018ca.png)

比如，在WebShell检测功能中，传统方法多采用规则特征匹配，但这种方式更适合一些初级的、规律性强的WebShell检测，如下图所示：

![](../Images/e0b2fb5242105a6b9575dcab7718b009.png)

然而，当前的攻击者们早已掌握了多项技能将WebShell高度变形、混淆导致难以辨别，如下图所示：

![](../Images/8f69bf2cf11d946ecd3ed2dafea0b6e3.png)

上图中的最后一个WebShell几乎已经到了乱码的程度，**传统的规则匹配很难检测这类的问题，然而这些都是牧云（ CloudWalker ）支持的检测项。**
