# 长亭科技参加第三届“香港—内地网络安全论坛”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651371543&idx=3&sn=10c1b3baff7f18e73395568aecf02d68&chksm=8d39c99fba4e4089484677c6e2f76a5fa480d30f4910576ffd10510b49c33ef503fdcffdc786&scene=126&sessionid=1681376274#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651371543&idx=3&sn=10c1b3baff7f18e73395568aecf02d68&chksm=8d39c99fba4e4089484677c6e2f76a5fa480d30f4910576ffd10510b49c33ef503fdcffdc786&scene=126&sessionid=1681376274#rd)

**4月11日，第三届“香港—内地网络安全论坛”在香港举行。**该会议由政府资讯科技总监办公室（以下简称“资科办”）与国家互联网信息办公室安全协调局合办。长亭科技有幸出席了这次会议，与众多来自香港和内地的资讯、通讯科技企业高管以及专家学者齐聚一堂，共同探讨网络安全技术和产业的发展。

  

![](../Images/36cad002520c2798e2f728be033ac03a.png)

  

**本次论坛的主题为“安全的智慧互联——挑战与机遇”。**大数据、人工智能等技术的发展与应用既给我们的生活带来便利，同时也潜藏着巨大的安全隐患。家居、支付系统、交通及医疗系统等共同组成了城市的智慧生活，可一旦这些网络基础设施遭到黑客攻击，后果也将不堪设想。

 

论坛期间，资科办介绍了正在开展的“网络安全资讯共享伙伴试验计划”，以促进公私营机构共享网络安全资讯，以提高香港整体应对网络攻击的防卫及复原能力。同时，论坛还设有四个专题演讲，由不同范畴的网络安全专家就智慧互联所带来的挑战提出建议，包括包围基础设施及大数据安全的措施和策略。  
  

**未来，长亭科技将持续进行前沿技术研究，探索城市智慧生活的系统安全保障，以高质量的产品与服务为内地乃至香港企业的网络安全保驾护航。**

国际顶尖的网络信息安全公司，全球首发基于人工智能语义分析的下一代Web应用防火墙产品，专注解决互联网安全问题，致力提高国内安全水平，接轨国际最高标准，为企业级客户带来智能的全新安全防护思路。

  

被《财富》评选为中国创新企业“人工智能和机器人”领域的全国第一，已服务包括中国银行、交通银行、安信证券、中国平安、爱奇艺、Bilibili、华为等系列知名客户。
