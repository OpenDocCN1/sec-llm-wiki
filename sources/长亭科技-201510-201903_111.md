# 北京站完美收官，长亭科技系列线下沙龙邀您“下江南”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651371531&idx=3&sn=0f3241f09235f3d5d95adc87279a2c53&chksm=8d39c983ba4e409583727245097290ba23735ddefdad97e7af65b42c2ec4140768d3ec5709ff&scene=126&sessionid=1681376279#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651371531&idx=3&sn=0f3241f09235f3d5d95adc87279a2c53&chksm=8d39c983ba4e409583727245097290ba23735ddefdad97e7af65b42c2ec4140768d3ec5709ff&scene=126&sessionid=1681376279#rd)

烟花三月，长亭科技2018年度系列线下沙龙北京站完美收官，来自企业安全建设一线管理者、学术界和监管机构的业内大咖莅临现场，带来了精彩纷呈的内容分享。众多互联网金融行业的安全从业人员和技术爱好者共聚一堂，共同探讨新技术背景下企业安全建设的创新思路。

  

![](../Images/d94e83f9f38c074827d73db94953f7a9.png)

  

开场，来自清华大学网络科学与网络空间研究院、网络空间安全实验室主任段海新教授带来了耳目一新的最新研究成果，**从在线推广技术检测角度深度剖析网络黑产的完整产业链**。段教授介绍了多种地下产业的在线推广技术，并介绍自动大规模检测这些黑产推广基础设施、自动提取黑话等方法，帮助参会人员**从攻击者角度拓展前沿技术的视野。**

  

![](../Images/a65cdf9b9a9c7c3b9412bdc821e6acc2.png)

  

随后，国家互联网应急中心互联网金融监管技术支撑专项组组长吴震进行了题为《互联网金融安全与风险防范》的演讲，解析了新技术背景下企业安全合规的方方面面，帮助与会企业安全负责人员拨云见日，**从监管者的角度理解安全建设的全局观。**

  

![](../Images/920ad16f983e7183ae8902fd7d92eccd.png)

  

企业一线的管理者带来的分享非常别具一格。中国移动互联网金融综合服务平台玖富集团安全总监杜中伟，曾在国内外多家知名安全厂商和甲方任职，将自身十几年的企业安全从业经验化繁为简的归纳为通用规律：以王者荣耀的攻防策略形象比拟安全建设的逻辑，为大家分享了**公有云企业在主机、网络、应用安全**等方面安全建设的心得体会，**赋予了不同安全行为以策略级意义。**

  

![](../Images/95b8d5efb75dad4bc25e344a162f945b.png)

  

国内最大母婴电商平台宝宝树安全总监王利，用详实的数据从**业务风控、纵深防御、开源开发、攻防渗透和风控与边控联动经验**等方面分享了社区电商类互联网公司安全体系落地实践，演讲风格深入浅出，在后会的问卷调查中被与会人员评为**本场最受欢迎的分享内容。**

  

![](../Images/92f17d46eba0e6639c7a5798fa1e36e8.png)

  

长亭科技技术支持总监崔勤从攻防本质依旧是人与人之间的对抗的思想出发，以自身多年的攻防实战与企业安全解决方案经验，为甲方安全从业者带来了**关于新技术领域（场景）下的攻击手法本质及智能化趋势下的安全建设思路。**

  

![](../Images/8b6dd7a790f3db887382986b5d53a064.png)

  

金融平台反欺诈可以从隔壁老王的故事说起。前百度金融高级产品经理刘海敏，以个体行为为切入点，完美还原了全流程薄弱环节和技术对抗的操作，着重分析了**传统安全、风控与人工智能技术下的安全有什么异同，以及什么是非标品数据和非标品数据的价值等。**
