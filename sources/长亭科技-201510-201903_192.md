# 互联网金融应用层防护，让理财更安全

中国已经成为全球互联网金融发展速度最快的国家，仅P2P网贷行业成交量已突破5万亿，行业影响人数超过5亿。

  

根据中国互联网络信息中心（CNNIC）发布的第40次《中国互联网络发展状况统计报告》显示：

截至2017 年6 月，我国购买互联网理财产品的网民规模达到1.26 亿，较2016 年底增加用户2724 万人，**网民使用率从13.5% 升至16.8%**。

2016.12-2017.06互联网理财用户规模及使用率

  

随着移动支付成为大众习惯被民众意识广泛接受，互联网金融规模也保持着高速上涨的趋势，截至2016年，中国互联网金融总交易规模超过12万亿，接近GDP总量的20%，互联网金融用户人数超过5亿，位列世界第一。

  

根据国家互联网金融风险分析技术平台的监测数据显示，目前，我国互联网金融平台一共有1.9万多家。从业态上看，现有互联网金融业态一共有21类，包括网络借贷、互联网资产管理、网络众筹等。其中，网络借贷平台累计有6000多家，互联网资产管理将近3500家，网络众筹有800家。

  

互联网金融攻击数量

剧增

  

来自公安部、工信部下属机构的检测数据显示：**2016年监测到的针对企业的网络金融攻击事件数量已超过万起，较2014年增长了近十倍**。金融行业遭到攻击的数量明显增加，尤其是互联网金融激增所带来的经济利益，已经成为黑客眼中一块“肥肉”。据亚洲反黑客组织披露，**全球黑客攻击导致中国互联网金融行业**每年**损失超过 200 亿。**  

  

互联网金融企业一旦遭到攻击，用户的资金和数以亿计的账户信息，都有可能受到威胁，如果用户认为金融企业不再安全，对于互联网金融企业而言，将是致命的打击。国内一些线上支付平台，承诺损失多少赔付多少，即使如此，损失发生时，无论是追溯犯罪还是按承诺赔偿，对于企业而言也是一笔不小的负担。 

*   **75%的攻击集中在应用层，这个数字还在增长**
    

  

Gartner报告指出，52%的网络请求都来自Bot，75%的攻击集中在应用层。Web Attacks全球攻击周报显示，仅在2017年8月10日至8月17日这一周内，**全球发生的攻击请求数高达85,237,136 次，**来自应用层的威胁在不断增长。业务开展完全依赖网络的互联网金融企业，急需专注应用层的安全解决方案，来保障业务安全。

安全人手不足怎么破？

  

尽管互联网企业健康发展离不开平台安全成为共识，然而在当前“用户为王”的互联网思维的指引下，有限的IT人手需要投放到平台的快速迭代和APP更新中，分配到安全的精力和人手非常有限，也让犯罪攻击者有了更多的可趁之机。

  

为了更专业解决这个问题，安全产品和服务必然成为主流的选择。对于互联网金融更是如是，所有的交易都在一个无形却真实、虚拟却有效的交易场所进行。这个交易场所资源高度集中、规模庞大、与其他产业频繁交互，完全依赖于互联网。网络安全可以说直接决定了平台安全。

  

人力成本连年攀升，事多人少，如何破局？

  

三合一

快准省的攻、防、抓应用层安全

  

根据常年在攻防领域的经验，长亭科技核心提炼了三个字的Trinity原则：攻、防、抓，完整覆盖企业应用层防护的三大环节，并将国际领先技术应用于相关产品，让企业能实现以业务导向为核心的真正安全。

  

*   **攻：渗透测试，先于攻击者发现漏洞**
    

  

越不起眼的角落，越容易成为攻击者进入整个系统的入口。  

  

渗透测试是专业安全团队为企业客户提供的一项网络安全测试服务，也是做好应用层安全的第一步。安全专家模拟真实黑客，对评测目标进行深入的入侵测试。这项服务可以用来评估评测目标是否存在可以被黑客利用的漏洞，以及该漏洞引起的风险大小，让企业先于攻击者发现存在的问题。

  

*   **防：下一代WAF，先于攻击者守护**
    

  

Website是暴露在公共视野中的一个入口！

  

WAF是国际公认的外部攻击防护的有效工具，而长亭科技的雷池（SafeLine）是国内唯一一款下一代Web应用防火墙，也是全球范围内第一款基于人工智能语义分析的NGWAF（Next Generation Web Application Firewall），完全**颠覆了传统WAF基于规则维护的工作原理，却带来了更精准的拦截率和提升百倍的运行速度**，这一点也在Gartner发布的2017《Web应用防火墙魔力象限》报告中被认可。

  

核心防护功能之外，NGWAF能在1天之内完成部署，为遭受攻击的互金平台快速提供保护；无需日常人工维护，为企业节省了75%的人力成本。

  

*   **抓：欺骗伪装的内网防护，实时预警溯源**
    

  

从外网渗透到内网，当攻击越来越难以觉察时……

  

**谛听（D-Sensor），熟悉古典文学的人可能知道名字的出处，是长亭科技研发的基于欺骗伪装技术的内网威胁感知系统。**在内网节点中部署相似度极高的高交互仿真蜜罐网，以欺骗的手段应对犯罪的攻击，似乎并不为过。渗透到内网的入侵行为能够第一时间被察觉，及时预警；攻击者进入到第一个蜜罐节点，就势必会掉入下一个陷阱，为制定策略赢得时间；追根溯源，找到犯罪发生的起点。
