言归正传~近几年来，安全事件愈发频繁。从早期黑客的炫技，到企业核心资产受损，再到政治格局的改变和抗衡……黑客的犯罪攻击带来的危害也越来越大。

  

2017年7月26日-8月2日期间，全球发生Web攻击的频次：

  

![](../Images/d065021f0c91ba805e67b619e8160d1d.png)

  

每一天，全球范围内有如此多的Web攻击在发生着：

  

![](../Images/bec635a3d52ada18dbec9377a9b8ab99.png)

  

哪怕是在世界最顶尖的科技公司的产品中，仍然存在漏洞。在今年的Pwn2Own世界黑客大赛上，短短三天，包括微软、苹果、谷歌在内的世界顶级公司的系统和应用，一共被挖出52个漏洞。

  

黑客技术在持续不断的发展，网络犯罪取证难、追踪难等特征，使其在现阶段属于成本较低的犯罪行为。甚至越来越多的普通黑客都已经具备了APT、自动化僵尸攻击的能力。

  

Ponemon Institute针对全球 419 家公司的研究《2017 Cost of Data Breach Study》显示：

2017年合计数据泄露总成本达到 362 万美元。**每条包含敏感和机密信息的丢失或被盗记录的平均成本达到 141 美元，最高甚至达到每条225美元。**对比往年，今年企业和组织数据泄露的规模较以往更大，比2016年平均规模增长了 1.8％。

  

![](../Images/6faa35f71d72922ec775e52bd2da8b3e.png)

  

**这其中，近半数的数据泄露事件是由黑客攻击造成的**：

  

![](../Images/ac317dc77360032e779805d6773398ea.png)

  

  

![](../Images/3313511114d149553714ea452a11417b.png)这这这这怎么忍？

  

  

Gemalto曝出的数据显示：

2016年上半年的数据泄露总数增长了15%。在全球范围内，2016年上半年已曝光的数据泄露事件高达974起，数据泄露记录总数超过了5.54亿条之多。而另一个值得注意的消息是，**国内安全投入占IT整体投入比重仅在1%-2%之间，远低于欧美国家的8%-12%**。

  

**数据泄露事件严重的结果**是：客户信任度下降、企业需要投入大量成本进行取证调查以挽回数据、相关客户的联系及法律成本，以及企业因此蒙受的品牌价值的损失。

  

![](../Images/374cd25ef2a09d5901ae278f00eebbbb.png)

**安全资讯**

北京时间2017年4月14日晚，一个名为“Shadow Brokers”的黑客组织，将其从NSA（美国国家安全局）窃取的机密文档公布，其中包含了多个精美的 Windows 远程漏洞利用工具，可以覆盖全球超过70%的 Windows 服务器，一夜之间几乎所有Windows服务器全线暴露在危险之中，任何人都可以直接下载并远程攻击利用。

  

  

考虑到国内不少高校、政府、国企甚至还有一些互联网公司还在使用 Windows 服务器，这次事件影响力堪称网络世界核弹级的爆炸。这简直就是Shadow Brokers提供了核弹，而任何一个普通人都能成为按下发射按钮的那个人。

  

  

**矛和盾，攻防世界的变化**![](../Images/c4b48c3e18b7c939ba871a61356f74eb.png)

  

53%的受访企业网络安全预算在过去12个月内有所上浮；

69%的受访者认为需要再增加50%的预算；

87%的董事会成员和企业高管都表示对其公司层面的网络安全缺乏信心。

数据来源：2017年安永《第19届全球信息安全调查报告(GISS)》

  

61％的中国受访者所在的企业正在建设或参与数字生态系统（全球平均水平为49%），中国企业的数字化、网络化建设正在蓬勃发展。

数据来源：2017年Gartner《2017 CIO Agenda: A China Perspective》

  

![](../Images/3d3359d1ba5626c2c1442020e05fb253.png)

  

投入到安全建设中的资金将会持续增长，单纯从数据看起来，增加安全预算似乎已经是强化企业网络安全大势所趋！

  

![](../Images/76d234554d491d3b95d54bd4f5b0b4c4.png)

  

**但是** ，《2017 CIO Agenda: A China Perspective》同时指出：

中国企业的数字生态系统质量普遍较低！这可能表明，当中国企业决定建立或加入数字生态系统时，他们并不知道自己想要的到底是什么。

  

![](../Images/a7965050ab94063df0e21c88fc7fb9e2.png)

  

国内企业的数字生态系统中合作厂商比较少，平均只有7个重要的数字合作厂商，而全球平均水平可是国内水平的足足6倍之多，达到了42个。

  

一些国有企业可能仅仅只是在执行政府的行政命令。**只有8％的中国企业认为应该优先提升网络安全。**（全球平均水平为16%）。中国和全球在安全和降低成本方面的反应也存在差异。
