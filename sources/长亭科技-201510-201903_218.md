**Keynote 1:****让不懂安全的人快速搞清楚负责安全的人做了什么**

简单休整之后就是第一天的会议，Opening Keynote 来自于 Gartner 的研究总监和两位 VP，题为《Manage Risk, Build Trust, and Embrace Change by Becomeing Adaptive Everywhere》，从他们的演讲内容来看，Gartner 认为安全只有做到能够不停地跟随业务变化，才能有良好地发展。如果安全（服务/产品）无法跟上业务发展的脚步，甚至阻碍了业务发展的速度，那么肯定会被淘汰掉，他们也提到了 DevSecOps，觉得在快速迭代开发地过程中，应该把安全有机地结合进去，还提到了安全的管理要基于证据（Evidence-Based Governance），**要能让不懂安全的人比较快的搞清楚负责安全的人做了什么。**

  

**Session 1:**** 2020****年，无“机器人恐惧者”**

接下来去听了《Gartner Essentials: Top Security Predictions/SPAs for 2017》，即 Gartner 对 2017 年的安全的几大预测。在这个议题中，首当其冲的就是：

  

![](../Images/1fc520ce331b27c90a4cbdde6f50f472.png)

  

2020年将没有“机器人恐惧者”的生存空间（因为机器人将无处不在）。

  

然后就是关于安全架构的预测：

  

![](../Images/eb5fbd6aa6ce6410cc667e5ff60de5df.png)

  

由预测、防护、检测、响应组成的灵活可适应的架构体系以及有完善问责制、良好的风险管理、合理的组织和有能力的人员组成的有效的管理体系。

  

整个演讲的三个关键引子：

1.  我们的风险环境将如何演变？
    
2.  在数字化营销时代，如何塑造我们的思维？
    
3.  我们需要改变什么？
    

  

  

在第一部分中，有个有趣的预测是：

*   到2020年，基于机器学习的智能机器人将进行 10％ 的渗透测试，而2016年为0％。
    
*   到2020年，IT安全失灵至少会引发一次重大安全事故，造成重大损失。
    

  

第二部分中：

*   到2020年，由 IT 部门指导的信息安全方案相比与由业务部门指导的会面临三倍以上的安全风险。
    

  

第三部分中：

*   到2018年，手工访问认证和请求批准任务的50％以上将是由机器根据政策来完成，而2016年为不到2％。
    

  

我觉得可以总结为一句话：基础的工作会越来越多地交给机器人来做，人，更应该解放精力关注战略。安全越来越重要，且要和业务深度结合。

  

**Session 2:**** DevSecOps****，节奏跟不上变化如何破？**

长亭势必更关心应用层防护的趋势。在和 Gartner 撰写 WAF 魔力象限的研究负责人聊天的过程中，他强调了 Adaptive 的重要性，即 WAF 需要能灵活地适应业务地变化。我们达成一致地观点是：传统的基于规则地防护策略是“常常会失效“的，而且由于 DevOps 观点在美国备受推崇，以及其衍生出的 DevSecOps 的观点，传统的 WAF 用来加强防护水平的“网站模型自学习”方案正在逐渐地跟不上业务的发展。

  

因为”网站模型自学习“意味着需要根据一段时间的流量（一周、一个月）来学习网站的各种参数规则，从而定义什么是正常、什么是非正常。但在业务飞速发展、迭代、变化的今天，可能一个月前学习得到的模型已经和之后的业务产生了脱节，业务逻辑，参数都有了一定的变化，用之前固化下来的模型反而会产生各种误报漏报。在这种互联网业务快速发展的时代，无法跟上业务发展的安全是无法被接受的。而我们的 WAF 产品使用的基于”语义分析“的 Web 攻击拦截技术则拥有更强的业务发展适应性，这一点也得到了分析师的认可。

  

【插播】

接下来中午吃了 VERACODE 赞助的接近十成熟的牛排，流下了感动的泪水。

  

![](../Images/762e9b160d7b4191b2e90f896591d771.png)

  

下午主要是在厂商的展区游荡，看了很多国外厂商的 Demo。整体上看，关注 EDR 的厂商增加了很多，很多外国厂商在激进地使用新技术来尝试把安全问题解决好。当然，这也和美国的市场有关系，美国的客户倾向与尝试新的技术和年轻的厂商，这也使得美国的初创安全公司能够更加放心地去冲刺技术前沿。我们观察到好几家在推进新技术的公司在收入并不大的情况下都融到了几亿美金的样子。

  

后来约到了一个关于市场动态的一对一交流，分析师是一位来自于韩国首尔江南区的美女，从数据统计上来看，目前中国的安全市场是美国的八分之一，还有这很大的增长空间，而且从整个亚太地区来看，中国的安全市场是增速最快的，达到了年增长率14%左右，高于周边国家的8-10%，这对我们来说是一个好的信号。

  

另外，从客户反馈来看，亚太地区的客户为高质量安全服务付费的意愿一直比较低，比较关注于有限的几个点，比如渗透测试和应急响应，但对于安全体系建设类的咨询兴趣有限。不过，这一情况在近期几年也有所改善，包括有客户倾向于寻求服务＋产品的打包解决方案，把自己的安全几乎完全交给第三方公司来做，自己则紧盯业务往前冲。由此看来，多元化、深度的安全服务将可能迎来增长的空间。

  

![](../Images/2040bc1f1795c47d5a1bf820d48e0abe.png)智能、灵活可变、与业务结合的安全将会引领接下来几年的安全潮流。

  

从第一天获得的信息来看，Gartner 的这个安全与风险管理峰会十分值得参加，是少有的能够很好从甲方视角出发，以解决好当下的问题以及如何解决好可能要面对的问题的一个非常实在的会议。
