# 六月“网安”？企业安全新挑战

　　网络安全行业会受到哪些影响？

　　各行各业该如何应对？

  

　　**长亭科技特邀**对此有着深入研究的，京师律师事务所国际法律事务部主任**封跃平律师为您解惑**。

  

　　《中华人民共和国网络安全法》是我国第一部专门针对网络安全问题的法律，即将在2017年6月1日正式实施。在中国从事互联网及其他涉及网络运营的各行业经营者**需履行更严格和全面的法律义务**，并将因违反相关义务受到处罚。

  

　　2017年5月25日，作为跨境并购、投资移民、互联网金融等领域的顶尖律师，京师律师事务所国际法律事务部主任封跃平律师对即将实施的网络安全法对相关行业的影响进行解读：

　　首先，**《网络安全法》的即将实施，让各行业经营者均抓紧时间学习理解《网络安全法》对于相关行业的影响**。因为《网络安全法》可能对于其网络安全架构、安全产品采购、数据存储等方面产生实质性的重大影响，各行业经营者需要从这些方面综合性的考虑是否需要采取业务和经营的调整，加强其网络安全保护以确保符合《网络安全法》的规定，并应关注相关新法规以及主管机关的实施意见。   

  

　　其次，由于《网络安全法》第24条规定网络运营者为用户办理服务时，应当要求用户提供真实身份信息。用户不提供真实身份信息的，网络运营者不得为提供相关服务。这使得**任何网络连接提供商(ICP)和服务提供商(ISP)自6月1日都要开始要实行全网范围内的实名制**。因此，继百度宣布将全面实行实名制之后，知乎表示也将于近期推行实名制。实名制推出后，注册使用知乎服务都需要提供、验证手机号码。并且基于“后台实名，前台匿名(可选)”的原则，经过实名验证的用户，可在前台选择实名或匿名形式展示。

  

　　同时，即将实施《网络安全法》将会让相关行业满足各行业对网络安全的需求，从而推动网络安全行业尤其数据安全防护领域迎来全新发展。近期网络病毒爆发开始于时间2017年5月12日，最新数据显示，目前全球已有超99个国家遭受攻击，超过10万台电脑被攻击。而目前遭受攻击的Windows系统在全球的市场占有率超过90%，更是应用于中国国内的各大国家部门及企业，可见，**未来软硬件的安全可控将成为重点党政部门及重要行业企业的刚需**。

  

　　并且，临近实施的《网络安全法》将改善我国网络安全环境，为推进和发展互联网相关产业扫清障碍。当前我国在网络安全方面的投入占整个IT产业比重仅为2%左右，远低于欧美国家10%左右的水平，这意味着我国网络安全相关产业将有巨大的发展潜力。随着各类智能硬件设备的涌现，相应行业的网络安全需求同样会大幅飙升，行业市场空间将从目前的一两百亿扩展到千亿元以上，网络安全行业的市值空间将被打开。因此，《网络安全法》将会推进**网络安全产业在“十三五”期间迎来黄金发展期，市场规模有望迅速扩张到千亿级别**。

  

　　最后，随着《网络安全法》的临近实施，网络安全概念股将迎来大涨，网络安全领域的启明星辰(002439)、卫士通(002268)、南洋股份(002212)、美亚柏科(300188)、绿盟科技(300369)，自主可控国产替代领域的中国长城(000066)、中国软件(600536)、太极股份(002368)、东方通(300379)，产业链受益标的北信源(300352)、任子行(300311)、蓝盾股份(300297)、天玑科技(300245)、同有科技(300302)等均受此影响。这也从侧面反映出网络安全相关行业未来的发展势头与趋势。
