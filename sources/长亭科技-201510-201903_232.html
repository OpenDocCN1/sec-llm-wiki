S2-045漏洞的危害有多大？


大家为何谈S2-045色变？因为此漏洞的影响是如此简单粗暴：攻击者可通过发送恶意构造的HTTP数据包利用该漏洞，在受影响服务器上执行系统命令，进一步可完全控制该服务器，引发数据泄露、网页篡改、植入后门、成为肉鸡等一系列安全事件。


长亭科技启动紧急响应模式——对公众开放测试网址，发送漏洞预警，公布应急解决方案。

截止到昨日下午，长亭科技针对此漏洞已经有了相对完整的解决方案，成功保障了客户的安全利益！


紧张过后，我们需要对技术原理进一步的追根溯源，才能更好地总结和应对。以下是长亭科技应急响应团队针对S2-045做出的技术要点分析，感兴趣的来拿走！

二、利用方式


通过上述分析可知，当 Content-Type 中包含 multipart/form-data 字符串但是并不能正确解析 Content-Type 时就会引发异常，这时异常信息中包含的 OGNL 表达式被解析，导致黑客可以构造恶意请求在 Struts2 服务器上执行任意代码。


三、修复方案


官方已经发布修复补丁：

  • Struts 2.3.5 - Struts 2.3.31 可升级到 Struts 2.3.32

  • Struts 2.5 - Struts 2.5.10 可升级到 Struts 2.5.10.1

若因为业务原因不能及时升级 Struts2 框架，也可使用长亭雷池 Web 应用防火墙对网站进行保护，长亭科技安全应急响应团队将持续关注漏洞影响后续。
