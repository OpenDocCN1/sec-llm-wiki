# 打怪升级一路开挂，醒哥教你安全开发！

本周，长亭科技与i春秋学院联手推出新课程，从Web安全、二进制安全、无线安全、开发、CTF五个方向指导安全小白的成长之路。当你具备了一些安全知识、开始使用黑客工具的时候，会不会突然有一种冲动也想打造一套属于自己的专属工具呢？来自长亭科技的高级研发工程师李昌志不仅有这种冲动，还付诸实践。

  

**李昌志，江湖人称醒哥**

![](../Images/a8fd05c1220655a56e60d42e929d201f.png)

多年热衷于研究网络安全知识与技能，发现过包括百度、阿里巴巴、腾讯在内的多家企业的客户端及Web漏洞，目前负责长亭科技雷池Web应用防火墙的研发工作，在Web攻击拦截领域有较高的造诣。当然他曾经也仅仅是一个刚刚入行，对安全研发有着满腔热情的学生，也走过很多弯路，正因为这样，他才最了解那些在安全研发时所需要的必备技能，深入浅出地告诉大家如何成为一名真正的黑客兵器师，开发出大牛产品。

醒哥参与研发的长亭雷池（SafeLine）Web 应用防护系统，是基于语义智能分析的Web应用防护系统（WAF）。这款长亭科技研发的Web应用防护系统在前不久的国家等级评测中被定为增强级，而此前获得同等级防火墙销售许可的产品只有15个，也难怪长亭科技的小伙伴敢以“雷池”命名，有了这款采用无规则的只能威胁识别引擎和无状态的并行数据分析框架的防火墙，各类Web应用攻击手段的确难以越雷池一步。

![](../Images/8f5d3448f26aca727f9c33d5ed0b1aec.png)

小伙伴们是否还记得最初在参加“百度杯”CTF大赛时，i春秋老司机们设置的小小障碍，参赛选手只有绕过这层障碍才能登录网站进行答题，这个小障碍其实就是利用了WAF的防护机制。

![](../Images/5847d336e89084ee5677a971b5bb2278.png)

**在本节课程中，醒哥总结自己的实践经验，介绍了一些新手在进入安全开发领域时必须掌握的技能，包括操作系统、计算机网络、数据学、密码学几大维度的知识**。小白们要想上手研发一款安全软件，首先要熟悉一门编程语言的语法，还有这个编程语言的周边，比如开发包以及一些模块，之后要看看别人是怎么写的，这时可以找一些开源软件的源代码去研究，理解其中的逻辑，自己勤练手，多试着写一写，在这个过程中要有自己的想法，最后做出来的东西就是你想要的一款安全软件。

![](../Images/3734c4a82e83049f7e74728ba74f48b8.png)

虽然课程的名字是**《安全开发学习捷径，打怪升级一路开挂》**，但听完醒哥的分享之后，大家可能也感觉到在安全研发的道路上，并没有捷径可言，要开发出一款安全产品并不是一朝一夕可以做到的事情，雷池Web应用防火墙的诞生前前后后也经历了两年时间的产品演变才能进入销售环节。醒哥向我们指明的是努力的方向，希望大家明白，打怪要注重基础知识的积累，多看多写多想，才能升级成大神，共勉！
