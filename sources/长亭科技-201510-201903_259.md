# Discuz 被曝存在的 SSRF 漏洞，结合Gopher 协议可危害内网

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651370521&idx=1&sn=1e9394da2c0a70995deab79046825ab5&chksm=8d39c591ba4e4c87ee4fd027faa62f1198c5753ce5c45b07569718dab980170cea7bfd8f4bf9&scene=126&sessionid=1681376315#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651370521&idx=1&sn=1e9394da2c0a70995deab79046825ab5&chksm=8d39c591ba4e4c87ee4fd027faa62f1198c5753ce5c45b07569718dab980170cea7bfd8f4bf9&scene=126&sessionid=1681376315#rd)

SSRF 漏洞是利用程序漏洞越过网络边界访问内部应用特定请求的攻击方式，只能发起 HTTP 请求或者验证端口开放状态。

  

通常安全人员会用“鸡肋”来形容 SSRF 这种攻击方式，然而，在Gopher 协议的帮助下，SSRF 可以发起非 HTTP 请求，进而攻击内网的 FTP、Telnet、Redis、Memcache等应用，造成更大的危害。

  

Gopher 是 Internet 上常见且常用的一个协议，出现在 HTTP 协议之前。利用此协议可以攻击内网的应用系统，也可以进行 GET、POST 请求，对SSRF 的危害有着扩大的作用。

  

利用 Gopher 协议拓展攻击面的具体内容可点击左下角阅读原文进入长亭科技blog查看。

  

前几日 Discuz 被报告存在的 SSRF 漏洞，此漏洞结合服务器开启了gopher wrapper，可以对 redis、fastCGI、memcache 等应用进行攻击，严重时可直接获取服务器权限。这样的攻击方式在一些漏洞报告平台已有成功案例，长亭科技安全研究人员建议网站管理员尽快进行自查以及修复工作。  

  

推荐修复方案：

1.  升级到最新版 Discuz；
    
2.  同时，查看 phpinfo，确认 gopher wrapper 是否已经关闭，如若开启立即关闭 gopher wrapper。
