# 长亭科技当选信通院网络安全卓越合作伙伴

近日，在2023年中国网络和数据安全产业高峰论坛网络安全技术创新赋能产业发展分论坛上，网络安全卓越验证示范中心发布了第四批网络安全卓越合作伙伴名单，长亭科技**从数百家申请单位中脱颖而出，成功入选十家合作伙伴之一**。

  

![](../Images/60bc75283c358842dff0c8c1ef344d9a.png)

![](../Images/d9eda2add39d7efb28d31a7b20865b1c.png)

卓越示范中心是在工业和信息化部网络安全管理局指导下，由中国信通院筹备建设的国家级网络安全能力验证平台、评价平台、示范平台和认证平台，以促进网络安全产业高质量发展目标，聚合产业链上下游各方优势。会上由中国信息通信研究院院长余晓晖、四川省通信管理局副局长刘小文、工业和信息化部网络安全管理局网络安全处处长袁春阳、成都高新区新经济产业局副局长彭卫为第四批网络安全卓越合作伙伴颁发了聘书。

  

![](../Images/b9fd8881db937740c65a122086e4c44c.png)

  

此次获聘为网络安全卓越合作伙伴，也是对长亭科技创新研发能力和行业人才培养实践的重要认可。以智能安全厂商代表作为标签，长亭科技以技术为导向，将创新融入研发，用智能颠覆传统，发布的智能语义分析检测引擎，从质变上提升了WAF的检测精准度，用智能为企业用户提供全新的安全防护解决方案。

  

之后，长亭科技将与卓越示范中心展开深度合作，以“拓展本质安全、立足实战对抗、着力前沿创新”为目标，就网络安全人才培养创新实践进行探索，共同推进安全领域人才培养和落地应用。
