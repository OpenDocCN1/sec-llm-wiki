# 长亭参与《中国网信》“学习二十大 践行企业责任”专题并发表内容

2022年10月，党的二十大胜利召开，网络安全作为热词再次被提及。报告指出，“推进国家安全体系和能力现代化，坚决维护国家安全和社会稳定。必须坚定不移贯彻总体国家安全观，把维护国家安全贯穿党和国家工作各方面全过程，确保国家安全和社会稳定”。

  

为深入贯彻党的二十大精神，结合行业发展方向，践行企业使命，《中国网信》推出相关专题活动。长亭科技作为网络安全领域的新锐力量，首席执行官肖力受邀参与并发表了相关内容。

  

*《中国网信》杂志由中央网信办（国家网信办）主管、中国网络空间研究院主办，致力于成为学习宣传贯彻党的创新理论的思想阵地，宣传解读中央网信委及其办公室重大决策部署的重要渠道，深化网信领域理论研究、科技创新和实践活动的交流平台。*

  
  

  

以下为收录稿件全文：

  

**守好网络安全防线**

**筑牢网络强国基石**

  
  
  
  
北京长亭科技有限公司 首席执行官 肖力

  

党的二十大站在新时代新征程的历史起点上，对中国未来五年乃至更长时间的发展作出科学谋划，擘画了以中国式现代化全面推进中华民族伟大复兴的宏伟蓝图。习近平总书记提出要加快建设网络强国、数字中国，赋予网络安全企业更重大的时代使命和历史责任。**多年来深耕网络安全事业的长亭科技全体上下备受鼓舞，深感重任在肩。**

  

党的二十大报告中“安全”一词贯穿全篇，并设专章论述国家安全问题。这对网安人提出了更高的使命要求，即在新时代新征程中奋力开创网信事业发展新局面，以网络强国建设新成效助力全面建设社会主义现代化国家、全面推进中华民族伟大复兴。

  

作为网络安全领域的新锐力量，一直秉持专业高效的长亭科技将全面学习贯彻党的二十大精神，坚定履行建设网络强国和数字中国、维护网络安全的职责使命，坚持守正创新，持续加大关键基础设施领域的安全技术研发投入；强化攻防领域关键核心技术攻关，努力打造更多行业引领性产品，守好千行百业的网络安全防线。在网络强国建设征程中，长亭人将持续深入产业领域场景，根据不同产业数字化转型升级的需求，提供行业定制化网络安全解决方案，提高关键基础设施和重点产业网络安全防护水平。
