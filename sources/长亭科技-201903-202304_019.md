# 安服实力认可！长亭科技入选嘶吼《网络安全服务市场洞察报告》

近日，嘶吼安全产业研究院正式发布《至人无己 正复为奇：网络安全服务市场洞察报告》（以下简称“报告”），长亭科技凭借领先的安全服务能力和扎实的行业技术探索，入选报告的**安全运营、安全实战、安全培训和安全咨询**四大细分领域，并作为安全实战代表企业被重点推荐，同时还获评通用安全服务厂商**“智能&分析化”及“内生&能力化”视角下代表厂商**。

*“报告”鉴于网络安全服务涉及细分领域的差异性和复杂性，重点聚焦网络安全服务细化需求+共性特征的深度分析，针对网络安全服务产业的界定及背景、需求、趋势进行梳理总结，对我国网络安全服务产业发展具有一定的指导意义和参考价值。*

  
  

  

**安全运营**主要包括态势感知、安全托管、监测分析和安全管理相关服务；**安全实战**主要包括红蓝对抗、渗透测试、重保支持和应急演练；**安全培训**主要包括网络安全相关资格认证、服务实训和意识教育培训等；**安全咨询**主要包括等保合规、安全战略规划和安全架构设计等。

  

本次入选四大领域，同时作为安全实战代表性企业被重点推荐，是对长亭安全服务能力与技术实力的重要认可。以多年攻防经验为基础，长亭安全服务团队梳理出了安全服务核心环节，可系统性地为企业提供全面贴合攻防实战的安全服务：包括攻击视角下的渗透测试，防守视角下的基线检查、代码审计和攻防视角下的应急响应。项目覆盖全国28个省、市、自治区，分布能源、金融、通信、政企、制造、教育、医疗、烟草、交通等多个行业。此外，长亭创办的珂兰寺，作为网络安全行业备受关注的人才培养“兵器库”，已为网络安全行业输送超百实战型人才，甚至超半数学员在毕业前就可以独立挖洞。

  

除了《网络安全服务产业需求行为全景图谱》，嘶吼研究院还从四化视角对国内的安全服务厂商进行了能力分析，长亭成功入选**“智能&分析化”及“内生&能力化”**视角下的代表厂商！
