近日，FreeBuf咨询正式发布 《CCSIP（China Cyber Security Panorama）2022 中国网络安全行业全景册（第五版）》。长亭科技凭借专业出色的产品能力、市场认可度以及产品多方位布局，入围28项细分领域，同时被评为应用防护一级类目星选厂商，表现突出。






入围领域


本次全景图以PDR网络安全模型为基础，并参考IPDRR安全框架和P2DR2模型，形成“防护——检测——响应——持续改进”的安全闭环，在原有的94个细分领域的基础上，又新增5个细分领域，为企业提供网络安全产品选型参考，帮助企业了解中国网络安全技术与市场的发展趋势。

此次入选多个细分领域，展现了行业、客户及媒体机构等对长亭科技的高度认可，也体现了长亭科技在云安全、应用防护、威胁检测、安全响应和安全服务等领域的强大竞争力。作为应用防护星选厂商，长亭科技在WAF和Web应用扫描与监控领域一直有着深入的探索与创新，其中长亭科技最早发布的明星产品，雷池（SafeLine）下一代web应用防火墙自发布以来已集齐三大国际权威咨询机构Gartner、Forrester和 IDC的认证，是少有的WAF类“大满贯得主”；去年，再次入选Forrester《Now Tech: Web Application Firewalls, Q2 2022》，被评为“WAF Specialist”。


截至目前，长亭科技已服务千余家来自金融、通信、政企、能源行业的企业级客户，为其提供更快、更精准、更智能的安全防护。
未来，长亭科技将持续坚持创新与技术突破，为企业用户提供稳定可靠的安全保障，为国家网络安全贡献力量。
