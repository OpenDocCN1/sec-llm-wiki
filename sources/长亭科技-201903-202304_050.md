# 长亭科技加入阿里云安全合作伙伴联盟，共建云上安全生态

11月4日，在“2022杭州·云栖大会”云上安全与合规分论坛上，阿里云联合多家生态厂商共同成立“云安全合作伙伴联盟“，作为首批入选合作的安全厂商，长亭科技CRO、首席安全研究员杨坤受邀参加签约仪式，并分享了“以攻促防的混合云安全运营体系”的主题演讲。

  

![](../Images/738b247559419d70015873d003543990.png)

长亭科技CRO、首席安全研究员杨坤参加签约仪式

  

**开放的云安全生态**

  

在今年的云栖大会上，云安全依然是一个关键词。阿里云智能总裁张建锋在主题演讲中提出“以原生、智能、弹性、透明和开放五个关键词来构建云上安全体系”；阿里云智能基础产品事业部总经理蒋江伟在技术主论坛的演讲中也提到云安全“需要开放生态共建，为帮助用户更好的构建云上纵深防御体系”；阿里云智能安全总经理欧阳欣则从安全责任共担的角度介绍到，阿里云将云原生安全能力划分为云平台、云产品和安全服务化三层，云厂商需要提供给企业安全的云平台、采用DevSecOps并融入安全特性的云产品、SaaS化形式即插即用的安全能力。

  

安全的特殊性在于其技术域极多且复杂，单点极致的市场格局决定了没有一家厂商可以独立满足用户所有的需求，因此在本次云栖大会分论坛上，阿里云还正式宣布牵头成立云安全合作伙伴联盟，以“开放、联合、协同”的态度，携手多方力量，打破业务架构对安全采用的束缚，用开放的态度让客户多云/混合云架构更安全。

  

本次作为首批加入的安全厂商之一，正是对长亭在云安全方向创新技术探索的认可。长亭科技安全产品全面拥抱云环境，融入云上安全特性，已经在流量安全、安全运营服务等方向与阿里云实现合作，与阿里云和其他安全厂商共同携手护航企业云上安全，为云上企业客户共建纵深防御体系。

  

**混合云安全运营体系**

  

长亭科技杨坤在主题演讲中分享了在混合云架构下安全运营服务的思考，未来，混合云将成为企业常态架构，实现更加敏捷和高扩展性的同时，也会带来新的挑战：更大的攻击面、安全策略不一致和缺乏有效评估手段。

  

![](../Images/8a3ea7c0b0af5e78dde5c6d170c21f0f.png)

  

根据一直以来坚守的“未知攻焉知防”的信念，长亭原创提出“敏捷”运营理念，以持续积累的攻击知识去度量防守的覆盖性与有效性，以持续评估保护对象的结果，促进防护策略的持续调整，从而提升防护能力，而防护能力的提升，也反作用于攻击能力，促进整体攻击能力的提升，形成良性循环。

  

![](../Images/8c7e465a7626230340f7c6d0406b4218.png)

  

而想要落地“敏捷”运营体系，第一个关键的部分就是安全度量体系。“企业攻防能力成熟度模型”是长亭率先在业界提出的，用“度量”和“量化”的思想和方法，去帮助企业建设体系化的安全能力。并在今年9月份，在4大防护基础能力和3个能力中心基础上升级为2.0。

  

*   体现运营度量，增加“覆盖度”和“有效性”部分，将成熟度向安全运营方向延伸。
    
*   增加框架融入：增加引入MITRE-ENGAGE框架，将“反制能力”升级为“交互防御能力”；
*   扩充能力单元，增加“开发安全”、“资产管理”、以及部分运营能力单元

  

基于自身在网络攻防与云安全领域的创新探索与落地实践，通过积极参与云安全生态的构建，未来，长亭科技将为用户提供更可靠、更可控、更优质的混合云安全解决方案。
