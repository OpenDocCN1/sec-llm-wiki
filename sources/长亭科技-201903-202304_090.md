# 共向未来 合作双赢|长亭2022年合作伙伴招募会深圳首站成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651381723&idx=2&sn=52e9cc87fd237fdd561e0a0524a07d75&chksm=8d39ae53ba4e2745743efa18fb2f24e1a9b2ec98313133d585bb4d3705bc0d4f306cf3366de6&scene=126&sessionid=1681376178#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651381723&idx=2&sn=52e9cc87fd237fdd561e0a0524a07d75&chksm=8d39ae53ba4e2745743efa18fb2f24e1a9b2ec98313133d585bb4d3705bc0d4f306cf3366de6&scene=126&sessionid=1681376178#rd)

6月9日，长亭科技2022年合作伙伴招募会首站—深圳站成功召开。**招募会以“共向未来，合作双赢”为主题**，向合作伙伴分享长亭发展历程和未来展望，全面剖析市场机会，解读合作伙伴战略。招募会现场一百三十余位合作伙伴齐聚，共同探讨合作未来；同时，会上还举行了合作伙伴年度目标承诺签约仪式。

  

![](../Images/f79262b10042e86bc734339cc949d2e3.png)

  

长亭科技创始人、CTO朱文雷首先对长亭科技发展历程与广阔合作未来前景进行了前瞻性介绍，在深入全面了解后促进合作的建立。朱文雷表示：在坚持“简单、开放、共生”的合作伙伴理念不变的基础上，长亭科技将加强加快合作伙伴生态建设，倾斜长亭产品技术力量，优先赋能生态合作伙伴，共同探索新的合作模式，形成互相依赖、互利双赢的合作关系。

  

![](../Images/710011392fa752d98d624e0c164d4860.png)

  

长亭科技华南区售前总监梁夏从更加具体方向介绍了长亭重点产品的安全能力和市场机会。当前，在数字化转型升级的浪潮之下，企业网络安全面临着更加严峻的挑战，攻击主体向规模化、组织化转变，尤其是APT攻击一直处于白热化的状态。攻击技术变得更先进、更隐蔽，攻击技术和工具变得更自动、更先进、更高效。同时攻防也趋向实战化。基于对网络攻防实战的深刻理解与丰富经验，在深入契合网络安全发展趋势和企业客户体系化防护体系构建的需求下，长亭科技以场景化和实战化为落地点，构建了“攻、防、知、查、抓”的新一代安全防护体系，为客户网络安全全方位的构建提供贴合行业的解决方案。同时基于长亭分布式滑板车底座，已天然具备云原生特性，能够适配各类云化场景，同样为客户的云上安全提供防护。目前，长亭科技已服务金融、政府、电力、电信、交通、教育、医疗、能源等十余个行业。

  

![](../Images/9043f7d74c574faaeef2c586253327bb.png)

  

会上，还有两家优秀合作伙伴代表进行了合作分享。深圳市常行科技有限公司副总经理庄严表示，数字经济发展为网络安全市场提供了巨大机遇。常行科技希望可以和长亭科技一起携手，定位安全技术服务型企业，以客户需求为导向，主动及时地提供优质专业的网络安全服务，赋能企业在数字化时代的安全能力。据统计，2023年网络安全市场预期规模或超1300亿，中国网络安全产业正在进入战略机遇期 。深圳市众成信息技术有限公司总经理曾晓庆表示，在与长亭科技去年合作中，双方优势互补，互信共赢，共同创造了巨大商机；今年希望与长亭科技继续深入合作，加深对产品能力的理解，持续扩大商机落地，拓宽市场覆盖广度，共同为客户创造价值。

  

![](../Images/233df1f69b70dee5438c2b2aac999e11.png)![](../Images/a294b24a53e7ef80513c68ffd51a67b3.png)

  

为了更好地传递长亭科技对于合作伙伴的支持，由长亭科技渠道部总经理杨帆对2022年合作政策进行了解读。杨帆表示，2022年，长亭将迈出渠道化更坚实的步伐，所有产品和服务向合作伙伴开放；同时也会不断地推出更多面向合作伙伴的产品及服务，构建体系化的合作方式，由点到面，从销售个人面向合作伙伴转变到整个组织面向合作伙伴。公司产研团队也将从后端走向前端，贴近合作伙伴，更快速的将合作伙伴或者用户好的产品/服务改进建议融合到产品研发中，与合作伙伴一起围绕行业深挖用户价值，实现从产品销售到解决方案的转变，共同推动网络安全模式创新。此外，对于新的合作伙伴激励政策也进行了介绍与解读，更多激励合作伙伴共同发展。

  

![](../Images/d7b586763c0ab72b1f69e9676d157943.png)

  

最后，由长亭科技华南区总经理何超频与4家Q2签约合作伙伴进行了年度目标承诺签约仪式。以更加专业和开放的态度与合作伙伴共同打造网络安全合作生态环境。

  

![](../Images/c31e786291b283f9ff7c1fc21e965cfb.png)

  

2022年，长亭科技将持续携手更多的合作伙伴共同构建简单、开放、共生的合作生态新格局，拥抱合作伙伴，共同携手奋进，开拓安全新局面。同时，长亭科技也会坚定不移推进渠道战略落地，构建长效稳定的合作伙伴关系，实现深耕细作，合作多赢。

  

**其他城市的合作伙伴招募会陆续举办中，欢迎持续关注。**
