高级销售经理

base：北京、上海、广州、深圳、西安、新疆、郑州、辽宁、杭州、南宁、厦门、福州、南昌、石家庄等地


岗位职责：

1. 负责公司行业/区域的销售工作，完成公司下达的任务指标；
2. 负责目标客户的关系拓展和维护，分析客户需求，寻找项目机会；
3. 负责行业市场信息的收集及竞争对手的分析，开拓新市场发展新客户，提升产品市场占有率；
4. 树立公司产品在该行业/区域的品牌和产品优势地位，负责公司产品的销售及推广；
5. 如有金融、通信、政府、能源、大型企业、交通、医疗、教育等行业资源均可。


任职要求：

1.本科以上学历，信息安全，计算机或相关专业优先；

2.三年以上安全行业销售工作经验，有良好的销售业绩；

3.形象良好，语言表达和思维逻辑清晰、性格乐观、能承受压力；

4.熟知相关区域渠道市场现状，有良好渠道合作关系者优先考虑。



高级售前工程师

base：北京、上海、广州、深圳、福建、广西


岗位职责：

1.根据客户企业安全现状、安全痛点，为客户制定安全建设规划；

2.完成公司产品/服务解决方案、组合式产品/服务解决方案、系统性解决方案编制；

3.分析重要行业安全需求，制定完整的行业解决方案；

4.完成售前技术服务工作，包括技术交流、方案撰写、投标和演讲等；

5.对销售人员进行产品和解决方案相关的培训；

6.执行产品策略、反馈市场需求，关注其他安全厂商的产品动态，反馈行业应用情况。


任职要求：

1.本科以上学历，计算机、通信、电子相关专业；

2.了解WAF、IPS、IDS、抗DDOS、漏洞扫描、堡垒机、数据库审计、网络准入、SOC等网络安全技术；

3.熟悉传统环境、云环境下网络安全架构设计和最佳实践，对云安全、物理安全、网络通信安全、设备计算安全、应用数据安全、管理体系规范均有全面的了解；

4.具备3年以上信息安全工作经验;

5.学习能力强，对企业IT 架构和业务需求有较深入的理解；

6.优秀的沟通能力和演讲能力，能够与客户方进行有效沟通交流。



区域渠道总监

base：北京、上海等地


岗位职责：

1. 负责区域渠道体系建设和运营管理工作；

2. 推动区域渠道工作落地，对区域渠道经营指标负责；

3. 指导渠道销售工作，维护区域良好渠道合作秩序；

4. 负责公司品牌渠道推广，组织推动相关渠道活动。


任职要求：

1. 三年或以上工作经验，专业不限，本科及以上学历；

2. 沟通表达流利，逻辑思路清晰，有良好的关系建立能力；

3. 有一定B2B销售实践经验，同行业渠道建设经验者优先；

4. 勤奋努力，积极进取，结果导向意识强。



安服项目经理

base：北京、上海、深圳、广州、成都


岗位职责：
1. 负责与客户沟通并确认安全服务需求（能够解决客户提出的安全技术相关问题）；
2. 负责客户安全服务类需求方案输出；
3. 负责安全服务项目实施过程中的项目管理，解决项目中出现的技术和管理问题，保证项目的正常进行及交付。

任职要求：
1. 计算机及相关专业本科以上学历，2年以上安全相关工作经验；
2. 具备较好的解决方案技术沟通和演说技能能力；
3. 能够独立承担安全服务项目经理等工作。



安全工程师

base：北京、杭州


岗位职责：

1. 参与设计安全产品技术架构；

2. 改进现有安全产品的安全策略；

3. 将安全思路转化为自动化工具。


任职要求：

1. 了解渗透测试过程，了解常见漏洞的原理；

2. 熟悉至少一种主流编程语言，如：C、Python、Golang、Lua 等；

3. 熟悉常见安全产品的实现原理与对抗方式；

4. 具有良好的计算机基础理论知识，能输出高质量的工程代码。



红队攻防工程师

base：北京、上海、深圳、广州、成都、厦门


岗位职责：

1. 负责红蓝对抗等高端渗透支持工作，能独立完成高安全防护条件下渗透测试；
2. 前沿攻击技术的研究。


任职要求：

1. 3年以上攻防渗透或漏洞挖掘经验、具备良好的沟通能力（优秀者不限）；
2. 具有丰富的实战经验，可独立完成渗透测试工作；
3. 熟练掌握常见的外网打点攻防技术，对相关漏洞的原理有深入的理解；
4. 熟悉常见的内网攻击思路和方法，域环境渗透等；
5. 对安全有浓厚的兴趣和较强的独立钻研能力，有良好的团队精神。



安全产品经理

base：北京


岗位职责：

1. 关注行业动态，研究国内外竞品，并完成产品竞争分析材料；
2. 为前场同事提供产品培训与技术资料；
3. 根据行业特性研究销售策略，输出目标行业的标准解决方案；
4. 跟踪客户，了解最一线的需求，辅助指导产品规划迭代；
5. 参与产品对外宣传与运营。


任职要求：

1. 具有良好的文档能力；
2. 具有良好的沟通与演讲能力；
3. 对待工作积极主动，能自我驱动地找到工作目标；
4. 有优秀的逻辑能力与抽象能力，可以透过现象快速看清事物的本质；
5. 熟悉企业安全产品的商务模式；
6. 了解黑客的常见攻击方式。



高级后端开发工程师

base：北京、杭州


岗位职责：

1. 参与后端服务的需求分析与技术方案设计；

2. 负责后端服务的架构设计与实现；

3. 持续改进系统的现有设计与实现，提出解决方案并推动落地；

4. 持续优化系统的性能，提升稳定性；

5. 保证项目的代码质量持续提升。


任职要求：


1. 计算机相关专业本科及以上学历，或具有同等效力的相关经历；

2. 三年及以上服务端工作经验；

3. 有扎实的 Python/Go/SQL 等编程语言基础；

4. 有一定的性能调优和复杂问题排查经验；

5. 熟悉至少一种常用后端框架如 Django；

6. 熟悉至少一种常用关系型数据库如 PostgreSQL、MySQL 等；

7. 熟悉至少一种常用非关系型数据库如 MongoDB、Redis 等。



系统研发工程师

base：北京、杭州


岗位职责：

1. 负责 Web 应用安全产品的核心检测引擎与基础组件的设计和研发工作；

2. 持续迭代与改进检测引擎，提升产品的核心竞争力。


任职要求：

1. 熟练使用 C / C++ / Go / Rust 编程语言之一，能够编写稳定高效可靠的代码；
2. 了解主流操作系统功能特性，能够选择合适的方式完成系统开发（网络、文件、进程操作等）工作；
3. 具备分布式高性能网络服务器设计开发经验者优先；
4. 具备编译器相关领域设计开发经验者优先。



产品运营

base：北京


岗位职责：

1. 能够深入理解产品，挖掘产品价值和客户需求，建立产品营销体系并执行推广；

2. 与产品、研发等团队紧密合作与沟通，能够把产品转化成市场行为所需要的营销材料，包括但不局限于产品手册、解决方案等；

3. 与销售团队配合，提升客户对产品的理解与应用，提供销售环节所需的市场支持；

4. 挖掘、搜集、分析行业产品资讯，能理解产品应用场景，细化客户画像。


任职要求：

1. 熟悉科技行业，三年以上工作经验，对产品运营有浓厚兴趣；
2. 学习能力较强，具有较强的独立思考能力和自我驱动力，逻辑清晰，有一定总结归纳和文字表达能力；
3. 优秀的沟通能力，良好的团队协作精神，具备较强的组织协调能力；
4. 有B端产品运营经验或网络安全行业背景者优先考虑。



招聘经理

岗位职责：

4. 活泼开朗、思维活跃、具备良好的沟通协调能力；
