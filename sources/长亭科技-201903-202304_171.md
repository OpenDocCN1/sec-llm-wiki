# 业务场景五项全能｜主机视角的漏洞管理

2021年7月12日工信部、国家网信办、公安部印发《网络产品安全漏洞管理规定》，该《规定》将漏洞管理定义为安全运营单位持续管控工作，要求规范漏洞发现、报告、修补和发布等行为，旨在维护国家网络安全，保护网络产品和重要网络系统的安全稳定运行。  
在主机安全视角下，网络运营者需要对现网环境中的主机服务器进行资产与脆弱性持续监测，且具备相关系统用于存储不少于6个月的漏洞事件信息，同时需具备符合国家标准漏洞定义的通报渠道，可快速获取已公布漏洞细节情况。  
网络运营单位需具备细粒度的主机资产信息采集与分析能力，应采用多种检测技术与手段获取现网全面的资产信息，形成组织内部的资产数据库，通过资产——漏洞——漏洞利用情报——修复措施及安全补丁自动关联匹配，完成漏洞发现，验证，处置修复工作。  
具备持续性资产与漏洞检测以及完整的漏洞管控能力，有效应对5个主机漏洞管理业务场景：资产识别、漏洞检测、风险排序、情报预警、漏洞修复，是运营单位在《规定》和网络实战中必备技能。

  

主机漏洞管理业务场景一**资产识别**

  

安全风险管控的基础核心是全面掌握资产情况，实时动态的资产管理能力可以有效提升脆弱性安全事件感知的效率、缩短脆弱性事件处置时间窗口。多维度资产持续监测与识别至关重要。

  

业务属性关联

  

建立安全视角的资产管控能力，需将技术数据与业务属性关联整合，结合实际业务场景中的组织架构、业务结构、空间位置和人员信息，将安全数据与IT数据关联、与业务属性关联，同时将安全事件与组织、系统、人员关联匹配，明确影响范围与事件责任。

  

多种资产探测技术

  

服务器环境中采用多种资产探测技术与方式，利于全面识别资产信息。

*   基于Agent：实时采集主机服务器资产信息。
    
*   CMDB系统同步：通过API同步CMDB资产管理属性。
    
*   资产数据手动导入：用于补充、扩展资产管理属性。
    
*   主动式网络嗅探：通过ICMP、端口扫描、ARP识别无主资产。
    

  

全面的资产识别包括：

  

  
  
**主机基本信息**

以硬件信息、网络接口、路由信息、分区信息、环境变量为主要数据，形成基本资产管理框架，掌握当前主机资产资源负载和网络状态等基本情况。

  
  
**进程信息**漏洞会影响主机资产以及相关应用，掌握进程状况可迅速理清漏洞的有效影响范围。  
  
**端口信息**漏洞的攻击途径可以归纳为网络、本地、物理、邻近网络攻击，识别端口了解主机暴露面，进而了解漏洞的主要攻击途径，以端口视角识别漏洞可利用程度和利用难度。  
  
**软件应用**通用漏洞与软件应用版本直接关联，攻击者探测是否存在漏洞时也会采用版本识别的方式进行快速发现。当全网爆发高风险漏洞事件时，实时的软件应用信息采集可帮助运营者提前预警、提前防范，缩短漏洞处置时间窗口。  
  
**用户信息**脆弱性安全事件中有一部分是由于操作系统弱配置所导致的，采集系统账户信息以及账户安全和密码安全策略，帮助运营者评估安全策略基线与现状差距，以及在脆弱性事件分析过程中，将账户与进程相关联，形成完整的漏洞攻击路径分析，用于追踪溯源。  
  
**网站信息**对于主机来说，很多脆弱性事件均是对网站进行漏洞利用，Web中间件也会经常爆发出高风险漏洞，识别每一个主机系统上的站点信息、对应的网络端口、采用的Web服务以及具体的路径，以网站视角分析、判断潜在的漏洞攻击威胁及风险。  
  
**容器资产**容器镜像的漏洞问题，也是需要关注的安全防护重点之一。运营者通常会直接采用互联网仓库中的镜像模板，识别容器镜像基础信息以及容器状态可了解该容器镜像中已知的漏洞情况。

  

主机漏洞管理业务场景二**脆弱性检测**

  

漏洞检测采用基于主机的白盒扫描机制，从主机内部深度分析运行环境、清点高危资产，依托智能的漏洞分析算法以及24h动态更新的漏洞库，实时精准全面的检测漏洞。基于业务场景采用不同的漏洞检测模式，应有针对性的实现全程全网的无人值守主机漏洞扫描能力。

应急漏洞重点扫描

应急漏洞扫描功能应该结合高水平安全服务团队的经验，提供对于关键漏洞的高强度扫描能力，为高风险漏洞提供高质量的扫描结果信息与POC信息，提高安全应急响应能力，从而缩短漏洞处置周期。

通用漏洞全面扫描

安全配置扫描

  

对于常见系统风险与常见业务风险具备检测能力，可发现包括账号风险、敏感文件变动、端口异常、权限异常、Web风险、配置不当在内的多种风险信息。

合规基线评估

  

合规基线提供基于国家、行业等安全规范的检测能力，快速掌握企业内网服务器资产对于安全规范的满足情况，适用于多种不同操作系统、Web服务、容器服务、数据库等应用的合规检测。

系统补丁检测

依托持续更新的补丁库，可快速、精准地发现系统升级所需的重要补丁，帮助用户第一时间发现潜在安全隐患。补丁检测通过探针识别系统内核、应用程序指纹，并结合指纹信息自动关联匹配官方补丁信息，以补丁视角进行事件聚合，提升漏洞修复效率。

  

主机漏洞管理业务场景三**漏洞风险排序与管理**

  

聚焦安全人员精力，通过漏洞风险排序，关注真实风险漏洞，对漏洞进行全生命周期管理，将大幅提升运维效率，进阶保障业务安全。

  

漏洞优先级排序  
  

  

具备从现网存量漏洞中快速定位最有价值的漏洞，清洗过滤低风险漏洞据的能力。以漏洞自身属性+漏洞已知利用威胁+现网处置状态为核心理念进行漏洞风险排序，在已有的传统定性和定量排序方法之上，结合用户实际情况进行细粒度的分层管理模式。

  

漏洞全周期管理  
  

  

在脆弱性事件生命周期内，持续跟踪漏洞，从发现、验证、修复、复测、闭环整个过程，通过自动化的方法，形成漏洞数据闭环、检测闭环、状态闭环的能力，支撑漏洞全周期管理。

  

联动消息通告与流转平台，与工单系统、邮件系统、短信平台、钉钉等相关IT信息系统，提供多样化的消息与工单推送模式，缩短暴露时间，快速有效控制风险。

  

主机漏洞管理业务场景四**情报预警和知识库**

  

实时检测内部主机资产和漏洞的同时，快速感知外部漏洞及其威胁情报，才能够提升漏洞管理能力。每天出现的新漏洞、可利用情报信息、持续更新和积累的知识库，是支撑用户资产和漏洞管理能力持续优化的基础，是资产和漏洞高级管理功能的支撑。

  

**情报中心**由平台核心知识库支撑，包括对知识库的多维度全库检索和分析能力；**知识库**由漏洞库、利用情报库、修复信息库关联构成，支撑漏洞优先级排序，形成漏洞知识闭环。

  

  

国家标准漏洞库

  

漏洞库覆盖CVE、CNNVD、CNVD条目。平台漏洞库应在此基础上进行漏洞库质量优化和提升，提供更加详尽的漏洞说明与修复建议，具有中国国家漏洞库CNNVD兼容性认证，可每天从CNNVD获取最新最全的漏洞信息。

  

全网漏洞利用情报库

  
情报库验证信息来自互联网常用的漏洞攻击代码共享平台，具备：长亭社区、Metaspoit、Exploit-DB三个不同漏洞情报平台的漏洞验证和说明信息，为用户提供发现漏洞后快速验证、快速响应的技术能力，可根据所发现的漏洞快速检索对应的漏洞验证方法，可通过CVE编号，POC来源等相关信息快速检索查询漏洞威胁情报数据，感知已公开漏洞的验证方法，快速确定漏洞已知利用途径。主机漏洞管理业务场景五**漏洞处置与修复**

  

漏洞处置工作会分为漏洞消除、漏洞缓解、漏洞接受三种处置动作：

  

**漏洞消除**是指升级应用版本、安装补丁、变更安全弱配置，该处置动作可消除已存在的漏洞。

  

**漏洞缓解**是指该漏洞依旧存在，但因为消除动作影响业务连续性或无有效消除方案等因素造成无法消除时，可采用网关防护或访问控制等手段减少漏洞利用途径。

  

**漏洞接受**是指接受该漏洞所造成的风险。应针对不同的漏洞处置场景，分别提供对应的、行之有效的解决措施与处置手段。

  

1漏洞修复方案漏洞修复方案库包括补丁链接、组件升级和配置修改，提供可落地执行的修复建议及方案，帮助运营者提升修复整改能力，为运营者提供不同修复方式和建议。2系统补丁修复通过安全补丁的检测以及相关漏洞的关联分析，平台以补丁视角分析漏洞，同时支持推送操作系统补丁，可自定义推送补丁文件以及修复范围，对安全漏洞进行快速消除处置。3访问控制与网络阻断平台应具备安全隔离能力，可灵活定义出入站规则，对主机进行访问控制，减少或屏蔽漏洞利用途径，在面对无法安装安全补丁的时候，提供有效的漏洞缓解能力。
