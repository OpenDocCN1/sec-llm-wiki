# 长亭科技牧云荣获“金帽子-年度优秀安全产品”奖

12月23日，由北京市经济和信息化局、通州区人民政府共同主办的2020网络安全行业生态大会暨金帽子年度盛典成功在北京成功举办。会上隆重公布了2020金帽子网络安全评选结果及中国网络安全产业100强企业名单。**长亭科技牧云（CloudWalker）主机安全管理平台**在全新发布后凭借着扎实的技术实力与市场认可再获殊荣，以总票数第一的成绩被评为“年度优秀安全产品”，同时长亭科技也成功入选中国网络安全产业100强企业。

  
  

  

本次大会共邀请了政府领导、安全专家学者、白帽子、媒体及社会意见领袖等上百位嘉宾，工业和信息化部网安局副局长张新、北京市经济和信息化局副局长潘锋，通州区委副书记刘东伟出席活动并发表致辞，共同探讨网络安全产业将迎来的重大发展机遇和广阔发展空间，见证“金帽子”和网络安全产业100强的重大发布。今年的“金帽子”评选共收录了**上百家安全厂商、安全研究者和爱好者共计70000+张的有效投票**，同时结合专家评审团的共50000张投票，评分前5的即可获得金帽子榜上提名。

  

  
  
  
  
笃实新一代主机安全能力

  

![](../Images/af6ad2fc9a0588320567318fc3de6f58.png)

  

长亭科技牧云（CloudWalker）主机安全管理平台自今年全新发布以来，就备受市场及客户的重点关注。随着网络安全态势的日趋紧张，新的网络安全威胁层出不穷，安全被要求更加贴合于业务逻辑与实际情况，主机安全产品亦然。

  

区别于传统的主机安全防护产品，牧云（CloudWalker）更加关注于新一代的主机安全能力。

*   以主机资产为核心，牧云建立了**基于设备、时间、空间、责任人属性等详尽**的资产指纹信息，主机资产的动态和持续监测开始变的有秩序感和程序化；
    
*   基于Agent，将主机安全深度检测前置，**提前对资产脆弱性进行全面评估**，同时还可全面、深度感知入侵风险，提前量+实时性，让主机安全监测覆盖攻击全链路；
    
*   此外，与其他安全防护产品的高效联动也是新一代主机安全能力的必备属性，**牧云自带轻量级蜜罐**，日常即可探测攻击行为，同时完备的API还支持与高交互蜜罐的联动，将主机安全防护能力进行高效的扩展，打造包围式监测网。
    

  

牧云（CloudWalker）主机安全管理平台还特别针对当前云时代而生，可**实现跨IDC机房、私有云、行业云、混合云环境下的部署**，多维提升安全防御能力。此次获评“年度优秀安全产品”，正是对牧云新一代主机安全能力的高度认可与价值体现。自面世以来，牧云已服务了金融、互联网、能源等多个行业企业客户，受到行业与企业的广泛支持，入选 “金融科技产品创新突出贡献奖”和“2020信创产业独角兽100强榜单“。

  

  
  
  
  
全面提升安全防护体系

  

无独有偶，长亭xray安全实验室也成功入围，被评为“年度杰出安全实验室“。xray 安全实验室主要专注于漏洞和前沿攻防检测类技术研究，以行业大佬phith0n、Koalr、K4ic 为首的核心团队成员，基于对国内安全生态改造的热爱而联手打造了致力于提供优秀安全工具的xray白帽子社区，分享各类免费安全工具如：xray漏洞扫描器、Radium 爬虫等。

  

![](../Images/b5ca475431d66e4b7ccff775aab61ee8.png)

  
  

此外，长亭科技还成功入选由嘶吼安全产业研究院发布的《中国网络安全产业100强》。据悉本次百强名单，主要从企业的公司规模、业务情况、运营情况、产品研发、投融资情况等对网络安全企业的发展跟踪分析，同时结合时事热点对于行业领域的发展潜力分析预测。长亭科技入围百强榜单成长型企业。

![](../Images/df419013a08de0c7ea399658edc1b1f1.png)坚持对技术的创新与钻研，长亭科技打造了攻(安全评估系统)、防(下一代Web应用防火墙)、查(主机安全管理平台)、抓(伪装欺骗系统)四位一体的产品体系和专业服务体系，目前已服务中国银行、建设银行、交通银行、光大银行、安信证券、中国平安、爱奇艺、Bilibili、华为等数百家知名客户，为企业客户提供全面专业的网络安全解决方案。

  

未来，长亭科技将继续坚持以技术为导向，以行业实际需求为方向，不断创新研发完善产品性能，打造更加贴合企业需求和行业发展的网络安全攻防体系，为企业用户带来更快、更精准、更智能的安全防护。
