# 12类66款产品入围央采！长亭科技实力再获国家级认可

中央国家机关信息类产品协议供货采购项目 (以下简称“央采”)，是中国政府采购领域级别最高、覆盖面最广的采购项目。采购单位覆盖中央直属上万个机关单位，对投标企业产品质量、技术实力、企业资质等各方面综合标准要求极高，审核严苛优中选优，被认为是政府采购的风向标，对地方采购同样具有重要指导意义。

  

本次采集项目主要包括计算机网络设备、视频会议系统及会议室音频系统、空调机三个大类产品，其中在二级品目“网络安全产品”中，**共包括有防火墙、网络入侵检测产品、漏洞扫描产品、主机监控与审计等37个三级品目**，基本涵盖了网络安全体系中的全流程产品。据悉本次共有340家供应商通过审核，12240款产品入围。

  

以技术实力雄厚和大佬云集而在行业中备受瞩目的长亭科技，自成立起就一直坚持“技术优先”的原则，创新研发的基于智能语义分析算法的下一代WAF，从更加AI的角度极大提升了攻击检测拦截正确率，降低漏报和误报率；以蜜罐产品研究第一梯队为始，将伪装欺骗技术应用到网络安全行业，产品可灵活部署，实现高交互包围式监测。基于产品线的不断丰富，**长亭科技提出了“攻、防、查、抓”的一体式安全塔防产品体系和专业全面的安全服务**。此次入选央采，正是对长亭科技深入研究网络安全创新技术并实践应用到行业场景中的高度认可。

  

未来长亭科技将继续坚持以技术创新提升产品能力，深入贯彻落实国家网络安全战略目标，深耕行业场景真实需求，为政府企业事业单位提供更加贴合实际使用的专业网络安全产品，高效提升网络安全防护能力，构建网络生态健康，守护网络安全空间和谐发展。
