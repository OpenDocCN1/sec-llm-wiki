# 谁搞崩了我的校园网-高校WAF安全防护最佳实践

受疫情的冲击，今年高校的大部分招生、教学工作“移”至线上，期间更多的家长、学生产生了大量的访问、点击、使用的需求，这对高校官网、教学网等响应速度和安全性发起挑战。在此期间，多所985高校出现了网站被"黑"的情况，典型的如网站被黑客挂马，用户浏览这些网站后，会感染病毒：Backdoor.Win32.IRCbot.xdo（后门病毒），导致用户被黑客远程控制和攻击。

  

肩负人才培养与重点科研项目研究工作，高校信息系统所承载的内容安全重要程度不容小觑。2019年，英国国家网络安全中心与网络服务供应商对英国部分学校进行了网络安全审计，**发现430多所学校中，有83％的学校曾遭受过网络攻击。**

  

![](../Images/66cd5304fdc72d6ec4665db73cd0401d.png)

  

面向高校的恶意攻击情况不容乐观，且高度集中在Web层面，但以高校现阶段的安全建设成熟度来讲，颇有些“难以招架”的意味。

  

> 无论是面对企图“更改期末成绩”的来自内部学生的恶搞，还是企图“欺骗学生钱财”的钓鱼攻击，或是“觊觎高校重点科研项目”的高级别攻击，**高校应用安全目前面临着困局**：
> 
> *   **网络情况复杂。**用户种类多，如教学区、办公区、家属区等，不同用户对网络需求不一样。
>     
> *   **应用系统丰富。**如教务系统、财务系统、学生档案管理系统、图书管理系统等，不同应用系统均面临着不同等级的攻击威胁。
>     
> *   **“补丁式”安全建设现状。**高校大多以发现问题-解决问题的思路进行安全防护，导致应用安全建设没有规划、更难掌握全局风险，难以应对高级网络威胁。
>     
> *   **人少活多。**网络安全管理人才匮乏，系统建设、运维安全不到位。
>     

  

打破“困局“，本期案例将结合高校应用安全建设现状，分享雷池（SafeLine）下一代Web应用防火墙在某高校的安全防护建设经验。

  

  
  
●案例●  
  

  

本期案例主角为国内某985高校，该学校现建设有两个数据中心，实现对学校内部网站及信息化业务系统的统一集中管理，对外开放了大量应用服务功能，业务种类丰富，但同时面临众多Web安全威胁。  

  

**安全建设需求**

**网络防护种类多，化繁为简。**校园网分为学生区、教学区、办公区、家属区等不同区域，学校内部学院众多，共开放了上千个Web应用，众多 Web应用框架协议大不相同，需要针对应用进行统一精准的防护。

**业务不中断，无缝衔接。**为保证各业务不受影响，需要Web应用防火墙进行无缝对接现有部署架构，实现在日常运维中平滑升级。

**把控安全运维成本，高效好省。**现有部署的传统规则性WAF在规则维护、使用性上都难以精准防护该高校的运行体系，日常运维需要实时调整防护规则，人力成本较高。

**限制流量超频次访问，全局检测。**为有效支撑校内众多诸如“考试选课”、“成绩查询”等与广大学生密切相关的Web业务，WAF要能对学生超频访问的场景有所限制。

**数据可视化，多维分析。**校园网站点较多，希望能够统一防护，实现攻击数据的全面可视化监控分析。

  

  

  

**雷池（SafeLine）部署解决方案**

  

长亭科技综合分析客户需求后，定制雷池(SafeLine)下一代Web应用防火墙防护方案，凭借其出色的能力体系，一一击破该高校现阶段应用安全防护难题。

  

*   **适配主流中间件，快速接入防御能力**
    

雷池(SafeLine)具备良好的兼容性，在网络中可无缝对接Tomcat、WebLogic、JBoss等主流Web中间件，无需自学习，即可对Web应用进行有效防御。  

*   **链路冗余，保障业务连续性**
    

为了保证高校的业务连续性，雷池(SafeLine)采用透明代理方式部署在学校网络出口，同时开启链路聚合模式，在双链路工作模式下，保证链路冗余。此外，雷池(SafeLine)硬件版本配备bypass接口，当有异常情况自动开启，保障业务正常运行。

*   **十秒升级能力引擎，一键拦截攻击**
    

该高校目前的Web站点繁多，安全管理者人员较少，因此产品要具备人性化的管理界面且简单易用。雷池 (SafeLine)摆脱了正则维护的束缚，学校内部安全运维人员无需频繁配置WAF规则，即可一键启用拦截模式，在日常运维过程中，可实现在线10秒完成引擎升级，不影响业务运行。

该学校完成部署后，雷池(SafeLine)通过智能语义分析技术判断攻击行为，准确率近乎100%，降低了WAF运维操作人员的工作难度的同时，有效杜绝了因为 WAF规则配置和管理不当而导致的安全风险。  

*   **细粒度访问控制，实时监测访客状态**
    

考虑到学校的内部有众多“考试选课”、“成绩查询”等业务 ，需要针对性的对访问频率进行有效控制。雷池(SafeLine)访问控制模块在此基础上可以细粒度到Session层面来锁定恶意访问用户，实现精准封禁。同时访问控制模块可对访问状态及访客进行实时统计并输出报告，满足该高校的相关要求。

*   **全站点覆盖，可视化数据支撑决策**
    

雷池(SafeLine)具有的二级域名配置功能，契合覆盖学校内部所有站点需求，可视化报告模板可展示多维度数据，为学校安全管理者提供全面的决策依据。 “

长亭雷池(SafeLine)下一代防火墙凭借极高的准确率、可用性和易操作性，有效提升该学校的防护水平，并在该学校百年校庆活动中表现尤为优异，校庆活动当天拦截百万次以上的实际攻击，有效保证校庆活动的顺利进行!
