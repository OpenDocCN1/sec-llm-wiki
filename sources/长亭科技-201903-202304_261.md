# 长亭科技亮相互联网之光展会 全新升级安全防护体系点亮数字经济

11月22日－24日，乌镇互联网时刻再次开启，以“数字赋能共创未来——携手构建网络空间命运共同体”为主题的世界互联网大会·互联网发展论坛拉开帷幕。长亭科技作为一家专注为企业级用户提供网络安全解决方案的公司，携**全新升级后的安全防护体系亮相世界互联网大会“互联网之光”博览会**，为企业数字经济的快速转型发展构建高效一体化防护能力。  
作为世界互联网大会“1+3”架构的重要功能板块，2020年“互联网之光”博览会聚焦互联网最新发展趋势和前沿技术动态，展示人工智能、云计算、大数据、区块链、5G等领域数字新技术、新成果、新产品、新应用，打造数字经济产业合作交流的重要窗口。据悉本次展会共有130家知名企业和机构亮相展示最新的前沿科技成果。  

![](../Images/4ee9ddf00f47f108833a9f1706a57818.png)

![](../Images/cdf703a07b8a829738f7489fe94ebfbd.png)

长亭科技携全新升级后的安全防护体系亮相

  

在人工智能、云计算、区块链、5G等新技术乘着新基建的风口快速发展之际，互联网迎来了更加强劲的发展动能和更加广阔的发展空间，万物互联的时代正在加速到来。但随着产业数字化转型升级的浪潮席卷而来，安全成为网络空间发展的基础和保障，现实和虚拟的边界正在逐渐模糊，网络攻击像张开的触手，更多的伸向现实空间。**携手构建安全、发展、责任与利益相融的网络空间命运共同体，成为信息技术发展的必然方向。**

  

  
  
**全新升级成熟化体系产品**  
  

  

网络安全的防护从来都不是单点的产品和服务，体系化的防护方案才是日益复杂网络环境下的能力体现。在今年的“互联网之光”博览会上，**长亭科技携全新升级，成熟化的体系产品亮相**，通过产品演示，系统呈现了网络安全防御体系中的产品功能与价值，为企业构建纵深安全建设提供云上云下一体化“护城河”解决方案，全方位护航企业数字化经济发展进程。

  

  

  

![](../Images/58e8d74c83c64eaa723732b9769fe3cf.png)

  

长亭科技在今年重磅推出全新升级的**牧云（CloudWalker）主机安全管理平台**，将主机安全能力前置，利用轻型探针Agent对主机进行深度安全检测，从细粒度掌握全局资产信息和变更信息，全面感知入侵风险，实时监测完整网络攻击链，覆盖ATT&CK模型12项战术场景和105项技术；同时内置了至少包括:CIDR、Domain、MD5、 IPV4、IPV6、 URL、EXP、POC全网威胁情报，提供基于更加全面的真实风险评价。现阶段的云环境下，牧云（CloudWalker）的表现也同样让人眼前一亮，可以在庞杂的混合云环境下为企业提供一个从内部观察资产安全状态的角度，实现多维管理。产品发布后已成功服务金融、互联网、政府等多家单位，**入选“2020信创产业独角兽100强”榜单，获评“入木三分”**。

  

长亭明星产品**雷池（SafeLine）下一代Web应用防火墙**，凭借着创新的智能语义分析和机器算法带来的超低误报率，打破了WAF依赖规则维护的工作原理，多次在攻防实战演习中备受好评；能够实现弹性扩展轻松满足各种新型应用场景，简单可用易扩展，已经成为当前大流量、上云企业的优选产品。

  

长亭蜜罐产品**谛听(D-Sensor)伪装欺骗系统是基于多年网络攻防经验打造的，国内最早落地的基于蜜罐技术的伪装欺骗系统**。支持真实的访问交互，实现高度仿真、高度交互的伪装服务，同时一改防守只能被动挨打的局面，专业的溯源能力为企业在面临攻击时可以实现主动出击。

  

长亭新锐产品**洞鉴（X-Ray）安全评估系统**，也是攻防体系中偏向“攻”的一款漏洞扫描应急响应产品。基于长亭安全服务团队积累的丰富攻防经验，创新打造分布式引擎节点产品架构，相较传统检测速度提升10倍的效率。近期入榜**Info Security Products Guide全球卓越奖**，荣获**Application Security and Testing（应用安全和测试）组铜奖**。

  

  
  
**产品与服务形象首次亮相**  
  

  

传统经济与互联网经济的深度融合，带来了“全民皆网民”的全新标签，互联网不再是触不可及的虚拟世界，传统与虚拟的界限正在打破，线下和线上正在全面融合。本届世界互联网大会上，**长亭科技全套产品与服务形象首次亮相大众**，以更加具象的方式进行产品的展示，简要诠释体系化的安全能力，让网络安全之光照亮企业，也可以照亮更多平凡大众的现实生活。
