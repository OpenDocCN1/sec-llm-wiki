# 长亭科技亮相江苏互联网大会，展示网络安全创新体系

11月5日-6日，由江苏省互联网协会主办的第八届江苏互联网大会在南京顺利召开。**长亭科技出席此次盛会，并在会场创新之光成果展示区展示了长亭科技网络安全攻防创新体系**，受到现场参展人员的热烈关注。

  

![](../Images/2c2967b1d7493a764e988df09be4ede2.png)

  

本次江苏互联网大会以“领航新机遇网聚新动能“为主题，大会设会前沙龙、互联网大会之夜沙龙、开幕论坛、12场高峰论坛，围绕互联网行业党建、数字江苏等主题开展讨论。首次采用“线下＋线上”模式，全方位、多角度展示江苏互联网行业新成就。

  

今年是长亭科技第四次参展，重点展示了经过多年攻防实战和行业实践总结出的网络安全攻防体系，只是被动的防御已经不再适合现今日益复杂的网络攻击环境，越来越多的企业开始注重主动防御的能力，而且安全从来都不是单一产品能够实现的，产品防护体系的价值由此凸显。通过多年对行业的深耕研究和客户反馈调研，**长亭科技创新构建了攻(安全评估系统)、防(下一代Web应用防火墙)、查(主机安全管理平台)、抓(伪装欺骗系统)四位一体的产品体系和专业服务体系**，为企业提供全方位安全防护。其中的明星产品雷池（SafeLine）下一代Web应用防火墙更是连续两年提名Gartner《Web应用防火墙魔力象限》报告，已成为超大流量、上云企业的不二首选。6年的市场检验让更多的客户选择认可了长亭，目前已服务中国银行、建设银行、交通银行、光大银行、安信证券、中国平安、爱奇艺、Bilibili、华为等数百家知名客户。

  

未来，长亭科技将继续坚持**以技术为导向，以行业实际需求为方向**，不断创新研发完善产品性能，打造更加贴合企业需求和行业发展的网络安全攻防体系，为企业用户带来更快、更精准、更智能的安全防护。
