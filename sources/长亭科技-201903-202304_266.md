# 长亭科技获评教育部产学合作育人优秀案例，共促国家安全教育落地高校

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651376257&idx=5&sn=df835524cbaedf7f5d7b2074d2416c78&chksm=8d39bb09ba4e321fc4d0325b3c2c92d2710494c4cbd0530e0157752d98d11c005ee3417bf891&scene=126&sessionid=1681376218#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651376257&idx=5&sn=df835524cbaedf7f5d7b2074d2416c78&chksm=8d39bb09ba4e321fc4d0325b3c2c92d2710494c4cbd0530e0157752d98d11c005ee3417bf891&scene=126&sessionid=1681376218#rd)

  

![](../Images/35e3332d36598baaa64b49448166375f.png)

  

10月30日-31日，由教育部高等学校网络空间安全专业教学指导委员会主办的产学合作育人论坛在湖北武汉举办，论坛中对征集评选的产学合作育人优秀案例进行了表彰。**长亭科技申请的案例顺利入选，并获评优秀案例三等奖**，这是对长亭科技积极持续促进产教融合、校企合作，构建创新产学合作育人新机制的认可与鼓励。

  

![](../Images/58dd46e87486fad4b3f11f7227007e0c.png)

  

  
  
  
  
近日，教育部发布《大中小学国家安全教育指导纲要》（以下简称《纲要》），将**网络安全与政治安全、国土安全、军事安全等16个方面作为重点领域**，正式纳入国家安全教育中，在大中小不同学习阶段全面落实，这是继“网络安全就是国家安全”基本战略后的又一重要举措。全面普及网络安全意识，培养应用型网络安全人才，已经成为当前网络安全竞争最核心也是最基础的部分。产学合作育人网络安全项目的实施，正是以企业和社会人才需求为导向，主要面向高校学生，共同培养学生网络安全综合素质和实践能力。本次优秀案例的评选也是对网络安全产学合作育人新模式、新机制的积极探索。  
  
  
  

  

此次申报的案例均是长亭科技近年来在高校中积极落地实施并有显著成效的实际案例。依托丰富的网络安全攻防经验和实践对抗能力，**长亭科技在促进产教融合、校企合作方面一直坚持践行着创新型企业的社会责任感**，积极大力推动更多优质社会资源转化为育人资源，助力高校提升高校能力和师资力量，推动培养符合社会需求工程应用和推广实用型网络安全人才。

  

  
![](../Images/b59f371f26c02c7be16c6f33d694da51.png)

**长亭科技与中国海洋大学**成立的网络空间安全研究生联合培养基地及联合安全研究实验室已在2018年秋季启动研究生的联合招收和培养，长亭科技将提供实践训练和培养指导，帮助学生在进入社会之前充分感受实战演练，实现理论与实践的有效结合；

  
![](../Images/b59f371f26c02c7be16c6f33d694da51.png)

**长亭科技还与清华大学计算机系高性能计算研究所**共建培养方案，利用自身生产条件，促进高校将科研成果尽快转化为生产力，不断提升相关产业的技术和管理水平，共同构建产学研联盟的创新体系。

![](../Images/b59f371f26c02c7be16c6f33d694da51.png)

除了与高校合作外，长亭科技在2018年走进**北京中学网络安全科普周**，用系列视频和案例科普网络安全基础知识，展示科技便利背后潜藏的安全隐患，帮助学生们养成良好的使用习惯，培养青少年的网络安全意识。

![](../Images/b59f371f26c02c7be16c6f33d694da51.png)

此外，长亭科技还利用**自有网络安全攻防交流社区平台**，为网络安全爱好者与研究者提供碰撞思维、提升技术的线上场所，吸引了大量高校学生在线上进行交流技术，同时还支持了**多场高校CTF赛事**，让高校学生在实战、比赛中对网络安全攻防演练有更深入的理解，为喜爱CTF赛事的同学们搭建成长的第一级阶梯。

  

![](../Images/0661344e64828be0fa7521904693330e.png)

  

作为一家比赛出身，多年深耕行业攻防服务的企业，长亭科技一直在致力于将自身的攻防经验传递分享出去，同时搭建一个可以交流与参与实践的平台。现阶段，网络安全纳入国家安全教育，从政策上持续发力网络安全人才培养和网络安全意识普及，**长亭科技也将深入贯彻落实，继续深化产学合作，帮助高校深化教育教学改革、提高人才培养质量，为建设网络安全强国贡献力量**。
