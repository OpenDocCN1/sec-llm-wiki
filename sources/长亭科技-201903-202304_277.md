# 长亭科技网络安全就业直通班二期开班啦

千呼万唤始出来！长亭科技网络安全就业直通班第二期在经过数月的调整和打磨之后终于正式开班啦！

  

继一期学员基本全部就业之后，我们的培训班第二期也于**10月14日**正式启航～来自全国各地的学员统一集结北京，将开启长达四个月的封闭式进修之旅。

  

本着对每一位学员负责的态度，培训班配置了实力雄厚的师资、设计了完备系统的内容、准备了高额的奖助学金。除此之外，为提高学员的学习效率，我们还安排了**极其舒适的住宿环境和十分适宜的学习场地**，保障每个人都能以最积极饱满的态度迎接未来的学习和挑战。
