# 长亭科技入选2020年中国网络安全成长之星

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651375907&idx=4&sn=9c98d2578a74e678a6dd22a5faff66e9&chksm=8d39b8abba4e31bd3fc7dce5a5bcfce18d423b5188c54763266d9a48ed9101098c1adfe4e9ff&scene=126&sessionid=1681376218#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651375907&idx=4&sn=9c98d2578a74e678a6dd22a5faff66e9&chksm=8d39b8abba4e31bd3fc7dce5a5bcfce18d423b5188c54763266d9a48ed9101098c1adfe4e9ff&scene=126&sessionid=1681376218#rd)

近日，中国网络安全产业联盟（CCIA）在“2020年国家网络安全宣传周——网络安全产业创新发展主题论坛”上首次发布“2020年中国网络安全成长之星”（CCIA成长之星）榜单，**长亭科技凭借着优质专业的网络安全产品与服务实力上榜，下一代Web应用防火墙、蜜罐和安全服务成为长亭的业务标签**。

  

![](../Images/e4fb76b583bc8a1563790f8b7d1a3cb4.png)

  

本次榜单由CCIA联合数说安全发起，共有228家网络安全企业参与，最后评选出“CCIA成长之星”30家，评价指标主要包括管理团队、外部资源、技术能力、产品竞争力、销售网络、经营数据等，此次入选是对长亭在网络安全行业发展能力的认可。  

  

**雷池（SafeLine）是全球首款基于智能语义分析的下一代Web应用防火墙产品**，它实现了对传统WAF产品革命性的创新，其基于语义分析智能化解析攻击行为的模式，打破了WAF依赖规则维护的工作原理。近年来，新基建带来的流量逐渐增大，雷池（SafeLine）能够实现弹性扩展轻松满足各种新型应用场景，且其部署方式十分灵活，可以适配复杂多样的网络环境，为企业带来更准确、更快速、更省心的Web安全防护理念。

  

**谛听（D-Sensor）伪装欺骗系统是长亭基于多年网络攻防经验打造的，国内最早落地的基于蜜罐技术的伪装欺骗系统**。谛听（D-Sensor）蜜罐支持用户自定义服务标识、伪装数据等，并支持真实的访问交互，实现高度仿真、高度交互的伪装服务；同时基于Docker架构，天然支持云端部署，全方位保障云上安全。目前已服务金融、电信等行业的多家客户，最新入榜2020年中国网络安全市场全景图“伪装欺骗”领域，受到行业和客户的广泛认可。

  

比赛出身的天然优势使得长亭科技在网络安全攻防方面有着深厚的积累与独特的经验，始终坚持以技术为重，**长亭科技逐步形成了以渗透测试、应急响应、代码审计和基线检查为主的完整的安全服务体系**，由长亭联合创始人、首席安全研究员杨坤带领，安全服务团队每年服务数百家企业机构，定制化解决方案，广受行业认可，尤其是提供的渗透测试服务有口皆碑，助力企业构建全面专业的网络安全体系。

  

没有网络安全，就没有国家安全，我国要从互联网大国向互联网强国迈进，网络安全至关重要。作为国际顶尖的网络信息安全公司之一，长亭科技将继续以最专业的安全研究和技术研发团队，不断提升自己的产品和服务，为我国网络安全行业的发展添砖加瓦。
