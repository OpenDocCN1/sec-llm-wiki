# 长亭科技获评“中国网络安全产业联盟优秀会员单位”

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIwNDA2NDk5OQ==&mid=2651375142&idx=3&sn=8f59dee25d2b9300dec6aafbc0bb4d73&chksm=8d39b7aeba4e3eb82faf02318e3742e097399063649d2544a19dde26229ea1092a1da4423151&scene=126&sessionid=1681376223#rd](http://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651375142&idx=3&sn=8f59dee25d2b9300dec6aafbc0bb4d73&chksm=8d39b7aeba4e3eb82faf02318e3742e097399063649d2544a19dde26229ea1092a1da4423151&scene=126&sessionid=1681376223#rd)

近日，2019年度中国网络安全产业联盟会员大会暨换届大会在线上成功召开。大会同时对在联盟工作中做出突出贡献的会员单位进行了表彰。长亭科技获评“2019年中国网络安全产业联盟优秀会员单位”荣誉称号。

  

![](../Images/15da556d0250a56f4076829b937b6213.png)

  

“

中国网络安全产业联盟（CCIA）由中央网信办网络安全协调局指导，旨在聚合产业势能，营造良好产业发展环境，促进产业创新发展，为推动网络安全产业做大做强，提升中国网络安全产业竞争力提供有力支撑。作为中国网络安全产业联盟的会员单位，长亭科技一直深耕行业需求，积极践行联盟服务宗旨，努力推进我国网络安全产业高质量发展。

  

长亭科技作为信息安全领域的创新企业，专注对网络安全攻防理念和产品体系进行深入创造性的研发实践，积极构建网络安全防护的全流程全方位解决方案，为企业数字化转型升级提供网络安全支撑与保障。目前，长亭科技已推出全球首款语义分析的雷池（SafeLine） 下一代 Web 应用防火墙、谛听（D-Sensor） 伪装欺骗系统、牧云（CloudWalker）  主机安全管理平台等重磅产品和多项安全服务，全面布局攻防之道，得到了政府、金融、教育、互联网等行业数百个用户的广泛应用与认可。

  

未来，长亭科技将继续坚持技术创新，契合行业发展需求，为更多的企业用户提供具有核心竞争力的网络安全解决方案，积极响应联盟组织号召，共同推进我国网络安全产业的创新发展。
