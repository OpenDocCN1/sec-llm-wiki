主动扫描能力，是考验一款漏扫产品是否“好用”的重要指标，而爬虫算法又是决定主动扫描能力的关键因素，只有全面且准确捕捉到网页中的 URL 入口，强大的 payload 和漏洞库积累才有用武之地。

2019年，洞鉴（X-Ray）安全评估系统针对用户遇到的漏扫爬虫采集目标 URL 不全的问题，创造性地提出了基于语义分析、机器学习和高仿真实时渲染 DOM 遍历算法的“新型爬虫”，在扫描过程中取得不错的效果。时隔一年，在经历企业实际复杂网络环境的检验和历练后，洞鉴（ X-Ray ）的爬虫算法再度升级，全面应对 Web 3.0时代的安全挑战。


首先让我们来看一下，爬虫在实际使用环境中受到的阻碍。


01
网页解析多样化

虽然网页采用的通用原理都是 JavaScript 解析，但此类网页远远不只 Angular、 React 、 Vue 等单页应用的 Web 框架，不同企业框架各异，带来了差异化的应对难题。


02
反爬机制导致爬取被迫终止

为了防止恶意漏洞扫描器的扫描攻击，企业在不断提升自身反爬机制和防御能力。类似的反爬策略例如使用 WAF 设置 IP 访问上限、在网站上验证表单填写速度、提交速度是否符合人为操作等，一旦判定为机器操作行为，立即被封，爬虫无法再进行任何操作。


03
网站资产日益复杂，扫描效率要求更高

一个体系庞大的 Web 网站可能拥有难以计数的 Web 资产，漏扫爬虫需要抽丝剥茧，有条不紊的巡检每一条 URL ，还要在 URL 全面采集的同时，降低无用功，提升扫描速率。


针对实际使用过程中的三类问题，洞鉴（X-Ray）多角度升级爬虫算法提升主动采集 URL 的能力。




智能动态适配各类网站



为应对 JavaScript 解析的各类 Web 网站，洞鉴（X-Ray）对高仿真实时渲染 DOM 遍历算法做了进一步优化，优化后的爬虫可以智能动态适配各种框架的网站，在模拟人的行为进行单击、输入等操作时，可以做到智能停止、返回、继续深入点击等操作，保证其有序化进行。


  • 不同Web框架场景通用化


不依赖于特定的页面布局，不依赖于 Angular、React、 Vue 等特定前端框架的具体实现，通过分析每个页面元素绑定的事件、元素的 placeholder / name / id / class / value 等属性、元素间的相对位置、元素的可见情况/重叠层次、浏览器进退控制、新窗口打开关闭控制等方法，根据元素视觉表现，自动调整爬取策略，还原一个真实用户面对未知页面时的种种行为。


  • 爬取顺序规律化


在深度和广度层面加入智能有序化规则，保证爬虫点击操作时的层次感，避免点击错乱、爬取过程无尽循环、无法收敛等问题。

高交互仿真爬虫提升检测效果



为应对反爬机制，安全评估工作向着“人工”驱动方向发展，但依靠“人工”手动进行安全检测时，成本、效率与最终评估效果难以平衡，因此一个“类人”的智能自动化检测工具成为网络安全评估工作中大家企盼的“理想国”。为了无限接近“类人”的检测能力，洞鉴（X-Ray）从算法根本进行优化，提升爬虫的仿真性，在环境仿真、交互操作和性能效率等方向作出提升。


  • 环境仿真性的提升


Headless 浏览器技术能够天然规避基于 Selenium、PhantomJS 的测试框架下爬虫易检测的特点，然而，Headless 环境和实际环境依然存在差异性，仍可能存在相关特征，从而被反爬策略识别并限制。


在未进行仿真算法提升时，爬虫容易被反爬策略限制，URL 的检出效果则会大打折扣。相关爬虫的检测结果样例如下图：



对此，洞鉴（X-Ray）对比环境差异，优化仿真性，抹去相关特征，内置真实浏览器最大限度模拟真实用户使用环境，大大提升了 URL 的检出效果。检测结果样例如下图：



  • 交互仿真性的提升


洞鉴（X-Ray）从点击速度、输入速度等细节上，提升人为操作的仿真度，无论是模拟真实的鼠标指针的点击操作（触发 click/mouseover/mousedown/mouseup 等细微操作事件）时，还是模拟真实的键盘输入操作（判断每个输入框究竟应该填写的内容，是手机号、邮箱、密码）时，都更接近人类的行为特征，能够有效绕过反爬策略机制。

检测性能效率提升



采用模拟浏览器爬虫算法，因为其仿真性和 URL 覆盖率提升，通常会消耗更多的时间和资源。洞鉴（X-Ray）此次爬虫算法的升级，经过以下方向优化调试，在保证资源可控的条件下，最大化保证模拟浏览器爬虫的检出效率，使“鱼”与“熊掌”可以兼得！


  • 并发爬取。洞鉴（X-Ray）可多窗口同时处理多个页面的响应，由原来模拟一个人的操作行为，升级为支持可控制调整为模拟多个人同时操作的行为，从而降低对一个网站完成URL采集所需的时长。

  • 过滤无效 URL。洞鉴（X-Ray）经过 bloom 过滤器、set 请求参数过滤、正则匹配等分析手段，对冗余 URL 进行过滤，不加载非必要静态资源，避免对重复内容进行多次冗余计算，避免对硬件资源以及带宽造成不必要的消耗(如图片加载请求、文件下载类请求)。
