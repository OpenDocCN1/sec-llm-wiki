# 长亭推出深度安全网关，完善高效智能安全防护体系

随着互联网的高速发展，攻击者的性质发生了变化，从个人“炫技”逐渐渗透到各行各业，给企业造成的影响也随之变大。与此同时，攻击事件与利益也直接挂钩，甚至催生了完整的黑色产业链，攻击者开始组织化，攻击更加规模化、持久化，破坏性越来越强，如**乌克兰电厂、希拉里邮件门、斯诺登事件等严重事件频发**。

  
  
  
  
  
攻击性质的改变直接导致了攻击方式的进化，随着攻击复杂性、多元化不断提升，传统安全设备受到更加严峻的挑战。攻击手段已从传统的僵木蠕、DoS等，向APT、组合攻击、0day等这些新型手段转变，这类攻击无法通过恶意程序签名或者过去的攻击技术报告进行检测，由此就造成了攻防不对等。单独依赖防火墙、入侵防御系统和反病毒软件，已无法有效防御这些攻击。

  

  
  
  
  
**长亭深度安全网关，安全高效实现智能防护**  
  
  
  
长亭科技推出长亭深度安全网关，采用先进的高性能多核架构，搭载接口丰富的硬件平台，结合智能路由等全面的网络层支撑以及双机热备，保障业务处理高效可靠，实现场景支撑灵活全面，同时配备具有入侵防御和独特实时病毒拦截技术的病毒防护功能，通过并行处理的安全检测引擎和应用识别功能，实现对用户、应用和内容的深入分析，**为用户提供安全智能的一体化防护体系**。

![](../Images/ee2eca1f38735fac13e094f282fe2e29.png)

长亭深度网关核心功能

*1*全网威胁情报，未知风险可防护

  

  

长亭深度安全网关使用自主研发威胁情报平台，通过预知风险的方式消除信息不对等，将威胁检测及情报处理能力落地，**降低平均威胁检测时间（MTTD）和平均威胁响应时间（MTTR）**。系统通过分析IP信誉、DOMAIN信誉、URL信誉、文件信誉（MD5/SHA）、最新攻击事件、攻击趋势与防范措施等多种威胁情报数据指标，**提升下一代防火墙、入侵防御系统、安全网关等技术的主动防御能力**。

  
  

#   

*2*灵活高效全面，场景支持更丰富

  

  
长亭深度安全网关具备领先的**多核架构及分布式搜索检测引擎，配合高性能的处理器，能够多业务并行处理**，确保在各种大流量、复杂应用的环境下，快速高效实现安全服务。系统搭载**自主可控的防火墙系统**，融合丰富的网络特性，**在满足IPv4/IPv6双协议栈的同时配合智能路由和DDNS等**，可在802.1Q、RIP、OSPF等各种复杂的网络环境中灵活组网，同时具备与第三方系统对接的能力，**实现数据共享从而提升业务价值**。  

  

*3*专业智能引擎，立体防护更安全

  

  
长亭深度安全网关集拥有超过**4000种预定义攻击特征的入侵防御功能**，集海量病毒特征识别的实时拦截技术及拥有高效引擎的病毒防护功能于一体，实时对流量进行分析，从数据链路层至应用层有效阻断网络中的攻击和病毒行为，全方位立体保护用户关键数据，避免机密文件泄露造成经济损失。  

##   

*4*数据深度识别，行为管控更细致

  

  

员工上班时间进行业务无关的行为无疑会降低办公效率，如果不慎发表不正当言论，将会给企业单位带来舆论风险，对形象声誉造成负面影响。系统采用**DPI/DFI融合识别技术**，通过对用户流量进行全面分析，**深入识别应用内置动作**，可针对微信识别多达12种行为动作。

  

  

*5*带宽优化管理，用户体验更迅速

  

  

长亭深度安全网关能帮助组织管理者透彻了解组织当前及历史带宽资源的使用情况，可在工作时间保障核心用户、核心业务所需带宽，限制无关业务对资源的占用，并于空闲时动态分配带宽资源，实现资源的充分利用，提升用户使用网络的体验。**其特有的流量限额和时长限额功能可区分用户权限，实现差分服务，助力企业营销**。

  

  

*6*集中统一管控，网络运维更便捷

  

  
**长亭深度安全网关采用一体化安全策略，使用方便，维护简单**。管理员只需通过一条策略便可统一管控应用、网址、入侵防御、病毒查杀等多项内容。在大规模部署时，管理员可配合集中管理系统，对分布部署的长亭深度安全网关进行零配置上线、统一策略管理、业务变更自学习、攻击事件监控、攻击事件分析、报表分析等操作，可极大降低网络更换难度进而简化繁琐的运维任务。
