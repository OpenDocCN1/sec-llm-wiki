# 长亭出席欧洲最大规模安全会议，现场分享The Great Escape of ESXi

![](../Images/0efe2977d4e53112858d3f4f91475e19.png)12 月 27 - 30 日，刚刚过去的圣诞 + 新年，36C3 大会在德国莱比锡正式启动，聚集了上万名技术的狂热爱好者，用他们自己的方式庆祝着这一神圣时刻。为期四天的活动吸引了来自世界各地的电脑高手和黑客精英，长亭科技高级安全研究员张焱宇（f1yyy）携虚拟机逃逸议题 The Great Escape of ESXi 进行现场分享，吸引了众多顶尖技术人员的关注。

![](../Images/b0e6a1c493381c10c7aacefb825f2ecf.png)

这一盛会始于 1984 年，全名是 Chaos Communication Congress，简称 CCC 或 C3，在国内也被称为“混沌通信大会”，由欧洲最大的黑客联盟组织“德国混沌电脑俱乐部”主办，与 DEF CON 齐名，是全球最大型、最具影响力的黑客大会之一。因为刚结束的这场正值第 36 届，所以全球通用简称为 36C3。大会拥护安全，对一切技术创造与社会运作持怀疑态度，互相争论、辩驳、分享，从而迸发出无数的创新火花。

![](../Images/7bbac4bbbad44a383ca357f2e3cd1085.png)

张焱宇（f1yyy）本次分享的 “The Great Escape of ESXi” 这一议题主要围绕 VMware ESXi 展开。

众所周知，VMware 在全球私有云市场占有率位列第一，为全球财富 100 强与 90% 以上的 1000 强公司提供私有云服务。而 VMware ESXi 是用于部署和服务虚拟机的企业级 1 类 bare-metal hypervisor，在企业的云基础架构中扮演着核心角色。其用于部署和服务虚拟机，也是 VMware 企业私有云服务中直接与硬件交互的一层。该平台使用了 VMware 自己开发的 VMkernel 用于构建更快速和更安全的虚拟化环境。ESXi 中的漏洞可能会破坏 Guest 和 Host 之间的安全边界，从而导致虚拟机逃逸，成功利用可 get root shell，将严重影响私有云安全。

2018 年极棒赛事上，在诸多挑战项目中，张焱宇（f1yyy）全球首次成功挑战 VMware ESXi 虚拟机逃逸项目，获得极棒名人堂荣誉及“最佳技术奖”。尽管之前有一些逃逸虚拟机的尝试都针对 VMware workstation，但直到长亭科技在 GeekPwn 2018 上成功演示之前，都没有公开的 VMware ESXi 逃逸案例。这主要是由于 ESXi 已采用沙箱机制，使用了其自定义文件系统和内核。腾讯安全玄武实验室负责人于旸曾比喻为：因为本身虚拟机技术设计的目标就是把你隔在里面，就像一个牢笼，牢笼的目的是隔离，而我们要逃逸出来。在本次的精彩演讲中，长亭科技高级安全研究员张焱宇（f1yyy）特别分享了对 ESXi 中安全增强功能的研究，并讲述及演示了如何发现并使用多个漏洞来逃逸在沙盒中的虚拟机。“云时代”的虚拟机安全被提升到至关重要的位置。虚拟机逃逸攻击已经可以影响云上用户的根本安全，成为不得不应对的严峻威胁。自 2016 年 Pwn2Own 破解大赛增设虚拟机逃逸项目以来，国际知名虚拟化软件 VMware 吸引了全球众多安全研究人员的注意力。作为世界范围内为数不多的虚拟化漏洞的研究者，长亭科技将持续输出研究成果。![](../Images/991ab0154d70f54a0cc4d38805386801.png)
