蜜罐 2.0 背景下

欺骗伪装技术（Deception Technology）

正焕发新生

传统的网络防御方式是“拒之门外”，企业在网络边界或者区域之间部署多种安全设备保护核心资产。但“世上没有不透风的墙”，随着攻击手段的飞速发展，企业网络被攻击者攻破的状况时有发生。

数据显示，在已经部署基础网络安全防护产品的前提下，49% 的被调查企业在过去一年内曾发生过一次或多次的网络安全问题；在这些已经发生的安全问题中，56% 是由外部攻击者的攻击导致的。居高不下的安全问题，成为了企业考虑增加部署更新、更有效的网络安全防御产品的有效驱动力。

欺骗伪装技术（Deception Technology）的一些特性，让蜜罐类产品越发成为高风险行业安全团队增加安全防御产品时的首选：
1、通过制造伪装真实服务的系统或应用来欺骗攻击者；
2、正常的访问不会触发蜜罐，因此，一旦蜜罐被触发，企业安全人员极易定位安全问题；
3、伪装真实服务的数据或应用基于“反侦察技巧”构建，欺骗性与迷惑性极高，不会轻易被攻击者识破。

Never Tell A Lie, Unless It’s To An Attacker.


升级一
应用场景更多元化


谛听（D-Sensor）伪装欺骗系统基于欺骗伪装技术，创新升级多种攻击者应对方式，高度适配企业业务场景和安全防御需求，从内网到外网，帮助企业用户在多种场景中解决问题，提升企业安全防御中的主动对抗能力。

场景一：感知外网信息嗅探

针对性越强、力度越大的攻击，往往是攻击者谋划已久的结果。攻击者在确定发起正式攻击前，会利用多种渠道收集目标的信息，包括目标的域名、IP 地址、操作系统类型、编程语言、版本等。在这过程中，企业对外提供的 Web 服务往往会成为突破口，攻击者利用服务的漏洞或管理的疏忽乘虚而入，获取权限或潜伏等待机会，进而掌控整个区域，不断窃取数据。

面对外网嗅探，谛听（D-Sensor）升级应对方式，转移攻击目标保护真实资产，同时收集信息，预判攻击行为避免损失，实现身份溯源。

 

干扰攻击路线，保护真实资产


互联网诱饵：在网络犯罪分子收集目标信息阶段，在公开区域暴露虚假信息（如虚假的项目名称、项目描述，IP 和用户名、密码等），引导网络犯罪分子攻击蜜罐而不是真实服务。


高仿真 Web 类蜜罐+真实漏洞：如果网络犯罪分子没有踩中诱饵，在他们入侵时，谛听（D-Sensor）的高仿真 Web 类蜜罐可高度仿真用户的真实业务，并且内置了真实漏洞，往往比真实服务“看起来”更加脆弱，当然也更有吸引力，从而干扰攻击视线。


虚假信息：谛听（D-Sensor）通过在蜜罐中设置虚假信息（如虚假邮件、虚假项目信息、脱敏的虚假数据等），让蜜罐更有黏性，让网络犯罪分子难以分辨。

预判攻击行为，避免损失


谛听（D-Sensor）可以捕获和分析网络犯罪分子的攻击行为，比如一些基于 0day 漏洞的 APT 攻击，进而帮助用户了解企业安全体系的缺陷，有针对性的补短。

精准身份溯源，主动制裁

在网络犯罪分子入侵到蜜罐时，谛听（D-Sensor）可以溯源到网络犯罪分子的设备指纹、地理位置、社交帐号等信息，协助网警快速定位攻击者身份和位置，精准打击网络犯罪。



场景二：遏制内网横向移动

由于意识薄弱或者疏忽大意，企业内部的工作人员可能会下载恶意软件或者访问网络犯罪分子挂马的网站，给了网络犯罪分子控制内网主机的机会，接下来，勒索、挖矿等安全事件会接踵而来，网络犯罪分子会横向移动控制更多主机，获取更多利益。

对于已经潜伏到内网的攻击，很多安全产品往往束手无策，很多企业也通过断网或者重装系统等方式解决问题，但收效甚微。
谛听（D-Sensor）应对方式：
大范围部署探针


通过在内网大范围部署探针，谛听（D-Sensor）可以监听多个 IP 的多个端口，探针在感知到攻击者的横向移动后，立即向安全运营人员发出告警，快速定位被控制的主机。

组合蜜罐


如果安全运维人员没有及时处理，谛听（D-Sensor）还可以利用操作系统蜜罐+系统服务蜜罐+数据库蜜罐组合的方式欺骗攻击者，吸引网络犯罪分子去控制虚假的主机，访问虚假的服务，获取虚假的数据。
主机诱饵


将诱饵部署在真实主机上，有助于达到更好的欺骗效果。一旦主机被控制，暴露给网络犯罪分子的将是虚假信息，比如虚假的历史操作命令、SSH 连接记录等，信息中会暴露蜜罐的地址，将攻击引导到蜜罐中。

虚假文件

在蜜罐中设置虚假的文件也会提高蜜罐的黏性，根据业务特点，将一些运维记录、人员名单等文件放到蜜罐中，安全运维人员能争取到更多的应急响应时间。


场景三：防止内鬼窃取数据和破坏系统

据安全公司迈克菲调查显示，43% 的数据泄露都来自内鬼。不同于网络犯罪分子的内网漫游，内鬼因熟知企业网络架构，往往有明确的攻击目标，他们会在同网段扫描并随时准备横向移动，进而有针对性地利用漏洞、绕过防御、获取权限、在短时间内窃取数据或者破坏系统。

谛听（D-Sensor）应对方式： 
大范围监听探针：探针能第一时间感知内鬼的资产探测行为并及时告警。
自学习蜜罐：根据企业业务生成更为真实的伪装，吸引内鬼攻击，间接保护真实资产。

升级二
基于 Docker 架构升级云端部署


针对当前各行各业业务上云的需求，云上安全（威胁感知&伪装欺骗）重要性与日俱增。谛听（D-Sensor）伪装欺骗系统基于 Docker 架构，天然支持云端部署，能够实现所有业务上云。Docker 同时具备轻量化、资源占用量少的特点，能够伪装更多类型的业务，构建更灵活的蜜网。
三大升级方案全方位保障云上安全 ：

支持探针部署在云端

支持蜜罐服务和管理节点上云

支持在云上组蜜网


升级三
适配更多行业需求

蜜罐技术做为安全工具已经有了近 20 年的发展。欺骗伪装类产品若要更好的发挥主动防御作用，就必须更贴合高风险行业的定制化安全需求，适配不同行业的业务特性，便捷部署与管理，适应愈发复杂的网络环境和架构。 
丰富行业型蜜罐：高风险行业定制专属蜜罐，实现更具针对性的伪装。
自定义服务类蜜罐：学习行业特性从而适配业务，包含业务学习式蜜罐、自定义 Web 页面蜜罐、自定义 TCP 响应蜜罐等。
架构更加灵活：适应不同行业的复杂网络环境，集中管理平台实现统一管理。
安全本身就是攻守双方互相博弈的过程，知己知彼方能百战不殆。
