# 长亭雷池 (SafeLine) 入选 Forrester 报告，获评 WAF Specialist

近日，全球权威市场研究与咨询机构 Forrester 发布了最新研究报告《Now Tech：Web Application Firewalls, Q4 2019》（以下简称“报告”），对 Web 应用防火墙（WAF）市场的 31 家知名企业，从市场规模、功能表现两大维度进行了综合评估。**长亭科技雷池（SafeLine）下一代 Web 应用防火墙，凭借出众的技术创新和在实际应用场景中的亮眼表现脱颖而出，成为五家入选的中国企业之一，得到了国际权威研究专家的高度认可**。 

![](../Images/b626b1ee60786b327e80975522a2c5d0.png)

如今，WAF 的功能已经拓展为跨越私有云、混合云、公有云，并为包括服务器端的移动应用在内的 API 提供保护。![](../Images/8e0b8f9fb54a37b235d378ca149f653e.png)![](../Images/087fb478170aed5a040e410aec2e8f72.png)

Forrester 认为，无论是错误配置还是尚未部署 WAF，都是造成近期一系列重大漏洞事故的症结所在。而这些“失误”也再次唤醒了企业对应用程序保护的重视：

首先，WAF 不能缺位，企业必须部署；

其次，无需盲目迷信大厂商，应根据特性功能选择与业务相匹配的 WAF 产品；

最后，始终将 WAF 作为初始应用程序保护技术，并在此之上继续构建其他应用保护措施。![](../Images/087fb478170aed5a040e410aec2e8f72.png)

  

此外，Forrester 还预测，到 2022 年，全球企业对 WAF 的总支出额将超过 10 亿美元。在报告中，Forrester 将 WAF 定义为：用于检查 Web 应用程序和 API 的输入和响应工具，以检测和阻止漏洞利用或攻击尝试，并会基于攻击特征、协议标准和异常检测来执行安全策略。

基于供应商提供的服务和产品形态及能力，报告将 31 家入选企业划分为四类阵营，分别是：

一、边缘网络 CDN WAF（CDN-adjacent WAFs guard on the network edge）；

二、云服务 WAF（Cloud-provider-adjacent WAFs offer protection as a cloud service）；

三、负载平衡 WAF（Network-performance-adjacent WAFs originated as part of load balancing）；

四、专注提供第七层防护的 WAF 专家（WAF specialists offer layer 7 protection as part of a security portfolio）。

  
长亭科技本次入选的雷池（Safeline），属于 WAF specialist 维度的领先产品。报告同时指出，**雷池（SafeLine）在金融、科技、互联网、能源与公共事业领域均备受认可，代表客户涉及众多国内知名企业，包括多家位于全球 500 强前列的大型商业银行，以及国内领先的互联网品牌**。

雷池（Safeline）是全球首个基于智能语义分析算法的下一代 WAF 产品，区别于传统的基于特征库和黑白名单机制的拦截原理，雷池（SafeLine）不止步于词法、语法的语言维度，而是更深入的完成了语义分析和威胁建模的过程，使检测的精准度和智能防护水平大幅提升。步入“云”时代，雷池（SafeLine）无论是应对私有云、公有云，还是混合云，都有灵活应变的部署防护模式，可帮助用户灵活配置网络环境。

![](../Images/dfe4ea8ab89a9e787aaeeaf856bdd59a.png)

自 2016 年首次亮相以来，雷池（SafeLine）就凭着出色的技术创新和防护表现在国际上屡获殊荣。 

**2017 年初，雷池（SafeLine）成功获得推选，在美国纽约时代广场大屏上亮相展示，被称为“改变世界网络安全的中国新力量”；****2017 年末，雷池（SafeLine）一举通过 OWASP “Web 应用防火墙基准测评”，获得由 OWASP 和国家互联网安全研究中心联合颁发的 Web 应用防火墙认证证书；******2017 年至 2018 年，雷池（SafeLine）连续两年提名 Gartner《Web 应用防火墙魔力象限》报告，并入围 Gartner 2018 年《Web 应用防火墙魔力象报告（亚太版）》，充分得到业界认可；******2019 年初，长亭科技凭借以下一代 Web 应用防火墙雷池（SafeLine）为核心的应用安全解决方案，入选 IDC《中国 Web 应用安全市场》报告潜力厂商。**作为一款既年轻又经验丰富的产品，经过三年来的沉淀，雷池（SafeLine）已经为众多企业保驾护航，有效应对数字经济时代层出不穷的网络应用威胁。未来，长亭科技还将继续关注用户的诉求和市场的变化，以技术创新和解决行业瓶颈难题为发力点，推出更多颠覆式的技术和创新性的产品，为客户创造更多价值，成为推动整个行业升级转型的新兴力量。
