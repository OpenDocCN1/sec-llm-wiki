# 长亭雷池 (SafeLine) 斩获 2019 关键信息基础设施“盘古奖”

12 月 26 日，第二届金融关键信息基础设施保护论坛暨 2019 关键信息基础设施安全优秀产品、解决方案颁奖仪式在京举办。**长亭科技雷池（SafeLine）下一代 Web 应用防火墙，凭借领先的技术优势、广泛的客户案例，以及出色的实践表现，从 238 个参评项目中脱颖而出，一举斩获优秀产品之技术创新“盘古奖”**。  

![](../Images/18c0f85c43d3182bf5fbc1ae6b6eb279.png)

据悉，此次评选由中国关键信息基础设施创新联盟发起，旨在发掘行业领先的产品和具有重要价值的创新技术，从而为整个相关行业的网络安全建设提供前沿洞察和技术支撑，评选结束后会出版《2019 关键信息基础设施优秀网络安全产品和解决方案推荐手册》，助力关键信息基础设施行业用户更好地甄选和部署最前沿的产品和解决方案，有效应对未来层出不穷的网络威胁。

![](../Images/e4b036b325fb80b586b1bf8c0fab9f40.png)![](../Images/7a586a434311aa5b8ec126011b962a53.png)本次评选荣膺“盘古奖”的雷池（SafeLine），是全球首个基于智能语义分析算法的下一代 WAF 产品，一举打破了传统 Web 应用防火墙依靠特征规则进行攻击检测的局面，变被动防御为主动识别，灵活支持软件、硬件、虚拟机、云端等不同需求，提升防御性能的同时解放人力，致力于用高性能 WAF 为关键信息基础设施的应用安全保驾护航。截至目前，雷池（SafeLine）已累计服务上百家客户，除了关键信息基础设施的相关企业外，也不乏全球流量 Top 100 的大流量视频网站、国内 Top 级别手机厂商、大型国有银行、大型股份制商业银行、证券公司、交易所、世界 500 强通讯企业、双一流高校等知名机构和企业，日均检测请求上亿次，拦截攻击千万级，为客户的门户站点、交易系统、管理平台等业务服务提供 7X24 小时贴身防护。未来，长亭科技将继续创新，深耕行业，为包括关键信息基础设施在内的各个领域贡献积极力量。![](../Images/f9c68919a60b9c79402b8b2b19b24890.png)
