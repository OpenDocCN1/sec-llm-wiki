# 长亭科技杨坤：金融网络安全形势及应对

随着金融业向移动化、数字化和智能化加速发展，金融网络安全保障也面临前所未有的挑战，APT 攻击、数据泄露、勒索病毒等网络安全事件频繁发生，网络威胁风险持续升级。当前，**金融网络和信息安全呈现哪些特点？****我国金融企业安全建设存在哪些痛点？**日前，国内新锐的网络安全公司长亭科技安全服务中心负责人杨坤博士在近期的访谈中，分析了金融业网络攻击态势，提出结合攻防实战的应对思路，阐述了 IT 国产化推进趋势下国内安全厂商的机遇和挑战。

**金融网络安全形势解析**![](../Images/3b47c42163055010542bc7360d16d65e.png)![](../Images/8e0b8f9fb54a37b235d378ca149f653e.png)![](../Images/087fb478170aed5a040e410aec2e8f72.png)近年来，网络攻击已经成为金融犯罪的重要手段，金融网络安全事件频繁发生：▪  2019 年 7 月，美国第一资本银行的 1.06 亿客户信息被黑客窃取；▪  2018 年 10 月，美国汇丰银行受到网络攻击，约 1% 的客户信息被泄露；▪  2018 年，“Denis.K”团伙通过钓鱼邮件控制 ATM 设备，造成 40 多个国家的银行、总计 10 亿美元的损失；▪  2019 年 7 月，日本加密货币交易所 Bitpoint 被黑客攻击损失了约 3200 万美元的加密货币，中国台湾远东国际商业银行被黑客窃取约 6000 万美元；▪  ……![](../Images/087fb478170aed5a040e410aec2e8f72.png)

金融机构成为网络犯罪分子的首选目标。同时，针对金融行业网络攻击特点表现为以窃取金钱为首要目标，窃取信息和数据为次要目标。  

从攻击的手段上看，可以划分为三个等级：

**一、****互联网扫描攻击**，其特点是范围广，以多地控制设备、获取权限为目标——金融企业互联网上的资产面临被全网扫描的风险。此类攻击的手段比较初级，防护相对简单。做好公开漏洞及时打补丁、管理好互联网出口、不把太多资产暴露在互联网中等基础安全防护工作即可。

**二、****普通黑产攻击**，此类攻击目标明确，具有指向性，攻击团队一般具有一定的漏洞挖掘能力以及深入纵向攻击能力，如渗透到某一家金融机构的内网获取更多权限、获取数据、盗取资金等。对于防护者来说，除了基础工作，还要建设防护监测响应体系。目前大多数金融企业都已经开展了相关的工作，差别在于体系健全程度、系统响应速度、应用延迟时间等。

**三、****APT 级攻击**，此类攻击潜伏时间长、技术能力高超、攻击手段隐蔽。APT 是一种有目标有组织的攻击方式，在流程上它是与普通的攻击行为没有明显的区别，在攻击步骤上具有“采用 0day 漏洞获取权限、通过不知名的木马来进行远程控制因而难以提取攻击行为特征、较强的单点隐蔽能力、多样化的攻击渠道、攻击持续时间长”等特点，使得传统以实时检测、实时阻断为主体的防御方式难以有效发挥作用。金融企业的防护体系大都不可避免存在盲区，APT 长期跟踪发现安全漏洞，隐蔽的破坏性极强的高级攻击技术给金融行业带来极大安全挑战。

从发展趋势上看，**金融 Web 应用和移动客户端仍然是重灾区**。面向金融生态链的攻击日益增多，针对开源组件的攻击成爆发趋势，攻击者更多的使用定制化工具，“羊毛党”造成的损失日益严重，新技术的应用也同时带来新的风险。

此外，日益复杂的国际环境使得国家级网络对抗随时可能发生，金融行业重要信息系统关系国计民生，更易成为攻击对象。

**结合攻防实战的应对思路**![](../Images/3b47c42163055010542bc7360d16d65e.png)

传统金融机构通常在物理、数据、网络、系统、应用、终端等层面分别部署各种安全设备、应用不同的安全技术，一方面设备与设备之间、技术与技术之间缺少智能联动；另一方面设备的最优使用方法，人员、组织配合等未经实践验证，设备负责人也不具备实战日志分析能力等。上述问题迫使金融机构重新思考如何转变安全体系的验证思路。

**网络安全防护需要立体化的纵深防御，但网络攻击只需要突破一个薄弱点即可**。面对 APT 级别的网络攻击，需要金融企业具备更高的综合分析和研判能力，而模拟实战的方式是提升防护水平、找到安全漏洞、发现真实问题的最有效的安全体系检验手段。对于金融机构而言，传统的安全验证思路（法律法规、国家标准、监管要求、国际标准规范与安全检查、漏洞扫描、基线检查、渗透测试等安全手段相结合的小规模、独立作战的安全检测）应向 APT、组织型，甚至国家层面的常态化攻防演练的新的验证体系转变。

具体实施策略，首先是**防护体系规划**，包括人员组织、流程制度和技术措施三方面工作。

其次，**攻防演练**划分为事前准备、事中保障、事后总结三个阶段。其中，事前阶段覆盖现状分析、评估加固、模拟优化流程，实现能力提升；事中保障由防护、检测、响应三个环节组成，防护指防火墙、WAF、IPS、安全网关、杀毒等边界设备，检测指入侵检测、蜜罐、扫描工具、威胁分析等技术手段，响应指日志分析与审计、脆弱性分析与管理、安全设备联动处置等；事后总结包括演练结束后要进行完整记录、汇总分析并进行针对性改进。最后，**建立分级应急响应体系**（如下图所示）。由于可能存在过度防御的情况，同时，企业也不可能始终保持高度紧张战备状态，制定分级应急响应体系策略成为一种很好的解决方案。根据目标对象的重要程度将安全措施分为特级、一级、二级、三级，以整体技术为基础，在管理层面调整应急响应体系的等级，如真实网络空间安全事件为特级，国家级别演练为一级，监管检查为二级，内部验证为三级等。

**长亭科技金融安全思考和实践**  

长亭科技认为，安全的本质是攻防。 

首先，****安全技术的发展离不开攻击和防守双方的博弈****，正是这种博弈促进安全技术不断向前发展。

其次，****安全是新技术发展的前提****。新技术发展之初一定要重视安全建设，缺乏应对攻击的手段和策略的新技术将难以为继，功亏一篑。

最后，****安全防护的未来在于数据和算法******。**由一个个单独的产品或技术组装成防御体系，架构松散，很容易给攻击者带来可乘之机。要实现对安全的整体把控需要企业内外部数据的支撑，而如何在海量数据中发现异常则需要算法的支持，数据是视野，算法是大脑，两者高度结合才能构建全面的防御体系。

  

基于上述思考，长亭科技致力于为金融行业提供体系化智能防护，一是从安全防御和业务发展角度出发，充分考虑安全建设价值最大化；二是从关键防护环节入手来构筑企业应用安全塔防体系，提升投资回报率；三是提升安全技术能力，完善安全保障机制，有效支撑安全防护体系运转；四是通过产品自动化+人工服务辅助，及时发现并补齐企业安全短板。

![](../Images/f9a0638e99e9f7f172d4a68f7a8f0fbd.png)

  

安全产品包括，**下一代 Web 应用防火墙雷池（SafeLine）**：采用前沿的智能语义分析算法，能够基于上下文逻辑实现攻击检测，提升准确率，降低误报率。**安全评估系统洞鉴（X-Ray）**：集合资产识别与漏洞验证，以攻击者视角精准评估系统安全风险。**安全实训平台墨攻（Reversi）**：全方位、一体化的网络安全人才培训平台，在实战中提升企业安全人员的安全素质和技术能力。**内网威胁感知系统谛听（D-Sensor）**：利用欺骗伪装技术，解决内网防护难以察觉、难以明确、难以追溯三大问题，赋予内网全新的主动对抗能力。**服务器安全平台牧云（CloudWalker）**：基于 Agent 的深度服务器工作负载安全平台，帮助企业提升资产能见度并有效防御入侵。

  

安全服务，以实际攻防效果为出发点，提供网络安全相关的全生命周期的服务，包括准备阶段：系统规划、建设咨询、人员能力提升；运营阶段：验证、整改和加固、值守和运营服务，其中验证包括安全意识、安全基线、渗透测试、代码审计、攻防演练等。

当前，全球步入以信息产业为主导的经济发展时期，网络空间作为与海陆空并列的人类活动第四空间，已经成为维护国家安全的战略要塞。相对于基础设施，安全产品由于涉及数据等国家敏感资产，国产化的需求更为迫切，而国外产品本地化能力不足，服务支持不到位也给国产安全企业带来机遇。对长亭科技来说，始终将研发国际领先技术放在首位，以过硬的产品和服务提升中国网络安全水平为己任，在国产化推进过程中，用成熟可落地的解决方案满足金融企业政策要求的同时，提升安全防护能力。![](../Images/f9c68919a60b9c79402b8b2b19b24890.png)
