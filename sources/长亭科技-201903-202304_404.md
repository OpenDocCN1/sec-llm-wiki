Android 十年，十年漏洞史。随着 Android 的进化，攻击面发生了怎样的改变？Fuzzing 和静态分析的技术上又有怎样的变迁？一个典型的 Pwn2Own fullchain 又是怎样诞生的？虽不免挂一漏万，此议题将为大家分享演讲者的观察和实践。

**智能安全在 Web 防护中的****探索和实践**

  

**<** 赵征/kcn **\>** 阿里云安全技术专家**<** 刘添龙 **\>** 阿里云安全算法专家有关 Web 防护的讨论经久不衰，近年来 AI 赋能安全也成为了安全行业的一个热门话题。从去年开始，我们在智能安全领域里有一些新的突破和工程化实践，并且取得了不错的成果。本次议题将介绍我们在结合数据智能和安全，去对抗 Web 攻击过程中的一些摸索和心得，从机器学习到深度学习都有涉及，希望可以给相关领域的听众一些收获和启示。

4

**使用差分重放检测内核信息泄露 **

  
**<** 杭特 **\>** 阿里巴巴安全部基础技术研究负责人内核信息泄露会导致本地提权，其检测一直是一个难题，尤其是针对闭源系统。目前最好的检测方式为 Google P0 团队的 Bochspwn Reloaded 和 Bochspwn Revolutions，虽然发现众多，但其检测精度不够，漏报较多。我们利用差分重放发现内核信息泄露漏洞，共发现微软漏洞 34+，获 CVE 编号 21 个，中稿安全学术顶会 CCS2019，是该会议成立 26 年以来国内首次中稿的企业论文。

  

5

**Bilröst 揭秘：****VMware Fusion REST**

** API 漏洞分析**

  
**<** 周智/CodeColorist **\>** 蚂蚁金服光年安全实验室安全专家虚拟化软件最常见的攻击面是客户机逃逸，但年初发现的一个有趣的 VMware Fusion 漏洞 CVE-2019-5514 却打破了这种刻板印象。通过物理机浏览恶意网页，可以稳定地在客户机内执行任意代码。通过逆向分析这个看似 Web 安全的问题，能让听众进一步了解这款桌面虚拟化软件的架构设计以及客户机的通信后门机制。

  

6

**非法副本—— Android 系统****移机服务**

**安****全****分析**

  

**<** 李鹤皓 **\>** 上海交通大学蜚语（G.O.S.S.I.P）软件安全研究组成员**<** 杨文博 **\>** 上海交通大学蜚语（G.O.S.S.I.P）软件安全研究组博士，蜚语科技创始人，前0ops成员如今各大厂商通常会在自家系统中内置“移机”服务，帮助用户在更换手机时迁移数据。但是，我们通过逆向工程发现这些特权应用在设备身份认证、网络访问控制、私有协议设计三个方面缺少相关的安全防护，使得 Android 系统固有的安全模型被破坏，令用户高度敏感的数据失去原有的保护。在实际使用中可能遭到窃听和数据修改攻击，导致用户隐私泄露，移动终端上恶意软件安装、私有数据和系统设置被恶意篡改等严重后果。
