# 长亭合作伙伴计划深圳落地开花 | 精诚合作 携手共进

![](../Images/0efe2977d4e53112858d3f4f91475e19.png)11月7日，**长亭科技 2019 合作伙伴技术沙龙——深圳站成功举办**，本次沙龙以“精诚合作，技术共享”为主题，邀请了多位合作伙伴到场，分享长亭科技的价值理念，共同探讨网络安全前沿技术和安全防护思路。**活动邀请了长亭科技的多位产品和技术专家，分享了在客户中成功落地的多种解决方案，并对华南地区的核心合作伙伴进行了授牌仪式**。![](../Images/a7d20c5966ade812f6389c0b9ded7b87.png)热情的开场致辞后，长亭科技产品服务总监龚杰首先登场，分享了**长亭科技以“化繁为简、智能安全”为核心，构筑的“攻、防、查、抓”应用安全塔防体系**。长亭科技在不断创新升级产品及服务的过程中，依托大量实战和丰富的服务经验，陆续发布了一系列深度贴合客户场景的解决方案，涉及金融、区块链、互联网、云安全等多个方向。简洁智能的解决方案已成功验证在客户实践中，能够实际全面、安全有效地满足个性化需求。![](../Images/6372e09f7553d5222f734d3771ac864a.png)长亭科技解决方案专家杨玉城，分享了此次面向合作伙伴推出的雷池（SafeLine）易捷版。长亭科技 2016 年发布了雷池（SafeLine） ——全球首款基于智能语义分析的下一代 Web 应用防火墙产品，并尝试将机器学习和语义分析的结果再次交叉，提供更高效准确的攻击检测能力，已累计服务多个行业的上百家客户。**此次推出的雷池（SafeLine）易捷版，功能完备，无需繁琐配置规则，易于部署交付，支持不限量站点，上线即可自动拦截攻击。****此外，硬件设备内置远程协助功能，设备满足等保合规要求，能够助力合规性检查与安全提升，能够更加简洁高效地为更多客户场景提供安全防护**。![](../Images/faa0b4e4767a88f33593c11a7b97e65b.png)（更多信息请参考：[雷池（SafeLine）易捷版 | 长亭科技面向合作伙伴正式推出](https://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651373471&idx=1&sn=5f086dcce91a47585f1e5dcee3a3d826&scene=21#wechat_redirect)）[](https://mp.weixin.qq.com/s?__biz=MzIwNDA2NDk5OQ==&mid=2651373471&idx=1&sn=5f086dcce91a47585f1e5dcee3a3d826&scene=21#wechat_redirect)解决方案专家陈波分享了长亭另一款主力产品：谛听（D-Sensor）。**基于蜜罐的欺骗伪装、威胁感知及溯源反制三大特性，谛听（D-Sensor）能够赋予内网全新的主动对抗能力，成为守护内网资产的不二选择**。产品同时具备开放 API，能够接入 SIEM 平台如 Splunk、ELK 等，实现对蜜罐告警的及时感知与响应。同时，外网蜜罐与防火墙联动，可以自动化封禁访问及扫描外网蜜罐的 IP，能有效将攻击者阻挡在前期“踩点”阶段，现已广泛应用于金融、能源、教育、政府等行业。

![](../Images/9db35dbfa2238525731810be2c8df830.png)

长亭科技**依托自身领先的攻防能力和多年安全服务经验，从单一的服务类型，转向体系化的安全服务**。深圳分公司安全服务负责人刘迪钦为在场人员介绍了升级的安全服务解决方案，覆盖安全能力提升、定制化安全咨询、安全评估及应急响应等。![](../Images/d6a59ee8cc4f173cb50dbcf5806f4ca9.png)本次活动的一大亮点，长亭科技为华南地区的核心合作伙伴——广东智越信息技术有限公司举行了授牌仪式。广东智越作为雷池易捷版的地区分销商，与长亭科技已在多个客户和项目上达成合作。![](../Images/c1f0eef8032ba0b1e076903c58fc3d0f.png)**长亭科技 2019 合作伙伴技术沙龙，将于 11月21日 落地上海，敬请期待！**
