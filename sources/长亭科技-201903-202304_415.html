11月7日，长亭科技将举办 2019 合作伙伴技术沙龙——深圳站，本次沙龙将以“精诚合作，技术共享”为主题，分享长亭科技的价值理念、网络安全前沿技术和全新的安全防护思路，届时还将面向合作伙伴推出雷池（SafeLine）易捷版，更加简洁高效，易于部署交付，为更多客户场景提供安全防护。

雷池（SafeLine）下一代 Web 应用防火墙发布于 2016 年，作为率先将语义分析技术进行商业化的 WAF 产品，雷池（SafeLine）从词法、语法、语义、威胁模型等多个维度完成了检测算法的构建，并尝试将机器学习和语义分析的结果再次交叉，提供更高效准确的攻击检测能力。

自发布以来，雷池（SafeLine）已累计服务上百家客户，其中不乏全球顶级流量视频网站、国内 Top 级别手机厂商、大型金融机构、世界 500 强通讯企业和国内双一流高校，为客户的门户站点、交易系统、管理平台等业务服务提供 7X24 小时贴身防护。

作为改变世界的下一代网络安全技术代表，雷池（SafeLine）凭借技术创新及客户调研中的良好口碑，得到了业界的充分认可：

  • 连续两年被 Gartner《Web 应用防火墙魔力象限》报告提名

  • 入围 Gartner 2018《Web 应用防火墙魔力象限报告亚太版》

  • 入选《IDC MarketScape: 中国 Web 应用安全市场 2019 年厂商评估》

  • 入选 IDC《中国 Web 应用安全厂商》

  • 荣获中国网络安全产业联盟 2018 网络安全创新产品二等奖

  • 被《金融电子化》杂志评选为 2018 年度金融科技优秀产品创新奖 

作为易捷版发布的雷池（SafeLine）功能完备，无需繁琐配置规则，支持不限量站点，上线即可自动拦截攻击。硬件设备内置远程协助功能，可以快速与原厂技术支持进行对接，同时设备满足等保合规要求，能够助力合规性检查与安全提升。

透明部署，快速上线

雷池（SafeLine）易捷版透明模式采用高性能服务器为载体，基于智能威胁识别引擎，自动分析判断攻击行为，检测算法高度契合后端业务，默认配置即可检测线路上的流量，能够实现快速上线，即插即用。

在该种模式下，硬件设备串联至 Web 服务器前端，无需改变网络架构和配置，所有访问流量通过雷池（SafeLine）检测后传递给后端服务器，发现攻击流量可立刻阻断，并产生告警信息，定期生成安全防护报告。

无需手动配置，
自动满足业务需求

Web 安全防护复杂，同时企业业务安全问题种类繁多、场景各异，WAF 需要适配业务场景才能抵御当下越来越智能化和复杂化的攻击，然而在实际执行过程中，安全人员面对繁杂的代码往往无从下手。

雷池（SafeLine）易捷版能够通过审计日志自动配置参数，安全维护人员无需理解复杂的匹配原理，通过日志详情的原始请求参数信息，进行自动化配置转换，实现快速设置个性化防护策略，针对性解决业务安全问题。

语义分析检测引擎，
防护效果不打折
雷池（SafeLine）易捷版采用智能语义分析技术，具有覆盖 OWASP 安全风险的智能检测引擎，不依靠传统规则匹配模型，智能识别和分析 HTTP/HTTPS，大大提升了对未知威胁的检测能力；在降低误报漏报的基础上，降低开销、提升运行速度，支持集中管理，能同时管控多台 WAF 设备，实现统一策略下发和日志搜集，提升防护效果。

应用案例1
某地市政府网站：提升防护能力

某地市政府网站之前使用下一代防火墙进行 Web 安全防护，发现效果不太理想，希望能通过专业网页防护设备进行 Web 安全防护，在推进国产化产品的过程中，经过完备的产品测试后选择了雷池（SafeLine）。

由于透明桥模式可以不改变网络拓扑，该地市政府最终选择此种部署模式，针对已经实现证书卸载的流量直接进行检测，通过串接的模式实现了防护需求。

应用案例2
某集团分支机构：快速完成部署

某集团在重保前期开展渗透测试工作，发现原有安全产品无法提供高质量的防护。

紧急采用了数十台雷池（SafeLine），通过串接模式实现快速部署，覆盖所有网络区域，在重保期间提升网页相关的攻击难度。

  • 雷池（SafeLine）直接替换原有 WAF，以串接方式接入系统。

  • 在该集团每个区域快速部署成功，总数量达数十台，有效提升攻击难度。

应用案例3
某银行 DMZ 环境：设备直接上线

某银行已部署 WAF 产品，在用雷池（SafeLine）进行测试后发现，部分经过特殊编码后的攻击请求被放过，安全运维压力较大。该银行最终用雷池（SafeLine）进行替换，采用透明桥模式进行部署，无需配置，实现快速上线。

  • 雷池（SafeLine）设备替换原有 WAF 设备，无需配置，直接上线。

  • 该银行生产、测试、办公等架构类似，每个环境部署两台透明串接的设备，实现安全防护。
