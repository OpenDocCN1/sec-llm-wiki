安全工程师（安全研究方向）
base北京

工作职责

1、跟进行业内的热点攻防思路；
2、研究甲方安全场景，研究不同甲方的实际安全需求；
3、为安全产品输出安全策略；
4、对外输出研究成果，建立技术影响力。

岗位要求

1、熟悉渗透测试思路，有渗透测试经验；

2、熟悉常见安全产品的对抗方法；

3、熟练掌握一门常见的脚本语言；

4、了解常见安全产品的实现方式；

5、了解甲方安全建设需求；

6、具有优秀的文档能力，能将研究成果转化为文档化的材料；

7、具有优秀的抽象能力，能将自身的安全经验梳理为方法论。




安全开发工程师（工程转化方向）
base北京

工作职责

1、参与设计安全产品技术架构；

2、将安全策略思路转化为工程化的代码；

3、编写安全产品的核心引擎。


岗位要求

1、热爱网络安全行业；

2、熟悉多种主流的编程语言，如：C、Python、Golang 等；

3、熟悉常见的网络安全攻防对抗思路；

4、了解常见安全产品的实现方式，如：WAF、漏扫等；

5、具有良好的计算机基础理论知识；

6、具有较强的工程能力，能输出高质量的代码。





后端开发工程师
base北京

工作职责

1、负责定位、解决客户使用网络安全防御系统中遇到的各种问题；

2、推动提升网络安全防御系统的稳定性、可靠性；

3、搭建内部测试环境，协助完成系统测试工作。


岗位要求

1、了解或愿意尝试多种编程语言（包括但不限于 Golang、Python）；

2、熟悉网络原理，掌握 Linux 下常用网络工具（如 tcpdump、iptables）；

3、深入理解 Linux 系统性能指标，掌握常见异常、错误信息的收集、诊断与处理方法；

4、深入理解产品的设计与实现原理，熟悉项目代码、文档、整体流程；

5、逻辑清晰，工作态度积极，有较强责任心与主动性。





系统研发工程师
base北京

工作职责

1、负责 Web 应用安全产品的核心检测引擎与基础组件的设计和研发工作；

2、持续迭代与改进检测引擎，提升产品的核心竞争力。


岗位要求

1、熟练使用 C / C++ / Go / Rust 编程语言之一，能够编写稳定高效可靠的代码；

2、了解主流操作系统功能特性，能够选择合适的方式完成系统开发（网络、文件、进程操作等）工作；

3、具备分布式高性能网络服务器设计开发经验者优先；

4、具备编译器相关领域设计开发经验者优先。





策略产品经理

base北京

工作职责

1、研究网络安全行业优秀的产品实践，收集客户应用场景，持续进行产品和解决方案的研究；

2、能独立负责产品的需求管理工作，主导公司内部及部分跨公司项目的管理和落地；

3、负责对销售、技术人员进行产品知识及技能培训；

4、与销售、售前合作制定重点项目的解决方案，并支持售前、测试、实施的工作；

5、支持市场营销、产品推广相关工作，负责编写及更新产品及解决方案、宣传材料等营销素材。


任职要求

1、本科以上学历，1 年以上网络安全从业经验，熟悉网络安全行业及产品；

2、有网络安全防护类产品的设计、售前经验；

3、有良好的产品分析、总结归纳能力，可以主动发现机会和问题；

4、思维逻辑清晰，语言/书面表达能力强；

5、具备较强的学习能力，能快速理解新的业务场景；

6、具备良好的沟通协同能力及团队领导能力，具有较强的项目管理能力；

7、敬业精神及良好抗压能力，有 Ownership。




业务产品经理

base北京

工作职责

1、挖掘客户需求，完成客户需求向功能需求的精确转化，持续推进产品功能迭代；

2、带领团队成员协同合作，进行产品方案设计、落地跟踪，横纵向协调资源，进行整体的项目管理，为里程碑负责；

3、竞品分析，研究产品业务及产品所在行业，对产品发展趋势有自己的见解。


岗位要求

1、熟悉 ToB 行业的商业模式；

2、主动挖掘客户需求，有能力独立设计一套完整的产品原型；

3、具备项目管理能力，可以主导协调推进公司内的大型项目及部分跨公司的项目；

4、能够总结项目组外部综合反馈，形成精确的说明文档；

5、帮助新人成长，能够将自己的经验传达给新人，并让其快速接受；

6、逻辑思维能力强，善于抽象和简化复杂问题，并给出可行性强的解决方案；

7、具有良好的学习能力、沟通能力和团队合作精神；

8、能承受高强度工作压力，责任心强，执行力高，能够保质保量完成自己负责的工作。


长亭科技是国际顶尖的网络信息安全公司，全球首发基于智能语义分析的下一代Web应用防火墙产品。目前，公司已形成以攻（漏洞扫描器）、防（下一代Web应用防火墙）、查（云服务器安全）、抓（内网威胁感知系统）为一体的全方位企业级应用安全防护塔防体系，并提供优质的安全测试及咨询服务，为企业级客户带来智能的全新安全防护思路。
