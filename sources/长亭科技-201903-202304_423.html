解决方案专家
base 北京、深圳、上海

职位描述

1、完成售前技术服务工作，包括技术交流、方案撰写、投标和演讲等；

2、对销售人员进行产品和解决方案相关的培训；

3、执行产品策略、反馈市场需求；

4、关注其他安全厂商的产品动态，反馈行业应用情况。


任职要求

1、本科以上学历，计算机相关专业；

2、熟悉 Ubuntu、CentOS 等 Linux 操作系统；

3、熟悉常用 Shell 命令，能够编写 Python 简单程序；

4、了解 WAF、IPS、IDS、抗 DDoS、漏洞扫描、堡垒机、数据库审计、网络准入、SOC 等网络安全技术；

5、了解 Nginx、Tengine、Apache、Tomcat 等常用 Web 软件的配置和管理；

6、学习能力强，对企业 IT 架构和业务需求有较深入的理解；

7、优秀的沟通能力和演讲能力，能够与客户方进行有效沟通交流；

8、有中大型项目的售前、研发、运维或互联网系统架构经验者优先考虑。



技术支持专家
base 北京、上海、深圳
职位描述

1、负责撰写安全产品相关文档；

2、负责公司产品项目测试、交付、验收工作；

3、负责公司安全产品的售后技术支持工作；

4、负责记录、反馈产品缺陷问题，协助产品经理完善公司产品。


任职要求

1、本科以上学历，计算机相关专业；

2、熟悉 CentOS、Ubuntu 等 Linux 操作系统；

3、熟练使用常用 Linux 命令，包括 ps、netstat、sed、wrk、curl、tcpdump 等；

4、熟练搭建常用服务器，包括 nginx、apache、dns 服务器等；

5、熟悉网络及网络安全设备的作用，包括交换机、路由器、防火墙、WAF、负载均衡、抗 DDoS 等；

6、熟悉 TCP/IP 协议，了解 TCP、UDP 通信机制；

7、熟悉 iptables、nat 工作原理；

8、了解 HTTP 基础知识，包括 HTTP 请求及响应的构成、URI 组成等；

9、了解 tcpdump、wireshark、浏览器抓包等技能；

10、熟悉代理的作用，正向代理和反向代理的区别以及各自的类型、机制；

11、了解 docker 基本原理，可熟练使用 docker 搭建各种应用服务；

12、学习能力强，有责任心，对企业 IT 架构和业务需求有较深入的理解；

13、良好的沟通能力，能够与客户方进行有效的沟通交流；

14、有 python、php、html、js 等前后端编程语言经验者优先考虑；

15、有大中型项目的售后、研发、运维或互联网系统架构经验者优先考虑。


品牌经理
base 北京

职位描述
1、根据企业的发展战略以及市场调研情况进行企业品牌定位；
2、对企业资源进行规划，制定企业品牌规划方案；
3、负责企业品牌管理工作，对包括 VIS 在内的企业品牌使用进行规范；
4、制定企业品牌推广宣传方案，并负责组织人员进行媒体、公关以及其他推广宣传活动，负责媒体专访、相关软文写作、宣传片拍摄等，负责企业公众号运营；
5、协助市场其他部门制定企业新产品的开发、推广方案。

任职要求
1、市场营销、管理类、广告类或相关专业本科及以上学历，5年以上品牌策划及管理相关经验；
2、文字功底扎实，有较强的策划、编辑、撰写能力；
3、系统规划品牌工作，具有独立承担品牌营销活动策划与项目管理能力；
4、具备敏锐的市场洞察力以及分析能力，熟悉产品价值提炼及竞争优势；
5、具备良好的沟通协调能力；
6、拥有智能科技行业、网络安全工作经验或 4A 公关公司背景者优先。

1、至少熟悉一门编程语言；
2、计算机等相关专业；
3、有安全技术背景为佳，应届生、实习生亦可。


市场营销实习生

base 北京

1、希望你思维活跃，有独到见解，能为市场活动出谋划策；
2、希望你善于沟通，能协助组织和实施市场推广、宣传等活动；

4、希望你踏实肯干、执行力强，能辅助市场部门其他工作。

任职要求
1、熟悉各类办公软件，能熟练使用Office、Excel、PPT等；
2、了解互联网正在发生的趣事，善于发现新事物，乐于分享；
3、较强的理解、沟通及协调能力，态度积极，良好的团队协作精神。
