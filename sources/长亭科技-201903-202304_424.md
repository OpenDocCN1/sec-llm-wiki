# 长亭科技被阿里云全资收购，全面升级安全服务能力

阿里云拟全资收购长亭科技，收购完成后，长亭科技品牌及团队均保持独立，继续保持独立运营，并在阿里云的技术、资金、业务的全方面支持下全力拓展市场，持续为企业级用户提供更具实力的网络安全解决方案。![](../Images/71ad222a9649366e29e3f7e9e93818a0.png)

长亭科技品牌迎来新突破

深耕细作在业内脱颖而出

![](../Images/d33bb69471c1c74b548582fe10980088.png)

长亭科技作为网络安全行业表现亮眼的新锐力量，以下一代Web应用防火墙雷池（SafeLine）为拳头产品，搭建攻、防、查、抓为核心理念的产品+服务应用安全塔防体系，连续三年实现营业额四倍增长。

数年里，长亭科技不断创新升级产品，形成了系列针对各类场景的解决方案，陆续发布的解决方案涉及金融、区块链、互联网、云安全等多个方向，更全面、实际有效且满足需求的实践方案，受到了各行业资深专家和客户的一致好评。

此次阿里云和长亭科技的战略合作，将实现双方产品和服务能力上的再次升级，无论是服务于B端客户，还是在安全产品和服务的创新上，长亭都将会有新的突破，深耕细作在安全行业内脱颖而出。

![](../Images/71ad222a9649366e29e3f7e9e93818a0.png)

阿里云实力支持  
长亭迎来跳跃式晋级

![](../Images/d33bb69471c1c74b548582fe10980088.png)阿里云智能历经十年发展，成为全球前三、亚太第一的公共云服务商，随着完成对长亭的收购，双方在技术层面的合作也已经紧锣密鼓展开。  
阿里云在大型政府企业客户安全定制化服务能力上将得到极大的扩充，尤其是在长亭的攻防优势上将和阿里云本身的安全实力强强融合，在对于客户提供安全实战演练等服务能力上将展现出独特的优势性。长亭科技也将凭借阿里云强大的云端资源和数据能力，帮助企业在日趋复杂的IT环境中紧抓网络安全中的关键环节，有效提升产品在安全建设中的实际价值。

与此同时，阿里云丰富的安全产品和解决方案让长亭科技在解决多场景的安全问题上拥有更多选择空间，实现私有云、混合云等多云安全防护体系，全方位解决客户安全问题，对长亭来说将是一次完美的跳跃式晋级。

近日，阿里云安全事业部肖力对外强调了云原生安全的能力，提出云原生安全将构筑新一代企业安全架构，这对于长亭科技来说又是一次新的机遇。长亭科技CEO陈宇森也表示：“此次的合作将让长亭在未来的一段时间内发展会非常快，阿里云提供的云计算能力、安全的技术实力和最佳实践将给我们原有的服务能力带来质的变化，给我们的客户提供更加丰富的安全产品和服务。”
