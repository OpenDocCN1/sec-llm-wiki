**xray社区版介绍篇**

  

  

  

xray 社区版是从洞鉴核心引擎中提取出的一部分功能，支持主动扫描和被动扫描方式，自备盲打平台、可以灵活定义 POC，支持 Windows / macOS / Linux 多种操作系统。**xray 社区版详细介绍请参见阅读原文。**

xray 社区版使用效果演示 ![](../Images/b1d2bb81cbdf630a05eb463bf43d28e1.png "上箭头 (1).png") ：

说到这，可能有很多人，尤其是企业版用户会有疑问， xray 社区版到底与企业版的洞鉴（X-Ray）有哪些区别呢？

首先，从扫描效果上来讲，洞鉴（X-Ray）包含了 Web 扫描引擎和主机扫描引擎，xray 社区版是洞鉴（X-Ray）Web 扫描核心引擎的一部分，覆盖了以下检测模块：

  

*   SQL 注入模块
    
*   XSS 模块（不含DOM型XSS）
    
*   命令/代码注入模块
    
*   目录枚举模块
    
*   路径穿越模块
    
*   XML 实体注入模块
    
*   文件上传模块
    
*   弱口令模块（只包含Web表单、HTTP基础认证弱口令）
    
*   jsonp 模块
    
*   ssrf 模块
    
*   基线模块
    
*   任意跳转模块
    
*   CRLF 模块
    
*   POC管理模块（便于用户自行构建POC）
    

其次，从业务功能上来看，xray 社区版没有可操作的界面，全命令行操作，可以使用HTTP代理模式或普通爬虫收集扫描目标，不包含各种数据的统计、资产管理、漏洞管理等洞鉴（X-Ray）的所有业务功能。  
最后，从使用场景上来说，社区版更适合作为一个 Web 通用漏洞检测工具，供安全从业者便捷使用、快速验证；而企业版洞鉴（X-Ray）则更多的是基于企业使用场景，为客户提供流量指纹识别、资产风险评估、资产管理、漏洞管理的解决方案，适用于企业不同级别的相关人员。

  

  

  

**xray社区版福利篇**

  

  

  

为了让 xray 社区版不负众望，研发团队除了和大家分享自己的研究成果之外，还希望能够集思广益，借助大家的力量，让它更快更好地成长。与此同时研发团队也为能够给 xray 贡献一份力的小伙伴们送来了福利。

从上文介绍的检测模块，大家可能已经注意到，xray 社区版公开的检测模块有一个 POC 管理模块。**在这个模块里，我们内置了少量 POC 供大家使用，同时还支持大家自行构建**。在此我们希望更多小伙伴们可以贡献自己的 POC，和社区所有人共享。贡献者可以在 github xray 仓库中的 pocs 文件夹，提交 PR 到该文件夹，提交的内容必须包含以下两点：  

1.  POC 的 YAML 文件；
    
2.  POC 对应的漏洞测试环境（dockerfile 或 docker-compose 形式)。
    

  

**如此严格的要求，那么 POC 的贡献者会有什么回报呢？**

  

  

福    利

  

  

*   提交 POC ，即可获得与 xray 社区版内部大佬技术切磋交流的机会，提交PR过程中会有内部大佬审核，帮助改进 POC 的实现，共同进步；
    
*   提交1个 POC 并被收录，可进入 xray 社区核心贡献者群，与 xray 社区版核心成员共同探讨漏洞检测算法，同时可获得 xray 社区版文化衫；
    
*   提交3个 POC 并被收录可获得不定期约饭活动入场券；
    
*   提交5个 POC 并被收录可获得 xray 社区高级版，高级版支持更多检测插件，诸如 struts、 weblogic 等漏洞一键检测；
    
*   线下参与 xray 社区技术分享的机会。
    

  

  

**奖励会根据贡献者的贡献值而定，具体的贡献值与奖励规则参见 POC 贡献说明，github 链接：**https://chaitin.github.io/xray/#/guide/contribute
