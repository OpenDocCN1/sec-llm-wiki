8月11日，今年北美最大的安全盛会 DEFCON 27 在拉斯维加斯顺利闭幕，长亭科技区块链安全研究团队携智能合约蜜罐的 JOP、源码替换等技术探索亮相大会，同与会观众分享了基于以太坊的新型合约蜜罐设计及利用手法，受到现场观众的密切关注。

据悉，面向 JUMP 编程在以太坊上是一种利用 EVM 指令集及架构特点，可用于隐藏后门的蜜罐技术，这种技术思路在传统应用环境中早已有之，是为大家熟知的 Return Oriented Programming 漏洞利用方法。在本次 DEFCON 大会上，长亭科技首次公开发布了将 Return Oriented Programming 方法应用于以太坊智能合约的尝试，为区块链安全领域提供了一种全新类型的智能合约恶意后门隐藏手法。

“这种后门技术探索最早用于 2018 Real World CTF 总决赛的命题中，当时对该手法的使用逻辑探索还不完善，也是在赛后与 CTF 选手的探讨中逐步成熟起来的。”长亭科技的区块链安全研究员介绍道。合约蜜罐更像是一种“黑吃黑”，是区块链领域特有的攻击方式，对它的探索，将有助于整个以太坊生态，乃至整个区块链生态的安全防护趋于完善。

关于 DEFCON

始于 1993 年的 DEFCON 是世界上最大的黑客 Party。每年8月，全世界那些敢于对不可能竖中指的 hacker都会聚集在罪恶之都拉斯维加斯，参与到这场最盛大的黑客聚会中。顶级黑客的聚会，少不了各种奇葩的破解和最前沿技术的分享，软件破解、IoT破解、汽车破解、医疗设备破解、无人机破解、区块链技术、社会工程学、量子密码技术…… 

在 2015 年的 DEFCON CTF 上，有3支中国队伍杀进前六，分别是 HITCON、蓝莲花和 0ops，而在演讲环节，则有来自 360 的五位黑客大神向全世界分享了他们的破解成果。自此，每年的DEFCON盛会都少不了中国黑客的身影。2018年，DEFCON 更是被引入中国，引领中国 hacker 不断为世界网络安全技术的发展贡献力量。

4、 DEFCON Badge，解锁 Hacker “say hello”最新姿势

每年的 badge（徽章） 是 DEF CON 独有的标志，也是 DEF CON入场的唯一凭证。

今年的 badge 是一个正面像是大理石一样的圆形 cool Mark，它的背面会有一些小灯泡，还有接口可读代码。传说把它戴在手上，当你在大会上遇见别的小伙伴，把 badge 贴在一起，它就会收集到一段非预期信号，遇见的人越多，收集到的隐藏信息也越多，当隐藏信息达到一定的数量的时候，就会改变小灯泡发光的规律，解锁不同姿势。
