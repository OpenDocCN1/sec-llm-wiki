腾讯CSS倒计时一周 | 长亭邀您共享基于Git的版本控制服务漏洞实践

7月30日-31日，腾讯年度最重磅安全峰会——第五届互联网安全领袖峰会（Cyber Security Summit，简称CSS）将在北京国际饭店拉开帷幕。作为CSS 2019开设的七大特色专场论坛之一，腾讯安全探索论坛（TSec）将以“前沿科技、尖端对抗”为主题，现场全球首发众多前沿技术议题，覆盖领域横跨工业界和学术界，聚焦多个独特的研究视角，充分诠释网安人的创造力。值得期待的是，长亭科技高级研发工程师黎荣熙也将在现场首次公开披露GitLab多个漏洞，给你漏洞挖掘最炫姿势。诸多精彩，不容错过！





一键剧透 技术挖掘最炫姿势




随着Git在一众版本控制软件中的脱颖而出，基于Git实现的在线合作式版本控制服务也逐渐被广大公司所接受。作为公司核心代码的保险箱，该类应用又存在哪些危及信息资产安全的漏洞呢？本次演讲，黎荣熙将从利用静态分析进行代码审计出发，介绍这项技术并结合Git的一些不为人知的特性，首次公开披露GitLab的多个漏洞经历。


据悉，除长亭科技的GitLab多个漏洞首次披露外，大会现场还将有技术大牛带来各种“冷门”研究视角的漏洞挖掘分析，源码漏洞扫描、语法分析、OS内核信息泄漏漏洞，各种漏洞挖掘的姿势齐聚，让你眼花缭乱，欲罢不能！




大咖云集 学术前沿一网打尽




本届TSec入围议题的演讲嘉宾均是长期从事网络安全工作的安全专家，不仅有来自长亭科技、绿盟科技、知道创宇、腾讯等一线企业的研究员，更有来自清华大学、上海交通大学、数学工程与先进计算国家重点实验室等学术界专家。

清华大学副教授张超博士携手数学工程与先进计算国家重点实验室甘水滔博士，分享当前最流行漏洞挖掘方案——模糊测试的优化空间；上海交通大学密码与计算机安全实验室蜚语软件安全小组聚焦源代码审计和漏洞挖掘；绿盟科技的张云海将进一步揭示Windows的安全体系，首次披露一种新型的内核漏洞。个中精彩，是不是令人期待？


关于CSS 2019


CSS 2019是腾讯年度最重磅安全峰会，将以“产业升级 安全升维”为主题，围绕金融安全、云安全、大中型政企通用安全、大交通安全、产业与安全标准化等议题展开，同时邀请到来自国内外的重磅嘉宾，包括亚马逊、IDC等不同领域的企业负责人，国内知名工程院院士，共同探讨产业安全的未来与机遇。
