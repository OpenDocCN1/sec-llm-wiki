以智能化、信息化为核心的第四次工业革命正席卷而来，其发展速度之快、范围之广、程度之深前所未有。它以大数据、云计算、人工智能等前沿技术为支撑，将改变生活方式、升级产业结构，给各行业带来系统性变革。


为了积极贯彻国家网络空间安全战略要求，6月29日，由中国信息安全测评中心、海南省工业和信息化厅、海南省大数据局管理局共同指导的全国信息安全企业家高峰论坛在海口召开，来自网络安全领域的多位专家和企业家代表参会，共同探讨产业发展新生态。长亭科技携基于攻防对抗思路的应用安全防护体系亮相大会，同与会嘉宾分享了在攻防对抗优势悬殊之下，应用安全防护的重点与难点。

攻击方和防守方的天平从来都是不平衡的，一个很重要的原因是攻在暗，守在明；攻击者只需要一个点的突破，而防守者需要考量的是一个面的安全。如何消除“攻”和“防”之间的这种不对称，就必须要求我们站在攻击者的角度来思考问题，先于攻击者找到问题及相应的应对方法就变得非常重要。然而攻击者的手段层出不穷，一些新型 0 day 漏洞攻击更是防不胜防，这就注定我们在构建防护体系的时候一定是一个动态对抗的过程。我们无法构建一套完全无敌的防御体系，但是可以做到在攻击路径上层层设防，联动多极安全设备做到纵深防御，这样即使发生了单点被突破的情况，我们也可以及时的响应处置开展反制措施。

总体来说，攻防对抗思路对于网络安全，尤其是应用层安全防护尤为重要。随着  Web 2.0、网络社交等一系列新型的互联网产品的诞生，基于 Web 环境的互联网应用越来越广泛。Web  业务的迅速发展吸引了黑客们的强烈关注，接踵而至的就是 Web 安全威胁的凸显。

长亭科技凭借多年在网络攻防对抗中的实战经验，持续进行技术创新，紧跟国际先进技术理念，构筑了以“化繁为简、智能安全”为核心，基于攻防对抗思路，“攻、防、抓、查”四维一体的应用安全防护塔防体系，有效助力企业应用安全防护，帮助企业安全在提升防护结果准确性的同时，增强其智能化及联动能力。

自 2016 年以来，长亭科技陆续推出雷池（SafeLine）、谛听（D-Sensor） 、洞鉴（X-Ray） 、牧云（CloudWalker） 多款产品，全面覆盖网络安全保障过程中的关键防护节点，同时，长亭科技由顶尖技术安全专家组成的团队，面向用户提供以渗透测试、代码审计、基线检查和应急响应等为主的全方位的安全服务，依据国际标准，以攻击者的视角，对检测目标进行模拟攻击，深入发掘应用层安全隐患，并进行检查和修复，有效、全面地帮助、保护企业免受网络攻击威胁，真正提升企业的安全系数。



长亭科技是国际顶尖的网络信息安全公司，全球首发基于智能语义分析的下一代 Web 应用防火墙产品。目前，公司已形成以攻（漏洞扫描器）、防（下一代 Web 应用防火墙）、查（云服务器安全）、抓（内网威胁感知系统）为一体的全方位企业级应用安全防护塔防体系，并提供优质的安全测试及咨询服务。


作为改变世界的下一代网络安全技术代表，长亭科技被评选为《财富》中国创新企业“人工智能和机器人”领域的全国第一、《CIO Advisor》亚太地区25家最热门人工智能公司。公司产品被 Gartner《Web应用防火墙魔力象限》报告提名，入围 Gartner 2018《Web应用防火墙魔力象限报告亚太版》。目前已服务中国银行、交通银行、安信证券、中国平安、爱奇艺、Bilibili、华为等系列知名客户。
