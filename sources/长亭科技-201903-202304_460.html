《私有云Web应用安全防护解决方案》发布 实现“硬核”云上安全

根据Wikibon和Gartner的调研，目前，已经有30%的数据中心在构建企业私有云，到2020年，这个比例会超过60%。

《中国私有云发展调查报告（2017年）》显示：2017-2020年,中国私有云市场仍将保持稳定增长，2020年市场规模将达到762.4亿元；在已经采用私有云的企业中，58.3%的企业计划未来加大对私有云的投入力度，近20%的企业表示，对私有云的投入增长在50%以上。

上述数据表明，中国企业用户更信赖私有云。

随着云计算技术日渐成熟，许多用户已经或正在将业务迁移至云上。金融、能源、政府等用户出于安全考虑，倾向于建设自主权限更高、安全把控更好的私有云。私有云具有资源利用率高、集中运维管理等优势，同时也对安全防护体系提出了新的要求。

从部署到运营 

私有云Web应用防护需求凸显




Web 应用作为私有云承载的重要应用系统，在提供各类服务的同时，也成为了最容易被利用的突破口。进行私有云建设的用户规划设计云平台 Web 应用防护解决方案时，在部署和安全运营方面拥有不可忽视的几大刚需：


  • 部署虚拟化；

  • 资源弹性可伸缩；

  • 基础设施标准化；

  • 管理运维统一化；

  • 防护功能服务化、平台化。

以大型能源企业为例，规划建设覆盖多级管理架构和跨越地理区域的内部私有云，意味着需要面向下属生产单位、销售单位、科研单位等多级多部门提供服务，因此，提供灵活的策略优化、弹性可伸缩的资源和集中的安全事件运营服务，是私有云安全建设过程中重点要解决的。


谋定思动

长亭科技助力私有云安全价值提升




在传统 IT 基础架构下，管理者只需在 Web 应用前按需部署硬件或软件Web应用防护系统，即可实现对 Web 应用系统的安全防护。在私有云环境下，随着网络、计算、存储资源的虚拟化和资源池化，适应这些需求也成为了私有云 Web 应用防护需要思考的难点。

为解决这一难题，长亭科技以雷池（SafeLine）下一代 Web 应用防火墙在云端Web 安全防护的实践经验为依托，深度调研各类大型企业在私有云环境下的业务安全场景，发布《私有云Web应用安全防护解决方案》，满足私有云环境下的WAF 部署需求和安全运营需求，助力企业实现私有云安全。

《私有云Web应用安全防护解决方案》


长亭科技充分理解私有云环境下企业对Web应用安全防护的高要求，从自身架构设计上即充分考虑了云计算的特点，将流量转发、威胁检测、流量分析、集中管理平台解耦并组件化，支持容器化分布式部署，预留与云管平台的各类接口，便于私有云快速部署，满足各类云服务场景化需求。


雷池（SafeLine） 

打造私有云安全核心竞争力




雷池（SafeLine）下一代Web 应用防护系统通过不断优化产品架构，能够满足私有云用户的系统部署与安全运营需求，为私有云用户提供部署虚拟化、检测能力资源池化、服务模式接口化和平台化的Web 应用安全防护解决方案，从而为企业私有云建设提供更具竞争力的部署架构。

雷池（SafeLine）云环境部署架构


部署容器化：将WAF的核心功能组件拆分，并利用容器技术实现快速部署，支持组件多活和集群模式，为Web应用防护系统的高可用和性能扩展提供基础条件；

资源弹性化：通过监控雷池（SafeLine）运行的实时状态，利用私有云资源管理平台对计算资源、网络资源和存储容量的管理调度机制，灵活调整计算资源分配；

功能接口化：雷池（SafeLine）支持以API功能接口对外提供流量分析、集中管理、流量检测等服务；

服务平台化：雷池（SafeLine）提供功能统一集中管理门户，且管理平台支持细粒度的功能与数据权限管理，满足平台安全运营需求。

IaaS & SaaS

雷池（SafeLine）服务模式再进化




随着云计算技术的不断成熟和应用，业务上云对企业运营能力的重塑越发凸显。这些在阳光灿烂的日子修屋顶，提早进行云上安全防护建设的企业，率先进入了收获期。基于雷池（SafeLine）建立的Web安全防护系统，能够以IaaS 和SaaS 两种模式为云平台租户提供安全防护服务，为云上企业安全架构的部署和运营保驾护航。

对于租户管理员需独立负责 Web 站点的配置、安全防护状态和安全事件处置的情况，雷池（SafeLine）能够提供基于云主机镜像的Web应用防护系统快速部署（即IaaS架构），管理者只需按照租户申请要求，建立相应的虚拟主机，即可自动化部署雷池（SafeLine）软件。

对于有构建一体化防护体系需求的私有云用户，基于SaaS服务模式部署的雷池（SafeLine），能够给私有云管理者提供具备统一服务门户的Web应用防护系统，为直观了解防护信息提供有效支撑。

伴随着企业上云，尤其是大型企业逐渐将业务迁移至自主权限更高，安全把控更好的私有云平台这一趋势的发展，以金融、能源、政府等行业为代表的企业用户对云环境下的安全防护愈发重视。让安全架构满足云上的复杂环境，已经成为企业进行安全建设时的首选。长亭科技也正在将更多成熟可落地的技术解决方案带到更加多元化的互联网安全体系建设中，为企业应用安全保驾护航。
