开篇之初，我们先来看一个真实的案例，发生在**雷池（SafeLine）下一代Web应用防火墙**客户的使用场景中。  

** 客户需求 **

金融某客户，其敏感业务的统一认证接口长期遭受**爆破和撞库**的威胁，希望WAF能够同步处理威胁情报服务产生的业务情报信息，两者联动保障业务正常稳定运行。

** 挑战 **

  

1\. 接口访问量巨大

2\. 不能出现业务延迟

3\. 尽量避免人工参与造成的错误

** 解决方案 **

第一步，雷池（SafeLine）通过独有的插件平台完成**插件配置**，对访问该统一认证接口的用户进行**指纹提取**——指定筛选条件的方式过滤出符合某种特征的用户指纹（如源 IP、域名、URL 等）的 HTTP 请求； 

第二步，信息传递由威胁情报服务进行**风险评估**，若威胁情报平台认为当前用户具有恶意，将回传当前的威胁信息及建议；

第三步，雷池（SafeLine）**接收威胁信息**，对相关请求进行逐条处理，并将执行手段下发给请求检测处理模块，进行**立即阻断或限制**该用户的后续访问行为，**保障业务的正常运行。**

![](../Images/6014c886f983e97ca776201a9bbec3cb.png)

** 客户反馈 **

进行了多轮测试验证后，企业对雷池（SafeLine）和威胁情报服务联动的可用性和准确性很满意，在处理的时效方面完全超出预期，**大大降低了安全业务的人工维护成本和时间成本，并有效降低了敏感业务的安全风险。**

  

云时代的WAF，早已不是你当年认识的那个WAF了。**平台属性增强，规则属性减弱，智能、灵活成为一款简单好用WAF的首要考虑因素。**雷池（SafeLine）下一代Web应用防火墙，作为新型WAF的代表作品，在越来越多的客户真实使用场景中被玩出了花样，解决了更多贴合业务场景和安全风险的问题。  

![](../Images/ce05325cbb708beebb0db73bc8848e1d.png)

本文着笔的WAF和威胁情报联动的想象空间在于：WAF根据自身的防护能力以及网络边界位置的独特性，检测到更多的未知威胁，更贴近业务场景，更精准、实时的阻断威胁从而降低业务风险。**威胁情报犹如为WAF带来新的武器库，可以应对更多类型的网络威胁。**

长亭科技的雷池（SafeLine）作为15后产品代表，从设计之初就对开放性与扩展性给予了非常高的重视，为用户提供了**全开放式的 API 接口和功能丰富可高度自定义的扩展插件接口，**使其能灵活的与各类平台和安全产品进行联动，例如风控平台、运维平台、蜜罐、扫描器以及威胁情报产品等。

文中提到最佳实践的**插件编写思路：**

使用** match 变量**进行筛选，过滤所有访问统一认证接口的 HTTP 请求；

注册一个**回调函数**，当用户访问统一认证接口时，将 HTTP 请求传入回调函数进行处理；

与威胁情报平台联动，判断访问者是否有**攻击背景**；

发现恶意用户后下发规则，阻断该用户的**后续访问**。

  

** 样例插件代码结构 **

  

local safeline = require "safeline"

  

header = {}

header\["User-Agent"\] = "safeline"

  

bantime = 60

  

\-- 威胁情报服务平台地址

url = "http://xx.xx.xx.xx/query?apiKey=xxxxxxxxxxxxxxx&src=%s"

  

match = {

    ip = "0.0.0.0/0",

    host    = "www.chaitin.cn",

    urlpath = "/safelinenb",

    type = safeline.MATCH\_TYPE\_ALL,

}

function action(ip, resp)

  local banip = {

      ip = ip,

  }

  if string.find(resp, "badboy") ~= nil then

    safeline.action\_ban(banip, bantime)

  end

end

  

function process(ip, host, urlpath)

    urltmp = string.format(url, ip)

        resp, err = safeline.http\_get(urltmp, header)

    action(ip, resp\["body"\])

end

  

safeline.register(safeline.TYPE\_PROCESS, match, process)
