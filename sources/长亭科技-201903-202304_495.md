# 长亭科技连续两年亮相 RSAC，多款产品引发业内关注

当地时间3月4日至8日，国际知名信息安全峰会 RSA Conference 2019在旧金山拉开帷幕。长亭科技凭借基于创新技术的多项解决方案连续两年亮相RSAC，多款产品及解决方案引发业内关注。**雷池（SafeLine）下一代防火墙云端解决方案、新品洞鉴（X-Ray）安全评估系统与牧云（CloudWalker）服务器安全平台****收获海内外人士诸多赞誉。**  

![](../Images/0ea00e3ca101665046d04251e22d7125.png)

作为拥有27年历史的专业信息安全产业展会，RSAC记录了信息安全行业发展的每一个重要时刻，今年更是吸引了超过700家来自全球的参展商和信息安全行业的领导者、专家及媒体聚集于此。今年RSAC的主题是“Better”，旨在数字化时代大背景下探索新的网络安全发展领域，致力寻找更优质的安全厂商及产品服务解决方案。**而长亭科技也正是凭借着在网络安全领域持续不断的创新，将这一理念付诸于实践。**

**雷池云端解决方案，重铸金融业安全防御力**

  

纵观本次大会，“云安全”成为当之无愧的热点话题。数据显示，42%的参展机构涉及到云安全内容。企业信息技术建设中已经有越来越多的应用和技术架构软件都集中在云端，然而云技术的大范围使用和云端应用安全防护技术的发展之间似乎存在了一个空白。**尤其是金融企业掌握着客户资金和信息双重重要信息，更需在日趋复杂的IT环境中紧抓网络安全中的关键环节。**因此，“保证业务连续性”、“保护核心敏感数据资产安全”等问题同时成为金融行业在上云过程中面对的重重关卡。

**面对云上的复杂变化，长亭科技升级推出雷池（SafeLine）云端解决方案，使雷池（SafeLine）无论应对私有云、公有云、混合云都能灵活应变。**基于技术升级和部署架构的变化，扩展的集群部署模式能够帮助企业灵活配置网络环境，从根本上避免云WAF存在轻易被绕过的风险，解决其可靠性低和保密性低的弊端。与此同时，**全新的雷池（SafeLine）进一步升级核心检测算法，可精准识别未知威胁，为企业防范场景化风险带来价值。**

**自2016年发布以来，雷池（SafeLine）已连续两年提名Gartner《Web应用防火墙魔力象限》，并入围Gartner 2018年《Web应用防火墙魔力象限亚太版》，充分得到业界认可。**

**新品洞鉴助力企业资产管理与漏洞发现**  

近年来，随着企业尤其是金融业数字化转型的不断加速，企业资产发现不全、人工管理效率低、不能及时感知风险等，越发成为企业信息安全亟待解决的问题，资产管理与风险控制正在逐渐成为企业关注的重点问题。长亭科技预见性地抓住了企业用户这一痛点，推出全新的漏洞扫描产品洞鉴（X-Ray）。

**洞鉴(X-Ray) 是一款集资产管理和漏洞扫描二合一的安全评估系统，基于长亭科技多年持续积累的大量高质量漏洞数据，为客户提供入侵风险检测与漏洞风险预警等安全防护服务，可发现大规模资产并进行方便快捷的管理，根据企业特点进行灵活的自定义漏洞扫描与管理，并提供专业的修复策略建议。**

针对不同的场景环境，洞鉴（X-Ray）能够通过主动与被动发现相结合的方式，帮助企业全面地发现资产、管理资产。洞鉴（X-Ray）的主动资产发现包括主机资产、 域名资产、Web 资产等，特别针对Web 资产发现，洞鉴（X-Ray）采用了模拟浏览器爬虫，可以爬取到普通爬虫无法爬取的复杂 Web 资产信息资源，满足企业对 Web 资产全面、准确爬取的需求，而被动资产发现则从代理、流量、日志三种方式出发，对主动扫描进行补充，且具备采集资源信息不耗时的特点，提升精准率和覆盖率，适用多种业务场景。

**牧云开源收获海内外良好反馈**

“保证安全不失控”是牧云（CloudWalker）着力解决的问题。**作为服务器安全产品，牧云（CloudWalker）基于管理、排查、监控三个维度，向用户提供一个从服务器内部观察网络环境的安全视角，提升资产能见度的同时还能有效防御入侵。**牧云（CloudWalker）以占用极少服务器资源的稳定性、及其轻量级和易管理的优势，为企业服务器安全带来价值。

**而此次在 RSAC 2019引发强烈关注的，是牧云（CloudWalker）的开源计划。**长亭科技希望为用户提供这样一款产品，任何一个甲方安全负责人都可以用它快速搭建一套自己的服务器安全平台。自2018年9月开源至今，牧云（CloudWalker）Webshell监控检测模块的强劲实力已收获海内外大量的良好反馈。

![](../Images/afb2af12ba571272314ee1199836abfe.png)

多款产品的精彩亮相，为长亭科技此次参加 RSAC 2019 赢得了更多的关注和赞誉。作为一家以技术为核心的网络安全公司，长亭科技一直以前瞻性的技术格局和敏锐的攻击者思维去探索企业安全的新问题，形成了“攻、防、查、抓”四维一体的应用安全防护塔防体系，并获得**中国银行、招商银行、建设银行、民生银行、安信证券、华为**等大型金融与互联网企业的认可。

未来，长亭科技将持续专注于安全产品研发，致力于以创新技术为企业多向提供简单高效、具有成熟商业化标准的安全解决方案。
