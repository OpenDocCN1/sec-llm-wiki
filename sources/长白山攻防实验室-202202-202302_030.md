
*   JDK9 或以上版本系列（存在 module 属性）
*   Spring 框架或衍生的 SpringBoot 等框架，版本小于 v5.3.18 或 v5.2.20（支持参数绑定机制）
*   Spring JavaBean 表单参数绑定需要满足一定条件
*   以 war 包的形式部署在 Tomcat 容器中，且日志记录功能开启（默认状态）
