# 漏洞通报丨CVE-2023-27326丨Parallels Desktop VM Escape

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg4MDY1MzUzNw==&mid=2247494340&idx=1&sn=fd0dae4284cab3cda5b6b34361e6c3d7&chksm=cf734f4af804c65c029b8273f89ff90d915c1f781c78024f585aefb92965234417aadb9f3283&scene=126&sessionid=1681576067#rd](http://mp.weixin.qq.com/s?__biz=Mzg4MDY1MzUzNw==&mid=2247494340&idx=1&sn=fd0dae4284cab3cda5b6b34361e6c3d7&chksm=cf734f4af804c65c029b8273f89ff90d915c1f781c78024f585aefb92965234417aadb9f3283&scene=126&sessionid=1681576067#rd)

**此漏洞允许本地攻击者在受影响的 Parallels Desktop 安装中提升权限。**

  

该漏洞在Parallels Desktop版本18.0.0(53049)上进行了测试，并在18.1.1(53328)安全更新中修补了该漏洞。

  

*01  **漏洞概述*

该漏洞**来自Toolgate组件**。由于在文件操作中使用用户提供的路径之前没有对其进行适当的验证。攻击者可以利用此漏洞升级特权，并在主机系统上当前用户的上下文中执行任意代码。  

  

详细信息：https://blog.impalabs.com/2303\_advisory\_parallels-desktop\_toolgate.html
