今天再来给大家推荐一款终端神器：WindTerm。此工具托管在GitHub上，并且完全开源，支持中文。


GitHub：https://github.com/kingToolbox/WindTerm

1

WindTerm特点

l 实现了 SSH v2、Telnet、Raw Tcp、串行、Shell 协议；

l 会话认证时支持 SSH 自动执行；

l 支持 SSH ControlMaster；

l 支持 SSH ProxyCommand 或 ProxyJump；

l 支持 SSH 代理转发；

l 支持使用密码、公钥、键盘交互、gssapi-with-mic 的 SSH 自动登录；

l 支持X11转发；

l 支持直接/本地端口转发、反向/远程端口转发和动态端口转发；

l 支持 XModem、YModem 和 ZModem；

l 集成sftp、scp客户端，支持下载、上传、删除、重命名、新建文件/目录等；

l 集成本地文件管理器，支持移动、复制、复制、删除、重命名、新建文件/目录等；

l 支持 Windows Cmd、PowerShell 和 Cmd、PowerShell 作为管理员；

l 支持Linux bash、zsh、powershell core等；

l 支持 MacOS bash、zsh、powershell 内核等；


2

WindTerm安装

WindTerm支持 Windows、Linux 和 macOS，可以直接在release页面按需求选择下载。


下载地址：https://github.com/kingToolbox/WindTerm/releases/

3

WindTerm使用

SSH

在主窗口工具栏中选择“会话”->“新建会话”。

输入自己主机相关信息即可进行连接。

4

WindTerm性能对比

作者还将WindTerm与rxvt、putty、xterm、iterm2、Kitty、Alacritty、Windows Terminal + ssh.exe等众多终端工具做了对比，最终结果WindTerm不仅响应速度快，占用内存也吊打其他各终端。
