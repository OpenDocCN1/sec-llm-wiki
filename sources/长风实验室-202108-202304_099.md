**国外热点**

**01**

**俄罗斯黑客再度出击**

**美国重要核实验室被攻击**

  

路透社消息，1月6日，来自冷河集团的俄罗斯黑客“攻击”了三个美国重要的核研究实验室，该报根据网络上的一些记录和网络安全领域匿名专家的话得出了这个结论。据记者介绍，去年8月至9月期间，一群俄罗斯黑客向实验室员工发送信件，并创建虚假互联网页面登录以获取密码，该报没有具体说明为什么这些实验室被选为“俄罗斯黑客的目标”。目前，美国核技术研究实验室或美国相关部门的代表还没有没有发表官方评论，早些时候有网络安全专家在媒体中称美国有遭到网络攻击的危险。

  

事实上，美国和俄罗斯之间一直相互进行网络攻击，俄罗黑客的技术能力高超，战果显著。俄罗斯黑客曾经攻陷美国联邦调查局，公布了联邦调查局的探员信息。俄罗斯黑客也曾攻陷乌克兰国防部和安全部门，获取了乌克兰大量黑客和乌克兰特工和军官的信息并公布于众。

  

**02**

**硬件漏洞无法修复，西门子PLCs易遭攻击**

固件安全公司 Red Balloon Security 的研究人员发现了一个严重漏洞，影响西门子的很多可编程逻辑控制器 (PLCs)。该漏洞是CVE-2022-38773，可导致攻击者绕过受保护的启动特性并可能修改控制器的操作代码和数据。研究人员指出，漏洞是由于西门子Simatic和Siplus S7-1500 CPU中存在一系列架构问题。

  

研究人员在本周二解释称，“西门子自定义的片上系统 (SoC) 并没有在早期的启动进程中建立无法破坏的根信任(RoT)，其中包括在执行前缺少对引导程序和固件所有阶段的异常签名认证等。未能在设备商建立RoT 可导致攻击者加载自定义修改的引导程序和固件。这些修改可导致攻击者执行并绕过设备上的防篡改和完整性检查特性。”

  

研究人员指出，攻击者可解密受影响 PLCs的固件并生成自己的恶意固件，可在100多款首映性设备机型上变得可启动。

  

**03**

**热门开源库 JsonWebToken 存在RCE漏洞**

Auth0 修复了热门开源库 JsonWebToken 库中的一个远程代码执行漏洞 (CVE-2022-23529)。该库已被超过2.2万个项目使用，每个月从NPM上的下载数量超过3600万次。该RCE漏洞影响在2022年12月21日前发布的JsonWeb Token 9.0.0以下版本。JsonWebToken 用于很多企业创建的开源项目中，如微软、Twilio、Salesforce、Intuit、Box、IBM、Docusign、Slack、SAP等等。该项目是用于创建、签名和验证JSON Web令牌的开源库。

  

Auth0 在jwt.io网站上指出，“JSON Web Token (JWT) 是一个开放标准 (RFC 7519)，为在作为JSON对象的各方定义紧凑独立的安全传输信息方式。由于信息经过了数字化签名，因此是可验证和可信任的。”该项目由Okta Auth0 所开发和维护，在NPM包仓库上的周下载量已超过900万次，已有超过2.2万个项目在使用它。成功利用该漏洞可导致攻击者绕过认证机制、访问机密信息以及窃取或修改数据。

  

然而，发现该漏洞的Palo Alto Networks公司Unit42团队研究人员提醒称，威胁行动者受陷需要攻陷app和JsonWebToken服务器之间的机密管理流程，使其更加难以利，因此将漏洞严重性下调至7.6分。

  

**04**

**美国联邦航空局出现系统故障**

**所有航班停飞**

  

当地时间1月11日8时50分，美国联邦航空管理局称，要求所有航空公司暂停执飞美国国内出发航班的命令已经取消。美国各地的正常空中交通业务正在逐步恢复。造成系统故障的原因仍在进一步调查中。当地时间11日，美国联邦航空管理局由于断网而发生电脑故障，美国联邦航空局下令将所有航班的起飞时间推迟至美国东部时间上午9时。

  

航班跟踪网站FlightAware的最新数据显示，截至美东时间8时50分，全美有4013架次航班延误，近698架次航班取消。据美国有线电视新闻网（CNN）最新消息，正在墨西哥出席北美峰会的美国总统拜登已经听取了关于这一事件的简报，并下令对此进行全面调查。

  

**国内热点**

**01**

**《互联网信息服务深度合成管理规定》**

**今日起正式施行**

  

2023年1月10日，《互联网信息服务深度合成管理规定》（以下简称“《规定》”）正式施行。《规定》由国家网信办2022年第21次室务会议正式审议通过，并经工业和信息化部、公安部同意后对外公布，旨在进一步加强互联网信息服务深度合成管理，弘扬社会主义核心价值观，维护国家安全和社会公共利益，保护公民、法人和其他组织的合法权益。

  

**02**

**国内一城市发布元宇宙三年行动计划**

1月6日，重庆市永川区人民政府官网发布《重庆市永川区元宇宙产业发展三年行动计划（2023—2025年）》。

  

该行动计划的发展目标指出，力争到2025年，将永川打造成为以数字内容制作为特色的全国知名、西部领先的元宇宙应用示范城市。元宇宙产业园区成熟运营，元宇宙技术应用日趋成熟，元宇宙产业生态基本形成，数字内容制作能力全国领先，元宇宙技术研发和应用推广取得明显进展，引入培育一批掌握关键技术、营收上亿元的元宇宙企业，构建科技影视、虚拟数字人、数字藏品等多领域元宇宙新模式新服务。
