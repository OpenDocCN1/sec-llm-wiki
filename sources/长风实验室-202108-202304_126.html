OutGuess是一个通用的隐写工具，它允许将隐藏信息插入到数据源的冗余位中。


OutGuess安装

GitHub：https://github.com/crorvick/outguess


下载源码至Kali中，执行如下命令进行编译及安装。

./configure && make && make install


OutGuess加密

outguess -k “my secret key” -d hidden.txt demo.jpg out.jpg


OutGuess解密

outguess -k “my secret key” -r out.jpg hidden.txt
