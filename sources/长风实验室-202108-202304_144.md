# 弱口令爆破神器——超级弱口令

超级弱口令检查工具是一款Windows平台的弱口令审计工具，支持批量多线程检查，可**快速发现弱密码、弱口令账号，密码支持和用户名结合进行检查**，大大提高成功率，支持自定义服务端口和字典。 

  

工具采用C#开发，需要安装.NET Framework 4.0，工具目前支持SSH、RDP、SMB、MySQL、SQLServer、Oracle、FTP、MongoDB、Memcached、PostgreSQL、Telnet、SMTP、SMTP\_SSL、POP3、POP3\_SSL、IMAP、IMAP\_SSL、SVN、VNC、Redis等服务的弱口令检查工作。

  

**工具特点**

1.支持多种常见服务的口令破解，支持RDP（3389远程桌面）弱口令检查。

  

2.支持批量导入IP地址或设置IP段，同时进行多个服务的弱口令检查。

  

3.程序自带端口扫描功能，可以不借助第三方端口扫描工具进行检查。

  

4.支持自定义检查的口令，自定义端口。

**基本使用**

  

工具界面非常清晰简洁，上手即会，在这里我演示了爆破mysql的基本操作参考，其他协议爆破方式相同。

  

**环境准备：**

  

win10主机使用phpstudy\_pro启动mysql服务，ip为本机 127.0.0.1

![](../Images/60db32f58a27b917854f48d1f0624760.png)

  

打开超级弱口令工具，填入ip地址勾选爆破协议，选择账户密码字典，开始爆破。

![](../Images/bf4d2e5c5a3b63fd97d2db9a23c31927.png)
