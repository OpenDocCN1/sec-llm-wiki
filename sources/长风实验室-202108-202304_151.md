# 渗透测试人员必备浏览器扩展

**1****“ FOFA Pro View**  
  
  

![](../Images/427ed5c237aa86f99d8b3b8101d9c8af.png)Fofa Pro View 插件会告诉您网站的托管位置（国家、城市）、IP 的所有者以及开放的其他服务/端口。也会自动检查Fofa Pro是否有当前网站的任何信息。该网站是否也运行FTP, DNS, SSH或其他不寻常的服务。

  
**2****“ Shodan**  
  
  

与FOFA Pro View类似，Shodan也会探测网站的托管位置（国家、城市）、IP 的所有者以及开放的其他服务/端口。

![](../Images/8ef26a29330a65140e37523556f73bdd.png)

  
**3****“ HackBar**  
  
  

![](../Images/8966bdfc889dc6b897e56a980ac16e49.png)Hackbar是一个浏览器中的一个插件,它的功能类似于地址栏,但是它里面的数据不受服务器的相应触发的重定向等其它变化的影响。

![](../Images/082b1322f52a4c9f4c89990a90d81d07.png)

  
**4****“ Cookie Editor**  
  
  

![](../Images/c2e9a387807321d8f64dd3aedb1d8382.png)Cookie Editor允许您高效地为当前选项卡创建、编辑和删除cookie。

![](../Images/b4364229853b05895f2b7012f4c0d464.png)

  
**5****“ FoxyProxy**  
  
  

![](../Images/a7094a7a759c0faf680f326d5071d308.png)FoxyProxy是一款简单的代理管理器，可兼容许多浏览器。

  
**6****“ Proxy SwitchyOmega**  
  
  

![](../Images/80d0fc9db3f34ec5076ac30a1610b317.png)Proxy SwitchyOmega 是一款非常优秀的浏览器插件，适用于 Chrome 和 Firefox，它可以轻松快捷地管理和切换 IP 代理。

  
**7****“ Wappalyzer**  
  
  

![](../Images/cfdf95f1d2fa64628be39687fbd60fe9.png)Wappalyzer 通过检查网站的源代码、HTTP头文件、Cookie、JavaScript 变量等其他技术方法，在数百万个网站上追踪了上千种网络技术，并使用他们的内部爬虫进行深入分析。

![](../Images/d392bf95f143e7a2f549046839b2e955.png)

  
**8****“ X-Forwarded-For Header**  
  
  

![](../Images/82998b145635f26028708d5a51440803.png)X-Forwarded-For Header扩展允许您快速设置X-Forwarded-For 一起其他HTTP Header。

![](../Images/1539eb16d208d8ebdd7073879713c699.png)

  
**9****“ 网页编码修改（Charset）**  
  
  

![](../Images/45edac0a7ad837b4509e1d799dddd97f.png)如果你在上网过程中，发现网页加载是乱码，那你需要用到这个插件，随意调整页面字符编码集，如简体中文、繁体中文、GBK、UTF-8、韩文、西文、日文等等，确保你的正常访问！

![](../Images/4f883489ac8c9bc6cb6db9e11abaa6d9.png)

  
**10****“ web编码解码工具**  
  
  

![](../Images/f35d581cf8b3cf976afa51acb4946757.png)web编码解码工具可以在浏览器端方便地进行Base64、URL、HTML实体编码解码。

![](../Images/3534ca5798fa393bc4b3e19f1b769b07.png)
