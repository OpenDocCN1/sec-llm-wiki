01

MSSQL-SQLi-Labs



MSSQL-SQLi-Labs是一个基于微软SQL Server数据库的注入靶场。


02

安装WinServer 2008



往期文章：教程 | 手把手教你安装Windows Server 2008


03

安装SQL Server 2008 R2



后台回复“ SQLServer ”获取安装包链接


安装数据库

解压缩ISO文件，找到setup，双击运行


选择全新安装

输入链接中的密钥

接受条款，点击下一步

安装程序支持文件

接下来没有提示的步骤，直接点击下一步即可

选择SQL Server功能安装


全选，点击下一步

默认，点击下一步

对所有SQL Server服务使用相同的账号，选择system，密码为空，点击下一步



 

选择混合模式，为sa设置密码，然后点击“添加当前用户”，点击下一步

添加当前用户，点击下一步


默认，点击下一步

默认，点击下一步

点击安装

安装完成


创建数据库

找到SQL Server Management Studio，点击进入

选择SQL Server身份认证，输入密码点击连接

在SQLServer中创建一个库，名为test




04

安装IIS



打开“服务器管理器”，选择“角色”，“添加角色”

勾选Web服务器IIS，点击安装即可


添加站点

在开始菜单中搜索IIS

找到网站中的Default，右键选择浏览

将靶场的源码替换原有的文件


05

安装MSSQL-SQLi-Labs



修改源码config.asp中的数据库密码

修改完成后，访问链接http://ip/index.asp

首次进入，需要点击install

靶场安装完成！
