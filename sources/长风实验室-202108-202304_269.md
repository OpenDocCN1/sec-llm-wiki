## MSSQL-SQLi-Labs

  
  

MSSQL-SQLi-Labs是一个基于微软SQL Server数据库的注入靶场。

  

02

安装WinServer 2008

  
  

往期文章：[教程 | 手把手教你安装Windows Server 2008](http://mp.weixin.qq.com/s?__biz=Mzg4MDY1MzUzNw==&mid=2247489839&idx=1&sn=bf938b8c610c3ff7ae15f6d4a3c003df&chksm=cf70bca1f80735b713d3e5643649e009aea9cc02a10c7b00548ab846f9f048eb4a99107204fc&scene=21#wechat_redirect)

  

03

安装SQL Server 2008 R2

  
  

后台回复“ **SQLServer**”获取安装包链接

  

**安装数据库**

解压缩ISO文件，找到setup，双击运行

![](../Images/afa8b001d4c0c460394ebf2f340836b5.png)  

选择全新安装

![](../Images/18842af8b7c66750d549fdc552339aa3.png)

输入链接中的密钥

![](../Images/4fc4479e076a51e49017aacb975a6a4f.png)

接受条款，点击下一步

![](../Images/0a92b679d1dd5780e8d5d82c2b68fdde.png)

安装程序支持文件

![](../Images/3a4ec44f808e647f2b034ae5984a51df.png)

接下来没有提示的步骤，直接点击下一步即可

选择SQL Server功能安装

![](../Images/bed7e196450dcc3bd1b2b83e708087aa.png)  

全选，点击下一步

![](../Images/2eb58ec394b73c00740a85be18cc8540.png)

默认，点击下一步

![](../Images/156cfe402d3318eff122aa094df08d84.png)

对所有SQL Server服务使用相同的账号，选择system，密码为空，点击下一步

![](../Images/dca48535a4ad526630e9848d7129c644.png)  

  

 ![](../Images/0609cbe55672a2510f9d070bc4cc97a4.png)

选择混合模式，为sa设置密码，然后点击“添加当前用户”，点击下一步

![](../Images/5bd1b61c3649550faf65032b4ed375a9.png)

添加当前用户，点击下一步

![](../Images/302a0dae1dddcc3679f55fbf67e74ca3.png)  

默认，点击下一步

![](../Images/491dd4c0711cca68a56e2e39d0a4e46d.png)

默认，点击下一步

![](../Images/8a4604b6fb303e296d754c905d6ecadd.png)

点击安装

![](../Images/95807739ad4973f5fb328ad8649ef90e.png)

安装完成

![](../Images/5561f31f7893f1f5066b3e0a7b31deda.png)

  

**创建数据库**

找到SQL Server Management Studio，点击进入

![](../Images/46167d1ffe6401ede365065cbd61c220.png)

选择SQL Server身份认证，输入密码点击连接  

![](../Images/15d511f443ed7247735549abe052a0e1.png)

在SQLServer中创建一个库，名为test

![](../Images/46ccc2c31eadcc633eca4b1e702c66f4.png)

  

![](../Images/0f4b6e78555941bace1f75b7b6bff913.png)  

  

04

安装IIS

  
  

打开“服务器管理器”，选择“角色”，“添加角色”

![](../Images/8e601f7c9d557b759d94100987652daf.png)

勾选Web服务器IIS，点击安装即可

  

**添加站点**

在开始菜单中搜索IIS

![](../Images/c4704b2bebf137e9ac8dcf417b7e1bd6.png)

找到网站中的Default，右键选择浏览

![](../Images/e817f5070e2ffeceae273d014f331d8a.png)

将靶场的源码替换原有的文件

![](../Images/e3c7d15c7bf6aaa23009ccb652f867c6.png)

  

05

安装MSSQL-SQLi-Labs

  
  

修改源码config.asp中的数据库密码

![](../Images/aa6ece357eb76f26fc4a24a5acc50c12.png)

修改完成后，访问链接http://ip/index.asp

首次进入，需要点击install

![](../Images/d6aa4344608414774b51fafeb5c3f26f.png)

靶场安装完成！

![](../Images/ef887d795ca78d19bc6b41c956424805.png)
