漏洞简介

当 Tomcat 运行在 Windows 主机上，且启用了 HTTP PUT 请求方法（例如，将 readonly 初始化参数由默认值设置为 false），攻击者将有可能可通过精心构造的攻击请求向服务器上传包含任意代码的 JSP 文件。之后，JSP 文件中的代码将能被服务器执行。





漏洞影响

Apache Tomcat 7.0.0 - 7.0.81





漏洞复现



环境搭建


docker镜像地址：

vulfocus/tomcat-cve_2017_12615:latest

# 拉取镜像docker pull vulfocus/tomcat-cve_2017_12615:latest
# 启动docker环境docker run -d -p 8080:8080 vulfocus/tomcat-cve_2017_12615:latest
