安装VMWare

VMware与kali安装


下载镜像

在公众号回复"winserver"获取下载链接




开始安装

在VMware主界面选择“文件”新建虚拟机。

选择“典型”，点击下一步。

选择“稍后安装操作系统”，点击下一步。


选择 Windows Server 2008 R2 x64，点击下一步

给虚拟机命名，选择安装位置后，点击下一步。


默认点击下一步。

点击完成。

点击“编辑虚拟机设置”。


左边选择“CD/DVD”，右边选择镜像的路径，之后点击确定。

点击“开启此虚拟机”。

稍等开启。

点击“下一步”。

点击“现在安装”。

选择第一个，点击下一步。

接受条款，点击下一步。

选择自定义。

默认点击下一步。

等待安装。

点击“立即重新启动”。

点击“确定”后创建登录密码。

使用密码登录之后，关闭默认打开的两个页面。

安装完成。





安装VMWare Tools

首先需要安装补丁kb4474419，之后才能安装VMWare Tools。
在控制面板找到 Internet选项，选择“安全”，取消保护模式。

打开浏览器，进入百度主页，搜索 kb4474419。
任意点击一个下载，下载之后运行补丁安装程序。

安装完成之后点击“立即重新启动”。

在VMware里面选择“虚拟机”，点击“安装VMware Tools”。

进入Win Server 2008，键盘按下win+r，输入 D:\setup.exe，之后点击确定。

弹出安装窗口，默认选择安装即可。



安装完成之后重新启动，即安装完成。
