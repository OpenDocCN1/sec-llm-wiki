***开始安装***

在VMware主界面选择“文件”新建虚拟机。

![](../Images/04a6fd3d624d2e01b2f18d21ccb71ae2.png)

选择“典型”，点击下一步。

![](../Images/c0db74797289dc80beeb7d7bc4bef0d3.png)

选择“稍后安装操作系统”，点击下一步。

![](../Images/691c6b9dd4dc8357c15cb13b400cd720.png)  

选择 Windows Server 2008 R2 x64，点击下一步

![](../Images/bb14e06524adc31a321ce8c608b89ca0.png)

给虚拟机命名，选择安装位置后，点击下一步。

![](../Images/26b61cd3b28a2cbc5daf40105af8782b.png)  

默认点击下一步。

![](../Images/caee2416c3f98e652c6499e5b8e13e45.png)

点击完成。

![](../Images/5bbdccee2f17bc9c68fb26bc16fec78c.png)

点击“编辑虚拟机设置”。

![](../Images/2263a0aeb2a56744074836210220f137.png)  

左边选择“CD/DVD”，右边选择镜像的路径，之后点击确定。

![](../Images/326dbd784f4f33cd84bfa4a16eca2c29.png)

点击“开启此虚拟机”。

![](../Images/db0494e34bfb80e1c6f1369f23c376ee.png)

稍等开启。

![](../Images/f46f22d2df8b45d850b9b24706f1b605.png)

点击“下一步”。

![](../Images/f04073a29d5923c677c50f9fb3be56d3.png)

点击“现在安装”。

![](../Images/465f11e142d7a228d3b001a20177df36.png)

选择第一个，点击下一步。

![](../Images/fd7cb4bea49e5bece5196409e9019a68.png)

接受条款，点击下一步。

![](../Images/45aa2f40a386883a0b258d7eca1d778c.png)

选择自定义。

![](../Images/8d7592f1afbf9b8df311971842bf1bb2.png)

默认点击下一步。

![](../Images/dbc9ff49504beec56734a13fe5b3da91.png)

等待安装。

![](../Images/7acf6d9c4f977d13b1869347bc80b48b.png)

点击“立即重新启动”。

![](../Images/e581c12ca5304eac1ad07626fdf113c8.png)

点击“确定”后创建登录密码。

![](../Images/988f1975a3a7ee51557d00039030d903.png)

使用密码登录之后，关闭默认打开的两个页面。

![](../Images/d7c3ba25be5e256685c0d1bc4a1e028a.png)

安装完成。

![](../Images/b9d776a0fb6d69ad32d267d6927fdcc8.png)

  

  

  
  

***安装VMWare Tools***

首先需要安装补丁kb4474419，之后才能安装VMWare Tools。在控制面板找到 Internet选项，选择“安全”，取消保护模式。

![](../Images/8817b2caa354642905824b7fa4b3ea8e.png)

打开浏览器，进入百度主页，搜索 kb4474419。任意点击一个下载，下载之后运行补丁安装程序。

![](../Images/c15d25365d0cf5502def5a88eec0271e.png)

安装完成之后点击“立即重新启动”。

![](../Images/e37779c5391b18866096336ea6721d85.png)

在VMware里面选择“虚拟机”，点击“安装VMware Tools”。

![](../Images/ddede3c3ab52baeb086e76d9009128bb.png)

进入Win Server 2008，键盘按下win+r，输入 D:\\setup.exe，之后点击确定。

![](../Images/f41d6c3eb45d261874b968e39980c02e.png)

弹出安装窗口，默认选择安装即可。

![](../Images/30e09c0f3e3a0a84116ed29301a50493.png)

![](../Images/f5d2f9580a2c0da78665ca347007e9e9.png)  

![](../Images/e6e936d9d2e18757d2ec84985e4fb18f.png)  

安装完成之后重新启动，即安装完成。  
![](../Images/a416865c44c758e95587dd7044be45fd.png)
