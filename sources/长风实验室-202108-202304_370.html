Vulhub是一个面向大众的开源漏洞靶场，使用者只需简单执行两条命令即可编译、运行一个完整的漏洞靶场镜像。Vulhub旨在让漏洞复现变得更加简单，让安全研究者更加专注于漏洞原理本身。 





安装docker和docker-compose

请看往期文章：教你如何在Kali中安装docker




下载vulhub

Kali中自带git工具，使用git可以下载vulhub
使用如下命令即可：
git clone https://github.com/vulhub/vulhub.git





漏洞测试

这里我以tomcat8弱口令来测试
首先进入它的目录

进入到vulhub/tomcat/tomcat8/目录下
执行以下命令构造测试环境
docker-compose up -d



访问: http://ip:8080


默认账号tomcat密码tomcat可以登录

测试成功

附上Vulhub的官方文档：
https://vulhub.org/#/environments/
