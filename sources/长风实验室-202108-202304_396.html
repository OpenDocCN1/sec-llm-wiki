我们在测试一些网站的时候经常会出现登陆验证需要验证码的情况。这时候很多朋友测一下弱口令发现不行就放弃了。那有没有一个种工具或者脚本能帮我们识别验证码，从而让我们能爆破更多的口令呢？



不要急，百度AI识图来了。
对付一些中规中矩的验证码百度识图的精度还是很高的。



但对于一些比较抽象的验证码，AI识图的性能就有点不尽人意了，这种高难度的验证码只能请专业的机器学习识图大佬，或者对接付费的打码平台来做了。什么是打码平台？请自行百度。



本次以一道CTF苦力题来做演示

此题中用户名和密码都已经给我们了，我们要做的就是提交1000次验证码！不会有兄弟手工提交1000次吧!!! 不废话上百度识图，识图之前先滤清逻辑。



抓个包 ，发现数据很清晰，post提交表单，带上自己的cookie就能给自己的次数加一。




复制验证码图片地址发现能直接访问



那使用python访问图片并编码为base64发送给百度识图接口就可以了。
百度识图地址：
https://ai.baidu.com/tech/ocr_general
选择 ：文字识别 –> 通用文字识别； 
点击立即使用：我们看一下百度识图接口需要的参数




文档中告诉我们加上access_token 将base64图片以post方式发送给识图接口就可以了。

3、开始访问百度识图 API ，打印出来的flag就是验证码了，不同接口的返回数据不相同，打印出res.text自己用正则处理一下。

# 请求头    headers = {       'Content-Type':'application/x-www-form-urlencoded'    }    # 请求 URL    host='https://aip.baidubce.com/rest/2.0/ocr/v1/formula'    host = host+'?access_token='+access_token    # 请求体    data = {}    data['access_token'] = access_token    data['image'] =img    # post请求    res = requests.post(url=host,headers=headers,data=data)    print(res.text)    flag = re.findall('"words":"(.*?)"',res.text)[0].replace(" ", "")    print(flag)
