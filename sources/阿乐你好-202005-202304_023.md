## 安卓导入Charles系统级证书

![](../Images/d9deb18b55f4148b3928583cdda4ce1c.png "安卓APP抓包解决方案(教程)插图5")

生成一个.pem的证书，但是安卓系统级的证书是.0结尾的，所以需要转换一下，我们通过kali中的openssl来计算出文件名就可以。

此处参考文章：https://www.cnblogs.com/YenKoc/p/14376653.html

拷贝pem文件charles.pem到KALI系统的opt目录，使用命令:

```



openssl x509 -subject_hash_old -in charles.pem
```

![](../Images/828e05997ed4e86ef630845f76aaf220.png "安卓APP抓包解决方案(教程)插图6")

\# 3ce07b0d为上步中的hash值

接着通过adb shell来把文件传到`/system/etc/security/cacerts/`目录中

连接命令:

```

.\nox_adb.exe connect 127.0.0.1:62001
```

![](../Images/c2152a2c6e2ee80d1bb282be68cde1a1.png "安卓APP抓包解决方案(教程)插图7")

拷贝证书文件到/data/local/tmp，然后连接shell

```


.\nox_adb.exe push Q:\3ce07b0d.0 /data/local/tmp
```

![](../Images/97f8f05c22171852bbe2fa925ab6948e.png "安卓APP抓包解决方案(教程)插图8")

执行下面命令，进行拷贝证书到系统证书目录:

```


mount -o rw,remount -t auto /system
```

![](../Images/8108686da21d7f91008442faac483c47.png "安卓APP抓包解决方案(教程)插图9")

然后重启，输入`reboot`就可以。

几秒钟之后重启就可以发现凭据里有了charles的证书

重启之后点击安卓系统里面的设置>安全>信任的凭据>系统>

![](../Images/be4f4ea263dda41c089fa337eeee8dc2.png "安卓APP抓包解决方案(教程)插图10")

## 联合burp

因为charles抓包能力强但是不好做修改数据包之类的操作，所以我们就再做一层代理到burp来方便我们渗透测试人员。

proxy - external proxy settings

 

![](../Images/dd556361e2b6e3101a16598e1b0b0b5f.png "安卓APP抓包解决方案(教程)插图24")

记得两个选项都要配置127.0.0.1:8080，因为我们的burp就是默认监听8080端口的，若不是8080，改成自己burp上监听的端口就可以了。

 

![](../Images/2495395d9baebb702315af7fbce9bb2f.png "安卓APP抓包解决方案(教程)插图25")

![](../Images/777191b8f093e6d75ddac602a324abb6.png "安卓APP抓包解决方案(教程)插图26")
