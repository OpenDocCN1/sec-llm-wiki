# 应届生轻松年薪10万+！零基础渗透测试集训营，包就业

根据智联招聘发布的《2022年网络安全人才市场状况研究报告》指出，网络安全相关岗位的薪资中，政企机构提供的相关岗位的平均薪酬约为12157.5元/月，安全企业提供的网络安全相关岗位的平均薪酬约为13718.5元/月。可见网络安全行业的年薪可轻松达到10万+。

![](../Images/5baca83dc9b43900855d33f087e3886e.png)

为了帮助更多的大学生或求职者进入网络安全相关岗位，拿到更高的薪资，承制科技推出安程似锦保年薪入职计划 —《渗透测试实战工程师集训营》。

**承制科技《渗透测试实战工程师集训营》将于12月开班，为了响应疫情防控政策，现调整为线上培训。**

**渗透测试实战工程师集训营**

**集训对象**

1.  全国各大高校大二至大四的计算机/信息/电子通信/网络安全等相关专业的大学生；
    
2.  计划从事网络安全行业的其他专业的大学生；
    
3.  对网络安全、攻防实战感兴趣，能吃苦耐劳的爱好者。
    

**开班计划**

1.  开班人数：40人
    
2.  开班时间：2022年12月
    
3.  学习周期：4.5个月
    

**学习目标**

1.  通过理论加实战技术的学习和实践，全面了解掌握各大厂商的主流设备及工具；
    
2.  通过全体系的技术培养，让学生迅速成长为【理论+技能+实践】的实用型的企业必需的人才；
    
3.  安程无忧，全方面提高学员的面试技巧、简历优化、职业道德、职场素养，更重要的是提升学生的网络安全意识及网络安全相关法律的普及；
    
4.  获得知名网络安全企业青睐，一线城市年薪10W+。

**职位匹配**

承制科技通过对用人企业的岗位需求分析，有针对性的培养人才技能。在培训结束会梳理并分析学员人才测评报告，与用人单位的岗位需求进行匹配，综合测评报告结果与企业需求匹配的学员直接推荐企业入职。测评报告不符合企业用人标准的学员，将会通过承制针对于企业需求的专项技能培训与进修，圆满毕业后可再次进行企业推荐/就业推荐。

**入职后陪伴成长**

承制科技将会定期对学员入职后状态进行追踪。如果发生了任何偏离，通过与企业和学员本身进行定期回访，及时对偏离的情况进行评估，反馈信息，并采取一定的措施，保证进度能够按照原来的设定实现员工与企业共同利益最大化。
