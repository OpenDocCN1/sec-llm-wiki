# 1\. 背景介绍

在攻防的时候，尤其在钓鱼时，常常需要对`Cobalt Strike`设置上线提醒，本文将从单用户提醒到多用户提醒，微信提醒到邮件提醒等进行描述。本文代码已经放到我的`GitHub`上：

`https://github.com/crow821/crowsec`如果师傅有需要的话，可以自行修改下即可使用。（文中部分代码参考`https://github.com/lintstar/CS-PushPlus`）

  

![](../Images/041790b0d8701f5fadf853702a61a500.png)

  

以前大部分都是使用server酱进行上线提醒，但是现在server酱免费版每日只能提醒5次，其余的都需要收费，所以这里以`pushplus`示例，目前`Pushplus`的日发送频率最大额为200次，基本满足日常攻防使用。

  

![](../Images/82046025c75c2e7c24be29cb1685664f.png)

图片参考：`[https://mp.weixin.qq.com/s/iCo8p5C-MTVh-LEFybHiTg](https://mp.weixin.qq.com/s?__biz=Mzg3OTQzNzY5Ng==&mid=2247483771&idx=2&sn=384d40994eca3bfe13beae4d8c322412&scene=21#wechat_redirect)`

# 2\. 微信单人提醒

在`http://www.pushplus.plus/push1.html`上扫码登录，会生成一个token。

![](../Images/bce306e0a91b47fc81334c025cd31b99.png)

在`https://github.com/lintstar/CS-PushPlus`里下载两个文件：`PushPlus.cna`和`PushPlus.py`

在`PushPlus.py`中将你刚刚的token进行替换：

![](../Images/c74e4e2fb3b35be0a2c0be5bf053e97f.png)

`content` 部分的信息可以自定义修改，修改完成之后，可以在本地使用python3进行测试：

![](../Images/a8d4e3d6a9e4941639ffc68b23becd45.png)

运行之后，微信收到通知：

![](../Images/dab4c2d2bd204b2abd643b9b4dfe578c.png)

  

测试成功之后，将文件传到服务器上，并且对 `PushPlus.cna`文件进行配置：

![](../Images/c40d244f82aa6a668ce296f780ae5e01.png)

其中红色部分为你当前文件的路径：

![](../Images/fe71bcadab025e70e819b2220c00b92a.png)

在配置完Cobalt Strike之后，可以用命令启动该脚本将其挂载到后台，注意你运行的路径

```
nohup sudo ./agscript Cobalt\_Strikeip 端口 用户 密码  CS-PushPlus-main/PushPlus.cna > PushPlus.log 2>&1 &
```

```


Agscript 用法
```

运行成功之后，可以使用`ps -aux | grep agscript` 查看当前进程：

  

![](../Images/c52b534c17d103f791464b876b924db3.png)

当有新主机上线时，在微信中会收到提醒：

![](../Images/ac3c6673b9e32f61f5be15e2855d7276.png)

# 3\. 设置微信多人提醒

`Cobalt Strike`的优点就是支持多人同时进行操作，因此在攻防中，可以对一台`Cobalt Strike`配置多人提醒，当有机器上线时，可以同时通知所有人，`Pushplus`目前也支持这种。

去 `http://www.pushplus.plus/push2.html`记录自己的token

新增一个群组：

![](../Images/81559b1970685b8fa009a1408d70bb6a.png)

![](../Images/973d69f817a543484e28cfc0be84a4c5.png)

在这里需要记住你的群组编号，按照`Pushplus`的官方文档，当前群组与单人提醒不同的地方在于传参的时候增加了一个`"topic"`参数。这里需要配置的信息如下：`"topic":"test1221",`

当前文件名称：`Pushplus_many.py`

![](../Images/a8cd18e24428ccd7a840cbef72a205b5.png)

  

配置完成之后，把上面新建的群租二维码发给其他人扫一扫加进来：

![](../Images/bb701c0a26b40a0eb576cfc42b96a125.png)

扫描完成之后，`pushplus公众号`会回复自定义设置的关键信息，代表加入成功。

![](../Images/3577335a27d6352edadbe6f55b83e5fc.png)

此时在创建的群组里也可以查看到当前加入的订阅人，在这里需要注意，群组即使是你创建的，你也需要扫码加入才可以。

![](../Images/981757e7f8cde67c7b5735f2b7df346e.png)

  

配置完成之后，在本地可以测试下：

![](../Images/9cf9310648c0885c8da5728645b73d9d.png)

此时群组内用户都收到了消息：

![](../Images/b777b99c36b3a4ba7cff11376b0080ca.png)

本地测试成功之后，将文件放到云服务器上使用同样的方式进行部署即可！

# 4\. 钉钉群上线提醒

钉钉群和上述的方法基本相同，首先需要在钉钉中拉群一个群聊，并添加一个机器人：

  

![](../Images/c7330a5688d4787f9af4b16805e386e0.png)

点击自定义：

  

![](../Images/4ce174ed6f7077d36eb65bd38bf3d950.png)

选择添加即可获得一个`Webhook地址`

```
https://oapi.dingtalk.com/robot/send?access\_token=12345678
```

在`Pushplus`公众号中，找到个人中心，并在渠道配置中进行配置：

![](../Images/95df9511675f0841ef8bced94736f1ac.png)

选择`Webhook`，填写相关信息：

![](../Images/91e5c45eefc674a633741ae1deb203d3.png)

确认之后，在脚本里面进行修改：`"channel":"webhook",`  `"webhook":"1221"`

![](../Images/960908327a20022886416cc5d7fc1860.png)

在这里确认你的Webhook地址信息，修改完成之后，在本地可以运行：

![](../Images/6186ab0e47226dc370da0f766ee3ad3e.png)

然后在钉钉群组就收到消息了：

![](../Images/5af2ee21aaddfb6b6c279c11d37e6f9c.png)

本次测试成功之后，直接将脚本部署到云服务器上即可，方法参考第二节。

# 6\. 注意事项

在使用`Pushplus`推送的流程中，还有一个比较重要的问题：如果短时间内有多个相同主机上线，`Pushplus`会默认不发送重复数据内容，而且对发送频率也有要求：

![](../Images/f3f6248378ac1d30fab63147e8ca5626.png)

  

![](../Images/fc1c2e3bc2694beae4fb5f805cabb9e8.png)

  

一般来说，短时间大量主机上线的概率不是很高，所以在上面的两个问题中，要优先解决短时间不默认发送重复数据内容，因此在以前的代码中，可以加入随机数或者时间戳，在这里以加入时间戳为例：

# 8\. 总结

在以上的方法中，主要讨论了利用第三方推送`Pushplus`进行微信单人、群组；钉钉群组；第三方邮件提醒方法，当然在`Pushplus`中还有其他的提醒方式，这种方式推送方式较多，但是缺点就是容易暴露个人信息。所以在本文提出了使用更加隐蔽的邮件提醒方法，优点就是不会暴露私人信息，缺点就是只能使用邮件提醒，而且需要使用两个邮箱账号。
