**事件背景**  
微步情报局近期检测到 SonarQube 未授权访问漏洞出现大规模在野利用，关联漏洞编号为 **CVE-2020-27986** ，漏洞评级：**高危**。SonarQube 是一个开源代码质量管理和分析审计平台,支持包括 Java、C#、C/C++、PL/SQL、Cobol、JavaScript、Groovy 等二十余种编程语言的代码质量管理，可以对项目中的重复代码、程序错误、编写规范、安全漏洞等问题进行检测，并将结果通过 SonarQube Web 界面进行呈现。此次受影响 SonarQube 版本如下：

| SonarQube版本 || 是否受影响 |
| --- | --- |
| <8.6 || 是  
 |
| \>=8,6 || 否  
 |

2  
**漏洞概况**  
该漏洞是由于配置不当造成的未授权访问，攻击者可以利用该漏洞在未授权的情况下访问 api/settings/values 接口从而获取到 SMTP、SVN、GitLab 凭据，进一步获取其它敏感代码和数据信息，造成严重危害。3  
  
**修复方案**  

根据检测工具排查受影响资产，并更新升级至新版本。
