# 安全“经典三问”，原来作用这么大！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMjUzNzYyNA==&mid=2247483760&idx=1&sn=615e0863b5d24d39d8b051601852be09&chksm=e82ab387df5d3a91e69f58c3098098e0e8177941de7f59bd106440e50811807fce995a3c449b&scene=126&sessionid=1681322020#rd](http://mp.weixin.qq.com/s?__biz=MzIyMjUzNzYyNA==&mid=2247483760&idx=1&sn=615e0863b5d24d39d8b051601852be09&chksm=e82ab387df5d3a91e69f58c3098098e0e8177941de7f59bd106440e50811807fce995a3c449b&scene=126&sessionid=1681322020#rd)

   前段时间与某安全公司创始人吴总在探讨企业未来安全建设问题，以及未来安全公司的产品方向时，吴总根据安全企业自身的发展经验和之前在甲方公司工作的经历，提出了安全**“经典三问”****：如何发现问题？如何解决问题？如何保障不出问题？**个人认为这是三个很好的问题，也是很重要的问题。****  

   之所以这么说，首先是因为当前国内安全行业经过10多年的发展，安全的理念现在已经开始被市场上的企业普遍接受了，不管接受了多少，至少都知道信息安全很重要，就像20年前，制造型企业都觉得ERP很重要一样。另外，在产业互联转型的浪潮下，科技赋能企业业务的速度也加快了，信息安全伴随科技而生，但是因为市场上，安全人才缺乏，安全预算不高，企业中的安全措施落地效果一直不太理想。**在这种背景下，不管是甲方的安全从业人员，还是乙方的安全公司都在寻找一种方式，让自家的安全水平能快速提高，让自己的安全产品能够得到市场的认可，**“经典三问”在这方面都能帮上大忙**。**那么，这安全“经典三问”对安全从业人员，乙方安全公司到底能起到什么作用？阿肯认为大致可以从以下三个方面考虑：

 

**1、“**经典三问**”是一种思维逻辑，让企业安全人员工作更加得心应手。**

    

   目前很多企业的安全建设还处于依据27001，或者等保落地安全体系建设的过程中，比如出制度、建组织、落产品等。企业安全人员在做这些事情的时候并不轻松，废了九牛二虎之力这些工作做完了以后，企业领导发现这些措施并没有达到他们当初的想法，安全人员觉得很委屈：其他公司也是这么做的，为什么我们做了这么多事却得不到肯定？

  其实，我们要明白一个问题：安全的目的是解决/处置风险，按照27001的说法，就是处理CIA的风险，防止数据泄密、保障系统安全可用、防止系统数据被篡改。但是安全的领域有14大类，130多个项目，企业不可能，也没必要一下子把所有的风险都处置了。所以，最好的方式是一个一个解决，这个时候就可以用到经典三问，解决每个风险项的时候，都需要考虑“如何发现风险、如何处置风险、如何规避后续的风险”这三个问题。

   比如，如果安全人员发现企业第一关注的风险是员工的安全认知问题，就可以利用经典三问的逻辑落地。

   首先，要发现员工的安全问题：通过调研，问卷，钓鱼等多种方式，摸底员工对安全的认识点和不足的具体点。

   其次，知道了问题所在，接下来就可以制定解决问题的方案了，员工的安全认知不足可以分为几类，1）有的是不了解在公司需要遵守什么样的安全底线。这种情况，安全人员根据公司实际业务情况，发布安全底线就可以了；2）有的员工对风险很敏感，但是缺乏规避的手段，这种情况，安全人员针对性进行常规安全技能培训考核就可以了；3）当然也有些同事总是会抱有侥幸心里，觉得无所谓，拒不执行公司的安全要求，那就通过稽核检查出报告，嗮清单的方式。

   最后，员工安全素养不是一次性工程，也需要不断的运营提升。企业安全人员，可以将员工的安全考试分数、内部提报的安全奖励分数、或者因安全问题被罚的次数、系统记录的电脑端违规、系统使用端违规以及特权账号的使用违规记录等都放到员工的安全指数中，通过日常的运营来及时发现和应急，来规避风险。

   **所以，基于管理信息安全风险的目标，安全“经典三问”这个思维逻辑就可以逐步闭环解决安全风险管理领域的每个风险项。坚持按这个逻辑做下去，企业的安全跟业务和文化就能融入很好，安全的体系化运作自然而然就建立起来了。**

 

**2、“**经典三问**”是火箭助推器，让安全ERP落地更加快捷高效。**

   如果我们的企业科技水平比较高，很多业务都实现了信息化、数据化，甚至自动化。那么这个阶段的安全建设就可以按照一句话安全的思路走：安全的员工，使用安全的设备，经过动态的鉴权，精细化的授权，访问安全的系统[（详细内容见《未来5年，企业安全建设落地思考-一句话安全》）](http://mp.weixin.qq.com/s?__biz=MzIyMjUzNzYyNA==&mid=2247483736&idx=1&sn=8045446d37233d63072293227d9b1435&chksm=e82ab3afdf5d3ab918b6bf978a530e894ffa353ad227d0d4a929f03fa19f25301f699c89f191&scene=21#wechat_redirect)。这种安全建设思路意味着，所有的安全要求都需要通过技术手段，产品思维去落地。安全的“经典三问”对于打造安全产品将会产生意想不到的效果。

   比如，如果企业要解决应用系统安全的风险问题，可以利用经典三问的思维，建立应用系统风险管控平台。

   首先，安全人员开发部署好发现风险的工具，包含资产发现（资产发现需要全而准，这是个业界难题，找时间可以专题介绍）和漏洞发现的工具，通过内/外部的安全扫描渗透发现系统存在的风险。

  其次，虽然应用系统安全风险的可视问题解决了，但推动风险解决的落地是一个更加难的问题。因为业务永远是企业的第一位，安全人员在跟产品开发人员沟通的时候，经常会被一句话堵回来，产品延迟上线你负责吗？增加防护措施影响了业务运行你负责吗？如何做到安全与效率的平衡，这个时候需要有一个风险推送的平台，把之前发现的某个资产有什么问题，高中低，对业务的影响，整改方案，要求整改时间等这些都通过风险管理平台推送给开发，产品和运营人员，没有解决就一直推送提醒，持续这样就能很多推动漏洞整改的落地。

  最后，产品开发是一个长期的生产过程，安全人员保障产品安全质量不出问题，这也需要有一个闭环的安全平台将风险管理起来。企业安全人员可以开发一个产品安全指数的统计报表，将每个应用系统在架构、代码、测试、上线运行各个阶段的风险发现、整改、延期、重复出现等情况做成统计报表，同时给出一个安全指数的对比，一来可以及时发现和处理应用系统存在的安全风险，二来可以让应用系统的负责人对自己产品的安全质量变化有个清晰的认知，这也是安全赋能业务的价值所在。

  所以，**基于未来一句话安全，“**经典三问**”可以让安全类的产品开发运营的目标和价值更加清晰，研发一个安全产品就解决一类风险**。**经过这种逐步迭代建设的过程，企业的安全ERP就可以逐渐形成，达到安全风险管理的信息化、数据化和自动化的效果。**

 

**3、“**经典三问**”是安全公司的产品原型图，让安全厂家的产品在未来更有竞争力。**

   因为市场的变化，科技在业务中的应用，企业业务对安全的需求也越来越高，安全产品市场正在从传统的探针式产品，走向问题解决型产品，而且这个变化会很快。面对此时模糊不清的市场需求，一方面，安全厂家要有海豹突击队的组织，以客户为中心的服务理念、为快不破的产品开发、适度超前的研发投入；另一方面，**就需要有安全“经典三问”的落地工具，帮助厂家清晰定位市场需求和产品逻辑，聚焦解决某个具体的安全痛点。**

   比如，做堡垒机的安全厂家，面对的是存量市场，产品第一曲线已经走得差不多了，需要尽快找到企业的第二曲线。但是市场对安全的需求很多，到底转型到哪里去呢？ 这时，**“经典三问”可以帮助安全厂家找到这样的客户场景，在不需要大量投入的情况下，验证测试安全产品，避免闭门研发带来的产品失败风险。**

   首先，厂家基于以客户为中心的理念，可以跟有痛点的客户聊，他们的业务痛点在哪里，头部客户对未来安全的需求，再结合厂家自身的经验看法，判断市场到底需要什么样的安全产品。

  然后，厂家对每个行业的客户需求进行梳理后，就可以针对普遍性问题进行思考和分析，企业安全人员需要用到堡垒机中的资产，实际上是要解决安全运维自动化的问题；客户会提出在堡垒机上加上准入/鉴权/授权/支持各种协议的需求，就是要解决随时随地远程研发/联调的安全问题...。在深入分析了客户需求的背后逻辑后，安全厂家就可以利用堡垒机接管了大部分IT资产的优势，建立动态及时的安全资产库，从而转向安全自动化运维的方向；也可以利用堡垒机原有的鉴权、授权、审计等功能，做一个超级网关，在解决随时随地远程研发/联调/运维的安全体系中，发挥关键的作用（详见内容见[《随时随地远程研发/联调安全的前景》](http://mp.weixin.qq.com/s?__biz=MzIyMjUzNzYyNA==&mid=2247483698&idx=1&sn=f6ec6244d79a0f4e5e0620a4295ab499&chksm=e82ab3c5df5d3ad36cb159a1e32f9a9f81d492beb8c05bc1963af84e7fb7f2bdcebd26bbf8d5&scene=21#wechat_redirect)）。这样**安全厂家和企业安全人员就建立了良性的沟通互动循环机制，安全厂家就能及时把握市场的脉搏，最重要的是以最低的成本，将需求转化成了市场需要的适应客户真实环境的产品。**

 

**4、经典三问与安全风险管理的关系**

   最后，我们还是要问下，经典三问与安全风险管理的关系？

   **我的理解很简单，就是一根萝卜和一把刀的关系**。如下图，安全领域的风险大致可以分为以下几类，安全“经典三问”就像一把切菜刀，不断把这些问题切割成单独的领域，逐个实现安全风险的闭环管理。

  **不管企业的安全建设处于什么样的水平，安全的“**经典三问**”都能化繁为简，各个击破，让企业的安全水平达到一个新高度**。安全厂家要发展第二曲线，也可以尝试“经典三问”，找到产品的第二曲线和落地场景。还等什么，免费的菜刀，赶紧用起来：）

 

**5、附：某安全公司创始人吴总对于“**经典三问**”的看法，供探讨。**

安全部门和运维部门面临同样的三个问题：

如何发现问题？ 

方法是监测，技术手段是：基线偏离触发+黑名单+白名单+机器学习

如何解决问题？ 

方法是处置，技术手段是：自动化编排 + 自动化调度 

如何确保不出问题？   

方法是运营，技术手段是：大数据分析平台 + 穷举应用

  

和运维不一样的是目标决定了方法和手段的差异，一个是确保业务系统的高可用，一个是发现异常。
