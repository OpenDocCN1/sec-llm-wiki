# 博览安全 放眼云上：阿里云亮相国家网络安全宣传周

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTQ2MjI5OA==&mid=2664075564&idx=1&sn=426f3283c0b664c4adc0e27a9037ed10&chksm=84aaa459b3dd2d4f89fe499764416f4bd4814f88c5562642b2e4ba8a11ead010ba28e7e5af19&scene=126&sessionid=1681366538#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTQ2MjI5OA==&mid=2664075564&idx=1&sn=426f3283c0b664c4adc0e27a9037ed10&chksm=84aaa459b3dd2d4f89fe499764416f4bd4814f88c5562642b2e4ba8a11ead010ba28e7e5af19&scene=126&sessionid=1681366538#rd)

  

9月19日-9月25日，由中央网信办、教育部、工信部、公安部、新闻出版广电总局、共青团中央等六部门举办的第三届国家网络安全宣传周在武汉召开。  

  

阿里巴巴集团亮相2016国家网络安全宣传周，从交易安全、资金保护、企业安全、生态安全和云安全五个维度，首次向外界展示其在安全领域的能力、战略、布局。 

  
**能力 + 责任 让安全成为全民红利**  

 “网络安全为人民，网络安全靠人民”为本届网络安全宣传周的主题。如今，安全走进了每个人的衣食住行，也关系着国家的稳定和平。它已不仅仅是一个行业或技术，也代表着“中国能力、中国方案”。

  

![](../Images/374c21ce69a07c873231efd113f2418c.png)  

  

在网络安全博览会上，阿里云通过数据大屏、创意T恤制作和网络安全知识漫画等形式，向现场参观者展示阿里云世界级的安全能力，以及完善的安全产品、服务体系。 

  

![](../Images/79251dfc248f301b6c6df96c1296afcf.png)  
![](../Images/09497c099d8684236fe51113f0ea35d2.png)  
志愿者正在向现场来宾介绍阿里云安全解决方案

  

近两年，云计算为技术革新、企业风险管理、重大活动护航带来了“红利”。在刚刚结束的G20峰会上，阿里云积极贡献技术力量，为峰会期间的云上安全、G20官网以及浙江省内政务、民生类网站提供安全保障，协助云上政府及事业单位网站拦截了超过1亿次攻击，封禁了3.16万个针对政府网站攻击的恶意IP。   

  

![](../Images/13c37cbe759a7c41bbd854806b1f7969.png)  
志愿者正在向现场来宾介绍阿里云安全解决方案

  

此外，通过诸如为世界互联网大会护航，为抗战胜利70周年纪念活动网络提供安全保障，为浙江省台风预警系统提供技术支撑……阿里云用“云计算＋大数据”实现了让安全能力像水、电一样，源源不断地输出给政府、机构和企业，为未来全球网络空间安全提供了“新药方”。 

  

  
**创意 + 手绘：将阿里云的“安全感”穿上身**  
  

安全知识的科普与教育贯穿了本届网络安全宣传周的议程，博览会也吸引了不少祖国的花朵。

  

![](../Images/0ba98057412c21d4d5faca01492833b5.png)

  

从大学生网络安全志愿者，再到前来参观的未来安全小卫士们，他们对安全，有着自己的态度和理解。 阿里云安全展台的创意T恤制作活动，就让大家“穿上”了自己手绘的安全畅想。

**科普 + 互动：安全知识也能让你“眼前一亮”**

  

![](../Images/3936cdf1c5bdfef5178271cfe4bf6144.png)  

  

阿里云本次参展，一改网络安全知识“高深莫测”的常态，用轻松活泼、寓教于乐的漫画，来科普网络安全的常见威胁有哪些？相应的解决方案是什么？

  

目前，阿里云提供6大安全解决方案：防DDoS，防入侵，内容安全，数据加密，业务风控和移动安全。为用户解决从云主机、网络、应用、数据、终端到内容等不同层级的安全问题，帮助用户应对复杂的云上/云下安全威胁场景，例如DDoS攻击导致业务瘫痪、垃圾注册、活动刷单、黑客入侵导致数据泄露和丢失等等。

网络空间是亿万民众共同的精神家园。阿里云希望将沉淀十多年的安全能力输出给各行各业，让稳定、可靠的云计算成为普惠国民的基础设施。同时，净化中国的互联网环境任重而道远，阿里云也希望汇聚国内外优秀安全厂商之力，为构建和平、安全、开放、合作的网络空间贡献一份力量。
