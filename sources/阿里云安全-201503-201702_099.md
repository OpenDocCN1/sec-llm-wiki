# 【微博热议】这些年，云盾抗下的那些DDoS

2016年5月21日下午，某在线支付服务平台遭遇了全球互联网史上最大的DDoS攻击之一——攻击峰值流量达到每秒318.7Gb。

  

将攻击流量引流到高防IP，确保源站的稳定可靠。 阿里云云盾高防IP成功防御，将318G的峰值流量同一时间分摊到3个IP上，用高防IP来引流，确保源站的稳定可靠。

**如果抗下318G的峰值流量**已经让你觉得不明觉厉的DDoS攻击"之一“，

  

那么…………

  

2014年，阿里云云盾**为一游戏用户抗下每秒453.8Gb攻击流量峰值**的DDoS攻击，

  

而2015年下半年，**阿里云云盾防御的最大攻击峰值流量为477Gbps**  

**这意味着什么？**

  

通常来说，300Gb每秒的峰值流量DDoS，已经是非常“痛”的力度了。

  

2013年3月创记录的300Gbps，Spamhaus、CloudFlare遭到攻击，被评价为“差点瘫痪欧洲网络”

  

2014年2月创纪录的400Gbps，攻击对象为CloudFlare客户，据称当时包括4chan、维基解密在内的78.5万个网站安全服务受到影响。

  

在2015年“1105”事件中，云盾成功防御了攻击者的海量HTTPS SSL/CC攻击，峰值达到95万 QPS，这是迄今为止全球有统计数据的最大的HTTPS SSL/CC攻击。云盾对超大规模攻击的成功防御，展示了其独一无二的防御能力。  

  

据说，在2015年下半年，阿里云安全团队共监控到DDoS攻击事件超过10万次，较2015年上半年攻击事件增加了32%。其中流量达到300Gbps以上的攻击次数达到66次。
