# 财报速递 | 阿里云Q1营收增175%，财年收入30亿！

5月5日晚，阿里巴巴集团（NYSE:BABA）公布2016年第一季度及2016财年全年业绩。

  

**财报亮点**  

  

*   2016年第一季度阿里云营收10.66亿元，同比增长175%。
    
*   2016财年（2015年4月1日至2016年3月31日）收入超30亿元，增幅达138%。
    
*   阿里云在2016年Q1营收10.66亿元，增速达175%，创历史新高。这是阿里云连续第四个季度保持三位数的营收增长。
    
*   截止今年3月31日，阿里云拥有超过230万用户，其中云计算付费用户达50万。
    
*   第一季度累计发布22个新产品和612项新功能，其中大数据方面就有12个新产品推出。
    

  

**细说财报**  

  

![](../Images/4e5786a069e0ba5f1bf6b8e4d54d9fbf.png)  

  

事实上，这已是阿里云连续第四个季度保持三位数的营收增幅，体现中国高科技服务产业的巨大潜力。

  

财报显示，2016财年（2015年4月1日至2016年3月31日）阿里云营收达30.19亿元，同比上年增长138%。

  

在该财年的四个季度中，阿里云一直保持三位数的收入增幅，增幅数字从106%一路增至175%，逐渐成为阿里巴巴集团的“第三级火箭”。

  

云计算业务的强劲增长得益于中国高科技、互联网产业，以及阿里云开始加速拓展国际市场。

  

过去12个月，阿里云对云计算大数据产品和服务进行了17次降价调整。

  

![](../Images/c6b527915258207c422b2c4dcf625a95.png)

  

阿里云研发的人工智能程序小Ai，在湖南卫视《我是歌手》决赛中，准确预测当季歌王归属李玟，成为人工智能在人类情感领域的首次突破。

  

阿里云正在将这一技术变成标准化的产品，让企业调用API即可使用。

  

![](../Images/5370d98243b0d2d72b5c754de7c749cd.png)

  

不久前，阿里云还发布了物联网、专有云(Apsara Stack)、混合云、视频云等一系列服务于企业级市场的产品和解决方案，并牵手SAP和埃森哲，共同拓展企业级市场。

  

在中国，从创业公司到大型央企，越来越广泛的企业群体选择云计算作为商业创新的基础设施。

  

阿里云的客户群体中，除了互联网创业公司，开始出现中石化、中石油、12306、海关、国家电网、北京国税、新浪微博、芒果TV等大型企业和政府机构。中国气象局、华大基因，则利用阿里云的计算和数据能力，在气象应用、生命科学等领域进行科技创新。

  

![](../Images/c4a8dc756845746ace66b5a2441efeb1.png)

  

阿里云在4月还宣布与韩国第三大跨国企业SK集团达成合作，正式进军韩国云计算市场。

  

此前，阿里云已经在美国、香港、新加坡设立了数据中心，大疆创新、飞利浦、施耐德、大拿科技等企业正在使用阿里云遍布全球的云计算基础设施。

  

未来，阿里云表示将继续拓展国际市场，在欧洲、日本、中东、印度等地设立新的数据中心。
