# RSA，我们来了！

阿里云云盾将参展7月22日\-24日于新加坡举办的RSA 2015亚太及日本大会。

  

在今年4月份的RSA旧金山大会上，RSA总裁Amit Yoran在其“逃出安全黑暗时代（Escaping Security Dark Age）”的主题演讲中，提出了信息安全的形势愈发严峻，信息失陷（Breach）事件频发，影响愈来愈大，对传统安全的变革势在必行。于是，我们看到RSA 2015主题被确定为“Change： Challenge today's security thinking（变化：挑战今天的安全理念）”。

  

“变”（Change）成为贯穿2015年度RSA大会的核心话题——包括即将在新加坡举行的RSA2015亚太及日本大会（RSA AsiaPacific & Japan 2015）。在本届RSA亚太及日本大会上，RSA总裁Amit Yoran的主题演讲是“游戏已经改变（The Game Has Changed）” ——很明显，还是改变。

  

![](../Images/7437f633fd5d4378642ba57b6d5f1f6d.png)  

  

RSA 2015亚太及日本大会将在7月22日\-24日在新加坡举行。大会一共设七个分会场，分别是安全基础设施、云计算和数据安全、移动安全、网络威胁及威胁角色、网络调查和执法、治理与风险管理、及赞助商特别专题。从专题以及各个分会场的议题来看，“威胁情报”、“APT／高级威胁”以及“云安全”仍旧是最炙手可热的几个安全关键词。

  

![](../Images/15e7441404680ae5c32bceec4b8ed7ff.png)  

  

在本届大会上，阿里云云盾将展示云盾的防护效果，包括全球网络安全实时状况、攻击地域分布、攻击及防御过程、攻击类型，特别是DDoS攻击、Web攻击和僵尸网络状况等。
