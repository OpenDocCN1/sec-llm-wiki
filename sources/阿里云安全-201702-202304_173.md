# 阿里云再次获得 CNVD 多项荣誉认定

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4MTQ2MjI5OA==&mid=2664080854&idx=2&sn=fdddc9842837ccb75f15415e65fc4fba&chksm=84aa90a3b3dd19b571b8911a7a5806cc41134bdc80370faf59d9ad434ce5831b1cc1242d1f20&scene=126&sessionid=1681366341#rd](http://mp.weixin.qq.com/s?__biz=MzA4MTQ2MjI5OA==&mid=2664080854&idx=2&sn=fdddc9842837ccb75f15415e65fc4fba&chksm=84aa90a3b3dd19b571b8911a7a5806cc41134bdc80370faf59d9ad434ce5831b1cc1242d1f20&scene=126&sessionid=1681366341#rd)

  

近日，国家信息安全漏洞共享平台（CNVD）2020年度工作会议上，CNVD 秘书处对2019—2020年度优秀成员单位、白帽子以及行业单位进行了表彰，阿里云获得 **CNVD 2020年度最具价值漏洞、年度漏洞报送贡献单位奖项**，并被认证为**CNVD技术支撑单位。**

  

![](../Images/76545a33072f2c3ef4e26271ba280a2b.png)

  

![](../Images/be232fa007febf83c5b58a949b89945b.png)

  

漏洞攻击事件影响我国基础网络设施和重要信息系统的运行安全，给国家政治、经济和社会造成了严重危害。2020年，阿里云共帮助用户修复超2000万次漏洞，支持全年近百起安全应急响应。目前应急漏洞功能已应用到云安全中心，并免费提供给云上客户一键检测，累计使用次数420余万次，发现高危漏洞超过500万个。

  

根据 Skybox Security 上半年发布的2020年漏洞和威胁趋势报告，2020年漏洞数量有可能突破新的记录—— 超过20000个。远程办公场景下，网络范围已急剧扩大，对企业来说当务之急是重新确认网络的边界和范围。组织需要能够识别个人和专业设备中存在的漏洞。

  

国家信息安全漏洞共享平台（CNVD）是由国家计算机网络应急技术处理协调中心（CNCERT）联合国内重要信息系统单位、基础电信运营商、网络安全厂商、软件厂商和互联网企业建立的信息安全漏洞信息共享知识库，是目前国内最权威的官方漏洞平台之一。

  

![](../Images/79c8af51f5629fe44c3734b050a61c7e.png)

  

作为 CNVD 的技术单位之一，阿里云安全团队实时跟踪安全态势更新漏洞 POC 库，形成漏洞检测、响应、修复的正向循环，为提升企业用户安全防御水平贡献力量。
