# 【漏洞通告】Apache HTTPd 2.4.49/2.4.50 路径穿越与命令执行漏洞（CVE-2021-42013）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MzY2MzM0Mw==&mid=2247486163&idx=1&sn=48fdba4276e4ba59657c2041ae4999eb&chksm=ec6fedd3db1864c5ec380c809e9ba3e4b4d064de07a8546a1e56c4af5477184e22a0ec59a08b&scene=126&sessionid=1681378651#rd](http://mp.weixin.qq.com/s?__biz=MzI5MzY2MzM0Mw==&mid=2247486163&idx=1&sn=48fdba4276e4ba59657c2041ae4999eb&chksm=ec6fedd3db1864c5ec380c809e9ba3e4b4d064de07a8546a1e56c4af5477184e22a0ec59a08b&scene=126&sessionid=1681378651#rd)

2021年10月8日，阿里云应急响应中心监测到 Apache HTTPd官方发布安全更新，披露了CVE-2021-42013 Apache HTTPd 2.4.49/2.4.50 路径穿越与命令执行漏洞。  

01

漏洞描述

Apache HTTPd是Apache基金会开源的一款流行的HTTP服务器。2021年10月8日Apache HTTPd官方发布安全更新，披露了CVE-2021-42013 Apache HTTPd 2.4.49/2.4.50 路径穿越漏洞。**由于对****CVE-2021-41773 Apache HTTPd 2.4.49 ****路径穿越漏洞的修复不完善**，攻击者可构造恶意请求绕过补丁，利用穿越漏洞读取到Web目录之外的其他文件。同时若Apache HTTPd开启了cgi支持，攻击者可构造恶意请求执行命令，控制服务器。**阿里云应急响应中心提醒 Apache HTTPd 用户尽快采取安全措施阻止漏洞攻击****。**
