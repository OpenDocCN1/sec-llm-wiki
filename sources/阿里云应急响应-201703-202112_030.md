# 【漏洞预警】Gitlab markdown 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MzY2MzM0Mw==&mid=2247485999&idx=1&sn=6c3ac58f2950a1df6072cd5a3f0c1a43&chksm=ec6fed2fdb18643984c9fb0c22fa0f4d1f91ec828fb70014201d447d0aa0d1ab21202906461e&scene=126&sessionid=1681378664#rd](http://mp.weixin.qq.com/s?__biz=MzI5MzY2MzM0Mw==&mid=2247485999&idx=1&sn=6c3ac58f2950a1df6072cd5a3f0c1a43&chksm=ec6fed2fdb18643984c9fb0c22fa0f4d1f91ec828fb70014201d447d0aa0d1ab21202906461e&scene=126&sessionid=1681378664#rd)

2021年3月18日，阿里云应急响应中心监测到Gitlab官方发布安全更新，修复了一处远程代码执行漏洞。

01

漏洞描述

Gitlab是一款基于Git 的完全集成的软件开发平台，且具有wiki以及在线编辑、issue跟踪功能、CI/CD 等功能。2021年3月18日Gitlab官方发布安全更新，修复了一处远程代码执行漏洞，攻击者可构造恶意请求，在Gitlab服务器上执行任意代码，控制服务器。阿里云应急响应中心提醒Gitlab用户尽快采取安全措施阻止漏洞攻击。

02

漏洞评级

Gitlab markdown 远程代码执行漏洞 严重。

03

影响版本

Gitlab CE/EE < 13.9.4

Gitlab CE/EE < 13.8.6

Gitlab CE/EE < 13.7.9

04

安全版本

Gitlab CE/EE 13.9.4

Gitlab CE/EE 13.8.6

Gitlab CE/EE 13.7.9

05

安全建议

1\. 升级Gitlab至安全版本。

2\. 将Gitlab服务器部署于内网，或通过设置安全组仅对可信地址开放。
