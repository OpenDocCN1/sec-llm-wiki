**阿里云安全风险提示**

  

**Apache shiro < 1.7.1权限绕过漏洞**  

**(CVE-2020-17523)**

  

![](../Images/c4f2d59dc3f5143e3970a96b1e614bb9.png)

  

  

Apache Shiro是一个应用广泛的权限管理的用户认证与授权框架。2021年2月1日，Apache Shiro发布1.7.1版本，修复了 Apache Shiro 身份验证绕过漏洞 (CVE-2020-17523)。攻击者可以使用包含payload的恶意请求绕过Shiro的身份认证。漏洞利用需要配合Spring环境，风险评定中危。阿里云应急响应中心提醒Apache Shiro用户尽快采取安全措施阻止漏洞攻击。

  

![](../Images/44b2fca79d9bf7df300d107bf4eb1543.png)

  

  

**漏洞描述**

  

Apache Shiro是一个应用广泛的权限管理的用户认证与授权框架。2021年2月1日，Apache Shiro发布1.7.1版本，修复了 Apache Shiro 身份验证绕过漏洞 (CVE-2020-17523)。

攻击者可以使用包含payload的恶意请求绕过Shiro的身份认证。漏洞利用需要配合Spring环境，风险评定中危。

  

阿里云应急响应中心提醒Apache Shiro用户尽快采取安全措施阻止漏洞攻击。

**漏洞评分**

CVE-2020-17523 中危，需结合Spring使用环境。

  

**影响版本 **

Apache Shiro < 1.7.1

  

**安全版本**

Apache Shiro >= 1.7.1
