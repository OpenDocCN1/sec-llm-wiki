# 【漏洞预警】 骑士CMS assign\_resume\_tpl 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MzY2MzM0Mw==&mid=2247485308&idx=1&sn=c8c3809076ba28fca75eaea9744126fa&chksm=ec6fe07cdb18696a9549a313d26c6ae9b5d6cbadd03a7fb8550133397d6cc151ed9dc0bf545d&scene=126&sessionid=1681378685#rd](http://mp.weixin.qq.com/s?__biz=MzI5MzY2MzM0Mw==&mid=2247485308&idx=1&sn=c8c3809076ba28fca75eaea9744126fa&chksm=ec6fe07cdb18696a9549a313d26c6ae9b5d6cbadd03a7fb8550133397d6cc151ed9dc0bf545d&scene=126&sessionid=1681378685#rd)

近日，阿里云应急响应中心监测到骑士CMS官方发布安全更新，修复了一处远程代码执行漏洞。

  

漏洞描述

骑士CMS是一套基于PHP+MYSQL的免费网站管理系统。骑士CMS官方发布安全更新，修复了一处远程代码执行漏洞。由于骑士CMS某些函数存在过滤不严格，攻击者通过构造恶意请求，配合文件包含漏洞可在无需登录的情况下执行任意代码，控制服务器。漏洞利用简单，且相关利用细节已公开，阿里云应急响应中心提醒骑士CMS用户尽快采取安全措施阻止漏洞攻击。

  

影响版本

骑士CMS < 6.0.48

  

安全版本

骑士CMS 6.0.48

  

安全建议

1\. 升级骑士CMS至最新版本。

2\. 由于二次开发过或其他原因无法直接升级的站点，建议参考 http://www.74cms.com/news/show-2497.html 中具体步骤修改文件进行手动升级。
