# 【漏洞预警】通达OA 多个高危漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI5MzY2MzM0Mw==&mid=2247485159&idx=1&sn=cf6779254cdc2a0d2b9b2fe17a246434&chksm=ec6fe1e7db1868f1f8e051aa8341411a34f56dda89aeb011f045bcb3eaf7aeaa0a268dd20660&scene=126&sessionid=1681378695#rd](http://mp.weixin.qq.com/s?__biz=MzI5MzY2MzM0Mw==&mid=2247485159&idx=1&sn=cf6779254cdc2a0d2b9b2fe17a246434&chksm=ec6fe1e7db1868f1f8e051aa8341411a34f56dda89aeb011f045bcb3eaf7aeaa0a268dd20660&scene=126&sessionid=1681378695#rd)

2020年8月20日，阿里云应急响应中心监测到通达OA官方发布安全更新，其中修复了多个高危漏洞。

  

漏洞描述

通达OA（Office Anywhere网络智能办公系统）是由北京通达信科科技有限公司自主研发的协同办公自动化软件。近日通达OA官方发布安全更新，其中修复了多个高危漏洞。攻击者通过文件删除漏洞，以及配合早期版本的后台文件上传漏洞，可以获取服务器系统权限。阿里云应急响应中心提醒通达OA用户尽快采取安全措施阻止漏洞攻击。

  

影响版本

文件删除漏洞：通达OA V11.6

任意文件上传：通达OA < V11.7

结合任意用户登录利用链：通达OA < V11.5

  

安全建议

通达OA官方已经发布相应安全加固程序，请根据当前OA版本选择所对应的程序文件，运行前请先做好备份。

安全更新下载地址：https://www.tongda2000.com/download/sp2019.php
