# 阿里云先知助力2018第三届SSC安全峰会 让互联网变得更加美好

CloverSec Security Conference（简称：SSC），致力于打造为国内顶尖的网络安全峰会，旨在推动国家网络安全事业整体发展。**2018第三届SSC安全峰会**以** “智御安全•洞鉴未来” **为主题，将于**9月18日**在**中国•西安（君悦酒店）**召开，阿里云先知受邀出席参加，共同助力网络强国建设。  

  

![](../Images/b4ccf660dc6276bcb4f5ef54e64de9bf.png)

  

SSC安全峰会作为中西部最具盛名，影响力最大，知名度最高的网络安全安全峰会，已连续举办两届，由西安四叶草信息技术有限公司（简称：四叶草安全）主办，峰会凝聚全国优秀的网络安全企业，汇聚全国网络安全专家学者、行业大咖、网络安全从业者、网络安全爱好者共同聚焦“网络安全”。

本次峰会共两天（9月18日-19日），第一天为高峰论坛，分为主论坛和分论坛，主论坛以“引领安全新方向，探究安全新理念，共创安全新未来”为主题，分论坛以“分享技术干货，交流前沿技术，共享研究成果”为主要内容；第二天为闭门会议。

阿里云先知是一个帮助企业收集漏洞信息、建立私有应急响应中心的安全众测平台。企业入驻先知平台后，可以借助先知平台众多优质、可信的白帽子及时发现现有业务的安全问题，有效地降低企业的安全风险。截至2018年6月，阿里云先知平台总计服务企业个数超过1200个，发现漏洞数量超过38000个，为企业间接避免了15亿损失。

四叶草安全作为国内安全行业发展最快的创新型企业之一，专注于为客户提供网络信息化安全服务，致力于帮助用户先于黑客发现并及时解决安全问题。

  

阿里云先知与四叶草安全的良好合作将有效推进我国网络安全整体建设，助力网络安全强国建设，最后，预祝2018第三届SSC安全峰会圆满成功！
