# 又被同龄人超越了！阿里17岁白帽冠军，已经年入30多万了

你眼中的白帽黑客是什么样的？是冷峻神秘的V字仇杀队？还是高大上的程序员？谈笑之间，挖漏洞，建安全防火墙，搞无人机？

  

11月26日下午，在阿里巴巴西溪园区举办的“双11安全保卫战颁奖典礼”上，颁奖伴奏音乐响起后，阿里巴巴安全部资深总监张玉东上台，为一位17岁的男孩颁奖。

  

这位少年瘦瘦的，看着还是孩子模样，在场的所有嘉宾都发出诧异惊叹。台下的阿里巴巴集团首席风险官郑俊芳甚至情不自禁地问主持人道：“我能上台和他合影吗？”

  

![](../Images/e1fb548f7ced0ae9db94a366d0751d20.png)

*（图说：阿里巴巴安全部资深总监张玉东为白帽少年颁奖。）*

**阿里巴巴为何要给这个00后颁奖？**

  

原来在今年双11前，阿里巴巴ASRC（阿里安全响应中心）联合菜鸟、网易、携程、微博等11家企业的SRC组成双11安全保障联盟，号召白帽提交安全风险建议。**这位少年用7天时间，挖到4家SRC的严重漏洞、7家SRC的高危漏洞，夺得第一名，获得“白帽司令”的称号，**这帮助参与的企业发现了安全风险，提升安全水位。

  

![](../Images/793a0bf4b020e02b276e69ca83424aa6.png)

*（图说：带头老哥的故事引发了多家媒体的报道）*

而实际上，在白帽中，他们有的爱飙机车，有的爱极限登山，有的是红酒文艺少年，有的是爱喝可乐的肥宅……他们是我们身边的普通人，却用自己的方式在燃烧着青春，在玩闹之间，守护着亿万互联网用户的网络安全。

 

![](../Images/a7426217a5af1939ed041c80bb92d1ac.png)

  

**17****岁少年一年挖漏洞获奖30多万元**

上台领奖的少年叫陈宇轩，2001年10月出生，目前在贵州黔东南一家中专学校读书。虽然年纪轻轻，但他喜欢“老哥”这一称呼，于是给自己起了一个老气横秋的白帽ID号“带头老哥”。

  

所谓白帽，是指用黑客技术维护网络安全的力量。

  

![](../Images/6238530b68b59a1bd3e2bfa241469326.png)

  

“带头老哥”最早接触网络安全是2015年，当时他在玩游戏，买装备的时候，有人传了一份文件给他，一点开电脑就中了远控木马，电脑被直接操控，鼠标点两下，全部金币被买了不值钱的东西。

  

他对此产生极大好奇，上网狂搜一通，了解相关知识，但作为门外汉，他两手空空啥也没学会。

  

2017年初，凭借着对计算机的兴趣，“带头老哥”开始系统学习有关基础架构和操作原理知识，并尝试审计开源代码，提交到某漏洞平台。问题是，技术他都知道，但他不能把漏洞知识跟实际结合起来，挖不到漏洞。

  

直到他遇到师傅“Jkgh006”，这位有八年经验的资深白帽，他不堪“带头老哥”十来天里类似“你在吗”之类的QQ信息“骚扰”，布置一项任务给他，让他渗透一家已授权公司的生产线内网，考验一下他的能力。

  

![](../Images/39edfa8891093d54bd2ff0e2fe8fe243.png)

*（图说：“带头老哥”上台分享他与师傅结缘的故事。）*

  

这个任务对一个刚入门的白帽子来说，并不简单，让“Jkgh006”没想到的是，这个小伙子通宵达旦，仅用7个小时，就完成了任务。**“我就问他，你认为10万元能干什么，他说能在家给爸妈买套房。”**就是这一单纯的想法触动了“Jkgh006”，他决定好好指导这个徒弟。

  

从去年5月，“带头老哥”成功发现一家互联网公司网站的执行命令漏洞，首次获奖10元起，一年多来，他为多家公司提交漏洞建议，共获得30多万元的奖励，给家人在县城买房的理想也已实现。

  

今年的双11安全保卫战中，“带头老哥”虽然是在活动中期才加入，但仅用7天时间，就完成比赛目标，比第二名早完成几分钟。

  

![](../Images/e291b526cc41ee0d177f14989f1dcc89.png)

（*图说：“带头老哥”获得的纯金勋章）*

“在这个过程中，我从一位参与者，变成网络安全的守护者，除了奖励，我认为这更多是一种荣誉。”“带头老哥”在获奖感言中说道。

**阿里联合经济体成员成立统一ASRC平台**

近年来，随着互联网发展，黑客活动攻击不断，面对企业的漏洞风险，包括微软、谷歌等企业提出SRC（Security Response Center安全应急响应中心）概念，发动有奉献精神的白帽子为企业提交漏洞，企业对漏洞及时响应，提高安全防御能力。

  

从2012年起，国内互联网公司也相继建立SRC，作为连接企业和外部安全白帽的桥梁。

  

阿里成立ASRC是在2013年10月，成立之初就推出“500万安全赏金计划”，根据白帽提交漏洞风险的等级，最高可奖励10万元。截止目前，5年来，阿里已发放超千万元的奖金。

  

![](../Images/01d0ff319aa7473554abd67a7f4c59f6.png)

*（图说：今年双11前，阿里巴巴ASRC联合网易、新浪、携程等11家企业的SRC组成双11安全保障联盟。）*

阿里ASRC积极与互联网生态伙伴建立合作机制。“带头老哥”这次参加的双11安全保卫战，是继去年双11后，举办的第二期，旨在发动白帽，发现有价值的安全漏洞并推动生态伙伴快速解决，提升整个生态的安全水位。

  

相比去年，今年参与的白帽人数翻了一倍。“今年我们收到的漏洞数也翻了一倍，感谢ASRC组织这样的活动，感谢白帽为我们提供险情建议，让我们把安全做的更好。”一家参与的企业SRC负责人如是表示。

  

去年12月，阿里巴巴还加入First（事件应急响应与安全小组）国际组织，与85个国家的414个应急响应相关组织建立联系，其成员包括微软等国际互联网巨头。

  

最新的消息是，原来分散在阿里巴巴安全部、菜鸟、饿了么、蚂蚁金服安和阿里云的SRC，在颁奖会上共同宣布成立统一的ASRC平台，这意味着五家SRC实现统一品牌。这是阿里巴巴白帽技术社区品牌的一次大升级。

  

“安全无竞争，只有共同的敌人。”张玉东希望多家企业联合能够有更多的碰撞和产出，真正赋能商业安全。作为资深技术专家，他还建议白帽群体提升国际化的能力，期望白帽群体在IOT安全和算法对抗方面提供更多输入。
