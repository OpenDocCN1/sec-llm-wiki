# 阿里安全专家提醒：勒索软件中招用户需要注意的三件事!

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMjEwNTc4NA==&mid=2652986781&idx=1&sn=4c5ebe6b0c49b9eb0a6ed23bb4b16941&chksm=8c9ed2cabbe95bdcd1aad1dd32d1711a5ea98399e225fa4123ea60dff356cdd19192bf593c10&scene=126&sessionid=1681378323#rd](http://mp.weixin.qq.com/s?__biz=MzIxMjEwNTc4NA==&mid=2652986781&idx=1&sn=4c5ebe6b0c49b9eb0a6ed23bb4b16941&chksm=8c9ed2cabbe95bdcd1aad1dd32d1711a5ea98399e225fa4123ea60dff356cdd19192bf593c10&scene=126&sessionid=1681378323#rd)

  

黑客利用“永恒之蓝”攻击程序，将被攻击者文件加密事件，阿里巴巴安全专家提醒大家除了按网上公布的技术方法来应对外，还要提醒受害者注意：

  

一.  尽可能通过邮件附件、IM聊天传输、云存储、系统备份等一切可能的渠道来找回曾保存过的版本，减少损失；

![](../Images/60934ae6ae5e574c2011937c495dd916.png)

  

二.  重装系统前把有用的被加密文件保存好，万一黑客被抓解密方法公布还有补救可能；

![](../Images/b4368d7d40cec27cc0a2274275caba21.png)

  

三.  不要轻信网上所谓的有偿解密方法、渠道，小心网络诈骗分子利用这次机会招摇撞骗。

![](../Images/8b59c34622e0362697415c95e88f91ed.png)

  

另外，阿里巴巴安全专家也表示，目前阿里的安全体系有效地保障着阿里巴巴对外服务系统、公司办公系统和员工电脑的正常运作。目前该病毒已在全球扩散中，阿里巴巴安全部正密切关注事态进程。
