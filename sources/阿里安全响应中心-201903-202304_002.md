# 阿里白帽大会，明年再见！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMjEwNTc4NA==&mid=2652993248&idx=1&sn=eb777f18428462c56f8656de7edd854f&chksm=8c9ef9b7bbe970a1f5e9437d4e86c62dc6b808634329b53e889558231051ef80d75ac260fedc&scene=126&sessionid=1681378028#rd](http://mp.weixin.qq.com/s?__biz=MzIxMjEwNTc4NA==&mid=2652993248&idx=1&sn=eb777f18428462c56f8656de7edd854f&chksm=8c9ef9b7bbe970a1f5e9437d4e86c62dc6b808634329b53e889558231051ef80d75ac260fedc&scene=126&sessionid=1681378028#rd)

![](../Images/68160ca3dc1c2f651f14f4a17e780d63.png)2023年4月1日，阿里白帽大会于杭州成功举办，来自全国各地近200位白帽同学、合作方和特邀嘉宾在此相聚！这是属于阿里巴巴优秀白帽子的盛会，也是属于网络安全白帽社区的盛会！

  

**【开场致辞】**

阿里云智能首席安全官欧阳欣对广大白帽子与阿里巴巴各业务合作方的有效协同表达了深切的感谢，同时也期许更多的线下技术交流，可以碰撞出云上攻防技术的创新闪光点。让白帽子可以和阿里云一起，和阿里云的客户一起，共同构建云上安全环境，让数据在流动中产生应有的价值！![](../Images/b2e3d08550020203e5451792f71bd493.png)

阿里云智能首席安全官欧阳欣

**【阿里云先知2.0计划发布】**

阿里云先知平台负责人宣义发布先知2.0重启计划，全平台奖励计划的总奖金额度将达到千万级，其中单漏洞奖励额度最高更可达到行业罕见的50万元，这将显著提升头部白帽子在先知平台年度获取到的总奖励额度。

![](../Images/6803db28c53229d477260a16b2e35d2a.png)先知负责人宣义  

**【首届阿里云CTF正式开启】**

阿里云智能首席安全官欧阳欣和清华大学副教授、蓝莲花战队教练张超，共同开启首届阿里云CTF发布仪式。![](../Images/4d4c76fd3e888a59f430a8050de07c03.png)

阿里云智能首席安全官欧阳欣(左)清华大学副教授、蓝莲花战队教练张超（右）

本次赛事的联合主办方，清华大学网络科学与网络空间研究院张超教授介绍，此次清华大学与阿里云联合举办CTF比赛，赛题除了传统的WEB、CRYPTO、PWN赛之外，针对性重点关注云场景攻防实践，直面真实云业务场景，涵盖可信计算、默认安全（RASP）、容器安全、虚拟化•IoT云管端通信等近年新兴的云原生安全技术，旨在集结未来力量培养更多云上安全人才，以前所未有的方式认知攻防，让“云”上安全更扎实！![](../Images/38debc252b63434449886bac27c0fcdf.png)

清华大学副教授、蓝莲花战队教练张超
