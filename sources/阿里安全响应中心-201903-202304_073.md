# 白帽成长营｜ASRC打卡特别活动

ASRC白帽成长营打卡活动是ASRC今年新推出的系列活动！邀请大家以挖洞打卡的方式，在活动期间专注漏洞挖掘技术的学习和实践。

活动一般为7天时间（工作日5天+周末2天）

*   【工作日5天】5天时间中投入到学习实践和成长中！
    
*   【周末2天】根据自己的节奏，用来休整/学习/挖洞！
    

如果你希望给自己一个**短期、密集、快速成长**的机会，欢迎来参加ASRC的白帽成长营打卡活动！

一起持续学习，希望2022年我们也有多多的收获和成长！

  

**活动时间**

2022.5.9-2022.5.15

  

**成长营每日时间安排**  

![](../Images/154a6137c20915cd6855a7b4ca45add1.png)

  

**活动规则**

**每人每天提交任意一个有效漏洞报告，视为完成打卡**

  

**活动奖励**

1、每完成一次打卡可获得：**安全币10个**

2、累计完成**5天打卡**的白帽同学可获得：**王牌A有效期60天**

说明：

*   1安全币=10元，活动总计7天时间，每人每天仅能打卡1次，如果每天打卡，累计可获得安全币70个
    
*   5天打卡可以不是连续的，活动7天中累计有5天成功打卡即可获得对应奖励  
    
*   已经是王牌A的同学，按当前最高等级增加60天有效期
    
    还不是王牌A的同学，直接获得王牌A梅花60天有效期
    
*   活动奖励将在活动期间的报告全部审核完毕后，统一发放
    

  

**报名方式**

扫二维码加**钉钉群**即可

进群请备注【自己的ASRC昵称】  

干货分享/活动信息等都会在群里同步  

![](../Images/d8c13085373d367f1b96da140e366966.png)

注：成长营活动期间，ASRC同时也在进行618安全保卫战

大家记得在618活动链接里提交报告  

这样618活动奖励+成长营的奖励都可以获得哦

**1、优秀学员评选**

**学员数量：**拟评选10名

**基础条件：**累计坚持5天挖洞打卡 

**加分项：**

*   在群里分享优质干货内容：技术文章/视频等
    
*   在群里和白帽同学一起交流，提问/解答/分享心得  
    

  

**2、优秀学员奖品**

**【优秀学员礼包】**

*   ASRC定制充电宝\*1
    
*   ASRC定制T恤\*1
    
*   ASRC定制勋章\*1
    
*   ASRC定制口罩\*10
    

**3、评选方式**

活动报告审核完成后，

ASRC工作人员将在活动群发起符合条件的同学的限时群投票

  

**白帽成长营Q&A**

  

**Q：我适合参加成长营吗？**

A：如果你想要持续学习更多挖洞干货**知识**

如果你有一定基础，想提高自己的挖洞**实力**

如果你愿意在提交漏洞时获得更多**奖励**

以上满足任意一项，都很适合来参加成长营哦！

  

  

**Q：参加成长营我需要做什么吗？**

A：成长营的发起初衷，是希望咱们白帽同学可以在活动期间

*   学习挖洞知识
    
*   将知识应用到实践，发现并上报漏洞报告
    

  

  

**Q：****参加成长营我能获得什么呢？**

A：

**【知识学习&分享】**

成长营群内每天分享**干货技术内容**，大家可以参与分享、提问讨论、自主学习。

**【活动福利】**  

参与成长营，活动期间提交有效漏洞会有额外奖励。

成为优秀学员，也会有额外奖励。  

**【创造一次坚持学习的成功经验】**
