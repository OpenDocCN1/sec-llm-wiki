高德移动安全专家

岗位职责

负责高德相关业务的移动端、IoT端的安全保障，以端攻防技术为出发点，保障业务安全。

1、负责端产品的安全评审、技术方案review及安全架构设计，评估安全风险并提供安全建议和解决方案

2、负责端产品漏洞挖掘与利用，以及相应的工具化、流程化落地

3、负责端应用安全规范制定、推广、评审；以及对研发、测试等人员进行安全培训

4、负责端代码及系统防护的研究与开发；

 

岗位要求

1. 精通Android、iOS或小程序的应用架构以及其对应的安全机制和安全风险；

2. 掌握客户端常见的安全漏洞以及解决方案，熟悉客户端的安全测试、漏洞挖掘以及自动化方案；

3. 熟悉客户端应用的安全加固，对客户端应用有逆向分析经验，熟练使用IDA Pro等工具；

4. 强烈的安全研究兴趣和专注的研究能力，持续关注国内外最新的客户端安全发展动向；

5. 良好的逻辑思维能力和团队合作精神，善于交流和表达。

高德数据安全专家

岗位职责

1. 根据集团及国家相关数据安全及隐私保护标准及规范，建立并优化部门相关安全流程，制定相关标准及细则；

2. 建立与各业务团队良好的沟通协作机制，负责数据产品及数据服务的安全合规，负责数据安全风险评估，给出相应的整改措施及解决方案；

3. 根据业务场景中相关的安全诉求，进行总结提炼归纳，推动安全技术、产品平台的不断优化迭代；

4. 建立完善的数据安全运营体系，及时发现数据安全风险，保障业务的前提下，不断提高数据安全水位；

5. 针对数据安全舆情、建立及优化相关的数据安全事件应急流程，协同各方妥善处置各类突发事件。


岗位要求

1. 有互联网工作相关经验，了解大数据或云计算平台相关工具或技术，具备一定数据分析能力（如SQL等）；

2. 在数据安全、应用安全、信息安全、安全运营等领域至少工作3年以上经验，了解相关法律法规；

3. 掌握风险识别、分析、研判、管控的技能，并有良好的业务感知和理解能力；

4. 工作态度严谨，风险意识强，关注细节，有较强的发现、独立分析及解决问题的能力，良好的总结表达、沟通及影响力；

5. GIS、测绘等相关专业，拥有互联网、导航电子地图或者测绘等相关行业工作经验者优先；
