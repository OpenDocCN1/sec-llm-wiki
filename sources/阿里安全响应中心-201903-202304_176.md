**背景**

在二进制逆向分析中，我们经常会遇到这样的问题，应用程序静态编译后，代码体积膨胀了几十倍，真正的用户逻辑代码所占比例很低。这在二进制恶意代码检测领域中更是极其常见，恶意代码与库代码杂糅在一起，极大地增加了安全研究人员的逆向分析难度，分析过程极为耗时。下图仅是一个简单的hello world程序，使用gcc默认参数编译后，静态链接的函数数量约为动态链接函数数量的**65倍**。

在逆向分析中，函数符号在起了很大的作用，有意义的函数符号可以帮助安全研究人员更快地理解其目的。然而为了对抗逆向分析，通常恶意程序的标配是静态链接和去除函数符号。对上述程序使用strip命令去除函数符号，那如何在近千个无符号的函数中找到用户代码呢？对于上述程序较为简单。根据ELF程序加载的过程，首先找到入口函数start，start函数会将一系列参数压栈，然后调用libc中的\_\_libc\_start\_main函数进行初始化工作，根据RDI寄存器的值得到main函数的地址，在main函数中分析整个程序的功能。

**二进制函数符号识别**  

对于上述问题，安全研究人员做了很多尝试，从最初使用特征码，到目前结合机器学习、深度学习技术去设计算法识别未知函数的符号，其中IDA中有一种基于模式匹配的方法——FLIRT，它通过提取函数的前32个字节的前缀码和操作码，来为函数生成一个签名，并用该签名进行模式匹配来识别函数。仅利用前32个字节必然存在冲突的情况。但是如果两个函数的前32个字节一样，该算法取第33字节到下一个变量之间的字节串，计算该字节串的crc16，使用该crc16的值和字节的长度来作为额外的签名，以此区分前32位字节冲突的函数。

![](../Images/ec2790ed56f5e004ec6f3bb90eca20da.png)

虽然FLIRT做了冲突处理，但是如果两个函数的前32字节和第33字节到下一个变量都一样的情况下，FLIRT仍然无法解决函数签名冲突的问题。另外，FLIRT需要人工提前生成或者收集静态二进制库文件，然后生成签名文件，不支持从可执行二进制文件到签名文件的转换，需要人工介入步骤多，自动化建库程度低。在IDA的sig目录下，可以看到不同架构的二进制签名文件。

![](../Images/982afc15ee22d59af2cb943d5c6d1172.png)

**Finger函数符号识别**

为了推动二进制恶意代码检测领域的基础能力建设，促进未知样本发现、漏洞挖掘、二进制文件组成成分分析等研究领域的发展，阿里云·云安全技术实验室正式推出一款二进制函数符号识别引擎--Finger，该工具集成了基于专家知识和AI的二进制函数签名算法识别能力，用户可以通过IDA插件和python SDK两种方式，识别二进制程序中的库函数与常见的第三方函数，快速定位恶意代码，提高样本分析效率。

```
# coding: utf-8import idcimport idaapiimport idautilsfrom finger_sdk import client, ida_funcimport platform
def recognize_functions(client):    for func_ea in idautils.Functions():        pfn = idaapi.get_func(func_ea)        func_name = idaapi.get_func_name(func_ea)        func_feat = ida_func.get_func_feature(pfn.start_ea)        if func_feat:            func_id, res = client.recognize_function(func_feat)            if res and res[func_id]:                func_symbol = res[func_id]                print("[+]Recognize %s: %s" %(func_name, func_symbol))
def main():    url = "https://sec-lab.aliyun.com/finger/recognize/"    headers = {'content-type': 'application/json'}    timeout = 5    version = platform.python_version()    if version.startswith('3'):        ida_auto.auto_wait()        my_client = client.Client(url, headers, timeout)        recognize_functions(my_client)        ida_pro.qexit(0)    else:        Wait()        my_client = client.Client(url, headers, timeout)        recognize_functions(my_client)        Exit(0)
if __name__ == "__main__":    main()

```

**海量数据支持**

Finger利用基于专家知识和AI的二进制函数符号识别算法，从阿里云海量样本数据与已知信息的公开二进制文件中提取函数签名并将其入库，目前函数签名库中已有亿级的函数签名与函数符号，且每天以百万级的速度自动增长，已支持x86/ARM/MIPS架构的32位/64位的ELF/PE文件的函数符号识别。

**识别准确率高**

目前，Finger已作为基础组件集成于阿里云云安全中心的多个安全产品中，并在日常工作中辅助团队研究人员在样本分析中快速定位恶意代码。经过数月阿里云平台日均过百万的海量样本数据训练和测试，准确率较高。
