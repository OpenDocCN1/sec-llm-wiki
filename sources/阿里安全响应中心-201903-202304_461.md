# 2019年第一季度ASRC团队奖励公告

**2019年1月**ASRC共有来自不同安全团队的182位专家向我们报告了安全漏洞和情报。本月产生1个黄金团队称号，为网络尖刀团队，1个青铜团队称号，为DX团队。让我们向他们表示祝贺！

**网络尖刀团队-黄金团队**

本月网络尖刀团队共有10位荣誉成员提交有效漏洞/情报，获得总安全币：7668，等价现金奖励76680元。  

![](../Images/3b90ea26f8abd7bc44f6eb7e22d50798.png)

**DX团队-青铜团队**

本月DX团队共有6位荣誉成员提交有效漏洞/情报，获得总安全币：1467，等价现金奖励14670元。

![](../Images/d12cb737ff76350deefe6585c4d28986.png)

  

**2019年2月**ASRC共有来自不同安全团队的124位专家向我们报告了安全漏洞和情报。本月产生1个白银团队称号，为网络尖刀团队，1个青铜团队称号，为米斯特安全团队。让我们向他们表示祝贺！

**网络尖刀团队-白银团队**

本月网络尖刀团队共有8位荣誉成员提交有效漏洞/情报，获得总安全币：4872，等价现金奖励48720元。

![](../Images/ccc8f0b1da1dd7000ca63bd9cd9e68b6.png)

**米斯特安全团队-青铜团队**

本月米斯特安全团队共有5位荣誉成员提交有效漏洞/情报，获得总安全币：1311，等价现金奖励13110元。

![](../Images/e60f2884d19139dc6b69181bde7dd67e.png)

  

**2019年3月**ASRC共有来自不同安全团队的90位专家向我们报告了安全漏洞和情报。本月产生1个白银团队称号，为网络尖刀团队，1个青铜团队称号，为芳华绝代团队。让我们向他们表示祝贺！

**网络尖刀团队-白银团队**

本月网络尖刀团队共有10位荣誉成员提交有效漏洞/情报，获得总安全币：3389，等价现金奖励33890元。

![](../Images/7a58cce02f25d8297b00020ccdff0d1d.png)

**芳华绝代团队-青铜团队**

本月芳华绝代团队共有5位荣誉成员提交有效漏洞/情报，获得总安全币：1458，等价现金奖励14580元。

![](../Images/2020b9399f6346bf4982b5ae438348f1.png)

ASRC再次向以上团队及其成员表示衷心感谢，根据奖励细则，我们将给团队的队长寄出奖金和ASRC的定制证书，愿我们携手为建设更安全的互联网事业而努力！  

ASRC团队奖励计划于2015年9月推出，奖励细则可参考《关于ASRC奖励开启团队奖励的公告》。
