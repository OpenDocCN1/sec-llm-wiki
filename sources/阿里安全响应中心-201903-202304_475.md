# 专家共议安全人才培养：产教融合互动是一流人才培养必由之路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxMjEwNTc4NA==&mid=2652989353&idx=2&sn=a9e39c6826972da36634dd1c198a771d&chksm=8c9ee8febbe961e81d620c7d72c7ba7d33a3fa421d3d41f59edf0d966eab6b4c076157a48ec6&scene=126&sessionid=1681378207#rd](http://mp.weixin.qq.com/s?__biz=MzIxMjEwNTc4NA==&mid=2652989353&idx=2&sn=a9e39c6826972da36634dd1c198a771d&chksm=8c9ee8febbe961e81d620c7d72c7ba7d33a3fa421d3d41f59edf0d966eab6b4c076157a48ec6&scene=126&sessionid=1681378207#rd)

       4月19日，阿里安全响应中心（ASRC）举办第四届ASRC生态大会，并为获得第一届大学生网络安全能力大赛的团队和个人颁奖。这场比赛有来自全国280所高校的2000多名大学生自发组队参与，经过3个多月的比拼，最终6个团队和3个个人获得漏洞挖掘、情报挖掘以及数据安全方面的前三甲。

![](../Images/6842734c81b0605dcd9cfd6e2584ec81.png)

（图说：第一届大学生网络安全能力大赛获奖的团队和个人上台领奖。）  

  

       值得注意的是，这些白帽子们大多数年龄在98年前后，很多来自全国各个高校的不同专业，比如法律、医学、声乐等。“跨界”挖洞正成为大学生群体中的一种新潮流。

      “95后年轻白帽涌现，这是很好的一件事。”在颁奖活动现场，阿里巴巴集团数据安全研究院高级研究员杜跃进如此点评道。他说，现在安全已是一个普遍存在的问题，传统做安全时只是从计算机学科出发思考，但现在什么都跟网络有关系，都在互联网化，因此安全需要多元化的人才。

![](../Images/7672b8cdbe642506fc040517b738498c.png)

（图说：杜跃进说网络安全需要多元化的人才）

  

       数据安全是目前社会急缺的广阔的新兴领域，在这次比赛中的数据安全竞赛中，来自武汉大学计算机学院的卢桃以86分的成绩夺得第一名，多位安全专家点赞称“非常难得”。杜跃进说，通过这样的高校竞赛，阿里巴巴作为企业输出当前数据安全领域的最新积累，与高校合作探索数据安全领域的专业人才培养。有网络安全行业专家指出，今天已有多所学校开设网络安全学院和信息安全专业，但企业安全人才需求和高校的培养体系之间仍然存在一个鸿沟，这需要整个安全人才培养理念和体系的升级。

      “网络安全人才培养需要接地气，满足社会需要。”杜跃进指出，在这种情况下，校企联合模式就尤为重要，学校要和企业建立一对一的合作关系，企业把需求告诉高校，高校在授课的时候有的放矢，另外要把高校和企业以一种合理成系统的方式组织起来，实现人才点对点的对接。

  

![](../Images/d10003d1e3457fb51df17ccdcddb84df.png)

（图说：四川大学教授杨频说，产教融合互动是一流人才培养必由之路。）  

  

       参会的四川大学网络空间安全学院杨频教授也表示，虽然产教融合在“企业供给的资源与学校需求规模”、“大学价值导向与产业价值导向”等方面存在挑战，但他认为最有效的途径是寻求高校和企业价值的最大公约数。

       “网络安全技术演化迅速，新的威胁和新的技术层出不穷，产教融合互动也是高校应对快速变化的形势、培养一流人才、建设一流学院的必由之路。”杨频说。

      这次大会也对供应链大赛、白帽漏洞挖掘等话题进行深入讨论。来自百度、腾讯、大疆、滴滴、360、小米等公司的安全运营伙伴，还针对SRC行业合作、白帽生态建设、行业创新发展、国际业务探索展开了热烈讨论。
