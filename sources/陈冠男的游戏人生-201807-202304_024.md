02

换源

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

在 Anaconda Prompt (Anaconda3) 中输入：

```

conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/set
 show_channel_urls yes
```

  

03

建立TensorFlow虚拟环境

![](../Images/0f97b741031ff3d893dd58b31ce530c6.png)

  

创建名为 tensorFlow 的环境

后面跟上 anaconda 会自动安装一些东西

```

conda create --name tensorFlow python=3.6.4 anaconda
```

进入tensorFlow虚拟环境：

```

conda activate tensorFlow
```

  

先升级一下 pip，安装一下要用到的库：

```


python -m pip install --upgrade pip
```

  

为了让 Jupyter Notebook 支持虚拟运行环境，需要在 Anaconda 里安装一个插件：

```

conda install nb_conda
```

  

然后运行：

```

jupyter notebook
```

![](../Images/cf29fd46dae476776bad9d204df3975e.png "image.png")

  

大概率会自己打开一个网页，如果不行就手动访问：

http://localhost:8888/tree

  

![](../Images/f42a2eb0dab1cd06a84860e6e68f70d1.png "image.png")

  

然后试一下能正确显示不，可以的话大功告成！

  

![](../Images/8221fe65b09e986ead80bf3c1ae9a80d.png "image.png")

  

`conda deactivate` 退出虚拟环境
