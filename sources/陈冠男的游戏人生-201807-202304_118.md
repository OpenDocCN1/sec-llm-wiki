**w4sp-lab环境搭建**

![](../Images/fcd1d0e981a3c151f62fad5ea78f9776.png)

  

之前 i 春秋有个答题活动，苟了个奖品，介绍 wireshark 的《wireshark 与 metasploit 实战指南》，里面是实验环境是用 docker 搭建的

  

然而作者给的是 dockerfile 让读者自己 build，实在不明白为啥不传到 dockerhub 上![](../Images/b14ce9464d2c7742bdb65121e4202564.png)

  

在搭建的过程中发现有些东西，国内的网下载速度实在是巨慢![](../Images/06fe356015f0fabea935ee43c4a18401.png)，看了一下他是用 ubuntu 14.04 的镜像作为基础镜像来拉起来的，就直接网上找了安装包，提前在一个 ubuntu 镜像里面安装好了，然后把 dockerfile 改了一下

链接：https://pan.baidu.com/s/1EsmZ-Q-gpxjyYGcnN3QVWQ
