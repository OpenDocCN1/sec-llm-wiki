### 调试理解

  

在调用函数 strlen 的这个 call 下个断点：b \*0x8048588

  

![](../Images/db72eb15fa2ab7341ca42cf5c1563080.png "image.png")

  

run 的时候把程序给断下来，然后 si 跟进这个 call 来看一下

  

![](../Images/a10e2535d5afee40c9b25dd0060bc476.png "image.png")

  

进去之后可以看到首先会去执行下面这一块

  

![](../Images/ef02358693c05b6e05cc713d863da8be.png "image.png")

对应之前讲的，跳转到自己的 plt 表项

  

继续单步执行，看一下

  

![](../Images/0a3804ad2b94c7c8b5df00f5237262a4.png "image.png")

对应之前讲的跳转到公共的 plt 表项

  

又一次进行了跳转

  

![](../Images/d2da7c1f71375aac1ac4d9a9c52e99fb.png "image.png")

对应之前讲的跳转到 dl\_runtime\_resolve 函数

  

这个地方就是 dl\_runtime\_resolve 了

  

![](../Images/0be1f376138fe98276b77092160e23c9.png "image.png")

  

需要注意的是，之前跳转的时候，程序 push 了两个参数，一个是 0x10，一个是 0x804a004 里面的内容

  

![](../Images/4cc3078e479ffce2cd7cab33c22538fa.png "image.png")

  

这两个参数就是 dl\_runtime\_resolve 这个函数的两个参数，我们看一下，0x804a004 里面存着什么

这个地址就是  link\_map 的地址

  

![](../Images/fb1848a601ec51f6f2ac8148e40fefff.png "image.png")

  

通过这个地址就可以找到 .dynamic 的地址，第三个就是 0x8049f14

  

![](../Images/c5371e7e455b650ef5a3d458efeac902.png "image.png")

  

再根据这一个找到 .dynstr、 .dynsym、 .rel.plt 的地址

*   .dynstr 的地址是 .dynamic + 0x44 -> 0x08048278
    
*   .dynsym 的地址是 .dynamic + 0x4c -> 0x080481d8
    
*   .rel.plt 的地址是 .dynamic + 0x84 -> 0x08048330
    

  

![](../Images/68dab479a63f504dd9679e0ccb6dd89c.png "image.png")

  

.rel.plt 的地址加上参数 reloc\_arg，即 0x08048330 + 0x10 -> 0x8048340

找到的就是函数的重定位表项 Elf32\_Rel 的指针，记作 rel

  

![](../Images/59c8c18388a0f353f5be3037716561fb.png "image.png")

  

通过这个 rel 可以得到以下信息

> r\_offset = 0x0804a014   //指向GOT表的指针
> 
> r\_info = 0x00000407

将r\_info>>8,即0x00000407>>8 = 4作为.dynsym中的下标，这里的 ">>" 意思是右移

  

我们来到 0x080481d8（上面找到的那个 .dynsym 的地址）看一下，在标号为 4 的地方，就是函数名称的偏移：name\_offset

  

![](../Images/4362c73ebf89cc4c5ba612350296ac3b.png "image.png")

  

.dynstr + name\_offset 就是这个函数的符号名字符串 st\_name

0x08048278 + 0x20 -> 0x8048298‬

  

![](../Images/c3fd4c561e43302d57c818586134b5f6.png "image.png")

  

最后在动态链接库查找这个函数的地址，并且把地址赋值给 \*rel -> r\_offset，即 GOT 表就可以了

  

![](../Images/614bc8f6bc54cd00e0170cc43354ca7a.png)

整理一下思路

![](../Images/fb944d01561e9aaaaa7d168b7e3742b3.png)

  

1.  dl\_runtime\_resolve 需要两个参数，一个是 reloc\_arg，就是函数自己的 plt 表项 push 的内容，一个是link\_map，这个是公共 plt 表项 push 进栈的，通过它可以找到.dynamic的地址
    
      
    
2.  而 .dynamic 可以找到 .dynstr、.dynsym、.rel.plt 的这些东西的地址
    
      
    
3.  .rel.plt 的地址加上 reloc\_arg 可以得到函数重定位表项 Elf32\_Rel 的指针，这个指针对应的里面放着 r\_offset、r\_info
    
      
    
4.  将 r\_info>>8 得到的就是 .dynsym 的下标，这个下标的内容就是 name\_offset
    
      
    
5.  .dynstr+name\_offset 得到的就是 st\_name，而 st\_name 存放的就是要调用函数的函数名
    
      
    
6.  在动态链接库里面找这个函数的地址，赋值给 \*rel->r\_offset，也就是 GOT 表就完成了一次函数的动态链接
