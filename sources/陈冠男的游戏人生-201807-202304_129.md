下载之后直接解压出来，就可以用了，下面说一下用法：  

*   

```
`LxRunOffline.exe list`
```

显示你电脑上安装了哪一些子系统  
![](../Images/ec2e9043867db9e7e0cf15980737905a.png)  

*   

```
`LxRunOffline.exe move -n kali-linux -d D:\kali`
```

把子系统 kali-linux 移动到 D 盘的 kali 目录下面，可能会显示一些 warning，不过问题不大，不用管他，我已经移动过了，就不演示了![](../Images/09b72ebc4bf211d481962b3b879328b6.png)
