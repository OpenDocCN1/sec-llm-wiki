 安装子系统

首先需要打开设置

再在左边打开启用或关闭 windows 功能



在里面找到适用于 Linux 的 windows 子系统



然后就可以在 windows 自带的应用商店里搜索 linux



想用哪一个，就安装哪一个 



下就好了打开会要求设置用户名跟密码


再用的时候打开 cmd 输入：bash 就会进入到 Linux 的界面

windows的目录都挂到了 mnt 目录下
使用命令：cd /mnt/d/anquan，进入 d 盘 anquna 文件夹下



1

 配置子系统 


     然而下好的系统干净的一塌糊涂，里面连 python 都没有，所以还得自己装一些东西，这里主要说怎么把 kali 里的那些工具装上


 好消息是：有个老哥写了个工具，可以直接安装
项目地址：
https://github.com/rikonaka/katoolin4china


当然，在安装工具之前，还是先换一下源 


执行：sudo apt-get install vim
执行：sudo vim /etc/apt/sources.list
把下面这两行贴进去，中科大的源deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contribdeb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib


然后再安装一些要用到的东西，依次执行下面的命令


sudo apt-get updatesudo apt-get install gitsudo apt-get install python3


下面安装第三方工具 


git clone https://github.com/Jayzisinstance/katoolin4china.gitcd katoolin4chinasudo pip3 install .注意后面有个点


使用下面命令打开第三方安装工具


sudo k4c



然后依次选择 2 和 0 就全部安装了，安装过程有点耗时间，而且期间会有两个需要选择的地方，还不能离开


安装好以后就舒服了呀 


终于不用等老长时间还原虚拟机了
