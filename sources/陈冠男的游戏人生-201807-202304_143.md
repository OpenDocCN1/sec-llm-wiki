1

 配置子系统 

  

    ![](../Images/b14ce9464d2c7742bdb65121e4202564.png) 然而下好的系统干净的一塌糊涂，里面连 python 都没有，所以还得自己装一些东西，这里主要说怎么把 kali 里的那些工具装上

  

![](../Images/2c6c3bc2a57553cd2dfa86b07b01c81c.png) 好消息是：有个老哥写了个工具，可以直接安装项目地址：https://github.com/rikonaka/katoolin4china

  

当然，在安装工具之前，还是先**换一下源** ![](../Images/9e26cc80cd6b165b7c22d30ccb269966.png)

  

*   
*   
*   
*   
*   
*   
*   

```
`执行：sudo apt-get install vim`` ``执行：sudo vim /etc/apt/sources.list`` ``把下面这两行贴进去，中科大的源``deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib``deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib`
```

  

然后再**安装一些要用到的东西**，依次执行下面的命令  

  

*   
*   
*   

```
`sudo apt-get update``sudo apt-get install git``sudo apt-get install python3`
```

  

下面**安装第三方工具** ![](../Images/7ead1b7c53fc358175e7d0942abe45d8.png)

  

*   
*   
*   
*   

```
`git clone https://github.com/Jayzisinstance/katoolin4china.git``cd katoolin4china``sudo pip3 install .``注意后面有个点`
```

  

使用下面命令**打开第三方安装工具**

  

*   

```
`sudo k4c`
```

  

![](../Images/452a69f48ba84f10a7fccf76f82a24e9.png)

  

然后依次选择 2 和 0 就全部安装了，安装过程有点耗时间，而且**期间会有两个需要选择的地方**，还不能离开

  

安装好以后就舒服了呀 ![](../Images/2c6c3bc2a57553cd2dfa86b07b01c81c.png)
