```
最近翻来覆去的写某一块的代码, 出于临时抱佛脚的目的, 又翻出来设计模式来找一下安全感。隐约记得，上一次看这个的时候，还是上一次找寻安全感的时候。看来看去东西还是同样没看明白。就不由得纳闷这么些模式是谁弄出来的, 总结的那么多, 能区分出来吗？为什么那么多莫名相似的模式对, 翻来覆去剥开了看, 也总结不出名字上的差异。看不懂，总得找原因, 找来找去, 还真就找到了自以为很正确的《解释》。所谓『失之毫厘，差之千里』, 它必然是规模足够大, 架构足够复杂, 才能让各个局部纤毫毕现, 分门别类。不然也就张李赵刘四个人组成的村政权, 你和我说说张村长、张县长、张秘书有什么区别，刘知府,刘总督哪不一样。我在新手村我爱喝兽奶，凭什么你就说我不能独断万古。对, 一定是这样, 它各种实践成果经过时间验证的理论总结, 它就是一本传记。我看不懂，一定是因为我站的还不够高。我悟了, 也变强了（但没秃）!一共四个人，还要什么村长、县长、秘书、知府的。每天把柴劈好、饭做熟就不错了。至于以后去攻占临近乡镇谁带兵、谁冲锋，再议吧。回到代码上, 目光长远但不要那么远。建个居民楼, 考虑好走水走电采光通风换气, 甚至考虑下隔音户型。阻尼器? 大可不必。不如一步一步搭好地基, 随着项目不断演化, 最后未尝不能也出一本传记。本来, 行文到这里就该结束了。鉴于每次对《设计模式》的攻克都无疾而终，所以决定换一种思路。既然, 它是进化出来的, 那就看看它是怎么个进化法。放置 or 养成, 我选择升级！**进化**
```

## **工厂模式篇**

工厂模式可以分为三个阶段

1.  简单工厂
2.  工厂方法
    
3.  抽象工厂
    

既然有阶段, 就有对应的进化过程, 我们从头开始模拟。

### **情景再现**

**野蛮生长阶段**在一个小村庄里, 王家、张家、李家这三个邻居在一个恰当的年代, 白手起家，分别在自家后院搭起了一个小作坊, 做起了手艺活的营生。作坊内容如下：王家(自行车车轱辘), 李家(摩托车车轱辘), 张家(拖拉机车轱辘)。需要的用户直接跑到各家，定制购买相应的产品。**简单工厂**考虑到这三家邻居确实比较偏僻，为了打出名声。于是他们从各自为战，开始了报团。在一顿酒过后，三家定了战略如下: 用一个栅栏，把这仨邻居的作坊给圈起来了，留个大门, 大门口挂个镶金大牌子(这个用户对接的门面，hin重要)。大牌子上内容如下：

```


1\. 自行车车轱辘用户下次来，不用『各复延至其家』, 只要在大门口一看，说我要自行车车轱辘。只要参照门牌上的名字，就可以拿到货。这下各家都方便了, 不需要和用户打交道了，只管在自己后院里安心画圈就可以了。考虑到目前这种方式实在是简陋，我们就叫它** 简单工厂模式 **。当然，就目前来说，这个小工厂已经够用了，经济实惠，不铺张。但是目前确实也存在了问题。假如隔壁的赵家，看到这三位邻居都奔了小康，于是富有商业头脑的赵老头盯准了市场蓝海，生产卡车轱辘，一起加入这个简单工厂。也简单，门口镶金大牌匾后面加一行字：4\. 卡车轱辘
```

这样就可以了。之后，每来一家，都需要在牌子上加上自己的生产项目，好让用户识别。但这样是有隐患的：镶金大牌匾造价这么高昂，之后每次都要往后加名字，牌子不够了怎么办，牌子弄坏了怎么办，把别人家的经营项目弄没了怎么办**（不符合开闭原则）**。但至少目前对于这少数的几个作坊，这栅栏工厂已经足够了。王张李刘，安心生产吧，改革即将到来。(大牌匾作为提供给用户的接口，改动一定要谨慎又谨慎)

> PS: 这里的简单工厂中的工厂，在故事中的代表就是栅栏厂房

**工厂方法**

历史的车轱辘滚滚向前，栅栏工厂建立之后，四家邻居安心生产，提高工艺，每家的订单量&营业额直线上升，惹得村里的邻居很是羡慕，纷纷发挥创意，也要加入工厂。看着排着长队的邻居，栅栏工厂的厂长压力hin大，大牌匾压力也hin大，栅栏压力也hin大...

厂长急中生智，提了个建议。把各个邻居召集起来，宣布了新政策：

> 咳咳，鉴于栅栏实在有限，这样吧。我们成立分厂，以后各个分厂独立接受订单，各自挂牌生产。总厂起到约束作用，对外作为唯一法人代表，改名为『栅栏公司』。

经过改革，栅栏公司的结构如下:

**栅栏公司**：(主营业车轱辘, 我们就叫它轱辘公司)

```


1\. 自行车轱辘厂之后公司大门负责接待，各个厂负责接单。用户需要什么产品，直接对接到各个厂区负责人，就可以拿货。在邻居要作为分厂加入进来时，需要遵守公司的约束及生产规范。经公司认可，刘家作为货车轱辘生产商加入公司， 自己建立一座工厂，挂牌生产即可。之后每成立一个新工厂，只需要熟读公司经营规范，自行建厂，挂牌生产即可，完全不影响其他的工厂**(符合开闭原则)**。厂长(现公司董事长)hin开心，为自己的机智暗暗点赞，自诩为千古轱辘第一人。以后这栅栏车轱辘公司，就是轱辘界的帝王，什么车轱辘想要提供产品，自行建厂挂牌，可传承千秋万代，安矣。*(工厂方法解决了同一层业务的线上扩展问题)*
```

> **这里的工厂方法中的工厂，在故事中的化身就是栅栏公司**，用于同一类产品的创建。

**抽象工厂**成立了公司之后，轱辘公司蓬勃发展，已经成为村里的第一大厂。与此同时，隔壁村子里同样也在整合各种资源，分别成立了轮胎公司，车配件公司...于是为了继续提升业绩，深度挖掘用户，各个公司建立合作关系。以后每次有用户来到轱辘公司进行订货的时候，业务员推荐用户去隔壁村的轮胎公司看有没有合适的轮胎... 三家公司合作之后, 各营业额翻倍，惹得邻村的邻村的车保险公司也要加入合作... 润滑油公司也要加入合作... 业务员表示最近脑力有点吃紧... 并且用户也表示，我跑这么远，累啊...正所谓需求推动市场，千古第一人的轱辘董事长动员轮胎董事长配件董事长........ : 然后发表了一段慷慨激昂的rap，最终一致决定，公司联盟将阵地迁移到城市去，地理上靠近，战略上才好深入。

于是在县城里包了一块地，各公司地理布局如下：

![](../Images/f33e7310a7799b7d093fff22b78eb5ea.png)

之前的各个公司横向排列，用户在买完自行车轱辘之后，如果要看别的轱辘就走横向路线，如果想看自行车的其他零件，就走纵向路线。  

磨合过一段时间后，各公司进行了资源深度整合，如下：

![](../Images/f4bb109a8ccafc4d6e40ec03cb00fcbe.png)

这时候已经不能再叫公司了， 各公司经过合并，已经改组为集团。经过商讨，集团的名字正式定为千古集团。

千古集团分出了各个车型的产品线。这时候回顾集团的元老之一-王家小作坊(这时候已经叫厂了)，在公司上隶属于轱辘公司，遵守轱辘公司规范，在业务线上隶属于自行车业务线，归该业务线支配。

再上一层，因为集团下有多家公司，那就有公司的规范(抽象产品，轱辘公司为具体产品); 有多条业务线，那就需要有业务线的规章(抽象工厂，自行车业务线为具体工厂)。

> **这里抽象工厂中的工厂，在故事中的体现就是各个业务线**，用于生产属于同一业务线的不同类产品。

之后如果要新添加一条业务线, 如货车业务线，需要在轱辘公司建厂，轮胎公司建厂，配件公司建厂等等*（遵循**开闭原则***）; 同样，如果想成立新的公司，如售后服务公司，则需要在每个业务线都添加过程处理。

目前来看，作为核心的工厂，隶属于综合两条管线。相信随着集团的发展，作为生产核心的工厂，会与越来越多的业务建立关系，正像天空下的人或物，时间长了，总会交织成网。当然简单来说，就是二维表格与三维表格与多维表格的区别。以上，最初的三家小作坊，乘上历史的马车之后，已然位列发展良好的集团。进化过程中，轱辘第一人也为我们轮番上演了**简单工厂 -> 工厂方法 -> 抽象工厂**的威风，感谢。相信集团之后还会有更多的故事，不过对我们来说就到这里了。工厂模式到抽象工厂这里也算是结束了，至少到目前是。因为抽象工厂只是指明了一种抽象的概念，它为之后将要建立的关系也留下了扩展的余地，相信已经能够指导形形色色的创建类方法论。

## **建造者模式篇**

### **情景再现**

在工厂模式的说明里，我们见证了千古集团的兴起。在那个故事里，轱辘人带领我们一步步完成帝国的创建, 光芒无两。如果说他是一个光芒璀璨的太阳，那争相辉映的群星也是另一道风景。这个故事发生在集团刚刚组建之后, 而故事的主角就是我们的群星之一。**包谷小金刚**包谷：自行车产线负责人。  
在集团成立之后，用户来购买自行车配件，确实方便了不少。赢得了广大新老客户的一致好评。产品是迭代的，需求也是随着市场不断迭代更新的。很快，用户提出了新的需求: 我们不要买零件，我们要自行车，嗷嗷嗷！！！孔子说过:** 市场, 都是需求推动的**。很快，自行车业务线完成了营业目标变更，自行车销售变更为主业，配件销售为辅。用户从以前的手提轮胎、肩抗车把出门到现在直接骑回家，真正实现了所见即所得。包谷也很开心，这几天其他的几个产线负责人纷纷过来取经，让他很是骄傲了一把。这天，包谷端着茶缸来转悠，看着成排结队的自行车被骑出大门，茶缸里的茶叶就像一条条悦动的金鱼，分外亮眼。不过，也看到了一个奇怪的现象：隔壁村的大壮骑着自行车出门的时候，弓着背，像是一条弯着的虾米，很是可爱；邻村的小王媳妇，平日里弱不禁风，这时候骑着自行车，脚都挨不着地，与诺大的自行车相比，像是一个纸片人，当然，比大壮那是可爱不少。包谷的眼里闪烁着诡异的光...之后的一个月里，人们发现，诡异的包督头失踪了。直到又半个月后，包督头突然现身，同时出现的还有一条大横幅。值此，**包谷小金刚**系列车型正式推出:

```


1\. 大有大的好(大款车)
```

并推出以旧换新活动。这天，久违了的包督头硬朗的身影又出现在产线大院里。看着大壮骑着大有大的好,那是一个英姿挺拔，意气风发；再看着小王媳妇，骑着巴啦啦，就像是一朵摇曳的花朵，要多好看有多好看。茶叶又像鱼儿一样跳动了起来，在阳光下闪闪发亮。面说，包谷失踪了一个多月，我们接下来来看看包同志在干啥:首先，我们来看看可爱大壮时期的自行车零件生产线:

```


三角架: 三角架公司生产
```

最后由工人操作拼装产线，完成自行车生产。（拼装产线虽然能装车轮，能装车把，但只是能，并不知道如果组装出一辆自行车）因为三角架产出的型号是一样的，轮胎也一个型号，所以尽管装配工人心灵手也巧, 但巧妇难为无米之炊, 产出的自行车也都是一个模子刻出来的，那真真的是不分彼此。这也是坑害了大壮一世英名的罪魁祸首。包督头闭关之后的生产线：拆分为7条![](../Images/dacc91c2013e0b54cf70523709743704.png)原来，包督头是跑到自行车业务线的下面工厂当监工去了，催着工厂生产了不同型号的轮胎，配件等等。  
显而易见，有了不同的零件支持,在自行车组装时,通过使用不同的配件，并以此生产出包谷小金刚系列产品。  
上面用到的就是建造者模式。针对此次的进化模拟, 与建造者模式专有概念进行说明:**产品角色**: 自行车**抽象建造者**: 自行车产线规范，用于指导自行车的组装规范。如三角架拼装规范，车轮拼装规范**具体建造者**: 具体的自行车产线, 遵从规范, 如bll 装饰时使用了粉色系等。**指挥者**: 拼装工人，收到用户订单后, 根据车型不同, 到不同的组装线, 进行自行车的拼装。**客户**: 用户

