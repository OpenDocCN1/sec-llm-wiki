# 公告｜一月积分兑换结算日提前

友情提示：  
  

年关将近，为避免春节期间放假等原因影响积分现金兑换奖励发放，**2020年1月积分兑换相关事宜稍作调整**，具体调整如下：  

  

（一）1月现金兑换结算日期提前至**2020年1月15日**，若1月15日后产生现金兑换，合并至2月25日结算；（二）实物兑换时间不受影响，**2020年1月10日**前兑换实物奖励即时发放，之后兑换实物奖励顺延至春节后发放。

  

以上。

MMSRC预祝各位新年快乐~  

  

  

MMSRC陌陌安全应急响应中心（MMSRC，MOMO Security Response Center）是陌陌建立的安全漏洞收集及安全应急响应平台，致力于保障陌陌旗下所有产品及用户信息安全，促进陌陌与白帽子及团队的交流合作。

  

为感谢白帽子及团队为亿万陌陌用户信息安全做出的贡献，陌陌安全应急响应中心特别设立年度百万奖金池，单漏洞或情报奖励可达万元，活动期间可获取更高奖励。于此同时，我们会不定期组织、赞助安全会议等线下活动，为广大白帽子创造线下交流沟通机会。
