**全新奖励体系**

  
  
  

  

取消之前的个人&团队奖励机制

我们来点直接的

  

  

以季度为周期，根据贡献值来决定当前季度提交漏洞&情报的积分奖励倍数。每60贡献值为一阶梯，每满一阶梯，会有额外奖励并且漏洞&情报积分奖励多0.5倍，3阶为满级，具体如下：

一阶

满足 60 ≤ 贡献值 < 120 且有效高危及以上漏洞≥1  

额外奖励1000京东卡并且当季之后有效漏洞&情报 1.5倍积分奖励

  

二阶

满足 120 ≤ 贡献值 < 180 且有效高危及以上漏洞≥2  

额外奖励2000京东卡并且当季之后有效漏洞&情报 2.0倍积分奖励

  

三阶

满足 180 ≤ 贡献值 < 240 且有效高危及以上漏洞≥4  

额外奖励4000京东卡并且当季之后有效漏洞&情报2.5倍积分奖励

（如遇活动，则以奖励较多的为准，活动期间额外奖励照常发放）

**注：不允许代提漏洞，一经发现，按作弊处理，不给予积分奖励**

MMSRC

陌陌安全应急响应中心（MMSRC，MOMO Security Response Center）是陌陌建立的安全漏洞收集及安全应急响应平台，致力于保障陌陌旗下所有产品及用户信息安全，促进陌陌与白帽子及团队的交流合作。

  

为感谢白帽子及团队为亿万陌陌用户信息安全做出的贡献，陌陌安全应急响应中心特别设立年度百万奖金池，单漏洞或情报奖励可达万元，活动期间可获取更高奖励。于此同时，我们会不定期组织、赞助安全会议等线下活动，为广大白帽子创造线下交流沟通机会。
