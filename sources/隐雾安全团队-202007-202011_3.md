# 一次简单的应急响应

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzMjQzOTg1OQ==&mid=2247483700&idx=1&sn=6f54442f34b1f5d42fda8c23019bd41c&chksm=e895a868dfe2217e4d4266054ba69398692acac85c5e09ff2d6e9bec1c66a09030e8021beb3c&scene=126&sessionid=1681575970#rd](http://mp.weixin.qq.com/s?__biz=MzIzMjQzOTg1OQ==&mid=2247483700&idx=1&sn=6f54442f34b1f5d42fda8c23019bd41c&chksm=e895a868dfe2217e4d4266054ba69398692acac85c5e09ff2d6e9bec1c66a09030e8021beb3c&scene=126&sessionid=1681575970#rd)

事因：今天早上刚上班就接到朋友公司电脑中毒的事情让我帮忙分析下。

 

![](../Images/31c429938da5925ee357c64e5f16182a.png)

  

然后我就问了具体情况出来：

Linux系统

内网机器

通网

然后我就通过向日葵连接到她电脑上控制他电脑在操作。

然后在服务器内发现了一个脚本

 

![](../Images/ac2e5a7c2443f1ff6cf5f5e13cb2ad3f.png)

wget（下载）一个文件。

然后去查看了历史命令：cat .bash\_history

也没发现什么

![](../Images/d7833d7e9ca088ee4e176b0b3f780c3e.png)

然后我又去看了定时任务也没发现异常 

![](../Images/abc6d0b1814e474f1f0dcf730ede0d4b.png)

  

然后我在去微步差了一下域名

**lpl.ackng.com**

 

![](../Images/028ef02aa8752d1c43dbd13257ec0c85.png)

这样就能确定了的确是已经中了病毒了。

因为他机子是通网络为了节省时间我就用最快的方法去查找病毒使用工具。

工具连接：https://github.com/grayddq/GScan

![](../Images/2f18e1535cbbfcf66e053921384b9f7f.png)

使用这个工具的确也发现了问题的所在。

可以看见7325这个进程号。

确定了进程号我就开始定位病毒的所在处

执行：lsof -p pid

![](../Images/75e31d7da6a2326e48db365d2090ff14.png)

  

病毒文件储存在一个隐藏文件内。

查找到了病毒的所在我再去查找被入侵的漏洞所在然后去查看了端口的情况

![](../Images/c5bba8893cc0264e4dd241262ddf3c56.png)

  

6379端口Redis开放，基本五五开是Redis出现了问题。

然后我在去百度了一波看见这个是个挖矿病毒，入侵的方法也是通过ssh。Redis等等

 

![](../Images/3fa1e90b4bc6b2fac94693fd9335ff5a.png)

![](../Images/950b162f2b2fb89f289eb35244064a34.png)

  

然后叫朋友删除了病毒文件以及代码段，这次应急也就结束了。
