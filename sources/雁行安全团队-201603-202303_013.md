# 0x00

hw中分到一个目标，目标的站点只有几个，其中有一个asp的站点看起来好打一点。那么我们就盘他一下。

网站就长这样，看着就很好搞。。。

![](../Images/b0ab826eaab98e905338fb5b0d53e449.png)

只有一个登录框那就简单的爆破一下吧，但是有验证码就很烦。也没想那么多就先试试admin/123456吧，很好。

![](../Images/1f0c7bcf7b033f6ce7d973d5c42f4af6.png)

手动尝试不行那就只能上工具识别验证码进行爆破了，刚准备抓包的时候瞄了一眼验证码的获取接口，一阵无语。这老哥直接Set-Cookie了。。。

![](../Images/5220d525c42021c914ab71bc1c4e550a.png)

复制粘贴一下验证码进行登录。

![](../Images/4ef4d639afdeaa73caf6ea2cc4742f1b.png)

直接扔repeater里面重放，不得不说开发老哥太贴心了。

![](../Images/036bcfa431d0f1aa9a27e7abf559a082.png)

同理尝试小试了一点验证逻辑，果然。。。6

![](../Images/6a07392c3437a3fa7a6c35ee03705583.png)

验证码废了，那就继续看看密码，由于是加密的，所以先找找加密算法。关键字一搜，很好找。

![](../Images/9cad4fc4f5ccd9c1d88f32a90298dc36.png)

由于是对称性加密每次加密的结果都是固定的，就不再把加密实现一遍了（就是懒），直接上常用账户名组合上加密后的123456开始爆破，但是很不幸运，拉了。

![](../Images/2e9d5b70523a531d6d0d27ac7429cb35.png)

后面组合了一下账号密码，用js把密码加密了再进行爆破，再后来上了万能密码，100w字典，反正没怼出来，

# 0x03

当然不能这么简单的结束了，我倒要看看是什么密码，让我爆了半天没报出来。

首先找到数据库配置文件，加密的。。。

![](../Images/3cd801f2353c5cd6ff0e688114e0ca80.png)

找了找数据库连接代码，结果C#嘛，只有一行代码。。。

![](../Images/3e946622504608630f19e75ace842f12.png)

没办法，只能看dll了。

![](../Images/09ed0062cbb0f0ac39a3492d84de9c9b.png)

通过反编译dll，发现了数据库的连接方式和解密代码。

![](../Images/137367bb5f10c8f11d7ff1457a4015ed.png)

跟进解密代码，发现是DES加密，解密的话需要密钥（key）和偏移量（iv）。

![](../Images/f52adde02d5cc62b7b8f897960ad00c3.png)

在代码定义变量的地方找到了明文的key和iv参数值。

![](../Images/73eebb09debf1f1044061acacd86b1f7.png)

通过在线网站http://tool.chacuo.net/cryptdes，进行解密，但是没有解出来。

![](../Images/ec61b9c3a141c6e0eac590816243ffd1.png)

又看了看代码，发现key和iv赋值前调用了Get8Byte函数，用0补齐了8位。

![](../Images/fe9ac49d7971e2d20f161de1a7d29ca6.png)

把偏移量拼上一个0后成功解密。

![](../Images/c38c6c49a3f7c457a8532e7e2e0b61a5.png)

配置数据库连接信息，成功连接。

![](../Images/d72dda9cc04007fe0621bde7665a44de.png)

![](../Images/ccb4656cd81aacda56d68b8dcc3490e9.png)

找到用户表，看了看，啥Adminrs?systemrs?我字典里没有啊。倒是下面的用户名看起来很简单，但是我为啥没爆出来呢。

![](../Images/255c767cf8cb6d0bd4cdef4860c6c9ff.png)

把加密后的密码扔到cmd5进行解密。

![](../Images/2f368edd85a5b7acefc1f70afef3e720.png)

。。。。。。

![](../Images/1347248a4119ff7e829bdaee1d681f74.png)
