# 【漏洞预警】Linux内核提权漏洞 CVE-2022-0847

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTIzMzM1Ng==&mid=2651104448&idx=2&sn=93d7708102efc16120bc36aa38c23a44&chksm=8c6b62e3bb1cebf5998928928e3b27bf29fc62deb2513ac3d62937aed9afe7043eb4bc764467&scene=126&sessionid=1681408515#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTIzMzM1Ng==&mid=2651104448&idx=2&sn=93d7708102efc16120bc36aa38c23a44&chksm=8c6b62e3bb1cebf5998928928e3b27bf29fc62deb2513ac3d62937aed9afe7043eb4bc764467&scene=126&sessionid=1681408515#rd)

2022年3月8日，雁行安全团队监测到 Linux内核提权漏洞 (CVE-2022-0847)的风险通告，漏洞概况如下：  

  

| CVE编号 || CVE-2022-0847 |
| --- | --- |
| 风险等级 || 高危  
 |
| 漏洞类型  
 || 本地提权 |
| CVSS评分  
 || 7.8 |

  

**漏洞详情**  

攻击者可以覆盖任意只读文件中的数据，导致权限提升。

![](../Images/3f68eaa631c11a924fe9e47fa9150f25.png)

  

**漏洞影响范围**

5.8 以上

< 5.16.11、5.15.25、5.10.102  

  

  

**安全版本**

5.16.11、5.15.25、5.10.102  

  

**修复建议**

对于低于5.16.11、5.15.25、5.10.102的版本尽快升级至安全版本
