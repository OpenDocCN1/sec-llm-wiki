2021年5月26日，雁行安全团队监测到 vmware 官方发布了 VMware vCenter Server远程代码执行漏洞(CVE-2021-21985) 的风险通告，漏洞概况如下：  

  

| CVE编号 || CVE-2021-21985 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行 |
| CVSS评分  
 || 9.8  
 |

  

**漏洞详情**  

VMware vCenter Server是美国威睿（VMware）公司的一套服务器和虚拟化管理软件。该软件提供了一个用于管理VMware vSphere环境的集中式平台，可自动实施和交付虚拟基础架构。  

  

VMware vCenter Server存在远程代码执行漏洞，该漏洞源于Virtual SAN运行状况检查插件中缺少输入验证，该插件在vCenter Server中默认启用。攻击者可利用该漏洞发送精心构造的请求包，造成远程代码执行，获取服务器权限。雁行安全团队提醒 VMware vCenter 用户尽快采取安全措施阻止漏洞攻击。

  

**漏洞影响范围**  

vCenter Server 7.0  

vCenter Server 6.7

vCenter Server 6.5

Cloud Foundation（vCenter Server）3.x

Cloud Foundation（vCenter Server）4.x

  

**安全版本**  

vCenter Server 7.0.U2b  

vCenter Server 6.7.U3n  
vCenter Server 6.5.U3p

Cloud Foundation（vCenter Server）3.10.2.1

Cloud Foundation（vCenter Server）4.2.1

  

**修复建议**

升级至最新版本：

https://www.vmware.com/security/advisories/VMSA-2021-0010.html
