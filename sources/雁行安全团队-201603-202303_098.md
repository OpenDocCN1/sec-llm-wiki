# 【风险通告】GitLab 远程代码执行漏洞

2021年4月16日，雁行安全团队监测到 GitLab 官方发布了 GitLab远程代码执行漏洞 的风险通告，漏洞概况如下：  

  

| 风险等级 || **高危**  
 |
| --- | --- |
| 漏洞类型  
 || 远程代码执行  
 |
| CVSS评分‍  
 || 9.9  
 |

  

  

**漏洞详情**  

GitLab是美国GitLab公司的一款使用Ruby on Rails开发的、自托管的、Git（版本控制系统）项目仓库应用程序。该程序可用于查阅项目的文件内容、提交历史、Bug列表等。

  

GitLab 存在远程代码执行漏洞，该漏洞源于GitLab未正确验证传递到文件解析器的 图像文件，攻击者可利用此漏洞上传精心构造的文件，造成 远程代码执行。该漏洞危害极大，雁行安全团队建议 GitLab 用户尽快采取安全措施阻止漏洞攻击。

  

**漏洞影响范围**  

GitLab >= 11.9  

GitLab >= 7.12  

  

**修复建议**

更新至最新版本：

https://about.gitlab.com/update/

  

**参考链接**  

https://about.gitlab.com/releases/2021/04/14/security-release-gitlab-13-10-3-released/
