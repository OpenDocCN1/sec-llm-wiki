近日，雁行安全团队监测到 Apache Solr 官方发布了 Apache Solr ssrf漏洞（CVE-2021-27905） 的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2021-27905 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 服务端请求伪造  
 |

  

**漏洞详情**  

Apache Solr是美国阿帕奇（Apache）软件基金会的一款基于Lucene（一款全文搜索引擎）的搜索服务器。该产品支持层面搜索、垂直搜索、高亮显示搜索结果等。  
  
Apache Solr < 8.8.2版本中存在ssrf漏洞。攻击者可通过该漏洞发送精心构造的请求包，造成服务端请求伪造，从而探测内网。同时Apache Solr官方通告中还包括了Apache Solr 敏感信息泄漏漏洞（CVE-2021-29262）和Apache Solr数据集读写漏洞（CVE-2021-29943）。雁行安全团队提醒Apache Solr用户尽快采取安全措施阻止漏洞攻击。

  

**漏洞影响范围**  

Apache Solr < 8.8.2  

  

**修复建议**

升级至最新版本：  

https://solr.apache.org/downloads.html
