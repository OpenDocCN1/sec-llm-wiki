【风险通告】 Apache Solr SSRF与任意文件读取漏洞

近日，雁行安全团队监测到 Apache Solr 存在 SSRF与任意文件读取漏洞 ，漏洞概况如下：


风险等级中危
漏洞类型
任意文件读取


漏洞详情

Apache Solr是美国阿帕奇（Apache）软件基金会的一款基于Lucene（一款全文搜索引擎）的搜索服务器。该产品支持层面搜索、垂直搜索、高亮显示搜索结果等。

Apache Solr 全版本 存在SSRF与任意文件读取漏洞。Apache Solr整体默认安装后不进行身份验证，未授权 的攻击者可通过该漏洞，发送精心构造的请求包，读取任意文件。目前，该漏洞POC已公开。雁行安全团队建议 Apache Solr 用户尽快采取安全措施阻止漏洞攻击。

漏洞复现



漏洞影响范围

Apache Solr <= 8.8.1


修复建议

目前官方表示暂不修复该漏洞，雁行安全团队提供临时防护建议如下：

1.将Apache Solr放置于内网，减小攻击面。

2.对Apache Solr增加身份验证。
