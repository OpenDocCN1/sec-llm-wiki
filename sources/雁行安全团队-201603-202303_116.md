# 【风险通告】VMware View Planner 远程代码执行漏洞

2021年3月5日，雁行安全团队监测到 vmware 官方发布了 VMware View Planner 远程代码执行漏洞（CVE-2021-21978） 的风险通告，漏洞概况如下：  

  

| CVE编号 || CVE-2021-21978 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型‍  
 || 远程代码执行 |
| CVSS评分  
 || 8.6  
 |

  

**漏洞详情**  

VMware View Planner 是美国威睿（VMware）公司旗下的一款针对view桌面的测试工具。通过这个测试工具可以估算出在指定的应用环境下可以发布多少个view桌面。  

  

VMware View Planner 4.6 版本存在 远程代码执行漏洞，该漏洞源于View Planner中某上传接口允许 跨目录任意文件上传。未授权的攻击者可利用此漏洞上传恶意文件，造成 远程代码执行。该漏洞相关细节已在互联网披露，影响较大，雁行安全团队提醒 VMware 用户尽快采取安全措施阻止漏洞攻击

  

**漏洞影响范围**  

VMware View Planner 4.6
