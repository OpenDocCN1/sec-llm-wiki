**漏洞详情**  

VMware ESXi 和 VMware vCenter Server是美国威睿（VMware）公司的两款产品。VMware ESXi是一套可直接安装在物理服务器上的服务器虚拟化平台。VMware vCenter Server是一套服务器和虚拟化管理软件，该软件提供了一个用于管理VMware vSphere环境的集中式平台，可自动实施和交付虚拟基础架构。  

  

**VMware vCenter远程代码执行漏洞（CVE-2021-21972）**

可以访问 443端口 的攻击者可利用该漏洞在托管vCenter Server的基础操作系统上以不受限制的特权 执行命令。  

  

**VMware ESXi堆溢出漏洞（CVE-2021-21974）**

与 ESXi处于同一网段 中且可以访问 427端口 的攻击者可利用该漏洞触发 OpenSLP 服务中的 堆溢出 问题，从而导致 远程执行代码。  

  

**VMware vCenter SSRF漏洞（CVE-2021-21973）**

可以访问 443端口 的攻击者可以通过向vCenter Server插件发送POST请求来导致信息泄露。  

  

**漏洞影响范围**  

*   **CVE-2021-**21972**、C**VE-2021-**21973****：**
    

        vCenter Server 7.0

        vCenter Server 6.7

        vCenter Server 6.5  

        VMware Cloud Foundation（vCenter Server） 3.x

        VMware Cloud Foundation（vCenter Server） 4.x

  

*   **CVE-2021-**21974**：**
    

        ESXi = 6.5

        ESXi = 6.7

        ESXi = 7.0

        VMware Cloud Foundation (ESXi) = 3.X

        VMware Cloud Foundation (ESXi) = 4.X
