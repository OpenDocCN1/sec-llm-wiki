近日，雁行安全团队监测到 Apache SkyWalking 官方发布了 Apache Skywalking远程代码执行漏洞 的风险通告，漏洞概况如下：  

  

| 风险等级 || **高危**  
 |
| --- | --- |
| 漏洞类型  
 || 远程代码执行  
 |

  

**漏洞详情**  

Apache SkyWalking是美国阿帕奇软件（Apache Software）基金会的一款主要用于微服务、云原生和基于容器等环境的应用程序性能监视器。

  

Apache SkyWalking 存在远程代码执行漏洞，此漏洞是由于SkyWalking历史SQL注入漏洞修复不完全导致。攻击者可以通过利用SkyWalking默认的某 GraphQL 接口 构造恶意的请求包进行 SQL注入，获取数据库敏感信息泄露，并利用h2数据库造成 远程代码执行。雁行安全团队建议 Apache SkyWalking 用户尽快采取安全措施阻止漏洞攻击。

  

**漏洞影响范围**  

Apache SkyWalking < v8.4.0  

  

**安全版本**  

Apache SkyWalking  v8.4.0

  

**修复建议**

厂商已发布升级补丁以修复漏洞，补丁获取链接：

https://github.com/apache/skywalking/releases
