2021年2月3日，雁行安全团队监测到 Windows Installer特权提升漏洞 的 EXP 已经在互联网上公开，漏洞概况如下：  

  

| 风险等级 || 高危  
 |
| --- | --- |
| 漏洞类型  
 || 特权提升  
 |

  

**漏洞详情**  

Windows Installer(MSI 管理器）存在 特权提升漏洞，该漏洞为CVE-2020-16902 的补丁绕过。攻击者成功利用该漏洞通过在目标系统上运行精心构造的恶意程序，即可从普通权限提升至 System权限。目前微软暂未发布该漏洞的补丁，影响较大，雁行安全团队提醒用户提高警惕。

  

**漏洞影响范围**  

Windows 10 1607-20H2  

Windows 8.1  

部分Windows Server

  

**修复建议**

厂商暂未发布升级补丁，雁行安全团队将持续关注，并及时同步厂商信息，另外，建议用户尽量不要下载、执行来源不明的可执行文件。
