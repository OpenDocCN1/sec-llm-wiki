2021年2月2日，雁行安全团队监测到 Apache 官方发布了 Apache Shiro 权限绕过漏洞（CVE-2020-17523） 的风险通告，漏洞概况如下:  

  

| CVE编号 || CVE-2020-17523 |
| --- | --- |
| 风险等级 || **中危**  
 |
| 漏洞类型  
 || 权限绕过‍  
 |
| 利用条件  
 || shiro与Spring一起使用 |

  

**漏洞详情**  

Apache Shiro是一个强大且易用的Java安全框架，执行身份验证、授权、密码和会话管理。使用Shiro的易于理解的API，可以快速、轻松地获得任何应用程序，从最小的移动应用程序到最大的网络和企业应用程序。  
  
Apache Shiro <1.7.1 版本中存在 权限绕过漏洞， 当 Apache Shiro与Spring一起使用 时，攻击者可通过发送精心构造的HTTP请求进行 权限绕过，对相关程序接口未授权访问。雁行安全团队建议 Apache Shiro 用户尽快采取安全措施阻止漏洞攻击。

  

**漏洞影响范围**  

Apache Shiro < 1.7.1  

  

**安全版本**  

Apache Shiro  1.7.1

  

**修复建议**

升级至最新版本：  

http://shiro.apache.org/download.html  

https://github.com/apache/shiro/releases/tag/shiro-root-1.7.1

  

**参考链接**  

https://shiro.apache.org/security-reports.html
