 近日，雁行安全团队监测到 Apache 官方发布了 Apache Druid 远程代码执行漏洞（CVE-2021-25646） 的风险通告，漏洞概况如下：

  

| CVE编号 || CVE-2020-25646 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

  

**漏洞详情**  

Apache Druid 是一个高性能实时分析数据库。它是为大型数据集上实时探索查询的引擎，提供专为 OLAP 设计的开源分析数据存储系统，它的设计意图是在面对代码部署、机器故障以及其他产品系统遇到不测时能保持100%正常运行。它也可以用于后台用例，但设计决策明确定位线上服务。  
  
Apache Druid <= 0.20.0 版本中存在 远程代码执行漏洞。由于Druid默认情况下缺乏授权认证，攻击者可通过发送精心构造的恶意请求，造成 远程代码执行，从而 获取服务器权限。雁行安全团队提醒 Druid 用户尽快采取安全措施阻止漏洞攻击。  

  

**漏洞影响范围**  

Apache Druid <= 0.20.0

  

**安全版本**  

Apache Druid = 0.20.1

  

**修复建议**

升级至最新版本：  

https://druid.apache.org/downloads.html

  

**参考链接**  

https://www.mail-archive.com/announce@apache.org/msg06335.html
