# 【风险通告】Sudo 堆缓冲区溢出漏洞

2021年1月27日，雁行安全团队监测到 Redhat 官方发布了 Sudo 堆缓冲区溢出漏洞（CVE-2020-3156）的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-3156 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 缓冲区溢出  
 |

  

**漏洞详情**  

Sudo是一个功能强大的实用程序，大多数基于Unix和Linux的操作系统都包含Sudo，它允许用户使用其他用户的安全特权运行程序。该漏洞本身已经隐藏了将近十年，它于2011年7月引入（commit：8255ed69），在其默认配置下会影响从1.8.2到1.8.31p2的所有旧版本以及从1.9.0到1.9.5p1的所有稳定版本。成功利用此漏洞，任何没有特权的用户都可以在易受攻击的主机上获得 root权限。Qualys（最先披露该漏洞的国外安全研究团队）安全研究人员已经能够在Ubuntu 20.04（Sudo 1.8.31），Debian 10（Sudo 1.8.27）和Fedora 33（Sudo 1.9.2）上验证漏洞并获得root权限，其他操作系统和发行版也可能会被利用。雁行安全团队提醒用户尽快更新阻止漏洞攻击。

  

**漏洞影响范围**  

sudo ：1.8.2 - 1.8.31p2  

sudo ：1.9.0 - 1.9.5p1  

  

**检验方法**

  

以非root用户登录系统，并使用命令 sudoedit -s /

  

*   如果存在漏洞，则报错信息以 sudoedit: 开头
    
      
    

![](../Images/e4dcea19a5b46e771a09dd778a2211ca.png)  

  

*   如果安装补丁，则报错信息以 usage: 开头
    

  

**修复建议**

将sudo升级至最新版本：  

https://www.sudo.ws/dist/
