# 【风险通告】Dnsmasq 远程代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTIzMzM1Ng==&mid=2651101692&idx=2&sn=ec238dccdc70321fe056df6b488ba7bf&chksm=8c6b5fdfbb1cd6c99373fa94b8fb23ce0ee6de1936ccfdfc5169a76e84e93d9cec5fe2c3dd96&scene=126&sessionid=1681408562#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTIzMzM1Ng==&mid=2651101692&idx=2&sn=ec238dccdc70321fe056df6b488ba7bf&chksm=8c6b5fdfbb1cd6c99373fa94b8fb23ce0ee6de1936ccfdfc5169a76e84e93d9cec5fe2c3dd96&scene=126&sessionid=1681408562#rd)

![](../Images/d89d750f72186bf4f1130e0796cb0cde.png)

2021年1月22日，JSOF 官方发布了 DNSmasq 远程代码执行漏洞（CVE-2020-25681/25682） 的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-25681/25682 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

  

**漏洞详情**  

Dnsmasq是一款使用C语言编写的轻量级DNS转发和DHCP、TFTP服务器。  
Dnsmasq < 2.83 版本存在 远程代码执行漏洞。该漏洞源于dnsmasq中的 缓冲区溢出，攻击者可通过发送精心构造的请求包，触发该漏洞，造成 远程代码执行。同时本次更新还包含其他多个漏洞，雁行安全团队提醒 Dnsmasq 用户尽快更新阻止漏洞攻击。

  

**漏洞影响范围**  

dnsmasq < 2.83

  

**安全版本  
**

dnsmasq >= 2.83

  

**修复建议**

目前厂商已发布升级补丁以修复漏洞，补丁获取链接：  

https://www.jsof-tech.com/disclosures/dnspooq/
