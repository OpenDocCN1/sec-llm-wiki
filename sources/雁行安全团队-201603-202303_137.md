近日，雁行安全团队监测到 jumpserver 官方发布了 jumpserver远程命令执行漏洞 的风险通告，漏洞概况如下：  

| 风险等级 || **高危**  
 |
| --- | --- |
| 漏洞类型  
 || 远程命令执行  
 |

  

**漏洞详情**  

Jumpserver 是全球首款完全开源、符合4A规范（包含认证Authentication 、授权 Authorization、账号 Accounting 和审计 Auditing）的运维安全审计系统，Jumpserver 通过软件订阅服务或者软硬件一体机的方式，向企业级用户交付多云环境下更好用的堡垒机。  

  
Jumpserver 特定版本存在远程命令执行漏洞,该漏洞源于Jumpserver某些接口存在未授权访问。未授权的攻击者可利用该漏洞获取敏感信息、执行API操作，从而造成远程命令执行的影响。雁行安全团队提醒Jumpserver用户尽快更新阻止漏洞攻击。  
  

**漏洞影响范围**

```





< v2.6.2
```

**安全版本**

```




>= v2.6.2
```

**修复建议**

升级至安全版本：  

https://github.com/jumpserver/jumpserver/releases

  

**参考链接**  

https://github.com/jumpserver/jumpserver/blob/master/README.md
