2021年1月13日，雁行安全团队监测到 微软 官方发布了 Microsoft Defender远程代码执行漏洞（CVE-2021-1647）的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2021-1647 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

  

**漏洞详情**  

微软官方于1月13日发布安全更新，其中修复了 Defender远程代码执行漏洞。攻击者可构造恶意的 PE文件，并通过发送邮件等方式诱导受害者获取该文件，即可触发 Defender 对该恶意文件的解析，造成远程代码执行的影响。同时，微软1月安全更新中还涉及 RPC Runtime远程代码执行漏洞（CVE-2021-1658）、Microsoft SharePoint Server 远程代码执行漏洞（CVE-2021-1707）、 Windows Win32k 权限提升漏洞(CVE-2021-1709)等其他多个高危漏洞，雁行安全团队提醒Windows用户尽快安装补丁阻止漏洞攻击。
