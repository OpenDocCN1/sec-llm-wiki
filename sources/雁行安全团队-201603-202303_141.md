2021年1月6日，雁行安全团队监测到 Apache Flink 官方发布了 Apache Flink目录遍历漏洞（CVE-2020-17518/17519）的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-17518/17519 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 任意文件写入/任意文件读取  
 |

  

**漏洞详情**  

Apache Flink是美国阿帕奇软件（Apache Software）基金会的一款开源的分布式流数据处理引擎。该产品主要使用Java和Scala语言编写。  
  
Apache Flink 特定版本中存在 目录遍历漏洞（CVE-2020-17518：文件写入漏洞、CVE-2020-17519：文件读取漏洞）。攻击者利用文件写入漏洞可通过修改http header，造成任意文件写入、利用文件读取漏洞可通过 JobManager 进程的 REST API 读取任意文件。雁行安全团队提醒 Flink 用户尽快采取安全措施阻止漏洞攻击。
