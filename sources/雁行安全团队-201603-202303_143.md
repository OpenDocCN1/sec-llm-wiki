2020年12月29日，雁行安全团队监测到 SolarWinds 官方发布了 SolarWinds Orion API 远程代码执行漏洞（CVE-2020-10148）的风险通告，漏洞概况如下  

| CVE编号 || CVE-2020-10148 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

  

**漏洞详情**  

SolarWinds Orion 是美国 SolarWinds Inc 公司提供的一套企业基础架构、系统监视、管理产品的平台。  
  
SolarWinds Orion 特定版本存在 远程代码执行漏洞,未经身份验证的攻击者可通过发送精心构造的恶意请求，绕过API身份验证，从而造成远程代码执行。雁行安全团队提醒 SolarWinds 用户尽快安装补丁阻止漏洞攻击。

  

**漏洞影响范围**

SolarWinds:Orion : <2020.2.1HF2

SolarWinds:Orion : <2019.4HF6

  

**修复建议**

升级至最新版本：  

https://www.solarwinds.com/securityadvisory  

  

**参考链接**  

https://www.solarwinds.com/securityadvisory
