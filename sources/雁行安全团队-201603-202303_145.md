# 【风险通告】Microsoft Exchange Server 远程代码执行漏洞

2020年12月10日，雁行安全团队监测到 微软 官方发布了 Exchange Server 远程代码执行漏洞（CVE-2020-17132）的风险通告，漏洞概况如下  

| CVE编号 || CVE-2020-17132 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

  

**漏洞详情**  

微软官方于12月9日发布安全更新，其中修复了 Exchange Server 远程代码执行漏洞，该漏洞源于Microsoft Exchange 服务器对 cmdlet参数 不正确的验证。攻击者通过在受影响的 Exchange 服务器上构造特殊的 cmdlet参数 即可触发该漏洞，造成执行任意代码的影响。同时，微软12月补丁中还涉及 Microsoft SharePoint 远程代码执行漏洞（CVE-2020-17118）、Hyper-V 远程代码执行漏洞（CVE-2020-17095）、  Windows NTFS 远程代码执行漏洞(CVE-2020-17096)等其他多个高危漏洞，雁行安全团队提醒Windows用户尽快安装补丁阻止漏洞攻击。

  

**漏洞影响范围**  

Microsoft Exchange Server 2016 Cumulative Update 18  
Microsoft Exchange Server 2019 Cumulative Update 7  
Microsoft Exchange Server 2016 Cumulative Update 17  
Microsoft Exchange Server 2019 Cumulative Update 6  
Microsoft Exchange Server 2013 Cumulative Update 23
