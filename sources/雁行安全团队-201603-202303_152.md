2020年11月11日（微软2020年11月补丁日），微软 官方发布了 Windows 网络文件系统远程代码执行漏洞（CVE-2020-17051）的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-17051 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |
| CVSS评分 || 9.8  
 |

  

**漏洞详情**  

微软官方于11月11日发布安全更新，其中修复了 Windows 网络文件系统远程代码执行漏洞。攻击者通过将特制的 NFS 数据包发送到Windows计算机上，可造成windows网络文件系统 缓冲区溢出，从而造成远程代码执行。同时，微软11月补丁中还涉及其他多个高危漏洞，雁行安全团队提醒Windows用户尽快安装补丁阻止漏洞攻击。

  

**漏洞影响范围**  

windows 7  
windows 8  
windows 10   
windows server 2008   
windows server 2012   
windows server 2016   
windows server 2019

  

**修复建议**
