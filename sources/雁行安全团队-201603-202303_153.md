近日，雁行安全团队监测到 Tomcat websocket 拒绝服务漏洞（CVE-2020-13935） 的利用代码在网上披露，漏洞概况如下：  

| CVE编号 || CVE-2020-13935 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 拒绝服务  
 |

  

**漏洞详情**  

Apache Tomcat是美国阿帕奇（Apache）软件基金会的一款轻量级Web应用服务器。该程序实现了对Servlet和JavaServer Page（JSP）的支持。  
  
Apache Tomcat 特定版本中存在 拒绝服务漏洞。攻击者可通过发送大量恶意请求包，使开启了 websocket 上传功能的 Tomcat 服务器 拒绝服务。雁行安全团队提醒 Tomcat 用户尽快采取安全措施阻止漏洞攻击。  

  

**漏洞影响范围**  

Apache Tomcat 10.0.0-M1 - 10.0.0-M6

Apache Tomcat 9.0.0.M1 - 9.0.36

Apache Tomcat 8.5.0 - 8.5.56

Apache Tomcat 7.0.27 - 7.0.104

  

**修复建议**

升级至最新版本：  

http://tomcat.apache.org/
