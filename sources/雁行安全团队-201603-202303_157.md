# 【风险通告】XXL-JOB 反序列化漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTIzMzM1Ng==&mid=2651101467&idx=1&sn=4af5ea3bc95a4d7a846b19871f17815d&chksm=8c6b5f38bb1cd62e19569b27c5d93055f1f16d5cc44951addffba10a3d62fdb8d85318856a10&scene=126&sessionid=1681408572#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTIzMzM1Ng==&mid=2651101467&idx=1&sn=4af5ea3bc95a4d7a846b19871f17815d&chksm=8c6b5f38bb1cd62e19569b27c5d93055f1f16d5cc44951addffba10a3d62fdb8d85318856a10&scene=126&sessionid=1681408572#rd)

2020年10月28日，雁行安全团队监测到 XXL-JOB API 接口存在 未授权访问导致的反序列化漏洞，漏洞概况如下：  

| 风险等级 || **高危**  
 |
| --- | --- |
| 漏洞类型  
 || 反序列化  
 |

**漏洞详情**  

XXL-JOB是一个分布式任务调度平台，其核心设计目标是开发迅速、学习简单、轻量级、易扩展。现已开放源代码并接入多家公司线上产品线，开箱即用。  
  
XXL-JOB <= 2.2.0 版本默认情况下 API接口 没有配置认证措施，未授权 的攻击者可通过发送精心构造的恶意请求，触发反序列化，造成远程命令执行，从而获取服务器权限。该漏洞利用 无需登录，风险极高。雁行安全团队提醒 XXL-JOB 用户尽快采取安全措施阻止漏洞攻击。  
  

**漏洞影响范围**  

XXL-JOB <= 2.2.0  

  

**修复建议**

增加授权验证，配置 xxl.job.accessToken 防止未授权访问漏洞。
