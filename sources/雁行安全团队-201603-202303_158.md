# 【风险通告】ZenTaoPMS 文件上传漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTIzMzM1Ng==&mid=2651101460&idx=1&sn=72c1208a67660de60b8c936e0dfc0fcc&chksm=8c6b5f37bb1cd6211842fd83238121e5e9e186ec954010269954af852dbdedeb8ff6131ca9ac&scene=126&sessionid=1681408572#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTIzMzM1Ng==&mid=2651101460&idx=1&sn=72c1208a67660de60b8c936e0dfc0fcc&chksm=8c6b5f37bb1cd6211842fd83238121e5e9e186ec954010269954af852dbdedeb8ff6131ca9ac&scene=126&sessionid=1681408572#rd)

  

2020年10月26日，雁行安全团队监测到 禅道 官方发布了 ZenTaoPMS 文件上传漏洞（CNVD-C-2020-121325） 的风险通告，漏洞概况如下：  

| CNVD编号 || CNVD-C-2020-121325 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 文件上传  
 |
| 利用条件  
 || 用户登录  
 |

**漏洞详情**  

禅道是第一款国产的开源项目管理软件。它集产品管理、项目管理、质量管理、文档管理、 组织管理和事务管理于一体，是一款专业的研发项目管理软件，完整地覆盖了项目管理的核心流程。禅道管理思想注重实效，软件架构合理，操作简洁高效，代码实现合理，内置灵活的扩展机制和api调用机制，支持多语言。  
  
ZenTaoPMS <= 12.4.2 版本中存在 文件上传漏洞，经过身份认证 的攻击者可利用该漏洞发送精心构造的请求包上传恶意文件，从而控制服务器。此漏洞暂时没有相关利用细节公开。雁行安全团队提醒禅道用户尽快更新至安全版本阻止漏洞攻击。  
  

**漏洞影响范围**  

ZenTaoPMS <= 12.4.2  

  

**修复建议**

升级至12.4.3版本：  

https://www.zentao.net/download/zentaopms12.4.3-80272.html

  

**参考链接**  

https://www.zentao.net/download/zentaopms12.4.3-80272.html
