2020年10月23日，雁行安全团队监测到 vmware 官方发布了 VMware ESXi 远程代码执行漏洞（CVE-2020-3992）的风险通告，漏洞概况如下：  

| CVE编号 || 

## CVE-2020-3992

 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

**漏洞详情**  

VMware ESXi是美国威睿（VMware）公司的一套可直接安装在物理服务器上的服务器虚拟化平台。

VMware ESXi 特定版本存在 远程代码执行漏洞，目前暂无漏洞利用细节公开。驻留在管理网络中的攻击者有权访问 ESXi 计算机上的 427端口，成功利用漏洞会在 OpenSLP 服务 中触发 UAF，从而导致远程代码执行。

  

**漏洞影响范围**  

ESXi 7.0

ESXi 6.7

ESXi 6.5

VMware Cloud Foundation(ESXi) 4.x

VMware Cloud Foundation(ESXi) 3.x

  

**修复建议**

ESXi 7.0 升级 ESXi\_7.0.1-0.0.16850804  
ESXi 6.7 升级 ESXi670-202010401-SG  
ESXi 6.5 升级 ESXi650-202010401-SG  
VMware Cloud Foundation(ESXi) 4.x  升级4.1  
VMware Cloud Foundation(ESXi) 3.x  升级3.10.1.1  

补丁获取链接：https://my.vmware.com/group/vmware/patch
