2020年10月21日，雁行安全团队监测到 Oracle 官方发布了 2020年10月关键补丁更新，漏洞概况如下：

  

**漏洞详情**  

Oracle官方于10月21日发布了关键安全补丁集合，修复了多个高危漏洞。其中影响严重的漏洞有：Oracle WebLogic Server多个反序列化漏洞（CVE-2020-14882、CVE-2020-14841、CVE-2020-14825、CVE-2020-14859、CVE-2020-14820） 以及 Oracle Communications、Oracle E-Business Suite、Oracle Financial Services Applications 等多个产品的严重漏洞。未经授权的攻击者可以利用这些漏洞在服务器 执行恶意代码，获取系统权限。

  

同时，Oracle 10月补丁中还涉及其他多个高危漏洞，雁行安全团队提醒 Oracle 用户尽快安装补丁阻止漏洞攻击。
