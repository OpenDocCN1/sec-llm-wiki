2020年10月16日，sonatype 官方发布了 Shiro & Nexus Repository Manger 2/3 权限验证绕过漏洞 的风险通告，漏洞概况如下：  

| 风险等级 || **高危**  
 |
| --- | --- |
| 漏洞类型  
 || 权限绕过  
 |

  

**漏洞详情**  

Sonatype Nexus Repository Manager(NXRM)是美国 Sonatype 公司的一款存储库管理器，它主要用于管理、存储和分发软件等。Sonatype Nexus Repository Manager2 & 3 特定版本存在 权限验证绕过 漏洞，攻击者可利用该漏洞发送特定的请求包绕过登录权限。  
雁行安全团队提醒Sonatype Nexus Repository Manager2 & 3用户尽快升级至安全版本阻止漏洞攻击。

  

**漏洞影响范围**  

Nexus Repository Manager 2：< 2.14.19

Nexus Repository Manager 3：< 3.27.0  

  

**修复建议**

升级至安全版本。  

Nexus Repository Manager 2下载链接 ：https://help.sonatype.com/repomanager2/download

Nexus Repository Manager 3下载链接 ：https://help.sonatype.com/repomanager3/download
