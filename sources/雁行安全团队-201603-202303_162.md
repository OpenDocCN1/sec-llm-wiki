2020年10月13日（微软2020年10月补丁日），微软 官方发布了 Windows TCP/IP远程代码执行漏洞（CVE-2020-16898）的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-16898 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |
| CVSS评分 || 9.8  
 |

**漏洞详情**  

微软官方于10月13日发布安全更新，其中修复了 Windows TCP/IP远程代码执行漏洞（CVE-2020-16898）。该漏洞源于 Windows TCP / IP堆栈 对 ICMPv6路由器广告数据包 不适当的处理。攻击者通过将特制的 ICMPv6 路由器广告数据包发送到远程Windows计算机上，可以获得在目标服务器或客户端上执行代码的能力。同时，微软10月补丁中还涉及其他多个高危漏洞，雁行安全团队提醒Windows用户尽快安装补丁阻止漏洞攻击。
