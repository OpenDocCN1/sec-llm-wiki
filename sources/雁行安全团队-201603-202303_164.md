近日，雁行安全团队监测到 Apache Solr 官方发布了 Apache Solr configset upload文件上传漏洞（CVE-2020-13957） 的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-13957 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 文件上传  
 |

  

**漏洞详情**  

Apache Solr是美国阿帕奇（Apache）软件基金会的一款基于Lucene（一款全文搜索引擎）的搜索服务器。该产品支持层面搜索、垂直搜索、高亮显示搜索结果等。  
  
Apache Solr 特定版本中存在文件上传漏洞。攻击者可通过 ConfigSets API 上传功能的未授权漏洞，发送精心构造的请求包，上传恶意文件，从而获得服务器的权限。  

  

**漏洞影响范围**  

Apache Solr 6.6.0 - 6.6.5

Apache Solr 7.0.0 - 7.7.3

Apache Solr 8.0.0 - 8.6.2

  

**修复建议**

升级至最新版本：  

https://lucene.apache.org/solr/downloads.html

  

**参考链接**  

https://www.mail-archive.com/announce@apache.org/msg06149.html  

https://issues.apache.org/jira/browse/SOLR-14925
