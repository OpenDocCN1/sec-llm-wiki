近日，雁行安全团队监测到 Openwall 社区发布了 Linux内核权限提升漏洞（CVE-2020-14386） 的风险通告，漏洞概况如下：  

| CVE编号 || CVE-2020-14386 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 权限提升  
 |
| CVSS评分 || 7.8  
 |

**漏洞详情**  

Linux kernel 是美国Linux基金会发布的开源操作系统Linux所使用的内核。Linux kernel 特定版本中存在权限提升漏洞。该漏洞源于发行版 \>4.6 的Linux内核中的 net / packet / af\_packet.c 在处理AF\_PACKET时存在整数溢出漏洞，导致越界写入从而实现权限提升。攻击者可利用此漏洞获取系统 root 权限。  

  

**漏洞影响范围**  

4.6<= Linux kernel < 5.9-rc4  

CentOS = 8

Ubuntu => 18.04

RHEL = 8

Debian = 9/10
