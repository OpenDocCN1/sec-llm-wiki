微软在8月补丁日发布了 NetLogon 特权提升漏洞 的风险通告，漏洞概况如下：

| CVE编号 || CVE-2020-1472 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 权限提升 |
| CVSS评分  
 || 10.0  
 |

2020年9月，该漏洞的POC被公开上传到Github，相关的技术细节已经被公布，风险较高。

**漏洞详情**

Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。Netlogon是一个用于为域控制器注册所有SRV资源记录的服务。

微软官方8月12日（8月补丁日）发布安全更新，其中修复了一个 NetLogon权限提升漏洞（CVE-2020-1472），攻击者通过 NetLogon（MS-NRPC）建立与域控间易受攻击的安全通道时，利用此漏洞可以获取到域管访问权限。成功利用此漏洞可以在该网络中的设备上运行任意代码。

雁行安全团队建议 Windows 用户尽快安装补丁阻止漏洞攻击。

  
  

**漏洞影响范围**

Windows Server 2008 R2 for x64-based Systems Service Pack 1

Windows Server 2008 R2 for x64-based Systems Service Pack 1 (Server Core installation)

Windows Server 2012

Windows Server 2012 (Server Core installation)

Windows Server 2012 R2

Windows Server 2012 R2 (Server Core installation)

Windows Server 2016

Windows Server 2016 (Server Core installation)

Windows Server 2019

Windows Server 2019 (Server Core installation)

Windows Server, version 1903 (Server Core installation)

Windows Server, version 1909 (Server Core installation)

Windows Server, version 2004 (Server Core installation)
