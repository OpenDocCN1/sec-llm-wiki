# 【风险通告】Exchange Server 远程代码执行漏洞

2020年9月8日（微软2020年9月补丁日），微软 官方发布了 Exchange Server 远程代码执行漏洞（CVE-2020-16875） 的风险通告，漏洞概况如下：

| CVE编号 || CVE-2020-16875 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

**漏洞详情**  

微软官方于9月8日发布安全更新，其中修复了 Exchange Server 远程代码执行漏洞，该漏洞源于 Microsoft Exchange 服务器对 cmdlet参数 不正确的验证。攻击者通过在受影响的 Exchange 服务器上构造特殊的 cmdlet参数 即可触发该漏洞，造成以系统最高权限(System权限)执行任意代码的影响。同时，微软9月补丁中还涉及 Windows DHCP Server 信息泄漏漏洞（CVE-2020-1031）、Microsoft SharePoint Server篡改漏洞（CVE-2020-1440）、 Windows摄像头编解码器远程代码执行漏洞（CVE-2020-0997）等其他多个高危漏洞。  
  

**漏洞影响范围**  

Microsoft Exchange Server 2016 Cumulative Update 16

Microsoft Exchange Server 2016 Cumulative Update 17  

Microsoft Exchange Server 2019 Cumulative Update 5  

Microsoft Exchange Server 2019 Cumulative Update 6

  

**修复建议**

厂商已发布升级补丁以修复漏洞，补丁获取链接：
