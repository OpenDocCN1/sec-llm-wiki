# 【风险通告】通达OA后台多处SQL注入漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIxNTIzMzM1Ng==&mid=2651101272&idx=1&sn=a3cd51a3afce1f74c4303759e5a23b5d&chksm=8c6b5e7bbb1cd76d2e5b77a455b28cf36ca9df7a97b6fefcad27be23a85d26ad4a734c41b00f&scene=126&sessionid=1681408582#rd](http://mp.weixin.qq.com/s?__biz=MzIxNTIzMzM1Ng==&mid=2651101272&idx=1&sn=a3cd51a3afce1f74c4303759e5a23b5d&chksm=8c6b5e7bbb1cd76d2e5b77a455b28cf36ca9df7a97b6fefcad27be23a85d26ad4a734c41b00f&scene=126&sessionid=1681408582#rd)

  

2020年8月24日，雁行安全团队监测到通达OA后台存在多处SQL注入漏洞，漏洞概况如下:

| 风险等级 || **高危**  
 |
| --- | --- |
| 漏洞类型‍  
 || SQL注入  
 |
| 利用条件  
 || 普通用户登录  
 |

**漏洞详情**  

通达OA（Office Anywhere网络智能办公系统）是由北京通达信科科技有限公司自主研发的协同办公自动化软件，是与中国企业管理实践相结合形成的综合管理办公平台。  
  
通达OA特定版本（V11.5版本已验证）中存在 多处SQL注入漏洞，攻击者以 普通用户登录 后，可通过发送精心构造的SQL语句，获取数据库敏感数据、执行恶意SQL语句。  

| **漏洞** || **漏洞接口**  
 |
| --- | --- |
| SQL注入漏洞1‍  
 || /general/appbuilder/web/calendar/calendarlist/getcallist  
 |
| SQL注入漏洞2‍‍‍ || /general/email/sentbox/get\_index\_data.php |
| SQL注入漏洞3  
 || /general/email/inbox/get\_index\_data.php  
 |
| SQL注入漏洞4  
 || /general/appbuilder/web/report/repdetail/edit  
 |

  

**修复建议**

升级至最新版本，雁行安全团队将持续关注官方更新公告并第一时间同步客户。
