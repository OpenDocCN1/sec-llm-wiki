2020年8月18日，Apache官方发布了 Apache Shiro 权限绕过漏洞（CVE-2020-13933） 的风险通告，漏洞概况如下:

| CVE编号 || CVE-2020-13933 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 权限绕过  
 |

**漏洞详情**  

Apache Shiro是一个强大且易用的Java安全框架，执行身份验证、授权、密码和会话管理。使用Shiro的易于理解的API，可以快速、轻松地获得任何应用程序，从最小的移动应用程序到最大的网络和企业应用程序。  
  
Apache Shiro <1.6.0 版本中存在 权限绕过漏洞，攻击者可通过发送精心构造的HTTP请求进行权限绕过，对相关程序接口未授权访问。  
  
雁行安全团队建议用户及时对受影响版本的Apache Shiro 进行升级。  

  

**漏洞影响范围**  

Apache Shiro < 1.6.0  

  

**修复建议**

升级至 >= 1.6.0版本，下载链接：  

http://shiro.apache.org/download.html
