# 【风险通告】 Apache Struts2 远程代码执行漏洞

2020年8月13日，Apache官方发布了 Struts2远程代码执行漏洞 的风险通告（CVE-2019-0230），漏洞概况如下:

| CVE编号 || CVE-2019-0230 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 漏洞类型  
 || 远程代码执行  
 |

**漏洞详情**  

Struts2是一个基于MVC设计模式的Web应用框架，它本质上相当于一个servlet，在MVC设计模式中，Struts2作为控制器(Controller)来建立模型与视图的数据交互。  
  
Apache Struts2 特定版本中存在 远程代码执行漏洞，该漏洞需要满足3个限制条件：1. Struts2标签的属性值可执行OGNL表达式；2. Struts2标签的属性值可被外部输入修改；3. Struts2标签的属性值未经安全验证。攻击者可以在Struts属性值构造恶意的 OGNL 表达式，当 OGNL 表达式被二次解析时，即可造成远程代码执行。  
  
雁行安全团队建议用户及时对受影响版本的Struts2进行升级。  

  

**漏洞影响范围**  

Struts 2.0.0 - Struts 2.5.20  

  

**修复建议**

升级至最新版本，下载链接：  

https://struts.apache.org/download.cgi#struts2522

  

**参考链接**  

https://cwiki.apache.org/confluence/display/WW/S2-059
