近日，Sonatype 官方发布了 Nexus Repository Manager 3.x 远程代码执行漏洞 的风险通告，漏洞概况如下：

| CVE编号 || CVE-2020-15871 |
| --- | --- |
| 风险等级 || **高危**  
 |
| 利用条件  
 || 需登录  
 |
| 漏洞类型  
 || 代码执行  
 |

**漏洞详情**  

Sonatype Nexus Repository Manager(NXRM)是美国 Sonatype 公司的一款存储库管理器，它主要用于管理、存储和分发软件等。

Sonatype Nexus Repository Manager 3 OSS / Pro 3.25.1 之前版本中存在 远程代码执行漏洞，攻击者**登录后**可利用该漏洞执行任意代码。

雁行安全团队建议Sonatype用户及时对受影响版本的 Nexus Repository Manager 3 OSS / Pro 进行升级。

  

**漏洞影响范围**

< Sonatype NXRM OSS/Pro 3.25.1

  

**修复建议**

升级至最新版本 3.25.1，下载链接如下：

https://help.sonatype.com/repomanager3/download
