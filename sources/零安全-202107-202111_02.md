前段时间一直在研究有关于RootKit相关的东西，试着想了一下既然R3可以将程序进行内存加载达到隐藏进程的效果，那么R0下是否可行呢？

### 0x01 PE前置知识：

在了解这项技术之前需要知道几个专有名词：

1.  FOA
    
2.  ROA
    
3.  导入表
    
4.  重定位表

### 0x03 在内存中展开文件：

在PE头中的扩展头中有个很重要的属性叫做：SizeOfImage，这个属性告诉了我们此PE文件在内存展开后有多大,使用LOADPE进行查看：

![](../Images/8bcaf0e2444637940239221c7acca5c7.png)

下面的SizeOfHeaders告诉我们PE头有多大，所以我们可以根据这个两个来展开PE文件：

![](../Images/c3d8a536a339734cee1b155111301283.png)

在申请好内存展开后的内存后，需要将PE复制进入内存:

```
1.  `memcpy(imageBuffer, fileBuffer, pNts->OptionalHeader.SizeOfHeaders);`
    
```

接下来就是拉伸PE了，我们需要知道这个PE文件有多少个节区，在非扩展头的NumberOfSections属性中：

![](../Images/0d7f1bfd32ed570d5987b434f9e0eade.png)

知道了这个我们还需要知道节表的偏移和尺寸，也就是PointerToRawData以及SizeOfRawData，我们需要套入公式：ImageBase.VirtualAddress = FileBase.PointerToRawData+SizeOfRawData

![](../Images/7bfc85b352fe89111a72e58d6425aca1.png)
