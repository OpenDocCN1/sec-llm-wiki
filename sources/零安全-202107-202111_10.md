### 0x01 前言

某些攻防对抗中，常常遇到一些对抗防护，有的即使目标能上线，执行命令正常的命令都会断开连接，由此简单判定这类防护对交互的流量进行了检测，本文从**beacon\_http/https**入手去修改**cobaltstrike **的一些默认流量躲避检测防护。

### 0x02 http流量混淆修改：

cobaltstrike 自带流量混淆伪装方式，用来过一般的检测设备问题不大。这个时候就要用到Malleable-C2。下图是cobaltstrike默认支持的数据编码转换方式，各位可以根据自己的需求自行修改添加：

![](../Images/e05912378db0daac34b37002d207a1e6.png)

每个人的思路不同，做出来的文件流量特征不同。

可以根据需要参考github的例子：https://github.com/rsmudge/Malleable-C2-Profiles，例如：

![](../Images/e7433d9cd5df3c9bcdc88470749b6919.png)

我们混淆这些操作，所做的一切都是让各种流量检测设备认为这是一个正常的请求交互流量，坚持这个核心想法就好了，详细操作官方文档里面有详细视频。需要值得注意的是：

1.  http-post.client size或者http-get.client size的大小必须小于252,否则c2lint检查会failed
    
2.  编码的http post 大小 小于 非编码post 大小x3,否则c2lint检查会failed
    

运用如上混淆后，检查你的xxxx.profile是否正确的命令：./c2lint xxxx.profile 修改创建profile的参考链接：https://www.cobaltstrike.com/help-malleable-c2

### 0x04 https 流量修改(非权威证书)

具体步骤如下：

1.  删除自带的cobaltstrike.store文件
    
2.  修改teamserver keytool生成文件那一行，如下图：
    

![](../Images/bb543a38362cf997284e5c525cbf85b6.png)

这里的密码改了之后，最后一行加载store文件的密码也需要修改：

![](../Images/ae18ac36a19192b49b647b5dc08d3f99.png)

    3.修改teamserver最后一行附近的keyStorePassword值

    4. 在.profile文件里面新增如下行（这一步一定要操作,否则你的证书啥的似乎不会生效）：  

```
1.  `https-certificate {`
    
2.  ` set keystore "cobaltstrike.store";`
    
3.  ` set password "xxxxx";`
    
4.  `}`
    
```

### 0x07 简单去除cobaltstrike stage uri的特征：

如上把profile文件配置好后，stager 例如下图设置好：

![](../Images/5f63699d80d6eeb4a3baeb9430120b85.png)

服务端启动之后，连接到cobaltstrike ，web服务管理 kill掉所有stager和stager64（这些是新建beacon\_http/https 会自动生成的，kill掉不会影响profile的效果），cobaltstrike默认的uri就访问不到了，所有上线的stager，都通过你自己profile定义好的uri来访问。到此，流量上的一些基本特征算是去除了。
