#### **0x05 配置防火墙和端口转发**

*   
*   
*   

```
iptables --table nat --append POSTROUTING --out-interface eth0 -j MASQUERADE iptables --append FORWARD --in-interface wlan0mon -j ACCEPT echo 1 > /proc/sys/net/ipv4/ip_forward
```

![](../Images/ce0bfea6125b8160142cdbe8c15a8313.png)  

#### **0x06 给无线网卡分配IP地址**

这样做是为了可以让连接钓鱼Wifi的人可以上网

*   
*   

```
ifconfig wlan0mon up 192.168.1.1 netmask 255.255.255.0 route add -net 192.168.1.0 netmask 255.255.255.0 gw 192.168.1.1
```
