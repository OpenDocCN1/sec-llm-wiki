## **01 项目安装**

先把DC-6的靶机安装到本地

下载地址是：https://www.five86.com/dc-6.html

![](../Images/f210abd944a263aeeafc4181e793d795.png)

进入页面点击`here` 进行下载

下载好之后，导入咱们的虚拟机

![](../Images/8b67e68d636621e6e599760111498d3f.png)

看到这个页面，表示我们靶机安装成功

  

## **02 信息收集**

首先我们进行信息收集，获取靶机的ip和相关端口

```
#获取ip地址
netdiscover \-r  192.168.1.0/24
```

![](../Images/e38fdd7433f9974c6d9972819486fc16.png)

知道了Ip，看下靶机开放了哪些端口

```
#获取端口
nmap \-A  192.168.1.148
```

![](../Images/76283ae908e02b43423399379ff9cc3a.png)

可以看到靶机开放了80端口和22端口，访问一下页面

![](../Images/a1e5ece418cb458be1d774253314e648.png)

可惜的是访问不了，因为做了域名绑定，所以需要我们在本地做个域名映射，这个和之前DC-2是一样的问题

打开C:\\Windows\\System32\\drivers\\etc下的hosts文件

在末尾加入

192.168.1.148   wordy (记住写上自己靶机的IP)

![](../Images/377bf275d36e69299b6d6f82acd67784.png)

ok，访问成功

当然咱们kali也需要进行进行配置

```
vi  /etc/hosts
\# 将 192.168.1.148   wordy 加入末尾
```

![](../Images/8d307ef2e8c88668276148cbea4168d8.png)

保存退出

  

## **03 指纹识别**

在页面查看一番，很明显这个是WordPress开发的，后台也是特定的是wp-admin，访问一下

![](../Images/ebb2755d72081a19ff94f4ff5ece4203.png)

后台也获取到

既然已经知道是WordPress，那我们可以使用一个神器工具 `wpscan` ，这个工具是专门用来扫描WordPress 漏洞的黑盒子扫描器

在kali中执行

```
\# 获取可能存在的用户名
wpscan  \--url  http://wordy/ \-e u
```

![](../Images/7f290c5c820c3c148794b3e458fbcedf.png)

用户名为：admin，mark，graham，sarah，jens

既然获取到了用户名，现在只需要获得密码，就可以直接爆破

寻找了一番，发现DC-6的作者已经把密码告诉我了我们：https://www.vulnhub.com/entry/dc-6,315/

```
OK, this isn't really a clue as such, but more of some "we don't want to spend five years waiting for a certain process to finish" kind of advice for those who just want to get on with the job.

cat /usr/share/wordlists/rockyou.txt | grep k01 > passwords.txt That should save you a few years. ;-)
```

在kali中执行

```
cat /usr/share/wordlists/rockyou.txt | grep k01 > passwords.txt
```

![](../Images/68d8c96ab71c32433daf8f7a5463626f.png)

可以看到密码已经获取到

创建个username.txt文件，把之前的用户名放入里面，准备开始爆破

![](../Images/a3b462ee39e535fb5ae57c6438208837.png)

执行

```
wpscan –url http://wordy –U username.txt –P passwords.txt
```

![](../Images/5631f0513f03071ae7e5a2930fe52e16.png)

获取到账户名为: mark，密码是: helpdesk01

![](../Images/a78a53a2acf03f534a807f2015b1ba03.png)

登录成功
