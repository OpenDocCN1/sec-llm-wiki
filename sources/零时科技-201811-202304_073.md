# 喜讯！零时科技中标“商洛市农产品智慧监管平台”建设项目

项目背景

食品安全问题已经上升为国家最关心的问题之一，尤其是食用农产品安全，也是解决民生问题的重要工作。中国自古以来就是农业大国，食用农产品又是关乎民生的头等大事，为了确保消费者“舌尖上的安全”，食用农产品的安全问题已经逐步成为政府及社会的重点关注点之一。

由于食用农产品生长及生产环节比较复杂，工艺过程数据实效性及真实性受各种因素影响没办法建立一个完成的数据库，导致传统食品安全监管存在一系列问题：

1.  食用农产品需要溯源的时候企业存在篡改信息及溯源流程信息不准确以及信息失效的可能性。
    
2.  农业生产过程中由于参与者管理体系都是独立运行的，信息数据孤岛严重。
    
3.  数据中心化，信息实效性不完整、不对称，监管不及时等。一旦信息出现不利于自身情况时，该环节主体很有可能篡改信息或者谎称信息丢失，推卸责任。造成举证、追责困难等无法准确的确权责任。
    
4.  农产品的数据复杂多样化，国家食品安全标准约束力较低，市场经营也因人而异，行政监管也比较难，监管体制数据难采集。
    

![](../Images/4e1fe7300b67a2bada9d215cbca84499.png)

为了解决这一问题，商洛市建立了市科技农业示范点，借助科技手段，打造一个从田间地头到餐桌的全方位无死角的科技新农业，每个环节数据均可实现智慧监督和监管，建立一个视觉农产品质量安全体系，规范食用农产品的市场销售行为，行之有效的提高农产品安全监督水平，有效防控食用农产品质量安全风险，从而进一步提升食用农产品的品质，提高消费者对食用农产品的放心程度。  

  

解决方案

零时科技通过区块链技术结合物联网设备，将食用农产品从选地、育种、除虫防治、施肥生长、采摘加工、农检残留、到产能等生产过程中的每个环节的数据记录上链，保证数据的真实性，且数据不可篡改从而提高农产品的质量监管，有效的防控食用农产品的安全。全面提升商洛市食用农产品的质量安全和防控监管数据。

![](../Images/9004ab850a9eb9c3a7a2d02b5f99b3a5.png)

通过“农产品智慧监管平台”确保每个环节都符合食用农产品安全标准后再将商洛市食用农产品投入到市场中销售。

消费者用户可以通过产品上面的二维码标识查看到商品的所有信息“追根溯源”，使消费者买的放心，吃的安心。

数据监控中心可以实时的同步展示农产品的生产环节数据，保证农产品每个环节公开透明，数据智能采集，真实记录，智慧监管，智能报警，全面提高商洛市食用农产品的安全质量。
