### 域前置与自删除

详情：FRP改造计划续

frps

```
1.  `[common]`
    
2.  `bind_port = 23333`
    
3.  `token = uknowsec`
    
```

frpc

```
1.  `[common]`
    
2.  `server_addr = test.com.w.cdngslb.com`
    
3.  `server_port = 443`
    
4.  `token = uknowsec`
    
5.  `protocol = wss`
    
6.  `#protocol = websocket`
    
7.  `tls_enable = true`
    
8.  `del_enable = true`
    
9.  `websocket_domain = test.com`
    
10.  
     
11.  `[http_proxy]`
     
12.  `type = tcp`
     
13.  `remote_port = 10002`
     
14.  `plugin = socks5`
     
```
