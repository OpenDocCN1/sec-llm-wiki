1100 1010 -> 反码：0011 0101 -> 补码：0011 0110 -> 十进制 -54

1111 1110 -> 反码：0000 0001 -> 补码：0000 0010 -> 十进制-2

1100 0000 -> 反码：0011 1111 -> 补码：0100 0000 -> 十进制-64

1011 1011 -> 反码：0100 0100 -> 补码：0100 0101 -> 十进制-69

最后就是byte\[\] b = {-54,-2,-64,-69}
