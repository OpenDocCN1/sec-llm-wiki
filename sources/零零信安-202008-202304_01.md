# 携手合作丨零零信安&众智维科技，构建新一代自动化攻防实战解决方案

在数字化进程中，网络安全技术体系和应用场景都在不停更迭，最明显的变化是网络安全逐步由重视建设进入到重视运营的阶段。网络安全越发向实战化、体系化、常态化发展，企业需要建立主动防御、动态防御、整体防护、纵深防御、精准防护、联防联控疏而不漏的安全防控体系，即“三化六防”要求。攻击面管理作为安全运营的创新技术，承载了安全行业的部分发展趋势和用户市场的高度期待。

  

为帮助企业有效应对新型安全风险攻击，零零信安联合南京众智维信息科技有限公司（以下简称“众智维科技”），构建新一代自动化攻防实战解决方案。

  

![](../Images/8a5a2d30dd0b30106a812f6ea63bc2d2.png)

  

EASM与RedOps携手合作，可直接获得企业外部攻击面情报数据，以安全运营目标为导向，以人、流程、技术与数据的融合为基础，在安全运营过程中实现自动化编排、自动化响应来建立可持续闭环的安全事件处理机制，构建高自动化水平的可信任安全智能AISecOps体系，实现从发现风险到处置风险的全面覆盖，进而也实现了从外部攻击面管理产品到外部风险管理解决方案的进化。

**联动**

  

在国内某头部运营商企业的攻防演练中，双方联动的硬实力得到了很好的展现。EASM与RedOps的联合解决方案，已经被多次运用到实际中。

  

![](../Images/ea4469a1463a75e4f1ce29596ae82231.png)

  

EASM与RedOps的高效协同作战，通过原生资产收集剧本从零零信安获取IP/域名，并通过nmap进行全端口扫描，模拟浏览器请求WEB页面存活探测，输出的结果通过漏扫，资产信息及漏扫报告通过钉钉发送给相关负责人。扩充资产收集剧本在原生资产收集剧本的基础上添加空间资产测绘节点，从而输出扩展资产：C段和子域名。

  

![](../Images/8109e847d29290873bb767a8b8d79e16.png)

  

数据泄露情报监测剧本通过零零信安7x24小时实时监测暗网及数千个泄露数据源，查询是否存在与目标单位相关的情报数据，一旦发现立即判断情报中是否存在关键要素：IP/域名、单位名称，并将结果通过钉钉APP进行提示。同时调动蓝凌OA系统查询内部资产台账，若符合内部资产，则创建协同作战室，启动数据泄露应急响预案。

  

![](../Images/f6dc4b7f3386f437dfc4cfa5ed1542d2.png)

  

原生资产收集剧本、扩充资产收集剧本和数据泄露情报监测剧本三个剧本的输出，极大的提高了红队的资产收集速度，同时协助蓝队生成外部攻击面安全报告，根据报告呈现出的风险进行相应的整改，对暴露的攻击面进行提前收敛，从而提前规避潜在的安全事件发生。

**安全产品**

  

云产品（CDN、云防、SASE等）：

为客户提供影子资产检测增值服务、互联网暴露面风险检测增值服务、了解客户哪些资产未上云，增加销售机会。

  

安全管理类（SOC、SIEM、SOR等）：

提供/补充安全管理中企业数字资产底图数据、与其他数据和产品进行联动、售前/演示/初始阶段即可拥有企业数据，增强产品效果展示。

  

漏洞管理类（扫描、BAS、ASM等）：

可在CMDB等之外的黑盒状态下为风险检测类产品提供资产靶标，作为补充、可协助客户检测影子资产并与产品联动检测其漏洞。

  

攻击检测类（XDR、IDS、蜜罐等）：

补充攻击检测全生命周期中“事前” 阶段风险数据、为攻击检测类产品综合分析和态势展示提供数据支持、增加产品控标指标。

  

数据安全类（审计、防御、DLP等）：

事前协助产品辅助检测数据泄露的外部风险、事中实时监测数据泄露外部情报信息、事后检查可能引起安全事件的路径。

  

**安全服务**

  

重保类（HW、重保等）：

为攻击队提供全面的企业外部攻击面情报，秒级输出5-15人日工作量的数据；快速、全面协助防守队甄别影子资产和企业数字资产暴露风险。

  

风险评估类（风评、渗透测试等）：

协助工程师快速定位突破口；可基于持续更新的情报数据为客户提供全年持续性渗透测试和攻击测试业务；可快速支持社工类测试服务。

  

安全运维类（MDR、MSS等）：

基于持续更新的数据为运维服务提供增量数据，协助定位优先关注点；协助定位影子资产和查找未知的互联网暴露数字资产风险点。

  

众测类（众测平台、SRC等）：

可协助众测平台和SRC，为白帽子提供更全面的测试范围和可利用情报，防止漏测和项目效果不佳；可将情报作为积分奖励，参与到平台运营中。

  

特殊场景类（监管、GA、JD等）：

快速、全量、准确获取目标各类情报信息，并自动化进行数据分类和标签处理，方便进行数据二次加工；节省特殊需求中厂商的资源投入。

**众智维RedOps 红鲸安全协同响应平台**

  

RedOps 红鲸安全协同响应平台将安全运营相关的团队、工具和流程通过编排和自动化技术整合，有序处理多源数据，持续进行安全告警分诊与调查、案例处置、协同作战、事件响应，并最终实现高效、有效安全运营的智能协作系统。RedOps实现了灵活可扩展性多种安全能力的集成和扩展，具体涉及威胁情报、网络安全防护、检测、响应及其他网络安全产品及工具。RedOps拥有较强的事件收集能力、API整合能力、情报分析和事件响应能力、结合用户自身形成的自动化响应机制。

**零零信安EASM攻击面管理平台**

  

北京零零信安科技有限公司立于2020年，是国内首家专注于外部攻击面管理（EASM）的网络安全公司。基于大数据立体攻防、以攻促防、主动防御、力求取得立竿见影效果的理念，为客户提供基于攻击者视角的外部攻击面管理技术产品和服务。零零信安EASM产品以最佳实践从而实现安全解决方案的扩展，获得客户及行业认可，在赛迪《中国攻击面管理白皮书》、Gartner《Hype Cycle for Security in China, 2022》数说安全《2022年中国网络安全十大创新方向》等被列为攻击面管理推荐厂商。

  

零零信安以扩展威胁情报（XTI）的形式从攻击者视角提供对情报的持续可见性，通过对公开网络和匿名网络中数千个威胁源，数百亿数据进行采集和分析，包括信息资产暴露面、影子资产的发现、漏洞、弱口令、文档和代码的泄露、组织和人员信息的泄露、供应链风险等，将企业IT暴露面、影子资产与企业之间进行映射，对可导致或形成攻击点的潜在风险进行数据泄漏风险查询，可与多种安全产品相结合，为不同安全服务项目提供有力支撑，让所有安全产品和服务团队以最低成本获得和补充暴露面&外部攻击面数据。![](../Images/23d6e4e70c653dd8a80223812851f85d.png)如何获取更多“数据泄漏情报”
