《2022中国网络安全行业全景册》


2023年2月1日，FreeBuf咨询正式发布《CCSIP（China Cyber Security Panorama）2022中国网络安全行业全景册（第五版）》。本次全景册面向广大国内安全厂商，经FreeBuf咨询团队审核并发布，为企业安全建设及产品选型提供参考。


零零信安荣获细分领域数据安全下的数据防泄漏DLP、漏洞检测与管理下的漏洞检测、安全情报下的威胁情报推荐厂商。



数据防泄漏DLP推荐厂商


零零信安EASM产品能够将企业暴露在外的（数字资产）与企业之间映射，对包括信息系统、移动端应用、敏感目录、电子邮箱、文档、产品代码、供应链、暗网情报、人员以及组织等可导致形成攻击点的潜在风险进行查询。


零零信安外部攻击面管理平台具有全网大规模（包括开放网络、非公开网络）数据采集能力，智能数据集群达到每秒近十万数据和每天每日数十万份入库数据数万份去重有效数据，当前已采集原始数据达数十亿条，进行智能处理和关联分析后的数据达近万亿条，每秒最大数据吞吐量为400万，智能分析速度可达到10万条/秒，每天互联网风险文件和代码检测速度最大可达1.2亿个，每天匿名网络入库数量为10-15万篇。


零零信安攻击面管理可为各种组织提供00SEC-D&D数据泄露报警系统，为监管侧、企业用户提供全网数据泄露可视性，该系统可对数千个泄露源进行7*24小时监控，通过对海量数据汇聚和数据智能分析，让客户第一时间获取是否存在数据泄露的情况发生，从而为后期的研判、应急提供支撑。



漏洞检测推荐厂商


零零信安漏洞管理技术，通过清晰的数据关联、统计分析，将全局风险、资产和漏洞变化、修复时长和修复指标等，进行可视化，配合企业的挂图作战和态势感知。灵活的账号体系，可支持外部渗透测试漏洞提交和电子化管理，协助企业更加全面的进行风险管理。可自动调度各主流扫描器及分析，配合自研的 1day 和缺省/弱口令检测功能，最大化发现企业漏洞。对数十万漏洞进行高级情报分析，结合企业业务、CVSS、漏洞情报、威胁情报、全球漏洞普适度和利用性等数据，为用户提供修复指导方案。


零零信安是国内首家将弱点/漏洞优先级技术（VPT）进行产品化和数据服务实践的厂商，是国内外部攻击面管理（EASM）技术的最早实践企业，通过自身的不断创新，推动了国内的外部攻击面管理技术加速落地，并已经成为 EASM 领域内的领军品牌，拥有行业领先的网络攻防实战经验及产品化能力。零零信安已为国家部委、运营商、能源企业、银行、高校、研究院以及大型互联网企业等提供产品和服务支持。



威胁情报推荐厂商


新冠疫情加速了云采用、数字化转型和远程工作的扩展，加之公司企业每天都有新资产涌入网络，其数字足迹和攻击面变得更广、更分散、更具动态性。由于外部入侵和部分人为因素造成的数据泄露仍然是用户和企业的心腹大患。


00SEC-ASM 外部攻击面管理系统以查询、订阅、外部攻击面数据服务的方式，提供给客户攻击者视角中该企业的各类型风险情报。这些数据是通过对全球开放和非公开网络中数千个威胁源，数百亿数据进行采集和分析得到的，包括信息资产暴露面、影子资产的发现、漏洞、弱口令、文档和代码的泄露、组织和人员信息的泄露、供应链风险等。


零零信安系统平台全面覆盖网络中可能会导致企业各级组织相关业务、系统、数据、产品项目、代码、第三方供应商风险，以及企业组织人员隐私等相关数据泄露的威胁源，其中包括天眼查、Gitlib、Github、百度网盘等各个威胁源、社交媒体和云存储，帮助企业更为全面地发现风险，让企业拥有非公开网络的可视性，提前感知风险和威胁。零零信安不仅是对企业发出预警情报而是将外部攻击面管理和数字风险保护二者的融合，构成完整的攻击者视角。


北京零零信安科技有限公司成立于2020年，是国内首家专注于外部攻击面管理（EASM）的网络安全公司。基于大数据立体攻防、以攻促防、主动防御、力求取得立竿见影效果的理念，为客户提供基于攻击者视角的外部攻击面管理技术产品和服务。零零信安EASM产品以最佳实践从而实现安全解决方案的扩展，获得客户及行业认可，在赛迪《中国攻击面管理白皮书》、Gartner《Hype Cycle for Security in China, 2022》数说安全《2022年中国网络安全十大创新方向》等被列为攻击面管理推荐厂商。
