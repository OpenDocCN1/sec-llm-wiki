# 「网安新兴赛道及厂商指南」正式出炉，零零信安凭借出色安全能力被该指南收录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg3MzM0ODk1NQ==&mid=2247484386&idx=1&sn=207c6fa7d982452d24d45cf1d439213c&chksm=cee029d6f997a0c0fc16bef216449174e4ebe470354da003f0f833267bd6d8d49128824baefa&scene=126&sessionid=1681372203#rd](http://mp.weixin.qq.com/s?__biz=Mzg3MzM0ODk1NQ==&mid=2247484386&idx=1&sn=207c6fa7d982452d24d45cf1d439213c&chksm=cee029d6f997a0c0fc16bef216449174e4ebe470354da003f0f833267bd6d8d49128824baefa&scene=126&sessionid=1681372203#rd)

 ![](../Images/4b85f4befb9b6946b6bc83fe83b98117.png)  

  

2022年2月22日，专注于网络安全行业发展与市场营销态势的头部媒体喵喵站，正式发布**「Cyber Security Billboard·网安新兴赛道及厂商速查指南」（下称：指南）。**

 

喵喵站本次发布的《指南》，旨在帮助企业安全负责人、渠道合作伙伴和安全从业者及时了解网安行业的新兴赛道和前沿产品。此次《指南》总共发布了**99个**新兴产品赛道，收录了**420+**国内厂商和**350+**国际厂商。

 

![](../Images/9bd27637064b67a1018de5e85a5f1516.png)

  

零零信安作为网络安全领域内新兴崛起的企业，凭借出色的弱点/漏洞优先级技术、攻击面管理能力等，被喵喵站**收录于《指南》中3个不同的细分领域内，分别为网络资产攻击面管理（CAASM）、弱点/漏洞优先级技术（VPT），以及基于风险的漏洞管理（RBVM）。**

 

![](../Images/251caf950124813887ef79b4d1b18eae.png)![](../Images/c45e6ac00b9a70f5a699287b54de5975.png)![](../Images/0854258705f230ee854c84906bcc4467.png)

 

此外，从《网络安全法》到《数据安全法》的出台，再到近日正式施行的《网络安全审查办法》，当前数据安全治理已成为网络安全领域重中之重的工作之一。

 

为了帮助企业规避风险，达到合法合规性要求，**零零信安将“数字风险保护（DRP）”、“攻击面管理（ASM）”、“弱点/漏洞优先级排序技术（VPT）”相结合，创建出了“数据驱动的数字风险保护”的方法。**

 

零零信安作为**国内首家将这3项技术融合在一起的厂商**，将利用ASM对于组织数字资产的自主发现能力与DRP的情报数据进行映射，结合VPT进行优先级排序和处置。

 

对全球开放网络和非公开网络进行可视性和大数据分析，探测数字足迹、外部攻击面、泄漏的业务数据等，为组织输出“主动威胁情报”，形成网络安全保护壁垒，为企业提供更高级别的保护。

 

**并且由零零信安推出的国内唯一的数字风险保护SAAS服务平台0.zone，将于近期上线。**

  

![](../Images/b4cfe449a86eba91bd1f40add22fa8a2.png)

  

届时组织可以使用0.zone了解业务系统漏洞情报信息，监测组织关键人员个人隐私泄漏情况，检测组织的敏感信息、数字资产、业务数据、产品代码等信息的泄漏程度，发现组织外部暴露面等。

 

**0.zone现已进入测试阶段，敬请期待！**
