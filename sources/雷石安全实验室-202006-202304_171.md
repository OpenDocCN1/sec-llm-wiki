**\# 国内资讯 #**

  

  

  

  

  

**01**

  

**工信部、公安部约谈阿里云、百度云**

**督促落实防范治理电信网络诈骗工作要求**

  

近日，工业和信息化部网络安全管理局、公安部刑事侦查局联合约谈阿里云、百度云两家企业相关负责人，通报了近期两家企业在防范治理电信网络诈骗工作中存在的接入涉诈网站数量居高不下等问题，要求两家企业切实履行网络与信息安全主体责任，严格落实《网络安全法》等法律法规要求，对相关问题限期予以整改；拒不整改或整改不到位的，将依法依规从严惩处。

消息来源：https://mp.weixin.qq.com/s/qn7KhpFq5yn0L2p9v6w8Iw

  

  

  

  

  

  

**02**

  

**贯彻《关键信息基础设施安全**

**保护条例》，加强供应链安全工作**

![](../Images/9e98235645a0a34f6bf2c13fec02db5d.png)

  

自 2021 年 9 月 1 日起 ,《关键信息基础设施安全保护条例》（以下简称《条例》）已正式施行。《条例》的出台，是确保关键信息基础设施安全的关键手段。贯彻落实《条例》的要求，对于保障国家安全、经济发展和社会稳定，以及推进信息化建设具有十分重要的意义。其中，《条例》第 19 条和 20 条，对运营者采购网络产品和服务提出了具体要求，对应对关键信息基础设施的供应链安全风险意义重大。

消息来源：https://www.secrss.com/articles/36553

  

  

  

  

**03**

  

**

腾讯迎来最严APP监管！

旗下所有APP需检测合规才可更新

**

![](../Images/1b6db997c79a99cfa03539b58f6edbcf.png)

消息来源：https://www.secrss.com/articles/36451

  

  

  

  

  

  

**04**

  

**太古海事遭勒索攻击，**

**部分中国雇员信息泄露**

![](../Images/53d3f679f00d51a0caa7d701e3367e43.png)

  

Swire Pacific Offshore(SPO)太古海洋开发集团(太古公司旗下)已确认成为Cl0p勒索软件团伙有针对性的网络攻击的受害者。该公司声称可能会暴露个人信息和机密专有商业信息。

消息来源：https://www.secrss.com/articles/36549

  

  

**\# 国外资讯 #**

  

  

  

**01**

  

**英国交通部官网遭黑，**

**关键页面被蓄意篡改**

  

当地时间11月25日早些时候，英国交通部(DfT)的一个网站被发现提供色情服务。正常情况下，被修改的特定DfT子域是为公众和部门的业务计划提供重要的DfT统计数据的。目前charts.dft.gov.uk页面仍然无法访问。

消息来源：

https://www.secrss.com/articles/36524

  

  

  

  

**02**

  

**德国政府报告：Open RAN存在安全风险**

  

据Light Reading报道，德国联邦信息安全办公室（德语简称BSI）刚刚发布了一份基于新概念的关于网络弹性的潜在破坏性报告，其中对Open RAN争论进行了权衡。它的主要结论似乎是，不同供应商的产品混搭在一起（Open RAN的主要主张）会招致麻烦，并且在技术规范方面没有做足够的工作来确保Open RAN是安全的。

消息来源：https://www.secrss.com/articles/36448

  

  

  

  

  

**03**

  

**苹果起诉NSO Group使用间谍软件**

![](../Images/b8ae4af29baa791a03234651c49a2aa1.png)

据官方报道，苹果正在起诉以色列间谍软件制造商NSO集团及其母公司Q Cyber“追究其对苹果用户的监视和攻击责任”，并寻求永久禁令，禁止NSO集团使用苹果设备、软件和服务。

消息来源：https://www.secrss.com/articles/36421

  

  

  

  

**04**

  

**酒店客户信息被泄露，新加坡**

**监管机构惩罚有史最大的数据泄露**

  

新加坡个人数据保护委员会(PDPC)对旅游公司Commeasure处以罚款74,000新元(合54,456美元)，原因是该公司未能部署安全保护措施，使其经营的一个名为RedDoorz的旅游预订网站曝光了590万客户的数据——这是该委员会自成立以来处理的最大一次数据泄露。

消息来源：https://zhuanlan.kanxue.com/article-17038.htm

  

  

**\# 威胁情报 #**

  

  

  

**01**

  

**A****PT组织利用FatPipe VPN**

**中的0 Day漏洞长达六个月**

![](../Images/459f95de91b054173d5ca90bba58fb87.png)

FBI警告称，至少从5月开始，威胁行为者就一直在利用FatPipe虚拟专用网络（VPN）设备中的0day漏洞来破坏公司并访问其内部网络。“截至2021年11月，FBI取证分析表明，FatPipe MPVPN设备软件中的0day漏洞至少可以追溯到2021年5月，”该局在周二的警报（PDF）中表示。

消息来源：

https://www.4hou.com/posts/MW7A

  

  

  

  

**02**

  

**Canopy家长控制应用程序曝出xss漏洞**

  

研究人员称，Canopy是一个家长控制应用程序，它提供了一系列的功能，可以通过内容检查来保护孩子们上网，但它却很容易受到各种跨站脚本（XSS）攻击。这些攻击可以造成禁用孩子的监控甚至是更严重的后果，还可以向家长提供恶意软件。

消息来源：https://www.4hou.com/posts/AKN3

  

  

  

  

**03**

  

**所有 Windows 版本均受影响 **

**Cisco Talos 发现一个高危提权漏洞**

  

计算机安全组织 Cisco Talos 发现了一个新的漏洞，包括 Windows 11 和 Windows Server 2022 在内的所有 Windows 版本均受影响。该漏洞存在于 Windows 安装程序中，允许攻击者提升自己的权限成为管理员。

消息来源：https://hackernews.cc/archives/36852

  

  

  

  

**04**

  

**Linux Kernel TIPC任意代码**

**执行漏洞安全风险通告**

  

近日，奇安信 CERT 监测到Linux kernel TIPC任意代码执行漏洞(CVE-2021-43267)的漏洞细节和EXP已在互联网公开。漏洞存在于Linux 内核中的 net/tipc/crypto.c 中，由于Linux Kernel TIPC模块对用户提供的 MSG\_CRYPTO 消息类型大小验证不足，攻击者可以利用此漏洞在目标者系统上以ROOT权限执行任意代码。鉴于漏洞危害较大且漏洞细节和EXP已公开，建议用户及时升级版本。

消息来源：https://www.secrss.com/articles/36572
