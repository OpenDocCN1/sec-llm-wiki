# 国内资讯 #






01


信安标委技术文件《即时通信

服务平台个人信息认定指南》

（征求意见稿）征求意见


全国信息安全标准化技术委员会组织制定的技术文件《即时通信服务平台个人信息认定指南》已形成征求意见稿。根据《全国信息安全标准化技术委员会技术文件制订工作程序（试行）》，现将该技术文件面向社会公开征求意见，如有意见或建议请于2021年12月12日24:00前反馈秘书处。

消息来源：https://mp.weixin.qq.com/s/fL83tNWNuVGWHVxaFLrYXg






02


工信部就“关于加强工业互联网

平台安全建设的建议”进行答复


为深入宣传工业和信息化部2021年全国两会建议提案办理工作成果，工业和信息化部政务新媒体“工信微报”特开设“复文选编”栏目，陆续编发部分建议提案复文案例。

消息来源：https://mp.weixin.qq.com/s/ac90X_2VLC5P7PWnomQdIg





03


知名科技公司员工卖了10万条

客户信息，被判近四年 处罚金30万元


表面上是科技公司数据分析师，背地里却非法贩卖平台客户信息。近日，上海市普陀区检察院办理了一起侵犯公民个人信息案，被告人陈某犯侵犯公民个人信息罪被法院判处有期徒刑三年七个月，并处罚金30万元。

消息来源：https://www.secrss.com/articles/36023








04


江苏省无锡市警方破获特大侵犯

公民信息案，数据高达54亿多条！


近日，江苏省无锡市警方成功破获了一起侵犯公民个人信息案，犯罪嫌疑人非法获取各类公民信息，数据累计高达54亿多条，并通过非法网络平台以查询、出售等方式牟利。

消息来源：https://mp.weixin.qq.com/s/-3OEWqtPm4N9q2mrKtWxMg



# 国外资讯 #




01


700万美元诈骗，美司法部判处

俄罗斯男子十年监禁


11月10日，美国司法部发布了一则消息，判处一名俄罗斯男子十年有期徒刑、没收其财产，罪名是电信诈骗罪、共谋电信诈骗罪、洗钱罪、共谋洗钱罪。该俄罗斯男子Zhukov及其同谋从美国广告相关行业公司诈骗了至少700万美元。

消息来源：https://zhuanlan.kanxue.com/article-16919.htm





02


黑客窃取美国警方监控录像，

400万份档案永久丢失


近日，黑客组织分享了美国警方 1.9TB 的数据，其中包括警用直升机在德克萨斯州达拉斯和佐治亚州亚特兰大及其周边地区拍摄的 600 小时空中监控录像。目前，德克萨斯州和佐治亚州的执法机构被窃取的视频已被 DDoSecret 泄露到网上。

消息来源：https://www.secrss.com/articles/35996






03


研究人员发现手机间谍

恶意软件间谍韩国公民


一项正在进行的移动间谍软件活动被发现，利用一个由23个恶意Android应用程序组成的家庭窥探韩国居民，以窃取敏感信息并获取设备的远程控制。Zimperium研究员Aazim Yaswant说："由于有一千多名韩国受害者，这场入侵运动背后的恶意组织已经能够访问他们设备上的所有数据、通信和服务。"受害者正在向恶意行为者广播他们的私人信息，没有迹象表明出了什么问题。

消息来源：https://thehackernews.com/2021/11/researchers-discover-phonespy-malware.html





04


伊朗的 Lyceum 黑客瞄准了

以色列、沙特阿拉伯和非洲的电信、ISP


最新调查结果显示，一名据称与伊朗有联系的国家赞助的威胁行为者与针对以色列、摩洛哥、突尼斯和沙特阿拉伯的互联网服务提供商（ISP）和电信运营商以及非洲外交部（MFA）的一系列有针对性的袭击有关。

消息来源：https://thehackernews.com/2021/11/irans-lyceum-hackers-target-telecoms.html


# 威胁情报 #




01


国家漏洞库CNNVD：

关于Palo Alto Networks GlobalProtect

安全漏洞的预警


近日，国家信息安全漏洞库（CNNVD）收到关于Palo Alto Networks GlobalProtect安全漏洞（CNNVD-202111-988、CVE-2021-3064）情况的报送。成功利用漏洞的攻击者，可以绕过身份验证破坏目标系统进程，并在目标系统实现远程代码执行。PAN-OS 8.1.17以下版本均受此漏洞影响。目前，Palo AltoNetworks官方已经发布了版本更新修复了该漏洞，建议用户及时确认产品版本，尽快采取修补措施。

消息来源：https://www.secrss.com/articles/35986





02


Apache httpd Server

CVE-2021-40438 漏洞分析


Apache官方发布了Apache httpd mod_proxy SSRF漏洞CVE-2021-40438，影响v2.4.48及以下版本。该漏洞影响范围较广，危害较大，利用简单，不得不引起重视。

消息来源：https://www.anquanke.com/post/id/257657





03


CVE-2021-43616详细信息


npm ci 命令在 npm 7.x 和 8.x 到 8.1.3 进行安装， 即使包裹锁. json 中的依赖信息与包裹. json 不同。此行为与文档不一致，使攻击者更容易安装恶意软件，而恶意软件本应被封装锁中确切版本匹配要求所阻止。

消息来源：https://nvd.nist.gov/vuln/detail/CVE-2021-43616





04


CVE-2021-41653详细信息


TP-Link TL-WR840N EU v5 路由器上的 PING 功能通过 TL-WR840N（EU）_V5_171211具有固件，通过 IP 地址输入字段中精心制作的有效载荷易受远程代码执行的影响。

消息来源：https://nvd.nist.gov/vuln/detail/CVE-2021-41653
