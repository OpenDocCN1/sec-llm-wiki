**Apache Portable Runtime 越界读取漏洞**

  

**01****漏洞描述**

  

由于其 apr\_time\_exp\*() 函数中存在越界数组读取问题，具有写访问权限的本地用户可对数据库使用这些函数导致进程崩溃或拒绝服务。

  

**02****漏洞信息**

  

漏洞名称：Apache Portable Runtime 越界读取漏洞

  

漏洞类型：代码问题

  

危害等级：高危

  

漏洞编号：CVE-2021-35940

  

厂商：Apache

  

发布时间：2021-08-23

  

**03影响版本**

  

Apache Portable Runtime = 1.7.0

  

**04修复建议**

  

厂商已发布修复漏洞补丁，请用户尽快更新至安全版本
