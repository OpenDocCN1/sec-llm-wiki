查看moc文件夹，分析编译器都给我们生成了什么

定义了一个结构体

qt\_meta\_stringdata\_QtClass\_t

  

*   
*   

```
struct qt_meta_stringdata_QtClass_t {     QByteArrayData data[6];     char stringdata0[31];};
```

  

后面创建了一个结构体静态变量里面存放一些类、参数、函数名等信息。这个第一个参数应该是ID，字符串的开始位置，字符串size
