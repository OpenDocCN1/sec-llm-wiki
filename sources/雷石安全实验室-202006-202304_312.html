漏 洞 报 送






 
漏洞描述
XXL-JOB API 接口未授权访问致反序列化漏洞。XXL-JOB是一个轻量级分布式任务调度平台。默认情况下XXL-JOB的API接口没有配置认证措施，未授权的攻击者可构造恶意请求，触发反序列化，造成远程执行命令，直接控制服务器。漏洞利用无需登录。

漏洞详情
漏洞等级：高危

影响版本
XXL-JOB <= 2.2.0

修复建议
增加授权验证，配置 xxl.job.accessToken 防止未授权访问漏洞。
