 **漏洞描述**近日 SonicWall Network Security Appliance (NSA) 设备上的操作系统 SonicOS存在CVE-2020-5135远程命令执行漏洞。SonicWall NSA 设备用作防火墙和 SSL VPN门户，用于过滤、控制并使员工访问内部和非公开网络。安全研究员表示，用于处理自定义协议的一个 SonicOS组件中存在一个 bug。该组件暴露在 WAN 接口，意味着只要发现该设备的 IP 地址，任意攻击者皆可利用该 bug。  
**漏洞详情**漏洞编号: CVE-2020-5135漏洞等级：高危
