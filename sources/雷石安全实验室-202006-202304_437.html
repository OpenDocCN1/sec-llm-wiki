运行使用




在docker仓库已经打包好2个扫描器，分别是awvs13和nessus，供广大兄弟们使用。





docker命令：


#pull 拉取下载镜像


docker pull leishianquan/awvs-nessus:v2


#启动


docker run -it -d -p 13443:3443 -p 8834:8834 leishianquan/awvs-nessus:v2


需要注意的是访问Nessus需要进入容器启动Nessus 服务：


#查看容器


Docker ps –a


#启动容器

Docker start 容器id


#进入容器


Docker exec –it 容器id /bin/bash


#启动nessus服务


/etc/init.d/nessusd start
