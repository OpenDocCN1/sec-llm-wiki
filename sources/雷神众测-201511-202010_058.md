**演讲人：奇安信盘古石取证实验室 卢瑀涛**

**议题：《那些可用作木马的 Android 漏洞》**

在当今仍然“不健全”的 Android 生态环境里，恶意 Android 木马仍然是个影响广大用户的棘手问题，终端上个人信息泄露和资产流失的新闻也频出不穷。而且，当今恶意木马的攻击技术也愈发复杂。未知攻焉知防，此次议题将为给大家分享几个能用作编写 Android 木马的通用漏洞，从而提升大家对于高级 Android 木马方面的安全意识。

  

  

![](../Images/87c89099297214315fdc92f81f56e517.png)

  

  

  

  

**演讲人：360未来安全研究院 李均**

**议题：《攻击智能汽车的N种方法》**

在智能汽车越来越普及的今天，越来越多的汽车厂家为汽车加入了各种各样网络连接，Wifi、蓝牙、蜂窝网等，这些连接在为汽车带来如远程控制、OTA升级等新功能的同时也将汽车暴露在了网络攻击的威胁之下。来自360未来安全研究院的研究员李均将通过介绍智能汽车潜在的攻击入口，并提供分析几个汽车攻击的典型案例，来讨论一些应对攻击的方法和技巧。在议题的最后更是邀请对智能汽车感兴趣的极客们一同前往云栖科技博悟馆对智能汽车进行安全研究

  

  

![](../Images/7847a2c2b5a0f19d275b7f0d0e69e110.png)

  

  

  

  

**演讲人：安恒水滴实验室 吕盟**

**议题：《对SQL Server CLR在红队行动中利用的探索》**

因为数据库服务的特殊性，数据库在红队行动中的价值较高。议题简要分析了常规的利用手法，然后介绍了SQL Server CLR的特点，并展示了几种通过CLR实现的利用手法。目的为了抛砖引玉，希望能与大家共同探讨。

  

  

![](../Images/727bc41b47b7a0008019d602a1d2f3b2.png)

  

  

  

  

**演讲人：奇安信奇物实验室 郑鑫**

**议题：《深入浅出IoT安全》**

如今物联网设备越来越走近人们的生活，IOT安全也变成了我们不得不关注且越来越重要的问题，此次议题将给大家介绍如何从零开始研究物联网IOT安全，分别从硬件层面、代码层面、通信层面和云服务层面来分析几款设备，通过真实的案例来讲解IoT中常见的攻击手法。
