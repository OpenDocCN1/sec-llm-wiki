1.VMware vRealize Operations Manager安全漏洞


漏洞介绍：

2020年5月8日，VMware官方发布了VMware vRealize Operations Manager (vROps)7.5.0、8.0.x、8.1.0版本存在身份验证绕过和目录遍历漏洞的严重安全漏洞公告，对应CVE编号：CVE-2020-11651、CVE-2020-11652，该漏洞来源于SaltStack的Salt，已确认VMware vRealize Operations Manager同样受到影响。


漏洞危害：

根据公告，VMware vRealize Operations Manager 7.5以上版本引入的应用程序远程收集器（ARC）受SaltStack的Salt漏洞影响，也存在该漏洞，恶意攻击者可以通过访问ARC上4505或4506的端口发起攻击请求，以控制ARC和ARC已部署Telegraf agent的任何虚拟机，建议使用该系统的用户及时关注漏洞修复补丁版本或采取缓解措施加固系统。


漏洞编号：

CVE-2020-11651

CVE-2020-11652


影响范围：

VMware vRealize Operations Manager (vROps) 7.5.0
VMware vRealize Operations Manager (vROps) 8.0.x（包含8.0.0、8.0.1）VMware vRealize Operations Manager (vROps) 8.1.0


修复方案：

高危：VMware vRealize Operations Manager漏洞修复补丁版本待发布，由于SaltStack已经发布补丁，恶意攻击者可能通过SaltStack补丁对比分析漏洞触发点进而开发漏洞利用代码，建议使用该系统的用户尽快采取临时缓解措施加固系统。


缓解措施：

暴露在互联网上未打补丁的系统容易遭到攻击，建议限制其端口的暴露，默认端口：
TCP 4505、TCP 4506
可以通过ARC内置的iptables实现阻断访问该端口，命令参考：
iptables -I DOCKER 1 -p tcp --dport 4505 -j DROP
iptables -I DOCKER 1 -p tcp --dport 4506 -j DROP注意：此解决方法不是永久性的，如果重启ARC，它将恢复为默认值，同时此方案仅限于ARC 7.5.0、8.0.0、8.0.1、8.1版本，不适用于VMware其他产品。


来源：安恒信息应急响应中心

2.vBulletin5 _=5.6.1 SQL注入漏洞


漏洞介绍：
近期，安恒Zionlab团队通过监控发现vBulletin官网于2020年05月07日发布了最新5.6.1版本安全补丁。产品更新说明提示修复一处安全漏洞，经过补丁对比发现官方疑似修复一处前台SQL注入漏洞。


漏洞危害：
未经授权的用户可以通过SQL注入获取敏感数据。


影响范围：

vBulletin 5.5.6pl1之前版本
vBulletin 5.6.0pl1之前的5.6.0版本
vBulletin 5.6.1pl1之前的5.6.1版本vBulletin表示，“如果你正在使用 5.5.2 之前的 vBuletin 5 版本，则应尽快更新


修复建议：

及时测试并更新到漏洞修复的版本


来源：CNVD

3.通达OA 11.4版本存在SQL注入漏洞


漏洞介绍：

通达OA（Office Anywhere网络智能办公系统）是由北京通达信科科技有限公司自主研发的协同办公自动化软件，是与中国企业管理实践相结合形成的综合管理办公平台。


漏洞危害：

通达OA 11.4版本存在SQL注入漏洞，远程攻击者可利用该漏洞匿名获取数据库敏感信息。


影响范围：

北京通达信科科技有限公司 通达OA 11.4


修复建议：

及时测试并更新到漏洞修复的版本或升级版本


来源：CNVD
