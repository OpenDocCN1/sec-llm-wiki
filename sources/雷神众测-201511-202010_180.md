***改造Gadget***

思考几个东西：  
1.要选择兼容JDK版本的gadget。  
2.最先开始知道是采用commons-collections:4.0作为gadget，但是shiro自带的commons-collections:3.2.1，所以需要进行改造。如果想让tomcat+shiro这个环境下本地命令执行，需要满足利用链上没有出现数组类型的对象。  
基于上述原因开始改造计划，首先先回顾一下commons-collections:4.0这个利用链。

   ObjectInputStream.readObject()  
           PriorityQueue.readObject()  
               ...  
                   TransformingComparator.compare()  
                       InvokerTransformer.transform()  
                           Method.invoke()  
                               Runtime.exec()  

本质原因在于commons-collections2这个利用链中 TransformingComparator 实现了 Serializable 序列化接口，也就是说这个对象是被序列化的。

![](../Images/5d7d5f3ecbd8ae8e3728166bdb9fb7e7.png)

 而我们再看看commons-collections5这个利用链，这里用的 ChainedTransformer 。 

ObjectInputStream.readObject()         BadAttributeValueExpException.readObject()

                               Method.invoke()  
                                   Runtime.getRuntime()  
                           InvokerTransformer.transform()

而 ChainedTransformer 他的 iTransformers 是数组类型 Transformers ，不符合我们的要求。 

![](../Images/0df22034373feb81a2c0268744b11960.png)

也就是说这里需要做个组合，反正目的很清楚，需要从InvokerTransformer.transform()->TemplatesImpl.newTransformer()，然后利用 TemplatesImpl.newTransformer 中的 loadClass 来动态加载我们的恶意class。  
关注一下这里，首先传入 Object 对象，通过 getMethod 处理 iMethodName ，假设这里的 iMethodName 是 newTransformer 。那么经过下面的反射处理，是可以到 TemplatesImpl.newTransformer 中。

![](../Images/e115e066fba8d6c9c66685c678668171.png)

当然从commons-collections5开始，出现了一种叫做TiedMapEntry的利用方法，使用 LazyMap.get()函数，所以这里实际上 Key 和 map 都是可控的。 

![](../Images/917160f54d1f8161f7ce1fab95869d0a.png)

LazyMap.get调用了transform函数，并将可控的key传入transform函数。

![](../Images/f1c577876cb17ae2f185a8f9fe05ba61.png)

Spring+tomcat+shiro  
理论上这种方法应该是可以在spring中通用的，实际测试起来不一样。spring是this.createSubject(request, response)中处理cookies等流程，在AbstractShiroFilter.this.executeChain(request, response, chain);中进入processRequest(HttpServletRequest request, HttpServletResponse response)。

![](../Images/d85f891c864cd7d53e57bc3d428d4e82.png)

   "field.setAccessible(true);\\n" +  
  "field.set((Object) fd,(Object) new Integer(3));\\n" +  
   "java.io.FileOutputStream os = new java.io.FileOutputStream(fd);\\n" +
