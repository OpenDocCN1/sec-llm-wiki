No.1

漏洞描述

问题列表Open Source Social Network(OSSN)5.3及之前版本中存在安全漏洞。攻击者可通过对SiteKey实施暴力破解攻击来为components/OssnComments/ossn_com.php,libraries/ossn.lib.upgrade.php插入特制的URL利用该漏洞读取任意文件

No.2

环境搭建

通过git命令下载OSSN环境：
git clone https://github.com/kevthehermit/CVE-2020-10560
使用docker一键搭载OSSN环境：
docker-compose up --build

当通过docker拉取创建镜像结束后会出现下图，表示已经搭建完成。 

通过访问127.0.0.1就可以进入管理界面（要是想要通过burpsuite抓包不能通过使用127.0.0.1搭建，否则会出现重定向错误，最好将环境搭载到vps上）。 

在点击下一步后，需要填写信息，注意一下内容填写：
• DB: ossn
• username: ossn
• password: ossn 

•host: mysqlserver

No.3

漏洞验证

由于我们是在本地搭建环境，那么我们可以不需要通过爆破方式获取site_key的值，只需要查询数据库中的表ossn_site_settings里面名字为site_key的值即可，通过下图可以看出我们查询出的site_key的值为578ad434。

通过使用我们从github上下载的poc进行漏洞利用，依次填写site_key的值、文件名以及目标站点，发现成功读取到文件内容。 

      当然正常网站的site_key我们没有办法得知，只能通过暴力破解的方式进行，根据发现该漏洞作者描述，现在仍需要13个小时左右爆破出site_key的值。 

No.4

漏洞分析

想要利用此漏洞，则需要知道site_key的值，那么我们来分析下site_key的值究竟是怎么来的。
      从我们已经获取到的site_key值可以知道加密的site_key的长度只有8个字符，不是一个长密钥。通过分析代码可以找到创建唯一site_key的函数：

function ossn_generate_site_secret() {

       return substr(md5('ossn' . rand()), 3, 8); 

通过分析该函数我们可以得出以下5点结论：
      1. 以字符串“ ossn ”开头。
      2. 用PHP rand（）计算一个随机数。
      3. 将数字附加到第一个字符串。
      4. 计算此新字符串的md5哈希值。
      5. 将字符4-11用作site_key。
    在php7或更高版本中使用rand（），最大可能值为2,147,483,647。即为2亿次左右的可能。作者通过使用c语言代替python，将采用4个线程，将时间缩短为原来的1/4。

void start_generators(long max_value, int thread_count) {

   pthread_t threads[thread_count];
   struct generator_args args[thread_count];

   while (max_value % thread_count != 0) {
       max_value++;
   }

   for (int i = 0; i < thread_count; i++) {
       args[i].max = (max_value / thread_count) * (i + 1);
       args[i].min = (max_value / thread_count) * i;

       if (args[i].min > 0) {
           args[i].min++;
       }

       pthread_create(&threads[i], NULL, attempt_generator, &args[i]);
   }

   for (int i = 0; i < thread_count; i++) {
       pthread_join(threads[i], NULL);
   }
}
