***No.1  
***

***漏洞描述***

问题列表Open Source Social Network(OSSN)5.3及之前版本中存在安全漏洞。攻击者可通过对SiteKey实施暴力破解攻击来为components/OssnComments/ossn\_com.php,libraries/ossn.lib.upgrade.php插入特制的URL利用该漏洞读取任意文件

***

通过git命令下载OSSN环境：  
git clone https://github.com/kevthehermit/CVE-2020-10560  
使用docker一键搭载OSSN环境：  
docker-compose up --build

***No.3  
***

***漏洞验证***

由于我们是在本地搭建环境，那么我们可以不需要通过爆破方式获取site\_key的值，只需要查询数据库中的表ossn\_site\_settings里面名字为site\_key的值即可，通过下图可以看出我们查询出的site\_key的值为578ad434。  

![](../Images/a665e3fdd469bf1a56c499e2b6382cd5.png)

通过使用我们从github上下载的poc进行漏洞利用，依次填写site\_key的值、文件名以及目标站点，发现成功读取到文件内容。 

![](../Images/df57cf26120a0a54235de2b8a67a560a.png)

      当然正常网站的site\_key我们没有办法得知，只能通过暴力破解的方式进行，根据发现该漏洞作者描述，现在仍需要13个小时左右爆破出site\_key的值。 

***No.4  
***

***漏洞分析***

想要利用此漏洞，则需要知道site\_key的值，那么我们来分析下site\_key的值究竟是怎么来的。  
      从我们已经获取到的site\_key值可以知道加密的site\_key的长度只有8个字符，不是一个长密钥。通过分析代码可以找到创建唯一site\_key的函数：  

function ossn\_generate\_site\_secret() {  

       return substr(md5('ossn' . rand()), 3, 8); 

通过分析该函数我们可以得出以下5点结论：  
      1. 以字符串“ ossn ”开头。  
      2. 用PHP rand（）计算一个随机数。  
      3. 将数字附加到第一个字符串。  
      4. 计算此新字符串的md5哈希值。  
      5. 将字符4-11用作site\_key。  
    在php7或更高版本中使用rand（），最大可能值为2,147,483,647。即为2亿次左右的可能。作者通过使用c语言代替python，将采用4个线程，将时间缩短为原来的1/4。  

void start\_generators(long max\_value, int thread\_count) {

   pthread\_t threads\[thread\_count\];  
   struct generator\_args args\[thread\_count\];  
  
   while (max\_value % thread\_count != 0) {  
       max\_value++;  
   }  
  
   for (int i = 0; i < thread\_count; i++) {  
       args\[i\].max = (max\_value / thread\_count) \* (i + 1);  
       args\[i\].min = (max\_value / thread\_count) \* i;  
  
       if (args\[i\].min > 0) {  
           args\[i\].min++;  
       }  
  
       pthread\_create(&threads\[i\], NULL, attempt\_generator, &args\[i\]);  
   }  
  
   for (int i = 0; i < thread\_count; i++) {  
       pthread\_join(threads\[i\], NULL);  
   }  
}
