看不懂代码没事，看注释,
就是获取操作方法和标签,然后判断module是否存在。

写个demo验证下:

<?php
// 本类由系统自动生成，仅供测试用途
class IndexAction extends Action {
   public function index(){
       header("Content-Type:text/html; charset=utf-8");
       echo 'hello world<br/>';
   }

   protected function _initialize(){
       echo "_initializ被调用了,相当于php的构造函数:__construct,我是控制器,我被调用了!<br/>";
   }

   public function _before_index(){
       echo "我会在index方法之前执行,被自动调用执行<br/>";
   }

   public function _after_index(){
       echo "我会在index方法执行之后,被自动调用执行<br/>";
   }

   public function test(){
       header("Content-Type:text/html; charset=utf-8");
       echo "测试";
   }
}

会发现在index方法执行前先执行了_before_index()然后是方法内容最后是_after_index()

No.3

总结

$module=m=C层 $action=a=类中的方法
那么整个的底层流程是这样的:
http://localhost/thinkphp3/ThinkPHP/Tpl/index.php/Index/index
当我在url中输入这个url地址访问的时候,thinkphp会自动加载这几个文件
分别是:

CORE_PATH.'Core/Think.class.php',
       CORE_PATH.'Core/ThinkException.class.php', // 异常处理类
       CORE_PATH.'Core/Behavior.class.php'

然后要对url地址上的url进行调度处理,加载Dispatcher.class.php类文件
dispatch方法就是用于分析地址栏中输入的参数，根据地址栏中的参数分析出类名和方法名。
最后调用App.class.php类,进行对$module的实例化,然后调用$action就是前面的方法index
