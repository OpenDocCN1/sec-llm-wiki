四种扫描类型用法

XSStrike共有四种测试模式，下面我分别介绍一下：

演示环境我用的是dvwa，使用docker只需两条命令即可部署完成。

docker pull citizenstig/dvwa
docker run -d -p 8088:80 citizenstig/dvwa

scan模式（常用模式）

python xsstrike.py -u http://127.0.0.1:8088/vulnerabilities/xss_r/index.php?name=1

需要cookie才能访问的页面需要自己添加header头信息。我搭建的环境是dvwa，需要添加header头才能正常测试xss。实测使用 --headers参数添加并不理想，我会打开config.py文件，通过修改里面的headers列表，添加cookies头和referers头信息来实现登录扫描。配置修改处如下图所示：XSStrike/core/config.py

代码分析

可配置性高

许多需要自定义的如header头信息，payload，fuzz需要的字符、参数，http代理等，均可在core/config.py下自行配置。

fuzz模式

流程：导入url->检测waf->逐个参数进行fuzz测试
在fuzz模式中，xsstrike会通过函数wafDetector()首先检测web站点是否存在waf。简单说就是通过比对触发waf的返回包中是否存在一些waf的特定文本特征来确定。
waf特征存储在XSStrike/db/wafSignatures.json。（使用的是与sqlmap相同的识别库。）
随后，会对每个传入的参数逐一进行fuzz测试，函数名为fuzzer()，下面贴一下代码。

def fuzzer(url, params, headers, GET, delay, timeout, WAF, encoding):
for fuzz in fuzzes:
if delay == 0:
delay = 0
t = delay + randint(delay, delay * 2) + counter(fuzz)
sleep(t)
try:
if encoding:
fuzz = encoding(unquote(fuzz))
data = replaceValue(params, xsschecker, fuzz, copy.deepcopy)
response = requester(url, data, headers, GET, delay/2, timeout)
except:
logger.error('WAF is dropping suspicious requests.')
if delay == 0:
logger.info('Delay has been increased to %s6%s seconds.' % (green, end))
delay += 6
limit = (delay + 1) * 50
timer = -1
while timer < limit:
logger.info('\rFuzzing will continue after %s%i%s seconds.\t\t\r' % (green, limit, end))
limit -= 1
sleep(1)
try:
requester(url, params, headers, GET, 0, 10)
logger.good('Pheww! Looks like sleeping for %s%i%s seconds worked!' % (
green, ((delay + 1) * 2), end))
except:
logger.error('\nLooks like WAF has blocked our IP Address. Sorry!')
break
if encoding:
fuzz = encoding(fuzz)
if fuzz.lower() in response.text.lower(): # if fuzz string is reflected in the response
result = ('%s[passed] %s' % (green, end))
# if the server returned an error (Maybe WAF blocked it)
elif str(response.status_code)[:1] != '2':
result = ('%s[blocked] %s' % (red, end))
else: # if the fuzz string was not reflected in the response completely
result = ('%s[filtered]%s' % (yellow, end))
logger.info('%s %s' % (result, fuzz))

其中第二行的fuzzes列表，也是在config.py中存在且可自行配置的，默认为以下列表：

scan模式

流程：dom型xss检测->获取参数->检测是否存在waf->逐一参数进行xss检测
dom型xss检测
如果命令行没有传入 --skip-dom参数，则传入dom()函数检测是否有dom型xss。
dom函数会分析传入的http返回包，首先通过正则提取页面内在标签<script></script>中的内容，然后用正则逐行去匹配可能触发dom型xss的js语句。正则语句如下：

sources = r'''document\.(URL|documentURI|URLUnencoded|baseURI|cookie|referrer)|location\.(href|search|hash|pathname)|window\.name|history\.(pushState|replaceState)(local|session)Storage'''
sinks = r'''eval|evaluate|execCommand|assign|navigate|getResponseHeaderopen|showModalDialog|Function|set(Timeout|Interval|Immediate)|execScript|crypto.generateCRMFRequest|ScriptElement\.(src|text|textContent|innerText)|.*?\.onEventName|document\.(write|writeln)|.*?\.innerHTML|Range\.createContextualFragment|(document|window)\.location'''

source：匹配可以由外部（不受信任）源控制的输入。
sink：匹配可能导致dom型xss漏洞的潜在危险方法。
可能是过滤html返回包里的特殊字符的部分没写好，dom检测实测并不是很理想～一些xss测试站点如*https://brutelogic.com.br/dom/sinks.html?name=KNOXSS*中的dom类型xss，xsstrike的dom型xss检测并没有检测出来。~~太菜了没分析出来~~
*获取参数*
如果命令行有 --params 参数，则还会arjun()函数通过正则匹配页面内存在的input标签，并提取出input标签内name属性的值，加入到blindParams列表内，尝试去发现更多的参数。blindParams列表在core/config.py内。

检测是否存在waf
通过wafDetector，与fuzz模式中一致。
逐一参数进行xss检测
xsstrike会通过函数htmlParser()判断传入的字符是否在页面中回显，并按照字符的位置分为在js代码内、html标签内、html普通文本内三种。
随后，使用filterChecker()函数测试站点对特殊字符的过滤情况。在filterchecker()函数中，会根据回显所在的位置生成不同的测试字符。如在js代码中，则会生成测试字符的集合{'>', '</scRipT/>', '<', "'"}，并逐个测试字符传入checker()函数中进行测试。在checker()函数中，函数使用了FuzzyWuzzy库中的fuzz.partial_ratio()函数去计算得出每个测试字符在页面中回显的准确度。
最后，根据每个测试字符的回显位置，通过generator()做前期处理，最后通过genGen()生成合适的payload。使用checker()函数获取结果并返回给命令窗口。

def checker(url, params, headers, GET, delay, payload, positions, timeout, encoding):
checkString = 'st4r7s' + payload + '3nd' #拼接payload
if encoding:
checkString = encoding(unquote(checkString))
response = requester(url, replaceValue( #得到执行payload后的返回包
params, xsschecker, checkString, copy.deepcopy), headers, GET, delay, timeout).text.lower()
reflectedPositions = []#payload回显的位置
for match in re.finditer('st4r7s', response):
reflectedPositions.append(match.start())
filledPositions = fillHoles(positions, reflectedPositions)
# Itretating over the reflections
num = 0
efficiencies = []
for position in filledPositions:#检测传入payload前后两次的回显情况并打分。取最高值
allEfficiencies = []
try:
reflected = response[reflectedPositions[num]
:reflectedPositions[num]+len(checkString)]
efficiency = fuzz.partial_ratio(reflected, checkString.lower())#使用fuzzywuzzy的partial_ratio函数判断回显值与payload的相似度
allEfficiencies.append(efficiency)
except IndexError:
pass
if position:
reflected = response[position:position+len(checkString)]
if encoding:
checkString = encoding(checkString.lower())
efficiency = fuzz.partial_ratio(reflected, checkString)#使用fuzzywuzzy的partial_ratio函数判断回显值与payload的相似度
if reflected[:-2] == ('\\%s' % checkString.replace('st4r7s', '').replace('3nd', '')):
efficiency = 90
allEfficiencies.append(efficiency)
efficiencies.append(max(allEfficiencies))#取最大值
else:
efficiencies.append(0)
num += 1
return list(filter(None, efficiencies))#返回一个payload准确度

bruteforce模式

流程：导入url->识别http方法和参数类型->载入payload->测试参数
如果命令行传入 -f 或者 --file则触发暴力穷举模式。通过 -f user_payload.txt还可载入自定义的payload列表。通过bruteforcer()函数，识别传入的http方法和参数的数据类型，随后导入payload列表，逐一对参数进行测试。bruteforcer函数具体代码如下：

def bruteforcer(target, paramData, payloadList, encoding, headers, delay, timeout):

crawl模式

流程：导入url->检测js版本漏洞->dom型xss检测->抓取有效链接->获取表单->测试表单参数
如果命令行传入 --crawl，则触发爬虫模式。通过photon()函数，检测dom型xss，retireJS()检测是否有js库版本漏洞，之后通过正则r'<[aA].*href=["\']{0,1}(.*?)["\']'匹配页面内的链接，并剔除后缀为'.pdf', '.png', '.jpg', '.jpeg', '.xls', '.xml', '.docx', '.doc'的页面。通过zetanize()匹配页面内的form表单，提取出action、method、name、type、value属性并形成一个集合。具体代码如下：

import re

def zetanize(response):#reponse为http返回包的内容
def e(string):
return string.encode('utf-8')

def d(string):
return string.decode('utf-8')

# remove the content between html comments
response = re.sub(r'(?s)<!--.*?-->', '', response)
forms = {}
matches = re.findall(r'(?i)(?s)<form.*?</form.*?>',
response) # extract all the forms
num = 0
for match in matches: # everything else is self explanatory if you know regex
page = re.search(r'(?i)action=[\'"](.*?)[\'"]', match)
method = re.search(r'(?i)method=[\'"](.*?)[\'"]', match)
forms[num] = {}
forms[num]['action'] = d(e(page.group(1))) if page else ''
forms[num]['method'] = d(
e(method.group(1)).lower()) if method else 'get'
forms[num]['inputs'] = []
inputs = re.findall(r'(?i)(?s)<input.*?>', response)
for inp in inputs:
inpName = re.search(r'(?i)name=[\'"](.*?)[\'"]', inp)
if inpName:
inpType = re.search(r'(?i)type=[\'"](.*?)[\'"]', inp)
inpValue = re.search(r'(?i)value=[\'"](.*?)[\'"]', inp)
inpName = d(e(inpName.group(1)))
inpType = d(e(inpType.group(1)))if inpType else ''
inpValue = d(e(inpValue.group(1))) if inpValue else ''
if inpType.lower() == 'submit' and inpValue == '':
inpValue = 'Submit Query'
inpDict = {
'name': inpName,
'type': inpType,
'value': inpValue
}
forms[num]['inputs'].append(inpDict)
num += 1
return forms

随后，通过crawl()函数对每个form表单、疑似dom型xss的url进行验证。
