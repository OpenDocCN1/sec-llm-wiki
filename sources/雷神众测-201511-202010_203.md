**1.通达OA高危漏洞**

  

漏洞介绍：

安恒应急响应中心对补丁进行了分析，结合论坛用户的反馈，发现勒索病毒可能通过文件上传漏洞植入，测试在11.3的版本中通过文件上传漏洞结合文件包含接口，恶意攻击者可以成功上传Webshell后门，并进一步释放勒索病毒，进程默认由System权限启动，危害较大。  

漏洞危害：

根据分析，在11.3的版本中通过文件上传漏洞结合文件包含接口，恶意攻击者可以成功上传Webshell后门。

  

影响范围：

2013版、2013增强版、2015版、2016版、2017版、V11版本

  

修复方案：

及时测试更新补丁，并做好数据备份。  

来源：安恒信息应急响应中心

**2.cPanel任意代码执行漏洞**  

  

漏洞介绍：  
cPanel是美国cPanel公司的一套基于Web的主机控制管理系统。

  

漏洞危害：  
攻击者可执行任意代码。

  

影响范围：

CVE-2020-10119：cPanel cPanel <84.0.20  
攻击者可使用演示帐户通过cpsrvd rsync shell利用该漏洞实现远程代码执行。

CVE-2020-10115：cPanel cPanel <84.0.20  
在使用PowerDNS情况下存在任意代码执行漏洞。攻击者可通过dnsadmin利用该漏洞以root用户身份执行任意代码。

  

修复建议：

更新对应补丁  

  

来源：CNVD

**3.****Microsoft IIS服务器篡改漏洞**

  

漏洞介绍：  
Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。IIS Server是其中的一个IIS（互联网信息服务）服务器。

  

漏洞危害：  
Microsoft Windows IIS Server中存在安全漏洞，该漏洞源于程序未能正确地处理格式错误的请求标头。攻击者可通过发送格式错误的HTTP请求利用该漏洞篡改返回给客户端的响应。

  

漏洞编号：

CVE-2020-0645

  

影响范围：  

Microsoft Windows Server 2008 SP2  
Microsoft Windows 7 SP1  
Microsoft Windows Windows Server 2012  
Microsoft Windows 8.1  
Microsoft Windows RT 8.1 SP0  
Microsoft Windows Server 2012 R2  
Microsoft Windows 10  
Microsoft Windows 10 1607  
Microsoft Windows Server 2016  
Microsoft Windows Server 2008 R2 SP1  
Microsoft Windows Server 1803  
Microsoft Windows Server 2019  
Microsoft Windows Server 1903  
Microsoft Windows 10 1709  
Microsoft Windows 10 1803  
Microsoft Windows 10 1809  
Microsoft Windows 10 1903  
Microsoft Windows Server 1909  
Microsoft Windows 10 1909

  

修复建议：  
更新对应补丁 

  

来源：CNVD

**4\. VMware Workstation Virtual Printer权限提升漏洞**

  

漏洞介绍：  
VMware Workstation是VMware公司推出的一款桌面虚拟计算软件。

  

漏洞危害：

VMware Workstation中的Virtual Printer模块存在安全漏洞，该漏洞源于在加载用户提交的共享文件之前，程序没有对该路径进行验证。攻击者可利用该漏洞提升权限并执行代码。

  

漏洞编号：

CVE-2020-3948

  

影响范围：  

VMware Workstation

  

修复建议：  
更新对应补丁

  

来源：CNVD
