**1.Microsoft Exchange远程代码执行漏洞**

  

**漏洞介绍：**

该漏洞是由于Exchange Control Panel(ECP)组件中使用了静态秘钥（validationKey和decryptionKey）所导致的。

  

**影响危害：**

ECP应用程序是以SYSTEM权限运行的，因而成功利用此漏洞的攻击者可以以SYSTEM身份执行任意代码，并完全控制目标Exchange服务器。

  

**影响范围：**

Microsoft Exchange Server 2010 Service Pack 3 Update Rollup 30  
Microsoft Exchange Server 2013 Cumulative Update 23  
Microsoft Exchange Server 2016 Cumulative Update 14  
Microsoft Exchange Server 2016 Cumulative Update 15  
Microsoft Exchange Server 2019 Cumulative Update 3  
Microsoft Exchange Server 2019 Cumulative Update 4

  

**漏洞编号：**

CVE-2020-0688

  

**修复方案：**

更新对应补丁

  

来源：360CERT

**2.Wi-Fi流量信息泄漏漏洞**

  

**漏洞介绍：**

网络安全研究员从使用广泛的博通 (Broadcom) 和 Cypress WiFi 芯片中发现了一个硬件漏洞，影响数十亿台设备，如智能手机、平板电脑、笔记本电脑、路由器和物联网设备。

  

**影响危害：**

该漏洞被称为 “Kr00k”，编号为 CVE-2019-15126，它可导致远程攻击者拦截并解密易受攻击设备通过无线传输的某些无线网络数据包。该漏洞产生的原因在于博通和 Cypress 芯片使用了一个全零加密密钥，从而导致数据被解密，破坏了 WPA2-Personal 和 WPA2-Enterprise 安全协议。攻击者无需连接到受害者的无线网络即可发动攻击。使用 WPA2-Personal 或 WPA2-Enterprise 协议、通过 AES-CCMP 加密保护网络流量的设备易受攻击。

  

**影响范围：**

broadcom bcm4356  
broadcom bcm4389  
broadcom bcm4375  
broadcom bcm43012  
broadcom bcm43013  
broadcom bcm43752  
Amazon Echo 2nd gen  
Amazon Kindle 8th gen  
Apple iPad mini 2 (ipad\_os < 13.2)  
Apple iPhone 6, 6S, 8, XR (iphone\_os < 13.2)  
Apple MacBook Air Retina 13-inch 2018 (mac\_os < 10.15.1)  
Google Nexus 5  
Google Nexus 6  
Google Nexus 6S  
Raspberry Pi 3  
Samsung Galaxy S4 GT-I9505  
Samsung Galaxy S8  
Xiaomi Redmi 3S  
Asus RT-N12  
Huawei B612S-25d  
Huawei EchoLife HG8245H  
Huawei E5577Cs-321

  

**漏洞编号：**

CVE-2019-15126

  

**修复方案：**

更新对应补丁或升级版本。

  

来源：venustech

**3. Microsoft Windows Remote Desktop Client代码执行漏洞**

**漏洞介绍：**

Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。

  

**影响危害：**

Microsoft Windows Remote Desktop Client存在代码执行漏洞，攻击者可利用该漏洞在客户端上执行任意代码。

  

**影响范围：**

Microsoft Windows Remote Desktop Client

  

**漏洞编号：**

CVE-2020-0817

  

**修复方案：**

升级至最新版本

  

来源：CNVD

**4.Symantec Critical System Protection (CSP)身份验证绕过漏洞  **

  

**漏洞介绍：**

Symantec Critical System Protection（CSP）是美国赛门铁克（Symantec）公司的一套关键系统保护安全软件。该软件包括病毒查杀、入侵检测和防火墙等功能。

  

**影响危害：**

Symantec CSP 8.0版本、8.0 HF1版本和8.0 MP1版本中存在身份验证绕过漏洞。攻击者可利用该漏洞绕过身份验证控制。

  

**影响范围：**

Symantec Critical System Protection (CSP) 8.0  
Symantec Critical System Protection (CSP) 8.0 HF1  
Symantec Critical System Protection (CSP) 8.0 MP1

  

**漏洞编号：**

CVE-2019-18374

  

**修复方案：**

更新对应补丁

  

来源：CNVD

**5.****VMware vRealize Operations for Horizon Adapter高危安全漏洞**

  

**漏洞介绍：**

vRealize Operations for Horizon Adapter启用的JMX RMI服务（默认端口有3091、3099、3101、3100等）不安全配置，可能导致恶意攻击者未经身份验证的远程访问并提交攻击代码，成功利用该漏洞后获取到目标系统的管理权限。

  

**影响危害：**

攻击者可以通过补丁对比方式逆向分析漏洞触发点和开发利用代码，存在远程代码执行漏洞、身份验证绕过和信息泄露漏洞。

  

**影响范围：**

CVE-2020-3943、CVE-2020-3944、CVE-2020-3945漏洞影响以下版本：

vRealize Operations for Horizon Adapter 6.6.0

vRealize Operations for Horizon Adapter 6.7.0

  

建议更新到漏洞修复的6.6.1和6.7.1以上版本：

vRealize Operations for Horizon Adapter 6.6.1

vRealize Operations for Horizon Adapter 6.7.1

  

**漏洞编号：**

CVE-2020-3943

CVE-2020-3944

CVE-2020-3945

  

**修复方案：**

建议及时测试并升级到漏洞修复的版本，或采取临时缓解措施加固系统。

  

来源：安恒信息应急响应中心
