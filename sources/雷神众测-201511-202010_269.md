***漏洞详情***

**1\. Bash权限提升漏洞**

  

**漏洞介绍：**

Bash是美国布莱恩-福克斯（Brian J. Fox）软件开发者的一款为GNU计划而编写的、运行于类Unix操作系统中的Shell（命令语言解释器）。它能够从标准输入设备或文件中读取、执行命令。

  

**影响危害：**

Bash 5.0 patch 11及之前版本中的shell.c文件的disable\_priv\_mode存在安全漏洞。攻击者可利用该漏洞获取权限。

  

**影响范围：**

Bash Bash 5.0 Patch 11

  

**漏洞编号：**

CVE-2019-18276

  

**修复方案：**

使用最新版本

  

来源：CNVD

**2.SUSE Mailman权限提升漏洞**

  

**漏洞介绍：**

SUSE Mailman是一套免费的用于管理电子邮件讨论和电子邮件列表的软件。该软件可与Web项目集成，使用户方便管理邮件订阅帐号，并提供内置归档、自动转发处理、内容过滤和反垃圾过滤器等功能。

  

**影响危害：**

SUSE Mailman中存在安全漏洞。攻击者可利用该漏洞从wwwrun权限提升至root权限。

  

**影响范围：**

SUSE SUSE Linux Enterprise Debuginfo 11-SP4  
SUSE SUSE Linux Enterprise Debuginfo 11-SP3  
SUSE SUSE Linux Enterprise Server 11-SP4-LTSS  
SUSE SUSE Linux Enterprise Point 11-SP3

  

**漏洞编号：**

CVE-2019-3693

  

**修复方案：**

更新至最新版本

  

来源：CNVD

**3.Symantec Industrial Control System Protection未经授权访问漏洞**

  

**漏洞介绍：**

Symantec Industrial Control System Protection (ICSP)该产品为工业控制系统和关键基础设施提供多维安全性。

  

**影响危害：**

Symantec Industrial Control System Protection (ICSP) 6.x.x版本中存在安全漏洞。攻击者可利用该漏洞无需相应的权限便可创建或修改应用程序用户账户容。

  

**影响范围：**

Symantec Industrial Control System Protection (ICSP) 6.x.x

  

**漏洞编号：**

CVE-2019-18380

  

**修复方案：**

更新至最新版本。

  

来源：CNVD

**4.phpMyAdmin SQL注入漏洞**

**漏洞介绍：**

phpMyAdmin是phpMyAdmin团队的一套免费的、基于Web的MySQL数据库管理工具。该工具能够创建和删除数据库，创建、删除、修改数据库表，执行SQL脚本命令等。

  

**影响危害：**

phpMyAdmin 4.9.2之前版本中存在SQL注入漏洞。该漏洞源于基于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令。

  

**影响范围：**

phpMyAdmin phpMyAdmin <4.9.2

  

**漏洞编号：**

CVE-2019-18622

  

**修复方案：**

更新至最新版本

  

来源：CNVD

**5\. Gitlab多个安全漏洞**

  

**漏洞介绍：**

Omnibus GitLab是美国GitLab公司的一款打包运行GitLab所需的不同服务和工具的软件包。

  

**影响危害：**

GitLab Omnibus GitLab 7.4版本至12.2.1版本中存在提权漏洞，攻击者可利用该漏洞提升权限。  
GitLab Omnibus GitLab EE 11.3及更高版本存在路径遍历和潜在的远程执行代码，在某些情况下，Maven程序包注册表的参数清理不足可能导致特权提升和远程执行代码漏洞

  

**影响范围：**

CVE-2019-15741：  
GitLab Omnibus GitLab >=7.4，<=12.2.1  
  
CVE-2019-19628：  
GitLab EE 11.3及更高版本

  

**漏洞编号：**

CVE-2019-19628  
CVE-2019-15741

  

**修复方案：**

更新至最新版本

  

来源：CNVD、Gitlab
