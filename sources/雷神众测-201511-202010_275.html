漏洞详情

1. Microsoft Excel 2016 1901 – XXE漏洞 


漏洞介绍：

如果用户选择“导入为”，则来自文件功能的Excel查询很容易受到基于“错误”的XML外部实体的攻击。在导入特制XML文件时收到错误时显示“ HTML页面”功能。这可能导致潜在的远程数据泄露，需要用户交互才能利用此漏洞。


影响危害：


影响范围：

Excel 2016 v1901


漏洞编号：


修复方案：

使用最新版本或不随意点开不信任的excel文件


来源：exploit-db

2.Microsoft Windows Media Center 2002 - XML External Entity MotW 绕过


漏洞介绍：

Windows Media Center是由Microsoft创建的已停产的数字视频录像机和媒体播放器。
Media Center于2002年在Windows XP Media Center上首次引入Windows。


影响危害：

这是一个完全正常的远程信息泄露漏洞，仍然会影响Windows 7。


影响范围：

Microsoft Windows Media Center。


漏洞编号：


修复方案：

不再使用Microsoft Windows Media Center


来源：exploit-db

3. Django管理员中的权限提升


漏洞介绍：

2.1.15之前的Django 2.1和2.2.8之前的2.2允许进行意外的模型编辑。显示内联相关模型的Django模型管理员将获得一个编辑UI，该用户可以访问父级模型，但对内联模型具有编辑权限，该用户可以通过POST请求来更新内联模型。无法直接编辑仅查看的父模型，但是调用了父模型的save（）方法，这会触发潜在的副作用。


影响危害：



影响范围：

·        Django主分支

·        Django 3.0

·        Django 2.2

·        Django 2.1


漏洞编号：

CVE-2019-19118


修复方案：

更新至最新版本


来源：seclists

4.趋势科技服务器深度安全防护系统客户端agent 11任意文件覆盖漏洞


漏洞介绍：

该漏洞允许无特权的本地攻击者删除文件系统上的任何文件，或使用其他位置托管的机密数据覆盖该文件（有限制）。
即使启用了自我保护。仍可以对其进行修改/简化以简单地删除目标文件。


影响危害：



影响范围：

趋势科技服务器深度安全防护系统客户端agent 11


漏洞编号：

CVE-2019-15627


修复方案：

更新至最新版本
