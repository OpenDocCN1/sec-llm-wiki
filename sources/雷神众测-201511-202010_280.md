***漏洞详情***

**1\. Apache Cordova InAppBrowser权限提升漏洞（Android） **

  

**漏洞介绍：**

在Android上的InAppBrowser Web视图中运行的网站可以执行在主应用程序的webview中使用特殊的任意JavaScript精制的gap-iab：URI。

  

**影响危害：**

  

**影响范围：**

使用InAppBrowser的Cordova Android应用程序（cordova-plugin-inappbrowser版本3.0.0及以下）

  

**漏洞编号：**

CVE-2019-0219

  

**修复方案：**

安装3.1.0或更高版本的cordova-plugin-inappbrowser

  

来源：www.seclists.org

**2.WordPress插件Google Review Slider 'tid' SQL注入漏洞**

  

**漏洞介绍：**

WordPress是基于PHP语言开发的博客平台，可以用于在支持PHP和MySQL数据库的服务器上架设网站，也可当做一个内容管理系统（CMS）。

  

**影响危害：**

WordPress插件Google Review Slider 'tid'存在SQL注入漏洞，该漏洞源于数据库的应用缺少对外部输入SQL语句的验证。攻击者可利用该漏洞执行非法SQL命令

  

**影响范围：**

WordPress Google Review Slider 6.1

  

**漏洞编号：**

CVE-2019-10070

  

**修复方案：**

更新至最新版本

  

来源：CNVD

**3\. Microsoft Windows Hyper-V远程代码执行漏洞（CVE-2019-0719）**

  

**漏洞介绍：**

Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。Windows Hyper-V是其中的一个虚拟化产品，支持在Windows中创建虚拟机。

  

**影响危害：**

Microsoft Windows Hyper-V存在远程代码执行漏洞，攻击者可借助特制的应用程序利用该漏洞在主机操作系统上执行任意代码。

  

**影响范围：**

Microsoft Windows Server 2008 R2 SP1

Microsoft Windows Server 2008 SP2

Microsoft Windows 7 SP1

Microsoft Windows Windows Server 2012

Microsoft Windows 8.1

Microsoft Windows Server 2012 R2

Microsoft Windows 10

Microsoft Windows 10 1607

Microsoft Windows Server 2016

Microsoft Windows Server 1803

Microsoft Windows Server 2019

Microsoft Windows Server 1903

Microsoft Windows 10 1709

Microsoft Windows 10 1803

Microsoft Windows 10 1809

Microsoft Windows 10 1903。

  

**漏洞编号：**

CVE-2019-0719

  

**修复方案：**

厂商已发布了漏洞修复程序，请及时关注更新

  

来源：CNVD
