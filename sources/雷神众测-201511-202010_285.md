***漏洞详情***

**1\. Symantec Endpoint Protection代码执行漏洞  **

  

**漏洞介绍：**

Symantec Endpoint Protection是美国赛门铁克（Symantec）公司的一套防病毒软件。该软件可跨物理和虚拟系统提供安全防护功能。

  

**影响危害：**

Symantec Endpoint Protection (SEP) 14.2 RU2之前版本中存在安全漏洞。攻击者可利用该漏洞执行未被签名的代码。

  

**影响范围：**

Symantec Symantec Endpoint Protection <14.2 RU2

  

**修复方案：**

目前厂商已发布升级补丁以修复漏洞

  

来源：CNNVD

**2\. Apache Shiro Cookie脆弱漏洞**

  

**漏洞介绍：**

Apache Shiro是一个强大且易用的Java安全框架,用于执行身份验证、授权、密码和会话管理。  

  

**影响危害：**

Apache Shiro 1.4.2之前的版本使用默认的“RememberMe”，配置时，cookie可能会受到填充攻击。

  

**影响范围：**

Apache Shiro <1.4.2

  

**漏洞编号：**

CVE-2019-12422

  

**修复方案：**

厂商已发布了漏洞修复程序

  

来源：www.seclists.org

**3\. Apache Atlas存储型XSS漏洞**

  

**漏洞介绍：**

在搜索功能中发现Apache Atlas UI易受存储的XSS。

  

**影响范围：**

Apache Atlas版本0.8.3、1.1.0

  

**漏洞编号：**

CVE-2019-10070

  

**修复方案：**

用户应升级到Apache Atlas的0.8.4或1.2.0或更高版本

  

来源：www.seclists.org

**4\. Piwik 跨站脚本漏洞**

  

**漏洞介绍：**

Piwik是一款基于PHP和MySQL的开源网络分析应用程序。

  

**影响危害：**

Piwik 1.10.1之前版本中存在跨站脚本漏洞。该漏洞源于WEB应用缺少对客户端数据的正确验证。攻击者可利用该漏洞执行客户端代码。

  

**影响范围：**

Piwik 1.10.1之前。

  

**漏洞编号：**

CVE-2013-0195

  

**修复方案：**

目前厂商已发布升级补丁以修复漏洞，详情请关注厂商主页

  

来源：CNNVD

**5\. Cisco Email Security Appliance AsyncOS Software 输入验证错误漏洞**

  

**漏洞介绍：**

Cisco Email Security Appliance（ESA）是美国思科（Cisco）公司的一个电子邮件安全设备。AsyncOS Software是运行在其中的一套操作系统。

  

**影响危害：**

Cisco ESA中的AsyncOS Software 13.0之前版本的MP3检测引擎存在输入验证错误漏洞，该漏洞源于程序没有正确验证MP3文件类型。远程攻击者可借助特制的MP3文件利用该漏洞绕过所配置的内容过滤器。

  

**影响范围：**

Cisco ESA中的AsyncOS Software 13.0之前版本

  

**漏洞编号：**

CVE-2019-15971

  

**修复方案：**

目前厂商已发布升级补丁以修复漏洞

  

来源：CNNVD
