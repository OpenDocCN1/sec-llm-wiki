# 北京时间 DEF CON China

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI0NzEwOTM0MA==&mid=2652470039&idx=1&sn=12715872b16eeaa92f378dfbad97a6a9&chksm=f258d8a4c52f51b25f5fda5d158c9255ce24a2556607df6e714ccdcddd343a1f378a91932360&scene=126&sessionid=1681371988#rd](http://mp.weixin.qq.com/s?__biz=MzI0NzEwOTM0MA==&mid=2652470039&idx=1&sn=12715872b16eeaa92f378dfbad97a6a9&chksm=f258d8a4c52f51b25f5fda5d158c9255ce24a2556607df6e714ccdcddd343a1f378a91932360&scene=126&sessionid=1681371988#rd)

从公元1992年开始，世界各地的黑客们对于DEF CON的热情一直持续至今，每年7月，在美国拉斯维加斯举办的黑客大会，成了黑客们盛大的秘密派对。然而今年5月，DEF CON正式登陆中国，携手百度安全，召集全球安全领域研究者，遇见北京，御·见未来。

**DEF CON China**

![](../Images/dfdda086bb0670e54661479f612ed45e.png)

  

虽然距离DCCB闭幕已有些时日，但各大公众号对于DEF CON China的回味以及剖析似乎并不会就此消散半分。

  

![](../Images/30a55b48aa6e1b1bcb047a694776d5c2.png)

  

所以，DEF CON到底是什么？

我翻遍了搜索引擎，也找不出一个适合它的形容词。

  

![](../Images/48ce46e020321a429fc75b0f2f4324f3.png)

  

它是在极客圈犹如麦加圣地一样的存在，是安全界的奥斯卡和世界杯，是全世界的黑客，是探索，是热爱。

  

想起百度安全的老大马杰手握话筒激动地说道：

DEF CON用了26年时间，走过了十个时区，才来到了中国。

  

**而此刻，是属于DEF CON的中国时间。**

![](../Images/1b3c04a9c2e1aeb832b6b937d9e96875.png)

兴趣所致，热情所往，于是我坐了6个小时的火车，翻山越岭，不远千里奔赴北京，以Humans的身份第一次与DEF CON进行亲密接触。

  

三天，是充满期待的三天。

踏入会场的一刹那，站在硕大的场地中央，我被震撼到无法踱步，酷炫的会场，轻松的氛围，满眼的歪果仁，让人仿若置身中国的拉斯维加斯。

  

![](../Images/a4c54a634eea360d3d0c61c424962aad.png)![](../Images/92307c96edf0e935552cd0cbe03d36e8.png)

  

拿到白色胸牌的时候，宣传册上雷神众测logo显得格外亲切。

  

![](../Images/8338fef2215f5e9c5545c40c54356eb7.png)

  

电梯缓缓上升，愈发心生错乱，像是在做梦一般，想到即将捕捉一大波野生极客，心情一路飙升。就像开了一架喷气机，扑哧扑哧。

  

![](../Images/f857eac1acf75b84efbfc78b8395d834.png)![](../Images/503bcaab66bbbdd950a1b6951b10b9ce.png)![](../Images/90d45867f40b9b02aa972d27ae437588.png)

  

开幕首日，议题现场就被挤得水泄不通。手握同声传译器却无法进入主会场的失落，在进入Hacking Village时瞬间消散。

  

![](../Images/1e8f0e6e9815db335f05db8f20fcf52e.png)![](../Images/216427941518c8baccfea7505b41dc92.png)![](../Images/c0b98fb90c1b5ccf1a0fa819fb47ca2b.png)![](../Images/7ca36d2d084d9dda0772d677565ca9ee.png)

  

第一次亲临现场，目睹一场席地而坐的正经全球会议，我站在门口愣了很久，才敢哧溜钻进去。可能是喊了一千次的“各部门注意”，现场却意外地充满了轻松愉快的气氛，不严肃，并且十分亲近。

  

![](../Images/2157c4aed7d5f914f9dac9ee9c0d74ad.png)![](../Images/e3dfb4e28653aa90c73758036a1a3067.png)

  

原来黑客们也都是普通人。

  

这种意外之喜就像飘了很久的泡泡被猛地戳破一样清脆。

  

从各大安全公司、各大应急响应中心的展位，到百度特制的自动贩卖机，再到BCTF现场，每一个Room似乎都是让人无法轻易挪步的。

  

三天，三天怎么够？

聚集众人的展位和现场动感的音乐，以及一言不合就互加微信的陌生人，仿佛自己是来放松周末的。

  

![](../Images/22a28641a974336b3138f54f17167910.png)![](../Images/d613719d811b43dadc8b03328416008e.png)

这大概就是传说中的运营小姐姐们吧

  

![](../Images/d9721e989538d13b157c92a18e170327.png)

▲

巨大的百度的logo也显得格外醒目，AI的未来被百度安全带到了现场。

  

![](../Images/e0e23011697b675427747a45106baa92.png)![](../Images/7a12951622dc419bf53e713c776dbc61.png)

▲

黑客们坐在贩卖机旁，势必要靠破译而喝到可乐的决心，拳击游戏，和被围观的街机，黑客们对一切事物都充满了好奇心。

  

![](../Images/9f80e4bcca7a9dfdc5cd55320134631d.png)![](../Images/795208bc0f312d6503cc593e0af7d22a.png)![](../Images/e321e2e77c64d619e00e63f1b40e26e2.png)

▲

BCTF黑客攻防比赛以及破解悬赏赛的现场，引得众黑客纷纷前往，一显身手。嗡嗡作响的硬盘，仿佛置身战场，一触即发。

![](../Images/3826c37bb44cab9ed6c0c22ede321d3c.png)

人，才是最大的漏洞。

![](../Images/bd4807b21d859bebc630479fff032719.png)

  

但更吸引我的，驱使我的，似乎是DEF CON的传统项目，Hacking Village。

  

不论是晶片数据分析Village（Chip-Off Village），生物特征识别Village（Biometrics Identification Village），硬件Village（Hardware Hacking Village），还是开锁Village（Lockpick Village），数据封包Village（Packet Hacking Village），都令人兴致盎然。

  

  

  

  

  

  

  

  

  

![](../Images/347841cf611df4f341a81ed08ca9a9d3.png)![](../Images/8973123ebc268f535f8a8e529c503589.png)![](../Images/1b4589c1f1936e9c0c92d07bffcea87e.png)![](../Images/37aa08e1127083bd4bd5c34fc02eb6c3.png)

  

不知为什么，我对开锁好像有一种特殊的执念。在潜心开了几把锁之后（/嘻😝），在Lockpick Village的现场，我偶遇了一位13岁的小黑客，只身前往DEF CON。

  

![](../Images/095c405f6181acc37765141f9c14cd70.png)

  

![](../Images/046b56b38543cb4274ddeb9e7825f4a3.png)![](../Images/e9b2f2994ca6387a361470e2b5c25286.png)![](../Images/b2ad7278530cffd5a53a2689ae6a0cb4.png)

  

13岁，13岁的时候我在干嘛？

  

想起Jeff Moss说的：

我在圣诞节的时候得到了我的第一台电脑，不到一年时间，街上所有的小伙伴都有了游戏机或计算机，我们相互到家中去玩，并且学会了分享。

十三岁的时候，我既不能开车，也不能投票，也没达到喝酒的法定年龄，但是在那个时候我却可以同来自俄罗斯、加拿大以及墨西哥的朋友进行相互交流。

也正是从那时候开始，我了解到一个人想法的力量有多大。我学会了评判一个人的标准，不是你的长相、性别，也不是宗教信仰，而是你的所做所为以及你的想法。

  

![](../Images/848d008805967de6af61a178b3e9e5e5.png)![](../Images/7834d4b38122997752b6d3bd3356a91d.png)![](../Images/e2fd05d876f0eb8ecad3f5620d6c52d8.png)![](../Images/1ccf2674e90174077b2bdbfe2a1af7b5.png)![](../Images/3826c37bb44cab9ed6c0c22ede321d3c.png)

人，才是最复杂的锁，也是最万能的钥匙。

![](../Images/bd4807b21d859bebc630479fff032719.png)

  

![](../Images/0c998ea2facaea4b6865514776547d3d.png)![](../Images/afcec6fb3f2054993852bf65d8a16384.png)

  

令我心心念念的，还是硬件Village的电焊设备，暗中观察了几日，终于得空坐下，体验焊电路板的乐趣所在。满怀欣喜，幸好学有所归。

  

![](../Images/86580d6c7b182d7058deb8447cbcd97b.png)![](../Images/ffaba4230d4f5d23a1dbc9a55e96845c.png)![](../Images/4abbe60eaddd6c82399cfc53f717074b.png)![](../Images/a95acdc66915fc0610e2017951317ba6.png)

  

硬件的世界总是令人满怀憧憬。

  

![](../Images/bcd7c08353c007d7a84adec97be78bc3.png)![](../Images/bc791f29e343bafbc849d046dbf04154.png)

  

其间，分会场的议题，我也有认真去听、去学习、去理解。即使是带着各地口音的英语，即使是只过了四六级的poor English，也努力尝试融入演讲者的情境。

  

![](../Images/2648f6d045c8eeb80cdbcfce1cbc721f.png)![](../Images/113efe1730070d32fd1c8203addb78b0.png)![](../Images/42c559e1d6c436f044ed04d4ca8156c0.png)

  

一想到，这里，可都是全球最顶级的黑客啊，就越发勇敢积极。

  

还有行走的大菠萝，WIFI仙人掌，酷炫之余，技术感满满。

![](../Images/c8cd92e12db5598018fc67babb431277.png)![](../Images/450d5494b3c134079fa9c84abaecf126.png)

  

唯一的遗憾大概就是未能参加属于黑客的LIVE MUSIC，据说现场很嗨。

  

![](../Images/2a9065b97b97df9581a982aa1153c05f.png)

  

// 尔尔。

  

持续了三天的热情，让我想起Jeff Moss所说：

有人问DEF CON是什么，我想说，这是探索，是寻找个人的力量，是回到生活的细节，是忠于内心，享受自己的过程。

  

![](../Images/b9893f5ce139ad316d47058ef8f7d5ac.png)

  

我想大概全世界的黑客都是一样的，一样的不甘平凡，一样的不断探索，一样的不屈于循规蹈矩安于现状。全世界的黑客都拥有一样的默契。

  

这些，都是我这三天以来亲眼所见的，是身边切切实实的黑客们所传达给我的。

  

感谢DEF CON的馈赠。

  

![](../Images/6deff50266a42834726ae64bd4dac708.png)![](../Images/cb9d0699a3322e820987b3806faf54bb.png)

  

有人说：

爱是奔赴，是相见和拥抱，不是浮云为寄，见字如面。当你还囿于山高水远道阻且长，有人已经披星戴月地去见他了。

  

![](../Images/3826c37bb44cab9ed6c0c22ede321d3c.png)

因为**热爱**，所以翻山越岭，马不停蹄。

![](../Images/bd4807b21d859bebc630479fff032719.png)

  

想要跻身世界，想要与千千万万的黑客一起站在这里，想要和一千个不同的自己face to face，想要成为独一无二的我。

  

在这里，我遇见的每个人都是我。

  

这就是我们的，**黑客精神**。
