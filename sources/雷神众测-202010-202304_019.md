关于KeePass

KeePass 是一款免费的开源密码管理器，可帮助您以安全的方式管理您的密码。您可以将所有密码存储在一个数据库中，该数据库由一把万能钥匙锁定。因此，您只需记住一个主密钥即可解锁整个数据库。数据库文件使用目前已知的最佳和最安全的加密算法（AES-256、ChaCha20 和 Twofish）进行加密。

![](../Images/b730b04fd0b0e139eb693398319b0ae6.png)

漏洞概述

对 KeePass 配置文件具有写入权限的攻击者可以修改它并注入恶意触发器，例如通过添加导出触发器来获取明文密码。

![](../Images/b730b04fd0b0e139eb693398319b0ae6.png)

利用前提

对 KeePass 配置文件具有写入权限。

![](../Images/b730b04fd0b0e139eb693398319b0ae6.png)

复现环境

KeePass：2.46  
OS:Ubuntu 20.04 LTS x64  
WEB：Apache2

![](../Images/b730b04fd0b0e139eb693398319b0ae6.png)

触发器值的设定

触发器示例：

https://keepass.info/help/kb/trigger\_examples.html

```












Name: name
```

  

![](../Images/b730b04fd0b0e139eb693398319b0ae6.png)

漏洞复现

打开KeePass 配置文件：KeePass.config.xml，并写入相应的触发器代码

![](../Images/e3994d6d05c4f1aeaa5019646e67c8b8.png)

触发器参考代码如下：

```






































<TriggerSystem>
```

在服务器启动web服务，并使用tcpdump抓包（可以根据个人喜好获取数据包，生成的exploit.xml也是保存有明文密码的）。

![](../Images/3aa5279d822e8c00b0f4f5b0b0ac08f1.png)

打开KeePass，生成一个密码并保存。

![](../Images/5a50fe395af3979b2c12961d14167ac3.png)

将服务器抓取到的数据包打开，可以获得带有base64加密密文的数据包。

![](../Images/60e306310fc6db64b3eeee66c839fb69.png)

将数据包解密，就能得到KeePass保存的密码。

![](../Images/825475c1ce6c3497c366bacf9ee9300d.png)

  

![](../Images/b730b04fd0b0e139eb693398319b0ae6.png)
