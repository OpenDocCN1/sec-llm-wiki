1. Apache CouchDB 远程代码执行漏洞


漏洞介绍：

CouchDB 是一个开源的面向文档的数据库管理系统，可以通过 RESTful JavaScript Object Notation (JSON) API 访问。


漏洞危害：

由于CouchDB的默认安装配置存在缺陷，未授权的远程攻击者可以通过访问特定端口，绕过权限验证并获得管理员权限，最终接管服务器。


漏洞编号：

CVE-2022-24706


影响范围：

Apache CouchDB < 3.2.2


修复方案：

及时测试并升级到最新版本或升级版本


来源：360CERT


2.用友U8-OA企业版存在SQL注入漏洞


漏洞介绍：

用友网络科技股份有限公司是一家企业云服务与软件提供商。


漏洞危害：

用友U8-OA企业版存在SQL注入漏洞，攻击者可利用该漏洞获取数据库敏感信息。


影响范围：

用友网络科技股份有限公司 用友U8-OA企业版 2.83


修复方案：

及时测试并升级到最新版本


来源：CNVD


3. VMware Workspace ONE Access and Identity Manager远程代码执行漏洞


漏洞介绍：

Vmware Workspace One Access是美国Vmware公司的将用户身份与设备和网络信息等因素结合起来，为 Workspace One 交付的应用程序制定智能驱动的条件访问决策。


漏洞危害：

VMware Workspace ONE Access and Identity Manager存在远程代码执行漏洞，该漏洞源于服务器端模板注入漏洞，攻击者可利用该漏洞通过网络访问Web界面以VMware用户身份执行任意shell命令。


漏洞编号：

CVE-2022-22954


影响范围：

VMware Workspace ONE Access (Access) >=20.10.0.0，<=20.10.0.1

VMware Workspace ONE Access (Access) >=21.08.0.0，<=21.08.0.1

VMware Identity Manager (vIDM) >=3.3.3，<=3.3.6


修复建议：

及时测试并升级到最新版本或升级版本


来源：CNVD


4.Google Android权限提升漏洞


漏洞介绍：

Google Android是美国谷歌（Google）公司的一套以Linux为基础的开源操作系统。


漏洞危害：

Google Android存在安全漏洞，此漏洞会影响 Amlogic 组件，攻击者可利用此漏洞升级权限。


漏洞编号：

CVE-2021-39672


影响范围：

Google Android


修复建议：

及时测试并升级到最新版本


来源：chd.edu.cn
