**1\. Microsoft Windows Print Spooler远程代码执行漏洞**

  

漏洞介绍：

Microsoft Windows Print Spooler是美国微软（Microsoft）公司的一个打印后台处理程序组件。

  

漏洞危害：

Microsoft Windows Print Spooler存在远程代码执行漏洞，攻击者可利用该漏洞在系统中运行恶意代码。

  

漏洞编号：

CVE-2021-36936

  

影响范围：

Microsoft Windows Server 2008 R2 SP1

Microsoft Windows Server 2008 SP2

Microsoft Windows 7 SP1

Microsoft Windows 8.1

Microsoft Windows RT 8.1 SP0

Microsoft Windows Server 2012 R2

Microsoft Windows 10 1607

Microsoft Windows Server 2016 null

Microsoft Windows Server 2019

Microsoft Windows 10 1809

Microsoft Windows 10 1909

Microsoft Windows Server 2004

Microsoft Windows 10 2004

Microsoft Windows 10 20H2

Microsoft Windows Server 20H2

Microsoft Windows 10 21H1

Microsoft Windows Server 2012

  

修复方案：

及时测试并升级到最新版本或升级版本

  

来源：CNVD 

  

**2.Tenda G1 and G3命令注入漏洞**

  

漏洞介绍：

Tenda G1 and G3是中国腾达（Tenda）公司的一个路由器。

  

漏洞危害：

Tenda G1 and G3 v15.11.0.17(9502)\_CN存在命令注入漏洞，攻击者可利用该漏洞通IPsecLocalNet 和 IPsecRemoteNet参数执行任意命令。

  

漏洞编号：

CVE-2022-24170

  

影响范围：

Tenda G1 and G3 15.11.0.17(9502)\_CN

  

修复方案：

及时测试并升级到最新版本或升级版本

  

来源：CNVD

  

**3.fastadmin代码问题漏洞**

  

漏洞介绍：

fastadmin是一套基于ThinkPHP和Bootstrap的网站后台开发框架。

  

漏洞危害：

Fastadmin存在安全漏洞，该漏洞源于Fastadmin v1.2.1受到一个文件上传漏洞的影响，该漏洞允许通过shell访问执行任意代码。目前没有详细的漏洞细节提供。

  

漏洞编号：

CVE-2021-43117

  

影响范围：

FastAdmin FastAdmin 1.2.1

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：CNVD

  

**4.向日葵个人版for Windows存在命令执行漏洞**

  

漏洞介绍：

向日葵是一款免费的，集远程控制电脑手机、远程桌面连接、远程开机、远程管理、支持内网穿透的一体化远程控制管理工具软件。

  

漏洞危害：

上海贝锐信息科技股份有限公司向日葵个人版for Windows存在命令执行漏洞，攻击者可利用该漏洞获取服务器控制权。

  

影响范围：

上海贝锐信息科技股份有限公司 向日葵个人版for Windows 11.0.0.33

  

修复建议：

及时测试并升级到最新版本

  

来源：CNVD
