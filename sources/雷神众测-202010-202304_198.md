***漏洞详情***

**1\. Apache DB DdlUtils代码问题漏洞**

漏洞介绍：

Apache DB DdlUtils是美国阿帕奇（Apache）基金会的一个易于使用的小型组件，用于处理数据库定义 (DDL) 文件。

  

漏洞危害：

Apache DB DdlUtils 1.0存在代码问题漏洞，该漏洞源于BinaryObjectsHelper类不安全，使用 ObjectInputStream.readObject 时未能验证输入数据是否可以安全地反序列化。攻击者可以利用漏洞造成远程代码执行。

  

漏洞编号：

CVE-2021-41616

  

影响范围：

Apache Apache DB DdlUtils 1.0

  

修复方案：

及时测试并升级到最新版本

  

来源：CNVD

  

**2\. Apache Storm代码问题漏洞**

  

漏洞介绍：

Apache Storm是一个免费开源的分布式实时计算系统。

  

漏洞危害：

Apache Storm代码问题漏洞。攻击者可利用该漏洞实现远程代码执行。

  

漏洞编号：

CVE-2021-40865

  

影响范围：

Apache Storm >=1.0.0，<1.2.4  
Apache Storm >=2.1.0，<2.1.1  
Apache Storm >=2.2.0，<2.2.1

  

修复方案：

及时测试并升级到最新版本

  

来源：CNVD

  

**3. Adobe Audition任意代码执行漏洞**

  

漏洞介绍：

Adobe Audition是一款音频编辑器和后期制作套件。

  

漏洞危害：

Adobe Audition 14.4及更早版本存在任意代码执行漏洞，攻击者可利用该漏洞执行任意代码 

  

漏洞编号：

CVE-2021-40740

  

影响范围：

Adobe Adobe Audition <=14.4

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：CNVD

  

**4\. MetInfo存在SQL注入漏洞**

  

漏洞介绍：

MetInfo是一款适合企业建站的开源免费CMS建站系统。

  

漏洞危害：

MetInfo存在SQL注入漏洞。攻击者可利用漏洞获取数据库敏感信息。

  

影响范围：

长沙米拓信息技术有限公司 metinfo V7.5.0

  

修复建议：

及时测试并升级到最新版本

  

来源：CNVD
