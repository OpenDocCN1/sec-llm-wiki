**1.Atlassian Confluence远程代码执行漏洞**

  

漏洞介绍：

Atlassian Confluence是Atlassian公司出品的专业的企业知识管理与协同软件，可用于构建企业文库等。

  

漏洞危害：

根据分析Atlassian Confluence存在一个OGNL表达式注入漏洞，该漏洞允许未经身份验证的攻击者构造恶意请求注入OGNL表达式，从而在服务器上执行任意代码，可导致服务器被攻击者控制。

  

影响范围：

Atlassian Confluence Server/Data Center < 6.13.23

Atlassian Confluence Server/Data Center < 7.4.11

Atlassian Confluence Server/Data Center < 7.11.6

Atlassian Confluence Server/Data Center < 7.12.5

Atlassian Confluence Server/Data Center < 7.13.0

  

修复方案：

及时测试并升级到最新版本或升级版本

  

来源: 安恒信息应急响应中心

**2\. Jenkins插件高危漏洞**

  

漏洞介绍：

近日，安恒信息应急响应中心监测到Jenkins发布安全公告，修复了多个Jenkins插件的安全漏洞，其中包括Code Coverage API插件的一个远程代码执行漏洞（CVE-2021-21677）和Nested View插件的一个XML外部实体注入的高危漏洞（CVE-2021-21680），黑客利用以上漏洞可在目标服务器执行任意代码或读取服务器敏感文件。

  

漏洞危害：

CVE-2021-21677：Code Coverage API插件用来集成和发布多种覆盖报告类型，根据分析，该插件1.4.0 及更早版本没有应用JEP-200反序列化保护，攻击者可利用该漏洞进行反序列化攻击，在一定条件下可以在目标服务器上执行任意代码。

  

CVE-2021-21680：Nested View插件是一个广泛应用的Jenkins视图插件，根据分析，该插件在1.20及更早版本存在XML 外部实体 (XXE) 注入漏洞，攻击者可配置视图，让Jenkins解析攻击者构造的恶意XML文件，从而导致服务器敏感文件泄漏。

  

影响范围：

Code Coverage API插件 < 1.4.1

Nested View 插件 < 1.21

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：安恒信息应急响应中心

**3\. Apache Dubbo多个高危漏洞**  

  

漏洞介绍：

Apache Dubbo是一款应用广泛的Java RPC分布式服务框架。

  

漏洞危害：

CVE-2021-36162 中，Apache Dubbo多处使用了yaml.load，攻击者在控制如ZooKeeper注册中心后可上传恶意配置文件从而造成了Yaml反序列化漏洞。 

  

CVE-2021-36163 中，Apache Dubbo中使用了不安全的Hessian 协议，攻击者可以利用此漏洞触发反序列化，造成远程代码执行漏洞。

  

影响范围：

2.7.0 <= Dubbo <= 2.7.12 

3.0.0 <= Dubbo <= 3.0.1

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：阿里云应急响应

**4\. Microsoft Windows/Windows Server远程代码执行漏洞**

  

漏洞介绍：

Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。

  

漏洞危害：

Microsoft Windows/Windows Server存在远程代码执行漏洞，漏洞源于Jet Database Engine未能正确处理内存中的对象，攻击者可利用该漏洞在受害者系统上执行任意代码。

  

漏洞编号：

CVE-2020-1407

  

影响范围：

Microsoft Windows Server 2008 R2 SP1

Microsoft Windows Server 2008 SP2

Microsoft Windows 7 SP1

Microsoft Windows 8.1

Microsoft Windows RT 8.1 SP0

Microsoft Windows Server 2012 R2

Microsoft Windows 10

Microsoft Windows 10 1607

Microsoft Windows Server 2016

Microsoft Windows Server 2019

Microsoft Microsoft Windows Server 1903

Microsoft Windows 10 1709

Microsoft Windows 10 1803

Microsoft Windows 10 1809

Microsoft Windows 10 1903

Microsoft Microsoft Windows Server 1909

Microsoft Windows 10 1909

Microsoft Windows Server 2004

Microsoft Windows 10 2004

Microsoft Windows Server 2012

  

修复建议：

及时测试并升级到最新版本

  

来源：CNVD
