***漏洞详情***

**1.SonicWall Analytics 远程代码执行漏洞**  

  

漏洞介绍：

SonicWall Analytics是一种强大的情报驱动分析服务，可以解决安全以及网络性能问题，SonicWall Analytics的使用场景多，适配于多种防火墙。

  

漏洞危害：

SonicWall Analytics默认将JDWP接口的调试端口9000暴露，攻击者能够访问该接口，构造特殊的请求造成远程代码执行。

  

漏洞编号：

CVE-2021-20032

  

影响范围：

sonicwall analytics on-prem <= 2.5.2518

  

修复方案：

及时测试并升级到最新版本或升级版本

  

来源: 360CERT

**2\. Fortinet FortiWeb 授权操作系统命令注入漏洞**  

  

漏洞介绍：

Fortinet FortiWeb是一个Web应用程序防火墙（WAF），旨在捕获针对受保护Web应用程序之前的已知和未知的漏洞。

  

漏洞危害：

攻击者首先通过 FortiWeb 设备管理界面的身份验证，然后在 SAML 服务器配置页面的“名称”字段中使用反引号执行命令，这些命令将以底层操作系统的 root 用户身份执行。

  

影响范围：

Fortinet FortiWeb version <= 6.3.11

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：NOSEC

**3\. 泛微OA E-office存在任意文件写入漏洞**  

  

漏洞介绍：

泛微OA E-office是一款专业的办公软件，是面向小型企业或团队的工作平台。

  

漏洞危害：

泛微OA E-office存在任意文件写入漏洞，攻击者可利用该漏洞获取服务器控制权限。

  

影响范围：

上海泛微网络科技股份有限公司 泛微OA E-office V10.0

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：CNVD

**4\. Microsoft Windows/Windows Server远程代码执行漏洞**

  

漏洞介绍：

Microsoft Windows和Microsoft Windows Server都是美国微软（Microsoft）公司的产品。Microsoft Windows是一套个人设备使用的操作系统。Microsoft Windows Server是一套服务器操作系统。

  

漏洞危害：

Microsoft Windows/Windows Server中的Windows Media存在远程代码执行漏洞，攻击者可利用该漏洞实现远程代码执行。

  

漏洞编号：

CVE-2021-33740

  

影响范围：

Microsoft Windows 10

Microsoft Windows Server 2019

Microsoft Windows 10 1809

Microsoft Windows Server 2004

Microsoft Windows 10 2004

  

修复建议：

及时测试并升级到最新版本

  

来源：CNVD
