**1.SonicWall SSL VPN高危安全漏洞**

  

漏洞介绍：  
2020年1月25日，安恒应急响应中心监测到外部安全研究员披露SonicWall SSL VPN历史版本存在远程命令执行漏洞，目前该漏洞的攻击代码已被外部研究员公开。

  

漏洞危害：  
SonicWall SSL VPN使用了旧版的Linux内核和HTTP CGI程序，攻击者可在未授权的情况下访问/cgi-bin/jarrewrite.sh通过构造恶意的HTTP请求头实现远程命令执行，进而控制目标机器。

  

影响范围：  
Sonic SMA < 8.0.0.4

  

修复方案：  
及时测试并升级到最新版本或升级版本

  

来源: 安恒应急响应中心

**2\. IBM WebSphere XXE 漏洞**  

  

漏洞介绍：

IBM WebSphere Application Server（WAS）是由IBM遵照开放标准，例如Java EE、XML及Web Services，开发并发行的一种应用服务器。

  

漏洞危害：

攻击者可构造恶意请求进行XXE攻击，造成文件读取、敏感信息泄漏等。

  

漏洞编号：

CVE-2020-4949

  

影响范围：

IBM WebSphere Application Server 9.0

IBM WebSphere Application Server 8.5

IBM WebSphere Application Server 8.0

IBM WebSphere Application Server 7.0

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：阿里云先知

**3\. Sudo 堆缓冲区溢出致本地提权漏洞**

  

漏洞介绍：

Sudo是一个功能强大的实用程序，大多数基于Unix和Linux的操作系统都包含Sudo。它允许用户使用其他用户的安全特权运行程序。

  

漏洞危害：

任何本地用户（包括普通用户和系统用户，sudoer和非sudoers）若成功利用该漏洞，可在无需密码的情况下获得root权限。

  

漏洞编号：

CVE-2021-3156

  

影响范围：

Sudo 1.9.0 到 1.9.5p1 所有稳定版（默认配置）

Sudo 1.8.2 到 1.8.31p2 所有旧版本（默认配置）

  

修复建议：

及时测试并升级到最新版本或升级版本

  

来源：阿里云先知

**4\. 锐捷⽹关存在未授权访问漏洞**  

  

漏洞介绍：

锐捷⽹络成⽴于2000年1⽉，中国数据通信解决⽅案领导品牌。

  

漏洞危害：

锐捷⽹关存在未授权访问漏洞，攻击者可利⽤该漏洞以root权限在⽬标设备执⾏任意命令。

  

影响范围：

锐捷网络股份有限公司 锐捷NBR路由器

  

修复建议：

及时测试并更新最新补丁

  

来源：CNVD
