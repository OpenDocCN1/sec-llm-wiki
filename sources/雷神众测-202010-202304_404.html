1.Laravel远程代码执行漏洞


漏洞介绍：
Laravel 是一个免费的开源 PHP Web 框架，旨在实现的Web软件的MVC架构。Laravel与Symfony、Zend、CodeIgniter、Yii2 和其他框架一起被视为最受欢迎的 PHP 框架之一。


漏洞危害：
Laravel <= 8.4.2 存在远程代码执行漏洞。当Laravel开启了Debug模式时，攻击者可以发起恶意的请求构造恶意的日志文件，再通过phar协议去访问日志触发php反序列化漏洞，造成命令执行。


影响范围：
Laravel 框架 <= 8.4.2
facade ignition 组件 < 2.5.2


修复方案：
及时测试并升级到最新版本或升级版本


来源: 腾讯安全威胁情报中心

2. Windows Defender RCE漏洞


漏洞介绍：

Windows Defender是微软安全防护软件。


漏洞危害：

攻击者通过构造特殊PE格式的恶意文件，通过钓鱼邮件/链接等方式使受害者获取到该恶意文件，从而触发Microsoft Defender对该文件进行解析，产生缓冲区溢出，最终造成远程代码执行。

3. JumpServer 远程命令执行漏洞


漏洞介绍：

JumpServer 是全球首款完全开源的堡垒机, 使用GNU GPL v2.0 开源协议, 是符合4A 的专业运维审计系统。JumpServer 使用Python / Django 进行开发。


漏洞危害：

JumpServer 是全球首款完全开源的堡垒机, 使用GNU GPL v2.0 开源协议, 是符合4A 的专业运维审计系统。JumpServer 使用Python / Django 进行开发。


影响范围：

JumpServer < v2.6.2

JumpServer < v2.5.4

JumpServer < v2.4.5

JumpServer = v1.5.9


修复建议：

升级 JumpServer 至最新版本。

设置当前产品的控制台登录IP地址白名单限制


来源：NOSEC-安全讯息平台

4. 禅道开源版存在命令执行漏洞

漏洞危害：
