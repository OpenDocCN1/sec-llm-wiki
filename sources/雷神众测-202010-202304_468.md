***漏洞详情***

**1.Windows 网络文件系统远程代码执行漏洞**  
  
漏洞介绍：  
网络文件系统（Network File System，NFS）是一种分布式文件系统，力求客户端主机可以访问服务器端文件，并且其过程与访问本地存储时一样。  
  
漏洞危害：  
未授权的攻击者通过发送恶意的NFS数据包，可以在目标Windows中的网络文件系统（NFSv3）造成内存堆溢出，进而实现远程代码执行。  
  
漏洞编号：  
CVE-2020-17051  
  
影响范围：  
microsoft:windows 10 : \*  
microsoft:windows 7 : \*  
microsoft:windows 8 : \*  
microsoft:windows server 2008 : \*  
microsoft:windows server 2012 : \*  
microsoft:windows server 2016 : \*  
microsoft:windows server 2019 : \*  
  
修复方案：  
及时测试漏洞修复的版本。  
  
来源:360CERT

**2\. 用友U8-OA存在SQL注入漏洞**  
  
漏洞介绍：  
用友创立于1988年，是全球先进的企业与公共组织云服务、软件、金融服务提供商。  
  
漏洞危害：  
用友U8-OA存在SQL注入漏洞，攻击者可利用该漏洞获取数据库敏感信息。  
  
影响范围：  
用友网络科技股份有限公司 用友U8-OA 11.0 企业版  
  
修复建议：  
及时测试并升级到最新版本  
  
来源：CNVD

**3\. QEMU越界访问漏洞**  
  
漏洞介绍：  
QEMU是一套由法布里斯·贝拉(Fabrice Bellard)所编写的、以GPL许可证分发源码的模拟处理器，在GNU/Linux平台上使用广泛。  
  
漏洞危害：  
QEMU 4.2.1中的hw/display/ati\_2d.c中的ati\_2d\_blt存在越界访问漏洞。攻击者可利用该漏洞导致QEMU进程崩溃。  
  
漏洞编号：  
CVE-2020-27616  
  
影响范围：  
Qemu QEMU 4.2.1  
  
修复建议：  
及时测试并升级到漏洞修复的版本。  
  
来源：CNVD

**4\. Microsoft .NET Framework远程代码执行漏洞**  
  
漏洞介绍：  
Microsoft .NET Framework是美国微软（Microsoft）公司的一种全面且一致的编程模型，也是一个用于构建Windows、Windows Store、Windows Phone、Windows Server和Microsoft Azure的应用程序的开发平台。该平台包括C＃和Visual Basic编程语言、公共语言运行库和广泛的类库。  
  
漏洞危害：  
Microsoft .NET Framework中存在远程代码执行漏洞。攻击者可借助特制文件利用该漏洞控制系统。  
  
影响范围：  
Microsoft .NET Framework 2.0 SP2  
Microsoft .NET Framework 3.5  
Microsoft .NET Framework 3.5.1  
Microsoft .NET Framework 4.7.2  
Microsoft .NET Framework 4.8  
  
修复建议：  
及时测试并更新最新补丁  
  
来源：CNVD
