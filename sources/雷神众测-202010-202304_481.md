***漏洞详情***

**1\. 禅道开源版高危漏洞**  
  
漏洞介绍：  
近日，安恒应急响应中心监测发现禅道官网发布了12.4.3版本更新公告，修复了一个文件上传的漏洞，对应CNVD编号：CNVD-C-2020-121325。

  

漏洞危害：  
根据公告，在禅道开源版低于12.4.3版本中存在任意文件读取和任意文件上传漏洞，恶意攻击者（需要登陆后台的任意⽤用户）可以通过该漏洞读取或上传任意文件，成功利用漏洞后可获得目标系统中敏感文件读取和系统管理权限。  
  
漏洞编号：  
CNVD-C-2020-121325

  

影响范围：  
禅道开源版<=12.4.2，建议升级到禅道12.4.3以上版本

  

修复方案：  
及时测试漏洞修复的版本并及时升级

  

来源：安恒信息应急响应中心

**2\. XXL-JOB远程命令执行漏洞**  
  
漏洞介绍：  
近日，安恒应急响应中心监测发现XXL-JOB存在未授权访问导致的远程命令执行漏洞公告。  
  
漏洞危害：  
根据描述，在XXL-JOB 未开启xxl.job.accessToken配置的场景中，恶意攻击者可以通过未授权访问接口实现远程命令执行效果，从而获得目标系统管理权限。

  

影响范围：  
XXL-JOB v2.2.0和之前版本

  

修复建议：  
及时测试并升级到最新版本  
  
来源：安恒信息应急响应中心

**3.致远OA更新安全补丁和高危漏洞**  
  
漏洞介绍：  
近日，安恒应急响应中心监测发现致远OA官方更新了安全补丁，针对致远A8+协同管理软件V8.0 sp1版本注入漏洞、seeyonreport服务器路径遍历漏洞等发布了安全补丁公告。

  

漏洞危害：  
根据描述，此次安全补丁更新修补了致远A8+协同管理软件V8.0 sp1版本存在的注入漏洞；seeyonreport服务器OA（V6.0-7.0）-帆软报表（8.0-9.0）版本存在的路径遍历等漏洞，恶意攻击者可以通过注入漏洞实现任意文件上传效果，和通过路径遍历漏洞获取服务器敏感信息。

  

影响范围：  

致远OA V8.0 SP1任意文件上传漏洞影响以下版本：  
致远A8+协同管理软件V8.0 sp1版本

seeyonreport 服务器路径遍历漏洞影响以下版本：  
(A8、A6) - V6.0补丁包覆盖：OA-V6.0-帆软报表8.0  
(A8、A6)- V6.0sp1补丁包覆盖：OA-V6.0sp1-帆软报表8.0  
(A8、A6、G6)-V6.1补丁包覆盖：OA-V6.1-帆软报表8.0  
(A8、A6)- V7.0补丁包覆盖：OA-V7.0-帆软报表8.0  
(A8、A6)-V7.0补丁包覆盖：OA-V7.0-帆软报表9.0

  
修复建议：  
及时测试并升级到漏洞修复的版本

  

来源：安恒信息应急响应中心

**4.WebLogic Console 权限认证绕过漏洞 ****CVE-2020-14882 补丁绕过**

  
漏洞介绍：  
Oracle 官方在 10 月 20 日发布了重要补丁更新中修复了存在于 WebLogic Console 组件中的两个漏洞 CVE-2020-14882 和 CVE-2020-14883。然而随后长亭科技的安全研究员经过对补丁的分析后，发现其中 CVE-2020-14882 漏洞的补丁并不完善，可以被绕过。

  

漏洞危害：  
其补丁被绕过后，攻击者就可以再度绕过 Console 控制台的权限校验，访问原本需要登录才可以访问的资源和接口功能。

  

漏洞编号：  
CVE-2020-14882

  

影响范围：  
WebLogic Server 10.3.6.0.0  
WebLogic Server 12.1.3.0.0  
WebLogic Server 12.2.1.3.0  
WebLogic Server 12.2.1.4.0  
WebLogic Server 14.1.1.0.0

  

修复建议：  

及时测试并升级到漏洞修复的版本

作为临时缓解方案，可考虑在不影响业务的情况下，对 Console 访问路径进行重命名（将默认的请求路径 console 更改为一个攻击者难以猜解的请求路径），或者禁用 Console

  
来源：长亭安全课堂
