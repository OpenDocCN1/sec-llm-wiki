0x01 工具介绍

Naabu是一个用Go编写的端口扫描工具，它允许您以快速可靠的方式枚举主机的有效端口，可以对主机/主机列表进行快速SYN/CONNECT扫描，并列出所有返回回复的端口。

0x02 安装与使用

1、安装方式
go install -v github.com/projectdiscovery/naabu/v2/cmd/naabu@latest
2、通过-p参数指定要在主机上扫描的端口。
naabu -p 80,443,21-23 -host hackerone.com
3、指定要从扫描中排除的特定端口。
naabu -p - -exclude-ports 80,443
4、以 JSON 行格式保存输出
naabu -host 104.16.99.52 -json{"ip":"104.16.99.52","port":443}{"ip":"104.16.99.52","port":80}
5、指定多个目标地址
naabu -list hosts.txt
