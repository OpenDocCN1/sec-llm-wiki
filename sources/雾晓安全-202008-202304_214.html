0x01 工具介绍

一款基于各大企业信息API的工具，解决在遇到的各种针对国内企业信息收集难题。一键收集控股公司ICP备案、APP、小程序、微信公众号等信息聚合导出。


0x02 安装与使用

  • 首先需要在目录生成config.yaml配置文件

./ENScanPublic_amd64_linux -v

  • 配置信息如下

  version: 0.1 # 请勿修改版本号！  common:  output: ""            # 导出文件位置  field: [ ]# 查询字段 如["website"]  cookies:  aiqicha: ''           # 爱企查   Cookie  tianyancha: ''        # 天眼查   Cookie  qcc: ''               # 企查查   Cookie  aldzs: ''             # 阿拉神灯 Token  xlb: ''               # 小蓝本   Token

  • 快速收集小米相关信息 默认收集：企业基本信息、微博、ICP备案、APP、公众号

./ENScanPublic_amd64_linux -n 小米

  • 导出信息

  • 只想获取备案信息

./ENScanPublic_amd64_linux -n 小米  -field icp
