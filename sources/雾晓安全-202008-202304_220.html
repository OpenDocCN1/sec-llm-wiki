0x01 Oralyzer介绍

一个简单的Python脚本，用于探测网站中的开放重定向漏洞。它通过模糊输入中提供的URL来做到这一点。

0x02 Oralyze安装用法

特征

可以识别以下类型的开放重定向漏洞：

  • 基于标题

  • 基于Javascript

  • 基于元标记

安装

$ git clone https://github.com/r0075h3ll/Oralyzer.git
$ pip3 install -r requirements.txt
