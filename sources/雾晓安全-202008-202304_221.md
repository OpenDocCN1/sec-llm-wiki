**0x01 URLFinder介绍**

URLFinder中JS是用于快速采集检测页面的工具，更注重于抽取链接中的JS和URL链接，抽取状态码的数据更完善且可查看内容大小。基于golang的多秒内出检测结果，创建个链接也秒内出检测。![](../Images/40e5fb6f875cebb602c250a1218d0782.png)

**0x02 URLFinder使用**

### **单url时使用**

```
URLFinder.exe -u http://www.baidu.com -s all -m 2
200,403 -m 2
```

### **网址时使用**

```
URLFinder.exe -s all -m 2 -f url.txt -o d:/
```

### **参数：**

```


-h  帮助信息1  正常抓取（默认），  2

  深入抓取  
```
