### 0x01 WebVpn突破

### 

受到**en0th师傅文章**启发，对学校WebVpn进行了一次SRC漏洞挖掘测试

![](../Images/ac24a54d0434cd1e777d940e2007c343.png)

账号为学号，密码规则在Web页面也给出来了，搜索开源信息，能搜索到学号和对应的人名  

![](../Images/6bc0581d6ab3b5523f73955691bf38fe.png)

### 0x02 内网资产

### 

进入内网系统后，发现点击相应的链接可以访问相应的内网资源

![](../Images/4067d61fe076d89c451a0ad49836b772.png)

对相应的内网域名及ip访问会经过WebVpn加密后再次拼接，如果想获取更多内网资源，就必须知道ip和域名的加密规则

```
 https://webvpn.xxxx.edu.cn/http/77726476706e69737468656265737421a1a013d2756326012c5ac7f8ca/
```

![](../Images/6cf6c4af95e25eae912c0c0a2eb47350.png)

通过页面源码的关键字搜索，发现了公开的WebVpn的url加解密流程，经过测试发现Key和iv都是默认的

![](../Images/867cb09bebc52fe8a461d576aaa3892d.png)

```

//安装aes-js库npm install aes-js

const weburl = process.argv.slice(2)[0];

console.log(encrypt(weburl,wrdvpnIV,wrdvpnKey));}

```

调用Nodejs来运行加密脚本，获取到url拼接内容

![](../Images/134594336c84b74dd8ee4235c7710d2f.png)

用python编写脚本，调用os.popen()读取控制台加密的url，对WebVpn界面显示的210.xxx 、121.xxxx等网段进行一次扫描，Request发包可以对内网存在的Web资源进行一次扫描

```


import os 

```

![](../Images/83e0a651e21eed919e055c6968998192.png)

除此之外，WebVpn还可以拼接端口和协议，类似规则为/http-xxx/ /https-xxxx/

![](../Images/a3f1c2c5d4da1b25127c02dbe73d72ec.png)
