**0x02 EmailAll安装&使用**

**安装：**

```


 $ git clone https://github.com/Taonn/EmailAll.gitt
```

**使用：**

```


 python3 emailall.py check
```

最终结果保存至`result`目录，分为不同模块json数据文件和汇总`{domain}_All.json`文件。
