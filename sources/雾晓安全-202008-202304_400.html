0x01 ezXss介绍

ezXSS 是渗透测试人员和漏洞赏金猎人测试（盲）跨站点脚本的一种简单方法。

0x02 ezXss特征


  • 易于使用的仪表板，带有统计数据、有效载荷、查看/共享/搜索报告

  • 有效载荷生成器

  • 通过邮件、电报或自定义回调 URL 的即时警报

  • 自定义 JavaScript 负载

  • 自定义负载链接以区分插入点

  • 阻止、白名单和其他过滤器

  • 通过直接链接、电子邮件或与其他 ezXSS 用户共享报告

  • 使用双因素 (2FA) 保护您的登录

  • 可以在易受攻击的页面上收集以下信息：

    • 页面的网址

    • IP地址

    • 任何页面引用（或共享引用）

    • 用户代理

    • 所有非 HTTP 专用 Cookie

    • 所有语言环境存储

    • 所有会话存储

    • 页面的完整 HTML DOM 源

    • 页面原点

    • 执行时间

    • 有效载荷网址

    • 页面截图

    • 提取其他定义的页面

0x03 ezXss必需


  • 使用 PHP 7.1 或更高版本的服务器或主机

  • 域名（考虑一个简短的）

  • 如果您想在 https 网站上进行测试，请使用 SSL 证书（考虑使用 Cloudflare 或 Let's Encrypt 以获得免费的 SSL）


0x04 ezXss安装

ezXSS 是 ez 与 Apache、NGINX 或 Docker 一起安装

使用 Apache 安装

  • 克隆存储库并将文件放在文档根目录中（例如 /var/www/html/）

  • 重命名.env.example为.env

  • 创建一个空数据库并在中提供您的数据库信息 .env

  • 在浏览器中访问 /manage/install 并设置密码和电子邮件完毕！那是对吗？

  • 确保您的 Apache 已启用标头、重写和 curl 模块（使用 a2enmod、apt-get curl+php-curl），并且 .htaccess 文件已正确上传并在 vhost 配置中允许（AllowOverride All）

使用 Docker Hub 安装

https://hub.docker.com/r/42elyesa/ezxsshttps://github.com/ssl/ezXSS/pull/80

使用 docker-compose 安装

  • 克隆存储库并 cd 到其中

  • 重命名.env.example到.env与安全的随机生成的密码更新

  • 更新 SMTP 信息 docker-php/msmtprc

  • 跑步 docker-compose build && docker-compose up -d

  • 在浏览器中访问 /manage/install 并设置密码和电子邮件

确保您使用的是 docker-compose 版本 1.26.0 或更新版本。访问下方连接获取安装说明

https://docs.docker.com/compose/install/

使用 nginx 安装

  • 克隆存储库并将文件放在文档根目录中

  • 像示例一样设置您的配置（例如/etc/nginx/sites-enabled/default）：nginx-rewrite.conf

  • 重命名.env.example为.env

  • 创建一个空数据库并在中提供您的数据库信息 .env

  • 在浏览器中访问 /manage/install 并设置密码和电子邮件完毕！
