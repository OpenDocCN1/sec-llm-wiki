# 青藤云安全再斩奖项！

全国顶级首席信息官（CIO）系列峰会于2018年4月18日在上海打响第一枪！青藤云安全受邀参加，并斩获“杰出自适应主机安全解决方案”奖！

![](../Images/338b3418e7c346d09afaca8d1e9b28f5.png)

华鹰奖·杰出自适应主机安全解决方案

首席信息官峰会自2015年开始，至今已经连续举办四届，每届盛会持续6个月。对国内CIO“聚焦IT热门技术，助力CIO引领企业发展”方面有着不可磨灭的贡献。据研究表示到2021年40%的IT人员将成为多面手，担任多种角色，但对于企业CIO们来说，机遇与挑战并存，怎样实现IT引领业务，将个人价值最大化一直是历年来CIO系列峰会的主要话题。

而随着业务的开展，网络安全逐渐演变成为了一个企业保持健康、持续发展的重要问题。本次青藤云安全亮相全国顶级信息官峰会--上海站，将主机安全的解决方案带到了会场。青藤云安全高级安全顾问颜伟海先生在现场进行了解决方案以及典型案例的分享。

![](../Images/ee8a77ef641c4484cb1240d046e5586a.png)

青藤云安全高级安全顾问·颜伟海

在分享中，青藤云安全高级顾问·颜伟海老师指出目前中国的信息化安全企行业分布碎片化严重，而且目前市场上90%以上的公司都在做安全防御，但是随着互联网+时代的不断发展，业务变得越来越开放和复杂，安全防护边界越来越模糊，加之近几年黑客攻击手段愈加丰富，并且有组织有计划的团体发动网络攻击，往往手段和方法都很复杂，传统的基于规则部署在网络边界的安全防护已经不能满足现在客户的需求。青藤云安全态势感知平台，主攻检测和响应两个方面，能够实现7\*24小时不间断监控，并在被入侵第一时间响应，给用户以防护策略的建议，大大缩短了以往入侵发现（MTTD）为172天的超长周期，提升防护效果，实现网络安全闭环，并且可以深度学习，不断完善用户安全防护体系，增强客户网络安全免疫系统。  

![](../Images/3de366c22b35529797ac193a2daedaca.png)

青藤云安全致力于“构建自适应安全的云工作负载保护平台”，保护客户网络安全最后一公里，并已在这个领域深耕四年。2017年入选“Gartner最酷安全厂商（Cool Vender）以及全球云安全市场指南报告(Market Guide)”两篇报告。云工作负载安全（CWWP）近几年一直是Gartner研究的对象，并在多次报告中将CWWP列为未来网络安全防护的重要解决方案。而自适应安全理念又是下一代安全产品的主要发展方向。基于国际以及国内市场的良好市场反馈，青藤云安全在此次大会中线上投票以及现场顶级CIO投票中胜出并获奖，这不仅仅是众多客户的认可，也是业界的认可。

![](../Images/353e4cc6d654677ce5d8585f118ee26d.png)

颜伟海老师代表青藤云安全上台领奖

  

近几年，虽国内安全厂商如雨后春笋般涌现并且茁壮成长，但是对于安全的精耕细作与国际上大的安全厂商还是有一定差距。“中兴事件”愈演愈烈，国人也感受到打铁还需自身强的切身之痛。我们需要在核心技术以及安全理念上不断的创新和提升。刚刚结束的RSA信息安全大会中，青藤云安全发布了首款英文产品，引起国内外安全企业的高度关注，青藤人也在用实际行动证明中国安全企业在不断努力着。青藤云安全，坚持在自适应主机安全领域不断深耕，做好安全最后一公里，为客户信息安全把好最后一关。
