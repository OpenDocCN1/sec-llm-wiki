# 青藤云安全发现Apache Synapse远程命令执行漏洞被CVE及CNVD收录

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650825598&idx=1&sn=a091c8353a6c5575a429d670571dadcf&chksm=80db00dbb7ac89cddd189c1a6e683836234f53bff0ae2bc297257c3453d5f7d9687c45fa318e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825598&idx=1&sn=a091c8353a6c5575a429d670571dadcf&chksm=80db00dbb7ac89cddd189c1a6e683836234f53bff0ae2bc297257c3453d5f7d9687c45fa318e&scene=27#wechat_redirect)

        Apache Synapse是一种轻量级的高性能企业服务总线（ESB）。Apache Synapse由快速和异步的中介引擎提供支持，为XML、Web服务和REST提供了卓越的支持。

                青藤安全研究员sevck发现Apache Synapse存在远程代码执行漏洞， Apache Synapse 3.0.1版本以前默认使用了Apache Commons Collections 3.2.1 (commons-collections-3.2.1.jar)及以前版本，攻击者可以通过精心构造恶意的反序列化对象，导致远程代码执行。

        青藤云安全已及时将漏洞信息提交给国际著名的漏洞知识库CVE组织和中国国家信息安全漏洞共享平台（CNVD）,并经过CVE和CNVD组织重现风险。目前，该漏洞已被CVE和CNVD同时收录，获得了CVE编号：CVE-2017-15708，以及CNVD编号：CNVD-2017-36700。

关于CVE

        CVE是国际上著名的漏洞知识库，也是目前在国际上最具公信力的安全弱点披露与发布单位，CVE组织是一个由企业界、政府界和学术界综合参与的国际组织，其使命是通过一种非盈利的组织形式，能更加快速而有效地去鉴别、发现和修复软件产品的脆弱性。CVE是编号与命名特定弱点的标准协议，以确保哪个弱点已经清楚确实地被辨识出来。目前，CVE的命名方案由MITER公司主持。CVE几乎收集了业界所有的系统漏洞信息并进行了CVE编号，是系统漏洞和漏洞防护领域事实上的工业标准。

关于CNVD

        国家信息安全漏洞共享平台(China National Vulnerability Database，简称CNVD)是由国家计算机网络应急技术处理协调中心(中文简称国家互联应急中心，英文简称CNCERT)联合国内重要信息系统单位、基础电信运营商、网络安全厂商、软件厂商和互联网企业建立的信息安全漏洞信息共享知识库。

       CNVD的主要目标即与国家政府部门、重要信息系统用户、运营商、主要安全厂商、软件厂商、科研机构、公共互联网用户等共同建立软件安全漏洞统一收集验证、预警发布及应急处置体系，切实提升我国在安全漏洞方面的整体研究水平和及时预防能力，进而提高我国信息系统及国产软件的安全性，带动国内相关安全产品的发展。

青藤云安全

            青藤云安全是国内专注于服务器安全产品的初创公司，国内首家践行自适应安全理念的厂商。青藤云安全运用领先独创的技术，竭力为各行业用户提供稳定、高效、个性化的安全解决方案。

       青藤云安全以服务器安全为核心，构建基于业务端的安全联动平台，提供持续的安全监控、分析和快速响应能力，为用户提供持续检测和分析，保障用户在公有云、私有云、混合云、物理机、虚拟机等各种业务环境下实现安全的统一策略管理，提高入侵响应能力.
