# 【漏洞通告】GoAhead远程代码执行漏洞通告（CVE-2017-17562）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650825593&idx=1&sn=72e0e30f67febf72aac80220a8205c67&chksm=80db00dcb7ac89cabf2440caf06c35bc933c7edc04cac4ac2a63ab8a0f990d2ce4c7c0472359&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825593&idx=1&sn=72e0e30f67febf72aac80220a8205c67&chksm=80db00dcb7ac89cabf2440caf06c35bc933c7edc04cac4ac2a63ab8a0f990d2ce4c7c0472359&scene=27#wechat_redirect)

尊敬的客户：

    GoAhead爆出远程代码执行漏洞，该漏洞详情如下：

 **1.综述 **

       GoAhead是一个开源(商业许可)、简单、轻巧、功能强大、可以在多个平台运行的嵌入式Web Server。

       GoAhead Web Server 3.6.5之前的版本存在远程代码执行漏洞。在使用不受信任的HTTP请求参数初始化CGI脚本的环境中会导致该漏洞，并且会影响所有启用了动态链接可执行文件（CGI脚本）支持的用户。当与glibc动态链接器结合使用时，攻击者将能够使用特殊变量（如LD\_PRELOAD）实现远程代码执行。

**2.漏洞概述**  

       漏洞类型：远程代码执行漏洞

       危险等级： 高危

       利用条件： GoAhead在受影响版本内

       受影响系统： GoAhead < 3.6.5

**3.漏洞编号**  

CVE-2017-17562  GoAhead远程代码执行漏洞

**4.漏洞描述**  

       GoAhead Web Server 3.6.5之前的版本存在远程代码执行漏洞。在使用不受信任的HTTP请求参数初始化CGI脚本的环境中会导致该漏洞，并且会影响所有启用了动态链接可执行文件（CGI脚本）支持的用户。当与glibc动态链接器结合使用时，攻击者将能够使用特殊变量（如LD\_PRELOAD）实现远程代码执行。

**5.****漏洞利用（POC）**

漏洞利用详见：https://github.com/elttam/advisories/tree/master/CVE-2017-17562  

**6.修复建议**  

       升级到官方最新版 3.6.5、4.0.0

https://github.com/embedthis/goahead/archive/v3.6.5.zip
