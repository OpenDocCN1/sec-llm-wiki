# 【原创漏洞通告】Apache Synapse远程命令执行漏洞通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650825588&idx=1&sn=29bf065ec584ec52f3d76389957f85e2&chksm=80db00d1b7ac89c797b42613820722692542b080bb88882bafc12bf5fcaadb7cca6f13f05a0e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825588&idx=1&sn=29bf065ec584ec52f3d76389957f85e2&chksm=80db00d1b7ac89c797b42613820722692542b080bb88882bafc12bf5fcaadb7cca6f13f05a0e&scene=27#wechat_redirect)

      2017年11月15日，青藤安全研究员sevck发现Apache Synapse存在远程代码执行漏洞，并第一时间将此漏洞细节提交Apache官方进行修复。12月10日Apache 官方公开CVE-2017-15708 Apache Synapse远程代码执行漏洞，最新版3.0.1已修复该漏洞。

 **1.综述 ** 

       Apache Synapse是一种轻量级的高性能企业服务总线（ESB）。Apache Synapse由快速和异步的中介引擎提供支持，为XML、Web服务和REST提供了卓越的支持。

       Apache Synapse存在远程代码执行漏洞，Apache Synapse 3.0.1版本以前默认使用了Apache Commons Collections 3.2.1 (commons-collections-3.2.1.jar)及以前版本，攻击者可以通过精心构造恶意的反序列化对象，导致远程代码执行。

**2.漏洞概述**  

      漏洞类型： 远程命令执行漏洞

      危险等级： 高危

      利用条件： Apache Synapse在受影响版本内，并使用默认包含的Apache Commons Collections 3.2.1

      受影响系统： Apache Synapse 3.0.0, 2.1.0, 2.0.0, 1.2, 1.1.2, 1.1.1

**3.漏洞编号**  

CVE-2017-15708 Apache Synapse远程代码执行漏洞

**4.漏洞描述**  

       Apache Synapse存在远程代码执行漏洞，Apache Synapse 3.0.1版本以前默认使用了Apache Commons Collections 3.2.1 (commons-collections-3.2.1.jar)及以前版本，攻击者可以通过精心构造的恶意反序列化对象，导致远程代码执行。

**5****修复建议**

升级到官方最新版3.0.1。

 http://synapse.apache.org/download/3.0.1/download.cgi
