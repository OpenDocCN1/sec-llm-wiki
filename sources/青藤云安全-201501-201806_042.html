   .NET Framework爆出远程代码执行漏洞，该漏洞详情如下：

1.综述

       Microsoft .NET Framework是用于Windows的新托管代码编程模型。它将强大的功能与新技术结合起来，用于构建具有视觉上引人注目的用户体验的应用程序，实现跨技术边界的无缝通信，并且能支持各种业务流程。

       当Microsoft .NET Framework处理不受信任的输入时，在.NET库中的SOAP WSDL 解析模块IsValidUrl函数不能正确处理回车换行符，导致调用函数PrintClientProxy时存在远程代码执行漏洞。在使用了.NET Framework软件的系统中，攻击者成功利用此漏洞可以控制受影响的系统。攻击者可以安装程序，查看，更改，删除数据，或创建具有完全用户权限的新帐户。

2.漏洞概述

      漏洞类型： 远程代码执行漏洞

      危险等级： 高危

      利用条件： 启用.NET Framework，并在受影响版本内

      受影响系统： Microsoft .NET Framework 4.6.2/4.6.1/3.5.1/4.7/4.6/4.5.2/3.5/2.0 SP2

3.漏洞编号

  CVE-2017-8759  Microsoft .NET Framework远程代码执行漏洞

4.漏洞描述

      当Microsoft .NET Framework处理不受信任的输入时，在.NET库中的SOAP WSDL 解析模块IsValidUrl函数不能正确处理回车换行符时，导致调用函数PrintClientProxy存在远程代码执行漏洞。在使用.NET Framework软件的系统中，攻击者成功利用此漏洞可以控制受影响的系统。攻击者可以安装程序，查看，更改，删除数据，或创建具有完全用户权限的新帐户。

      Windows操作系统大都默认安装.NET Framework，攻击者可通过office文档嵌入恶意的.NET代码进行攻击。当被攻击者打开恶意的office文档后，系统可直接被攻击者控制。安装office的用户在未安装.NET Framework官方补丁时，需尽量避免打开未知来源的office文档。

5.漏洞利用（POC）

      漏洞利用代码： https://github.com/bhdresh/CVE-2017-8759

      漏洞利用演示：http://v.youku.com/v_show/id_XMzAyNTI4NjE3Mg==.html

6.修复建议

      安装官方补丁升级到最新版本

      1.官网下载补丁安装：https://portal.msrc.microsoft.com/en-us/security-guidance/advisory/CVE-2017-8759

      2.使用Windows update安装更新补丁，补丁名“2017-09，适用于 xxx 上用于 .NET Framework 3.5.1、4.5.2、4.6、4.6.1、4.6.2、4.7 的安全和质量汇总”

7.即时检测

        青藤云安全在漏洞爆出的第一时间，已经及时分析响应并支持该漏洞的检测。

       具体产品的使用方法：点击左侧的Windows资产清点- 安装软件统计-.NET Framework，查看所有已部署青藤产品agent主机上存在的.NET Framework和对应的版本以及路径等信息。
