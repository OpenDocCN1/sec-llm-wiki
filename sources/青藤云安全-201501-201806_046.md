# 【漏洞通告】Linux内核UFO到非UFO路径切换内存破坏漏洞通告

Linux 内核爆出UFO到非UFO 路径切换内存破坏漏洞，该漏洞详情如下：

  

1.综述

UFO（UDP Fragmentation Offload）是将较大的UDP数据包进行分片。由于UDP 数据包不会自己进行分段，因此当长度超过了 MTU 时，会在网络层进行 IP 分片。 这将减少较大的UDP数据包分片到MTU大小的数据包中的堆栈开销。

Linux 内核存在内存破坏漏洞，从UFO到非UFO在路径切换过程中，构建UFO数据包时使用了MSG\_MORE \_\_ip\_append\_data（）调用ip\_ufo\_append\_data（）。在两个send（）调用之间，路径从UFO切换到非UFO过程中，会导致内存破坏。Linux 内核 UFO到非UFO 路径切换内存破坏漏洞会造成普通用户提权到root用户。

  

2.漏洞概述

漏洞类型： 内存破坏漏洞

危险等级： 高危

利用条件： 在受影响系统版本内并开启UFO的接口

受影响系统： Ubuntu内核4.4.0-\*，4.8.0-\*，4.10.0-\*

  

3.漏洞编号

CVE-2017-1000112 Linux 内核UFO到非UFO路径切换内存破坏漏洞

  

4.漏洞描述

Linux 内核存在内存破坏漏洞，从UFO到非UFO 在路径切换过程中，构建UFO数据包时使用了MSG\_MORE \_\_ip\_append\_data()调用ip\_ufo\_append\_data（）。在两个send（）调用之间，路径从UFO切换到非UFO过程中，会导致内存破坏。Linux 内核 UFO到非UFO 路径切换内存破坏漏洞会造成普通用户提权到root用户。

  

5.漏洞利用（POC）

https://github.com/xairy/kernel-exploits/blob/master/CVE-2017-1000112/poc.c

  

6.修复建议

Linux内核升级到官方最新版。

  

7.即时检测

青藤云安全在漏洞爆出的第一时间，已经及时分析响应并支持利用该漏洞进行提权的行为检测，若利用该漏洞进行提权，青藤云安全会邮件报警并在console上显示。
