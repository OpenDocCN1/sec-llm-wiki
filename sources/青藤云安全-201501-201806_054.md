日前，全球权威的IT咨询及调研机构Gartner发布了《2017云安全最酷厂商》（*Cool Vendor in Cloud Security 2017^(\[1\])*）报告，**青藤云安全凭借其在云安全领域丰富的实践经验和领先的技术成果成为入选本次报告的唯一中国企业！**

Gartner对Cool Vendor（以下简称最酷厂商）的定义为：在商业社会、IT领域拥有“可以重塑行业的破坏性技术和商业模式创新”。

  

**报告显示，青藤成为全球最酷厂商的原因为：**

1\. 青藤云安全通过综合实现服务器进程行为的深度可视化、网络交流和蜜罐技术（诱骗漏洞及服务器上的应用和端口）来精确检测高级威胁——这些能力在中国厂商产品中并不常见。

2. 青藤核心检测技术是一个进程行为模型，该模型以系统中正常的进程行为、父进程子进程关系、服务器之间的访问关系等为基线，并将数据上传到云分析平台（用户可选择本地化部署），再通过匹配威胁情报库，进一步分析入侵指标。

3. 青藤云安全能为用户交付受托管的快速检测与响应服务。

4. 青藤能评估服务器上的漏洞和错误配置，以判断服务器的整体安全态势，让企业集中精力减少被攻击面。

  

Gartner认为，当前管控云上操作行为的技术方案在不断增加，但云安全最佳实践还是让人困惑不已。**《2017云安全最酷厂商》报告的目的是为全球信息安全官们提供令人关注的、能解决云计算挑战的安全新产品，通过这份报告，安全和风险管理领导能更好地理解最前沿的、即将成为主流的云安全解决方案。**

 

青藤云安全的新方案“持续监测与分析平台”在保护云计算环境的道路上，已经迈出了坚实的步伐。据Gartner调查，很多云工作负载保护平台（CWPP）厂商为了实现服务器负载安全增加了行为监控功能，另外采用诱骗（蜜罐）技术的厂商也在不断涌现，但很少有厂商能像青藤云安全一样将这两者结合到位。**据悉，今年3月底，青藤云安全已经作为唯一的中国安全公司，与Symantec、McAfee等国际知名安全公司并列，正式进入Gartner全球市场指南《*Market Guide for Cloud Workload Protection Platforms*》 报告。**

 

作为一家成立不到3年的初创公司，青藤云安全在竞争激烈的全球安全厂商榜单中，连下两城！在入选全球市场指南短短两个月后，又成为Gartner的全球云安全最酷厂商，一跃成为安全界翘楚！而作为全球最具权威的IT研究与顾问咨询公司，Gartner的魔力四象限与最酷厂商一直是其两大知名研究报告，前者针对成熟市场的成熟玩家，后者推荐的厂商则是具备极大发展潜力，具有某个垂直领域强大的、令人耳目一新的能力，有发展成该领域内独角兽的绝对优势，能进入该榜单再次佐证了青藤云安全不俗的实力！

 

根据调研，2004-2011年，入选过Gartner最酷厂商的提供商有1427家，其中97%仍在运营，不乏首次披露成为最酷厂商后，被谷歌、思科、微软、甲骨文等收购的企业（具体数据见下图），如知名安全厂商Mandiant（被FireEye以10亿美元收购），此外安全界的最酷厂商还有Dome9、Lookout、vArmour等。而一些明星企业如Skype、Snapchat、Instagram、VMware、Splunk等，也是曾经的最酷厂商，如今成为通过创新发展起来的成功典范。
