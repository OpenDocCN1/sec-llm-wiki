# 青藤云安全荣膺安全牛“2017最具发展潜力初创企业”榜单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650825421&idx=1&sn=012024f30d5623d7eb1ee0c983ecbedd&chksm=80db0168b7ac887e2d8b9fb8c4437b0c761a6d3f497f47d89623e8a48491dd713b5fa9ab7be2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825421&idx=1&sn=012024f30d5623d7eb1ee0c983ecbedd&chksm=80db0168b7ac887e2d8b9fb8c4437b0c761a6d3f497f47d89623e8a48491dd713b5fa9ab7be2&scene=27#wechat_redirect)

据最新消息，信息安全专业新媒体安全牛于今日发布《中国网络安全企业50强》（2017年上半年），调查区间为2016年全年的企业信息及各项数据。青藤云安全荣膺“最具发展潜力初创企业”版块，是唯一一家专注于自适应安全领域的入选企业。推荐理由为：

*   国内较早推出自适应安全理念的公司，产品已得到多家互联网企业的应用，效果显著。
    
*   专注领域：自适应安全
    

  

![](../Images/4bf1bd71a1a499eb3b608825e361154f.png)

图1：青藤云安全入选安全牛【最具发展潜力初创企业】

  

安全牛称：本次报告在“最具发展潜力初创企业”版块中只列出了15家，以精选出各个安全细分领域最值得推荐的创业公司。所列榜单企业条件是：C轮融资以前，且成立时间不超过6年。

  

青藤云安全成立于2014年，是国内首家落实自适应安全理念的厂商，2017年3月，入选Gartner的《Market Guide for Cloud Workload Protection Platform 》报告（CWPP被Gartner列为2017顶级安全技术榜单之首），成为十年来第一家也是唯一一家入选Gartner全球安全市场指南的中国初创公司。

  

青藤产品安全联动平台以服务器安全为核心，通过持续的安全监控和分析，快速发觉异常行为，并自动开启响应模式，自内向外地解决业务动态变化中的安全问题。产品还开发了API集成能力，对内可向用户提供灵活高效的检测和准确实时的数据，实现IT运维自动化；对外则允许用户引用整个安全行业的能力服务于一家企业，满足企业各种业务角色的安全需求。![](../Images/6cc4cd10e32b8cbe516a517b8fa4fc6f.png)

青藤云安全致力于为政府、运营商、互联网、金融等行业用户提供强大稳定的安全解决方案，让用户能在公有云、私有云、混合云、物理机、虚拟机等各种业务环境下实现安全的统一策略管理，提高入侵响应能力。

![](../Images/c9f7ef629fce375f1e2bf7a30c6a7020.png)**青藤 简介**

青藤是国内首家自适应安全服务商，目前已经为政府、运营商、互联网、互联网金融等多家知名互联网企业提供轻量级、弹性可扩展的新一代安全服务体系。2017成功入选Gartner全球安全市场指南青藤，为企业云安全保驾护航。
