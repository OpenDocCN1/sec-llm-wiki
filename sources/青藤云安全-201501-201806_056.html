原文：Gartner Identifies the Top Technologies for Security in 2017

概要：Gartner强调了2017年顶级信息安全技术及其对安全企业的影响。


Gartner副总裁兼著名分析师Neil MacDonald表示：“2017年，企业IT的威胁级别仍然处于非常高的水平，每天都有大量账户被泄露或遭到攻击。随着攻击者能力的提升，企业也必须加强自身保护访问和防范攻击的能力。安全和风险负责人必须评估并了解最新的技术，以防范高级攻击，更好地实现数字业务转型，拥抱云、移动和DevOps这样的新计算类型。”


一、信息安全的顶级技术包括：


云工作负载保护平台（Cloud Workload Protection Platform）

现代数据中心支持运行在物理设备、虚拟机、容器、私有云基础设施中的各种工作负载，并且几乎总是涉及一个或者多个公有云基础设施及服务（IaaS）提供商。混合云工作负载保护平台（CWPP）为信息安全负责人提供了一种集成方式，通过统一管理平台保护这些工作负载，并提供了一种无论工作负载运行在哪些基础设施上，都能表达安全策略的方法。


远程浏览器（Remote Browser）

几乎所有成功的攻击都是源自于公共互联网，基于浏览器的攻击是用户遭遇攻击的主要来源。信息安全架构师无法阻止攻击，但是他们可以将终端用户访问互联网与企业终端、企业网络隔离开来，从而避免受到损害。通过隔离浏览功能，恶意软件无法入侵用户系统，大大减少企业的被攻击面，将攻击的风险转移到服务器会话，就可以在每个新浏览会话、已打开的标签页或者被访问的URL中重置成已知的正确状态。


诱骗（Deception）

诱骗技术的定义是通过使用欺骗或者诱骗手段来阻碍或者阻止攻击者的认知过程，破坏攻击者的自动化工具，拖延攻击者的活动或者检测攻击。通过在企业防火墙背后使用诱骗技术，企业就可以更好地检测出已突破防御的攻击者，对所检测到的事件高度信任。诱骗技术的实施现在已经覆盖堆栈中的多个层，包括终端、网络、应用和数据。


终端检测和响应（Endpoint Detection and Response）

终端检测和响应（EDR）解决方案通过监控终端异常行为以及恶意活动迹象，加强传统的终端预防性控制措施，例如防病毒。Gartner预测，到2020年有80%的大型企业，25%的中型企业，以及10%的小型企业将投资部署EDR。


网络流量分析（Network Traffic Analysis）

网络流量分析（NTA）解决方案监控网络流量、连接和对象，找出恶意行为迹象。有些企业正在寻找基于网络的方法来识别绕过了边界安全的高级攻击，这些企业应该考虑使用NTA来帮助识别、管理和分类这些事件。


托管检测和响应（Managed Detection and Response）

托管检测和响应（MDR）提供商为那些希望改善威胁检测、事件响应和持续监控功能，但自身缺乏专业知识或资源的购买者提供服务。来自中小企业（SMB）和小型企业的需求尤其强烈，因为MDR服务触到了这些企业的“痛点”，即这些企业缺乏在威胁检测能力方面的投资。


微分割（Microsegmentation）

一旦攻击在企业系统中站稳脚跟，他们通常会毫无阻碍地横向（东/西）移动到其他系统。微分割就是在虚拟数据中心内实施隔离和分段的过程。就像潜艇中的舱壁一样，在发生破坏时微分割有助于将损失降到最小。微分段以前主要用于描述服务器之间在相同层或者相同区域内的东西向或者横向通信，但是现在已经演变为虚拟数据中心之间的通信。


软件定义边界（Software-Defined Perimeters）

软件定义边界（SDP）是指在一个安全计算区域内，逻辑不同、但网络相互连接的一组主体。这些资源通常隐藏在公众视野之外，智能通过信任代理才能访问区域内的特定主体，资产不公开以减少被攻击面。Gartner预测，到2017年底，至少有10%的企业组织将利用软件定义边界（SDP）技术来隔离敏感环境。


云访问安全代理（Cloud Access Security Brokers）

云访问安全代理（CASB）解决了云服务和移动使用迅猛增加所导致的安全漏洞。CASB为信息安全专业人士提供了适用于任意用户、任何设备、在现有多种云服务基础上的单点控制方案。SaaS的重要性日益增加，再加上对安全、隐私及合规性的持续担忧，都增加了对云服务的控制和可见性的紧迫性。


针对DevSecOps的OSS安全扫描和软件组合分析（OSS Security Scanning and Software Composition Analysis for DevSecOps）

信息安全架构师必须能够自动地把安全控制融入到整个DevSecOps周期中，而不需要手动配置，这种方式对DevOps小组来说应该尽可能透明，不影响DevOps的敏捷性，同时满足法律和法规标准要求，能管理风险。为了实现这一目标，安全控制必须结合DevOps工具链一起实现自动化。软件组合分析（SCA）工具专门分析源代码、模块、框架和库，开发者用这些来识别和清点OSS组件，在应用用于生产环境中之前，找出任何已知的安全漏洞或者许可问题。


容器安全（Container Security）

容器使用共享的操作系统（OS）模式。一个针对主机OS的漏洞攻击可能导致所有容器都受到影响。容器本身是安全的，但是开发者以不安全的方式进行部署，安全团队又很少参与其中，安全架构师也没有指导建议，就会导致这种情况。传统网络和基于主机的安全解决方案不适用于容器。容器安全解决方案保护容器从创建到生产的整个生命周期，大多数容器安全解决方案都提供了生产前的扫描以及运行期间的检测和保护功能。


二、关于CWPP和青藤云安全：


2017年3月底，Gartner发布《Market Guide for Cloud Workload Protection Platform》报告，青藤云安全作为作为唯一的中国安全公司，与Symantec、McAfee等国际知名安全公司并列，进入Gartner世界代表公司名录。青藤成为十年来第一家也是唯一一家入选Gartner全球安全市场指南的中国初创公司。


在今年的Gartner Security & Risk Management Summits 2017会议上， Gartner将CWPP（云工作负载保护平台）列为顶级信息安全技术之首，足以见得未来3-5年内，该技术将得到安全和风险领导人足够的关注，并爆发极大的市场潜力。CISO们应该利用这些最新的安全技术防范高级攻击，更好地实现数字业务转型。
