Windows search爆出远程代码执行漏洞，该漏洞详情如下：


1.综述

Windows search 是Windows一项默认启用的基本服务。允许许多用户在多个Windows服务和客户端之间进行搜索。

当Windows搜索处理内存中的对象时，存在远程代码执行漏洞。成功利用此漏洞的攻击者可以控制受影响的系统。攻击者可以通过向Windows search发送一个特定的SMB消息利用该漏洞，从而提升权限并控制计算机，随后攻击者可以安装程序，查看、修改或删除数据库，创建一个拥有全部权限的新用户。此外，在一个企业中一个远程未经身份验证的攻击者可以通过SMB连接，远程触发该漏洞控制目标主机。

 

2.漏洞概述

漏洞类型： 远程代码执行漏洞

危险等级：高危

利用条件： Windows在受影响系统内，并开启使用Windows search

受影响系统： Windows10，Windows8, Windows8.1，Windows7，Windows Vista，WindowsXP，Windows server 2003，Windows server 2008，Windows server 2008 R2，Windows server 2012，Windows server 2012 R2，Windows server 2016

 

3.漏洞编号

CVE-2017-8543 Windows search远程代码执行漏洞

 

4.漏洞描述

当Windows搜索处理内存中的对象时，存在远程代码执行漏洞。成功利用此漏洞的攻击者可以控制受影响的系统。攻击者可以通过向Windows search发送一个特定的SMB消息利用该漏洞，从而提升权限并控制计算机，随后攻击者可以安装程序，查看、修改或删除数据库，创建一个拥有全部权限的新用户。此外，在一个企业中一个远程未经身份验证的攻击者可以通过SMB连接远程触发该漏洞控制目标主机。
