# 青藤第二届·互联网安全体系建设分享沙龙

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650825156&idx=1&sn=2de6306132c2b8b934e77f057a675386&chksm=80db0261b7ac8b778b4ee922029612c6bfff0e981116b3eea980177aaf9a64bdc65994a2f9cc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825156&idx=1&sn=2de6306132c2b8b934e77f057a675386&chksm=80db0261b7ac8b778b4ee922029612c6bfff0e981116b3eea980177aaf9a64bdc65994a2f9cc&scene=27#wechat_redirect)

2016年12月7日，青藤云安全在北京举行“安全体系建设"闭门交流会议，邀请了青藤云安全COO程度、安全运营总监孙维伯、安全顾问刘磊，并特邀某P2P公司高级安全专家谭捷文4位演讲嘉宾为来宾们带来关于信息安全等保、网络安全法解读、渗透与应急响应实例分享、APT攻击分析及P2P企业如何构建安全体系建设等一系列干货内容。

![](../Images/9aa125b712d8213a39fce097c019de75.png)  

此次闭门会议邀请的嘉宾有互联网金融企业的CTO、安全总监、运维总监，以及互联网租约车平台、招聘企业、O2O企业的安全负责人等。

  

COO程度对信息安全等级保护的背景、定级方法和基本实施流程做了较为细致的解读，并提出等保有5项基本的技术要求，包括：主机安全、物理安全、网络安全、应用安全、数据安全及备份恢复。而青藤云安全的产品自适应安全体系解决的就是主机安全这一领域问题，通过用户身份多重鉴别、访问控制、敏感文件监控、操作审计、资产管理等方法，满足了信息安全等级保护三级中主机安全的全部要求。

  

![](../Images/95c1c99cba9ce7ba9bdf3799c5390ed4.png)  
程度指出了即将颁布的云等保2.0标准中的4项重点变化：责任主体一分为二、不同模式责任不同、等保级别必须匹配、测评对象适当增加。

![](../Images/60ad418847cc2a769a82d4d76c1b6e2f.png)  
最后，程度还根据11月国家刚通过的《网络安全法》，盘点了国内金融机构的法律责任，如实名制、配合网信部门审查、制定应急预案、及时检测评估等，赢得在场来宾的一阵掌声。[戳这里看《七个角色、七大视角，带你全面解读<网络安全法>》。](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650825025&idx=1&sn=ed470636ad2c4a6a52f83818301d081c&chksm=80db02e4b7ac8bf28d087cb82013be1b6314184d9dcda2d3cdb1e8ca6e3326d4be52ddb59073&scene=21#wechat_redirect)

  

安全运营总监孙维伯带来的演讲主题为《渗透测试精彩案例与应急响应实例》，连举8个找回“任意”用户密码的案例，并通过验证码null提交被撞库的案例讲述了空变量的危害。然后用指出行业内模糊查询滥用的两个场景分析，最后用青藤为用户提供的两个应急案例（分别应用bash命令审计和事件回溯功能）结束了自己的技术分析分享。  

![](../Images/a7d1a84480506c7b46f3bca387765ca5.png)  
  

安全顾问刘磊分享了《APT攻击分析与安全最后一公里》，APT攻击主要针对大型企业或政府机构如极光行动（Operation Aurora）、夜龙行动（Night Dragon），以造成最大的危害。根据调查，有目的性的攻击事件比例正逐年上升，然而很多企业的安全仍然差在最后一公里，无法有效防止来自互联网的入侵和攻击，尤其是新型攻击（如APT攻击和0day漏洞攻击等。）

![](../Images/c4f144978b40e2d57dd2c663467ec5b3.png)  

因此，安全防御体系要转向聚焦于“服务器”+“人”的安全联动架构，见下图：

![](../Images/8ce862c42102cedb5da375b224fa02c3.png)  

此次闭门会议，还邀请了青藤云安全的一个重点客户，某P2P公司的安全专家谭捷文，用自身实例，讲述互联网企业如何构建安全体系。他指出互金企业主要面临着这些安全难题：IDC多、数据量大、业务线长且变更频繁，还有后台对外、内网线上线下测试混乱等问题。在自身缺乏足够的安全运维人员的情况下，他们采用了青藤云安全的安全产品及服务。解决了主机弱口令、服务配置错误、系统漏洞、服务漏洞、主机操作审计和入侵监控、线上恶意薅羊毛等问题。

![](../Images/3a6c81785b2adfc11150c401e7143ea3.png)  

从而保证了数据安全（数据库防删除、业务数据防泄漏），也培养了企业内部的安全意识（运维安全、开发安全和全员安全意识）。后续，青藤会继续全力支持该企业的安全建设，提供全流量分析监控及处理、实现测试与代码审计自动化、应急响应和威胁情报共享等更多安全服务。

  

这3位嘉宾的演讲为在场的来宾奉献了一场技术型的饕餮盛宴。

  

活动中，青藤还为现场来宾准备了加湿器、蓝牙耳机、桌面音响、充电宝等实用礼品，第二届互联网安全体系建设分享沙龙圆满结束。
