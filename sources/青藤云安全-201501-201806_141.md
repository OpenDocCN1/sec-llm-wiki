# 青藤邀您参加2016国家网络安全宣传周

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650824749&idx=1&sn=cf519ade1b1c5464baafdd1edfc30eea&chksm=80db0388b7ac8a9ebedf3a84012333bd826b1792f1eb57cdc1adb4ec578fa1e038193c04b220&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650824749&idx=1&sn=cf519ade1b1c5464baafdd1edfc30eea&chksm=80db0388b7ac8a9ebedf3a84012333bd826b1792f1eb57cdc1adb4ec578fa1e038193c04b220&scene=27#wechat_redirect)

今年上半年，经中央网络安全和信息化领导小组同意，中央网信办、教育部、工信部、公安部、新闻出版广电总局、共青团中央六部门联合印发了《国家网络安全宣传周活动方案》。**今年网络安全宣传周将于9月19 -25日在武汉举行，主题为“网络安全为人民，网络安全靠人民“。**

![](../Images/ec4a4676012b486ad2b8ac397ea6532a.png)  
作为15家受邀的网络安全初创厂商，尽管16日还在中秋假期，青藤CEO就率领参展小分队奔赴武汉准备参展，为宣传周带来产品——自适应安全平台，**为企业网站提供轻量级、一站式的安全解决新方案**。

  

*   **青藤展位：**
    

武汉国际博览中心A6-1馆，D22展台。（点击原文查看展台位置）

  

*   **宣传周日程**
    

9月19日  

开幕式暨先进典型表彰9月20日主题日-教育日9月21日主题日-电信日9月22日主题日-法治日9月23日主题日-金融日9月24日主题日-青少年日9月25日主题日-公益宣传日

  

*   **宣传周论坛活动**
    

主论坛

2016网络安全技术高峰论坛

  

分论坛：

1.  网络安全人才培养和创新创业
    
2.  大数据安全技术与实践
    
3.  提高网络素养，争做中国好网民
    
4.  智慧城市建设与安全保障
    
5.  网络安全标准与技术
    
6.  核心技术·自主创新
    
7.  协同联动·共守互联网安全
    

国内知名院士专家、大型互联网和网络安全企业高管，俄罗斯、美国、英国、以色列、南非、新西兰和中国香港的企业领袖和专家将参会并发表演讲。

宣传周期间，青藤还将大力普及全民安全意识，共同推动网络安全建设。展位现场还为大家准备了精美礼品，青藤安全顾问团队携带满满诚意，欢迎您的到来！
