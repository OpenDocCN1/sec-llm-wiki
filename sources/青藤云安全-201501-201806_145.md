# 如果网络安全市场是一个班级……

如果网络安全是一个班级，那么市场主流厂商分别是什么角色呢？

  

**班长——启明星辰**

各方面都吃得开。尤其在班主任面前（国家部门）有一定的话语权，时刻与组织保持高度一致。刚刚和班级其他成员完成国际级G20峰会的网络与信息安全保障工作，获得一大堆先进旗帜。**无论是班务管理复杂程度、还是从影响力和创新力来说是当之无愧的老大。**

**团支书——绿盟科技**

德智体美劳综合指标非常强劲，但总体光芒不如班长耀眼的全能选手。旗下管理的班务也很多，在上半年的三好名单里，绿盟的成绩非常漂亮。

**学习委员——天融信**

能力很牛逼，家里也很有钱。一直在认真钻研，学霸一枚。学习实力和排名与隔壁超融合班的H3C旗鼓相当。

有传安恒有意竞争该职位，最近的安保工作十分卖力。还自建了游侠学习网站给大家提供一些班级、年级、校外资讯，所以得到班主任和英语老师的信任，是心头宝。

**劳动委员——山石网科**

行业里任劳任怨的代表，希望靠成绩改变一切。八个字——朴实无华、与世无争。不甚在意title的山石网科，一直在努力，某科学习成绩甚至可以与班长比肩，身怀几个绝技，其中一项刚评选进入一个国际组织的表扬名单（四象限）中，毕业找工作时（market share）实力加分！

 

**纪律委员——360企业安全**

安静啦，听我宣布一件事：这个学科很火大家好好学、辣个学科将来不好找工作，建议班主任要多给我们班多争取一些消息和资源……360企业安全业务方面是火力全开。撇开背后家族不谈，自身业务实力赶不上班长和团支书，但上学前收了一个小弟起名叫网康。

**文艺委员——知道创宇**

“大家好，我们要做摇滚演唱会了、我们邀请XX好声音的歌手开唱了、我们主办黑客狂欢夜了、我们的大会有啤酒、香槟和妹纸啦！嘿！过来看看我们策划的周边，484比国际班的更炫更酷更拽？”身为文艺委员，影响力不可小觑，每天也在给大家提供一些班级内外信息，尽职尽责，得到众多（男）同学喜爱和支持。

**体育委员——亚信安全**

靠武力打天下，一言不合就砸钱！亚信安全，多次校级评选都肯定了他的实力。最近还收了国际班的一个小弟，实力愈发强大。能独挑大梁、举办年级活动。

 

**宣传委员——阿里云安全**

班里的风向标。稍微有点风吹草动、小道消息，全校都得侧目！刚刚上任，就聚全班之力，搞了一个年级大会，不仅邀请了校长、班主任和各科老师，甚至还有全校最出名的外教为自己站台，活动办得很成功，因此获得了不错的口碑。

  

**官二代——北信源**

背景雄厚，背后有部队支持，所以一般人惹不起。但为人低调，深藏不露，从不惹事。

  

**富二代——安全狗**

出身好。近来提家长美亚比较多，希望能震慑众人。

  

**特长生**——**青藤云安全**

两年自学一举考进这个班级，是个有远大理想的学生，立志考上好大学。之前默默无闻搞学习搞业务，现在开始抬头被更多的人认识了，小伙子思维很缜密，数学能力也不错！

  

**组织委员——空缺**

该职位要求多组织活动啊，学生的精力不够，班主任也比较头疼。希望有同学能自告奋勇顶上空缺，多组织一些学习活动，与其他班级、年级、高校互动，把班级的声誉和名气打出去。

  

此外，近两年实力雄厚的校董亲戚们看这个班级的实力日益上涨，甚至在国际比赛中也锋芒毕露。开始慢慢关注并安排底下人来旁听，如百度、华为、腾讯等，这几位的学习能力和举一反三的能力真的很强！家大业大，以后估计会朝这个特长方向发力。

当然，由于竞争激烈，学习强度大，有同学没能走到最后高考就离开了，不过不要气馁！吸取教训、调整方向、重新来过，加油！
