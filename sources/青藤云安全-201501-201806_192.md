Microservices的概念我们早已不再陌生，它为组织架构、设计、交付、运维等方面带来了很大变革。相比传统的SOA架构或者单块架构，微服务有很多的优势，如技术的多样性、模块化、独立部署等，对于高速发展的互联网企业来说，如何设计微服务架构？如何保障微服务间通信畅通？如何让应用无缝完美地迁移？

  

5月21日，灵雀云『释放云的无限潜能之微服务』，有你想要的答案！

**郭靖，VIPKID高级架构师**

曾在豆瓣工作四年，参与豆瓣社区、豆瓣同城等的项目开发，后出来创业，喜欢 Python、GO 及 Geek 文化。主要关注服务化架构和高性能 Web 开发。借此机会和大家分享 HTTP2 在后端服务化使用中的前景和问题。

**分享提纲：**随着业界在服务化上的认识，越来越多的公司开始尝试服务化。服务化初期，团队就要针对 RPC 框架进行选型，我们在对比了 HTTP、Thrift 和 gRPC 之后选择了gRPC。gRPC 基于 HTTP2，保留了 HTTP 的简单，也提升了相当多的性能。gRPC 是 Google 推出的高性能 RPC 框架，这次分享介绍 gRPC 的相关内容。

  

**灵雀云神秘嘉宾**

  

**分享提纲：**现代的应用程序架构正稳步地向微服务转变，且微服务间的通信选择也逐渐丰富。我将借这次交流会跟大家探讨一些选择包括REST，Apache Thrift和消息队列和它们的用例。

  

**周秉政，乐视云基础云平台架构师**

主要负责乐视云云计算平台的研发及架构设计工作，新技术的孵化和产品推广工作。主要关注领域：电商云、Container、Galera、Mesos、ELK、Openstack等云计算领域。

**分享提纲：**本次分享将带大家了解电商系统的发展过程，并分析在高速发展期的电商面临的问题，同时跟大家分享乐视电商云的架构和实践方案。

  

**    毛郸榕、肖凌，亚马逊AWS解决方案架构师 **

毛郸榕，亚马逊AWS解决方案架构师。负责基于AWS的云计算方案架构的咨询和设计，同时致力于AWS云服务在国内的应用和推广，在大规模后台的架构、企业混合IT、移动应用开发和自动化运维等方面有着多年的设计和实践经验。

肖凌，AWS解决方案架构师，负责基于AWS的云计算方案架构的咨询和设计，同时致力于AWS云服务在国内和全球的应用和推广，在大规模并发后台架构、跨境电商应用、社交媒体分享 、Hadoop大数据架构以及数据仓库等方面有着广泛的设计和实践经验。在加入AWS之前曾长期从事移动端嵌入式系统开发，IBM服务器开发工程师。并负责IBM亚太地区企业级高端存储产品支持团队，对基于企业存储应用的高可用存储架构和方案有深入的研究。

**分享提纲：**自从 Martin Fowler 提出Microservices 这个概念以后，这个架构良好扩展性并可持续开发能力的特点迅速成为业内的热点话题。那到底什么是微服务，当我们谈论微服务时，它代表着一种什么样的含义？微服务适合应用在什么场景下，以及它有什么样的优缺点？尤其是当我们步入到云计算的时代，我们究竟需要如何实现良好的Microservice 架构？随着AWS在基础设施自动化技术的发展，将大大减少构建、发布、运维微服务的复杂性。在本次演讲中，将为大家揭开微服务的神秘面纱，从传统的单一结构，到SOA的发展，再到微服务架构的引入，最后到“无服务器”式的架构模式，全面为您展示在AWS的环境中构建一个符合Microservice特点的架构。
