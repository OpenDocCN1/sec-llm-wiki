Technologies for Docker Container Monitoring

Saurabh Wagh

灵雀云首席架构师

Saurabh在卡耐基梅隆大学获得计算机科学硕士学位，曾在Nutanix（这也是家美国独角兽公司）与微软负责虚拟机与容器的核心技术研发，具有多年的企业与大型云计算架构经验。Saurabh致力于为不断创新的云计算领域做出贡献，在灵雀云，Saurabh带领着研发团队共同创造领导云计算革命的容器服务。

分享提纲：在Docker容器技术飞速发展之时，监控容器的效率与健康也变成了至关重要的需求。在Docker自身提供的监控技术逐渐成熟时，来自第三方的监控工具也同时步入人们的视线。在这次分享中，我们将概述Docker容器的监控，并讨论时下在容器生态圈最受欢迎的监控工具。
