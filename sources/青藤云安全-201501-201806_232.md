# 腾讯云发生故障 大面积用户受损严重

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=204752263&idx=1&sn=0fa0e2886384343c4318db1a7c60cff6&chksm=12ef26222598af34d6dbcb960d07d3eb42b57d19fe8ccbbd6d1f2ce8584e7d05e3a0b7fec351&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=204752263&idx=1&sn=0fa0e2886384343c4318db1a7c60cff6&chksm=12ef26222598af34d6dbcb960d07d3eb42b57d19fe8ccbbd6d1f2ce8584e7d05e3a0b7fec351&scene=27#wechat_redirect)

![](../Images/d670c78ead5d395cbfd2cc6062aa098e.png)

3月6日晚间消息，腾讯云出现故障，用户大面积无法访问腾讯云。对用户造成了巨大损失，部分用户在微博和论坛上进行投诉。时间从早间10点开始，持续到3:20分前后开始大面积出现故障，故障具体原因不明，腾讯发布公告上海机房出现问题，部分用户出现连接中断和访问延时加大的问题。

![](../Images/cd9629b8c96fe6a7043a32dac474d2ea.png)

用户收到的关于腾讯云的故障短信

![](../Images/aa8ad6497a01261867694d1ceba4bc87.png)

部分用户在微博以及腾讯云论坛上进行投诉。

![](../Images/756fc43ec56ea96165719dd68af05d74.png)

用户持续收到故障提醒报告，截止3月6日晚10点，腾讯云仅部分修复，有用户反映仍然无法正常使用。
