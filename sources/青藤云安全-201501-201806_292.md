# Gartner：今年亚太公共云支出将达74亿美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=203865020&idx=1&sn=7c7e0e9e5193d26aca5dfea8d6de0594&chksm=12fdd819258a510fa7afd136a2957ac2848173583b574f224776686c6053ed9c07b9447abf24&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=203865020&idx=1&sn=7c7e0e9e5193d26aca5dfea8d6de0594&chksm=12fdd819258a510fa7afd136a2957ac2848173583b574f224776686c6053ed9c07b9447abf24&scene=27#wechat_redirect)

市场调研机构Gartner最新报告显示，亚太地区（包括日本）的公共云服务市场已发展成熟，预计2015年，该地区的公共云服务支出将较2014年增长近14.2%，达74亿美元。其中，云管理和安全服务将成为2015年公共云增长最快的领域，较2014年增长29.9%，达2.645亿美元。

  

Gartner研究副总裁埃德·安德森称：“亚太地区的许多国家都拥有稳固可靠的电信基础设施和相对先进的技术使用配置文件。尽管面临全球经济的挑战，我们预计到2018年亚太地区的公共云服务仍将持续稳定增长。”Gartner预测，到2018年，亚太地区公共云服务支出将达115亿美元，其中，业务流程即服务（BPaaS）占比将达9.2%；平台即服务（PaaS）将占比3%；软件即服务（SaaS）将占比21.5%；云管理和安全服务将占比4%；基础设施即服务（IaaS）将占比9.8%；剩下的52.5%则将来自云广告。

  

此外，Gartner调查还显示，随着越来越多的企业和政府用户使用云服务，到2018年，SaaS、云管理和云存储将成为公共云服务中增长较快的领域。研究表明，受益于亚太地区服务和产业的跨区域一体化发展，如2015年东盟经济一体化、跨太平洋伙伴关系协定等贸易区协定很可能将推动对公共云服务的使用。
