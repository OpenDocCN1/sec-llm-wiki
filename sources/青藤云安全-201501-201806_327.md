# 盘点2014年10大云故事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=203571805&idx=1&sn=44f3f92833f9e17d3bc8d8a0d18d0ca1&chksm=12f921f8258ea8eea03bc026a1c16eb2b13c89f12cb377bf43008f5d6f031582eac8843d1ee7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=203571805&idx=1&sn=44f3f92833f9e17d3bc8d8a0d18d0ca1&chksm=12f921f8258ea8eea03bc026a1c16eb2b13c89f12cb377bf43008f5d6f031582eac8843d1ee7&scene=27#wechat_redirect)

2014是云计算的变革年。很多专家认为，总有一天我们会回顾2014年，发现这是一个转折点——这一年中，大小规模的企业终于接受了基于云的IT的必然性，并开始规划未来。

企业对于安全性、隐私和合规性的担忧似乎也有所缓解，或被想要实现敏捷性、可扩展性和成本的愿望盖过。

但是云计算的格局在这一年变得越来越复杂，传统厂商动荡，新技术起飞，服务提供商开打价格战，提早下手的精明的解决方案提供商享受着迅猛的业务增长。

以下是今年的10大云故事。

  

**10、Equinix发布Cloud Exchange**

Equinix在全球拥有超过100多个顶级数据中心，提供云基础设施服务。

4月，这家网络中立托管提供商利用其独特的能力、连接性和性能构建了云交换，让客户可以无缝地连接到多个公有云和私有云，所有这些都是通过他们想要的专有连接。

此后，Equinix Cloud Exchange吸引了几乎所有主流公有云服务提供商的眼球，并与他们建立了合作伙伴关系，向微软Azure、AWS、Google Cloud Platform、GoGrid和IBM SoftLayer提供安全的、高吞吐的门户。

预计明年Equinix将在该市场中分得更大的一杯羹。

  

**9、IBM SoftLayer的成功**

IBM以20亿美元收购SoftLayer，这是一个大胆的市场举动，是否取得成功有待证明。

今天，IBM的云业务也许是IBM增长最快的资产。

SoftLayer现在只在公有云市场占大约7%的份额——排在Google云平台之前位列第三。

但是IBM已经明确表示无意参与价格战。

渠道合作伙伴非常高兴地听到IBM试图通过性能、可靠性和安全性区分自己作为首屈一指的企业平台的定位。这是为实现健康盈利的对策。

  

**8、微软Azure崛起**

2月，萨蒂亚·纳德拉从微软云和企业级部门升任微软首席执行官，掌舵这家全球最大的软件公司。

纳德拉的升职被解读为微软在云上下重注，而这没有令人失望。微软反复强调微软对于Office 365和Azure的承诺，微软的云要比该领域的其他对手增长都快。

当然，Azure仍然主导着市场。但是Synergy Research Group估计，微软云业务的增长速度是本土竞争对手的2.5倍。

凭借在第三季度136%的增长，微软现在控制着公有云市场大约10%的份额，突出重围站在不受挑战的第二位置。

  

**7、思科构建Intercloud**

虽然是云这场大派对的后来者，但思科今年确有大动作，利用其网络连接的优势向市场中推出了一款名为Intercloud的独特产品。

思科的云战略围绕着名为Intercloud Fabric展开，它将很多联合公有云和私有云聚合到一起，允许工作负载无缝地在这些云之间移动。

思科的Intercloud已经连接到数百个数据中心连接各种支持思科托管基础设施的分销商、管理服务提供商和云服务提供商的生态系统。

  

**6、拥抱OpenStack**

OpenStack正如很多人期望的那样被证明是一项变革性技术。但是OpenStack最大的进展是发生在2014年，也是在NASA开发出这项技并被Rackspace推出后的数年，被广泛接受和采用。

这给很多厂商、合作伙伴和企业客户带来了另一个独特挑战：寻找具有构建、部署和管理OpenStack云的技能的工程。

红帽在6月宣布打算以7000万欧元现金和股票的形式收购法国管理服务提供商eNovance——OpenStack社区的主要贡献者。

这次收购将帮助红帽向客户交付它自己的OpenStack分发版，人才的匮乏可能会危及到这个开源项目。

  

**5、惠普收购Eucalyptus**

大胆和意想不到的举动，惠普在9月宣布收购软件初创厂商Eucalyptus——Amazon Web Services的亲密盟友，OpenStack的竞争对手。

Eucalyptus提供云运营软件，利用Amazon的API，市场定位为一种构建能够兼容AWS的混合云环境的方式。作为Amazon的竞争对手之一，惠普现在成为OpenStack项目的最大贡献者，一个云运营系统部分可取代Eucalyptus。

至于惠普是否会让两个有竞争关系的开源云平台共存、或者Amazon是否会对惠普的侵犯作出回应，这些都有待观察。

  

**4、Rackspace要上市？** 

5月，Rackspace对外公布惊人消息称，向SEC透露它已经聘请摩根士丹利来评估“集客式战略建议”。

这个消息引发了关于谁会收购这家位于圣安东尼奥的云计算和服务器托管巨头的大量猜测。

在数月的猜测和大量被证明是错误的媒体报道之后，Rackspace在9月终结了所有收购传闻，宣布仍将作为一家独立公司运营。Rackspace同时任命Taylor Rhodes作为首席执行官负责公司未来云战略的管理。

随后Rackspace宣布股票回购以安抚股东。

  

**3、人人都爱Docker**

对于Docker来说这是分水岭的一年，这项开源Linux容器技术通过分布式应用跨不同计算环境的开发、部署和管理打破其流程。

6月，Docker项目背后的Docker Inc.实体公司宣布其首款企业级产品。自此，追随者们争相与Docker牵手。

最近几个月，Docker与微软Azure、Amazon Web Services、Google Cloud Platform和IBM SoftLayer的合作伙伴关系都取得成果。

  

**2、谷歌向企业级领域推进**

什么是品牌重塑？

从谷歌来看，这家搜索巨擎最近、也许是最重要的迹象就是对于企业级市场非常非常上心。

谷歌在9月初向全世界传递了这个信息，并且将其企业云业务更名为Google For Work。

虽然品牌重塑就其本身来说并不是一个大新闻，但是谷歌向一家企业产品转型、与微软竞争更加白热化，这无疑是一个改变游戏规则的举动。

谷歌向企业级领域转移，随之而来的是对其构建渠道的更多承诺。

  

**1、AWS不容忽视**

似乎这已经是一个规律了，但凡一家知名的计算巨头、新兴公司还是开源社区的公司要进入云领域，都会宣称要击败Amazon。尽管成为众矢之的，但AWS的业务体量仍然要比四大竞争对手的总和还多。

Amazon的合作伙伴网络在去年增长了75%，不久还将通过其平台提供超过500项独有服务。

虽然并不像竞争对手那样增长快速，但AWS的领先优势明显，很难想象谁能不制造一场动荡就赶超它的。

一些解决方案提供商认为，AWS已经成长到如此巨大和多样化，他们别无选择只能试图与其合作。
