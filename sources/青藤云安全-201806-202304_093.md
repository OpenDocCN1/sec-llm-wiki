# 青藤入选信通院“数据安全推进计划”成员单位

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650834253&idx=1&sn=07fda4d5dd5226f5760db8755790db3f&chksm=80dbe6e8b7ac6ffe33445dc586ee1c073ecbed9893a3d0a843ffecc24788776b9e65b02d38d3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650834253&idx=1&sn=07fda4d5dd5226f5760db8755790db3f&chksm=80dbe6e8b7ac6ffe33445dc586ee1c073ecbed9893a3d0a843ffecc24788776b9e65b02d38d3&scene=27#wechat_redirect)

近日，信通院发起的“数据安全推进计划”（Data Security Initiative，以下简称“DSI”）公布了最新参与单位名单。**青藤成****功入****选为“DSI”的成员单位**。  
![](../Images/dc9d80a019f47c4daff9cbf731e1d2dc.png)图1 信通院“数据安全推进计划”部分参与单位名单  
DSI是由信通院发起的公益性合作项目，旨在**推动《数据安全法》的深入贯彻落实**，依托大数据协同安全技术国家工程实验室、中国通信标准化协会大数据技术标准推进委员会、中国互联网协会数据治理工作委员会开展具体工作，致力于打造健康规范的数据安全生态体系，帮助企业了解监管要求，全方位提升企业数据安全能力。自启动以来受到全行业广泛关注和讨论，参与单位均为业内龙头企业，行业广泛分布于金融、互联网、通信、汽车、安全厂商和医疗等领域。  
本次入选，是对青藤技术实力以及行业地位的高度认可。青藤为推动网络安全产业在数据安全方面的创新发展献力献策，曾深度参与由中国网络安全产业联盟、全国信息安全标准化技术委员会秘书处指导，中国网络安全产业联盟数据安全工作委员会组织的“《数据安全法》实施参考（第一版）”的编制工作。[（青藤参与编写的《数据安全法》实施参考（第一版）发布）](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650833969&idx=1&sn=f0777b1930b82498f9724a3f2f965a99&chksm=80dbe794b7ac6e82e6abc7d47f9175f4a7630d90cb2f300ebf331a7ade22a8c7d0cbbbb80e31&scene=21#wechat_redirect)  
未来，青藤将继续积极承担企业责任，充分发挥自身优势，与广大成员单位携手奋进，凝聚共识，为进一步推动数据安全产业发展贡献力量。
