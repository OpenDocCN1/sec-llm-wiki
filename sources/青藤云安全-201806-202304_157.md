# 青藤作为唯一1家安全厂商，入选2021 REAL100创新家榜单

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650832015&idx=2&sn=2e43b297aaad76f451d188faa7ec75c9&chksm=80db1f2ab7ac963c31674e6fb4266f7d2b8fa6144181180c85e1abf9420f865167a5df415de5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650832015&idx=2&sn=2e43b297aaad76f451d188faa7ec75c9&chksm=80db1f2ab7ac963c31674e6fb4266f7d2b8fa6144181180c85e1abf9420f865167a5df415de5&scene=27#wechat_redirect)

10月13日，由界面新闻主办的首届REAL科技大会在北京举办。本届大会以“尤以进化 看往未来”为主题，涵盖元宇宙、人工智能、自动驾驶、量子计算、未来城市等前沿科技话题。大会从六大维度（**估值规模、行业地位、创新性、商业潜力、成长速度、社会舆情**）公布了覆盖五大赛道的2021 REAL100创新家榜单。**青藤作为唯一1家安全厂商，入选榜单。**

  

![](../Images/78127a9009286ccc22ec39edb1444bed.png)

PROVIDE NEW SECURITY FOR 

NEW TECHNOLOGIES

![](../Images/02869ec07eff51a74b21195747cbb891.png)  
本届大会是界面新闻“REAL大会”品牌首次亮相。在界面新闻的诠释里，REAL代表一种进化、向上的力量，也是观察时代的价值观。界面新闻将“REAL”定义为重塑Rebuild、进化Evolution以及链接Link——关注重塑的力量、见证革命的进化、提供链接的赋能。  
作为中国主机自适应安全开创者、云原生安全领军企业，青藤自成立以来就以“为新技术提供新安全”为使命，专注于自主研发，不断提高核心技术创新能力，致力于成为一家富有社会责任感、为用户持续创造价值的世界级安全公司。未来，青藤将继续坚持自主创新，重塑安全能力，进化安全技能，链接安全世界。
