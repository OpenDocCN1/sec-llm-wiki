# 青藤加入深圳市网络与信息安全行业协会

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650831592&idx=2&sn=7c7f065f819588dbc93b2b802af3b3c6&chksm=80db194db7ac905ba4dd839d62e979e445790aa370de7afa654c457b9b6e8f9fdb4b0fcd2eda&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650831592&idx=2&sn=7c7f065f819588dbc93b2b802af3b3c6&chksm=80db194db7ac905ba4dd839d62e979e445790aa370de7afa654c457b9b6e8f9fdb4b0fcd2eda&scene=27#wechat_redirect)

近日，青藤正式加入深圳市网络与信息安全行业协会。青藤未来将以“为新技术提供新安全”为使命，携手协会开展网络安全政策宣传、行业探讨、学术交流；协同会员单位，展开技术优势互补和深度融合，为数字经济社会转型升级，深圳市网络安全整体水平的提升赋能。

  

![](../Images/77e9b1e457374d98d9c824fb9373e674.png)

深圳市网络与信息安全行业协会秘书长白健、青藤华南大区总经理曹语馨等出席会员单位授牌仪式  
**深圳市网络与信息安全行业协会简介：**  
深圳市网络与信息安全行业协会，英文名称为：Shenzhen Network and Information Security Trade Association（SNISA），是经深圳市经贸信息委信息安全处倡议，由业内企业自主发起，于2014年7月25日获深圳市民政局批准成立的非盈利性社会团体，是深圳市网络与信息安全行业的权威行业组织。协会是中国网络安全审查技术与认证中心（CCRC）在深圳唯一授权的工作站，是经深圳市人力资源和社会保障局核准，开展网络空间安全工程技术专业职称评审工作的社会组织。
