# 《党委（党组）网络安全工作责任制实施办法》解读

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650831514&idx=2&sn=c845e76a0a52516e62780628fa1b1e00&chksm=80db193fb7ac9029572a8af4aeae68e52649865f3d542baf5871c226c736bd667a7e87e9c17d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650831514&idx=2&sn=c845e76a0a52516e62780628fa1b1e00&chksm=80db193fb7ac9029572a8af4aeae68e52649865f3d542baf5871c226c736bd667a7e87e9c17d&scene=27#wechat_redirect)

**背景**

  

2017年8月15日，在距离《中华人民共和国网络安全法》颁布实施一年多后，中共中央办公厅发布了《党委（党组）网络安全工作责任制实施办法》（下文简称《实施办法》）。该《实施办法》发布后，全国各级党组织都根据文件精神制订了相应的落实和考核办法，但一直属于内部文件，并未向全社会公开。近期，中共中央办公厅法规局编辑的《中国共产党党内法规汇编》由法律出版社公开出版发行。《汇编》收录新中国成立至2021年6月党中央以及中央纪委和党中央工作机关制定的现行有效且公开发布的党内法规，共183部。《实施办法》是其中第24部，属于“党领导宣传思想文化工作”章节，该文的具体内容也就此面向大众。  
**《实施办法》明确了网络安全工作的责任主体**

  

**1、各级党委（党组）**

  

党的十九大强调：“党政军民学，东西南北中，党是领导一切的。”《实施办法》也明确指出：各级党委（党组）对本地区本部门网络安全工作负主体责任，领导班子主要负责人是第一责任人，主管网络安全的领导班子成员是直接责任人。也就是说各级党委（党组）的书记作为单位一把手承担了第一责任人的角色，这对网络安全工作的落实具有重要意义。通常而言，党组织的一把手负责党组织全面工作，工作内容覆盖广，对于很多工作更多是间接领导，一些具体工作事项则由领导班子的其他成员分管，对于大部分单位而言网络安全只是保障工作的一部分，并不是单位的主体业务内容，尤其是一些具有经营业绩考核要求的央企、地方国企单位，网络安全工作更是重视度不够。但《实施办法》发布后，明确了一把手是该项工作的第一责任人，避免了很多单位只重数字不重网络安全的现状。

  

**2、行业主管监管部门**

  

行业主管监管部门的定义非常广泛，从字面理解，主管则是直接管理，监督主要是根据相关法律、法规、规章、规范性文件对行业内单位承担监督管理职能。如中国证监会是全国证券期货市场的主管监管部门，中国银保监会是全国银行业和保险业的主管监管部门，工业与信息化部则是全国通信行业的主管监管部门。

  

**3、各级（各地区各部门）网络安全和信息化领导机构**

  

各级（各地区各部门）网络安全和信息化领导机构主要是指各地区的网络安全和信息化委员会、各政府部门/企事业单位内部承担网络安全和信息化的领导机构。  
**《实施办法》明确了责任主体的责任内容**

  

《实施办法》针对不同的责任主体，明确了不同的责任内容。  
**一是****明确各级党委（党组）的主要责任内容。**《实施办法》第三条规定：各级党委（党组）主要承担的网络安全责任是：  
1、认真贯彻落实党中央和习近平总书记关于网络安全工作的重要指示精神和决策部署，贯彻落实网络安全法律法规，明确本地区本部门网络安全的主要目标、基本要求、工作任务、保护措施；

  

2、建立和落实网络安全责任制，把网络安全工作纳入重要议事日程，明确工作机构，加大人力、财力、物力的支持和保障力度；

  

3、统一组织领导本地区本部门网络安全保护和重大事件处置工作，研究解决重要问题；

  

4、采取有效措施，为公安机关、国家安全机关依法维护国家安全、侦查犯罪以及防范、调查恐怖活动提供支持和保障；

  

5、组织开展经常性网络安全宣传教育，采取多种方式培养网络安全人才，支持网络安全技术产业发展。  
**二是****明确行业主管监管部门的主要责任内容**。《实施办法》第四条规定：行业主管监管部门对本行业本领域的网络安全负指导监管责任。没有主管监管部门的，由所在地区负指导监管责任。主管监管部门应当依法开展网络安全检查、处置网络安全事件，并及时将情况通报网络和信息系统所在地区网络安全和信息化领导机构。各地区开展网络安全检查、处置网络安全事件时，涉及重要行业的，应当会同相关主管监管部门进行。  
**三是****明确各级（各地区各部门）网络安全和信息化领导机构的主要责任内容**。《实施办法》第五条规定：各级网络安全和信息化领导机构应当加强和规范本地区本部门网络安全信息汇集、分析和研判工作，要求有关单位和机构及时报告网络安全信息，组织指导网络安全通报机构开展网络安全信息通报，统筹协调开展网络安全检查。  
《实施办法》第六条规定：各地区各部门网络安全和信息化领导机构应当向中央网络安全和信息化委员会及时报告网络安全重大事项，包括出台涉及网安全的重要政策和制度措施等。

  

**《实施办法》明确了启动问责的条件**

  

《实施办法》中规定的启动问责的条件分为两种情况：  
**一是****针对履职尽责的情况**。《实施办法》第八条规定：各级党委（党组）违反或者未能正确履行本办法所列职责，按照有关规定追究其相关责任。

  

**二是****针对产生后果的情况**。《实施办法》第八条规定：有下列情形之一的，各级党委（党组）应当逐级倒查，追究当事人、网络安全负责人直至主要负责人责任。协调监管不力的，还应当追究综合协调或监管部门负责人责任。  
1、党政机关门户网站、重点新闻网站、大型网络平台被攻击篡改，导致反动言论或者谣言等违法有害信息大面积扩散，且没有及时报告和组织处置的；

  

2、地市级以上党政机关门户网站或者重点新闻网站受到攻击后没有及时组织处置，且瘫痪6小时以上的；

  

3、发生国家秘密泄露、大面积个人信息泄露或者大量地理、人口、资源等国家基础数据泄露的；

  

4、关键信息基础设施遭受网络攻击，没有及时处置导致大面积影响人民群众工作、生活，或者造成重大经济损失，或者造成严重不良社会影响的；

  

5、封锁、瞒报网络安全事件情况，拒不配合有关部门依法开展调查、处置工作，或者对有关部门通报的问题和风险隐患不及时整改并造成严重后果的；

  

6、阻碍公安机关、国家安全机关依法维护国家安全、侦查犯罪以及防范、调查恐怖活动，或者拒不提供支持和保障的；

  

7、发生其他严重危害网络安全行为的。  
**无论是以上哪种情况，均可启动问责程序。前者明确了责任主体在承担网络安全工作责任时不作为或乱作为行为应被问责的情况，后者明确了责任主体因产生不良后果及负面影响而应被问责的情况。这两种情况相互独立，又形成因果关系，履职尽责不到位必然导致产生严重后果。**  
**《实施办法》明确了问责的工作原则**  
**一是****明确领导责任**。《实施办法》第九条规定：实施责任追究应当实事求是，分清集体责任和个人责任。追究集体责任时，领导班子主要负责人和主管网络安全的领导班子成员承担主要领导责任，参与相关工作决策的领导班子其他成员承担重要领导责任。  
**二是****明确问责主体**。《实施办法》第九条规定：对领导班子、领导干部进行问责，应当由有管理权限的党组织依据有关规定实施。各级网络安全和信息化领导机构办公室可以向实施问责的党委（党组）、纪委（纪检组）提出问责建议。  
**有管理权限的党组织主要指责任主体的上级党组织，或是批准责任主体设立的党组织。另外，各级网络安全和信息化领导机构办公室虽然不是责任主体的有管理权限的党组织，但因其工作职责的特殊性，是可以对问责主体提出问责建议的。**

  

**三是****明确问责措施**。《实施办法》第九条规定：对领导班子、领导干部进行问责，应当由有管理权限的党组织依据有关规定实施。  
**《实施办法》属于党内法规体系中“党的领导法规”板块，因此，这里的有关规定应为《中国共产党问责条例》。《中国共产党问责条例》规定了三种对党组织的问责方式以及四种对党的领导干部的问责方式。三种对党组织的问责方式有检查、通报及改组；四种对党的领导干部的问责方式有通报、诫勉、组织调整或者组织处理及纪律处分。**  
**《实施办法》明确了网络安全的工作保障**  
为了更好地执行党委（党组）网络安全工作责任制，《实施办法》中规定了三种保障措施：  
**一是****表彰奖励措施**。《实施办法》第七条规定：中央网络安全和信息化委员会办公室会同有关部门按照国家有关规定对网络安全先进集体予以表彰，对网络安全先进工作者予以表彰奖励。  
**二是****考核评价措施**。《实施办法》第十条规定：各级党委（党组）应当建立网络安全责任制检查考核制度，完善健全考核机制，明确考核内容、方法、程序，考核结果送干部主管部门，作为对领导班子和有关领导干部综合考核评价的重要内容。  
**三是****纳入审计措施**。《实施办法》第十一条规定：各级审计机关在有关部门和单位的审计中，应当将网络安全建设和绩效纳入审计范围。  
另外，《实施办法》第十二条规定：网络意识形态工作责任制按照《党委（党组）网络意识形态工作责任制实施细则》执行。涉密网络按照有关规定执行。对日益严峻的有关网络意识形态的相关工作责任制及涉密网络进行了补充。  
**结语**  
近年来,以习近平同志为核心的党中央高度重视网络安全工作,通过一系列的工作推进了网络空间安全的理论创新和实践创新。在机构改革方面，为加强党中央对网络安全工作的集中统一领导，强化决策和统筹协调职责，在2018年《深化党和国家机构改革方案》中把中央网络安全和信息化领导小组改为中央网络安全和信息化委员会，同时优化了中央网络安全和信息化委员会办公室职责。提出了为维护国家网络空间安全和利益，将国家计算机网络与信息安全管理中心由工业和信息化部管理调整为由中央网络安全和信息化委员会办公室管理。

  

在法律、政策保障方面，陆续出台了《中华人民共和国网络安全法》、《中华人民共和国密码法》、《关键基础设施保护条例》、《中华人民共和国数据安全法》、《网络安全审查办法》等法律及规范性文件。

  

本次《党委（党组）网络安全工作责任制实施办法》正式面向大众公布，夯实了各级党委（党组）领导班子成员网络安全工作的责任，成为强化统筹协调，推进网络安全各项工作任务落实的重要指导，对加快网络安全保障体系建设，提高国家网络安全防护能力、促进网络安全产业的发展具有重要意义。
