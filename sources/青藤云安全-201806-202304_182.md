# 青藤亮相GOTC，首次提出“一二四”云原生安全体系

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650831418&idx=1&sn=2e491e318f2634d0a63bc112f5e1bef0&chksm=80db199fb7ac9089f10926d8498d335920ce083eb9f3325f5af1d9601a55149a77f7c5b18d5a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650831418&idx=1&sn=2e491e318f2634d0a63bc112f5e1bef0&chksm=80db199fb7ac9089f10926d8498d335920ce083eb9f3325f5af1d9601a55149a77f7c5b18d5a&scene=27#wechat_redirect)

8月1日，全球开源技术峰会（GOTC）“开源云原生计算时代论坛”专题论坛在深圳成功举办，青藤作为云原生安全领军企业受邀出席。  
GOTC是由开源中国OSCHINA联合Linux基金会、开放原子开源基金会发起的，面向全球开发者的一场盛大开源技术盛宴。诸多头部开源公司和顶级开源项目亮相峰会。  

**青藤创新构建“一二四”云原生安全体系**

在峰会上，青藤联合创始人、产品副总裁胡俊认为云原生一系列新技术的出现，带来了新的安全挑战。一方面是技术挑战，云原生引入了大量新的基础设施，也带来了新的安全问题，需要新的安全手段和工具，同时新的开发模式也会对安全集成、安全自动化提出新的要求；另一方面是组织挑战，安全建设和整个开发、运维的生产过程的融合会更加深入，导致安全职责划分需要重新考虑，组织内各个角色的组织形式、安全管理流程都需要重新的调整。  
![](../Images/21e23ad578ef7a11c28a58252b0b7311.png)

青藤联合创始人、产品副总裁胡俊出席GOTC

  
胡俊表示，青藤在实战化思想下创新构建了**“一二四”云原生安全体系**，即**一个体系、两个方向、四个环节**。云原生安全体系需要覆盖整个DevOps生产流程，在Dev和Ops这两个方向上分别要做到“安全左移，上线即安全”和“持续监控和响应，自适应安全”，然后在安全开发、安全测试、安全管控、安全运营这四个环节中通过各种工具和手段来进行落地，以应对云原生带来的安全挑战。  

**青藤走在行业最前沿，屡获认可**

青藤在云原生安全领域投入了大量的资源和人力，树立了多个标杆客户，覆盖行业广泛。在云原生安全方向，不管是技术层面，还是产品层面，青藤都走在了行业的最前沿，在国家各有关部委指导下，参与制定了多项云原生安全方向的国家标准和行业标准。  
青藤自主研发的青藤蜂巢·云原生安全平台更是屡获行业权威认可：荣获中国信息通信研究院、云计算开源产业联盟联合颁发的**0001号可信云容器安全解决“先进级”测评证书**；入选云原生产业联盟评定的“**2021年云原生技术创新解决方案/产品**”，成为**安全品类唯一入选平台**。  
同时，青藤一直积极与云原生行业协会进行合作，共建云原生安全生态。青藤加入云原生计算基金会（CNCF），并成为云原生产业联盟首批理事会员单位和长三角云原生产业联盟创始成员。  
**近期，CNCF中国区负责人Keith Chan来访青藤时表示，安全是企业在部署云原生技术时面临的挑战之一，需要青藤这样的行业专家来切实解决安全问题**。未来，青藤会再接再厉，持续为云原生产业赋能，为生态合作伙伴提供高品质的云原生安全产品和服务，加速国内云原生安全发展进程。
