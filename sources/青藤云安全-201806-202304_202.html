青藤携手CNCF：面向未来，加快云原生安全发展进程

近期，国内领先的云原生安全厂商青藤加入云原生计算基金会CNCF(Cloud Native Computing Foundation)。未来，青藤将与CNCF紧密合作，积极推动云原生安全行业的发展，向各行业输出面向未来的创新性技术。



据悉，CNCF是目前在云原生应用领域最具影响力的非营利性组织，隶属于Linux基金会。自2015年成立以来，始终致力于帮助云原生技术开发人员快速地构建出色的产品，推动云原生技术可持续发展。目前CNCF拥有超过200多家会员以及一系列终端用户与支持者企业，包括Twitter、Docker、Google、Intel、RedHat、IBM、思科等国际知名科技公司。青藤与国际IT巨擘共同融入云原生技术生态，意味着其技术前瞻性获得了业界高度认可，将在云原生的世界舞台上发挥更大作用。


CNCF中国区负责人 Keith Chan表示，CNCF最近组织了很多关于安全的会议，因为安全是企业在部署云原生技术时面临的挑战之一。我们正在积极招募该领域的专家，例如青藤,  以便我们能够共同应对这一挑战。CNCF 还推出了认证计划（Certified Kubernetes Security Specialist，CKS），以培养更多该安全领域的技术人才。


青藤以“为新技术提供新安全”为使命，积极投身于云原生安全落地的一线。2020年7月，发布自主研发的容器安全平台——青藤蜂巢，为企业级用户提供覆盖容器全生命周期的一站式容器安全解决方案，实现了容器安全预测、防御、检测和响应的安全闭环，能有效解决云原生架构安全防护体系中的基础设施安全、云原生计算环境安全、云原生应用安全等问题。青藤作为云原生安全领域代表性厂商，一直以来都积极参与行业活动和标准规范制定。2021年5月，信通院牵头的国内首个“云原生能力成熟度标准体系”发布，其中由青藤深度参与的《云原生能力成熟度模型 第3部分：架构安全》为企业云原生安全建设提供指导；同期，青藤受邀参与的《云原生架构安全白皮书》，成为了企业极具参考价值的行业应用指南。


青藤与CNCF推崇自研与包容的理念不谋而合。未来，将在坚持核心技术自主可控的同时，拥抱和助推云原生生态建设，从而为生态合作伙伴提供高品质的安全产品和服务，加速我国云原生安全发展进程。
