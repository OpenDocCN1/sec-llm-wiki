# 坚持合作伙伴计划，引领网络安全生态融合

**新形势、新市场催生新生态**

  

在中国，网络安全发展的原动力是国家安全与网络强国战略。2014年上半年中共中央网络安全和信息化领导小组成立，国家对网络安全重视程度显著提升。近年来，国家加大对攻防演练的重视程度，覆盖范围也日益扩大。在今年通过的十四五规划纲要中，有175次提及安全相关的内容，其中14次与网络安全相关，由此可见，网络安全已成为国家、社会发展面临的重要议题。

  

但另一方面，人工智能快速发展，安全问题亟待解决；大数据飞速发展，数据泄露风险日益加剧；云计算快速落地，新安全隐患层出不穷。目前，网络攻击已成为全球重大威胁，给社会造成了重大经济损失。前段时间，美国最大燃油管道商Colonial Pipeline受到勒索软件攻击，导致系统下线，所有管线停止运营，再次为人们敲响警钟，关键基础设施安全问题不容忽视。

  

新形势、新市场，催生新生态，推行合作伙伴计划是青藤着手布局网络安全生态的一个重要环节。当前，在网络安全市场上，安全厂商已经从产品提供商转向综合解决方案服务商，服务范围覆盖安全咨询、战略规划、解决方案、以及各类安全运营服务，涉及客户业务的全生命周期。这种变化既是机遇也是挑战，一方面，青藤愿与合作伙伴共享网络安全行业的发展新机遇，另一方面，青藤会与合作伙伴一道，共同克服安全风险挑战，携手共赢。

  

**坚持合作伙伴计划，深耕基础设施安全**

  

青藤是一家高标准的创新型安全公司，坚持合作伙伴计划，深耕基础设施安全，其根本目的在于放弃与合作伙伴的零和竞争关系，充分发挥合作伙伴的积极性，实现互利共赢。同时，这也意味着青藤会坚持克制性地增长，不会为实现短期的营收增长，对各品类产品、各种项目都大包大揽，偏离自己的业务主航道。

  

在今后的发展中，青藤将携手合作伙伴，扎根网络安全的沃土，众智众力，共生共济，在网络安全的道路上不断前行。

  

**加大投入，共建网络安全新生态**

  

未来几年，青藤将加大研发投入，聚焦基础设施安全，以匠心打磨更多安全产品，保障业务的持续增长，力争在不远的未来突破百亿大关！与此同时，青藤将在金融、政府央企、互联网、运营商等领域加大投入，从商机共享、体系化培训、完整解决方案支持、技术支撑等方面为合作伙伴全面赋能。同时，青藤也会积极地帮助合作伙伴构建并提升解决方案能力，让更多开发者以青藤的技术优势为基础进行业务创新，打造贴近客户业务需求的行业解决方案，为客户创造更大价值。

  

未来，无论环境如何变化，企业业务做何种调整，青藤都将坚定不移地走合作伙伴道路，坚持合作伙伴计划，与合作伙伴共建网络安全新生态。

  

  

**相约青藤2021合作伙伴峰会**

  

时代在变，需求在变，数字化转型的内涵在变，不变的是青藤对高品质安全产品、专业安全服务的追求，不变的是青藤全面拥抱合作伙伴的战略方向。青藤将在基础设施安全这一赛道上持续深耕，与全国各地的合作伙伴建立起竞争优势，与他们一起迈入新征程，谱写网络安全生态新篇章。

  

6月4日下午，以“开放共享 融合共生”为主题的青藤2021合作伙伴峰会即将盛大启幕。届时，青藤将与众多合作伙伴和客户分享中国最前沿的网络安全发展趋势，全面传递青藤的合作伙伴计划和支持政策，展示青藤在金融、央企政府、运营商、互联网等领域的领先解决方案！
