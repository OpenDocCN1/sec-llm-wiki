# 中国网络安全能力100强出炉，青藤技术与创新力位列竞争者第一

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAwNDE4Mzc1NA==&mid=2650828172&idx=1&sn=889b085cebb171112b11c3c09979dfc4&chksm=80db0e29b7ac873f07070411741f37da575749d6f374593f7b593d8a50e889048e5af9f51c84&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAwNDE4Mzc1NA==&mid=2650828172&idx=1&sn=889b085cebb171112b11c3c09979dfc4&chksm=80db0e29b7ac873f07070411741f37da575749d6f374593f7b593d8a50e889048e5af9f51c84&scene=27#wechat_redirect)

![](../Images/8fc27b7344848b97f80139ce546ba14e.png)

  

6月29日，国内网络安全行业第三方权威调研机构“数世咨询”发布《中国网络安全能力100强》。青藤作为我国主机安全先行者和领导者，成功入选中国网络安全能力100强“竞争者企业”。**在技术与创新力层面，位列竞争者企业第一。**（见下图右下角“技术与创新力”）

  

![](../Images/9b77ba2d45d93924fbf48c4dac8243b0.png)

  

此次，数世咨询从500家网络安全企业中选择了100家具备代表性的企业，基于上百项指标结合多种角度、不同维度的企业相关数据进行评价和梳理，并对领军企业、中坚力量和潜力企业进行了能力画像，最终通过综合影响力、市场执行力、技术与创新力三大维度，以数轴点阵图的形式将100家企业展现出来。该评选清晰客观的反映了国内网络安全企业的真实状况，能够为国家主管部门、研究机构、行业用户，以及广大网络安全企业及相关从业者提供有价值的参考。

  

 其中，竞争者点阵图多为近年来在各自安全细分领域上升趋势较快的企业，以及一些在各自细分领域表现突出或至少五年以上行业资源和技术经验积累的企业，展现出向领军企业发展的势头和实力。**尤其是位于点阵图右半区域的企业，是冲击科创板和创业板的有生力量代表，是目前网络安全市场的中坚力量。**此次从众多企业中脱颖而出，代表了专家对青藤技术创新能力、综合影响力、市场执行力的高度肯定。

  

据悉，青藤自2014年成立以来，始终致力于核心技术自主研发，已推出包括青藤万相·主机自适应安全平台、青藤蜂巢·容器安全等产品服务，帮助来自政府、金融、运营商、大型企业、互联网、医疗、教育等组织机构的上百万台核心服务器提供稳定、高效的安全防护。此外，核心产品“青藤万相·主机自适应安全平台”以其卓越的效能，连续四年入选Gartner云工作负载保护平台市场指南（CWPP），备受国际权威机构关注和认可。

  

未来，青藤将不负认可，砥砺前行，以“为新技术提供新安全”为企业使命，不断提高核心技术创新能力，致力于成为一家富有社会责任感、为用户持续创造价值的世界级安全公司。
