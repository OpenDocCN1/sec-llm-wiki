# 喜报|青藤云安全连续三年进入Gartner全球云安全市场指南

2019年4月8日，世界知名IT研究和分析机构Gartner发布了今年的全球云安全市场指南（Market Guide for Cloud Workload Protection Platforms）。青藤云安全与微软、McAfee、赛门铁克等国际知名安全公司并列，第三次成功登上了此次指南。

![](../Images/0a01f5f974cee374e0a58f00e885a32b.png)

Gartner作为全球最具权威的IT研究和顾问咨询公司，Gartner分析师每年都在数千家企业中挑选行业中的“创新者”和“颠覆者”。作为一家仅成立4年的公司，青藤云安全已经三次进入这个世界级的公司名录，这是对青藤在业务端安全领域技术实力的认可。同时，也体现出青藤的产品和理念不仅在国内受到认可，在国际的赛道上也位居前列。  

![](../Images/c6afbd96a11fc5bd8f7d331b4599c583.png)

从最初自适应安全落地时的备受质疑，到今年第三次入围Gartner全球云安全市场指南，青藤云安全证明了自己一直奔跑在对的道路上。相信未来青藤云安全会继续提升自身安全与技术能力，为全球网络安全贡献中国力量。

\-The End-

关于青藤云安全

青藤云安全以服务器安全为核心，采用自适应安全架构，将预测、防御、监控和响应能力融为一体，构建基于主机端的安全态势感知平台，为用户提供持续的安全监控、分析和快速响应能力，帮助用户在公有云、私有云、混合云、物理机、虚拟机等多样化的业务环境下，实现安全的统一策略管理，有效预测风险，精准感知威胁，提升响应效率，全方位保护企业数字资产的安全与业务的高效开展。
