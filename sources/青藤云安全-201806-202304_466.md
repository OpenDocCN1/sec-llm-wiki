# 喜报|青藤云安全荣获2018北京软件高成长企业TOP20

11月28日，北京软件和信息服务业协会第九届会员代表大会第二次会议在北京新世纪日航饭店举行。活动现场，北京软件和信息服务业协会发布了2018北京软件高成长企业报告。会上宣布，青藤云安全（北京升鑫网络科技有限公司）荣获2018北京软件高成长企业Top20。

![](../Images/f0a26535cc67b9ca8790ceadb968fdb4.png)

2018北京软件高成长企业报告聚焦于北京市快速成长型软件企业，旨在通过此次活动发掘一批北京软件信息服务业的高成长企业，它们既反映出这个时代特征和软件行业“快”的特点，还能反映出公司的活力、创新和发展。  

报告由北京软协副会长刘古权发布，依据会员企业提交的参报数据和公开材料，设定3年平均收入增长率大于30%和近一年研发投入大于300万为准入门槛，对企业近3年营业收入（50%）、研发投入（30%）、利润（20%）三个相关指标进行量化计算，经过专家评审，最后确定出北京软件高成长企业。

获奖企业均为北京软件高成长企业，均在高成长的领域，有好的商业模式，具备很强的技术创新及强大技术背景。满足营业收入高速增长且规模过亿、研发投入强度高且投入持续性好、利润率高且利润丰厚且企业在垂直领域不断做深做实做细等特质。

**关于青藤**

作为下一代主机安全领跑者，青藤云安全以服务器安全为核心，采用自适应安全架构，将预测、防御、监控和响应能力融为一体，构建基于主机端的安全态势感知平台，为用户提供持续的安全监控、分析和快速响应能力，帮助用户在公有云、私有云、混合云、物理机、虚拟机等多样化的业务环境下，实现安全的统一策略管理，有效预测风险，精准感知威胁，提升响应效率，全方位保护企业数字资产的安全与业务的高效开展。

自2014年创立以来，青藤云安全已经连续获得真格基金、宽带资本、红点创投、红杉资本等资本机构近3亿元投资。业务覆盖了银行、保险、证券、基金、互联网、政府等数十个领域，防护服务器超过百万台，且在大型集团客户的核心服务器中，稳定不间断运行超过26000个小时。

青藤云安全于2017年，成为首家入选《Cool Vendor in Cloud Security》的安全创业公司，并于于2017年，2018年连续两年作为中国唯一安全公司入选Gartner CWPP全球安全指南。
