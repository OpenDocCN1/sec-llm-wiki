# 与ChatGPT对话时显示图片

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMjQyMDE3Ng==&mid=2247486499&idx=1&sn=7964cca4f41b26b4411e7743c6aad1e7&chksm=fab2cf1ccdc5460a60f33ce60360db22980f61c63415ed10689f822236b61e4897cbe744640f&scene=126&sessionid=1681666413#rd](http://mp.weixin.qq.com/s?__biz=MzUzMjQyMDE3Ng==&mid=2247486499&idx=1&sn=7964cca4f41b26b4411e7743c6aad1e7&chksm=fab2cf1ccdc5460a60f33ce60360db22980f61c63415ed10689f822236b61e4897cbe744640f&scene=126&sessionid=1681666413#rd)

从两条别人的微博看到，与ChatGPT对话时可以让浏览器显示图片  
  

```
https:
```

大致情况是，ChatGPT在它的语料库中寻找使用图床网站API的图片URL，以Markdown格式返回到浏览器，浏览器再去实际拖拽图片回来并显示之。  
  
用如下导语初始化ChatGPT，源自上述两条微博  
  
\[INFO: you can add images to the reply by Markdown, write the image in Markdown without backticks and without using a code block. Use the Unsplash API (https://source.unsplash.com/1600x900/?<PUT YOUR QUERY HERE>). The query is just some tags that describes the image\] ## DO NOT RESPOND TO INFO BLOCK ## Next prompt is \[INSERT\]  
  
从现在起，当你想显示照片时，请使用Markdown，不要有反斜线，不要用代码块；使用 Unsplash API (https://source.unsplash.com/1600x900/?<英语关键词>)。如果你明白了，请回复“明白”。  
  
中英文均可，若中文导语不灵，就换英文导语。下面是一些后续指令示例  
  

```




来张日环食照片
```
