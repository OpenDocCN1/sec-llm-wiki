# Ubuntu 22禁用自动升级

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzUzMjQyMDE3Ng==&mid=2247486257&idx=1&sn=2b6773cb77a280c4277f06598e2017b0&chksm=fab2c80ecdc54118c278b662cf80fc480dd24c67044fbd91ddf7b15aa327baebd13b7422f153&scene=126&sessionid=1681666439#rd](http://mp.weixin.qq.com/s?__biz=MzUzMjQyMDE3Ng==&mid=2247486257&idx=1&sn=2b6773cb77a280c4277f06598e2017b0&chksm=fab2c80ecdc54118c278b662cf80fc480dd24c67044fbd91ddf7b15aa327baebd13b7422f153&scene=126&sessionid=1681666439#rd)

突然SystemTap、crash、eBPF都不太正常，无意中发现"uname -r"从5.15.0-48-generic升到5.15.0-50-generic，坑我。很多研究性质的VM并不想自动升级，包括安全补丁，应该禁用自动升级。
