我出个小题。问，OS是Win10，在不动用"\\\\?\\"前缀的前提下，如何不依赖任何第三方工具只利用系统自带命令，在NTFS分区上创建名为"AUX"的目录？向AUX目录复制PE，执行位于AUX目录的PE，查看AUX目录，删除AUX目录。标准答案在凌晨的公众号上见，有兴趣的还有几个小时可以做。  
  
☆ 名为"AUX"的目录 (小实验)  
  
1) 创建目录  
  
mkdir "AUX\\"  
  
注意最后这条命令，"AUX"之后有个反斜杠"\\"  
  
2) 访问目录  
  
echo | set /p="foo bar blahblah" > "AUX\\foo.bar"  
  
dir /R /S "AUX\\"  
  
type "AUX\\foo.bar"  
  
more < "AUX\\foo.bar"  
  
copy /y "AUX\\foo.bar" foobar.txt  
  
del "AUX\\foo.bar"  
  
没有找到进"AUX"目录的办法，无论是cmd还是资源管理器  
  
3) 执行"AUX"目录中的PE  
  
copy /y calc\_xp.exe "AUX\\calc\_xp\_other.exe"  
  
"AUX\\calc\_xp\_other.exe"  
  
4) 删除目录  
  
rmdir /s /q "AUX\\"  
  
5) 资源管理器  
  
资源管理器无法进"AUX"目录，无法删除"AUX"目录。  
  
为了删除"AUX"目录，cmd中rmdir /s /q "AUX\\"最省事。
