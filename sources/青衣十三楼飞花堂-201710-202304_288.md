# 四季更迭，又到了送人上路的季节

最近删了几个以前的同事。说是前同事，其实也没真打过交道，后来别个加，就通过了。只要有一丁点香火情，我一般做不出太过拒绝的事。然后就进入了长久的双向静默期，大家都懂的吧。无怨无仇，但也无情无谊，这种我是留着让人窥私吗？  
  
也不是所有双向静默的都会被我单向删除。有个前同事兼师弟，嗯，院校合并前的正经师弟，从入学年份上排的师弟，上大学时没有过时间交集，但后来相遇在NS，线下也朝过面，这种就算双份香火情了。以前微信联系人少，刚开始加时没用过备注，时间一长，忘了ID与活人的映射关系。有年清理微信联系人时，咣唧，以为是路人甲，把他误删了。转瞬激活了备份记忆，颠颠地加回来，说了咋回事。师弟回消息说，四哥，下手轻些～  
  
我是个交游非常不广泛的人，没有非常强烈的社交爱好，凭感觉交友。若是觉得某人可交，即便多年双向静默也无所谓，终有再见之日。自打这次误删后，开始启用微信的备注，每次新添加联系人，必备注，一个永久有效的映射。所以后来的单向删除，没有一个是误删，都是有意识地定向精准删除。  
  
我见过最奇葩的一次前同事的添加请求，他假设我知道他的现公司以及现ID，没有任何初次相遇时的礼节性自我介绍，总共四个字，我不复述了。像这种有过香火情的，即便我不喜欢TA，也不太打脸打得这么直接。那我是怎么对上号的呢？当时没有选通过，也没有选拒绝，只是人工忽略了这个请求。又过了很久，在通过其他请求时，注意到曾经的请求残像，这次我脑补了一下，然后问了问前NS马三、前TSRC负责人马总、前同盾马院长、前南京一霸红衣马大妈。众所周知，红衣马大妈是个江湖交游广泛的人，接下来我就知道前面那个人是谁了。心里一万头羊驼奔过，你这个ID很有名吗，已经到了人尽皆知的地步，假设是个人收到后都知道你个5B是谁？这得是狂到什么程度才有这种假设的，亦或是情商着实不高？  
  
这个事例让我想起TK跟我说过的另一件事。具体哪年我不记得了，有个当时很有名的搞安全的，姑且用张三称之吧，与TK相逢在某个安全会议上。张三走过去跟TK朝面，没有任何初次相遇时的礼节性自我介绍，直接开聊，聊些有的没的，好像双方是老熟人的样子，TK一头雾水。张三终于发现事情有些不对头，问TK，你不认识我吗，你不知道我是谁吗？TK心说，你谁啊，我应该认识你吗？大意如此。你瞧，张三这就是典型的自我认知失调，估计平日里接受吹捧多了，真地有些找不着北。说起来我倒是知道这个张三，当然，从未打过交道，亦未朝过面。  
  
不要加我微信，加也白加，因为有一天我无声无息地就把你删了，凭感觉单向删除。真地没有社交爱好，不维系过于复杂的社交关系。若是发现自己被删了，相互遗忘就好了。  
  
不渴而饮、四季交配，又到了博马舍胡说八道的季节。哦，不对，是四季更迭，又到了送人上路的季节。
