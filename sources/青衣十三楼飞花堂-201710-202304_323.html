c) 假设答案是"…"，那么有两组SHA256验证集

sth = hashlib.sha256()
sth.update(b"...")
sth.hexdigest()

634d3f95e2c1b43ba54f4374616549552b2ea0be80cd67cee8b118886f5fbe9a

import hashlib
sth = hashlib.sha256()
sth.update(b"..."+b"202110012150")
sth.hexdigest()

0b0b70ec088918e2f2b1412c7a775eacd637a05e1f803628ea620c8450b293bf

因为用自然语言描述，答案"…"有潜在歧义，但通过这两组SHA256验证集可以消除潜在歧义。

d) 为了不破坏TA人解迷乐趣，这样反馈迷题答案

import hashlib
sth = hashlib.sha256()
sth.update(b"..."+b"<your time>")
sth.hexdigest()

反馈你解迷成功时的12位时间戳及上面这个SHA256，不要直接反馈答案"…"。
