标题: XOR相关的趣味数学题(1)

本题不是给小白们做的，莫要莽撞。

```

$ xxd -g 1 example.txt
```

假设example.txt是明文信息，xorkey.txt是4字节的xorkey，用后者对前者进行异或加密得到example.txt.enc。

```

$ xxd -g 1 example.txt.enc
```

上面是简单举例，以说明基本概念，下面是本文题目。

已知secret.msg是一段英文文章，用64字节的xorkey对之进行异或加密得到secret.msg.enc。

```

$ xxd -g 1 secret.msg.enc
```

假设你通过某种技术手段从secret.msg.enc反推出明文版secret.msg.guess，对于人类来说，阅读后者内容可以从中析取出一段"敏感信息"。提问，这段"敏感信息"是什么，你花了多长时间找到它的？

注意，没有更多辅助信息可提供，求解本题的必要信息已在前文给完。不挖坑，求解本题所消耗的计算资源是PC可承受的，虚拟机就可以。
