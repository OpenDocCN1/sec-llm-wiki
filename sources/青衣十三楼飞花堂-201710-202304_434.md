# x64/FreeBSD 10.3/12.0中lsof的替代方案

现在用FreeBSD的很少，估计比SPARC/Solaris多点。  
  
在\*nix中经常用lsof查看网络端口与进程之间的关联。Linux的netstat有增强，-p参数会显示进程信息。  
  
在FreeBSD 10.3/12.0中欲达此目的，仍然可以使用lsof:  
  
$ pkg install lsof  
$ lsof -lnPR -i  
$ lsof -lnPR -i4  
$ lsof -lnPR -i TCP  
  
有时没有条件安装、使用lsof，只能寻找其他替代方案。  
  
1) sockstat  
  
FreeBSD 10.3/12.0有个sockstat:  
  
$ sockstat  
$ sockstat -4 -l  
$ sockstat -4  
  
2) sockstat.pl  
  
在FreeBSD 4.x时sockstat还是个perl脚本，从5.x起变成ELF了。如果系统被裁剪过而没有ELF版sockstat，可以去下载perl版sockstat.pl:  
  
http://sources.freebsd.org/releng/4.9/usr.bin/sockstat/sockstat.pl  
  
$ perl sockstat.pl  
$ perl sockstat.pl -4  
  
3) 手工模拟sockstat.pl  
  
裁剪过的系统很可能没有perl解释器，此时sockstat.pl也不能用。可以尝试手工模拟sockstat.pl，下面解释一下sockstat.pl的内在原理。  
  
下面用到的fstat、netstat、awk都是系统自带工具。  

  

![](../Images/587cd7ac20e3b3f69dc169d6c6c3e75b.png)

  

![](../Images/d786a87c3effbb669014aeb9b2c7c172.png)

  
fstat输出的最后一列是进程用到的协议控制块(PCB)，netstat的-A参数使得第一列输出对应PCB。以PCB为key求fstat、netstat输出的交集即可。  

  

![](../Images/9e3efc267662ae24487a9799220c1c43.png)

  

上图最后一条命令是:

  

awk 'NR==FNR{xxx\[$8\]=$0;next}$1 in xxx{printf("%s    %s\\n",substr(xxx\[$1\],1,25),substr($0,18));}' fstat.txt netstat.txt  
  
awk方案没有处理多个PCB一样的情形，最后一个PCB所在行被留存。  
  
4) procstat  
  
FreeBSD 10.3/12.0有个procstat:  
  
$ procstat -f -a | grep " s -"  
$ procstat -f -a | grep -E " (TCP|UDP) "  
$ procstat -f <pid> | grep -E " (TCP|UDP) "
