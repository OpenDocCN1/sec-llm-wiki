# 我也想当安全圈申典启？

来谢不邀，人在欧洲，没下火车。有段时间没更了，车上无聊扯会儿淡。  
  
最近润的话题热度回升，俨然成了流量密码。朋友说我成天写些穷酸技术文章，搬运别人的成果，要么就是流水账，大家都没耐心看下去。反正现在在外面浪，不如当月亮圆博主。

  

实在不行吃播旅游也比那些代码有意思。备选思路有鼓吹国外的 work life balance，低成本获得更好的生活质量，空气香甜等，“拉踩”一下。然后接下来这篇文章的走向应该是：  
  
1\. 介绍工作和生活，开始招人  
2\. 发旅游照拉仇恨  
3\. 散播焦虑，宣传 Java 的重要性，开始卖课  
4\. 宣传月亮圆和学外语，开始卖课  
  
不不不，没课卖，卖惨要不要？  
  
去年夏天搬过来之后，虽然充满了各种不便，生活还是很快适应了。中途穿插各种大小碰壁插曲，体验一些机构低下的办事效率等。  
  
本着不测就是没有的理念，不敢说没中，至少现在没测出来过。我一直自闭到今年二月，终于熬到了 OffensiveCon，心一横去了趟柏林，线下参会。侥幸没发生什么事，终于战战兢兢开始后疫情时代出游。

  
你可能要问，我嘴上说一套，还不是跑到共存区，在这装 COVID phobic 呢？  
  
虽然暂时没阳过，类似 long COVID 几年前倒是体验过一次。当年大家都去打 p2o，我没机会去就算了，同一时间还突发气胸进了医院。肺部开刀之后在病房躺了一个月，之后疗养了很久。气短乏力呼吸困难，除了味觉嗅觉还在，其他症状都模拟了一番。出院后几个月楼梯都上不了，一年内没敢运动。亲身体验过，自然心有余悸。  
  
Omicron 最凶的那段时间门都不太敢出。朋友好几个先后中奖，而我好不容易苟到现在。夏天一到新增降了，下一波新变种出来之前先缓一口气，补偿一下疫情之前没怎么玩的遗憾。  
  
以前看偶像 byvoid 大佬的游记看的心痒痒，忍不住想能不能模仿一个低配版。草，怎么不学人上清华？为啥大佬能这么浪，每个周末换个国家玩。后来稍微研究了一下交通，发现还是 base 在德国的一些主要城市或者苏黎世最方便，无论火车还是飞机。看着收件箱里几个月前的 Hello from Google Recruitment Team，直感叹没缘分。

  

![](../Images/ae2deeb0f39789c69648e887ec0e76c6.png)

  
欧洲旅游确实方便，申根区说走就走。

很多廉航和火车，也有睡一觉第二天在陌生国家醒来的夜班火车，能同时节省机票和住宿的钱，适合我这种穷鬼。

实际上交通都是毛毛雨，花销的大头在住宿，哪怕是 Airbnb 也不便宜。

  
所谓的后疫情时代，旅游体验依旧是打折扣的。想到这又开始掐大腿，之前有机会出去开会也不知道自费多转几个国家。现在倒是彻底不需要折腾投稿了，想去就买票，别再给人白送 0day 思路了。

  
说到 work life balance，几个月体验下来确实比国内清闲不少。当然可能也有疫情远程办公的原因。其实完全可以找个 Airbnb 每星期换个地方工作，总觉得这么干太狂野了，循序渐进吧。

  
这两个月转了不少地方，打算先走马观花一遍，然后挑喜欢的深度游。

  
之前的文章说到我 zer0con 被签证坑了没去成。气不过扭头就订了去阿姆斯特丹的机票，故地重游，骗自己还活在 2019 年。和当地网友面基的时候听说正好当天有 ETHAmsterdam，v 神本人也到现场站台。

  

![](../Images/66b217e263ff54d340d8500e056ddee3.png)

  
实话说我看不懂也没太大兴趣，身体倒是很诚实，厚着脸皮跟网友刷脸进去看热闹。想着要是碰到 v 神就抱着大腿不让走：“您好我是学生能给我 2k 个 ETH 吗？”当然这段对话没有发生，最后是扫货一般进去白嫖了好几件文化衫和若干贴纸。

  

这个场地也是三年前 HITB 同款会场，彻底满足了我故地重游的心愿。

  

回去的时候贪便宜订的 RyanAir 从布鲁塞尔走。布鲁塞尔是我目前去过的地方里最无聊的城市，加上当天下大雨被淋了个透，体验糟透了。显然安特卫普更值得一去。

  
临近值机发现不对劲，原来布鲁塞尔有两个机场，我的票在 CRL，远得离谱，没有机场酒店。去的路上还能路过滑铁卢，真是好兆头呢。廉航之所以便宜，不但机场远，时间也是大清早。研究了一番只能在沙勒罗瓦过夜，然后赶一早五点的大巴。  
  
我在自助机上买机场大巴票的时候操作太快，加上触摸屏不太灵敏，买成了当天的车票。正要重新操作买一张新的，旁边来了个妹子问我这机器（同时还卖火车票）能不能订机场大巴的票。  
  
我一边操作一边告诉她可以，给她看了下票，说我买错日期了，正在重新操作。接着又复现了一遍 bug，果然触摸屏不好使，一通狂点才选中。这时我突然灵光一闪问她要买哪天的，答当晚的。不如我把这张转手给你吧？对方愉快地同意了。我这就当了一回黄牛。

  

之后还特地去了几个电影的取景地。

这周末在前奥匈帝国的地盘上打卡。

  

![](../Images/d6f20615f8d1a9d35ce47244e7c7b6db.png)

  

日程定的匆忙，没细看火车时间，搞到我在布达佩斯起床后只能逗留五六个小时，就得赶车去下个目的地。如果时间允许其实这一次也可以找人面基，下次再来一趟吧。

  

坐个火车几小时换个国家的体验，对我这种零留学经历，疫情前也没怎么旅游过的土鳖实在太有趣了。  
  
最近一年躺得非常彻底。可以说被疫情彻底改变了心态，活在当下。  
  
几年前互联网行业努力点还有盼头，现在红利期过了，新的一些玩法实在也看不懂。我对甲方的 PR 导向漏洞研究也一直不看好，资源富余的时候可以养闲人，现在可说不定。攻防研究本来就需要一直跟上前沿，长期来说挖洞这事一不小心被淘汰的概率不小，一旦到时候做不动，又长时间脱产……  
  
反正人只能挣到自己认知范围内的钱，何苦牺牲自己的身体和心理双重的健康做无用功，干脆跑到红利期过得更彻底的老牌资本主义国家摆烂。本该最高工作效率的时候拿来躺平，虽然多了很多空闲时间，但是失去了成长的机会呀。
