Phrack 在经历了数年跳票之后终于放出了第 70 期。

  

始创于 1985 年的 Phrack 杂志是信息安全圈一本经典的网络出版物，每期都是干货非常硬的文章合集。经典的 Smashing The Stack For Fun And Profit 也是其收录的文章之一，还有我个人特别喜欢的两篇讲 Objective-C Runtime 利用的文章。

一看就知道这一期的文章攒了好几年，真不容易。Attacking JavaScript Engines 几乎成了 2016 年之后浏览器漏洞利用的模版，addrof 和 fakeobj 都成了固定套路。

  

这次首发的文章，也是个人认为非常具有亮点的一份研究，是罗马尼亚安全研究员 xerub 的 The Bear in the Arena。信息量太大，我到现在也没读完。

  

光看标题很难猜到是什么内容。这篇文章主要介绍 Security.framework 里解析 ASN.1 的漏洞和利用，可以通过恶意的证书触发，影响 macOS 和 iOS。

  

xerub 在文章中实现了一整套利用，可以通过 USB 物理连接在锁屏的手机上执行任意代码，甚至支持 Before First Unlock（BFU，开机后未输入密码的状态）。当然，由于 64 位手机之后都支持 SEP，BFU 代码执行并不等于锁屏密码破解和数据解密。但如果手机没重启过，就能访问到相当多的数据。
