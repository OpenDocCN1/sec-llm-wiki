今年的 BlackHat USA 上有不少来自中国大陆的议题。本文要自吹的是这篇 Hack Different: Pwning iOS 14 with Generation Z Bugz。


据维基百科，所谓 Z 世代（Generation Z）就是大约在 1995 年和 2012 年间出生的一代人。议题中提到的两个关键漏洞分别由 iOS 3（2009 年）和 iOS 6（2012 年）引入，又和他（她）们一样在 2020 年这个有些特殊的年份受到关注，所以就蹭了这个名字。


2020 年的天府杯是继 iPhone XS（A12 芯片）推出 Pointer Authentication Code 之后，全世界首个实现公开破解 iPhone 项目的安全比赛。一共有两支队伍分别用不同的漏洞链条远程破解了搭载 iOS 14.2 的 iPhone 11，都绕过了硬件级的安全防护。


这篇议题便是介绍其中一个项目的细节和利用技巧。这个项目由于其漏洞隐藏的历史惊人的长，利用技巧与传统 WebKit 大相径庭，有幸被评上了最具价值产品破解奖。


前几天的 MOSEC 上，趁 BaijiuCon 环节我上台做了个预告，讲了一小部分内容，还是有点遗憾没能把完整的议题在国内首发。


这一小部分内容是一个从 iOS 3 就引入的客户端 xss。这个漏洞完全不用任何内存破坏，甚至不需要初始的 shellcode 执行即可直接绕过浏览器沙箱。单纯使用特殊的 URL 触发 xss 弹计算器，百分百稳定。


漏洞除了默认浏览器，还可以通过 AirDrop 触发。如果接收了陌生人恶意的 AirDrop，在 iOS 14.3 和以下版本就可以直接获取手机号等隐私信息，当然还可以顺带弹一个计算器。一不小心就交出手机号（约等于微信号）了，还是比较恐怖的。具体 PoC 不会放出，但仍然建议大家升级到系统的最新版本以防护自己的隐私安全。


在天府杯的演示自然没有止步于此。弹计算器只是传统，而比赛是要求实现本地代码执行和绕过 PAC 的。


除了纯逻辑的信息获取之外，这个特殊的漏洞还打开了一个特别大的攻击面，让任意的 WebKit 漏洞，无论是否与 just-in-time 有关都能被利用，并在一个沙箱限制远小于默认 WebContent 渲染进程的上下文执行。


脚本会在一个权限很高、带有额外功能的 WebView 当中运行，类似 Android 上被玩坏的 addJavaScriptInterface。由于错误的访问控制，一些本不应该被 js 访问的方法被放行。接下来构造出一系列的类型混淆、地址泄漏、释放后重用和 double free，最终结合多个 Objective-C 的运行时特性实现任意函数调用，最终绕过 PAC 和 APRR 加载了任意的 shellcode。



有条件的话可以直接在 BlackHat USA 听。这个议题将在北京时间八月 5 日清晨 6:20 开始。
