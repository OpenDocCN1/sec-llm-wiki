# 提取已知密码 iTunes 备份中的文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzk0NDE3MTkzNQ==&mid=2247483935&idx=1&sn=02d3502b8bc0054cd1d743de88214fd5&chksm=c329fceff45e75f946c99a523c9062fe8bb47eb7f9d5501454afe1a2df8817bbdd4a1b9de781&scene=126&sessionid=1681657511#rd](http://mp.weixin.qq.com/s?__biz=Mzk0NDE3MTkzNQ==&mid=2247483935&idx=1&sn=02d3502b8bc0054cd1d743de88214fd5&chksm=c329fceff45e75f946c99a523c9062fe8bb47eb7f9d5501454afe1a2df8817bbdd4a1b9de781&scene=126&sessionid=1681657511#rd)

这两天在逆向一个 App 的功能，需要收集一些使用了一段时间后的手机数据样本。主力机暂时没有越狱环境，就先尝试直接在越狱设备上用 iCloud 同步，再用 SSH 直接导出来。可惜事与愿违，同步速度非常慢。

  

正好前几天在电脑上做过一次整机备份，就想试一下有没有现成的解密工具——那么为什么不直接恢复到越狱机上呢？因为备份要求版本不能低于原来的机器，而之前的太新了。

  

网上找到的方案有一些第三方个人设备管理辅助如 iMazing、iPhone Backup Extractor，或者满足专业需求的数据取证方案如 Elcomsoft Phone Breaker。都要掏钱。

  

iTunes 备份用的是 lockdown 的接口与设备的 idevicebackup2 服务通信。第三方手机管理软件也一样。关于 lockdown，之前的文章也略微提到过一些：[frida 与 iOS lockdown 交互](http://mp.weixin.qq.com/s?__biz=Mzk0NDE3MTkzNQ==&mid=2247483878&idx=1&sn=65f57920a9ca5c7514dba3ba449f70c0&chksm=c329ff16f45e76006a99f7af808dcfe2199eedeb9259dd883ff336622360114c5f61fb12682b&scene=21#wechat_redirect)

  

开源项目 libimobiledevice 就有 idevicebackup 和 idevicebackup2 命令（分别对应 iOS < 3 和更新版本），协议细节可以查看其源码：

  

https://github.com/libimobiledevice/libimobiledevice/blob/master/tools/idevicebackup2.c

  

为了保护数据安全，iTunes 备份时强制要求用户设置一个密码用于生成加密密钥，否则备份会跳过一些内容。  

  

在 macOS 上，备份的文件储存在如下目录  
~/Library/Application\\ Support/MobileSync/Backup

  

备份是我做的，所以密码已知。而我的需求就是提取其中特定路径的文件内容。iMazing 的文档称支持此功能。已知 iMazing 用到了 libimobiledevice，以此推断解密文件肯定有对应的开源实现。

  

* * *

  

本着抠门不想花钱的出发点，我打开了搜索引擎，果然找到了宝贝：

  

*   http://conference.hackinthebox.org/hitbsecconf2011ams/materials/D2T2%20-%20Jean-Baptiste%20Be%cc%81drune%20&%20Jean%20Sigwald%20-%20iPhone%20Data%20Protection%20in%20Depth.pdf
    
*   https://github.com/jsharkey13/iphone\_backup\_decrypt
    

  

解决方案到这里已经有了，直接下载安装这个 GitHub 上的 Python 库：

*   
*   

```
pip install biplist pycryptodome fastpbkdf2 # 依赖pip install git+https://github.com/jsharkey13/iphone_backup_decrypt # 解密库
```

  

然后调用

*   
*   
*   
*   
*   
*   

```
from iphone_backup_decrypt import EncryptedBackup, RelativePath, RelativePathsLike
backup = EncryptedBackup(backup_directory=backup_path, passphrase=passphrase)# Extract the call history SQLite database:backup.extract_file(relative_path=RelativePath.CALL_HISTORY,                     output_filename="./output/call_history.sqlite")
```

  

即可将其中的通话记录调取出来。同理可以提取其他路径的文件。

  

* * *

  

这个库的原理来自 2011 年，在阿姆斯特丹的安全会议 HITB 上的主题演讲：iPhone data protection in depth。其介绍了 iPhone（当时还是跑着 iOS 3 和 4 的 3GS）的数据保护实现，例如数据分区的加密实现，如何从锁屏密码生成加密密钥等。

  

![](../Images/a22303a42d9427c6730ea634dee94ff0.png)

  

从 47 页开始详细介绍了 iPhone 备份文件的格式和密钥生成规则。

  

不过这居然已经是十年前的文档了，自然有一些内容已经过时。比如 Manifest.mbdb, Manifest.mbdx 两个文件变成了 Manifest.db，直接嵌入了一个加密过的 SQLite3 数据库来记录文件的相对路径、元数据和 AES 加密密钥。

  

![](../Images/e5bbb7c402dc0d0a6c471f001147cfb0.png)  

这个 Python 库的代码加起来一共不到五百行，想详细了解备份的 KeyBag 机制和密钥生成算法可以阅读一下。主要有 pbkdf2 和 AES。笔者目前还沉浸在省下买软件的钱的嘚瑟中无法自拔，就不装腔作势分析一遍了。
