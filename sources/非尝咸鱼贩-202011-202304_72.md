因此至少需要 hook 三个方法：

  

*   \-\[SUDescriptor publisher\]  出品方
    
*   \-\[SUDescriptor humanReadableUpdateName\] 系统的名字和版本
    
*   \-\[SUDocumentation releaseNotesSummary\] 更新日志的 HTML  
    

  

系统更新服务内部用到了 iOS 的 Assets 框架。这是一个用来分发 OTA 更新的私有库，除了操作系统的升级包之外还有很多动态下发的资源包，例如一些语音合成、词典等五花八门的文件。

  

iOS 请求更新之后会下载一小部分元数据到如下目录，解压为 \[随机 UUID\].asset 子目录  

  

/var/MobileSoftwareUpdate/MobileAsset/AssetsV2/com\_apple\_MobileAsset\_SoftwareUpdateDocumentation

  

asset 里面就是多语言国际化过的许可信息、更新日志等 HTML 文件：

  

./546d54a246970a7179b48e842d3de5a604f20aa9.asset/AssetData/zh\_CN.lproj/License.html

./546d54a246970a7179b48e842d3de5a604f20aa9.asset/AssetData/zh\_CN.lproj/ReadMeSummary.html

./546d54a246970a7179b48e842d3de5a604f20aa9.asset/AssetData/zh\_CN.lproj/documentation.strings

./546d54a246970a7179b48e842d3de5a604f20aa9.asset/AssetData/zh\_CN.lproj/ReadMe.html

  

\-\[SUDocumentation releaseNotesSummary\] 方法从 ReadMe.html 中读取一次数据，之后会缓存到内存的一个 NSMutableDictionary 里。为了与原始的更新日志风格一致，可以参考原版的 HTML 文件。

  

至于这个方法从哪里读取的内容其实不重要，我们只要直接在上层调用把 HTML 返回值替换掉即可。需要注意这个方法的返回值是个 NSData 而不是 NSString。
