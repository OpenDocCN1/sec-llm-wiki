Cellebrite 旗下产品 Physical Analyzer（https://www.cellebrite.com/en/physical-analyzer/）以“作为业界标杆的数字数据检查技术（The Industry Standard for Digital Data Examination）”闻名。但现在他们突然宣布停止支持 iPhone 的数据提取。


此前 Cellebrite 因为发布了一篇解密 Signal 数据库的文章，被媒体曲解为 Signal 通信加密被破解。Signal 方面作为回应，首先抨击了报道的谬误，在数月之后再次发声，演示了通过恶意的 app 数据攻击 Physical Analyzer 的安全漏洞执行任意代码。Signal 还表示其中为了访问 iPhone 数据而包含了来自 Apple 的设备支持库，可能存在版权问题。


Cellbrite 近期发布了 UFED 和 Physical Analyzer 的版本更新：


This message is to inform you that we have new product updates available for the following solutions:


Cellebrite UFED v7.44.0.205

Cellebrite Physical Analyzer v7.44.2

Cellebrite UFED Cloud v7.44.2


Cellebrite UFED 7.44.0.205 and Cellebrite Physical Analyzer 7.44.2 have been released to address a recently identified security vulnerability. This security patch strengthens the protection of the solutions.


As part of the update, the Advanced Logical iOS extraction flow is now available in Cellebrite UFED only.


在公告中提到修复了数个安全漏洞。此外还提到了 iOS 逻辑镜像提取功能在 Physical Analyzer 中被停止支持，仅通过 UFED 软件提供。


Physical Analyzer 应该就是 Signal 文章中“从卡车上掉下来，散步时无意中捡到”的设备：



相信此举是为了规避捆绑 Apple 相关驱动程序所带来的法律风险。


不过这仅仅是停止支持在 Physical Analyzer 上直接获取 iPhone 数据。实际上仍然可以在别的设备上自行安装 iTunes 获取逻辑备份，或者使用 UFED，然后再将数据导入到 Physical Analyzer。


以前只见过安全厂商用漏洞做 PR 的。这反过来被 PR，还差点连累自家产品线业务，爽文一般的反转还是少见。
