```

```

**参数解释** become: yes #是否允许身份切换 become\_method: su #切换用户身份的方式，有sudo、su、pbrun等方式，默认为sudo become\_user: root #切换指定的用户

phil 用户执行命令**ansible-playbook 1.yml**可以直接拿到 root 的 shell。
