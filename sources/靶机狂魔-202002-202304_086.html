于是这次将我的全部copy过来，一个个工具到mac下调试到完美环境

今天先它RED_HAWK

一款终端下针对PHP整合简单信息搜集和漏洞扫描的二合一工具

 https://github.com/Tuhinshubhra/RED_HAWK

此工具需要先安置php环境

mac下包管理工具是homebrew,这个的安装不赘述了 我们一步步来走

xcode-select --install

接下来梳理brew当前环境

brew updatebrew upgradebrew cleanupbrew doctor

拆掉原来的所有php相关，再梳理brew资源

brew list | grep phpbrew uninstall --force $xrm -rf /usr/local/Cellar/phprm ~/Library/LaunchAgents/homebrew.mxcl.php*sudo rm /Library/LaunchDaemons/homebrew.mxcl.php*ps ax | grep phpbrew cleanupbrew doctor

执行安装php

brew install php 如果是其他版本，如下命令即可

brew install php@5.6brew install php@7.0 brew install php@7.1

以上安装完后，执行type php来验证当前安装的是不是正确的homebrew下的php，如果回显/usr/local/...anything.../php那么就对了，如果回显/usr/bin/php那就还没部署到位，我们brew doctor一波即可自动修复

多版本的话如下命令进行切换

brew unlink php@7.2brew link --force --overwrite php@5.6brew doctorphp -v
brew unlink php@5.6brew link --force --overwrite php@7.2brew doctorphp -v

通过PECL可以安装php扩展

pecl install xdebugpecl install imagick

查看版本php -v查看扩展php -m

打完收工
