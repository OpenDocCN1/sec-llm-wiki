模块介绍

1. Directories and Files

rustbuster dir -u http://localhost:3000/ -w examples/wordlist -e php -t 10

2. A/AAAA DNS Entries

该dns模块可用于发现给定域的子域。它的工作原理是简单地要求您的默认DNS解析器解析潜在的主机名，并报告成功解析的主机名。

rustbuster dns -d google.com -w examples/wordlist

3. Vhost Enumeration

该vhost模块可用于枚举Web服务器上可用的虚拟主机。它通过使用给定的单词列表对Host HTTP Header进行模糊处理，并通过检查-x,--ignore-string响应的HTTP正文中提供的参数的存在来过滤结果来进行工作。

rustbuster vhost -u http://localhost:3000/ -w examples/wordlist -d test.local -x "Hello"

4. Custom Fuzzing

fuzz当需要更灵活的模糊模式时，可以使用该模块。您可以定义注入点和每个注入点的单词表。将生成请求的cartesian product。还支持CSRF令牌！在下面的示例中，我们将强制执行一个登录表单，该表单需要为每个请求使用不同的CSRF令牌，可以通过应用RegEx提取该令牌。

rustbuster fuzz -u http://localhost:3000/login \    -X POST \    -H "Content-Type: application/json" \    -b '{"user":"FUZZ","password":"FUZZ","csrf":"CSRFCSRF"}' \    -w examples/wordlist \    -w /usr/share/seclists/Passwords/Common-Credentials/10-million-password-list-top-10000.txt \    -s 200 \    --csrf-url "http://localhost:3000/csrf" \    --csrf-regex '\{"csrf":"(\w+)"\}'

5. IIS 8.3 shortname enumeration mode

该模块可用于利用与Microsoft IIS和DOS 8.3文件名有关的已知信息泄露问题，从而可以轻松枚举服务器端文件系统结构。

rustbuster tilde -u http://localhost:3000/ -e aspx -X OPTIONS
