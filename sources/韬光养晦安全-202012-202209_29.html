前言：说到apt研究，最强王者肯定非火眼公司莫属了，如果你说你对自己的技术很自信，想要去火眼工作，那需要满足什么样的要求呢？想要入职火眼，光有技术是不够的，你还要具备以下。


火眼红队招聘标准

职责：

  • Web和APP程序测试，代码审计，应用程序测试以及IOT测试

  • 能够完成安全报告和演示文稿

  • 有效地交流调查结果和策略

  • 熟悉常用渗透测试工具，分析和识别漏洞

  • 开发脚本，工具来增强火眼的应用程序渗透测试能力

  • 协助整个从渗透测试到漏洞修补的流程，指导经验不足的员工


资格

  • 在以下至少两项中具有4-7年的经验，或在以下一项中具有高于平均水平的能力：

    • Web应用评估

    • APP应用评估

    • 应用评估

    • 嵌入式设备评估（IOT）

    • 代码审计

    • 逆向工程

  • 其他技能或经验应包括以下四个或更多：

    • 参与黑客挑战，竞赛或漏洞赏金

    • 开发用于测试和分析的工具或插件

    • 相关的应用程序渗透测试认证，例如（OSWE）【科普：这是WEB渗透的认证】，GIAC Web（GWAPT）或等效的认证

    • 使用Perl，Python或Ruby进行自动化脚本编写

    • 用C＃，ASP，.NET，ObjectiveC，Go或Java（J2EE）开发应用程序

    • 逆向工程恶意软件，数据混淆或加解密

  • 具有针对不同应用程序类型和平台进行静态和动态分析方面的经验

  • 具有用于应用程序测试和不同平台测试的工具的丰富知识，包括用于静态和动态分析的工具

  • 全面了解网络协议，数据传输，客户端-服务器模型，应用程序设计和体系结构以及不同类别的应用程序安全漏洞

  • 精通Unix / Linux / Mac / Windows操作系统，包括bash或其他编程语言

  • 在没有赞助的情况下在美国工作

  • 计算机学位毕业优先


         ------好了，看完了------

总结一下，火眼的潜台词是什么

  1. 你至少得有计算机本科及以上的学位

  2. 在web、app、逆向、IOT这四个领域的其中一项有较强的渗透测试能力

  3. 你得有坚实的编程基础，这意味着你得熟悉至少两种编程语言，一个用来开发自动化脚本，一个用来代码审计

  4. 最好是与美国有关系的人（火眼的意思是，不会为你申请工作签证的）

  5. 熟悉常用工具，漏洞利用，横向渗透的能力

上面只是基础条件，问问自己，有没有满足至少四项

  1. 你玩SRC或者CTF吗？

  2. 你会开发红队工具吗？

  3. 你考证了吗？

  4. Perl，Ruby，Python精通哪一个？

  5. C＃，ASP，.NET，ObjectiveC，Go或ava（J2EE）精通哪一个？

  6. 会逆向和混淆免杀吗？
