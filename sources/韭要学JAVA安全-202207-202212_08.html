通常再内网上传中，会遇到很多限制，当拿下目标主机拿到webshell之后发现只能上传几百kb的小文件，文件大点的就比如几M的就会无法上传

解决方法:

1.使用split

使用 split 以 500 K 大小分割 shell.exe 文件，split 命令在 Linux 和 MAC 下都是自带的，因此在自己的电脑上分割好后，直接上传即可。

实例:

split -b 500k shell.exe teamssix*

Linux：

windows:

copy /b teamssix* 1.exe
