# 如何突破内网上传大文件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=Mzg2NTgzMDg1NA==&mid=2247483753&idx=1&sn=e46ec2444611e2712ab46aa244d71a8d&chksm=ce5553c0f922dad639cbfa51e09b2bee5933041d9204b5c2e8d1082be3c1a4a6795c524b4668&scene=126&sessionid=1681655543#rd](http://mp.weixin.qq.com/s?__biz=Mzg2NTgzMDg1NA==&mid=2247483753&idx=1&sn=e46ec2444611e2712ab46aa244d71a8d&chksm=ce5553c0f922dad639cbfa51e09b2bee5933041d9204b5c2e8d1082be3c1a4a6795c524b4668&scene=126&sessionid=1681655543#rd)

**通常再内网上传中，会遇到很多限制，当拿下目标主机拿到webshell之后发现只能上传几百kb的小文件，文件大点的就比如几****M的就会无法上传**

**解决方法:**

**1.使用split**

**使用 split 以 500 K 大小分割 shell.exe 文件，split 命令在 Linux 和 MAC 下都是自带的，因此在自己的电脑上分割好后，直接上传即可。**![](../Images/d0a5a84509d7627a77bad1559756df8f.png)

**实例:**  

```
split -b 500k shell.exe teamssix\*
```

**Linux：**

![](../Images/0b9fac5dd94c9297559ad506e6be7fe3.png)

**windows:**  

```
copy /b teamssix\* 1.exe	
```
