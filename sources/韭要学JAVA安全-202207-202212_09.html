某天闲着无聊打开这个 无聊的时候结果发现 ，此次渗透测试非常的基础（大佬勿喷呜呜呜） 首先这个站就是 tp写的，简单了看下了看版本号发现是是 ThinkPHP V5.0.0 

这洞不就来了嘛......................................首先再某度找到了ThinkPHP V5.0.0的payload ，看了试了一下看看poc可以执行吗. 首先 科普一下:

条件一：获取Session保存文件路径 条件二:phpinfo页面查看 


结果发现可以RCE php版本是7.0.33版本 这就说明存在ThinkPHP V5.0.0 rce漏洞的啊,接下来可以尝试下session包含写shell.........然后使用蚁剑连上去 即可getshell ，尝试使用 session 包含的方法来 getshell，首先通过设置 session 会话并传入一句话木马，然后直接利用文件包含去包含 session 文件，tp5 的 session 文件一般都是在 /tmp 下面，文件名为 sess_sessionid（这个 sessionod 在 Cookie 里面）

写了一句话之后 再用session包含一下马子就可以getshell

发现写入了，执行了phpinfo也是可以使用的啊，那就连上蚁剑就可以了.............

直接拿下getshell之后 肯定这个是执行不了命令的 得绕过disable_functions接下来使用蚁剑的插件看看绕过

发现可以绕过disable_functions 那么接下来 反弹shell(出网) 看到机器是centos 使用4034 提权是没问题的 因为这个是宝塔会降权 

反弹shell成功 得用CVE-2021-4034 提权 首先进入根目录make编译一下然后就是./cve-2021-4034 提权拿下服务器

提权成功.............................................发现是root权限  痕迹清理走人................................ 此次渗透测试 非常的基础....
