某天闲着无聊打开这个 无聊的时候结果发现 ，此次渗透测试非常的基础（大佬勿喷呜呜呜） 首先这个站就是 tp写的，简单了看下了看版本号发现是是 ThinkPHP V5.0.0 

![](../Images/18278e83b93467dd02d070c1ad0b682d.png)

这洞不就来了嘛......................................首先再某度找到了ThinkPHP V5.0.0的payload ，看了试了一下看看poc可以执行吗. 首先 科普一下:

## 条件一：获取Session保存文件路径 条件二:phpinfo页面查看 

  

![](../Images/164817081b9ede3e9c6749dec0955338.png)

结果发现可以RCE php版本是7.0.33版本 这就说明存在ThinkPHP V5.0.0 rce漏洞的啊,接下来可以尝试下session包含写shell.........然后使用蚁剑连上去 即可getshell ，尝试使用 session 包含的方法来 getshell，首先通过设置 session 会话并传入一句话木马，然后直接利用文件包含去包含 session 文件，tp5 的 session 文件一般都是在 /tmp 下面，文件名为 sess\_sessionid（这个 sessionod 在 Cookie 里面）

![](../Images/5e6044e8684bf72419419d35a535a5fb.png)

写了一句话之后 再用session包含一下马子就可以getshell

![](../Images/544075a483f3a8b2df85ed8174a6626e.png)

发现写入了，执行了phpinfo也是可以使用的啊，那就连上蚁剑就可以了.............

![](../Images/fdc571f459d5b514fcde87c57b161985.png)

![](../Images/7e8d78e65d022ab1e87b94c891687f7c.png)

直接拿下getshell之后 肯定这个是执行不了命令的 得绕过disable\_functions接下来使用蚁剑的插件看看绕过

![](../Images/4e8951ad1e8d11abde167f52636821f5.png)

发现可以绕过disable\_functions 那么接下来 反弹shell(出网) 看到机器是centos 使用4034 提权是没问题的 因为这个是宝塔会降权 

![](../Images/164457c6ab43330d0414f5d750c7eab4.png)

反弹shell成功 得用CVE-2021-4034 提权 首先进入根目录make编译一下然后就是./cve-2021-4034 提权拿下服务器

![](../Images/e7ee593283a591557a52c1f71dcdf86a.png)

提权成功.............................................发现是root权限  痕迹清理走人................................ 此次渗透测试 非常的基础....
