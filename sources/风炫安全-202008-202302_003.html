我们先来看下维基百科对于NFT的解释

非同质化代币（英语：Non-Fungible Token，简称：NFT），是一种被称为区块链数位账本上的数据单位，每个代币可以代表一个独特的数码资料，作为虚拟商品所有权的电子认证或凭证。由于其不能互换的特性，非同质化代币可以代表数位资产，如画作、艺术品、声音、影片、游戏中的项目或其他形式的创意作品。虽然作品本身是可以无限复制的，但这些代表它们的代币在其底层区块链上能被完整追踪，故能为买家提供所有权证明。[1][2][3]诸如以太币、比特币等加密货币都有自己的代币标准以定义对NFT的使用[4]

2.3 修改智能合约

我这里已经写好了一个测试用的NFT智能合约的代码，地址是：https://github.com/fengxuangit/nftmetademo/blob/main/meta.sol。

这个是NFT发行的关键，我来简单的解释一下，写在注释里。

 bool public _isSaleActive = false; #表示是否准许售卖
  bool public _revealed = false; #盲盒开关，开启表示可以抽到不同的NFT

	uint256 public constant MAX_SUPPLY = 10; # 设定好NFT被挖掘出来最大的总量
  uint256 public mintPrice = 0.01 ether; #这个是用户每次铸造一个NFT的基本价格
  uint256 public maxBalance = 1; #表示每个钱包地址只能拥有一个
  uint256 public maxMint = 1; #这个是一次能挖掘的NFT的个数
  
  #构造函数，启动的时候，可以填入一些参数进去
   constructor(string memory initBaseURI, string memory initNotRevealedUri)
   	#的ERC721的两个参数。第一个参数表示NFT的名称，第二个是代号，
        ERC721("Fengxuan Meta", "FM")
    {
        setBaseURI(initBaseURI);
        setNotRevealedURI(initNotRevealedUri);
    }
    
    # 这段代码主要是给用户抢NFT用的， 下面每个require的规则代表挖掘NFT的条件
 function mintFengxuanMeta(uint256 tokenQuantity) public payable {
				#这段要求总个数不能超过MAX_SUPPLY
        require(
            totalSupply() + tokenQuantity <= MAX_SUPPLY,
            "Sale would exceed max supply"
        );
        #这段要求必须激活售卖开关，才可以售卖
        require(_isSaleActive, "Sale must be active to mint FengxuanMetas");
        
        require(
            balanceOf(msg.sender) + tokenQuantity <= maxBalance,
            "Sale would exceed max balance"
        );
        require(
            tokenQuantity * mintPrice <= msg.value,
            "Not enough ether sent"
        );
        require(tokenQuantity <= maxMint, "Can only mint 1 tokens at a time");

        _mintFengxuanMeta(tokenQuantity);
    }
 	

    function tokenURI(uint256 tokenId)
        public
        view
        virtual
        override
        returns (string memory)
    {
        require(
            _exists(tokenId),
            "ERC721Metadata: URI query for nonexistent token"
        );

        if (_revealed == false) {
            return notRevealedUri;
        }

        string memory _tokenURI = _tokenURIs[tokenId];
        string memory base = _baseURI();

        // If there is no base URI, return the token URI.
        if (bytes(base).length == 0) {
            return _tokenURI;
        }
        // If both are set, concatenate the baseURI and tokenURI (via abi.encodePacked).
        if (bytes(_tokenURI).length > 0) {
            return string(abi.encodePacked(base, _tokenURI));
        }
        // If there is a baseURI but no tokenURI, concatenate the tokenID to the baseURI.
        return
            string(abi.encodePacked(base, tokenId.toString(), baseExtension));
    }

我们的solidity版本是用的最新的0.8.0以上版本，整个NFT开发是必须要继承ERC721的协议的，所以需要重写里面部分方法。你可以把区块链理解成一个速度很慢的数据库，就是不那么好用而已。

tokenUrl  的作用是首先你需要设定一个ipfs的地址，然后基本就是在挖NFT的时候， 它就是一个不会重复的数字一直往上堆叠，如果不指定挖掘那个数字，那么就是从零开始，然后一直到你的NFT总量结束，就是因为有这个数字，所以我们才可以做拼接

就比如你设定的地址是evalshell.com，那么就会生成evalshell.com/1.jpg,evalshell.com/2.jpg,这样的地址 所以让它们挖到NFT之后，根据地址可以拼接成一个图片，比如下图

https://gateway.pinata.cloud/ipfs/QmVxLawgqNyhzXre7L225pmKxi677WwYotkwdkQFn4oiDp/5.png


就可以让购买者看到这个NFT图片是什么。

2.4 部署合约

首先进入到remix在线编辑器中，我们可以选择从github上加载，

在弹出的对话框中输入我们的智能合约地址是

https://github.com/fengxuangit/nftmetademo/blob/main/meta.sol，然后点击import就出现在编辑器中了

依次点开左边的目录，就可以看到我们智能合约。然后我选需要选择编译的版本。

这里默认选择0.8.7就可以，是最新的稳定版本，然后点击编译。如果左边出现一个绿色的勾就说明编译成功了

编译成功之后，我们需要部署合约。在deplay选项卡，我们

需要在环境选择器中选择Injected Web3，一般选择之后，你的metamask就会出现弹窗让你确认，确认通过之后就可以发布在Rinkeby测试网络中啦，最后点击Deploy，就会出现Metamask弹窗让你确定gas费用，然后你点击确认后，就会会把这个合约部署发布到区块网络中，这里需要等待一会时间，因为所有上链的东西都需要矿工进行区块确认，所以不是及时的。

最后，如果看到下面控制台能输出这样的日志，然后左下方edployed出现自己部署好的合约，那么就说明部署成功啦！👏👏👏

2.5 使用合约

如果我们直接在mintFengxuanMeta 这个函数中开始出售NFT，那么就会报错，这个报错信息是我们在代码中指定的，其意思是如果要开始出售，那么必须先点击开始出售按钮，激活一下。

点击flipSaleActive 函数，在弹出的对话框中选择确认，这是因为如果要改变合约中的变量信息，也是需要在区块上进行确认的，那么就需要支付一定的GAS费用。

然后当你支付gas费用之后，点击下面的_isSaleActive 按钮， 就可以看到现在已经是允许出售了。当然也可以看下方日志输出，也可以看到变量信息。

再次点击mint 还是报错。

这里说没有足够的ETH进行发送，那么这里也是在我们代码中写到，每次出售的价格最低是0.01eth。这里需要在界面上进行输入金额，

我们一般会用Gwei这个单位进行换算，如果大家不知道如何进行换算，提供一个网址

https://eth-converter.com/，

这里输入eth就会转换为相应的Gwei和Wei

换算好，在Value这里填入好金额

再按下mintFengxuanMeta 函数就可以看到成功与合约交互成功，需要支付Gas费用。到这一步基本上就挖到自己写的NFT了。

2.8 发布到IPFS

星际文件系统( IPFS ) 是一种协议和点对点网络，用于在分布式文件系统中存储和共享数据。IPFS 使用内容寻址来唯一标识连接所有计算设备的全局命名空间中的每个文件。IPFS 允许用户以类似于BitTorrent的方式托管和接收内容

我推荐使用 https://pinata.cloud 这个网站，只要注册后，用户有一个1GB的免费空间，在IPFS上是用区块链去存储数据的，我们可以在后台上传文件夹。

2.9 同步区块

再次回到我们的remix，在部署的合约下方的setNotRevealedURI 输入ipfs://QmNbgVii5zsywA5xLreA8KuC8Y8twmoXR9d2z74jEaDSyg 这里的CID是刚刚你拿到的unpack.json的CID,然后transact,点击metemask确认之后,再点击setBaseURI 也是一样 ipfs://QmP4WUaznLYacjE8oWDTzmPaYucozVfD9MBnbKdSiNFG4w/ 加上你最后拿到的FXMETA_JSONS的CID，但是这里注意因为要拼接url，所以这里的是以/结尾的。然后再次点击transact。

把所有的信息都送上链之后，再到opensea上刷新，就可以看到一张黑色的背景图片了，这就是盲盒图片，然后点击编辑器中的filpReveal 这个按钮，就是关闭盲盒，看看你抽到那个图片，这样我们整个NFT开发就完成了。NFT的地址是
