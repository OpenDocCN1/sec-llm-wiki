# 闲置了快半年的风炫官网，竟然....

本来这个文章前几天就要发的，可没想到半路杀出一个log4j漏洞，搞得我一直在研究，然后前两天也写出了一篇 [《Log4j漏洞复现+漏洞靶场》](https://mp.weixin.qq.com/s?__biz=MzI5MDE0MjQ1NQ==&mid=2247513120&idx=1&sn=b3868562803c5200a0daf59c162d3ba3&scene=21#wechat_redirect) 耽误了几天。

因为9月1日，《漏洞管理法》的实施，新法的颁布，让我对网安的法律界限有些模糊。所以我暂停开发了网站，漏洞库的页面也一直处于关闭状态，只是保留了信息检索、分类浏览和知识图谱。默默潜水和大家一样也是先看看风向。不过时间长了， 对官网我就处于闲置的状态了(爬虫都是自动的)，转而去做了一个小程序

，话说大家感兴趣的话可以试试，因为都是免费的，我只是想对大家有用的小产品，就没管了。截至目前看来，对我们的影响貌似也不是很大。  

这段时间，我不是不想更新网站，只不过我这段时间业余的时候，一直在做恬音和学习java开发，嗨，java是真TM的卷！恬音的小程序后端就是我用springboot2 来开发的。也算是我的一个练手项目。

然而，越来越多的人告诉我，他们希望我继续更新，他们经常使用我的网站来查网络安全方面的资料，我深深感受到了这一份社会责任感，😄。

看了看小伙伴的呼唤，我决定继续开发风炫官网，完善官网，补充完整知识图谱，知识图谱这块我打算做一个在线的思维导图+资料整合，让一个啥都不懂的小白，无脑照着我的图谱一个一个试就能完成网络安全的渗透测试，代码审计等等（别怪我又加速了行业的内卷），我觉得这些事情我不做也迟早会有人做的。

先不过多的立下flag了，我担心到时候又没做好，啪啪打脸。
