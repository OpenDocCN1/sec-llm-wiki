# 抖音批量取消喜欢的方法

## 准备工作

BurpSuite配置IOS手机抓包，这个不知道的可以在搜索引擎里找文章。我在这里就不赘述了。

## 利用方式

1.  配置好抓包手机请求喜欢列表，后找到下面图片中的域名：![](../Images/1488cdde90fb0346bd1ce86d5b92cbab.png)  
    `https://api3-normal-c-lq.amemv.com/aweme/v1/aweme/favorite/?version_code=12.2.0&js_sdk_version=1.73.0.1&tma_jssdk_version=1.73.0.1&app_name=aweme&app_version=12.2.0&vid=547589C5-960B-4568-BAF4-4771C5EAB8A6&device_id=34825158007438&channel=App%20Store&mcc_mnc=46001&aid=1128&screen_width=828&openudid=365172e1260b8ddeaaa0b555979a4eef74d84e0d&cdid=0984AB4F-136B-4DE7-B5D2-D04DD66F7289&os_api=18&ac=4G&os_version=14.2&build_number=122007&device_platform=iphone&device_type=iPhone11,8&is_vcd=1&iid=87601716930136&idfa=826A4F2F-F5C0-496C-8532-E69DA0791BBD&invalid_item_count=0&sec_user_id=MS4wLjABAAAAnqsPNBj2X1V8CVY5gxB-M64FN_rd60JBWe0nKq208E2NkUjG9mZXWXwJn1-8dYxJ&hotsoon_has_more=0&count=21&hotsoon_filtered_count=0&user_id=1213501623768734&max_cursor=1608090790000&is_order_flow=0&is_hiding_invalid_item=0`这里的域名可能会变，但是接口就是`aweme/v1/aweme/favorite`,这个是抖音喜欢列表的接口 然后把这个接口的header信息填入到脚本中，需要填写的字段
    
      
    

```










       sdk-version
```

  

  

2.  然后手动取消一个作品, 找到下面这个接口，注意这是一个POST请求类型的接口`https://api26-normal-lq.amemv.com/aweme/v1/commit/item/digg/?tma_jssdk_version=1.85.0.16&ac=WIFI&is_vcd=1&`

然后把这个接口中的一个header字段`x-common-params-v2`填入

到此准备工作已经做完

使用

`python douyin_cancel_favorite.py 100`

**100是你要取消的数量，就这么简单**

总结

这个需求是我没事从5118上挖到的需求。没想到还挺多人用的，很多人有这个需求，我就把脚本公开吧，这个只能取消自己的抖音号的喜欢，不能清空别人的。所有的准备操作的前提就是你拥有这个抖音号的账号管理权了。
