# django haystack深入研究

## 前言

evalshell.com  是我自己开发的一个搜集全网安全领域知识库的一个垂直领域的网站，对于一个垂直搜索网站，我深知搜索准确度和速度的重要，所以经过一番调研之后我选择了haystack这个全文搜索扩展库。

但是我有着自定义的需求，所以对haystack进行了源码分析定制。

## 软件简介  

Haystack 是 Django 框架的搜索扩展模块。Haystack 提供统一的 API 允许你使用不同的搜索后端，包括 Solr, Elasticsearch, Whoosh, Xapian 等等。
