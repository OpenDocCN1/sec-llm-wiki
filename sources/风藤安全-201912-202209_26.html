有时候需要将多个接口封装起来用，Splunk 输入参数后输出搜索的结果，由于且有些敏感参数不适宜直接在前端输入，因此考虑自己编写一个应用，而且后续升级也比较方便。本篇是讨论Splunk 搜索命令APP，当然Splunk有很多特色的APP，例如KV Store 、Modular alerts等。


0x01  下载SDK

要自行编写一个APP，需要Splunk 官方提供的SDK。开发者网址：https://dev.splunk.com/ 。源代码，在Github上

https://github.com/splunk/splunk-sdk-python  「python 版本」

python 可以使用 [sudo] pip install splunk-sdk  命令安装

不过后面涉及到打包应用，因此需要把splunklib 目录所有文件提取出来一起打包。

0x02 应用配置

新建3个目录，分别为default，metadata，static 。

default：包含app.conf(主要是ui的一些配置)，commands.conf(核心配置,执行命令的文件路径），searchbtn.conf(定义界面上搜索按钮需要传入的参数要求）。

app.conf: 其中需要注意【package】下面的id这个要和工程名相同，这是因为后面上传应用打包文件后Splunk 解压后会把最外层的目录名称作为应用的id 。

## Splunk app configuration file#[install]is_configured = 0[ui]is_visible = 1label = curl command[launcher]author = xxdescription = xx[package]id = curl_command

commands.conf：核心配置，定义应用被调用的名称及对应的执行文件，下面代码curl-command 应用下的curl 命令 ，filename 指定curl 命令的文件位置，用来通知Splunk。

[curl]filename = curl-command.pychunked = true


searchbtn.conf：非必须，如果使用Splunk页面上的搜索面板，则需要配置。

[curl-command]syntax = | curl <curl-options>[curl-options]syntax = (url=<url>) | (paramMap=(param1=val1, param2=val2))? | (output=default:json|text)? | (timeout=<int>)? | (auth=(method(basic|digest), user, password)? | (headers=<json>)? | (proxies=(http://proxy, https://proxy))? | (unsetProxy=<bool>)?


metadata：非必须项，主要用来定义该应用的权限，包含default.meta

# Export CURL command and its settings system wide[commands/curl]access = read : [ * ], write : [ admin ]export = system[curl_command]access = read : [ * ], write : [ admin ]export = system[searchbnf/curl-command]export = system[searchbnf/curl-options]export = system


0x03  编写命令主文件

在文章最前面提的bin 目录下新建一个文件，文件名需要和commands.conf 内容中的filename 参数相同，这样在Splunk 上面输入指定的命令后会运行这个文件。

按需导入 Splunk 依赖包

#!/usr/bin/env python# -*- coding: utf-8 -*-
# Splunk specific dependenciesimport sys, osfrom splunklib.searchcommands import dispatch, GeneratingCommand, Configuration, Option, validators, splunklib_logger as logger

然后自己定义一个类，后面就是实现的逻辑：

@Configuration(type='reporting')class curlCommand(GeneratingCommand)://省略

文件最后加上这段代码就可以了

dispatch(curlCommand, sys.argv, sys.stdin, sys.stdout, __name__)

0x04  应用打包

这里需要注意需要把.pyc文件删除，Splunk 不能识别这种格式。有个好用的打包脚本-来自Benjamin Macher，最后生成tar.gz 格式文件在Splunk >应用>新建应用上传本地文件后重启后就可以了。

import os, re, glob
# Open app.conf and read all lineswith open('./curl_command/default/app.conf') as appconf:  lines = appconf.readlines()
appconf.close()
# Get current version -> version = 1.0.0for line in lines:  if re.match('version', line):    version = re.search(r'version\s?=\s?(\d\.\d\.\d)', line).group(1)    os.system('cp -R curl_command dist/')os.system('find dist/curl_command -name ".*" -delete')os.system('find dist/curl_command -name "*.pyc" -delete')os.system('tar -zcf dist/curl_command-%s.tar.gz curl_command' % (version))os.system('rm -rf dist/curl_command')
print 'App <curl_command-%s.tar.gz> successfully built!' % (version
