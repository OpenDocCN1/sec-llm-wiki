背景

虽然Proxyman 已经内置了不少JS库供我们使用，其中不乏有base64.js、atob.js、btoa.js、hashes.js、lodash.js、vkBeautify.js和crypto-js.min.js，具体的用处可参看下图。但有时往往不能满足渗透测试过程中对某些算法二次使用的需求（例如有些网站在登录或修改密码等过程对前端输入的密码进行了加密，截获报文看到的密码字段都是加密后的字符串，这个时候还拿个密码字典去硬刚则会成为徒劳……(≧∇≦)），今天在用Proxyman做测试时发现某系统使用RSA加密，但发现竟然没有内置，百度也没找到，那只能自己从0开始实现下。

当然如果自己熟悉目标网站使用的加解密算法，也可以自行用python或者Java语言实现加密和解密过程，也有看到过直接在浏览器的Console中 编写js 调用加解密函数的。本次主要讨论如何实现将目标网站加解密算法平滑“移植”到proxyman中作为扩展的一般做法，由于加解密算法众多，故仅以常用的RSA算法为例进行说明（RSA算法未内置在Proxyman中）。

Scripting

Proxyman 的Scripting功能可以针对URL的请求和返回进行修改/MOCK，支持正则表达式匹配URL，还支持选定请求方法匹配以及支持Request和Response选定生效。这这里面编写的都是js代码模版，也称为Snippet Code，

官方解释：A collection of snippet Javascript code for the Scripting Tool.

看以下示例代码

// Addons List: https://docs.proxyman.io/scripting/addonsconst { sayHello } = require("@addons/HelloWorld.js");function onRequest(context, url, request) {  // console.log(request);  console.log(url);  // Update or Add new headers  // request.headers["X-New-Headers"] = "My-Value";}function onResponse(context, url, request, response) {  // console.log(response);  // Update or Add new headers  // response.headers["Content-Type"] = "application/json";  // Update status Code  // response.statusCode = 500;  // Update Body  // var body = response.body;  // body["new-key"] = "Proxyman";  // response.body = body;  // Done  return response;}

这样每次请求都会调用onRequest()，可以对请求内容作修改。例如修改请求方法GET为POST，增加Header字段等；同样地，若修改返回报文则需在onResponse()方法里编写要注入的代码。
