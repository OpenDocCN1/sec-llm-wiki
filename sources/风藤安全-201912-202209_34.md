因为上面的input标签没有结束标签，访问前端模板就会抛出异常，这点和其他前端框架不太一样。

（2)thymleaf 和for函数不是很兼容(准确的是和一些特殊字符，例如“<”、“>”等），需要额外添加注解：例如我想写一个for函数循环创建一些<a>元素，最后访问的时候也会报错，是因为<(小于号）这个符号被解析器解析原因，解决办法就是在for循环前后添加注解/\* <!\[CDATA\[ \*/

for函数 /\* \]\]> \*/ 也就是不解析这个<之类的特殊符号，标记为文本。这个受org.thymeleaf.TemplateEngine影响的。  

*   
*   
*   
*   

```
for (i=0;i<arr.length;i++) {     var label=document.createElement("a");       }
```

最后正确的代码就是下面这样==，注意使用内联javascript

*   
*   
*   
*   
*   
*   
*   

```
<script th:inline="javascript"><!-- inline不能少!-->/* <![CDATA[ */for (i=0;i<arr.length;i++){    var label=document.createElement("a");   } /* ]]> */  
```

（3)thymleaf 如果 定义变量，而这个变量想从Controller层获取的参数，使用var a=${apples} 会发现永远获取的是null ,正确的方法是

*   
*   
*   
*   
*   
*   
*   

```
//后台代码@RequestMapping(value = "/", method = RequestMethod.GET)public String index(HttpServletRequest request, HttpServletResponse response){        request.setAttribute("apples", Apples);        return "index";        }

```

*   
*   
*   
*   
*   
*   
*   
*   

```
//index.html<script th:inline="javascript"><!-- inline不能少!-->/* <![CDATA[ */for (i=0;i<arr.length;i++){    var label=document.createElement("a");     var a=[[${apples}]];} /* ]]> */  
```

这样前端渲染的时候就能变量a就能接受到后台传递的数据。
