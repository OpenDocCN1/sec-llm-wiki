# MinIO信息泄露漏洞（CVE-2023-28432）预警

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485750&idx=1&sn=9d612eb498da1bf8ac4a1f1f76bf92dd&chksm=eb668c35dc1105238813eadd57abdb5d51d7d53cbb7fafa01a9df9bf16d54175791faa10d5e6&scene=126&sessionid=1681407021#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485750&idx=1&sn=9d612eb498da1bf8ac4a1f1f76bf92dd&chksm=eb668c35dc1105238813eadd57abdb5d51d7d53cbb7fafa01a9df9bf16d54175791faa10d5e6&scene=126&sessionid=1681407021#rd)

近日，飓风安全监测到 MinIO 官方发布安全更新，修复了一处信息泄漏漏洞(CVE-2023-28432)。该漏洞允许未经身份验证的远程攻击者通过在集群部署中的 MinIO 发送特殊的 HTTP 请求获取到所有环境变量信息，导致信息泄漏。目前官方发布安全更新，建议受影响的用户尽快采取安全措施。

MinIO中存在一处信息泄露漏洞，由于Minio集群进行信息交换的9000端口，在未经配置的情况下通过发送特殊HPPT请求进行未授权访问，进而导致MinIO对象存储的相关环境变量泄露，环境变量中包含密钥信息（**MINIO\_SECRET\_KEY和MINIO\_ROOT\_PASSWORD**），能看到对应权限的存储文件。

影响范围

  

**受影响版本：**

MinIO RELEASE.2019-12-17T23-16-33Z <= version < MinIO RELEASE.2023-03-20T20-16-18Z

**不受影响版本：**

version>=MinIO RELEASE.2023-03-20T20-16-18Z  
version < MinIO RELEASE.2019-12-17T23-16-33Z

**注意：若MinIO不是集群模式配置的情况下，则不受该漏洞影响**
