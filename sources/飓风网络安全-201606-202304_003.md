# Spring Framework 身份认证绕过漏洞预警(CVE-2023-20860)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485743&idx=1&sn=92585738ccd95aebd967ebe5f9737452&chksm=eb668c2cdc11053a7ae181c7fa6bf4b1fd9af0ca9492dbee8958196620978d4cb4d4362dffed&scene=126&sessionid=1681407021#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485743&idx=1&sn=92585738ccd95aebd967ebe5f9737452&chksm=eb668c2cdc11053a7ae181c7fa6bf4b1fd9af0ca9492dbee8958196620978d4cb4d4362dffed&scene=126&sessionid=1681407021#rd)

漏洞描述  
SpringFramework存在身份认证绕过漏洞，当SpringSecurity使用mvcRequestMatcher配置并将"\*\*"作为匹配模式时，在SpringSecurity和 Spring MVC 之间会发生模式不匹配，最终可能导致身份认证绕过。

![](../Images/eb91dd2c303899bd3c22f6f89e5df1e3.png "点击查看图片来源")  
影响版本  
Spring Framework 6.0.x <= 6.0.6  
  
Spring Framework 5.3.x <= 5.3.25  

（其他低于5.3.x的系列版本不受此漏洞影响）  
  

处置建议  
  
目前官方已有可更新版本，建议用户升级至:   
  
Spring Framework 6.0.x >= 6.0.7  
  
Spring Framework 5.3.x >= 5.3.26  
  
https://spring.io/
