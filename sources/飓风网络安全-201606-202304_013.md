# Apache Shiro 权限绕过漏洞-CVE-2023-22602预警通告

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485693&idx=1&sn=8a953df205507278262d49bcfbd232ef&chksm=eb668dfedc1104e825d3cd6f5d271e256461ad207333781c13e9210192ccd9a8f07b5b8b0bf5&scene=126&sessionid=1681407223#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485693&idx=1&sn=8a953df205507278262d49bcfbd232ef&chksm=eb668dfedc1104e825d3cd6f5d271e256461ad207333781c13e9210192ccd9a8f07b5b8b0bf5&scene=126&sessionid=1681407223#rd)

基础信息   

*   漏洞等级:高危
    
*   漏洞类型:权限绕过
    
      
    
    影响范围   ：
    
*   涉及厂商：
    
    apache  
    
*   涉及产品：
    
     shiro
    

![](../Images/2b978e9b479ae5b6d37530d4864da6e1.png)

  

*   漏洞描述： Apache Shiro是一个开源安全框架，提供身份验证、授权、密码学和会话管理。Shiro框架直观、易用，同时也能提供健壮的安全性。 Apache Shiro与Spring Boot 2.6+一起使用时，特制的HTTP请求可能导致认证绕过。 当Shiro和Spring Boot使用不同的模式匹配技术时，认证绕过就会发生。
    
      
    
*   漏洞危害： 攻击者利用此漏洞可以绕过权限认证，访问普通用户不能访问的api
    
      
    
*   影响范围： Apache Shiro < 1.11.0 与 Spring Boot 2.6+ 一起使用
    
      
    
*   安全版本： Apache Shiro >= 1.11.0
    
      
    

*官方漏洞通告*   
https://lists.apache.org/thread/dzj0k2smpzzgj6g666hrbrgsrlf9yhkl  

修复方案:

版本升级  

厂商已发布了漏洞修复程序，安全版本如下：  
Apache Shiro >= 1.11.0  

官方下载地址：https://shiro.apache.org/download.html
