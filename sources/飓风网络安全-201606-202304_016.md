# node-jsonwebtoken远程代码执行漏洞 （CVE-2022-23529）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485678&idx=2&sn=a7ece86318adddf7c2f5094790842b82&chksm=eb668deddc1104fbbfaab235b525965a5464c02562ca370d201daa44eb716c19c1f90b0006fe&scene=126&sessionid=1681407223#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485678&idx=2&sn=a7ece86318adddf7c2f5094790842b82&chksm=eb668deddc1104fbbfaab235b525965a5464c02562ca370d201daa44eb716c19c1f90b0006fe&scene=126&sessionid=1681407223#rd)

漏洞描述: 

  

近日，飓风安全应急团队监测node-jsonwebtoken发布安全公告，修复了一个存在于node-jsonwebtoken中的远程代码执行漏洞，该漏洞是当允许不受信任的实体修改jwt.verify()控制的主机上的密钥检索参数时恶意攻击者可以修改函数的密钥检索参数，导致远程代码执行。

![](../Images/f0b4843f7b83368d6f6e6170830b7897.png)

**【受影响版本】**

*   node-jsonwebtoken <= 8.5.1
    
      
    
      
    

**【安全版本】**

*   node-jsonwebtoken >= 9.0.0
    

node-jsonwebtoken 是 node.js 的 JsonWebToken 实现。

  
  

影响范围        

node-jsonwebtoken <= 8.5.1

  

解决方案                          

修复建议                                            

**临时修复建议：**

*   如果目前无法升级，若业务环境允许，使用白名单限制相关端口的访问来降低风险。
    
      
    
      
    

**通用修复建议：**

官方已经针对漏洞发布版本更新，下载地址如下：
