漏洞描述

近日，飓风应急团队监测到Apache发布安全公告，修复了一个存在于Apache James Server中的信息泄露漏洞，该漏洞是由于使用具有不安全权限的临时文件，可能导致具有本地访问权限的攻击者访问传输中的私有用户数据，造成敏感信息泄露。

【受影响版本】

  • Apache James Server <= 3.7.2

【安全版本】

  • Apache James Server >= 3.7.3


Apache的James项目提供了一组丰富的开源模块和库，使用Java语言开发，将Internet邮件通讯打造成为一个先进的企业邮件服务器。

影响范围

Apache James Server <= 3.7.2

解决方案

修复建议

临时修复建议：

  • 如果目前无法升级，若业务环境允许，使用白名单限制相关端口的访问来降低风险。
