# Apache James Server信息泄露漏洞 （CVE-2022-45935）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485669&idx=1&sn=a1f32e9116c5054b13087fa83ea6d947&chksm=eb668de6dc1104f009a530a781fbade2073f2c4e2a71124f266e541663ded1e3851033d794b2&scene=126&sessionid=1681407223#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485669&idx=1&sn=a1f32e9116c5054b13087fa83ea6d947&chksm=eb668de6dc1104f009a530a781fbade2073f2c4e2a71124f266e541663ded1e3851033d794b2&scene=126&sessionid=1681407223#rd)

漏洞描述

近日，飓风应急团队监测到Apache发布安全公告，修复了一个存在于Apache James Server中的信息泄露漏洞，该漏洞是由于使用具有不安全权限的临时文件，可能导致具有本地访问权限的攻击者访问传输中的私有用户数据，造成敏感信息泄露。

**【受影响版本】**

*   Apache James Server <= 3.7.2
    

**【安全版本】**

*   Apache James Server >= 3.7.3
    
      
    

![](../Images/60b3d047527e0a30b418a8529bd1af23.png)

影响范围

Apache James Server <= 3.7.2

修复建议

*   如果目前无法升级，若业务环境允许，使用白名单限制相关端口的访问来降低风险。
