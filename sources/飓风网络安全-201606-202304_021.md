# Spring Boot Admin 代码注入漏洞 （CVE-2022-46166）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485656&idx=1&sn=83ce84486c5447e70e50741f7914029f&chksm=eb668ddbdc1104cda3d22cf8e6205751ebaf5deae6885d36ace86eec94c34922c44c7d50fce2&scene=126&sessionid=1681407223#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485656&idx=1&sn=83ce84486c5447e70e50741f7914029f&chksm=eb668ddbdc1104cda3d22cf8e6205751ebaf5deae6885d36ace86eec94c34922c44c7d50fce2&scene=126&sessionid=1681407223#rd)

漏洞描述                                        

近日，飓风安全应急团队监测到Spring Boot发布安全公告，修复了一个存在于Spring Boot Admin中的安全漏洞，该漏洞是由于Spring Boot Admin 的 notifiers 通知模块没有对用户输入进行有效过滤，导致所有运行Spring Boot管理服务器、启用了通告程序(例如团队通告程序)并通过UI对环境变量具有写访问权限的用户都可能受到影响。

**【受影响版本】**

*   Spring Boot Admin < 2.7.8
    
*   Spring Boot Admin < 2.6.10
    
*   Spring Boot Admin < 3.0.0-M6
    

**【安全版本】**

*   Spring Boot Admin = 2.7.8
    
*   Spring Boot Admin = 2.6.10
    
*   Spring Boot Admin = 3.0.0-M6
    

![](../Images/d6abde26c88bb123c5347c287e9fff00.png)

Spring Boot Admin提供了Spring Boot应用程序提供了一个管理界面。

  

影响范围        

Spring Boot Admin < 2.7.8、 Spring Boot Admin < 2.6.10 、Spring Boot Admin < 3.0.0-M6

  

解决方案    

修复建议            

**临时修复建议：**

*   如果目前无法升级，若业务环境允许，使用白名单限制相关端口的访问来降低风险。
    

**通用修复建议：**

官方已经针对漏洞发布了补丁更新，下载地址如下：

*   https://github.com/codecentric/spring-boot-admin/releases
