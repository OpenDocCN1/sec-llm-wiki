# Smartbi商业智能BI软件存在命令执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485639&idx=1&sn=a8943c071956036681f590556241cef2&chksm=eb668dc4dc1104d2e696aa4aea42b64438c80a56bb578310e7c8bcda585fc71ef350ffc06b6b&scene=126&sessionid=1681407223#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485639&idx=1&sn=a8943c071956036681f590556241cef2&chksm=eb668dc4dc1104d2e696aa4aea42b64438c80a56bb578310e7c8bcda585fc71ef350ffc06b6b&scene=126&sessionid=1681407223#rd)

漏洞描述                                        

近日，飓风安全应急团队监测到Smartbi官方发布安全公告，修复了一个存在于Smartbi商业智能BI软件中的命令执行漏洞，该漏洞是由于未对DB2的JDBC特殊连接字符做过滤，触发JNDI注入进行命令执行。  
  

**【受影响版本】**

*   Smartbi商业智能BI软件 < 10.5.8
    

**【安全版本】**

*   Smartbi商业智能BI软件 >= 10.5.8
    

![](../Images/c89bc86e34d9ce1ba5ec43c7775b3fc1.png)

Smartbi商业智能BI软件是企业级商业智能和大数据分析平台。

  

影响范围        

Smartbi商业智能BI软件 < 10.5.8

  

解决方案    

修复建议            

**临时修复建议：**

*   如果目前无法升级，若业务环境允许，使用白名单限制相关端口的访问来降低风险。
    

**通用修复建议：**

官方已经针对漏洞发布了版本更新，下载地址如下：

*   https://www.smartbi.com.cn/patchinfo
