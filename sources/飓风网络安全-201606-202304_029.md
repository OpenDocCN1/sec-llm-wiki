# 群晖Synology Presto File Server 存在多个漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485625&idx=3&sn=7f3cafdf8b8d8a38cb04a1cd205f8ca7&chksm=eb668dbadc1104acf1600f5db7b2cefb13033707a9846b6e6e5686d88414a1a4ba9f9bba6447&scene=126&sessionid=1681407228#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485625&idx=3&sn=7f3cafdf8b8d8a38cb04a1cd205f8ca7&chksm=eb668dbadc1104acf1600f5db7b2cefb13033707a9846b6e6e5686d88414a1a4ba9f9bba6447&scene=126&sessionid=1681407228#rd)

漏洞描述                                        

近日，飓风安全应急团队监测到群晖Synology安全公告，（CVE-2022-43748,CVE-2022-43749）修复了2个存在于Presto File Server中的安全漏洞，详情如下：

**1.CVE-2022-43748 Presto File Server 路径遍历漏洞**

漏洞类型：路径遍历

漏洞简介：在文件操作管理中存在对受限目录的路径名的不当限制(“路径遍历”)漏洞，使得远程攻击者能够通过未指定的向量写入任意文件。

  
  

**2.CVE-2022-43749 Presto File Server 权限管理不当漏洞**

漏洞类型：权限管理不当

漏洞简介：在摘要报告管理存在的权限管理不当漏洞，该漏洞允许远程身份验证用户通过未指定的向量绕过安全约束。

**【受影响版本】**

*   Presto File Server < 2.1.2-1601
    
      
    

**【安全版本】**

*   Presto File Server for DSM 7.1 >= 2.1.2-1601
    
*   Presto File Server for DSM 7.0 >= 2.1.2-1601
    
*   Presto File Server for DSM 6.2 >= 2.1.2-0601

Presto File Server 是专为实现高速文件传输而设计的套件。

影响范围        

Presto File Server < 2.1.2-1601

  

解决方案    

修复建议            

**临时修复建议：**

*   如果目前无法升级，若业务环境允许，使用白名单限制相关端口的访问来降低风险。
    

**通用修复建议：**

官方已经针对漏洞发布了版本更新，下载地址如下：

*   https://www.synology.cn/zh-cn/support/download
