漏洞描述

近日，飓风安全应急团队监测到Apache发布安全公告，修复了一个存在于 Commons Text中的安全漏洞，攻击者可利用该漏洞在受害者机器上执行任意代码。

【受影响版本】

  • 1.5<= Apache Commons Text <=1.9

【安全版本】

  • Apache Commons Text = 1.10.0

Apache Commons Text 项目实现了一系列关于文本字符串的算法，专注于处理字符串和文本块。
