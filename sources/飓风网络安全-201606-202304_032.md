# Apache Shiro 身份认证绕过漏洞 （CVE-2022-40664）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485605&idx=1&sn=19e697a6b0a562749f4d3388ed6f59a1&chksm=eb668da6dc1104b05ba9d66b96d5eb11a7ebfb4aecf1c2f32cf643caa326edd7520021b33aa1&scene=126&sessionid=1681407228#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485605&idx=1&sn=19e697a6b0a562749f4d3388ed6f59a1&chksm=eb668da6dc1104b05ba9d66b96d5eb11a7ebfb4aecf1c2f32cf643caa326edd7520021b33aa1&scene=126&sessionid=1681407228#rd)

基本信息

风险等级： 高危

漏洞类型： 身份验证绕过  

漏洞编号： 

CVE-2022-40664

漏洞描述

近日，飓风安全应急团队监测到Apache发布安全公告，修复了一个存在于Shiro组件中的安全漏洞，当通过 RequestDispatcher 进行转发或包含时存在身份验证绕过漏洞。

【受影响版本】

*   Apache Shiro < 1.10.0
    

【安全版本】

*   Apache Shiro = 1.10.0
    

![](../Images/480ff9bfac3657a0601ba0bef37ab559.png)

Apache Shiro 是美国阿帕奇（Apache）软件基金会的一套用于执行认证、授权、加密和会话管理的Java安全框架。  

影响范围

Apache Shiro < 1.10.0

解决方案

修复建议

**临时修复建议：**

*   如果目前无法升级，若业务环境允许，使用白名单限制web端口的访问来降低风险。
    

**通用修复建议：**

官方已经针对漏洞发布了软件更新，下载地址如下：

*   https://shiro.apache.org/download.html
