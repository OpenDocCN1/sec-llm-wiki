# Apache Airflow 存在多个漏洞 （CVE-2022-40754,CVE-2022-40604）

风险等级:高危                    

漏洞类型:开放重定向,信息泄露                  

漏洞编号：           

CVE-2022-40754,CVE-2022-40604

漏洞描述                                        

近日，飓风安全应急团队监测到Apache发布安全公告，修复了2个存在于Airflow中的安全漏洞，漏洞详情如下：

**1.CVE-2022-40754 Apache Airflow 存在开放重定向漏洞**

风险等级：高危

漏洞类型：开放重定向

漏洞简介：该漏洞由于`/confirm` 端点未对url 进行过滤导致存在开放重定向漏洞，攻击者可利用此漏洞进行网络钓鱼攻击。

  
  

**2\. CVE-2022-40604 Apache Airflow 存在格式化字符串漏洞**

风险等级：中危

漏洞类型：信息泄露

漏洞简介：该漏洞由于对 url 中的部分内容进行不必要的格式化，导致攻击者可利用此漏洞对 url 字符串进行信息提取，从而获取系统敏感信息。

【受影响版本】

*   2.3.0 <= Apache Airflow <= 2.3.4
    
      
    

【安全版本】

*   Apache Airflow >= 2.4.0
    
      
    
*   ![](../Images/52242c1f9dbfefcfe691d7b83a14838b.png)
    
    Apache Airflow 是一个以编程方式创作、安排和监控工作流的平台。
  
  

影响范围：2.3.0 <= Apache Airflow <= 2.3.4

  

修复建议            

**临时修复建议：**

*   如果目前无法升级，若业务环境允许，使用白名单限制web端口的访问来降低风险。
    
*     
    

**通用修复建议：**

官方已经针对漏洞发布了软件更新，下载地址如下：

*   https://github.com/apache/airflow/releases
