# 【漏洞通告】Apache Spark Shell命令注入（CVE-2022-33891）

**  漏洞综述 **

  

**■ 漏洞背景**

Apache Spark 是一种用于大数据工作负载的分布式开源处理系统。它使用内存中缓存和优化的查询执行方式，可针对任何规模的数据进行快速分析查询。它提供使用 Java、Scala、Python 和 R 语言的开发 API，支持跨多个工作负载重用代码—批处理、交互式查询、实时分析、机器学习和图形处理等。近日，飓风安全威胁预警团队监测到Apache官方发布了Apache Spark Shell命令注入漏洞通告（CVE-2022-33891），成功利用此漏洞可对受害主机进行任意命令执行。

![](../Images/62b2335a55c19a67bb57eb3db37b895b.png)

  

  

**■ 漏洞详情**

Apache Spark UI可通过配置spark.acls.enable启用 ACL（访问控制），当启动ACL时，HttpSecurityFilter代码路径允许用户通过任意用户名访问执行。恶意攻击者能够在访问权限检查时，构造一个恶意的Unix shell命令进行注入，从而导致目标主机执行任意shell命令。

  

**■ 影响范围**

Apache Spark <= 3.0.3

3.1.1 <= Apache Spark <= 3.1.2

3.2.0 <= Apache Spark <= 3.2.1

**漏洞等级：高危**

  

**  处置方法 **

  

**■ 官方补丁**

目前官方已修复该漏洞，受影响用户可以升级更新到Apache Spark 3.2.2或更高版本，官方链接：https://github.com/apache/spark
