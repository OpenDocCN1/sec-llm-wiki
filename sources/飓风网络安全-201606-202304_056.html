WSO2 API 远程代码执行漏洞（CVE-2022-29464）风险通告

原文：http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485453&idx=1&sn=f2683ebd5084a2a2fe2e3600880b3436&chksm=eb668d0edc110418fcf1b25aa82b83d570db13547aba274ef166767c4a0c4d75509641c018a8&scene=126&sessionid=1681407238#rd

漏洞描述：

WSO2 API Manager中存在任意文件上传和远程代码执行漏洞。该漏洞源于某些 WSO2 产品中对用户输入的验证不当，攻击者可以将任意文件上传到服务器的任意位置。通过利用任意文件上传漏洞，可以进一步在服务器上实现远程代码执行。

安全专家建议受影响的用户尽快升级到最新版本。

WSO2 API Manager是美国WSO2公司的一套API生命周期管理解决方案。

 

漏洞编号：

CVE-2022-29464

 

漏洞等级：

严重，CVSS评分9.8（最高10分）
