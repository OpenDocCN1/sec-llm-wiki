# 【漏洞预警】Jira 和 Jira Service Management身份验证绕过漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485442&idx=2&sn=cbb3bd8d8d7f21113cda1673c5b9e385&chksm=eb668d01dc1104172620a858cc3345fdcf7397f2525ffd3d0ff6c2ec2f1ca1a191f436140f60&scene=126&sessionid=1681407238#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485442&idx=2&sn=cbb3bd8d8d7f21113cda1673c5b9e385&chksm=eb668d01dc1104172620a858cc3345fdcf7397f2525ffd3d0ff6c2ec2f1ca1a191f436140f60&scene=126&sessionid=1681407238#rd)

漏洞描述

Atlassian Jira是澳大利亚Atlassian公司的一套缺陷跟踪管理系统。该系统主要用于对工作中各类问题、缺陷进行跟踪管理。

![](../Images/dd9eed28ec19897538384b1d3df8cf0d.png)

2022年4月20日，Atlassian 发布安全公告，修复了一个存在于Jira和Jira Service Management中的身份验证绕过漏洞。漏洞编号：CVE-2022-0540，漏洞威胁等级：高危，漏洞评分：8.5。

**漏洞描述**

 || 

受影响的Atlassian Jira Server and Data Center允许具有路线图管理员权限的远程攻击者通过 Jira 和 Jira Service Management 容易受到其 Web 身份验证框架 Jira Seraph 中的身份验证绕过的攻击。未经身份验证的远程攻击者可以通过发送特制的 HTTP 请求来利用此漏洞，以使用受影响的配置绕过 WebWork 操作中的身份验证和授权要求。

修复建议

**Jira：**

8.13.x >= 8.13.18

8.20.x >= 8.20.6

Jira所有版本 >= 8.22.0

  

**Jira Service Management：**

4.13.x >= 4.13.18

4.20.x >= 4.20.6

Jira Service Management所有版本 >= 4.22.0

  
与此同时，请做好资产自查以及预防工作，以免遭受黑客攻击。
