# CVE-2022-0847Dirty Pipe – Linux 内核本地提权漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247485385&idx=1&sn=547f433a3b2134effe40d9c8df636820&chksm=eb6682cadc110bdce4667fa167c40232d3c37b290239da1a7035febdad89f6a8ba8f5af49f2a&scene=126&sessionid=1681407244#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247485385&idx=1&sn=547f433a3b2134effe40d9c8df636820&chksm=eb6682cadc110bdce4667fa167c40232d3c37b290239da1a7035febdad89f6a8ba8f5af49f2a&scene=126&sessionid=1681407244#rd)

3 月 7 日，国外的安全研究员马克斯·凯勒曼发布，披露了一处存在于Linux 内核中的本地提权漏洞 

3月8日，飓风安全应急响应情报安全小组发现该高危漏洞的情报并进行复现

漏洞描述

存在于 Linux内核 5.8 及之后版本中的本地提权漏洞。攻击者通过利用此漏洞，可覆盖重写任意可读文件中的数据，从而可将普通权限的用户提升到特权 root。

漏洞原理类似于脏牛漏洞，但它更容易被利用。漏洞发现者将此漏洞命名为“Dirty Pipe”

影响范围

  

5.8 <= Linux 内核版本 < 5.16.11 / 5.15.25 / 5.10.102

安全解决方案

更新升级 Linux 内核到以下安全版本：

Linux 内核 >= 5.16.11

Linux 内核 >= 5.15.25

Linux 内核 >= 5.10.102
