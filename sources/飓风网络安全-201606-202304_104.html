数据时代，更需要数据安全解决方案

随着计算机与互联网行业的发展，数据已经渗透到了当今社会的每一个领域，并成为重要的生产因素。各领域，数据都占据了至关重要的地位，决定着企业的生存和发展。随着数据的迅速膨胀，数据安全的重要性也日益凸显。系统故障、硬件故障、病毒攻击、误操作等造成的数据丢失、邮件系统崩溃、数据库错误等问题时常威胁着企业的数据安全和业务的正常运行。

同时，迅速膨胀的数据对企业硬件环境升级的要求，也对企业提出了数据管理和迁移的新需求。数据备份和恢复，是当今企业为保障业务和生产服务等得以正常运行所应当采取的重要战略举措。

常用的几种解决方案:

云备份 -云备份软件。除了可通过FTPS访问在线存储服务之外，还能执行SFTP服务器上的备份，可备份到 Amazon S3 和 Microsoft Azure、Google 网盘、Dropbox 和 OneDrive，同时具有压缩、AES 256 位加密、自定义过滤器和带宽限制功能。

驱动器镜像 -可以执行功能强大、重要的备份类型 - 驱动器镜像备份。可以为整个磁盘创建镜像, 并在几分钟内恢复计算机或服务器, 而无需重新安装操作系统或程序。可用于 Windows 7、Windows 8、Windows 10、Server 2008 及 Server 2012。还可以进行异机恢复、磁盘克隆、创建恢复磁盘、自动上载到FTP、Amazon S3 以及云端、单个文件恢复、裸机恢复、保存多份磁盘镜像、Windows 增量备份。驱动器镜像可直接存放于网络, 甚至网络存储设备中。

FTP 传输 -可进行多个FTP传输，向/从不限数量的服务器进行数据传输。可以制作上传和下载双向的 FTP 备份，同时加以 ZIP 压缩、FTPS / AES 加密和带宽限制。

各种数据库的备份 -可对 Oracle、PostgreSQL、MySQL、MariaDB 和 SQL Server 数据库进行（热）备份。可以制作自动备份，支持对备份文件进行压缩和加密，并可复制备份文件到任何目标地址。

虚拟机的备份 -可对 Hyper-V/ESXi/vSphere Hypervisor(ESXi Free)等虚拟机进行(热)备份。使用一份授权，可进行不限数量的虚拟机备份。可执行 VMware 虚拟机的热备份, 并通过全自动方式，将备份文件复制到网络中的 NAS 设备或磁带设备。

Exchange 服务器备份 -提供 Exchange 邮箱服务器的完整备份方案。可将 Exchange 邮箱导出到 PST 文件，使用日志截断进行热备份以及单个邮箱的还原。与 Exchange 2016、2013 和 2010 SP1 兼容。


磁带备份 -易备可以将数据备份到任何磁带驱动器（LTO、DAT等）中。同时提供如下功能：压缩文件、进行AES加密、自动弹出磁带、恢复单个文件。
已打开文件的备份(VSS) -可以复制任何已被其他程序打开或锁定的文件, 以利于卷影复制功能。用户可以对Outlook文件(.pst)、虚拟机、邮件数据库等进行热备份。
主动防勒索病毒的保护机制 -针对 CryptoLocker,Locky, WannaCry, Cerber, Petya, Bad-Rabbit, Osiris 等，提供主动的有效防护机制。
自动无值守备份 –除了进行热备份，易备还能够根据用户设定的时间、目标地址等信息，自动执行备份任务。
Email邮件通知 –将备份任务的执行结果通过Email邮件发送给用户，以便实时了解备份状态。
适应各种备份需求的不同版本

安全服务：可满足各种场景的备份需求。同时，提供多种版本，除了更完美地提供基础备份功能之外，更专注于提供卓越的高端功能，阶梯式地为用户量身打造了专属于他们自己的备份解决方案：免费版、桌面版、精简版、高阶磁带版、高阶数据库版、高阶虚拟机版、高阶 Exchange 服务器版、完整版。用户可以根据具体的数据类型、规模及备份需求，选择专门的版本，或选择完整版以获得全方位的解决方案。
