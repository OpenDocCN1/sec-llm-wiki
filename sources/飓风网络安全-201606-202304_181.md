# Ubuntu 16.04 本地提权漏洞复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247484644&idx=1&sn=a3f8e24f7fc45e335cb493f485658097&chksm=eb6681e7dc1108f1c38e366fd3ffc8cb223cde0a04990fa06ae8e372e10461b616cd380c4063&scene=126&sessionid=1681407294#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247484644&idx=1&sn=a3f8e24f7fc45e335cb493f485658097&chksm=eb6681e7dc1108f1c38e366fd3ffc8cb223cde0a04990fa06ae8e372e10461b616cd380c4063&scene=126&sessionid=1681407294#rd)

漏洞简介

    Twitter上Nikolenko发推表示ubuntu最新版本存在一个本地提权漏洞，并且提供了EXP下载地址（http://cyseclabs.com/exploits/upstream44.c），该漏洞在老版本中已经完成修复，但是在ubuntu16.04版本依旧可以被利用。

  

影响范围

    目前已知范围**ubuntu 16.04  **

    **Linux Kernel Version 4.14-4.4**

    **仅影响Ubuntu/Debian发行版本**

**复测环境**

**ubuntu 16.04.1**

******修复方案**  
    目前暂未有明确的补丁升级方案。   
    建议用户在评估风险后，通过修改内核参数限制普通用户使用bpf(2)系统调用：  
        echo 1 > /proc/sys/kernel/unprivileged\_bpf\_disabled  
    ubuntu官网暂时没有提供修复方案，补丁更新请关注ubuntu官方漏洞公告：********https://usn.ubuntu.com/****
