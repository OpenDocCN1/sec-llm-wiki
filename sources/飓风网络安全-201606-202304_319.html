查看内存使用情况

>free -m//显示以下内容（-m表示显示单位为mb）total          used       free     shared    buffers     cached
Mem:           996        249        746          0          1         39-/+ buffers/cache:        208        787Swap:            0          0          0

查看释放缓存的参数

>cat /proc/sys/vm/drop_caches//显示如下（默认值为0，不释放）0

将系统缓存区中的脏数据写入磁盘中，包括已修改的i-node、已延迟的块I/O和读写映射文件

>sync

修改释放缓存的参数

>echo 3 > /proc/sys/vm/drop_caches

不重启机器使以上配置生效

>sysctl -p
