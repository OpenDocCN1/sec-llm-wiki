# 如何用一句cmd命令开启3389端口

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzI3NzMzNzE5Ng==&mid=2247483954&idx=1&sn=6084b1ca382561a022ad608c593d88bf&chksm=eb668731dc110e27fbb37b9907f66a656348b326d5b701206277a583c1df6a50dcbfa45c599d&scene=126&sessionid=1681407375#rd](http://mp.weixin.qq.com/s?__biz=MzI3NzMzNzE5Ng==&mid=2247483954&idx=1&sn=6084b1ca382561a022ad608c593d88bf&chksm=eb668731dc110e27fbb37b9907f66a656348b326d5b701206277a583c1df6a50dcbfa45c599d&scene=126&sessionid=1681407375#rd)

1.  REG ADD HKLM\\SYSTEM\\CurrentControlSet\\Control\\Terminal" "Server /v fDenyTSConnections /t REG\_DWORD /d 00000000 /f
    

  

对Windows XP 和2003系统有用，不用重启，只要对方是外网，执行后方可连接3389终端
