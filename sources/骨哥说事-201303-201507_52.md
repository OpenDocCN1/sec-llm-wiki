# TIFF图片0day漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mzc4MzUzMQ==&appmsgid=10013102&itemidx=1&sign=fb6e85fceaadb9cb6b9850f97e272345&scene=126&sessionid=1681667073#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&appmsgid=10013102&itemidx=1&sign=fb6e85fceaadb9cb6b9850f97e272345&scene=126&sessionid=1681667073#wechat_redirect)

本周二微软的补丁更新中将包括TIFF图片0day漏洞补丁（据称，目前已经有黑客攻击得手。）。黑客将带有恶意代码的TIFF图片放到Word文档中，通过邮件发出。接收者打开文档被感染后，黑客将可以控制接收者的计算机。存在TIFF图片漏洞的系统包括Windows Vista, Windows Server 2008 和Microsoft Office 2003-2010。**请各位及时更新，并谨慎打开陌生邮件中的附件。**
