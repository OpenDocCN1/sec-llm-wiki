# ChinaISG信息安全竞赛题目解析（一）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mzc4MzUzMQ==&appmsgid=10000068&itemidx=1&sign=a8b9363cc051fa86995b636a694953ec&scene=126&sessionid=1681667075#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&appmsgid=10000068&itemidx=1&sign=a8b9363cc051fa86995b636a694953ec&scene=126&sessionid=1681667075#wechat_redirect)

背景介绍：ChinaISG，全称China Information Security Game，由公安部第三研究所主办，该竞赛每年举办一次，已举办多届，以往几届骨哥都是从别人口中得知一些信息，今年有幸参与其中，决定将亲身经历或同事遇到的题目整理后做一个系列报道，一是让那些对信息安全有着浓厚兴趣的童鞋们有所了解，二是将题目的解题思路抛钻引玉，如果各位童鞋有更好的解题思路，非常欢迎将你的答案发送骨哥，骨哥也会甄选出比较优秀的答案发布在本平台分享给大家。

 

\====我是万恶的分割线===

 

本次初赛的最后一轮是一道需要过8关的题目，相信很多童鞋都卡在了第二关，言归正传，下面是8关题目的解题思路：

1.首先第一关：http://172.31.200.99/index.php，查看源代码（网页有JS脚本禁止右键查看，可利用Firefox浏览器中的NoScript之类的插件将其禁用），发现绿色字符串（如下图），利用ASCII码转换后获得第二关地址：http://172.31.200.99/chinaisg2o13.php；

![](../Images/dd5f1fb0a99fb061714f0483826fafb4.png)

2.第二关的页面上多了“USER\_AGENT”提示，因此推断可能需要利用修改网站请求的“头”信息来获得第三关地址，于是利用FireFox浏览器中的“Tamper Data”插件，对“包头”进行修改，将user\_agent改为“chinaisg”后提交（相信很多童鞋看到这里都要吐血了吧，后面还有更坑爹的呢......），得到第三关地址（如下图）：http://172.31.200.99/chinaisg2o1322.php；

![](../Images/5c23a36e2faa26405876c3dde1426c82.png)

3.第三关页面显示一张图片，并附上一段文字说明，于是将图片下载到本地，使用ultraedit打开图片，拖到最末尾发现第四关地址（如下图）：http://172.31.200.99/ec981ssd2.php；

![](../Images/fabaa36ccc19635a98a1fd222c316397.png)

4.仍然利用“TamperData”对网站请求信息抓取，发现该页面登陆时有一段COOKIE信息的提示，于是将Cookie信息修改为“user=admin”后，得到第五关地址（如下图）：

http://172.31.200.99/dkxiFd2.php；

![](../Images/08cda52096ab46d19cf4f7b8a5e3e14a.png)

5.第五关的页面上只显示“url?key”这段简单的提示，

于是尝试将第五关的地址改为：http://172.31.200.99/dkxiFd2.php?key=\*进行尝试，于是很快得到第六关地址（如下图）：http://172.31.200.99/dkxiFd2.php?key=6；

![](../Images/d599f1ec0f6d3eedf6eded7602d4f01c.png)

6.第六关页面显示需要下载isg.7z压缩包，（直接点击链接是无法下载的，实际链接地址应为“http://172.31.200.99/isg.7z”）；

顺利进入第七关页面：http://172.31.200.99/admin.php；是一个需要用户名和密码的登陆框，Title提示为“XX公司员工管理系统”（与之前几关的Title信息有所不同），利用Wireshark工具分析下载来的isg.7z压缩包中的isg.pcap文件，可以得到一个类似登录用户名的信息“sec558user1”，尝试“sec558user1/ sec558user1”、“sec558/user1”、“secuser/5581”等组合猜解，最终发现“sec558user1/sec558”登录成功（骨哥不禁感慨，组委会你们太坑爹啦！！！），获得第八关地址（如下图）：http://172.31.200.99/wo3dpr3ss/；

![](../Images/03e1f661226b92d737892fd9e6fc77d1.png)

7.第八关实为一个WordPress的博客系统，后台是http://172.31.200.99/wo3dpr3ss/wp-admin；所有8关似乎到这里就算结束了，骨哥尝试了几个密码，都无法登陆后台，于是作罢。
