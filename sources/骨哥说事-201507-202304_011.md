再推荐5款 ChatGPT 效率神器：Hotoke AI、ChatPDF、OpenAI Translator 、ChatExcel  
  
1.Hotoke AI  
  
它是一个基于ChatGPT的佛祖平台。非常火！上线仅仅几天，已经为数万人“解决烦恼”，ChatGPT现在已经开始为人类 “佛系”排忧解难了。  
https://hotoke.ai/  
  
2.ChatPDF  
  
基于chatGPT技术的在线应用 –通过它，可以让ChatGPT 帮我们读 PDF 文档，提取关键内容  
https://www.chatpdf.com/  
  
3.OpenAI Translator  
  
基于 ChatGPT API 的翻译程序，翻译出来的结果更符合真人翻译，而不是硬邦邦的机翻。  
https://github.com/yetone/openai-translator  
  
4.通过AI技术帮我们免费设计LOGO

这是一款最近开始火的AI产品，也是基于ChatGPT技术，仅通过聊天来操控您的Excel表格  
https://chatexcel.com/
