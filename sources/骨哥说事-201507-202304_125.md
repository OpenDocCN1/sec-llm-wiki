# 

# **背景介绍：**

  

骨哥最近在做Portswigger的一个“业务逻辑漏洞“实验时，发现了BurpSuite中Macro自动宏脚本的强大功能，特分享给各位：

  

# **实验环境：**

  

先来看看实验环境：

  

# 登录实验所给的账号、密码（wiener/peter）：

![](../Images/b2967a57decdf538e41a08f221ee89ad.png)

  

登录后，可以看到账户中预设了$100.00余额，同时还具有对邮箱进行更新以及购物卡兑换功能：

![](../Images/d150a63b2b03dd53fb59f7a66fc79a4c.png)

  

返回主页面查看，最下方提供了输入邮箱“订阅时讯”的功能：  

![](../Images/aeb313e03398738838356e5f8bf2c84b.png)

  

随便输入一个邮箱注册可以看到获得一个购物“优惠码”：

  

![](../Images/84d9908f5f85ee1849f8e9a3b21aa0c3.png)

  

随便购买一个低于$100价格的商品，然后在结算时使用刚刚获得“优惠码”：

  

![](../Images/d937ec25d20316346efd5c4110f20298.png)

  

支付成功后，可以看到获得一张礼品卡：  

![](../Images/1685ea85d409582f5f8793dd6d85943b.png)

回到账户信息页面，使用刚刚获得礼品卡，发现账户余额变为了$103.00：  

![](../Images/c5a5cbe073d9a5d0d83b178cf5aac793.png)

  

**基于这样的逻辑，我们只需要不断的申请“购物优惠码” -> 结算 -> 使用“购物卡”，如此循环，即可让账户的余额不断增加。**

  

那么下面就要有请Burpsuite中的强大的Macros功能登场了！

  

# **Macros使用：**

  

第一步，增加一条规则，Project options -> Sessions -> Add：  

  

![](../Images/fcd7f0932d4b4ac05c534de6ad8c4c91.png)

  

第二步，脚本适用范围，为了实验方便，索性将Scope中设置为all URLs：  

  

![](../Images/9550f051339f25de386739bd9b77963d.png)

  

第三步，新建一条规则，Rule Actions -> Add -> Run a macro：

  

![](../Images/5f32782576ca8745b19b0a2e9b3982f6.png)

  

第四步，新增一个脚本录制：  

  

![](../Images/a2af5f15bd07a07344e55b0fb7abced9.png)

  

第五步，从抓包记录中，选择要将哪些操作加入宏脚本：

  

![](../Images/9b5b3b224cc0172d7db322a8a995b098.png)

  

根据前面实验环境的了解，我们只需要选择以下5个动作加入宏脚本即可：

  

![](../Images/81490aeda58bb8159f4bfb4d7a4ddd3b.png)

  

第六步，需要让脚本自动获取到响应包中的购物卡直接填入兑换框：

  

1、选中第4个动作，点击右侧的Configure iterm，然后在下方自定义参数中点击Add：  

  

![](../Images/352ea46a4ca743a158d9b846728d0f83.png)

  

2、为参数起个名称，然后在下方的响应请求中找到购物卡的信息，选中它：  

  

![](../Images/08004fd4a145bf0c4938e09819ca7b40.png)

  

3、选中第5个动作，同样点击右侧的Configure iterm，然后在中间栏中的参数设置那里，选择Derice from prior response，选择Response4：  

  

![](../Images/3b7344c1647a7b96b7c5837b6bb11517.png)

4、设置完成后，通过可以点击“Test macro”进行测试，如果可以成功获取到新的购物卡信息，则表示脚本成功：

![](../Images/23dbd0391f70edd7f4436047f97ab74d.png)

  

第七步，回到Burpsuite的抓包信息中，找到添加商品的那条请求，将其加入Intruder，并将所有参数Clear：  

  

![](../Images/97cdf15e8dd23944f097c502e4419df6.png)

  

第八步，将Payload选为“Null payloads”，Payload Options中可以选择次数，骨哥这里选择了跑100次：

  

![](../Images/861724286f8827d80e4fca5e30e99ecf.png)

  

第九步，在Payload发送频率这里，Burpsuite-2021版跟以前旧版有所不同，统一放在了Resource Pool中，将频率设置为2秒发送一次：  

  

![](../Images/44e4e3d7259050de4e5eef98743b1dee.png)

  

第十步，一切妥当后，点击“Start Attack”，开跑：  

  

![](../Images/d98333dc92e366eae25361e60476d915.png)

  

刷新账户信息页面，可以看到余额在不断增加ing...

  

![](../Images/aa3f7c86c86a8f36ee4953e8c783ebc7.png)

  

# **总结：**

通过该实验，学习了Burpsuite中的强大宏功能，对于在实战中要重复进行的一些操作，可以考虑利用该功能进行脚本化实现，省时、省力，加快渗透效率。希望本篇文章也能给各位带来一些收获和不一样的心得，如果你有更好的想法和技巧，也欢迎留言分享。
