继上次13款Chrome渗透插件推荐后，有网友私信说能否推荐一些FireFox浏览器的渗透插件，那么本文就整理了一下火狐上的渗透插件，推荐给各位有需求的同学：


Firefox是Mozilla推出的一款流行的Web浏览器，火狐的流行不仅是因为它是一个很好的浏览器，它同样也支持附加组件来增强自身功能，一些附加组件对渗透人员和安全分析师很有帮助。废话不多说，进入正题：


1、FoxyProxy standard


FoxProxy是火狐浏览器的高级代理管理插件，它改进了Firefox的内置代理功能，骨哥个人感觉与SwitchyOmega的功能差不多，但很多人觉得FoxProxy的功能包括配色看起来与火狐更“搭”。


2、Firebug


大名鼎鼎的Firebug，自然不用多说。一个字：装！就对了。目前FireFox的插件市场中无法找到Firebug，可直接前往Mozilla的官网下载：

https://www.mozilla.org/en-US/firefox/developer/


3、Web Developer


Web Developer在浏览器中添加了更多的 Web 开发工具，可有助于更好的开展 Web 应用程序渗透测试。


4、User agent switcher


可以模拟各种不同版本操作系统、浏览器（比如移动端模拟）打开要访问的网页。



5、Live HTTP headers


这是一款记录浏览器和Internet之间的所有HTTP实时通信的插件，类似BurpSuite的抓包功能。



6、Tamper data for FF Quantum


同样一款类似Burpsuite抓包改包功能的插件，它可以允许用户在网站请求发生时对其进行修改。



7、Hackbar


这个插件不用骨哥多说，必装！谁用谁知道！


8、Web Securify Audit



该插件可以被动地审核用户正在访问的网站的安全状况，帮助用户分析网站服务器的常见易受攻击设置，有点类似BurpSuite的“被动扫描”功能。


9、Cookie-Editor


该插件可以让用户编辑cookie，此插件在劫持易受攻击的测试会话时非常有用，它允许用户删除、编辑、添加/或搜索cookie。它还允许用户保护、阻挡或以JSON格式导出cookie。


10、FOFA Pro View


类似Shodan一样的插件，个人用下来感觉响应速度有些慢。骨哥个人还是比较推荐Shodan。
