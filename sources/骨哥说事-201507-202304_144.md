继上次[13款Chrome渗透插件推荐](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&mid=2650254653&idx=1&sn=d51779cacb9b7baef9af0ab7d10bfe35&chksm=be92c6b989e54faf2b17ff7c4be19d19d69282cf17b155ba0e1778ef1431e265db9253dc7767&scene=21#wechat_redirect)后，有网友私信说能否推荐一些FireFox浏览器的渗透插件，那么本文就整理了一下火狐上的渗透插件，推荐给各位有需求的同学：  

  

Firefox是Mozilla推出的一款流行的Web浏览器，火狐的流行不仅是因为它是一个很好的浏览器，它同样也支持附加组件来增强自身功能，一些附加组件对渗透人员和安全分析师很有帮助。废话不多说，进入正题：

  

1、FoxyProxy standard

![](../Images/cff3230150f2bae4db97dec272fd26f1.png)

  

FoxProxy是火狐浏览器的高级代理管理插件，它改进了Firefox的内置代理功能，骨哥个人感觉与SwitchyOmega的功能差不多，但很多人觉得FoxProxy的功能包括配色看起来与火狐更“搭”。

  

2、Firebug

![](../Images/0897f7c922f50eefb8032e1c7de26e75.png)

  

大名鼎鼎的Firebug，自然不用多说。一个字：装！就对了。目前FireFox的插件市场中无法找到Firebug，可直接前往Mozilla的官网下载：

https://www.mozilla.org/en-US/firefox/developer/

  

3、Web Developer

![](../Images/09dfe25705d6a6fea8815c68aa9bcdc5.png)

  

Web Developer在浏览器中添加了更多的 Web 开发工具，可有助于更好的开展 Web 应用程序渗透测试。

  

4、User agent switcher

![](../Images/0725994d5bbe4825c29c01f876f9d896.png)

  

可以模拟各种不同版本操作系统、浏览器（比如移动端模拟）打开要访问的网页。

  

  

5、Live HTTP headers

![](../Images/54d31ba2dc674774fce90518f708041e.png)

  

这是一款记录浏览器和Internet之间的所有HTTP实时通信的插件，类似BurpSuite的抓包功能。

  

  

6、Tamper data for FF Quantum

![](../Images/f82ba4791ece8d56dd9057dcfd594417.png)

  

同样一款类似Burpsuite抓包改包功能的插件，它可以允许用户在网站请求发生时对其进行修改。

  

  

7、Hackbar

![](../Images/be6fc8fda70f95297516e36bd98f02c1.png)

  

这个插件不用骨哥多说，必装！谁用谁知道！  

  

8、Web Securify Audit

![](../Images/a0d2c2a4c31691c22ab68daa8972c92e.png)

  
  

该插件可以被动地审核用户正在访问的网站的安全状况，帮助用户分析网站服务器的常见易受攻击设置，有点类似BurpSuite的“被动扫描”功能。

  

# **9、Cookie-Editor**

![](../Images/dfb1e9f047f92f61a01562d171b676d7.png)

  

该插件可以让用户编辑cookie，此插件在劫持易受攻击的测试会话时非常有用，它允许用户删除、编辑、添加/或搜索cookie。它还允许用户保护、阻挡或以JSON格式导出cookie。  

# **10、FOFA Pro View**

![](../Images/e6b1139e1fa007d3409cabd973ae230b.png)

  

类似Shodan一样的插件，个人用下来感觉响应速度有些慢。骨哥个人还是比较推荐Shodan。

  

另外，越来越多的同学开始使用微软的Edge浏览器，关于Edge浏览器的插件使用，我在之前的文章中也有写过，大家除了可以直接使用插件市场安装插件，也可以参考[Edge使用Chrome插件教程](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&mid=2650253921&idx=1&sn=6fe8d4b5a2e5c461fd104fd23562c7c9&chksm=be92c1e589e548f3ea1b075d1cc78e97f65d67a65573754796f670ff88ebaad6b588de07bc02&scene=21#wechat_redirect)，来实现Edge共用Chrome插件。
