# 思科Jabber漏洞可致黑客远程攻击Windows系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mzc4MzUzMQ==&mid=2650254178&idx=1&sn=24948de7cb04feac9f5c9fb05cafde2d&chksm=be92c0e689e549f090bcbb6cf564d0d218d62eb42fd41454d4a1f266cb4cbf9b7ff50f83f74f&scene=126&sessionid=1681667021#rd](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&mid=2650254178&idx=1&sn=24948de7cb04feac9f5c9fb05cafde2d&chksm=be92c0e689e549f090bcbb6cf564d0d218d62eb42fd41454d4a1f266cb4cbf9b7ff50f83f74f&scene=126&sessionid=1681667021#rd)

网络设备制造商思科(Cisco)发布了用于Windows的Jabber视频会议和消息应用的最新版本，其中包括针对多个漏洞的补丁。如果漏洞被利用，经过身份验证的远程攻击者就可以执行任意代码。

  

挪威网络安全公司Watchcom在一次渗透测试期间发现了这些漏洞，这些漏洞影响了Jabber客户端目前支持的所有版本(12.1-12.9)，目前Cisco已修复了这些漏洞。

  

四个漏洞中的两个可以通过在组对话或特定的个人对话中发送特殊编写的聊天消息来获得目标系统上的远程代码执行(RCE)。

  

最严重的是一个漏洞(CVE2020-3495, CVSS评分9.9)是由错误的消息内容验证引起的，可被攻击者利用，通过发送恶意精心设计的可扩展消息和存在协议(XMPP)消息到受影响的软件。

  

思科(Cisco)在昨天发布的一份报告中表示:“一个成功的漏洞可以让攻击者利用运行思科Jabber客户端软件的用户帐户的特权，使应用程序在目标系统上执行任意程序，可能导致任意代码执行。”

  

就在几天前，思科(Cisco)警告称，其IOS XR路由器软件存在一个被积极利用的零日漏洞。

  

**XSS缺陷到RCE缺陷**

  

XMPP（最初称为Jabber）是一种基于XML的通信协议，用于促进任何两个或多个网络实体之间的即时消息传递。

  

它还被设计为可扩展的，以适应其他功能，其中之一就是XEP-0071：XHTML-IM-规范了使用XMPP协议交换HTML内容的规则。

  

Cisco Jabber中的漏洞来自解析XHTML-IM消息时的跨站点脚本(XSS)漏洞。

  

Watchcom的研究人员解释说:“该应用程序不能正确地清理传入的HTML消息，而是通过一个有缺陷的XSS过滤器来传递消息。”

  

因此，可以拦截和修改合法的XMPP消息，从而导致应用程序运行已经存在于应用程序的本地文件路径中的任意可执行文件。

  

![](../Images/3854cc12b926b7b0b7e1d4efd417b411.png)

为了实现这一点，它利用了Chromium嵌入式框架(CEF)中一个单独的易受攻击的功能，CEF是一个用于在其他应用程序中嵌入Chromium浏览器的开源框架，它可能会被一个破坏者滥用以执行恶意行为，受害者机器上的".exe" 文件。

  

然而，攻击者成功利用漏洞需要访问受害者的XMPP域来发送恶意的XMPP消息。

  

此外，Jabber中还有三个漏洞(CVE-2020-3430、CVE-2020-3498、CVE-2020-3537)可以被利用注入恶意命令，导致信息泄露，其中可能包括窃取用户NTLM密码散列。

  

随着视频会议应用程序在疫情爆发后变得越来越流行，Jabber的用户必须尽快更新到该软件的最新版本，以减轻风险。

  

Watchcom表示:“鉴于它们在各种规模的企业中都很流行，这些应用程序正成为攻击者越来越有吸引力的目标。”“很多敏感信息都是通过视频电话或即时消息分享的，大多数员工都在使用这些应用程序，包括那些有权访问其他IT系统的员工。”

  

“因此，这些应用程序的安全是至关重要的，确保应用程序本身及其使用的基础设施定期进行安全漏洞审计很重要。”
