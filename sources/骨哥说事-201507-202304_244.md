# 来！干了这碗鸡汤！

一个教授先拿出一个空罐子

  

![](../Images/3ada3c33d2bf3cbc658f7f7779110c7f.png)

  

然后教授把高尔夫球放到罐子里，问学生罐子满了吗，学生说满了  

  

![](../Images/5a7165a6dc32815276533a1c00974ebd.png)

  

然后教授又把小石头、沙子放到罐子里，问学生满了吗，学生说满了

  

![](../Images/ceee2d0ec5599dae849704ebfe23f6ac.png)

  

最后，教授又在满满的罐子里倒入了一些啤酒

  

![](../Images/343fa4528c34ba0c12441812c439328c.png)

教授说：

*   罐子就是你们的时间、人生；
    
*   高尔夫球代表最重要的事情，石头、沙子代表其他重要的事情、小事；
    
*   如果先把石头、沙子放到罐子里，你就放不进去高尔夫球了；
    
*   也就是说如果你把时间精力都消耗在小事上，你就不会有时间去做真正重要的事情了；
    
*   人生应该优先、专注那些重要的事情
    
*   最后的啤酒代表啥呢？不管你时间多么紧凑，仍然有空和朋友们把酒言欢。
