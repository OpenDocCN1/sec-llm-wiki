# 高通芯片缺陷可以让黑客窃取Android设备中的私人数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mzc4MzUzMQ==&mid=2650253462&idx=1&sn=ecd4d33cd0d2990ba00d219ab57f0f69&chksm=be92c31289e54a04372c60eb9d0aa88c101403fd8dfa3715089db9fa7e0b898e6116df1beec9&scene=126&sessionid=1681667030#rd](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&mid=2650253462&idx=1&sn=ecd4d33cd0d2990ba00d219ab57f0f69&chksm=be92c31289e54a04372c60eb9d0aa88c101403fd8dfa3715089db9fa7e0b898e6116df1beec9&scene=126&sessionid=1681667030#rd)

使用高通芯片的数亿台设备（尤其是Android智能手机和平板电脑）容易受到一系列潜在严重漏洞的攻击。  
  
根据网络安全公司CheckPoint与The Hack News分享的一份报告，这些漏洞可能会让攻击者窃取存储在安全区域的敏感数据，而这些安全区域本应是移动设备中最受保护的部分。

  
  
该漏洞位于高通公司的安全执行环境（QSEE）中，该系统是基于ARM TrustZone技术的受信任执行环境（TEE）的实现。  
  
QSEE也称为高通公司的安全世界，是主处理器上一个硬件隔离的安全区域，旨在保护敏感信息，并为执行受信任的应用程序提供一个独立的安全环境(REE)。  
  
除了其它个人信息，QSEE通常包含私人加密密钥、密码、信用卡和借记卡凭证。

  

由于它是基于最小特权原则，因此除非有必要，否则即使驱动程序和应用程序等Normal World系统模块具有root权限也无法访问受保护区域。

  

> 研究人员告诉The Hack News：“在一个为期4个月的研究项目中，我们成功地逆向了高通公司的Secure World操作系统，并利用了模糊测试技术暴露了漏洞。”

  

> “我们实现了一个定制的Fuzzing工具，在三星、LG和摩托罗拉的设备上测试可信代码，”这使得研究人员可以找到三星实施的可信代码中的四个漏洞，其中一个在摩托罗拉中，一个在LG中。

  

*   dxhdcp2 (LVE-SMP-190005)
    
*   sec\_store (SVE-2019-13952)
    
*   authnr (SVE-2019-13949)
    
*   esecomm (SVE-2019-13950)
    
*   kmota (CVE-2019-10574)
    
*   tzpr25 (acknowledged by Samsung)
    
*   prov (Motorola is working on a fix)
    
      
    

![](../Images/7b6f1aacd363fd420aa197a1660d79c2.png)

据研究人员称，高通安全组件中所报告的漏洞可使攻击者能够：

  

*   在正常世界（Android OS）中执行受信任的应用
    
*   将修补的受信任应用程序加载到安全世界（QSEE）中
    
*   绕过高通的信任链
    
*   调整受信任的应用程序以使其在其他制造商的设备上运行
    
*   以及更多
    

  

“一个有趣的事实是，我们也可以从另一个设备加载信任密钥。我们要做的就是用从设备制造商的信任密钥中提取的哈希表，签名和证书链替换信任密钥的.mdt文件中的哈希表，签名和证书链。”研究人员称。

  

简而言之，TEE组件中的漏洞使设备容易遭受各种安全威胁，包括受保护数据的泄漏，设备Root，引导加载程序解锁以及无法检测到的APT攻击。  
  
该漏洞还影响使用QSEE组件保护用户敏感信息的各种智能手机和IoT设备。  
  
Check Point Research负责地向所有受影响的供应商披露了调查结果，其中三星，高通和LG已针对这些QSEE漏洞发布了补丁更新。
