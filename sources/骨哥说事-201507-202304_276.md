# 新的PHP漏洞可能使攻击者入侵在Nginx服务器上运行的站点

如果您正在NGINX服务器上运行任何基于PHP的网站，并且启用了PHP-FPM功能以提高性能，请当心一个最新公开的漏洞，该漏洞可能允许未经授权的攻击者远程入侵您的网站服务器。  
  
该漏洞为**CVE-2019-11043**，影响具有某些PHP-FPM配置的网站，据报道这种配置在野外并不罕见，并且很容易地利用，该漏洞的概念验证（PoC）已经公开发布。  
  
**PHP-FPM**是另一种PHP FastCGI实现，可为用PHP编程语言编写的脚本提供高级且高效的处理。  
  
主要漏洞是PHP-FPM模块中的“ env\_path\_info”下溢内存损坏问题，将它与其他问题链接在一起可以允许攻击者在脆弱的web服务器上远程执行任意代码。

  

该漏洞是Wallarm的安全研究员安德鲁·达瑙(Andrew Danau)在一次名CTF(Capture The Flag)竞赛中发现的，当时他正在寻找漏洞，后来他的两位同事奥马尔·加尼耶夫(Omar Ganiev)和埃米尔·勒纳(Emil Lerner)将其升级为‘武器’，以开发一种完全可用的远程代码执行漏洞。

  

## 哪些基于PHP的网站容易受到黑客的攻击？

  

尽管公开发布的PoC漏洞专门针对运行PHP 7+版本的易受攻击的服务器，但PHP-FPM下溢错误也影响早期的PHP版本，并且可以采用其他方式进行攻击。  
  
简而言之，如果存在以下情况，则网站容易受到攻击：  
  

*   NGINX配置为将PHP页面请求转发到PHP-FPM处理器
    
      
    
*   fastcgi\_split\_path\_info指令出现在配置中，包括一个以'^'符号开头、以'$'符号结尾的正则表达式，
    
      
    
*   PATH\_INFO变量是使用fastcgi\_param指令定义的
    
      
    
*   没有像try\_files $ uri = 404或if（-f $ uri）之类的检查来确定文件是否存在。

## PHP 7更新发布以修补FPM缺陷

  

  

如上所述，成功利用的先决条件并不罕见，因为一些Web托管提供商正在使用易受攻击的配置，并且许多PHP FPM教程的一部分可在Internet上获得这些配置。

  

受影响的网络托管提供商之一就是Nextcloud，该公司昨天发布了一份警告，警告其用户“默认的Nextcloud NGINX配置也容易受到此攻击”，并建议系统管理员立即采取行动。  
  
在研究人员向PHP开发人员小组报告该漏洞后近一个月，该漏洞补丁已于昨天发布。  
  
由于PoC攻击已经可用，并且补丁昨天才发布，因此黑客很可能已经开始扫描互联网来搜索易受攻击的网站。  
  
因此，强烈建议用户将PHP更新到最新的**PHP 7.3.11**和**PHP 7.2.24**。即使您没有使用易受攻击的配置，也应该这样做。
