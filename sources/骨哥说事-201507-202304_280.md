# 研究人员发现在野针对Microsoft SQL Server后门恶意软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MjM5Mzc4MzUzMQ==&mid=2650253321&idx=1&sn=70978b210e0de80e4109d5057387e5f1&chksm=be92c38d89e54a9b324826656fe5b70a757dc237a55c45410bbcdf52cb2373a15e6178723251&scene=126&sessionid=1681667031#rd](http://mp.weixin.qq.com/s?__biz=MjM5Mzc4MzUzMQ==&mid=2650253321&idx=1&sn=70978b210e0de80e4109d5057387e5f1&chksm=be92c38d89e54a9b324826656fe5b70a757dc237a55c45410bbcdf52cb2373a15e6178723251&scene=126&sessionid=1681667031#rd)

网络安全研究人员声称，他们发现了一个以前没有记录的后门，专门为Microsoft SQL服务器设计，可以让远程攻击者秘密地控制一个已经被入侵的系统。

  

这个被称为Skip-2.0的后门恶意软件是一个运行在内存中的利用工具，它允许远程攻击者使用一个“魔法密码”连接到运行MSSQL version 11和version 12的服务器上的任何帐户。

  

恶意软件通过在每次使用“魔法密码”时禁用受害机器的日志功能、事件发布和审计机制，以保证不被受害者的MSSQL服务器检测到。

  

有了这些功能，攻击者可以偷偷地复制、修改或删除存储在数据库中的内容，其影响因应用程序的不同而不同，这些应用程序与目标服务器集成在一起。

  

“例如，这可能被用来操纵游戏内的货币以获取经济利益，Winnti运营商数据库中的游戏货币被操作曾被报道过。”研究人员称。

  

**中国黑客创建了 Microsoft SQL Server 后门**

![](../Images/c484c14c804cca3b460c4f2b74bb65a2.png)

  

在网络安全公司ESET发布的最新报告中，研究人员将Skip-2.0后门归因于中国政府资助的Winnti group威胁行为组织，因为该恶意软件与其他已知Winnti group工具存在多种相似之处，尤其是portrecycling后门和ShadowPad。

  

本月早些时候，ESET首次记录了PortReuse backdoor，它将自己注入一个已经在监听TCP端口的进程，“重用”一个已经打开的端口，然后等待到来的魔法包从而触发恶意代码。

  

在2017年7月针对软件制造商NetSarang的供应链攻击中首次出现，ShadowPad是一个Windows后门，攻击者部署在受害网络上，以获得灵活的远程控制能力。

  

与其他Winnti Group有效载荷一样，Skip-2.0也使用了加密的VMProtected launcher、自定义打包程序、内部加载注入和挂钩框架来安装后门，并通过利用Windows进程中的DLL劫持漏洞来持久的存在于目标系统上。

  

由于Skip-2.0恶意软件是一种后利用工具，攻击者首先需要对目标MSSQL服务器进行攻击，以获得必要的管理特权，从而实现持久性和隐蔽性。

  

“请注意，尽管MSSQL Server 11和12不是最新的版本(分别在2012年和2014年发布)，但根据Censys的数据，它们是最常用的版本，”研究人员称。
