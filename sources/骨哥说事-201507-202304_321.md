# Black Hat 2019 WhatsApp 协议解密与消息篡改

研究人员： Dikla Barda，Roman Zaikin和Oded Vanunu

  

据消息人士透露，Facebook拥有的消息应用程序WhatsApp在180多个国家/地区拥有超过15亿用户，普通用户每天打开WhatsApp超过23次，预计到2021年，美国WhatsApp用户数量将增长至2560万。

  

考虑到所有的流言蜚语，网络诈骗、谣言和假新闻的可能性是巨大的。威胁者的“武器库”中还有一个额外的"武器"-可以利用消息平台实现他们的恶意意图。

2018年底前，Check Point Research向WhatsApp通报了消息传递应用程序中的新漏洞，这些漏洞将使威胁者能够拦截和操纵在私人和群组对话中发送的消息，从而使攻击者从值得信赖的来源中能够创建和传播看似错误的信息。

Check Point Research团队观察到三种可能利用此漏洞的攻击方法 - 所有这些攻击都涉及社交工程策略以欺骗最终用户，威胁者可以：

1.  使用群组对话中的“引用”功能更改发件人的身份，即使该人不是该群组的成员。
    
2.  改变别人的回复文本，看起来像是从他们口中所说。
    
3.  向另一个群组发送一个私有消息，该消息伪装成面向所有人的公共消息，因此当目标个人响应时，对话中的每个人都可以看到该消息。
    

  

WhatsApp修复了第三个漏洞，该漏洞允许威胁者向另一组参与者发送伪装成公共信息的私人信息，但是我们发现仍然可以操纵引用的消息并从看似可信的来源传播错误信息。

在负责任披露过程之后，Check Point Research向WhatsApp通报了其调查结果，从Check Point Research的角度来看，我们认为这些漏洞至关重要，需要引起注意。

为了在WhatsApp中演示此漏洞的严重性，我们创建了一个工具，允许我们解密WhatsApp通信并欺骗消息。

众所周知，WhatsApp会对您发送的每封邮件，图片，电话，视频或任何其他类型的内容进行加密，以便只有收件人才能看到它。WhatsApp无法查看这些消息。

![](../Images/0472c209d83d1f48f5275432d2530b0a.png)

图1：  WhatsApp加密聊天

  

这些加密过程引起了我们的注意，我们决定尝试颠覆WhatsApp的算法来解密数据。事实上，在解密WhatsApp通信后，我们发现WhatsApp正在使用“ protobuf2协议 ”来实现这一目的。

通过将protobuf2数据转换为Json，我们能够看到发送的实际参数并对其进行操作以检查WhatsApp的安全性。

我们的研究结果是一个  Burp Suit 扩展 插件 和  **3种操作方法** （其中第三种方法是已经修复的我们向WhatsApp披露的漏洞）

但是在开始操作前，我们首先必须获取会话的私钥和公钥，并将其填入我们的burpsuit扩展插件中。

这里要注意的有趣参数是：

*   conversation - 这是发送的实际内容。
    
*   participant  - 这是实际发送内容的参与者。
    
*   fromMe  - 此参数表示是否由我发送了数据给组中的其他人。
    
*   remoteJid  - 此参数表示数据发送到哪个组/联系人。
    
*   id  - 数据的id，相同的ID将出现在手机数据库中。
