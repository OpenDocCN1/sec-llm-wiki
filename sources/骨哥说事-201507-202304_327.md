# KDE Linux桌面可能会在没有打开恶意文件的情况下被黑客攻击

如果您在Linux操作系统上运行KDE桌面环境，则需要格外小心，一段时间内请避免下载任何“.desktop”或“.directory”文件。  
  
一名网络安全研究人员在KDE软件框架中披露了一个未修补的零日漏洞，该漏洞可能允许恶意制作的.desktop和.directory文件在用户的计算机上静默运行任意代码，甚至不需要受害者实际打开它。  
  
KDE Plasma是Linux用户最流行的基于窗口小部件的桌面环境之一，是许多Linux发行版的默认桌面环境，如Manjaro，openSUSE，Kubuntu和PCLinuxOS。

  

发现漏洞的安全研究员Dominik Penner联系了The Hacker News，告知KDE 4/5 Plasma桌面存在命令注入漏洞，原因与KDE处理.desktop和.directory文件的方式有关。  
  
“当实例化.desktop或.directory文件时，它通过KConfigGroup :: readEntry（）函数，使用了不安全的KConfigPrivate :: expandString（）环境变量和Shell扩展” Penner说。  

  

利用这个影响KDE Frameworks包5.60.0及更低版本的缺陷很简单并涉及一些社交工程，因为攻击者需要欺骗KDE用户下载包含恶意.desktop或.directory文件的存档。  
  

> “使用特制的.desktop文件，远程用户只需在文件管理器中下载和查看文件，或者将其链接拖放到文档或桌面中就可能会受到影响，”研究人员解释说。  
>   
> “从理论上讲，如果我们可以控制配置条目并触发读取，我们就可以实现命令注入/ RCE。”

  
作为概念验证，Penner还发布了漏洞利用代码以及两个成功演示利用KDE KDesktopFile命令注入漏洞的攻击场景的视频。**（骨哥注：****以下是搬运过来的其中一个视频演示）**

显然，研究人员在发布详细信息和PoC漏洞之前没有向KDE开发人员报告漏洞，KDE社区承认了该漏洞并向用户保证修复工作正在进行中。  
  

> “此外，如果您发现类似的漏洞，最好在公开之前发送电子邮件security@kde.org。这样我们就有时间修补它并在坏人试图利用它之前保证用户安全，”KDE社区说。

  
与此同时，KDE开发人员建议用户“避免从不受信任的来源下载.desktop或.directory文件”，直至漏洞被修补。
