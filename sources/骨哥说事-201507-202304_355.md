# 一部非常值得一看的“性教育”短片

昨晚翻看我的豆瓣时，发现在“想看”列表里有一部《父与子的性教尬聊》的影片，努力回想之下，想起应该是在某APP时看到别人的推荐，当时顺手在豆瓣上做了mark，于是昨晚一口气将这部剧刷了，并在自己的朋友圈做了安利，同时有了今天这篇公众号的推送。

  

我们一直以来缺失了2门重要的课程，一门关于--“生“(性教育），一门关于“死“（死亡教育），家长、学校几乎很少正面传授，而我们大多数人都是靠自学成才（感谢cang老师![](../Images/d6f0f32199f9131affa08586bbd287ea.png)）。而这两门课程却是我们每个人生命中的重要课程。

  

推荐指数：★★★★★

每集时长：10~15min

  

这其实是印度在2016年播出的一部迷你家庭喜剧，短片通过父子一问一答的形式，将我们一直以来谈之色变的“性教育”以诙谐、轻松的方式展现给了每位观众。

  

影片简介：

> 　一个好奇的7岁小男孩帕普，从抛出“什么是自慰”一问开始，不停地提问爸爸阿南德性知识方面的问题。虽然爸爸最初很尴尬，但他尽其所能地用各种简单的生活事例、生动的童话故事解答着儿子的这类困惑，最终带来了很多乐趣。然而他自己的父亲却是一个非常传统、保守的人，一直在质疑他的这些行 为，还不时地冒出来分散他的注意力，阻止他与儿子进行“尬聊”。他那怀孕的妻子与和蔼的母亲也在这场疯狂的冲突之间徘徊，并帮助“父与子”找到了平衡。

  

这部短片一共5集，分别解释了5个不同的问题，第一集“什么是自慰？”、第二集“我从哪里来？”、第三集“什么是保险套？”、第四集“什么是大姨妈？”和第五集的“什么是同性恋？”，其中第4、第5集给骨哥的印象最为深刻，影片中父亲用电子邮件的比喻生动形象的讲解了什么是“大姨妈”，而第5集中不但解释了什么“同性恋”，更是直面这一问题在国家法律层面的尴尬。
