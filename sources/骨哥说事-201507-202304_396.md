今天来咱们来说说约翰卡马克（John D. Carmack II）这位大神，这位大神被称为“3D 游戏之父”的大神又会有怎样非比寻常的人生呢？

![](../Images/bcee4e51b8ff2aa512f170bb8342a9b1.png)

 

# **儿时**

* * *

#   

1970年出生的卡马克，小名约迪，儿时家境还是很不错的，父母曾是堪萨斯城较为有名电视台的新闻主播，于是他们一家很早就搬到了郊外的富人区居住，这一年，卡马克有了自己的弟弟，他也进入了圣母玛利亚天主教小学，这个从一岁时就戴着眼镜，长着一头金发看起来有些瘦小的男孩儿却很快在当地这所学校展示出了与众不同的一面。

 

**彩蛋1：据说卡马克开口说话比较晚，大概在他15个月大的时候，才开口说了第一句话“爸爸，你的洗澡巾。”**

# **初露锋芒**

* * *

#   

卡马克七岁时就几乎在所有标准化测验里获得了满分的成绩（据说这个成绩相当于九年级的水平），他还养成了一种独特的口吃习惯（喜欢在每句话后面加上简短的类似机器人那样的嗡嗡声）。

  

他在就读高中时，被同学和老师们认为是“怪才”，因此被学校视为心理问题，被停课一年。复课后，卡马克还是拿到了毕业证书，并顺利考入了当地著名的堪萨斯大学，在编程方面，卡马克几乎是无师自通，大一还没读完，他编写的一些小游戏就被不少软件公司买走哦，于是他也成为了几家公司的兼职程序员。

  

![](../Images/bcc059e56a57f7eac0d75e574629d571.png)

**彩蛋2：对于无师自通，卡马克家族似乎有着自学成才的传统，他的爷爷只上过两年学，却自学成了一名电气工程师。**

然而他的大学生活仅仅维持了两个学期，便主动提出了退学，原因是他觉得大学的课程全都是靠死记硬背的能力，毫无挑战，缺少创造性。（画外音，难道国外也是应试教育么？）

  

# **奋斗经历**

* * *

#   

1990年，正值20岁的卡马克迎来了计算机技术发展的黄金时代，然而此时的软件多以商业用途为目的，游戏却少人问津。当时一家Softdisk的软件公司找到了卡马克，希望他能够加入一起开发游戏软件。出于对游戏软件的热爱，他毫不犹豫的同意了对方的邀请。

  

在这家公司工作了一年后，卡马克决定自己创业，他与朋友共同创办了IDSoftware游戏公司，1993年的时候他们做出了《德军总部3D》，游戏界第一款仿3D的作品，风靡全球的386电脑。而次年，卡马克完了成名作《Doom》，不到一年的时间，这款游戏就售出了几百万份拷贝，也给IDSoftware创造了过亿的利润，而当时这家公司只有13人。

  

![](../Images/53e28505fe377bf4589a1c473db533fd.png)

  

**彩蛋3：曾经有一次，卡马克的朋友为了测试他的注意力，特意租了一盘H影片，并把音量开到最大，他的朋友很快就被影片中的声音吸引到了电视机旁，而卡马克却无动于衷地坐在电脑跟前，直到过了一两分钟，他才察觉到了异样，而他只是简单地“嗯”了一声，然后就继续埋头工作。**

  

# **一次挑战**

* * *

#   

1998年，卡马克对自己进行了一次挑战-------在21点游戏中记牌。在出发前他进行了一些训练，他先是买了一些书来看，然后在计算机上写出程序模拟，第一次他就在赌场中赢得了两万美元，他也将这笔钱捐给了自由软件基金会（FreeSoftware Foundation），在他第二次前往拉斯维加斯赌场时，几个彪形大汉围到了他的身边对他说“如果你不玩21点而改玩其它游戏的话，我们将不胜感激。”

  

**彩蛋4：赌场上邻桌的女人问卡马克他们为何对你这么说话，卡马克说“他们认为我在记牌”，女人非常诧异的问“他们认为你能记住所有这些牌？天哪，请问你是做什么的？”，卡马克如实回答“我是个程序员”，说完他便被彪形大汉护送着走出了赌场。（画外音，是被客气地轰出去了吗？汗~~）**

# **热衷开源**

* * *

#   

卡马克是一个热衷开源运动的倡导者，他也再三强调反对“软件专利”，所以在卡马克内心一直是很鄙视苹果这类软件专利的公司，在他眼里，这简直荒谬绝伦，于是在1995年他放出了《德军总部3D》的源代码，之后又公布了《DOOM》和《Quake-III Arena》的源代码，这些代码的公布全部遵循了GPL准则。

  

这些开源出来的东西简直牛逼爆了，比如使用《Quake-IIIArena》引擎制作的《半条命》后来风靡全球，用知乎上一位网友的话来说就是“我给你们抄袭，因为你们永远超越不了我……”

  

而在公开的《Quake-IIIArena》源代码中，人们被其中一段代码震惊了，这是一个求平方根倒数的算法（***扩展阅读，点击最下方“阅读原文”***），源代码种使用了一个十六进制的魔术数字“0x5f3759df”（据未经证实的说法，该算法其实并不是卡马克发明的，它真正的作者是Nvidia的Gary Tarolli），通过这个魔术数字获得平方根倒数的首次近似值，而后重新将其作为浮点数，以牛顿法反复迭代，以求出更精确的近似值，直至求出符合精确度要求的近似值，更为牛逼的是该算法比直接使用浮点数除法提高了四倍。

  

**彩蛋5：普渡大学的数学家Chris Lomont看了以后也觉得很有趣，决定要研究一下卡马克弄出来的这个猜测值有什么奥秘。Lomont也是个牛人，在精心研究之后从理论上也推导出一个最佳猜测值，和卡马克的数字非常接近, 0x5f37642f。Lomont计算出结果以后非常满意，于是拿自己计算出的起始值和卡马克的神秘数字做比赛，看看谁的数字能够更快更精确的求得平方根，结果居然还是卡马克赢了...**

**Lomont怒了，采用暴力方法一个数字一个数字试过来，终于找到一个比卡马克数字要好上那么一丁点的数字，虽然实际上这两个数字所产生的结果非常近似，这个暴力得出的数字是0x5f375a86。**

# **后记**

* * *

#   

卡马克在《DOOM》系列游戏成功后，拥有了不菲的身价，他喜爱豪车，于是买了二十多辆豪车。玩腻了豪车之后，他又成为了一名火箭技术爱好者，2000年左右还成立了自己的宇航公司犰狳航空公司(ArmadilloAerospac)，特斯拉的创始人ElonMask在推特上曾向他抛出橄榄枝“既然您这么喜欢火箭，干脆来SpaceX咱们一块去探索火星吧！”

  

卡马克10岁儿子Ryan使用Racket编程语言开发了一个游戏叫 FLY，这不是Ryan开发的第一个游戏，他之前还开发了一个游戏叫 Angry Face。Ryan在他的个人网站上放出游戏下载，称他还学习用Blender做3D建模和动画，用 Audacity做声频（跪了，果然虎父无犬子）。

  

![](../Images/0f56f0c2c29d068443be9954adb6610b.png)

  

卡马克目前特别看好移动VR，于是他加入了Oculus（一家VR技术公司）这家公司，在Oculus未被Facebook收购的时候，他独自负责Gear VR的项目，由于三星公司的官僚作风，并未开放给卡马克必要的手机设备（前置缓冲区）的访问权限。

  

**彩蛋6：卡马克是如何做到的呢，据他自己说，“和三星前几个月的合作令人非常沮丧……为了打破这个僵局，我想到了一个办法，黑了他们的手机。”**

![](../Images/4768d7a1676bd2f4754e0ee3f6a97f62.png)

  

他就是这样一位神奇的大神，大学半途辍学，受到盖茨尊重，与马斯克谈笑之间探讨火箭技术，和小扎并肩共同迎战VR未来，也许还会有更精彩的故事上演。让我们拭目以待！
