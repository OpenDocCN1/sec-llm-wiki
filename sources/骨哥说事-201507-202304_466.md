# 谈谈CTF

  我第一次听闻CTF的时候，大概是在2010左右，那时候所在公司的安全部有几位做渗透测试的同事参加了上海ISG举办的信息安全竞赛，其中一名同事还获得了第一名的佳绩。

  

  而真正参加ISG，则是在这之后的2013年下半年，同样也是参加ISG每年举办的信息安全竞赛，这一届比赛也是第一次采用了线上预选赛的方式，然后选出前10名选手进入半决赛，而半决赛可允许选手带上两名队友共同参加，预选赛我没能进入前10名，因为是第一次参加这样的比赛，所以就将当时做题的思路写了出来并发布在公众号上（[ChinaISG信息安全竞赛题目解析（一）](http://mp.weixin.qq.com/mp/appmsg/show?__biz=MjM5Mzc4MzUzMQ==&appmsgid=10000068&itemidx=1&sign=a8b9363cc051fa86995b636a694953ec#wechat_redirect)），心想这次比赛就这样被拦在门外了，多少有些失落。但幸运的是，网友“过客”因为看到我写的Writeup联系到我，并邀请一同进行半决赛，于是我有幸见识了那一次比赛的半决赛，也认识了逆向大牛“softdebug（看雪ID）”，也是从这一届CTF，我开始越来越多的接触CTF比赛。

  

  ISG的信息安全竞赛结束后没多久，百度公司便举办了第一届BCTF（百度杯全国网络安全技术对抗赛），于是“过客”建立了QQ群，叫来了几位有共同爱好的小伙伴，决定一起参加BCTF，2014年3月的一个周末，我们组建了111110101战队，开启了BCTF的征战，最终在200多支队伍中获得了39名的成绩，现在回想起来，那48小时的鏖战依然历历在目。

  

  在接下来的日子里，11111010战队参加了各种国内的CTF比赛，由于队伍中有“梓鹏”、“RickGray”这样大牛的加入，随着比赛经验的不断增加，队伍开始在各大比赛中崭露头角......（当然，随后的比赛我就没怎么参与了，只能作为围观者默默的仰望），而在2014年、2015年间，我逐渐开始向Android安全方向转移，也参加了第二届阿里移动安全竞赛以及2015年ISG信息安全竞赛中的移动题目。

  

  话说感觉话题与标题有点不符啊，怎么感觉有点回忆录的味道？咳咳~言归正传，今天的主题其实主要是CTF的扫盲帖，首先来说一下CTF的概念。

  

  *“CTF（Capture The Flag）中文一般译作夺旗赛，在网络安全领域中指的是网络安全技术人员之间进行技术竞技的一种比赛形式。CTF起源于1996年DEFCON全球黑客大会，以代替之前黑客们通过互相发起真实攻击进行技术比拼的方式。发展至今，已经成为全球范围网络安全圈流行的竞赛形式。”（来自百科）*  

  

 2013年似乎是国内CTF崛起元年，当时参加BCTF的时候，我还在群里调侃说“以后CTF也许会像电子竞技一样火热，说不定还会产生CTF经纪人的职业”，现如今CTF有多火爆，相信各位也有目共睹了。

  

  CTF一般分为6大类题目，“Misc”、“Reverse”、“Crypto”、“Exploit”、“Web”和“Stega”，现在有些比赛可能会分的更细一些，如增加“Networking”和“Mobile”的题型，每类题目中考题一般由易到难，分数也相应的从低至高。下面是对这几类题目的一个简要介绍：

  

  Misc其实是英文Miscellaneous的前四个字母，意思是杂项、混合体、大杂烩的意思，这类题目范围很广，可能会给你一个网络抓包让你分析传输数据，也可能是一个让你脑洞大开的“急转弯”题目，总之这个类别的题目挺考验“跳跃性思维”的。

  

  Reverse（逆向），主要是考察参赛者的逆向技术，一般会给你一个程序，让你在逆向分析中找到FLAG，一些还会在程序中进行加壳处理和增加反调试技术以增加题目难度。

  

  Crypto（加解密），主要考察参赛者的密码学知识，一般会对题目进行一些加密处理（如各常见的各类加密技术：凯撒、CRC、MD5...），然后由参赛者进行解密后获得FLAG。

  

  Exploit（渗透），主要考察参赛者的渗透能力，近两年这类题目更注重参赛者的实战能力，比如给参赛者一个系统，要求渗透进该系统，并获得某个目录下的文件，而这个文件中则存放着FLAG，对参赛者的综合能力要求比较高。

  

  Web（网站安全）， 这个类型的题目考察面也是相当广的，不但要求参赛者对前端技术有非常坚实的基础，而且要对前端安全非常了解，前端的各种知识几乎都会涉及，Cookie、Http Header、JSON、JS、SQL注入、XSS、目录遍历、弱口令等等无所不在。

  

  Stega（隐写术），英文Steganography的前五个字母，一般会给参赛者一些图片或文件，参赛者需要通过各种工具和分析，从这些图片或文件中找出FLAG。

  

  而对于刚刚入门CTF的同学们可能经常会问，要学习哪些知识，我个人觉得，既然选择了“信息安全”，那么就注定要有很广的知识面，不仅要对汇编、加解密有所了解，也要对网络协议、网站代码、软件开发加以学习，然后找出你擅长的部分加以磨炼，取长避短，再找到几个与你“互补”的小伙伴们，组起队伍，征战乐（nao）趣（dong）无限的CTF吧！
