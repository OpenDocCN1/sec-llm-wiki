# 推荐两款正在使用的神器

推荐两款正在使用的神器，如果各位对下载，尤其是网页视频下载比较感兴趣的话，可以试试我下面推荐的这两款神器：

  

**1\. EagleGet**

**为了上网安全，强烈建议官方下载！**  

官方网站：http://www.eagleget.com/

  

厌倦了迅雷的弹窗、边栏广告，会员制度了是吗？那么试试这个小众的神器吧，界面简洁，无弹窗，无广告，很棒的用户体验。

  

![](../Images/e02ae64650737ae6e29a3f539fcae783.png)

喜欢追剧、看电影或者逗趣视频的童鞋们，通过“视频抓取”功能，便可以顺利下载（格式为.flv&.mp4）。  

  

比如打开土豆网，随便点开一个视频，然后将视频的URL复制到“视频下载”的网址处，然后点右侧的‘放大镜’按钮，妥妥的下载吧（还可自行选择视频品质）：

  

![](../Images/732d345f47469a6583e29470811c7921.png)

  

如果在一个网站听到了好听的高品质音乐，EagleGet强大的视频嗅探功能可以帮你轻松实现，点击EagelGet的“视频嗅探”功能：

  

![](../Images/239612b6e61c8ec7563fb10492765891.png)

  

然后打开IE（如果是Chrome或Firefox浏览器，需安装插件），这里我选择豆瓣音乐，随便打开一个高品质音乐，嗅探功能会自动将你正在收听到的音乐捕获到，点击“确定”收入囊中吧！

  

![](../Images/4a80c2d11278e19b8e757d07192fceb4.png)  

  

目前EagleGet已经支持很多国内外视频网站的视频嗅探了，下图是官方支持的部分列表：

  

![](../Images/e5348c1fa789a1c686abafc3b409d6ae.png)  

**2\. YouGet**

同样是一款视频下载神器，以前只支持Youtube，如今已支持国内优酷、爱奇艺等主流视频网站

  

**同样强烈建议官方下载！**

官方下载地址：https://you-get.org/

  

一条指令即可下载指定视频：

**指令：*****you-get  '视频url'***

![](../Images/ad0a55d82bd88d85f6aa12e8d9e447c4.png)  

  

最后推荐一个不错的IP查询网站，查询结果要比ip138之类的网站精确很多，个人感觉是目前体验度最好的IP查询网站了：

http://ipip.net

  

也可点击“阅读原文”直接访问。
