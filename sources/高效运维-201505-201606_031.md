**系统运维工程师**

**【岗位职责】**

**【任职要求】**

1、本科及上学历，计算机、网络工程、通信相关专业；

2、精通 Linux 平台的业务维护；

3、精通 Nginx+MySQL+PHP 的配置、使用 调优；

4、熟悉 zabbix 等监控软件的使用；

5、了解 Shell 编程、熟悉 Python 语言优先；

6、有较强的学习能力，热爱系统管理工作，有高度的责任心，喜欢钻研系统管理相关技术。

  

  

**运维开发工程师**

  

**【岗位职责】**

参与运维支撑平台、自动化平台的建设、开发相关运维工具，提高运维效率。

  

**【任职要求】**

1、本科及上学历，计算机、软件工程类专业优先；

2、熟练掌握python语言；有项目开发经验优先；

3、有高度的责任心、较强的沟通能力和良好的团队合作精神，善于思考问题，并提出自己的解决思路；

4、有较强的学习能力，热爱系统运维工作，有高度的责任心，能承受较大的工作压力。

  

  

**IT网络工程师**

  

**【岗位职责】**

负责企业级桌面支持，对网络进行规划、部署与维护，建立管理公司安全高效的上网环境。

  

**【任职要求】**

1、本科及上学历，计算机、网络工程、通信相关专业；

2、熟悉 TCP/IP 协议、计算机网络交换、常规路由原理，熟悉局域网常见故障，熟悉配置二、三层交换和路由；

3、熟练掌握 Linux 、 windows 的常用命令、工具和服务的配置，有脚本编写能力；

4、主动的服务意识、良好沟通能力，有一定的抗压能力； 

5、有 Cisco CCNA 、CCNP 或相关技术水平。
