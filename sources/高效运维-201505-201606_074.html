关于运维开发
 
我们需要 2 名运维开发新同事，主要负责新产品的运维开发，现有产品的运维（服务器集群的管理及日志分析, 监控系统的日常维护, Nginx 性能分析及数据库性能调优）
 
待遇：
  • 薪水区间 15K－25K，具体可面谈
  • 宽松舒适的办公环境
  • 不加班、不打卡、有各种零食、Macbook Pro + 显示器
  • 除了五险一金之外，还有补充医疗保险，饭补、房补、话补、车补等等
 我们希望的新同事：
  • 有一定的实际运维及开发经验，熟悉 Linux 系统，TCP/IP 协议等，以及常见监控及自动化运维工具
  • 熟悉常见应用配置及优化，如 Nginx/Redis/Mongodb/Mysql/ELK…
  • 熟练使用 Shell，熟悉 Python/Ruby/Nodejs/Go… 语言中的一种或多种
  • 熟悉 Docker 使用及其 API 使用，熟悉配置使用过 AWS、青云、阿里云等
  • 熟悉常见存储系统，如 Glusterfs 等，熟悉 Git 等版本控制工具等
  • 另外，如果有 Python 开发经验，那就最好不过了
