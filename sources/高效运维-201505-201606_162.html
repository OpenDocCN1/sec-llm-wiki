应用运维工程师（SRE）

工作职责：
1) 负责小米产品后端的日常运维，包括MILIAO消息、应用商店、MICLOUD等，做好日常排查、故障预案、优化、评估等工作，做到7*24快速响应;
2) 与DEVS共同设计产品后端架构， 实现分布式、集群化运维，确保集群可用性，稳定性，制定并实施相关运维技术方案，确保服务高效、稳定的运行负责设计实现与运维相关的自动化工具或系统，减少人工干预，实现运维系统管理业务系统
3) 通过技术手段进行成本控制及优化，通过工具化及流程提升服务管理效率

职位要求：
1） 熟悉LAMP架构，特点及架构，有网站运维、集群设计和实施经验者优先；
2）熟练BASH编程，熟练 PHP / PYTHON / PERL / RUBY中的任意一门语言在计算机技术领域拥有扎实的技术功底，尤其在数据结构、算法和代码、软件设计方面功力深厚；
3）熟悉分布式计算、网络系统设计，数据库设计和大规模存储系统，娴熟的C/C 编程技巧；
4）熟悉HTTP协议，开发基于HTTP协议的应用；5）有联网应用、联网游戏开发经验者优先；
6）具备Web service / Ajax / JavaScript / Apache / Tomcat / Struts / iBatis / Spring / PHP / JSP / Python等方面经验者优先考虑；
7）熟悉TCP/IP协议，熟悉socket和多线程开发，具备高访问量网络开发工作经验；

数据库管理员（DBA）

工作职责：
1）维护小米数据库服务的正常运行和应急响应
2）制定和改进应急预案、策略和流程,提高服务运行质量
3）优化数据库服务，提升可靠性、性能
4）开发数据库自动化运维平台。

职位要求：
1）熟悉MySQL的运行机制和体系架构
2）精通/熟悉SQL，精通数据库设计与优化
3）熟悉Linux/Unix操作系统至少熟悉一门所列编程语言golang/python/php/perl/bash
4）抗压能力强，有强烈的责任心，良好的沟通能力
5）有专职DBA工作经验优先

2）负责维护公司运维基础设施的正常运行为开发工程师，SRE工程师提供运维技术支持研究运维新技术和新方向，提高生产力
