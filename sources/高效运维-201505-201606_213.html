课程描述


Docker 和容器技术只有放到集群和大规模部署的场景下才能体现其最大的价值，面对当下的 Mesos、Kubernetes、Swarm、Rancher 等众多集群方案，如何做出正确的选择呢？


这个课程将带大家亲手架设并体验这些主流的容器集群框架，用最少的学习时间掌握第一手的容器集群知识。


学什么？


- 从零开始学习容器集群的概念

- Mesos 和 Marathon 集群的架设和使用

- Kubernetes 集群的架设和使用

- Machine、Compose 和 Swarm 工具的使用

- Rancher 和 RancherOS 集群架设和使用

- 对常见的集群解决方案进行总结


学完能干什么？


- 掌握 Docker 容器集群的关键概念和技术

- 掌握不同容器集群框架的异同之处

- 根据实际项目设计恰当的容器集群方案

- 能够快速构建一个高可用的容器集群


适用人群


- 对容器和 Docker 技术有一定基础

- 希望进一步了解容器在集群领域的应用

- 每周六晚上可贡献1小时参与课程，持续6周

课程大纲

[第一周]

  • 容器集群概述

  • Docker 的三驾马车 Machine、Compose 和 Swarm

  • Docker 的网络模块

  • 使用 Machine 构建 Docker 主机

  • 使用 Swarm 创建 Docker 集群

  • 使用 Compose 部署集群服务

  • 实践练习


[第二周]


  • Kubernetes 框架概述

  • 构建 Kubernetes 集群

  • 构建容器 Overlay 网络

  • Kubernetes 集群的基本操作

  • 在 Kubernetes 集群部署服务

  • 服务的在线更新升级

  • 实践练习


[第三周]


  • Mesos 和 DCOS 概述

  • 构建 Mesos 集群

  • 使用 Marathon 框架运行后台任务

  • 使用 Chronos 框架运行定时任务

  • 使用 Mesos-DNS 辅助服务间通信

  • 实践练习


[第四周]


  • 构建高可用的 Mesos 集群

  • 在 Marathon 上使用 Docker 容器

  • 在 Chronos 上使用 Docker 容器

  • 将 Kubernetes 集成到 Mesos

  • 实践练习


[第五周]


  • Rancher 和 RancherOS 概述

  • 构建 Rancher 集群

  • 使用 Rancher Compose 部署服务

  • 使用 Rancher UI 管理服务

  • 使用 RancherOS 操作系统

  • 实践练习


[第六周]


  • 其他容器集群相关的项目

  • 使用 CoreOS 操作系统

  • 使用 Hyper 解决方案

  • 使用 OSv 操作系统

  • 容器集群方案的选型和对比
