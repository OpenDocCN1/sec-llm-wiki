清流迅的拳头产品“会真 iHi”视频会议系统可实现互联网上超低延时的高清交互视频，同时可以跨卫星做低码流的监控直播和网真会议。“会真 iHi”应用场景包括中小企业分支机构之间、连锁店之间的日常沟通、企业培训、产业协作，跨国视频会议和移动会议，应急视频通信，卫星互联网视频会议，远程教育互动课堂，新一代实时交互娱乐，电视购物和品牌广告，养老院日间照料和老年大学，银行/保险的远程客服，远程医疗，法院庭审和政务公开，展会电商，远程招聘等等。“会真 iHi”不依赖于专线接入和专线骨干网传输，完全基于宽带互联网，其市场定位是“超一流的高清视频交互体验、极具竞争力的价格和使用成本”。

DevOps 运维工程师

【人数】1-2人

【职位描述】

  1. 负责公司视频产品如视频云和视频会议的运维，包括架构、部署和监控等。

  2. 从运维的角度参与公司产品的架构规划和审核。

  3. 负责制定和持续优化运维规范，运维自动化的研究和实现。

  4. 负责需求收集、技术沟通和应用部署等客户技术支持工作。  


【职位要求】

  1. 计算机相关专业大学专科及以上学历，计算机或者相关专业。

  2. 年以上的 Linux 系统和应用运维经验，深入理解 Linux 系统和计算机网络。

  3. 熟悉lvs/heartbeat/drbd/nginx/lighttpd/tomcat/mysql/salt/zabbix/svn/git 等部署和配置。

  4.  熟悉 shell，以及 python 和 php 中的任一一门语言，较好的 html/css/js/jquery基础。

  5. 善于沟通、分析和解决问题，好的文档管理。

  6. 对技术敏感，风险识别能力强。具备一定的架构能力，很强的故障排查能力。 

工作地点：北京东城区或昌平区

待遇： 面议
