【运维内推】

  

上海浦东发展银行

信用卡中心信息科技部

  

上海浦东发展银行（简称“浦发银行”）信用卡中心成立于2004年1月，是浦发银行设立的专业从事信用卡业务的直属经营机构，也是国内最早获得金融许可证的信用卡中心之一。

浦发银行信用卡中心秉承“就要多一分”的品牌理念，致力于信用卡专业化管理和运作，为国内的消费者带来更多、更先进的信用卡产品和功能。

  

  

**应用运维高级工程师**

**【职位描述】**

01、负责处理系统方面日常变更、控制突发情况，对疑难问题进行分析并解决。

02、负责与业务、开发部门进行良好的沟通并完成相应支持工作。

03、根据业务、开发部门的需要给出架构层面的合理化建议。

04、负责技术运维相关的文档、手册、流程编写整理、编写数据分析报告等。

**【职位要求】**

01、3 年以上工作经验，有大型网站维护经验优先。

02、熟练 shell、Python 至少一种脚本工具。

03、熟悉 Keepalive/LVS/Nginx/HAProxy 等负载均衡技术。

04、熟悉 fastdfs/ceph/Glusterfs 分布式存储维护经验优先。

05、运营过 hadoop、hive、hbase 等相关系统，有从事过海量数据分布式处理，各种分布式计算，或者分布式存储、分布式计算系统相关的工作经验优先考虑。

06、熟悉 saltstack、pupppet、ansible。

07、熟悉常用服务的安装及配置如 nginx、tomcat、redis、mongodb、zookeeper、rabbitmq 等。

08、对业内新技术及趋势有较强的敏感度，具有挑战精神和前瞻性。

09、熟悉 ISO20000/ITIL 的优先。

10、有 2 年以上 Java 开发经验优先。

**【中间件高级运维工程师】**

**【职位描述】**  

01、编制中间件系统实施安装、巡检、迁移、升级、调优等标准运维流程及作业指导书。

02、编制中间件系统日常维护脚本工具。

03、对中间件系统实施安装、巡检、监控、迁移、升级、调优、故障处理等日常维护。

04、与研发团队一起解决应用系统的性能问题，进行容量管理。

05、参与应用服务系统的整体规划、架构设计及优化等工作。

**【职位要求】**

01、大学本科及以上学历，计算机相关专业，有三年以上相关工作经验者不限。

02、熟悉 Linux 操作系统。

03、熟悉 Oracle、Sqlserver、MySQL 等数据库，熟悉 SQL 语言，具备一定的数据库使用维护经验。

04、精通 WebLogic、tomcat、MQ 等中间件的安装部署、维护管理调优工作。

05、熟练掌握中间件、Java 虚拟机调优及故障分析; 具备丰富的系统应急和故障处理能力者优先。

06、至少熟悉掌握 Python、Shell、Perl 等一种以上编程语言。

07、工作责任心强，良好的学习能力、良好的沟通能力、团队合作精神; 工作踏实努力，能承受工作压力。

08、有 java 开发工作经验优先。

09、熟悉 RPC 框架、消息队列、分布式缓存、分布式存储经验者优先。

10、熟悉大型网站网络架构规划设计，3年以上大型互联网企业运维工作经验优先。

**【职位要求】**

01、本科及以上学历，3 年及以上相关领域工作经验。

02、勤于沟通，喜欢协作，懂得如何共识目标，懂得如何开会，必须有严谨的工作风格。

03、精通 Python/Java，精通常见的 Python/Java 模块/框架的使用，有其他语言如 Golang 开发技能者优先。

04、良好的编码习惯，遵守 PEP8，或 Google Python Style Guide  规范。

05、熟练使用 Django/Tornado/Web.py 或其他 web 框架，精通 MVC 模式，研究过源码者优先。

06、熟练使用 MySQL/MongoDB/HDFS 等数据库或者文件系统，有调优经验者优先。

07、熟练使用 html/css/js 等前端技术，有web作品者优先。

08、了解自动化运维知识，了解 puppet，saltstack 者优先。

09、熟悉 Zabbix，Open-Falcon 原理和使用方法者优先

10、有 OpenStack/Kubernetes/Docker 平台开发经验者优先。

11、有数据产品设计，指标定义，数据分析，数据运营等相关经验者优先。

12、有独立需求分析和方案设计能力者优先。

13、有软件项目管理经验者优先。
