Linux基金会

   

Linux是大多数开源软件的基础，要做开源首先就要了解Linux基金会。该组织的核心目标是推动Linux系统的发展。近年来，随着开源的兴起，Linux基金会适应时代发展的需要，在Linux的基础上扩大涉足领域，并监管大型协作项目。业界如雷贯耳的Xen、KVM、CNCF、Hyperledger等知名项目，都来自于Linux基金会。

 

Linux基金会采用的是会员制，分为：银级、金级、白金级三个等级，白金级是最高等级。Linux基金会的会员数量不胜枚举，不过白金会员却是一份短名单，包括思科、富士通、惠普企业、华为、IBM、英特尔、NEC、甲骨文、高通、三星和微软。不要问为什么名单这么短，白金会员的年费高达50万美元，阿里巴巴刚刚成为Linux基金会黄金会员。这不是随便什么企业可以玩得起的！

![](../Images/d9016ab6b137c02f12ab725fd32d0b1b.png)

  

值得一提的是，作为白金会员的华为，在linux成功建立了一个项目——OpenSDS，这是首个由我国主导的linux项目。OpenSDS旨在为不同的云、容器、虚拟化等环境创建一个通用开放的SDS解决方案，提供灵活的按需供给的存储数据服务。

OpenStack基金会

 

在开源的世界，OpenStack是全球最火的面孔之一，专注于云计算平台的操作系统开源。

 

OpenStack由NASA（美国国家航空航天局）和Rackspace合作研发并发起,旨在为公共及私有云的建设与管理提供软件的开源项目。OpenStack的优点：社区、灵活性、创新、不被厂商锁定、生态系统、进化、API驱动的基础设施。

 

今天，OpenStack当之无愧地成为了全球成长最快的开源组织之一。 你造吗？OpenStack官方称，中国已经成为OpenStack市场增长最快的区域。

 

在基金会黄金会员的24个席位中有10家都是中国公司，他们包括华为、中国移动、中国电信、EasySstack、九州云、中兴、浪潮、有云（UnitedStack）、台湾云端运算产业协会(CCAT)、inwinSTACK。中国正逐步成为OpenStack的主角。

Apache基金会

 

Apache基金会是开发者的乐园！

 

Apache软件基金会，简称为ASF，它支持的Apache项目与子项目中，所发行的软件产品都需要遵循Apache许可证（Apache License）。

 

作为一个非营利性组织，Apache基金会采用的是会员制，这样的好处就是能够确保 Apache 项目在没有任何个人志愿者参与的情况下，仍然可以独立存在。Apache基金会倡导的是合作和贡献，在 Apache 的生态世界中，信奉“贡献者→提交者→成员→导师” 这样一条精英路径。

 

想成为贡献者，很简单，积极为 Apache 社区贡献代码，补丁或者文档。要想成为提交者，那需要会员的指定，而成为了提交者，就会拥有一些“特权”。提交者中的积极分子和优秀生就可以“毕业”成为成员了。

 

Apache基金会的运营模式得到了业界的高度认可，使其发展成为权威最具影响力的基金会之一。Apache基金会会为孵化项目提供组织、法律和财务方面的支持，目前其已经监管了数百个开源项目，其中包括Apache HTTP Server、Apache Hadoop大数据分析平台、Apache Tomcat等。

 

Apache基金会也正在帮助更多来自于中国的项目落地，Kylin就是我国首个Apache顶级项目。

 

在这里有必要八卦一下，Apache Kylin在2014年10月1日由eBay在github上开源，2014年11月25日正式加入Aapche孵化器项目，经过不到一年的时间，Apache Kylin正式成为Apache顶级项目，这是全部由华人团队贡献至Apache的首个项目！

三大基金会和云计算开源的关系

 

 呃~~~谈关系，这有点尴尬耶。

  

 不是因为关系太复杂，而是因为都告诉了你们，我就要没饭吃了。

 

![](../Images/ba88a45960e3e2c54476b3d288bc2a71.png)

  

整体而言，云计算开源体系可以分为：硬件、容器、资源调度管理和应用，在容器中又有虚拟化和虚拟化管理。如果头脑中有了这样一个结构图，要理解三大基金会和云计算开源的关系就会简单很多。

 

Linux基金会关注的的领域比较多，涉及硬件、容器以及资源调度管理。在虚拟化层面， Linux有KVM和XEN项目这样大家熟知项目。在容器上，Docker和Linux基金会联合发起了OCI项目；在跨容器和资源调度管理上，Kubernetes和Linux基金会发起了CNCF项目。

 

相比之下，OpenStack的关注点就更为聚焦，专注于虚拟化管理。
