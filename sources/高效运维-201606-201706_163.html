云计算高级工程师

（容器方向）

职位数量：2

工作年限要求：2年以上

专业要求：信息技术类及相关专业本科及以上学历


【岗位优先技能】

1、精通 mesos、marathon 或项目经验。

2、熟悉 go 或 C++ 语言编程。

3、熟悉 Docker Native 相关技术或项目经验。

4、熟悉 kubernetes 相关技术或项目经验。


【工作内容描述】

参与 Dcos 容器平台建设，负责 Dcos 平台开发维护工作：

1、负责 Dcos 容器平台需求实施及推广。

2、负责 Dcos 容器平台日常生产维护。

3、负责 Dcos 容器平台持续优化。


【岗位必备技能】

1、精通 Docker 容器平台实现原理并有实际实施经验。

2、熟练掌握 linux 操作系统。

3、精通 linux shell、python 编程

高级业务运维工程师

(财务运维和分析方向）

职位数量：2

工作年限要求：3年以上

专业要求：信息技术类及相关专业本科及以上学历


【岗位优先技能】

1、有财务类系统项目经验。

2、有实施或维护 Oracle EBS 等专业财务软件项目经验。

3、具有信息技术相关的水平和资格证书者，如系统分析师、ITIL相关认证等。


【工作内容描述】

1、根据服务 KPI 指标要求，确保对财务类应用系统终端用户的服务响应和解决时效，督导制定问题处理机制，稳步提高用户满意度；

2、主动了解用户需求，掌握用户动态，编写服务绩效报告，跟进用户投诉和建议。

3、制定服务工作规程和内部绩效考核制度，保障服务支持工作有序进行，不断提升团队工作积极性； 

4、分析研究财务类业务和系统运行的数据，对应用系统的需求、设计、功能提出持续优化方案；

5、根据知识管理要求，督导本领域的知识管理工作，通过不断积累和总结经验，进行知识转移，提升团队的服务能力；


【岗位必备技能】

1、熟悉软件工程；

2、熟悉常见的应用系统架构，掌握相关产品及辅助工具的技术知识；

3、熟悉 Oracle 数据库，熟练掌握SQL语句；

4、熟悉中间件产品，如：Jboss、tomcat、weblogic、websphere 等,在至少其中一种平台上有运维或开发的经验；

5、熟悉事件管理、问题管理、知识管理流程；

6、工作责任感强，具备良好的服务意识和沟通能力。


【行业背景要求】

具备1年以上金融行业应用系统维护支持和管理的工作经验。
