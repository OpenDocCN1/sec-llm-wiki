运维领域人才

OPPO


关于我们：

在追求极致的理念下，我们不仅在让ColorOS越来越稳定、流畅和更加省电，也在努力让国内上亿的用户群和海外正日益膨胀的多国用户群体有一个更可靠、更流畅、也更智能的网络服务。OPPO数据中心在这其中承担了平台运维能力和大数据平台两个基础职能。

关于我们的团队，你可能想要了解： 

- 成员从70后到90后都有，主要来自知名互联网公司比如BAT、UC、迅雷等；

- 我们的服务器、数据量的增速丝毫不慢于业务的增长量，甚至还要走在前面；

- 比起已然整套体系成熟的大公司，我们在工具化、系统化上还有很多能充分发挥能力的地方，服务好亿级用户我们还需要持续进步；

- 公司乐意在核心关键问题上付出苦功夫大力气，不用担心总需要做些杂七杂八没价值的东西；

- 上下班不打卡，我们更关心你的产出价值和个人成长。 


运维工程师

薪资：15K~30K

岗位职责：

1. 负责承接产品运维需求，参与产品的可运维架构设计；

2. 负责产品服务器、IDC资源规划，环境部署，为开发团队提供支持，保证产品的开发进度；

3. 对业务和服务器做好监控，维护业务的稳定性；

4. 跟进推动运维技术项目，保证项目的成功完成；

岗位要求：

1. 计算机或相关专业本科以上学历；

2. 两年以上运维工作经验；

3. 熟悉Linux系统， 包括操作系统原理、常用系统命令，系统服务.。如Apache、 Nginx、MySQL、Bind、 Squid、 Memcached和Redis等；

4. 具备故障分析和处理能力，能熟练使用相关命令和工具， 如strace、netstat、perf、trace、dstat、iostat、top、sar和dig等；

5. 具备脚本编写能力，能通过脚本快速高效的完成工作 ，如Shell/Perl/Python， 以及awk、 sed等；

6. 有一定的网络基础， 理解TCP/IP、HTTP、FTP、 NTP、 SNMP、VRRP等常用协议。 熟悉相关工具的使用和配置，如tcpdump、 iptables等；

7. 熟悉运维平台类工具， 如Nagios、Cacti 、Ganglia 或Puppet。 熟悉PXE/Cobbler/Kickstat自动部署工具；


运维研发工程师

薪资：15K~30K

岗位职责：

1. 负责运维平台系统开发；

2. 设计开发高可靠性系统架构和运维工具，提高运维工作效率；

岗位要求：

1. 3年以上Python开发工作经验，熟悉Linux系统及Django开发框架； 

2. 熟悉JavaScript、HTML前端开发，有jQuery、Bootstrap、AngularJS使用经验者优先； 

3. 熟悉MySQL数据库，了解数据库性能优化基本概念； 

4. 有数据处理、监控系统、云服务产品相关经验者优先；


渗透测试工程师(安全)

薪资：15K~30K

岗位职责：

1. 负责对公司信息系统开展安全测试；

2. 评估和测试新的信息安全技术，进行安全研究并分析最新的安全事件问题。

岗位要求：

1. 具有良好的沟通能力和团队合作精神，良好的职业道德；

2. 对Web安全整体有较深刻理解，具备Web渗透技能，熟悉渗透测试流程，熟练掌握各类安全测试工具；

3. 熟悉安卓APP安全测试方法，包括接口测试和android组件测试等；

4. 了解源代码安全审计；

5. 掌握Python开发语言，能编写相应的安全工具；

6. 熟悉各种攻防技术以及安全漏洞原理，有过独立分析漏洞的经验；


网络架构师

薪资：20K~40K

岗位职责：

1. 对于公司的互联网业务IDC网络提供整体规划，制定网络规范和运营体系，包括设计、使用、安全、管理等；

2. 制定和执行网络设计、搭建、配置、监控、优化、调整的实施方案；

3. 根据网络运行规范，负责网络的日常运行维护工作；

4. 一般性网络调整和故障处理，并能够对深度网络技术故障进行分析、快速定位、并提出解决问题的建议或办法；

5. 网络运行规范和技术手册的编写，机房内硬件设备的管理工作；

岗位要求：

1. 本科或以上学历，计算机或相关专业5年或以上工作经验；

2. 具有网络架构的设计、规划能力，精通 TCP/IP 的通讯原理及常用的网络标准、协议、技术规范；

3. 熟练掌握Cisco、H3C、华为网络设备的安装、调试、维护；

4. 熟悉网络交换技术，如生成树、多层交换、组播、 OSPF 等；

5. 熟悉Linux操作系统架构和工作原理，精通 LINUX/UNIX、Windows 操作系统的安装、配置和升级； 熟悉基于 Cacti 的网络监控;

6. 具备 CCNP 证书或同等水平者优先考虑；有团队管理经验 / Python 开发经验就更好不过了。
