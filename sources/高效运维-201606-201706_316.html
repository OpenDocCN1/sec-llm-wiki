Facebook 发布了新的 Node 模块管理器 Yarn
在 Facebook 中，工程师们多年来一直在使用 npm 客户端并取得了成功，但随着代码仓库与团队人数的增长，他们在一致性、安全性以及性能方面遇到了挑战。在尝试解决每个方面的问题后，最终决定着手打造一套新的客户端解决方案，以帮助工程师们更可靠地管理依赖。工程师们把这个客户端工具称为Yarn —— 更加快速、可靠、安全的 npm 客户端的替代品。他们与 Exponent、 Google 和 Tilde 进行了合作，并开源 Yarn 项目。工程师在使用 Yarn 时，依然需要访问 npm 仓库，但 Yarn 能够更快速地安装软件包和管理依赖关系，并且可以在跨机器或者无网络的安全环境中保持代码的一致性。Yarn 提高了开发效率，并解决了共享代码时面临的一些问题，使得工程师们可以专注在构建新产品以及新特性上。

B站简历开源工作组：ijkplayer等多个项目开源
弹幕视频网 Bilibili（B 站）近日在 GitHub网站上建立了开源工作组（BOSTF），用以分享与维护自己的开源项目，其中包括 DanmakuFlameMaster（燃烧吧！烈焰弹幕使）与ijkplayer。前者是免费提供 Android 平台下应用弹幕集成的解决方案，而后者则提供 Android 和 iOS 双平台视频播放器的解决方案。B站的两个开源项目已经被多个 App 使用。其中美拍和斗鱼使用了 ijkplayer 项目，DanmakuFlameMaster项目则被包括优酷土豆、开迅视频、MissEvan、echo 回声、斗鱼 TV、天天动听、被窝声次元、ACFUN 等 App 使用。

MySQL 8.0 将结束使用 MyISAM 引擎
由于MySQL 8.0 引入了新的数据字典，系统表便有了新的依赖，且MySQL 8.0中将极大程度上限制MyISAM使用范围。MyISAM的落寞也因为他存在的一些弱点，包括表级锁、不支持CRASH恢复、不支持事务等。而且MyISAM的原有的优点逐渐被InnoDB所实现。

精确wifi诞生，精度增20倍
日前，MIT的计算机科学与人工智能实验室发明了一个名为DubbedChronos的新系统，能为咖啡厅和商店提供店内免密码Wi-Fi，与此同时可避免店外的用户蹭网。不仅如此，该精确Wi-Fi技术还可以安装在无人机上，在其飞行的过程中，即可检测到各楼层是否有人。据研究报告指出，这个系统比传统的跟踪系统要精确20倍，而且对房间内用户定位的准确率达到94%。

Apache Spark 2.0.1 稳定版正式发布。
Apache Spark 2.0.1 作为一个维护版本，一共处理了300个Issues，推荐所以使用Spark 2.0.0 的用户升级到此版本。Apache Spark 2.0 为用户没带来了许多新功能，例如：DataFrame和Dataset统一；一个新的切入点SparkSession；性能更高的accumulate API；支持视图规范化。Spark 2.0也大幅提升SQL性能，并支持SQL2003。 Spark SQL现在可运行所有的99 TPC-DS查询。支持ANSI-SQL和Hive SQL的内置SQL解析器。

Google搜索结果正式AMP化
Google搜索副总裁David Besbris宣布Google搜索正式AMP化，AMP全称Accelerated Mobile Pages，Google一直追求让移动网络上的体验更加快速。2016年2月，Google搜索在新闻版块中应用AMP，以一种更迅速、更精确的方式提供新闻；到8月时，Google将整个移动搜索结果进行AMP；如今，Google已向全世界用户提供了AMP技术来体验这种速度感。AMP化的网页加载时间将小于一秒钟，除此之外，AMP化的网页与未AMP化的网页相比，流量节省了将近90%。

Visual Studio 现已支持Cmake
Visual C++ 团队在他们的官方博客上宣布 Visual Studio 现已支持 CMake。CMake 是一个跨平台的开源工具，通过抽象本地构建环境和编译器以管理建立跨多平台程序。CMake提供了一种语言，开发者可以用它来定义项目的结构以及各种必要的配置步骤，它是跨平台的。CMake工具能处理这些代码，根据程序的目标平台，生成对应的makefile或项目文件。Visual C++在博客说他们已经可以提供一个坚实的CMake与VS整合了，并附有诸多特性，例如，为每个目标枚举CMake的对象和文件；为CMake对象检测输出；检测CMakeLists.txt中的变化和依赖，并且自动重新配置等。

Chrome 54终结YouTube的Flash内嵌技术
Google启动Chrome 54项目，最新发布版本将进一步边缘化FLash，转而使用HTML5在浏览器内嵌YouTube视频，同时包含大量问题修复和功能改进。谷歌移除Flash的工作已经进行了一段时间，发布的多个更新强化了用户和开发者对HTML5的使用体验。YouTube从2015年1月份开始使用HTML5作为默认的视频内嵌技术，谷歌在去年改变了Chromium处理网站Flash的方式。Chrome 54稳定版重写了YouTube内嵌Flash的方式，当检测到有内嵌的Flash YouTube视频，浏览器会自动使用HTML5替代它。谷歌表示这个变化是“为了减少Flash在Chrome中的使用”。
360将停止个人云盘服务
360云盘10月20日发布公告称，因部分不法分子利用360云盘存储传播非法文件、侵权盗版牟利、传播淫秽色情信息等违法犯罪行为屡有发生，360云盘决定停止个人云盘服务，之后转型企业云服务。从即日起到明年2月1日，360云盘将进行会员退款。仍是会员身份的用户，无论剩余多少天，均全额退款；2016年11月1日起停止云盘上传服务，包括上传、转存等数据写入功能均关闭；2017年2月1日起不再保留云盘数据，关闭所有的云盘账号并清空数据。近年来，360云盘始终严格遵守互联网法律法规要求，持续投入大量人力物力以及技术资源，对非法行为进行严厉打击。但是，由于云盘存储的私密性，管理的复杂性，依然使企业面临巨大的安全风险。
