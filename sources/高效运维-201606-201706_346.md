![](../Images/4d043997da10420a5d97f8f6ceefd3b6.png)我们在GOPS·上海站等你**大数据专场精彩演讲预告**大数据专场日程（9月23日 下午）![](../Images/e8e1a9a6ab3f623346be5df4395812bf.png)**主题一**爱奇艺Hadoop平台的运维管理实践  
刘骋昺![](../Images/c34c14f523f560812817b46ea6adadbe.png)**刘骋昺**毕业于上海交通大学计算机系，2013年加入爱奇艺云平台，负责爱奇艺Hadoop的运维和研发。目前主要负责Hadoop工作平台与工作流管理系统Gear的系统设计和开发工作。**演讲简要：**  
Hadoop已经成为大数据的基础架构中必不可少的一环。此次演讲将给大家分享爱奇艺Hadoop平台的运维管理实践，包括平台架构的演变，运维体系的建立，踩过的“坑”，基于开源Hadoop系统的优化，以及作业管理系统Gear的介绍。  
**主题二**阿里大数据计算平台运维实践范伦挺![](../Images/d0c37012bb9c3bcc1600bd55a931a55a.png)**范伦挺**花名萧一。曾就职于sogou负责搜狗搜索系统后端运维，2010年加入阿里巴巴，现任阿里巴巴集团大数据计算平台运维负责人。团队主要负责集团各自研大数据计算平台（如ODPS、GALAXY、ADS等）的运维、基础架构及资源管控等，为阿里公共云上大数据计算客户和集团内各BU用户提供稳定、廉价的大数据计算能力。**演讲简要：**随着云计算大数据的迅猛发展，集群规模和处理的数据量呈爆发式增长，对软件平台、基础设施和人员成本都带来了极大的挑战。本次分享主要介绍大规模集群运维中面临的问题及在解决这些问题方面所做的一些尝试。  
  
**主题三**eBay Hadoop海量集群自动化运维实践李健![](../Images/091a4065180342dcca04877dc20dbf2c.png)**李健**eBay Cloud Services高级软件工程师 兼 eBay Hadoop Service China Team Leader。2010 年加入eBay, 参与了Hadoop 集群硬件与系统监控，报警，集群扩容与管理，自动化运维等多个重要项目。现在专注于Hadoop 集群的自动化运维，负责Hadoop Robot 这一集群自动化运维系统。  
**演讲简要：**  
传统的单点运维工作模式很难适应Hadoop 这一分布式场景，在集群上应用不断出错的压力下客户是不可能给运维人员足够时间去一个个故障点做排查， 运维人员一直在疲于奔命的救火试图尽快定位并快速解决问题，有时候定位的“坏节点“ 有可能只是受害者，下线该节点只能解决表象问题并不能解决本质问题。如何第一时间发现本质问题并将该问题节点下线? 坏节点下线后还需要将其修复并最终加回上线，如何自动化这一流程以确保运维人员关注更重要的事情?  
如何确保加回来的节点在硬件，系统和软件层面是可信的绝对健康？如何可视化的展现集群各机架节点健康状态？如何确保运维流程标准化？  
对这些痛点，我们开发了Hadoop Robot　这一eBay hadoop 集群自动化运维系统，它有效地确保廉价的Hadoop 集群服务器硬件不会影响集群和应用的性能，并提供了一整套由异常发现，节点下线，节点修复，下点上线的自动化运维解决方案，级大地节约了人力并确保集群的高可用性。  
Hadoop Robot 同时也是hadoop 集群action API center ，直接处理多种Hadoop 集群硬件，系统与应用问题，并且提供统一的Hadoop 管理员操作界面。本演讲主题包含以下部分:   
1\. eBay hadoop平台(万台服务器规模)概况。2\. Hadoop 平台运维实践经验(包含硬件, OS, hadoop与应用四个层面进行详细分享)。3\. Hadoop Robot系统介绍与其带来的价值。  
**主题四**大数据时代运维的机遇与挑战尹会生![](../Images/009c21c2cd8aece31864f191cade5252.png)**尹会生**现任珠海金山西山居高级系统工程师。曾在北京尚观科技担任高级讲师，后就职新浪研发中心担任技术经理。拥有五年的企业集群解决方案培训经验和内核调优经验。近四年专注于Hadoop集群、Spark集群在推荐系统和BI相关领域的解决方案。在新浪广告、微博广告、西山居大数据平台架构中担任关键角色，并提供高性能和高可用性集群咨询服务。同时也是国内知名RHCA讲师，有丰富的培训和授课经验。   
**演讲简介：**

大数据时代来了，机器学习算法，海量日志分析，各种大数据工具给运维带来了哪些影响？基于数据化的运维思想又能为运维带来哪些助力？
