# 全国网络最脆弱的不是双十一，不是春运而是724运维日

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651661080&idx=1&sn=8345326eee4e562bbdee6dfafdb7cf65&chksm=8bcbe0b1bcbc69a7c0102eafc9d86c7d1e1a681ce08ffb34d8c620f4faa35952a798f178cc6e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651661080&idx=1&sn=8345326eee4e562bbdee6dfafdb7cf65&chksm=8bcbe0b1bcbc69a7c0102eafc9d86c7d1e1a681ce08ffb34d8c620f4faa35952a798f178cc6e&scene=27#wechat_redirect)

7月24日，由开放运维联盟和高效运维社区共同主办的724运维日暨运维武林盟主争霸赛在北上广深蓉五大城市顺利举行。  

 

本次运维日活动共有四千多人报名，由于场地容量有限，只有部分幸运儿通过层层筛选，获得了亲临现场的机会。

  

没有来到现场的运维，通过观看线上直播的方式共同见证了首届运维武林盟主的诞生。最终盟主称号归属于深圳站岛主刘栖桐。

  

**最红火之北京御林军**

 

在董伟大统领的带领下，724当天下午，资深运维：张家良、孙杰和盖国强分别带来了以数据存储为主题的精彩演讲。

**最奇葩之上海桃花岛**

 上海站匡萃彪岛主举办了一场运维奇葩说：正反双方关于【容器是一场革命】VS【容器是一种just so so 的技术】进行了一场激烈的辩论。

 

![](../Images/75ba3bebd2217c2ac185f8b1ab816781.png)  

  

太平洋保险高级运维工程师陆翔、京东商城高级研发工程师李旦、富麦信息科技有限公司CTO余军给大家带来了关于“容器”的分享演讲。

  

![](../Images/8f8e5789161701c46b11373a8a39cb03.png)  

来自高效运维的刘欣向大家介绍了，两个月之后的9月23日、24日，在上海将会举办GOPS2016全球运维大会

  

**最豪气之深圳侠客岛**

刘栖桐岛主带领的深圳侠客岛开场即发放了大红包。老将新秀齐亮相，GOPS2016深圳大会金牌讲师同台竞演。

  

  

![](../Images/e4105a23db64163f91bc04d8294937fe.png)

  

刘湘权、杨胤、党受辉纷纷围绕“运维如何升职加薪”这一主题结合各自多年的运维经验带来了精彩的分享。  

  

**![](../Images/0e200266a5d9ebe3cb9a41d675f2119e.png)**

深圳站运维日最大的亮点可以说是运维技能擂台挑战赛，三千元现金、iPhone6s凭本事领走。各位运维豪杰纷纷摩拳擦掌，当技能成为可以get现金与荣耀的筹码，没有谁会抱怨平日里的积累都是无用功！
