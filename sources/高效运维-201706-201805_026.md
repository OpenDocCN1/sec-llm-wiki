金山云，金山集团旗下云计算品牌，是全球领先的云计算服务提供商，中国TOP3的云计算公司。创立于2012年，在北京、上海、成都、广州、香港和北美等全球各地设立数据中心及运营机构。

职位：高级运维开发工程师（监控系统方向）

  

职位描述：

1. 主导监控系统的设计、开发和运维工作；

2. 研发高性能、高可靠性 API 接口，对外输出服务；

3. 对现有系统提出建议，并组织实施，新技术调研和推广；

4. 研发自动化运维工具，提高运维效率和准确性；

5. 编写工作文档、技术文档；

  

职位要求：

1. 计算机相关专业毕业，本科及以上学历，至少2年工作经验；

2. 了解linux操作系统的原理，熟悉系统配置、服务管理，有shell脚本开发经验；

3. 熟悉常见开源监控系统如zabbix、open-falcon、nagios、prometheus等；

4. 熟练掌握go或python编程语言，熟悉相关技术栈，如 gRPC、protobuf、Flask、sqlalchemy、Jinja2等，熟悉网络开发；

5. 熟悉大数据技术栈，如ELK、kafka、spark等，熟悉mysql、redis、elasticsearch等数据库编程；

6. 能够独立完成工作，具有较强的分析问题、解决问题能力，学习能力强，能够熟练阅读涉及产品和技术的英文文档；

7. 良好的代码风格，对工作有洁癖，及时按要求撰写、更新工作流程及技术文档；

8. 热爱开源，喜欢折腾，有强烈的求知欲，对新技术有强烈的好奇心，乐于实践和分享；

9. 自我驱动，良好的沟通和团队协作能力，责任心强，有一定的抗压能力；

  

加分项：

1. 有主流大型监控系统开发实施经验，有10万+台设备规模监控经验；

2. 有DevOps/AIOps实践实施经验；
