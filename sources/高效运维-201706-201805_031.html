岗位一： Agent技术专家

岗位职责

  1. 负责大型公有云云平台服务器基础设施的自动化运维平台建设，自主研发Agent产品，为Devops运维系统提供统一底层支持;

  2. 负责Agent产品的命令通道、插件平台能力的设计和研发，实现百万级的管理服务器规模, 以及灵活可扩展的平台能力；

  3. 负责Agent产品高可用、高并发、安全的架构设计、以及跨平台兼容性的产品研发;

岗位要求

  1. 本科及以上学历，具有6年以上大型互联网公司或大型IT企业基础架构或运维系统架构设计经验;

  2. 精通Linux/Unix平台上的C/C++编程、安全控制、网络编程、多线程编程，熟悉操作系统架构和分布式架构;

  3. 对技术有热情，学习能力强，具有良好的团队协作能力，乐于分享;

  4. 有自动化运维平台研发、产品化、平台化的经验者优先;



岗位二：运维平台软件架构技术专家

岗位职责

  1. 作为华为公有云SRE软件技术专家，负责自动化运维平台的系统分析和架构设计，指导研发团队实现设计，规划未来平台技术架构方向;

  2. 负责全局性和前瞻性的架构设计，以及关键技术细节的实现，解决业务发展遇到的架构问题，持续提升系统平台稳定性;

  3. 负责持续关注业务技术发展和最佳实践，并结合华为云运维产品业务特点推进新技术及实现方案的落地;

岗位要求

  1. 本科及以上学历，6年以上大型业务应用系统的架构设计和落地的实际能力，熟悉分布式、缓存、消息等机制，能对分布式常用技术进行合理应用，解决实际架构问题;

  2. 海量数据处理和架构能力及经验，熟悉SOA并具有系统的架构设计经验;

  3. 精通Java/Python/Go/C/C++其中至少1种编程语言;

  4. 精通操作系统，数据库，IO、多线程编程原理、集合等基础框架，对JVM原理有深入的了解;

  5. 精通分布式事务处理框架原理和实现，精通多线程及高性能的应用的设计，编码及性能调优经验;


岗位三： 基础设施自动化技术专家

岗位职责

  1. 负责华为云基础设施自动化平台的架构设计，包括基础服务器、基础网络、云服务数据面等领域的高效管理和自动化;

  2. 对基础设施自动化平台的技术竞争力负责，负责识别相关的关键技术，输出演进策略和路标，并推动和规划落实，构筑业界领先的基础设施高效运维能力;

  3. 负责相关基础设施自动化平台的设计和支撑工作，构建有竞争力的产品;

岗位要求

  1. 6年以上大型互联网或公有云的基础设施自动化平台架构设计经验，深刻理解大型互联网或公有云基础设施的特点，主导过大型互联网或大规模公有云基础设施自动化平台的架构设计及落地;

  2. 对公有云基础设施的管理有独到的理念和软件服务基础构架设计思路;

  3. 具备很强的架构设计和沟通能力，能够和产品研发团队高效沟通，构建有竞争力的产品;

  4. 善于主动思考和自我驱动、具备较强执行力及抗压能力，有很强的独立工作能力和解决问题的能力;

  5. 良好的语言、文字表达能力、优秀的团队协作能力;


岗位四：容器运维技术专家

岗位职责

  1. 负责公有云大规模容器服务相关产品的自动化运维体系建设，保证Docker/Kubernetes基础设施的稳定可靠运行;

  2. 负责容器服务相关产品的DevOps运维产品研发，包括自动化部署、监控系统、日志分析、自动扩容、智能故障处理等产品研发;

岗位要求

  1. 本科及以上学历，具有6年以上大型互联网公司容器运维产品架构设计经验;

  2. 至少有1种面向容器的集群资源调度平台使用经验（Kubernetes），了解源码和实现者优先;

  3. 熟悉1个或多个Docker/Kubernetes生态开源项目代码，并有改进优化经验，有贡献容器相关开源项目者优先；

  4. 对Linux系统有深入的理解，有Docker在linux上的丰富的运维经验；

  5. 至少精通Go/Java/Python/C/C++ 其中一种编程语言;


岗位五：智能运维技术专家

岗位职责

  1. 负责华为公有云自动化运维平台产品的架构方案设计与研发，构建以运维大数据为基础的智能化运维能力;

  2. 负责建立基于机器学习的智能运维产品，不限于故障自动检测/自动预测、自动化部署、防人因差错的智能化配置、事故自动恢复、数据建模&分析等核心智能运维能力，带领团队完成需求分析、设计（含原型验证），技术牵引等能力构筑工作;

岗位要求

  1. 本科及以上学历，6年以上知名互联网公司大型云化系统的架构设计和落地的实际能力;

  2. 在研发领域有丰富的工作经验，精通云计算、人工智能、机器学习、认知计算等技术和方案;

  3. 具有将机器学习算法应用在海量规模云运维经验者优先;

  4. 具有公有云自动化运维平台实际项目设计开发经验者优先;


岗位六：基础平台运维专家（DBA)

岗位职责

  1. 负责华为云数据库自动化运维工具的设计及落地。

  2. 负责华为云数据库疑难问题攻关，性能优化；

  3. 负责数据库高可用、集群、容灾及备份恢复方案设计及落地；

  4. 负责华为云各服务数据库相关方案设计，优化；

  5. 负责华为云数据库技术标准、规范的输出，数据库相关运维流程建设；

岗位要求

  1. 8年以上大型互联网企业的数据库架构设计和交付经验。精通数据库架构，参与过数据库架构设计和大型数据中心数据库设计和规划；

  2. 精通数据库高可用、集群、容灾及备份恢复方案；

  3. 具备自动化运维理念，并参与过自动化运维能力建设；

  4. 能解决运维工作中重大故障，性能瓶颈等；

  5. 深刻理解主流数据库架构，主导过数据库架构及部署方案的设计。有海量接入运维工作经验者优先。


岗位七：基础平台运维专家(LB&DNS)

岗位职责

  1. 负责华为云基础平台LB&DNS等组件及开源软件的运维及自动化运维设计工作，对华为云LB&DNS等组件及开源软件的稳定性、性能负责；

  2. 负责基础服务的运维团队建设和运作，带领团队，完成既定目标；

  3. 负责资源隔离研究和实践(基于虚拟化/docker)；

  4. 负责云主机的运维，包括主机稳定性，性能调优等。

岗位要求

  1. 8年以上大型互联网企业的LB&DNS设计和运维经验。

  2. 至少3年以上架构经验，精通LB&DNS等组件及开源软件，对常用开源软件原理、特点有深入实践和研究，到代码级为佳；

  3. 至少3年以上数据中心交付实施或者运维经验，2年以上项目管理经验；

  4. 具备云计算的各种产品开发或者运维经验及迁云上云的工作经验；

  5. 精通linux操作系统，对系统性能相关问题有较深刻理解；

  6. 具备很强的ownership，具备设计能力和故障排查能力，有很好的技术敏感度和风险识别能力。
