有位少年，

立志，

要去追风！

他，是硅谷云计算泰斗，

他，是全球华人工程师的楷模，

他，是中国科技大学少年班高材生，是耶鲁大学计算机博士，Rancher Labs 联合创始人，

他，被誉为 CloudStack 之父，更是 Citrix 首位华人CTO 。


这位少年叫：梁胜！

追风少年，1988年毕业于中科大少年班，和张亚勤、马东敏等少年班大咖一样，梁胜的追风之旅，从这里起航！

右一为梁胜，左一为梁胜妹妹，也是87级少年班高材生

1990年，梁胜进入耶鲁大学攻读计算机科学，1996年取得耶鲁大学计算机博士学位

Java 编程语言（JVM）核心工程师

毕业后梁胜博士加入当时刚刚发布Java编程语言的Sun公司，成为一名工程师。

梁胜博士是Java语言J2SE平台核心组件JNI（Java Native Interface ）的作者，并领导设计了Java语言最为核心的JVM (Java 虚拟机) ，并于1999年出版了《The Java Native Interface: Programmer's Guide and Specification (The Java Series)》

注：Java平台由Java虚拟机（Java Virtual Machine）和Java 应用编程接口（Application Programming Interface、简称API）构成。

2000年，梁博士离开Sun公司，开启了自己的第一次创业之旅，创办了应用防火墙软件公司 Teros Network 并担任CTO。2001年公司被Citrix收购后，梁博士相继在Openwave System和SEVEN Networks担任工程主管和工程副总裁。

CloudStack VS OpenStack

2008年，梁博士开始了自己的第二次创业之旅，创办Cloud.com并担任CEO，推出著名的云计算管理软件CloudStack，也因此被誉为CloudStack之父，从此进入云计算时代。此时距亚马逊正式推出其第一个云计算服务（2006 年）刚刚过去两年。

2011 年Cloud.com被 Citrix 以 2 亿美金收购，梁胜博士出任 Citrix云平台首席技术官，也是 Citrix 公司首位华人 CTO。此时，诞生于2011年的OpenStack刚刚满周岁，正在快速生长。

2012年，OpenStack与CloudStack之争异常激烈。2012年4月，Citrix将开源云平台项目CloudStack捐献给了Apache基金会，2013年，CloudStack成为Apache孵化器的顶级项目。


在2013年，面对来自记者的提问，梁胜博士说：“虽然CloudStack已经成为Apache基金会最大的顶级项目，但它还远远没有成功。”他认为，与Apache HTTP Server等成熟的开源产品相比，CloudStack还是太过复杂。他还在继续追求：简单是最美的未来。

梁博士认为：最正宗的云还是公有云，国内云计算还有很大的上升空间。

容器英雄

2014年，梁胜博士创办了Rancher Lab并担任CEO，继续他的追风之旅，到去年，Kubernetes已经成为新的基础设施标准，作为开源容器管理平台，Rancher 聚焦企业级的Kubernetes集群管理，继续承载在梁博士的技术梦想。

成为世界一流

作为一名连续创业者，梁博士是一位标准的技术梦想家，也是一位具有开拓精神的优秀创业者和企业家。

作为华人工程师的泰斗，梁博士勉励国内工程师：不要相信程序员只能吃青春饭，绝对没有任何其它职业比编程序更能体现个人创造力和技能的价值，程序员就像艺术家，要努力成为世界一流。

左起： Rancher 中国区总经理 秦小康、创始人 梁博士 和 高效运维社区 萧帮主（GOPS 2018 深圳站）


作为华人工程师的杰出代表，梁博士先后创造了CloudStack、Rancher等云计算开源软件，不负韶华，也赢得了硅谷的尊重，成长为真正的世界一流。

追风少年，无论岁月沧桑，有梦想，出走半生，归来仍是少年。
