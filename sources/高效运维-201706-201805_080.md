作为 DevOps 理念的领军人物和布道者，**John Willis **拥有出色的履历，在行业内有着丰富的阅历。

![](../Images/eb285bac97b9781fdcaa1c399a4fefae.png)

  

> 作为 DevOps 全球权威之一，曾在 Docker 公司担任 Ecosystem Development Director。
> 
> John 因 2015 年 3 月他联合建立的公司 SocketPlane（专注于容器 SDN）被 Docker 公司收购而加入 Docker。
> 
> 2014 年建立 SocketPlane 之前，John 作为戴尔首席 DevOps 布道者曾在 2013 年 5 月参与戴尔收购 Enstratius 的项目。
> 
> John 曾管理 Opscode 公司的 Chef 项目和 Canonical 公司的 Ubuntu 项目。
> 
> John 是 IBM 红书的作者，并与 Gene Kim、Jez Humble 联合撰写了 Devops Handbook，是关于 DevOps 的名著之一，亚马逊上信息管理类书籍的销量冠军。
