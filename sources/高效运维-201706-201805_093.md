About Us

![](../Images/ea49533ca73131c3a3c255927f7ac0bb.png)

Oracle is a fast growth cloud company. Oracle Asia Research & Development Center aims to accelerate cloud adoption in JAPAC regions. We are looking for engineers who have ability and passion to drive the cloud transformation from infrastructure perspective

Principal/Senior Cloud DevOps Developer-APG

  

Basic Qualifications

*   Great coding skills in two programming languages such as Python, Ruby or Java
    
*   Hands on experience and knowledge in Docker, Docker network, storage, security. Orchestration tools like kubernetes or SWARM, and related registry tools.
    
*   Hands on experience in cloud operation tools including one or more monitoring, log systems i.e. Zabbix (or Nagios, Prometheus), ELK
    
*   Good understanding at devOps, master continuous integration and continuous delivery technologies and tools i.e. Jenkins. 
    
*   Familiar with infrastructure cloud automation tools i.e. Chef, Puppet, Foreman
    
*   Good at English communication, both verbal and written
    
*   Good understanding on SRE, micro service governance. 
    
*   4+ years cloud operation and maintenance experience.
    
*   5+ years professional experience in software development
    
*   Fluent English language skills 
    
*   Bachelor’s Degree in Computer Science or related field or equivalent combination of technical education and work experience
    

  

  

Preferred Qualifications

*   Self-motivated and quick learner
    
*   Experience in building complex software systems
    
*   Knowledge of professional software engineering practices & standards for the full software development process, including coding standards, code reviews, source control management, build processes, testing, and operations
    
*   Experience mentoring junior software engineers to improve their skills, and make them more effective, product software engineers
    

  

  

Description

You will be part of a team building cloud infrastructure internally and working with dynamic teams to improve cloud experience. You will have the space and opportunity to make a significant contribution in our efforts to change cloud computing for the better. As a member of this team, you will have the opportunity to build cloud infrastructure using tools and languages you and your team selects to be the best fit for the job. You will provide guidance and mentorship to other team members. In the innovative and creative environment, you will be able to learn in depth about existing software development tools, collaborate with and learn from exceptional engineers while using technology to solve hard challenges.
