2018年3月22日，由中国信息通信研究院（以下简称“信通院”）主办、中国通信标准化协会支持的"OSCAR云计算开源产业大会"在北京国家会议中心圆满落幕。

本次大会上，高效运维年后首场 DevOps 论坛同期举行。会上，6位专家带来精彩演讲，涵盖：DevOps 实践，微服务，Python 开发。更有高效运维社区萧帮主为您权威解读《DevOps标准体系及能力成熟度模型》

萧田国

高效运维社区 发起人，DevOpsDays 中国联合发起人

个人简介：高效运维社区发起人，开放运维联盟联合主席，GOPS 全球运维大会发起人，复旦大学特聘讲师。2004 年硕士毕业于北京科技大学，先后就职于联想集团、搜狐畅游、 触控科技等。十余年互联网运维从业经验，运维自媒体。国内第一个 EXIN DevOps Master 认证专家，首批官方授权讲师。

DevOps 是水，水无常态，但具体应用到各行各业，无疑需要有适当的容器才行。而 DevOps标准 就是这个容器。本次演讲将向您分享汇聚国内顶级互联网及电信、金融专家心血的的、国内外第一个 DevOps系列标准，内容涵括敏捷开发管理、持续交付、技术运营、应用架构、安全管理及组织结构等。此系列标准已在工信部正式立项，相信对贵司实施DevOps不无裨益，并可用来衡量贵司的DevOps能力。

郭宏泽

华图教育 技术总监

个人简介：12年IT行业经验，曾任职于易车网，中国电信，跟谁学等公司，现任HPE顾问讲师。擅长超大规模路由交换网络设计与运维，大规模Linux集群运维管理，Mysql集群解决方案。目前专注于私有云、Devops、数据库领域。

如何用 Python 开发一个企业级的运维平台？运维平台的应该怎么样模块化？如何使用Django快速实现原形？用Python怎么搞定异步任务模块？前后台交互是用Ajax还是WebSocket？Agent的设计要点？Python开发出来的CMDB应该如何整合自动化工具如ansible？此次分享以实际的开源项目AdminSet为基础，提供Python开发运维平台的经验与思路。

刘学斌

用友畅捷通信息技术有限公司云产品研发部 架构专家

个人简介：用友畅捷通信息技术股份有限公司架构专家，擅长领域驱动设计建模、微服务架构设计、应用安全开发、持续集成、DevOps、业务分析建模、开发流程设计等领域。有大型企业组织实施持续集成、应用安全开发、DevOps、架构设计实践经验。目前任职用友畅捷通云产品研发部，专职企业云产品微服务架构设计、企业应用建模（领域建模、物理建模、流程建模），坚信并实践DDD建模解决复杂业务问题之道。

公有云SAAS产品不同于传统的软件包产品，我们不仅需要负责软件的研发，同时需要负责产品的运维，面对众多用户，需要保障产品7X24不间断运行；客户业务是不断变化的，产品需要在持续运行过程中进行持续升级，以满足客户业务不断变化的需要。相对传统软件包产品，公有云产品的升级更加复杂，风险也更高，类似于在运动的汽车上更换轮胎。我们需要从多个维度采取措施，保障SAAS产品变化更容易（变化速度快、风险低）。

设计的本质就是让产品变化更容易。微服务架构是互联网时代以适应快速的业务变化而产生的一种架构模式，提供了让变化更容易的基础。技术上没有免费的午餐，微服务在给我们带来众多好处的同时，也带来了众多的复杂性，这其中包括DevOps复杂性、分布式系统复杂性等。我们必须采用合适的分析设计方法、工具和流程，改善产品设计架构、自动化DevOps、建立高质量的领域模型等，从而最大限度获得微服务架构的好处，降低微服务架构带来的负面影响。

景韵

DevOps 时代社区联合创始人

个人简介：DevOps 时代社区联合创始人，Certified DevOps Master，Certified Jenkins Engineer。先后就职于用友、乐视，从事持续交付、DevOps落地改进工作。曾主导用友集团DevOps整体改进与持续交付平台建设；乐视EUI持续集成方案改进。

基于Kubernetes与微服务架构的端到端流水线驱动DevOps落地。DevOps落地需要工程实践与工具平台支撑，端到端的流水线作为持续交付的核心实践，真正实现了打通从需求、研发、测试、发布到运维的DevOps全流程，实现价值流动。DevOps时代社区专家结合互联网公司实践经验，基于开源工具链打造的端到端的流水线，整合Jenkins/Gitlab/SonarQube/Kubernetes/Grafana等开源工具，覆盖用户故事地图管理、需求与代码关联、代码管理、持续集成、自动化测试、容器化、监控等实践，实现微服务架构的持续交付与DevOps。

洪烨

个人简介：资深数据中心架构师，培训讲师， Oracle YEP 成员， DBA+社区专家成员。拥有 DB2 V9 Advanced、Administrator、 Oracle 11g OCP， 6sigma 绿带、 AIX CATE 等多项国际认证。拥有多项国家软件著作权及专利，2013 年出版著作《DB2 数据库内部解析与性能调优》，擅长关系型数据库高可用及分布式架构设计、性能优化及数据中心架构设计。长期致力于金融行业系统架构设计及数据库技术推广。

对于以安全和可靠为第一位的传统银行，客户体验与业务转型已经逐渐成为企业主要关心的内容。DevOps能否适应传统银行的文化背景，又如何帮助传统银行建立交付完整的生命活动周期，如何能在不丧失安全可靠的前提下，加快业务交付速度。

关于2018云计算开源产业大会背景

近年来，云计算开源技术逐渐成为云计算发展的重要支撑和导向，改变了以往的信息技术进化模式，引领软件技术标准的发展和创新，深刻影响着整个信息技术产业的发展格局。为进一步探索我国云计算开源技术发展模式，加速云计算与各行业的深度融合，更好地发挥云计算在经济社会创新发展中的支撑和引领作用，促进我国云计算产业快速、健康发展。

由工业和信息化部指导、中国信息通信研究院主办、云计算开源产业联盟承办的"2018云计算开源产业大会"将于2018年3月21日－22日在国家会议中心举行。
