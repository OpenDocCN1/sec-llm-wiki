招聘企业：Keep

工作地点：北京

   运维开发工程师   

 职责描述：

1.  负责公司应用产品的运维，保障服务的稳定高效，不断提升用户体验
    
2.  负责应用服务和数据库相关的部署、维护和优化工作
    
3.  开发高效的自动化运维、管理工具，提升运维工作效率
    
4.  各类故障的应急响应、处理、协调，保证产品7\*24小时业务连续性
    
5.  优化运维解决方案，包括但不限于柔性容灾、弹性扩容与防攻击等  
    
      
    

职位要求：

1.   统招本科及以上学历，2年以上Linux工作经验
    
2.  熟悉Linux操作系统原理，TCP/IP以及常用的网络协议
    
3.  精通MySQL,Redis,mongoDB，Hbase等数据库的操作和维护
    
4.  熟练各种互联网应用服务：nginx/lvs/kafka/tomcat等，熟悉高可用机制，有监控和容灾的实际经验
    
5.  熟练使用Linux下的常用工具，熟练掌握Python / Shell / Go / PHP至少一门语言
    
6.  具备良好的自学能力,良好的沟通、组织协调能力和强烈的责任心，具备很强的分析和解决问题的能力
    
7.  擅长使用工具实现自动化，对于重复工作“0”容忍
    
8.   有大型互联网公司运维工作经验优先，211、985院校优先
