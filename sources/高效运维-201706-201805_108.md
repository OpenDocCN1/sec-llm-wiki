 关于我们 

医渡云（北京）技术有限公司（简称“医渡云”），是一家专注于医疗大数据研究与应用的高科技企业。在医疗大数据整理及深挖掘方面，处于绝对领先地位。

    医渡云公司致力于与中国领先的医疗机构共同建立“医疗大数据”平台，利用公司先进的机器学习和人工智能技术，对医疗数据进行集成、挖掘、利用，辅助开展新型临床、科研、医院管理等服务，助力医疗机构和医生，为患者提供更好的医疗服务

  

办公地点

北京北京海淀区牡丹园健康智谷

招聘岗位

01

  高级运维开发工程师  20K-40K  

  岗位职责：

1.  打造基于公有云及众多私有云环境的统一运维管理平台
    
2.  负责虚拟化及云计算平台相关管理工具的二次开发
    
3.  负责监控平台、流量调度、自动部署等平台的构建与优化
    
4.  参与设计、开发各种运维工具，提升运维效率
    

  

  岗位要求：

1.  计算机相关专业，具备2年以上互联网运维经验，1年以上运维开发经验
    
2.  具有良好的沟通能力、强烈的责任心，具备较强的分析和解决问题的能力
    
3.  具有运维自动化、配置管理、监控系统、发布系统等系统的开发经验
    
4.  熟悉Python/Golang/PHP/JavaScript/CSS/HTML相关开发技术
    

02

  高级运维工程师  15K-35K 

  岗位职责：

1.  负责公共平台、基础平台及线上业务的运维工作，保障业务稳定
    
2.  负责协调沟通，推进应用系统问题解决及优化，将业务需求转化为运维项目
    
3.  优化生产环境的部署效率，优化服务器的利用率
    
4.  研究主流运维技术，为业务发展提供可靠稳定的基础环境
    

  

  岗位要求：

1.  3年以上互联网运维工作经验, 有大规模服务器集群管理经验优先；
    
2.  精通Linux原理、系统、应用知识，深入了解互联网运维的主流开源系统与技术

4.  熟悉saltstack/ansible/puppet等常用配置管理工具
    
5.  熟悉如下任意一项加分：Docker相关技术；ElasticSearch；Mongo/mysql运维；PXE批量装机
