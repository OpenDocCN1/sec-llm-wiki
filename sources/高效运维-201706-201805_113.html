胜任要求


岗位一：安全运维专家

招聘人数：1人

岗位职责

  1. 了解云计算安全架构，熟悉互联网安全防护、PCI DSS等认证流程和技术要求。

  2. 熟悉Linux操作系统、应用中间件、网络技术；熟悉常见的脚本语言python、shell，可利用相关语言编写脚本工具。

  3. 熟悉常见的攻防技术和工具使用，对网络安全、系统安全和应用安全有深入的理解和自己的认识。

  4. 精通Linux操作系统和WEB应用的入侵证据获取、保存与分析。

岗位要求

  1. 了解云计算安全架构，熟悉互联网安全防护、PCI DSS等认证流程和技术要求。

  2. 熟悉Linux操作系统、应用中间件、网络技术；熟悉常见的脚本语言python、shell，可利用相关语言编写脚本工具。

  3. 熟悉常见的攻防技术和工具使用，对网络安全、系统安全和应用安全有深入的理解和自己的认识。

  4. 精通Linux操作系统和WEB应用的入侵证据获取、保存与分析。

有以下经验者优先录用

  1. 大学本科，信息安全专业或计算机相关专业。

  2. 通过国际计算机调查取证资质认证。

  3. 具备5年以上互联网安全风险评估经验。

  4. 有安全漏洞扫描和渗透测试实践经验者。

  5. 有大型CTF比赛(DEFCON,XCTF,etc)获奖经历。


岗位二：CDN运维专家

招聘人数：1人

岗位职责

  1. 负责视频流媒体业务：

  2. CDN服务稳定性问题排查、定位和持续优化，追求极致性能和稳定性

  3. 制定和优化CDN运维解决方案，包括不限于智能调度、网络优化、安全防范，促进业务体验提升

  4. 主导业务在CDN方面的可运维性设计和自动化工具的落地，提高运维工作效率

岗位要求

  1. 具备3年以上互联网视频业务运维经验或CDN服务商调度系统调优与运维经验

  2. 精通CDN原理和技术，精通CDN各种调度系统工作原理

  3. 熟悉Linux系统管理，熟悉Shell/Perl/Python脚本编程，熟悉各种运维工具（如Puppet/Ansible）的使用

  4. 强烈的责任心，做事认真细致，具备良好的团队合作精神，沟通能力佳

  5. 具有良好的分析问题和解决问题的能力，善于学习，有强烈的兴趣攻关疑难问题


岗位三：智能运维专家

招聘人数：1人

岗位职责

负责业务AIOps能力中心建设，包括但不限于指标异常检测、智能故障定位及影响面分析、成本智能管理相关的智能化产品设计和落地工作，具体如下：

  1. 负责智能化运维相关产品平台的整体解决方案的调研和输出

  2. 负责新技术的预研及跟踪，促进技术进步创新与应用场景落地

  3. 负责智能化运维相关产品平台逻辑：用户交互等内容的设计

  4. 负责智能化运维相关产品平台的落地闭环与持续改进工作

  5. 调研业界先进的智能运维方案及适用场景，并结合现有业务需求输出整体解决方案

岗位要求

  1. 计算机相关专业，本科及以上学历。

  2. 具备5年以上互联网运维工作经验，有智能运维实际工作经验。

  3. 熟悉运维监控体系、故障联动分析策略、运维成本规划管理。

  4. 强烈的责任心，做事认真细致，具备良好的团队合作精神，沟通能力佳。

  5. 具有良好的分析问题和解决问题的能力，善于学习，有强烈的兴趣攻关疑难问题。


岗位四：运维开发工程师

招聘人数：3人

岗位职责

  1. 负责自动化运维平台设计及开发，实现自动化部署、监控、自动化配置等，提高运维效率；

  2. 负责运维新技术、新平台的研究和实践；

  3. 与运维团队合作，收集与理解需求，提供解决方案，改善运维流程；

岗位要求

  1. 能熟练使用Python/GO 编程语言。

  2. 热爱开源技术，熟悉一种或多种开源软件（Ansible、Django、Puppet、Celery,ETCD等），熟悉源码者优先

  3. 熟悉linux，Docker、VM等系统

  4. 具有互联网运维平台开发或系统运维经验 

  5. 熟悉网络知识，了解DNS/HTTP/Proxy/Load balancing/CDN方案和原理

  6. 有良好的沟通能力、推动能力和良好的服务意识。


岗位五：业务运维工程师

招聘人数：3人

岗位职责

  1. 负责应用市场、游戏、浏览器业务的后台环境搭建和维护、版本更新、方案规划及实施；

  2. 负责监控业务的运行状况，识别风险，分析优化，及时处理突发故障，保障服务正常；

  3. 负责持续提升用户体验，提升系统健壮性，提升服务可用性，优化运维成本；

  4. 参与运维平台工具建设，参与DevOps中持续部署、持续监控、持续反馈工作；

岗位要求

  1. 熟悉linux系统，对服务器硬件知识有一定的了解，熟悉网络知识，了解tcp/ip协议；

  2. 能使用shell/perl/python等脚本语言编程，了解mysql、redis、ngnix、等组件；

  3. 敬业、有责任心，有良好的沟通能力、推动能力、服务意识；

  4. 有互联网公司工作经验的优先，有视频、游戏、支付、应用商店、浏览器、CDN运维经验的优先；


岗位六：网络运维工程师

招聘人数：1人

岗位职责

  1. 负责网络部署、规划、设计、日常运维。

  2. 负责从网络层分析识别现网问题，提出优化方案并推动落地。

岗位要求

  1. 计算机网络等相关专业，本科及以上学历。

  2. 2年以上相关工作经验，熟悉TCP/IP协议。

  3. 熟悉主流的网络设备、F5，精通路由协议（ospf，bgp），有大规模网络部署规划、运维经验优先。

  4. 熟悉华为网络设备，能使用shell、perl、python等脚本编程语言优先考虑。


岗位七：系统运维工程师

招聘人数：1人

岗位职责

  1. 负责Linux系统的运维及运营管理。

  2. 负责系统的部署架构、容灾、监控、管控规范以及自动化运维方案的制定和实施。

  3. 推动流程及工具的改进，保障系统的高可用性和稳定性。

岗位要求

  1. 计算机网络等相关专业，本科及以上学历。

  2. 3年以上linux操作系统运维经验。

  3. 熟练掌握各种linux常用命令，熟练使用shell脚本编程

  4. 熟悉TCP/IP网络原理。

  5. 大规模linux服务器运维管理经验者优先
