  3. 对保险行业有一定的业务理解，对架构治理有一定的认知，具备一定的保险业务知识；
    沟通能力强，有团队合作精神。

  3. 熟悉 http协议、缓存、序列化、nio、RPC调用框架等

  5. 熟练掌握Oracle及 MySQL应用开发、数据库原理和常用性能优化

  6. 具有良好的文档撰写能力，精通至少一种建模工具

  云技术工程师  

  岗位职责：

  1. 根据我司的发展战略，主持云计算平台整体架构设计、容灾方案制定、各种新技术新产品测试和选型；

  2. 对云平台系统的搭建和运用有丰富的经验，推动云服务的应用；

  3. 分析并解决云平台开发&运维过程中的问题；

  4. 了解云平台行业的发展趋势，为云平台决策提供技术方面的支撑；

  5. 构建技术团队，并且能带领技术团队与其他团队紧密配合。


  岗位要求：

  1. 熟悉云平台（IaaS/PaaS/SaaS等）架构设计或应用开发经验；

  6. 熟悉软件定义及分布式存储。

  网络工程师   

  岗位职责：

  1. 负责公司网络整体架构的规划、设计、建设、运维、监控、管理，参与重大网络故障的处理，对网络运维过程中出现的常见问题及重复出现的故障，进行详尽的分析，并提交相应的问题解决方案；

  2. 负责网络需求的沟通，参与业务的架构优化，容灾优化、应用性能优化等项目，保证数据和业务安全，从网络上保证业务产品的部署结构、IDC分布、HA方案等的控制和改良

  3. 制定和完善网络运维管理相关制度；

  4. 负责公司生产、测试、办公环境网络维护，公司防火墙、路由器、交换机等所有网络相关设备管理。


岗位要求：

  1. 能够对全行的生产网、开发测试网、办公网等网络区域进行架构规划和设计；

  2. 精通IP规划、二三层协议等网络知识，有数据中心实施经验；

  3. 熟悉主流网络设备，能够独立安装、调试、测试、监控主流厂家（华为、H3C、思科、Juniper、hillstone、checkpoint)的路由交换防火墙设备；

  4. 熟练配置VPN、防火墙、IPS等网络安全设备，熟悉维护F5、A10等负载均衡设备；
    能独立编写技术文档及方案，能快速、准确的定位故障并能及时的进行处理；

  5. 能够熟练使用sniffer等工具进行网络故障分析，处理常见的网络问题，制定解决方案；
    熟悉SDN和网络虚拟化技术者优先考虑

  岗位职责：

  1. 负责我司存储服务器的规划、建设及运维工作

  3. 组织数据中心服务器、存储的日常运维工作；

  4. 组织对数据中心服务器、存储发现问题的排查和解决。


  岗位要求：

  1. 熟练掌握ITIL标准体系和ISO27001安全体系

  4. 具有丰富的运行维护经验，能够快速准确的判断问题故障点。

 DBA  

  岗位职责：

  1. 负责数据库的日常运维工作，改进与完善数据库运维管理相关制度；

  2. 负责数据库的变更、部署、安装、问题排除及解决

  3. 负责定期对整体数据库架构进行必要的升级、性能评估及调优以提高整体性能，且负责合理规划和使用数据库；

  4. 负责对突发事件和疑难问题进行排查和解决。

  5. 负责公司数据库整体架构的规划、设计、建设、运维、监控、管理，参与重大故障的处理，对数据库中间件运维过程中出现的常见问题及重复出现的故障，进行详尽的分析，并提交相应的问题解决方案。


 岗位要求：

  1. 全日制本科或以上学历，计算机或相关专业，5年以上数据库工作经验；

  2. 熟悉主流的数据库及中间件架构；熟悉ORACLE数据库运维、高可用集群的搭建、调优及安全配置技术。

  3. 精通MySQL或PostgreSQL等开源数据库的基本原理以及高可用、高性能架构规划设计、分析及调优方法，并能进行数据库的高可用部署、性能分析和复杂调优；

  4. 能熟练的进行ORACLE、MySQL或PostgreSQL等数据库运维管理操作,并能熟练的解决较严重数据库故障；

  5. 精通数据库的各种备份及恢复方法，能进行数据库备份方案的设计，并能进行方案的实施和维护；

  6. 具有上进心、责任心、良好的沟通能力和团队合作精神，热爱学习、做事积极主动，能承受工作压力；
