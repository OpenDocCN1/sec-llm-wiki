# 【巅峰对决】OSCAR五大尖峰开源奖项，总有一款适合你

近年来，随着新技术的发展应用，云计算已成为越来越重要的基础设施。在工信部印发的《云计算发展三年行动规划（2017-2019年）》中，提出我国云计算产业规模要达到4300亿元的发展目标。  

![](../Images/a5ae23ff68d7b55a8df6da7af0acc9ba.png)

伴随着云计算业务规模的扩大，开源技术也呈现爆发式增长趋势，以OpenStack、Docker等开源技术为代表的应用愈发广泛，国内开源生态圈逐步建立。当前云计算开源已正是进入下半场，越来越多的新型开源项目涌现，开源企业的实力也与日俱增，在国际开源社区中的影响力也不断提升。  

如今，许多技术人员和企业都爱上了开源，为什么？因为并不是每个软件每个产品的开发都需要从头做起。借助开源社区的力量，站在软件巨人的肩膀上，选用合适的开源技术，比独自开发能节省时间和效率，更能得到事半功倍的功效。可究竟什么是开源？不懂开源的企业，如何才能开源？企业通过哪些方式来参与开源？如何维护管理开源社区？在被开源技术围绕的时代，不懂开源如何去拥抱开源？在3月21-22日举办的“2018云计算开源产业大会”中将一一进行解读。

为了更好地推动开源技术在中国市场的落地，更好地鼓励企业和厂商使用开源，云计算开源产业联盟特设“OSCAR尖峰开源技术和人物”大奖，以表彰在云计算开源领域具有杰出贡献的企业、个人和技术。目前奖项申报正在火热进行中，欢迎相关企业或个人积极申报。

![](../Images/049fe4e797c81e58a78910e90c47b8e7.png "动图跳跃分割线")

**本次开源奖项评选共设五个奖项：**

![](../Images/443771f2c16921272c22a03b7e095995.png)

开源人物奖

此奖项面向在开源项目或开源社区活动等开源事务上具有突出贡献、成就的个人。如发起或负责过市场影响力较大的开源项目，为受欢迎程度较大的开源项目贡献过代码，活跃在开源社区活动中或在开源基金会、联盟、社区等组织担任重要角色。

![](../Images/443771f2c16921272c22a03b7e095995.png)

开源企业奖

此奖项面向在开源项目或开源社区活动等开源事务上具有突出贡献、成就的创新型企业或普通企业。如发起或负责过市场影响力较大的开源项目，在开源社区具有较大贡献或在开源基金会、联盟、社区等组织担任重要角色。

![](../Images/443771f2c16921272c22a03b7e095995.png)

开源技术创新奖（自主负责或研发的技术和项目）

此奖项面向在OpenStack、容器、开源存储和开源数据库领域的创新型技术或项目。技术或项目应为申请机构、申请人自主负责或研发的，具有一定的受欢迎程度和突出创新点。

![](../Images/443771f2c16921272c22a03b7e095995.png)

开源技术创新奖（基于社区版本二次开发的技术或项目）

此奖项面向在OpenStack、容器、开源存储和开源数据库领域的创新型技术或项目。技术或项目应为申请机构、申请人基于社区版本二次开发的，在社区版本的基础上具有一定改进和创新。

![](../Images/443771f2c16921272c22a03b7e095995.png)

开源用户奖

此奖项面向使用开源技术或项目的活跃企业用户。

![](../Images/c77061c72a98fae247dd28c986397efe.png)![](../Images/d1133f9a16329e9d4dd075b8af7dcdf1.png)

奖项申报

![](../Images/b72716738f75e00a8aa3b91622790ede.png)

时间流程如下

1月19日—3月9日为报名时间，3月13日进行现场答辩、专家评审打分评比，3月22日发布结果并颁奖。

参加开源奖项评选，申报企业或个人需按奖项申请模板中的提示如实填写各项内容。收到申请表后，评审委员将根据分数分配标准对申请表进行打分，分数将作为评奖的基准。最终评选结果将在“2018云计算开源产业大会”上隆重揭晓。
