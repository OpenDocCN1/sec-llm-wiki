 关于我们 

在追求极致的理念下，我们不仅在让ColorOS越来越稳定、流畅和更加省电，也在努力让国内上亿的用户群和海外正日益膨胀的多国用户群体有一个更可靠、更流畅、也更智能的网络服务。OPPO数据中心在这其中承担了平台运维能力和大数据平台两个基础职能。

 

 关于我们的团队  

成员从70后到90后都有，主要来自知名互联网公司比如BAT、UC、迅雷等；

我们的服务器、数据量的增速丝毫不慢于业务的增长量，甚至还要走在前面；

比起已然整套体系成熟的大公司，我们在工具化、系统化上还有很多能充分发挥能力的地方，服务好亿级用户我们还需要持续进步；

公司乐意在核心关键问题上付出苦功夫大力气，不用担心总需要做些杂七杂八没价值的东西；

上下班不打卡，我们更关心你的产出价值和个人成长。

  系统运维工程师  15K-35K 5人 

  岗位职责：

  1. 负责OPPO云平台的建设和保障工作；

  2. 负责操作系统的选型、初始化、参数调优、升级等工作；

  3. 负责OS、云主机、容器等日常排障及维护工作；

  4. 负责Redis、Nginx、Tomcat等各类组件的日常排障及维护工作；

  5. 负责容器平台的建设及维护工作。


  岗位要求：

  1. 计算机、网络、通信或相关专业，本科及以上，3年以上工作经验；

  2. 精通linux操作系统，对linux内核参数有深入理解；

  3. 精通网络原理，熟悉主流网络设计原则；

  4. 熟悉docker，有大规模容器化运维经验者优先；

  5. 熟悉各类互联网业务常用开源组件的调优、排障等；

  6. 上述能力可以各有侧重，不需要全部精通。

  业务运维工程师 15K-35K 5人  

  岗位职责：

  1. 负责承接产品运维需求，参与产品的可运维架构设计；

  2.  负责产品服务器资源规划，环境部署，为开发团队提供支持，保证产品的开发进度；

  3.  对业务和服务器做好监控，维护业务的稳定性；

  4.  跟进推动运维技术项目，保证项目的成功完成。


  岗位要求：

  1.  两年以上互联网业务运维工作经验；

  2.  熟悉Linux系统，包括操作系统原理与Linux系统命令，掌握Linux系统服务、常用中间件的使用，如NFS、Nginx、Apache、Redis等；

  3. 具备故障分析和处理能力，能熟练使用相关命令和工具，如strace、netstat、dig、tcpdump等；

  4. 具备脚本编写能力，能通过脚本快速高效的完成工作，如Shell/Perl/Python，以及awk、sed等；

  5. 有一定的网络基础， 了解TCP/IP、HTTP、VRRP等常用协议；

  6. 熟悉了解行业主流运维平台类工具，如监控相关Nagios、Zabbix或Ganglia，自动化相关Jenkins、Puppet或Ansible等。

  运维研发工程师 15K-35K  2人 

  岗位职责：

  1. 设计、开发高可靠性、方便的运维工具，提高运维工作效率；

  2. 建设OPPO的运维自动化体系。


  岗位要求：

  1. 3年以上Python+Django/Java开发工作经验，熟悉Linux系统； 

  2. 熟悉JavaScript、HTML前端开发，有jQuery、AngularJS使用经验者优先； 

  3. 熟悉MySQL数据库，了解数据库性能优化基本概念； 

  4. 有数据处理、监控系统、云服务产品相关经验者优先。

  网络工程师 15K-35K  2人  

  岗位职责：

  1. 制定和执行网络设计、搭建、配置、监控、优化、调整的实施方案；

  2. 根据网络运行规范，负责网络的日常运行维护工作，以及网络调整和故障处理等；

  3. 网络运行规范和技术手册的编写，机房内硬件设备的管理工作。


岗位要求：

  1. 一年以上网络维护工作经验，有基础的网络故障判断和定位能力；

  2. 熟悉CISCO、华为、H3C等主流交换机品牌，有实际的操作配置能力；

  3. 熟练掌握VLAN、STP、OSPF、BGP等协议的原理和配置实施；

  4. 熟悉lvs，防火墙等设备的基本原理和操作；

  5. 熟悉linux网络原理和知识，能够编写基本的linux自动化脚本；

  6. 有其他互联网公司IDC网络建设和运维工作经验者优先；

  MySQL DBA 15K-35K 1人  

  岗位职责：

  1. 负责数据库的安装配置及升级改造、性能监控及优化、故障诊断和排除；

  2. 负责数据备份和恢复的策略定制已经对DB权限的管控等；

  3. 研究数据库高可用架构方案并将方案在生产环境中投入使用，提升关键系统的稳定性和健壮性；

  4. 负责处理各个业务部门提出来的各种DB需求并与开发团队紧密配合，规划、设计、评审和优化数据库技术方案。


岗位要求：

  1. 3年以上互联网应用领域大数据量及大并发量的数据库运维经验;

  2. 熟悉MySql数据库的运行机制和体系架构，精通Mysql数据库配置、监控、备份、优化;

  3. 对主流MySQL分支(MariaDB,Percona Server)有了解;

  4. 熟悉mysql主从、keepalived、MHA、MMM等高可用方案;

  5. 熟悉linux OS,熟悉shell/Perl/Python，至少一种脚本的编写;

  6. 有oracle、mongodb、redis相关维护经验优先。
