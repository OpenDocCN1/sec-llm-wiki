   存储研发高级工程师－2人   

  岗位职责：

  1. 参与分布式对象、存储、备份平台及技术方案规划、设计、研发；

  2. 负责分布式存储平台的运维、升级、排障与调优；

  3. 研发中的技术难题，保证最终性能和稳定性，支撑整体云平台的对接需求；

  4. 跟踪存储行业最新发展技术、研究和积累新技术；

  5. 参与并跟进开源社区，开源技术的预研。

  任职要求：

  1. 本科及以上，5 年以上开发经验，3 年 Ceph、Gluserfs 等分布式块、对象存储相关工作经验；

  2. 深入理解文件系统、存储技术、开源云存储产品；

  3. 对高性能、分布式、海量存储、对象存储等领域有深入理解；

  4. 具有分布式存储服务项目及相关运维自动化项目实施经验者优先；

  5. 具有较强的 C/C++/python 等语言编程功底，在 ceph@Github 贡献过源代码者或有编写过核心模块代码的经验者优先；

  6. 具有良好的沟通能力，良好的书面和口头表达能力，能熟练阅读专业的英文资料，具备较高的文档撰写水平；

  7. 思维缜密，逻辑性强，自我驱动，具有挑战精神和前瞻性，良好的团队协作精神。

   运维开发工程师－1人   

  岗位职责：

  1. 负责运营支撑平台、运维自动化平台及其组件的设计和开发；

  2. 负责优化、改进运维支持系统，并保证其安全高效稳定的运行；

  3. 参与运营平台、运维系统的需求分析、设计、编码；

  4. 负责开发、完善运维内部系统及辅助系统，提升运维质量及效率；

  5. 通过技术手段控制和优化成本，提升资源使用率。

  任职要求：

  1. 精通 Unix/Linux 操作系统、良好的 Bash 与 Python 编码规范；

  2. 全日制统招本科以上学历，3 年以上工作经验，具有良好的学习能力、沟通能力、服务理念和合作精神；

  3. 强烈的责任心与主动性，对所负责工作有 owner 意识，并能自我驱动成长；

  4. 有 Docker、K8S 等容器虚拟化技术经验者优先；熟悉 python、Ansible 和 web 前端开发优先；

  5. 有运维自动化、监控系统、发布系统、运营支撑系统等开发经验者优先；

  6. 有大型分布式系统设计与开发经验者优先。

  3. 对完成的页面进行维护和对网站前端性能做相应的优化；

  4. 熟悉当前互联网的各种流行应用，在交互开发、用户体验等方面有自己的见解。

  2. 熟练掌握 elementui 框架，bootstrap 框架、自适应布局以及浏览器兼容性；

   产品经理－3人   

  岗位职责：

  1. 产品需求挖掘及收集：负责内外部产品调研分析，根据调研结果，形成产品规划意见提出明确产品需求；

  2. 产品实施：负责原型设计、撰写需求文档，保证落实产品需求。跟进产品研发过程中反馈的问题，协调并提出相应产品改进方案；

  3. 产品跟踪优化：收集反馈和新的产品需求，形成优化建议方案，推进产品优化的落实和相应产品指标的跟踪达成；

  4. 产品持续运营：负责制定相关运营政策（如内容完善、活动策划、促销推广等），达成产品运营目标；

  5. 协作支持：负责与关联部门职能协作，引导关联部门达成产品愿景。

  任职要求：

  1. 本科及以上学历，3年以上产品经理工作经验；

  2. 对产品前端功能用户交互设计、及后端系统逻辑有所了解；

  3. 有经历过需求调研、产品构想、设计、开发、上线、运营全流程；

  4. 熟练掌握原型设计工具，如Axure、Visio、MindManager、MSOffice等；

  5. 能通过市场跟踪、竞品分析、用户调研及运营数据分析优化产品功能，推动产品不断优化完善；

  6. 良好的学习能力，沟通协调能力，抗压能力；

  7. 具有全局观、对于整体产品规划有自己的见解和理念。

   测试工程师－1人   

  岗位职责：

  1. 测试需求理解：能够充分理解项目需求和产品设计思想，并能对产品的结构及功能提出建设性意见；

  2. 测试计划：能够对负责的测试任务准确的进行工作量的估算，以及制定较合理的测试计划；

  3. 测试方案及用例设计：能够根据产品需求进行功能方面测试方案及测试用例的设计；

  4. 环境的搭建及部署：能够按照环境搭建手册对测试环境进行搭建和部署；

  5. 测试执行：能够按照测试方案和用例执行测试工作，并能够遵照缺陷管理规范中的要求进行缺陷的管理、对缺陷的变化曲线及具体的缺陷类型的分布进行深入的分析，给研发员提出建设性的改进建议；

  6. 编制报告：根据产品的测试情况编写相应的测试报告，对发现缺陷的各种属性进行汇总和分析，并能够给出研发工作的改进建议。

  任职要求：

  1. 本科及以上学历，至少3年测试工作经验；

  2. 熟悉软件开发、测试流程以及测试过程管理；

  3. 熟练使用 SQL 语言，掌握 SQL Server、Oracle 等一种或多种数据库系统的使用；

  4. 熟练掌握各种黑盒测试技术，能够进行测试用例设计、测试执行、编写缺陷报告；

  5. 至少掌握一种当前主流的自动化测试工具（Loadrunner&Selenium 尤佳）；

  6. 会用Python;

  7. 熟悉 Jenkins 构建与底层配置。

   数据分析工程师－2人   

  岗位职责：

  1. 负责产品运营数据规划，为运营人员提供数据支持，包含数据埋点需求梳理、数据报表及呈现方式梳理等相关运营工作底盘标准化建设；

  2. 结合产品运营需求，负责对运营数据进行采集、清洗、建模及统计分析整理 ，对日常的运营数据进行监控、分析，按需求形成数据分析报告；

  3. 深入理解业务，对渠道及相关的业务数据进行分析、挖掘，撰写运营分析报告，发现业务特征和渠道价值，为业务决策、产品方向提供分析建议；

  4. 根据业务需求，通过领域分析和数据分析提出创新性的解决方案，并形成数据产品工具；

  5. 负责不同部门之间的沟通和协调工作，推动跨组织合作项目发展。

  任职要求：

  1. 本科及以上学历，应用数学、统计学及计算机相关专业；

  2. 3 年以上数据统计分析、数据挖掘等互联网行业数据分析经验，熟悉掌握数据规划、数据仓库构建等知识；

  3. 熟悉数据建模知识、数据挖掘理论，掌握数据分析体系方法，熟悉大型数据仓库模型设计和 ETL 开发经验，曾经参与过完整的数据采集、整理、分析工作；

  4. 能够熟练使用 Hive、SQL、Python 、R、SAS、SPSS 及其他数据语言统计者优先

  5. 熟练掌握 Oracle 或 Mysql 传统数据库开发技术；

  6. 具备一定的产品思维，熟练掌握产品需求分析、设计技巧，对交互设计过程有一定的理解； 

  7. 业务理解能力强，善于和业务、技术、运营等相关团队同事有效沟通；心态开放，乐于学习，富有激情。
