> 无人不知的私人管家 Jenkins ，在日常的工作中可以说是非常给力：

*   写好发布Job，开发同学自己就能上线
    
*   代码提交即时编译打包，根本不用我操心
    
*   轻松搞定持续集成，代码质量有保障，发版不愁人
    
*   调度Ansible定期清理垃圾文件，so easy！
    
*   代码开源、社区活跃，想要实现什么需求去找插件就可以了，自己定制插件也不难
    

**但是你知道吗？Jenkins 还有更多新特性，怎样更加全面发挥 Jenkins 的性能？**

跟随 KK 的脚步、首先我们来到主会场：

主会场

  

Jenkins 创始人 KK 亲自为我们介绍了 Jenkins 过去在持续集成上的努力。并结合现状、讲解了 Jenkins 目前的特性。最后对于 Jenkins 未来的表达了自己的期许。

来自微软的 Program Manager Pui Chee Chan 老师为大家介绍了微软内部是如何驱动 DevOps 发展、如何促进开发、技术运营和质量保障部门之间的沟通、协作与整合。

![](../Images/4ccb1a5c836cd8cac1bb49cfb99d15b5.png)

最后、Pinterest 发布工程和开发效能主管 / Apple 前构建工程师郑旭老师为我们带来精彩演讲《在Kubernetes中运行Jenkins服务》主要介绍了 Pinterest 正在进行的一个项目实践，即从传统的用一台机器运行一个 Jenkins master，一台机器运行一个 Jenkins Slave 移植到用 Kubernetes 运行和管理 Jenkins。

持续交付&DevOps 专场

  

潘金赤老师为大家介绍了手Q研发体系建设与工具实践。随后王潇俊为大家介绍了携程持续交付平台的演进、变革与展望。来自京东的讲师潘晓明为大家揭秘京东软件研发高速迭代的秘密。最后、来自 vivo 的讲师杨振涛老师为大家讲解 vivo 基于 Jenkins 的持续交付实践和演进。  

![](../Images/74dab961aeb1b0c11b7b1a85352c8d27.png)

企业级 Jenkins 实践专场

  

CloudBees Software Engineer Sam Van Oort 老师带来主题演讲《Pipelines At Scale: How Big, How Fast, How Many?》你讲知道这些：我们一次可以运行多少个 Jenkins Pipeline？什么因素会限制了 Pipeline 的执行速度和规模？ 如何使我们的 Pipeline 运行更快？

随后、我们一起与石雪峰老师探讨 Jenkins 如何支撑 CICD，何为轻量化 Jenkins 的理念，以及实现 Jenkins 的高可用性的核心技术实践，让 Jenkins 持续不断的驱动企业价值交付。

诺基亚无线云平台公共服务部门负责人何军老师介绍了诺基亚无线云平台如何通过对 Jenkins Log 的秒级切片数据采集，构建研发大数据平台。

华为高级架构师刘长城给我们分享乐使用 Jenkins 构建 DevOps 工具链的经验。

![](../Images/9a157caf1ec89a6f79ea3f7140c1b49c.png)
