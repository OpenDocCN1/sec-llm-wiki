Jenkins Area Meetup (JAM) 是 Jenkins 官方在全球范围内的线下沙龙活动，旨在分享 Jenkins 理念与实践经验，促进 Jenkins 用户、爱好者们相互交流和学习。


本次活动由 DevOps 时代社区联合 Jenkins 爱好者联合发起，超低的价格让中国的 Jenkins 用户与爱好者有机会相互交流和共同成长。


本次活动也是中国首次Jenkins用户大会的一个组成部分，在Jenkins用户大会上，Jenkins创始人KK将有机会与您面对面交流。


活动内容分为两个部分：精彩演讲+现场演练 //您也有机会和 Jenkins 创始人不期而遇，甚至合影留恋。

企业级 Jenkins 实践


Sam  Van Oort         

CloudBees Software Engineer

Jenkins Committer


演讲者介绍：Sam Van Oort 是 CloudBees 的软件工程师，也是开源 Jenkins 的贡献者。 专注于领域包括 Jenkins Pipeline 插件，Docker，Jenkins 本地化安装包（兼职维护者）及其 Jenkins Docker 安装包的自动化测试。 之前任职于红帽。业余时间活跃在开源领域。 是一名 Certified CloudBees Jenkins 平台工程师和红帽认证系统管理员。


《Pipelines At Scale: How Big, How Fast, How Many? 》


主题简介： 

我们一次可以运行多少个Jenkins Pipeline？ 什么因素会限制了Pipeline的执行速度和规模？ 如何使我们的Pipeline运行更快？为了回答这些问题，我们将借鉴大规模用户，基准以及Pipeline 代码内部等领域的经验。 然后，我们将展示一系列提高Pipeline性能的全新功能，并解释是如何提高 Pipeline可伸缩性的。这个演讲将有助于尝试在大型 Jenkins 实例上运行 Pipeline，以及在有限资源的Jenkins实例上如何提升性能。                                 


石雪峰       

新乐视 配置管理技术总监                                 


演讲者介绍：07年天津大学毕业后赴日从事多年软件开发工作，回国后加入华为，现乐视致新软件配置管理工程效率团队负责人，技术总监，负责乐视内部产品软件交付，研发工具链基础设施建设，多年安卓产品技术经验，深信技术改变世界。


《轻量化 Jenkins 高可用实践》


主题简介：

随着近年来DevOps理念的深入人心，持续交付已经成为企业的核心竞争力和工程实践，其中Jenkins作为承载企业端到端交付流水线的系统平台，堪称IT业务价值流的枢纽和生命线。在本次分享中，我们一起探讨Jenkins如何支撑CICD，何为轻量化Jenkins的理念，以及实现Jenkins的高可用性的核心技术实践，让Jenkins持续不断的驱动企业价值交付。

                         


何军        

诺基亚   无线云平台公共服务部门负责人


演讲者介绍：从事研发及产品管理相关工作17年以上。秉持管理需要深入了解技术实现细节的理念，一直保持对技术的关注与投入，多年从事无线技术，云技术，网络技术，测试自动化，工业自动化，人工智能及大数据技术等一线研发工作。同时，作为管理人员，具有海外研发管理，跨国研发管理和大团队研发产品管理经验。擅长基于数据分析和自动化的敏捷管理改进。


《基于Jenkins Log 秒级数据的研发效能改进》


主题简介：

介绍诺基亚无线云平台如何通过对Jenkins Log的秒级切片数据采集，构建研发大数据平台。通过机器学习等算法，实时量化研发过程质量和效能情况，供研发人员，云平台产品集成系统（Nokia Cloud Platform Production System）， 研发效能和运维专家，研发管理团队随时了解研发进展及瓶颈情况，达到持续交付目标。                            


刘长城

华为 高级架构师                                        


演讲者介绍：2007年加入华为并在华为工作至今，一直从事华为研发工具相关的设计开发工作，参与打造华为研发全流程工具链，包括从需求管理、架构设计、开发测试、测试工厂、环境管理、Android手机测试、持续交付流水线等研发各环节的工具支撑。


《如何借助 Jenkins 实现 DevOps 工具链》


主题简介：

主要分享使用 Jenkins 构建 DevOps 工具链的经验，重点介绍如何实现 Jenkins 支持编译各种程序语言的持续集成服务，如何解决 Jenkins Master 高可用，执行slave资源共享，更高效的Job调度、更安全的租户资源管理等问题。并介绍如何利用Jenkins 2.0 Pipeline，实现构建、测试、部署、灰度上线、发布等拉通的 DevOps 工具链。
