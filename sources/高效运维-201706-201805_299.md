# 灵雀云（Alauda）B轮融资获腾讯云领投，领跑容器PaaS市场

**摘要：灵雀云（Alauda）获B轮融资，腾讯云战略领投，之前轮次投资方高榕资本、宽带资本跟投，其他战略投资者持续跟进，B轮融资总额超亿元人民币。融资后，腾讯云与灵雀云双方将在容器及企业级PaaS领域展开深入合作，深耕中国企业级IT服务市场。共同助力企业成功实现数字化转型。**

2017年11月8日北京，全球领先的企业级容器PaaS服务商灵雀云今日宣布，B轮融资阶段性完成，此轮融资由腾讯云领投，高榕资本、宽带资本跟投，其他战略投资者持续跟进，融资总额超过亿元。

  

此前，灵雀云曾获得高榕资本的Pre A轮融资，以及由宽带资本领投、高榕资本跟投的A轮融资。本次B轮融资之后，灵雀云已成为迄今为止国内唯一一家实现B轮融资的容器PaaS企业，奠定了在该领域的领导者地位。

  

在引入腾讯云投资的同时，灵雀云也迎来重大战略升级——成为腾讯云在企业服务领域的长期战略合作伙伴。双方将在企业级云平台展开合作，深耕金融、制造、传统企业和政府等领域，共同拓展企业级IT服务市场，助力传统企业实现数字化转型。

> **企业数字化转型聚焦容器PaaS 灵雀云进入快车道**  

  

随着传统企业对数字化转型需求的日益迫切，用户对容器和PaaS服务的市场需求也从单纯技术试探性引入，转向行业纵深定制化普及推广。

  

数字化转型能够帮助企业实现产品差异化，建立竞争优势，并提供极致的用户体验。在这个过程中，企业IT面临的最大挑战，是如何提高业务敏捷度和加速交付节奏。而容器PaaS可以帮助客户快速构建云原生应用，实现持续集成和交付，加速应用迭代，从而成为企业落地微服务架构改造及实现DevOps运维架构理念的最佳选择。

  

灵雀云成立于2014年，拥有业界领先的企业级PaaS平台产品和服务能力。2017年6月，灵雀云继发布SaaS版本的Alauda Cloud和Alauda Cloud Pro之后，面向企业级市场推出以DevOps为理念，面向微服务应用的新一代PaaS平台Alauda EE，从而迅速占领企业级PaaS市场。2017年9月，灵雀云作为唯一一家容器服务企业，受邀加入“未来就绪企业云联盟“，加速推动了云原生理念和微服务解决方案在中国及全球市场的实践。

  

灵雀云不仅是容器技术社区早期的实践者，也是CNCF的正式成员，是国内最早从事容器PaaS平台服务的专业服务商。创始人兼CEO左玥，是业界OS内核、虚拟化和网络领域的顶级专家，拥有六项全球云计算专利，更曾是微软容器技术“第一人”；创始人兼CTO陈恺，曾领导Azure最核心的中控系统团队，一手建立并管理这一世界领先的云服务平台，承载了百万台虚拟机和千万个云应用。

  

> **“腾讯云＋灵雀云”强强联手 抢占企业PaaS制高点**

  

今年三月，双方就曾签署战略合作协议，在企业级容器云平台展开合作，推动容器技术在云服务领域中的落地。此次战略投资的达成，更将让这一合作更加深入。灵雀云容器PaaS平台将成为腾讯云解决方案中的核心组件之一，双方将共同拓展企业级云服务市场，为客户提供企业级应用集成、交付、运维的一站式解决方案。

  

“灵雀云的创办人和团队拥有强大的技术和服务优势，同时灵雀云一直以来深度拥抱以Kubernetes为代表的国际上最先进的技术和理念，又有着很强的市场洞见和对用户需求的把握能力。此次注资灵雀云，正是看好其作为一家技术驱动的创业公司，通过多年积累形成了自己的市场壁垒和行业先发优势，” 腾讯云总裁邱跃鹏表示，“腾讯云期望专注于基础的平台型业务，而把更多垂直领域的上层业务交给合作伙伴。相信腾讯云与灵雀云的合作，对共同推进云端生态在行业解决方案、技术、产品等方面的快速完善，会产生很大的积极推动作用。”

  

对于腾讯云的战略投资，左玥表示。“未来，灵雀云希望与腾讯云开展更为深入的合作，推动容器技术在更多行业领域中的应用，为企业用户提供基于多种基础设施的应用集成、交付、运维的一体化PaaS解决方案，赋能企业IT，助力企业数字化转型。”

  

> **拓展多行业场景加速PaaS产品落地**

  

灵雀云目前已帮助金融、运营商、制造、能源、航空、汽车等领域的诸多中国五百强企业，实现了基础设施云化、应用架构现代化和开发流程敏捷化。

  

金融方面，灵雀云在银行、证券和保险领域都有成熟的PaaS产品和解决方案落地，使用DevOps平台规范化开发、部署和管理多方应用，获得了数家股份制银行和排名领先的证券公司的高度赞誉；在传统企业领域，灵雀云也帮助多家汽车和制造企业建设基于容器的PaaS平台，打造IoT+大数据支撑平台，形成车联网和工业互联网整体解决方案，最终帮助客户实现智能产业升级。

  

未来，灵雀云将携手更多的合作伙伴，为企业数字化转型提供更为完善的解决方案和更加优质的全栈服务。
