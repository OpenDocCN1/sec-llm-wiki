维护与支持高级经理（1 人）


【工作职责】

1. 搭建和管理系统运维，应用运维和客户服务支持团队；

2. 负责与开发团队对接；

3. 保证对内对外服务的 SLA；

4. 建设 TITL/ITSM/devops 体系；

5. 确保开发，测试和生产环境的稳定运行；

6. 确保内部 IT 环境的稳定。


【招聘要求】

1. 管理过 20 人以上的运维团队，善于客户和跨部门沟通和协调；

2. 熟悉 ITIL/ITSM 标准和流程并有实际实施经验；

3. 熟悉 DevOps 流程并有实际实施经验，获得 DevOpsMaster 认证优先考虑；

4. 熟悉服务器、网络、安全、存储、虚拟机、容器、云管理平台（如openstack)、OS、DB 及常见信息系统的运维（监控，安装部署，调度，配置，备份恢复，系统和网络调优，安全防范，系统管理和集成，问题处理等），熟悉至少两种 PHP，Perl, Python, linux shell, windows BAT/CMD 等脚本语言；

5. 熟悉客户服务中心和 Callcentre 管理流程；

6. 熟悉内部IT服务的管理流程；

7. 211 院校毕业，英语能进行基本的技术类的口头沟通；

8. 年龄 30-40，运维相关经验 8 年以上。


维护与支持高级专员（3 人）


【工作职责】

1. 内外部客户服务对应（2 线或 3 线）；

2. 对私有云平台和应用软件进行运维（安装，打补丁，账号维护，备份，性能监控，问题对应等）；

3. 网路安全保证；

4.与开发团队对接；

5. 内部 IT 服务。


【招聘要求】

1. 熟悉服务器、网络、安全、存储、虚拟机、容器、云管理平台（如 openstack)、OS、DB 及常见信息系统的运维（监控，安装部署，调度，配置，备份恢复，系统和网络调优，安全防范，系统管理和集成，问题处理等），熟悉至少两种 PHP，Perl, Python, linux shell, windows BAT/CMD 等脚本语言；

2. 熟悉 ITIL/ITSM 标准和流程并有实际经验；

3. 熟悉Devops流程并有实际经验；

4. 熟悉内部IT服务并有实际经验；

5. 善于沟通和团队协作；

6. 211 院校毕业，CET-4 以上，CET-6 优先；

7. 年龄 25-30，运维相关经验 3 年以上。
