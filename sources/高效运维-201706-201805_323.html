资深运维工程师（若干）


【工作职责】


1.

支持业务上线、架构设计部署,业务系统运维；

2.

负责大型故障处理，分析定位原因,并解决；

3.

分析系统瓶颈,容量评估,完成扩容、架构改造等工程；

4.

参与架构设计、架构优化、容灾优化、性能优化等项目；

5.

负责生产环境自动化工具编写,提高运维效率和质量。


【招聘条件】


1.

深入理解 Linux 系统以及优化，能够针对业务场景定制 Linux 参数设置，熟练使用 grep、awk、sed 等系统工具，擅长 (shell/perl/python) 脚本语言编程，实现自动化运维，提高运维效率与质量；

2.

熟悉主流开源软件 (Nginx/Tomcat/php-fpm/Nodejs) 的配置及调优；

3.

了解运维高容量、大流量、大并发 Web 系统的业务知识以及解决方案；有大、中型网站维护实战经验者优先；

4.

深入理解网站高可用性架构： lvs/Haproxy/F5/Twemproxy，以及 Nosql 相关（Memcache/Redis）等；

5.

对DNS 体系/CDN原理有一定的了解；

6.

对技术文档编写规范有一定了解；

7.

良好的沟通和语言表达能力，逻辑清晰，学习能力强,有自我激励能力，乐于承担工作压力，责任心强；

8.

加分项：在系统优化，大规模集群管理，体系建设，运维开发方面精通其一。


大数据平台资深运维工程师（若干）

等生态组件 ；

向开发人员提供大数据技术支持和计算存储架构咨询；

3.

【招聘条件】


1.

熟悉 HDFS、Spark、Storm、Hive、Presto、HBase、Kafka 等组件运维和开发支持工作；

2.

要求对上述开源软件的实现原理有深刻理解，有源码研究经验或 PATHC 能力的同学优先考虑；

3.

要求掌握 linux shell、Python、Java 等开发语言中的一种或者多种；

4.

有独立思考分析问题的能力，热爱钻研技术，对工作充满激情。

5.

加分项：在系统优化，大规模集群管理，体系建设，运维开发方面精通其一。
