中兴 IT 部招聘

工作地点：深圳市

大数据运维工程师（2名）


【工作职责】


1.

负责公司大数据集群的运维工作（部署/监控/优化/故障处理）；

2.

负责大数据集群的容量规划/扩容/性能优化等；

3.

负责大数据平台的用户管理/权限分配/资源分配；

4.

参与公司业务平台的设计，并给出可执行的运维方案。


【任职资格】


1.

本科或以上学历，计算机或相关专业，至少三年大数据平台及相关组件的运维经验；

2.

熟悉 Linux 操作系统，熟练掌握 Hadoop 各组件（hadoop，yarn，hbase，hive，spark，kafka等）；

3.

熟练掌握至少一门运维语言（shell/python）；

4.

熟悉常见的开发语言（如Java/Go）；

5.

熟练掌握至少一门自动化运维工具（puppet/ansible/saltstack）。

    面议

资深应用运维专家（2名）


【任职资格】


1.

负责应用系统的架构审核，生产环境的重大变更审核；

2.

负责应用重大故障的根源定位、原因分析，并提供解决方案，确保系统快速恢复；

3.

负责组织跨领域应用故障的根源定位、原因分析，并提供解决方案，确保系统快速恢复；

4.

负责给其他工程师提供支持和帮助，促进团队的学习和能力提高；

5.

负责跟踪业内新技术新动态，研究相关应用架构和运维技术，制定运维技术方案；

6.

负责研究和建立运维系统，推动运维系统的规范化、标准化、自动化和智能化；

7.

负责提升应用的性能、稳定性、可靠性、安全性，降低成本。


【任职资格】


1.

本科及以上学历（本科要求5年以上工作经验，研究生3年以上工作经验）；

2.

熟悉 Windows Server、Linu x以及 Unix 等多种操作系统的运维管理，具备丰富的运维自动化脚本编写能力和经验；

3.

精通 Apache、Nginx、Tomcat、JBoss、WebSphere、IIS 之中多种应用服务器的管理、配置和优化；

4.

熟悉 Oracle 或 MySQL 数据库的运维管理、性能分析和调优；

5.

具备主机、存储、网络等方面的基本知识，能够牵头负责跨领域的工作；

6.

具有上进心、责任心、良好的沟通协调能力和团队合作精神，热爱学习、做事积极主动，能承受工作压力；

7.

有应用程序架构设计和开发经验者优先，有大型系统应用运维经验者优先。


【薪资待遇】

资深 MySQL DBA 专家（2名）


【工作职责】


1.

作为 MySQL 数据库专业领域带头人，培养和提升员工的数据库技术能力；

2.

结合工作需要，制订数据库相关的标准和规范，并推动相关标准和规范的落地；

3.

研究、引入和建设先进的数据库自动化运维平台，提升数据库运维效率和质量。


【任职资格】


1.

本科或以上学历，计算机或相关专业，5 年以上 MySQL 数据库运维经验；

2.

精通 MySQL 数据库的基本原理以及高可用、高性能架构规划设计、分析及调优方法，并能进行数据库的高可用部署、性能分析和调优；

3.

精通 SQL 性能分析及优化方法，并能进行复杂 SQL 的调优；

4.

能熟练的进行 MySQL 数据库运维管理操作,并能熟练的解决较严重数据库故障；

5.

精通数据库的各种备份及恢复方法，能进行数据库备份方案的设计，并能进行方案的实施和维护；

6.

具有上进心、责任心、良好的沟通能力和团队合作精神，热爱学习、做事积极主动，能承受工作压力；

7.

获得 OCP 证书优先。

自动化运维专家（2名）


【工作职责】


1.

牵头规划、研究和建设先进的自动化运维平台，提升运维效率和质量；

2.

负责运维人员自动化运维开发能力的培养和提升。


【任职资格】


1.

本科或以上学历，计算机或相关专业，具备开发和运维工作经验；

2.

精通 Java、Python、Shell、Go 等编程语言；

3.

精通业界流行的自动化运维开源软件，如 Zabbix、Open-Faclon、Prometheus、Telegraf、SaltStack 等；

4.

在具体的自动化运维平台建设项目中，担任过牵头人或骨干人员；

5.

具有上进心、责任心、良好的沟通能力和团队合作精神，热爱学习、做事积极主动，能承受工作压力。
