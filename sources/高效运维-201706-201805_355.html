中信合肥异地灾备中心岗位详情

系统管理岗（若干）

【薪资范围】   

    面议

【工作地点】   

    在合肥灾备中心启用前为北京和西安两地办公，最终工作地点为合肥（先北京&西安，后合肥）

【工作职责】

1.  从事灾备中心开放平台基础软硬件相关的变更实施、事件与问题处理；

2.  从事开放平台操作系统、数据库、中间件等的版本和补丁管理，以及开放平台基础软硬件性能优化；

3.  配合开放平台应用系统进行基础软硬件可研、设计、部署、测试、扩容等工作；

4.  从事开放平台基础软硬件技术、产品的研究、跟踪、测试，参与相关产品的选型和技术方案审核；

5.  从事灾备中心总体性能容量管理；

6.  从事灾备中心的管理及灾备系统的建设、维护。

【任职要求】

1.  30周岁以下且为全日制本科及以上学历；

2.  熟悉开放平台技术架构；掌握开放平台运维管理技术；熟悉质量安全管理体系；

3.  精通 AIX、LINUX 操作系统，熟悉数据库或中间件技术；

4.  精通小型机、服务器虚拟化环境管理，了解云计算环境管理；了解运维支撑管理工具；

5.  从事系统或存储运维管理及规划相关工作2年以上；具备银行、金融IT公司工作经验，了解银行业务的技术人员优先；

6.  英语四级或同等水平；

7.  善于学习，具备快速吸收新知识的能力；

8.  有强烈的工作责任心，有较好的沟通能力和创新能力，有良好的团队合作精神，能够承担工作压力。

网络运维管理岗（若干）

【薪资范围】   

    面议

【工作地点】   

     在合肥灾备中心启用前为北京和西安两地办公，最终工作地点为合肥（先北京&西安，后合肥）

【工作职责】

1.  从事灾备中心网络系统的运行维护工作，包括变更实施、事件与问题处理；负责数据中心网络系统的容量管理，承担扩容、升级、优化的实施工作；

2.  从事灾备中心全行网络相关技术方案的审核；

3.  从事网络技术、产品的研究与跟踪，参与网络产品选型与技术方案审核；

4.  从事灾备中心网络的日常监控，负责监控信息的分析挖掘，负责监控策略的调整和优化。

【任职要求】

1.   30周岁以下且为全日制本科及以上学历；

2.   熟练掌握网络相关技术；计算机、网络、信息相关专业；精通某一项核心网络技术，熟悉其他核心网络技术，广泛了解其它相关领域的网络技术；

3.    2年及以上商业银行及其他金融机构、大型企业网络相关技术经验；或者具备大型网络设备提供商及服务商技术工作经验；条件优秀者可适当放宽；

4.    英语四级或同等水平；

5.   善于学习，具备快速吸收新知识的能力；有强烈的工作责任心，有较好的沟通能力和创新能力，有良好的团队合作精神，能够承担工作压力，有主流网络厂商高级认证证书者优先考虑。

应用运维岗（若干）

【薪资范围】   

    面议

【工作地点】   

    在合肥灾备中心启用前为北京和西安两地办公，最终工作地点为合肥（先北京&西安，后合肥）

【工作职责】

1.  从事开放平台应用系统的运行维护工作，包括变更实施、事件与问题处理以及应急管理；

2.  从事所辖开放平台应用系统的应用容量管理、优化的实施工作；

3.  从事开发平台应用系统运行管理工具的设计与建设；

4.  参与开放平台基础软硬件技术规范与技术标准的制定。

【任职要求】

1.   30周岁以下且为全日制本科及以上学历；

2.  开放操作系统应用维护及开发经验；熟练掌握WAS、MQ等中间件的应用；掌握DB2、ORACLE等数据库应用维护经验或开发经验；

3.  具备银行系统运维管理经验，熟悉银行系统的业务处理流程和业务规则；熟悉大型银行系统应用架构、掌握ITIL运维流程；

4.   2年及以上商业银行或其他金融机构信息技术相关工作经验；条件优秀者可适当放宽；

5.  英语四级或同等水平；

6.  优秀的组织协调及创新能力，出色的沟通及问题解决能力，较好的文字表达能力。
