2017年，

混合云在IT界异军突起，成为落地元年。

  

6月28日，Nutanix和谷歌云宣布达成战略合作关系，双方将共同布局混合云市场。此外，9月7日，谷歌云宣布推出全新一代私有云平台，旨在为客户更好的部署混合云环境。

  

7月11日，微软正式发布混合云应用服务Azure Stack。同时，戴尔EMC和微软发布了Dell EMC Cloud for Microsoft Azure Stack的联合产品，加速企业寻求部署和管理混合云战略。

  

8月23日，阿里云与ZStack达成混合云战略合作，提供无缝连接的混合云服务。

  

8月29日，在VMworld 2017大会上，亚马逊AWS与VMware宣布继去年十月的战略合作之后的一项重要成果，VMware Cloud on AWS初步可用，全面部署混合云环境。

  

9月10日，在IBM与VMware达成混合云战略一年之后，IBM和戴尔EMC公开发布，为戴尔EMC的商业客户提供对IBM Cloud的VMware混合云解决方案。

  

至此，Gartner2017年全球IaaS强者象限的云服务商的混合云战略都已尘埃落定。

  

![](../Images/0cf0c745f5ff859295c359d8ee088851.png)

  

巨头们频频的战略动作背后仿佛预示着黎明前夜的沙场风暴，那这是否意味着混合云成未来云计算市场发展趋势?  

  

是的，混合云的春天来了。

  

据中国信息通信研究院调查统计，2016年我国企业采用混合云比例为11.8%。RightScale调查报告显示，采用混合云的企业较2015年上升了9%。IDC预测，未来混合云将占据整个云市场份额的67%。种种迹象表明，混合云正被越来越多的企业所采纳，甚至对于大多数企业而言，混合云似乎成为最优的云战略。

  

过去，混合云的概念比较混乱，最早将物理机+虚拟机的管理称为混合云，后来又陆续把多个私有云的管理、多个公有云的管理、公有云+私有云的管理都称为混合云，直到最近一两年业界对混合云的认知才逐渐趋同。将私有云和公有云之间部件控制面，以及数据面彻底打通的云，才能称之为真正的混合云。

  

那么，对于整个市场而言，混合云的标准形态该如何定义?对于用户而言，标杆案例具备哪些创新架构技术特点及附属价值?

  

为了更好地推进中国云计算产业的蓬勃发展，由中国信息通信研究院指导，云计算开源产业联盟(OSCAR)主办、技术选型类垂直门户盛拓传媒IT168承办主题为“中国混合云标杆案例暨寻找2017中国混合云十大用户”活动。汇聚多家用户案例，本着“公平、公正、公开”的原则，以专区形式展示混合云行业重点案例，并以专家评选、行业用户和云计算产业人员共同参与投票的方式，最终评选出十大优秀案例并进行进一步宣传。
