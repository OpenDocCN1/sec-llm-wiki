每一位开发、测试和运维工程师，都有一位私人管家，他的名字叫做Jenkins。一位面带笑容的小老头（出生于2004年），他就像蝙蝠侠身边的阿尔弗雷德一样，不断给我们提供武器装备，帮助我们实现自动化构建、持续集成、自动化测试、自动化部署、持续交付、DevOps。

活动简介

Jenkins Area Meetup (JAM) 是Jenkins 社区在全球范围内的线下沙龙活动，旨在分享Jenkins 理念与实践经验，促进 Jenkins 用户、爱好者们相互交流和学习。本次沙龙由DevOps时代社区联合Jenkins 爱好者联合发起，希望让中国的 Jenkins 用户与爱好者有机会相互交流和共同成长。

演讲主题

主题一：《大型团队 Jenkins 的构建最佳实践》

主题介绍：

1.  持续集成的组织挑战

2. 大型团队建立好 Jenkins 的几个关键原则

  1. 不要设立“持续集成管理”部门

  2. 集成 LDAP 账号

  3. Pipeline as Code

  4. 一个代码库，一条流水线

  5. 个人级CI 和 团队级CI

  6. 解除流程和架构 双依赖

  7. 部署和发布 解耦

  8. 研发 CI 和 生产 CI

  9. 制品库不是必要的




讲师介绍：顾宇，ThoughtWorks 高级咨询师，9年工作经验。加入ThoughtWorks之前曾经参与中国移动，中国联通省级BOSS系统以及呼叫中心系统的研发、实施和割接。担任过售前，项目经理，维护工程师和开发工程师等职务。拥有丰富的大型系统开发及维护的实战经验。

主题二：《乐视基于Kubernetes 的 Jenkins 构建集群实践》

主题介绍：介绍乐视Android产品的Jenkins构建集群演化过程与实施方案，包括从基于实体机/虚拟机的单点构建环境到基于Kubernetes的容器构建集群，实现构建环境标准化与动态化。

讲师介绍：李华强，Certified Jenkins Engineer，乐视致新SCM组资深DevOps架构师，曾就职于飞维美地、爱立信、北电网络等多家外企，从事配置管理、持续集成等工作。

主题三：《Be A CloudNative DevOps Ninja In Alibaba Cloud 》

主题介绍：本主题分享阿里云CodePipeline的架构设计，在改造Jenkins的过程中遇到的问题，以及如何设计Cloud Native的持续交付流程。

讲师介绍：莫源，阿里云高级研发工程师。在加入阿里巴巴之前，先后在北京天方地圆科技有限公司、微软亚洲研究院任职。现主要负责阿里云容器服务产品的底层服务发现系统、集群管理系统的研发，从事容器的持续交付、持续集成的方案的设计与实现。在云计算、分布式系统、图像识别与虚拟现实方向有多年的开发经验。

主题四：《企业互联网公司基于Jenkins的CI/CD实践》

主题介绍：

  1. 发布流水线建模——Jenkins job template

  2. Jenkins DSL 自动生成实现 Job 自动化配置

  3. 基于Docker的 Jenkins Slave 管理

  4. 基于Jenkins/Gitlab/SonarQube的持续集成实践

  5. 基于Jenkins Folder/Dashboard 管理 Job

  6. 基于Jenkins/Hubot实现：一句话完成打包部署上线
