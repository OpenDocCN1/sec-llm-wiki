运维经理

【工作地点】   

    上海


【岗位职责】

1. 负责拍拍贷运维部全面管理工作；

2. 负责产品稳定性保障，带领团队做好运维应急处理，基础系统建设，监控完善，运维自动化研究等；

3. 制定运维部的发展规划，确保可用率指标的提高；

4. 团队人员培养，确保符合运维部和公司的做事标准和职业规范。



【岗位要求】

1. 具有 5 年以上大规模 Linux 集群运维经验，精通 Linux 操作系统，熟悉 Windows 操作系统；

2. 有技术感觉，关注业界新的技术如云计算，Docker 等；

3. 具备 2 年以上的管理经验；

4. 熟悉各种虚拟化技术，分布式管理、容错、备份，负载均衡等技术；

5. 熟悉 IDC 环境，以及各类常见服务器、网络设备，防火墙。


运维开发工程师

【工作地点】   

    上海


【岗位职责】

1. 负责自动化运维平台的建设；

2. 负责自动化运维技术的研究和推广；

3. 提高运维团队的效率。


【岗位要求】

1. 熟练掌握 Python 等编程语言；

2. 熟练掌握 HTML／CSS／JS 等前端语言；

3. 熟悉常用 Python web 框架如 Django／Flask；

4. 熟悉 Bootstrap，jQuery 等前端框架；

5. 熟悉 Linux 系统，熟悉网络基础知识；

6. 熟悉常用的自动化运维工具、监控工具、持续集成／发布工具等；

7. 具备一定的产品意识；

8. 强烈的责任心与良好的团队合作精神。

资深运维工程师／运维架构师（若干）

【工作地点】   

    上海


【岗位职责】

1. 基础服务日常维护工作，保障业务稳定可靠；

2. 配合业务团队完成业务部署，发生故障需快速定位解决；

3. 各种运维项目实施；

4. 持续改进运维基础架构以适应公司业务发展。


【岗位要求】

1. 本科及以上学历；

2. 熟悉 Linux / Window 系统管理，三年以上互联网行业实际工作经验；

3. 高度责任心，积极主动的工作态度。 具备良好的团体精神，能快速融入团队，抗压性强；

4. 熟悉 Shell / Python / Perl / PowerShell  等其中一种语言；

5. 熟悉操作系统以及常用服务的性能优化，及故障排除能力；

6. 熟悉 Nginx / MySQL / Hadoop/ ELK 等应用；

7. 熟悉 Zabbix / Cacti / Nagios 等任何一种或多种开源监控工具；

8. 最少具有独立维护 100 台以上 Linux 服务器的能力；

9. 熟悉 LB / LVS 产品者更佳；

10. 熟悉 Puppet / SaltStack / Ansible 等自动化运维工具优先考虑；

11. 熟悉 Hyper-V / KVM / OpenStack 等虚拟化技术优先考虑；

12. 有 C / Python / PHP 等编程语言能力者优先考虑。
