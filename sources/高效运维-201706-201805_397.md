**运维经理**

**【工作地点】  ** 

    上海

  

**【岗位职责】**

1. 负责拍拍贷运维部全面管理工作；

2. 负责产品稳定性保障，带领团队做好运维应急处理，基础系统建设，监控完善，运维自动化研究等；

3. 制定运维部的发展规划，确保可用率指标的提高；

4. 团队人员培养，确保符合运维部和公司的做事标准和职业规范。

  

  

**【岗位要求】**

1. 具有 5 年以上大规模 Linux 集群运维经验，精通 Linux 操作系统，熟悉 Windows 操作系统；

2. 有技术感觉，关注业界新的技术如云计算，Docker 等；

3. 具备 2 年以上的管理经验；

4. 熟悉各种虚拟化技术，分布式管理、容错、备份，负载均衡等技术；

5. 熟悉 IDC 环境，以及各类常见服务器、网络设备，防火墙。

**资深运维工程师／**运维架构师（若干）****

**【工作地点】  **

**【岗位职责】**

3. 各种运维项目实施；

4. 持续改进运维基础架构以适应公司业务发展。

  

**【岗位要求】**

1. 本科及以上学历；

2. 熟悉 Linux / Window 系统管理，三年以上互联网行业实际工作经验；

6. 熟悉 Nginx / MySQL / Hadoop/ ELK 等应用；

7. 熟悉 Zabbix / Cacti / Nagios 等任何一种或多种开源监控工具；

9. 熟悉 LB / LVS 产品者更佳；

11. 熟悉 Hyper-V / KVM / OpenStack 等虚拟化技术优先考虑；

12. 有 C / Python / PHP 等编程语言能力者优先考虑。
