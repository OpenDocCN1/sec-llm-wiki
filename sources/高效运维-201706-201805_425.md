阿里巴巴移动事业群以移动互联网领军企业 UC 优视为基础，整合阿里巴巴集团相关优势资源组建。

  

旗下拥有 UC浏览器、神马搜索、九游、阿里文学、PP 助手等多个行业领先的移动互联网产品及平台，为用户提供多领域、全方位的移动互联网服务。

  

阿里移动事业群专注移动互联网业务创新，致力于打造简单，可信赖的移动互联网信息服务平台，用技术和数据创造变量。

  

高级运维工程师

**【薪资待遇】  ** 

    面议

  

**【工作职责】**

1.保障平台稳定、安全的运行，做到7\*24快速响应；

2.负责平台测试环境系统维护、上线、环境配置服务搭建、监控及应急响应等； 

3.负责线上系统层面稳定性保障，系统监控、应用监控、日志监控、内核升级、安全事件响应处理等；

4. 从技术和服务层面具体分析业务，提出优化改进方案并推进实施；

5. 从质量、效率、成本、安全等维度不断推进业务运营的优化 。

  

**【任职要求】**

1. 3 年以上的 linux 系统运维经验，至少 1 年以上大型互联网业务运维经验；

2. 精通 shell 和 python (php 亦可) ；

3. 精通 LNMP 架构，熟悉 lvs、nginx、redis、memcached；

4. 具备故障分析和处理能力，能熟练使用相关分析命令和工具，如 tcpdump、strace、netstat、perf、dstat、iostat、top、sar、vmstat、dig 等；

5.有 Django 开发经验优先,ELK 经验优先；

6.有虚拟化，容器化运维经验优先；有 CDN、IDC 运维经验优先；

7. 责任心强，积极主动，较强团队意识，较强的安全风险意识和跟进能力。
