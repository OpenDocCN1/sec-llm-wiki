关于我们

在追求极致的理念下，我们不仅在让 ColorOS 越来越稳定、流畅和更加省电，也在努力让国内上亿的用户群和海外正日益膨胀的多国用户群体有一个更可靠、更流畅、也更智能的网络服务。

OPPO 数据中心在这其中承担了平台运维能力和大数据平台两个基础职能。




成员从 70 后到 90 后都有，主要来自知名互联网公司比如 BAT、UC、迅雷等。

我们的服务器、数据量的增速丝毫不慢于业务的增长量，甚至还要走在前面。

比起已然整套体系成熟的大公司，我们在工具化、系统化上还有很多能充分发挥能力的地方，服务好亿级用户我们还需要持续进步。

公司乐意在核心关键问题上付出苦功夫大力气，不用担心总需要做些杂七杂八没价值的东西。

上下班不打卡，我们更关心你的产出价值和个人成长。

基础架构师

【薪资待遇】

【岗位职责】

  1. 负责服务器、存储、IDC 资源规划，环境部署，为应用运维及开发团队提供支持，保证项目上线进度；

  2. 负责服务器、存储相关资源的管理和优化，保证业务的稳定性和连续性；

  3. 负责桌面云项目的优化及维护工作；

  4. 负责私有云项目的规划和导入工作。


【岗位要求】

  1. 本科或以上学历，计算机或相关专业 3 年或以上工作经验；

  2. 熟悉 Linux 系统，包括操作系统原理、常用系统命令，系统服务。如Apache、 Nginx、MySQL、Memcached 和 Redis 等；

  3. 熟悉虚拟化、私有云技术，包括 VMware 虚拟化、桌面云等；

  4. 了解各大厂商的硬件设备（包括但不限于：服务器、存储、一体机）；

  5. 具备故障分析和处理能力，能熟练使用相关命令和工具， 如 strace、netstat、perf、trace、dstat、iostat、top、sar 和 dig 等；

  6. 有一定的网络基础， 理解 TCP/IP、HTTP、FTP、 NTP、 SNMP、VRRP 等常用协议。 熟悉相关工具的使用和配置，如 tcpdump、 iptables 等。
