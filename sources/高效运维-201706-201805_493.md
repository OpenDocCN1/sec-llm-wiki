【深圳市大疆创新科技有限公司】

**【公司介绍】**

深圳市大疆创新科技有限公司总部位于中国深圳，以“The Future of Possible（未来无所不能）”为主旨理念，致力于成为全球飞行影像系统先驱。2006 年创立至今，公司目前全球员工人数超过8000 人，除中国大陆地区外，在美国、德国、荷兰、日本及香港设有分支机构，客户遍布全球百余个国家和地区。

技术创新是大疆的发展命脉。以梦想为源动力，凭借精湛的技术力量和高端人才储备，大疆从商用自主飞行控制系统起步，之后又陆续推出了飞行控制系统、云台系统、多旋翼飞行器、小型多旋翼一体机等产品系列，目前占据全球70% 的市场份额，在全球同行业中独占鳌头，重新定义“中国制造”的内涵。目前大疆的产品也被广泛应用于影视、摄影、农业、地产、新闻、救援、能源、旅游、考古、野生动物保护等领域。

大疆推崇“激极尽志、求真品诚”的价值观，力图以梦想为动力，开辟创新、拼搏、极致的创作净土，吸引和影响更多志同道合的人。我们愿与全世界范围内产业思路清晰、视野超前的同行紧密合作，形成强大的大疆文化模式及商业圈，创造和推广更多、更极致的技术和产品。

目前大疆开放多个运维相关岗位，期待真诚，正直而满腹才华的技术大牛加入我们！

**职位**

**运维工程师**

**【职位描述】**  

1.  负责互联网事业部应用系统的部署、发布、监控、维护及性能优化
    
2.  及时响应及处理故障，并输入文档报告，保障线上系统稳定运行
    
3.  配合需求部门，快速交付运维基础资源及数据资源
    
4.  参与系统架构设计、改进、优化，并实施技术方案
    
5.  参与团队管理工作  
    

  

**【职****位要求】**

1.  本科以上学历，计算机相关专业，一年以上运维经验
    
2.  Linux资深玩家，熟悉常用网络协议
    
3.  熟练掌握Nginx、Mysql、Redis、LVS等软件的原理及优化
    
4.  熟练使用运维监控及自动化工具：Zabbix、Newrelic、Ansible、Saltstack等
    
5.  能开发出脚本或软件系统代替重复手工性工作，并熟练使用awk、sed、find、tcpdump及系统监控命令
    
6.  强烈的安全运维意识，具备基本的安全防御经验
    
7.  高度责任感及团队精神、良好的学习能力及较强的问题分析与解决能力
    
8.  熟悉docker、kubernetes等容器技术，熟悉公有云AWS、阿里云，具有大型网站运维经验的优先
    

  

  

**运维开发工程师**

**【职位描述】**  

1.  责运维平台/工具的设计、开发、优化并持续迭代，提升运维效率
    
2.  负责基础服务组件（存储、负载均衡、数据库、Docker、私有云、CMDB等）平台的开发工作，并保障高可用
    
3.  参与系统架构设计、改进、优化，并实施技术方案
    
      
    

**【职位要求】**  

1.  本科以上学历，计算机相关专业，2年以上运维开发经验
    
2.  熟悉linux操作系统，熟悉TCP/IP、HTTP协议
    
3.  精通Python, 精通web框架开发，熟悉前端JS/css框架
    
4.  熟悉版本控制工具、构建工具以及常用的自动化运维工具
    
5.  熟悉nginx、mysql、redis等基础组建，并熟悉常用的高可用方案
    
6.  高度责任感及团队精神、良好的学习能力及较强的问题分析与解决能力
    
7.  熟悉docker、kubernetes等容器技术，熟悉公有云AWS、阿里云的优先
    

  
  

 

**网络架构师**

**【职位描述】**  

1.  在现有网络架构基础上优化，确保网络的高可用性，高性能及高扩展性
    
2.  建立网络与业务有效的常态沟通机制
    
3.  了解业务规划，以此为前提进行基础设施技术路线及资源规划
    
4.  带领团队制定网络解决方案，协调并支撑解决方案落地
    
5.  参与团队管理工作
    

**【职位要求】**  

1.  网络通讯、计算机相关专业本科及以上学历，3-7年工作经验
    
2.  熟悉主流网络及安全厂商的产品及技术架构，精通F5、路由、交换、安全、防火墙、负载均衡等技术
    
3.  熟悉掌握各种网络协议，网络架构等网络技术
    
4.  英语能力良好，能独立与国外业务沟通
    
5.  通过高级网络认证（CCIE或HCIE）者优先
    

**服务管理工程师**

**【职位描述】**

1.  负责IT一二线服务台的日常工作管理
    
2.  负责用户反馈、投诉跟进、解决，并进行流程优化及质量管理
    
3.  负责IT需求接口，与业务方进行需求沟通并给出初步解决方案
    
4.  负责对公司VIP用户的IT需求或故障进行支持
    
5.  管理IT变更流程，配合变更请求工作
    

  

**【职位要求】**

1.  计算机相关专业专科及以上学历，3年以上IT工作经验
    
2.  熟悉IT服务管理在行业中的具体实践应用，具备丰富的IT服务管理项目的实施经验
    
3.  熟悉ITSM理念、ITIL标准，通过ITIL认证者优先
    
4.  具备良好的沟通能力
    
5.  具备一定英语沟通能力
