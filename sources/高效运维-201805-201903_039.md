**招商银行总行信息部 **

**DevOps 推广负责人**

> 在招行服务15年，伴随着招行信息技术部从200多人发展到现在4000多人的规模，获得了PMP、CSM、CSPO认证。从推动配置管理工具 firefly 起步，全程参与CMMI 三级体系的建立和认证，牵头招行CC、CQ、BuildForge、RTC 和 Git 等全平台配置管理工具的落地实施。2015年开始牵头研究和推进DevOps持续交付实践落地，更好地支撑招行的精益化转型。2018年参加 DevOps 国际峰会 2018 深圳站主题演讲，获评金牌讲师。

**研发工程师**

**议题简介**

> 企业级持续交付平台的建设，面临诸多现实困难和痛点。要适配组织IT发展现状及技术背景，既要勇于创新支持IT技术架构升级，也要稳健兼容各类复杂场景。2017年招商银行总行IT部门打造了基于K8S的持续交付流水线平台，打通研发工具链，利用容器技术实现了资源的动态化和标准化，在此基础之上，也实现了非容器化场景（如.NET Framework 技术栈）的支持。本次演讲主要分享招行在落地 DevOps 流水线平台的一些思考和实践，希望与大家交流。

**演讲提纲**  

1.  流水线平台建设背景
    
2.  基于 K8S 的 Jenkins 动态化方案
    
3.  非容器场景支持方案
    
4.  未来计划
