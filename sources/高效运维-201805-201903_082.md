# 运维成长日记：我是如何走上IT运维这条不归路的

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651675664&idx=1&sn=3a36cadb8089ec4bda35435b0384eac6&chksm=8bcb9fb9bcbc16af79c4a808df042ef32b60cd165f0ac067f3fe8112ecafb51f8e649df33832&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651675664&idx=1&sn=3a36cadb8089ec4bda35435b0384eac6&chksm=8bcb9fb9bcbc16af79c4a808df042ef32b60cd165f0ac067f3fe8112ecafb51f8e649df33832&scene=27#wechat_redirect)

出来工作好些年了，从最初的小白，慢慢变成了老练的守城狮。

大学的时候，学的是电子信息工程专业，有一门选修课叫做“Linux基础教程”，当时是第一次接触Linux这块，记得当时花了好几天才装好一个Linux系统，学的东西也如课程名字一样，都是基础的命令，什么创建目录啊（mkdir），什么拷贝文件啊（cp），什么去到哪个路径啊（cd）等等，第一次发现，原来可以有个系统叫Linux，是可以通过字符界面去操控系统，感觉这样挺有乐趣的。

有些人觉得，图形界面操作系统不是更好用吗，对于这个问题，我觉得是因人而异，就像你买个车，有人觉得手动好，因为手动的有操控感，省油；有人觉得自动好，因为省事简单，操作就跟骑个电动车差不多。

到了大四，越感迷茫，我不知道我毕业了之后可以做什么，能做什么。所以我做出了一个很大的决定，我和几个同学背起行囊就来到了广州。来到了大城市，越发觉得压力倍增，没有一技之长如何傍身？而恰恰是这个时候，我去面试了一间电商公司，他们刚好需要初级的能够打杂的运维，而我刚好需要这样的一个机会，于是就顺其自然进入了这间电商公司。那个时候试用期的工资是3500，转正4000。在广州吃一顿饭至少要10块钱起，租房城中村单间也要4000左右，这点工资除了维持正常的生活，我都不敢轻易约同学出来吃饭，回想还是挺窘迫的。

在我的第一间公司，**我搬过电脑，剪过网线，帮同事处理网络问题，管过交换机，配过路由器，管过服务器，部署过应用，执行过更新**，在前期我就是一个网管+打杂+初级运维的化身，那个时候因为怕过不了试用期，所以很多东西都会很努力去学，去请教，但是我觉得，如果你要请教你的上级，请你先认真思考解决办法，如果实在想不到办法，再去请教，否则你可能会给人留下一个不善于思考的标签。一两年过后，因为部门老大离职，我升为运维主管，这个是压力也是动力。部门老大离职4个月后，完成了公司的B2B可交易大项目后，我提出了离职。至此，我的第一份工作到此为止。

第二份工作，我在一个打车和金融公司担任运维经理。来到这里的第一天我就不想干了，运维的东西乱七八糟，没有运维团队，服务器是由网管管理的。内网测试开发服务器均是PC机，**生产服务器上只要能堆的东西都会堆在物理机上，数据库端口3306直接暴露公网，而且连个最起码的监控系统也没有。**来之前没想到会如此之乱，但是最后我和我另一个伙伴一起熬过来了，成立了运维部门，搭起了监控系统，将物理机环境逐渐改造成了私有云环境。前前后后花了将近1年时间，才把运维相关的工作以及环境梳理规范。现在回想，其实我当初留了下来，经历这些事，也会有所成长。人嘛，总要学会承担责任和接受压力。

在这些年的工作中，我自己也会时常总结，但是简单来说，其实就是：

*   第一，在你没有能力的时候，你别去选择你该做什么工作内容，即使是打杂，只要是能学到东西，那就努力给心思去做；
    
*   第二，在你稍微有能力的时候，你要看下除了会用（比如mysql）技术以外，你了解mysql的工作原理吗，不要只停留在会用的阶段，要多去思考为什么能这么做，原理是什么，还有你要多学习新技术，技术不前，居安不思危只会是淘汰的宿命；
    
*   第三，在你有能力的时候，要多审视自己，这个环境是否是你想要的，是否能满足你的发展，到了现在这个时候，我觉得一个公司值得我留下的最大原因不是因为公司给我开了多少钱的薪水，而是我在这里能不能提现我的价值，我的团队能不能一起往更好的方向去发展去提升自己。
    

开这个头条号，其实就是想给大家说说一些运维的经验，给一些想入运维行业，或者刚入运维行业的人一些善意的提醒，希望能够帮助大家。
