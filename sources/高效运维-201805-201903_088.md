# 阿里老专家：超大型运维平台的面向终态设计 | 活动通知

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651675630&idx=2&sn=9053e8f2de2c892cba6b5279dce3bab1&chksm=8bcb9847bcbc115145655ccbf9d12e440cb204d2ee7901655cb359190bcfa281ae39262f2e87&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651675630&idx=2&sn=9053e8f2de2c892cba6b5279dce3bab1&chksm=8bcb9847bcbc115145655ccbf9d12e440cb204d2ee7901655cb359190bcfa281ae39262f2e87&scene=27#wechat_redirect)

最近十年，互联网的发展速度越来越快，线上承载的数据流量呈几何级数的增长。这种增长直接刺激了基础设施的迭代优化，由于供应链持续紧张，新老架构不得不同时对外提供计算能力，同时不同业务方对运维目的有着不同的诉求，有的重视稳定性，有的重视成本。

  

![](../Images/0417bd17050ae59f0e300282a774d9fe.png)

  

这导致了可以操作的元素与操作组合越来越多。比如：做应用迁移，既可以切流-搬迁-引流，也可以容器扩容-缩容，也可以直接做 Serverless。条条大道通罗马，没有哪条一定对，一定错。

  

可问题在于，在某种情况下，可能适合操作路径 A，而在另一种情况下，可能适合路径 B。主观判断的不确定性随之放大，这给我们运维平台的稳定性保障带来了极大的挑战，同时也让我们认识到，面向过程与操作的的运维模式将难以为续。

  

面对这样的处境，业界巨头其实早已开始了这方面的探索。典型系统有微软的 AutoPilot、Google 的 brog（K8S），阿里的 Apsara Infrastructure。这些系统的背后，都具有一个共同的基本原理 - 面向终态。

  

虽然一百个人会有一百种走法，但每个人要到的目的地都是罗马。如果我们直接告诉系统，最后想要的结果，而让系统自主决定操作方式的话，就能很好规避操作不确定性的问题。这意味着用户不必再心惊胆战的规划执行路径，而是简单告诉系统，你的最终目的。而至于系统怎么规划执行路径，则根据线上实时状况以及知识库来决定，动态调整，使命必达。

  

架构背后的逻辑，非常简单。告诉系统最终结果，系统自己做，边做边调整。但真正实现起来，复杂程度远远超出了之前的预估。Normandy 作为阿里的应用运维平台，是阿里集团最大的运维入口。往上承载了天猫、淘宝、等诸多 BU 的业务，这引入了业务的多样化，需求的多样化。往下，Normandy 对接多种基础设施，包括阿里云、物理机、Sigma/K8S 等诸多设施，这意味着基础架构的多样化。

  

运维形态上，应用运维适合无状态，但中间件的运维，又是有状态。诸多问题一股脑的摆在了我们的面前。如何用一套架构，以一种抽象形式一揽子解决这些问题？同时分享这些问题背后，我们对运维的思考，这是本话题会交付的主要内容。

**乔斌**

**阿里巴巴技术专家**

  

> 个人简介：阿里巴巴技术专家，百年技术讲师，应用运维平台新一代架构的主要设计者。十年以上海内外工作经历，曾为多家财富500强企业提供服务。同时他还是一位社区活跃者，曾在 Global Scrum Gathering，Regional ScrumGathering，Agile Tour 上发表主题演讲。

  

![](../Images/57ea78ed5afeb0ea322d91ba66443a5d.png)

GOPS 全球运维大会由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办，七里台互联网100人论坛（SIF100）协办，指导单位为工信部信通院数据中心联盟（DCA）。全球运维大会是国内第一个运维行业大会，面向互联网及传统行业、广大运维技术人员，传播先进技术思想和理念，分享业内最佳实践。

迄今为止，GOPS 已经举行了十一次，大会参会嘉宾累计突破4万人次，国内每一站均为本地区最大规模的高端运维盛会，满意度和推荐度高达95%以上。

**第十二届 GOPS 全球运维大会将于2019年4月12日-13日在深圳召开。**大会为期2天，侧重方向是 AIOps、运维自动化和 DevOps。目前已经有全国各地大公司组团前来参加。

  

此外还有一些特色专场如：金牌运维专场、大数据运维专场、金融案例、基础架构、运维管理及容器与微服务等专场。

  

主要面向运维行业的中高端技术人员。目的在于为了帮助运维人员系统学习了解相关知识体系，让创新技术推动社会进步。你将会看到国内外知名企业的相关案例，也能与国内顶尖的技术专家探讨技术实践，使企业可以根据最佳实践确定自己的选型方案，并提前预估相关的风险和收益，实现技术落地。
