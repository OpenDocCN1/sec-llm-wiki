《研发运营一体化（DevOps）成熟度模型》（也就是我们经常说的 “DevOps 标准”）又有新进展啦！


2018年最后一件大事，在百度大厦，中国信息通信研究院旗下OSCAR联盟给中国工程效率的先导者——百度，完成 DevOps 标准工作组成员单位的正式授牌。

在此感谢百度工程效率部负责人李涛先生、百度集团标准负责人蒋晓琳女士等的大力支持。



从左至右：百度工程效率专家、DevOps 标准核心编写专家@雷涛，百度集团标准负责人@蒋晓琳女士，百度工程效率部@金锐，OSCAR联盟 DevOps 标准工作组组长@牛晓玲女士，OSCAR联盟 DevOps 标准工作组联合组长，高效运维社区发起人 @萧田国。


这也是继2018年11月2日，招商银行正式加入 DevOps 标准工作组之后的又一重要事件。


百度将继续发挥其在工程效率、DevOps、工具链以及智能研发等方面的极具前瞻性和深度实践的经验，将其和 DevOps 标准体系更多融合，让广大企业更多受益。


百度作为全球领先的科技公司，一直以来都十分重视其自身的 IT 效能。在前不久的第六届百度技术开放日上，百度更是首次发布其“软件工程能力白皮书（软件工程标准1.0）”。

百度在《研发运营一体化（DevOps）成熟度模型》（DevOps 标准）的编写制定工作中贡献卓越。百度工程效率专家雷涛担任《研发运营一体化（DevOps）成熟度模型》（DevOps 标准）组织结构部分编写小组组长、持续交付部分核心编写专家。


雷涛

DevOps 标准核心编写专家


关于《研发运营一体化（DevOps）成熟度模型》（DevOps 标准）的一点介绍：


全球首个 DevOps 标准，即《研发运营一体化（DevOps）能力成熟度模型》，由工信部直属单位中国信息通信研究院牵头，云计算开源产业联盟、北京华佑科技有限公司（高效运维社区和DevOps时代社区）联合发起，携手国内互联网、电信、金融等行业领先企业百余位顶级专家共同编制。


目前，DevOps 标准已在联合国直属标准化组织ITU-T、中国工信部、中国通信标准化协会正式立项（立项行标号为：2018-1753T-YD等）。



《研发运营一体化（DevOps）能力成熟度模型》（即 DevOps标准）覆盖端到端软件交付生命周期全流程，包含了总体架构、敏捷开发管理过程、持续交付过程、技术运营过程、应用设计、安全风险管理、评估方法、系统和工具等8个部分。


以应用为核心，将应用的需求、开发、测试、部署和运营统一起来，基于整个组织的协作和应用架构的优化，实现敏捷开发、持续交付和技术运营的无缝集成。



中国银行、浙江移动、腾讯、招商银行、广东移动和北京移动等已先后通过 DevOps 标准，其 DevOps 持续交付流水线平台及相关能力被认定为国内领先或顶级水平。


目前全国股份制银行的 Top 10、证券行业等头部也在纷纷参加下一批 DevOps 标准评测，以提升或证明其 DevOps 能力。
