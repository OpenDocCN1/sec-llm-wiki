# 谁是运维年度领军人物？2018 GOLF 金牌运维领导力论坛精彩实录（附PPT）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651675204&idx=1&sn=36814b7a1c15ed0c85e2f1cb10776bfe&chksm=8bcb99edbcbc10fbb9baa51ce4d5a17d8fd852f3c3b066abf1c65a2eadff4d3a466737735c57&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651675204&idx=1&sn=36814b7a1c15ed0c85e2f1cb10776bfe&chksm=8bcb99edbcbc10fbb9baa51ce4d5a17d8fd852f3c3b066abf1c65a2eadff4d3a466737735c57&scene=27#wechat_redirect)

是的！为期一天的运维行业年度最重要的顶级盛会圆满结束了。

12月14日，由中国信息通信研究院、云计算标准和推进委员会主办，云计算开源产业联盟、高效运维社区、DevOps 时代协办的 2018 GOLF 金牌运维领导力论坛成功在北京召开。为凝聚行业共识，促进行业发展，信通院领导、行业一线大咖、学术界重量级嘉宾齐聚一堂，与您分享运维行业年度精彩。  

既然是运维行业年度最重要的顶级盛会，本次论坛颁出了哪些重量级奖项？有哪些年度风云人物和团队，又有哪些值得期待的明星产品和优秀产品？

> 让我们拭目以待~

首先，中国信息通信研究院云计算与大数据研究所张雪丽副所长为论坛致辞。张副所长对 2018 GOLF 金牌运维领导力论坛成功召开表示祝贺，并对行业同仁的支持和参与表示了衷心感谢。

![](../Images/dc370f6a1658c72cfff398703efb1518.png)

▲ 信通院云大所张雪丽副所长在金牌运维领导力论坛上致辞

随后，是本次 GOLF 金牌运维领导力论坛的重要环节——颁证环节。首先颁发的是 “可信云金牌运维专项评估”。信通院云大所张雪丽副所长亲自为获评单位颁发证书，获得此殊荣分别是是网宿科技、紫光云、浪潮云三家单位。

![](../Images/60d1a9b0a899e7fc65c694c40914e809.png)

▲ 获颁证书的三家单位与张雪丽副所长现场合影

随后颁发的首个奖项是“运维行业 2018 年度风云人物”（此处应该有掌声👏👏），获得此殊荣的分别是余何（顺丰科技数据中心总监）、陈亚殊（平安科技集团运营管理部总经理）、徐奇琛（京东商城前台技术服务负责人）三位行业大咖。

![](../Images/352821136148e8103f4313d396db3c95.png)

▲  运维行业 2018 年度风云人物 颁奖现场

获得“运维行业 2018年度技术专家”殊荣的分别是饶琛琳（日志易产品总监）、毛茂德（虎牙基础保障部总经理）、范伦挺（阿里巴巴高级运维专家）、郭宏泽（华图教育集团技术总监）、孙杰（中油瑞飞资深系统架构师）、Steve Mushero（上海云敞 CTO）6位专家。

![](../Images/9e9258d96efdfac0c7b1e712707a20f1.png)  

▲  运维行业 2018 年度技术专家 颁奖现场

接下来是“运维行业年度风云团队”奖项的颁发，由张雪丽副所长和信通院云计算与大数据研究所云计算部栗蔚副主任（主持工作）联合颁发，获得此殊荣的分别是广东移动网管支撑团队、民生银行应用运维团队、北京燃气应用运维团队、移动云自动化运维团队、中移杭研持续交付运维团队、中国电信云计算分公司运行维护部、数梦工场专有云运维二线团队、联通 CCTO 云服务团队，让我们在此表示祝贺。

![](../Images/9a89faad96d63dbd9643c93f5b0bd0e0.png)

▲ 运维行业年度风云团队 颁奖现场

接下来颁发的是“运维行业 2018 年度极具影响力产品或企业”，获得此殊荣的是华为云 DevCloud、优诺科技 Tarsier、安徽继远软件数据库深度运维工具、尚航科技融合云平台、博睿数据 Bonree Server、基调网络（听云）智能业务运维平台和唯一网络。

![](../Images/57d89ebec3975fda1b636b1522cd0bcc.png)  

▲ 运维行业 2018 年度极具影响力产品或企业 颁奖现场

接下来颁发的奖项是“运维行业 2018 年度明星产品”，获得此殊荣的是擎创科技“夏洛克智能运维大数据分析系统”、锐捷网络“数据中心25G接入交换机”、数智慧 “AIOps 智能运维平台”、京东云“京东云翼”、灵雀云 Alauda Cloud Enterprise、无锡华云数据 CloudUltra、同方有云 UOS 私有云平台、讯达云“Arbiter 运维管理平台”、中睿天下“睿眼攻击溯源系统&网络安全态势感知监测平台”。

![](../Images/bb86571ff7e99621f68841c0993ef4bb.png)

▲ 运维行业 2018 年度明星产品 颁奖现场

倒数第二个奖项，“运维行业 2018 年度优秀产品”。获得此殊荣的是ONES “ONES 研发管理管理工具”、JFrog 杰蛙 “JFrogArtifactory 全语言软件制品仓库”、云智慧 “智能业务运维平台（DOCP）”、睿至大数据 “AIOps 智能运维平台”、优维科技 EasyOps、云杉网络 DeepFlow、LinkedSee灵犀 Linked AIOps智能根因分析产品、睿云智合 WiseCloud企业级容器PaaS 平台。

![](../Images/e3d9dd770a1c2fc86822dfd1a270eec7.png)  

▲ 运维行业 2018 年度优秀产品

最后颁发的是“运维行业 2018 年度优秀项目”，获得此殊荣的是民生银行信用卡 机房搬迁项目、讯达云 Nexus 项目、浪潮云 ICP 平台项目。获得“运维行业 2018 年度新锐产品”殊荣的是华青融天 EZAccur——态势感知和用户行为风险管理平台、北京升鑫网络青藤主机自适应安全平台V3.0 。

![](../Images/a3df0d2bf204b275c54c24d87016ecb8.png)
