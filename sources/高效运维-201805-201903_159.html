DevOps 研发工程师

数量：若干

工作地点：深圳、北京

【岗位职责】

  • 负责持续交付、容器管理、应急响应、效率提升、成本优化、性能调优和速度优化等一系列工作；

  • 负责通过自动化和编码管理系统和环境；

  • 负责从运维角度参与并推动研发、产品改进架构体系；

  • 负责从全局的角度分析优化系统的软硬件架构；


【岗位要求】

  • 具备 Linux 运维及开发经验

  • 深刻理解运维自动化、服务化和运营理念，熟悉 Linux 基本原理、网络和互联网运维技术；

  • 熟悉 DevOps 工具链和生态体系（部署、监控、日志、链路、CMDB等），关注 DevOps 全流程的效率提升和最佳实践；

  • 具有团队协作精神和良好的沟通能力。



高级运维工程师

数量：若干

工作地点：深圳、北京

【岗位职责】

  • 负责运维工作规划；

  • 负责对运行监控、分析、优化等；

  • 负责组织对突发事件、故障等的应急处理；

  • 负责推进运维自动化，提升运维效率；

  • 探索、研究新的互联网、金融科技技术方向，参与新技术的预研与技术改进研究。


【岗位要求】

  • 具备丰富的运维相关工作经验；

  • 熟悉对主流硬件、操作系统、中间件和数据库基础系统软件的运维管理及系统安全管理，对业务连续性保障、运行风险管理及应急处置具备丰富实践经验

  • 主持或全程参与大型机构或成熟商业系统计算机软硬件基础设施及应用系统建设项目；

  • 具有使命感、敬业精神、风险意识以及缜密的思维能力。

符合以下条件者优先：

  • 具备金融和IT符合专业背景或工作背景者。



报名要求

  1. 报名材料包括：《基本信息表》（扫码下载）及个人简历（word格式）；

  2. 报名者应真实、准确、完整填写报名材料，如与事实不符，我院将有权取消其应聘资格；

  3. 每位应聘者可最多报3个岗位，请在《基本信息表》中注明应聘岗位；

  4. 报名邮件请按统一格式设置名称：“应聘+岗位名1+岗位名2+岗位名3+姓名”；

  5. 报名材料请按统一格式设置名称：《基本信息表》名称为“姓名+基本信息”；个人简历名称为“姓名+简历”。


即日起 应聘者可向指定邮箱 szjobs@pbcidm.cn 提交报名材料。
