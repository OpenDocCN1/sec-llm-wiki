# “人不多，事不少” 我们该如何让 IT 运维管理越来越高效？| 活动通知

十几年前，广东移动成立了网络线条的 IT 团队，人不多，事不少、钱多，大部分系统的建设和维护都要靠外包。从那时候起我们就在不断地思考，如何让IT运维管理越来越高效？

  

![](../Images/8873060898905ede3d70526ac2f4ef76.png)

  

我们从经典的管理理论中吸收养分，通过计划、组织、领导、控制四个方面来实现越来越精细的管理，我们从杰克·韦尔奇的无边界管理中寻求灵感，通过众包、搭台，实现IT系统的建用结合，热建热用。最终我们终于找到了IT领域最佳实践的集大成者——DevOps，并一鼓作气，于今年11月通过了 DevOps 能力成熟度评估的3级认证。

  

**精彩回顾：**[以通信网络敏捷转型的名义！广东移动 DevOps 标准认证独家揭秘](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651674475&idx=1&sn=735a6e80818d1914584bd09192ec68f2&chksm=8bcb94c2bcbc1dd479b81b81210e95ae006386d23991aa9c7fd66cff70d90ecf47e21f52a492&scene=21#wechat_redirect)

**左一：**中国移动广东公司 网管支撑业务主任黄倚霄****

  

即便如此，我们发现仍然存在难以绕开的困难，比如：过度依赖外包、议价能力低、被厂家绑定、外包厂家水平参差不齐等等。回顾十几年来的学习成长经历，我们突然惊觉，原来将无边界管理的思想与 DevOps 结合起来，完全可以解决上述的这些困境。简而言之，就是甲方搭舞台、建平台，让合作伙伴在受控的环境下、以众包的模式开展 DevOps 转型。

  

**12月14日、2018 金牌运维领导力峰会上，中国移动广东公司 网管支撑业务主任黄倚霄老师将为你详解：从精细管理走向无边界精益敏捷 |广东移动 O 域 IT 运维管理的成长之路**

前半生没啥好说的，唯一值得骄傲的是，96年因为高考成绩不够高，被调剂到了北大01系，学校又不让转系，于是坚持站着旁听学完了08系的几乎所有专业课。（听说现在01系比08系要难考，感觉自己当年捡了个大便宜，哈哈哈……），后来去了双鸭山读研，终于有了IT的科班出身。 

  

就业十多年也没啥好说的，一直在通信圈呆着，前五年从甲方跳槽到乙方，又回到甲方。从国企到外企、民企，又回到国企。因为都经历过，所以知道甲方的不易，更了解乙方的委屈。

**作为运维行业年度盛典，以及18年年末最重要的运维盛会，《2018 GOLF 金牌运维领导力峰会》即将于12月14日的北京隆重举行。**

  

GOLF金牌运维领导力峰会是运维行业年末最重要的高端邀请制闭门盛会。

  

自2016年起，金牌运维领导力峰会已经举办两届，收到报名企业及厂商累计50多家，收到投票20000余次，颁发出50多个奖项。金牌运维领导力峰会的所有奖项均秉持公平公正，由中国信通院、云计算开源产业联盟和高效运维社区联合颁发，旨在推动中国运维行业发展，在运维圈获得了运维人的高度评价，是运维界一年一度的顶级盛会。

【评选流程】

  

本次评选将由申报征集期、评审期、颁奖大会、展示期四个阶段组成：  
第一阶段：申报与征集期**时间： 2018年11月13日-2018年11月23日**

活动前期，开放运维联盟将在全国范围内发起征集，收到个人及企业申报的候选材料后，将在评选专题栏目中向广大公众传播。同时活动组委会办公室将设立评选信箱、热线电话等方式，通过各地自荐、专家推荐以及公众推荐等各种方式，最广泛地征集候选对象。经过筛选，针对每个奖项给出“提名”名单。

  
第二阶段：评审期**时间：2018年11月24日-2018年12月1日**经过上一阶段的征集，借助开放运维联盟及高效运维社区的优势，进行全网络评选，评选规则详见评选规则。  
第三阶段：颁奖大会**时间：2018年12月14日**  

届时，在2018金牌运维领导力峰会年度运维颁奖盛典现场公布年度评选结果并进行颁奖。

  
第四阶段：展示期**时间：2018年12月15日-2018年12月31日**

会议结束后，将通过“高效运维”、“全球运维大会”等公众号及多家互联网媒体对评选结果进行展示，以获得更好的宣传与推广效果。
