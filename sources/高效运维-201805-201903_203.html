精心挑选的书单

敬请笑纳



《代码的未来》

“站在摩尔定律的尽头，重新理解编程的本质”。


Ruby 之父松本行弘结合当下时代背景和计算机领域的发展情况，对多种编程语言的进行深入分析和展望。不论你现在用的是什么语言或者做的是什么业务的开发，相信这本书都能帮你拓宽视野，带来新的启发。


-- 腾讯高级工程师

织云作业平台负责人：陈镇杭



《The Practice of Programming》

(程序设计实践)


Unix 环境下编程风格与技巧方面的经典书籍， 两位作者都是70年代起就和Unix有紧密关系的研究员：Brian Kernighan 是《C程序设计语言》的合著者之一（与Dennis M.Ritchie合作） (他也是 UNIX 这个名字的命名者)，Rob Pike 是 Plan 9和 Inferno 操作系统的主要结构设计与实现者、UTF-8 的发明者、Go 语言的设计者之一。

-- 腾讯高级工程师

音视频业务运维负责人：郭智文



《机器学习实战》


该书拥有详细的 Python 源码和常见的机器学习算法解释。


《机器学习》


经典的西瓜书，适合机器学习的初学者入门。


  -- 腾讯高级研究员

织云智能运维算法负责人：张戎


《深入理解Linux内核》


从设计思想到代码实现，深入理解 Linux 内核。


《Linux系统编程》 


带你了解应用程序如何与 Linux 内核对话，学习如何充分利用 Linux 系统功能编写优雅高效的应用程序。


《C和指针》


 一本带你入门并深入掌握 C 语言的书


--腾讯高级工程师

Linux技术一哥：王子勇


《linux内核设计与实现 》


适合业务开发的童鞋在平时工作的一些场景中, 对于内核的运行原理有一个简单深刻的理解。

-- 腾讯高级工程师

织云开发一哥：吴万利


《Go 语言程序设计》


Go 开发入门教程，快速上手，实用。


《构建高性能 Web 站点》


码农必看，WEB 优化 & 架构设计深入浅出。


《编程之美》


程序员喜欢的数学题。


-- 腾讯高级工程师

织云自动化开发设计：黄浩宇


《Kubernetes权威指南》 


K8S快速入门。


《SRE:Google运维解密》 


本书汇聚了多年的运维经验，值得大家研读借鉴，运维必看。


《Redis实战》


 能深入浅出理解 Redis。


《RabbitMQ实战》


深入浅出的了解相关知识要点。


《凤凰项目:一个IT运维的传奇故事》


运维必定对此书的故事感同身受，可以启发对自身工作的思考，同时了解DevOps必要性。


创新者系列：《创新者的窘境》《创新者的解答》《创新者的基因》


可作为思考工具，去分析和理解IT行业的很多现象，突破困局。

织云技术负责人：陈芳录


《IT不再重要》


在云计算时代，各行各业都在互联网+，都在谈变革，看下这本书可以掌握很多给传统行业贩卖焦虑的案例和技巧。

-- 腾讯运维总监
