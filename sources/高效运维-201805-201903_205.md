# 官宣！阿里巴巴云效平台成功助力国内首个 DevOps 标准建设！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651674566&idx=2&sn=1e18124222192b8d7f21e2204d434f74&chksm=8bcb946fbcbc1d7950ae844143638ab392b34ff512df46e1f66310b8f87df46d22f8708f7393&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651674566&idx=2&sn=1e18124222192b8d7f21e2204d434f74&chksm=8bcb946fbcbc1d7950ae844143638ab392b34ff512df46e1f66310b8f87df46d22f8708f7393&scene=27#wechat_redirect)

11月2日，由中国信通院云计算开源产业联盟指导、DevOps 时代社区和高效运维社区联合主办的 DevOps 国际峰会·深圳站正式拉开帷幕。

  

会上，信通院云大所运维业务主管、DevOps标准工作组组长牛晓玲权威发布了DevOps 标准的第9部分——系统和工具，并为DevOps标准工作组成员单位进行了授牌。

# **作为全球领先的云计算及人工智能科技公司，阿里云受邀成为 DevOps 标准工作组的成员单位，并主导了此次发布标准第9部分中 7个能力域的编写。**

# **其中5大能力域由阿里一站式研发协同平台——云效平台负责。****除此之外，云效还深度参与了整个标准第9部分的整体结构以及其他各个能力域的评审和讨论。**  

![](../Images/b56971b38339e89d4d84e8878b7067b8.png)

  

源于阿里巴巴在软件领域多年先进的管理理念和工程实践，云效一直以工具化建设DevOps 体系为核心策略，为企业提供从“需求->开发->测试->发布->运维->运营”，覆盖产品研发全生命周期的端到端的协同服务和研发工具支撑。

 

**截至目前，云效已经服务****近****4万****家企业，帮助众安保险、光大银行、天弘基金、南方航空、上汽通用、南京银行、万科、国泰产险等众多企业成功完成DevOps转型。**

   

此次，云效参与 DevOps 标准的制定，旨在将云效的 DevOps 理念及在工具研发和实践中积累的经验贡献出来，指导行业更好地落地 DevOps。

 

# 据悉，当前此 DevOps 标准已在在联合国 ITU-T 成功立项为国际标准。

  

**云效扶持计划**

为更好地服务云效新老用户，扶持创新创业小微企业，企业成员（研发、测试）**小于等于30人**，可在云效官网后台申请云效扶持计划，审核通过后可0元享云效一站式研发套餐。
