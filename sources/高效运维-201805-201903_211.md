# 招商银行 “财富W+系统，招嬴通系统，预约易系统、基金资讯系统”首批通过 DevOps 标准评估

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651674353&idx=3&sn=543f524429836edf31963c38ccd78d94&chksm=8bcb9558bcbc1c4e2ee4c59c579a470692959e292f49193f168298b4a26e20a5a99866bcbe87&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651674353&idx=3&sn=543f524429836edf31963c38ccd78d94&chksm=8bcb9558bcbc1c4e2ee4c59c579a470692959e292f49193f168298b4a26e20a5a99866bcbe87&scene=27#wechat_redirect)

2018年11月2日在深圳召开的 DevOps 国际峰会（DOIS）· 深圳站上，招商银行的 四个项目：财富W+系统，招嬴通系统，预约易系统、基金资讯系统获得由工信部中国信息通信研究院主持颁发的《研发运营一体化（DevOps）能力成熟度模型》（即DevOps标准）评估证书，证书编号为 G01005。

![](../Images/cb23f1ea0a99fb418a6507e9033f812c.png)

为打造招商银行端到端“精益”研发管理体系，招商银行经过近2年建设了DevOps 综合平台，包括基于JIRA的协同工作平台，基于docker+kubernetes的持续交付流水线平台，以及基于Tableau的度量分析平台，实现价值驱动，质量为先，以行业领先的科技能力驱动创新与变更的战略目标。

![](../Images/24aed3e334b45c186d56ef54e28cd292.png)招商银行评估现场合影  

DevOps 标准《研发运营一体化能力成熟度模型》是由云计算开源产业联盟（OSCAR联盟）、高效运维社区和 DevOps 时代社区联合发起，汇聚了国内BATJ等一线互联网企业、通信及金融等行业顶级单位及专家共同编制而成，此标准目前已在中国通信标准化协会（CCSA）立项，并在国际电信联盟（联合国ITU-T）立项成功，成为国际标准。

![](../Images/5e4bb3fc744f682a420c22fdf9e90afe.png)

DevOps 标准在在联合国 ITU-T 正式立项

此次 DevOps 国际峰会（DOIS）· 深圳站由中国信息通信研究院旗下云计算开源产业联盟（OSCAR联盟）指导、DevOps时代社区与高效运维社区联合主办，是国内外首个 DevOps 标准《研发运营一体化能力成熟度模型》的官方指定发布平台。中国信息通信研究院-云计算与大数据研究所云计算部副所长张雪丽女士为通过评估的企业授牌。
