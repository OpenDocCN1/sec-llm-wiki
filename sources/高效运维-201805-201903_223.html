第一批 DevOps 标准评估已经正式完成啦！


2018年7月26日 ，《研发运营一体化（DevOps）能力成熟度模型》 （即DevOps 标准）在联合国 ITU-T（国际电信联盟）正式立项后，国内一批金融、互联网行业的顶级公司参与到了解以及 DevOps 标准评估报名的工作中。

DevOps 标准认证评测由中国信息通信研究院主持，DevOps时代社区和高效运维社区荣誉支持。

目前 DevOps 标准评估组已经完成首批正式报名的参评单位持续交付能力项的评估，他们分别是腾讯IEG、招商银行、广东移动、北京移动。

第一站：腾讯 IEG——深度整合 的 CI/CD 能力

10月15日，DevOps 标准认证评估首站走进腾讯，腾讯互动娱乐事业群（IEG）的基础 PaaS 平台参与了本次评测，基础 PaaS 平台以蓝盾和蓝鲸为蓝本，深度整合了腾讯IEG 从研发、测试、安全到运维的各个高能组件，并拥有华丽的流水线编排等功能。

第三站：广东移动——MSB 微服务管控平台

2018年10月21日（星期日8点30分），DevOps 标准国内正式评估第3站——全球最大单体运营商广东移动，网管自研 DevOps 团队迎来了正式认证评估。10名自研骨干，3名友商代表参评项目成员全部到场迎审。

谁说大象不能跳舞？广东移动本次参评的项目是基于 Istio+ kubernetes + docker 的MSB 微服务管控平台，评测历时前后两个周日，系统演示占 80%。


第四站：北京移动——电子商务系统

10月24日，DevOps 标准国内首批正式评估的收官之站。80% 系统现场演示及问答，北京移动前期资料准备齐全（200多个文件），整体评估紧张有序。同时，北京移动也是拿出了自己的核心业务平台—电子商务系统参与评测 。
