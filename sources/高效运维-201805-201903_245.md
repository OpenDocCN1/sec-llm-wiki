**DevOps 标准**

**企业 DevOps 之路的灯塔**

  

DevOps  大家都知道

  

它把开发、测试和测试绑在一起

  

![](../Images/5c79499f0eeaed61cbaa25d4c13a8761.png)

  

DevOps 标准当然就是教你该如何绑咯

  

▽

  

DevOps 标准全称**《研发运营一体化能力成熟度模型》**

  

它覆盖端到端软件交付生命周期全流程

  

是一套体系化的方法论、实践和标准的集合

  

![](../Images/0c1dada589cb9810e6bf9d368e9c080c.png)

  

![](../Images/29b801ec0ef222264d4ce743b57a3f0a.png)

  

DevOps 标准集合了国内数十位 DevOps 领域的技术专家

  

是国内外首个 DevOps 标准

  

> 2017年8月18日——**正式开始研讨**
> 
>   
> 
> 2018年4月23-25日——**中国通信标准化协会立项成功**
> 
>   
> 
> 2018年6月29日——**亮相 DevOps 国际峰会·北京站，首批试评估企业中国移动和中国银行现场授牌**
> 
>   
> 
> 2018年7月10日 ——**工信部立项**
> 
>   
> 
> 2018年7月26日 ——**联合国 ITU 立项成功**
