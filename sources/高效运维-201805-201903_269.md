# 2018年的九月，DevOps 时代社区及高效运维社区默默地行走在美国大地，希望将中国原生 DevOps 技术力量输出到世界，建立中国 IT 技术应有的影响力。

本次社区美国行，来自中国信息通信研究院及云计算开源产业联盟、DevOps 时代社区及高效运维社区、腾讯、京东、百度等企事业单位多名专家深入和美国技术群体进行交流。

短短几天时间，本次行程横跨美国东西海岸（境内1万公里），是一次真正意义上的全美行。

![](../Images/b361b4736d22ea8685bb1122e8ae5b67.png)

更多精彩，请随我来。

# **一、Jenkins World | DevOps World（旧金山）**  

Jenkins World 每年在旧金山举办，旨在推广Jenkins、持续交付与DevOps，从2018年开始，启用新名字：DevOps World。

  

![](../Images/98c1f0a612905ed71ccbd8c5cf794b5e.png)

> 后排左起：百度雷涛、腾讯Mark、京东石雪峰，前排左起：中国信息通信研究院及云计算开源产业联盟陈屹力、DevOps时代社区景韵、中国信息通信研究院及云计算开源产业联盟郭雪

本届 Jenkins World | DevOps World的主题是：Transform，大量的演讲围绕Jenkins、持续交付、DevOps、云原生进行分享，后续社区还会专门推送演讲资料给大家。

本次大会，Jenkins 创始人KK代表Jenkins社区将今年社区的Most Valuable Advocate 荣誉授予 Jenkins Pipeline Experts Groups（DevOps 流水线核心专家团队）。

期待更多的中国Jenkins专家能和我们一起，推动Jenkins、DevOps在中国的发展。

![](../Images/f6f17d5c5e8c64b4e2c3ba959b059baa.png)  

DevOps 时代社区石雪峰、雷涛、景韵也有幸成为Jenkins社区首批9位Jenkins Ambassador天团的一员。

**二、DevOps 国际峰会·美国站（硅谷）**

美国本地的朋友会问，为什么来到美国硅谷举办DevOps国际峰会，我的回答：**为了把中国的技术力量输出，不再只是跟随，要引领！**

  

社区首次面向美国当地 DevOps 实践者举办的 DevOps 国际峰会·美国站，全程英文演讲，对国内讲师也是很大的挑战。

  

国内 DevOps 中坚力量，来自中国信息通信研究院、腾讯、百度、京东和 DevOps 时代社区的技术专家，和来自 Google 等美国硅谷大公司的 DevOps 从业者进行了一次广泛而深入的纯英文交流。此次大会小编深深的感受到两点：

> 1\. 英语对技术从业者非常非常重要
> 
> 2\. 印度工程师非常好学，乐于交流
