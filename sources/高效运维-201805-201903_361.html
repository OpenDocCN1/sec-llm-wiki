由我国提出的全球首个 DevOps 标准：研发运营一体化能力成熟度模型，正式立项国际标准，从此确立了国际领先地位！

DevOps 标准在联合国 ITU 正式立项名称为：“ Cloud computing-Requirements for cloud service development and operation management ”。

ITU 立项会议现场照片

ITU 和 ISO、IEC 并称国际三大标准化组织。

ITU（国际电信联盟）是联合国的国际标准组织，成立于1865年（比联合国还早80年），是193个主权国家的政府间组织。ITU 和 国际原子能机构、国际货币基金组织和教科文组织并列，均为联合国专门机构。

DevOps 国际标准的历程

本次 ITU 标准立项会议包括中国、美国、英国、德国、俄罗斯、韩国等20多个国家，近90名专家代表参与，需要得到与会代表的一致同意，DevOps 标准才能成为国际标准，为此 DevOps 标准工作组做出了极大的努力。

时间拨回两个多月前，那时，DevOps 标准工作组的专家就已开始准备。本次DevOps 标准征求意见稿也已于6月29日在北京发布，浙江移动和中国银行软件中心已成为首批通过评估的单位。

在 ITU-T 已经有的标准 Y.3502 和 Y.3522 中规定了云服务生命周期，从设计、部署、运营到终止。

和 Y.3502,Y.3522 不同， DevOps 标准强调实践和技术对 DevOps 的关键作用，主要是Management、Practice 和 Technology，并进一步突出容器与微服务对 DevOps 的重要性，如下图。

DevOps 标准由中国信息通信研究院牵头，联合云计算开源产业联盟、高效运维社区、DevOps时代社区、阿里巴巴、腾讯、百度、京东商城、中国移动、中国银行、中国银联、中国电信、太平洋保险、华为、中兴通讯、中国联通、大唐软件等组织及专家进行编写，感谢他们对 DevOps 标准的卓越贡献。

背后的故事：DevOps 标准的前世今生

DevOps 标准的雏形《互联网应用运维框架及能力模型》初稿于2015年开始编写，七位专家在模型的编写过程中发现，单靠运维无法解决所有问题，无法真正体现业务价值，因此开始寻求更好的方向。

重新起航，奔向新的目标

在2017年8月18日，七位跨领域 DevOps 专家在上海正式开始 DevOps 标准的研讨，并经过多轮次线下专家评审，于2018年4月23-25日在中国通信标准化协会立项成功，6月29日，DevOps 标准亮相 DevOps 国际峰会·北京站，首批试点评估企业中国移动和中国银行现场授牌。


工信部信软司李琰处长（左一）和中国信通院云大所何宝宏所长（右一）为通过单位授牌。
