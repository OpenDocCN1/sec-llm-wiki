**【DevOps 标准引领行业发展】**

  

工信部信息化和软件服务业司信息服务业处副处长李琰先生在大会上致辞，充分肯定 DevOps 标准对行业发展的意义，并和中国信息通信研究院云计算与大数据所所长何宝宏先生一起，为DevOps及AIOps 标准工作组成员单位、专家、通过评估的企业进行授牌。

![](../Images/b3d594384f551907b5a0a327f6c52e24.png)

⬆️工信部信息化和软件服务业司信息服务业处副处长李琰先生在大会上致辞

  

![](../Images/e1b122b81f49fe0bedcfec9c07497f28.png)

⬆️李琰先生（左一）和何宝宏先生（左四）为 DevOps 标准国内外首批试评估通过单位中国移动通信集团浙江有限公司和中国银行股份有限公司软件中心授牌

中国信息通信研究院云计算和大数据与大数据研究所云计算部副主任（主持工作）栗蔚女士带来了重磅全量发布和权威解读《研发运营一体化（DevOps）能力成熟度模型》（DevOps标准）。

![](../Images/520c87899cb25d332c20bce2520a84ec.png)

  

研发运营一体化（DevOps）能力成熟度模型覆盖端到端软件交付生命周期全流程，是一套体系化的方法论、实践和标准的集合。

![](../Images/6f2e15bd4fe45dd0fc670e1331f4d4ac.png)

该标准由中国信息通信研究院旗下云计算开源产业联盟（OSCAR 联盟）、高效运维社区和 DevOps 时代社区联合发起，汇聚了国内 BATJ 等一线互联网企业、通信、金融等传统行业顶级单位的100余名专家联合编写而成，是国内外首个 DevOps 标准。此标准已在中国通信标准化协会（CCSA）正式立项，并正向国际电信联盟（ITU）申请成为国际标准。

同时栗蔚女士公布了首批参加评估单位的评估结果，中国移动通信集团浙江有限公司和中国银行股份有限公司软件中心均通过《研发运营一体化（DevOps）能力成熟度模型 第3部分：持续交付》三级成熟度评估。

  

![](../Images/406c6b173d68c389720016864d09bb22.png)

**【DevOps 标准首次深度解读】**

  

DevOps 标准专场中，7位 DevOps 标准工作组核心专家为大家分享了标准中7个部分的内容，并一起进行了相关案例的分析和研讨。

![](../Images/0ddc4e818e8c7ca8a04b841afd77fba7.png)

>     
> 2.  《第2部分：开发管理标准》组长方炜、《第3部分：持续交付标准》组长石雪峰、《第4部分：技术运营标准》核心编写专家杨军分别介绍了开发管理、持续交付、技术运营相关标准及案例落地研讨。
>     
> 3.  《第5部分：应用设计标准》核心编写专家顾宇、《第6部分：安全及风险管理标准》组长韩方、《第7部分：组织结构标准》组长雷涛分别介绍了应用设计、安全及风险管理、组织结构相关标准及案例落地研讨。
