# 超越自我，精益求精！DevOps 助力中国电信 DICT 应用能力提升

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651681482&idx=2&sn=ad243b64e09a4de352c44e96f6850370&chksm=8bcbb163bcbc38752d767aeeca3bd27a1e844d7b64cfe5269a2631b840823f83d8662e6a07cd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651681482&idx=2&sn=ad243b64e09a4de352c44e96f6850370&chksm=8bcbb163bcbc38752d767aeeca3bd27a1e844d7b64cfe5269a2631b840823f83d8662e6a07cd&scene=27#wechat_redirect)

![](../Images/c2e2259852da561246cb710dae69adcb.png)12月26日，由云计算标准和开源推进委员会（TC608）主办，中国信息通信研究院、中国标准化协会指导，2019运维大会在北京市国宾酒店国宾厅圆满举行。中国电信集团数字化应用能力中心研发管理部总经理杜忠田在2019运维大会上以 DevOps 在中国电信 DICT 体系的探索和实践为题发表主旨演讲，他对近年 DevOps 在中国电信 DICT 的探索实践做了详细介绍，引起业内人士的广泛关注。

  

![](../Images/338b5d61869ae8f7281b814e4b4bd83e.png)

会上，杜忠田总经理围绕主题展开四大方面内容分享：1\. 中国电信转型之路；2\. DICT应用能力中心发展思路；3\. 比翼研发云平台建设，提升体系软件研发能力 4. DevOps开发运营一体化平台，在中国电信的应用。

![](../Images/caee1f7527cec16bc56b1d3efbbb6926.png)在 DevOps 一体化平台演进部分，杜总详细介绍了 DevOps 在中国电信 DICT 落地的过程，建设的核心就是打造一站式敏捷研发交付平台。依托容器、持续集成、网络信息安全等技术，实现从需求、开发、测试、集成、部署、运维整个过程的流程化、自动化、安全化，通过快速频繁的版本迭代，推动研发过程管控，缩短产品功能交付周期，助力中国电信 DICT应用研发能力提升。
