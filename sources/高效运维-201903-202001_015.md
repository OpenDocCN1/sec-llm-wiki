# 重磅！江苏电信通过 DevOps 持续交付标准 3 级评估，相关项目能力达到国内领先水平

**编者按：**根据麦肯锡的一项研究结果，科技公司想要成功，关键所在无外乎两点：**标准化和工具赋能。**标准本身是最佳实践的集合，有了标准，每一步都离目标更近（而不是偏离），将标准固化在工具里，让人做更有价值的事情。这和 DevOps 标准及 DevOps 持续交付流水线工具平台的核心理念和实践不谋而合。

 

12 月 26 日，2019 运维大会在北京顺利召开。会议由中国信息通信研究院、中国通信标准化协会指导，TC608 云计算标准和开源推进委员会主办，云计算开源产业联盟支持。旨在为进一步推动行业发展，促进运维新技术、新理念时间落地，加强行业内经验分享交流，聚集多领域大咖分享宝贵运维经验。

 

大会隆重发布了 DevOps 标准持续交付部分第六批评估结果。**其****中，江苏电信操作维护中心、中国电信集团数字化应用能力中心和江苏电信软件研究院共同推进智能预处理系统顺利通过DevOps 标准持续交付部分3级评估，获得由中国信息通信研究院（以下简称信通院）开展的《研发运营一体化（ DevOps ）****能力成熟度模型》持续交付评估证书。**DevOps 标准共分5级，持续交付部分如果能达到 3 级已经是国内领先水准，这代表着江苏电信在该系统的持续交付能力达到国内领先水平。这也是中国电信集团首家通过 DevOps 持续交付标准评估的省公司/单位。

  

由******中国通信标准化协会副秘书长潘峰女士**与中国信息通信研究院云计算和大数据研究所所长何宝宏博士**共同**为江苏电信授牌：

此次，我们采访到江苏电信操作维护中心主任章澎先生，深聊了项目参评的细节和幕后团队的故事，分享江苏电信 DevOps 实践经验。

  

**\-Q&A-**

**Q:请介绍一下您和您的企业，以及此次参与评估的项目。**

**A:**江苏电信操作维护中心是江苏电信的直属中心，承担全省城域网、核心网、传输、云平台等集约化维护与 7\*24 集中监控。智能预处理系统是面向网络故障场景打造的障碍自动定位、诊断分析、提供主动处理建议的应用平台。  

  

**Q:恭喜您通过DevOps 标准评估，此次项目通过的是持续交付三级，表明达到了国内领先水平，请说一下您此时的感受。**

**A:**很高兴能够通过 DevOps 持续交付能力成熟度 3 级标准评估。智能预处理系统是江苏电信首个参评项目，取得了开门红。通过本次评估，切实提升了应用的持续交付能力，在团队中贯彻了 DevOps 理念，同时为其他应用的 DevOps 建设积累了宝贵的经验。  
  

**Q:此项目是如何决定加入 DevOps 标准评估工作中的？**

 

**A:**电信运营商正在向客户服务转型，在"以客户为中心，推动高质量发展"的指导下，快速定位、解决故障的智能预处理系统就尤为重要。而客户报障的描述复杂，诉求多样，直接导致系统需求种类丰富、变化迅速、对需求上线速度要求非常高，因此需要集中力量快速提升 e 智能预处理项目的 DevOps 能力，是非常关键的。

 

**Q:通过 DevOps 标准评估对项目团队意味着什么？**

 

**A:**通过标准评估，首先是对团队在持续交付能力建设上的肯定，意味着项目的持续交付能力已经达到了一定的高度。同时也意味着我们距离 4 级还有较大的提升空间，也指明了后续的改进方向。  
  

**Q:关于 DevOps 标准，您怎么看，对您企业带来了什么帮助？**

 

**A:**DevOps标准评估对企业来说，能够在落地 DevOps 最佳实践的过程中提供系统性的参考依据。DevOps 自兴起以来，还没有相关的标准能够指导企业进行实施。通常他人的经验并不一定适合自己。因此需要通过标准来指导实践，并且通过标准的分级，能够让企业了解自身的 DevOps 能力处于何种水平，找准差距，以推动持续改进。  
  

**Q:对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？**

 

**A:**智能预处理系统作为服务平台，需要对接底层网络操作能力与网络数据，经过对能力、数据统一编排，按照业务规则输出故障段落,诊断报告等供上层应用。从该项目组建起，项目组就参照 DevOps 的规范要求操作。

 

**Q:此次通过评测的过程顺利吗？****遇到什么困难？****如何解决的？**

 

**A:**智能预处理项目可以说是中国电信的第一个采取 DevOps 工作模式的试点项目，我们面临着经验缺乏、改动量大等新的挑战，同时还要保证日常的功能的按时上线。为保证项目的顺利运营，我们进行了项目改造与平台能力改造的联合开发，运用 DevOps 工作模式，使用快速迭代的新功能来探索 DevOps 功能是否能够适应我们的日常开发，最终苦尽甘来，大大提高了我们的开发效率。

 

**Q:团队的下一步计划是什么？**

 

**A:**领导们非常重视 DevOps 的推广和落地工作，我们接下来计划让一批项目使用DevOps 模式，提高项目的开发效率，总体来说可以分为两个方面：

**1.人员赋能：**将智能预处理项目组在践行 DevOps 规范中总结的经验与教训，实现其他项目组成员的 DevOps 能力赋能；

**2.系统调整：**新建系统按照 DevOps 规范标准设计，存量系统在架构优化时不断进行DevOps调优。

 

**Q:关于 DevOps 的发展前景，您怎么看？**

 

**A:**我们看到 DevOps 在面对多变的用户需求和提高研发效率方面巨大的作用，持续高效地向生产环境发布新的功能逐渐成为一种基本的需求。在未来，DevOps 可以助力科技企业在云计算、物联网、大数据、视频等多个领域提升研发效率，提升中国电信的 DICT 能力。

全球首个 DevOps 标准，即《研发运营一体化（DevOps）能力成熟度模型》，由中国信息通信研究院牵头，联合云计算开源产业联盟、高效运维社区、 DevOps 时代社区、 Google、BATJ、清华大学、南京大学、通信及金融等行业顶尖企事业单位专家共同制定。

 

目前，由中国信息通信研究院主导的 DevOps 标准已在联合国直属标准化组织 ITU-T、中国通信标准化协会（CCSA）正式立项。

 

在此之前，通过中国信通院 DevOps 持续交付能力成熟度评估的企业包括：中国工商银行、中国银行、华泰证券、浙江移动、腾讯、招商银行、广东移动、北京移动、去哪儿网、郑州银行、神州泰岳等。
