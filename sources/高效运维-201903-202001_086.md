# 扬帆上海！LinkedAIOps 斩获 2019 运维行业年度极具影响力产品

2019年11月1日，上海光大会展中心，LinkedSee灵犀凭借其自主研发的LinkedAIOps智能业务运维平台，斩获了“2019运维行业年度极具影响力产品”奖项。此奖项一方面印证了LinkedSee灵犀的技术研发能力，也从另一方面验证了LinkedAIOps在各场景的落地服务能力。

  

  

  

![](../Images/55451dd766b9e524884ead3587c5abfa.png)

  

LinkedSee灵犀成立于2015年，总部位于北京，在上海、广州、深圳、杭州、南京、济南等地设立了分支机构。LinkedSee灵犀致力于为客户提供企业级IT服务，提供云计算和大数据时代的智能IT运维产品和解决方案，帮助客户优化其IT基础设施及网络和业务的可用性，TCO和运营效率，满足客户不断增长的业务规模和IT架构迭代需求。

  

![](../Images/ef90fe06d025a79cb38c39003b558cc9.png)

  

  

  

LinkedAIOps是一款以告警事件、业务日志、网络及业务拓扑等管理对象，通过算法智能降噪、算法智能聚类的管理过程，依托人工智能技术实现智能事件关联组合和分析，达到在海量运维事件中智能化分析事故根本原因的管理目标，确保在运维事故发生时可快速定位导致故障的关键事件，提升事故的处理效率。

  

  

  

LinkedAIOps具有以下核心优势：

1.  数据统一接入和治理。将分散孤立的运维数据集中管理和分析；
    
2.  90%告警降噪率。告警去重一级降噪，告警聚类二级降噪，极大降低无效告警的干扰；
    
3.  日志异常检测。从海量日志中实时分析日志模式的变化趋势，及时发现日志异常，并发出告警；
    
4.  指标异常检测。实时接入运维监控指标，通过异常检测算法得出指标的异常点，及时发出告警；
    
5.  智能根因分析。基于故障模式及关联消息的持续自我学习，初始可实现60%根因推荐的准确率，进行自主机器学习后，根因推荐准确率可大于90%；
    
6.  多重根因定位。告警中找不到根因时，可以通过关联日志模式、关联指标等辅助排障工具，快速发现和定位故障；
    
7.  一键故障排查。在没有监控或系统未接入对应主机的告警时，与主机相关的模块或业务出现故障，可通过一键排障功能，实现简单快速故障排查的目标，降低MTTR提升SLA；
    
8.  数据可视化。多维度运维数据统计展示，灵活运维KPI报表。
