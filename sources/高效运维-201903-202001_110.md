# 证券行业首家！华泰证券同时通过 DevOps 持续交付和技术运营标准评估

**编者按：**根据麦肯锡的一项研究结果，科技公司想要成功，关键所在无外乎两点：**标准化和工具赋能**。标准本身是最佳实践的集合，有了标准，每一步都离目标更近（而不是偏离），将标准固化在工具里，让人做更有价值的事情。

  

  

2019 年 11 月 1 日，GOPS 全球运维大会在上海正式召开。GOPS全球运维大会至今已经举办了13届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。

 

此次会议，除主会场精彩分享外还分为技术运营标准专场、AIOps 场景实践专场、AIOps 行业案例专场、DevOps 标准企业案例专场、阿里巴巴专场、腾讯专场等，名企专家近70个议题完整覆盖运维全技术领域。

 

特别值得关注的是，**华泰证券CRM营销中心、XTrader 通过 DevOps 标准持续交付部分评估，华泰证券涨乐财富通交易服务全国首批通过 DevOps 标准技术运营部分评估。**三个项目的相关能力达到国内先进乃至领先水平。

  

至此，华泰证券成为证券行业唯一同时通过 DevOps  标准体系的“持续交付”和“技术运营”相关评估的企业。（全国获此殊荣的企业也仅2家）

   

又快又稳才是真功夫！如果说持续交付标准解决的是“快”的问题，横向打通开发、测试及运维，使得快速发布高质量版本，那么技术运维标准解决了“稳”及“好”的问题。

全球首个 DevOps 标准，即《研发运营一体化（DevOps）能力成熟度模型》，由中国信息通信研究院牵头，联合云计算开源产业联盟、高效运维社区、 DevOps 时代社区、 Google、BATJ、清华大学、南京大学、通信及金融等行业顶尖企事业单位专家共同制定。

 

目前，由中国信息通信研究院主导的DevOps标准已在联合国直属标准化组织 ITU-T、中国通信标准化协会（CCSA）正式立项。
