# 25岁以后，你更应该逼自己系统性成长

书单君和不少20多岁的粉丝聊过，发现大家的困惑都很相似：  

  

**怎样才能快点度过这段又穷又迷茫的岁月？**

  

其实我很能理解。这些年轻人在离开学校、进入社会时，心智还尚浅，对商业世界运行规则毫无认知，但现实却要求他们必须快速选择自己的方向。**在这些决定命运的十字路口，没有经验的他们只能凭直觉去选**。

  

这就导致3年后，他们中99%的人，对工作大多的感觉是：**正确的模糊**。

  

做着正确的努力，却走向模糊的方向，明明用力踩着油门，手上却没有一份人生地图。

  

事实证明这样做，职场和人生大概率会出问题。

  

**人生要做的功课**** 早晚都逃不掉**

  

日本500强企业家稻盛和夫在《思维方式》里，曾提出过一个乘法公式：

  

**人生（工作）的结果=思维方式 X 热情 X 能力**

  

有意思的是，他认为热情和能力可以用0到100打分，但思维方式的打分却是-100到100。

![](../Images/446154eeaeb7a5af1f32dc8748dcf17d.png)

  

也就是说：如果你的思维方式是负值，那么“能力”越强，“热情”越高，其结果只会是更大的负值。

而大多数人最常犯的一个思维错误，就是觉得努力比天赋更重要。

我们常常很努力想做成一件事，在没做成之后，怪自己还不够努力。但却从没有想过，是不是努力的方向不对？自己是不是在这件事上没有天赋？

**事实上，找到自己天赋的人，一年的努力能抵得上十年。**秦海璐就是一个很好的例子。  

早在2000年，只有18岁的秦海璐就凭借在《榴莲飘飘》的表演获得**台湾电影金马奖最佳新人奖和最佳女主角**。

  

凭借处女作获得很多演员们追求多年的大奖，不得不说，这起点太高。

  

但当时的秦海璐，并不觉得演员就是自己该吃的那碗饭。她的理想，是做个白领。

  

于是，她就真的去当了白领，却因为不懂电脑知识和职场规则，不久就被辞退。不服气的她又开始创业，先后开过美发店、火锅店，成立过广告公司，却统统经营不善失败了。

在一番兜兜转转之后，秦海璐发现，**她的天赋，还是演戏**。当好一名演员，不凭美貌，自己也够料。天赋就是自己最大的底气。

这才有了后来的故事：她塑造了很多深入人心的角色，《钢的琴》的女工淑娴、《红高粱》里偷看人洗澡的大少奶奶、《白鹿原》里的仙草……也拿了更多大奖，成为被观众和专家都认可的演员。  
在20多岁时，你的迷茫也许和当时的秦海璐一样，自己什么都做不顺，**如何找到这场人生游戏中的位置？**

  

答案是：**用清晰的思维系统****找到自己的天赋**，因为这也意味着你能找准定位，在正确的道路上高速成长。

  

这才是你过好这一生最有效的方法。

  

**天赋为王的时代****看不清未来该怎么办**

  

但是，现在很多人并没有寻找天赋的意识和方法，而是在迷茫中开启自己的职场道路，且在得过且过中一直迷茫着。

前两个月，书单君的侄女小爱就找我诉说了她的困扰：毕业了要找工作，自己是英语专业的，要不要找一份与之有关的工作？

  

我没有直接告诉她，而是给她介绍了一个分析问题的工具：**「冰山模型」**。

  

![](../Images/4ec990cea925f1062f2a6198f7e419c9.png)

  

所谓“冰山模型”，简单来说，就是人的内在价值由三部分组成：**知识技能、能力和天****赋**。

  

第一类要素，知识和技能，是你很容易学到的硬能力，比如编程，PPT等等。

  

第二类要素，软能力，是指你在所有领域和工作中“可迁移的能力”，例如创新能力，表达能力等等。

  

而冰山模型里最有价值的，就是第三类要素，天赋，**包括价值观、性格特质、动机等等**。

因为相比前面两个，天赋的门槛最高，在职场有着难以超越的竞争力。**你大多数的职场问题，都应该围绕天赋来优先考量。**

回到小爱如何选择工作的问题，我是这么跟她分析的：

英语是可习得的技能，门槛并不高，类似的技能还有编程、运营、策划等等。你应该考虑，语言能力是否是你天赋所在？如果不是，英语这项技能，就不应该成为你职场中的核心竞争力。  
绝大多数人在30岁前找不到天赋，当经济环境变化，行业遭遇寒潮时，**他们就是最容易被优化和替换的“末位20%”**。

  

即便月入2万，也只是在努力地贩卖自己的体力，迟早被新人淘汰。
