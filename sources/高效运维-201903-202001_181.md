# 技术运营最佳实践案例专场沙龙成功举办

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651679687&idx=4&sn=40c83578104cec2762a72358eb69457e&chksm=8bcba86ebcbc21785c5afa272b01e812168be957bab9766d88d138543736a42af3f5834804a3&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651679687&idx=4&sn=40c83578104cec2762a72358eb69457e&chksm=8bcba86ebcbc21785c5afa272b01e812168be957bab9766d88d138543736a42af3f5834804a3&scene=27#wechat_redirect)

![](../Images/c2e2259852da561246cb710dae69adcb.png)9月21日，于上海举办的技术运营最佳实践案例专场沙龙成功举办。本次沙龙活动由高效运维社区和交通银行信用卡中心主办，来自金融、通信、互联网等行业的资深运维专家齐聚一堂，呈上一场精彩技术分享。  

![](../Images/0f0fd91be58f5a057165063df6d186ed.png)  

  

首先带来分享的是浙江移动 SRE 团队首席架构师李佐辉带来“运营商网络运维工程师的 SRE 转型之路”，运营商网络技术日新月异，传统通信网络运维工程师正向IT化转型，李佐辉老师以浙江移动的转型经验为例，分享了网络运维工程师如何转型。

今年是 DevOps 的十年，也是业务互联网化过程中，精细化运维从萌芽到大树的10年，在 DevOps 日趋成熟的今天，运维如何借助 DevOps，打造一体化运维生态？苏宁消费者金融安全运维部负责人顾黄亮老师分享了“DevOps，助推企业研发运维蜕变”的精彩分享。

  

云计算、自动化、DevOps 的技术大潮下，大型企业如何做到高效、安全的运维？中国人寿数据中心资深自动化运维专家王浩分享了“自动化、自助化、服务化-新形势下大型企业 SRE 之路”。  

  

最后一位分享的神秘大咖来自交通银行信用卡中心云平台负责人杨晓东老师，杨老师分享了交通银行信用卡中心应用系统从微服务架构如何演化进云原生架构，并演示了云原生应用如何做到分钟级发布及秒级扩充实例数。
