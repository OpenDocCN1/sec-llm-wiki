# 重磅！中国工商银行通过 DevOps 标准评估，相关项目持续交付能力达到国内领先水平

**编者按：**根据麦肯锡的一项研究结果，科技公司想要成功，关键所在无外乎两点：**标准化和工具赋能。**标准本身是最佳实践的集合，有了标准，每一步都离目标更近（而不是偏离），将标准固化在工具里，让人做更有价值的事情。这和 DevOps 标准及 DevOps 持续交付流水线工具平台的核心理念和实践不谋而合。

  

2019年9月6日 GNSEC 高峰论坛在北京顺利召开，本次论坛专注于全方位的软件工程和技术，致力于定义新一代的软件工程。论坛聚集软件工程行业的专家、学者、从业者，讲述重要的最新研究成果，并分享最前端的实践经验，同时促进产、学、研领域的专家互相交流合作。

  

特别值得关注的是，**中国工商银行（以下简称工行）工银e生活项目顺利通过 DevOps 标准持续交付部分3级评估，**获得由中国信息通信研究院（以下简称信通院）开展的《研发运营一体化（ DevOps ）能力成熟度模型》评估证书，证书编号是：G01027。这代表着工行在该系统的持续交付能力达到国内领先水平。

  

论坛上，**由中国信息通信研究院副总工程师史德年先生为工商银行授牌：**

  

![](../Images/b7651b50ff0de4241057250bee30284e.png)

▲史德年先生（左）为工商银行(右)授牌  

  

  

全球首个 DevOps 标准，即《研发运营一体化（DevOps）能力成熟度模型》，由中国信息通信研究院牵头，联合云计算开源产业联盟、高效运维社区、 DevOps 时代社区、 Google、BATJ、清华大学、南京大学、通信及金融等行业顶尖企事业单位专家共同制定。

  

目前，由中国信息通信研究院主导的DevOps 标准已在联合国直属标准化组织 ITU-T、中国通信标准化协会（CCSA）正式立项。

  

在此之前，通过 DevOps 标准评估的企业包括：浙江移动、中国银行、腾讯、招商银行、广东移动、北京移动和去哪儿网等（按参评顺序）。

  

  

恭喜工行通过 DevOps 标准持续交付部分3级评估，为此我们采访到了负责工银e生活项目评估工作的专家，深度揭秘了工行 DevOps 能力建设进展与参评背后的故事。

  

** Q&A**

  

**GNSEC：****您好，请介绍一下您和您的企业，以及此次参与评估的项目。** 

  

**工行专家：**中国工商银行软件开中心成立于1996年，经过23年的跨越式发展，**成为一个在珠海、广州、上海、北京、杭州、成都、西安七个城市设有研发部的高新金融软件研发机构，**肩负着应用研发、技术研究、系统培训、生产运维等诸多领域的职能。

  

从电子化、信息化，到国际化、综合化、信息化，再到开启智慧银行建设，软件开发中心在科技手段的代际更新中打造了工商银行不可复制的核心竞争力。

  

 工银e生活项目是为工行牡丹卡中心打造的一款集生活、消费和金融于一体的综合消费服务平台，**是工行信用卡中心在互联网渠道面向客户的****第一平台****和****唯一对客App渠道****。****用户规模千万级****，日活用户数量在****50万左右。**

  

****GNSEC**：****此次选择工银 e ****生活项目参与评估，是出于怎样的考虑****？**

**工行专家：**工银e生活作为我行信用卡业务唯一对客App渠道，其业务价值重要性不言而喻。而信用卡业务领域，需求种类丰富、变化迅速、对需求上线速度要求非常高，是最能体现银行快速交付能力的领域。因此集中力量快速提升 e 生活项目的 DevOps 能力，是非常关键的。

  

****GNSEC**：****恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是3级，表明相关项目达到了国内领先水平，请说一下您此****时的感****受**。 

  

**工行专家：**很高兴能够通过 DevOps 持续交付能力成熟度3级标准评估。工**银e生活是我行首个参评项目，取得了开门红。**通过本次评估，切实提升了应用的持续交付能力，在团队中贯彻了 DevOps 理念，同时为其他应用的 DevOps 建设积累了宝贵的经验。

  

****GNSEC**：****作为金融行业头部，贵公司是如何决定加入 DevOps 标准评估工作中的？**

  

**工行专家：**金融行业近年来的变化非常大，**面对快速变化的业务需求，金融科技企业必须提升软件交付效能。**而在组织中推广实施 DevOps 并不容易，参与标准评估以评促建，各个领域都可以对照标准寻找差距，有利于快速推进 DevOps 的落地实施。

  

****GNSEC**：****通过 DevOps 标准评估对贵团队意味着什么？ **

  

**工行专家：**通过标准评估，首先是对团队在持续交付能力建设上的肯定，意味着项目的持续交付能力已经达到了一定的高度。同时也意味着我们距离4级还有较大的提升空间，也指明了后续的改进方向。

  

********************GNSEC**：********************关于 DevOps 标准评估，您怎么看，对您企业带来了什么帮助？**

  

**************工行专家：**************DevOps 标准评估对企业来说，能够在落地 DevOps 最佳实践的过程中提供系统性的参考依据。DevOps 自兴起以来，还没有相关的标准能够指导企业进行实施。通常他人的经验并不一定适合自己。因此需要通过标准来指导实践，并且通过标准的分级，能够让企业了解自身的 DevOps 能力处于何种水平，找准差距，以推动持续改进。

  

********************************GNSEC**：********************************此次评估遇到什么困难？****如何解决的？**  

  

****************工行专家：****************由于 DevOps 涉及从开发到上线的交付全流程，需要行内多个机构和部门的共同努力。大家的办公地点并不统一。我们采用每周视频例会的形式，持续跟踪进度和问题、严格落实改进计划和责任人，**中心上下对于评级建设中的各项需求都以最高优先级处理。**

  

此外，各相关部门都安排专人跟进评级相关工作，大家主动放弃周末休息时间，确保各项改进如期完成。

  

**GNSEC：****在项目改进的过程中有没有特别难忘的事情？**

  

******************工行专家：******************本次评估准备过程中，恰好逢工行 ETC 项目研发，项目组既要保证 ETC 项目按时上线，又要兼顾评估涉及的各个能力提升项，日夜兼程，付出了极大的努力。在中心上下各部门的全力配合支持下，确保 ETC 项目准时上线，同时保证了评级准备工作稳步推进。

  

******************GN************************************SEC******************：**在****通过 DevOps 标准评估之后，贵企业打算怎样继续推进 DevOps 落地？** 

  

********************工行专家：********************准备在企业内部以 DevOps 评估标准来重新审视和规划持续交付能力建设。把评估中获得4级的优势能力向其他项目推广，同时研究专家提出的改进建议，结合工行目前的实际情况推进落实，进一步提升全中心的 DevOps 能力。

  

**具体来说：**

  

一是继续打造高效的持续交付工具平台，提升各个阶段的标准化和自动化能力。

  

二是从研发模式转型入手，对需求拆分、需求设计、迭代计划等实施更加精细化管控，提升端到端的价值交付能力。

  

********************************GN********************************************************SEC************************：**在企业内部大规模落地 DevOps 的经验和技巧，您有哪些可以分享给我们吗？**

  

**********************工行专家：**********************大规模落地 DevOps ，首先要有组织层级要进行强有力的推动，中心各级领导非常重视 DevOps 的推广和评估工作，在组织内部 DevOps 的相关工作是有很高优先级的。其次，要建立专门的持续交付平台建设团队，负责工具链的服务化封装，降低开发组的学习成本，工具要让大家喜欢，就要持续提升稳定性和易用性，也能让工具的推广更容易。

  

此外，要在组织内传播和贯彻 DevOps 理念，让大家对 DevOps 文化产生认同，这样才能体现 DevOps 的价值，也能激发大家的积极性。

  

GN******************SEC************************************************************：********************************************关于 DevOps 的发展前景，您怎么看？**

  

************************工行专家：************************DevOps 发展10余年，目前已经成为软件行业最受关注的领域之一。在 VUCA 时代，面对急速变化的用户需求，提升研发效能，加快上线频率已经逐渐成为行业的基本要求了。

  

将来结合大数据和人工智能技术，必将大幅提升研发运营效率，工行软件开发中心将持续推进 DevOps 的建设，将行业最佳实践与工行实际相结合，打造具有工软特色的 DevOps 体系，助力工行软件开发中心成为一流的金融科技企业！
