# 采他山石 取众家长 ——记中国农业银行研发中心参加 DevOps 国际峰会之行

**DevOps 这一概念诞生于2009年，主要针对敏态业务。**时至今日已经走过了10个年头，不管是互联网还是金融科技圈都在不断探索 DevOps 给企业带来端到端的价值交付速度提升的方法实践。

  

**中国农业银行研发中心从2018年开始结合企业的数字化转型目标，启动敏捷研发、DevOps 建设等工作，开启研发转型之路。**征途漫漫，路险且阻，为了更加高效的推进 DevOps 工程建设，研发中心积极向同业和互联网企业取经，以期采他山之石、取众家之长。

  

![](../Images/113c72bb1784342244cd00cc94a1f243.png)

  

7月5日、6日，DevOps 国际峰会2019北京站正式召开。

  

DevOps 国际峰会是国内唯一覆盖 DevOps 全领域的国际性技术峰会，由 OSCAR 联盟指导，DevOps 时代社区和高效运维社区联合主办，邀请全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

  

研发中心在项目管理办公室与人力资源部共同组织下，由项目办处长带队，北研技术保障部、架构管理办公室、系统支持部等部室领导以及 DevOps 建设工程相关的技术骨干20余名参加了本次大会。

  

![](../Images/c3306c17443ad55d9b8508bf3cff16b9.png)

  

7月5日上午信通院领导隆重介绍了企业级 DevOps 赋能（共促）计划，该计划由云计算开源产业联盟联合开放运维联盟、国内外多家企业及专家共同发起，目的是更好地促进中国企业实施组织级 DevOps 能力建设，让IT更好的支撑业务的快速发展。农行研发中心在本次 DevOps 国际峰会上正式加入该计划，农行代表上台参加授牌仪式，并接受了央视7套《态度》栏目专访。

  

此次峰会共举办了18个专场，70+议题，涵盖精益/敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、云原生 Kubernetes 等，覆盖 DevOps 全领域。

  

![](../Images/e63eb7f3d33b594a849ca9b427f58acd.png)

  
  

农行研发中心团队认真聆听专家演讲、充分吸取先进理念、积极与专家们进行互动，重点关注互联网行业领军企业的 DevOps 转型经验、同业 DevOps 平台建设以及微服务与高可用架构、自动化测试和持续集成等专项领域的优秀实践，这些正是研发中心 DevOps 建设中的重点学习对象和攻坚领域。  

  

![](../Images/87d2216d4a21117188c9981338b6b297.png)

  

经过两天的学习交流，研发中心的代表们收获颇丰。研发中心表示，后续将在企业内部分期组织专题沙龙，在分享交流中碰撞出更多思想火花，指导落地实践，通过不断优化管理流程、建设持续交付流水线、建立正确的研发效能度量机制，为农业银行产品研发提质增效助推加力。
