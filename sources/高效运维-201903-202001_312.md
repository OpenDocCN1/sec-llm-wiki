是的！为期两天，万众期待的 DevOps 国际峰会 2019 · 北京站圆满结束啦！

与以往相比，本次 DevOps 国际峰会有哪些精彩？两天的时间，18个专场，70+议题，涵盖精益/敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化的 DevOps 全领域技术大会，今年夏天，是 DevOps 的狂欢！

DevOps 国际峰会是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导，DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。  

  

**【大会第一天主会场】**  

上午的主会场可谓精彩纷呈，首先开场的是本次峰会的“超级5分钟”环节，四位演讲嘉宾分别在5分钟的时间完成演讲。

随后是主会场的第一场主题演讲，由中国信息通信研究院云计算和大数据研究所所长何宝宏博士带来：“互联网二十年，开源的“绿帽子”和技术的食物链”。

何宝宏博士的演讲幽默风趣、同时更具深度。  

▼

![](../Images/47f0e46f14105cd7e1924e859d8365af.png)

随后，中国信息通信研究院云计算和大数据研究所云计算部主任栗蔚女士带来“携手前行，企业级 DevOps 赋能（共促）计划”。

  

为更好地促进中国企业实现组织级 DevOps 能力，打造一流的、端到端的 DevOps 持续交付流水线平台、提升组织效率与质量，让 IT 更好地支撑业务快速发展，由中国国信通院旗下云计算开源产业联盟联合开放运维联盟、国内外多家企业及专家力量共同发起的一项企业级 DevOps 赋能（共促）计划。

▼

![](../Images/da3470065493087a3a64d2ca1c4fc2b1.png)

一批国内顶尖企业加入本计划并在近千位观众面前荣耀的接受授牌。

  

主持人宣布此次加入企业级 DevOps 赋能（共促）计划的企业，分别是中国农业银行研发中心、中信银行股份有限公司、中国移动通信集团广东有限公司、中国移动通信集团浙江有限公司、国泰君安证券股份有限公司、国信证券股份有限公司、郑州银行股份有限公司、长沙银行股份有限公司、泰康保险集团股份有限公司。

**本次大会还有很多精彩演讲，就不一一罗列了。**

紧张而又刺激的2 天的时间，70 个议题，18 个专场， DevOps 国际峰会 2019 · 北京站有哪些令您印象深刻的演讲和细节？

以下为此次 DevOps 国际峰会 2019 · 北京站参会者周国庆的参会总结![](../Images/623517f553991025f5406dc78f61e4e5.png)：

1\. DevOps 逐渐成为了业界标准，一种被大家广泛认可的文化；

2\. 各行各业都在践行 DevOps，希望通过 DevOps 提升研发交付效率；

3\. DevOps 的发展催生了很多研发效能平台/云：腾讯Tars、阿里云效、蚂蚁、京东、百度…

4\. 研发效能平台在大厂内部主要解决大规模研发团队的研发效能：上千上万的研发团队，几百个代码仓库，产品，研发效能非常重要，都在解决研发过程管理、交付效率慢、线上质量保障的问题；

5\. 组织先行，大厂不仅自建研发效能平台，同时都有自己的研发效能部；

6\. DevOps 未来几年会大行其道；

7\. 通过AI，让 DevOps 更加智能，AIOps 正在逐步落地应用。
