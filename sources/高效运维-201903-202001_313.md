# DevOps 国际峰会 2019 · 北京站第一天精彩回顾

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651678390&idx=1&sn=1871002890fb8b066c1d0f3015cab244&chksm=8bcba51fbcbc2c09c41d722d4bafaa3f00c3d9f5bfd038d363ddfd5deaff6e289fd0b99bd529&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651678390&idx=1&sn=1871002890fb8b066c1d0f3015cab244&chksm=8bcba51fbcbc2c09c41d722d4bafaa3f00c3d9f5bfd038d363ddfd5deaff6e289fd0b99bd529&scene=27#wechat_redirect)

万众期待的 DevOps 国际峰会 2019 ·北京站终于开始啦~

  

2019 年是 5G 元年，2019 也是 DevOps 诞生的10年，DevOps 因其先进性和全面性，被认为是软件工程的第三次变革，在这个独具意义的一年，2019年7月5日，国内唯一的国际性 DevOps 技术峰会，DevOps 国际峰会 2019 · 北京站在朝阳区悠唐皇冠假日酒店盛大开幕。

▼

![](../Images/f088348c70a576b6c1e9b72bd57c7d93.png)

  

DevOps 国际峰会是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导，DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

  

**第一天上午、主会场**

上午的主会场可谓精彩纷呈，首先开场的是本次峰会的“超级5分钟”环节，四位演讲嘉宾分别在5分钟的时间完成演讲。

▼

随后是主会场的第一场主题演讲，由中国信息通信研究院云计算和大数据研究所所长何宝宏博士带来：“互联网二十年，开源的“绿帽子”和技术的食物链”。

何宝宏博士的演讲幽默风趣、同时更具深度。  

▼

![](../Images/47f0e46f14105cd7e1924e859d8365af.png)

  

随后，中国信息通信研究院云计算和大数据研究所云计算部主任栗蔚女士带来“携手前行，企业级 DevOps 赋能（共促）计划”，为更好地促进中国企业实现组织级 DevOps 能力，打造一流的、端到端的 DevOps 持续交付流水线平台、提升组织效率与质量，让 IT 更好地支撑业务快速发展，由中国国信通院旗下云计算开源产业联盟联合开放运维联盟、国内外多家企业及专家力量共同发起的一项企业级 DevOps 赋能（共促）计划。

▼

![](../Images/da3470065493087a3a64d2ca1c4fc2b1.png)

  

一批国内顶尖企业加入本计划并在近千位观众面前荣耀的接受授牌。

  

主持人宣布此次加入企业级 DevOps 赋能（共促）计划的企业，分别是中国农业银行研发中心、中信银行股份有限公司、中国移动集团广东有限公司、中国移动集团浙江有限公司、国泰君安证券股份有限公司、国信证券股份有限公司、郑州银行股份有限公司、长沙银行股份有限公司、泰康保险集团股份有限公司。

高效运维发起人、DevOps 国际峰会发起人萧田国老师带来“DevOps 10年：3C 引领的新一代软件工程变革”的精彩演讲。听完萧老师的演讲，相信你会对 DevOps 的未来发展更具有信心。

▼

![](../Images/3d47c690aa8dc7dd3598c0ca32ba798d.png)

  

DevOps 是 IT 行业的热点，5G 是通信行业的热点，这两个热点相遇，会起哪些化学反应？在网络运维工作中，5G 为 CT 带来了 IT 特性，对运营商提出了要自研自维，能力内化的新要求。广东移动趁着建设 5G 的契机，探索 5G 的业务敏捷交付，将 DevOps 生产线延伸到通信网络，和华为公司一起探索出一条可行道路。

  

广东移动网管中心总经理孙剑骏带来“DevOps for 5G：广东移动与华为在 5G 落地中的 DevOps 探索。

▼

![](../Images/23fed6ebe9ff48cf8ea13c35568314c2.png)

  

  

蚂蚁金服资深技术专家、金融科技 PaaS 产品线负责人王磊（玉攻）带来“金融级平台即服务：打造技术中台拥抱金融科技创新”的精彩演讲。王磊老师从实际落地案例出发，分享蚂蚁金服金融科技对于 PaaS"平台即服务"的理解，全面解读蚂蚁金融科技的数字金融平台产品战略和实践。  

▼

![](../Images/76400bfc2f642bd5457c74c5c32f4025.png)

  

复旦大学软件学院副院长/教授彭鑫带来“基于代码大数据的软件开发质量追溯体系”精彩演讲。演讲中，老师详细介绍了软件开发质量追溯体系的含义及其应用场景、软件开发质量追溯的基本问题和技术困难以及如何基于代码大数据打造软件开发质量追溯方案。

▼

![](../Images/57f7954618a996a3f89f32c4ee62df3d.png)

  

  

台湾著名精益布道师、91APP总经理室敏捷教练李智桦老师带来上午最后一个主题演讲：敏捷破坏者实战手册。何为“敏捷”？，“敏捷”是如何被破坏的？老师抛出这个有意思的问题并给出属于敏捷化的解答。

**第一天下午**  

**蚂蚁金服专场**

下午分会场拉开帷幕，蚂蚁金服专场，第一个带来演讲的是蚂蚁金服高级专家、SOFAStack 开源负责人章耿（余淮）带来的”蚂蚁金服金融级分布式架构的10年演进之路“。蚂蚁金服技术专家罗其平（重岳）带来支付宝超大业务移动应用的弹性动态架构及智能运营实践。蚂蚁金服技术专家杨超（空弦）带来蚂蚁金服极速CI实践：分钟级运行30万测试用例；蚂蚁金服高级技术专家肖祎和国泰产险运维专家张君带来“互联网金融保险场景下云原生运维增效之道”。  

  

![](../Images/24f07f6643e6a7b009a97101d1234b2f.png)

**腾讯 DevOps 专场  
**

腾讯 微信 Android 基础优化团队负责人郭锐带来”十亿用户背后的秘密：微信 DevOps 实践过程中走过的哪些坑；腾讯蓝鲸产品中心总监 T4 工程师党受辉带来“研发运营一体化”的精彩演讲。腾讯蓝鲸 DevOps 平台负责人刘章雄带来“腾讯研发的 DevOps 实践”。腾讯蓝鲸容器平台及微服务项目负责人带来“容器技术对 DevOps 的助力”。

  

![](../Images/a3d9decfbf3329375c6e3fdbbfc6a388.png)

**DevOps 标准案例专场  
**

接下来是 DevOps 标准案例专场，招商银行总行信息技术部 DevOps 推广负责人 陈展文带来“打造金融科技之路：招行规模化 DevOps 落地之路”。中国移动广东有限公司网管支撑中级主管佟得天和华为 IT领域运维专家钱良健带来“DevOps for 5G：华为在广东移动通信网元敏捷上云的实践。”中国移动北京公司 DevOps 项目经理带来 5G时代：北京移动核心 BSS 系统在复杂环境下的 DevOps 实践。最后登场的是 DevOps 标准工作组核心评估专家牛晓玲、雷涛带来转型的灯塔：DevOps 标准认证评估权威指南及案例解读。  

  

![](../Images/70f45349fb94888f0266b2a3a3296c46.png)

**技术运营专场**  

DevOps 技术运营专场为大家带来 DevOps 标准新版 第4部分：技术运营的解读，首先由中国信息通信研究院云计算和大数据研究所牛晓玲老师带来“权威解读新版《DevOps 标准 第4部分：技术运营》；腾讯 T4 技术专家《技术运营标准》核心编写专家梁定安和京东商城前台技术负责人、《技术运营标准》核心编写专家徐奇琛带来技术运营的深度解读，两位专家分别解读了监控管理、配置管理、容量与成本管理、事件与变更管理、高可用管理、业务连续性。

  

![](../Images/32c98421d81bb56b84bf2fb6a7e608b2.png)

  

**精益敏捷专场**

精益敏捷专场首先由淘宝用户增长项目管理负责人张孙恩带来”双11淘宝增长的秘密，打造全链路敏捷团队。随后是NOKIA Transformation Owner 马林胜带来“经验与教训：详解诺基亚规模化敏捷案例”和菜鸟研发效能专家廖希密带来“菜鸟十亿包裹背后的研发效能”，最后是好未来 家长帮 PMO 赵兰兰带来“敏捷的好未来 - 百人团队实战攻略。”
