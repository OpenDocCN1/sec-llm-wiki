# 以标准的名义！DevOps 国际峰会 2019 · 北京站盛大开幕

2019 年是 5G 元年，2019 也是 DevOps 诞生的10年，DevOps 因其先进性和全面性，被认为是软件工程的第三次变革，在这个独具意义的一年，2019年7月5日，DevOps 国际峰会 2019 · 北京站在朝阳区悠唐皇冠假日酒店盛大开幕。

▼

![](../Images/f088348c70a576b6c1e9b72bd57c7d93.png)

  

DevOps 国际峰会是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导，DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。  

  

上午的主会场可谓精彩纷呈，首先开场的是本次峰会的“超级5分钟”环节，四位演讲嘉宾分别在5分钟的时间完成演讲。

▼

随后是主会场的第一场主题演讲，由中国信息通信研究院云计算和大数据研究所所长何宝宏博士带来：“互联网二十年，开源的“绿帽子”和技术的食物链”。

何宝宏博士的演讲幽默风趣、同时更具深度。  

▼

![](../Images/47f0e46f14105cd7e1924e859d8365af.png)

  

随后，中国信息通信研究院云计算和大数据研究所云计算部主任栗蔚女士带来“携手前行，企业级 DevOps 赋能（共促）计划”，为更好地促进中国企业实现组织级 DevOps 能力，打造一流的、端到端的 DevOps 持续交付流水线平台、提升组织效率与质量，让 IT 更好地支撑业务快速发展，由中国国信通院旗下云计算开源产业联盟联合开放运维联盟、国内外多家企业及专家力量共同发起的一项企业级 DevOps 赋能（共促）计划。

▼

![](../Images/da3470065493087a3a64d2ca1c4fc2b1.png)

  

一批国内顶尖企业加入本计划并在近千位观众面前荣耀的接受授牌。

  

主持人宣布此次加入企业级 DevOps 赋能（共促）计划的企业，分别是中国农业银行研发中心、中信银行股份有限公司、中国移动集团广东有限公司、中国移动集团浙江有限公司、国泰君安证券股份有限公司、国信证券股份有限公司、郑州银行股份有限公司、长沙银行股份有限公司、泰康保险集团股份有限公司。

高效运维发起人、DevOps 国际峰会发起人萧田国老师带来“DevOps 10年：3C 引领的新一代软件工程变革”的精彩演讲。听完萧老师的演讲，相信你会对 DevOps 的未来发展更具有信心。

▼

![](../Images/3d47c690aa8dc7dd3598c0ca32ba798d.png)

  

DevOps 是 IT 行业的热点，5G 是通信行业的热点，这两个热点相遇，会起哪些化学反应？在网络运维工作中，5G 为 CT 带来了 IT 特性，对运营商提出了要自研自维，能力内化的新要求。广东移动趁着建设 5G 的契机，探索 5G 的业务敏捷交付，将 DevOps 生产线延伸到通信网络，和华为公司一起探索出一条可行道路。

  

广东移动网管中心总经理孙剑骏带来“DevOps for 5G：广东移动与华为在 5G 落地中的 DevOps 探索。

▼

![](../Images/23fed6ebe9ff48cf8ea13c35568314c2.png)

  

  

蚂蚁金服资深技术专家、金融科技 PaaS 产品线负责人王磊（玉攻）带来“金融级平台即服务：打造技术中台拥抱金融科技创新”的精彩演讲。王磊老师从实际落地案例出发，分享蚂蚁金服金融科技对于 PaaS"平台即服务"的理解，全面解读蚂蚁金融科技的数字金融平台产品战略和实践。  

▼

![](../Images/76400bfc2f642bd5457c74c5c32f4025.png)

  

  

复旦大学软件学院副院长/教授彭鑫带来“基于代码大数据的软件开发质量追溯体系”精彩演讲。演讲中，老师详细介绍了软件开发质量追溯体系的含义及其应用场景、软件开发质量追溯的基本问题和技术困难以及如何基于代码大数据打造软件开发质量追溯方案。
