# 携手前行！企业级 DevOps 赋能（共促）计划最新一批成员公布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651678367&idx=2&sn=3bf41bd4223f03aa20030191983cea85&chksm=8bcba536bcbc2c20fc0e36f235d93532553f8a84ebf9099fda8b3159aa9a268b05b77a0ca4ac&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651678367&idx=2&sn=3bf41bd4223f03aa20030191983cea85&chksm=8bcba536bcbc2c20fc0e36f235d93532553f8a84ebf9099fda8b3159aa9a268b05b77a0ca4ac&scene=27#wechat_redirect)

2019年7月5日，也就是今天，2019 DevOps 国际峰会在北京正式召开，中国信息通信研究院云计算和大数据研究所云计算部主任栗蔚女士带来重磅演讲：“携手前行，企业级 DevOps 赋能（共促）计划”。

为了更好促进中国企业实施组织级 DevOps 能力，打造一流的、端到端持续交付流水线平台、提升组织效率与质量，让 IT 更好地支撑业务快速发展，云计算开源产业联盟联合开放运维联盟、国内外多家企业及专家力量，共同发起企业级 DevOps 赋能（共促）计划。

此次加入企业级 DevOps 赋能（共促）计划的企业，分别是：

*   中国农业银行研发中心
    
*   中信银行股份有限公司
    
*   中国移动通信集团广东有限公司
    
*   中国移动通信集团浙江有限公司
    
*   国泰君安证券股份有限公司
    
*   国信证券股份有限公司
    
*   郑州银行股份有限公司  
    
*   长沙银行股份有限公司
    
*   泰康保险集团股份有限公司

另外，DevOps 标准工作组成员单位也有新的进展，在 DevOps 国际峰会7月5日上午主会场上公布了最新一批加入 DevOps 标准工作组的成员单位，分别是：

*   大连华信计算机技术股份有限公司
    
*   浪潮云信息技术有限公司
    
*   苏州博纳讯动软件有限公司
    
*   普元信息技术股份有限公司
    
*   北京贝斯平云科技有限公司
    
*   北京云思畅想科技有限公司
    
*   苏宁消费金融有限公司

全球首个 DevOps 标准，即《研发运营一体化（DevOps）能力成熟度模型》，由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、 DevOps 时代社区联合 Google、BATJ、清华大学、南京大学、通信及金融等行业顶尖企事业单位专家共同制定。  

  

目前，DevOps 标准已在联合国直属标准化组织 ITU-T、中国通信标准化协会（CCSA）正式立项。
