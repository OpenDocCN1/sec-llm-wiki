# 云智慧作为金牌合作伙伴，荣耀参加 DevOps 国际峰会 2019 · 北京站

云智慧（北京）科技有限公司成立于2009年，是业内领先的智能IT运维服务商。云智慧以实现企业数字化运营(Make Digital Online)为使命，为用户提供专业的数字化运维产品和全栈智能业务运维解决方案，应用大数据和人工智能技术帮助客户构建DOCP数字化运维中台，全面支撑企业数字化转型和业务创新。

公司旗下业务有云智慧数字化运维中台 DOCP（Digital Operation Central Platform)、云智慧数字化运维数据平台（Digital Operation Central Platform）、云智慧数字化运维事件管理产品（DOEM，Digtital Operation Event Management）、云智慧数字化运维监控中心（DOMC，Digital Operation Monitor Center)等十几个产品。

云智慧智能化IT运维产品和解决方案体系通过把来自不同数据源的IT性能数据、告警信息、业务指标数据进行梳理、规范和关联建模，利用大数据和人工智能技术自动重构业务逻辑拓扑，实时追踪和分析系统异常对业务造成的实际影响，从而帮助企业找到亟需解决的根源问题。云智慧智能化IT运维关注的不是单纯的IT系统运行状态，而是以业务健康作为核心指标，采集、分析和管理企业数据，为业务决策提供有效的数据支持。

成立10年来，云智慧凭借优质的产品、可靠的服务和广泛的用户认可，获得了多家顶尖投资机构的支持，2013年获得戈壁创投A轮300万美元融资，2014年和2015年分别获得由红杉资本中国基金领投，戈壁创投跟投的B轮1500万美元和B+轮1200万美元融资，2017年5月获得由宽带资本(CBC)领投，海纳亚洲创投基金(SIG)、红杉资本中国基金跟投的C轮2600万美元融资。

目前，云智慧已累计服务银行保险、证券基金、航空航天、交通物流、电信能源、制造零售、房地产、互联网、政企、教育医疗等行业的几十万企业用户，是中国企业数字化转型首选的智能化IT运维服务商。

2019年7月5日至6日，DevOps 国际峰会 2019 · 北京站在北京悠唐皇冠假日酒店举行，云智慧作为金牌合作伙伴加盟本次 DevOps 国际峰会。

  

**关于 DevOps 国际峰会  
**

![](../Images/ea4373f90339c4810714a9933a454f4a.png)  

DevOps 国际峰会（DevOps International Summit，缩写：DOIS）是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导、DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

DOIS 大会是国内唯一覆盖 DevOps 全领域的技术大会，包括：精益与敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化。

DOIS 大会是国内外首个 DevOps 标准《研发运营一体化能力成熟度模型》（已在联合国ITU-T成功立项国际标准）的官方指定发布平台。

DOIS 大会为您呈现互联网大厂、海外名企和行业一流企业的实践案例与工具技术，聚焦 DevOps 在金融、通信等行业的系统性实践，不空谈、不务虚，专注 DevOps 落地。
