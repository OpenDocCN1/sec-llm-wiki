# DOIS 大会，玉符科技邀你一起踏云相会

作为国内唯一的国际性 DevOps 技术峰会，DevOps 国际峰会（DevOps International Summit，缩写：DOIS）承载着精益与敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化，目前是国内唯一覆盖 DevOps 全领域的技术大会。

![](../Images/3a32bac2aa154aa45533754791669786.png)

本月7月5-6号，DOIS 大会将共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。其中，玉符科技 CTO 陈伟嘉受邀参加题为“DevOps如何迎接不断蔓延的云安全挑战”的演讲。

据了解，陈伟嘉多年致力于面向未来的技术应用和实践，擅长于涵盖分布式系统、微服务架构、Web应用、机器学习。他在Facebook期间，曾利用大数据分析、智能语音识别技术，负责视频平台功能开发；在Splunk曾负责分布式集群的自动化调度和部署。

![](../Images/25de221d1d241e6f520ea860879e09e1.png)

**玉符科技 CTO 陈伟嘉**

陈伟嘉一直相信技术改变世界，关于DevOps，他将围绕三种不同的安全管理方式、代码安全、线上、应用安全三个实践要点等方面展开阐述。

他认为，安全性和易用性是鱼与熊掌不可兼得的两个方面，在新的技术趋势下，打破这两者的平衡，兼顾两者将成为推动 DevOps 全面发展的重要动力。

会上，他将与大家一起分享在面对不断蔓延的云安全挑战时，传统的服务和应用安全管控方式暴露出很多缺陷的情况下，作为 DevOps 甚至 DevSecOps 需要关注哪些方面，怎么配合开发甚至全公司一起进行安全实践。

大会将重点围绕探索技术风向、洞悉行业发展、共创新一代软件工程等方面展开，陈伟嘉介绍，玉符科技作为领先的企业身份管理（IAM）云服务商，将利用集成认证技术，帮助企业更好地应对云时代下复杂、繁琐的身份认证和权限管理。

他介绍，玉符科技将在新时代下，提供身份集成（UD），单点登录（SSO），账户生命周期管理（LCM）和安全审计（SA）产品及服务，为客户打造完整的企业身份信息管理体系，帮助企业降低成本、提升运维效率、增强业务协同性，进而提升企业身份的整体安全级别。

作为国内外首个 DevOps 标准《研发运营一体化能力成熟度模型》（已在联合国ITU-T成功立项国际标准）的官方指定发布平台。届时，DOIS 大会将呈现互联网大厂、海外名企和行业一流企业的实践案例与工具技术，聚焦 DevOps 在金融、通信等行业的系统性实践，专注 DevOps 落地。玉符科技将在DOIS 大会现场与您不见不散。
