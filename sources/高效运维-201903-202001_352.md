**《大型银行 DevOps 落地的最佳实践 》**

  

中国银行海外核心银行系统是基于IBM大型主机研发，安全稳定运行多年。在产品交付方面，通过建设工具链并不断完善，实现了持续集成、持续交付、用户反馈和系统优化的有机整合，为海外核心银行系统的高效开发与安全运行提供了可靠保证，探索了一条大型主机核心银行系统的DevOps践行之路。当大型主机核心银行系统遇到DevOps，大象会怎样起舞？随着产品的不断升级，DevOps平台也在迭代更新，全新的平台又会带来怎样全新的体验？

**《银行敏捷转型：基于微服务架构的 DevOps 实践  》**

  

光大科技在探索一条适合银行科技 Devops 之路中的一些经验：引入互联网敏捷实践先进理念的同时，重要节点保留传统金融行业对监管、流程方面的基本要求，同时优化繁杂的审批流程。 依托平台化、工具化、服务化的技术支撑，对所有项目均可灵活配置，支持项目多样化（多种开发投产模式，审批模式）。

  

基于微服务架构，设计需求管理，代码管理，流水线管理，组织管理四位一体持续联动的Devops一体化平台，同时流水线管理以插件设计方式支持编译，部署，代码扫描，单元测试等，并可对接行内各类第三方外购资源。对于构建数据，设计数据仓库，需求看板，全方位追溯项目质量，反推项目中的问题。

2019 DevOps 国际峰会·北京站

2019年7月5日-6日 北京市朝阳区悠唐皇冠假日酒店

DevOps 国际峰会（DevOps International Summit，缩写：DOIS）是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导、DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

DOIS 大会是国内唯一覆盖 DevOps 全领域的技术大会，包括：精益与敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化。

DOIS 大会是国内外首个 DevOps 标准《研发运营一体化能力成熟度模型》（已在联合国ITU-T成功立项国际标准）的官方指定发布平台。

DOIS 大会为您呈现互联网大厂、海外名企和行业一流企业的实践案例与工具技术，聚焦 DevOps 在金融、通信等行业的系统性实践，不空谈、不务虚

，专注 DevOps 落地。
