# 《2019年中国DevOps现状调查》全面启动

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651677998&idx=2&sn=6ba54e282f2f191daaf88cb62d133440&chksm=8bcba687bcbc2f91a3a50d53046d79e38ed2baf8afbea0cc7371ae6a5c67ec71df7ba8ffc80d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651677998&idx=2&sn=6ba54e282f2f191daaf88cb62d133440&chksm=8bcba687bcbc2f91a3a50d53046d79e38ed2baf8afbea0cc7371ae6a5c67ec71df7ba8ffc80d&scene=27#wechat_redirect)

![](../Images/69a2ce487e650f18c1ea7c3ab3c89129.png)

随着云计算、大数据、微服务架构和容器等新技术的高速发展，各组织纷纷投入巨资打造自己的DevOps生态链，希望可以借此提高交付效率，跟上市场快速前进的步伐。但是对自己DevOps实践的现状是否了解，对DevOps实践的成熟度是否有清晰的认知，业界亟需一个统一的标准作指导。由中国信息通信研究院牵头发起的《研发运营一体化（DevOps）能力成熟度模型》标准正好填补这一空缺。该标准分别从敏捷开发管理、持续交付、技术运营、应用设计、安全及系统和工具等几个环节，全面评估企业DevOps实践的现状，发现不足，并确定改进方向。  

目前，由中国信息通信研究院、云计算开源与产业联盟、华为与南京大学联合发起的《2019年中国 DevOps 现状调查》已经全面启动，本问卷聚焦中国本土DevOps实践成熟度现状，并根据问卷答案实时给出 DevOps 实践成熟度及状态分析。如果您希望实时得到您的组织实践DevOps 的现状及建议，同时了解国内其他企业实践 DevOps 的最新现状水平，请您如实填写问卷，以便调查能够捕捉到每个人真实的现状。

  

感谢您对我们研究工作的支持。无论您是刚刚开始 DevOps 之旅，还是已经是 DevOps 实践专家，我们都非常乐于聆听您的意见，您的见解对整个 DevOps 行业的发展非常有价值。回答该问卷大约占用您20分钟的时间。欢迎您将问卷推荐给您认为适合参加本次调查的专业人士。我们将于7月份正式发布《2019年中国DevOps现状调查报告》，每一位完整回答问卷的朋友都将第一时间免费收到最新的完整版调查报告。
