DevOps 成立的10年时间，

从最初诞生的名不经传到现在令人瞩目，星光熠熠

DevOps 打破开发、测试和运维之间的壁垒

如何把 DevOps 做到高大上，如何借鉴行业 DevOps 解决方案，与 DevOps 技术专家面对面交流？

7月5日，来自神州泰岳、博云、杰蛙和龙图游戏的资深技术专家为您带来企业级 DevOps 解决方案，不可错过~

1. 可汗之路 - 神州泰岳 DevOps 生态体系建设与实践

主题简介：DevOps 10年，从还是一个新兴名词发展到如今的令人瞩目，神州泰岳作为软件服务企业以切身实践见证 DevOps 的发展。在这个发展历程中，从迷茫到尝试、从闭门造车到主动分享、从群雄皆立到体系建设，神州泰岳以”可汗”为名建立公司统一 DevOps 生态体系。可汗之路以实践记录公司 DevOps 生态体系的建设历程，有汗水、有困难更有收获。经验分享希望与各位专家共勉。

- 群雄皆立，迷茫中探索软件研发效能提升之路
- 可汗之路，以”可汗”为名搭建统一DevOps生态体系
- 精益求精，数据驱动体系迭代发展


张凯（老K）
神州泰岳 云资源运营事业部 总经理

IT运维管理领域资深顾问，江湖人称老K，早年曾主导监控产品线的设计与开发工作。近10余年，致力于面向通信运营商IT建设和维护部门，提供一体化的IT运维管理解决方案，负责大型项目建设以及创新产品研发等工作。

目前担任神州泰岳云资源运营事业部总经理职位，打造基于CloudOps、DevOps和AIOps不同运维模式下的CMDB产品及创新应用。 因为相信IT技术的发展离不开运维体系的支撑，所以坚守这个行业；因为见证IT运维的发展历程深知苦与痛，所以致力于技术手段提升运维效率与质量；因为心怀助力运维的梦想，所以砥砺前行。

2. DevOps 在金融行业的管理流程和仪表盘设计分享

主题简介：DevOps 在落地过程中，有两个比较重点的方面：客户化流程设计、管理仪表盘设计。客户化流程主要涉及 DevOps 理念和客户实际组织在组织现状下的妥协和坚持。管理仪表盘设计主要解决开发管理过程可视化和数字化的问题，为整个团队和管理者提供数字化的DevOps 过程管控依据。博云将分享相关的经验。


赵安全
博云 产品总监

个人简介
赵安全，博云产品总监、高级解决方案架构师，在 IT 架构和云计算等领域有超过 12 年的丰富经验，认证 DevOps Master。先后负责过民生银行、江苏银行、佰仟金融、中石油等容器云 /Devops 项目的技术方案、架构设计、落地咨询等工作。对云计算、DevOps、分布式架构有深入的研究和理解。

3. 基于二进制包的 DevSecOps 落地实践

主题简介：

  1. DevOps 知识体系

  2. 源码 VS 二进制包

  3. 基于二进制包持续交付

  4. JFrog 内部持续交付之旅

  5. 二进制包安全管理

  6. 企业级 DevOps Scale Up


刘永强
JFrog 中国解决方案架构师

个人简介
JFrog 中国解决方案架构师，服务客户有华为，去哪网，宜人贷，顺丰等等，专注系统架构、软件 CI/CD 及 Devops 领域，曾在 HPE，亿玛等公司任高级工程师，负责过多个互联网平台和移动应用的研发和运维工作。

4. 游戏后台的容器化与 Kubernetes 实践

主题简介：游戏后台的开发与运营需要RPC服务框架与治理框架的支持，本议题将说明在结合开源项目TARS与Docker和Kubernetes的过程中的一些心得经验。

演讲提纲
简单介绍TARS在工作中的应用
介绍TARS docker镜像的构建历程及经验教训
介绍TARS上K8s的难点及解决过程
总结最佳实践
