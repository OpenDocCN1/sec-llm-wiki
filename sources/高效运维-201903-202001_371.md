# 揭秘新版技术运营标准

眼下，IT运维还处于“救火”模式，面对繁杂琐碎的运维工作，网络卡顿、电脑故障、系统瘫痪等等，IT运维工程师可以说是随叫随到，疲于奔命。

由中国信息通信研究院牵头、高效运维社区和 DevOps时代社区联合参与编写的运维行业标准，历时多年的打磨，汇集了国内众多运维专家的经验和智慧的结晶——“技术运营成熟度模型”。  

  

分别以六大技术运营的管理维度，提供可量化和可评测的运维能力成熟度检查项，供广大企业的运维同仁参考与自评，找准技术运营能力提升的路径。

  

![](../Images/3749087938f6a5bcee078c4d4a185cff.png)

  

每个管理维度下，将过程域逐层展开到评估维度：

![](../Images/27ad78addc3e5b96881836e63853a946.png)

  

各项技术运营能力评估维度被划分为五个成熟度，分别是**初始级、基础级、全面级、优秀级、卓越级**，五个阶梯式的技术运营提升的路径。

  

我们不能把命系在别人的裤腰带上，让业务质量强依赖于基础设施的可靠性是极不明智的。立足于技术运营的诉求，有计划、分阶段的提高运维能力，让业务架构越来越成熟，才是我们返躬内省，砥砺前行的正确方向。
