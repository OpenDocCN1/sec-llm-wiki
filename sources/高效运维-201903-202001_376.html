JFrog杰蛙科技是一家专注于端到端一站式DevOps解决方案的服务商，2008年成立于以色列，是中国信通院Devops/AIOps标准工作组成员单位。杰蛙科技开发了世界上第一个通用工件管理平台，开启了DevOps的新时代—“持续更新”。

JFrog杰蛙科技作为DevOps解决方案的领头羊企业，在过去十年里，已经在国际市场上得到了世界500强中93%企业的认可，包括谷歌、思科、Netflix、亚马逊、苹果、ING、微软、富国银行等5000多家企业先后成为杰蛙核心产品“Artifactory”的忠实用户。国内市场上，杰蛙也深受包括腾讯、华为、招商银行、小米、京东、滴滴出行、中国移动等种众多企业的青睐。

JFrog 一直致力于为客户提供领先的软件管理和分发通用解决方案，满足所有DevOps需求。

公司的四大产品包括：

  • JFrog Artifactory（通用工件仓库管理平台）：管理您的任何格式的二进制包，持续集成服务器和构建工具，以及 Docker 镜像中心，Maven，npm，PyPi，YUM，Ruby Debian 的通用平台。

  • JFrog Bintray（通用分发平台）：基于Akamai CDN的全球分发平台，兼容全语言和多种终端，灵活的策略和事件驱动，企业级的安全认证支持。

  • JFrog Mission Control（全球仓库管理）：为你所有的Artifactory节点提供视图，管理以及健康、可用性监控。从一个终端去控制全球的企业服务实例。

  • JFrog Xray（通用漏洞扫描平台）：提供一站式方案，不仅仅能够保护你的容器镜像，还可以保护所有的软件包，并且能和已有的漏洞数据库集成。

以上产品均可采用开源、私有云部署和SaaS云解决方案，客户遍布世界各地。

JFrog技术团队凭借丰富的开发以及运维经验，已经为全球多行业的企业提供了统一的持续交付解决方案和安全扫描通用的解决方案，为客户快速交付软件提供最强助力！

关于 DevOps 国际峰会 2019 · 北京站


DevOps 国际峰会（ DevOps International Summit，缩写：DOIS ）是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导、DevOps 时代社区与高效运维社区联合主办，共邀全球80余名顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

DOIS 大会是国内唯一覆盖 DevOps 全领域的技术大会，包括：精益与敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化。

DOIS 大会是国内外首个 DevOps 标准《 研发运营一体化能力成熟度模型 》的官方指定发布平台。

DOIS 大会为您呈现互联网公司与海外企业的实践经验与工具技术，聚焦 DevOps 在金融、通信、零售等行业的系统性实践，不空谈、不务虚，专注 DevOps 落地。
