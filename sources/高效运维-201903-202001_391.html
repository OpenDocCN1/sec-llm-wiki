DevOps 标准及中国 DevOps 技术力量亮相香港

2019年5月22～23日，香港会展中心，DevOps 时代社区携 DevOps 标准首次亮相香港，社区还邀请了四位 DevOps 专家共同参加 Cloud Expo 香港站 DevOps Live ! 专场并做精彩分享。

全球首个 DevOps 标准，即《研发运营一体化（DevOps）能力成熟度模型》，由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、 DevOps 时代社区联合 Google、BATJ、清华大学、南京大学、通信及金融等行业顶尖企事业单位专家共同制定。

目前，DevOps 标准已在联合国直属标准化组织 ITU-T、中国通信标准化协会（CCSA）正式立项。

截至目前，通过评级的企业分别是：浙江移动（三级）、中国银行（三级）、腾讯（四级）、招商银行（三级）、广东移动（三级）、北京移动（三级）、去哪儿网（三级）、郑州银行（三级）（按参评顺序）。

作为世界上最大的企业级专有云技术盛事（The Largest Dedicated Cloud Event for  Business）— 香港亚太云端科技博览会（Cloud Expo）汇聚了世界领先思想，来自不同行业的领导者和从业者在会议上分享他们多样的想法。

此次Cloud Expo，DevOps 时代社区邀请了景韵（DevOps 时代）、曾海剑（广东移动）、顾宇（埃森哲）、单致豪（腾讯 TARS）四位专家赴香港会展中心进行了 DevOps 相关技术分享。

景韵 - 转型的灯塔！基于 DevOps 成熟度模型的研发运营能力建设

DevOps，作为新一代软件工程变革的核心，被越来越多的互联网、金融、通信企业所接受。

DevOps 时代景韵首先分享对《研发运营一体化（DevOps）能力成熟度模型》对敏捷开发管理、持续交付、技术运营（自动化运维）、应用架构设计、安全及风险管理、组织结构、DevOps 工具等七大能力域进行了定义，帮助企业进行转型。

曾海剑（广东移动）- 外包模式下的 DevOps 进化史

本次演讲介绍了外包模式下广东移动的 DevOps 体系和平台如何从无到有的建立过程，以及在 DevOps 体系落地过程中遇到各种难题，如何通过 DevOps 体系不断进化和完善逐步解决生产中的难题。

顾宇（埃森哲）- 云原生 DevOps

随着云计算厂商和平台的日益成熟以及 SaaS 化应用的涌现，企业已经开始适应将数据中心迁移到云计算平台上，以充分享受云计算和互联网所带来的各种低成本的技术服务。

然而，云计算改变的不仅仅是工具。基于云计算的应用程序给企业级的 IT 研发和IT 运维带来了新的挑战。我们不能基于以往虚拟化数据中心的经验构建 DevOps 实践，而是需要充分利用云计算所带来的优势建立云原生的 DevOps 体系。

本话题从组织应用的安全框架出发。通过构建安全的流程和工具链协助企业打造够快速响应开发运维需要的组织和流程。通过采用全云端的开发运维工具和云计算服务构建无服务器（Serverless）的服务快速构建应用程序。

单致豪（腾讯）- Linux 基金会微服务开源项目 — TARS

TARS 是腾讯从2008年到今天一直在使用的微服务开发框架。该框架为用户提供了涉及到开发、运维以及测试的一整套解决方案，帮助一个产品或者服务快速开发、部署、测试、上线。它集可扩展协议编解码、高性能RPC通信框架、名字路由与发现、发布监控、日志统计、配置管理等于一体，通过它可以快速用微服务的方式构建自己的稳定可靠的分布式应用，并实现完整有效的服务治理。

本次主要介绍 TARS 的整体架构、演进过程及功能特性，以及TARS在2017年开源后成为Linux基金会开源项目，并支持多种开发语言和建设开源生态的过程。最后，讲述在各个行业大并发场景下的应用实践。

此次，《研发运营一体化（DevOps）能力成熟度模型》（DevOps 标准）首次亮相香港亚太云端科技博览会， 参会企业及专家对 DevOps 标准表现出极大的兴趣，得到不少香港本地和外国朋友的认可，为 DevOps 标准真正成为国际标准，迈向更重要的一步。

社区也借此机会将《企业级 AIOps 实施建议白皮书》和相关 DevOps 相关书籍作为礼品与大家一起互动，探讨 DevOps。
