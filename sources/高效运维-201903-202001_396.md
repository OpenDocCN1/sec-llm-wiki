 **课程介绍：**

  

Jenkins X 是 CloudBees 向社区推出的一个开源项目，目前属于 CDFoundation 的核心项目，它支持基于持续交付最佳实践在 Kubernetes 平台上快速创建，交付和编排云原生应用程序。

通过结合 Jenkins 和 Kubernetes 的强大功能，Jenkins X 项目为微服务和云原生应用程序的持续交付提供了强大的支持。

Jenkins X 基于 Jenkins 和 Kubernetes 及相关工具和软件，它提供了一个交互式命令行界面，用于实例化应用程序，存储库，环境和管道，并协调持续集成和持续交付。它是用于在 Kubernetes 上开发现代云应用程序的 CI / CD 解决方案。

我们将在培训中探讨如何使用容器，Kubernetes，Jenkins X 和其他一些工具创建一个完全可操作的连续交付流水线。
