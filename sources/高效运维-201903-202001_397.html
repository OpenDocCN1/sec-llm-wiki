飞雪连天做IT，笑书神侠代码间

《天龙八部》第四十三回，慕容氏父子，萧氏父子大战少室山，欲了结两代人的恩怨，无名扫地僧现身点化众人。



只见窗外长廊之上，一个身穿青袍的枯瘦僧人拿着一把扫帚，正在弓身扫地。这僧人年纪不少，稀稀疏疏的几根长须已然全白，行动迟缓，有气没力，不似身有武功的模样。


慕容复问道：“你躲在这里有多久了？”

    

那老僧屈指计算，过了好一会儿，摇了摇头，脸上现出歉然之色，道：“我……我记不清楚啦，不知是四十二年，还是四十三年。这位萧老居士最初晚上来看经之时，我……我已来了十多年。后来……后来慕容老居士来了。唉，你来我去，将阁中的经书翻得乱七八糟，也不知为了什么。”


萧远山大为惊讶，心想自己到少林寺来偷研武功。全寺僧人没一个知悉，这老僧又怎会知道？多半他适才在寺外听了自己的言语，便在此胡说八道，说道：“怎么我从来没见过你？”


那老僧道：“居士全副精神贯注在武学典籍之上，心无旁鹜，自然瞧不见老僧。记得居士第一晚来阁中借阅的，是一本《C++20天速成指南》，唉！从那晚起，居士便入了魔道，可惜，可惜！”



萧远山这一惊当真非同小可，自己第一晚偷入藏经阁，找到一本《C++20天速成指南》，知是少林派七十二绝技之一，当时喜不自胜，此事除自己之外，更无第二人知晓，难道这老僧当时确是在旁亲眼目睹？一时之间只道：“你……你……你……”


老僧又道：“居士第二次来借阁的，是一本《15天精通 Python》。当时老僧暗暗叹息，知道居士由此入魔，习武急功近利，更加愈陷愈深。于是老僧心中不忍，在居士惯常取书之处，放了一部《程序员修炼之道》、一部《计算机程序设计艺术》，只盼居士能借了去，研读参悟。不料居士沉迷于武学，于正宗佛法却置之不理，将这两部经书撇在一旁，找到一册《BATJ Python 面试必问100题》，便欢喜鼓舞而去。唉，沉迷苦海，不知何日方得回头？”



那老僧慢慢转头，向慕容博瞧去。慕容博见他目光呆滞，直如视而不见其物，却又似自己心中所隐藏的秘密，每一件都被他清清楚楚地看透了，不由得心中发毛，周身大不自在。


只听那老僧叹了口气，说道：“慕容居士虽是鲜卑族人，但在江南侨居已有数代，老僧初料居士必已沾到南朝的文采风流，岂知居士来到藏经阁中，将我祖师的微言法语、历代高僧的语录心得，一概弃如敝屣，挑到一本《运维甩锅指南》，却即如获至宝。昔人买椟还珠，贻笑千载。两位居士乃当世高人，却也做此愚行。”



慕容博心下骇然，自己初入藏经阁，第一部看到的武功秘笈，确然便是《运维甩锅指南》，但当时曾四周详察，查明藏经阁里外并无一人，怎么这老僧直如亲见？


只听那老僧又道：“居士之心，比之萧居士尤为贪多务得。萧居士所修习的，只是如何速成写好代码，慕容居士却将本寺七十二绝技逐步囊括以去，尽数录了副本。想来这些年之中，居士尽心竭力，意图参透 DevOps 之奥秘，说不定已传授于令郎了。”


他说到这里，眼光向慕容复转去，只看了一眼，便摇了摇头，跟着看到鸠摩智，这才点头，道：“是了！令郎年纪尚轻，武学造诣不深，恐难领悟 DevOps 之理念，原来是传之于一位吐蕃高僧。大轮明王，你错了，全然错了，你想自己搭建 DevOps 平台，却又次序颠倒，大难已在旦夕之间。”



鸠摩智从未入过藏经阁，对那老僧绝无敬畏之意，冷冷地说道：“什么次序颠倒，大难已在旦夕之间？大师之语，不太也危言耸听么？”


那老僧道：“不是危言耸听。本派 DevOps 武功传自帕特里克（Patrick）“老祖”。打造 DevOps 体系时，务须精通敏捷开发、持续交付、安全及风险管理等理念。倘若不以此为基，则打造之时，必定困难重重。IT 系统结构越复杂，难度越大。如所搭建的只不过是小规模 DevOps 流水线，那也罢了，对自身危害甚微，只须脑子灵活，尽自修复的来……”


那老僧继续说道：“但如搭建的是大规模金融级 DevOps 体系，例如银行、证券之领域，不以安全及风险管理等理念加以修正，则很容易会出现重大安全漏洞，比之任何BUG都要厉害百倍。大轮明王原是我专业弟子，精研开发，测试，运维武学，当世无双，但如不存精研理论之念，虽然典籍淹通，妙辩无碍，终不能领悟 DevOps 之奥妙。”



鸠摩智寻思：“少林寺的七十二绝技让慕容先生盗了出来，泄之于外，少林寺群僧心下不甘，却又无可奈何，便派一个老僧在此装神弄鬼，想骗得外人不敢练他门中的武功。嘿嘿，我鸠摩智哪有这么容易上当？”


忽听得嗤、嗤、嗤三声轻响，响声过去更无异状。玄因等均知这是本门“《黑客秘笈：网络渗透实用指南》”的功夫，齐向鸠摩智望去，只见他脸上已然变色，却兀自强作微笑。


原来鸠摩智越听越不服，心道：“你说少林派七十二项绝技不能遍学，我不是已经学会不少？怎么又没神经错乱，成为民科？”双手拢在衣袖之中，暗暗使出“《黑客秘笈：网络渗透实用指南》”，神不知、鬼不觉地向那老僧弹去。


不料 DDoS攻击包甫及那老僧服务器之处，便似遇上了一层柔软之极、却又坚硬之极的屏障，嗤嗤嗤几声响，攻击包散得无形无踪，却也并不反弹而回。鸠摩智大吃一惊，心道：“这老僧竟然使用了隐藏源站IP大法，果然有些鬼门道，并非大言唬人！”



那老僧又道：“本寺七十二绝技，均分‘体’、‘用’两道，‘体’为内力本体，‘用’为运用法门。萧居士和慕容居士本身原有上乘内功根柢，来本寺所习的，不过是七十二绝技的运用法门，虽有损害，却一时不显。大轮明王曾练过‘高效运维’的‘《DevOps 三十六计》’吧？”


鸠摩智又是一惊，自己偷学‘《DevOps 三十六计》’，从无人知，怎么这老僧却瞧了出来？但随即释然：“虚竹适才跟我相斗，使的便是《DevOps 三十六计》。多半是虚竹跟他说的，何足为奇？”便道：“‘DevOps’虽非源出中原，但近日中原习者亦多，演变之下，已集众家之所长。即是贵寺之中，亦不乏此道高手。”



那老僧微现惊异之色，说道：“少林寺中也有人会‘《DevOps 三十六计》’？老衲今日还是首次听闻。”鸠摩智心道：“你装神弄鬼，倒也似模似样。”微微一笑，也不点破。那老僧续道：“《DevOps 三十六计》高深莫测，凝聚国内外众多 DevOps 领域专家智慧结晶，以此为根基，本寺的七十二绝技，倒也皆可运使。”


那老僧又道：“明王若只修习少林派七十二项绝技的使用之法，其伤隐伏，虽有疾害，一时之间还不致危及本元。可是明王此刻‘服务器’报警不断，‘业务端’网络十分不稳定，‘投诉电话’框框作响，种种迹象，显示明王在练了少林七十二项绝技之后，又欲霸王硬上弓，强行去搭建那 DevOps 平台“，他说到这里，微微摇头，眼光中大露悲悯惋惜之情。



那老僧见他脸上初现忧色，但随即双眉一挺，又是满脸刚愎自负的模样，显然将自己的言语当做了耳畔东风，轻叹了口气，向萧远山道：“萧居士，你近来上线服务时，可经常遇到业务不稳定？”


萧远山全身一凛，道：“神僧明见，正是这般。”那老僧又道：“你每天服务器的宕机，近来却又如何？”萧远山更是惊讶，颤声道：“这宕机十年前只每月一次，现下……现下几乎每天一次了。”



萧峰一听，知父亲服务器现出这般迹象，系强练《15天精通 Python》所致，从他话中听来，这征象已困扰他多年，始终无法驱除，成为一大隐忧，当即上前两步，双膝跪倒，向那老僧拜了下去，说道：“家父病根已深，还祈慈悲解救。”


那老僧道：”要化解萧居士的病痛，还需对症下药，寻求开发、测试、运维诸多专家的指导答疑解惑。如果施主真心求教，老衲奉劝各位施主前去 2019年7月5日举行的 DevOps 国际峰会·北京站以求良药...“



2019 DevOps 国际峰会·北京站

2019年7月5日-6日 北京市朝阳区悠唐皇冠假日酒店


DevOps 国际峰会（DevOps International Summit，缩写：DOIS）是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导、DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

DOIS 大会是国内唯一覆盖 DevOps 全领域的技术大会，包括：精益与敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化。

DOIS 大会是国内外首个 DevOps 标准《研发运营一体化能力成熟度模型》（已在联合国ITU-T成功立项国际标准）的官方指定发布平台。

DOIS 大会为您呈现互联网大厂、海外名企和行业一流企业的实践案例与工具技术，聚焦 DevOps 在金融、通信等行业的系统性实践，不空谈、不务虚，专注 DevOps 落地。
