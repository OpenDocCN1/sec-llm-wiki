DevOps 年度调研，对于 DevOps 在中国的发展有着里程碑的意义。所幸，一群有心人为中国 DevOps 社区做了这样有价值的事情。2019年度《DevOps 中国 · 年度调研》正式开始，高效运维社区和 DevOps 时代社区觉得“推波助澜”责无旁贷。

南京大学、DevOps 中国社区期望借由这份问卷，收集 DevOps 的率先实践者们关于 DevOps 实践及相关的信息，从而了解 DevOps 在中国的概况和最新进展，并从收集的数据中分析总结出在 DevOps 实践中可能遇到的障碍与挑战、最佳的实践以及 DevOps 可以为组织及每一位从业人员带来的变化。

我们期望通过调查报告让 DevOps 在中国获得进一步的推广，让更多的组织和团队了解 DevOps，分享 DevOps 的经验，同时，也为 DevOps 的每一位实践者提供有效指引和帮助。

这份问卷是匿名的，调查结果只用于统计、分析和生成最终的报告，我们将确保不会泄漏每一位受访者的相关信息。同时，为了确保 DevOps 调查报告的可信度，我们也衷心的希望每一位受访者能够如实的回答每一个问题，再次感谢您的支持和参与！
