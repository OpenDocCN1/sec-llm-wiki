运维开发工程师（基于k8s的ES搜索服务和ELK方向）


工作职责

1. 集团所有ES目前都基于k8s和物理机构建，要求应聘者同时具备k8s和es，elkb的工作背景 

2. 负责elasticsearch集群的方案架构，问题追踪，性能优化，支持项目组应用等负责基于kibana的运维数据可视化，报表/仪表盘/监控的开发

3. 负责项目数据的接入和整理,数据生命周期管理

4. 负责es集群的日常支持和维护

5. 熟练掌握python，helm，ansible 

6. 参与ES云PAAS服务的开发工作


任职要求 

1.精通ES查询表达式(Query DSL)和通正则表达式, 能通过logstash/beats/ingest node对文本进行整理和提取. 

2. 精通kibanna可视化，熟练定制图表和仪表盘，canvas 

3. 精通es的生命周期管理，能够设计和实施异地多集群的同步和复制. 

4. 熟悉k8s，helm，ansible，自动化日常运维和管理工作 

5. 熟悉python，有良好的编码习惯，参与Paas平台的开发和维护 

6. 2年以上大规模ES集群的运维支持工作经验 

7. 有良好的文档习惯, 乐于分享. 


如方便可在简历中附上个人github地址或技术博客。


SRE工程师

任职要求

1. 3年以上互联网运维支持工作经验 

2. 精通lvs，nginx，haproxy 对4层和7层负载均衡高并发场景有较深入的理解和实际解决问题的经验。 

3. 精通centos/rhel/ubuntu（至少精通其中之一）运维管理和调优 

4. 熟悉kong、Zuul、traefik等GATEWAY开源体系，并有过实际应用经验。 

5. 熟悉Nginx 以及 Openresty，有过nginx模块开发经验，熟悉 Lua 语言，能结合 ngx-lua 模块来进行相关业务开发更好。 

6. 熟悉HTTP协议，了解RestFul api思想 

7. 熟练掌握shell/python，熟悉ansible/saltstack，能够自动化日常运维工作。 

8. 熟悉MySQL等数据库。熟悉Redis等缓存服务。熟悉ELK体系。 


职责描述

1. 负责维护管理负载均衡、CDN加速平台业务，提升接入质量和接入可靠性，自动化管理和调度流量。 

2. 负责维护API GATEWAY平台，制定API接入规范和熔断策略，优化GATEWAY性能，根据需求迭代GATEWAY架构和版本。 

3. 负责分析流量层数据，输出API质量和性能服务数据，制定API性能指标规范，以此推动后端API服务的优化。 

4. 支撑应用部署团队，为其提供更加便捷的测试和发布环境，在服务发现、DNS注册、流量转发等方面提供自动化手段。


资深运维工程师


岗位职责 

1. 负责Linux平台持续交付、服务配置、安全加固、故障处理等工作； 

2. 负责线上生产环境及测试环境的服务器和其他相关设备的日常维护工作； 

3. 负责保障系统层面的稳定运行，有能力处理突发事件、对疑难问题进行跟踪并最终解决并善于归档； 

4. 负责系统层面基础架构的规划设计，发现生产环境中的问题和隐患，持续优化改进工作； 

5. 负责相应加班或者值班工作；   


任职要求 

1. 3年以上相关工作经验，计算机或者相关专业优先； 

2. 熟悉Linux系统，了解网络基本技术，熟悉TCP/IP协议工作原理； 

3. 熟悉shell，熟悉python/perl/powershell脚本语言的一种以上； 

4. 熟悉至少一种配置管理工具者，如saltstack/puppet/chef； 

5. 熟悉大型互联网公司架构，熟悉Nginx，Redis，消息队列，分布式服务调用框架等基础组件； 

6. 熟悉常规业务架构，熟悉tomcat、php、mysql、apache等服务； 

7. 熟悉直播工作流程，熟悉直播相应rtmp、udp协议规则； 

8、对Docker有深入研究；有大型集群维护； 

9、责任心强，积极主动，热爱学习，有良好的沟通能力和团队合作能力。


大数据实时计算架构师

 任职要求 

1. 本科及以上学历，5年以上大数据项目经验； 

2. 精通大数据实时计算平台架构及相关项目标准，能够根据数据及业务需求构建大数据实时计 算平台，并随着需求和技术的进步，不断演进； 

3. 精通Java、Python中的一种或多种编程语言； 

4. 深入理解大数据实时数据处理如：流计算、分布式计算、分布式存储等相关技术和实现方法， 具备独立沟通需求，设计，架构的能力 

5. 精通Hadoop生态技术栈、Druid 、Hive、Hbase、Spark、Presto、Impala、HAWQ等大数据解 决方案； 

6. 精通至少一种大数据实时计算处理引擎，如：Storm、Spark streaming、Flink； 7、具有较强的文档编写能力，能够按照公司要求编写大数据架构设计文档. 


职责描述 

1、 负责大数据实时计算平台可扩展性架构设计、高可用性环境及撰写相关文档等工作。 

2、 收集项目大数据实时计算需求和接口开发工作。 

3、负责大数据实时计算平台整体资源合理规划、性能优化、故障处理。 

4、制定新东方大数据实时计算平中数据质量、数据信息安全以及监控管理方案； 

5、对大数据实时计算平台框架技术预研和培训，负责为开发团队进行技术指导和问题解决.
