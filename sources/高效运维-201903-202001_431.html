东软成为 DevOps 标准工作组成员单位

第十二届 GOPS 全球运维大会于 2019年4月12日-13日在深圳召开。作为国内首个运维行业大会，GOPS 全球运维大会已举办十二次，大会参会嘉宾累计突破 4 万人次，是国内最大规模的高端运维盛会。

本次大会汇聚了全球顶级专家、业界知名企业等共同探讨运维领域的技术发展与案例实践。凭借在 DevOps 领域的深入研究与贡献，东软被授予 DevOps 标准工作组成员单位。

DevOps 标准由中国信息通信研究院牵头，云计算开源产业联盟(OSCAR联盟)、高效运维社区和 DevOps 时代社区联合国内华为、东软等一线互联网企业、通信、金融等行业顶级单位及专家编写而成，是国内外首个 DevOps 标准。此标准已在中国通信标准化协会(CCSA)以及联合国直属标准化组织ITU-T正式立项。

DevOps 包含三个要素：开发(Dev)、测试(QA)和运维(Ops)，这种极具吸引力的技术框架旨在加强软件开发人员和运维人员的沟通合作，通过自动化流程来使得软件构建、测试、发布更加快捷、频繁和可靠。这种 IT 工具链的打通促进各团队更加高效地协同工作，良好的闭环可以大大增加整体的产出，从而使软件开发到交付的各阶段都实现真正意义上的敏捷。

运维的黄金时代即将到来，东软作为国内领先的 IT 解决方案提供商，始终关注热点技术的发展与实践。目前，东软有一整套从需求、设计、开发、测试到运维的一体化 DevOps 工具链及实施方法论，能够做到持续开发、持续部署、持续运维。此外，东软参与 DevOps 标准，将与业界一同帮助用户了解自身所处的 DevOps 能力成熟度位置，清晰未来的改进方向，实现 DevOps 技术在用户 IT 环境的落地，为企业带来更多收益及价值。

目前，DevOps 标准持续交付能力第三批评估开始报名啦~
