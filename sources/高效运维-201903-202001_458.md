快来 DevOps 国际峰会找答案

  

还记得2018年6月29日的 DevOps 国际峰会·北京站吗？作为国内本土成长起来的唯一国际性 DevOps 技术峰会。DOIS 大会覆盖 DevOps 全领域技术，包括：精益与敏捷、持续交付/自动化测试、技术运营、高可用架构与微服务、DevSecOps、组织与文化。

  

DOIS 大会将为您呈现互联网大厂、海外名企和行业一流企业的实践案例与工具技术，聚焦 DevOps 在金融、通信等行业的系统性实践，**不空谈、不务虚，专注 DevOps 落地**。

时隔一年，2019年7月5日-6日，DevOps 国际峰会再次走进帝都

  

![](../Images/5a3c6ae5901c67a63c3d64a9dbc51d3d.png)

  

DevOps 国际峰会（DevOps International Summit，缩写：DOIS）是国内唯一的国际性 DevOps 技术峰会，由 OSCAR 联盟指导、DevOps 时代社区与高效运维社区联合主办，共邀全球顶级专家畅谈 DevOps 体系与方法、过程与实践、工具与技术。

  

**五大亮点  
**

  

![](../Images/16b2fa487b86c81f1a8770bb670d5469.png)

  

**灯塔：**DevOps 标准官方第一手全新发布，作为国内外首个 DevOps 标准《研发运营一体化能力成熟度模型》（已在联合国ITU-T成功立项国际标准）的官方指定发布平台。你将在 2019 DevOps 国际峰会·北京站上看到最新的 DevOps 标准进展以及评估结果公布、案例解读。标杆企业还将现身说法。

  

**思考：**996 带来给我们什么？企业应该拼时间还是拼效率？各大名企专家告诉你答案，通过 DevOps 对企业IT 效能带来提升，这才是正解。

  

**案例：**聚焦 DevOps 在国内外互联网、金融、通信等行业的实践与落地案例，取长补短、融会贯通，在这里，你可以看到同行是如何开展工作的，同时也可以学习到顶尖互联网公司的 DevOps 落地经验。

  

**深度：**来自国外 Google、Facebook，国内 BATJ 等名企为你现身说法。一起深挖一线大厂的 DevOps 落地的秘密。  

  

**风向：**探索技术风向，洞悉行业发展，共创新一代软件工程。
