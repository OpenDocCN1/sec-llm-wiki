是的！为期两天，1500余人签到的 GOPS 2019 · 深圳站圆满结束！

与以往相比，此次大会最有特色的地方有哪些？有哪些精彩议题？参会的同学听得嗨不嗨？

是的。除了依旧星光璀璨的讲师阵容，硬到不行的技术干货（技术专场真的没有广告啦）以及 GOPS 依旧贴心的服务，本次大会还有超多新颖之处。⬇️

  

**【大会第一天主会场】**

首先开场的就是本次大会既紧张又刺激的超级5分钟，所有演讲嘉宾须在5分钟内将主题表达清楚，并且引起全场观众的喝采，参加超级5分钟的四位嘉宾分别为阿里巴巴基础设施事业部基础专家菅晓翔，中国银行数据技术专家刘扬清，中国移动广东公司网管支撑业务主任黄倚霄，百信银行首席技术架构师张真。下次 GOPS，期待您的挑战！

本次大会上，萧田国发布了企业级 AIOPS 实施建议白皮书 V1.0 及新版技术运营标准。

![](../Images/c15f3af53246142fe45e71d8c5c56936.png)

![](../Images/d6dde433cd0f2834edb650b83f615cc8.png)

本次大会还有其他诸多重大事项发布，第一件重大事项就是企业级 DevOps 赋能（共促）计划的重磅发布。为更好促进中国企业实现组织级 DevOps 能力，打造一流端到端持续交付流水线平台、提升组织效率与质量，企业级 DevOps 赋能（共促）计划由云计算开源产业联盟、开放运维联盟联合国内外、行业内外及专家力量，一经发布便获得国内外顶级企业的纷纷响应。  

首批加入单位包括如工行、平安、招行、中行、京东、腾讯、北京移动、联通软研院、安信证券、海通证券、华泰证券、百信银行、戴姆勒、上汽出行和中航信等（按照行业及公司名排序）。

▲中国信通院云大所何宝宏所长（右一）为首批企业级 DevOps 赋能（共促）计划参与单位授牌仪式  

第二件隆重的事项就是中国民航信息集团运行中心戚前方部长为 GOPS 手书的《运维骆驼》题词捐赠仪式。  

![](../Images/1792d9322c03301febec493ca93f3d72.png)

2019 年新的一年，好事不断，DevOps / AIOps 标准工作组又增加一批新的单位，众多互联网、金融、通信名企纷纷加入 DevOps / AIOps 标准工作组，此次又新增了9加单位，这对于 DevOps / AIOps 的发展又前进一步。

![](../Images/4df50837068ffd86a1d32888c8c1538a.png)

![](../Images/970b0233ba89d7e096954a283bf5816c.png)

▲ DevOps / AIOps 标准工作组成员单位授牌仪式

大事当然不止一件，全球首个 《研发运营一体化（DevOps）能力成熟度模型》，即DevOps 标准第二批正式通过评估单位新增了北京趣拿软件科技有限公司（去哪儿网）和郑州银行股份有限公司，我们在此祝贺这两家企业。  

去哪儿网的综合评定结果为所有已评测企业中的 TOP 3。郑州银行在2018年9月即已全身心投入到 DevOps 标准评测工作中来。另外还有其他6家企业因为商务流程过长等原因，未能赶得上本次授牌。我们2019年7月的授牌典礼上再相见~  

> 另外已通过 DevOps 标准评测的企业包括中国银行、浙江移动、腾讯、招商银行、广东移动和北京移动（以时间为序）。
