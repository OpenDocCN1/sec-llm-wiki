**招行如何基于 K8S 建设支持多种技术栈的 DevOps 流水线**

![](../Images/08918df50164128ed15d4176b7f93000.png)

**陈展文**

招商银行总行信息技术部

DevOps 推广负责人

**个人简介**：在招行服务15年，伴随着招行信息技术部从 200 多人发展到现在 4000 多人的规模，获得了PMP、CSM、CSPO 认证。从推动配置管理工具 firefly 起步，全程参与 CMMI 三级体系的建立和认证，牵头招行CC、CQ、BuildForge、RTC 和 Git 等全平台配置管理工具的落地实施。2015年开始牵头研究和推进 DevOps 持续交付实践落地，更好地支撑招行的精益化转型。2018年参加 DevOps 国际峰会 2018 · 深圳站主题演讲，获评金牌讲师。

  

**主题简介**：企业级持续交付平台的建设，面临诸多现实困难和痛点。要适配组织IT发展现状及技术背景，既要勇于创新支持IT技术架构升级，也要稳健兼容各类复杂场景。2017 年招商银行总行 IT 部门打造了基于K8S的持续交付流水线平台，打通研发工具链，利用容器技术实现了资源的动态化和标准化，在此基础之上，也实现了非容器化场景（如.NET Framework技术栈）的支持。本次演讲主要分享招行在落地 DevOps 流水线平台的一些思考和实践，希望与大家交流。

  

![](../Images/2a2a404d0f59d26138594d0ee86587ba.png)

**谢沁沐**

招商银行成都软件中心 研发工程师

**个人简介**：招商银行DevOps持续交付流水线平台开发负责人，先后从事容器集群运维、持续交付平台设计/开发等相关工作，曾参与多个企业级CI/CD平台设计与实施。专注于容器技术、持续交付实践、研发效能等领域。  

  

  

**十年磨一剑：qunar DevOps 生态体系建设之路**

  

![](../Images/3699aa0b043e8b91b16807278239ae2b.png)

**王晓翔**

去哪儿网 高级总监

**主题简介：**DevOps 倡导的是一种文化，通过消除部门壁垒，让开发、测试、运维之间的沟通更加顺畅；是一种能力，开发工程师也可以胜任服务运维的能力；是一个平台，提供各种自动化工具的平台。然而， 一个企业要落地 DevOps，更是一个系统工程。Qunar 工程效率团队联合基础组件、运维团队，历史2年时间在 Qunar 内部成功落地 DevOps，并打造了一个蓬勃的 DevOps 生态，实现了以应用为中心的全生命周期管理的目标，大大提高了公司整体的研发效率。我会从 Portal 平台的设计理念、业务模型，以及系统架构逐层展开，与大家分享 Qunar 的 DevOps 实践之路。

  

**个人简介**：2013 年加入去哪儿，现任平台事业部工程效率组高级总监。在软件配置管理、过程管理和工程效率方面有十多年的工作经验。曾在中国海关数据中心, 索尼移动通信产品(中国)有限公司等多家公司工作。在去哪儿网供职五年间，逐步构建起了持续集成、持续交付流水线，形成以应用为中心的全生命周期管理体系，并通过 portal 平台不断为研发团队赋能，共建 Qunar 的 DevOps 生态圈，同时带领团队完成了从传统配置管理到工程效率团队的转型。
