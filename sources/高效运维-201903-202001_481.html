支撑滴滴快速发展的代码工具链演进史


杨永强

滴滴出行 代码团队技术负责人

主题简介：滴滴一直在打造适合公司快速成长的代码工具链，从底层的代码托管服务的分布式改造到上层自研系统的建设：代码审查，代码扫码以及代码检索等均已在滴滴内部大规模使用并支撑了每天百万次的代码迭代和验证。另外，我们也基于 LSP 协议自研了滴滴自己的云端 IDE 并且与公司的研发工具链实现了打通，形成了一站式的云端研发平台，给工程团队带来了全新的研发体验。本次演讲主要是对各个自研系统的设计方案，系统架构以及关键技术分别进行展开介绍，希望能通过本次演讲能和大家一起交流一下在代码生态链建设下我们踩到的坑和获得的经验。

个人简介：2015年加入滴滴，先后负责了滴滴内部持续交付平台的建设，代码托管服务(git)的分布式改造，自研CR系统（鲲鹏）的研发和推广，代码扫描平台化的改造以及云端IDE的探索等多个研发工具项目。热衷系统架构和新技术尝鲜，作为 golang 的布道师，顺利完成团队 golang 技术栈的切换。目前是代码团队的技术负责人，专注于研发工具链的建设和研发效能的提升。


华为云性能调优解决方案架构解析


刘毅

华为云测试架构师

个人简介：在华为一直从事华为云平台的测试及测试架构设计工作，经历了从传统CT领域到云服务产品领域的测试流程、测试技术的变革，在测试质量体系构建、测试设计、测试服务平台构建等领域有较深入的理解。


日调用量数万亿次：腾讯分布式缓存最佳实践


山宝银

腾讯后台高级工程师

个人简介：山宝银，腾讯后台高级工程师，专注于分布式NOSQL存储领域的技术研发工作，参与腾讯多个自研存储系统的开发，在分布式系统、高可用、高性能服务等领域有较丰富的经验。


主题简介：DCache 是腾讯自研的分布式内存型 NOSQL 存储系统，主要用于高性能分布式缓存。该系统支持k-v，k-k-row，list，set，zset 多种数据结构，具备快速水平扩展能力。目前，腾讯内部近百个业务在使用 DCache，日调用总量超数万亿次。此次分享将介绍 DCache 的主要功能、应用场景以及整体架构和设计思路。


基于分库中间件的 SQL 改造指南


孙正方

爱可生资深开发工程师

个人简介：任职上海爱可生信息技术股份有限公司，开源项目DBLE核心研发成员，拥有丰富的数据库中间件开发、咨询以及调优经验。擅长数据库中间件问题的排查和处理，对于线上中间件部分排错有深入的实践与认知。

主题简介：本人拥有多年的分布式中间件的开发和调优经验；结合各大金融和互联网项目的实战经历，讲讲基于分布式中间件的 SQL 改造的最佳实践；希望通过分享 SQL 语句的改造方法和实施原则，给大家在解决 MySQL 大容量、大并发等分布式场景提供参考。


非容器项目如何进行 kubernetes 改造


王青

JFrog 中国首席架构师

个人简介：JFrog 中国首席架构师，之前在 IBM，HPE，爱奇艺，新浪，VIPKID 等公司做过研发和架构，是有十多年开发经验的互联网老兵，专注于软件生命周期管理，微服务架构，云原生应用，容器化等领域。


主题简介：将应用、微服务部署到 Kubernetes 环境里真的是像想象当中那么轻松、简洁吗？Kubernetes is hard！在 Kubernetes 中部署和运行应用，并不是那么简单。JFrog 通过 Kubernetes 的实践，目前可以做到每周自动化部署100+的不同产品线、任意版本组合的测试环境，而每个环境都要部署50+的微服务，大大提高研发进行自我验证的效率，提升的软件交付的速度。

在达到这样的部署规模的过程中，我们遇到了很多的问题，也积累了很多的经验和教训。在这次案例分享当中，我将基于JFrog自身落地实践的总结，介绍 JFrog 是如何从准备开始，一步一步实现应用在 Kubernetes 环境中的成功部署的。
