这三个月里，朋友圈里充斥着 年终奖、996、裁员、不再是兄弟、金三银四如何跳槽的信息。  

最让小编无力吐槽的就是各种招聘信息上写的“35岁以下”，难道35岁以上的人都不用换工作吗？

终于有一天，在某群看到一条招聘信息：“某国企（金融）招CTO，要求40—45”。

小编终于知道35岁以上IT从业者的归宿，原来是CTO。

小编立马萌生写一本书的念头，书名就叫《人人都是CTO》。

小编很想说：”去他的35岁，我学习，我怕啥？“

我要做一辈子技术！

学习一门新语言

学习一种新框架

学习一个新工具

学习一种新方法

因为我学习，无论是”不把我当兄弟“还是”35岁以下“，我都不怕！

 **DevOps 转型必修课**

DevOps 落地，需要体系化的标准、方法、实践与工具，更需要建设度量能力和学习型组织，本系列课程让您在 DevOps 落地中掌握先机与 DevOps 快速落地的方法。

**1、企业级 DevOps 立体化实施框架**

由国内研发运营一体化成熟度模型（DevOps 标准）核心专家基于标准内容研发，深度讲解DevOps全领域知识和案例。

**2、DevOps 落地实践、组织变革过程与转型策略**

由台湾精益敏捷老专家 李智桦老师亲自授课，讲述DevOps 三步工作法、看板方法以及老师多年的企业敏捷实践经验。

  

 **Jenkins X Workshop**

Jenkins X 正式发布后，所有新特性你都了解了吗？要想把 Jenkins X 玩的高大上，那就来参加我们的 Jenkins X Workshop 吧。作为一个高度集成化的CI/CD平台，Jenkins 与 Kubernetes 的完美结合后，Jenkins X 能给持续交付带来了新的可能，Jenkins X 重新思考了未来云原生应用下研发工程师和 CI/CD 的交互方式，通过整合工具，自动化和 DevOps 最佳实践，改善了研发过程中的复杂环节，让研发可以专注于价值创造，其他的事情通通交给 Jenkins X 来帮你解决。

**1、Jenkins X 实战工作坊**

由国内外Jenkins X 核心开发者和专家亲自授课，指导你一步步掌握Jenkins X。

**2、Certified Jenkins Engineer**

由国内资深的Jenkins专家授课，帮助你掌握Jenkins的必备技能，还能获得Jenkins创始人KK签署的认证Jenkins工程师证书。
