# 中国移动研究院诚聘持续集成、持续测试专业人才

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651688499&idx=5&sn=c472d2e452d383a0ca45ce57beed4243&chksm=8bcb4d9abcbcc48c220c41a11488569b8452e6b153a05da81716e03eef18c0475f13fe9603f6&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651688499&idx=5&sn=c472d2e452d383a0ca45ce57beed4243&chksm=8bcb4d9abcbcc48c220c41a11488569b8452e6b153a05da81716e03eef18c0475f13fe9603f6&scene=27#wechat_redirect)

![](../Images/ee79aca37bf59c4287dee79b22116ddc.png)网络的 IT 化和云化转型已经成为全球通信产业公认的技术发展趋势，这其中不仅包括云计算相关技术的引入，也包括 DevOps 等研发运维模式的变革。中国移动目前已经启动全球规模最大的网络云建设，为应对开放解耦后多厂商集成过程中周期长、问题多、成本高等问题，中国移动研究院组建了专业的集成交付技术团队。截至目前，团队通过定义跨厂商的标准化流程、数据接口和研发集成测试工具，实现总计数万台节点规模的超大型云资源池自动化集成和测试验收，极大的提升了中国移动网络云建设效率和质量。在技术方面，团队借鉴软件开发 CI/CD 的理念，集成业界成熟的 DevOps 工具，并联合业界主流软硬件产品供应商构建多厂商的持续集成持续测试（CI-CT）流水线和反馈闭环，加快网络云相关技术的实验室验证并支持现网实际交付。在此基础上，团队未来将进一步帮助构建中国移动网络云的 DevOps 闭环，实现大规模、多厂商的网络云快速迭代和持续优化。加入我们，你可以：

*   在全球最大规模的云资源池上积累丰富的第一手经验
    
*   挑战全球参与厂商最多、最复杂的云资源池，发现并解决实际问题
    
*   引领通信产业未来网络向 CI-CT 和 DevOps 的方向不断优化拓展
    
*   获得通信产业最前沿技术信息并深入细节探寻奥妙
    
*   参与国际标准化组织和开源组织，发表观点分享见解
    

中国移动研究院集成交付技术团队期待您的加入！
