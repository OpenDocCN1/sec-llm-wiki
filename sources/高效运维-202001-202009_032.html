创新是提高企业市场竞争力、增强企业生命力的重要引擎。而在大数据、云计算、人工智能、区块链等技术快速崛起的同时，为企业赋能就成为了培养创新力的重点。赋能是企业通过提升被赋能的能力，直接地增强了赋能企业生态系统的竞争优势，从而增强创新力，更好的服务自己的用户。


                       

赋能型生态系统的结构模式



当IT企业在打造生态圈时，为了更好更快速的面临市场变化，因 DevOps 的先进性和全面性，纷纷逐步实践组织级 DevOps ，由此 DevOps 被认为是软件工程的第三次变革。
                        
可如何打造一流的、端到端的 DevOps 持续交付流水线平台、提升组织效率与质量，让IT更好地支撑业务快速发展，是很多IT企业止步不前的难题。由此由中国信息通信研究院指导，云计算开源产业联盟和开放运维联盟联合国内外、行业内外公司及专家力量，发起此企业级 DevOps 赋能（共促）计划。


企业级 DevOps 赋能（共促）计划旨在交流、共促，帮助企业从内消除壁垒，实现一流流水线平台，从外拓展企业生态圈，建立良性循环的企业交流平台。

2019年从发起至今，赋能计划合作企业目前已有45家，覆盖了互联网、银行、证券、保险、互联网金融、通信、航空、物流、制造、高校等不同行业、领域的单位加入赋能计划。其中金融领域已有24家企业加入。


企业级 DevOps 赋能（共促）计划企业行业分布（截止到 2020 年 6 月 19 日）

 

首站企业行(成都)

2019年5月24日，以“DevOps的实践”为主题的企业交流会在成都招商银行金融后台服务中心举行。中国信通院专家牛晓玲对“企业级 DevOps 赋能（共促）计划”的发起背景进行介绍。招商银行陈展文分享了招行的 DevOps 和精益研发之路。由谢沁木分享招行基于K8S建设支持多种技术栈的 DevOps 流水线的实践经验，从建设背景、容器化技术栈解决方案、非容器化技术栈解决方案以及未来计划等方面进行了介绍。

           

在活动的互动交流环节，根据《研发运营一体化(DevOps)能力成熟度模型》(DevOps 标准)的持续交付部分的7个能力域，配置管理、构建与持续集成、测试管理、部署与发布管理、环境管理、数据管理、度量与反馈，主要在于参会专家对自身企业问题的“抛出”以及参会企业专家的群力群策的互动解答。 

参会企业名单


第二站北京--企业级DevOps平台建设

2019年10月18日，企业级DevOps赋能（共促）计划二次企业交流会在北京成功举办。本次研讨会围绕“ DevOps 平台建设”进行展开讨论。中国信通院专家牛晓玲对“企业级 DevOps 赋能（共促）计划”的合作单位以及参会情况进行介绍。

         

百度专家从 DevOps 实践，工程能力与 DevOps 的关系等维度介绍了百度的平台建设经验；郑州银行刘婷分享了城商行核心业务系统的持续交付实践，介绍了该系统的项目管理用的开源工具，需求和常规的项目管理计划、管理人员、管理测试等。

在活动的互动交流环节，参会专家对关于 DevOps 平台建设的提出问题并共同探讨，交流分享经验。

参会企业名单
                       

第三站杭州--企业级 DevOps 规模化建设

本次活动主题聚焦“ 企业级 DevOps 规模化建设”，以演讲+研讨形式探讨企业级 DevOps 规模化建设的经验与案例。此次活动我们邀请到金融、互联网、通信行业顶级企业的专家进行议题分享，通过本次活动能够了解名企 DevOps 转型之路，并在自己企业的实践中举一反三，寻找捷径，更快落地实践 DevOps。

中国信通院专家牛晓玲对“携手前行，企业级DevOps 赋能（共促）计划”的发起背景、合作单位、企业行活动进行了介绍与总结。中国工商银行方俊山分享了工行做 DevOps 的初衷、DevOps 实践经验和未来计划。广东移动段新阐述了从 1 到 N 的挫折和踩坑，碰到问题后，企业应该做出的调整，重启在企业内部做规模化的推广思考和探索。阿里巴巴神秀详细介绍了在实践程中遇到的问题和对工具、平台等的思考，企业要如何 DevOps 转型以及未来的计划。  

 

参会企业名单

                       

第四站--聚焦 DevSecOps 落地与实践

2020 年 6 月 23 日，企业级 DevOps 赋能（共促）计划第四次研讨会成功于线上举办！

本次交流围绕着 DevSecOps 这一主题展开交流和讨论。在 DevOps 协作框架下，安全防护是整个 IT 团队的共同责任，需要贯穿至整个生命周期的每一个环节。在 DevOps 计划刚启动时就要邀请安全团队来确保信息的安全性，并制定自动安全防护计划，实现持续 IT 防护、DevOps 安全防护自动化。

中国信通院专家牛晓玲带来《携手前行，企业级 DevOps 赋能（共促）计划》的演讲，介绍了赋能计划新一批的合作单位以及《研发运营一体化（DevOps）能力成熟度模型 第六部分:安全及风险管理》详情。华泰证券庄飞分享了华泰证券面临的安全挑战，对于 DevSecOps 理念传递及实践经验，以及华泰的安全工具平台建设过程等。腾讯安全专家张祖优介绍了腾讯云产品体系与安全挑战，从边界建立的安全防线，基于风险控制的安全体系以及腾讯 DevSecOps 的落地尝试。
