# 全球征集令|“5G+智慧金融”创新案例征集活动正式开启

随着5G时代的到来，科技应用给金融行业带来的改变正在从量变走向质变，尤其是5G技术与云计算、大数据、人工智能、区块链、物联网等新一代信息技术相互融合，正在推动全球金融行业更加深刻的数字化和智能化转型变革，而这种转型由于疫情的影响，又呈现出进一步的加速趋势。

  

为了进一步推动5G在金融领域的应用落地，总结与分享优秀创新案例经验，为金融科技产业各界提供宣传展示平台，**中国信息通信研究院联合相关各方，依托于“2020第三届中国金融科技产业峰会|第二届中新(苏州)金融科技应用博览会”（以下简称“金博会”），在国内外金融科技产业机构的支持下，发布“全球征集令”，全面开展“5G+智慧金融”创新案例征集活动。**

**02 征集标准**

  

  

本次案例征集将从实用性、创新性以及推广性等三个维度，对申报产品进行评价。其中：

  

**实用性**是指产品或应用能够满足金融行业业务发展需求，有金融行业成功落地经验，能为客户创造积极价值。

  

**创新性**是指产品或应用本身具备先进性，具有一定行业领先性，而且在自主研发及应用模式方面拥有独特优势。

  

**推广性**是指产品或应用符合相关法律法规要求及相关规范标准，场景典型，可作为样板项目大规模推广。

  

**03 征集时间安排**

  

  

**申报时间：**8月14日-9月10日

  

**评审时间：**9月11日-9月15日

**材料填写：**申报单位下载并按要求填写附件《5G+智慧金融创新优秀案例征集表》，并附上相关材料。

  

**征集表获取：**关注公众号回复“**案例征集**”获取征集表~  

  

**材料提交：**申报单位请于**2020年9月10日17点前**，将**加盖公章的扫描版材料**发送至邮箱hanyibo@caict.ac.cn，邮件命名为“5G+智慧金融创新优秀案例征集-申报单位-产品名称”。（不需提交纸质版材料）
