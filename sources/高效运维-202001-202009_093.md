# Python 爬了1W+运维招聘信息，原来运维这么惨？

近日 JackTian 的一篇文阐述了他通过朋友爬取了 13966 条关于运维的招聘信息，之后通过数据分析，看到了运维行业的一些差异化。分别从热门行业的用人需求、热门城市的岗位数量、不同规模公司规模用人数量、岗位对学历的需求等几个维度分析了运维的生存现状。

  

其中，排名前 10 的岗位平均薪资，运维开发、应用运维、数据库运维、Linux 运维均在 1W 以上。           

![](../Images/3736bfa61c50bce1e9b8b429684a2762.png)           

从图表中我们不难看出，不同的运维工程师薪资水平相差很多，运维开发岗位占据优势，但是其平均工资也不是很高水平。而随着技术的发展，开发运维工作流逐渐打通，DevOps 工程师也是不错的职业发展选择。DevOps 工程师 40% 左右的人平均月薪在 20K-30K 之间，这也侧面说明了对此职位人才的需求。
