## **![](../Images/9e80045f00fc9745acaae76213e2bb33.png)BOSS直聘：二季度50城白领平均月薪8190元 北京以12602元领跑全国**

7月21日，根据BOSS直聘发布的《2020二季度人才吸引力报告》显示，二季度就业市场复苏显著，招聘高峰延迟到来，人才需求环比增长57.2%，同比增长14.8%。数据显示，2020年第二季度，人才需求量前50城白领平均招聘月薪为8190元，北京以12602元领跑全国，乌鲁木齐冲上第八位。           ![](../Images/be19d3811f3b7417c3e363d716275b89.png)  

## **![](../Images/4ad8eb78462dfc41590e93d47e283d65.png)Cloudflare因路由器配置错误突发服务故障，数以百万网站瘫痪**

流行的Web基础架构提供商Cloudflare昨晚早些时候遭受了广泛的停机，影响了包括Discord，Medium和Riot 在内的众多服务。根据官方博客文章，这一严重中断始于美国东部时间下午5:15(美国标准时间凌晨2:45)，持续了大约27分钟。Cloudflare确认故障已广泛蔓延，并影响了近20个地点。其中包括圣何塞，达拉斯，西雅图，洛杉矶，伦敦，巴黎，莫斯科等。根据博客文章，它的网络流量下降了大约50%。Cloudflare很快就出现在现场，这令人欣慰，因为我们没有在本周目睹另一次黑客入侵。（来源CSDN）            ![](../Images/327ffcf3d0cfa92e60192086ae799807.png)              

## **![](../Images/bdd8789c808aaf66cf693fa88c06a952.png)12306 又崩了：部分用户出现出票失败、无法登录等情况**

7 月 17 日下午，有大量用户在社交平台上反映 12306 出现宕机，随后，“12306 崩了”登上微博热搜。据悉，大量网友反映 12306 页面显示“现在访问人数太多，请稍后再试”。此外，还有用户页面显示“暂时查询不到联系人”，并且卡在订单处理页面，无法进行改签等操作。中国铁路客户服务中心于 2013 年 12 月推出 12306 软件，12306 抱着缓解购票压力的缘由“出生”，但从“出生”那一刻起就被很多人吐槽，每年逢年过节购票高峰期，“12306 又崩了”这个话题都会被骂上热搜。现如今，12306 互联网购票已是民众购票的主要渠道，占据购票旅客总量的 70% 以上，平均一年售出 30 亿张火车票，成为全球最大的票务系统。这次突然出现问题并非在节假日等高峰时段，具体原因尚不清楚。目前，中国铁路官方也暂未给出解释。  

## **![](../Images/29982e3e388097ddc8393c76fb855996.png)哈啰App宕机：官方称受第三方网络升级影响，正在修复**

7月20日晚间消息，今日哈啰出行App出现宕机，官方在微博上回应称，受第三方网络升级影响，哈啰App暂时无法使用，技术人员正在加紧修复中。在微博上，不少用户反馈哈啰App无法使用，“还不了车咋办？”“多花的钱怎么办？”（来源：新浪科技）

## **![](../Images/e3e4ca6fb28755247ab636dcfaa5b549.png) GitHub 已将首批开源项目代码保存到位于北极的数据仓库 **

早在 2019 年 11 月，GitHub 就宣布了要在北极设立 Arctic Code Vault 数据存档仓库的计划。该设施选在了位于北极附近的世界档案馆（Arctic World Archive）中，作为一个具有长期目标的存档设施，其被埋入了山下 250 米深的永久冻土层。GitHub 希望将代码保存一千年的时间，从而为后代留下宝贵的开源财富。7 月 17 日，GitHub 官方宣布，首批开源项目代码已于 2020 年 7 月 8 日被正式存储到北极数据仓库。过去几个月，GitHub 与 Piql 合作，将 21 TB 的 GitHub 存储库数据写入了 186 卷的 piqlFilm 数字光感档案胶片中。为表彰数以百万计的开发者们做出的贡献，GitHub 还设计了一枚特殊的 Arctic Code Vault 徽章，源代码被收录储存在北极的开源开发者个人资料页面将显示该徽章。快移步至你的 GitHub 个人资料页面看看你有没有获得「北极开源贡献者」 称号吧！  

## **![](../Images/e1c668d8936b9f72225ff16b5a5b54ad.png)华为云发布GaussDB系列新品，数据库战略全面升级**

7月20日，华为云在TechWave技术峰会上正式发布了GaussDB系列新品，数据库战略全面升级，进一步满足政企客户业务需求，持续加速客户数字化转型进程。发布会上，华为云重磅推出了关系型数据库GaussDB（for MySQL）和非关系型数据库GaussDB NoSQL系列两大云原生数据库新品。GaussDB(for MySQL)基于华为最新一代DFV分布式存储，采用计算存储分离架构，支持1写15读的只读节点的极速扩展，最高支持128TB的海量存储，可实现超百万级QPS吞吐，单节点相比原生MySQL性能提升7倍，业界第一。GaussDB NoSQL拥有极强的多模数据管理能力，在并发读写能力、扩容时间缩、故障重构时间、备份效率、恢复效率等方面也都实现业界领先。华为云数据库还提供统一管控平台和接口，实现多业务数据融合，支撑多样化的应用服务。  

  

## **![](../Images/cfcd9b367aa7a183b72beca8f1cd6b1c.png)腾讯云数据库SQL Server基础版发布，价格为自建数据库二十分之一**

7月20日，腾讯云数据库SQL Server基础版（单机）正式上线。云数据库SQL Server 基础版提供了正版授权、高可用、高安全、高性能及轻运维的全套数据库解决方案，且兼具超高性价比。腾讯云SQL Server基础版是业内首个支持云上sysadmin权限的云数据库，真正做到自建数据库用户的数据、服务和业务访问都能完全平滑上云，在为用户提供正版企业级服务的同时，价格仅为自建数据库的二十分之一。腾讯云数据库SQL Server通过减少数据库节点，利用大量云服务器、数据YUN盘资源带来的规模化效益，大幅节省企业成本。据悉，云数据库SQL Server在价格上是云服务自建数据库的开销的五分之一，与IDC自建服务器搭建数据库的开销相比，仅为二十分之一。同时，还为用户免费提供实例的本地和云上备份空间，免除了用户研发、管理备份系统以及购买备份存储空间的成本。（来源：墨天轮）

## **![](../Images/17c5cc917dce1f89cda6db8cb8fef7d3.png)阿里P9干部内部考试找代考被举报，员工：对处罚结果失望 引发价值观辩论**  

2020年6月4日，一个寻常工作日的下午，阿里内网上举行了一场面向全体员工的直 播。这场直 播最高同时观看人数超过3万人，相当于每4位阿里员工就有1位正在观看。直播源于一次实名举报。一位阿里钉钉P9级别（阿里较高的职级，P9为资深专家）的女性中层干部在钉钉内部的传承官考试中——类似集团的价值观考试——找下属 DAI 考，其直属上级钉钉CEO陈航在内网上将这件事判定为员工手册中的二类违规行为，惩罚是扣除这位P9这一年的股票和年终奖。陈航的处理不仅没有平息争议，反而遭到了更多阿里员工的抗议。有人在内网留言说，此事件突破了公司的诚信红线，属于一类违规，应直接开除。抗议的呼声越来越高涨。最后，阿里的精神领袖——合伙人们出面了。他们召集了陈航、被举报的当事人、合规部门员工等人举办圆桌会议，公开讨论这一事件。现场有三位阿里巴巴合伙人出席，他们是阿里巴巴董事局主席兼首席执行官张勇、阿里CPO（首席人才官）童文红、副CPO蒋芳。他们召集了陈航、被举报的当事人、合规部门员工等人举办圆桌会议，公开讨论这一事件。现场有三位阿里巴巴合伙人出席，他们是阿里巴巴董事局主席兼首席执行官张勇、阿里CPO（首席人才官）童文红、副CPO蒋芳。
