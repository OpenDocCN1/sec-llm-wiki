工作地点：深圳 

  

**岗位职责:**

1.  负责建立企业级 DevOps 体系，建立持续交付流程，提升研发交付效率；
2.  主导搭建 DevOps 技术工具链，提高软件项目开发运维效率及质量，实现工具化、自动化、平台化；
3.  负责企业软件产品的研发、实施、交付的流程规范和优化 ；
4.  负责设计并跟踪 DevOps 全链路的度量指标，并根据度量数据制定和落地优化措施。

 

**岗位要求:**

1.  本科及以上学历，5年以上工作经验，2年以上 DevOps 工作经验；
    
2.  精通 Linux 系统的使用、DevOps 工具链和生态系统，精通掌握 CI/CD 的开源工具，例如 Jenkins、maven、git 等；
    
3.  熟悉敏捷开发流程，熟悉 Scrum、精益等敏捷开发和项目管理方法论；
    
4.  熟悉 Java、C++ 等语言的编译和单元测试框架，熟悉 Robot Framework 等自动化测试框架；
    
5.  熟悉 Docker、Kubernetes，具有 Kubernetes 搭建、配置和管理的经验；
    
6.  具备 Python、Shell 编程能力，乐于运用工具实现自动化运维。
