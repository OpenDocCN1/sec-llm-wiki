# 中国电信启动IT系统全面上云 数字化转型促高质量发展

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651686649&idx=2&sn=bd079f40e2f077dc4f70279b8c7a45ae&chksm=8bcb4550bcbccc4622690e43edefb33aaee85459dcc3408b5e8aaa3743f845ccea3daa3a0577&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651686649&idx=2&sn=bd079f40e2f077dc4f70279b8c7a45ae&chksm=8bcb4550bcbccc4622690e43edefb33aaee85459dcc3408b5e8aaa3743f845ccea3daa3a0577&scene=27#wechat_redirect)

7月16日，中国电信召开视频会议，对系统全面上云工作进行部署，明确提出“新建系统100%上云，存量系统三年上云”的工作目标。

会上，中国电信党组副书记邵广禄表示，中国电信不仅要做好自身的数字化转型，还肩负着以自身的数字化转型，推动全社会数字化转型的社会责任。他提出“不忘初心，以高质量党建促进高质量云改，以IT云改效果检验党建质量。”要求中国电信不仅要勇立数字化转型潮头，更要履行央企担当，服务各行业各领域数字化转型，培育壮大经济新动能。

![](../Images/c7f875832ffdce4c9293bd62e6eeb4e4.png)

**应数字化转型--乘风破浪**

当前的时代，是5G和云的时代，是人工智能的时代，更是数字化的时代。

今年4月7日，国家发改委与中央网信办正式下发通知，推进“上云用数赋智”行动，明确了加快产业数字化、培育新经济发展、构建新动能主导经济发展的新格局、助力构建现代化产业体系、实现经济高质量发展等目标，进一步掀起了企业“上云”的热潮。

顺应数字化转型趋势，中国电信坚持“业务上云”“系统上云”“网络上云”为核心的企业“云改”发展战略。其中，“系统上云”在中国电信的“云改”中有特殊的地位，是用数（大数据的融合运用）和赋智（企业智能化改造）的基础和前提条件，是高质量发展的助推器。

**树全面上云标杆--三年必达**

在推进上云进程中，中国电信以实现“业务上云、生产上云、管理上云、数据融通、能力开放”为目标，力争在2022年前实现系统全面上云，为“用数”和“赋智”夯实基础。

![](../Images/98e63583bf94bbd8791d5c5cf134338c.png)

为保证上云工作有序进行，中国电信制定了“MBOD四域协同”的上云策略：对于 MSS，采用重构业务流程和产品服务，重点提升数字化管理能力，推动业界优秀SaaS上天翼云形成最佳实践的策略；对于BSS，在前期上云的基础上升级到2.0上云；对于OSS，启动新一代云网运营系统重构上云；对于DSS，基于大数据湖采用“平台+应用”架构，推动大数据应用升级上云。在上云过程中，首先制定系统上云技术标准，梳理系统清单，明确上云业务目标、路径和步骤；全网统一PaaS清单、统一PaaS技术底座承载多专业多系统，改变原来按专业按系统独占资源的模式，全面上天翼云。

中国电信将充分发挥5G+ABC（人工智能、大数据、云）的优势，打造云翼、云道、云眼、云桥四个集中的上云基础平台，提供PaaS/IaaS集成一体化服务的自助申请、分钟级开通能力，降低上云使用PaaS组件技术门槛，提供开发运营一体化的Devops环境，提供立体化的监控和智能运维能力，并实现全网DICT能力统一开放、统一管理、统一运营，为31省公司IT系统上云保驾护航。

通过新建系统100%上云，存量系统“关移转并”三年上云，中国电信将从根本上提升企业竞争力，解决实际业务问题，降本增效提感知，助推企业数字化转型。

**建用数赋智样板--蓄势待发**

在全面上云的基础上，中国电信融通企业级数据，运用大数据/AI技术，在“用数”和“赋智”方面积极行动，并已取得五方面的初期成效。

![](../Images/57208346e42b3a162876bb0acae4bd8e.png)

数据驱动营销能力提升。中国电信升级了客户全生命周期洞察能力，以客户为中心对销售品支撑体系和客户经营支撑体系进行了重构，推进基于OneID的客户标签体系3.0建设。上半年，全网精准营销客户覆盖率超过50%，AI精准营销试点成功率提升119%。

数据驱动服务能力提升。在安徽、广东、四川等省试点，中国电信实现客户感知与网络数据关联应用，构建了投诉预测、感知评价、故障预判等大数据能力，并构建了网络舆情监控和追踪能力，开展投诉热点分析，为一线装维、客服赋能。

数据驱动企业管理能力提升。围绕企业关键的人、财、物，实现大数据/AI注智各项管理流程。目前，地址识别、证件稽核、车牌识别等19项AI通用能力在12省应用推广，驱动企业资源配置优化、效能提升。

数据驱动网络价值和运营能力提升。聚焦资产价值，支撑5G精准投资，中国电信实现5G基站全生命周期数字化管理，并推进广东、四川等试点开展基站造价及投资效能评估。目前AI基站节能应用8本地网，周均节约能耗10%。

大数据助力疫情防控。基于企业级大数据平台拉通B/O，中国电信开展大数据分析支撑疫情防控和复工复产，已向有关部委和省级政府提供8亿条数据；构建“翼知疫行”产品，支撑工信部“行程卡”、海关等调用，用户访问量超2亿人次。

**行央企使命担当--赋能行业**

中国电信致力于通过全面上云，促进内外部客户数字化转型。对内，通过系统上云提升企业竞争力、提升客户感知、解决实际业务问题、降低IT总成本，促进企业数字化转型；对外，中国电信作为企业上云标杆，提供上云咨询方案、迭代云公司IaaS/PaaS产品和运维能力、推动业界优秀SaaS产品上天翼云，助力客户企业实现数字化转型。

中国电信不仅要做好自身的数字化转型，还肩负着以自身的数字化转型，推动全社会数字化转型的社会责任。履行央企担当，中国电信率先实施上云战略，树立企业上云标杆，全面推进“上云用数赋智”行动，培育“新基建”新经济发展基础。

勇立数字化转型的潮头，中国电信积极做云建设云应用的先行者和引领者，正在以自身的实践和能力，推动和加速全社会信息化、网络化、数字化和智能化的进程，促进社会各行各业的数字化转型。
