企业级 DevOps 教练是企业实践 DevOps 的高级专家，是为企业内部 DevOps 推广的主力军，帮助企业加速实现组织级 DevOps 转型的尖端人才。

想要成为企业级 DevOps 教练，首先要通过企业级  DevOps 教练认证。

企业级 DevOps 教练（DEC）认证培训是由全球最大的 DevOps 认证培训机构 DevOps Institute 和 DAOPS Foundation 联合推出的高级认证，面向在企业中实践 DevOps 的人员。该认证覆盖在企业级引入和实践 DevOps 所需的所有能力，包括：组织结构和文化，精益和敏捷，应用架构设计，持续交付，测试及其自动化，技术运营，DevSecOps，度量，转型和持续改进。该认证及其相关课程的目的是为企业培养DevOps教练，以加快企业的DevOps转型。


每个正进行DevOps转型的企业都应该有一支由企业级 DevOps 教练组成的团队。
