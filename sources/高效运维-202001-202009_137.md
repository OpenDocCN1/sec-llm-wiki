雪松控股以创造实业价值作为最大的社会责任，通过雪松公益基金会积极投身社会公益事业，秉承“可持续的绿色未来”CSR发展理念，在精准扶贫、绿色供应链、文化保育、社区关爱、教育等领域不断发力，与合作伙伴、员工一起塑造“爱的共同体”，努力建设更美好的绿色未来。

  

雪松立业二十余载，正值松茂竹苞之盛。作为中国改革开放进程中涌现出的最具成长性的民营企业之一，雪松控股以“坚守实业兴中国，创造价值报社会”作为企业使命，积极开拓全球大宗商品产业布局，为制造业夯筑发展基石，为全球客户创造价值。

  

1测试开发高级经理

**岗位职责：**

1.  负责测试团队管理，以及测试体系规范和质量保证体系规范的建设；
2.  负责并指导产品/项目测试的全流程，包括参与需求分析、设计评审，制定测试计划，设计和执行测试用例，进行缺陷跟踪和软件质量分析等；
3.  负责并指导自动化测试工具/框架开发，自动化测试用例设计和执行，自动构建测试环境，持续集成等；
4.  推进自动化测试方案的规划和实施落地，并对问题进行跟踪分析和报告，推动自动化测试中发现的问题及时合理地解决；
5.  通过质量度量分析、测试方法、测试工具改进和项目流程优化等方法，持续提升研发的总体质量及效率。

**职位要求：**

1.  计算机专业本科及以上学历，具备良好的英语读写水平；
    
2.  精通测试全流程和测试用例设计方法，包括参与需求分析、设计评审、制定测试计划，设计和执行功能、性能、安全、兼容性等各种测试用例；
    
3.  具有 5 年以上软件测试及自动化测试经验，熟悉软件工程、软件测试理论和方法，有负责带领进行大型项目测试经验优先；
    
4.  具备较强的编程能力，熟悉 Java/Python 等至少一种编程语言，熟练使用 Linux 或 Unix 操作系统常用命令，熟悉 oracle 或 mysql 等主流数据库，有 Shell/Javascript 等使用经验者优先；
    
5.  熟悉 Jenkins、Junit、Postman、LoadRunner、RobotFramework、MockServer、Jmeter、selenium 等常用测试工具或平台；
    
6.  具备很强的逻辑思维能力，有较好的分析解决问题能力、学习能力、抗压能力、沟通能力和团队协作；
7.  有性能、安全、白盒测试、机器学习等专业测试领域经验者优先； 
8.  有基于Jira/Confluence等工具进行项目敏捷管理者优先；/docker/大数据测试经验者优先；
9.  有docker使用或大数据测试经验者优先。

  

2数据研发经理

1.  参与数据仓库和数据中台技术架构规划和设计
2.  全程参与数据仓库建模、开发、部署、运维，以及建设数据仓库辅助平台（包括元数据平台、数据资产和服务）；

4.  负责数据开发团队（内部和外包）技术管理，指导、规范数据工程师各项数据提取、清洗、整合工作，保障交付质量；
5.  参与制定数据仓库运行管理规范、数据标准、技术管理流程等；

**任职资格 **

1.  计算机科学与技术、软件工程、或其他计算机相关专业本科及以上学历，5年以上大型数据仓库实践经验，2年以上项目管理经验；
    
2.  具备大中型数据仓库的总体规划、方案设计、实施经验，精通企业级数据仓库实施方法论；
    
3.  熟练掌握数据库设计、数据仓库模型设计、ETL开发和调度监控、OLAP建模、前台分析展现设计与开发等技能；
    
4.  熟悉 Oracle、SQL Server、MySQL 等一种以上关系数据库，精通 SQL 语句；
    
5.  熟悉 Kettle、Informatic、Datastage 等一种以上ETL工具；
    
6.  有 Vertica、Greenplum、HAWQ 等 MPP 数据仓库相关经验；
    
7.  熟悉 Hadoop/Spark 大数据生态相关技术：Hadoop、Spark、Spark Streaming、Hbase、Hive 等；
    
8.  熟悉一种 BI 工具，比如 Tableau、Cognos等；
    
9.  具有较强的计划、组织能力，良好的口头/文案表达及沟通能力；
