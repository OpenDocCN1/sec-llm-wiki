什么是企业级 DevOps 教练

企业级 DevOps 教练（DEC）认证培训是由全球最大的 DevOps 认证培训机构 DevOps Institute 和 DAOPS Foundation 联合推出的高级认证，面向在企业中实践 DevOps 的高级专家，旨在为企业培养合格的内部 DevOps 教练，作为内部 DevOps 推广的主力军，帮助企业加速实现组织级 DevOps 转型。

每个正进行 DevOps 转型的企业都应该有一支由企业级 DevOps 教练组成的团队。

通过企业级 DevOps 教练考试，你将获得由 DevOps institute 和 DAOPS 基金会颁发的证书，你就可以正式成为一名合格的企业级 DevOps 教练啦，整个考试过程90分钟，通过真刀真枪的考试就有逼格满满的认证徽章一枚。

关于发起方：

  • DevOps Institute 是全球领先的DevOps认证培训机构，学员与合作伙伴覆盖全球主要国家，DevOps Institute 倡导建设持续学习社区，基于T型和E型人才理念，培训面向企业的DevOps人才。


  • DAOPS FOUNDATION 是一家全球性的非营利组织，致力于推进新一代软件工程，希望通过标准化和人工智能技术，提升全球IT企业的软件工程能力。基金会总部位于新加坡，由Alan Shimel、Kohsuke Kawaguchi、Jeff Liu等业界权威专家担任董事会成员。
