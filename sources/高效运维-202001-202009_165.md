**什么是企业级 DevOps 教练**

企业级 DevOps 教练（DEC）认证培训是由全球最大的 DevOps 认证培训机构 DevOps Institute 和 DAOPS Foundation 联合推出的高级认证，面向在企业中实践 DevOps 的高级专家，旨在为企业培养合格的内部 DevOps 教练，作为内部 DevOps 推广的主力军，帮助企业加速实现组织级 DevOps 转型。

![](../Images/0335b97d7ee11373e4b22d8b3d7c3bee.png)

> 每个正进行 DevOps 转型的企业都应该有一支由企业级 DevOps 教练组成的团队。

![](../Images/8054712ec904c53f16081b08a02ba260.png)

通过企业级 DevOps 教练考试，你将获得由 DevOps institute 和 DAOPS 基金会颁发的证书，你就可以正式成为一名合格的企业级 DevOps 教练啦，整个考试过程90分钟，通过真刀真枪的考试就有逼格满满的认证徽章一枚。

**关于发起方：**![](../Images/3c52611277f0510eb1c05cb89de05ae6.png)

*   DevOps Institute 是全球领先的DevOps认证培训机构，学员与合作伙伴覆盖全球主要国家，DevOps Institute 倡导建设持续学习社区，基于T型和E型人才理念，培训面向企业的DevOps人才。
    

![](../Images/5fdac50e815828c3b6af87a55c540d77.png)  

*   DAOPS FOUNDATION 是一家全球性的非营利组织，致力于推进新一代软件工程，希望通过标准化和人工智能技术，提升全球IT企业的软件工程能力。基金会总部位于新加坡，由Alan Shimel、Kohsuke Kawaguchi、Jeff Liu等业界权威专家担任董事会成员。 

发起方权威、科学且有效，绝对是你选择企业级 DevOps 教练的不二选择。下面应该是你最关心的地方了，本次课程会学到什么？  
**培训时长：**3天**课程大纲**  
  
  

1.  **DevOps 导论**
    

*   DevOps 起源与理解
    
*   DevOps 优化目标
    
*   DevOps 十策略
    

*   **组织结构与文化**
    

*   DevOps 组织结构
    
*   DevOps 文化
    

*   **精益敏捷**
    

*   精益与敏捷基础
    
*   敏捷研发模型：Scrum、XP、价值流图、精益看板等
    
*   需求活动：用户故事与和工作故事、需求拆分、需求估算、需求规划与发布、需求架构等
    
*   跨团队敏捷
    

*   **应用架构设计**
    

*   微服务架构
    
*   应用可扩展性设计
    
*   应用可伸缩性设计
    
*   应用可用性设计
    
*   应用可观测性设计
    
*   应用高性能设计
    

*   **持续交付**
    

*   软件交付过程：工作项、提交、特性、集成发布、流程自动化等
*   源代码及其构建：版本控制、构建及构建环境、制品管理等
*   部署运行：部署、运行环境、应用配置、数据变更等

*   **测试及其自动化**
    

*   测试设计方法
    
*   测试分层策略
    
*   代码质量管理
    
*   自动化功能测试
    
*   性能测试
    
*   测试数据管理
    
*   测试基础架构
    
*   混沌工程
    

*   **技术运营**
    

*   监控与预警管理
    
*   配置、事件与变更管理
    
*   容量与成本管理
    
*   高可用管理
    
*   业务连续性管理
    

*   **DevSecOps**
    

*   安全组织与工具
    
*   安全需求与设计
    
*   安全开发
    
*   安全测试
    
*   安全部署
    
*   安全运维
    

*   **度量**
    

*   度量指标
    
*   度量报告
    
*   度量体系改进
    

*   **转型与持续改进**
    

*   转型方法
    
*   转型路径
    
*   体系和工具
    
*   持续改进
