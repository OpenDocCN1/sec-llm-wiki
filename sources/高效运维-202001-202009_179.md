近几年，DevOps 可谓红透半边天，DevOps 已经从时髦概念落地到最佳实践，进而改变着整个软件行业。  
然而，许多企业在落地 DevOps 上也是云里雾里，企业间的IT架构，人员结构，工具平台等等方面五花八门，往往缺少一个明确的 DevOps 落地方向。因此，企业急需专业的 DevOps 人才来做指引和实施。  
与此同时，DevOps 人才就业趋势和工资也发生了很大变化，在供不应求的背景下，DevOps 从业人员的薪水也是一涨再涨。

**什么是企业级 DevOps 教练**

企业级 DevOps 教练是由 DAOPS 基金会开发并由 DevOps Institute 管理的高级认证，面向在企业中实践 DevOps 的人员。 该认证覆盖在企业级引入和实践 DevOps 所需的所有能力，包括：组织结构和文化，精益和敏捷，应用架构设计，持续交付，测试及其自动化，技术运营，DevSecOps，度量，转型和持续改进。该认证及其相关课程的目的是为企业培养 DevOps 教练，以加快企业的 DevOps 转型。  

![](../Images/0335b97d7ee11373e4b22d8b3d7c3bee.png)

> 每个正进行 DevOps 转型的企业都应该有一支由企业级 DevOps 教练组成的团队。

![](../Images/8054712ec904c53f16081b08a02ba260.png)

通过企业级 DevOps 教练考试，你将获得由 DAOPS 基金会和 DevOps institute 颁发的证书，你就可以正式成为一名合格的企业级 DevOps 教练啦，整个考试过程90分钟，通过真刀真枪的考试就有逼格满满的认证徽章一枚。
