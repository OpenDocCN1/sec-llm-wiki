# 携手前行！企业级 DevOps 赋能（共促）计划最新一批成员公布

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651685410&idx=3&sn=ef81329475507dc1367b868e3b1fba53&chksm=8bcb418bbcbcc89d125ad47f9a8d10f73b1b8ef4609f950730820900fea3bfcd442e5332ef3e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651685410&idx=3&sn=ef81329475507dc1367b868e3b1fba53&chksm=8bcb418bbcbcc89d125ad47f9a8d10f73b1b8ef4609f950730820900fea3bfcd442e5332ef3e&scene=27#wechat_redirect)

  

2020年6月19日，GNSEC 全球新一代软件工程线上峰会隆重举行，本次活动由云计算开源产业联盟指导、高效运维社区和 DevOps时代社区联合举办。

  

本次活动全程通过网络直播将精彩内容分享给广大同仁，活动盛况空前，近3000人参与并邀请到了众多行业内的顶级技术专家。  

 

GNSEC 全球新一代软件工程线上峰会专注于全方位的软件工程和技术，致力于定义新一代的软件工程。GNSEC 定义了新一代的软件工程，旨在聚集软件工程行业的专家、学者、从业者，讲述重要的最新研究成果，并分享最前端的实践经验，同时促进产、学、研领域的专家互相交流与合作。

 

此次线上峰会上午的主会场中，同时还公布了云计算开源产业联盟、开放运维联盟联合发起的企业级 DevOps 赋能（共促）计划新一批合作单位名单。

此外，全球首个 DevOps 标准，即《研发运营一体化（ DevOps ）能力成熟度模型》，由中国信息通信研究院牵头，联合云计算开源产业联盟、高效运维社区、DevOps 时代社区联、Google、BATJ、清华大学、南京大学、通信及金融等行业顶尖企事业单位专家共同制定。  

目前，DevOps 标准已在联合国直属标准化组织 ITU-T、中国通信标准化协会（ CCSA ）正式立项。
