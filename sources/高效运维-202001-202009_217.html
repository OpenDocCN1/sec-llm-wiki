微信被指监听用户，腾讯回应假的！

近日有消息称，微信正在监听用户的聊天记录，并在视频中传授所谓“1分钟关闭”诀窍。

             

对此，微信官方回应称，“聊天内容属于用户的通信秘密和个人隐私，微信不会监测用户的聊天记录，腾讯更不会通过监测用户聊天记录来推送广告。”


至于所谓的“按照聊天内容推送广告”，更是典型的“嫁接”谣言。微信称，腾讯的广告投放标签是针对用户群体而非单个用户，且所有的广告投放都经过加密处理。同时，腾讯表示，微信上广告投放基于用户的合法授权和腾讯的数据技术支持诞生的，可以保护用户隐私的安全。监听、监视用户聊天并推送广告，微信是绝不会做的。


Gartner：阿里云安全能力全球第二

近日，国际机构Gartner发布报告，首次全面评估全球TOP云厂商的整体安全能力。作为亚洲唯一入围厂商，阿里云整体安全能力拿下全球第二，11项安全能力被评估为最高水平（High），超过亚马逊，仅次于微软。

                       


2020年6月数据库流行度排行：阿里云数据库创佳绩，华为GaussDB转型引热议

2020年6月号 DB-Engines 数据库流行度排行如约而至。在 Top 10 中，除了 Microsoft Access 跌出前十外，前九位的次序依旧没有任何变化，不过长期占据前三甲的 Oracle、MySQL 和 Microsoft SQL Server 相较上月均出现了明显的分数下滑，尤以 SQL Server 为甚，下跌10.99分；位列第四的 PostgreSQL 则继续保持开源数据库的强劲势头，本月再涨8.19分，相较去年同期已提升接近10%。

                       


IDC：2019年中国云系统和服务管理软件市场规模同比增长44.2%

IDC最新发布的云系统和服务管理软件市场半年跟踪报告显示，2019年中国云系统和服务管理软件市场的市场规模达到了1.51亿美元，同比增长44.2%。IDC预测，受新冠疫情的影响，该市场在未来五年的增长会受到一定影响，但是仍然会保持高速增长，其年复合增长率为30.0%，到2024年的时候市场规模将达到5.62亿美元。

                        




百度云计算中心项目提前封顶 李彦宏点赞新基建提速

6月1日消息，今天百度CEO李彦宏在其百家号动态中转发“百度云计算中心项目二期主体结构提前封顶”一文，并评论：新基建提速。据阳泉日报报道，百度云计算(阳泉)中心项目二期顺利封顶，比原计划提前了20多天。


百度云计算(阳泉)中心项目二期是省级重点项目，计划总投资14亿元，总建筑面积8.6万平方米，建设内容包括D9、D10、D11、D12共计4个数据中心模组和1栋扩展厂房，建成后将为“百度搜索+信息流、智能云、智能驾驶”等业务提供有力支持。


Q1全球交换路由市场规模91亿美元：七年来最低点

6月1日消息，美国市场研究机构Synergy Research最新数据显示，2020年Q1全球以太网交换机和路由器市场的收入，下降到了七年来的最低点。
           

今年第一季度的环比降幅达到23%，同比降幅14%，收入为91亿美元，是自2013年以来最低水平的第一季度。以太网交换机、企业路由器和服务提供商路由器市场均同比出现了两位数的下降。


在众多市场参与者中，思科在第一季度的交换机和路由器市场中的份额为51%，在三个主要细分市场中，思科在以太网交换机中的份额为57%、企业路由器为65%、服务提供商路由器为35%。紧随思科之后的是华为、诺基亚、Juniper、Arista和HPE。



投资100亿！中国移动扬州数据中心落户仪征

5月29日，中国移动江苏公司与扬州仪征市政府在扬州签订中国移动(江苏扬州)数据中心项目合作协议，双方将携手加快区域内新基建布局，共同在仪征市大数据产业园打造长三角区域屈指可数的超大型数据中心。


据悉，中国移动(江苏扬州)数据中心总投资100亿元，可满足国内知名互联网企业及行业客户对机柜托管、大颗粒带宽、流量清洗、云资源落地等方面的发展需求。
