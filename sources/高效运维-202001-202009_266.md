# 你还不知道？DevOps 转型一定要避开的坑！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651683787&idx=3&sn=73e139538058d9ec3a1df6589881b97c&chksm=8bcbb862bcbc3174999f1444e146f288499c7ad1da2bac44a341fd598562d1516feb6d2d2364&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651683787&idx=3&sn=73e139538058d9ec3a1df6589881b97c&chksm=8bcbb862bcbc3174999f1444e146f288499c7ad1da2bac44a341fd598562d1516feb6d2d2364&scene=27#wechat_redirect)

**![](../Images/c2e2259852da561246cb710dae69adcb.png)****企业核心竞争力就是两个字：效率。**

![](../Images/51b8b6d577c81f8cb71723c87e1debdd.png)

DevOps 不能帮你直接解决业务问题，它只能帮你更快更好的交付业务需求，这就是效率。实践DevOps 的好处显而易见，使参与项目的成员感受到业务人员和技术人员沟通顺畅、效率很高，之前需要几个月才能完成的需求梳理和设计，缩短到1-2周项目就可以启动了。而这种顺利沟通的默契在后续的开发过程中使工作更容易推进，也让涉及到的人员感受到价值。

![](../Images/1a4144f8cd4117ffb507c275683ef361.png)

企业在实践 DevOps 时不能盲目....这需要企业决策层的决心，以及自上而下的文化转变、自下而上的实践支撑、贯穿中间的工程落地。

  

同时企业需要避开的坑：

  

**文化：强行实施就有好效果 ？**DevOps的敏捷文化在企业推行的时候绝非易事，而通过文化影响员工和工作习惯都需要时间，并且良好的文化需要配套的资源才能运转，效果才能凸显。

![](../Images/73ffbc06f03c434f67796a7677a2b898.png)

**工具：有工具就有了DevOps ？**

DevOps的工具链建设是实践的第一步，有了工具的确能提高某些阶段的效率。但DevOps是为了提高整个研发流程的效率和质量，让需求流动起来，并通过不断的反馈，持续改进，加速交付高质量的用户价值。

![](../Images/8ada3830e526d12466bd5f8a6517f33b.png)

**组织：靠 DevOps 人员来推动即可 ？**

DevOps转型使企业组织结构发生变化，团队拆分小队，机动灵活。业务和&技术部门共同组成 DevOps 实践小组。只靠一两个DevOps开发人员推动整个企业的DevOps转型，是非常困难的。           ![](../Images/16d270f135656a3f3221996a4a83c438.png)             那么如何绕过这些坑呢？**《2020年中国 DevOps 现状调查问卷》正式针对行业发展现状展开调查****汇集实践 DevOps 真实情况，用数据说话！**           

![](../Images/71f470df0a6a7f06e31eeb13c7212f82.png)

              

2019 年，中国信息通信研究院联合云计算开源与产业联盟、华为与南京大学进行了首次关于中国 DevOps 现状的问卷调查，并发布《2019 年中国 DevOps 现状调查报告》，在业界产生了良好的反响。

  

目前，由中国信息通信研究院联合云计算开源与产业联盟、高效运维社区、南京大学、腾讯蓝鲸智云、百度、京东智联云、苏宁消费金融、华为云 DevCloud、中国移动通信研究院、中国电信天翼云、中国联通软件研究院、中国农业银行、广东移动、浙江移动、平安科技、云智慧等企业共同发起的 2020 年中国DevOps 现状调查已经正式启动，现诚挚地邀请各位业界同仁参与本次调查。

 

本问卷以中国信息通信研究院牵头编制的《研发运营一体化（DevOps）能力成熟度模型》标准为参考，聚焦中国DevOps实践成熟度现状，并根据问卷填写情况实时给出受访者所在组织的DevOps实践成熟度。
