4月30日，由 DevOps 时代社区和高效运维社区联合主办，2020 DevOps 线上峰会圆满举行，本次线上峰会累计在线近 7000 人次，峰会涵盖 DevOps、AIOps、技术运营、云原生。

一天下来紧张而又充实，各位专家在远程为大家奉上一场关于 DevOps 的技术盛宴。参会者听得嗨不嗨？让我们来一一回顾下。

  

**主会场**  
2020 DevOps 线上峰会主会场由四位老师带来演讲，分别是台湾著名精益布道师、91APP 总经理室敏捷教练李智桦、中国信息通信研究院云大所云计算部运维主管牛晓玲、京东高级技术总监徐奇琛、浙江移动云计算支撑中心主任方炜总。这四位老师分别带来 DevOps、DevSecOps、质量体系建设等相关精彩议题。

![](../Images/a5f1454cc3cbeb455e468e6a1d069d0e.png)

**李智桦**

**台湾著名精益布道师、91 APP总经理室敏捷教练**

质量体系构建是个大话题，特别想 BATJ 这样量级的互联网企业如何做好质量体系建设？主会场第三位演讲嘉宾为京东高级技术总监、《技术运营标准》核心编写专家徐奇琛老师带来“京东：面向互联网时代的质量体系建设与能力构建。

当运维遇到业务，会擦出什么不一样的火花？2020 DevOps 线上峰会上午主会场由浙江移动云计算支撑中心主任、DevOps 标准核心编写专家方炜总带来“当运维遇到业务思维会擦出什么火花？”的精彩议题。

**AIOps 与技术运营专场**

![](../Images/e771c48d7f3f4de8a178df290c4c3b78.png)

▲ 从上至下依次为：袁纯良、龚诚、汪欢、秦晓辉   
下午的直播演讲同样精彩，首先由中国银行软件技术专家袁纯良老师带来“银行领域大规模X86分布式系统的无阈值智能监控实战”。随后，云智慧技术总监汪欢带来“数字化时代 AIOps 最佳应用场景实践”的精彩分享。58同城智能运维团队负责人、技术副总监龚诚带来“未来已来，从传统运维走向 AIOps 之路”的精彩分享。

夜莺是滴滴基础平台联合滴滴云研发和开源的企业级监控解决方案，此次峰会，滴滴运高级运维专家秦晓辉带来“滴滴开源夜莺：助企业构建稳定性体系”的精彩分享。

**DevOps 最佳实践专场**![](../Images/c6784ba41477e8eed4ac2974df7a59cb.png)▲ 从上至下依次为：景韵、茹炳晟、张祖优中台是热门话题，DevOps 博大精深，那么DevOps 体系下的测试中台该如何建设？由 Dell EMC 中国研发集团资深架构师茹炳晟老师带来精彩分享，让大家获益良多。  
腾讯安全专家张祖优带来“从混沌到体系化：DevSecOps 在腾讯云的落地实践”的精彩分享。最后，由 DevOps 时代社区联合创始人景韵带来“三元方程式，破解组织级 DevOps 转型难题”的精彩分享。组织级的 DevOps 建设一直是个难题，此次景帅带来的分享再次大受欢迎。**云原生专场**
