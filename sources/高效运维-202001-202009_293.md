公司简介

  
  

  
北京江娱互动科技有限公司成立于2018年，是一家集手游研发、运营、发行业务为一体的综合型游戏公司。公司的主营业务为移动网络游戏的研发与发行。江娱互动创立之初就把自己定位为全球性、国际化的游戏公司，致力于开发global级别的移动游戏产品并推广至全球。旗下产品现已推广至日本、俄罗斯及多个欧美国家。

> 游戏运维工程师 25-35K·13薪

**职责描述**

1.  负责游戏服务器的环境部署、日常运行维护、性能调优、故障应急响应，确保服务运行稳定、高效；
2.  负责游戏服务的部署、更新维护、状态监控；
3.  积极配合与研发、运营等部门的测试、BUG 处理；
4.  负责运维工具的开发、维护，确保更高效简洁的运行；
5.  负责运维新技术的探索及应用等。

**任职要求**

1.  熟练掌握 Linux 系统的操作和维护；
2.  熟练掌握 Shell 编程，会 Python 尤佳；
3.  熟练使用常用的系统监控软件，如 Zabbix、Nagios、Cacti、Monit 等，至少一项；
4.  熟练使用常用的运维工具，如 Fabric、Ansible、Puppet 等，至少一项；
5.  熟悉云服务器，有游戏运维经验及编程经验优先。
