# DevOps 企业赋能：你有一个和金融名企互联网大厂私享沟通的机会

![](../Images/c2e2259852da561246cb710dae69adcb.png)为了更好地促进中国企业实现组织级 DevOps 能力，打造一流的、端到端的 DevOps 持续交付流水线平台、提升组织效率与质量，让IT更好地支撑业务快速发展，由中国信息通信研究院指导，云计算开源产业联盟和开放运维联盟联合国内外、行业内外公司及专家力量，发起此企业级 DevOps 赋能（共促）计划。  

## 截止 2019 年末，赋能计划合作企业已有 32 家，覆盖了互联网、银行、证券、保险、消费金融、通信、航空、物流、汽车等多个行业。其中金融领域已有 17 家企业加入。

**首站企业行**(成都)

![](../Images/832906ccd60dd6399e9349521ecf059f.png)

### 2019 年 5 月 24 日，以“DevOps的实践”为主题的企业交流会在成都招商银行金融后台服务中心举行。招商银行陈展文分享了招行的 DevOps 和精益研发之路。由谢沁木分享招行基于K8S建设支持多种技术栈的 DevOps 流水线的实践经验，从建设背景、容器化技术栈解决方案、非容器化技术栈解决方案以及未来计划等方面进行了介绍。

###            ![](../Images/eb7f76021def5d9e7bb06465af062c4a.png)![](../Images/3027cf509c1296b56776653bd8ed1b21.png)

在活动的互动交流环节，根据《研发运营一体化(DevOps)能力成熟度模型》(DevOps 标准)的持续交付部分的7个能力域，配置管理、构建与持续集成、测试管理、部署与发布管理、环境管理、数据管理、度量与反馈，主要在于参会专家对自身企业问题的“抛出”以及参会企业专家的群力群策的互动解答。

参会企业名单

  

**第二站北京-**\-企业级DevOps平台建设

![](../Images/832906ccd60dd6399e9349521ecf059f.png)2019 年 10 月 18 日，企业级 DevOps赋能（共促）计划二次企业交流会在北京成功举办。本次研讨会围绕“ DevOps 平台建设”进行展开讨论。   
         ![](../Images/7cd681507769f9d7e755cb17a1469b95.png)

百度专家从 DevOps 实践，工程能力与 DevOps 的关系等维度介绍了百度的平台建设经验；郑州银行刘婷分享了城商行核心业务系统的持续交付实践，介绍了该系统的项目管理用的开源工具，需求和常规的项目管理计划、管理人员、管理测试等。

在活动的互动交流环节，参会专家对关于 DevOps 平台建设的提出问题并共同探讨，交流分享经验。

![](../Images/fd491392653d60aed3f6eee6d690e303.png)参会企业名单                       

**第三站杭州**\--企业级 DevOps 规模化建设

![](../Images/832906ccd60dd6399e9349521ecf059f.png)

本次活动主题聚焦“ 企业级 DevOps 规模化建设”，以演讲+研讨形式探讨企业级 DevOps 规模化建设的经验与案例。此次活动我们邀请到金融、互联网、通信行业顶级企业的专家进行议题分享，通过本次活动能够了解名企 DevOps 转型之路，并在自己企业的实践中举一反三，寻找捷径，更快落地实践 DevOps。

![](../Images/c8db111a6c222704018515427a338b64.png)

中国工商银行方俊山分享了工行做 DevOps 的初衷、DevOps 实践经验和未来计划。广东移动段新阐述了从 1 到 N 的挫折和踩坑，碰到问题后，企业应该做出的调整，重启在企业内部做规模化的推广思考和探索。阿里巴巴神秀详细介绍了在实践程中遇到的问题和对工具、平台等的思考，企业要如何 DevOps 转型以及未来的计划。
