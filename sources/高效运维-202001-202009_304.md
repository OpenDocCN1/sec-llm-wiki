# 博云 DevOps 3.0 重大升级 | 可用性大幅提升、自研需求管理&自定义工作流上线，满足客户多样化需求

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651683365&idx=2&sn=94ee2e988ce52bc8eda5873a55da1682&chksm=8bcbb98cbcbc309a702833976de5f5367ea4601de20d33523d6199b182f534699463c4a1f2ff&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651683365&idx=2&sn=94ee2e988ce52bc8eda5873a55da1682&chksm=8bcbb98cbcbc309a702833976de5f5367ea4601de20d33523d6199b182f534699463c4a1f2ff&scene=27#wechat_redirect)

  

DevOps 能够为企业带来更高的部署频率、更短的交付周期与更快的客户响应速度。标准化、规范化的管理流程，可视化和数字化的研发进度管理和可追溯的版本也为企业带来的了更多的价值。引入DevOps成为企业实现快速发展、适应市场变化和提升软件交付质量与效率的捷径。据信通院《中国DevOps现状调查报告（2019年）》显示，DevOps正在各个行业全面落地，企业对DevOps的重视度越来越高。

  

在当前这场应对疫情的战斗中，大量企业都被迫采取远程办公的方式来尽可能的减轻疫情对企业正常业务的影响，企业的IT部门同样面临了居家办公给研发工作带来的巨大不便，这些难题进一步促进了企业数字化转型决心，也使得在企业内部推动DevOps落地受到了越来越多企业研发部门的重视。

  

BoCloud博云早在2016年即推出DevOps咨询及解决方案，帮助企业从理念到实践，建立DevOps文化，通过博云的DevOps解决方案**使研发团队能够基于DevOps进行整体管理，贯穿软件开发的全生命周期，提升产品及项目交付效率，实现DevOps在客户企业研发体系的落地**。2019年，博云将多年帮助企业实践DevOps以及博云内部推行DevOps的实践经验进行总结和落地，推出了产品化的BeyondDevOps产品，并在迭代中不断丰富整套系统的功能。

  

在今年春节过后，全国战疫进入新阶段，各行各业按照政府指导开始复工复产的时候，博云为某客户交付的基于BeyondDevOps的远程开发协作支撑平台，发挥了重要作用，**为客户的研发人员提供分布式研发条件和线上集中协同作业条件，突破传统线下集中式办公模式，实现对远程研发效能、多地联动研发效能的实质性改善，保障客户的研发体系在员工分散的情况下依然可以高效运行**，不但可以保障研发业务的连续性，而且可以促进研发体系的运营管理的提升。

  

![](../Images/6f3c462b7dc5a8d004ad6598e7bdf5ec.png)

BeyondDevOps 产品架构

  

4月15日，博云BeyondDevOps完成了重大升级，推出3.0版本——该版本基于从客户实际情况总结提炼的需求出发，对之前的产品版本进行针对性的功能升级和完善，**构建从需求到开发、测试、上线的可视化、自动化的研发过程管理和持续反馈度量体系，帮助企业打造标准化、规范化的研发流水线，实现业务稳定高效的持续运营。**

 

  

  

**版本亮点**

  

  

***01***

  

**管理模型升级**

**多层级项目+服务树管理模型，管理对象组织清晰、简洁易用**

  

当前，企业普遍采取业界成熟的敏捷开发方法来提升研发效率，但是管理流程不够严谨，这就可能会带来潜在的风险。**BeyondDevOps支持项目-多应用-多服务三级管理模型****，可针对各种复杂业务架构项目进行协同开发测试**，通过平台可对多团队应用协同提测、部署、测试、发布和上线流程管理。

 

***02***

  

**敏捷项目管理**

**简洁易用的自研需求管理平台**

  

根据敏捷开发理念，**提供针对项目工作项跟踪管理的功能特性，**用户可通过平台做项目需求管理、任务管理、缺陷跟踪，并且提供了迭代看板视图，覆盖了团队敏捷开发实践的管理所需，为项目管理者提供全面的统计报告。  

  

对内对外、对上对下的透明化，通过清晰的度量和过程展示、驱动，对上保证过程和结果的可控，对内通过可视化的方式反复清晰的展示目标和过程，增强目标感并驱动持续改进，助力团队研发效能提升。

 

***03***

  

**工作流升级**

**可视化的研发流程灵活配置和管理**

  

BeyondDevOps关注用户实际需求，平台提供可灵活配置的研发流程管理。**用户可根据自己的组织情况定义合适的研发流程，通过平台支持的关键研发活动驱动研发流程的自动化流转，**并对流程的流转记录进行可视化的展示，使项目管理者和项目成员能够一目了然的查看当前项目的进展情况。  

  

![](../Images/e963237ec6528965509307f8e5807879.png)

  

***04***

  

**创造性引入应用/服务树视角**

**对各类管理对象进行组织，实现对多种软件架构开发的支持**

  

不论是项目制、微服务架构、中台架构、单体架构的开发，BeyondDevOps都能为不同架构提供良好的支持。**平台创造性的以应用-服务树的方式进行代码、pipeline、制品、环境的管理，极大的增强了平台的可用性。**  

  

![](../Images/cb42151f70a16f83b069747653084734.png)

  

***05***

  

**真正可编排、运行管理灵活的pipeline**

  

**在Jenkins之上利用编排引擎进行调度，可以实现灵活的CICD流水线功能**，支持并行、串行、暂停、失败重试等功能。支持可视化拖拽。

 

![](../Images/68a769a43d55b83dcbd730318f891185.png)

  

***06***

  

**简洁好用**

  

作为一个管理平台，在功能强大的同时，还需要具有可用性，因此博云在平台可用性上投入大量精力，真正做到了简洁好用。

 

  

BeyondDevOps平台覆盖了DevOps落地所需功能，能够适配企业不同的开发模式，具备高度的可用性及灵活性。同时，**博云拥有专业的咨询团队，能够帮助企业进行组织架构和职责的梳理落地，**规划实施路径，关注实际效果，由点及面，帮助企业真正建立DevOps文化，推进业务部门与开发团队深度配合，提升开发效能，专注于创造价值。

 

容器与微服务等云原生技术大大推动了DevOps进程。微服务架构已被广泛应用到企业的软件开发中，通过服务的独立部署、独立运行、独立管理，很大程度上使得DevOps的管理对象从一个复杂的系统变成一个个简单标准的单进程服务。而容器大大降低了持续交付流水线的门槛，通过标准化实现应用部署和运行管理的标准化。**由容器云、微服务、DevOps组成博云PaaS产品体系，能够为企业提供面向应用管理，满足全新互联网化下的应用全生命周期场景管理需求。**

  

随着企业数字化转型的加速推进，DevOps将持续高速发展，BoCloud博云将继续探索用户真实需求，提升产品能力，为用户提供安全、全面、适应性更强的DevOps平台，为企业提升研发运维效率提供助力。
