PART1

Android 软件开发工程师


职位描述

  1. 负责 Android 系统的深度定制，系统模块的开发、维护和问题修复；

    包括应用开发、framework 开发、多媒体开发（音视频，相机）、系统优化（功耗，性能，稳定性，内存）等方向

  2. 负责所维护模块的各项优化，如性能优化，功耗优化，内存优化等

职位要求

  1. 本科以上学历，计算机或相关专业，3年及以上 Android 开发经验
  2. 熟练掌握 Java 语言或 C++ 语言，熟练掌握面向对象编程，熟悉 Android 平台的应用设计规范、具有良好的编程习惯和代码规范意识
  3. 熟悉 Android 平台下的代码调试和调优技术
  4. 熟悉 Android 系统运行机制，对 UI 编程，四大组件，主要系统服务和主要通信机制有足够的了解
  5. 具备良好的分析、解决问题的能力；
    接受能力强，能很快学习和掌握新技术
  6. 具有良好的工作态度、沟通技巧和团队协作精神

   符合以下任一条件者优先：

  • 有 framework 实际工作经验；

  • 有音视频及多媒体框架实际工作经验；

  • 有系统或应用性能优化实际工作经验；

  • 了解并使用过开源框架或技术如 Rxjava，Retrofit，EventBus，Android JetPack，OpenGL，组件化开发等。

软件配置管理工程师


职位描述

  1. 与各产品的开发团队配合，为产品的配置管理活动提供技术支持；
  2. 负责项目负责产品代码基线升级，软件构建、版本管理、发布管理等，优化流程, 保障构建的稳定运行；
  3. 维护产品代码仓库，维护产品编译环境，并为开发提供统一的配置环境和工具；
  4. 开发和完善配置管理工具平台，实现操作规范化、自动化，提高工作效率；
  5. 为项目提供配置管理流程、工具方面的咨询、培训和相关支持。

职位要求

  1. 具有 3 年以上软件配置工作经验；

  2. 熟悉 Git，Gerrit，Jenkins/Hudson，maven 等工具，并能将工具进行集成使用；

  3. 熟悉 Ruby，Shell，Python，Perl 等任意一种脚本语言，并可以按照一定的要求进行功能的开发；

  4. 熟悉 Android 系统的编译流程，有持续集成环境搭建及维护经验；

  5. 熟悉 Linux 系统基础操作和命令、 Linux 环境下版本编译和构建；

  6. 良好的沟通技能，团队合作能力，具备吃苦耐劳精神；

  7. 有大型软件构建速度优化经验者优先。
