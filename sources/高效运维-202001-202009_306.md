![](../Images/c2e2259852da561246cb710dae69adcb.png)  职位描述

您将负责【高效运维】【DevOps 时代】等技术公众号的运营工作  

  

  入职后您将承担：

1.  跟踪前沿运维技术、IT技术，挖掘具有价值的技术内容及新闻；
    
2.  策划栏目、活动、话题，持续提升公众号的粉丝数量、互动率、关注度等数据；
    
3.  对新媒体运营、社群运营等有深入研究，形成独立的运营逻辑并具备丰富的运营实践；
    
4.  文笔出众，能独立撰写面向公司业务的创意文案；
    
5.  熟悉 IT 热词，段子手，文案高手，创意出众；
    

  

  我们期望您：

1.  计算机、新闻学及编辑学相关专业本科以上学历；
2.  三年以上新媒体运营经验，具有IT类公众号运营经验更佳；
3.  了解 IT 技术领域、了解运维领域更佳；
4.  文笔佳，创意高，脑洞大，思维活跃，具有线上活动策划能力。

  

  具备这些您会特别加分

1.  对IT技术行业感兴趣，愿意思考程序员、运维等IT工作者心理和用户行为；
2.  爱研究爱思考、有较强的自我驱动力；
3.  注重自我提升，乐于提升专业能力；
4.  注重文笔，如随同简历附带您的作品，我们将优先为您启动推荐流程。
