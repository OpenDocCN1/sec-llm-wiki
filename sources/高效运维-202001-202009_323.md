# 中国农业银行研发中心2020年社会招聘启事

中国农业银行是一家同时在上海证券交易所、香港联合交易所挂牌的国有大型上市银行，作为中国主要综合性金融服务提供商和全球系统重要性银行，致力于建设多功能协同的现代金融服务集团。

研发中心作为承载农业银行信息化建设、金融科技创新和数字化转型重任的总行直属部门，依托一流的人才队伍和强大的自主研发实力，搭建了中国银行业最大的数据仓库和大数据平台；在金融PB级大数据建设中率先实现技术自主可控，打造了业界领先的人工智能基础支撑平台和同业首个企业级AI金融平台解决方案；为农业银行2.4万个境内分支机构、30余家控股子公司和境外分支机构，在零售银行、公司银行、投资银行、基金管理、金融租赁、资产管理、人寿保险等多业务领域提供完善、可靠的金融交易支撑，为全球逾5亿客户提供高效稳健的金融交易服务。

我中心为广大员工提供广阔的研发领域、高水平的技术平台和多维度、全方位的职业培训，致力于实现员工的个人成长和价值提升；为每一位员工提供能者多得的薪酬回报、有为有位的职业发展和最完善的福利待遇。**一、招聘岗位****（一）岗位类别**

1.  软件研发类：研发工程师、移动端研发工程师、前端研发工程师、中间件研发工程师、数据库研发工程师、测试开发工程师。
2.  前沿技术类：云计算研发工程师、大数据工程师、人工智能工程师、区块链研发工程师。
3.  技术管理类：应用架构师、QA工程师、应用安全工程师。

**（二）岗位级别**

1.  软件研发类、前沿技术类岗位设置专员、高级专员、资深专员3个级别。
    
2.  技术管理类岗位设置高级专员、资深专员2个级别。

**招聘职位一览 ▲****二、应聘基本条件**

1.  境内外院校全日制大学本科及以上学历。其中海外留学生需提供国家教育部国外学历学位认证书。
    
2.  专员岗位要求全日制硕士研究生工作满2年、全日制大学本科生工作满3年;高级专员及以上岗位要求全日制硕士研究生工作满4年、全日制大学本科生工作满6年。
    
3.  诚实守信、遵纪守法；综合素质较好，具有较强的综合分析、逻辑思维能力和团队合作精神。
    
4.  身心健康。
    
5.  专员、高级专员岗位级别要求年龄不超过35周岁；资深专员岗位级别年龄不超过40周岁。
    
6.  符合农业银行亲属回避要求。
    
7.  其他应聘条件见具体岗位要求。
    

计算工作年限和年龄的截止日期为岗位投报日期。

**三、招聘流程**常年在线报名。欢迎有意加入农业银行研发中心的同仁登录我行官方招聘网站https://career.abchina.com，在线注册和岗位投报，我中心将根据报名情况和岗位需求情况多批次开展集中或专场选录。选录流程如下：报名、简历及电话初选、现场或远程编程笔试、现场或远程在线面试、体检、签约。**四、有关注意事项**

1.  应聘者需对个人信息的完整性和真实性负责，不得弄虚作假。如与事实不符，我中心有权取消其考试和录用资格，后果由应聘者本人承担。
    
2.  我中心将通过网站站内信和手机短信的方式发送笔面试的具体安排；如手机号码更换，请及时登录招聘网站变更。
    
3.  应聘者请持续关注本网站发布的招聘信息。各项招聘安排，以网上最新公布的信息为准。
    
4.  本次考试不指定考试辅导用书，不举办也不委托任何机构举办考试辅导培训班。
    
5.  根据岗位需求变化及报名情况等因素，我中心有权调整、取消或终止个别岗位的招聘工作，并享有最终解释权。
