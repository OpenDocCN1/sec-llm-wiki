工作职责

  

1.  参与监控告警系统、资源管理、变更管理、基础架构自动化、devops工具链的深入研究，结合业务落地技术方案和相关开发工作。 
    
2.  维护产品线的测试、开发使用的代码部署环境。 
    
3.  维护产品线的系统构建环境，确保版本发版的时间与质量。 
    
4.  维护产品线所需要的测试资源、演示资源。 
    
5.  参与产品线镜像层面的系统配置、中间件配置的引入和调优，保证镜像满足开发进度。

任职资格

1.  计算机相关专业，大学本科及以上学历。有运维自动化、监控系统、发布系统、运营支撑系统设计及开发经验；
2.  掌握 Nginx、Redis、Kafka 等常用开源组件的部署、配置及优化；
3.  熟练使用 Python、Shell 等脚本语言，可以开发相关自动化工具；
4.  熟悉 ansible 或 saltstack 等自动化运维工具；
5.  熟悉 Docker 及相关工具，如 mesos、k8s 等；
6.  了解 MySQL 或其它关系型数据库（如 PostgreSQL )的部署、配置及优化；
7.  了解 DevOps 理念；责任心强，善于沟通和分享，积极学习新技术。
