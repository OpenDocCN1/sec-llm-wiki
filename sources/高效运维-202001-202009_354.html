王洋：招商基金 DevOps 从0到1实践之路

王洋

招商基金 基础架构师

首先由招商基金基础架构师王洋带来招商基金王洋带来“招商基金 DevOps 从0到1实践之路 — 中小金融行业 DevOps 建设思考”的精彩分享。王洋老师介绍了招商基金两年时间内 DevOps 从0到1的建设过程，这个过程中有哪些实际情况与挑战。


雷涛：牢记！成功实践 DevOps 的5个关键因素

雷涛

Jenkins Ambassador

Certified Jenkins Engineer 

DevOps 标准核心编写专家


在当前的数字化时代，企业需要更快速更灵活的交付来保障业务运营，各个行业的头部企业通过成功引入并大规模实施 DevOps 获得显著的竞争优势。本次线上直播，雷老师介绍了成功实施 DevOps 5个关键因素，从而让更多企业获益。


朱加玉：基于博云 DevOps 对研发流程、版本及环境管理的实践分享

朱加玉

博云 DevOps 资深专家

随着 DevOps 在各行业的广泛探索与实践，大家对 DevOps 的文化理念、流程规范及工具的使用有了越来越多的理解与重视，博云 DevOps 资深专家朱加玉从流程管理、版本管理和环境管理三个点来介绍了博云的深度实践。

王晓翔：坚持 MVP 原则构建企业内部 DevOps 体系

王晓翔

前 Qunar 工程效率总监

企业内部构建完善的 DevOps 体系不是一触而就的，而负责 DevOps 落地的部门经常会被挑战的几个问题，前 Qunar 工程效率总监分享了如何基于 MVP 原则不断推进 DevOps 体系建设，以及实践 MVP 原则中的几个关键点。
