安徽继远介绍


安徽继远软件有限公司属于国家电网信通产业集团子公司，（A股上市名称国网信通，股票代码：600131），目前已发展成注册资本 40000 万元、员工近 500人、资产总额超过六亿元的“国家规划布局内重点软件企业”，其中硕士及以上学历占员工总数的25%，本科以上学历占员工总数的 85％，项目经理、架构师、系统分析师、数据库工程师、开发工程师、软件测试人员、业务咨询专家和技术工程师等专业技术人员达到 325 人，是一支高素质、有朝气的专业团队。


继远软件以电力行业背景为支撑，为客户提供信息设备集采、信息系统集成、信息系统维保、信息运维总包等业务领域的专业产品和服务。


本次招聘岗位主要为网省级电力公司服务，工作性质为驻场运维外委工程师，稳定不出差，工作地点：安徽合肥



PART1

云平台架构师


岗位职责：
  1. 参与省级电力公司阿里云平台的资源需求、预算及规划、管理；
  2. 根据上线应用项目需求，提供系统相关软硬件资源的选型、安装部署、开发、优化升级的技术支持；
  3. 参与阿里云平台的相关项目规划与实施，组织系统数据备份、恢复与应急演练等工作；
  4. 参与阿里云平台的灾备体系规划、建设、应用系统灾备建设及评估；


任职要求:
  1. 学历及专业：本科（含）以上学历，计算机或相关专业毕业；
  2. 工作经验：三年以上工作经验，有阿里云平台实施或运维经验者优先；
  3. 专业技能：精通Linux操作系统，有阿里云平台的相关建设、管理工作经验；熟悉云组件及产品的维护；
  4. 有云计算架构师（ACE）或其他相关资质者优先；
  5. 综合能力：具备较强的学习和总结能力，高度的责任感，工作严谨负责，能够承受较大心理压力。



PART2
虚拟化运维工程师


岗位职责：
  1. 负责VMware、KVM等虚拟资源池的日常管理、维护监测、故障排除和性能调优，对可能发生的故障及时制定优化或消缺措施；
  2. 参与虚拟资源池的备份、扩容等规划，分析运行状况及趋势；


任职要求：

  1. 学历及专业：专科（含）以上学历，计算机或其他相关专业毕业；

  2. 工作经验：二年以上工作经验；

  3. 专业技能：熟悉Linux操作系统，对网络及存储知识有所了解；有丰富的KVM或VMware运维经验；有python或shell开发自动化脚本经验者优先；

  4. 综合能力：具备较强的学习和总结能力，高度的责任感，工作严谨负责，能够承受较大心理压力。



PART3

SAP技术顾问


岗位职责：
  1. 负责SAP及BW、XI、EP的日常管理、维护监测、故障排除和性能调优，对可能发生的故障及时制定优化或消缺措施；

  2. 参与 SAP 的及 BW、XI、EP备份、扩容、迁移改造等规划，分析运行状况及趋势；

任职要求：
  1. 学历及专业：专科（含）以上学历，计算机或其他相关专业毕业；
  2. 工作经验：二年以上工作经验；
  3. 专业技能：熟悉SAP应用，对网络及存储知识有所了解；有丰富BW运维经验； 
  4. 综合能力：具备较强的学习和总结能力，高度的责任感，工作严谨负责，能够承受较大心理压力。
