一、岗位名称：

自动化运维产品经理，1人

工作地点：一般情况下在上地，根据技术能力和项目情况安排，需中短期出差

岗位要求（必要条件）：

  1. 本科及以上学历或学位，计算机相关专业毕业3年以上（必要条件）；

  2. 熟悉 Struts 、Hibernate、Mybatis、SpringMVC、Springboot、SpringCloud等java 技能，熟悉主流操作系统 linux/aix/hp/windows 等，能够根据客户需求编写shell 脚本（必要条件），熟悉主流数据库 oracle/db2/mysql/postgresql/sqlserver等，熟悉数据库的运行指标（必要条件）

  3. 熟悉数据中心运维自动化工具，有运维自动化产品开发经验。熟悉日常维护自动化、巡检自动化、应急处置自动化、灾备切换自动化、批量调度自动化、流程审批自动化及基础设施自动化中的若干模块

  4. 具有良好的沟通能力和文档编写能力，思路清晰，沟通表达能力和理解能力，责任心强，具有一定的团队合作精神（必要条件）

  5. 有运维服务产品研发与实施经验（必要条件）

岗位要求（加分条件）：

  1. 熟悉常用网络或者存储设备、kvm/vmware等虚拟化技术(加分条件)

  2. 熟悉hadoop生态圈相关技术（加分条件）

  3. 有DBA、系统管理员、网络管理员证书者优先（加分条件）

  4. 熟悉python语言（加分条件）

工位职责：

  1. 负责自动化运维平台产品设计、制作产品原型

  2. 负责组织市场调研、竞品分析、形成调研报告

  3. 负责组织产品设计文档的编写、管理

  4. 负责组织产品需求调研及功能模块设计、更新迭代等工作

  5. 负责公司内产品培训、组织建立产品设计相关制度、规范

  6. 组织定期召开功能评审会与需求部门充分沟通
