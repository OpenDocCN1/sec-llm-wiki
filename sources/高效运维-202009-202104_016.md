# 做到这5件事，就可以在2021年成为DevOps工程师？

也许对于许多组织而言，DevOps都是新手，这需要大量的培训和“技能提升”。能够有效沟通，跨业务孤岛工作以及与组织中不同人员合作是成功的唯一途径。有经验的 DevOps 工程师曾总结，做到以下几点，离成为 DevOps 工程师更进一步：

1.  有开发者的心态。因为将以代码形式进行管理，因此需要从开发人员的角度来审视挑战和问题，学习 Git 并编写可在未来几年内维护的代码。
    
2.  在系统工程中获得基础信息。了解三层应用程序体系结构，能够解释基本的系统管理任务（以及如何使它们自动化），了解Linux的基础知识。
3.  能够谈论云中的经验。现在几乎每个公司都以某种形式或方式采用云，所以需要能够证明您按代码配置的经验。
    
4.  对容器有所了解。不需要全面使用Kubernetes的经验，但是确实需要知道什么是容器，在CI构建过程中重点关注容器的使用。
5.  软技能很重要。DevOps不仅是工具和技术，而且是文化。要成为一名成功的DevOps工程师，需要能够结交朋友并影响人们。  
    

从上述中我们可以了解，成为 DevOps 工程师需要综合技能以及文化沟通的能力，目前美国最流行的，同时也是全球范围持证人数最多的 DevOps 认证 ——DevOps Foundation®，具有全球国际认可度的权威中立认证，能够快速帮助你了解：  

*   DevOps的目标及词汇
*   对业务和IT的收益
*   相关的原则及实践，包括：持续集成、持续交付、测试、安全和三步工作法
*   DevOps与敏捷、精益和 ITSM的关系
*   改善的工作流、沟通和反馈循环
*   自动化相关实践，包括部署流水线和 DevOps 工具链

课程包含来自DevOps institute最新思想、原则和实践，包含对高效能组织真实案例的剖析，如ING Bank, Ticketmaster, Capital One, Alaska Air, Target, Fannie Mae, Societe Generale, and Disney。吸引并激励学员,利用多媒体和互动实践,将学习经验运用于实践。内容还包含对《凤凰项目》作者 Gene Kim 在书中强调的三步工作法以及《DevOps现状报告》中最新成果的重点讲解。
