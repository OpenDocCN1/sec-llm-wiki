什么才是企业判断 DevOps 成功与否的主要标准？

原文：http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651697612&idx=3&sn=a6439d8396ee0c170c52df67372942ad&chksm=8bcb7265bcbcfb73e7b079b64ce1baeb28ba180c711ea41545f10a115fbc07cd0830d00085ac&scene=27#wechat_redirect

众多企业为更快更好的适应市场和增强创新力，纷纷采用 DevOps 来为 IT 赋能。如今，DevOps 已经在互联网、科技、金融、运营商和制造业等行业得到了广泛的落地实践，很多传统企业积极转型，并取得很好的成效，可企业如何判断 DevOps 成功与否还缺乏明确判断标准。
从中国信息通信研究院发布的《2020中国DevOps现状调查报告》中得知，超六成企业已实践 DevOps，但难以确认转型成功与否。据调查，63.35%的企业已进行DevOps转型，其中 29.14% 的被调查者无法判断所在组织的 DevOps 实践是否成功。
据报告显示，产品质量、研发效率的提升、客户满意度和按时交付是企业判断 DevOps 成功与否的主要标准，上述四项具体所占比例分别为58.83%、57.97%、57.32%和53.23%。在进行了 DevOps 转型的企业中，41.39%的企业通过在公司内部引入培训、咨询辅导等专业服务的方式推动 DevOps 转型。采用 DevOps 的企业中，超过 50% 已在一定范围内实践敏捷开发，处于优化阶段。
通过以中国信息通信研究院牵头编制的《研发运营一体化（DevOps）能力成熟度模型》系列标准为参考，调查结果显示，当前处于基础级的企业占比最高，为43.66%；26.56%的企业位于全面级阶段，相比2019年增长8.49%。由此可看出中国企业 DevOps 成熟度逐步向全面级发展。
前途虽然光明，道路依旧崎岖。根据 2020 DevOps 现状调查显示，29.28%的企业缺少具备DevOps经验的专家，导致推进缓慢无从下手；22.17%的企业没有定义度量指标；33.89%的企业在整个开发生命周期的各个阶段均定义了度量指标，但仅限于部门内部。由此可看出缺乏相关领域专家、转型路径不清晰、超半数企业均处于度量体系建设初期，未形成多维度完整的度量体系等多方面还存在很多困难和挑战。同时在人才培养方面也存在很多阻碍。

为进一步清晰中国 DevOps 发展现状，中国信通院已经连续两年牵头发起中国DevOps 现状问卷调查工作，并发布了2019及2020《中国 DevOps 现状调查报告》，在业界产生了良好的反响。目前，由中国信通院发起的第三次即2021年中国DevOps 现状调查已经正式启动，本次调查联合近40家企业共同发起，包括高效运维社区、中国农业银行、工商银行软件开发中心、招商银行、腾讯蓝鲸智云、华为云DevCloud、中兴RDCloud、字节跳动、京东零售、中国移动研究院、中国联通软件研究院、极狐 GitLab、蚂蚁集团、中软国际、神州泰岳、红帽、苏宁消费金融、杰蛙科技、中国电信研究院、星邺汇捷网络科技、宝信软件、复旦大学、东软、中软国际、中国铁塔、润联科技、浪潮云、用友网络、平安科技、兴业证券、中泰证券、百信银行、内蒙古移动、棱镜七彩、谐云科技、杭州新视窗、时速云、赛可出行、深圳华大生命科学研究院、博云、众安保险、龙智等（*以上排序不分先后），现诚挚地邀请各位业界同仁参与本次调查。

中国信息通信研究院牵头发起制定《研发运营一体化(DevOps)能力成熟度模型》即DevOps标准，从敏捷开发管理、持续交付、技术运营、应用设计、安全和风险管理及系统和工具等几个环节，帮助企业提升 IT 效能，将应用的需求、开发、测试、部署和运营统一起来，基于整个组织的协作和应用架构的优化，实现敏捷开发、持续交付和应用运营的无缝集成，在保证稳定的同时，快速交付高质量的软件及服务，灵活应对快速变化的业务需求和市场环境。此外， DevOps 国际标准也已于2020年7月在国际电信联盟ITU-T成功获批。
