国信证券创立于改革开放前沿的深圳，深耕于这片改革开放的土壤，承载着深圳速度、深圳质量和科技创新的深圳基因。国信核心价值观：创造价值、成就你我、服务社会。国信文化理念：合规自律、专业务实、诚信稳健、和谐担当。

经过20多年的发展，国信证券已成长为全国性大型综合类证券公司，截至2020年9月底，注册资本96.12亿元。

近年来公司的总资产、净资产、净资本、营业收入、净利润等核心指标排名行业前列。

### Java 资深开发工程师

##### 岗位描述：

*   参与国信微服务治理平台的研发及维护工作。
    
*   解决平台使用者的相关技术问题，支撑线上问题排查等。
    

##### 任职要求：

*   211/985院校计算机或相关专业本科或以上学历，3 到 5 年 Java 开发经验。
    
*   Java 语言基础扎实，对 JVM 有所了解，熟悉掌握 SpringBoot、Mybatis 等框架的使用。
    
*   熟悉掌握数据库和缓存的使用，如 MySQL、Redis 等。
    
*   熟悉微服务体系相关理念，如服务注册发现、服务治理；掌握某类微服务框架的使用，如 SpringCloud、Dubbo
    

工作地点：深圳
