# 华为车海平：聚力网络自治，加速行业转型

【中国，上海，2021年2月25日】在 MWC 2021 上海智能自治网络峰会上，华为数字转型首席战略官车海平博士发表了《聚力网络自治，加速行业转型》的主题演讲。

车海平认为，各行各业的数字化转型正在牵引 ICT 技术及产业的结构性升级，人类社会从“弱联接”历经“广联接”后加速走向“智能联接”。Autonomous Networks 产业倡议如同工业 4.0 对制造业的结构性升级驱动，正推进通信服务业态的生产装备供给、生产服务供给和通信服务产品供给的全面升级。经过升级改革简化产业链结构，提升产业链敏捷性，助力运营商有效把握客户和市场错综复杂的价值需求。

![](../Images/c488bb8a535370902f2e5e4180d26cf0.png)

**电信行业服务产品的柔性生产体系呼之欲出**

而今，疫情对于数字化转型的催化作用愈加明显。产业界通过推进简化、自动、智能、协同等办法，寻求更优的生产架构，以应对市场要求的灵活且定制化程度高的网络服务需求，电信产业已经进入架构性创新周期。与此同时，运营商通过生产装备智能化和生产管理体系扁平化协同，共同构筑“产品按需化、服务可编排”的柔性生产模式，打造使能各行业转型的开放创新、协同生产的新型数字生态，提升电信产业的经济效能，成为智能社会和数字经济的智能 ICT 基础设施平台。Autonomous Networks 产业倡议已成为电信网络智能化升级的广泛共识与核心关切。车海平在会上表示：“Autonomous Networks 产业倡议定义了网络及运维架构的新范式，从而优化电信产业生产成本结构、提升 E2E 生产柔性和商业敏捷度，以此凝聚电信产业生态各方合力。可以说，Autonomous Networks 就是电信行业的工业 4.0。”华为自动驾驶网络 ADN 解决方案正是 Autonomous Network 产业倡议指导下的先发实践。华为参考 TM Forum 提出的层域闭环协同架构，在无线接入、有线接入、IP 承载、光传输、核心网、数据中心网络等各网络领域，开展网络智能化、运维智能化的架构和产品创新，实现未来网络演进的两大转变：

转变一：从功能到意图，加快定义自治域标准

为了逐步实现 L5 级自动驾驶网络的目标，产业各方正式提出 “自治域（Autonomous Domain）”技术概念，加速网络生产单元从执行功能升级为执行意图。以自治域为基础管理对象，构筑“单域自治”和“跨域协同”的扁平化架构，通过表达业务语义的层间和域间意图接口，简化跨域协同难度、提升综合决策效率，增强业务层和商业层应对行业需求复杂性的 E2E 敏捷能力。我们认为，网络装备智能化和生产运营智能化应协同演进，面向千行百业，高效提供新型智能联接服务。

转变二：从关注可行性到关注可用性，构建行业知识生态

  
“场景化运营/运维的行业知识”，作为电信业内生产服务市场的核心供给品，一直陷于项目化定制的低效集成，是行业共同的痛点和难点所在。应加快构建产业级汇聚平台和生态，使网络运维方案的供给，向产品化运作、组件化构建、编排化集成、效能化定价的新能级跃迁，实现“可执行知识”的柔性生产，提升生产服务市场经济性。  
为了将电信行业知识转化为生产力，产业应共同加快数据运维（DataOps）、模型运维（ModelOps）和开发运维（DevOps）的工程化技术应用，促进算法和模型的性能、可扩展性、可解释性和可靠性。通过云地协同的技术架构，实现模型的持续注入和逐级递进，让网络越用越智能。2020年在电信运营商、行业组织、垂直行业客户的支持与认可下，华为 ADN 各产品取得了不斐的成绩。华为 iMaster NCE 连续四次被评为广域网 SDN 控制器业界最具竞争力领导者，并率先在数据中心网络发布 L3 级自动驾驶网络解决方案；华为 iMaster MAE荣获 2020 通信世界年度优秀解决方案奖，xExpress/xTurbo/xSuite 三大系列解决方案全球规模部署；华为 iMaster NAIE 支撑智能化特性加快工程化落地和应用，2020年全球规模应用 100+ 局点。作为自动驾驶网络理念的倡导者和积极的实践者，我们呼吁产业界进一步清晰 Autonomous Networks 分级标准和评估方法，结合实践加快意图化 API 创新孵化和标准定义，凝聚产业合力定义产业节奏。华为将紧跟全球运营商发展的脚步，与全球产业伙伴加强沟通对话，共同开展更广泛、更深入、更高效的合作，共同构建开放合作新生态，推动自动驾驶网络的规模化应用，为数字经济的高质量发展添薪续力。
