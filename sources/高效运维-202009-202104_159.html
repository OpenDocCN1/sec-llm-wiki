Java 资深开发工程师
岗位描述：
  1. 参与国信微服务治理平台的研发及维护工作。
  2. 解决平台使用者的相关技术问题，支撑线上问题排查等。
任职要求：
  1. 计算机或相关专业本科或以上学历，3 到 5 年 Java 开发经验。
  2. Java 语言基础扎实，对 JVM 有所了解，熟悉掌握 SpringBoot、Mybatis 等框架的使用。
  3. 熟悉掌握数据库和缓存的使用，如 MySQL、Redis 等。
  4. 熟悉微服务体系相关理念，如服务注册发现、服务治理；掌握某类微服务框架的使用，如 SpringCloud、Dubbo
简历投递：chenpeixin@guosen.com.cn
