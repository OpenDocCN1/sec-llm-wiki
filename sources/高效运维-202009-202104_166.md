# 优维科技助力银行快速完成人行金融业科技信息综合管理平台接入工作

近期人民银行总行组织建设了金融业科技信息综合管理平台，要求各级分支机构、全国性银行机构、地方性银行机构将IT基础设施、基础软件和应用系统等相关数据例行报送。旨在提高金融行业科技信息数字化管理水平，促进金融业科技信息共享交流，全面掌握金融业信息化建设情况。

![](../Images/7a5a45b259343d51217084843058a12a.png)

该要求建议6月底前至少完成机构总部直属数据中心的数据报送，9月底前完成全部的数据报送。

![](../Images/b9d0534ae4504d52e1a208c4adc0834d.png)

图1：数据接入范围

目的虽然明确，但是要实际落地，面临的挑战依然不少：

1.  人行的金融元数据版本后续会持续调整和更新，需要基础数据中台灵活的动态建模能力；
2.  数据范围广，金融元数据V2版本目前涉及59种资源元数据采集，数据录入量大，涉及全行基础设施元数据的采集，地方通过文档上报到中心汇总，中心通过接口上报；
3.  采集接口的数据有严格的约束，至少符合M0规则，还需要对C型数据进行合规性核验和检测，避免上报出错；
4.  监控要求及时增量上报，金融机构的失败数据可定位，失败原因可反馈，失败批次可重传。
    

  
![](../Images/90a1560025b8cfca28eb32ece74450dd.png)

**EASYOPS金融元数据上报平台**

为了满足人民银行下发的建立金融基础数据统计制度的要求，优维科技凭借多年深耕金融行业的实践经验，推出金融基础数据报送系统解决方案。该方案通过界面标准Execl模板、内部CMDB已有数据同步、或者ITSM流程行政审批等多种方式批量导入数据，经过优维内置的可配置的合规性规则进行数据核验，根据人行的MC0型等各项规则要求对数据进行核验、补录、报文生成、报文上报一系列流程，最终实现数据的采集、录入、治理以及上报。

**数据报送系统使用优维内置的低代码开发平台进行编排开发**，借助已有的CMDB作为数据中台，充分利用CMDB的模型管理、采集管理、增量更新发布、实例管理、模型行业化、数据校验等等诸多优势，**达成2天内完成了产品设计方案和实施解决方案，5天内输出客户可演示Demo，2周内产品正式上线，1个月帮助客户达成上报联调成功的战略目标。**

**平台功能**

上报平台主要包含数据管理以及上报管理2大核心模块。

![](../Images/29ad1c4ba3e04a3fc3702200de53df32.png)

借助优维的CMDB作为数据中台，数据管理主要提供以下能力：

*   标准化模型导入：人行标准化采集元数据模型的导入和管理，借助已有CMDB的图数据库引擎，可以轻松处理模型定义，字段约束，关系处理，视图设置等多种能力；
*   模型映射：上报平台模型映射功能，可以让已有的CMDB数据映射到人行标准化模型上，使用旧的CMDB模型进行数据上报，对已经在使用优维CMDB的用户，可以实现对历史数据的复用；
*   实例管理：基于优维CMDB的实例管理来实现，实例批量导入导出，实例模型查询、关联查询，数据自动发现等多项强大的功能；
*   数据治理：对M型强约束数据进行录入控制，对C0型数据定制数据合规检测规则，定时巡检，及时发现违规数据，通知相关科室进行处理。

![](../Images/6796e7c2fc2a5feb6eebcc50d04b9cfa.png)  
根据人行的上报要求，上报管理主要提供以下能力：

*   设置上报任务：可以配置上报方式增量或者是全量，上报范围是所有模型或者是指定模型，上报类型是手工、定时或者是事件变更触发等；
*   查看上报历史：可查看上报任务状态，执行时间，任务中每一个采集接口的上报批次、批次的上报阶段和状态，失败原因以及导出失败的实例列表进行人工处理。
    

  
![](../Images/176c761ea1e8b7dbcc33cac889753a28.png)

**平台特点**

1.  优维CMDB作为数据中台，提供模型管理、采集管理、增量更新发布、实例管理、模型行业化、数据校验等多项能力；
2.  全面支持人行上报的模型的同时，兼容金融机构已有的数据模板；
3.  支持全量上报和增量上报；
4.  支持手工、定时或者事件触发等多种上报触发方式；
5.  支持跟踪、分析失败批次，导出失败实例；
6.  **快速上报：优维在广东农信及其他城商行银行已提前部署上报工作，实例证明，优维元数据上报平台整体工作量可于1个月内完成。**
