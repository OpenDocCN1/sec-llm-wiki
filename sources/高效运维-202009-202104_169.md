## 一、** 运维架构师**

**岗位职责：**  
1、深刻理解 DevOps 体系，推动 DevOps 体系落地；  
2、负责运维技术架构的设计、优化和演进；  
3、推动运维平台全面建设工作，通过赋能全面提升产研效率；  
4、通过自动化能力的提升，来支撑业务的快速稳定增长；  
5、负责团队技术能力建设，提升企业技术优势；

**职位要求：**  
1、大学本科及以上学历，计算机或者相关专业；  
2、深刻理解 DevOps 体系，精于运维架构设计、运维平台建设等；  
3、熟练使用 Python、Go 等语言，并精通 Django、Flask 框架的使用；  
4、熟练掌握K8S架构和技术原理，并有大规模使用经验；  
5、有丰富的业务运维经验，对计算机网络、大数据、安全等有一定的了解；  
6、有 CMDB 设计、建设、推广经验，对云原生有一定的了解；  
7、思路清晰、善于思考、能独立分析和解决问题；  
8、责任心强，具备良好的团队合作精神和承受压力的能力；

**优先条件：**  
1、有 DevOps 体系落地经验者优先；  
2、有 Java 开发经验者优先；

## 二、** K8S架构师**

**岗位职责:**  
1、推动业务和K8S深度融合，并推进k8s的大规模使用；  
2、负责容器化技术和CICD的设计、优化和演进；  
3、保障线上业务的安全、稳定、高效运行；  
4、推动团队技术能力建设，不断探索新技术；

**职位要求:**  
1、深刻理解 K8S 技术，并有大规模生产 K8S 的使用经验；  
2、有分析 K8S 源码的能力，并对 K8S 各功能模块的优化有一定了解；  
3、有容器化技术在 CI/CD 场景中的设计和开发经验；  
4、精通 GO、Python 语音，并有丰富运维平台开发经验；  
5、对各主交流云厂商的容器服务有丰富实用经验，并对 Linux 系统有深入的理解；  
6、针对应用场景中的 kubernetes 问题能够快速 troubleshooting。

**优先条件：**

1、较好的沟通协调能力者优先；  
2、有Java开发经验者优先；

## 三、**运维平台产品经理**

**岗位职责:**  
1、负责企业运维平台和专有云（SAAS）部署平台的设计及优化；  
2、深入了解业务需求，优化产品以改善用户体验，帮助运维平台做演进和迭代；  
3、融合专有云平台以及运维平台，实现运维-运营平台一体化；  
4、负责需求管理，原型(Demo)设计、产品需求文档（PRD）产品相关文档的撰写;**职位要求：**  
1、1年以上运维经验，2年以上产品经验，具备从0到1落地产品的能力；  
2、有较强的抽象建模以及文档撰写能力，以及良好表达和呈现技巧；  
3、对大规模运维自动化产品的设计有自己的深入思考；  
4、有丰富的项目管理能力，有较好的协作能力；  
5、有责任感，具备创新精神，用户价值导向，乐观，抗压。
