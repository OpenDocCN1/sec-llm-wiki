## 根据 Gartner 的数据，70% 的IT市场现在都集中在 DevOps 上。

![](../Images/8548fdf0e51ba6904c43a198d523bb42.png)

从上图中，我们可以看出 DevOps 的发展呈明显的上升趋势。但 Gartner 也同时发现，目前使用 DevOps 的组织中，至少有 50% 无法达到原本商业论证中所期待的好处。甚至有文章指出, "在财富 500 强企业中敏捷和 DevOps 正在失败。”

而企业 DevOps 转型取决于组织中人的能力，在组织 DevOps 转型所依赖的人才团队中，DevOps 教练是一个极为重要的关键角色。企业级 DevOps 教练是企业实践 DevOps 的高级专家，是为企业内部 DevOps 推广的主力军，帮助企业加速实现组织级 DevOps 转型的尖端人才。而企业级 DevOps 教练这类人才能大大提高企业转型的成功率。企业级 DevOps 教练（DEC）认证培训是由全球最大的 DevOps 认证培训机构 DevOps Institute 和 DAOPS Foundation 联合推出的高级认证，面向在企业中实践 DevOps 的人员。该认证覆盖在企业级引入和实践 DevOps 所需的所有能力，包括：组织结构和文化，精益和敏捷，应用架构设计，持续交付，测试及其自动化，技术运营，DevSecOps，度量，转型和持续改进。该认证及其相关课程的目的是为企业培养DevOps教练，以加快企业的 DevOps 转型。

  

![](../Images/a168d23f01831b1652635dbc282e2464.png)**每个正进行DevOps转型的企业都应该有一支由企业级 DevOps 教练组成的团队。**
