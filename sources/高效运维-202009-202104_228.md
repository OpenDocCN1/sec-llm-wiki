# 全国首批！中国工商银行手机银行项目通过 DevOps 标准安全及风险管理首批试评估，相关项目能力达到先进水平

**编者按：**从各大企业的实践来看，标准化和工具赋能是科技公司成功的关键所在。标准本身是最佳实践的集合，有了标准，每一步都离目标更近（而不是偏离），将标准固化在工具里，DevOps 重点关注人员、流程和产品，并已经在企业和交付环节持续取得成功，获得良性反馈和循环。从安全角度来看，DevOps 有助于创建“一种协作文化，通过减少生产环境的变化来降低风险”。

  

2020年12月23日，为提高企业IT治理水平，加强行业内经验交流分享，2020 GOLF+ IT新治理领导力论坛在北京召开！本次大会旨在“让IT治理‘融惠’科技创新”，围绕“治效赋能，领航科技新生态”和“ XOPS 聚力，引领运维新风向”两大主题展开。

 

**大会隆重发布了DevOps能力成熟度安全及风险管理首批试评估结果。**中国工商银行股份有限公司参评的项目为手机银行项目，该项目顺利通过由中国信息通信研究院（以下简称信通院）开展的《研发运营一体化（DevOps）能力成熟度模型》安全及风险管理**（DevSecOps标准）**安全开发模块2级评估，代表着中国工商银行在该业务系统的安全开发能力达到国内先进水平。

  

此前，中国工商银行工银e生活项目、智能投顾项目均顺利通过 DevOps 标准持续交付3级评估（相关新闻稿链接详见文末）。

▲DevOps评估结果公布现场

  

此次，我们采访了中国工商银行软件开发中心总经理办公室信息科技专家李兵、中国工商银行软件开发中心经理三级邹晓鸥，一同聊一下中国工商银行手机银行项目参与评估的故事以及中国工商银行 DevSecOps 落地实践的经验。

  

**\-Q&A-**

  

**Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。****工行专家：**中国工商银行软件开中心成立于 1996 年，经过 24年的跨越式发展，成为一个在珠海、广州、上海、北京、杭州、成都、西安七个城市设有研发部的高新金融软件研发机构，肩负着应用研发、技术研究、系统培训、生产运维等诸多领域的职能。从电子化、信息化，到国际化、综合化、信息化，再到开启智慧银行建设，软件开发中心在科技手段的代际更新中打造了工商银行不可复制的核心竞争力。此次参与评估的应用为手机银行，手机银行系统通过移动网络为个人客户提供账户管理、安全管理，支付管理、投资理财、信用卡管理、贷款管理、生活缴费、外汇兑换、征信查询等银行金融服务。通过自助、文字、语音、视频等多种形式提供多场景金融服务；通过人工智能、大数据等先进技术提供智能化、个性化、高度安全线上服务。  
**Q：恭喜您通过DevOps 标准评估，此次贵公司项目通过的是安全及风险管理（DevSecOps）2 级，表明达到了国内先进水平，可以分享您的感受吗？****工行专家：**这是首批实践中国信通院《研发运营一体化（DevOps）能力成熟度模型 第6部分：安全及风险管理》标准（DevSecOps标准）的企业并取得阶段性效果，试点体量大、代表性强，其应用安全性保障机制更加完善，具有较大的金融行业示范效应，客观反映了我行安全开发能力成熟度水平。通过此次评估，丰富了我们在应用安全提升的最佳实践经验，后续将不断完善和推广。  
**Q：贵公司是如何决定参与 DevSecOps 标准评估工作中的？**

**工行专家：**作为金融行业，安全一直都是重中之重，我行中心领导一直十分高度重视安全体系，近几年 DevSecOps 的产生与发展，促使安全体系建设登上新的台阶，在我行领导的指导下，2020 年开始全面践行 DevOps ，并继续探索引入 DevSecOps 理念与方法体系，因为 DevSecOps 的出现改变和优化了之前安全工作的一些现状，比如安全测试的孤立性、滞后性、随机性、覆盖性、变更一致性等问题；通过固化流程、加强不同人员协作，通过工具、技术手段将可以自动化、重复性的安全工作融入到研发体系内，让安全属性嵌入到整条流水线。所以我行积极参与到信通院《研发运营一体化（DevOps）能力成熟度模型 第6部分：安全及风险管理》的评估，最终在DevSecOps领域初具成果。

  
**Q：贵公司之前已经通过其他标准，请问通过多个标准的原因是什么？****工行专家：**银行业的安全不仅仅是信息安全，更是人民财产与国家安全，作为资产规模排名第一的国有商业银行，积极响应和持续践行国家相关部门对金融企业的安全法规与要求，包括《中华人民共和国网络安全法》、《中华人民共和国密码法》等，同时我行积极探索新型的安全体系方法，将安全工作内建于应用软件的全生命周期，借鉴行业领先的DevSecOps标准，以 DevSecOps（安全内建）理念为指导，实施应用安全内建，帮助手机银行等应用提升安全性，保护了用户信息的安全。对于我行应用安全能力持续提升奠定了规范基础与成功样例，为国内金融企业，尤其是银行业探索出一条应用安全建设的新道路。  
**Q：对于此次参评的项目哪些特色？在日常安全风险的管理方面，面临哪些安全挑战？****工行专家：**工行手机银行项目通过引入信通院的DevSecOps标准进行应用安全开发能力提升，具体分析如下特点：体系化：覆盖组织职责、人员能力、工具维护、第三方人员与软件、数据管理、基础设施等领域，形成了体系化的方法规范；端到端：覆盖完整的需求、设计与开发周期，形成了全流程的安全开发规范；能力内建：将规范与制度内建到工具平台中与日常巡检中，包括 轻量级威胁建模方法、开源软件成分分析、安全需求固化等； 手机银行在日常安全风险的管理方面，面临的安全挑战如下：客户环境复杂：手机银行作为银行app中的头部应用，面对的客户使用场景非常复杂，不法分子的渗透、灰色产业链人员不恰当使用、黑客攻击等经常会威胁手机银行的安全使用。业务场景复杂：手机银行目前包含上百个业务场景，业务场景众多，给手机设计、开发带来全新的挑战。用户多、影响大、应急时效要求高：手机银行面对4亿+的用户群体，安全问题带来的影响大，应急时效要求高。软件开发流程较多、迭代更新快：从需求、设计、开发、测试、监控 参与人员众多，对于不同阶段中安全要求众多，存在较难统一安全意识的问题。

  

  

**Q：通过安全及风险管理（DevSecOps）标准的评估给您的企业带来了什么收获？****工行专家：**通过此项目的实施,对开发中心内部的安全需求规范化、安全设计组件化、安全编码规范化、安全内建进行统一建设与赋能。打通安全与 DevOps 的衔接流程与工具链。项目建设完成后，试点应用安全漏洞显著下降，为应用安全水平的整体提升积累了规范化和标准化实施 DevSecOps 的成功经验，也为后续推广做出有益的探索。**Q：DevSecOps 核心理念为安全是整个 IT 团队（包括开发、运维及安全团队）每个人的责任，是否可以详细的给我们介绍下，贵司是如何从文化、流程及技术三方面落地 DevSecOps 的？**

**工行专家：**首先在组织内传递和贯彻 DevSecOps 理念，让大家认识并认同 DevSecOps 方法论和优点，促进大家的积极性。其次在技术方面，通过工行应用安全开发提升项目的落地实施，打通了应用安全开发的全流程，包括需求、设计、编码三大部分的安全建设，其中技术核心点列举如下：建设完成移动应用安全编码规范并落地实施；基于源代码扫描工具实现开发本地安全规则扫描与安全质量门禁控制；基于软件成分分析工具进行开源组件的安全防护，在引入开源组件时进行登记与及扫描，不符合要求的组件禁止引入，针对引入后的开源组件，当安全规则升级后进行全量扫描，及时修复，避免因为开源组件问题引发安全事故；基于轻量级的威胁建模方法，分析业务场景、潜在攻击行为、应对措施，并纳入安全需求进行实现；建成基于国家相关法律法规与行业监管要求的需求库，如：敏感信息掩码等。

  

  

**Q：安全与风险管理标准对于企业安全风险管控能力提升提供了有效的指引，请问贵司对于 DevSecOps 落地实践的下一步计划是什么？****工行专家：**推广手机银行 DevSecOps 试点探索经验，赋能七大研发部 DevSecOps 能力，符合二级水平目标要求；深度挑战 DevSecOps 高要求，以手机银行为标杆应用，探索三级能力评估，实现安全内建的深度效果。

**研发运营一体化（DevOps）能力成熟度模型介绍：**《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已在中国通信标准化协会（CCSA）立项在研。与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。![](../Images/c656d5dc0ae9a30269a21e7a55a88029.png)
