随着技术分工越来越细致，有一种人越来越受重视，能够推动企业内部 DevOps 变革，为企业培养 DevOps 人才，是企业内部 DevOps 推广的主力军，是企业实践DevOps 的高级专家。但是这样的角色也不是那么容易做到的，必须有企业级引入和实践 DevOps 所需的所有能力，包括：组织结构和文化，精益和敏捷，应用架构设计，持续交付，测试及其自动化，技术运营，DevSecOps，度量，转型和持续改进。


不禁感叹，这也太难了！


也许，并没有那么难哦~近期全球首个企业级 DevOps 教练认证培训开始正式招生了！企业级 DevOps 教练（DEC）认证培训是由全球最大的 DevOps 认证培训机构 DevOps Institute 和 DAOPS Foundation 联合推出的高级认证，面向在企业中实践 DevOps 的人员。该认证及其相关课程的目的是为企业培养DevOps教练，以加快企业的DevOps转型。


每个正进行DevOps转型的企业都应该有一支由企业级 DevOps 教练组成的团队。
