## **![](../Images/342868072ad179ee9ee2b62c4093a61c.png) 重磅！Kubernetes 决定弃用 Docker；**

## **官方：不要慌！**

这是真的。Kubernetes 现已弃用 Docker。

目前，kubelet 中的 Docker 支持功能现已弃用，并将在之后的版本中被删除。Kubelet 之前使用的是一个名为 dockershim 的模块，用以实现对 Docker 的 CRI 支持。但 Kubernetes 社区发现了与之相关的维护问题，因此建议大家考虑使用包含 CRI 完整实现（兼容 v1alpha1 或 v1）的可用容器运行时。

简而言之，Docker 并不支持 CRI（容器运行时接口）这一 Kubernetes 运行时 API，而 Kubernetes 用户一直以来所使用的其实是名为“dockershim”的桥接服务。Dockershim 能够转换 Docker API 与 CRI，但在后续版本当中，Kubernetes 将不再提供这项桥接服务。

## 随后，官方解释： 不要慌，Kubernetes 和 Docker 没分手。

如果你是 Kubernetes 的最终用户，那么不会有太多的变化。这并不意味着 Docker 的消亡，也不意味着你不能或不应该再使用 Docker 作为开发工具。Docker 仍然是构建容器的有用工具，运行 Docker build 产生的镜像仍然可以在 Kubernetes 集群中运行。如果你正在使用像 GKE 或 EKS 这样的托管 Kubernetes 服务，那么在 Kubernetes 的未来版本中删除 Docker 支持之前，你需要确保你的工作节点使用的是受支持的容器运行时。如果你在创建自己的集群，你还需要进行更改，以避免集群崩溃。

## **![](../Images/afd98af61fcd812c974fa5d27478f3ba.png) Salesforce 宣布 277 亿美元收购 Slack**

全球最大的 CRM 云计算服务供应商 Salesforce 于周二（12/1）宣布将以价值 277 亿美元的股票与现金，买下协作通信平台 Slack，双方预计于 Salesforce 的2022财年第二季（2021年7月底）以前完成交易，未来Slack将成为 Salesforce Customer 360 的新接口。

根据双方的协议，Slack 股东每股将收到 26.79 美元的现金与 0.0776 的 Salesforce股份，换算之后该交易约价值 277 亿美元。消息传出后，Salesforce 当天股价下滑了 1.81%，盘后再下滑 4.81%，股价跌至 229.75 美元，反观 Slack 股价则微幅上涨至 43.56 美元。

## ![](../Images/c56be988a9794b4eb1c450a52254a27e.png) **意义重大！MacOS 首次出现在云端，**

## **云上 Mac 时代来临**  

11月30日晚间，Amazon Web Services (AWS) 发布了在 Amazon EC2 平台上的首批本地运行、基于云的 macOS 实例。  
![](../Images/748173209e438bdb019420eff9982383.png)

新的 macOS 实例是 Amazon EC2 副总裁 David Brown 在亚马逊 re: Invent 2020 大会的开幕之夜发布的新服务，它为苹果开发人员提供了一种在云端运行按需 macOS 工作负载的方法。

此举意义重大，因为这意味着苹果开发人员可以在短短几秒钟内在 AWS 上配置和访问 macOS 环境，并开始针对 iPhone、iPad、Mac、Apple Watch、Apple TV 或 Safari 浏览器开发软件，无需购置任何特定的硬件或软件。

## **![](../Images/a77341f1140aa6563e096f69bab04022.png) 传新荣耀员工现金补偿最高可拿N+5**

12 月 3 日，据腾讯一线独家报道，新荣耀已进入人员整合阶段。此次整合为期一个月，如无意外，所有员工的新劳动合同签署工作将于本月底完成。新劳动合同将自 2021 年 1 月 1 日生效，合同期为 4 年。腾讯《一线》援引一位已签署了新劳动合同的荣耀员工的说法，公司给予所有加入新荣耀员工的签约费是 N + 1，在此基础上，另提供二选一的补偿方案 — 4 个月工资或购买公司一定要的 ESPO（虚拟股分红），两个二选一。此外，对于加入新荣耀的员工，根据职级、年限差异，每个人可选择不同的补偿方案，有选择最高 N + 1 + 4 的现金补偿，也有选择 N + 1 和享受长期 ESPO 分红，还有选择 N + 1 和 TUP 分配。目前，荣耀官方未就此事做出正面回应，也尚未官宣员工补偿方案。(来源：腾讯一线)

## **![](../Images/e14ff3072cc99018c9849659b4741bb4.png) 特斯拉前员工因泄露 Model 3 机密被判赔偿 40 万美元**

12 月 1 日消息，据外媒报道，一份法庭文件显示，特斯拉前员工马丁· 特里普（Martin Tripp）与特斯拉 CEO 马斯克（Elon Musk）之间长达两年多的法律纠纷终于有了眉目。在特里普承认向一名记者泄露公司机密信息后，被法院责令向他的前雇主——特斯拉支付 40 万美元。40 万美元的赔偿金属于拟议和解案的一部分。2018 年，特斯拉起诉特里普，指控他非法泄露 Model 3 生产相关的商业机密。特里普曾对记者透露，特斯拉内华达州超级工厂遇到了生产延期的麻烦。作为和解协议的一部分，特里普承认违反了商业秘密法和保密协议，承诺若是在被法官禁止的情况下继续泄露特斯拉信息，他向特斯拉支付 2.5 万美元。（来源：AI前线）

## **![](../Images/61d9be02c461e9a1d43c9cf542a262bc.png) Google 开发者披露 iPhone Wi-Fi 漏洞发现过程**

今年早些时候，苹果修复了 iPhone 的一个高危漏洞，该漏洞是 iOS 内核 内存破坏 bug 导致的，允许攻击者通过 Wi-Fi 远程访问整个设备，整个过程无需任何用户交互。该漏洞利用能像蠕虫一样从一个设备传播到附近的另一个设备。这一传播过程也无需任何用户交互。Google Project Zero 安全研究员 Ian Beer 向苹果报告了该漏洞并开发出了漏洞利用的 POC。他在官方博客上详细讲述了 Wi-Fi 漏洞的发现过程。他开发的漏洞利用能完整访问 iPhone 上的用户数据，包括 电邮、照片、消息，以及储存在 keychain 的密钥和密码。
