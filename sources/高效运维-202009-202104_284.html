2020 DevOps 领域年度极具影响力产品！专访 CODING

2020 年注定是不平凡的一年，全球范围的疫情冲击着各行业的发展，IT 行业同样不能幸免，受整体经济环境的影响面临着巨大的发展压力。但与此同时，在国家卓有成效的抗疫政策下，在区块链、人工智能、云计算和大数据等信息技术大潮下，我国 IT 行业仍保持迅猛的发展势头，越来越多的企业开始加大信息化的投入，这对中国 IT 行业而言即是机遇，亦是挑战。
2020 IT 技术领导力年度评选旨在通过对 IT 行业从业者、产品、企业、服务商的横向评选及表彰，鼓励 IT 行业企业持续开展技术创新、激励 IT 人才勇于开拓的有益探索，期望 IT 行业企业和从业人员能够不忘初心，砥砺前行，继续引领 IT 行业技术发展、再创佳绩。
2020 年 11 月 27 日，2020 年 IT 技术领导力颁奖盛典在千人规模的 2020 GOPS 全球运维大会·上海站主会场隆重举行！在经过行业推举、网络投票以及综合专家委员会的意见后，会上，CODING  DevOps 荣获 2020 DevOps 领域年度极具影响力产品奖项！


由高效运维社区发起人、GOPS 全球运维大会发起人萧田国先生为 CODING  颁奖：



▲ 获奖企业代表与萧帮主现场合影


会上，我们采访了 CODING DevOps 布道师 杨周，分享企业专注领域、明星产品，以及对未来的展望！


CODING DevOps 布道师 杨周


Q: 恭喜获得 2020 DevOps 领域年度极具影响力产品奖项，现在感受是怎样的？
杨：非常高兴 CODING 在 2020 年 IT 技术领导力颁奖盛典网络票选中获得极具影响力产品奖项，也非常感谢大会给我这个机会作为领奖嘉宾在这里代表 CODING 获此殊荣。感谢腾讯云领导的大力支持，也感谢目前正在孜孜不倦工作的 CODING 的员工，正式因为他们才有了 CODING 今天的成绩。

Q: 请您介绍一下您所在的企业和产品，有什么独特之处？有哪些成功案例？
杨：作为腾讯云产品部重点支持的 DevOps 产品，CODING 团队在过去一年的发展中规模扩大了一倍多，并且也在进一步地扩张。CODING 的业务量比起一年前翻了四倍，在未来也会继续强劲增长。作为市面上少有的 DevOps 一站式平台，CODING  提供了一套功能齐全却又轻量的端到端 DevOps 解决方案，尤其是对云原生的支持。CODING 目前已有超过 200 万的开发者用户，服务了超过 50000 家企业，大客户方面有像银联，深圳农商行，中体彩，PICC，南方电网等大型银行和大型国有企业。不久之前我们也荣获工信部信通院首批 DevOps 先进级平台认证。

Q: 此次获奖对企业有哪些积极影响？
杨：此次能获得最具影响力奖，代表着用户对 CODING 一站式 DevOps 产品的肯定。我们会再接再厉，一方面把 CODING 的产品做的越来越成熟、满足客户更多的需求；另一方面，根据客户的反馈并结合 CODING 的战略，做出 CODING 自己的特色。在某些领域做出亮点和优势，争取成为国内 DevOps 产品的头部企业。此次获奖也获得了领导的肯定，可以预见不久的将来会有很多来自管理层的支持和投入。

Q: 未来的计划和展望有哪些？
杨：CODING 未来将继续致力于一站式 DevOps 平台的开发，服务好我们的客户。争取未来几年成为这个领域的领头羊，让客户享受到功能更强大，覆盖更全面，上手更容易的端到端 DevOps 服务。
