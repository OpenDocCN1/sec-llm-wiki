# 2020银行业DevOps领域年度风云团队！专访中国农业银行 DevOps 建设工程团队

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651692088&idx=4&sn=4d0c90568410f75351d10dab292c7be7&chksm=8bcb5f91bcbcd687bc26ad76b82e0eec2dbccc50732ffcef46224768c8f132a448d9b6a54b9d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651692088&idx=4&sn=4d0c90568410f75351d10dab292c7be7&chksm=8bcb5f91bcbcd687bc26ad76b82e0eec2dbccc50732ffcef46224768c8f132a448d9b6a54b9d&scene=27#wechat_redirect)

![](../Images/c2e2259852da561246cb710dae69adcb.png)2020 年注定是不平凡的一年，全球范围的疫情冲击着各行业的发展，IT行业同样不能幸免，受整体经济环境的影响面临着巨大的发展压力。但与此同时，在国家卓有成效的抗疫政策下，在区块链、人工智能、云计算和大数据等信息技术大潮下，我国IT行业仍保持迅猛的发展势头，越来越多的企业开始加大信息化的投入，这对中国IT行业而言即是机遇，亦是挑战。  
2020 IT 技术领导力年度评选旨在通过对IT行业从业者、产品、企业、服务商的横向评选及表彰，鼓励IT行业企业持续开展技术创新、激励IT人才勇于开拓的有益探索，期望IT行业企业和从业人员能够不忘初心，砥砺前行，继续引领 IT 行业技术发展、再创佳绩。**2020 年 11 月 27 日，2020 年 IT 技术领导力颁奖盛典在 2020 GOPS 全球运维大会·上海站主会场隆重举行！在经过行业推举、网络投票以及综合专家委员会的意见后，会上，****中国农业银行 DevOps 建设工程团队荣获 2020 银行业 DevOps 领域年度风云团队奖项！**  
****大会公布中国农业银行 DevOps 建设工程团队评选结果**：**![](../Images/23140e8b5d7a6bb363a630e14acbf5b4.png)  
我们对中国农业银行研发中心副总经理赵韵东进行了独家专访，和他们一同回顾 2020 年的工作历程，分享心得的同时也展望未来~![](../Images/2149b80b43c56a4f1eca1fd9bf30a002.png)中国农业银行研发中心副总经理赵韵东  
**Q：恭喜您和团队荣获 2020 年度风云团队奖项，现在感受如何？****赵：**首先感谢组委会及评审团队将此殊荣授予中国农业银行 DevOps 建设工作组，这既是对团队过去一年来工作成效的肯定，也是对未来持续推进 DevOps 全行应用推广工作的激励。此次获奖得益于行领导对农行数字化转型的坚定决心，和对DevOps助力IT研发与运营模式的整合提升能力的认可，同时也依赖于农行科技局、研发中心、数据中心各管理及工具条线、各试点项目组的日夜艰苦奋战、不辞辛劳，才能构建形成农行本地化特色的 DevOps 生态环境，支撑我行双模研发体系有效运作；在此也再次感谢所有 DevOps 建设工程参与者的共同努力！  
**Q****：请您介绍一下您和团队****赵：**DevOps 建设工程团队成立于 2019 年 4 月，由研发中心总经理负责，项目管理办公室牵头，架构管理办公室、系统支持部、信息安全与风险管理部、北研及上研技术保障部、应用平台研发一部及二部、开发一部、开发二部、开发五部、北研开发一部、北研开发三部、测试一部、测试二部、北研测试部等十余个部门共同参与，科技局、数据中心相关部室协力支持，按照流程优化、工具链贯通、数据可视、试点评估五大条线共同推进 DevOps 能力建设。设置总体组、管理链优化组、流水线建设组以及五个试点项目组，各团队各司其职、互帮互助、合力攻坚，其中总体组制定工程实施总体方案，绘制流水线蓝图，夯实各项重点任务，是工程的引航器；管理链优化组则扛起 DevOps 建设工程流程优化和数据可视的重任；流水线建设组收敛专业领域工具，实施需求、开发、测试、部署、运营工具链上近 20 个工具间的互联互通、数据共享；试点项目组先行先试，业务、开发和测试协同工作，对其他条线的交付成果充分验证，并适时将先行探索的优秀实践反哺组织级，最终达到需求研发过程快速迭代，端到端全链路交付无缝衔接，产品交付更快捷、项目管理更规范、代码质量和研发效率大幅提升的显著效果。在工程推进期间，恰逢疫情，各条线人员主动作为、加班加点、努力开拓，最终实现六个项目的顺利评估。  
**Q：在过去的一年里，团队的突出贡献有哪些？****赵：**经过团队成员一年多的不懈努力，通过工具赋能和研发活动标准化，形成由专业工具、精益流程、度量体系及配套规范构成的 DevOps 能力体系：**一是建设形成研发工具链，**实现研发闭环、全流程线上化，形成满足持续集成、持续交付、运营反馈工具集成，通过数据共享提效率，通过质量门禁控质量；**二是打造研发全流程管理链，**融合研发管理和研发实施行为、融合开发测试运维活动，形成支持瀑布和敏捷研发模式的研发管理链；**三是建立研发度量体系，**通过工具、平台间的数据共享、调度集成、双向反馈，实现研发度量数据统一视图，通过度量驱动改；**四是建设覆盖双模的 DevOps 规范体系，**构建开发、测试、运维一体化的组织形态，以及各技术角色之间分工协作框架，通过标准化研发活动及操作，降低新加入成员的学习成本。  
**Q：****在这过程中，有什么困难和难题吗？是如何攻克难关的？****赵：**推进 DevOps 能力建设及实践落地，时间紧，任务重，但是农业银行只用了一年时间就完成了首批5个项目的成功评估，其中遇到了非常多的困难，但是我们都一一克服了，路程虽远，无惧向前。首先，最难的就是疫情期间不能现场办公，大大增加了同事间的沟通成本，但是同事们依旧不惧挑战，通过每日站会等方式时刻跟踪项目进度，确保不会因沟通原因滞后进度。其次，是工具链本地化建设方面，农业银行项目管理、配置、测试、变更、部署等工具相对独立，工具间集成度低，数据复用度低，基于既有自研和已购工具做定制化开发，投入成本很大，困难点多，通过引入制品库，打通 ITA、TFS、星云等研发工具近 20 个工具、153 个接口间的断点，实现研发工具的集成，形成研发工具和流程闭环、数据传递和复用，形成满足持续集成、持续交付、运维反馈的工具链。再者，度量体系建设方面，看似简单实则很难的一个领域，要同时结合企业管理导向和评估要求，既要收集组织级数据，更要注重项目过程数据，所以在搭建度量平台方面更是反复尝试反复调整，最终形成了过程数据可视、度量驱动改进的目标。  
**Q：****在团队协作和管理方面，有哪些心得可以分享？****赵：**关于团队协作，最关键的就是如何在时间紧迫的情况下，发挥团队的最大效率。在我行确定参加 2020 年的 DevOps 持续交付标准 3 级评估时，虽然以前有一定的持续交付能力基础，但时间上也是非常紧张的，之所以能够顺利过级，就是依赖了良好的团队协作和管理机制。首先就是提高团队凝聚力，让大家齐心协力为了同一个目标而持续奋斗；其次就是有完善的团队协作管理机制，通过日报跟踪、站会等方式汇总团队进度、跟进项目流程，有效提升了团队运作效率。最关键的就是要发挥团队中每个成员的优势，充分调动成员积极性，团队才会表现出强大战斗力。  
**Q：****2021年的计划有哪些？****赵：**DevOps 评估通过仅是起点，我行 DevOps 建设任重道远，需要继续沉淀DevOps 最优实践，充分识别当前改进点，以问题为导向，深化研究，逐步拓展 DevOps 应用范围。目前正在通过内化、内测、保鲜三方面的举措，夯实 DevOps 能力的基础，同时根据研发中心各系统技术栈和成熟度情况，已分批次分阶段的推进 DevOps 能力的全面落地 ，加速研发中心精益运行，提升IT生产率，并同步内建我行的 DevOps 教练队伍，辅助 DevOps 能力推广落地，促进科技数字化转型、敏捷实践、研发运维一体化的快速发展。
