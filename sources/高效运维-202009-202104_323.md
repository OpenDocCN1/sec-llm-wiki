近期，年度报告《 2020 年开源工作报告》发布，该报告首次发现组织正在寻找比拥有开发人员（59％）更多的具有开源 DevOps 技能的 IT 人员（65％）。

《 2020年开源工作报告》显示，随着 COVID-19 大流行之后更多的工作负载转移到云中，寻求技术人员的、拥护最佳 DevOps 实践的企业数正在大幅增加。该报告发现 70％ 的受访者更有可能聘请具有云计算技能的 IT 专业人员。

根据对 175 名招聘经理和 900 名具有开源专业知识的 IT 专业人员的调查，该报告还发现，尽管大流行带来了经济衰退，但仍有 37％ 的招聘经理表示，在未来半年内他们将寻求在该行业招聘更多技术熟练的 IT 专业人员。

该报告还发现 93％ 的调查受访者表示难以找到开源人才。81%的招聘经理表示，招聘开源人才是 2020 年的重点，其中 56％ 的人才希望在未来六个月内招聘具有开源技能的 IT 专业人员，近三分之二（63％）的企业表示，他们的组织已开始以代码或其他资源支持开源项目，其明确目的是招募具有开源软件技能的人员。

更多的 IT 组织将需要集中精力发展具有开源 DevOps 技能的团队，而不是希望从其他组织引进超级巨星。从内部选择培养专业的  DevOps 技能人员是最稳妥的方式。

在如今的需求下，成为专业的DevOps 工程师是初学者的最好选择。DevOps 工程师更能支持软件开发团队实现手动流程的自动化，并提高人员和技术系统的效率。其职责包括确保为任何有需要的团队安装可使用的工具，也会通过教团队如何利用 CI / CD 和其他 DevOps 实践来帮助团队。由此可见，DevOps 工程师的薪资水平处于很高的水平。
