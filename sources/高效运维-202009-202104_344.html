 16岁少年为逃课，8次攻击至学校网络瘫痪？

据外媒报道，近日，一位来自佛罗里达州的 16 岁高中生策划了八次 DDoS 攻击，不仅让全校线上课程不得不终止了一段时间，还间接导致了地区级网络崩溃.....

据悉，这名少年已经被抓获，正面临着欺诈和干扰教育机构的双重罪名。
           
网友直呼：这招够狠，这位少年干了我多年想干不敢干的事，佩服佩服。


GitHub 源代码泄露，GitHub CEO 回应：没被黑，一切正常

Hacker News 今天一篇标题为"GitHub Source Code Leaked Online"的帖子引起了热议。

帖子被链到 TypeScript 开发者 Resynth 的博客。按照他的说法，GitHub DMCA 的官方 repo 出现了非常可疑的 commit，这些 commit 的备注是

“felt cute, might put gh source code on dmca repo now idk”。

看起来是一个不明身份的人冒充 Nat Friedman（GitHub CEO）利用 GitHub 应用的 bug 上传了一些机密源代码。

因为 Readme 显示这些代码包含 linting 配置、CI 工作流、Dockerfiles 和其他与构建相关的配置文件，以及“This is Github.com and GitHub Enterprise.”文案。

Github CEO Nat Friedman 已回复此帖子，他表示 GitHub 没有被黑客入侵，一切都很正常。所谓泄露的代码是几个月前他们意外地将 GitHub Enterprise Server 源代码未脱敏/混淆的 tarball 交付给了一些客户。（来源：开源中国）

 证监会回应蚂蚁集团暂缓上市：是对投资者和市场负责任的做法

对于蚂蚁金服暂缓上市，证监会新闻发言人称：“蚂蚁集团暂缓科创板上市是上交所依法依规做出的决定。金融监管部门的监管约谈和近期金融科技监管环境的变化，可能对蚂蚁集团业务结构和盈利模式产生重大影响，属于上市前发生的重大事项。本着保护投资者合法权益，充分透明准确披露信息，切实维护市场公平公正的原则，上交所依据科创板注册管理办法相关规定作出了暂缓蚂蚁集团上市的决定。（来源：新浪科技）                      

Docker 限制 Docker Hub 上免费用户镜像拉取次数

Docker 宣布要在 11 月 1 日，对平台上的镜像实施两个新政策，分别是移除免费帐户中，长期无人使用的镜像文件，另外则是限制免费使用者拉取镜像的次数，现在官方宣布暂缓前者，在 2021 年中之前，都不会删除长期无人使用的镜像，但在 11 月 1 日，仍会开始限制免费帐号的镜像拉取次数。是因为官方发现，仅占所有用户 1％ 的匿名使用者，却产生 30％ 的拉取请求，因此 Docker 决定要限制匿名免费用户的拉取次数，每 6 小时只能拉取 100 次，经过验证的用户，每 6 小时可以拉取 200 次。

 双 11 给服务器“泡澡”散热，阿里云启用全球最大液冷数据中心

11月3日，在阿里巴巴双11技术沟通会上，阿里巴巴副总裁、阿里云基础设施负责人周明表示，为支撑屡创纪录的交易峰值，2020年双11将有包括张北、乌兰察布、河源、南通、杭州在内的五大超级数据中心合力支撑。其中在杭州数据中心内，全球规模最大的液冷服务集群将有上万台液冷服务器投入生产处理双11的海量计算工作，这些服务器的网线连起来，可以绕地球一周。
据悉，阿里巴巴重构了业内罕见的“给服务器泡澡”冷却技术——工程师将服务器浸泡在特殊的绝缘冷却液中，散热全程无需风扇、空调等制冷设备，大大降低了数据中心的能耗，整体节能超70%。除了硬件外，阿里工程师还设计了一套适合浸没液冷的监控管理系统，故障率降低了50%。（来源：墨天轮）


忍无可忍，谷歌披露 GitHub 高危漏洞

谷歌 Project Zero 披露了 GitHub Actions 中存在的严重安全漏洞。
Actions 主要负责与“动作执行器”（Action Runner）之间的通信工作。这次问题在于，GitHub Actions 中的工作流命令极易受到注入攻击。
根据 Project Zero 团队的披露，当进程解析至 STDOUT 的每一行，以寻找工作流命令时，每个 GitHub Actions 操作都会在执行过程中打印出不受信任的内容。在大多数情况下，设置任意环境变量的功能，会在执行另一个工作流程后立即执行远程代码。换言之，这一缺陷使之极易受到注入攻击。
GitHub 最终决定弃用易受攻击的命令，并发出“中等严重的安全漏洞”的修补建议，通知开发者更新其工作流程。但这只是临时性应对措施，由于问题如 Felix Wilhelm 所说，是“根本性的”不安全问题，长期解决仍需将工作流命令从界内通道移往它处，而这么做又会破坏其它相关代码。Felix Wilhelm 也无法确定该如何解决这个问题 ，GitHub 并没有完成修复。（来源：51CTO）

 TIOBE 11 月榜单：Python 挤掉 Java，成功跃至第二

Python 已成功跃居榜单第二名，本月排名率为 12.12%；Java 被挤到第三位，排名率降至 11.68%。自有 TIOBE 榜单以来，C 和 Java 之前一直占据着前两名的位置。然而现如今，C 仍然是第一名，但 Java 却已经被 Python 成功赶超。 
TIOBE CEO Paul Jansen 称，前段时间他的车在路上爆胎了，于是打电话给路政巡警帮忙解决。在和工作人员的闲聊中，修理工曾非常热情的谈论起了自己的爱好，即：用 Python 编程。他表示，“从那一刻起，我就知道 Python 会变得无处不在了。”（来源：开源中国）

 10 年官司终落败，苹果判赔 5 亿美元，原告是神秘“专利巨魔”

北京时间 11 月 2 日，彭博社报道称，得克萨斯州的一个陪审团裁定，苹果必须向 VirnetX 公司支付 5.028 亿美元的 VPN on Demand 特许权使用费，该功能使 iOS 用户访问 VPN 连接。两家公司之间的法律纠纷已有十年之久，VirnetX（有媒体称之为“专利巨魔”）宣称苹果的 VPN on Demand 和 FaceTime 使用了他们的技术。（来源：新浪科技）

 甲骨文发布紧急补丁修复 WebLogic Server 严重漏洞（CVE-2020-14750）

据外媒报道，10 月更新的严重漏洞 CVE-2020-14882 补丁刚过去不久，甲骨文在周末又发布了带外安全更新，修复了影响多个 Oracle WebLogic Server 版本的关键远程代码执行（RCE）漏洞。

甲骨文向安全公告中的 20 家组织和人员表示感谢，因为他们提供了有助于公司修复 CVE-2020-14750 漏洞信息。（来源：E安全）
