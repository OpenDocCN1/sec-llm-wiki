2020 年 9 月 25 日，2020 GOPS 全球运维大会在深圳圆满举行。本次大会盛况空前，精彩纷呈，中行、招行、腾讯、阿里、京东、广东移动等名企专家献上一场精彩的分享。

GOPS 全球运维大会由云计算开源产业联盟（OSCAR）指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十四届 GOPS 全球运维大会在深圳正式召开。GOPS 全球运维大会至今已经举办了 13 届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。

在大会现场我们采访了腾讯云 CODING DevOps 创始人兼 CEO 张海龙，他分享了企业产品及参加本次大会的感受。
腾讯云 CODING DevOps 创始人兼 CEO 张海龙


Q：请老师先简单介绍一下您和您所在的企业。
张：大家好，我是张海龙，我们的产品叫作 CODING DevOps，我是程序员出身，从 2014 年开始做 CODING 云端的研发管理平台，从最早的代码托管慢慢延伸到整个 DevOps 领域。目前 CODING DevOps 包括代码托管、项目管理、测试管理、持续集成、制品库和持续部署等多款功能和服务，涵盖了软件开发从构想到交付的一切所需，研发团队可以在云端高效协同，实践敏捷开发与 DevOps，提升软件交付质量与速度。

Q：可否介绍一下贵公司的技术产品，有什么独特之处？有哪些成功案例？
张：CODING 从最早是比较单一的代码托管平台，发展到现在成为一站式的平台，最大的亮点是全生命周期的管理。做技术的软件开发人员应该都知道，在开源的领域，在每一个功能点上，比如说代码管理或持续集成都有相应的开源工具。但是 CODING 最大的亮点是可以从需求，到最后软件的发布整个一站式地全部串联起来，在一个系统里清晰地看到整个软件开发的流程，不用在系统之间做跳转，也不用权限账号的打通，数据会有更好的沉淀，为将来做各种度量，做各种数据的挖掘提供更多的帮助。事实上对于一站式的平台，很多的客户有非常迫切的需求，我们在中国银联、墨刀、深圳农商行、PICC人保、富士康等企业等等都有相应的实践，不同的企业有不同的场景，我们也会有相关的架构师为不同的企业做相关场景的适配。目前看起来不同行业研发的流程，对于一站式的需求越来越大，我们也希望我们的产品给大家带来价值。

Q：此次参加 2020 GOPS 全球运维大会深圳站 有哪些感受？
张：刚到会场的时候感觉非常的热闹，没有想到这么多人参加这个会，在会场的展区也看到了非常多类似的厂商，或者上下游的合作伙伴，我觉得高效运维社区把这么多生态链上的厂商，包括使用者和开发者都聚在一起，大家有一个交流的空间，我也希望通过这个会议跟我们的客户、开发者和上下游的厂商有更好的互动，后续形成一些合作。
