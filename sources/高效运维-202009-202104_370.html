一、运维开发工程师（广州）岗位职责:

  1. 为信用卡IT运维团队进行IT技术支撑，参与信用卡基础运维工作；

  2. 参与设计、开发、优化信用卡运维系统以及各业务系统的体系架构；

  3. 负责自研平台相关自动化运维工具开发以及自研平台日常运维运营工作；

  4. IT团队日常工作支持。

岗位要求:

  1. 计算机或相关专业全日制本科及以上学历，精通Linux、Windows操作系统；

  2. 具备2年以上运维开发经验，熟悉Python、shell、Java、PHP、C/C++开发语言，有良好的编码规范；

  3. 熟悉 Python 和 web前端开发，使用过Django、flask等应用框架，有过Python项目经验者优先考虑；

  4. 对云计算、虚拟化领域有接触或浓厚兴趣，对DevOps、AIOps、数据治理相关工作经验或感兴趣者加分；

  5. 有运维自动化、监控系统、发布系统、配置管理、任务调度、运营支撑系统等开发经验者优先；

  6. 思维敏捷，富有创新精神，具备良好的分析判断能力；

  7. 有良好的沟通能力、学习能力和服务理念，对工作认真负责，积极主动。

二、运维工程师（广州）岗位职责:

  1. 负责信用卡相关业务系统运行故障和生产差错的处理，协调开发共同分析和定位问题原因，跟进处理进度，及时与业务沟通反馈，与开发共同制定和实施解决方案；
  2. 对各类生产差错进行整理，分析系统优化可行性，并提出合理化建议；解答业务部门关于信用卡业务系统的咨询。
  3. 对系统资源使用情况进行监控和分析，对系统资源使用提出合理化建议。
  4. 负责业务系统对应的应用服务器及相关中间件管理，实施信息安全措施;负责相关运维管理制度的编制和执行。

岗位要求:

  1. 计算机/金融等相关专业全日制本科及以上学历，精通 Linux、Windows 操作系统；

  2. 具备3年以上系统运维工作经验，熟悉 Python、shell 等脚本语言；

  3. 熟悉 DevOps流程，CI/CD 持续部署相关工具的应用和配置；

  4. 熟悉 Nginx/Tomcat/MySql/MQ/Memcached/Redis 等软件系统的安装、监控、排错、配置、运维和调优能力；

  5. 熟悉主流系统架构，包括分布式、微服务、容器化、云计算、大数据等技术，对主流的高可用、负载均衡方案有较深理解；

  6. 对云计算、虚拟化领域有接触或浓厚兴趣，对 DevOps、AIOps、数据治理相关工作经验或感兴趣者加分；

  7. 有大型系统项目参与经验者，或深入了解信用卡业务相关系统知识者优先考虑；

  8. 有良好的沟通能力、学习能力和服务理念，对工作认真负责，积极主动，能承受高强度工作压力。
