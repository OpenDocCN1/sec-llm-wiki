2020年10月27日，云原生领域创业公司睿云（wise2c.com）已完成首轮千万元的股权融资。本轮融资由数字化领域新锐企业成都万维图新信息技术有限公司战略投资，欣羽鸿联跟投。新融资主要用于加大产品研发、市场营销和技术服务等方面。

  
  
  
  
  
  
  
  
  
  
  
  
  
  

睿云是 Linux 与 CNCF 基金会会员，全球首批 Kubernetes 官方认证服务提供商（KCSP），旗下产品 WiseCloud 是全球首批 Kubernetes 官方认证平台提供商。交付团队全员考取Kubernetes 官方认证工程师证书。

  

睿云的 WiseCloud以 Kubernetes 为容器基础，通过友好的人机交互实现完善的多集群管理、DevOps、微服务治理、应用管理等功能，在物理机、虚拟化和云端各种异构基础设施环境中快速构建、部署、运维容器架构，实现应用的敏捷开发与全生命周期管理。WiseCloud 还集成多种云原生技术工具，提供面向研发和运维的统一基础服务平台。

  

从 2016 年开始，睿云率先将容器技术引进到中国保险行业，并在生产环境成功落地。之后一直把业务聚焦在容器服务与云原生领域，已经累计服务以金融行业为主的企业客户超过 50 家，其中不乏有中国太平、招商金科、平安科技、恒丰银行、富德生命人寿、恒大人寿、民生人寿、安盛天平、国任保险、中宏人寿、太平金服等标杆性的金融企业。

对于本次融资成功和新合伙人加入，睿云创始人兼CEO 钟巧红女士表示：“一直以来，睿云一步一个脚印围绕着金融客户的需求踏踏实实地做产品做服务，取得了一些成绩，但在风起云涌的行业大潮中，我们前进的速度还是不够快，这次不光是借助资本的力量，我们还邀请到云计算行业老兵卢敏先生以联合创始人身份加入睿云。卢敏在华为公司营销与战略团队履职多年，后加入青云成为第三号员工，任职副总裁，帮助青云构建了全国的营销体系。相信卢敏先生丰富的营销经验和行业资源，能够带领睿云加快商业服务的步伐。"

  

新晋合伙人卢敏表示：“因为疫情的原因，本该在年初完成的融资稍有延迟，目前投资已经到位，正好也赶上睿云新战略的发布。2016 年睿云随 docker 技术大潮进入云原生领域，2018 年推出自主知识产权的产品，从现在开始我们会以WiseCloud为核心，拓展基于容器数字化底座的应用方案。金融行业里，我们会打造更具价值的创新性行业解决方案；其他行业里，我们会携手战略合作伙伴，为他们丰富的应用提供坚实且灵活的容器底座平台。"

  

万维图新执行总经理杨霖，对于此次投资表达了乐观的预期：“睿云团队在金融行业，尤其是保险领域取得了傲人的市场业绩，很多客户都是长期合作的知名企业，这让我们对于睿云团队充满信心，希望通过我们的投资，以及万维图新在电信与政企行业里的资源和西南地区的布局，能够帮助睿云服务于更多的客户。"

**睿云智合**

深圳睿云智合科技有限公司是由金融科技、云计算行业营销与技术专家共同创立的高科技企业，业务聚焦在容器服务与云原生 PaaS 领域，公司是 Linux 与 CNCF 基金会会员，全球首批 Kubernetes 官方认证服务提供商（KCSP），旗下产品 WiseCloud 是全球首批 Kubernetes 官方认证平台提供商。

2016 年开始，睿云率先将容器技术引进到中国保险行业后，不断帮助企业客户将云原生技术应用于新一代 IT 架构平台建设，目前已经为金融、政企、医疗、运营商、制造、能源、教育及互联网等行业客户基于容器技术和微服务架构，提供全生命周期企业应用服务管理，为企业数字化转型和业务发展赋能。

  
  
  
  

**万维图新**

成都万维图新信息技术有限公司是成都市国家高新区瞪羚企业55强，入选成都市新经济“双百强”重点企业、成都市“小巨人”培育计划等荣誉榜单。

公司主要客户包括中国移动、中国电信、中移全通系统集成有限公司、四川省铁投集团、成都产业投资集团等大型中央、省、市国有企事业单位。
