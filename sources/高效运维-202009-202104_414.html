史上最大服务中断事故：全球互联网流量下降3.5%只因一次配置错误？

近日，美国互联网服务提供商 CenturyLink 因数据中心的错误配置导致多个网站受到影响。据了解，这次事故是 BGP 路由配置错误引起的连锁反应，受到影响的服务包括 Cloudflare、AWS、Garmin、Steam、Discord 和 Blizzard 等。
  Twitter 用户吐槽服务中断

在此次事故中受到严重影响的 Cloudflare 表示：“CenturyLink 的向外传播问题导致全球互联网流量下降了 3.5%，这将是有史以来最大的互联网中断之一。”最终，CenturyLink 花了 7 个小时才解决了这个问题。（来源：InfoQ）


百岁“蓝色巨人”迎历史性变革 IBM宣布重大拆分押宝云计算

老牌科技巨头IBM上周四正式宣布将拆分为两家上市公司，以专注于加强混合云平台和AI能力。根据最新的拆分计划，IBM会将IT基础设施服务部门单独上市，该部门包括一系列旧的基础架构以及相关的数字化转型，但不包括服务器业务。
IBM新公司名为NewCo，将于2021年底前完成更名拆分。IBM CEO阿尔文德·克里希纳称，此次拆分是拥有109年历史的IBM 业务的重大转变，云计算市场规模高达1万亿美元，现在是双倍押注混合云的时候。在克里希纳的主导下，去年IBM以340亿美元收购了红帽软件。（来源：第一财经）


TIOBE 10 月榜单：Python 有望第二？Rust 出局前二十


TIOBE 公布了 2020 年 10 月的编程语言排行榜。Python 的受欢迎程度已十分逼近排在第二的 Java，本月排名率为 11.28％，达到历史新高。而 Java 已降至 12.56%。自有 TIOBE 榜单以来，C 和 Java 一直占据着前两名的位置，Python 则从后面一路奋起直追，去年才升上第三名。依照目前的排名数据涨幅，拿下第二也不是没有可能。（来源：开源中国）

  
           

Oracle Linux 7.9发布：Linux 5.4 LTS与UEK 6构建

甲骨文刚刚发布了 Oracle Linux 7.9，作为该公司最新推出的企业级 Linux 发行版更新，其引入了许多新功能和体验改进。 据悉，Oracle Linux 7 的 Update 9 基于红帽企业 Linux 7.9 构建，并将牢不可破的 UEK 6 企业内核作为主流 x86_64（64-bit）和 AArch64（ARM64）平台的默认内核。
            

思科被判四项专利侵权：需支付19亿美元赔偿金

10月10日讯，美国法官周一责令思科向弗吉尼亚州一家公司支付19亿美元赔偿金，后者指控思科抄袭其网络安全专利。在经过一个月的无陪审团审判后，弗吉尼亚州诺福克（Norfolk）的美国地区法官亨利·摩根（Henry Morgan）判定，思科侵犯了弗吉尼亚州私人持股公司Centripetal Networks（以下简称“Centripetal”）的四项专利，但并未侵犯另一项专利。
摩根在一份长达167页的判决书中表示，此案对思科来说“并非侥幸脱险”，指出该公司提供的证据不一致，且其自己的技术文件“证明了Centripetal发起的诉讼案”。思科被责令支付18.9亿美元的赔偿金，这反映了Centripetal遭受的7.558亿美元实际损害，再乘以2.5以反映思科的“故意和恶劣”行为，外加判决前利息。
摩根在判决书中写道，对于上述四项专利，“思科在审判中没有提出任何客观合理的辩护”。他补充称：“侵权功能是在2017年6月20日之后添加到被指控的思科产品中的，这促使其销售额大幅增长，而思科在技术和营销文件中都吹嘘了这种增长。”
思科发言人在一份声明中说：“鉴于有大量的证据表明并未侵权、无效，更何况思科的创新比对方的专利早好多年问世，我们对初审法院的裁决感到失望。我们会向联邦巡回法院提出上诉。”（来源：新浪科技）


诺基亚迁移到谷歌云：签下五年大单！

芬兰诺基亚周三表示，已与谷歌签署了一份为期五年的协议，将其IT基础设施（包括数据中心）换成谷歌的云产品，这家网络设备厂商在竭力削减成本。
诺基亚在一份声明中说：“由于减少了场地占用面积、硬件能耗和硬件容量采购需求，预计这份协议会随着时间的推移大幅提高运营效率、大幅节省成本。”
诺基亚没有透露合同的财务细节，但表示全部迁移需要18个月至24个月才能完毕。（来源：云头条）

曝微信视频号正内测直播功能，可无限制转发到朋友圈和群聊

近日，有网友爆料，视频号正在灰度测试 “直播”功能，不能打赏，但能点赞、能带货，还能无限制转发到群聊和朋友圈。具体来看，微信视频号在原本 “发表新动态”功能右侧新增 “发起直播”键，点击后出现 “直播”和 “直播预告”两个选项。点击直播选项，可直接进入直播页面；直播预告选项则可支持用户创建预告、提前设定直播时间。
据悉，该内测功能内测范围较小，随机发放。值得一提的是，其内测时间也较短，短暂上线后，部分用户的 “直播”功能已经下线。（来源：互联网）


赔偿 525 万？联想前副总裁跳槽小米仲裁案后续，常程不服提起诉讼

9月17日，联想方面在北京对常程提起劳动仲裁，近日，这一仲裁案有了新进展。10月9日，北京市海淀区劳动人事争议仲裁委员会发布了有关联想集团与前员工常程的劳动仲裁结果：常程继续履行竞业限制义务，并且要求常程于本裁决书生效之日起十日内，支付联想移动通信进出口（武汉）有限公司违反竞业限制义务违约金525.2821万元和竞业限制补偿金7.2万余元（税前）。但是驳回联想移动通信进出口（武汉）有限公司其他仲裁请求。这意味着常程需要继续履行竞业限制义务，同时违反竞业限制义务违约金也会由小米集团和常程支付给联想。
目前，小米方对此事表示不回应。据悉，对于这一结果，常程已委托律师事务所提起诉讼。被委托的律师事务所在声明中称，“裁决书依法未生效”。目前，常程微博认证依旧为小米集团副总裁。（来源：CSDN）
