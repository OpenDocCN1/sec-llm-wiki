燃！浙江移动通过 DevOps 系统和工具标准首批评估，相关项目能力达到国内领先水平！

编者按：从各大企业的实践来看，标准化和工具化是实践组织级 DevOps 的基石，唯有统一标准，并固化到工具中，才能最大程度减少人为失误，减少人力成本，提高开发和运维的效率及质量。

2020 年9月 25 日，由云计算开源产业联盟（OSCAR）指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十四届 GOPS 全球运维大会在深圳正式召开。GOPS 全球运维大会至今已经举办了 13 届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。

大会隆重发布了 DevOps 标准系统和工具部分首批评估结果。中国移动通信集团浙江有限公司（以下简称“浙江移动”）本次参评的浙江移动蜂云能效平台项目。该项目顺利通过由中国信息通信研究院（以下简称信通院）开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具部分首批评估，在其构建与持续集成模块获评为优秀级。代表着浙江移动的 DevOps 系统和工具在相关模块达到国内领先水平。


评测单位：中国信息通信研究院

中国信息通信研究院云计算与大数据研究所所长何宝宏博士为浙江移动授牌：

此次，我们采访了中国移动通信集团浙江有限公司信息技术部副总经理任赣，一起深聊浙江移动蜂云能效平台项目参与评估的细节和幕后团队的故事，分享浙江移动 DevOps 实践的经验。


-Q&A-  

中国移动通信集团浙江有限公司信息技术部副总经理

任赣


Q： 老师您好，请介绍一下您和您的企业，以及此次参与评估的项目。

任：本人目前在中国移动浙江有限公司信息技术部，任职副总经理。有 20 多年IT领域的工作经历和经验，对IT领域的业务、架构、技术等方面有深刻的了解和理解，先后从事过IT领域的规划、建设、开发及运维各专业方向的工作，目前主要负责浙江移动智慧中台的规划及业务中台的建设、开发工作。

中国移动浙江公司（简称“浙江移动”）隶属于中国移动通信集团有限公司，统一经营浙江省的中国移动通信网络。公司于 1997 年在全国通信行业中最早在海外（香港、纽约）上市，建立和不断完善符合国际惯例的企业治理结构，成长为业绩优秀、管理出色、服务优质、行业领先的主导运营商，实现了国有资产、品牌价值的保值增值。截至 2019 年底，公司员工总数 1.9 万人，总资产规模超 930 亿元，全年实现运营收入超过 470 亿元，连续两年蝉联全集团第一，移动客户和宽带客户份额均居行业第一位，是全集团的标杆企业、省内规模最大的电信运营商。

浙江移动信息技术部作为公司IT能力枢纽，负责公司IT系统的发展规划、建设开发、生产服务和运行保障等工作，致力于构建运营商企业级大IT中台、云原生架构下的大PAAS 平台，以数据驱动IT运营和新业务的发展，以效率服务内部管理和市场发展，以大IT平台使能公司全域智慧运营，助力公司持续健康发展

本次参与评估的项目为浙江移动蜂云能效平台。该项目为目前浙江移动内部系统主要的构建和持续集成的平台，承建了全部的内部系统应用的构建和集成发布工作，提供一站式的系统应用接入服务，以敏捷开发为服务目标，提供一键发布的能力，有效提升研发效能，实现了可靠、高效、灵活的持续交付。


Q： 恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是系统与工具标准，您的感受是怎样的？

任：很高兴浙江移动能够参与中国信息通信研究院组织研发运营一体化 DevOps 能力成熟度模型构建与持续集成模块的评估。我们的项目达到了优秀级水平，这是对浙江移动从传统研发模式向 DevOps 高效研发模式转型过程的肯定，证明了我们团队的能力，和为公司做出的贡献的价值。我们将继续演进，坚持不懈的走下去。


Q： 打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？

任：打造端到端的流程化、一体化的工具链是一个落地 DevOps 的工具，可以提高IT系统的交付效率和交付质量，降低复杂度，推动组织更快的完成企业数字化转型，赋能一线。


Q： 贵单位参与本次系统和工具标准评估，请问企业有哪些考量？有科技输出的规划么？

任：企业数字化转型是国家级战略，DevOps 工具链路能够有效的加速战略执行落地。在公司层面和整个中国移动集团层面，都非常重视该领域的体系建设和工具建设。浙江移动在 DevOps 流程、工具建设层面一直都是集团内部的排头兵，有效的实践加上标准化的评估后能够面向全集团输出成果，更好的服务于公司转型战略。


Q： 通过系统和工具标准评估带给企业和团队哪些变化？

任：企业的流程和团队模式在标准评估后带来了实质性改进，系统化的全面评估，明确了 DevOps 能力基线，并在此基础上找到差距点并逐条改进。同时也需要结合行业特性和组织特点，量身打造合适的工具链，最终能够系统全面提升企业级的 DevOps 能力。

评估的过程中，对于能力项标准要求差距的理解，加深了团队对于 DevOps 一些最佳实践的理解，从而有效的将 DevOps 能力相关的一些最佳实践引入到企业团队中，帮助企业团队快速提升了交付能力。


Q： 您通过本次评估，项目的改进成果体现在哪些方面？

任：我们的持续交付平台已经在浙江移动内部系统中全部推广使用，已经接入了 400多个系统，包括了浙江移动的地市，电渠，业务支撑，大数据，云管等多个部门的系统。为每个接入系统管理了从开发到生产等多套系统运行环境的构建和集成，累计接入了 1500 多的系统应用环境管理。各类环境每月构建 10000 多次，每月承接各类系统生产发布服务 1000 多次，重点支持了浙江移动业务支撑域核心系统发布。为开发，测试，运维等各类用户提供服务支持，服务了2000多的用户数量。建立流水线约 5000 条，流水线执行总量近 67 万次。实现小时级生产发布，支持紧急需求当天上线。对于此次参评的项目级改进成果主要有以下几个方面：持续集成响应时间由每天一次集成优化为代码提交合并既集成；编译构建时长由 30 分钟下降至 5 分钟，同时在编译阶段集成了代码静态扫描、质量门禁等质量保证措施，以及单元测试、接口测试等自动化测试；生产发布频率由每月 2次提高到每月 4-8 次，生产发布前置时间由1天缩短为 2 个小时。


Q：对于此次参评的项目规划和设计有哪些特色与不同？

任：此次参评的项目结合了浙江移动自身的业务特点，规划和设计了符合浙江移动内部系统的发布管控要求和系统应用架构特点的构建和持续集成的工具平台。

比如基于通过浙江移动架构治理管控要求的系统应用来进行构建管理，要按照架构治理管控的要求进行构建管控。同时在构建时支持通过浙江移动的内部的配置中心获取对应系统应用的对应环境的配置文件构建入应用的代码包中。在构建成功后，支持自动通过浙江移动内部的微服务管理平台触发对应应用的注册服务的上架发布，调用缓存平台刷新对应系统应用的缓存配置等功能，从而达到一站式的，快速的发布部署浙江移动自身特点的系统应用。


Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?
任：在此次评估过程的确有困难需要解决，但是企业团队在标准评估后带来了实质性改进，系统全面提升企业级的 DevOps 能力，价值重大，我们也不惧挑战。在过程评审过程中，需要对标能力项的评估标准和要求，找到差距点并逐条改进。怎么在找到差距点时，正确的理解能力标准要求，快速的设计改进方案，规划改进计划，并在规定时间内及时的完成对应的改进工作，对于整个团队的响应能力，交付能力都带来了一次挑战。特别是部分功能需要跨团队，跨部门协作，怎么及时推进外部团队按照计划完成配合，协调难度很大。但是我们不畏艰辛，合力攻坚，通过多次的专题会议，多部门的骨干人员协同专研，共同推动评审改进的落地。采用敏捷开发的模式，快速迭代交付，在收到改进需求后能在当天就上线发布部分改进功能，从而快速的完成评审的改进点。


Q： 对于 DevOps 工作的开展，下一步计划有几方面？ 

任：计划进一步提升部署发布频率，解决高频部署发布中的障碍，引入低风险的发布，例如蓝绿发布、灰度发布，滚动升级等，研究高频发布支撑技术。同时扩大 DevOps 闭环管理范围，将软件项目全生命周期工作纳入到 DevOps 管理体系中来。


Q： 对于 DevOps 的未来发展方向，您有何看法？

任：提升软件交付效率是数字化转型的成功关键之一，而 DevOps 是提升软件交付效率有效的实践。随着越来越多的企业开始数字化转型，DevOps 的发展也会变成组织管理的发展趋势，在IT领域越来越普适。对于不同行业，不同企业的数字化过程中，DevOps 也肯定会发展出各自所在行业特点和企业特点方向。

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已在中国通信标准化协会（CCSA）立项在研。
与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
