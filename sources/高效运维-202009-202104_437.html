编者按：从各大企业的实践来看，标准化和工具赋能是科技公司成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，使得企业的软件研发效能飞速提升、更快更灵活应对市场变化，助力IT成为企业的核心竞争力之一。
2020 年9月 25 日，由云计算开源产业联盟（OSCAR）、工信部信通院数据中心联盟（DCA）为指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十四届 GOPS 全球运维大会在深圳正式召开。GOPS全球运维大会至今已经举办了13届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。
大会隆重发布了 DevOps 标准持续交付部分第八批评估结果。上海赛可出行科技服务有限公司（简称“赛可出行”）本次参评项目为享道出行后台系统项目，该项目顺利通过由中国信息通信研究院（以下简称信通院）开展的《研发运营一体化（ DevOps ）能力成熟度模型》持续交付部分 3 级评估。DevOps 标准共分 5 级，持续交付部分如果能达到 3 级已经是国内领先水准，这代表着赛可出行在参评项目的持续交付能力达到国内领先水平。

评测单位：中国信息通信研究院

此次，我们采访了上海赛可出行科技服务有限公司运维支持中心总监周莹，一起深聊享道出行后台系统项目参与评估的细节和幕后团队的故事，分享赛可出行 DevOps 实践的经验。

-Q&A-


赛可出行运维支持中心总监 周莹


Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。
周：赛可出行是上汽旗下面向移动出行的战略型企业。这个企业成立于 2018 年，汇聚了一群互联网人，经历了一段非常快速的发展到达现在的状态和规模。享道是我们的 C 端出行产品的品牌，本次参评的就是享道的后端核心系统。


Q：恭喜您通过 DevOps 持续交付标准 3 级评估，请说一下您此时的感受。
周：有些欣慰，这个结果也在意料之中。我们会将这个标准作为我们的标准和起点，向其他产品线乃至其他分子公司兄弟公司推广 DevOps 的理念，一同去追求更高的产品标准和工程效率。


Q：贵公司是如何决定加入 DevOps 标准评估工作中的？
周：DevOps 的理念是这个公司的核心技术团队的共识，实际上已经融入各自工作中，但在实践中我们会加入各自的理解和妥协。这个标准本身吸引了我们，一方面让我们有机会验证我们的理解，另一方面让我们有机会通过评估去学习业内的先进经验，这两个理由都让我们无法错过这个评估学习的机会。


Q：通过 DevOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？
周：最大的帮助是让整个技术团队经历了一次理念的洗礼，并有了一个比较完整的自我认知。


Q：可否请您详细的介绍一下，通过本次评估有哪些数据指标可以直观的体现项目改进成果？


Q：此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？
周：参评系统均为微服务架构，并行设计开发，需求迭代密度高；运行环境中负载高流量大，且对稳定性要求高。因为处于最核心位置，软件质量和工程效率需要并重，新的方法、工具、架构在短暂验证后都会进入这个项目。


Q：此次通过评估的过程顺利吗？遇到什么困难？如何解决的？
周：最大的困难是平衡，产品开发任务目标和工程效率建设目标对资源都有要求，经常会出现计划冲突。主要解决方案是达成共识，特别是让工程效率建设的结果可衡量。


Q：对于 DevOps 评估的实施，您觉得最大的收获是什么？您的下一步计划是？ 
周：既有自身产品质量和工程效率方面的收获，也有团队协作能力的收获，还有对外部宣传的底气。
下一步计划是跟进 DevOps 能力评估标准在技术运营和产品设计方面的标准，以及挑战一下持续集成方向上部分四级标准。


Q：对于 DevOps 的发展前景，您怎么看？
周：前景很好，因为这个理念在价值链上自洽并且在方式标准上自由开放，我认为 DevOps 理念推动了最近 5-10 年的工程效率工具领域的高速发展，至今势头不减。
DevOps 理念标准化以后的前景会更好，特别适合国内环境。目前国内公司技术驱动比例偏低，普及标准可以让此比例上升，还有利于先进工程技术发展和推广，最后这些都会体现为国际竞争力。
希望这个标准向严肃、专业、权威、与时俱进的方向发展。

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个DevOps系列标准，目前，由中国信息通信研究院主导的DevOps标准已在中国通信标准化协会（CCSA）正式立项。DevOps 标准已在联合国直属标准化组织 ITU-T 正式结项，成为国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分的评估。
