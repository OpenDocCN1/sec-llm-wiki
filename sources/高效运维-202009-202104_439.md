# 燃！中国电信系统集成公司通过 DevOps 系统和工具标准首批评估，相关项目能力达到国内领先水平！

**编者按：**从各大企业的实践来看，标准化和工具化是实践组织级 DevOps 的基石，唯有统一标准，并固化到工具中，才能最大程度减少人为失误，减少人力成本，提高开发和运维的效率及质量。

2020 年9月 25 日，由云计算开源产业联盟（OSCAR）指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十四届 GOPS 全球运维大会在深圳正式召开。GOPS 全球运维大会至今已经举办了 13 届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。

**大会隆重发布了 DevOps 标准系统和工具部分首批评估结果。**中国电信集团系统集成有限责任公司（以下简称“中国电信系统集成公司”）本次参评的比翼协同研发平台顺利通过由中国信息通信研究院（以下简称信通院）开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具部分首批评估，在其构建与持续集成模块和流水线模块均获评为优秀级。代表着中国电信系统集成公司的 DevOps 系统和工具在相关模块达到国内领先水平。

  

****评测单位：中国信息通信研究院****

此次，我们采访了中国电信 DICT 中心研发管理部副总经理、中国电信系统集成公司软件服务部副总经理、软件共享研发中心总经理王彦君，一起深聊中国电信系统集成公司比翼协同研发平台项目参与评估的细节和幕后团队的故事，分享中国电信系统集成公司 DevOps 实践的经验。

  

**\-Q&A-**  

![](../Images/b4fc70e5ee323ed6f003997b1b14c426.png)

DICT 中心研发管理部副总经理、中国电信系统集成公司软件服务部副总经理、软件共享研发中心总经理 

王彦君

  

**Q： 老师您好，请介绍一下您和您的企业，以及此次参与评估的项目。****王：**中国电信集团系统集成有限责任公司（以下简称“中国电信系统集成公司”）是中国电信股份有限公司的专业化全资子公司，是中国电信提供综合信息服务的主力军，专注于为政企、金融等行业客户提供涵盖云计算、大数据、安全灾备服务、网络系统建设、系统运营维护以及移动互联网应用等在内的融合 ICT 服务。

比翼研发云平台是 DICT 应用能力中心牵头，整合系统集成体系各公司多年研发积累，打造的行业领先基础研发平台。本次参与评估的平台是比翼协同研发平台，它是一款项目管理及自动化持续集成软件。它集项目管理、应用自动持续化集成管理、测试申请管理等功能于一体，可以帮助项目团队中的不同角色敏捷、高效地完成各自的任务以及相互之间的协作任务，基本形成了从产品需求—项目研发—应用构建—产品测试—产品发布这样一个覆盖产品研发整个生命周期的管理闭环。

  

**Q： 恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是系统与工具标准，您的感受是怎样的？****王：**很高兴能够通过研发运营一体化（DevOps）能力成熟度模型系统与工具评估。比翼协同研发平台是中国电信首个参评的系统与工具，取得了开门红。通过本次评估，切实提升了平台的持续集成和流水线能力，在团队中贯彻了 DevOps 理念，同时为其他应用的 DevOps 建设提供了一个研发运维一体化平台。

  

**Q： 打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？****王：**端到端的流程化、一体化的工具链，可以简化 DevOps 落地的整个流程，为提升项目研发效率，更快速、便捷地交付项目需求、更好的协作发挥了积极作用。

  

**Q： 贵单位参与本次系统和工具标准评估，请问企业有哪些考量？有科技输出的规划么？****王：**中国电信正在 3.0 转型：着重推进网络智能化、业务生态化、运营智慧化，为用户提供综合智能信息服务，引领数字生态，服务产业转型升级和社会治理创新，目标是做领先的综合智能信息服务运营商。在这个背景下，我们需要通过 DevOps 理念和方法论提升软件交付速度和交付质量，传统的网络运维工具手段已远远无法满足要求，这就要求我们基于 DevOps 快速打造全新的网络技术运营体系。最初衷的想法是想通过对标信通院的成熟度标准来确定我们的 DevOps 平台能力到底处在什么水平，在接受评估的过程中找到自身的差距，指导平台后续开发建设。目前项目也申请了相关软著以及专利。  
**Q： 通过系统和工具标准评估带给企业和团队哪些变化？****王：**DevOps 标准评估对企业来说，能够在落地 DevOps 最佳实践的过程中提供系统性的参考依据。DevOps 自兴起以来，还没有相关的标准能够指导企业进行实施。通常他人的经验并不一定适合自己。因此需要通过标准来指导实践，并且通过标准的分级，能够让企业了解自身的 DevOps 能力处于何种水平，找准差距，以推动持续改进。通过标准评估，也是对团队在 DevOps 系统与工具建设上的肯定，意味着比翼协同研发平台的持续构和流水线相关能力已经达到了一定的高度，也为我们指明了向更高级别 DevOps 成熟度学习的方向，我们还需要向业界先进的科技企业学习，继续努力，深化提升、扩大推广 DevOps 实践，全力打造基于 DevOps 的研发运维一体化体系生态。  
**Q： 您通过本次评估，项目的改进成果体现在哪些方面？**

**王：**比翼平台 2019 年 1 月发布公开测试版，9 月发布 1.0 正式版，面向中国电信全体系研发人员免费使用。平台已经对外提供了 103 个成熟组件，托管了 1000 多个自研项目，成功构建应用 10000 多次，微服务环境承载 2000 多个容器，稳定运行 580 多天。

![](../Images/feaab5b9584d750ab604883b89fe8774.png)

**Q：对于此次参评的项目规划和设计有哪些特色与不同？****王：**本次参评的 DevOps 平台是比翼协同研发平台，它是基于微服务架构，集成了 Jenkins、Nexus、Harbor、Sonarqube 等常用的 DevOps 工具，并进行了深度定制化，比如通过二次开发对 Jenkins 自动化流水线进行了可视化编辑和运行过程全监控，提供基于云原生架构的一站式软件全生命周期管理。最初规划的就是从产品需求—项目研发—应用构建—产品测试—产品发布,这样一个覆盖产品研发整个生命周期的管理闭环。  
**Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?****王：**比翼协同研发平台是中国电信的第一个参评的系统与工具，我们面临着部分高级功能欠缺、改动量大等新的挑战，同时还要保证其他工功能的正常使用。各级领导非常重视 DevOps 的推广和评估工作，在组织内部 DevOps 的相关工作是有很高优先级的，为保证平台的顺利运营，我们运用 DevOps 工作模式，同时借鉴行业内其他公司的实践方法，通过整个产品团队的不懈努力、深入研究、持续改进，最终通过 DevOps 成熟度评估。  
**Q： 对于 DevOps 工作的开展，下一步计划有几方面？ **

**王：**比翼协同研发平台参与本次 DevOps 标准评估的 2 个模块，均达到较优秀级水平。领导们非常重视 DevOps 平台的推广和落地工作，我们接下来计划让一批项目使用 DevOps 模式，提高项目的开发效率，总体来说可以分为两个方面：

**1.人员赋能：**将前面使用比翼协同研发平台通过 DevOps 成熟度评估的智能预处理项目作为示范项目进行推广，分享在践行 DevOps 规范中总结的经验与教训，实现其他项目组成员的 DevOps 能力赋能；

**2.系统调整：**新建系统按照 DevOps 规范标准设计，存量系统在架构优化时不断进行 DevOps 调优。  

  

**Q： 对于 DevOps 的未来发展方向，您有何看法？****王：**DevOps 发展了 10 余年，目前已经成为软件行业最受关注的领域之一。我们看到 DevOps 在面对多变的用户需求和提高研发效率方面巨大的作用，持续高效地向生产环境发布新的功能逐渐成为一种基本的需求。在未来，DevOps 可以助力科技企业在云计算、物联网、大数据、视频等多个领域提升研发效率、规范研发流程，为深化落实中国电信“云改数转”战略，发挥作用。

**研发运营一体化（DevOps）能力成熟度模型介绍：**《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已在中国通信标准化协会（CCSA）立项在研。与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。            ![](../Images/c656d5dc0ae9a30269a21e7a55a88029.png)
