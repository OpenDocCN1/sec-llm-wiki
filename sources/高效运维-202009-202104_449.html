关于 CODING

深圳市腾云扣钉科技有限公司（coding.net）是一家秉承 “让开发更简单” 使命的互联网公司，旗下 CODING DevOps 是国内首个一站式云端软件服务平台，从需求提交到产品迭代，从产品设计到代码管理，自动化测试、持续集成，构建物管理直至最终持续部署，整套流程均在 CODING DevOps 完成，流水线标准化作业，自动化版本记录，降低企业研发管理难度，提升研发效率。

CODING DevOps 提供代码托管、项目管理、测试管理、持续集成、制品库、云端 IDE Cloud Studio 等多款产品和服务，涵盖软件开发从构想到交付的一切所需，开发者无需对接第三方工具，研发团队能够云端高效协同，实践敏捷开发与 DevOps。同时团队内产品、设计、测试、运营等其他多角色岗位均能在同平台上无缝协作，提高各部门间信息流通透明化，快速接受业务部门反馈，加速产品迭代优化。此外，依托腾讯云强大的 CDN 能力，使用者可以通过全球连通极速网络进行上传下载，快速完成应用发布。

CODING 于 2014 年 2 月在深圳成立，2019 年 8 月被腾讯全资收购，正式进驻腾讯云官网「开发者工具」系列，为腾讯云用户提供 DevOps 研发管理协作工具。目前， CODING 已累积 100 万公有云用户量，7000 多家企业，170 万个项目，交付超过 30 家私有云头部客户。

关于 GOPS 全球运维大会

GOPS 全球运维大会由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办，指导单位为工信部信通院数据中心联盟（DCA）。全球运维大会是国内第一个运维行业大会，面向互联网及传统行业、广大运维技术人员，传播先进技术思想和理念，分享业内最佳实践。

迄今为止，GOPS 已经举行了十三次，大会参会嘉宾累计突破6万人次，国内每一站均为本地区最大规模的高端运维盛会，满意度和推荐度高达97%以上。

第十四届 GOPS 全球运维大会将于2020年9月25日在深圳召开。大会为期2天，侧重方向是 AIOps、运维自动化和 DevOps。目前已经有全国各地大公司组团前来参加。

此外还有一些特色专场如：AIOps 场景实践专场、DevOps 最佳实践专场、DevOps 标准企业案例专场、金融专场等。

GOPS 主要面向运维行业的中高端技术人员。目的在于帮助运维人员系统学习了解相关知识体系，让创新技术推动社会进步。你将会看到国内外知名企业的相关案例，也能与国内顶尖的技术专家探讨技术实践，使企业可以根据最佳实践确定自己的选型方案，并提前预估相关的风险和收益，实现技术落地。
