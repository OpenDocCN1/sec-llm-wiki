思科前员工为报复恶意删除400多台虚拟机，公司损失超1600万

前思科员工于本周三在圣何塞联邦法院认罪，称其曾非法访问思科公司的 Amazon Web Services 基础设施，并对其云计算资源施以破坏。
Sudhish Kasaba Ramesh 离职之后，“他曾使用个人 Google Cloud Project 账户部署代码，删除掉了 456 台虚拟机。这部分虚拟机主要用于交付视频会议、视频消息收发、文件共享以及其他协作工具服务。”Ramesh 承认自己“鲁莽地”部署了恶意代码，而且“明确意识到自己的行为可能给思科业务带来巨大风险。”
根据检察官的说明，Ramesh 的行为导致超过 16000 个 WebEx Teams 账户被异常关闭，持续时间达两个星期。为此，思科方面共计损失 240 万美元（约合 1650 万人民币），其中包括对问题进行修复所支付的约 140 万美元人力成本和超过 100 万美元的客户退款损失。对此，思科方面表示，值得庆幸的是此次事件并未导致客户信息丢失或泄露。
据悉，30 岁的 Ramesh 或将面临五年有期徒刑与 25 万美元的罚款。目前，Ramesh 已被保释，保释金为 5 万美元，其宣判会将于 2020 年 12 月 9 日举行。（来源：InfoQ）



又一个高等级数据中心着火了！

据外电报道，8月27日，澳洲电信Telstra位于英国首都伦敦的托管数据中心发生火灾并引起宕机。当地消防部门共调集了4辆消防车和25名消防员到场救援。
火灾发生在位于E14格林威治景广场6号的Telstra伦敦托管数据中心（LHC），该数据中心共有8台发电机，火灾造成一半大楼断电。消防人员表示，虽然只烧毁了三层供应间的一小部分区域，但由于大火使支撑母线的断路器跳闸，工程师们不得不通过发电机恢复电力。
有相关人士据公开资料分析，这次火灾事故很有可能是由于UPS故障引起，事故击穿了温度保障、消防灭火及ups预测性维护、ups预防性维护等多重保障，最终导致火灾。（来源：IDC圈）



Linux 29 周年：你第一次使用 Linux 是在什么时候？

1991 年的 8 月 25 日，来自芬兰赫尔辛基大学的 Linus Torvalds 用 Minix 操作平台建立了一个新的操作系统内核，并把它发回 Minix Usenet 新闻组。此时，年仅 21 岁的大学生 Linus 不会意识到，自己当做兴趣爱好开发的一个小项目会在 29 年后发展成统治世界的庞大操作系统内核。（来源：开源中国）

总投资100亿元 服务器装机20万台 百度将在广东佛山建两个云计算中心

9月2日，广东省佛山市顺德区人民政府与百度（中国）有限公司签署项目投资合作协议。合作协议显示，百度将在顺德区建设人工智能云计算产业基地，分别在顺德高新区和顺德区均安镇畅兴工业园三期各选址100亩地块投资建设两个云计算中心，总投资100亿元，服务器装机规模达20万台，将成为“AI+5G”时代强大的人工智能基础设施底座，支撑百度在自然语言处理、深度学习、图像识别、语音技术和大数据方面应用。(来源：中国经济周刊-经济网)



中国西部最大的单体数据中心 腾讯西部云计算数据中心二期50%已建成

据媒体报道，腾讯西部云计算数据中心二期已经完成一半的项目规划，比既定时间提前不少，加速智博会成果落地见效。腾讯西部云计算数据中心二期建成后，能有效带动腾讯西部云计算数据中心形成20万余台服务器计算能力，并成为中国西部最大的单体数据中心。
按照项目进度，预计到2022年，腾讯西部云计算数据中心二期项目将建成投用。


Windows 95 诞生 25 周年

8月24日是 Windows 95 诞生 25 周年的纪念日，1995年8月24日对于微软来说是重要的一天，杰伊·莱诺(Jay Leno)与微软联合创始人比尔·盖茨(Bill Gates)共同宣布了 Windows 95，整个 Windows 95 开发团队也登台亮相。
Windows 95 作为微软历史上具备里程碑意义的操作系统版本之一，拥有许多新功能和变化，简单回顾一下：

  1. 全新的“开始”按钮、菜单和任务栏

  2. 引入 Windows 资源管理器

  3. 改进多任务处理

  4. 引入即插即用机制，支持自动检测和安装硬件

  5. 支持长文件名（最多 250 个字符）

  6. 引入 Microsoft Network (MSN)，MSN 旨在通过拨号连接访问电子邮件、聊天室，新闻组和首个 WWW 主页

  7. 首次提出在多台计算机之间同步数据的想法，自带的"My Briefcase"程序旨在在笔记本电脑和台式计算机之间同步文件

  8. 首个搭售 Internet Explorer(IE) 的系统



滴滴云国内首发一款GPU云服务器


北京时间9月1日，滴滴云发布基于NVIDIA Tesla A100 GPU的云服务器产品，据悉滴滴云是该型GPU云服务器产品的国内首发云厂商。
滴滴云基于A100 GPU的产品包括裸金属服务器（BMS）、透传性GPU云服务器和vGPU云服务器产品，可用于深度学习训练/推理、视频处理、科学计算、图形图像处理等场景。目前基于A100 GPU的裸金属服务器产品开放测试。（来源：特大牛）



海南将建互联网根服务器镜像、国家顶级域名节点 10月底完成

9月2日，据南海网报道，中央网信办与中国互联网信息中心（CNNIC）已批复同意海南部署根服务器镜像节点和国家顶级域名节点，预计10月底前“两个节点”将建设完成并投入使用。
据了解，域名系统（DNS）是互联网的重要基础服务和“中枢神经”，是互联网安全和稳定的保障，关系到互联网应用及其承载的经济社会的稳定运行，世界各国均把域名系统作为互联网重要基础设施和国家重要战略基础设施。
在海南设立根服务器镜像及域名节点之后，海南地区的网络用户访问互联网的速度及域名解析响应时间都会更快。
根据中国互联网络信息中心(CNNIC)的消息，截至去年底，中国目前共引入13个根镜像服务器，北京9个，浙江2个，上海1个。



Dell'Oro：Q2中国数据中心交换机市场呈现强劲复苏

近日，来自市场研究公司Dell'Oro Group的最新报告显示，今年第二季度，数据中心交换机市场收入在中国市场出现了强劲复苏，同比增长近30%。于此同时，中国以外地区的市场收入降幅相较2020年第一季度继续加大。
这份2020年第二季度数据中心以太网交换机市场报告的其他重点内容包括：
Arista、思科和Juniper在2020年第二季度均呈现两位数百分比的收入同比下滑；
尽管市场疲软，但一些大型云服务提供商的需求仍然强劲，例如亚马逊、微软、阿里巴巴和腾讯；
在2020年第二季度，400Gbps的出货量达到近25万个端口，主要由谷歌和亚马逊推动。



神州数码10名董事、高管拟集体减持

9月2日晚间，神州数码发布公告，称公司CTO郝峻晟、副总裁叶海强等共10名董事和高管拟自减持计划披露之日起15个交易日后的六个月内以集中竞价交易方式减持公司股票，不超过公司总股本比例 0.10%，减持理由是个人资金需求。
公告显示，上述10名董事和高管共持有神州数码1.07%的股票，其股票部分来源公司股权激励计划授予的限制性股票，此外副总裁韩智敏、郝峻晟的部分股票还来自二级市场增持。（来源：新浪科技）
