视频云业务运维（base 深圳）：

#### 岗位职责

1.  负责云产品 DevOps 流水线的落地及维护；
2.  负责云产品运维，规划和运维平台的建设；
3.  负责云产品的质量，成本，和整体运维效率；
4.  负责云产品技术疑难问题定位、分析、解决及沉淀；
5.  负责云产品系统架构梳理、优化、升级；
6.  负责云产品运维流程的抽象、运维工具的实现；

#### 岗位要求

1.  3年以上运维开发或者运维平台建设经验，熟悉集群高可用解决方案；
    
2.  熟悉多种开源组件：KVM、Nginx、tomcat、Jenkins、Git、Maven、Memcached、Redis、MySQL/SQL 等；
    
3.  熟悉 Linux 系统管理维护，熟悉 HTTP 协议、TCP/IP 网络协议，对系统性能原理有深刻理解
    
4.  熟悉 Shell 脚本语言，以及 Python 开发语言；
    
5.  热衷 DevOps，有 DevOps 落地经验，并且有维护 K8S 平台经验优先；
    
6.  具备良好的合作精神和快速学习能力；
    
7.  具备云平台运维经验、中间件产品运维经验、熟悉 Docker 技术、熟悉音视频技术、常见运维开源系统运维经验者优先；
