## 关于腾源会

腾源会是腾讯云成立的汇聚开源项目、开源爱好者、开源领导者的开放社区，致力于帮助开源项目健康成长、开源爱好者能交流协助、开源领导者能发挥领袖价值，让全球开源生态变得更加繁荣。

![](../Images/1fcbb5427e06f7d351f371ba3b543e79.png)

腾源会自 2021 年成立之初，就致力于帮助开源项目健康成长、帮助构建与国内外顶尖基金会的连接桥梁、帮助高校群体及企业早期的开源项目实现创新和商业化，全力建设开源生态，打通上、下游生态链。目前腾讯在 Github 上发布了超过 130 个开源项目，覆盖云原生、大数据、AI、移动开发、Web 开发五大技术领域。其不少开源项目已经取得了较大的影响力，并且形成社区治理的体系。例如 TARS 框架捐赠到了 Linux 基金会，并于2020年3月孵化成立单独的TARS基金会、Angel项目顺利从 LF AI 基金会完成毕业；2019年9月又向 Apache 捐赠了 TubeMQ（现更名 InLong ），TencentOS Tiny 和 TKEStack 也成为国内开放原子开源基金会首批孵化项目等。未来，腾源会也将持续不断地帮助更多企业和项目，提供商业化的路径指导，构建开放的开源社区，提供一套成熟的成长指导方案，帮助更多开源人和项目的成长。期待开源社与腾源会等众多社区小伙伴一起，让开源走向更大的舞台！

## 关于 GOPS 全球运维大会

![](../Images/cd12c64c7e60b26bbbc78f0e629e6886.png)

GOPS 全球运维大会由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）、RPA时代社区联合主办，指导单位为工信部信通院数据中心联盟（DCA）、RPA产业推进方阵。全球运维大会是国内第一个运维行业大会，面向互联网及传统行业、广大运维技术人员，传播先进技术思想和理念，分享业内最佳实践。迄今为止，GOPS 已经举行了十六次，大会参会嘉宾累计突破7万人次，国内每一站均为本地区最大规模的高端运维盛会，满意度和推荐度高达97%以上。**第十七届 GOPS 全球运维大会将于2021年11月18日-19日在上海召开。**大会为期2天，侧重方向是 AIOps、运维自动化和 DevOps。目前已经有全国各地大公司组团前来参加。此外还有一些特色专场如：AIOps 场景实践专场、DevOps 最佳实践专场、DevOps 标准企业案例专场、金融专场等。GOPS 主要面向运维行业的中高端技术人员。目的在于帮助运维人员系统学习了解相关知识体系，让创新技术推动社会进步。你将会看到国内外知名企业的相关案例，也能与国内顶尖的技术专家探讨技术实践，使企业可以根据最佳实践确定自己的选型方案，并提前预估相关的风险和收益，实现技术落地。**票务咨询**：
