希望借助新的思维模式来处理开发和运维问题。

又该如何将技术与企业完美融合？

2021年11月19日，上海中庚聚龙酒店，4位 DevOps 技术专家将结合大厂具体的 DevOps 案例，带大家一同揭秘！

地点：上海闵行区中庚聚龙酒店

演讲主题：800万行代码仓库迁移到 Bazel 的工程实践

石骁毅

腾讯软件工程师

个人简介：石骁毅先生曾在 Google 任 SWE-SRE，负责技术基础设施建设。归国后加入创业公司，作为基础设施负责人从 0 至 1 搭建电商 PaaS 和 SaaS，支撑每年数十亿 GMV 业务高速流转。现就职于腾讯PCG，负责工程效能相关工作。

主题简介：Bazel 是谷歌2015年开源一个构建和测试工具。Bazel 支持多种语言的项目，并为多种平台构建输出。同时也支持跨多个存储库和大量用户的大型代码库。腾讯QQ作为“国民”级即时通讯软件，截止到2021年Q1季度，QQ月活达到6亿规模。2008年腾讯发布QQ的IOS版本，在过去十余年积累了800万行第一方代码，使用了超过300个第二或第三方依赖，并且有超过200人的开发团队。随着项目的复杂度增加，代码库体量越来越大，APP的构建和测试速度逐渐减慢。考虑业务发展和未来需求，最终我们决定将IOS APP迁移到Bazel。本次分享将重点介绍迁移Bazel的面临的挑战，迁移过程以及性能、稳定性、平台化管理方面的一些实践和优化经验。

演讲主题：云原生微服务架构复杂应用管理的高效实践

潘俊明

腾讯云CODING 高级技术专家

个人简介：潘俊明 ，腾讯云 CODING 高级技术专家，拥有多年技术架构经验，完整经历多家企业应用上云，对企业应用上云最佳实践有独特见解。2019 年开始在腾讯云 CODING 负责持续部署产品研发，帮助多个行业客户完成研发效能的方案设计和最终落地。

议题简介：随着云计算的不断成熟，企业 IT 对降本增效的高度关注，应用云原生化正在成为一种不可逆的趋势。企业如何基于自身特点，打造标准可靠的云原生应用管理体系，成为企业应用优雅转型云原生的最大挑战。腾讯云 CODING ORBIT 基于腾讯内部多年应用云原生化转型经验，打造一站式云原生应用管理平台，提供云原生应用构建、交付、运维、销毁全生命周期管理的能力，助力企业应用高效转型云原生 演讲提纲：1. 云原生应用管理现状及挑战 2. 异构多云环境下的应用构建 3. 打造高效可靠的应用交付 4. 建设以应用为中心的轻运维体系

演讲主题：听说你不知道什么是软件物料清单？（SBOM）

王青

JFrog (中国) 首席架构师

个人简介：信通院 DevOps 标准制定委员会评委，ArchSummit，GOPS金牌讲师，Musp 案例 100大会级联主席

议题简介：1. 什么是软件物料清单？2. 为什么需要提供软件物料清单？3. 如何自动的提供？

演讲主题：众安科技智能运维体系建设实践

鄢晶

众安信息技术服务有限公司 

平台架构技术负责人 高级技术专家

个人简介：鄢晶，众安科技高级技术专家，在微服务，Devops，云原生技术领域有丰富的实践经验。主导了众安新一代智能运维平台的建设。

主题简介：区别于传统保险业务，互联网保险同时具备互联网和金融双重业务属性。在服务可用性，链路追踪，异常处理，业务洞察以及业务合规上有着强烈的诉求。众安科技在金融科技业务背景下对服务可观测技术进行了持续的投入与探索。本次分享将介绍众安在互联网保险业务场景下对围绕异常检测、辅助故障定位、辅助业务决策方向上的思考与实践。
