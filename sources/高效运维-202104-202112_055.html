 网易游戏崩了，多款游戏出现网络故障！

11月3日，大量网友反映网易旗下多款游戏出现网络故障，导致无法登录和断连。包括网易热门手游哈利波特、阴阳师、第五人格及网络永劫无间等，网易旗下的多家游戏官方微博回应称，服务器出现异常，导致无法登录游戏，正在紧急排查和修复。


 Facebook 关闭人脸识别系统，将删除超过10亿人脸识别数据
Facebook 11月2日宣布将会关闭面部识别系统，因为来自用户和监管者的担忧越渐增强。Facebook 母公司现在的名字叫 Meta。受到新政策的影响，Facebook将会删除超过 10 亿用户的个人面部识别范本。按照 Facebook 的说法，超过三分之一的日活跃用户（超6亿账户）选择使用面部识别技术。（新浪科技）


 网盘下载速度太慢？工信部正式发话！

11月1日，工信部发布《关于开展信息通信服务感知提升行动的通知》。通知决定，自11月1日起开展信息通信服务感知提升行动，待改进的地方有5类，其中有“优化网盘类服务提供方式”，特别强调在同一网络条件下，向免费用户提供的上传和下载的最低速率应确保满足基本的下载需求。
消息一出，网友们立即想到百度网盘，就差直接点名了。

 Github 换帅：CEO Nat Freidam 宣布即将卸任

2018 年，微软宣布正式收购GitHub，微软副总裁 Nat Friedman 担任GitHub 的新 CEO。2021 年 11 月 3 日，GitHub 首席执行官Nat Friedman在任职三年后宣布即将卸任，并回归到他的创业根源。在题为“Thank you, GitHub”的博客中，Nat Friedman 表示：

“考虑到我们已经取得的所有成就，以及我在微软的五年多辉煌时光，我决定是时候回到我的创业根源了，我将继续下一次冒险：支持、指导以及投资那些正在用技术创造未来并应对当今一些最大机遇的创始人和开发者。”


 网传字节跳动、腾讯将执行1075和965工作制

11月1日，在脉脉上有字节跳动员工发帖表示：字节跳动将执行1075工作制（上午10点上班，晚上7点下班，每周工作5天），7点以后算加班。

同时，腾讯正式发文执行“965”工作制度，即 9 点上班、6 点下班、工作 5 天。同时，员工在 7 点后加班需要向公司申请。

 微软 CEO 纳德拉：Xbox 游戏平台将加入元宇宙
微软CEO萨提亚·纳德拉（Satya Nadella）11月2日表示，将来 Xbox 游戏平台也将加入到“元宇宙”中。纳德拉称，在“元宇宙”市场，微软的企业应用处于领先地位，但预计Xbox游戏平台将来也将参与其中。纳德拉还表示，微软专注于“元宇宙”的切实可行的应用，这些应用的裨益是显而易见的。

 Linux 内核 5.15 正式发布

11月3日消息，Linus 本人在万圣节没有休息，于近日发布了 Linux 5.15 版本，该版本增加了对英特尔 独显的初步支持，并采用最新 NTFS 文件系统驱动，还为 AMD Zen 3 APU 带来温度监控支持。


 11月数据库排行榜正式揭晓，MySQL、SQL Server、MongDB 分数持续低迷
DB-Engines 发布11月份流行度排行榜（基于10月份的整体数据变化），排名前二十的数据库和上个月的保持一致，其中排名前十的分别是 Oracle、MySQL、Microsoft SQL Server、PostgreSQL、MongoDB、Redis、IBM Db2、Elasticsearch、SQLite 和 Cassandra。分数方面，MySQL、SQL Server 和 MongoDB 出现了明显的下降，分别减少了 8.25、16.32 和 6.21 分。
