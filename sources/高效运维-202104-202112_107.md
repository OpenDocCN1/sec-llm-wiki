2021年 10月22-23日，DevOps 国际峰会 2021 · 北京站将于北京拉开帷幕，国内 DevOps 解决方案领军企业、Atlassian 全球白金合作伙伴——龙智也将作为金牌赞助出席此次峰会。  
龙智已为金融、汽车、游戏、互联网、芯片以及电子产品等诸多行业的500多家知名企业提供DevOps的解决方案，并且赢得了一致好评。  
是什么让这些企业信赖、选择龙智？

  

**近十年深耕，专精 DevOps 领域**

  

DevOps 是整合软件开发和IT团队之间的流程并使其自动化的一系列实践，帮助企业更快、更可靠地进行构建以及软件测试、发布。  
龙智深耕 DevOps 领域近十年，拥有软件研发管理领域的专业知识与丰富经验，集成 DevOps、Agile 理念及该领域的领先工具，为软件研发团队提供完整的 DevOps 解决方案。  
秉承“让开发团队更好、更快地交付软件”的理念，龙智提供从专业咨询、定制方案、实施部署、集成开发、团队培训到综合运维的 DevOps 解决方案一站式服务。![](../Images/7bd576e38543531869d05f04ef4f9387.png)龙智的 DevOps 解决方案一站式服务首先从分析现状、了解期望着手，为客户提供最佳实践作为参考，并展示 DevOps 工具链，让客户直观了解自己的需求，初步判断适合的方法和工具。  
其次，龙智根据企业用户的行业特性以及现场实际情况，设计适合该企业的 DevOps 流程与整体方案，并协助用户规划阶段式实施部署方案，从基础工具构建，到提升阶段，再到成熟阶段，逐步提升企业的 DevOps 水平。  
龙智还提供定制开发服务，帮助用户实现更高效的自动化DevOps流程，同时更好地连接各环节，打通与周边系统的数据，实现单一数据来源，提升可追溯性。  
结合 DevOps 和 Agile 的理念，龙智提供专业培训服务，针对具体实施的系统，让企业的相关团队快速掌握 DevOps 的最佳实践。  
系统实施后，龙智还提供综合运维服务，包括定期检查系统环境，确保系统良性运行；如果遇故障，还可提供故障分析服务，比如用户现场经常出现的网络、硬件、储存的故障的分析和切分服务。  
VIRTUOS 公司的 Group IT Director 如是评价龙智：“龙智的方案及服务不仅解决了我们多团队多地实时协作、代码检查、版本管理的问题，还帮助我们提升研发的流程管理，帮助开发团队合理规划任务流程，把控风险，做到按时发布、持续监控、安全交付，并保证持续更新迭代。”

  

**释放工具的力量，打造适合企业需求的 DevOps 解决方案**

  

工欲善其事，必先利其器。龙智与国外多家 DevOps 工具顶级厂商合作，将国际市场上先进的工具引入中国市场，帮助企业打造领先的 DevOps 解决方案。  
Atlassian 是 DevOps 工具领域处于领袖地位的厂商，其项目和问题跟踪软件 Jira、文档协作软件 Confluence 已被全球团队广泛使用。Atlassian 系列产品及其生态可以覆盖 DevOps 全过程，帮助企业快速搭建 DevOps 平台，实现 DevOps 的最佳实践。![](../Images/6e1e5b84097d5754f911ef3406a138d9.png)龙智也积极地参与到Atlassian生态建设中，自主研发了Jira 和Confluence系列插件，更好地满足多样化的企业需求，进一步释放Atlassian工具的力量，助力企业更快、更好地交付软件。龙智工具包括：

*   Jira工时管理插件：帮助用户在Jira中轻松规划、管理项目和团队时间；
*   Jira组织机构插件：能够按现实中的组织结构在Jira中进行用户分类管理、数据展示及统计分析；
*   Jira工作流扩展和并行审批插件：无需创建审批子任务或编写复杂的脚本，即可在Jira中进行多人多节点的并行审批，并追溯审批历史；
*   Confluence 水印插件：为Confluence页面及附件设置水印，保护文档版权、跟踪信息来源、提高信息可信度；
*   Confluence到期日提醒插件：能够针对Confluence页面或表格，灵活设置日期提醒，帮助用户不再错过重要事项；
*   Confluence 页面和附件安全插件：实时记录、限制用户在Confluence中复制页面内容、下载附件等行为，提升信息安全性；
*   Confluence 报表模板插件：轻松地将Jira项目的进度、工时等数据进行汇总，自动在Confluence中生成报告。
*   Jira, Confluence和Jira服务台的移动端插件：将企业微信与Jira, Confluence，Jira服务台相连，助力移动办公，让效率提升不止一倍。
