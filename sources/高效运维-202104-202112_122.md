# 荣耀时刻！中国光大银行 DevOps 标准评估授牌仪式暨项目总结会圆满举行！

在数字化转型的浪潮下，实践 DevOps 来提升IT效能是企业的最佳选择之一，由中国信息通信研究院（以下简称“信通院”）牵头的《研发运营一体化（DevOps）能力成熟度模型》系列标准（以下简称“DevOps 标准”）对企业落地 DevOps 具有非常高的指导意义，通过参与标准评估工作可以达到以评促建、以评促改的目的，因此越来越多的各行业头部企业纷纷参与进来，进而实现参评项目 IT 效能的巨大提升。  

2021年 9 月 14 日，中国光大银行 DevOps 标准评估授牌仪式暨项目总结会在京成功举行！中国信通院及中国光大银行相关领导出席了本次活动，一起与参评项目组分享通过评估的喜悦。

![](../Images/0b9a90a11fb5d208b82056667a3f7be7.png)

中国信通院&中国光大银行领导与参评项目团队合影

会议开始，首先由中国光大银行信息科技部总经理史晨阳先生致欢迎词。史晨阳先生对与会嘉宾及专家表示热烈欢迎，对本次中国光大银行的参评项目顺利通过 DevOps 标准持续交付 3 级评估表达了祝贺，并对参评项目组团队的付出表达了肯定！![](../Images/9225205f6ebc53dedb0eb3f6a7fbcacf.png)中国光大银行信息科技部总经理史晨阳先生致欢迎词接下来，由中国信息通信研究院云计算与大数据研究所所长何宝宏博士为中国光大银行授牌，中国光大银行信息科技部总经理史晨阳先生作为企业代表出席仪式！![](../Images/7d5cbf1a8d8f47e6126c40ab2f0d64b9.png)

何宝宏博士（左一）为中国光大银行史晨阳先生（右一）授牌  

光大银行参评的自主研发平台、现金管理云服务系统两个参评系统全部顺利通过持续交付 3 级评估，是光大在“敏捷、科技、生态”战略指引下落地科技敏捷深化的一项重要成果，也是对光大银行科技敏捷转型成果的充分肯定，标志着光大银行端到端持续交付能力达到了国内领先水平，对下一步敏捷深化的持续推进将起到积极的促进作用。在授牌仪式结束后，中国信通院云大所所长何宝宏博士进行了精彩分享，介绍了信通院云大所围绕云计算、大数据、人工智能、数据中心以及关联应用领域开展的技术、标准研究，构建技术测试平台，承担国家重大科技项目的相关工作。![](../Images/5813b80ed48b3fcc0309a372ec067395.png)信通院云大所所长何宝宏博士进行分享信通院云大所治理与审计部副主任牛晓玲女士向与会人员分享了 DevOps 标准评估的内容及更多进展，同时也介绍了中国光大银行此次标准评估工作的优秀成果。![](../Images/9301d981495a2b35059b93934f270663.png)信通院云大所治理与审计部副主任牛晓玲女士进行分享

在此之后，光大银行信息科技部自主研发平台团队主管柳朝晖先生介绍了光大银行自主研发平台（POIN）是基于 JAVA 标准的底层技术架构，为应用项目组提供微服务开发工具和底层公共构件，是光大 300 多个系统的开发基础平台。

![](../Images/1280818178cabccb7f44d6c3245beb8c.png)

中国光大银行信息科技部自主研发平台团队主管柳朝晖先生进行分享

光大银行信息科技部产品开发处副处长林付兵先生也详细介绍了现金管理云服务系统是定位于企业财资管理，为客户构建企业资金池、票据池，为客户提供账户管理、投融资、结算管理、流动性管理、预算管理、信息服务等综合和现金管理服务，满足客户深层次的、精细化现金管理需求。

中国光大银行科技部创新与需求管理处副处长陈莹女士对本次评估进行了总结，同时分享了光大银行更多信息化建设进程和成果。

![](../Images/8596f1dec11c4250669fe436027b0ae3.png)

中国光大银行科技部创新与需求管理处副处长陈莹女士进行分享

陈莹女士表示，此次评估光大银行结合现有研发管理体系及参评项目特点，对照研发运营一体化（DevOps）标准持续交付3级的标准要求，实施了软件交付过程的专项改进及敏捷研发流程、工具平台的持续优化完善，通过推进评估改进工作，切实提升了我行的 IT 交付质量和效率，构建集成成功率达到 90%以上，每月可投产4次左右，敏捷能力进一步得到增强，体现了“响应快、开发快、交付快”，业务部门快速交付的诉求得到了充分保障。同时，在敏捷理念、敏捷文化培育方面，也得到了充分认同，为光大的 DevOps 建设积累了宝贵的经验。在分享中陈莹女士提到，光大银行是在 2016 年启动了“双模IT”管理，探索项目级敏捷实践。2018 年，在光大集团“敏捷、科技、生态”战略指引下，银行基于“响应快、开发快、交付快”的转型目标，制定新一版 DevOps 敏捷深化发展规划，构建具有光大特色的领域级“业技融合”和项目级“双态三模”研发体系，投产 DevOps 研发效能平台群，将工程流水线和管理流水线进行融合，并开展重点项目敏捷实践导入，同时，在月度集中投产的基础上，对一些需求比较多、投产要求快的业务系统增加了按周投产的小窗口，加快了系统的交付频率。经过不断探索和努力，光大银行成功实现了持续集成全覆盖、重要关键系统自动化测试覆盖、微服务、容器化改造等，交付质量和交付效率持续提升，有效满足了业务诉求，响应了市场变化，也积累了敏捷实践的经验，取得了良好的效果。

随后，信通院云大所人工智能部门工程师李荪、信通院云大所云计算部工程师宋佳明和信通院云大所金融科技部工程师刘孝贵三位老师（下图由左至右）为与会嘉宾介绍了更多信通院云大所部门工作方向和概况。

作为此次光大银行贯标项目的咨询团队，北京华佑科技有限公司技术合伙人及 CTO 雷涛先生也发表精彩观点。![](../Images/6e249544b1ae9024f03ff7427f755c7b.png)北京华佑科技有限公司技术合伙人及 CTO 雷涛先生进行分享雷涛先生回顾了本次两个项目的咨询改进过程，并认为高层领导支持是贯标成功的最重要因素之一，再加上横跨项管、开发、测试、安全、运维和平台的项目组的共同努力最终取得优异成绩。雷涛先生表示贯标过程也是一个查缺补漏的过程，对比同行业的 DevOps 优秀实践，取长补短，针对弱项引入外部同业改进经验，避免“入坑”、“重复造轮子”，降低改进成本，实现DevOps 流程体系的先进性。光大银行在改进过程中，通过构建 DevOps 研发效能平台群，实现从研发到交付全流程端到端流水线的全面贯通、研发过程数据的集中存储，以及研发效能的自动化展示，进一步丰富了研发管理的手段，累积了评估的方法和评价指标，为下一步建立适应科技的工程应用成熟度评价模型奠定了基础，填补了工程实践评价管理空白。最后，与会领导、专家和嘉宾进行了讨论和交流，这次会议标志着中国光大银行信息化建设的阶段性成功，打造了企业标杆项目，从而对数字化转型起到了推进作用，也是中国光大银行  DevOps 建设的里程碑！**精彩瞬间：**![](../Images/458360af9758c65c94ea875195a20c69.png)![](../Images/ee9ea2de27c5727735361604064c1a64.png)![](../Images/de68bc5ae1ee258ef13a7ed207c659e0.png)![](../Images/8ad40df9dbcf43a7f7d003f6a97782b1.png)![](../Images/9f709506c46ca37146fc9121dc4d7064.png)![](../Images/b5f248c4cd645cbaf5c4350b5cc32e77.png)
