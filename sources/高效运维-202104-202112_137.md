Web 管理后台由于其本身的管理属性与敏感性，安全意识不够的业务，将未经加固的 Web 管理后台直接暴露在互联网，一旦被攻击者发现并攻击成功，极易导致敏感数据泄露或服务器被 getshell。

因此，Web 管理后台治理一直是企业安全团队的重点工作之一，11月18-11月19日，GOPS 全球运维大会 2021 · 上海站，腾讯游戏应用运维安全负责人将分享腾讯游戏在Web 管理后台治理方面的一些实践经验，敬请期待。

  

**演讲议题：腾讯游戏 Web 管理后台安全治理实践**  

![](../Images/51eb29a4294d5bf12e8e5ace939ded5e.png)

**郑江林**

腾讯游戏应用运维

安全负责人

**个人简介**：郑江林，毕业后加入腾讯，拥有4年运维与运营规划经验，5年安全建设工作经验。

曾负责过火影忍者手游等重点业务的运营规划工作，从 2016 年开始负责腾讯游戏的应用运维安全标准规范、流程以及自动化系统的建设与运营工作，搭建安全运营体系，最近两年一直在持续推进 DevSecOps 理念与 SOAR 在腾讯游戏的落地。

**演讲提纲：**

1、Web管理后台是什么 

2、Web管理后台治理的必要性 

3、Web管理后台治理的思路与框架 

4、治理效果与未来展望
