# 荣耀时刻！中信建投证券 DevOps 标准评估授牌仪式暨项目总结会圆满举行！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651704019&idx=2&sn=360ae762e5bd9f8c303e7462b4f6d809&chksm=8bcb097abcbc806c5e0c384248583b2514b68171f4be3a98240a76b165533d471e9ee60ebaaf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651704019&idx=2&sn=360ae762e5bd9f8c303e7462b4f6d809&chksm=8bcb097abcbc806c5e0c384248583b2514b68171f4be3a98240a76b165533d471e9ee60ebaaf&scene=27#wechat_redirect)

![](../Images/c2e2259852da561246cb710dae69adcb.png)

在数字化转型的浪潮下，实践 DevOps 来提升IT效能是企业的最佳选择之一，由中国信息通信研究院（以下简称“信通院”）牵头的《研发运营一体化（DevOps）能力成熟度模型》系列标准（以下简称“DevOps 标准”）对企业落地 DevOps 具有非常高的指导意义，通过参与标准评估工作可以达到以评促建、以评促改的目的，因此越来越多的各行业头部企业纷纷参与进来，进而实现参评项目IT效能的巨大提升。  

2021年 9 月 7 日，中信建投证券 DevOps 标准评估授牌仪式暨项目总结会在京成功举行！中国信通院及中信建投证券相关领导出席了本次活动，一起与参评项目组分享通过评估的喜悦。

![](../Images/3ab11aa8b07596fd88d83e2b612ae12e.png)

中国信通院&中信建投证券领导与参评项目团队合影  

中信建投证券此次参与信通院 DevOps 标准评估的项目为：**托管外包服务平台项目**。该项目通过持续改进顺利通过了第十三批《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。**中国信通院标准评估官方新闻：[燃！中信建投通过 DevOps 持续交付标准 3 级评估，相关项目能力达到国内领先水平！](https://mp.weixin.qq.com/s?__biz=Mzg2NTUyNjkzMQ==&mid=2247491047&idx=7&sn=ca621d9294a431bf85431b9596c66d63&scene=21#wechat_redirect)**（链接来源自：中国信通院“CAICT数字化治理”公众号）**出席本次活动的主要领导有：**

中国信通院云计算与大数据研究所所长何宝宏

中国信通院云大所治理与审计部主任杨玲玲

中国信通院云大所治理与审计部副主任牛晓玲

何宝宏博士（右一）为中信建投代表肖钢（左一）授牌

中信建投证券是华北地区第一家通过 DevOps 标准持续交付 3 级评估的企业，此次评估代表了信通院对中信建投 DevOps 建设成果的认可，同时表明参评项目平台已具备研发全流程端到端自动化价值交付能力，将有效助力企业数字化转型。

接下来，中信建投证券信息技术部执行总经理、买方业务系统开发及运行管理组负责人万锟先生详细介绍了中信建投基本情况及更多信息化建设进程和成果。

![](../Images/a3c2859e3295ed7ea9542c36efece837.png)

中信建投证券信息技术部执行总经理

买方业务系统开发及运行管理组负责人万锟先生进行分享

据万锟先生介绍，中信建投证券股份有限公司成立于 2005 年 11 月 2 日，是经中国证监会批准设立的全国性大型综合证券公司。![](../Images/0f10ff7d0578046c9b9d235f8a15ee28.png)

中信建投证券信息技术部执行总经理

买方业务系统开发及运行管理组负责人万锟先生进行分享

万锟表示，随着业务的发展和 IT 规模的扩张，对于 IT 支持、交付速度提出了更高的要求。需要持续深化 IT 治理和管控，提升研发质量和敏捷交付能力，中信建投在 2019 年年底启动了 DevOps 平台建设。DevOps 标准评估工作帮助公司完善了从传统 IT 到分布式、云原生等金融科技转型的技术支撑平台，推动了研发模式向敏捷模式转型，增强了自主研发和自主掌控，提升了业务响应的灵活性，支持公司业务快速创新的能力。随后，中国信通院云大所所长何宝宏博士进行了精彩分享，介绍了信通院云大所围绕云计算、大数据、人工智能、数据中心以及关联应用领域开展的技术、标准研究，构建技术测试平台，承担国家重大科技项目的相关工作。![](../Images/daeedd2201da9498f1a3d033dc6ddf14.png)信通院云大所所长何宝宏博士进行分享信通院云大所治理与审计部副主任牛晓玲女士向与会人员分享了 DevOps 标准评估的内容及更多进展，同时也介绍了中信建投证券此次标准评估工作的优秀成果。![](../Images/d98b6eab4dcf2a49edf75629cfaf51f2.png)信通院云大所治理与审计部副主任牛晓玲女士进行分享

随后，信通院云大所人工智能部曹峰副主任，大数据与区块链部姜春宇副主任，金融科技部魏博锴工程师（下图由左至右）为与会嘉宾介绍了更多信通院云大所部门工作方向和概况。

![](../Images/4e65dd1b38c9b0ca8d67a31664a202a4.png)
