Linus 怒批 GitHub：制造了毫无用处的垃圾合并信息！

Paragon 软件公司最近将他们的 NTFS 驱动提交到了 Linux 内核，但 Linus 在把相关代码拉取到 5.15 版本的内核时，抱怨他们的这个 commit 使用了 GitHub merge，并直言“Github 制造了毫无用处的垃圾合并信息”，永远都不应该使用 Github 的操作界面来合并任何东西。

Linus 表示，GitHub 是一个很好的代码托管网站，它在许多方面都做得很好，但「合并」不是其中之一。Linus 强调道，Linux 内核的合并需要在符合规则的情况下进行，这就意味着所提交的消息应包含：正在合并的内容以及为什么合并这些内容。同时，还需要确切的作者身份和提交者信息等。但所有这些都 GitHub 完全搞砸了。

谷歌被曝过去9年欠薪超1亿美元

2019年5月，《纽约时报》曾发文表示，截至当年3月，谷歌在全球拥有超过10.2万名正式员工，然而临时员工和合同工的数是12.1万，这令外界不安，因为在薪酬和福利方面，临时工、合同工的待遇远低于正式员工。
现在，一名举报人向美国证券交易委员会(SEC)提交了一份申诉，指出谷歌临时工、合同工薪资福利低于正式员工的这个现象在近些年进一步扩大了。
该起诉书中表示，谷歌一直按过时的比例支付薪资，而人力资源机构却在犹豫这么做到底对不对。在过去的9年里，谷歌在全球超过16个国家欠下了超过1亿美元的工资。

淘宝搜索崩了登上热搜

昨天下午，淘宝似乎又崩了，设备都无法进行页面搜索，疑似出现服务器故障。日前 #淘宝崩了# 话题在微博热度数亿，无数网友都表示玩着玩着突然就发现搜不出来东西了，受影响的用户包括全国多个省市。目前，淘宝服务已经恢复。

2021 年度 TIOBE 9 月榜单出炉：Python 与 C 仅差 0.16%

近日，TIOBE 出炉了 2021 年度 9 月份编程语言榜单。在入围该榜单的 100 种编程语言里，C、Python 和 Java 分别以 11.83%、11.67% 和 11.12% 的评级，位列该榜单前 3 甲。其中， 排名第 2 的 Python 与排名第 1 的 C 语言之间，评级仅仅相差 0.16% ，随时有超越 C 的可能。

据 TIOBE 数据显示，本次榜单 C 和 Java 这两种语言的排名，迄今为止第一次进入前三。

         


彭博社：iPhone 13系列，史上力度最小的更新

9月15日据彭博社，对于全世界的1亿多果粉来说，恐怕没有一款产品能比苹果一年一度的新品更令人期待，而iPhone 13系列相比前代，更新力度堪称史上最小。                

亚马逊内部文件泄露，程序员薪酬高达 462 万元

8月26日，《商业内幕》杂志在一份泄露的亚马逊文件中发现，为了将程序员和产品经理招聘进来，亚马逊的招聘人员有权给他们定多高的薪水。文件显示，对于一些更高级别的职位，薪酬总额可能高达71.54万美元。在市场领先的亚马逊公司，这份文件似乎意在给招聘人员提供具有指导性的最低、最高和平均薪酬，来招聘某个团队的软件开发、产品管理和项目管理等九个空缺的职位。

46%的本地数据库系统存在安全漏洞

根据Imperva一项为期五年的新研究，全球46%的本地数据库包含安全漏洞，其中大多数是严重或者高危漏洞。Imperva在五年内扫描了全球2.7万个数据库，发现平均每个数据库包含26个漏洞，其中约56%都是严重或者高危漏洞。这意味着一旦被利用，会导致严重的危害。
