# 通信行业 DevOps 标准评估情况概览（2021Q3）

在数字化转型的大背景下，企业选择实践 DevOps 来提升效能，由中国信息通信研究院牵头的《研发运营一体化（DevOps）能力成熟度模型》系列标准》具有非常高的指导意义，各行业头部企业在通过 DevOps 能力成熟度模型评估的过程中，提升改进 IT 能力，整合团队资源及人才，更好的支持业务系统，其实践经验对于行业有很好的的借鉴价值。  

  

**中国联通、中国移动、中国电信、华为、中国铁塔和中兴通讯**等通信行业企业通过 DevOps 能力成熟度模型评估的项目**共 17 个**。

**浙江移动：OSS 4.0能力中心化性能中心**  

OSS 4.0 能力中心化性能中心，项目以企业级服务、平台级能力为定位，按照“数据统一、能力下沉、统一开放、应用拉通”的思路进行建设，以中国移动 OSS 4.0 架构为蓝图打造网络业务的核心能力。在数据支撑上，性能中心能够基于多类数据统一接入、统一建模、统一计算，有效的支撑业务的数据分析需求；在应用对接上，性能中心基于浙江移动 OSS4.0 架构，实现上层应用从强耦合到最终解耦的演进，能够支撑应用的灵活、快速开发。

在 DevOps 转型过程中总结出“四层三队二线一体”的浙江移动 DevOps 研运营体系和“五步走”转型标准流程，从组织、技术、流程、文化四个维度持续优化与变革，推进 DevOps 转型工作。我们也把 DevOps 研运营体系简称为“4321”航母，四层是体系架构，是标准赋能平台的一个总结归纳，自上而下包括标准、工具、平台和模式；三队是网络支撑团队、业务SRE团队、一线智慧运营团队三支队伍；两线就是内部建设和外部对标两条路线；一体是指自动、可靠、降本、增效的研运营一体化。

![](../Images/1a928eacb3b170dd2f07b5070a0c643a.png)

  

**北京移动：2 个项目通过评估**

**电子商务系统**

北京移动的电子商务系统，基于自研的 DevOps 研发运营一体化 AiDo 平台，以可视化度量管控、可自编排流水线与分层自动化测试的融合实践，为北京移动全渠道业务支撑带来研发效率与交付质量双提升。

  

**集中性能管理系统**

参评的集中性能管理系统是通过微服务解耦、容器化部署的 DevOps 最佳实践。北京移动网管系统基于“厚中台、薄应用”原则进行系统分层解耦，拉通底层数据底座，通过数据中台实现数据采集和分析共享，通过技术中台提供 GIS、UIUE、AI 等通用技术组件服务，通过业务中台发布O域微服务原子能力，如告警衍生和派单等能力，向重点通信保障和性能分析专题等上层应用提供能力化服务。  

本次参评的 DevOps 平台是基于北京移动网管服务能力创建运营中心，集成了 DevOps 工具链、容器云管理平台、微服务管控平台、全面软件资产管理、能力开放平台相关功能，并进行了深度定制化，比如通过二次开发对 Jenkins 自动化流水线进行了可视化编辑和运行过程全监控，提供基于云原生架构的一站式软件全生命周期管理。![](../Images/9a976bc41691a0cccf3946fa90b6ac02.png)

  

**江苏移动阿拉盯行销赋能项目**

通过此次 DevOps 持续交付标准 3 级评估，团队在持续交付七个能力子域均获得了显著提升，业务上线周期缩短，能够更快的、高质量的响应业务的变化和需求。如下图所示，可以详细看到参与评估带来的改进：需求交付周期，缩短45%；变更前置时间，缩短50%；变更失败率，降低到5%以内；平均构建时长，缩短到5分钟左右；自动化测试覆盖率提升到100%；上线发布频次，具备按需发布的能力。

![](../Images/e9eefcfd51023badf65ce23dc34c5ba5.png)

  

**中移软件中移舆情项目**  

本次参评的项目是我们移动云中的一款产品叫做中移舆情，是一个偏应用的项目，这个项目涉及到从网上采集数据，然后做数据清洗、数据治理、人工智能的分析，最后，以情报的方式交付给用户使用，这是我们参评项目的一些情况。

![](../Images/0007348a540d65c108ef238a509ce32c.png)

![](../Images/e95d9468cf1e2bad591631d9dc71f27d.png)

  

**江苏电信智能预处理系统**

智能预处理系统作为服务平台，需要对接底层网络操作能力与网络数据，经过对能力、数据统一编排，按照业务规则输出故障段落,诊断报告等供上层应用。从该项目组建起，项目组就参照 DevOps 的规范要求操作。

![](../Images/ec4f3628e1d8a7aca7f44757aeb484b5.png)

  

**中国联通集团资源中心-一卡充项目**

参评项目通过技术中台的形式，统一了全国31省“一卡充卡管理”的标准接口能力，强化了通用功能的复用和集中管控能力，并杜绝了不同省份的重复建设问题，能够更好地集中优势力量，解决业务当中的重难点问题。同时，由于标准的统一，降低了软件的异构化程度，再结合 DevOps 的研发效能管理，不但使得企业软件管理成本显著下降，也提升了软件研发效率，是一次基于传统项目改造与现代化软件管理手段相结合的一次典型案例。

![](../Images/3a24dafa14a6b56776e9406219d28a89.png)

  

**内蒙古移动的政企业务支撑系统（Esop）**  

本次参与评估的项目是政企业务支撑系统（ESOP）项目，该项目是面向全区客户经理使用的集团业务统一受理门户。该系统在智慧中台整体架构体系下，新建了政企服务中心，对集团业务分散的处理能力进行收敛和整合，统一对外提供服务。作为一站式政企业务支撑系统，系统不仅对内整合服务能力，还集成了集团 BBOSS 系统、集客大厅、省 CRM、经分等多个业务平台。

通过此次 DevOps 持续交付标准 3 级评估，团队在持续交付七个能力子域均获得了显著提升，业务上线周期缩短，能够更快的、高质量的响应业务的变化和需求。如下图所示，可以详细看到参与评估带来的改进：需求交付周期缩短25%；版本交付周期缩短 50%；集成效率提升 300%；集成时间由之前的 2 小时下降到 30 分钟以内；自动化测试覆盖率提升到 95%，同时自动化测试效率提升 50% 左右；上线发布频次，具备按需发布的能力。

![](../Images/d7f1d5eaaaac56fcdfafe09c5d3a9545.png)

  

**中国铁塔主数据管理模块项目**  

此次参评的是中国铁塔软件系统中的主数据管理系统，是建立总部各类主数据标准及标准化管理体系，切实提高总部管控数据标准的能力。现阶段致力于铁塔组织、人员、行政区域、管理区域、供应商、客户、业主物料等主数据的治理工作。目前，数据管理共开放 115 个接口、为 46 套铁塔内部系统提供数据服务、存储数据量约 30G。

此次评估帮助中国铁塔打造更加完整的软件生产过程管理，使软件生产过程可管理、可追溯、可度量，具备支持多研发中心统一管理的能力。打造全生命周期的一站式研发服务，使软件开发更加简单高效。

对于团队主要是对软件研发的管理流程、管理规范形成了共识，提升了整体团队对 DevOps 的理解。

![](../Images/ecc96f94c4cfc4546bf812bba1b5dae2.png)

  

  

**技术运营（标准4）贯标情况**

  

**北京移动 CRM 订单中心项目**  

本次参评的“CRM订单中心项目”，是从核心业务中选择的典型项目来进行试点，用来对标、评估并持续改进本项目的技术运营能力。CRM系统作为核心业务系统之一，其订单中心是面向企业，提供业务运营及运营支撑。CRM订单中心，是可独立部署并对外提供一组标准化订单服务的载体，用于管理产商品交易的信息处理，支持各核心业务系统和客服系统在多种渠道进行商品销售、退订等服务。

![](../Images/3fc615ef76f76e667d424b3e63aa3e9c.png)

北京移动目前的订单中心，基于k8s和（Mesos+Marathon）全云化架构搭建，采用 OpenStack 技术实现硬件资源虚拟化，全域支持弹性扩缩容，支持在业务高峰时全域弹性调度，基于AIF（电信定制化业务开发架构，支持电信业务定制的服务治理，服务开放，服务监控能力）开发框架，实现调度的服务治理，支持扩缩容，限流，熔断，分域等服务治理能力。具备完备的服务列表，服务调用关系展示和控制功能。

![](../Images/b9af5ddb74eac0893bc07abc0f46f37c.png)

  

  

**系统和工具（标准8）贯标情况**

  

**浙江移动蜂云能效平台项目**  

此次参评的项目结合了浙江移动自身的业务特点，规划和设计了符合浙江移动内部系统的发布管控要求和系统应用架构特点的构建和持续集成的工具平台。

比如基于通过浙江移动架构治理管控要求的系统应用来进行构建管理，要按照架构治理管控的要求进行构建管控。同时在构建时支持通过浙江移动的内部的配置中心获取对应系统应用的对应环境的配置文件构建入应用的代码包中。在构建成功后，支持自动通过浙江移动内部的微服务管理平台触发对应应用的注册服务的上架发布，调用缓存平台刷新对应系统应用的缓存配置等功能，从而达到一站式的，快速的发布部署浙江移动自身特点的系统应用。

![](../Images/f33532ec9ecf0fe1e679f552867ad656.png)

  

**中国电信集成比翼协同研发平台项目**  

中国电信集成参评的项目是比翼协同研发平台，它是基于微服务架构，集成了 Jenkins、Nexus、Harbor、Sonarqube 等常用的 DevOps 工具，并进行了深度定制化，比如通过二次开发对 Jenkins 自动化流水线进行了可视化编辑和运行过程全监控，提供基于云原生架构的一站式软件全生命周期管理。最初规划的就是从产品需求—项目研发—应用构建—产品测试—产品发布,这样一个覆盖产品研发整个生命周期的管理闭环。

![](../Images/feaab5b9584d750ab604883b89fe8774.png)

**研发运营一体化（DevOps）能力成熟度模型介绍：**《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已在中国通信标准化协会（CCSA）立项在研。与此同时，DevOps 标准已于 2020 年 7 月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。![](../Images/c656d5dc0ae9a30269a21e7a55a88029.png)
