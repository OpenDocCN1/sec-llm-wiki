各大企业的实践及相关数据表明，标准化和工具赋能是企业成功的关键。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，能有效针对企业软件研发提质增效，不仅更快更灵活，也大幅度提高企业核心竞争力！

2021 年 9 月 9 日，中国信息通信研究院隆重发布了 DevOps 标准系统和工具评估结果。中国银行股份有限公司（以下简称“中国银行”）软件中心的中行 DevOps 云平台参与本次中国信息通信研究院（以下简称“信通院”）开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具技术要求评估，其流水线及构建与持续集成模块顺利通过优秀级评估。代表着中国银行的 DevOps 系统和工具在相关模块达到国内领先水平。

评测单位：中国信息通信研究院

此次，我们采访了中国银行软件中心副总经理李兆云女士，一同深聊在项目参与评估时的细节和故事，分享中国银行 DevOps 实践的经验。

中国银行软件中心副总经理 李兆云

Q：李总您好，请介绍一下您所在的企业，以及此次参与评估的项目。
李兆云：中国银行股份有限公司（简称“中国银行”）软件中心是中国银行总行直属机构，总部位于北京，在深圳、西安、合肥设有分中心，承担中国银行全球应用系统的软件开发、功能测试、应用维护等工作。软件中心按照中国银行“激发活力、敏捷反应、重点突破”的战略要求，秉承业务数字化、场景生态化、技术平台化为关键要素的发展理念，坚持科技赋能、创新驱动，以高质量发展助力中国银行全球一流现代银行集团建设。
中国银行软件中心质量管理部作为软件中心技术管理部门之一，负责统筹引领中心包含开发、测试、运维部门在内的质量条线，建立中心质量管理体系和标准，牵头软件中心 DevOps 建设，推动质量管理数字化转型，助力敏捷交付。
本次参与评估的中行 DevOps 云平台，是企业级 DevOps 平台，该平台以 DevOps 工程实践为指导，以支持产品端到端敏捷交付为目标，在保证质量的前提下加快开发、测试、运维一体化实施和敏捷转型，保证质量稳定，提升交付效率，形成规模化效益。

Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是系统与工具标准，您的感受是怎样的？

李兆云：很高兴中国银行软件中心能够参与中国信息通信研究院组织的研发运营一体化 DevOps 能力成熟度模型评估，这次我们参加了“构建与持续集成”、“流水线”两个模块的评估，并且两个模块都达到了优秀级水平，这是对中国银行软件中心在敏捷转型与 DevOps 建设中成果的肯定，证明了中国银行特色的 DevOps 体系的先进性及应用产品敏捷交付的能力。


Q：打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？

李兆云：当今，业务市场快速发展，打造端到端的流程化、一体化的工具链是 DevOps 成功落地的基础条件。有效的 DevOps 工具链，通过持续的构建、测试、部署、监控等活动，有助于提升快速交付能力；内嵌质量控制手段，有效规范研发交付全过程；同时快速发现产品缺陷，在发现问题时及时通知，减少事件管理成本，形成闭环管理，促进 IT 交付效率和质量双提升，这些都使得企业可以更快速、更可靠地交付质量更好的软件，推进数字化转型进展。


Q： 贵单位参与本次系统和工具标准评估，请问企业有哪些考量？有科技输出的规划么？

李兆云：中国银行非常重视 DevOps 建设，随着中国银行数字化转型工作的推进，为应对业务市场的快速发展，急需提升敏捷交付能力。DevOps 相关工具链是基础性建设，对标业界先进，才能找到自身差距，不断改进工艺流程和提升技术能力，我们的 DevOps 建设成果，将为总、分行提供服务，促进我行 IT 敏捷交付能力规模化提升。


Q： 通过系统和工具标准评估带给企业和团队哪些变化？
李兆云：当前，中行 DevOps 云平台以端到端交付流水线为核心，以业务快速发展为导向，建立各工程活动的连通和联动，为工程人员提供统一的研发交付支撑平台，规范研发交付全过程，内嵌质量标准，实现统一的过程管理和监控。同时，沉淀出一套规范模型与应用指南，形成融合协作的 DevOps 文化，指导 DevOps 落地实施，引领数字化转型。全面而系统的标准评估过程，进一步推动了我行研发能力建设，对标业界领先的能力标准，通过对各个标准能力子项的解读和差距分析，既能发现我行DevOps 云平台的优势，为全面推广和赋能分行提供有力支撑，同时也发现了不足，进一步优化完善，持续提升平台能力。

Q：您通过本次评估，项目的改进成果体现在哪些方面？ 

李兆云：中行 DevOps 云平台通过统一标准整合 IT 研发能力，高效地支撑了企业内不同技术架构产品的全领域持续集成和持续部署能力。根据应用产品研发场景需要，已基本覆盖中行主流应用产品在研发、测试、交付、质量管理、安全控制、版本和制品管理等自动化活动需要。在系统的标准评估中，通过针对性解决方案，各方面的能力不断改进和提升。其中，构建成功率增加了 11%，部署成功率增加了 22%。通过一些加速手段，构建阶段平均时长从 6 分钟下降至 3 分钟，流水线整体执行耗时下降 40%。完善后的可视化质量指标，提升了各应用产品的交付质量。


Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?

李兆云：纵观整个评估和改进的过程，确实遇到了一些问题和挑战。

首先，在对标和差距分析过程中，如何理解行业标准能力与企业特色的融合，金融企业在IT系统建设中优先考虑安全性和稳定性要求，与互联网企业会有一些不同，在专家老师的指导下，深入理解标准的实际价值和意义，求同存异，定制和实施专业解决方案。

其次，我们两个模块一同评级，在几个月的时间完成标准对标，识别改进点，并完成系统改造，时间紧，压力大，对我们是个很大的挑战。在牵头部门带领下，充分发挥各分中心技术优势，团结协作，各部门全力以赴，制定了一系列的里程碑和迭代计划，对 DevOps 云平台完成了多轮问题识别、迭代优化及测试验收。

最后，DevOps 平台因其贯穿开发、测试、运维整个过程，关联工具较多，部分改进点涉及跨工具、跨部门的联合改进，实施难度比较大。我们通过建立柔性组织，统筹规划实施，协同改进，共同提升产品能力，最终顺利通过评估。


Q：对于 DevOps 工作的开展，下一步计划有几方面？ 
李兆云：中国银行已打造了统一 DevOps 云平台，有效支持上云产品的开发部署，后续会在总行全面推广，并持续优化完善。同时，以统筹全局的视野，理顺“强总部”和“活基层”的关系，加强总分协同，科技赋能分行，坚持全行 IT 一盘棋，不断提升分行科技能力。

Q：对于 DevOps 的未来发展方向，您有何看法？

李兆云：DevOps 平台正逐渐成为核心生产系统，而不再是边缘支撑系统，是企业核心竞争力之一。为应对业务市场的快速发展，进行数字化转型，提升应用产品的交付效率和质量极为重要。而 DevOps 是提升交付质量和效率的最佳实践，可以更好地赋能数字化转型。随着网络安全事件层出不穷，安全性已成为各大企业发展战略的关键部分，SecDevOps 正被逐渐探索和应用，将安全性融入自动化流程中，以确保产品整个生命周期的信息安全，是未来的一个重要研究方向。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。
与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
