各大企业的实践及相关数据表明，标准化和工具赋能是企业成功的关键。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，能有效针对企业软件研发提质增效，不仅更快更灵活，也大幅度提高企业核心竞争力！

2021 年 9 月 9 日，中国信息通信研究院隆重发布了 DevOps 标准系统和工具评估结果。建信金融科技有限责任公司（以下简称“建信金科”）的瑶光-敏捷研发平台参与本次由中国信息通信研究院（以下简称“信通院”）开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具技术要求全国首批正式评估，其流水线模块顺利通过优秀级评估。代表着建信金科的 DevOps 系统和工具在相关模块达到国内领先水平。

评测单位：中国信息通信研究院

此次，我们采访了建信金融科技有限责任公司基础技术中心总裁李晓敦先生，基础技术中心总工程师舒展先生和基础技术中心智慧敏捷研发部总经理李卓先生 ，分享建信金科 DevOps 实践的经验。

-Q&A-  

建信金融科技有限责任公司

基础技术中心总裁 李晓敦


Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。
李晓敦：建信金科是中国建设银行（以下简称“建行”）的金融科技子公司，传承建行三十年的科研力量积淀，在建行新一代核心系统的基础上，运用人工智能、区块链、云计算、大数据、量子计算等前沿技术，在基础技术、行业应用、咨询顾问、数字化运营等领域构建成熟、系统的金融科技核心能力。同时，公司积极拓展新场景，构建新生态，将金融科技能力成功运用于智慧金融、智慧政务、智慧出行、监管科技、乡村振兴等领域。公司将积极落实建行新金融行动，助力建行集团数字化转型，赋能“数字中国”建设，让金融科技尽其所能，让社会更美好。
以前沿技术为核心的金融科技应用正在全方位地重塑银行业务模式。为应对变化，建行开启数字化经营探索，打造业务、数据、技术三大中台体系。建信金科打造的技术中台对应用研发、交付、运行所依赖的技术进行了平台化、组件化，以云服务为主要交付方式，实现技术基础能力的快速供给，支持业务创新和快速发展。技术中台的核心能力是各专业技术平台，包括敏捷研发平台、容器云平台、分布式微服务平台、人工智能平台、移动开发平台、大数据平台、区块链平台。我们以“北斗七星”的名字分别将其命名为“瑶光”“开阳”“玉衡”“天权”“天玑”“天璇”和“天枢”。
其中，瑶光-敏捷研发平台（以下简称“瑶光平台”）在建行的数字化转型背景下应运而生，打造面向应用研发全流程的研发平台，支持建信金科所有事业群和建行 38 家分行的全面使用，提供协作研发、DevOps 工具链、研发管理、研发资产、研发度量、低代码开发等能力，支撑建行的研发效能提升和敏捷研发转型。

Q：恭喜建信金科通过 DevOps 标准评估，此次贵公司项目通过的是系统与工具标准，您的感受是怎样的？
李晓敦：非常高兴我司的瑶光平台能够通过国内首批正式 DevOps 工具标准评估。特别感谢信通院各位专家在标准评估过程中对于我们的指导与帮助。
近几年在数字化转型的背景下，我司开始 DevOps 相关技术实践，提高研发效能，打造 DevOps 平台，支撑团队研发实践落地，这也是实现 DevOps 的阶段性成果。本次顺利通过系统与工具标准的评估，更加坚定了我们深化改革的决心，未来会不断提升研发水平，为业务赋能，切实做到提质增效。
 
Q：对于 DevOps 的未来发展方向，您有何看法？
李晓敦：面对日益激烈的市场竞争和日趋多样化的客户需求，以及层出不穷的新技术、新工艺，企业要想求得生存与发展，必须以最快的上市速度，最好的质量，最低的成本，最优的服务，来满足不同客户的更便捷、更高端、更有效率、更低成本的产品需求。为了能够更灵动从容的应对未来形式，需要建立完善的研发运营体系，建设智能的研发平台。敏捷成为驱动研发组织高效协作、打破研发数据孤岛的重要能力。DevOps 的产生加速了开发和运维团队之间的融合，提升 IT 的交付速度和质量，在未来随着容器云平台、人工智能和大数据等的飞速发展，DevOps 的实现方式将更加的一体化和智能化。DevOps 将基于组织的需求，支持更多应用类型和场景，丰富包含从分析到运营的全流程工具链，在保证稳定性的同时，灵活、完备的标准化研发度量体系，促使研发与运营之间无缝对接，为业务赋能，为用户带来极致的体验。在数字化转型的浪潮中，DevOps 是变革的基石，也将成为企业核心竞争力之一。

建信金融科技有限责任公司
基础技术中心总工程师 舒展


Q：打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？
舒展：落地 DevOps 需要体系、文化和平台的支撑，其中打造端到端的流程化、一体化的工具链为我司 DevOps 落地提供平台支撑，提高IT交付效率、提升交付质量，为建行全行推广降低使用门槛及复杂度，更快的推动建行数字化转型，科技赋能业务。
 
Q： 贵单位参与本次系统和工具标准评估，有哪些考量？
舒展：建行在 DevOps 的内部实践所覆盖的产品线范围已经十分广泛，规模也比较大，想借此次参与标准评估的机会，横向的与行业内进行一下比较，更好的审视一下我们在工具建设过程中的不足，以评促改，以评促建，促进快速提高平台能力，达到国内领先水平，以此助力后续的科技输出计划及全行推广工作。同时也希望通过同行业的进一步交流分享，共同探索银行业 DevOps 体系建设的最佳实践，为行业健康发展增砖添瓦。
 
Q： 通过系统和工具标准评估带给企业和团队哪些变化？
舒展：通过本次系统和工具标准评估，进一步完善了建行流水线的能力。
同时，通过评估是对团队努力的充分肯定，也给团队带来很大改变。对于技术团队而言，随着 DevOps 能力体系和工具平台的持续优化完善，实现了从需求到生产再到运维的持续连接，大幅度提升了效率，减轻团队工作负荷，通过工具平台的协作，促使团队更加紧密，保障了对业务的服务。

建信金融科技有限责任公司

基础技术中心 智慧敏捷工程部总经理 李卓


Q：通过本次评估，您觉得项目的改进成果体现在哪些方面？  
李卓：通过本次评估，瑶光平台流水线状态更加健壮、稳定，增加简易性和便利性的同时更加规范化、标准化。流水线实现了自定义函数封装，精简了流水线代码；流水线编辑脚本版本化，可以进行可视化比对；流水线过程信息图形化展示，方便项目组排查问题。
 
Q：此次参评的项目规划和设计有哪些特色与不同？
李卓：本次参评的流水线模块，是采用产品化设计的思路衍生而来，经过建行大规模实践的验证，适配于多种场景及复杂模式，应用于多种技术栈及产品线、高可配置化、独立部署。结合丰富的 UI 配置和灵活的脚本式任务，满足不同能力等级的项目组需求。
 
Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?
李卓：在工具标准评估过程中，我们经历了一些管理协同、工程技术及运维支持上的一些难点，在团队的共同努力与默契配合下都被逐一攻克了，顺利地实现了预期的效果及评级目标。
 
Q：对于 DevOps 工作的开展，有什么进一步的计划？
李卓：接下来，我们计划将本次成功案例在建行全面推广使用，最大化项目的效果和价值。通过最佳实践的经验总结与积累沉淀，引导母行实践更好的研发模式。另一方面我们将继续扩展项目的能力，为支持更多新技术的使用打下良好基础，从而通过科技为产品、业务更好的赋能，并把成熟的实践经验对外分享和输出，做到全业务全领域获益，做到以流水线为核心，加强 IT 体系自动化、智能化建设，拉通工具、体系、人员、业务之间的链路，支撑研发团队的 DevOps 交付实践，成为数字化改革的引擎。

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。
与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
