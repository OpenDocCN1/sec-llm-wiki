2021 年 10 月 20-21 日，2021 全球下一代软件工程大会 GNSEC 2021将于线上举办！本次峰会由 DAOPS 基金会和 Escom Events 共同主办。大部分与会者来自东南亚地区（新加坡、泰国、印度尼西亚、菲律宾、马来西亚、越南）、印度和中国。

大会致力于定义下一代软件工程的标准，聚集 1000 多名行业翘楚，行业高级软件工程师、架构师和团队负责人聚集一堂，共同交流学习，同时行业专家和IT领袖将分享最前沿的技术实践经验和案例。由于当前的疫情限制，GNSEC 2021 将通过 Airmeet 线上呈现，峰会将为与会者提供虚拟展览、虚拟会议、同行网络会议、商务配对会议、虚拟讨论组。大会设有云原生与微服务、人工智能与软件工程、DevSecOps、精益敏捷、持续交付及自动化、质量与测试、金融行业实践案例、可靠性工程等多个专场。

会上，腾讯 T4 级专家、腾讯研究院特约研究员茹炳晟老师将发表精彩演讲：《测试左移背景下的测试中台建设》


茹炳晟

个人简介

茹炳晟，腾讯T4级专家，腾讯研究院特约研究员，业界知名实战派研发效能和软件质量双领域专家。腾讯云、阿里云、华为云最具价值专家，“软件研发效能度量规范”团体标准的核心编写成员，Certified DevOps Enterprise Coach，年度 IT 图书最具影响力作者，畅销书《测试工程师全栈技术进阶与实践》作者，极客时间《软件测试52讲》作者，新书《软件研发效能提升之美》也即将出版。

演讲主题&简介

测试左移背景下的测试中台建设

目前，包括 Google、Facebook 和 eBay 在内的跨国互联网公司的研发团队正在进行“不再需要 QE 和 DEV 进行测试”的组织转型。质量工程团队正在逐渐过渡到工程生产力团队。在此过程中，从工程生产力的角度设计和构建高效的测试基础设施和工具链生态系统以支持“没有更多的 QE 和 DEV 应该进行测试”原则是非常关键的。对于传统 IT 公司，“不再需要 QE 和 DEV 进行测试”可能并不完全适用，但我们可以从工程生产力的创新中学到很多很棒的想法。

在此之后，本讲座将讨论以下工程最佳实践：

1. 测试即服务 

2. 统一测试执行服务 

3. 统一测试数据服务 

4. 统一测试床服务



1. 理解“测试即服务” ” 提高开发人员的测试效率 

2. 了解大型互联网公司中测试数据的最佳实践 

3. 了解大规模测试执行的最佳实践 

4. 了解测试执行环境设置的最佳实践。
