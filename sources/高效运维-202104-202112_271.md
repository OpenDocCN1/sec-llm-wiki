# 腾讯 IEG 资深专家：腾讯业务的 DevOps 实践 | 活动通知

![](../Images/bbe47bd3bb7f1014d724abb03d13a9fc.png)随着云计算、大数据、AI等前沿科技的发展，传统的研运模式，越来越难满足企业快速发展的需求。DevOps也成了继商业模式、技术突破之后的另一核心竞争力。同时，如何有效降低研发和运维的成本也是DevOps需要关注的重要课题，尤其是在大型互联网公司或传统企业，当某个环节哪怕只有少量优化的时候，由于其规模效应（比如集群规模，用户流量等）的放大作用，最终节省的成本也会是相当可观的。为了让更多企业掌握DevOps体系快速升级之道和降本增效的方法，DevOps 国际峰会 2021 · 北京站，腾讯 IEG 资深专家刘章雄老师将分享腾讯业务 DevOps 落地方法以及实践案例，研效工具设计和开发实践之路，深入浅出 DevOps 的度量和改进优化，探讨 DevOps 理念和技术指导。
