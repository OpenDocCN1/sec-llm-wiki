B 站宕机并无火情，官博凌晨致歉

7月13日晚间据网友大规模爆料：B站崩了，A站也崩了，晋江，豆瓣在微博热搜会晤，新浪服务器果然挺住了。
起因是疑似 B 站服务器机房故障崩了，大量用户涌入A站，A站承受不住这么大流量，然后也崩了，随后网友又一起涌入豆瓣、晋江想看看是怎么回事，这两个平台也没hold住齐刷刷瘫痪，最后所有网友齐聚在微博，热搜话题爆了，最后就是新浪程序员连夜加班扩容，互联网内卷之《谁也别想睡觉》。
                         
几个小时后，B站官博微博宣布故障排除，服务器正常。 
         

网传阿里巴巴和腾讯考虑互相开放生态系统

有消息人士称，阿里巴巴和腾讯考虑互相开放生态系统，阿里巴巴的初步举措可能包括将腾讯控股的微信支付引入淘宝和天猫；而腾讯可能将允许阿里巴巴的电商信息在微信分享，或者允许微信用户通过小程序使用阿里巴巴的一些服务。双方都在分别制定放松限制的计划。
此消息一出，阿里巴巴美股盘前涨超3%，腾讯控股ADR盘前涨3.76%。阿里巴巴此前在腾讯旗下的微信上架了几款小程序：闲鱼、1688和盒马集市。可以看出两家正在探索如何深入合作。

上海 90 后用优惠券薅羊毛 45 万被捕

近日，某买菜平台的两名前员工，通过平台漏洞薅羊毛，造成公司损失45.5万元。目前，两人已被浦东新区检察院依法批准逮捕。

据警方调查，两人对于平台优惠活动十分熟悉，通过非法手段获取了大量虚拟账号注册新用户，骗取大量新用户优惠券及邀新优惠券，后利用大额“优惠券”以较低价格大量购入实体商品，转卖后赚取差价，每单至少获利30元。

这起薅羊毛事件再一次引发热议。有网友认为遵照平台规则操作，不算违法。也有网友说，利用平台漏洞，低价买入高价卖出，已经归入诈骗范畴了。平台需要的“新用户”，是可以留存下来，为平台持续提供利润的实际用户，而不是单纯用手机号注册出来的虚拟用户。



华为再招 201 万元年薪“天才少年”，任正非说养得起！

近日，华中科技大学又有2名毕业生入选华为“天才少年”。三年内，华中科技大学已有6名毕业生入选，拿到令人羡慕的百万年薪。今年入选的廖明辉和武敏颜分别来自华中科技大学电信学院和计算机学院。廖明辉为应届博士毕业生，已拿到“天才少年”最高一档年薪201万元；武敏颜本科毕业，年薪也超百万元。“天才少年”计划由华为创始人任正非发起，旨在吸引顶尖人才，“天才少年”的工资按年度工资制度发放，共有三档，最高年薪达201万元。今年2月，任正非在接受媒体采访时坦言，华为是踏踏实实做好产品与服务，欢迎科学家加入，养得起天才。


京东宣布涨薪两个月：14薪涨至16薪

京东集团宣布自2021年7月1日开始到2023年7月1日，用两年时间，将员工平均年薪由14薪逐步涨至16薪，在2021年7月1日之前的基础上直接涨薪两个月。
       

         

7 月数据库排行榜：三大数据库分数下降最多

DB-Engines 7 月份流行度排行已更新（基于 6 月份的整体数据变化）。

分数方面，三大数据库 Oracle、MySQL 和 SQL Server 与去年同期相比出现了较大的下跌，分别减少了 77.59、40.13 和 77.77。即便与上个月相比，除了 MySQL 增加 0.52 分，其余两个是排行榜中分数下跌最多的数据库。

《中国互联网发展报告（2021）》发布：中国公有云市场 990.6 亿元、私有云市场 791.2 亿元

7月13日，由中国互联网协会主办的2021（第二十届）中国互联网大会在京开幕，会上《中国互联网发展报告》正式发布。报告显示：2020年我国云计算整体市场规模达到1781.8亿元，增速为33.6%。其中，公有云市场规模达到990.6亿元，同比增长43.7%，私有云市场规模达791.2亿元，同比增长22.6%。
