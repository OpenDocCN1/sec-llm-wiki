DevOps 工程师这一角色具有广泛的含义，不属于某一职业，专业人员可基于自身技术背景演变。例如，DevOps 工程师可能从IT 运营各个方面的软件开发人员演变而来，也可能会从系统管理员角色晋升，因为他们获得了有关编码、脚本、集成和测试的知识。DevOps 工程师的职责包括根据需要更改业务流程以解决组织问题和改善业务成果。

因此 DevOps 工程师的薪资也会高于传统IT人员薪资，具有非常好的职业前景和规划方向。9月2日，在 DevOps 国际峰会前夕，DevOps Foundation 课程可以帮助初学者明确目标和职责，课程适用于希望能够掌握最新 DevOps 发展动态的所有专业人员，在 DevOps 团队中工作的任何人员，或正考虑转向 DevOps 的企业及该企业内的人员等。本课程主要探索 DevOps 的精髓，学习 DevOps 核心原则和实践，清晰业务和技术框架，掌握自动化及构建 DevOps工具链、度量、指标和报告等等。


DevOps Foundation®是 DevOps Institute独立认证的课程。本课程及其相关考试的目的是传授、测试和验证DevOps 的基本词汇、主旨和实践知识。词汇术语表、概念和实践都包含在课程学习手册中。DevOps Foundation课程旨在培养个人对 DevOps Foundation概念的理解以及 DevOps 如何用于提升软件开发人员和 IT 运维人员之间沟通、合作和集成的效率。


课程包含来自DevOps institute最新思想、原则和实践，包含对高效能组织真实案例的剖析，如ING Bank, Ticketmaster, Capital One, Alaska Air, Target, Fannie Mae, Societe Generale, and Disney。吸引并激励学员,利用多媒体和互动实践,将学习经验运用于实践。内容还包含对《凤凰项目》作者 Gene Kim 在书中强调的三步工作法以及《DevOps现状报告》中最新成果的重点讲解。


通过学习学员将深入理解 DevOps 的精髓，强调沟通、协作、集成和自动化，进一步帮助改善软件开发人员和IT运维人员之间的工作流。


本课程针对广泛技术从业者设计，使业务侧人员理解 Kubernetes 和容器，使技术侧人员理解 DevOps 的商业价值，例如降低成本(整体IT成本降低15-25%)并提高质量(变更失败率降低50-70%)及敏捷性(供应和部署时间减少高达90%)来支撑商业目标并支持数字化转型方案。


本认证由国际知名认证机构DevOps Institute认证，目前全球持证人数超过8000人，是全球范围内DevOps领域持证人数最多的认证课程，该认证在全球范围认可，目前是美国最流行的DevOps 认证。课程中设置了独特的练习，并提供范本文件、模板、工具和技术，以供课后使用。通过学习本门课程，进一步支持组织工作，在减少成本的同时提高敏捷性，质量和用户服务；利用案例研究，真实的成功案例，以及度量指标去证明此基础级课程中的商业成功,以支持数字化转型。
