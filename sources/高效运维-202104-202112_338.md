随着公司扩大规模以满足新的业务需求，对 DevOps 角色的需求仍然很高。成功采用 DevOps 需要强大的学习文化。最好的学习文化专注于培养新的和广泛的想法以及强大的反馈和前馈循环，成功实施组织拓扑和价值流管理有助于推动强大的 DevOps 转型。

  

**“成功的 DevOps 之旅具有学习型组织的 DNA”，**而企业级 DevOps 教练作为企业转型先锋队中重要的角色，在带领团队人员学习，渗透 DevOps 文化及技术指导方面有突出贡献。自 2020 年 9 月开班的企业级 DevOps 教练公开课已经举办三次，深受大家喜爱，知名金融企业、通信、互联网大厂的技术前辈们都纷纷学习并顺利毕业，目前 DEC 公开课已经被多家头部银行、互联网大厂应用于内部培训！

**7 月 ****16-18日，****企业级 DevOps 教练（DEC，DevOps Enterprise Coach）全国第四次公开课将于上海开课！**

![](../Images/05485c0adc2a3ed4d26598cc275f6b2f.png)想提升 DevOps 专业技能，成为 DevOps 落地实践者的朋友们快来报名啦！~  
![](../Images/c871be0f71a95e59352bd8467329784c.png)

企业级 DevOps 教练（ DEC，DevOps Enterprise Coach ）是由 DAOPS 基金会开发并由 DevOps Institute 管理的高级认证，面向在企业中实践 DevOps 的人员。该认证覆盖在企业级引入和实践 DevOps 所需的所有能力，包括：组织结构和文化，精益和敏捷，应用架构设计，持续交付，测试及其自动化，技术运营，DevSecOps，度量，转型和持续改进。该认证及其相关课程的目的是为企业培养 DevOps 教练，以加快企业的 DevOps 转型。

每个正进行 DevOps 转型的企业都应该有一支由企业级 DevOps 教练组成的团队。

![](../Images/5f8968a90f5ad347e843075f879511fb.png)

**课程目标**

**DevOps Enterprise Coach ™ 课程的学习目标包括对下述内容的掌握：**

*   DevOps 核心知识、概念、实施策略
    
*   精益敏捷核心方法框架与实施方法
    
*   持续交付核心实践技术，包括：版本控制、持续集成、持续部署、持续交付等
    
*   测试分层策略与自动化测试技术，包括：接口测试、测试数据、混沌工程等
    
*   技术运营管理流程与实践技术，包括：监控预警、高可用管理等
    
*   DevSecOps 核心实践技术，包括：安全开发、安全测试、安全运维
    
*   DevOps 度量体系与方法框架
    
*   DevOps 转型典型方法路径与案例 
    

  

** 核心收益 **

**对企业**

●有利于成功实现组织级 DevOps，提高产品/服务的研发运营效率、质量、安全性、可用性

建立企业 DevOps 转型的专业团队  

构建跨领域型专家团队  

提高企业 DevOps 转型效率，缩短转型周期

**对个人**

● 提升 DevOps 专业技能，成为 DevOps 的推动者

实现持续学习与能力改进  

更好的职业发展机会

  

**目标学员**

DevOps Enterprise Coach ™ 旨在培养企业级DevOps转型教练，支撑企业快速低成本的实现 DevOps 转型。

  

**目标群体包括（不限于）：**

*   中高级开发工程师与软件架构师
    
*   中高级测试工程师
    
*   中高级运维工程师
    
*   配置管理、持续交付专业人员
    
*   敏捷教练、项目管理专业人员
    
*   IT 管理者与主管人员
    
*   需要掌握 DevOps 的其他IT专业人员
