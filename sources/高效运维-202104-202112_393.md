# Nginx 开启 ssl 会话复用，能提升多少性能？

之前专门写过[如何优化你的 https](https://mp.weixin.qq.com/s?__biz=MzI1MzY3NTE1NQ==&mid=2247483968&idx=1&sn=70f90ecd4bc3f5829f2a8b70b6fd0100&chksm=e9d191bcdea618aac724913f729b57f1ebe6726c766a57e7d74f927047b7746300dc4ada4bcc&scene=21#wechat_redirect)，里面总结了几点 Nginx 下优化 HTTPS 的方法，最后有两点小的建议，没有详细说明，最近在群里看到朋友发的Nginx配置文件，只配置了证书和密钥部分，所以觉得有必要再把这些刨析一下

![](../Images/813f238679ccdccf99366b744f4b7034.png)

上图是 Nginx 官网文档中，关于ssl\_session\_cache的介绍，ssl\_session\_cache，就是缓存ssl会话状态的缓存，它有4种模式可选，分别是：

*   off：严格的禁止使用会话缓存
*   none：宽松的禁止使用会话缓存，即虽然nginx不说不允许使用会话缓存，但实际不会将会话缓存下来
*   builtin：openssl的内置缓存，只有一个工作进程可以使用该缓存，官方指出，内置缓存，会导致内存碎片
*   shared：共享缓存，所有worker进程共享

这条配置，能带来多大的性能提升？我们抓包看

![](../Images/cb36ad89451776e9ca86eed0e1a0b0e0.png)

首先实验环境 Nginx 只配置了证书和密钥，通过 wireshark 抓包查看不配置 ssl\_session\_cache 的完整连接过程

![](../Images/2efedfe92414f8bd0866abe1cf4fc9b9.png)

可以看到，三次握手完成后，开始建立TLS连接，交换证书、验证证书，详细的TLS连接过程可参考另外一篇文章《Wireshark抓包帮你理清HTTPS请求流程》，这里不多说了，总结完整建立TLS连接过程如下：

![](../Images/0b67e248f9b0b896c88ad30276fc1ca7.png)

接着我们在Nginx开启ssl\_session\_cache，重新抓包

![](../Images/525f2596e42a896619c184f07374842a.png)

可以看到，简单的TLS握手包，完成3个TLS，就建立连接，传输数据，总结简短TLS链接过程如下：

![](../Images/7fa35c5adf024ee042fb7562f6340ec7.png)

可以看到，简短的TLS链接，比完整的TLS链接少了一个完整的往返，如果按照50ms的TTL，那么一次链接就可以节省100ms，效率提升40%

### 缓存如何实现的？

在 nginx 中设置ssl\_session\_cache之后，就开启了TLS缓存复用，整个过程如下：

客户端Client Hello的时候，会带一个Session ID，如果6769号包中

![](../Images/5d3b672d41fe6816cf363330a8d274fd.png)

服务端和客户端协商建立连接，确认Session ID

![](../Images/2589cc0b55ce09ee1c4dfe261eb77750.png)

然后客户端将Session ID保存在本地，再次发起连接的时候，Client Hello会带上这个ID

![](../Images/cceba9614dcd07006b023a9031842b7b.png)

因为服务端开启了ssl\_session\_cache，则在缓存中查找对应的Session ID，如果存在则接受并恢复会话，返回相同的Session ID

![](../Images/61a4c97670d9ca56a6cf52afd711aa24.png)

如果在缓存中，未找到对应的Session ID，则转换成完整的TLS握手

缓存的时间由ssl\_session\_timeout决定，默认是5分钟

### 总结：

TLS通过复用ssl来优化TLS连接过程，tls的复用由服务端决定是否可复用，包括session的过期时间，在nginx中，通过开启ssl\_session\_cache来开启缓存和复用，性能提升40%。来源：本文转自公众号运维研习社，[点击查看原文](https://mp.weixin.qq.com/s?__biz=MzI1MzY3NTE1NQ==&mid=2247485283&idx=1&sn=dbb05b57df581ce9cc579906c8c1f17f&scene=21#wechat_redirect)。**GOPS 全球运维大会 2021 · 深圳站精彩集锦，点击下方视频了解~****近期好文：**
