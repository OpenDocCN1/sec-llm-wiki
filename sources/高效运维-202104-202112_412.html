燃！国信证券通过 DevOps 持续交付标准 3 级评估，相关项目能力达到国内领先水平！

编者按：从各大企业的实践来看，标准化和工具赋能是科技公司成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，使得企业的软件研发效能飞速提升、更快更灵活应对市场变化，助力IT成为企业的核心竞争力之一。

2021 年 5 月 21 日，由云计算开源产业联盟（OSCAR）指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十六届 GOPS 全球运维大会在深圳正式召开。GOPS全球运维大会至今已经举办了 15 届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。
会上，中国信息通信研究院隆重发布了 DevOps 标准持续交付第十二批评估结果。国信证券股份有限公司（以下简称“国信证券”）本次参评项目为金太阳资讯中台，该项目顺利通过由中国信息通信研究院（以下简称“信通院”）开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。DevOps 标准共分 5 级，持续交付部分如果能达到 3 级已经是国内领先水准，这代表着国信证券在参评项目的持续交付能力达到国内领先水平。同时，国信证券也是全国第三家通过持续交付 3 级评估的券商。
评测单位：中国信息通信研究院。

由中国信息通信研究院云计算与大数据研究所所长何宝宏博士为国信证券授牌：


▲DevOps评估结果公布现场

此次，我们采访了国信证券首席工程师刘汉西先生和信息技术总部渠道产品开发部总经理薛仲义先生 ，一同深聊团队在项目参与评估时的细节和故事，分享国信证券 DevOps 实践的经验。

-Q&A-

国信证券首席工程师刘汉西


Q：请介绍一下企业以及此次团队参与评估的项目。
刘汉西：您好，我是国信证券首席工程师刘汉西。
国信证券创立于改革开放前沿的深圳，经过 20 多年的发展，国信证券已成长为全国性大型综合类证券公司，近年来公司总资产、净资产、净资本、营业收入、净利润等核心指标排名行业前列。
金太阳是国信证券自主研发的一站式金融投资理财软件，为投资者提供实时证券行情、财经资讯、开户业务办理、证券交易、理财等功能。目前金太阳注册用户数超过1600 万，证券客户数超过 700 万，委托交易占比超过 50%，已成为公司重要交易渠道。
金太阳资讯中台服务，为客户提供有价值的资讯参考信息。包括国信证券投资研报、专家观点、上市公司资讯及数据、市场分析、股票F 10、智能选股、股票搜索等特色栏目。金太阳资讯中台服务采用国信自研 Zebra 微服务框架，已全部实现微服务化。现结合自研 Simba 研发效能平台，打通开发、测试、运维，项目研发效能能力上了一个新台阶。

Q：恭喜国信证券通过 DevOps 标准持续交付3级评估，表明达到了国内领先水平，感受如何？
刘汉西：很高兴项目通过 DevOps 持续交付 3 级标准评估。近年来，随着公司业务的发展和IT规模的扩张，对 IT 业务支持、交付速度提出了更高的要求。需要持续深化IT治理和管控，提升研发质量和敏捷交付能力，为此我司在 2017 年年底启动了 DevOps 平台建设。
此次评估代表着对我们这些年努力付出的认可，表明了平台已具备研发全流程端到端自动化价值交付能力，将显著提升开发、测试、运维一体化程度，在保证质量的同时，进一步提高 IT 研发效率，使研发人员能够及时响应多变的市场需求，降低企业成本，助力公司数字化转型。

Q：国信证券是如何决定加入 DevOps 标准评估工作中的？
刘汉西：公司作为国有大型证券公司，为了迎接数字化、信息安全、业务变革、架构演进的新时代新挑战，提升信息技术敏捷交付能力，灵活响应业务变化，支持公司业务快速创新，公司决定加入 DevOps 标准评估工作，从而更好的衡量我们的研发效能能力，推动其持续提升，实现信息系统服务高效、高质量输出，以落实公司“数字化、智慧化、敏捷化和集团化”的 IT 战略规划。

国信证券信息技术总部渠道产品开发部总经理薛仲义

Q：通过 DevOps 标准评估对企业带来了什么帮助？对团队有哪些影响？
薛仲义：您好，我是国信证券信息技术总部渠道产品开发部总经理薛仲义。

作为传统金融机构，DevOps 标准评估工作完善了我们从传统 IT 到移动化、分布式、云原生等各类金融科技转型的技术支撑平台，推动了研发模式向敏捷模式转型，增强了核心关键技术的自主研发和自主掌控，提升了灵活响应业务变化，支持公司业务快速创新的能力。

金太阳资讯中台系统实践过程中，借鉴了国内外金融科技先进理念，结合公司实际情况，以云原生技术体系与路线图为中心，从技术架构、研发效能、服务治理等角度入手，建设基础支撑平台，使团队敏捷研发能力极大提升。


Q：团队项目通过本次评估有哪些数据指标可以直观的体现项目改进成果？

薛仲义：本次评估对项目研发效能方面带来了显著的提升，包括平均交付周期从 1.5 个月缩短至一周、单测覆盖率从 40% 提升至 84.39%、自动化测试覆盖率达到 100%，自动化测试成功率达到 97.99%，流水线构建成功率以及测试、生产部署成功率均达到 100%，并且各类关键指标都设定了度量和阈值，推动团队持续改进。


Q：对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？

薛仲义：我司在移动互联网中台技术架构方面走的比较快，此次参评的金太阳资讯中台项目已基于自研的微服务架构实现微服务化与容器化，我们也有敏捷研发管理、CI\CD流水线、部署、安全等各类研发工具，但工具间没实现端到端的打通，为此我们让此次参评项目作为试点，希望通过评估，进一步优化敏捷研发流程，完善并提升DevOps 自动化能力，实现端到端打通，成为信息技术内部标杆项目，促进部门的 DevOps 能力提升，助力公司数字化战略。


Q：团队参与评估的过程还顺利吗？遇到哪些困难？如何解决的？

薛仲义：在项目实施初期遇到了较大挑战，步履维艰，主要是人员的 DevOps 理论基础薄弱，DevOps 技术储备缺乏，对于如何将需求管理、开发测试、部署、安全等各领域联动起来，缺乏充分的理解。

为了应对这些困难，首先我们与先进互联网公司、证券同行等进行了深入的交流学习，结合公司实际情况，逐步理清研发流程、端到端的结合点，为整个项目实施提供的理论支撑；其次我们从头部互联网招聘了具有 DevOps 研发能力的人才，并培养了一批技术过硬的自有人员，为项目实施提供了良好的人才技术基础；最后在公司领导的支持下，我们引入了 DevOps 多个领域先进工具，夯实了设施基础。

最终我们在平台团队与项目团队共同协作努力下，持续进行优化改进，问题逐个击破，项目的进展持续向好。


Q：对于国信证券 DevOps 的实施，团队最大的收获是什么？下一步计划有哪些？

薛仲义：通过此次 DevOps 评估项目，一方面，我们对 DevOps 各个领域进行全方位整合，建成 Simba 研发效能平台，结合组织架构对研发全流程进行梳理优化，极大提升开发、测试、安全、运维一体化程度；另一方面我们通过自研方式，培养了市场稀缺的 DevOps 相关人才，为后续的 DevOps 持续发展奠定基础。

接下来，一方面我们将结合各类业务研发场景，包括前中后台等多领域，不同技术栈体系进行完善适配，最终实现一套平台、一个门户服务各类不同研发场景，让不同研发团队都能享受到 DevOps 带来的便利；另一方面我们围绕研发效能度量改进系统持续运营，将指标与团队能力结合，建设符合国信实际情况的研发效能分级体系，促进各个研发团队的持续改进，成为更加先进、具有战斗力的组织。


Q： 对于 DevOps 的发展前景，有哪些看法？

薛仲义：Gartner 指出 DevOps 是数字化转型成功的六个关键之一，DevOps 将应用的需求、开发、测试、部署和运营统一起来，基于整个组织的协作和应用架构的优化，实现敏捷开发、持续交付和应用运营的无缝集成。帮助企业提升IT效能，在保证稳定的同时，快速交付高质量的软件及服务，灵活应对快速变化的业务需求和市场环境，在国家数字化转型的浪潮中，DevOps 将成为研发数字化的基石，并持续发展。

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。
与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
