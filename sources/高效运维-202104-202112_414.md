# 燃！中国人寿财险通过 DevOps 持续交付标准 3 级评估，相关项目能力达到国内领先水平！

**编者按：**从各大企业的实践来看，标准化和工具赋能是科技公司成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，使得企业的软件研发效能飞速提升、更快更灵活应对市场变化，助力 IT 成为企业的核心竞争力之一。

2021 年 5 月 21 日，由云计算开源产业联盟（OSCAR）指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十六届 GOPS 全球运维大会在深圳正式召开。GOPS 全球运维大会至今已经举办了 15 届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。

**会上，中国信息通信研究院隆重发布了 DevOps 标准持续交付第十二批评估结果。**中国人寿财产保险股份有限公司（以下简称“中国人寿财险”）本次参评项目为农险理赔系统，该项目顺利通过由中国信息通信研究院（以下简称“信通院”）开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。DevOps 标准共分 5 级，持续交付部分如果能达到 3 级已经是国内领先水准，这代表着中国人寿财险在参评项目的持续交付能力达到国内领先水平。**评测单位：中国信息通信研究院。**

**由中国信息通信研究院云计算与大数据研究所所长何宝宏博士为中国人寿财险授牌：**

▲DevOps评估结果公布现场

此次，我们采访了中国人寿财产保险股份有限公司研发中心总经理郭海涛先生 ， 一同深聊团队在项目参与评估时的细节和故事，分享中国人寿财险 DevOps 实践的经验。

**\-Q&A-**![](../Images/7861d6ce1a970fd972e5ab5fa0070b09.png)

中国人寿财产保险股份有限公司研发中心总经理 郭海涛

  
****Q：请介绍一下企业以及此次团队参与评估的项目。******郭海涛：**中国人寿财险成立于 2006 年 12月 30 日，系中国人寿保险（集团）公司旗下核心成员，注册资本为 188 亿元，经营范围包括财产损失保险、责任保险、信用保险和保证保险、短期健康保险和意外伤害保险，上述业务的再保险业务，国家法律、法规允许的保险资金运用业务，经中国保监会批准的其他业务。中国人寿财险保持了规模效益协调发展，打破了财产保险经营常规模式，综合实力步入财产保险行业前列。国际权威评级机构穆迪对中国人寿财险的首次保险财务实力评级为“A1”，评级展望为“稳定”。2020 年，中国人寿财险实现保费收入 863.96 亿元。此次参与评估的项目为农险理赔系统，农险理赔系统作为公司新一代核心业务系统重点项目之一，具有“功能丰富、技术先进、使用友好”的三大特点，主要实现了农业保险四大险类的报案、调度、立案、理算、核赔、结案、重开等全流程理赔操作和管理，针对农业保险业务处理流程实现理赔智能化、流程自动化和管理精细化。  
******Q：****恭喜中国人寿财险通过 DevOps 标准持续交付 3 级评估，表明达到了国内领先水平，感受如何？********郭海涛：**面对新形势、新挑战、新要求，中国人寿财险紧密依托“科技财险”三年行动方案和数字化转型工作方案，全面推进各领域数字化建设，不断拓宽移动化、数据化、智能化等各类应用场景，在服务、营销、产品、运营、风控、平台等方面均取得不错的成绩。中国人寿财险作为财险行业首批通过 DevOps 持续交付标准三级评估的企业，实施过程中充分结合研发管理体系现状及参评系统特点，对照 DevOps 标准，查漏补缺，优化交付流程，打通交付工具，可视化交付过程，建立从需求、开发、测试到部署的端到端持续交付流水线，切实提升IT交付效率和质量，快速交付有用的价值，标志着中国人寿财险农险理赔项目的持续交付能力达到国内领先水平，也是我们在 DevOps 转型实践路上的一个重要的里程碑。  
****Q：**中国人寿财险**是如何决定加入 DevOps 标准评估工作中的？****

**郭海涛：**在新时代、新经济、新金融的大背景下，为加速助推公司数字化转型，与之相适配的，是改变研发工作模式来提升敏捷性，通过落地DevOps转型来提高持续交付能力，成为未来研发体系的发展趋势。为快速响应市场需求，中国人寿财险于2019年初正式启动DevOps能力建设，但是在探索DevOps实践的过程中，缺乏明确的实践指导。我们希望通过DevOps标准来衡量目前持续交付的能力，了解我们在DevOps实践过程中的不足，找准切入点，明确未来的改进方向，以便进行针对性的改进，进而快速提升交付的效率和质量，助力科技和业务的融合发展，提升科技赋能水平。

 

****Q：****通过 DevOps 标准评估对企业带来了什么帮助？对团队有哪些影响？****  

**郭海涛：**随着 DevOps 工程的落地实践，初步建立符合中国人寿财险特点的DevOps运行体系，贯通 DevOps 工具链，建成端到端的持续交付流水线，制定分层测试策略，推进分层自动化测试，建立质量门禁体系，提升生产运营能力，保证产品快速验证与交付，实现研发过程中工具贯通、流程贯通、数据贯通，提升农险理赔系统交付效率和质量，引领公司转型升级。

 ******Q：团队项目****通过本次评估有哪些数据指标可以直观的体现项目改进成果？******

**郭海涛：**通过 DevOps 持续交付的 3 级评估，我们在需求、开发、测试、部署等多个能力域均获得了显著的提升，具备快速、高效、高质量的交付能力，真正实现提质增效的目的。其中，交付质量方面，通过集成单元测试、自动化代码扫描、自动化UI/接口测试、质量门禁等多种技术工艺，持续降低历史技术债务，保障需求交付质量，单元测试通过率为 100%，自动化接口测试覆盖率达 100%；交付效率方面，需求交付周期缩短至 5 天左右，平均构建时长降低至 15 分钟内，自动化构建成功率达到 90% 以上。

![](../Images/752bdbae7b4c469a6f4d0942a9af3b05.png)

  

********Q：****对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？**********郭海涛：**农险理赔系统是基于中国人寿财险统一开发平台进行建设，具有微服务、异步化、弹性伸缩、分布式计算、按需组装、高并发、高可用等技术特性，具体特色表现为：在基础扩展能力上，以案卷引擎为核心，规则引擎与流程引擎相结合形成控制中心，驱动前端页面引擎，共同结合形成了理赔系统快速、灵活的支撑能力，从最源头的数据标准化，到过程中的元数据管理，再到持续的数据质量监控，建立全生命周期的数据管理体系，系统设计上，面向各类用户提供大量操作便捷性设计，大大提高工作效率，提供极致的用户体验。    
**********Q：团队参与****评估的过程还顺利吗？遇到哪些困难？如何解决的？************郭海涛：**本次参与评估对我们来说挑战还是挺大的，一方面在疫情的背景下远程办公沟通成本高；另一方面还需要保证系统在原有开发运维任务的基础上，配合完成 DevOps持续交付能力的改进，如何确保评估工作顺利进行具有一定的挑战，我们通过成立 DevOps 实践工作组，深刻理解持续交付的理念，围绕改进工作项开展专题讨论，进一步细化任务，制定详细的实施方案，明确时间计划和人员分工，不断优化实施方案，确保改进工作顺利推进。最终整个团队还是不负众望，攻坚克难，不畏艰辛，保质保量完成持续交付能力改进。  
************Q：对于**中国人寿财险 **DevOps 的实施，团队最大的收获是什么？下一步计划有哪些？**************郭海涛：**通过 DevOps 标准评估对标业界最佳实践，既开拓了眼界，同时从中发现自身薄弱环节。通过集成自动化代码质量检查、单元测试、自动化UI/接口测试，设置质量门禁，消除不必要的人为操作。随着 DevOps 标准在项目团队内的落地实践，大幅提升了研发交付效能，同时也获得了团队成员的认可与拥抱。未来我们将基于本次参评项目取得的成果，在组织内部持续推进 DevOps 实践，全面提高研发管理的整体水平，并建立公司内部的 DevOps 成熟度评价标准。

 

**************Q：**** 对于 DevOps 的发展前景，有哪些看法？****************郭海涛：**DevOps 的范畴涵盖了一切对开发过程有利的实践，其理念与软件行业整体发展目标是一致的。DevOps 强调的是高效组织团队之间通过自动化的工具协作和沟通来完成软件的生命周期管理，从而更快、更频繁地交付高质量的软件，真正能够实践DevOps 的团队也会为自身的业务带来巨大的提升。当前传统企业的研发模式越来越多地受到来自互联网等企业的挑战，DevOps 能够很好地赋能数字化转型。我们通过 DevOps 的落地实施，切实提升了研发效能，具备高频发布产品的能力，在快速响应市场等方面也表现出了积极的作用。总之，我们相信随着 DevOps 理念的进一步推广，参与其中的企业将会逐步增加，DevOps 将会助力IT成为企业的核心竞争力之一。

**研发运营一体化（DevOps）能力成熟度模型介绍：**《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。![](../Images/c656d5dc0ae9a30269a21e7a55a88029.png)
