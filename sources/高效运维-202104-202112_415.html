燃！内蒙古移动通过 DevOps 持续交付标准 3 级评估，相关项目能力达到国内领先水平！

编者按：从各大企业的实践来看，标准化和工具赋能是科技公司成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，使得企业的软件研发效能飞速提升、更快更灵活应对市场变化，助力IT成为企业的核心竞争力之一。

2021 年 5 月 21 日，由云计算开源产业联盟（OSCAR）指导，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第十六届 GOPS 全球运维大会在深圳正式召开。GOPS全球运维大会至今已经举办了 15 届，是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会，面向互联网及金融、通信等传统行业广大运维、开发等技术人员，传播先进技术思想和理念，分享业内最佳实践。

会上，中国信息通信研究院隆重发布了 DevOps 标准持续交付第十二批评估结果。中国移动通信集团内蒙古有限公司（以下简称“内蒙古移动”）本次参评项目为政企业务支撑系统（Esop）项目，该项目顺利通过由中国信息通信研究院（以下简称“信通院”）开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。DevOps 标准共分 5 级，持续交付部分如果能达到 3 级已经是国内领先水准，这代表着内蒙古移动在参评项目的持续交付能力达到国内领先水平。

同时，内蒙古移动是移动体系通过持续交付 3 级评估的第五家公司，此前通过的有：浙江移动、广东移动、北京移动和江苏移动（相关新闻稿链接详见文末）。

评测单位：中国信息通信研究院。

由中国信息通信研究院云计算与大数据研究所所长何宝宏博士为内蒙古移动授牌：

▲DevOps评估结果公布现场

此次，我们采访了内蒙古移动信息技术部总经理乔栋先生， 一同深聊团队在项目参与评估时的细节和故事，分享内蒙古移动 DevOps 实践的经验。

-Q&A-

信息技术部总经理 乔栋


内蒙古移动政企业务支撑系统（ESOP）项目团队


Q：请介绍一下企业以及此次团队参与评估的项目。
乔栋：内蒙古移动隶属中国移动通信集团公司,是中国移动有限公司在内蒙古设立的全资子公司。作为内蒙古自治区最大的通信运营商，内蒙古移动近年的 IT 领域能力建设以公司发展战略为引领，以“转型升级”为目标，践行力量大厦及三融三力价值体系。数字化业务转型需要IT支撑模式、IT 架构和组织保障同步进行转型升级，以实现敏捷、高效的 IT 支撑能力。在此背景下，需要建立一套完善的IT保障体系（包括方法论、组织保障、流程制度和工具等）来支撑公司的“转型升级”。
本次参与评估的项目是政企业务支撑系统（ESOP）项目，该项目是面向全区客户经理使用的集团业务统一受理门户。该系统在智慧中台整体架构体系下，新建了政企服务中心，对集团业务分散的处理能力进行收敛和整合，统一对外提供服务。作为一站式政企业务支撑系统，系统不仅对内整合服务能力，还集成了集团 BBOSS 系统、集客大厅、省 CRM、经分等多个业务平台。

Q：恭喜内蒙古移动通过 DevOps 标准持续交付3级评估，表明达到了国内领先水平，感受如何？

乔栋：本次能够通过持续交付标准 3 级评估实属不易，首先要感谢信通院对我们的指导和帮助，也感谢集团公司、省公司领导对 DevOps 转型给予的肯定和帮助。ESOP项目建设了独立的Web端门户，聚焦政企业务，支持政企管理人员、运营人员、客户经理个性化的功能和布局，全面助力支撑工作的开展。

此次通过能力成熟度评估是内蒙古移动 IT 实施敏捷、精益转型的里程碑，要感谢内蒙古公司信息技术部为 DevOps 践行和研发运营一体化建设工作辛勤付出的同事，同时也感谢各方合作伙伴及单位的大力支持。


Q：内蒙古移动是如何决定加入 DevOps 标准评估工作中的？

乔栋：2017年内蒙古移动第三代 CRM 系统上线后，支撑业务发展的系统架构有了质的飞跃，与此同时我们发现软件的交付能力出现了瓶颈。所以从那时起我们就逐步的在尝试将持续集成和持续发布在软件交付过程中使用，并取得了一定的成果。这个过程中我们使用了敏捷开发模式、使用单点的工具代替人工操作，但是并没有形成完整的体系和工具链。2019 年底，集团公司提出了建设“企业级智慧中台”的战略，企业级智慧中台通过打造业务中台、数据中台、AI中台、技术中台等平台能力，推动业务组件、技术组件的标准统一；通过打造中台能力运营中心逐步沉淀能力资产，针对不同的业务场景，实现业务的快速交付与生产、管理融智。为实现企业级智慧中台的战略，实现敏捷、高效的IT支撑能力，同时我们也看到了与业界先进水平的差距，研发运营一体化（DevOps）能力成熟度模型为软件工程能力全面对标提供了指引和参考，所以我们决定以ESOP项目作为参评项目。通过对此项目新建完整的工具链、完成 DevOps 体系和文化建设，完成在此项目中的工程实践，并将此工程实践在组织级进行推广。


Q：通过 DevOps 标准评估对企业带来了什么帮助？对团队有哪些影响？
乔栋：此次通过 DevOps 持续交付标准 3 级评估对于内蒙古移动意义重大，包括以下三个方面：
首先， DevOps 标准评估助力内蒙古移动 DevOps 研发运营一体化体系的优化。内蒙古移动自 2017 年开始，结合运营商研发运维现状，逐步建立了自身特色的 DevOps 体系，但是并不完整和健全。DevOps 标准评估实现了软件交付生命周期的全覆盖，在深度和广度上具有参考和指导意义，可以帮助我们了解 DevOps 能力现状,并推进 DevOps 转型在企业的落地。
其次，对于组织来说在体系建立、平台构建、文化建设、试点项目几个方面均取得了优异的成绩。体系方面建立了DevOps持续交付的流程及规范，单项目级的双模研发管理流程、规范及角色，组织级度量指标集。平台方面建立了敏捷开发体系和度量平台，建立多条构建、部署流水线以及分层分级的自动化测试模式。文化方面针对内蒙古移动的双模研发文化建设，交付流程、规范固化辅以培训支撑DevOps文化落地。试点项目高效高质量完成，完美支撑业务发展需求。
最后，对于公司来说顺利通过能力成熟度模型评估，加入了“企业级 DevOps 赋能（共促）计划”，可以获得更多和优秀企业交流学习的机会，为提升软件工程能力，提升组织效率与质量，让 IT 更好地支撑业务快速发展奠定基础。在项目实施过程中，通过自查了解了企业 DevOps 自身发展情况，发现问题，查漏补缺，明确未来持续优化的方向；公司选派了 6 位核心人员参与了 DevOps 相关考试，并全部通过，为企业后续在公司级推广 DevOps 储备了充足的人才。

Q：团队项目通过本次评估有哪些数据指标可以直观的体现项目改进成果？

乔栋：通过此次 DevOps 持续交付标准 3 级评估，团队在持续交付七个能力子域均获得了显著提升，业务上线周期缩短，能够更快的、高质量的响应业务的变化和需求。如下图所示，可以详细看到参与评估带来的改进：需求交付周期缩短25%；版本交付周期缩短 50%；集成效率提升 300%；集成时间由之前的 2 小时下降到 30 分钟以内；自动化测试覆盖率提升到 95%，同时自动化测试效率提升 50% 左右；上线发布频次，具备按需发布的能力。


Q：对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？

乔栋：我省旧版本 ESOP 系统的活跃量极低，系统的版本老旧，客户操作体验差，已经无法满足政企业务综合运营的支撑需求。相对先进省份，我省 ESOP 业务系统建设落后 3-4 年。基于此我们确定了新建 ESOP 项目的计划，并从以下四个维度进行能力提升：

系统架构升级：借助第三代 CRM 架构体系，将原来的独立的 ESOP 系统，升级为三代 CRM 体系，对 ESOP 功能进行收敛，统一对外提供服务。

客户体验提升：升级 ESOP 门户为互联网风格的政企运营门户，能支持根据不同角色岗位职责定制化页面布局和操作方式，突出展现工作关注重点内容，可明显改善和提升用户的操作体验。

门户整合：整合为政企业务的一站式综合运营门户，政企的管理人员、运营人员、客户经理登录后都能支撑工作开展。新增嵌套集团一级系统、本省CRM系统、经分、考试培训等系统。

多种方式接入：系统提供了互联网访问、OA 登陆、4A 登录等多种接入方式，满足了不同使用场景的访问需求。


Q：团队参与评估的过程还顺利吗？遇到哪些困难？如何解决的？

乔栋：虽然我省从 2017 年开始就在探索和尝试 DevOps 在系统中应用，但是真正按照能力成熟度模型进行自我评估后我们仅获得 1.7 级的成绩，这个结果在项目初期就给了我们很大的触动。也正是这个结果激发了项目团队的斗志，让我们确立了更加明确的目标。整个过程中我们遇到了非常多的困难和挑战，但我们结合自身的努力和专家的建议，最后均一一克服，取得了最终的胜利成果。以下几点是过级中解决问题的一些经验：

 

梳理分析

工具链及平台

  • 充分的梳理和分析，确定适合流程；

  • 对成熟度模型进行分析解读，确保准确的理解；

  • 按照要求梳理文档类型、编写要求、详细程度、更新制度、一致性检查、管理权限、目录结构、存储方式等；

  • 各流程环节的输入信息、输出信息以及明确的要求；

  • 分析制定一份合理的计划；

  • 选择一个适当的参评项目；

  • 选择适合的工具链及技术栈，一定是可长期相对稳定使用的；

  • 确保工具链各环节集成环境的打通，并有稳定的运行环境；

  • 选择并建立流水线，以及流水线维护的策略和对应各环节的门禁指标；

  • 平台正常使用的保障（备份、高可用、恢复演练）；


规则及改进

团队及其他

  • 制定合理的指标和管理要求，并严格的执行；
  • 平台各项功能不打折扣的使用，并通过度量进行持续的改进；
  • 对差分和改进验收中提到的问题进行充分有效的沟通讨论，确定原则后完整准确的进行整改；
  • 迭代改进计划务必按照要求进行；
  • 各项改进操作留痕；
  • 明确团队中每个成员的工作职责，并确保其尽量稳定；
  • 持续不断鼓励团队成员进行交流、分享、培训；
  • 建立充分信任的工作环境；
  • 敏捷能带来的收益取决于对工作流程和仪式的保留和裁剪，慎重进行；
  • 一个合格的环境管理员是必不可少的；
  • 制定明确的除过级以外的其他目标，并在过程中落实；

 


Q：对于内蒙古移动 DevOps 的实施，团队最大的收获是什么？下一步计划有哪些？
乔栋：DevOps 项目的实施对于我来说收获是方方面面的，自身对 DevOps 得理解更加全面、广泛和充分了；收获了一个战斗力极强的工程实践团队；收获了顺利评估过级的结果......但是最重要的一份收获是试点 ESOP 项目顺利完成，并按时高质量的投入到生产运营中，完美支撑了业务发展。
2020 年项目初期我们就制定了关于 DevOps 的三年工作规划，2020 年已经顺利完成了“筑基、评级”的工作计划。2021 年我们将按照计划实现“深入、贯通”的目标，实现需求提出到发布全流程支撑试点推广，面向多中心多项目协同管理，实现项目 DevOps 体系推广。2022 年我们将持续发力，实现“成熟、生态”的工作目标，届时 DevOps 将面向内蒙古移动所有项目，全面推广使用；同时项目全面应用 DevOps 体系，实现开发运维一体化管理应用。

Q： 对于 DevOps 的发展前景，有哪些看法？

乔栋：DevOps 目标是实现持续、快速、高效、高质量的业务价值交付，同时也重视组织文化建设，通过自动化、精益、反馈和分享等方面的提升，结合理论、实践、工具打造高效能团队，这是效率驱动创新的关键路径，因此选择 DevOps 将会是众多企业的共识。

在数智化、互联网化转型的大趋势下，运营商需要具备越来越快的 IT 交付能力和稳定高效的 IT 服务支撑能力，未来仍需要通过深化 DevOps 实践，进一步修炼内功，获得技术革新和组织效能的提升，从而赋能创新。另一方面，近年来国家对信息安全管理的规范愈加严格，作为通信运营商，在持续交付的同时还需要考虑将 IT 安全防护融入应用到整个生命周期中 ，因此 DevSecOps 也必将成为 DevOps 演进的未来趋势。

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，由中国信息通信研究院主导的DevOps标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。
与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
