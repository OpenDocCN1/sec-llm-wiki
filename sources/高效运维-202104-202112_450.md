# GitLab发布报告：高达60％受访者发布程式码速度是过去的2倍

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651698890&idx=5&sn=b8593101ac957891826d9e4ed9651ffa&chksm=8bcb7563bcbcfc75c608b5f99faf757a7fdea936aa49866b7e3f9fab42d46bf989380dd3bfc4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651698890&idx=5&sn=b8593101ac957891826d9e4ed9651ffa&chksm=8bcb7563bcbcfc75c608b5f99faf757a7fdea936aa49866b7e3f9fab42d46bf989380dd3bfc4&scene=27#wechat_redirect)

![](../Images/c2e2259852da561246cb710dae69adcb.png)GitLab 调查全球 DevOps 团队并发布《2021年全球DevSecOps调查》报告，调查发现在疫情的驱使下人们发展出新的工作方式，促使过去一年 DevOps 的成熟度有了超出预期的成长，无论是自动化程度、发布节奏、持续部署和安全性状态（Security Posture），或是人工智慧和机器学习等先进技术，都有大幅进步。首先，开发人员的程式码发布速度更快了，由于得利于 DevOps，有 60％ 的开发人员发布程式码的速度是过去的2倍速，比 2020 年增长了 25％。在自动化方面，56％ 的营运团队表示组织已经「完全」或是「大部分」自动化，比2020 年成长 10％。在安全性上也有长足的进步，在2021年，有 72％ 的安全专业人员评估自己的组织安全等级为「好」或是「强健」，比2020年增长14％。现在也有 75％ 的团队，在「使用」或是「计划使用」人工智慧和机器学习来测试和审查程式码，而在2020年时，这个比例只有 34％。在去年，无论是开发者、安全人员还是营运人员，都表示自己的职业需要更好的沟通和协作技能，但这些目标在过去一年受环境影响，经半强迫性的训练之后，DevOps相关人员已经把职业技能目标转移到人工智慧和机器学习、主题专业知识和进阶程式开发上。从调查我们看出 DevOps 角色的不断变化，与开发人员有关的通常是测试和营运任务，而营运的重点通常在云端和基础设施，而安全性则是跨功能团队的一部分。GitLab 提到，DevOps 不断变化发展并不奇怪，在今年的调查中，发现有 43％ 的受访者，已经从事 3 到 5 年的 DevOps 工作，并且继续投入在 SCM、CI/CD和自动化测试等 DevOps 实践中。DevOps 团队仍在追求更好的实践方向，主要目标是要提升程式码品质、上市时间以及安全性等方面。GitLab 表示，测试仍然是 DevOps 重要的问题，测试常是发布延迟的最大原因。今年有也很大改善，拥有完全自动化测试的团队比去年增长2倍。随着 DevOps 在全世界范围内被采用，对相关人才的需求量也在逐渐增多。相比于去年，受访者将发展重点放在自动化、CI/CD和整体DevOps基础工作上不同，在今年受访者表示将把投资主力放在云端上，其次是人工智慧等方面。而 DevOps 工程师也将面临更多的技术挑战。目前美国最流行的，同时也是全球范围持证人数最多的 DevOps 认证 ——DevOps Foundation®，具有全球国际认可度的权威中立认证，能够快速帮助你了解：  

*   DevOps的目标及词汇
*   对业务和IT的收益
*   相关的原则及实践，包括：持续集成、持续交付、测试、安全和三步工作法
*   DevOps与敏捷、精益和 ITSM的关系
*   改善的工作流、沟通和反馈循环
*   自动化相关实践，包括部署流水线和 DevOps 工具链
*   重要成功因素和关键效能指标
*   现实中 DevOps 实践案例和结果

  

**5月20日，在第十六届 GOPS 2020 全球运维大会深圳站前夕，**DevOps Foundation 课程可以帮助初学者明确目标和职责，**课程适用于希望能够掌握最新 DevOps 发展动态的所有专业人员，**在 DevOps 团队中工作的任何人员，或正考虑转向 DevOps 的企业及该企业内的人员等。本课程主要探索 DevOps 的精髓，学习 DevOps 核心原则和实践，清晰业务和技术框架，掌握自动化及构建 DevOps工具链、度量、指标和报告等等。![](../Images/c9f0665cb245e4411c2a5ef94223bea1.png)

  

DevOps Foundation®是 DevOps Institute独立认证的课程。本课程及其相关考试的目的是传授、测试和验证DevOps 的基本词汇、主旨和实践知识。词汇术语表、概念和实践都包含在课程学习手册中。DevOps Foundation课程旨在培养个人对 DevOps Foundation概念的理解以及 DevOps 如何用于提升软件开发人员和 IT 运维人员之间沟通、合作和集成的效率。

  

课程包含来自DevOps institute最新思想、原则和实践，包含对高效能组织真实案例的剖析，如ING Bank, Ticketmaster, Capital One, Alaska Air, Target, Fannie Mae, Societe Generale, and Disney。吸引并激励学员,利用多媒体和互动实践,将学习经验运用于实践。内容还包含对《凤凰项目》作者 Gene Kim 在书中强调的三步工作法以及《DevOps现状报告》中最新成果的重点讲解。

  

通过学习学员将深入理解 DevOps 的精髓，强调沟通、协作、集成和自动化，进一步帮助改善软件开发人员和IT运维人员之间的工作流。

  

本课程针对广泛技术从业者设计，使业务侧人员理解 Kubernetes 和容器，使技术侧人员理解 DevOps 的商业价值，例如降低成本(整体IT成本降低15-25%)并提高质量(变更失败率降低50-70%)及敏捷性(供应和部署时间减少高达90%)来支撑商业目标并支持数字化转型方案。

  

本认证由国际知名认证机构DevOps Institute认证，目前全球持证人数超过8000人，是全球范围内DevOps领域持证人数最多的认证课程，该认证在全球范围认可，目前是美国最流行的DevOps 认证。课程中设置了独特的练习，并提供范本文件、模板、工具和技术，以供课后使用。通过学习本门课程，进一步支持组织工作，在减少成本的同时提高敏捷性，质量和用户服务；利用案例研究，真实的成功案例，以及度量指标去证明此基础级课程中的商业成功,以支持数字化转型。
