## **中国公有云 IaaS 格局已变：华为市场份额增加 2.9%，位居第二位；腾讯下滑0.9%，跌至第三位；阿里下滑2.1%**

IDC最新发布的《中国公有云服务市场（2020第四季度）跟踪》报告显示：2020年第四季度中国IaaS市场规模为34.9亿美元（约226.3亿人民币）。                2020年中国IaaS市场规模达到119.3亿美元（约774.26亿人民币），同比增长53.7%。

## **报告：Python开发者达 1010 万，位居第二**

研究公司 SlashData 最新发布的”State of the Developer Nation“第 20 版报告指出，全球开发者社区在过去六个月中的经历了巨大的增长。据估计，截至 2021 年第一季度，全球共有 2430 万开发者；相较 2020 年 10 月的 2130 万增加了约 14%。其中，Python 以 1010 万的社区规模位居第二，是开发者人数增长最多的语言，增长率为 20%。报告指出，数据科学和机器学习（ML）的兴起是推动 Python 流行的一个重要因素，有接近 70% 的 ML 开发者和数据科学家报告在使用 Python。        ![](../Images/107ff49f59c3e71e54c5a32dc47de583.png)

## **华为一则面试题目登上热搜**

近日，华为公司的一道面试题目刷屏网络。4 月 28 日，该话题登上知乎热搜榜第二。试题内容为：一头牛重 800 千克，但前面一座桥承重 700 千克，问牛怎么过桥？       ![](../Images/4f0382e1faff5b7864998a4e555687c5.png)         题目低栏标注时间是 2021 年 4 月 14 日。面试试题曝光后，很多网友脑洞大开，比如：“把牛卖掉，然后买华为手机，华为手机就牛”。

## **Linux 内核维护人员 Greg Kroah-Hartman 拒绝明尼苏达大学教授的道歉**

明尼苏达大学助理教授 Kangjie Lu 及其博士生 Qiushi Wu 未经许可将 Linux 内核维护者作为研究对象的安全研究引发了争议，最终导致内核社区拒绝接受来自明尼苏达大学的所有代码。上周六，Kangjie Lu 等三人发表了公开信，向 Linux 社区公开道歉。但稳定版内核维护者 Greg Kroah-Hartman 拒绝了这一道歉，他表示 Linux 基金会和基金会的技术咨询委员会已经在上周五致函明尼苏达大学，概述了需要采取的具体行动，以让 Lu 的研究小组和大学重新获得内核社区的信任。在采取行动前，内核社区不会在这一问题继续展开进一步的讨论。

## **Linux Kernel 5.12 稳定版发布**

Linus 在版本发布邮件提到：“非常感谢大家的耐心等待，使我在最终发布 5.12 版本的时候感到非常高兴”。他还表示 5.12 是一个相对较小的版本，下一个版本 5.13 将会相当庞大。Linux 5.12 的新特性和变化包括：移除了大量过时的 32 位 Arm 子架构，BPF 原子操作指令，有条件文件查找 LOOKUP\_CACHED，Btrfs 文件系统支持分区块设备，内核线程 NAPI 轮询，文件系统 ID 映射，支持 Clang 链时优化构建内核，内核调试工具 KFENCE 等等。

## **GitHub 宣布禁用 Google FLoC 功能**  

GitHub 宣布在所有 GitHub Pages 网站上推出一个新的 HTTP 标头，使用户能够从他们的 GitHub 仓库中直接创建网站。实际上，GitHub 网站返回的这个标头，是为了让网站所有者选择不接受谷歌 FLoC 追踪。       ![](../Images/94663acef0a5462cd17481248e685014.png)

## **被曝私自采集用户数据 创维电视与勾正数据相继回应**

日前有网友指称创维电视在后台暗藏应用以收集家庭隐私数据。据该网友称，一开始他只是觉得自家电视卡顿，于是检查了电视的后台服务程序。最后发现，自家创维电视有个“勾正数据服务”的应用正在“监视”他家中所有联网设备。据《每日经济新闻》记者了解到，“勾正数据服务”是一家致力于家庭数据智能营销的第三方大数据公司。对此，4月27日，创维电视在其官网发布声明称：“公司已于第一时间全面禁用了所有创维电视上的“勾正服务”，并展开相关调查。勾正数据与创维旗下酷开网络科技股份有限公司有业务合作。其合作内容仅限于以抽样调查国内收视情况为目的的必要的数据采集。其他任何超出此范围的行为，均未得到创维电视的许可及授权。“
