# 燃！海发宝诚（原中远海运租赁）通过 DevOps 持续交付标准 3 级评估，相关能力达到国内领先水平

国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力，助力企业数字化转型。

2022年7月28日，中国信息通信研究院隆重发布了 DevOps 标准持续交付最新批次评估结果。

海发宝诚融资租赁有限公司（原中远海运租赁有限公司，以下简称海发宝诚）本次参评的项目为该公司研发的**鲸元宝管理平台**项目，本项目顺利通过由中国信息通信研究院开展的《研发运营一体化（ DevOps ）能力成熟度模型》**持续交付 3 级评估，**代表着海发宝诚的 DevOps 能力达到国内领先水平。**评估单位：中国信息通信研究院**

**中国信息通信研究院云计算与大数据研究所所长何宝宏先生公布评估结果：**

![](../Images/8bb5eda2c104d6e5df80aa1e52c0a6a5.png)

▲  DevOps 评估结果公布现场

  
  
此次，我们采访了海发宝诚信息科技部负责人付有略先生、信息科技部部门助理罗霆先生和信息科技部架构组负责人危绍林先生，一同深聊团队在项目参与评估时的细节和故事，分享海发宝诚 DevOps 实践的经验。

  

### **\-Q&A-**

### ![](../Images/aef23d31ceb6064228a5af7d31ed7f06.png)

海发宝诚

信息科技部负责人 付有略

  

**Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。**  

**付有略**：以公司信息科技部人才为依托，海发宝诚成立了朗沃格科技公司，它是海发宝诚下属的全资科技子公司。朗沃格科技公司拥有市场前沿的人工智能技术，汇聚行业内优秀金融科技人才，自主研发构建了敏捷、高效的管理体系和工具。在市场向小微业务下沉的背景下，公司从场景金融、中台运营、智慧办公和基础技术等领域持续发力，积淀金融科技核心能力，用金融科技赋能产业上下游，助力母公司数字化转型。本次参评项目是创新业务线中的“鲸元宝”项目。本项目服务于保险场景下的供应链金融业务，具有流量大、单均小的特点，对时效、操作体验要求高。此外，本项目迭代周期短，智能化、自动化程度高，对研发质量管控和运维体系协同提出非常高的要求。“鲸元宝”项目紧抓业务特色，通过DevOps实践，构建研发运维一体化工具，打通研发与运维的边界，为项目目标达成奠定了坚实的基础。

  

**Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是持续交付3级，表明达到了国内领先水平，请说一下您此时的感受。**

**付有略：**首先感谢各位专家在评估过程中给予的帮助。本次我司的“鲸元宝”项目能够顺利通过DevOps持续交付标准3级评估，成为了融资租赁行业首个通过评估的项目，要感谢各位专家团队给予的支持。在整个评估过程中各专家密切配合，高效协同，提出很多专业建议，特别是在疫情期间，依旧保持高频的远程协同，为我们通过评估提供了很大的帮助。其次，本项目能够通过 DevOps 标准评估不仅是对我们项目管理体系的认可，也是对我们团队转型升级的认同。经过本次评估洗礼，我们整个团队能力都有了质的提升，相关管理理念、工具已被广泛用于公司多个小微、创新业务研发领域，成为助力公司数字化转型的强大推动力。  
**Q：贵公司是如何决定加入 DevOps 标准评估工作中的？**  

******付有略******：面对快速多变的市场环境及持续下沉的客群，如何给客户带来更好的服务体验？如何为公司构筑差异化的竞争优势？这是我们持续思考的问题，数字化变得不可或缺，这对于我们IT团队来说，既是机遇也是挑战。我们整个团队群策群力、集思广益，通过专项调研交流，认真学习并积极消化DevOps先进理念，实现工具化赋能，通过工具把人和产品融合成一个有机体。

###   

![](../Images/d8688d7f6e91b0ba0aed045443be6196.png)

海发宝诚信息科技部部门总经理助理 罗霆

  

**Q：通过 DevOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？**

**罗霆：**2021年，国资委下发《关于加快推进国有企业数字化转型工作的通知》，数字化转型被列入国有企业的战略目标。数字化已然成为企业走向成功的核心要素，而要有力推进公司的数字化转型，首先科技团队自身要进行数字化转型，参与DevOps评估从某种意义上来说也是科技团队完成数字化转型的重要组成部分，使得科技团队有机会更多地实践优秀的管理理念和先进科技工具，有效转变过往传统的作业模式，实现持续改进升级，为公司的数字化转型提供源源不断的科技动能。  
**Q：对于 DevOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？ **

**罗霆：**通过今年标杆项目的贯标实施，让我们在思维上发生了转变，也为我们指明了改进方向；总的来说，我们通过实现研发过程可视化，找到研发过程的瓶颈点并不断进行改进，进而提高研发质量，在适当的质量保障下实现研发效率的提升；

具体来说，第一，通过工具链的实施，实现研发各个环节数据的沉淀以达到研发过程的可视化；第二，研发端到端沉淀的数据为管理者提供改进的数据依据，首先是找到研发过程中的瓶颈，针对瓶颈点进行分析总结，然后采用具体措施进行改进，并在工具链沉淀的数据上得到及时的反馈，以达到持续改进的目的；第三，通过开展端到端的质量内建等工作，提高研发项目的质量，以提升用户的满意度；第四，在一定的质量要求下，想方设法提升研发效率。

通过这一系列的举措迈出我司研发部门的数字化转型最关键的一步，构建起数字化治理的研发团队；目前我司研发团队正处于快速增长期，本次标杆项目通过评审后，下步计划将进一步推广到其他研发项目中进行复制应用，实现各项目研发过程的可视化。

另外，我们也将以评估项目为标杆，以工具链平台作为抓手，以度量平台指标为指引，持续让研发部门其他项目往DevOps持续交付三级靠近。

  

**Q：对于 DevOps 的发展前景，您怎么看？****罗霆：**毫无疑问，DevOps已形成一种趋势，据了解，我们公司应该是行业内第一家落地DevOps评估的企业，而可以预见的是，DevOps将出现在更多的行业领域。在当前瞬息万变、信息量巨大的时代，业务的灵活与高效是各企业不懈追求的目标，而DevOps可以给企业带来这种优势。在实践过程中，我们越来越感受到系统架构、持续交付和数字化能力的紧密关联。近年来，微服务等架构技术的快速发展，如果能与DevOps实践有效结合，将更快地促进DevOps的发展，赋能企业的数字化转型，提升企业核心竞争力。

**Q：您可否详细的介绍一下，通过本次评估有哪些数据指标可以直观的体现项目改进成果？（需求耗费时长、持续集成响应时间、项目过程缺陷密度、编译构建时长、投产频率等）**

**危绍林：**本次评估项目经过能力项持续改进磨练后，在DevOps标准7个域49个能力子域上均得到提升，较为直观提升的指标项有：自动构建成功率达到90%以上，自动化接口通过率达到100%，流水线前端项目构建时长只需5.6分钟等等，这些极大提升了研发协同效率；另外我们的单元测试覆盖率达到86%以上的行业优先水平，技术债保持在0.25小时以下等，这些为提高代码质量保驾护航。

![](../Images/73701ad4b2a78b49e6700cd063a6fb06.png)

  

**Q：对于此次参评的项目，其IT系统有哪些特色，当时是怎么规划和设计的？**

**危绍林：**本次参评项目主要针对公司供应链金融业务的保险场景研发设计的，主要面向广大保险代理企业，解决客户集中管理多渠道保单信息的问题，满足客户基于业务规模弹性扩张诉求和成本最小化而产生的“短频快”的融资需求。我们的“鲸元宝”项目能够通过在线导入债项、发起融资、审批、放款、清分等功能，大幅度提高客户协同效率、降低小微企业融资成本。

  

**Q：此次通过评估的过程顺利吗？遇到什么困难？如何解决的？****危绍林：**项目总体推进较为顺利，过程中也遇到过不少困难，但团队充分发挥了自身主观能动性，众志成城、攻坚克难，最终顺利通过评估。

主要困难是对标准的不熟悉和工具链能力的不完整。项目启动后项目组里五个职能团队对持续交付三级标准都不了解，使用的工具链也十分简陋。面对各种困难首先我们是按照标准里7个能力域49个能力项逐项与现有研发现状进行对比分析，整理出差距项有120多项；其次我们将这些差距项分类，责任到各个负责改进小组长后，编排出第一次迭代改进计划，并且每周特定一天进行改进验收找出差距同时制定出下周迭代计划；最后我们在两个月时间里，通过团队内彼此充分沟通协作完成里第一次改进目标，使持续交付能力达到了2.0分的水平。在接下来的第二次改进和最后冲刺阶段，我们采用同样战术，使第二次改进完成后持续交付能力达到2.6分的水平，最后阶段整体水平已突破了3.0，值得一提的是我们有五项能力已改进到持续4级标准，如：单一数据源、环境依赖与配置管理等。整个过程中大家相互鼓劲、协同并进，在相互磨合中，成就彼此，成为“最佳拍档”，最后顺利完成贯标并通过了三级评估。

《研发运营一体化（ DevOps ）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（ DevOps ）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
