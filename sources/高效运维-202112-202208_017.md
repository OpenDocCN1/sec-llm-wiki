# 携手前行！2022 企业级 DevOps 赋能（共促）计划最新一批成员单位公布

2022年7月28日，由中国信息通信研究院主办的“**2022 首届XOps产业生态峰会**”在北京成功召开。本次大会以“智效赋能·价值引领，共筑XOps新蓝图”为主题，旨在提高企业研发运营能力水平，加强XOps体系建设经验交流分享。

本次大会上还发布了由云计算开源产业联盟、开放运维联盟发起的最新一批企业级 DevOps 赋能（共促）计划合作单位名单。

**中国信息通信研究院云计算与大数据研究所副所长魏凯先生公布了企业级DevOps赋能（共促）计划最新一批合作单位**

![](../Images/a495b4c2ebb703261e7018be25a4e84f.png)

**此次加入企业级 DevOps 赋能（共促）计划的企业，分别是：**

*   交通银行股份有限公司
*   浙商银行股份有限公司
*   宁波银行股份有限公司
*   盛银消费金融有限公司
*   新奥新智科技有限公司
*   南京荣耀软件技术有限公司
*   中国银河证券股份有限公司
