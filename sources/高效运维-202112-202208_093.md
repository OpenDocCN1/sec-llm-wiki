# 如何在研发数据中“掘金”？腾讯专家教你洞见数据价值 | 活动通知

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651718198&idx=3&sn=c63968294f3d3d121157d2ab6d740936&chksm=8bc8c19fbcbf4889db33f2b620ade853601babee61c4f330b3adcba58992f809729f65cbae4b&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651718198&idx=3&sn=c63968294f3d3d121157d2ab6d740936&chksm=8bc8c19fbcbf4889db33f2b620ade853601babee61c4f330b3adcba58992f809729f65cbae4b&scene=27#wechat_redirect)

![](../Images/c2e2259852da561246cb710dae69adcb.png)近几年，**研发效能**成为行业热词。尤其是面对疫情和全球经济萎缩的前提下，各互联网大厂、传统行业IT部门和追求高效的团队都在对如何提升研发效能进行积极探索。要提升研发效能，必须在研发流程中找到关键性的数据指标。高效率收集有价值的数据信息，洞察和智能化分析研发数据，在研发数据中“掘金”，能够帮助团队快速发现研发过程中存在的问题，提高团队研发效能。

  

  
  

在**2022年 DevOps 国际峰会·北京站**上，腾讯 PCG 数据觉察与决策副总监张阳，将带大家深入了解腾讯在研发效能数据洞察与分析过程中的尝试以及建设成果。

**张阳**

腾讯 PCG 数据觉察与决策副总监

  

**个人简介**  
  
资深互联网从业者，曾就职多家国内外知名通信公司和国内知名互联网公司，涉足领域包括内核开发、系统架构、高并发处理了、APM、大数据、研发效能等。加入腾讯后负责内容与平台事业群工程效能部研发数据洞察分析平台的建设工作。
