 IPv6 有可能比 IPv4 速度更快？

IPv6 的普及度在加快，有人可能会产生疑问，用 IPv6 是不是速度更快点？PanSift 在30天内收集了 IPv6 和 IPv4 网络数据，发现在 39.18% 的时间里 IPv6 更快，31.45% 的时间里 IPv4 更快，其余打平。

这一结果很难解释，作者猜测可能是网关处理 ICMPv6 和 ICMPv4 流量的方式导致的。IPv6 的协议栈比 IPv4 的更简单，固定包报头更简单解析更快，ICMPv6 包含了路由器和邻居发现协议，路由器通常不会在传输过程中对大数据包进行分片。
IT 行业的高校毕业生薪酬最高
麦可思研究院发布的《2022 年中国大学生就业报告》显示，IT 业持续领跑高校毕业生薪酬榜，2021 届毕业生选择在长三角、珠三角就业者薪资较高。就业报告数据显示，2021 届应届毕业生在信息传输/软件和信息技术服务业就业月收入持续较高（2021 届本科 6781 元人民币，高职 5023 元），但 2021 届毕业生起薪涨幅（本科 5%，高职 4%）低于全国平均（本科 7%，高职 6%）。

报告显示，2021 届毕业生月收入较高的主要专业前 10 位大都与 IT 行业有关，包括信息安全、软件工程、信息工程、计算机科学与技术、网络工程、物联网工程、电子科学与技术等。除直接就业外，报告指出，应届本科生读研比例持续上升。2021 届本科毕业生国内外读研比例为 19.2%。2021 届本科毕业生国内读研比例为 17.2%，较 2019 届（15.2%）的增幅为 13%。(Solidot）

乌克兰将国家重要数据迁移至北约邻国
受俄乌战事影响，乌克兰政府官员已经开始将敏感数据存储在国外上，希望能免受俄罗斯的网络和物理攻击。
乌克兰数字化转型副部长 George Dubinskiy 表示，自俄乌战争爆发以来，已有不同政府部门和办公室的约150个登记数据库或备份副本，正在商议或已被迁往国外。
Dubinskiy称，之前政府的大部分信息记录都保存在国内的数据中心，需要先迁移至云端，然后才能传输备份副本。为此，政府决定优先考虑将重要的数据库从旧的遗留数据存储系统中迁出，为其创建副本，以便存储到国外的云设施当中。
同时副部长还表示，部分数据已成功迁至波兰，迁移是一项长期昂贵的工程。
百度打算70亿美元卖掉爱奇艺，官方紧急回应
近日，据国外媒体爆料，百度公司正在洽淡出售所持网络视频播放平台爱奇艺53%的股份，拥有超过90%的投票权，百度洽谈出售53%的股份，也意味着出售全部所持有股份。

爱奇艺在通过电子邮件发给路透社的声明中表示：“这纯粹是市场谣言”，但未给出进一步评论。
魅族回应被吉利收购：已签署协议，交易细节还在协商中
6月13日下午，国家市场监督管理总局发布湖北星纪时代科技有限公司收购珠海市魅族科技有限公司股权案案件公示。根据公示信息，星纪时代已与魅族科技以及涉及交易的股东签署协议，星纪时代拟收购珠海魅族79.09%的股权。对此，魅族相关人士回应称：近期，由李书福先生领衔投资的星纪时代已和魅族科技就战略投资事宜签署协议，本次交易尚需履行相关监管机构的审批手续，交易细节还在协商中。（新浪科技）

 27岁高龄IE浏览器正式退役，微软将永久禁用且移出其图标

陪伴许多人进入互联网世界的IE浏览器终于要退役了。

6月15日，微软宣布停止对 IE（Internet Explorer）的所有支持和更新，为这款服务用户超过27年的浏览器画上句号。未来将由微软推出的 Edge 浏览器接棒。

同时，微软也发布了新声明对 IE 浏览器的后续情况进行说明，后续 IE 浏览器会被彻底禁用，IE 浏览器图标会被移除、启动IE浏览器时自动重定向到 Microsoft Edge 浏览器。

但 IE 的结局不仅标志着一个时代的结束，也见证了一个行业的启蒙和兴盛。
