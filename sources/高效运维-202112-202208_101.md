**![](../Images/ff6af27d7f1c96f899dced0a9e7d82d7.png) ****IPv6 有可能比 IPv4 速度更快？**  

IPv6 的普及度在加快，有人可能会产生疑问，用 IPv6 是不是速度更快点？PanSift 在30天内收集了 IPv6 和 IPv4 网络数据，发现在 39.18% 的时间里 IPv6 更快，31.45% 的时间里 IPv4 更快，其余打平。

这一结果很难解释，作者猜测可能是网关处理 ICMPv6 和 ICMPv4 流量的方式导致的。IPv6 的协议栈比 IPv4 的更简单，固定包报头更简单解析更快，ICMPv6 包含了路由器和邻居发现协议，路由器通常不会在传输过程中对大数据包进行分片。![](../Images/3932b116745427eef4c2aee3a6082df6.png)**IT 行业的高校毕业生薪酬最高**麦可思研究院发布的《2022 年中国大学生就业报告》显示，IT 业持续领跑高校毕业生薪酬榜，2021 届毕业生选择在长三角、珠三角就业者薪资较高。就业报告数据显示，2021 届应届毕业生在信息传输/软件和信息技术服务业就业月收入持续较高（2021 届本科 6781 元人民币，高职 5023 元），但 2021 届毕业生起薪涨幅（本科 5%，高职 4%）低于全国平均（本科 7%，高职 6%）。

报告显示，2021 届毕业生月收入较高的主要专业前 10 位大都与 IT 行业有关，包括信息安全、软件工程、信息工程、计算机科学与技术、网络工程、物联网工程、电子科学与技术等。除直接就业外，报告指出，应届本科生读研比例持续上升。2021 届本科毕业生国内外读研比例为 19.2%。2021 届本科毕业生国内读研比例为 17.2%，较 2019 届（15.2%）的增幅为 13%。(Solidot）

**![](../Images/71f88864e1890e2ab38529fa7111fdf8.png) ****27岁高龄IE浏览器正式退役，微软将永久禁用且移出其图标**  

陪伴许多人进入互联网世界的IE浏览器终于要退役了。  

6月15日，微软宣布停止对 IE（Internet Explorer）的所有支持和更新，为这款服务用户超过27年的浏览器画上句号。未来将由微软推出的 Edge 浏览器接棒。  

同时，微软也发布了新声明对 IE 浏览器的后续情况进行说明，后续 IE 浏览器会被彻底禁用，IE 浏览器图标会被移除、启动IE浏览器时自动重定向到 Microsoft Edge 浏览器。

但 IE 的结局不仅标志着一个时代的结束，也见证了一个行业的启蒙和兴盛。
