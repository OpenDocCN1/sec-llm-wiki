# 「猪齿鱼」助力汉得信息智能制造集中交付高效协同

**导语**

IT咨询行业面临着人天单价难以提高，而员工待遇和营运成本持续提升的压力，这大大压缩了咨询公司的利润空间，逼迫着咨询公司要想办法提高项目的交付效率，进行业务模式的变革。采用远程集中交付的模式是变革的一种尝试。

  

汉得信息作为国内IT咨询行业的领头羊，率先进行了多年的实践，通过不断的摸索，逐渐开拓出一条远程与现场结合的路线，可以兼顾交付效率提升和交付质量保障。近三年因疫情反复，通过协同管理工具助力企业集中交付的模式得到越来越多的客户认可及IT服务商的青睐。

   

**汉得信息智能智造&猪齿鱼**

咨询业是知识服务型行业，不同于核心资源是设备这样相对固定的制造业，咨询业的核心资源是人，需要每位员工发挥自己的主观能动性进行工作，也需要员工积极思考和不断优化改进，更需要员工之间相互协作配合，这样才能保证整体工作的质量和效率。  

  

集中交付部门的产能对人员的能力与状态高度依赖，具有非常大的不确定性。所以在**作业标准管理**、**工作计划管理、日常任务管理、内外部工作协作、工时管理、工作进度跟进、文档在线管理、软件测试管理、代码合并管理、环境部署管理、异常及风险识别与跟进、数据分析与持续改进**等各个方面都需要有针对性的应对策略。

  

考虑到需要并行管理的人员多（大于50-150人的规模），管理的任务量大（并行活动的任务卡片约1000-3000张以上），传统的软件研发与交付管理方法，已经难以让如此大规模的知识工作者高效协同交付多个项目，难以快速在团队统一目标与节奏。

  

上市公司「汉得信息」就在这样的环境下探索搭建了自己的集中交付模式，而其智能制造事业部的集中交付中心在管理模式与协作工具融合探索方面就相当成功。其一边探索集中交付模式的流程、组织、监控等工作，同时一边探索**使用协作工具-猪齿鱼数智化开发管理平台，进行各项工作的协同管理，大大提高了其协同效率。**

  

为此，汉得信息智能制造事业部基于自身管理需要，深入应用了**「甄知科技」的协同管理产品-猪齿鱼数智化开发管理平台（以下简称为猪齿鱼系统）**，助力其对集中交付内部核心业务进行线上管理，也可以与项目现场进行工作协同，达成开发过程的在线管理，开发进度的在线实时查询，做到对内、对外、对上的信息共享，过程管理的公开透明。

  

具体**猪齿鱼系统**对其管理监控&效率提升主要体现在以下几方面：

  

**作业标准管理**

项目交付需要有关键产出物的输出，为了统一产出物的格式及内容的颗粒度，在猪齿鱼系统中根据产出物类型创建了产出物的模板。

  

如：开发功能设计模版、接口设计模板、测试脚本模版等，后续开发设计直接基于作业模版在线编辑，保证了工作输出的质量。  

![](../Images/d78d1f1616870b3a05f3cbac3d213e98.png)

  

**开发计划管理**

开发经理在线进行开发计划排定，明确开发任务的标准工时预估及大致的起止日期与初步责任人，完成开发计划的初步创建。

  

后续如果有计划调整，在项目对接人与项目现场确认后，由项目对接人在系统直接修改发布。

![](../Images/2bebaf0f0816fe70f103a8347919567c.png)

  

**日常任务管理**

每周由集中交付业务组经理核定下周开发任务。在猪齿鱼系统中将任务卡片下发给具体责任人，同时明确任务卡片的预估工时、起止时间。

  

每日早、晚例会集中交付各业务组分别组织回顾任务进度及遇到的障碍，进行任务调度，如：增减任务、调配人员。

![](../Images/f5678b755c0ef6b410f4d85a8c76f07c.png)

  

**工作结果管理**

集中交付功能顾问经与项目现场方案顾问沟通，明确开发需求。在猪齿鱼系统中按照模版在线编写开发设计文档，测试脚本文档，完成文档编写后，向集中交付开发人员面对面针对在线文档讲解设计思路。

  

如果存在调整修改，直接在文档中通过注释调整，保证文档的一致性、可追溯、及时归档。

![](../Images/d80196a979adadf8da8ed6f46361b437.png)

  

**代码管理**

集中交付开发人员进行本地的代码编写于本地的初步调试后，每日固定两个时间点在猪齿鱼系统中提交代码。

  

由开发经理或指定专人负责进行代码合并（如有需求可以随时申请进行代码合并），集中交付开发经理及时解决代码冲突问题，同时用猪齿鱼系统提供的代码质量扫描工作检查代码不规范、低效率的问题，发现问题及时打回提交人进行纠正，从而保证在猪齿鱼系统归档代码的质量和最新状态。  

![](../Images/51a3c16d415a052e08aff4c4fd250073.png)

  

**软件测试管理**

集中交付测试人员通过猪齿鱼系统中的测试计划功能，将测试脚本转换为测试任务。在开发环境完成单元测试后，在猪齿鱼系统中登记测试结果。

  

如果发现有BUG，登记在具体的测试步骤中，猪齿鱼系统中会同步生成BUG解决任务卡片，由技术经理指派责任人解决。

![](../Images/0d5c3c07a1f8f1fa979ba399aad722cf.png)

  

**工时报工管理**

为便于做详细的数据分析，所有任务卡片启用了工时管理。

  

在集中交付的所有员工，每日下班前在猪齿鱼系统，对自己当日工作的卡片填写作业工时，有了每张任务卡片的工时数据，就可以基于任务类型、所属开发项、所属项目进行分类汇总分析。针对关键性的KPI进行定期和不定期的分析，如：BUG工时率、变更工时率、设计工时率、开发工时率、测试工时率，及时识别出工作过程中的隐性问题。也可以做环比数据的分析，看到整体情况的持续改进情况。  

![](../Images/228cdea6e4664456eeb07d1126ddd7ee.png)

  

**异常及风险管理**

集中交付及现场项目管理人员通过猪齿鱼的甘特图功能，可以按项目、按业务组、按责任人来多视图查看所有开发项目的进展情况。

  

对延期的开发项目有红色线条标识警示，便于及时发现各类资源及推进障碍问题，再通过组织例会及专题会议来推进解决遇到的问题。  

![](../Images/a032efd58c20f2585e9a4e91b2c0b707.png)

  

**代码部署管理**

采用集中交付模式后，多系统的环境管理面临着不同项目、不同用途（开发、测试、UAT、正式）的各个维度的问题，对代码的部署管理提出了更高的挑战。

  

而猪齿鱼系统可提供环境部署功能，并可按环境进行授权管理，将代码部署工作进行流水线标准化，提高部署效率的同时也避免了在部署过程中各种人为不可控问题的发生。 

![](../Images/027c528a75ef34cdc6a0535be6f29855.png)

  

**总结**

正如汉得信息智能制造事业部高级经理霍经理所述：“当前猪齿鱼系统已经成为我们的必备业务管理系统，基于猪齿鱼系统提供的能力，保障了企业在集中交付中团队协作工作顺利运行，提高了团队协作的效率，从而降低了企业人力资源成本。”

  

诚然，为确保猪齿鱼系统的可靠与稳定，使类似于“汉得信息智能制造事业部”深度应用的客户不受系统问题的影响，**「甄知科技」猪齿鱼数智化开发管理平台**一直秉持以为客户提供更优质服务的理念，在产品功能上不断迭代升级持续优化，并且安排专门客户成功经理对接服务等措施，最大程度的保障系统的高可用及不断的优化需求。
