常见问题 Q&A


Q：什么是 SMTX OS 和 CloudTower?


A：SMTX OS 是由 SmartX 研发的超融合软件，其功能涵盖分布式块存储、计算虚拟化和网络服务，以帮助企业快速构建稳定可靠的 IT 基础架构。


CloudTower 是 SmartX 发布的统一管理平台，用以进一步提升数据中心内及跨数据中心的多 SmartX 产品集群统一管理能力。


Q：社区版商业版本有什么区别？


A：SMTX OS 与 CloudTower 社区版将包含商业版的所有基本功能，并且可永久免费使用，其与商业版的主要区别如下：


  • 社区版 SMTX OS 支持 3 节点以内的小规模集群

  • 社区版 CloudTower 最多可管理 3 个集群 

  • 只支持 SmartX 原生虚拟化（ELF）平台 

  • 不支持全闪存存储、分离式部署、Kubernetes CSI 及 Openstack Cinder Driver

  • 不包含双活及备份服务

  •  不包含商业服务


Q：SmartX 社区版的部署环境有哪些？主要区别是什么？


A：你可选择基于裸金属服务器部署，或者利用 OVF 镜像，基于 VMware  ESXi 虚拟机部署（OVF 部署方案），后者仅用于功能体验。


  • 裸金属服务器部署手册

  • VMware ESXi 虚拟机部署手册


Q：如果用裸金属部署，需要几个节点的服务器可以体验社区版？


A：最少只需 1 台 X86 服务器，就可体验社区版大部分功能。如果需要体验全部社区版功能，则至少需 3 个节点的服务器。


Q：我需要多久能够完成社区版的部署？


A：部署时间和您的服务器和部署熟练度有关。一切准备好的情况下，您大概需要 1~4 小时即可完成部署，获得授权码。


Q：我已经部署社区版，且已获得 license，还可以参与活动吗？


A：可以的，您只需要通过活动邮件链接提交授权码即可。


Q：我已经部署社区版，是否可以参与这个活动？


A：可以的，只要您近期部署成功即可以，同时您需要在 SmartX 官网
(https://www.smartx.com/community-license/)
提交序列号，获取授权码并提交至活动表单。


Q：我已经下载过社区版，是否需要重新下载？


A：不需要，您完成后续的部署和授权码提交即可。


Q：如果我在部署过程中碰到问题，怎么办？


A：您可以加入 SmartX 用户社群，与我们的社区技术专家随时交流。


Q：SmartX 用户社群有哪些成员？有哪些价值？


A：SmartX 用户群由超融合专家、渠道和最终用户组成。您在用户群可通过深入了解 SmartX 超融合产品，探索超融合架构，和其他成员一起共同学习成长，获得知识和帮助。


Q ：活动礼品规则是什么？


A：只要您成功提交授权码，即可获得活动证书，前 100 名完成挑战者还将获得定制文化衫与保温杯；其他小伙伴则获得保温杯。


Q：我多久可以收到我的礼品呢？


A：我们会尽快寄给您，如果对礼品有疑问可加社群管理员微信询问。
