 历经 27 载风雨，IE 浏览器正式退役

5月16日，微软宣布 IE 浏览器将于6月16日正式退役，由 Edge 正式接棒，一代传奇就此落下帷幕。

IE 作为 Windows 的第一个默认浏览器而诞生，作为 Windows 95 的默认浏览器，IE 很快就占领市场，并于2003年走上世界巅峰，高峰时期占据全世界 95% 的市场份额。

自2004年后，随着 Chrome、Firefox 相继问世，IE 浏览器的市场占有率开始下滑，尽管 IE 后来不断更新，但都无法力挽狂澜，微软深知IE 已无可能重回巅峰时期，于2015年放弃对 IE 的支持，转而将更大的力度放在 Edge 上。

作为见证互联网发展的探路者，我们一起来重温 IE 各个版本的 logo。看看你最熟悉它的哪个阶段。

20天内开发 APP 后遭解雇，技术负责人怒用公司公号发文

5月16日下午，一科技公司公众号疑遭原技术团队负责人盗号发文并祝公司“早日倒闭”。文章称，公司曾要求技术团队20天内开发出一款 APP，天天通宵加班；后在修复 BUG 的过程中不断施压，还要求一周内完成 im 即时通讯功能。文章最后称，团队被集体解雇。

经过舆论不断发酵，随后该公司连夜发布了声明回应，表示与事实严重不符：

  1. 该文章内容与事实严重不符，严重抹黑公司形象；

  2. 微信公众号文章发布后，已要求公司法务处理相关事宜，并与原技术取得沟通，现已妥善解决该问题；

  3. 因处理该问题需要时间，所以公众号文章未能及时删除，并非公司恶意炒作；

  4. 对各大平台及个人针对该文章进行断章取义的宣传，我公司保留追究其法律责任的权利；

  5. 我司对占用了大家的时间和公共资源表示歉意，请不要恶意转载。

腾讯起诉 vivo 不正当竞争

5月18日消息，济南市中级人民法院开庭公告显示，腾讯起诉vivo网络不正当竞争案将于5月20日开庭。据悉，此轮诉讼是腾讯应用宝诉vivo利用手机底层系统优势，通过插入弹窗、文字、按钮、设置风险检测等方式，限制用户正常下载安装应用宝以及通过应用宝下载安装应用，同时诱导用户到vivo自带的应用商店下载或安装应用，以此获得更多的流量和商业利益。

据悉，法院此前做出了行为保全民事裁定，要求vivo立即停止在vivo手机上以插入弹窗、文字、按钮、设置风险检测等方式，妨碍应用宝应用正常运行以及通过以上方式为vivo应用商店导流的行为。

利好消息，Python 重大提案，废除全局解释器锁
据 Python 基金会博客介绍，开发者 Sam Gross 在 2022 Python 语言峰会上带来了一个新提案：完全移除 CPython 解释器的 GIL - 全局解释器锁，使 Python 程序获得更快的性能 —— 尤其是多线程程序。

作为 Python 核心解释器，其内存管理非线程安全，因此设计了 CPython 的 GIL （Global Interpreter Lock - 全局解释器锁），以防止竞争条件并确保线程安全。

但随着互联网高速发展，GIL 使用并不理想，因为它阻止了多线程的 CPython 程序充分利用多核处理器的性能。但由于 GIL 长期存在，许多官方和非官方 Python 包和模块都深度融合了 GIL 模块，移除 GIL 功能的工作变得任重而道远。此前，开发者 Larry Hastings 在其 “Gilectomy” （GIL 切除手术）项目中试图完成 CPython GIL 功能的移除，但该项目失败了，因为它使单线程 Python 代码显着变慢。

据 Python 基金会的介绍，Gross 将发明一种新型锁，一种 “更吉利” 的锁。如果顺利的话，这个新锁很可能在 Python 3.12 版本亮相，因为 Gross 的提案就是 “在 Python 3.12 中引入一个新的编译器标志，该标志将禁用 GIL。”（开源中国）

微软开放Windows系统以应对云垄断的指控

微软公司总裁布拉德·史密斯周三宣布，微软将修改其许可条款，允许云服务提供商更好地竞争，以回应对手的投诉。

此前，微软已被欧盟反垄断监管机构罚款16亿欧元（约合114亿元）。史密斯称，这些调整包括允许云服务提供商把 Windows 作为完整的桌面操作系统提供给客户，提供长期的价格保护，以及修改许可条款。
俄罗斯表示无意切断与全球互联网的接入
俄罗斯数字发展部长 Maksut Shadaev 周二表示该国不打算封锁 YouTube，因为此举会影响到俄罗斯用户。YouTube 在俄罗斯有九千万月活用户，虽然俄有很多西方流行社交媒体的替代品，但还不存在规模上接近 YouTube 的替代。俄罗斯此前限制了对 Twitter、Facebook 和 Instagram 的访问，曾测试过切断全球互联网接入的试验。Shadaev 否定了俄罗斯可能考虑切断与全球互联网接入的猜测，表示俄罗斯不想与任何人隔离开来，应该继续成为全球网络的一部分。
Gitee仓库开源必须审核，官方回应来了

国内的 GitHub 替代 Gitee 宣布所有开源库将先审再上线，即日生效。Gitee 在周三晚上发表的声明中称：Gitee 即日起执行开源仓库审核后上线的措施，所有新上线的开源仓库需要进行人工审核后可正式公开。

已经是开源状态的仓库，我们会暂时转为私有仓库，经审核后会进行公开，同时我们会加大对于审核的技术投入和人力投入，加快审核进度，努力确保每一名开发者的使用体验。此举也是迫于无奈，目前已经是 Gitee 团队能确保大家尽快正常使用的最优解，我们正在尽全力减少大家的不便，希望大家能够理解。
