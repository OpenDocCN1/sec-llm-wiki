**苹果官宣 iPod 停产，iPod 之父**

承载着一代人记忆的“iPod时代”正式画上句号。本周二，据官方网站消息，苹果宣布将停产iPod。

iPod是苹果在2001年10月首次推出的一款便携式音乐播放器。如今在售的第7代iPod touch是该播放器的最后一个型号，这批库存售罄后，iPod将不再出现在苹果的货架上。

这个小小的“口袋播放器”一经推出就受到了欢迎。苹果曾宣称，iPod可以容纳1000首CD质量的歌曲。当时，人们听音乐的方式是从网络下载音乐再刻录，iPod的出现可以让播放器和iTunes软件进行歌曲的传输，用户因此开始购买数字音乐。 

之后，苹果公司陆续推出iPod mini、iPod nano和iPod shuffle等产品。不过，2014年-2017年期间，苹果陆续停售上述iPod产品。 不过，在2007年iPhone推出之后，iPod的功能被智能手机取代。自2019年推出iPod touch（第七代）以来，iPod touch就再没有更新过。 

苹果公司在官网表示，将继续通过网站销售剩余的iPod touch设备，直到库存售罄。该设备提供了32GB、128GB和256GB的型号，以及包括银色、粉色、蓝色和金色在内的六种颜色。 

**![](../Images/6f94708882aa2553da5f9e476e34d4f5.png) 除了 Python，Go 也能在浏览器上运行了**

Anaconda 开发商最近发布了 ，这是一个可以让开发者在 HTML 中混写 Python 代码的框架，有人将其称为 “Python 版 JSP”。事实上，PyScript 底层采用了 WebAssembly， 因为它基于 Pyodide 构建，Pyodide 由编译成 WebAssembly 的 CPython 3.8 解释器组成，允许在网页浏览器中运行 Python。

无独有偶，开发者采用相同的思路让 Go 也顺利在浏览器上运行。https://goscript.dev 网站支持在浏览器端直接运行 Go 代码，这是一个 Go playground，底层采用 Goscript，通过 WASM 实现。

Goscript 是 Go 语言规范的非官方实现，用于 Rust 项目的内嵌或封装，提供了更简单的方式封装和调用底层的 Rust 代码。就像 Lua 之于 Redis/WoW，或者 Python 之于 NumPy。（开源中国）

![](../Images/df19eb2cc53dd33a6e228ca562790fd5.png) **Luna 币暴跌**

经过连续两日的暴跌，加密货币Luna价格已经跌破2美元，市值也仅剩11亿美元。而UST最低跌破0.21美元，处于与美元严重脱钩状态。据coingecko，Luna曾在4月5日达到119.5美元高点，也达到最高市值410亿美元。

Terra是一种使用Cosmos SDK创建的区块链网络，致力于创建稳定币。Terra 链上最大的算法稳定币是 UST，而LUNA为Terra链的原生PoS质押代币，Luna的价格将直接影响该链的安全性，这也就意味着Luna价格越高，Terra链内可安全承载经济价值将越高。

UST作为算法稳定币，通过一套链上铸币与销毁机制来维持与美元的挂钩。即理论上，这些机制应该确保交易者始终可以将价值 1 美元的 UST 换成价值 1 美元的 LUNA，LUNA 具有浮动价格，旨在作为 UST 价格波动的一种“减震器”。
