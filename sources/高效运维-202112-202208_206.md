![](../Images/fc666b5505b50fabe5df805896e94613.png) **向日葵远程崩了：因用户暴增引发服务超负荷**

2022年5月5日，有微博网友反馈，向日葵远程控制应用奔溃，无法登录。同时，当日“向日葵远程”登上微博热搜。对此，向日葵远程控制官方向用户致歉，称由于大量用户涌入，导致服务器繁忙，目前已在紧急回复中，请将向日葵保持登录状态，恢复后请重试连接即可。  

截至发稿前，向日葵远程控制官方已发布服务器恢复服务公告（含用户补偿方案）。

![](../Images/0ebce480828dc240fb6b40909d740d50.png)

**![](../Images/84a43a380b8bc86ccf9e504d9cad0517.png) 显示 IP 属地功能后，很多人慌了……**最近，依据规定显示 IP 属地功能后，微博、微信公众号、抖音、小红书等各大平台推出 IP 属地功能，很多博主也相继翻车，上演了一出出好戏。  
首先被注意到的是本地生活大V们，包括西安、广州、重庆的吃喝玩乐资讯，这些名字相似、粉丝数量几百万+的大号，他们都显示在一个地方：**湖南**。  

![](../Images/4daab6fd43d5e375d940dc6427c50a7e.png)

而对那些打造定居在海外的人设，主打分享海外日常生活的博主来说，就真的可以算翻车了。

那么，对于 IP属地显示，你支持吗？

**![](../Images/e69809664914b8ad2e0b800c0aca0d3f.png) “跳槽”字节跳动，百度高级经理因违反竞业协议一审被判107万**

日前，北京法院公开原告百度在线网络技术(北京)有限公司(以下简称百度公司)与被告潘xx劳动争议纠纷一案，北京海淀人民法院立案审理后，该案现已审理终结。百度在线公司在2020年4月2日潘xx离职后，按约向其足额支付了6笔税后竞业限制补偿金，潘xx应依约履行竞业限制义务。潘xx于2020年7月27日至8月7日期间多次将车辆停放于字节跳动公司办公区地库，多次在工作日期间出入字节跳动公司，潘xx虽称出入原因为与朋友有约，拜访朋友，但未就此提供证据予以证明。潘xx未对其上述行为作出合理解释，应承担举证不能的不利后果，故本委对百度在线公司所持潘xx存在违反竞业限制义务行为的主张予以采信，潘xx应当依约向百度在线公司支付违反竞业限制义务违约金。

最终法院判决潘xx于本判决生效后十日内返还百度在线网络技术(北京)有限公司竞业限制补偿金214800元；违反竞业限制义务的违约金859200元；继续履行对百度在线网络技术(北京)有限公司的保密义务；驳回百度在线网络技术(北京)有限公司的其他诉讼请求。（雷锋网）

**![](../Images/5aa4848a637361ae68a76c21ce6ad82d.png) 即将迎来5周岁，Google 向 CNCF 捐赠 Istio**  

![](../Images/fd444fb5551e83b7893025d5779120ae.png)4月25日，Google Cloud 官方博客发布公告称，即将迎来5周岁的 Istio 已提交至云原生基金会（CNCF），供其考虑作为一个孵化项目。同一时间，Istio 在官网发出公告，确认了这一消息。  
Istio 是一个开源的服务网格项目，由 Google 联合 IBM 和 Lyft 团队合作开发。  
2020年，Google 曾宣布将 Istio 的商标所有权，移交给一个全新的自建开源组织——Open Usage Commons（OUC），而不是 CNCF，此举立即引发争议。

Istio 官网在公告中表示，项目在捐赠给 CNCF 后，会加深 Istio 与 Kubernetes 的整合，加快 Istio 及其他 CNCF 合作伙伴的反馈、功能和开发周期，最终把首要的云原生堆栈统一在同一保护伞下。

**![](../Images/84a43a380b8bc86ccf9e504d9cad0517.png) K8s 1.24 版发布，dockershim被正式移出**2022年5月4日，Kubernetes 1.24 暨 2022 首个版本正式对外发布，1.24版涉及46项增强功能，其中14项已升级为稳定版，15项进入 beta 阶段，13项刚刚进入 alpha 阶段，此外有2项功能被弃用、2项功能被删除。其中，dockershim 组件终于在 1.24 的 kubelet 中被删除，也就是说，即 1.24 版本开始，使用其他受到支持的运行时选项，如 container 或 CRI-O，如果用 Docker Engine，则需要使用 cri-dockerd。

此外，Kubernetes 1.24 主题为 Stargazer，即观星者。

**![](../Images/a603c879200dfe8c5129d89afdb722df.png) 苹果、谷歌和微软扩大对无密码登陆的支持**

据 Apple Insider 报道，安全机构 FIDO 获得了苹果、谷歌和微软的新支持，科技公司都宣布他们正在扩大对联盟无密码登录标准的支持。继2020年加入 FIDO（FAST Identity Online）联盟后，苹果现已宣布扩大对该组织技术和目标的支持。苹果平台产品营销高级总监Kurt Knight在声明中表示：「正如我们将产品设计得直观且功能强大一样，我们也将它们设计得私密且安全」。到目前为止，苹果已经在 iOS 15.4中引入了对其「万能钥匙」密码技术的初步支持。（CSDN）
