国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让DevOps标准更快更好落地，助力企业数字化转型。


2022年4月26日，中国信息通信研究院隆重发布了 DevOps 标准持续交付第十七批评估结果。
北京市燃气集团有限责任公司（以下简称“北京燃气”）本次参评项目为北京燃气通州呼叫中心建设项目，该项目顺利通过由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付2级评估，相关能力达到国内先进水平。
评估单位：中国信息通信研究院

此次，我们采访了北京燃气信息档案中心主任王广清先生，一同深聊团队在项目参与评估时的细节和故事，分享北京燃气 DevOps 实践的经验。


- Q&A -

北京燃气信息档案中心主任 

王广清先生


Q:您好，请介绍一下您和您的企业，以及此次参与评估的项目。

王广清:大家好，北京燃气集团是中国城市燃气行业内最大的单体城市燃气供应商，管网规模、燃气用户数、年用气量、年销售收入均位列全国前茅，长期以来，北京燃气集团在“立足北京，内外并举；专注能源，上下延伸”的发展战略指引下，实现了上游资源和中游长输管线建设及下游燃气应用领域的全产业链发展。北京燃气集团成立以来，积极参与各项社会公益事业，得到政府和社会的广泛赞誉。先后获得“中国企业500强”、“北京十大影响百姓生活企业”、“全国企业文化建设50强”、“全国五一劳动奖状”、“首都平安示范单位”、“首都文明单位”、“全国模范劳动关系和谐企业”、“百家重诚信单位”等殊荣。


北京燃气智能客服系统以“全域、全业务、全功能、全空间”为导向，建立以客户为中心的服务模式，整合北京燃气集团与客户之间的沟通渠道，打造云化、智能化、业务定制化的数字智能化平台。通过深入推广智能应用及客服自助服务，有效实现话务分流，有效解决北京燃气集团各分、子公司及外埠公司呼叫中心各自为政分散运营、坐席人员异地办公统一管理、多系统接入等问题，实现服务体验均一化，降低服务体系建设成本，提升企业客户服务能力和水平。


Q: 恭喜您通过DevOps 标准评估，此次贵公司项目通过的是持续交付2级，表明达到了国内先进水平，请说一下您此时的感受。

王广清:北京燃气通过本次DevOps 持续交付能力成熟度评估,是对目前北京燃气DevOps 持续交付能力的肯定，是北京燃气研发过程管理的一项重要成果，标志着北京燃气在DevOps研发运营方面上了一个新台阶，为后续 DevOps 在北京燃气的全面推广确定了目标和发展方向，为将来的DevSecOps建设奠定了坚实的基础。


Q:贵公司是如何决定加入 DevOps 标准评估工作中的？

王广清:北京燃气注重新技术、新理念的引入，积极探索科技创新。自2018年开始，加强DevOps研发运营一体化的人员与技术储备，组织DevOps中心级培训与DevOps工程师的培养。2020年着手建设DevOps工具平台，积极实践敏捷交付过程，在实际应用过程中，对标DevOps能力成熟度和行业先进实践，持续完善我们 DevOps 体系建设，寻找不足，努力缩小差距。参加DevOps 标准评估也是为了检验北京燃气目前DevOps水平，明确方向，以进一步提升团队敏捷开发和持续交付能力。


Q:通过 DevOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？

王广清:更好的服务客户、快速响应业务需求一直是我们追求的目标。DevOps研发运营一体化作为重要手段，可以有效促进整个研发运营团队的敏捷化，提高研发运营过程的规范化，完善研发运营指标的可视化，持续推动北京燃气研发运营体系的建设，有效支撑了北京燃气数字化转型工作，提升了IT团队对业务响应能力和项目研发效率。通过DevOps工具平台，打通并整合项目需求管理、开发、测试、部署、运维5个环节的流程链路，实现项目需求管理团队、研发团队、测试团队、运维团队4种角色的线上高效协作，实现DevOps工具平台内、外相关工具的深化以及打通，提高各环节协同性，提升团队能力，有效管理和提升研发进度与交付质量。


Q:您可否详细的介绍一下，通过本次评估有哪些数据指标可以直观的体现项目改进成果？（需求耗费时长、持续集成响应时间、项目过程缺陷密度、编译构建时长、投产频率等）

王广清:试点项目改进成果体现在需求、编译构建时长、发版时长等明显缩短。

Q:对于此次参评的项目，其IT系统有哪些特色，当时是怎么规划和设计的？

王广清:本项目建设的智能客服系统基于云架构、大数据处理、人工智能，突破呼叫中心服务渠道割裂体验差、坐席分散多地管理难、业务受理及处理分散、运营人员成本高等难题，为提供一体化智能服务和多渠道业务发展提供支撑。在项目实施过程中，利用DevOps工具平台，坚持对标 DevOps 研发运营一体化方法论指导研发工作，做好DevOps理念宣贯，持续完善流水线及各项度量指标，保障了系统的交付质量和效率。


Q:此次通过评估的过程顺利吗？遇到什么困难？如何解决的？

王广清:评估过程基本还算顺利，对于我们传统能源行业的公司来说，经历DevOps从无到有的过程，开发及运维团队从不懂DevOps到接受DevOps需要有一个过程。我们在评估过程中，主要有以下两个困难：一是北京燃气的DevOps工具平台由开源软件自主建设，在软件使用过程中，管理与使用不太方便，各软件间对接不灵活，有些度量指标无法实现，使用效果稍显不足。如果想取得更好的效果，需要在平台建设方面继续努力。二是参与DevOps评估的人员少且身兼多职，日常工作多，尤其业务系统故障时，往往身不由己，这对大家是一个挑战，也锻炼大家不断挑战自我，努力提高工作效率和多工作并行场景下的自我管理能力，以便留出更多的时间投入DevOps研发运营一体化相关工作。


Q:对于 DevOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？ 

王广清:通过北京燃气DevOps 的实施与评估，为北京燃气开发运维团队积累了大量的敏捷开发持续交付的宝贵经验，团队技术能力得到了较大的提升，试点项目软件质量和研发效率得到显著提升，能够更快速的进行业务价值交付。后续，我们将结合公司特点，展开以下工作：首先，持续和深入地推广DevOps到更多的项目中去；其次，将进行DevSecOps实施，把安全引入持续交付的全过程，提升相关安全工作的效率；最后，进一步优化DevOps工具平台，提升 DevOps 能力。


Q:对于 DevOps 的发展前景，您怎么看？

王广清:提升研发效能是我们研发部门的一个重要目标，DevOps在企业研发效能提升方面，是一个非常有效的手段，目前越来越多的企业加入DevOps大军，并从DevOps过程中受益，我想，将来会有更多观望的企业试水DevOps。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
