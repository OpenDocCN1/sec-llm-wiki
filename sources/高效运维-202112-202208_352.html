中信建投证券成立于2005年11月2日，是经中国证监会批准设立的全国性大型综合证券公司。公司注册于北京，注册资本76.46亿元，在全国30个省、市、自治区设有295家营业网点，并设有中信建投期货有限公司、中信建投资本管理有限公司、中信建投（国际）金融控股有限公司、中信建投基金管理有限公司和中信建投投资有限公司5家子公司。公司在为政府、企业、机构和个人投资者提供优质专业的金融服务过程中建立了良好的声誉，自2010年起连续十一年被中国证监会评为目前行业最高级别的A类AA级证券公司。
2016年12月9日，中信建投证券在香港联交所上市，股票代码6066.HK；公司A股于2018年6月20日在上交所主板上市，股票代码601066.SH。公司拥有实力强大的股东背景，主要股东有北京国有资本经营管理中心、中央汇金投资有限责任公司与中信证券股份有限公司等，均为拥有雄厚资本实力、成熟资本运作经验与较高社会知名度的大型企业。
成立以来，中信建投证券各项业务快速发展，在企业融资、收购兼并、证券经纪、证券金融、固定收益、资产管理、股票及衍生品交易等领域形成了自身特色和核心业务优势，主要经营指标目前均位居行业前列。

职位详情
证券投资信息系统开发岗：
证券公司自营投资业务是证券公司利用自有资金，买卖境内外交易所上市交易的股票、债券、商品及衍生品，获取投资收益。信息系统涉及投资研究、量化策略、高频交易、另类投资、场外衍生品等具体应用领域。对研发（C/C++、JAVA、FPGA)、测试、产品方面的人才有大量需求。本岗位主要为JAVA 方向的系统研发与管理，参与衍生品、FICC等项目。
职位要求：
1、具备2—5年左右 JAVA 相关项目实践经验；年龄 30 周岁以下，全日制硕士学历（本硕均为双一流），计算机相关专业；
2、JAVA 基础扎实，对多线程、分布式、缓存、消息、搜索等有开发经验；
3、熟练使用 Spring 等应用框架；
4、熟悉 vue 或 react 以及前端技术；
5、熟悉 Linux 常用命令，可部署系统与分析性能；熟悉至少一种数据库 Oracle、MySQL；
6、熟悉面向对象设计方法和设计模式，逻辑能力佳， 熟悉 UML 设计工具；
上班地点：
地址：北京市东城区朝阳门内大街188号

薪资：20-40K・14薪
工作经验：3-5年
学历要求：硕士
奖金绩效

年终可期

职位详情
证券自营投资信息系统产品经理岗：
证券公司自营投资业务是证券公司利用自有资金，买卖境内外交易所上市交易的股票、债券、商品及衍生品，获取投资收益。信息系统涉及投资研究、量化策略、高频交易、另类投资、场外衍生品、境外交易等具体应用领域，对研发（C/C++、JAVA、FPGA）、测试、产品方面的人才有大量需求。本岗位为产品经理岗。
岗位职责：
1、参与系统规划，需求调研和产品定义评估，参与并负责业务需求讨论与设计。
2、负责需求调研工作，获取并管理客户需求，对现有业务流程进行分析改善，编写详细需求说明书。
3、按项目管理规范要求编写相关文档，准确描述和解释业务需求、解决方案，提供给系统设计师和软件工程师。
4、配合测试人员编写测试计划、测试用例和测试报告。参与系统功能验收工作及用户手册、新增产品功能培训资料的编写。
5、基于产品对软件需求进行管理，包括对需求点的跟踪和验证。
6、参与整个产品开发流程，与整个项目团队一起保证最终产品发布。
任职要求：
1、全日制硕士学历（本硕均为双一流），年龄30周岁左右，具有3年以上金融行业或金融科技行业工作经验。
2、熟悉软件工程的理论，掌握软件需求获取与分析方法。善于把握需求要点和重点。
3、具有良好的团队协作精神，有较强的业务模型分析能力，思维清晰敏捷，逻辑分析能力强。
4、善于与人沟通，有一定的客户沟通经验，善于控制需求，进行范围管理。
5、有较强的文档编写能力，熟练使用 MindManager 、AxureRP、墨刀等产品设计工具。
6、能熟练使用 Microsoft office 软件以及 Visio。熟悉 UML 建模工具，如 Rational Rose、EA 等优先考虑。
7、有交互设计及用户体验优化经验。
上班地点：
地址：北京市东城区朝阳门内大街188号

1、全日制硕士（本科为一本院校），计算机、软件工程或相关专业，5年以上测试经验，学历未到者勿扰。

3、熟悉自动化测试，可用 Python 实现相关自动化测试。
4、至少会一种数据库操作，比如 MySQL；熟悉基本的 SQL 优化知识；
5、有较丰富的性能测试经验；
6、熟悉 Linux 基本操作；

地址：北京市东城区朝阳门内大街188号
