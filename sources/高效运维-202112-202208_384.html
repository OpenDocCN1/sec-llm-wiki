# 导读 #

当前，算法、模型正日益广泛地应用在金融、信息推荐、电子商务、智能诊疗、企业服务等商业和公共领域，成为推动企业数字化转型和国家治理能力现代化的重要力量。国内外对于算法治理的关注日益提升。我国陆续出台的《个人信息保护法》、《关于加强互联网信息服务算法综合治理的指导意见》、《互联网信息服务算法推荐管理规定》、《关于银行业保险业数字化转型的指导意见》等法律法规中均对算法、模型应用过程中的公平公正、透明可解释、隐私保护、安全可靠、可审计等问题提出监管要求。

企业作为算法和模型生产和应用的主体，通过建立治理体系，以制度、流程、平台、技术工具等手段有效保障算法和模型生产应用全生命周期的安全可控、透明可解释、公平公正、尊重隐私、可审计、可监督等目标，是企业在数字化时代积极履行社会责任及合规运营的必要选择。

《人工智能模型风险治理能力成熟度模型》标准

在此背景下，中国信息通信研究院牵头并依托中国互联网协会信息技术（IT）风险治理工作委员会，联合20余家企业单位共同制定了《人工智能模型风险治理能力成熟度模型》标准（以下简称“标准”）。

标准针对组织在开发、实施和使用人工智能模型过程中面临的主要风险挑战，规范模型生命周期各环节中的风险治理活动，从策略制度、组织架构、资源配置、技术手段等方面提供保障，提出切实有效的治理措施，快速灵活应对模型风险，推动科技向善。

标准在很大程度上能够紧密呼应监管相关要求，并支持相关要求的有效落地，帮助企业提升算法模型风险治理能力。（相关内容可见：标准应用 |《人工智能模型风险治理能力成熟度模型》紧密呼应《关于加强互联网信息服务算法综合治理的指导意见》中相关要求）


标准中对人工智能模型生命周期的各个环节提出了明确的风险管控要求，旨在规范企业对于人工智能模型的风险治理活动，为企业开展相关模型风险治理提供参考和指导建议。

人工智能模型风险治理能力成熟度评估

中国信通院基于标准开展“人工智能模型风险治理能力成熟度评估”，旨在检查和验证人工智能算法模型风险治理能力，对标同业优秀实践，提升企业对人工智能算法模型风险治理的水平。当前，评估开放16个模块，并根据企业对于人工智能模型的风险治理能力分为5个级别：基础级、增强级、优秀级、卓越级、引领级。


首批试评估

中国信通院已完成首批试评估工作，通过2021年人工智能模型风险治理能力成熟度首批试评估的企业有（详情可见：重磅！人工智能模型风险治理能力成熟度首批试评估结果公布！）：


评估价值及收益

【1】  通过评估前自查，企业识别自身薄弱环节和潜在风险

       通过评估前自查，企业可了解人工智能模型的风险治理模式以及普遍存在的风险点，识别自身存在的薄弱环节和潜在风险，及时修补漏洞，明确改进方向。

【2】  借助第三方评估，帮助企业验证自身模型风险的可控程度及风险管理水平

       借助第三方评估，企业可验证模型开发、测试、监测、修正和下线等全生命周期的安全和风险是否达到适当的可控程度，以及可验证开发、实施和使用人工智能模型的相关内部控制和风险管理机制是否达到适当的程度。

【3】  对标同业优秀实践，提升企业模型风控能力建设，建立行业互信互认机制

       企业可以对比同行业在人工智能模型风险治理方面的优秀实践，相互取长补短，从策略、组织、流程、技术等方面全面提升自身的人工智能模型风险治理能力。通过中国信息通信研究院权威评估验证，建立各行业企业互信互认机制，促进行业共同进步。

【4】  助力企业积极响应监管要求，建立健全企业模型风险合规管理体系

       标准制定过程中充分参考了人工智能模型相关监管思路和监管要求，并紧密结合了企业治理架构和管理体系，给出具体可落地的应对方案。企业通过评估，可以积极落实监管要求，建立健全自身模型风险合规管理体系。

【5】  促进企业实施模型差异化管理，降低企业管理成本

       企业通过评估，可以了解国际上主流的人工智能风险管理理念，根据模型的重要性和影响程度，进行模型差异化管理。以评促建，指导企业构建科学的风险管理体系和内部资源优化配置，降低企业管理成本。
