# 荣耀时刻！中国邮政储蓄银行 DevOps 标准评估授牌仪式暨项目总结会圆满举行！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651708500&idx=1&sn=b9eaaf78246a7736b633752e099accfe&chksm=8bcb1ffdbcbc96ebf61f4a924a7c535aa4a205319c4267c9a6cc23efed053ca7d9aa759c538c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651708500&idx=1&sn=b9eaaf78246a7736b633752e099accfe&chksm=8bcb1ffdbcbc96ebf61f4a924a7c535aa4a205319c4267c9a6cc23efed053ca7d9aa759c538c&scene=27#wechat_redirect)

![](../Images/eac5cb089ed87c1e3b9f03c85c8e73a2.png)

在数字化转型的大背景下，企业选择实践 DevOps 来提升效能，由中国信息通信研究院（以下简称“信通院”）牵头的《研发运营一体化（DevOps）能力成熟度模型》系列标准具有非常高的指导意义，各行业头部企业纷纷参与信通院组织的 DevOps 能力成熟度模型评估并顺利通过。  
2021年 12 月，中国邮政储蓄银行股份有限公司（以下简称“中国邮政储蓄银行”）DevOps 标准评估授牌仪式暨项目总结会在京成功举行！中国信息通信研究院、中国邮政储蓄银行和北京华佑科技（高效运维社区）相关领导及专家出席了本次活动，一起畅谈中国邮政储蓄银行在 DevOps 领域的成果，分享 DevOps 落地实践经验。![](../Images/63c54c6e3addaa2f2ca546fc604bba16.png)中国邮政储蓄银行本次参评项目为**邮储经营系统、****营运中心系统****和操作风险管理系统，**三个项目均顺利通过由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。**通过评估详情请点击****中国信通院标准评估官方新闻：[燃！中国邮政储蓄银行通过 DevOps 持续交付标准 3 级评估，相关能力达到国内领先水平](https://mp.weixin.qq.com/s?__biz=Mzg2NTUyNjkzMQ==&mid=2247495063&idx=2&sn=585b4104d62b44a191d34a6d1338daf2&scene=21#wechat_redirect)**

本次会议由中国邮政储蓄银行软件研发中心副总经理张耕华先生主持，会议首先进行“2021 GOLF + IT 新治理领导力论坛”评选活动杰出企业和先锋人物的授牌仪式。  

中国邮政储蓄银行软件研发中心总经理胡军锋先生代表企业上台领奖，中国信通院云计算与大数据研究所所长何宝宏先生进行授牌。![](../Images/7313f1548d0845bea902e3bdfd33533b.png)

“杰出企业”授牌现场（何宝宏先生左，胡军锋先生右）

中国邮政储蓄银行软件研发中心资深信息技术专家张兰英女士荣获先锋人物评选，中国信通院云计算与大数据研究所所长何宝宏先生进行授牌。![](../Images/57f122009f629f09b747768f48b96463.png)

“先锋人物”授牌现场（何宝宏先生左，张兰英女士右）

在 DevOps 标准评估授牌仪式前，中国邮政储蓄银行软件研发中心总经理胡军锋先生上台致辞。他首先对与会的信通院和华佑科技的领导和专家表示感谢，然后详细介绍了 DevOps 在中国邮储银行的落地历程，并且充分肯定了本次信通院评估对项目的促进与提升。

![](../Images/ece425446876e7e6e3407cb9e8f5a10c.png)

中国邮政储蓄银行软件研发中心总经理胡军锋先生致辞

**中国信息通信研究院云计算与大数据研究所所长何宝宏先生为中国邮政储蓄银行进行授牌：**

![](../Images/70bb258b7278193d23864877b3695e66.png)

此次通过评估，代表信通院对中国邮政储蓄银行 DevOps 建设成果的肯定，同时表明平台已具备研发全流程端到端自动化价值交付能力，达到了国内领先水平。会上，中国信通院云计算与大数据研究所所长何宝宏先生详细介绍了信通院云大所围绕云计算、大数据、人工智能、数据中心以及关联应用领域开展的技术、标准研究，构建技术测试平台，承担国家重大科技项目的相关工作，并进行了《从AI到元宇宙：2022年互联网风向展望》的主题演讲。

![](../Images/e2f20b4d79c7e6596165685539cb0f01.png)

中国信通院云计算与大数据研究所所长 何宝宏先生

中国信通院云大所治理与审计部副主任牛晓玲女士向与会人员分享了治理与审计部的工作内容和 DevOps 标准评估的内容及更多进展，同时也介绍了此次标准评估工作的优秀成果。  

![](../Images/5df3ed914ae39342fe3dd221396efe68.png)

中国信通院云大所治理与审计部副主任 牛晓玲女士中国邮政储蓄银行邮储经营系统、营运中心系统和操作风险管理系统三个参与并通过评估的项目组代表依次上台，对项目的研发历程进行了说明，对项目及项目团队进行了风采展示。![](../Images/29c0860317f3662b2c8a7119e2e3c97d.png)

邮储经营系统项目组风采展示现场

![](../Images/334924a1f0070edb21fafae51acf3e3c.png)  

营运中心系统项目组风采展示现场

![](../Images/0b9ce11a43a55a83547a53d93e6e7795.png)

操作风险管理系统项目组风采展示现场

最后，作为本次参评项目的咨询公司代表，华佑科技技术合伙人施景丰先生进行项目总结汇报。报告围绕 DevOps 持续交付三级标准进行的项目改进，通过流程梳理、工具链打通和集成等工作，最终实现端到端持续交付的历程。  

![](../Images/1597b56855ac5008728c3d17f215170b.png)

北京华佑科技有限公司技术合伙人 施景丰先生

本次会议在与会领导与专家热烈交流中圆满落幕，此次授牌也标志着中国邮政储蓄银行的信息化建设取得了阶段性成功，打造了企业标杆项目，对企业数字化转型起到了积极的推进作用，也是中国邮政储蓄银行 DevOps 建设的里程碑！
