各大企业的实践及相关数据表明，标准化和工具赋能是企业成功的关键。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，能有效针对企业软件研发提质增效，不仅更快更灵活，也大幅度提高企业核心竞争力！
12 月 24 日，由中国信息通信研究院主办的“2021 GOLF+ IT新治理领导力论坛”隆重开幕，论坛围绕 “治效兼顾，构筑科技治理新生态” 和 “XOPS 创新，领航运维发展新脉络” 两大主题展开，旨在 “新治理融惠创新，数字化行稳致远” 。会上产学研各界嘉宾进行了精彩的主题演讲和经验分享，促进了企业间的学习交流和各行业数字化治理持续健康发展。
中国信息通信研究院隆重发布了 DevOps 标准持续交付第十六批评估结果。中国邮政储蓄银行股份有限公司（以下简称“中国邮政储蓄银行”）本次参评项目为邮储经营系统、营运中心系统和操作风险管理系统，三个项目均顺利通过由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。
评估单位：中国信息通信研究院

此次，我们采访了中国邮政储蓄银行软件研发中心总经理胡军锋先生和中国邮政储蓄银行软件研发中心资深信息技术专家张兰英女士，一同深聊团队在项目参与评估时的细节和故事，分享中国邮政储蓄银行 DevOps 实践的经验。


- Q&A -

中国邮政储蓄银行
软件研发中心总经理 胡军锋

Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。
胡军锋：大家好，我是中国邮政储蓄银行软件研发中心总经理胡军锋，首先非常感谢信通院及评审专家对邮储银行 DevOps 持续交付能力的肯定。
中国邮政储蓄银行是中国领先的大型零售商业银行，拥有近 4 万个营业网点，服务个人客户超过 6 亿户。近年来，邮储银行积极推进科技创新发展布局，持续加大在信息科技领域的投入，实施科技领军人才战略，科技人才队伍快速增长，持续提升自主研发能力和金融科技创新能力。邮储银行将信息科技视为业务发展的核心驱动力，建设大数据平台、云计算平台、区块链服务平台和“邮储大脑”人工智能平台，打造金融科技中台能力，实现客户营销、运营管理、风险管理的新技术赋能。在数字化转型过程中，邮储银行积极深化 IT 治理，结合自身特点建立了开源治理体系，建设 DevOps 平台，不断提升 IT 治理的能力和水平，提高研发效率与质量，降低运维成本，加速产品与服务创新，服务业务发展。
本次邮储银行参评的 3 个项目分别为邮储经营系统、营运中心系统和操作风险管理系统。邮储经营系统专注为小微企业客户提供线上融资等核心金融服务，通过提供”金融+场景”的综合服务实现“获客+活客” 的最终目标；营运中心系统主要服务于我行运营条线，致力于打造集约化运营管理平台；操作风险管理系统用于支撑全行操作风险管理，为银行操作风险管理提供工作平台、管理平台和信息分析平台，功能涵盖关键流程管理、操作风险三大工具及经济风险计量等。


Q：恭喜通过 DevOps 标准评估，此次贵公司 3 个项目均通过持续交付 3 级评估，表明达到了国内领先水平，请说一下您此时的感受。
胡军锋：很高兴 3 个参评项目顺利通过 DevOps 能力成熟度三级评估，这是对我行持续交付能力的肯定，代表我们的 DevOps 水平达到国内领先水平。中国邮政储蓄银行首次参加 DevOps 标准评估，能够在较短的时间内达到持续交付三级标准的能力要求，包括我个人在内的所有参与这个事的领导和同事都很开心，我行 2019 年开始探索和实践 DevOps，一步一个脚印，从最开始仅支持自动构建和单元测试，到逐步实现自动化部署和发布，再到后来加入质量扫描和自动化测试、到最后打通需求、开发、集成、部署、测试各个环节，实现端到端持续交付，并可以通过各种度量指标助力持续改进。能有这样的进步，是对领导的支持和大家不懈努力的最好回报，此时此刻我们感到非常骄傲和自豪。

Q：贵公司是如何决定加入 DevOps 标准评估工作中的？
胡军锋：我行一直关注业内前沿技术和未来发展趋势，并积极探索将新技术、新方法应用于工程实践。
DevOps 实现开发与运维的协同，以一系列自动化为基础完成软件的持续交付与持续部署，提高产品和服务的交付效率与质量。DevOps 标准，是由中国信息通信研究院牵头，联合多个企事业单位专家制定的行业标准，通过与标准对标识别差距，借鉴标准最佳实践并进行持续优化改进，对落地 DevOps、提升研发效能有着重要意义。
我们从 2019 年开始建设 DevOps 研发协同系统，2020 年初步形成并进行试点使用，2021 年开始大力推广，目前已支持 77 个项目使用。我行 DevOps 结合了组织级流程规范，通过自动化、智能化的工具，打通需求、开发、集成、部署、测试各个环节，实现端到端的持续交付。今年年中，我们启动 DevOps 标准对标，学习和借鉴行业最佳实践，进一步提升我行 DevOps 能力水平，提升工程交付效能。

Q：通过 DevOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？
胡军锋：顺利通过 DevOps 能力成熟度评估，标志着邮储银行的持续交付能力、标准化、自动化能力达到行业领先水平。
对标 DevOps 标准，通过识别与标准的差距并进行持续改进，有效提升了我行的软件交付能力和质量。一是通过梳理、优化、集成多个项目管理支撑类系统，打通了需求、设计、开发、运维各环节协作，实现信息和流程互通，满足跨团队的协作需要。二是利用工具和自动化流程，使持续集成与部署流程更加便捷，提高了工程开发与交付效率。三是在构建过程中引入质量门禁，进行代码质量检查与安全扫描，提高了代码的规范性和安全性，进一步提升了交付质量。

中国邮政储蓄银行

软件研发中心资深信息技术专家 张兰英

Q：您可否详细的介绍一下，通过本次评估有哪些改进成果？
张兰英：大家好，我是中国邮政储蓄银行软件研发中心资深信息技术专家张兰英。
本次评估我行基于 DevOps 应用现状，对标 DevOps 标准的 49 个能力项，充分学习和借鉴标准的最佳实践，根据现状和标准的差距，对流程和工具进一步优化，有效提升了系统的交付效率和质量。3 个参评项目对标改进的主要效果展现在以下几方面：自动构建成功率  90%  以上、自动部署成功率 90% 以上、单元测试覆盖率 65% 以上、自动化测试通过率 98% 以上，流水线修复时长 30 分钟内。具体实施效果如下图：


Q：对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？
张兰英：本次参评的三个项目，涵盖了前端面客、后端运营以及操作风险三大领域，在技术架构上，既有传统集群架构也有分布式微服务架构，在研发模式上，既有传统瀑布模式也有敏捷开发模式，涉及了稳态和敏态两种模式。数字化转型大背景下，客户对银行应用的交付能力要求也越来越高，我们希望通过对标 DevOps 行业标准和国际标准，同时结合我行实际情况和工程建设的特点，探索出我行适用的 DevOps 最佳实践，逐步推广到更多的项目，全面提升我们的研发效能水平，提升交付质量，服务业务高质量发展。

Q： 此次通过评估的过程顺利吗？遇到什么困难？如何解决的？

张兰英：本次评估过程总体比较顺利。各级领导给了项目组最大的支持，相关部门、处室协同推进，大家目标一致、共同努力，大部分问题都能迎刃而解，参评项目才能在这么短的时间顺利通过评估。

今年年中，我们启动了 DevOps 能力成熟度标准对标，这是邮储银行首次进行 DevOps 能力评估。最大的困难，主要还是时间比较紧张，前期我们已经进行了一些 DevOps 实践和流程优化，但对标标准时发现，还是有一些做法和 DevOps 标准的最佳实践有差异，团队成员必须要调整惯性思维、统一理解，这需要一个过程。另外，行内一些管理支撑类系统之间的贯通，也还不是很顺畅，虽然打通了数据流，但也存在一些可自动处理的人工处理环节，需要进一步优化。

上述困难的解决，首先得益于各级领导的支持，行领导亲自批示与指导，将 DevOps 作为提升全行交付效率的重要举措；软件研发中心、数据中心的领导同事全程参与并给了项目最大的支持，确保 DevOps 评估顺利落地。跨处室评估团队同心协力，制定详细的改进计划，每周开展迭代优化、复盘、问题回顾，持续提升各个能力项指标，逐步满足三级标准要求，一些能力项指标达到四级标准。


Q：对于 DevOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？ 

张兰英：最大的收获不仅仅是 3 个参评项目通过了 DevOps 持续交付三级标准评估，并实现工程效率和质量提升。更重要的是，通过对标 DevOps 行业标准和国际标准，我行结合自身实际情况和工程建设的特点，探索出了合适的 DevOps 最佳实践，可以进一步推广到其他项目，帮助更多项目实现研发效率和质量的提升。

下一步，我们将持续优化 DevOps，总结完善最佳实践并进行全面推广。主要有以下几个方面：一是继续进行与 DevOps 系列标准对标，借鉴行业先进经验，进一步完善端到端工具集成，提升研发效能。二是将 DevOps 衍生到 DevSecOps，落地企业级软件开发、安全等组织级规范，将安全关口左移，提升软件交付质量，防范安全风险；三是加快 DevOps 最佳实践推广，逐步推广到全行项目，实现邮储银行研发效率和质量的全面提升。


Q：对于 DevOps 的发展前景，您怎么看？
张兰英：在全球数字化转型大背景下，DevOps 显得尤为重要：一是 DevOps 整合了企业文化理念、项目管理、流程规范、自动化工具、最佳实践等，实现跨团队的线上协作，成为企业打通各部门壁垒的最佳实践。二是 DevOps 促进软件高效率、高质量的交付，并提高客户满意度、快速响应市场需求，助力企业数字化转型。
当然，DevOps 也是不断演进和持续发展的，随着信息安全越来越被重视，诞生了 DevSecOps，随着人工智能、容器、云原生等技术的兴起和广泛应用，衍生出了 AIOps、DataOps 等。未来，邮储银行将持续关注 DevOps、XOps 发展趋势，不断探索将业界最佳实践与邮储银行实际工作相结合，提高运营效率，提升交付效能，服务全行业务高质量发展。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
