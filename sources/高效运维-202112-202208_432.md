从各大企业的实践来看，标准化和工具赋能是科技公司成功的关键所在。标准本身是最佳实践的集合，有了标准，每一步都离目标更近（而不是偏离），将标准固化在工具里，DevOps 重点关注人员、流程和产品，并已经在企业和交付环节持续取得成功，获得良性反馈和循环。从安全角度来看，DevOps 有助于创建“一种协作文化，通过减少生产环境的变化来降低风险”。  

2021年12月24日，为提高企业IT治理水平，加强行业内经验交流分享，2021 GOLF+ IT新治理领导力论坛于线上召开！本次大会旨在“新治理融惠创新，数字化行稳致远”，围绕“治效兼顾，构筑科技治理新生态”和“ XOPS 创新，领航运维发展新脉络”两大主题展开。

**大会隆重发布了 DevOps 能力成熟度安全及风险管理首批正式评估结果。**中原银行股份有限公司（以下简称“中原银行”）的个人手机银行项目参与了本次由中国信息通信研究院（以下简称“信通院”）开展的《研发运营一体化（DevOps）能力成熟度模型》安全及风险管理（DevSecOps标准）安全开发模块2级评估，代表着中原银行在该业务系统的安全开发能力能力达到国内先进水平。

****▲DevOps评估结果公布现场****此次，我们采访了中原银行技术总监扈浩先生、中原银行信息技术部总经理薛恩峰先生，分享中原银行 DevSecOps 的实践经验。**\-Q&A-**![](../Images/e52c160c1dec5945920849188f9318da.png)中原银行技术总监 扈浩

**Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目**

**扈浩**：中原银行成立于2014年12月26日，是河南省唯一一家具有营业网点覆盖全省、省委省政府寄予厚望、中原人民视为自己银行鲜明属性的省级法人银行。2017年7月19日，中原银行在香港联交所主板挂牌上市。开业以来，中原银行按照河南省委省政府提出的“将中原银行办成一流商业银行”的发展目标，积极开展“上网下乡”“数字化转型”“人才强行”战略，取得了较好发展成果。截至2021年6月末，全行资产总额7530.02亿元；下辖18家分行和2家直属支行，共有营业网点494家；作为主发起人，在省内设有9家村镇银行和1家消费金融公司；控股设立邦银金融租赁公司。同时，蝉联六年《金融时报》“年度十佳城市商业银行”，相继荣获“铁马十佳银行”“最佳上市公司”“年度卓越城商行”等称号，位列英国《银行家》杂志2021年全球1000强银行第185名和《财富》2021年中国500强入围商业银行第24名。

此次参与评估的项目为“个人手机银行”，个人手机银行项目是中原银行推出的全新移动金融服务工具，通过移动端APP为客户提供账户管理、支付管理、投资理财、信用卡管理、贷款管理、生活服务（含便民缴费、征信查询、娱乐购物）等综合金融服务，客户足不出户即能享受到中原银行贴心、专业的优质服务。

个人手机银行系统基于不同客户群体特点，推出“标准版”、“财私版”、“芳华版”与“家和版”四大版本，分别致敬中流砥柱、社会精英、幸福人生与美丽田野。通过划分“一点通”、“财富”、“贷款”、“生活”、“我的”五大模块为客户提供精准、聚焦的金融和非金融产品与服务。同时个人手机银行系统借助大数据、人工智能等先进技术提供智能化、个性化、便捷安全的移动金融服务。

**Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是安全及风险管理（DevSecOps）2级，表明达到了国内先进水平，可以分享您的感受吗？**

**扈浩**：非常高兴“个人手机银行”项目能够顺利通过安全及风险管理标准评估，这是我行在 DevSecOps 实践领域的一个重要里程碑，表明我行个人手机银行在 DevSecOps 领域实践达到国内先进水平。在此特别感谢中国信息通信研究院各位专家在标准评估过程中对于我行的指导和帮助，同时非常感谢参评团队全体人员的辛勤付出与努力。

本次顺利通过信通院《研发运营一体化（DevOps）能力成熟度模型 第6部分：安全及风险管理》首批正式评估，表明我行信息安全体系建设获得业界认可，更加坚定了我行深化推进 DevSecOps 技术体系建设的信心与决心。我行科技团队将继续保持专注，锐意进取，积极向优秀同业实践学习，不断改进提升 DevSecOps 实践能力水平。

**Q：贵公司是如何决定参与 DevSecOps 标准评估工作中的？****扈浩**：中原银行成立以来，科技团队始终秉承“科技立行、科技兴行”的发展理念，不断夯实金融科技基础设施，提升核心技术能力，全面推进数字化转型实践，有力支撑了全行业务的持续稳健发展。DevSecOps 是一套基于 DevOps技术体系的全新安全实践框架，旨在将安全服务内嵌至敏捷交付过程中，通过设计一系列可集成的安全控制措施，赋能研发团队高效安全交付业务价值。自2017年起，我行全面启动企业级应用开发全生命周期安全管理体系建设，自主研发“安全技术服务平台”，构建应用安全能力支撑技术体系，持续完善涵盖安全培训、需求分析、系统设计、编码开发、安全测试等环节的软件开发生命周期安全管理体系，多措并举，筑牢安全防线护航业务创新发展。本次参加 DevOps 安全及风险管理标准评估，是对我行 DevSecOps 能力体系建设水平的一次全面评估与检验，有助于我行对标业界先进实践，完善应用开发安全管理体系，促进团队持续改进提升。

**Q：贵公司之前已经通过其他标准，请问通过多个标准的原因是什么？**

**扈浩**：中原银行2020年“云缴费平台”项目与“企业手机银行”项目通过了 DevOps 持续交付标准3级评估，DevOps 平台通过了国内首批 DevOps 系统和工具标准优秀级评估，今年我行个人手机银行项目通过安全及风险管理（DevSecOps）标准2级首批正式评估。信通院 DevOps系列标准凝结了业界先进企业的最佳技术实践，具有很强的规范指导意义。参与多项 DevOps 标准评估，有助于我行全面对标业界先进水平，对 DevOps 建设实践进行体系化检视评估，以评促建，促进提升研发交付效能，助力持续顺畅、安全交付高质量的业务价值。

**Q：通过安全及风险管理（DevSecOps）标准的评估给您的企业带来了什么收获？****扈浩**：通过此次 DevSecOps 标准评估，对标业界先进实践，助力我行进一步提升DevSecOps 能力体系建设的标准化、专业化水平，为后续全行规模化推广 DevSecOps落地实践奠定了坚实基础。在 DevSecOps 实践理念的指引下，我行在软件应用服务设计前期即引入安全管控，探索“安全左移”落地实践，全面覆盖安全需求、安全设计、安全开发、安全测试、安全发布等系统开发全生命周期，有效降低安全问题修复成本，全方位赋能应用安全开发管理，提升人员安全能力水平。

![](../Images/fd0a652282e0ccae6f7259628b37d34a.png)

中原银行信息技术部总经理 薛恩峰**Q：DevSecOps 核心理念为安全是整个IT团队（包括开发、运维及安全团队）每个人的责任，是否可以详细的给我们介绍下，贵司是如何从文化、流程及技术三方面落地DevSecOps 的？****薛恩峰**：一是在文化方面，安全团队定期面向全行科技团队开展安全意识和安全技术相关培训，积极宣导 DevSecOps 文化理念，以此促进提升全员参与 DevSecOps 实践的积极性。二是在技术方面，通过建设“安全技术服务平台”，全面贯彻落实系统安全开发全生命周期管理要求，主要包括：通过交互式安全需求识别工具与轻量级的威胁建模方法，分析业务场景潜在安全风险，并有针对性地提出安全需求与系统设计方案；通过源代码扫描工具实现开发本地源码扫描和代码仓库流水线质量门禁控制，有效保障代码质量安全；基于安全需求和安全测试用例库进一步规范渗透测试等。三是在流程方面，我行安全技术服务平台与 DevOps 平台实现了从安全需求至安全测试的全流程集成，通过安全需求、安全工具链、渗透测试、漏洞管理等环节，实现安全管控和 DevOps 流程的无缝衔接，有力保障了 DevSecOps 落地实施。**Q：对于此次参评的项目哪些特色？在日常安全风险的管理方面，面临哪些安全挑战？****薛恩峰**：个人手机银行是我行最具代表性的核心移动金融应用产品，该系统覆盖此次参评的组织建设、安全工具链、数据管理、基础设施和安全开发等能力项领域，具备全面的流程规范体系；同时个人手机银行开发全面覆盖需求、设计、开发与测试的软件开发生命周期。个人手机银行在日常安全风险管理方面，主要面临如下安全挑战：一是手机银行包含上百个业务功能场景，开发迭代更新频繁，对持续高效安全管控带来了较大挑战。二是手机银行作为银行最重要的移动应用产品，面临的外部环境较为严峻，交易欺诈、黑客攻击、不法分子渗透等灰黑产业日益猖獗，对手机银行的安全防护保障造成很大威胁。**Q：安全及风险管理标准对于企业安全风险管控能力提升提供了有效的指引，请问贵司对于 DevSecOps 落地实践的下一步计划是什么？****薛恩峰**：中国信通院《研发运营一体化（DevOps）能力成熟度模型 第6部分：安全及风险管理》标准对于我行 DevSecOps 的落地实践具有很强的指导意义。下一步，我行将积极推广个人手机银行 DevSecOps 实践经验，赋能全行科技项目团队，不断提升安全研发效能。同时我行将持续深化 DevSecOps 体系建设，探索落地三级及以上能力标准，努力推动安全实践向深度规范化、工具系统化、全面自动化、度量驱动化演进发展。**中原银行手机银行团队评估现场图：**

**研发运营一体化（DevOps）能力成熟度模型介绍：**  

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
