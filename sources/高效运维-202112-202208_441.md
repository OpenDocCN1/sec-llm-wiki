12 月 24 日，由中国信息通信研究院主办的“**2021 GOLF+ IT新治理领导力论坛**”隆重开幕，论坛围绕 “治效兼顾，构筑科技治理新生态” 和 “XOPS 创新，领航运维发展新脉络” 两大主题展开，旨在 “**新治理融惠创新，数字化行稳致远**” 。会上产学研各界嘉宾进行了精彩的主题演讲和经验分享，促进了企业间的学习交流和各行业数字化治理持续健康发展。

**中国信息通信研究院隆重发布了 DevOps 标准持续交付第十六批评估结果。**四川新网银行股份有限公司（以下简称“新网银行”）本次参评项目为**分布式消费信贷核心系统**，本项目顺利通过由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。

  

**评估单位：中国信息通信研究院**

▲DevOps评估结果公布现场

此次，我们采访了新网银行信息科技总监毛航先生，一同深聊团队在项目参与评估时的细节和故事，分享新网银行 DevOps 实践的经验。

**\- Q&A -**

![](../Images/15e88662eba232589b3cd1b2aeb874e4.png)

新网银行信息科技总监 毛航  
**Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。**

**毛航：**我行自成立以来，始终坚持“技术立行”，用科技做资产与资金的“路由器”。作为新一代数字原生银行，将数字基因融入金融生态，践行敏捷开发理念，致力于为客户提供有温度的数字金融服务。

此次参评的项目是分布式信贷核心系统，该系统采用分布式架构，通过领域建模构建产品、用户、额度、借据、支付、账务等微服务体系，以金融产品配置化为核心设计理念，实现一套全新线上信贷核心系统，支撑我行快速打造差异化信贷产品。  
**Q：恭喜通过 DevOps 标准评估，此次贵公司通过的是持续交付 3 级，表明达到了国内领先水平，请说一下您此时的感受。******毛航******：**很高兴本次参评的项目顺利通过了中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级能力评估。这是对新网银行 DevOps 实践的肯定，是新网银行在研发过程管理的一项重要成果，将对新网银行全面推广 DevOps 实践起到示范作用。特别感谢信通院各位专家在评估过程中对我们的帮助和指导，同时感谢我们新网项目组成员的辛苦付出。  
**Q：贵公司是如何决定加入 DevOps 标准评估工作中的？**

******毛航******：****我行开业之初就践行敏捷开发理念，快速响应业务需求，并取得较好成果。随着业务规模不断增长，科技团队规模也大幅增加。为保障团队的协作效率和交付质量，研发管理流程需要更加规范和高效。

我行为进一步提升研发精细化管理水平，启动了 DevOps 能力建设。中国信息通信研究院的《研发运营一体化（DevOps）能力成熟度模型》是全球首个 DevOps 行业标准。希望通过 DevOps 标准来评估我行目前持续交付的能力，明确改进方向，达到降本增效，提质降熵的管理目标。

  

**Q：通过 DevOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？**********毛航******：******在参评项目评估过程中，不仅实现了参评项目研发周期缩短、制品质量提升等效果，还对 DevOps 文化在科技部的推广起到促进作用。取得上述成果，得益于我们基于 DevOps 标准打通了研发过程工具链，建立端到端持续交付流水线，制定测试分层策略，建立质量门禁体系。随着 DevOps 文化融入科技部，进一步提升科技部研发效能，保障产品快速验证与交付。  
**Q：您可否详细的介绍一下，通过本次评估有哪些改进成果？************毛航******：********通过本次评估，平均每天代码提交达到 30 次，平均每天集成 4 次，平均每天构建 85 次，平均每次构建 3 分钟，单元测试覆盖率达到 80%，接口测试覆盖率达到 100%，自动化冒烟测试成功率达到 100%，自动化测试成功率达到 99.5%，需求交付能力较之前提升 35%，缺陷密度较之前下降 60%，平均每周投产 2 次，投产成功率达到 100%。

![](../Images/700ca884ed52c9d1163cb11008028798.png)

  
**Q：对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？************毛航******：********该项目采用分布式技术架构，运用领域建模思想进行横向和垂直的微服务化拆分设计，各微服务明确边界和职责，项目实施过程中，坚持对标 DevOps 方法论指导研发活动，落地构建出一套高效的需求、开发、测试、运维的“正向飞轮”，保障了系统的交付质量和效率。  
**Q： 此次通过评估的过程顺利吗？遇到什么困难？如何解决的？************毛航******：********该项目自建设之初就定下了围绕 DevOps 实践的落地实施方针，总体来说，本次评估过程还是很顺利的。我们对本次评估活动非常重视，科技部各中心抽调骨干成员组建了专项评估团队，也是期望通过 DevOps 标准对内部研发过程进行一次检验。在项目刚开始，发现各团队前期虽然都按照 DevOps 在落地实施，但在对标准的理解上存在一些偏差和误区，项目团队通过共同解读标准和纠正误区，最终达成了对标准的一致理解，后续改进工作推进也更为顺利。另外，在推进过程中遇到新冠疫情反复，导致沟通成本增加，项目组及时调整实施方案，将所有的沟通事项转变成任务跟踪项，由项目成员跟进并实施，最终顺利完成持续交付能力改进。  
**Q：对于 DevOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？ **

**********毛航******：********通过此次评估软件质量和研发效率得到显著提升，能够更快速地交付业务价值。后续将结合我行实际情况持续和深入地开展优化和实践落地，主要围绕以下方面，首先对标信通院的 DevOps 标准进行改造，建立适合新网的 DevOps 标准。其次进一步完善我行效能平台，做好更大范围的推广和落地，赋能研发团队。

  
**Q：对于 DevOps 的发展前景，您怎么看？**

**********毛航******：********DevOps 是通过平台、流程、人的整合，以 CALMS 文化为指引，即协作、自动化、精益、度量、共享，旨在建立一共可交付价值并且具有持续改进能力的现代化IT组织。中国信息通信研究院的《研发运营一体化（DevOps）能力成熟度模型》覆盖了从需求、开发、测试、部署、运营全开发流程的标准，基于整个组织的协作和应用架构的优化，实现敏捷开发、持续交付和应用运营的无缝集成，在保证稳定的同时，快速交付高质量的软件及服务，灵活应对快速变化的业务需求和市场环境。其理念与我行业研发过程管理的目标高度一致。相信通过 DevOps 实践的全面落地，我行研发效能和质量会更上一个台阶。

**研发运营一体化（DevOps）能力成熟度模型介绍：**  

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。  

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
