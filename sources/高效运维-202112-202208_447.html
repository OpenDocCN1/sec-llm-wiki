燃！中金公司通过 DevOps 系统和工具标准评估，相关能力达到国内领先水平

各大企业的实践及相关数据表明，标准化和工具赋能是企业成功的关键。DevOps 标准及基于标准的 DevOps 持续交付流水线平台，能有效针对企业软件研发提质增效，不仅更快更灵活，也大幅度提高企业核心竞争力！


12 月 24 日，由中国信息通信研究院主办的“2021 GOLF+ IT新治理领导力论坛”隆重开幕，论坛围绕 “治效兼顾，构筑科技治理新生态” 和 “XOPS 创新，领航运维发展新脉络” 两大主题展开，旨在 “新治理融惠创新，数字化行稳致远” 。会上产学研各界嘉宾进行了精彩的主题演讲和经验分享，促进了企业间的学习交流和各行业数字化治理持续健康发展。
中国信息通信研究院隆重发布了 DevOps 标准系统和工具第三批评估结果。中国国际金融股份有限公司（以下简称“中金公司”）的天玑DevOps平台参与本次由中国信息通信研究院开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具技术要求第三批评估，其流水线模块顺利通过优秀级评估。代表着中金公司的 DevOps 系统和工具在相关模块达到国内领先水平。

评估单位：中国信息通信研究院

此次，我们采访了中金公司信息技术部董事总经理李建鸣先生、中金公司信息技术部执行总经理叶明登先生、中金公司信息技术部副总经理方飞先生和天玑 DevOps 主要建设参与者曹文文女士，分享中金公司 DevOps 实践的经验。

-Q&A-  

中金公司信息技术部董事总经理 李建鸣


Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。

李建鸣：中国国际金融股份有限公司成立于 1995 年，是国内首家中外合资的投资银行。中金公司率先将国际经验和中国资本市场经验相结合，用于市场创新，创造了诸多市场交易先河。中金公司于 2015 年香港上市，2017 年与中金财富证券整合，2020 年回归 A 股上市，目前已经成为一家拥有上万员工的上市公司。

2021 年是中金数字化转型的开创之年，围绕数字化转型，中金信息技术部打造了企业级 DevOps 平台“天玑”，天玑提供了持续集成和持续部署的能力，贯穿设计、开发、测试、上线、维护五大软件生命周期，天玑作为公司项目敏捷管理，研发效能提升以及转型工程实践平台，在公司内部迅速推广，促进了公司整体的交付成熟度显著提升。


Q：恭喜中金公司通过 DevOps 标准评估，此次贵公司项目通过的是系统与工具标准优秀级，您的感受是怎样的？

李建鸣：很高兴能够通过 DevOps 系统和工具流水线模块优秀级评估，也非常感谢信通院的专家在评估过程中对我们平台和技术提出的诸多建设性意见。任何理论落到实处，都需要有实操性，企业级的系统以及工具链的建设促进我们将之前大量线下的手工工作变成线上标准化流程。信通院发布的“系统与工具标准”是全球领先的 DevOps 行业标准，在行业中具有充分的公信力。在打造天玑 DevOps 平台的过程中，团队秉持系统与工具能力项的要求，探索最佳实践，这次评审无疑是用最高标准来检验公司敏捷和 DevOps 转型成效，评审的通过也证明了平台建设的阶段性显著成果。


Q：打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？

李建鸣：在公司内部，业务系统的项目开发全流程由天玑承载，在每次小的迭代中，平台强大的工具支撑给敏捷项目团队提供了灵活的自动化能力，平台就像人体骨骼一样牵引着业务用不同的肌肉组织发挥力量，不断提升公司内部组织效率和质量。


Q： 贵单位参与本次系统和工具标准评估，有哪些考量？
李建鸣：首先 DevOps 平台为业务与科技的深度融合提供土壤，敏捷程度和业务发展息息相关，DevOps 建设从整体战略布局到战术执行都需要与业务“同呼吸共进退”。面对不同业务特点和部门需求，天玑 DevOps 标准化公司内部工具链以及开发技术栈，为业务开发提供重要支撑。其次工具链在金融公司落地，一定要考虑监管以及安全的审慎要求，DevOps 除了敏捷效率，一定要将发展和安全并举，工具链才能更好地为业务服务。
 
Q： 通过系统和工具标准评估带给企业和团队哪些变化？
李建鸣：首先我们实现了技术部门与业务部门“车同轨，书同文”，能在同一个平台上无缝协作，虽然大家不在一个办公室办公，但是处在同一个数字化空间，平台将科技生产的全流程串联起来，做到项目管理、科技工作的流程化、标准化以及可视化。

中金公司信息技术部执行总经理 叶明登


Q：贵公司对于 DevOps 工作的开展，有什么进一步的计划？

叶明登：关于 DevOps 建设未来规划，我们经过深入的思考，工具链成熟度的评估是一个很好的开始，未来我们还是要不断打磨我们的产研体系，让更多的工具沉淀下来，能够更好地与平台对接，优化和提升平台的服务能力。目前我们将整个实践过程划分为平台化、精益化、一体化三个大的阶段：

  • 构建 DevOps 的平台化。专注于工具链建设，着重实现 DevOps 意识提升、研发转型，以及初步的研发效率与质量提升。
  • 精益化阶段。构建面向业务和研发全过程的度量体系，形成持续改进机制，将 IT  生产过程转变为线上高度自动化、可视化的 IT 生产线，团队高度自治，敏捷交付，应用持续优化落地，提升业务竞争力。
  • 一体化阶段。构建覆盖业务，研发测试，质量，运维运营的延展与闭环，实现应用系统的生命周期 DevOps 覆盖，推动业务持续创新，引领业务发展，建成完善的业务度量反馈机制，形成 IT 与业务的“同频共振”。

Q：对于 DevOps 的未来发展方向，您有何看法？  

叶明登：公司的 DevOps 实践是一个长期过程，会一直伴随公司业务发展以及 IT 能力提升，涉及业务组织和 IT 组织的紧密协作与持续优化。道阻且长，行而将至。DevOps 的发展不能一蹴而就，在今后的平台发展中，我们会更关注精益化、创造力，在瞬息万变的数字化市场环境下，成为推进业务走上快车道的新引擎。


中金公司信息技术部副总经理 方飞


Q：通过本次评估，项目的改进成功体现在哪些方面？

方飞：随着公司数字化转型工作的不断推进，团队和资源的不断扩张，开发管理流程越来越多。过去“小作坊”的管理模式主要靠人的自觉性，体量扩张之后，标准的 DevOps 工具链建设是发展的基石，是日常规范的沉淀。工具链建设是敏捷理念整套方法论的落地和实现，在提升日常工作效率的同时做到可度量，可追踪。工具链建成之后，目前的自动发布效率比之前手工的发布效率提升 3 倍以上。


中金公司信息技术部

天玑 DevOps 主要建设参与者 曹文文


Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?

曹文文：主要和大家分享两方面，一个是如何满足评估标准的严格要求？自古华山一条道，科技这条路必定坎坷不平，为攻克技术难题，弥补和标准之间的技术差距，在平台功能的迭代和演进的过程中，团队啃下了很多技术难题。其次是如何快速地工具推广？目前我们的 DevOps 平台团队和应用处于推广阶段，团队快速扩张之后，问题和阻碍必定也会呈现几何级增长，前期我们专注于技术的落地，考虑到公司整体流程，组织，文化等诸多因素，一个平台需要打通整个 IT 生命周期时，现有的文化、流程和组织结构都需要慎重推敲下是否能够满足。平台的建设过程中一直秉持“业务和技术同频共振”的理念，关注业务使用过程中的问题，适配各种技术栈，充分满足合规安全标准。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
