研发效能架构师
base：上海
招聘人数：1

岗位描述

1.设计 DevOps 工具链平台日常开发发布与运维全流程，负责实现 DevOps 全流程策略，包括 CICD、项目管理、自动化发布部署、自动化测试等，并制定相关流程规范；
2.参与企业 DevOps 研发效能平台建设，包括整体规划、架构设计、平台开发及推进落地；
3.洞察业界 DevOps 软件工程发展趋势，输出本领域工程能力建议规划；

任职要求

1、至少5年以上 DevOps 相关工作经验，熟悉开发/运维/测试各岗位工作内容；
2、具备丰富的软件工程知识，对业内领先的 DevOps 方法论较熟悉，熟练常见的 DevOps 工具链；
3、有主导过 CI/CD 在企业内的实际落地经验，熟悉常见研发流程管理，如瀑布流、敏捷开发；
4、有设计开发测试等研发背景，掌握主流的开发语言，有 docker 及 k8s 的实际应用经验；
5、熟悉业界主流的微服务框架，如 HSF、SpringCloud，熟悉 ServcieMesh 相关技术并了解其实现原理，如 Linkerd、Istio等；
6、有较强的推动协调组织能力；具备良好的结构化思维和与人连接力；具备高度责任心，发现问题并解决问题，能够系统的识别和分析解决复杂问题；
7、有成功的企业内主导落地过 DevOps 相关项目者优先；有研发团队管理经验优先；
8、优秀的分析问题和解决问题的能力，对解决具有挑战性的问题充满激情；
9、本科及以上学历，计算机、应用数学、统计或其他理工科等相关专业，8年以上工作经验；
