#### 岗位职责：

*   设计与规划 DevOps 工具链平台开发、发布与运维全流程，负责实现 DevOps 全流程策略，包括 CICD、项目管理、自动化发布部署、自动化测试等，并制定相关流程规范
*   主导企业 DevOps 研发效能平台的建设和规划，明确 DevOps 演进路线和推广计划，对公司整体软件工程效能和质量负责，包括整体规划、架构设计、平台开发，及推进落地
*   负责建立公司软件工程效能研发、度量和管理体系，逐步实现可度量、可管理、可改进的 DevOps 体系
*   不断引入 DevOps 新技术和方法，持续改进 DevOps 流程，实现开发过程自动化，持续提升软件工程效能

#### 岗位要求：

*   计算机相关专业本科以上学历，3年以上 DevOps 生态链和系统建设和维护的经验，具备 DevOps 体系思维
*   对 DevOps 业界动态和新技术保持敏锐关注和尝试的热情，敢于尝试不同的思路和方法
*   熟悉 DevOps 相关工具和技术，例如蓝鲸，Git，Jenkins，Docker/K8S，Ansible，Nexus/Artifactory，Maven/Gradle，ELK等，有自动化测试、开源组件治理、DevSecOps、智能运维等经验者优先考虑
*   组织过企业级 DevOps 推广和实践，拥有企业或开源敏捷、DevOps社区运营或管理经验
    
*   熟悉容器、云原生相关技术理念，对云原生技术充满热情
    
*   语言要求：不限
    
*   行业要求：汽车行业优先
