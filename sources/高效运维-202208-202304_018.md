# 燃！中国邮政储蓄银行通过 DevOps 测试工具标准评估，相关能力达到国内领先水平

国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，提高企业市场竞争力，同时实现更高的安全性和敏捷性！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

  

2023年4月7日，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第 20 届 GOPS 全球运维大会在深圳正式召开。GOPS 全球运维大会是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会。大会主要面向互联网及金融、通信等传统行业广大运维、开发等技术人员，旨在传播先进技术思想和理念，分享业内最佳实践。

  

在本次会议上，**中国信息通信研究院隆重公布了 DevOps 系统和工具标准最新批次评估结果。**

  

中国邮政储蓄银行股份有限公司（以下简称“中国邮政储蓄银行”）本次参评的项目为**星辰平台**，该项目顺利通过中国信息通信研究院开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具标准**【测试数据管理】【测试用例与计划管理】**两个模块优秀级评估，代表着中国邮政储蓄银行的 DevOps 系统和工具在相关模块达到国内领先水平。

  

在本批次 DevOps 系列标准评估结果中，中国邮政储蓄银行也同时通过了 DevSecOps 标准评估 1 项。

  

目前，中国邮政储蓄银行共通过 9 项中国信通院 DevOps 标准评估。通过 DevOps 持续交付标准评估 3 项，通过 DevOps 系统和工具标准评估 5 项，通过 DevSecOps 标准评估 1 项。

  

**评估单位：中国信息通信研究院**

  

**2023年4月7日在“2023 GOPS 全球运维大会·深圳站”主会场上，由**中国信息通信研究院云计算与大数据研究所副总工程师王蕴韬先生**为企业授牌**：

  

![](../Images/8f25224a8f16dfc1b53e35d4ec377809.png)

  

此次，我们采访了中国邮政储蓄银行软件研发中心总经理胡军锋先生和软件研发中心资深信息技术专家张兰英女士，一同深聊团队在项目参与评估时的细节和故事，分享中国邮政储蓄银行 DevOps 实践的经验。

**Q&A**

中国邮政储蓄银行

软件研发中心总经理 胡军锋

  

**Q**

**您好，请介绍一下您和您的企业，以及此次参与评估的项目。**

**A**

**胡军锋：**大家好，我是中国邮政储蓄银行软件研发中心总经理胡军锋，非常感谢信通院及评审专家对邮储银行 DevOps 能力建设的肯定，很高兴能有机会和大家一起分享相关实践经验。

  

中国邮政储蓄银行是六大国有银行之一，拥有近4万个营业网点，服务个人客户超6亿户，定位于服务 “三农”、城乡居民和中小企业，依托“自营+代理”的独特模式和资源禀赋，致力于为中国经济转型中最具活力的客户群体提供服务。邮储银行以金融科技赋能高质量发展，坚持战略“入脑”、科技“强心”、数据“造血”，深入推进智慧、平台、体验、生态和数字化“加速度”（SPEED）科技战略实施，通过实施 DevOps、开源治理等举措，持续提升 IT 治理能力水平，努力建设成为客户信赖、特色鲜明、稳健安全、创新驱动、价值卓越的一流大型零售银行。

  

本次邮储银行以“星辰平台”参加 DevOps 能力成熟度的系统与工具标准评估。“星辰平台”定位为邮储银行企业级测试管理平台，通过标准化测试工艺、全流程测试质控管理、测试工具闭环集成、测试资产沉淀复用等过程，形成全流程版本交付数据通路，输出一体化测试管理能力。

  

双鱼座任务与计划子系统围绕测试任务创建、测试计划闭环管理、测试结果追踪反馈进行建设，狮子座用例与缺陷子系统实现需求用例映射、测试用例管理、执行过程追踪、手工/自动化执行等功能，猎户座测试环境子系统致力于打造测试环境与测试数据统一线上化管理平台，为测试人员提供自助式数据生成服务，降低数据获取成本。

  

  

**Q**

**恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是系统和工具标准，请说一下您此时的感受。**

**A**

**胡军锋：**非常荣幸邮储银行再次通过 DevOps 标准评估。同时也十分感谢信通院对我行的大力支持，感谢各位评审专家全程细致用心的评测，整个评估改进过程为我行 DevOps 能力建设提供了大量实用有效的建议。“星辰平台”项目组上下团结一心，查缺补漏，紧扣标准要义，充分贯彻 DevOps 理念，切实提升了“星辰平台”测试计划管理、测试用例管理、测试数据管理能力。在评估过程中，我们得到了行业专家的肯定，这不仅是对我们系统能力的认可，也是对邮储银行 DevOps 能力应用成果的认可。

  

  

**Q**

**打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？**

**A**

**胡军锋**：当前世界面临百年未有之大变局，银行业面临的发展环境复杂多变，机遇与挑战并存。银行需要快速响应市场变化，快速为客户提供更有价值、可持续的金融产品服务。DevOps 打通需求、设计、开发、测试、部署、运维各个环节，将研发运维过程标准化、自动化，可有效提升产品交付效率，帮助企业实现高效的价值交付。

  

打造端到端的流程化、一体化的工具链是 DevOps 成功落地实施的必要条件，建立有效的适应企业特征的工具链有助于快速提升上线交付能力。通过一体化流程将开发构建、测试、部署等任务、步骤串接，实现全流程自动化、标准化。这个过程需要各种工具的支撑，市面上也有很多成熟的商业工具，但外部产品很难解决行内实际需求，邮储银行依托软件研发中心建设能力，坚持自主研发，使用自研工具解决企业内部管理运行的问题，先后建设了 DevOps 研发协同平台、云图管理系统、星辰平台，这些系统平台在特定的流程节点上发挥效用，又在特定的流程节点上衔接串联，实现研发测试全流程管理，既满足各团队特征化使用需求，又符合组织级效能管理要求，助推整个组织高质量高效率运转。

  

  

**Q**

**贵单位参与本次系统和工具标准评估，请问企业有哪些考量？**

**A**

**胡军锋：**邮储银行始终坚持科技兴行，坚持创新驱动，坚持数字生态银行转型。一直关注业内前沿技术和未来发展趋势，并积极探索新技术、新方法应用于工程实践。DevOps 标准，是由中国信息通信研究院牵头，联合多个企事业单位专家制定的行业标准，通过与标准对标识别差距，借鉴标准最佳实践并进行持续优化改进，对落地 DevOps、提升研发效能有着重要意义。

  

我行从 2019 年开始建设 DevOps 能力，先后通过了《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估、系统和工具【流水线】【构建与持续集成】【接口/服务测试】3个模块优秀级评估、【安全及风险】2级评估。通过这些评估过程，产品研发能力进一步提升，在实际推广效果中看到较好成效，因此希望继续开展测试计划管理、测试用例管理、测试数据管理模块的能力评估，进一步夯实星辰平台系统能力，提升工程项目全流程管理的精细化程度和实施效率。

  

  

**Q**

**通过系统和工具标准评估带给企业和团队哪些变化？**

**A**

**胡军锋：**邮储银行“星辰平台”通过 DevOps 系统和工具【测试用例与计划管理】【测试数据管理】标准，体现我行的测试管理能力达到了行业领先水平。在评估过程中，与标准能力项进行持续对标，不断识别差距并完善改进，极大程度提高了邮储银行 DevOps 系统和工具能力，使得“星辰平台”更好的赋能业务产品研发过程。主要体现在以下方面：

  

一是完善测试管理过程，形成测试任务创建、测试计划变更、测试执行实施、测试数据管理、测试结果反馈全流程支撑能力。标准能力项为系统工具建设提供大方向的参考，改进过程深抠细节，体现标准在企业内部落地的实践方案，通过反复推敲打磨，将标准规则内嵌于系统平台，增强“星辰平台”全流程测试支撑能力。

  

二是提升团队成员凝聚力和战斗力。参与评估改进工作对于项目组成员都是一次历练和成长的机会，可以接触到行业领先的标准和最佳实践，开阔思维和视野，主动迎接挑战并努力取得胜利，通过此次评估，我们锻炼出来一批奋发有为、敢闯敢拼的青年骨干力量，这也是后续企业发展的宝贵财富。

**Q**

**通过本次评估，项目的改进成功体现在哪些方面？**

**A**

**张兰英：**大家好，我是中国邮政储蓄银行软件研发中心资深信息技术专家张兰英。本次评估，邮储银行对标标准能力项、对标同业最佳实践、对标行内工作实际，对“星辰平台”测试计划管理、测试用例管理、测试数据管理能力进行进一步优化完善，打通需求、版本、计划、用例、环境数据通路，实现全流程精细化测试过程管理。

  

在实际推广应用上，双鱼座任务与计划子系统已实现760+个工程，共2400+个子计划进行集中管理；狮子座用例与缺陷子系统累计支撑测试项目100+个，用例量达500000+个。猎户座测试环境子系统数据服务接入量 30+，日均造数量 300+，支撑项目组 30+。

**Q**

**在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?**

**A**

**张兰英：**在整个评估过程中，总体来说还是比较顺利的。各级领导对评估工作给予了高度的关注和支持，软件研发中心成立专班项目组，深入分析标准并探讨研究落地实现方案，各干系方同心协力，有序推进项目实施。

  

“星辰平台”于2021年进行规划建设，在评估项目启动时虽有一定积累，但距离标准要求还有一定的差距。项目组成员针对差距项启动三批次迭代改进工作，任务拆分到人到天，每日晨会开展进度对标，不断完善提升各个能力项指标。改进过程中，“星辰平台”还在同步支撑我行新一代核心系统的测试工作，双线并行的建设压力比较重，既要确保生产稳定有序，又要加速推进能力建设，项目组全体同事不畏艰辛、加班加点，最终顺利通过评估。

  

  

**Q**

**对于 DevOps 在测试领域的发力方向，下一步计划如何？**

**A**

**张兰英：**DevOps 通过工具、流程、技术赋能，促进需求、开发、测试、部署、运维环节之间的高效协作，实现 IT 全生命周期的标准化、自动化、智能化，助力工程交付效率与质量全面提升。

  

在测试领域，我们将充分借鉴前期已有的评估改进经验，也总结实施过程中的痛难点，构建 DevTestOps 持续测试体系，涵盖产品需求到线上运营所有环节，具备完整的度量和反馈机制，通过全流程闭环的持续流动和各环节内部的持续流动，达到快速验证业务的目标。在持续测试能力建设过程中，要建立规范的流程和管理机制，这是持续测试落实和发展的重要保障；要具备可靠的环境和数据能力，这是持续测试快速流转的基石；要打造一站式一体化平台，这是组织能力和公共价值的积淀；要建立可视化、实时的监控度量体系，及时发现个性化瓶颈，并持续解决优化。我们将借助 DevOps 持续测试能力建设与评估，打通测试过程的横向和纵向关联，以一系列自动化能力为基础完成软件产品的交付，将研发-测试-运维过程标准化、工具化、自动化，有效提升软件产品交付速度和质量。

  

  

**Q**

**对于 DevOps 的未来发展方向，您有何看法？**

**A**

**张兰英：**随着数字技术的不断进步，企业的研发运营体系正在向多元化方向发展，DevOps 向业务与 IT 技术相融合的 XOps 快速延伸。AIOps 利用大数据、云计算、人工智能等新技术，帮助运维人员快速发现异常，定位故障，预测容量趋势，保障业务系统稳定、安全、高效运行；BizDevOps 从业务价值管理、业务流程管理、协同支持、业务交付、业务运营等多方面入手，重塑服务流程。FinOps 从企业内部管理需求出发，打通 IT、财务、业务之间的视角差异，推动 IT 资源高效管理。ArchOps 对企业架构核心领域的设计以及相关交付物进行监督、控制、管理、审查和维护，保证自上而下的一致性与遵从性，实现资源与风险的优化，提升 IT 对企业经营贡献。

  

未来，邮储银行将紧跟 DevOps、XOps 发展趋势，不断探索将业界最佳实践与邮储银行实际工作相结合，将实际业务与 IT 技术相融合产生的最佳实践融入到研运一体化、效能度量、安全体系建设、智能化等多个方面，持续推进科技赋能，助力业务高质量发展。

**研发运营一体化（DevOps）能力成熟度模型介绍：**

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。![](../Images/42b82d9144a4c2539b650a9c17c46efd.png)![](../Images/e8a4867188405787515740cc4a29dc70.png)![](../Images/866f8509cca56339b54367efeaacd0f3.png)**DevOps 标准评估相关事宜，请联系：**中国信息通信研究院@刘凯铃电话：15650786171（同微信）
