国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

  

2023年4月7日，由高效运维社区（GreatOPS）和开放运维联盟（OOPSA）联合主办的第 20 届 GOPS 全球运维大会在深圳正式召开。GOPS 全球运维大会是国内第一个也是最大的运维行业大会，也是备受瞩目的千人峰会。大会主要面向互联网及金融、通信等传统行业广大运维、开发等技术人员，旨在传播先进技术思想和理念，分享业内最佳实践。

  

在本次会议上，**中国信息通信研究院隆重公布了 DevOps 能力成熟度最新批次评估结果****。**

  

南方电网数字平台科技（广东）有限公司（以下简称“南方电网”）本次参评的项目为**“****云燕平台DevOps子系统****”**，该项目顺利通过信通院《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具标准**“构建与持续集成”**和**“流水线”****两个模块的优秀级评估**，代表南方电网的 DevOps 系统和工具在相关模块达到国内领先水平。

  

目前，南方电网共通过 DevOps 系统和工具标准评估 3 项。

  

**评估单位：中国信息通信研究院**

  

**2023年4月7日在“2023 GOPS 全球运维大会·深圳站”主会场上，由**中国信息通信研究院云计算与大数据研究所副总工程师王蕴韬先生**为企业授牌：**

**Q**

**请介绍一下您和您的企业，以及此次参与评估的项目。**

**A**

数字平台科技公司是南方电网数字电网集团有限公司的全资子公司，在业务实践中积极对照集团职责定位，发挥南方电网数字化转型战略支援部队、数字电网建设主力军作用。公司紧密围绕数字电网建设，专注于数字基础支撑平台建设和企业资产域数字化、智能化开发、建设和服务。公司业务范围涵盖平台层南网云、中台、数据底座、统一研发平台、企业管理信息化业务、电网数字化与智能化等8类业务、12个业务域，具备完整的 IT 服务价值链能力和为客户提供全栈式解决方案的能力。公司同时正突出产品化发展方向，面向市场实现核心能力输出。

  

本次参与评估的云燕平台 DevOps 子系统，作为电网数字化平台建设技术支撑平台，通过提供研发协同、代码仓库、代码扫描、打包构建、自动化部署及自动化测试等敏捷研发所需的基础支撑能力，实现持续构建、持续集成、持续发布、持续测试，确保每次均达到统一的代码质量要求，满足敏捷开发的需求。评估内容为流水线和构建与持续集成模块，以项目组实际应用场景为指导，有效助力项目快速构建部署，提升高质量的软件交付，支撑南方电网数字化工程全面质量管理。

  

  

**Q**

**恭喜通过 DevOps 标准评估，此次贵公司项目通过的是系统和工具标准，请说一下您此时的感受。**

**A**

很荣幸能够参与中国信通院组织的研发运营一体化 DevOps 能力成熟度模型评估。我们参加了流水线、构建与持续集成能力项的评估，并且达到了优秀级水平，让我们备受鼓舞，对我们自研平台的前景充满信心，这是对数字平台科技公司在数字化转型与 DevOps 建设中成果的肯定。同时也非常感谢中国信通院专家老师提供的意见，感谢我们的团队以及一直给予我们支持的合作伙伴。

  

  

**Q**

**打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？**

**A**

云燕平台 DevOps 子系统通过打通需求、设计、开发、测试、部署、运维各个环节，实现持续构建、持续集成、持续发布、持续测试的能力，保证端到端的流程化、规范化、一体化，提升高质量的软件交付，支撑南方电网数字化工程全面质量管理。

  

  

**Q**

**贵单位参与本次系统和工具标准评估，请问企业有哪些考量？**

**A**

通过《研发运营一体化（DevOps）能力成熟度模型》中 IT 软件研发交付运营的使用方实施相关系统、工具和服务建设进行评价和指导，了解企业 DevOps 自身发展情况，发现问题，查漏补缺，明确未来持续优化的方向，进一步提升软件工程能力，以高质量数字化产品推进南方电网数字化转型。

  

  

**Q**

**通过系统和工具标准评估带给企业和团队哪些变化？**

**A**

团队以 DevOps 行业标准为抓手，内部试点操练，让 DevOps 实践在内部生根，内部人员充分理解和掌握 DevOps 的核心关键实践，并能够将其在项目中应用。通过“以评促改，以评促建”，充分利用标准中的要求来提升组织效能，在过程中将核心实践落入平台，打造平台基础服务能力。

  

平台聚焦于建设端到端的流水线，打通各个阶段环节的工具平台，沉淀总结提炼适合南网自身的研发模式，并将其固化到流水线平台，在组织内试点与推广，使平台具备稳定快速且高质量交付的能力。

**Q**

**通过本次评估，项目的改进成功体现在哪些方面？**

**A**

本次参评的是流水线、构建与持续集成能力项，我们根据现状发现问题，查漏补缺，通过打造一体化的工具链管理，实现流水线各个阶段流程化、标准化、规范化，有效提高了持续交付工具效率，构建成功率提升27%，部署成功率提升33%，构建阶段平均时长降低37%，流水线整体执行耗时降低34%。

  

  

![](../Images/676311501e68bd261c9d3dbc724a4a57.png)

  

**Q**

**在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?**

**A**

在参与流水线、构建与持续集成标准评估的过程中遇到了一些困难及挑战，我们结合专家指导建议与自身实践，顺利完成了评估，主要问题是协作及沟通成本较高，为降低协作成本，组建了跨部门和跨地域团队，共同研究能力项成熟度评估标准，团队成员对能力项标准的解读形成共识，参照业界优秀实践，稳步改进。

  

  

**Q**

**对于 DevOps 工作的开展，下一步计划有几方面？**

**A**

建立 DevOps 人才培养体系 ，解决工程教练能力无法对齐行业领先经验和高阶工程教练短缺问题，培养内部 DevOps 教练，持续赋能项目团队，持续纠偏，为项目持续稳定的高效交付提供保障。

  

根据成熟度模型进行差距分析，识别改进点，融合业务痛点，结合工具、流程、赋能、度量等维度逐步维稳推进，以用促建，进一步深化 DevOps 实践和方法论。

  

  

**Q**

**对于 DevOps 的未来发展方向，您有何看法？**

**A**

随着 DevOps 理念的广泛推广和应用，为电网数字化转型提质增效，企业的研发运营体系也在向多元化方向发展。

  

未来希望通过借鉴信通院发布的 DevOps 行业标准，能够在安全及风险管理、智能运维等领域深入实践，持续提升平台科技公司的 DevOps 能力，以标准化推动DevOps 高质量发展。

**研发运营一体化（DevOps）能力成熟度模型介绍：**  

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
