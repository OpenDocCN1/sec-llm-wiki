腾讯云宕机并道歉

据报道，3月29日凌晨2点左右，有部分用户使用微信、微信支付相关功能出现异常，同时，后经工程师抢修，系统正在逐步恢复。腾讯云发布公告：

由于机房配套设施故障，广州五区部分云产品（CLB、Redis、WAF、TKE、控制台等）出现服务异常现象，经工程师紧急修复，目前故障已恢复，非常抱歉对您的业务造成的影响。若您有任何问题，请随时联系我们处理。

国产数据库性能打破世界纪录，每分钟处理8.14亿笔交易

3月30日，据权威机构国际事务处理性能委员会（TPC，Transaction Processing Performance Council）官网披露，腾讯云数据库 TDSQL 性能成功打破世界纪录，每分钟交易量达到了8.14亿次——这标志着我国国产数据库技术取得新的突破。

中国工程院院士郑纬民表示：“国产数据库持续突破性能瓶颈，这是国内基础软件坚持长期投入的结果，也是走向科技自立自强的关键一步。”

数据库事关国计民生，小到每个人的日常购物、抢红包，大到银行核心系统的稳定运行，海量数据的存储、管理和调用都离不开数据库。当前，数据库亟需解决“卡脖子”问题，是中国必须坚持自主可控的关键技术。

由TPC发起的TPC-C是全球数据库厂商公认的性能评价标准，被誉为数据库领域的“奥林匹克”。它模拟超大型高并发的极值场景，同时有一套严格的审计流程和标准，对数据库系统的软硬件协同能力要求极高。

阿里重组为六大部门，阿里云可独立上市

阿里巴巴集团董事会主席兼首席执行官张勇28日发布全员信，宣布启动“1+6+N”组织变革。张勇在信中表示：“未来，具备条件的业务集团和公司，都将有独立融资和上市的可能性。”

全员信透露，在阿里巴巴集团之下，将设立阿里云智能、淘宝天猫商业、本地生活、菜鸟、国际数字商业、大文娱等六大业务集团和多家业务公司。

业务集团和业务公司分别成立董事会，实行各业务集团和业务公司董事会领导下的CEO负责制，阿里巴巴集团全面实行控股公司管理。

秘史公开：马斯克与 OpenAI 创始人的爱恨情仇！
近日，一封包括图领奖得主 Yoshua Bengio、特斯拉 CEO 伊隆 · 马斯克、纽约大学名誉教授 Gary Marcus 等 1000 位知名人士签名的公开信悄悄在互联网上发酵。

公开信链接：https://futureoflife.org/open-letter/pause-giant-ai-experiments/

这封信的内容想必很多关心科技界的盆友都有关注，但近日，一份关于马斯克和 OpenAI 创始人山姆 · 奥特曼之间早年纠纷，却被悄悄挖了出来……。

OpenAI 成立于2015年，由马斯克和里德 · 霍夫曼等科技界大佬共同创办。但2018年，马斯克断然撤销一笔巨额资金拂袖而去。

原因是马斯克为 OpenAI 的掌控权和运营的原因，被奥特曼和其他创始断然拒绝。这场冲突的后果，2018年2月20日马斯克宣布离开 OpenAI 并挖走了最优秀的人才加入到特斯拉。

外界曾以为是利益原因导致分道扬镳，可是据知情人士称，马斯克许诺的数年时间捐赠约10亿美元，在马斯克离开后即停止，这使得 OpenAI 无法支付在超级计算机上训练人工智能模型所需的巨额费用。

而在 OpenAI 上线后，这场冲突纠葛也从未停止，马斯克取消了 OpenAI 对 Twitter 的数据访问权限，并随后发推称，OpenAI 是一个开源的非营利性公司存在，但现在成了以利润为最大目标，受软件控制的公司。

腾讯副总裁、郄小虎离职

据报道，腾讯副总裁、PCG （平台与内容事业群）信息与服务线负责人郄小虎已离任。公开消息显示，郄小虎曾担任 Google 全球技术总监及谷歌中国研究院副院长。15年后，他曾先后加入小红书和滴滴任 CTO。有消息称，郄小虎离职后将进入AI相关领域行业，具体情况还不明晰。

滴滴云宣布不再对外提供公有云

近日，滴滴云发布公告，由于产品线调整，将于2023年3月31日00: 00 起不再对外提供公有云服务，如您账户中仍有余额或资源，请在2023年6月30日24:00前及时进行资源备份迁移和提交退款申请。
重磅！Twitter 源代码泄露，GitHub 连夜下架

国外某安全网站披露，Twitter 最近遭遇了一次罕见的源代码泄露事件，事件发生不久，Twitter 迅速向协作平台 Github 发送侵权通知，要求其删除泄露源代码。

目前还不清楚泄露源代码在网上发布多长时间，但至少已达数月。两名内部调查人士表示，Twitter 对此次泄露事件展开了调查。负责此事的高管称，责任人去年离开了公司。
谷歌与 Replit 联合发布编码工具，对抗 GPt-4 加持的 Copilot！

近日，为了与微软竞争，谷歌宣布与 Replit 达成合作，推出基于 AI 的智能编程，向微软的 GitHub Copliot 挑战。一周前，GitHub 发布轰动全球的 Copilot X。Copilot X 采用最新的 OpenAI GPT-4 模型，并引入聊天和语音功能，帮助开发者提升工作效率。
