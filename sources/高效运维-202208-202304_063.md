**Web 系统架构师**

1

**工作职责**

1.  开发面向三星半导体全球研发团队的 DevOps 平台软件产品架构，并在此架构上应用户需求，持续开发新 Service ，以满足各个事业部的需求。
    
2.  定义、调整和跟踪整个架构和模块设计（接口，灵活性，编译及设计规则）。
    
3.  确保各 Service 模块在一个统一系统架构里的可复用性。
    
4.  审核未来规划的产品和模块的需求，确认相关的技术可行性，并将新功能和技术集成到架构里。
    
5.  负责产品开发全流程监督和质量评审。
    

2

**工作经验与能力要求**

*   硕士研究生及以上学历，211/985院校优先。专业：计算机，电子，自动化及相关专业。
    
*   工作经验：软件开发项目经验8年及以上。2个以上大中型 Web 开发项目架构设计经验。
    
*   精通以下的开发技术及工具：  
    
*   **front** - end for web - based system : HTML / CSS , JavaScript , Node . js , React , Vue .
    
*   **back** - end for web - based system : Python , Java , JavaScript , Node . js / Express , RestAPI Server ( Flask / FastAPI ), Nginx , DB ( Mysql , postgreSql , redis ),
    
*   **Infra and tool** : Docker / Kubernetes , QuickBuild , Jenkins , Git / Gerrit , Github , Gitlab ,P4/Swarm Common : language : Python , JavaScript , Script language ( bash , sh )
    
*   **SCM / Branch Policy .**
    
*   **S / W development process ( Integration , Release ) S / W Architecture design **
    
*   **Agile practice , DevOps practice .**
    
*   **Android development** : Android Platform Build / Build Script .
    
*   **Android Device Control ( ADB , fastboot )**
    
*   熟悉多种 Web 前端、后端框架，对产品需求和设计有深刻的理解，不断优化产品设计。
    
*   熟悉软件开发过程，软件构建与发布等软件工程知识。
    
*   良好的中英文书面和口语表达，精通韩语者优先。
    
*   有项目管理经验者优先。
    

3

**个性要求**  

1.  具有良好学习能力、团队合作精神，富有责任感与主动性；
    
2.  能够接受并快速适应具有挑战性的任务；
    
3.  自我激励，追求结果，创新思维。
