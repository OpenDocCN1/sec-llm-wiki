百度正式发布文心一言：对标 ChatGPT

3月16日，百度正式发布知识增强大语言模型“文心一言”，文心一言对标 ChatGPT，甚至 GPT-4。李彦宏表示在全球大厂中，这样的产品百度率先发布。在现场，百度展示了文心一言在文学创作、商业文案、数理逻辑、中文理解和多模态生成方面的能力。既可以续写《三体》，还可以给科技公司起名字、写 slogan、写新闻稿，还可以解鸡兔同笼问题。

OpenAI正式发布GPT-4：10秒出一个网站，1分钟开发一个游戏

就在“文心一言”发布2天前，OpenAI 宣布发布多模态大模型 GPT-4，该模型实现了几个重大的突破：具备强大的图像识别能力、能够输入长达2.5万字的文本、回答的准确性也显著提高。

此外，GPT-4 还能够生成歌词、创意文本以及模拟不同的风格。尽管 GPT-3.5 和 GPT-4 之间的差异微妙，但当任务的复杂性达到一定阈值时，GPT-4 显得更加可靠，并且能够处理更为精细的指令。为了了解这两个模型之间的差异，OpenAI 对它们进行了多种基准测试和人类设计的模拟考试。值得注意的是，GPT-4 在图像输入方面表现得更加出色。例如，当给 GPT-4 一个奇怪的充电器图片时，它能够回答为什么这张图片很好笑：

Docker将删除开源组织

日前，Docker 向所有创建了 “组织” 的 Docker Hub 用户发出一封电子邮件，提醒称如果不升级至付费团队计划，他们的账户乃至所有镜像都将被删除。邮件中还随附一条 PDF说明文件链接。但由于邮件和文件都很简短、缺乏细节，因此给整个开源维护者群体带来了巨大的冲击和焦虑情绪。

此次决定只会影响开源社区内的活跃用户，个人账户不受影响，免费个人账户将保留6个月，而组织托管公共镜像的成本将从0美元/年上传至420美元/年。

微软投资数亿美元建造驱动 ChatGPT 的超算
3月15日凌晨，OpenAI 发布多模态预训练大模型 GPT -4，你知道 GPT-4 背后是什么在提供支持吗？
近日，微软斥资数亿美元建造驱动 AI 聊天机器人 ChatGPT 的超算。微软称它在其 Azure 云计算平台使用了数以千计的英伟达 GPU，以为 OpenAI 的项目提供强大的运算能力，帮助 OpenAI 训练愈来愈强大的模型，解锁 ChatGPT 和 Bing 等工具的 AI 能力。微软使用了英伟达的 H100 和 A100 Tensor Core GPU，以及 Quantum-2 InfiniBand 网络。这能为 OpenAI 以及其它公司训练更大更复杂的 AI 模型。
美国要求字节跳动出售其持有的 TikTok 股份
据《华尔街日报》报道，美国拜登政府要求 TikTok 的中国所有者出售其股份，否则该应用可能会在美国被禁。
TikTok 高管曾表示，总部位于北京的母公司字节跳动有 60% 的股份由全球投资者持有，20% 由员工持有，另外 20% 由创始人持有。创始人的股份拥有超额投票权。
TikTok 周三表示，强制出售持股并不能解决所谓安全风险。该公司承诺往一项计划投入 16 亿美元，以保护美国用户数据和内容。
放大招！谷歌开放大语言模型 PaLM API

3月15日，谷歌开放自家的大语言模型 API 「PaLM API」，此外今天谷歌还发布了一款帮助开发者快速构建 AI 程序的工具 MakerSuite。谷歌表示，此举是为了帮助开发者们快速构建生成式 AI 应用。

谷歌介绍称，PaLM API 是 Google 大型语言模型的入口，可用于各种应用程序。它将为开发者提供面向对轮交互而优化的模型，如内容生成与对话。它也能为开发者提供摘要、分类等多种任务的通用模型。

Stack Overflow：开源、云计算和机器学习是最得到认可的技术

Stack Overflow 调查了数千名开发者，询问哪些新兴的技术趋势已经证明了自己。它将一个技术根据 0-10 的尺度进行评分，其中 0 代表实验性，10 代表已被证明。

结果显示，被认为已获得证明得到广泛认可的技术是开源 6.9、云计算 6.5 和机器学习 5.9，被认为尚未证明的技术包括量子计算 3.7，纳米技术 4.5，低代码/零代码 4.6。
对于下一个人人都将使用的技术，AI 高居第一，之后是开源、机器学习和云计算。调查还根据 0-10 的尺度对一项技术产生正面还是负面影响进行评价（0 代表负面，10 代表正面），结果显示开源技术得分最高 7.2，可持续技术 6.6，机器学习 6.5。
低代码/零代码的评价非常低，这可以理解，因为这可能会对部分开发者的职业安全产生冲击。大多数开发者认为，低代码/零代码以及区块链在未来不会广泛使用。
