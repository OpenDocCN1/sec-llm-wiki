# 进击的价值交付：招行适配云的 BizDevOps 怎样进化而来？| 活动通知

![](../Images/1f71d78e24a261bc871356134816ba6a.png)在招行从 Incloud 到 Oncloud 云时代变革背景下，BizDevOps 工具链要打通从业务到开发再到运维的整个流程，充分发挥上云后的优势，实现业务、产品和运维的有机融合，形成高效的业务交付、运行和反馈闭环，打造一站式的研发管理平台。**2023年4月7日-8日，第20届 GOPS 全球运维大会 · 深圳站**，**招商银行总行信息技术部 EPG 组核心成员、DevOps 资深专家、BiZDevOps 工具平台负责人陈展文老师**将和你探讨，如何找到切入点，形成整体平台建设的解决方案，如何应对建设过程中遇到的管理、技术等多重挑战。

**陈展文**

招商银行总行信息技术部

 EPG组核心成员 DevOps资深专家

BizDevOps工具平台负责人

  

**个人简介**

陈展文，招行服务19年，伴随招行信息技术部从 200多人发展到10000多人的规模，获得了PMP、CSM、CSPO、CSP、DOF、DOP、AWS、CSAA认证。2015年开始牵头研究和推进招行 DevOps 持续交付实践落地，推动招行 DevOps 到 BizDevOps 升级，牵头建设流水线，并在2022年通过信通院（DevOps）能力成熟度模型“卓越级”评估，该案例也同时入选“2022IT新治理年度卓越创新案例”。

  

**听众收益**  

了解 BizDevOps 工具链从业务到开发、到运维打通的整个流程。了解 BizDevOps 产品如何发挥上云优势，实现业务、产品的有机融合，提升服务和体验。
