国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。
2022年12月26日，中国信息通信研究院（简称“中国信通院”）隆重公布了 DevOps 系列标准最新批次评估结果。
中国银河证券股份有限公司（以下简称“银河证券”）参与评估的项目为中国银河证券CMDB平台，该项目顺利通过中国信通院《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具标准【配置管理】模块的优秀级评估，代表银河证券的 DevOps 系统和工具在相关模块达到国内领先水平。
评估单位：中国信息通信研究院
2023年1月6日在“2022 GOLF+IT新治理领导力论坛”主论坛上，由中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：
此次，我们采访了中国银河证券副总经理罗清平先生、中国银河证券信息技术部基础平台团队负责人张冰先生，一同深聊团队在项目参与评估时的细节和故事，分享交通银行 DevOps 实践的经验。
- Q&A - 

中国银河证券副总经理 罗清平

Q：老师您好，请介绍一下您和您的企业，以及此次参与评估的项目/工具
罗清平：中国银河证券股份有限公司，是中国证券行业领先的综合金融服务提供商。公司在国内拥有证券市场业务全牌照以及覆盖较广的营业网络，海外业务遍及全球9个国家和地区，是国内分支机构最多、亚洲布局最广的证券公司。

公司坚持金融科技驱动，全面推进金融科技战略，加强人工智能、大数据云计算、区块链等新技术与业务的深度融合，打造“智能银河”，中国银河证券信息技术部包括正式员工约400人，负责公司整个IT 300多套生产系统的开发运行，本次通过《研发运营一体化（DevOps）能力成熟度模型》系统和工具标准评估的系统为中国银河证券CMDB平台。

中国银河证券 CMDB 平台由信息技术部基础平台团队负责研发运营，包含了软件、硬件、虚拟资产、基础资源等大类资产模型，并根据应用消费场景，建立了模型间的关联关系。从应用系统到服务器中间件，从安全设备到网络设备，拥有面向IaaS、PaaS、SaaS层全面的资源管理能力。CMDB打通了与云管平台、带外系统、青藤云系统、观星台系统等周边系统，在数据质量充分保证的基础上，拓展了多个消费场景，如支持了公司的信创实施情况跟踪，网络安全攻防演练资产树构建，IP资源管理，机房数字孪生等。

Q：恭喜您通过 DevOps 标准系统和工具评估，您的感受是怎样的？

罗清平：很高兴由我司自研的 CMDB 平台能通过信通院 DevOps 系统和工具标准中配置管理模块的评估，这是我司通过的第一个DevOps系列标准评估，也是配置管理评估模块首个参评并获得优秀级水平的项目，这是对我司 CMDB 平台的巨大肯定。在准备评估的改进过程中，我们投入了开发力量对平台进行了功能规划和开发，提升了平台的效能，我们切实感受到DevOps理念技术在落地过程中对IT过程管理。接下来我们将继续在DevOps 技术应用上深耕，为公司运营提供数据支撑，推动公司数字化转型。

Q：贵单位参与本次 DevOps 标准系统和工具标准评估，请问企业有哪些考量？

罗清平：中国银河证券CMDB平台是中国银河证券一体化平台的一个模块。一体化平台作为运维门户，基于一套架构，一个代理，一组接口集成了包括CMDB系统、监控系统、ITIL流程系统、RPA系统等多个运维工具模块，从管理上形成运维的闭合环路，确保系统的高效、安全、稳定、可靠运行。在建设该平台的过程中，我们觉得平台整体与评估标准《研发运营一体化（DevOps）能力成熟度模型》相关理论比较契合，系统与工具标准的配置管理模块所要求的IT资源全生命周期管理能力，自动发现能力，与第三方平台的集成能力等，都是我司CMDB平台设计中极为强调的点。回顾评估与改造的过程，我们通过该项目达到了预期效果，完善了CMDB平台的功能，提升了银河一体化运维平台的研发、运维整体能力水平。

Q：通过 DevOps 标准系统和工具标准评估带给企业和团队哪些变化？

罗清平：通过本次评估，达到了以评促改、以评促建的目的，对我司CMDB平台的工具执行效率、支撑能力等提升都是非常明显的。本次评估，中国银河证券CMDB平台对标系统与工具标准的配置管理能力项，充分学习和借鉴标准，根据现状找差距，对流程和系统进一步优化，有效提高了CMDB的数据支撑能力。

在CMDB平台的评估改进过程中，我部也得到上级领导的大力支持，以应用系统为中心，在公司IT层面统一了认识，发布了《中国银河证券股份有限公司信息技术配置管理实施细则》。我们将研发运维过程标准化，形成完整闭环，很好地满足了跨部门、跨团队的高效协同，相信对于参与评估、制定制度的每个人都是一次很好的学习成长机会，这次评估提升了整个团队的能力，开阔了视野，也明晰了我们未来的优化方向。

中国银河证券信息技术部 基础平台团队负责人 张冰

Q：对于 DevOps 工作的开展，下一步计划有几方面？

张冰：还是要特别感谢信通院专家的指导，在本次评估中我们获得了优秀级的评估，且我司所提供的两大创新点，数字孪生与IP资源管理，都得到了评委专家组的认可。中国银河证券CMDB平台作为一个快速迭代发展的平台，还有很多方面需要进行优化，正如 DevOps 体系闭环一样，完善没有止境，CMDB 的建设仍是一个持续迭代优化过程，后续我们将根据信通院专家指出的指导意见，继续完善我司CMDB平台，争取在未来完成评估升级（卓越级），同时我们将争取打通智能知识库与CMDB平台，实现配置项智能化自动发现，图形化元数据关系展示以及数据异常自动化修复等。

Q：对于 DevOps 的未来发展方向，您有何看法？

张冰：随着 DevOps 的广泛应用和金融科技的不断进步，企业的研发运营体系正在向多元化方向发展。同时，人工智能已经改变了企业的运营方式，通过简化和加速 SDLC 的每个阶段，将 DevOps 生态系统提升到一个新的水平。人工智能注入使组织能够将超级自动化引入 DevOps，将减少甚至消除从代码更改到部署的整个流程中人工干预的需要，使用人工智能增强应用程序和基础设施监控以实现 IT 运营能力。作为企业，应该顺应DevOps 趋势，推动内部IT转型，将其融入到研运一体化、效能度量、安全体系建设等多个方面，帮助企业提升运营水平，推动业务价值高效交付，助力企业数字化转型。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
