# 燃！招商银行荣获中国信通院2022年度IT新治理评选活动【年度领军企业】【年度卓越创新案例】荣誉

2023年1月6日，由中国信息通信研究院、中国通信标准化协会主办，中国内部审计协会、中国互联网协会信息技术（IT）风险治理工作委员会支持的“**2022 GOLF+ IT新治理领导力论坛**“在北京成功召开。

论坛上，**中国信息通信研究院云计算与大数据研究所副所长魏凯先生隆重公布了”2022年度IT新治理评选活动“结果**。其中，招商银行股份有限公司荣获“**年度领军企业**”“**年度卓越创新案例**”两项荣誉。

该评选活动由信通院牵头组织，聚焦具有行业领导力、创新力的企业、团队、个人以及解决方案产品，被誉为IT治理领域的风向标。

在当前数字经济背景下，国家越来越重视企业IT治理，在以数字化、信息化、智能化为特征的科技变革浪潮中，招商银行提出了价值驱动的“6+2”精益管理框架。以“价值驱动，质量为先”为原则，在流程、工具、和人才赋能三方面建立一套完整的价值驱动的精益管理标准化体系，并构建相匹配的工具平台，以产品思维为导向，对齐业务战略和目标，促进业务和IT高效协作、责任共担、面向价值快速响应、持续交付。该体系融合CMMI、精益思想、设计思维、精益创业、敏捷开发、看板方法、精益产品开发、DevOps等先进方法实践，很好的解决大型金融企业多职能部门之间高效协同、共同决策和交付业务价值的痛点问题，大幅提升交付速度和效能。长远来看，招行精益管理体系和精益之星平台的持续完善及未来在行业内的推广应用，为我国金融业的数字化转型提供可借鉴的经验。

招商银行的“精益之星-流水线”在本次卓越创新案例评选活动脱颖而出，这是继今年在DevOps能力成熟度评估中获取“卓越级”之后，又获得的一项在业内具有影响力的荣誉。招行也是目前国内首家在“流水线”类被评定为“卓越级”的企业。评审专家对“精益之星-流水线”给予了很高评价，认为其在技术、架构、创新、成效上满足所有要求，在性能上很好地支撑了全企业的持续集成和持续交付，各项运行数据表现优秀，同时在用户体验、智能化运营等方面有多项自主创新，平台对招行科技研发质量和研发效能的支撑能力表现出色，整体水平位于行业前列。

回顾过去几年的历史，招商银行在精益管理和DevOps领域持续获得业界认可，包括：2018年-2020年先后有25个交付团队通过信通院《研发运营一体化（DevOps ）能力成熟度模型》三级评估，是国内通过评估最多的企业；2021年12月，招行工程效能团队在参选的数百家企业中，用优秀的实力突出重围，荣获“2021 GOLF+IT新治理领导力论坛”年度评选“2021年度影响力团队”荣誉；2022年10月，在信通院《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具评估中，招商银行的“精益之星-流水线“顺利通过评估。

招商银行将以此次荣誉为新的起点，坚持创新引领、科技驱动，进一步深耕基础研究，促进业技融合和价值创造，不断推进数字化转型。构建多元化研发运营标准体系，加速产业数智化转型，加强行业内的交流分享，在行业中发挥示范引领作用。
