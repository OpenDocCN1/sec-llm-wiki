# 燃！南方电网通过 DevOps 系统和工具标准评估，相关项目能力达到国内领先水平

国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

2022年12月26日，**中国信息通信研究院（简称“中国信通院”）隆重公布了 DevOps 系列标准最新批次评估结果**。

南方电网数字平台科技（广东）有限公司（以下简称“数字平台科技公司”）参与评估的项目为**云燕平台DevOps子系统**，该项目顺利通过中国信通院《研发运营一体化（ DevOps ）能力成熟度模型》**系统和工具标准【用例与测试计划管理】模块的优秀级评估**，代表南方电网的 DevOps 系统和工具在相关模块达到国内领先水平。

数字平台科技公司是首批通过 DevOps 系统和工具标准【用例与测试计划管理】模块的企业。  

**评估单位：中国信息通信研究院**

**2023年1月6日在“2022 GOLF+IT新治理领导力论坛”主论坛上，由中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：**

![](../Images/06d2b8781502eba6750b08411b2b6e44.png)

此次，我们采访了数字平台科技公司研究中心总监杨漾女士和研究中心副总监沈宇红女士，分享数字平台科技公司 DevOps 实践的经验。

**\-Q&A-**

![](../Images/3884ef8094fb58400966f18ca703eacd.png)数字平台科技公司

研究中心总监 杨漾

**Q：**** 您好，请介绍一下您和您的企业，以及此次参与评估的项目。**

**杨漾：**数字平台科技公司紧密围绕数字电网建设，专注于数字基础支撑平台建设和企业资产域数字化、智能化开发、建设和服务。业务范围涵盖平台层南网云、中台、数据底座、统一研发平台、企业管理信息化业务、电网数字化与智能化、网络安全系统及产品等8类业务、12个业务域，具备完整的IT服务价值链能力和为客户提供全栈式解决方案的能力，是南方电网数字化转型的战略支援部队、数字电网建设主力军。同时正突出产品化发展方向，面向市场实现核心能力输出。

本次参与评估的云燕平台DevOps子系统，作为电网数字化平台建设技术支撑平台，通过提供研发协同、代码仓库、代码扫描、打包构建、自动化部署及自动化测试等敏捷研发所需的基础支撑能力，实现持续集成、持续构建、持续测试、持续发布，确保每次均达到统一的代码质量要求，满足敏捷开发的需求。评估内容为用例与测试计划管理模块，以测试实践为指导，有效助力开发和测试团队衔接，提升高质量的软件交付，支撑南方电网数字化工程全面质量管理。 

**Q： 恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是系统和工具标准中的【用例与测试计划管理】，为首批通过此评估的企业，请说一下您此时的感受。**

****杨漾：****很荣幸能够参与中国信通院组织的研发运营一体化 DevOps 能力成熟度模型评估。我们参加了“用例与测试计划管理”模块的首批评估，并且达到了优秀级水平，让我们备受鼓舞，对我们自研平台的前景充满信心，这是对数字平台科技公司在数字化转型与 DevOps 建设中成果的肯定。同时也非常感谢中国信通院专家老师提供的意见，感谢我们的团队以及一直给予我们支持的合作伙伴。

**Q：根据国内外企业实践表明，系统和工具赋能是企业成功的关键所在，您对这块的重要性怎么看？**

**杨漾：**在中国信通院指导下，我们顺利通过 DevOps 能力成熟度评估，标志着数字平台科技公司的用例与测试计划管理达到行业领先水平。

系统和工具赋能可以帮助企业提升IT效能，在保证稳定的同时，快速交付高质量的软件及服务，灵活应对快速变化的业务需求和市场环境。云燕平台DevOps子系统为电网数字化转型项目提供研发全生命周期管理所必要的环境、工具，覆盖需求、开发、构建、部署、测试等研发全过程的各个环节，在南方电网数字化转型及敏捷赋能方面起着重要的支撑作用。

**Q：贵单位参与本次系统和工具标准评估，请问企业有哪些考量？**

**杨漾：**通过《研发运营一体化（DevOps）能力成熟度模型》中IT软件研发交付运营的使用方实施相关系统、工具和服务建设进行评价和指导，了解企业 DevOps 自身发展情况，发现问题，查漏补缺，明确未来持续优化的方向，进一步提升软件工程能力，以高质量数字化产品推进南方电网数字化转型。

![](../Images/f281a7a5972578b8f724a30cc2f26f25.png)数字平台科技公司

研究中心副总监 沈宇红

**Q：通过系统和工具标准评估带给企业和团队哪些变化？**

**沈宇红：**团队以 DevOps 行业标准为抓手，内部试点操练，让 DevOps 实践在内部生根，内部人员充分理解和掌握 DevOps 的核心关键实践，并能够将其在项目中应用。通过“以评促改，以评促建”，充分利用标准中的要求来提升组织效能，在过程中将核心实践落入平台，打造平台基础服务能力。

平台聚焦于建设端到端的流水线，打通各个阶段环节的工具平台，沉淀总结提炼适合南网自身的研发模式，并将其固化到流水线平台，在组织内试点与推广，使平台具备稳定快速且高质量交付的能力。

**Q：通过本次评估，项目的改进成功体现在哪些方面？**

****沈宇红：****本次参评的测试管理模块涵盖测试用例、接口测试、测试计划、统计分析等，兼容主流开源标准，协助开发团队和测试团队共享协作，实现测试管理全过程跟踪可视化，加速高质量的制品交付，促进了数字平台科技公司数字化项目在测试管理方面的流程化、标准化、规范化，提升了数字化项目建设的测试质量水平。

![](../Images/0349feb680e6517d8836a32cb5d05579.png)

**Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?**

****沈宇红：****在参与用例与测试计划管理标准评估的过程中遇到了一些困难及挑战，我们结合专家指导建议与自身实践，顺利完成了评估，主要问题是协作及沟通成本较高，为降低协作成本，组建了跨部门和跨地域团队，共同研究能力项成熟度评估标准，团队成员对用例与测试计划管理的解读形成共识，参照业界优秀实践，稳步改进。

**Q：对于 DevOps 工作的开展，下一步计划有几方面？**

****沈宇红：****建立 DevOps 人才培养体系 ，解决工程教练能力无法对齐行业领先经验和高阶工程教练短缺问题，培养内部 DevOps 教练，持续赋能项目团队，持续纠偏，为项目持续稳定的高效交付提供保障。

根据成熟度模型进行差距分析，识别改进点，融合业务痛点，结合工具、流程、赋能、度量等维度逐步维稳推进，以用促建，进一步深化 DevOps 实践和方法论。

**Q：对于 DevOps 的未来发展方向，您有何看法？**

****沈宇红：****随着南方电网数字化转型持续深入推进，研发运营体系逐渐多元化，XOps将是数字化转型的有力抓手。

DevOps 子系统实现从需求/问题的提出，到研发过程支撑和跟踪，研发过程逐步量化，实现端到端的持续交付，并获得大量研发历史数据。

AIOps智能运维从系统中抽取分析历史数据，面向用户提供服务、提供智能运维决策模型的自动化决策支撑。

DevSecOps促进开发人员、安全人员和操作员之间的协作，通过软件制品及运行环境进行多层分析,了解漏洞/许可证合规性和质量,持续提升制品的安全。

下一步将继续沿着 DevOps 标准的思路持续完善体系化工作，结合南方电网数字化转型高质量建设要求，整体提升产品交付质量。

**研发运营一体化（DevOps）能力成熟度模型介绍：**《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
