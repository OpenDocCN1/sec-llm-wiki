# 农行DevOps实践丨全文检索服务平台DevOps实践，助力中国农业银行数字化转型

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651729466&idx=3&sn=63311f991b6257a66fe46bd1459e23e2&chksm=8bc8ed93bcbf6485e75bd4d5ab916c1b855d845e089fa843037367a37787dfe673f561d73776&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651729466&idx=3&sn=63311f991b6257a66fe46bd1459e23e2&chksm=8bc8ed93bcbf6485e75bd4d5ab916c1b855d845e089fa843037367a37787dfe673f561d73776&scene=27#wechat_redirect)

2022年12月26日，中国信息通信研究院隆重公布了 DevOps 系列标准及 AIOps 系列标准最新批次评估结果。中国农业银行股份有限公司（简称“中国农业银行”）本次共有 **9** 个系统模块通过中国信息通信研究院《研发运营一体化（ DevOps ）能力成熟度模型》系列标准总计** 11 项**评估。其中，中国农业银行参评项目--**全文检索服务平台（ARROW）**顺利通过《研发运营一体化（DevOps）能力成熟度模型》**持续交付标准三级**评估。

在2023年1月6日举行的“2022 GOLF+IT新治理领导力论坛”主论坛上，**中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为中国农业银行进行了授牌**。

**全文检索服务平台DevOps持续交付建设**

ARROW定位于中国农业银行统一智能化搜索服务平台，为行内各应用系统提供标准的一站式企业级搜索服务。ARROW对标业界最佳实践，遵循中国农业银行 DevOps 工程规范，借助一站式工具平台、研发工具链和运营工具链，利用可靠可重复的流水线实现相关质量门禁的检查，完成持续集成和持续部署，实现产品快速迭代。在研发过程中，ARROW建立敏捷型团队，以交付高质量产品为导向，快速应对检索业务需求变化，提升智慧检索业务服务能力和持续交付能力。  

*   **确立目标**
    

ARROW响应中国农业银行 DevOps 工程建设要求，应用管理链、研发链、测试链和运维链工具，搭建流水线，实现从需求受理到版本发布的一站式、可追溯、全自动化流程，为研发赋能，助力研发提效。

*   **持续交付**

![](../Images/207aa2eef73119333ec9280f3b87c3cb.png)

ARROW的流水线覆盖产品研发、测试及投产上线全流程。流水线中设置了单元测试、代码合规检查、源代码安全检查、接口自动化测试、接口覆盖率、开源组件漏洞扫描等质量门禁，提升交付产品质量。使用线上代码评审，代码多人复核，降低了代码缺陷率。配置精准通知，保障相关人员第一时间知晓流水线状态，快速诊断和解决流水线问题，防微杜渐，提升工作效率。

*   **驱动改进**

![](../Images/a60435135151daa22539f4a22c03bbaf.png)

ARROW将度量反馈问题纳入研发迭代的待办事项列表，作为持续改进的一部分。通过分析重复代码，进行代码精简，提升代码质量，使代码重复率降低92.8%，平均圈复杂度降低7.3%，最大圈复杂度降低42.3%，后端代码违例数降低90%。

*   **赋能增效**

![](../Images/55a9d50ac8dc385486153c0e792a9c84.png)

DevOps 赋能ARROW快速交付能力和持续部署能力，实现研发与测试高效协同、需求研发过程快速迭代、端到端全链路交付无缝衔接，提升了产品交付效率和质量，便于快速满足行内应用系统提出的检索需求，为实现高效、稳定检索服务奠定了基础。

**0****2**  
**DevOps持续交付实践体会**

![](../Images/dccf3d1214f1978bd23e867514700d91.png)

*   **提升项目管理粒度**

精细化拆分需求，基于任务项开发，滚动更新任务项状态，直观展示项目需求完成进度，实现了从需求到产品发布的交付链条全流程可追溯和可视化。

*   **提升产品交付效率**

应用与配置分离，能够让研发人员专注于代码开发，无需关心构建与配置，保证单一制品的不断晋级，实现所测即所投。利用统一的部署工具实现一键部署，减少了重复性工作，大幅降低了部署时长，提升了产品交付效率。

*   **提升产品交付质量**

研发团队采用TDD测试驱动开发模式，以测试驱动需求研发，基于迭代开发的不断重复，将需求转化为具体的测试用例和功能代码。借助可视化代码评审工具，引入多种质量门禁，利用丰富的自动化测试，提升整体测试效率和质量，保障了产品交付高标准。

**0****3**  
**总结**

为贯彻落实中国农业银行数字化转型战略，全文检索服务平台践行研发运营一体化标准，实现了业技融合、研测一体高效协同、全链条密切协作，有效提升了代码质量和产品交付质量，顺利通过信通院 DevOps 持续交付标准三级评估，为金融同业输出优秀、全面的 DevOps 最佳实践。全文检索服务平台以评估标准为抓手，以交付成果为基础，持续提升业务交付水平和迭代创新，满足全行各应用系统检索需求，助力中国农业银行在数字化转型的浪潮中乘风破浪。未来，全文检索服务平台将继续强化检索服务创新能力，打造稳定、高效的智慧检索服务，助力解决 DevOps 建设中的难点问题，为 DevOps 标准体系建设贡献力量。

**研发运营一体化(DevOps)能力成熟度模型介绍：**  

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
