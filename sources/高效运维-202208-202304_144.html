国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

2022年12月26日，中国信息通信研究院隆重公布了 DevOps 系列标准最新批次评估结果。

平安壹钱包电子商务有限公司（以下简称壹钱包）本次参评的项目为AJ（AgileJoin）产研一体化全流程协同平台，该项目顺利通过信通院《研发运营一体化（DevOps）能力成熟度模型》系统和工具标准平台全面级评估。

壹钱包是首家通过系统和工具持续交付全面级的企业，通过4个模块评估，分别为“构建与持续集成”、“流水线”、“制品管理”和“部署管理”。代表壹钱包在 DevOps 相关领域能力达到国内先进水平。
评估单位：中国信息通信研究院
2023年1月6日在“2022 GOLF+IT新治理领导力论坛”上，由中国通信标准化协会副理事长兼秘书代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：

此次，我们采访了平安壹钱包CTO 吴鹏越先生、平安壹钱包工程效能平台团队负责人王宇女士、平安壹钱包项目管理部架构师、敏捷教练杨大鹏，一起深聊团队在项目参与评估时的细节与故事，分享平安壹钱包 DevOps 实践经验。

- Q&A - 

平安壹钱包 

CTO 吴鹏越

Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。

吴鹏越：平安壹钱包（下称“壹钱包”）是中国平安旗下专注于支付、账户、积分领域提供数字化解决方案的公司，拥有多元化支付经营资质，和合作伙伴联合共建，在金融支付、定向商城服务、车生态、健康生态等领域赋能企业客户，为用户提供“省心、省时、又省钱”的客户体验。
本次参评的项目是壹钱包自研的AJ（AgileJoin）产研一体化全流程协同平台。该平台可持续帮助企业实现需求规划、研发过程、持续交付、价值检视的全流程协同，同时还具备数据呈现、数据分析等功能。AJ平台是壹钱包敏捷转型及平台工程建设的重要成果，壹钱包始终坚持科技平台赋能的战略方向，于2021年启动产研一体化敏捷转型及工程效能体系建设，旨在解决企业产研一体化协同难题，提升企业稳定并快速交付高质量软件及服务的能力。经过1年多建设和实践，最终成功建立了涵盖需求、研发、投产、生产运营全生命周期的一体化平台，有效支撑了企业效能提升与数字化转型工作。
Q：恭喜贵公司国内首家通过《DeveOps能力成熟度模型-工具与系统》持续交付平台全面级评估，参评的流水线、部署管理等多个模块均高分通过评估，请说一下您此时的感受。
吴鹏越：很高兴AJ项目顺利通过评估，尤其是作为国内首家通过持续交付平台级评估的企业，我们倍受鼓舞，说明壹钱包相关平台能力已获得业界权威认可。感谢各位专家对壹钱包 DevOps 平台综合能力水平的高度肯定，更感谢各位专家在评估过程中的建设性意见，也为我们下一步的改进指明了方向，更加坚定了我们深化推进 DevOps 技术体系建设的信心与决心。壹钱包科技团队将继续开拓创新，积极向同业同行优秀实践学习，不断提升 DevOps 建设水平，为推动行业加快数字化发展步伐做出更大贡献。

Q：贵公司是如何决定加入 DevOps 标准评估工作中的？

吴鹏越：信通院牵头制定的《研发运营一体化（DevOps）能力成熟度模型》是行业内最完整、最权威、最具行业指导性的 DevOps 能力标准之一。而平安壹钱包作为以支付科技为核心的平台型金融互联网企业，坚持科技驱动，不断打造更好的工具平台。我们的 DevOps 能力代表了科技团队在支持业务持续发展方面的专业能力，但在这个体系的建设过程中，不应闭门造车，而是要践行精益敏捷思想，学习业界优秀实践，对标业界先进标准，这样才能少走弯路，不断夯实基础，实现持续改进，我们期待能受到行业权威标准的检视与认可，提升团队研发交付效率、提升业务平台及产品的建设质量。
因此我们非常积极地准备本次 DevOps 标准评估工作，贯彻“以评促建，以评促改”，以评估为抓手检验我们的建设水平，进一步明确未来的建设方向，从而实现组织效能改进，助力企业数字化转型。

平安壹钱包 工程效能平台 

团队负责人 王宇

Q：请介绍下此次参评的项目特色，当时是如何规划和设计的？

王宇：此次参评项目是端到端的一站式产研一体化全流程协同平台，平台整合了底层基础服务群，高可视化展示CICD全过程，并具备多维度度量能力，能够更好推动 DevOps实践落地。

业务架构方面，我们采用领域驱动设计，打造构建领域模型，划分好领域的限界上下文，并以限界上下文作为微服务拆分和设计的边界，做业务核心逻辑的编排；
应用架构方面，分为展示层、应用管理层、应用支持层，应用数据层、基础层；
而技术架构和数据架构方面，则与我们的业务系统保持一致，依托公司已有能力，实现应用的高可用、可扩展、易运维。

Q：此次通过评估的过程顺利吗？遇到什么困难？如何解决的？

王宇：评估过程还是有一些波折的，比较大的困难有三点。

  • 第一点，要在短时间内分析识别出评估差距，确认改进点，并完成平台改造，且一定要保证系统稳定性和可用性，毕竟这是一个供全公司使用的线上平台；

  • 第二点，我们发现完成改造不仅关系上下游关联应用，甚至还关系流程以及使用方式方面的改造，现有各种流程都是经过以往的论证和实施验证所沉淀下来的，其不经过再次详细论证而轻易改造，容易使得以往期望通过流程规避的风险重新发生，需要慎之又慎；

  • 第三点，DevOps体系建设是整体能力的提升，在改进过程中也暴露了我们自动化测试、日志实时监控查询等平台工具方面的不足，需要作为专项解决这些瓶颈问题。

为解决这些问题，我们联合公司EPG团队（工程过程组）深度剖析评估标准中各种能力项的深层含义，并联合各团队集中优秀资源一起夜以继日共同论证方案完成升级改造。

经过团队的不懈努力，最终实现稳定落地，顺利通过了评估。

Q：对于 DevOps 今年的实施，您觉得最大的收获是什么？团队的下一步计划是？

王宇：最大的收获是我们经过一年的努力目前已经打造出了一体化的DevOps平台，并且通过本次评估进一步完善了平台的能力，大幅提升了持续集成、持续交付的效率和质量，更快速地交付了业务价值。后续会结合我们的实际情况不断进行深度优化，在DevOps的基础上，进一步完成DevSecOps，BizDevOps的建设，通过专业创造价值，为客户提供更安全、高效的数字化科技服务。

平安壹钱包 项目管理部 

架构师、敏捷教练 杨大鹏

Q：通过本次项目评估，带给企业和团队哪些变化，改进成功主要体现在哪些方面？
杨大鹏：本次评估是针对我们整个持续交付平台，对平安壹钱包 DevOps 整体能力与规范化有较大提升。
在功能层面，我们实现了从业务需求、技术交付、价值检视的持续连接，打通了研发过程工具链，建立了端到端持续交付流水线，建立了质量门禁体系，做到了端到端过程全覆盖，从而使业产研基层团队从中直接获益、通过流畅易用的一站式操作体验，实现了全链路高效协同，助力团队更高效、更可靠、可持续地交付业务价值。
在数据层面，我们做到了数据自动采集，建成了指标度量体系，使得团队可以自主进行数据分析，关注投入产出，降低了管理负荷，方便大家进行自我管理。
大家体会到了平台带来的便捷，更加提升了持续改进的积极性，更好促进了DevOps文化在我们科技团队的推广落地。

Q：对于 DevOps 的发展前景，您怎么看？

杨大鹏：只要软件工业的发展不停滞，DevOps及研效工具的发展就不会停滞，会不断有新的问题、新的场景、新的模式促进DevOps理论与实践的发展。在业务数字化的浪潮下，能够实现业务技术融合的数字化组织才更具备竞争力。DevOps 体系建设是企业数字化转型的重要组成部分，这也要求DevOps体系建设要进一步实现业务和技术有机融合和有效协同，进一步打破业务与研发之间的屏障，这就要克服组织、流程、技术等层面的诸多挑战，使业务人员与研发人员能够无缝、顺畅地高效协同，实现端到端价值交付。

在数字化时代，新的实践可能包括能够支撑产品导向、业务驱动的团队组织协同机制、以应用为核心的研发资产和流程管理，具备业务特征的持续业务交付，全量、全要素、实时数据支持的度量和持续改进，从而实现全链路数字化运作，赋能数字业务的持续创新和长期发展。在业务技术融合的基础上，DevOps体系将不单单作为持续价值交付的引擎，而终将演进成为企业的创新实验平台和业务发展引擎。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
