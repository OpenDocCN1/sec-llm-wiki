****![](../Images/6780d47cae7148a2d31a60c46fb74975.png)**GitHub用户数突破1亿**  

近日，面向开源及私有软件项目的代码托管平台 GitHub 宣布：现在已有 1 亿名开发者在使用该平台。

![](../Images/977944286cf52804e720dfac7aa2e4b5.png)

自 2008 年成立以来，GitHub 取得了长足的进步，从0到1个亿，Github用了15年的时间，成为了全球最大的开源代码托管平台，并且成为数百万开源和专有软件项目的默认托管服务，让开发者在不同的地方围绕共享代码库进行协作。在这 1 亿的用户之中，有超过一千万名开发者来自中国，印度开发者为增长之最。  

**![](../Images/6780d47cae7148a2d31a60c46fb74975.png)谷歌宣布裁员1.2万人，61岁程序员再求职**

谷歌母公司 Alphabet 宣布裁员大约1.2万人，其中波及多名资深开发者。有报道称，本次裁员名单是通过算法来完成的。在这些被裁员工中，有人刚得到高绩效评估或高级管理职位，年薪在50万至100万美元不等。此外，裁员名单中还有多位知名开源明星人物，其中还有不少来自谷歌开源项目办公室的员工。

现年61岁的 Jeremy Allison 也是谷歌开源项目办公室的一员，同时也是知名开源软件 Samba 的联合创始人。Samba 是在 Linux 和 UNIX 系统上实现 SMB 协议的一个免费软件，主要用于实现 Windows 和 Linux 之间互相共享资源。**1 月 21 日**，Jeremy Allison 在推特上公开求职：“刚被谷歌解雇。如果有人需要 SMB 1/2/3 协议或者开源经验，我很感兴趣。

![](../Images/0e9aee081e98246ddb7b089b7a8da9a4.png)

谷歌一直积极参与和推动开源发展，不少软件更是依托开源的力量才屹立不倒。有意思的是，不仅谷歌，在过去一年，其他美国科技巨头如亚马逊、Facebook、微软、Twitter、特斯拉均经历了裁员。  

**![](../Images/84247e2bc5d4130375b01bfbb5f3ce3c.png)俄版百度44.7G源码遭泄露  
**近日，俄罗斯第一大科技巨头 Yandex 44.7GB源代码，全被泄露到了网上。Yandex 是俄罗斯网络拥有用户最多的网站，不仅在搜索引擎，还在老百姓购物、打车、订外卖、租车这一连串生活服务都给包圆了。简单来说，约等于俄版**百度+淘宝+美团+滴滴**。据称，该公司源码被前员工出售在黑客论坛上，泄密者称，这份44.7GB的 Yandex 代码库，包含该公司2022年7月以前，除反垃圾邮件规则之外的所有源代码。**![](../Images/8e41bb4ddcb0ce1344d022e7d69b7c13.png)60天月活1亿，爆火聊天机器人ChatGPT付费版出炉**史上最强聊天机器人ChatGPT自推出以来，迅速刮起一场席卷科技行业的热潮。无论是科技大拿的争相吹捧，还是普通用户拿它聊天解闷、冒充专家去答题，还是辅助写论文，反正大家乐此不彼。导致的结果是**卡****爆****了**，新申请的用户进入了“等待名单”，而且高峰期用户登陆需要经常性排队，还时不时卡顿、停止响应。2月2日，OpenAI 正式官宣了 ChatGPT 的“试点订阅计划”，每月20美元（约人民币134元），这项付费服务被称为ChatGPT Plus。![](../Images/b7a4c81a25f1dd607f110a8bd4dc45eb.png)

OpenAI官网显示，与基础级别的ChatGPT相比，这个Plus版有不少好处，即使在高峰期也能普遍使用ChatGPT，不用排队，响应时间更快，并能优先获得新功能和改进。不得不说，**付费真香。**  

**![](../Images/55d4349efa51f3a1e1137d5c2d5ae559.png)优酷首月1元会员引争议，取消续费却扣24元**近日优酷的“1元会员”又引发争议。据上观新闻报道，优酷视频于2022年年末上线“首月1元”会员优惠充值活动，但多名用户反映，其在完成支付后才发现，支付宝相应页面中弹出的实则为“优酷月月省”活动界面，支付1元后默认签约1年，除首月外，每月将自动扣费12元。由于并无长期会员需求，不少用户选择了提前中止参与该活动，不料却立刻收到了扣费24元的提示：“未完成任务，扣回已享优惠。”

**![](../Images/59df79e1442da9b6ae7b57aec56ab35f.png)ChatGPT大火之后，各大科技公司慌了？！**

距CNBC爆料，谷歌正在测试一款类似ChatGPT的聊天机器人，名为 Apprentice Bard。该产品基于谷歌对话模型LaMDA，面向各种对话，将给出尽可能让人满意的合理回答。据爆料者称，即便近期刚发生的事，它也能回答出来，而此种能力，训练数据集基于2021年底的ChatGPT并不具备。另外，据传百度也将于今年推出类似 ChatGPT 的产品，微软已将 ChatGPT 集成到必应里，Meta、小米等相关科技公司也在积极推进。![](../Images/0c78b4446645b8618c0d00d431db156c.png)

**![](../Images/33e91f63ccd9debbb033354db52b5c16.png)北京2023年将新增1万个5G基站**

近日，北京市经信局召开市经济和信息化工作会。会上披露，去年全市经信系统全力推动产业经济企稳恢复，今年全市规模以上工业增加值增速目标为4%，数字经济增加值增速目标为6.5%。相关负责人介绍，本市将加快建设城市数字智能转型新基座，推动高可靠低时延车联网、工业互联网和算力调度体系建设，新增1万个5G基站。同时，率先突破数据要素市场化配置改革，加快培育壮大数字产业发展集群，推动北京国际大数据交易所实现交易品类和交易额提质上量。（北京日报）。
