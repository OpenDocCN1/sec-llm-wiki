# 领先！中移动信息“中国移动集中化AIOps”通过 AIOps 系统和工具技术要求多个模块优秀级评估，相关能力达到国内领先水平

智能化运维（AIOps）：人工智能技术（如机器学习等）和数据科学在IT运营问题上的应用，用于增强和部分替代主要的IT运营功能。根据 Gartner 阐释，AIOps 通过松耦合、可扩展方式去提取和分析数据量、种类和速度这三个维度不断增长的IT数据，进而为IT运维管理产品提供支撑。在新技术的促进下，AIOps 成为未来运维发展的趋势，是企业级 DevOps 在运维（技术运营）侧的高阶实现。

2022年12月26日，**中国信息通信研究院隆重公布了智能化运维 AIOps 系列标准最新批次评估结果。**

中移动信息技术有限公司（以下简称“中移动信息”）本次参评的项目为“**中国移动集中化AIOps**”项目，该项目顺利通过中国信息通信研究院（以下简称“信通院”）开展的《云计算智能化运维(AIOps)能力成熟度模型 第2部分：系统和工具技术要求》标准**【告警收敛】【故障自愈】和【根因分析】**三个模块的**优秀级**评估。代表着中移动信息的 AIOps 相关能力达到国内领先水平。

**评估单位：中国信息通信研究院****2023年1月6日在“2022 GOLF+IT新治理领导力论坛”主论坛上，由中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：**

![](../Images/40965808eee1138a54f191b2cb81ff77.png)

此次，我们采访了中国移动十百千技术专家陈理华先生，一同深聊团队在项目参与评估时的细节和故事，分享中移动信息 AIOps 实践的经验。

**\- Q&A -**

![](../Images/654c62dd59626882c591f9a02d8ca0fc.png)中国移动十百千技术专家陈理华

**Q：老师您好，请介绍一下您和您的企业，以及此次参与评估的项目。**

**陈理华：**中国移动信息技术中心（以下简称：中移动信息）隶属于中国移动通信集团有限公司。中移动信息以“成为数智化转型、高质量发展的重要引擎”为愿景，持续夯实智慧运营体系、中台赋能体系、科技创新体系和IT治理体系，以四大目标为牵引，七大重点工程为抓手，实现运营、能力、创新、管理同步发展。

本次参评的项目是集中化AIOps能力平台，围绕创世界一流“力量大厦”和“注智赋能力”战略要求，以全面提升智能运维能力为目标，实现管理对象全覆盖、AIOps多场景联动，打造事前预防、事中辅助修复、事后复盘的全局数智化故障治理体系，并在11省的AIOps建设中全面落地，保障移动业务高效稳定运行，并作为开放式的工具能力应用于公司其他IT系统的运维工作中。

**Q：恭喜您通过信通院 AIOps 标准系统和工具评估，您的感受是怎样的？**

****陈理华：****AIOps是运维的发展方向，是数智化时代下人机协同的运维模式，是一项需要持续运营迭代的系统性工程。本次三项能力同时通过AIOps标准系统和工具评估的优秀级评估，其中告警收敛、根因分析都是运营商中第一批获得优秀级评估的能力，故障自愈更是业界第一个通过优秀级评估的能力。这是对我们两年来建设、运营、优化的集中化AIOps能力平台的肯定，这也将鼓励我们持续探索、提升我们的AIOps能力，持续为故障管控赋能，实现移动业务连续性保障目标，在新时代IT系统的变革提供支持保障。

**Q：贵单位参与本次 AIOps 标准系统和工具标准评估，请问企业有哪些考量？**

****陈理华：****中移动信息中心通过信通院的AIOps标准评估，推动运营商业务系统的运维保障工作朝着自动化、智能化的人机协同模式演进。AIOps本质上是在自动化运维的基础上，添加实时数据、自动化分析执行和实时感知。这两年来我们的建设过程中，也是在逐步构建场景地图，在学习和实践中落地AIOps。我们通过构建运维大数据基座，实现主机、网络、数据库和应用的管理对象全覆盖，再结合机器学习算法和运维专家经验，建设包括检测、告警、诊断和自愈的智能运维工具平台，这四大能力今年都获得了AIOps标准系统和工具评估的优秀级评估，其中：

1.  异常检测模块构建动态阈值监控体系，解决传统监控在出现业务故障时难以响应和定位难的问题。
    
2.  告警收敛模块应用文本算法解决传统运维中告警风暴的问题。
    
3.  根因定位模块基于调用链数据识别异常节点和疑似异常节点并形成故障树，结合错误次数和故障贡献率进行根因排序，有效提高根因分析的准确率。
    
4.  故障自愈模块构建自动化运维工具链，建设可自定义编排构建诊断模型的功能，最终实现一键故障修复，极大提高了运维的自动化水平和运维效率。

集中化AIOps能力平台，作为中移动信息在智能运维的实践，通过评估对标国际AIOps标准体系，打造AIOps能力品牌，作为智慧运维体系的一部分，继续推动移动业务系统的数智化转型。

**Q：通过** AIOps 标准系统和工具标准评估**带给企业和团队哪些变化？**

****陈理华：****一方面，为系统能力的建设提供了经验。本次AIOps标准系统和工具标准评估，是对这两年来的集中化AIOps的建设工作的全方位审视，并且优秀级评估也是对我们工作的鼓励和肯定，标准化的体系也为后续我们继续推进集中化AIOps能力平台的建设工作提供指引。

另一方面，这次评估也促进了我们团队成员的成长，建设集中化AIOps能力平台的过程中，需要运维专家、大数据专家和算法专家协同工作，在实施落地过程中不断地磨合和总结经验，逐渐积累形成智能化的人机协同运维体系，本次评估过程也让团队成员AIOps有更清晰的认知和体会，为后续继续探索、迭代AIOps能力提供新的方向。

**Q：对于 AIOps 工作的开展，下一步计划有几方面？**

**陈理华：**我们一共规划了三方面工作。第一，运维的贡献不能只体现在内部，也要体现到业务上。从业务视角看待故障管控能力和全局状况，前者在故障发生时通过智能算法甄别出有效的故障传播链，后者通过实施的数据更新、历史数据的挖掘来展示全局状况，从而让业务部门更清晰的了解到业务状态和运维支撑的关系。第二，形成运维能力闭环。通过构建运维知识图谱，采集指标、日志、告警、操作记录和异常案例，完成从检测、告警、诊断、自愈到知识更新的能力闭环，并且运维知识图谱中沉淀的数据构建异常案例博物馆，进一步完善我们的根因定位能力。第三，将AIOps更多的推广到公司的其他IT系统的运维工作中，带来运营商业务的质量、效率的全面提升。

**Q：对于 AIOps 的未来发展方向，您有何看法？**

****陈理华：****AIOps是运维的发展方向。AIOps的出现，既符合时代的需求，也给运维工作打了一剂强心针。智能运维是将AI技术运用到运维领域， 通过一定的策略和算法来实现智能化诊断决策， 适应大数据和云原生时代下对运维的要求，而 AIOps对运维人本身的要求， 可以帮助运维工作者建立自我提升的路线图，适应新时代IT体系对运维工作的挑战。

**智能化运维(AIOps)能力成熟度模型介绍：**《智能化运维AIOps能力成熟度模型》系列标准由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、dbaplus社群、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个智能运维（AIOps）国际标准，并在国际电信联盟第十三研究组 ITU-T SG13 成功立项！目前，基于《云计算智能化运维(AIOps)能力成熟度模型第2部分：系统和工具技术要求》评估已开放8个模块：异常检测、故障预测、告警收敛、根因分析、故障自愈、故障预防、容量预测、知识库构建。
