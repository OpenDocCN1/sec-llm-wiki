# 运营商首家！浙江移动通过信通院DataOps-研发管理能力评估

中国移动通信集团浙江有限公司（以下简称“浙江移动”）参与了中国信通院数据研发运营一体化（以下简称DataOps）研发管理模块的首批评估，经过严格的评估过程，浙江移动“网络反诈运营分析项目”获评三级（优秀级），达到国内同业领先水平，是首个通过DataOps研发管理模块评估的运营商企业。

  

01项目背景  
  

  

当前电信诈骗存在广域性、技术专业化、产业化、多样化、隐蔽性的特点，使得电信诈骗打击管控难度大。为更好地构建行业反诈体系，应对不断涌现的各类新兴诈骗手段，内聚用户基础数据资源与分析能力，浙江移动在“开放性底座+微服务+生态化创新”理念的指导下，打造了数据驱动、技管结合、以技管网、统筹调度的通讯信息反欺诈中台。通过网络数据融合平台提供多源、安全、标准化的话单、信令等数据，对用户通讯产生的通话、上网、信令的异构、多源安全数据进行了统一数据采集、标准化和关联补齐，形成了集中分析、有针对性打击的通讯信息反欺诈业务的场景化应用和治理体系，满足了新型电信网络诈骗治理需求，有力支撑了反欺诈工作。

02DataOps的实践  
  

  

浙江移动基于DataOps理念，推动建设有浙江移动特色的数据研发运营管理体系，从而实现在数据流程、数据质量等方面的跃升，具体实践措施有两个方面。

  

### **1\. ****加强****工具平台建设**

  

通过加强数据在线运营流程的支持功能，进一步优化平台工具建设，一体化承载数据申请、需求分析、数据采集、建模开发、数据消费、数据保障所需的功能，提升数据治理能力与数据开发能力。

### **2\. ****推动****工程实践与流程优化**

  

打通需求、设计、研发、运维之间的协同壁垒，形成标准化、一体化的数据流水线。通过制度规范保障、技术平台支撑，将数据标准深入设计开发流程，数据安全管控深入租户管理流程，形成工程化、规模化的数据管理能力提升。

  

****数据开发********方面********：****提升数据端到端效率，持续优化数据集成过程，确保数据在被发现和利用的过程中的时效性，对****需求分析效率提升****20%****、********开发效率提升****25%********、********需求********处理率提升********28.47%****。主要优化措施包括：

  

1、制度能力方面，通过制定和持续优化技术开发规范与细则，标准化开发流程，建立可落地的技术标准。

2、技术能力方面，践行持续集成、持续部署、持续交付的理念，实现数据的高质量交付。

3、协同能力方面，提升数据在研发、测试、投产等环节的协同效率，平滑实现平台间联动，提升团队内协作，**数据****质量问题当天****处理****及时******率提升到****96.7%****。  

  

****数据模型设计：****构建了自动化、可视化的数据模型设计工具和全面的数据标准，通过线上化方式实现数据模型的设计和落标，降低人工依赖，限制人为操作风险，简化设计流程，****问题自发现率提升********近****20%****。

  

****安全及权限管控：****平台面向全域的个人、项目进行数据共享，通过建立数据安全管理规范、数据安全管控流程，优化权限管理工具，持续提升涉敏数据的管控能力，做到对各租户的功能、数据权限、数据申请的精细化管控，实现全年零安全事故。

**DataOps研发管理标准评估简介**  

《数据研发运营一体化(DataOps)能力模型》系列标准由中国信息通信研究院牵头，由来自金融、通信、互联网等领域的众多行业专家共同制定。该系列标准共分为总体架构、研发管理、交付管理、数据运维、价值运营、系统工具、组织管理、安全风险八项内容。

  

《数据研发运营一体化(DataOps)能力模型 第2部分：研发管理》对数据研发管理工作进行标准化，并将数据管理工作融入数据研发过程，推动数据管理能力的工程化落地和渐进式提升。研发管理标准包括数据需求管理、设计管理、数据开发和自助分析4个模块，共考察13个能力项，42个动作环节，共有200+等级要求，700+条款要求。标准能够全面细致指导企业开展数据研发工作，补齐工作，提升研发效率。
