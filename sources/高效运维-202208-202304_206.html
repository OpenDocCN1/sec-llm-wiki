燃！安信证券通过 DevSecOps 标准评估，相关项目能力达到先进水平

国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

12月26日，中国信息通信研究院隆重公布了 DevOps 系列标准及 AIOps 系列标准最新批次评估结果。

安信证券股份有限公司（以下简称“安信证券”）参与评估的项目为金融商店系统项目，该项目顺利通过由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》安全及风险管理（DevSecOps 标准）安全开发模块 2 级评估，代表安信证券 DevSecOps 领域能力达到国内先进水平。

目前，安信证券总共通过 5 项中国信通院 DevOps 标准评估，其中通过 DevOps 持续交付标准评估 3 项，通过 DevOps 技术运营标准评估1项，通过安全及风险管理标准评估 1项。

评估单位：中国信息通信研究院
2023年1月6日在“2022 GOLF+IT新治理领导力论坛”主论坛上，由中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：

此次，我们采访了安信证券安全总监李维春先生、安信证券开发安全负责人覃阳青先生，一同深聊团队在参与评估中的细节与故事，分享安信证券 DevOps 实践经验。

- Q&A - 

安信证券安全总监 李维春

Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目

李维春：安信证券是国家开发投资集团有限公司旗下的证券公司，是一家全牌照综合类券商，多项业务排在行业前列。信息技术委员会作为公司数字化转型和金融科技创新的牵头部门，为超 800 万公司客户在股票交易、理财投顾等多个金融领域提供完善、可靠的交易IT服务。
此次参评的金融商店系统项目，围绕以客户为中心，从产品营销、交易到资产持仓为客户提供一整套完整投资交易功能。目前系统已经提供了智能理财、基金交易、资产全景、个性化产品、非金融产品下单等服务。
Q：恭喜您公司通过 DevOps 标准评估，此次贵公司项目通过的是安全及风险管理（DevSecOps）2级，表明达到了国内先进水平，可以分享您的感受吗？
李维春：非常高兴金融商店系统项目顺利通过 DevSecOps 二级标准评估，这体现了我司在 DevSecOps 领域实践的先进性。项目团队在借鉴行业标准的基础上，结合安信证券自身的技术特点，在持续建设独具特色的开发安全解决方案的同时，取长补短，完善当前开发安全的能力，进一步提升公司整体的安全及风险管理水平。在此特别感谢信通院各位专家在标准评估过程中对于我司的指导和帮助，同时非常感谢参评团队全体人员的辛勤付出与努力。

Q：贵公司是如何决定参与 DevSecOps 标准评估工作中的？

李维春：近年来，安信证券始终以“业务引领+科技赋能”为指导理念，将区块链、云计算和大数据等金融科技前沿技术融入到实际业务发展中，全面推进公司的数字化转型实践，有力支撑起整个公司业务的持续稳健发展。DevSecOps 是一套基于 DevOps 技术体系的安全实践框架，旨在将安全左移，安全服务内嵌到 DevOps 交互过程中，构建全流程安全内建与闭环，在提升IT效率、质量、投资收益比的同时，保障安全风险可控。安信证券近几年从人员组织、安全工具、基础设施、三方管理、数据管理等多方面构建全司安全体系、框架。本次参与标准评估的目的，一方面是检验自身水平，另一方面也是为了解与其他领先企业的差距，审视自身不足，以便进行针对性的过程改进，不断完善。

Q：通过 DevSecOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？

李维春：通过 DevSecOps 的标准评估，表明了我们建设方向是正确的，具备了安全及风险管理标准中各类安全规范和流程，我们团队成员也具备充足的安全意识和安全基础技能。在整个评估过程中，我们以金融商店这个项目为切入点，对各个安全规范要求、安全技术能力和安全经验积累进行了全方位的梳理与总结，后续也会不断完善，并推广到其他项目，全面实现安全左移。

Q：对于此次参评的项目哪些特色？在日常安全风险的管理方面，面临哪些安全挑战？
李维春：金融商店系统是我司基金理财产品和金融服务类产品的交易系统，也是我司主要的场外产品和服务的线上交易渠道，面向的是互联网客户，拥有超800万用户基数，其中场外交易客户数占到全公司的90%以上。金融商店系统不断在探索和使用各项新技术、持续的发展和完善研发模式，以快速响应业务需求，向客户提供高效、稳定、安全的服务平台。

在日常安全风险的管理方面，面临的安全挑战有：

  • 金融商店是我司重要的交易系统，也是我司主要的线上交易渠道，系统的安全、稳定运行对保障业务正常开展尤为重要，因此，对系统安全运营过程中的安全保障能力有着更高的要求，即需要有足够的风险防范能力，更需要有极高的风险识别能力。

  • 系统面向的是互联网用户，且用户体量大，涉及的业务场景丰富，系统在开放的网络环境、复杂的数据应用和众多的用户访问等多种风险环境运行，使得数据在保密性、完整性和可用性等方面面临更大的挑战。

  • 各种新技术发展过程中的安全性、合规性并未得到充分的论证，容易导致各类安全漏洞，项目引入了新技术，会对业务系统的应用安全性产生一定的影响，对软件开发的安全性带来挑战。

安信证券开发安全负责人 覃阳青

Q：DevSecOps 核心理念为安全是整个IT团队（包括开发、运维及安全团队）每个人的责任，是否可以详细的给我们介绍下，贵司是如何从文化、流程及技术三方面落地 DevSecOps 的？

覃阳青：在文化方面，首先，公司领导层对信息安全工作高度重视，大力支持DevSecOps建设；其次，我们建设跨团队协作的机制，定期召开团队间会议，共同协作处理开发、运维及安全问题，协助 IT 团队成员对安全工作的理解；最后，我们持续开展应用安全意识、开发安全流程和规范、安全技术和技能等不同领域的安全培训，提升IT团队成员的安全意识，明确各项安全活动的要求和相关人员的安全职责，完备对应人员的安全技能；

在流程方面，遵照 DevOps 的思想，在 DevOps 流程的基础上嵌入安全开发流程，将安全问题尽量在各个阶段同步解决，通过设置合理的安全检查点和安全卡点，实现安全左移；
在技术方面，引入自动化安全检测和安全加固等能力，将持续安全评估和安全管理工作流程自动化，减少人工操作步骤，提升安全检测与验证效果；将积累的安全评审经验梳理形成知识库，以知识库作为标准开展安全评估和安全管理工作。

Q：此次通过 DevSecOps 评估的过程顺利吗？遇到什么困难？如何解决的？

覃阳青：安信证券 DevSecOps 已建设有几年， 在安全管理体系和安全技术规范制定、安全开发流程建设、安全工具链构建、安全知识库管理等方面具有丰富的积累。此次评估的目的是引入 DevSecOps 标准，对我司建设的 DevSecOps 方案进行评价，指导我们对已建的能力向更高级别提升。因此，此次评估工作，需关注的是评估材料整理和演示环境准备的进度控制。为此，我们严格执行项目计划，每周开展项目例会跟进项目进度，及时发现问题并解决，保障项目顺利通过评估。
Q：对于 DevSecOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？

覃阳青：本次评估工作，推动了信息系统分类分级标准的梳理及明确，保证分类分级标准的可落地性；提升了安全需求管理方面的能力，实现安全知识库线上化管理维护和安全需求条目化跟踪；完善了安全度量指标，基于自动化度量和问题跟踪平台，持续度量与反馈改进，实现安全度量的闭环。接下来，我们将以此次参评项目的解决方案作为最佳实践案例，在公司逐步推广使用到其他项目，进一步提升安全检测效果和效率；同时，持续深化 DevSecOps 体系建设，优化完善落地方案，达到更高级别能力标准。

Q：对于 DevOps 的发展前景，您怎么看？

覃阳青：DevOps 不断发展和转变，以推动实现业务目标为根本出发点，它将有助于提高公司研发设计、生产、发布和维护高质量软件解决方案的能力。DevSecOps 理念是在 DevOps 的基础上被提出，既延续了 DevOps 的理念，还增加了安全要求，能帮助企业在软件研发阶段关注安全风险，提前解决大部分安全风险。随着 DevSecOps 标准的发布，许多大型企业也纷纷加入到 DevSecOps 的实践行列中，足以体现 DevOps 转向DevSecOps 已是大势所趋。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
