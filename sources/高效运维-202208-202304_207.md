# 燃！中信建投通过 DevSecOps 标准评估，相关项目能力达到先进水平

![](../Images/aa264a4646f517c63cb2c5eb4f339736.png)国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。12月26日，**中国信息通信研究院隆重公布了 DevOps 系列标准及 AIOps 系列标准最新批次评估结果**。

中信建投证券股份有限公司（以下简称“**中信建投**”）参与评估的项目为**机构业务服务平台项目**，该项目顺利通过由**中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》安全及风险管理（DevSecOps 标准）安全开发与运营模块 2 级评估，**代表着中信建投 DevSecOps 领域能力达到国内先进水平。

目前，中信建投已有1个项目通过 DevOps 持续交付标准3级评估，1个项目通过 DevSecOps 标准评估。**评估单位：中国信息通信研究院**

******2023年1月6日在“**2022 GOLF+IT新治理领导力论坛**”主论坛上，由**中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：****

![](../Images/d1971e9dc8f82b9272674ad4bf1798ee.png)此次，我们采访了中信建投证券执委会委员、首席信息官、信息技术部行政负责人肖钢先生、中信建投信息技术部总监张建军先生，一同深聊团队在项目参与评估时的细节和故事，分享中信建投 DevOps 实践的经验。**\- Q&A - **

**Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目**

**肖钢：**中信建投证券成立于2005年11月2日，是经中国证监会批准设立的全国性大型综合证券公司。公司在为政府、企业、机构和个人投资者提供优质专业的金融服务过程中建立了良好的声誉，自2010年起连续13年被中国证监会评为目前行业最高级别的A类AA级证券公司。自成立以来，中信建投证券各项业务快速发展，在企业融资、收购兼并、证券经纪、证券金融、固定收益、资产管理、股票及衍生品交易等领域形成了自身特色和核心业务优势，并搭建了研究咨询、信息技术、运营管理、风险管理、合规管理等专业高效的业务支持体系。凭借高度的敬业精神与突出的专业能力，中信建投证券主要经营指标目前均位居行业前10名。  

此次参与评估的项目为机构业务服务平台，是我司推出的针对机构客户的全新移动金融服务工具，通过移动端APP，小程序为机构客户提供投研服务、券源服务、衍生品服务、托管服务、运营服务等多品类、一站式的综合金融服务，为机构客户提供千企千面的个性化解决方案，打造行业领先的线上机构客户服务体系。

**Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是安全及风险管理（DevSecOps）2级评估，表明达到了国内领先水平，请说一下您此时的感受。**

**肖钢：**很高兴能够顺利通过本次评估，这代表中国信息通信研究院对我司安全能力的肯定。中信建投证券非常重视这个工作，投入大量人员和精力进行落地实践，确保项目按预期计划完成。感谢信通院各位专家在标准评估过程中对于我司的指导和帮助，同时非常感谢参评项目组全体人员的辛勤付出与努力。

**Q：贵公司是如何决定加入 DevSecOps 标准评估工作中的？**

**肖钢：**我司数字化转型工作，以服务公司主营业务为根本、以数字化理念为指引、以安全稳定合规为前提，通过建设与引入先进的管理体系与金融科技手段，建立服务能力强大、自主可控、助力公司数字化转型的一流金融科技平台。

信息安全是信息技术发展的生命线，在公司“十四五”发展规划与数字化转型过程中，要不断加强信息安全相关方面建设。目标是遵从开发运维安全一体化（DevSecOps）体系化建设的理念，通过安全开发生命周期管理体系的搭建，形成从立项、开发、测试到上线、部署、运维全生命周期的信息安全防护。

**Q：通过 DevSecOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？**

**张建军：**此次评估检验了 DevSecOps 标准在我司的实践落地情况，助力我司进一步提升 DevSecOps 能力体系建设的标准化、专业化水平，为后续全面推广 DevSecOps 落地实践奠定了坚实基础。通过本次评估，我司明确了未来持续优化的方向，将持续提升 DevSecOps 能力成熟度。

在 DevSecOps 实践理念的指引下，我司在应用开发前期即引入安全管控，探索“安全左移”落地实践，全面覆盖安全需求、安全设计、安全开发、安全测试等系统开发全生命周期，有效降低安全问题修复成本，全方位赋能应用安全开发管理，提升人员安全能力水平。

**Q：对于此次参评的项目哪些特色？在日常安全风险的管理方面，面临哪些安全挑战？**

**张建军：**此次参评的机构业务服务平台是我司为客户服务的重要窗口，对用户体验要求较高，开发迭代快速。

在日常安全风险的管理方面，主要面临如下安全挑战：一是该系统面向客户群体广泛，业务场景丰富，开发迭代更新频繁，对敏捷安全带来较大挑战。二是该系统为移动端应用产品，新型漏洞层出不穷，新型攻击手法与日俱增，需要安全人员快速高效响应安全事件，及时有效处理安全问题。

**Q：DevSecOps 核心理念为安全是整个IT团队（包括开发、运维及安全团队）每个人的责任，是否可以详细的给我们介绍下，贵司是如何从文化、流程及技术三方面落地 DevSecOps 的？**

**张建军：**文化方面，我们持续通过安全意识培训、专项安全培训、钓鱼邮件演练等形式，让研发及运维人员意识到安全是整个IT团队每个人的责任，持续推进我司网络安全文化建设和网络安全意识的提升。

流程上安全工具与 DevOps 平台实现了从安全需求至安全测试的全流程集成，包括安全需求、安全工具链、渗透测试、漏洞管理等环节，实现安全管控和 DevOps 流程的融合，确保 DevSecOps 落地实施。

技术上建立了较完整的安全工具链，覆盖应用安全开发全生命周期。通过结合流水线工具，实现了安全工具的自动调度，打通了安全数据的流转，尽量减少开发测试人员的学习成本。

**Q：此次通过 DevSecOps 评估的过程顺利吗？遇到什么困难？如何解决的？**

**张建军：**本次评估总体来说比较顺利。首先，这得益于各级领导对项目组的大力支持，先后从相关条线、中心挑选了多名骨干成员协助项目组进行攻坚克难；其次，整个项目组成员目标一致，相互协作，勇于担当，使得项目顺利通过评估；最后，感谢大家在本次评估过程中付出的努力。

**Q：对于 DevSecOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？ **

**张建军：**评估工作对于 DevSecOps 的落地实践具有重要的指导意义。本次项目取得的成果，对其他项目起到了标杆作用。下一步，我们将把机构业务服务平台的 DevSecOps 实践经验，推广到全公司的项目团队，不断提升安全研发效能。同时，我们要争取“更上一层楼”，对照更高级别的标准要求，分析差距不足，继续提升安全风险管理水平，努力获得更高级别的评估。

**Q：对于 DevOps 的发展前景，您怎么看？**

**张建军：**DevOps 是数字化转型成功的关键之一，帮助企业提升IT效能，在保证稳定的同时，快速交付高质量的软件及服务，灵活应对快速变化的业务需求和市场环境。而 DevSecOps 将应用的需求、开发、测试、部署、运营同安全统一起来，基于整个组织的协作和应用架构的优化，实现敏捷开发、持续交付和应用运营与安全无缝集成。随着 DevOps 的发展，微服务应用，无服务计算，低代码平台，云原生，AIOps 等深入到安全方面，我们会从行业实际情况出发，通过 DevOps 来推动企业的 IT 转型，提供企业数字化发展。

**研发运营一体化（DevOps）能力成熟度模型介绍：**

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。![](../Images/42b82d9144a4c2539b650a9c17c46efd.png)![](../Images/e8a4867188405787515740cc4a29dc70.png)![](../Images/866f8509cca56339b54367efeaacd0f3.png)**DevOps 标准评估相关事宜，请联系：**中国信息通信研究院@刘凯铃电话：15650786171（同微信）
