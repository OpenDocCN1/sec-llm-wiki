国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

2022年12月26日，**中国信息通信研究院隆重公布了 DevOps 系列标准最新批次评估结果**。

中国移动通信集团广东有限公司（以下简称“**广东移动**”）参与评估的项目为**广东移动CRM客户关系管理系统项目**，该项目顺利通过由**中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》技术运营 2+ 级评估，**代表广东移动的 DevOps 相关能力达到国内领先水平。**评估单位：中国信息通信研究院**

************2023年1月6日在“**2022 GOLF+IT新治理领导力论坛**”主论坛上，由**********中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：**

![](../Images/8c776885b2b0f7ebbe9c4e60ad2e9c74.png)此次，我们采访了广东移动信息系统部副总经理陈辉先生，一同深聊团队在参与评估中的细节与故事，分享广东移动 DevOps 实践经验。**\- Q&A - **![](../Images/21a458c2560aebcc8966bd4c93d4067e.png)

广东移动信息系统部副总经理 陈辉

**Q：请您介绍一下此次参与评估的项目**

**陈辉**：此次参与评估的项目是广东移动最核心、最复杂的业务支撑系统，CRM系统主要包括客户管理、产品管理、渠道工号管理、销售与订单管理等功能模块，承载了广东省21个地市约1.3亿个人用户，以及超2000万宽带用户，涉及的关键业务如：开户、补卡、充值、信控停开机、产品订购退订、家宽业务、清账单查询等，月均调用量总计超90亿次。具有规模庞大、结构复杂、业务核心、运营难度高的特点。

**Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是技术运营 2+ 级，达到国内领先水平，麻烦您说一下此时的感受****陈辉**：CRM系统能顺利通过技术运营2+ 级是具有里程碑的意义，广东移动作为国内第一家CRM系统整体通过技术运营2+ 级的单位，标志着我们在 DevOps 研发运营一体化的实践上达到了较高水平。我们为了做好业务支撑服务，一直在通过不断的改进技术架构、管理流程、运营工具来提升系统的稳定性、安全性、可靠性，同时也注重效率、体验和效益，促进高质量发展。这次2+评估通过，是对我们一直以来不断探索的肯定，同时也感谢各合作伙伴的大力支持，感谢信通院的悉心指导，这是大家共同努力的成果。**Q：贵公司是如何考虑将此项目进行技术运营评估的？****陈辉**：选定最具代表性、最复杂的 CRM 业务支撑系统参加研发运营一体化（DevOps）技术运营评估，不是浅尝辄止，是想深入真实检验我们在监控管理、事件和变更管理、配置管理、容量与成本管理、高可用管理、业务连续性管理、用户体验管理等方面的系统运营能力，全面覆盖各能力域的建设及运营情况，评估复杂系统的能力成熟度，并针对性的进行能力补齐和提升。同时，CRM系统作为标杆系统进行技术运营评估，能为其他业务支撑系统的运营能力提升提供样本，快速复用技术运营能力。

**Q：通过此次 DevOps 标准技术运营部分评估对贵团队意味着什么？具体有哪些改进？**

**陈辉**：通过此次评估，团队成员增强了对 DevOps 思想的理解，为后续IT系统技术运营能力持续提升打下坚实的基础。在评估初期，CRM系统部分容量与成本管理能力相对薄弱，部分平台一体化能力相对欠缺，容器化、微服务等新技术的应用能力也处于起步阶段，后经过多次差距分析和优化改进，我们在工单系统、数智化运维平台、统一PAAS平台、系统体验管理平台等基础上进行功能迭代更新，引入多维度容量预测、知识图谱多场景联动等补齐相关能力短板，提升了整体运维工作的数智化水平。

**Q：对于此次参评的项目，其 IT 系统有哪些特色，当时是怎么规划和设计的？**

**陈辉**：CRM系统承载的业务种类多、并发量大、连续性要求高。在规划设计时采用两地双中心建设，满足异地应急容灾能力。架构上采用前后端分离、前台和接口业务分离等方式，提供多端化服务，技术上已实现了X86化、容器化、集群化，并基于Prometheus构建容器PaaS监控平台，以多种视图的方式提供监控。在业务高峰时，可通过弹性计算能力实现资源弹性调度，抵抗浪涌冲击。既满足了高可用要求，也提升了开发运维效率。

**Q：此次通过评估的过程顺利吗？遇到什么困难？如何解决的？**

**陈辉**：这次评估过程总体比较顺利。技术运营能力评估涉及多方面领域，包括系统监控、高可用、业务连续性、容量成本管控等，2+标准要求也比较高，对各个能力项都有比较细致严格的规范要求。为了完成这次挑战，部门也高度重视，挑选了部门维护团队多名骨干核心成员，组建了专项项目团队。在辅导老师的指导下开展了多轮自评及对标，梳理了35个能力域、113个改进点，并制定了详细的解决方案及改进计划，通过小步快跑的方式不断迭代改进，经过近一年的合力攻坚，高质高效的完成了改进优化，完善了我们的技术运营体系，达到了国内领先水平。

**Q：关于 DevOps 标准，您怎么看，对您企业带来了什么帮助？**

**陈辉**：信通院 DevOps 标准是一套权威且专业的能力成熟度评估标准，对技术运营的各个方面都有很清晰的规范和要求，具有较强的行业指导性。通信行业IT技术转型不断推进，对我们运营维护工作也提出了更高的要求。DevOps标准为我们提供了很好的引领和参考，帮助我们分析差距，找到持续改进的方向。**Q：关于 DevOps，接下来团队有什么样的计划？****陈辉**：通过这次评估，我们团队整体技术运营的水平有了一定的提升，一些关键领域的水平有了突破性的进展，同时我们也认识到了自身的不足和差距。接下来我们将继续朝着 DevOps 标准更高等级的要求继续研发创新，深入改进我们的各个能力项。这次评估经验也会总结形成技术规范，实现规范、流程、工具一体化，最终通过以点带面推广至其他IT系统，支撑集团数智化转型战略在我省落地。**Q：关于  DevOps  的发展前景，您怎么看？****陈辉**：我认为 DevOps 是精益理念的实践，提升IT效率和质量、降低运营成本是IT行业不变的追求。随着IT技术的快速发展，使得DevOps的很多理念越来越容易落地成为现实，越来越多的项目正在主动引入 DevOps 理念、工具、文化。DevOps已经呈现出与IT技术相互促进的发展趋势。**广东移动 CRM 平台项目组合影及评估现场：**![](../Images/73de86a98f5e5df673fc9b14fcb29daa.png)**广东移动 CRM 平台项目介绍：**

**研发运营一体化（DevOps）能力成熟度模型介绍：**  
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
