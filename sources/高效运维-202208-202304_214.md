国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

2022年12月26日，**中国信息通信研究院隆重公布了 DevOps 系列标准最新批次评估结果。**

中国中金财富证券有限公司（以下简称“中金财富”）参与评估的项目为**中金财富E-Space投顾平台项目**，该项目顺利通过信通院《研发运营一体化（ DevOps ）能力成熟度模型》**持续交付标准 3 级**评估，代表中金财富的 DevOps 相关能力达到国内领先水平。

目前，中金财富共有 2个项目通过 DevOps 系列标准评估。除本次通过评估的项目之外，另外 1 个项目通过了 DevOps 系统和工具标准评估。

**评估单位：中国信息通信研究院**

**中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：**

![](../Images/97c1fde6f7489c01cefdf092f14b93cb.png)

此次，我们采访了中金财富信息技术部总经理谢碧松先生、中金财富信息技术规划总监罗畅先生、中金财富E-Space投顾平台敏捷团队长邓雅琳女士和CL 孔培先生，一同深聊团队在项目参与评估时的细节和故事，分享中金财富 DevOps 实践的经验。

**\- Q&A -**

![](../Images/97e6cfc3b70b9cf28b602276590f5673.png)中金财富信息技术部

总经理 谢碧松

**Q：****您好****，请介绍一下您和您的企业，以及此次参与评估的项目。**

**谢碧松：**大家好，我是中金财富信息技术部总经理谢碧松，首先非常感谢信通院各位专家在评估过程中的指导与帮助，以及对中金财富 DevOps 持续交付能力的肯定。

E-Space投顾平台是中金财富投资顾问一站式展业与成长平台。平台以科技赋能金融、随时随地创造价值为理念，基于买方投顾视角，拆解降维ONE CICC的全链资源，通过中金研究、投研投管、CIO Office等行业领先的研究及服务能力并根据对投资模型和大数据分析，专业的为客户定制个性化财富规划方案。从客户的实际需求出发，让每一位客户的个性化财富目标尽可能地得到满足。践行买方投顾理念，以投顾服务为核心的财富管理时代正在到来，如何更好地为客户服务，成为了我们前进路上的持续动力。

**Q.****恭喜您通过****DevOps ****标准评估，此次贵公司项目通过的是持续交付****3****级，表明达到了国内领先水平，请说一下您此时的感受。**

**谢碧松：**很高兴能够顺利通过中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级能力评估。作为中金财富侧首个通过该项能力评估的团队，这意味着E-Space投顾平台团队的 DevOps 持续交付能力达到了国内金融行业的领先水平。本次评估成功，一方面是对公司持续交付能力的肯定，极大地鼓舞了金融科技板块全体成员，另一方面也对我们的 DevOps 能力建设工作起到了积极的推进作用。同时，也非常感谢信通院各位专家在评估过程中对我们的帮助和指导，感谢我们E-Space投顾平台同事们的辛苦付出。

  

![](../Images/61d3984e017844d6ce600bbacce029cd.png)

中金财富信息技术规划总监 罗畅

**Q.****贵公司是如何决定加入 ****DevOps ****标准评估工作中的？**

**罗畅：**DevOps 是实现开发与运维的协同，以一系列自动化为基础完成软件的持续交付与持续部署，提高产品和服务的交付效率与质量的重要抓手。DevOps 标准，是由中国信息通信研究院牵头，联合多个企事业单位专家制定的行业标准，通过与标准对标识别差距，借鉴标准最佳实践并进行持续优化改进，对落地 DevOps、提升研发效能有着重要意义。

E-Space投顾平台团队作为中金财富全渠道部落的一个敏捷团队，2021年中金财富全面数字化转型，提出用“敏捷+创新”作为引擎，驱动一基两端三赋能的数字化场景落地，E-Space投顾平台在团队工作中，践行敏捷宣言，应用 DevOps 工作方法和流程，高度重视“软件开发人员（Dev）”和“IT运维技术人员（Ops）”之间沟通合作，透过自动化“软件交付”和“架构变更”的流程，来使得构建、测试、发布软件能够更加地快捷、频繁和可靠。在近两年的时间坚持不懈的追求Technical Excellence和Good Design，既完成了系统的重构和新功能的规划，又满足了业务发展的紧急需求，系统的稳定性和响应速度也不断提高，这也是我们决定加入 DevOps 标准评估工作的信心所在。

**Q.****通过 ****DevOps ****标准评估对您企业带来了什么帮助？对贵团队有哪些影响？**

****罗畅：****本次通过 DevOps 能力成熟度模型评估，证明了平台的阶段性建设有了显著的成果，DevOps 需求管理看板真正实现了业务与技术的融合，促进了平台整体交付成熟度的提升。

敏捷转型助力E-Space投顾平台可持续高质量建设。我们自2021年至今通过敏捷实践，已经初步实现了资产配置全流程线上化的目标。从技术方面来看，在公司敏捷转型、数字化驱动的背景下，投顾平台采取 DevOps 驱动升级，敏捷协作全面提速的工作方式，极大的提升了平台开发效率。产品需求是核心，我们通过对业务需求的分层管理和覆盖需求全生命周期的全景价值流和看板展示，在目标上保证了业务与科技岗位的层层对齐；过程上通过整合串接各研发工具链实现研发全过程的数字化协作，支持业务与技术对研发全链条的穿透式管理。对于敏捷开发而言，实现业务与技术融合、规范交付过程、缩短开发周期是三大突破点。

E-Space投顾平台团队在 DevOps 的理论学习与实践应用中，积累了丰富的经验，沉淀了一些独到的方法流程，在公司内部也作为先锋团队进行了多次分享与工作方法宣导，获得公司内部开发团队的一致好评。

  

![](../Images/7be8c9d99e16f9012a0215a3e34df99c.png)中金财富E-Space投顾平台

敏捷团队团队长 邓雅琳

**Q.****您可否详细的介绍一下，通过本次评估有哪些数据指标可以直观的体现项目改进成果？**

**邓雅琳：**在敏捷开发与 DevOps 一体化研发平台的双向加持下，项目平均迭代时间缩短了2-3天左右，在提升研发交付效率的同时，E-Space平台也大大缩短了开发时间周期。利用一体化研发平台提供静态代码扫描能力，可以在3-5分钟实现对一个应用系统代码质量的检查，有效提升开发人员CodeReview效率。同时通过 DevOps工具链集成可持续交付的自动化测试，设立各环境质量门禁，全面把控测试质量，接口回归测试从原来的1-3天缩短至目前的2-3小时，有效缩短了测试时间周期。

通过数月的敏捷— DevOps 双重整改，前后端代码静态扫描缺陷问题从200+降为0，单元测试覆盖率提升至50%以上，规范上线流程，实现业务需求+技术需求全覆盖，提供单周上线能力。从原来1-3天手工测试到目前平台接口自动化测试1小时内，有效缩短测试时间周期，持续监控系统测试环境稳定性，达到快速持续交付效果；设立各环境质量门禁规则，建立基于测试金字塔模型的测试分层策略，全面把控测试质量。

**Q：对于 DevOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？**

**邓雅琳：**我认为最大的收获是通过敏捷开发与 DevOps 工程化实践双向加持，内部效率得到显著提升，能够更快速地交付业务价值，并在业务效率与业务规模上不断提高。在E-Space新版客户360、产品360、学习发现及工作台等模块的助力加持下，员工的工作效率极大提升。

在后续的过程中，我们将结合我们的实际情况持续和深入地开展优化和实践落地，帮助公司内部更多的IT团队提升 DevOps 工程能力水平，作为中金财富侧首个通过了 DevOps 能力成熟度评估的团队，我们希望通过我们的努力使我司 DevOps 持续交付能力水平攀登上一个新的高度。

  

![](../Images/b399c875e54ed554939df5c55309076d.png)中金财富E-Space投顾平台

敏捷团队CL 孔培

**Q.****对于此次参评的项目，其****IT****系统有哪些特色，当时是怎么规划和设计的？**

**孔培：**通过拆解降维ONE CICC的全链资源，打造了网页端、移动端和企微生态赋能投顾。在技术架构层面采用分布式技术架构，运用领域建模思想进行横向和垂直的微服务化拆分设计，各微服务明确边界和职责，项目实施过程中，坚持对标 DevOps 方法论指导研发活动，落地构建出一套高效的需求、代码、构建、测试、发布、评价的“全景价值流”，再结合我们团队内部需求看板及迭代度数据看板，保障了系统的交付质量和效率。

**Q.****此次通过评估的过程顺利吗？遇到什么困难？如何解决的？**

**孔培：**成功路上总是充满曲折。在本次 DevOps 能力评估整改期间，其实我们的业务方面的革新在同步进行。尤其是我们首次进行1018品牌日焕新升级活动，打通了端到端之间的联系，并且对平台自身进行了一次大的版本升级。给我感触最深的就是我们团队的小伙伴们既要忙着进行 DevOps 能力评估又要忙着我们1018品牌日升级的工作，正是他们夜以继日的付出，才换来了我们今天所取得的成就。  

另一个人让我印象深刻的地方是进行 DevOps 能力整改的前期，由于对各能力项指标理解不深，各研运链路之间存在壁垒，使得我们的整改工作进行的并不顺利，一定程度上增加了我们的开发维护成本。最后，我们通过对各能力指标项的深化理解，剖析其背后的深层含义，并且打通我们研发运维链路上的壁垒。到现在，形成了独有的敏捷开发流于研运一体化研发平台相结合的持续交付能力，使我们感受到了 DevOps 能力评估给我们团队带来的正反馈。

**Q.****对于 ****DevOps ****的发展前景，您怎么看？**

**孔培：**随着越来越多的金融企业走上数字化转型之路，DevOps 变得比以往任何时候都更加重要。DevOps 在聚焦持续交付的过程中，提高团队效率、保证更高的安全性、缩短了软件发布时间、促进了快速可靠的软件交付、产出更高品质的产品，提高了客户满意度等等都有着举足轻重的意义。未来，DevOps 将不断发展和转变，中金财富会持续关注 DevOps的发展趋势，专注于持续改进成果，不断探索，提高运营效率，提升交付效能，在开发、IT 和业务团队之间建立更好沟通的催化剂，服务团队业务高质量发展。

**研发运营一体化（DevOps）能力成熟度模型介绍：**《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
