国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

2022年12月26日，中国信息通信研究院隆重公布了 DevOps 系列标准最新批次评估结果。

招商证券股份有限公司（以下简称“招商证券”）本次参评的项目为天工研发管理平台，该项目顺利通过信通院《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具标准“流水线”和“构建与持续集成”两个模块的优秀级评估，代表招商证券的 DevOps 系统和工具在相关模块达到国内领先水平。

截止目前，招商证券在2022年共通过 5 项中国信通院 DevOps 标准评估，其中包括：通过 DevOps 持续交付标准评估 2 项，通过 DevOps 技术运营标准评估 1 项，通过 DevOps 系统和工具标准的评估 2 项。

评估单位：中国信息通信研究院

中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：

此次，我们采访了招商证券金融科技中心总经理邓曙光先生和金融科技中心技术规划部总经理曾凡林先生，一同深聊团队在项目参与评估时的细节和故事，分享招商证券 DevOps 实践的经验。

-Q&A-

招商证券

金融科技中心总经理 邓曙光

Q：邓总，您好，请介绍一下贵公司此次参与评估的项目。

邓曙光：根据公司“1633”数字化战略布局，研发数字化是数字化转型的基础底座，通过建设 DevOps 研发运维一体化体系，加大数字化队伍的建设投入，逐步强化自主可控能力，为公司数字化转型提供坚实保障。我们非常重视研发数字化工作，在2021年就建立了一站式研发管理平台，打通了业务部门、研发部门、运维部门之间的工具链孤岛及协作壁垒，并通过组织级数字化度量体系可视化研发的过程数据。

本次我们参与评估的工具是“天工研发管理平台”，该平台以 DevOps 工程实践和敏捷管理实践为指导，兼顾稳态和敏态两种业务形态，覆盖了项目管理、需求管理、研发协作、代码仓库、持续集成、代码扫描、制品管理、测试管理、自动化测试、版本管理、度量中心、用户中心、软件资产管理、数字化研发门户等15+研发子领域，实现研发全生命周期的管理，为我司的研发数字化提供了组织级的平台支撑，是敏捷交付的核心底座，助力我司数字化转型。

Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是系统和工具标准两个模块的评估，请说一下您此时的感受。

邓曙光：非常高兴我司的天工研发管理平台项目通过信通院 DevOps 系统和工具标准中“流水线”、“构建与持续集成”两个模块的评估，并且均达到优秀级水平。取得这样的成果，是对我司的敏捷交付核心能力的认可，也是对我们 DevOps 研发数字化体系建设成果的肯定，为打造质效卓越、稳敏合一、数据驱动的“数字化产品”生产线夯实了基础。

Q：打造端到端的流程化、一体化的工具链对落地 DevOps 有多重要，您对这个问题怎么看？

邓曙光：落地 DevOps 是流程制度、方法体系、工具平台三位一体的融合，其中打造端到端的流程化、一体化的工具链是 DevOps 实践的核心底座，提供了研发、测试、发布等关键研发阶段的平台化能力，减少了各研发环节的无效等待，提升了研发协作效率，为我司研发管理数字化奠定了坚实的基础。

招商证券

 金融科技中心技术规划部总经理 曾凡林

Q：曾总，您好，通过本次项目评估，带给企业和团队哪些变化，项目的改进成功体现在哪些方面？

曾凡林：通过此次 DevOps 系统和工具标准评估，进一步完善了我司持续集成和流水线等相关 DevOps 领域的平台工具能力，缩短了研发团队从提交代码到部署环节的反馈周期，建立起了基于我司研发管理制度的质量门禁，规范了团队的 DevOps 工程实践，支撑了我司规模化 DevOps 实践推广。

天工研发管理平台通过本次评估累计功能完善优化近30项，其中在流水线编排方面增加了组织级和团队级的模板能力，提升了流水线的规范性，降低了流水线的使用门槛和编排时长；优化了构建缓存机制，提升了2倍的构建速度；完善了流水线和构建环境的权限体系，让流水线的管理更加灵活和精细化；完善了流水线的度量指标，丰富了研发团队的构建质量的评价维度；丰富了流水线的调度策略，提升了构建任务的企业覆盖场景。

Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?

曾凡林：在系统和工具标准评估过程中，一方面整个评估周期时间紧，压力大，在短时间内完成差距分析，识别出改进点，并完成工具平台改造，对我们是个很大的挑战，另一方面因为流水线、持续集成涉及对接的上下游工具链很多，例如：协同平台、代码库、代码扫描平台、制品库、发布平台、自动化测试平台等，涉及技术栈跨度大，我们遇到了一些工程技术上的难点，但是，在整个研发效能管理团队的不懈努力和攻坚协作下都被逐一解决了，顺利通过了工具评估。

Q：对于 DevOps 工作的开展，下一步计划有几方面？

曾凡林：招商证券目前已打造了统一的 DevOps 平台（天工研发管理平台），有效支撑组织级的持续集成和持续交付，后续会结合招商证券内部的研发管理诉求，持续完善平台能力和加强方法体系的导入，深度推广 DevOps 实践，借助 BizDevOps，全面塑造数字化能力，建立技术从“支撑使能”向“价值赋能”变革的数字化认知，运用“数据+技术”打造数字化劳动力，持续推动业务价值交付。

研发运营一体化（DevOps）能力成熟度模型介绍：

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
