# 燃！国信证券通过 DevOps 技术运营标准 2+ 级评估，相关能力达到国内领先水平

国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。  

2022年12月26日，**中国信息通信研究院隆重公布了 DevOps 系列标准最新批次评估结果**。

国信证券股份有限公司（以下简称“国信证券”）本次参评的项目为**乾坤集中运营平台非现场开户项目**，该项目顺利通过由中国信息通信研究院开展的《研发运营一体化（ DevOps ）能力成熟度模型》**技术运营标准 2+ 级评估**，代表国信证券在 DevOps 相关领域能力达到国内领先水平。目前，国信证券共有 1 个项目通过 DevOps 持续交付标准评估，2 个项目通过 DevOps 技术运营标准评估，1 个项目通过 DevSecOps 标准评估。**评估单位：中国信息通信研究院****中国通信标准化协会副理事长兼秘书长代晓慧女士和中国信息通信研究院云计算与大数据研究所所长何宝宏先生为企业授牌：**

![](../Images/c69c1e31afe392b4f2d740fb5e867d1e.png)  

此次，我们采访了国信证券系统运行总部负责人杨阳先生和金融科技总部交易系统开发部负责人李锋先生，一同深聊团队在项目参与评估时的细节和故事，分享国信证券 DevOps 实践的经验。

**\- Q&A -**

![](../Images/ff87946a44901b667673a9185829932f.png)

国信证券系统运行总部

负责人 杨阳  

**Q：请您介绍一下此次参与评估的项目。**

**杨阳：**国信证券始终秉持创造价值、成就你我、服务社会的理念，多年来在数字化领域不断深耕，是行业内率先开展财富管理数字化转型的证券公司。近年来，国信证券持续加大金融科技投入，技术与管理并重，实现科技赋能业务，助力公司数字化转型。

公司本次参评的项目是乾坤集中运营平台非现场开户系统，它是我司核心业务系统之一。乾坤集中运营平台非现场开户系统是我司自主研发，集受理、审核及管理三大平台于一体的数字化运营平台，为投资者提供7\*24小时无间断的业务服务，包括非现场开户、智能终端（VTM）开户等多渠道多终端开户服务、各类业务权限开通及业务资料变更等服务。

我司创新性实现了容器化非现场开户微服务，开户效率同比行业内传统的单体架构开户系统提升23%以上，为我司的业务展业奠定了坚实基础。

**Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是技术运营 2+ 级，达到国内领先水平，麻烦您说一下此时的感受~**

**杨阳：**我司系统运行团队一直以“打造稳定、高效、安全、具备优秀用户体验的数据中心运营服务，为公司创造价值”为使命，围绕着“学习、分享、协作、创新、持续改进”的团队文化和价值观，努力打造学习成长与持续改进的系统运行保障组织。积极拥抱创新，沿着“规范化-标准化-自动化-平台化-数字化”的发展路线，不断提升技术运营能力和系统服务质量，助力公司的业务发展和技术变革。

公司结合行业监管要求、ISO20000标准、DevOps 技术运营规范等，从“监、管、控、析、营”五个方面，围绕场景建设，基于数据驱动，积极打造完备的运维技术管理体系，涵盖故障的快速发现与有效预防、智能大数据诊断与定位、运维多维度平台自动化等多方面技术运营管理能力。以业务数字化转型为纽带，在 DevOps 良好实践的基础上，打通业务、研发、运营等各环节，缩短产品迭代周期，加快业务交付上线节奏，持续为业务数字化转型赋能。

乾坤集中运营非现场开户系统通过 DevOps 技术运营成熟度 2+ 级的评估，既是对系统运行团队 DevOps 技术运营体系价值的认可，也是对我司在技术运营领域多年技术和管理方面的探索与实践的肯定。

我司将以更快、更安全地交付更好的价值给到我们的客户为目标，在技术运营体系内不断深耕，为公司业务发展更好地保驾护航。

**Q：贵公司是如何考虑将此项目进行技术运营评估的？**

**杨阳：**我司在选取评估对象时，一是选择核心业务系统，充分检验我司系统服务能力；二是在技术上选择符合后续技术演进方向的典型系统，便于后续通过平台化建立组织级能力，以提升我司的整体系统服务能力。

经综合评估，选取了以微服务架构转型的乾坤集中运营平台非现场开户系统，通过项目的有序推进，该系统的技术运营能力达到业内领先水平，同时积累了相关经验，达到了项目预期。

**Q：通过此次 DevOps 标准技术运营部分评估对贵团队意味着什么？具体有哪些改进？**

**杨阳：**本次评估不仅是对团队多年技术沉淀的认可，也进一步巩固和提升我司技术运营能力水平，帮助我们更加精准把脉技术运营发展线路。中国信息通信研究院牵头制定的 DevOps 技术运营标准，为公司打造技术运营体系提供了有实践意义的行动指引。

本次在技术运营能力改进提升中主要有两点，一是通过改进应用系统、数据库与缓存的高可用架构，持续建设与完善运维工具与平台体系，保障乾坤集中运营平台7\*24小时的可用性与连续性，为用户提供良好的服务体验；二是完善了相关的管理保障体系和技术保障体系，通过运维场景的平台化实现了组织级技术运营能力的提升，辅之以持续改进的数字化运营手段，实现了运行管理的“全流程、全过程、全覆盖”管控，确保信息系统的可控、能控和在控。

**Q：关于 DevOps ，接下来团队有什么样的计划？**

**杨阳：**公司早在2020年就已经通过了金太阳资讯业务系统的技术运营 2 级评估,并以此实践经验在公司内部推广、优化和持续改进。乾坤集中运营平台非现场开户系统正是基于公司内部的平台化技术沉淀，顺利通过技术运营 2+ 级评估，此次评估将成为公司运营技术提升路线上的重要里程碑。

后续团队将以乾坤集中运营非现场开户系统项目所形成的平台化能力，以渠道和核心后台类关键业务系统为切入点，全面提升整体的运营技术能力。同时，公司将继续在技术运营领域深耕，结合证券行业和公司实际情况，制定和形成企业内组织级的技术运营标准，进一步优化和完善公司的技术运营体系，实现快速复制和推广，为客户提供更加极致的服务体验，为行业持续贡献可借鉴的良好实践经验。

![](../Images/fe1006c929f417b08d1fbf369a31da19.png)国信证券金融科技总部交易系统开发部负责人李锋  

**Q：对于此次参评的项目，其IT系统有哪些特色，当时是怎么规划和设计的？**

**李锋：**在规划和设计方面，乾坤集中运营平台以“前台统一运营终端、中台集中运营服务、后台连通业务系统”为建设目标，运用人脸识别、OCR、语音识别等前沿金融科技，打造公司集中、统一的数字化运营平台。技术体系采用微前端+微服务，系统开发采取高低码结合，研发管理模式采用敏捷研发+ DevOps 研发运营一体化模式。主要特色有：

*   **智能化：**把AI技术与业务流程融合共建，以智慧能力提升效率降低成本；
    
*   **敏捷化：**打破系统间壁垒，建立高速枢纽，推动流程提优、客户体验更好；
    
*   **一体化：**建立国信特色的受理—审核—管理体系，通过BI智慧驾驶舱与多重动态关联方式实时跟踪。

**Q：在项目实施过程中遇到什么困难？如何解决的？**

**李锋：**通过评估准备整体比较顺利，虽然在过程中也遇到了一些困难，但经过项目团队的共同努力，最终保证了项目的高效、高标完成。项目共计新建和优化了300多项系统能力。

项目实施过程中主要有两个难点，但通过大家齐心协力最终得以顺利解决。一是在用户体验指标方面，前期有较大差距，项目团队通过参考业内优秀技术方案，结合系统特色，针对事件上报、数据埋点、用户使用等多方面进行了技术攻关和定向突破，最终取得了很好的效果；二是在全链路动态扩缩容方面，对金融软件系统来说本身是存在一定风险的，金融行业本身对系统稳定性要求非常高，如何让系统平稳的扩容缩容是个业界难题，通过结合平台能力+业务模块改造，最终实现了稳定扩缩容的目标要求。

**Q：关于 DevOps 标准，您怎么看，对您企业带来了什么帮助？**

**李锋：**DevOps 标准明确了研运各能力成熟度级别要求以及效能度量指标，对标能力成熟度模型可以将团队或企业的现状可视化，并以此明确短板及改进方向；运用效能度量指标，可以持续、定期度量，量化可视化能力差距，并以此做出对应的改进措施。

DevOps 标准为我们提供了业界先进理论和框架指引，为提升公司研发效能提供了明确的目标和有效的方法。在技术实现上，通过对标 DevOps 能力成熟度模型分级标准，不断建设与完善平台级能力，提升研运效能；在系统保障能力上，促进了我司全面提升系统运行保障能力。

**研发运营一体化（DevOps）能力成熟度模型介绍：**  

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
