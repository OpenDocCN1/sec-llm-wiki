燃！中国邮政储蓄银行通过 DevOps 系统和工具标准评估，相关能力达到国内领先水平

国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。
2022年12月26日，中国信息通信研究院隆重发布了 DevOps 系统和工具标准最新批次评估结果。

中国邮政储蓄银行股份有限公司（以下简称“中国邮政储蓄银行”）本次参评的项目为DevOps研发协同平台项目和星辰平台金牛座自动化测试系统项目，两个项目均顺利通过中国信息通信研究院开展的《研发运营一体化（ DevOps ）能力成熟度模型》系统和工具标准最新批次评估。其中，DevOps研发协同平台通过系统和工具标准【流水线】【构建与持续集成】两个模块优秀级评估；星辰平台金牛座自动化测试系统通过系统和工具标准【接口/服务测试】模块优秀级评估。代表着中国邮政储蓄银行的 DevOps 系统和工具在相关模块达到国内领先水平。

目前，中国邮政储蓄银行共通过 6 项中国信通院 DevOps 标准评估。其中，通过 DevOps 持续交付标准评估 3 项，通过 DevOps 系统和工具标准评估 3 项。此外，中国邮政储蓄银行是首家通过 DevOps 系统和工具标准【接口/服务测试】模块的企业。

本批次评估将于2023年1月6日中国信通院主办的 “2022 GOLF+ IT新治理领导力论坛”上正式举行授牌仪式。


此次，我们采访了中国邮政储蓄银行软件研发中心总经理胡军锋先生和软件研发中心资深信息技术专家张兰英女士，分享中国邮政储蓄银行 DevOps 实践的经验。

-Q&A-

中国邮政储蓄银行

软件研发中心总经理 胡军锋


Q：胡总好，请介绍一下您和您的企业，以及此次参与评估的项目。
胡军锋：大家好，我是中国邮政储蓄银行软件研发中心总经理胡军锋，首先感谢信通院的采访邀请，很高兴能有机会给大家介绍邮储银行和邮储银行在 DevOps 上的实践。
中国邮政储蓄银行是中国领先的大型零售商业银行，定位于服务“三农”、城乡居民和中小企业，拥有近4万个营业网点，服务个人客户超过6亿户。2022年，在英国《银行家》杂志“全球银行1000强”排名中，邮储银行一级资本位列第13位。邮储银行深入贯彻新发展理念，紧扣高质量发展主题，将信息科技视为业务发展的核心驱动力，加快推进分布式架构转型和技术中台建设，通过实施 DevOps、开源治理等举措，持续提升IT治理能力水平，加速产品与服务创新，努力建设成为客户信赖、特色鲜明、稳健安全、创新驱动、价值卓越的一流大型零售银行。
2021年，邮储银行获评GOLF+IT新治理领导力论坛“杰出企业”，2022年，邮储银行再次获评“领军企业”，“DevOps 赋能邮储银行高质量发展实践”成功入选“年度卓越创新案例”，感谢信通院及业界专家对邮储银行IT治理和DevOps能力的肯定。
本次邮储银行参加了 DevOps 能力成熟度的系统与工具标准评估，星辰平台金牛座自动化测试系统参加接口测试工具能力评估，DevOps 研发协同平台参加构建与持续集成、流水线工具能力评估。星辰平台金牛座自动化测试系统致力于打造企业级自动化测试基座，为开发和测试人员提供UI自动化和接口自动化测试服务；DevOps 研发协同平台集项目管控、需求管理、组件管理、代码管理、持续集成、自动部署、度量分析等功能一体化，以 DevOps 理论为指导、数据为基础、工具为支撑，落地行内研发管理流程，实现IT全生命周期的规范管理。
Q：恭喜您通过DevOps 标准评估，此次贵公司项目通过的是系统和工具标准中的【接口/服务测试】【流水线】【构建与持续集成】三个模块，其中贵公司还是【接口/服务测试】模块首批通过评估的企业，请说一下您此时的感受。
胡军锋：很高兴邮储银行顺利通过接口/服务测试、构建与持续集成、流水线三个能力项评估。
2021年，我行开展了 DevOps 能力成熟度持续交付标准三级评估，实现了工程效率和质量提升，形成了适合邮储银行的 DevOps 最佳实践。今年我行再次与 DevOps 能力成熟度的系统与工具标准对标，进一步提升 DevOps 工具标准化支撑能力。
本次顺利通过系统与工具标准评估，说明邮储银行系统与工具能力、持续交付能力已经达到国内领先水平。尤其是作为首批通过接口/服务测试工具评估的企业，倍受鼓舞，这是业界和各位专家对我行自动化测试能力水平的高度肯定。我行2019年开始的探索、实践自动化测试，经历3年多探索，逐步形成现在统一的自动化测试基座和端到端的持续交付能力。能有今天这样的成绩，离不开领导的支持和大家辛勤的付出与努力，顺利通过 DevOps 标准评估就是最好的回报，此时此刻我们感到非常骄傲和自豪。
Q：流水线做为端到端价值交付的一个环节，您对这块的重要性怎么看？
胡军锋：在全球数字经济浪潮下，银行需要快速响应市场变化，快速为客户提供更有价值、可持续的金融产品服务。DevOps 打通需求、设计、开发、测试、部署、运维各个环节，将研发运维过程标准化、自动化，可有效提升产品交付效率，帮助企业实现高效的价值交付。
流水线是 DevOps 实施必不可少的技术手段和工具，流水线通过一组自动化流程将构建、测试、部署等任务、步骤串联起来，实现端到端全流程自动化、标准化，进而提升软件交付质量和效率，赋能业务创新。流水线可以进行灵活的编排以应对不同的场景需要。在构建阶段，可以根据需要进行流水线的灵活组合，解决依赖复杂、服务数量多、构建频繁等问题，提高构建效率和质量，节省人力成本；在发布阶段，可以通过多流水线的编排串联，实现多环境一键部署，串行流水线解决服务依赖问题，并行流水线提升发布效率，有效解决微服务架构部署难题，满足各种复杂场景的持续部署需要。
Q：贵单位参与本次系统和工具标准评估，请问企业有哪些考量？
胡军锋：随着数字化转型的快速推进，银行纷纷向业务敏捷化、体验场景化、产品个性化、服务生态化和运营数字化转型。数字化转型已成为金融业焕发新生的重要驱动力，已成为金融机构的必答题和必选项，高效的价值交付是数字化转型成功的关键因素。
邮储银行一直关注业内前沿技术和未来发展趋势，积极探索新技术、新方法并应用于工程实践。“工欲善其事，必先利其器。”优秀的系统和工具是 DevOps 成功实施的重要保障。邮储银行 DevOps 研发协同平台集成需求、设计、开发、测试等阶段的开发测试工具，提供标准的、自动化的任务管理、组件设计、持续集成、自动部署等能力，整合已有的研发过程辅助系统，串接数据及流程，形成企业级研发运营一体化合力，目前已服务全行178个项目；邮储银行星辰平台金牛座自动化测试系统作为面向企业级自动化测试平台，提供接口自动化、Web UI自动化、APP UI自动化、挡板服务等测试服务，目前已服务73个项目。
通过与 DevOps 系统与工具标准对标，可以借鉴业界最佳实践，进一步优化 DevOps 支撑工具，提高工程实施效率和交付质效，更好地实现价值交付。
Q：通过系统和工具标准评估带给企业和团队哪些变化？
胡军锋：顺利通过系统和工具标准评估，体现邮储银行的接口自动化能力和持续交付能力达到了行业领先水平。对标系统和工具标准，通过识别与标准的差距并进行持续改进，有效提升了邮储银行 DevOps 系统和工具能力，实现测试和交付的提质增效。主要体现在以下几点：
一是提升我行自动化测试能力水平。通过与标准对标，对自动化测试标准能力有了更为全面的认知，对自身工具的优势和短板有了比较客观的定位，从而可以有的放矢地进行优化改造。二是提升软件交付质效。对标标准和业界最佳实践，对软件产品端到端交付的各个环节进行全面梳理及优化，将研发运维过程标准化，形成完整闭环，很好地满足了跨部门、跨团队的高效协同需要。三是提升团队人员能力水平。本次评估对于参与其中的每个人都是一次很好的学习成长机会，在评估实践过程中，我们学习和借鉴业界的优秀实践，提升了自身能力，开阔了视野，也明晰了未来的优化方向。

中国邮政储蓄银行
软件研发中心资深信息技术专家 张兰英

Q：通过本次评估，项目的改进成功体现在哪些方面？
张兰英：大家好，我是中国邮政储蓄银行软件研发中心资深信息技术专家张兰英。
本次评估，邮储银行对标系统与工具标准的接口/服务测试、流水线、构建与持续集成能力项，充分学习和借鉴标准，根据现状找差距，对流程和系统进一步优化，有效提高了自动化测试和持续交付工具效率，全面提升 DevOps 系统工具支持能力。在测试方面，脚本建设时间减少70%，脚本维护时间减少50%，测试执行时间至少减少40%；在持续交付方面，构建成功率提升20%，部署成功率提升21%，构建时长降低40%，流水线时长降低30%。
Q：在系统和工具标准评估过程中的困难与解决办法，可以分享一下吗?
张兰英：本次评估过程总体比较顺利。各级领导给予项目组最大支持，软件研发中心统筹规划，各相关处室协同推进实施，大部分问题都能迎刃而解，参评项目才能在这么短的时间顺利通过评估。
今年9月，我行启动了 DevOps 能力成熟度标准对标，三个模块同期参加评估，时间上比较紧张，又受到疫情影响，团队成员时不时就需要远程办公，相对现场办公沟通交流略显不便，对实施进度有些影响。另外，前期我们进行了一些技术预研和功能优化，但对标标准时发现，还是有一些功能未达到标准的要求，团队成员必须要打破固有思维模式，深入理解标准的要求。
针对上述困难，项目团队同心协力，制定详细的改进计划，任务分配具体到人到天，按周开展迭代优化、复盘、问题回顾，持续提升各个能力项指标，逐步满足标准要求，最终顺利通过评估。
Q：对于 DevOps 工作的开展，下一步计划有几方面？
张兰英：DevOps 通过工具、流程、技术赋能，促进需求、开发、测试、部署、运维环节之间的高效协作，实现IT全生命周期的标准化、自动化、智能化，助力工程交付效率与质量全面提升。
下一步，我们将继续完善 DevOps 体系，持续总结最佳实践并进行全面推广，主要有以下几个方面：一是开展 DevSecOps 评估，与 DevOps 能力成熟度的安全与风险管理标准对标，开展端到端安全管控，覆盖工程实施全流程，降低交付、运营过程中的安全风险，保障研发运营一体化的整体安全。二是2023年继续开展测试计划管理、测试数据管理工具能力的成熟度评估，加快测试工具赋能，重塑测试价值，使测试过程更高效、测试覆盖更全面、测试成本更节约。三是将自动化测试与 DevOps 流水线进行深度融合，将自动化测试左移，进一步提升软件交付质量。四是全面推广 DevOps 端到端的最佳实践，实现邮储银行测试效率、交付效率和交付质量的全面提升。
Q：对于 DevOps 的未来发展方向，您有何看法？
张兰英：随着 DevOps 的广泛应用和数字技术的不断进步，企业的研发运营体系正在向多元化方向发展，DevOps 也正在向 XOps 快速延伸。大数据、AI技术在运维场景的应用，加快了运维从自动化到智能化的转变；云原生加持的 DevOps，让研发人员更专注于业务快速迭代，比传统 DevOps 具有更高的服务质量和更低的开发运维成本；混沌工程致力于在故障出现之前识别并修复故障，有助于构建更健壮更强的应用程序，更好地支撑业务发展。XOps 正在将实际业务与IT技术相融合产生的最佳实践，融入到研运一体化、效能度量、安全体系建设、智能化等多个方面，帮助企业实现数智化运营，推动业务价值高效交付，助力企业数字化转型。
未来，邮储银行将继续探索和总结 DevOps 最佳实践，加快推进 XOps 落地应用，持续提升工程研发效能，助力业务高质量发展。

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
