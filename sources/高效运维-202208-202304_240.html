国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！“以评促建，以评促改”，以评估为抓手，让 DevOps 标准更快更好落地，助力企业数字化转型。

2022年12月26日，中国信息通信研究院隆重公布了 DevOps 系列标准及 AIOps 系列标准最新批次评估结果。

国金证券股份有限公司（以下简称“国金证券”）参与评估的项目为国金佣金宝App波段掘金项目，该项目顺利通过信通院《研发运营一体化（ DevOps ）能力成熟度模型》持续交付 3 级评估，代表国金证券的 DevOps 相关能力达到国内领先水平。

本批次评估将于2023年1月6日中国信通院主办的 “2022 GOLF+ IT新治理领导力论坛”上正式举行授牌仪式。

此次，我们采访了国金证券财富委领导（执行委员）金融科技总监郑坚良先生、国金证券财富委科技开发中心总经理熊友根先生、国金证券研发效能部负责人杜铁绳先生、国金证券DevOps项目经理陈智豪先生和国金证券DevOps架构师李晨先生，一同深聊团队在项目参与评估时的细节和故事，分享国金证券 DevOps 实践的经验。

- Q&A -

国金证券财富委领导（执行委员）
金融科技总监 郑坚良


Q：您好，请介绍一下您和您的企业，以及此次参与评估的项目。

郑坚良：国金证券股份有限公司（以下简称“国金证券”或“公司”）前身为成都证券，经中国人民银行批准，成立于1990年12月，注册地在四川省成都市，是一家资产质量优良、专业团队精干、创新能力突出的上市证券公司，是上证180指数、上证180金融股指数、MSCI新兴市场指数成份股。

公司目前控股国金期货有限责任公司、国金鼎兴投资有限公司、国金创新投资有限公司、国金道富投资服务有限公司、国金金融控股（香港）有限公司，参股国金基金管理有限公司、国金涌富资产管理有限公司。截至2021年末，公司共下设8家分公司，69家证券营业部，分布在全国24个省（直辖市、自治区）的重要中心城市。

国金证券肩负“让金融服务更高效、更可靠”的使命，以“成为举足轻重的金融服务机构”为愿景，秉承【客户至上】、【视人才为公司最重要的资本】、【以开放的心态真诚沟通】、【团队合作】、【专业规范】、【持续优化】、【追求卓越】的核心价值观，致力于为客户提供证券交易、投资银行、资产管理、财富管理等全方位金融服务。

我们本次的参评项目是佣金宝App中的波段掘金项目，波段掘金是针对客户自有持仓股票进行买卖波段操作从而降低客户持仓成本的工具，主要包含三大业务目标，基于客户持仓情况进行个性化的股票择时信号推荐，提供特色股票咨询服务；客户签约免费，信号跟单盈利后才收取差异化佣金，以客户价值为第一要义；作为增值服务辅助工具，助力员工服务展业与拓客。

Q：恭喜您通过 DevOps 标准评估，此次贵公司项目通过的是持续交付 3 级，表明达到了国内领先水平，请说一下您此时的感受。

郑坚良：很高兴国金证券能够参与信通院牵头的 DevOps 研发运营一体化能力成熟度模型持续交付部分的评估，我们首个项目参评并达到了 3 级水平，这是对国金证券 DevOps 高效能研发模式转型的肯定，希望我们能不忘初心，继续探索 DevOps 技术在金融科技领域的应用和创新，赋能企业的数字化转型。

Q：贵公司是如何决定加入 DevOps 标准评估工作中的？

郑坚良：加入 DevOps 标准评估的目的是通过 DevOps 领域权威的标准体系落地企业的研发流程和规范，打造一套适配本地工具链生态，覆盖需求、开发、持续集成、测试、部署等环节的 DevOps 一体化平台，为企业软件研发工作提供平台支撑和技术保障，同时按信通院持续交付能力成熟度3级以上标准落地企业研发流程和规范，从而使研发过程更加透明化、标准化、自动化、数字化，提升线上协作效率和交付质量。


国金证券财富委科技开发中心总经理 熊友根

Q：通过 DevOps 标准评估对您企业带来了什么帮助？对贵团队有哪些影响？

熊友根：通过 DevOps 标准评估，企业在经济和社会两方面都产生了效益。

1、经济效益

  • 提升研发效率：通过标准规范的落地，显著提升了工作效率和质量。平台与现有工具链集成后实现了应用的持续集成和部署，打破了开发、测试和运维的隔离墙。将需求管理、开发、测试、构建、集成、部署、安全扫描等标准规范落地成可执行的操作体系（包含流程、工具、方法），使软件研发工作更加规范和高效。

  • 提升安全管控能力：代码、制品的统一管理和自动化扫描，有效降低了安全风险。

  • 研发过程管理可视化：通过工作流、价值流的统一，实现研发过程的高度可视化，项目各阶段和进展一目了然。

  • 研发过程数据可追溯：端到端的一体化平台深度融合了研发规范和标准，建立了精细化和自动化的度量体系，细分过程指标为团队研发效能持续提升找准方向，人效、质量等数据为持续改进提供了量化支撑。

  • 持续交付能力成熟度提升：通过 DevOps 一体化平台的建设提质增效的同时，逐步提升我司持续交付能力成熟度，达到行业领先水平（中国信通院 DevOps 持续交付能力成熟度三级）
2、社会效益

通过创新研发的 DevOps 一体化平台，我们积极响应中国证券业协会对证券业数字化转型的建议，即《关于推进证券行业数字化转型发展的研究报告》，给整个行业的数字化转型提供了宝贵经验。

Q：对于 DevOps 今年的实施，您觉得最大的收获是什么？您的下一步计划是？ 

熊友根：通过实施 DevOps，我们最大的收获是使企业管理更加透明、规范，并形成了企业在研发过程数据资产方面的核心竞争力。

1、DevOps 建设的目标旨在赋能国金的数字化转型。数字化的前提是信息化，通过信息系统的建设，我们把传统的线下的业务和管理模式搬到线上，使企业管理更加透明和规范化。

2、随着信息系统的建设，各部门开始形成的自己的数据资产（孤岛）。通过一体化平台建设，我们协同上下游的工作，使过程更加自动化，同时对端到端的过程数据进行治理，形成了整个企业在数据资产方面的核心竞争力。

3、数据最终要回归到复杂的业务场景，能指导企业的管理决策。我们计划对一体化平台进行持续迭代，从 DevOps 到 AIOps，实现企业管理的智能化，这也是我们正在持续探索的方向。


国金证券研发效能部负责人 杜铁绳

Q：对于 DevOps 的发展前景，您怎么看？

杜铁绳：2020年的8月份，中国证券业协会发布了关于《推进证券行业数字化转型发展的研究报告》，2021年初，国资委正式印发《关于加快推进国有企业数字化转型工作的通知》，明确数字化转型的基础、方向、重点和举措。在数字化转型过程中，众多组织通过 DevOps 实现了软件的价值交付和科技数据的落地。DevOps 通过转变企业的文化思维、打破有害的组织孤岛为持续变革和快速实验铺平道路，通过将人员、流程和技术结合在一起发现有助于组织改进的模式，帮助团队自我导向更好的解决方案，从而极大提高组织的敏捷性和客户满意度，帮助组织成功实现数字化转型。DevOps 正在成为一种新的研发模式，其最佳实践逐渐成为企业数字化转型的必经阶段，而这种趋势在以金融为代表的传统行业中尤为突出。


国金证券DevOps项目经理 陈智豪

Q：对于此次参评的项目，其IT系统有哪些特色，当时是怎么规划和设计的？

陈智豪：波段掘金作为券商典型的核心业务，和周边系统，如综合管理平台、恒生柜台和数研CRM平台，均有一定的交互。首先产品运营会在恒生柜台创建波段掘金商品；属于目标客群且满足前置签约条件的客户，可以通过佣金宝APP的前端进行签约，形成的订单会打到恒生柜台，同时签约成功的客户会收到综合管理平台的消息推送；签约成功的客户可以在APP、收件箱或微信收到投资顾问通过CRM平台推送的操作信号，可以在App前端的信号Tab下查看推送的信号、信号详情，并决定是否跟随信号进行股票买卖；恒生柜台会根据用户每笔的交易情况判断是否是有效跟单并计算差异化佣金；用户可以在App前端查看信号清单、前一交易日的跟单明细以及月度报告。

从技术架构来说，Java后端拆分了5个微服务并做了容器化改造，分别部署在同城双活的2个机房，单个机房的每个服务启起了2个pod实例；H5前端是非容器的，客户端请求首先通过F5负载触达机房的服务器，然后通过NG反向代理+Node服务转发的方式将请求分发到后端的微服务。

Q：此次通过评估的过程顺利吗？遇到什么困难？如何解决的？

陈智豪：此次评估的主要难题在于按三级标准打造适配国金研发现状的 DevOps 一体化平台，通过专家和团队协作，成功解决了如下3个挑战：

1、DevOps 一体化平台需全面提供项目协同、代码管理、制品管理、流水线管理、测试管理、部署管理、度量分析等能力，业务逻辑非常复杂。

2.、需适配企业现状，创新研发基于Gitlab Runner的底层流水线可视化编排引擎，基于Ansibile和ArgoCD的容器非容器双模多环境混合部署等功能，业界并无案例可以参考。

3、DevOps 一体化平台从0到1的建设需要深度融合精益、敏捷和 DevOps 等领域的专业技能，并结合企业的业务形态和研发工具链现状进行深度定制，高效协同业务试点团队、研发效能团队、测试团队、运维团队、DBA团队和平台开发团队进行上百人月的研发和改进。


国金证券DevOps架构师 李晨

Q：您可否详细的介绍一下，通过本次评估有哪些数据指标可以直观的体现项目改进成果？

李晨：通过 DevOps 标准和规范在一体化平台的落地，项目研发效能得到了显著的提升。DevOps 平台通过对研发工作涉及的大部分流程进行自动化从而提升了研发效率，比如平台自动创建分支、打tag、编译构建、打包上传、部署、上线审批和基线升级等功能。同时，持续集成和测试左移的理念和实践保证了研发质量和安全，包括持续集成、单元测试、静态扫描、自动化测试和制品扫描等步骤。度量数据方面：

1、存量单测代码覆盖率50%以上，增量覆盖率70%以上，成功率100%；
2、自动化API和UI测试门禁值100%，成功率90%以上；
3、平均每日向主干分支集成1.86次；
4、平均需求交付周期从一个月缩短到一周；
5、平均发布频率从每月1次提升到每月4次；

6、生产自动化部署成功率100%；

研发运营一体化（DevOps）能力成熟度模型介绍：
《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。

与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。研发运营一体化（DevOps）总体架构可划分过程（敏捷开发管理、持续交付、技术运营）、应用设计、安全及风险管理、系统和工具、业务价值管理、合作开发运维、持续测试等。
