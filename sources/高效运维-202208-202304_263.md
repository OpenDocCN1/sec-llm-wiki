Part.1

**DevOps Foundation®认证课程**

  

**课程介绍**

Course Introduction

DevOps Foundation® 是 DevOps Institute 独立认证的课程。本课程及其相关考试的目的是传授、测试和验证 DevOps 的基本词汇、主旨和实践知识。词汇术语表、概念和实践都包含在课程学习手册中。DevOps Foundation课程旨在培养个人对 DevOps Foundation 概念的理解以及 DevOps 如何用于提升软件开发人员和 IT 运维人员之间沟通、合作和集成的效率。

DevOps Foundation® 课程提供了对 DevOps 核心术语的基本理解，以确保每个人都在使用相同的语言，并强调了DevOps 在支持组织级成功方面的益处。

课程包含来自 DevOps institute 最新思想、原则和实践，包含对高效能组织真实案例的剖析，如ING Bank，Ticketmaster，Capital One，Alaska Air，Target，Fannie Mae， Societe Generale，and Disney。吸引并激励学员，利用多媒体和互动实践，将学习经验运用于实践。内容还包含对《凤凰项目》作者 Gene Kim 在书中强调的三步工作法以及《DevOps现状报告》中最新成果的重点讲解。

通过学习学员将深入理解 DevOps 的精髓，强调沟通、协作、集成和自动化，进一步帮助改善软件开发人员和IT运维人员之间的工作流。

  

**课程目标**

Course Objectives

DevOps Foundation®课程的学习目标包含对下述内容的理解：

*   DevOps 的目标及词汇  
    
*   对业务和 IT 的收益
    
*   相关的原则及实践，包括：持续集成、持续交付、测试、安全和a三步工作法
    
*   DevOps 与敏捷、精益和 ITSM 的关系
    
*   改善的工作流、沟通和反馈循环
    
*   自动化相关实践，包括部署流水线和 DevOps 工具链
    
*   重要成功因素和关键效能指标
    
*   现实中 DevOps 实践案例和结果
    

  

**目标人群**

Target Population

DevOps Foundation 认证体系的目标人群是希望能够掌握最新 DevOps 发展动态的所有专业人员。在 DevOps 团队中工作的任何人员，或正考虑转向 DevOps 的企业及该企业内的人员，都将受益于 DevOps Foundation 认证项目。

**DCA-智能运维能力培训课程**  

  

**课程介绍**

Course Introduction

人工智能和机器学习不断发展，传统的 IT 运维，也从自动化运维升级到 AIOps 时代。如何 将 AIOps 技术应用到企业及个人的实际运维工作中显得尤为重要。本课程通过对 AI 理论，算法，实操，以及案例的介绍，帮助大家深入理解 AIOps，并将其实际运用到工作中。

  

**课程目标**

Course Objectives

1.  掌握 AIOps 的主要算法，通过算法实操，结合具体 AIOps 应用案例，手把手教大家如何在实际工作中玩转 AIOps，解决运维难题。  
    
2.  从自动化到智能化，从被动运维到主动运维。
    
3.  参训人员通过培训，参加考核，成绩合格者统一颁发工业和信息化部人才交流中心《工业和信息化人才能力提升证书》，证书可以在工信部相关部门(工业和信息化部人才交流中心) 官方网站查询，全国通用，官方认证，可作为个人参加学习和更新知识的有效依据。
    

  

**目标人群**

Target Population

*   有一定基础的运维工程师（熟悉运维场景）
    
*   运维、开发、架构及 DevOps 工程师
    
*   对智能运维感兴趣的技术人员
    
*   由传统运维向智能运维转型的技术人员

Part.3

**SRE Foundation®认证课程**

  

**课程介绍**

Course Introduction

SRE(站点可靠性工程)Foundation 课程是对 SRE 原理和实践的介绍，使组织能够可靠且经济地扩展关键服务。引入 SRE(站点可靠性工程)需要组织重新调整，关注工程和自动化并采用一系列新的工作范式。  

该课程重点介绍了 SRE 的发展及其未来方向，并为参与者提供了实践，方法和工具，以使整个 组织中的人们参与到可靠性和稳定性中，这些案例通过使用真实场景和案例来证明。完成课程后， 学员将在回到公司后可以切实地利用，了解、设置和跟踪服务水平目标(SLO)的内容。

该课程使学习者能够成功完成 SRE Foundation 认证考试。

  

**课程目标**

Course Objectives

SRE Foundation 课程的学习目标包括对以下方面的实践与理解：

*   SRE 的历史及其在 Google 中的实践
    
*   SRE 与 DevOps 和其他流行框架的相互关系
    
*   SRE 背后的基本原则
    
*   服务水平目标（SLO）及其用户关注点
    
*   服务水平指标（SLI）和现代化的监控环境
    
*   错误预算和相关的错误预算策略
    
*   可观测性可以指示服务的运行状况
    
*   SRE 工具，自动化技术和安全性的重要性
    
*   抗脆弱性，我们的失败和失败测试方法
    
*   引入 SRE 带来的组织影响
    

  

**目标人群**

Target Population

*   SRE Foundation 课程的目标受众是专业人员，包括:
    
*   任何对更高可靠性感兴趣的人
    
*   任何对现代 IT 领导力和组织变革方法感兴趣的人
    
*   包含但不限于下述的 IT 角色：SRE 工程师 、业务经理 、商业利益相关者 、顾问 、DevOps 从业者 、IT 主管 、IT 经理 、IT 团队负责人 、产品负责人 、Scrum 大师 、软件工程师 、系统集成商 、工具提供者
