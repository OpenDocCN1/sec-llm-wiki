# 祝贺！软通动力 DevOps 团队荣获“互联网行业DevOps领域明星团队”奖项

2022年10月28日，“**GOITI 2022 IT技术领导力年度颁奖盛典**”在上海隆重举行。本次年度盛典已经是第6届了，依然由高效运维社区（GreatOPS）和 DevOps 时代社区联合主办，相关奖项在千人技术峰会——GOPS全球运维大会·上海站的主会场隆重颁发，近百家单位出席了本次 IT 行业的盛大活动。

本次活动旨在通过对IT行业从业者、产品、企业、服务商的横向评选及表彰，鼓励IT行业企业及IT人才持续进行技术创新和探索，引领IT行业技术发展。

颁奖盛典上，GOITI 2022 IT技术领导力年度颁奖盛典评选活动结果隆重公布。其中，**软通动力信息技术（集团）股份有限公司“软通动力 DevOps 团队”荣获互联网行业DevOps领域明星团队奖项**。

![](../Images/11294732cf570d29850818167b56150c.png)

作为 DevOps 规范任务组成员单位，软通动力具备成熟的 DevOps 端到端建设能力。迄今为止，软通动力已成功协助多个客户实现了 DevOps 相关工程实践落地，并围绕这一过程研发了相关体系化支撑工具，在相关领域积累了丰富的经验。

软通动力 DevOps 团队由公司技术研究院领导，专注于数字技术行业 DevOps 效能提升，致力于为集团内外部客户实现以 DevOps 为核心的云原生数字化转型，协助用户搭建以云原生、微服务化为架构、插件化设计的一站式 DevOps 平台，推动传统行业数字化转型与发展。团队拥有丰富的软件工程管理、企业IPD研发流程实践经验，核心牵头人具有10多年操作系统、虚拟化、容器、云计算研发管理经验，是国内第一批云计算、大数据技术专家。  

当前，在 DevOps 团队的主导推动下，公司对内部平台工具实现进一步的整合与贯通，改进了公司级端到端持续交付平台能力；同时，推进公司研发过程规范得到进一步细化和落地，更具可操作性，帮助实现了研发效能与质量的可观测、可度量、可改进，为 DevOps 高效研发体系在公司内部持续推广和优化提供了重要基础与参考依据。  

此外，团队打造的软通动力ISSCloud云原生 DevOps 平台，是企业快速建立易用、稳定软件发布内部开发者平台的得力工具，提供覆盖组织、流程、技术（工具）的 DevOps 落地咨询，给出研发管理流程落地的最佳实践方案，帮助客户快速形成软件工程能力，获得持续改进收益，助力企业高效数字化转型。
