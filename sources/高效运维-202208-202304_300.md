# 辽宁移动信息技术中心总经理王欣先生荣获“通信行业年度风云人物”奖项，并接受专访

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651726120&idx=4&sn=7494b54bc92a9c87b79226d5308f83cb&chksm=8bc8e281bcbf6b9776f439cb0f8c02651b1ae4d8d7eec39f715d72861a908ac9e1ffda1a3e65&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651726120&idx=4&sn=7494b54bc92a9c87b79226d5308f83cb&chksm=8bc8e281bcbf6b9776f439cb0f8c02651b1ae4d8d7eec39f715d72861a908ac9e1ffda1a3e65&scene=27#wechat_redirect)

2022年10月28日，“**GOITI 2022 IT技术领导力年度颁奖盛典**”在上海隆重举行。本次年度盛典已经是第6届了，依然由高效运维社区（GreatOPS）和 DevOps 时代社区联合主办，相关奖项在千人技术峰会——GOPS全球运维大会·上海站的主会场隆重颁发，近百家单位出席了本次 IT 行业的盛大活动。

本次活动旨在通过对IT行业从业者、产品、企业、服务商的横向评选及表彰，鼓励IT行业企业及IT人才持续进行技术创新和探索，引领IT行业技术发展。

颁奖盛典上，GOITI 2022 IT技术领导力年度颁奖盛典评选活动结果隆重公布。**中国移动通信集团辽宁有限公司信息技术中心总经理王欣先生荣获“通信行业年度风云人物”奖项**。

![](../Images/22543a0dfa0cbc3ae2bd9672fa578140.png)

同时，中国移动通信集团辽宁有限公司信息技术中心总经理王欣先生受邀参加了主办方的专访。**\- Q&A - **![](../Images/c34e1e3a934ea09151d150b948e03cc0.png)

辽宁移动

信息技术中心总经理 王欣

**个人简介：**王欣，辽宁移动公司信息技术中心总经理，中国移动业务支撑网专家，亚太地区首批Oracle大师级专家（OCM），致力于智慧中台建设运营、自研能力锻造等，为打造信息服务与科技创新型企业注智赋能。多年来他始终坚持“实力、实战、实效”的价值导向，发挥技术专长，主动突破创新，围绕数据库管理、主机管理、架构设计等工作，带领团队产出国家技术发明专利60余项，曾获 “全国工人先锋号”“中国移动劳动模范”“全国通信行业企业管理现代化创新成果奖”“中国移动业务服务创新优秀奖”“省自然科学学术成果奖”等荣誉。**Q：您好，请先介绍一下您和您所在企业。**

**王欣：**我是辽宁移动王欣**。**辽宁移动隶属于中国移动通信集团，负责中国移动在辽宁的网络建设和业务经营，为地方社会提供全方位的数字化服务。在省委省政府和集团公司的战略指导下，经过辽宁移动人数十载的不懈努力，移动客户规模突破3000万，家庭客户达到600万户，服务企事业单位40万家，累计纳税350亿元，是辽宁地区网络规模最大、客户数量最多的数字化服务商。辽宁移动信息技术中心成立于2017年9月，由原信息技术中心和业务支撑中心合并而成，现任班子成员（党总支委员会）4人，专业科室（基层党支部）12个，主要负责公司IT云架构规划建设，PaaS层维护，智慧中台建设运营以及业务支撑系统、网管支撑系统、管理信息系统和大数据平台的建设、运营和维护工作。

**Q：恭喜您获得 2022 IT 技术领导力年度评选的通信行业年度风云人物荣誉奖项，能谈一下您现在的感受吗？**

**王欣：**很高兴荣获2022IT技术领导力年度风云人物。

首先，感谢主办方，也感谢集团公司、省公司各位领导和同事，这个奖项不是给我个人的荣誉，而是对辽宁移动IT团队的肯定。辽宁移动IT团队多年来始终坚持以高质量党建统领高质量发展，持续推进大IT“1422”规划：发挥技术要素、数据要素对公司数智化转型发展的放大、叠加、倍增作用，以打造“一个智慧中台”为中心，深耕IT全域四项规划，提升自主可控能力；内外兼修，畅通以外为主、内外互促的“双循环”机制，提升面向用户的“敏捷交付的开发能力、精准赋能的运营能力”两大能力。

我们获得不仅仅是一份荣誉，更是一种鞭策，我们将不忘初心，砥砺前行，助力公司成为世界一流信息服务科技创新公司。

**Q：请您介绍一下您和您的团队在数字化转型方面有哪些成功经验？对企业的整体发展起到哪些积极作用？**

**王欣：**加速数字化转型，已成为“十四五”发展基调，各行业纷纷围绕“数字化转型”进行全方位、战略性布局。中国移动创世界一流力量大厦明确了“推进数字化转型，实现高质量发展”的发展主线，杨杰董事长指出“智慧中台是推进产业转型升级的重要创新，是‘两个新型’的重要组成部分与关键能力底座”。

企业数字化转型有助于推动管理模式和理念创新，激发企业发展内生动力。2020年至今，辽宁公司积极落实集团公司智慧中台战略部署，边建设、边运营、边完善，先后上线了涵盖个人市场、家庭市场、政企市场、网格运营、智慧网维、精细化管理等六大领域的115个业务场景，持续为一线赋能，为运营注智，助力公司数字化转型和高质量发展。

辽宁公司推动生产方式、生活方式、治理方式数字化转型的步伐持续加快，IT驱动公司转型升级面临新挑战。重构IT生产关系，推进供给侧结构性改革势在必行，实现“传统研发模式向敏捷研发模式的演进”是改革的重要路径。在此背景下，辽宁移动参照集团公司磐舟和磐基统一技术底座以及智慧运维最新理念与最佳实践，从DevOps人员团队建设、持续交付工具、云原生部署架构和智能运维体系四个方面对研发运营一体化（DevOps）能力进行整体规划：

**一是人员团队建设。**建立数字化转型IT人才管理体系，锚定现有职位人员未来转型方向，并通过转型培养实现其能力提升，持续打造“懂技术、懂需求、懂客户、懂市场”的“四懂团队”，以“专业创新、协作担当、敬业责任”为核心价值，努力成为公司数字化转型先锋、智慧服务基石、自主创新表率、数据赋能专家。

**二是持续交付工具。**打造研发运营一体化平台，保证 DevOps 的工程实践，缩短从业务想法的提出到实现和交付的时长；设立电子看板，实现需求流程端到端的数据统一展现，消除业务需求交付过程中的一切阻碍和等待，让IT交付节奏，跟上业务发展的需要。

**三是云原生架构。**打造容器云平台，实现统一云原生技术底座，提供云原生组件技术生态，通过弹性计算实现资源弹性调度，形成统一的服务治理框架，推动全域应用容器化迁移改造。引入灰度流量网关，建立灰度发布机制，实现无DB变更需求的部分用户在线可控升级。

**四是智能运维体系。**通过完善云原生复杂环境下容器化、微服务化资源动态管理及监控运营体系建设，夯实端到端故障治理能力，加速 AIOps 落地生产，深度技术运营，优化自动化运维能力，减少人为干预，逐步向无人值守方向演进，重点围绕业务应用，深耕“故障自愈”“营业厅开门测”等自动化运维场景，拓耕场景覆盖，实现系统运行的连续可用性和安全稳定。

**Q：能否介绍一下 DevOps 在您所在企业的落地进程，过程中遇到了哪些困难？是如何解决的？**

**王欣：**在进行 DevOps 落地和敏捷试点的过程中，遇到了一些痛点问题：

**一是在开展 DevOps  转型实践的过程中，并未形成可复制的系统方法论，尤其是缺乏相关领域的人才**。为此，我们加入了由中国信息通信研究院指导，云计算开源产业联盟、开放运维联盟联合发起的“企业级 DevOps 赋能（共促）计划”，和更多优秀企业交流学习，了解行业最佳实践；另外我们派遣骨干人员参加外部学习，先后16人次通过相关培训认证，为后续推广 DevOps 储备了充足的人才。

**二是面对全新开发模式与系统工具，付出了一定的学习成本**。如编译方式由ANT转为Maven；版本控制工具由SVN切换为Git并且引入制品库Nexus，开发人员需要自行写编写单元测试等。通过对开发、测试和运维人员进行培训和选取试点团队进行转型两方面举措，逐步推广全新的开发模式及系统工具，减少模式和工具更换对整个团队的影响。**三是 DevOps 理念与公司现行的IT管理要求相冲突**。如 DevOps 强调单一可信数据源，代码要求一次编译，在不同环境进行部署。而传统情况下，出于安全性的考虑，测试环境与生产环境是隔离的，需要将测试环境验证过的代码在生产环境重新编译打包。

针对与公司现行IT管理要求的冲突，我们经过咨询行业专家，结合本地开发实际的特点，采用其它替代方式来满足 DevOps 的要求。如测试环境和生产环境隔离的问题，我们将部署环境由虚拟机切换为容器，将代码与环境分别打包，生成为一个镜像，通过制品晋级由测试制品库晋级到生产制品库，生产环境拉取生产制品镜像并进行部署，来解决该问题。

**Q：我们整个社会都在提倡数字化转型，对于 DevOps 在企业数字化转型中的作用，您个人有什么见解？**

**王欣：**每一次产业变革都从革命性的技术开始，围绕它建立新的基础设施，形成新的技术和管理范式，最终彻底变革整个产业。以5G、云计算、大数据、人工智能、IoT等为代表，新的数字化基础设施已经就绪，并将继续演进。更重要的是与之配套的技术和管理范式的转变，如：数字化转型路径、面向数字化的组织、数字化的全链路协同、数字化时代的IT研发模式。其中 DevOps 已成为数字化时代IT研发和管理范式，并成为企业数字化转型重要的组成部分。

**Q：能否简单介绍一下您所在企业下一步数字化转型的规划以及对未来的展望？**

**王欣：**我们将在现有 DevOps 研发体系基础上，以敏捷交付为目标，进行开发模式的转型，在CRM全域推广敏捷开发模式，探索适合辽宁移动IT领域的企业级敏捷交付标准，进一步完善敏捷开发流程，拓展研发运营一体化平台，建立敏捷人才培养机制，实现组织的敏捷转型，帮助组织顺应数字化变革的要求。让技术发挥其核心作用，加速业务发展，引领业务创新，是我们追求的目标！
