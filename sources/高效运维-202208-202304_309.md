# 祝贺！辽宁移动信息技术中心中台运营室荣获“通信行业 DevOps 领域风云团队”奖项

2022年10月28日，“**GOITI 2022 IT技术领导力年度颁奖盛典**”在上海隆重举行。本次年度盛典已经是第6届了，依然由高效运维社区（GreatOPS）和 DevOps 时代社区联合主办，相关奖项在千人技术峰会——GOPS全球运维大会·上海站的主会场隆重颁发，近百家单位出席了本次 IT 行业的盛大活动。  

本次活动旨在通过对IT行业从业者、产品、企业、服务商的横向评选及表彰，鼓励IT行业企业及IT人才持续进行技术创新和探索，引领IT行业技术发展。

颁奖盛典上，GOITI 2022 IT技术领导力年度颁奖盛典评选活动结果隆重公布。其中，中国移动通信集团辽宁有限公司“**信息技术中心中台运营室**”荣获**通信行业 DevOps 领域风云团队奖**。

**团队简介及建设背景**

![](../Images/8d666020d01b25202edad14722529cd9.png)

团队合影

习近平新时代中国特色社会主义思想明确了新时代我国社会主要矛盾是：“人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾”。辽宁移动始终将提供卓越的信息化服务，满足人民美好生活需要作为奋斗目标，紧紧抓住“人心红利”，通过供给侧结构性改革，不断丰富产品权益和提高服务质量，赢得客户信赖，提高客户的满意度和获得感。

供给侧结构性改革要求IT部门能够对市场需求进行迅速、高效的响应。然而，快速增长的业务需求与有限研发资源之间一直存在矛盾，如何提高研发效能，快速上线业务需求，支撑市场发展，助力组织数智化转型，是IT支撑系统始终面临的挑战。因此，辽宁移动对标业界最佳实践，结合通信行业业务支撑领域开发特点，以渠道集中化平台为试点，通过引入敏捷方法论，探索基于Scrum方法的敏捷开发组织和流程体系，建设 DevOps 工具链，进行持续集成和持续部署，实现业务系统的快速迭代。在此过程中，通过建立人才培养机制，打造能够应对快速市场和技术环境变化的跨职能和自组织团队，形成可落地的敏捷实践，实现以交付高质量、高价值需求为导向的开发模式转型，提升业务敏捷开发和持续交付能力，提高内、外部客户满意度，助力企业数智化转型。

**团队项目的建设方案**

**1、定目标（目标是 DevOps 体系的根本方向）**

以业务为源头，打通从业务到开发再到运维的整个流程，将业务、产品和运营的有机融合，实现以交付高质量、高价值需求为导向，以快速迭代、持续优化为的开发模式转型，进而提升业务敏捷开发和持续交付能力，提高内、外部客户满意度。

**2、立流程（流程是 DevOps 体系的根本保障）**

引入Scrum方法论，结合实际开发管理流程，构建可实操落地敏捷开发体系，制定敏捷标准和框架，形成基于Scrum方法敏捷开发组织保障和流程保障。

![](../Images/652dfc970aa12cf29e21798bf275794b.png)

**3、建团队（团队是 DevOps 体系的重要基石）**

建立敏捷管理人员培养机制，通过学习和交流等方式实现人员培养，打破传统开发、测试、运维团队独立模式，努力打造一只能够应对快速市场和技术环境变化的跨职能和自组织团队。

![](../Images/f2339f7edce5c1c74fa7166c2bdc26cb.png)

**4、搭系统（系统是 DevOps 体系的有利抓手）**

建设 DevOps 研发运营一体化平台，引入自动化测试、持续集成/持续部署工具，实现试点项目（渠道集中化平台）版本发布和上线部署的统一管控。

**团队遇到的难点及问题**

团队在 DevOps 转型过程中确实遇到了一些难点：  

**一是在开展 DevOps  转型实践的过程中，并未形成可复制的系统方法论，尤其是缺乏相关领域的人才**。为此，我们加入了由中国信息通信研究院指导，云计算开源产业联盟、开放运维联盟联合发起的“企业级 DevOps 赋能（共促）计划”，和更多优秀企业交流学习，了解行业最佳实践；另外我们派遣骨干人员参加外部学习，先后16人次通过相关培训认证，为后续推广 DevOps 储备了充足的人才。

**二是面对全新开发模式与系统工具，付出了一定的学习成本**。如编译方式由ANT转为Maven；版本控制工具由SVN切换为Git并且引入制品库Nexus，开发人员需要自行写编写单元测试等。通过对开发、测试和运维人员进行培训和选取试点团队进行转型两方面举措，逐步推广全新的开发模式及系统工具，减少模式和工具更换对整个团队的影响。**三是 DevOps 理念与公司现行的IT管理要求相冲突**。如 DevOps 强调单一可信数据源，代码要求一次编译，在不同环境进行部署。而传统情况下，出于安全性的考虑，测试环境与生产环境是隔离的，需要将测试环境验证过的代码在生产环境重新编译打包。

针对与公司现行IT管理要求的冲突，我们经过咨询行业专家，结合本地开发实际的特点，采用其它替代方式来满足 DevOps 的要求。如测试环境和生产环境隔离的问题，我们将部署环境由虚拟机切换为容器，将代码与环境分别打包，生成为一个镜像，通过制品晋级由测试制品库晋级到生产制品库，生产环境拉取生产制品镜像并进行部署，来解决该问题。

**项目系统亮点展示**

辽宁移动 DevOps 研发运营一体化平台，通过引入自动化测试、持续集成/持续部署工具，实现系统版本发布和上线部署的统一管控。DevOps 研发运营一体化平台主要包括统一门户(AIDO)、持续交付流水线（CMP）、自动化测试平台（智测云ATP）、度量平台。

其中，统一门户(AIDO)是平台的“一站式”门户，为项目管理人员、开发人员和测试人员提供统一的操作入口。

![](../Images/c14db36664a0ec933f0123e3c2c118cd.png)

持续交付流水线（CMP）打造了需求开发、质量保证、投产部署的价值交付链，通过流程引擎将各项基本服务串接起来。

自动化测试平台（智测云ATP）是组织级的自动化测试自服务平台，和上下游需求、变更管理系统打通，进行自动化测试用例的统一管理，实现自动化测试资源池化以及自动化测试结果的自动分析。

**成果及荣誉**

自2019年10月份渠道团队引入试点以来，交付需求数量由月均49个上升到58个、需求缺陷率由12下降到2（单位：个/100个故事）、单元测试增量覆盖率达到80%，接口自动测试覆盖率达到100%。同时，随着试点工作持续推进，团队的人员的工作主动性、业务能力也有了明显提升。
