 Meta 史上最大裁员开始，扎克伯克视频道歉

11月9日，Meta 首席执行官扎克伯格在一封公开信中宣布，计划裁员1.1万人，占其员工总数的13%。除了裁员外，扎克伯格称还将实施其他削减成本的措施，以使公司变得“更精简、更高效”，具体措施包括削减可自由支配支出，并在2023年一季度酌情削减开支，以及将招聘冻结期延长至第一季度。

据报道，Meta核心广告业务受到苹果公司隐私变更、广告商收紧预算及TikTok短视频平台等竞争，导致Meta公司第二季度收入大幅下降，其利润较去年减少了一半。Meta 去年市值超1万亿美元，此后跌至2500亿美元左右。

“宏观经济低迷、竞争加剧和广告损失导致我们的收入比预期要低得多。”扎克伯格说道，“我做错了，我想对此负责。”

 salesforce 计划裁员 2500 人
Salesforce 周二证实，因一些国家和行业的需求减少，该公司本周裁减了一些销售团队的员工。一位知情人士表示，赛富时周一解雇的员工数量达到近千人。有媒体此前报道了该公司的裁员情况，称可能会影响多达2500名员工。
Salesforce 8月发布了低于预期的全年业绩指引，其股价次日下跌3%。该公司财务主管Amy Weaver对分析师称，中小型企业的需求已放缓，尤其是在北美和欧洲，涉及的行业包括通信、媒体和零售业。赛富时联合创始人兼联合首席执行官 Marc Benioff 表示，预计更长的销售周期和更严峻的企业采购形势仍将持续。

 神反转：马斯克取消远程办公、求被裁工程师复职

除在推特服务器上削减 10 亿美元基础设施成本、求被裁工程师复职，马斯克本周又出大新闻。

当地时间周三晚间，推特新公司老板马斯克向员工发送第一封邮件，要求他们为“未来的困难时期”做好准备，并将取消远程工作，除非经他亲自批准。

马斯克表示，经济前景将对推特这样的广告公司造成负面影响，没有办法粉饰这一信息。他指出，推特将不再允许远程办公，员工必须每周至少在办公室工作40小时，但他本人会批准一些例外情况。

马斯克已经入主推特近两周了，在此期间，他对推特进行了大刀阔斧的改革，大约有50%的员工和高管被解雇。

马斯克还将推特标志性的蓝色认证标记将作为8美元/月的付费订阅功能，马斯克在邮件中告诉员工，他希望看到付费订阅功能占到推特收入的一半。

 万维网之父称 Web3 根本不是 Web

在 1989 年发明 World Wide Web 的蒂姆·伯纳斯-李认为 Web3 根本不是 Web，我们应该忽略它。在里斯本举行的 Web 峰会上，这位英国计算机科学家说，讨论新技术的影响首先需要澄清其意义，必须理解正在讨论的术语的实际含义。他说令人遗憾的是真正的 Web3 被以太坊贩子拿去描述区块链相关的东西，而 Web3 根本不是 Web。

今天大部分人所说的 Web3 与区块链、加密货币和 NFT 相关。他不认为区块链是构建下一代互联网的可行方案。伯纳斯-李正在领导一个去中心化 Web 项目 Solid，Web3 不是 Web 3.0，他认为区块链对 Solid 没有好处，它太慢太昂贵太公开，而旨在让用户掌控个人数据的 Solid 需要快、便宜且私有。

 全球人口即将达到 80 亿

据《世界人口展望2022》，到本月15日，全球人口将达到 80 亿。这一数字在今后几十年里将持续增长，但增速会有所放缓，且存在地区差异。

据统计，1950年全球人口25亿，达到80亿意味着增加两倍多。由于预期寿命和育龄人口增加，联合国预计到2030年全球人口增加至85亿左右。

 币安收购竞争对手 FTX

11月9日，币安创始人兼CEO赵长鹏 在社交平台发文称，“今天下午，FTX向我们寻求帮助。FTX存在严重的流动性困境。为了保护用户，我们签署了一份不具约束力的意向书，打算全面收购 FTX，并帮助解决其流动性危机。我们将在未来几天进行全面的尽职调查。
