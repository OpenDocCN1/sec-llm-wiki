# 交通银行软件开发中心副总经理李锐先生荣获“银行业年度风云人物”奖项，并接受专访

2022年10月28日，“**GOITI 2022 IT技术领导力年度颁奖盛典**”在上海隆重举行。本次年度盛典已经是第6届了，依然由高效运维社区（GreatOPS）和 DevOps 时代社区联合主办，相关奖项在千人技术峰会——GOPS全球运维大会·上海站的主会场隆重颁发，近百家单位出席了本次 IT 行业的盛大活动。

本次活动旨在通过对IT行业从业者、产品、企业、服务商的横向评选及表彰，鼓励IT行业企业及IT人才持续进行技术创新和探索，引领IT行业技术发展。

颁奖盛典上，GOITI 2022 IT技术领导力年度颁奖盛典评选活动结果隆重公布。**交通银行股份有限公司软件开发中心副总经理李锐先生荣获“银行业年度风云人物”奖项**。

![](../Images/b7c0d798bc74ef39b7672d6e1d61aa19.png)

**个人简介**  

![](../Images/7bd117a4851455197e1ca0527fc2ee04.png)  

交通银行软件开发中心副总经理 李锐

李锐，具有二十多年金融行业工作经验，曾任研发部门副高级经理、运维部门高级经理、现任交通银行股份有限公司软件开发中心副总经理职位。曾参与交通银行大集中项目、531工程、新531工程、数字化转型项目建设，并主导建设企业级数据交换平台、企业级安全系统、主导搭建应用运维标准化规范化总体框架，有非常丰富的开发运维一体化经验和独到的见解。2021年度开始主导交通银行 DevOps 成熟度评估项目，交通银行 DevOps 平台-软件研发支撑平台项目，获得3级评估和多个奖项。曾多次获得人民银行科技发展奖、上海金融创新奖、世界人工智能大会SAIL奖TOP30榜单。  

![](../Images/c27dd588b5f6d8bab41d67087ed79622.png)

**个人及其团队重点项目介绍**

2021年度主导智慧人资与跨境金融两个项目顺利通过中国信通院 DevOps 能力成熟度模型评估持续交付 3 级评估。  

智慧人资团队通过敏捷开发模式实现业务需求的快速响应和功能迭代上线，同时持续进行测试前移、质量内建以及自动化测试工作，实现交付效率和质量的同步提高。

跨境金融综合服务平台项目使用交行自研工作平台，打通需求、研发、运维、度量全流程，形成了高度自动化的研发运维一体化的软件交付过程。

同时，主导推进了建设交通银行的 DevOps 平台-软件研发支撑平台。软件研发支撑系统目前已支持交通银行200多套主系统，软件研发支撑系统流水线实现了构建、部署一体化，近期平台日均构建700次，原后台工程手工构建时长均值15分钟，使用流水线后构建均值3分钟，效率提升80%。

另外，2022年 DevOps 成熟度评估项目正在开展顺利推进中，共3个持续交付项目，1个安全项目，预计于本年度11月底参加正式评估。
