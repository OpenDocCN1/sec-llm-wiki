# 可信AI标准动态 | 中国信通院正式发布MLOps模型交付标准

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651725338&idx=2&sn=76dfddd9332d566ec06d48762db37dc3&chksm=8bc8ddb3bcbf54a5bfe7df87fa3ae4606ef770666117ade8e66012dbe31ed9623ae2ca8b2c52&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651725338&idx=2&sn=76dfddd9332d566ec06d48762db37dc3&chksm=8bc8ddb3bcbf54a5bfe7df87fa3ae4606ef770666117ade8e66012dbe31ed9623ae2ca8b2c52&scene=27#wechat_redirect)

“十四五发展规划和2035远景目标纲要”将人工智能作为创新发展的关键依托。人工智能（AI）产业发展迎来大比拼，正式从PoC(概念验证)转向产品落地应用阶段，各行各业都将AI工程化能力作为智能化转型比拼的基础。AI工程化能力的高低很大程度上取决于AI生产运维管理水平，而MLOps为AI工程化落地的**团队协作难、过程管理乱、业务交付差**等3大难题提供了最佳实践和解决方案。

在此背景下，中国信息通信研究院持续开展《人工智能研发运营一体化（Model/MLOps）能力成熟度模型》系列标准的研究和编制工作。系列标准的第一个标准，《人工智能研发运营一体化（Model/MLOps）能力成熟度模型 第一部分：开发管理》****已于********2022年4月********正式********发布****，现正式发布《人工智能研发运营一体化（Model/MLOps）能力成熟度模型 第二部分：模型交付》（以下简称模型交付标准）。

![](../Images/aea002f1a5616992b0fe98094d567004.png)

本标准自2022年5月启动编制，2022年9月完成定稿，汇聚了百余名业界专家的技术和智慧力量。经过小组内和组间研讨20余次，集中研讨5次，以及多次评审和公开意见征集等过程，不断打磨修订，历时近半年的精雕细琢，标准最终定稿。

****模型交付****标准围绕高效构建和持续部署，致力于为实现规模化、一体化、标准化的过程管理，可通用、可复用的模型生产流水线，提升数据、模型、特征等AI资产的版本管理和价值共享能力，打造全能力的CI(持续集成)、CD（持续部署）、CT(持续训练)流水线，而提供一套可参考的不同级别（****基础级、专业级、领先级、卓越级和领航级****）的标准能力成熟度要求。

  

![](../Images/65d9d209d002901bac0b9be8edeebc14.png)

本标准包括构建集成、部署发布、模型测试、配置管理、度量反馈等5个能力子域，12个能力项，32个能力子项及300余条分级要求。  

![](../Images/318badd93d0969608b8336446f80cc2e.png)

本次标准的发布，离不开诸多优秀企业和专家的大力支持与贡献。编制过程中共有来自金融行业、互联网头部企业、电信运营商和主要科技创新企业等30余家单位及其相关专家参与，在此向以下企业表示诚挚的感谢。

![](../Images/a22c317fddbbe4c900322e653a2fa00b.png)

此外，重点感谢标准编制过程中的组长、副组长等核心参编单位及其专家，包括：**浦发银行****（李铭梁）、****华为****终端（鞠细建）、****中原银行****（韦东东）、****百度****（****谢永康****）、****移动研究院****（杨艳）、****华佑****科技（梁万强）、联通研究院（亓振锋）、****蚂蚁集团****（付大鹏）、农行（司忠平）、****渊亭****科技（陈光淙）、****马上消费****（韩卫强）、****万达信息****（童庆）、九章云极DataCanvas（刘军）。**  

![](../Images/ac908e4c19795da21525188464d5714f.png)

****模型交付****标准的正式发布，标志着行业在MLOps模型交付阶段已取得阶段性进展，相信我国AI工程化道路会越走越远，质量越走越高，AI场景落地应用会愈发百花齐放，为各行业智能化转型持续释放能量。
