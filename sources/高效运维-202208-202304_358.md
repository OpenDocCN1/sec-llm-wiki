**![](../Images/b3d93b107c2acbfc5ec8d720dfab0e2d.png) 数据中心火灾：韩国互联网巨头遭遇宕机事故**  

18日消息，位于首尔南部板桥的数据中心15日下午发生火灾，电力供应被切断，导致韩国两大互联网巨头 Naver 和 Kakao 都遭遇了大规模宕机事故，一度陷入瘫痪状态。该数据中心由 SK C&C 运营，始建于 2014 年，占地 **66 942 平方米**。据韩国警方消息，起火地点为数据中心A栋地下3层电气室的锂电池架附近。电源堆放在五个电池架上，事发时，其中一个锂电池产生了火花并引发火灾，随后自动灭火设备启动并喷洒气体。数据中心起火后，由锂电子不间断电源（UPS）供电，随后 UPS 室也开始起火。为控制火势，消防部门放弃使用高压气体灭火，转而准备使用水枪。为避免短路，消防部门要求数据中心运营商SK C&C切断所有电源。八小时后，火灾最于**15日晚上**11：46左右被扑灭，事故虽未造成人员伤亡，但有消息显示，所有的电池都在这场大火中被烧毁。据称，该数据中心为 Kakao 主数据中心，有 **Kakao 3.2 万个服务器**。火灾当天，包括消息、打车、电子商务等服务均受到影响。同时，Naver 的大部分服务从周六下午开始就无法访问，影响广泛。  

19日表示上午5时许，数据中心全面恢复供电，但连续多日的服务故障，导致 Kakao 公司代表董事南宫燻辞职。

****![](../Images/eb2727b2ae444bbc605e8b7cf98de3de.png) 周星驰招聘 Web 3.0 人才，要求“项目管理管理经验和宅心仁厚”****

![](../Images/9d13d98669c53d90830d43f4ba0f3f3c.png)

10月18日，周星驰首度开通社交账号，并且公开招聘 Web3.0 人才，港媒曝其准备为进军元宇宙铺路，之后会在这个领域大展拳脚。周星驰还表示，自己对招聘相当重视，而且会亲自挑选人才。由于该社交账号并没有经过认证，很多网友都不敢相信真的是周星驰本人。港媒对此求证了周星驰的助理 Chris，他证实了这个账号确实是周星驰本人的，但并未回应招人以及之后的事业规划等问题。

**![](../Images/c1ddb638ed6e5cfad92213117f3c2e34.png) 支付宝上线微信好友转账功能**

支付宝 App 转账页面新增“转微信好友”功能。该功能并非全新上线，9 月中旬已有用户进行了体验。从公开平台上的用户反馈来看，仍有部分用户支付宝账户无法使用这一功能。该功能的原理类似红包码，并非双方支付线下二维码互扫互认的“互联互通”动作。分析师表示，“按照现有监管要求，支付机构之间不能不经过银行和清算机构直接进行账户互转。上述功能并不是支付互联互通动作，而是支付宝希望通过产品创新，以实现更大范围的场景辐射，提升用户使用体验。从便捷度上来看，打开支付宝后不用发起人再操作转账，更多价值还是在满足用户对转账的便捷化需求上。”

**![](../Images/3181253872aeae2ac8738a053e4bc4c2.png) Copilot 涉嫌抄袭代码，律师宣布调查 GitHub Copilot  
**

![](../Images/17048157a6a060b5bd1965522d1bd1db.png)

GitHub 的 AI 编程助手 Copilot 使用公开的代码库进行训练，在开发者写代码时根据函数名等上下文自动补充完后续代码。很多时候 Copilot 补充的是公开代码库中代码片段的拷贝。这就引起了版权相关的问题。律师 Matthew Butterick 本周宣布与律所 Joseph Saveri 合作调查对 Copilot 提起版权索赔的可能性，包括：GitHub 用开源代码训练 Copilot 是否有不当行为；在补充代码时是否不当的推荐了其他人的版权作品。自由软件基金会（FSF）此前曾呼吁对 GitHub Copilot 所产生代码的许可授权问题展开调查。

**![](../Images/b492654bff279d11cffd87ec0dc84422.png) 某科技公司违反《数据安全法》被行政处罚**

近期，上海网信办发现，某科技公司在处理政务类数据时违规操作，且未采取相应的技术措施和其他必要措施保障数据安全，导致数据存在泄露风险。上海网信办依据《中华人民共和国数据安全法》对该公司责令改正，给予警告，并处以人民币五万元罚款的行政处罚。

上海网信办相关负责人表示，数据安全关乎人民群众切身利益，关乎国家安全和社会稳定，上海网信办将针对数据安全保护义务履行不力，造成重要数据泄露风险的违法违规行为加强监督检查和执法，进一步营造安全稳定的网络环境。

**![](../Images/e2e17b0a436ae9b26e85ce203b541297.png)中国首家元宇宙新闻与传播学院在南开推出  
**

百年学府南开大学校庆日暨南开大学新闻与传播学院成立一周年之际，中国首家元宇宙新闻与传播学院今日（10月17日）在南开大学推出，根据南开大学新闻与传播学院秀山堂现实物理空间虚拟复制的数字空间正式上线。

**![](../Images/fa3884e5a69fcdab09f26b46952b1e98.png) Tiktok 日活突破 10 亿**

Tiktok 母公司北京字节跳动内部人士透露，Tiktok 全球日活跃用户数（DAU）突破10亿。此举一度触发在线用户登录警报，开发人员临时扩容才允许新用户访问。

目前全球日活突破 10 亿的 App 有 Facebook、WhatsApp、Instagram 和 YouTube。
