+ + + + + 

王欣

辽宁移动公司信息技术中心总经理，中国移动业务支撑网专家，亚太地区首批 Oracle 大师级专家（OCM），致力于智慧中台建设运营、自研能力锻造等，为打造信息服务与科技创新型企业注智赋能。多年来他始终坚持“实力、实战、实效”的价值导向，发挥技术专长，主动突破创新，围绕数据库管理、主机管理、架构设计等工作，带领团队产出国家技术发明专利60余项，曾获“全国工人先锋号”“中国移动劳动模范”“全国通信行业企业管理现代化创新成果奖”“中国移动业务服务创新优秀奖”“省自然科学学术成果奖”等荣誉。

01

数智化转型提速，持续为研发运营注智赋能

加速数智化转型，已成为“十四五”发展基调，各行业纷纷围绕“数智化转型”进行全方位、战略性布局。中国移动创世界一流力量大厦明确了“推进数智化转型，实现高质量发展”的发展主线，杨杰董事长指出“智慧中台是推进产业转型升级的重要创新，是‘两个新型’的重要组成部分与关键能力底座”。

企业数智化转型有助于推动管理模式和理念创新，激发企业发展内生动力。2020年至今，辽宁公司积极落实集团公司智慧中台战略部署，边建设、边运营、边完善，先后上线了涵盖个人市场、家庭市场、政企市场、网格运营、智慧网维、精细化管理等六大领域的115个业务场景，持续为一线赋能，为运营注智，助力公司数智化转型和高质量发展。

王欣在采访中表示，辽宁公司推动生产方式、生活方式、治理方式数智化转型的步伐持续加快，IT驱动公司转型升级面临新挑战。重构IT生产关系，推进供给侧结构性改革势在必行，实现“传统研发模式向敏捷研发模式的演进”是改革的重要路径。

在此背景下，辽宁移动参照集团公司磐舟和磐基统一技术底座以及智慧运维最新理念与最佳实践，从DevOps人员团队建设、持续交付工具、云原生部署架构和智能运维体系四个方面对研发运营一体化（DevOps）能力进行整体规划：

1

人员团队建设

建立数智化转型 IT 人才管理体系，锚定现有职位人员未来转型方向，并通过转型培养实现其能力提升，持续打造“懂技术、懂需求、懂客户、懂市场”的“四懂团队”，以“专业创新、协作担当、敬业责任”为核心价值，努力成为公司数智化转型先锋、智慧服务基石、自主创新表率、数据赋能专家。

2

持续交付工具

打造研发运营一体化平台，保证 DevOps 的工程实践，缩短从业务想法的提出到实现和交付的时长；设立电子看板，实现需求流程端到端的数据统一展现，消除业务需求交付过程中的一切阻碍和等待，让 IT 交付节奏，跟上业务发展的需要。

3

云原生架构

打造容器云平台，实现统一云原生技术底座，提供云原生组件技术生态，通过弹性计算实现资源弹性调度，形成统一的服务治理框架，推动全域应用容器化迁移改造。引入灰度流量网关，建立灰度发布机制，实现无DB变更需求的部分用户在线可控升级。

4

智能运维体系

通过完善云原生复杂环境下容器化、微服务化资源动态管理及监控运营体系建设，夯实端到端故障治理能力，加速 AIOps 落地生产，深度技术运营，优化自动化运维能力，减少人为干预，逐步向无人值守方向演进，重点围绕业务应用，深耕“故障自愈”“营业厅开门测”等自动化运维场景，拓耕场景覆盖，实现系统运行的连续可用性和安全稳定。

02

对标业界最佳实践，打造辽宁移动 DevOps 研发体系

近期，“辽宁移动 DevOps 研发体系建设与实践项目”成功入选今年服贸会“企业数智化转型论坛”企业数智化转型典型案例，该项目旨在提高研发效能，快速上线业务需求，支撑市场发展，助力组织数智化转型。

据王欣介绍，辽宁移动对标业界最佳实践，结合通信行业业务支撑领域开发特点，以渠道集中化平台为试点，通过引入敏捷方法论，探索基于 Scrum 方法的敏捷开发组织和流程体系，建设 DevOps 工具链，进行持续集成和持续部署，实现业务系统的快速迭代。

在此过程中，通过建立人才培养机制，打造能够应对快速市场和技术环境变化的跨职能和自组织团队，形成可落地的敏捷实践，实现以交付高质量、高价值需求为导向的开发模式转型，提升业务敏捷开发和持续交付能力，提高内、外部客户满意度，助力企业数智化转型。

从具体方案来看，流程是 DevOps 体系的根本保障，其中引入 Scrum 方法论。Scrum 是用于开发、交付和持续支持复杂产品的一个框架，是一个增量的、迭代的开发过程。在这个框架中，整个开发过程由若干个短的迭代周期组成，一个短的迭代周期称为一个迭代，每个迭代的建议长度是一至四周。王欣表示，Scrum 起源于软件开发项目，但它适用于任何复杂的或是创新性的项目。参考 Scrum 敏捷框架，结合系统现状，我们量身定制具有辽宁移动特色的敏捷开发标准流程，主要包括以下管理实践：

系统是 DevOps 体系的有利抓手，辽宁移动 DevOps 研发运营一体化平台，通过引入自动化测试、持续集成/持续部署工具，实现系统版本发布和上线部署的统一管控。DevOps 研发运营一体化平台主要包括统一门户、持续交付流水线、自动化测试平台、度量平台。

其中，统一门户是平台的“一站式”门户，为项目管理人员、开发人员和测试人员提供统一的操作入口。持续交付流水线打造了需求开发、质量保证、投产部署的价值交付链，通过流程引擎将各项基本服务串接起来。

自动化测试平台是组织级的自动化测试自服务平台，和上下游需求、变更管理系统打通，进行自动化测试用例的统一管理，实现自动化测试资源池化以及自动化测试结果的自动分析。度量平台通过可视化看板聚合报告内容多维度展示需求管理、版本控制、构建、测试、部署等阶段的指标状态，支持自动生成数据趋势图和趋势分析。

王欣表示，开发运营一体化（DevOps）打破了IT开发部门和IT运维部门之间的隔阂，包括技术、流程和组织上的隔阂。以业务为源头，打通从业务到开发再到运维的整个流程，实现业务、产品和运营的有机融合形成高效的业务交付、运行和反馈闭环。我们将依托辽宁移动DevOps研发体系，逐步分批次推广，以研发敏捷促进组织的敏捷转型，进而帮助组织顺应数智化变革的要求。

03

打破项目落地三大困境，探索成果经验复制推广

“辽宁移动 DevOps 研发体系建设与实践项目”是助推企业数智化转型的又一积极实践，但该项目并不是一蹴而就的事情，而是一项复杂的系统性工程。王欣表示，该项目在落地过程中面临诸多挑战，对此辽宁移动也全力攻坚突破，促进项目成功落地。

其一，作为近年来新出现的IT研发和管理范式，DevOps 目前还在持续发展中，其内涵也在不断变化。如何建设研发运营一体化平台能更好地提升软件工程能力，提高软件质量与组织效率非常关键，同时也缺乏具有相关知识的人才。为此，辽宁移动加入了由中国信息通信研究院、云计算开源产业联盟、开放运维联盟发起的“企业级 DevOps 赋能（共促）计划”，和更多优秀企业交流学习，了解行业最佳实践；参加由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付标准评估，使辽宁移动 DevOps 持续交付能力已达到国内领先、行业顶尖水平；派遣骨干人员参加外部学习，先后 16 人次通过相关培训认证，为后续推广 DevOps 储备了充足的人才。

其二，面对全新开发模式与系统工具，团队人员由于使用习惯，不能直接适应，需要一定的学习成本。如编译方式由 ANT 转为 Maven；版本控制工具由 SVN 切换为 Git，引入制品库 Nexus，开发人员需要自行写编写单元测试；使用 sonar 进行代码扫描，进行强制代码评审；开发人员需要自行通过流水线提交触发自动构建、持续集成与发布。基于此，辽宁移动通过对开发、测试、运维人员进行培训，使其熟悉新的开发模式、掌握新的系统工具。通过先选取试点团队进行转型，试点团队总结经验教训后再逐步推广的模式，减少模式和工具更换对整个团队的影响。

其三，DevOps与传统 IT 管理理念不同，导致公司现行很多 IT 管理要求相冲突。如DevOps 强调单一可信数据源，代码要求一次编译，通过制品晋级，在不同环境进行部署。而传统情况下，出于安全性的考虑，测试环境与生产环境是隔离的，生产部署时不能访问测试环境主机目录，拉取软件包，需要将测试环境验证过的代码在生产环境重新编译打包。

于是辽宁移动针对与公司现行 IT 管理要求的冲突，经过咨询行业专家，结合本地开发实际的特点，采用其它替代方式来满足 DevOps 的要求。如测试环境和生产环境隔离的问题，将部署环境由虚拟机切换为容器，将代码与环境分别打包，生成为一个镜像，通过制品晋级由测试制品库晋级到生产制品库，生产环境拉取生产制品镜像并进行部署，来解决该问题。

基于 DevOps 研发体系建设与实践项目，辽宁移动也总结了诸多关于团队建设、管理实践、代码管控、质量保证、变更管理、度量体系、生产运行等方面的经验成果，包括建立敏捷管理人员培养机制；通过引入 Scrum 方法论，构建可实操落地敏捷开发体系；建立依赖库，对三方组件做统一来源管理；将单元测试集成到流水线中，实现新增单元测市覆盖率 100%；建立代码基线并确定与投产包有对应关系、建立清晰明确的版本号规则；建立跨团队度量指标，进行全流程量化度量；建立环境更新的流程，使用标准化的部署工具对各种环境进行管理等。

据了解，辽宁移动下一步计划将成功经验复制推广到 CRM 全域，在推广的同时保持对各个项目差异化的实践和创新，需进一步打通信息屏障，为更多的产品赋能；同时，进一步提升 DevOps 平台的通用性和扩展性，探索跨团队的规模化敏捷协同及持续集成，进行基础设施即代码等实践，对团队也是新的机遇和挑战。

04

面向数智化时代，着力打造IT研发管理新范式

每一次产业变革都从革命性的技术开始，围绕它建立新的基础设施，形成新的技术和管理范式，最终彻底变革整个产业。以 5G、云计算、大数据、人工智能、IoT 等为代表，新的数智化基础设施已经就绪，并将继续演进。更重要的是与之配套的技术和管理范式的转变，如：数智化转型路径、面向数智化的组织、数智化的全链路协同、数智化时代的IT研发模式。其中 DevOps 已成为数智化时代 IT 研发和管理范式，并成为企业数智化转型重要的组成部分。
王欣认为，DevOps 引领工程技术和协作模式两个方面的变革，这两者相辅相成，又相互制约。工程技术对应研发敏捷，协作模式对应组织敏捷。我们将在现有 DevOps 研发体系基础上，以敏捷交付为目标，进行开发模式的转型，在 CRM 全域推广敏捷开发模式，探索适合辽宁移动 IT 领域的企业级敏捷交付标准，进一步完善敏捷开发流程，拓展研发运营一体化平台，建立敏捷人才培养机制，实现组织的敏捷转型，帮助组织顺应数智化变革的要求。让技术发挥其核心作用，加速业务发展，引领业务创新，是我们追求的目标！
