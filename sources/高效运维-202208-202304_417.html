课程介绍

DevOps Foundation® 是 DevOps Institute 独立认证的课程。本课程及其相关考试的目的是传授、测试和验证 DevOps 的基本词汇、主旨和实践知识。词汇术语表、概念和实践都包含在课程学习手册中。DevOps Foundation课程旨在培养个人对 DevOps Foundation 概念的理解以及 DevOps 如何用于提升软件开发人员和 IT 运维人员之间沟通、合作和集成的效率。

DevOps Foundation® 课程提供了对 DevOps 核心术语的基本理解，以确保每个人都在使用相同的语言，并强调了DevOps 在支持组织级成功方面的益处。

课程包含来自 DevOps institute 最新思想、原则和实践，包含对高效能组织真实案例的剖析，如ING Bank，Ticketmaster，Capital One，Alaska Air，Target，Fannie Mae， Societe Generale，and Disney。吸引并激励学员，利用多媒体和互动实践，将学习经验运用于实践。内容还包含对《凤凰项目》作者 Gene Kim 在书中强调的三步工作法以及《DevOps现状报告》中最新成果的重点讲解。

通过学习学员将深入理解 DevOps 的精髓，强调沟通、协作、集成和自动化，进一步帮助改善软件开发人员和IT运维人员之间的工作流。

课程目标

DevOps Foundation®课程的学习目标包含对下述内容的理解：

  • DevOps 的目标及词汇

  • 对业务和 IT 的收益

  • 相关的原则及实践，包括：持续集成、持续交付、测试、安全和a三步工作法

  • DevOps 与敏捷、精益和 ITSM 的关系

  • 改善的工作流、沟通和反馈循环

  • 自动化相关实践，包括部署流水线和 DevOps 工具链

  • 重要成功因素和关键效能指标

  • 现实中 DevOps 实践案例和结果
