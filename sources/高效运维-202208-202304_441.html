腾讯会议回应崩了

8月29日，大量用户反馈腾讯会议崩溃，有网友反映称会议进行到一半直接卡退，也有反映登陆时网络异常。还有网友进入会议时显示“当前为高峰阶段，系统线路拥挤，请稍后重试。”

对此，腾讯会议官方微博回应，由于当前使用量激增，导致部分用户登录受影响，请您稍后再试，给您造成不便，非常抱歉。

8月29日10点50分，腾讯会议已恢复正常。
 Awk 霸榜 Github，80多岁原作者亲自更新 
近日，“Linux三剑客”中的一个非常古老工具登上 GitHub 热榜，这竟是80岁的原作者更新了，🙆，你没听错，有人80岁了还在改代码。

这位80多岁的一线程序员便是布莱恩·柯林汉（Brian Kernighan）。这位老爷子的大名估计是无人不知无人不晓，“Hello, world”就是他发明的，Unix 早期系统开发人员，Awk 共同创造者，怎么样，是不是感受到了迷之恐惧？

AWK 是用于处理文本的编程语言工具，也是 UNIX 操作系统的核心组件之一，任何 POSIX 兼容操作系统被认为都应该包含 AWK。其名字来自于三名原作者 Alfred Aho、Peter Weinberger 和 Brian Kernighan 姓氏的首字母缩写。
英伟达、AMD 断供中国

8月31日，美国政府命令芯片厂商NVIDIA（英伟达）停止向中国销售部分高性能GPU，同时，另一家 AMD 称也收到了相关禁止命令。

早在8月26日，美国政府通知英伟达，已对公司未来向中国（包括香港）和俄罗斯出口的 A100，和即将推出的 H100 芯片实施了新的许可要求，立即生效。

根据消息，被封锁的产品是有足够双精度计算能力的高端 GPU，就英伟达来说，以A100 算力为准，比它先进的所有显卡产品都会受限。

8个月60多款 App 密集下架，大厂再无产品神话？

近日，腾讯QQ空间花藤宣布10月关停，仅10天后，《冒险岛2》也宣布在11月停运。

据统计，除上述两款产品外，腾讯今年已经宣布下架的产品（含游戏类）已接近40款，平均每月下架5款产品。

其它互联网大厂App 也相继迎来下架，其中包括字节跳动的派对岛、识区、可颂，百度的Wonder、看多多、音磁、一局等10多款产品，同时还有阿里下架采源宝、友啥、礼发发等3款产品，以及京东的京东金融App青春版。
跨境电商巨头 Shopee 大规模取消 Offer 
近日，东南亚电商巨头 Shopee 大规模取消 offer 一事，在网上引起热议，不少准员工在临近入职期却被毁约，其中主要包括 Shopee 在新加坡设立的岗位。
更有网友在脉脉上爆料刚下飞机，就当天收到了 offer 取消通知，“当时刚落地新加坡不久，正在入镜处排队弄材料入镜。”
遭遇上述境况的 Shopee准员工并非少数，对于取消 offer 一事，Shopee 方面回应称，由于Shopee部分技术团队的招聘方案调整，一些技术相关岗位被关闭。我们正与相关人员持续沟通，会尽最大努力和支持帮助其妥善过渡。

俄罗斯流媒体巨头遭攻击，210万用户数据泄露

俄罗斯流媒体巨头 START 某个MongoDB数据库暴露在公网，72GB大小的4400万用户数据遭恶意黑客窃取，其中包括210万中国用户。
START 公司没有透露具体有多少用户受到此次事件的影响，但根据 Information Leaks的信息（该频道率先公布了此次事件，并附上一张据称为泄露信息的截图），泄露数据库总计72 GB大小，包含4400万客户的数据。
此次泄露的信息包括用户名、电子邮件地址、哈希密码、IP地址、用户注册国家、订阅起始及结束日期，以及最后一次登录记录。
START共在超过174个国家销售电影和电视节目，此次事件也让其成为俄乌冲突爆发后，遭受数据泄露和黑客攻击影响的众多俄罗斯企业之一。
据称，这起数据泄露事件已经影响到全球观众，包括俄罗斯本土的2460万用户、哈萨克斯坦的230万用户、中国的210万用户及乌克兰的170万用户。（安全内参）
Istio 1.15.0 正式发布，支持 Arm 架构
8 月 31 日，Istio 1.15.0 正式发布，这是 2022 年的第三个 Istio 版本，Kubernetes 1.22 到 1.25 版本已正式支持 Istio 1.15.0。
根据公告，Istio 1.15.0 版本的重要更新是支持 arm64，用户可以在 Raspberry Pi 或 Tau T2A VM 上运行。
Istio 是基于容器的云原生技术栈的三大核心技术之一，另外两个是 Kubernetes 和 Knative。其中 Kubernetes 和 Knative 早已支持了 arm64 架构，甚至连 Istio 的数据平面 Envoy 早在 1.16 版本 就已支持 arm64 架构（2020 年 10 月）。随着 Istio 1.15 的发布，你可以开箱即用得在 arm64 架构上部署 Istio，不需要自己来编译 arm 架构的镜像。
