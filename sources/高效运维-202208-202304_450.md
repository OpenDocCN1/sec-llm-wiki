由于缺少标准化的构建、包管理等工具，嵌入式C/C++ 应用的构建不像 Java 或 Python 这些面向应用的开发语言一般方便。2022年10月，GOPS 2022 · 上海站，蔚来汽车车机系统软件架构师与效能提升专家韩锴将分享如何“复制”Java世界的一些构建、包管理的方法，从而可以标准化构建与包管理的方案，左移并加速构建流程，减少延迟构建带来的项目风险，敬请期待。![](../Images/474cd08b17a49c9bfe3cc64045a7103c.png)
