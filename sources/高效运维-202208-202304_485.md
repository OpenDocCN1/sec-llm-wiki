# 恭贺！交通银行跨境金融和智慧人资荣获“研运质效典范标杆案例”大奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzA4Nzg5Nzc5OA==&mid=2651721500&idx=2&sn=d582c1ccadc5d295da7be4e60eaa407e&chksm=8bc8ccb5bcbf45a3cabc5ac984aa6eabe2665cfb8dac16d7e04d6bb69d463c97e6f47af3eb41&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzA4Nzg5Nzc5OA==&mid=2651721500&idx=2&sn=d582c1ccadc5d295da7be4e60eaa407e&chksm=8bc8ccb5bcbf45a3cabc5ac984aa6eabe2665cfb8dac16d7e04d6bb69d463c97e6f47af3eb41&scene=27#wechat_redirect)

![](../Images/1f71d78e24a261bc871356134816ba6a.png)国内外大型企业实践表明，标准化和工具赋能是企业成功的关键所在。DevOps 标准及基于标准的 DevOps 持续交付流水线平台和项目实践，可以较大幅度地提质增效，更加安全敏捷地提高企业市场竞争力！  
7月28日，中国信息通信研究院主办的“2022首届XOps产业生态峰会”隆重召开，本次大会以“**智效赋能·价值引领，共筑XOps新蓝图**”为主题，旨在提高企业研发运营能力水平，加强XOps体系建设交流分享。  
大会揭晓了XOps领域优秀案例，交通银行**跨境金融和智慧人资**两个案例在众多参评案例中脱颖而出，荣获“**研运质效典范标杆案例**”大奖。  
此前，交通银行跨境金融和智慧人资项目顺利通过由中国信息通信研究院开展的《研发运营一体化（DevOps）能力成熟度模型》持续交付 3 级评估。[**👉重磅！交通银行通过 DevOps 持续交付标准 3 级评估，相关能力达到国内领先水平**](https://mp.weixin.qq.com/s?__biz=Mzg2NTUyNjkzMQ==&mid=2247492486&idx=2&sn=8b9c029efa8e7bae00ff0df93616f25e&scene=21#wechat_redirect)  

![](../Images/b91e5c33d10f73c857658da360b64ca5.png)

  
交通银行一直以来都是高度关注业界新技术、新理念的发展动态，积极探索新方法、新实践的落地应用。行内2019年启动敏捷和DevOps建设，2020年大力推广DevOps平台，**已应用在超过200套系统的研发过程中**，2021年以来，交行启动DevOps标准评估，学习业界最佳实践，借用DevOps标准来检验交行敏捷和DevOps转型成效。  
本次获奖的两个项目分别为跨境金融系统，负责对接各类跨境金融业务，对接海关总署、支付公司、外综服企业等多个平台和客户，提供身份鉴权、风控筛查、结售汇、国际结算及贸易融资等功能。智慧人资系统，为全集团员工提供基于AI大数据以及移动端的数字化人事管理、薪酬管理、干部管理、教育培训、考勤、绩效等智慧化的人力资源管理平台。  
  

![](../Images/1ce0b83a9822c43933c33fc4b6873ef2.png)

  

通过运用DevOps交通银行在组织层面进行了基于标准的最佳实践比如以端到端交付流水线为核心，打通各项工程活动，为研发人员提供统一的开发测试运维一体化平台，规范研发交付全过程，内嵌质量标准，实现统一的过程管理和监控。在项目层面进行落地并持续改进，形成融合协作的DevOps文化，有效支撑交行数字化转型工作，提升了对业务响应能力和IT自动化水平及研发效率。同时DevOps工具平台也为交行十四五金融科技规划重塑业务流程、建设开放式企业架构、强化科技引领的落地实施提供更快捷更高效的工具支撑。

**研发运营一体化（DevOps）能力成熟度模型介绍：**

《研发运营一体化（DevOps）能力成熟度模型》系列标准是由中国信息通信研究院牵头，云计算开源产业联盟、高效运维社区、BATJ等顶级互联网公司以及各大金融、通信企业共同制定的国内外首个 DevOps 系列标准，是最完整、最权威、最具行业指导性的研发运营一体化（DevOps）能力标准之一。由中国信息通信研究院主导的 DevOps 标准已由工信部发布并被众多金融、通信和互联网等行业名企纷纷采用并通过评估。与此同时，DevOps 标准已于2020年7月在联合国直属标准化组织 ITU-T 正式结项，成为全球首个 DevOps 国际标准。DevOps 标准评估体系主要包括敏捷开发管理、持续交付、技术运营、应用设计、安全及风险管理、系统和工具等部分。
