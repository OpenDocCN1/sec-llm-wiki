前言

最近Shiro 认证绕过漏洞（CVE-2022-32532）在国内炒得火热，在研究的过程中，发现了有趣的一个小Tip，同样是正则表达式中的 '.'，java和python处理\r\n时的策略是不同的。

本文不针对Shiro这个漏洞展开，通过具体案例详细来谈谈这个正则小Tip。


区别

先上结论：


- java正则匹配中 '.' 是不匹配 \r或\n的

- python中的正则实现不同于java，'.' 只不匹配\n

P.S. 讲的也算清楚了，其他利用就是：不光\n可以绕过，\r，\r\n也是可以被这个洞利用绕过shiro的


Java测试

测试代码

public class Test {
    public static void main(String[] args) {        String content = "";        String pattern = ".*";        boolean isMatch = Pattern.matches(pattern, content);        System.out.println(isMatch);    }}


- 无\r, \n

String content = 'aaaabbb'> true

- \r

String content = 'aaaa\rbbb'> false

- \n

String content = 'aaaa\nbbb'> false

- \r\n

String content = 'aaaa\r\nbbb'> false

Python测试

- 无\r, \n

re.fullmatch(r".*", "aaaabbb")> <re.Match object; span=(0, 7), match='aaaabbb'>

- \r

re.fullmatch(r".*", "aaaa\rbbb")> <re.Match object; span=(0, 8), match='aaaa\rbbb'>

- \n

re.fullmatch(r".*", "aaaa\nbbb")> None

- \r\n

re.fullmatch(r".*", "aaaa\r\nbbb")> None
