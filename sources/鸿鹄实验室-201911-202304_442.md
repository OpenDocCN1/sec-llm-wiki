# CVE-2020-0796本地提权复现

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU0MjUxNjgyOQ==&mid=2247484568&idx=1&sn=bb57a3dcad1d4f0605ddbd981c5d8960&chksm=fb1837aacc6fbebc34f04b59fe3c99913b597b98e089fb7343ef6061fc0ed4f4fefb41397292&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzU0MjUxNjgyOQ==&mid=2247484568&idx=1&sn=bb57a3dcad1d4f0605ddbd981c5d8960&chksm=fb1837aacc6fbebc34f04b59fe3c99913b597b98e089fb7343ef6061fc0ed4f4fefb41397292&scene=27#wechat_redirect)

  

CVE-2020-0796漏洞影响运行Windows 10版本1903，Windows Server版本1903（服务器核心安装），Windows 10版本1909和Windows Server版本1909（服务器核心安装）的设备。

  

*“这表示攻击企图利用Microsoft SMB服务器中的缓冲区溢出漏洞。该漏洞是由于易受攻击的软件处理恶意制作的压缩数据包时发生的错误而引起的。遥控器未经认证攻击者可以利用此漏洞在应用程序的上下文中执行任意代码。” *
