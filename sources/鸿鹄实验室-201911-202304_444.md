![](../Images/575cab24bf3df4cfdee87e6280d0affa.png)点击上方“蓝字”带你去看小星星关于EmpireEmpire是一款基于powershell的后渗透工具，由于其开源、方便的特性被渗透测试人员所喜爱。本文均基于3.1.3 版本编写  
Empire的官方下载地址为：https://github.com/EmpireProject/Empire官方网址为：http://www.powershellempire.com/我们可以使用下面的方法快速安装Empire：

*   
*   
*   

```
`git clone https://github.com/EmpireProject/Empire.git``cd Empire/setup``./install.sh`
```

安装后，我们便可以使用下面的命令启动Empire

*   

```
`./empire`
```

![](../Images/1af26e30cdaaf616ed3425e22f7afb09.png)这样就进入了我们的命令行界面。Empire除了命令行界面，它还具有一个开源的GUI界面，项目地址如下：https://github.com/EmpireProject/Empire-GUI我们可以将其pull下来，然后使用下面的方法启动Empire

*   

```
`./empire --server --shared_password ILikePasswords --port 1337`
```

然后在gui的目录输入下面的命令：

*   

```
`npm start`
```

即可打开我们的gui界面：![](../Images/80ee73a944ab2eed88881caf1ce67d63.png)输入刚才你的用户名和密码即可：![](../Images/d260be94fd8f7d77e67e6349c09e6c79.png)Empire的使用我们可以使用help命令查看Empire的帮助信息：![](../Images/9cea2c16f41a611122072c58199f6dc6.png)Listeners 101拿到这个款工具之后，我们首先要做的就是设置一个本地的监听器，我们可以使用listener命令跳转到监听模块的主目录，使用list命令查看活动中的监听器。![](../Images/2e433b108e3282bf1fbaf0428fe512e0.png)我们可以使用uselistener 命令，查看支持的监听器  
![](../Images/822cfc0a79496a4bf398895a65248266.png)比如我们使用最基础的http模块：

*   

```
`uselistener http`
```

然后既可以使用info命令去查看监听器的详细信息：![](../Images/0b94af06568447be685ae85f639d032d.png)我们可以使用下面的方法去添加端口，和开启监听：

*   
*   

```
`(Empire: listeners/http) > set Port 6666                                                                                         ``(Empire: listeners/http) > execute`
```

![](../Images/c93a0783721b9fe865d4bce27a2bfed5.png)Stagers 101既然已经生成了一个监听，此时我们就需要使用生成器去生成一个我们进行上线的木马了，我们先使用back返回主目录，然后就可以使用usestager查看我们所支持的生成器了。![](../Images/55a9c4a696f8cc522d6a9f4942e35593.png)multi 开头的是通用类，osx 开头即 mac 使用，windows 即 win 平台使用，我这里就以windows为例了。![](../Images/1a668754015aeaedc60eaa1720349f42.png)设置好监听器之后，执行即可获得我们的一个木马![](../Images/b14982479286f1059fdcbebb99e22208.png)运行之后就会获得一个会话回来。![](../Images/0d77e416caabe88e1ad316df0afbb4e6.png)Agents 101使用agents就可以进入我们的会话菜单：![](../Images/aa7814009eac962043cd021c6e725a97.png)使用下面的方法，可以与指定的会话进行交互

*   

```
`interact PL4DMKY6`
```

![](../Images/68928017189f795ff9445288187984ba.png)输入help即可查看常用的命令![](../Images/9d4d299c393700fd58e4d3f080acce1b.png)比如ps列出进程![](../Images/b57f903046f942d192989c318bef0c64.png)Mimikatz and CredentialsEmpire 一般可以将mimikatz的输出保存在本地，一般可以使用 creds 进行查看，比如

*   

```
`creds krbtgt/plaintext/hash/searchTerm`
```

即可查看各类密码。![](../Images/9b5bc16873a158ab92521687586703b9.png)当然你也可以去使用下面的方法去生成一个凭证。

*   

```
` creds add domain username password`
```
