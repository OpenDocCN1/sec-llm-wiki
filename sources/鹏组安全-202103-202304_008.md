# 还没有结束

本着不浪费的原则，还是cs上线一波，不然就白白浪费调试cs服务器的时间了 用cs客户端先建立listener，![](../Images/c699d1ee6674fd5c82209355b3d424fb.png)然后选择Attacks->Web Drive-by->Scripted Web Delivery(s),host就写服务器地址，端口随便写，listener就选择刚刚创建的监听，可以得到一条让目标上线的payload![](../Images/52c14c228698b1425f730fe47abe3a64.png)用shell去执行这个payload，过一会就能上线cs了![](../Images/4b776199e8226090abae6259f8a3eb12.png)成功上线~至于为啥会上线这么多个，我也还在思考中，![](../Images/3fd8271575acb739d8b19eff23e6fbbe.png)右键目标，就可以使用很多种攻击方式了![](../Images/aaa2ebe79ee575fcc2eff654ba3d5036.png)因为菜，所以这是个裸的cs4.0，那么还是回到kali吧 用配置好的frp尝试把这个shell反弹到msf试试 这里需要在cs上重新建立一个新的listener![](../Images/12c7000c4a256bc8b0d0eeaa3786c9c7.png)然后进入msfconsle设置监听本地的1235端口
