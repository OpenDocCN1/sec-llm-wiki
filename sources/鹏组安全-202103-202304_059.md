### 2、列出文件/目录的命令

ls -a：显示所有文件，包括隐藏文件（Linux中以.开头的文件是隐藏文件）![](../Images/8e9e6b9de332b13d890e008c17bf198d.png)ls -l：显示详细信息，可以简写为ll![](../Images/e86fdce1c459d857e1c5505ddce068f9.png)ls -R：递归显示子目录结构![](../Images/2a7f7ca922a42bb6bdda007f35e7c5fe.png)ls -lD：显示目录和链接信息![](../Images/bcdb519b67e15fee3513f825ccdde441.png)pwd:显示当前目录![](../Images/5f1579031e60d8165e2b70e976a4e742.png)

### 3、操作文件命令

cp -r\[递归复制\] 源文件 目标文件 （拷贝文件和目录）![](../Images/c0d36662ba320d5174ccfd3ef712359b.png)touch 文件名 （创建文件，如果存在则修改创建时间为现在系统的时间）![](../Images/3fa3d320a5679162e00c6a9a510fc329.png)mkdir 文件夹名称（创建目录） mv 文件 目标文件（移动或者重命名文件/目录） rm -r\[递归删\] -f\[强制删\] 文件名（删除文件或命令） ln -s\[软链接\] 源文件/目录 目标文件/目录 （建立链接） vim 文件名 （编辑文件）

### 4、打包、压缩命令

zip 要压缩的文件（压缩为zi格式） unzip 要解压的文件 （解压zip格式的文件） gzip 要压缩的文件（压缩成gz类型） gunzip 要解压的文件（解压gz格式的文件） tar 打包命令

```


-c：创建一个新tar文件
```

常用：tar -zcvf xxx.tar.gz 文件名1 文件名2 ... （将所有文件打包使用gzip压缩）![](../Images/eb7fe27bf4e15a4cf2bc5af94440541b.png)tar -zxvf xxx.tar.gz (将所有文件解压)![](../Images/68eb00a136262b67154fa83cf8faf5d0.png)

### 5、输出文件、查看文件类

#### echo命令

```
echo "hello"
 输出内容  echo "hello"  > a 将"hello"
覆盖a文件echo "hello" >> a 将"hello"
追加到a文件里
```

#### cat命令

用法 ：\[参数\]<文件名> （显示文件内容,也可以将数个文件合并成一个文件）

```


cat  a （显示a文件内容）
```

#### head 命令

用法 ：-n\[行数\] 文件名 （显示文件的头几行（默认10行）

#### tail

用法：-n\[行数\] -f\[持续显示文件更新\]  显示文件的末尾几行（默认10行）)

#### more

用法：用于翻页显示文件内容（只能向下翻页），按q退出

#### less

用法：翻页显示文件内容（带上下翻页）按下上键分页，按q退出

#### find

用法：\[<路径>\] \[匹配条件\] 查找文件、文件夹

```


find . -name redis 查找当前目录下名称为redis的文件type
 d 查找根目录下所有为目录类型的文件
```

![](../Images/01415ab009d048b75527471cfc508e6f.png)

image.png

#### locate 命令

让使用者可以很快速的搜寻某个路径（默认每天自动更新一次，所以使用locate 命令查不到最新变动过的文件。可以在使用locate之前，先使用updatedb命令）

```


updatedb pwd 查找和pwd
相关的所有文件
```

# 二、系统操作类

### 1、开关机

#### shutdown

用法：-h\[关机\] -r\[重启\]  设置延迟时间或关机时间

```


立即关机：shutdown -h now
```

### 2、显示时间类

date（查看或设置当前系统的时间：格式化显示时间：+%Y-%m-%d）![](../Images/03313498a955075a892c09a9613d4643.png)date -s（设置当前系统的时间） cal \[月\] \[年\]（查看日历）显示当月的日历 cal 5 2000 ：显示2000年5月的日历![](../Images/2f32b6578e9fffc772d177b926ac645c.png)uptime （查看系统运行时间）![](../Images/9bbabedf6c0eaef17a4b1b101130a583.png)

### 3、网络、进程类

ifconfig （查看网卡信息） 

ps -ef （查看正在运行的进程） 

kill -9\[强制杀\] pid （杀进程） 

ping ip 查看与某台机器的连接情况 

netstat  查看当前网络状态 参数：

```


-a (all) 显示所有选项，默认不显示LISTEN相关。
```

#### 资源监测命令

top -d\[间隔number秒刷新一次\] 秒数  （监控linux的系统状况）![](../Images/93c6193a200ce8a0b0448ae0cf131979.png)

### 4、系统服务

#### sudo 切换root用户

#### su

用于用户之间的切换。但是切换前的用户依然保持登录状态。如果是root 向普通或虚拟用户切换不需要密码，反之普通用户切换到其它任何用户都需要密码验证

```
su test:切换到test
用户，但是路径还是/root目录test : 切换到test用户，路径变成了/home/test


```

#### chmod  设置文件权限

```


读，写，执行对应字母为 r、w、x， r=4，w=2，x=1
```

#### chown 设置拥有者

```


user : 新的文件拥有者的使用者
```

#### service服务管理

```


service iptables status  --查看iptables服务的状态
```
