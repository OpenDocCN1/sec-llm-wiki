漏洞描述


ntopng是监控服务器网络流量的工具，对外提供Web页面。其4.2及以前的版本中存在一处权限绕过漏洞，利用该漏洞可以未授权访问目标任意接口。


影响范围


ntopng commit < e8b9721479f401f595c5c7bb151819aceb03ad71


复现过程


使用docker搭建环境 docker-compose up -d


搭建完成后我们访问 127.0.0.1:3000




我们在本地搭建完之后可以使用默认账号密码进去选一个感兴趣的接口


账号密码:admin/admin




比如 http://127.0.0.1:3000/lua/macs_stats.lua


首先我们利用poc计算出ntopng lua目录的长度


python poc.py --url http://ip:3000/ baselength




可见长度为36


在使用poc生成越权的url


python poc.py --url http://ip:3000/ generate -l 36 -p macs_stats.lua




访问即可




可使攻击者可以在未授权的情况下请求复合漏洞利用条件的接口


相关poc关注公众号回复 Ntopng
