0x01、认识mysql提权基础

一、数据库提权的条件:

判断mysql服务的运行权限，服务器必须安装数据库，这里可以从服务器端口扫描中看出;

1、系统账号查询net user2、ps -ef|grep mysql 或 ps aux|grep root 也可以查看当前以root用户身份运行的所有进程3、查看mysqld运行的Priority值，如果权限Priority值为8 则Mysql是以System运行的


二、获取数据库的账号密码

   为什么一定要拿到数据库账号密码？

            数据库提权的时候一定要是root权限。


获取密码的方式：

1、获取网站数据库的账号密码

对于CMS系统，比如WordPress系统，数据库信息都是在/wordpress/wp-config.php中。针对CMS系统，可以先去百度，查查相关配置文件的目录

2、对于操作系统：

  windows操作系统：

读取到数据库存储或备份文件,比如mysql数据库中  收集用户密码，可以读取到MDY类型文件，在MYSQL数据库文件夹下有@@basedir/data/mysql/user.MYD文件（最常见的）



从文件里可以读取到给了一个mysql5加密的pw，拿到解密网站下解密


linux操作系统： 

  可以通过查看./root/.mysql_history&&/root/.bash_history进行查看mysql操作涉及的密码。

      对于mysql版本在5.6以下版本，由于设计mysql程序时对于安全性重视程度很低，用户密码都是明文传输，所以mysql对于binary log中的用户密码相关的操作是不加密的

3、Mysql密码查询

可以通过查询语句直接查询mysql数据库中的用户名和密码。

在mysql数据库下面，有一个mysql.user表里面

select user，password from mysql.user

4、Mysql密码加密算法

Mysql实际上使用两次SHA1夹杂一次uhex的方式对用户密码进行加密

具体的算法可以用公式表示：password_str = concat('*', sha1(unhex(sha1(password))))，可以通过查询语句进行验证，查询结果如下图所示。

select password('mypassword'),concat('*',sha1(unhex(sha1('mypassword'))));


0x02、什么是UDF提权

UDF提权的详细介绍

UDF提权的详细介绍：UDF(user-defined function)是MySQL的一个拓展接口，也可称之为用户自定义函数，它是用来拓展MySQL的技术手段，可以说是数据库功能的一种扩展，用户通过自定义函数来实现在MySQL中无法方便实现的功能，其添加的新函数都可以在SQL语句中调用，就像本机函数如ABS()或SOUNDEX()一样方便。

 UDF提权条件

(1)Mysql版本大于5.1版本udf.dll文件必须放置于MYSQL安装目录下的lib\plugin文件夹下。

(2)Mysql版本小于5.1版本udf.dll文件在Windows2003下放置于c:\windows\system32，在windows2000下放置于c:\winnt\system32。

(3)掌握的mysql数据库的账号有对mysql的insert和delete权限以创建和抛弃函数，一般以root账号为佳，具备root账号所具备的权限的其它账号也可以。

(4)可以将udf.dll写入到相应目录的权限。
