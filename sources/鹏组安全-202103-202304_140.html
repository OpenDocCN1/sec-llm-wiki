Telnet服务（centos7中安装）

关闭防火墙并禁止开机自启

systemctl stop firewalld.servicesystemctl disable firewalld

检查telnet是否安装

rpm -qa | grep telnet

yum安装telnet

yum -y install telnet telnet-server xinetd

设置xinetd开机自启

systemctl enable xinetd.service

设置telnet开机自启

systemctl enable telnet.socket

启动telnet服务

systemctl start telnet.socketsystemctl start xinetd

默认Root无法远程访问，因此需要修改以下配置文件

/etc/securettyvi /etc/securetty在末尾添加pts/0pts/1

查看telnet服务是否启动

ps -ef | grep 23

安装Telnet客户端

从Win7开始默认不会安装Telnet客户端，因此需要手动进行安装（如安装了请忽略）打开程序管理-启用或关闭Windwos功能，勾选上Telnet客户端点确定进行安装

安装完成后打开CMD，输入Telnet IP地址，出现以下界面表示配置Telnet成功了。
