```

```

### 扫描开放端口及对应服务

```
nmap \-sV \-p- 192.168.56.117
```

## 漏洞发现

### 暴力破解登录页面

访问80端口，是一个登录页面没有验证码验证，经过测试也没有登录次数限制，所以这可以进行暴力破解![](../Images/df77f3bd8869cf5c7c86a0e7cdac7d36.png)通过返回的长度猜测暴破成功![](../Images/9d8cf22c4d8b398c2ad233564377c256.png)

### 命令注入

成功登录，通过页面中system tools command等英文单词猜测可能存在命令注入![](../Images/303852cb287d030ec48b5f1356d4339d.png)进入command，run执行，可以看到成功执行了 ls -l 命令![](../Images/63254044ddfa6b6fdf30e94b1f212762.png)这里抓包进行分析，成功执行两条命令![](../Images/b977f58f2926e4369a1731f04682656f.png)

执行nc![](../Images/1988211dc9231262351f338d132a2352.png)可以看到kali中反弹成功，利用python获取交互式shell

![](../Images/7fb66356e4fea13868a7732531564658.png)这里是www-data的权限，sudo -l发现需要www-data的密码，没得办法只好跳过，另外想办法![](../Images/65a691385310b94d44e98ffdbcd4776d.png)到home目录看到charles jim sam 三个目录，其中charles和sam什么也没有，jim中存在文件目录

### hydra ssh暴破

接下来进行暴破，且成功暴破出密码

```
hydra \-l jim \-P old-passwords.txt \-t 30 \-f 192.168.56.117 ssh
```

![](../Images/3abc0ad959fbd0f8c63161c9fe996cca.png)利用暴破出来的密码登录ssh![](../Images/de48fc0b94cbfe4d3116aba7b87991ac.png)首先还是sudo -l 输入密码 ，弹出说在dc-4中jim用户不能执行sudo，但是下面有个提示，有个新邮件在/var/mail/jim中。![](../Images/1b7eb781aab306a144a986104541a7e6.png)根据提示cat打开文件，直接就得到了charles用户的密码![](../Images/5d030c7cecf15ce7cf297a0ccf940ddd.png)用户直接切换成功，还是普通用户权限，接着就是提权了![](../Images/126a6c592dcc68c16b19580d30f3e034.png)

## 提权

再次利用sudo -l 看到charles用户可以无密码以root执行teehee![](../Images/20a48dc77b26ab3d5f591e35875a89e0.png)teehee没见过这个命令 --help查看，了解到teehee -a 可以写入文件内容并不覆盖文件原有内容。![](../Images/608ee49ac1a310306ca164d4ed752740.png)最后还是通过百度了解到如何利用teehee提权向/etc/passwd里面直接写入一个用户，uid写为0，gid写为0

```
echo "baba::0:0:::/bin/bash" | sudo teehee \-a /etc/passwd
```

![](../Images/5fef0cf3f595c81fdcf7ed3269dec00a.png)切换到baba用户，id查看为root用户，提权成功![](../Images/a34948b44759d195509d75d4af6ace6d.png)进入root目录 cat flag.txt![](../Images/f4a0c19f50576336a90901f3b3bc43ae.png)
