**一、工控系统漏洞挖掘技术研究**

PLC、DCS控制器、智能传送器等嵌入式设备，它曾经通过串行电缆和专有协议连接到计算机网络，现在则通过以太网电缆和标准化的TCP/IP通信协议连接到计算机网络。供应商提供许多这样的设备，拥有嵌入WEB服务器、开放的FTP服务，而且能够通过不安全TELNET的之类的协议连接到他们。只有小比例的设备支持身份验证或加密，因此这些设备很容易受到劫持连接或被伪装成控制室发送控制命令欺骗。

美国国土安全部DHS定义漏洞为：“存在一个漏洞，设计或实现的错误，会导致意外、不良事件并危及组织、系统、网络、应用程序或协议的安全”。降低由这些漏洞带来的风险首先是要定位和修复漏洞。一个完善的脆弱性评估方法应整体地分析所有涉及的系统，以一个分层的方式从最接近威胁的边界开始，逐步深入安全分层的方法。

工控设备攻击测试一般分为：枚举和被动扫描、拒绝服务，获取控制权，或者其他高级的攻击，其中包括测试协议极限和对协议的逆向工程。

对工控设备的这些网络攻击测试不可以运行在实际的系统中，因为这些攻击是设计用来测试设备最大的极限性能所以这些攻击测试都应该运行在模拟平台或者正在开发、测试的网络中。

  **1.1网络流量分析技术**

仅仅知道基础设施是不够的，因为更重要的是网络上实际的流量。网络上的流量包括在边界设备内的网络节点流量的被动截取。这些网络流量抓包交给离线的网络分析软件分析设备之间通信的具体信息，当前网络的主要协议，是否有明文传输。网络流量包也可能因劫持会话或注入技术而被劫持。

如果环境是一个测试或建设中的系统，那么额外的活跃”的网络漏洞扫描可以更准确地识别系统设备功能和任何有漏洞的服务。通过欺骗和中间人攻击，所有的网络流量都会被迫首先到实验台，然后到交换网络。这使得通信捕获软件收集网络上的所有流量，包括活动会话、明文密码，应用程序调用其他应用程序和的协议。当试图逆向SCADA/DCS的协议，或当试图注入自定义数据包时，收集一个足够大的样本的网络通信是至关重要的。

  **1.2fuzzing技术**

使用fuzzing技术，攻击者需要知道每个协议可以被修改部分的功能限制。例如，如果一个攻击者知道系统使用Modicon PLC。一旦IP地址和Modicon单位ID已知，那么fuzz技术可以应用于PLC中的单个寄存器。

另一个先进的技术是获取足够通信协议的网络流量，这样可离线的研宄协议。然后对SCADA或DCS网络中的流量进行逆向分析。一旦己知了协议内容，就可以生成定制的协议命令，并且注入网络，因为网络中没有身份验证和加密措施，这些协议注入技术是可行的，即使真正的SCADA或DCS用户也在试图写控制器的内存地址。

  **1.3软件逆向工程技术**

软件逆向工程（，顾名思义就是通过反向分析软件的运行过程，取得软件的源代码，获知软件的设计原理，软件系统架构，获知软件的算法，数据处理过程等。软件逆向分析可以采用分析运行软件的系统，使用解密算法，反汇编和程序理解等方法。

实际上，我们用不着把软件设〖丨的每一个细节都搞清楚，这样会耗费很大的精力，而且对工作的进展并无多大好处。我们只需要对软件进行部分逆向分析，获知软件的算法或部分程序设计流程，然后对软件进行修改或功能扩展等。

工程师站的软件用来监控、设置和维护工控系统的现场设备和工控网络中的各网络节点，攻击者可以对工程师站的软件进行逆向分析，从而破坏工控现场设备的运作流程。

**二、工控系统攻击图自动生成方法研究**

目前国内外还不存在专门针对工控系统的攻击图自动生成技术，但是随着工控系统信息化程度的加深，工控网络越来越多的使用普通互联网的协议和系统等，这就使应用普通互联网攻击图自动生成技术分析工控系统网络成为可能。本节将介绍5项典型的，针对普通互联网的，同时基于攻击图技术的在线检测和防御方法。它们分别是：多主机、多阶段漏洞分析（Multi-host，Multi-stage Vulnerability Analysis，MulVaL）、拓扑漏洞分析技术（TopologicalVulnerability Analysis，TVA）、skybox view技术、卡耐基梅隆大学的Attack Graph Toolkit技术和Net Spa（A Network Security Planning Architechure）技术。

下面逐一介绍每项技术。

  **2.1 MulVaL**

MulVaL是“多主机、多阶段漏洞分析”是Multi-host，Multi-stage Vulnerability Analysis的简称，是堪萨斯州立大学的一个开源项目，目前己有开放源代码。

工具使用逻辑编程语言Datalog来描述网络元素和其安全联动情况，这简化了分析第三方工具和数据的工作。MulVaL分析工具的输入是：漏洞通告（漏洞库情况）、主机配置和网络配置、允许的访问策略，这些输入是Datalog语法描述的文件的形式。输出为PDF或TXT等格式描述的攻击图。该攻击图的节点并不是主机，其节点有三种类型：①圆形的攻击步骤节点；②菱形的权限节点，表示能从其前任结点获得的权限；③矩形的配置信息节点；下图所示，是MulVaL工具生成的攻击图的一个例子，其中的一条攻击路径是攻击者妥协了Websever后，以它为跳板攻击到Database server（0-28-8-7-6-4-3-2-1）

MulVaL是个命令行工具，可以配置漏洞库文件（默认的漏洞库为NVD）、转换OVAL/Nessus的漏洞报告、配置主机访问控制列表，然后生成攻击图。MulVaL工具的作者在文章中称攻击图生成算法的复杂度在O（n∧2）～O（n∧3）

  **2.2 TVA/Cauldron**

TVA是一款利用网络渗透的方法来研宄网络脆弱性的工具，它实现了网络渗透的自动化分析，它生成的攻击图是基于攻击步骤和攻击条件的网络状态攻击图，并由此分析出网络配置的脆弱性。TVA的攻击规则的建立尚需依靠人工手动输入，没有完善的机器学习模块。生成的攻击图会随着分析网络中节点数量的增多而变复杂，分析一个较大网络时TVA就会生成一非常庞大的攻击图文件，这给文件管理带来了不便。此外，TVA的网络脆弱性信息的输入完全依赖于nessus.如果nessus给出的结果不准确必然会导致TVA分析结果的错误。

TVA技术的商用版本称作是Cauldron。Cauldron是由NSA支持，目前己开放商用，价格为起步价15万美元。最多支持四个子网，支持更多子网的版本价格至多为几十万美元。但是经销商提供的邮件购买渠道回复称，该工具受美国国际武器贸易条例限制，想要从中国购买很困难。Cauldron工具的图形界面使用保护域

的方式使输出的攻击图变得直观清晰。保护域是一组机器的集合，他们彼此之间能够完全互相访问。关于保护域的一个事实是：攻击者如果控制了保护域中的一台机器，他就控制了其中的所有机器。除了主视图以外，Cauldron图形界面中还包括了缩略图（方便用户浏览全局）、主机目录树（方便查看保护域中的主机）、己加固缺陷的列表（进行假设分析）、漏洞列表（罗列选中主机的所有漏洞）、加固建议（消控指导）。TVA的作者声称其攻击图生成算法的复杂度为O（n∧2）

  **2.3 Skybox view**

Skybox view一款商业软件，能够进行网络建模、攻击模拟和报告。它与上述的类似，也需要以先邮件后电联的方式购买。价格为2万美元12个月，可包含100个网络。Skybox view拥有像Cauldron—样清晰直观的界面，它的界面如下图所示：

  **2.4Attack Graph Toolkit**

此工具由Oleg的等人完成，是一个在Linux操作系统平台下的攻击图工具，具有图形界面。它具有开放的源代码，但自从2007年就没有再更新过源码。Oleg等的文章中给出了其生成的攻击图界面。该工具生成的是状态攻击图，状态节点代表系统全局状态。节点是状态，边是状态转移，因此攻击图的直观效果一般。这种状态攻击图的缺点的扩展性差，攻击图构建时间长，对一个适中的网络都显得无能为力。攻击图生成算法的复杂度在指数级。

![](../Images/e8f24d27b4984bd8bffbd0565040773e.png)  

  **2.5NetSPA**

前述TVA一样，NetSPA也是美国国家政府支持的。现在已经转化为FireMon公司的一款商业软件。曾有两款增强图形显示效果的工具：GARNET和NAVIGATOR。通过Nessus（系统漏洞扫描与分析软件）扫描获得连接和漏洞信息，手工建模渗透规则并入库，生成攻击图。不足：1.mp图包含很多环路，使得网络管理人员理解起来非常困难。2、没有包含客户端漏洞。3对个别漏洞的划分存在错误，会误把客户端漏洞当做服务端漏洞来处理。

根据上表的比较以及本章对各种攻击图自动生成技术的介绍，可以知道目前典型的攻击图生成工具都是釆用先漏涧扫描和配置信息输入，然后根据这些输入信息匹配规则库分析得到攻击图的设计思路。这种思路是一种有效的攻击图生成设计方案。但是，他们都不是针对工控系统的，在分析网络结构具有层次化的工控系统时不具有针对性，且效率低下。

在网络状态信息输入和攻击图展示方面，典型的攻击图自动生成工具有的是采用命令行输入，这不利于方便的实用工具。另外，攻击图展示有的不是基于主机的，这也不利于管理人员理解。

**三、小结**

本文介绍了工控网络安全隐患分析技术，从工控系统网络漏洞挖掘技术和目前主流的攻击图技术。工控网络漏洞挖掘技术方面主要介绍了网络流量分析技术、fuzzing技术和软件你想工程技术。使用这些工控网络漏洞挖掘技术发现工控系统中各个设备上存在的漏洞和工控通讯协议上存在的漏洞，再基于这些工控漏洞研究工控系统网络整体的安全性。

本节还比较分析了五种国内外比较典型的攻击图生成工具在攻击图生成方法和分析结果展示方面的优势和劣势。通过分析，本文在使用典型攻击图生成工具设计方案的基础上针对工控系统网络的分层特点设计针对工控系统的攻击图生成方案，并提供网络状态信息输入接口和基于主机的攻击图动态展示界面。接下来的章节将详细介绍本论文给出的适用于工业控制系统网络的攻击图生成工具的设计和实现方法。
