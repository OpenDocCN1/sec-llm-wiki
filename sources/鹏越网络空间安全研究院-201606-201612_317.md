# 【鹏越工控安全】专题系列（34）——工业控制系统网络安全隐患分析方法研究(上)

![](../Images/38117b4dd20040b811f73948c9d7b29b.png)摘要：近年来，传统互联网安全风险逐步深入到工业控制系统领域，对工业控制系统的网络安全问题进行分析显得尤为重要。可以从使用自动扫描工具扫描工控网络中存在的安全隐患和进行信息安全等级保护测评两个方面保护工控系统安全。本文首先研究了工业控制系统网络的特点，其次给出了一种适用于工业控制系统安全分析的基于层的攻击图生成方法，应用这种方法可以高效准确地分析出工控系统中存在的安全隐患。最后基于工控系统的特点，本文给出工控系统等级保护应注意的问题。  

![](../Images/38e2e951f26d6ff0bcd25bfe6c018686.png)

**引言**

![](../Images/38e2e951f26d6ff0bcd25bfe6c018686.png)

工业控制系统是国家基础设施的重要组成部分，也是工业基础设施的核心，被广泛用于炼油、化工、电力、电网、水厂、交通、水利等领域，其可用性和实时性要求高，系统生命周期长，是信息战的重点攻击目标。  

![](../Images/9b4a89de69ea5694a7842ce98cbed078.png)  

随着信息化不断深入，工控系统从封闭孤立的系统走向互联体系的IT系统，采用以太网、 TCP/IP网及各种无线网，控制协议迁移到应用层；采用标准商用操作系统、中间件与各种通用软件，已变成开放、互联、通用和标准化的信息系统。因此，安全风险也等同于通用的信息系统。但是，工控系统的安全保护措施不能和传统IT网相比拟。近年来工控系统安全事件频发，尤其是“震网”“火焰”“毒区”等APT攻击的出现，充分反映出工控系统信息安全所面临形势的严峻性。  

目前国内外针对工业控制系统网络安全隐患分析的工具极少。攻击图是根据网络中各节点的连接关系以及网络中各节点的脆弱性等信息图形化地给出网络的攻击过程的方法，它适用于对工控系统网络整体进行安全性分析。与此同时，也应该加强信息安全等级保护在工控系统网络中的应用，从而保障工控系统网络的安全性。

![](../Images/38e2e951f26d6ff0bcd25bfe6c018686.png)

**1工控系统的特点**

![](../Images/38e2e951f26d6ff0bcd25bfe6c018686.png)

工业控制系统，英文简写 ICS（IndustrialControlSystems），由一系列具有自动化控制功能的器件和能够实时采集或检测现场数据的过程控制器件组成，从而保证工业基础设备的自动化运行，并对工业基础设备的运行过程进行监测和控制的工控业务管理控制系统。  

1.1

工控系统网络特点

工业控制系统网络不同于其他IT网络，它是一个半封闭的网络，具有以下特点：  
（1）实时性通信；  
（2）系统不允许重启；  
（3）人和控制过程安全；  
（4）通信协议多种多样；  
（5）设备不易更换；  
（6）设备生命周期为15～20年。

工业控制系统的这些特点决定了传统的“封堵查杀”方法难以解决工业控制系统的安全问题。  

 

1.2

工控系统网络的层次性

工控系统网络具有明显的层次结构。通常情况下，一种典型的工业控制系统架构图如图1所示。![](../Images/564a312effc10bf39a8cdf347887cff6.png)  

由上图可知，典型工业控制系统网络可分为三层，分别是IT层、办公层和工控层。

IT层是全开放的网络，即我们经常使用的网络，它可以连接到Internet。办公层是工控层和IT层的中间层，这一层的主机上有办公管理软件，OA、SCADA客户端、历史数据库客户端、ERP客户端等。SCADA客户端为用户实时地提供用户感兴趣的工控系统运行过程中产生的数据，历史数据库客户端方便用户查看工控系统历史运行据，ERP（EnterpriseResourcePlan）是企业资源计划，是企业的业务管理系统，为企业会计、财务、采购、销售、人力等企业管理人员提供工作方便。EMS位于ERP企业计划层和工控系统执行层之间，实现企业计划数据和工厂实际数据的实时通信，为企业提供实现企业执行目标的执行手段。

企业管理层使用的是企业网络。过程控制与监控部分包括历史数据库服务器、实时数据库服务器、SCADA服务器和工程师站等。

这部分是工控系统的中间部分，与企业管理相连的设备使用的是企业网络，与工控现场设备相连的设备使用的是工控系统网络。

工控层包括工控现场设备和控制现场设备的工控设备，如PLC、RTU、SCADA服务器等。控制现场设备工作，采集现场数据。

**2应用攻击图方法研究网络安全**

![](../Images/38e2e951f26d6ff0bcd25bfe6c018686.png)

目前，工业控制系统的安全性没有受到足够的重视，基本没有专门针对工业控制系统的安全性分析方法，攻击图技术适用于从整体上分析工控系统网络的安全。  

2.1

攻击图技术介绍

攻击图技术根据网络状态和脆弱性信息，分析出攻击者攻击网络时对网络脆弱性的利用序列，并将这些序列组成一张有向图，即攻击图。攻击图技术通过对网络建立模型，来模拟目标网络的实际状态，然后再分析网络中的脆弱性在网络模型中是如何被攻击者利用，从而使得攻击者可以通过利用若干个脆弱性达到其攻击目标。攻击图技术是用图的方式展示网络中脆弱性之间的关联关系，使网络管理员能够直观地观察攻击者是如何利用若干个脆弱性进行攻击，以及攻击者对网络进行攻击的全部路径，便于网络安全管理员对网络进行安全防护。

目前国内外攻击图生成算法有很多，例如基于有序搜索的攻击图生成算法、基于模式的反向搜索攻击图生成算法、基于攻击期望的双模攻击图生成算法等等。这些攻击图生成算法都是在经典的攻击图生成算法的基础上，结合使用场景需要而衍生出来的。但是现在还没有适用于工业控制系统网络的攻击图生成算法。

常规的攻击图生成算法有攻击图正向生成算法和攻击图反向生成算法两种。本论文先简要介绍这两种经典的攻击图生成算法，然后给出一种适用于工业控制系统的基于层的攻击图生成算法的设计方案。

 

2.2

攻击者属性

攻击图正向生成算法和反向生成算法的输入可以用攻击者属性来描述。攻击者属性是一个二元组，记做（Host，Goal）。其中，Host表示发起攻击的主机，他可以是单个主机，也可以是一个主机列表中的某个元素。Goal表示被攻击的主机。（Host，Goal）有四种组合方式：（Host，Goal）、（Host，Null）、（Null，Goal）和（Null，Null），不同组合方式可以表示不同的攻击图生成算法。（Host，Goal）表示攻击源和攻击目标都是确定的攻击图生成算法。（Host，Null）表示攻击源已知，攻击目标未知的情况，它代表的攻击图正向生成算法。

（Null，Goal）表示攻击目标已知，攻击源未知的情况，它代表的是攻击图反向生成算法。（Null，Null）表示攻击源和攻击目标都是未知的，这种情况下的攻击图生成算法叫做全网攻击图生成算法，这种算法的复杂度较高，不适合网络结构自身已经很复杂的工业控制网络，所以本文中不对此算法做深入介绍。

2.3

攻击图正向生成算法 

攻击图正向生成算法是由攻击源发起，逐步寻找由攻击源可以攻击到的网络中的全部节点，它适用于分析已知攻击源所在位置求网络中哪些主机容易受到攻击源威胁的情况。

攻击图正向生成算法的算法思想是攻击源首先进入队列，由攻击源出发，寻找与它直接相连的可被攻击到的主机，如果这个主机不在队列中，则这个主机入队。下一次判断是以这个新加入队列的主机为源结点，寻找可被它攻击到的其他主机。以此类推，最终得到网络中所有可被攻击源攻击到的主机列表。

2.4

攻击图反向生成算法

反向攻击图生成算法和正向攻击图生成算法正好相反，它是已知攻击目标，反向逐步推导能够攻击到这个主机的全部可能攻击源主机。它适用于已知网络中的某些特别需要保护的设备，寻求为了保护这些关键设备，我们还应该额外保护哪些网络设备的情况。

攻击图反向生成算法的思想是攻击目标主机首先进入队列，由攻击目标出发，寻找与它直接相连的可被它攻击到的主机，其他步骤与攻击图正向生成算法类似，最终得到网络中可以攻击到攻击目标的所有主机列表。
