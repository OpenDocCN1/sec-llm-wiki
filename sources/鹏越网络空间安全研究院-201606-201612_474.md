# 【鹏越精选】未来5年威胁预测分析(1)

展望未来五年，计算技术日趋普遍，几乎改善了个人生活和企业的方方面面，在为创新带来越来越多机会的同时也带来了越来越多的威胁。视觉、语音和触控技术让用户以不同的方式感知世界，并以非同寻常的新方式彼此互动。日常物品越来越智能，其互联性越来越强，将带动新一波计算浪潮。企业将与其供应商、合作伙伴、政府和客户建立更深入的实时连接，从而收集和有选择性地共享大量数据。存储和传输中的信息的价值急剧攀升，将推动新市场的发展，带动安全连接设备的需求，为云提供受信任的数据，并通过分析创造价值。像一切有价值的东西一样，信息也吸引着敌手千方百计地窃取和利用它，并从中获益。尽管人们通常想到的是有组织的犯罪等犯罪活动，但潜在敌手还包括黑客行动主义者、国家和不一定是追求直接经济利益的其他对手。就像我们对未来个性化和消费化网络攻击进行的展望一样，敌手可能还包括竞争对手、政敌、配偶、邻居或其他个人对手，以及活动日益频繁的幸灾乐祸的捣乱者。

![](../Images/9f23ec74c4976a1745dcda838815716e.png)  

关于硬件  
2015年，我们见证了硬件攻击和基于硬件的攻击方面发生的变化。安全行业和组织也发现了多种肆虐的基于硬件的攻击。就今年年初发现的Equation Group 攻击而言，恶意软件相关产品被发现时的确已经存在数年。再举一个实例，威胁研究人员发现了超低水平和极其复杂的恶意软件，根据恶意软件作者和攻击者的标准，这些恶意软件都是“旧软件”（同时）。我们之前已在受威胁的产品（如Flame、Duqu 及其他同类产品）中发现了旧版恶意软件。  
商业化攻击工具的出现，会放大硬件攻击的危害。2015年，我们发现了首个商业化UEFI Rootkit，包括源代码。该Rootkit的作者是Hacking Team，他们提供了一个名为Remote Control System 的平台，该平台就包含了这个Rootkit模块。我们已经矫正了部分正在肆虐的攻击工具。清楚源代码可以使攻击者根据自身需要轻松地自定义和更新威胁。2016 年可能会出现山寨代码和类似工具。通过努力，如NSA Playset，我们也可以找到类似实例和研究。再次强调，这些攻击工具并非新的，但是攻击者可以并且会继续使用这些工具来达到他们不可告人的目的。对于所有技术层面的威胁实施者（无论是普通的网络窃贼，还是国家）来说，攻击程序能够驻留在操作系统下都是极具吸引力的。与云或云服务提供商相结合时，系统基于固件的攻击会构成严重威胁。2015年，Intel ATR团队演示了如何通过多种媒介（包括固件Rootkit 或简单的错误配置）来获取邻近虚拟机的访问权。为了防御肆虐的攻击，可以对类似于S3 Boot Script 攻击的威胁进行矫正。在多数情况下，只需要在UEFI或BIOS 中利用简单的错误配置。  
展望未来，我们必须非常了解操作系统下的系统组件，以及如何使用这些组件来防御攻击。可以用来在操作系统下防御攻击的控件包括工具（如英特尔的Kernel Guard Technology (Intel iKGT) 和Intel BIOS Guard）。  
—Jim Walter

 

关于勒索软件  
2016年，勒索软件仍然会是主要的威胁，而且数量会激增。随着新变体即将出现以及“勒索软件即服务”的商业模式取得成功，预计2014年第三季度出现的勒索软件的数量激增的趋势会持续到2016年。2015年，我们发现了“勒索软件即服务”这种商业模式，其托管于Tor网络上，并使用虚拟货币进行支付。2016年会出现更多这种模式，因为缺乏经验的网络犯罪分子会以相对匿名的方式获取这种服务的访问权。虽然目前只有少数勒索软件系列（包括CryptoWall第3版、CTB-Locker和CryptoLocker）上市，但是，我们预计，这些系列的新变体以及新的系列会呈现新的隐秘功能。例如，新变体可能会秘密地对数据进行加密。攻击者会备份这些加密的文件，最后会取走密钥，从而导致系统上的文件和备份文件都处于加密状态。当用户访问这些文件时，其他新变体可能会使用Kernel组件实时连接文件系统和加密文件。

![](../Images/1656e54a3994db35d5e5cccd9542a760.png)  

最新勒索软件活动的幕后操纵团队通过发送垃圾邮件活动和利用工具包（如Angler），将公民有能力支付赎金的富裕国家/地区作为勒索目标，寻求一夜暴富。虽然我们预计这种趋势会持续到2016年，同样我们也预见到了不同行业/部门（包括金融行业和地方政府）的全新关注点，这些行业会快速地支付赎金，以恢复他们的关键操作。事实上，我们已经发现，犯罪分子攻击这些行业/部门的效率相当高。通常只有

Microsoft Office、Adobe PDF 和图形文件是攻击对象；我们预测，2016年，业务环境中常见的其他文件扩展名也会变成攻击目标。MicrosoftWindows 仍将会继续受到攻击。我们预计，由于MacOS X的日益普及，2016 年勒索软件也会开始将其作为攻击目标。

在2015年的报告中，我们预测了勒索软件会攻击云和移动设备，但却很少发现它们在这些领域尝试发起攻击。尽管人们将个人文件保存于手机中，但从应用程序提供商的云服务或本地备份中还原加密的或损坏的文件却非常容易。  
—Christiaan Beek

 

关于漏洞  
对于软件开发人员及其用户而言，应用程序漏洞是始终是无法避免的问题。Adobe Flash 可能是最常被攻击产品：Flash漏洞（包括CVE-2015-0311 和CVE-2015-0313）几乎占安全产品公司2014年和2015年检测到的零日攻击的三分之一。尽管Flash 已经臭名昭著，但是Adobe仍然快速地修复了存在的漏洞。而且，由于最新的Flash Player 补丁中引入了新的降低风险的功能，我们预计，这种攻击媒介的热潮（尤其是通过漏洞利用工具包发起攻击）会在明年降温。  
由于不断提升Flash 安全和利用标准，这些降低风险的功能会让“媒介喷洒” 这种利用手段不再受欢迎。不过，任何防御措施或风险降低方案都不是完美的。由于Flash 的代码质量和复杂性并未改变，因此，仍然会存在很多Flash 漏洞。我们预计会发现一些风险降低方案概念的工作证据，并于明年披露。  
一些开发人员呼吁HTML5 取代Flash，而且，Google Chrome 即将禁用Flash。不过，禁用Flash 的过渡期会很漫长。互联网充斥着遗留的Flash 内容，至少桌面机是这样（但移动设备不是这样）。我们不敢奢望很快发生这种变化。

![](../Images/ef09a7ff4993ad426b5d724da66bf62c.png)  

虽然我们有时仍然能遇到肆虐的漏洞（如CVE-2015-2425 和CVE-2014-1815），但是，如今Internet Explorer中的漏洞数量却远少于几年前。漏洞数量的减少基本上归功于最新风险降低方案，该方案提高了漏洞利用的成本。另一方面，虽然Microsoft不断提升IE的新防御能力（增强保护模式、虚拟表防护、数据流控制防护、独立堆和内存保护等），但是攻击者经常会找到方法绕过这些防御措施。绕过这些防御功能的技巧经常会被泄露。因此，发现高级的零日攻击绕过IE的最新防御功能只是时间问题。  
配置了Windows 10的Microsoft新浏览器和Edge怎么样？根据其不断扩大的攻击面（因为支持新的Web标准）以及新增强的风险降低方案（如内存垃圾收集器），我们预测这个新战场上会出现一些有趣的竞争现象。Edge会像IE一样易受攻击吗？我们预计仍然可以在Edge 中找到漏洞，不过，要利用这些漏洞会变得越来越困难。  
最近几年，Java、PDF和Office的漏洞利用已大幅度减少。在过去的两年内，我们只在肆虐的攻击中发现了一个Java零日攻击(CVE-2015-2590)。我们将这种趋势归功于提升了Java Runtime Environment最新版本的安全性。在过去几年中，基于Office的主要零日攻击的数量并不多，但是这种攻击在企业计算环境中却非常危险。在2015美国黑帽子大会上，我们展示了对象链接和嵌套(OLE)（Office 文件使用的一项重要功能）安全的研究成果。我们发现OLE具有非常大的攻击面，预计攻击者会继续攻击OLE。当前用来阻止基于Office 漏洞攻击的检测和防护方法仍然不是很有效（例如，加密的Office文件可用于逃避检测）。因此，我们预计明年会出现更多基于Office的攻击。  
尤其是，我们预计会看到在Windows以外的其他领域利用新发现的漏洞。嵌入式系统、物联网安全和基础架构软件会逐渐成为高级威胁和零日攻击的目标。这些目标包括Unix 变体、常用的职能手机平台、IoT 特定系统（如Tizen 和ProjectBrillo）以及底层基础组件和数据库（如Glibc 和OpenSSL等）。尤其要说的是，广泛使用的基础数据库和组件，特别是开源框架工具并未完全发挥其应有的安全防护功能。回顾过去两年发现的主要零日攻击，我们发现，大多数攻击都与开源软件中的漏洞有关。例如CVE-2015-0235 (GHOST) 和OpenSSL 故障（如CVE-2015-1793、CVE-2014-3566和CVE-2014-0160）。我们预计这些非Windows 目标在2016 年会遭遇越来越多的攻击。  
—Bing Sun 和Haifei Li

 

关于支付系统  
过去，购物非常简单。要购物，您只需要在钱包里放入足够的现金就行。但是如今，其他支付方式的数量令人眼花缭乱，包括Bitcoins、ApplePay、信用卡、贷记卡以及在线支付服务等。根据Wikipedia 的记录，目前已有740 多种加密货币！Wikipedia 还记录了60 多种在线支付服务。  
我们着重关注信用卡和贷记卡交易相关漏洞的安全。这样做很有必要，因为大部分数字交易都通过这两种形式进行支付。但是，随着其他支付方式的增加，攻击面的数量也随之增加，从而给网络窃贼提供了更多可以选择的攻击目标。我们很少发现信用卡和贷记卡相关的攻击方式有所创新。大多数攻击方式仍然是支付卡窃贼在过去10 年内使用的方式，即攻击支付机制或数据库中的支付卡数据。一旦窃贼获取到支付卡数据，他们就会以最快的速度倒卖这些数据以获取利益。

不过，目前这种情况正在发生变化。由于支付方式过于繁杂，大多数支付方式仍然需要用户名和密码，这些凭据已经变得非常宝贵。为了窃取这些凭据，网络犯罪分子会将消费者直接视为攻击目标，因为消费者不仅是这些凭据的来源，而且还是支付流程中最薄弱的环节。我们预计，支付系统网络犯罪分子的目标会越来越集中于可盗取数据的攻击，以及倒卖盗取到的凭据。我们认为，他们会利用传统的且经过时间验证有效的机制，包括网络钓鱼攻击和按键记录程序，不过他们也会采用新的攻击方式。我们同时还预测，支付系统窃贼的数量会持续增加。  
—Raj Samani
