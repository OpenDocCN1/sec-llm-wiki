**引言**

       等级测评活动是确保信息安全等级保护工作的关键环节，通过测评能够了解系统的安全现状与等级保护要求之间的差距，明确安全整改的目标与方向。工具测试作为一种高灵活性的辅助测试手段，在测评活动中发挥着重要作用。

本文旨在通过对测评工具在等级测评中的作用进行分析，为各测评机构在工具的选择、使用和维护方面提供参考。

 ![](../Images/30fdff07abce58ed3b934187b4e97410.png)  

  

**1 ****测评工具在等级测评中的作用**

      信息系统安全等级测评是信息系统安全等级保护工作中的一项重要环节。“43号文” 第十四条指出“ 信息系统建设完成后，运营、使用单位或者其主管部门应当选择符合本办法规定条件的测评单位，依据《信息系统安全等级保护测评要求》等技术标准，定期对信息系统安全等级状况开展等级测评”。信息系统备案单位通过委托测评机构开展等级测评，可以查找系统安全隐患和薄弱环节，明确系统与相应等级标准要求的差距和不足。而根据《信息系统安全等级保护测评要求》，测评指标直接指向《信息系统安全等级保护基本要求》（以下简称《基本要求》）中相应等级的级别要求。要准确的对信息系统进行等级测评，除依靠测评人员的技能外，利用测评工具进行工具测试也是等级测评的一种辅助手段，测评工具能够简化测评工作并提供规范化的测试流程和公正客观的测评结果，在一定程度上解决了手动测评的局限性。

      根据在等级测评过程中任务的不同，等级测评工具可以分成如下三大类：

1）等级测评安全测试工具：主要用于对信息系统的主要部件（如操作系统、数据库系统、网络设备等）的弱点进行分析，或实施基于弱点的攻击。此类工具又可进一步细分为脆弱性扫描工具、渗透测试工具和静态分析工具；

2）等级测评辅助工具：主要实现对数据的采集、现状分析和趋势分析等单项功能；

3）等级测评管理工具：主要用于规范等级测评的过程和操作方法；或者是用于收集测评所需要的数据和资料，并根据测评知识库和推理专家知识库辅助测评人员进行测评结果判断。

 

**2 ****测评工具的分类和常见工具介绍**

2.1 等级测评安全测试工具等级测评安全测试工具包括脆弱性扫描工具、渗透性测试工具和静态分析工具。

       脆弱性扫描工具又称为安全扫描器或漏洞扫描仪，是目前应用比较广泛的测评工具之一，主要用于识别网络、操作系统、数据库系统的脆弱性。通常情况下，这些工具能够发现软件和硬件中已知的弱点，以决定系统是否易受已知攻击的影响。

       目前常见的脆弱性扫描工具有以下几种类型：

1）基于网络的扫描器：在网络中运行，能够检测如防火墙的错误配置或连接到网络上的易受攻击的网络服务器的关键漏洞；

2）基于主机的扫描器：发现主机的操作系统、特殊服务和配置的细节，发现潜在的用户行为风险，如密码强度不够，也可实施对文件系统的检查；

3）分布式网络扫描器：由远程扫描代理、对这些代理的即插即用更新机制、中心管理点三部分构成，用于分布式网络的脆弱性扫描；

4）数据库脆弱性扫描器：对数据库的授权、认证和完整性进行详细的分析，也可以识别数据库系统中潜在的弱点。当前比较流行的扫描工具有：天镜脆弱性扫描与管理系统、绿盟极光远程安全评估系统、明鉴数据库 /WEB 应用弱点扫描器、ISS Internet Scanner、Appscan、Nessus等。

       脆弱性扫描工具主要的缺陷包括：需要人工干预（扫描工具容易产生漏洞及误报）；只能发现已知弱点（受漏洞库制约）。

       渗透性测试工具是根据脆弱性扫描工具扫描的结果进行模拟攻击测试，判断被非法访问者利用的可能性，从而进一步判断已知的脆弱性是否真正会给系统或网络带来影响。通常渗透性工具与脆弱性扫描工具一起使用，并可能会对被测评系统的运行（尤其是稳定性）带来一定影响。目前比较常用的渗透性测试工具有：Metasploit、Canvas、Threatex、CoreImpact、Webravor 等。

       在等级测评过程中，静态分析是渗透测试的必要补充。静态分析工具在不执行程序的状态下，通过对被测软件进行建模，发现满足所有可能执行状态的软件属性，再藉由一组规则集分析并检测软件中存在的安全漏洞。在等级测评常用的静态分析工具是软件代码安全分析系统，它可以对软件源代码进行安全扫描和审计分析的信息汇总。此类工具有 Fortify、Coverity等。

2.2 等级测评辅助工具

       等级测评的过程中，可以利用一些辅助性的工具和方法来采集数据，帮助完成现状分析和趋势分析，如：

1）性能测试工具：主要功能包括网络流量测试、数据拦截、 IP 查询、流量分析、预测系统行为和性能的负载测试等。常见的此类工具有Smartbits、loadrunner、 Avalanche；

2）协议分析工具：主要用于IP网络流量分析、故障排除和长时间监测、对通讯协议进行解码和显示、对不同技术的数据流量和状态进行全面的物理层测试，并以图形化的方式显示结果。协议分析工具一般提供多种实用的分析功能对常用的协议进行流量分析，例如 IP 地址对、源地址、目的地址、IP上层协议分布、TCP/UDP 端口号等，可长时间在线实时统计，并提供饼、表、线等多种形式的报表。此外，协议分析工具还可以对网络流量进行协议划分，如：Web浏览（HTTP）、电子邮件（POP3、 SMTP、WEB MAIL）、文件下载（FTP）、即时聊天（MSN、QQ 等）、流媒体（MMS、RTSP）等。针对不同的网络应用协议进行流量监控和分析，如果某一个协议在一个时间段内出现超常占用可用带宽的情况，就有可能是攻击流量或蠕虫病毒出现。常用的协议分析工具包括：Radcom、Sniffer Pro、Wireshark等；

 3）网络拓扑生成工具：通过接入点接入被测评网络，完成被测评网络中的资产发现和统计功能，并提供网络资产的相关信息，包括网络硬件设备的识别、操作系统版本、型号等。此类工具有： HP Openview 等。

2.3 等级测评管理工具

       等级测评管理工具是一套集成了等级测评各类知识和判据的管理信息系统，用以规范等级测评的过程和操作方法；或者是用于收集测评所需要的数据和资料，并根据测评知识库和推理专家知识库辅助测评人员进行测评结果判断。等级测评管理系统工具可以对信息系统、制度和人员等进行全面的安全性证据获取，并提供多种自动化的测试手段，测评人员通过接入客户的信息系统对目标网络进行信息调查，获取大量全面的系统安全性数据，同时测评人员在工具的引导下，手工输入非工具自动收集的证据数据，在知识库的辅助分析下，综合得出系统的安全现状和保护等级的符合度，并以多种格式的测评报告形式输出测评结果。

**3 ****测评工具在等级测评中的应用**

3.1 等级测评安全测试工具的应用

       脆弱性扫描工具在等级测评中可用于扫描防火墙、路由器、交换机、服务器操作系统、数据库和 Web 应用程序并发现其中的薄弱点，如非法账号、弱口令、权限配置错误、系统补丁、文件目录及文件系统安全、不必要的服务和端口等薄弱点。发现的薄弱点以及针对该薄弱点的评价可以作为系统脆弱性严重判断的依据之一。例如IBM ISS Scanner 是一款典型的基于网络的扫描器，可以用于评估操作系统和应用程序的漏洞。与其它扫描器相同，ISS Scanner有自身的内部漏洞信息数据库以便精确地识别远端系统的漏洞。使用ISSscanner 进行扫描一般包含如下步骤：

1）对指定 IP 的网络或远端主机进行端口扫描，识别网络的基本拓扑信息和远端主机正在运行的服务，为下一步的漏洞扫描采集信息做好铺垫；

2）根据端口扫描返回的信息，扫描器调用自身漏洞库信息进行规则匹配，匹配成功即视为漏洞存在；

3）生成评估报告。ISS scanner的评估报告采用包括 HTML 在内的多种格式。使用扫描器要求评测者根据自身经验，人工识别扫描结果中的漏洞和误报，从而得出正确的评估结果。

       渗透测试工具还能通过模拟黑客行为，进行黑客测试，检测已发现的漏洞是否真正会给系统或网络环境带来威胁。渗透工具最典型的当属Core Impact。Core Impact可以让测评者从攻击者的角度去审视和评估整个网络的安全性，测评者不必掌握所有漏洞细节和任何攻击代码开发技能，就能完成一次自动的渗透测试过程。使用Core Impact 进行渗透测试的典型步骤包括：远程信息获取、攻击渗透、本地信息获取、权限提升、清除日志、生成报告。此外，与一般的扫描工具相比， Core Impact 最大的优势在于它对漏洞的评估是建立在攻击成功的基础之上，因而不存在误报（假警报）。

        静态分析工具可用于检查应用系统是否满足《基本要求》中提出的安全控制要求。目前的静态分析工具大多采用多种分析引擎从多个层面对应用程序进行安全分析。以 Fortify SCA为例，Fortify 包含五个不同的分析器：数据流分析器、控制流分析器、语义分析器、结构分析器以及配置分析器。每个分析器均会接受不同类型的规则。例如，数据流分析器可以检测用户控制的数据用于危险用途的潜在漏洞。使用数据流分析方法来跟踪攻击数据的污染传播（Taintpropagation），是识别许多输入验证缺陷和表示缺陷的关键。例如，数据流分析器可以检测一个用户控制的特别长的字符串输入是否正被复制到一个固定长度的缓冲区中，还可以检测一个用户控制的字符串是否正被用来构建 SQL 查询文本。数据流分析器可用于检查应用系统是否提供了《基本要求》在“ 软件容错”控制点上提出的数据有效性检验功能。

3.2 等级测评辅助工具的应用

       等级测评辅助类工具可以发现，收集并统计异常行为，从而为等级测评中威胁发生可能性、薄弱点的严重程度判断提供技术依据。例如，对系统中可能面临的“ 外部攻击”威胁，测评人员可以通过主观的分析，得到大致发生的概率，但如果有等级测评安全测试工具的支持，通过统计一段时间内发生攻击的次数，对威胁发生概率和入侵利用薄弱点的严重程度判断就能更为准确。以Sniffer Pro为例：Sniffer Pro是一款功能强大的协议分析软件，提供网络查询和应用性能故障诊断功能。智能化的专家分析系统协助测评人员在进行数据包捕获、实时解码的同时快速识别各种异常事件；其数据包解码模块支持广泛的网络和应用协议，不仅限于常见的HTTP、 FTP、Oracle、还包括VoIP 类协议，以及金融行业专用协议和移动网绚类协议等等。此外Sniffer Pro提供直观易用的仪表板和各种统计数据、逻辑拓扑视图，并且提供能够深入到数据包的点击关联分析能力。能够给予测评人员实时的网络监视、数据包捕获、异常流量监测以及故障诊断分析能力。借助此类协议分析工具，测评人员可以发现异常的网络通讯，如蠕虫病毒、黑客扫描等。

3.3 等级测评管理工具的应用

       等级测评管理工具是对于整个等级测评过程的管理，是专家知识的具体体现。管理工具一般基于某个标准或某种最佳实践，它将所形成的方法论进行了固化。相对而言，等级测评安全测试工具和辅助工具是针对系统具体对象，管理工具是针对等级测评活动的。信息系统安全等级测评工具是在国内领先的信息安全检查专家团队在深入分析信息安全检查技术要求、国内信息系统面临安全威胁和典型案例的基础上研制而成。提供了详细的操作流程、步骤说明，还具有融合自动化工具和第三方安全检查工具检查、扫描的功能，能够有效协助使用者对信息系统进行安全检查和管理工作。

3.4 工具测评与《基本要求》的对应举例

        工具测试作为一种高灵活性的辅助测试手段，在测评工作中发挥着重要作用。以《基本要求》对三级系统的基本要求为例，工具测试在等级测评过程中发挥的作用详见表1。

表1  三级系统的基本要求

| 《基本要求》项 || 工具测试方法 |
| --- | --- |
| 7.1.2.1 结构安全 c) 应在业务终端与业务服务器之间进行路由控制建立安全的访问路径； || 利用Traceroute 等命令，跟踪路由信息，查看网络之间的路由情况。 |
| f) 应避免将重要网段部署在网络边界处且直接连接外部信息系统，重要网段与其他网段之间采取可靠的技术隔离手段； || 利用多点扫描结果对比分析 |
| 7.1.2.2 访问控制（G3）b) 应能根据会话状态信息为数据流提供明确的允许 / 拒绝访问的能力，控制粒度为端口级； || 利用多点扫描结果对比分析 |
| c) 应对进出网络的信息内容进行过滤，实现对应用层 HTTP、FTP、TELNET、SMTP、POP3 等协议命令级的控制； || 利用端口、漏洞扫描及渗透测试工具，验证是否具备命令级别的检测及阻断能力 |
| 7.1.2.5 入侵防范（G3）a) 应在网络边界处监视以下攻击行为：端口扫描、强力攻击、木马后门攻击、拒绝服务攻击、缓冲区溢出攻击、IP 碎片攻击和网络蠕虫攻击等； || 在入侵防范设备监控范围内，针对入侵防范设备策略配置情况，进行漏洞扫描以及渗透测试等手段，发送攻击数据，查看入侵防范设备的响应情况。 |
| b) 当检测到攻击行为时，记录攻击源  IP、攻击类型、攻击目的、攻击时间，在发生严重入侵事件时应提供报警。 || 在入侵防范设备监控范围内，针对入侵防范设备策略配置情况，进行漏洞扫描以及渗透测试等手段，发送攻击数据，查看入侵防范设备的响应情况。 |
| 7.1.2.7 网络设备防护（G3）a) 应对登录网络设备的用户进行身份鉴别； || 利用扫描器弱口令探测功能探测网络设备弱口令 |
| e) 身份鉴别信息应具有不易被冒用的特点，口令应有复杂度要求并定期更换； || 利用扫描器发现网络设备漏洞，尝试利用渗透工具进行验证测试 |
| 7.1.3.2 访问控制（S3）d) 应严格限制默认帐户的访问权限，重命名系统默认帐户，并修改这些帐户的默认口令； || 利用扫描器探测服务器是否存在默认账户，利用扫描器探测系统是否存在弱口令 |
| 7.1.3.5  入侵防范（G3）a) 应能够检测到对重要服务器进行入侵的行为，能够记录入侵的源IP、攻击的类型、攻击的目的、攻击的时间，并在发生严重入侵事件时提供报警； || 利用扫描器、渗透工具，对目标服务器进行漏洞扫描及模拟攻击操作，查看目标服务器报警及日志情况 |
| c) 操作系统应遵循最小安装的原则，仅安装需要的组件和应用程序，并通过设置升级服务器等方式保持系统补丁及时得到更新。 || 利用扫描器漏洞扫描功能，探测目标系统所开启的服务及漏洞情况 |

**4 ****结束语**

        工具测试，结合其他核查手段，可以为等级测评结果的客观和准确提供保证。三种不同类型测评工具在等级测评过程中都可发挥其各自的功能优势。与此同时，国内具有自主知识产权的测评工具不断涌现将为等级测评人员提供更多的选择。
