# 赛虎-鹏越“工业控制系统安全运维师(CIIP-I)”培训正式启动！

***20******17年3月21******日，*****全国首个权威工控网络信息安全类培训课程——“*****工业控制系统安全运维师（***CIIP-I***）*****”*****培训 *****将在华北电力大学信息安全工程实验室正式启动！**  

  

       本次培训由**公安部信息安全等级保护评估中心**主办，**北京赛虎网络空间安全技术发展有限公司具体**承办，**鹏越网络空间安全研究院**负责招生。此次培训为期4天。3月20日报到，3月21日至24日为正式培训日。各行业工业控制系统的管理决策、规划设计、集成建设、运营管理、应用维护、安全保障等相关人员均可报名参加培训与考试。考试合格者可获得由公安部信息安全等级保护评估中心颁发的工业控制系统安全运维师（CIIP-I）（初级）证书 。
