# 【鹏越·学霸专区】Linux操作系统的安装

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMTQyOTc2OQ==&mid=2247488161&idx=4&sn=fde0b36e653644e6889318ff63e4f776&chksm=e83dbbc7df4a32d14ea2ceeccfbe83cf63bc6d8bb900ffed040a03376269d237d1c9b2ad361c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyMTQyOTc2OQ==&mid=2247488161&idx=4&sn=fde0b36e653644e6889318ff63e4f776&chksm=e83dbbc7df4a32d14ea2ceeccfbe83cf63bc6d8bb900ffed040a03376269d237d1c9b2ad361c&scene=27#wechat_redirect)

![](../Images/38117b4dd20040b811f73948c9d7b29b.png)因为笔者一直都是使用CentOS，所以这次安装系统也是基于CentOS的安装。把光盘插入光驱，设置bios光驱启动。进入光盘的欢迎界面。

![](../Images/698de1d454b97089b40d0499ac4d101d.png) 

其中有两个选项，可以直接按回车，也可以在当前界面下输入 linux text 按回车。前者是图形下安装，可以动鼠标的，后者是纯文字形式的。建议初学者用前者安装。直接回车后，出现一下界面：

<img src="http://www.92csz.com/study/linux/images/3\_27.png" "alt="\[image\]" border="0">

这一步是要提示你是否要校验光盘，目的是看看光盘中的安装包是否完整或者是否被人改动过，一般情况下，如果是正规的光盘不需要做这一步操作，因为太费时间。接下来是：

![](../Images/ec9e54273bd9d054e4ace2ae0cde99c5.png)

这一步没有什么可说明的，直接点“Next”

![](../Images/632b4935c340d0f20709fdb67b1dfd3c.png)

这里是选择安装系统时所用语言，笔者习惯用English，当然你也可以选择Chinese(Simplified)（简体中文），选择好后点“Next”

![](../Images/5981961d6f0c5edbc5526ea9d1b5c733.png)

这里是选择合适的键盘，我们平时使用的都是英文键盘，所以这里不用动，默认即可，直接“Next”

![](../Images/529279113da934f3b620f1d793e2cb39.png)

到这里就会提示你，下面会分区，会初始化磁盘，磁盘上的数据会丢失，问你是否要初始化设备并清除磁盘上的数据。因为是空盘，所以选择“Yes”

![](../Images/eaf0eda1851cf5f172f7a7eb23de21b0.png)

 

到这一步，就该分区了。其中一共有四种方式可以供你选择

![](../Images/3db7c468cb7046eabd3a245e4a20e828.png)

 

第一种，在所选磁盘上把所有分区移除，然后按照默认的方式分区；

第二种，在所选磁盘上把所有linux分区移除（如果磁盘上有windows格式的分区，并不会移除），然后按照默认方式分区；

第三种，在所选磁盘上只使用空闲部分，并且按照默认方式分区；

第四种，用户自定义。

这里我们选第四种。然后“Next”

![](../Images/6bc2ff490f4226dc5c6380bd85b6567c.png)

 

![](../Images/4c5e332214fa3a88b2ae7ad63d3d0910.png)

 

接下来该分区了，分区的很灵活，但大体上按照这个规则来（这是服务器上这样分，如果你是虚拟机，请看后边部分）：

1.  /boot 分区 100M
    

![](../Images/904cd58a2b64ca018da6f0a7bfb594b0.png)

2.  Swap 分区 内存的2倍，如果大于等于4G，则只需给4G即可
    

 

![](../Images/6c871058faa02964e314aae6e061e770.png)

 

3.  / 分区给20G
    

 

![](../Images/a3eac9b74a75f527a8e8bcc61fb5d26f.png)

 

4.  剩余空间给/data
    

![](../Images/b9f08d863957c67bc03466e90e1e0149.png)

说明：/boot 分区是系统启动所需要的文件，就跟windows的C盘中的windows 目录类似，这个分区中的文件并不大，只需要100M足够。Swap分区是交换分区，当内存不够时，系统会把这部分空间当内存使用。/ 分区，其实就是一个根目录，在以后的章节中会介绍到。现在不懂并没有关系，只要知道有这么一个东西即可。/data 这个分区是我们自定义的，就是专门放数据的分区。

如果你安装的是虚拟机，并且你只有8G的磁盘空间，那么我建议你这样分区：

1 /boot 100M

2 swap 内存的2倍

3 / 全部剩余空间

分区完后，点“Next”

![](../Images/9e76d28eae26c37cba4dc8713e7d3737.png)

可以在Use a boot loader password 前面打勾，这个选项的作用是，给boot loader 加一个密码，为了防止有人通过光盘进入单用户模式修改root密码。

下面的选项同样可以打勾，笔者从来没有用过该功能，如果你有兴趣，可以研究一下。然后下一步

![](../Images/3c3d4fa161da13831c335ac2f038a095.png)

这一步是配置网卡信息，可以现在自定义网卡的IP，和配置主机名，默认是通过DHCP获得，你也可以点manually 自定义一个主机名，如 mail.example.com 。如果这两种方式都没有配置，那么linux会给你配置一个万能的主机名，即localhost.localdomain 剩下的几个就不用配置了，默认留空。

接着下一步，选择时区，在这里当然要选择我们所处的时区Asia/Chongqing 如果没有Chongqing那就选择Asia/Shanghai。

![](../Images/65de577c3c3d96c26c5b1281017218b7.png)

继续下一步

![](../Images/15ca6479790f1319452a447bb21bbbb4.png)

在这里自己定义一个root的密码，继续下一步

 

 

![](../Images/85e4b17236cf548b8eeba2d62b27f8c5.png)

这里要我们选择要安装的包，笔者习惯自定义安装，需要点下面的“customize now”然后下一步

“Desktop Environments” 看右侧，把GNOME 前面的勾去掉，这个其实就是图形界面的安装包，如果不去掉这个勾，就会安装图形界面。

![](../Images/105947af5cd2579ee657a2af9d6fe592.png)

“Applications” 除了Editors 前面的勾去掉外，其他均不要

![](../Images/1c677d137b24fea589b94037668aa7c7.png)

“Development”全部都要勾上

![](../Images/42bb22c7b2e424d9d6c7e08d2496b840.png)

“Servers”以及以下所有项都不要勾任何，然后下一步

![](../Images/c534769e26d85f67a6d1906c5fbc7c7a.png)

点Next 后，系统就开始安装了。

![](../Images/17fac90210ab0c9c68a62d5a5c961dfe.png)

等过会后，会出现

![](../Images/a60724ca864d66a3079878a0218de019.png)

至此，linux系统已经安装完成了。接下来点“Reboot”重启一下，进入linux系统看看吧。
