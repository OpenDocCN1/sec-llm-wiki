**摘　要：** 随着互联网的迅猛发展，其规模不断扩大、应用更加广泛，许多部门和企业的关键业务活动越来越多地依赖于网络，各种网络攻击、信息安全事件发生率在不断攀升。态势感知与 APT 逐渐成为网络热词。文章阐述了一种基于大数据的网络空间安全态势感知数据收集的实现方法。结合网络流量分析方法，进行网络空间态势感知分析，产生可持续、即时性强的网络安全数据，实时分析感知网络攻击行为。并且通过可视化手段，为网络安全实施感知以及未来趋势、决策研判提供有力手段。文章着重介绍网络空间安全态势感知系统数据收集方式，并说明 APT 检测技术在网络空间安全态势感知系统中的应用与实现，将二者相结合，提供一种新的态势感知数据构建思路。

**关键词 ：** 大数据 ；态势感知 ；流量分析 ；高级持续性威胁

**1 概述**  

网络安全事件对于社会和经济的影响越来越大，外部攻击事件、国家支持的网络间谍活动日渐增多（如斯诺登揭露的 NSA 间谍活动），带有政治意图的网络攻击大量增加，意识形态也逐渐成为网络攻击的最大诱因。而攻击方式也随着互联网技术发展，由传统网络攻击模式转变为高级持续性攻击，利用的手段往往是未知威胁与持续性组合攻击模式。乌克兰电力系统受到 APT 攻击事件，给国内外企业和用户都敲响了警钟，而未知威胁感知手段也成为热议话题。网络空间的安全态势感知系统，应当能够结合重点网络监控防御与流量威胁分析，实时感知并以可视化方式展现“现在”网络安全态势，为安全“应激”提供支持，并为“未来”安全决策提供数据支撑。

**1.1 网络安全态势感知**  

态势感知（Situation Awareness，SA）概念起源于 20世纪 80 年代的美国空军：分析空战环境信息，快速判断当前及未来形势并做出正确反应。公认的 SA 解释是：在特定时空下，对动态环境中各元素或对象的觉察、理解以及对未来状态的预测。  
从这个解释上讲，我们把网络安全态势感知从时间维度上理解，网络安全态势感知应当是积累“过去”的安全事件及资产底数，感知“现在”的威胁与风险，预测“未来”的风险可能，以求在最短的时间内发现攻击并提供应急方案，并对后续的决策提供有力支撑。  
从系统能力上，网络态势感知系统应具备以下能力：数据收集能力、数据存储能力、数据挖掘能力、实时处理并可视化呈现能力，并能够与传统网络安全技术与经验相结合，进行网络安全的感知预测。  
一般我们可把网络安全态势感知分为三个阶段：1）攻击事件和安全漏洞感知，这一阶段主要建设态势感知的数据来源，数据来源可以包括网络安全设备、蜜罐、服务器日志、主动扫描的数据、木马病毒防护软件等，该部分主要用于识别攻击及漏洞等威胁，收集网络安全相关数据；2）进行安全态势建模、进行大数据统计与分析、利用机器学习技术实现数据挖掘，由于态势感知的实现往往数据来源较大，所以一般可考虑结合云计算技术，大幅度提高实时分析挖掘能力；3）关联的威胁评估，主要把监测、挖掘到的攻击行为、漏洞、威胁等进行关联，深入结合挖掘，在第二阶段的基础上，利用概率论的统计方法，进行态势感知的统计与预测。网络安全态势的理解是指在获取海量网络安全数据信息的基础上，通过解析信息之间的关联性，对其进行融合，获取宏观的网络安全态势。图 1 为网络安全态势感知的三个阶段。

**1.2 网络安全态势感知要解决的问题**  

根据前文所述，本文讲述的网络安全态势感知系统主要用于解决以下问题：  
1）收集网络安全相关的数据信息，便于安全运维人员全方位掌握当前安全状况；  
2）通过机器学习、数据挖掘、大数据统计等方法，结合数据建模，进行深层次数据分析，结合概率统计、因果分析、行为关联等方法，统计现在，预测未来，解决传统防护孤岛难题，将网络安全防护方案有效整合，并为安全决策提供支撑；  
3）把收集到和挖掘到的数据通过可视化方式呈现，提供实时态势分析与感知；  

4）结合大数据、云计算特点，及时感知网络空间最新攻击技术，为未知威胁的攻击手法提供分析手段，降低网络安全风险。  
围绕这些问题，本文重点描述网络安全态势感知所需的数据来源与数据收集方法，并对数据挖掘、关联提出方案。

**2.1 态势感知数据来源**  

态势感知实质上是对网络空间安全的威胁分析。威胁分析包括威胁识别和威胁评估两个过程。威胁识别就是根据资产实际所处的环境和既定的经验对资产可能遭遇的威胁进行判断。需要识别的威胁具有多种类型，主要有软件硬件故障、物理环境影响、管理问题、恶意代码、网络攻击、物理攻击、泄密、篡改等。由于篇幅原因，本文仅讨论恶意代码、网络攻击等内容。  
对重要信息系统的网络安全防护主要分为几个方向：  
1）安全防护建设，主要以入侵防御系统、入侵检测系统、防火墙、Web 应用防火墙、防攻击篡改系统、数据库防火墙、抗 DDoS 设备以及其他与云技术结合的网络防护技术。  
2）安全监测建设，主要包括重点信息系统的网站安全监测（包括可用性监测、木马检测、篡改监控、漏洞分析、暗链检测等）、数据库漏洞检测、系统与应用漏洞分析检测技术、弱口令探测、设备指纹分析等。  
3）运维、审计建设，主要包括数据库审计、综合日志分析审计、运维审计系统（堡垒机）等。  
4）终端安全防护，个人 PC 的防病毒软件等。  
除了以上几个传统的网络安全防护方向以外，目前也产生了几种新型网络安全防护技术，与传统网络安全防护技术相结合，提供更多防护能力（传统防护设备基于已知威胁特征进行防护，而越来越多的攻击方式转为持续攻击。不论是单独或同时使用特征码防火墙、入侵防御系统（IPS）、网络闸道器、沙箱或防毒（AV）软件，都无法完全阻隔攻击\[5\]。），如 APT网络攻击入侵检测系统（具备 Web 攻击检测、邮件攻击检测和文件攻击检测能力。针对基于各种方式发起的 APT 攻击，通过对网络中的流量进行深度解析，发现其中的攻击事件。利用网络流量分析技术，异常访问定位技术、邮件社工分析技术、基于 Web 的特征检测技术、恶意文件分析技术、动态行为分析技术，有效分析、关联攻击行为，识别未知威胁及攻击手段），Web 业务审计系统（结合机器学习技术，通过对比分析 Web 业务的正常访问与非法探测，识别非法探测与攻击行为）。  
以上防护技术都应当纳入态势感知数据收集方法与来源，并通过有效的结合，形成全网位安全监控。

“云上”态势感知系统结合分布式计算技术，建立以高速分析能力为核心的快速数据转存与分析挖掘平台，并在全国各地建立分布式网站可用性探测端进行网站监控，并将“地端”平台数据与个人 PC 木马病毒防护数据进行结合分析，进行特征提取。在接收“地端”与个人 PC 客户端数据的同时，主动为“地端”推送威胁识别特征与全网态势感知信息。

**2.3.1 网站安全监控数据**  

常见网站安全监控技术的主要功能包括：网站可用性监测、篡改监测、网站木马检测、漏洞检测以及全文关键字索引等。  
1）可用性监测 ：网站域名、IP 地址、是否可用、检测时间。  
2）篡改监测 ：网站域名、IP 地址、更改位置、更改内容、更改时间。  
3）网站木马检测 ：网站域名、IP 地址、网马类型、网马特征、检测时间、样本。  
4）漏洞检测 ：网站域名、IP 地址、漏洞类型、描述与建议、漏洞编号、检测时间。

**2.3.2 APT网络攻击入侵检测技术**  

APT 网络攻击入侵检测系统是一种依托网络流量分析，并结合特征检测、沙箱模拟分析、木马回连分析等技术进行关联性分析，以达到识别未知威胁与入侵目的的技术手段。  

该技术具有以下特点：  
1）系统使用旁路部署方式，不影响被检测网络和服务器的正常运行；  
2）使用多种检测技术确保 APT 攻击检测的全面性和准确性；  
3）集成成熟全面的 WebShell 后门访问特征库，深度分析各种返回异常数据行为；  
4）支持综合关联分析，发现各种基于 Web 的未知威胁；  
5）支持邮件社工类攻击行为检测，发现各种利用社会工程学发起的攻击；  
6）支持基于恶意文件发起的攻击行为检测；  
7）通过动态分析技术和综合关联分析技术发现更隐蔽和深层次的攻击行为；  
8）支持木马回连行为检测，完整覆盖特种木马传输、恶意 IP/URL 访问、异常数据传输多个阶段；  
9）攻击路线分析，深度挖掘攻击规律，直观展示攻击路径。  
而检测内容上支持以下流量检测：  
1）Web 攻击行为检测  
（1）对 H T T P 协议完整性检测，发现各种异常访问行为；  
（2）对恶意 URL、恶意 IP 访问行为进行检测；  
（3）全面成熟的 Web 攻击检测特征库，对所有已知Web 漏洞利用的攻击行为检测；  
（4）对利用 Web 发起的 WebShell上传和利用行为进行检测；  
（5）对 Web 传输恶意文件行为检测；  
（6）对 Web 行为进行动态关联分析。  

2）文件攻击行为检测  
（1）对 HTTP、FTP、SMB、SMTP、POP3 协议进行解析，在协议中分离文件；  
（2）对病毒木马进行扫描，快速发现各种已知特征的恶意文件攻击行为；  
（3）采用 ShellCode 静态分析检测机制，有效发现各种隐藏威胁；  
（4）通过沙箱动态行为分析，输出完整的二进制分析报告，全过程解析文件在运行过程中存在的各种隐藏行为。  
3）基于行为的动态分析  
（1）通过访问行为对恶意攻击进行检测；  
（2）由于利用特征攻击会存在大量的探测攻击的误报，这部分没有成功的攻击对我们发现真正的攻击是一个极大的干扰，所以需要进一步进行基于行为的检测。  
4）基于频度的动态分析  

 

（1）通过一段时间对访问频度进行统计，发现其访问频度的异常行为，如暴力破解操作、SQL 注入数据获取（短时间大量请求相同页面）、扫描（长时间遍历网站文件）等；  
（2）基于 URL 异常访问行为的统计；  
（3）通过一段时间的请求分析，对请求 URL 进行统计分析，发现其中的异常，如没有带 referrer 的 URL 进行逆序排列。频繁访问特定页面，并且时间非常集中。  
5）基于攻击路线的关联分析  
（1）通过对多个攻击行为的关联分析，分析攻击之间的关联性，还原真实攻击路线，并以直观的形式展示分析；  
（2）基于海量数据的分析模型，提取多种类型的攻击行为，挖掘攻击规律；  
（3）基于攻击路线的关联分析，可快速识别非持续性的威胁，提取真正的 APT 攻击。  
6）木马回连行为分析  
（1）对内网向外请求异常行为进行分析，包括非法请求外连、恶意盗取数据和敏感数据回传等行为；  
（2）基于恶意行为的模型化分析，提取真正的恶意回连行为。

**2.3.3 个人PC木马病毒防护数据**  

木马程序具有较强的隐蔽性和伪装性，它通常嵌入在一些合法程序（如游戏程序、工具软件）或数据文件（如office 文档、pdf 文档）中，或者木马服务器本身假冒成一个合法程序（如网页中的 Active 控件），如果受害者运行了经过改装或假冒的程序，就会自动激活木马服务器，而普通计算机用户对此通常无法察觉。  
针对这一特性，往往海量的个人 PC 往往更早发现新木马及变种（受到侵害时根据木马回连与入侵结果更容易有效识别），并获得特征。

**2.4 关联性分析**  

有了以上三点态势感知数据源，就可以有效地进行关  
联分析：  
1）某个个人 PC 或 APT 入侵检测发现木马、入侵行为，  
采集木马样本或攻击样本；  
2）将该特征与样本发送至态势感知云端平台；  
3）云端平台发布预警，并通知各地端态势感知节点；  
4）地端感知节点将该威胁发送至地端 APT 检测系统进行入侵检测；  
5） 地端态势感知节点将威胁特征发送给网站监测平  
台，并下发检测任务对重点信息系统网站进行特征检测，  
验证是否受到感染或篡改。

**2.5 APT网络入侵检测技术关键算法分析****  
2.5.1 应用层攻击检测算法**  

1）算法原理  
利用爬虫工具和攻击工具或手工攻击行为生成训练数据集，以会话为单位，对访问请求和服务器应答行为生成日志。采用统计方法，对指定的指标（包括文件及图片的字节数占比、点击次数、返回码 4XX 次数占比、未知来源请求占比、请求深度的标准差、HTTP 连续请求占比等）进行统计。  
在上述日志中增加扩展属性（如访问频率、访问时间间隔、时间、地理位置及时区、返回字节长度、属性字符分布、属性的出现与缺失、属性字符出现频率、路径、调用或访问顺序等），以若干属性作为多维向量的变量，应用分类算法（如贝叶斯、决策树、SVM 等）进行分类。理想的分类结果可以将攻击行为和正常访问行为区分为不同的类别。  
2）预期效果  
找出异常的访问日志，给出攻击者的 IP 地址或 UID，给出攻击类型说明。

**2.5.2 WebShell检测算法**  

1）算法原理  
在 Web 访问日志中，查找符合条件 { User-Agents ：内容简短、版本陈旧；Referrer ：空；URIs ：首次出现；客户端行为特征：只访问某一个 URI 、一天之内同一 User-Agent 使用多个 IP 地址 } 的访问日志，称为访问日志结果集合。  
在 Web 访问日志中，增加扩展属性（如访问频率、访问时间间隔、时间、地理位置及时区、返回字节长度、属性字符分布、属性的出现与缺失、属性字符出现频率、路径、调用或访问顺序等），将若干属性作为多维向量的变量，应用聚类算法，找出属于离散点的日志。  
在主机访问日志中，查找特权用户的操作（如创建用户、重启进程、清除磁盘空间、读取日志等），如果有操作，给出操作时间。  
在堡垒机日志中搜索在上述时间前后的管理员登录记录。  

如果在此时间范围内，没有管理员登录记录，则在访问日志结果集合中，搜索该时间范围内的访问日志，从日志中提取 URI。

以上述提取的 URI 作为算法输出结果。  
2）预期效果  
给出 WebShell 的文件路径及文件名（即认定该文件为WebShell），疑似攻击者的 IP 地址或 UID。

**2.5.3 Web入侵检测算法**  

1）算法原理  
字段抽取和清洗数据：将返回码小于 200 大于 399 的日志以及 URI 字段包含多媒体文件后缀的日志删除。  
用户识别和会话识别：不同的 IP 地址视为不同用户，相同 IP 地址不同的客户端类型视为不同用户，以 30 分钟为会话时长来识别会话。  

学习阶段：使用 Apriori 算法计算属性出现的频率，学习阶段建立正常行为模型，一旦正常行为模型建立好，系统就切换到检测阶段。  
检测阶段 ：从学习阶段切换到检测阶段时，与正常行为进行比较，如果有异常行为则认为是入侵发生。对于parameter list，如果发现禁止的关键词（如 select,insert,update,<script>,exec）则认为是 SQLinjection 和 CSS 攻击。  
2）预期效果  
给出攻击者 IP 地址，给出入侵行为类型。

2）预期效果

**2.5.6 网站数据泄露检测算法**  

1）算法原理  
以会话为单位，对访问请求和服务器应答行为生成日志。在上述日志中增加扩展属性（如访问频率、访问时间间隔、时间、地理位置及时区、返回字节长度、属性字符分布、属性的出现与缺失、属性字符出现频率、路径、调用或访问顺序等），以若干属性作为多维向量的变量，应用分类算法（贝叶斯、决策树、SVM 等）进行分类。  

对日志进行统计分析，以期发现异常。  
对数据库访问日志进行相似性分析，找到异常行为。  
2）预期效果  
异常的返回内容，攻击者的 IP 地址或 UID。
