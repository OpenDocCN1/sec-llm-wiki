# 全球物联网技术暨软件应用趋势分析【鹏越·物联网】

　　近年来由于**网络、智能芯片、传感器、智能终端**技术发展，使物联网(Internet of Thing，IoT)成为产业界瞩目的新兴科技应用。顾名思义，物联网是将各种智慧设备或传感器连上网络并加以利用而产生的新应用机会与商机。

****一、云端运算与物联网技术暨软件的结合****

　　云端的信息运作主要分为**产生、处理、储存和传递四个部分**。产生就如同Youtube提供影片服务;处理则是由于现今云端技术的发展，所有流程都强调要智能运作;储存是大数据时代下的必须;传递是物联网(Internet of Thing，IoT)概念的延伸。物联网跟云端的关系密不可分，有了云端技术的支持，才能达到物联网中万物皆可联网的愿景。

　　物联网是云端架构下的一项应用，云端是躯干，物联网则是四肢，两者相互辅助，不应该分开来谈。物联网结合云端可以达成远程控制的功能，达成监控的目的，同时也可以达到能源管理;电扇若结合物联网芯片，则可以用App控制开关及转速等;图书馆数字化也要借助物联网和云端的帮助。

****二、物联网相关技术暨软件****

　　观察全球物联网相关技术发展趋势，可以发现整个物联网的平台市场是又热又挤，物联网平台已成为许多厂商进军物联网市场常用的一种商业模式，不管大型科技公司，或者是传统产业，都开始利用自建物联网平台的方式，来提供企业从端点到端点之间的物联网解决方案，为了抢占标准制定话语权，各国际大厂如Amazon、Microsoft均推出功能完整的物联网平台，根据物联网的研究机构调查，目前市面上各种物联网平台已经超过400个，其中有超过200家是新创公司，有25家是大型跨国企业。

　　此外，Amazon、Microsoft、IBM及Google等四大云端服务端服务大厂为应对物联网时代的来临，进而满足各种新兴需求莫不积极扩大其生态系，竞争也相对白热化，相继推出物联网、区块链等平台服务抢攻新兴应用市场。

　　另一方面，为了让物联网世界中的装置更加智能化，**机器学习将是需善加利用的关键技术**，近来国际各大厂也纷纷将其机器学习平台开放，提供开放原始码，借此来吸引用户与进一步优化其系统，例如：Amazon Machine Learning(DSSTNE)、Google NEXT Cloud Platform(TensorFlow)、IBM Watson Analytics(IBM SystemML)、Microsoft Azure Machine Learning(CNTK-Computational Network Toolkit)等。

　　物联网应用需要将信息实时传递至云端，将来将造成数据量大增，网络带宽呈现吃紧态势，借助将运算需求分层次、分区域处理，可化解可能出现的网络塞车与传输延迟现象。**雾运算****技术采用分布式的运算方式，将运算、通讯、控制和储存资源与服务，分布给使用者或靠近用户的设备与系统。**可以说，雾运算扩大了云端运算的网络运算模式，将网络运算从网络中心扩展到了网络边缘，从而更加广泛地应用于各种服务，是云端运算概念的延伸。

　　物联网在概念上可分成**四层架构，由底层至上层分别为“感知设备层”、“网络连接层”、“平台工具层”与“应用服务层”**。

感知设备层(此部分的实现在于利用各项物联网终端装置，其软件主要范围用于支持与维系物联网终端装置运作)、网络连接层(旨在提供物联网装置间或与装置与运算平台间的介接功能，软件主要范围涵盖传输功能、互动机制与接口完善等实现)、平台工具层(平台工具层软件主要范围涵盖在提供数据处理以及运算能力，诸如各式云端平台、计算平台与数据分析平台等)、应用服务层(在不考虑个别垂直应用系统下，范围以涵盖整体的管理系统为主，例如虚拟/增强现实、能源管理、服务导向应用等系统服务)。由于这四层各司其职，同时又环环相扣。感知设备层用来识别、感测与控制末端物体的各种状态，透过感测网络将信息搜集并传递至网络连接层，网络连接层可将将感测信息传递至平台工具层进行进一步的运算、分析和管理，应用服务层则是结合各种数据分析技术，以及子系统重新整合，提供具体的服务项目来满足不同的功能需求。此外，信息安全相关技术涵盖与遍及在物联网架构下之四个层面。

****三、发展核心仍在软件开发与应用服务之扩散****

　　产业普遍的共识，认为在物联网应用愈普及与复杂后，**平台、分析、应用、服务等软件与服务，在物联网的角色将愈重要****，包括与信息安全相关的软件或服务等**。其衍生的商机将逐渐超过智慧设备或服务器、储存设备等硬件或基础设施。因此许多设备与芯片大厂，如Siemens、GE、ARM等，纷纷发展软件或云端服务以抢占物联网软件与服务商机。

　　从应用需求方来看，企业也积极看待物联网能协助企业发展新的服务。据观察，企业普遍期待物联网能带来的新型服务包括**远程诊断服务、预测维修服务、产品即服务、软件更新服务等**。显示企业期待物联网应用可不仅改善内部的营运效率，更能积极地为客户提供加值服务。

　　因此，许多设备或软件服务厂商均积极发展云端平台服务，并提供异质设备、网络及数据整合、分析、应用，协助企业利用物联网服务平台来服务其客户或企业内部。这种提供物联网设备管理的平台，**可归纳为“物联网服务平台”或“M2M(Machine to Machine)平台”**。其中“物联网服务平台”着重在企业物联网信息搜集与分析、“M2M平台”则着重在联网产品间的链接、沟通与协同。

****四、物联网之垂直领域应用趋势****

　　观察全球物联网之垂直领域应用别之市场商机最大之前六名，分别为制造、医疗、能源与公共事业、商务、交通、家庭。而未来物联网技术结合发展之最具潜力企业应用领域，将成为未来智能家居、智能企业、智慧城市等衍伸出的商机。
