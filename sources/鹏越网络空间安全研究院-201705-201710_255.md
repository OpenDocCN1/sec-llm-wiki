# Ruff 推工业物联网应用产品「设备宝」，想加速工厂智能化转型【鹏越·行业动态】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMTQyOTc2OQ==&mid=2247490761&idx=3&sn=34cae953284560c35f0c58042a10176b&chksm=e83db5afdf4a3cb9ec6dd811ad217daa3e2be39abb89f032b7c44ed6092504bdbb8224b01c8a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyMTQyOTc2OQ==&mid=2247490761&idx=3&sn=34cae953284560c35f0c58042a10176b&chksm=e83db5afdf4a3cb9ec6dd811ad217daa3e2be39abb89f032b7c44ed6092504bdbb8224b01c8a&scene=27#wechat_redirect)

工厂管理者希望实现生产透明化，包括每一个产品的生产进度、工人工作状态、设备运行效率等。而目前工厂更像一个“黑箱”，具体来说存在以下问题：首先，产成品库存堆压，半成品环节库存不明，数据的统计仍依赖人工完成，结果不准确，影响生产计件；其次，意外停机影响生产效率，导致设备维修成本高。传统工厂设备故障排查依赖人工巡检，只有约 30% 的设备在故障前被发现；最后，工厂无法实时了解设备运行状态，进而影响设备综合效率。

与此同时，业内数据显示，到 2020 年，将有 300 亿设备接入物联网，2025 年，物联网在工业生产中创造的产值将达 11.1 万亿美元。

  

Ruff 成立于 2014 年 10 月，目前推出了两款产品，一款是支持 Java 开发应用的 Ruff 物联网操作系统，另一款是针对工业领域的物联网应用产品 Ruff Plant Insight（设备宝）。前者主要为软件开发者提供物联网应用开发平台，平台上拥有近万名开发者，开发者可以通过 Ruff 将应用部署到终端用户的系统内。

  

而基于工厂的生产痛点，Ruff 在今年 3 月推出物联网应用产品“设备宝”，主要想解决工厂产量自动化统计、设备故障提前预警和设备效率智能化分析等问题。设备宝目前服务客户数十家，覆盖人造板、汽车制造、光伏能源等产业。

![](../Images/1bdc4c722038af1b6a047b5a5087450d.png)

具体操作流程为，设备宝对工厂的设备进行统一接入，已经具备 PLC 设备数据将通过 Ruff 智能工业网关进行数据采集和传输。该网关名为 Ruff Connector，支持西门子、三菱等主流 PLC，同时提供二次开发接口，用户可以使用 Java 对硬件设备进行二次开发。网关收集数据后，会通过 Wi-Fi、4G 和 GPRS 信号把数据传输到云端，随后进行 OEE （设备综合效率）损失分析等，工厂工作人员可以通过运维宝 app 进行查看。

  

Ruff 团队认为，传统物联网解决方案应用到工厂生产中，通常需要较长的周期和更高的成本，设备宝的目标用户群为中小型工厂，安装试用周期约为一周，客单价在数万元左右。

  

Ruff CMO 荆天为也透露了目前公司的融资情况：Ruff 于 2014 年 9 月获得了极客邦基金的天使轮融资，2015 年 2 月获景林资产的 Pre-A 轮融资，2016 年 5 月获山行资本、戈壁资本提供的 A 轮融资，现阶段正在进行 B 轮融资。

  

团队方面，Ruff 的 CEO Roy Li 是一名连续创业者，此前曾任 Nokia 技术总监；CTO 郑晔为 QCon、MDCC 等出品人，曾任 ThoughWorks 首席咨询师；首席架构师周爱民此前为支付宝、豌豆荚和盛大首席架构师，Qomo 开源项目发起者，技术研发人员占比约 70%。
