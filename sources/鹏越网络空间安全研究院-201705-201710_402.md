# 李开复看好人工智能：不接受“AI+概念”的公司将被颠覆【鹏越·精选】

人工智能时代已来临！

  

2月17日，创新工场董事长兼首席执行官李开复在中泰证券资本市场年会上发表了演讲。他表示，未来看好这些领域：人工智能、文化娱乐、在线教育、B2B以及消费升级。  
  

![](../Images/a10058fe33c38ab4c29d03e29d4a8e46.png)

在未来科技投资趋势中，李开复表示，人工智能有特别大的机会。

 

李开复指出，互联网的革命才刚刚开始，它将改变的是彻底改造所有人类的习惯和行业。未来改造会是一个非常彻底的、非常血腥的。那些不能接受互联网+、AI+概念的公司，他们就会被颠覆。

  

**未来的机会主要掌握在懂得互联网和数据威力的公司**，它们会来颠覆传统公司。

 

他提到，**互联网的红利已经结束了**。“所谓的互联网用户红利，纯粹靠炒用户、烧钱、买用户、增加流量，这个模式已经不太行了。当整个互联网市场在爆发式成长的时候，你可以先烧出用户来，再想怎么挣钱，但是这个方法已经行不通了。”他说。

 

对于人工智能，他认为，“**能够取代基本人类所有需要低于5秒的工作，它都可以取代**。”比如，识别人脸，识别语音，或识别手写的字，在这些方面，机器会全面的超过人类。

 

他提及，“**哪些领域不需要七情六欲的机器人，这个就是有戏的。比如说扫地机器人，比如说工业机器人，比如说老人陪伴**。”李开复认为，**无人驾驶也是有机会的**。

 

他表示，并不是说人工智能会取代人类的工作，而是“**用更低的成本给人类创造了更高的价值**。”

 

人工智能取代了这些人类以后，人会被推向去做更有意义的工作，也会释放更多的时间，追随我们想做的事情，这对人类肯定是一个好的事情。

>  
> 
> 还有什么改变呢，停车场没有了，你们要投停车场可以注意了。这些改变的是整个行业，绝对不是说造车而已，这只是一个领域。未来你可以想象，工业机器人、家庭机器人、陪聊机器人，机器人有越来越多其它的方向，这些都是特别巨大的改变。今天时间有限，就谈这几个领域。你可以想象无人驾驶只是一个领域，十年以后回顾十年前的今天，会突然发现你的整个生活方式都改变了。   
> 
>  
> 
> 创新工场在这方面投了很多公司，比较著名的几个，我挑几个例子，刚才谈得“face++”，人脸识别的公司。比如说“小鱼在家”，一个机器人的公司。比如说我们投的银行软件公司，“用钱宝”是AI小额贷款的公司。我们在美国还投了很多神奇的公司，帮助老人站起来的公司，这些对人类都是非常正面的改变。还有Robbyraby（音），无人驾驶很危险，怕撞到人。这个不是无人驾驶，美国有人行道，走人行道，从店里把货送到家里，送货机器人。在人行道上走得那么慢，不会撞到人，这些东西都是一步一步来。
> 
>  
> 
> 还有我们投的无人驾驶公司，驭势玉石科技（音），他们就在研究在哪些领域没有人身危险的问题可以先进入的。比如说景区的车，或者在路上行驶的，每天晚上出来的清洁车、垃圾车，走得很慢，半夜路上没有人。而且它那么一个庞然大物，没有人会撞上去，我们会寻找现在领域里有哪些可以使用的。
> 
>  
> 
> **第二个领域，文化娱乐。**
> 
>  
> 
> 因为大家都在上网，所以文化娱乐被彻底的颠覆。看电视的人越来越少，我们认为什么文化领域会被最快的颠覆呢？第一个，优质的头部内容。这一部是可以挣很多钱，因为它经过口碑传播，打造品牌，真的改变各种可能的方式。我们投的最有名的就是《奇葩说》，可能在座很多都看。还有很多类似其它头部内容，比如说《让我们相爱吧》，这些都是创新工场作为科技公司，看到科技颠覆娱乐所投资的一些优质顶尖的头部内容。
> 
>  
> 
> 第二种，小朋友喜欢看的。因为未来的内容趋势是被95后，甚至00后所引导。他们才是出生在移动互联网时代的人，他们所看的东西会倒过来教我们应该用什么。如果我回头看自己，我用facebook是孩子教我的，我用Youtube是孩子教我的，在座各位可能都是这样。因此未来孩子喜欢的东西，一定是会引领整个时代的。包括我们投资的SNH48，暴走爆走漫画，文火传媒，这些都是一些很好的例子，孩子喜欢的来引领大人。
> 
>  
> 
> 而且随着这些优质内容的发展，它就有可能成为一个平台。一个优质的头部产品成为一个平台，来搭更多其它的产品。最典型的，我们投资了一个成功的优质的内容产品，就是知乎，相信很多在座的都用这个产品，现在甚至超越微博成为业内一些专业知识，甚至有趣八卦的分享平台，大家都上知乎，不太上微博了。一定程度，微博已经成为95后的内容平台，当然也是非常有价值的。知乎对对标微博，成为下一个有价值的内容平台。
> 
>  
> 
> **下一个领域，在线教育。**
> 
>  
> 
> 国内的教育虽然这十年进步很多，但还是有很多问题，家长望子成龙，望女成凤，看到已有教育的不足，想要推动。但是改变已有的教育体制是最困难的，这些家长为了唯一的孩子是愿意花钱的，同时技术也在升级。十年前没有足够快的带宽和无所不在的移动平台，教育是不太能用到技术的。但是今天有四个很大的趋势在发生，第一个，教育的获客可以用互联网来做的。教育里每一个获客成本是非常高的，但是每一个获客的终生价值是非常高的。现在可以用互联网获客了，这是一个特别大的利好。如果你是一个教育机构用互联网获客，利润就会更高。
> 
>  
> 
> 第二，空间距离不是问题。大家愿意在网上上课了，因为视频会议的质量够高了。所以很多不可能授课的机会就成为机会了，比如我们投资的VIPKIDVIP kay（音），就可以让美国的老师来教育中国的孩子。中国要学英语的孩子是无限大的，而中国的优质英语教师是不够多的，只有2万名外教在中国，如何服务上亿的孩子们。如果每个孩子要有一对一的外教，必须走向美国。而美国哪一个知识分子的收入是最低的，就是老师。这些对上了，他们爱上了VIPKID kye的，这一年就会有几十亿，甚至名明后年上百亿的收入，这只是一个给4-12岁孩子学英语的平台。
> 
>  
> 
> 第三个重点，在网上更有趣味性，强交互。所以那些优质的老师，有趣的老师可以让孩子快乐的学习，而不只是痛苦的学习。
> 
>  
> 
> 最后一点，用了人工智能的技术以后，网上的教学，比如我们投的“学吧学霸课堂”，可以用AI判断每一个学生需要学习什么，推一些产品给你。我们也知道你什么没有学好，如何让你加强。我们也知道你学习的过程中有没有专心，因为它整个录像都是全程监控的，学生的态度，他的满意度不需要问卷了，我们马上就知道。用这种个性化老师随时知道学生的需求，来增加个性化、针对性的教学，又是一个特别大的帮助。
> 
>  
> 
> 比如我们和朗朗一起投资的The  ONE，现在是中国卖得最多的乐器。我们投的“盒子鱼”是最好的高中教学的产品，回家复习的产品。我们投资的“七天网络”，帮助老师更快的阅读考卷，这些都是互联网教育的一些布局。
> 
>  
> 
> **再下一个机会，有关B2B，还有企业级的交易**，我们都看到了。比如说“找钢网”是一个例子，还投了其它的公司。还有什么公司是撮合促合交易的，我们投的“买好车”是一个新车的交易平台，它们的交易不是对用户的交易，“买好车”会把当地非4S汽车经销商，连接上了所有可以进口的每一辆车。而且这些交易不是说降低交易成本，而是找到你找不到的东西。可能你就想买那么一台进口车，在国内马自达吗斯塔不卖的车，也不贵，但就是买不到。当你买这台马自达吗斯塔的时候，可能愿意多花3万块钱去买。它促成了交易，而且可以得到非常好的利润，这三个公司都是有非常大的潜在盈利空间。
> 
>  
> 
> **再下面**，我想谈一下消费升级。
> 
>  
> 
> 随着中国人富起来了，这批人的消费习惯是会改变的。改变了之后，过去的销售模式可能是不合适的。比如说电商是一种模式，过去的电商就是上淘宝买到更便宜的用品。现在的用户愿意多花一点钱，用更好、更快、更美的模式，让他满足一些小资心态，得到一些享受，让你挣到利润。我们这里考虑的是房产销冠卡考，还有互联网卖车。我们投的“点我吧”“淘汰狼”，让大家在家里享用一些过去不能享用的美食，比如火锅。“多彩世家”，帮助大家装修一下自己的家，但是又不花过分的钱，更不会被坑。我们投的一些“名堂”，是把时尚带到线下和线上，给你一个新的体验，让设计师也能够上网去做销售。
> 
>  
> 
> 新的品牌打造，有些是新的渠道，新的模式，新的传播模式，整个消费升级会带来特别大的机会，这个不一定完全是互联网的机会，可能是线上线下的结合，在座这方面会有更多的语言和机会。在这样的环境之下，创新工场做了什么事情呢，我们决定募资的时候，就要募一大笔资，因为我们认为未来风口很多。募资的时候，美金要募得多，人民币要更多，因为创业者大部分想要在二级市场上市。我们看到那些做高科技、长周期的想要美金，其它的几乎都要人民币，这个未来对在座每一位都是利好。不止是我们，每一个VC都看到这一点。过去两三年投资的，再过两三年，就可以你们考虑的待上市和并购的标的。 接下来我们再分享一两个投资的标的，我们投资的“用钱宝”是2015年7月上线的，到今天上线还不到一年半，但是它做小额贷款，上个月放贷是120万笔，基本已经超过了银行的规模。单月放贷18亿，月到月是百分之好几十的成长，你可以推算一下这样的公司已经完全是一个上市公司的规模。但因为它不用人，只用机器来做判断，所以放贷的速度。假如说有无限的需求，它一个月放1千万笔，或者1亿笔是可以做的。而一个银行，或者一个靠人的机构是做不到的。我不是完全正确，虽然放贷不需要人，催债还是需要人的。这一点不多说了，你们都懂得。
> 
>  
> 
> 第二个公司，“face++”。刚才谈到的，随时可以识别50万人，然后现在单月云服务已经到了4千万次，而且这也是月到月的快速成长。这个公司仅仅靠人脸和人的识别，就可以成为一个上市公司。它作为一个最顶尖的科学家创业平台，拥有2015年世界视觉识别冠军，是他的首席科学家，绝对不仅仅是人脸。还能做什么呢，可以从他的投资人，阿里巴巴、富士康中很容易的想到。做物流，做工厂，还有可以做配送，这些东西都是有大量的机器人，可以想象想像“face++”的空间有多大。
> 
>  
> 
> 销冠科技，这个公司是一家传统的公司。它考虑的一点，网上可以卖房，传统的分割，新房和旧房销售的分割不用网络，而且垄断性的这种作风不是最好的办法。有没有办法让所有的经销人都可以经过我来帮助一个房子的销售，从中分成。这样的一个概念，很多新楼基本把所有的销售都包给了销冠。这个公司也不是很久，大概三年多。单月销售已经超过了100亿，这也是一个上市规模的公司，也就是这几年出来的。
> 
>  
> 
> 刚才讲到的“摩魔贝”，混合化合物，这样的东西好像很复杂，才需要网上的交易平台。如何描述一个混合化合物，很难描述，有各种公式，它提供了这方面的服务。做B2B怎么挣钱呢，靠金融。最终“买好车”，“摩魔贝”，都是靠金融的产品，经过金融的产品让它有月收入20亿的流水。然后经过金融的产品产生相当好的价值，这也是一个上市的公司。
> 
>  
> 
> 创新工场除了这些服务之外，我们吸引创业者有一些特殊的方法。我们有相当强的硅谷链接，刚才讲的很多趋势都是跟硅谷学的，有些是自己研究出来的，刚才讲的送货的机器人就是美国的项目。第二，我们有非常强大的服务生态链，对投资的公司，要帮助他们在法务、财务、市场推广，发现社交媒体都是在推我们的产品，当然是对粉丝有用的产品。除此之外，我们也认为投资的公司非常需要和二级市场的对接，所以这一次来也是很希望能够交到更多的朋友。我们自己会发挥各种影响力，帮助投的公司，让他们尽快走向上市之路。
> 
>  
> 
> **最后还想讲的一点**，我们最近挂了新三板，正在做一个人工智能的工程院。这个工程院本身就是要打造一个AI的公司，因为我们认为中国现在有三个最大的AI公司，叫做BAT。但是这三个公司是不分享的，他们做的一切都自己拥有的。我们认为还是需要有一个公司，它能够获取大量的数据，用分享的心态让一个AI的创业公司能够有技术支持，能够有数据支持，然后能够有大量的机器，能够让它做好AI。
> 
>  
> 
> 刚才谈得这几个公司，包括知乎、用钱宝，都是和工程院在一起做这件事情。我们认为工程院第一步当然是帮互联网公司，因为他们最懂人工智能能产生什么价值。再下一步，还是要帮各个传统的公司。对未来，我们是非常的看好，认为会有各种我们投的，从文化传媒到人工智能，各种公司都需要和二级市场对接，需要你们的关注，需要你们的投资，需要你们的对接。在这里，我特别重视这次会议，也希望和你们交个朋友。
