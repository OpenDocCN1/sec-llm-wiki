**亚马逊机器学习服务**

亚马逊机器学习提供了高度自动化功能，可提供可视化辅助功能和易于访问的分析功能，使开发人员无需学习复杂的机器学习算法和技术即可访问机器学习。它还为企业提供了一个简单的、高度可扩展的解释数据。它有助于企业构建机器学习模型，而无需自己创建代码。

  

![](../Images/11d9b3be9d7506e0684c83aae07daf5b.png)

  

亚马逊机器学习可以帮助每天生成数十亿的预测，并以高实时和高吞吐量实现这些预测。根据亚马逊的说法，亚马逊ML基于同样被证明的、高度可扩展的机器学习，该技术被亚马逊用于执行诸如供应链管理、欺诈交易识别和目录组织等关键功能。

**Azure机器学习工作室**

这款机器为初学者和经验丰富的数据科学家学习提供了一系列对于开箱即用算法更灵活的工具。 Azure支持一系列操作系统，如编程语言、框架、数据库和设备。它还提供跨设备体验，支持所有主流移动平台。借助名为Machine Learning Studio的集成开发环境，开发人员还可以通过拖放手势和简单的数据流图来构建数据模型。

![](../Images/015fe72e290c11ad8ffc06667b7310ba.png)

  

因此，它不仅有助于节省大量时间，而且还可以通过ML Studio的样品实验库最小化编码。 Azure ML Studio也有各种各样的算法，为开发人员提供了大约100种方法。微软Azure机器学习工作室中最流行的选项是免费提供的，只需要一个微软帐户。这还包括永不过期的免费访问，它还提供10 GB存储、R和Python支持以及预测性Web服务。

**Google云端机器学习引擎**

  

Google Cloud Machine Learning Engine非常灵活，为用户提供了一种简单的替代方法，可以为任何规模和类型的数据构建机器学习模型。但该平台主要针对深度神经网络任务。您可以注册免费试用以访问谷歌云机器学习。

**IBM的沃森机器学习**

  

Watson Machine Learning运行在IBM的Bluemix上，它可以进行训练和评分。借助训练功能，开发人员可以使用Watson来优化算法，以便从数据集中学习。评分功能有助于使用训练有素的模型预测结果。沃森解决了数据科学家和开发人员的需求。 Watson的笔记本工具可以帮助研究人员更多地了解机器学习算法。根据报告，Watson目的是解决部署、操作化问题，甚至从机器学习模型中获取业务价值问题.

![](../Images/524907b23061c6532da1cb3e34a5c480.png)

  

IBM沃森机器学习的可视化建模工具可帮助用户快速识别模式，获得洞察力并更快做出决策。开源技术可帮助用户继续使用自己的Jupyter笔记本与Python、R和Scala。

**HPE Haven OnDemand**

Haven OnDemand机器学习服务为开发人员提供了用于构建应用程序的服务和API。Haven提供了60多种API，包括人脸检测、语音识别、图像分类、媒体分析物体识别、场景变化检测、语音识别等功能。它还提供了强大的搜索策略功能，可以为开发人员优化搜索结果。在这台机器学习服务的帮助下，组织可以提取、分析和索引多种数据格式，包括电子邮件、音频和视频档案。 

**BigML**

BigML易于使用并具有灵活的部署。它允许从AWS、微软Azure、谷歌存储、谷歌Drive、Dropbox等数据导入。BigML有更多的功能集成到其Web UI中。它还有一个大型的免费数据集模型库。它也有一个有用的聚类算法和可视化。它具有异常检测功能，可帮助检测模式异常，这将帮助您节省时间和金钱。

![](../Images/f3fd290dae62de31b3233a17db32d45f.png)

BigML数据集非常易于重用、编辑、扩展和导出。您可以轻松地为每个字段重新命名和添加描述，并根据采样或自定义过滤器生成子集。

**MLJAR**

MLJAR是一个用于机器学习的“人类第一平台”，可用于测试版本。它为开发、原型设计和部署模式识别算法提供服务。它提供了诸如内置超参数搜索，许多算法的一个界面等功能。开始，用户需要上传数据集，选择输入和目标属性，机器学习服务提供商将找到匹配的ML算法。 MLJAR也基于现收现付定价模式。

**Arimo**

Arimo使用机器学习算法和一个大型计算平台在数秒内收集海量数据。它将自己描述为“针对物联网的行为人工智能”，它从过去的行为中学习、预测期货行为并推动卓越的业务成果。该服务提供商基于深度学习架构，可与时间序列数据配合使用以发现行为模式。

**Domino**![](../Images/49426b93b312bbea508e5d566f7ccf32.png)

Domino是一个支持现代数据分析工作流程的平台。该平台支持Python、R、MATLAB、Perl、Julia、shell脚本等语言。Domino也是数据科学家、数据科学经理、IT领导者和高管的平台。这种机器学习服务可以在现场或在云中实施。开发人员可以使用现有的工具和语言进行开发、部署和协作。它还简化了知识管理，使所有项目都能存储、可搜索和保存。

**Dataiku数据科学工作室**

它是数据科学家、数据分析师和工程师的协作数据科学平台，可以更有效地探索、原型、构建和交付自己的数据产品。该平台支持R、Phyton、Scala、Hive、Pig、Spark等。它在数据流原型制作过程的任何步骤都使用可定制的拖放式可视化界面。该平台在可视化用户界面中提供了Scikit-Learn、MLlibXgboost、H2O等机器学习技术。
