# 这么袖珍的电脑你见过吗？它比盐粒还要小很多【鹏越·科技】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMTQyOTc2OQ==&mid=2247493518&idx=3&sn=97f4817688207626f92b525482b0f7a8&chksm=e83e4ee8df49c7fecd57a90ceac265ba44fe4d9f6c0fedc896dec56e3ed1c9558a4ccee75999&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyMTQyOTc2OQ==&mid=2247493518&idx=3&sn=97f4817688207626f92b525482b0f7a8&chksm=e83e4ee8df49c7fecd57a90ceac265ba44fe4d9f6c0fedc896dec56e3ed1c9558a4ccee75999&scene=27#wechat_redirect)

在今年举行的IBM Think 2018大会上，IBM展示了号称是世界上最小的电脑。那它到底有多小呢?你可能需要显微镜才能看清，因为这部电脑比盐粒还要小很多，大概只有一平方毫米大小。而且，这个微型电脑的成本只有10美分。

麻雀虽小，但是五脏俱全。这个小不点可是一个货真价实的电脑，它里面有几十万个晶体管，搭载了SRAM(静态随机存储芯片)芯片和光电探测器。

![](../Images/bf45d5d68021c09afb7ffdac6791b441.png "1")

　　当然，这部电脑并不是常见意义上的个人电脑，其运算能力只有二十多年的X86电脑性能。不过这个微型电脑也不是用于我们常见的用途，而是用在数据的监控、分析和通讯上。实际上，这个微型电脑是用于区块链技术的，可以用作区块链应用的数据源，追踪商品的发货，预防偷窃和欺骗，还可以进行基本的人工智能操作。

　　据IBM介绍，未来五年，这种比盐粒还小的电脑为代表的密码锚定技术将被广泛应用，确保产品从生产源头直到送至顾客手上的整个过程都真实可信。不过，这部微型电脑的正式发布时间还没有确定，目前还处在原型阶段。

![](../Images/00d74109e586f109bd827c6f906bd88e.png "1")

　　可以设想，未来每一件商品都能附带这个几乎看不见的小电脑，让商品从生产到流通到消费的每一个环节都可以尽在掌握，真正实现区块链最实际的应用场景——让假货无处遁形。
