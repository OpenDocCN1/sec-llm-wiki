# 华为云国内首发Windows容器 打破Linux容器一统天下格局【鹏越·行业动态】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMTQyOTc2OQ==&mid=2247493298&idx=4&sn=041fbd7b8392ee25e236826cde9dbe10&chksm=e83e4fd4df49c6c21b3b00828e7e7d181a198452b428868fe5914bb86c19c101b8198a746376&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyMTQyOTc2OQ==&mid=2247493298&idx=4&sn=041fbd7b8392ee25e236826cde9dbe10&chksm=e83e4fd4df49c6c21b3b00828e7e7d181a198452b428868fe5914bb86c19c101b8198a746376&scene=27#wechat_redirect)

**![](../Images/0b5033649d6f42d1e26cf78348884cfd.png)**

近日，华为云·云容器引擎CCE在国内首家发布了基于Windows Server系统的容器服务——Windows容器，这是继此前裸金属容器特性上线后又一重要发布。其意味着在Windows系统下，大量如基于.NET开发的应用可借助CCE的Windows容器能力实现容器部署，帮助其提升云上运行效率，减少资源消耗，尽享容器化带来的便捷，焕发系统第二春。

![](../Images/25163f30a389984dd1a0b753ef034976.png)

**Windows Server海量应用改造空间巨大**  
![](../Images/11fd69bbea3b994bcc0309d49473bc71.png)

根据第三方咨询公司统计，大约有80%以上的企业现有系统仍是通过Windows Server部署运维在服务器上，统计显示Windows Server在x86伺服器中的市占率高达6成。随着云原生技术的迅速发展，对比传统基于windows系统的容器，Linux上日趋成熟的容器技术优势主要体现在以下几个方面 ： 

![](../Images/4467901c8274867b7fc290e9935defaa.png)

![](../Images/5f4074517d7199d4b760f9a2fde5872d.png)

**kubernetes生态正式拥抱Windows Server**![](../Images/11fd69bbea3b994bcc0309d49473bc71.png)

作为容器编排市场的主导者，近期kubernetes新版本发布，其中的一个重要更新就是使kubernetes支持Windows Server的运行，早在一年前的1.5版本中Kubernetes就尝试在测试环境中支持windows server 2016操作系统，如今终于一年后的新版中正式对外开放，这也标志着kubernetes正式打开了支持Windows Server的大门。

**华为云CCE帮助企业windows应用容器化演进**![](../Images/11fd69bbea3b994bcc0309d49473bc71.png)

CCE推出了基于Kubernetes的Windows Server操作系统的容器管理服务，完美兼容Kubernetes能力，支持容器CPU/内存资源编排，无状态/有状态应用模型等能力；可纳管最新的Windows 1709系统（最新Windows支持容器的操作系统），支持启动Windows Native容器，帮助企业轻松实现.NET等Windows应用的容器部署。 

华为云PaaS服务产品部部长廖振钦表示：“企业应用中Windows系占了半壁江山以上，企业对使用Windows容器上云的诉求非常强烈。华为云CCE团队攻克了Windows容器在Kubernetes、容器网络、容器存储等方面的多项技术难题，成功推出了CCE Windows容器服务。我们正与微软研发团队密切合作，持续共同推进Windows容器的发展。”  

云容器引擎CCE - Windows容器的上线，使CCE的服务生态进一步完整，让海量运行在企业现有的Windows Server上的应用无需繁杂改造，即可实现云上容器化部署，立享容器带来的便捷与高效，日前Windows容器已正式在华为云官网发布，欢迎第一时间试用体验。
