# 人脸识别开启数十亿市场，看看国内外都有哪些玩家【鹏越·人工智能】

近日，一段关于“中国天网”的视频刷爆了朋友圈。在视频中，我们可以看到除了识别行人脸部特征以外，“天网”系统还可以连接数据库，按照识别特征进行匹配查找。这样以来，在犯罪分子搜捕、人员失踪查找方面就会发挥巨大作用。

![](../Images/76b8de6a06832fbb304662af565f6a7f.png)

而在之前召开的“杭州·云栖大会”上，人脸识别技术的表现更是亮眼。据了解，该技术不仅被用于大会的后台管理，在大会期间，中邮速递易更是展示了刷脸取件这一黑科技，成功博得全场观众眼球。

从公布的相关视频中可以看到，用户在接到取件通知后，便可前往自提柜进行刷脸取件。对准摄像头，快递柜就能通过红外摄像头进行图像采集，采集靠近红外和可见光两种图像，分析人脸皮肤纹理和微表情的方式进行人脸识别。若是匹配成功，则开启箱门，用户就能取到包裹。

相比以往快递小哥叫你取件，可能还得在一堆包裹里边翻找半天的场景，是不是感觉这种刷脸取件快捷了许多呢？这还不是最重要的，据了解，整个刷脸取件过程响应程度已达毫秒级，并搭载了金融级别防风险模块，有效过滤照片、视频、软件合成、面具等影响人脸识别的因素，从而有效防止他人通过翻拍照片、打印照片等方式盗取用户快递。可以说，通过刷脸取件不仅提高了取件效率，更是极大地降低了邮件的丢失率。

**人脸识别的广泛应用**

事实上，人脸识别技术早已走进大众视野，很多人都坐过飞机，机场安检口查验机票时，安检员会让乘客面对摄像头站立，这个过程就是进行本人面部识别，核实持件人是否是本人。不过，这个面部识别过程需要乘客保持静止。而且对于经常坐飞机的朋友来说，过安检时超长的队伍和漫长的等待实在难受。

为了解决这个问题，迪拜国际机场宣称，将从2018年起陆续使用人脸自动识别技术代替普通的护照检查流程。据介绍，届时从迪拜出发的旅客无需通过出境检查，而是进入一个设置了约80个人脸识别技术摄像头的特殊通道。通道内部还将放映高清水族池画面，游客们只需一路欣赏通道美景，便可以被摄像头纪录下面部特征进行识别。如此一来将更有效地应对客流量增加的问题。

![](../Images/cd2cf19794c44b4b0178457d0eb7cf67.png)

除了在物流取件、安检安防这些领域以外，目前在深圳、济南、海口、上海等城市的交通路口也出现了一种黑科技：闯红灯人脸识别系统。该系统可以对闯红灯的行人抓拍，并在路口大屏幕上曝光，闯红灯的行人一抬头就会看到自己被曝光的闯红灯丑态。

在实际应用时，多数闯红灯的行人会意识到错误，为了不继续被曝光而主动联系交警，接受罚款以求撤掉照片。通过利用“羞耻心”结合“黑科技”的方式，“中国式过马路”的陋习也得到了一定的约束。

**人脸识别市场前景及挑战**

  

相关分析报告显示，全球人脸识别市场规模从2009年的3.90亿美元增长到2016年的26.53亿美元，年均复合增长率达到31.5%，实现了飞速发展。预计未来一段时间人脸识别市场规模将保持20%左右的增速，到2022年，全球人脸识别市场规模将达75.95亿美元。

如此迅猛的增长态势，可谓前景一片良好。但是发展至今，人脸识别技术依然存在一定的缺陷。尤其是采集条件与采集对象两方面，比如，采集环境的光照条件可能影响采集效果。人脸比对时，假如剃了胡子、换了发型、带了眼镜、变了表情都有可能引起比对失败。而且对于双胞胎来说，由于相似特征太多，人脸识别基本不可能完成。

另外，若是处于非配合情况下的人脸图像采集，被监控对象可能会戴着眼镜、帽子等饰物，使得被采集的人脸图像有可能不完整，从而影响了后面的特征提取与识别，甚至会导致人脸检测算法的失效。

同时，随着年龄的变化，面部外观也会变化，特别是对于青少年，这种变化更加明显。因此年龄变化对人脸识别算法的影响也必须得到解决。

但是从发展趋势来看，越来越多科研单位已开始对人脸识别技术进行更深入地研究。与此同时，人工智能等先进技术也将使得人脸识别进一步完善。未来物联网时代，人脸识别也有望成为有效身份识别，商业前景非常广阔。

**国内外人脸识别主要玩家**

  

一直以来，国内外对于人脸识别的研究都非常的活跃。美国、日本、德国等经济发达国家和部分发展中国家都有相关科研单位对此进行研究。小编在这里整理收集了国内外几家比较知名的人脸识别公司，以供各位参考：

国外公司：德国CognitecSystem、西班牙HertaSecurity、日本NEC、美国的Identix、Bioscrypt、Google以及Facebook。

以上几家里面，德国的Cognitec主要从事政府项目的人脸识别系统，西班牙Herta是一家学术氛围很浓厚的公司，而NEC公司主要做机器人视觉识别系统。美国Identix公司则是多模认证(指纹、虹膜)为主体业务，而Bioscrypt公司早期起于指纹识别考勤，后来转战人脸识别领域，在市场上占据了不小份额。

这五家公司都属于比较早期的老牌强者，而Google和Facebook进入人脸识别领域的时间并不算长，但因其本身的雄厚技术实力以及海量数据支持，占据国外主流人脸识别公司的地位也是合情合理。

国内公司：商汤科技、科大讯飞、旷视科技、云从科技。

其中商汤科技可以说是现在国内人脸识别技术领域的龙头企业，曾在一次公开评测中超过了Facebook和Google，由此获得了知名风险投资公司IDG的垂青；科大讯飞最早是从事智能语音及语言技术，在2014年联合香港中文大学汤晓鸥教授团队，共同推出世界领先的人脸识别技术，识别率高达99%；旷视科技目前为阿里巴巴旗下蚂蚁金服提供面部扫描系统，在金融、安防、零售领域分别开始了商业化探索并成功发育出Face++Financial等多款垂直人脸验证解决方案产品；云从科技，成立于2015年4月，是一家从中科院重庆研究院孵化的专注于计算机视觉与人工智能的高科技企业。目前已成为是中国银行业人脸识别第一大供应商。
