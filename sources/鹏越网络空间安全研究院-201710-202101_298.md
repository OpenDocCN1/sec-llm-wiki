# 煤炭行业工控系统信息安全防护关键技术研究【鹏越·工控安全】

**摘 要：** 煤炭行业在走新型工业化发展道路，推进“两化深度融合”过程中，涉及很多新技术、新业务模式的建设和引用，数据共享越来越深入，工控系统越来越开放，而针对工控系统的安全防护措施却严重滞后，导致煤炭行业的工控系统信息安全问题异常突出。本文通过对煤炭行业工控系统面临的信息安全现状及存在的安全风险进行分析，并对煤炭行业自身特殊性及其适用的关键防护技术进行研究，结合 IEC62443、GB/T30976 等工控系统安全通用技术标准，提出切实解决煤炭行业信息安全问题、适用于煤炭行业工控环境的信息安全防护方案。  
**关键词：**煤炭行业工控系统；信息安全；关键技术；安全防护  

0、引言

煤炭行业的自动化生产控制应用、自动化控制系统对煤矿的安全生产运营起到了举足轻重的作用。煤炭企业工控系统作为煤炭企业工业装备和重要基础设施的核心，其自身的安全可靠性尤为重要。目前，煤炭行业越来越多的工控系统与公共网络进行互联，而针对性的安全防护却严重欠缺，导致煤炭行业工控系统遭受计算机病毒、黑客攻击、信息泄密和人为蓄意破坏等外部威胁的可能性与日俱增，相关安全方面的脆弱性也正在逐渐显现，煤炭企业一般的安全管理制度已无法有效保证其工控系统的安全。

1、煤炭行业工控系统现状及风险分析

目前普遍的煤炭企业仍然只关注物理安全，对工控系统安全认识程度仍然不够，普遍缺乏应有的信息安全防护措施及应有的防护约定责任，煤炭行业的工控系统信息安全形势十分严峻。总体上讲煤炭行业工控系统主要面临两大方面安全风险：（1） 具有行业特征的自身安全风险； （2） 新型工业化发展道路中，安全配套措施不足。

**1.1 具有行业特征的自身安全风险**  
（1） 终端自身免疫力不足  
很多煤炭企业生产现场的工业 PC 多是 Windows 操作系统，而且系统、软件，设备等大多比较老旧，长期运行后积累大量漏洞。即使有安装常规病毒防护产品，其基于病毒库查杀的机制在工控领域使用也非常局限，特别是对于零日攻击起不到任何防护作用。  
（2） 工业环网扁平化  
煤炭行业的工控网络是环形工业以太网，所有联网工控设备均通过工业环网互联互通，缺乏关键区域及层次间的有效隔离，一旦感染木马病毒，可以轻易在整个环网肆意扩散。  
（3） 国外品牌工控产品使用较多  
煤炭行业工控领域的操作系统、协议、工控软件、工控终端设备等使用国外产品较多，国内自主知识产权的技术和产品使用较少，加上缺乏适当的安全保障和专业测评工具，可能存在难以预料的安全风险。  
（4） 工控安全意识淡薄  
U 盘等移动存储介质随意使用，设备维修时笔记本电脑随意接入，互联网电脑随意远程接入，对终端、服务器、网络设备故障响应延迟等等，工控安全意识淡薄。  
（5） 安全管理困难  
煤炭企业工控系统属于典型的多系统并存模式，并且包括很多种类，各种系统分而自治，点多面广，非常分散，单纯依靠制度管理手段难以奏效。  
（6） 安全问题应急处置能力弱  
煤炭企业工控系统缺少信息安全评估工作，对现有信息安全问题没有整体把握，现有的防护能力和应急处置能力非常弱。  
**1.2新型工业化发展道路中，安全配套措施不足**  
（1） 工控系统与业务系统日益紧密结合，之间缺乏有效隔离，使其易于受到来自互联网的攻击。  

（2） 随着云计算虚拟化平台的广泛实施应用，工控系统内部的层次和边界越来越不清晰。  
（3） 随着云计算虚拟化技术的广泛应用，云安全问题也逐渐开始暴露。近年来云虚拟化平台的漏洞数量整体均呈上升趋势，云计算的安全风险不容忽视。  

2、煤炭行业工控系统特殊性分析

（1） 工控系统种类繁多  

煤炭行业由于生产工艺及开采环境决定所包含的工控系统类型特殊，种类繁多，地理位置分散，且涵盖地面以及井下，如监测监控系统、瓦斯抽排系统、通风系统、压风系统、皮带系统等几十个与安全、生产、环保相关的重要子系统，安全防护需统筹考虑。  
（2） 非标准的通信协议较多  
煤炭行业的工控系统除了采用国际及国家标准的通信协议外，还存在大量的行业标准协议以及私有协议，例如，基于文本文件的数据交换协议（如： MT1116）、基于工业数据库的数据交换协议、基于 RS232 总线的私有协议等，安全产品选择及配置需针对性考虑。  
（3） 特殊的井下作业环境  
我国大多数煤矿井下环境条件恶劣，如高温、高湿、粉尘及有害气体,水灾、火灾及瓦斯爆炸等, 井下生产多工种、多方位、多系统立体交叉连续作业等，井下系统安全防护需针对性考虑。  
（4） 特殊的政策要求  
国家和行业制定了一系列的章程来规范煤炭行业生产运行，并且国家煤矿安全监察局对煤矿安全监测监控实时数据有联网需求，安全防护要符合相关政策要求。  
（5） 特殊的网络拓扑  
矿井环形工业以太网的安全防护需要作为重点考虑，环网上所有控制系统设备都互联互  
通，病毒蠕虫等在工业环网内可以肆意扩散。  
（6） 无线网络接入需求  
煤炭企业井下部分子系统有无线联网接入需求，如何对无线网络接入设备进行安全认证防护需重点考虑。  

3、煤炭行业工控系统适用性关键防护技术

**3.1 煤炭行业工控系统安全风险评估方法**  

传统信息安全的风险评估标准 GB/T20984 对于煤炭行业工控系统而言并不是完全适用。GB/T20984 中对资产的描述以及资产赋值的方法并不能满足煤炭行业工控系统评估需求，GB/T20984 中推荐的风险测试工具，并不能照搬运用于煤炭行业工控系统。  

煤炭行业的工控系统安全评估可以以 GB/T20984 为参考，要紧密结合 GB/T30976.1，利用原有信息安全研究成果，以实际工控系统特殊性及应用环境为基础，建立煤炭行业工控系统风险评估模型和指标体系。  
（1） 建立风险评估模型  
首先，对煤炭行业工控系统进行关键资产识别，确定要评估的目标范围和对象，范围确定时需重点考虑，风险评估应贯穿于工业控制系统规划、设计、实施、运行维护、废弃全生命周期的各个阶段。然后，根据 AHP(层次分析法)建立煤炭行业安全评估树状层次模型，以煤炭行业特殊性研究为基础，结合安全评估技术方法进行细化，最终构建煤炭行业安全评估体系及实施细则。  
（2） 选择风险评估方法  
煤炭行业工控系统安全评估可以选择定性和定量风险评估与详细风险评估想结合的方式，具体的技术方法可以采取分析法、比较法、采用试验法等技术手段，其中采用试验法可以在模拟实验室中进行，或者在备用网络、非关键生产环境、非生产周期内进行。风险测试要选择目前技术相对成熟的工控系统专用评估工具及漏洞挖掘测试工具，切忌在工控网络中盲目使用传统的渗透测试工具，以防止损害工控系统的正常运行。  
**3.2煤炭行业工控系统各层次关键防护技术**  
煤炭行业工控系统各层次关键防护技术研究主要以煤炭行业工控网络、工业环境、系统类型、技术要求等的特殊性为基础，是整个煤炭行业工控系统信息安全技术研究的重要组成。  
（1） 白名单快速过滤机制  
传统的黑名单机制并不适用于工控系统运行防护。煤炭行业工控网络有着专有的通信协议和通信机制，对网络实时性要求高。基于该特点，研究适用于煤炭行业工控系统防护的白名单快速过滤机制。通过提前设定好的白名单规则来限制网络数据的交换，在数据交换过程中进行动态行为判断，通过对约定协议的特征分析和限制，从根源上节制未知恶意程序的运行和传播。为了尽量降低对原有工业系统造成的影响，数据延迟是该技术的重要性能指标。白名单快速过滤机制原理如图 1 所示。

（2） 区域隔离交换技术  
根据煤炭行业环形工业以太网互联互通，工控系统种类多、地理位置分散等特点，研究以“工控系统类型+重要性+物理位置分布”作为功能组划分依据，识别关键功能组，确定安全边界及区域管理策略，并根据业务与通信类型确定分区间的通信管控、网络隔离技术。  
（3） 通信协议安全分析与深度解析技术  
①协议安全性分析  
煤炭行业的传输协议基本都是明文传输，并且非标准通信协议较多，首先要验证工控系统现有协议在遭受攻击情况下的安全性和可靠性。可以借助工具进行模糊性的攻击性测试，发现被测协议中可能存在的安全漏洞，测试必须在离线环境进行。  
②协议深度解析技术  
以研究通信规约的一致性、工控协议的内容深度检查为基础，结合行为识别及异常检测技术，确定相应的安全策略。

例如，针对 OPC协议采用不固定动态端口通信的特点，研究 OPC通信端口的动态追踪技术，随时只开放OPC动态端口，并使用通信协议内容识别技术进行深度解析，设定 OPC深度白名单及OPC 只读控制。针对 MTT1116数据交换协议，通过抓包深度解析，生成协议白名单，利用已知 SMB协议漏洞库结合行为识别及异常检测进行动态检测。  
针对控制协议，例如 Modbus 通讯协议，通过 Modbus 功能码、 Modbus 线圈/寄存器、Modbus读写值域内容的深度识别进行特征行为分析，并配合 IP 地址、端口、传输层协议限制等进行综合防护。  
（4） 终端防护技术  
针对煤炭行业现场终端自身免疫力不足的特点，首先对现场终端进行完整性以及关键配置确定，然后建立可信基线， 并结合异常检测技术、外置设备的使用管控等，设计综合防御模型。  
（5） 工控漏洞检测技术  
工控漏洞检测技术包括已知漏洞检测和未知漏洞检测。已知漏洞检测要不断积累已知漏洞库。未知漏洞检测要监测测试目标、选择对应协议和测试用例，向被测设备发送各种变异报文，最终通过变异输入来观察被测目标的非正常反应，发现可能的未知漏洞。  
（6） 云计算虚拟化平台安全防范技术  
虚拟化技术当前主要表现出来的安全问题包括虚拟机逃逸、虚拟机跳跃、远程管理缺陷、拒绝服务攻击、虚拟机迁移安全问题等。针对这些问题，结合信息安全技术研究成果，利用动态身份验证技术、 SQL 注入技术、漏洞检测技术、监测审计技术，并结合管理手段，制定私有云的安全防护及改进方法。

4、煤炭行业工控系统信息安全关键防护方案

**4.1 开发基于国产核心技术的安全防护产品**  

煤炭行业使用的网络设备及工控设备大多属于国外产品，存在核心技术受制于人带来的安全隐患。煤炭行业工控系统的防护趋势是建立及使用自主知识产权的高效安全防护产品。产品研发应着重考虑工业环境、协议的适应性，基于自主可控的安全体系，进行软硬件平台、安全防护装置、安全测评工具和安全管理软件等方面的技术研究和产品研发。  

 

![](../Images/8c972afde694a9e70d6004139784ad01.png)

**4.2 安全措施部署前，创建纯净安全环境**  
基于白名单策略的安全产品的防护效果，跟白名单创建质量紧密相关。白名单产品理想的部署模式是新系统规划时安全产品同步建设，但是煤炭行业大多属于长期建设运行的工控系统，部署白名单策略安全防护产品前，必须进行安全风险评估及采取措施尽可能创建相对纯净的安全环境。创建安全环境的主要解决方法是利用白名单和黑名单相结合的方法，被动进行流量检测，及时发现工控网络内已经存在的病毒、木马等异常问题，记录特征并进行处理。  
**4.3把握煤炭行业工控网络特点，自定义适用安全规则**  
自定义安全规则是煤炭行业工控系统与其他一般系统防护的显著区别之处。自定义规则配置的好坏，直接影响产品部署实际防护效果。煤炭行业工控系统防护的质量与效果，与对煤炭行业工控系统运行的把握程度息息相关。因此，自定义安全规则最有效的模式是由既懂信息安全，又懂实际工控系统运行的专业团队制定。  
**4.4典型煤矿企业工控系统信息安全防护架构**  
以典型的井上井下双环网络结构煤矿为例，以 IEC62443推荐的安全模型以及 SP800-82提出的纵深防御理念为指导，结合煤炭行业工控网络、业务类型、技术要求的特殊性，设计煤炭行业工控系统安全防护基本架构如图 3 所示。整体设计思路为： 

（1） 外层边界隔离； 

（2） 内部安全域划分与边界隔离管控； 

（3） 终端防护； 

（4） 安全审计。  

5、结语

本文在充分了解煤炭行业网络结构和安全现状的基础上，结合煤炭行业自身特点，对其工控系统的信息安全关键技术进行了深入研究，并对煤炭行业工控系统关键防护方案进行了探讨分析。但是，随着工业自动化技术、信息技术的不断发展，会对煤炭行业工控系统信息安全提出更高的挑战，其信息安全技术也需要持续改进和优化，煤炭行业的工控系统信息安全任重道远.
