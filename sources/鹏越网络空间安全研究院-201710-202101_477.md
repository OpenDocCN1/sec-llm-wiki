# 流线感十足！全新四轮驱动的安保机器人K7亮相【鹏越·科技】

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIyMTQyOTc2OQ==&mid=2247491914&idx=2&sn=f9fab1b46c08efed1cb5e334f9377f42&chksm=e83e482cdf49c13a01df27dc809595b2a870f520774b1dde8536c0aa7b21753c6974b82414b7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzIyMTQyOTc2OQ==&mid=2247491914&idx=2&sn=f9fab1b46c08efed1cb5e334f9377f42&chksm=e83e482cdf49c13a01df27dc809595b2a870f520774b1dde8536c0aa7b21753c6974b82414b7&scene=27#wechat_redirect)

**![](../Images/493b233a9486c0593ba8bd27cccb4fbb.png)**

越来越多的智能机器人应景融入到了我们的日常生活中。据外媒报道，知名安保机器人公司Knightscope本周在加利福尼亚推出了一款全新四轮造型的安保机器人K7 ，以响应用户对能够覆盖更大区域和更大的传感器有效载荷的机器人的要求。与今年早些时候意外掉进喷泉池的K5安保机器人不同的是，K7更像是一辆自动驾驶汽车。

![](../Images/09aeb776114caf4b2e3368770373ca8c.png)

与普通安保机器人适用于光滑地面不同的是， K7能够应对更加复杂的地形。它也相当灵活。通过向内旋转四个轮子，它可以从一侧向另一侧枢转。像K5一样，K7的主要目的是监控和监视，而不是追逐坏人。K7将以3英里/小时的速度前进。((即使它确实追上了一个缓慢前行的罪犯，也没有办法拘留他们。)到目前为止，K5已经在全球范围内的各种任务部署中一共运作了超过18万小时。

![](../Images/7e7a81ef0908e70511e2b6e37d42e966.png)

另外Knightscope还推出了全新的固定式K1机器人，其专为像医院，机场，学校等提供服务，能够发现枪支和其他金属物体。该公司表示，它还具有升级传感器以寻找化学武器的能力。

![](../Images/5e25872929e9cf6d867a9874fdd23dcc.png)

Knightscope表示，K7将在2018年初进入测试阶段，而K1也将在2018年开始部署。

(来源:环球科技)
