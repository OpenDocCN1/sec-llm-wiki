其中校验码的规则如下：

  

作为尾号的校验码，是由号码编制单位按统一的公式计算出来的，如果某人的尾号是0-9，都不会出现X，但如果尾号是10，那么就得用X来代替，因为如果用10做尾号，那么此人的身份证就变成了19位，而19位的号码违反了国家标准，并且中国的计算机应用系统也不承认19位的身份证号码。Ⅹ是罗马数字的10，用X来代替10，可以保证公民的身份证符合国家标准。

  

这里给大家介绍一种强大的python库用于实现以上校验功能:id\_validator

我们可以直接利用这个库实现以上的校验功能，筛选出符号要求的身份信息，但是也只是能筛选出90%左右，剩下的我们可以利用BP写个字典进行校验，这里因为法律法规要求，俗说君就不给大家演示了╮（﹀\_﹀）╭

import timefrom id_validator import validator
def dateRange(year):    fmt='%Y-%m-%d'    bgn=int(time.mktime(time.strptime(year+'-01-01',fmt)))    end=int(time.mktime(time.strptime(year+'-12-31',fmt)))    date=[time.strftime(fmt,time.localtime(i)) for i in range(bgn,end+1,3600*24)]    return[i.replace('-','') for i in date]
def vali_dator(id1,id2,id3):    for i in dateRange(id2):        theid = id1 + i + id3        if validator.is_valid(theid):            print(theid)
vali_dator('350324','2018','1725')#此处身份信息仅是俗说君编的，并不是实际信息
