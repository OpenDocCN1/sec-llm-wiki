好了下面到了今天的主角，event，在pygame中例如鼠标操作，键盘输入等都会被记为一个叫做事件消息。

所有的事件有都会被写入事件队列，然后利用for语句迭代执行。

利用pygame编写游戏的时候通常会是以下过程：

游戏\->死循环\->利用事件控制游戏进行/结束

今天我们就利用event的特性来实现一个事件记录的功能

```
import sys,pygame
#初始化pygamepygame.init()
size = width,height = 600,400
#创建指定大小的窗口 Surfacescreen = pygame.display.set_mode(size)#利用上面设置好的size创建#设置窗口标题pygame.display.set_caption("My First Pygame ^-^")
f = open("record.txt","w")
#利用死循环实现game的运行while True:    for event in pygame.event.get():        f.write(str(event) + "\n")#写入操作事件，为方便观察，将event转换为str        if event.type == pygame.QUIT:            f.close()            sys.exit()#设置点击关闭键退出，由于pygame和tkinter冲突，所以有设置的必要性  
```

```
size = width,height = 600,400screen = pygame.display.set_mode(size)pygame.display.set_caption("Gun&Konmu demo")bg = (0,0,0)#黑色
font = pygame.font.Font(None,20)#实例化font对象，并设置字体，字的大小line_height = font.get_linesize()#获取行高position = 0#文字开始开始位置
screen.fill(bg)
while True:    for event in pygame.event.get():#控制程序结束        if event.type == pygame.QUIT:            sys.exit()
        screen.blit(font.render(str(event),True,(0,255,0)),(0,position))#控制文字从左侧进入        position += line_height
        if position > height:#清屏            position = 0            screen.fill(bg)
```
