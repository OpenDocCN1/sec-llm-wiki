PHP serialize() &unserialize()




 02 

PHP的序列化函数serialize()简单概括就是把变量和它们的值编码成文本形式存储。

官方手册给出的解释是：对象的字符串表示

而就我个人理解来看这样说有些欠妥，因为我们再使用serialize()函数时可以发现它的参数不只可以是实例化的对象，亦可以是数组等其他类型的变量，而比较常见的类型(即O则是对象)

下面来看一些实例：

<?php class FileF{  public $filename='a.txt';  public $second=true;  public $number=1;  public $kong=NULL;}$struct2 = array('C', 'L', 'f', 'd');$a = new FileF();echo $a->filename.'<br />';echo serialize($a);echo '<br />';echo serialize($struct2);?>

以上则是创建一个类FileF,并生成一个实例化对象的序列化

再是创建一个数组并生成序列化

对于各字母的解释：

O：常用的复合类型（此处就是对象，指代类class）

5：表示对象名长度 FileF：就是对象名

4：表示类中所含成员个数

s：表示字符串类型   8：字符串长度 filename：字符串名

(PS:这里的类型种类有很多，如上图中的b：布尔型 i：整型等)

a：表示是数组类型   4：表示数组长度(注意区别：没有记录数组名) 

i:整型(此处是键值) s:表示字符串类型的变量 

1：表示长度 C：数组存储的值




 03 

以上是将对象进行序列化后存储，那么对于恢复成原样则需要利用到新的函数unserialize()。

unserialize():反序列化函数用于将单一的已序列化的变量转换回 PHP 的值。

官方给出的解释:构造对象

对于unserialize()这个函数，其功能如下：

  • 如果传递的字符串不可解序列化，则返回 FALSE，并产生一个E_NOTICE

  • 返回的是转换之后的值，可为integer``float、string、array或object

  • 若被反序列化的变量是一个对象，在成功重新构造对象之后，PHP会自动地试图去调用__wakeup()成员函数（如果存在的话）

下面看一个实例：

可以看到unserialize()函数将序列化字符串还原成对象还有数组并且还原后的和之前的功能是一样的，所以还是同一个。
