  解题思路

好了闲话少说，我们发现它是利用同一个q进行加密之后，后面就简单多了，对于这种类型的RSA，困难就在于n的分解，由于两个n共有一个因数q，所以对于这个q我们只需要对这两个n求公因数即可，而用于加密flag的只有第一段的内容故而剩下的与第二段已经完全没关系可以忽略。

接下来只需要用n/q即可求得p

最后在只需要求逆元d，即可解出本题

  约束条件下爆破sha256

这次密码学的题目对于俗说君这种等级的菜鸟来说就真的是有些力不从心了，刚拿到两个密码的题目的时候发现第一层全都要去爆破sha256，像俗说君这种解密基本靠脚本的菜鸟来说无疑是当头一击，没办法，只好硬刚了

加密思路还是很清晰的，首先是获取8位的随机数，再是对整体进行sha256生成哈希并且生成十六进制的摘要，而后最对明文的前五位进行十六进制编码，最后要求我们输入整段明文hex()后的结果

  解题思路

  • 解题目标也是很明确的，我们已知的是明文的前五位和整段的哈希值，所以我们只要去爆破后三位即可达成目标

  • 下面附上解题代码：

    import hashlib
    def proof(skr,ha):    for i in range(0x100):        for j in range(0x100):            for k in range(0x100):                ch = skr + chr(i)+ chr(j)+ chr(k)                ch=shr.encode()                if hashlib.sha256(ch).hexdigest() == ha:                    print(ch.encode("hex"))                    return ch.encode("hex")
