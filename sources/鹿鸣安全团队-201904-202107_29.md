首先介绍一下相关术语：

AES，高级加密标准（英语：Advanced Encryption Standard）。是用来替代DES，目前比较流行的加密算法。 

它是一种对称加密算法，与上一篇博文提到过的RSA非对称算法不同，AES只有一个密钥，这个密钥既用来加密，也用于解密。

AES只是个基本算法，实现AES有几种模式，主要有ECB、CBC、CFB和OFB这几种（其实还有个CTR）  

  

CBC:CBC模式对于每个待加密的密码块在加密前会先与前一个密码块的密文异或然后再用加密器加密。第一个明文块与一个叫初始化向量的数据块异或。

下面看一下其主要接收的三个参数：

*   key：初始密钥。根据 AES 规范，密钥长度为 16 字节、24 字节和32 字节长，分别对应 128 位、192 位和 256 位；
    
*   mode：加密模式。可以寻找相关的文档了解。俗说君此次实现的只是CBC模式。
    
*   vi：初始化向量。在部分加密模式中需要使用到，如对于 CBC 模式来说，它必须是随机选取并且需要保密的；而且它的长度和密码分组相同（AES 的分组长度固定为 16 字节）。

'''AES_MODE_CBC实例，自动随机生成16位keyPlaintext="helloworldKonmua"'''
from Crypto.Cipher import AESimport random,stringimport base64
Plaintext='helloworldKonmua'
class AES_CBC_Test:    def __init__(self):        self.key=''.join(random.sample(string.ascii_letters +string.digits,32))#随机生成32位的key                    global encoded    def AES_Encrypt(self,data):        cipher=AES.new(self.key,AES.MODE_CBC,self.key[:16])#密钥生成实例AES对象（CBC模式）        cipher_text=cipher.encrypt(Plaintext)#AES加密密文        global encoded        encoded=base64.b64encode(cipher_text)#base64加密密文，以便数据传输        print(encoded)        return encoded        def AES_Decrypt(self):        cipher=AES.new(self.key,AES.MODE_CBC,self.key[:16])#生成AES对象        decoded=base64.b64decode(encoded)#解密base64加密的密文        plain=cipher.decrypt(decoded)#AES解密        print(plain)        return plain    
x=AES_CBC_Test()x.AES_Encrypt('helloworldKonmua')x.AES_Decrypt()
