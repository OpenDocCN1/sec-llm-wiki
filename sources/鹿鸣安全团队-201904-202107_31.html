Web redos

这题一开始提示：Do you know .swp file?

故而想到备份文件，所以在url中输入/.index.php.swp(此处注意，最前方有一个“.”，俗说君一开始漏打了所以一直返回404o(≧口≦)o)

普及一下：

备份文件格式还有：1.~ 2.swp 3.bak

下载到备份文件后，丢到kali输入以下命令还原

vim -r index.php  #swp文件为 ./.index.php.swp

这里提到一个preg_match函数：用于执行一个正则表达式匹配,由于preg_match函数不能处理数组，因此在CTF中常常可以同过构造数组来进行绕过。

再看本题还有一个判断数组的函数，是想让正则中的 .*匹配到后面的所有内容，然后再回溯匹配，因为回溯次数上限默认是 100 万。那么，假设我们的回溯次数超过了 100 万，把字符长度加到100万以上，使其匹配超出限制返回false。

下面是python3实现的代码：

from requests import post
payload = {'greeting':'Baby PHP'+'a' * 1000000}res = post('http://120.27.3.220:10001/index.php',data=payload)print(res.text)
