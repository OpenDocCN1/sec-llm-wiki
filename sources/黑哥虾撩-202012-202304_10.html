Q：先需要一个数组，对数组里的元素["Connection: close","Connection: keep-alive"]对header1，header2进行替换为空 

（简单说明下这个是什么目的，这个是因为ZoomEye探针发包方式不一样或者因为目标服务器设置不一样，同一类服务器导致有的“Connection: close”有的没有，所以我需要预先处理替换为空）

A：经过一段苦口婆心，且无关紧要的“教学”后给出了代码（这里吐槽下，在这个时候打工仔的这些废话很影响老板的急切压榨打工仔的心情～～）

def headers_to_set(header_str):    header_list = ["Connection: close", "Connection: keep-alive"]    for header in header_list:        header_str = header_str.replace(header, "")    lists = header_str.split('\n')    lists = [i for i in lists if i]    return set(lists) if header_str else set()

def headers_to_set(header_str):    header_list = ["Connection: close", "Connection: keep-alive"]    for header in header_list:        header_str = header_str.replace(header, "")
