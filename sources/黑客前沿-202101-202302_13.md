# F5 BIG-IP

F5 BIG-IP 链路控制器用于最大限度提升链路性能与可用性的下一代广域网链路流量管理。

# 漏洞简介

F5 BIG-IP 存在代码执行漏洞，该漏洞允许定义身份验证的攻击者通过 BIG-IP 管理界面和自身IP地址对 iControl REST 接口进行网络访问，以执行任意系统命令，控制目标机器。

# 影响版本

F5 BIG-IP 15.1.0-15.1.2 

F5 BIG-IP 14.1.0-14.1.3.1
