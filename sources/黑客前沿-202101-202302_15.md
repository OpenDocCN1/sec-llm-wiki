# 环境搭建

VulnHub是一个丰富的实战靶场集合，里面有许多有趣的实战靶机。

本次靶机介绍： 

`http://www.vulnhub.com/entry/gigachad-1,657/`

下载靶机ova文件，导入虚拟机，启动环境，便可以开始进行靶机实战。

# 虚拟机无法分配IP处理办法

VulnHub的靶场虚拟机环境可能会出现无法分配到ip的情况，这里需要做如下配置处理：

第一步，进到这个界面时按`e`

![](../Images/8de1ae22195f7f74a217afe23af5c008.png)

第二步，将此处的`ro`替换为`rw signie init=/bin/bash`

![](../Images/a8283fea7258cf03fdb4100db573baa6.png)![](../Images/75e32933673e56b5f4655a658f3b2e77.png)

第三步，按下`Ctrl` + `x`，进入命令行模式

![](../Images/ecf698ed0c853db492a3055022cd7129.png)

输入命令`ip a`查看ip状态

![](../Images/63f9653b2d26f09a181829d1c697db19.png)

查看网卡配置文件`vi /etc/network/interfaces`

![](../Images/a72995f0a34fd3345ae66f30d69a1a3b.png)

发现配置文件的网卡名称与实际的不符，将其改为实际的网卡名称，保存退出

![](../Images/84229ddfc2689064e2e29cb965dd477f.png)

重启网络服务 `/etc/init.d/networking restart`

![](../Images/9aa224cf5d82065284c744a9b439e66e.png)

此时查看ip状态发现已经正常可以获取到ip

![](../Images/89593f9dd914ddfabe39be0138f854c9.png)

最后重启虚拟机，配置完毕。

# GETSHELL过程

环境配置完成后，我们需要探测出靶机的ip地址，使用nmap快速探测C段（这里使用NAT模式打开虚拟机，因此靶场地址必定在指定的C段中）

```

nmap -sn -v -n --min-hostgroup 1024 --min-parallelism 1024 -PE 192.168.157.0/24
```

![](../Images/6a8fbfc7fcbe8330401d76e49a1c0334.png)

得到靶机ip：192.168.157.154（133是攻击机地址），此时我们进行端口探测

```

nmap -sS -p 1-65535 -v --min-parallelism 1024 -Pn --open 192.168.157.154
```

![](../Images/e2d2d284c3158950013b52c08ee2b158.png)

开放了21、22、80等端口，我们先从80端口尝试突破，浏览器访问：

![](../Images/6c7cb63c9613b2b7dcb76b0816a321ed.png)

首页没有太多有用的信息，我们右键查看源代码，在底部发现两串MD5：

![](../Images/35e5ab63e533b86e5aeec5a70b061d37.png)

尝试解密一下：

![](../Images/505335f6d63a3431e7a792800937a4ef.png)![](../Images/607f623f6bee28006cdf4ffdf36a560c.png)

（出题归出题，骂人就是你的不对了呀大兄弟）得到字符串`VIRGIN`，添加到路径中访问一下，提示404 NOT FOUND，改成小写再次访问

![](../Images/9208f7473449db149da4ab3280ebae58.png)![](../Images/59e477336d7c536ba0cf37410513d33c.png)

得到了这么一个页面，似乎用处也不大，先祭出目录扫描器扫一下，然后我们访问一下`robots.txt`

![](../Images/589b21e5f7540cbc204025ba0f4339c1.png)

继续访问`/kingchad.html`

![](../Images/e53ad61a0ba8f181f933960f6d989dd6.png)

这个憨憨竟然打电话给军情六处了？！看了一眼目录扫描结果，全都是那个用代码画的人脸，没有有用的信息，只能暂时先放弃web了。

web无法突破，我们打算从ftp入手，掏出top2w字典，弱口令爆破尝试：

![](../Images/5f247bad5173dd49e1701b08b68f8c33.png)

本以为是个弱口令，后来发现是个空口令（手动汗颜！），FileZilla连一下，发现一个文件：

![](../Images/16e32112ad11cc6947c4eee98d2468af.png)

下载回来，记事本打开发现PK头，改后缀为rar，打开发现文本文件

![](../Images/f2d17784da5ba2ba32d0c9feec8eda68.png)![](../Images/a6ebb212032b8e8996e1f972a9b84252.png)![](../Images/273634dc501701b6bf4edcfb40e555e2.png)

这里得到提示，用户名`chad`，访问图片地址：

![](../Images/fd5ba3aab62788a94a3260674c65107f.png)

根据图片提示得知密码就是该建筑的名称，百度识图一下：

得知建筑名为女儿塔，百度其英文名：

![](../Images/c5504b8bd8b689207ebc4de1ba784cdf.png)

`Maiden’s Tower` 尝试用此密码登录ssh发现失败，后来尝试了几种组合发现密码为 `maidenstower`，成功连接ssh：

![](../Images/217d2b887010f6f636af6fd7b8bf82fa.png)

查看桌面文件

user.txt中发现第一个flag:
