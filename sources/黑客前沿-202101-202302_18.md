# 漏洞简介

锐捷 RG-UAC 统一上网行为管理审计系统存在信息泄露，攻击者通过网页源代码可间接获取管理用户账号密码，登录管理后台。

# 漏洞复现

fofa搜索以下关键字

`title="RG-UAC登录页面" && body="admin"`

登录界面如下所示：![](../Images/e7793fbd35d964b3089b6781d168f785.png)

`Ctrl + U`查看源代码，搜索`password`获取管理员账号密码：

![](../Images/15bd87cf16b4d8f9389d5b8d6f027893.png)

somd5解密密码![](../Images/29c982f6ec1a8c84e4dd834f5d4fd36c.png)

使用账号密码成功登录管理平台：![](../Images/c4aa3602e92a4d0b5c6643103e3e958d.png)
