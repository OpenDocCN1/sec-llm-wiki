# 0x01 漏洞简介

2021年1月26日，国外研究团队披露了sudo 中存在的堆溢出漏洞（CVE-2021-3156）。利用该漏洞，非特权账户可以使用默认的sudo配置主机上获取root权限，该漏洞影响1.8.2到1.8.31p2的所有旧版本以及从1.9.0到1.9.5p1的所有稳定版本。

# 0x02 影响范围

sudo 1.8.2到1.8.31p2的所有版本

sudo 1.9.0到1.9.5p1的所有稳定版本
