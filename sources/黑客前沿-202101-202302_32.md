# 0x01 信息收集

目标站点：*.*.72.243，首页如下图所示：![](../Images/b9bc46716c8b9d899f372a14ed6e574f.png)

# 0x02 Getshell

Thinkphp框架搭建的网站可以利用远程执行或者找找注入，本人习惯先从后台入手，URL随手加个admin得到后台：![](../Images/7bd187453244da0c65f1b7400199c41c.png)

这里没有验证码复用，我们手动爆破下账号密码，这里运气不错，管理账号弱口令，直接进入后台：![](../Images/e228022a567873e5f9c25b4a1a5a0939.png)

有了后台，getshell就相对比较容易了，找到一处上传点，抓包修改下后缀，成功上传webshell:![](../Images/16d93a6da15ead095e4c553c6ec06cd7.png)

![](../Images/48f25cb73ce30f265267df722249a5db.png)

# 0x03 绕过宝塔提权

用shell执行命令发现网站开启安全模式：![](../Images/812f39fd939532109ac839299eb4e19a.png)

phpinfo查看一下禁用的函数：![](../Images/23fc640499528182628d4bdfa96e2d73.png)

```

passthru,system,chroot,chgrp,chown,shell_exec,proc_open,proc_get_status,popen,ini_alter,ini_restore,dl,openlog,syslog,readlink,symlink,popepassthru,putenv,exec
```

这里禁用了exec函数，我们就无法使用windows COM组件来绕过disable\_functions执行命令。联想到网站使用Mysql数据库，遂查找root密码：

![](../Images/b6f79d99f867182e300c2f3c780e306e.png)

尝试使用UDF提权，上传暗月UDF提权脚本：

![](../Images/6dc179bfc322abac787b37c69157a704.png)

无奈这里无法导出UDF，此路不通。此时联想到网站是宝塔搭建，在翻找目录时发现文件权限较大，兴许可以利用。果不其然，在`D:\BtSoft\panel\data\admin_path.pl`发现宝塔后台路径:

![](../Images/1010fb4d3866b9348d994e2164233324.png)

宝塔后台默认端口一般为8888，访问得到宝塔后台：

![](../Images/1a8a1868d3d5fd3404262645a1d2b529.png)

有了后台，剩下的就是寻找密码了，宝塔后台账号密码默认存放在`default.db`数据库的users表中，我们将数据库下载回来，利用kali的SqLite databese browser工具打开：

![](../Images/cf668ead357fcf5e0b39f932f167528b.png)

在users表中发现管理员账号与MD5加密密码：

![](../Images/72cb04342d608e7eb7bd4a95db9edd76.png)

在somd5中解密管理员密码，成功解出：

![](../Images/c9eb162bab0d26bc6bd5a5b95769611e.png)

利用账号密码成功登陆宝塔后台：

![](../Images/ead267b62842e21015d6da3c8ec08077.png)

接下来事情就好办多了，我们利用宝塔计划任务功能，执行系统命令添加系统管理员用户：

![](../Images/e560e3cfb9225b69bf63830c1a1ae361.png)![](../Images/c1ad4d53faaa79ed4efe90ad0b88912e.png)![](../Images/e00e90fb01b6d72734b2de6115eee0c9.png)

这里我们无法扫描端口，可以使用计划任务，将端口信息导出到指定路径，即可知道服务器远程端口：

![](../Images/6a3a17433aee9dc8be6bfc2645cbac0d.png)![](../Images/173b91795032f3a67797a9917794221e.png)

使用系统管理员账号登入桌面，提权成功：

![](../Images/67fd1e5cbdaba3098db6a6e9f1374f58.png)

清理痕迹，留下后门维持权限。打完收工~
