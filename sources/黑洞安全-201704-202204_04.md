## **前言**

奶茶CMS是一个视频网站CMS。解决了传统CMS安装繁琐、配置麻烦的常见问题，可以通过解压缩到绿色的本地目录来使用。  
操作不需要每天手动更新，系统自动同步数据，一分钟内拥有30000个视频资源。  
上传可以在没有数据库的情况下运行，对接久草资源，并且经常用于**非法视频网站**。

**奶茶CMS登录：**

2.  网站后台系统默认账户**9ccms**，默认密码为**9ccms**


其中的**`$str .= 'define(\'IPPASS\', \''.$ippass.'\');';`**只过滤了“/”，没有对进行严格过滤。  
可以看到，在接收到修改数据之后，代码只对提交的数据进行了简单的函数过滤，便拼接字符串，然后存储到AdminUser.php文件中。修改密码成功之后再一次重定向到security\_userpass.php当中，这样就可以触发之前的插入的shell了。之后我们看一下AdminUser.php文件的存储结构。

```
5.  `define('IPPASS', '');`
    
6.  `?>`
    
```


## **总结**

随着互联网的快速发展，当前违法犯罪的态势正在呈现向网络犯罪发展的趋势。  
但是我们通过寻找漏洞，破坏犯罪分子的网站，或收集信息一网打尽，以此维护网络安全。  
同时在这个漏洞中，对提交的数据过滤不严格，导致代码执行。同时也因为默认的弱口令，导致后台被暴露在网络当中。所以我们要及时修改密码。作为白帽子，如果能进入网站后台，则尽可能地寻找危害性更大的漏洞，来发现潜在的安全风险。
