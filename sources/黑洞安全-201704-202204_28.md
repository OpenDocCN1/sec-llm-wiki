# 读书分享之———《做人要稳，做事要狠》（鸿图）

       人生看似复杂,实际上不外乎件事,一是做人,二是做。做人之难难于从躁动的欲和情绪中稳定心态,做事之难难于从纷乱的矛盾和利益的织中理出头绪。而最能促进己、发展自己、成就自己的人生道理便是做人要稳,做事狠。故人一定要稳。**人要稳是一种修为,是—种人生的理解,是一种做人的策略,其中包含了很多值得人们好好品味和反思的内容。人生成功与否的最大差距便是在做人上,做人的至高境界就一个字:稳。唯有做到这点,才能够在复杂的社会环境立足、发展。做人要稳,就一定要懂得什么叫随机应变,什么叫恰如其分,什么叫不偏不倚:什么叫谨言慎行,什么叫远离是非。做人要稳,在自我表现时,懂得既表现自己,又不让人感到享收藏扬在说话时,懂得说话的轻重、虚与实,即使批评别人,也能够润物:细无声;在与人交往时既善于与人相处又不失自我,总是能够把握与人相交的恰当距离.做事先做人,做人务求稳。只有深刻理解了|稳"字含义的人,才能在人生之路上顺风顺水、左右逢源。**51特色购至于做事,当然要狠。有一则电视广告说一生就是二场度场的战斗,人就要对自狠一点,一针见血地道出了做事的真理梦想是美丽的,现实是残酷的。并不是所有的梦想都能变成现实,也并不是所有的人都进入成功者的行列。成功自有成功的道理,成功者自有成功者的道行,若要问其中的奥,那肯定离不开一个"狠字。是的一个人要成就自己伟大的一生,不能不狠。不狠的人很无力,不狠的人生很苍白。做事要狠,这不是一个哗众取宠的写作命题,而是一个在现实生活当中,大多数人所面临的最为真实的挑战。狠,不是酷无情、心狠手辣,而更多是一种做事的风格,是一种处世的态度。然狠也是一门艺术。什么时候该狠,什么时候不该狠,狠要狠到什么程度,这都是需要细细思量、用心体会“做人要稳,做事要狠"做人做事的艺中的运用。
