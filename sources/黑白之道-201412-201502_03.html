如何检查并修复GHOST（幽灵）漏洞

原文：http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=202700008&idx=1&sn=2d8aa17a7acb593bb38c01065545a2fd&chksm=1255910c2522181a99c3419069bc087a565cdb2e62d585d9bf86a0816e5f5c1fb0f86a8445b2&scene=27#wechat_redirect

　　漏洞简要描述

　　该漏洞存在于 glic 库中的__nss_hostname_digits_dots() 函数，在nss/getXXbyYY.c这个文件中，gethostbyname()会使用这个功能。另外，这个漏洞本地远程都可以利用，要利用此漏洞，攻击者需要构造一个特定的 hostname 数据条给linux 上开放的服务，如果服务不对数据做安全处理，就会引发一个任意代码执行漏洞。

　　下面列出了几个受影响的服务：

　　procmail

　　Exim

　　pppd

　　clockdiff

　　你也可以用下面命令来查看你的 server 上有哪些服务依赖 glibc：

　　lsof | grep libc | awk '{print $1}' | sort | uni

　　下面是各个系统的升级方法：

　　Centos/RHEL/Fedora 5,6,7

　　yum update glibc

　　sudo restart

　　ubuntu

　　sudo apt-get update

　　sudo apt-get dist-upgrade

　　sudo restart
