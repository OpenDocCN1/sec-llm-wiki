# Ubuntu 12.04 Unity 3D失效的解决方法

突然心血来潮，借别人的显示器玩了一下双屏，结果，杯具了 =.=  
  
（2B程序员每个月总有那么几天系统出问题的，习惯了，淡定）  
  
好好的Unity 3D 变成了Unity 2D ,而且，我朋友也经历了同样的情况，最后他放弃了，选择了重装。  
  
但是，个人感觉重装系统配环境麻烦，所以，也是心血来潮的想了个鬼主意=.=  
  
好了，重点  
  
分析过程：  
  
\----》本来好好的Unity 3D 变成了Unity 2D ,而且一去不回，当中设置双屏的时候改动的地方，却只有一个：  
  
/etc/X11/xorg.conf  
  
\----》 这个我想遇到这情况的盆友都会想到，所以回去修改，计划把配置文件改回最先版本，可惜很多都白干了  
  
我把设置双屏时候添加的配置都删掉，而且还原到了原来的样子了，还是不行……悲催  
  
这时，狠下心来想想：如果把这配置文件删掉，会怎样？  
  
\----》记得这配置文件是安装显卡驱动之后的产物，那刚刚装完系统也是没有驱动的，所以，删掉是没事的！！  
  
斟酌了下，敲了一条命令：  
  
sudo rm -rf /etc/X11/xorg.conf  
  
接着敲了第二条：  
  
sudo reboot  
  
重启后的结果真是叫人激动，Unity 3D 可以正常使用了 ,而那文件，要就重装一次驱动，要么就不管了算=.=  
  
反正我的Ubunutu 是活过来了 yeah~
