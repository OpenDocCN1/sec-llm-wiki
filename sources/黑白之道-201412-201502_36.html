　 安装ubuntu 11.10后发现txt文件乱码，去网上查发现好多方法不能用，
　　几经努力之后终于有了结果，
　　ubuntu 11.10解决办法如下：
　　在终端输入sudo apt-get install dconf-tools 安装dconf-editor
　　然后输入命令dconf-editor打开
　　dconf-editor下 org--->gnome--->gedit--->preferences--->
　　encodings--->auto-detected最前面添加
　　'GB18030', 'GB2312', 'GBK',注销之后OK
