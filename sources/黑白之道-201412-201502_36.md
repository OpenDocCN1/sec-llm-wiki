# Ubuntu 11.10乱码问题

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=202123793&idx=3&sn=5d5eb404749fad653dd566561ad731c7&chksm=124d4ff5253ac6e32d97bb294f30612373f7f84a3260eeb0e600536754df329ad74dcfd184f2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=202123793&idx=3&sn=5d5eb404749fad653dd566561ad731c7&chksm=124d4ff5253ac6e32d97bb294f30612373f7f84a3260eeb0e600536754df329ad74dcfd184f2&scene=27#wechat_redirect)

　 安装ubuntu 11.10后发现txt文件乱码，去网上查发现好多方法不能用，  
　　几经努力之后终于有了结果，  
　　ubuntu 11.10解决办法如下：  
　　在终端输入sudo apt-get install dconf-tools 安装dconf-editor  
　　然后输入命令dconf-editor打开  
　　dconf-editor下 org--->gnome--->gedit--->preferences--->  
　　encodings--->auto-detected最前面添加  
　　'GB18030', 'GB2312', 'GBK',注销之后OK
