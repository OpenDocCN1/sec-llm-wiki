# 白宫称网袭联邦政府的黑客身份尚无明确指向

美国白宫于6月5日表示，联邦调查局(FBI)已就联邦政府部门遭遇网络攻击一事展开调查。目前，黑客身份尚无明确指向。

  

美国媒体本月4日报道称，有黑客入侵美国联邦人事管理办公室，并窃取了400万名联邦政府雇员及前雇员的个人信息。还有匿名美方官员称，怀疑上述网络攻击来自中国。

美国白宫发言人欧内斯特在5日举行的例行记者会上表示，FBI正在就相关网络攻击进行调查，尚未证实是谁或哪个国家发起了此次网络攻击。他说，FBI将就遭窃取信息的规模进行评估，查明黑客身份，并采取措施将黑客捉拿归案。

美国务院负责战略传播事务的高级顾问哈夫5日表示，此事不会影响到本月下旬即将在华盛顿举行的第七轮美中战略与经济对话。她说，美方一直致力于这一对话机制，将继续推动本轮对话。她还表示，尚在养伤之中的美国务卿克里将按计划出席本轮对话。

中国外交部发言人洪磊5日表示，中方望美方在打击网络黑客攻击领域不要疑心重重、捕风捉影，而是在这一领域更多展现信任和合作。

洪磊表示，中方一贯强调，中方坚决打击一切形式的网络黑客攻击行动。中国自己也是网络黑客攻击的受害者，在这一领域，中方愿意开展国际合作，共建和平、安全、开放、合作的网络空间。
