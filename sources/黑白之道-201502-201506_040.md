陌生网络里的恐惧（第一篇）我给大家科普了路由器后门与漏洞，忘记给大家说了，这个领域很快会有一本书发行，书名的前7个字符是「路由器0DAY」:)

  

路由器入侵，除了用路由器后门、漏洞，还有一个非常主流的分支：Wi-Fi 破解，这点我之前系列文章里已经提过，这里不说。这篇我重点八卦下「当你成为那只特洛伊木马之后」的 ARP 攻击。  

  

ARP 攻击的形成本质和 ARP 协议有关，ARP 协议是网络层的协议，这是互联网协议发展过程中极其经典的协议，存在的目的是为了解决同一网段机器通讯的问题，这种解决方式很粗暴：广播。由于很粗暴，任何机器都可以伪造这种广播，造成的一种常见结果是：你的终端上网流量本该只经过网关（路由器）进出的，却绕了一下，经过这个网络里攻击者的终端进出。这样一来，你的上网过程几乎毫无隐私了，哪怕是 https，也有一些方式可以攻破。  

  

关于互联网协议有篇入门文章推荐：

> http://www.ruanyifeng.com/blog/2012/05/internet\_protocol\_suite\_part\_i.html

  

这里我推荐一些强大的工具进行 ARP 攻击，这些工具好好玩吧，不仅玩，还建议如果能看到源码的就看源码，这样可以很快深入本质 ;)  

  

**Android 上的 App（root）**  

> dSpoit  
> 
> 用法很简单，随便点击点击就能看到效果，内置端口探测、routerpwn.com（第一篇文章提过这个）、登录爆破等。其中 MITM（中间人攻击）常用：Password Sniffer、Session Hijacker，偶尔用到 Script Injection :)，这几个功能看名字就知道是做什么的，不用介绍。
> 
>   
> 
> 关于 Password Sniffer，我有个疑问：为什么可以 sniff 到 IMAPS/POP3S 的账号密码？谁知道的告诉我下，感谢。  
> 
>   
> 
> zANTI  
> 
> 用法也很简单，内置 Nmap、routerpwn.com、登录爆破等。MITM 常用：SSL Strip（针对 https 的攻击技巧）、Intercept Download（替换下载文件，比较粗暴）、Insert HTML（这个能达到 dSploit 的 Script Injection 效果）。
> 
>   
> 
> 综合来说，用户体验比起 dSploit 要好。

  

**Linux 命令行（root）**

> Linux，无论是你自己 PC 上的 Kali Linux，还是黑客手机上的 Kali NetHunter 等，命令行可以让我们更接近真相。  
> 
>   
> 
> ettercap
> 
> 这个命令行很不错，也有图形方式，还可以扩展脚本，基于它做开发扩展是个不错的选择。命令行样例：  
> 
> echo 1 >> /proc/sys/net/ipv4/ip\_forward  
> ettercap -M arp:remote /192.168.0.1/ /192.168.0.100/ -T
> 
> 意思是，针对 192.168.0.100 这个 IP 进行针对性 ARP 欺骗，网关地址是：192.168.0.1。  
> 
>   
> 
> arpspoof
> 
> 比起 ettercap，极度轻量级与专注（核心代码就百来行），命令行方式稍微复杂了点点（这都不是事）。
> 
>   
> 
> dsniff
> 
> 这是一个工具集合了，arpspoof 是集合之一，都是古董了，但是古董有古董的好处，就是那样牛，不爽你就改进，其实很多网络工具都有借鉴 dsniff。
> 
>   
> 
> 说到改进，如果你会 Python，其实就不必去啃 dsniff 那些 C 了，基于 Scapy、Twisted 这是一件比较容易的事 ;)  
> 
>   
> 
> MITMf
> 
> 神器，Python 打造的，基于很多经典模块，如 Scapy、Twisted，这样一来曾经基于 ettercap 等经典命令行的功能都可以不需要了，完全自己重构。这个框架里的插件基本上涵盖了 ARP 攻击的各种姿势，不读源码，对不起自己：
> 
> https://github.com/byt3bl33d3r/MITMf
> 
>   
> 
> 特别提下有个功能是 FilePwn，这个功能利用 BDF 技巧直接篡改 HTTP 下载的可执行文件，可以植入后门，结合 MSF 反弹 Shell。BDF 技巧参考链接如下：
> 
> https://github.com/secretsquirrel/the-backdoor-factory  
> 
> https://github.com/secretsquirrel/BDFProxy  
> 
> 猥琐至极的高姿势...
> 
>   
> 
> 还有一些恶作剧功能，比如替换图片（这个功能 dSploit、zANTI 也有）、颠倒网页等，Just for fun :)  
> 
>   
> 
> LANs.py
> 
> 我偶然发现的，相见恨晚，神器，也是 Python 打造的，同样基于 Scapy、Twisted ;) 结构非常简单，就一个 Python 脚本，1603 行代码，姿势也比较齐全（但是没 SSLstrip、FilePwn 这种高难度姿势），不读源码，同样对不起自己：  
> https://github.com/DanMcInerney/LANs.py
> 
>   
> 
> 比较另类的：
> 
> 1.  具备 Wi-Fi 破解相关功能，基于 Aircrack-ng
>     
> 2.  局域网探测一些功能，如 Nmap、nbtscan 等，这种集成和上面介绍的 zANTI 类似  
>     
> 
>   
> 
> 比较有趣的是 LANs.py 的作者推荐：MITMf :)  

  

介绍到这，基本上所有姿势都能涵盖了（自己玩），顺藤摸瓜下去，你会发现这是一个神奇的世界，令人敬畏。其实很多知识你深挖下去，都令人敬畏。这篇文章你可以发现：现在的黑客攻击成本其实很低。在一些场景下，一个完全新手，我 5 分钟就可以教他如何黑掉别人，但是对于一个对知识敬畏、追求更高境界的人来说，永远不能停滞在这点小小虚荣心上。

  

因为这种低成本，以及网络自身的架构缺陷，我们所处的网络才可能随时蔓延着恐惧。其实如果你是个名副其实的攻击者，那么这个网络对你来说将一点都不陌生。我下一篇文章将尽最大努力给出这个网络里的安全防御，你会感谢我的 :)
