可好玩了，吓人，外加装13必备，时不时来一句，发现违禁词，已经报警了，哈哈，小伙伴都吓死了。

*   ![](../Images/949d209142830bbf1096388a25ac61d2.png)手头没有安卓机，以 iOS + Mac 为例。![](../Images/314ce5b438da34eafa51d30d40ca172e.png)使用 iTools ，定位到 QQ ，Documents/contents/你的QQ号 ，然后把 QQ.db 导入到电脑上。下载一个 SQLiteBrowser，打开这个 db 文件，看到结构如下![](../Images/d5bb5b47bd13a764fded2a202fbc4464.png)Troop 是群聊 c2cMsg 是私聊，找到你刚刚看到这种消息的群，tb*Troop*群号，右键 — Browser Table
    
    ![](../Images/6d9310f0dc2efb4449727805dcfd1142.png)
    
    找到 sMsgType 为 141 的消息，双击 strMsg 的值，把他改成你想要的内容
    
    ![](../Images/914b870a246727c1e8eb0937b16a637f.png)
    
    改好了之后点击 OK ，然后点击 Write Changes 来保存。
    
    再次进入 iTools ，把修改后的 QQ.db 覆盖回去，重新打开手机 QQ，找到这条消息，长按进行转发即可。
