# 以后说话小心点：苹果与第三方公司共享Siri语音数据

　　引导据两周前披露在Reddit(美国著名的旧事论坛)的音讯，苹果供认其语音助手效劳Siri(iPhone ，iPad ，iPod，iPod Touch 下面的一个十分智能的助手)搜集和存储用户语音数据，还......

　　据两周前披露在Reddit(美国著名的新闻论坛)的消息，苹果承认其语音助手服务Siri(iPhone ，iPad ，iPod，iPod Touch 上面的一个非常智能的助手)收集和存储用户语音数据，还将其提供给第三方公司。

　　苹果、微软还在用人肉分析语音数据

　　我们平常会在网上看到很多高大上公司关于语音识别技术的演讲，比如百度首席科学家吴恩达去年就说过：按照客观的衡量正确率的标准，百度的语音识别技术已经超过了谷歌和苹果的技术。??

　　

![](../Images/bcd0d0276bdb976e88f66c3faa2ebcc5.png)

　　虽然有国内网友质疑百度吹牛，但是看了下面的消息你也许就信了……

　　—名为FallenMys的用户抱怨说，他最近在一家叫Walk N’ Talk Technlogies的公司开始了一份新的工作，而他的工作就是负责听那些从苹果、微软的用户处收集来的语音数据，并检查及其翻译错误的部分：??

　　“我负责听那些录音，判断其翻译的准确率，并给与反馈，以帮助提高机器的准确率。我告诉大家吧，如果你们对手机siri说话，那么这些音频都将会被录下来，并被送给第三方公司处理。我听到过所有那些小伙子们说的话，比如’Siri ,你喜欢我吗?’……还有一些人请求Galaxy来舔他的屁眼，但愿我只是在开玩笑吧”

　　诸如Walk N’ Talk Technologies等许多第三方公司会跟苹果、微软等合作，帮助他们提高机器翻译的准确率，比如 Siri, Dictation ，Cortana 等工具的翻译准确率。??

　　苹果承认与第三方公司共享Siri语音数据

　　苹果 iOS 许可协议中明确说明：

　　“如果使用Siri或者Dictation，你将默认同意苹果及其子公司、代理商收集你的一些信息，包括你的个人信息及一些录音信息，收集这些信息是来帮助提高Siri，Dictation，及苹果的其他产品的服务质量。”

　　但是，这些条款压根就没人会仔细的阅读，绝大部分人都是直接点击接受。

　　去年苹果发布了关于保护用户隐私的申明，他们会使用一串随机数来标示用户，并将siri 的语音命令跟这串随机数关联起来，这串数字不是苹果用户 ID 也不是用户的 email 地址。即使你的 ID 没有跟你的录音数据绑定，你仍然需要当心你跟你的语音助手说了些什么。

　　如果你使用文字转语音的方式发送私密信息、商量机密，或者其他你不想让别人知道的内容，那就得多留点心眼了，因为所有你跟你的手机讲的话都会被陌生人听到，也不排除有泄露的可能性。(iPhone用户们，长点心吧!)
