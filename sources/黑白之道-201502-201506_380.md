# 记录一次OFFICE恶意宏分析

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=203432809&idx=4&sn=e8c64661eba1263196d0bf2ba48a938a&chksm=1261468d2516cf9b737ca5a718d712905c62bbcfb8807048618a942fe17cd8f6e6fe68a3a1eb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=203432809&idx=4&sn=e8c64661eba1263196d0bf2ba48a938a&chksm=1261468d2516cf9b737ca5a718d712905c62bbcfb8807048618a942fe17cd8f6e6fe68a3a1eb&scene=27#wechat_redirect)

垃圾邮件的附件中通常存在大量恶意的word文档，这些文档常常会把自己伪装成发票、收据。今天要说的这个吸引了我的注意，我不知道这个方法以前有没有人用过，但我确实没见过。这是一个不错的方法，相当聪明。

　　这封电子邮件附有一个zip文件，解压后便是一个word文档，用着糟糕的英语写着：“感谢你的付款，你的发票。。。在附件中。谢谢你的惠顾，我们非常感谢”。

![](../Images/5fbf437734522d148cb06cac88e682f4.png)

打开word文档，你首先看到的是安全警告，下面便是一堆乱码。用红色字写着的是：“如果文件显示乱码，请启用宏。”

![](../Images/c412595a1b5bb7d75b9e839d05cfe855.png)

点击“启用宏”按钮，你便看到了发票内容。这让文件有了一点信服力，足以让那些不设防的人相信其真实性。

![](../Images/775b62959bb225c49d4d1023ed048c1b.png)

使用 OfficeMalScanner，你可以将宏导出来以便分析。这儿值得注意的是“ThisDocument”这个宏。

![](../Images/de581babf19ddad56f6ac5b7405d6a51.png)

这儿我们使用 OleDump，他能很好的显示出文档的内部对象。

![](../Images/d01762ee9331fe4a0797b714b114f218.png)

我们还能导处‘ThisDocument’对象。

![](../Images/d08c3fab80f1413f4d602dd141df9a0c.png)

从这个宏中，可以看到一堆像垃圾一样的字符串连接存在于VBA代码中，很典型。

![](../Images/f815c0bf8fafe1454d3eb20af200afa2.png)

再往下，你会发现一些URL。

![](../Images/2d1fb600b029a39881cffae08041b09a.png)

这个VBA宏生成了VBS脚本，并重定向到文件中。

![](../Images/cf28bc3520391c235eb419edefa008b2.png)

有趣的是这个脚本还调用了一个Powershell 脚本，真会赶时髦啊。现在就很清楚它在干嘛了：从互联网上下载并执行一个文件，然后再下载一个图片用来做统计并清理。

![](../Images/9358c0fedc91aa873035ce2b64543458.png)

现在我们就来下载这个文件

![](../Images/bae9d25de6f1aee90ffe9a09fb792733.png)

来看看这个VirusTotal到底是什么。。。

![](../Images/feb36afaafd0795bd83a60dcda532e22.png)

这便是所下载的图片

![](../Images/33cc1fd9290e916c9ccdec37023be555.png)

下图红框中的内容便是下载统计。不清楚其中到底有多少是受害者还是安全研究人员，但单纯看数字的话还是不少的。

![](../Images/ac9a0e32ec301a770e54521f71530989.png)

再来看看这个宏，我想查出它是怎么将一堆乱码转换成文字的。 

在靠近底部，并在清理代码的上方，我看到对“findText”和“secondText”的调用。

![](../Images/00f507f72951baf037967a1f1cd4ca60.png)

通过查看“findText”函数，发现它查找“<select></select>”标签并删除其中的内容。

![](../Images/04c252c42c11508431a3928a384ef05b.png)

“secondText”函数查找“<inbox></inbox>”，并将其中字体颜色改为黑色。

![](../Images/44a321c0a7342e98eda5a194c67225b2.png)

Duang!!! 这家伙根本就没做什么解码工作，只是耍了个小花招。发票的文字从开头就一直在那，只是被设置成白色，和背景色相同，所以你看不到。只要改变字体的颜色（如绿色），哈哈，看到没：

![](../Images/72ed7de43fd8e3f417d796576072a298.png)

真他妈太狡猾了。
