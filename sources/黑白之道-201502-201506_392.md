# 教你简单备份win7系统

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=203397680&idx=6&sn=8cf7888023b98b8548caff368d23e002&chksm=125effd4252976c2920f22f80f0589532d4de2ef2f074ee7295eccd49899ee243063caee4f71&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=203397680&idx=6&sn=8cf7888023b98b8548caff368d23e002&chksm=125effd4252976c2920f22f80f0589532d4de2ef2f074ee7295eccd49899ee243063caee4f71&scene=27#wechat_redirect)

Windows 7操作系统自带系统备份，尤其是正版的Windows 7操作系统，首先应该使用这个功能做一下备份，以便需要的时候可以及时还原，不必重装操作系统。

方法/步骤

1、开始→控制面板→恢复

![](../Images/690e4a143c7aace29edeebc27c76600a.png)  

2、打开系统还原

![](../Images/d417abe2f7d6cc41ffa6f55a136e0fa2.png)  

3、系统还原→下一步

![](../Images/1f63c9f5d3919523736dbc5f5f04c9ba.png)  

4、一般情况下，正版的操作系统都是默认开启自动备份，如果是克隆版操作系统可能会关闭此功能，甚至将其优化掉了。

  
![](../Images/f1bc4c7f4799fc974c5cda0a3aad2bd2.png)  

5、这个备份、还原的功能只是对系统、设置等进行备份，而不会对用户的资料进行改动。所以，可以点击扫描受影响的程序来查看是否有必要进行备份（新建还原点）。

![](../Images/228ef7e85f39a9e1bb2365bfe86179b5.png)

6、一阵扫描，系统还原就会给出扫描之后的详细信息，看完清楚这个还原点之后操作系统做了些什么？尤其是打了系统补丁、驱动程序之后异常，通过还原，就能恢复到还原点之前的系统状态，很有用。

  
![](../Images/93454fc64dafc646f8b75a21094e7757.png)

7、点击完成，就将备份操作进行完毕了，系统异常，需要的时候就可以使用已经备份的还原点，进行还原操作了。

![](../Images/eb0f5b2d24e803b3cf7cfb39699c7b54.png)
