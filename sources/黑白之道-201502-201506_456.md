今天有个小测试，要求爆破一个wifi密码，以前没怎么关注这个，第一次使用相关工具，各位大大别见笑。

环境：kali linux  
工具：fern WIFI Cracker v1.9  
1、打开fern WIFI Cracker ，路径 ：应用程序-->Kali Linux-->无线攻击\-->无线工具集-->fern-WIFI-Cracker  
软件界面如下：  
![](../Images/4ad7370029214e5bad352991f3e5d513.png)  
  
2、点select interface 选择你的网络设备 wlan(x) （如：wlan0），此时可能会有个提示，点确定即可；  
![](../Images/a078ff45628aec902a761d593af2d5c6.png)  
  
3、点“scan for Access points”按钮，稍候片刻，按钮后面的状态会变成绿色的“Active”；  
  
4、点“WIFI wpa”按钮（后面应该有以及扫描到的wifi信号），点此按钮后会出现如下“Attack Panel”界面；  
![](../Images/4869d694e9de0a593c2cf3b7bd8cde6a.png)  
  
5、点选你想要破解的wifi，再勾选上“Automate”复选框  
  
6、点 Browse 按钮，加载你自己的字典（这个东西自由发挥）  
  
7、最后点“WIFI attack”按钮，如何等着收粮食吧（速度比较慢，还得等待加载目标mac，等着吧）！！
