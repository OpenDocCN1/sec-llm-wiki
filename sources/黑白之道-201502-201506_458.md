# 过年回家-注意安全-平平安安到家-快快乐乐过年

　　家，是这个残酷世界留给大家最后一处温房，为此不管是在外学子还是在外务工人员，每到假期，每到佳节都会回家看看，回家感受家的温暖，回家吃爸妈的简单饭菜，回家见很久未见的老朋友，回家了吗？  

　　但在回家之前，有哪些回家安全注意事项必须引起我们的重视呢？

　　**检查个人物品**

　　要回家了，在临出门之前，必须做好行李整理，财务归放，并且保管好宿舍钥匙，带上必备的手机，充电器，化妆品，日用品，足够的衣物，车票...【建议在出门前一天整理好】

　　![](../Images/8f668f5f9fc8c8aef0df94d145f499eb.png)

　　**出门前必检查**

　　不管在外是住宿舍，还是拥有自己的家，在回家之前都要做水电防漏检查，建议拔掉电源;残留食品整理，日常垃圾倾倒，并且关好门窗。【建议出门前在确认一遍，并关好门窗】

　　![](../Images/0374ce803b6f93c9a575755441811e25.png)

　　**提前到站候车**

　　对于直接开车回家的朋友，可以直接跳过此步骤，对于乘坐交通工具的朋友，建议提前预备好时间，提前到站候车，切勿奢望让车候你。【建议提前到站等候，以免错过回家的车】

　　![](../Images/7c1be0ee21b1d531c5256f4f8a937dee.png)

　　**看护老人小孩**

　　老人和小孩容易走失，外出路途上切勿让老人和小孩离自己太远，切勿让老人和小孩离开自己的视线范围，避免走失，在人多拥挤的地方，牵住老人和小孩。【可以丢面子不能丢人】

　　![](../Images/06ccc75a4ee726fcb0dbf51a0798edbb.png)

　　**切勿张显财物**

　　在路上不要随意张显个人财物，对于出门在外，建议简易携带银行卡，现金不易过多，如果身上现金过多，建议备用零钱袋，够路上用即可。【重要财物贴身存放，并且提高警惕】

　　![](../Images/5a4ada12c7172fb9c62cdaf305be16ba.png)

　　**妥善保管行李**

　　回家路上保管好个人行李同样重要，将个人财物放置在视野可见的范围内，方便自己随时看管，重要钱包行李，可携带小包贴身存放。【行李看管须谨慎，不可掉以轻心】

　　![](../Images/2e07a40a9b052c9380784c44449f0d14.png)

　　**切勿泄露信息**

　　在回家路上，总难免一个人孤单在路上，在回家途中遇到陌生人，可以适当的交谈，但是切勿过多的泄露个人信息、提高警惕和防备心理。【害人之心不可有，防人之心不可无】

　　![](../Images/2e53432b0fe173d8d3fb9e36dba84512.png)

　　**问路技巧必知**

　　当迷路了，亦或是找不到目的的时候，一定不要慌张保持镇定，找车站工作人员、服务台、交警、志愿者、拨打付费求助热线、问路人。【特别是问路人要有自己的判断】

　　![](../Images/a0f5b262fe837c252717756ade05d8cd.png)

　　**突发情况处理**

　　路上难免遇到突发情况，可以适当的向身边人求助，向服务台求助，向安保人员求助，向警察求助，虽然陌路人多，但是乐于助人者同样多。【突发状况切勿过分急躁须冷静】

　　![](../Images/bdbe70fd599e93949b61733aeca68320.png)

祝愿路上的人，平平安安到家，快快乐乐过年,新年快乐！
