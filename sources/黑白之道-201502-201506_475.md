# 网络云存储（云盘） 谁与争锋 谁才是心目中的王者？

人们随着时代的变迁，网盘除了充当个人数据的存储备份器之外，其文件分享功能也越显重要。如今，我们对网盘文件分享的要求也越来越多元化。究竟谁能满足挑剔的我们，先来看一组直观的对比图。

容量小课堂：1T=1024G ，1G=1024M

**百度云盘**

内存:

百度云网盘一般可以免费的扩充到2T左右的大小，更进一步的话，就要看百度云盘有没有更多的优惠了。不过一般2T对我而言是够用了，如果不够用，多注册几个网盘账号就行了。

![](../Images/10234da447fc38977e4c9e23610cf35b.png)

资源共享：

可以通过公开连接，以及私密链接的方式分享资源。不过就资源的公开分享以及搜索来看，百度网盘更优一些。因为百度网盘提供了网盘的搜索引擎，可以帮助我们搜索其他网盘用户共享的文件。如下图所示：

![](../Images/dd33cc60a6acef642ec62768599d5cad.png)

仅仅是有一个登陆密码，并未提供文件保护的其他措施；如果就我们从电脑上上传的重要资料，可以通过压缩软件给文件多设置一个密码。

特色：

除了与网盘有所关联的联系人、短信、图片自动同步功能之外，百度云还提供找回手机、视频播放、好友关注、热门资源分享等多元化服务。支持压缩包在线查看、网盘视频在线播放、BT离线下载。

**360云盘**

内存：

基本上可以免费扩容到20T以上，每天还可以抽取免费的云盘空间等等。

就云盘的免费扩充容量来看，360云盘更好一点。

![](../Images/e6e2fbdd9af37bb4b851b42a5da85cd6.png)

速度：

上传与下载的速度：老实的说个人认为差别不大，不过这方面百度网盘目测要好一些。当然这个和我们自身的网速有比较大的关系。（这个需要根据大家自己的实际使用情况而定）

安全性：

360网盘的安全性要更高一些，因为对于想存入网盘的重要资源，可以设置一个文件保险箱。我们再设置一个独立的文件获取密码。

![](../Images/978923c02b0f9d65183bec526842d1b6.png)

**腾讯微云**

内存：10T

命名：

在产品命名上都使用了比网盘更高规格的“云”。而事实上，网盘仅仅是腾讯微云三大功能的其中之一而已。

特色：

微云还支持不同设备之间相册同步，以及同一WIFI网络下的文件快速传输。 支持多文件共享、二维码下载，无需登录即可下载、清爽的下载界面，一个不少。深度整合腾讯QQ，QQ邮箱附件、QQ文件传输能一键保存到微云上。

![](../Images/d37f672a555b5ed455e2ab17cfabaa7d.png)

不足：

但市场占有率太低，用的人没几个。虽然亲爹是富可敌国的腾讯，但这也掩盖不了这个残酷的事实。在存在感这方面，微云还需继续努力，怒刷存在感！

**新浪微盘**

特色功能

围绕文件传输/同步而开展的。支持WIFI环境下图片、视频的自动备份；通讯录的手动上传下载。同时，微盘还提供WIFI传输功能，方便不同设备在同一WIFI下进行快速文件传输，与快牙之类的传输工具有点相似。深度整合微博，微博私信文件自动保存，指定微博好友分享。支持私信文件自动保存到微盘、定时发送、分享给指定好友、链接加密等功能还是值得我们给予肯定的。

![](../Images/ac130930487bea19cd8f38f7d9349cdd.png)

不足：

撇除不支持文件夹共享之外，其登录才可下载、以及诱导性的下载文件发送微博的行为十分令人发指。同时，偶尔还会出现外链失效以及文件无法创建外链的问题。要是你曾出现过分享文件失败，不妨试试重命名再分享，因为微盘对于部分带有和谐字眼的文件是有分享限制的。

**结语：**百度云、腾讯微云、新浪微盘、360云盘这几款产品的特点已经凸出，相信经常使用网盘的人对这几款产品也有了深入的了解，通过以上的对比，我们可以发现，百度云可谓是个不折不扣的优等生，综合实力出色，各方面表现均衡。

因此，小编个人认为：百度云>腾讯微云>新浪微盘>360云盘，小伙伴你们觉得呢？
