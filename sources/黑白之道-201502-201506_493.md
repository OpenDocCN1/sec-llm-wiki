# 微软将向“树莓派”提供免费Win10

腾讯科技讯 在物联网大潮中，出现了一类专门充当物联网设备“大脑”的袖珍电脑或板卡电脑，比如英国的RaspberryPi（以下称“Pi”），以及英特尔公司的“爱迪生”和“伽利略”。这些电脑也需要运行操作系统。而日前，微软作出宣布，将面向Pi提供免费版的Windows10。

这被认为是微软提前布局物联网大潮的一个重大举措。

从外观上看，Pi很像传统电脑攒机时代的一个外插板卡。不过它其实是一台完整的电脑。在最新版的Pi中，处理器性能翻了四倍，搭载了1GB内存，增加了多个USB接口，售价仍然保持35美元。

据报道，之前Pi电脑主要使用了Linux和其他开源操作系统。而在最新版硬件发布之后，微软宣布，将面向Pi提供免费版的Windows10操作系统。

Windows是一个闭源操作系统，不过最近几年，微软开始和开源业务改善关系，微软将多个知名的开源应用软件，整合到了Windows系统中，另外微软一部分软件也转为了开源软件。

通过面向Pi电脑提供免费操作系统，微软将和广大的硬件开发爱好者，建立更紧密联系。

据悉，Pi电脑最早诞生于2012年，最后这种袖珍电脑已经成为许多智能设备和物联网设备的“大脑”，从无人机到啤酒发酵系统，到超级计算机，都有Pi的身影。

媒体称，微软如今希望参与到这场Pi带来的“迷你革命”中，并期待带来更大的创新和进步。

另外一家提前布局物联网的英特尔公司，也面向物联网设备推出了袖珍电脑和板卡电脑。在今年的拉斯维加斯消费电子展上，英特尔展示了新一代的“居里”电脑，仅有拇指大小，却具备了电脑完整功能。

在智能手机和平板电脑逐渐普及之后，科技行业已经掀起了物联网和穿戴设备的大潮，其中谷歌(微博)收购的Nest，成为行业先锋企业。

据分析，微软已经意识到，在未来物联网设备的开发中，来自草根的硬件发烧友和开发者，将扮演重要角色，微软也希望他们开发的物联网产品，能够使用Windows10系统。

实际上在去年四月份，微软已经宣布了“物联网Windows计划”，即面向屏幕小于9英寸的智能设备，提供免费Windows系统。而在去年八月份，微软已经向英特尔另外一款板卡电脑“伽利略”（酷似Pi），提供了免费操作系统。

不过需要指出的是，虽然微软提供免费的操作系统，但是微软并未提供系统源代码。目前，微软免费Windows面向物联网设备的授权协议尚不得而知，不过科技媒体预测，微软Windows可能会推出多个版本，支持不同类型的物联网硬件。
