# 另一个OS X提权漏洞

　　如果你正使用OS X Yosemite,请看一下这篇文章,恶意软件利用了一个新的方式来控制你的Mac。

　　在苹果的操作系统中已经发现了一个漏洞,该漏洞可以在没有主人许可的情况下让电脑上的普通软件获得root权限,允许可疑的应用程序安装新程序,创建用户,删除用户,垃圾文件消耗系统空间等操作。

　　一位18岁的意大利人Luca Todesco本周在推特上放出了该漏洞的详细信息,例如利用程序的代码,以及临时解决方案。

　　在OS X 10.9.5到10.10.5版本中都存在该漏洞。还在公测中的OS X El Capitan,又名OS X 10.11中,没有相同的编程错误。

　　这个安全漏洞的核心实际上是两个问题结合在了一起,通过利用IOKitLib中使正常的应用程序访问设备的一个接口。

　　根据Todesco的描述,如果你调用库中的IOServiceOpen函数使用了无效的owningTask参数,一个内核级的IOUserClient将传递一个空指针来调用任务。这个指针通过操作系统进行操作,并用于在内存中寻找一个设置了一个bit的变量。通过控制在地址为0的内存页,攻击者可以知道这些bit设置的位置,从而操作内核内存,并最终获取到完整内核级权限执行的控制权。

　　“这并不是世界上最难找到的bug。”Todesco补充道。

　　这是在10.10.4上的情况,但10.10.5也没什么不同。pic.twitter.com/dFTiTcUm06

　　——Luca Todesco (@qwertyoruiop) 2015年8月15日。

　　Todesco说他将bug报告给了苹果的工程师,并在上周日将漏洞利用代码上传到Github上进行公开,因为他觉得不得不这样做。

　　“我曾在一篇博客文章中隐晦的公开它。我报告给苹果只是因为,你应该知道,苹果可能根本没注意我的文章。”他说,“如果不是不得不公开,我会一直等到10.11。但因为已经有坏家伙开始利用\[本地权限提升漏洞\]。”

　　该安全漏洞还没有补丁存在,除非升级到OS X El Capitan。仍使用Yosemite的Mac用户将不得不确保他们运行的是拥有唯一信任签名的应用程序,并且祈祷没有人他们的机器进行远程代码执行。如果多个用户共用一台机器,其中任何一个用户都可以利用这个漏洞来获得管理员级控制权限。

　　Todesco也发布了一个名为NULLguard的内核扩展,它可以停止应用程序,使用零页面——进而停止程序,它可以利用该漏洞,但现在建议人们安装Stefan Esser的SUIDGuard,功能正好相反。

　　IOKitLib缺陷出现后不久,苹果修复了同样存在于OS X Yosemite中的DYLD\_PRINT\_TO\_FILE权限提升漏洞。
