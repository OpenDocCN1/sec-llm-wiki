# **二、《Graphic Content Ahead: Towards Automated Scalable Analysis of Graphical Images Embedded in Malware》**

# **三、《Internet Scale File Analysis》**

**公司**：Novetta

**技术**：恶意文件分析系统 ＋ 大规模静态分析 ＋ hypervisor level 动态分析

**亮点**：

技术现状：恶意文件的主动检测靠二进制分析技术， 恶意文件的防御主要靠签名

攻击现状：恶意文件增长快，投放场景复杂

提出的解决方案：

动态沙箱分析＋静态逆向分析＋集成第三方工具（Cuckoo, Drakvuf, PEInfo, VirusTotal, Yara… 这也算情报聚合) ＋机器学习
