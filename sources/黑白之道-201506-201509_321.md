# 从2.5英里外匿名访问Wi-Fi，屌炸天

匿名在这个被政府监管的时代看起来似乎已经是不可能的事情了。甚至Tor和VPN都不再足够保护用户隐私。一旦你的IP地址被发现，你的游戏也就结束了。

然而，一种新的方法已经诞生，它不仅允许用户匿名连接到公共Wi-Fi网络，而且也可以让他们从2.5英里之外进行连接。

安全研究人员Benjamin Caudill已经开发出了一种设备，这种设备为告密者，记者，不同政见者，当然还有罪犯，提供扩展的匿名功能。

这种设备被称为“ProxyHam”，它是一个硬件代理，允许用户通过一个无法辨认的低频无线电频道连接到远程的公共Wi-Fi网络，对于政府机构和间谍来说，挖掘网络流量的真实身份和来源将变得更加困难。

**Proxyham是怎么做的?**

Proxyham由启用WiFi功能的树莓派构成，安装有3个天线。一个天线被用于连接公共场所的Wifi网络，其他两个天线用来在900MHz的频率传输Wi-Fi信号。

通过一个900MHz的无线电连接，ProxyHam有效的连接到一个远距离Wi-Fi，可以在1到2.5英里的距离之间，这取决于某些因素的干扰。

因此，如果间谍设法完全跟踪目标的网络连接，他们只会发现ProxyHam在某一方向发送的低空无线电信号中的几千英尺之外的IP地址。

Caudill告诉Motherboard，他和他的同事也正在增加额外的功能，如可自我毁灭的ProxyHam。未来它可能足够小，甚至能够将Proxyham 伪造成一本书，使其更便于隐藏。

Caudill说：“如果你把它带到图书馆，它会让你耗费几年时间将它识别出来”。

Caudill会在下个月在拉斯维加斯举行的Defcon上推出这个改变游戏的ProxyHam。他也会放出设备的硬件规格，源代码和设计蓝图，因此任何人都可以开发出自己的设备。

Caudill计划以200美元的价格出售ProxyHam，“作为对社区的服务”，他也希望他能够很快将价格降到150美元。
