这节课来教大家在kali下安装中文的输入法，因为在新安装的kali下是没有中文输入法的，想必安装了kali的同学都有体会

　　使用到的命令：

　　apt-get install fcitx fcitx-pinyinfcitx-module-cloudpinyin fcitx-googlepinyin h

　　im-config

　　在这之前，我们首先要更新一下kali的下载源。不然的话在安装输入法的时候会提示缺少很多东西的,无法安装选下去

　　源的路径：

　　/etc/apt/sources.list

　　找到源文件之后我们需要用vi编辑器编译一下

　　Vi编辑器的使用方法：

　　Vi sources.list，按一下insert键，进入编辑模式

　　然后将你所要添加进去的源的链接加进去(看操作)

　　加完之后按一下esc键，接着同时按住“shift” +“：” ，输入wq就会编辑完成保存退出

　　接着运行一下

　　apt-get update && apt-get dist-upgrade

　　到这里，我们源更新的步骤就算是完成了，接下来就到了安装输入法的环节了

　　输入命令

　　apt-get install fcitx fcitx-pinyin fcitx-module-cloudpinyinfcitx-googlepinyin

　　进行下载安装输入法(敲命令的时候一定要小心，我这键盘因为字母全磨没了，所以有时候打错了不知不觉)

　　下载安装之后你可以使用

　　im-config

　　进行设置，也可以在图形化界面设置，具体的看操作

　　重启一下看看效果。Ok了
