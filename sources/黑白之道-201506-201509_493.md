# 美陆军网站当地时间8日1点遭黑客入侵

　　“叙利亚电子军”当天在推特上表示，该组织袭击了美陆军网站(army.mil。)，还把该网站用户的电邮地址和个人信息发布在推特上。有截屏显示，“叙利亚政府军”使用英语在美陆军网站上留言。留言内容包含多处语法错误，大意可理解为“你们的指挥官已经承认他们在训练武装人员，他们在让你们送死”。

　　“叙利亚电子军”是一个支持叙政府的黑客组织，此前曾多次入侵《纽约时报》、美联社、英国广播公司等媒体的网站。该组织最早于2011年5月进入公众视线。该组织自称由叙利亚年轻人自发组成，与叙政府无关。

　　在发动针对美陆军网站的袭击后，“叙利亚电子军”当天接受了一家IT网站的采访。当被问及发动此次网络攻击的目的时，“叙利亚电子军”回复称，“因为美军在土耳其训练‘恐怖分子’。”

　　美军自今年1月起在土耳其、沙特、卡塔尔等国训练叙反对派武装。美军表示，这批人员一方面可以用以对抗“伊斯兰国”武装，另一方面可以向叙政府军施压。而在叙政府看来，反对派武装等同于“恐怖分子”。

　　美陆军发言人弗罗斯特8日发表声明证实，美陆军网站确遭入侵。他表示，军方已经采取措施，确保信息安全。

　　截至当天下午5时，遇袭的美陆军网站仍未恢复正常。
