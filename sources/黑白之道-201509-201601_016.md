# Win系统数据自动备份云同方案

 服务器数据要定期备份，很多都知道，但没几人会做，数据备份就是后悔药，当数据出错，被黑客入侵，被人删除， 这颗后悔药起大作用。  

 本文，主要内容，windows系统下自动备份数据，本地保存一份，上传到云盘一份，本地与异地都有数据，这样如果出错，可以下载还原。

**正文：** 

 前段时间，受够了每天去服务器上一遍一遍拖拽东西然后上传到网盘上去，因为作为一个网管，每天要查看很多东西。所以，要是能够减轻工作量节省时间是一件很有必要的事情。于是，今天就把前不久弄出来的一些简单的方法跟大伙分享一下

  

　　首先，我们要先安装一个备份软件-------apbackup，这个软件网上有破解版的(当然土豪是可以忽略破解二字滴)

  

　　在这里我使用的破解版的，下载好破解版的apbackup压缩包后直接解压找到主程序就可以运行了

　　

![](../Images/bb5e103ddfb195bc5b618caf3f569557.png)

　　接下来我们来设置备份的文件，关掉界面的提示之后，点击“new”，然后点“next”，在comment处输入备注，这里我就写test吧，其他的看你自己的需求，这里我就选“压缩文件—archive files”

　　

![](../Images/decd5a84a7c3bef69f7778af24d3fd9d.png)

　　完了“next”

　　

![](../Images/aecac53cf1c95b50057b4fbc52670923.png)

　　看到这里，两个路径需要注意一下，上面的“包括文件”指的是要备份的文件或者文件夹的路径，下面的“排出文件”就不用我多说了吧

  

　　这里需要注意一下，不能直接点“add”，那样是无效的，必须先单击“add”，然后再ok才能加上选中的文件夹

　　

![](../Images/3887caf9bf8bda7edcfc4e0b11c5993f.png)

　　

![](../Images/dec1609da074635287977727227e2226.png)

　　完了添加上以后就会有这样的显示

　　

![](../Images/9108ea4fb62d4ffb3777f676a27e0929.png)

　　

![](../Images/93f4db75871a1f1a7a5644039d699f95.png)

　　这里要备份的目录文件就设置好了，剩下的排出文件就不多说了，操作是一样的，接着“next”

  

　　出现下面的界面

　　

![](../Images/a17fd57916d810aeeecb84695b8a3629.png)

　　这里“压缩文件夹”是设置文件压缩后放置的地方，选好路径就好了，然后就是那个文件夹前缀，自行根据文件的标识或者习惯来吧，这里不多说，设置好了就“next”

　　

![](../Images/cc6aa5d2258d4046b3ac9530648abc19.png)

　　这个相信大家一看就明白，是设置备份的周期，有按天算的，有按周算的，按月算的等等，这里我就设置within weeks(每周一次吧)，“next”，会要求我们设置在每周固定一天启用备份，这里我就默认了

　　

![](../Images/f0dc4dc2170788a08d8d0258b0e07d31.png)

　　接着还是“next”，然后“done”，但是别点“ok”，我们选中我图中标注的位置，出现下面的界面

　　

![](../Images/499cc9a0a4738d1cbee6a7119bb605de.png)

　　我这里是想在备份压缩完成之后让他运行一个批处理，让他完成把备份文件copy到我定义的自动上传的文件夹去(我这里定义的文件夹是E:\\upload)，选中“run application”，然后把“@echo off

  

　　if exist E:\\upload\\\*.zip (del E:\\upload\\\*.zip && copy E:\\web-backup\\\*.zip E:\\upload) else copy E:\\web-backup\\\*.zip E:\\upload”这个写到记事本里另存为test.bat。接着把批处理的路径填好，如图

　　

![](../Images/3aca9b83c7eb8d51e06a7d92bbd2e5a8.png)

　　然后呢，我们再给他加一个发送邮件提醒的功能，作用是每次备份拷贝完成之后发一封邮件给我们，说完事啦，如果我们收到右键，说明备份完成了，要是没有收到，说明出问题了，得上去查看一下是什么状况

  

　　依然是最下面的左边，有一个“notifications”，我们选中它，出现下面的界面

　　

![](../Images/9fb46b207dfa2698572b990c6ae79601.png)

　　我习惯邮件提醒方式，设置如下：

　　

![](../Images/1bcf7b91211dacb4312254dbc31fee56.png)

　　然后“ok”，软件的设置就到这里了，接下来就是设置自动上传了，现在免费的支持自动上传的网盘太多了，我就已百度网盘为例(百度网盘的安装就不说了，相信大家的智商都正常)，登录百度云管家

　　

![](../Images/cf997f9b7cbf68a80773f57bce9c13da.png)

　　看到箭头的地方，选中它

　　

![](../Images/f4f469c13bcab9736037bafed615d562.png)

　　选择“手动添加文件夹”，所以我现在把E:\\upload这个文件夹加上,选择备份到云端，这个时候云盘会提醒你在云端的存储路径，新建一个文件夹，我这里就设置为test(1)吧

　　

![](../Images/764d978a06e826019b9b5b03c04a55ba.png)

　　最后，确定一下。整个设置部分就完事了，我们来测试一下吧，现在我的云盘test(1)是空的，同时e:\\upload和e:\\web-backup也是空的，我们回到apbackup这个软件的界面，选中我们刚才建立的任务

　　

![](../Images/e2e5f0fd7e440c4e58da1a3af4c4f628.png)

　　

![](../Images/5221aaec697d1ede267bc07417e279b5.png)

　　选择执行，看结果

　　

![](../Images/84a462a5f60a9781729dbf5f0ccc7c15.png)

　　

![](../Images/db9fca4bb577bab7e8f3d8c276b7cb6a.png)

　　

![](../Images/019bb2b8ae40086257a97d91d1335368.png)

　　

![](../Images/c2a4f20d8935fa1d6a27636820f706fb.png)

　　突然想到如果服务器关机重启了那个这个备份软件不是不会跑起来么，那给注册成服务就可以。

  

华盟网最后重点提示，打包备份上传，注意给rar文件加个密码，如果被别人支持下载之后，没有解压密码，也不能盗走你的数据。

  

　　然后确定，这样，这个简单的自动备份教程到这里就算是结束了。
