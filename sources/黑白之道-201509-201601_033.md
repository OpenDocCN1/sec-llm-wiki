　　Armitage是一款Java写的Metasploit图形界面的攻击软件，可以用它结合Metasploit已知的exploit来针对存在的漏洞自动化攻击。bt5、kali linx 下集成免费版本Armitage，Cobalt Strike是它的商业版本，乃们懂得，图形界面非常友好，一键傻瓜化使用MSF高级功能，自动攻击测试。

  

  

　　本文针对Cobalt Strike 3.0或者最新版本!环境为Kali 2.0

  

　　Cobalt Strike的下载地址用的是之前文章分享的文件，大家也可到官网下!

  

　　戳这里:Cobalt Strike

  

　　下载到一个cobaltstrike 3.1原版文件里面有三个文件

  

　　你可以得到一个cobaltstrike-trial.tgz文件

　　![](../Images/40f93ba1a262a8ba27c95bd25b552eaa.png)

  

　　解压后的文件如图所示

　　![](../Images/e99e405fa61f0ff0dfd05af29dd1f201.png)

  

　　在root目录下创建一个名为cobaltstrike的文件夹，把cobaltstrike.jar 右键提取到cobaltstrike文件夹去!

  

　　进入cobaltstrike文件夹，再进入common文件夹

  

　　jad License.class

　　![](../Images/3c454b283897c0f80fe4fb2b58207b34.png)

  

　　找到图中的21L 修改成99999天，或者一个你输入数字的天数

　　gedit License.jad

  

　　![](../Images/698ae2d3eb806a3d2abfef1c70aea0f5.png)

  

```
mv License.jad License.java
javac \-classpath ../ License.java
cp License.class /root/

Desktop
```

　　然后把桌面上的License.class的文件放进cobaltstrike.jar下的common文件夹去，注意查看修改时间和其他不同即可 。

  

　　回到cobaltstrike文件夹下，终端执行

```
./teamserver 192.168.1.9 

密码
```

　　![](../Images/5e5975133b680747c156fd0176ec58d4.png)

  

　　之后输入密码确认就可以使用了，在帮助里可以看见这是一个试用版，但是使用时间是99999天

  

　　![](../Images/9b89d2d2744a7d73a5fee2cc88062488.png)
