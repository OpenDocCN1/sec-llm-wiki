在网上找了一些在Linux下安装zabbix客户端的教程，都是用源码安装，比较繁琐，还要安装一大堆的依赖安装包。我发现其实yum也是可以直接安装，而且非常方便，下面跟大家分享一下Centos 下yum安装zabbix-agen客户端的方法。

　　**(1)安装zabbix客户端软件**

 先添加一个zabbix的官方yum源

rpm -ivh http://repo.zabbix.com/zabbix/2.4/rhel/6/x86\_64/zabbix-release-2.4-1.el6.noarch.rpm

　　yum install zabbix-agent

　**　(2)在客户端上添加zabbix的监控端口**

　　vim /etc/services

　　添加如下内容

　　zabbix\_agent 10050/tcp

　　zabbix\_agent 10050/udp

　　保存退出!

　　**(3)修改客户端配置文件**

　　vim /etc/zabbix/zabbix\_server.conf

　　修改以下几项

　　Server = zabbix服务器IP

　　Hostnae= 本机的主机名

　　**(4)启动zabbix客户端并添加开机自启动**

　　service zabbix\_agentd start #启动zabbix客户端

　　echo "service zabbix\_agentd start" >>/etc/rc.local #开机自启动

　**　(5)查看进程，确实zabbix客户端是否启动**

　　ps -ef | grep zabbix

![](../Images/43cdd8b41f41e49489aae2aba1840cc9.png)  
  
　　可以看到6个zabbix进程，说明客户端安装完成，启动成功。

　　关于zabbix 在linux客户端上安装就完成了，有问题还请大家提出，一起学习，一起交流。
