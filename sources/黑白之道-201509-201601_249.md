# 简单制作Windows 10安装U盘

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=400291228&idx=3&sn=a921495e01ee4e0939c4c478e93180f5&chksm=099a90783eed196ed712287e03e62ab54b3ca0058c05d8cad57dadae9dcf96a134564ca1ce39&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=400291228&idx=3&sn=a921495e01ee4e0939c4c478e93180f5&chksm=099a90783eed196ed712287e03e62ab54b3ca0058c05d8cad57dadae9dcf96a134564ca1ce39&scene=27#wechat_redirect)

  

至 Windows 10 发布以来，很多网友都选择了升级安装的方式进行安装，但我个人比较喜欢全新安装的方式。由于光驱已经逐步退出历史舞台，微软从发布 Windows 10 时开始也不再提供安装光盘。因此，我们只能通过自制 Windows 10 安装U盘的方式来进行全新安装。

从系统长期运行的稳定性和兼容性来考虑，我个人也比较建议大家首选采用全新安装方式来安装。把话说回来，当系统故障之后你不太可能安装老版本，再升级到 Windows 10 吧。因此，手上备一个 Windows 10 安装U盘可以应付不时之需。

在本文中，我们将介绍使用微软官方的 Media Create Tool 镜像制作工具及第三方的 Rufus 工具两种方式来详细介绍 Windows 10 安装 U 盘的制作说明，通过工具制作出的 U 盘还能够支持 GPT 分区。

## Media Creator Tool工具制作Windows 10安装U盘

1\. 下载 Windows 10 Media Creator Tool U盘镜像制作工具

Media Creator Tool 32位   
http://go.microsoft.com/fwlink/?LinkId=616935Media Creator Tool 64 位  
http://go.microsoft.com/fwlink/?LinkId=616936  
2\. 打开下载好的 Media Creator Tool 工具选择 **为另一台电脑创建安装介质 **后点击** 下一步**

![](../Images/3702966b2ae2221e70a5053d742afd68.png "Media Creator Tool")

3\. 在此步中我们需要选择系统镜像的**语言**和 **Win 10版本**，还需要选择好要制作的 Windows 10 U盘是32位还是64位，当然也可以直接选择32及64位集成镜像。

![](../Images/c04d67bfb0d9dce47e2ae9bb46d263ec.png "Media Creator Tool")

4\. 在此步骤中，我们需要选择是制作 U 盘（直接制作）还是只下载 ISO 光盘镜像（以后制作），如果是直接制作的话，我们必需插入一个至少大于 4 GB 的 U 盘。

![](../Images/995905fb0db18d4291b06b1282be553d.png "Media Creator Tool")

注意：虽然工具写的 U 盘必需大于 3GB，其实光 3GB 是不够的。

5\. U 盘插入之后点击 **下一步**，确认 U 盘的盘符正确之后再点击 **下一步** 开始制作

![](../Images/b1a3f2a5c2b800f099074d8b519e5259.png "Media Creator Tool")

## 创建支持UEFI BIOS的Windows 10安装U盘

如果你的电脑使用的是 UEFI 引导方式，用微软官方工具制作的 U 盘直接引导可能会遇到安装 Windows 10 的问题。因此，我们建议使用其它专业工具来制作安装 U 盘。我推荐的就是大名鼎鼎的 **Rufus**，该工具是可以帮助我们制作支持 MBR 或 GPT 分区引导 U 盘的免费工具。

1\. 先到官网下载最新版本 Rufus

Rufus 官网下载

2\. 将要制作的 U 盘插入电脑

3\. 在**分区方案和目标系统类型**选项中选择**用于UEFI计算机的GPT分区方案**，**文件系统** 选择 **NTFS**

4\. 点击光盘图标选择好 Windows 10 的光盘镜像文件

![](../Images/0dd87ca46c1794215b26d0e7f60d007c.png "Rufus")

5\. 点击 **开始** 按钮进行制作

制作过程完成后，就可以用该 U 盘去 UEFI BIOS 的计算机上安装 Windows 10 了。
