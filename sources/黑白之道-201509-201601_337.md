# 网易邮箱样本新鲜程度高(80%)，互联网出大事了

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=400033003&idx=2&sn=2f3d1614d2475469e6cf2f7f678bf167&chksm=0999610f3eeee819b1fc4a626162ca9b38c0f2a20533c0fd06deb30d4bf8512a1c9efe6115d1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=400033003&idx=2&sn=2f3d1614d2475469e6cf2f7f678bf167&chksm=0999610f3eeee819b1fc4a626162ca9b38c0f2a20533c0fd06deb30d4bf8512a1c9efe6115d1&scene=27#wechat_redirect)

根据样本的新鲜程度，可以确定出大事了：“又有用户量大的公司被脱裤！”   
  
乌云上披露的数据文件显示有50GB，其中路人甲给出了100个用户邮箱的样本，统计分析结果显示，这100个人中仅有21个人的邮箱在密码泄露历史（12亿条）中出现过，也就是说另外80%的用户信息来历不明，由此是否可推测，要么网易自身被骇客脱裤，要么有新的大公司(用户量上亿)被脱裤？   
  
100个邮箱泄露的样本大小为13KB，泄露数据50GB(压缩文件)，大概的用户量接近4亿。   
平均每KB：100/13=7.6人，用户数：50GB = 52428800KB ，50GB \* 7.6 = 398458880(4亿)   
  
通过乌云官方微博给出的信息，在google上搜索到 site:pastebin.com 163 mail 一份样本，与 互联网已泄露的12亿条公开数据 进行关联性匹配分析，发现这批样本数据与已泄露的数据交叉耦合度非常低，按照黑产的话说：“价值很高，新鲜度很高”！
