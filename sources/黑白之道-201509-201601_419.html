　　BackBox

　　BackBox是基于Ubuntu的发行，它被开发用于网络渗透测试及安全评估。它设计得十分快捷且易于使用。它提供了一份最低纲领的但完整的桌面环境，而这得益于它自己的软件仓库，该仓库总是同步到最新版本的、最常用且以合乎道德而闻名的测试工具。

　　新版更新内容

· 预装的Linux 3.16内核
· 基于Ubuntu 14.04.2封装
· Ruby2.1
· 使用LVM和全磁盘加密选项安装
· Thunar自定义操作方便
· 关机/重启内存擦除
· 系统改进
· 上游元件
· 错误更正
· 性能提升
· 改进的匿名模式
· ARM体系结构的倾向（armhf Debian软件包）
· backbox云平台的倾向

　　新更新的黑客工具：beef-project, btscanner, dirs3arch, metasploit-framework, ophcrack, setoolkit, tor, weevely, wpscan,等。

　　系统要求

· 32位或64位处理器
· 512 MB内存（RAM）
· 6GB的磁盘空间安装
· 图形卡800×600分辨率
· DVD-ROM驱动器或USB端口（2 GB）

　　升级指令

　　从以前的版本升级(backbox linux 4.x)请遵循这些指示：

sudo apt-get update
sudo apt-get dist-upgrade
sudo apt-get install -f
sudo apt-get install linux-image-generic-lts-utopic linux-headers-generic-lts-utopic linux-signed-image-generic-lts-utopic
sudo apt-get purge ri1.9.1 ruby1.9.1 ruby1.9.3 bundler
sudo gem cleanup
sudo rm -rf /var/lib/gems/1.*
sudo apt-get install backbox-default-settings backbox-desktop backbox-tools --reinstall
sudo apt-get install beef-project metasploit-framework whatweb wpscan setoolkit --reinstall
sudo apt-get autoremove --purge

　　最后，backbox linux采用一贯的小巧最快。最大亮点目录爆破dirs3arch工具，以往的发行版都没有的提及功能。
