# 误删了手机里的照片如何恢复？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=402539628&idx=4&sn=62f8247d4ceeebe6a00dab54f9f92bec&chksm=09bf21883ec8a89e4f3255d3fa74007fbb245ee3ae5d14562b67b5d5fb5c17ed09e716f958dc&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=402539628&idx=4&sn=62f8247d4ceeebe6a00dab54f9f92bec&chksm=09bf21883ec8a89e4f3255d3fa74007fbb245ee3ae5d14562b67b5d5fb5c17ed09e716f958dc&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)  

一：将手机连接到电脑，选择U盘模式或者大容量储存模式!  

 ![](../Images/2f6482bbb5b1a572c23a0603ee02512c.png)

二：手机内存或内存卡应该是以可移动磁盘的形式出现的。

三：记下你所删除文件所在的磁盘名称

四：然后打开360 在此目录下找到文件恢复，然后打开。如图：

 ![](../Images/809554f2b6af679bde519c3b8715e4d9.png)

五：出现界面后，在左上角选择你删除文件所在的储存卡。

 ![](../Images/e107f00952886ab47c0317ab15db22a4.png)

六：单击开始扫描。

七：扫描完毕后，文件就会出现在列表中。

八：点击全选。

 ![](../Images/0bee261e8a1d14c547d9891e6e26e04d.png)

九：选择恢复文件保存目录。

最后，打开你保存的文件夹，不仅仅是照片，还有其他的文件，如果只需要图片，那么就分一下类，只恢复图片文件。

  

![](../Images/359cae7a42a3076197f4e7ad28b02d1d.png)
