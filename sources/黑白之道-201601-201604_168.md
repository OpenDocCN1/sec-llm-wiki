　今天在给客户处理问题的时候，需要mysql的帐号密码，客户忘记了怎么办?在百度上搜索一下发现有七八中方法，下面我来分享一个怎么在CentOS系统找回MySQL数据库root登录密码的方法。

　　CentOS系统中忘记了mysql的登录密码,怎么办?我们可以使用安全模式进行修改密码。

　　第一步：停止mysql数据库:

　　#service mysqld stop

　　第二步：在CentOS系统继续输入:

　　#mysql -udebian-sys-maint -p

　　下面的密码直接键入回车即可.

![](../Images/7225ba6dc3b46b112219aef434c624dc.png)

　　第三步：在CentOS系统重新设置密码:

　　mysql> update mysql.user set password=password("123456") where user="root";

![](../Images/5e0a19839f67cfb0783bfbdb384888a7.png)

　　刷新权限

　　mysql>flush privileges;

　　退出

　　mysql>exit;

　　第四步：启动mysql,继续以往的登录动作即可.

　　# service mysqld start

　　# mysql -u root –p

![](../Images/3f77adad2f8bc204e8ead50bce788398.png)
