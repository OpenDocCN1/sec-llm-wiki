　　项目简介

  

　　Ranger是一个提供多种windows远程访问的工具，可以代替psexec等工具，支持多种访问模式，并且内置了多重攻击模式，并且还支持直接通过Powershell Mimikatz进行密码的dump，还能配合msf注入payload，还有内存注入等等功能等待发现,实在是内网渗透神器　　

### 模式 & 攻击:

```
--scout
--secrets-dump
```

### 模式:

```
--wmiexec
--psexec
--atexec
```

### 攻击:

```
--command
--invoker
--downloader
--executor
--domain-group-members
--local-group-members
--get-domain-membership
--get-forest-domains
--get-forest
--get-dc
--find-la-access
```
