# 社工，学校联考试卷！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=402119492&idx=1&sn=3c1d85566c54adcf46d06f368b5d80d8&chksm=09b6bea03ec137b63f4384fbbe36b64d192a3e9408b3050530ce9b896afc11c4aa0e5f36338e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=402119492&idx=1&sn=3c1d85566c54adcf46d06f368b5d80d8&chksm=09b6bea03ec137b63f4384fbbe36b64d192a3e9408b3050530ce9b896afc11c4aa0e5f36338e&scene=27#wechat_redirect)

> **故事发生在五月，至今已过去快两个月了。当时确实想写文章，但是迫于学业的紧张，还是搁置了这个想法。现在难得有空余时间，分享这次经验，希望其中一些思路对大家能有所启发。**
> 
>   
> 
> **其中的有些细节我也记不大清楚了，我会尽我所能的描写的详细一些，也望大家提出问题， 不过我虽然社工了试卷，但是没有进行交易或者有作弊的行为，这也对得起我的良心。我希望大家不要用社工去做坏事。下面开始正文，我会写的生动一点。**
> 
>   
> 
> 又是普通的一天，云淡风轻。十点多钟，正在上第三节课，是一节化学课，眼中已有些疲惫。思绪飞向了窗外，想着今天正在进行的NBA的比赛，还在幻想着我最爱的马刺捧起冠军奖杯的场景。忽然的，一阵电话铃声将我的思绪拉回了化学老师的身上。
> 
>   
> 
> 本来一个电话倒也不至于引起我多大的注意，但是这个电话明显不一样。化学老师从来没有接电话的习惯。他大多数时候通常选择看一眼就挂掉电话。而这次，他先是望向了墙上的挂钟，然后眼睛向上看（这是明显的思考的标志），又望了一眼手机屏幕，然后离开教室，接起了电话。
> 
>   
> 
> 我觉得这个电话应该是不简单的，但也只是有一个这样的想法。这时机（duo）灵（zui）的同桌突然告诉我，会不会是联考的事情？于是我突然的回想起来了，老师前几天刚和我们说的事情，说教研组正在和兄弟学校联合出卷，一段时间过后就会举行联考。  
> 
>   
> 
> 感谢同桌，我瞬间警觉了起来，于是有了这次的社工。我开始留意谈话的内容（化学老师就站在离门口不远处，可能是考虑到我们是尖刀班的学生，也没什么好遮遮掩掩的，放心的接听，声音还挺大）。谈话的具体内容我已经记不清楚了，大概如下。
> 
>   
> 
> “你好，我XX中学的X老师。您是A中学的B老师吧？”
> 
> “对没错，没想到你们就好了？”
> 
> “好的好的。这样，你发到我的邮箱吧，我下课把我的邮箱打个短信给你。”
> 
> “好的好的，辛苦了。”
> 
>   
> 
> **到此，社工才真正可以开始了。**
> 
>   
> 
> 他涉及到了邮箱这么关键的东西，我自然有了可查之处。
> 
>   
> 
> 首先我想到的是学校所谓的老师通讯录。因为在那上面有老师的详细联系方式和一些个人信息，并且每个老师都有一本，理论上来说是比较方便的。
> 
>   
> 
> 在请一同学吃了顿晚饭之后，我死乞白赖的让他把他爸（他爸是老师）的老师通讯录拿来了。翻到了化学老师那一页，果然，不出所料，果然是有邮箱的。看了看还是QQ邮箱。我加了老师QQ，开始引他上钩。这里的过程没有技术含量，我直接的借到他的QQ邮箱。
> 
>   
> 
> 没错，就是直接借到的，因为我心里知道的很清楚，他对我应该是充分信任的，虽然他问了我一句干什么，我只是很敷衍的说了句测试一下我最新的程序（我和他关系不错，他知道我对编程这块有一定的兴趣），他就给我了。
> 
> 我以为社工到这里就算结束了，谁知道上文只是小孩子过家家。
> 
>   
> 
> 兴奋的打开了他的QQ邮箱，看到了这样的画面（弄来一张图，我也是蛮拼的）：
> 
> ![](../Images/7858e9c6dbbd5b4ba621b9d5e0c92b42.png)  
> 
> 呵呵？删除了还是什么情况？翻了下垃圾箱，都是一些垃圾邮件。但是我注意到日期，还有前天的。
> 
>   
> 
> 怎么回事？不可能啊？
> 
>   
> 
> 这时我仔细想了想，到底是哪里出错了？
> 
>   
> 
> 思前想后，我觉得他不可能删除邮件，因为联考还有一段时间（后来想想这真不算什么好理由，庆幸自己的运气真是好）。
> 
>   
> 
> 抱着试一试的想法，我继续进行了社工，不过要从其他方面入手。
> 
>   
> 
> 在排除了QQ邮箱之后，我确实拙计了，一会儿想不到一个好的突破口，仔细回想了一下他们那天的电话对话之后我突然想到了一个关键的东西：
> 
>   
> 
> 手机。那种旧的手机应该有已发信息的记录。
> 
>   
> 
> 但是要从手机入手未免有点不现实。于是，非常巧合的事情发生了，第二天，我上完第二节课突然肚子疼。因为家里离学校近，我准备请假，让家长来接走。
> 
>   
> 
> 走到办公室的时候，发现班主任不在，于是只能到身为年级主任的化学老师那里请假了。这个时候，一个点子就出来了。
> 
>   
> 
> 要不借着请假的机会，看看他的手机吧？
> 
>   
> 
> 说做就做。
> 
>   
> 
> 走到他办公室，他刚上完课回来，我问他借手机，他稍微询问了一下我的情况就借给我了，去洗手间洗掉手上的粉笔灰。天助我也。
> 
>   
> 
> 我很快的找到短信功能，果然有已发信息这个选项，我赶快打开。
> 
>   
> 
> 往下翻，果然没有删除。赶快打开那条信息，一个网易邮箱的地址映入眼帘。快速的背下邮箱地址，邮箱Get成功，离成功又近了一步!
> 
>   
> 
> 虽然是去看医生了，但是一个问题开始困扰我：邮箱虽然知道了，但是密码该怎么得到？
> 
>   
> 
>   想要和第一次一样直接问显然不现实，入侵他的电脑或者学校的听起来是个不错的主意，但我明显没有这方面的技能。只能靠猜了吗？
> 
>   
> 
>   忍着剧痛，思前想后，还是猜一下靠谱一点。实在不行再想其他的办法。
> 
>   
> 
>   回到家已经下午了，鉴于身体情况和下午的课并不太重要，我一个人留在了家里休息。
> 
>   
> 
>   我拿出一张纸，写下了那个邮箱地址，进行分析。
> 
>   
> 
>  \*\*\*\*（学校缩写）\*\*\*\*（我们这个地方的座机区号）@163.com
> 
>  
> 
>  诶？怎么，有点眼熟的感觉啊？
> 
>   
> 
>   我躺在床上仔细回想起来，想想我在那个地方看过这个邮箱或者是@163.com前面的内容。
> 
>   
> 
>   好像是一本书？？
> 
>   
> 
>   我突然想起来了，到床边的书桌上看着那一堆下学期要用的我用来预习的课本（大多数是老师给的），想了一会，翻开了某一本化学书（下图拍摄于写文章的晚上）
> 
>   
> 
>   
> 
> 这里的用户名就是邮箱的前缀，会不会密码也恰巧是？
> 
>   
> 
>   怀着试一试的心情，我尝试了一下这个密码。
> 
>   
> 
>   密码错误。
> 
>   
> 
>   我懵了。
> 
>   
> 
> 这下怎么办？一时想不出另外的办法，只能再次猜解。
> 
>   
> 
>   不过这次我将注意力放在了这本书上，开始分析这里的密码。
> 
>   
> 
>   这是一个很普通的结构，一眼就能看出是某个人的生日。
> 
>   
> 
>   仔细看了看，哟，这不是化学老师的生日吗？
> 
>   
> 
>   突然我又回想起来老师的QQ邮箱密码：\*\*\*（他女儿的名字缩写）\*\*\*\*\*\*（她女儿的生日）（这些信息是我从喜欢八卦的同学那边了解的）
> 
>   
> 
> 于是我有一个大胆的猜想：
> 
>   
> 
> ** 他会不会很喜欢用日期做密码？**
> 
>   心头活泛了起来，考虑到这是学校方面的邮箱，我找出了一本关于学校的宣传册。
> 
>   
> 
>   找到建校日（我们这所高中是百年老校），当做密码，输入到邮箱的密码框。
> 
>   
> 
>   错误。
> 
>   
> 
>   前面加上\*\*\*\*(学校名称的缩写)之后：
> 
>   
> 
> ![](../Images/4c34fd503ed58c2863b8ccc37a636cda.png)  
> 
>   
> 
> （这两张图是我写文章的时候截的，密码没有更改）
> 
>    
> 
>  社工到此结束。
> 
>   
> 
> **小结一下：**
> 
> 这对我来说真的是一次艰难但是激动人心的社工，过程在各位看客眼里可能非常的简单，甚至没有什么技术含量，但是其中的艰辛我自己才知道，有些细节问题对我来说是很难把握的。
> 
>   
> 
> 在这次社工之中，我用到的最大的，也是最有成效的工具就是————**我宝贵的人脉资源**。**如果你注意到了，就会发现我很多事情都没有费很大的气力，甚至有别人帮我代劳。**
> 
>   
> 
> 这次社工其中的思路希望各位能够自己领悟，什么都要人点拨，始终是学不到什么东西的。社工这东西，最主要还是脑力游戏，只要你想法够大胆新奇巧妙而又不失现实性，那么你很可能就找到了一条社工的捷径，所以各位，**不要总是使用其他人用烂了的思路，试着自己开拓新的方法，这样，就算你失败了，你也会有其他人没有的收获。**
