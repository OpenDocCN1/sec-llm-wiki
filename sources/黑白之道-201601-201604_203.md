# 美国监狱新趋势 - 学编程

　　今天，微博帐号@王威廉 一条关于美国圣昆丁监狱的囚犯积极学习编程技能的微博受到关注：**这些罪犯在狱中学习编程后，没有一人因再次犯罪重返监狱。**不过编程真的能让罪犯们迷途知返吗?看看这项监狱编程课程创始团队成员James Cavitt在TED上是怎么说的：

![](../Images/b3f0a3013823eee7bb9b8c7948055bc8.png)

　　六年前，我第一次来到圣昆廷州立监狱。我从来没进过这种地方，更别提这个臭名昭著的圣昆廷了。

　　我穿过了一道道门禁，才终于来到了监狱的核心区域。在我左边是关押加州最难管教的死刑犯人的整治中心，我右边是天主教堂，被精心照料的花园围绕着。我，站在圣昆廷，彷佛站在天堂与地狱的分界线上。

　　**太阳缓缓下山，我走在精心铺就的路上，路过警卫塔，走进了一个院子，院子里有数百个身着蓝色制服的犯人正在锻炼、下棋或四处晃悠。**

　　坦白地说，那时候，我真怀疑自己来错了地方。

　　我被带到一个小教室里，他们安排我在这里给犯人们讲讲商业和企业家精神。

　　当我开始演讲时，我发现听众们在认真倾听每一个字，他们没有分心，哦对了，因为监狱里没有手机。

　　**当我结束演讲时，犯人们纷纷举起手，我20分钟的演讲引发了他们长达两小时的热烈讨论，显然他们有备而来，并且致力于去学习这些能帮助他们在服刑后过上全新生活的技能。**

　　而我从未想过自己会遇到这样的情形。

　　那晚我离开监狱之后感到非常兴奋。我在一个早期的风投机构工作过许多年，我在有抱负的硅谷企业家手下干了很长时间，但是现在，我开始设想，我能否在监狱做同样的事?

　　我兴奋地告诉了我的妻子，并开始着手计划。

　　而她的第一反应却是：“我可不愿在监狱里浪费美好光阴。”

　　我劝她在下结论之前用一种更开放的方式去思考问题，并让她帮我做一些关于美国监狱的研究，再去参观一次圣昆廷，让她看看我遇见的那些犯人们。

　　研究后，我们才真正意识到监狱所面临的问题有多么严重：

　　- 从1972年到2010年，美国监狱的人数增加了700%;

　　- 世界上25%的犯罪人口被监禁在美国;

　　- 加州一年在监狱上的花费已经超过了在高等教育上的投入;

　　- 在加州，囚犯在监狱一年的花费是47,000美元;

　　- **超过67%的州囚犯都会在3年内二进宫。**

　　谁都能看出来，对于纳税者来说，把钱花到监狱是一项多么糟糕的投资。

　　如果我们能减少5%的惯犯，就能在未来的10年内节省数十亿美元。但如果什么都不做，这些问题将永远存在。

　　**2010年，我与加州刑事局、加州监狱管理局一起合作，开展了一个为期6个月的关于商业和创业的叫做“最后一英里”的项目，这个项目主要介绍我们投资实践中的一些原则和规律。**

　　我们的学生是有许多是罪名多项的犯人，还有一些重刑犯。(但是我们不面对死囚，以及对儿童犯罪的犯人。)

　　**我们的“毕业生”没有一个重返牢狱**

　　我们要求学员们根据个人的兴趣去创办一家企业，并教他们如何建立一个商业计划。在一个早期的培训班里，一名叫詹姆斯·休斯顿的犯人学员开发了一个非营利性的商业计划，这个项目能对他曾生活的老社区里的高危青年产生积极影响。

　　詹姆斯创办了一个青少年科技中心，这是一个课外项目，旨在教10至14岁的儿童应用开发和基本的编码。

　　**在监狱服刑18年之后，詹姆斯回到加州的里士满去追求他的梦想，他打算在2016年的秋天推出他的青少年科技中心。**

　　2014年，我们推出了“Code.7370圣昆廷监狱”课程，这是美国监狱历史上第一个计算机程序设计课程。

　　这项课程的成果颇丰。我们的一些毕业生今年将被监狱释放，我们有信心未来他们能够当上软件工程师。他们努力工作、有决心，并已经克服了严重的障碍，他们通过学习编程，创造了一条通向未来的积极道路。

　　“Code.7370”课程将在今年被推广到加州的另外5个监狱，包括两个女子监狱，我们还计划在5年内开始将这项计划推广到全国。

　　**我们为我们的毕业生感到骄傲，他们中没有人因再次犯罪而重返监狱，他们走了一条正确的路。**
