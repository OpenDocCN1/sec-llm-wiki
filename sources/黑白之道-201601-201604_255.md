# Centos下安装zabbix3.0提示NOKEY解决方法

　事情缘起于安装zabbix3.0相信很多人跟我一样，都对这个软件的安装很熟悉了，不过还是扯一下吧。开始的时候是去zabbix的官网下载了 rpm版本(rpm -ivh zabbix-release-3.0-1.el7.noarch.rpm)，执行安装的时候出现一段提示：

  

![](../Images/0366cb43656b493f2ed95c8cf41b0586.png)

　　**究竟什么是KEY?**

　　KEY，翻译过来就是“钥匙”， 也就是说，谷歌使用KEY验证软件包，也许这是出于对软件的保护吧，总之现在利用KEY来验证软件包是很常有的事啦。

　　应该注意到的是如果签名校验失败，你就会看到KEY ID的错误消息：

  

　　error: V3 DSA signature: BAD, key ID 0352860f

  

　**　解决方法：**

　　在CentOS下有时候用yum安装软件的时候最后会提示：

  

　　warning: rpmts\_HdrFromFdno: Header V3 DSA signature: NOKEY, key ID\*\*\*\*\*

  

　　这是由于yum安装了旧版本的GPG keys造成的，解决办法就是

  

　　rpm --import /etc/pki/rpm-gpg/RPM\*

  

![](../Images/3710331c8a3d19a2377102fc77e50d96.png)

  

　　再安装软件时就不会有这个错误提示了。

  

　　The Linux Package Signing Key

  

　　但是以上只说明了一种情况，也就是Header V3 DSA\*\*\*\*NOKEY，实际情况是还存在另外一种，也即：Header V4 DSA\*\*\*\*NOKEY。

  

　　出现这个的原因是linux的发行版和linux应用软件之间的兼容性出现问题，那么怎么解决呢?很简单，只要输入：

  

　　sudo yum install lsb

　　即可，再次安装软件包就不会出现这个问题啦。
