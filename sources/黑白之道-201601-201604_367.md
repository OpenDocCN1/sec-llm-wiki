# iPhone在大冷天里集体自动关机？苹果回应了...

    这几天，全国上下都被寒流笼罩，大家都直呼一个冷字。这场寒流也给大家的生活带来不小的影响，比如快递包裹被冻成冰块，手机莫名其妙自动关机等等。

这两天，有不少网友吐槽，自己的iPhone手机莫名其妙的自动关机了，还有些南方的同学更是无奈的表示，自己的设备明明在家里也突然之间就没电，这到底是什么情况？太冷了！

![](../Images/28097e2301db81694e20a897a6191119.png)  

苹果对此表示，iPhone自动关机是因为天太冷了，其理想使用温度带介于16°C至22°C之间。如果因为天冷导致手机关机，这种情况只是暂时的。当电池温度返回正常操作范围，其性能也会随之恢复正常。

![](../Images/b7844bc4995a1f925c11cc0c73f4879b.png)  

除了iPhone，安卓手机也会受到自动关机的影响，准确来说是，使用了锂离子电池的手机都会遇到这样的情况。

![](../Images/8a12c3d80d115e37da463b0e77de0509.png)

锂离子电池内部的电解质通过化学反应的变化在正负极出现电势差从而产生电流。在低温环境下电解质会移动的相当慢，从而影响锂离子在正负极之间的转移活性。导致电池充放电性能下降。

目前能解决的办法，避免长时间在室外寒冷环境使用就好。话说，你遇到iPhone自动关机的问题了么？我反正是遇到了！
