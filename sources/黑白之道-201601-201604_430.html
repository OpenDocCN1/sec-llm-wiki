　　乐乐说，“我是不会出这个钱的!因为我穷，我决定睡觉。不养足精神怎么跟坏人战斗。”

　　第二天，她拨通了苹果客服电话，并向客服提供了自己手机Apple ID的原始信息，通过苹果公司技术人员的帮助，十几个小时后终于找回被更改的苹果账户，并成功解锁。

　　密码曾泄露 警方提醒勿私下汇款

　　浙江的江先生也遇到了同样的事件。江先生回忆，他与Apple ID相同的邮箱近日收到过邮件，他曾点击操作过，至于密码怎么泄露的也不清楚。

　　警方分析，江先生很可能是登录了木马网页，或者使用了公共wifi信号，在伪造Apple ID登录页面弹出时，没有仔细辨别，就输入了自己的Apple ID和密码。被敲诈者后台获取Apple ID和密码后，继而在电脑登录，然后利用iCloud里的“查找我的iPhone”功能，把江先生的手机锁死，实施敲诈。

　　


　　△ iPhone手机“查找我的iPhone”功能界面

　　苹果公司客服表示，目前已接到很多类似的投诉。

　　警方提醒：手机用户尽量避免使用陌生的WIFI，在网吧等陌生环境下上网请注意与手机关联邮箱的密码安全;发现账户异常时，请尽快与客服联系。如果碰到上述这种情况，应立即报警，不能私下汇款给对方。

　　使用苹果手机的用户，切记一定将设置Apple ID时的安全问题答案与一些售后资料记录下来。这样，就算遭遇类似被锁机的情况，也可以通过苹果公司的客服进行解锁。

　　提升安全性 这件事你一定要做

　　


　　△ 进行两步验证时要求输入验证码

　　1进入苹果官方网站，点击网站右上方的“技术支持”选项，并选择Apple ID。

　　2在选择Apple ID 之后跳转的页面上点击“管理账户”>“管理您的Apple ID”，输入Apple ID 和密码之后将进入Apple ID 管理界面。

　　3点击“密码和账户安全”选项，并回答此前设置的安全提示问题，开始两步验证的设置。

　　4添加手机号码之后，在弹出的验证框中输入收到的短信验证码 。

　　5手机号码验证完毕之后，需要验证自己的苹果设备，这一步仍然需要输入验证码。

　　6设备验证成功之后，会得到一个非常重要的恢复密钥，最好将它抄录在一个不会丢失的本子上，留着以后备用。系统将会要求我们输入恢复密钥以确认我们已经拥有了密钥。

　　完成这一步，就已经成功开启两步验证。开启两步验证后，需要输入验证码才能对iCloud账户进行操作。如果想要修改Apple ID的密码，则需要输入上面获得的恢复密钥。
