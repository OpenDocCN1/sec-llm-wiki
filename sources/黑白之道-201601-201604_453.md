# 苹果电脑怎么装双系统，其实也很简单！

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=401072896&idx=2&sn=d6d9f537a686514392fc839b9988d07f&chksm=09a686e43ed10ff2934a397ebab6cc1e6105ce2472dceab6ff1c56d1ed369fc153abda4a7954&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=401072896&idx=2&sn=d6d9f537a686514392fc839b9988d07f&chksm=09a686e43ed10ff2934a397ebab6cc1e6105ce2472dceab6ff1c56d1ed369fc153abda4a7954&scene=27#wechat_redirect)

步骤一先使用Boot Camp 分割磁盘

1.在Finder工具条中点选“前往”按钮，在弹出的菜单中选择“实用工具”

![](../Images/2b30ae47acbea54124dd6f3ef57ff985.png)  

2.在打开的“实用工具”窗格中，选择“实用工具”资料夹下的“Boot Camp助理”程式：

![](../Images/c338144e1162631a7ebdf2af516bdb96.png)  

3.执行BootCamp程式，打开“BootCamp助理”窗格第一步，是BootCamp的介绍，可直接点击“继续”按钮进了下一步：

![](../Images/7463a44da1b68f84faa6913b763e72a3.png)  

4.在此步，是从当前硬盘中给将要安装的MS windows操作系统的系统分区的重要一步。可以“使用32G”分区，也可以均等分割，也可以拖动中间的小点按需要划分，具体根据使用情况来定。Win7较XP要多些空间，同时如果你将在Windows中安装较多程序的话也建议多分一点，但一般50G都应该足够了：

![](../Images/048ddbe192cdc05edb6bb6ba161b23e5.png)  

5.大小确定后点击右下角的“分区”按钮开始分区，很人性化的有进度条显示，而不像WINDOWS系统一样分区只有干等着：

![](../Images/5d055b13bbf955309ca463157cc88066.png)  

6.稍等一会，分区完毕，切换到“开始安装Windows”界面，提示插入系统光盘：

![](../Images/6fca2488c6a4edc5ee61c7f4a4ac6283.png)  

7.系统光盘插入后直接点击右下角的“开始安装”按钮，一会系统系统会自动重启。重启正确读取光盘后，会直接进入到我们熟悉的Windows安装界面。

步骤二 安装Windows OS

1.重启进入分区界面后，一定要选择BOOTCAMP的分区，然后点选“Driveoptions(advanced)”按钮：

![](../Images/664c2fc1c78160cdff9b3138151bc1e4.png)  

2.在下一界面中，单击“Format”按钮，先将把分区格式化成NTFS格式：

  

3.后面的操作就和MS Windows安装步骤一样了，直接等安装过程完成，直到出现Windows桌面即可：

  

步骤三 为Windows安装驱动待系统安装完毕后，如果提示安装驱动，先不要安装集成的驱动;将苹果电脑随带的苹果系统光盘播放光驱，让系统自动安装完成BootCamp驱动，双击光盘内的Setup.exe程序：

  

打开欢迎使用boot camp安装程序：

![](../Images/20ffb768b9edeec62fbfcbe85e8b9445.png)  

在“Boot Camp”窗口上，点击“下一步”，如上图;之后一路点击“下一步”，完成所有驱动以及软件的安装;在最后一步建议勾选上“apple software update(windows版)”复选框：

![](../Images/ec15592f268b23d7cd1167e20e830cb0.png)  

单击“安装”按钮开始安装，如上图;安装完毕后机器会自动重启，并进入Windows操作系统;进入windows系统后建议并运行Apple Software Update软件，对驱动进行更新：

![](../Images/b44718a7ebffdb7cdab446e3e04a3bd6.png)  

10.在以后需要切换系统时，可以在开机时按住ALT键，会弹出系统选择功能：

![](../Images/7cd6311fecd25e5f9d05a29f297739cd.png)  

11.按键盘上的方向键选择好系统后按回车键即可进入相应的系统。
