# 程序自动判断，那些微信好友将你删除！

这个软件功能就是自动找出你的好友中，有谁已经将你删除了，这是一个忧伤的软件，知道结果的你可能心情不会很好。

  

软件官方网址：https://github.com/0x5e/wechat-deleted-friends

![](../Images/945df338bcdf807dd6c517b9bc171bcf.png)

  

  

作者：0x5e 运行环境：Mac OS

  

运行原理：就是新建群组,如果加不进来就是被删好友了(不要再群组里讲话,别人是看不见的)，用的是微信网页版的接口。

  

查询结果可能会引起一些心理上的不适,请小心使用。

  

还有些小问题:

  

1.  结果好像有疏漏一小部分，原因不明。
    
2.  最终会遗留下一个只有自己的群组，需要手工删一下。
    

  

Mac OS用法: 启动Terminal

  

$ python wdf.py

  

运行之后，会提示扫描二维码，扫描完之后，一路回车，最后会显示用户名，都谁给你删除了，我们也可以给他删除就行。
