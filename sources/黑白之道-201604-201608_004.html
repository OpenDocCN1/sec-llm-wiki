月底Black Hat 2016上10 个不容错过的Talk

美国 2016年黑帽子大会即将来临，7 月 30 日到8 月 4 日，会议将返回到神话般的拉斯维加斯曼德勒湾！

 



创建近 20 年来，该会议为信息安全专业人员提供了一个共享和学习的极佳机会。可惜的是，不是所有人都有条件参加，例如：Pr0.s就没机会去。

 

好在网络便捷性，使得我们不再受地域和时空的限制，即可享受信息。DarkReading给出了5类，10个不容错过的Talk。

 

这里与大家分享，即将成行的人可以在现场关注，不能成行的我们一起在网络看“直播”吧~！

 

0X01  Overall

 




车联网高级CAN注入技术（Advanced CAN Injection Techniques for Vehicle Networks）， Charlie Miller 和Chris Valasek 再次一起深入探讨车辆控制系统的数字操作。在其50分钟的演讲中，Charlie Miller 和Chris Valasek将演示通过CAN注入，绕过诸多限制，并验证车辆制动，转向和加速系统反应。

 



打破FIDO（Breaking FIDO: Are Exploits In There?）， Jerrod Chong在其25分钟演讲内，他将讨论隐藏在FIDO部署中的漏洞，展示发现这些漏洞如何困难，企业和组织如何能够保护自己。

 

0X02  Application Security

 



安全自动化的设计之路（Design Approaches for Security Automation），在50分钟演讲内，Adobe的安全战略官（Lead Security Strategist）Peleus Uhley将回答如下问题：

 

What criteria should decide the best approach for security automation?

Are there simpler alternatives to building a complex, custom-built, automation environment?

Where do you deploy?

Which tools do you need?

How do you ensure your implementation will effectively enable teams rather than just create false positives at scale?

 



高级跨站搜索攻击：从未如此实用(Timing Attacks Have Never Been So Practica: Advanced Cross-Site Search Attacks)，Nethanel Gelernter将利用50分钟，讲解和展示目前利用跨站点攻击，实现敏感信息提取，例如：Gmail 和雅虎的电子邮件内容，以及 Bing 用户的搜索历史。

 

0X03  Microsoft

 



Windows 10 的缓解改进（Windows 10 Mitigation Improvements），微软首席安全工程师David Weston 和 Matt Miller将展示微软独特的主动安全防御方法，包括：进攻安全（offensive security）研究，红队"red team"研究等。

 



Windows 10内隐藏Linux内核，Linux在Windows机器上做什么？（The Linux Kernel Hidden Inside Windows 10：What’s this Linux stuff doing in my Windows machine, you ask? ），CrowdStrike首席架构师Alex Ionescu，利用50分钟分享，全面、 内置，默认加载情况下，以 Linux 3.4 内核特权运行在 Windows 10，可以导致大量的新的安全挑战。

 

0X04  Mobility

 



移动OAuth中1000种死法（1000 Ways to Die in Mobile OAuth）， 由于其迅速和广泛的采用，OAuth 已成为颇具影响力的协议之一。报告将展示几个有代表性的案例，来具体地解释如何真正实现遇到的陷阱。这 50 分钟的会议将由专家小组完成，令人印象深刻，他们是：

 

Eric Chen - Software Engineer, Gridspace

Patrick Tague - Associate Research Professor, Carnegie Mellon University

Robert Kotcher - Software Engineer, Expii

Shuo Chen- Senior Researcher, Microsoft Research

Yuan Tian - Ph.D candidate, Carnegie Mellon University

Yutong Pei - Software Engineer, Uber

 



一种新型BLE代理工具，GATTacking 蓝牙智能设备（GATTacking Bluetooth Smart Devices—Introducing a New BLE Proxy Tool: ），Slawomir Jasek的25分钟，将给听众介绍一个开源的工具，它打开了物联网设备逆向、调试和漏洞分析的全新篇章。该工具可以在便携式的树莓派上运行，携带可以到达任何地方，演讲中将分享他们在接管控制智能锁，扰乱智能家居和甚至得到免费的午餐等案例中的经验，并展现相关代码。

 

0X05  Internet of Things

 



进入核心 — — Windows 10 物联网核心深入探索（Into The Core—An In-Depth Exploration of the Windows 10 IoT Core），来自 IBM Security X-Force的安全研究人员Paul Sabanal，利用50分钟， 讨论Windows 10 物联网核心操作系统及其括安全功能。Paul Sabanal还将讲到如何访问运行在Windows 10 IoT Core 上的设备，包括：静态/动态逆向工程和 fuzzing方法。

 



灯泡蠕虫？（A Lightbulb Worm?）NewAE科技的CTOColin O'Flynn，问了一个问题︰ 蠕虫可能通过智能光网络传播吗？他将在25分钟内，讨论包括攻击物联网和嵌入式的硬件设备、如何绕过加密引导程序、飞利浦某款智能灯的固件等内容。
