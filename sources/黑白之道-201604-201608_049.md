# \[Android\] 专治流氓软件神器!仅12K的流氓克星

App的流氓行径一直是安卓平台的大问题，很多安卓App特别是国内互联网公司出品的App，动不动就在后台塞上好几个进程，压根就关不掉。所幸的是，还是有不少工具可以治一治这些流氓的。今天，为大家介绍一款近期新鲜出炉的专治流氓App驻留后台的工具“边缘”，这款工具不仅效果相当好，而且体积是一大亮点——它仅有12K多一些！          这款“边缘”App和VIA浏览器来自同一个开发者，VIA浏览器的一大亮点就是极其袖珍，边缘App的体积也是非常的小巧，只有13K不到，除了本职工作外，没有其他多余的功能了，非常绿色。这款边缘App的作用是，能够把你不想在后台运行的App冻结住，被冻结的App不再会在后台运行（也意味着不会有推送），不会再消耗任何电量，直到你把它解冻为止。用来对付后台泛滥的国产App，实在是再合适不过了。   
          边缘App对付安卓流氓后台的原理是“冻结”，这个“冻结”是什么意思呢？如果你接触过钛备份这类安卓系统工具，应该会对这个词有所印象。所谓的冻结，其实是安卓系统的一个固有命令，在adb中输入相应的命令行“adb shell pm disable +程序包名”，其效果就是让一个App被冻结停用，这个App会在系统中消失（但没有被卸载），用“enable”命令解冻后又可以重新使用了。   
　     “冻结”用来对付流氓App，无疑是非常有效的。从原理上来看，冻结命令能够让App从系统中整个“消失”，只有解冻才能够重新使用，流氓App们被冻结后自然也无法驻留后台。一般来说，冻结命令需要从adb界面输入，如果仅靠手机中的App实现，则需要root权限。因此，边缘App也需要root后才能使用。   
      边缘App的使用方法非常简单，开启后，就可以看到手机中已经安装的App了。长按某个App，直到这个App的图标旁边出现像雪花一样的星号，则说明这个App已经被冻结住了。这时候回到桌面，可以发现被边缘App冻结的应用，已经找不到了。开启系统的程序列表，也是找不到被冻结住的App的。这时候，被冻结的App只能够从边缘App中找到和开启，想要使用被冻结的App，只要在边缘App中单击解冻再单击一次，就能够再次开启了。   
       由于边缘App的原理是冻结，所以在某个App被冻结的时候，如果把边缘App给卸载了，那么这个被冻结的App也会随之消失。所以在使用的时候，这点要注意一下。如果不想用边缘App想要卸载掉，记得先把里面的App都解冻。   
　　 总的来说，这是一款对付流氓App后台效果很好的工具。边缘App的“冻结”原理，令它比一般的杀后台、休眠后台工具更加有效，理论上是没有什么正常安装的App能够逃过冻结的。如果你需要一款强力的杀后台工具，不妨试试这款边缘App吧。
