# 百度搜索深夜推赌博网站清晨关闭 推广费超30万

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

　　7月17日6点26分至7点零7分，记者通过百度搜索进入一家名为“澳门威尼斯人”的赌博网站，页面数据显示，投注额从7900万元暴增至一亿元，参与投注的用户数也在一夜之间由47万人增加到62万人。记者发现，夜间10点以后，盗用多家公司营业资质，多家赌博网站被标注“商业推广”字样悄悄上线，次晨9点前全部下线，恢复自然搜索结果。与此同时，推广费也超30万。

  

　　7月17日6点26分至7点零7分，重案组37号通过百度搜索进入一家名为“澳门威尼斯人”的赌博网站，页面数据显示，投注额从7900万元暴增至一亿元，参与投注的用户数也在一夜之间由47万人增加到62万人。

![](../Images/7f0365001645f346603635ab79758664.png)

　　澳门新葡京赌博网站首页

  

　　从2015年12月起，百度非企渠道业务员刘明(化名)持续不断向百度公司和北京消协举报百度搜索推广赌博网站的问题，至今无果。

  

　　同一时段，长沙的工薪族陶阳(化名)沉溺网络赌博难以自拔，正想扳回输掉的20多万元。此前，他通过百度搜索“注册送礼金”进入“澳门威尼斯人”、“九五之尊”等网上赌场。

  

　　重案组37号(微信ID:zhonganzu37)持续两个月关注百度搜索发现，夜间10点以后，盗用多家公司营业资质，多家赌博网站被标注“商业推广”字样悄悄上线，次晨9点前全部下线，恢复自然搜索结果。在季度末和周末，赌博网站更是大量涌现。

  

　　在百度推广系统，参与竞价的客户分为企业和非企业两大类。多名从事非企渠道业务员透露，非企账户主要用来进行灰色或非法业务推广，如赌博、保健品、“定位找人”等，其消费多用来充业绩。

  

　　刘明称，以今年一季度为例，有百度推广业务代理商为了完成任务，给非企渠道业务员的回扣达到80%;且其所展示的企业资质多为造假，多家赌博网站百度的推广费用一晚累计超过30万元。

  

　　此外，根据规定要求百度“对商业推广信息逐条加注醒目标识”(百度推广)，而百度向垂直类网站收取数亿元导流费用的阿拉丁计划，在搜索中未见“商业推广”等标识。

  

　　赌博网站深夜上线百度搜索

  

　　“澳门新葡京赌场，单日可提款5000万人民币”、“MG电子游艺天天返水，最高可达3.0%”、“体育投注天天返水，最高可达2.5%”……

  

　　6月26日晚，这是通过百度搜索关键词“新葡京”，点击第一条“点击进入新普京官方娱乐网99199.com娱乐首选”后的页面介绍。

  

![](../Images/b270425ad072d3074e0d78f49afba2e7.png)

  

　　百度搜索"新葡京"的结果

  

　　在百度搜索输入上述关键词后得到的前4条链接右下方，均被浅蓝色字体标注为“商业推广”，紧随其后则为正常搜索结果。逐一打开后分别显示为“澳门新葡京赌场”、“明升亚洲网投”、“威尼斯人娱乐赌场”、“太阳集团”，4家网站子栏目中均涉及赌博电子游艺项目，并介绍了如何存款及提现。

  

　　“魏则西”事件后，百度表示将从六个方面全面落实，其中包括“控制商业推广结果数量，每页面商业推广信息条数所占比例不超过30%”，也就是相当于全新调整之后，每个页面上、下和右侧的推广信息合计起来不会超过4条。

  

　　而恰恰上述4条链接在跳转后，均经推广导入至赌博网站。赌博内容均为网络赌博常见的MG、EG、BBIN等电子游艺。点击“评价”进入“百度口碑”关于上述公司评价多为“骗子”等负面评价。

  

　　此外，上述4条带有“商业推广”字样的搜索结果，均加注绿色粗体“V1”信誉认证。排名前三位的3家赌博网站认证信息均为“河南爱车之道商贸有限公司”，“太阳集团”则认证为“郑州阿尔梅商贸有限公司”。

  

　　点击绿色粗体“V1”进入河南爱车之道商贸有限公司百度信誉认证，该认证分基础信息和认证类型。其中网站地址显示为“biujw.pw”,认证类型为“实名认证”。

  

　　百度推广非企渠道资深业务员李晟介绍，这个“V”是百度认定的, 但这并不是真实公司。赌博网站随便PS了人家的营业执照,就可以提交百度审核认定。

  

![](../Images/b96830f44a82518cc2575b5d4af13f2e.png)

  

　　被盗用的河南爱车之道商贸有限公司 百度信誉认证

  

　　有网络赌博玩家推算，以“新葡京赌场”一家网站为例，一晚上资金流水达上千万元，大多有返水，一分钟短信提醒到账。

  

　　一家“澳门威尼斯人”的赌博网站动态数据显示，截至2016年7月17日6点26分，该网站累计投注额达到7900余万元，这个数字仍在持续增长，截至7月17日7点7分，该网站累计投注额已超过一亿元。参与投注的用户数也在一夜之间由47万人增加到62万人。

  

　　事实上，这类推广信息大量存在。重案组37号(微信ID:zhonganzu37)在夜间以及在长沙、苏州、济南等地打开百度搜索，输入关键词“新葡京”、“老虎机遥控器”、“线上娱乐”、“注册送礼金”等，同样能找到不少类似赌博网站。在PC端百度搜索页面靠前位置，多有加注“商业推广”字样。

  

![](../Images/d582c63d815cbe42ba258b33ee0327a4.png)

  

　　同样的关键词，在百度手机端夜间搜索，几乎为满屏的赌博信息。而在次日早上，多家被推广的赌博网站悄悄下线。

  

　　非法网站盗用企业信息注册百度账户

  

　　赌博网站是如何与普通企业关联起来的?

  

　　刘明介绍，除少量以个人名义开户，大部分百度非企渠道用户认证信息都是盗用的，被盗用信息公司根本不知情，即使知道投诉了，代理商或非企渠道业务员会马上将“举报账户”下线，第二天换家公司注册，继续推广。

  

　　上述“澳门威尼斯人”赌博网站就盗用了“河南爱车之道商贸有限公司”的注册信息。工商资料显示，河南爱车之道商贸有限公司注册资本100万元，注册地为郑州，经营范围包括“批发零售汽车配件、汽车饰品、其他化工产品(不含危险化学品)”。

  

　　“我们没有做过百度商业推广。”6月27日上午，重案组37号(微信ID:zhonganzu37)致电河南爱车之道商贸有限公司，对方如是回复，“我们做汽车零部件销售的，不可能跟赌博有关系啊”。同样，郑州阿尔梅商贸有限公司信息亦被一家“新葡京”赌博网站盗用，其工作日人员亦表示对此不知情。

  

　　百度推广系统要求：参与竞价的非企业客户须提交相关资质。然而，非企业竞价客户数量巨大，于是催生了专业出售“开户资质”的灰色生意，大量qq群公开销售用于百度推广开户认证的“营业执照”。

  

![](../Images/8b47ab14cd50fae6ef2c8b759f8ec088.png)

　　百度搜索推广代理商管理系统

  

　　张涛(化名)是江苏徐州的百度非企渠道业务员。2015年11月，他与百度推广济南地区总代理山东开创集团有限公司(下称“开创集团”)合作，在缴纳1万元保证金后，对方给其百度“端口”前后开户43个，开户价格为2400元/户。

  

　　公开资料显示，开创集团是百度第二大代理商，独家代理了山东7地百度推广业务。

  

　　2015年10月30日，开创集团在新三板挂出的《公开转让说明书》提到，“公司百度搜索引擎推广业务即为代理销售百度币，占比最高，2015年1-6月、2014年和2013年分别实现收入5.5亿元、9.7亿元、5.4亿元。占比分别为99.24%、99.02%和99.58%，是目前公司收入的主要来源。”

  

　　开创集团给张涛的百度后台信息显示，账户名“lei62”,财务信息一栏显示该账户推广资金池累计总消费额为4,267，952元。而这仅是开创集团推广业务当中的一个用户。

  

　　“这些账户都不是浙江的，大多数推广捕鱼等赌博游戏。”张涛说，自己的企业资质是从网上买来的。该批账户使用4个月前后消费40余万元，提成5%，张涛拿到2万多元。

  

　　他介绍，营业执照售价根据推广行业难易，价格也不一样。如果不要对公账户，仅要求有法人和营业执照的，售价在400-500元/份;普通商贸企业，有营业执照和对公账户，售价在1500-2000元/份;用于兼职招聘推广的资质数量稀少，价格至少在3500元/份。

  

　　“看什么客户，什么行业，寻找相关执照，如果在百度账户开过户，就不能用;没开过的都能使用。”从事百度非企业务多年的刘明(化名)说，自己的营业执照信息是从某企业工商信息集合软件中下载，然后进行PS上传，最快一天时间上线。

  

　　赌博账户推广收入累计超过30万/晚

  

　　“一到晚上九点以后，就是百度灰色收入的黄金时间。”李晟强调说，百度搜索“兼职”、“服装批发”等全是骗子。

  

　　6月26日晚，重案组37号(微信ID:zhonganzu37)统计，仅以搜索到的5个赌博网站盗用河南爱车之道商贸有限公司、郑州阿尔梅商贸有限公司、郑州市爱倍加商贸有限公司、郑州阿逸多商贸有限责任公司、深圳典成教育发展有限公司资质推广赌博，上述5个资质分别关联的账户数量分别为8个、8个、7个、8个、7个，共38个推广账户。

  

![](../Images/8119c4ba2b735b9b5a16a726c6a9f6a7.png)

　　盗用河南爱车之道商贸有限公司的账户

  

　　刘明介绍，百度非企推广开户价格最低在2400元/户，部分达到3000元-4000元/户。以上述38个账户全部“跑光”算，消费至少在9.12万，加上其他没有搜索到的关键词，保守估计，百度一晚从赌博一项得到的推广收入累计超过30万。

  

　　在百度推广系统，企业信誉等级分为“V1、V2、V3”，根据企业信誉等级的不同，一个营业执照可关联的推广账户数量从50个到200个不等。“这个账户消费完了，自动下线，进入下一个账户消费”。

  

　　刘明说，一般来说，非企渠道业务员手上的客户比较单一，如果做赌博，就全是赌博类客户，如果是卖保健品，客户就全是卖保健品的。

  

　　江苏某非企渠道业务员李晟(化名)介绍，所谓非企渠道就是帮百度正规代理商拉消费的代理人。“我们之间不需要任何协议，也不用见面，通过QQ联系，相互介绍，他需要消费，我有客户消费，给你一个端口，就可以自己在百度开户上线推广，所有业务都以百度币结算。”

  

　　百度前代理商江苏仕德伟网络科技股份有限公司(下称仕德伟)是百度在苏州、扬州、淮安和宿迁四个地区的总代理，是这些地区商家做百度推广的官方渠道。2015年12月，由于百度收回其代理权而引发诉讼。

![](../Images/6ac144ae4ae4f54e0a69521acba5aac2.png)

　　百度前代理商江苏仕德伟网络科技股份有限公司

  

　　仕德伟在起诉状中表示，希望法院能判令百度返还其在2015年上半年垫付的非企推广费用，暂计3000余万元。

  

　　仕德伟总经理陈德阳表示，2014年起，《百度地区总代理政策》规定，如果一个季度点击消费的完成比例低于目标的95%，百度就会对代理商进行罚款，同时有权取消其代理资格。

  

　　陈德阳说，自己不是所有代理商中情况最严重的。由于给这些非企客户的折扣要远远大于百度提供给代理商的折扣，代理商需要为这些交易的差价贴钱。但相对于被百度罚款或取消代理商资格，代理商又不得不承受这部分损失，以完成消费目标。

  

　　李晟也证实，由于代理商背负了巨额百度推广任务，大多数代理商不得不拉非企消费冲业绩，甚至自己垫付消费。

  

　　刘明介绍，百度在大陆共有49家代理商，非企客户可通过全国任意代理商开户，并可以获得高额返点。

  

　　“代理商冲业绩，非企消费就管得宽松，基本都能通过，其返点也会相应提高。”刘明说，以温州为例，该地区代理商季度总消费在4亿元以上，其中非企消费比重约占60%。“温州任务重，今年一季度，和广东渠道合作，返点高达80%，也就是说，你充值10万，返你8万”。

  

　　刘明介绍，通常各地区百度代理商给客户返点比例在20%-30%，年末可提高至35%。“跑的量大，可以直接和代理商谈”。

  

　　7月6日上午，“百度前代理商索赔案”开庭前，仕德伟方面撤诉。针对撤诉原因，仕德伟代理律师表示“原因很复杂”。

  

　　隐藏商业推广的阿拉丁计划

  

　　“你根本就不知道，百度是收了钱的，这类垂直网站给百度支付巨额广告费，就是商业推广。”陈强(化名)是华中地区某网站负责网站运营及百度推广的负责人，他说，但是，广告链接并没有按规定标注“商业推广”。

  

　　陈强介绍，在百度推出的阿拉丁计划中，其先后与慧聪网，爱卡汽车，汽车之家等垂直类信息网站签订了巨额广告协议。

  

　　总结起来，阿拉丁计划就相当于百度做了图文字竞价位，让如慧聪网、爱卡汽车等代理，代理商拿着这些广告位然后卖钱。

  

　　公开资料显示，慧聪网是国内知名的内贸B2B电子商务运营商，向百度购买的关键词覆盖93个行业，10177个品类，3264741条商品。2014年，慧聪网以5008万价格与百度阿拉丁订立协议，2015年、2016年续签，具体价格不详。

  

　　在慧聪网标王频道查询关键词“工业门”显示，其第一至第五位5条广告位已经售罄，分别卖给了佛山市新广大自动门窗工程有限公司、北京东方万盛科技有限公司、无锡艾锐特门业科技有限公司、任丘市林垚工业门厂、杭州振兴卷闸门厂5家企业，合同期限从1-2年不等，价格在5000元-36500元/年。

  

　　随后，重案组37号(微信ID:zhonganzu37)在百度中搜索关键词“工业门”，在搜索首页中间位置，图文竞价位置5条链接则对应了上述5家企业。

  

　　公开信息显示，今年3月，国内汽车垂直门户网站爱卡汽车斥资3.7亿元签订百度PC端、移动端双平台阿拉丁，合作期限为12个月。

  

　　爱卡汽车向百度购买的关键词分为品牌词，如“长安福特”;车系词，如“宝马5系”;厂商词，如“奥迪”。新京报记者在百度输入“宝马5系”发现，首页前4条链接均被标注为“商业推广”，紧随其后的爱卡汽车图文竞价位，则如同自然搜索一般。

  

　　显然，一般用户并不知道，这是商业推广的结果。

  

　　5月9日，“魏则西”事件后，国家网信办会同国家工商总局、国家卫生计生委成立的联合调查组入驻百度进行调查，提出6点整改要求，其中包括“对所有搜索结果中的商业推广信息进行醒目标识，进行有效的风险提示”。

  

　　对此，百度搜索总裁向海龙表示“坚决拥护”，“绝不打一丝折扣”。

  

　　6月25日，国家互联网信息办公室发布《互联网信息搜索服务管理规定》，《规定》要求对“提供付费搜索信息服务应当依法查验客户有关资质，醒目区分自然搜索结果与付费搜索信息，对付费搜索信息逐条加注显著标识”。

  

　　7月8日，国家工商总局公布《互联网广告管理暂行办法》，自2016年9月1日起施行。《办法》首次将付费搜索结果定义为广告。《办法》提出，互联网广告应当具有可识别性，显著标明“广告”
