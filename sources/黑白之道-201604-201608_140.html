【原创】用SRVINSTW工具完美卸载sql2008数据库

　今天来跟大家聊聊怎么完全干净的卸载sql2008

　　首先我们得下载一个工具SRVINSTW.exe，这个是专门用来卸载微软服务的

　　准备的东西准备好之后就开始动手卸载了

　　一.控制面板--程序和功能;

        

　　二.找到如下程序，按照图中顺序分别卸载;

　　Microsoft SQL Server VSS WriterMicrosoft

　　SQL Server Setup Support Files(English)

　　Microsoft SQL Server Native Client

　　Microsoft SQL Server 2008 Books Online(English)

　　Microsoft SQL Server 2008 Backward compatibillty

　　Microsoft SQL Server 2008

　　三.使用SRVINSTW.exe这个软件，打开SRVINSTW.exe,移除服务;(记住，是移除或者说删除所有sql的服务)删除所有SQL服务

        

　　选择本地机器

       

        

　　四.删除注册表中：

　　1.点击左下角“开始”菜单，在弹出的菜单中，点击“运行”;

　　2.在弹出的窗口中输入命令：“regedit”;

　　3.点击“确定”，即可进入注册表了。;

　　把

　　HKEY_CURRENT_USER\Software\Microsoft\Microsoft SQL Server

　　HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\MSSQLServer

　　HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\ Microsoft SQL Server

　　HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\MSSQLServer

　　HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\SQLSERVER AGENT

　　HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services \MSSQLServerADHelper

　　全部删除。

　　五.使用控制面板的【添加或删除程序】工具，查看有无其他未删除的SQL Server程序，如有都一并删除掉

　　六.删除C:\WINDOWS\inf 下所用文件(我是在该文件夹下搜索“sqlserver”，然后删除所有结果文件)可能搜索inf文件夹，根本没有任何信息，那就不用删了

　　删除残留文件 ：

　　将C盘——Program File下的Microsoft SQL Server 文件夹删除。(一般有C:/Program Files/Microsoft SQL Server和C:/Program Files/SQLXML 4)

　　七.清除C盘下所有跟sql有关的文件夹或者文件，一般这个里面是有的Documents and Settings

　　八.做完这些之后重启一下机器，然后把上面的在重复一遍，检查一下，看看有没有漏的，如果发现有“余党”，干掉。接着重启，之后就可以安心的重新安装sql2005了
