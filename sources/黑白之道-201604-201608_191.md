# 匿名洋葱路由Tor 又增一层皮（新加密算法）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650438121&idx=2&sn=98660f09d584009bc892d7b2bec29a7f&chksm=83bb1c0db4cc951befd54aa1f574de563f33a1a8603aaf28225aec70f59aa27a7a75f94a1c0a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650438121&idx=2&sn=98660f09d584009bc892d7b2bec29a7f&chksm=83bb1c0db4cc951befd54aa1f574de563f33a1a8603aaf28225aec70f59aa27a7a75f94a1c0a&scene=27#wechat_redirect)

Tor是互联网上用于保护您隐私最有力的工具之一，但是时至今日仍有许多人往往认为Tor是一个终端加密工具。

 

    ![](../Images/4235bff541aa49c1aae803cf800ff7e2.png)  
  
　　事实上，Tor是用来匿名浏览网页和邮件发送(并非是邮件内容加密)的。

　　匿名是自由的，是无罪的，但是大多数都是由一些非法交易网站如(Silk Road)等在使用，所以 FBI 穷追不舍Tor 用戶的行为也通常被大家认为是合理的。近日，Tor为躲过FBI的穷追不舍，进行了一次升级，又增加了一层新的加密算法，这下FBI要哭了。

　　6月初的时候，Tor发布了6.5a1版本，与之前版本相比，这个版本为加强版，并在加强版中添加了一种新的随机算法──Selfrando。就在近日，加州大学尔湾分校的研究专家们针对这个技术发表了一篇详细的论文，文中对这种新的算法定义是：

　　这是一个经过加强，同时具有实用性的随机加载时间技术。说得简单点，这种技术更加方便的用来防止黑客对Tor用户去除匿名化的攻击。

　　Tor团队和加州大学的研究专家们花费了大量时间和精力合作研究出Selfrando，想要用这种技术替代传统的位址空间随机加载技术。

　　位址空间随机加载技术是让代码在其运行的內存中进行转换，而Selfrando的工作方式是将不同功能代码分开，并将它们所运行的內存位址进行随机分布。

　　如果攻击者不能准确猜到每个代码执行所在的內存位址，那他就不能触发到內存中所存在的漏洞，也就不能让Tor浏览器运行他们的恶意代码，从而更好地保护了使用者的个人信息。

　　Selfrando中的二进位档案都构建在相同的硬盘内，直到被加载到主內存中后才会被随机分布。

　　Tor一直让FBI咬牙切齿，FBI也总是孜孜不倦的去研究如何攻破Tor，甚至花钱在全世界范围内找帮手，目的就是想揪出Tor用户的真实身份。然而这次Tor的更新让FBI一下掉进底谷，接下来FBI如何迎头赶上，还需要针对性的找到合理的突破口才行。
