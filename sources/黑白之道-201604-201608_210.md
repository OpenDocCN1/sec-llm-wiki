# XenServer云主机怎么添加多网卡？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650438073&idx=3&sn=c055a599d29a1d6e619983abfbb30a2d&chksm=83bb1c5db4cc954b9896fea97433eef182a91c750adb82a7ac434b0948e10a11d99be8bae1b8&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650438073&idx=3&sn=c055a599d29a1d6e619983abfbb30a2d&chksm=83bb1c5db4cc954b9896fea97433eef182a91c750adb82a7ac434b0948e10a11d99be8bae1b8&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

因为工作的需要，要给XenServer云主机添加多网卡，这样可以更方便的管理。找了一些资料做参考，说的都是很专业，我仔细的看了一下发现其实很简单，做个教程和大家分享一下!

![](../Images/201436731f37c1ce8258267aba29577e.png)

  

　　1，登录我们xencente管理模版，找到要修改的机器。选择网卡----添加网卡

　　

![](../Images/c3f3f2b52e6abf05560cc09e2c818aa7.png)

  

　　2,填出配置网卡的选项，添加一个新的网卡就可以了。

　　

![](../Images/715b82774b2f44d1fe3c4f9e9812ad40.png)

  

　　3，这样网卡就添加好了。

　　

![](../Images/e189bcdcd02fb75f9704bd2976e4391d.png)

  

　　4，上vps服务器看一下，我们就可以看见新添加的网卡了。

　　

![](../Images/f948970207bd18796e43376360dd2b8c.png)

  

　　注意：linux主机也是同样的添加网卡，但是添加完网卡后，要重启你的vps才可以识别新的网卡。
