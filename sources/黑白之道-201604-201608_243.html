Rootkit 通常是指加载到操作系统内核中的恶意软件，因为其代码运行在特权模式之下，极具危险性。

有 Rootkit，就需要 Anti Rootkit，用到的就是 ARK 工具。
针对32位的 Windows XP 或 Windows 7 系统，已经有很多成熟的工具了，比如冰刃、早期的冰刃 (IceSword)、Wsyscheck、到后来的狙剑 (SnipeSword)、XueTr，还有最近很给力的 PowerTool 等，但是64位操作系统下的 ARK 工具发展相对缓慢。而 Tesla.Angela 开发的 Win64AST 是其中一款，由于使用了特殊的内核技术，WIN64AST 能够从底层控制系统，有很大的操作权限，
是一个强大的 Anti Rootkit 工具，能够查看并管理64位 Windows 系统的各种内核信息，可用于手工杀毒、辅助调试、内核研究等。
