　　项目介绍

　　fbctf是一个由facebook开源的ctf程序，由php语言编写。

　　安装方法

　　sudo apt-get install git

　　git clone https://github.com/facebook/fbctf

　　cd fbctf

　　./extra/provision.sh prod `pwd`

　　开发环境

　　git clone https://github.com/facebook/fbctf

　　cd fbctf

　　vagrant up
