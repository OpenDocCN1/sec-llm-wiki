在上一篇的文章中，我们介绍了 websploit 的基本安装及命令使用方法。在这章中，我将使用其中一个模块来进行实战演示。话不多说，让我们开始进入实战。

打开 terminal 输入命令:

websploit

显示模块列。我们选择network modules 下的 webkiller 。

show modules

输入命令，使用该攻击选项并 show 它的基本配置。

use network/webkiller

show options

我们可以看到，在 show 选项下要求我们配置 网卡和目标网址。我们可以用 ifconfig 命令来查看你的网卡。我设置如下:

wsf:Webkiller > set interface wlan0
wsf:Webkiller > set target youtube.com

接着我们就可以开始攻击了。我们输入命令:

run

此时我们打开浏览器输入 youtube.com 你会发现，我们无法正常进行连接。因为网络中的 TCP 包都被丢弃了。我们打开 CMD 命令来对该网站进行 ping ，我们发现可以正常 ping 通。因为 ping 是 ICMP 包，因此并未被丢弃。

最后我们按 Enter 键停止攻击。
