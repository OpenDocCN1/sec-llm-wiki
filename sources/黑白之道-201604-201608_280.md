# 实战演练之websploit攻击

在上一篇的文章中，我们介绍了 websploit 的基本安装及命令使用方法。在这章中，我将使用其中一个模块来进行实战演示。话不多说，让我们开始进入实战。

打开 terminal 输入命令:

**websploit**

![](../Images/24d6d980bee8d66b10b11a08f684832c.png "实战演练之websploit攻击")

显示模块列。我们选择network modules 下的 webkiller 。

** show modules**

![](../Images/11337e5928c08f96b5549c0142a8ccec.png "实战演练之websploit攻击")

输入命令，使用该攻击选项并 show 它的基本配置。

**use network/webkiller**

**show options**

![](../Images/bc5099e43ae1fef9254272e53ee31def.png "实战演练之websploit攻击")

我们可以看到，在 show 选项下要求我们配置 网卡和目标网址。我们可以用 ifconfig 命令来查看你的网卡。我设置如下:

**wsf:Webkiller > set interface wlan0**  
**wsf:Webkiller > set target youtube.com**

![](../Images/8bfd95b41387769e32942ea59f46d62e.png "实战演练之websploit攻击")

接着我们就可以开始攻击了。我们输入命令:

**run**

![](../Images/0f2219c2bfa105ffb13ad61bd9ad1d4c.png "实战演练之websploit攻击")

此时我们打开浏览器输入 youtube.com 你会发现，我们无法正常进行连接。因为网络中的 TCP 包都被丢弃了。我们打开 CMD 命令来对该网站进行 ping ，我们发现可以正常 ping 通。因为 ping 是 ICMP 包，因此并未被丢弃。

![](../Images/320070e74ae672788addf54c2e4f3cc7.png "实战演练之websploit攻击")

最后我们按 Enter 键停止攻击。

![](../Images/10d052d508d176df75e7f1fc62142591.png "实战演练之websploit攻击")
