　　本文所涉及/需要的平台程序如下:

　　1.操作系统 Windows 2003

　　2. IIS 6.0

　　3. WordPress最新版本

　　4. MySQL 5.1

　　5. PHP 5.5

　　首先需要配置wordpress需要的安装环境，iis和mysql与php，网上有教程，作者在此就不一一叙述，直接从环境已经配置好后开始。

　　视频开始，输入密码，进入数据库，添加数据库，视频内在之前已经添加了，在这我直接放出命令。

　　使用 create database \*\*\*\* ;【\*为数据库名】可以添加数据库，注意：分号前有空格

　　视频内则使用show databases ; 查看已有的数据库，在视频内之前已经创建了一个c1数据库。

　　然后我们解压下载好的wordpress复制到需要的目录，视频内是解压在IIS默认的网站目录内。接着我们打开IIS管理器，添加网站，详细步骤基本按视频内就可以，注意：如果出现权限问题需要在wordpress文件夹添加IIS所有权限，或者直接在新建网站右键权限内添加IIS所有权限。

　　配置成功后右键浏览，页面在这里报了一个提示：wp-config.php不存在，然后找到之前的wordpress目录内，按照视频步骤填写数据库信息，当然其实可以直接在新建网站内浏览填写，不过视频内没有录制就不说明了，填写完后记住保存后修改文件名就行。

　　填写信息后按照视频浏览安装页面，填写wordpress相关信息，之后就可以登录wordpress，注意低版本IE使用管理会有组件无法加载所以在2003上需要安装其他浏览器，作者本人使用的是火狐浏览器，至于为什么不用谷歌是因为最新的不支持2003系统。

　　最后，附加一个web管理数据库的phpmyadmin安装视频，因为使用的是2.7低版本，可以直接改名放置到网站目录内在浏览器输入地址登录使用就行。

　　至此，本人录制的教程就到此结束了。因为作者本人水平有限，其中有一些问题没有详细叙述，所以还请见谅。
