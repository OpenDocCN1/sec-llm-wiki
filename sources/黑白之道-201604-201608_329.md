# 一键搭建移动联通电信免流服务器间易教程

　　服务系统：Debian 7.x 64位 (支持腾讯云阿里云蜂巢Debian 7.x 64位)

　　推荐宽带：10M 以上

　　最后更新：2016-05-22 (1.加入康师傅Web流量控制)

　　重启服务：vpn (仅支持此命令重启服务)

　　流控后台管理命令：kang

　　脚本流控有已知BUG，如天数不计算，使用空账户崩溃等

　　工具 xshell vps一台

　　1) 使用 root 账号登录 Linux 服务器。

![](../Images/1085ca60b4200dc9b8316ea5e3f3bf3f.png)  
  
　　2)执行一键安装脚本：

　　wget file.kangml.com/debian/debian-kangml;chmod +x debian-kangml;./debian-kangml

　　授权码：kangml.com

　　如果网易蜂巢的debian不能用xshell5登录或提示某些未知错误的 可以在网页上先请执行 apt-get install wget;apt-get -y install ssh

　　3) 根据终端返回提示完成安装配置，安装有点慢 请耐心等待

      ![](../Images/f2728d94cbda1baee00d98472c96e1b2.png)

      ![](../Images/eda462418b8d5d3b5a988c0b1d93c34a.png)

　　4)并创建vpn账户和密码。

　　5) 安装完成后，复制终端输出的地址并下载链接中的配置文件。

      ![](../Images/0822c32071eb1f6f368cafbeae35f55c.png)

     ![](../Images/8fe22551df9d47e42e49e3d1b941b997.png)

　　7) 解压下载的压缩包，提取配置文件。

     ![](../Images/1003c442c72392131fd581ae6ad6ba7a.png)

　　CA证书：ca.crt

　　TLS密钥：ta.key

　　成品配置文件：OpenVPN.ovpn

　　8)安装openvpn

　　安卓 http://www.coolapk.com/apk/net.openvpn.openvpn?from=rss&version=1.1.16

　　苹果版自己去appstre下

　　9把配置文件OpenVPN.ovpn发送到手机并导入openvpn，输入账号和密码 移动网络下连接vpn

　　10选择合适的配置文件 一定要测试哪一个是免流的 不免流试试切换手机apn

　　11注意，要保持vpn在后台运行，不被管家杀死.免流一定不要开手机节

　　流，省流量的软件

　　免流验证方法 (注意延迟 不是能立即查到你的流量使用记录) 查询套餐详单 查不到你的上网记录 或者查到很少的流量 几k左右的流量

　　恭喜你免流成功

　**　附件**

**　　苹果手机安装教程**

**　　一、首先进入手机设置，点击下图苹果商店设置**

**        ![](../Images/216946b3e94b2e778ff6c7ea794c9b57.png)**

  

　　二、点击ID，如之前已有账号点击注销，没有ID直接输入美国ID (国内的id登陆搜不到openvpn)

　　注意你自己的id是下载不了openvpn的，为了安全起见。下载安装完openvpn后 请退出这个账号

        ![](../Images/9239870afb846713fe248f550f801679.png)

　　三、进入苹果商店 App Store，点击搜索，输入openvpn，下载安装

       ![](../Images/d0a2b75262ffcca4fa46cc376fc52ffd.png)

　　四、下载云流量苹果专用 ovpn在 其他应用打开之后，点击拷贝至OpenVpn

      ![](../Images/670d28e5810327ef93236b93b5a1d274.png)

　　五、打开之后点击 “ + ”

        ![](../Images/61660829bd08ee8596e328d5e5489c2a.png)

　　六、在User Id 里面输入账号，Password里面输入密码，点击Save和Disconnected变成绿色

        ![](../Images/b30bf1f846395b0a85b7864a368e6042.png)

　　七、打开Disconnected,出现此界面选择YES

       ![](../Images/2913f87a560464d0bf9eb65088ca66e0.png)

　　八、出现以下此界面则表示安装成功，手机右上角出现VPN的标志即为已安装

       ![](../Images/1b99970c160618d0c39b092ad7ac0175.png)

　　九.第一次使用请测试你自己的免流路线，1g扣1m左右的套餐流量是正常的。

　　恭喜你成功了
