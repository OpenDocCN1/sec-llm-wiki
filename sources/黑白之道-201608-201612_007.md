# 脚本病毒之源码分析

今天学习了一下脚本病毒感染模块的原理，了解感染模块的流程。准备好了吗，跟我一起在回顾一下吧!  

  

![](../Images/84046e1e9928eebcca716241743e6d5d.png)

  

　　脚本(Script)病毒是以脚本程序语言(如VB Script, JavaScript, PHP)编写而成的病毒。实际上，用任何语言都可以编写病毒，而用脚本编写病毒则更为简单，并且编写的病毒具有传播快、破坏力大等特点。例如，爱虫病毒、新欢乐时光病毒，就是用VBS (VB Script)编写的，称VBS脚本病毒。  

  

![](../Images/4becd9a05ba157ef30a2fc087db6e3d6.png)

  

计算机病毒的逻辑结构中包括感染标记、引导模块、感染模块、破坏模块等部分。这是计算机病毒的感染模块简化模型。

  

　　然后来看一下这个是感染模块的一个源代码，大家可以分析学习学习!

  

![](../Images/c85ec74c931d17b488cda1c9ddad5b5a.png)

  

　　下面我们用这个源码实战操作一下

  
　　一、检验目标文件，修改代码中的目标文件路径。  

  

![](../Images/492276406cacdb1ca0a2bab2565a7bcb.png)

　　二、感染目标文件

  
　　将“脚本感染模块.txt”的文件后缀名改为“vbs”，发现文件图标改变了，双击运行这个脚本出现弹框，确定之后会提示成功。  

  

![](../Images/a1629e46ba55fd0dd1a32511d1b58fc2.png)

  

![](../Images/63901ad1c2921ac2a8432946d18dfdf1.png)

  

　　然后我们再回过头来看目标文件图标和后缀都发生了改变，将目标文件用记事本打开文件内容变为病毒源码说明我们感染文件成功了。
