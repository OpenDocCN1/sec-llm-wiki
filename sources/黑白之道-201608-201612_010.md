主要就是说在运行java程序的时候比如burpsuite在打开之前尽量不要运行其它程序，否则可能会造成程序无响应。

快捷键：

CTRL + T ：要打开新的标签页  
CTRL + C ：要关闭脚本/程序运行。  
如果多个选项卡是开放的，那么你可以使用它们访问，number是选项卡的tab。例如，该数量将1对第一个选项卡，2代表第二个标签等。SHIFT+ ALT + number  
CTRL + w ：关闭当前活动的控制台。  
ALT +Enter ：全屏。
