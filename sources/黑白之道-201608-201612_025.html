Docker多容器间共享数据

有时候，一个工程中会需要好多容器。不同容器间需要相互通信，相互交换数据。


那么多个容器之间如何方便的共享数据呢？


有两种方法。


一、数据卷


挂载一个本地的目录到容器中作为数据卷。使用-v参数:

-v [本地目录] : [容器目录]

在/home/franky目录下创建test目录，在其下创建test.txt



挂载/home/franky/test这个目录到名为test的容器中的/test目录下。



docker ps查看正在运行的容器，可以看到test容器已经创建好在后台运行了。



从后台把它唤出来，可以看到挂载的test目录。ls一下，有刚刚创建的test.txt文件。



在test目录下创建一个文件后退出。



回到宿主机查看test目录，是不是多了一个文件？



二、数据卷容器


如果容器很多，各个容器之间需要共享一些动态的数据，那就可以用数据卷容器。


数据卷容器就是一种普通容器，专门提供数据卷供其它容器挂载使用。



创建数据卷容器dbdata:

# docker run -i -t -v /dbdata:/dbdata--name dbdata ubuntu

# echo 123 > dbdata/test.txt



另开终端，创建容器db1，使用—volumes-from挂载dbdata容器中的数据卷：

# docker run -i -t --volumes-from dbdata--name db1 ubuntu



去db1容器中查看/dbdata目录，有了在dbdata中创建的文件：



另开一个终端，查看宿主机根目录下已经有了dbdata，目录下有了刚刚在dbdata容器中创建的文件。
