# 刺猬用爪纹都能解锁iPhone手机！这种安全你敢信？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650440142&idx=2&sn=c4d429806a3e4d5058dd4d92ac22701c&chksm=83bbe42ab4cc6d3c82e1470684257631494354bf25e9c4ed890268a5082b92b862e6541fa71c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650440142&idx=2&sn=c4d429806a3e4d5058dd4d92ac22701c&chksm=83bbe42ab4cc6d3c82e1470684257631494354bf25e9c4ed890268a5082b92b862e6541fa71c&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

　　近日，一段刺猬的爪纹可以像人的指纹一样解锁iPhone手机的视频引起了网友的注意。安全专家向人们发出警示，指纹扫描识别可能并非我们想象的那样安全。

  

![](../Images/7374bf52edd2461536ab76fb6313c28b.png)  

　　通过这个视频可以看到，这只小刺猬成功用它的小爪子对iPhone手机解锁了。这个视频给我们敲了个安全的警钟，通过指纹给手机或者电脑锁屏虽然方便，但是可能并不像我们想象的那样安全。

  

　　虽然用户可以利用智能手机和其他设备上带有“生物识别”，比如指纹识别、面部识别和虹膜识别功能的扫描仪来进行身份验证，登录到网络或者电子支付页面，但是黑客可以偷走你的指纹，或者指纹的数字显示。

  

![](../Images/d515d058a64fb6a9b6ef962d1ef725bf.png)  

  

　　美国密歇根州立大学计算机科学与工程系教授Anil Jain表示：“可能我们对生物识别期望得太高的了，没有哪个安全系统是绝对安全的。”这位教授曾经通过用一个机主电子合成的指纹，协助警方对机主手机进行解锁。

  

![](../Images/29c6800094eea2f4644d309d1eb257d1.png)  

  

　　此外，指纹也很容易留在被用过的水杯上，或被收集在不同的数据库里。生物识别技术的发展进步是好事，给人们带来便利的同时，又给人提供了一个保障安全的途径，但是使用多重安保措施才是最好的防御办法。
