有时候使用 Docker Hub 这样的公共仓库可能不方便。我们可以搭建一个本地仓库，方便Team或者个人的使用。
docker-registry 是官方提供的工具，可以用于构建私有的镜像仓库。

在安装了 Docker 后，可以通过获取官方 registry 镜像来运行。
# docker pull registry

-d指定registry后台运行：
# docker run -d -p 5000:5000 registry

（可以通过 -v 参数来将镜像文件存放在本地的指定路径。
例如下面的例子将上传的镜像放到 /opt/data/registry 目录。
#docker run -d -p 5000:5000 -v /opt/data/registry:/tmp/registry registry
）

但是，此时如果把镜像push到这个仓库的话会因为没有配置https而报错。需要在配置文件添加--insecure-registry选项，允许使用http协议。
# vim /etc/default/docker
添加的内容如图所示。
 

　　(网上给的是DOCKER_OPTS="$DOCKER_OPTS --insecure-registry=192.168.177.149:5000"，而这句话我用了会报错。改成DOCKER_OPTS="--insecure-registry=192.168.177.149:5000"反而对了。我用的是ubuntu16.04)

　　重启docker

　　# service docker restart

　　若能重启成功，证明配置好了。

　　查看本地有什么镜像：

　　# docker images



 
　　使用 docker tag 将你要上传的镜像标记为 YOUR_IP:5000/test1 (格式为 docker tag IMAGE[:TAG]

[REGISTRYHOST/][USERNAME/]NAME[:TAG])。

　　# docker tag barnybug/mysql-server 192.168.177.149:5000/test1


 

　　push一个镜像到本地仓库：

　　# docker push 192.168.177.149:5000/test



 

　　看到如上图说明是上传成功了，同局域网里的机器可以从你这里pull镜像了。

　　我用一台同局域网里的虚拟机，系统为ubuntu14.04演示。

　　首先，pull之前还是别忘了修改配置文件/etc/default/docker, 不然会报错。添加

　　DOCKER_OPTS="--insecure-registry=192.168.177.149:5000"

　　然后重启docker

　　# service docker restart

　　# docker pull 192.168.177.149:5000/test
