# 数据库不会备份怎么办? 来看这里！

       数据库的建立和使用极大的方便了人们对数据的管理和应用，同时数据的稳定性和可恢复性也至关重要，因此要定期对数据库的数据进行备份和整理。

  
　　通过使用数据库系统自带的相关功能即可实现对数据库的备份与恢复。  

  

![](../Images/47b2b4b19a6e86285d5d872db374638e.png)

  配个图放松一下

  

　　利用sql语句备份数据库so easy!

　　1、 首先在程序中开启mysql.exe输入密码，检查一下版本”select version<>”，再看一下数据库列表中有哪些数据库”show databases”

  

![](../Images/70c8af626af30cb1f5d29e9499d2ed0b.png) 

  
　　2、 进入想要备份的数据库中”use 数据库名”(这里我要进入的是mysql数据库)，查看此数据库存在那些表”show tables”

  
![](../Images/c58bc59fbd42a573cec507d4bc386d4b.png)   
　　3、 命令“describe help\_keyword”显示help\_word表的表结构，”select \* from help\_keyword”,看这个表里的所有数据。

  
![](../Images/75a3bad1576b91402e714e0528915bd7.png)   
　　4、 输入如图命令，修改help\_word表中id=459中的数据。”select \* from help\_keyword”,查看添加结果。

  
![](../Images/a5bd093afce6cd0362dca9ffe4936303.png) 

  
　　5、 “select \* from help\_keyword into outfile ‘c:/abc.sql’”，就是备份help\_keyword数据表。然后看一下本地的C盘看到生成了的abc.sql文件。

  
![](../Images/d37240daf1a1f505ec237d767ec27f8e.png)   
![](../Images/2c14ae8dd036c82c69701afd76d993ce.png)   
　　这样备份就搞定了，是不是很easy，下面我们来测试一下看怎么恢复。

  
　　输入”delete from help\_keyword where help\_keyword\_id=459”,删除表中的test记录。查看结果显示id=459这一行被删除了。”load data local infile ‘c:/abc.sql’ into table help\_keyword”这条命令可以使用生成了的abc.sql进行恢复。
