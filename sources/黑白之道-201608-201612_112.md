# 内核升级，对抗脏牛(Dirty COW)

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650439810&idx=3&sn=4f88a0c090c369a56e650de7cc8eb0ca&chksm=83bbe566b4cc6c703d8f8038ce122f6c9fbdfee4410c3849532f083062589730f894ba9b8c03&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650439810&idx=3&sn=4f88a0c090c369a56e650de7cc8eb0ca&chksm=83bbe566b4cc6c703d8f8038ce122f6c9fbdfee4410c3849532f083062589730f894ba9b8c03&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

　　漏洞描述 漏洞编号:CVE-2016-5195

　　漏洞名称：脏牛(Dirty COW)

　　漏洞危害：低权限用户可以利用该漏洞修改只读内存，进而执行任意代码获取 root 权限。

　　该漏洞的影响

　　影响：

　　①没有权限的本地用户可以使用此漏洞获取写访问权限，修改只读内存映射，从而增加他们在系统上的特权。

　　②该漏洞允许攻击者使用本地系统帐户修改磁盘上的二进制文件，绕过标准的权限机制，这些权限机制通常用于防止修改没有适当的权限集。

　　影响范围：

　　Linux内核>=2.6.22(2007年发行)开始就受影响了，直到2016年10月18日才修复。

　　漏洞相关细节

　　根据官方发布的补丁信息，这个问题可以追溯到2007年发布的Linux内核。现在还没有任何证据表明，2007年后是否有黑客利用了这个漏洞。但是安全专家Phil Oester发现一名攻击者利用该漏洞部署攻击，并向Red Hat通报了最近的攻击事件。

　　虽然业内并不认为"脏牛"对Linux生态系统构成了致命危险，不过还是应该及时更新系统。

　　因为“脏牛”漏洞构成的威胁还是真实存在的。在接受V3的采访时，Oester披露，有攻击者上传并执行CVE-2016-5195漏洞利用，攻击了他管理的某个网站。

　　修复方案：

　　升级更新

　　1.首先我们导入公钥。

　　rpm --import https://www.elrepo.org/RPM-GPG-KEY-elrepo.org

　　 ![](../Images/34286cbdda39cf5611b672289162283e.png)   

　　2.安装源

　　rpm -Uvh http://www.elrepo.org/elrepo-release-7.02.el7.elrepo.noarch.rpm

       ![](../Images/96cff8818257ff8b2051f34439e41cd3.png) 

　3.安装内核

　yum --enablerepo=elrepo-kernel install kernel-ml-devel kernel-ml -y

　    ![](../Images/949d6922d1ac12f2d4c1e7743b13e410.png)   

　　4.修改内核启动顺序，默认启动的顺序应该为1,升级以后内核是往前面插入，为0

　　grub2-set-default 0

　  
       ![](../Images/e801eba9170e152cb229c35844899af4.png)   

　

　5.重启系统

　　reboot

  

　　6.查看内核版本

　　uname -r

　  
       ![](../Images/31ff70914b74be74946b5d5a46491bb3.png)
