# 把一站式便利的云安全服务点连成线-上海柯力士信息安全与北京华安普特网络科技有限公司达成战略合作

　　随着云计算的快速崛起，越来越多的企业进入到云领域。云计算产品及解决方案的日趋丰富也使云安全上升到重要地位。数据显示，目前全球云安全服务市场规模大约为36亿美元，整体云安全服务市场规模增长将达到23%，据行业专家分析，预计到2022年，整体市场规模将达到120亿美元左右。

  

　　而一场席卷半个美国的网络信息大洪水更是引起了全世界对于信息安全服务的关注，信息安全企业纷纷寻找着属于自己的应对道路。整合现有资源针对可能发生的风险进行全面的一站式信息安全服务成为当下流行的做法之一。然而面对日益复杂的信息安全形势日渐变化的信息安全风险，要实现一站式信息安全服务，以单家信息安全企业而言是比较困难的，那为什么不选择合作呢?上海柯力士信息安全与北京华安普特网络科技有限公司就在这种大环境下握手达成了战略合作协议。

  

　　两个信息安全的站点确定一条安全的防线

  

　　那么为何双方会选择合作呢?首先我们介绍一下双方。

  
  

  

![](../Images/8aeb9e581657cf4ddedd377f4de0d9e2.png)  

  

  

　　北京华安普特网络科技有限公司是一家从事信息安全行业、提供信息安全服务的技术型安全公司，董事长为中国知名互联网安全站点华夏黑客同盟网站站长(怪狗)。

  

       北京华安普特网络科技有限公司(以下简称 华安普特)成立于2006年8月，总部位于北京。华安普特将确保互联网的安全和普及网络安全知识作为己任，通过不断创新安全技术，全方位高品质且具有竞争力的安全产品以及专业的安全服务，力争在短时间内成为国际知名网络安全公司。

  

　　华安普特基于多年网络安全领域的经验，华安普特在互联网基础安全、移动安全等领域，为客户提供入侵检测/防护、抗拒绝服务攻击、远程安全评估以及Web安全防护等产品以及专业安全服务。

  

　　华安普特拥有多年的信息安全行业服务的经验，提供高品质的网络安全产品、双赢的运作模式以及创新的发展方向与柯力士信息安全不谋而合。对于一站式信息安全服务双方达成了共识，而这正是促使柯力士与华安普特达成战略合作契机。

  

![](../Images/5b00b90fd5be5bfb9d970743de400b33.png)  

  

　　上海柯力士信息安全技术有限公司是一家国内领先的信息安全服务供应商。

  

　　柯力士专注于全球漏洞特征的收集，最新漏洞信息的发布，并提供专业且先进的漏洞检测服务、产品，以及其它相关信息安全产品与服务。

  

　　柯力士已陆续被上海市信息安全协会，山东省网安总队，广东省信息安全协会推荐为行业领先的安全漏洞扫描服务提供商。

  

　　同时，公司每年为各大企业及集成商提供数万次的大批量专业扫描服务，并已承接了更多政企委托的扫描任务，机构在业界得到了高度认可与一致的好评。上海柯力士信息安全技术有限公司同时获得了中国信息安全中心颁发的信息安全服务中的信息安全风险评估(ISV-RA)以及应急处理服务资质(ISV-ER)两项等级资格证书。柯力士专注于漏洞扫描，其核心扫描技术在业界遥遥领先，被广泛行业认可。

  

　　在刚刚结束不久的杭州G20峰会，安犬漏洞扫描云平台以高效精准的漏洞发现，详实易懂的漏洞报告，广范围大批量的漏洞扫描功能，顺利完成G20的信息安全护航。经历了G20全球性的实战考验之后，安犬漏洞扫描云平台得到了宝贵的实践经验，成为柯力士信息安全一站式信息安全服务中的重要一环。

  

![](../Images/809eca4d0afbecadb247b150967373cf.png)  

图为柯力士创始人Jonathan(颜明华)与华安普特董事长“怪狗”的合影  

  

　　一站式的信息安全

  

　　我们为什么要做一站式的信息安全服务?一站式的优势在于全，能面对多种不同的信息安全问题。并且把线上与线下资源结合起来，对客户进行全方位的服务，一套组合能切实解决客户问题，而互联网+传统业务的服务模式更能填补单一方面服务的缺失，给客户更优质的信息安全体验。柯力士与华安普特秉持的共识之一就在于此。

  

　　连线，构建纵横南北的信息安全血脉。

  

　　此次双方将达成以下几个重要方面的合作：

  

　　1.柯力士与华安普特的合作将共建云端防线，共抗信息安全危机：柯力士核心产品安犬漏洞扫描云平台与华安普特云安全服务深度集合，全方面为客户提供信息安全服务。

  

　　2.双方将在多种企业商业资源方面进行深度合作，互通有无，共享优势信息与技术资源。华安普特拥有着深厚的技术底蕴，董事长也拥有丰富的技术背景，其技术实力获得了国内外政企机构的认可，从技术上来讲处于国内领先地位。而柯力士拥有着兼收并蓄的儒家传统文化管理模式，其整合国内外资源的安犬漏洞扫描云平台正是其重要的成果，地处长三角，无论从物理层面和技术服务层面来讲都拥有着极为广阔的市场，技术与市场的结合合作正是互联网新概念信息安全理念的体现。

  

　　3.一南一北，用一站式的信息安全服务思想，人性化的优质安全服务理念，将一种属于我们的安全服务标准推广至安全行业，从而促进信息安全行业发展。
