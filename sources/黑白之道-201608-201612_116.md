# WebGoat漏洞环境搭建并配置为局域网访问

webgoat是owasp的一个漏洞测试环境，搭建后可以在上面测试学习，并且有提示和教程。只是一点，这个网站都是英文的= =，中文版的不知道有没有。  
webgoat下载：https://pan.baidu.com/share/link ... fid=838773808964934  
  
jdk 32位下载：  
https://www.baidu.com/link?url=E ... e0000000003581171be  
  
jdk下载好后先配置java环境变量和tomcat环境变量，参考网址：  
http://wenku.baidu.com/link?url= ... r7sI5ZPK7n6-5Abluoq  
  
运行webgoat\_8080.bat，则访问地址是localhost:8080/WebGoat/attack 用户名/密码：guest/guest  
（如果运行的是webgoat.bat，则访问地址是localhost/WebGoat/attack）  
  
配置局域网访问：  
如果你运行的是webgoat\_8080.bat，修改tomcat目录下/conf/server\_8080.xml  
用文本打开该文件，CTRL+F查找127.0.0.1。找到如下代码：  
<Connector address="127.0.0.1" port="80" maxHttpHeaderSize="  
修改为：  
<Connector address="0.0.0.0" port="80" maxHttpHeaderSize="  
然后重启服务器。  
  
注意，webgoat.bat、webgoat\_8080.bat分别和server\_80.xml，server\_8080.xml对应。你用哪个端口就修改哪个端口对应的xml文件。  
  
搭建webgoat环境其实不难，主要是环境变量配置有些麻烦。然后因为是要给华盟内部培训用，需要设置局域网访问，搞懂这个耽误了点时间。
