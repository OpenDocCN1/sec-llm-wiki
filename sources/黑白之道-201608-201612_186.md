# 学习Metasploit溢出Distcc后门漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650439579&idx=2&sn=6fb879da0a92d34d06471de02119f1d9&chksm=83bb1a7fb4cc936994d0ab96ee96ae3db326c130ddcc056f3869b9611d5fb096c7094e95964c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650439579&idx=2&sn=6fb879da0a92d34d06471de02119f1d9&chksm=83bb1a7fb4cc936994d0ab96ee96ae3db326c130ddcc056f3869b9611d5fb096c7094e95964c&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

　　distcc是用于在网络中多个机器间发布C、C 、Objective C或Objective C 代码的程序。

  

　　学习目的：利用Distcc后门漏洞获取目标主机的管理员权限

  

　　原理：Distcc用于大量代码在网络服务器上的分布式编译，但是如果配置不严格，容易被滥用执行命令，该漏洞是XCode 1.5版本及其他版本的distcc 2.x版本配署对于服务器端口的访问不限制。

  

　　1、 首先使用nmap命令对目标机器192.168.1.3进行端口扫描，查看有开启哪些端口。

  
![](../Images/2e77db5afb5272e5fe1c295d1f739e79.png)   
　　2、 输入命令“msfconsole”开启MSF框架。

  
![](../Images/1024251369154130d21eb731a206657b.png)   
　　　3、 输入命令“search distcc\_exec”,搜索和distcc相关工具和攻击载荷。

  
![](../Images/82e0940c24dcd0d7e4671ae188e667ac.png)   

　　4、 写入如图命令，启动漏洞利用模块，进入到distcc\_exec路径下。

  

![](../Images/f5bb04ce1032c612d2ecf2c437315c65.png)   
　

　　5、 “show options”命令查看需要修改设置的相关选项，yes是必须填写的参数。

  
![](../Images/b44371e0eab93c7eec1cd86e4c2efff3.png)   
　

　　6、 设置目标主机的IP地址“set RHOST 192.168.1.3”

  
![](../Images/7a42b0c2fac6a39eb80dab31eb45d2bc.png)   
　

　　7、 然后开始攻击目标主机，输入“exploit”开始攻击。

  
![](../Images/e426d7273f020329104b9c8c3d2dbe53.png) 　　

　　8、 在终端中输入“id”查看获得的权限，输入ifconfig查看相关信息。

  
![](../Images/c9d942ce6fab85aad424b9af9186e8e6.png)
