# 构造图片木马，绕过文件内容检测上传shell

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650439479&idx=2&sn=69fa25b87ebe0e56254ac2412234e14d&chksm=83bb1ad3b4cc93c597fa944224843afdad626f22095a65dc043ddcc3243485e5d9f2ce2f891c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650439479&idx=2&sn=69fa25b87ebe0e56254ac2412234e14d&chksm=83bb1ad3b4cc93c597fa944224843afdad626f22095a65dc043ddcc3243485e5d9f2ce2f891c&scene=27#wechat_redirect)

　　一般文件内容验证使用getimagesizeo函数检测，会判断文件是否是一个有效的文件图片，如果是，则允许上传，否则的话不允许上传。句话木马插入到一个【合法】的图片文件当中，然后用菜刀远程连接。

　　1. 在火狐浏览器中输入地址192.168.1.3：8080/up,进入文本上传页面。

　　

![](../Images/a6b70570d907070d525d71f9580d9c4a.png)

  

　　2. 选择一个php的木马文件，将后缀名.php改为.php.jpg 点击上传页面提示不允许上传，服务器对上传文件内容进行了检测。

　　

![](../Images/ab8ab91fbc5903f4e3e5ae3cd04a089f.png)

  

　　3. 开始制作图片木马，在c:下的文件夹中存在的pic.jpg的图片文件。打开cmd，进入木马存在的文件夹。

　　

![](../Images/94bd708de955b73708605eaa027bcf82.png)

  

　　

![](../Images/3aa16bcfc2a2c77dc1ca82754134cd98.png)

  

　　4. 输入copy pic.jpg/b+lubr.php/a PicLubr.jpg。将lubr.php插入到pic.jpg中。

　　

![](../Images/91407c17584a5ab2a6a31c430da4e82c.png)

  

　　5. 在上传文件中浏览上传piclubr.jpg文件，将名字重名命为piclubr.jpg.php.然后上传成功复制路径，访问木马文件。

　　

![](../Images/76fc5df1798320c2acfc87ecfbb7a8bd.png)

  

　　

![](../Images/bbc8b4c6117da2d3ff7641f738c63ccd.png)

  

　　6. 使用菜刀连接木马地址，输入密码、选择脚本类型然后添加。双击添加的shell就可以看到网站的完整目录了

　　

![](../Images/61e35b6cd6b741f6fae15122f7171548.png)

  

　　

![](../Images/171a0d78bf875ffb6ad6059888a22550.png)
