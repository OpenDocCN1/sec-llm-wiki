# 利用mysql-udf提权

　　这是我们上传的phpshell，上次已经讲过通过漏洞上传大马，这个同理上传phpshell

  

　　1.输入我们phpshell的密码登录进去

  

![](../Images/c9c1ed9f6e636d2c6d716281ac6d44fc.png)

  

　　2.首先可以扫一下开放的端口，看到有3306开放端口说明安装有mysql数据库

  

![](../Images/5c2d1455f32a88699f5d262ebb06fc45.png)

  

　　3.利用Mysql-udf提权，点击【mysql-udf提权】，在右侧输入一直的数据库连接用户名和密码，点击【mysql链接】

  

![](../Images/5aebedb0b4aec3ff9bb0e70338c2e039.png)

  

　　4.点击【安装DLL】

  

![](../Images/725dd648c03920bb19abc63f68168101.png)

  

　　5.我们新建一个用户，选择【添加管理员】，点击【执行】

  

![](../Images/98d43b9d3bb57347172a739182d7ab5a.png)

  

　　6.将我们新建的用户设置为管理员运行，选择【设为管理组】，点击执行

  

![](../Images/92c5c9a0db0f9b5c6324807b0f6657e5.png)

  

　　7.输入在cmd执行中输入【net user】查看当前用户 发现我们新建的用户也在里面，说明新建成功

  

![](../Images/1234692f7a2db3042b0ca92180032441.png)

  

　　8.输入命令【netstat -an】查看所以开放的端口，看到有3306

  

![](../Images/1245f73aebc4ea6a0d7e24f751a57c14.png)

  

　　9.输入【ipconfig】，可以查看本地ip、mac、网关等信息

  

![](../Images/e87be4a4b3d787229a5e6917340e2009.png)

  

　　10.远程登陆我们新建的管理员用户，登陆上以后 咳咳 你想干嘛?!

  

![](../Images/75fd2e90a512f224d89fdfd4009b27fc.png)
