    测试dell服务器，io读写时间，分析服务器性能，公司用于采购最新的存储设备时参考数据。


1.    将文件dpack_x86.tar.gz上传到要测试的服务器，使用winscp上传

2.    先创建一个文件夹          mkdir dellp

3.    移动dpack文件到dellp文件夹  mv dpack_x86.tar.gz dellp/dpack_x86.tar.gz

4.     进入文件夹                                cd dellp

5.     解压dpack_x86.tar.gz          tar -xvf  dpack_x86.tar.gz

6.     执行./delldpack --extended


检查是否安装GCC,如果没有安装gcc  执行yum install gcc
如果是/lib/ld-linux.so.2报错，执行 yum install glibc.i686
如果是libstdc++.so.6报错，执行yum install libstdc++.so.6
这个原因是x64位系统使用了x86的程序造成的。所以在此之前要确定系统版本以及位数。
