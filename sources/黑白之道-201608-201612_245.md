## 项目简介

PenQ是一个基于Linux版火狐打造的渗透测试浏览器套装，它配备爬虫，先进的网络搜索，指纹识别，匿名浏览，Web服务器扫描，生成报告等功能。

*   OWASP ZAP
    
*   Wfuzz Web Application Fuzzer
