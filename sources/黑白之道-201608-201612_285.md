# 有了webshell用Mysql\_UDF提权

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650439317&idx=2&sn=00cfc0e5870875e4248bfa728210440d&chksm=83bb1b71b4cc92673a0b118aa812e1927b99b4999a46f0bbd5fd0b308e05e155d8b69269a0f7&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650439317&idx=2&sn=00cfc0e5870875e4248bfa728210440d&chksm=83bb1b71b4cc92673a0b118aa812e1927b99b4999a46f0bbd5fd0b308e05e155d8b69269a0f7&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

　

　　原理：

　　利用webshell读取网站数据库连接配置文件，获取数据库链接密码

　　通过webshell上传mysql\_udf文件，添加系统文件

　　一、利用webshell读取服务器信息，发现服务器系统安装mysql数据库

　　1在网站中输入webshell的路径，输入密码(admin)

　　![](../Images/4fe06e15509e565f0fdce9684e8ee57b.png) 

  

　　2利用左侧功能“端口扫描”，结果显示开放3389并安装有mysql数据库

　　

![](../Images/69e4acad5f82a726f096055e7c30f816.png)

  

　　3利用“mysql\_udf提权”功能，在右侧输入已知的数据库用户名和密码(root 123456)，然后安装DLL，在下面的选框中选择“添加管理员”点击执行。

　　输入命令“net user spider spider /add”会看到命令成功完成。然后选择权限为管理组。

　　

![](../Images/7536d0e33260817694fcdd57bb96398a.png)

  

　　4左侧栏选择“CMD命令”输入命令 net user 执行查看用户，netstat –an 查看端口。

　　

![](../Images/6af36900f8101b7ef78aeb3fc3de9d8e.png)

  

　　

![](../Images/86fbf27e4e851303a7390a5abbf3d945.png)

  

　　5用新建的用户远程连接进去就ok了

　　

![](../Images/c4d6163c62abbcb2cfc16f375f6ab695.png)
