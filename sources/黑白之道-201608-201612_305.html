微信过中秋节，不能群发有点麻烦，搞个脚本发送一下祝福，还是可以的！


我在mac系统下测试的，

运行环境 python 2.7

先安装 pip,再安装

sudo easy_install pip

sudo pip install requests

sudo pip install BeautifulSoup

sudo pip install bs4

组件都安装完之后就可以了


python wechat-sendall.py -s

运行之后，让你微信扫码，完了就开始群发了！



他一个一个读取，读用户名，再发中秋快乐！
