# 经典回顾：Webshell提权之Tomcat

论坛某大牛发的shell，着么半会拿下...小菜分享经验..大牛莫笑

查看端口，有8080，tomcat会用到这个端口，而且权限很大

![](../Images/3c1fd0cd3a01b4046b3e0c672dacedb9.png)

　　用tasklist/svc命令查看系统进程信息，果真有tomcat

       ![](../Images/c60cff57e53693dc4802c93f624c9ab4.png) 

　　来到tomcat目录conftomcat-users.xml，查看到其明文密码

       ![](../Images/542286ee5b601eef07e25b61f85ffdc5.png) 

　　到tomcat后台登录上去，上传war包

       ![](../Images/7983dd6cc747326b0990fb153c4bc982.png) 

　　查看下系统用户，经测试，不可以直接添加用户，但可以把系统内置帐户添加到管理员

      ![](../Images/fc1099dac3042094d924bba172ef0423.png)

　　找到系统guest用户，应为guest用户密码为空

        ![](../Images/74e3139b56885244f2e9b727672306ae.png) 

　　使用net user HnabGuest /active:yes命令激活此guest用户

         ![](../Images/d6c9799988ab65490fa47362a554058b.png) 

　　用net localgroup administrators HnabGuest /add命令添加到管理员

         ![](../Images/8b63c76cf123c8e367bcc4a90003a5cf.png) 

　　得到系统终端端口9021

        ![](../Images/1cce6716752b09a0eaef9c9fd7070f31.png) 

　　成功用guest用户登录上去

       ![](../Images/8386aabc25fab63bfccbc5dce957ebf0.png)
