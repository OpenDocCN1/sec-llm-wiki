Sysstat 是一个软件包，包含监测系统性能及效率的一组工具，这些工具对于我们收集系统性能数据，比如CPU使用率、硬盘和网络吞吐数据，这些数据的收集和分析，有利于我们判断系统是否正常运行，是提高系统运行效率、安全运行服务器的得力助手；
1.安装Sysstat软件，命令是 yum install sysstat 
 
sysstat安装好后，就会有iostat、mpstat、sar、sa的功能。

2.sysstat工具包提供的主要命令：iostat mpstat sar

（1）sar的用法: sar [ 选项 ] [ <时间间隔> [ <次数> ] ]

1. 输出CPU使用情况的统计信息，每秒输出一次，一共输出5次，命令如下：sar -u 1 5

2. 显示I/O和传送速率的统计信息，命令如下：sar -b 1 5
