# 【亲测】教你绕过百度云大文件下载限制

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650438822&idx=1&sn=7ada733d919fc2eb39f286ba3f29b2ae&chksm=83bb1942b4cc9054342c53c02716ca63bebe284791420169489e7e92336562db52a311c0ee8d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650438822&idx=1&sn=7ada733d919fc2eb39f286ba3f29b2ae&chksm=83bb1942b4cc9054342c53c02716ca63bebe284791420169489e7e92336562db52a311c0ee8d&scene=27#wechat_redirect)

平时经常用百度云分享文件，但是呢，在遇到大文件时候老弹提示让下载百度云管家，真烦，网上还有方法说用迅雷可以绕过，什么？，我为了不用云管家就得下个迅雷？no，no，no，迅雷我也不想用，任性的我就是既不想用你的云管家又要下你的文件，这时候该怎么办呢？

![](../Images/787f30e4d24839fcf331bac493317a96.png)  

首先给文件一个加密分享，然后将链接发到手机上，在手机浏览器里打开链接填入提取密码

![](../Images/824fc78186b2faff976121822b156762.png)

然后转到safari打开

![](../Images/e5c0f5c4e0f7f6c771957f4d84a096b2.png)

打开之后点击地址栏，就显示一个长链接，然后将此链接复制，发送到电脑

![](../Images/3e33ed3c244b0ea5c6f2541b366c955d.png)  
放到地址栏打开，你就会发现.......还是原来的样子还是下载不了！哈哈，不用急，还没完呢，这时候大家会发现链接地址不一样了，现在把地址里的share改为wap，当你访问改好后的网址的时候它会有多次跳转，中间会有一次是手机端可以下载文件的界面，最后再给你跳回电脑端不能下载文件的界面，所以咱们一访问，立马按键盘的Esc键让它停止跳转即可。

![](../Images/236cc1608e881010e3c58c82b813be8d.png)  
停下来了，截图证明新鲜可用~

![](../Images/79277b00ab7eaa0b10ff39377c5b782b.png)  

嗯，点击下载，可爱的下载框出来了~~

![](../Images/7e9cc49af6835a6cf09f357d6fd77d79.png)

可以正常下载，木有任何问题，然后终于可以去随意下载我想要的文件而不用安装管家了。
