废话不说，直入主题

这个网站第一眼看上去就很廉价

甚至是看一看就知道哪里有漏洞

  

点了两个链接访问到  

> asp?id=523

单引号跳转500

and 1=1返回正常页面

and 1=2返回空数据页面

OK，疑似存在SQL注入

丢进sqlmap得到以下信息

> web server operating system: Windows 2008
> 
> web application technology: ASP.NET, Microsoft IIS 7.5, ASP
> 
> back-end DBMS: Microsoft Access

  

access得到一个admin

以下是字段：

>  Column     | Type

此时，夜深了

![](../Images/15774b2eba3851121e76d30b7274470f.png)

再把这些站导出来，批量扫一波目录

有些网站的上传点不在主页上显示

耐心下来从新翻一遍所有网站

既然没办法注册
