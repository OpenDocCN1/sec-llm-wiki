清晨是一天的开始，像个男人一样的开始战斗吧。这个库的api文档库在这里http://pexpect.readthedocs.io/en/stable/api/index.html主要的组成部分：Spawn类Run函数ExceptionsUtility我们主要介绍的是spawn类和pxssh（这个是控制一个ssh会话的类）Sapwn类的初始化函数：


  1. __init__(<i>command</i>, <i>args=[]</i>, <i>timeout=30</i>, <i>maxread=2000</i>, <i>searchwindowsize=None</i>, <i>logfile=None</i>, <i>cwd=None</i>, <i>env=None</i>, <i>ignore_sighup=False</i>, <i>echo=True</i>, <i>preexec_fn=None</i>, <i>encoding=None</i>, <i>codec_errors='strict'</i>, <i>dimensions=None</i>)



所以我们创建这个产卵类的对象的时候我们可以调用这样子做：


  1. child = pexpect.spawn('/usr/bin/ftp')child = pexpect.spawn('/usr/bin/ftp', [])


第一种是直接在command这个参数的地方给出命令和相应的参数第二章是单独的给出，command参数给出命令，args给出参数，一个列表又如我们想要记录这个过程中的日志到某一个文件，我们可以这样子做


  1. child = pexpect.spawn('some_command')fout = open('mylog.txt','wb')child.logfile = fout


让这个类的logfile变量指向一个文件对象之后我们想要去获取程序的返回，针对性的进行反应，这时候我们就用到expect函数了。这个函数的原型为：expect(pattern, timeout=-1, searchwindowsize=-1, async=False)Pattern参数是让我们提供我们预计划的程序输出，如


  1. index = p.expect(['bar', 'foo', 'foobar'])


P为spawn的对象，这个例子是我们认为程序可能输出这三个值，expect函数会从目标程序输出的一个缓存区中匹配这些值，比配到bar时返回0，foo为1pexpect.EOF, pexpect.TIMEOUT我们可以使用这两个eof和timeout来捕获异常，而不是通过一个抛出异常来捕获。程序的一般结构为：


  1. index = p.expect(['good', 'bad', pexpect.EOF, pexpect.TIMEOUT])


  1. if index == 0:    do_something()elif index == 1:    do_something_else()elif index == 2:    do_some_other_thing()elif index == 3:do_something_completely_different()
