## 简介

Kadimus是用于本地文件包含漏洞检测和入侵的LFI扫描器和利用工具。

![](../Images/69e82bac662980bedf259256ed384f2c.png)

## 安装

```
$git clone https://github.com/P0cL4bs/Kadimus.git$ cd Kadimus
```

然后可以运行配置文件：

```
./configure
```

然后：

```
$ make
```

## 特点

*   检查所有url参数
    
*   /var/log/auth.log RCE
    
*   /proc/self/environ RCE
    
*   php://input RCE
    
*   data://text RCE
    
*   源码公开
    
*   多线程扫描
    
*   通过HTTP请求传输command shell
    
*   代理支持(socks4://, socks4a://, socks5:// ,socks5h:// 和 http://)
    
*   支持绑定代理socks5连接
