渗透测试

  

渗透测试过程包括漏洞探测和提供概念证明（Proof of Concept, POC）攻击，

以证明系统漏洞确实存在。

威慑安全（offensive security, OS）

渗透测试（Penetration Testing或者Pen Testing, PT）

！辨析：渗透测试/PT与漏洞评估/VA（Vulnerability Assessment）的区别——

VA：检查系统和服务是否存在潜在安全问题的过程；PT比VA更进一步

PT：通过执行漏洞利用和POC攻击，即模拟黑客行为并提供攻击载荷（payload）

！区分：黑帽与白帽——二者的差异——授权、动机、保密

Linux系统上手动编译和安装软件基础方法：apt-get指令

APT（Advanced Package Tool, 高级软件包工具），使用命令行方式，

自动解析软件间的依赖关系；是对过去“依赖地狱”（dependency hell）的重大改进。

如，安装网络映射工具Cheops，在命令行输入

apt-get update

apt-get install cheops

又如，重装Medusa，命令行输入

apt-get update

apt-get install medusa

如不使用命令行，可使用GUI（Graphical User Interface, 图形用户界面/接口）

与API交互；当前通行的图形交互前端软件是Aptitude

光盘重装系统：“刻录iso格式文件”（burning an iso），在BIOS中将光驱设置为优先启动。

如仍无法正常启动，选择“图形界面安全模式”（in Safe Graphical Mode）启动Backtrack

默认用户名 root 默认密码 toor

登陆后，在系统提示符“root@bt:~#”后输入命令 startx，启动GUI

在启动器中输入 konsole，启动终端会话

出于安全，BT默认网络功能不自启（否则会立即向全网申请DHCP服务器和IP地址）

如需启动网络，打开终端，输入 ifconfig -a，获得本机所有可用接口列表；

其中“lo”是计算机本地环回接口，“eth0”是计算机上第一张以太网卡（VM默认主接口）

如打开指定网卡，在终端输入 ifconfig eth0 up，将第一个网络设备接口设置成打开

至此，接口打开，如需手动分配IP地址，终端输入 ifconfig eth0 up IP；

IP配置完成后，还需配置网关和域名系统（DNS）服务器

！“设置linux网络接口卡”（setting up nic linux）

如不考虑网络隐身，获取地址的简便方法是通过DHCP分配，终端输入 dhclient eth0

关闭系统 poweroff 重启系统 reboot

隔离环境：断开连接、改变路由流量、无线NIC关闭

渗透测试基本步骤：搜集信息、漏洞扫描、漏洞利用、维持访问

  

*   信息搜集/侦察（Reconnaissance）：获得目标IP列表和攻击向量（attack vector）
    
*   扫描（scan）：端口扫描、漏洞扫描等
    
*   漏洞利用（exploitation）：使用攻击载荷（payload），获得管理员临时访问权限
    
*   维持访问（maintaining access）：创建后门，永久控制系统
    
    ！5.“隐藏痕迹/销毁证据”
