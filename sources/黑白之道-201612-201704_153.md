# 原创 windows7系统封装（二）系统基本优化

今天给大家带来新一期的教程，上节课我们讲了封装系统的基本步骤，这节课我们要对系统进行优化，根据用户的需求开启关闭一些不常用的设置，让系统有个纯净简洁的界面，使系统更流畅。

  

Okay，下面来看我操作。

  

首先封装不推荐联网，目的是防止病毒感染系统。  

  

![](../Images/6013da46f4eeda55caa1fa42c4ca0c53.png)

  

下面对系统进行基本设置。

  
1.我们把系统最高权限打开，并且使用最高权限（这样做是方便以后大家在用的过程中，由于某些软件打不开权限不够的问题）。操作步骤：开始→计算机→管理→本地用户和组→用户→administrator→属性→去掉“用户已禁用”勾选→应用确定→切换用户为administrator→删除系统创建用户。

  
![](../Images/8894168de400f6f1423d425cfffc4cb6.png)

  

![](../Images/6963dfcda065e950dfa2dba71e01daa9.png)  

  

2.系统基本设置大家根据个人喜好对系统进行基本设置，例如：开启桌面图标，系统通知设置，防火墙，系统更新等。大多数是在控制面板中就可以设置的。  
  

![](../Images/e36c3f692303b42336ac038f0a5e9a90.png)

  

![](../Images/43e4746bd37f63f99d7af0c520801f9e.png)

  

![](../Images/21c7e7cda18d13f41290261f73e2fae8.png)

  

这里我们先把防火墙关闭，目的是为了在封装系统时避免未知错误，而给过程带来不便的影响，如果有需要，可以在安装系统完毕之后再把防火墙打开。

  
3.安装常用补丁和运行库系统补丁对于个人系统来说还是很重要的，推荐大家去微软官网下载windows7集成补丁包。集成运行库的目的是为了方便大家可以直接运行一些软件，比如说studio，office，adobe的一些软件，当然，玩游戏也是要运行库的，推荐大家去微软官网下载运行库。（这些都是按照个人需求来安装的，用不到的补丁或者运行库可以不必安装）。  
  
4.常用软件的安装我这里列举一些常用的软件供大家选择。  
（1）Office  
（2）Cclean（清理垃圾软件）  
（3）激活工具  
（4）Winrar  
（5）输入法这些常用软件也是根据自己需要来安装，在这里只是推荐。
