简介

Stitch是一个跨平台的Python远程管理工具，也叫做AKA RAT

此框架允许您为Windows，Mac OSX和Linux自定义payload。


功能

通用功能

  • 自动检索文件

  • 过杀软检测

  • 可以关闭/打开显示屏

  • 隐藏/取消隐藏文件和目录

  • 查看/编辑主机文件

  • 查看所有系统环境变量

  • 键盘记录（可将日志存储到本地计算机）

  • 查看目标机器的位置和其他信息

  • 执行自定义的python脚本

  • 屏幕截图

  • 虚拟机检测

  • 从目标系统下载/上传文件

  • payload可以“伪装”成其他已知程序

Windows特定功能

  • 获取用户密码

  • 记录Chrome保存的密码

  • 清除系统安全和应用程序的日志

  • 启用/禁用RDP，UAC和Windows Defender等服务

  • 修改、创建文件

  • 自定义弹框

  • 查看连接的摄像头并拍摄快照

  • 查看过去连接的WiFi及密码

  • 查看所有驱动信息

  • 查看注册表值的摘要，如DEP

MacOSX特定功能

  • 获取用户密码

  • 在用户的登录屏幕显示自定义文本

  • 捕获摄像头快照

Mac OSX / Linux特定功能

  • SSH从目标机器进入另一台主机

  • 运行sudo命令

  • 强制修改用户密码，

  • 网络摄像头快照（在Linux上未测试）

 

用法

# for Windows

pip install -r win_requirements.txt 
 
# for Mac OSX

pip install -r osx_requirements.txt 
 
# for Linuxp

ip install -r lnx_requirements.txt
