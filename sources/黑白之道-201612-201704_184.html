简介

BurpSmartBuster是一款用于收集与发现文件目录和后缀的Burpsuite插件

特征

  • 根据Burp Suite收到的当前请求查找文件，目录和文件扩展名

  • 检查：

  1. 目录中的目录

  2. 当前URL目录中的文件

  3. 当前文件添加扩展名或替换

  4. 在当前文件中添加后缀和前缀

  • 易于记录代码

  • 详细和记录

    • 需求

    • Jython 2.7

    • bs4

    • tld

    • nltk

    • TextBlob

    安装

    1.安装Jython 2.7（jython_installer-2.7.0.jar）

    2.安装bs4和tld：

    • /path/to/jython/bin/pip install bs4 tld

    3.安装版本2.10的要求

    • 下载并安装：/path/to/jython/bin/jython setup.py install

    4.安装nltk：

    • git clone https://github.com/nltk/nltk.git

    • cd nltk

    • git checkout tags/3.1

    • /path/to/jython/bin/jython setup.py install

    5.安装TextBlob：

    • git clone https://github.com/sloria/TextBlob.git

    • cd TextBlob

    • git checkout tags/0.11.0

    • /path/to/jython/bin/jython setup.py install

    6.在Burp Suite Extender中激活插件

    • Tab Extender – > Tab Options – > Python环境：path/root/jython2.7.0/jython.jar
