## 项目主页

https://github.com/xdavidhu/mitmAP

## 简介

一个用来创建假AP和嗅探数据的python程序。

![](../Images/2e8d6f4402a046a525673940faaf02e8.png)

  

## 2.0版本新增功能

*   用于HSTS绕过的SSLstrip2
    
*   使用Driftnet捕获图像
    
*   用于命令行.pcap捕获的TShark
    

## 特征

*   SSLstrip2
    
*   Driftnet
    
*   Tshark
    
*   全功能接入点，具有可配置的速度限制
    
*   mitmproxy
    
*   Wireshark
    
*   DNS Spoofing
    
*   将结果保存到文件
    

## 要求

*   Kali Linux/Raspbian需具有root权限
    
*   无线网卡和以太网适配器，或者2个无线网卡
    
*   Python3（mit APP会安装依赖项）
    

## 下载

```
git clone https://github.com/xdavidhu/mitmAP
```

## 开始

*   Kali Linux
    

```
sudo python3 mitmAP.py
```

*   Raspberry PI
    

```
sudo python3 mitmAP\_rpi.py
```

注意：在第一次运行时，选择“y”安装依赖项和创建配置文件！
