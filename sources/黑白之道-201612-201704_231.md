## 简介

SQLite-lab是基于SQLite设计的SQL注入的测试代码，在SQLite数据库中SQL注入的Payloads是不同的，这在实践挑战中会非常有趣的。这个项目可以让你练习SQLite数据库的注入，提升自己的能力。

## 注入类型

*   Union based SQL Injection (numaric based)
    
*   Union based SQL Injection (String based)
    
*   Boolean based Blind SQL Injection
