# 照片处理软件 Prisma 一键照片变艺术品

Prisma，图片处理App。Prisma通过人工智能把你手机中那些普通的照片模仿出著名艺术家画作的风格。

  

![](../Images/dd96a563c8b5e1d0d782a01f48016935.png) 

  

Prisma综合了人工神经网络技术和人工智能技术，获取著名绘画大师和主要流派的艺术风格，然后对你的照片进行智能风格化。对照片进行超级炫酷上档次的艺术化处理，分分钟让你的照片变成名画！

  

![](../Images/09173c1bb8bd3ac4bff56f754d5848c2.png)

  

首先我随便照了一张照片。 

  

![](../Images/2499276a69ad0b0d814cf42e53bd02fd.png)

  

只需要打开APP点击中间的拍照按钮。 

  

![](../Images/e3a616017c8c1f186342329384a796db.png)

  

然后拍照之后就进入了照片选择风格的界面，有数十种风格供你选择，而且还在不断的更新。 

  

![](../Images/24c340d796549e3f9e4cee4f7e4d3c35.png)

  

还可以不直接拍照，选择自己原来的照片。添加之后可以选择角度和大小。 

  

![](../Images/e341a38087621502ace4355ef4b31bdc.png)

  

选择风格都是一键的，不过我这个版本是需要在wifi状态下才可以使用，但是我之前的版本在非网络下也可以进行处理。 

  

![](../Images/1bd0510c400b4402534da1dab628e209.png)

  

然后还可以修改照片的艺术化程度，只需要手指在照片上左右滑动就可以调整照片的处理程度。 

  

![](../Images/c35c180ad1d2b6ad60f4b33f0818186a.png)
