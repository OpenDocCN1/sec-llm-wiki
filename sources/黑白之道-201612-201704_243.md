## 工具简介

Tater是一个基于PowerShell实现的Hot Potato Windows提权利用工具

## 功能

### Invoke-Tater

*   主Tater函数
    

#### Parameters

*   IP — 指定特定的本地IP地址。 如果不使用此参数，将自动选择IP地址。
    
*   SpooferIP  — 指定NBNS欺骗的IP地址。 当使用两个主机绕过privesc目标使用的80端口时，需要这样做。
    
*   Command — 在localhost上作为SYSTEM执行的命令。 如有必要，请使用PowerShell字符转义。
    
*   NBNS — Default = Enabled:(Y/N) Enable/DisableNBNS暴力欺骗。
    
*   NBNSLimit — Default = Enabled: (Y/N) Enable/Disable NBNS暴力欺骗程序限制，以在主机名正确解析时停止NBNS欺骗。
    
*   ExhaustUDP — Default = Disabled: (Y/N) Enable/DisableUDP端口耗尽以强制所有DNS查找失败，以回退到NBNS解析。
    
*   HTTPPort — Default = 80: 为HTTP侦听器和重定向响应指定TCP端口。
    
*   Hostname — Default = WPAD: 主机名欺骗。 Windows Server 2008可能需要WPAD.DOMAIN.TLD。
    
*   WPADDirectHosts  — 逗号分隔在wpad.dat文件中列出为直接的主机列表。 注意localhost总是被列为direct。
    
*   WPADPort — Default = 80: 指定要包括在wpad.dat文件中的代理服务器端口。
    
*   Trigger — Default = 1: 要使用的触发器类型，以便触发HTTP到SMB中继。 0 =无，1 = Windows Defender签名更新，2 = Windows 10 Webclient /计划任务
    
*   TaskDelete — Default = Enabled: (Y/N) Enable/Disable如果启用，将向任务名称添加一个随机字符串，以避免在多次触发2运行后出现故障。
    
*   Taskname — Default = Tater:与触发器一起使用的计划任务名2.如果观察到Tater在多个触发器2运行后不工作，请尝试更改任务名。
    
*   RunTime — Default = Unlimited: （Integer）设置运行时间持续时间（以分钟为单位）。
    
*   ConsoleOutput — Default = Disabled: (Y/N) Enable/Disable实时控制台输出。 如果通过shell使用此选项，请进行测试以确保它不挂起shell。
    
*   StatusOutput — Default = Enabled: (Y/N) Enable/Disable启动消息。
    
*   ShowHelp — Default = Enabled: (Y/N) Enable/Disable 启动时的帮助消息。
    
*   Tool — Default = 0: (0,1,2) Enable/Disable通过Metasploit的交互式Powershell Sessions和Empire等外部工具实现更好的操作。 Empire. 0 = None, 1 = Metasploit, 2 = Empire。
    

### Stop-Tater

*   手动停止Invoke-Tater的功能。
    

## 用法

*   使用Import-Module导入：Import-Module ./Tater.ps1
    

*   使用点源方法导入：. ./Tater.ps1
    

### Examples

*   基本触发示例1
    

Invoke-Tater -Trigger 1 – 命令：

```
 net user tater Winter2016 /add && net localgroup administrators tater /add
```

*   基本触发示例2
    

Invoke-Tater -Trigger 2  – 命令：

```
net user tater Winter2016 /add && net localgroup administrators tater /add
```

*   两个系统设置绕过在privesc目标上正在使用的80端口
    

WPAD System — 192.168.10.100 这个系统将只提供一个wpad.dat文件，该文件将把prifsc目标上的HTTP流量定向到非80 HTTP端口

Invoke-Tater -Trigger 0 -NBNS N -WPADPort 8080A — 命令：null

Privesc Target – 192.168.10.101

Invoke-Tater -命令：

```
net user Tater Winter2016 / add && net localgroup administrators Tater / add
```

HTTPPort 8080 -SpooferIP 192.168.10.100
