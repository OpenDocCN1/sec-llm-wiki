Hello，大家是否还在放假期间呢，小Lionel已经开始新一年的工作了，今天为大家继续更新教程。

  

在本节教程中，我们将涵盖一些新的东西。首先我们将介绍两个新的 Measure 类型和两个新的 Meter 类型，以及各自的选项。 然后我们将接触 Measure 中 UpdateDivider的用法，并将使用变量来设置、使用和改变被 Measure 和 Meter 使用的选项值。

  

在这个皮肤要用到很多东西，所以我们在下面简单介绍一下最终效果，方便你在制作皮肤过程中知道自己进行到了哪一步。首先，让我们看一下最后皮肤的样子。

  

![](../Images/93f7c17b7058eea00d6109b115e78f17.png)

  

在本节教程中，我们要做的是测量 CPU 的使用率和硬盘的空间。我们会用 Roundline类的 Meter 来显示使用率， 用 Line 类 Meter 来持续监视 CPU 使用率， 以及显示硬盘空间的信息。

  

构建System皮肤

  

首先就像我们之前教程做的那样，添加\[Rainmeter\]节点来控制皮肤的更新率。

  

\[Rainmeter\]  
Update\=1000

  

下面我们要做的是为皮肤定义一些变量。变量用于构建一个值，使这个值可以通过用#号包围的变量名（如#变量名#，中英皆可）来在皮肤中不断被使用。

  

\[Variables\]  
DarkBlue\=27,63,107,255  
MediumBlue\=92,135,209,255  
LightBlue\=207,224,255,255  
LightRed\=250,148,135,255  
AlmostBlack\=40,40,40,255  
CurrentDrive\=C:  
Drive1\=C:

Drive2\=D:

  

现在在这里我们犯规一下。在之前的教程，我们都是在教程的最后才用图片 Meter为皮肤设置来了填充背景。这次让我们直接来设置背景，这样我们就能在这里首次用到上面设定的变量。

  

\[MeterBackground\]  
Meter\=Image  
X\=0  
Y\=0  
W\=185  
H\=110  
SolidColor\=#AlmostBlack#

  

注意我们这里在 Meter 的 SolidColor 选项用到了变量#AlmostBlack#。因此这个Meter 就会使用我们之前在\[Variables\]节点下定义值 AlmostBlack=40,40,40,255。记住如果你在 Image 类 Meter 中定义 SolidColor 但不定义 ImageName或MeasureName 选项，那么这个Meter 将根据 W 和 H（宽和高）选项来简单的画一个矩形。让我们加载一下我们的皮肤看看效果。在管理窗口的列表中找到System.ini， 单击右上方的加载按钮。

  

![](../Images/f37ddac1fa4aeeace41cadd7ac30d0f4.png)

  

现在还没什么能看到的。

  
下面让我们创建一个 Measure 来在每次更新时以百分比获取CPU 使用量。

  

\[MeasureCPU\]  
Measure\=CPU

  

是时候介绍新的 Meter 类型了。我们要使用Roundline 类 Meter 以填充圆环的方式  
在屏幕上显示\[MeasureCPU\]的返回值。 用下面的代码创建一个新节点。

  

\[MeterCPUCircle\]  
Meter\=Roundline

MeasureName\=MeasureCPU  
X\=5  
Y\=8  
W\=40  
H\=40  
StartAngle\=(Rad(270))  
RotationAngle\=(Rad(360))  
LineStart\=15  
LineLength\=20  
Solid\=1  
LineColor\=#LightBlue#  
AntiAlias\=1

  

刷新皮肤，这样我们就能看到这些选项的效果。

  

![](../Images/2dc6c81050ef282e3ca26e4c12b075a3.png)

  

旋转线Meter 在这里绘制了以 Meter 的 W 和 H 选项为旋转中心的一条线段的旋转路径。我们定义了 Meter（也就是圆）的大小为 40x40 像素。记住这里定义的是外直径长度 40 像素，也就是从圆心到圆外侧边缘为20 像素。
