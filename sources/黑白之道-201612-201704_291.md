# you-get？ 你一定要get。

之前发了浏览器看视频的插件，但是有些小朋友和我说，想下载视频看，路途中不然会寂寞狠多，毕竟我们和土豪不太一样，可以不用考虑流量的问题

  

  我们介绍的这款工具呢是you-get，其实看题目懂得人已经知道我要说的是什么了。如果你懂，哈哈，你走，快走。

  

  You-get是一个微小的命令行下的程序，就是说它运行在cmd下，当然linux也可以使用它，因为它基于python。你可以使用you-get下载媒体内容（反正我用它主要是下载视频的，油管的视频居多，你要问我油管是什么，就是那个超级马里奥经常去的那个地方。）

  

目前you-get支持71个视频站点（全球），国内的支持爱奇艺、优酷、乐视、哔哩哔哩等，其实自行测试。

  

1.首先我们安装

  

python3（https://www.python.org/downloads/release/python-360/）根据自己的系统要求x86/x64下载对应的，然后安装，一定勾选 ADD python 3.6 to PATH

  

![](../Images/af03d52e5cb2677a2f4cfd839dfaf547.png)

  

2.安装完以后，在cmd输入python，出现如下证明python安装成功，关闭窗口 

  

![](../Images/7951294bbcaf1114ea6c43cfb3a14188.png)

  

3.然后我们解压you-get-0.4.626压缩文件包。在屏幕空白处，安装shift 鼠标右键 ，点击在此处打开命令窗口。这样会自动切换到我们的you-get文件目录，输入python setup.py install --user

  

![](../Images/250180838b9bcf2a89dabc793e2d5b34.png)

 ![](../Images/441fc1ecebb7b4e2bbc4762f780d216f.png)

  

 4.然后我们输入you-get出现以下内容，证明you-get安装成功

  

![](../Images/8c623abbfc5d24f2e1255aa485a155cf.png)   

然后我们找一个优酷的视频，复制浏览器的地址。打开cmd输入you-get -o E:/video 视屏地址（命令的意思是将视频文件下载到e:/video 文件夹里。）

  
![](../Images/b2f7efcafbc9248ec64449836b382d5f.png)  
  
![](../Images/af33d1fc73b944157c128553d39e739a.png)  

  

8.你会看到视频正在下载中。

  
![](../Images/3a75c1040347d20a8018ddcaaa9d8c11.png)   

9.打开文件查看文件，并播放没有问题。

  
![](../Images/768a68f479e004a460581c2e2b438860.png)  
  

到这里就完了，你是不是想问能不能直接下载会员电影呀。是不是想问，是不是想问。
