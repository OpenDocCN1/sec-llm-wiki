Charles一个网络抓包工具，可以清晰看到网络请求参数值以及返回的response结果。对于日常开发还是非常有帮助的。

显示视图

Charles提供了两种显示视图的方式，分别为 Structure 和 Sequence 。

区别如下：

Structure 视图将网络请求按访问的域名分类。 Sequence 视图将网络请求按访问的时间排序。

前面的图为 Structure

下面的图为 Sequence   
![](../Images/2c8daf39d05bfe7bc11b1eb49fbd9cea.png)  

单击其中一个网络请求，根据面板上的tag即可在下面空白看到相应的 request 请求参数和 response 返回结果了

过滤网络请求 在 Sequence 视图模式有一个 Filter 的输入框   
![](../Images/7f74d358db29869155c9d2c09c9b442a.png)  
另一种方式，选中一个在右键出的下拉菜单中点击 Focus ，然后 Filter 的输入框后面勾选 Focused   
![](../Images/81c61e998b6b0c508eef5985b26e4340.png)  
在 Structure 视图模式 在菜单栏选择 Proxy->Recording Settings ，然后选择 Include 栏，选择添加一个项目，然后填入需要监控的协议，主机地址，端口号。   
![](../Images/9a411c6d492f7a194aecda6841c5e40b.png)

手机上的设置

PC和手机最好用同一个网关要方便点，毕竟都是在办公室工作嘛。

获取到电脑的ip地址   
![](../Images/035300a08c1c0a424a881042eedeb596.png)  
设置手机的HTTP代理

进入到 “设置” - “无线局域网” - “【你的WiFi名字】旁边的详情” 向下拉到最底，填入你PC的ip和Charles的代理端口号

  
![](../Images/a45c9876b3c2f7e39b963c7eedfbfc53.png)  
选择 Allow   
![](../Images/ad69145bffc3c994ada73221492f987f.png)  

在面版将会看到手机发出接受的网络请求了。
