# DVWA是一个学习Web漏洞的很好的工具

　DVWA是一个学习Web漏洞的很好的工具，一个基于PHP/MYSQL环境写的一个web应用。如果你想学习web渗透测试测试遇见DVWA是你的幸运。这次分享使用DVWA实例，理解php中的文件包含漏洞的原理及其利用方法。

　　一、原理知识

  
　　PHP文件包含漏洞的产生原因是在通过PHP的函数引入文件时，由于传入的文件名没有经过合理的校验，从而操作了预想之外的文件，就可能导致意外的文件泄露甚至恶意的代码注入。

  
　　PHP文件包含漏洞分为本地文件包含漏洞(LFI)和远程文件包含漏洞(RFI)，能够打开并包含本地文件的漏洞，被称为本地文件包含漏洞。利用本地文件包含漏洞，可以查看系统任意文件内容，如果具备一些条件，也可以执行命令。

  
　　二、低安全等级php文件包含

  
　　使用浏览器打开安装好的DVWA程序192.168.1.3:8080/dvwa/login.php。账户密码登陆。

  
![](../Images/2a4332035566bcc3496192971aac11a1.png) 

  
　　调整好安全级别之后，选择File Inclusion。

  
![](../Images/4afcef5e625ae0bcafcd34881f136c5d.png)   
　　参数page的值是include.php可以尝试修改page的值。在dvwa的文件目录下存在一个phpinfo.php的文件，可以尝试打开。URL的值是:http://192.168.1.3:8080/dvwa/vulnerabilities/fi/?page-../../phpinfo.php页面成功打开。

  
![](../Images/f84133723043be036ba8e3c67cc81e91.png)   
　　上面所展示的是本地文件包含，远程文件包含需要在php.ini中修改配置。

  
　　; Whether to allow the treatment of URLs (like http刀or ftp://)as files.  
　　allow url\_fopen = On  
　　allow url include=On  
　　;Magic quotes for incoming GET/POST/Cookie data.  
　　magic\_quotes\_gpc二off  
  
　　查看源代码，结台DVWA\\vulnerabilities\\fi\\index.php文件。

  
![](../Images/bd0cdcd6b0314ed3fb161cae50b02309.png) 

  
　　在低级别的时候没有对参数$file的值做任何处理。include($file)直接执行了$file传过来的值。从而导致可以任意文件包含。

　　三、中级安全等级php文件包含

  
　　首先调整DVWA的安全级别为中，再次查看源代码。

  
![](../Images/587f8b2c0f63de809008d3fb0526d602.png) 

  
在中等级别的时候，对输入的$file参数利用str\_replaceo函数进行了处理。将http和https进行了替换，从而无法执行远程文件。但是这种简单的方式是不全面的，存在一定的绕过方法。由于php远程文件包含漏洞仅存在PHP4版本中。在PHP5版本仅存在本地文件包含。

  
替代模式错误利用：

**可以使用类似:http://192.168.1.3:8080/dvwa/vulnerabilities/fi/?page=httphttp://localhostlphpcrosv9/phpinfo.php**

**  
从代码中可以看出对http进行了替换，但是不会将替换后的字符在进行替换，所以可以继续使用http://和https://。**
