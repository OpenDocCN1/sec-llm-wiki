# Rainmeter教程（四）Launcher（Image类）

接着上一节我们继续讲，上节我们学习了Meter类型，轻松的在桌面实现了文字链接程序的操作，方便的打开想要的程序。简单，便捷。现在我们换个方向，介绍一种       新的 Meter 类型。我们的下一个 Meter 将用来显示图片。单击后将启动一个程序。  

  

　　\[MeterLaunch3Image\]  
　　Meter=Image  
　　ImageName=C:\\Users\\Administrator.PC-201612060936\\Documents\\Rainmeter\\Skins\\illustro\\@Resources\\1.jpg  
　　W=32  
　　H=32  
　　X=0r  
　　Y=2R  
　　LeftMouseUpAction=\["Calc.exe"\]

  
　　我们新建一个节点，并设置 Meter 选项为 Meter=Image 。我们要在皮肤中包含图片文件，所以我们要先做下面的事情：

  
　　o 首先，我们需要创建一个文件夹来存放所有教程皮肤的图片。这个文件夹不仅用于现在的 Launcher 皮肤，更要在后面用到。

  
　　o 在 Windows 资源管理器中，在 Skins\\Tutorials\\路径下新建文件夹@Resources。@Resources 文件夹是一个位于皮肤或套装皮肤根配置文件夹下的特殊文件夹，存放图像、音频、字体、 inc 文件和其他在皮肤间共享的资源。

  
　　o 在 Skins\\Tutorials\\@Resources 文件夹中新建文件夹 Images，将下面的图片保存到 Skins\\Tutorials\\@Resources\\Images 中。  
  
　　现在我们解释一下陌生的代码。

  
　　Meter=Image //定义一个Meter类型的Image类。  
　　ImageName=路径 //图片的路径  
  
　　OK，现在我们加载设置好的.ini文件，保存修改并刷新皮肤，单击图标启动Windows计算器。  

  

![](../Images/e7afdb25b91019bf50706a2c3acab335.png)

  

      这样还不够，我们要给这张图片配上些文字，让用户更加了解图片的用处，就像以前讲的，加一个文字链接。

  
　　\[MeterLaunch3Text\]  
　　Meter=String  
　　X=0R  
　　Y=6r  
　　FontFace=Trebuchet MS  
　　FontSize=14  
　　FontColor=146,197,94,255  
　　StringStyle=Bold  
　　SolidColor=0,0,0,1  
　　AntiAlias=1  
　　Text=Calculator  
　　LeftMouseUpAction=\["Calc.exe"\]

  
注意我们用了 X 和 Y 选项来对 Meter 进行定位，使其与上一个 Meter (图片 Meter)右边缘对齐，并且低于它的上边缘 6 像素。这样我们就差不多把 Meter 对齐在图片中         部。我们添加了与之前图片 Meter 一样的 LeftMouseUpAction，这样无论我们单击图片还是文字，程序都会起动。娱乐一下，我们也修改了文字的 FontColor。  
  
保存修改，刷新皮肤，让我们来看看效果。  

  

![](../Images/614fb34f014046a73977fd9b736e02f4.png)

  

　   Rainmeter 一个非常重要的概念是“层覆盖”的概念。哪一个 Meter 显示在屏幕上

  
　　面，哪一个 Meter 显示在屏幕下面，这取决于 Meter 的代码在皮肤 ini 文件的书写位置。

  
　　既然我们要把背景 Meter 放在所有 Meter 后面，我们就需要把背景 Meter 的代码放在

  
　　其它 Meter 代码的上面。

  
　　所以，让我们回到皮肤顶部，就在\[Rainmeter\]节点后面，在第一个文本 Meter

  
　　\[MeterLaunch1\]的前面，插入新的背景图片 Meter。

  
　　\[Rainmeter\]  
　　Update=1000  
　　\[MeterBackground\]  
　　Meter=Image  
　　W=145  
　　H=95  
　　SolidColor=60,60,60,255  
　　\[MeterLaunch1\]  
　　Meter=String  
　　X=5  
　　Y=5  
　　FontFace=Trebuchet MS  
　　FontSize=14  
　　FontColor=255,255,255,255  
　　StringStyle=Bold  
　　SolidColor=0,0,0,1  
　　AntiAlias=1  
　　Text=Notepad  
　　LeftMouseUpAction=\["C:\\Windows\\System32\\Notepad.exe"\]

  
　　我们设置了特别的 W 和 H(宽和高)让 Meter 足够大能够覆盖所有其它 Meter 的范围。没有设置 X 和 Y 选项，这样 Meter 将从整个皮肤的最左上角开始。然后我们设置了       SolidColor=60,60,60,255 。这样的代码在没有 ImageName 的 Image 类 Meter 中将以W 和 H 选项作为大小绘制一个填充矩形。(对于有图片的 Image 类 Meter 将填充 图片的透明部分。)  
  
　　保存修改，刷新皮肤。
