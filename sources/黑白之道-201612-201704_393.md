接着第一节开始，今天我们学习雨滴桌面的基本语句命令，在本节的学习中，你可以掌握最基本的命令，从而进阶。使桌面参数变得更简洁，流畅。

  

首先提出几个常用的参数（以后会频繁使用）：

  

Meter

  

皮肤显示控件。用于构建能够被看到被点击的物体。

  

Measure

  

皮肤的信息控件。用于从电脑或互联网上收集信息。

  

Bang

  

皮肤的交互元素。用于向Rainmeter或其他程序发送指令。

  

Update

  

皮肤的频率时钟。用于控制皮肤计时与皮肤事件的同步。

  

Variable

  

皮肤的数据元素。用于处理储存了各种信息的独立字符串。

  

     “Hello world！” 皮肤

  

      首先你要给你的皮肤添加的是\[Rainmeter\]节点。这里是一个皮肤的“头”属性，就 像 HTML 中的<head>标签一样。下面给\[Rainmeter\]节点添加一个设置：

  

   \[Rainmeter\]

    Update=1000

  

  update选项设置了皮肤更新周期的时长，单位是 1 毫秒，即千分之一秒。所以

   Update=1000 表示皮肤每一秒更新一次。所谓更新是指皮肤对数据信息的相应变化，注意不要与刷新混淆。以后的内容将更详细的介绍更新。

  

现在你已经给了你的皮肤“头”，下面你该给他“身体”了。 你要创建一个 String类的Meter，它是最常见的 Meter 之一，用来显示一段文本。

  

   \[Rainmeter\] 

　　Update=1000

   \[MyMeter\]

  

   Meter\=String

  

   Text\=Hello, world!

  

  Meter 选项是用来告诉 Rainmeter 这个节点是一个 Meter。所有 Meter 都具有这一选项，这一选项决定了Meter 的类型。

  

  Text 选项则不同，它是专属于 String 类型的 Meter的选项。

  

  不论你信不信，你现在已经做了一个完整的可用的Rainmeter 皮肤。让我们加载一下看看它是什么样子的。使用任意之前讲过的方法来加载，你可以：

  

  o 单击系统通知区Rainmeter 图标打开管理窗口，在皮肤列表中找到 "自己的皮肤名字"， 单击右上方的加载按钮。

  

  o 右键系统通知区Rainmeter 图标弹出右键菜单，然 后选 择 Skins → 自己文件夹的名称 →皮肤的名称.ini。

  

（当你熟悉Rainmeter 的用户界面后，你会自己决定更喜欢使用右键菜单或更喜欢使用管理窗口。）

  

  现在，仔细查看你桌面的左上角，这就是你的皮肤！

  

      ![](../Images/5a31960549ca371e8fd843ab65c76cd9.png)

  

  说实话，他并不是很好看。通常没有很多选项的Meter 都很简单并且不显眼。

  让我们为文字添加更多格式。

  

   \[MyMeter\]

   Meter\=String

   Text\=Hello, world!

   AntiAlias\=1

   FontColor\=255,255,255

   FontFace\=Segoe UI

   FontSize\=20

  

  下面是我添加了的东西：

   o AntiAlias

  

  抗锯齿。它是一个通用 Meter 选项，用于平滑 Meter 边缘。它常被用于改善 String类 Meter 的外观。

  

   o FontColor

  字体颜色。它是一个颜色选项，用来改变文字颜色。

  

   o FontFace

  字体。它用来改变当前Meter 字体的设置。 Rainmeter 可以使用任何你安装在系统中的文字，或者是在皮肤Resources 文件夹中的字体（这个以后再介绍）。 

   o FontSize

  字体大小。

  

![](../Images/69e1051bc0c2b590c5607848f9c9c0c2.png)

  

  现在，让我们保存文件并刷新皮肤。你既可以在管理窗口按下刷新按钮，也可以在上下文菜单中 皮肤的名字 → 刷新皮肤。
