简介

  

Damn Small Vulnerable Web (DSVW) 是一个100行代码的Web漏洞演示程序， 它支持大多数（最受欢迎的）Web应用程序漏洞以及适当的攻击。

  

![](../Images/f3d56e10c8f0939ca3cfa711e28b398c.png)

  

快速启动

  

运行下面命令：

  

$ python dsvw.py Damn Small Vulnerable Web (DSVW) < 100 LoC (Lines of Code) #v0.1k by: Miroslav Stampar (@stamparm)\[i running HTTP server at '127.0.0.1:65412'..

  

![](../Images/6c62a4923d20eb2f450e245eec5dd67a.png)

  

然后打开 http://127.0.0.1:65412/

  

![](../Images/e4a58edcc26ebd8579718d318c02ce28.png)  

安装依赖

运行此程序需安装Python（2.6.x或2.7.x）。XML External Entity (local)、 XML External Entity (remote) 、Blind XPath Injection (boolean) 等项目需要安装python-lxml（例如apt-get install python-lxml）。 否则，这些将不能进行演示。
