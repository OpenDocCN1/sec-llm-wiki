1\. 设置Go环境变量  
  
打开终端，输入命令：  
  
export GOROOT=$HOME/go  
export PATH=$GOROOT/bin![](../Images/7fed71a4a38b82cf9847856c8b5c1ea2.png)PATH  
当然，你需要设置项目的目录  
export GOPATH=$HOME/Applications/Go  
  
2\. 安装C工具  
  
由于Go的工具链是用C语言编写的， 因此在安装Go之前序言安装相关的C工具。执行一下命令：  
  
sudo apt-get install bison ed gawk gcc libc6-dev make  
  
3\. 安装Mercurial  
  
由于Go的源码是通过Mercurial进行管理的， 所以需要先安装Mercurial来实现Go源码的获取，一次执行一下命令：  
  
sudo apt-get install python-setuptools  
sudo apt-get install pythone-dev  
sudo apt-get install build-essential  
sudo apt-get install mercurial  
  
4\. 获取Go源代码  
  
hg clone -r release https://go.googlecode.com/hg/ $GOROOT  
  
5\. 构建Go  
  
在终端中执行一下命令来构建Go  
  
cd $GOROOT/src  
  
./all.bash  
  
编译完成后会自动测试，但是在测试net/http时会链接google.com, 在国内环境稍微有一点不稳定（第一次编译成功挂掉了...)，所以建议是增加一条环境变量  
  
export DISABLE\_NET\_TESTS=1   
  
来跳过net的测试.  
  
6\. 测试安装  
  
完成安装后，新建一个文档来测试环境是否搭建成功:  
  
Example helloWorld.go  
  
复制代码  
1 package main  
2   
3 import (  
4     &quot;fmt&quot;  
5     &quot;runtime&quot;  
6 )  
7   
8 func main() {  
9     fmt.Println(&quot;Hellow World!&quot;, runtime.Version())  
10 }  
复制代码  
执行go run helloWorld.go, 应该会打印出：  
  
Hellow World! go1.2  
\~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  
安装完go环境，接着安装zgrab  
  
终端命令，  
  
$ go get github.com/zmap/zgrab  
  
如果不成功，说明go环境有问题，  
$ cd $GOPATH/src/github.com/zmap/zgrab  
$ go build

vi /etc/profile  
加入

export GOARCH=386  
export GOOS=linux  
export GOPATH=/home/administrator/workspace/go  
export GOBIN=$GOPATH/bin  
export PATH=$GOPATH/bin![](../Images/7fed71a4a38b82cf9847856c8b5c1ea2.png)PATH  
export GOROOT=$HOME/go  
export PATH=$GOROOT/bin![](../Images/7fed71a4a38b82cf9847856c8b5c1ea2.png)PATH
