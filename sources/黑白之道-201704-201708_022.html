大家好，我是你们的老朋友Alex。今天教大家在手机安装kali的工具集，无需ROOT哦~~


https://github.com/LionSec/katoolin这个链接就是我们要安装的工具了


首先在手机上面安装GNURoot Debian，


https://play.google.com/store/apps/details?id=com.gnuroot.debian&hl=en



打开软件等待它首次加载完成，建议大家再安装一个Hacker's Keyboard，因为有一些电脑的功能按键，手机的普通输入法无法实现。


https://play.google.com/store/apps/detailsid=org.pocketworkstation.pckeyboard&hl=en



现在需要更新我们的软件和安装SSH服务来实现远程管理，因为手机敲命令是真的累QAQ


apt update


apt install -y nano安装一下nano编辑器，因为默认是没有文本编辑器的。我这里已经安装过了





之后安装openssh-server    apt install -y openssh-server


安装完成后，编辑sshd_config配置文件，修改端口和启动root登录


UsePrivilegeSeparation no


PermitRootLogin yes




完成后ctrl X退出并保存就可以了！注意目前的root是没有密码的，需要设置密码！


直接执行passwd修改密码即可！之后重启ssh服务，就可以在电脑上使用putty连接我们的手机终端了


因为工具集的源码托管在GITHUB中，所以需要我们在手机中安装一些必须的依赖组件才能成功从GITHUB库中克隆到本地使用！


apt-get install git-core


apt-get install python-dev python-pip libncurses5-dev git


我这里已经安装过了，大家执行命令后静静的等待安装完成就可以了！




然后执行执行git clone https://github.com/LionSec/katoolin.git克隆工具到本地


然后进去文件夹，执行katoolin.py




接下来的操作我就不做叙述了，软件的功能和使用在GITHUB简介中都有写明而且安装kali套件也不易报错。
