# 没人碰，摄像头突然动了 太可怕，竟是被黑客入侵

近日，家住九龙坡的黄女士无意中发现家里的摄像头被别人操控！经警方调查，原来其连接摄像头的台式电脑被人恶意植入病毒，不仅窃取个人资料，还对其进行了远程监控。目前，此案还在进一步调查中。

  

**奇怪**

  

**无人操作摄像头自己动了**

  

黄女士8月初养了一只苏格兰牧羊犬，为方便观察狗狗的进食状况，黄女士在客厅的天花板加装了一个悬顶监控探头，服务器设置在家中的台式电脑上，并通过密码账号与自己的手机相连：打开手机，就能看到客厅地板的画面。

  

8月5日早上，黄女士在给狗狗喂食的时候，突然发现头顶斜对面的摄像头在动。吓了一跳的黄女士立即打开电脑后台查看，发现除了自己的账号，还有一个陌生用户在监看这个摄像头的信息。

  

意识到自己遭遇偷窥，黄女士立即拔掉了监控摄像头上的网线，并向公安机关报案求助。

  

**吓人**

**电脑遭黑客入侵资料可被随意窃取**

  

九龙坡区公安分局陶家派出所民警对黄女士家中的视频监控系统检查发现，其安装服务器的台式机电脑系统，被人恶意植入病毒。

  

据警方调查，该病毒伪装成电子相册，通过电脑邮件进行传播。经电脑操作者不慎下载点击激活后，即侵入计算机服务器，并对计算机内各软件进行数据篡改，同时攫取管理权限。黄女士的监控探头被控制，应该只是“入侵者”进行信息窃取的“副产品”。

  

民警通过侦查发现，入侵的“黑客”对黄女士的计算机已经达到了完全操纵的程度，只要愿意，对方实际上可以做任何事情。所幸黄女士电脑中没有什么重要的个人信息。

  

目前，民警已经针对此案展开侦查。

  

**警方提醒**

  

**四招防范此类病毒入侵**

  

重庆市公安局九龙坡区分局网安支队民警周警官表示，近年来，计算机远程攻击的案例频频发生，特别是今年肆虐全球的WannaCry比特币勒索病毒，更是为计算机安全敲响了警钟。

  

市民应提高警惕，提升计算机以及网络安全防护的知识水平，扎紧篱笆，看好门户，则是预防计算机信息泄露和侵入的治本之策。以下是几种常见的计算机安全防护措施：

  

1.关闭“文件和打印共享”。文件和打印共享应该是一个非常有用的功能，也是黑客入侵的安全漏洞。所以在没有必要“文件和打印共享”的情况下，我们可以将它关闭。

  

2.禁用电脑Guest账号。黑客攻击很多都是通过Guest账号获得管理员密码或者权限的。因此，在不用时关闭该账号是非常必要的。另外，将Administrator账号改名可以防止黑客知道自己的管理员账号，这会在很大程度上保证计算机安全。

  

3.安装必要的安全软件和防火墙，这样即便有“黑客”通过常规病毒渗透我们的电脑，电脑的安全还是有保障的。

  

4.对陌生邮件保持警惕。面对随机收到的陌生邮件，不管其名目如何有诱惑力，请保持警惕。
