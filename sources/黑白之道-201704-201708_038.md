# QQ刷屏脚本

写的一个QQ的刷屏脚本，安全无毒~纯天然~  
  
![](../Images/77dd5e433ffa2ad5f61e402b089eb05e.png) 首先，新建一个txt文档，  
  
![](../Images/d131adf37b73d966dfd1367a4ed70af5.png)   
写入脚本语言：  
Set WshShell= WScript.Createobject("WScript.Shell")  
for i=1 to 200         刷屏的数量  
WScript.Sleep 30     刷屏的时间/S  
  
WshShell.SendKeys"^v"  复制自身  
  
WshShell.SendKeys "%s"   模拟用户敲击键盘  
wshShell.SendKeys "{ENTER}"  模拟键盘操作回车  
next  
  
(注：使用前删除我在后面解释用到的汉字)  
  
![](../Images/6d26019bb70cd68b7ba8768b8064ce1e.png)   
  
保存，更改后缀，将.txt改成.vbs  
  
![](../Images/8486acaffd7242da4baa985faded7f52.png)   
随便打开一个QQ聊天窗口，测试一下，  
  
![](../Images/61e10edb4126903859eed2eb8f7dcbca.png)   
输入你想刷屏的话，复制一下，然后运行qq.vbs，然后立马点击聊天窗口的输入框，然后就达到了一个高速刷屏的效果~  
（注：一般一秒两句不会卡死，像我刚刚设置的30秒，200句，刷屏的前部分QQ提示输入框不能为空，不过过一会就好了）  
  
![](../Images/77d09fe216877b7fa8149145785251db.png)   
然后受害者QQ看到的就是这样一个结果，1秒那么多句... ... 抓紧删好友  
  
友情提示：  
此刷屏脚本可能会在你电脑有其他窗口弹出的时候把其他窗口的刷屏了，所以在使用前一定要确定电脑是否会有其他弹窗的出现，避免误会的发生。
