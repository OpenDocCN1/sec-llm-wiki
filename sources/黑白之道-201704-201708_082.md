# MariaDB数据库主从复制

大家好，我是Adam，前面两周讲了MariaDB的安装以及简单的安全配置，这周就深入一些，讲一点相对来说复杂的东西，两个数据库之间的主从复制，没有看前面教程的朋友可以点击下面的链接去看一下

  

好了，走起走起

  

1、需要两个数据库服务端，数据库版本一致，并且互通

  

![](../Images/395551da1ba91cc24699e62a2942c5b7.png)

  

2、先来配置主数据库

  

vi /etc/my.cnf

  

然后按i编辑，输入下图红框中两行数据

  

![](../Images/8700e4d1168a6e763eeb79f03b18cee0.png)

  

3、退出之后重启数据库

  

systemctl restart mariadb

  

![](../Images/a4555814e7d4d19dfc90ed84737f09ad.png)

4、进入数据库

  

mysql -u root -p

  

查看主数据库状态

  

show master status\\G;

  

根据返回的信息可以得出结论，配置的主数据库文件没有问题

  

![](../Images/c7892099efc6da25ecae82dc6cff623c.png)

  

5、1、锁定所有的表，使其他人不能对表做出修改的操作

  

flush tables with read lock;

  

![](../Images/c7fd8856e9a4d2dcfe0eabc395f69f26.png)

  

6、退出数据库，接下来对数据库做一个导出

  

mysqldump -hlocalhost -uroot -p3306 -p test > /home/test.sql

  

然后输入数据库密码即可

  

![](../Images/94c5af651c0bcea5ae83074f90e92531.png)

  

7、进入home目录，看test.sql是否已创建

  

![](../Images/82119a90a862a04578d8c2e23ce94b2c.png)

  

8、利用scp命令把test.sql文件传到从数据库服务器上

  

scp test.sql root@192.168.2.197:/home/

  

输入从服务器密码

  

![](../Images/fcc71556b771bb51a7a0728d801a9983.png)

  

9、在从数据库服务器上查看文件是否上传成功

  

![](../Images/56ca7530a2f2fca227dd8f717e46fc31.png)

  

10、回到主数据库服务器，解除表的锁定

  

unlock tables;

  

![](../Images/faea3baccd533863ef8aa3de1f4e3926.png)

11、在主数据库中把从数据库需要用的用户创建出来

  

grant replication slave on \*.\* to 'slave'@'192.168.2.197' identified by '123456';

  

‘slave’为用户名  ’192.168.2.197’为从数据库IP地址  ’123456’为密码

  

![](../Images/f099ad2d40e859d86826105a8af5f47f.png)

  

12、主数据库服务器配置完成，接下来配置从数据库服务器，在主数据库服务器中进入数据库界面，执行第4步操作，把界面放到旁边，待会用得到

  

![](../Images/f174bdf2eef77536a6e2c00877172ef1.png)

  

13、操作从数据库服务器，一样的，也需要修改数据库配置文件参数

  

vi /etc/my.cnf

  

14、同样的，配置完成后重启数据库

  

15、进入数据库，设置主从复制

  

CHANGE MASTER TO           MASTER\_HOST='192.168.2.196',MASTER\_USER='slave', MASTER\_PASSWORD='123456', MASTER\_LOG\_FILE='mariadb-bin.000001', MASTER\_LOG\_POS= 555;

  

后面两项要填写的参数为第12步中显示的参数

  

![](../Images/2677ff3cbd099b31c8b04b38c7cf2999.png)

  

16、开启主从复制

  

START SLAVE;

  

![](../Images/6ed870266d2955c124b795058062b037.png) 

  

17、查看从数据库状态

  

show slave status\\G;

  

![](../Images/d92fb409510dd32bbefb874bd3d08d90.png)

  

可以看到，已经连接成功，配置完成！
