## 什么是Libenom？

  

一款快速创建MSFvenom payload的工具

  

![](../Images/03091eccbdfe61a03879f3cdfac4fb69.png)

  

## 环境要求

Linux环境下（ Ubuntu, Debian, Mint）

推荐:Kali Linux 2.0 sana，rolling, Parrot OS, Blackarch, Dracos ,Lionsec

## 安装

```
git clone https://github.com/bounteous/libenom.git 
cd libenom
chmod +x libenom.py
```

## 使用

执行 ./libenom.py 来显示所有的选项。例如：你可以先创建一个配置文件命名为”Profile1″用 -C 选项将它分配给msfvenom参数

  

![](../Images/7d2d6b5943327312cf35a7bccbaf4f7d.png)

  

然后你可以用 ./libenom.py -x profile1 命令来执行它，或者用 -d 或者 -r 选项来删除它
