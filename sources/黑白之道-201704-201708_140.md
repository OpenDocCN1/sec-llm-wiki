首先，来简单说一下mysql数据库的优点，mysql数据库有很多优点：安装简单、运行速度快、安全稳定，适应性也很强，非常适合中小型企业的需求，无论是网站还是软件系统的开发，mysql数据库都能完全满足功能上的要求，这也是为什么mysql应用广泛的原因。

  

下面我们就开始在centos7下安装mysql，目前在centos7中，MariaDB已经代替了mysql数据库，MariaDB跟MySQL在绝大多数方面是兼容的，对于开发者来说，几乎感觉不到任何不同。所以我们来安装MariaDB数据库

  

**一、先在yum里查找是否有MariaDB**

  

yum search mariadb

  

可以找到mariadb的server项，说明可以直接用yum进行安装

  

![](../Images/655a27a8e3c66633cac98c987e2fc4d5.png)

  

**二、使用yum安装mariadb**

yum install mariadb-server.x86\_64

  

![](../Images/3bd9bff86c54c9f86264bb447d5e6b67.png)

  

安装完成

  

![](../Images/20784c1820ec2fffe6f7716be10f34ca.png)

  

**三、开启mariadb服务**

  

systemctl start mariadb

  

![](../Images/a1700293de5a23f638404af089a1a69f.png)

  

**四、登录mariadb**

  

mysql -u root -p会提示输入密码，初始密码为空

  

![](../Images/b1fe49dba0a76b6fb798b89d379442da.png)

  

**五、退出数据库之后，设置mariadb密码**

mysqladmin -u root -p password 123456

  

然后输入原密码，空密码直接回车

  

![](../Images/5013c3a78ec4638cd33137c92bf39976.png)

  

这里的123456为密码，我这里演示用，所以设置的简单，如果是在服务器数据库上，大家可千万不要设置这么简单的密码

  

 到这里MariaDB数据库就已经安装好了，今天要做的就到这里，后续我再讲一下MariaDB的配置方法。
