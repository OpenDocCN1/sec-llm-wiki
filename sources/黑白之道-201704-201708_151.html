4.2 Web漏洞攻击工具

Websecurify 跨平台扫描；路径：BT - Exploitation Tools - Web Exploitation Tools
单击Start new automated test，开始自动化扫描测试；Target输入扫描对象；
如对网站内部界面扫描，点击login or initialize target 用注册用户密码登陆验证

5.1.1 在线密码破解

Hydra 由THC出品，可对samba、smb、ssh、smtp、telnet、mysql、ftp，
vnc、icq、socks5、pcnfs、cisco等主流服务进行在线密码破解，支持ssl加密；
缺陷在于不能破解ssh；BT5内置图形化界面hydra-gtk，另有命令行hydra
路径：BT - Privilege Escalation - Password Attacks - Online Attacks
例 对内网IP为192.168.1.113的计算机的smb/mssql/ftp破解出主机的登陆密码
1.Target选项卡；Single Target目标IP，protocol选择服务，勾选Show Attempts
2.Passwords选项卡；输入用户名/字典或双击选择list，双击导入字典文件
3.字典默认存放 /pentest/passwords/wordslist/darkc0de.lst；选项卡Start，开始

6.2 IBM Rational AppScan

即Watchfire AppScan；书中所述补丁地址http://download.csdn.net/source/2211125
破解补丁亲测实际下载地址http://download.csdn.net/detail/arlen_zhang/2211125

破解补丁的安装及前期准备


1.双击安装原版AppScan，安装前自动安装Microsoft .NET Framework 2.0/3.0
2.安装插件完成后，默认所有选项，正式安装；关闭杀软，打开破解补丁文件夹
3.将破解补丁中的patch.exe文件复制到默认目录的Rational AppScan文件夹
4.运行patch.exe后单击Patch完成注册；运行破解补丁文件夹里的keygen.exe
5.选择Generate生成lic文件：当Status显示License saved to license.lic，成功
6.此时在破解补丁文件夹下可见生成的lic文件；安装目录打开Licence文件夹
7.将此前破解文件夹内生成的lic文件复制到安装目录下Licence文件夹；完毕
8.运行Appscan，如果正在更新，直接关闭；弹出欢迎界面
9.取消左下角“启动AppScan时显示该屏幕”的勾选，直接关闭
10.查看“帮助”选项卡“许可证”，显示“许可证：旧许可”，说明破解成功

以http://zero.webappsecurity.com为例


1.创建新的扫描，选择“常规扫描”进入配置向导，选择“Web应用程序扫描”
2.在“起始URL”下输入要扫描的域名；注意！必须输入http://或https://
3.勾选“将所有路径作为区分大小写来处理（Unix/Linux）”，增加扫描的准确度
4.“其他服务器和域”可以添加服务器，增加扫描速度；代理需要即填
5.一直默认配置，“启动全面自动扫描”；启动“扫描专家”，默认“自动保存”
6.选择保存路径；通常先快速扫描一遍，再进行完全扫描；结果依严重性递减
7.左侧“基于URL”列举服务器目录漏洞个数；“仪表板”显示安全问题格式
