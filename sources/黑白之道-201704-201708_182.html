3.2.2 Web漏洞扫描

3.2.2.1 asp-auditor 探测asp服务器版本信息；终端 cd /pentest/web/asp-auditor
路径：BT - Vulnerability Assessment - Web Assessment - Vulnerability Scanners
Shell输入 ./asp-audit.pl [http://target/app/file.aspx]

3.2.2.2 grendel-scan 开源图形化自动检测；终端 cd /pentest/web/grendel-scan
路径：BT - Vulnerability Assessment - Web Assessment - Vulnerability Scanners
1.选项卡General Settings中Internal Proxy Settings栏内Enable internal proxy
之前的复选框需要勾掉；之后在Base URLs栏内输入目标域名，单击Add添加
2.单击选项卡Test Moudle Selection选择扫描模块；依次选择菜单栏Scan - Start Scan，
提示扫描报告的保存位置 /pentset/web/grendel-scan/scans/扫描报告
3.进入“扫描报告”文件夹双击report.html查看漏洞报告；
其中“Severity”项包括Low/Medium/High等，其中informational表示敏感信息泄露

3.2.2.3 nikto 扫描指定主机的Web类型、主机名、特定目录、cookie、特定cgi漏洞、xss / sql漏洞等；
终端 cd /pentest/web/nikto；输入 ./nikto.pl -h domain
路径：BT - Vulnerability Assessment - Web Assessment - Vulnerability Scanners
例 ./nikto.pl -h hackin9.com -F html -o 1234.html，参数 -F 保存类型 -o 文件名

3.2.2.4 skipfish Web漏洞扫描，google出品；终端 cd /pentest/web/skipfish
路径：BT - Vulnerability Assessment - Web Assessment - Vulnerability Scanners
输入 ./skipfish -o output_dir -W dictionaries/complete.wl [URL1][URL2]...
参数 -o 制定扫描报告 -W 指定字典，这里使用skipfish自带complete.wl字典
1.扫描结果Issus Found显示威胁 / 敏感信息，可执行Ctrl C终止扫描
2.终端 firefox output_dir/index.html，但由于Noscript扩展禁用了script脚本，没有内容显示；
选择地址栏前S中Allow Scripts Globally，即可查看生成文件

3.2.2.5 w3af 图形化/命令行Web应用程序攻击框架；终端 cd /pentest/web/w3af
路径：BT - Vulnerability Assessment - Web Assessment - Vulnerability Scanners
其中Profiles选择扫描方式，Plugin为插件/输出格式扫描，Target必须加http://
1.输入Target，默认扫描配置为empty_profile，仅选择audit插件，单击Start
2.扫描完成后，单击Result选项卡查看结果；例中共返回3条信息，
红色xst（Cross Site Tracing）为安全漏洞（可在Exploit选项卡直接对漏洞发起攻击），
Server Header显示服务器软件信息，allowMethods显示探测到的HTTP方法
3.在Plugin - output框架中选择htmlfile，即可保存报告文件

3.2.2.6 wapiti 命令行Web漏洞扫描器，终端 cd /pentest/web/wapiti
路径：BT - Vulnerability Assessment - Web Assessment - Vulnerability Scanners
输入 python wapiti.py http://server.com/base/url/ 参数 -u 高亮显示漏洞信息
报告默认路径 /generated_report/index.html，报告中Parameter为利用参数

3.2.3 Web模糊测试

3.2.3.1 dirbuster 路径及网页后台暴力破解工具；终端 cd /pentest/web/dirbuster
路径：BT - Vulnerability Assessment - Web Assessment - Web Fuzzers
1.Target URL中输入目标（必须加http://）；单击Browse选择字典，随机即可
2.左下方Select starting options全部勾选，单击右下Start开始破解
3.扫描完成后，单击Tree View，以目录树形式显示破解结果；
单击Report查看完整报告；单击Browse选择保存位置，此处默认，单击Generate Report生成
4.Vi编辑器打开，输入 vi /pentest/web/dirbuster/DirBusterReport-domain-80.txt

3.2.3.2 powerfuzzer 自动化Web fuzz工具，在Target URL输入（必须加http://）
路径：BT - Vulnerability Assessment - Web Assessment - Web Fuzzers
