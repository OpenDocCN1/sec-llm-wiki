漏洞信息搜集篇

3.1.1 漏洞扫描

3.1.1.1 nessus 采用本机 / 服务器结构，扫描代码与漏洞数据相互独立；
可自定义插件（Plug-in），完整支持SSL（Secure Socket Layer）；
漏洞插件由NASL（Nessus Attack Scripting Language）编写，Tenable开发；
路径：Back track - vulnerability assessment - network assessment - vulnerability scanners

启动nessus之前的准备工作：
1.单击“nessus register”注册，选择Home用户（免费版）；
阅读条款，AGREE；填写姓名/邮箱，REGISTER；登陆注册邮箱获取注册码X，
shell输入 /opt/nessus/bin/nessus-fetch --register X 后完成注册
2.单击“nessus sser add”添加用户（区分管理员/成员组），设置用户名/密码，
输入“y”将此用户列入管理员组；用户规则默认空白；再次确认添加用户
3.启动支持nessus的Web服务，路径：Backtrack - Services - HTTPD - apache start；
Shell界面显示“Starting web server apache2”，片刻自动消失

开启nessus之后所需的一些设置：
1.单击“nessus start”开启nessus服务，浏览器输入 https://localhost:8834
2.注意！此地址为本机登录使用，外网访问需要backtrack IP 映射8834端口
3.https证书选择“是”继续，根据实际情况选择安装Adobe Flash play 10.0
4.如果此时访问nessus，Firefox提示“This Connection is Untrusted”
5.选择“I Understand the Risks”后，选择“Add Exception”进入设置
6.选择“Confirm Security Exception”将域名添加至信任网站
7.注意！安装好nessus，需要用安装主程序的计算机打开；稍后即可登录
8.输入此前设置的用户名/密码，依次单击“Log In”“OK”进入操作界面

扫描方式参见“Policies”选项卡，内置4种扫描方式（可自定义）：
a)Internal Network Scan
b)Web App Test
c)Prepare for PCI DSS Audits
d)External Network Scan
选“Add”自定义扫描，设置General / Credentials / Plugins / Preferences；Submit

以域名扫描为例，单击“Scans”选项卡下的命令按钮“Add”新建任务，依次输入
“Type”（Run Now或延后）、“Policy”（这里选Web App Test）、“Scan Targets”（域名/IP或IP段），
单击右下角Launch Scan开始扫描；当“Report”选项卡中“Status”下方显示Completed，扫描完成；
选择“Browse”查看结果

另 扫描IP段192.168.1.1/254为例，单击“Scans”选项卡，“Policy”这里选择Internal Network Scan；
单击Launch Scan扫描；下载格式选择HTML export

3.2.1 CMS（Content Management System）漏洞检测

本节所述工具在虚拟机运行时需要桥接，使用NAT模式会导致扫描失败

3.2.1.1 joomscan 针对joomla（PHP MySQL）内容管理系统进行扫描，
路径：Vulnerability Assessment - Web Assessment - CMS Vulnerability Identification
Shell输入 ./joomscan.pl -u <string>(joomla url) -x proxy:port(proxy to tunnel)，
例 ./joomscan.pl -u joomlagate.com -x localhost:80；检测到xss/csrf等威胁漏洞

3.2.1.2 plecost 针对wordpress，终端 cd /pentest/web/scanners/plecost，
路径：Vulnerability Assessment - Web Assessment - CMS Vulnerability Identification
shell输入 ./plecost-0.2.2-9-beta.py -s 12 -M 30 -t 20 -o result.txt -i wp_plugin_list.txt domain
