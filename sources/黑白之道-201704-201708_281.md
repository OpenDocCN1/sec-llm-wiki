# 潜伏长达11年之久的内核漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650442676&idx=1&sn=42517304ccdf728f68b98fa83167f9a9&chksm=83bbee50b4cc674681fea2d62a33a3b383f7709c545c307f4000b01ca1e6dc32a7f05dbb0dca&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650442676&idx=1&sn=42517304ccdf728f68b98fa83167f9a9&chksm=83bbee50b4cc674681fea2d62a33a3b383f7709c545c307f4000b01ca1e6dc32a7f05dbb0dca&scene=27#wechat_redirect)

**About “Phoenix Talon”**

2017年5月9日，启明星辰ADLab发现Linux内核存在远程漏洞“Phoenix Talon”（取凤凰爪四趾之意），涉及CVE-2017-8890、CVE-2017-9075、CVE-2017-9076、CVE-2017-9077，可影响几乎所有Linux kernel 2.5.69 ~Linux kernel 4.11的内核版本、对应的发行版本以及相关国产系统。可导致远程 DOS，且在符合一定利用条件下可导致 RCE，包括传输层的TCP、DCCP、SCTP以及网络层的IPv4和IPv6协议均受影响。实际上该漏洞在 Linux 4.11-rc8 版本中已经被启明星辰ADLab发现，且后来的Linux 4.11 stable版同样存在此问题。经研究这些漏洞在 Linux 内核中至少已经潜伏了11年之久，影响极为深远。

这些漏洞中以CVE-2017-8890最为严重（达到Linux内核漏洞两个评分标准的历史最高分，CVSS V2评分达到满分10.0，CVSS V3评分是历史最高分9.8，NVD上搜索历史上涉及Linux内核漏洞这样评分的漏洞不超过20个），以下分析以该漏洞为例，引用官方描述如下：

*“The inet\_csk\_clone\_lock function in net/ipv4/inet\_connection\_sock.c in the Linux kernel through 4.10.15 allows attackers to cause a denial of service (double free) or possibly have unspecified other impact by leveraging use of the accept system call.”*

  

  

The Vulnerability

![](../Images/b9978ed087f0165e3e2a4e322df270a3.png)

  

CVE-2017-8890本身是一个 double free 的问题，使用setsockopt()函数中MCAST\_JOIN\_GROUP选项，并调用accept()函数即可触发该漏洞。

接着先看看几个组播相关的数据结构：

![](../Images/b7245560796b46b35fc8e261c7a30012.png)

该结构体的两个成员分别用于指定所加入的多播组的组IP地址和所要加入组的本地接口IP地址。ip\_setsockopt()实现了该功能，它通过调用ip\_mc\_join\_group()把socket加入到多播组。

![](../Images/508e1f4170a47532f758e2ac5dce8dd1.png)

其中sk.\_\_sk\_common.skc\_rcv\_saddr对于组播而言，只接收该地址发来的组播数据，对于单播而言，只从该地址所代表的网卡接收数据；mc\_ttl为组播的ttl；mc\_loop表示组播是否发向回路；mc\_index表示组播使用的本地设备接口的索引；mc\_addr表示组播源地址；mc\_list为组播列表。

![](../Images/47bb812d6abeebb162043080374c48a5.png)

next\_rcu指向链表的下一个节点；multi表示组信息，即在哪一个本地接口上，加入到哪一个多播组；sfmode是过滤模式，取值为MCAST\_INCLUDE或MCAST\_EXCLUDE，分别表示只接收sflist所列出的那些源的多播数据报和不接收sflist所列出的那些源的多播数据报；sflist是源列表。
