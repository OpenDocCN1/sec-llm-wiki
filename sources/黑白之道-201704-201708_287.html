2.1.4 电子邮件探测


2.1.4.1 smtpscan 探测25端口所运行的服务器软件；
终端cd /pentest/enumeration/smtp/smtpscan；输入smtpscan -v/d domain
路径：BackTrack - Information Gathering - Network Analysis - SMTP Analysis

2.1.4.2 smtp-user-enum 扫描域名25端口，探测服务器中已存在的邮箱帐户
终端cd /pentest/enumeration/smtp/smtp-user-enum
路径：BackTrack - Information Gathering - Network Analysis - SMTP Analysis
输入 ./smtp-user-enum.pl -M VRFY -U /opt/framework3/msf3/data/wordlists/unix_users.txt -t domain
参数 -M默认VRFY；-U指定用户名字典，此处使用BT5自带msf字典；-t指定枚举服务器；
返回exists后缀表示SMTP账户存在

2.1.4.3 swaks SMTP连通性测试工具；终端cd /pentest/enumeration/smtp/swaks
输入 ./swaks --to 邮箱帐户 --from 邮箱帐户；
路径：BackTrack - Information Gathering - Network Analysis - SMTP Analysis

2.1.5 域名、IP注册记录探测

2.1.5.1 whois 在backtrack5中并未内置；终端执行 apt-get install whois安装

2.2.1 CMS（Content Management System）程序版本探测

2.2.1.1 blindelephant 通过比较插件指纹，判断Wordpress程序版本；
终端cd /pentest/web/blindelephant/src/blindelephant
路径：Information Gathering - Web Application Analysis - CMS Identification
输入 python BlindElephant.py domain wordpress，参数domain即探测目标

2.2.1.2 builtwith 火狐浏览器Builtwith.com输入待查域名单击lookup；可能需要VPN

2.2.1.3 whatweb 终端cd /pentest/enumeration/web/whatweb
路径：Information Gathering - Web Application Analysis - CMS Identification
初次使用终端输入 update-alternatives --config ruby，选择自动模式
输入 ./whatweb domain/URLs

2.2.2 WAF（Web Application Firewall）防火墙探测

2.2.2.1 waffit 判断是否运行WAF防火墙；终端 cd /pentest/web/waffit
路径：Information Gathering - Web Application Analysis - IDS IPS Identification
输入 ./wafw00f.py domain/URLs，回显 ...seems to be behind a WAF / NO WAF

2.2.3 Web网络爬虫检测

2.2.3.1 webshag-gui 爬虫工具；另有webshag-cli，cli（command-line interface）
可对Web内容及url扫描分析，回显内部路径、管理员邮箱账号、外部链接等
位置：Information Gathering - Web Application Analysis - Web Crawlers
通常选择spider模式；注意！此工具需用桥接方式，使用NAT没有返回信息
