2.1.1.10 revhost 终端cd /pentest/enumeration/web/revhost；

需要安装python-dns，终端apt-get install python-dns；

安装完毕后，在启动路径选择revhosts-cli工具；

输入 ./revhosts pig [module] google.com；[module]模块：

subnet/getmail/DNSBruteforce/vhh/Getdirectories/whois/Findssubdomains

输入 /revhosts sdg [module] google.com；[module]模块：Mailloop/Pykto

以google为例，输入命令配置 dns ./revhosts pig DNSBruteforce config；“y”；

输入dns地址：222.246.129.80；59.51.78.210；8.8.8.8；Enter

暴力破解DNS，输入 ./revhosts pig DNSBruteforce google.com；

旁注查询（查看该域名在虚拟主机中其他域名） ./revhosts pig vhh palalz.com；

子域名探测，输入 ./revhosts pig Findsubdomains google.com；

站点目录探测，输入 ./revhosts pig Getdirectories google.com


2.1.1.11 zenmap，即GUI版nmap

路径：Information Gathering - Network Analysis - Network Scanners

“Profile”处选择10种扫描方式：

例1.Intense scan：-T4 快速执行，-A 操作系统及版本探测，-v 显示详细输出

例2.Intense scan plus UDP：-sS TCP/SYN扫描，-sU UDP扫描

例3.Intense scan，all TCP ports：-p 指定端口范围，如 -p 1-65535；慢

例4.Intense scan，no ping：-Pn 非ping扫描

例5.Ping scan：-sn ping扫描，快但容易被防火墙屏蔽，无结果

例6.Quick scan：-F 快速模式

例7.Quick scan plus：-sV 探测端口及版本服务信息，-O 开启操作系统检测，

                   --version-light 设定侦测等级为2

例8.Quick traceroute：-sn Ping/关闭端口扫描，-traceroute 本机到目标的跃点

例9.Regular scan：-sn Ping/关闭端口扫描，-traceroute 本机到目标的路由跃点

例10.Slow comprehensive scan：慢速全面扫描，“Command”显示nmap命令

输出结果选项卡：Ports/Hosts 端口及服务信息；Topolog网络分布；Host Details


2.1.2 操作系统探测


2.1.2.1 xprobe2 通过ICMP协议获得指纹；终端cd /pentest/scanners/xprobe2

路径：Information Gathering - Network Analysis - OS Fingerprinting

输入 ./xprobe2 domain；输入 ./xprobe2 -v -r IP，-v 详细 -r 显示traceroute；

注意！网络模式由NAT改为桥接，以免回显host port版本或直接报错


2.1.3 端口服务软件探测


2.1.3.1 amap 操作系统、端口对应服务版本判断；nmap后细化探查；

路径：Information Gathering - Network Analysis - Service Fingerprinting

Application Mapping 模式：amap -A domain port；返回服务器软件

Banner 模式：amap -B domain port；返回操作系统

如果扫描报错，输入 amap -P domain port；返回OPEN则端口开启


2.1.3.2 dmirty 输入 -w/i/n/p domainn，whois域名/IP/服务器OS/端口

路径：Information Gathering - Network Analysis - Service Fingerprinting


2.1.3.3 httprint Web服务器指纹工具；也可检测没有旗帜字符串的设备

路径：Information Gathering - Network Analysis - Service Fingerprinting

1.查询目标域名IP，输入 nslookup domain

2.扫描目标服务器信息，输入 ./httprint -h IP -s signatures.txt

注意：可以通过改变server bannerstrings，mod security / servermask插件混淆


2.1.3.4 httsquash查询dns或ip服务器相关信息工具

终端cd /pentest/scanners/httsquash；探测方式banner

路径：Information Gathering - Network Analysis - Service Fingerprinting

输入 ./httsquash -r domain -p port，返回服务器、IP、传输编码；默认80端口


2.1.3.5 sslscan 探测基于ssl的服务，如https；作为识别ssl加密强度的首选；

http://www.titania.co.uk；使用前确定域名可用https访问/433端口开放；路径：

BackTrack - Information Gathering - Network Analysis - Service Fingerprinting

输入 sslscan --no-failed domain；参数 --no-failed，列出服务器支持的加密算法
