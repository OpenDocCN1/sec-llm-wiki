      什么是zabbix？

  

zabbix是一个基于WEB界面的提供分布式系统监视以及网络监视功能的企业级的开源解决方案。

  

zabbix能监视各种网络参数，保证服务器系统的安全运营；并提供灵活的通知机制以让系统管理员快速定位/解决存在的各种问题。

  

zabbix由2部分构成，zabbix server与可选组件zabbix agent。

  

zabbix server可以通过SNMP，zabbix agent，ping，端口监视等方法提供对远程服务器/网络状态的监视，数据收集等功能，它可以运行在Linux，Solaris，HP-UX，AIX，Free BSD，Open BSD，OSX等平台上。

  
  

搭建环境的准备

1,.有网（最好是一个公网IP，内网也可以。）

2.Centos7系统

3.一台测试监控的电脑。

操作步骤：

1.    yum update -y #更新系统到最新

2.    vi/etc/sysconfig/selinux #编辑selinux

3.    把SELINUX=enforcing 修改为 SELINUX=disabled #关闭selinux

4.    :wq #保存并退出

5.    yum install -y wget #安装wget

6.    cd /tmp/

7.    wget http://repo.mysql.com/mysql-community-release-el7-5.noarch.rpm#下载mysql

8.    rpm -ivh mysql-community-release-el7-5.noarch.rpm#安装mysql

9.    yum install -y OpenIPMI.x86\_64net-snmp.x86\_64 unixODBC.x86\_64 java-1.7.0-openjdk-headless.x86\_64dejavu-sans-fonts gcc.x86\_64 mysql-community-server.x86\_64mysql-community-devel.x86\_64 libxml2-devel.x86\_64 net-snmp-devel.x86\_64 libssh2-devel.x86\_64OpenIPMI-devel.x86\_64 libcurl-devel.x86\_64 java-1.7.0-openjdk-devel.x86\_64httpd php.x86\_64 php-mysql.x86\_64 php.x86\_64 php-mysql.x86\_64 php-devel.x86\_64php-xml.x86\_64 php-cli.x86\_64 php-bcmath.x86\_64 php-mbstring.x86\_64php-gd.x86\_64 #安装各种软件包

10.  rpm -ivh

http://ftp.tu-chemnitz.de/pub/linux/dag/redhat/el7/en/x86\_64/rpmforge/RPMS/fping-3.10-1.el7.rf.x86\_64.rpm#下载安装fping

11.  rpm -ivh http://dl.fedoraproject.org/pub/ ... 4-6.el7.x86\_64.rpm#下载安装iksemel

12.  wget http://repo.zabbix.com/zabbix/2. ... 3-1.el7.x86\_64.rpm#下载zabbix-server

13.  wget http://repo.zabbix.com/zabbix/2. ... 3-1.el7.x86\_64.rpm#下载zabbix-server-mysql

14.  wget http://repo.zabbix.com/zabbix/2. ... 3-1.el7.noarch.rpm#下载zabbix-web

15.  wget http://repo.zabbix.com/zabbix/2. ... 3-1.el7.noarch.rpm#下载zabbix-web-mysql

16.  rpm -ivh http://repo.zabbix.com/zabbix/2. ... 3-1.el7.x86\_64.rpm#安装zabbix

17.  rpm -ivh http://repo.zabbix.com/zabbix/2. ... 3-1.el7.x86\_64.rpm#安装zabbix-agent

18.  rpm -ivh http://repo.zabbix.com/zabbix/2. ... 3-1.el7.x86\_64.rpm#安装zabbix-get

19.  rpm -ivh http://repo.zabbix.com/zabbix/2. ... 3-1.el7.x86\_64.rpm#安装zabbix-java-gateway

20.  rpm -ivh Zabbix-server-2.4.3-1.el7.x86\_64.rpmZabbix-server-mysql-2.4.3-1.el7.x86\_64.rpm #安装zabbix-server-mysql

21.  rpm -ivh Zabbix-web-mysql-2.4.3-1.el7.noarch.rpm Zabbix-web-2.4.3-1.el7.noarch.rpm#安装zabbix-web-mysql web

22.  systemctl enable mysql.service #开启mysql.service

23.  systemctl start mysqld.service #开启mysqld

24.  systemctl status mysqld.service | grep Active

25.  mysql -u root #进入mysql

26.  CREATE USER ‘zabbixuser’@’localhost’IDENTIFIED BY ‘123456’; #创建数据库用户

27.  create database zabbixdb character set utf8 collate utf8\_bin; #创建utf8字库

28.  grant all privileges on Zabbixdb.\* to zabbixuser@localhostidentified by ‘123456’;

29.  exit #退出

30.  cd /usr/share/doc/Zabbix-server-mysql-2.4.3/create/ #到create

31.  mysql -uroot zabbixdb < schema.sql

32.  mysql -uroot zabbixdb < images.sql

33.  mysql -uroot zabbixdv < data.sql

34.  vi /etc/zabbix/zabbix\_server.conf #修改zabbix\_server.conf

35.  #DBHost=localhost改成DBHost=localhost #打开本地

36.  DBName=zabbix改成DBNname=zabbixdb #修改名字

37.  DBUser=zabbix改成DBUser=zabbixuser #修改用户

38.  #DBPassword=改成DBPassword=123456 #修改密码

39.  :wq #退出

40.  systemctl enable zabbix-server.service #打开zabbix-server

41.  systemctl start zabbix-server.service

42.  systemctl status zabbix-server.service | grep Active

43.  systemctl enable zabbix-agent.service

44.  systemctl start zabbix-agent.service

45.  systemctl status zabbix-agent.service | grep Active

46.  systemctl enable zabbix-java-gateway.service

47.  systemctl start zabbix-java-gateway.service

48.  systemctl status zabbix-java-gateway.service | grep Active

49.  vi /etc/php.ini #修改php.ini

50.  max\_execution\_time=30改成max\_execution\_time=300

51.  post\_max\_size=8M 改成 post\_max\_size=16M

52.  ;max\_input\_time改成max\_input\_time=300

53.  ;date.timezone=改成date.timezone=America/Sao\_Paulo

54.  :wq #退出

55.  Systemctl enable httpd.service #开启httpd

56.  Systemctl start httpd.service #开机启httpd

57.  Systemctl status httpd.service | grep Active

58.  cd /tmp/ #进入tmp

59.  firewall-cmd –-permanent --zone=public --add-service=http

60.  firewall-cmd –-permanent –-zone=public –-add-service=https

61.  firewall-cmd--permanent –-zone=public –-add-service=mysql

62.  systemctl restart firewalld.service

63.  reboot#重启
