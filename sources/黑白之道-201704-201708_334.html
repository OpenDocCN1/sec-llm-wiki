敏感信息收集（Information Gathering）



2.1.1 网络踩点-DNS（Domain Name System）记录探测



2.1.1.1 dnsenum 针对DNS信息的收集

终端cd /pentest/enumeration/dns/dnsenum

shell输入 ./dnsenum.pl domain

附www.wooyun.org/search.php?q=域传送



2.1.1.2 dnsmap DNS类枚举；推荐使用OpenDNS IP

终端cd /pentest/enumeration/dns/dnsmap

shell输入 ./dnsmap domain -r

参数-r：将破解结果保存至其后目录



2.1.1.3 dnsrecon 枚举DNS记录

终端cd /pentest/enumeration/dns/dnsrecon

shell输入 ./dnsrecon.py -d domain <options>

参数 -x，--axfr 请求枚举；-s，--do_spf 反向查询；-w，--d_whois 查whois；

-g，--google 通过google枚举子域名及IP；--lifetime TIME 响应时间/秒（必选）



2.1.1.4 dnswalk 基于OpenDNS IP的域传送专查

终端cd /pentest/enumeration/dns/dnswalk

shell输入 dnswalk domain. 这里domain之后的“.”一定不能省略；

如果没有域传送漏洞域名，返回“错误”



2.1.1.5 fierce 域名暴力破解

终端cd /pentest/enumeration/dns/fierce

shell输入 ./fierce.pl -dns domain -wordlist PASSWORD.txt

-wordlist后指定字典/密码表



2.1.1.6 lbd 负载均衡检测

终端cd /pentest/enumeration/web/lbd

shell输入 ./lbd.sh domain



2.1.1.7 maltego 自动化情报搜集

路径 BT - Information gathering - network analysis - dns analysis

注册地址https://www.paterva.com/web5/community/index.php#Register

实际注册地址https://www.paterva.com/web7/buy/maltego-clients.php

将左侧工具栏图标拖入主界面，如DNS Name、Domain、IPv4 Address等；

扫描结果选项卡：Mining View，Dynamic View，Edge Weight View，Entity List



2.1.1.8 netifera 图形化踩点/嗅探

路径 BT - Information gathering - network analysis - identify live hosts

Tools/Sniffing两种模式；后者终端telnet DNS 80，查看Tools返回结果



2.1.1.9 reverseraider 域名暴力破解

终端cd /pentest/enumeration/reverseraider

shell输入 ./reverseraider -d DNS -w wordlists/x.list

在reverseraider命令行下查看字典，依次输入 ls，cd wordlists，ls

内置字典：fast.list；services.list；word.list



附：

1.域名（Domain Name System），映射为IP地址的过程称为“域名解析”。

2.MX信息是邮件交换记录，用于发邮件时收信地址后缀定位邮件服务器。

3.Whois包含域名及相关注册信息。AXFR记录/请求经常导致全区域传输。

4.存在域传送（zonetransfer）漏洞的服务器，可通过-ls命令列出Domain地址。

5.最短路径优先算法（Shortest Path First）是OSPF路由协议基础。SRV记录。
