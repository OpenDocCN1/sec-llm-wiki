# Cisco路由破解特权密码

大家好，我是Alex。今天给大家带来cisco路由器破解特权密码的教程

  

拓扑图如下

  

![](../Images/dc08190908e4dbad116bf415ceddd457.png)

打开路由器控制台

  

![](../Images/7eb28ddc9cd15bf2b719785b5ae2975a.png)

  

尝试。。。。。。发现密码忘记了

  

开始破解，重新启动路由器

  

![](../Images/8fe13f375d8aa68885dcb55aa99b1434.png)

  

在此时按下Ctrl C终止路由启动，输入confreg 0x2142   配置寄存器值为0x2142

  

![](../Images/0c76bd76a37208dba0cec3c1486b924e.png)

  

Reset重启路由器。

  

输入no不加载启动时的引导配置文件

  

![](../Images/7f527c9a9e2dfdd7969a509543d2ed5b.png)

  

之后

  

![](../Images/f86e159b93300dd4949974ea91d64f41.png)

  

成功进入！

  

使用show startup-config查看配置和先前的密码

  

![](../Images/3699ac062d7ebeae8ec2f1ab2c119af0.png)

![](../Images/f588fadcfb779f18f9ed649c616741d4.png)

copy startup-config running-config来复制启动配置到当前运行配置

  

![](../Images/c0d0f1638aefc96f343d983be68fbb30.png)

  

修改密码为cisco

  

![](../Images/854823ae905f9e316eb24786a4507515.png)

  

之后copy running-config startup-config将当前配置保存到启动加载配置文件

  

![](../Images/552565e42dc80bb487869cbffae81242.png)

  

使用show version来查看版本和寄存器的值

  

![](../Images/eb18ada454f4a4b609609b035ad63ffa.png)

  

更改寄存器的值为原前的0x2102就可以了！

  

![](../Images/3f822f31f7fe91d2305b89379990ad1d.png)

  

重启试一下

  

![](../Images/bbd599f46f616375a36299e6aa8e5a3c.png)
