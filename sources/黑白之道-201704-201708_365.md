关于 Back track

初期版本为安全审计类光盘auditor security collection，

由Remote-exploits.com基于knoppix开发；

之后与黑客攻击类光盘WHAX（White-Hat SLAX）整合。

类似操作系统：WiFiSlax、Wifiway、nUbuntu、SkyRidr、

PHLAK、slitaz、mpentoo、NodeZero、REMnux、

Security Onion、OWASP livecd、backbox等

1.4 基本命令及环境配置

  

  

ifconfig查看网卡/接口；ethx为所用网卡

ifconfig ethx up激活

dhclient ethx自动获取网卡设置

ifconfig ethx IP netmask -- 设置静态IP/子网掩码

route add default gw -- 设置默认网关

nano /ect/resolv.conf设置DNS

nameserver 208.67.222.222/220.220设置DNS服务器为openDNS

Ctrl X退出并输入Y确认保存，手动设置成功

  

  

切换网络连接方式

（1）桥接：直接连接物理网络

（2）NAT：使用已经共享的主机地址

（3）Host-only：与主机共享一个私有网络

（4）自定义虚拟网络

  
  

注意！虚拟机关闭状态，选择NAT模式启动，否则开机后网卡无法识别

终端 cd /gedit /etc/apt/sources.list或

路径 Places-Computer-File System-etc/apt/sources；

其中sources文件为deb更新源（内容另附）

  

  

终端 apt-get update，开始更新源代码；

终端 apt-get install language-selector安装输入法，

路径 System-Administration-Language Support弹出对话框

选择Remind Me Later开启Language&Format

  
  

1.6 光盘启动安装back track 5

  
  

录制光盘

Nero express7选择“映像项目复制”，“光盘映像或保存的项目”，选择iso文件。

  

  

光驱引导系统读取back track 5光盘 选择：

Back track text字符模式（默认）

Back track Stealth无网模式

Back track Forensics取证模式（不使用硬盘/交换分区）

Back track noDRM无DRM驱动模式

Back track Debug安全模式

Back track Memtest内存测试

Hard Drive Boot从第一块硬盘启动其他系统
