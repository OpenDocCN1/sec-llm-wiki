John the Ripper  登陆网站 http://www.openwall.com/john 下载软件

加密过的密文称为散列（hash）；确保不可能从散列值逆向转换为明文信息

不同的系统会采取不同的加密算法以创建散列；大部分系统将密码散列保存在单一位置

步骤：1.选择散列算法 2.选择明文 3.用此算法对明文加密 4.将密文与目标系统中散列对比

获得远程目标计算机访问权限后破解密码所需步骤：

1.关闭目标计算机；2.设置BIOS重新启动并进入backtrack；

3.挂载本地磁盘驱动器；4.Samdump2提取散列；5.John the Ripper

生成密码散列的速度取决于生成散列加密算法及硬件性能；衡量单位为c/s（破解次数/秒）；

打开终端 cd /pentest/passwords/jtr；进入目录后输入 ./john --test 显示性能指标列表


破解windows密码

在基于NT内核的windows系统中，经常将散列保存在SAM（安全账号管理器）的文件里；

SAM保存在“C:\windows\System32\Config\”目录；系统启动同时文件锁定加密且不可见；

只要目标处于运行状态，就可以利用Meterpreter和SAM Juicer远程获取目标计算机散列；

获得系统的物理权限之后，在其上启动backtrack，即可绕过windows对SAM文件的锁定



打开终端输入 fdisk -l 列出目标系统全部可用驱动待选；

同时，还需要在“/mnt”目录下创建一个挂载点（mount point），使用mkdir命令 mkdir /mnt/sda1；

之后输入mount /dev/sda1 /mnt/sda1挂载本地硬盘，尤其是包含windows文件夹的本地硬盘



成功在backtrack中挂载本地驱动器之后，将可以浏览windows下的“C:\”盘；

此时打开终端，输入 cd /mnt/sda1/windows/system32/config 即可进入包含SAM文件的目录；

之后在终端窗口执行“ls”命令，将当前文件夹里的内容列出；如果目录正确即可见SAM文件

**成功定位SAM（此时仍处于加密状态）以后，可以利用 Samdump2 工具提取散列

**这个工具利用本地计算机上system文件（与SAM在同一目录）对SAM文件进行解密



命令 cd /mnt/sda1/windows/system32/config 进入SAM文件夹之后，提取SAM文件内容

输入 samdump2 system SAM > /tmp/hashes.txt 调用Samdump2程序；

后面“> hashes.txt”命令的作用是将结果存到“hashes.txt”文件中，并保存在backtrack的“/tmp”目录里

**输入 cat /tmp/hashes.txt 使用“cat”命令显示hashes.txt文件的内容

**需要将密码散列从光盘引导的BT系统的磁盘上转移出来，自生（live CD）无法保存



微软原先使用的散列加密算法Lan Manager（LM）存在严重缺陷：

1.利用LM算法生成散列时，整个密码字符都将大写，降低了密码强度

2.所有LM算法密码长度都是14个字符；少于14以空值（null）填满，大于14会被截短

3.利用LM算法生成的14个字符密码，在保存时会被均分为两段，每段包含7个字符

微软现在已使用NTLM算法生成密码散列，但仍有系统可以设置激活LM



要运行BT中内置的John the Ripper，只需在终端中输入john；

调用此命令其实是运行了一段脚本程序，以进入到“/pentest/passwords/jtr”目录中，执行 ./john/tmp/hashes.txt；

其中“./john”用来调用john the ripper；此命令强制Linux在当前目录下运行程序

如果目标计算机使用的是NTLM散列，命令后应加上“-f:NT”参数；余者不变



破解Linux和OSX密码

Linux系统将加密的密码散列包含在“shadow”文件中，完整路径为“/etc/shadow”；

另有“/etc/passwd”类似于windows系统中的system文件；JtR自带将二者结合的功能；

需要用到“unshadow”命令，位于“/pentest/passwords/jtr”目录下，终端输入

./unshadow /etc/passed /etc/shadow > /tmp/linux_hashes.txt

成功提取散列之后，使用支持破解不同类型密码散列的John the Ripper版本；

如JtR未打补丁，将返回错误信息，显示“No password hashes load”；

大多数现代linux系统都使用SHA散列加密算法保存密码；

在“/pentest/passwords/jtr”目录下执行命令 ./john /tmp/linux_hashes.txt




使用chntpw命令进行密码重置：直接覆盖SAM文件（需要物理访问权限且不可恢复）

1.使用backtrack光盘引导，以启动目标系统；

2.重启之后，终端挂载存有SAM文件的系统物理硬盘驱动器：

打开终端输入 fdisk -l 列出目标系统全部可用驱动待选；

同时，还需要在“/mnt”目录下创建一个挂载点（mount point），使用mkdir命令 mkdir /mnt/sda1；

之后输入mount /dev/sda1 /mnt/sda1挂载本地硬盘，尤其是包含windows文件夹的本地硬盘；

3.挂载硬盘驱动器之后，终端输入 cd /pentest/passwords/chntpw 进入chntpw目录；

4.查看完整的选项列表和可用参数，执行 ./chntpw -h 命令；

5.重置管理员密码，执行 ./chntpw -i /mnt/sda1/WINDOWS/system32/config/SAM 命令：

“-i”参数表示以交互模式运行该程序，并选择需要重置的用户；

其后是目标计算机上挂载包含SAM文件的目录；具备访问SAM文件权限；运行“fdisk -l”，确定挂载驱动器名称；

6.此后会显示一系列交互菜单选项，方括号内为回车默认选项，如：

“what to do？[1]”，这里[1]为 Edit user data and passwords；

此后屏幕显示本地可以进行密码重置的用户列表，再次默认选择[administrator]；

下一步进入 User Edit Menu，选择[1]Clear user password（切记默认）；

之后屏幕出现“Password cleared！”，即可重置密码或输入“！”退出程序；

但此时新的SAM文件尚未写入硬盘驱动器，在之后的菜单中选择“q”退出chntpw，

提示是否将更改写入硬盘驱动器，输入“y”（切忌默认）；

7.全部完成后，选中用户密码已清除，输入“reboot”命令关闭Backtrack并弹出光盘



网络嗅探（network sniffing）：截获并查看某一网络进出流量，从而获取目标系统访问权限；

默认情况，网卡/接口卡/适配器在非混杂（nonpromiscuous）模式下运行，只传递指向本机地址的特定网络流量；

而混杂（promiscuous）则强制网卡接受流入的所有数据包，例如，广播流量/使用集线器（hub）而非交换机（switch）路由流量



Macof（Dsniff工具集）：泛洪攻击交换机

当计算机连上交换机时，网卡的MAC地址会在交换机上注册；

而交换机针对不同地址分别使用不同路由信息的设计，可以被强迫按照集线器的工作方式运行；

多数交换机保存包含MAC地址和对应端口号匹配表的内存容量有限；

将内存耗尽，并用伪造的MAC地址泛洪匹配表，以致交换机无法匹配正确端口而全部发送，称为“失效开放”（fail open）；

反之，当交换机被设置为“失效关闭”（fail closed），造成“拒绝服务”（Denial of Service）攻击；

Backtrack内置macof，打开终端，执行命令 macof -i eth0 -s 172.16.45.123 -d 172.16.45.2 ；

“macof”调用程序，“-i”指定源MAC地址所在网卡，“-s”指定源地址，“-d”攻击对象


Wireshark：在交换机上进行网络流量嗅探

2006年以前曾命名ethereal，由Gerald Comb于1998年编写，http://www.wireshark.org

Backtrack已内置wireshark，路径：Privilege Escalation（提权）>Sniffers（嗅探器）> ；

默认Backtrack不启用网卡/首次警告“Running Wireshark as user ‘root’ can be dangerous.”

单击左上角List available capture interfaces（列出可抓包的接口），默认/设置Options，Start；

单击红叉，停止捕捉；在Filter框输入ftp等协议后单击Apply；Clear清除过滤视图返回



Fast-Track Autopwn：自动化漏洞攻击

启动路径：Backtrack>Penetration>Fast Track>Fast-Track WebGUI；

此后Firefox将自动打开Fast-Track网页，单击右下Autopwn Automation链接后：

Enter IP Address or Range，选择bind/reverse（正/反）shell后，确定攻击；终端执行msf > sessions -l，列出所有shell；

终端执行msf > sessions -i shell_id，即进入远程计算机shell；列出当前目录meterpreter > ls
