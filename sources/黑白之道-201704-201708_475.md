## 项目地址：

https://github.com/mrschyte/nmap-converter

## 简介

将nmap报告转换为XLS的Python脚本

## 要求

```
sudo pip install python\-libnmap
sudo pip install XlsxWriter
```

or

```
sudo pip install \-r requirements.txt
```

## 用法

```
usage: nmap\-converter.py \[-h\] \[-o XLS\] XML \[XML ...\]
```
