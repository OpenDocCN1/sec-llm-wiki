# Firefox未经用户许可 植入《黑客军团》沉浸游戏插件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650444757&idx=3&sn=bf46c48dcff13bb8101b39b43b41d419&chksm=83bbf631b4cc7f270064fcd9994059fe9d93a5888007b7c68c503581fda69b218a4799358fdd&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650444757&idx=3&sn=bf46c48dcff13bb8101b39b43b41d419&chksm=83bbf631b4cc7f270064fcd9994059fe9d93a5888007b7c68c503581fda69b218a4799358fdd&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

昨天，不少Firefox用户在使用过程中发现新增了名为Looking Glass的插件。虽然这款插件默认处于关闭状态，但未安装用户会收到相关的提醒通知，而插件描述则显得模糊不清：“我的实际情况和你不同”。

  

![](../Images/acc2aa8a5ad2ba7edeea772264ef7964.png)

  

在支持社区上，有用户写道：“在我的记忆中没有安装这款扩展的历史，而且我也不会选择去安装它。我甚至在网络上找不到相关的描述。”

  

Mozilla官方网站随后发表声明称，这项插件其实是公司和Mr. Robot（黑客军团电视剧）系列开展合作的尝试，这是作者给玩家预留的线索。文档中表示这款插件在设计初衷是为了提升Mr Robot系列游戏的沉浸感，是由Mozilla和Mr Robot在美国的团队共同开发的。

  

![](../Images/771707d6009f0bee1808dabcad5f5937.png)

  

这款插件在激活之后，会修改部分指定网站内容，从而为Mr. Robot ARG玩家提供更多的线索。文档中写道“你是 Mr Robot 的粉丝吗？你想解决黑客军团提出的难题吗？如果是，你找对人了！” 官网如是说。
