大家好，我是Alex。今天教大家windows下使用netsh实现端口转发！

目标IP：192.168.1.200

跳板机IP：192.168.1.199（1.200的远程管理机）

攻击机IP：192.168.1.19


IP 192.168.1.200开启了远程桌面连接以及3389端口，但在防火墙做了策略只能通过管理机（192.168.1.199）访问，如下图



192.168.1.19无法访问192.168.1.200远程连接



IP 192.168.1.19可以远程管理机（192.168.1.199）




那么好，我们就通过远程管理机使用netsh命令来新建一条端口转发规则，使得攻击机可远程管理机本地转发后的端口来连接目标机器


在管理机中（192.168.1.199）使用如下命令，将本地端口443转发至192.168.1.200的3389端口

netsh interface portproxy add v4tov4 listenport=443 listenaddress=0.0.0.0 connectaddress=192.168.1.200 connectport=3389


PS：删除转发规则 ，add改为delete



可使用命令netsh interface portproxy show all来查看所有已建转发规则，


注意：防火墙例外443端口！



这样攻击机就可以直接连接目标远程桌面了



我们再看一下管理机443端口的服务状态



如果大家防火墙例外后还是无法连接，请在服务里面开启IP Helper
