今天给大家介绍的是一款名叫MAC-的WiFi的命令行工具，它可以管理的MacOS系统的无线网络，并且还提供了交互式外壳。

MAC-的WiFi

MAC-WiFi的脚本可以查询或管理的MacOS平台上的无线网络配置以及网络环境信息，脚本代码在最小化的类中实现了针对MacOS的环境的设计逻辑，并且允许开发者轻松地添加针对其他操作系统的支持，但是目前该工具仅支持MacOS的操作系统。

该工具可以在单一命令行或交互模式下运行，交互式模式使用pry gem，并可提供类似Rubyists或其他REPL用户的交互式接口。

在使用这款工具时，你甚至都不需要下载整个代码库，或者进行任何的安装，你只需要运行仓/ MAC-WiFi的脚本文件就可以了。

该工具是基于Mac的命令行工具实现的，但这并不是最佳的解决方案。本来我更愿意去使用Mac系统的系统调用，但现在的这种方法可以提高我开发脚本的速度。

更好的输出结果

如果你想在非交互模式下获取更形式化的输出结果（使用信息命令），你需要安装awesome_print gem，否则你只能使用“pp”命令了（效果不够好）。因此我建议大家安装awesome_print，安装命令如下：


gem install awesome_print

查看底层操作系统命令和输出

如果你想查看MacOS的命令以及相应的输出，你可以设置环境变量MAC_WIFI_OPTS为-v（使用信息命令进行演示）：


export MAC_WIFI_OPTS=-v./mac-wifi i


或者


MAC_WIFI_OPTS=-v  ./mac-wifi i

使用交互式壳牌

如果当你尝试运行壳时程序崩溃的话，你可以尝试更新撬或撬byebug操作命令如下：


gem install prygem install pry-byebug


使用样例

单一命令行调用


mac-wifi i            # 打印输出WiFi信息mac-wifi lsa          # 输出可用网络mac-wifi lsp          # 输出优先选择的网络mac-wifi co a-network a-password # 与一个需要密码的网络进行连接mac-wifi co a-network            #与一个不需要密码的网络进行连接mac-wifi t on && say "Internetconnected" # 当与一个网络连接成功之后播放消息
