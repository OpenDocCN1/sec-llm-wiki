# 印媒诬称印机密视频会议遭到“中国黑客”入侵

《印度快报》19日称，印度政府高层上个月通过卫星进行机密的视频会议时，遭到“中国黑客”入侵。报道援引匿名消息人士的话说，在印方进行反击之前，“中国黑客”大概控制了四五分钟。

  

该报称，印度网络巡逻队追踪到这次袭击来自中国，但尚不确定是国家参与的行动，还是网络犯罪分子的行为。“来自黑客的消息是明确的：由于我们松懈的网络安全机构，他们随时都可以‘关上水龙头’”，上述消息人士说，“中国黑客”侵入最复杂和秘密的链接的方式令人震惊，表明他们可以轻易利用漏洞，破坏关键基础设施。

  

“安全威胁变得更有组织和有针对性。国家和非国家行为体正在从数据交换中获益”，印度电子信息工业部在一封内部通信中承认，缺乏对信息基础设施的全面保护方法，甚至安全机构都不能有效抵制这些有针对性的攻击。《印度快报》称，该报查阅的印度国内间谍机构——情报局的报告显示，印政府已经被警告需要反击日益增加的网络间谍活动。

  

据报道，印度电子信息工业部已指示相关部门准备一个详尽的应急计划，以应对外部电子攻击引起的危机，并由负责基础设施、网络应用和网站的专家进行审议。12月8日，法律、劳工、外交、重工业和公共企业部等印度中央7个部门将进行模拟演习，测试关键设施的网络安全。

  

有中国网络安全专家19日对《环球时报》记者说，网络安全是世界共同面对的问题。印度加强网络安全意识和措施是积极举动，但无需拿“中国黑客”说事。事实上，中国也是网络黑客攻击的受害国，中国政府一贯坚决反对和打击任何形式的黑客攻击活动。
