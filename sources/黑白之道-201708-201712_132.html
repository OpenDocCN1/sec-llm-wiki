juice shop是一个开源的web漏洞练习靶场，练习神器


环境：Ubuntu16.04


首先更新一下 sudo apt-get update



然后sudo apt-get install docker 安装docker



执行 sudo apt install docker.io 执行后才能使用docker 



项目地址：https://github.com/bkimminich/juice-shop


下载完后进行配置：docker run -d -p 3000:3000 juice-shop



然后访问http://localhost:3000即可！
