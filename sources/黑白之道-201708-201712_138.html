Hello，大家好，我是Lionel，今天给大家带来一个修改默认启动内核的教程，利于bbr的安装和性能的稳定。看我操作。



1、查看启动配置里有没有内核


cat/boot/grub2/grub.cfg | grep menuentry



2. 修改默认启动项


grub2-set-default 0


从上图可以看到，我这里新内核已经在配置文件里是第一个了，第一个的序号是 0 ，第二个是 1 ，以此类推。所以我这里是0、


3. 查看是否设置成功


grub2-editenvlist



4. 最重要的一步，更新grub.cfg


grub2-mkconfig -o/boot/grub2/grub.cfg



5.reboot
