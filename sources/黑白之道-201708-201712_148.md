哈喽，大家好，我是Adam。上周讲了NFS服务器的搭建方式，这是一种共享文件的服务。今天来讲一下centos7服务器下搭建FTP的方法。

  

1、首先，通过yum的方式安装vsftpd

  

yum install vsftpd

  

![](../Images/62d529512fe0c874a5e49870fd505b9d.png)

  

2、默认的主配置文件放在/etc/vsftpd/vsftpd.conf

  

vi /etc/vsftpd/vsftpd.conf

  

![](../Images/28050db74b700aacc6979da248f544c1.png)

  

打开后看上去虽然很乱，但是仔细看不难发现，绝大多行都是注释符#注释了的，主要是用来介绍几个参数的应用，唯一有用几个参数我已经用红色框标注出来了

  

3、下面来说一下每个参数的意思

  

anonymous\_enable表示是否同意匿名用户访问，YES表示允

local\_enable表示是否允许本地用户登录

write\_enable表示是否允许本地用户拥有写入操作

local\_umask=022表示除本地用户外，其他用户是不能进行写入操作

dirmessage\_enable表示目录消息

xferlog\_enable表示日志信息  

connect\_from\_port\_20表示连接端口

  

4、在centos7里，查看vsftpd状态是下列命令的格式，如果要重启或者开启关闭服务时，就把status换成restart等等就可以了systemctl status vsftpd.service

  

![](../Images/85d3fe5de5b6da03e5bb32808c0533d6.png)

  

查看状态显示vsftpd正在运行，没问题

  

5、同时不要忘记关闭防火墙

  

systemctl stop firewalld.service

  

6、测试成功，可以成功访问

  
![](../Images/a1cf0e9a6a3246398fce9b609a262ca0.png)

  

OK，到这里FTP服务器就算是搭建好了，下周再来讲一下权限设置和访问限制的一些内容。
