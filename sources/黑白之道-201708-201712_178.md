# NFS服务器的安装配置

大家好，我是Adam。今天来讲一下NFS网络文件服务器的安装和配置。

  

NFS是linux系统进行文件共享的一种网络协议，NFS客户端通过挂载NFS文件系统的方式来访问NFS服务器中输出的共享目录

  

1、NFS服务器需要yum -y install nfs-utils rpcbind这个软件包，现在来安装一下两个软件包

  

yum -y install nfs-utils rpcbind

  

![](../Images/9ac9eec60e685e9d74876d07fc02d298.png)

  

![](../Images/7395dd10f54a0a6632faa5652c9e952c.png)

  

2、在nfs服务器修改配置文件

  

  vi /etc/exports

  

  比如要共享/home/share这个目录，只需要填写下图命令，修改保存即可

  

![](../Images/cc9ff026bf5b452f422581488d9b04c9.png)

  

此处\*这个符号的意思是指定给哪些人分享，\*为全部，也可设置IP段、域名，甚至是只指定特定唯一的IP来访问

  

sycn：设置nfs服务器同步写磁盘，这样不容易丢失数据

  

ro：表示客户端对该目录是只读权限，如果想添加写入权限，可以改成rw

  

3、重启服务，关闭防火墙

  

![](../Images/18a8c3600c5ed2af1c1be21e89a83765.png)

  

![](../Images/e638b2bc556a251201fe7a51172c4ee2.png)

  
  

4、在/home目录下创建share文件夹

  

![](../Images/11ece742dee75d94f2ccde250b905c25.png)

  

5、创建的share文件夹的属主为root，需要把它的属主修改为nfs的用户才可以

  

![](../Images/63054099d75b8858758cfa032f4aa9b7.png)

  

6、NFS服务器就配置完成了，然后就是客户端的操作了

  

首先，同样的，在客户端也要安装nfs的软件包，然后重启关闭防火墙，然后同样在/home目录下创建一个文件夹，然后把属主修改为nfsnobody

  

![](../Images/56e447cf4562ae8cd20dfaf918aa2d38.png)

  

使用mount挂载的方式来访问

  

![](../Images/3ca12c746744052c3aa0fe6895559c1f.png)

  

7、挂载成功后，然后进行测试，在NFS服务器上的share文件夹中创建一个文件，客户端的nfs文件夹中也显示该文件，表示配置成功

  

![](../Images/b26b1c97f722bc12a7b752018e879069.png)

  

![](../Images/e6140c9223898901f65b694728aaf5b5.png)

  

8、然后是一些后续配置操作，可以把nfs设置为开机启动项

  

![](../Images/60f690aeb0dd0b3faa8e8ea5e26745b3.png)

  

然后在挂载项中，添加这个项目

  

vi /etc/fstab

  

![](../Images/e08841d40a68976a7dd89b72f4e2b0d3.png)

  

到这里就设置完成了！
