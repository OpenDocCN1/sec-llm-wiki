# 爆破带验证码的后台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650444217&idx=2&sn=331451a3a138c2aed71dfaaba294526e&chksm=83bbf45db4cc7d4bf56f28e82fb1be8cc7115d22fad6f87fc09ffb236eb1feaaed90636af15d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650444217&idx=2&sn=331451a3a138c2aed71dfaaba294526e&chksm=83bbf45db4cc7d4bf56f28e82fb1be8cc7115d22fad6f87fc09ffb236eb1feaaed90636af15d&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

用到的工具是 PKAV HTTP Fuzzer 一款神器

  
![](../Images/3be1f26ce1dc1c15adfe4b9df8e5bbe5.png)   
要先用burp抓到登录的包放到这里，然后载入字典，可以选择重放模式  
  
![](../Images/60f868c5e986c4c6df48119da487e576.png)   
  
然后找到验证码的地址复制，可以先进行验证码测试，其他默认就好  
在重放选项里可以设置错误返回内容，http重定向等，与burp类似  
然后在发包器里点击启动即可  
  
![](../Images/07b80d2ec851eb46f809a6a6749e3d56.png)
