今天给大家介绍一款RTSP流数据访问工具-Cameradar，这是一款可以渗透CCTV摄像头的工具，并且自带了相关代码库。

  

![](../Images/0b82429d535c592abcf619d00e4b95d6.png)

  

## Cameradar功能介绍

> \\1. 检测任何可访问的目标主机并扫描出开放的RTSP主机；
> 
> \\2. 检测正在传送监控数据的设备型号；
> 
> \\3. 发动自动化字典渗透入侵目标流路由器；
> 
> \\4. 发动自动化字典渗透获取目标摄像头的用户名以及密码；
> 
> \\5. 自动生成完整的分析报告；

  

![](../Images/d674141c6fd5f198241c9957d06bcab7.png)

  

## 工具安装

首先你需要在电脑上安装docker，然后运行下列命令：

```
docker run -t ullaakut/cameradar -t
```

示例：

```
docker run -t ullaakut/cameradar -t192.168.100.0/24 
```

上面这条命令将会扫描192.168.100.0/24子网中所有主机的554和8554端口，并对发现的RTSP流数据进行渗透，最后输出调试日志。

<YOUR\_TRGET>可以是一个子网（例如172.16.100.0/24），一个IP地址（例如172.16.100.10），或是一个IP地址范围（例如172.16.100.10-20）。

如果你想获取XML格式的nmap详细扫描结果，你可以在运行docker命令时（在ullaakut/cameradar之前）加上“-v /your/path:/tmp/cameradar\_scan.xml”。

你还可以使用-r或-c参数来指定使用你的自定义字典，命令如下：

```
docker run -t -v
```
