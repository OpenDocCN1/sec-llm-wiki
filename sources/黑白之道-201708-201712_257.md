清晨是一天的开始，像个男人一样的开始战斗吧。这个库的api文档库在这里http://pexpect.readthedocs.io/en/stable/api/index.html主要的组成部分：Spawn类Run函数ExceptionsUtility我们主要介绍的是spawn类和pxssh（这个是控制一个ssh会话的类）Sapwn类的初始化函数：

  

1.  \_\_init\_\_(<i>command</i>, <i>args=\[\]</i>, <i>timeout=30</i>, <i>maxread=2000</i>, <i>searchwindowsize=None</i>, <i>logfile=None</i>, <i>cwd=None</i>, <i>env=None</i>, <i>ignore\_sighup=False</i>, <i>echo=True</i>, <i>preexec\_fn=None</i>, <i>encoding=None</i>, <i>codec\_errors='strict'</i>, <i>dimensions=None</i>)
    

  

  

所以我们创建这个产卵类的对象的时候我们可以调用这样子做：

  

1.  child = pexpect.spawn('/usr/bin/ftp')child = pexpect.spawn('/usr/bin/ftp', \[\])
    

  

第一种是直接在command这个参数的地方给出命令和相应的参数第二章是单独的给出，command参数给出命令，args给出参数，一个列表又如我们想要记录这个过程中的日志到某一个文件，我们可以这样子做

  

1.  child = pexpect.spawn('some\_command')fout = open('mylog.txt','wb')child.logfile = fout
    

  

让这个类的logfile变量指向一个文件对象之后我们想要去获取程序的返回，针对性的进行反应，这时候我们就用到expect函数了。这个函数的原型为：expect(*pattern*, *timeout=-1*, *searchwindowsize=-1*, *async=False*)Pattern参数是让我们提供我们预计划的程序输出，如

  

1.  index = p.expect(\['bar', 'foo', 'foobar'\])
    

  
P为spawn的对象，这个例子是我们认为程序可能输出这三个值，expect函数会从目标程序输出的一个缓存区中匹配这些值，比配到bar时返回0，foo为1pexpect.EOF, pexpect.TIMEOUT我们可以使用这两个eof和timeout来捕获异常，而不是通过一个抛出异常来捕获。程序的一般结构为：

  

1.  index = p.expect(\['good', 'bad', pexpect.EOF, pexpect.TIMEOUT\])
    

  

1.  if index == 0:    do\_something()elif index == 1:    do\_something\_else()elif index == 2:    do\_some\_other\_thing()elif index == 3:do\_something\_completely\_different()
    

  

在介绍一个会用到的内置变量beforeP.before这个会打印出匹配之前的字符串。相应的也有aftersendline(*s=''*)函数允许我们去发一个命令到指定的程序。接下来我们介绍一下pxssh这个类，这个类的构造器为：  

  

1.  <i>class </i>pexpect.pxssh.pxssh(<i>timeout=30</i>, <i>maxread=2000</i>, <i>searchwindowsize=None</i>, <i>logfile=None</i>, <i>cwd=None</i>, <i>env=None</i>, <i>ignore\_sighup=True</i>, <i>echo=True</i>, <i>options={}</i>, <i>encoding=None</i>, <i>codec\_errors='strict'</i>)from pexpect import pxsshimport getpasstry:    s = pxssh.pxssh()    hostname = raw\_input('hostname: ')    username = raw\_input('username: ')    password = getpass.getpass('password: ')    s.login(hostname, username, password)    s.sendline('uptime')   # run a command    s.prompt()             # match the prompt    print(s.before)        # print everything before the prompt.    s.sendline('ls -l')    s.prompt()    print(s.before)    s.sendline('df')    s.prompt()    print(s.before)s.logout()except pxssh.ExceptionPxssh as e:    print("pxssh failed on login.")  
    

  

 print(e)这个是官方的一个例子。 这个类增加了login函数（用来登录），prompt函数（匹配提示符）logout（退出）接下来我们试着去连接一下我虚拟机里面的centos里面的ssh
