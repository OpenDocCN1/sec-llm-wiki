Hello 大家好 我是Lionel，今天给介绍一个linux中测试路由 回程路由的方法。一些网站也提供这些功能，比如说ipip 和TraceRoute路由追踪软件。这些只是测试去程路由，大多数都关注去程路由，但是回程路由一样重要。


不管你是科学上网还是搭建个人博客或者做一些测试。你都应该关注回程路由。因为服务器回把你需要的信息回传到自己的PC里，所以要有一些数据包会回来。所以回程不好走的话也会影响访问质量。


给你举个例子

比如说我们有一个博客。或者在服务器中有一个测试软件。

我们需要传输一个文件或者工具。在传输的过程中是去程路由，如果质量不好就会很慢。很卡。回程也一样，在服务器中打开一个软件，服务器会给你放回一个数据包。如果回程质量不好，同样会慢。


TraceRoute linux版

yum update 更新系统软件包管理

yum install traceroute 安装软件

使用方法

traceroute ip




Nali-ipip

这个软件需要调用traceroute 所以要先安装上面的软件 IP库有ipip提供的

yum update

yum install traceroute git gcc make

git clone https://github.com/dzxx36gyy/nali-ipip.git

cd nali-ipip

./configure

make

make install



BestTrace

yum install traceroute

wget -N --no-check-certificate https://softs.fun/Other/besttrace.tar.gz

tar -xzf besttrace.tar.gz && cdbesttrace && chmod x *



如果需要测试回程路由，你可以安装一个MTR的软件。
