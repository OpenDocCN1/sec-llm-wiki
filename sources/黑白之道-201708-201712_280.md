## 简介

攻击网络协议和网络开发的框架。

官方网站：  http : //dedsploit.github.io

此框架旨在利用和攻击一些常见的每日漏洞，如SSH服务器错误配置。

该框架包括若干模块，并且在每个模块内将是攻击矢量。

```
主|\+  - SSH | \+ - | |  - bruteforce \- bruteforce易受攻击的SSH服务器| \+  - SMTP | \+ - | | \- bruteforce \- bruteforce SMTP地址（又称电子邮件）  | | | | \- smsbomb \- 利用SMTP \- 到\- 邮件网关垃圾邮件短信|  \+  - HTTP | \+ - | | \- arpspoof \- MITM 其中用户假货局域网ARP报文，拦截数据包从主机| |   | | \- slowloris \- 层\- 7 的DoS 攻击利用慢头和畸形的GET请求到脆弱的Web服务器|    \+  - 侦察| \+ - | | \- pscan \- 使用Nmap进行端口扫描   | | | | \- 主机\- 扫描为活动主机|  \+ ------
```

## 安装和使用

最好是在卡利环境中安装这款程序，在Mac系统上使用也可以。

首先，git克隆。

```
混帐克隆的https ：//github.com/ex0dus-0x/dedsploit
```

改变目录，然后运行安装脚本（必须是根用户或具有超级用户权限）：

```
cd dedsploit sudo的Python安装程序。PY
```

installer.py脚本会为你安装必要的依赖。

一旦完成，执行与\*：

```
dedsploit
```
