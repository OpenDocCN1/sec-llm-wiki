1.weblogic

  

![](../Images/91fa4a0c21df5f0838464de8702c2149.png)

  

后台页面：（http为7001，https为7002）

Google关键字：WebLogic Server AdministrationConsole inurl:console

默认的用户名密码

1、用户名密码均为：weblogic  
2、用户名密码均为：system  
3、用户名密码均为：portaladmin  
4、用户名密码均为：guest

上传地方：

workshop> Deployments> Web应用程序> 部署新的 Web 应用程序模块…

上传war的webshell。

  
![](../Images/1979ee78c54bafbed67028f6e9cff91b.png)   

上传后目标模块->部署。

  

2.Tomcat

后台：http://172.16.102.35:8080/manager/html  
默认用户名密码  
tomcat tomcat

  

上传地方：

  
![](../Images/0b8b0fe800622a9b631a5801842e6f58.png)   

Deploy之后即发布成功

shell地址：http://172.16.102.35:8080/magerx/test.jsp(其中magerx为war包的名字）

  
![](../Images/d7f080bc751b566d10f44f6ea4dfd64d.png)

  
  

3.jboss

后台：http://172.16.102.35:9990

上传地方：Deployments>Manage Deployments>Add Content

  
![](../Images/6adaa91cd7e3347fff367fb4155964af.png)   
  
  

Enable后即可发布

shell地址：

http://172.16.102.35:8080/magerx/test.jsp

![](../Images/4838fcba3d752b075eb04f2ef74c95f9.png)

  

4.JOnAS

后台：http://172.16.102.35:9000/jonasAdmin/

默认用户名密码：  
jadmin jonas  
tomcat tomcat  
jonas jonas

上传地方：Deployment>Web Modules (WAR)>Upload

![](../Images/3effad9cd689465324aa4880cdabee83.png)

![](../Images/90b53233d3aae60eb354426736ddf826.png)

Apply之后即可发布

shell地址:http://172.16.102.35:9000/magerx/test.jsp

  

5.WebSphere

后台地址:https://172.16.102.35:9043/ibm/console/logon.jsp

上传地方:应用程序>新建应用程序>新建企业应用程序

  
![](../Images/aca9ff1ddb28b50ac99f881e34aba6b7.png)   
![](../Images/a16aac26f1f38627248df7f9c7b2efac.png)   

接下来各种下一步，步骤4注意填好“上下文根”

![](../Images/4e5a9549de504c5d3dca9dd4579ca0a3.png)

完成后单击保存

  
![](../Images/8d2625a27dd5d6bbf3b78a5005f3306c.png)   

回到应用程序>应用程序类型>WebSphere 企业应用程序

  
![](../Images/acf80905407a82ab330c0c1331c76fe9.png)   

选中你上传的war包 这里是paxmac  点击启动 即可发布  
shell地址:http://172.16.102.35:9080/paxmac/test.jsp
