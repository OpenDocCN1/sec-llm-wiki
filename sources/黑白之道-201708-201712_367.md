# 坏消息！你的性爱机器人可能被黑客控制伤害你

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

一名网络安全科学家发出奇怪警告：如果黑客能侵入性爱机器人的大脑，他们某天或会奋起反抗，杀死其主人。

  

![](../Images/4d5543a47004080242f356b684059de8.png)

  

上个月，科技行业亿万富翁伊隆马斯克声称，人工智能会接管地球，他并不是唯一一个担心杀手技术隐患的人。网络安全讲师尼克帕特森博士透露，随着性爱机器人的普及和复杂化，这些栩栩如生的娃娃最终会成为我们的“终结者”。

  

然而，性爱机器人的危险并不是爱情玩偶最终会发展成“西部世界”风格，风险在于，黑客会侵入性爱机器人的内部防御系统。帕特森在接受《明星在线》采访时表示，与智能手机和电脑等更为复杂的设备相比，黑客侵入包括性机器人在内的许多现代机器人十分简单。

  

![](../Images/f7485717a6e31a637898df52a1e367ff.png)

  

来自澳大利亚迪肯大学的技术专家说：“黑客可以侵入机器人或机器人设备，完全控制其手臂、腿和其他附件，比如刀或焊接设备。一旦机器人被黑客入侵，黑客就能彻底控制机器人并向其发出指令。”这一警告听起来可能有些牵强，但其实不然，因为这些机器人本质上使用的是操作系统，如同手机或PC一样。

  

![](../Images/4a375e9362aa5942b7cbfa46044eb684.png)

   

一旦系统连接到互联网，黑客就有可能入侵它。这位网络防御专家补充道：“最不希望的就是黑客控制机器人。一旦被黑客入侵，机器人们将被用来采取行动破坏有利场景。”
