（一）   环境配置

1\.  物理环境：我用的是Digitalocean的VPS。比较良心的公司。VPS的架构比较好。

  

2.配置环境：Debian7 x64  1核 512MB内存 20G硬盘 美国旧金山机房。

  

3\. 软件环境：我这次用的是lnmp集成环境，可能一些刚接触这些的同学不知道lnmp是什么意思，下面解释。

  

##什么是lnmp？##

简单通俗的说  l=linux

                         n=nginx

                         m=mysql

                         p=php

  

这四个加起来组成的环境就叫lnmp。还有叫lamp的，a=apache。还有各种集成环境。

  

##为什么用集成环境？##

  

部署快，不容易出错。测试环境易部署。一个一个安装报错黑人？？？。Lionel 懒！

  

（二）   安装环境

  

1\.  安装lnmp

用putty链接到服务器 输入账号密码登录

  

登陆后运行：screen -S lnmp  
如果提示screen: command not found 命令不存在可以执行：yum install screen 或 apt-get install screen安装。

  

2\. 下载安装lnmp

wget http://soft.vpser.net/lnmp/lnmp1.4-full.tar.gz        ##下载lnmp安装包

  

3\. 解压lnmp 1.4-full.tar.gz

tar zxvf lnmp1.4-full.tar.gz

  

4\. 进入lnmp 1.4-full文件夹

cd lnmp 1.4-full

  

5\. 运行install.sh安装lnmp

./install.sh

  

6\. 运行上述LNMP安装命令后，会出现如下提示：

  

![](../Images/d4760f077678bf13579104eb7beae3dc.png)  

  

选择第2项 输入2按回车。  

  

接下来会让你设置mysql密码。输入密码即可。

  

![](../Images/4dd52e80b70f8dbe2f12c44519c40236.png) 

  

询问是否需要启用MySQL InnoDB，InnoDB引擎默认为开启，一般建议开启，直接回车或输入 y 。

  

![](../Images/4279e31c916018f21e4137b9c8ed8154.png) 

输入要选择的PHP版本的序号，我们这里选择4。回车进入下一步，选择是否安装内存优化

  

![](../Images/93e6aa7a6b954b22c2a471158e191b52.png) 

  

选择1 不安装。

  

然后按任意键开始安装。

  

##安装的过程较慢，大概20分钟左右##

  

![](../Images/1bec187eacee42881665696be7c47645.png)

  

看到这个就代表完成安装了。

  

（三）   配置环境

  

1.命令行继续输入

Lnmp vhost add    ##编辑主机名 写上自己的域名。回车进行下一步

        

2.输入一遍不加WWW的域名 回车进行下一步。

        

3.域名文件夹存放位置，他给出了一个位置，默认就可以。直接按回车。

        

4.不需要rewrite 输入n回车

        

5.允许访问日志 根据个人偏好设置，我这里选择n 回车

       

 6.是否创建mysql用户 选择n回车。

       

 7.是否添加ssl证书规则 选择n回车

  

![](../Images/e43b9cff03f52dd2a16201049468d32f.png)

  

这里我们按任意键创建主机。

  

##上面我全是n是因为节省时间，大家需要哪个按y就可以##

  

（四）   数据库配置

  

1.访问ip/phpmyadmin登录数据库。用户名root 密码刚才配置lnmp设置了。

  

2.点击账户→新增用户账户

          User name 填写一个名字 一定要记住

          Host name %（如果本身有%就不用添加了）

          密码 输入一个密码

          重新输入再输入一遍

          打钩   创建与用户同名的数据库并授予所有权限。

          ##其他的不用管。滚轮到网页最下方 有一个执行点击##

  

3.创建好后左面会出现一个用户，点击用户。然后选择中上方的导入按钮。

  

选择从计算机中上传。我们这里要上传五个文件，文件我会在教程最下方以链接的方式分享给大家的。

  

![](../Images/5680b83ddc838c89194befa77c239f16.png)

  

分别是这5个文件。每次只能上传一个，分五次上传。

  

![](../Images/1955aeb5977145cf0baeb37faf6e9f5c.png)

  

OK。我已经上传完成了。

（五）   网站配置

1.打开lib文件夹把config-simple.php修改成config.php

  

2.用notepad 打开这个php文件

  

3. define('DB\_USER','root');中root修改成你的数据库账户名

  

4. define('DB\_PWD','password');中password修改成你的数据库密码

  

5.$site\_url  = "https://panel.com/";中把域名修改成你的域名

  

6. $salt ="ss-panel";ss-panel修改成

  

保存文档

  

7.重启nginx       //lnmp nginx restart

  

8.上传网站包，把ss-panel-2中的文件全部打包，上传到/home/wwwroot/你的域名文件夹

  

##怎么上传文件。百度谷歌搜索winscp##

  

9.上传完成后 putty中输入 cd /home/wwwroot/你的域名

  

10.进入后输入 unzip 压缩包的名字.zip，进行解压。

  

11.把域名解析VPS服务器的IP上。

  

##怎么解析？？？##

  

咨询你的域名供应商。

  

12.访问域名

OK已经完成了配置，我们打开自己的域名。可以看到前端的界面。下节课我们讲一下后端的配置。
