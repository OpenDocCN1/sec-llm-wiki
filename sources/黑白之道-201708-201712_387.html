大家好，我是你们的老朋友Alex。这次教大家在暗网中搭建一个属于自己的博客，这样就可以做一些羞羞的事情了~


说明一下环境：主机是亚马逊的Ubuntu16.04.2，Web容器Nginx，网站程序wordpress，数据库MYSQL。


接下来的具体步骤以及报错解决，我会按顺序分两部分写完！


我们开始吧！


首先看一下目前的安全组策略





一共应用了三个安全组，22 8080端口和ICMP-IPv4。


使用新建的密钥对登录主机并且使用命令sudo passwd设置root密码，之后切换到root用户下




我们优先配置tor服务，刷新软件源并下载tor



对tor进行配置，编辑/etc/tor/torrc



将这两行前注释去掉后，修改127.0.0.1:8080。把本地8080端口通过tor代理服务转发到80端口。


之后重启tor服务



通过文件/var/lib/tor/hidden_service/hostname获取属于自己的洋葱域名



这样tor的服务已经配置完毕了，接下来就是配置nginx来搭建网站了！


先安装nginx


从官网http://nginx.org 下载最新nginx



安装 gccg 的依赖库

apt-get install build-essential

apt-get install libtool

安装 pcre依赖库

apt-get install libpcre3 libpcre3-dev

安装 zlib依赖库

apt-get install zlib1g-dev

安装 ssl依赖库

apt-get install openssl

然后解压nginx，编译安装。我已经解压安装过了，我下面写一下命令

tar -zxvf nginx-1.13.5.tar.gz

cd nginx-1.13.5

./configure --prefix=/usr/local/nginx

Make && make install

然后下载wordpress


https://cn.wordpress.org





解压出来就可以了！



我们还需要安装数据库，我这里选择的是MYSQL


apt-get install mysql-server php7.0-mysql


紧接着，登录数据库创建用户、数据库并且把库授权给wordpress用户



最后就剩下php没有安装了，我们继续安装PHP7.0



apt-get install php7.0-cli php7.0-cgiphp7.0-fpm


查看当前php版本信息，如果没有报错就算完成了



到此所有的环境已经安装好了，下一节就是配置和解决报错了！我们下次见！！
