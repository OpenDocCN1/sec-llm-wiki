# 防止服务器被下shift后门的思路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650443505&idx=2&sn=dbc2148e7561a0ba2513fdfdef163e3a&chksm=83bbeb15b4cc6203785b73ff636a5515c96723a20e891ce9d04154a916e2186d0cf7d3f0ec4e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650443505&idx=2&sn=dbc2148e7561a0ba2513fdfdef163e3a&chksm=83bbeb15b4cc6203785b73ff636a5515c96723a20e891ce9d04154a916e2186d0cf7d3f0ec4e&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

shift后门存在于

c:\\windows\\system32\\sethc.exe  c:\\windows\\system32\\dllcache\\sethc.exe 这两个路径

  

防止shift被替换可以删除所有用户组  或者把shift键直接删除掉  

  

![](../Images/87d5da06672ae2889017eed71c5bcc3d.png) 

  

在注册表中设置防止sethc被劫持  
  

注册表：HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Image File Execution Options\\  
  

删除所有用户的用户组,加上everyone的组然后设置全部拒绝即可

  

![](../Images/cfc1eb9e0386e25efd0f679b0e9b9547.png)
