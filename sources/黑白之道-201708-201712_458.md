# 我与短信拦截木马的故事

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650443434&idx=2&sn=ff08691fe912775abdc47bac79fd96c3&chksm=83bbeb4eb4cc625831730c220f1fbd610eba241146d5db0c996b072941b20e7ee221c6aee06d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650443434&idx=2&sn=ff08691fe912775abdc47bac79fd96c3&chksm=83bbeb4eb4cc625831730c220f1fbd610eba241146d5db0c996b072941b20e7ee221c6aee06d&scene=27#wechat_redirect)

大家好，我是你们的老朋友Alex。正在想写什么的时候，突然发现网盘里安安静静的躺着一个以前哥们脱壳的短信拦截木马，就决定写这样一篇文章来让大家了解拦截马并且保护自己免受这种木马的侵害！

  

![](../Images/8689e830972c32d1c2dbc02fa2948ec1.png)

  

首先看了一下样本，大小是400K左右。功能的话就是收集通讯录联系人和所有短信记录下发到指定163邮箱和手机号，拦截所有短信转发到指定邮箱和手机，后台清理不下线。不过这样的话应该算是这种木马的基础功能吧，另外设置有自删除和替换原有短信应用的功能！看了一下支持版本在安卓4.0及以上，卸载木马的时候有一定的技巧而且大部分的管理软件无法卸载此木马。

  

看一下大致的木马利用过程！

  

用到工具：apktool   apktool助手   MT管理器

  

需要准备一个手机号注册的163邮箱并且开启授权码，如图

  

![](../Images/95e0b46614c6b4fa53698e7c0eafb33b.png)

  

![](../Images/1ef03c9b10e5a44f071ecbb0cb09ece9.png)

  

这样收信的邮箱就准备好了。

  

接着该配置木马了，使用MT管理器打开apk

  

![](../Images/9c114c18829234de4a616cfa1a594f46.png)

  

打开classes.dex文件，选择搜索类输入手机号

  

![](../Images/e8ef393910564602a71882fb068fad94.png)

  

将手机号码改为替换的手机号和箭头指向的地方填入邮箱授权码，大家可以知道为什么要用手机号注册163邮箱了吧=W=

  

![](../Images/1cb84b550ae89a2665d16895fec0895a.png)

  

修改有效期也是同样如此

  

![](../Images/701e76de46ab1f3c92d812fa6b176f06.png)

  

修改很简单，然后就是更换应用名称  图标了，更换的方式有两种。

  

第一种直接在现有打开的文件中替换，图标在/res/drawable-hdpi中

  

![](../Images/3f03183d7e51b953fa4dfa3a35d5dde2.png)

  

名称在

  

![](../Images/abbf1a87e30dac1778e8762e9c1f2a8c.png)

  

![](../Images/2eef81ee22585beadacd8bfffc57fcc9.png)

  

第二种使用apktool反编译apk

  

![](../Images/ab7666c5e51b18dd48c73a534dbe5391.png)

  

然后在apktool助手中打开反编译后的文件夹

  

![](../Images/8adf7375e958c958b2a9fcc154d9d9a6.png)

  

![](../Images/e89c065529a62816ffc50f50ad83d874.png)

  

![](../Images/2cc41288016fa5fff06fc405c185a284.png)

  

这样就可以修改了，还可以修改包名！然后再使用apktool编译然后签名就OK了！

  

![](../Images/bb57c6979bd490f2378c2c3fdc8bdfc1.png)

  

如果可以的话加一个壳，或者转码加密手机号和邮箱。

  

![](../Images/7838fc74d32dcc8f338b81c46adbe22b.png)

  

我们安装测试

  

  

![](../Images/da4e67e8bacf590bf79dd17bf512146e.png)

  

![](../Images/2b6b709e1d7490e02297c6dcaf9a5540.png)

  

安装激活后，会向我手机号发送上线信息

  

![](../Images/6e21cf198a45f44074204b992b9dbe34.png)

  

还有邮箱

  

![](../Images/eedc7050fe99a5ad85e5e9ede520066d.png)

  

再看桌面，木马已经消失了！！！！

  

![](../Images/b01c70ee619576961f40cbbd6672cb34.png)

  

如果找不到实用的图标可以使用Restorator提取

  

![](../Images/3cc1598ef8fc485a6afeffbd238562a3.png)

  
  

具体的卸载我就不演示了，手机截图再传太麻烦了！首先取消激活再使用系统自带卸载就可以删除掉了！手机管家查到毒了，但是不能卸载就很尴尬。

  

谢谢大家阅读此文章，用攻击者的角度来讲解木马利用，也就更好防范了！
