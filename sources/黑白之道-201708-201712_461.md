# 央视发出最强音：共筑网络安全防火墙

今晚央视《焦点访谈》播放了共筑网络安全防火墙的报道，描述了当今社会网络安全形势的严峻性，提醒着相关单位相关责任人需要重视网络安全工作。

  

![](../Images/bb3646a259d62f5ebcfb791c3f49bdbc.png)

  

其中某科研单位在13个月期间共受到374万次网络攻击，平均每个月受到28.76万次攻击，每天受到接近一万次的攻击。

  

![](../Images/872608f597742156a14ae3a82001f328.png)

  

某单位人员电脑被植入木马，可以获取该电脑上所有涉密信息等重要资料，可以密切关注该人员的活动。

  

![](../Images/697a5c34a43f7a98d59d970199571fc5.png)

![](../Images/faae8118eaec93acd922ec5b919a3ef5.png)

  

斯诺登事件爆发后，我们知道国外有专门的间谍组织在对他国涉密信息和关键信息基础设施进行攻击，获取其想要的资料。

  

![](../Images/b4125d3fd2f4cd0fa12cb49b23c56b8b.png)

  

责任主体：谁使用是负责，谁主管谁负责，谁运营谁负责。不要认为系统托管在外，责任主体就转移改变了。

  

![](../Images/5958fb8f55345041248704eb13c48c4c.png)

  

安全责任重于泰山，没有网络安全就没有国家安全。
