# 微信发的“原图”中隐藏了重要的信息

自从知道微信也可以发送原图之后，在微信上发图片给对方会习惯性选择“原图”发送。对方发来的原图我也习惯性下载好保存至手机上。

  

![](../Images/5ddd2ee366eca5ccca95fd6d15c32939.png)

  

直至今天，小编发现一个可怕的事情：原图发给好友，对方可以根据图片的信息找出你所在的具体位置，甚至定位到你**住所的街道、小区、单元楼**。

  

![](../Images/b7ea6a9a5b858380e77218e6a94c3d7d.png)

  

以小编所在公司为例，具体操作是，下载完对方的原图后保存至手机，在图库里打开图片，点击更多，可以看到类似“地图位置”、“详情”的选项。

  

![](../Images/14f6a8d5c64103d89657fd5856a3005e.png)

![](../Images/a9700fa8d56b07e90368262ea0915df6.png)

  

点击详情，可以看到拍摄的详细信息，包括**经纬度地址，拍摄时间，手机型号**等。在查询经纬度，你所在的位置就一目了然。

  

![](../Images/d951fb219c2d3424ec3b759a8d0ee26a.png)

![](../Images/87890a1ec8a018b68ccdb10db1888f96.png)

  

根据这个地址差不多可以找到公司所在位置了。  

  

如果想要更确切的位置，点击地图位置选项，拍摄照片所在的街道也能给你挖出来。把照片的位置显示在地图上，甚至可以具体定位到你家所在的小区、单元楼。

  

![](../Images/6723155f783799a03074ad7c2b3fc9f3.png)

  

**为什么会这样？**

  

现在的手机都有GPS功能，并且是默认打开的，而手机的相机在拍照的时候也会自动搜索GPS信号，将你所在的位置嵌入图片中。

  

所以一旦发原图，连着自己的位置信息也一并泄漏了出去。对方只需要保存图片，点开详细信息，就可以利用地图软件知道你身在何处甚至是家庭住所。

  

**有什么办法阻止这类事情发生呢？**

  

有两种办法：

> 不发原图
> 
> 关闭相机中的位置记录功能

  

如果还是忍不住想发原图也不想关闭地址位置，那就发闪照吧，阅后即焚，对方没办法保存。

  

不仅只是微信，一切能不压缩、传输完整照片的工具都有此风险，比如QQ、微博等。所以，给陌生人发照片时尽量别发原图，非原图和截图是不会留下位置信息的。

  

至于**P过的照片**也会暴露隐私吗？这个大家可以试试，毕竟P图也成了小公举们的终身事业。按理说P过的图片已经不算原图了，但有的网友还能识别出地址，谁能告诉我这是什么操作？
