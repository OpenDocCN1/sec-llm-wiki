# 防止服务器被下shift后门的思路

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650446441&idx=3&sn=4079180a4e7ef1774f2108623fcba08b&chksm=83bbff8db4cc769b99edf80e6cfd78bd3c857521113f61f28b0678bbdabffbfe9157c5e3e82d&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650446441&idx=3&sn=4079180a4e7ef1774f2108623fcba08b&chksm=83bbff8db4cc769b99edf80e6cfd78bd3c857521113f61f28b0678bbdabffbfe9157c5e3e82d&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

shift后门存在于

  

c:\\windows\\system32\\sethc.exe  c:\\windows\\system32\\dllcache\\sethc.exe 这两个路径

  

防止shift被替换可以删除所有用户组  或者把shift键直接删除掉  

  

![](../Images/00071147e51e4da9579f63e80bf68550.png) 

  

在注册表中设置防止sethc被劫持  
  

注册表：HKEY\_LOCAL\_MACHINE\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Image File Execution Options\\  
  

删除所有用户的用户组,加上everyone的组然后设置全部拒绝即可

  

![](../Images/c9b29466812a71cb54d9b4ef59854f41.png)
