WordBrutePress是一款基于Python的Multithreaded Wordpress bruteforcing工具。  
  

**特征：**

  
多线程  
XML-RPC爆破模式  
HTTP和https协议支持  
随机用户代理  
大单词表支持  
  
**用法：**

标准登录请求：  
python wordbrutepress.py -S -t http ：//target.com \[：port\] -u用户名-w wordlist   
\[ - 以秒为单位\]  
  
Xml-rpc登录请求：  
python wordbrutepress.py -X -t http ：//target.com \[：port\] -u用户名-w wordlist   
\[ - 以秒为单位\]
