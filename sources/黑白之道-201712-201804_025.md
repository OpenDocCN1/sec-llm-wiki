Nessus是一款漏洞扫描器，能够进行高速资产发现，配置审计，目标分析，恶意软件检测，敏感数据发现等等。

  

**报告和监测：**

  

灵活的报告：自定义报告以按漏洞或主机排序，创建执行摘要或比较扫描结果以突出更改。

  

本机（XML），PDF（需要在Nessus服务器上安装Java），HTML和CSV格式。

  

针对扫描结果的电子邮件通知，修复建议和扫描配置改进。

  

**扫描功能：**

  

发现：准确，高速的发现。

  

扫描：漏洞扫描（包括IPv4 / IPv6 /混合网络）。

  

未认证的漏洞发现。

  

用于系统强化和丢失补丁的证书扫描。

  

满足内部漏洞扫描的PCI DSS要求。

  

覆盖范围：广泛的资产覆盖和分析

  

网络设备：防火墙/路由器/交换机（瞻博网络，Check Point，思科，帕洛阿尔托网络），打印机，存储。

  

网络设备的脱机配置审计。

  

虚拟化VMware ESX，ESXi，vSphere，vCenter，Microsoft，Hyper-V和Citrix Xen Server。

  

操作系统：Windows，OS X，Linux，Solaris，FreeBSD，Cisco iOS，IBM iSeries。

  

数据库：Oracle，SQL Server，MySQL，DB2，Informix / DRDA，PostgreSQL，MongoDB。

  

Web应用程序：Web服务器，Web服务，OWASP漏洞。

  

云：扫描云应用程序的配置，如Salesforce和云实例，如Amazon Web

Services，Microsoft Azure和Rackspace。

  

合规性：有助于满足政府，法规和企业要求。

  

有助于强化PCI DSS对安全配置，系统强化，恶意软件检测，Web应用程序扫描和访问控制的要求。

  

威胁：僵尸网络/恶意，进程/防病毒审计检测病毒，恶意软件，后门，与受僵尸网络感染的系统进行通信的主机，已知/未知进程以及链接到恶意内容的Web服务。

  

合规审计：FFIEC，FISMA，Cyber??Scope，GLBA，HIPAA / HITECH，NERC，SCAP，SOX。

  

配置审计：CERT，CIS，COBIT / ITIL，DISA STIG，FDCC，ISO，NIST，NSA，PCI。

  

控制系统审计：SCADA系统，嵌入式设备和ICS应用程序。

  

敏感内容审核：PII（例如，信用卡号码，SSN）。

  

**主要优点**

  

减少攻击面：通过识别需要解决的漏洞来防止攻击。

  

综合性：符合最广泛的合规性和监管标准。

  

可扩展性：从Nessus Professional单用户许可开始，随着漏洞管理需求

  

增加，迁移至Nessus Manager或Tenable.io。

  

低总体拥有成本（TCO）：以低成本完成漏洞扫描解决方案。

  

不断更新： Tenable研究团队不断添加新内容
