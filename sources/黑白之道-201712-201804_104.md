# 细思极恐，当你的车辆被黑客远程控制

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650446072&idx=1&sn=463241eab05fd757cc63500bb99ba39c&chksm=83bbfd1cb4cc740a04de9f559b8c2f4dded40545359feca089ae960cbaf41ea3578e51cbcdb4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650446072&idx=1&sn=463241eab05fd757cc63500bb99ba39c&chksm=83bbfd1cb4cc740a04de9f559b8c2f4dded40545359feca089ae960cbaf41ea3578e51cbcdb4&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

今年315期间爆出一条消息，说是比亚迪远程锁定车辆，阻止车主去现场维权。  

![](../Images/0477e0683b50484cd22d5b43554373a7.png)

当然这事很快被辟谣，说是租车公司的行为，因为承租者拖欠租金，所以就锁定了车辆。  

![](../Images/0c3e46ea8f6b542b4ac5bcaac580685d.png)

我相信比亚迪是不会做这种事情的，车企私自锁定已经出售的车，这样做涉嫌违法，而且为了区区50辆车，而自毁声誉，显然也不划算。但我今天要讲的并不是比亚迪，而是车辆远程控制。

![](../Images/6fd6ad48c07e2cf3be3154ae6d04d720.png)

首先要明确一点，车辆是可以被远程锁定的，这也不是新鲜技术，比较早的像通用安吉星就有这个功能，最初这种技术主要是用来防盗的，后来逐步扩展出更多的更能，比如远程启动，远程诊断等。

  

但是，就像电脑一样，既然汽车可以通过网络实现远程控制，就可能会招来黑客入侵。在美国，有一对叫 Miller 和 Valasek的好基友，他们热衷于研究用电脑控制汽车的技术。起初他们用电脑接入汽车诊断接口来操控车辆，而现在他们已经能通过车载无线网络或蓝牙来操控汽车。

![](../Images/2922c447a87a35c59cc229c2ad6aed69.png)

Miller 和Valasek 通过网络控制汽车，可以让降被黑的汽车加速、减速，刹车、熄火，还可以让刹车失灵。如果被黑车辆有自动驾驶功能，那么他们也可以远程控制转向。看过《速度与激情8》吗，影片中的反派利用远程控制技术，随意操控路上的汽车堵截目标……原来这不是科幻而是现实。

  

恐怖吧？不过你且放心，米勒与瓦拉塞克不是坏人，他们只是找出车载电脑系统的漏洞，然后报告给汽车制造商。当然有这本领的人可不止他们两个，美国一些大学的研究员也做过类似的实验，实际上这事很多高水平的黑客都能做到。

![](../Images/547baeeee4409e76830742cce0bb2ddf.png)

随着自动驾驶技术的发展，车辆远程控制技术也在发展。Phantom Auto是一家研发车辆远程控制的初创公司，它的创始人Magzimof认为远程驾驶控制对于自动驾驶汽车来说至关重要。

  

Magzimof说目前的自动驾驶技术并不完善，机器人可能无法识别建筑区内的环境，也无法识别交警的指挥，所以，当机器人遇到无法解决的问题时，人类可以通过远程控制暂时接管车辆。

![](../Images/2a492bd88185b387263c9156fe7df6d2.png)

远程干预除了能加强安全，还能帮助自动驾驶机器人学习。当自动驾驶每次遇到问题而停滞不前时，开发人员都可以将问题和解决方案提供机器人学习系统，并教导机器人在下一次做得更好。例如：Waymo的汽车在路口遇到红灯不敢右转，经过人类多次指导，现在它们都能自主右转了。

  

事实上，汽车远程控制的发展已经如火如荼了。Phantom Auto计划建立呼叫中心。另一家叫Starsky Robotics的公司也在研发类似的系统，他们想让卡车在路况单一的高速公路上自动驾驶，而一旦卡车驶入复杂的城市街道，人类可以通过远程控制接管它。

![](../Images/3e378f3f895e20520ee3d75c06843658.png)

大公司也不甘落后，谷歌的Waymo自动驾驶公司也有自己的远程控制中心。通用计划明年推出自动驾驶量产车型，并且也在建设一个远程控制中心，用以帮助自动驾驶车辆应对棘手情况。福特在2015年就提出了遥控汽车的计划，此外网约车巨头Uber和Lyft也有类似的规划。

  

相关立法也在刺激远程控制的发展。加州、佛州、亚利桑那州都出台了自动驾驶规则，其中有对远程控制的要求。从趋势来看，美国国会最终必定会通过相应的联邦法案，最终取代这些州立法规。

![](../Images/539e9e5c18f4bd00b4fb0cddd74134d1.png)

然而这是否也为黑客入侵汽车的历史拉开了序幕呢？是否为监视和绑架行为提供了便捷途径？这一切都起决于汽车系统的安全性。当然，如果某些政府部门采用权力来强迫车企交出远程控制代码，那也不是没有可能。

**点评：**

> 
> **无论如何，自动驾驶已经是必然趋势，将来各国政府或许会立法禁止人类驾驶。但是人类在享受便捷舒适的同时也交出了更多的自由，或许有一天你将没有任何隐私可言，或许你将面莫名其妙地被汽车绑架，这一切都需要我们去思考，去权衡……**

**值得回望的平托丑闻**

上世纪70年代初，美国福特公司看到石油危机引发进口小型车热销，随即开发了廉价小型车平托（Pinto）。工程师发现，该车型的油箱设计存在安全问题，但福特公司在成本效益分析后认为，召回己销售的车并修正油箱问题需花费1.37亿美元，而按照概率，可能致死180人，重伤180人。按照美国联邦公路交通安全管理局的计算标准，死者人均赔偿20万美元，伤者人均6.7万美元，再加上可能的车辆损毁造成的损失，显然是不召回更划算。  
       平托上市后不断发生伤亡事故。针对平托发生了117宗起诉，福特也付出了巨额惩罚性赔偿。1978年，在联邦公路交通安全局正式发出召回令前，福特被迫主动召回150万辆车，这是当时最大规模的汽车召回。1981年福特平托永久退出市场。  
       这是一起不尊重生命的丑闻，企业为了经济利益而对生命进行定价。某种程度上，Uber自动驾驶致死案，同样是由Uber公司的冷漠和监管部门的放任共同造成。  
       世卫组织的数据显示，全世界每天交通事故死亡人数超过3000人。安全恰恰是发展自动驾驶的理由之一。Uber这样的互联网企业，可能已习惯了以革命颠覆传统的快感，但发展自动驾驶是一场新技术的建设，需要科学和耐心。  
新技术的应用必然有代价。但这种代价不能以无辜的人的生命来承担，至少要在力所能及的范围内降到最小。
