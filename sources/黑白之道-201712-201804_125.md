GPing是一个带有图表的基于Python的ping实用程序。  
  

![](../Images/c5a143235bfc475f5926ea9b25b8a4dd.png)   
安装如果您使用Linux，则可以使用snap安装gping ：  
sudo snap install gping && sudo snap connect gping：network-observe然后使用gping命令照常执行。  
  
使用pip：  
使用Python 3.4和2.7创建/测试。  
pip3安装pinggraph  
在Windows，Ubuntu和OS X上测试。安装后运行：  
gping \[yourhost\]  
  
下载地址：https://github.com/orf/gping
