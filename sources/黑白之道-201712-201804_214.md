# 声称可解锁运行iOS 11的设备 包括iPhone X

还记得苹果公司和FBI之间在加利福尼亚的加密战斗中解锁两年前发生的圣贝纳迪诺大规模射击背后的一名属于恐怖分子的iPhone吗？

  

在苹果拒绝帮助联邦调查局访问锁定iPhone上的数据之后，联邦调查局最终向第三方公司支付了超过一百万美元的费用，用于解锁该射击者的iPhone 5c。

  

现在看来，由于以色列移动取证公司Cellebrite据报道已经找到了解锁市场上几乎任何iPhone的方法，包括最新的iPhone X ，联邦机构似乎不必与iPhone 解锁iPhone  

  

据《福布斯》报道，该公司据说向客户建议其能够访问运行iOS 11的设备。向执法机构宣传该公司的高级解锁和高级提取服务的营销文件指出其可以访问运行iOS 5到iOS 11的iOS设备，包括所有iPhone、iPad、iPad Pro和iPod touch型号。 一份报告称，美国国土安全部在2017年11月成功地解锁iPhone X搜索数据，这很可能是通过使用Celebrite的技术。警方取证界的一名独立消息人士称，Cellebrite告知他可以解锁iPhone 8及iPhone X。
