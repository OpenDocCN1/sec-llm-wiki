# 战死沙场的男人

![](../Images/60f5cc3e43a1ee4e1f8e8d5f794d8d9f.png)  

  

首先选择一个图片，把背景扣掉，  
  
![](../Images/ecb9239c205ae87c0b103c7de241590f.png)   
然后找个内部骨骼的图片，安装比例调整好姿势和大小，放到人物图层下面，  
  
![](../Images/c660451e8d523fd6a687f16e526993cb.png)   
然后选择人物轮廓，反向，  
  
![](../Images/b4377ce11bb3f2d6f1523488b58f1c66.png)   
然后吧骨骼多余的部分删除即可，要不然骨骼会突出去，  
  
![](../Images/8946a38ba1c8d71f1526bd4337430409.png)   
然后用撕裂类的画笔进行一个人物的撕裂感涂抹，画笔网上有很多可以下载，根据自己需要进行下载，  
  
![](../Images/be36e0c9372894f4772c815cc6b33733.png)   
然后在轮廓上加上血迹，  
  
![](../Images/e517eaa15ab484719f8dbbfb466d7db2.png)   
胳膊处也一样，  
  
![](../Images/b13c288daf50610aeace293cc38f29cf.png) 

  
然后复制一个胳膊图层，改成黑色，放到人物图层下面，骨骼上面，主要是做一个阴影效果，  
  
![](../Images/e14e69eeeb3bed8862310c526c6fcab3.png) 

  
如上图，根据衣服厚度来自定义阴影厚度，  
  
![](../Images/894b7ddae506ba698bc3b97e87f50e13.png) 

  
然后可以找个图片，或者找合适的画笔，做一个这样的效果和撕裂感，  
  
![](../Images/6448317f29f8dfed50522a132629b52c.png) 

  
然后在红色后面加上橙色来增加一个感觉，  
  
![](../Images/8cdaa775a15385d10941426587f121fe.png)   
脸部也一样，不过根据撕裂程度，我要对皮肤进行扭曲，已达到更好的效果，  
  
![](../Images/99438d87932aa67355f734b00f369963.png) 

  
完成，  
  
![](../Images/8063beb857354adf180ae19b9f33b4f4.png)   
然后增加血迹，用画笔，颜色加深，  
  
![](../Images/4d7467850e011f0a1de76c878af050f6.png)   
铠甲上颜色，新建一个图层，然后涂颜色上去，  
  
![](../Images/9c339fb28f22e63fa9e63e576564be7c.png)   
然后把图层模式改成颜色即可，  
  
![](../Images/e67dd3f91b9d536948f4ca71de24046e.png)   
  
完成
