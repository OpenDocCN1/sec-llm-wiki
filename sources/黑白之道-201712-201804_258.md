利用Fiddlerweb debugger 这款工具来进行修改数据包，从而达到突破的目的。

  

步骤：

  

注意：安装Fiddler web debugger  ，需要安装.NET环境以及.NET的SP2补丁方可运行！

  

打开Fiddler web debugger：

  

![](../Images/cfdb2f1fe529b846b3bea944c4d0f274.png)

  

打开FCKeditor的编辑器上传页面，例如http://www.xxxxxx.com/FCKeditor/editor/filemanager/browser/default/browser.html?Type=Image&Connector=http://www.system-instruments.com/FCKeditor/editor/filemanager/connectors/aspx/connector.aspx

打开Fiddler web debugger，点击设置—自动断电—选择“请求之前

  

打开编辑器的上传页面，创建文件夹，并输入你想要创建的文件名，例如：

  

（cctv.asp）

  

![](../Images/2d8002cd3823c93675852f324fb5faef.png)

  

然后打开Fiddler web debugger，选择链接—点击右侧的嗅探：

  

![](../Images/87a6eabaac312d0ef4852e0fa5e43f72.png)

  

修改currentfolder内的参数，改成你要建立的文件夹名字，如：cctv.asp

  

![](../Images/d6807be067cc21fe0a98bd169e90796c.png)

然后点击右侧的：run to completion

![](../Images/d1d0b85db9c4b1fa9093fd250f48d50f.png)

  

最后一步，点击软件设置—自动断点—禁用，就OK了！

  

![](../Images/7fec63b8959e0244e23bd225522c0645.png)

  

文件就会建立成功
