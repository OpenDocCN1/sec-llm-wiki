## xwaf  

xwaf是一个python写的waf自动绕过工具,上一个版本是bypass\_waf,xwaf相比bypass\_waf更智能,可无人干预,自动暴破waf

```

```

### Requirement

```
python3
pip3
works on linux(test on ubuntu and kali2.0,others not test)

python3安装可参考如下步骤:
    apt-get 
```
