哈喽，大家好。今天要讲的是linux的守护进程。


什么是守护进程呢？守护进程(daemon)是一类在后台运行的特殊进程，用于执行特定的系统任务。很多守护进程在系统引导的时候启动，并且一直运行直到系统关闭。另一些只在需要的时候才启动，完成任务后就自动结束。



这就类似于windows系统的中服务，每个服务都支撑着系统的某个功能



例如DNS Client这个服务，启动类型是“自动”，说明这个服务是随着操作系统的开启而自动开启的，如果禁用掉的话，那么操作系统将不会有自动获取IP的功能。而在linux系统当中，也是拥有这些功能的，可能会存在差异，名称也不一样，它们就叫做“守护进程”。


‍match‍


使用ps -ef可以查看所有进程



接下来来看一下守护进程树，如果出现下图找不到命令的情况，那就是安装系统时没有勾选相应的选项



使用yum来安装psmisc就可以了


yum install psmisc



接下来再看一下，因为是虚拟机的原因，导致进程树可能有点小，不过还是能够看出linux系统在启动过程中先后打开哪些守护进程



如果有不需要自启动的守护进程，我们也是可以关闭掉的，比如这里可以直接禁用掉防火墙的进程


systemctl disable firewalld.service



把disable换成enable便能再次开启防火墙进程



还有重新载入和重启



如何来查看守护进程是否跟随操作系统启动的呢？可以使用ntsysv这个命令来查看，如果系统提醒找不到命令就使用yum来安装一下，安装完成后输入ntsysv这个命令，就会进入下图这个界面



好，有关守护进程的内容就讲到这里，大家拜拜！在上图最上方有一行问句，“what services should be automatically started?”，意思是说哪些服务要自动启动。所以在这里面，前面标注*符号的进程，将会和操作系统一起启动，其他的将不和操作系统一起启动。使用空格键将会选择光标所在处的进程是否标注*，然后操作完成后使用tab键切换到ok来保存设置退出。
