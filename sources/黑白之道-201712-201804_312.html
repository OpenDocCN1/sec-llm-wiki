大家好，我是你们的老朋友Alex。今天教大家如何使用远程桌面连接ubuntu主机。


首先更新系统，apt-get update


安装xrdp，apt-get install xrdp


安装vnc4server，apt-get install vnc4server


安装tightvncserver ，apt-get install tightvncserver


安装xubuntu-desktop ，apt-get install xubuntu-desktop


安装顺利即可进入下面的步骤


service xrdp restart  重启xrdp服务


reboot 重启主机


打开cmd输入mstsc，输入IP之后输入账号密码即可登录！




如果出现灰屏以及鼠标不显示或者显示为X的问题


第一，  ubuntu版本较低时可以安装gnome桌面 apt-getisntall gnome；第二，


14.04远程不支持gnome版本，更换xfce步骤如下：


1.apt-get install xubuntu-desktop


2.echo xfce4-session >~/.xsession


3.vim /etc/xrdp/startwm.sh


在./etc/X11/Xsession前插入xfce4-session



4. service xrdp restart


即可！
