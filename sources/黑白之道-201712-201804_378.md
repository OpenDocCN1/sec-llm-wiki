# 初中文化黑客“四剑客” 盗走成都网站25万元

一般人印象中，网络“黑客”都是精通计算机的高学历人才。但实际上，网络世界有很多不起眼的小角色，往往才是真正的高手。15日，成都市公安局召开“向人民报告”冬季铁拳行动打击网络犯罪通气会，近期破获的一起“黑客”破坏计算机系统捞钱案，四名“主角”正是仅有初中文化的网友。

  

不久前，成都市公安局网安支队接到了报案，辖区一架网站的平台充值金额被盗刷了。经初步调查，有人在平台上进行了大量虚假充值，填写银行卡，将充值好的金额进行盗走提现。

  

那这些人是如何盗取充值平台的资金的呢？成都网安民警首先对该公司平台服务器日志进行提取和分析，对充值平台的网络协议规则进行研究，民警发现，该平台在进行系统充值时，平台没有对充值金额进行对账效验，取走资金时也无身份证、手机、银行卡认证，存在严重的系统漏洞，而对方就是利用系统漏洞，盗刷钱财，到报案时，已经被盗刷人民币25万余元。

  

经过1个多月的缜密侦查和部署，成都警方辗转山东、辽宁等地，在辽宁省辽阳市一小区内将犯罪嫌疑人邱某、梁某、陈某抓获，在逃人员闫某也在1个月后落网。

  

审讯发现，这四名“黑客”都是90后，而且都仅仅只有初中文化，但却是网络世界里少有的电脑高手。他们四人基本是自学成才，由于对计算机黑客技术的痴迷，来自不同城市的四人在网上通过一个QQ群走到了一起，四人在群里切磋研究黑客技术，并密谋利用某些网站的漏洞来捞钱，从而一步步走上了犯罪的道路。

  

在此案中，首先，由黑客技术较好的闫某利用网络工具，寻找各种充值网站的漏洞，在发现成都辖区这家网站平台充值到平台的金额没有对账效验后，将该漏洞有偿提供给了邱某，邱某组织梁某、陈某一起，利用软件工具不断在该网站上进行虚假充值、提现，共盗走人民币25万余元。

  

最终，成都警方查获该团伙使用的未实名注册手机卡50余张、收款用银行卡30余张，注册网站账号20余个。目前，四人已因涉嫌破坏计算机信息系统罪，被移送检察院审查起诉。
