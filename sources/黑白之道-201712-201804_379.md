Lalin是一个Kali专用的懒人工具包，集成了众多较新的工具以及一些基础功能，目前与Kali rolling兼容，适合新手及非深度Kali用户使用。

![](../Images/2b718834715ea87d61c4adad91c2a4f5.png)  

## 安装及使用

```
git 
```

## 工具及功能介绍

该工具近一年未更新，故一些功能不推荐使用。

下面是一些使用截图，这里只介绍一些实（能）用的，其他功能还请自行安装体验。

### 1.Update Kali

![](../Images/303767ff36a370c12419a24ba8b6d3e0.png)

1和2已过时，且会修改sources.list，如果你的kali版本比较新，那么不要使用1和2！

3：更新kali，同apt-get update

4：更新并清理kali

5和6分别为还原和备份源，备份后/etc/apt中会生成一个sources.list.backup文件，以后恢复的时候可以直接使用该文件恢复。

### 2.Virtual Machine

![](../Images/244a87f5cd4cdf4c804fe3969624a4de.png)

如果你在虚拟机里运行Kali linux，这些可能会对你有帮助。输入序号即可安装对应工具（如选择2就会安装VMware-tools）

### 3.Browsers

![](../Images/ed6e6865f84a4a65ac1cbb1348000579.png)

如果不喜欢自带的浏览器，可以在这里输入序号安装Google Chrome及其他浏览器。

### 4.WIFu

![](../Images/51fc959a4b125354e2d2ce56b510be1f.png)

这里包含了一些WIFI破解相关的工具，有些没有被Kali集成，按需安装！

### 5.Exploit-db

![](../Images/282869569cb0534e0965f8fb51507096.png)

1：更新Exploitdb

2：搜索，选择2会提示输入关键词，搜索完成会弹出新窗口显示结果

![](../Images/be2b4ca00e5be2057440236f6343dc10.png)

![](../Images/b3c8b7be5a4050f70c672c0edb4b48a9.png)

### 6.sniffing&MITM

![](../Images/b619907d4610bf0713840e2e7e2c8176.png)

这里包含了流量嗅探和中间人攻击的工具，按需安装。

### 7.Firefox security toolkit

![](../Images/4148cd931c2dbfe61ef1884493191eea.png)

这会在firefox上添加拓展，让你的firefox成为渗透利器！详情点击这里。
