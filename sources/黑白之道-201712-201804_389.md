# Linux源程序代码安装

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650445047&idx=2&sn=4807326c5acdcb34ff0e466273f6cec6&chksm=83bbf113b4cc780545cce8d4b4afc1186f594fb163f27b761f4be838a5b3d974856689a4f286&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650445047&idx=2&sn=4807326c5acdcb34ff0e466273f6cec6&chksm=83bbf113b4cc780545cce8d4b4afc1186f594fb163f27b761f4be838a5b3d974856689a4f286&scene=27#wechat_redirect)

![](../Images/bfdb8e6b5064b2f16eba66e913995d58.png)

  

在linux下，除了yum和rpm两种安装程序的方式外，还有一种使用源代码安装程序的方法，这种方法较麻烦，但却支持更广泛的安装程序，下面就让我带大家看一下吧！

  

1、首先确定系统中是否已经安装了编译环境

  

![](../Images/296385b33eb30a20fede1ecee4991057.png)

  

已经安装就不用管了，没有安装的话就使用yum安装一下gcc就好了

  

  

2、获取源代码安装包文件的下载地址，使用windows系统浏览要下载的安装包地址，确定地址后在linux系统中使用wget获取安装包文件。如果linux系统中没有安装wget命令的话，再使用yum安装一下wget就好了，安装好wget之后，这里用nginx来做例子，使用wget来获取nginx的安装包文件

  

![](../Images/7b947391264cf7e7cb91883592474489.png)

  

3、下载完成后，使用tar命令解压安装包

  

![](../Images/eb3f6a42dc78a222604596b2d960966c.png)

  

4、解压完成后，进入nginx-1.13.8目录

  

![](../Images/6a0572dde94390451008c22833bc461f.png)

  

5、安装直接来运行configure这个文件就好了

  

sh configure 或者 ./configure

  

![](../Images/43af2a0c1fcf3d27903916d0e038e907.png)

  

6、完成后可以看到最后报错，如下图所示，如果出现下列错误时，说明安装这个软件需要依赖库，而现在缺少的是PCRE library这个依赖库

  

![](../Images/cdb0a617eb144f2b5319a2fd48ca077e.png)

  

7、依然是使用yum的方式来安装pcre

  

![](../Images/2f10fa6d9e66be86977c3968717d4b35.png)

  

这里不光要安装pcre，还要安装pcre的开发库，因为我安装完pcre后运行过一次configure，结果还是提示缺少pcre的依赖库，然后使用yum search pcre的方式，就能查看到还需要开发库

  

![](../Images/bc8370c7c63306418843a8ef2157e597.png)

  

![](../Images/d3cc027d27399ec94f85c33523314182.png)

  

8、再来执行一遍sh configure看看是否还报错，这次不缺少pcre了，换成了zlib

  

![](../Images/4da0d2b750641cfb53fc2030d47b84da.png)

  

![](../Images/83b4452613b4c9796dd0888cff736e4c.png)

  

9、同样的方法，使用yum search zlib查看，然后安装

  

![](../Images/3d02dd553c8c0b3b4de350d43496bfc3.png)

  

![](../Images/96bbc30a7e321a59b291d7947e6ad586.png)

  

10、再来运行configure，没有再报错。红框里的信息是说明nginx的每个文件安装到哪个目录中

  

![](../Images/ac5abd72828849dac989a42dc83b4481.png)

  

11、到目前为止，只是在测试系统环境是否可以安装nginx，也就是说刚才运行configure，只是来检查系统环境是否满足安装nginx的要求，接下来就是安装过程了，很简单，只是两个命令，第一步，使用make来执行编译，如下图，有很多信息，过程中不需要任何操作，只需要等待就可以了

  

![](../Images/8efa53f14bc59f701d1fc28d2e98386c.png)

  

12、直接执行make install，很快，一瞬间就完事了

  

![](../Images/d57125aa5434ee8431ac5f7417883146.png)

  

13、接下来就是验证了，很简单，看刚才运行完configure后的目录路径下，是否有nginx

  

![](../Images/9728a60f4a29a090ef3168551f31c65d.png)

  

运行一下看看

  

![](../Images/598d7869d2f7168140670eb7ac75673b.png)

  

OK，使用源代码安装编译就是这么个过程，大家拜拜。
