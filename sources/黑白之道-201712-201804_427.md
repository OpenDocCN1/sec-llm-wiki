# 自建网速测试

大家好，我是Alex。今天教大家建立一个网速测试客户端网站。

  

源码地址：https://wo.ci/download/speedtest\_lite\_c2s\_by\_jonvi\_fixed.zip

  

原版地址：https://github.com/adolfintel/speedtest

  

服务器版本：ubuntu 16.04；网站容器：nginx1.11.13；php：php7.0.25

  

首先安装nginx

  

wget -chttps://nginx.org/download/nginx-1.11.13.tar.gz

tar -zxvf nginx-1.11.13.tar.gz

d nginx-1.11.13/

./configure --add-module=/root/ngx\_brotli--add-module=/root/nginx-ct-1.3.2 --with-openssl=/root/openssl-OpenSSL\_1\_0\_2h--with-http\_v2\_module --with-http\_ssl\_module --with-http\_gzip\_static\_module

  

安装php7.0

  

apt-get install php7.0-cli php7.0-cgiphp7.0-fpm

  

![](../Images/3669163f28aa376528e11e06bec1b34b.png)

  

我把源码解压到了/var/www/html目录，所以我们在nginx中这样设置，我还开启了HTTPS

  

![](../Images/3fa33cc829ad15c13cdcb9d6a7702361.png)

  

![](../Images/4124a6e5e3bb64d7830d243f778189a9.png)

  

![](../Images/b09cbe6953fe5fd4f71261977ef3a5fd.png)

  

最后保存配置然后以此配置文件启动nginx

/usr/local/nginx/sbin/nginx -c/usr/local/nginx/conf/nginx.conf  

  

访问主页就能看到网速测试界面

  

![](../Images/eaba4ac255a3ed192e34d7575d845aff.png)

  

但是遇到了一个问题，客户端获取不到IP

  

![](../Images/a77ca89cff230704b15af77d5df9f1be.png)

  

这下可就着急了…然后我访问getIP.php，发现502了！！！！！！

  

![](../Images/ad94fa43fed83367e145be07c1a0c954.png)

  

我们去查看nginx日志

  

![](../Images/51d5926ad1ef40a5ec26c6db12cdfed7.png)

  

发现php7.0-fpm.sock连接访问存在权限问题，那么问题就好解决了！

  

查看文件/etc/php/7.0/fpm/pool.d/www.conf

  

![](../Images/12972738d4fbbfdf200935d229f6e429.png)

  

取消这些前面的注释后…发现还是不行….我们查看nginx的用户

  

![](../Images/e05ee73ca74b880549e37972938a00a9.png)

  

哦哦………我们修改nginx.conf，增加user www-data www-data

  

![](../Images/13b13fa1ff5cac711b8934b7221ed827.png)

  

最后网站就完美运行啦~~

  

![](../Images/919303307ccdaa01a78b07432c2fadaa.png)
