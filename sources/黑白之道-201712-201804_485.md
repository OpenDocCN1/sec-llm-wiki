# 黑客“拿破仑”承认攻击优步、美团等软件

一名居住在房车公园的25岁英国小伙格兰特西上周对17家网站进行网络攻击，并在暗网上出售被盗的用户信息。

  

事后格兰特西，承认自己对优步、美团、T Mobile、Just Eat、Ladbrokes、Asda, Argos、Nectar、Sainsburys、AO.com、Coral Betting、Vitality、RS Feva Class Association 2017、the British Cardiovascular Society, Mighty Deals Limited、Truly Experiences Ltd和M R Porter等软件进行了网络渗透。

  

调查人员说，格兰特西使用名叫“哨兵MBA”的账户进行对网站上有效用户进行暴力破解。然后，格兰特西获取了被盗账户的用户个人信息并在暗网出售。

  

警方说，格兰特西建立了一个暗网商店，在暗网上用比特币出售被盗账号，格兰特西在暗网名叫“拿破仑”除了卖被盗账号还卖大麻等毒品。

  

当警察搜查他的家时发现了£25000（33300美元）的现金和大量比特币，还发现了大量在暗网出售的毒品。

  

当局于9月30日逮捕格兰特西，他在上星期认罪后等待判决。
