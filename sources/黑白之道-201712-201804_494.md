# 淄博：“抓肉鸡”牟利 黑客非法控制他人电脑获刑

说到黑客，大家脑海中第一印象就是电影中能随时进入别人的电脑的计算机高手，其实黑客就在咱们身边不得不防，最近，淄博周村区一名黑客就因为非法操控别人电脑牟利，最终被法院判刑。

  

被告人亓某是一个电脑爱好者，从小就喜欢网络技术，他通过种植木马和扫描工具来远程控制对方的计算机信息系统，也就是黑客俗称的“抓肉鸡”。淄博周村区人民法院刑事审判庭法官肖洪告诉记者：“所谓的“抓肉鸡”就是被远程控制的计算机 被告人亓某交代，他是用扫描工具，扫描对方的服务器，当扫到管理权限比较弱的服务器时，就能够发现对方的IP地址，管理员账号，以及密码等信息，这样这台计算机就完全的被亓某给掌握了，亓某可以肆意的登录这台服务器。”

  

亓某很快发现，当黑客还能捞外快，可以出售被登录的服务器信息来获取利益，于是，他就将控制的这些肉鸡信息控制权出售给网络上的买家，获取利益，截止案发，被亓某控制了信息的计算机系统一共有75台。记者了解到，依据刑法规定以及司法解释的规定，对亓某以非法控制计算机信息系统罪，判处其有期徒刑2年，缓刑3年，并处罚金1万元，被告人亓某当庭认罪伏判。

  

据亓某交代，当他人电脑处于低保护状态时，他利用工具可以很容易就扫描到对方的电脑信息，让这台电脑受他控制，一般这个操作流程仅仅需要几分钟的时间。淄博周村区人民法院刑事审判庭法官肖洪：“在此建议市民，首先安装好杀毒软件及安全辅助性软件，第二一定要安装好正版的操作系统，第三，不要随便进入网站，不要从小的论坛，小的电子市场下载应用，不浏览一些钓鱼网站，不要随意点击网页中、短信中的网站链接。防止被黑客进入远程操控，盗走我们的数据或破坏我们的资料。”
