红芯浏览器成多家政府部门标配？国资委、中车否认

#   

# 对于“标配”一说，澎湃新闻记者联系到相关政府部门和企业，则给出了不同的回应。

#   

# 国务院国资委一位内部人士告诉澎湃新闻记者，国资委的个人电脑中没有统一安装红芯浏览器，现在都是根据个人爱好自行选择浏览器，也没有通知要求安装此软件。据其了解，国务院国资委并未购买红芯公司的服务。

#   

# 中车集团内部人士对澎湃新闻记者表示，中车集团层面使用的电脑并未安装红芯浏览器，下属子公司层面则不确认。

#   

# 红芯公司官网曾披露，2017年，该公司曾与中国中车集团旗下广州电力机车有限公司签约。对此，上述中车集团人士表示，这只是一家拥有几百人的小公司，不足以代表整个中车集团。

#   

# 海信集团官方也向澎湃新闻记者表示，海信不是红芯浏览器的用户。

#   

# **目前，红芯浏览器已在官网停止下载。**

#   

# 红芯联合创始人高婧在8月16日下午对中新网回应称，安装包里之所以有Chrome文件，因为本来就是基于开源的Chrome架构。但红芯依然是自主可控的国产内核，因为有智能感知渲染等其他方面的创新。至于安装包为何下线，是因为技术部启动应急预案，开始自查。

#   

# 科大讯飞、森马服饰否认投资红芯浏览器

#   

# 8月16日盘后，浙江森马服饰股份有限公司（森马服饰，002563）投资者热线工作人员在接受澎湃新闻记者采访时表示，该公司未投资涉嫌“抄袭谷歌”的红芯浏览器。

#   

# 同一天，另一家传言中的投资方科大讯飞（002230）董秘办一名工作人员，也对澎湃新闻记者否认了该公司投资了红芯浏览器，“并不是我们上市公司投资的。”

#   

# 目前，晨兴创投、达晨创投、IDG尚未对此公开置评。

#   

# 8月15日，红芯宣布完成2.5亿元C轮系列战略融资。网络上发布的新闻稿称，这轮融资投资方主要来源于红芯的客户——大型上市公司及政府客户。同时，晨兴资本、达晨创投、IDG资本继续跟进投资。

#   

# 红芯浏览器宣称自己打破美国垄断、自主研发出国产浏览器内核，不过，8月16日，有质疑称，红芯浏览器使用的是谷歌的Chrome浏览器内核，是以谷歌浏览器Chrome内核换皮打造成“自主可控的国产浏览器”。

#   

# 此后，红芯浏览器的投资方开始引发各方关注。

#   

# 红芯浏览器官网显示，其运营公司主体为美通云动（北京）科技有限公司。工商资料显示，美通云动（北京）科技有限公司 在2018年6月更名为了红芯时代（北京）科技有限公司。

#   

# 虽然森马服饰和科大讯飞均称未投资红芯浏览器，不过，澎湃新闻记者查询发现，和两家公司有关联公司对红芯作出了投资。

#   

# 企查查数据显示，红芯时代（北京）科技有限公司的注册资本为1694.13万元，森马集团认缴出资额为16.91万元，安徽讯飞产业投资有限责任公司认缴出资额为117.79万元。

#   

# 工商资料显示，安徽讯飞产业投资有限责任公司持有红芯时代（北京）科技有限公司6.95%股份。安徽讯飞产业投资有限公司的大股东为科大讯飞董事长刘庆峰，持股比例为38.55%。

#   

# 谈及这家安徽讯飞，科大讯飞董秘办人士称，“不是我们上市公司下属公司。”

#   

# 科大讯飞股份有限公司成立于1999年，聚焦智能语音与人工智能产业。2008年在深圳证券交易所挂牌上市。

#   

# 而森马服饰的控股股东森马集团有限公司也是红芯时代（北京）科技有限公司的投资方，持股比例为1%。

#   

# 对此，森马服饰方面的工作人员回复澎湃新闻记者称，上市公司并未投资红芯浏览器，高管的投资不需要向上市公司报备及公告，可以查询红芯的工商资料。

#   

# 森马服饰2011年3月11日登陆了深交所中小板，主营休闲服饰、儿童服饰，实际控制人为邱光和。邱光和持有森马集团40%股份。

#   

# 红芯资本的注册资本为1694.13万元，森马集团认缴出资额为16.91万元，安徽讯飞产业投资有限责任公司认缴出资额为117.79万元。
