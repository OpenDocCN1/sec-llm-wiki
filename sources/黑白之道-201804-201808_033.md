# 融资2.5亿的国产浏览器之光，竟然只是谷歌浏览器换了层皮？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650448960&idx=3&sn=d331aaa0b6e52e6ad328ac6142201e64&chksm=83bbc1a4b4cc48b21ec2131800b39f02c894fc4d36a955fa3b9e69463eb2a23e04432ddd7efb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650448960&idx=3&sn=d331aaa0b6e52e6ad328ac6142201e64&chksm=83bbc1a4b4cc48b21ec2131800b39f02c894fc4d36a955fa3b9e69463eb2a23e04432ddd7efb&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

放眼世界上四大主流浏览器内核（微软IE浏览器内核Trident、谷歌Chrome浏览器内核Blink、苹果Safari内核Webkit、火狐浏览器内核Gecko）皆为国外所有。  

  

![](../Images/d13bd48b1a068244a79983db51f1c2b8.png)

  

但就在昨日，号称自主研发浏览器核心产品的“红芯”公司宣布完成2.5亿C轮系列融资，该公司称研发出具有我国自主知识产权的浏览器核心技术，推出世界第五颗也是唯一一颗属于中国人自己的浏览器内核——**红芯Redcore**。

  

![](../Images/a5011d13484c082eca2709d9da4d78cf.png)

  

“**自主研发**”、“**国产浏览器内核**”、“**2.5亿融资**”，听起来就很牛逼，我们还是先去官网看看一探究竟吧

  

![](../Images/07a1ca7383fbaab1998a1f2d86e3f280.png)

  

官网的首页的图片。可以说非常有气势了，接下来是介绍，介绍中表示：**红芯内核 - 打破美国垄断，中国首个自主创新智能浏览器内核。**

  

![](../Images/6edf17f48033905086a98d326bc87ede.png)

![](../Images/6ba278a78a1d3ed414a5438622d38ad4.png)

  

拥有智能的认证引擎、渲染引擎、管控引擎，而且还有强大的“国密通讯协议”，支持统一管控、远程控制......按照红芯的说法，这实力确实秒杀Chrome、火狐等浏览器。

  

这样的浏览器，相信谁看到都想尝试一下，但是**红芯官网却已删除下载链接**。不过没关系，早就有网友下载验证了一番，我们一起来看看：

  

网友**@Touko** 把红芯浏览器 Windows 版的exe文件多次解压后，出现了广为人知的 Chrome，并且是**Chrome 49v**。

  

![](../Images/c69ba7e93ddaf44edd35cdf9fbe76552.png)

  

打开红芯浏览器的安装目录，文件结构基本上和Chrome一模一样，甚至在redcore的「属性」中，原始文件名显示**chrome.exe**

  

![](../Images/21e4c6f7f550c3242dd174ca39ae97a5.png)

**安装目录**  

  

![](../Images/76073bf691605113fac74bfc3d5a08ac.png)

**主程目录**  

  

而且安装好的程序里连Chrome的logo都没删干净！！！

  

![](../Images/acf0db680a3a49286c7b6244803cbfd2.png)

截图来自：@泷涯

  

接着打开这个浏览器，随便输一个地址，无法访问的提示，也和Chrome一模一样，就连没有联网的小游戏也一样

  

![](../Images/f74b27097a87ca34d32e77d2c894c7a1.png)

截图来自：小声比比

  

到这里相信你也认为：红芯浏览器就是一个披着所谓“国产”“自主”外皮的Chrome……

  

  

**“红芯公司”及创始人**

  

接下来，我们再去查一下红芯浏览器背后的这家公司以及公司的创始人，“红芯”公司它最开始做的是HTML5开发和移动适配，2018 年5月初，「云适配」召开媒体会，宣布品牌战略升级为红芯。

  

![](../Images/1268ce65da01974a6191b4aafdb5ec16.png)

  

据官方数据显示，红芯业务收入已连续2年实现同比近3倍增长，业务已覆盖高端制造、能源、交通基建、金融、政府军工等多行业。

  

**以下为红芯融资记录：**

  

> 2016年11月获达晨创投领投的B+轮1亿元人民币融资；
> 
> 2015年6月获IDG、晨兴资本1000万美元B轮融资；
> 
> 2013年12月获天创资本、虎童基金1000万人民币A轮融资；
> 
> 2013年11月获科大讯飞300万人民币天使轮融资

  

![](../Images/c0744a7bfef02a82c47059730fcc5aa7.png)

  

接下来是该公司创始人陈本峰，百度百科上是这样介绍的：国家“千人计划”特聘专家、国际云安全联盟CSA专家委员、企业级HTML5产业联盟主席、HTML5国际标准制定者之一。

  

![](../Images/d9c0d565493aeedc51d44510d78a5958.png)
