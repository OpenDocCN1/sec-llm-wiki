说到wordpress漏洞扫描就不得不提wpscan，他们维护了一个针对wp的漏洞库，是一个十分强大的扫描器，该工具与其相似，但是又有一个强大的漏洞，就是可以针对本地的wp插件的php代码静态扫描

  

## **Installation**

```

$ git clone https://github.com/m4ll0k/WPSeku.git wpseku
$ cd wpseku
$ pip3 install -r requirements.txt
$ python3 wpseku.py
Usage
```

`python3 wpseku.py --url https://www.xxxxxxx.com --verbose`
