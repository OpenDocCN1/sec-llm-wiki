# “黑客”入侵邮箱，外籍骗子骗外籍客户28万多元

6月15日，花都狮岭某公司事主王某报案称，被网络黑客侵入其业务邮箱，并被人冒充该公司诈骗外国客户货款4.4万多美元（折合人民币28万多元）。

  

接报案后，花都区公安分局打击电信网络新型专业队多管齐下，迅速查清涉案资金流向，并锁定涉案账户为湖南省邵阳市某工艺品有限公司的对公账户。专业队立即冻结了该涉案资金，并奔赴邵阳市进行深入摸排。

  

办案民警介绍，嫌疑人黑入该公司邮箱时，根据公司邮件往来，就摸清楚了该公司与外国客户的交易时间，便掐准时间黑入邮箱，冒用其名义向外国客户发邮件，称公司账户变更，要求外国客户以后把货款打到嫌疑人提供的新账户上。

  

变更收款账户后，嫌疑人便在湖南省邵阳市某工艺品有限公司下了一个价值4万美元的订单，并让外国客户将“货款”直接打入邵阳公司账户。

  

调查中，警方也发现，邵阳某工艺品公司只是嫌疑人用来“套现”的工具。待外国客户“货款”到账后，嫌疑人便向邵阳公司要求退部分货品，订单额从28万多元变为1000元，并要求该公司将其中4万美元余款退回，按当天汇率换成人民币，转至一个中国银行账户。

  

专业队民警连夜加班梳理信息，最终锁定嫌疑人\*\*\*\*某（女，22岁，广东湛江人），并通过分析，发现其外籍男朋友JOAO也有重大作案嫌疑。

  

7月上旬，专业队民警兵分两路，在天河区天源路地铁站出口将嫌疑人\*\*\*\*某抓获，在白云区东平街某公寓将嫌疑人JOAO抓捕归案。

  

目前，专业队已成功冻结涉案资金20多万元。
