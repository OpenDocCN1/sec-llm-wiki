iCloudBrutter是一个简单的python脚本（基于python3.0）主要用于执行AppleID的暴力攻击。

  

安装方法：

```
$ git clone https://github.com/m4ll0k/iCloudBrutter.git
$ cd iCloudBrutter
$ pip3 install requests,urllib3,socks
$ python3 icloud.py
```
