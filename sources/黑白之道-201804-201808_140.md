**工具介绍**

  

Envizon是一个网络资产可视化工具，其通过nmap自动扫描网络中的主机进行可视化的展示，让用户能更好的观察网络结构

  

核心功能如下：

  

*   Scan networks with predefined or custom nmap queries
    
*   Order clients with preconfigured or custom groups
    
*   Search through all attributes of clients and create complex linked queries
    
*   Get an overview of your targets during pentests with predefined security labels
    
*   Save and reuse your most used nmap scans
    
*   Collaborate with your team on the project in realtime
    
*   Export selected clients in a text file to connect other tools fast
    
      
    

**使用方法**

其支持通过docker部署

For the lazy ones

```

wget https://raw.githubusercontent.com/evait-security/envizon/master/
```

##### Running from local git checkout

```


git clone https://github.com/evait-security/envizoncd envizon/
```

  

安装完成之后需要设置密码

  

![](../Images/e410668a6ea4c93fc3fbe58808796a51.png)

  

然后进行网络设置

  

![](../Images/2fd32aa94ba783285f6d1e56a56c2a56.png)

添加之后就会进行扫描，请耐心等待

![](../Images/024a60717b388e17c765ab755396e8a4.png)

  

扫描完成之后将以如下方式展示

  

![](../Images/2ef24e1f8619c4a62d8239b7857a48b3.png)

  

支持强大搜索模式

  

例如：

 hostname contains 'win' AND mac address starts with '0E:5C' OR has port 21 and 22 open.
