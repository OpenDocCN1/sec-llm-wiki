**工具介绍**

  

adhrit是一款开源的android apk反向和分析工具，可以帮助安全研究人员和ctf爱好者。

  

**使用方法**

  

1.  下载并解压或者clone( git clone https://github.com/abhi-r3v0/Adhrit.git ).
    
2.  将应用程序放置在工具目录中。
    
3.  打开一个终端并cd进入该目录。
    
4.  运行 python installer.py 进行安装
    
5.  运行 python adhrit.py -h 查看帮助
    
      
    
    Example: python adhrit.py -a my\_app.apk
