**工具介绍**

  

arpağ：土耳其神话中的神奇字的意思。

  

Arpag通过扫描目标的端口的服务，然后去msf中寻找是否存在合适的漏洞进行自动化exploit

  

**使用方法**

  

> git clone https://github.com/anilbaranyelken/arpag.git
> 
> cd arpag
> 
> pip install -r requests
