从burpsuitev1.7.31版本起，大家应该都可以用到正版授权的burpsuite了 ^\_^ 。 在之前的文章里面我介绍过Windows下面如何正确的注册及使用Burpsuitev1.7.31，今天试了一下在macos下面使用，发现还是有些小问题的。

  

目前burpsuite已经更新到Burpsuitev1.7.32，请大家移步至此处下载：

  

BurpSuitePro v1.7.32及注册机下载：

  

https://www.waitalone.cn/burpsuite-v1732.html

  

1、请下载最新版的JDK和JRE并安装，下载链接如下：

  

Java JDK 8u161

  

http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html

  

Java JRE 8u161

  

http://www.oracle.com/technetwork/java/javase/downloads/jre8-downloads-2133155.html

  

2、安装完jdk&jre后，可以双击打开burp-loader-keygen.jar, 然后点击run运行burpsuite注册。

  

3、剩余步骤同Windows下面的正版授权过程，请参考BurpSuitePro v1.7.32及注册机下载：https://www.waitalone.cn/burpsuite-v1732.html

  

4、且记，一定要点击那个run才行哦。。

  

将下来将介绍今天的正文，如何在MacOS下将burpsuite制作为app，然后点击运行？

  

### **MacOS下将burpsuite制作为APP**

  

1、首先完成上面的正版授权过程，确保每次使用run运行后burpsuite为正版授权。

  

2、打开automator.app开始制作过程，可以使用cmd+空格键搜索。

  

![](../Images/3fdab7b8056f471a30524b77bc23448e.png)

  

3、选择应用程序，制作一个应用程序。

  

![](../Images/788cb8f97b8de182605bc10f0cd152d8.png)

  

4、选择运行shell脚本，输入下面的命令：

  

![](../Images/08789e2be0541469c801eeaa923b7686.png)

  

![](../Images/b0ee5d98783ca85750ba612bbf7cdf0a.png)

  

5、保存为burpsuite.app即可完成制作。

  

![](../Images/f5e2b75904c662a981e9b849ff8e7094.png)

  

6、为burpsuite.app添加一个图标后拖到应用程序中即可。

  

google一个图片，双击打开，复制，然后点击你制作的包，显示简介，然后粘贴即可。

  

7、以后就可以单击打开了，打开以后就是正版注册的。

  

![](../Images/26d29a4c1b2020b4b8565ed89e7ed393.png)
