# RootHelper - 帮助Linux系统的权限升级

Roothelper将通过获取大量枚举和利用建议脚本来帮助在受到攻击的Linux系统上进行特权升级。最新版本下载五个脚本。两个枚举shellcripts，一个信息收集shellcript和两个漏洞利用建议者，一个用perl编写，另一个用python编写。

  

Priv-Esc脚本：LINENUM列举了系统配置的Shellscript。

  

UNIX的privesc检查Shellscript枚举系统配置并运行一些特权升级检查。

  

Firmwalker通过搜索已安装的固件文件系统收集有用的信息。对于诸如SSL和Web服务器相关文件，配置文件，密码，常见二进制文件等等。

  

linuxprivchecker一个python实现，用于向系统泄露特定的漏洞

  

Linux\_Exploit\_Suggester一个perl脚本，它和上面提到的一样。

  

用法：要使用该脚本，您需要根据您在该特定系统上可用的内容，在使用git或wget等实用程序泄露的系统上获取该脚本。从那里你需要使用chmod x roothelper.sh使其可执行。然后运行它，它会显示可用选项和关于选项的信息性消息。为了清楚起见，我也在下面发布了它。

  

'帮助'选项显示此信息性消息。'Download'选项提取相关文件并将它们放在/ tmp /目录中。“下载并解压缩”选项下载所有文件并提取压缩文件的内容 档案到各自的子目录，请注意; 如果'mkdir'命令不可用，但操作将不会成功，并且“下载” 选项应该用来代替'清理'选项删除所有下载的文件，'退出'退出roothelper。
