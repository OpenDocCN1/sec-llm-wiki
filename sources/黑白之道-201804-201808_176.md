# 教你搭建个人/企业私有云盘，再不担心资源丢失

环境用的是centos7.2 64位

首先你的有个VPS或者ecs服务器（没有的话本地弄个虚拟机练手）

cd/home/www(这个可以用mkdir/home/www创建)    

  

![](../Images/545311b40117822bb50dcdb7fb41947c.png) 

  

使用mkdir命令在www文件夹下建一个seafile文件夹。

mkdir seafile

  

![](../Images/c107ad9cab5037b989d83bd23e8774fd.png)

  

使用cd命令转到新建的seafile文件夹。

cd seafile

  

![](../Images/13fb42c80dd5ed3544bf1074ce5b92f0.png)   

  

使用wget 资源地址命令将seafile软件包下载到新建的seafile文件夹中。

  

wget http://seafile-downloads.oss-cn-shanghai.aliyuncs.com/seafile-server\_6.2.5\_x86-64.tar.gz

  

![](../Images/89cc43ce2a3f66d4f23719849183eada.png)   

  

![](../Images/897aa60cdc52159ddc2c6fee96039f8b.png)   

  

使用tar-xzvf命令解压下载好的资源包。

tar-xzvf seafile-server\_6.2.5\_x86-64.tar.gz

上面的命令结构是tar-xzvf文件名.tar.gz根据下载的软件名子改变即可。

  

![](../Images/26472407a94967f8b13619439d25ba42.png)   

按照官方要求，要在seafile目录里再建一个installed文件夹。

  

mkdir installed

  

![](../Images/0de106efc438edf0ed19606b1bd4bdc4.png)   

  

然后把下载的安装包移到installed文件夹下（这步其实没什么卵用，就是为了养成好习惯而已）

  

mv seafile-server\_6.2.5\_x86-64.tar.gz installed/

  

![](../Images/975588ea38c7b302f90b33e6b04b1213.png)   

安装依赖组件

安装前的准备工作

安装Seafile服务器之前，请确认已安装以下软件

MariaDB或者MySQL服务器(MariaDB是MySQL的分支)

python 2.7(从Seafile 5.1开始，python版本最低要求为2.7）python-setuptools        python-imaging        python-mysqldb        python-ldap        python-urllib3        python-memcache(或者python-memcached)

如果没装，就执行下面命令安装MariaDB

yum install mariadb-server-y

  

![](../Images/311aeca88f40956da2fec3b5ec58491d.png)   

设置mysql密码

systemctl start mariadb

mysql\_secure\_installation

  

![](../Images/6260706a625c10557c849ab6d752c89a.png)   

  

再执行下面的命令安装python。

  

yum install python-setuptools python-imaging python-ldap MySQL-python python-memcached python-urllib3-y

  

![](../Images/259764eba921c6d1d50dd83327a3bf0b.png)

  

安装srafile

执行cd命令转到解压出来的seafile文件夹。

cd seafile-server-6.2.5/

  

![](../Images/cf3fbb33acd943a18836e9aa8964bbaa.png)   

  

运行安装脚本并回答预设问题

./setup-seafile-mysql.sh

到达下图这里按回车键继续：

  

![](../Images/8f9e8cad6220a02b3e4c96a31988153d.png)   

设置服务器名称，输入seafile，并回车

  

![](../Images/3dbd3250eef758187d02ff8bda2577f1.png)   

  

输入域名或者ip

  

![](../Images/3cd6c32e244004ed0ba099fa02f9b3c8.png)   

  

接下来就是设置存放你的宝贝资源的文件目录了，这里要选择大的磁盘路径哦，小编这里www目录挂载的磁盘是最大的，所要当初下载文件的时候都是往www目录里下载。因此程序默认的文件就在www下。回车！

  

![](../Images/ba98c22b382a6beccc8fc72109afd620.png)   

  

接下来是设置端口号，小编这里就默认了，直接回车，如果你的服务器8082端口被占用，就改别的吧。回车。

  

![](../Images/1ff5c5fe9745b0aaf254bbd6bf0981db.png)   

  

下面是新建数据库或者选择已经存在的数据库，我们是新安装的，当然是新建，果断选1，回车

  

![](../Images/faa929305264e31acce31d7154530a4e.png)   

  

再下面是填写数据库服务器地址，我这个就是本机，默认即可。回车

  

![](../Images/db94ef26c71fcdf854e45bb10d950e8c.png)   

  

下面是填写数据库端口，一般都是3306，默认，回车。

  

![](../Images/a1c2766b45e511db81e8adfbc605c28c.png)   

  

下面是输入数据库用户名为root的密码，这个在安装lnmp的时候是你自己设置的。这里注意，linux输入密码是不显示的，你直接输入即可，输入完成按回车。

  

![](../Images/4dcd622d631af9e6976507e0d007b13a.png)   

下面为seafile创建mysql用户，输入用户名，默认即可。回车

  

![](../Images/edbcddd53327b77759e13ea04ac2ebc7.png)

  

file:///C:\\Users\\admin\\AppData\\Local\\Temp\\ksohtml\\wps9428.tmp.jpg

这里设置一个密码，回车

  

![](../Images/569b15704722bd30152f6e4a91bebfa2.png)   

  

设置ccnet服务的数据库名（步骤真多啊，我有点后悔写这个教程了。。。。），默认，回车

  

![](../Images/3d891678dec827838c85de4da7c80020.png)

  

file:///C:\\Users\\admin\\AppData\\Local\\Temp\\ksohtml\\wps942A.tmp.jpg

  

给seafile-server起个数据库名，默认，回车

  

![](../Images/14a0075cd5e85824b20a119f8d08da58.png)   

  

给seahub设置数据库名……，默认，回车！！！！！！！！

  

终于到了确认配置信息的步骤了/(ㄒoㄒ)/~~，按回车。

  

![](../Images/6c7fbc41698be6064a2983175fd3e86d.png)   

安装成功的画面！

  

![](../Images/ef30a828d44815f66dd9b7b1cd8a99b5.png)   

启动seafile服务./seafile.sh start

  

![](../Images/8f75389134fc2d41dd435c32569f7e44.png)   

启动seahub，并设置后台登陆邮箱

./seahub.sh start

  

![](../Images/1350fe822e4a9015a9cb17581da3a7dc.png)   

输入登录密码\=》确认密码=》启动成功！

  

![](../Images/aab12e6f46df3b8f63c6aaa725f89650.png)   

登录网页版网盘，并配置。

在浏览器中输入：你的ip地址：端口号

就会重定向到登陆界面

  

![](../Images/c1dcea07e454b3f0e2e24f31439fa762.png)
