# 高级Windows服务管理器 - 分析Windows服务的工具

高级Windows服务管理器是分析Windows服务的软件。它提供独特的功能，如‍恶意/ Rootkit服务检测，自动威胁分析，服务过滤机制，集成的在线病毒/恶意软件扫描，基于颜色的威胁表示以及基于HTML / XML的服务报告。

  

它使用  启发式分析和其他反rootkit技术（如Bypass Hook方法）来检测恶意服务。而且，集成的“ 在线扫描”功能允许您通过使用VirusTotal，ProcessLibrary和Google来验证服务的恶意特性。

  

它适用于几乎所有的Windows系统（XP到10）。

  

如何使用先进的WINDOWS服务管理器

  

首先，将高级Windows Service Manager下载并安装到您的计算机上（下载链接位于本文结尾处）。然后以管理员权限运行该程序（以管理员身份运行）。你会看到一个如下所示的窗口。

  
![](../Images/e488735cb226ebd641031d3ecef286bd.png)

  

如果您想以分类方式查看服务，请转到窗口的右侧，然后从下拉菜单中选择您的选项，然后单击“ 刷新 ”按钮。

  

例如，如果您想查看所有正在运行的非系统服务，只需进入窗口的右侧，然后从下拉菜单中选择“ 仅显示正在运行的非系统服务 ”，然后单击“ 刷新 ”按钮。

  

要使用VirusTotal扫描服务，只需选择服务并单击“ 在线扫描 ”按钮。它会向你显示一个像这样的VirusTotal分析页面：

  
![](../Images/d99af467f88d3004a641038b59c69f57.png)

  

如果您想查看有关特定服务的更多详细信息，请选择该服务，然后单击“ 属性 ”按钮。这会显示属性窗口：

  
![](../Images/f7fa6abf7893e8ff913a0c41cb39ca9e.png) 

  

如果要将显示的服务列表导出到磁盘，请单击“ 导出... ”按钮，然后用一个很酷的名称保存该文件（因为为什么不？）。

  

如果右键单击服务，还可以执行其他操作 - 可以停止并禁用服务，在VirusTotal，Google和ProcessLibraray上搜索服务，查看文件属性以及访问文件位置
