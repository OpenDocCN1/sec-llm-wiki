PenTBox - 一个开源的安全套件

PenTBox是一个开源的安全套件，其中包含许多面向网络和系统的安全性和稳定性测试的工具。它是用Ruby编写的，面向GNU / Linux系统，但与Windows，MacOS以及Ruby工作的每个其他系统兼容（Ruby可执行文件在应用程序内部提供）。


它包含以下工具：


加密工具


Base64编码器和解码器 - 它允许您编码或解码Base64字符串。


多摘要 - 此工具可以将文本转换为MD5，SHA1，SHA256，SHA384，SHA512和RIPEMD-160字符串。


哈希密码破解 - 该工具可以破解MD5，SHA1，SHA256，SHA384，SHA512，RIPEMD-160哈希。它提供了3种不同的破解方法：Numbers Bruteforce，Dictionary attack和Dictionary-Bruteforce混合攻击。


安全密码生成器 - 它可以从单词或短语创建高度安全的复杂密码。


网络工具


Net DoS测试器 - 它允许您执行DoS（拒绝服务）攻击。此工具支持欺骗性SYN Flood本机，欺骗性SYN Flood hping3和TCP Flood攻击。它还为DoS提供了以下漏洞：


[其他/ http] 3Com SuperStack交换机DoS


[其他/ http] 3Com OfficeConnect路由器DoS


[windows / ftp] Windows 7 IIS7.5 FTPSVC UNAUTH'D DoS


[windows / ftp] Solar FTP Server 2.1 DoS


[windows / pptp] MS02-063 PPTP格式错误的控制数据内核DoS


[windows / smb] Windows Vista / 7 SMB2.0协议请求DoS BSOD。


TCP端口扫描器 - 这是一个简单的扫描器，您可以使用它来发现打开的端口。


蜜罐 - 它允许你创建一个蜜罐。如果你不知道蜜罐是什么，那么让我告诉你，“ 蜜罐是一种检测，偏转或以某种方式抵制未经授权使用信息系统的尝试的机制。通常蜜罐由数据组成例如，在一个网站中），这似乎是该网站的合法组成部分，但实际上是被隔离和监控的，似乎包含了信息或对攻击者有价值的资源，然后这些信息被阻止。警察诱骗罪犯，进行秘密监视，并最终惩罚罪犯 - 维基百科。 “ 记住： 为了创建蜜罐，你必须以root权限运行PentBox。


模糊器  - 此工具允许您测试缓冲区溢出的应用程序。


DNS和主机收集 - 它允许您查找主机和DNS信息。


MAC地址定位 - 它允许您通过路由器XSS查找坐在网络浏览器后面的用户的*精确* GPS坐标。


Web


HTTP目录Bruteforce - 该程序允许您发现并暴力破解 Web服务器中存在的目录。


HTTP公共文件Bruteforce - 此程序允许您发现并强制存在于Web服务器中的公共文件。
