# V3n0M - 一款开源漏洞扫描器

V3n0M是一款免费的开源扫描器。从Baltazar的扫描仪演变而来，它已经采用了几项可改进功能和可用性的新功能。  

  

该程序用于查找和执行各种漏洞。它使用dorks清理网页并组织它找到的URL。

  
![](../Images/e095134486d3f7d8bc1b37460797c719.png)   
这对于执行：  

*   Cloudflare解析器\[Cloudbuster\]
    
*   LFI-> RCE和XSS扫描\[LFI-> RCE＆XSS\]
    
*   SQL注入漏洞扫描程序\[SQLi\]
    
*   非常大的D0rk目标列表
    
*   AdminPage查找
    
*   毒素\[Vulnerable FTPs Scanner\]
    
*   DNS BruteForcer
    
*   Python 3.6基于Asyncio的扫描  
    

  

darkd0rker的正式采用严重记录，更新，扩展和改进  

*   全新的，只是在箱子外面！
    
*   最有效的Cloudflare解析器与易于使用的界面。
    
*   非常快速的“毒素”易受攻击的IP扫描器可以扫描潜在的数百万IP用于已知易受攻击的服务。
    
*   一次最多最强大的d0rker在线搜索，14k d0rks搜索引擎。
    
*   免费并打开/ src /
    
*   跨平台的基于Python的工具包
    
*   版本425于2018年2月18日发布
    
*   根据GPLv3获得许可  
    

  

测试： ArchLinux 4.14，Ubuntu，Debian，Kali，MacOS，BlackArch，Manjaro / ArchLinux ARM Ed。Android的Termux。

  

请注意Ubuntu用户：请确保已安装 - > sudo apt-get install python3-bs4和apt-get install python3-setuptools 否则，您可能会收到语法错误，从而阻止程序运行。

  

注意Kali用户：请确保你已经安装了 - > apt-get install python3-dev apt-get install python-dev

  

**安装注意：**

*   克隆存储库：
    
*   $ git clone https://github.com/v3n0m-Scanner/V3n0M-Scanner.git
    
*   然后进入：
    
*   $ cd V3n0M-Scanner /
    
*   然后安装它：
    
*   $ python3 setup.py install --user
    

  

下载地址：https://github.com/v3n0m-Scanner/V3n0M-Scanner/archive/master.zip
