# 95后“黑客”更改商家支付宝账号 三天盗走75万元

两网络“黑客”利用技术手段，更改他人支付宝账号，3天时间，盗窃全国各地10余家商户营业款75万元。民警顺线发现一辆蓝色宝马车，揪出两人。16日，涉嫌盗窃他人钱财的网络黑客戚某、王某被江汉警方从乐山押解返汉。

  

4月30日上午8时，万松园派出所接到某连锁酒店胡老板报警，该酒店40余万营业款被人在网上盗走。胡老板介绍说：他在汉开了多家连锁酒店，各店每天支付宝收款均打入同一账户。但4月28日，全天支付宝收得的近20万元却不翼而飞。郁闷之下，他找到网站客服查询，才发现绑定的支付宝账号被人恶意更改，营业款进入他人账号。胡老板当即将原来账号冻结。4月30日，胡老板20余万营业款再次以同样方式被盗，他随即报案。

  

江汉警方经过10余天摸排，发现四川乐山夹江县戚某、王某有作案嫌疑。戚某21岁，是个计算机迷，自学获取计算4级证书。王某17岁，现在某网吧做游戏代练。

  

5月13日，8名民警前往乐山实施抓捕，赶到两人住宿酒店后，发现他们刚办理退房手续离开。民警调取酒店周边监控录像，获知戚某驾驶一辆蓝色宝马车驶进一小区。次日下午4时，民警敲开戚家房门，将正在睡梦中的戚某抓获。随后，王某落网。

  

警方介绍，戚某与王某是夹江县同村人，戚某是名网络高手，他设法攻破网站，利用服务器漏洞获取客服后台管理员的权限，在网上购买账号，而后恶意更改商户绑定的对应支付宝账号，并拉拢王某入伙作案。

  

两人通过网站后台，瞄准全国各地交易流量排名前列商户，盗窃10家商业营业款75万余元，警方已冻结追回57万余元。另18万元，王某分得2万元，戚某网上购得虚拟货币16万元。案件在进一步深挖审理中。
