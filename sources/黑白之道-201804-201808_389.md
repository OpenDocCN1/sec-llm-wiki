Nipe是一个使Tor网络成为你的默认网关的Perl脚本。

  

此脚本可让您直接将所有流量从计算机传送到Tor网络，通过该网络您可以匿名浏览Internet，而无需担心被跟踪或追溯。  
  
**安装：**

$ git clone https://github.com/GouveaHeitor/nipe$ cd nipe$ cpan install Switch JSON LWP :: UserAgent$ perl nipe.pl安装  
开始：$ perl nipe.pl start  
停止：$ perl nipe.pl stop  
状态：$ perl nipe.pl status  
重新开始：$ perl nipe.pl restart  
  
下载地址：https://github.com/GouveaHeitor/nipe
