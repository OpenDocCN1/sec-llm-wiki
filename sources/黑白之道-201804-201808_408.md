今天学到了一个新的Word执行代码的方式，也是不需要启用宏的，所以分享给大家一波。操作也挺简单的。

  

首先新建一个word文档，然后插入域：

  

![](../Images/afd284d3e383549bc4cba084102c0079.png)

  

选择 = (Formula)

  

![](../Images/816bd57e04343d8dbe87d51c8c34d1c8.png)

  

右键，切换域代码

  

![](../Images/d4345780738220aa6cb0f367b22cbc53.png)

  

代码处修改为：

  

{DDEAUTO c:\\\\windows\\\\system32\\\\cmd.exe "/k calc.exe"  }

  

![](../Images/9d58d03dce764db38e324badc268dee7.png)

  

之后，右键更新域，再把文档改成docx格式即可。最终效果如下：

  

![](../Images/7601111b9518827d23282ac9c80d6f90.png)

  

比较鸡肋的是点是以后才会执行。

  

除了使用DDEAUTO，使用DDE也是可以的，具体如下：

  

{DDE "c:\\\\windows\\\\system32\\\\cmd.exe" "/c notepad" }

  

需要注意的是，使用DDE不会自动执行，需要对文档进行修改，将文档重命名为rar，打开以后修改 word/settings.xml,添加

  

  

<w:updateFields w:val="true"/>

  

使用DDE效果如下：

  

![](../Images/d0502ea04ed97b75ebdb7e66e60d2f9d.png)

  

个人感觉使用DDE效果更好点。
