# 频繁接到推销电话骚扰，正常生活受到影响；担心父母长辈被电信诈骗，生命财产受到威胁；害怕家中老人被电话推销，购买三无保健品危害健康等等，这些担忧的背后都离不开公民信息泄漏这一问题。

近年来，随着信息网络技术的不断发展，公民个人信息的安全性问题日益成为一个全社会关注的问题。侵犯公民个人信息犯罪呈高发多发态势，社会危害日益突出。  

  

![](../Images/7ead60d127367a16c562a55c9568e0df.png "1525679022443560.jpg")

近日，清江浦分局在相关部门的大力支持下，耗时一年，辗转全国多地，终于破获一起通过黑客技术非法入侵快递公司后台，获取客户信息后转手卖给他人谋取暴利案件。此案中，清江浦警方共抓获犯罪嫌疑人13名，均采取刑事强制措施，其中首批移送起诉3名嫌疑人均被判处有期徒刑3年以上，其他在逃人员正在追捕中，缴获非法获取的公民信息近1亿条。

案情回顾

![](../Images/d1827ba2faa610ffb029e1fd2a6bfa4d.png)

  

  

**案情简要**

  

2017年5月10日，淮安市公安局清江浦分局接到当地某快递公司报警称，其辖区内一家从事工艺品销售的客户信息被外部人员盗取。清江浦分局情报技术中心经前期研判，发现该公司的计算机信息系统数据有一万余组于2017年3、4月份被外部人员非法获取。经过调查，民警发现该速运公司一长期合作的大客户曾接到多家下级商家反映，近期总是受到推销电话骚扰，而如此集中的投诉现象表明，信息泄露的源头正是承接这些商家快递业务的快递公司。民警还发现，不仅是该快递的网站后台被非法入侵，多个快递公司不同程度的出现后台被非法入侵，公民信息的数据被非法获取的现象。由于此案涉及群众切身利益，清江浦分局高度领导重视，要求立即成立专案组开展侦查。2017年7月3日公安部正式挂牌督办此案。

**一、综合研判，精准锁定嫌疑人身份**

  

经研判，民警发现该快递公司有一组电脑后台地址异常，并立即赶赴地点开展工作，经过大量排查走访，民警发现了一个以湖北人杨某为首的犯罪团伙。

**二、果断出击，攻坚克难成功抓捕**

  

在将线索锁定在湖北孝感后，专案组民警立刻赶到湖北孝感某小区开展工作，却发现最初锁定的地点只是一间普通的民居，犯罪嫌疑人不在这里。后经蹲守、摸排，民警发现小区楼道三层一户人家昼伏夜出，形迹可疑。经分析，民警怀疑该户人家通过蹭网器实现“借”用他人的网络进行上网，进而锁定嫌疑人藏匿地点。抓捕组迅速开展行动，当场抓获非法获取、买卖公民个人信息犯罪嫌疑人4人。现场收缴重要物证：蹭网器一套，银行卡10张、笔记本电脑2部、手机6部、U盘8个，公民信息数据近100G，为案件成功侦破奠定了基础。

![](../Images/509902dbe9c382bbda2efcbfbfa2b7d8.png)

![](../Images/629da1435381eb81dd87d03f1dd899c2.png)

  

**三、深挖线索，除恶务尽穷追不舍**

  

抓获嫌疑人后，侦查民警立即对杨某、胡某、熊某、陈某进行突击审查。审查中发现杨某等人主要通过使用黑客手段对快递公司的后台进行登录，获取快递信息的数据，再通过QQ群、微信等网络聊天工具对非法获取的公民信息数据进行出售，非法获利。

![](../Images/92ec269c587b255a0d0d11179f18e625.png)![](../Images/6d99400c553211f3026c1697cc9bb25d.png "1525680095960160.jpg")![](../Images/cd78fd71b8543d6e5ae1959a5eb18598.png "1525680128591758.jpg")

在主要嫌疑人杨某等人到案后，办案人员发现大量买家通过购买公民信息的数据，推销各类三无产品非法获利，行为非常恶劣，侵害了公民的权利，也给社会治安非常不良的影响。

在对该案侦办的同时，专案组民警利用近一个月的时间，整理出了快递公司后台登录的漏洞，并总结出相应的改善意见，及时对各个快递公司进行通报，提升了各快递公司的网络安全级别，对保护公民的个人信息起到了重要作用。
