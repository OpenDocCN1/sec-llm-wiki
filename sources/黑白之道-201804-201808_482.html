CookieScanner是一个基于Python的工具，用于检查多个站点中的Cookie标志。


要求：

requests > = 2.8.1

BeautifulSoup> = 4.2.1


安装：

pip3 install --upgrade -r requirements.txt


用法：

用法：cookiescanner.py [选项] 

例如：./cookiescanner.py -i ips.txt


选项：

  -h，--help显示此帮助信息并退出

  -i INPUT，--input = INPUT

                        带有web服务器列表的文件输入

  -u URL，--url = URL URL

  -f格式， - 格式=格式
                        输出格式（json，xml，csv，normal，grepable）
        -G GOOGLE，--google = GOOGLE

                        按域搜索谷歌

  --nocolor禁用颜色（用于正常格式输出）

  - 我， - 信息更多信息


 性能：

-t TIMEOUT响应超时

-d DELAY请求之间的延迟
