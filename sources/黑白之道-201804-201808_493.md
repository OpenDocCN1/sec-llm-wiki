# 黑客转移阵地 比特币勒索病毒首次侵入腾讯云

近期，腾讯云安全团队监测到云上Linux服务器开始出现比特币勒索事件。用户在访问自身Linux服务器的时候会出现相关勒索信息，并且发现服务器中除必要系统文件外的一些其他文件均被粗暴删除。

  

　　如果没有及时对数据文件进行备份，被删除的数据文件可能无法找回，只能请第三方数据恢复公司帮忙进行恢复。

![](../Images/70c2bc4172bd11483851ad3203c90368.png)  

  

　　在此之前，黑客一直是在Windows环境下通过勒索软件来进行文件加密勒索的行为。影响最大的一次是发生在2017年5月12日，在全球近百个国家共同爆发了规模浩大的WannaCry比特币勒索病毒。而这次是首次在云上发现Linux服务器遭比特币勒索。

  

　　从Windows到云上，黑客为何始终乐于用比特币（加密货币）进行勒索？很明显，去中心化、匿名性是其看中的主要特性，这使得他们的非法行为不受地域限制，难以找到实际参与者，而且还易于携带、容易变现。

  

　　目前有一种质疑声很高，那就是比特币等加密货币容易变成犯罪份子的洗钱工具。多国领导人也都曾在公开场合表示过对这一现象的担忧。这也是为什么各国政府在制定加密货币相关法律法规时，都显得十分谨慎。

  

　　一方面，各国都不想把这一有可能成为未来发展趋势的新事物完全扼杀，另一方面又得对国内的普通民众的安全与稳定负责。介于两者，国家监管的力度、界限等都较难拿捏，这也就注定了各国政府目前态度不明的现状。
