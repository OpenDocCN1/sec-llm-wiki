# 美英称俄黑客监视西方公司和政府 俄罗斯：莫须有

在俄罗斯政府与西方国家的关系因外交危机而降至低谷之时，美国和英国情报机构联合发布预警称，俄罗斯网络攻击者正在瞄准关键的互联网基础设施，以监视西方公司和政府。

  

据《华尔街日报》4月18日报道，美国国土安全部、联邦调查局和英国国家网络安全中心罕见地发表联合预警称，俄罗斯政府支持的黑客已经渗透到全球范围的设备和软件程序，从路由器到交换机到防火墙，旨在窃取公司机密和从事间谍活动。他们还警告说，俄罗斯的隐蔽行动旨在为未来对西方目标发动网络攻击奠定基础。这些机构称，俄罗斯的上述活动威胁到了他们各自的安全和经济福祉。

  

另据美国媒体4月18日报道，美英两国说，黑客在全球的广泛活动开始于2015年，可能被扩展到开始发动攻击性袭击。美英官员说，攻击影响了范围广泛的组织，包括互联网供应商、私人企业、关键基础建设供应商。他们没有指出任何受害者，或提供攻击产生的影响的任何细节。

  

  

联合声明警告称：“俄罗斯国家资助的相关组织正用受损的路由器进行欺骗性的‘中间人攻击’来支持间谍、夺取知识产权、维护对受害网络不断的侵入和可能为未来的攻击行动建立基础。”报道称，此前，两国只谈了“俄罗斯发起”的袭击，关于俄罗斯犯罪和国家活动的字句被模糊，但这次他们转而指责克里姆林宫。

  

对于来自英美的联合预警，俄罗斯否认了相关指责。克里姆林宫发言人德米特里·佩斯科夫说，“我们不知道这些新的指控是基于什么。”他在记者会上告诉记者，美英没有展示任何证据，以“莫须有”和“不合理”为由驳回了指控。

  

白宫网络安全协调人乔伊斯则说：“当我们看到恶意网络行动，不管是来自克里姆林宫还是其他国家的恶意组织，我们都会反击。”
