# 增强型缓解体验工具包（EMET）

增强型缓解体验工具包（EMET）是一种免费的安全工具，可以预测攻击者在破坏计算机时可能使用的最常见操作和技术，并通过转移，终止，阻止和使这些操作和技术无效来帮助您保护计算机。

  

它甚至可以保护您免受新的和未发现的威胁。

  

这并不意味着EMET就是保护您的计算机免受黑客攻击所需的一切。EMET只是一个额外的安全层。因此，请不要删除您的反恶意软件和防火墙程序。

  

**EMET的好处：**

  

帮助提高针对攻击者的标准： EMET有助于防御新的和未发现的威胁，甚至在通过安全更新或反恶意软件正式解决之前。它包括12种安全缓解措施，可以补充其他防御深度安全措施，例如Windows Defender和防病毒软件。EMET使用默认保护配置文件进行安装，这些配置文件是包含常见Microsoft和第三方应用程序的预配置设置的XML文件。

  

适用于企业：企业IT专业人员可以通过Microsoft System Center Configuration Manager轻松部署EMET，并在Windows Active Directory中应用组策略以符合企业帐户，用户和角色策略。管理员可以自定义和配置EMET部署，并通过哪种缓解技术确定要保护的应用程序。即使对于无法轻易重写的企业遗留软件，或者在源代码不可用的情况下逐步淘汰软件，EMET也会提供缓解保护。EMET中的报告功能通过名为EMET Agent的组件提供，该组件允许企业为审计目的创建日志和通知。

  

有助于在各种情况下进行保护： EMET与家庭和企业中最常用的第三方应用程序兼容，从生产力软件到音乐播放器。它适用于家庭和企业中使用的一系列客户端和服务器操作系统。当用户浏览Internet上的安全HTTPS站点或登录到流行的社交媒体站点时，EMET可以通过根据一组用户定义的规则验证安全套接字层（SSL）证书来帮助进一步保护。

  

最新版本的EMET（v 5.5）支持Windows 10，Windows 7，Windows 8.1，Windows Server 2008，Windows Server 2012，Windows Server 2012 R2和Windows Vista。而且，它需要.NET Framework 4.5。
