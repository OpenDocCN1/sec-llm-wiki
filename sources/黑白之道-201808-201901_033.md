HconSTF（Hcon安全测试框架）是一个开源的半自动安全评估工具集，可以执行各种任务，如Web渗透测试，漏洞利用开发，恶意软件分析和开源智能（Cyber?? Spying＆Doxing）。

  

整个框架使用不同的Web技术客户端作为其开发基础平台，并进一步定制它以满足安全评估需求。

  

HconSTF有两种主要口味：Fire base和Aqua base。

  

消防基地：它建立在Mozilla的技术基础之上，  

  

*   壁虎
    
*   XUL亚军
    
*   大量的附加组件
    
*   内置的Web调试工具
    
*   用户界面自由
    
*   完全黑客友好  
    

  

Aqua基地：

  

*   WebKit的
    
*   铬
    
*   Google Chrome附加组件
    
*   最简单的用户界面
    
*   Fire base的强大替代品  
    

  

基于两个不同Web客户端的两个版本为用户提供了更多选择，还提供了基本级别具有不同设计的不同工具集。

  

HconSTF的推荐系统要求：

  

操作系统：  

  

Microsoft Windows XP SP2或更高版本，Microsoft Windows Vista，Microsoft Windows 7，Microsoft，Windows 8和8.1，所有主要的Linux发行版，包括Kali，Backtrack，Backbox。  

  

硬件：

  

CPU： 1GHz x86和x64架构

RAM：最低1 GB

硬盘空间： 150 MB

  

下载地址:http://www.hcon.in/downloads.html
