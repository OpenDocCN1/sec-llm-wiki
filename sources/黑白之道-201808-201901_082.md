# 20个堪称神器的Linux命令行软件

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650451109&idx=1&sn=6e0c8e52faf40d339415c8f72f5cad1d&chksm=83bbc941b4cc40572de0e33d3ed8e5e3f4e2d6c943999eebe4b02dcfd40598fe96ec56a7dcf4&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650451109&idx=1&sn=6e0c8e52faf40d339415c8f72f5cad1d&chksm=83bbc941b4cc40572de0e33d3ed8e5e3f4e2d6c943999eebe4b02dcfd40598fe96ec56a7dcf4&scene=27#wechat_redirect)

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

1.ag：比grep、ack更快的递归搜索文件内容。  

  

![](../Images/e099c06ae9c43e6dde4765c9fc26dea9.png)

2.tig：字符模式下交互查看git项目，可以替代git命令。

  

![](../Images/4797ded016468c4c18824aefff2b2e4c.png)

  

3.mycli：mysql客户端，支持语法高亮和命令补全，效果类似ipython，可以替代mysql命令。

  

![](../Images/04f9d7ea1e4dd90373e652a5df995021.png)

  

4.jq: json文件处理以及格式化显示，支持高亮，可以替换python -m json.tool。

  

![](../Images/114dc1427753de0b727ba12124ebb910.png)

  

5.shellcheck：shell脚本静态检查工具，能够识别语法错误以及不规范的写法。

  

![](../Images/f8fa094901dbe25621efb70fc87a475c.png)

  

6.yapf：Google开发的python代码格式规范化工具，支持pep8以及Google代码风格。

  

7.mosh：基于UDP的终端连接，可以替代ssh，连接更稳定，即使IP变了，也能自动重连。

  

8.fzf：命令行下模糊搜索工具，能够交互式智能搜索并选取文件或者内容，配合终端ctrl-r历史命令搜索简直完美。

  

![](../Images/3a2da5673271c548bb902910ee18ffae.png)  

9.PathPicker(fpp):在命令行输出中自动识别目录和文件，支持交互式，配合git非常有用。

  

运行以下命令：

```
git diff HEAD~8 --stat | fpp
```

![](../Images/5be8d61fdcec678889408216e2f4757b.png)

  

10.htop: 提供更美观、更方便的进程监控工具，替代top命令。

  

![](../Images/d8446dc99d08986408a13a766813d336.png)

  

11.axel：多线程下载工具，下载文件时可以替代curl、wget。

  

```
axel -n 20 http://centos.ustc.edu.cn/centos/7/isos/x86\_64/CentOS-7-x86\_64-Minimal-1511.iso
```

![](../Images/da6636a0f06f9dc7088126b8b9938271.png)

  

12.sz/rz：交互式文件传输，在多重跳板机下传输文件非常好用，不用一级一级传输。

  

13.cloc：代码统计工具，能够统计代码的空行数、注释行、编程语言。

  

![](../Images/4259c3bcd9cf31847a1c381e39b6f56a.png)

  

14.ccache：高速C/C++编译缓存工具，反复编译内核非常有用。使用起来也非常方便：

  

```
gcc foo.c
```

改成:

```
ccache gcc foo.c
```

  

15.tmux：终端复用工具，替代screen、nohup。

  

![](../Images/6752cf4897a96c505efe1fd261b0893a.png)

  

16.neovim: 替代vim。

  

17.script/scriptreplay: 终端会话录制。

  

```
script -t 2>time.txt session.typescript # 录制开始# your commandsexit # 录制结束
```

回放:

```
scriptreplay -t time.txt session.typescript
```

  

18.you-get: 非常强大的媒体下载工具，支持youtube、google+、优酷、芒果TV、腾讯视频、秒拍等视频下载。

  

还有mac专有的pbcopy/pbpaste：

  

把命令行输出拷贝到系统粘贴板：

```
cat test.sh| pbcopy
```

把系统粘贴板内容拷到终端:

```
pbpaste
```

  

mac下的say命令支持多种语言(英语、普通话、粤语)文本朗读，支持各种销魂恐怖的语气。跑这个命令感受下，小心被吓着了：

  

```
for i in \`say -v '?' | cut -d ' ' -f 1\`; do echo $i && say -v "$i" 'Hello World';done
```

  

19.thefuck：用途是每次命令行打错了以后，打一句fuck就会自动更正命令。比如apt-get打成了aptget。fuck以后自动变成apt-get。但还是没加sudo。再fuck，成功！

![](../Images/c104dfb05db89c179f8b93e97226b038.png)

又比如git branch打成了git brnch。fuck！更正成git branch。

![](../Images/f4873b96ca8e80d1ae607ea19eb77ca6.png)

又比如python打成了puthon。fuck！一秒变python。

![](../Images/fa53a7ad0401e779f6943ad00e165f03.png)

而且关键是每次打命令和内心os完全一致，有种人机合一的快感。fuck！
