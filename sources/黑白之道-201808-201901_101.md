FruityWiFi是一种用于审核无线网络的开源工具。它允许您通过直接使用Web界面或向其发送消息来部署高级攻击。

  

最初创建应用程序是为了与Raspberry-Pi一起使用，但它可以安装在任何基于Debian的系统上。  
  

![](../Images/0bb163f6fd14b4943369083542f0c469.png)

  

最新版本的FruityWiFi（v2.0）有很多升级版本。新的接口，新模块，Realtek芯片组支持，移动宽带（3G / 4G）支持，新的控制面板等。

  

![](../Images/1319e8ae9ff8425db25439b519b7682e.png)

  

  

安装 x86 / x64版本：

*   您需要安装Debian（或基于）（或Live CD版本）才能使用此脚本。
    
*   下载FruityWifi。
    
*   解压缩文件并运行install-FruityWifi.sh（此脚本将安装所有依赖项和设置）
    
*   完成。  
    

转到http：// localhost：8000（对于http）  
转到https：// localhost：8443（对于https）  
用户： admin  
传递： 管理员   
  
Kali Linux版：  
FruityWifi现在是Kali Linux存储库的一部分。  

*   apt-get install fruitywifi
    
*   /etc/init.d/fruitywifi start
    
*   /etc/init.d/php5-fpm start  
    

转到http：// localhost：8000（对于http）  
  
转到https：// localhost：8443（对于https）  
  
用户： admin   
pass： admin  
  
安装FruityWiFi将安装所有模块。如果你只想安装一些模块，你可以先安装fruitywifi-core然后再安装每个模块，例如fruitywifi-module-dnsspoof。  
  
ARM版（Raspberry Pi）：

*   您需要Raspbian，Pwnpi或Kali Linux版本才能使用此脚本。
    
*   下载FruityWifi。
    
*   解压缩文件并运行install-FruityWifi.sh（此脚本将安装所有依赖项和设置）
    
*   完成。  
    

转到http：// localhost：8000（对于http）  
  
转到https：// localhost：8443（对于https）  
  
用户： admin   
pass： admin
