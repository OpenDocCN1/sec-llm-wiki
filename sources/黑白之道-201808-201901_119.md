2.5 使用Item Pipeline

  

Item Pipeline为项目管道，当Item生产后，他会自动被送到ItemPipeline进行处理：

  

我们常用ItemPipeline来做如下操作：

清理HTML数据

验证抓取数据，检查抓取字段

查重并丢弃重复内容

将爬取结果保存到数据库里。

 执行如下命令来启用数据爬取

  

```

```

  

 将结果保存到json、csv、xml、pickle、marshal中

  

```
scrapy crawl fang -o fangs.json
```

```
scrapy crawl fang -o fangs.csv
```

```
scrapy crawl fang -o fangs.xml
```

```
scrapy crawl fang -o fangs.pickle
```

```
scrapy crawl fang -o fangs.marshal
```
