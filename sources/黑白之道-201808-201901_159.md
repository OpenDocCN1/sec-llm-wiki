# 可恶！男子4个月出售千万条个人信息获利5万

近日，磐安警方破获一起侵犯公民个人信息案，抓获犯罪嫌疑人8名，查获各类公民个人信息100余万条。

  

今年7月份，磐安县公安局接到群众反映，多名考生接到某教育培训机构的推销电话，这些考生的信息疑似遭到泄漏。

  

得知该情况后，磐安县公安局网警大队立即开展侦查，发现确实有人在网上倒卖相关公民个人信息，且数额巨大。

  

磐安县公安局随即成立专案组，全力侦办此案。

  

通过一系列的前期侦查，民警成功锁定了提供公民个人信息的犯罪嫌疑人谈某，并于7月20日在云南省西双版纳景洪市将其抓获。

  

经查，犯罪嫌疑人谈某在2018年4月至7月期间，通过QQ在网上出售公民个人信息，共计1000余万条，非法获利5万余元。

  

![](../Images/9141debdb590791303c9805034e3066a.png)

  

随后，在金华市公安局网警支队的大力支持下，磐安公安先后在浙江诸暨、河北石家庄等地相继抓获徐某、刘某、李某等3名犯罪嫌疑人，当场查扣电脑、手机、U盘等物品若干，缴获公民个人信息上百万条。

  

据悉，谈某2017年曾因侵犯公民个人信息罪被判处有期徒刑1年3个月，刚出狱没多久，“手头有点紧”的谈某又开始重操旧业。

  

谈某添加了多个QQ群，并在群里不定期发布售卖信息，将买来或交换得来的公民个人信息以每份几十到几百元不等的价格，销售给教育培训机构等组织或个人。

  

谈某贩卖的信息包含名字、电话号码、身份证号码、详细地址等数据，涵盖了建造师、会计师、造价师、医师等考生的个人信息，每个数据包少则几千条，多则上百万条，根据数量、年份等制定售卖价格。

  

经营教育培训机构的刘某等人在网上看到谈某的广告后，向其购买了个人信息，并通过电话、短信等方式“精准”骚扰受害人，让人不厌其烦。

  

经过近4个多月的努力，磐安警方陆续抓获数个谈某的下家。

  

![](../Images/d4cdffd2cb377a73f29f0a54dc4e9152.png)

  

目前，谈某等8名犯罪嫌疑人因涉嫌侵犯公民个人信息罪被采取刑事强制措施，案件在进一步侦查中。
