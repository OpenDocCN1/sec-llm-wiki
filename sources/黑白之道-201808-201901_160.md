# Firefox 新增预警功能，自动提醒用户网站有过数据泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650450752&idx=2&sn=8eeb1c9266c9708f414711103d01a7db&chksm=83bbcea4b4cc47b205a93be5bd2dc6c8d1c9c7eccede7bd9c7d5452a1d3cb549be9ed178ad54&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650450752&idx=2&sn=8eeb1c9266c9708f414711103d01a7db&chksm=83bbcea4b4cc47b205a93be5bd2dc6c8d1c9c7eccede7bd9c7d5452a1d3cb549be9ed178ad54&scene=27#wechat_redirect)

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

Mozilla 近日宣布 Firefox Quantum 浏览器新增了一项新的安全功能，在用户访问以前存在数据泄露的网站时会自动显示来自 Firefox Monitor 的警告。 该功能旨在提醒用户可能存在的问题，并建议他们检查自己的电子邮件，看看是否有遭到泄露。

  

![](../Images/3b259071ff02db59b4737e7dd323354f.png)

  

当出现警报时，用户可单击 Check Firefox Monitor 按钮转到 Firefox Monitor 站点，或单击 Dismiss 按钮关闭警报，也可以单击向下箭头选择 “never show Firefox Monitor alerts ” 以禁用此功能。

  

根据 Mozilla 的说法，该预警功能并非侵入性的，每个站点最多只出现一次，而且仅针对过去12个月内有出现过数据泄露事件的网站。

  

![](../Images/f5f7900ceae9e3cbbd2ddfb30cb23e17.png)

  

Firefox Monitor 是一项免费的隐私数据泄露通知服务。要使用它，只需访问 Firefox Monitor 网站并提交电子邮件地址即可。它通过和 “Have I Been Pwned” 中超过31亿个已确认出现安全问题的庞大数据库进行比对，在发现问题时及时提醒用户。
