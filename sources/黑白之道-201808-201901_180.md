路由器密码Kracker是一个免费程序，允许您破解您的路由器密码。

  

您还可以使用此工具从您的Internet调制解调器或受HTTP BASIC / DIGEST身份验证保护的网站恢复密码。

  

注意： 此工具仅适用于受HTTP BASIC / DIGEST身份验证保护的设备。

  

路由器密码Kracker使用字典攻击来恢复密码。 

  

如果您对字典攻击一无所知，请允许我简单介绍一下：

  

字典攻击是一种通过系统地输入字典中的每个单词作为密码来打入受密码保护的计算机的方法。

  

如果您需要更多详细信息，请参阅此维基百科文章：  字典攻击

  

默认情况下，Router Password Kracker附带适用于路由器的示例字典文件。如果您想要更大更好的字典文件，可以从以下位置免费获取：
