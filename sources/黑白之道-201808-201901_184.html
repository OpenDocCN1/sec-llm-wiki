fwknop - 单包授权

fwknop代表“ FireWall KNock OPerator ”，并实现称为单包授权（SPA）的授权方案。这种授权方法基于默认丢弃数据包过滤器（fwknop在Linux上支持iptables和firewalld，在FreeBSD和Mac OS X上支持ipfw，在OpenBSD上支持PF）和libpcap。


SPA仅需要单个加密分组以便传送各种信息，包括通过防火墙策略的期望访问和/或在目标系统上执行的完整命令。 


通过使用防火墙维护“默认丢弃”站点，fwknop的主要应用是保护OpenSSH等服务，增加一层安全性，以便更好地利用漏洞（0天和未修补的代码）难。 


部署了fwknop后，任何使用nmap查找SSHD的人都无法告诉它正在侦听 - 如果他们想要针对SSHD运行密码破解程序，或者即使他们有0天的攻击，也没有区别。 


授权服务器通过libcap被动地嗅探SPA数据包，因此没有传统意义上的连接“服务器”。只有在从fwknop客户端监视经过身份验证，正确解密和未重放的数据包之后才能访问受保护的服务（请参阅以下网络图; SSH会话只能在嗅探SPA数据包后进行）： 


特征：


  • 在Linux上的 iptables 和firewalld防火墙，* BSD和Mac OS X上的ipfw防火墙以及OpenBSD上的PF上实现单个数据包授权。

  • fwknop 客户端运行在Linux，Mac OS X，* BSD和Windows（在Cygwin下）。此处还有一个单独的Windows UI，其中包含源代码。此外，iPhone和Android手机都有一个客户端端口。

  • 支持Rijndael和GnuPG方法用于SPA数据包的加密/解密。

  • 支持Rijndael和GnuPG的HMAC认证加密。操作顺序是加密 - 然后验证以避免各种密码分析问题。

  • 通过有效传入SPA数据包的SHA-256摘要比较来检测和阻止重播攻击。还支持SHA-1和MD5，但SHA-256是默认值。

  • 通过libpcap从导线上被动地嗅探SPA包。所述 fwknop 服务器还可以从由一个单独的以太网嗅探器写入到（例如用“文件获取分组数据的tcpdump -w <文件>”），或者从 iptables的ULOG PCAP 作家。

  • fwknop 是在GPL（v2）下发布的开源软件，可以通过 github 在这里查看/克隆完整的源代码。

  • 对于iptables的防火墙，接受补充规则 fwknop 从自定义添加和删除（后配置的超时）的iptables 链，以便 fwknop 不与任何现有的干扰 iptables的政策。

  • 支持经过身份验证的SPA通信的入站NAT连接（仅限 iptables 防火墙）。这意味着可以将 fwknop 配置为创建DNAT规则，以便您可以从开放Internet访问RFC 1918 IP地址上的内部系统上运行的服务（如SSH）。

  • 多个用户通过fwknop支持的服务器，并且可以为每个用户分配通过/ etc /自己的对称或非对称加密密钥 fwknop /access.conf文件。

  • 通过http://www.cipherdyne.org/cgi-bin/myip自动解析外部IP地址（当从NAT设备后面运行 fwknop 客户端时，这很有用）。由于外部IP地址在此模式下在每个SPA数据包内进行加密，因此中间人（MITM）会攻击内联设备拦截 SPA 数据包并仅从其他IP转发以获取访问权限受到阻碍。

  • SPA数据包的目标端口以及通过iptables NAT功能进行后续连接的端口支持端口随机化。后者适用于转发到内部服务的连接以及授予运行fwknopd的系统上的本地套接字的访问权限。

  • 与Tor集成。请注意，由于Tor使用TCP进行传输，因此通过Tor网络发送SPA数据包要求每个SPA数据包都通过已建立的TCP连接发送，因此从技术上讲，这会打破“单数据包授权”的“单一”方面。但是，Tor提供的匿名优势在某些部署中很容易超过这个考虑因素。

  • 实现SPA通信的版本化协议，因此很容易扩展协议以提供新的SPA消息类型，同时保持与旧的 fwknop 客户端的向后兼容性。

  • 支持代表有效SPA数据包执行shell命令。

  • fwknop 服务器可以配置为对入站SPA数据包施加多个限制，超出加密密钥强制执行的限制和重放攻击检测。即，包年龄，源IP地址，远程用户，对请求端口的访问，针对命令过滤正则表达式等。

  • 捆绑了fwknop是一个全面的测试套件，它发布了一系列测试，旨在验证fwknop的客户端和服务器部分是否正常工作。这些测试涉及在本地环回接口上嗅探SPA数据包，构建临时防火墙规则，根据测试配置检查相应的访问权限，并解析来自fwknop客户端和fwknopd服务器的输出，以获得每个测试的预期标记。测试套件输出可以很容易地匿名化，以便与第三方进行通信以进行分析。

  • fwknop是第一个将端口敲击与被动操作系统指纹识别相结合的程序。但是，单包授权提供了除端口敲门之外的许多安全优势，因此通常不推荐端口敲门操作模式。
