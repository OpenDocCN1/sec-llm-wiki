# AIEngine - 一种人工智能入侵检测系统引擎

AIEngine是下一代交互式/可编程Python / Ruby / Java / Lua和Go网络入侵检测系统引擎，具有学习功能，无需人工干预，DNS域分类，垃圾邮件检测，网络收集器，网络取证等等。

  

它还可以帮助网络/安全专业人员识别流量并开发签名，以便在NIDS，防火墙，流量分类器等上使用它们。

  

AIEngine的主要功能是：

  

支持在引擎运行时与用户进行交互/编程。

支持PCRE JIT进行正则表达式匹配。

支持正则表达式图（复杂的检测模式）。

支持五种类型的NetworkStack（lan，mobile，lan6，virtual和oflow）。

用于IP搜索的支持集和布隆过滤器。

通过Linux，FreeBSD和MacOS等操作系统支持x86\_64，ARM和MIPS架构。

支持HTTP，DNS和SSL域匹配。

支持HTTP，DNS，SMTP和SSL的禁止域和主机。

未知流量和自动正则表达式生成的频率分析。

生成Yara签名。

与数据库（MySQL，Redis，Cassandra，Hadoop等）轻松集成，实现数据关联。

与其他数据包引擎（Netfilter）轻松集成。

支持内存清理缓存以刷新存储的内存信息。

支持在网络/应用层检测DDoS。

支持拒绝TCP / UDP连接。

实时支持网络取证。

支持比特币，CoAP，DHCPv4 / DHCPv6，DNS，GPRS，GRE，HTTP，ICMPv4 / ICMPv6，IMAP，IPv4 / v6，Modbus，MPLS，MQTT，Netbios，NTP，OpenFlow，PPPoE，POP，Quic，RTP等协议， SIP，SMB，SMTP，SSDP，SSH，SSL，TCP，UDP，VLAN，VXLAN。

  

使用AIEngine要使用AIEngine（reduce版本），只需执行二进制aiengine或使用python / ruby / java / lua绑定。  
luis @ luis-xps：?/ c / aiengine / src $ ./aiengine -h一些1.8.0

强制性论点：  -I \[--input\] arg设置网络接口，pcap文件或pcap文件的目录。

链接层可选参数：  
  -q \[--tag\] arg选择以太网层的标记类型（vlan，mpls）。

TCP可选参数：  
  -t \[--tcp-flows\] arg（= 32768）设置池上的TCP流数。

UDP可选参数：  
  -u \[--udp-flows\] arg（= 16384）设置池上UDP流的数量。

  

正则表达式可选参数：

  

  -R \[--enable-signatures\]启用签名引擎。-r \[--regex\] arg（=。\*）设置用于再次评估流的正则表达式。  
  -c \[--flow-class\] arg（= all）使用tcp，udp或all匹配签名关于流量。  
  -m \[--matched-flows\]显示与正则表达式匹配的流。  
  -M \[--matched-packet\]显示与之匹配的数据包有效负载正则表达式。  
  -C \[ - 继续\]继续评估正则表达式流的下一个数据包。  
  -j \[--reject-flows\]拒绝与之匹配的流正则表达式。  
  -w \[--evidence\]生成匹配的pcap文件 法医分析的正则表达式。  
  
  
频率可选参数：  
  -F \[--enable-frequencies\]启用频率引擎。  
  -g \[ -  group-by\] arg（= dst-port）按src-ip，dst-ip，src-por分组频率t和dst-port。  
  -f \[ -  flow-type\] arg（= tcp）使用tcp或udp流。  
  -L \[--enable-learner\]启用学习者引擎。  
  -k \[--key-learner\] arg（= 80）设置学习者引擎的密钥。  
  -b \[--buffer-size\] arg（= 64）设置内部缓冲区的大小生成正则表达式。  
   -Q \[--byte-quality\] arg（= 80）设置字节的最小质量生成的正则表达式。  
  -y \[--enable-yara\]生成yara签名。  
  
  
可选参数：

  
  -n \[--stack\] arg（= lan）设置网络堆栈（lan，mobile，lan6，virtual，\[size=13.3333px\]oflow）。  
  -d \[--dumpflows\]将流转储到stdout。  
  -s \[--statistics\] arg（= 0）显示网络堆栈的统计信息（5级）。  
  -T \[--timeout\] arg（= 180）设置流超时。  
  -P \[--protocol\] arg显示特定协议的统计信息网络堆栈。  
  -e \[--release\]释放缓存。  
  -l \[--release-cache\] arg释放特定的缓存。  
  -p \[--patatistics\]显示进程的统计信息。  
  -o \[--summary\]显示协议summmary statistics字节，数据包，％字节，缓存未命中，内存）。  
  -h \[--help\]显示帮助。  
  -v \[--version\]显示版本字符串。  
  
NetworkStack类型AIEngine支持五种类型的网络堆栈，具体取决于网络拓扑。

  

*   基于IPv4的StackLan（L??AN）局域网。
    
*   StackLanIPv6（lan6）支持IPv6的局域网。
    
*   用于IPv4的StackMobile（移动）网络移动（Gn接口）。
    
*   StackVirtual（虚拟）堆栈，适用于具有VxLan和GRE透明的虚拟/云环境。
    
*   StackOpenFlow（oflow）用于OpenFlow环境的堆栈。
