三个月前微软官方宣布75亿美元收购GitHub，微软在 26 日正式收购 GitHub，新任 GitHub CEO Nat 发文宣布了这一消息。



新任 CEO 何许人也？


Nat Friedman，曾经是 Xamarin(另一家专注于开发的初创公司，2016 年被微软收购)的首席执行官。Nat Friedman 也是开源界的领军人物之一，在今年 3 月加入微软前是 AI Grant 的联合创始人。



而 GitHub 的创始人和前首席执行官 Chris Wanstrath 将成为微软的技术研究员，从事战略软件计划。(在 2014 年他的联合创始人汤姆•普雷斯顿-沃纳(Tom Preston-Werner)因性骚扰调查辞职后，Wanstrath 重新回到了 CEO 的位置。)


Nat 在博文中再次提到了 GitHub 原则：


GitHub 将作为社区，平台和业务独立运营。这意味着 GitHub 将保留其开发人员的第一价值观，开放的可扩展性。我们将始终支持开发人员选择任何语言，许可证，工具，平台或云。


GitHub 将保留其产品理念。我们喜欢 GitHub，因为开发人员体验的每个方面都有着深刻的关怀和体验。我理解并尊重这一点，因此我将继续打造开发人员喜爱的高雅，活泼，精美的工具。


新官上任三把火：先定三个小目标


Nat Friedman 在博客里重申收购不会改变 GitHub 的独立运营和其产品理念，并说明了 GitHub 未来的目标。他这样写道：


在过去的几个月里，一直在为这个新角色做准备，与数百名开发人员会面，从维护人员到初创企业，再到大型企业。他们对GitHub的热情令人惊讶——无论是在我们擅长的领域，还是在希望我们做得更多的方面。我从中学到了很多东西，倾听客户的想法将是 GitHub 作为一家公司运作的核心部分。


关于 GitHub 的未来，Nat 有几个优先考虑的方向：

● 确保 GitHub 是运营高效社区和团队的最佳场所。

● 使 GitHub 可供全球更多开发人员使用。

● 可靠性、安全性和性能


我们将从关注使用 GitHub 的日常经验开始，并将加倍我们的 paper cuts 项目。我们将改进核心场景，如搜索、通知、问题/项目，以及我们的移动端体验。当然，我们很高兴 GitHub Action 可以被广泛使用。


我们相信社会的力量——当我们与他人合作时，我们就都能取得更大的成就。作为世界上最大的开发者社区，GitHub 聚集了超过 3100 万开发者来创建、合作、分享和构建彼此的工作。


我们的愿景就是成为一个构建软件的最佳平台，为地球上的每一个开发者服务。对于 GitHub 的所有人来说，这都是一个梦寐以求的机会，我们再没有比卷起袖子开始下一章更激动的了。


目前，GitHub 拥有 3100 万开发者，因此 GitHub 保持独立运营和继续获得开发者的信赖非常重要。微软 CEO 纳德拉在Twitter对收购GitHub表示祝贺：“我们将继续推动 GitHub 成为开发者喜爱并受信赖的平台。”



微软预计，在经过调整的基础上，本次收购将会提升 2020 财年的营业利润。作为我们程序员最大的交友网站，我们还是祝GitHub越来越好
