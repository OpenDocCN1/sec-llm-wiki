小伙伴们 你们的kali炫酷吗？ 和我一起美化界面吧！

首先查看并更新源

vim /etc/apt/sources.list


阿里云

deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib 
deb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib 



我更新的源是阿里云的，你们也可以换别的


更新

apt-get clean && apt-get update && apt-get upgrade -y && apt-get dist-upgrade -y

命令讲解： 
apt-get clean    //清除缓存索引 
apt-get update    //更新索引文件 
apt-get upgrade    //更新实际的软件包文件 
apt-get dist-upgrade    //根据依赖关系更新


先换一张背景图片吧！



然后安装gnome

root@Black:~# apt-get  install  gnome-tweak-tool



安装多窗口终端（terminator）

lack:~# apt-get  install terminator


安装完后记得重启，重启完打开终端选择配置文件首选项



这里就可以更改终端里的文字样式和颜色



kali配置里选择优化，在这里你可以配置你喜欢的外观、字体、主题、光标等，如果这些还不够的话，你还可以下载自己喜欢的插件，你们自己美化吧!
