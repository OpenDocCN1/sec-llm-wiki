# 黑客盗取虚拟币，反被奖励5000美元

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650450002&idx=2&sn=85d8ed70769471d0a4e4a4c05306a2e5&chksm=83bbcdb6b4cc44a0f26f268dcb3d800eb17e1c2148c90f5086ff0e9631ba8e20a41644e7101a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650450002&idx=2&sn=85d8ed70769471d0a4e4a4c05306a2e5&chksm=83bbcdb6b4cc44a0f26f268dcb3d800eb17e1c2148c90f5086ff0e9631ba8e20a41644e7101a&scene=27#wechat_redirect)

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

据外媒cointelegraph消息，10月6日，国外一家以虚拟币以太坊（ETH）为基础的成人娱乐平台SpankChain发现，自家平台的ETH虚拟币被黑客盗取了165枚，价值约32000美元（约合人民币‪221510元‬）。  

  

10月12日，SpankChain发推文表示，公司与黑客通话之后，黑客将所盗取虚拟币全部返还。近日，SpankChain证实，自己被盗窃的虚拟币已全部收回。

  

![](../Images/78cc9078013f6573060ecfe8bc7dfd99.png)

  

有意思的是，在确认资金到账之后，SpankChain还给黑客奖励了大约价值5000美元的虚拟币，并补偿黑客用于发起攻击的价值约1000美元的虚拟币。

  

SpankChain甚至还发推对该黑客表示祝贺：“Congratulations, anonymous haxor!（祝贺你，匿名黑客）”

  

网上盗号、盗取虚拟币的行为千千万，全部返还的却寥寥无几，成人网站的黑客素质都这么高的吗？
