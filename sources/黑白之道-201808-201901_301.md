# 偶遇菠菜网站，随手提之

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

今天逛正经网站的时候，点进去一个正常的链接，没想到直接跳转到了双色球网站，这令我很是气愤啊，扫了我网上冲浪的雅兴！于是开始曰站。

扫了一下，发现很多的注入

  

获取到了后台管理界面的账号密码：liming   123456

![](../Images/4255a36d8106b2df85c1ee7162a0e96b.png)

有了账号密码之后马上就登录进去

  

随手点一个发布广告的动能

  

发现有上传点并且泄露了网站物理地址

![](../Images/f7b3054d631ea4fa8ffd10f1ca9622ff.png)

  

我就去用brup上传jpg文件，果然失败了，看来上传文件不行，要从别的方向下手了。

  

之后用了扫描器扫，发现了不为人知的秘密

![](../Images/5d7f4f3fde4b10b7408b109358d5c5cd.png)

  

FTP password  is  NULL

  

于是就用ie资源管理器登录ftp，上传了webshell，之后上菜刀

![](../Images/065db85f47047637929282064f2900aa.png)

  

接下来就开始提权了，运行了cmd，获取了一系列的信息

![](../Images/e21e88dcc06cffc2412ecf455c6239d6.png)

  

win2003sp2的机子，现在来说有点太老了，漏洞比比皆是，尝试上传一个pr

![](../Images/5b9a2fa11b7e3de6ed27c7ef742734f2.png)

  

然后找到他所在的目录执行文件，果然得到了system

![](../Images/2e2663a3a3229e67219f67ec0446e81e.png)

然后就开始创建用户了

  

看到很简单就成功创建用户了，没有狗之类的东西还挺好，

![](../Images/a09b7a2f4e0fcbc5625fb595fe5179fa.png)

  

马上就用创建的用户登录，

![](../Images/6d2c923db7a11cdfdec52c3fa0c9ebdb.png)

  

终端服务器超出了最大连接数。。。心碎了一地啊，那就尝试用管理员账号登录试试吧，先去抓个密码出来。

  

于是上传pw7抓密码

![](../Images/eea61b2e9a53f21277febadf2c8e0c8c.png)

  

把抓出来的密文找网站破解一下

![](../Images/4bfb6a4e262e976e29a6105114e4f6f5.png)

  

真是赶赶单单啊

![](../Images/75d11700c70499d1dcb7e2fd96c71cb4.png)

  

本来先把盘格了来着，后来想想还是算了毕竟都不容易。哎，擦擦屁股走人了。
