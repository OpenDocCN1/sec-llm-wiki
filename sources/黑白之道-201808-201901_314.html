YASAT - 一个简单的安全审计工具

YASAT是一个简单的审计工具，具有最小的二进制依赖性（只有sed，grep和cut）。


它记录每个测试的最大信息和官方文档的链接。


 


它能检查许多软件配置，例如： 


Apache
Bind DNS
CUPS
PHP
kernel configuration
mysql
network configuration
openvpn
Packages update
samba
snmpd
squid
syslog
tomcat
user accounting
vsftpd
xinetd

已经经过YASAT测试的：


Gentoo
Debian
Ubuntu
FreeBSD
OpenBSD
RedHat
CentOS
ArchLinux

安装：


只需解压YASAT tarball：
tar xvzf yasat-releasenumber.tar.gz
将目录更改为YASAT目录：
cd yasat
并输入：
./yasat
