## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

![](../Images/e8bff05e029a66ae443df4f214fde646.png)   
YASAT是一个简单的审计工具，具有最小的二进制依赖性（只有sed，grep和cut）。

  
它记录每个测试的最大信息和官方文档的链接。

  
![](../Images/c4288928103dc5c91321a2fc9807196f.png) 

  
**它能检查许多软件配置，例如：** 

  
Apache  
Bind DNS  
CUPS  
PHP  
kernel configuration  
mysql  
network configuration  
openvpn  
Packages update  
samba  
snmpd  
squid  
syslog  
tomcat  
user accounting  
vsftpd  
xinetd  
  
**已经经过YASAT测试的：**

Gentoo  
Debian  
Ubuntu  
FreeBSD  
OpenBSD  
RedHat  
CentOS  
ArchLinux  
  
**安装：**

  
只需解压YASAT tarball：  
tar xvzf yasat-releasenumber.tar.gz  
将目录更改为YASAT目录：  
cd yasat  
并输入：  
./yasat
