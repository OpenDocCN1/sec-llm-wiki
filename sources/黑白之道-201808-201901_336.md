mwebfp（Massive Web Fingerprinter）是一个基于Python的Web服务器指纹识别工具。

  

**要求：**

  

为了运行mwebfp“out-of-the-git”，启用所有选项，您将需要：

  

*   Python - 编程语言（sudo apt-get instal python）
    
*   nmap - 端口扫描程序（sudo apt-get install nmap）
    
*   python-nmap - Python模块（apt-get install python-nmap）
    
*   请求 - Python模块（apt-get install python-requests）
    
*   cutycapt - Qt WebKit Capture Utility（最新版本）
    
*   正在运行脚本的\* nix服务器上的图形界面（GUI）（我假设Linux）  
    

  

**特征：**

  

*   输入  
    

*   目标可以是IP地址，IP地址范围，服务器名称等。
    
*   目标可以直接在命令行或文件中提供  
    

*   端口定义  
    

*   默认端口为80（HTTP）和443（HTTPS），但可以在运行时轻松配置任何端口  
    

*   产量  
    

*   扫描的所有输出文件和相关支持文件都保存在用户在运行时配置的目录中
    
*   目前，mwebfp仅在CSV文件（在MS Excel上轻松使用）上导出结果  
    

*   虚拟主机  
    

*   如果在运行时请求，mwebfp将找到目标服务器的所有虚拟托管域和网页  
    

*   Webserver截图  
    

*   如果在运行时请求，mwebfp将抓取所有找到的网页的截图（需要Linux下的图形UI）  
    

  

**用法：**

  

usage: mwebfp.py \[-h\]                 \[-i INPUT\_RANGE | -n SERVER\_NAME | -f INPUT\_FILE | -r\]                 \[-p HTTP\_PORTS\] \[-s HTTPS\_PORTS\] \[-o OUTPUT\_DIR\]                 \[-t {HTML,XLS,CSV,XML}\] \[-v {yes,no}\] \[-w {yes,no}\]optional arguments:    
\-h, --help            show this help message and exit    
\-i INPUT\_RANGE, --input-range INPUT\_RANGE                        input IP CIDR range    
\-n SERVER\_NAME, --server-name SERVER\_NAME                        name of server (DNS name)    
\-f INPUT\_FILE, --input-file INPUT\_FILE                        input file containing IP addresses and/or IP ranges    
\-r, --recover         recover/continue previous process    
\-p HTTP\_PORTS, --http-ports HTTP\_PORTS                        TCP HTTP ports (Default: 80/tcp)    
\-s HTTPS\_PORTS, --https-ports HTTPS\_PORTS                        TCP HTTPS ports (Default: 443/tcp)    
\-o OUTPUT\_DIR, --output-dir OUTPUT\_DIR                        working directory    
\-t {HTML,XLS,CSV,XML}, --output-format {HTML,XLS,CSV,XML}                        output report format (Default: HTML)    
\-v {yes,no}, --vhosts {yes,no}                        choice of processing vhosts for each IP address                        (Default: no)    
\-w {yes,no}, --web-screenshots {yes,no}                        choice of taking web schreenshots (Default: no)
