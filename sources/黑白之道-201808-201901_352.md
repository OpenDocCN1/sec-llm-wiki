# Hyperfox - HTTP / HTTPS流量拦截器

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

![](../Images/c97d952d33715c78521a4a5a9e486d5e.png)

  

Hyperfox是一种开源安全工具，用于在LAN上代理和记录HTTP和HTTP通信。它是用Go编程语言编写的

  
![](../Images/874a35b2c63eb7f465b3d1f9934acdfe.png)

  

它能够使用根CA证书及其相应的密钥（均由用户提供）即时伪造SSL证书。如果目标计算机将根CA识别为受信任，则可以成功拦截并记录HTTP流量。

  
![](../Images/96c20b5bbc6a157c9be5aaf8b1a22bfb.png)

  

Hyperfox将捕获的数据保存到SQLite数据库以供以后检查，并提供用于观看实时流量和下载有线格式消息的Web界面。

![](../Images/0022f69d0e19df0846d8a38797d7b2df.png)

  

下载链接：https://github.com/malfunkt/hyperfox/releases
