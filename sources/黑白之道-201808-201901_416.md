# 月薪 3 万 Java 开发经理「实施诈骗」，已被抓

## ![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

9月8日，32岁的周某伟在深圳宝安某招待所被深圳南山警方抓获。一个月前，他前往深圳南山一科技公司应聘，并在向公司借了3万元、向同事借了1万元之后就玩消失。目前，嫌疑人李某伟已被南山警方依法刑事拘留。

  

![](../Images/878067fe537293dc3a557d4634d2a876.png)

  

8月7日，深圳市公安局南山分局高新派出所接到市民苏女士报称：今年8月3日，其公司接待一名应聘java软件开发经理职位的人员李某伟。在了解对方个人生活情况后，同意预支一个月的工资30000元人民币以解决对方的生活所需，并让对方写了借条。后发现李某伟手续不全，但怎么都联系不上对方。据了解，李某伟还通过微信向其公司的三名同事借款共计10000元人民币未还。

  

接报后，南山警方迅速开展案件侦查。警方了解到，该科技公司员工考虑到李某伟是公司技术人员，工资高，周转完肯定会还给自己，没考虑太多便将钱转了过去。可是没想到，借钱后就再也联系不上对方。民警通过视频研判和摸排，最终锁定了嫌疑人的落脚点，并于9月8日在深圳宝安某招待所将实施诈骗的嫌疑人李某伟（男，32岁）抓获。

  

经审讯，犯罪嫌疑人李某伟对其实施诈骗的犯罪事实供认不讳。据民警进一步调查，犯罪嫌疑人李某伟2016年期间曾因诈骗被公安机关处罚过，是一名诈骗惯犯。

  

目前，嫌疑人李某伟已被南山警方依法刑事拘留。
