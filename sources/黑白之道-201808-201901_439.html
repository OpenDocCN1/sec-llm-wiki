插件扫描:


参考和学习了wpscan的工作模式，进行了对目标网站插件的暴力扫描，然后通过扫描出的结果去dzscan漏洞库中查找是否已经有存在的漏洞，然后生成报告。


创始人密码爆破:


对uc的创始人密码进行爆破，绕过了验证码限制，从到达到无限制暴力破解，采用多线程方式，加大破解速度。


使用方法

python dzscan.py --update 
更新插件列表（目前已是最新无需更新）
python dzscan.py -u http://bbs.dzscan.org/ --gevent 20 
20是线程数量，可以自定义
