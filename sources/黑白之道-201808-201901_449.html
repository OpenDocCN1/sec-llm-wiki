工具介绍


Subover是一个域名托管检测工具，检测域名是否托管到一个第三方的服务商 它将会检测是否托管到如下服务商


  • Github

  • Heroku

  • Unbounce

  • Tumblr

  • Shopify

  • Instapage

  • Desk

  • Tictail

  • Campaignmonitor

  • Cargocollective

  • Statuspage

  • Amazonaws

  • Cloudfront

  • Bitbucket

  • Smartling

  • Acquia

  • Fastly

  • Pantheon

  • Zendesk

  • Uservoice

  • Ghost

  • Freshdesk

  • Pingdom

  • Tilda

  • Wordpress

  • Teamwork

  • Helpjuice

  • Helpscout

  • Cargo

  • Feedpress

  • Surge

  • Surveygizmo

  • Mashery


使用方法


git clone https://github.com/Ice3man543/SubOver.git
cd SubOver
go build subover.go
./subover -l subdomains.txt
