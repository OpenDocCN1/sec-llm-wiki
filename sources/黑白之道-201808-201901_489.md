# Raspberry Pwn – 树莓派渗透测试套装

Raspberry Pwn 是一个树莓派渗透测试套装，包含了众多的渗透测试工具,你需要拥有一个树莓派和安装了Debian系统，才能使用这个套装。

  

他包含了如下的工具列表：

  

asp-auditor

bed

cisco-auditing-tool

cisco-global-exploiter

cms-explorer

darkmysqli

dnsmap

easy-creds

fasttrack

fierce

fimap

goodfet

goohost

grabber

lbd

metagoofil

miranda

plecost

revshells/encrypted\_http\_shell

sickfuzz

sipvicious

smtp-user-enum

snmpenum

sqlbrute

sqlmap

sslstrip

theharvester

ua-tester

untidy

voiper

waffit

weevely

wifitap

wifite

wifizoo

xssfuzz

  

使用方法：

git clone https://github.com/pwnieexpress/Raspberry-Pwn.git

```
cd Raspberry-Pwn
./INSTALL\_raspberry\_pwn.sh
```
