**Windows Terminal**

 ![](../Images/5b9c348bf3a8a2a00e36956a6d402688.png)

  

微软目前已经宣布推出名为Windows Terminal的新款命令行工具 ,这款工具可以访问多种环境的中心位置还支持表情符号和基于GPU的文本呈现。

  

例如可以直接访问PowerShell、CMD.EXE、Windows Linux子系统等并整合了此前的Powershell、cmd命令行工具，再加上新发布的WSL2、AI（IntelliCode）辅助写代码，想必程序员对敲代码又一次充满了激情。

 

**简单介绍下Windows Terminal 是什么？**

  

![](../Images/75686ff320779a2fbdca2bdbf77ae5ca.png)

  

Windows Terminal 是一个全新的、流行的、功能强大的命令行终端工具。包含很多来社区呼声很高的特性，例如：多 Tab 支持、富文本、多语言支持、可配置、主题和样式，支持 emoji 和基于 GPU 运算的文本渲染等等。同时该终端依然符合我们的目标和要求，以确保它保持快速、高效，并且不会消耗大量内存和电源。

  

Windows Terminal使用的是基于DirectWrite/DirectX的GPU加速文本渲染引擎。这个新的引擎支持显示PC中存在的文本字符，意味着终端里的汉字、日文不再乱码，而且还能玩emoji表情。

  

![](../Images/916db212fe2005dfc8eb00f853c807f9.png)

  

此外，微软还为它增加了一种新的等宽字，以增强现代外观和感觉。预计于六月中旬面向开发者提供预览，而1.0正式版将会在今年冬季发布。微软已经将该项目搬上了Github，短短数小时内已经接近7000颗星，数字仍在快速上升中，分享也已经有500多次了！

**机器人平台**

![](../Images/f252153db911a63677f8c8814c9c2496.png)

  

在收购了专注于自主系统强化学习的AI（人工智能）创业公司Bonsai之后，微软宣布推出一个基于Azure的新平台有限预览版。这个平台部分建立在微软收购Bonsai交易的基础上，可帮助开发人员训练模型，以便为自主物理系统提供动力。

 

这个新平台可将微软的机器教学和机器学习工具与模拟工具（如微软自己的AirSim模拟工具或第三方模拟器）相结合，用于在现实但安全的环境中训练模型，并与微软的诸多物联网（IoT）服务和开源机器人操作系统（Robot Operating System）结合到一起。

  

**Windows 10中内置完整Linux内核**

  

![](../Images/e3cb35e7d358cb8316602e1d20cf2771.png)

  

微软项目经理Jack Hammons解释道：“微软计划在今年夏天的Windows内部人员测试版本开始，加入一个内部定制的Linux内核，以支持最新版本的Windows Linux子系统(WSL)，内核本身最初将基于4.19版本，这是Linux最新的长期稳定版本。内核将在稳定发行版更新时重新构建，以确保WSL内核始终具有最新的Linux优势。”

  

对于开发者来讲，这将显著提高Windows中微软Linux子系统的性能。微软也承诺通过Windows update更新这个内核，它将是完全开源的，开发者可以创建自己的WSL内核并进行修改。

  

**AR版本《我的世界》**

  

![](../Images/d9876505d1020d7f966034ad3e284239.png)

  

微软在Build 2019开发者大会主题演讲结束时展示了一段视频，展示了《我的世界》（Minecraft AR）在手机上运行的增强现实技术。也就是说，微软即将推出一款针对移动设备开发的新游戏Minecraft AR。

  

此次会议上发布了多款新产品和服务，涉及云服务、人工智能、机器人、物联网等诸多技术领域。内容涉及微软Azure云服务，改进的Chromium驱动的Edge网络浏览器，一款面向移动设备的增强现实Minecraft游戏等。对于微软来讲，Build 2019是具有“里程碑”意义的一次开发者大会。
