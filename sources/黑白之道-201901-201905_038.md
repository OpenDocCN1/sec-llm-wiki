trape是一种识别工具，可以让你跟踪任何人，你可以得到的信息非常详细。通过去识别现有的网站所登录的用户，来追踪一个人的虚拟身份

  

如何使用它首先卸载工具。  
git clone https://github.com/boxug/trape.git  
cd trape  
python trape.py -h  
  
如果它不起作用，请尝试安装文件requirements.txt中的所有库  
pip install -r requirements.txt  
  
执行的例子  
示例：python trape.py --url http://example.com --port 8080  
  
下载地址：https://github.com/jofpin/trape
