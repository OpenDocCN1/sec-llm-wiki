项目简介

  

PytheM是基于python编写的网络／渗透测试工具，其包含了如下的功能：

  

*   \[暴力破解\]
    
*   \[中间人攻击\]:
    
*   \[Remote\]:
    
*   \[嗅探\]:
    
*   \[扫描\]:
    
*   \[web攻击\]:
    
*   \[无线攻击\]:  
    

  
安装方法

$sudo git clone https://github.com/m4n3dw0lf/PytheM/  
$cd PytheM  
$sudo pip install -r requirements.txt  
$sudo ./pythem
