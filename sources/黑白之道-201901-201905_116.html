LaZagne - 检索存储在本地计算机上的密码工具

LaZagne项目是一个开源应用程序，用于检索存储在本地计算机上的大量密码。每个软件使用不同的技术（明文，API，自定义算法，数据库等）存储其密码。该工具的开发目的是为最常用的软件找到这些密码。

注意：您的防病毒软件可能会将LaZagne检测为病毒。因此，在下载/使用它时禁用您的防病毒软件。



要求：要编译源代码，需要一些外部库。在两个系统上编译项目都需要Python 2.7。


对于Windows：

用于Python 2.7的Microsoft Visual C 编译器

pip install pycrypto pyasn1 psutil

pip install https://github.com/n1nj4sec/memorpy/archive/master.zip


对于Linux：

pip install pycrypto pyasn1 dbus-python

pip install https://github.com/n1nj4sec/memorpy/archive/master.zip

apt-get install python-gnomekeyring python-kde4


对于Mac：

pip install pycrypto pyasn1


注意： 对于wifi密码\ Windows Secrets，使用管理员权限启动它（UAC身份验证/ sudo）

用法：

检索版本

laZagne.exe --version

启动所有模块

laZagne.exe全部
仅启动特定模块
laZagne.exe浏览器
仅启动特定的软件脚本（适用于Firefox）
laZagne.exe的浏览器-f 
将找到的所有密码写入文件（正常txt为-oN，Json为-oJ，所有为-oA）
laZagne.exe all -oN
得到帮助
laZagne.exe -h
laZagne.exe browsers -h
使用文件进行字典攻击（仅在必要时使用：Mozilla主密码，系统哈希等）。该文件必须是明文中的单词列表（没有彩虹），它还没有被优化为快速但对基本密码有用。
laZagne.exe all -path file.txt
更改详细模式（2个不同级别）
laZagne.exe all -vv
安静模式（标准输出上不会打印任何内容）
laZagne.exe all -quiet -oA
在另一个驱动器上检索密码（默认值：C）
laZagne.exe all -drive D.

苹果系统：在Mac OS系统中，如果没有用户密码，则很难检索存储在计算机上的密码。所以，我建议使用其中一个选项
如果您知道用户密码，请在命令行中添加它
laZagne all --password SuperSecurePassword

您可以使用交互模式，该模式将向用户提示对话框，直到密码正确为止

laZagne all -i
