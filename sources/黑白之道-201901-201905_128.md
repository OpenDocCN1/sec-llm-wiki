BruteX是一个简单的程序，可以自动强制执行目标上运行的所有服务。  
  
安装：运行./install.sh  
用法：brutex target <port>  
  
Docker：docker build -t brutexdocker run -it brutex target <port>  
  
下载地址：https://github.com/1N3/BruteX
