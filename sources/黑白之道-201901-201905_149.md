WebSploit Framework是一个开源命令行实用程序，可以扫描和攻击目标服务。它的功能如下所列。  
  

  

*   Autopwn - 从Metasploit用于扫描和利用目标服务  
      
    

*   WMAP - 从Metasploit wmap插件使用的扫描，爬虫目标  
      
    

*   格式化infector - 注入反向并将有效负载绑定到文件格式  
      
    

*   phpMyAdmin扫描仪  
      
    

*   CloudFlare解析器  
      
    

*   LFI Bypasser  
      
    

*   Apache用户扫描程序  
      
    

*   Dir Bruter  
    

*   管理员查找器  
      
    

*   MLITM攻击 - 中间人，XSS网络钓鱼攻击  
      
    

*   MITM - 中间人攻击  
      
    

*   Java Applet攻击  
      
    

*   MFOD攻击（末日攻击的中指）  
      
    

*   ARP Dos攻击  
      
    

*   网络杀手攻击  
      
    

*   假更新攻击  
      
    

*   假接入点攻击  
      
    

*   无线蜜罐  
      
    

*   Wifi Jammer  
      
    

*   Wifi DoS  
      
    

*   Wifi Mass De-Authentication攻击  
      
    

*   蓝牙POD攻击
