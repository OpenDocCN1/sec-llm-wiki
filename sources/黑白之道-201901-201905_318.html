Joomscan（Joomla漏洞扫描程序）是一个用Perl编程语言编写的开源工具，可以检测和分析Joomla CMS漏洞。


用法：  joomscan.pl -u <string> -x proxy：port 
        -u <string> = joomla Url 
      
        == Optional == 
        -x <string：int> = proXy to tunnel 
        -c <string> = cookie（name = value;）
        -g“<string>”=所需的useraGent字符串“ 
        -nv =无版本指纹识别检查
        -nf =无防火墙检测检查
        -nvf / -nfv =无版本 防火墙检查
        -pe =仅限Poking版本
                           （并退出扫描仪）
        -ot =输出到文本文件（target-joexploit.txt）-oh 
        =输出到Html文件（target-joexploit.htm）
        -vu =详细（输出每个Url扫描）
        -sp =显示已完成百分比

示例：  joomscan.pl - pv -u victim.com -x localhost：8080

Joomscan当前版本的局限性：

  • 漏洞数据库仍然缺少未知漏洞检查。如果漏洞利用检查不可用，则扫描程序将根据推断的版本进行验证。如果推断的版本不可用，则无法验证漏洞。

  • 扫描仪缺乏IDS逃避旁路。

  • 扫描仪缺乏复杂的模糊测试。

  • 扫描程序不是一个完整的SQL注入工具。

    开发人员正在开发这个工具的新版本，希望他们将在即将发布的版本中消除这些限制。
