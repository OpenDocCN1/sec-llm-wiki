PWGen是一个专业的密码生成器，允许您创建大量加密安全密码 - “经典”密码，可发音密码，基于模式的密码以及由单词列表中的单词组成的密码短语。
它使用基于强加密技术的“随机池”技术，从不确定的用户输入（击键，鼠标处理）和易失性系统参数生成随机数据。

PWGen提供了许多选项来根据用户的各种需求自定义密码。此外，它还提供强大的文本加密和随机数据文件的创建（例如，可用作加密实用程序的密钥文件）。


特征：

  • 基于加密安全伪随机数生成器（SHA-256和AES的组合）生成密码

  • 通过测量击键，鼠标移动和鼠标点击之间的时间间隔来收集; 另外，以规则的时间间隔收集来自易失性系统特定参数

  • 生成由单词列表中的单词组成的密码短语基于模式的密码生成（格式化密码）提供了几乎无限的可能性来根据用户的需求自定义密码

  • 基于语言特定的三元组（3字母序列）频率生成语音（可发音）密码

  • 用于各种目的的众多密码选项

  • 一次生成大量密码

  • “密码加密”功能

  • 安全文本加密（使用256位密钥的AES）

  • 多语言支持

  • 完整的Unicode支持

  • 在所有32位和64位Windows版本上运行（即Windows 95 [OEM SR2]，NT 4.0,98,2000，Me，XP，Vista，7,8,10; Windows Server 2003,2008,2012）


PWGen能够生成以下类型的密码：

  • “经典”密码，例如VLyw68JsSq0m，即来自特定字符集的字符的随机序列（示例中为大写/小写字母和数字）。

  • 语音（可发音）密码，例如terweeptoton，它是通过评估某种语言的所有可能的三元组（1个三元组= 3个字母的序列; 1个三元组，有26个3 = 17,576个可能的字母组合）的频率生成的。这个例子）。


  • 密码短语，如khaki cello waxy mecca verdi，由单词列表中随机选择的单词组成。单词可以很容易地与随机字符组合以给出密码，例如lends-ah susie-Tx chats-Hz joins-TE。


  • 基于模式的格式化密码或密码：这是最通用的密码生成功能，因为它提供了各种格式说明符，用于将预定义字符集中的字符和特定单词列表中的单词插入到生成的密码中。此外，它允许在密码中重复和随机置换序列。示例：格式字符串{％4u％4l％2d％s％}表示“插入4个大写字母，4个小写字母，2个数字和1个特殊符号;之后置换字符序列”，并生成密码等作为fP4eM＃mAiV


  • “哈希”密码，基于主密码和参数的密码，此功能使您可以使用（秘密）主密码和（不一定是秘密）参数（例如网站名称）重复生成唯一密码。例如，主密码qwerty（提示：不要使用那个！）和参数yahoo一起产生密码W4hfOL21K3FYb8Qx。PWGen的密码hasher提供了几个预定义的字符集供用户选择。由于独立于存储的参数 - 密码组合的任何加密数据库，因此它可以用作完全可移植的“密码安全”。如果您想独立于基于Windows的应用程序，PWGen还可以提供与Hashapass生成器的完全兼容性，该生成器可通过Internet访问，并且可以与任何浏览器一起使用。为了让用户估计生成的密码的质量，PWGen显示“密码质量条”，其颜色范围从红橙色（不太安全）到深绿色（更安全）。
