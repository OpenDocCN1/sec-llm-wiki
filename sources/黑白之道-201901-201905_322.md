哇噢！ 黑客和渗透测试人员的好消息。

Offensive Security 刚刚发布了Kali Linux 2019.1，这是其面向网络安全专业人士的第一个2019年版瑞士军刀。

最新版本的Kali Linux操作系统使用了最高版本为4.19.13的Linux内核，并包含了针对众多错误的补丁，以及许多更新的软件，如Metasploit，Harvester，DBeaver等。

Kali Linux 2019.1 附带了Metasploit(5.0版本)渗透测试工具的最新版本，该工具“包括数据库和自动化api、新的规避功能以及整个可用性改进” 使其成为渗透测试人员更有效的平台。

Metasploit 5.0版是该软件自2011年发布的4.0版以来的首个主要版本。

谈到ARM映像，Kali Linux 2019.1现在再次添加了对内核版本4.19的Banana Pi和Banana Pro的支持。

> Banana Pi 和 Banana Pro 开源平板电脑，了解更多请参考  
> 百度百科: https://baike.baidu.com/item/Banana%20Pro  
> 维基百科: https://en.wikipedia.org/wiki/Banana\_Pi

> Kali Linux项目维护人员在他们的官方发布声明中说：“Veyron已经被转移到了4.19内核上，Raspberry Pi映像也被简化了，因此更容易找出要使用的内核”  
> 对于使用TFT LCD的用户，不再有单独的Raspberry Pi镜像，因为我们现在在所有这些镜像上都包含了re4son的kalipi-tft-config脚本，因此如果你想设置一块带有TFT的电路板，请运行’kalipi-tft-config ‘并按照提示进行操作。“

虚拟机和ARM映像也已更新到最新的2019.1版本。
