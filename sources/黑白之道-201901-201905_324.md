# 喜达屋发布在线工具 帮助客户查询个人信息是否被黑客窃取

去年12月，万豪国际(Marriott)旗下的喜达屋连锁酒店(Starwood)发生严重的客户信息外泄事件。公司承认多达3.83亿客户（最初为5亿）受到影响，时间最早可追溯到2014年，泄露的信息包括邮寄地址、电邮、电话号码、护照号码、出生日期、性别、入住和退房信息、预订时间、首选沟通方式和喜达屋SPG俱乐部成员信息等。

  

![](../Images/6dfaf8f18e5494cacd15ba2d3334ee8c.png)

  

如果你也是喜达屋连锁酒店的会员之一，那么现在有新的检查工具方便你快速确认你的信息是否窃取。万豪与安全公司OneTrust合作，推出了一个信息检查网站。该网站要求客户提交有限的个人信息，从而可以交叉引用确认你的信息是否出现在黑客窃取名单中。

喜来登旗下的酒店品牌包括W饭店(W Hotels)、瑞吉(St. Regis)、喜来登(Sheraton)、威斯汀(Westin)、源宿(Element)、雅乐轩(Aloft)、豪华精选(The Luxury Collection)、臻品之选(Tribute Portfolio)、艾美(Le Meridien)、福朋(Four Points)、设计酒店(Design Hotels)以及喜达屋的分时度假产品。
