KisMAC是适用于Mac OS X 的免费开源无线绊脚石和安全工具。

最新消息：


  • Mac OS 10.9 - 10.12（仅限64位）

  • ARC（仅限64位）

  • 新的GUI

  • 现代Objective-c语法

  • 重写了大部分已弃用的方法

  • 从发布中删除调试信息


如何构建：

  • git clone https://github.com/IGRSoft/KisMac2.git ./KissMac2

  • cd KissMac2

  • git submodule update --init --recursive

  • 打开KisMac2.xcworkspace

  • 建立
