大家好我是sean，今天给大家带来的是linux安装kvm虚拟机软件，废话不多说，教程开始

1.首先你需要查看下你的系统版本

\[root@localhost ~\]# cat /etc/centos-release

CentOS Linux release 7.4.1708 (Core) 

![](../Images/d009ffa882e5cd8024c8184101a121a9.png)

2. 然后检查下是否支持和开启了虚拟化。有vmx或者svm就是支持

\[root@localhost ~\]# cat /proc/cpuinfo | egrep 'vmx|svm'

![](../Images/a4c38e9595582455237f4e8d237c4b02.png)

3. 查看是否加载vkm

\[root@localhost ~\]# lsmod |grep kvm

kvm\_intel             170086  0 

kvm                   566340  1 kvm\_intel

irqbypass              13503  1 kvm

![](../Images/618dfdcd2c7ce00d4afac93346b0dc24.png)

这种情况就是加载了kvm。如果没加载输入一下命令加载

\[root@localhost ~\]# modprobe kvm

4. 关闭selinux

\[root@localhost ~\]# setenforce 0

\[root@localhost ~\]# vim /etc/sysconfig/selinux 

\[root@localhost ~\]# SELINUX=disabled

![](../Images/f0e2d9c1ddc88777a34e139eebf89d6b.png)

5. 安装kvm相关软件包

\[root@localhost ~\]# yum install qemu-kvm qemu-img \\

\>  virt-manager libvirt libvirt-python virt-manager \\

\>  libvirt-client virt-install virt-viewer -y

![](../Images/f139fb55be4fec8d4f23ca66a13af87e.png)

6. 启动libvirt并设置开机启动

\[root@localhost ~\]# systemctl start libvirtd

\[root@localhost ~\]# systemctl enable libvirtd

![](../Images/9853b78efa33f5845c3c40a687e38656.png)

7\. 进入图形化界面

\[root@localhost ~\]# virt-manager

![](../Images/3ec17808f56d6b220bdf30427f6d1369.png)

安装完事，手工，自己折腾吧。
