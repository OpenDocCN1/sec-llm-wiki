Ngrok集成的终极网络钓鱼工具。  
  
必备条件  

*   Python 2.7
    
*   来自Python的Wget
    
*   PHP  
    

  
在Kali Linux上测试 - ROLLING EDITION   
  
CLONE  
git clone https://github.com/UndeadSec/SocialFish.git  
RUNNING  
cd SocialFishsudo pip install -r requirements.txtpython SocialFish.py  
可用的页面  
Facebook：  

  

*   传统的Facebook登录页面。
    
*   使用Facebook进行高级登录。  
      
    

谷歌：  

*   传统的Google登录页面。
    
*   使用Facebook进行高级登录。  
      
    

LinkedIN：  

*   传统的LinkedIN登录页面。  
      
    

Github：  

*   传统的Github登录页面。  
      
    

Stackoverflow：  

*   传统的Stackoverflow登录页面。  
      
    

Wordpress：  

*   类似的Wordpress登录页面。
