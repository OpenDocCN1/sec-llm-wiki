Comodo Password Decryptor是一个免费程序，您可以使用它立即从Comodo Dragon浏览器恢复所有存储的登录详细信息。它支持配置文件路径的“ 拖放 ”，但实际上并不需要，因为它会在您在计算机上运行此程序时自动检测当前用户的配置文件路径。

  
它允许您将恢复的密码备份到HTML / XML / TEXT / CSV文件，还提供按用户名，密码或网站对显示的密码列表进行排序的选项。  
  
如何使用Comodo密码解密器首先，将Comodo Password Decryptor下载到您的计算机上（下载链接位于文章末尾）。然后运行“ ComodoPasswordDecryptor\_Installer.exe ”，并在计算机上安装该程序（需要工作的Internet连接）。然后启动程序，您将看到如下所示的窗口。

  

![](../Images/24459da12608d75df39c6dd6e8c41c04.png)

  

现在单击“ 开始恢复 ”按钮。所有存储的密码都将显示在程序中。
