# Linux搭建socks5代理服务器

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650451961&idx=3&sn=c3c7d34aef3672bef204bbd9e86e453b&chksm=83bbca1db4cc430b416f549e924ccebb480ca1749792689a0af79764e7ca2e3d85666a3b983c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650451961&idx=3&sn=c3c7d34aef3672bef204bbd9e86e453b&chksm=83bbca1db4cc430b416f549e924ccebb480ca1749792689a0af79764e7ca2e3d85666a3b983c&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

1、编译安装SS5需要先安装一些依赖组件

  
yum -y install gcc gcc-c automake make pam-devel openldap-devel cyrus-sasl-devel openssl-devel

  

![](../Images/97e2b76f62428039b0999c9d077d5886.png)

  

2、去官网http://ss5.sourceforge.net/ 下载SS5最新版本的源代码

wget http://jaist.dl.sourceforge.net/ ... /ss5-3.8.9-8.tar.gz

  

![](../Images/c29998677af1ebb85e2f3e223b9c103c.png)

  

3、解压后开始编译安装：

  

tar zxvf ./ss5-3.8.9-8.tar.gz  
cd ss5-3.8.9  
./configure  
make  
make install

  

4、设置SS5自启动

  

![](../Images/d769e6bddbfd7537939230eb7f0169fd.png)

  

5、在ss5.conf中找到auth和permit两行，安装下列两图进行修改  
vi /etc/opt/ss5/ss5.conf

  

![](../Images/e78ee53eefc8e9d13abc4a41b56d638d.png)

  

![](../Images/705be6c77a3d315a07f17b9c6ad207d9.png)

  

6、ss5默认1080端口，并允许任何人使用，如果要修改端口的话，请看下图  
在/etc/sysconfig/ss5这个文件中，在-b后面添加监听的ip地址和端口号

  

![](../Images/7ef09755236a74293b1c1c7fc5d64629.png)

  

7、启动ss5

  

![](../Images/7be5727b70297600dd3b7da420b3d9f0.png)

  

8、切记开放在防火墙开放ss5所使用的端口

  

![](../Images/94cdacee2f2b545f7a0ce3bc273a45c5.png)

  

9、如果需要添加用户，如下：  
回到刚才auth和permit两行参数，在两个参数的指定位置添加

uvi/etc/opt/ss5/ss5.conf

  

![](../Images/f2dc333d8ff0c88b8578e589a7990acc.png)

  

![](../Images/7cc7a51f6aaa5e11aca49f63a1b4e003.png)

  

添加账号密码，按下图格式添加  
vi/etc/opt/ss5/ss5.passwd

  

![](../Images/042ce8d9eabf94aa268e9e40d7af5224.png)

  

然后重启服务即可

  

![](../Images/287e1e564b87a7ec3bd679e5949bc2d6.png)

  

安装完成！
