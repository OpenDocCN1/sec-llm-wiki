# EtterCap简单入侵获取目标浏览图片

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650451932&idx=3&sn=3e06fd3fe6e6dc272d7e77ddfed72831&chksm=83bbca38b4cc432efa58220bb32a80d5168184934ce3770ab24a5a302546eb0a736ce3ce22aa&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650451932&idx=3&sn=3e06fd3fe6e6dc272d7e77ddfed72831&chksm=83bbca38b4cc432efa58220bb32a80d5168184934ce3770ab24a5a302546eb0a736ce3ce22aa&scene=27#wechat_redirect)

EtterCap是一个基于ARP地址欺骗方式的网络嗅探工具，主要适用于交换局域网络。借助于EtterCap嗅探软件，渗透测试人员可以检测网络内明文数据通讯的安全性，及时采取措施，避免敏感的用户名/密码等数据以明文的方式进行传输。ettercap几乎是每个渗透测试人员必备的工具之一。

  

今天演示一下EtterCap简单入侵获取目标浏览图片！首先打开kali选择应用中心下拉选项中的嗅探/欺骗选项里的EtterCap，或者在终端里输入ettercap -G 

  

![](../Images/ad971696f0682061dda9145ce935d744.png)

  

点击打开后右上选择Sniff选项里的Unified sniffing（嗅探模式）或者Ctrl＋U设置好要嗅探的网卡（一般都是eth0），开始嗅探。

  

![](../Images/682d7ebaa8fa73b5db785293268ec90b.png)

  

嗅探局域网内的所有存活主机，选择Hosts下拉选项里的Hosts list选项。

  

![](../Images/3710741f710accce0743fb69e3612b14.png)

  

![](../Images/41febca1465b1d9b36b7b16ee3c32c5c.png)

  

开启中间人监听模式，将要监听的两端分别添加到Target1、Target2，然后选择mitm下拉选项里的arp posoning选项 ，勾选sniff remote connections（嗅探并保持原连接状态）点击确定。

  

![](../Images/d0c031f5f29d3dd369e441c4c4323110.png)

  

![](../Images/2f371b54981d12df1ad0396c9f8edc4c.png)

  

![](../Images/7c9839551de5a3fc21aef84f462f88d4.png)

  

查看被监听主机之间的所有连接信息，选择View下拉选项里的Connections选项。

  

![](../Images/37109254e94c1abbe8aa26e3a29ae523.png)

  

打开一个终端，输入：ettercap -i eth0 -Tq -M arp:remote //目标ip// //自己ip//，开启中间人监听；再打开一个终端，输入：driftnet -i eth0 ，就可以截获目标正在浏览的图片了。

  

![](../Images/ca08a1298975340637835f15d8b0dc17.png)

  

![](../Images/254bc8406b2a230000df8a90ae43b2b0.png)

  

![](../Images/210af61f5826e3c4a1f12867957224d8.png)

  

目标主机和攻击者必须在同一个局域网内。在截取图片时，目标主机需得在攻击者窃听后开启浏览器浏览带图片的网页，然后才会获取到图片。
