# MSF下利用MS17-010漏洞入侵

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650451917&idx=3&sn=6263c51ef168ba6a391a3ca536980e6e&chksm=83bbca29b4cc433fe6769b4b2ddc2c16f85c5cbbe374a2bd04857be510d207e67e72110b8ea2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650451917&idx=3&sn=6263c51ef168ba6a391a3ca536980e6e&chksm=83bbca29b4cc433fe6769b4b2ddc2c16f85c5cbbe374a2bd04857be510d207e67e72110b8ea2&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

  

MS17-010是一个安全类型的补丁，MS17-010更新修复了 Microsoft Windows中的漏洞。 如果攻击者向 Microsoft 服务器消息块 1.0 (SMBv1) 服务器发送经特殊设计的消息，则其中最严重的漏洞可能允许远程代码执行。

  

![](../Images/1eda690d803a147a0e29acc1cf620af2.png)

  

搜索到了 4 个相关的插件：

1\. auxiliary/admin/smb/ms17\_010\_command

2\. auxiliary/scanner/smb/smb\_ms17\_010

3\. exploit/windows/smb/ms17\_010\_eternalblue

4\. exploit/windows/smb/ms17\_010\_psexec

  

加载

auxiliary/scanner/smb/smb\_ms17\_010  

扫描可能含有 ms17-010 漏洞的服务器 模块并show options查看参数信息

  

![](../Images/207a0c261c9d2194302d2af0f16b4247.png)

  

扫描目标网段，设置扫描线程，插件默认是1，这里设置为100，发现存在漏洞的主机（这里我们以红箭头为目标主机）

  

![](../Images/5575201c4a5ee9e716a408c99623f23c.png)

  

加载

use exploit/windows/smb/ms17\_010\_eternalblue   

模块，设置监听端口为4444，设置目标主机ip和本机ip后exploit 攻击

  

**![](../Images/31792761e75556bc2c8868e1052b402d.png)**  

  

入侵成功！

  

![](../Images/b1fcb753cc98b0499bf13fb1faec1118.png)

  

MS17-010是微软在2017年发现的第十个漏洞，俗称“永恒之蓝”，主要针对win7系统。为此，建议大家升级系统或及时打上补丁以免造成不必要的损失。
