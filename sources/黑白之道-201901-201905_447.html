Katoolin是一个基于Python的工具，可以自动安装所有Kali Linux工具。

要求：


  • Python 2.7

  • 操作系统（在Ubuntu上测试）

特征：

  • 添加Kali Linux存储库

  • 删除Kali Linux存储库

  • 安装Kali Linux工具


安装：

  • sudo su

  • git clone https://github.com/LionSec/katoolin.git&& cp katoolin / katoolin.py / usr / bin / katoolin

  • chmod x / usr / bin / katoolin

  • sudo katolin


用法：

  • 键入工具的编号将安装它

  • 键入0将安装所有Kali Linux工具

  • 回：回去

  • gohome：转到主菜单

  • 通过安装Armitage，您将安装Metasploit。
