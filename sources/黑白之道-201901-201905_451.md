1.安装前需要先关闭selinux

  
\# sed -i "s/SELINUX=enforcing/SELINUX=disabled/g" /etc/selinux/config  
grep SELINUX /etc/selinux/config

  
![](../Images/5a235c04dd9dcfb5b6a45b2a5a25d48a.png)  
  

然后重启系统 # reboot  
2.安装Apache  
install httpd  
启动httpd并且设置为开机启动  
.service  
systemctl enable httpd.service  
安装成功后，可以看到熟悉的测试界面   
如果之前已经安装我们先卸载一下  
remove php\*  
由于linux的yum源不存在php7.x，所以我们要更改yum源  
.fedoraproject/pub/epel/epel-release-latest-noarch.rpm  
rpm -Uvh https://mirror.webtatic.com/yum/el7/webtatic-release.rpm  
yum 安装php72w和各种拓展，选自己需要的即可  
yum -y install php72w php72w-cli php72w-common php72w-devel php72w-embedded php72w-fpm php72w-gd php72w-mbstring php72w-mysqlnd php72w-opcache php72w-pdo php72w-xml  
完成后我们可以新建一个PHP页面查看安装的组件  
vi /var/www/html/info.php

  
编辑为以下内容：

  

![](../Images/16a89324d1bc584b459404037f33fd22.png) 

  

重启httpd服务  
systemctl restart httpd.service  
打开网址 http://192.168.188.210/info.php 进行查看

  
![](../Images/5e0d12cc8f393d032037c110978a0b63.png)

  

4.yum安装MariaDB（个人认为其实跟MySQL没有任何区别）数据库  
同样还是利用yum命令进行安装，并且配置开机启动  
yum -y install mariadb-server mariadb  
systemctl start mariadb.service  
systemctl enable mariadb.service  
5.安装和配置zabbix服务器  
使用mysql数据库安装存储库  
\# rpm -i https://repo.zabbix.com/zabbix/4 ... .0-1.el7.noarch.rpm  
安装zabbix服务器前端代理  
\# yum install zabbix-server-mysql zabbix-web-mysql zabbix-agent  
创建初始数据库  
\# mysql -uroot -p  
password（这里密码为空，直接敲回车就好了）  
MariaDB> create database zabbix character set utf8 collate utf8\_bin; //创建zabbix库  
MariaDB> grant all privileges on zabbix.\* to zabbix@localhost identified by '123456';    //在zabbix库里给zabbix用户权限  

MariaDB>  flush privileges;   //刷新权限

MariaDB> quit;  
导入初始架构和数据。系统将提示您输入新创建的密码。

  

\# zcat /usr/share/doc/zabbix-server-mysql\*/create.sql.gz | mysql -uzabbix -p zabbix

  
为zabbix服务器配置数据库  
编辑文件vi /etc/zabbix/zabbix\_server.conf  
找到这一项DBPassword= ，然后改成DBPassword=123456 自己之前创

建的数据库密码

  

![](../Images/9bb45b3c211783a003def92c1c5f1fd8.png)   

  

为zabbix服务器配置时区  
编辑文件，取消注释并为您设置正确的时区。  

vi /etc/php.ini

然后在配置文件里搜索date.timezone  改成date.timezone = Asia/Shanghai

  

![](../Images/1ea45c24ed7f121a1dc77114578c11ab.png)

  

添加完成后，重启http服务

启动zabbix

\# systemctl restart zabbix-server zabbix-agent httpd

\# systemctl enable zabbix-server zabbix-agent httpd
