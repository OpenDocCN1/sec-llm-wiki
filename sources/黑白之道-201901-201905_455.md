**一、配置zabbix中文界面**

  

1.在zabbix服务端安装完成之后，然后我们登陆zabbix  web管理页面：

 ![](../Images/7580a9b5b291094582cc70726cbca050.png)

  

2. zabbix默认的用户名是Admin 密码是zabbix 随后我们点击sign in 登录即可--随后出现以下界面：

  

![](../Images/4345d12b5b072bbc6a91e02dc4f983fd.png)

  

3、在上图中我们发现什么都没有，不过不要方我们之后会配置，那么我们看到的是英文界面，如何换中文字体呢？选择右上角的人头 如下：

 ![](../Images/80362ddc6cc59439ff0b5b7a164efb06.png)

 ![](../Images/138a37832a7ca1fc139b6f5f13b6ef30.png)

  

只要在这儿切换一下中文就可以换成中文了

  

![](../Images/fc0d06d73133d32875b653a97212600f.png)

  

4、那么到这里我们zabbix配置中文字体其实并没有结束，因为在默认的zabbix中文字体中还是存在一些问题的-我们选择；检测中--->图形将会看到以下画面，在cpu后面的数据信息会有乱码：

 ![](../Images/6d9ee4e5d30616aa75e5b92236b6aaba.png)

  

解决乱码方法：

  

把Windows 系统中找到 C:\\Windows\\Fonts 中的楷体（常规）复制到windows桌面上

 ![](../Images/a619be2161e5a9053e3a5da219908049.png)

  

如何将 window 文件上传到 linux 上，很简单下一个软件就可以了:Winscp，下载地址上网百度一下就有

  

 ![](../Images/3769181c8343e54f00460bb365e8903d.png)

  

完成之后双击打开

 ![](../Images/2adb34e7a5bd39676da26f314af6335d.png)

  

输入主机名（ ip 地址）端口 22 用户名和密码，然后登陆

 ![](../Images/baac46d9a8aa12afb6884325e8e46877.png)

  

左面是 window 桌面，右面是 linux 根目录，直接把左面的文件拖动到右面就是把 window 文件复制到 linux 中，这样可以上传到 linux 里面了，接下来把 simkai.ttf 移动到 zabbix 安装目录的 fonts 目录下

 ![](../Images/8ee3fbc37decd6b7401649602d07d0f0.png)

  

\[root@zabbix ~\]# mv simkai.ttf /usr/share/zabbix/fonts/

\[root@zabbix ~\]# cd /usr/share/zabbix/fonts/

\[root@zabbix fonts\]# ls

graphfont.ttf  simkai.ttf

\[root@zabbix fonts\]# chmod 777 simkai.ttf

\[root@zabbix fonts\]# cp graphfont.ttf graphfont.ttf.bak

\[root@zabbix fonts\]# mv simkai.ttf graphfont.ttf

mv ：是否覆盖 "graphfont.ttf" ？ y

然后覆盖就完事儿了，查看一下，OK了

 ![](../Images/5f5dcc9867def04eecc268c0c14e3ba1.png)

  

  

到这里为止，我们的zabbix配置中文界面就已经结束了。
