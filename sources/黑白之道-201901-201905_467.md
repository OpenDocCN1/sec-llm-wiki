V3n0M是一款免费的开源扫描仪。从Baltazar的扫描仪发展而来，它采用了几项改进功能和可用性的新功能。

  

该程序用于查找和执行各种漏洞。它使用dorks清理网络并组织它找到的URL。

  

  

![](../Images/40f61cb96fbcca1e1982f7aee214bc2c.png)

  

它对执行非常有用：

· Cloudflare解析器\[Cloudbuster\]

· LFI-> RCE和XSS扫描\[LFI-> RCE＆XSS\]

· SQL注入Vuln扫描程序\[SQLi\]

· 非常大的D0rk目标列表

· AdminPage查找

· 毒素\[易受攻击的FTPs扫描仪\]

· DNS BruteForcer

· Python 3.6基于Asyncio的扫描

  
darkd0rker的官方采用重新编码，更新，扩展和改进

· 全新的！

· 最有效的Cloudflare解析器，易于使用的界面。

· 非常快速的“Toxin”易受攻击的IP扫描程序，可扫描数百万个已知易受攻击的IP服务。

· 最大和最强大的dkrk在线，14k d0rks一次搜索~Engines。

· 免费和开放/ src /

· 跨平台的基于Python的工具包

· 第425期发布于2018年2月18日发布

· 根据GPLv3许可

  

测试： ArchLinux 4.14，Ubuntu，Debian，Kali，MacOS，BlackArch，Manjaro / ArchLinux ARM Ed。Android的Termux。

  

Ubuntu用户注意事项：请确保已安装 - > sudo apt-get install python3-bs4和apt-get install python3-setuptools

否则，您可能会遇到语法错误，导致程序无法运行。

Kali用户注意事项：请确保已安装 - > apt-get install python3-dev apt-get install python-dev

  
安装说明：

· 克隆存储库：

$ git clone https://github.com/v3n0m-Scanner/V3n0M-Scanner.git

· 然后进去：

$ cd V3n0M-Scanner /

· 然后安装它：

$ python3 setup.py install --user
