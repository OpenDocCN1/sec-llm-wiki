# 社工神器之Maltego

Maltego是一款十分适合渗透测试人员和取证分析人员的优秀工具，其主要功能是开源情报收集和取证。比起其它的情报收集工具，Maltego显得格外不同并且功能强大，因为它不仅可以自动收集到所需信息，而且可以将收集的信息可视化，用一种格外美观的方式将结果呈现给使用者。Maltego允许从服务器中更新，整合数据，并允许用户很大程度上的自定义，从而实现整合出最适合用户的“情报拓扑”。

  

Maltego用于从互联网中发现数据，并用可视化的方式展现这些信息，适用于链接分析和数据挖掘。Maltego的首次于2008年5月推出。

  

在公司官网注册后，可下载免费版的maltego，注册时需要翻墙，并且最好使用国外的邮箱注册。官网地址：https://www.paterva.com/  接下来，我们来介绍下kali里如何使用Maltego来进行情报收集吧！

  

  

![](../Images/679a3e864ef9d1062212f2eddc6ea552.png)

  

打开kali后选择应用程序，在应用程序的下拉菜单中选择Social Englineering Tools 选项里的maltego 工具

  

![](../Images/3804e1607e2be028ffd670b680e2e32f.png)

  

第一次使用时需要登陆，所以需要先进行注册。

https://www.paterva.com/web7/community/community.php#tab-1

（温馨提醒：注册是要翻墙的，如果不翻的话，是不显示人机身份验证的）

  

![](../Images/a95dbca31418bf9725f8b94d95dce015.png)

  

因为我已经注册完了所以直接就可以进来了（不注册也可以进来，就是不能加载模块，不能执行任务！），首先建立一个新项目 ctrl t 或者 点击 ＋号  

  

![](../Images/0732a91bb79c43d4a4768543c8d1e053.png)

  

然后选择Domain 按住拖动到白色工作区域，然后双击编辑项目名，点击ok后maltego将会开始自动化地收集这个域名的信息，并且为所收集的信息创建一个可视化地图

  

![](../Images/faff510e85f02267e33d44ba831aeda9.png)

  

是不是很神奇，我们将其放大，以便更清晰地查看所收集的信息。你可以看到许多有用的信息，比如DNS信息，邮件服务器，IP，用户，电子邮箱ID，网络等。这里我指简单的介绍一下，如果有缘我们在聊！
