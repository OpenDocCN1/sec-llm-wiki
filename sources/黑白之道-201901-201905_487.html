1、Metasploit：渗透测试仪指南


 

Metasploit Framework是一个众所周知的用于快速发现、利用和分享漏洞的工具，并且被各地的安全专业人员使用。但这并不真正适合那些刚开始从事该领域的人，因为可能很难掌握。然而，本书通过教您如何使用框架并帮助您与Metasploit贡献者社区进行交互来填补这一空白。

 

通过阅读本书，您将了解框架的约定、接口和模块系统。您还将学习高级渗透测试技术，包括网络侦察和枚举、客户端攻击、无线攻击和有针对性的社会工程攻击。

 

这本书甚至触及了零天研究的漏洞发现，它会教你如何编写一个模糊程序，将现有的漏洞移植到框架中，它也会教你如何覆盖你的轨道，这样你就不会被抓到！

 

本指南对希望保护自己的网络或测试其他人的网络的任何人都有用。

 

2、  黑客攻击和渗透测试的基础知识

 

 

这本书为您提供了在没有任何先前黑客经验的情况下完成渗透测试或从头到尾执行道德黑客所需的步骤，因此它是针对完全初学者的。

 

您将学习如何正确地利用和解释现代工具的结果，如Backtrack和Kali Linux、Google侦察、MetaGooFil、DNS询问、Nmap、Nessus、Metasploit、Social Engineer Toolkit(SET)、w3af、Netcat、后期开发策略、黑客防御者rootkit等等。

 

本书提供了简单而干净的解释，并提供了进行渗透测试或黑客攻击的分步指南，通过阅读本书，您 将更好地了解攻击性安全性，这将有助于您作为一名测试者的职业生涯。

 

3、Shellcoder的手册：发现和利用安全漏洞

 

 

这是一本经典书籍，解释了漏洞利用如堆栈溢出，堆溢出和格式字符串漏洞的工作原理。本书还讨论了  堆栈保护以及如何规避堆栈保护。  这本书是专业编写的，涵盖了一些非常先进的概念，并包含许多十六进制字节，代码和内存地址。因此，您需要很好地理解C和C ++等语言以及汇编语言才能理解本书。


所以如果你正在寻找一本初学者书，这可能不适合你。但如果你花时间仔细阅读它，独立研究每个概念，那么你就会像专业人士一样思考。

 

4、Nmap网络扫描：网络发现和安全扫描的官方Nmap项目指南

 

 

Nmap Network Scanning是Nmap Security Scanner的官方指南，Nmap Security Scanner是一个免费的开源实用程序，全世界数以百万计的测试人员使用它来进行网络发现，管理和安全审计。


本书从端口扫描基础入手，因此适合初学者，但后来开始详细介绍高级黑客使用的低级数据包制作方法。因此，所有级别的安全和网络专业人员都可以使用它。


本书中包含了参考指南，其中记录了每个Nmap功能和选项，但本书还演示了如何应用它们来快速解决现实任务，例如破坏防火墙和入侵检测系统，优化Nmap性能以及自动执行常见网络任务使用Nmap脚本引擎。

 

2、鬼魂在线：我的冒险是世界上最想要的黑客

 

 

我把这本书包括在内并不是因为它会让你成为一个更好的黑客，而是为那些渴望进入这个领域的人提供灵感。这本书是关于凯文米特尼克的书- 这是历史上最难以捉摸的黑客/社会工程师之一。他访问了世界上最大的公司的计算机和网络，并且能够侵入电话交换机，计算机系统和蜂窝网络。


这本书涵盖了米特尼克所做的一切，从他开始黑客攻击到他最后被联邦政府逮捕的时间，以及之后的一点点。这本书会吸引你的注意力，很幽默，而且整体阅读非常好。
