# 近百万条个人信息遭泄露 杭州警方刑拘8人

先生，市中心精装修低总价商品房了解下？”“商铺有没有兴趣了解下？”

  

类似的推销电话，大家都经常接到吧，很烦对不对？前段时间，傅先生也接到了类似的骚扰电话，但是他更懊恼，因为他接到的是养生类的产品推销电话。

  

这些骚扰电话是这样的：

  

“傅先生，你最近身体还好吗，需要进行肿瘤筛查吗？”

“傅先生，干细胞检查产品需要介绍一下吗？”

“傅先生，我们有养生禅修了解一下？”

……

  

傅先生是杭州一家公司的老总，平时工作很忙，经常接到这样的骚扰电话，他恼了！“别人推销房子商铺，还可能被认为有钱；可我接到的骚扰电话，他们是认为我有病？”

  

傅先生很生气，向杭州拱墅公安报了警。

  

9月9日，拱墅公安雷霆出击，把骚扰傅先生的这伙人抓了，一共8人，全部刑事拘留。

  

为啥这么严重？因为这伙人手上的个人信息，都是非法得来的。

  

![](../Images/89d9ea598a8881393bcf8803008c8ad5.png)

  

**频繁电话推销**  

**牵出一个“不能说的秘密”**

  

事实上，除了傅先生，今年8月以来，拱墅警方陆续接到多个电话举报，内容都是一样的，被电话骚扰了。

  

而且，被骚扰的内容都跟傅先生差不多，而被骚扰的对象都是老总级别的高管级人物。

  

民警初步侦查发现，频繁骚扰这些人的，是杭州某德健康科技有限公司，而这个公司有一个“不能说的秘密”。

  

该公司位于杭州城北的一个写字楼内，规模不大，六七十个平方米，一个隔间里，有七八个工位。

  

老板董某某是个80后，其他7名员工也都是80后、90后，4男4女。公司经营的业务就是干细胞检查、肿瘤筛查、禅修等健康类服务的推广，还有一些延伸出来的保健品（酵素等）销售。

  

说白了，这是一家“中介公司”，他们帮上级客户公司电话推广各类健康服务项目。如果有老板感兴趣，他们就把这个老板的电话交给上级客户公司，从中赚取差价（也可以说是介绍费），同时自己也销售一些保健品。

  

他们每天的工作就是“上网聊天”，然后给“客户”打电话，每个人办公桌上还放着一叠叠“客户”资料。  

  

这些“客户”资料的信息很高级，基本都是公司法人代表、管理层人员，姓名、工作单位、联系方式一清二楚，有些甚至连身份证号码都有。

  

9月9日，拱墅网警大队与上塘派出所对涉嫌侵犯公民个人信息的这家公司进行了统一抓捕。现场抓获涉案人员7名，扣押电脑8台、手机19部及大量纸质书证，含有公民个人信息的表格数量4000余份，查获公民个人信息数据多达近百万条。

![](../Images/72293f3a3e24d1bdb93da481474ecd8f.png)

  

**最多的一个人手里**  

**有30万条个人信息，全是企业高管的**

**这些人是从何处得到的个人信息？**

  

通过民警的调查，这家公司获取公民个人信息的途径有三种。

  

第一种：前期积累。员工中有几个人之前是在教育培训机构里面上班的，有一些签到登记的个人信息，以及个人自己积累的信息。

  

第二种：网上互换个人信息，这也是这家公司主要的个人信息获取途径。

  

“网上有一些微信群、QQ群，叫某某地区老板群，有些直接就叫信息互换群，他们通过群里的信息互换获取个人信息。这些信息不局限于杭州地区，全国各地的都有。我们查证过，最多的一个员工手上有30多万条个人信息，而且都是公司、企业的高管、老板、法人。”

  

他们一开始并没有那么多客户信息，采取的是一个“空手套白狼”的方式。

  

这家公司的员工同时跟A、B两个人联系，说他手上有客户信息可以交换。

  

员工会要求A把信息发给他，拿到A的信息后，员工转手将A的信息发给B，B会将自己的信息发过来。A其实拿到的是B的信息，B拿到的是A的信息，而这个员工，同时拥有了A、B两个人的信息。

  

他们靠这个方法迅速掌握了大量的客户信息。

  

另外有部分个人信息，是买来的。

  

这家公司于2017年年底成立，虽然大多数人不会听信电话销售，但偶尔也有“老板”向他们买一些保健品或者体验项目，往往这样一笔生意就能赚3万多元。

  

所以他们不怕“生意少”，一年能做成几笔就能养活自己了。而且，他们会对“老板”的信息进行严格筛选，如果只是一般的小老板，不会继续打电话，如果是大老板，他们会不停跟进。

  

据了解，通过这样的营销模式，这家公司每年获利至少十几万元。

  

目前，这8名人员都以涉嫌侵犯公民个人信息罪，被拱墅警方刑事拘留。涉及到交换个人信息的群以及其他网络上侵犯个人隐私的行为，拱墅公安也在进一步跟进中，该案还在进一步深挖中。
