Veil是一种工具，旨在生成绕过常见防病毒解决方案的metasploit有效负载


GitHub项目地址：https://github.com/Veil-Framework/Veil


kali下的安装：apt -y install veil


apt-get install wine32 --fix-missing


/usr/share/veil/config/setup.sh --force --silent


安装过程漫长





使用./Veil.py -h查看帮助



启动MSF监听

msfconsole-r /var/lib/veil/output/handlers/admin.rc
