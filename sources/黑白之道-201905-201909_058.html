在我们搭建一台机器，做完系统，上来我们都需要来创建一个新的虚拟网卡，来进行启动起来，有的时候，当你做了某些修改的时候，他不会去自动启动，需要手动启动，这里需要一些命令来重启或者手动收藏。


重启的命令，最常用的有五个，这里我们来说一下这五个命令。


用ifconfig命令启动关闭网卡



Ifconfig是用来配置网卡的命令 在系统启动的过程中 我们经常使用这个命令来启动网卡 ifconfig也还可以提供很多网卡的信息 ip之类的 



常用语法也比较简单

Ifconfig [NIC/NAME] Down/Up


举例说 我们网卡eth1 要启动这个网卡 就把eth1家中中间去Ifconfig eth1 Down/Up



输入下# ip a | grep -A 5 "eno16777736:"查看网卡是否启动或者关闭




用ifdown ifup来启动禁用网卡



这个也是比较简便跟常用的命令


Ifdown禁用网卡 ipup启动网卡



查看下是否禁用了

这个命令有一个问题 就是不支持enpXXX命名的网卡



用ip命令来启动网卡


Ip是用来管理网卡，代替，ifconfig这个不常用，也没有ip这个命令方便，主要还是功能方面的问题，ip命令比ifconfig多了许多强大的功能


Ip link set Down/up这个命令来启动或者禁用



用nmcli命令来启动关闭网卡

nmcli 是一个控制 NetworkManager 并报告网络状态的命令行工具。也是一中用作nm-appplet或者其他图形化的替代品，这个命令大多数都是使用配置名称，不像之前的都是再用设备名称这些，所以我们来说一下执行命令来获得网卡的配置名称



Nmcli con show



这样就可以查看到网卡的配置名称了


nmcli con Down/Up来开启或者关闭网卡


注意一下 在后面加的是配置名称
