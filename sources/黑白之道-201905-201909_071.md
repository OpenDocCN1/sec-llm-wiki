# 18年的漏洞仍未彻底修复：黑客仍能几秒内破解特斯拉Model S

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650456970&idx=2&sn=7f92b6b7f9a07aeca372519a4604c617&chksm=83bba66eb4cc2f78e975f56dbad51ab8c289c0f680c0786c660f120ca8d49b469aa834f4bdbf&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650456970&idx=2&sn=7f92b6b7f9a07aeca372519a4604c617&chksm=83bba66eb4cc2f78e975f56dbad51ab8c289c0f680c0786c660f120ca8d49b469aa834f4bdbf&scene=27#wechat_redirect)

破解一辆特斯拉Model S需要多长时间？在2018年安全团队COSIC就曾演示过在短短几秒内完成破解！这主要利用了特斯拉 Model S中PKES（无钥匙进入系统）与无线钥匙的认证过程中存在的安全问题，从而让黑客可以在几秒内复制汽车钥匙将汽车偷走。随后特斯拉立即做出反应解决了这个问题并转换到新的遥控车钥匙。

  

![](../Images/7763661212154f776667d986a01d818d.png)

![](../Images/25a6b12fd79e49cc02515cdb8813d027.png "null")

不过根据《连线》本周二发布的一篇报道称，特斯拉最新发布的车钥匙同样非常脆弱。来自比利时大学的科研团队发现新款车钥匙中同样存在原先的漏洞，不过破解过程需要更长的时间并且需要靠的更近才能完成。
