# GitMiner 一款自动化的高级敏感内容挖掘工具

GitMiner是一款自动化的高级敏感内容挖掘工具。此工具旨在通过代码或代码片段在github搜索页面进行挖掘，并以此来证明公共存储库的脆弱性，以及将包含敏感信息的代码存储在其中所带来的安全隐患。  

  

![](../Images/6c98cbbb194103e9e6fd41a98530fe61.png)

  

**要求**  
lxml  
requests  
  
**安装**  
git clone http://github.com/danilovazb/GitMiner  
sudo apt-get install python-requests python-lxml   
OR  
pip install -r requirements.txt  
  
git clone http://github.com/danilovazb/GitMiner  
cd GitMiner  
docker build -t gitminer .  
docker run -it gitminer -h
