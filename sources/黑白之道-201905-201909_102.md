# CentOS7.x安装Apache-Tomcat9

1.安装Apache-Tomcat9之前需要安装jdk:  

https://bbs.77169.net/forum.php?mod=viewthread&tid=373666&highlight=jdk

  
2.下载Tomcat9压缩包  
进入Apache Tomcat官网，进行下载

https://tomcat.apache.org/download-90.cgi

  

![](../Images/556ce24c90a62a292049c227d21ff33d.png)

  

用winscp工具上传到服务器/usr/local 目录下

  

![](../Images/8a31b5637427691be515a17c01e094ae.png)

  

3.新建目录并解压  
cd /usr/local mkdir tomcatcp apache-tomcat-9.0.22.tar.gz /usr/local/tomcattar -zxvf apache-tomcat-9.0.22.tar.gz解压完成后查看目录：

  

![](../Images/f8d26aa5f6b6b7c1c518da105a153978.png)

  

4.启动Tomcat  
进入到bin目录下，启动startup.shcd bin  
./startup.sh  
ps -ef | grep tomcat 出现以下信息，则表示服务启动成功

  

![](../Images/2110a1c6bb79efcc81930afbc9773e14.png)

  

开放防火墙端口8080  

firewall-cmd --zone=public --add-port=8080/tcp --permanent  
firewall-cmd --reload  
都做完之后就可以访问了192.168.188.9:8080
