什么是Xampp?

XAMPP（Apache MySQL PHP PERL）是一个功能强大的建站集成软件包。这个软件包原来的名字是 LAMPP，但是为了避免误解，最新的几个版本就改名为 XAMPP 了。它可以在Windows、Linux、Solaris、Mac OS X 等多种操作系统下安装使用，支持多语言：英文、简体中文、繁体中文、韩文、俄文、日文等

环境：Ubuntu 16.05

安装xampp

下载：wget 

 https://sourceforge.net/projects ... .31-2-installer.run



下载完成后cd切换到xampp安装文件所在目录下


首先修改文件权限：chmod 777 *.run

执行可执行文件进行安装：sudo ./xampp-linux-x64-7.1.31-2-installer.run会

弹出一个图形界面如图，与主机名称一样，点击next：



看到以下界面为安装完成：



启动xampp：/opt/lampp/lampp start



图形化启动：/opt/lampp/./manager-linux-x64.run



启动mysql：sudo /opt/lampp/bin/mysql -uroot -p
