**第一步安装**

\[root@localhost ~\]# yum install -y docker

对了 如果你不确定你之前装没装过docket 可以先检查一下是否装过

\[root@localhost ~\]# yum list installed | grep docker

  

  

删除命令： \[root@localhost ~\]# yum remove –y docker.x86\_64

\[root@localhost ~\]# yum remove –y docker-client.x86\_64

\[root@localhost ~\]# yum remove –y docker-common.x86\_64

emmm 安装过程可能有一些慢 等一会就好了

  

![](../Images/b26cc2e92a8e35b56a935ff35bd72314.png)

  

我这里装好了 我们来启动它

\[root@localhost ~\]# systemctl start docker.service

如果想要停止的话 输入systemctl stop docker

查看当前你的docket的状态

  

![](../Images/c2d1e007097b42b528c62c3548b2d37f.png)

  

现在我们来说一下docket镜像

首先我们要从docket hub拉取镜像

https://hub.docker.com/

我是在公用仓库下载的镜像 慢的很  国外下载很快的

  

![](../Images/9983fe37919628fc30bcdcc443c9512d.png)

  

还有一个拉取方法 就是用ustc拉取 小编是强烈推荐这种方法 

在机器编辑vi /etc/docker/daemon.json 直接这么输入就好 这样没有这个文件的话也会自动创建 在这个文件中 加入

"registry-mirrors":\["https://docker.mirrors.ustc.edu.cn"\]  

然后记得要重启服务 

systemctl restart docker 之后在通过pull拉取 这速度是嗖嗖的

镜像拉取完了 我们来列出

  

![](../Images/4fee5c7b3f50729b5706b5ea75db8d38.png)

  

  

导入导出

导出镜像：docker save 镜像 > /root/xx.tar.gz

导入镜像：docker load < /root/xx.tar.gz

删除

  

![](../Images/32a76e4463d123a027d589ce5ab75116.png)

  

交互式启动容器：docker run -it --name 容器名称 镜像 /bin/bash

退出容器：exit

守护进程式启动：docker run -d --name  容器名称  镜像

停止容器：docker stop mytomcat

重启：docker start 容器名称或者容器ID

删除：删除指定容器：docker rm 容器名称或者容器ID

删除所有容器：docker rm 'docker ps -a -q'

查看：docker ps：查看正在运行的容器

docker ps –a：查看历史运行过的容器
