# Centos7.x安装jdk 1.8完整安装步骤

**一、下载linux版jdk1.8的jar包：****jdk-8u221-linux-x64.rpm**

  

可访问jdk官方网站

https://www.oracle.com/technetwo ... nloads-2133151.html

  

根据不同的linux系统位数来选择rpm包；下载时注意需选择Accept License Agreement，先选择同意才能下载包。  
  

![](../Images/8f986107ad6c191f900913f4294c0b01.png)

  
**二、用winscp工具将jdk-8u221-linux-x64.rpm上传至/usr目录下**  
  

![](../Images/6030fe9200a3185fdf040bf41745ad82.png)

  

**三、进入/usr目录下解压安装jdk，默认会装在/usr/java目录下**  
  
\[root@localhost usr\]# sudo rpm -ivh jdk-8u181-linux-x64.rpm   
  

![](../Images/35cf8c61eca0a4aaa28cf79743f3cc1d.png)

![](../Images/497fefdbc2ad433eb1f1758894a4c30d.png)

  

**四、配置环境变量**

  

1、编辑profile文件

  

\[root@localhost java\]# sudo vim /etc/profile

  

2、添加配置：其中JAVA\_HOME为Java的安装位置  
1.export JAVA\_HOME=/usr/java/jdk1.8.0\_221-amd64  
2.export CLASSPATH=.:$JAVA\_HOME/jre/lib/rt.jar:$JAVA\_HOME/lib/dt.jar:$JAVA\_HOME/lib/tools.jar  
3.export PATH=$JAVA\_HOME/bin:$PATH  
  

![](../Images/f404222ed3767a57d0cfde2324b13f22.png)

  
3、保存退出后，执行source命令生效：  
  
\[root@localhost java\]# source /etc/profile  
  
**五 、测试是否成功**  
  
\[root@localhost tool\]# java -version  
  

![](../Images/37aa2265e86f46f6d69e3aee8484889e.png)

  
到这里就已经说明安装成功了。
