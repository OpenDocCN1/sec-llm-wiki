Galileo是一个用于Web应用程序的开源渗透测试工具，可帮助开发人员和渗透测试人员识别和利用其Web应用程序中的漏洞。  

  

![](../Images/d256b8d114eed988e265f4609f982efe.png)

  
安装$ git clone https://github.com/m4ll0k/Galileo.git galileo$ cd galileo

安装要求

$ python2 -m pip install -r requirements.txt

要么

$ apt-get install python-pysocks

对于窗户

$ python2 -m pip install pysocks

命令

$ python2 galileo.py用法
