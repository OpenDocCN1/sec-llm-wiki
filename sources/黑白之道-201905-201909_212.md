描述  
Project iKy是一个从电子邮件中收集信息并在一个漂亮的可视界面中显示结果的工具。  
  
安装  
克隆存储库  
git clone https://gitlab.com/kennbroorg/iKy.git  
  
必须安装Redis  
wget http://download.redis.io/redis-stable.tar.gz  
tar xvzf redis-stable.tar.gz  
cd redis-stable  
make  
sudo make install  
  
并打开终端中的服务器  
redis-server  
必须在requirements.txt中安装库  
pip install -r requirements.txt  
  
然后在目录后端的另一个终端中打开Celery  
./celery.sh  
  
最后，再次，在另一个终端打开目录后端的后端应用程序  
python app.py  
  
安装nodejs  
  
Dependencias  
在目录前端内部安装依赖项  
npm install  
  
打开前端服务器  
最后，要运行前端服务器，请执行：  
npm start  
  
浏览器  
在此网址中打开浏览器
