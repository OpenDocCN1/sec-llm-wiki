快速开始

首先安装Pown：

$ npm install -g pown @ latest  

直接从Pown调用：

$ pown ducta  

否则，从项目的根目录在本地安装此模块：

$ npm install @ pown / duct --save  

完成后，调用pown cli：

$ ./node\_modules/.bin/pown-cli duct  

您还可以使用全局pown在本地调用该工具：

$ POWN\_ROOT =。管道
