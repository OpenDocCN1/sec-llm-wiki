Shellsum是一种防御工具，可通过md5sum检测本地目录中的Web shell。以下是此工具的一些功能。

  

**特征**  
速度快  
轻量级  
大数据库  
表输出

  

**安装**  
git clone https://github.com/ManhNho/shellsum.git  
chmod 755 -R shellsum/  
cd shellsum/  
pip install -r requirements.txt  
  
**命令**  
python shellsum.py
