一些企业的网站大都会用到cms。cms对于企业来说确实很好用，不过随之而来的也是cms所带来的漏洞


wordpress，动易，织梦，帝国，dz，这些cmd每个版本都是有漏洞的。


不过不用慌，我现在就介绍怎么检查这些网站的漏洞


好的环境都是要自己搭建的，先弄一台服务器


git clone https://github.com/iceyhexman/onlinetools.git


先安装git  之后直接克隆到本地目录

cd onlinetools


进入文件夹

pip3 install -r requirements.txt


需要先安装python3 和pip3  安装了之后别忘了两个都需要创建软连接
之后就安装所需的环境的包

nohup python3 main.py &

设置后台进程，让他在后台安静的运行，
