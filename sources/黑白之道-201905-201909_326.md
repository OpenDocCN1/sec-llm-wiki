ApacheBench 是 Apache 服务器自带的一个web压力测试工具，简称ab。ab又是一个命令行工具，对发起负载的本机要求很低，根据ab命令可以创建很多的并发访问线程，模拟多个访问者同时对某一URL地址进行访问，因此可以用来测试目标服务器的负载压力。总的来说ab工具小巧简单，上手学习较快，可以提供需要的基本性能指标，但是没有图形化结果，不能监控。  

  

1、安装依赖

  

yum -y install apr-util

  

yum -y install yum-utils

  

![](../Images/33a7b60c15ad25d08c79b67168d405df.png)

  

2、创建临时文件夹

  

cd /usr/local

  

mkdir httpd

  

cd httpd

  

  

![](../Images/be86d19fa731ba6bf0f72269678f60af.png)

  

3、下载安装包

  

yumdownloader httpd-tools\*

  

rpm2cpio httpd-tools-\*.rpm |cpio -idmv

  

![](../Images/a76c4cb36aadd477d670c19b4c80ce97.png)

  

4.移动ab文件夹到系统bin目录

  

mv usr/bin/ab /usr/bin/ab

  

![](../Images/d2cb3cf4e348f9b9e1549d27e1073ce0.png)

  

5.删除创建的临时文件夹

  

cd ..

  

rm -rf httpd

  

到这里已经基本安装完成了，下回我们再来说说他的使用及简单的进行一些压力测试。
