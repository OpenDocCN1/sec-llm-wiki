**安装**

**要求： **  

BeautifulSoup4pip install bs4  
要求pip安装请求  
python 3.7  
命令：git clone https://github.com/menkrep1337/XSSConchmod 755 -R XSSConcd XSSConpython3 xsscon.py --help

  
**用法**

基本用法：

python3 xsscon.py -u http://testphp.vulnweb.com  
高级用法：python3 xsscon.py --help  
  
主要特点

*   抓取网站上的所有链接（抓取引擎）
    
*   支持POST和GET表单
    
*   许多可以自定义的设置
    
*   高级错误处理
    
*   多处理支持。![](../Images/83a1de995836bccabba32f91bf6a07fd.png)
    
*   等等....
