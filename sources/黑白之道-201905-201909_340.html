FinalRecon是一个用于网络侦察的快速而简单的python脚本。它遵循模块化结构，因此将来可以轻松添加新模块。接下来我们就试试这个工具的强大功能吧！


安装 git clone https://github.com/thewhiteh4t/FinalRecon.git



进入FinalRecon所在目录  cd FinalRecon



安装依赖pip3 install -r requirements.txt



运行 python3 finalrecon.py -h 查看有哪些功能



用法：finalrecon.py [-h] [--headers] [--sslinfo] [--whois] [--crawl] [--full] 网址


可选参数：  


- help显示此帮助消息并退出  


--headers获取标题信息  


--sslinfo获取SSL证书信息  


--whois获取Whois查询  


- 抓取抓取目标网站  


--full获取完整分析，测试所有可用选项


先来查看一下baidu的whois信息 python3 finalrecon.py --whois www.baidu.com


在查看下ssl证书 python3 finalrecon.py --sslinfo www.baidu.com 效果还可以！



还有检查标题、抓取目标等功能你们自己试试吧！
