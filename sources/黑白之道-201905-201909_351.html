什么是Osmedeus？


Osmedeus允许您自动运行一系列令人敬畏的工具，以针对目标进行侦察和漏洞扫描。


使用
如果您不知道自己在做什么，只需输入以下命令或查看高级用法：
./osmedeus.py -t example.com

安装
git clone https://github.com/j3ssie/Osmedeus
cd Osmedeus
./install.sh
这个安装只关注Kali linux，在Wiki页面上查看更多安装。
