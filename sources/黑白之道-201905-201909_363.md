此工具将使您的基本测试任务如信息收集，安全审计和报告，因此该工具将完全自动完成每项任务。

  

工具使用指南

  
使用下列命令将项目代码克隆至本地：  
git clone https://github.com/baguswiratmaadi/reverie  
  

进入项目目录：  
cd reverie  
  

提供完整权限：  
chmod 777 \*.sh  
  

无需安装即可运行reverie：  
./reverie.sh  
  

如需安装，可直接运行install.sh文件：  
./install.sh
