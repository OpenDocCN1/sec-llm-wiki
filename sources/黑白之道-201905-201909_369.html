FinalRecon是一个用于网络侦察的快速而简单的python脚本。它遵循模块化结构，因此将来可以轻松添加新模块。



特征



FinalRecon提供详细信息，例如：



标题信息






WHOIS查询






SSL证书详细信息




在SSL证书中找到标志



网络爬虫





将来会增加更多模块


经过测试


Kali Linux 2019.1BlackArch Linux


安装


git clone https://github.com/thewhiteh4t/FinalRecon.git


cd FinalRecon


pip3 install -r requirements.txt


用法


python3 finalrecon.py -h


finalrecon.py [-h] [--headers] [--sslinfo] [--whois] [--crawl] [--full] 网址


可选参数：  


- help显示此帮助消息并退出  


--headers获取标题信息  


--sslinfo获取SSL证书信息  


--whois获取Whois查询  


- 抓取抓取目标网站  


--full获取完整分析，测试所有可用选项


＃检查标题

python3 finalrecon.py --headers < url >


＃检查ssl证书

python3 finalrecon.py --sslinfo < url >


＃查看whois信息

python3 finalrecon.py --whois < url >


＃抓取目标

python3 finalrecon.py --crawl < url >


＃完全扫描

python3 finalrecon.py --full < url >
