# 微软修复了五个SandboxEscaper零日漏洞中的四个

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650455164&idx=2&sn=68442e3e978c901812a85ae66d279bb7&chksm=83bbd998b4cc508e7fbd4e6e8d012836472034687b1d082b81d3ae2af2bd7675caf123b237bb&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650455164&idx=2&sn=68442e3e978c901812a85ae66d279bb7&chksm=83bbd998b4cc508e7fbd4e6e8d012836472034687b1d082b81d3ae2af2bd7675caf123b237bb&scene=27#wechat_redirect)

> **文章来源：****cnBeta.COM**

过去几个月，微软一直深受“沙箱逃逸”（SandboxEscaper）零日漏洞的困扰。因为黑客那边不按常理出牌，不仅没有给出 90 天的预备披露时间，还接二连三地抛出了针对 Windows 操作系统的特权提升漏洞。万幸的是，尽管准备工作有点仓促，该公司还是设法修复了已流出概念验证代码的五个漏洞中的四个，且目前尚无被人在野外利用的报道。

  

![](../Images/722488065f50e9d1e9f7118a2b399495.png)

  

（SandboxEscaper 概念验证，via MSPU）

  

![](../Images/be385d809013dd92ce3b3edc3feeaedf.png)

  

据悉，已修补的这四个 SandboxEscaper 漏洞分别为：

● CVE-2019-1069 | 任务计划程序的特权提升漏洞

● CVE-2019-1053 | Windows Shell 的特权提升漏洞

● CVE-2019-1064 | Windows 特权提升漏洞

● CVE-2019-0973 | Windows Installer 特权提升漏洞

  

鉴于漏洞的普遍严重程度，还请诸位及时安装每月发布的安全更新。
