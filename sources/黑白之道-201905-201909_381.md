# Scanless 一款匿名端口扫描的Pentesting工具

网络渗透测试通过发现开放端口，对实时系统进行故障诊断，端口扫描和抓取系统横幅来确定网络状况的漏洞。端口扫描程序是用于检查服务器或主机的开放端口的应用程序。开放端口是攻击者进入和安装恶意后门应用程序的门户。

  

非扫描

  

它是用于开发网站的命令行实用程序，它将代表您执行端口扫描。此工具可帮助渗透测试的早期阶段在一堆上运行端口扫描，并使其不会从您的IP地址返回。

  

端口扫描仪支持

  

yougetsignal

viewdns

hackertarget

ipfingerprints

pingeu

spiderip

portcheckers

t1shopper

  

使用端口扫描

  

它是一个简单易用的工具，可以在几分钟内获得结果，也可以保持匿名

  

下载地址：

https://github.com/vesche/scanless/blob/master/README.md

  

安装无扫描和帮助

  

sudo pip install scanless   
scanless -help

  

![](../Images/ed968adf20a659d9189dd2878b2ff91f.png)

  

列出所有支持的扫描仪

scanless -l

  

![](../Images/e9687c70cb49bcda5be14b008fb82510.png)

  

运行扫描 

scanless -s yougetsignal -t domain.com

  

![](../Images/30be66aa5114a757bf2c8cf5064cb5e8.png)

scanless -s pingeu -t domain.com  

  

![](../Images/e8f175fb42127ce6a97582d3263b1af4.png)
