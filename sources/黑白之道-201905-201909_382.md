今天给大家介绍一款由Python编写的信息收集工具----Webkiller，当网站需要简单的信息收集时，每次都要手动收集，利用大型工具也很浪费时间，这时不妨试试这款工具。

  

![](../Images/e45aebd0d48c3f3bd86d4c6c074b6e3f.png)

  
首先在kali里安装工具 git clone 

https://github.com/ultrasecurity/webkiller.git  
  

![](../Images/6af871e82a0f2e8089c446aae6682ee4.png)

  
进入webkiller所在的目录 cd webkiller  
  

![](../Images/692594fe3c5199a30bc98f4c61ae7e0b.png)

  
安装依赖 pip install -r requirements.txt  
  

![](../Images/19a78648f0b4eb8139c9d81665640244.png)

  
运行webkiller   python webkiller.py   
  

![](../Images/3e88dd0b19510e4785aa230cbfdea25d.png)

  
安装好后看看这个工具都有什么功能，英文是不是看不懂？没事贴心地找了一张对应翻译图！  
  

![](../Images/445e6402c3be1ba083b0792f453c688f.png)

  
先whois一下www.baidu.com，速度很快信息也很详细！  
  

![](../Images/e58824b89fca31c8a88cc3db6059aed9.png)

  
再来看看端口扫描，用了1.64秒准不准就要问一下百度了！  
  

![](../Images/3c76f6f39062a6ddf2baa4f0cdcc6b57.png)

  
总的来说这款工具很不错，功能很多，如果有兴趣的话就试试吧！
