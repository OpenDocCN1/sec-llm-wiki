SPARTA - 网络基础设施渗透测试工具

SPARTA是一个python GUI应用程序，它通过帮助渗透测试程序进入扫描和枚举阶段来简化网络基础架构渗透测试。它允许测试人员通过点击访问他的工具包并以方便的方式显示所有工具输出来节省时间。如果花费很少的时间来设置命令和工具，则可以花更多的时间专注于分析结果。





特征：

  • 从SPARTA运行nmap 或导入 nmap XML输出。

  • 透明的分阶段nmap ：快速获得结果并实现全面覆盖。

  • 每个服务的可配置上下文菜单。您可以配置在已发现服务上运行的内容。可以从终端运行的任何工具都可以从SPARTA运行。

  • 只需单击鼠标，即可在范围内的所有主机上运行服务上的任何脚本或工具。

  • 定义服务的自动化任务（即，在每个HTTP服务上运行Nikto，或在每个SSL服务上运行sslscan）。

  • 默认凭据检查大多数常见服务。当然，这也可以配置为自动运行。

  • 确定已测试基础架构上的密码重用。如果Hydra找到任何用户名/密码，它们将存储在内部单词列表中，然后可以在同一网络中的其他目标上使用（突发新闻：系统管理员重用密码）。

  • 能够标记您已经处理过的主机，这样您就不会浪费时间再次查看它们。

  • 网站截图接受者，这样你就不会在不那么有趣的网络服务器上浪费时间。


    要求：

  • Kali Linux（也应该在基于Debian的系统中工作）

  • nmap（用于添加主机）

  • 九头蛇（用于爆破）

  • cutycapt（截图）

在Kali Linux中，这些可以安装：
apt-get install nmap hydra cutycapt
在Kali中，为了确保您拥有SPARTA默认配置使用的所有工具，请使用：
apt-get install ldap-utils rwho rsh-client x11-apps finger
