当用户需要在目标计算机上启用远程桌面时，可以在内部渗透测试期间使用PeekABoo工具。它使用PowerShell远程处理来执行此任务。注意：默认情况下，在所有Windows操作系统上禁用远程桌面。  
  
该工具仅在启用WinRM时有效。由于Windows Server 2012 WinRM默认在所有Windows服务器操作系统上启用，但在客户端操作系统上不启用。注意：默认情况下，在所有Windows操作系统上禁用远程桌面。用户需要服务器上的本地管理员密码或管理员权限才能在目标计算机上启用RDP。  

  

![](../Images/970e79a79e5c6c3d3882b4161f82ecb8.png)

如何安装？-  git clone   

https://github.com/Viralmaniar/PeekABoo.git-cdPeekABoo-python peekaboo.py我该如何使用它？

*   按1：这会将PowerShell设置为不受限制的模式。
    
*   按2：启用Remote Desktop目标计算机并显示RDP端口（3389）状态。
    
*   按3：它禁用Remote Desktop目标机器上的。
    
*   按4：退出程序。  
    

  
我的Windows机器没有安装Python？  

*   从Github的发布部分下载exe文件以及此处提供的PowerShell文件，或者在查看源代码后使用PyInstaller自行完成。
    
*   peekaboo.py使用Pyinstaller编译成可执行文件
    
*   PyPI是在PyPI上提供的。你可以通过pip安装它：
    
      
    

pip install pyinstaller
