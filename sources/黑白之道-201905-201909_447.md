Kostebek是一种侦察工具，它使用公司的商标信息来发现他们的领域。  
安装  
  
sudo apt-get -y install python3-pip   
pip3 install -r requirements.txt  
  
下载Chromedriver的最新版本并配置您的驱动程序路径  
#sudo apt-get install unzip   
#sudo unzip /tmp/chromedriver.zip chromedriver -d / usr / local / bin /  
  
下载最新版本的Chrome  
https://www.google.com/chrome/browser/desktop/#  
dpkg -i google-chrome-stable\_current\_amd64.deb   
＃apt-get install -f   
#dpkg -i google-chrome-stable\_current\_amd64.deb  
  
案例  
  
商标扫描：python3 kostebek.py -u list.txt -n 组织名称  
获取Google域名：python3 kostebek.py -g组织名称获取公司商标：python3 kostebek.py -t 组织名称
