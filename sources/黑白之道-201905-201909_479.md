**Tunna简介：**

Tunna1.1是secforce在2014年11月出品的一款基于HTTP隧道工具。其中v1.1中支持了SOCKS4a。

  

**Tunna演示稿：**

https://drive.google.com/open?id=1PpB8\_ks93isCaQMEUFf\_cNvbDsBcsWzE

  

Github：https://github.com/SECFORCE/Tunna

                192.168.1.4       Windows 7

  

靶机：  192.168.1.119 Windows 2003

**如果：没有出现“无法验证此远程计算机的身份，是否仍要连接？”**

注册表键值：HKEY\_CURRENT\_USER\\Software\\Microsoft\\Terminal Server Client\\Servers删除对应IP键值即可。

非常遗憾的是，Tunna对PHP的支持并不是太友好。
