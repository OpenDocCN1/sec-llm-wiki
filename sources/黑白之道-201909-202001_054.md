命令行直接输入：  
pip install pyspider   
不出意外的话肯定会报错，怎么解决呢？  
  
一，下载pycurl 库

  
下载地址：

https://www.lfd.uci.edu/~gohlke/pythonlibs/#pycurl 

  

这里注意 选择与自己下载python版本相对应的

  

![](../Images/f4d6fb9c9dc11b3c939380cb48071765.png)   
  
下载好之后将下载的文件放在python 目录下像我一样

  

![](../Images/e4441a6d5aae8c0760d8b6561d6953af.png)   
  
然后在回到cmd   
  
   先  cd D:\\python3 下 然后执行下边命令  
  
   pip install pycurl-7.43.0.3-cp38-cp38-win\_amd64.whl  

 （这里 .whl文件名 是你下载的那个.whl文件名） 

 切勿直接复制

  

  

![](../Images/8238375ba859a16e2989a4fc2caf20bb.png)   
  
二，安装pyspider 

  
直接cmd 下

  
pip install pyspider

  

![](../Images/122e3fc3fe64ea6ceaf89e6b4b655188.png)   
  
三，此时在运行pyspider 还是会报错

  
打开python安装目录，找到下边这四个文件(这里给大家截图看不懂文字的直接看图，标注的很清楚)。

  

![](../Images/c34c0ba178f035a6c716257722afa59d.png)   

  

1)Libsite-packagespyspiderrun.py

  
![](../Images/b7ba6dc5abd7691a20947c419bb3f203.png)   

  

2)Libsite-packagespyspiderwebuiapp.py

  

![](../Images/e9902ec75baed9c087e952dd146a18a0.png)   

  

3)Libsite-packagespyspiderfetchertornado\_fetcher.py

  

![](../Images/2005978bbca036e3c51aa16a3a201512.png)   

  

重点来了，将这三个文件里边的async 全部修改为 async123（新手的话装一个小红本打开就好）  
  
4)Libsite-packagespyspiderwebuiwebdav.py

  

![](../Images/a9edb32526915c4bcc4b07aafdc527d5.png) 

  

将这个文件里边的  
209行的  'domaincontroller': NeedAuthController(app),  
修改为  
'http\_authenticator': {  
        'HTTPAuthenticator': NeedAuthController(app),  
},  
  
四，运行pyspider测试是否成功安装

  
最后 在来运行 pyspider

  

![](../Images/1372944817264c50867d56fa19085172.png)   

  

此时打开浏览器试试 127.0.0.1:5000 

  

![](../Images/d8432226d14198e0ba111566bd5c018b.png)   
  
完美解决！
