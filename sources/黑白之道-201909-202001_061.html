一、环境 Kali2019.3 python2 


二、安装过程：


下载到本地 git clone 


https://github.com/yanxiu0614/subdomain3.git


 


安装依赖包 pip install -r requirement.txt 


三、命令 

python2/3 brutedns.py -d xxx.com -s high -l 5
   -d 指定目标 
   -s 速度模式
   -l 域名等级
