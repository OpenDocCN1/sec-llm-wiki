# 爆破带验证码的后台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650459217&idx=3&sn=a53d8567557d1f27ec15a20f1b37c074&chksm=83bba9b5b4cc20a3aab3ae3fae5e87a2aacfcb9d31d6842fe76104eed44b16413bfb51250e9c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650459217&idx=3&sn=a53d8567557d1f27ec15a20f1b37c074&chksm=83bba9b5b4cc20a3aab3ae3fae5e87a2aacfcb9d31d6842fe76104eed44b16413bfb51250e9c&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)  

用到的工具是 PKAV HTTP Fuzzer 一款神器

  
![](../Images/46f4f3478d544f99020bc15d60068c99.png)   

  

要先用burp抓到登录的包放到这里，然后载入字典，可以选择重放模式  
  
![](../Images/1b79c714609c17f73b487293a0e341e2.png)   
  
然后找到验证码的地址复制，可以先进行验证码测试，其他默认就好  
在重放选项里可以设置错误返回内容，http重定向等，与burp类似  
然后在发包器里点击启动即可  
  
![](../Images/7dedf65140060706ec60531a95351cb4.png)
