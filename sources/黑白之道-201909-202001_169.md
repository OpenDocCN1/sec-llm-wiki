# 20家Web托管商突然关闭 只给客户两天时间下载数据

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650458474&idx=2&sn=2414dfa92d6a84f62e57adbf42a824f9&chksm=83bbac8eb4cc2598031856f17eecd9f13508e6b108c6259e210f7d22ac2367c761b4cae9cc12&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650458474&idx=2&sn=2414dfa92d6a84f62e57adbf42a824f9&chksm=83bbac8eb4cc2598031856f17eecd9f13508e6b108c6259e210f7d22ac2367c761b4cae9cc12&scene=27#wechat_redirect)

> **文章来源于：****solidot.org**

至少 20 家 Web 托管服务商在上周末突然通知客户，宣布将在周一关闭，只给客户两天时间从服务器下载数据。所有服务商提供的都是提供廉价的 VPS 服务，所有网站都有着相似的页面结构，使用相同的邮件模板通知客户。

  

![](../Images/dabaea44ae4ac5e3f7a8da45bbfb984f.png)

  

种种迹象显示它们可能是同一个实体运营的，一些客户认为这是某种“退出骗局”，认为这些 VPS 服务商背后的公司携款跑路了。

  

业内人士称这是 Web 托管行业低端市场的常见现象。
