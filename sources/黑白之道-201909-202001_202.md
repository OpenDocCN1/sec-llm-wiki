# Kail Linux今年最后一次更新，有新功能！

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)

**![](../Images/8db296b0dab2f9931e0cf8c9be0ea3fb.png)**Kali Linux官网宣布了2019年第四个也是最后一个版本——Kali Linux 2019.4。相比之前有不少的变动。**一，支持Android，可以在手机上使用Kail**名为 NetHunter Kex 的功能可在 HDMI 输出上连接安卓设备，在安卓智能手机上获得 “完整无删减的 Kali 桌面”。  

  

**二. 放弃 Gnome，使用最新 Xfce**  

  

该最新迭代用 Xfce 替换了其主要桌面环境 Gnome，Gnome 对于大多数 Kali 用户而言太过臃肿，新的 Xfce 用户界面 (UI) 是可运行于各层级 Kali 安装上的轻量级 UI。其功用在于无需变动即可处理普通用户的各种需求。且其现代 UI 元素充分运用屏幕空间，外观十分精美。

  

该团队还创建了名为 “Kali Undercover”的 Kali 主题，仿 Windows界面。

  

![](../Images/89e81532d6ed96bd99960f2388b06f31.png)

  

**三. BTRFS**

  

Kali Linux 文档中新增将 BTRFS 用作根文件系统的内容，赋予用户在升级后回滚文件系统的能力。

  
**Kali Linux 2019.4发行版更新说明**一个新的默认桌面环境，Xfce新的GTK3主题(用于Gnome和Xfce)引入Kali Undercover模式Kali文档有了一个新家，现在支持Git公共包装-把你的工具放进Kali安装在Android上的NetHunter Kex – Full Kali 桌面安装过程中的BTRFS添加PowerShell内核升级到5.3.9版本...以及常规的错误修复和更新
