安装
eva @ paradise：? $ git clone https://github.com/Th3Hurrican3/PEpper/ 
eva @ paradise：? $ cd PEpper
eva @ paradise：? $ pip3 install -r requirements.txt
eva @ paradise：? $ python3 pepper。 py ./malware_dir
