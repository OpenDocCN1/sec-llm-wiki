# 一加公布个人信息安全漏洞并向受影响客户致歉

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650458121&idx=2&sn=424be805f0974979df9e439ada1999ed&chksm=83bbadedb4cc24fb7653463b42b9e19f491b3293a80ebf8f398eaae27145d12157d951489fb9&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650458121&idx=2&sn=424be805f0974979df9e439ada1999ed&chksm=83bbadedb4cc24fb7653463b42b9e19f491b3293a80ebf8f398eaae27145d12157d951489fb9&scene=27#wechat_redirect)

今天，一加安全团队通过 OnePlus 社区论坛公布了自家智能机上的一个“个人信息安全漏洞”。当用户在 OnePlus 商店订购时，其中一个环节会导致“未经授权的第三方接触到用户的某些订购信息”。尽管其中并不包括付款、密码或 OnePlus 账号等信息，但该公司还是就此事向用户表达了歉意。

![](../Images/e5a68663b04a28e300cd3a519e35a51f.png)

  

一加安全团队验证了在此期间暴露的几条用户信息，团队成员 Ziv C. 今日表示：“某些用户的姓名、联系电话、电子邮件和送货地址可能已经被泄露”。  
  
如有任何疑问，可通过 OnePlus 官方支持网站或快速问答（FAQ）页面，与该公司取得联系。  
此前，一加已经向所有受影响用户发送了一封告知邮件。但除此之外，尚未发现有其它更多的信息被泄露。  
不幸躺枪的用户，或在后续遭垃圾邮件或网络钓鱼骚扰。若安全团队在后续公布了更多信息（比如登录和银行信息），还请进一步提高警惕。  
Ziv C 补充道：“目前我们正在与有关部门合作，以对此展开进一步的调查”。对于已发生的事情，一加深表歉意，并承诺尽一切力量防止此类事件重演。
