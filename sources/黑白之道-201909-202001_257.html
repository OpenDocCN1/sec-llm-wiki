Zarp是一个网络攻击工具，主要围绕局域网的利用。这不包括系统开发，而是滥用网络协议和堆栈来接管，渗透和淘汰。可以管理会话，以快速一次毒化和嗅探多个系统，自动将敏感信息转储或直接转给攻击者。包括各种嗅探器，以自动解析来自各种协议的用户名和密码，以及查看HTTP流量等等。包括DoS攻击以击倒各种系统和应用程序。这些工具为在实时网络上快速，干净和安静地发生非常复杂的攻击场景提供了可能性。

安装
zarp旨在尽可能避免依赖。可用时，zarp选择使用纯Python或本地Python实现，而不是要求或导入庞大的库。即使这样，zarp仍需要运行以下命令：
Linux
Python 2.7.x
Scapy（与zarp一起包装）
还建议用户安装以下组件以访问特定模块：
airmon-ng套件（用于您的所有无线破解需求）
tcpdump
libmproxy（与zarp打包）
paramiko（SSH服务）
nfqueue-bindings（数据包修饰符）
建议的安装过程是运行：
git clone git://github.com/hatRiot/zarp.git

然后可以运行：
sudo python zarp.py --update
