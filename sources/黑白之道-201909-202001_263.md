Invader Framework是一个后期开发框架，其中包括Pure-PowerShell 2.0 / 2.1 Windows和Pure-Python 2.6 / 2.7 Linux / OSX远程管理工具。  

  

  

![](../Images/9b3279cf45faeb120df6d341bbf63a05.png)

  
安装  
cd invader/setup  
chmod x install.sh  
./install.sh  
  
卸载  
cd invader/setup  
chmod x uninstall.sh  
./uninstall.sh  
命令  
invader -h
