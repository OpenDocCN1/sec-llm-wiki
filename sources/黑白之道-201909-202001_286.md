现在，我们讨论如何生成动态靶机。

###  

利用大佬开发的CTFd-Whale：1、在机器上安装好 Docker 和 Docker-Compose，并且启用 Docker Swarm。Docker Swarm 参考：https://www.jianshu.com/p/77c4c62d9afe注意需要用以下命令来标记节点：

```
docker node ls #检查节点 ID
```

```
docker node update --label-add name=linux-1 <节点 ID>
```

参考链接：

*   https://docs.docker.com/install/linux/docker-ce/ubuntu/
*   https://docs.docker.com/compose/install/

2、在机器上下载代码。

```
git clone -b single https://github.com/glzjin/CTFd.git
```

3、进入目录，编辑 frp 两端配置文件，使 token 随机，再使用 docker-compose 启动相关组件。

```
cd CTFd
```

```
vi frp/frps.ini # token 一定要随机
```

```
vi frp/frpc.ini # token 一定要随机
```

```
git submodule update --init
```

```
docker-compose up -d
```

4、启动完毕，打开 http://ip:8000 安装 CTFd。5、进入系统后台设置，打开插件设置页面，按照如下指导进行设置。点击可看大图。![](../Images/728b6690b6753544932bcfc2632be12b.png)![](../Images/d2ace17b5d7915e38459e254693b2645.png)![](../Images/352fcdd436a3d7239b2ed0284267e4b0.png)![](../Images/98b0448a1f2a9b6629e18ac3c694603d.png)Frp Config Template，记得修改 token:
