描述
Tilt：终端ip查找工具，这是一个简单易用的开放源代码工具，用Python实现，用于被动侦察的自动ip查找和反向探测工具。



特征
主机到IP的转换
IP到主机的转换
DNS到IP
GeoIP翻译
广泛的信息收集槽主机名
Whois与：
注册商信息
日期
名称伺服器
SiteStatus
车主信息
附加数据
子域名
访问百分比
广泛的名称服务器
SOA记录
具有大量数据的DNS记录
反向IP查询
广泛的反向IP查找，在同一台计算机上查找具有不同IP的主机

下载并安装
您可以通过从Git存储库克隆Tilt来下载最新版本：
git clone https://github.com/AeonDave/tilt.git
依存关系
当然是Python 2.7.3
pip install beautifulsoup4
或
easy_install BeautifulSoup4

您只需下载该库，然后
cd BeautifulSoup
