# 今年五月发现的Windows BlueKeep高危漏洞正被利用

今年五月，微软不同寻常的向已终止支持的 Windows XP 和 Windows 2003 释出了安全更新，修复一个据称能像 WannaCry 蠕虫那样快速传播恶意程序的漏洞。该漏洞被称为 BlueKeep，位于远程桌面服务中。

  

![](../Images/cc1defc2bb7f769986916e3a542f15d7.png "1572965348710055.jpg")

  

微软以及美国 NSA 都先后发出警告，呼吁 Windows XP 及其它受影响版本的用户及时打上补丁。除了 XP，Windows 7、Windows Server 2008 R2 和 Windows Server 2008 也都存在该漏洞。

  

![](../Images/14d0f262c9eaddcbbe75ec8450a896d1.png "1572965364683747.jpg")

  

安全研究人员现在报告，BlueKeep 攻击正在进行之中。目前攻击者主要利用该漏洞挖掘数字货币，未来可能将其用于其它恶意目的。至今仍然有 70 万台 Windows 系统没有打上补丁。
