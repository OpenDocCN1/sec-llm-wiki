# 英特尔芯片安全问题将会存在很长时间

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650457854&idx=2&sn=0c9fd2d2cd2b7474cd58e8ac61edcbca&chksm=83bba31ab4cc2a0ceb5d6e5b1099dc73690945f5b00722edef0505c9651e094259b83d766ba1&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650457854&idx=2&sn=0c9fd2d2cd2b7474cd58e8ac61edcbca&chksm=83bba31ab4cc2a0ceb5d6e5b1099dc73690945f5b00722edef0505c9651e094259b83d766ba1&scene=27#wechat_redirect)

稳定版内核维护者 Greg Kroah-Hartman 在欧洲开源峰会上发表主题演讲时指出，英特尔芯片的安全问题将会存在很长时间。这些被称为 MDS、RDDL、Fallout 和 Zombieland 的芯片漏洞从某种程度上说都是相同的问题或者说是相同问题的不同变种，但解决方法各不相同。

  

举例来说，RIDL 和 Zombieload 漏洞能跨应用程序、虚拟机和安全区域（secure enclaves）窃取数据，讽刺的是英特尔软件防护扩展(SGX)在芯片内本是保护数据安全的，结果本身却有很多漏洞。

  

![](../Images/f422dc32c5e85d08550c77eb693cc92b.png)![](../Images/9854f36ae0e8641f5526a3aeeba25a04.png)

  

Kroah-Hartman 称为了修复每一个曝出的问题，你必须同时给 Linux 内核、CPU BIOS 和微码打上补丁。这不只是 Linux 的问题，任何操作系统都面临相同的问题。

  

他承认 OpenBSD 给出了解决此类漏洞的最近解决方案：关闭英特尔处理器的超线程，克服带来的性能损失。Kroah-Hartman 称，你必须选择性能还是安全，而这里不存在好的选择。
