# Mozilla Firefox 70 正式发布 包含隐私报告工具 进一步提高性能

Mozilla今日正式宣布用于桌面计算机的Firefox 70.0，以及用于Android的68.2以及长时间支持版Firefox ESR 68.2.0。尽管具有里程碑式的版本号，但Firefox 70并没有太多新增功能，最明显的变化仅仅是更新后的图标和新的欢迎屏幕，同时还为操作系统的系统暗模式提供了更好的支持，而增强跟踪保护（ETP）现在已成为所有平台和用户的默认设置。

  

下载地址：

  

http://ftp.mozilla.org/pub/firefox/releases/70.0/

  

![](../Images/5521e394795effd06e7e107d210f2558.png)

  

Firefox 70将社交网络跟踪保护组件作为其ETP系统的标准功能来打开，该组件可防止来自Facebook，Twitter和LinkedIn的跨站点跟踪。

  

此外，Firefox 70添加了新的隐私报告，通过从Firefox主菜单中选择“隐私保护”可以访问该报告。这提供了您当前保护级别的摘要，并显示了过去一周中每天有多少跟踪器被阻止的图表（分为ETP提供的五种保护类别）。

  

![](../Images/9099597fcb56ecaba9573420f5a6e66f.png)

  

![](../Images/05fc1ff9710961aca12804f325d05e6f.png)

该报告还结合了两个最新更新的组件中的信息：Firefox Lockwise（一种可以与Bitwarden和LastPass等竞争对手相抗衡的跨平台密码管理工具）和Firefox Monitor。 Lockwise显示有关数据泄露中暴露的潜在易受攻击密码的警报，如果不希望使用，用户可以通过“登录和密码”下的“选项>隐私和安全性”禁用此功能。

  

Firefox 70还首次启用了一个新消息面板，可通过地址栏中的礼品盒图标进行访问，它仅在Mozilla向用户发布新信息后才会显示。地址栏中的其他增强功能是一个地理位置图标，它在网站使用地理位置时提醒用户。

  

Firefox的核心引擎组件也已得到了改进，有望带来更好的性能-包括更快的Javascript Baseline Interpreter，用于Windows的WebRender图形渲染引擎的更广泛推出以及对macOS的合成器改进，这些升级可以降低功耗，加快页面加载速度高达22％，视频资源使用减少37％。

  

Firefox的自带页面（如“首选项”和新的“隐私保护”报告）现在遵循系统暗模式的设定而自动切换颜色，而macOS用户现在可以从Chrome浏览器导入密码。
