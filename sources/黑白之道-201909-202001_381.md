**0x01安装Kali**  

  

由于小编想后期做个HACK移动工作站，所以这里选择kali，在kali官网下载好img镜像，然后利用Win32DiskImager进行烧录即可，这里已经烧录好了，所以不再演示。

  

![](../Images/9f672a3e3cb1e0fe86e3aa669fafa027.png)   

  

烧录好kali后，将内存卡插入卡槽，连接树莓派电源，这里需要注意，卡槽没有弹片，安装时注意不要太用力，否则容易弄坏卡槽。  
  

**0x02三种连接场景**

  
1、有额外的显示器，使用转换头直接连接即可。  
2、没有额外的显示器这时我们可以利用我们的安卓手机来安装下图两款工具来进行连接。  
  

![](../Images/5e5d88c630462e9dab116b842b51d5c6.png)

  

具体方法：首先使用数据线连接手机和树莓派，然后开启手机上的USB网络共享，然后利用IP Tools来进行局域网扫描获取树莓派的IP，最后利用JuiceSSH来进行ssh连接，连接效果如下。

  
![](../Images/20113d1e6ca25b6f2919ec887621ee78.png)  

  

3、只有笔记本呢？  
可以利用一根网线来连接树莓派和电脑，然后笔记本用无线来连接网络，arp -a 获取树莓派IP,然后配置共享网络，利用putty或者xshell等ssh工具进行连接，这里不再进行演示。  

  

**0x03树莓派Kali的基本配置**

  
以下操作可以在GUI下，也可以在SSH终端上进行。

  
1、更换源  
vim /etc/apt/sources.list，然后将官方源注释，添加下面的任意1-2个源即可，我个人用的阿里云和清华大学的源。

deb http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib  
deb-src http://mirrors.ustc.edu.cn/kali kali-rolling main non-free contrib  

  

#阿里云  
#deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib  
#deb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

2、解决GUI下浏览器中文乱码

  
（1）首先确定locales已经安装，如果没有用apt-get install locales命令来安装  
（2）locale -a查看当前系统支持的字符集。  
dpkg-reconfigure locales会弹出图形化界面，选中en\_US.UTF-8和zh\_CN.UTF-8，确定后，将en\_US.UTF-8 选为默认（空格是选择，Tab是切换，\*是选中状态）。  
（3）安装中文字体  
   apt-get install xfonts-intl-chinese  
   apt-get install ttf-wqy-microheireboot  
  
3、安装中文输入法  
apt-get install fcitx   
apt-get install fcitx-googlepinyin  
apt-get install fcitx-module-cloudpinyin   
apt-get install fcitx-sunpinyinreboot  
  
4、时区、时间校准同步  
由于树莓派没有内置电池，所以断电后，时间无法保存，如果不同步时间像GUI下的浏览器等都无法使用。  
（1）临时方案：登陆后终端手动同步时间date --s=“2019-10-10 14:38:00”  
（2）永久方案：更换时区，设置同步  
dpkg-reconfigure tzdata  
然后选择asia(亚洲)  
然后选择shanghai  
apt-get install ntpdate  
去/etc/profile.d/目录新建一个脚本.sh,内容为  
#!/bin/bash  
sudo ntpdate cn.pool.ntp.org  
  
最后chmod xx.sh 755  
  
5、安装完整版kali

apt-get update   
apt-get install kali-linux-full
