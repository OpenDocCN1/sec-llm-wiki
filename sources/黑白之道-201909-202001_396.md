**要求**  
DNSlivery不需要构建复杂的服务器基础结构实际上，只有两个简单的要求：能够NS在您的公共DNS中区域创建记录拥有一台能够UDP / 53从互联网接收流量的Linux的服务器  
  
**特点**  
网求允许打印，或执行保存文件到目标不需要目标上的任何客户端的不需要完整的DNS服务器。 

  
DNSlivery将为给定目录的所有文件提供服务（PWD默认情况下），并且需要以根权限运行以侦听传入的udp / 53数据包。  
  
**用法**  
dnslivery.py \[-h\] \[-p PATH\] \[-s SIZE\] \[-v\]接口域名服务器DNSlivery  - 通过DNS 位置参数传递简单文件和有效负载：  

  
接口接口DNS流量域DNS区域名称服务器的FQDN名称运行DNSlivery参数可选的服务器的FQDN名称：  

  
\-h， -  help显示此帮助消息并退出  
\-p PATH， -  path通过DNS服务的目录路径（默认值：pwd）  
\-s SIZE， -  size SIZE size（以字节为单位）的base64块（默认值：255）  
\-v， -  verbose增加详细程度  
  
**示例**  
$ sudo python3 dnslivery.py eth0 dnsd.no0.be vps.no0.be -p / tmp / dns-delivery
