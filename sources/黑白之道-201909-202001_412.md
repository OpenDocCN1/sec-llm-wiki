**下载**

git clone 

https://github.com/t0thkr1s/revshellgen  
  
**安装**  
该脚本有3个依赖项：  
pyperclip  
COLORAMA  
readchar  
  
**您可以输入以下命令安装：**  
python3 setup.py install
