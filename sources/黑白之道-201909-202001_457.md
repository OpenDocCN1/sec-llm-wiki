Konan是一种高级开源工具，旨在用于在Web /应用程序服务器上强制执行目录和文件名。  

  

![](../Images/b80f5a0fe8a15b914b7365e3ddb4a337.png)

  

**安装**  
通过克隆Git存储库来下载Konan：  
git clone https://github.com/m4ll0k/Konan.git konan  
安装要求 pip  
cd konan && pip install -r requirements.txt  
  
**运行**  
python konan.py  
  
**支持平台**  
Linux  
windows  
MacOSX  
  
**用法**  
基础：  
python konan.py -u/--url http://example.com/
