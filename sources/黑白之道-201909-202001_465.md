**安装**  
只需下载预编译版本（不需要python解释器），或者从源代码构建：  
  
需要Python2.7  
  
git clone git@github.com:NuID/nebulousAD.git  
  
python setup.py install  
  
然后初始化你的密钥。您可以访问以下网址获取密钥：https：//nebulous.nuid.io/#/register 注册后，单击按钮生成API密钥并进行复制。  
  
现在你可以像这样初始化它们： nebulousAD -init-key <api\_key>  
  
**用法**  
转储所有哈希并根据NuID的api检查它们的示例： nebulousAD.exe -v -snap -check
