# splunksecrets 一款离线处理Splunk秘密的工具

splunksecrets是一个离线处理Splunk秘密的工具，它目前支持密码的加密和解密，但将来支持将Splunk安装从一个splunk.secret文件脱机递归转换到另一个（例如，用于在整个分布式基础架构中同步splunk.secret）  
  

![](../Images/d537be86c2a31362eb074062a5d78190.png)

  

**安装**  
splunksecrets 可以使用pip3安装：pip3 install splunksecrets  
或者，如果您喜欢冒险，可以直接从github安装：  
pip3 install git https：//github.com/HurricaneLabs/splunksecrets.git

  
**用法**  

Use——加密/解密Splunk 7.2秘密(用$7$表示)时新增

使用——加密/解密Splunk pre-7.2未散列的秘密时不使用salt

使用——splunk-secret-text指定splunk。命令行上的秘密内容

使用——password指定要在命令行上加密/解密的密码

使用——散列密码为$SPLUNK\_HOME/etc/passwd生成散列
