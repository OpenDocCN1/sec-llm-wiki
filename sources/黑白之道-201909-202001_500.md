CALDERA是一个基于MITRE ATT和CK?框架的自动对手仿真系统。CALDERA通过将能力附加到对手并在操作中运行对手来工作。可以在Wiki中找到该系统的完整文档。  
  

![](../Images/f74953443001e33e5ced282e1f0f86b6.png)  

  
要求  
Python 3.5.3   
Google Chrome测试的浏览器  
此外，此代码（C2服务器）旨在在Linux或MacOS上运行。代理 - 连接到C2 - 可以在Windows，Linux和MacOS上运行。

  
安装  
首先以递归方式克隆此存储库。这将拉出所有可用的插件。  
git clone https://github.com/mitre/caldera.git --recursive  
pip install -r requirements.txt  
python server.py
