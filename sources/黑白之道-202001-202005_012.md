# 上网须谨慎！一男子使用免费VPN“翻墙”被抓罚款

华盟君引言“前两天，一男子使用“翻墙”软件接入境外网络被调查，根据管理规定，对该男子给予行政警告并处500元罚款的处罚。”

  

某地区执法机关人员在工作中发现，有人使用“翻墙”软件接入境外网络。情指中心立即会同城郊派出所展开调查，并迅速查明并传唤“翻墙”软件使用者杨某。

  

经调查，**杨某在2019年9月的时候在手机上下载“老王VPN“、”蚂蚁VPN”两款软件，安装在手机上免费使用**，并擅自利用这两款软件建立非法信道进行国际联网。违法人杨某对此供认不讳。

  

当地公安依据《中华人民共和国计算机信息网络国际联网管理暂行规定》第六条、第十四条之规定，给予杨某行政警告并处500元罚款的处罚。  

  

![](../Images/6e0411c793db94b41b19ee54590045e7.png)

  

我认为近些年人们对于“翻墙”的研究和讨论有些本末倒置了。

  

行政法规作出一个禁止性规定，首先要有禁止的主体和对象。换言之，在我们讨论“翻墙违法性”之前，我们应当先讨论到底什么是“墙”，“墙”到底存不存在。这道墙在我们每个人眼中看来，显然它是事实存在的。我在上一篇文章提及一个想法——“在一个个生活事实和亲身体验中，人的大脑永远不会欺骗自己”。但是，生活事实和亲身体验很可能影响我们对于一件事情在法律意义上的判断——因为人们倾向于相信，如果一件事情在生活中是被事实禁止的，那么他就一定规定在了法条上。

  

但实际上：

没有任何一个公开的规范性文件规定过：个人不允许访问境外网站。

没有一个哪怕是效力最低的红头文件敢声称：访问youtube、Twitter是违法的。

  

不知道是不是因为“翻墙”之后做了什么，还是仅仅是“翻墙”的原因。这条微博随后被官博删除。华盟君在这里提醒大家，**如果有需要必须使用国家批准的合法国际出入口信道，并且不要做违反规定的事！**我们公司就有专线申请的pop点，备案之后，这是正规的，大概十几万一年的那种。
