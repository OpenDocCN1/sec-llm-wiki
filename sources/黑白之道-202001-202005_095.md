# win10提示管理员已阻止你运行此应用解决方法

这里以自己遇到的一个软件为例，下图就是禁止的图画：

  
![](../Images/a2b87ab30563bf306f428098e5ee177b.png) 

  
方法一：在开始菜单中输入“cmd”，然后以管理员身份运行

  
方法二：或者找到C:\\Windows\\System32目录下的cmd右键管理员身份运行

  

![](../Images/263279a3f1381006fed9280353f2ef43.png) 

  
按住“shift”键，同时右键点击程序，然后选择“复制为路径”

  
![](../Images/1ee0c45575098accf45dfe0db65c22ac.png) 

  
将复制的路径放在cmd内，按下"enter"键

  
![](../Images/b4a117e44665b4ea96dc6a792c6e9a90.png) 

  

打开成功

  
![](../Images/d15b04db33291e6ad955ca7cf6086ca3.png)
