描述

JavaScript和VBScript Shellcode启动器。这将生成指定二进制文件的32位版本，并将shellcode注入其中。

DotNetToJScript可以在这里找到：

https : //github.com/tyranid/DotNetToJScript

  

用法：  

*   选择您要注入的二进制文件，默认为“ rundll32.exe”，例如，可以使用notepad.exe，calc.exe ...
    
*   在所需的任何框架中生成32位原始shellcode。经过测试：钴击，Metasploit框架
    
*   运行：cat payload.bin | base64 -w 0
    
*   对于JavaScript：将base64编码的有效负载复制到下面的代码变量中
    
    var code = "<base64 encoded 32 bit raw shellcode>";
    
*   对于VBScript：将base64编码的有效负载复制到下面的代码变量中
    
    Dim code: code = "<base64 encoded 32 bit raw shellcode>"
    
*   然后运行：
    
      
    

wscript.exe CACTUSTORCH.js或wscript.exe CACTUSTORCH.vbs通过目标上的命令行，或双击资源管理器中的文件。

*   对于VBA：将base64编码的有效负载复制到文件中，例如code.txt
    
*   运行python splitvba.py code.txt output.txt
    
*   在以下位置复制output.txt，使其看起来像：
    
    code = ""code = code & "<base64 code in 100 byte chunk"code = code & "<base64 code in 100 byte chunk"
    
*   将整个有效内容复制并粘贴到Word宏中
    
*   保存Word Doc并发送或运行它。
    
      
    

打开cs  

*   加载CACTUSTORCH.cna
    
*   转到攻击->主机CACTUSTORCH有效负载
    
*   填写栏位
    
*   文件托管，随时可以使用！
