# CVE-2016-1531 简单利用

Exim是一个MTA（Mail Transfer Agent，邮件传输代理）服务器软件，该软件基于GPL协议开发，是一款开源软件。该软件主要运行于类UNIX系统。通常该软件会与Dovecot或Courier等软件搭配使用。Exim4被设计成能高效地、不间断地在Internet上运行，而且能处理各种混合邮件。具有suid权限后在4.86.2之前的Exim允许本地用户通过perl\_startup参数获得特权。  
  
**漏洞环境**  
kali IP : 192.168.123.151  
Ubuntu IP:192.168.123.227  
exim4 ：4.87  
  
**漏洞利用**  
首先连接一个shell，查看当前用户whoami  

  

![](../Images/7df7e169eeba9d85ac615160eb22687f.png)

  
当前用户是www-data接下来提权，查看suid  
  

![](../Images/714ce266f6036fdb7390373eee011e1b.png)

  
发现可以尝试提权exim4，查看版本exim --version  
  

![](../Images/9129943cef51748b269e50f484fd5e38.png)

  

版本是4.89可以提权，搜索漏洞脚本 searchsploit   exim

  

![](../Images/9977e6b06a618b4116931bb641619114.png)

  
编辑脚本修改里面的shell连接后上传到目标/tmp目录下

  

  

![](../Images/3b95ca8f65d0c8b10bef69fea20be4b0.png)

  
给脚本设置执行权限后执行./46996.sh -m netcat 执行完查看当前用户  
  

![](../Images/43ee7e5567ddedaca3fb590ef86a8da8.png)

  
稍等一会在查看当前用户发现由www-data变成了root，说明提权成功了
