# Docker 搭建 upload-labs 靶场

![](../Images/8e5d77bf7751a0da7834b3686fe0b4b6.png)  

upload-labs是一个使用php语言编写的，专门收集渗透测试和CTF中遇到的各种上传漏洞的靶场。旨在帮助大家对上传漏洞有一个全面的了解。目前一共20关，每一关都包含着不同上传方式。  
  

![](../Images/31defc9454a87dda5503d49ad83d24a4.png)

  

靶场搭建

获取upload-labs镜像

docker search upload-labs

  

![](../Images/ed21235e9acf016c474f07eb48e9a70c.png)

  

docker pull c0ny1/upload-labs  

下载镜像后 docker images upload-labs 查看镜像

  

![](../Images/02cb24406221bfc2c4262755ee5e94ce.png)

  

docker run -it -d -p 8080:80 aa4fdd1dd211  运行镜像

systemctl stop firewalld.service  关闭防火墙

  

![](../Images/ae490be1dc3fa95c8c7514d50c4d1cd6.png)

  

docker ps 查看镜像是否运行后输入ip port访问网站

  

![](../Images/0b21a4f72b28e06fe824cc3000b7c8c3.png)

  

到这里靶场就搭建完了，另外第一关论坛有解题步骤的详解，不信你就搜一下！
