首先安装python环境，楼主为python3.6.6

  

用pip 安装selenium

  

pip install selenium

  

下面是代码的具体实现：

  

#交互模式

from selenium import webdriver

  

#导入时间模块

import time

  

#创建浏览器对象

driver = webdriver.Chrome()

  

#打开要操作的网址

driver.get("http://www.taobao.com")

  

#下面都是获取id属性值为q的节点对象

input = driver.find\_element\_by\_id("q")

  

#模拟键盘输入iphone

input.send\_keys('iphone')

  

time.sleep(3)

  

#清空输入框

input.clear()

  

#模拟键盘输入iPad

input.send\_keys('iPad')

  

#获取搜索按钮节点

botton = driver.find\_element\_by\_class\_name("btn-search")

  

#触发点击动作

botton.click()
