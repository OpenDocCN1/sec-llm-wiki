                       \[-p PROJECT\] \[-r CUSTOM\_REGEX\] \[-s CUSTOM\_SEARCH\] \[-u\]  
                       \[-v\] \[-w WRITE\_FILE\]  
  
该工具用于从GitHub获取信息。默认情况下是这样的。对于文件名为“wp-config”的代码。  
并取出auth信息可选参数:  
  -h, --help        显示此帮助消息  
  -a ACCOUNT        指定一个特定用户  
  -d DIRECTORY      将结果下载到特定目录  
  -o ORGANIZE       根据“新”“旧”“所有”来组织结果  
  -p PROJECT        Specific project to搜索. 使用做  
  -r CUSTOM\_REGEX   自定义正则表达式字符串  
  -s CUSTOM\_SEARCH  自定义Github搜索字符串  
  -u, --url         找到对象的输出url  
  -v, --verbose     打开详细输出，这将输出  
  -w WRITE\_FILE     将结果写入文件
