# 最近更新后的Windows 10的文件资源管理器仍然存在Bug

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650459610&idx=3&sn=2b43cf5c994462399d32b1db65d9d296&chksm=83bba83eb4cc21289df797e78133f2023f0e678ba204f4e5b58bcddeb4415e595029bed2f942&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650459610&idx=3&sn=2b43cf5c994462399d32b1db65d9d296&chksm=83bba83eb4cc21289df797e78133f2023f0e678ba204f4e5b58bcddeb4415e595029bed2f942&scene=27#wechat_redirect)

微软此前已经将Windows 10累积更新KB4532695作为消费者和企业的可选更新提供，它可修复文件资源管理器中的多个错误。根据更改日志，Windows 10的可选更新修复了使文件管理器搜索栏损坏的问题。发现这些问题用户报告说搜索栏在使用时依然可能会长时间冻结，文件资源管理器的新搜索体验会阻止用户右键单击搜索栏中的内容。

  

![](../Images/abf8deb8eff918831e0c4d3e2966d951.png)

  

![](../Images/7f243c9e9603da162458e14f41f8cabd.png)

  

尽管微软解决了影响文件浏览器和控制面板的上述两个问题，但新的搜索体验仍然存在问题。例如，您必须单击两次以重置插入标记的位置并输入搜索查询。  

  

尽管微软表示已启用了右键单击支持，但搜索框在您右键单击该栏将其激活之前，无法右键单击它。新的搜索栏还有一个错误，即高级查询语法关键字，运算符和过滤器不再以蓝色突出显示。

  

统一搜索体验仍然更是一团糟，在Windows 10的20H1更新发布之前，情况似乎不会变得更好。

  

微软尚未意识到文件管理器存在的诸多问题，并且似乎没有任何解决方法。如果您已安装Windows 10 November 2019 Update，则必须接受文件管理器和控制面板出现问题的可能性。

  

Windows 10的2019年11月更新已通过Windows Update向更多用户推出，但除非您使用的是2018年10月更新，否则不会自动安装。如果您还没有准备好使用文件管理器带来的麻烦，可以随时延迟2019年11月更新。

  

与每个累积更新一样，KB4532695本身也是个麻烦制造者，目前已知在某些系统上引起了BSOD，音频问题，TPM和其他问题。
