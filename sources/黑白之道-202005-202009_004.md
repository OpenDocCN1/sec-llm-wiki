# 看我如何拿下违法APP后台

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650480718&idx=2&sn=850c62afc8fb6dd880dd5fe99d0ff8c2&chksm=83ba45aab4cdccbcd93b99068d272ec956e85b08c51a2c776b2a6e66ee9ee7eeb9f233e3e08a&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650480718&idx=2&sn=850c62afc8fb6dd880dd5fe99d0ff8c2&chksm=83ba45aab4cdccbcd93b99068d272ec956e85b08c51a2c776b2a6e66ee9ee7eeb9f233e3e08a&scene=27#wechat_redirect)

> **文章作者：**** cc**

**前言**

经过测试后，发现该app，在输入手机号和验证码之后，会申请获取手机号权限，一旦授予权限，app会立刻获取通讯录手机号和姓名，上去至数据库。性质及其恶劣！！  

**一、事情的开始**

app来自于一个妹妹发给我的。  

![](../Images/ecff820943aa1b92fd0abf09e0761961.png)

  
app界面

![](../Images/6175094b0fdc46afa1fc22e821b47a16.png)

  

随便新建几个联系人。

![](../Images/abbbeaa3714914e6a91d3a276fe8b081.png)  
进行注册![](../Images/e098f0ac8a85614f0f63c20b96b39972.png)  
进行抓包发现，电话号是进行加密的，看的不是很清晰明了。![](../Images/97175ee2fb5c3c4c15183c65f34b21db.png)  
由于已经进入了后台，直接看后台记录。![](../Images/76ee01c6db1bf9b9a2fbe8e1d40ca609.png)  
以及我刚刚新建的几个联系人，也都被传到了后台里。![](../Images/4752890d7c5f30091adaa7de553c3fbe.png)  
那么渗透的意义就有了，为了不让更多人受害，为了匡扶世间正义，我挺身而出！![](../Images/9497725fe87c21be576ff4229e591018.png)  
**二、渗透过程**先抓个包，看到网站的地址。![](../Images/3fde64c197baf3efd5bc30a50287a460.png)  
浏览器，打开网址，发现是空白页。![](../Images/c01b3186736de606ca14305ce8862692.png)拿出我的初恋，进行后台扫描。![](../Images/3b4d36a1a4f19e0db9dedd13dd88fdd3.png)  
发现 域名/gm/  是后台登录界面![](../Images/8102ac366bdc675bb96318750b37190e.png)  
在后台登录的页面，我一般有这几个想法：1、sql注入，万能密码绕过登录2、用户名枚举，爆破密码3、网站备份文件，查找密码4、代码审计  
发现并不存在注入，也找不到备份文件，这个后台也不是开源的，那么只能进行爆破了。  
拿出我的大字典。![](../Images/6e26802ec1ddf0c6b5a4f6c568508c81.png)  
开始爆破admin，尝试了10000次爆破后，还是没能登录进后台。正在我一筹莫展的时候，突然发现了新大陆。柳暗花明又一村！![](../Images/c7234da2a1bf6d786e2179be82a8cf6e.png)  
漏洞1：无账号密码，直接登录我试着把账号 密码 都为空，然后登录，居然进来了！！至于能登录进来的原因，我后面再讲。  
后台界面是这样的，![](../Images/e52c85567ea899566928f333e545b3c5.png)  
漏洞2：搜索处存在，字符型注入域名/gm/sblist.php?m=123'or 1=1--+![](../Images/8d814a98fdaf225e9761fb69a945e7ce.png)  
漏洞3 查看电话处，存在字符注入域名/gm/alllist.php?i=0 'or 1=1--+![](../Images/5888fbcf6414b677cb4006a536b00718.png)  
漏洞4 删除电话号，存在注入域名/gm/alllist.php?way=del手动测试不出来，但确实存在注入，可用sqlmap 跑出来。  
**三、继续深入渗透**通过注入查看，users的用户名和密码，发现用户名都是一堆杂乱没规律的账号，猜测可能是管理员，为了保护admin账号，即使被注入，也不会很快发现admin的密码。管理员太天真了。  
猜测管理员在添加小号时候，添加了一个用户名为空 密码也为空的账户，导致可以直接绕过登录进入后台，这就是账号为空 密码为空 可以进后台的秘密。![](../Images/f0a93f6ec104f79a50f36bcc280065d8.png)  
users的用户，居然有10000多个，。。。![](../Images/00df89101d931590d19697383ebd8d15.png)  
查询admin的密码。执行：域名：/gm/sblist.php?m=123%27union select username,password,qudaonum,4 from users where username = %27admin%27 -- #  
![](../Images/806091244d9132ceb732d8aec8e04a47.png)  
密码解md5，解不开，可能是强密码。这里思路断了。sql的权限 写一句话，找不到物理目录，无法写文件。sql查看根目录文件，没有权限，读不出来没有其他上传点，无法上传文件  
渗透暂时到这里 没的思路了。  
sqlmap 打包网站数据库，交给网安处理，结束我的渗透之旅。执行：sqlmap -r sql.txt -D tongxunlu -T dianhuaben --dump --thread 5
