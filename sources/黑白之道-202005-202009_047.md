当拿到weblogic 服务器后需要对内网的某些端口转发到公网进行各种花式操作，此次我们转发的是22端口。

  

登陆到Ubuntu

  

service docker start #首先开启docker 服务

  

docker ps  #查看当前docker 进行是否启动

  

![](../Images/cd45845ce5f5cbe11f62a0c820c572af.png)  
发现进程为空、所以我们执行 docker ps -a 查看挂起的所有进程  
![](../Images/3c61c442a9f9cdab5105a141e7d3328b.png)  
使用docker start aa  启动挂起进行、也可以把ID号输全效果一样aad658f37233  
![](../Images/016944a23ff1554ff16be2f4c2c8fb2a.png)  
再次使用docker ps 查看  
![](../Images/c2f4cfa83f1176367d925a2db0242b0e.png)  
可以看到进程已经启动、我们使用宿主机访问下  
 192.168.50.157:7001/console  
![](../Images/5cf5af6b6de3aa70898ec0eff215a7a1.png)  
到此基本可以确定环境没有问题、我们登陆到靶机上安装下ssh服务。  
使用docker exec -it aa /bin/bash 登陆到靶机shell下  
![](../Images/e8f7df681f433ae2d2787396d92f8c2e.png)  
apt-get install ssh  
![](../Images/f4325a569f38eddb88ab58dda1339a6f.png)  
报错 提示要更新系统（更新的时候可能会很慢、建议大家修改更新源）  
![](../Images/bdb75ea88573f8f5ef2539d138f57b55.png)![](../Images/b40586438f428e869c1ae6c2af386ca0.png)  
再次安装 apt-get install ssh  
![](../Images/c51722ce84d407e4193651bd9cd55ce4.png)  
可以看到已经安装成功、使用service ssh start 开启22端口  
![](../Images/a2da39e28b7ad311d9bcec0406c0eb80.png)  
按下Ctrl+d断开当前shell连接、在Ubuntu下抓取ens33接口流量方便后期分析  
![](../Images/20db42706e9a6bf012e60def5c44078b.png)  
打开kali linux 进行攻击、因为上篇文章已经说了如何进行攻击 这次就不截图说明、直接在反弹后的shell 下进行操作。  
![](../Images/1009d5af5c56c2543d764747a79263b4.png)  
打开冰蝎进行连接  
![](../Images/7a0dc3fe084ac6ee38d46e3679bfb4df.png)  
![](../Images/1281b196f872c27c69e57e1caeb3a062.png)  
下载内网穿透工具解压后上传到根目录  
https://www.ngrok.cc/sunny/linux\_amd64.zip?v=2.1  
![](../Images/cc4f688cf93b235c9cac50f4d0763e84.png)  
然后打开http://www.ngrok.cc/\_book/start/ngrok\_linux.html 看下使用方法./sunny clientid 隧道id  
隧道ID需要注册账号才能获取  
![](../Images/13e1f4acb9f91095eb6791109b34552f.png)![](../Images/3c924497469efae003b2e52de822eda9.png)  
运行内网穿透工具  
![](../Images/6a2d5e2cd4b9dd8240106b7a86a170d3.png)  
传入公钥到/root/.ssh/authorized\_keys下  
![](../Images/ea012f106155dbbe4025430fda801796.png)  
使用ssh 免秘钥登录  
去掉注释 重启服务 service ssh restart否则登录提示需要输入密码  
![](../Images/ab1be8957244b68e2436ffab7a8fbd41.png)  
ssh root@ vipgz4.idcfengye.com -p 11111  
![](../Images/887bfd0ccb74b4b905c16b1671771b58.png)  
可以看到已经不需要输入密码直接可以进行登录  
Weblogic环境只对外只开放了5556、7001 端口、而我们可以直接使用./sunny 进行内网穿透、无视防护墙、WAF，但是此方法容易被安全设备告警。  
![](../Images/85b3a79f79936fc29d2db071633fb989.png)
