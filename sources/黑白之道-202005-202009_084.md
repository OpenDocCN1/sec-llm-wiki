# 东南亚最大的钢板制造公司之一被勒索，黑客泄露大量数据

去年，微软委托弗若斯特沙利文公司（Frost＆Sullivan）进行了一项研究，发现网络攻击可能给亚太地区的大型制造公司造成平均1070万美元的经济损失。而对于中型制作公司，平均经济损失也达38000美元。  
  
沙利文公司在监控Deepweb和darkweb泄露期间，研究人员发现了被勒索泄露后的帖子，据称Maze勒索软件的运营商违反了与Hoa Sen Group的协议，并声称拥有公司的敏感数据。  
  
成立于2001年的Hoa Sen Group（HSG）位于胡志明市，是东南亚最大的私营钢板公司之一。和森集团在343个公司中拥有7,100名员工，年收入约为11.8亿美元。

目前，Mase运营商的运营商声称已发布了公司总数据泄露的5%。  
  
一家位于美国亚特兰大的全球性高级网络安全公司-Cyble一直在将这些数据泄露的报告给个人，使他们意识到自己正在遭受的风险。  
并建议这些疑似被泄露个人信息的人们：  
  

1.  切勿通过电话、电子邮件或短信共享个人信息，包括财务信息。  
    
2.  使用强密码并在可能的情况下强制执行多因素身份验证
3.  定期监控您的财务交易，如果发现任何可疑交易，请立即与您的银行联系。
4.  在可能的情况下，在计算机，移动设备和其他连接的设备上启用自动软件更新功能
5.  在连接的设备（包括PC，笔记本电脑，移动设备）上使用知名的防病毒和Internet安全软件包
6.  担心自己在暗网中的暴露程度的人可以在AmiBreached.com上  进行注册，  以确定他们的暴露程度。
