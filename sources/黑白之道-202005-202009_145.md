  -h, --help        显示此帮助消息  -a ACCOUNT        指定一个特定用户  -d DIRECTORY      将结果下载到特定目录  -o ORGANIZE       根据“新”“旧”“所有”来组织结果  -p PROJECT        Specific project to搜索. 使用做  -r CUSTOM_REGEX   自定义正则表达式字符串  -s CUSTOM_SEARCH  自定义Github搜索字符串  -u, --url         找到对象的输出url  -v, --verbose     打开详细输出，这将输出  -w WRITE_FILE     将结果写入文件
