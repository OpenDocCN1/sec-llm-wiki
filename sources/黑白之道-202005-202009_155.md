Bluto安装说明  
  
⑴一次点已经成功下载和安装，我们可以安装Bluto:  
  
sudo pip安装bluto  
  
(2)您现在应该能够在任何终端的任何工作目录中执行“bluto”。  
  
bluto  
  
升级说明  
  
(1)升级过程非常简单；  
  
sudo pip安装bluto -升级  
  
从开发分支安装  
(1)从最新的开发分支安装(可能不稳定)；  
  
sudo pip卸载bluto  
  
sudo pip安装git git://git hub . com/darr yllane/Bluto @ dev
