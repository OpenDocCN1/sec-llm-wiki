# WAScan 一款Web应用程序扫描仪

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650473262&idx=5&sn=a6e3a298bff8b093d707449e62c981b7&chksm=83ba66cab4cdefdc5a511f3b6fe2e23ba15b44464eae16f9765a8e996ad941821a9adcc4219e&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650473262&idx=5&sn=a6e3a298bff8b093d707449e62c981b7&chksm=83ba66cab4cdefdc5a511f3b6fe2e23ba15b44464eae16f9765a8e996ad941821a9adcc4219e&scene=27#wechat_redirect)

![](../Images/495c0590f8941b6954000f1e159d52a9.png)WAScan（（W）eb（A）复制（Scan）ner）是一个开源Web应用程序安全扫描程序。它旨在使用“黑匣子”方法查找各种漏洞，这意味着它不会研究Web应用程序的源代码，而是像模糊测试器一样工作，扫描已部署的Web应用程序的页面，提取链接和表单并进行攻击脚本，发送有效载荷并查找错误消息，等等。WAScan基于python2.7构建，并且可以在具有Python环境的任何平台上运行。

  

![](../Images/f9f43eb1a0be2cd7440a92dd53df3c9c.png)

用法  
指纹：  
$ python wascan.py --url http://xxxxx.com/ --scan 0  
  
攻击次数：  
$ python wascan.py --url http://xxxxx.com/index.php?id=1 --scan 1  
  
审计：  
$ python wascan.py --url http://xxxxx.com/ --scan 2  
  
暴力破解：  
$ python wascan.py --url http://xxxxx.com/ --scan 3  
  
披露：  
$ python wascan.py --url http://xxxxx.com/ --scan 4  
  
全面扫描：  
$ python wascan.py --url http://xxxxx.com --scan 5   
Bruteforce隐藏参数：  
$ python wascan.py --url http://xxxxx.com/test.php --brute
