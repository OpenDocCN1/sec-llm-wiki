开发环境  
编译相关系数：docker build -f .docker/php/Dockerfile -t 1024tools\_php .docker/php  
启动：docker stack deploy -c docker-compose.yml tools  
登录mysql shell：docker exec -it <your\_mysql\_container> -u root -p123456  
初始化mysql：在mysql shell中执行 source /tmp/init.sql  
访问http://127.0.0.1
