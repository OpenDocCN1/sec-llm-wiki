nessus是扫描主机漏洞的扫描器中最流行的扫描器之一，有个人免费版本和专业版本。但是个人免费版本有很多功能上面的限制，所以，今天来给教大学如何安装破解成专业版的。


安装nessus

下载好安装包以后双击Nessus-8.10.1-x64.msi安装路径使用默认路径。


 
 
这个地方可以自己选择安装地址  但一定要选一个没有创建的文件夹  因为安装包会自己创建一个文件夹  选择已经创建的文件夹的话  会引起错误。



 
在安装过程中会出现安装pcap的安装  点击next
 
 
 
 
 
安装完成后会出现一个弹框  让重启的  点击yes即可
 
访问https://localhos:8443
 
 
账号密码就是  admin  密码  password
这时可以看见  只有设置  不能进行扫描
 
开始破解
按win R键输入services.msc快速进入服务列表
 


找到Tenable Nessus ，右击属性停止服务
 
找到nessus的安装地址
找到plugin_feed_info.inc文件 
 
修改里面的内容  将下面的粘贴进去  保存   记住两个都要粘贴
PLUGIN_SET = "201912022000";
PLUGIN_FEED = "ProfessionalFeed (Direct)";
PLUGIN_FEED_TRANSPORT = "Tenable Network Security Lightning";
找到Tenable Nessus服务  开启
这个时候可以看见有了scan页面  可以进行扫描了
 
更新插件
下载好插件库
用 nessuscli update '' 你的插件库压缩包绝对路径''。


安装包地址：https://www.tenable.com/downloads/nessus
