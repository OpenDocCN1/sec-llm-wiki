# nessus 特别安装方法

nessus是扫描主机漏洞的扫描器中最流行的扫描器之一，有个人免费版本和专业版本。但是个人免费版本有很多功能上面的限制，所以，今天来给教大学如何安装破解成专业版的。  

  
**安装nessus**  
  
下载好安装包以后双击Nessus-8.10.1-x64.msi安装路径使用默认路径。

  
![](../Images/fafe4341150f4b84aec19cf38b66c3ec.png)   
![](../Images/0d6f34add7fde97c5d05ef1cc6b495c0.png)   
这个地方可以自己选择安装地址  但一定要选一个没有创建的文件夹  因为安装包会自己创建一个文件夹  选择已经创建的文件夹的话  会引起错误。  
  
![](../Images/5187e8fad8030ec73fcd36bd4118ce45.png)  
  
![](../Images/1666328a0238156aa265d926c86dd3e5.png)   
在安装过程中会出现安装pcap的安装  点击next  
![](../Images/d28a79fdc221490f70d0e2ea173bb6ba.png)   
![](../Images/6890c7ffd8c34882fa1926157221bba2.png)   
![](../Images/1a8695635fd7adbedff8ec0a33d593fb.png)   
![](../Images/9c46df3f1dfd6e8d99483e3ac4394e9c.png)   
![](../Images/80c07558398b2935cd653399a07552d5.png)   
安装完成后会出现一个弹框  让重启的  点击yes即可  
![](../Images/3bd9a0ae4f82f59e0a996e8a943bd12f.png)   
访问https://localhos:8443  
![](../Images/63187f0e6e91a2b3d51883c983246290.png)   
![](../Images/050c490f09c8f1ed7c783efd1338e6d8.png)   
账号密码就是  admin  密码  password  
这时可以看见  只有设置  不能进行扫描  
![](../Images/d92698d91d1890f043204526124e9e54.png)   
开始破解  
按win R键输入services.msc快速进入服务列表  
![](../Images/751646f54e879224a8363d3b2606827b.png)   

  

找到Tenable Nessus ，右击属性停止服务  
![](../Images/f577ec2d3ecf25b7d779a9f030520b32.png)   
找到nessus的安装地址  
找到plugin\_feed\_info.inc文件   
![](../Images/96cb0408c0081e1af331b7ca5b1200b7.png)   
修改里面的内容  将下面的粘贴进去  保存   记住两个都要粘贴  
PLUGIN\_SET = "201912022000";  
PLUGIN\_FEED = "ProfessionalFeed (Direct)";  
PLUGIN\_FEED\_TRANSPORT = "Tenable Network Security Lightning";  
找到Tenable Nessus服务  开启  
这个时候可以看见有了scan页面  可以进行扫描了  
![](../Images/4cb395b40e205057ee5b1e47f60ab911.png)   
更新插件  
下载好插件库  
用 nessuscli update '' 你的插件库压缩包绝对路径''。

  

安装包地址：https://www.tenable.com/downloads/nessus
