# pycharm中python解释器的配置

在pycharm中写python代码时出现了如下错误：Error: Please select a valid Python interpreter  

  

![](../Images/1629d42648a76fcb2e7e5a7c33b29b66.png)

  
这是因为没有配置python解释器，如果已安装python解释器，只要配置一下就好了。如果没有安装请先安装一下相应版本的，由于python的2和3版本不兼容，所以要特别注意你写的是哪个版本的python语法。

  
具体配置步骤如下：

  
1、打开“File”->点击“Settings”

  

![](../Images/d3266197fd23f3b6aa72d7e758dfb72b.png)

  

2、找到“Project Interpreters”，然后在该对话框中点击“Project Interpreter”选项。  

  

![](../Images/aa1dd9d5a92a3c60d1a0c01e8d2ab77d.png)

  
3、点击右边的加号，添加对应版本的解释器。  

  

![](../Images/1f95639225dbfee11a86356d59faf81d.png)

  
4、添加对应版本的解释器，再点击“OK”完成配置。

  

![](../Images/19b6f99507b4dd636eed680ce64fb2d0.png)
