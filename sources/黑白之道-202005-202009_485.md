# Windows被爆5个0 day高危漏洞，半年仍未修复

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650463260&idx=2&sn=cb5c6782aac3b5d4c02eedf940e516a1&chksm=83bbb9f8b4cc30ee093cf90f9ba9cdaac1a458dc12e57973fec189c5edf39068d68a715676f5&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650463260&idx=2&sn=cb5c6782aac3b5d4c02eedf940e516a1&chksm=83bbb9f8b4cc30ee093cf90f9ba9cdaac1a458dc12e57973fec189c5edf39068d68a715676f5&scene=27#wechat_redirect)

![](../Images/495c0590f8941b6954000f1e159d52a9.png)

国外安全团队ZDI的研究人员在前几天发布了5个 Windows系统的0 day漏洞，其中有4个漏洞威胁等级被评为高危漏洞。

  

![](../Images/88f13f721239585d91af81f48ce3c9b3.png)

  

5个漏洞中有4个漏洞被分配了CVE编号，其中Microsoft Windows WLAN连接配置文件缺少身份验证特权提升漏洞，该漏洞CVSS得分为7.0，本地攻击者在目标系统上获取低特权，利用此漏洞提升特权。攻击者可以创建恶意配置文件，在管理员的上下文提升特权并执行代码。

  

ZDI的研究人员表示早在2019年12月的时候就向微软报告了这5个漏洞，但时至今日，在2020年5月的微软补丁日里也没有得到修复，因此ZDI决定公开这些漏洞的相关信息。
