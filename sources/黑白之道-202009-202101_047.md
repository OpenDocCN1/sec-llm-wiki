# 到底是谁盗了我的QQ号？？

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650499575&idx=1&sn=4e85e4e8b7f9303c6b7a50fe174d454e&chksm=83ba0c13b4cd85052e632f91223b86e32b6563a2c8b2525e96924fea1157be5976914a882a87&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650499575&idx=1&sn=4e85e4e8b7f9303c6b7a50fe174d454e&chksm=83ba0c13b4cd85052e632f91223b86e32b6563a2c8b2525e96924fea1157be5976914a882a87&scene=27#wechat_redirect)

多年不联系的老友，许久无人说话的同学群，突然有人说话，发了一个图片“招聘兼职在家就能做”、“玩游戏就能赚钱”、“下载这个APP日进5000+”，你可能会疑惑，曾经的老朋友/同学现在这么行了？不！他们只是被盗号了！  
![](../Images/0fcfee3231fa49aec0b5e1810da7bb92.png)![](../Images/5d4c2f632de7d8866e5ad4fa9e1cbaf3.png)  
常年在网上冲浪的高强度网友都知道是假的，肯定是我的好朋友浏览了不该浏览的网站，下载了不该下载的APP，点了不该点的链接，才被盗了号。不过还是有一些不常在互联网冲浪，只是把这些软件当做沟通的工具的一些老人或者工作者还是会时有发生中招的事件。  
不然这些人为什么还一直孜孜不倦的不停搞呢？但其实有时钉子也疑惑，干这个油水到底有多大？能让这帮人这么高频率的出现在我们生活中。  
就在前两天，警方通报了一起在“净网2020”专项活动中端掉了一条制作QQ盗号程序——盗号者实施盗号——“号商”贩卖账号——号码最终流入电信诈骗、网络赌博等违法犯罪团伙手中的黑灰产业链条。  
在2020年10月份的时候，湖北网警根据公安提供的线索，调查发现一网民许某自主开发QQ盗号程序，盗取大量QQ帐号进行贩卖，以此谋取暴利。  
![](../Images/4fcc407aaeb08b83fc084967f0e17c4f.png)  
随后警方对该线索继续进行分析调查，发现此次的事件很有可能是一个团伙组织。从许某这条线索顺藤摸瓜警方又锁定了刘某、黄某、张某。三人在许某处购买了盗号软件进行扫号，然后将盗取的QQ分别通过下游冉某等8人再进行出售。冉某等人最终将这些被盗的QQ卖入至电信诈骗、网络赌博、洗钱等犯罪团伙手中。  
![](../Images/867aa806f1df92509de876b4b99ea057.png)经过一个月的研判调查后，警方在掌握案件中12名犯罪嫌疑人犯罪证据和住址后，在11月3日组织**70**余警力分赴北京、上海、山西等**12**地将所有嫌疑人全部抓获。  
![](../Images/124adc58af217013c70a7a5b677d7ff5.png)

  

![](../Images/d09c9f5b49b081e7633f6b922cf551fb.png)  
据犯罪嫌疑人交代，刘某三人开展扫号时将许某开发的盗号程序安装在远程服务器上，再将QQ号和密码文件导入盗号程序，程序自动运行并保存结果，扫号结束后将成功扫到的QQ卖给下游号商进行获利。  
“SF”盗号软件自开发以来验证QQ账号数量约**2亿**个，验证成功约**50余万**个，涉案资金约**1000余万**元。触目惊心！  
![](../Images/922675df31ca11b912bdca324268859d.png)  
此次盗号案件共抓获犯罪嫌疑人**12**名，扣押手机卡**70**张、手机**77**部、银行卡**35**张、电脑主机**11**台、硬盘**32**个、U盘**35**个，涉案资金约**1000**余万元，冻结涉案资金**120**余万元。  
![](../Images/9d1b21e160c881a8f97edc57fd3b522e.png)![](../Images/8ff52fbdbfa09a8b5507ab86ecc2d000.png)目前，许某、刘某等人已被依法逮捕。

案件来源：公安部网安局  

  

警方此次抓捕的犯罪团伙肯定不是国内搞这些的最后12个人，还有许许多多大大小小的个人或组织在弄，大家在平时进行网络冲浪时一定要小心，小心，再小心！可能稍有不慎就会被盗QQ，这样影响的不只是你自己，还有你身边的人。  
  
我们也经常在后台看到很多用户留言说自己不慎被骗了多少多少钱，希望我们可以帮忙追回。这种事情不是我们不想帮忙，很多狡猾的犯罪团伙通过各种境外服务器或其他方式进行藏匿作案。一旦调查起来人力、财力、时间都会大大的投入，很有可能在刚查到一点矛头就会被具有反侦查意识的犯罪团伙发现，从而前功尽弃。  
  
最好的方法就是自己不确定的东西全都不要去尝试，也不要相信天上掉馅儿饼的事。如果真的大意了，那就及时报警，很有可能很多人都被同一犯罪团伙所骗，更多的受害者提供不同的线索给警方更能加快破案速度。
