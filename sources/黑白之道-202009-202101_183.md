# ReverseTCPShell C2 反弹shell工具

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650493533&idx=3&sn=9726ded1f969c59da7dc8dc505b4bb4c&chksm=83ba37b9b4cdbeafd6dbd9fc6fbad102cb467267e655ada03964275d9c0a0a8db47ef2d16527&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650493533&idx=3&sn=9726ded1f969c59da7dc8dc505b4bb4c&chksm=83ba37b9b4cdbeafd6dbd9fc6fbad102cb467267e655ada03964275d9c0a0a8db47ef2d16527&scene=27#wechat_redirect)

  

![](../Images/495c0590f8941b6954000f1e159d52a9.png)

ReverseTCPShell C2是一款powershell编写的反弹shell工具，流量经过AES加密，payload通过三种混淆方式可绕过一些杀软的检测。

  

测试：  
1. 在文件目录下启动powershell  
![](../Images/788371c391af8ac0ddf0e524f86f4a00.png)  
2. .\\ReverseTCP.ps1 ,启动程序  
![](../Images/15f30b393128117e8ae8fc5117022a6e.png)  
会出现这个界面，功能介绍，设置好lhost和lport（监听地址及端口）Modules (模块)   | - Show C2-Server Modules.(显示c2服务器模块)Info (信息)      | - Show Remote-Host Info.(显示远程主机信息)Upload (上传)    | - Upload File from Local-Host to Remote-Host.(上传文件从本地主机到远程主机。)Download(下载)   | - Download File from Remote-Host to Local-Host.(从远程主机下载文件到本地主机。)Screenshot (截图) | - Save Screenshot from Remote-Host to Local-Host.(保存屏幕截图从远程主机到本地主机。)  
![](../Images/10cd9019d349bb763e304207ed8adc15.png)  
可以看到三种混淆方式  
![](../Images/0c68064020a83ab44fcf4c1152b62d8e.png)  
这里我选择的是base64，生成powershell和cmd的payload  
![](../Images/7d8e793b5475032ed05941ca5d245060.png)  
复制出cmd的payload，靶机执行  
![](../Images/464560ebfd77958c79e92b270c056232.png)  
靶机上线，杀软未提示和拦截  
![](../Images/2d15c6439f7dd9d74a8a499d5c67105a.png)  
执行命令ipconfig  
![](../Images/954cab9c6c48e122364df7f484b9ed62.png)  
可直接执行shell命令 ，截图经常报错，远程文件上传和下载，方便后渗透的进行，可进一步利用。
