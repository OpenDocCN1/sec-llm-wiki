# 小心变砖！苹果 MacOS Big Sur 新系统升级翻车

> **文章来****源：云头条**

macOS Big Sur是苹果针对Mac设备开发的新款操作系统，旨在提升性能，并引入旨在改善Mac使用体验的新功能特性。  
![](../Images/c8363b0137dad8c1b86ae3b5c6879784.png)  
然而据一些失望的MacBook Pro用户声称，新的macOS更新版一旦安装上去，设备瞬间变成了废砖。  
![](../Images/491d0126224f1253db31c49ac63b5c74.png)  
几位MacBook Pro用户最近跑到Reddit、MacRumors论坛和苹果的支持社区寻求有关其设备的帮助。据这些用户声称，macOS Big Sur可用后，他们第一时间下载了这个新版本，并将其安装在设备上，但随后他们的MacBook Pro就变成了废砖。  
用户们表示，他们尝试过了苹果员工建议的那些方法，也尝试过了他们已知的所有故障排除方法，可是依然不管用。  
一位用户简要叙述了因这个问题而导致无法使用的设备所发生的情况：  

*   首先，用户将macOS Big Sur下载到自己的MacBook Pro设备上并安装它。
    
*   其次，重新启动后，盖子背面的苹果徽标将点亮。
    
*   第三，设备会显示黑屏。没有显示苹果徽标。键盘上的背光无法开启，包括Caps Lock按钮的LED指示灯。没有任何提示声。
    
*   第四，风扇起初不会发出任何动静，但一分钟左右后会发出很大的动静。
    
*   第五，用户将无法使用按键重置组合（包括NVRAM、SMC、安全模式和Internet恢复）来解决这个问题，因为这些按键重置组合不可用。
    
*   最后，试图联系苹果支持部门以寻求帮助的那些人得到了将设备送去维修的指示说明。
    

  
值得一提的是，这个问题主要发生在2013年年末或2014年年中发布的13英寸MacBook Pro机型上。这些是可以安装Big Sur的最旧的MacBook Pro机型。目前尚不清楚有多少这样的设备受到了影响，目前尚无明确解决这个问题的任何方法。  
这个问题的原因也仍然是个未知数。然而，一些遇到该问题后拆卸旧MacBook Pro的用户发现，该问题可能与设备的一些部件有关。  
话虽如此，最好还是等待苹果确认这个问题。
