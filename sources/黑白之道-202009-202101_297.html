工具安装

git clone 

https://github.com/capture0x/XCTR-Hacking-Tools/cd xctr-hacking-toolspip3 install -r requirements.txt

工具使用

python3 xctr.py

所有结果保存在results/project-name中

工具搜索

有两部分，bing和yandex
例如*.php?id=

Cms查找器

您将从元名称中找到cms版本。


IP历史

该工具显示并保存域的IP历史记录。

例如用法：


targetsite.com

反向ip

使用此工具，您可以在服务器上找到域。

例如用法：


212.57.147.54

页面浏览器

您可以增加目标站点的页面浏览量。

例如用法：


https://targetsite.com

代理查找器

该工具在free-proxy-list.net上找到代理，并在主目录上更新proxy.txt。
