使用

dnssearch接受一个输入域（-domain参数）和一个单词列表（-wordlist参数），然后它将使用单词列表的行作为子域执行并发DNS请求，最终对顶级域上可用的每个子域进行暴力破解。


它支持自定义文件扩展名（-ext，默认为php）和其他可选参数：


Usage of ./dnssearch:  -consumers int        Number of concurrent consumers. (default 8)  -domain string        Base domain to start enumeration from.  -wordlist string        Wordlist file to use for enumeration. (default "names.txt")  -a bool        Lookup A records ( default true )  -txt bool        Lookup TXT records ( default false )  -cname bool        Show CNAME results ( default false )


编译

go get github.com/evilsocket/dnssearch
cd dnssearch
go build -o dnssearch main.go

Docker的编译和使用


docker build -t dnssearch .docker run -it --rm dnssearch
