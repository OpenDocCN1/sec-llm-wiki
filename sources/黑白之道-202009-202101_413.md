# Windows XP源代码被曝泄露

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650484233&idx=1&sn=d7f36877260113eea9eb46c482f56ff0&chksm=83ba4bedb4cdc2fbd4e87ed3c8c66bb4c8ad3def4138218b2ecd696c701f038b21ccd85787a2&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650484233&idx=1&sn=d7f36877260113eea9eb46c482f56ff0&chksm=83ba4bedb4cdc2fbd4e87ed3c8c66bb4c8ad3def4138218b2ecd696c701f038b21ccd85787a2&scene=27#wechat_redirect)

[![](../Images/4d18a542a7b3f8424d19035b1e0fda1b.png)](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650466877&idx=3&sn=06016373daab95504e269cc6275bea55&chksm=83bb8fd9b4cc06cfecfaae913e653b7431d970af0edfee7a6d1d4b6de96474216ea10efdbee2&scene=21#wechat_redirect)

昨天，疑似匿名组织放出Windows XP源代码，从压缩包打包时间看，为2020年6月6日。数据下载请后台回复：**0926源代码。**  

![](../Images/0f66011595119078d0cc3fada24acbf7.png)

  
最开始是推特上看到有人发出这个消息，百万网盘和迅雷大军迅速出动。  

![](../Images/6cb1a4c1140691a1396b12c024a5ad1c.png)

  
不过最开始流传的网盘资源都是2~3g的所谓Windows XP源码，直到一个种子文件的出现才真正揭露了这次泄露事件的全貌。

  

![](../Images/46c53cc59826af9b80dd257cd97aac69.png)

  

可以看到这次全部的泄露内容远不止Windows XP源码，不过其中重量级的确实当属XP源码。  
黑客声称这是他收集两个月得来的资料，包含Windows XP及Windows Server 2003的源码，也包括DOS、NT、2000等部分此前泄露过的源码。并且表示，这是第一次正式公布。

  

此源代码的真实性有待确认，不过有兴趣的朋友还是可以下载来深入研究Windows。
