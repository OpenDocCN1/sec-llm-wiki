安装过程

Docker 启动

拉取镜像

docker pull tophant/arl

修改docker/docker-compose.yml 中services web image 和 services worker image 对应的镜像地址。

git clone https://github.com/TophantTechnology/ARL
cd ARL/docker/
docker-compose up -d
