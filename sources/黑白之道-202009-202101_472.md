### 安装过程

### Docker 启动

拉取镜像

```
docker pull tophant/arl
```

修改`docker/docker-compose.yml` 中services web image 和 services worker image 对应的镜像地址。

```


git clone https://github.com/TophantTechnology/ARL
```

  

![](../Images/42b5d215bc2913495f2e0b7a6fc44487.png)
