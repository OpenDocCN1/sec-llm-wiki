# evillimiter分析和限制本地设备上的带宽的工具。

evillimiter一种无需物理或管理访问即可监视，分析和限制本地设备上的带宽（上传/下载）的工具。evillimiter使用ARP欺骗和流量整形来限制网络上主机的带宽。要求Linux发行版

  
Python 3或更高版本

  
在安装过程中可能会安装可能丢失的python软件包。

  
安装

  
git clone 

https://github.com/bitbrute/evillimiter.git 

cd evillimiter  --cd到该文件所在目录下

sudo python3 setup.py   --安装

  
用法

  
键入evillimiter或python3 bin/evillimiter运行该工具。

  

evillimiter 会尝试自行自动解析所需的信息（网络接口，网络掩码，网关地址等）。

限制条件

  
仅限制IPv4连接，因为ARP欺骗要求仅在IPv4网络上存在的ARP数据包。
