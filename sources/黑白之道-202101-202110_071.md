**ag：**比grep、ack更快的递归搜索文件内容。

  

![](../Images/5075e39404ab96509bc8d50bd7117dd4.png)

  

**tig：**字符模式下交互查看git项目，可以替代git命令。

  

![](../Images/d1231de19bc21f10406565579e222161.png)

  

**mycli：**mysql客户端，支持语法高亮和命令补全，效果类似ipython，可以替代mysql命令。

  

![](../Images/e7aa9c83ec661e6b0bcd39e4c7866f8a.png)

  

**jq: **json文件处理以及格式化显示，支持高亮，可以替换python -m json.tool。

  

![](../Images/a519f487a267fd06e7b665de1883af44.png)

  

**shellcheck：**shell脚本静态检查工具，能够识别语法错误以及不规范的写法。

  

![](../Images/87b68d3153a9c66ffa88b693ceb9f0c1.png)

  

**fzf：**命令行下模糊搜索工具，能够交互式智能搜索并选取文件或者内容，配合终端ctrl-r历史命令搜索简直完美。

  

![](../Images/6c942e85fce7f094f81f4c3fe68b3d6c.png)

  

**PathPicker(fpp): **在命令行输出中自动识别目录和文件，支持交互式，配合git非常有用。

运行以下命令：

  

```
git diff HEAD~8 
```

  

![](../Images/8bbe1bfda8403a68c40f451078395395.png)

  

**htop: **提供更美观、更方便的进程监控工具，**替代top命令。**

  

![](../Images/4fccaedd53b65d3a868676b94ba6524a.png)

  

**glances：**更强大的 htop / top 代替者。

htop 代替 top，glances 代替 htop：

  

![](../Images/37aa2807082c0abd174414abb4f21198.png)

  

信息比 htop 丰富了不少，更全了，对吧？除了命令行查看外，glances 还提供页面服务，让你从页面上随时查看某服务器的状态。

  

**axel：**多线程下载工具，下载文件时可以替代curl、wget。

  

```
axel -n
```

![](../Images/087d10872783e84416045a6c9ada4b0b.png)

![](../Images/cc0e98cb53b830f207935ada1933e196.png)
