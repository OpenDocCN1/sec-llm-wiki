# 下一代起名Windows 11？？？NO.NO.NO

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxMjE3ODU3MQ==&mid=2650514304&idx=1&sn=de8cf9547c2d1a8082ede958aed2eeac&chksm=83bac664b4cd4f72066f63bcaa115d42e67a5541159d15a0074046ed7cd1f276eb8997cd0efe&scene=27#wechat\_redirect](http://mp.weixin.qq.com/s?__biz=MzAxMjE3ODU3MQ==&mid=2650514304&idx=1&sn=de8cf9547c2d1a8082ede958aed2eeac&chksm=83bac664b4cd4f72066f63bcaa115d42e67a5541159d15a0074046ed7cd1f276eb8997cd0efe&scene=27#wechat_redirect)

微软员工可能错误地泄露了即将到来的下一代 Windows 10的命名，转而使用类似苹果公司的地理位置或开发命名方案。

  

![](../Images/1d6e60bf8c67af4cb7a5ca66e7d43c8d.png)

  

**当微软发布Windows的新主要版本时，它历来只是更改了与该版本相关联的数字。例如，Windows 7 > Windows 8 > Windows 8.1 > Windows 10。**

  

**上周，微软宣布在6月24日将举行一场新闻发布会，届时将“推出下一代 Windows”。 **  
微软全球副总裁在推特上发布了一段预告视频，其中显示了阳光通过Windows徽标流过以显示数字**11**。

  

![](../Images/355a3521f262447de1f528c94e134075.png)

  

因此，许多人认为微软可能会暗示下一个版本是Windows 11。  
无论名称如何，我们都知道Windows 10的下一个主要版本目前代号为**“Sun Valley”（太阳谷）**。与过去的几个功能更新不同，它是一个具有新的现代功能和更新的用户界面的大规模版本。

  

**泄露的元数据可能指向新的命名方案**  
当微软更新他们的网站文档时，他们会在他们的GitHub存储库上发布更改。正如Windows Latest首次报道的那样，微软最近更改了公共“ Windows 应用程序管理”页面的HTML元描述，以使用以下描述：

  

“了解如何在 Windows 10 和 Windows Sun Valley 中管理应用程序。”![](../Images/9ef603b9c81ecf50778becb3c4564bd9.png)参考 Microsoft 文档站点中的 Windows 10 Sun Valley

  

在意识到他们错误地将“Windows Sun Valley”添加到页面的元数据后，他们迅速将元描述更改为“了解在 Windows 10 中管理应用程序”。  
![](../Images/56304aa54e5ab04c88487d9e19b2f36c.png)GitHub 提交显示已删除的对 Windows Sun Valley 的引用

  

此次泄密是微软首次公开提及 Windows 10的后续版本Sun Valley更新。但是，它的编写方式也表明，微软认为Windows 10和 Windows Sun Valley有很大不同，而不仅仅是对Windows 10的更新。

  

**这也可能表明微软正在转向类似于苹果操作系统的Windows操作系统的新命名方案。例如：macOS Catalina > macOS Big Sur > macOS Monterey。**

  

**当然目前这只是猜测，直到即将到来的Windows活动我们才能确定，或许真叫11，毕竟这样方便全球化统一称呼。**

  

正如微软之前所说，Windows 10是Windows的最后一个版本，他们可以继续使用当前的代码库并切换到新的命名方案。通过这样做，他们将继续验证他们的声明，即Windows 10在微软的开发史上即将终结。
