# 用短视频作色情APP的外衣？这伙人被江苏泰州警方抓了！

> **文章来****源：****安全圈**

如今各类短视频平台迅猛发展、热度不减但由于短视频门槛低、传播广极易被不法分子非法利用进而演变为违法犯罪活动。

  

近日在泰州市公安局网安支队指导下兴化警方成功破获一起利用短视频平台引流推广色情APP的非法利用信息网络案件。

![](../Images/030faff305f81bcebdd96ee5cc26bd1d.png)

  

![](../Images/26271dc71a4ec6f1b2c46c5066d77b84.png)

  
今年1月，兴化市公安局网安大队在工作中发现有人利用某短视频直播平台，为某境外色情APP进行引流视频发布点击量较大，影响恶劣兴化警方迅速成立专案组展开侦查。  
![](../Images/05835303ed24cc883b13ec443a8d948d.png)

  

1月29日，兴化警方通过研判分析，成功抓获7名犯罪嫌疑人后民警进一步研判深挖组织架构，于2月下旬至5月初分赴河南、广东、福建、浙江、广西等地再次抓获17名嫌疑人扣押作案手机200部、电脑30台涉案金额500余万元。![](../Images/72ed6166f052722b20f497081a781b5d.png)  
  

经查，该团伙制作包含色情APP下载地址的视频通过某短视频平台发布，引导网民大量下载，后根据下载量以每次几十元的价格与该APP结算从而获利。

  

![](../Images/faeb49569c1d282f533e3c53e2d74367.png "4.jpg")

  

此案组织架构复杂，团伙分工明确，最上层为APP境外客服，国内设代理商并由其各自发展下线。

  

![](../Images/3ab416087cc50a1e552902702279990b.png)

  

目前，该团伙主要嫌疑人王某，因涉嫌非法利用信息网络罪已被逮捕。其他23名涉案嫌疑人，均被采取刑事强制措施，案件正在进一步侦办中。

  

**警方提示**

根据《中华人民共和国刑法》第二百八十条之一第一款和最高法、最高检《关于办理拒不履行信息网络安全管理义务、非法利用信息网络、帮助信息网络犯罪活动等刑事案件适用法律若干问题的解释》第十条，**发布有关违法犯罪的信息或者为实施违法犯罪活动发布信息情节严重的，应当认定构成非法利用信息网络罪。**
