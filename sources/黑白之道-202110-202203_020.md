**Neo-reGeorg + Socks = 进入目标内网漫游**

  

想要扩大战果还是要做个隧道进行目标内网，但是我发现常用的 frp、nps 都用不了，猜测目标做了限制，后来通过 http 隧道成功进了目标内网！

reGeorg 是 reDuh 的升级版。主要把内网服务器的端口通过http或https隧道转发到本机。

项目地址：https://github.com/L-codes/Neo-reGeorg
