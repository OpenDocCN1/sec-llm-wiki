# 东京警方遗失两枚储存有38名民众个人信息的软盘引民众惊讶

> **文章来源：****安全学习那些事儿**

2021年12月27日，对于当前的许多“00后”来说，对于U盘这一可移动介质应该并不陌生，但是对“软盘”这一储存介质可能没有见过和听过，在U盘容量越来越大的当下，你敢相信在数码领域拥有诸多贡献的日本，居然还有警察在用软盘储存信息吗?

  

  

![](../Images/0da63b5788535c1f9c6ea7b928393556.png)  

  

近日，据日媒报道，东京警方发现**遗失了两枚储存有38名民众个人信息的软盘，并为此向涉事民众致以由衷的歉意**。这一消息被报道后在日本国内引起了热议，而引发讨论的并不是警方可能造成民众信息泄露一事，而是对日本警方居然还在使用软盘存放信息表示惊讶。

  

  

![](../Images/0231b14b457851455f221f7d03e27672.png)  

  

针对这一事件，日本网友纷纷发表了自己的看法，有人称：“在听到软盘时，我第一反应以为是个假新闻”。也有网民称：“官方机构竟然还在用能够读取软盘的计算机，那么这些计算机的系统会是什么样?”。也有网友针对日本警方的管理疏忽讽刺道：“即使软盘丢失了，(盗取的人)会因为没有读取软盘的机器所以没法看到里面的内容，真是‘值得称赞’的防泄漏对策。”据悉，软盘是个人计算机中最早使用的可移介质，最首先由IBM公司于1967年推出，在不断迭代发展之后，容量为1.44MB的3.5英寸软盘成为了最常用的型号。软盘曾经盛极一时。之后由于U盘的出现，软盘的应用逐渐衰落直至淘汰，至今几乎已经很难再看到其身影。而此次日本警察竟然还在使用软盘储存民众的个人资料，也着实让人感到意外。
