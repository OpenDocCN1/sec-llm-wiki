## **前言**

  

最近几天不断收到系统的报警信息，提示CPU利用率过高。

主机长时间的高占用一般是由挖矿木马导致的，因此下面就以挖矿木马的方式进行排查系统。

  

![](../Images/98ad5910ba99ed1ca3f0886a3be5053c.png)

  

## **排查思路**

  

### **查看资源占用情况**

```
ps
```

查看到“ftpuser用户”的一个进程占用了将近90%的CPU资源。

  

![](../Images/7e4c3d737d38c4a3e78cef747b1c39fc.png)

  

### **查找进程真实路径**

```
ll /proc/2850
```

由下图所示，可以发现攻击者在目录/home/ftpuse创建了一个隐藏目录

  

![](../Images/c85c8cee252ca4fc1f63ffbab40a2c45.png)

  

进一步查看文件内容

  

![](../Images/75d988e0812e5342286b24ea57527918.png)

  

### **分析文件启动进程**

  

由于此处文件太长，就不全部展示了

大致分为两个部分

第一部分：

由Base64编码的恶意代码

  

![](../Images/47319c624952aae628e87e82488d6126.png)

  

将这部分的代码进行解码，解码发现这部分数据仍然存在加密情况

  

![](../Images/c19f0b82b8824f647a57b89306369bd5.png)

  

通过构造prel脚本，对文件进行解密

```
perl error.pl
```

![](../Images/ac6b3692b08f052579a444d5c7c51f64.png)

  

（注:这一部分只需要将eval替换为print，就可以使用prel脚本进行解密了）

由上图所示，可以发现木马真实进程为“PS”

并且攻击者的IP为45.9.148.99，ip真实地址为荷兰

  

![](../Images/dd88bfbb12015fe5bb933886f67b233b.png)

  

通过威胁情报平台查看该IP的标签，至此基本断定本次捕获的为批量挖矿代码植入的攻击

  

![](../Images/46d98c7b2974921ccaae3b65189c2831.png)

  

第二部分：

  

攻击者的植入了rsa公钥，方便以后免密登录ssh的后门

  

![](../Images/b00292ab2e1a738479b18ad19cce5c28.png)

  

### **挖矿木马文件结构分析**

  

从上面的检查过程中可以发现定时任务一共建有5个任务下面对文件一一进行查看

文件一：

定时任务：1 1 \*/2 \* \* /home/ftpuser/.configrc/a/upd>/dev/null 2>&1

路径：/home/ftpuser/.configrc/a/

  

![](../Images/f03aaf2e7c26bf6eb107a0709a0b2a92.png)

  

先打开文件upd

  

含义：如果当前进程存在，就清除进程。然后执行/home/ftpuser/.configrc/a/run

  

![](../Images/42525c6a4ff4949144fcbb012f9ecf8a.png)

  

再打开文件run

含义：先判断cpu类型，本机是x86\_64所以执行/home/ftpuser/.configrc/a/cron:

  

![](../Images/6e5d89a37b9bce82dc46e2c913405f3d.png)

  

文件二：

定时任务：@reboot /home/ftpuser/.configrc/a/upd>/dev/null 2>&1

与上同，重启时生效

文件三：

定时任务：5 8 \* \* 1 /home/ftpuser/.configrc/b/sync>/dev/null 2>&1

路径：/home/ftpuser/.configrc/b

文件sync

含义：运行真正shell文件是/home/ela/.bashtemp/b/run

  

![](../Images/3c3d3c70441b3bc6c6d26a7821ea9347.png)

  

文件run

含义：执行恶意代码

  

![](../Images/75569afdf64a961c3f8647b2ab3a0866.png)

  

文件四：

定时任务：@reboot /home/ftpuser/.configrc/b/sync>/dev/null 2>&1

与上同，重启的时候生效

文件五：

定时任务：#0 \*/23 \* \* \* /tmp/.X26-unix/.rsync/c/aptitude >/dev/null 2>&1

路径：/tmp/.X26-unix/.rsync/c

文件：aptitude

  

![](../Images/4f89b1677e898ad51de051a4227ec61f.png)

  

文件：run

  

![](../Images/a7ba0a7445b6de3809e28fa35659e1f0.png)

  

这里面调用的shell的是golan

  

golan内容如下:

  

![](../Images/ca6d0fa155a7ecd008e9a2fed36292f4.png)

  

并且在/tmp目录下发现了

  

位于/tmp/.X26-unix/木马压缩包

  

![](../Images/1f85f65671ef88e99c791488709965ef.png)

  

位于/tmp/.X19-unix/.rsync/initall下的木马安装脚本

## **挖矿木马清除**

  

删除进程

  

![](../Images/dc80c485cdbe0879801a19308d7e02e9.png)

  

删除所有定时任务

```

crontab -l -u ftpuser
```

![](../Images/c810d8c9f57524b8120a6d75936cb046.png)

  

删除.SSH下的文件

  

![](../Images/e609fcf50954e22e844bc08f81b39cb8.png)

  

删除用户ftpuser下的木马目录

  

![](../Images/4c26615aaea1fd3b2442e993fd37584a.png)

  

删除用户root下的木马文件

  

![](../Images/9eada1d924e5cb30a0dd5568c3f4d9d6.png)

  

至此就完成了挖矿木马全部清除，但是正常服务器需要排查日志，查看入侵完整路径并及时修补才能结束。
