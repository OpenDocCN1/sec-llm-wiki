微软封禁下，俄罗斯对盗版 Windows 的需求量“暴涨”！

受当前局势影响，近几个月来已有多家跨国科技企业宣布停止在俄业务，不少游戏厂商、音乐和电影流媒体也先后暂停了俄区服务，甚至连本该“无国界”的开源也变得不再纯粹：GitHub 封禁俄罗斯开发者账户、开源项目 NGINX 宣布禁俄……

面对如此境遇，俄罗斯在努力开发国产替代的同时，对盗版的需求也直线暴涨，尤其是对以 Windows 系统为代表的盗版微软产品。

1、对各类盗版微软产品的搜索量猛增

早在今年 3 月，微软就曾宣布暂停其在俄罗斯的所有新产品和服务销售。彼时微软还留有一丝余地，即会继续服务俄罗斯的中小学、医院和其他一些机构。

但从 6 月中旬开始，俄罗斯用户突然毫无征兆地面临各种问题：无法从微软官网下载 Windows 10 和 Windows 11 系统，连带着系统的实用程序、镜像和媒体创建工具程序等也不能下载。一旦俄罗斯用户尝试下载上述内容时，系统就会显示“404-找不到文件或目录”。

经过测试，俄罗斯 IT 人员发现如若使用非俄罗斯地区的 IP 地址即可正常操作，由此得出结论：来自俄罗斯的 IP 地址已被微软限制使用此项服务。

不仅如此，微软总裁 Brad Smith 上周在接受采访时也表示，微软将继续退出俄罗斯市场，直到完全退出（据路透社报道，微软将在三个月后完全退出俄罗斯）。

此消息一出，许多俄罗斯人的第一反应就是：火速上网搜索包括 Windows 操作系统在内的各类盗版微软产品。

据《生意人报》报道，过去三个月内俄罗斯对盗版微软产品的网络搜索量飙升了 80-250%，光 6 月份 Excel 下载的搜索量就激增了 650%，而在过去一周，即曝出俄罗斯用户无法从官网下载 Windows 10 和 Windows 11 后，关于 Windows 10 媒体创建工具的搜索量也增加了 47 倍。

2、一条不可持续的“死胡同”

在众多微软产品中，操作系统作为基础软件之“魂”，加之 Windows 的份额在桌面操作系统市场中“一骑绝尘”，从微软在 3 月宣布暂停俄区服务时，俄罗斯或许就已经预测到 Windows 将受到限制：过去三个月中，除了盗版 Windows 的搜索量猛增，基于 Linux 的俄罗斯软件开发商的销售额也略有上升。

据报道，俄罗斯政府机构已计划从 Windows 转向 Linux，其中约有 2% 的台式电脑已开始使用基于 Linux 的国产操作系统。

但是，对与广大俄罗斯用户而言，过渡至基于 Linux 的系统和软件主要存在两个问题。

  • 无法轻易切换。如今很多公司的运作流程均由软件控制，而正如钢铁巨头 Severstal 首席信息官 Sergey Dunaev 所说，软件通常会嵌入到设备中，而设备制造商为严密保护其知识产权，不会让客户轻易访问其中的代码，这就很难进行切换。

  • Linux 的生态不如 Windows 繁荣。相较于着重为普通用户开发各类应用和游戏的 Windows，现阶段的 Linux 仍然是一个专业社区。在此情况下，IDC 分析师 Elena Semenovskaya 指出，转向 Linux 的用户“必须足够厉害，才能应对驱动程序、应用程序和其他组件的调整”，而这在很大程度上劝退了许多人。

这两个问题也就意味着：起码在短期内，俄罗斯几乎很难找到 Windows 的完美替代。IDC 分析师 Elena Semenovskaya 对此表示：“（俄罗斯）目前的方法是依靠盗版和过时版本，但这是一条死胡同，不可持续。”

3、网友：“这难道会是 Linux 桌面元年？”

针对上述情况，许多网友纷纷留言，认为这或许是 Linux 崛起的大好机会。

  • “… 这难道会是 Linux 桌面元年？”

  • “微软退出俄罗斯市场，显然增加了 Linux 的用户群。”

同时，也有人认为这对俄罗斯而言或许没有太大影响：“自打我记事起，俄罗斯好像就一直在使用盗版软件。从 PC 首次出现在俄罗斯以来，很多俄罗斯人都在使用盗版 Windows、Microsoft Office 和大量其他应用程序，大概是因为其工资收入一直远远落后于西方国家。”
