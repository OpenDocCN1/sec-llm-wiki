1，软件界面、功能及限制  
![](../Images/f94a12dc4e7d11a12c11d1801c127949.png)  
![](../Images/f353c0df0b8f39a6f89514ea0b28b2da.png)  
功能：屏幕画笔、放大镜、按键显示、聚光灯、鼠标指针亮显等功能  
  
限制：功能都正常使用，试用版每5分钟弹注册窗（见上图的翻译）  
  
2，查壳  
  
.net程序：.NET + dotfuscator - PreEmpire Solutions v1.2 - 6.2 \[ v.?.? \] - www.preemptive.com  -  stub :  MS Visual C# / Basic.NET / MS Visual Basic 2005 - EP Token : 060001A4  

![](../Images/ee4fc4ea42bebacc5651a1592aca6526.png)

  
  
3，去混淆  
  
用De4dot.exe去混淆。  
  
4，用dnspy打开分析  
(1)查找注册窗中文本“Register”,如下图找到按钮  

![](../Images/0011f347c86c6ebcb9bc1d92229f5976.png)

  
(2)转到按钮事件的方法并分析  

![](../Images/77a2720a1a668325bfba42c107bdbd68.png)

  
(3)试试这个注册码“11111111x111111”吧，竟然如此简单！？我被骗到了……  

![](../Images/c949ba0cda0e2bf2478894f7233e6b77.png)

  
(4)注册窗还是准时到来  

![](../Images/ccd54c9a71ff08c2452f42a37e27dbcb.png)

  
(5)限制说明怎么说来着？每5分钟弹注册窗口，要从“Timer”和注册窗体入手了。  

![](../Images/0b4dbf75b604cd97306e7669b2b6b9d0.png)

  
(6)分析这些方法  
①“timer\_0\_Tick”、“method\_3”、“method\_6”中无创建操作，不考虑。  
  
②“timer\_4\_Tick”中“FormToolBar”的成员“bool\_1”要为“true”创建窗口；“FormToolBar\_MouseClick”中“FormToolBar”的成员“bool\_2”要为“true”创建窗口。  

![](../Images/50267dd6c3f2ccb5975d472b2f8081a8.png)
