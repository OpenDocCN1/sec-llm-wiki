一、工具介绍

是一个 Web 应用程序侦察套件，专注于通过引擎、侦察数据关联、持续监控、数据库支持的侦察数据和简单而直观的用户界面的高度可配置的流线型侦察过程。 

  

  
二、安装与使用1、下载项目到本地

*   

```
`git clone https://github.com/yogeshojha/rengine && cd rengine`
```

  
2、编辑dotenv文件，务必修改postgresql POSTGRES\_PASSWORD 的密码

*   

```
`nano .env`
```

  
3、运行安装脚本，如果没有权限，运行chmod +x install.sh

*   

```
`sudo ./install.sh`
```
