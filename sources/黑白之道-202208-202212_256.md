**0x01 前言**在日常登录和获取验证的时候，会遇到各种各样的加密方式，今天介绍最近刚到的提示。加密密码出现在表单提交过程中，下面是中国电信的登录中，支持详细讲解利用pyv8来加密的。**0x02 JS加密**首先我们电信用户的登录了解`xxx.cn/web/login` ，打开开发者工具，点击网络，输入手机号和秘钥，点击验证码，点击登录，在所有人栏登录。![](../Images/76fbd2235d011864e1891e291a61fbb5.png)可以看到密码字段是加密以后的密码，那么怎么加密的呢？![](../Images/56baedf01541287d7935ae8208d62685.png)点击发现右边的不就是加密吗？不着急，我们看到CryptoJS库了吗？`https://xxxx.cn/web/static/js/crypto-js/rollups/aes.min.js` 分析一下这就是JS加密算法，的思路是加载CryptoJS发现然后，用他来加密我的密码，我们来找到CryptoJS这个加密JS。![](../Images/0303e03a38d1d762c47fc5015caeeea6.png)继续下看我们看到aes.min.js（进去后发现就是我们上面需要的加密算法），到这里我们才能够成功，然后下载这个加密算法，运行加密函数，我们输入的明文密码再加密成密文。我们先下载aes.min.js这个js文件，保存到本地取名为：crawl\_.js。  
接下来就是我们使用pyv8来执行JS加密的过程，代码如下：

```
`import PyV8  ctxt   = PyV8.JSContext() '请输入验证码:' ) ''  ' ''+"'{}'"。格式(c)+''  ',i, { ''  open('crawl_.js'  )as f: func()`
```

![](../Images/bcc4348935d3e531847f38185477c3c6.png)运行代码我们输入：`123456` 加密后的结果为：`aeMui9uecQAA8XCQwfpUEA==`
