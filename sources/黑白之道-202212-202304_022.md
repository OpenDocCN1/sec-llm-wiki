**0x01 fuxploider介绍**

  

Fuxploider是一种开源渗透测试工具，可自动检测和利用文件上传表单缺陷的过程。该工具能够检测允许上传的文件类型，并能够检测哪种技术最适合在所需的Web服务器上上传`Web Shell`或任何恶意文件。![](../Images/04d046122233675de2f9d673028539e9.png)

  

  

**0x02 fuxploider安装**

  

  

Python3.6+

```


git clone https://github.com/almandin/fuxploider.git
```

如果您的pip有问题(并且您使用Windows)：

```
python3 -m pip install
 -r requirements.txt                       
```

对于Docker安装

```
docker build -t almandin/fuxploider .                   
```

  

  

**0x03 fuxploider使用**

  

  

要获取基本选项和开关的列表，请使用：

```

python3 fuxploider.py -h              
```

帮助：

