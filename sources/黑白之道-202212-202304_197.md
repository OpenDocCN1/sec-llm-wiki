0x01 工具介绍  
  
功能：协助红队人员快速的信息收集，测绘目标资产，寻找薄弱点。语言：python3开发功能：一条龙服务，只需要输入根域名即可一键化收集敏感信息。具体案例见下文。调用：脚本借用了JSFinderjs内容提取脚本，感谢Threezh1作者  
0x02 安装与使用  
为了避免踩坑,建议安装在如下环境中1、当前用户对该目录有写权限，不然扫描结果无法生成。root权限即可2、Python环境必须是3.7以上，因为使用了异步。建议VPS环境是ubuntu20，默认是python3.8。安装模块的时候切记不要走豆瓣的源

*   
*   

```
`chmod 777 build.sh``./build.sh`
```

3、查看帮助信息

*   

```
`python3 webpackfind.py -h`
```

![](../Images/07c7700787b80a471ebd8f384af140a7.png)4、自动爬取网站

*   

```
`python3 webpackfind.py -u http://www.baidu.com`
```

![](../Images/135eab8779e4d445b0924e4273ea2544.png)5、自动爬取本地文件

*   

```
`python3 webpackfind.py -j ./js/http://www.baidu.com/`
```
