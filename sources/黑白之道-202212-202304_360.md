一、工具介绍xp\_CAPTCHA (白嫖版)，是一款验证码识别工具，是BurpSuite的一款插件，支持验证码返回包为json格式。  
二、安装与使用(需要python3 小于3.7的版本)1、安装 muggle\_ocr 模块（大概400M左右）

*   

```
`python3 -m pip install -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com muggle-ocr`
```

  
![](../Images/ff9e1f7cce777ca20b318c32680c5025.png)  
2、运行 server.py，等待显示出 Starting server, listen at: 0.0.0.0:8899 访问 http://127.0.0.1:8899/ 显示下面界面即为正常。  
![](../Images/b8752f86e1e51e209f987e16c6d40aae.png)  
3、burp联动识别验证码爆破如果 server.py 在服务器上跑的话，xp\_CAPTCHA.py需要修改对应的IP。  
![](../Images/5bed2c54ef7cde10677c555a88742484.png)  
修改完后导入burp

![](../Images/df9d3fd6e6f7397b41b45e7e3e5485d2.png)

此处导入字典
