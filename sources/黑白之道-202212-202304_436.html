张小龙推出微信键盘，

不为市场只为保护用户隐私

12月19日，微信键盘 1.0.0 正式版发布，用户可从各大应用商店下载。与其他第三方输入法类似，用户首先需要下载微信键盘，并在设置中开启微信键盘，且将输入法切换到微信键盘，便可开始使用。

根据官方介绍，微信键盘是腾讯微信团队打造的一款中文输入法，支持中英文输入，可选择九宫格、全键盘、五笔、笔画、双拼、手写等多种输入方式。同时支持语音转文字，可识别普通话、粤语、英语等。
微信键盘还拥有智能推荐和拼写检查等多种功能，其中，智能推荐允许用户在微信聊天中输入文字，便捷分享与文字相关的书影音、小程序、公众号等内容。拼写检查可以为输入的内容精准校对，将错别字转换为正确版本。
微信键盘在App Store中的部分介绍。
微信做输入法始于2021年年初的微信十年公开课上。在2021年1月19日的个人演讲中，腾讯高级执行副总裁、微信事业群总裁张小龙称，为了更好地保护用户隐私，微信正在灰度测试自己的输入法。
张小龙称，微信本来并不想去做输入法，但收到很多用户投诉自己的聊天记录被窃取，因为输入什么就会看到相应的广告。据他解释，腾讯员工窥探聊天记录会被开除，且微信不在云端保存聊天记录，但从输入到接收信息的链路很长，因此为了更好地保护用户隐私，微信正在灰度测试自己的输入法。
据易观千帆数据，2021年11月中国第三方输入法整体月度用户规模7.14亿，活跃人数全网渗透率68.5%，市场“马太效应”显著，搜狗输入法、讯飞输入法、百度输入法占据了95%以上的市场份额。
事实上，市场占有率较高的搜狗输入法也是腾讯旗下产品，2021年10月腾讯耗资11.5亿美元的搜狗收购案落下帷幕，搜狗旗下浏览器、输入法等业务融入了腾讯平台与内容事业群。
此次推出的微信键盘则属于腾讯旗下的微信事业群。据腾讯公司三季报，截至2022年三季度，微信和WeChat（微信海外版）合并月活用户量为13.09亿，同比增长3.7%。在用户量超十三亿的国民级应用中推出微信键盘，国内输入法的市场格局是否会被改写，仍需等待时间的检验。

GitHub与微信达成合作帮助防护用户隐私

12 月 20 日消息，据微软 GitHub 官博消息，GitHub 与腾讯微信达成合作，通过扫描访问令牌，来帮助保护所有公共仓库和私有仓库的共同用户。

GitHub 密钥扫描会通过搜索存储库中的已知类型的密钥来保护用户。通过识别和标记这些密钥，有助于防止数据泄露和欺诈。
腾讯微信令牌则允许用户验证微信公众号和小程序开发者，获取业务应用的敏感信息，并可用于验证商家身份。
具体来说，GitHub 会将在公共仓库中找到的访问令牌转发给微信，微信将通知受影响的用户。微信鼓励用户删除 GitHub 上泄露的 API token，并在微信支付商家平台或微信公众号平台上创建新 token。
微信支付的密钥包括：
APIv2 密钥 (opens new window)，用于 APIv2 所有接口。
商户 API 证书 (opens new window) 对应的私钥，用于 APIv2 的高安全级别接口和 APIv3 所有接口。
APIv3 密钥 (opens new window)，用于 APIv3 的微信支付平台证书下载接口以及回调通知。
如果以上密钥在 GitHub 泄漏，可以根据链接中的文档执行应急处理。
