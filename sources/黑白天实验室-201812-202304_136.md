# 网安行业人才短缺，年薪30w虚席以待

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzU4NTY4MDEzMw==&mid=2247490496&idx=1&sn=6d6869bc41cbe3e9c00ea6921b477c20&chksm=fd878faacaf006bc42949eb04f46d90eb1886c27fd1b23c06c55c33743473d681466189e0d36&scene=126&sessionid=1681574463#rd](http://mp.weixin.qq.com/s?__biz=MzU4NTY4MDEzMw==&mid=2247490496&idx=1&sn=6d6869bc41cbe3e9c00ea6921b477c20&chksm=fd878faacaf006bc42949eb04f46d90eb1886c27fd1b23c06c55c33743473d681466189e0d36&scene=126&sessionid=1681574463#rd)

随着全球范围内网络安全事件的日益增加，《网络安全法》及一系列配套政策法规的逐步落地实施，国内政企机构对网络安全的重视程度也日益提高，对网络安全人才的需求呈现爆发式增长。

  

  

**供不应求，高薪难抵百万缺口**

  

2020年9月16日，中国信息通信研究院发布的《中国网络安全产业白皮书(2020年)》显示，在2019年我国网络安全产业规模已达1563.59亿元，同比增长17.1%，预计2020年将达1702亿元。

![](../Images/3a8d9343e563d695020da26b6ea5defc.png)

  

报告中指出，2019年我国网络安全人才缺口仍在不断扩大。全球网络安全劳动力缺口高达127万，需在现有280万的基础上增加45%，才能够满足热议增长的网络安全专业人员需求。  

  

根据智联招聘网络安全人才大数据显示，2019年6月网络安全人才市场需求的规模达到2016年1月需求的24.6倍，相比2018年7月也增长了3倍，增长速度堪称惊人！

![](../Images/681c8cee833172eabdd07070502ccca5.png)

同时，伴随规模的增长，网安人才需求的地域集中度持续下降。2019年网安人才需求最多的5个城市占全国总需求的比例从60.7%下降到48.8%，降低了16.5个百分点，网络安全人才需求不再集中于少数的几个大城市。

  

![](../Images/5d0b7e05bf8e1e796f754ad1202a5c37.png)

此外，网络安全行业人员的**薪资水平也存在很大的晋升空间**。据猎聘联合上海控安推出的《2019中国网络安全与功能安全人才白皮书》显示，去年我国网络安全人才的平均年薪为24.09万元。

  

2019年求职者期望的平均薪资为11263.9元/月。而政企机构提供的网络安全相关岗位的平均薪酬约为11728.9元/月。安全企业提供给网络安全相关岗位的平均薪酬约为12004.8元/月。

  

![](../Images/e8011ff34ab89f12d7e3fd0b4cc0b10d.png)

由此可见，网络安全是一个市场前景和职业发展前景都相当广阔的行业。但**任何一个行业，所谓“人才短缺”缺的都是人“才”，而不是人“力”。**因此，比起对网络安全行业的价值认知，如何成为真正的网安人才更值得研究。

  

网络安全行业的从业者，从入门开始就要学习诸如安全运维、系统编程等纯技术相关的专业知识，这是行业基础和门槛。但随着职业生涯的发展，除了提升专业技能外，还需要更广泛的知识覆盖面和专业认证来提供晋升背书，而CISAW认证无疑是最佳的选择。

  

  

  

**机遇：全国独有的情报培训**

  

目前，我国情报系统中的国家部委、各省市自治区、地方等绝大多数情报机构（信息机构）均独立建立有网络系统。国家对于网络情报能力的重视度逐渐加强，但由于缺乏体系化、专业化的网络情报分析理论和技术培训机制，网络情报分析人才的短缺成为网络情报体系搭建最大的短板。

  

近期，作为国内官方认证的专业网络情报培训中心，福韵数据携手中国网络安全审查技术与认证中心重启CISAW网络情报分析培训，重点培养学员网络情报收集、整合、分析和转化的能力，力求辅助各个行业培养更多的情报分析专家。

  

为打造“开源情报+融合”课程体系，2021年起福韵将不定期邀请开源情报和跨学科融合领域的专家参与授课交流，致力为学员打造更高质更全面的网络情报培训服务。

培训介绍

  

在中央网信办、中国网络安全审查技术与认证中心的大力支持下，**福韵数据服务有限公司**成为**官方认证**开设CISAW网络情报分析方向培训课程的企业。

  

CISAW（Certified Information Security Assurance Worker）为信息安全保障人员认证，是中国网络安全审查技术与认证中心针对信息安全保障领域不同专业技术方向、应用方向和保障岗位，依据国际标准ISO/IEC 17024所建立的、不同层次的信息安全保障人员认证体系。

  

网络情报分析为CISAW主要认证方向之一，主要是指依托软硬件系统，应用网络情报相关理论、技术、方法、手段和经验，对互联网数据进行深度挖掘、全面搜集和综合分析，以获取有价值的情报。
