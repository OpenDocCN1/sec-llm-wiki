工具介绍

```




reGeorg
```

为什么使用代理？

```



就好像我拿下了一个webshell,想进行内网渗透,但是我不能直接访问内网的其他主机,他只允许内网主机互相通信。那我们就可以在webshell的这台主机上设置代理,把流量转发出来。
```

