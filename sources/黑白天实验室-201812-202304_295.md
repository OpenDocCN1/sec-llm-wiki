burp右键菜单选择Engagement tools 中文翻译为作战工具

右键选择Engagement tools  
从上到下依次翻译为

```








Search                        搜索
```

![](../Images/cfcec54871240f87e4249c3b35d3efc2.png "83825-fjc9cwwauvw.png")

Search搜索  
输入字符串即可查找需要的字符串，相当于浏览器view-source后再Ctrl + F查找字符串。通常配合正则使用例如一些敏感的参数user pass id 等等

```

(.user|pass|accessKeyId|accessKeySecret|secretToken|callback|admin|config|key|access|token?)
```

![](../Images/7ffd1b04bb563eba05760a4d6293dcef.png "99558-0haw2qudr5q5.png")

可以在每次测试完漏洞时全选选取一下敏感参数 说不定会有意外发现

Find Comments 查找注释

清晰看到注释，说不定有开发送上的账号密码等等

![](../Images/49ddb8ee10e2f06096c01cdf0e931a81.png "45698-j7puz6vfy2p.png")

Find scripts 查找js代码

该功能处理.js后缀的文件之外，页面中script标签的内容也会自动匹配出来。等同于右键看完当前页面的js逻辑后在接着Ctrl F 搜.js然后继续看代码，在Burp里相对方便得多。

![](../Images/6b3b3db26eaedf2700db263d5b8c4ce5.png "72359-l4mhe6gte1.png")

Find references 查找引用

匹配出页面中存在的各类链接

![](../Images/f58f61f40b0e9075d54d247ac4e52e11.png "49184-use4ca2t5y8.png")

Analyze target 分析目标

假设拿到100个目标，筛选软柿子的时候通过总结页面判断一下，寻找交互点多的站点/链接进行单点突破，未尝不是一个高效的选择。

![](../Images/43ef83ca1f1b3ee808aaa8ce7f0ec5f7.png "92888-4dybhtf3nz2.png")

该功能可以快速筛选出带外部参数的url，并统计了参数的数量，秉着交互点越多可能存在的问题就越多的原则，筛选一下，效率极高。

![](../Images/635a301851eab97bebd388cd46bb053d.png "19348-lgdjddcd7qf.png")

该功能可以理解为Find references功能遍历出来所有的连接后再去除Dynamic URLs中带交互点的Url的结果。

![](../Images/3aab810427d56e6b86f2c7c3573796de.png "42957-wjyhwaav41.png")

一般用来检测参数问题，一个参数存在问题后能快速定位到其他地方的元素

![](../Images/36418138e1f194b5127e0d892e0a4476.png "26558-ib3xigo4gab.png")

Discover content 内容勘测  
递归扫描站点备份文件是否泄漏

![](../Images/049c843e976292bcd2b6e2ebb93d2ea5.png "08762-b5ds5kz5yi8.png")

![](../Images/b540f6a30f2a4fb44a32c6a512b6269b.png "11399-7llvig92o9.png")

建议选取相对于的后缀进行扫描，重复的字典太多了
