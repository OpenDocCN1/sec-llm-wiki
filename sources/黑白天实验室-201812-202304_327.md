0x01 Bettercap简介

```


Bettercap是一个非常强大、灵活可移植的中间人攻击框架，它具有跨平台、轻量级以及模块化等优点，在渗透测试过程中能够非常好的进行中间人测试。在Kali Linux上可以通过apt install bettercap直接安装。使用Bettercap时并不需要Cain和Ettercap一样手动扫描内网主机，在打开时会选择正在上网网卡自动完成扫描任务并实时发现网络中新接入的设备。
```
