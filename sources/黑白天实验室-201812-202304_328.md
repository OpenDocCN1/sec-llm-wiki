```
2.在虚拟机中打开终端，利用arpspoof工具，对物理机发起ARP断网攻击
```

![](../Images/622e8ea7e9f0e6710ec697642df831e7.png)

从图中可以看出，此时虚拟机不断地向物理机发送ARP应答包，这个应答包将网关的ip地址192.168.1.1和虚拟机的MAC地址00:0c:29:ee:fa:6d 绑定在一起，从而将物理机的ARP缓存表中的网关的MAC地址修改为虚拟机的MAC地址。  
arp -a查看mac绑定地址  
![](../Images/f1f73abca96a3b47c313be8b05de45e7.png "84792-ttqw0az66i.png")

  
此时物理机已无法上网(没做流量转发)

  
![](../Images/c85d5bf4894e3380e8e63c657f77232a.png "84637-ey355ls5cdr.png")  

2.中间人攻击

```



 在进行中间人攻击前，得先打开攻击主机的IP转发功能，linux因为系统安全考虑，是不支持IP转发的，其配置文件写在/proc/sys/net/ipv4的ip_forward中。默认为0，接下来修改为1。
```

![](../Images/ed5a2872a85c1b227246c46854c41eb4.png "33705-o67s3v40lod.png")

3.在虚拟机中打开driftnet。  
driftnet -i ens33  

![](../Images/8b7c1c4ba18f8ab57e382bda2a85def8.png)

此时，物理机和网关通信的数据包都会流经虚拟机，那么可以在虚拟机中利用driftnet工具，可以捕获物理机正在浏览的图片。
