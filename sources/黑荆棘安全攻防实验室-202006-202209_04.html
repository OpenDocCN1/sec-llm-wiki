Kali之旅

  1. 以root用户登录Kali

  2. passwd 修改密码

    用户密码文件 /etc/shadow

    用户账户文件 /etc/passwd 

    ┌──(rootðkali)-[~]
    └─# passwd -S root
    root P 2022-08-19 0 99999 7 -1

    #-S 查看密码状态
    # P 代表 root用户设置了密码 L代表 未设置密码
    # 2022-08-19 代表2022年八月19日设置的密码
    # 0 表示可以随时更改密码
    # 99999 表示用不过期
    #7 表示提前7天会提醒
    #-1 表示不会锁定

  3. Linux文件系统

    Linux只有一个根（/）

    从根开始描述的路径叫做绝对路径

倒树型结构为Linux标准

  1. /boot Linux内核文件 系统引导文件 grab

  2. /home 用户家目录

  3. /etc 系统配置文件

  4. /mnt 常用挂载点 对于设备访问需要进行挂载（mount） 把设备和目录关联

    /dev 设备文件目录

    如 /dev/cdrom 光盘

    /dev/sda 第一块scsi接口的硬盘

    /dev/sda1 第一块scsi硬盘的第一个分区

    /dev/sdb 第二个分区

  5. /proc 虚拟文件系统，反映的是内核的数据信息

  6. /sys 内核关于硬件的数据信息

  7. /bin --- 普通程序

  8. /sbin ---管理程序

  9. /lib --- 库文件 （相当于Windows的dll文件）

  10. /usr --面向用户的文件

    /usr/bin

    /usr/sbin

    /usr/lib

基本Linux命令

哪个目录存放配置文件？

mkdir 创建目录
mkdir -p 创建多级目录
mkdir -pv 显示详细信息
mkdir -pv work/{doc,ppt,txt} 创建多个目录列表

┌──(rootðkali)-[~]
└─# mkdir -pv work/{doc,ppt,txt}
mkdir: 已创建目录 'work'
mkdir: 已创建目录 'work/doc'
mkdir: 已创建目录 'work/ppt'
mkdir: 已创建目录 'work/txt'

mkdir -p test/{1..5}  创建一个test的目录并在下面创建一个1-5的目录
┌──(rootðkali)-[~/work/exam]
└─# mkdir -p test/{1..5}
                                                                                          
┌──(rootðkali)-[~/work/exam]
└─# ls
test

┌──(rootðkali)-[~/work/exam]
└─# cd test                                                                          
                                                          
┌──(rootðkali)-[~/work/exam/test]
└─# ls
1  2  3  4  5
