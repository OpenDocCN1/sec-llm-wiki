我准备的虚拟机是Linux的CentOS 7.9的镜像。Linux与Windows是两种截然不同的操作系统，在Linux中，将会使用大量的命令行操作，也就是类似于Windows中的CMD命令行。希望大家做好准备。

等待安装之后。我们先使用ping命令来查看一下我们是否连上网。

咦？这是怎么回事呢，众所周知，某度是一个测网络的好网址，那么如果没办法ping通的话，那么我们就要调节一下linux的网络设置。但是linux的网络设置，并不像Windows一样，使用的图形化界面，Linux的网络设置，是存放在文件中。我们需要更改文件配置才可以进行网络设置。

首先，我们进入 /etc/sysconfig/network-scripts 目录，然后使用vi编辑器，修改/etc/sysconfig/network-scripts/ifcfg-eth0

使用命令vi ifcfg-ens33这里可能你的文件名并不是这个，但是找前面是ifcfg-ens的就是啦。进入之后我们就能看到这样的文件。

接着我们将红圈框起来的部分=后的no改为yes。然后保存退出，记得一定要保存哦！

然后我们使用service network restart命令来重启网络服务。

那么现在我们再次ping一下某度，看看是否能ping通呢。

完美ping通！

答疑

既然刚刚的哪个配置文件是一个普通的网络设置的配置文件，那么其中的各个选项，我们都是要了解的，现在我们就来解释一下刚刚修改配置的文件中的各个选项都是干嘛用的。

[root@localhost network-scripts]# cat ifcfg-ens33
TYPE="Ethernet"     #网卡类型（通常是Ethemet以太网）
PROXY_METHOD="none"#代理方式：为关闭状态
BROWSER_ONLY="no"#只是浏览器：否
BOOTPROTO="static"#网卡的引导协议【static：静态IP  dhcp：动态IP   none：不指定，不指定容易出现各种各样的网络受限】
DEFROUTE="yes"      #默认路由
IPV4_FAILURE_FATAL="no"     #是否开启IPV4致命错误检测
IPV6INIT="yes"      #IPV6是否自动初始化：是（现在还未用到IPV6，不会有任何影响）
IPV6_AUTOCONF="yes"#IPV6是否自动配置：是（现在还未用到IPV6，不会有任何影响）
IPV6_DEFROUTE="yes"#IPV6是否可以为默认路由：是（现在还未用到IPV6，不会有任何影响）
IPV6_FAILURE_FATAL="no"     #是否开启IPV6致命错误检测
IPV6_ADDR_GEN_MODE="stable-privacy"#IPV6地址生成模型
NAME="ens33"        #网卡物理设备名称
UUID="ab60d501-535b-49f5-a76b-3336a4120f64"#通用唯一识别码，每一个网卡都会有，不能重复，否则两台linux机器只有一台可上网
DEVICE="ens33"      #网卡设备名称，必须和‘NAME’值一样
ONBOOT="yes"        #是否开机启动，要想网卡开机就启动或通过 `systemctl restart network`控制网卡,必须设置为 `yes`
IPADDR=192.168.137.129      # 本机IP
NETMASK=255.255.255.0       #子网掩码
GATEWAY=192.168.137.2       #默认网关
DNS1=8.8.8.8#
DNS2=8.8.8.5#
ZONE=public#
[root@localhost network-scripts]# service network restart#重启网卡
Restarting network (via systemctl):                        [  确定  ]
[root@localhost network-scripts]#

那么有些之前用过Kali的小伙伴就有些疑问了，为什么显示的网卡名称叫做ens33而不是eth0呢，那就又到了我们的答疑环节啦！

答疑

到底哪儿不一样？

其实eth0是内核的命名风格，现在更多地设备以虚拟化的方式运行，同时同一个局域网之间通信方式再基础网络设施的基础上，通过软件定义网络等技术，提供虚拟的路由器和交换机来实现内部网络的隔离和转发策略。比如公有云中提供的VPC网络。

现在vmware中选择CentOS8安装的系统默认叫ens160，也有网友反应他的设备上叫做ens32，其实这都跟你选取的系统版本有关。

安装 MYSQL

有些Linux版本中会自带有MySQL数据库，所以在安装之前，需要检查当前Linux环境中是否已有MySQL数据库，若有，要先将其卸载哦。

1）首先，我们查看当前系统是否自带MySQL数据库

并没有结果，那么就可以直接安装啦！

而如果有的话该怎么办呢？

直接使用rpm -e --nodeps[卸载的软件名]这个命令来卸载就好啦！

2）下面开始下载，如果直接使用yum命令来下载的话，会下载成MariaDB，其功能差不多，但是我们还是需要下载Mysql，还是使用repo源来下载。那么什么是repo源呢？我们放在后面的答疑环节再和大家解释。

我们使用 wget https://dev.mysql.com/downloads/file/mysql80-community-release-el7-3.noarch.rpm来下载mysql。如果提示命名没有找到的话，就使用之前我们下载ifconfig的方式先搜寻包含wget命令的安装包然后进行安装我们的命令，在此我们就不赘述了。

3）接着我们直接进行安装，使用命令rpm -ivh进行解压。

4）使用 yum install mysql-community-server执行安装

安装时，它会自动帮我们加载Mysql依赖，我们只需要输入y就行了

5）安装完成后，我们进行验证

1 systemctl mysqld start　　　　　　　　#开启MySQL服务　　　　只要没有错误信息就表示已经正常启动了。
2 systemctl mysqld stop　　　　　　　　#关闭MySQL服务
3 systemctl mysqld restart　　　　　　#重启MySQL服务 
4 systemctl mysqld status　　　　　　#查看服务状态

6）Mysql的密码问题

　　　　一些朋友可能发现安装MySQL没有密码设置项的问题，有人说这是因为MySQL不需要密码！这里说明一下，MySQL5.7会在安装后为root用户生成一个随机临时密码。但无论你安装的MySQL是哪个版本，无论使用哪种方式安装，无论是否需要密码登录，始终记住数据库的安全大于一切，所以请设置密码。又有人会问：如果能使用空密码登录，我登录后面再设置密码也行，可是有密码时，我怎么知道默认密码是多少如何登录呢？

　　　　本次安装的MySQL没有设置密码，但系统赋予了默认的且临时的密码，打开mysql默认日志文件/var/log/mysqld.log，可以查看（前提，你刚刚安装好MySQL，且没有重复重启服务）

打开日志文件查看
cat /var/log/mysqld.log

或者
在日志文件中定位临时密码
cat /var/log/mysqld.log|grep 'temporary password'

7）登录Mysql

我们使用刚刚定位到的临时密码来进行登录

7）使用 show databases;来查看所有的数据库。但是这时，系统会报错，提示需要重新设置密码。而我们设置的密码规则要符合MySQL安装时默认安装的 validate_password软件，MySQL的密码策略比较复杂。这个插件要求密码至少包含一个大写字母，一个小写字母，一个数字和一个特殊字符，并且密码长度至少8个字符。过于简单的密码，不会被通过。

8）重设密码

完成啦！之后我们重启一下服务，然后再输入新的密码就能登陆进去啦！

9）成功登录并查看数据库

我们使用Show DATABASES;来查看数据库。

答疑

什么是repo源呢？

repo其实是我们使用Linux中下载命令yum时所用的配置文件，这个文件呢，可以把他想象成为是一个专为一个软件服务的应用商店，这个文件中规定了我们要去哪里下载需要安装或者升级的软件包。而有些软件我们这个yum中默认的应用商店中没有，那么我们就要在网上找到一个专门为这个软件服务的应用商店，并把它放进我们的应用商店中，扩展我们的应用商店。
