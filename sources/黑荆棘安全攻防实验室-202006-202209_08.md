##### 答疑

既然刚刚的哪个配置文件是一个普通的网络设置的配置文件，那么其中的各个选项，我们都是要了解的，现在我们就来解释一下刚刚修改配置的文件中的各个选项都是干嘛用的。

```
\[root@localhost network-scripts\]# cat ifcfg-ens33
TYPE="Ethernet"     #网卡类型（通常是Ethemet以太网）
PROXY\_METHOD="none"#代理方式：为关闭状态
BROWSER\_ONLY="no"#只是浏览器：否
BOOTPROTO="static"#网卡的引导协议【static：静态IP  dhcp：动态IP   none：不指定，不指定容易出现各种各样的网络受限】
DEFROUTE="yes"      #默认路由
IPV4\_FAILURE\_FATAL="no"     #是否开启IPV4致命错误检测
IPV6INIT="yes"      #IPV6是否自动初始化：是（现在还未用到IPV6，不会有任何影响）
IPV6\_AUTOCONF="yes"#IPV6是否自动配置：是（现在还未用到IPV6，不会有任何影响）
IPV6\_DEFROUTE="yes"#IPV6是否可以为默认路由：是（现在还未用到IPV6，不会有任何影响）
IPV6\_FAILURE\_FATAL="no"     #是否开启IPV6致命错误检测
IPV6\_ADDR\_GEN\_MODE="stable-privacy"#IPV6地址生成模型
NAME="ens33"        #网卡物理设备名称
UUID="ab60d501-535b-49f5-a76b-3336a4120f64"#通用唯一识别码，每一个网卡都会有，不能重复，否则两台linux机器只有一台可上网
DEVICE="ens33"      #网卡设备名称，必须和‘NAME’值一样
ONBOOT="yes"        #是否开机启动，要想网卡开机就启动或通过 \`systemctl restart network\`控制网卡,必须设置为 \`yes\`
IPADDR=192.168.137.129      \# 本机IP
NETMASK=255.255.255.0       #子网掩码
GATEWAY=192.168.137.2       #默认网关
DNS1=8.8.8.8#
DNS2=8.8.8.5#
ZONE=public#
\[root@localhost network-scripts\]# service network restart#重启网卡
Restarting network (via systemctl):                        \[  确定  \]
\[root@localhost network-scripts\]#
```

##### 答疑

### 到底哪儿不一样？

其实eth0是内核的命名风格，现在更多地设备以虚拟化的方式运行，同时同一个局域网之间通信方式再基础网络设施的基础上，通过软件定义网络等技术，提供虚拟的路由器和交换机来实现内部网络的隔离和转发策略。比如公有云中提供的VPC网络。

现在vmware中选择CentOS8安装的系统默认叫ens160，也有网友反应他的设备上叫做ens32，其实这都跟你选取的系统版本有关。

### 安装 MYSQL

有些Linux版本中会自带有MySQL数据库，所以在安装之前，需要检查当前Linux环境中是否已有MySQL数据库，若有，要先将其卸载哦。

1）首先，我们查看当前系统是否自带MySQL数据库

![](../Images/f3834f74b3d051aec1b8dff8bf518d2b.png)

并没有结果，那么就可以直接安装啦！

而如果有的话该怎么办呢？

直接使用`rpm -e --nodeps[卸载的软件名]`这个命令来卸载就好啦！

2）下面开始下载，如果直接使用`yum`命令来下载的话，会下载成MariaDB，其功能差不多，但是我们还是需要下载Mysql，还是使用repo源来下载。那么什么是repo源呢？我们放在后面的答疑环节再和大家解释。

我们使用 `wget https://dev.mysql.com/downloads/file/mysql80-community-release-el7-3.noarch.rpm`来下载mysql。如果提示命名没有找到的话，就使用之前我们下载ifconfig的方式先搜寻包含wget命令的安装包然后进行安装我们的命令，在此我们就不赘述了。

3）接着我们直接进行安装，使用命令`rpm -ivh`进行解压。

![](../Images/0a39437e775b8b97edb28eb5947546a2.png)

4）使用 `yum install mysql-community-server`执行安装

安装时，它会自动帮我们加载Mysql依赖，我们只需要输入y就行了

5）安装完成后，我们进行验证

```
1 systemctl mysqld start　　　　　　　　#开启MySQL服务　　　　只要没有错误信息就表示已经正常启动了。
2 systemctl mysqld stop　　　　　　　　#关闭MySQL服务
3 systemctl mysqld restart　　　　　　#重启MySQL服务 
4 systemctl mysqld status　　　　　　#查看服务状态
```

6）Mysql的密码问题

　　　　一些朋友可能发现安装MySQL没有密码设置项的问题，有人说这是因为MySQL不需要密码！这里说明一下，MySQL5.7会在安装后为root用户生成一个随机临时密码。但无论你安装的MySQL是哪个版本，无论使用哪种方式安装，无论是否需要密码登录，始终记住数据库的安全大于一切，所以请设置密码。又有人会问：如果能使用空密码登录，我登录后面再设置密码也行，可是有密码时，我怎么知道默认密码是多少如何登录呢？

　　　　本次安装的MySQL没有设置密码，但系统赋予了**默认的且临时的**密码，打开mysql默认日志文件/var/log/mysqld.log，可以查看（前提，你刚刚安装好MySQL，且没有重复重启服务）

```
打开日志文件查看
cat /var/log/mysqld.log
或者
在日志文件中定位临时密码
cat /var/log/mysqld.log|grep 'temporary password'
```

![](../Images/f24c057a5466eaeb918cc6082847871d.png)

我们使用刚刚定位到的临时密码来进行登录

##### 答疑

什么是repo源呢？

repo其实是我们使用Linux中下载命令`yum`时所用的配置文件，这个文件呢，可以把他想象成为是一个专为一个软件服务的应用商店，这个文件中规定了我们要去哪里下载需要安装或者升级的软件包。而有些软件我们这个`yum`中默认的应用商店中没有，那么我们就要在网上找到一个专门为这个软件服务的应用商店，并把它放进我们的应用商店中，扩展我们的应用商店。
