Python | Go | PHP | JacaScript   简介与为什么学习

Python 简介

Python 于八十年代末与九十年代初被研究出来，他的特点具有易于学习（较少的关键字，结构简单，明确定义的语法），易于阅读(代码定义清晰，结构简单易于阅读)，易于维护(源代码易于维护)，一个广泛的标准库 (这是比较重要的一点，也是python的优势，在Unix，Windows，Macintosh的兼容性都很好)，具有互动模式(可以直接在终端输入执行代码并获得结果的语言)，可移植(python的源代码是开放的，也使得其被移植到许多平台)，可拓展性(如果你有一些需要运行很快的关键代码，或者一些不想要开放的算法，就可以用C或者C++完成那部分程序，然后从你的Python程序中调用)，连接数据库，GUI编程(Python支持Gui可以创建和移植到许多系统调用)，可嵌入(你可以把Python嵌入到C/C++程序，让你的程序的用户获得"脚本化"的能力)。

Python主要应用领域

  • 云计算：云计算最热的语言，典型的应用OpenStack

  • WEB开发：许多优秀的WEB框架，许多大型网站是Python开发、YouTube、Dropbox、Douban……典型的Web框架包括Django

  • 科学计算和人工智能：典型的图书馆NumPy、SciPy、Matplotlib、Enided图书馆、熊猫

  • 系统操作和维护：操作和维护人员的基本语言

  • 金融：定量交易、金融分析，在金融工程领域，Python不仅使用最多，而且使用最多，其重要性逐年增加。

  • 图形 GUI：PyQT，WXPython，TkInter

Python 在一些公司的运用有:

  • 谷歌：谷歌应用程序引擎，代码。Google.com、 Google 爬虫、Google 广告和其他项目正在广泛使用 Python。

  • NASA：美国航天局广泛使用 Python 进行数据分析和计算。

  • YouTube：世界上最大的视频网站 YouTube 是用 Python 开发的。

  • Douban：几乎所有公司的业务都是通过 Python 开发的。

  • 知乎：中国最大的 Q＆A 社区，通过 Python 开发（国外 Quora）

除此之外，还有搜狐、金山、腾讯、盛大、网易、百度、阿里、淘宝、土豆、新浪、果壳等公司正在使用 Python 来完成各种任务。

WHY

Python最开始被设计用于编写自动化脚本，所以基于Python写成的扫描工具不计其数，例如被称为瑞士军刀的Nmap，还有强大的SQL注入工具SQLMAP，并且Python是跨平台的，Linux与Windows都可以使用，他能快速实现并验证我们的想法，而且如果不能学会自己使用开发语言来开发自己的工具，只会使用别人开发的工具那么永远 没办法成为一个强大的白帽黑客，只能成为脚本小子(script kiddie).相信没有一个对网络攻防有兴趣的人想要被叫成脚本小子吧。

Go 简介

Go 是一个开源的编程语言，由谷歌公司开发，它能让构造简单、可靠且高效的软件变得容易。

Go是从2007年末由Robert Griesemer, Rob Pike, Ken Thompson主持开发，后来还加入了Ian  Lance Taylor, Russ Cox等人，并最终于2009年11月开源，在2012年早些时候发布了Go 1稳定版本。现在Go的开发已经是完全开放的，并且拥有一个活跃的社区。

Go 语言特点

大多数现代编程语言（如Java，Python等）都来自90年代的单线程环境。虽然一些编程语言的框架在不断地提高多核资源使用效率，例如 Java 的 Netty 等，但仍然需要开发人员花费大量的时间和精力搞懂这些框架的运行原理后才能熟练掌握。

Go于2009年发布，当时多核处理器已经上市。Go语言在多核并发上拥有原生的设计优势，Go语言从底层原生支持并发，无须第三方库、开发者的编程技巧和开发经验。

很多公司，特别是中国的互联网公司，即将或者已经完成了使用 Go 语言改造旧系统的过程。

WHY

学习Go语言，我们可以使用他开发出属于自己的漏洞扫描工具，例如Goby，Goby是一款基于Go语言开发的网络安全测试工具，他能够针对一个目标企业梳理最全的攻击面信息，同时进行高效实战化的楼动画扫描。

JavaScript 简介

JavaScript 是Web的编程语言。所有的现代HTML页面都使用JavaScript，JavaScript非常容易学习。他与Python一样都是脚本语言。

JavaScript 特点

JavaScript是一种脚本语言，可插入HTML页面的编程代码。插入HTML页面后，可由所有的现代浏览器执行。

WHY

JavaScript可以广泛用于服务器，PC，笔记本电脑，平板电脑与智能手机等设备，但是身为网安人员，不能精通JavaScript，但是却要能看懂基本的语法，要知道如何利用JS脚本实现XSS(跨站脚本漏洞)漏洞，并且如何防范XSS。

PHP 简介

PHP是服务器端脚本语言，是一种动用的开源脚本语言。其在服务器上执行。

PHP文件可以包含文本、HTML、JavaScript代码和PHP代码，PHP执行结果以纯HTML的形式返回给浏览器，默认扩展名是 .php

PHP能做什么

  • PHP 可以生成动态页面内容

  • PHP 可以创建、打开、读取、写入、关闭服务器上的文件

  • PHP 可以收集表单数据

  • PHP 可以发送和接收 cookies

  • PHP 可以添加、删除、修改您的数据库中的数据

  • PHP 可以限制用户访问您的网站上的一些页面

  • PHP 可以加密数据

WHY

PHP 可以包含JavaScript代码，所以PHP是研究Web安全的我们所要掌握的主要代码，不仅如此，未来我们还要面对黑盒测试，白盒测试，需要对PHP代码尽可能的熟悉，才能在海量的代码中找到存在的漏洞。
