# 穆勒的报告显示特朗普没“通俄”后，总统先生开心的像只猴子

据外媒报道，当地时间18日上午9时30分，美国司法部部长巴尔就特别检察官穆勒的“通俄门”报告举行记者会。巴尔说，特别检察官穆勒没有发现特朗普团队与俄罗斯政府密谋的证据。但他表示，穆勒的报告证实，俄罗斯政府试图干涉美国2016年大选。

  

今年3月，穆勒完成了为时22个月的调查。巴尔表示，经过近两年的调查、成千上万的传票、数百份逮捕令和证人的访谈，特别检察官证实，俄罗斯政府支持非法干涉2016年美国总统大选的活动，但调查没有发现特朗普的竞选活动或其他美国人与此有合谋。

同时，巴尔表示，特朗普没有采取行动阻挠穆勒的调查。

  

穆勒”通俄门“有删减版的调查报告，139MB。

报告表示特朗普没有通俄，并表示俄罗斯确实干扰了2016的美国大选。

  

然而俄方表示，不接受。

俄总统新闻秘书佩斯科夫19日回应称，穆勒的报告仍然没有提供任何有说服力的证据证明俄罗斯干涉了美国的选举进程。莫斯科仍不接受美国这种指责。  

  

“我们从这份报告一开始就谈到，无论调查人员在做什么，他们都找不到任何干预(的证据)，特别是普京总统已经说过这一点了。因为(俄罗斯)没有干预。事实上，穆勒报告证实了这一点。我们感到遗憾的是，这种质量的报告对已不是最佳状态的俄美双边关系发展有直接影响。”佩斯科夫说道。

  

**另据美国有线电视新闻网(CNN)18日报道，在巴尔的新闻发布会后，特朗普发表具有《权力的游戏》风格的图片，他在图片中转身离开并配上文字“游戏结束”。特朗普稍早还在推特上指责“通俄门”调查是“史上最大的政治骗局”，并要求对发起调查的民主党进行调查。**
