# 俄罗斯取消封禁 加密聊天软件Telegram

俄罗斯周四取消了对Telegram加密聊天APP的禁令，尽管该禁令生效已超过两年，但该禁令未能阻止该程序被广泛使用和运作。

  

![](../Images/43532b95bb1a1043fa334430cb3ba116.png)

  

一些俄罗斯媒体将这一举动视为妥协，但通讯监管机构Roskomnadzor表示，之所以采取行动是因为该应用程序的俄罗斯创始人Pavel Durov准备在平台上合作打击恐怖主义和极端主义。

  

它在一份声明中说：“**俄罗斯国防部长**正在与俄罗斯总检察长办公室达成协议，放弃限制Telegram进入俄罗斯的要求。”

  

  

![](../Images/88edee035a43c3e696838d59e3e30031.png)

谷歌翻译版本

  

明确表明了，他们准备通过与领先的俄罗斯和外国互联网公的合作，平均每周清除一次以下资料：

\-宣传自杀行为 2,500条；

\-极 端主义和恐 怖主义性质 1,300条；

\-宣传 毒 品 使用情况，大约涉及其购买地点 800条；

\-未成 年人的 色 情 图片 300条。

![](../Images/6d562ce22b7ee137b89e33b0b911384b.png)

  

  

俄罗斯于2018年4月13日正式禁止电报。该禁令是在电报拒绝与俄罗斯主要情报部门联邦安全局（FSB）合作之后发生的。

  

当时，FSB的调查人员试图从Telegram获取加密密钥，以解密2017年圣彼得堡地铁爆炸中正在调查的两名嫌疑人之间的对话。

  

Telegram拒绝合作，FSB提起诉讼，最终于2018年初在俄罗斯最高法院胜诉。

  

Roskomnadzor于2018年4月采取行动禁止该应用程序，但尽管封锁了IP地址，但是，Telegram不断更改其服务器的IP地址，还采用了一种称为“ 域前置(Domain Fronting) ” 的技术来绕过审查，并允许俄罗斯用户继续使用其服务。

  

在努力禁止在俄罗斯使用该服务时，Roskomnadzor暂时对超过1900万个Amazon和Google Cloud IP地址实施了全面禁止，从而屏蔽了俄罗斯内部无数合法服务，例如所有Google服务，在线游戏，银行网站，加密货币交易所和移动应用。俄罗斯还禁止了俄罗斯用来访问该服务的50多种VPN和代理服务。

  

但它仍无法成功封锁，Telegram继续在俄罗斯蓬勃发展，是俄罗斯领先的新闻频道服务。

  

尽管禁止使用该应用程序，**但俄罗斯外交部和国家冠状病毒工作队等政府部门仍在Tel****egram上设有官方频道。甚至被俄罗斯政客使用，官员们信任该应用程序，以确保他们的对话不受FSB监视。**

  

Telegram在4月份表示，每月活跃用户已达到4亿，在过去两年中，其用户群翻了一番。

  

终究是拿下了。。
