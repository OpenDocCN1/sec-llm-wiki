# "五眼"情报联盟与日本就朝鲜问题结盟，共享规模或将扩大

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTM1MDQ1NA==&mid=2451179192&idx=1&sn=8264e217760acbb028946771851a104e&chksm=8c26f061bb517977c78a101b160ae3244e8edacaf731a268d97dd5458c9af2f645940e55d45d&scene=126&sessionid=1681276242#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451179192&idx=1&sn=8264e217760acbb028946771851a104e&chksm=8c26f061bb517977c78a101b160ae3244e8edacaf731a268d97dd5458c9af2f645940e55d45d&scene=126&sessionid=1681276242#rd)

日本政府消息人士周日说，英语国家的“五眼”情报共享联盟已与**法国，日本和韩国**联手，以制止朝鲜的挑衅。

  

随着情报共享框架的扩大，由澳大利亚，英国，加拿大，新西兰和美国以及三个新伙伴组成的联盟将加强情报活动，而这将超出对日本，韩国和美国目前对朝鲜弹道导弹的分析范围。

  

![](../Images/f6cc05e3b505f0db9045cdecfd4f7554.png)

（朝鲜的“超大型多管火箭筒”于2019年10月31日试射。）\[朝鲜中央通讯社/共同社\]

  

据日本和美国政府消息人士称，**去年秋天，来自八个国家的官员聚集在一起，讨论了如何最好地收集有关朝鲜的信息。**

  

消息人士称，“五眼”还打算将与这三个国家的伙伴关系发展为一种伙伴关系，**以促进就中国日益增长的军事力量交换情报。**

  

八个国家利用位于美国港口城市横须贺的美国第七舰队的旗舰蓝岭作为指挥和协调中心，一直在监视海上活动，以防止朝鲜船只从事非法的船对船货物转运。

  

但是直到最近，它们的情报部门之间还没有合作框架。

  

美国寻求与友好国家建立“五眼+”框架，以应对包括空间和网络安全在内的新领域的威胁，在这些领域中，中国也在增强力量。

  

消息人士说，关于如何应对中国的网络攻击，五国联盟的情报机构已与**法国，德国和日本**举行了多次会议。

  

该联盟的根源在于二战后英美之间达成的情报共享协议。

  

特别是与关键盟友日本一道，美国希望进一步扩大该框架。

  

美国政府消息人士称，日本已经接近五国联盟的“第六只眼睛”，因为它与中国和朝鲜毗邻，并具有通过卫星和信号情报收集相关信息的能力。
