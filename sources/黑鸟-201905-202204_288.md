# 日本东京奥运会组委会称：存在伪造其工作人员的电子钓鱼邮件

2019年12月18日，2020日本东京奥运会组委会在其官网发布了这样一个告示，警告不要打开看似来自**奥运会和残奥会东京组织委员会的电子邮件。**

  

在详情中他们称最近**检测**到伪装成看起来是来自东京2020工作人员的电子邮件。 尽管该电子邮件看起来是来自官方的，但是如果没有理由收到此类邮件或对内容存在疑问，则不要单击链接或打开任何附件。很有可能将被重定向到网络钓鱼站点或感染了恶意软件。

对于此事件很容易定性，即有人伪造成工作人员发起了钓鱼活动，而组委会的安保人员能够检测到这一事件，也恰恰证明了该邮件可能已经出现在了他们的内部网络，可能是奥运村的场馆设施，也可能是远程控制台等。以上便是关于“detected emails”一词的过分解读。
