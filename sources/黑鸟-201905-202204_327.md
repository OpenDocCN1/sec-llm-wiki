# 印度情报机构： 调查分析局，国防情报局和印度情报局

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTM1MDQ1NA==&mid=2451178171&idx=1&sn=d647c91506d0d7f650b860e37b7b0bb2&chksm=8c26f462bb517d7422ebd6f92fe2294fcb0fbb36ee393101ce8e351d3049cef46110a6c0fb81&scene=126&sessionid=1681276277#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451178171&idx=1&sn=d647c91506d0d7f650b860e37b7b0bb2&chksm=8c26f462bb517d7422ebd6f92fe2294fcb0fbb36ee393101ce8e351d3049cef46110a6c0fb81&scene=126&sessionid=1681276277#rd)

**前言**  

印度独立前的情报机构是英属印度情报局，整个情报工作受控于英国秘密情报局，其主要任务是监视印度国内各政党。独立后，在美、英等国专业培训的情报人员继续新成立的情报机构就职，不仅工作方式带有浓厚的西方特色，情报体制上也深受美、英等国的影响。

  

**正文**  

  

事实上，目前印度情报系统有三大机构组成，分别是直接向总理报告工作的印度调查分析局，直属于内政部的中央调查局（CBI，类似于美国联邦调查局FBI）和军方领导的军事情报局。印度情报机构分为：对外，对内，军事和信号情报机构。下面按照其方向进行展示。

  

**对外情报机构**

按照惯例，先讲名气最大的：印度调查分析局（RESEARCH AND ANALYSIS WING，简称RAW，R&AW，或称印度内阁秘书处研究分析室），其实力在印度最强、规模最大，它主要是通过谍报和侦察等手段执行对外情报任务，搜集整理对方的政治、军事、经济、宗教等情报，同时具有策反、颠覆和一定的反间谍任务。

  

![](../Images/28ec715c8b74a52a6c398ecef615fa00.png)

  

其于1968年9月21日正式成立，是印度共和国政府主要对外情报收集单位。调查分析局所属人员已经7000余人，在世界各地设有70多个情报站。研究分析室首长为秘书处研究秘书 ，受印度总理直接指挥，同时兼任联合情报委员会委员 ，行政隶属于内阁秘书长 ，同时必需每日向印度国家安全顾问简报。因为所负责内容较为特殊，所以并不需要接受印度国会监督。

  

值得注意的是秘书长都需要对巴基斯坦和中国的问题异常了解的专家担任。

下属机构：航空研究中心，无线电研究中心，电子与技术服务，国家技术研究组织（NTRO），特殊边防部队，**特别行动局**。

  

调查分析局内部建制主要分三部分：  

  

一是局长直接领导的**特别行动局OSO**。它是**仿效美国CIA、前苏联KGB和英国MI6**建立的对外情报机构，从事进行搜集情报、组建秘密组织、建立和训练雇佣军；实施心战颠覆等活动。1970年肢解巴基斯坦，以及其后将锡金吞并为印度的一个邦的隐蔽行动和军事行动，均系该局一手策划实施。

  

二是由安全总监负责的**航空研究中心ARC**。航空研究中心是专门的航空侦察机构，工作对象主要为军事目标，运用侦察飞机等先进设备对周边国家实施空中侦察，进行航空摄影和为特别行动提供后勤支援等。印度发射的CARTOSAT遥感卫星就由ARC负责管理。这颗卫星的解析度达1米，而印度以前使用的遥感卫星的解析度只有5米。70年代，该中心曾获得过高质量的印中、印巴边界地区设施航空图。据印度《星期日》周刊报道，印度派遣的**藏民**间谍中，有些曾在该中心受过训练。

  

三是分工负责体制。调查分析局的副局长相当于政府的助理秘书级，负责行政管理、外国情报搜集、维持国内稳定的特别行动、电子监听和密码等工作，**由五个联合秘书具体对他负责。其中四个联合秘书分别负责四个特定地域的情报工作，分别是巴基斯坦、中国和东南亚、中东和非洲以及其他国家**。也就是**地区业务处**。

  

另一个秘书主管电子技术、行政和国内部分的情报业务工作。局内各个方面的情报都按上述地域划分、归口、研究分析、处理整编、上报或下发。

  

黑鸟特地找了张组织架构图，就是对应上面那段话的一个解释。

![](../Images/52f13f9b1a63c4e2e09dcbb068b8b1e2.png)

上述四个业务片各有一名主管，负责总部同驻外情报站的联系，并保管有关文件档案。驻外情报站设有站长，他们以适当的掩护身份在驻外使领馆工作，监督专案员和其他特工。

  

专案员负责专案，并直接或间接地招募基层情报员。一般情况下，一项行动计划有一名专案员，但有时一名专案员也处理几项行动计划。专案员向下主要同首席情报员接头，首席情报员是专案员与基层情报员联络的枢纽。基层情报员是刺探原始情报的主力，多数是情报对象国的国民。此外还有由总部直接外派和指挥的情报员，他们单独行动，驻外情报站站长一般不了解他们的行动。  

  

此外，还有一个“特别边境部队”，它最早是美国中央情报局训练的“第22部队”，现在总部设在北方邦靠近萨哈兰普尔的萨尔萨瓦，人数约8000人。

  

国际情报分析专家一般认为RAW代表印度政府一种深具代表性的对外影响力，是一个在南亚地区不可轻忽的重要情报机关。

  

# **军事情报机构**

**国防情报局**

https://mod.gov.in/

![](../Images/9d5901ae0c2472c2db8e2dc7b2658525.png)

说到军事体系名气最大的印度国防情报局，黑鸟先说一个故事。

  

1999年，因为应对与巴基斯坦的卡吉尔冲突严重失利，冲突结束后，国内反应强烈，各界指责情报机构效率低下，导致印方在冲突初期陷于被动。印度政府成立了一个由战略家苏布拉马尼亚姆牵头的调查委员会进行彻底调查。该委员会发现，原来在卡吉尔冲突爆发前一个月，印度就已经获悉巴基斯坦正在采购大量用于高寒地带的靴子和帐篷等物资，**但调查分析局却对此战争信号没有发出任何预警**。

  

因此委员会强烈建议成立统一机构来负责军政情报的分析和处理工作，**处理来自不同渠道的不同情报，结束以前情报界军政不分、交叉重叠的混乱局面**，在这种情况下，国防情报局应运而生。该局（DIA）的主要任务是指导和协调各情报部门及陆海空三军情报搜集部门的工作，以实现情报共享。国防情报局在本土以外开展的活动，主要是搜集邻国的战术、战略情报。

  

因此，可想而知，其职责为指导协调军情搜集，而国防情报局是印度军方的军事情报部门，国防情报局较之印度其他两大情报机构，最大区别在于其主责是**领导情报工作**而非实施侦察。

  

**印度的陆海空三个军种各有独立的情报机构，**国防情报局的主要职责是指导和协调三军情报搜集部门的工作并实现情报共享，其次才是兼顾信息战并搜集信号情报。

  

当前，陆军情报处属陆军司令部参谋局领导，约有400名工作人员，负责陆军的情报搜集整理、军内安全保卫、驻外陆军武官的管理以及陆军的外事活动等。

https://indianarmy.nic.in/

  

空军情报处属空军司令部第一参谋局领导，约有180名工作人员，负责搜集空军情报资料、空军的安全保卫、驻外空军武官的管理。

http://indianairforce.nic.in/

  

海军情报处隶属于国防部，由海军司令部第二副参谋长领导，约有200名工作人员，负责海军情报资料的搜集、整理和分析。

https://www.indiannavy.nic.in/

  

此外还有一个军事情报局（DMI）成立于1941年，是印度武装部队的军事情报机构，还包括军队中的反间谍，这需要在军事领域侦查间谍。

  

**对内情报机构**

**印度情报局 （IB）**

http://www.ceib.nic.in/

印度情报机构之一，成立于1887年，它主要负责印度国内安全和情报工作，包括**情报收集、反情报和反恐任务等**等。该机构人员在25000名左右，全国有3500余名外勤人员，其中大多数人从事的是政治情报工作。

![](../Images/c27403b77682d397884608b68feaa414.png)

该局是世界上历史最悠久的情报机关之一，其前身是1885年由英国陆军少将查尔斯·马基创建的英印军事情报部门，早期任务是监视进军中亚的沙俄，防止其南下印度。1921年，该机构正式改制为印度政治情报处（IPI）。1947年印度独立后，该局继续同英国军情五处保持密切联系，以至于外界长期将其视为英国情报机构的分支。1950年，它更名为印度情报局，在周边国家边境地区挑选人员培养成特工并监视边境动态。

  

不过，由于在1960年代印度与周边国家的边境冲突中毫无作为，导致印度政府错估形势，在1968年被剥夺了海外情报活动权限，只负责国内情报活动。  

  

据西方专家估计，印度情报局现有雇员约2.5万名，在全国设有3500个联络站点，由于历任局长注重保密，该局越来越神秘，甚至连印度总理也无法弄清其工作状态。(666)

  

情报局内部等级森严，负责高层管理的局长、副局长、助理局长和各科室主管掌控着印度各邦的情报联络站，对要害部门实行垂直监管。同时，情报局可对印度各大党派、军队、政府机构进行监控，甚至有权向军队派驻特派员进行监督，以至于印军也对其畏惧三分，并给特派员冠以“新德里密探”的称谓。

  

虽然印度有统一情报领导机关，却又认为需要多个情报机构并存，通过“健康竞争”实现相互印证、对比核实。国内情报与国外情报两大系统相对隔离，导致了各自为政的局面。调查分析局与情报局之间不仅难以合作，还经常互不相让，争相向政府邀功，甚至到了互相窥测对方情报的地步。而印度军方不仅对谍报活动“嗤之以鼻”，对情报局实施的特派监督和监控更是反感。

  

**这种职权分配真让人get不到点，可能这就是为什么印度联合情报委员会（JIC）要统一领导，构成由调查分析局、印度情报局、国防情报局3个部门组成的情报体制的干活模式吧。**

  

下面是一些其他的情报局。

**印度中央调查局（CBI）**

http://www.cbi.gov.in/

印度刑事调查和国家安全情报机构，成立于1963年，该机构主要调查经济犯罪，特殊犯罪，腐败案件和其他备受瞩目的案件。该机构拥有7274名人员，实际上只有5685名，空缺1589名。

**印度国家统计委员会（NSC）**

是一个自治机构，成立于2005年，它的目标是减少该国统计机构在收集数据方面面临的问题。

**全印度无线电监测服务（AIRMS）**

全印度无线电监测服务（AIRMS）是监测印度广播以及印度感兴趣的所有外国广播的中央监测服务。它与RAW和军事情报部门联络。

  

# **信号情报机构**——**联合密码局（JCB）**

负责信号情报和密码分析并协调军事情报机构的类似活动和行动。联合密码局与IB和R＆AW密切合作。它负责敏感数据的密码分析和加密，还负责与公钥和私钥管理有关的问题。

  

先总结到这，还有更多的细节内容黑鸟日后将分单个部门解说，总体情况大致如上，可见印度情报机构已形成了严密的布局，覆盖了情报侦察的各个领域。同时，其情报机构深受西方国家影响，采用各种手段搜集监视对象国，与[越南的对内情报机构](http://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451178160&idx=1&sn=97a07b1eb7bc5d2d708067417253a063&chksm=8c26f469bb517d7f5ff6764e89a52d81b3b27c2acf23e8a8383b9ec26bcff22ef0cb0a6416f3&scene=21#wechat_redirect)相比，可见印度的情报机构极具英美特色，而越南与我们的更为相似。

因此，对于我们而言，印度对外以及军事相关的情报机构会是我们比较需要重点关注的对象。
