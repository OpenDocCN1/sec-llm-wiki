# 发完推文后，一个阿根廷安全研究员被抓了。

近日，在日常逛T子过程中，发现日常关注的一个阿根廷安全大佬的动态被人转发了一下，按描述来看，其好像是被阿根廷警方监视并调查了。

  

![](../Images/2417e35e708e498b467cb240ddb14896.png)

  

大致是，阿根廷警方以涉嫌黑客入侵和泄漏政府系统数据为由，短暂拘留并突袭了他的住所。

  

按照黑鸟往常惯例，这时候必定会介绍一下地理，国土和海岸线还是很大的阿根廷，曾经很牛逼，如今被美帝一番操作直接没落，有兴趣可以自行查看百度。

  

![](../Images/928c064289a1b79b00bf6747aac44630.png)

  

那么开始进入正题，只见大佬发了一份法庭文件图。  

  

![](../Images/487c6ad3f2463100dc2ba9364d452488.png)

  

法庭文件中，记录了发推文者的记录。

  

![](../Images/6e2875c02334a7c5b7fed2281f89e2ba.png)

  

而法庭文件均被安全研究员拍了下来，如下所示，实际上，我看完之后，很有代入感，慌的很。。  

  

https://ia601500.us.archive.org/20/items/ciberpatrullaje/ciberpatrullaje.pdf

  

更令人悚然的是，这个法庭文件把该研究员的所有推文全部录了进去。

![](../Images/a6a66ae71e148cf627601205f7329b13.png)

  

甚至还有他的博客也被录了进去  

![](../Images/30b86257eaa11bf8d12ee2dd15af6449.png)

  

看不懂，有点像访问记录？

![](../Images/6bcedf7f1fee56902cc710c0fe8d699d.png)

  

安全研究员Smaldone声称他的逮捕和袭击描述为“政治pohai”。

  

根据他在推文的描述，他认为是因为此前曾在阿根廷参议院面前作证，反对使用电子投票机，并定期发表博客文章，批评政府使用此类设备的计划。主要是认为电子投票机存在安全漏洞，因此而导致出现报复行为。

  

**而根据其推文称，他是第三个在报告了委内瑞拉公司Smartmatic开发的电子投票系统中的漏洞之后**，房屋遭到突袭的安全研究员。

  

而阿根廷政府目前正在对该电子投票系统进行测试，以计划在未来的选举中首次部署，可以说是，很强硬了。

  

**黑鸟大道理①：因此，报告漏洞，要小心，不然会有人突突突。(本句话仅针对国外，我三观正的很)**  

  

但是据阿根廷新闻网站Clarin称，Smaldone只是10月8号遭到房屋搜查的许多嫌疑人之一，主要原因是阿根廷当局正在寻找名叫La Gorra Leaks 2.0的黑客。

  

事情是这样的，在今年8月12日，这个叫做La Gorra Leaks 2.0的黑客在暗///网，Telegram和Twitter上发布了5 GB的数据，其中包含超过200,000个PDF文件，而这些文件包含阿根廷联邦警察的姓名，姓氏，ID号，家庭住址，电话号码和银行信息。

  

从法庭文件来看，Smaldone是最早发此事件的推特之一，当局似乎认为他以某种方式参与其中。

  

**黑鸟大道理②：有些涉及自己方的事情，别第一个说，枪打出头鸟，以前就打了我这只鸟，现在鸟闭嘴了。**

  

Smaldone仅仅因为在网上发布有关敏感问题的推文而被捕，并在当天被释放。然而这在阿根廷并不是第一次。目前阿根廷警方严厉打击在网上发布有关敏感问题的推文。
