# 乌克兰核电站员工因偷核电进行数字货币挖矿被捕。

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzAxOTM1MDQ1NA==&mid=2451177156&idx=1&sn=05396414aa2bb53d8daf00e02c84c3a9&chksm=8c25081dbb52810b7d28bcadc0d5cb7ae0df12c638dcaa6d7abac9c9dda405dbcedababde9ed&scene=126&sessionid=1681276317#rd](http://mp.weixin.qq.com/s?__biz=MzAxOTM1MDQ1NA==&mid=2451177156&idx=1&sn=05396414aa2bb53d8daf00e02c84c3a9&chksm=8c25081dbb52810b7d28bcadc0d5cb7ae0df12c638dcaa6d7abac9c9dda405dbcedababde9ed&scene=126&sessionid=1681276317#rd)

![](../Images/8c166db529ed7425da18e2391ff02cbc.png)

封面图即为乌克兰核电站

  

2019年8月21日，乌克兰安全局(SBU)，因在核电站现场发现了**数字货币采矿设备，而发起**逮捕行动。

  

据报道，有数字货币矿工通过部署挖矿设备在核电站，而与互联网进行外联挖矿，导致破坏了核设施的安全，并最终泄露了**核电站物理保护系统的机密信息**。而数字货币开采可能涉及乌克兰国民警卫队守卫核电站的员工。  

  

![](../Images/84f3da6911923e15e6aff4d17dd828b7.png)

  

7月10日，由于在南乌克兰核电厂SE NAE Energoatom的一个单独单位的中央控制面板行政大楼104号办公室进行了授权搜查，发现并没收了计算机设备和部件。

  

计算机设备未在核电厂领土内获得授权，形成了一个可以访问互联网的单独的局域网，并用于接收加密货币。

  

在104号机柜中，SBU 查获了六个Radeon RX 470显卡，两个延长线，四个电源，三个系统单元（其中一个是自制的），一个带有电源的开关，带有三个显卡的金属支架，七个提升器和五个延长线，一个主板，一个U盘和一个硬盘。此外还有一套金属框架，其上安装了主板，三个冷却器，五个显卡，一个硬盘和两个电源。

![](../Images/c8e6bf2e1335ea5a8c0ac5ffb62d5a59.png)

![](../Images/73a806605332cc3136056f59824073a7.png)

  

同一天，搜查工作在军事单位3044（乌克兰国民警卫队编辑）使用的场所进行，位于南乌克兰核电站的领土上。搜索结果发现并查获了 16个显卡，一个具有军事单元库存号的system unit，即台式计算机的组件，可见水深，背后是否还涉及军事单位的人参与挖矿呢？

![](../Images/85f83f249dde7fc5c64ffc6a00c5b235.png)

当然，还有七个机械硬盘，两个固态硬盘，一个U盘和一个路由器，均用于数字货币挖矿。  

![](../Images/b849d2f94734304c7d30df2844e06ac1.png)

  

此外，SBU员工在SUE NPP的其他场所发现并没收了CTC联合媒体转换器，光纤和网络电缆，理论上这些电缆不应该出现在这些场所内。

  

![](../Images/983376df3c73cc3ccc404e2991c63c3e.png)

  

当然，这不是乌克兰第一次被偷电挖矿了，据此前报道，2018年2月，俄罗斯联邦核中心的多名工程师因试图使用乌克兰最大的超级计算机之一开采比特币(BTC)而被捕。

  

而这台计算机每秒能够执行1000万亿次计算，为了安全起见，一直与互联网断开连接。

  

当然，怎么着都没有白俄罗斯牛逼。
