# 为实现端对端加密通讯，Zoom买了一个公司

视频会议软件公司Zoom收购了Keybase，后者是端到端加密消息传递和云存储系统的制造商，一个该领域非常著名的初创安全公司。

  

借助Keybase，Zoom用户将能够为视频通话添加端到端加密。

![](../Images/d65efcf96bf6fcaac242fe9ef1af17b9.png)

Zoom首席执行官Eric Yuan说，这项交易旨在支持Zoom的90天安全计划，以增强其平台的安全性和隐私能力。

*“我们自豪地宣布收购Keybase，这是Zoom的90天计划中的另一个里程碑，旨在进一步加强我们的视频通信平台的安全性。自2014年推出以来，Keybase的杰出工程师团队利用其深层的加密和安全专业知识，构建了安全的消息传递和文件共享服务。我们很高兴将Keybase的团队整合到Zoom系列中，以帮助我们构建可以达到当前Zoom可扩展性的端到端加密。  
*

*这次收购标志着Zoom迈出了关键的一步，因为我们试图完成一个真正的私有视频通信平台的创建，该平台可以扩展到亿万参与者，同时还具有支持Zoom广泛用途的灵活性。我们的目标是为每个用例提供尽可能多的隐私，同时还要平衡用户的需求和我们对防止平台上有害行为的承诺。Keybase经验丰富的团队将是此任务的关键部分。”*

  

Keybase的联合创始人Max Krohn称，将Keybase的技术应用到Zoom的软件中需要一些时间，这主要是因为目前该产品主要由安全和密码专家使用，需要对Zoom的广大客户基础进行简化。

  

但需要注意的是，Keybase可以帮助Zoom用户在安排会议时启用端到端加密功能，还可防止手机和云端通话录音。

  

增加的安全功能只能通过Zoom的付费服务享用。
