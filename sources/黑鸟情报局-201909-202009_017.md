# 谷歌已获批运营从美国到中国台湾的海底电缆系统

据外媒报道，谷歌获得美国联邦监管机构批准，可以运营一个从中国台湾到美国的海底电缆系统，此前该公司表示需要更多的连接能力。

  

美国司法部周三的一项决定显示，在美国国土安全部和国防部的支持下，谷歌于4月2日申请了这一许可，并表示其“有迫切需要”，因为该公司认为其系统有可能在未来6个月内达到亚太地区的最大容量。谷歌对监管机构表示，如果不获得批准，它很可能不得不以“明显更高的价格”寻求替代产能。

  

在与联邦通信委员会（FCC）签署最终文件之前，谷歌称之为太平洋光缆网（Pacific Light cable network System）的海底光缆系统将在未来6个月内从美国通到中国台湾。

  

据悉，谷歌在陆地和海底都经营电缆，以确保快速可靠地接入其服务。去年，该公司推出了从非洲到欧洲的电缆网络Equiano。

  

然而，谷歌高管此前曾表示，有足够的能力满足由于消费者在家中接受隔离而对YouTube等产品产生的更高需求。

  

![](../Images/5abd1dac1c5c0693f573c8b9535ecb2f.png)

  

  

谷歌技术基础架构高级副总裁Urs Holzle将3月下旬解决的停电问题归因于第三方路由器中的软件错误。此后不久，他在博客文章中写道，峰值流量水平已在我们处理负载的能力之内。  

  

但是，谷歌在3月底宣布，由于使用量增加，它将暂时默认YouTube上的所有视频恢复为标准清晰度。几份报告显示，最近谷歌云平台的短暂中断导致Gmail、Snapchat(SNAP.US)和谷歌智能家居部门Nest出现故障。

  

谷歌发言人表示，目前，公司认识到谷歌服务的重要性，并致力于增加容量以保持领先水平。公司的全球网络部署和运营团队正在不断提高容量以满足用户的需求，包括运营海底电缆系统
