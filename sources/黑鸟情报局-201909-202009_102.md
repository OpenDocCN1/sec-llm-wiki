# 人在迪拜，被判死刑。

据巴基斯坦《黎明报》当地时间12月17日报道，当天，由三名法官组成的特别法庭对巴基斯坦前总统穆沙拉夫（Pervez Musharraf）判处死刑。穆沙拉夫被控犯有叛国罪。

穆沙拉夫1999年10月通过军事政变上台，2001年正式就任巴基斯坦总统，2008年8月辞去总统职务，2009年开始“自我流放”，旅居英国。2013年3月他回到巴基斯坦，目的是参加大选，但被法院禁止参选。  

  
![](../Images/98d2e25be53a717af17a1864f1b7bfc5.png)

《黎明报》称，穆沙拉夫本人目前并不在巴基斯坦国内，而是身在阿联酋迪拜。

穆沙拉夫2001年开始担任巴基斯坦总统，后多次连任。2007年11月，他宣布实施紧急状态，并解除近60名法官的职务，此举涉嫌违宪。2008年穆沙拉夫辞职，移居英国。2013年，他回到巴基斯坦参加议会选举，但巴选举法院裁定他没有参选资格。

  

![](../Images/e93a9405a0109edecfd56eee1ced56b1.png)

穆沙拉夫回国后，面临包括叛国罪、谋杀前总理贝娜齐尔·布托、杀害宗教神职人员等多项指控。

![](../Images/0512dee83ff0d708e1c342fef6d7a87d.png)

分析人员被打脸。  

  

![](../Images/3269e2858a0aeac86e38e4d6fcd352de.png)

一周前，穆沙拉夫在迪拜的一张病床上抱怨说，对他叛国罪的缺席审判是不公平的。

![](../Images/5825a973cf3b8ad618b56040cb49a638.png)

据报道，穆沙拉夫上因心脏和血压问题入院。穆沙拉夫在迪拜医院发表的视频讲话中说：“我一生都为巴基斯坦服务，我因叛国罪受到审判我为巴基斯坦打仗，为我的国家服务了10年。”

这位近几年居住在迪拜的政治家呼吁巴基斯坦法庭在医院听取他的陈述，并确认他的健康状况。他还要求在宣读对他的案件的判决之前听取他的律师的意见。穆沙拉夫说：“我希望我能得到公正。”穆沙拉夫表示，他受到了不公正的对待。  

  

简单来说，你别回来了。
