# 国家级！默安科技荣登专精特新“小巨人”企业名单

近日，工业和信息化部下发了《工业和信息化部关于发布第四批专精特新“小巨人”企业和通过复核的第一批专精特新“小巨人”企业名单的通告》（工信部企业函〔2022〕191 号），凭借多项优异的指标，默安科技被认定为国家级第四批专精特新“小巨人”企业。

  

  

专精特新“小巨人”企业，指专注于**细分市场、创新能力强、市场占有率高、掌握关键核心技术、质量效益优**的“排头兵”企业。本次获评国家级专精特新“小巨人”，是默安科技继上榜省级专精特新中小企业名单后的又一重要突破，这是对公司在技术研发、自主创新、市场竞争力以及网络安全专业方向的高度认可。

  

作为国内最早专注欺骗防御类产品的优秀网络安全厂商，默安科技汇聚一群擅长“抓”黑客的攻防实战专家，推出了全面适配云环境的“基于攻击欺骗的主动防御体系”。

  

默安科技拥有业内领先的完整DevSecOps方案，具备强大竞争力的产品矩阵，其中的SCA、IAST等核心能力获得国际权威机构Gartner和国内相关机构的多次认可。

  

凭借在DevSecOps、CWPP、容器安全、CSPM等能力的深厚沉淀与布局，默安科技于2022年正式推出业界领先的云原生应用保护平台，帮助客户打造覆盖全栈全生命周期的云原生安全解决方案。

  

自2016年成立以来，默安科技自主研发多款创新型网络安全产品，获得多项专利与软著，并深度参与多项标准制定，在政府、金融、能源、运营商、交通、教育、制造、IT，以及互联网等众多领域有成熟的落地经验和实践成果，累计为上千家政企客户提供网络安全保障。

  

在国家网信办发布的《数字中国发展报告（2021年）》中指出，数字中国建设始终坚持统筹发展与安全，以安全保发展、以发展促安全。作为国家级专精特新“小巨人”企业，默安科技将继续在网络安全专业领域不断深耕，以创新引领、用技术超越，凭借建立领先的下一代安全防护体系，帮助广大政企客户实现更稳健的数字化转型、更高效的业务增长，为全国的网络安全保障体系和能力建设注入新动能，为建设稳定、安全和可持续性的数字中国贡献力量。
