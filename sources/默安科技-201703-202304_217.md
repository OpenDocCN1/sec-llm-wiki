# 默安科技成功举办新安全赋能城市数字化发展创新论坛

近日，由上海临港集团、国泰君安指导，默安科技主办的“上海临港新安全赋能城市数字化发展创新论坛”在上海临港新片区成功举办。

  

来自临港新片区、国家信息技术安全研究中心、国泰君安、上期所、上金所、中证指数、上海农商银行、银联商务、海通证券、光大证券、国金证券、东吴证券、大地保险、上海人寿、同济大学、东华大学、公共卫生中心等近百位领导与嘉宾欢聚一堂，共同探讨城市数字化发展中的网络安全建设创新思路。

  

![](../Images/29602024f1101529319eb4b0126fcc47.png)![](../Images/f300b5ce48e942793630f209e7a9919a.png)

论坛现场

  

首先，由临港集团产业投资促进中心常务副主任陆春发表致辞。他对默安科技在临港新片区成立全资子公司，以及创立云安全创新实验室表示热烈的欢迎和衷心的祝贺，并预祝本次创新论坛圆满成功。

![](../Images/91f738b7182f4e62f955ed932278a7ab.png)

临港集团产业投资促进中心常务副主任 陆春

  

之后，由临港新片区滴水湖金融湾的陆俊杰老师为大家介绍临港新片区的总体概况、建设规划、众多金融开放与创新政策以及当前建设成果。他表示，新片区旨在打造特殊经济功能区，建设现代化产业新城，包含现代服务业开放区、特殊综合保税区、高品质国际社区等功能分区。以现代服务业开放区为例，该区首发地块已投入建设，并与众多金融机构完成签约，致力于将新片区建设成为统筹在岸及离岸业务的国际枢纽。

![](../Images/5953593dac7d0fabcd4b3658430560eb.png)

临港新片区滴水湖金融湾 陆俊杰

  

在深入了解上海临港片区的情况之后，默安科技CEO聂万泉上台发言，他表示，上海是默安科技非常重要的一个市场，是目前投入最大的区域。默安科技是面向数字经济的网络安全厂商，坚持从安全实战与实效的角度出发，帮助企业迎接数字化转型带来的变革与挑战。默安科技作为国内最早在欺骗防御领域从事研究探索与产品落地的安全企业，已经在实战对抗与攻防演练中发挥实实在在的效果和价值，随着安全往实战化、情报化、对抗化的方向发展，默安科技欺骗防御体系化的落地将会为客户带来更大的价值。  

  

在安全前置化领域，默安科技2017年开始探索安全开发的场景与方案，与合作伙伴一起，致力于将安全风险在上线前尽早解决，让线上的业务系统更加安全，做了很多落地的实践工作，目前已经在多个行业有成功案例。相信在未来，默安科技能带来更多创新型的产品与解决方案，帮助客户解决更多真实的问题。

![](../Images/0f730f7dda463981967ed1cbd3316ec7.png)

默安科技CEO 聂万泉

  

国泰君安CIO 俞枫认为，数字中国已经上升为国家战略，在数字化时代背景下，网络安全面临6大挑战：变化的趋势、变化的战场、变化的对手、变化的武器与战术、变化的打击目标，以及变化的指挥监管。目前，网络安全建设工作的视角从关注脆弱性向关注威胁与处置转变，而实战是检验安全防护能力的唯一标准，需要重视实战化的安全运营能力和常态化的安全对抗能力。最后俞总分享了国泰君安在国家级网络攻防演练中的实践经验，以及与默安科技在安全运营中的合作探索。

![](../Images/3cd781ee4f38e34cd355bf7c6586ef60.png)

国泰君安CIO 俞枫

  

演讲结束后，俞总为默安科技云安全架构师韩继颁发了特别聘书，感谢他及默安科技团队为国泰君安的网络安全保障做出的特别贡献，并且希望双方在今后的合作中能够创造更多有价值的成绩。

![](../Images/519f6af6c990e032a4e060e7162bd1a0.png)

国泰君安为默安科技专家颁发特别聘书

  

国家信息技术安全研究中心原副主任兼总工程师李京春发表了题为《关键信息基础设施网络安全治理新举措》的主题演讲。从近期美国地区发生的重大网络安全事件，分析美国网络安全管控新动向，同时为与会嘉宾梳理了自2004以来我国网络安全管控方面的新举措，包括2020年新出台的《网络安全审查办法》、《密码法》、《数据安全法（草案）》等。最后，李总从关键信息基础设施保护框架研究，与加快关键供应链产品创新和应用模式创新两个主要方面，分享了我国关基保护框架研究与新对策的相关内容。

![](../Images/b4abb527f4a3b20a48c4a4cc3cb41bfd.png)

国家信息技术安全研究中心总工程师 李京春

  

默安科技副总裁沈锡镛分享了“实战对抗下的安全运营机遇”，他从攻击视角剖析当下网络安全运营中面临的资产遗漏、漏洞、弱口令等问题，总结出3大安全运营趋势与机遇：数字化催生风险常态化、业务化催生成本集约化、对抗化催生应急常态化。面对这样的机遇与挑战，沈总认为企业需要将攻防、合规、风控作为抓手，以技术、策略、架构为基础，同时安全效果的保障需要依赖于企业文化的“升级与迭代”。

![](../Images/f5e0fb9379aff1c49fdca6fb15b47996.png)

默安科技副总裁 沈锡镛

 

默安科技云安全架构师韩继则与现场嘉宾探讨了如何实现多云环境下的安全治理。多云部署拥有低成本、更便捷、满足合规等多项优势，但安全痛点也同样非常明显。韩继提出构建以云安全态势管理和云工作负载安全服务为主要模块的多云安全架构，包括统一的身份认证与权限管理、云资产自动识别、云合规检测、DevSecOps与容器安全、云威胁防护、云数据保护等。最后韩继为现场嘉宾介绍了默安科技即将发布的容器安全解决方案——影木。

![](../Images/52b2478a10063190e45d9a076f17bbcb.png)

默安科技云安全架构师 韩继

  

会议最后，默安科技华东总经理张源进行了与临港新片区的合作展望，并致谢全体参会嘉宾。他表示，目前正值建党百年重要时刻，国家、社会和时代赋予新的机遇和挑战，相信在临港新片区政府和临港集团的支持下，默安科技将用新安全体系和最佳实践为上海这座面向全球的数字化之城再增加一份安全感！
