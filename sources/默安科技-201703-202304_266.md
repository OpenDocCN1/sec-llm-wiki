# 华为安全商业联盟例行沟通会在默安科技召开

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODQxMjM2NQ==&mid=2247487089&idx=1&sn=35bdf101580a1c24c0f719cc38cd2a6d&chksm=e938f953de4f7045642cdeb27d1a73f6b39cebfa5ef944e5eb49c4cccec806ad5a00eafb00cc&scene=126&sessionid=1681373009#rd](http://mp.weixin.qq.com/s?__biz=MzIzODQxMjM2NQ==&mid=2247487089&idx=1&sn=35bdf101580a1c24c0f719cc38cd2a6d&chksm=e938f953de4f7045642cdeb27d1a73f6b39cebfa5ef944e5eb49c4cccec806ad5a00eafb00cc&scene=126&sessionid=1681373009#rd)

近日，华为安全商业联盟（以下简称“联盟”）例会在默安科技召开，华为安全产品领域总裁宋端智带队与默安科技CEO聂万泉及管理团队共同回顾了从建立合作以来各阶段的合作情况，并对双方优势方案整合、产品发展方向、重点场景识别、标杆项目突破等方面展开研讨，形成了可执行性较强的合作计划。

  

![](../Images/6278ea3c9c3368eec33c757cd5f79be1.png)

华为与默安科技安全合作高层工作会议

 

默安科技CEO聂万泉首先带领华为安全产品领域总裁宋端智一行专家参观默安科技杭州总部办公环境，并对公司整体情况、产品体系、成果成就以及市场占有率等作了简单介绍。

 

会上，默安科技COO汪利辉及相关方案负责人向华为安全与会专家介绍了默安科技在欺骗防御和开发安全两大领域的技术研究、产品落地和市场拓展情况。在重点合作的欺骗防御细分领域，双方均表达了继续深入合作的意向，并对进一步的合作方向、合作内容展开了深入讨论，期盼双方携手发展，合作共赢，共同促进安全产业发展。

 

![](../Images/ea328e2d2f32fce9b2a2e080060280c3.png)

默安科技COO汪利辉发言  

 

华为安全产品领域总裁宋端智表示：“默安科技是国内在安全细分有优势、具创新性的一家新兴安全厂商。特别是默安的欺骗防御产品，是对流量检测等安全产品的有力补充，同时有很多创新性的思考和功能落地。本次例行沟通是双方合作进入新阶段的转折点，我们也从详细的默安业务介绍中看到了更多方案融合和市场开拓的可能性。希望借助建立的华为安全商业联盟例行沟通机制，默安与华为及其他联盟成员能够持续加大业务沟通，碰撞产生化学反应，在商业上双方有更多产出，实现共赢。”

 

![](../Images/6f7747453e97385401ce9e9228a770ab.png)

华为安全产品领域总裁宋端智发言  

 

聂万泉表示：“默安科技自加入华为的联盟生态以来，与华为安全在市场拓展工作中合作紧密，并取得阶段性的项目成果。而本次例会则进一步加深了双方对彼此业务重点的理解，将合作水平推向了一个全新的层次。在未来的合作中，默安仍将发挥自己在欺骗防御与攻防对抗领域的优势能力，根据实际应用场景，加强与华为HiSec安全解决方案的深度整合，形成优势互补，共同服务好各行业客户。”

 

![](../Images/b2f929e8be5f0063fe2fbf82835c4e04.png)

默安科技CEO聂万泉发言

 

**华为安全商业联盟**

“华为安全商业联盟”由华为技术有限公司牵头成立，集合国内安全产业细分领域具有领先竞争力的安全企业自愿组成。联盟旨在基于创新的华为HiSec安全解决方案，深度整合联盟伙伴在细分领域的竞争力领先产品，实现网络、应用和终端之间的协同联动，为政企客户提供更具防护实效的安全解决方案和服务。2019年初，默安科技作为欺骗防御技术细分领域优秀伙伴，与华为开展相关技术和产品方案深度合作，并于2020年8月8日成为华为安全商业联盟2.0正式成员。
