# 捷报！默安逐日实验室获中国电信“天翼杯”攻防大赛一等奖

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODQxMjM2NQ==&mid=2247486736&idx=1&sn=596c68f51d0b68cc2801d956c64c16f6&chksm=e938fa32de4f732424151525f8b614c78be045ec41b3210bcdf057224a3c43ed9f30a9f0bc0d&scene=126&sessionid=1681373014#rd](http://mp.weixin.qq.com/s?__biz=MzIzODQxMjM2NQ==&mid=2247486736&idx=1&sn=596c68f51d0b68cc2801d956c64c16f6&chksm=e938fa32de4f732424151525f8b614c78be045ec41b3210bcdf057224a3c43ed9f30a9f0bc0d&scene=126&sessionid=1681373014#rd)

  

8月14日上午10点，2020 中国电信“天翼杯”网络安全攻防大赛决赛拉开帷幕。**默安科技逐日实验室（逐日战队）**经过长达六个小时的角逐，凭借对攻防能力的积累和对内网渗透体系的研究实践，在比赛中过关斩将，最终获得总排名**第二名(一等奖)**的好成绩。

  

![](../Images/f3e588b3e3d5c6875742c1c51df819e0.png)

  

本次大赛由中共上海市委网络安全和信息化委员会办公室指导，中国电信股份有限公司主办，移动互联网系统与应用安全国家工程实验室等单位协办。

  

大赛赛题，采用模拟仿真综合渗透赛的模式，搭建了一个企业的网络环境，涉及多个前沿热门应用、及多层网络越级技术，模拟真实企业生产环境，涉及内网安全、反向代理、内网穿透、服务器提权、中间件安全、数据库安全等知识点，参赛选手以攻击者的身份，对模拟的企业网络环境进行内网渗透、内网穿透等操作。

  

![](../Images/9ab67eada8b395900bf077b29d36e49e.png)

  

比赛尘埃落定，安全仍需奋勇前行。逐日团队在追逐网络安全的路上，仍将砥砺前行。期待超越昨天的自己，渴望遇见更强的对手，创造属于逐日的安全时刻！
