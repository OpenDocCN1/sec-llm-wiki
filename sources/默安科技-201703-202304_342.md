# 预警！Apache Solr Velocity注入远程命令漏洞（哨兵云支持检测）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODQxMjM2NQ==&mid=2247485881&idx=1&sn=baf63f71cb82b8d612950a739370e285&chksm=e938fe9bde4f778d0a03906a33611eb95fd598a2dad7746b1b94a6126fd48dbf262aab83c91d&scene=126&sessionid=1681373044#rd](http://mp.weixin.qq.com/s?__biz=MzIzODQxMjM2NQ==&mid=2247485881&idx=1&sn=baf63f71cb82b8d612950a739370e285&chksm=e938fe9bde4f778d0a03906a33611eb95fd598a2dad7746b1b94a6126fd48dbf262aab83c91d&scene=126&sessionid=1681373044#rd)

Apache Solr 是一个开源的搜索服务器，主要基于 HTTP 和 Apache Lucene 实现。2019年10月31日，国外安全研究员S00pY在GitHub公开了该漏洞的poc，漏洞等级严重，危害影响面广。目前Apache Solr官方未发布该漏洞的补丁。攻击者进行攻击后，可以进行反弹shell，直接获取服务器系统权限，进一步可威胁内网。

默安科技的哨兵云资产风险监控系统目前已支持该漏洞的检测。如果您的企业存在相关风险，可联系我们辅助检测是否受到此类漏洞影响，以免被攻击者恶意利用，造成品牌和经济损失。

 

  

**漏洞描述**

当Apache Solr被可以直接访问控制台，并且可以通过POST请求修改模块的配置文件，同时VelocityResponseWriter模块中的params.resource.loader.enabled参数被设置为true时，将允许用户通过设置请求中的参数来指定相关资源的加载，这也就意味着攻击者可以通过构造一个具有威胁的攻击请求，在服务器上进行命令执行。  

  

  

**受影响的版本**

经过测试，我们发现影响面包含Apache Solr 7.x.x和8.x.x，推测影响全版本。  

 

  

**漏洞检测**

对于该漏洞，目前默安科技的哨兵云资产风险监控系统已支持通过安装相关应急插件进行检测，如下图所示。

![](../Images/523e4b4ea4090f8570eb19b2b29ca440.png)

  

  

**漏洞修复**

官方尚未有补丁，建议配置Apache Solr为授权访问，并手动修改params.resource.loader.enabled为false。
