# 漏洞预警 | fastjson<1.2.60远程拒绝服务漏洞（雳鉴SAST支持检测）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODQxMjM2NQ==&mid=2247485764&idx=2&sn=3f007298804f12123997cb0318ae5f53&chksm=e938fe66de4f7770eebee840c9fd0a951259e6b216ab8d392c5dc4d7fc9d45b97a20c816e611&scene=126&sessionid=1681373049#rd](http://mp.weixin.qq.com/s?__biz=MzIzODQxMjM2NQ==&mid=2247485764&idx=2&sn=3f007298804f12123997cb0318ae5f53&chksm=e938fe66de4f7770eebee840c9fd0a951259e6b216ab8d392c5dc4d7fc9d45b97a20c816e611&scene=126&sessionid=1681373049#rd)

fastjson是阿里巴巴的开源JSON解析库，它可以解析JSON格式的字符串，支持将Java Bean序列化为JSON字符串，也可以从JSON字符串反序列化到JavaBean。  

  

近日，默安科技应急响应中心监测到fastjson曝出远程拒绝服务漏洞，该漏洞影响fastjson多个版本，攻击者通过发送恶意字符串可导致服务器CPU/RAM过载，造成服务器宕机。

  

该漏洞危害大且不适宜远程检测，而默安科技雳鉴SAST能够开展软件成分风险检测，及时发现fastjson<1.2.60远程拒绝服务漏洞，梳理存在该漏洞所影响的项目和代码，帮助客户避免损失。

  

**漏洞描述**

fastjson中的funcion中处理转义字符时（\\x），通常情况下正确的格式为\\xHH（H表示16进制字符），如果输入的字符串没有使用该格式，应当会触发程序错误，进而报错（Jackson使用该处理方式）。fastjson在这样的情况下，会继续读取后续字符，如果此时fastjson读取的为EOF（文件结束符），则不会触发发序列化结束，而是继续不断读取EOF，在内存中不断申请内存存储EOF，最终导致OOM（内存溢出）。

  

针对上述情况，可以在读取\\x字符时，对参数进行检验，如果\\x格式不为通常的格式，程序可以抛出异常信息JSONException。  

  

**受影响的版本**

fastjson < 1.2.60  

fastjson sec版本 < sec06

  

**漏洞修复**

版本升级至fastjson >= 1.2.60；兼容性版本升级至fastjson sec版本 >= sec06；较低版本升级至最新版本可能会出现兼容性问题，建议升级至特定版本的sec06 bugfix版本。
