# 漏洞预警 | Confluence本地文件泄露漏洞（哨兵云支持检测）

> 原文：[http://mp.weixin.qq.com/s?\_\_biz=MzIzODQxMjM2NQ==&mid=2247485748&idx=1&sn=6e94764f2fa8627bdd77e5abc3a7e460&chksm=e938fe16de4f7700ea2def8c54cf664e790bb711810e73ab3715275bb530da239fab44333bfe&scene=126&sessionid=1681373049#rd](http://mp.weixin.qq.com/s?__biz=MzIzODQxMjM2NQ==&mid=2247485748&idx=1&sn=6e94764f2fa8627bdd77e5abc3a7e460&chksm=e938fe16de4f7700ea2def8c54cf664e790bb711810e73ab3715275bb530da239fab44333bfe&scene=126&sessionid=1681373049#rd)

Confluence是一个非常流行的专业的企业级知识管理与协同软件。近日，Confluence 官方发布预警，指出Confluence Server 与 Confluence Data Center 中存在本地文件泄露漏洞。攻击者可能利用此漏洞读取特定目录下的任意文件，同时该漏洞被赋予编号CVE-2019-3394。

  

默安科技的哨兵云资产风险监控系统目前已支持该漏洞的检测，如果您的企业存在相关风险，可以联系我们辅助检测是否受到此类漏洞影响，以免被攻击者恶意利用，造成品牌和经济损失。

  

![](../Images/ae7863032a4ef670eb8241c2ea809d73.png)

**漏洞描述**

  

Confluence Server和Confluence Data Center在页面导出功能中存在本地文件泄露漏洞。具有添加页面空间权限的远程攻击者将能够读取<install directory>/confluence/web-inf目录中的任意文件，其中可能包含用于与其它服务集成的配置文件、也可能包含泄露凭据（如LDAP凭据）或其它敏感信息，给攻击者二次攻击提供便捷。

  

![](../Images/ae7863032a4ef670eb8241c2ea809d73.png)

**受影响的版本**

  

6.1.0 <= version < 6.6.16

6.7.0 <= version <  6.13.7

6.14.0 <= version < 6.15.8

  

![](../Images/ae7863032a4ef670eb8241c2ea809d73.png)

**漏洞检测**

  

对于该漏洞，目前默安科技的哨兵云资产风险监控系统已支持通过安装相关应急插件进行检测（目前仅哨兵云saas支持），如下图所示。

  

![](../Images/9a35d543c564062fc69b4c1c7ca5520d.png)

  

![](../Images/ae7863032a4ef670eb8241c2ea809d73.png)

**漏洞修复**

  

1\. 升级 Confluence 到已修复漏洞的更新版本：6.15.8 或 6.13.7 或 6.6.16。

2\. 检查<install directory>/confluence/web-inf目录及其子目录（尤其是/classes/），查找包含LDAP或Crowd凭据（crowd.properties、atlassian user.xml）的任何文件，管理员可能已将其放入此目录。如果没有发现任何漏洞，则说明暂时不会被利用该漏洞。如果在这些目录中找到凭据，则应修改相应密码。
