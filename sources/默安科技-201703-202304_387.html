漏洞预警|Atlassian Confluence远程代码执行(CVE-2019-3396)

        Confluence是一个非常流行的专业的企业级知识管理与协同软件。2019年3月28日，Confluence 官方发布预警，指出Confluence Server 与 Confluence Data Center 中的 Widget Connector存在服务器端模板注入漏洞。攻击者可能利用此漏洞实现目录遍历和远程代码执行，同时该漏洞被赋予编号CVE-2019-3396。


        默安科技的哨兵云资产风险监控系统目前已支持该漏洞的检测，如果您的企业存在相关风险，可以联系我们辅助检测是否受到此类漏洞影响，以免被攻击者恶意利用，造成品牌和经济损失。


        漏洞描述


      Widget连接器中的Confluence Server和Data Center中存在服务器端模板注入漏洞。攻击者能够利用此问题在运行易受攻击的Confluence Server或Data Center版本的系统上实现目录遍历和远程代码执行。


        受影响的版本


     版本6.6.12之前的所有版本的Confluence Server和Confluence Data Center，6.12.3之前的版本(6.7.0~6.12.x的固定版本)，6.13.3之前的版本(6.13.0~6.13.x的固定版本)和6.14.2之前的版本(6.14.0~6.14.x的固定版本)。

      对于该漏洞，目前默安科技的哨兵云资产风险监控系统已支持通过安装相关应急插件进行检测，如下图所示。
